# Книга — HTML-обгортка над курсом

Гарна навігована «книжка», що збирається **прямо в браузері** з тих самих `.md`-файлів,
якими пишеться курс. Без збірки: закомітив новий розділ — і він у книзі.

## Файли обгортки

| Файл          | Призначення |
|---------------|-------------|
| `index.html`  | Оболонка (сайдбар + область вмісту). Точка входу. |
| `book.css`    | Усі стилі (палітра й компоненти з прототипу `ch01.html`). |
| `book.js`     | Рушій без залежностей: парсер Markdown під конвенції курсу, hash-роутер, збірка навігації. |
| `manifest.js` | **Структура книги** — повна мапа всіх 50 розділів зі статусами. Єдине, що редагується вручну. |

Старий рукотворний прототип `…/ch01-charge-field-potential/ch01.html` більше не потрібен
(його замінює спільний рушій) — можна лишити як зразок або видалити.

## Як подивитися локально

`index.html` тягне `.md` через `fetch`, а він **не працює** з `file://`. Тому — будь-який
локальний сервер:

```
cd embedded
python -m http.server
```

і відкрий <http://localhost:8000/>. (Обкладинка/зміст показуються навіть без сервера —
бо беруться з `manifest.js`; а от вміст розділів потребує саме `http://`.)

## Як викласти на GitHub Pages

Репозиторій уже на GitHub. Увімкни **Settings → Pages → Deploy from branch**, гілка `main`,
папка `/ (root)`. Книга буде за адресою:

```
https://<користувач>.github.io/<репозиторій>/embedded/
```

Усі шляхи в обгортці **відносні**, тож працює і локально, і на Pages без змін.
(Якщо хочеш короткий URL без `/embedded/` — скажи, додам у корінь репо маленький
`index.html`-редірект.)

## Як додати готовий розділ у книгу

Відкрий `manifest.js`, знайди потрібний розділ і додай йому поля (приклад — Модуль 1):

```js
{
  n: 7, status: "done",
  title: "Конденсатор",
  dir: "block-2-components-analog/ch07-capacitor",
  main: "ch07-capacitor.md",
  histories: [                       // у порядку читання; заголовки тягнуться з файлів
    "ch07-history-leyden-jar.md"
  ]
}
```

Більше нічого: сайдбар (теми + історії), якорі, перехресні `.md`-лінки й мапа курсу
зберуться самі. Поки `status: "pending"` — розділ показується в змісті сірим («незабаром»).

## Що рушій розуміє в Markdown (конвенції курсу)

- `## N.M Назва` → тема з якорем `#ch=<slug>&at=sec-N-M`; `###`/`####` — підзаголовки.
- `> 🔧 …` → інженерна рамка «Навіщо це»; `> 📜 …` → історична; `> ▶️ …` → навігаційна.
- `![alt](img/fig.svg)` + наступний рядок `*Рис. N.M.k. …*` → `<figure>` з підписом.
- Код-блоки ``` ``` ``` → моноширинні формули/обчислення (Unicode-математика — як є).
- `[текст](файл.md)` і `[§N.M](../chNN-slug/файл.md)` → переписуються на маршрути книги
  (історії того ж розділу — внутрішні якорі; інші розділи — перехід між сторінками).
- Історичні файли (`# 📜 …`) додаються як окремі блоки в кінці своєї сторінки-розділу.
