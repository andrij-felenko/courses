# writer_ua

Конвеєр письма для корпусу в `root/`. Самодостатній: нічого зі `scripts/` не бере.

**Алгоритм** — `ALGORITHM.md`, словами автора. Де код чи інший документ розходяться з
ним — правда там.

**Правила** — `rules/`, мапа файлів і збирання запитів — `rules/README.md`.

**Скрипти** — `API.md`: локальні команди (`local/`), перевірки (`checkers/`), рушій
(`runners/`).

## Два рівні

**Оркестратор** (`runners/orchestrator.js`) тримає чергу одиниць, пул активних, стан батчу
в `inwork/<хеш>/`, приймає виклики від алгоритму (завести вставку, код, фігуру, нову тему)
і в кінці пише маніфест.

**Алгоритм** (`runners/algorithm.js`) веде одну одиницю етапами 1–10. Запити збирає
`runners/prompt.js` з файлів `rules/`, відповіді розбирає `runners/parse.js` — блоками туди
й назад, ніколи JSON. Локальні кроки — `runners/local.js`.

## Одиниця

Версія статті (`<тема>-d.md`, `<тема>.md`) або вставка (`<тип>-<ім'я>.md`); код і фігура —
свої одиниці з власною дорогою. Адреса — `книга/тема:detailed`, `книга/тема:hist-<ім'я>`.
