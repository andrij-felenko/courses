# code — правила КАРКАСА

Іде в запит 2 (етап 3). Більше нікуди.

## Що просимо

Склади архітектуру: які файли, які класи, базова структура.
Для кожного файла скажи, що він робить. Біля кожного постав важливість.

## Що повертає

    <ФАЙЛИ>{шлях} | важливість: {…} | {що робить}</ФАЙЛИ>
    <КЛАСИ>{ім'я} | {відповідальність}</КЛАСИ>
    <СТРУКТУРА>{як воно складається докупи}</СТРУКТУРА>

## Що знаємо

Важливість каже одне: **що розширювати першим**, коли буде чим. Це не «цінність для читача».

## Що треба зробити

- групування: чи рахує обсяг локальний скрипт і передає числом, чи каркас виводить сам —
  **не вирішено**
