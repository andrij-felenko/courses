📋 `api-` — **інтерфейс/довідка («те, що стирчить назовні»):** не сухий список сигнатур, а зрозумілий опис контракту: призначення інтерфейсу, параметри, повертувані значення, коди помилок, інваріанти (thread-safety, preconditions) та реальний приклад виклику. **Загальна назва для обох доменів, але НЕ змішувати:** треба темі і залізо, і софт — **два окремі `api-` файли** (напр. `api-wiring.md` + `api-lib.md`), не один мішаний.
