# comp — правила ПИСЬМА

Іде в запити 3, 4, 6, 7. Це найдорожчий текст у системі: його носить кожен письменник і
перечитує на кожному ході. ⛔ Тут лише те, без чого текст буде НЕПРАВИЛЬНИМ.

## Треба зробити

Проведи всі варіанти строго по одній осі, названій каркасом.

<!-- канон: початок -->
🔌 `comp-` — **компонент**: **узагальнений** клас пристрою/мікросхеми (фізичний принцип дії, розпіновка, підключення, інтерфейси та інженерні граблі) — **без партномерів**; конкретні продукти йдуть у каталозі (критерій — §1).

    <ТЕКСТ>готова проза розділів</ТЕКСТ>

    <ЧИ ПОВНО>чи покрито поставлені питання</ЧИ ПОВНО>
    <ЩО ЗЖАТИ>що можна стиснути без втрати сенсу й на чому; немає — пустота</ЩО ЗЖАТИ>
