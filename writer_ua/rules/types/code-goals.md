# code — ціль

**Код.** Окрема одиниця з власною дорогою: ціль → архітектура → файли. Прози в ній немає.

Іде в запит цілі, етап 1. Дані — що замовив каркас проєкту: що реалізувати і якою мовою.

## Треба зробити

Сформулюй, що саме цей код має реалізувати і що людина має зрозуміти, читаючи його: за
кілька хвилин, дивлячись на файли, код і коментарі, — усю концепцію того, як це робиться.
Не ідеально вилизаний продукт, а приклад з реальності в мінімальному прояві.
