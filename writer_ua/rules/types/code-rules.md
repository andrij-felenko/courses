# code — письмо

Іде в написання одиниці коду разом із `code-lang.md`. Прози тут немає.

## Треба зробити

**Реалізуй те, що названо архітектурою.** Код не має бути вилизаним: він приклад, пишеться
швидко і показує реальність у мінімальному прояві — з ракурсу професіонала, який знає, які
бувають проблеми, і враховує їх в архітектурі поверхово, не роблячи головною задачею.

**Мірило одне:** людина за кілька хвилин, дивлячись на весь проєкт, код і коментарі,
розуміє всю концепцію.

**Повнота.** Код реалізує все, що названо: жодного «лишаємо читачеві», «решта симетрично»,
жодної заглушки там, де обіцяно поведінку. Обробка помилок і незручні випадки є; без
конфігурованості, без шарів «щоб потім підмінити», без узагальнень на випадки, яких у темі
немає. Коментарі — українською.

**Модулів стільки, скільки має сама річ,** а річ навчальна й мала. README — ніколи; файл
збірки — лише коли без нього не запускається, і тоді один і мінімальний.

**Тека мови — корінь проєкту**, всередині звичайна для цієї мови розкладка; платформа —
під мовою окремим рівнем.

**Вкладка C++ мусить бути C++, а не C з іншим розширенням:** контейнер або розумний
вказівник замість ручного звільнення; обгортка з деструктором замість закриття наприкінці;
рядок-вид або span замість вказівника з довжиною; шаблон замість макроса. Якщо після
перекладу C++ не відрізняється нічим, крім заголовків, — приклад суто C-шний, і другої
вкладки не треба.

**Мікроконтролер.** Код під Arduino ніколи не стоїть сам: поруч щонайменше ще одна
платформа — те саме завдання так, як його справді пишуть там.
