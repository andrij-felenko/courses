# code — правила ПИСЬМА

Іде в запити 3, 4, 6, 7. Це найдорожчий текст у системі: його носить кожен письменник і
перечитує на кожному ході. ⛔ Тут лише те, без чого текст буде НЕПРАВИЛЬНИМ.

## Треба зробити

Реалізуй те, що названо каркасом. Поверни розкладку файлів: який файл і що в
ньому. Тексту прози не пиши.


## Треба отримати

По одному блоку на файл; шлях — відносний від кореня проєкту мови:

    <ФАЙЛ>{шлях} :: {що робить}
    {вміст файла}</ФАЙЛ>

## Коментарі

- мова прикладів коду для книги — **не задано**; агенти обирали самі й обирали різне
- чи діє тут правило «є C — має бути й C++» — **не сказано в завданні**
