# code — письмо

Іде в написання одиниці коду разом із `code-lang.md`. Прози тут немає.

## Треба зробити

**Реалізуй те, що названо архітектурою.** Код не має бути ідеально вилизаним: він слугує
прикладом, пишеться швидко і показує реальність у мінімальному прояві — але з ракурсу
професіонала: ти вже знаєш, які можуть бути проблеми, як їх обходити, як писати
перевірки, і враховуєш це в архітектурі поверхово, не роблячи з цього головну задачу.

**Мірило одне:** людина за кілька хвилин, дивлячись на весь проєкт, код і коментарі,
розуміє всю концепцію. Не заскладний; показує мінімально те, що поглибить знання.

**Повнота.** Код реалізує все, що названо: жодного «лишаємо читачеві», «решта симетрично»,
жодної заглушки там, де обіцяно поведінку. Обробка помилок і незручні випадки в ньому є,
бо професіонал інакше не пише; але без конфігурованості, без шарів «щоб потім підмінити»,
без узагальнень на випадки, яких у темі немає. Коментарі — українською.

**Модулів стільки, скільки має сама річ,** а річ навчальна й мала: десятків файлів не буває.
Тягне завести ще один файл «щоб було правильно» — спитай, чи піде читач його читати. Пиши
те, про що файл: предмет файла вирішує вміст теки. README — ніколи: його роль виконує
стаття. Файл збірки — лише коли без нього не запускається, і тоді один і мінімальний.

**Тека мови — корінь проєкту**, всередині звичайна для цієї мови розкладка. Платформа
лягає під мову окремим рівнем.

**Вкладка C++ мусить бути C++, а не C з іншим розширенням.** Ідіоматичний еквівалент — це
те, чим C++ відрізняється в цій задачі: контейнер або розумний вказівник замість ручного
звільнення; обгортка з деструктором замість закриття наприкінці; рядок-вид або span замість
вказівника з окремою довжиною; шаблон замість макроса чи void-вказівника з розміром. Якщо
після перекладу C++ не відрізняється нічим, крім заголовків, — приклад суто C-шний, і другої
вкладки не треба.

**Мікроконтролер.** Код під Arduino ніколи не стоїть сам: поруч щонайменше ще одна
платформа — те саме завдання так, як його справді пишуть там, не переклад рядок у рядок.

## Треба отримати

    {вміст файла}</ФАЙЛ>
