# code-lang

**Обсяг:** якою мовою пишеться код

Іде туди, де вирішують мову: у каркас проєкту, в архітектуру коду, у письмо з кодом.

## Треба зробити

**Мова — та, якою це найбільше роблять насправді.** Не одна назавжди: якщо цю річ роблять
кількома мовами паралельно — пишемо кількома, вкладками. Мова має бути правдивою для
прикладу: доменно-замкнений код лишається однією мовою; загальну ідею, коректну в кількох,
можна показати кількома.

**C і C++ додавай завжди, окремими вкладками,** поруч із мовою, якою це роблять. Кожна з
двох — самостійний ідіоматичний приклад тієї самої задачі, не переклад із сусідньої.

**Без вкладки C++ — лише там, де C++ неможливий:** простір ядра, де немає ані бібліотеки,
ані винятків; приклад про сам C як мову, де предметом є C, а не задача; чужий інтерфейс,
показаний як є, який ми цитуємо, а не пишемо. Усе інше — простір користувача, файли й
сокети, розбір форматів, обчислення, структури даних, утиліти — дістає обидві.

**Платформа — не мова.** Середовище мікроконтролера лягає під мову окремим рівнем, і в
полі «мова» стоїть саме мова.

## Коментарі

- C і C++ завжди, без «чи хоч хтось так пише» (автор, 14.09): два абзаци тягли в різні
  боки, і відповідач брав той, що дає вибір, — проєкти книг про програми виходили без C і C++
