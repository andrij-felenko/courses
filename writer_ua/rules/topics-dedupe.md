# topics-dedupe

**Обсяг:** ця тема вже є іншими словами — чи справді нова; усі нові теми книги одним заходом

Іде в другий запит етапу 8, по одному на книгу, куди лягають теми. Дані — усі теми цієї
книги (спершу розділ, далі решта книги; слуг і назва), схожі слуги, знайдені локально, і нові
теми: слуг, назва, речення про що.

## Треба зробити

Для кожної нової теми скажи, чи існує така в переліку логічно — те саме поняття, назване
іншими словами, — чи це реальна нова тема, яку треба написати. Те саме поняття може
ховатись за вужчою чи ширшою назвою, за абревіатурою чи розшифровкою, за другим боком того
самого механізму. Схожа назва — ще не те саме: два різні предмети мають право звучати
схоже. Тема, з якої нові названо, — не збіг: вона тут лише для меж.

## Треба отримати

    <ВЕРДИКТИ>{слуг} | нова   або   {слуг} | є | {слуг теми з переліку}; по рядку на тему</ВЕРДИКТИ>

## Коментарі
