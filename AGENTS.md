# Репозиторій курсів-книг (4 книги, збираються в браузері)

Чотири книги, що збираються прямо в браузері з Markdown:
- **«Вбудована електроніка й автономні системи»** (`embedded/`) — головний курс;
- **«Хімія»** (`chemistry/`) — короткий ввідний курс;
- книги-довідники до embedded: **«Математика»** (`math/`) і **«Компоненти»** (`components/`).

Обгортка — корінь репо: `index.html` (бібліотека), entry-сторінки (`electronics.html`/`chem.html`/`math.html`/`comp.html`), рушій `book.js`, складач `scripts/bookbuild.js`, кореневі індекси `manifest*.js`.

## Єдине джерело правди — per-module `manifest.js`

- **На кожен модуль** книги — один файл `<book>/<module-slug>/manifest.js`, що реєструє модуль:
  `(window.__MODREG__ = window.__MODREG__ || []).push({ n, slug, title, chapters:[…] })`.
  Це ЄДИНЕ джерело: **навігація + план + черга + статуси**. Старих `_status.md`/`PLAN.md`/`SYLLABUS.md`/`FINDINGS.md`/`DEEPENING.md` **немає**.
- Кожен `chapter` має `{ n, title, dir, main, status, scope, topics:[…] }`. `topics[]` містить **теми** `{mrt,title,status,scope}` і **вставки** `{kind,file,at,status,title}` (`kind` ∈ hist/comp/math/proj). Рушій сам ВИВОДИТЬ `histories[]`/`extras[]` зі `topics[]`.
- **Статуси (enum):** `done` (готово) · `empty` (не почато) · `update` (треба переписати) · `deeper` (треба поглибити). Міняй статус ПРЯМО в `manifest.js` модуля одразу після правки.
- **Кореневі `manifest*.js` — тонкий ІНДЕКС книги:** `window.BOOK_META` + `window.BOOK_MODULES` (масив рядків-URL `"<slug>/manifest.js"` або inline-обʼєктів). Складає `scripts/bookbuild.js` (`assembleBook`, серіалізовано); книга без `BOOK_MODULES` працює legacy через `window.BOOK`.

## Канон правил — один файл

- **`AUTHORING.md`** у корені — ЄДИНИЙ канон для всіх книг: §1 спільне ядро (метод Фейнмана, плавність, жива мова, формули, фігури, факти), §2 розміри, §3 тип «нормальна учбова книга» (**embedded + математика + компоненти**), §4 тип «короткий ввідний курс» (**Хімія**), §5 шаблони тем/підтем. Правила — лише тут; план/черга — у `manifest.js`.
- **Нумерація М.Р.Т** (модуль.розділ.тема): заголовки тем `## М.Р.Т Назва`, фігури `Рис. М.Р.Т.k`. Нейминг **slug-only** (теки/файли без номерів; номери — лише в manifest).

## Скрипти — усі в `scripts/` (універсальні)

- Помічники: `bookbuild.js` (складач книг), `svgkit.py`/`svgcheck.py`/`linkcheck.py` (фігури/перевірки; `figs.py` розділу імпортує `svgkit` зі `scripts/`), `index-from-manifest.js`/`split-modules.js` (трансформи індексів).
- Воркфлоу (запуск через `Workflow scriptPath="scripts/<name>.js"`): `complete-module.js` (написати модуль: бере `empty`/`update` → проза), `deepen-inserts.js` (поглибити `deeper`), `restructure-book.js`. Скрипти **універсальні** (параметр книги), не per-book.

## Паралельність і loop-сесії

- **Модулі ізольовані** (своя тека + свій `manifest.js`) → кілька `/loop`, по одному на модуль, працюють паралельно. Працюй лише в `manifest.js` свого модуля.
- Кожна ітерація **самодостатня**: усе потрібне — у `manifest.js` модуля + `AUTHORING.md`; результати попередніх ітерацій у контексті не потрібні.
- Великий крок (повна тема/розділ) **делегуй сабагенту** з повною інструкцією й файловими шляхами; у головну сесію loop'а повертай лише короткий звіт (що зроблено, які статуси переставлено) — жодного тексту тем у контекст оркестратора.
