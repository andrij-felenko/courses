# 🧮 Звідки береться навантажувальний доданок і формула зрізу

Тут розкладено по кроках те, що в основній розповіді лишилося на рівні «друга ланка п'є струм». Мета — побачити **точну** передавальну функцію двох ланок поспіль, упевнитися, чому вона не дорівнює добутку, і вивести два числа, якими користуються щодня: коефіцієнт зсуву зрізу й правило `R2 ≥ 10·R1`.

Працюємо в **комплексній частоті** (комплексне число замість «опору» конденсатора), бо так алгебра ділення напруги лишається такою самою, як у звичайному резистивному дільнику, тільки з частотно-залежними членами. Хто хоче згадати, чому конденсатор зручно описувати одним комплексним імпедансом і звідки береться зсув фази — це окрема тема.

> Конденсатор на синусоїді частоти ω поводиться як «опір», що залежить від частоти: його імпеданс Z_C = 1/(jωC), де j — уявна одиниця, а ω = 2πf. Модуль цього імпедансу — та сама реактивність X_C = 1/(ωC); множник j кодує зсув фази на чверть періоду. З цим імпедансом закон Ома й правило дільника напруги працюють без змін. Деталі — у [реактивності](book:electronics/reactance).

## Одна ланка: знайомий результат

Почнемо з однієї RC-ланки нижніх частот — резистор R послідовно, конденсатор C на землю, вихід знімаємо з конденсатора. Це звичайний дільник напруги, у якому нижнє «плече» — імпеданс конденсатора:

```
            Z_C              1/(jωC)
H(jω) = ───────────  =  ───────────────
          R + Z_C         R + 1/(jωC)
```

Помножимо чисельник і знаменник на jωC, щоб прибрати дріб у дробі:

```
              1
H(jω) = ─────────────
          1 + jωRC
```

Це канонічний вигляд однополюсного фільтра. Уся його поведінка сидить в одному добутку ωRC. Коли ωRC = 1 — тобто на частоті ω_c = 1/(RC), або f_c = 1/(2πRC), — знаменник дорівнює 1 + j, його модуль √2, і |H| падає до 1/√2 ≈ 0.707. Це і є **зріз −3 дБ**. Вище за цю частоту модуль спадає обернено пропорційно до частоти — нахил −20 дБ на декаду.

## Дві ланки поспіль: чесний розрахунок

Тепер під'єднаємо другу ланку R2C2 **прямо** до виходу першої, без нічого між ними. Спокуса написати H = H1 · H2 виникає тому, що для першої ланки ми вважали, ніби з її виходу струм не тече. Але тепер тече: R2 і далі C2 утворюють шлях струму з вузла A на землю, паралельний до C1.

Розв'яжемо схему чесно. Позначимо вузол A (між ланками) і вихід. Запишемо, що до вузла A приходить струм через R1, а виходить — два струми: у C1 і в R2. Це [закон струмів Кірхгофа](book:electronics/kcl) у вузлі. Замість того щоб тягнути систему рівнянь, скористаймося прийомом **імпеданс навантаженого вузла**: на вузлі A висить паралельне з'єднання C1 та «вхідного імпедансу другої ланки» Z_in2 = R2 + 1/(jωC2). Тоді перша ланка — це дільник, у якого нижнє плече вже не сам C1, а C1 паралельно з Z_in2; а друга ланка ділить уже свою вхідну напругу.

Проведемо це акуратно. Нехай для стислості s = jω (так пишуть завжди — менше символів). Імпеданс конденсатора — 1/(sC).

Крок 1. Вхідний імпеданс другої ланки (вона ж навантаження першої):

```
Z_in2 = R2 + 1/(sC2)
```

Крок 2. Нижнє плече першого дільника — це C1 паралельно з Z_in2. Паралельне з'єднання двох імпедансів — добуток на суму:

```
            (1/(sC1)) · Z_in2
Z_low = ───────────────────────
           1/(sC1) + Z_in2
```

Крок 3. Напруга на вузлі A — дільник із верхнім плечем R1 і нижнім Z_low:

```
 U_A          Z_low
───── = ─────────────────
 U_вх      R1 + Z_low
```

Крок 4. Друга ланка ділить напругу вузла A своїм власним дільником R2 / C2:

```
 U_вих        1/(sC2)            1
─────── = ─────────────── = ───────────
  U_A       R2 + 1/(sC2)      1 + sR2C2
```

Перемноживши крок 3 і крок 4 і розкривши дужки (це механічна алгебра — зводимо все до спільного знаменника), дістанемо повну передавальну функцію двох ланок:

```
                              1
H(s) = ───────────────────────────────────────────────
        1 + s(R1C1 + R2C2 + R1C2) + s²·R1C1R2C2
```

Зупинімося на знаменнику — у ньому вся суть. Якби ланки були незалежні, добуток (1 + sR1C1)(1 + sR2C2) дав би в знаменнику:

```
1 + s(R1C1 + R2C2) + s²·R1C1R2C2
```

Порівняйте два знаменники. Квадратичні члени однакові. Постійний член однаковий. А лінійний — ні: у чесному розрахунку з'явився **зайвий доданок sR1C2**. Це і є математичний слід навантаження: добуток ємності другого конденсатора на опір першого резистора. Він не виникає нізвідки — це той самий струм, що друга ланка тягне з вузла A через свій конденсатор крізь R1.

> 🔧 **Навіщо це.** Лінійний доданок у знаменнику керує тим, **наскільки гострий** перехід (полюси, добротність). Зайвий +sR1C2 робить його більшим — а більший лінійний член «розсуває» полюси, тобто перехід стає **пологішим і ширшим**, ніж задумано, а ефективний зріз — нижчим. Тому некерована пара завжди ріже раніше й м'якше за паспорт двох ланок.

Ту саму «провину» хочеться зібрати в один множник — але тут легко схибити. Спокуслива, та **хибна** форма — записати H(s) як добуток трьох окремих дільників напруги. Так робити не можна: три множники, кожен лінійний по s, дали б у знаменнику **куб** по s (степінь 3), а чесний знаменник — лише **квадрат** (степінь 2), що в нас перед очима. Куб не дорівнює квадрату, тож такого добутку просто не існує. Найшвидша перевірка — постійний струм: справжня H(0) = 1, а будь-яка форма, у якої останній множник має вигляд R2/(R1 + R2 + …), дала б на нулі R2/(R1 + R2) ≠ 1. Отже правильний «навантажувальний множник» — не окремий дільник, а чесне **відношення двох знаменників**.

Позначмо знаменник омріяних незалежних ланок D_ideal = (1 + sR1C1)(1 + sR2C2) і справжній знаменник D = 1 + s(R1C1 + R2C2 + R1C2) + s²R1C1R2C2. Обидва — квадратні по s, і ми їх уже виписали вище. Навантажувальний множник — їхнє відношення:

```
 H(s)          D_ideal
─────── = L = ─────────
 H1·H2            D
```

Ми вже бачили: ці два знаменники різняться рівно на один доданок — зайвий sR1C2 у справжньому D. Тобто D = D_ideal + sR1C2, і

```
         D_ideal                    1
L = ─────────────────── = ─────────────────────
     D_ideal + s·R1C2       1 + s·R1C2/D_ideal
```

Перше, що звідси видно, — значення на постійному струмі. При s = 0 зайвий член зникає, D = D_ideal, і L = 1 **точно**. На нулі частоти навантаження не спотворює нічого: обидва конденсатори розімкнені, друга ланка не тягне ані краплі струму, вихід дорівнює входу за будь-яких опорів. Ніякої «статичної похибки ділення» немає — уся біда навантаження прокидається лише з частотою, разом із множником s у зайвому доданку.

## Звідки береться правило R2 ≥ 10·R1

Уся похибка навантаження сидить в одному доданку знаменника — sR1C2. Щоб її приборкати, треба зробити цей доданок малим проти тих, що стоять у знаменнику законно. Найпрозоріше порівняти його з власною сталою часу другої ланки — коефіцієнтом R2C2, що теж сидить у лінійному члені:

```
 R1·C2       R1
─────── = ──────
 R2·C2       R2
```

Зайвий доданок — це той самий конденсатор другої ланки C2, але побачений крізь **чужий** резистор R1 замість свого R2 (струм у C2 приходить із вузла A саме через R1). Тому його вага відносно законного R2C2 — рівно відношення опорів R1/R2. Якщо R2 = 10·R1, паразитний внесок — 10 %; якщо R2 = 100·R1 — 1 %. Ось звідки емпіричне «у десять разів»: воно тримає зайвий доданок у межах десятка відсотків від того, що й так є в знаменнику. (Коли ланки роблять з однаковою сталою часу, R1C1 = R2C2, те саме відношення читається і як C2/C1 — легша, слабша друга ємність.)

Але не забуваймо про множник s: похибка не однакова на всіх частотах. На постійному струмі її немає зовсім; з частотою вона наростає й найдужче дається взнаки в околі коліна фільтра; а далеко за зрізом знову спадає — там знаменник D_ideal росте як ω² і придушує лінійний зайвий доданок. Тому навіть за R2 = 10·R1 форма саме біля коліна трохи відхиляється: правило `R2 ≥ 10·R1` гарантує добру збіжність **у смузі пропускання**, але не обіцяє ідеалу прямо в точці зрізу. Для точних фільтрів цього мало — там розв'язують ланки буфером.

> 🔧 **Навіщо це.** Звідси випливає типова практика сходу імпедансів: у багатоланковому пасивному ланцюгу кожну наступну ланку роблять «легшою» за попередню — більший R, менший C (щоб зберегти ту саму сталу часу RC). Виходить, що дальші ланки майже не навантажують ближчі. Платять за це зростанням опору: остання ланка має дуже високий вихідний опір і сама вже погано тримає навантаження — тому наприкінці ланцюга все одно зазвичай ставлять повторювач.

## Скільки коштує зсув зрізу: формула для n однакових буферованих ланок

Окремий, чистий випадок — коли ланки **розв'язані буферами** (між кожними двома стоїть повторювач), тож навантаження немає й відгук — справді добуток. Хай усі n ланок однакові, з однаковим зрізом f_c кожна. Питання: де опиниться зріз −3 дБ усього ланцюга?

Модуль однієї ланки на частоті f:

```
|H1| = 1 / √(1 + (f/f_c)²)
```

Для n однакових ланок модулі перемножуються:

```
|H| = 1 / (1 + (f/f_c)²)^(n/2)
```

Зріз усього ланцюга — там, де |H| = 1/√2. Прирівняємо й розв'яжемо відносно f:

```
(1 + (f/f_c)²)^(n/2) = √2 = 2^(1/2)

1 + (f/f_c)²  =  2^(1/n)

(f/f_c)²  =  2^(1/n) − 1

f_−3дБ  =  f_c · √( 2^(1/n) − 1 )
```

Підставмо числа. Для однієї ланки (n = 1): √(2 − 1) = 1 — зріз там, де й мав бути, перевірка зійшлася. Для двох (n = 2):

```
f_−3дБ = f_c · √(2^0.5 − 1) = f_c · √0.4142 ≈ f_c · 0.644
```

Дві однакові ланки, навіть ідеально розв'язані буферами, дають сумарний зріз на рівні **0.64 від зрізу однієї**. Логіка прозора: на частоті f_c кожна ланка вже забрала свої −3 дБ, удвох — −6 дБ, а це нижче за поріг −3 дБ; щоб сумарне падіння було лише −3 дБ, доводиться відступити на нижчу частоту, де кожна ланка ще майже не ріже. Для трьох ланок коефіцієнт падає до ≈ 0.51, для чотирьох — ≈ 0.43.

> 🔧 **Навіщо це.** Якщо ви ставите три однакові ланки заради крутого схилу −60 дБ/декаду, пам'ятайте: смуга пропускання при цьому стиснеться вдвічі (0.51) проти однієї ланки. Тож зріз кожної ланки треба закладати **вище** від бажаного сумарного — поділити на цей коефіцієнт. Інакше готовий фільтр почне різати корисний сигнал раніше, ніж ви розраховували.

Це й пояснює, чому однакові RC-ланки — простий, але «тупий» спосіб дістати крутий схил: за гострий спад платять і зсувом смуги, і пологим, розмазаним коліном (кожен полюс на тій самій частоті дає не різке, а м'яко закруглене коліно). Коли коліно має бути гострим і точним, обирають інше розташування полюсів — і тут на сцену виходять [іменні апроксимації фільтрів](guide:embedded/filter-families), які навмисно розставляють полюси по-різному заради потрібної форми.
