# 🧮 Чому усереднення працює: σ ∕ √N

Шукаючи джерело завади, ви рано чи пізно вмикаєте на осцилографі режим **усереднення** (*Average*) — і слабкий сигнал, що тонув у «траві», раптом проступає чистою лінією. Це не магія дисплея: за нею стоїть одна з найкорисніших формул усієї електроніки вимірювань — **σ ∕ √N**. Вона каже, наскільки тихішим стає шум, коли ми складаємо багато вимірювань, і чому за певною межею усереднювати далі майже марно.

### Означення: усереднення як спосіб приборкати випадковість

За своєю природою **[шум — це випадкова величина](guide:embedded/noise-interference)**. Кожне окреме вимірювання напруги дає число, що складається з двох частин: справжнього сигналу μ (який ми хочемо) і випадкового відхилення (яке заважає). Ширину цього відхилення міряє **стандартне відхилення** (*standard deviation*, σ) — те саме σ гаусового дзвону, яким описують розкид випадкової напруги.

Ключове припущення: справжній сигнал **щоразу той самий**, а шум **щоразу новий і незалежний** від попереднього. Тоді, якщо взяти N таких вимірювань і обчислити їхнє **середнє арифметичне** (*sample mean*), справжня частина залишиться на місці (вона ж не змінювалася), а випадкові кидки частково **погасять одне одного** — додатні й від'ємні відхилення в сумі тягнуть у різні боки.

### Інтуїція: чому випадкове частково самознищується

Щоб відчути це взаємне гасіння наочно, замінімо вимірювання простішим образом. Уявіть N людей, що незалежно кидають камінь у ту саму мішень. Кожен трохи промахується — хто ліворуч, хто праворуч. Якщо взяти **центр ваги** всіх влучань, він ляже куди ближче до мішені, ніж типовий окремий кидок: промахи в різні боки взаємно скорочуються.

Але — і це найважливіше — вони скорочуються **не повністю**. Якби шум зникав пропорційно N, досить було б усього кількох вимірювань. Натомість він спадає повільніше — як **корінь** із N. Причина в тому, що випадкові відхилення додаються не як звичайні числа, а як **незалежні** величини: їхні розмахи складаються «по теоремі Піфагора», через суму **квадратів**, а не напряму. Тому щоб зменшити шум удвічі, мало взяти вдвічі більше вимірювань — їх треба **вчетверо** більше.

![Режим Average: що більше усереднених проходів, то чистіший слід](/guide/embedded/proshyvka/noise-hunting/img/avg-traces-vs-N.svg)
*Один і той самий слабкий імпульс під однаковим шумом, усереднений по N = 1, 4, 16, 64 розгортках. Справжній сигнал (фіолетовий пік) стоїть на місці, а «трава» навколо нього стискається: при N = 64 шум увосьмеро вужчий, ніж при N = 1, і форма імпульсу нарешті читається.*

### Апарат: звідки береться √N

Запишемо це строго. Маємо N незалежних вимірювань x₁, x₂, …, x_N; кожне має те саме середнє μ і те саме стандартне відхилення σ. Їхнє вибіркове середнє:

```
x̄ = (x₁ + x₂ + … + x_N) / N
```

Для **незалежних** величин дисперсії (квадрати σ) при додаванні **складаються**:

```
Var(x₁ + … + x_N) = σ² + σ² + … + σ² = N·σ²
```

Ділення суми на N зменшує дисперсію в N² разів (стала виноситься з-під дисперсії у квадраті):

```
Var(x̄) = N·σ² / N² = σ² / N
```

А стандартне відхилення — це корінь із дисперсії. Отже шум середнього:

```
σ_x̄ = √(σ² / N) = σ / √N
```

Це і є шукана формула. Її варто читати разом із поняттям **відношення сигнал/шум** (*signal-to-noise ratio*, SNR): сигнал μ не змінився, а шум упав у √N разів, тож SNR **зростає теж як √N**.

![Крива σ∕√N: закон спадних віддач усереднення](/guide/embedded/proshyvka/noise-hunting/img/avg-sqrt-n-curve.svg)
*Шум середнього як функція N. Перші вимірювання дають найбільший виграш; далі крива стрімко вирівнюється. Перехід від N = 1 до N = 4 ділить шум навпіл, від 4 до 16 — ще навпіл, але кожен наступний крок коштує дедалі більше проходів за дедалі менший зиск.*

Кілька орієнтирів, корисних просто запам'ятати:

```
N = 4    →  шум ÷2     (−6 дБ)
N = 16   →  шум ÷4     (−12 дБ)
N = 100  →  шум ÷10    (−20 дБ)
N = 1000 →  шум ÷31.6  (−30 дБ)
```

**Приклад (усереднення на осцилографі).** Сигнал має розмах шуму ≈ 30 мВ peak-to-peak (для гаусового шуму [розмах ≈ 6σ](guide:embedded/noise-interference), тобто σ ≈ 5 мВ). Корисний сигнал — слабкий імпульс ~10 мВ, який «на око» не видно. Скільки розгорток усереднити, щоб шум упав до 1 мВ?

```
треба:  σ / √N = 1 мВ,  при σ = 5 мВ
√N = σ / 1 мВ = 5
N  = 25 розгорток
```

Двадцять п'яти проходів досить, щоб шум став уп'ятеро тихішим і імпульс упевнено проступив. Хотіти ще вдесятеро тихіше (0.1 мВ)? Тоді N = 2500 — і тут уже впирається в час: осцилограф мусить зловити дві з половиною тисячі однакових розгорток.

### Межі застосовності

Формула σ ∕ √N — фундамент усіх «тихих» вимірювань. Режим *Average* осцилографа усереднює саме незалежні розгортки. Та сама ідея стоїть за тим, чому **повільне** вимірювання точніше за швидке: даючи приладу більше часу на пробу, ми по суті усереднюємо більше відліків. Важлива й межа застосовності: √N працює **лише** для незалежного, нескорельованого шуму ([теплового](book:physics/thermal-noise), [дробового](book:physics/shot-flicker-noise)). **Періодичну** заваду — [гул 50 Гц](book:physics/capacitive-coupling) — звичайне усереднення прибере погано, бо вона не випадкова: вона повторюється від розгортки до розгортки й не гасить сама себе. Саме тому, полюючи на заваду, спершу з'ясовують її **природу**: випадкову «траву» втихомирює √N, а регулярний гул доводиться ловити інакше — синхронізацією, екрануванням чи фільтром.
