# 🧮 Обернена задача: з (X, Y, Z) дістати (φ, λ, h)

Дорога від геодезичних координат до земних декартових — три рядки формул без жодного наближення. Дорога назад влаштована принципово інакше: одну координату вона віддає задарма, а дві решти тримає в зчепленні, з якого елементарного виходу немає взагалі. Нижче — звідки береться це зчеплення, чому воно зводиться до рівняння четвертого степеня, і три способи його розв'язати: з виведеннями, числами й чесними межами кожного.

## Довгота відокремлюється, широта — ні

Прямий перехід записується так:

```text
X = (N + h)·cos φ·cos λ
Y = (N + h)·cos φ·sin λ
Z = (N·(1 − e²) + h)·sin φ

N(φ) = a / √(1 − e²·sin²φ)
```

Погляньмо, у якому вигляді сюди входить довгота. Вона з'являється рівно двічі — множниками cos λ і sin λ при одній і тій самій величині (N + h)·cos φ. Позначимо цю величину p; вона невід'ємна, бо це відстань точки до осі обертання. Тоді перші два рядки — це просто пара (p·cos λ, p·sin λ), і обидві невідомі дістаються негайно:

```text
p = √(X² + Y²) = (N + h)·cos φ  ≥ 0
λ = atan2(Y, X)
```

Довгота вийшла, не питаючи ні φ, ні h. Причина не в щасливому збігу: λ — це кут повороту навколо осі Z, а p до цього повороту байдужа. Тому обертання «відкручується» окремо від усього іншого. Двоаргументний [atan2](book:math/atan2) тут обов'язковий: звичайний арктангенс від Y/X втратив би чверть і поставив би точку в Тихому океані замість Азії.

Далі задача стає плоскою. Лишилися дві невідомі, φ і h, і дві величини, у яких вони заховані: p та z ≡ Z. Уся дія відбувається в площині меридіана.

## Рівняння, у якому широта сидить під коренем

Візьмімо два рівняння, що лишилися:

```text
p = (N + h)·cos φ
z = (N·(1 − e²) + h)·sin φ
```

Висота входить в обидва однаково — доданком, бо вона відкладена вздовж нормалі, а нормаль має складові (cos φ, sin φ). Отже, h легко вилучити. З першого рівняння h = p/cos φ − N; підставимо в друге:

```text
z = (N·(1 − e²) + p/cos φ − N)·sin φ = (p/cos φ − e²·N)·sin φ
```

тобто

```text
z = p·tan φ − e²·N(φ)·sin φ          ⟹          tan φ = (z + e²·N(φ)·sin φ) / p
```

Ось воно, зчеплення в чистому вигляді: φ стоїть ліворуч і водночас праворуч, до того ж під коренем усередині N. Формули «φ = щось від p і z» не існує.

Варто побачити, звідки саме взялася ця біда. Якби Земля була кулею, e² дорівнювало б нулю, доданок e²·N·sin φ зник би, і лишилося б просто tan φ = z/p — явна відповідь одним арктангенсом. Отже, усю складність оберненої задачі створює сама сплюснутість, і нічого більше.

Заразом видно, що доданок цей аж ніяк не малий. У точці над Києвом (φ = 50.4501°, h = 180 м) він дорівнює

```text
e²·N·sin φ = 0.00669438 · 6 390 868 · 0.7710703 = 32 989 м
```

майже тридцять три кілометри. Викинути його — це сплутати геодезичну широту з геоцентричною: 50.4501° проти 50.2610°, різниця 11.34 кутової хвилини, тобто 21 кілометр уздовж поверхні.

## Чому це рівняння четвертого степеня

Твердження «елементарної формули немає» вартує доведення — а доводити його найкраще конструктивно, показавши, до чого задача таки зводиться. Зручно ввести одну безрозмірну невідому замість двох розмірних. Візьмімо

```text
κ = p·tan φ / z
```

і подивімось, чим вона є насправді. Підставивши p і z через φ та h, дістанемо

```text
κ = [(N + h)·cos φ · tan φ] / [(N·(1 − e²) + h)·sin φ] = (N + h) / (N·(1 − e²) + h)
```

Отже, κ — це відношення двох «радіусів», що стоять у знаменниках p і z; воно трохи більше за одиницю й на реальній Землі лежить між 1 і 1/(1 − e²) = 1.006739.

Тепер уся геометрія виражається через κ. З означення p і z маємо

```text
cos φ = p / (N + h)          sin φ = κ·z / (N + h)
```

(друга рівність — бо z·κ = p·tan φ = (N + h)·sin φ). Сума квадратів дає одразу перший корисний вираз:

```text
(N + h)² = p² + κ²·z²
```

Другий вираз дістанемо з того самого, домноживши на W² = 1 − e²·sin²φ:

```text
W²·(N + h)² = (N + h)² − e²·[(N + h)·sin φ]² = p² + κ²z² − e²·κ²z² = p² + (1 − e²)·κ²·z²
```

Обидва вирази — уже без φ і h, лише через дані p, z та невідому κ. Лишилося зв'язати κ саму з собою. Рівняння попереднього розділу в записі p·tan φ = z + e²·N·sin φ має ліворуч рівно κ·z, тож

```text
κ = 1 + e²·N·sin φ / z
```

Тепер обидва множники в цьому доданку виражаються через κ: N = a/W, а sin φ = κ·z/(N + h). Разом вони дають e²·N·sin φ/z = e²·a·κ/(W·(N + h)), і знаменник W·(N + h) — це якраз другий здобутий корінь:

```text
κ = 1 + e²·a·κ / √(p² + (1 − e²)·κ²·z²)
```

Та сама неявність, але вже в одній невідомій і без жодної тригонометрії. Тепер її можна розв'язати від кореня: перенесімо одиницю ліворуч і піднесімо до квадрата.

```text
(κ − 1)²·[p² + (1 − e²)·κ²·z²] = e⁴·a²·κ²
```

Розкривши, дістанемо многочлен четвертого степеня:

```text
(1−e²)z²·κ⁴ − 2(1−e²)z²·κ³ + [(1−e²)z² + p² − e⁴a²]·κ² − 2p²·κ + p² = 0
```

**Чотири корені для точки над Києвом.** Дано p = 4 069 499.796 м, z = 4 894 958.756 м.

```text
коефіцієнти:  2.380022·10¹³  −4.760044·10¹³  4.035923·10¹³  −3.312166·10¹³  1.656083·10¹³

корені:  κ₁ = 1.00673931          (справжній)
         κ₂ = 0.99329776          (фантом)
         κ₃,₄ = −1.85·10⁻⁵ ± 0.834i

перевірка κ₁:  (κ−1)·√(p² + (1−e²)κ²z²) = +42 985.43     e²·a·κ = +42 985.43   ✔
перевірка κ₂:  (κ−1)·√(p² + (1−e²)κ²z²) = −42 411.50     e²·a·κ = +42 411.50   ✘
```

Другий дійсний корінь задовольняє піднесене до квадрата рівняння, але не вихідне: знаки різні. Це звичайний паразитний корінь, народжений самим піднесенням до квадрата, — і водночас перше попередження всім, хто збирається розв'язувати цю четвірку в лоб: правильний корінь треба вміти вибрати.

Загальний розв'язок рівняння четвертого степеня існує в радикалах — його знайшов Лодовіко Феррарі (1522–1565) року 1540, а надрукував його вчитель Джероламо Кардано в «Ars Magna» (1545); публікацію довелося відкласти саме тому, що будь-який алгебричний розв'язок четвертого степеня спирається на розв'язок кубічного. Про сам метод — у [рівнянні четвертого степеня](book:math/quartic-equation); тут важливо лише те, що замкнена формула є, вона громіздка й містить кубічний корінь із проміжної кубічної резольвенти.

## Спосіб перший: проста ітерація

Найпряміший підхід — узяти рівняння як є й підставляти в нього самого себе:

```text
φ₀ = atan2( z,  p·(1 − e²) )                     — початкове наближення, h = 0
φₖ₊₁ = atan2( z + e²·N(φₖ)·sin φₖ,  p )
h = p/cos φ − N(φ)                               — наприкінці, один раз
```

Початкове наближення взяте не з повітря. Якщо покласти h = 0, то p = N·cos φ і z = N(1 − e²)·sin φ, а їхнє відношення дає рівно tan φ = z/(p(1 − e²)) — точну відповідь для точки на самому еліпсоїді. Наземна точка від еліпсоїда далеко не відходить, тож старт уже майже влучний.

Тепер головне питання: як швидко воно збігається. Метод — це [ітерація нерухомої точки](book:math/fixed-point-iteration) для відображення F(φ) = atan((z + e²N(φ)sin φ)/p), тож швидкість визначає |F′| у нерухомій точці. Продиференціюймо. Похідна арктангенса дає множник cos²φ, а всередині треба взяти похідну добутку N·sin φ:

```text
dN/dφ = N · e²·sin φ·cos φ / (1 − e²·sin²φ)

d(N·sin φ)/dφ = N·cos φ · [1 + e²·sin²φ/(1 − e²·sin²φ)] = N·cos φ / (1 − e²·sin²φ)
```

Отже

```text
F′(φ) = cos²φ · (e²/p) · N·cos φ / (1 − e²·sin²φ) = e²·N·cos³φ / (p·(1 − e²·sin²φ))
```

і, підставивши p = (N + h)·cos φ,

```text
F′ = e²·N·cos²φ / ((N + h)·(1 − e²·sin²φ))
```

Цей вираз варто прочитати уважно, бо він відповідає на всі питання про метод одразу. По-перше, при h ≥ 0 множник N/(N + h) не перевищує одиниці, а дріб cos²φ/(1 − e²sin²φ) не перевищує одиниці й досягає її на екваторі. Отже **|F′| ≤ e² = 0.0067 усюди на еліпсоїді й над ним** — стиск гарантований, збіжність теж, без жодних припущень про висоту чи широту. По-друге, кожен крок додає щонайменше log₁₀(1/e²) = 2.17 правильної десяткової цифри. По-третє, чим вища точка, тим сильніший стиск: на висоті навігаційного супутника множник N/(N + h) — це вже приблизно чверть.

**Числа над Києвом** (φ = 50.4501°, h = 180 м). Теоретичний множник:

```text
F′ = 0.00669438 · 6 390 868 · 0.6367500² / (6 391 048 · 0.99601986) = 0.0027250
```

а спостережений хід похибки широти (у метрах уздовж поверхні):

```text
старт   0.594   м
крок 1  1.618   мм      ×0.00273
крок 2  4.409   мкм     ×0.00273
крок 3  0.0120  мкм     ×0.00273
крок 4  0                — уперлися в подвійну точність
```

Множник збігається з теоретичним до третьої цифри, і це найкраща перевірка виведення. Практичний висновок теж очевидний: три кроки — і похибка вже нижча за все, що взагалі можна виміряти; чотири — і вона нижча за роздільність самих чисел.

![Похибка широти в логарифмічному масштабі: проста ітерація дає пряму зі спадом ×0.0027 за крок, один крок Боуринга одразу лягає на підлогу подвійної точності](/book/math/geometry/ecef-ned-enu/img/inverse-convergence.svg)
*Пряма лінія в логарифмічному масштабі — підпис геометричної збіжності: кожен крок множить похибку на ту саму сталу 0.0027, тобто додає 2.6 правильної десяткової цифри. Горизонтальна межа знизу — не властивість методу, а межа арифметики: один ulp у числі порядку 6.4·10⁶ метрів становить близько 0.9 нанометра, і нижче не опуститься жоден алгоритм у подвійній точності.*

Ціна кроку — один корінь, один atan2 і пара sin/cos. Вада — цикл: у коді з передбачуваним часом виконання змінна кількість ітерацій незручна. Її, щоправда, можна прибити цвяхом: оцінка |F′| ≤ e² разом із найгіршим можливим стартом дає фіксовані п'ять кроків із запасом на будь-яку висоту від дна океану до орбіти навігаційного супутника.

Те саме рівняння піддається й [методу Ньютона](book:math/newton-raphson), який квадратує похибку за крок замість множити її на сталу. Виграш невеликий: при множнику 0.0027 проста ітерація й так з'їдає задачу за три кроки, а Ньютон вимагає похідної та ділення на неї.

## Спосіб другий: підстановка Боуринга

1976 року Б. Р. Боуринг показав, що правильно вибрана заміна змінної майже прибирає з цієї задачі ітерації взагалі (*Survey Review*, 23(181), 323–327). Заміна — зведена, або параметрична, широта β.

Означення геометричне: точку еліпса проєктують паралельно осі обертання на коло радіуса a, і β — кут цієї проєкції. Алгебрично це просто параметризація меридіанного еліпса:

```text
p = a·cos β        z = b·sin β        (точка НА еліпсоїді, b = a√(1 − e²))
```

Зв'язок із геодезичною широтою виходить із того, що обидва набори описують одну точку:

```text
tan β = (b/a)·tan φ = √(1 − e²)·tan φ

cos β = cos φ / W        sin β = √(1 − e²)·sin φ / W        W = √(1 − e²·sin²φ)
```

Перевірка миттєва: cos²β + sin²β = (cos²φ + (1 − e²)sin²φ)/W² = 1.

Одразу видно й користь. Оскільки N·cos φ = a·cos φ/W = a·cos β, а N(1 − e²)·sin φ = a√(1 − e²)·sin β = b·sin β, точка на висоті h розкладається геть прозоро:

```text
p = a·cos β + h·cos φ
z = b·sin β + h·sin φ
```

тобто «основа нормалі на еліпсоїді в параметричному вигляді плюс h уздовж нормалі».

### Точна тотожність

А тепер — головне. Погляньмо на розклад p = a·cos β + h·cos φ, z = b·sin β + h·sin φ і спитаймо: чого бракує, щоб відношення z до p відразу дало tan φ? Другий доданок у кожному рядку вже пропорційний до (cos φ, sin φ) зі спільним множником h — ділення його не зіпсувало б. Заважає лише перший, «еліпсоїдний»: пара (a·cos β, b·sin β) дивиться не вздовж нормалі. Отже, треба знайти поправку, яка розверне саме цю пару на нормаль, — і виявляється, що досить відняти від p та додати до z по одному кубічному доданку.

Порахуймо їх. Другий ексцентриситет визначають як e′² = (a² − b²)/b² = e²/(1 − e²).

```text
z + e′²·b·sin³β = h·sin φ + b·sin β·(1 + e′²·sin²β)
```

Дужка згортається до однієї дробини:

```text
e′²·sin²β = [e²/(1 − e²)] · (1 − e²)sin²φ/W² = e²·sin²φ/W²
1 + e′²·sin²β = (W² + e²sin²φ)/W² = 1/W²
```

а b·sin β = N(1 − e²)·sin φ = a(1 − e²)·sin φ/W. Разом:

```text
z + e′²·b·sin³β = h·sin φ + a(1 − e²)·sin φ/W³ = sin φ · [ h + a(1 − e²)/W³ ]
```

Те саме зробімо з другим виразом:

```text
1 − e²·cos²β = (W² − e²cos²φ)/W² = (1 − e²)/W²

p − e²·a·cos³β = h·cos φ + a·cos β·(1 − e²·cos²β) = cos φ · [ h + a(1 − e²)/W³ ]
```

Квадратні дужки в обох рядках **однакові**, і це не збіг: величина a(1 − e²)/W³ — меридіанний радіус кривини M. Поділивши одне на одне, дужки скорочуємо:

```text
tan φ = (z + e′²·b·sin³β) / (p − e²·a·cos³β)
```

Це рівність, а не наближення. Числа над Києвом підтверджують її до останньої цифри:

```text
z + e′²·b·sin³β = 4 914 518.675 = (M + h)·sin φ
p − e²·a·cos³β = 4 058 410.370 = (M + h)·cos φ
M + h = 6 373 632.287       відношення = 1.2109467074 = tan(50.4501°)
```

### Чому один крок влучає

Тотожність точна — але β невідома так само, як φ. Боуринг бере для неї найдешевше можливе наближення: те, що було б точним при h = 0. З параметризації p = a cos β, z = b sin β одразу випливає

```text
tan β₀ = a·z / (b·p)
```

Похибка цієї підстановки рахується просто. Підставивши p = a cos β + h cos φ і z = b sin β + h sin φ у праву частину й порівнявши з tan β, дістанемо

```text
δβ = h·a·e²·sin φ·cos φ / (W²·b·(N + h))
```

Над Києвом це 9.33·10⁻⁸ радіана — близько 59 сантиметрів уздовж поверхні. Здавалося б, звідси й має вийти похибка широти того самого порядку. А виходить майже в мільярд разів менша, і причина — головна властивість цієї формули.

Позначмо Φ(β) праву частину тотожності (як функцію β при фіксованих даних p, z) і продиференціюймо в справжній точці. Чисельник U = z + e′²b sin³β, знаменник V = p − e²a cos³β, тож

```text
Φ′ = (U′V − UV′)/(U² + V²)

U′ = 3e′²b·sin²β·cos β        V′ = 3e²a·cos²β·sin β
U = (M + h)·sin φ             V = (M + h)·cos φ

Φ′ = 3·[ e′²b·sin²β·cos β·cos φ − e²a·cos²β·sin β·sin φ ] / (M + h)
```

Порахуймо обидва доданки в дужці через φ. Пам'ятаючи, що e′²b = e²a/√(1 − e²), sin β = √(1−e²)sin φ/W і cos β = cos φ/W:

```text
e′²b·sin²β·cos β·cos φ = e²a·√(1 − e²)·sin²φ·cos²φ / W³
e²a·cos²β·sin β·sin φ  = e²a·√(1 − e²)·sin²φ·cos²φ / W³
```

Вони тотожно рівні. Отже **Φ′(β) = 0** у справжній точці: перша похідна відповіді за параметром дорівнює нулю. Похибка в β коштує не першого порядку, а другого.

Друга похідна рахується тим самим прийомом і виходить напрочуд компактною:

```text
Φ″ = 3·e²·a·sin φ·cos φ / (W·(M + h)) = 0.009887 рад⁻¹
```

а з нею — і вся похибка одного кроку:

```text
δφ ≈ ½·Φ″·δβ² = ½ · 0.009887 · (9.33·10⁻⁸)² = 4.3·10⁻¹⁷ рад ≈ 0.3 нм
```

Виміряна похибка одного кроку — 1.11·10⁻¹⁶ радіана. Це рівно один ulp числа 0.8805 радіана, тобто вже не властивість методу, а округлення останнього біта. Математична похибка Боуринга над наземною точкою тоне під підлогою [подвійної точності](book:math/floating-point).

### Що це означає геометрично

Нуль першої похідної — не алгебричний фокус, і побачити його можна без жодних викладок. Придивімось, чим є чисельник і знаменник тотожності. Обидва — це різниці координат заданої точки й ось цієї:

```text
C = ( e²·a·cos³β,  −e′²·b·sin³β )

бо  p − e²·a·cos³β = p − p_C     і     z + e′²·b·sin³β = z − z_C
```

Це параметризація **еволюти** меридіанного еліпса — кривої, складеної з центрів кривини. Точка C — центр кола, що найкраще прилягає до еліпса в основі нормалі; лежить вона на самій нормалі, на відстані M від поверхні. Тому тотожність Боуринга читається одним реченням: **тангенс кута, під яким видно задану точку з центра кривини, і є тангенс геодезичної широти** — бо центр кривини стоїть на тій самій нормалі, що й точка.

Звідси й стаціонарність. Головна властивість [еволюти](book:math/evolute) в тому, що її дотична в кожній точці — це нормаль вихідної кривої. Зсунувши β, ми совгаємо C **уздовж тієї самої прямої**, напрям якої й міряємо. Точка P не рухається, C ковзає по прямій, що проходить через P, — а отже напрям P − C у першому порядку не змінюється. Уся точність Боуринга виросла саме з цього: сорок два кілометри зсуву обертаються на нуль першого порядку.

![Меридіанний еліпс, його еволюта біля центра, нормаль у точці поверхні й центр кривини C на ній; вектор від C до заданої точки P розкладений на складові p − e²a·cos³β та z + e′²b·sin³β](/book/math/geometry/ecef-ned-enu/img/inverse-bowring-geometry.svg)
*Уся точність Боуринга — в одному факті: центр кривини C лежить на нормалі, тому кут вектора CP і є геодезична широта, точно. Складові цього вектора — саме чисельник і знаменник формули. Коли β береться наближено, C зсувається вздовж еволюти, а дотична до еволюти — це та сама нормаль; C ковзає по прямій, на якій уже стоїть P, і напрям CP лишається тим самим із точністю до другого порядку. Сплюснутість на рисунку перебільшена в півсотні разів — інакше еволюту (у справжніх числах вона вміщається в 43 км навколо центра) не було б видно.*

### Ціна й межі

Ціна одного кроку — два atan2, один корінь і кілька множень, без циклу й без розгалужень. Точність із висотою падає, бо δβ росте разом із h, а похибка — як квадрат δβ:

```text
h = 0          похибка широти  0            (β₀ точна)
h = 180 м                      0.7 нм       (= 1 ulp, тобто нуль)
h = 10 км                      0.8 мкм
h = 400 км                     1.1 мм
h = 20 200 км                  4.7 см       і 0.24 м по висоті
```

Для всього, що стоїть чи літає над Землею, одного кроку більш ніж досить. Для орбіти навігаційного супутника варто зробити другий: він переносить похибку в ту саму підлогу подвійної точності, і на цьому все закінчується назавжди.

## Спосіб третій: замкнена формула Феррарі

Рівняння четвертого степеня розв'язується в радикалах — отже, від ітерацій можна відмовитися зовсім. Найзручніше впорядкування ланцюжка дали М. Гейккінен (*Zeitschrift für Vermessungswesen*, 107, 207–211, 1982) і Г. Вермей (*Journal of Geodesy*, 76(8), 451–454, 2002); кубічний корінь у ньому — це якраз розв'язок кубічної резольвенти за Кардано:

```text
ζ = (1 − e²)·z² / a²
ρ = (p²/a² + ζ − e⁴) / 6
s = e⁴·ζ·p² / (4·ρ³·a²)
t = ∛(1 + s + √(s·(s + 2)))
u = ρ·(t + 1 + 1/t)
v = √(u² + e⁴·ζ)
w = e²·(u + v − ζ) / (2·v)
κ = 1 + e²·(√(u + v + w²) + w) / (u + v)
```

а далі — уже здобутими виразами, без жодної тригонометрії, крім одного atan2:

```text
R = √(p² + κ²·z²)                      — це і є N + h
W = √(p² + (1 − e²)·κ²·z²) / R
N = a / W
h = R − N
φ = atan2(κ·z, p)
```

Формула точна — і це не декларація: для точки над Києвом вона видає κ = 1.0067393056492135, що збігається з еталоном, порахованим у п'ятдесяти значущих цифрах, у всіх сімнадцяти доступних розрядах. Проте «точна формула» й «надійна формула» — різні речі, і всі три вразливі місця цього ланцюжка варто назвати поіменно.

**Вибір кореня захований у самій конструкції.** Паразитний корінь κ₂ = 0.9933 нікуди не подівся — просто ланцюжок побудований так, що виводить саме на κ₁. Хто розв'язує ту четвірку власним універсальним розв'язувачем, мусить сам перевірити знак у вихідному, не піднесеному до квадрата рівнянні. Інакше відповідь буде цілком осмислена на вигляд і хибна на кілометри.

**Величина ρ змінює знак.** Умова ρ ≥ 0 розписується так:

```text
p²/a² + (1 − e²)z²/a² ≥ e⁴      ⟺      p² + (1 − e²)·z² ≥ (e²·a)²
```

Це еліпс із півосями e²·a = 42 698 м уздовж p та e²a/√(1 − e²) = e′²·b = 42 841 м уздовж z. Усередині нього ρ < 0, тоді s < 0, вираз s(s + 2) від'ємний, і корінь із нього — помилка області визначення; а ρ³ стоїть у знаменнику. Ланцюжок не «втрачає точність», він просто падає. Перевірено на точці (p, z) = (10 км, 10 км): помилка області визначення.

**Висота дістається відніманням майже рівних чисел.** У наземній точці N + h = 6 391 047.954, N = 6 390 867.954, а відповідь — 180. Шукана величина становить 2.8·10⁻⁵ від зменшуваного, тобто в різниці гине близько чотирьох з половиною десяткових цифр — класичне [взаємознищення значущих розрядів](book:math/numeric-stability). У подвійній точності це не страшно: лишається ще одинадцять цифр, і похибка висоти — близько нанометра. В одинарній точності це смертельно: крок представних чисел біля 6.4·10⁶ становить 0.5 метра, тож висота перетворилася б на чистий шум. Те саме, до речі, стосується й h = p/cos φ − N у двох попередніх способах — це спільна властивість задачі, а не конкретного методу.

Виправдання замкненої формули — сталий, наперед відомий час без циклів і без залежності від даних: у векторизованому коді, у конвеєрі приймача чи в апаратурі це важить більше, ніж кілька зайвих множень.

## Де все ламається

Три вироджені випадки варто розібрати не тому, що вони трапляються, а тому, що вони показують, де саме проходить межа самої постановки задачі.

**Точка на осі обертання.** Полюс: p = 0. Тут довготи **не існує** — не «важко порахувати», а немає: площини меридіана через вісь проходить нескінченно багато. Реалізації віддають atan2(0, 0) = 0, і це домовленість, а не відповідь. Широта ж рахується без проблем: формула Боуринга дає atan2(a·z, 0) → β = ±90°, далі atan2(z + e′²b, 0) → φ = ±90°.

А от висота ламається — і саме там, де цього не чекають. Вираз h = p/cos φ − N при φ = 90° має вигляд 0/0; у подвійній точності cos(π/2) виходить не нулем, а 6.1·10⁻¹⁷, тож ділення дає нуль, і відповідь h = −N = −6 399 594 метри. Помилка завбільшки з Землю з абсолютно правильної широти. Лікується перемиканням на другу форму, яка виводиться з z = (N(1 − e²) + h)·sin φ так само тривіально:

```text
|cos φ| > 0.5:   h = p/cos φ − N
інакше:          h = z/sin φ − N·(1 − e²)
```

Поріг 0.5 (тобто 60° широти) взято із запасом: обидві форми дають однакову відповідь усюди в широкому перекритті. Перевірено на φ = 89.99°, h = 1000 м — обидві повертають 1000.000000000.

**Точка поблизу центра Землі.** Тут ламається не арифметика, а сама постановка. Відображення (φ, h) → (p, z) взаємно однозначне лише доти, доки з точки виходить одна нормаль до еліпсоїда. Межа — та сама еволюта: усередині неї з точки виходять **чотири** нормалі, тобто чотири різні пари (φ, h) дають одну й ту саму точку. Задача просто не має єдиного розв'язку, і жоден метод не зобов'язаний угадати, яку гілку ви мали на увазі.

Числа заспокоюють: еволюта вміщається в 42.7 км по горизонталі та 42.8 км по вертикалі від центра Землі — це висоти від −6 335 до −6 400 кілометрів, залежно від того, з якого боку підходити. Практична перевірка коштує двох множень — тієї самої умови ρ ≥ 0:

```text
відкидати, якщо   p² + (1 − e²)·z² < (e²·a)²
```

Умова трохи сувора — еліпс описаний навколо еволюти й дотикається її лише у вістрях, тож між двома кривими лишається тонкий шар, де розв'язок іще єдиний, а перевірка вже відкидає. На глибині шести тисяч кілометрів ця різниця нікого не турбує.

![Меридіанний еліпс із еволютою й описаним навколо неї еліпсом ρ = 0; із точки всередині еволюти виходять чотири різні нормалі до поверхні](/book/math/geometry/ecef-ned-enu/img/inverse-caustic.svg)
*Усередині еволюти обернена задача не має єдиної відповіді: з точки Q проведено чотири нормалі до еліпса, і кожна дає свою «широту» та свою висоту. Сірий пунктир — еліпс p² + (1 − e²)z² = (e²a)², на якому обертається в нуль величина ρ замкненої формули; він описаний навколо еволюти й дотикається її вістер. У справжніх пропорціях Землі вся ця область умістилася б у коло радіусом 43 км навколо центра планети — на рисунку сплюснутість перебільшена в півсотні разів.*

**Великі від'ємні висоти.** Доки точка не дійшла до еволюти, тобто доки h > −M, розв'язок єдиний, і всі три способи чесно його знаходять. Псується лише **швидкість** Боуринга, бо δβ росте разом із |h| — та ще й швидше, ніж лінійно, бо (N + h) стоїть у знаменнику:

```text
h = −1 000 км:   один крок дає похибку 1.4 см,   другий — нуль
h = −6 000 км:   один крок дає похибку 1.6 км,   другий — нуль
```

Простій ітерації від'ємна висота теж не подобається, і з тієї самої причини: у множнику стиску стоїть N/(N + h), а при від'ємних h цей дріб більший за одиницю. На глибині шести тисяч кілометрів множник виростає з 0.0027 до 0.0446 — це все ще стиск, просто замість двох з половиною цифр за крок він додає одну з третиною. За межею h = −M питання «яка тут широта» втрачає сенс разом із єдиністю нормалі; сама ж M пробігає від 6 335 до 6 400 кілометрів залежно від широти.

## Туди й назад на одних числах

Візьмімо ті самі координати, що виходять із прямого переходу для точки над Києвом, і повернімося.

```text
дано:  X = 3 505 555.9    Y = 2 066 859.1    Z = 4 894 958.8   (м)

p = √(X² + Y²) = 4 069 499.810
λ = atan2(Y, X) = 30.5233994°

проста ітерація:   φ = 50.4501001533°   h = 180.043560 м   (4 кроки)
Боуринг:           φ = 50.4501001533°   h = 180.043560 м   (1 крок)
Феррарі:           φ = 50.4501001533°   h = 180.043560 м   (без ітерацій)
```

Три різні за природою методи зійшлися до останнього виведеного розряду. Але порівняння з вхідними даними прямого переходу (φ = 50.4501°, λ = 30.5234°, h = 180 м) дає розбіжності:

```text
Δφ = 1.53·10⁻⁷ °  →  0.017 м уздовж меридіана
Δλ = −6.0·10⁻⁷ °  →  0.043 м уздовж паралелі
Δh =                  0.044 м
```

Спокуса списати це на методи хибна — усі сантиметри тут походять із самого запису координат. X, Y, Z у прикладі округлені до десятої частки метра, тож кожне з трьох чисел зсунуте не більш як на 5 сантиметрів — і рівно ці п'ять сантиметрів вилізли назад у трьох каналах відповіді. Якщо подати неокруглені координати, картина інша:

```text
X = 3 505 555.865079859   Y = 2 066 859.130507229   Z = 4 894 958.755552504

Боуринг:  φ = 50.450100000000°   λ = 30.523400000000°   h = 180.000000000 м
```

Замкнене коло без жодного залишку. Це і є повна перевірка обох переходів одразу: помилка в будь-якому знаку, у множнику (1 − e²) чи в порядку дій зламала б цю рівність на метри.

Наостанок — межа, до якої взагалі має сенс доводити ці формули. Проганяння туди й назад по сітці широт від −90° до 90°, довгот від −180° до 180° і висот від −5 км до 20 200 км дає найгіршу розбіжність 1.1·10⁻⁸ метра для Боуринга з двома кроками і 3.7·10⁻⁹ метра для п'ятикрокової ітерації — одиниці нанометрів. Це вже не геодезія, а межа самих чисел: з одним кроком Боуринга та сама сітка дає найгірші 0.24 метра, і всі вони припадають на єдиний рядок — висоту 20 200 км.

## Код

Обидва варіанти — і кроковий, і безциклічний — коротші, ніж їхнє виведення.

:::tabs
```cpp
#include <cmath>
#include <stdexcept>

constexpr double WGS84_A   = 6378137.0;
constexpr double WGS84_F   = 1.0 / 298.257223563;
constexpr double WGS84_E2  = WGS84_F * (2.0 - WGS84_F);
constexpr double WGS84_B   = WGS84_A * (1.0 - WGS84_F);
constexpr double WGS84_EP2 = WGS84_E2 / (1.0 - WGS84_E2);
constexpr double RAD2DEG   = 57.29577951308232;

struct Geodetic { double lat_deg, lon_deg, h; };

// Висоту беремо тією формулою, у якій знаменник не наближається до нуля.
static double height_from(double p, double z, double phi) {
    const double s = std::sin(phi), c = std::cos(phi);
    const double N = WGS84_A / std::sqrt(1.0 - WGS84_E2 * s * s);
    return std::fabs(c) > 0.5 ? p / c - N
                              : z / s - N * (1.0 - WGS84_E2);
}

// Боуринг 1976: один крок для всього наземного, другий — для орбіт.
Geodetic ecef_to_geodetic(double x, double y, double z, int steps = 1) {
    const double p = std::hypot(x, y);

    // Усередині цього еліпса нормаль не єдина — широти просто немає.
    if (p * p + (1.0 - WGS84_E2) * z * z < (WGS84_E2 * WGS84_A) * (WGS84_E2 * WGS84_A))
        throw std::domain_error("точка всередині еволюти: розв'язок неоднозначний");

    double beta = std::atan2(WGS84_A * z, WGS84_B * p);   // точно при h = 0
    double phi  = 0.0;
    for (int i = 0; i < steps; ++i) {
        const double sb = std::sin(beta), cb = std::cos(beta);
        phi = std::atan2(z + WGS84_EP2 * WGS84_B * sb * sb * sb,
                         p - WGS84_E2  * WGS84_A * cb * cb * cb);
        beta = std::atan2((1.0 - WGS84_F) * std::sin(phi), std::cos(phi));
    }
    return { phi * RAD2DEG, std::atan2(y, x) * RAD2DEG, height_from(p, z, phi) };
}

// Проста ітерація: |F'| <= e² = 0.0067, тож п'ять кроків вистачає завжди.
Geodetic ecef_to_geodetic_iter(double x, double y, double z) {
    const double p = std::hypot(x, y);
    double phi = std::atan2(z, p * (1.0 - WGS84_E2));     // старт: h = 0
    for (int i = 0; i < 5; ++i) {
        const double s = std::sin(phi);
        const double N = WGS84_A / std::sqrt(1.0 - WGS84_E2 * s * s);
        phi = std::atan2(z + WGS84_E2 * N * s, p);
    }
    return { phi * RAD2DEG, std::atan2(y, x) * RAD2DEG, height_from(p, z, phi) };
}
```
```py
import math

WGS84_A = 6378137.0
WGS84_F = 1.0 / 298.257223563
WGS84_E2 = WGS84_F * (2.0 - WGS84_F)
WGS84_B = WGS84_A * (1.0 - WGS84_F)
WGS84_EP2 = WGS84_E2 / (1.0 - WGS84_E2)


def _height_from(p, z, phi):
    """Висоту беремо тією формулою, у якій знаменник не близький до нуля."""
    s, c = math.sin(phi), math.cos(phi)
    n = WGS84_A / math.sqrt(1.0 - WGS84_E2 * s * s)
    return p / c - n if abs(c) > 0.5 else z / s - n * (1.0 - WGS84_E2)


def ecef_to_geodetic(x, y, z, steps=1):
    """Боуринг 1976: один крок для всього наземного, другий — для орбіт."""
    p = math.hypot(x, y)

    # Усередині цього еліпса нормаль не єдина — широти просто немає.
    if p * p + (1.0 - WGS84_E2) * z * z < (WGS84_E2 * WGS84_A) ** 2:
        raise ValueError("точка всередині еволюти: розв'язок неоднозначний")

    beta = math.atan2(WGS84_A * z, WGS84_B * p)          # точно при h = 0
    phi = 0.0
    for _ in range(steps):
        sb, cb = math.sin(beta), math.cos(beta)
        phi = math.atan2(z + WGS84_EP2 * WGS84_B * sb ** 3,
                         p - WGS84_E2 * WGS84_A * cb ** 3)
        beta = math.atan2((1.0 - WGS84_F) * math.sin(phi), math.cos(phi))

    return (math.degrees(phi), math.degrees(math.atan2(y, x)),
            _height_from(p, z, phi))


def ecef_to_geodetic_iter(x, y, z):
    """Проста ітерація: |F'| <= e² = 0.0067, тож п'ять кроків вистачає завжди."""
    p = math.hypot(x, y)
    phi = math.atan2(z, p * (1.0 - WGS84_E2))            # старт: h = 0
    for _ in range(5):
        s = math.sin(phi)
        n = WGS84_A / math.sqrt(1.0 - WGS84_E2 * s * s)
        phi = math.atan2(z + WGS84_E2 * n * s, p)
    return (math.degrees(phi), math.degrees(math.atan2(y, x)),
            _height_from(p, z, phi))
```

На сітці з попереднього розділу — з полюсами, точками під поверхнею й висотою навігаційної орбіти — п'ятикрокова ітерація тримає нанометри, а Боуринг тримає їх же, щойно `steps` стає двійкою; з одиницею він відступає лише на орбіті. Уся різниця між функціями — не в точності, а в тому, чим ви готові платити: п'ятьма проходами циклу чи двома арктангенсами й знанням, коли одного кроку замало.
