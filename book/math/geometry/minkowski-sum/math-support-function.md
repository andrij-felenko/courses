# 🧮 Опорна функція: доведення того, що ⊕ додає ширини й площі

Уся арифметика суми Мінковського тримається на одному числі — наскільки далеко фігура сягає в наперед заданий напрям. Тут це число означено строго, доведено головну тотожність про нього, а з неї виведено решту: чому ширини складаються, чому вершини суми є сумами вершин, звідки береться зайва площа роздутої фігури й скільки її саме.

<preknowlist>
- [Скалярний добуток](book:math/dot-product) — проєкція вектора на напрям і розклад u·(a + b) = u·a + u·b: саме на ньому тримається головне доведення.
- [Опукла множина](book:math/convex-set) — множина, що разом із будь-якими двома своїми точками містить увесь відрізок між ними; опукла комбінація точок.
- [Супремум](book:math/supremum-infimum) — точна верхня межа числової множини: найменша з усіх верхніх меж, тож на будь-яку відстань ε нижче за неї вже трапляється елемент множини.
- [Площа многокутника за координатами](book:math/shoelace-area) — формула шнурівки, якою ми перевірятимемо всі числа.
</preknowlist>

## Число, що дивиться в один бік

Візьмімо непорожню обмежену множину A на площині й одиничний вектор u. Кожній точці a ∈ A скалярний добуток u·a ставить у відповідність одне число — наскільки далеко ця точка просунулася в напрямі u. Найбільше з цих чисел і називають **опорною функцією** множини A:

```
h_A(u) = sup { u·a : a ∈ A }
```

Чому саме sup, а не max. Множина чисел {u·a} обмежена зверху, бо обмежена сама A, — тож точна верхня межа існує завжди. А от досягається вона не завжди: у відкритого круга жодна точка не є найдальшою в напрямі u, хоча супремум — цілком конкретне число. Для замкненої обмеженої множини неперервна функція a ↦ u·a досягає максимуму, і тоді sup можна читати як max; там, де ця різниця важить, вона застережена окремо.

Геометричний зміст читається з рівняння прямої. Рівність u·x = c за одиничного u задає пряму, перпендикулярну до u, віддалену від початку координат на c (від'ємне c означає «по інший бік»), а нерівність u·x ≤ c — півплощину, яку ця пряма відтинає з боку початку координат. Тепер зменшуймо c: півплощина стискається, і найменше c, за якого A ще вміщається в неї цілком, — це рівно h_A(u). Пряму u·x = h_A(u) називають **опорною**: фігура лежить по один бік від неї й дотикається до неї (принаймні наближається впритул).

```
точка {p}:                      h(u) = u·p
круг радіуса r з центром 0:     h(u) = r
круг радіуса r з центром c:     h(u) = u·c + r
відрізок від 0 до v:            h(u) = max(0, u·v)
опуклий багатокутник:           h(u) = max по вершинах u·vᵢ

(рядки про круг записано для одиничного u)
```

Останній рядок ще треба виправдати — це станеться далі, разом із дечим більшим. Зауважмо принагідно, що означення не вимагає |u| = 1: для будь-якого λ ≥ 0 маємо h_A(λu) = λ·h_A(u), тож функція повністю визначена своїми значеннями на одиничному колі, а геометричне читання «відстань до опорної прямої» лишається чинним саме для одиничних u.

## Головна тотожність

**Теорема.** Для будь-яких непорожніх обмежених A, B і будь-якого напряму u

```
h_{A⊕B}(u) = h_A(u) + h_B(u)
```

Доведемо дві нерівності — «≤» і «≥».

**≤.** Кожен елемент A ⊕ B має вигляд a + b, де a ∈ A, b ∈ B. Тоді

```
u·(a + b) = u·a + u·b ≤ h_A(u) + h_B(u)
```

перша рівність — розподільність скалярного добутку, далі — означення супремуму як верхньої межі, застосоване двічі. Отже число h_A(u) + h_B(u) є верхньою межею для всієї множини {u·x : x ∈ A ⊕ B}. А супремум — **найменша** з верхніх меж, тож h_{A⊕B}(u) ≤ h_A(u) + h_B(u).

**≥.** Тут працює те, заради чого все й затівалося: доданки незалежні. Візьмімо будь-яке ε > 0. За означенням супремуму знайдеться a ∈ A з u·a > h_A(u) − ε/2. Незалежно від цього вибору — жодна умова не пов'язує a з b — знайдеться b ∈ B з u·b > h_B(u) − ε/2. Точка a + b належить A ⊕ B саме тому, що в означенні беруть **усі** пари, а не якісь узгоджені. Отже

```
h_{A⊕B}(u) ≥ u·(a + b) > h_A(u) + h_B(u) − ε
```

Нерівність справджується за кожного ε > 0, а число, більше за h_A(u) + h_B(u) − ε для всіх ε, не може бути меншим за h_A(u) + h_B(u). Обидві нерівності разом дають рівність. ∎

Якщо A і B компактні, доведення коротшає: беремо не «майже рекордсменів», а самих рекордсменів a* і b*, і ε не потрібне взагалі.

Варто зупинитися на тому, що саме тут спрацювало, — бо для сусідньої операції той самий хід неможливий. Точка з перетину A ∩ B мусить бути **однією й тією самою** і для A, і для B; вибрати двічі незалежно не вийде. Лишається тільки

```
h_{A∩B}(u) ≤ min( h_A(u), h_B(u) )
```

і нерівність зазвичай строга. Покладіть навхрест два довгі вузькі прямокутники: у напрямі під 45° кожен сягає далеко, а їхній перетин — маленький квадратик посередині, і його опорна функція набагато менша за обидві.

> 🔧 **Навіщо це.** Тотожність перетворює операцію над множинами на додавання чисел. Опукла фігура повністю описана функцією на колі; ⊕ для таких описів — звичайне поточкове додавання. Усе, що далі, — це наслідки одного рядка «функції складаються», прочитані в різних термінах: відстані, довжини, площі.

## Що з неї випливає негайно

**Ширина складається.** Ширина фігури в напрямі u — це відстань між двома опорними прямими, перпендикулярними до u:

```
w_A(u) = h_A(u) + h_A(−u)
```

(другий доданок міряє, наскільки далеко A сягає в протилежний бік). Додавши тотожність для u й для −u, дістаємо w_{A⊕B}(u) = w_A(u) + w_B(u) — і це справджується **в кожному напрямі без винятку**. Звідси, зокрема: роздути фігуру на круг радіуса r означає додати рівно 2r до її ширини в кожному напрямі, бо ширина круга скрізь однакова.

**Периметр опуклих багатокутників складається.** Коли напрями двох ребер збігаються, вони зливаються в одне ребро, довжина якого — сума довжин (вектори однонапрямлені); решта ребер переходить у суму як є. Отже сумарна довжина контуру додається: perim(A ⊕ B) = perim(A) + perim(B). Для трикутника з катетами 4 і 3 та одиничного квадрата: 12 + 4 = 16, і п'ятикутник-сума справді має периметр 5 + 1 + 5 + 1 + 4 = 16. Для довільних опуклих фігур те саме дістають граничним переходом від багатокутників; цей перехід ми не проводимо.

**Опорна функція не бачить неопуклості.** Нехай x — опукла комбінація точок A, тобто x = Σλᵢaᵢ з λᵢ ≥ 0 і Σλᵢ = 1. Тоді

```
u·x = Σ λᵢ (u·aᵢ) ≤ Σ λᵢ h_A(u) = h_A(u)
```

Отже h для [опуклої оболонки](book:algorithms/convex-hull) не більша за h_A, а що A ⊆ conv(A), то й не менша: h_A = h_{conv A}. Заразом виправдано рядок таблиці про багатокутник — максимум лінійної функції на оболонці досягається на вершині.

Звідси й тотожність про оболонки, причому без опорних функцій. Візьмімо точку з conv(A) ⊕ conv(B):

```
Σᵢ λᵢaᵢ + Σⱼ μⱼbⱼ = Σᵢ Σⱼ λᵢμⱼ · (aᵢ + bⱼ),   бо Σⱼμⱼ = 1 і Σᵢλᵢ = 1
```

Ваги λᵢμⱼ невід'ємні й у сумі дають 1, а точки aᵢ + bⱼ лежать в A ⊕ B — отже ліва частина належить conv(A ⊕ B). Навпаки, A ⊕ B ⊆ conv(A) ⊕ conv(B), а права множина опукла (сума опуклих опукла), тож і опукла оболонка лівої в ній міститься. Два протилежні включення дають

```
conv(A) ⊕ conv(B) = conv(A ⊕ B)
```

**Опукла множина відновлюється зі своєї опорної функції.** Замкнена опукла множина A є перетином усіх своїх опорних півплощин:

```
A = ⋂ { x : u·x ≤ h_A(u) }   по всіх одиничних u
```

Включення «⊆» — це просто означення h. Зворотне спирається на [теорему про відокремлення](book:math/supporting-hyperplane) (беремо як факт): якщо точка x₀ не належить замкненій опуклій A, то знайдеться напрям u з u·x₀ > h_A(u), тобто x₀ відсікається однією з півплощин. Отже для замкнених опуклих множин відповідність «множина ↔ опорна функція» взаємно однозначна, і ⊕ на них — буквально додавання функцій.

Для неопуклих цієї взаємної однозначності немає: множина та її опукла оболонка мають ту саму h. Тому все, що ми читаємо з опорної функції суми — опорні прямі, ширини, рекордсмени, — стосується conv(A) ⊕ conv(B) і нічого не знає про западини доданків. Сама множина A ⊕ B западини мати може; просто цей апарат про них мовчить, і тому працює лише для опуклих.

## Грані й вершини: рекордсмени складаються

Назвімо **гранню** множини A в напрямі u множину її рекордсменів:

```
F(A, u) = { a ∈ A : u·a = h_A(u) }
```

Для компактної A вона непорожня. У багатокутника це або одна вершина, або ціле ребро.

**Теорема.** Для компактних A, B: F(A ⊕ B, u) = F(A, u) ⊕ F(B, u).

**⊇.** Якщо a ∈ F(A, u) і b ∈ F(B, u), то u·(a + b) = h_A(u) + h_B(u) = h_{A⊕B}(u), тобто a + b — рекордсмен суми.

**⊆.** Нехай x ∈ F(A ⊕ B, u) і x = a + b — будь-який його розклад. Тоді u·a + u·b = h_A(u) + h_B(u), причому окремо u·a ≤ h_A(u) і u·b ≤ h_B(u). Дві нерівності «≤», сума яких є рівністю, можуть бути лише рівностями: якби хоч одна була строгою, сума вийшла б строго меншою. Отже a ∈ F(A, u), b ∈ F(B, u). ∎

**Наслідок про вершини.** Точка x — вершина опуклого багатокутника C тоді, коли для якогось напряму u грань F(C, u) складається з єдиної точки x. Нехай так для C = A ⊕ B. За теоремою {x} = F(A, u) ⊕ F(B, u), а сума двох множин одноточкова лише тоді, коли обидві одноточкові: якби в F(A, u) знайшлися дві різні точки a₁ ≠ a₂, то a₁ + b ≠ a₂ + b дали б у сумі дві різні точки. Отже F(A, u) = {a}, F(B, u) = {b}, і

```
x = a + b,  де a — вершина A, b — вершина B, рекордсмени в ОДНОМУ напрямі u
```

Ось звідки береться алгоритм злиття ребер: обертаючи u, ми переставляємо пару рекордсменів, і пара змінюється рівно тоді, коли u перетинає нормаль ребра A або ребра B. Заразом видно, чому лобовий спосіб «скласти всі пари вершин і натягнути оболонку» дає правильну відповідь (кожна вершина суми серед цих пар є) і чому він марнотратний: до межі доходять лише пари, рекордсмени в спільному напрямі, а таких пар лінійно мало.

## Площа: скільки саме зайвого

Площа під ⊕ не додається: трикутник площею 6 і квадрат площею 1 дають п'ятикутник площею 14. Надлишок — не похибка й не залишок; це самостійна величина, яку **означують** саме через цю різницю:

```
2·V(A, B) := area(A ⊕ B) − area(A) − area(B)
```

V(A, B) називають **змішаною площею**. Вона симетрична задарма, бо ⊕ комутативна. Для нашої пари 2V = 14 − 6 − 1 = 7.

Тепер порахуймо це число незалежно — і побачимо, з чого воно складене. Позначмо L_C(n) сумарну довжину ребер опуклого багатокутника C із зовнішньою нормаллю n (нуль, якщо такого ребра немає). Злиття ребер дає L_{A⊕B} = L_A + L_B, а теорема вище — h_{A⊕B} = h_A + h_B. (В опуклого багатокутника на кожен напрям нормалі припадає щонайбільше одне ребро, тож L_C(n) — це просто його довжина.) Потрібна ще формула площі через опорну функцію: кожне ребро разом із початком координат утворює трикутник з основою L_C(n) і висотою h_C(n) — бо h_C(n) і є відстань від початку координат до прямої цього ребра. Звідси

```
area(C) = ½ · Σ_n h_C(n) · L_C(n)
```

(коли початок координат поза фігурою, деякі трикутники входять зі знаком мінус, і рівність усе одно чинна). Підставмо суму:

```
2·area(A ⊕ B) = Σ (h_A + h_B)(L_A + L_B)
              = Σ h_A L_A + Σ h_B L_B + Σ h_A L_B + Σ h_B L_A
              = 2·area(A) + 2·area(B) + Σ h_A L_B + Σ h_B L_A
```

тобто

```
2·V(A, B) = ½ · ( Σ_n h_A(n)·L_B(n) + Σ_n h_B(n)·L_A(n) )
```

**Умова: A — трикутник (0,0), (4,0), (0,3); B — одиничний квадрат із кутом у початку координат.**

```
нормаль n      L_A   L_B    h_A(n)   h_B(n)
(0, −1)         4     1       0        0
(1, 0)          0     1       4        1
(0.6, 0.8)      5     0      2.4      1.4
(0, 1)          0     1       3        1
(−1, 0)         3     1       0        0

Σ h_A L_B = 0·1 + 4·1 + 3·1 + 0·1 = 7
Σ h_B L_A = 0·4 + 1.4·5 + 0·3     = 7
2V = ½·(7 + 7) = 7                       ✓ збігається з 14 − 6 − 1

контроль тією самою формулою площі:
area(A)     = ½·(0·4 + 2.4·5 + 0·3)              = 6
area(B)     = ½·(0·1 + 1·1 + 1·1 + 0·1)          = 1
area(A ⊕ B) = ½·(0·5 + 5·1 + 3.8·5 + 4·1 + 0·4)  = 14
```

Обидві однобічні суми дали по 7 — це не збіг: кожна з них окремо дорівнює 2V(A, B), хоча доведення цієї симетрії довше й нам не знадобиться — симетричний вираз вище вже повний.

Два зауваження про масштаб. По-перше, h_{tB} = t·h_B і L_{tB} = t·L_B, тож

```
area(A ⊕ tB) = area(A) + 2t·V(A, B) + t²·area(B),   t ≥ 0
```

— площа роздутої фігури є квадратним тричленом від коефіцієнта роздування. По-друге, V(A, A) = area(A): для опуклої A маємо A ⊕ A = 2A (включення «⊇» очевидне, а «⊆» — бо a₁ + a₂ = 2·(½a₁ + ½a₂), і середина належить A за опуклістю), звідки 2V(A, A) = 4·area(A) − 2·area(A) = 2·area(A). Для неопуклої це хибно: для множини з двох точок {0, v} сума A ⊕ A дає три точки {0, v, 2v}, а 2A — лише дві. Змішана площа, отже, узагальнює звичайну — звідси й назва.

## Круг замість B: формула Штайнера

Нехай K — опуклий багатокутник, D — одиничний круг із центром у початку координат, а B = rD. Спершу переконаймося, що K ⊕ rD — це просто r-окіл:

```
x ∈ K ⊕ rD  ⟺  x = k + r·d, |d| ≤ 1, k ∈ K  ⟺  |x − k| ≤ r для якогось k ∈ K
```

тобто множина точок, віддалених від K не більш ніж на r. Тепер розберімо її на шматки за **найближчою точкою** K. Найближча точка єдина: якби їх було дві, то їхня середина, теж належна K за опуклістю, лежала б до x строго ближче — суперечність. Отже кожен x належить рівно одному з таких шматків:

- x ∈ K — найближчою є сама точка x;
- найближча точка лежить усередині ребра e — тоді x стоїть на перпендикулярі до e, тобто в прямокутнику, поставленому на e назовні з висотою r;
- найближча точка — вершина v — тоді x лежить у круговому секторі радіуса r із центром у v, розкритому між нормалями двох ребер, що сходяться у v.

Шматки не накладаються (найближча точка одна) і покривають усе. Лишається скласти площі: сам K; прямокутники дають r·Σ|eᵢ| = r·perim(K); сектори мають кути, рівні зовнішнім кутам багатокутника, а ті в сумі дають 2π, тож усі сектори разом — це ½r²·2π = πr², повний круг. Разом:

```
area(K ⊕ rD) = area(K) + r·perim(K) + π·r²
```

*Розбиття r-околу за найближчою точкою: сам K, смуга на кожне ребро, сектор на кожну вершину.*

**Умова: квадрат зі стороною 2, r = 1.**

```
за формулою:      4 + 1·8 + π = 12 + π ≈ 15.14

незалежна перевірка: r-окіл вписано в квадрат 4×4 (площа 16),
з якого в кожному куті вийнято «квадратик мінус чверть круга»:
16 − 4·(1 − π/4) = 16 − 4 + π = 12 + π                    ✓
```

Порівняння з квадратним тричленом дає ще одне прочитання: 2V(K, D) = perim(K), тобто змішана площа фігури з одиничним кругом — це половина її периметра. Формулу відкрив 1840 року швейцарський геометр Якоб Штайнер для опуклих кривих на площині й поверхонь у просторі (усталений факт); для довільних опуклих фігур вона дістається граничним переходом від багатокутників.

## Куди це виросло

Наостанок — межа, до якої доросла ця операція. Для будь-яких непорожніх компактних A, B справджується **нерівність Брунна–Мінковського**; доведення тут не наводимо й беремо її як факт:

```
на площині:   √area(A ⊕ B)  ≥  √area(A) + √area(B)
у ℝⁿ:         vol(A ⊕ B)^(1/n)  ≥  vol(A)^(1/n) + vol(B)^(1/n)
```

Для опуклих тіл рівність настає тоді й лише тоді, коли A і B гомотетичні — однакові за формою з точністю до розтягу й перенесення. Наша пара не гомотетична, тож нерівність має бути строгою: √14 ≈ 3.742 проти √6 + 1 ≈ 3.449. ✓

Підставмо сюди означення змішаної площі й піднесімо обидві частини до квадрата:

```
area(A) + 2V(A,B) + area(B)  =  area(A ⊕ B)
                             ≥  (√area(A) + √area(B))²
                             =  area(A) + 2·√(area(A)·area(B)) + area(B)
```

Однакові доданки скорочуються, і лишається нерівність Мінковського для змішаної площі:

```
V(A, B) ≥ √( area(A) · area(B) )
```

(перевірка: 3.5 ≥ √6 ≈ 2.449 ✓). А тепер візьмімо A = K, B = D. Ліворуч, як щойно з'ясовано, стоїть perim(K)/2, праворуч — √(area(K)·π):

```
perim(K)/2 ≥ √(π·area(K))   ⟹   perim(K)² ≥ 4π·area(K)
```

Це класична ізопериметрична нерівність: серед фігур однакового периметра найбільшу площу має круг. Задача про неї давня, а тут вона випала за три рядки з нерівності про суму двох фігур — і це, мабуть, найкоротший спосіб побачити, наскільки глибоко ⊕ вросла в геометрію. Саму нерівність довів 1887 року Герман Брунн у мюнхенській дисертації «Über Ovale und Eiflächen», а Герман Мінковський 1896 року дав загальне формулювання, умову рівності й теорію змішаних об'ємів, з якої походить усе на цій сторінці (усталений факт).
