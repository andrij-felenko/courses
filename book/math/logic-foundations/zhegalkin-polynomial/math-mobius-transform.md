# 🧮 Алгебра перетворення Мебіуса: XOR підмножин, інволюція, єдиність

Перетворення Мебіуса перекидає таблицю істинності в коефіцієнти полінома Жегалкіна одним каскадом XOR-ів — і, що найдивніше, той самий каскад, пущений удруге, повертає таблицю назад. За цією механікою стоїть одна коротка алгебра, з якої випливає геть усе: чому коефіцієнт при добутку змінних — це XOR значень функції на підмножинах, чому перетворення само собі обернене, і чому поліном для кожної функції рівно один. Розберімо її від першої цеглини — далі не буде жодного кроку «повірте на слово».

## Один об'єкт у двох мовах: значення й коефіцієнти

Візьмімо [булеву функцію](book:math/boolean-algebra) f від n змінних. У неї два цілком рівноправні описи. Перший — **таблиця значень**: 2ⁿ рядків, у кожному вихід 0 або 1. Другий — **поліном Жегалкіна**: вибір, які з 2ⁿ можливих добутків змінних увімкнені. Перетворення Мебіуса — це точний словник між цими двома мовами. Щоб його вивести, спершу оберемо одну спільну систему координат для обох.

Кожному входу a = (a₁, …, aₙ) зіставмо його **носій** — множину індексів, де стоїть одиниця:

```
A = supp(a) = { i : aᵢ = 1 } ⊆ {1, …, n}
```

Носіїв рівно стільки, скільки входів, — 2ⁿ, по одному на кожну підмножину. Тож віднині писатимемо f(A): значення функції на вході, чий носій — множина A. Таблиця істинності — це просто функція на підмножинах.

Так само занумеруємо мономи. Кожному добутку відповідає множина його змінних: константі — порожня множина, добутку xᵢ — одноелементна {i}, добутку xᵢ·xⱼ — двоелементна {i, j}. Позначмо моном множини S так:

```
m_S = ∏(xᵢ : i ∈ S)        порожній добуток m_∅ = 1
```

Поліном Жегалкіна — це XOR деяких із цих мономів, тобто набір бітів-коефіцієнтів c_S ∈ {0, 1}, по одному на кожну підмножину S:

```
f = ⊕(c_S · m_S : S ⊆ {1, …, n})
```

Тепер ключове спостереження — коли моном m_S дає одиницю. Добуток ∏(aᵢ : i ∈ S) — одиниця тоді й лише тоді, коли **всі** співмножники одиниці, тобто коли aᵢ = 1 для кожного i ∈ S. А це і є умова S ⊆ A. Моном множини S «спрацьовує» рівно на тих входах, чий носій **містить** S:

```
m_S(A) = 1,  якщо S ⊆ A;   інакше 0
```

Підставмо це у формулу полінома. На вході A вцілюють лише мономи з S ⊆ A, решта занулюються, і значення функції стає XOR-ом їхніх коефіцієнтів:

```
f(A) = ⊕(c_S : S ⊆ A)        ← пряме перетворення (значення з коефіцієнтів)
```

Ось воно, серце всієї теми, в один рядок. Значення функції на вході A — це [«виключне або»](book:electronics/xor-comparison) коефіцієнтів усіх мономів, що «вкладаються» в A. Назвімо оператор, що робить цю згортку по підмножинах, буквою M:

```
(M g)(A) = ⊕(g(S) : S ⊆ A)
```

Тоді пряме перетворення — це просто f = M·c: беремо вектор коефіцієнтів c і згортаємо його оператором M у вектор значень f. Лишилося обернути: маючи f, дістати c. І тут починається справжня алгебра.

## Одна лема тримає все: інтервали в ґратці підмножин

Обернути M — означає розплутати вкладену подвійну суму. Уся складність згортається до єдиного лічильного факту про підмножини, тож виведімо його окремо й раз назавжди.

**Лема.** Нехай R ⊆ S. Кількість множин T, затиснутих між ними (R ⊆ T ⊆ S), дорівнює 2 у степені кількості «вільних» елементів:

```
#{ T : R ⊆ T ⊆ S } = 2^|S∖R|
```

Чому саме так? Кожна допустима T зобов'язана містити весь R і не вилазити за S. Отже, R у ній є завжди, а вирішувати можна лише про елементи різниці S∖R: кожен із них або докидаємо в T, або ні. Незалежний вибір «так/ні» на кожному з |S∖R| елементів дає 2^|S∖R| різних T. Жодної хитрості — просто перелік підмножин вільної частини.

А тепер — навіщо нам ця лічба. Ми складатимемо коефіцієнти [за модулем 2](book:math/modular-arithmetic), а там важлива не сама кількість копій, а її **парність**: однакові доданки гинуть парами (x ⊕ x = 0), тож XOR парного числа копій — нуль, непарного — сама копія. Степінь двійки 2^k непарний лише в одному-єдиному випадку — коли k = 0, тобто 2⁰ = 1. А |S∖R| = 0 означає S∖R = ∅, тобто R = S. Підсумок, який ми носитимемо в кишені весь час:

```
2^|S∖R| непарне  ⟺  |S∖R| = 0  ⟺  R = S
```

Тобто в будь-якій XOR-сумі, де коефіцієнт c_R трапляється 2^|S∖R| разів, він виживає **тільки** при R = S, а всі R ⊊ S взаємно знищуються ще до того, як ми на них глянемо. Ця асиметрія — увесь двигун теми.

![Ґратка підмножин {a,b,c}: вісім вузлів у чотири яруси, ребра з'єднують множину з надмножиною на один елемент; виділено інтервал [∅, {a,b}] з чотирьох вузлів (2²), поряд — формула леми про 2^|S∖R| наборів і правило, що парне число копій гине за модулем 2](/book/math/logic-foundations/zhegalkin-polynomial/img/mobius-lemma.svg)
*Підмножини впорядковані вкладенням: знизу порожня, зверху повна. Інтервал [R, S] — це маленький підкуб між ними, і в ньому рівно 2^|S∖R| вузлів. Для XOR за модулем 2 значуща лише парність цього числа: усе, крім поодинокого випадку R = S, іде парами й гине.*

## Формула коефіцієнтів: c_S = ⊕(f(T) : T ⊆ S)

Тепер оберталка сама впаде нам у руки. Стверджуємо: коефіцієнт при мономі множини S — це XOR значень функції на всіх наборах-підмножинах S.

```
c_S = ⊕(f(T) : T ⊆ S)
```

Доведімо це в лоб — підставмо в праву частину пряме перетворення f(T) = ⊕(c_R : R ⊆ T) і поспостерігаймо, що вціліє:

```
⊕(f(T) : T ⊆ S)
   = ⊕( ⊕(c_R : R ⊆ T) : T ⊆ S )        ← кожне f(T) розписали через коефіцієнти
   = ⊕( c_R · #{T : R ⊆ T ⊆ S} : R ⊆ S)  ← зібрали однакові c_R докупи
   = ⊕( c_R · 2^|S∖R| : R ⊆ S )          ← лема дала кратність
   = c_S                                 ← парні кратності згасли, лишилось R = S
```

Придивімося до другого рядка. Ми поміняли порядок підсумовування: замість «пробігти всі T, а в кожному — всі R ⊆ T» рахуємо «для кожного R — скільки разів він узагалі виник». Коефіцієнт c_R з'являється рівно стільки разів, скільки є проміжних T із R ⊆ T ⊆ S, — а це наша лема, 2^|S∖R|. Далі спрацьовує парність: для будь-якого R ⊊ S кратність парна, і всі ці доданки гинуть; уцілів лише R = S із кратністю 2⁰ = 1. Права частина стиснулася до самого c_S. Формулу доведено.

Варто зупинитися й відчути, що сталося. Пряме перетворення й обернене записуються **однією й тією ж** формулою — «XOR по всіх підмножинах індексу». M бере коефіцієнти й видає значення; те саме M бере значення й видає коефіцієнти. Це не збіг запису, а глибокий факт, до якого зараз і дійдемо.

Перевірмо формулу не на слово, а перебором — на мажоритарній функції МАЖ(a, b, c), що видає одиницю за більшості одиниць на вході:

```python
from itertools import combinations

n = 3
maj   = lambda k: bin(k).count("1") >= 2          # більшість одиниць у 3 бітах
truth = [int(maj(k)) for k in range(1 << n)]      # таблиця значень МАЖ

def mobius(v):                                    # каскад SOS — той самий в обидва боки
    v = v[:]
    for i in range(n):
        for k in range(1 << n):
            if k >> i & 1:
                v[k] ^= v[k ^ (1 << i)]
    return v

coef = mobius(truth)
assert mobius(coef) == truth                      # інволюція: двічі — тотожність

bit = lambda A: sum(1 << i for i in A)            # підмножина індексів → номер входу
def c(S):                                         # формула c_S = ⊕(f(T) : T ⊆ S)
    r = 0
    for m in range(len(S) + 1):
        for T in combinations(S, m):
            r ^= truth[bit(T)]
    return r

assert c((0, 1))    == coef[bit((0, 1))]    == 1                       # при a·b — одиниця
assert c((0, 1, 2)) == coef[bit((0, 1, 2))] == truth.count(1) % 2 == 0  # верхній = парність ваги
print("формула c_S і каскад збігаються; M(M(f)) == f")
```

Обидва `assert` мовчать. Формула коефіцієнтів через XOR підмножин працює клітина в клітину з каскадом, а на додачу видно дві речі, до яких ми ще повернемося: прогін Мебіуса двічі повертає вихідну таблицю, і верхній коефіцієнт дорівнює парності ваги таблиці.

## Чому це інволюція: M² = I над GF(2)

Тепер строго про «двічі — тотожність». Застосуймо M до вже перетвореного вектора й простежмо, що вийде. Обчислення дослівно повторює доведення формули коефіцієнтів — з тією ж лемою, лише перейменованими буквами:

```
(M(M g))(A) = ⊕( (M g)(S) : S ⊆ A )
            = ⊕( ⊕(g(T) : T ⊆ S) : S ⊆ A )
            = ⊕( g(T) · #{S : T ⊆ S ⊆ A} : T ⊆ A )
            = ⊕( g(T) · 2^|A∖T| : T ⊆ A )
            = g(A)
```

Знову вся сума схлопнулася до єдиного вцілілого доданка — тепер T = A, — і M(M g) = g для будь-якого g. Оператор, застосований двічі, дає тотожність: **M² = I**. Ось строга причина, чому один і той самий каскад будує і поліном із таблиці, і таблицю з полінома, і чому другий прогін повертає початок.

Найчистіше це видно, якщо записати M **матрицею**. Занумеруймо рядки й стовпці підмножинами; на перетині ставмо одиницю саме там, де стовпець вкладається в рядок:

```
M[A][S] = 1,  якщо S ⊆ A;   інакше 0
```

Тоді пряме f = M·c і обернене c = M·f — це множення на ту саму матрицю над [полем із двох елементів GF(2)](book:math/finite-fields), а рівність M² = I каже, що ця матриця сама собі обернена. Для двох змінних її можна виписати повністю й перемножити руками:

![Матриця M перетворення Мебіуса для двох змінних: нижньотрикутна 4×4 матриця з нулів та одиниць, рядки й стовпці позначено підмножинами ∅, a, b, ab; поряд — тотожна матриця I як результат M², з підписом, що f = M·c і c = M·f задає той самий M, а M² = I означає інволюцію](/book/math/logic-foundations/zhegalkin-polynomial/img/involution.svg)
*Матриця M нижньотрикутна з одиницями на діагоналі — уже тому вона оборотна. Над GF(2) її обернена — вона сама: M·M дає тотожну I, тож перетворення в обидва боки — це одне множення на M.*

А тепер — найглибше «чому», яке відрізняє GF(2) від решти світу. У звичайній комбінаториці обернення Мебіуса на ґратці підмножин **не** повторює пряму суму: якщо g(A) = Σ(f(S) : S ⊆ A) над цілими, то назад доводиться йти зі **знаками**, f(A) = Σ((−1)^|A∖S| · g(S) : S ⊆ A). Пряме й обернене — різні операції саме через ці чергові плюси й мінуси. Але ми лічимо за модулем 2, де −1 = +1: у [характеристиці 2](book:math/finite-fields) знак «мінус» не існує, він збігається з «плюс». Усі множники (−1)^|A∖S| обертаються на одиниці, знакова оберталка вироджується в ту саму беззнакову пряму суму — і перетворення стає інволюцією. Самообернення Мебіуса над GF(2) — це прямий подарунок характеристики 2: там, де над цілими живуть два різні перетворення, над бітами лишається одне.

## Єдиність — строго, через бієкцію

Тепер збираємо врожай. Ми маємо дві операції між двома скінченними світами — векторами коефіцієнтів c і функціями f:

```
Знач:  c ↦ f,   f(A) = ⊕(c_S : S ⊆ A)      (обчислити поліном)
Коеф:  f ↦ c,   c_S = ⊕(f(T) : T ⊆ S)      (перетворення Мебіуса)
```

Формула коефіцієнтів каже, що Коеф(Знач(c)) = c для будь-якого c — беремо коефіцієнти, згортаємо в значення, розгортаємо назад і дістаємо ті самі коефіцієнти. Інволюція каже дзеркальне: Знач(Коеф(f)) = f. Обидві композиції — тотожність, тож **Знач і Коеф — взаємно обернені бієкції**. А бієкція означає рівно те, що треба: кожній функції відповідає **рівно один** вектор коефіцієнтів. Не жодного, не два — один. Поліном Жегалкіна єдиний, і це не окрема теорема, а безкоштовний наслідок того, що ми виписали обернене перетворення явно. Явна оберталка — і є доведення єдиності.

Є й друга дорога до єдиності — чиста лічба, — і варто пройти нею теж, бо вона показує, де саме лічба **сама по собі нічого не доводить**. Порахуймо обидва світи. Векторів коефіцієнтів — 2 у степені 2ⁿ: підмножин рівно 2ⁿ, кожній свій біт. Булевих функцій — теж 2 у степені 2ⁿ: таблиця має 2ⁿ рядків, у кожному 0 або 1. Числа збіглися:

```
|усі вектори коефіцієнтів| = 2^(2ⁿ) = |усі булеві функції|
```

Спокусливо оголосити: раз порівну — значить, відповідність один-до-одного. Але сам збіг чисел цього **не** дає. Уявіть, що якісь функції мають по два поліноми, а якісь — жодного; кількості цілком могли б лишитися рівні, а єдиність — завалитися. Щоб замкнути аргумент, потрібен ще один факт: відображення Знач **накриває** всі функції — кожну функцію якийсь поліном таки задає (це доводить сама побудова полінома згортанням). А сюр'єкція між скінченними множинами **однакового** розміру автоматично є ін'єкцією: якби два різні поліноми давали одну функцію, образів забракло б, щоб накрити всі 2^(2ⁿ) функцій. Отже, різні поліноми дають різні функції — знову єдиність. Лічба працює лише в парі з існуванням; поодинці — це половина доведення. Явна ж оберталка обходиться без цього застереження: вона будує бієкцію на очах, а не вгадує її з рівності чисел.

## Степінь і булева похідна: власне числення полінома

Коли функція нарешті записана поліномом, у неї з'являються величини, невидимі в мові ∧, ∨, ¬. Перша — **алгебричний степінь**: найбільша потужність множини серед увімкнених мономів.

```
deg f = max( |S| : c_S = 1 )
```

Степінь 0 — сталі; степінь не вище 1 — лінійні (афінні) функції, самі XOR-и й заперечення; щойно з'являється добуток двох різних змінних — степінь 2 і вище. Формула коефіцієнтів одразу дає гарний факт про **верхній** моном x₁·x₂·…·xₙ. Його коефіцієнт — це c для повної множини, тобто XOR значень на **всіх** підмножинах, а їх рівно всі входи:

```
c_{повна} = ⊕(f(T) : T ⊆ повна) = ⊕(f по всіх 2ⁿ входах) = парність ваги таблиці
```

Отже, найстарший моном присутній тоді й лише тоді, коли одиниць у таблиці **непарне** число. Для МАЖ їх чотири — парно, тож a·b·c не входить, і степінь рівно 2. Ми щойно бачили це в коді: `c((0,1,2)) == truth.count(1) % 2 == 0`.

> 🔧 **Навіщо це.** Степінь — не декоративне число. Функції степеня не вище r, узяті як таблиці істинності, утворюють лінійний підпростір, і цей підпростір — рівно код Ріда — Маллера порядку r; уся сім'я цих завадостійких кодів побудована на алгебричному степені полінома Жегалкіна. А в криптографії високий степінь — це стійкість: лінійну (степеня 1) функцію зловмисник наближає системою рівнянь і розв'язує за мить, тож вузли шифру навмисне беруть високого степеня, щоб такого наближення не існувало.

Друга величина — **булева похідна** за змінною, дискретний аналог d/dx:

```
∂f/∂xᵢ = f|xᵢ=1 ⊕ f|xᵢ=0
```

Це різниця двох зрізів функції — при xᵢ = 1 і при xᵢ = 0, — і вона каже просту річ: похідна дорівнює одиниці рівно там, де **перемикання** входу xᵢ перемикає вихід. Це чутливість функції до i-ї змінної, її локальна «швидкість зміни». А що вона робить із самим поліномом? Розкладімо f по змінній xᵢ, зібравши окремо мономи з нею й без неї:

```
f = xᵢ · g ⊕ h        (g, h не містять xᵢ)
f|xᵢ=1 = g ⊕ h        f|xᵢ=0 = h
∂f/∂xᵢ = (g ⊕ h) ⊕ h = g
```

Похідна вихоплює g — усі мономи, що містили xᵢ, зі стертою xᵢ. Це буквально формальне диференціювання многочлена в GF(2), де кожна змінна підкоряється xᵢ² = xᵢ: похідна від xᵢ·(щось) — це «щось», а від доданків без xᵢ — нуль. Тому вона **знижує степінь**: кожен уцілілий моном коротшає на змінну, а найдовші, що не містили xᵢ, гинуть, отже deg(∂f/∂xᵢ) ≤ deg f − 1. Це й підтверджує, що степінь — справжній «степінь многочлена»: досить продиференціювати по всіх змінних поспіль, і врешті лишиться самий верхній коефіцієнт:

```
∂/∂x₁ … ∂/∂xₙ f = c_{повна} = парність ваги таблиці
```

Мішана похідна по всіх змінних зчищає з полінома все, крім старшого монома, — і замикає коло: похідна, степінь і формула коефіцієнтів виявляються трьома боками однієї фігури. (Похідна майже слухається правила Ляйбніца: ∂(f·g) має звичні два доданки f·∂g ⊕ g·∂f, але над GF(2) до них додається поправка ∂f·∂g — квадратичний слід характеристики 2, якого в шкільному диференціюванні немає.)

## Що з цього забрати

Уся тема тримається на одному рядку — f(A) = ⊕(c_S : S ⊆ A) — і одній лемі: у ґратці підмножин інтервал [R, S] має 2^|S∖R| вузлів, а за модулем 2 значуща лише парність цього числа, і непарна вона єдино при R = S. З цієї асиметрії одразу випливає формула коефіцієнтів c_S = ⊕(f(T) : T ⊆ S); те саме обчислення, дзеркально, дає інволюцію M² = I — самообернення, що є подарунком характеристики 2, де −1 = +1 стирає знаки звичайного обернення Мебіуса. Явна оберталка робить пару «значення ↔ коефіцієнти» бієкцією, а отже, доводить єдиність полінома напряму — без лічби, яка сама по собі, без існування, єдиності ще не дає. І вже на готовому поліномі проступають дві його власні величини — алгебричний степінь і булева похідна, — що ведуть від завадостійких кодів до стійкості шифрів.
