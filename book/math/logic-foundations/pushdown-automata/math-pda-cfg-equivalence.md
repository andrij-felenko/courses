# 🧮 Граматика ⇄ автомат: конструкція рівносильності

Твердження «магазинні автомати розпізнають рівно контекстно-вільні мови» легко проковтнути як підсумок і піти далі. Але воно дивніше, ніж звучить, і варто спершу здивуватися.

Граматика й автомат працюють у протилежні боки. Граматика **породжує**: бере єдину змінну й вирощує з неї рядок, ні на що не озираючись, — вона нічого не читає, вона пише. Автомат **розпізнає**: йому підсовують готовий рядок, він проходить його зліва направо й каже «так» чи «ні». Один творить із нічого, другий судить готове. Заявити, що ці два пристрої охоплюють ту саму множину рядків, — це заявити, що дві зовсім різні речі якимось дивом збігаються.

Дивом воно не є, і саме тому доведення варте більшої уваги, ніж результат. Рівносильність тут **конструктивна**: не «існує», а пара алгоритмів. Дайте граматику — збудую автомат; дайте автомат — випишу граматику. Обидві побудови короткі, і в кожній є одне місце, де стає видно, ЧОМУ інакше й бути не могло.

### Що саме доводимо

[Контекстно-вільна граматика](book:math/formal-grammar) — це четвірка ⟨V, Σ, P, S⟩: скінченна множина змінних V (вони ж нетермінали), алфавіт терміналів Σ, скінченна множина правил P вигляду `A → γ` (ліворуч рівно одна змінна, праворуч будь-який рядок зі змінних і терміналів) і стартова змінна S. Крок виводу `α ⇒ β` — це заміна однієї змінної на праву частину якогось її правила; мова граматики L(G) = { w ∈ Σ\* : S ⇒\* w } — усе, що вдалося виростити до самих терміналів. Магазинний автомат задають сімкою ⟨Q, Σ, Γ, δ, q₀, Z₀, F⟩, а прийом за порожнім стеком позначмо N(M) = { w : (q₀, w, Z₀) ⊢\* (p, ε, ε) } — слова, дочитавши які машина спорожнила магазин.

Тепер теорема:

```
Для мови L ⊆ Σ* такі твердження рівносильні:

  (1) L = L(G)   для якоїсь контекстно-вільної граматики G;
  (2) L = N(M)   для якогось магазинного автомата M  (прийом за порожнім стеком);
  (3) L = L(M′)  для якогось магазинного автомата M′ (прийом за станом).
```

Працюватимемо з (2): прийом за порожнім стеком тут не забаганка, а суть справи — стек і є той рахунок, який має зійтися. Перехід між (2) і (3) — окрема дрібна вправа, що нічого не додає до головного.

Наскрізний приклад візьмімо найкоротший із небанальних:

```
G:   S → ( S ) S
     S → ε
```

Ця граматика породжує рівно всі збалансовані дужкові рядки: `ε`, `()`, `(())`, `()()`, `(()())`. Два правила — а мова вже не регулярна.

### Ключ: стек — це недороблений вивід

Випишімо **лівий** вивід рядка `()()` — той, де щоразу розгортають найлівішу змінну:

```
S  ⇒  ( S ) S  ⇒  ( ) S  ⇒  ( ) ( S ) S  ⇒  ( ) ( ) S  ⇒  ( ) ( )
```

Придивіться до будь-якого рядка, скажімо до `( ) ( S ) S`. Він сам розпадається надвоє: `()` — суцільні термінали, з ними більше нічого не станеться; `(S)S` — усе, що ще треба розгорнути. Це не випадок, а властивість саме **лівого** виводу: розгортають найлівішу змінну, отже все, що лівіше за неї, уже стало терміналами — і залишиться таким назавжди.

Накладімо цю картину на машину. Термінали ліворуч — це рівно те, що автомат уже **прочитав із входу**. Права частина — те, що він ще **винен**. І тут з'являється єдине питання, від якого залежить усе: у якому порядку цей борг гаситься?

Найлівіша змінна розгортається перша. Замість неї стає рядок γ — і всі зобов'язання з γ треба погасити **раніше** за ті, що вже чекали праворуч. Новий борг лягає **поверх** старого й знімається першим. Це слово в слово означення стека.

Ось і вся таємниця: **стек тримає недороблену частину виводу**, а вершина стека — найлівіший ще не оброблений символ. Сентенційна форма розпадається рівно по головці входу:

```
сентенційна форма  =  прочитаний вхід  ·  вміст стека
                      └─── минуле ───┘    └── майбутнє ──┘
```

Далі побудова вже не потребує вигадливості — вона просто зачитує цей рядок. На вершині може лежати одне з двох. Якщо там **змінна** A — ми винні розгортання: беремо будь-яке правило `A → γ`, міняємо A на γ і входу не чіпаємо. Якщо там **термінал** a — ми винні буквально цей символ: читаємо його з входу, збігся — знімаємо, не збігся — цей прогін мертвий. А коли порожні і вхід, і стек, усі борги погашено.

### Граматика → автомат: розгортай і звіряй

```
Дано G = ⟨V, Σ, P, S⟩. Кладемо

    M = ⟨ {q}, Σ, V ∪ Σ, δ, q, S, ∅ ⟩          прийом — за порожнім стеком

    δ(q, ε, A) = { (q, γ) : (A → γ) ∈ P }      розгортання, для кожної A ∈ V
    δ(q, a, a) = { (q, ε) }                    звірка,      для кожного a ∈ Σ
```

Прочитаймо сімку повільно, бо в ній є несподіванка. Q = {q} — стан **один**. Γ = V ∪ Σ — алфавіт стека є весь словник граматики, разом із терміналами. Z₀ = S — початковий борг є стартова змінна. F = ∅ — приймальних станів не треба взагалі.

Несподіванка в тому, що скінченне керування — те, чим магазинний автомат відрізняється від голого стека, — тут **порожнє**. Воно не пам'ятає нічого й ніколи. Граматика не закодована в станах; вона лежить **на стеку** у вигляді шматків сентенційних форм, а машина — лише механізм, що обслуговує борг. Для нашої G це три рядки:

```
M = ⟨ {q}, {(, )}, {S, (, )}, δ, q, S, ∅ ⟩

δ(q, ε, S) = { (q, "(S)S"), (q, ε) }     ← два правила = два здогади
δ(q, (, () = { (q, ε) }
δ(q, ), )) = { (q, ε) }
```

**Прогін на вході `()()`.** Миттєвий опис — це трійка (стан, що лишилось на вході, стек); вершину пишемо ліворуч.

```
крок    вхід      стек     дія
  0     ()()      S        старт: увесь борг — на стеку
  1     ()()      (S)S     розгортання  S → ( S ) S      ← здогад
  2      )()      S)S      звірка «(» — pop
  3      )()      )S       розгортання  S → ε            ← здогад
  4       ()      S        звірка «)» — pop
  5       ()      (S)S     розгортання  S → ( S ) S      ← здогад
  6        )      S)S      звірка «(» — pop
  7        )      )S       розгортання  S → ε            ← здогад
  8        ε      S        звірка «)» — pop
  9        ε      ε        розгортання  S → ε            ← здогад
                           вхід порожній + стек порожній → ПРИЙОМ
```

Тепер прочитайте самі лише рядки-розгортання, згори вниз:

```
S → ( S ) S ,   S → ε ,   S → ( S ) S ,   S → ε ,   S → ε
```

І порівняйте з лівим виводом, що ми виписали для цього самого рядка. Той самий список правил, у тому самому порядку. Прогін автомата не «відповідає» виводу й не «моделює» його — прогін автомата **і є** вивід, лише розказаний з іншого краю: граматика його пише, автомат зачитує вголос, звіряючи з входом. А звірки — це ті кроки, де вивід стоїть на місці, а рухається головка.

![Десять знімків прогону низхідного автомата на вході «()()»: у кожному рядку сірі клітини — прочитаний вхід, сині — вміст стека, червона риска — головка між ними](/book/math/logic-foundations/pushdown-automata/img/cfg-pda-derivation.svg)
*Прогін низхідного автомата за граматикою S → ( S ) S | ε. Кожен рядок, прочитаний зліва направо, — це поточна сентенційна форма лівого виводу, розрізана головкою на прочитане (сіре) і борг на стеку (синє). Сині кроки міняють форму — це і є кроки виводу; сірі лише посувають головку, не змінюючи нічого. Тому п'ять синіх рядків, узяті підряд, дають рівно лівий вивід рядка «()()».*

> 🔧 **Навіщо це.** Ось чому рекурсивний спуск виглядає так, наче його не писали, а списали з граматики: одна функція на змінну, виклик на кожен нетермінал у правій частині, звірка на кожен термінал. Це не стиль і не збіг — це та сама побудова, у якій роль стека грає стек викликів. Побачивши це, ви перестанете гадати, як «перекласти» BNF у код: переклад тут механічний, а думати треба лише там, де в машині лишається здогад.

**Чому це правильно.** Доведення пише себе саме, бо весь зміст сидить в одному інваріанті. Нехай α — уже прочитана частина входу, β — вміст стека. Тоді на кожному кроці прогону

```
S  ⇒*лів  α β
```

тобто «прочитане · стек» — завжди сентенційна форма лівого виводу. Звіримо з таблицею: крок 5 — прочитано `()`, на стеку `(S)S`, разом `()(S)S`; крок 8 — `()()` і `S`, разом `()()S`. Обидві форми стоять у лівому виводі, який ми виписали, — і так на кожному кроці, без винятків. Цей збіг і є теорема.

Доводять [індукцією](book:math/mathematical-induction) за числом кроків: перевіряють базу, а тоді показують, що кожен крок зберігає властивість, — і вона автоматично тримається на всьому прогоні, хай яким довгим. База тут задарма: 0 кроків, α = ε, β = S, і справді S ⇒\*лів S за нуль кроків. Крок розбирають за видом переходу, а їх лише два. **Розгортання**: β = Aβ′, машина міняє його на γβ′; за припущенням S ⇒\*лів αAβ′, а правило A → γ дає S ⇒\*лів αγβ′ — і законним кроком саме **лівого** виводу це є через те, що A найлівіша змінна: усе в α — термінали. **Звірка**: β = aβ′, на вході a; α стає αa, β стає β′, а добуток αβ не змінився взагалі — розріз просто переїхав на символ праворуч. Обидва випадки інваріант зберігають.

Звідси обидва боки теореми. Якщо машина прийняла w, то наприкінці α = w і β = ε, отже S ⇒\*лів w — граматика породжує w. Навпаки: маємо вивід S ⇒\*лів w, читаємо його як список здогадів — на кожен застосований крок у δ за побудовою є розгортання, а звірки додаються самі, щойно на вершину виходить термінал; прогін дійде до порожнього стека. Це та сама індукція, лише за довжиною виводу.

**Про здогади.** У δ(q, ε, S) стоять дві пари, і машина вибирає навмання. Це не недбальство побудови: правило залежить від того, що на вході **далі**, а машина туди ще не дивилася. Забрати здогад — означає зажадати, щоб правило вгадувалося з вершини стека й одного поточного символа; граматики, де це вдається, — окремий, вужчий клас, і саме з нього ростуть LL-парсери. Теорему ж заявлено про **недетермінований** автомат, і не з ліні: детермінований бере строго менше.

**Одна пляма.** Розгортання йдуть по ε, тобто входу не рухають, і правило `A → A` закрутить машину назавжди. Теореми це не ламає (питання в тому, чи **існує** приймальний прогін, а не чи всі скінченні), але враження чесності псує. Латка красива: **нормальна форма Ґрейбах** — вигляд, у якому кожне правило починається з термінала, `A → a A₁ A₂ … A_k` (Шейла Ґрейбах, *Journal of the ACM*, 1965). До нього зводять будь-яку контекстно-вільну граматику, чия мова не містить порожнього слова; наша містить, тож для `S → ( S ) S | ε` довелося б окремо дозволити єдине правило `S → ε` — звичайна для цієї форми поступка. Зате тоді розгортання й звірку зливають в один крок, що **обов'язково з'їдає символ входу**:

```
δ(q, a, A) ∋ (q, A₁A₂…A_k)      для кожного правила  A → a A₁A₂…A_k
```

На стеку тепер живуть самі змінні, а прогін на слові довжини n має рівно n кроків: автомат стає **реального часу**. Ціна — переробка граматики; зиск — доведення без холостих обертів.

### Той самий міст із другого кінця: зсув і згортка

Ми клали на стек **майбутнє** — те, що винні. А що як класти **минуле** — те, що вже зібрали?

Машина тоді працює навпаки. Вона **зсуває** (shift) черговий символ входу на стек, просто складаючи прочитане. А коли на вершині назбирався рядок, що дослівно збігся з правою частиною якогось правила `A → γ`, вона може його **згорнути** (reduce): зняти γ і покласти натомість A. Прийом — коли вхід дочитано, а на стеку лишилося рівно S.

Формальна дрібниця, яку варто вимовити вголос: справжня δ бачить лише **один** символ вершини, тож «зняти цілий рядок γ» — це макрокрок, тобто |γ| послідовних pop-ів через ланцюжок допоміжних станів, які пам'ятають, скільки вже знято. Керування тут уже не порожнє — на відміну від низхідного автомата, цьому стани потрібні. Але їх скінченне число (по одному на позицію в кожному правилі), тож це чесний магазинний автомат.

Прогін на тому самому `()()`; стек пишемо дном ліворуч — так він читається як зібраний префікс:

```
крок    стек        вхід    дія
  0     ε           ()()    старт
  1     (            )()    зсув «(»
  2     (S           )()    згортка  S → ε          ← здогад: тут порожня група
  3     (S)           ()    зсув «)»
  4     (S)(           )    зсув «(»
  5     (S)(S          )    згортка  S → ε          ← здогад
  6     (S)(S)         ε    зсув «)»
  7     (S)(S)S        ε    згортка  S → ε          ← здогад
  8     (S)S           ε    згортка  S → ( S ) S    ← згорнули хвіст «( S ) S»
  9     S              ε    згортка  S → ( S ) S
                            вхід порожній + на стеку лише S → ПРИЙОМ
```

Знову прочитайте самі згортки — але цього разу **знизу вгору**:

```
S → ( S ) S ,   S → ( S ) S ,   S → ε ,   S → ε ,   S → ε
```

Це **правий** вивід того самого рядка:

```
S  ⇒  ( S ) S  ⇒  ( S ) ( S ) S  ⇒  ( S ) ( S )  ⇒  ( S ) ( )  ⇒  ( ) ( )
```

Зсув-згортка — це правий вивід, прокручений назад. Машина виводу не будує, вона його **розбирає**, знімаючи по правилу з кінця.

І тепер місток, який показує, що це не два трюки, а один. Інваріант низхідного автомата ми вже знаємо. У висхідного він дзеркальний:

```
низхідний:   прочитане  ·  СТЕК         =  ліва  сентенційна форма
висхідний:   СТЕК       ·  недочитане   =  права сентенційна форма
```

Перевірте на кроці 5: на стеку `(S)(S`, на вході `)`, разом `(S)(S)` — і саме ця форма стоїть у правому виводі, який ми щойно виписали. Обидві машини тримають на стеку **половину сентенційної форми**, розрізаної рівно по головці входу. Різниця лише в тому, **яку** половину: низхідний стереже правий шматок (борг), висхідний — лівий (набуток). Звідси й береться «лівий проти правого виводу» — це не окремий факт, який треба запам'ятовувати, а прямий наслідок вибору половини.

Здогад потрібен обом, висхідному навіть подвійний: коли згортати і яке правило брати. Гляньте на крок 2 — машина згортає **порожнечу** в S, не прочитавши нічого, суто з віри, що тут почнеться група. Прибирання цих здогадів поглядом наперед і дає родину LR-парсерів, на якій стоять генератори на кшталт yacc і bison. Теоремі ж здогад не заважає: вона про недетермінований автомат.

### Автомат → граматика: змінна-трійка

Тепер важчий бік — і той, де конструкція справді дивує.

Маємо машину, треба вигадати правила. Заковика не в техніці, а в тому, що незрозуміло, з чого починати. Змінна граматики породжує **множину рядків**, отже всередині поведінки автомата треба намацати якусь одиницю роботи, чия множина прочитаних слів природно рекурсивна. Стани не годяться — вони рядків не породжують. Символи стека самі по собі теж.

Ключ — у тому, що робить стек стеком. **Символ, покладений на стек, рано чи пізно з нього зійде, а поки лежить — усе під ним недоторканне.** Не «його не чіпають з делікатності», а буквально: щоб дістатися нижчого символа, треба спершу зняти цей. Доступ лише з вершини — це не обмеження, це **гарантія ізоляції**.

Отже, життя машини саме розпадається на **епізоди**: на вершині лежить X, машина в стані q… далі вона робить що завгодно, скільки завгодно, як завгодно глибоко… аж поки рівень повертається під X, а машина опиняється в стані p. Усе, що діялося всередині епізоду, **не залежить** від того, що лежить під X, — бо туди не заглядали. Тому епізод самодостатній: він визначається трійкою (q, X, p) і більше нічим.

Самодостатній і повторюваний шматок — це рівно те, чим є змінна граматики. Оголошуємо:

```
[q X p]  ⇒*  усі слова w, читаючи які автомат
             зі стану q знімає зі стека рівно один символ X
             (жодного разу не зазирнувши під нього)
             і опиняється в стані p
```

Дужки — частина імені: `[q X p]` це **одна** змінна, а не три.

**Чому трійка, а не пара?** Питання не риторичне — тут увесь трюк. Здавалось би, епізод задає пара (q, X): звідки почали й що знімаємо. Але епізоди доводиться **склеювати**: наступний починається там, де скінчився попередній. Отже, треба знати, **де саме** машина з епізоду вийшла, — а стан виходу з (q, X) не випливає: автомат недетермінований, той самий X із того самого q можна зняти різними прогонами й опинитися в різних станах. Стан виходу мусимо **вгадати наперед і записати в ім'я змінної**. Тому змінних |Q|²·|Γ| — квадрат від числа станів. Уся ціна цього доведення схована в одному слові «склеювати».

> 🔧 **Навіщо це.** Прийом «поклади обидва кінці в ім'я шматка» — не місцева хитрість, а стандартний хід скрізь, де ціле збирають зі шматків, а шматки треба стикувати. Він упізнається одразу: щойно бачите квадрат від числа станів у розмірі результату — знайте, що всередині вгадують і записують точку стику.

Тепер правила виписуються з δ майже механічно.

**Випадок 1: X знімають одразу.** Нехай δ(q, a, X) ∋ (r, ε) — прочитали a (можливо, a = ε) і вершину прибрали. Епізод скінчився за один крок, і слово епізоду є саме a:

```
[q X r] → a
```

Це база рекурсії — тут і лише тут з'являються термінали.

**Випадок 2: X замінюють на рядок.** Нехай δ(q, a, X) ∋ (r, Y₁Y₂…Y_k). X зник із вершини, але рівень **не** повернувся: на його місці стоять k нових символів, і борг перейшов до них. Щоб рівень опустився під X, доведеться зняти всі Y₁…Y_k — по черзі згори: Y₁ на вершині, під ним Y₂, і так далі. Отже, машина зі стану r знімає Y₁ і опиняється в якомусь стані s₁; звідти знімає Y₂ і опиняється в s₂; … нарешті знімає Y_k і опиняється в s_k — а це і є вихід із епізоду X.

Кожне таке зняття — сам по собі епізод, тобто вже названа змінна. А проміжні стани s₁…s_{k−1} нам невідомі. Виходу нема: пишемо правило на **кожен** можливий набір здогадів.

```
[q X s_k] → a [r Y₁ s₁] [s₁ Y₂ s₂] … [s_{k−1} Y_k s_k]

для всіх s₁, s₂, …, s_k ∈ Q          (|Q|^k правил на один перехід)
```

Придивіться до індексів — у них уся конструкція. Кінець одного епізоду є початок наступного: s₁ стоїть виходом у першої дужки й входом у другої, s₂ — виходом у другої й входом у третьої. Доміно. Кінці зчеплені, і саме тому склейка не бреше: граматика фізично не здатна зшити два епізоди, що не стикуються станами. Здогади, які не збіжаться, просто дадуть змінні, з яких нічого не виводиться.

Лишається старт. Прийом за порожнім стеком — це «зняли Z₀ з дна», а де машина при цьому опинилася, нам байдуже:

```
S → [q₀ Z₀ p]        для кожного p ∈ Q
```

![Графік висоти стека в часі: епізод символа X від його появи на вершині в стані q до повернення рівня під нього в стані p, із замороженим шаром під X і двома вкладеними епізодами Y₁ та Y₂](/book/math/logic-foundations/pushdown-automata/img/cfg-pda-episode.svg)
*Епізод одного символа стека. Поки X лежить, висота не спадає під його рівень — сірий шар заморожений, автомат туди не заглядає, і тому все, що діється всередині, залежить лише від (q, X, p). Перехід δ(q, a, X) ∋ (r, Y₁Y₂) розбиває епізод X на два менші — епізоди Y₁ і Y₂, — а стани на межах зчеплені доміно: s₁ є виходом першого й водночас входом другого. Саме ця зчепленість і змушує тримати обидва кінці в імені змінної.*

**Наскрізний приклад: із машини назад у граматику.** Візьмімо магазинний автомат для збалансованих дужок — не виведений із граматики, а зроблений руками, як його написала б людина:

```
M = ⟨ {q, f}, {(, )}, {Z₀, X}, δ, q, Z₀, ∅ ⟩       прийом за порожнім стеком

(1)  δ(q, (, Z₀) = { (q, X Z₀) }     відкрили дужку на дні — кладемо фішку
(2)  δ(q, (, X)  = { (q, X X)  }     відкрили ще одну — ще фішку
(3)  δ(q, ), X)  = { (q, ε)    }     закрили — знімаємо фішку
(4)  δ(q, ε, Z₀) = { (f, ε)    }     дно оголилося — прибираємо його: кінець
```

Два стани, два символи стека — отже, змінних |Q|²·|Γ| = 4·2 = 8, плюс стартова. Виписуємо:

```
S         → [q Z₀ q] | [q Z₀ f]                старт: по правилу на кожен p

з (1):    [q Z₀ s₂] → ( [q X s₁] [s₁ Z₀ s₂]    4 правила:  s₁, s₂ ∈ {q, f}
з (2):    [q X s₂]  → ( [q X s₁] [s₁ X s₂]     4 правила
з (3):    [q X q]   → )                        база
з (4):    [q Z₀ f]  → ε                        база
```

Дванадцять правил. Тепер приберімо мертве — і тут добре видно, що трійка справді щось міряє, а не просто роздуває запис.

Зі стану `f` не виходить **жодного** переходу. А правила народжуються саме з переходів — отже, жодна змінна вигляду `[f Y p]` не має лівої частини взагалі: з неї не виводиться нічого. Далі `[q X f]`: база для неї мала б узятися з переходу, що знімає X і приземляється в `f`, — а правило (3) приземляється в `q`. Рекурсивні ж правила `[q X f] → ( [q X s₁][s₁ X f]` щоразу знову потребують `[q X f]` або мертвої `[f X f]`. Дна нема — змінна порожня. Так само `[q Z₀ q]`: єдиний перехід, що знімає Z₀, веде в `f`, а не в `q`. Живими лишаються рівно три:

```
S         → [q Z₀ f]
[q Z₀ f]  → ε  |  ( [q X q] [q Z₀ f]
[q X q]   → )  |  ( [q X q] [q X q]
```

Перейменуймо `[q Z₀ f]` на S (правило `S → [q Z₀ f]` — просто синонім), а `[q X q]` на B:

```
S → ε  |  ( B S
B → )  |  ( B B
```

Перевіримо на `()()`:  S ⇒ ( B S ⇒ ( ) S ⇒ ( ) ( B S ⇒ ( ) ( ) S ⇒ ( ) ( ). Працює.

І ось найцікавіше. Вирушили ми від `S → ( S ) S | ε`, а повернулися з чимось іншим. Мова та сама, запис інший. Звідки взялася зайва змінна B і що вона означає?

За означенням `B = [q X q]` — це слова, читаючи які машина знімає рівно одну фішку X. А фішку кладуть на `(` і знімають на парній `)`. Отже, B — це все, що діється **від відкритої дужки до її закриття, разом із самою закривною дужкою**:

```
B  =  { u )  :  u — збалансований рядок }
```

Тобто B є буквально фрагмент «S )» вихідної граматики. Підставмо назад:

```
B ≡ S )

B → )         стає   S ) → )            тобто   S → ε          ✓
B → ( B B     стає   S ) → ( S ) S )    тобто   S → ( S ) S    ✓
S → ( B S     стає   S → ( S ) S                               ✓
```

Це та сама граматика — з «S )» під одним іменем. Коло замкнулося.

А чому машинна граматика порізана саме так, а не по дужкових групах? Бо машина ріже по **епізодах стека**, а епізод фішки X починається **після** того, як `(` прочитано (фішку кладуть уже за нею), і закінчується на `)`. Тому природна одиниця для машини — це «S )», а не «( S )». Граматика, здобута з автомата, чесно розповідає, як автомат бачить світ, — а бачить він його зсунутим на одну дужку.

**Санітарна перевірка й ціна.** Візьміть той низхідний автомат, що ми будували з граматики, і проженіть його через ту саму трійкову конструкцію. Стан у нього один, тож вибору для s-ів нема взагалі: `[q A q]` на кожну змінну A і `[q a q]` на кожен термінал a. З `δ(q, a, a) = {(q, ε)}` виходить `[q a q] → a`; з `δ(q, ε, A) ∋ (q, Y₁…Y_k)` — `[q A q] → [q Y₁ q] … [q Y_k q]`. Перейменуйте `[q A q]` на A, `[q a q]` на a — і перед вами дослівно вихідна граматика. При |Q| = 1 трійка вироджується сама в себе; вона потрібна рівно настільки, наскільки в машині є стани.

Ціна теж на видноті. Змінних — |Q|²·|Γ|; правил на один перехід, що кладе k символів, — |Q|^k. Для нашої іграшки це 12 правил, з яких вижило 5. Для машини на сотню станів — мільйони, і майже всі мертві. Тому трійкова конструкція є **знаряддя доведення, а не інструмент компілятора**: вона доводить, що граматика існує, а не видає граматику, яку захочеться читати. На практиці по ній проганяють обхід досяжності й викидають мертві змінні — рівно те, що ми щойно зробили руками.

### Двійник теореми Кліні — на сходинку вище

Відступімо на крок і подивімося, що ми, власне, зробили двічі.

Щаблем нижче в [ієрархії](book:math/chomsky-hierarchy) — драбині класів мов за силою потрібної пам'яті — стоїть така сама пара й така сама теорема. [Регулярні мови](book:math/regular-languages) мають два обличчя: формулу (регулярний вираз) і машину ([скінченний автомат](book:math/finite-automata) — п'ятірка ⟨Q, Σ, δ, q₀, F⟩, пам'ять якої вичерпується поточним станом). Те, що обидва описують рівно один клас, — теорема Кліні. Стівен Кліні виклав її 1951 року в меморандумі RAND RM-704 «Representation of events in nerve nets and finite automata»; сам термін «регулярний вираз» у тому меморандумі ще не звучить — він з'являється у друкованій версії 1956-го, у збірнику *Automata Studies*.

Порівняймо не гасла, а самі доведення.

**Легкий бік — формула в машину.** У Кліні автомат збирають із виразу покомпонентно: по гаджету на кожен оператор, склейка через ε-переходи. У нас автомат збирають із граматики по переходу на правило, склейка через ε-розгортання. Обидві побудови **синтаксично керовані** — форма машини повторює форму формули, розмір лінійний. Прийом той самий.

**Важкий бік — машина у формулу.** І ось де збіг перестає бути випадковим. Кліні будує сходинку виразів

```
Rᵏᵢⱼ  =  слова, що ведуть машину зі стану i в стан j,
         проходячи проміжними лише через стани з номерами ≤ k
```

за рекурсією

```
Rᵏᵢⱼ  =  Rᵏ⁻¹ᵢⱼ  ∪  Rᵏ⁻¹ᵢₖ · (Rᵏ⁻¹ₖₖ)* · Rᵏ⁻¹ₖⱼ
```

Погляньте на індекси. **Пара станів (i, j) — вхід і вихід.** Точнісінько як у `[q X p]`. І з тієї самої причини: шматки треба склеювати, а склейка законна лише тоді, коли вихід одного збігається з входом наступного, — отже, обидва кінці мусять стояти в імені. Квадратичний роздув по |Q| — теж той самий і теж звідти.

Різниця сидить рівно в **третьому індексі**, і в ній увесь поверх.

```
Кліні:   третій індекс — k, СТЕЛЯ на проміжні стани.
         Рекурсія лізе вниз по k і впирається в k = 0.
         Скінченна драбина → рекурсію розгортають → скінченна формула.

Тут:     третій індекс — X, символ стека.
         Рекурсія лізе вниз по вкладеності епізодів — а стелі їй НЕМА.
         Розгортати нíчим → рекурсія і є відповідь: граматика.
```

Ось і весь підйом на сходинку. Не «стек сильніший за стан», а: **у Кліні третій індекс скінченно спадає, тож рекурсію можна розкрутити до кінця й записати відповіддю; тут розкручувати нíчим, і рекурсія лишається відповіддю**.

**Те саме алгеброю — і тут воно вже зовсім голе.** Граматику можна читати не як правила, а як **систему рівнянь** над мовами: `|` це об'єднання, сусідство — склейка.

```
праволінійна (регулярна) граматика   →   рівняння ЛІНІЙНІ:
     X = A·X ∪ B              (змінна входить у кожен доданок не більше разу)

контекстно-вільна граматика          →   рівняння КВАДРАТНІ:
     S = { ( }·S·{ ) }·S ∪ { ε }     (S у першому доданку двічі — це добуток)
```

Лінійне рівняння **розв'язується**. Правило Ардена (Дін Арден, «Delayed Logic and Finite State Machines», жовтень 1961) каже: найменший розв'язок `X = A·X ∪ B` — це `X = A*·B`, і він єдиний, коли ε ∉ A. Розв'язуючи змінні одну за одною, систему згортають у замкнену формулу над {∪, ·, \*} — а це і є регулярний вираз. Ось звідки береться зірка: **зірка — це розв'язок лінійного рівняння**.

Квадратне рівняння в цих операціях **не розв'язується**. У `S = (S)S ∪ ε` змінна стоїть у добутку двічі, і винести її нíяк — Арден не бере. Замкненого вигляду над {∪, ·, \*} тут і не може бути: якби він був, мова була б регулярна, а вона не регулярна. Сама мова, звісно, існує — це найменша нерухома точка системи (погляд, що його виклали Ноам Хомський і Марсель-Поль Шютценберже 1963 року в «The algebraic theory of context-free languages»), — але записати її можна лише самою системою. Тобто граматикою.

Отже, «на сходинку вище» має точний зміст: **лінійні рівняння → квадратні**. Тому на регулярному щаблі є регулярний вираз, а на контекстно-вільному жодного «контекстно-вільного виразу» в ужитку нема — і не тому, що не додумалися, а тому, що формулою відповідь не записується. Граматика і є формула цього поверху.

**І ще один спосіб побачити той самий щабель.** Візьміть праволінійну граматику (правила `A → aB`, `A → a`, `A → ε`) і проженіть її через нашу низхідну побудову. Стек починає з `S`; розгортання `S → aB` кладе `aB`; звірка знімає `a`; лишається `B`. Далі те саме. На стеку **завжди рівно одна змінна** — і ніколи більше. А одна комірка зі скінченного алфавіту це і є скінченний стан.

Так ось чим виявляється скінченний автомат: це магазинний автомат, у якого стек ніколи не тримає більше за одну змінну. Теорема Кліні — це наша теорема з обмеженим стеком.

*Два щаблі, одна будова доведення. Легкий бік обох теорем — синтаксично керована побудова машини за формулою. Важкий бік обох — шматок, названий парою станів «вхід-вихід», бо шматки треба стикувати; звідси й однаковий квадратичний роздув. Різниця одна: третій індекс у Кліні (стеля k на проміжні стани) скінченно спадає, тож рекурсія згортається у формулу з зіркою, а третій індекс тут (символ стека) стелі не має — і рекурсія лишається відповіддю.*

### Де це працює

**Генератори парсерів існують саме завдяки цій теоремі.** Ви пишете граматику, бо людині зручно **писати правила**; yacc, bison чи ANTLR будують автомат, бо машині зручно **виконувати розпізнавання**. Обидві наші побудови — скелети двох родин: розгортай-і-звіряй є рекурсивний спуск і LL, зсув-і-згортка є LR. Варто пам'ятати й те, чого теорема **не** дає задарма: вона будує **недетермінований** автомат. Уся інженерія парсер-генератора — у прибиранні здогаду поглядом наперед, і рівно там живе славнозвісна відмова «конфлікт зсув/згортка»: це генератор каже, що на цій граматиці здогад прибрати не вдалося.

**Два обличчя — це вибір зручнішого для кожного доведення.** Найпрактичніша вигода з рівносильності, і вона щодня економить роботу. Треба довести, що перетин контекстно-вільної мови з регулярною знову контекстно-вільний? Через **автомат** це кілька рядків: беремо добуток магазинного автомата зі скінченним — стан стає парою станів, а стек лишається один, отже це знову магазинний автомат. Через граматику — мука. Треба довести, що якась мова **не** контекстно-вільна? Через **граматику**: досить довгий рядок мусить мати високе дерево виводу, на якомусь шляху змінна повториться, а повтор можна накачувати. Через автомат — мука. Теорема дозволяє щоразу заходити з того обличчя, з якого задача виглядає легкою.

**Розв'язність.** Питання «чи порожня мова цієї машини?» і «чи належить їй слово w?» відповідають через граматику — обходом досяжності й алгоритмом CYK відповідно, — а трійкова конструкція є той міст, яким туди переходять. Тим самим мостом ходить і статичний аналіз програм: рекурсивна програма — це магазинна система, і питання про досяжність її станів зводять до питання про контекстно-вільну мову.

Підсумуймо суцільно. Граматика й автомат дивляться в різні боки — одна пише, другий читає, — і все ж окреслюють рівно один клас мов, бо між ними стоїть один-єдиний факт: **вивід є вкладена структура, а стек є пам'ять рівно на вкладеність**. Звідси обидві побудови. Уперед: стек тримає недороблену частину виводу, розгортання є крок виводу, звірка є прочитаний символ, і прогін автомата з лівим виводом — це той самий об'єкт із двох боків; а якщо класти на стек не борг, а набуток, дістанемо зсув-згортку й правий вивід — та сама сентенційна форма, лише розрізана з іншого краю. Назад: доступ лише з вершини робить життя кожного символа стека самодостатнім епізодом, епізод є змінна `[q X p]`, і обидва кінці стоять в її імені тому, що склеювати можна лише збіжні стани. Обидві побудови точно повторюють доведення теореми Кліні щаблем нижче — аж до квадратичного роздуву по станах, — і різняться в одному: там третій індекс має стелю, тож рекурсію розгортають у формулу, а тут стелі нема, тож рекурсія лишається відповіддю. Алгебраїчно це «лінійні рівняння проти квадратних»: зірка є розв'язок лінійного, для квадратного розв'язку в зірках нема, і граматика записує сама себе. Тому парсер-генератор узагалі може існувати, тому кожне доведення про контекстно-вільні мови беруть із зручнішого обличчя — і тому «граматика ⇄ автомат» це не декорація підручника, а робочий міст, яким ходять щодня.
