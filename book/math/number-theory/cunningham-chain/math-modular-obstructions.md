# 🧮 Математичний вивід модулярних перешкод та константи Бейтмана — Горна

У цій вставці наведено повний алгебраїчний вивід модулярних конгруенцій, що визначають періодичність діленості членів ланцюжка Каннінгема на малі прості числа, доведення теореми про локальні модулярні перешкоди, а також математичний розрахунок константи Бейтмана — Горна для асимптотичної щільності розподілу.

## 1. Загальна формула n-го члена ланцюжка першого роду

Розглянемо рекурентне співвідношення для ланцюжка Каннінгема 1-го роду, у якому кожний наступний член обчислюється через попередній за правило подвоєння зі збільшенням на одиницю. Починаючи з початкового простого числа `p₁`, послідовні члени мають вигляд:

```
p₁ = p
p₂ = 2p₁ + 1
p₃ = 2p₂ + 1 = 2(2p₁ + 1) + 1 = 4p₁ + 3
p₄ = 2p₃ + 1 = 2(4p₁ + 3) + 1 = 8p₁ + 7
```

Застосовуючи метод математичної індукції, виведемо загальний вираз для `i`-го члена ланцюжка `pᵢ` при `1 ≤ i ≤ k`:

```
pᵢ = 2ⁱ⁻¹ · p₁ + (2ⁱ⁻¹ - 1)
```

Для подальшого алгебраїчного аналізу зручно перегрупувати цей вираз, додавши та віднявши одиницю у правому доданку:

```
pᵢ = 2ⁱ⁻¹ · p₁ + 2ⁱ⁻¹ - 1
   = 2ⁱ⁻¹ · (p₁ + 1) - 1
```

Отримане канонічне вираження `pᵢ = 2ⁱ⁻¹(p₁ + 1) - 1` показує, що значення будь-якого члена ланцюжка повністю визначається величиною `(p₁ + 1)` та відповідним степенем двійки `2ⁱ⁻¹`. Ця формула є фундаментальною для дослідження порівнянь за довільним простим модулем `q`.

## 2. Алгебраїчний аналіз порівнянь за простим модулем q

Нехай `q` — непарне просте число (`q > 2`). Дослідимо остачу від ділення `i`-го члена `pᵢ` на `q`. Застосовуючи канонічну формулу, отримуємо порівняння:

```
pᵢ ≡ 2ⁱ⁻¹ · (p₁ + 1) - 1 (mod q)
```

Розглянемо дві фундаментально відмінні ситуації для вибору остачі початкового числа `p₁ mod q`:

### Випадок А: Початкова остача p₁ ≡ -1 (mod q)

Якщо початкове число `p₁` задовольняє порівняння `p₁ ≡ -1 (mod q)` (що еквівалентно умові `p₁ + 1 ≡ 0 (mod q)`), то при підстановці у канонічний вираз маємо для будь-якого індексу `i`:

```
pᵢ ≡ 2ⁱ⁻¹ · (0) - 1 ≡ -1 ≡ q - 1 (mod q)
```

Оскільки модуль `q` є непарним простим числом (`q ≥ 3`), остача `q - 1` суворо більша за нуль (`q - 1 ≥ 2`). Це доводить важливу теорему: **якщо початковий член p₁ задовольняє конгруенцію p₁ ≡ -1 (mod q), то жоден член ланцюжка pᵢ не ділиться на q**. Клас остач `p₁ ≡ -1 (mod q)` створює так званий «модулярний захисний бар'єр», який повністю усуває діленість послідовності на просте число `q`.

### Випадок Б: Початкова остача p₁ + 1 ≢ 0 (mod q)

Якщо значення `p₁ + 1` не ділиться на `q`, то в кільці остач за модулем `q` існує мультиплікативно обернений елемент `(p₁ + 1)⁻¹ mod q`. Знайдемо умови, за яких член `pᵢ` ділиться на `q` (тобто `pᵢ ≡ 0 (mod q)`):

```
2ⁱ⁻¹ · (p₁ + 1) - 1 ≡ 0 (mod q)
2ⁱ⁻¹ · (p₁ + 1) ≡ 1 (mod q)
2ⁱ⁻¹ ≡ (p₁ + 1)⁻¹ (mod q)
```

Позначимо через `d = ord_q(2)` мультиплікативний порядок числа 2 за модулем `q` (тобто найменше натуральне число `d`, для якого `2ᵈ ≡ 1 (mod q)`). За малою теоремою Ферма порядок `d` завжди є дільником числа `q - 1`.

Послідовність степенів двійки `2⁰, 2¹, 2², ..., 2ⁱ⁻¹ mod q` утворює циклічну підгрупу `⟨2⟩` порядку `d` у мультиплікативній групі остач `(Z / qZ)*`. Розглянемо наслідки цього для діленості членів:

1. Якщо величина `(p₁ + 1)⁻¹ mod q` належить до циклічної підгрупи `⟨2⟩`, то в межах кожної послідовної групи з `d` членів ланцюжка **рівно один член обов'язково ділиться на `q`**. Якщо цей член перевищує `q`, він є складеним числом, і ланцюжок простоти переривається.
2. Якщо величина `(p₁ + 1)⁻¹ mod q` не належить до підгрупи `⟨2⟩`, то рівняння не має розв'язків, і жоден член ланцюжка не ділиться на `q`.

## 3. Детальний аналіз модулярних перешкод для малих простих модулів

Розглянемо конкретні значення малих простих модулів, які виступають головними «фільтрами» при побудові ланцюжків Каннінгема.

### Аналіз для модуля q = 3
Для числа 3 маємо `2¹ ≡ 2 (mod 3)` та `2² ≡ 1 (mod 3)`. Порядок дорівнює `d = ord₃(2) = 2`. Циклічна підгрупа `⟨2⟩ = {1, 2}` покриває геть усі ненульові остачі за модулем 3.
- Якщо `p₁ ≡ 1 (mod 3)`, то `p₁ + 1 ≡ 2 (mod 3)`. Його обернений елемент `(2)⁻¹ ≡ 2 (mod 3)`. Рівняння `2ⁱ⁻¹ ≡ 2 (mod 3)` має розв'язок при `i = 2` (бо `2¹ = 2`). Це означає, що другий член `p₂` обов'язково ділиться на 3. Якщо `p₁ > 3`, число `p₂` є складеним.
- Якщо `p₁ ≡ 2 ≡ -1 (mod 3)`, то `pᵢ ≡ 2 (mod 3)` для всіх `i`. Жоден член не ділиться на 3.

**Висновок:** Для побудови будь-якого ланцюжка Каннінгема 1-го роду довжини `k ≥ 2` (зі стартовим числом `p₁ > 3`) початковий член зобов'язаний задовольняти порівняння:
```
p₁ ≡ 2 ≡ -1 (mod 3)
```

### Аналіз для модуля q = 5
Для числа 5 обчислимо степені двійки: `2¹=2, 2²=4, 2³=3, 2⁴=1 (mod 5)`. Порядок дорівнює `d = ord₅(2) = 4`. Циклічна підгрупа `⟨2⟩ = {1, 2, 3, 4}` охоплює всі ненульові остачі за модулем 5.
- Якщо `p₁ ≢ 4 (mod 5)` (тобто `p₁ + 1 ≢ 0`), то значення `(p₁ + 1)⁻¹ mod 5` гарантовано належить до підгрупи `⟨2⟩`. Це означає, що **з кожних чотирьох послідовних членів ланцюжка рівно один член ділиться на 5**.
- Отже, якщо `p₁ ≢ 4 (mod 5)` і `p₁ > 5`, довжина ланцюжка **не може перевищувати 4** (`k ≤ 4`).
- Для побудови ланцюжків довжини `k ≥ 5` необхідне дотримання конгруенції:
```
p₁ ≡ 4 ≡ -1 (mod 5)
```

### Аналіз для модуля q = 7
Для числа 7 степені двійки дорівнюють: `2¹=2, 2²=4, 2³=1 (mod 7)`. Порядок дорівнює `d = ord₇(2) = 3`. Циклічна підгрупа `⟨2⟩ = {1, 2, 4}` складається з трьох елементів (квадратичних лишків mod 7).
- Нелишки за модулем 7 складають множину `{3, 5, 6}`.
- Якщо `p₁ ≡ 6 (mod 7)` (`p₁ ≡ -1`), то `p₁ + 1 ≡ 0`, і жоден член не ділиться на 7.
- Якщо `p₁ ≡ 2, 4, 5 (mod 7)`, то елемент `(p₁ + 1)⁻¹` потрапляє у множину нелишків `{3, 5, 6}`, і рівняння не має розв'язків. Жоден член не ділиться на 7!
- Якщо `p₁ ≡ 0, 1, 3 (mod 7)`, то кожний третій член ділиться на 7, що обмежує довжину `k ≤ 3`.

| Простий модуль `q` | Порядок двійки `d = ord_q(2)` | Сприятливі остачі `p₁ mod q` (без перешкод) | Заборонені остачі `p₁ mod q` (обмеження довжини) |
|---|---|---|---|
| `3` | 2 | `2` (`-1`) | `1` (обмеження `k ≤ 1`) |
| `5` | 4 | `4` (`-1`) | `0, 1, 2, 3` (обмеження `k ≤ 4`) |
| `7` | 3 | `2, 4, 5, 6` | `0, 1, 3` (обмеження `k ≤ 3`) |
| `11` | 10 | `10` (`-1`) | Усі інші остачі (обмеження `k ≤ 10`) |
| `13` | 12 | `12` (`-1`) | Усі інші остачі (обмеження `k ≤ 12`) |
| `17` | 8 | `1, 2, 4, 8, 9, 13, 15, 16` | `0, 3, 5, 6, 7, 10, 11, 12, 14` (обмеження `k ≤ 8`) |

## 4. Строгий розрахунок константи Бейтмана — Горна Cₖ

Гіпотеза Бейтмана — Горна (1962) дає математичний апарат для точної кількісної оцінки щільності розподілу простих послідовностей. Розглянемо систему `k` многочленів із цілими коефіцієнтами:

```
fᵢ(t) = 2ⁱ⁻¹ · t + (2ⁱ⁻¹ - 1),   1 ≤ i ≤ k
```

Головною величиною при обчисленні коефіцієнта відсіювання є кількість розв'язків `ω(q)` конгруенції:

```
∏_{i=1}ᵏ (2ⁱ⁻¹ · t + 2ⁱ⁻¹ - 1) ≡ 0 (mod q)
```

Значення `ω(q)` дорівнює кількості різних класів остач `t mod q`, для яких принаймні один із многочленів `fᵢ(t)` ділиться на `q`.

- Якщо `q` не ділить жодного з коефіцієнтів при `t` (тобто `q > 2`), кожен многочлен `fᵢ(t)` має один розв'язок `t ≡ (1 - 2ⁱ⁻¹) · (2ⁱ⁻¹)⁻¹ (mod q)`.
- Якщо `k < d = ord_q(2)`, усі `k` розв'язків є різними за модулем `q`, тому `ω(q) = k`.
- Якщо `k ≥ d`, деякі розв'язки збігаються, або покривають усе кільце остач. Якщо `ω(q) = q`, то система не має жодного розв'язку в цілих числах, оскільки кожне число `t` робить принаймні один член `fᵢ(t)` кратним `q`.

Незсунута константа Бейтмана — Горна `Cₖ` обчислюється як нескінченний добуток за всіма простими числами:

```
Cₖ = 2⁻⁽ᵏ⁻¹⁾ · ∏_{q > 2} ((1 - ω(q)/q) / (1 - 1/q)ᵏ)
```

Застосуємо цю формулу для обчислення константи пар Софі Жермен (`k = 2`):
- Для `q = 3`: `ω(3) = 1` (заборонено `t ≡ 1 mod 3`). Множник дорівнює `(1 - 1/3) / (1 - 1/3)² = 3/2`.
- Для `q > 3`: `ω(q) = 2` (два розв'язки за модулем `q`). Множник дорівнює `(1 - 2/q) / (1 - 1/q)² = (q(q-2)) / (q-1)²`.

Тоді константа `C₂` набуває відомого вигляду константи простих чисел-близнюків:

```
C₂ = 2⁻¹ · (3/2) · ∏_{q > 3} (q(q-2) / (q-1)²) ≈ 1.3203236316...
```

Аналогічно для `k = 3` константа дорівнює `C₃ ≈ 2.8582`, а для `k = 4` — `C₄ ≈ 4.1511`. Зростання величини `Cₖ` для більших `k` відображає факт, що після проходження початкового модулярного фільтру остач `p₁ ≡ -1 (mod 3·5·11...)` імовірність збереження простоти на наступних кроках виявляється вищою за середню імовірність випадкового простого числа.
