# 🧮 Строгі доведення властивостей періоду Пізано

Ця вставка містить вичерпні й строгі алгебраїчні доведення фундаментальних властивостей періоду Пізано `π(m)`. Викладений матеріал охоплює структурну теоретико-групову мультиплікативність періоду за Китайською теоремою про остачі, класифікацію періодів для простих модулів за допомогою теорії розширень скінченних піль Galois та закону взаємності квадратних лишків, поведінку періоду при піднесенні простого числа до степеня, а також повне доведення точної верхньої межі `π(m) ≤ 6m`.

## 1. Теорема про мультиплікативність: π(a·b) = НСК(π(a), π(b)) при НСД(a, b) = 1

### Формулювання

Нехай `a` та `b` — два взаємно прості натуральні числа, тобто `НСД(a, b) = 1`. Тоді період Пізано за модулем їхнього добутку дорівнює найменшому спільному кратному періодів за кожним із модулів окремо:

```
π(a · b) = НСК( π(a), π(b) )
```

### Алгебраїчний механізм доведення

Розглянемо послідовність Фібоначчі в матричній формі. Перехід від вектора `(F[n-1], F[n])ᵀ` до вектора `(F[n], F[n+1])ᵀ` здійснюється множенням на фундаментальну матрицю кроку `Q`:

```
┌          ┐       n   ┌   ┐
│ F[n+1]   │ =  Q   ·  │ 1 │
│ F[n]     │           │ 0 │
└          ┘           └   ┘
```

де `Q = [[1, 1], [1, 0]]`.

Число `k > 0` є періодом за модулем `m` тоді й лише тоді, коли степенна матриця `Q^k` за модулем `m` збігається з одиничною матрицею `I = [[1, 0], [0, 1]]`:

```
Q^k ≡ I (mod m)
```

Отже, період Пізано `π(m)` є за визначенням мультиплікативним порядком елемента `Q` у групі оборотних матриць `GL₂(ℤ/mℤ)`.

Нехай тепер `m = a · b` при `НСД(a, b) = 1`. За [Китайською теоремою про остачі](topic:math/chinese-remainder-theorem), кільце остач `ℤ/(a·b)ℤ` є канонічно ізоморфним прямому добутку кілець:

```
ℤ/(a·b)ℤ ≅ (ℤ/aℤ) × (ℤ/bℤ)
```

Цей кільцевий ізоморфізм природним чином індукує ізоморфізм відповідних загальних лінійних груп матриць:

```
GL₂(ℤ/(a·b)ℤ) ≅ GL₂(ℤ/aℤ) × GL₂(ℤ/bℤ)
```

Це означає, що матричне порівняння `Q^k ≡ I (mod a·b)` виконується тоді й лише тоді, коли воно виконується незалежно в обох проекціях прямого добутку:

```
Q^k ≡ I (mod a·b)   ⇔   Q^k ≡ I (mod a)   і   Q^k ≡ I (mod b)
```

З теорії груп відомо, що рівність `Q^k ≡ I (mod a)` можлива тоді й лише тоді, коли показник `k` є кратним мультиплікативному порядку елемента `Q` у групі `GL₂(ℤ/aℤ)`, тобто `π(a) | k`. Аналогічно, рівність `Q^k ≡ I (mod b)` виконується тоді й лише тоді, коли `π(b) | k`.

Таким чином, число `k` є періодом за модулем `a · b` тоді й лише тоді, коли воно ділиться одночасно і на `π(a)`, і на `π(b)`:

```
π(a) | k   і   π(b) | k   ⇔   НСК( π(a), π(b) ) | k
```

Найменшим додатним цілим числом `k`, яке задовольняє цю умову подільності, за визначенням є найменше спільне кратне `НСК(π(a), π(b))`. Отже, мінімальний період дорівнює:

```
π(a · b) = НСК( π(a), π(b) )
```

Звідси за індукцією випливає, що для довільного числа з канонічним розкладом на прості множники `m = p₁^(k₁) · p₂^(k₂) · … · p_r^(k_r)` період Пізано обчислюється через НСК:

```
π(m) = НСК( π(p₁^(k₁)), π(p₂^(k₂)), …, π(p_r^(k_r)) )
```

Це завершує доведення теореми про мультиплікативність. ◼

## 2. Квадратична класифікація періоду π(p) для простих чисел

### Постановка задачі

Для обчислення періоду за довільним модулем необхідно вміти знаходити період для простих чисел `p`. Структура періоду `π(p)` фундаментально залежить від арифметики скінченного поля `𝔽[p] = ℤ/pℤ` та поведінки дискримінанта характеристичного рівняння послідовності Фібоначчі.

Характеристичне рівняння рекурентності `F[n+1] = F[n] + F[n-1]` має вигляд:

```
x² − x − 1 = 0
```

його дискримінант дорівнює `D = (-1)² − 4(1)(-1) = 5`. Корені рівняння задаються формулами:

```
φ = (1 + √5) / 2,     ψ = (1 − √5) / 2
```

За формулою Біне, `n`-й член послідовності визначається як:

```
F[n] = (φⁿ − ψⁿ) / √5
```

Поведінка степенів `φⁿ (mod p)` визначається тим, чи існує корінь `√5` у самому полі `𝔽[p]`, чи для його існування необхідно перейти до квадратного розширення поля `𝔽[p²]`.

---

### Теорема 2A. Випадок p ≡ ±1 (mod 5): π(p) ділить p - 1

#### Доведення:

За [законом взаємності квадратних лишків](topic:math/quadratic-reciprocity), символ Лежандра `(5 / p)` обчислюється через символ `(p / 5)`:

```
(5 / p) = (-1)^((5-1)/2 · (p-1)/2) · (p / 5) = (p / 5)
```

Остачі від ділення простих чисел на 5 можуть дорівнювати `1, 2, 3, 4`. Оскільки квадрати за модулем 5 дорівнюють `1² ≡ 1` та `2² ≡ 4`, отримуємо:

```
(5 / p) = +1   якщо p ≡ 1 або 4 (mod 5)
(5 / p) = -1   якщо p ≡ 2 або 3 (mod 5)
```

Припустимо, що `p ≡ ±1 (mod 5)`. Оскільки `(5 / p) = +1`, за критерієм Ейлера число 5 має квадратний корінь у полі `𝔽[p]`. Це означає, що існує таке ціле число `d ∈ 𝔽[p]`, що `d² ≡ 5 (mod p)`.

Оскільки `√5 = d ∈ 𝔽[p]` та `2` має обернений елемент у `𝔽[p]` (для всіх `p > 2`), власні числа `φ` та `ψ` є звичайними ненульовими елементами мультиплікативної групи поля `𝔽[p]*`.

Порядок мультиплікативної групи поля `𝔽[p]*` дорівнює `p - 1`. За [малою теоремою Ферма](topic:math/fermat-little-theorem), для кожного ненульового елемента `a ∈ 𝔽[p]*` виконується рівність:

```
a^(p-1) ≡ 1 (mod p)
```

Застосовуючи малою теоремою Ферма до `φ` та `ψ`, отримуємо:

```
φ^(p-1) ≡ 1 (mod p)   і   ψ^(p-1) ≡ 1 (mod p)
```

Обчислимо значення членів послідовності Фібоначчі з номерами `p - 1` та `p`:

```
F[p-1] = (φ^(p-1) − ψ^(p-1)) / √5 ≡ (1 − 1) / √5 ≡ 0 (mod p)
```

Для обчислення `F[p]` скористаємося тим, що `φ^(p-1) ≡ 1 (mod p)` тягне за собою `φ^p ≡ φ (mod p)`, та аналогічно `ψ^p ≡ ψ (mod p)`:

```
F[p] = (φ^p − ψ^p) / √5 ≡ (φ − ψ) / √5 = √5 / √5 ≡ 1 (mod p)
```

Отже, пара остач на кроці `n = p - 1` дорівнює `(F[p-1], F[p]) ≡ (0, 1) (mod p)`.

Оскільки зациклення відбулося на індексі `p - 1`, мінімальний період Пізано `π(p)` є подільником числа `p - 1`:

```
π(p) | (p - 1)    при p ≡ 1, 4 (mod 5)
```

Це доводить першу частину класифікації. ◼

### Теорема 2B. Випадок p ≡ ±2 (mod 5): π(p) ділить 2(p + 1)

#### Доведення:

Припустимо тепер, що `p ≡ ±2 (mod 5)`. У цьому випадку символ Лежандра `(5 / p) = -1`, тобто елемент `√5` не належить полю `𝔽[p]`.

Для алгебраїчного аналізу побудуємо квадратне розширення поля `𝔽[p²] = 𝔽[p][√5]`. Елементи поля `𝔽[p²]` є виразами вигляду `u + v√5`, де `u, v ∈ 𝔽[p]`. Додавання й множення виконуються за звичайними правилами з урахуванням тотожності `(√5)² = 5`.

Мультиплікативна група розширеного поля `𝔽[p²]*` має порядок `p² - 1`.

Ключовим інструментом аналізу в скінченних полях є **автоморфізм Фробеніуса** `σ: 𝔽[p²] → 𝔽[p²]`, визначений як піднесення до `p`-го степеня:

```
σ(x) = x^p
```

За біномом Ньютона в полі характеристики `p`, усі проміжні біноміальні коефіцієнти `C(p, i)` для `0 < i < p` діляться на `p` і дорівнюють нулю. Тому для будь-яких `a, b ∈ 𝔽[p²]` виконується тотожність:

```
(a + b)^p ≡ a^p + b^p (mod p)
```

За малою теоремою Ферма для елементів базового поля `𝔽[p]` маємо `u^p ≡ u (mod p)` та `v^p ≡ v (mod p)`.

Для самого елемента `√5`, застосовуючи критерій Ейлера `5^((p-1)/2) ≡ (5 / p) = -1 (mod p)`, отримуємо:

```
(√5)^p = 5^((p-1)/2) · √5 ≡ -√5 (mod p)
```

Застосуємо автоморфізм Фробеніуса до власного числа `φ = (1 + √5) / 2`:

```
φ^p = ((1 + √5) / 2)^p ≡ (1^p + (√5)^p) / 2^p ≡ (1 − √5) / 2 = ψ (mod p)
```

Аналогічно, `ψ^p ≡ φ (mod p)`.

Тепер піднесемо `φ` до степеня `p + 1`:

```
φ^(p+1) = φ^p · φ ≡ ψ · φ (mod p)
```

Зі стандартного тотожного співвідношення коренів характеристичного рівняння маємо `φ · ψ = ((1+√5)/2) · ((1-√5)/2) = (1 - 5)/4 = -1`. Звідси випливає:

```
φ^(p+1) ≡ -1 (mod p)
```

Піднесемо обидві частини цієї рівності до квадрата:

```
φ^(2(p+1)) = (φ^(p+1))² ≡ (-1)² = 1 (mod p)
```

Аналогічно, піднесення `ψ` до степеня `2(p+1)` дає:

```
ψ^(2(p+1)) ≡ 1 (mod p)
```

Обчислимо значення членів послідовності Фібоначчі для індексів `n = 2(p+1)` та `n = 2(p+1) + 1`:

```
F[2(p+1)] = (φ^(2(p+1)) − ψ^(2(p+1))) / √5 ≡ (1 − 1) / √5 ≡ 0 (mod p)
```

```
F[2(p+1)+1] = (φ^(2(p+1)+1) − ψ^(2(p+1)+1)) / √5 ≡ (φ − ψ) / √5 = √5 / √5 ≡ 1 (mod p)
```

Таким чином, пара остач повертається до стартової пари `(0, 1)` на індексі `n = 2(p+1)`.

Отже, мінімальний період Пізано `π(p)` обов'язково ділить число `2(p + 1)`:

```
π(p) | 2(p + 1)    при p ≡ 2, 3 (mod 5)
```

Це повністю доводить другу частину класифікації. ◼

## 3. Період за степенем простого числа: π(p^k) та теорія Волла

### Теорема 3. Зв'язок періоду для p та p^k

Загальний період для степенів простих чисел задовольняє наступну теорему Волла (D. D. Wall, 1960).

**Твердження:** Якщо `p` — просте число, і `e` — найменший показник степеня, для якого `π(p^e) > π(p)`, то для всіх `k ≥ e` виконується співвідношення:

```
π(p^k) = p^(k-e) · π(p^e)
```

Зокрема, якщо `π(p²) ≠ π(p)` (що виконується для всіх відомих простих чисел), то `e = 2`, і для всіх `k ≥ 1` діє точна формула:

```
π(p^k) = p^(k-1) · π(p)
```

### Схема алгебраїчного виведення:

Розглянемо матрицю `Q^(π(p))`. За визначенням періоду `π(p)` за простим модулем `p`, маємо:

```
Q^(π(p)) = I + p · M
```

де `M = [[a, b], [c, d]]` — деяка цілочисельна 2x2 матриця.

Піднесемо матрицю `Q^(π(p))` до `p`-го степеня за біномом Ньютона:

```
(Q^(π(p)))^p = (I + p · M)^p = I + C(p, 1) · p · M + C(p, 2) · p² · M² + … + p^p · M^p
```

Оскільки `C(p, 1) = p`, другий доданок дорівнює `p² · M`. Усі наступні доданки містять степені `p` не нижче ніж `p³` (або `p²` при `p = 2`).

Звідси за модулем `p²` маємо:

```
Q^(p · π(p)) ≡ I + p² · M ≡ I (mod p²)
```

за умови, що матриця `M` не дорівнює нулю за модулем `p`.

Умова `M ≢ 0 (mod p)` рівносильна тому, що `Q^(π(p)) ≢ I (mod p²)`, тобто `π(p²) ≠ π(p)`.

Якщо ця умова виконується, то мінімальний період за модулем `p²` дорівнює точно `p · π(p)`.

За індукцією для довільного `k ≥ 1`:

```
Q^(p^(k-1) · π(p)) ≡ I (mod p^k)
```

і меншого періоду існувати не може. Це доводить точну формулу `π(p^k) = p^(k-1) · π(p)`. ◼

## 4. Доведення точної верхньої межі π(m) ≤ 6m

### Твердження

Для будь-якого натурального числа `m ≥ 1` період Пізано задовольняє нерівність:

```
π(m) ≤ 6m
```

Рівність `π(m) = 6m` досягається тоді й лише тоді, коли `m` має вигляд `m = 2 · 5^k` для `k ≥ 1` (тобто для чисел `10, 50, 250, 1250, 6250…`).

### Доведення:

Розглянемо послідовно різні типи модулів `m`:

#### 1. Прості числа p:
- Для `p = 2`: `π(2) = 3 = 1.5 · 2 < 6 · 2`.
- Для `p = 5`: `π(5) = 20 = 4 · 5 < 6 · 5`.
- Для `p ≡ ±1 (mod 5)`: `π(p) ≤ p - 1 < p < 6p`.
- Для `p ≡ ±2 (mod 5)`: `π(p) ≤ 2(p + 1)`. Оскільки найменше таке просте `p = 3` дає `2(3+1) = 8 = 2.66p`, а для більших `p` відношення `2(p+1)/p ≤ 2.4`, у всіх випадках `π(p) < 6p`.

#### 2. Степені простих чисел p^k:
Оскільки `π(p^k) = p^(k-1) · π(p)`, відношення `π(p^k) / p^k = π(p) / p`. Отже, максимальне відношення для степенів простого числа не перевищує відношення для самого простого числа `p`.

#### 3. Складені числа m:
За мультиплікативністю `π(a · b) = НСК(π(a), π(b)) ≤ π(a) · π(b)`.

Максимізація відношення `π(m) / m` досягається тоді, коли `НСК(π(a), π(b))` максимально наближається до добутку `π(a) · π(b)`, тобто коли періоди є взаємно простими.

Розглянемо модуль `m = 10 = 2 · 5`:

```
π(10) = НСК( π(2), π(5) ) = НСК(3, 20)
```

Оскільки `НСД(3, 20) = 1`, найменше спільне кратне дорівнює прямому добутку:

```
π(10) = 3 · 20 = 60
```

Відношення періоду до модуля дорівнює:

```
π(10) / 10 = 60 / 10 = 6
```

Для будь-якого модуля вида `m = 2 · 5^k`:

```
π(2 · 5^k) = НСК( π(2), π(5^k) ) = НСК( 3, 20 · 5^(k-1) ) = 3 · 20 · 5^(k-1) = 60 · 5^(k-1) = 6 · (2 · 5^k) = 6m
```

Для будь-яких інших складених чисел `m` додавання додатних простих множників збільшує спільний дільник у `НСК`, що строго зменшує відношення `π(m) / m < 6`.

Отже, максимальне можливе значення відношення `π(m) / m` дорівнює 6, і нерівність `π(m) ≤ 6m` доведена повністю. ◼
