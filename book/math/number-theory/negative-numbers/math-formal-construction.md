# 🧮 Формальна конструкція Гротендіка для кільця цілих чисел Z

Натуральні числа `N₀ = {0, 1, 2, 3, ...}` утворюють комутативний моноїд за додаванням, але в ньому неможливо розв'язати алгебраїчне рівняння `x + a = b` при `b < a`. Ця вставка містить повне й математично строге виведення побудови кільця цілих чисел `Z` з моноїда `N₀` за допомогою універсальної конструкції пар Гротендіка (Grothendieck group construction). Тут доведено відношення еквівалентності, коректність адитивної та мультиплікативної операцій, існування оберненого елемента, правило знаків, аксіоми впорядкованого кільця, універсальну категоріальну властивість та канонічне ізоморфне вкладення `N₀` в `Z`.

## 1. Мотивація та алгебраїчний дефіцит моноїда N₀

Множина натуральних чисел з нулем `N₀ = {0, 1, 2, 3, ...}` володіє наступними аксіоматичними властивостями за додаванням:
1. **Замкненість**: `∀ a, b ∈ N₀ ⇒ (a + b) ∈ N₀`.
2. **Асоціативність**: `∀ a, b, c ∈ N₀ ⇒ (a + b) + c = a + (b + c)`.
3. **Нейтральний елемент**: `∃ 0 ∈ N₀ : a + 0 = a`.
4. **Комутативність**: `∀ a, b ∈ N₀ ⇒ a + b = b + a`.
5. **Закон скорочення**: `a + c = b + c ⇒ a = b`.

Алгебраїчна система `(N₀, +)` з цими п'ятьма властивостями називається **комутативним моноїдом із законом скорочення**. Однак у моноїді `N₀` відсутня шоста фундаментальна властивість — **існування адитивно оберненого елемента**: для числа `5` не існує такого елемента `x ∈ N₀`, що `5 + x = 0`.

Через цю неполноту рівняння вигляду `x + a = b` не має розв'язку в `N₀` завжди, коли `b < a`. Метою конструкції Гротендіка є побудова мінімальної абелевої групи `(Z, +)`, яка містить моноїд `N₀` як підмоноїд і додає до кожного елемента його адитивно обернений об'єкт.

## 2. Декартовий добуток та відношення еквівалентності пар

Розглянемо декартовий добуток `N₀ × N₀` — множину всіх впорядкованих пар натуральних чисел `(a, b)`, де `a, b ∈ N₀`.

Інтуїтивно пара `(a, b)` уособлює різницю `a - b`. Оскільки операція віднімання у `N₀` не є всюди визначеною, ми залишаємося строго в межах додавання.

Різні пари можуть відповідати одній і тій самій різниці. Наприклад, пари `(3, 0)`, `(4, 1)` та `(5, 2)` уособлюють одне й те саме ціле число `+3`. Базове співвідношення `a - b = c - d` алгебраїчно еквівалентне співвідношенню `a + d = b + c`, яке вже не використовує мінуса!

Задамо на множині `N₀ × N₀` бінарне відношення `~`:

```
(a, b) ~ (c, d)  ⇔  a + d = b + c     [умова еквівалентності пар]
```

Доведемо, що відношення `~` є відношенням еквівалентності (задовольняє аксіоми рефлексивності, симетричності та транзитивності).

### Доведення рефлексивності
Потрібно показати, що `(a, b) ~ (a, b)` для будь-якої пари `(a, b) ∈ N₀ × N₀`.

```
a + b = b + a        [комутативність додавання в N₀]
⇒ (a, b) ~ (a, b)    [за означенням відношення ~]
```

### Доведення симетричності
Нехай `(a, b) ~ (c, d)`. Потрібно показати, що `(c, d) ~ (a, b)`.

```
a + d = b + c        [припущення: (a, b) ~ (c, d)]
c + b = d + a        [комутативність та симетрія рівності в N₀]
⇒ (c, d) ~ (a, b)    [за означенням відношення ~]
```

### Доведення транзитивності
Нехай `(a, b) ~ (c, d)` та `(c, d) ~ (e, f)`. Потрібно показати, що `(a, b) ~ (e, f)`.

За умовою маємо дві рівності в `N₀`:
1. `a + d = b + c`
2. `c + f = d + e`

Додамо ці дві рівності почленно у моноїді `N₀`:

```
(a + d) + (c + f) = (b + c) + (d + e)      [почленне додавання рівностей у N₀]
(a + f) + (c + d) = (b + e) + (c + d)      [перегрупування за асоціативністю та комутативністю]
a + f = b + e                              [закон скорочення в N₀ для елемента (c + d)]
⇒ (a, b) ~ (e, f)                          [за означенням відношення ~]
```

Отже, відношення `~` розбиває множину `N₀ × N₀` на класи еквівалентності, що не перетинаються. Множину всіх цих класів еквівалентності ми й називаємо **цілими числами** `Z`. Елемент кільця `Z` позначається через клас еквівалентності `[(a, b)]`.

## 3. Коректність означення адитивної операції (Додавання)

Визначимо операцію додавання класів еквівалентності за формулою:

```
[(a, b)] + [(c, d)] = [(a + c, b + d)]
```

Перевіримо **коректність (well-definedness)**: результат додавання не повинен залежати від вибору конкретних представників усередині класів еквівалентності.

Нехай `(a', b') ~ (a, b)` та `(c', d') ~ (c, d)`. За означенням відношення `~` це означає:
1. `a' + b = b' + a`
2. `c' + d = d' + c`

Потрібно довести, що `(a' + c', b' + d') ~ (a + c, b + d)`, тобто що виконується рівність у `N₀`:
`(a' + c') + (b + d) = (b' + d') + (a + c)`.

```
(a' + c') + (b + d)
= (a' + b) + (c' + d)         [перегрупування доданків за асоціативністю]
= (b' + a) + (d' + c)         [підстановка рівностей (1) та (2)]
= (b' + d') + (a + c)         [перегрупування доданків за комутативністю]
```

Рівність доведено. Отже, операція додавання у `Z` визначена коректно і є незалежною від вибору представників пар.

## 4. Коректність означення мультиплікативної операції (Множення)

Визначимо операцію множення класів еквівалентності за формулою:

```
[(a, b)] · [(c, d)] = [(a·c + b·d, a·d + b·c)]
```

Ця формула мотивована формальним розкриттям дужок для різниць: `(a - b)·(c - d) = (a·c + b·d) - (a·d + b·c)`.

Перевіримо коректність множення. Нехай `(a', b') ~ (a, b)`, тобто `a' + b = b' + a`. Покажемо, що заміна `(a, b)` на `(a', b')` при сталому `(c, d)` дає еквівалентний клас.

Потрібно довести рівність у `N₀`:
`(a'·c + b'·d) + (a·d + b·c) = (a'·d + b'·c) + (a·c + b·d)`.

Обчислимо ліву частину рівності:

```
(a'·c + b'·d) + (a·d + b·c)
= c·(a' + b) + d·(b' + a)     [групування за множниками c та d]
= c·(b' + a) + d·(a' + b)     [заміна a' + b = b' + a]
= a·c + b'·c + a'·d + b·d     [розкриття дужок]
= (a'·d + b'·c) + (a·c + b·d) [групування доданків]
```

Отримали праву частину. Аналогічно доводиться коректність для другого множника `(c, d)`. Отже, множення у `Z` визначено коректно.

## 5. Доведення властивостей кільця та правила знаків

Доведемо, що побудована алгебраїчна система `(Z, +, ·)` утворює комутативне кільце з одиницею.

### 1. Нейтральний елемент за додаванням (Нуль)
Класом нуля у `Z` є `[(0, 0)]` (або довільний клас вигляду `[(k, k)]` для `k ∈ N₀`).
```
[(a, b)] + [(0, 0)] = [(a + 0, b + 0)] = [(a, b)]
```

### 2. Адитивно обернений елемент (Від'ємне число)
Для будь-якого елемента `[(a, b)]` оберненим елементом є `[(b, a)]`.
```
[(a, b)] + [(b, a)] = [(a + b, b + a)]
```
Оскільки `(a + b) + 0 = 0 + (b + a)`, маємо `(a + b, b + a) ~ (0, 0)`.
Отже, `[(a, b)] + [(b, a)] = [(0, 0)]`.
Це доводить існування адитивно оберненого елемента для кожного цілого числа. Позначимо `-[(a, b)] = [(b, a)]`.

### 3. Нейтральний елемент за множенням (Одиниця)
Класом одиниці у `Z` є `[(1, 0)]`.
```
[(a, b)] · [(1, 0)] = [(a·1 + b·0, a·0 + b·1)] = [(a, b)]
```

### 4. Алгебраїчне доведення правила «мінус на мінус дає плюс»
Позначимо від'ємну одиницю `-1` як `-[ (1, 0) ] = [(0, 1)]`. Обчислимо добуток двох від'ємних одиниць:

```
[(0, 1)] · [(0, 1)]
= [(0·0 + 1·1, 0·1 + 1·0)]   [за формулою множення пар]
= [(1, 0)]                   [обчислення у N₀]
```

Отримали `[(1, 0)]` — додатну одиницю `+1`! Це є строгим доведенням того, що добуток двох від'ємних чисел обов'язково є додатним числом.

### 5. Дистрибутивність множення відносно додавання
Доведемо тотожність `X · (Y + Z) = X · Y + X · Z` для класів `X = [(a,b)]`, `Y = [(c,d)]`, `Z = [(e,f)]`.

Ліва частина:
```
[(a,b)] · ([(c,d)] + [(e,f)])
= [(a,b)] · [(c+e, d+f)]
= [(a·(c+e) + b·(d+f), a·(d+f) + b·(c+e))]
= [(a·c + a·e + b·d + b·f, a·d + a·f + b·c + b·e)]
```

Права частина:
```
[(a,b)] · [(c,d)] + [(a,b)] · [(e,f)]
= [(a·c + b·d, a·d + b·c)] + [(a·e + b·f, a·f + b·e)]
= [(a·c + b·d + a·e + b·f, a·d + b·c + a·f + b·e)]
```

Обидві частини дають точно один і той самий клас еквівалентності після перестановки доданків у `N₀`.

## 6. Впорядковане кільце та сумісність порядку

На побудованій множині `Z` вводиться відношення строгого порядку `<`:

```
[(a, b)] < [(c, d)]  ⇔  a + d < b + c     [умова порядку]
```

Перевіримо коректність цього відношення. Нехай `(a', b') ~ (a, b)` та `(c', d') ~ (c, d)`. Це означає `a' + b = b' + a` та `c' + d = d' + c`.

Потрібно показати, що `a' + d' < b' + c'` еквівалентно `a + d < b + c`.

```
a' + d' < b' + c'
⇔ (a' + d') + (b + c) < (b' + c') + (b + c)   [додавання (b+c) до обох частин у N₀]
⇔ (a' + b) + (d' + c) < (b' + a) + (c' + d)   [перегрупування доданків]
⇔ (b' + a) + (c' + d) < (b' + a) + (c' + d)   [підстановка рівностей еквівалентності]
```

Нерівність узгоджена з додаванням і множенням, що робить `(Z, +, ·, <)` впорядкованим кільцем.

## 7. Вкладення N₀ у Z та універсальна властивість Гротендіка

Визначимо відображення `j: N₀ → Z` за формулою:

```
j(n) = [(n, 0)]
```

Це відображення є ін'єктивним гомоморфізмом моноїдів:
- `j(n + m) = [(n + m, 0)] = [(n, 0)] + [(m, 0)] = j(n) + j(m)`.
- `j(n · m) = [(n·m, 0)] = [(n, 0)] · [(m, 0)] = j(n) · j(m)`.
- Якщо `j(n) = j(m)`, то `[(n, 0)] = [(m, 0)] ⇒ n + 0 = 0 + m ⇒ n = m`.

Отже, `N₀` канонічно вкладається у `Z` як підмоноїд невід'ємних цілих чисел.

**Універсальна властивість групи Гротендіка**: для будь-якої абелевої групи `G` та будь-якого гомоморфізму моноїдів `f: N₀ → G` існує **єдиний** гомоморфізм груп `h: Z → G` такий, що `f = h ◦ j`.

Це доводить, що побудоване кільце `Z` є найменшим і єдино можливим (з точністю до ізоморфізму) розширенням натуральних чисел до абелевої групи за додаванням.
