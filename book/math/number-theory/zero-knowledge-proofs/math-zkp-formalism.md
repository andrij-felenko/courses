# 🧮 Математичний формалізм нульового розголошення: повнота, обґрунтованість та симулятор

Формалізація доведень з нульовим розголошенням спирається на апарат теорії ймовірностей, обчислювальної складності та абстрактної алгебри. Інтерактивна система доведення розглядається як гра між двома ймовірнісними машинами Тюрінга поліноміальної складності (англ. *Probabilistic Polynomial Time*, PPT).

Нехай `L ⊂ {0, 1}*` — мова з класу NP, а `R_L` — відповідне бінарне відношення таке, що префіксне слово `x ∈ L` тоді і тільки тоді, коли існує короткий свідок `w` (англ. *witness*) такий, що `(x, w) ∈ R_L`. Мета протоколу полягає у тому, щоб доводжувач `P`, який володіє свідком `w`, переконав перевіряльника `V` (який знає лише публічне слово `x`) у тому, що `x ∈ L`, не передавши жодного біта інформації про `w`.

## Формальне означення інтерактивного доведення

Пара інтерактивних алгоритмів `(P, V)` утворює доведення з нульовим розголошенням для мови `L` із відношенням `R_L`, якщо виконуються три фундаментальні аксіоми.

### 1. Повнота (Completeness)

Для будь-якого коректного публічного входу `x` та відповідного йому секретного свідка `w` такого, що `(x, w) ∈ R_L`, чесний перевіряльник `V` завжди приймає доведення від чесного доводжувача `P`:

```
Pr[ ⟨P(x, w), V(x)⟩ = 1 ] = 1
```

де позначення `⟨P, V⟩(x)` означає випадкову величину результату обміну повідомленнями між `P` та `V` на вході `x`.

### 2. Обґрунтованість знання (Knowledge Soundness)

Для будь-якого (можливо фальшивого чи зловмисного) доводжувача `P*`, який не має доступу до свідка `w`, імовірність обманути чесного перевіряльника `V` не перевищує нехтовну функцію `ε(|x|)`:

```
Pr[ ⟨P*(x), V(x)⟩ = 1 ] ≤ ε(|x|)  для x ∉ L
```

Зокрема, якщо `P*` здатний переконати `V` з імовірністю `p(x) > ε(|x|)`, то існує поліноміальний екстрактор знань `E` (англ. *extractor*), який, маючи доступ до внутрішнього стану та механізму скидання (англ. *rewinding*) доводжувача `P*`, здатен обчислити свідок `w`:

```
Pr[ E^{P*}(x) = w | (x, w) ∈ R_L ] ≥ p(x) - ε(|x|)
```

### 3. Нульове розголошення (Zero-Knowledge)

Протокол задовольняє властивість нульового розголошення, якщо для будь-якого (навіть зловмисного) перевіряльника `V*` існує поліноміальний ймовірнісний симулятор `S` такий, що для всіх `(x, w) ∈ R_L` розподіл ймовірностей транскриптів симулятора `S(x)` є нерозрізнюваним від розподілу транскриптів реальної взаємодії `⟨P(x, w), V*(x)⟩`.

Залежно від строгості нерозрізнюваності виділяють три класи нульового розголошення:

1. **Ідеальне (Perfect Zero-Knowledge)**: Розподіли випадкових величин збігаються тотожно:
   ```
   S(x) ≡ ⟨P(x, w), V*(x)⟩
   ```
2. **Статистичне (Statistical Zero-Knowledge)**: Статистична відстань `Δ` між розподілами є нехтовно малою функцією від довжини входу:
   ```
   Δ( S(x), ⟨P(x, w), V*(x)⟩ ) ≤ negl(|x|)
   ```
3. **Обчислювальне (Computational Zero-Knowledge)**: Жоден ймовірнісний алгоритм поліноміальної складності `D` (розрізнювач) не може відрізнити згенерований симулятором транскрипт від реального з помітною перевагою:
   ```
   | Pr[ D(S(x)) = 1 ] - Pr[ D(⟨P(x, w), V*(x)⟩) = 1 ] | ≤ negl(|x|)
   ```

## Строгий математичний аналіз протоколу Шнорра

Розглянемо циклічну групу `G` простого порядку `q` з твірним елементом `g` та модулем `p`, де `q | (p - 1)`. Нехай публічним входом є елемент `y = g^x mod p`, а секретним свідком — дискретний логарифм `x ∈ ℤ_q`.

### Доведення повноти

Чесний доводжувач обирає випадкове `k ∈ ℤ_q` та обчислює `r = g^k mod p`. Отримавши виклик `c ∈ ℤ_q`, він надсилає відповідь `s = (k + c · x) mod q`. Перевіряльник перевіряє рівність:

```
g^s mod p
= g^{(k + c · x) mod q} mod p         [за означенням відповіді s = k + cx mod q]
= g^{k + c · x} mod p                 [бо порядок g дорівнює q, тобто g^q ≡ 1 mod p]
= (g^k mod p) · ((g^x)^c mod p) mod p [властивість піднесення до степеня у групі]
= r · y^c mod p                       [за підстановкою r = g^k та y = g^x mod p]
```

Отже, тотожність `g^s ≡ r · y^c (mod p)` виконується завжди. Повнота доведена з імовірністю `1`.

### Доведення обґрунтованості через екстракцію свідка

Припустимо, що ненадійний доводжувач `P*` здатний успішно відповісти на два різні виклики `c₁ ≠ c₂ mod q` для одного й того самого початкового зобов'язання `r = g^k mod p`.

Тоді утворено два коректні транскрипти `(r, c₁, s₁)` та `(r, c₂, s₂)`, для яких виконуються тотожності:

```
g^{s₁} = r · y^{c₁} mod p
g^{s₂} = r · y^{c₂} mod p
```

Поділимо перше рівняння на друге у групі `ℤ_p^*`:

```
g^{s₁ - s₂} mod p
= (r · y^{c₁}) / (r · y^{c₂}) mod p  [ділення рівнянь верифікатора у групі]
= y^{c₁ - c₂} mod p                 [скорочення однакового множника r]
= (g^x)^{c₁ - c₂} mod p             [підстановка y = g^x mod p]
= g^{x · (c₁ - c₂)} mod p           [властивість степеня підгрупи]
```

Переходячи до показників степеня у циклічній групі порядку `q`, отримуємо порівняння за модулем `q`:

```
s₁ - s₂ ≡ x · (c₁ - c₂)  (mod q)
```

Оскільки `q` — просте число, а `c₁ ≠ c₂ mod q`, то `gcd(c₁ - c₂, q) = 1`. Отже, елемент `(c₁ - c₂)` має єдиний обернений елемент `(c₁ - c₂)^{-1} mod q`. Помноживши обидві частини на цей обернений елемент, отримуємо пряму формулу екстрактора для обчислення секрету `x`:

```
x = (s₁ - s₂) · (c₁ - c₂)^{-1} mod q
```

Це доводить, що якщо доводжувач не знає `x`, він не може відповісти більше ніж на один виклик `c` для заданого `r`. Імовірність випадкового вгадування виклику дорівнює `1/q`, що є нехтовно малою величиною для криптографічно стійких груп (де `q ≈ 2^{256}`).

### Конструкція симулятора нульового розголошення (HVZK)

Доведемо властивість нульового розголошення для чесного перевіряльника (англ. *Honest-Verifier Zero-Knowledge*, HVZK), побудувавши симулятор `S`.

Симулятор `S` не має доступу до секрету `x`. Замість цього він виконує обчислення у зворотному порядку:

1. Генерує випадковий виклик `c' ∈ ℤ_q` з рівномірним розподілом.
2. Генерує випадкову відповідь `s' ∈ ℤ_q` з рівномірним розподілом.
3. Обчислює підроблене зобов'язання `r'` за формулою:
   ```
   r' = g^{s'} · y^{-c'} mod p
   ```
4. Видає транскрипт `T_sim = (r', c', s')`.

Перевіримо, чи задовольняє згенерована трійка рівняння верифікатора:

```
g^{s'} mod p
= g^{s'} · (y^{-c'} · y^{c'}) mod p    [нейтральний множник: y^{-c'} · y^{c'} = 1 mod p]
= (g^{s'} · y^{-c'}) · y^{c'} mod p    [асоціативність множення в групі]
= r' · y^{c'} mod p                    [за підстановкою означення r' = g^{s'} · y^{-c'}]
```

У реальному протоколі `c` обирається випадково та рівномірно з `ℤ_q`, а `s = k + c · x mod q` також має рівномірний розподіл у `ℤ_q`, бо `k` обрано випадково. Оскільки в симуляторі `c'` та `s'` обрано випадково та незалежно з `ℤ_q`, а `r'` однозначно визначається ними, розподіл ймовірностей трійки `(r', c', s')` тотожно збігається з розподілом справжнього транскрипту `(r, c, s)`:

```
{ S(y) } ≡ { ⟨P(x), V(y)⟩ }
```

Це доводить ідеальне нульове розголошення протоколу Шнорра відносно чесного перевіряльника.

## Доведення обґрунтованості у неінтерактивному режимі: Лемма про розгалуження (Forking Lemma)

Застосування евристики Фіата — Шаміра замінює живого перевіряльника запитом до криптографічної хеш-функції `c = H(g, y, r)`. Для того щоб довести обґрунтованість неінтерактивного доказу (NIZK) у моделі випадкового оракула (ROM), спираються на **Лемму про розгалуження** (англ. *Forking Lemma*), сформульовану Деніелом Пойнчевалем (англ. *David Pointcheval*) та Жаком Стерном (англ. *Jacques Stern*).

Припустимо, що існує ненадійний доводжувач `P*`, який за поліноміальний час створює підроблений неінтерактивний доказ `π = (r, s)` з помітною ймовірністю `ε`.

Екстрактор `E` запускає `P*` та моделює хеш-функцію `H` як випадковий оракул:

1. `E` фіксує випадкову послідовність внутрішніх кроків та генератора випадкових чисел доводжувача `P*`.
2. Коли `P*` робить перший запит до оракула `H(g, y, r)`, оракул повертає випадкове значення `c₁`. Доводжувач видає підсумковий доказ `(r, s₁)`.
3. Оскільки `E` контролює випадковий оракул, він виконує **скидання стану** (англ. *rewinding*) доводжувача `P*` строго до моменту виклику оракула `H(g, y, r)`.
4. На другому прогоні оракул повертає нове незалежне випадкове значення `c₂ ≠ c₁`.
5. Оскільки внутрішній стан `P*` до моменту запиту був тотожним, він згенерує те саме зобов'язання `r`, але обчислить нову відповідь `s₂`.

У результаті скидання стану Екстрактор отримує дві успішні трійки `(r, c₁, s₁)` та `(r, c₂, s₂)`. Зауважимо, що вони мають однакове `r`. Використовуючи формулу екстракції:

```
x = (s₁ - s₂) · (c₁ - c₂)^{-1} mod q
```

Екстрактор обчислює секретний ключ `x` за поліноміальний час. Згідно з Леммою про розгалуження, якщо імовірність підробки `ε > 1/q`, то Екстрактор успішно вилучить свідок `x` за час `O(Q_h / ε)`, де `Q_h` — кількість запитів до випадкового оракула. Це доводить, що неінтерактивний аргумент Шнорра є криптографічно обґрунтованим у моделі випадкового оракула.

## Нульове розголошення відносно зловмисного перевіряльника (Malicious Verifier ZK)

У базовому доведенні HVZK ми припускали, що перевіряльник `V` генерує виклик `c` строго за правилами — випадково та рівномірно з `ℤ_q`. Проте зловмисний перевіряльник `V*` може адаптивно обирати виклик `c` як складну функцію від отриманого зобов'язання `r`: `c = V*(r)`. Його метою є отримання відповідей `s`, які б залежили від секрету `x` у нелінійний спосіб і дозволили відновити біти `x`.

Для захисту від зловмисного перевіряльника застосовують три основні методи:

1. **Запити з попереднім зобов'язанням (Commitment Schemes)**: Перевіряльник зобов'язаний зафіксувати свій виклик `c` у вигляді хешу `h_c = H(c)` ДО того, як доводжувач надішле зобов'язання `r`. Це позбавляє `V*` можливості адаптивно підбирати `c` під `r`.
2. **Модель спільного довідкового рядка (CRS)**: У неінтерактивному режимі евристика Фіата — Шаміра детерміновано фіксує `c = H(g, y, r)`. Оскільки доводжувач сам обчислює `c` через публічний хеш, зловмисний перевіряльник взагалі позбавлений можливості впливати на виклик `c`.
3. **Симуляція зі скиданням часу (Black-Box Rewinding Simulator)**: Якщо `V*` є довільною програмою, симулятор `S` запускає `V*`, отримує перше зобов'язання `r'`, зчитує виклик `c' = V*(r')`, після чого виконує скидання часу `V*` і перераховує `r'' = g^{s''} · y^{-c'}` для обраного наперед `s''`. 

Таким чином, математичний формалізм симуляції гарантує абсолютне нульове розголошення навіть у присутній агресивно налаштованого супротивника.
