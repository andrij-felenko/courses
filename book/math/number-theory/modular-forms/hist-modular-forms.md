# 📜 Історія виникнення та розвитку теорії модулярних форм

Формування теорії модулярних форм охоплює двовіковий шлях розвитку — від класичного обчислення еліптичних інтегралів у XVIII столітті до доведення Великої теореми Ферма та побудови програми Ленглендса наприкінці XX століття. Функції комплексного аналізу, наділені нескінченною симетрією відносно дробово-лінійних перетворень, виявилися ключовим інструментом для розв'язання фундаментальних арифметичних задач про підрахунок точок, розклад простих дільників та структуру діофантових рівнянь.

## 1. Еліптичні інтеграли та подвійна періодичність (Ейлер, Ґаусс, Якобі)

Витоки теорії модулярних форм сягають класичної механіки та геометрії XVIII століття, а саме задачі про обчислення довжини дуги еліпса та періоду коливань математичного маятника при довільних амплітудах. Обчислення таких геометричних величин приводило до інтегралів вигляду:

```
I(x) = ∫₀ˣ dt / √( (1 - t²) (1 - k² t²) )
```

які не виражалися через елементарні тригонометричні чи логарифмічні функції.

Леонард Ейлер у 1750-х роках виявив дивовижну теорему додавання для еліптичних інтегралів, а також відкрив пентагональну теорему про розклад нескінченного добутку:

```
∏_{n=1}^∞ (1 - qⁿ) = ∑_{k=-∞}^\infty (-1)ᵏ · q^{k(3k - 1) / 2}
```

Цей добуток згодом виявився 24-м коренем із модулярного дискримінанта `Δ(τ)`.

Проте справжній геометричний прорив здійснили Карл Фрідріх Ґаусс, Нільс Генрік Абель та Карл Ґустав Якобі у 1820-х роках. Вони зрозуміли, що замість вивчення самого інтеграла `I(x)` необхідно розглядати **обернену функцію** `x = f(u)`.

Виявилося, що ці обернені функції (еліптичні функції) володіють новою алгебраїчною властивістю, якої не мали тригонометричні функції: вони є **подвійно періодичними** у комплексній площині `ℂ`. Тобто існують два комплексні числа `ω₁` та `ω₂` із недійсним відношенням `τ = ω₂ / ω₁`, такі що для будь-якого `z ∈ ℂ`:

```
f(z + ω₁) = f(z),    f(z + ω₂) = f(z)
```

Множина `Λ = ℤ·ω₁ + ℤ·ω₂` утворює решітку (ґратку) в комплексній площині. Карл Якобі запровадив тета-функції `θ(τ, z)` як фундаментальні будувальні блоки подвійно періодичних функцій і помітив, що при перетворенні решітки параметр `τ` у верхній півплощині `ℍ = {τ ∈ ℂ : Im(τ) > 0}` зазнає дробово-лінійних перетворень.

## 2. Від геометрії решіток до групи модулярних перетворень (Дедекінд, Ейзенштейн, Кляйн, Пуанкаре)

У середині XIX століття Ґотгольд Ейзенштейн поставив питання: як класифікувати самі решітки `Λ` з точністю до масштабування? Дві бази `(ω₁, ω₂)` та `(ω₁', ω₂')` задають одну й ту саму решітку `Λ` тоді й лише тоді, коли вони пов'язані цілочисельною матрицею з детермінантом `+1`:

```
( ω₂' )   ( a  b ) ( ω₂ )
(     ) = (      ) (    ),     a, b, c, d ∈ ℤ,  ad - bc = 1
( ω₁' )   ( c  d ) ( ω₁ )
```

Відношення базисних векторів `τ = ω₂ / ω₁` при цьому перетворюється за правилом дробово-лінійного перетворення Мебіуса:

```
τ' = (a·τ + b) / (c·τ + d)
```

Множина таких матриць утворює модулярну групу `SL(2, ℤ)`. Ейзенштейн побудував перші систематичні приклади функцій на просторі решіток, які перетворюються з певним ваговим множником — суми за всіма вузлами решітки `G_k(τ) = ∑ 1 / (mτ + n)ᵏ`.

Ріхард Дедекінд у 1877 році запровадив псевдомодулярну ета-функцію `η(τ) = q^{1/24} ∏ (1 - qⁿ)`, яка відіграє центральну роль у комбінаториці розбиттів цілих чисел та теорії модулярних форм півцілого степеня.

Фелікс Кляйн у 1870–1880-х роках об'єднав комплексний аналіз, геометрію та теорію груп, побудувавши фундаментальну область `ℱ` дії групи `SL(2, ℤ)` на півплощині `ℍ` та створивши абсолютний інваріант `j(τ)` (абсолютний інваріант Кляйна). Приблизно в цей же час Анрі Пуанкаре узагальнив модулярні форми до автоморфних функцій для довільних фуксових груп, довівши існування рядів Пуанкаре.

## 3. Таємниця функції Рамануджана та аналітична теорія чисел (Рамануджана, Морделл, Гекке, Делінь)

На початку XX століття індійський геній Срініваса Рамануджан під час дослідження розкладу параболічної модулярної форми ваги 12 — дискримінанта `Δ(τ)` — відкрив її коефіцієнти `τ(n)` (функція Рамануджана):

```
Δ(τ) = q · ∏_{n=1}^∞ (1 - qⁿ)²⁴ = ∑_{n=1}^n τ(n) · qⁿ,    де q = e^{2πiτ}
```

Рамануджан емпірично виявив дивовижні мультиплікативні властивості цих коефіцієнтів та сформулював знамениту гіпотезу про межу зростання:

```
1. τ(m · n) = τ(m) · τ(n)                    при gcd(m, n) = 1
2. τ(pᵏ⁺¹) = τ(p) · τ(pᵏ) - p¹¹ · τ(pᵏ⁻¹)       для простого p
3. |τ(p)| ≤ 2 · p¹¹/²                        (Гіпотеза Рамануджана)
```

У 1917 році Луїс Морделл довів перші дві властивості, використавши оператори перетворення решіток. Проте повну алгебраїчну теорію побудував Еріх Гекке у 1930-х роках. Гекке запровадив відкриті ним лінійні **оператори Гекке** `T_n`, які діють у просторах модулярних форм.

Гекке довів, що власні форми цих операторів утворюють базис у просторі модулярних форм, а їхні коефіцієнти Фур'є відповідають Ейлеровим добуткам для асоційованих рядів L-функцій. Це остаточно зв'язало модулярні форми з аналітичною теорією чисел та L-функціями Діріхле.

Третя гіпотеза Рамануджана `|τ(p)| ≤ 2 · p¹¹/²` залишалася нерозв'язаною понад півстоліття. Лише у 1974 році П'єр Делінь довів її у повній загальності (для всіх параболічних власних форм ваги `k`: `|a_p| ≤ 2 · p^{(k-1)/2}`), зв'язавши коефіцієнти модулярних форм із власнозначеннями Фробеніуса на мотивних когомологіях алгебраїчних многовидів над скінченними полями (доведення гіпотез Вейля), за що Делінь був нагороджений Філдсівською премією 1978 року.

## 4. Гіпотеза Таніями-Шимури-Вейля та розв'язання Великої теореми Ферма (Вілс, Тейлор, Рібет)

У 1955 році на міжнародному симпозіумі в Токіо японський математик Ютака Таніяма висловив сміливу гіпотезу, яку згодом уточнили Ґоро Шимура та Андре Вейль (гіпотеза Таніями-Шимури-Вейля): **кожна еліптична крива, визначена над полем раціональних чисел `ℚ`, є модулярною**.

Це означало, що для кожної еліптичної кривої `E: y² = x³ + ax + b` з провідником `N` існує така параболічна модулярна форма ваги 2 рівня `N` (тобто для підгрупи конгруентності `Γ₀(N)`), коефіцієнти Фур'є `a_p` якої точно відповідають кількості точок кривої `E` над скінченними полями `𝔽_p`:

```
a_p = p + 1 - #E(𝔽_p)
```

Тривалий час ця гіпотеза вважалася недосяжною та відірваною від інших розділів математики. Однак у 1986 році Ґергард Фрей зауважив, що якщо Велика теорема Ферма хибна (тобто існує розв'язок `aⁿ + bⁿ = cⁿ` для `n ≥ 5`), то гіпотетична крива Фрей:

```
E_Frey: y² = x · (x - aⁿ) · (x + bⁿ)
```

мала б настільки екстремальні арифметичні властивості, що її модулярна форма не могла б існувати. Жан-П'єр Серр сформулював гіпотезу зниження рівня, а Кен Рібет у 1990 році довів її: з модулярності кривої Фрей випливало б існування ненульової параболічної форми ваги 2 і рівня 2 (`S₂(Γ₀(2))`). Але прямий обчислювальний аналіз показує, що розмірність простору `S₂(Γ₀(2))` дорівнює `0`!

Отож, аби довести Велику теорему Ферма, достатньо було довести модулярність напівстабільних еліптичних кривих over `ℚ`. Ендрю Вілс працював над цією задачею у повній таємниці протягом 7 років у своєму горищному кабінеті. У червні 1993 року на конференції в Кембриджі Вілс анонсував доведення. 

Під час рецензування у 1993 році Ніколас Кац виявив прогалину у конструкції деформаційного кільця `R = T`. Протягом року Вілс разом зі своїм колишнім учнем Річардом Тейлором намагався закрити цю діру, і у вересні 1994 року Вілс осяяв новий підхід через теорію Івасави. У травні 1995 року в журналі *Annals of Mathematics* вийшла вирішальна праця Вілса та Тейлора, що остаточно закрила 358-літню проблему Ферма.

У 2001 році Крістоф Брейль, Браян Конрад, Фред Даймонд та Річард Тейлор довели теорему про модулярність у повній загальності для всіх еліптичних кривих над `ℚ`.

## 5. Сучасний стан: програма Ленглендса та «Monster Moonshine»

Сьогодні модулярні форми розглядаються як найпростіший вимір масштабної **програми Ленглендса** — грандіозного веб-проекту сучасної математики, висунутого Робертом Ленглендсом у 1967 році, що пов'язує автоморфні представлення груп Лі з мотивними Galois-представленнями.

Крім того, наприкінці XX століття Річард Борчердс довів гіпотезу «Monstrous Moonshine» (довільні місячні сяйва), запропоновану Джон Конвеєм та Саймоном Нортоном у 1979 році. Борчердс показав, що коефіцієнти модулярної `j`-функції Кляйна:

```
j(τ) - 744 = q⁻¹ + 196884·q + 21493760·q² + ...
```

точно відповідають градуйованій сумі розмірностей непривідних представлень найбільшої скінченної простої спорадичної групи — Монстра (порядок якої становить приблизно `8 · 10⁵³`). За використання алгебр Каца-Муді та вершинних операторних алгебр для доведення цієї гіпотези Борчердс був нагороджений Філдсівською премією 1998 року.

Модулярні форми також стали центральним математичним апаратом у теорії струн (партиційні функції замкнених струн на конформних поверхнях та компактифікаціях Калабі-Яу) і квантовій теорії поля.
