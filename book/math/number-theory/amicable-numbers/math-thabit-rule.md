# 🧮 Теорема Сабіта ibn Кюрри та алгебра суми дільників

Ця вставка містить вичерпний розбір алгебраїчної теорії, яка лежить в основі побудови та аналізу дружніх чисел. Тут детально виведено мультиплікативні властивості арифметичної функції суми дільників `σ(n)`, подано поетапне доведення теореми Сабіта ibn Кюрри з математичною деталізацією кожного перетворення, розібрано числові приклади перевірки для різних показників степеня двійки та представлено узагальнення Вальтера Борхо й Леонарда Ойлера.

## 1. Арифметична функція суми дільників та її властивості

Для будь-якого натурального числа `n` функція `σ(n)` означає суму всіх його позитивних дільників, включаючи одиницю та саме число `n`. Аліквотна сума `s(n)` — це сума лише власних дільників, тобто `s(n) = σ(n) − n`.

Щоб зрозуміти, як виводиться загальна формула для `σ(n)`, звернемося до [Основної теореми арифметики](topic:math/fundamental-theorem-arithmetic). Кожне натуральне число `n > 1` однозначно розкладається на добуток простих множників:

```
n = p₁ᵏ¹ · p₂ᵏ² · … · pₘᵏᵐ
```

де `p₁, p₂, …, pₘ` — різні [прості числа](topic:math/prime-numbers), а `k₁, k₂, …, kₘ` — їхні натуральні показники степеня.

### Структура довільного дільника

Будь-який дільник `d` числа `n` утворюється вибором степеня кожного з простих множників `pᵢ` від `0` до `kᵢ`:

```
d = p₁ᵃ¹ · p₂ᵃ² · … · pₘᵃᵐ,   де 0 ≤ aᵢ ≤ kᵢ
```

Якщо розкрити дужки в добутку сум геометричних прогресій для кожного простого множника:

```
P = (1 + p₁ + p₁² + … + p₁ᵏ¹) · (1 + p₂ + p₂² + … + p₂ᵏ²) · … · (1 + pₘ + pₘ² + … + pₘᵏᵐ)
```

то за правилом дистрибутивності кожний доданок, що виникає після повного розкриття дужок, буде виглядати як `p₁ᵃ¹ · p₂ᵃ² · … · pₘᵃᵐ`. Оскільки кожна комбінація показників `(a₁, a₂, …, aₘ)` виникає рівно один раз, сума всіх можливих доданків дорівнює точній сумі всіх дільників числа `n`.

Звідси маємо фундаментальну формулу для `σ(n)`:

```
σ(n) = ∏ [i=1..m] (pᵢᵏⁱ⁺¹ − 1) / (pᵢ − 1)
```

### Доведення мультиплікативності

Арифметична функція `f(n)` називається **мультиплікативною**, якщо для будь-яких двох взаємно простих чисел `u` та `v` (тобто таких, у яких `НСД(u, v) = 1`) виконується співвідношення `f(u·v) = f(u) · f(v)`.

Перевіримо цю властивість для `σ(n)`. Нехай `u` та `v` — взаємно прості числа. Це означає, що канонічні розклади `u` та `v` на прості множники не мають жодного спільного простого числа. Нехай:

```
u = p₁ᵏ¹ · … · pᵣᵏʳ
v = q₁ᵐ¹ · … · qₛᵐˢ
```

де всі `pᵢ` та `qⱼ` є попарно різними простими числами. Тоді канонічний розклад добутку `u·v` має вигляд:

```
u·v = p₁ᵏ¹ · … · pᵣᵏʳ · q₁ᵐ¹ · … · qₛᵐˢ
```

Загальна формула суми дільників дає:

```
σ(u·v) = [ ∏ (pᵢᵏⁱ⁺¹ − 1)/(pᵢ − 1) ] · [ ∏ (qⱼᵐʲ⁺¹ − 1)/(qⱼ − 1) ]
       = σ(u) · σ(v)
```

Мультиплікативність `σ(n)` доведено. Вона є наріжним каменем для аналізу складених чисел: якщо ми знаємо розклад числа на взаємно прості блоки, суму дільників усього числа можна обчислити як добуток сум дільників цих блоків.

### Часткові випадки для простих чисел та степенів двійки

1. Для простого числа `p` дільниками є лише `1` та `p`, тому:
```
σ(p) = 1 + p
```
2. Для степеня простого числа `pᵏ` дільниками є `1, p, p², …, pᵏ`, отже:
```
σ(pᵏ) = (pᵏ⁺¹ − 1) / (p − 1)
```
3. Для степеня двійки `2ⁿ` знаменник `p − 1 = 2 − 1 = 1`, що дає особливо просту й зручну формулу:
```
σ(2ⁿ) = 2ⁿ⁺¹ − 1
```

Ця формула показує, що сума всіх степенів двійки від `2⁰` до `2ⁿ` дорівнює наступному степеню двійки мінус одиниця.

## 2. Повне доведення теореми Сабіта ibn Кюрри

Теорема Сабіта ibn Кюрри (близько 850 року) дає строгий конструктивний спосіб побудови дружніх пар виправданою алгебраїчною формою.

### Строге формулювання

Нехай `n ≥ 2` — ціле число. Сформуємо три алгебраїчні вирази:

```
p = 3 · 2ⁿ⁻¹ − 1
q = 3 · 2ⁿ − 1
r = 9 · 2²ⁿ⁻¹ − 1
```

Якщо всі три числа `p`, `q` та `r` є **простими числами**, то натуральні числа:

```
a = 2ⁿ · p · q
b = 2ⁿ · r
```

утворюють **дружню пару**, тобто виконуються рівності `s(a) = b` та `s(b) = a`.

### Аналіз взаємної простоти та умов

Перш ніж застосувати мультиплікативність, перевіримо взаємну простоту множників у числах `a` та `b`:

1. Єдиним простим дільником числа `2ⁿ` є число 2.
2. Значення `p = 3·2ⁿ⁻¹ − 1` при `n ≥ 2` є непарним числом (бо `3·2ⁿ⁻¹` парне, мінус 1 дає непарне). Оскільки за умовою `p` — просте число, воно не може ділитися на 2. Отже, `НСД(2ⁿ, p) = 1`.
3. Аналогічно, `q = 3·2ⁿ − 1` при `n ≥ 2` є непарним простого числа, тому `НСД(2ⁿ, q) = 1`.
4. Для `r = 9·2²ⁿ⁻¹ − 1` маємо непарне просте число, отже `НСД(2ⁿ, r) = 1`.
5. Числа `p` та `q` є різними простими числами, оскільки при `n ≥ 2` вираз `q = 3·2ⁿ − 1` строго більший за `p = 3·2ⁿ⁻¹ − 1`. Отже, `НСД(p, q) = 1`.

Всі множники у виразах `a = 2ⁿ · p · q` та `b = 2ⁿ · r` є попарно взаємно простими.

### Крок 1: Обчислення σ(a) та σ(b)

Застосуємо властивість мультиплікативності для обчислення `σ(a)`:

```
σ(a) = σ(2ⁿ · p · q)
     = σ(2ⁿ) · σ(p) · σ(q)                    [мультиплікативність для взаємно простих 2ⁿ, p, q]
     = (2ⁿ⁺¹ − 1) · (p + 1) · (q + 1)         [бо σ(2ⁿ) = 2ⁿ⁺¹ − 1, σ(p) = p + 1, σ(q) = q + 1]
```

Тепер обчислимо добуток дужок `(p + 1) · (q + 1)` у чисельному вигляді через показник `n`:

```
p + 1 = (3·2ⁿ⁻¹ − 1) + 1 = 3·2ⁿ⁻¹             [зведення протилежних доданків −1 та +1]
q + 1 = (3·2ⁿ − 1) + 1   = 3·2ⁿ               [зведення протилежних доданків −1 та +1]
```

Перемножимо ці два вирази:

```
(p + 1) · (q + 1) = (3 · 2ⁿ⁻¹) · (3 · 2ⁿ)
                  = (3 · 3) · (2ⁿ⁻¹ · 2ⁿ)      [перегрупування числових та степеневих множників]
                  = 9 · 2⁽ⁿ⁻¹⁾⁺ⁿ              [додавання показників степеня при однаковій основі 2]
                  = 9 · 2²ⁿ⁻¹                 [зведення (n − 1) + n = 2n − 1]
```

Звернемо увагу на означення числа `r = 9·2²ⁿ⁻¹ − 1`. Якщо додати до обох частин одиницю, отримуємо:

```
r + 1 = 9 · 2²ⁿ⁻¹                             [перенесення одиниці з лівої частини]
```

Отже, маємо тотожність:

```
(p + 1) · (q + 1) = r + 1                     [доведено алгебраїчний збіг добутків]
```

Підставимо отриманий вираз у формулу для `σ(a)`:

```
σ(a) = (2ⁿ⁺¹ − 1) · (r + 1)                    [заміна (p+1)(q+1) на (r+1)]
```

Тепер обчислимо `σ(b)` для числа `b = 2ⁿ·r`:

```
σ(b) = σ(2ⁿ · r)
     = σ(2ⁿ) · σ(r)                           [мультиплікативність для взаємно простих 2ⁿ та r]
     = (2ⁿ⁺¹ − 1) · (r + 1)                   [бо σ(2ⁿ) = 2ⁿ⁺¹ − 1 та σ(r) = r + 1]
```

Порівнюючи вирази для `σ(a)` та `σ(b)`, бачимо їхню абсолютну тотожність:

```
σ(a) = (2ⁿ⁺¹ − 1) · (r + 1) = σ(b)             [доведено першу рівність тотожності]
```

### Крок 2: Перевірка умови a + b = σ(a)

Тепер доведемо, що сума самих чисел `a + b` дорівнює цьому ж значенню `σ(a)`.

Запишемо суму `a + b` та винесемо спільний множник `2ⁿ`:

```
a + b = 2ⁿ·p·q + 2ⁿ·r
      = 2ⁿ · (p·q + r)                         [винесення спільного множника 2ⁿ за дужки]
```

Обчислимо добуток `p·q`:

```
p·q = (3·2ⁿ⁻¹ − 1) · (3·2ⁿ − 1)
    = (3·2ⁿ⁻¹)·(3·2ⁿ) − (3·2ⁿ⁻¹)·1 − 1·(3·2ⁿ) + 1·1    [розкриття дужок за дистрибутивним законом]
    = 9·2²ⁿ⁻¹ − 3·2ⁿ⁻¹ − 3·2ⁿ + 1              [перемноження 3·3 = 9 та 2ⁿ⁻¹·2ⁿ = 2²ⁿ⁻¹]
```

Тепер підставимо `p·q` у суму `p·q + r`:

```
p·q + r = (9·2²ⁿ⁻¹ − 3·2ⁿ⁻¹ − 3·2ⁿ + 1) + (9·2²ⁿ⁻¹ − 1)
        = (9·2²ⁿ⁻¹ + 9·2²ⁿ⁻¹) − 3·2ⁿ⁻¹ − 3·2ⁿ + (1 − 1)   [групування подібних доданків]
        = 18·2²ⁿ⁻¹ − 3·2ⁿ⁻¹ − 3·2ⁿ             [зведення 9 + 9 = 18 та скорочення 1 − 1 = 0]
```

Перетворимо доданок `18·2²ⁿ⁻¹`:

```
18 · 2²ⁿ⁻¹ = (9 · 2) · 2²ⁿ⁻¹ = 9 · 2²ⁿ         [винесення двійки в показник степеня]
```

Перетворимо доданок `3·2ⁿ`:

```
3 · 2ⁿ = 3 · (2 · 2ⁿ⁻¹) = 6 · 2ⁿ⁻¹            [виділення множника 2ⁿ⁻¹]
```

Підставимо ці вирази назад у `p·q + r`:

```
p·q + r = 9·2²ⁿ − 3·2ⁿ⁻¹ − 6·2ⁿ⁻¹
        = 9·2²ⁿ − (3 + 6)·2ⁿ⁻¹                [винесення спільного множника 2ⁿ⁻¹ за дужки]
        = 9·2²ⁿ − 9·2ⁿ⁻¹                       [додавання 3 + 6 = 9]
        = 9·2ⁿ⁻¹ · (2ⁿ⁺¹ − 1)                  [винесення 9·2ⁿ⁻¹ за дужки, бо 2²ⁿ / 2ⁿ⁻¹ = 2ⁿ⁺¹]
```

Згадаємо, що `9·2ⁿ⁻¹ · 2ⁿ = 9·2²ⁿ⁻¹ = r + 1`. Підставимо отриманий вираз у `a + b = 2ⁿ · (p·q + r)`:

```
a + b = 2ⁿ · [ 9·2ⁿ⁻¹ · (2ⁿ⁺¹ − 1) ]
      = (2ⁿ · 9·2ⁿ⁻¹) · (2ⁿ⁺¹ − 1)             [перестановка множників]
      = (9 · 2²ⁿ⁻¹) · (2ⁿ⁺¹ − 1)               [додавання показників степеня n + (n − 1) = 2n − 1]
      = (r + 1) · (2ⁿ⁺¹ − 1)                   [підстановка 9·2²ⁿ⁻¹ = r + 1]
```

Отримане значення повністю збігається з виразом для `σ(a)` та `σ(b)`:

```
a + b = (r + 1) · (2ⁿ⁺¹ − 1) = σ(a) = σ(b)     [доведено тотожність a + b = σ(a) = σ(b)]
```

Звідси маємо:
- `σ(a) − a = (a + b) − a = b`
- `σ(b) − b = (a + b) − b = a`

Теорему Сабіта ibn Кюрри **доведено повністю**.

## 3. Детальний числовий аналіз прикладів

Щоб унаочнити доведені тотожності, розберемо числову структуру двох найпростіших пар.

### Детальна перевірка для n = 2: пара (220, 284)

При `n = 2` отримуємо прості числа `p = 5`, `q = 11`, `r = 71`.

Числа пара дорівнюють `a = 2² · 5 · 11 = 220` та `b = 2² · 71 = 284`.

1. Розклад дільників для `a = 220 = 2² · 5 · 11`:
   За графічною сіткою розкладу, дільниками є всі можливі добутки `2ᵃ · 5ᵇ · 11ᶜ`, де `a ∈ {0,1,2}`, `b ∈ {0,1}`, `c ∈ {0,1}`.
   Сума дільників обчислюється за кроками:
   ```
   σ(220) = (1 + 2 + 4) · (1 + 5) · (1 + 11)   [підстановка суми дільників простих множників]
          = 7 · 6 · 12                         [обчислення суми в дужках]
          = 504                                [перемноження значень]
   ```
2. Розклад дільників для `b = 284 = 2² · 71`:
   Дільниками є добутки `2ᵃ · 71ᵇ`, де `a ∈ {0,1,2}`, `b ∈ {0,1}`.
   Сума дільників обчислюється за кроками:
   ```
   σ(284) = (1 + 2 + 4) · (1 + 71)            [підстановка суми дільників простих множників]
          = 7 · 72                             [обчислення суми в дужках]
          = 504                                [перемноження значень]
   ```
3. Сума самих чисел:
   ```
   a + b = 220 + 284 = 504
   ```

Рівність `σ(220) = σ(284) = 220 + 284 = 504` виконується арифметично бездоганно.

### Детальна перевірка для n = 4: пара (17 296, 18 416)

При `n = 4` отримуємо прості числа `p = 23`, `q = 47`, `r = 1151`.

Числа пара дорівнюють `a = 2⁴ · 23 · 47 = 17 296` та `b = 2⁴ · 1151 = 18 416`.

1. Обчислення `σ(17 296)` за кроками:
   ```
   σ(17 296) = σ(2⁴) · σ(23) · σ(47)           [мультиплікативність для взаємно простих множників]
             = (1 + 2 + 4 + 8 + 16) · (1 + 23) · (1 + 47)  [підстановка суми дільників простих множників]
             = 31 · 24 · 48                    [обчислення суми в дужках]
             = 35 712                          [перемноження значень]
   ```
2. Обчислення `σ(18 416)` за кроками:
   ```
   σ(18 416) = σ(2⁴) · σ(1151)                 [мультиплікативність для взаємно простих множників]
             = (1 + 2 + 4 + 8 + 16) · (1 + 1151) [підстановка суми дільників простих множників]
             = 31 · 1152                       [обчислення суми в дужках]
             = 35 712                          [перемноження значень]
   ```
3. Сума чисел:
   ```
   a + b = 17 296 + 18 416 = 35 712
   ```

Збіг до 35 712 є точним підтвердженням теореми.

## 4. Узагальнення Вальтера Борхо (1972)

Формула Сабіта вимагає, щоб парна частина мала вигляд `2ⁿ`. У 1972 році німецький математик Вальтер Борхо запропонував більш загальну теорему, яка дозволяє будувати дружні пари на основі довільного ядра `u`.

### Теорема Борхо

Нехай `u` — ціле число. Зафіксуємо додатне число `S = σ(u)`. Нехай `x` та `y` — натуральні числа, для яких алгебраїчні вирази:

```
p = (S + u) · x − 1
q = (S + u) · y − 1
r = (S + u)² · x · y − 1
```

одночасно є **простими числами**, які не ділять `u`. Якщо при цьому `σ(u)` задовольняє спеціальну умову сумісності дільників, то числа:

```
a = u · p · q
b = u · r
```

утворюють дружню пару.

Якщо підставити в теорему Борхо `u = 2ⁿ`, то `S = σ(2ⁿ) = 2ⁿ⁺¹ − 1`. Тоді `S + u = (2ⁿ⁺¹ − 1) + 2ⁿ = 3·2ⁿ − 1`. При `x = 1/2` та `y = 1` формула Борхо тотожно перетворюється на класичну теорему Сабіта.

Теорема Борхо відкрила можливість шукати дружні пари з новими ядрами `u`, що містять інші прості множники (наприклад, 3 або 5), пояснюючи глибоку алгебраїчну єдність між різними класами дружніх чисел.
