# Дружні числа

<preknowlist>

- [Досконалі числа](book:math/perfect-numbers) — числа, сума власних дільників яких дорівнює самому числу.
- [Надлишкові та недостатні числа](book:math/abundant-deficient-numbers) — класифікація чисел за співвідношенням суми дільників та самого числа.
- [Прості числа](book:math/prime-numbers) — цілі числа, що мають рівно два натуральні дільники.
</preknowlist>

Візьміть число 220 і випишіть усі його власні дільники — числа, менші за нього, на які воно ділиться без остачі: 1, 2, 4, 5, 10, 11, 20, 22, 44, 55 та 110. Складіть ці числа разом — ви отримаєте точно 284. Тепер виконайте зворотну дію: візьміть число 284 й зіберіть його власні дільники: 1, 2, 4, 71 та 142. Сума цих частин дає 220. Кожне з двох чисел виявляється точним відображенням внутрішньої будови іншого: власні частини одного складаються в цілість другого, і навпаки.

Таку пару натуральних чисел називають **дружніми числами** (лат. *numeri amicabiles*, грец. *φίλοι ἀριθμοί*). Якщо [досконале число](book:math/perfect-numbers) перебуває в абсолютній автономній рівновазі зі своїми власними дільниками, то дружні числа утворюють замкнений дует із двох елементів, де кожен живить сумою своїх дільників свого партнера. Це найпростіший приклад системного числового циклу, який відкриває глибокі зв'язки між мультиплікативною структурою дільників та їхнім додаванням.

## Арифметика взаємного відображення

Щоб описати цей механізм мовою математики, зручно запровадити оператор суми власних дільників. Нехай `σ(n)` — сума **всіх** натуральних дільників числа `n`, включаючи 1 та саме `n`. Власні дільники — це всі дільники, крім самого `n`. Тоді сума власних дільників (яку в математиці називають **аліквотною сумою**) виражається як:

```
s(n) = σ(n) − n
```

Для пари натуральних чисел `(a, b)` за умови `a ≠ b` рівність аліквотних сум означає взаємне замикання:

```
s(a) = b        (сума власних дільників a дорівнює b)
s(b) = a        (сума власних дільників b дорівнює a)
```

Підставивши означення `s(n) = σ(n) − n`, перепишемо ці дві вимоги через повну суму дільників:

```
σ(a) − a = b   →   σ(a) = a + b
σ(b) − b = a   →   σ(b) = a + b
```

Отримуємо строге й напрочуд прозоре критеріальне правило: **два різні натуральні числа a та b утворюють дружню пару тоді й лише тоді, коли сума всіх дільників кожної складової є однаковою і дорівнює сумі самих цих чисел:**

```
σ(a) = σ(b) = a + b
```

Для класичної першої пари (220, 284) маємо розпис:
```
σ(220) = 1 + 2 + 4 + 5 + 10 + 11 + 20 + 22 + 44 + 55 + 110 + 220 = 504
σ(284) = 1 + 2 + 4 + 71 + 142 + 284 = 504
a + b  = 220 + 284 = 504
```

Усі три значення ідеально збігаються: `504 = 504 = 504`.

### Фундаментальна асиметрія: надлишок і дефіцит

Поставимо питання: чи можуть два дружні числа бути однаковими за розміром або мати однакову класифікацію за відношенням суми дільників до числа? Відповідь негативна, і тут ховається важлива теорема про внутрішню симетрію пари.

За означенням, `a ≠ b`. Нехай для визначеності `a < b`. Поділимо рівність `σ(a) = a + b` та `σ(b) = a + b` на відповідні числа `a` та `b`:

```
σ(a) / a = (a + b) / a = 1 + b/a      [розділення дробу на суму часткових доданків]
σ(b) / b = (a + b) / b = 1 + a/b      [розділення дробу на суму часткових доданків]
```

Оскільки `a < b`, відношення `b/a > 1`, а відношення `a/b < 1`. Звідси випливає подвійна оцінка для відношення збагачення:

```
σ(a) / a = 1 + b/a > 1 + 1 = 2        →   σ(a) > 2a   (число a є НАДЛИШКОВИМ)
σ(b) / b = 1 + a/b < 1 + 1 = 2        →   σ(b) < 2b   (число b є НЕДОСТАТНІМ)
```

Це фундаментальний закон теорії дружніх чисел: **у будь-якій дружній парі (a, b) з умовою a < b менше число a ЗАВЖДИ є [надлишковим](book:math/abundant-deficient-numbers), а більше число b — ЗАВЖДИ є [недостатнім](book:math/abundant-deficient-numbers).**

![Асиметрія надлишковості та недостатності в дружній парі](/book/math/number-theory/amicable-numbers/img/abundance-asymmetry.svg)

*Менше число дружньої пари завжди надлишкове, а більше — завжди недостатнє: вони врівноважують одне одного відносно межі досконалості.*

Досконале число задовольняє `σ(n)/n = 2` — воно стоїть точно на вершині межі. Дружня пара розпадається на два боки цієї вершини: менше число `a` лежить на «надлишковому» схилі (`σ(a)/a > 2`), а більше число `b` — на «дефіцитному» схилі (`σ(b)/b < 2`). Вони ніби перекидають місток через точку досконалості, компенсуючи надлишок одного дефіцитом іншого.

> 🔧 **Навіщо це.** Таке розщеплення на надлишкове й недостатнє число визначає стратегію комп'ютерних алгоритмів пошуку. Програмі не потрібно перевіряти довільні пари чи шукати `s(a)` для всіх чисел поспіль: кандидат `a` обов'язково має бути надлишковим числом (`s(a) > a`), що одразу відсікає понад 75% усіх натуральних чисел ще до обчислення зворотного зв'язку `s(b)`.

## Теорема Сабіта ibn Кюрри та алгебраїчний генератор

Першу відповідь на питання, як систематично будувати такі числа, а не знаходити їх випадковим перебором, дав у IX столітті багдадський математик Сабіт ibn Кюрра. [📜 Історія пошуку дружніх чисел](book:math/amicable-numbers/hist-amicable-numbers.md) зберігає пам'ять про цей прорив, який перервав двотисячолітню павзу після відкриття єдиної античної пари.

Сабіт довів теорему, яка перетворює простоту трьох спеціальних чисел на гарантовану дружню пару.

### Правило генерації

Оберемо ціле число `n > 1`. Обчислимо три допоміжні значення `p`, `q` та `r`:

```
p = 3 · 2ⁿ⁻¹ − 1
q = 3 · 2ⁿ − 1
r = 9 · 2²ⁿ⁻¹ − 1
```

Якщо всі три числа `p`, `q` та `r` є **простими числами**, то наступні дві формули дають дружню пару:

```
a = 2ⁿ · p · q
b = 2ⁿ · r
```

![Генератор дружніх пар Сабіта ibn Кюрри](/book/math/number-theory/amicable-numbers/img/thabit-generator.svg)

*Схема генерації другої нетривіальної теми: три прості числа p, q, r породжують парну дружню пару за алгоритмом Сабіта.*

### Робочі приклади застосування

Перевіримо роботу генератора для кількох початкових `n`:

**1. Випадок n = 2:**
```
p = 3·2¹ − 1 = 5           (просте ✓)
q = 3·2² − 1 = 11          (просте ✓)
r = 9·2³ − 1 = 71          (просте ✓)

a = 2² · 5 · 11 = 4 · 55 = 220
b = 2² · 71      = 4 · 71 = 284
```
Отримуємо класичну античну пару (220, 284).

**2. Випадок n = 3:**
```
p = 3·2² − 1 = 11          (просте ✓)
q = 3·2³ − 1 = 23          (просте ✓)
r = 9·2⁵ − 1 = 287         (287 = 7 · 41 — СКЛАДЕНЕ ✗)
```
Оскільки `r` виявилося складеним числом, генератор зупиняється — при `n = 3` дружньої пари за цією схемою не існує.

**3. Випадок n = 4:**
```
p = 3·2³ − 1 = 23          (просте ✓)
q = 3·2⁴ − 1 = 47          (просте ✓)
r = 9·2⁷ − 1 = 1151        (просте ✓)

a = 2⁴ · 23 · 47 = 16 · 1081 = 17 296
b = 2⁴ · 1151    = 16 · 1151 = 18 416
```
Цю другу в історії пару (17 296, 18 416) у XIII столітті відкрив арабський учений al-Фарісі, а в 1636 році незалежно перевідкрив П'єр де Ферма.

**4. Випадок n = 7:**
```
p = 3·2⁶ − 1 = 191         (просте ✓)
q = 3·2⁷ − 1 = 383         (просте ✓)
r = 9·2¹³ − 1 = 73 727     (просте ✓)

a = 2⁷ · 191 · 383 = 9 363 584
b = 2⁷ · 73 727    = 9 437 056
```
Цю третю пару відкрив Рене Декарт у 1638 році.

### Чому працює формула Сабіта

Аналітика доведення тримається на мультиплікативності суми дільників `σ`. Згадаймо, що для простого числа `p` сума дільників `σ(p) = p + 1`, а для степеня двійки `σ(2ⁿ) = 2ⁿ⁺¹ − 1`.

Розпишемо `σ(a)` для `a = 2ⁿ·p·q`:

```
σ(a) = σ(2ⁿ) · σ(p) · σ(q)
     = (2ⁿ⁺¹ − 1) · (p + 1) · (q + 1)        [мультиплікативність σ для взаємно простих множників]
```

Обчислимо добуток `(p + 1)(q + 1)`:
```
p + 1 = 3·2ⁿ⁻¹
q + 1 = 3·2ⁿ
(p + 1)(q + 1) = (3·2ⁿ⁻¹) · (3·2ⁿ) = 9 · 2²ⁿ⁻¹
```

Але за означенням `r = 9·2²ⁿ⁻¹ − 1`, тож `r + 1 = 9·2²ⁿ⁻¹`. Отже, `(p + 1)(q + 1) = r + 1`!

Підставивши це значення у `σ(a)`, отримуємо:
```
σ(a) = (2ⁿ⁺¹ − 1) · (r + 1)
```

Тепер обчислимо `σ(b)` для `b = 2ⁿ·r`:
```
σ(b) = σ(2ⁿ) · σ(r) = (2ⁿ⁺¹ − 1) · (r + 1)
```

Значення `σ(a)` та `σ(b)` алгебраїчно збігаються. Повна індуктивна перевірка доводить, що їхня сума також дорівнює `a + b`. Детальні алгебраїчні перетворення та узагальнення Вальтера Борхо винесені в [🧮 Теорема Сабіта ibn Кюрри та алгебра суми дільників](book:math/amicable-numbers/math-thabit-rule.md).

Обмеження правила Сабіта в тому, що воно вимагає **одночасної** простоти трьох чисел `p, q, r`. Для `n > 7` триплети простих чисел стають винятково рідкісними — до `n = 100 000` більше немає жодної потрійної простої трійки. Математика потребувала більш загальних методик.

## Анатомія пар: парність, структури та нерозв'язані таємниці

Пари, згенеровані формулою Сабіта, мають спільний канонічний вигляд: обидва числа є парними і мають однаковий множник `2ⁿ`. Проте загальна множина дружніх чисел значно різноманітніша й містить глибокі структури.

### Парність дружніх пар

За парністю елементів усі можливі дружні пари `(a, b)` поділяються на три класи:
1. **Парно-парні пари (Even-Even):** обидва числа `a` та `b` є парними. Це переважна більшість знайдених пар (понад 95%). Приклади: (220, 284), (1184, 1210), (17 296, 18 416).
2. **Непарно-непарні пари (Odd-Odd):** обидва числа `a` та `b` є непарними. Першу таку пару виявив Леонард Ойлер у 1747 році:
   ```
   a = 122 265 = 3³ · 5 · 7 · 13 · 71
   b = 124 155 = 3³ · 5 · 17 · 547
   ```
   Власні дільники обох чисел складаються виключно з непарних множників і дають точну взаємну суму.
3. **Змішані пари / Різнопарні (Even-Odd):** одне число парне, а інше — непарне.

> ❓ **Велике відкрите питання:** Чи існує хоча б одна дружня пара різної парності (одне парне, інше непарне)?

Досі не знайдено **жодного** прикладу такої пари. Більше того, якщо така пара `(a, b)` існує з парним `a` та непарним `b`, то сума `a + b` має бути **непарною**. А отже, сума дільників `σ(a) = a + b` повинна бути непарним числом.

З [Основної теореми арифметики](book:math/fundamental-theorem-arithmetic) відомо, що сума дільників `σ(n)` є непарною **тоді й лише тоді**, коли `n` є або точним квадратом, або подвоєним точним квадратом! Це накладає колосальне затискання на точну структуру потенційного парного числа `a`, через що багатьом математикам здається, що різнопарних дружніх чисел взагалі не існує. Проте строге спростування залишається невіднайденим.

### Проблема спільних дільників

Майже всі відомі дружні пари мають великий спільний множник: `НСД(a, b) > 1`. Наприклад, для (220, 284) `НСД(220, 284) = 4 = 2²`. Для непарної пари Ойлера `НСД(122 265, 124 155) = 3³ · 5 = 135`.

Друге відкрите питання теорії чисел: **чи існують взаємно прості дружні числа (тобто такі, у яких `НСД(a, b) = 1`)?**
Комп'ютерні перевірки довели, що якщо взаємно проста пара існує, то обидва числа в ній мають перевищувати `10¹⁰`.

## Послідовності аліквот та орбіти чисел

Дружні числа — це не ізольований феномен, а частковий випадок динамічного процесу ітерації оператора `s(n) = σ(n) − n`.

Якщо ми візьмемо довільне початкове число `n₀` й будемо послідовно застосовувати до нього обчислення суми власних дільників:

```
n₀ ↦ n₁ = s(n₀) ↦ n₂ = s(n₁) ↦ n₃ = s(n₂) ↦ …
```

ми отримаємо числову траєкторію, яку називають **аліквотною послідовністю** (*aliquot sequence*).

![Долі чисел під дією оператора s(n)](/book/math/number-theory/amicable-numbers/img/aliquot-trajectories.svg)

*Чотири траєкторії аліквотних послідовностей: згасання до 1, нерухома точка (досконале), 2-цикл (дружні числа) та k-цикл (компанійські числа).*

Аналіз орбіт аліквотних послідовностей показує чотири принципово різні фінали:

1. **Згасання до 1 (Термінація):** Послідовність потрапляє в [просте число](book:math/prime-numbers) `p`, для якого `s(p) = 1`, а далі `s(1) = 0`, і процес зупиняється. Це найпоширеніша доля для більшості натуральних чисел. Приклад для `n = 12`:
   ```
   12 ↦ 16 ↦ 15 ↦ 9 ↦ 4 ↦ 3 ↦ 1 ↦ 0
   ```
2. **Нерухома точка (1-цикл):** Послідовність потрапляє в [досконале число](book:math/perfect-numbers), де `s(n) = n`. Обертання зациклюється на одному елементі:
   ```
   6 ↦ 6 ↦ 6 ↦ 6 ↦ …
   ```
3. **2-цикл (Дружні числа):** Послідовність зациклюється між двома числами `a` та `b`, де `s(a) = b` та `s(b) = a`:
   ```
   220 ↦ 284 ↦ 220 ↦ 284 ↦ …
   ```
4. **k-цикл з k ≥ 3 (Компанійські числа):** Послідовність утворює замкнений орбітальний цикл із трьох або більше елементів. Такі числа називають **компанійськими числами** (*sociable numbers*). Перший 5-елементний цикл виявив у 1918 році Поль Пуле (*Paul Poulet*):
   ```
   12 496 ↦ 14 288 ↦ 15 472 ↦ 14 536 ↦ 14 264 ↦ 12 496
   ```

### Гіпотеза Каталана–Діксона та п'ять некерованих послідовностей

У 1888 році Ежен Каталан висловив припущення, що **кожна** аліквотна послідовність зрештою зациклюється (потрапляє в 1-, 2- чи `k`-цикл) або обривається на 0. Докладніше цю думку сформулював Леонард Діксон у 1913 році.

Проте сучасні чисельні експерименти ставлять цю гіпотезу під сумнів. Існують так звані «некеровані послідовності», для яких аліквотна траєкторія обчислена вже на сотні тисяч кроків до велетенських чисел із сотнями знаків, і вона продовжує зростати без жодних ознак зациклення чи згасання.

П'ять найменших некерованих початкових чисел до 1000 — це числа **276, 552, 564, 660 та 960**.
Наприклад, для `n = 276` послідовність швидко виходить за межі `10¹⁰⁰`, створюючи враження необмеженого зростання. Чи прямує послідовність для 276 до нескінченності — одна з найбільших нерозв'язаних таємниць сучасної алгоритмічної теорії чисел.

## Щільність, алгоритми пошуку та межі знань

Скільки існує дружніх пар і як часто вони трапляються серед натуральних чисел?

### Асимптотична щільність Поль Ердеша

У 1955 році видатний угорський математик Пал Ердеш (*Paul Erdős*) довів фундаментальну теорему про розподіл дружніх чисел: **асимптотична щільність дружніх чисел дорівнює нулю.**

Це означає, що якщо позначити через `A(X)` кількість усіх дружніх чисел, що не перевищують `X`, то відношення цієї кількості до загального обсягу діапазону прямує до нуля при зростанні `X`:

```
lim [A(X) / X] = 0     при X → ∞
```

Пізніше у 1981 році Карл Померанс (*Carl Pomerance*) суттєво уточнив верхню межу для кількості дружніх чисел `A(X)`, довівши, що для достатньо великих `X`:

```
A(X) < X · exp( − (log X · log log X)^(1/3) )
```

Дружні числа є надзвичайно рідкісними об'єктами у числовому океані. Попри це, математики переконані, що множина дружніх пар є **нескінченною**, хоча строге математичне доведення цього факту досі не знайдене.

### Чисельні алгоритми пошуку

Як ефективно знаходити дружні числа за допомогою комп'ютера? [⚙️ Пошук дружніх пар](book:math/amicable-numbers/proj-amicable-search.md) демонструє еволюцію від поелементного перебору до паралельного адитивного решета.

Прямий алгоритм перевіряє кожне число `a` шляхом розкладу на дільники за `O(√a)`. Загальний час пошуку в діапазоні до `N` становить `O(N √N)`.

Натомість адитивне решето суми дільників будує таблицю `s[n]` для всіх чисел одразу, використовуючи ідею [Простих чисел](book:math/prime-numbers):

```
для кожного d від 1 до N/2:
    для кожного кратного m = 2d, 3d, 4d, ... в межах N:
        s[m] += d
```

Цей підхід знижує складність до **O(N log N)**, дозволяючи просканувати мільйонні діапазони за частки секунди.

Завдяки сучасним обчислювальним мережам станом на сьогодні науці відомо понад **1.2 мільярда** дружніх пар. Проте кожен новий виявлений дует лише підтверджує: за простим співвідношенням суми частин ховаються глибокі непорушні закони арифметичної гармонії Всесвіту.
