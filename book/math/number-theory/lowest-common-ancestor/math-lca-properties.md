# 🧮 Математичні властивості та алгебраїчні структури LCA

Ця математична вставка розкриває суворі алгебраїчні, метричні та комбінаторні властивості оператора найменшого спільного предка, доводячи його еквівалентність супремуму у напівґратах, метричну формулу відстаней на деревах та зв'язок з деревними медіанами й послідовностями Фарея.

---

### 1. Алгебраїчна структура напівґрати (Lower Semilattice)

Нехай `T = (V, E)` — орієнтоване кореневе дерево з множиною вершин `V` та коренем `R`. Визначимо бінарне відношення часткового порядку `u ≼ v` на множині вершин `V`. Ми кажемо, що вершина `u` передує вершині `v` у сенсі предківства (`u ≼ v`), якщо вершина `u` лежить на єдиному простому низхідному шляху від кореня `R` до вершини `v`. При цьому корінь `R` виступає найменшим елементом для всієї множини: `R ≼ u` виконується для будь-якої вершини `u ∈ V`.

Оператор найменшого спільного предка `LCA: V × V → V` є точним алгебраїчним супремумом (операцією точної верхньої межі `join` або `∨`) у цій частково впорядкованій множині `(V, ≼)`.

Для будь-яких довільних вершин `u, v, w ∈ V` оператор `LCA` задовольняє наступні класичні аксіоми математичної теорії напівґрат:

1. **Ідемпотентність:**
   ```
   LCA(u, u) = u
   ```
   *Доведення:* Розглянемо множину всіх предків вершини `u`, яку позначимо через `Ancestors(u)`. Оскільки вершина `u` за визначенням вважається предком самої себе, множина `Ancestors(u) ∩ Ancestors(u) = Ancestors(u)` містить `u` як свій унікальний найглибший елемент. Отже, найменшим спільним предком вершини `u` та її самої є сам вузол `u`.

2. **Комутативність:**
   ```
   LCA(u, v) = LCA(v, u)
   ```
   *Доведення:* Перетин двох множин предків `Ancestors(u) ∩ Ancestors(v)` є симетричною теоретико-множинною операцією, яка не залежить від порядку вибору аргументів. Точна верхня межа цієї множини перетину тотожно збігається в обох випадках.

3. **Асоціативність:**
   ```
   LCA(u, LCA(v, w)) = LCA(LCA(u, v), w)
   ```
   *Доведення:* Обчислимо множину спільних предків для трійки вершин `u, v, w`, тобто `A_{uvw} = Ancestors(u) ∩ Ancestors(v) ∩ Ancestors(w)`. У кореневому дереві множина предків будь-якої вершини утворює строго впорядкований лінійний ланцюг від кореня `R` до цієї вершини. Перетин трьох таких ланцюгів також є лінійним ланцюгом, оскільки всі вони починаються в спільному корені `R`. Найглибший елемент цього спільного ланцюга є єдиним і дорівнює як `LCA(u, LCA(v, w))`, так і `LCA(LCA(u, v), w)`.

4. **Монотонність та поглинання:**
   Якщо `u ≼ v` (тобто вершина `u` є предком `v`), то виконується рівність поглинання:
   ```
   LCA(u, v) = u
   ```

Завдяки виконанню цих чотирьох властивостей алгебраїчна система `(V, LCA)` утворює комбінаторну **нижню напівґрату**.

### 2. Метричні простори та ультраметрика на деревах

Визначимо функцію глибини вершин `depth: V → ℕ₀` як довжину (кількість ребер) унікального шляху від кореня `R` до вершини `x`, причому для самого кореня `depth(R) = 0`.

Визначимо функцію топологічної відстані між довільною парою вершин `u, v ∈ V`:
```
dist(u, v) = depth(u) + depth(v) − 2 · depth(LCA(u, v))
```

#### Доведення метричних властивостей `dist(u, v)`

Щоб довести, що математична пара `(V, dist)` утворює повноцінний метричний простір, необхідно строго перевірити виконання трьох фундаментальних аксіом метрики:

1. **Невід'ємність та тотожність:**
   Оскільки найменший спільний предок `w = LCA(u, v)` лежить на шляху від кореня до обох вершин `u` та `v`, його глибина не перевищує глибину жодної з них: `depth(w) ≤ depth(u)` та `depth(w) ≤ depth(v)`. Звідси випливає:
   ```
   depth(u) − depth(w) ≥ 0
   depth(v) − depth(w) ≥ 0
   dist(u, v) = (depth(u) − depth(w)) + (depth(v) − depth(w)) ≥ 0
   ```
   Рівність `dist(u, v) = 0` можлива тоді й лише тоді, коли `depth(u) = depth(w)` та `depth(v) = depth(w)`. Оскільки на дереві існує лише одна вершина даної глибини на низхідній гілці, це рівносильно умові `u = v = w`.

2. **Симетрія:**
   Рівність `dist(u, v) = dist(v, u)` безпосередньо випливає з комутативності оператора `LCA(u, v) = LCA(v, u)` та симетрії додавання дійсних чисел.

3. **Нерівність трикутника:**
   Для будь-яких трьох вершин `u, v, w ∈ V` виконується нерівність:
   ```
   dist(u, w) ≤ dist(u, v) + dist(v, w)
   ```
   *Доведення:* На дереві між будь-якими двома вершинами існує єдиний простий шлях. Об'єднання унікального шляху від `u` до `v` та унікального шляху від `v` до `w` утворює зв'язний підграф, що з'єднує `u` та `w`. Довжина найкоротшого шляху між `u` та `w` за визначенням не може перевищувати сумарну довжину цих двох шляхів.

#### Ультраметрична властивість (Чотиривершинна умова)

Для будь-яких чотирьох вершин `a, b, c, d ∈ V` на дереві зважені суми парних відстаней задовольняють так звану чотиривершинну умову ультраметричності:
```
dist(a, b) + dist(c, d) ≤ max( dist(a, c) + dist(b, d),  dist(a, d) + dist(b, c) )
```
Дві найбільші суми серед трьох можливих парних комбінацій `dist(a, b) + dist(c, d)`, `dist(a, c) + dist(b, d)` та `dist(a, d) + dist(b, c)` обов'язково рівні між собою. Це підтверджує, що топологічна відстань на дереві формує строгий ультраметричний простір.

### 3. Деревна медіана та центральна вершина трійки

Для довільних трьох вершин `u, v, w ∈ V` існує єдина вершина `m ∈ V` (яка називається **медіаною трьох вершин**), що лежить на перетині трьох простих шляхів між цими вершинами: `Path(u, v) ∩ Path(v, w) ∩ Path(w, u) = {m}`.

#### Теорема про ядро медіани

Вершина-медіана `m` конструктивно визначається через парування оператора `LCA`:
```
m = SelectDeepest( LCA(u, v), LCA(v, w), LCA(w, u) )
```
де функція `SelectDeepest` вибирає з трьох кандидатів вершину з максимальним значенням глибини `depth`.

*Доведення:* Розглянемо трійку предків `w_1 = LCA(u, v)`, `w_2 = LCA(v, w)`, `w_3 = LCA(w, u)`. Принаймні два з цих трьох значень є тотожно рівними між собою, а третє значення розташоване строго глибше (або дорівнює їм). 

Тобто серед трьох вершин `w_1, w_2, w_3` одна завжди домінує за глибиною і є унікальною точкою розгалуження трьох шляхів. Ця вершина мінімізує суму відстаней до трьох вузлів: `dist(u, m) + dist(v, m) + dist(w, m)`, виконуючи роль центру Медіанного графа.

### 4. НСК та НСД у ґратах дільників `(ℕ, |)`

Розглянемо множину натуральних чисел `ℕ`, частково впорядковану відношенням подільності `a | b` (число `a` ділить `b` без остачі).

Згідно з основною теоремою арифметики, кожне натуральне число `n > 1` однозначно розкладається на канонічний добуток простих множників:
```
n = ∏_{i=1}^{k} p_i^{α_i(n)}
```
де `p_i` — прості числа, а `α_i(n) ≥ 0` — відповідні цілі показники степенів.

#### Алгебраїчна еквівалентність

Для двох чисел `a, b ∈ ℕ`:
1. **Найбільший спільний дільник (Meet / Infimum / GLB):**
   ```
   НСД(a, b) = ∏_{i=1}^{k} p_i^{\min(α_i(a), α_i(b))}
   ```
2. **Найменше спільне кратне (Join / Supremum / LCA):**
   ```
   НСК(a, b) = ∏_{i=1}^{k} p_i^{\max(α_i(a), α_i(b))}
   ```

#### Доведення тотожності зв'язку

Для будь-яких показників степенів `α, β ∈ ℕ₀` виконується арифметична тотожність:
```
min(α, β) + max(α, β) = α + β
```

Підставляючи цю тотожність у розклад на прості дільники, отримуємо фундаментальне алгебраїчне співвідношення для будь-яких натуральних чисел `a, b ∈ ℕ`:
```
НСД(a, b) · НСК(a, b) = a · b
```

Порівняємо це з метричною формулою відстані на дереві `dist(u, v) = depth(u) + depth(v) − 2 · depth(LCA(u, v))`. 

Якщо перевести формулу подільності у логарифмічний простір показників степенів:
```
log(НСК(a, b)) = log(a) + log(b) − log(НСД(a, b))
```
Ми бачимо точну алгебраїчну двоїстість: операція `НСК` виступає прямим аналогом найменшого спільного предка (LCA) у векторній ґратці степенів простих множників.

### 5. Дерева Стерн-Броко та найближчий спільний раціональний предок

У двійковому дереві Стерн-Броко (Stern-Brocot Tree) кожне додатне раціональне число `p/q` в нескорочуваному вигляді займає унікальну позицію.

Корнем дерева є медианта `1/1`. Для будь-яких двох раціональних чисел `a = p_1/q_1` та `b = p_2/q_2` їхній найменший спільний предок у дереві Стерн-Броко `LCA(a, b)` відповідає **найпростішому раціональному числу** (з найменшим знаменником), яке лежить у відкритому інтервалі між `a` та `b`.

Ця властивість відкриває прямокутний зв'язок між обчисленням LCA у комбінаторних двійкових пошукових деревах та апроксимацією дійсних чисел ланцюговими дробами й послідовностями Фарея.
