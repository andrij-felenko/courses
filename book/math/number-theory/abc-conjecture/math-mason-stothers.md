# 🧮 Теорема Мейсона — Стозерса: поліноміальний аналог ABC

Ця вставка містить повне виведення, алгебраїчне доведення та детальний аналіз теореми Мейсона — Стозерса (1983–1984) — точного поліноміального аналогу гіпотези ABC для кільця многочленів `C[t]`. Вивчення поліноміального випадку є ключем до розуміння того, чому гіпотеза ABC є арифметично природною: у світі многочленів ролі логарифма числа та його радикала переходять відповідно до степеня полінома та кількості його різних коренів.

## Алгебраїчний контекст: кільце багаточленів `C[t]`

Щоб зрозуміти зв'язок між многочленами та цілими числами, розглянемо алгебраїчну структуру кільця `C[t]` — многочленів від однієї змінної `t` з комплексними коефіцієнтами.

Кільце `C[t]` має багато спільних властивостей з кільцем цілих чисел `Z`:
1. **Евклідове кільце:** Для будь-яких двох многочленів `A(t)` та `B(t) ≠ 0` існує ділення з остачею: `A = Q · B + R`, де `deg(R) < deg(B)`.
2. **Факторіальність (Unique Factorization Domain):** За основною теоремою алгебри, кожен некопостійний многочлен розкладається на добуток лінійних множників `(t - αᵢ)`, де `αᵢ ∈ C` — комплексні корені.
3. **Прості елементи:** Простими елементами у `C[t]` є незвідні многочлени першого степеня `(t - α)`.

Проте кільце `C[t]` має фундаментальну перевагу над `Z`: воно володіє оператором **диференціювання** `d/dt`, який задовольняє правила Лейбніца та лінійності:

```
(P + Q)' = P' + Q'
(P · Q)' = P' · Q + P · Q'
```

Диференціювання дозволяє точним чином контролювати кратність коренів багаточлена, що робить поліноміальний аналог гіпотези ABC абсолютно строгою теоремою.

## Сформулювання теореми Мейсона — Стозерса

Нехай `A(t)`, `B(t)`, `C(t)` — некопостійні ненульові многочлени над полем комплексних чисел `C`, які є взаємно простими в сукупності (`НСД(A, B, C) = 1`) та задовольняють тотожність:

```
A(t) + B(t) = C(t)
```

Позначимо через `N₀(P)` кількість **різних** комплексних коренів многочлена `P(t)` (без урахування їхньої кратності). Формально, якщо `P(t) = c · ∏ (t - αᵢ)ᵏⁱ`, то `N₀(P)` є кількістю різних елементів `αᵢ`.

Позначимо через `deg(P)` алгебраїчний степінь многочлена `P(t)`.

> **Теорема Мейсона — Стозерса (1983–1984):** Для степенів взаємно простих многочленів `A(t)`, `B(t)`, `C(t)`, що задовольняють `A + B = C`, виконується строга нерівність:
>
> ```
> max(deg A, deg B, deg C) ≤ N₀(A · B · C) - 1
> ```
>
> де `N₀(A · B · C) = N₀(A) + N₀(B) + N₀(C)` внаслідок взаємної простоти многочленів.

## Покрокове виведення та доведення

Для доведення застосуємо диференціальне числення та властивості Вронськіана.

### Крок 1: Утворення раціональних функцій

Розділимо початкову рівність `A(t) + B(t) = C(t)` на `C(t)` (це припустимо, оскільки `C(t) ≠ 0`):

```
A(t)/C(t) + B(t)/C(t) = 1
```

Покладемо `f(t) = A(t)/C(t)` та `g(t) = B(t)/C(t)`. Тоді рівність набуває вигляду:

```
f(t) + g(t) = 1
```

### Крок 2: Диференціювання та визначення Вронськіана

Продиференціюємо отриману рівність відносно змінної `t`:

```
f'(t) + g'(t) = 0  ⇒  f'(t) = -g'(t)
```

Обчислимо похідну раціональної функції `f(t) = A/C` за правилом частки:

```
f'(t) = (A'·C - A·C') / C²
```

Аналогічно для `g(t) = B/C`:

```
g'(t) = (B'·C - B·C') / C²
```

Оскільки `f'(t) = -g'(t)`, прирівняємо отримані вирази:

```
(A'·C - A·C') / C² = -(B'·C - B·C') / C²
```

Помножимо обидві частини на `C²`:

```
A'·C - A·C' = B'·C - B·C'
```

Визначимо диференціальний визначник (Вронськіан) двох многочленів `W(A, B)`:

```
W = A·B' - A'·B
```

Скориставшись співвідношенням `B = C - A`, підставимо `B` у вираз для `W`:

```
W = A·(C - A)' - A'·(C - A)     [підстановка B = C - A у вираз W = A·B' - A'·B]
  = A·(C' - A') - A'·C + A'·A   [лінійність похідної (C - A)' = C' - A' та розкриття дужок]
  = A·C' - A'·C                 [скорочення протилежних доданків A·A' - A'·A = 0]
```

Таким чином, Вронськіан `W` задовольняє симетричні рівності:

```
W = A·B' - A'·B = B·C' - B'·C = C·A' - C'·A
```

### Крок 3: Оцінка степеня Вронськіана зверху

Вронськіан `W = A·B' - A'·B` є многочленом. Знайдемо верхню межу його степеня.
Степінь добутку `A·B'` дорівнює `deg(A) + (deg(B) - 1)`.
Степінь добутку `A'·B` дорівнює `(deg(A) - 1) + deg(B)`.
Отже, степінь різниці задовольняє нерівність:

```
deg(W) ≤ deg(A) + deg(B) - 1
```

Зауважимо, що `W(t)` не є тотожним нулем (`W ≢ 0`). Якби `W ≡ 0`, то `A·B' - A'·B = 0 ⇒ (A/B)' = 0`, що означало б `A/B = const`, а це суперечить умові взаємної простоти та некопостійності `A` і `B`.

### Крок 4: Лема про кратність коренів Вронськіана

Сформулюємо та доведемо ключову лему про ділимість Вронськіана на лінійні множники.

> **Лема:** Якщо `α` є коренем многочлена `A(t)` кратності `k ≥ 1`, то `(t - α)ᵏ⁻¹` ділить Вронськіан `W(t)`.

*Доведення леми:*
Нехай `A(t) = (t - α)ᵏ · P(t)`, де `P(α) ≠ 0`.
Знайдемо похідну `A'(t)` за правилом добутку:

```
A'(t) = k·(t - α)ᵏ⁻¹ · P(t) + (t - α)ᵏ · P'(t)     [похідна степеня та правилом добутку]
      = (t - α)ᵏ⁻¹ · [k·P(t) + (t - α)·P'(t)]      [винесення спільного множника (t - α)ᵏ⁻¹]
```

Бачимо, що `(t - α)ᵏ⁻¹` є спільним дільником як `A(t)`, так і `A'(t)`.
Підставивши `A` та `A'` у вираз для Вронськіана `W = A·C' - A'·C`, маємо:

```
W(t) = (t - α)ᵏ⁻¹ · [ (t - α)·P(t)·C'(t) - (k·P(t) + (t - α)·P'(t))·C(t) ]
```

Отже, `(t - α)ᵏ⁻¹` строго ділить `W(t)`. Лему доведено.

Оскільки `A`, `B` та `C` є взаємно простими в сукупності, вони не мають спільних комплексних коренів. Жоден корінь `A` не може бути коренем `B` чи `C`. Тому лінійні множники, утворені з коренів `A`, `B` та `C`, є взаємно простими між собою.

Підсумуємо кратності коренів `W(t)` за всіма коренями трьох многочленів:

- Внесок усіх коренів `A`: `∑ (k_{A,i} - 1) = deg(A) - N₀(A)`
- Внесок усіх коренів `B`: `∑ (k_{B,j} - 1) = deg(B) - N₀(B)`
- Внесок усіх коренів `C`: `∑ (k_{C,m} - 1) = deg(C) - N₀(C)`

Оскільки `W(t)` ділиться на добуток усіх цих взаємно простих множників, його степінь задовольняє нижню межу:

```
deg(W) ≥ (deg(A) - N₀(A)) + (deg(B) - N₀(B)) + (deg(C) - N₀(C))
```

### Крок 5: Зведення нерівностей та завершення доведення

Об'єднаємо оцінку степеня `W(t)` зверху (Крок 3) та знизу (Крок 4):

```
deg(A) + deg(B) + deg(C) - N₀(A) - N₀(B) - N₀(C) ≤ deg(W) ≤ deg(A) + deg(B) - 1
```

Скоротиємо однакові доданки `deg(A) + deg(B)` з обох боків нерівності:

```
deg(C) - N₀(A) - N₀(B) - N₀(C) ≤ -1
```

Перенесемо суму кількості коренів у праву частину:

```
deg(C) ≤ N₀(A) + N₀(B) + N₀(C) - 1
```

Оскільки `N₀(A·B·C) = N₀(A) + N₀(B) + N₀(C)`, отримуємо:

```
deg(C) ≤ N₀(A·B·C) - 1
```

Внаслідок повної симетрії початкового рівняння `A + B - C = 0`, аналогічні нерівності виконуються для `deg(A)` та `deg(B)`.
Отже:

```
max(deg A, deg B, deg C) ≤ N₀(A·B·C) - 1
```

Теорему доведено повністю.

## Практичні числові приклади та межі тотожності

Розглянемо два детальних приклади застосування теореми Мейсона — Стозерса.

### Приклад 1: Випадок граничної рівності

Розглянемо трійку многочленів:

```
A(t) = 1
B(t) = tⁿ
C(t) = tⁿ + 1
```

Перевіримо умови теореми для `n = 4`:

```
A(t) = 1          ⇒ deg(A) = 0,  N₀(A) = 0
B(t) = t⁴         ⇒ deg(B) = 4,  N₀(B) = 1 (корінь t = 0 кратності 4)
C(t) = t⁴ + 1     ⇒ deg(C) = 4,  N₀(C) = 4 (чотири різні комплексні корені e^(iπ(2k+1)/4))
```

Обчислимо сумарну кількість коренів добутку:

```
N₀(A · B · C) = N₀(A) + N₀(B) + N₀(C) = 0 + 1 + 4 = 5
```

Максимальний степінь многочленів дорівнює `max(0, 4, 4) = 4`.
Перевіримо нерівність Мейсона — Стозерса:

```
4 ≤ 5 - 1  ⇒  4 ≤ 4
```

Нерівність перетворюється на точну рівність! Це доводить, що константа `-1` у теоремі Мейсона — Стозерса є оптимальною і не може бути покращена.

### Приклад 2: Небанальна кубічна тотожність

Розглянемо тотожність двох кубів:

```
A(t) = (t - 1)³ = t³ - 3t² + 3t - 1
B(t) = (t + 1)³ = t³ + 3t² + 3t + 1
C(t) = A(t) + B(t) = 2t³ + 6t = 2t(t² + 3)
```

Обчислимо степені та кількість коренів:
- `A(t) = (t - 1)³`: `deg(A) = 3`, корінь `t = 1` кратності 3 `⇒ N₀(A) = 1`.
- `B(t) = (t + 1)³`: `deg(B) = 3`, корінь `t = -1` кратності 3 `⇒ N₀(B) = 1`.
- `C(t) = 2t(t - i√3)(t + i√3)`: `deg(C) = 3`, три різні корені `0, i√3, -i√3 ⇒ N₀(C) = 3`.

Сумарна кількість коренів добутку:

```
N₀(A · B · C) = N₀(A) + N₀(B) + N₀(C) = 1 + 1 + 3 = 5
```

Максимальний степінь `max(3, 3, 3) = 3`.
Перевіримо нерівність Мейсона — Стозерса:

```
3 ≤ 5 - 1  ⇒  3 ≤ 4
```

Нерівність виконується із запасом у 1 одиницю.

## Геометрична інтерпретація: формула Рімана — Гурвіца

Теорема Мейсона — Стозерса має глибоке геометро-топологічне тлумачення.

Раціональну функцію `f(t) = A(t)/C(t)` можна розглядати як голоморфне відображення з комплексної сфери Рімана `P¹(C)` на себе:

```
f: P¹(C) → P¹(C)
```

Степінь цього відображення дорівнює `d = max(deg A, deg C)`. 
Точки `α ∈ P¹(C)`, де `f(α) ∈ {0, 1, ∞}`, відповідають кореням многочленів `A(t)` (корені `f = 0`), `B(t)` (корені `f = 1`, оскільки `A + B = C ⇒ A/C + B/C = 1`) та `C(t)` (полюси `f = ∞`).

За **формулою Рімана — Гурвіца** для розгалужених накриттів сфери, сумарна кратність розгалуження відображення `f` задовольняє точну топологічну рівність. Нерівність Мейсона — Стозерса еквівалентна твердженню, що відображення `P¹ → P¹`, яке має лише 3 точки розгалуження `{0, 1, ∞}`, обмежене евклідовою характеристикою сфери `χ(P¹) = 2`.

Це пояснює, чому теорема Мейсона — Стозерса є настільки фундаментальною: вона є алгебраїчним відображенням того факту, що комплексна сфера має род `g = 0`.

## Порівняння `C[t]` та `Z`: чому цілочисельний випадок складніший

Порівняємо ключові риси двох структур:

| Властивість | Кільце багаточленів `C[t]` | Кільце цілих чисел `Z` |
| :--- | :--- | :--- |
| **Міра величини** | Степінь `deg(P)` | Натуральний логарифм `log(n)` |
| **Мультиплікативний носій** | Кількість коренів `N₀(P)` | Логарифм радикала `log(rad(n))` |
| **Диференціальний оператор** | Похідна `d/dt` | **Відсутній у звичайній арифметиці** |
| **Формулювання ABC** | `deg(C) ≤ N₀(ABC) - 1` | `log(c) < log(C(ε)) + (1+ε) log(rad(abc))` |
| **наявність параметра `ε`** | **Не потрібен (`ε = 0`)** | **Обов'язковий (`ε > 0`) через аномалії** |
| **Статус** | Доведена теорема (1983) | Відкрита гіпотеза (1985) |

У кільці цілих чисел `Z` відсутність диференціального оператора не дозволяє безпосередньо виділити "кратності" простих множників через Вронськіан. Саме це змушує математиків розробляти надзвичайно складні теорії (p-адичний аналіз, арифметичну геометрію та IUT-теорію Мочізукі), щоб створити штучний аналог похідної для цілих чисел.
