## 1. Контракт інтерфейсу та обчислювальні параметри

Для невід'ємних індексів послідовність монотонно зростає, починаючи з початкового значення. Для від'ємних індексів послідовність коливається за знаком відповідно до закону парності.

По-перше, дробове відношення чисел Люка до відповідних чисел Фібоначчі дуже швидко збігається до ірраціональної величини квадратного кореня з п'яти. Це пояснюється тим, що при великих значеннях індексу згасаючий доданок стає нехтовно малим, і відношення визначається виключно основними коефіцієнтами формул Біне.

По-друге, квадратична різниця між квадратом числа Люка та п'ятикратним квадратом числа Фібоначчі суворо чергує свої значення між чотирма та мінус чотирма. Це підтверджує належність відповідних числових пар до розв'язків гіперболічного рівняння Пелля.

По-третє, остачі чисел Люка від ділення на п'ять створюють циклічну послідовність із чотирьох повторюваних елементів. Відсутність нуля в цьому циклі свідчить про те, що жодне число Люка не ділиться на п'ять націло.

## 2. Систематичний довідник тотожностей та алгебраїчних зв'язків

Нижче наведено зведений довідник тотожностей для чисел Люка. Вони розгруповані за категоріями для зручного використання в аналітичних перетвореннях.

Базове рекурентне правило визначає кожен член через суму двох попередніх елементів. Зворотна форма дає можливість виражати попередні значення через наступні. Зв'язок із послідовністю Фібоначчі визначається дзеркальними формулами додавання сусідніх членів. Сума двох сусідніх чисел Фібоначчі утворює число Люка, а сума двох сусідніх чисел Люка утворює п'ятикратне число Фібоначчі.

При множенні індексів застосовуються квадратичні формули подвоєння. Подвоєння індексу числа Фібоначчі дорівнює добутку відповідних членів Фібоначчі та Люка. Подвоєння індексу числа Люка обчислюється через квадрат поточного значення з відніманням або додаванням двійки залежно від парності індексу. Для потроєння індексу використовується кубічна формула, яка виражає значення через добуток поточного числа на різницю його квадрата та трійки.

Нелінійні тотожності Кассіні, Каталана та д'Оканя описують співвідношення між добутками зсунутих членів послідовності. Вони дозволяють згортати складні суми та перевіряти детермінанти матриць переходу в алгебраїчних обчисленнях.

## 4. Загальні квадратичні послідовності Люка та їхні параметри

Узагальнення послідовностей Люка полягає у введенні довільних цілих коефіцієнтів першого та нульового степеня в характеристичне рівняння. Це створює два фундаментальних сімейства послідовностей.

Послідовність першого роду задається початковими значеннями нуль та одиниця. Вона моделює дискретні аналоги синусоїдальних коливань. Послідовність другого роду задається початковими значеннями два та перший коефіцієнт. Вона моделює дискретні аналоги косинусоїдальних коливань.

Різні вибори параметрів дають відомі числові системи. При одиничному коефіцієнті та від'ємному вільному члені ми отримуємо класичні числа Фібоначчі та Люка. При подвоєному коефіцієнті утворюються числа Пелля та Пелля–Люка. При від'ємній двійці у вільному члені виникають числа Якобсталя. При виборі трійки та двійки утворюється двійкова біноміальна пара чисел Мерсенна та Ферма.

Така універсальність робить теорію послідовностей Люка потужним інструментом для дослідження загальних арифметичних властивостей рекурентних систем другого порядку.
