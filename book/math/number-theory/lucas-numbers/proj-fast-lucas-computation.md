# ⚙️ Швидке обчислення чисел Люка

У цій алгоритмічній вставці описується швидкий метод обчислення чисел Люка за логарифмічний час за допомогою формул подвоєння аргументу, розглядаються особливості паралельного та матричного обчислення, наводяться готові реалізації мовами C і C++, а також показується застосування в тесті простоти Люка–Лемера.

## Алгоритм швидкого подвоєння (Fast Doubling)

Наївний рекурентний розрахунок за формулою додавання двох попередніх членів потребує кількості операцій, пропорційної індексу. Для обчислення мільйонного члена це вимагало б мільйона кроків додавання над багатьма тисячами цифр, що для обчислювальної практики є неприпустимо повільним.

Використовуючи формули подвоєння аргументу, ми можемо за один бітовий крок перейти від пари поточних членів до подвоєних індексів. Це дає можливість розганяти індекс удвічі на кожній ітерації.

Аналогічні формули подвоєння існують і для парної обчислювальної системи чисел Фібоначчі й Люка. Подвоєння індексу числа Фібоначчі обчислюється як добуток числа Фібоначчі на число Люка. Подвоєння індексу числа Люка обчислюється через квадрат поточного числа Люка з додаванням або відніманням двійки.

Алгоритм аналізує двійкові біти числа, починаючи від старшого встановленого біта до молодшого, накопичуючи пару сусідніх чисел Люка. На кожному кроці здійснюється подвоєння індексу. Якщо поточний аналізований біт дорівнює одиниці, робиться додатковий одиничний зсув індексу шляхом додавання двох поточних чисел.

Кількість кроків алгоритму дорівнює кількості бітів у двійковому записі індексу, що забезпечує логарифмічну складність обчислення.

## Матрична форма та бітовий розбір

Альтернативним поглядом на алгоритм є піднесення матриці переходу другого порядку до відповідного степеня. Множення вектора початкових умов на n-ний степінь матриці переходу дає новий вектор зі значеннями наступного та поточного чисел Люка.

Піднесення матриці два на два до степеня методом бінарного піднесення виконується за логарифмічну кількість матричних множень. Однак пряме використання формули подвоєння через пару сусідніх чисел вимагає лише два цілочисельні множення на біт, тоді як матричне множення чотирьох елементів вимагає вісім множень. Тому метод швидкого подвоєння є значно ефективнішим на практиці.

Розберемо роботу алгоритму для індексу одинадцять. У двійковій системі число одинадцять записується як один нуль один один у двійковому коді.

На стартовому кроці старший біт знаходиться в позиції три. Початковий стан визначається базовою парою з чисел два та один для нульового та першого індексів.

На першому кроці аналізується біт зі значенням нуль. Здійснюється подвоєння індексу з нульового на другий. Обчислюються нові значення для другого та третього індексів. Оскільки біт дорівнює нулю, додатковий зсув не виконується, і пара залишається без змін.

На другому кроці аналізується біт зі значенням один. Виконується подвоєння індексу з второго на четвертий. Обчислюються значення для четвертого та п'ятого індексів. Оскільки біт дорівнює одиниці, робиться зсув індексу на одиницю вгору, і нова пара формується з п'ятого та шостого індексів.

На третьому кроці аналізується останній біт зі значенням один. Здійснюється подвоєння індексу з п'ятого на десятий. Обчислюються значення для десятого та одинадцятого індексів. Оскільки біт дорівнює одиниці, робиться остаточний зсув індексу на одинадцятий та дванадцятий члени.

У результаті за три бітові ітерації алгоритм отримує точне значення одинадцятого числа Люка, яке дорівнює ста дев'яноста дев'яти.

## Реалізація алгоритму

Нижче наведено ідіоматичні реалізації швидкого обчислення числа Люка та перевірки чисел Мерсенна мовами C та C++.

```c
#include <stdio.h>
#include <stdint.h>
#include <stdbool.h>

/* Структура для збереження пари сусідніх чисел Люка (Lₖ, Lₖ₊₁) */
typedef struct {
    uint64_t l_k;
    uint64_t l_k1;
} lucas_pair_t;

/* 
 * Обчислює пару (Lₙ, Lₙ₊₁) за час O(log n)
 * Використовує 64-бітну цілочисельну арифметику без переповнення для n <= 92
 */
lucas_pair_t fast_lucas_pair(uint32_t n) {
    if (n == 0) {
        lucas_pair_t base = {2, 1};
        return base;
    }

    /* Знаходимо позицію старшого встановленого біта */
    uint32_t mask = 1U << 31;
    while ((mask & n) == 0) {
        mask >>= 1;
    }

    uint64_t a = 2; /* L₀ */
    uint64_t b = 1; /* L₁ */
    uint32_t k = 0;

    while (mask > 0) {
        /* Формули подвоєння: k -> 2k */
        int sign = (k % 2 == 0) ? 1 : -1;
        uint64_t next_a = a * a - (uint64_t)(2 * sign);
        uint64_t next_b = a * b - (uint64_t)sign;

        a = next_a;
        b = next_b;
        k = 2 * k;

        /* Якщо поточний біт дорівнює 1: 2k -> 2k + 1 */
        if ((n & mask) != 0) {
            uint64_t temp = a + b;
            a = b;
            b = temp;
            k = k + 1;
        }

        mask >>= 1;
    }

    lucas_pair_t res = {a, b};
    return res;
}

uint64_t fast_lucas(uint32_t n) {
    return fast_lucas_pair(n).l_k;
}

/*
 * Тест Люка-Лемера для перевірки простоти числа Мерсенна M_p = 2^p - 1
 */
bool lucas_lehmer_test(uint32_t p) {
    if (p == 2) return true;
    uint64_t m_p = (1ULL << p) - 1ULL;
    uint64_t s = 4;
    for (uint32_t i = 0; i < p - 2; ++i) {
        s = (s * s - 2) % m_p;
    }
    return s == 0;
}

int main(void) {
    printf("Обчислення чисел Люка (C):\n");
    for (uint32_t n = 0; n <= 15; ++n) {
        printf("L_%-2u = %llu\n", n, (unsigned long long)fast_lucas(n));
    }
    printf("\nПеревірка чисел Мерсенна M_p:\n");
    uint32_t primes[] = {3, 5, 7, 13, 17, 19, 31};
    for (size_t i = 0; i < sizeof(primes)/sizeof(primes[0]); ++i) {
        uint32_t p = primes[i];
        printf("M_%-2u є %s\n", p, lucas_lehmer_test(p) ? "ПРОСТИМ" : "СКЛАДЕНИМ");
    }
    return 0;
}
```

```cpp
#include <iostream>
#include <cstdint>
#include <utility>
#include <vector>
#include <bit>

namespace math {

/*
 * Обчислює пару (Lₙ, Lₙ₊₁) за час O(log n) в ідіоматичному стилі C++20
 * Повертає std::pair<std::uint64_t, std::uint64_t>
 */
constexpr std::pair<std::uint64_t, std::uint64_t> fast_lucas_pair(std::uint32_t n) noexcept {
    if (n == 0) {
        return {2ULL, 1ULL};
    }

    const int bit_length = 32 - std::countl_zero(n);
    std::uint64_t a = 2ULL; // L₀
    std::uint64_t b = 1ULL; // L₁
    std::uint32_t k = 0;

    for (int i = bit_length - 1; i >= 0; --i) {
        const std::int64_t sign = (k % 2 == 0) ? 1 : -1;
        const std::uint64_t next_a = a * a - static_cast<std::uint64_t>(2 * sign);
        const std::uint64_t next_b = a * b - static_cast<std::uint64_t>(sign);

        a = next_a;
        b = next_b;
        k *= 2;

        if ((n >> i) & 1U) {
            const std::uint64_t temp = a + b;
            a = b;
            b = temp;
            k += 1;
        }
    }

    return {a, b};
}

constexpr std::uint64_t fast_lucas(std::uint32_t n) noexcept {
    return fast_lucas_pair(n).first;
}

/*
 * Тест простоти Люка-Лемера для M_p = 2^p - 1 у C++20
 */
bool lucas_lehmer_test(std::uint32_t p) noexcept {
    if (p == 2) return true;
    const std::uint64_t m_p = (1ULL << p) - 1ULL;
    std::uint64_t s = 4ULL;
    for (std::uint32_t i = 0; i < p - 2; ++i) {
        s = (s * s - 2ULL) % m_p;
    }
    return s == 0ULL;
}

} // namespace math

int main() {
    std::cout << "Обчислення чисел Люка (C++20):\n";
    for (std::uint32_t n = 0; n <= 15; ++n) {
        std::cout << "L_" << n << " = " << math::fast_lucas(n) << '\n';
    }

    std::cout << "\nПеревірка чисел Мерсенна M_p:\n";
    const std::vector<std::uint32_t> primes = {3, 5, 7, 13, 17, 19, 31};
    for (auto p : primes) {
        std::cout << "M_" << p << " є " << (math::lucas_lehmer_test(p) ? "ПРОСТИМ" : "СКЛАДЕНИМ") << '\n';
    }
    return 0;
}
```

## Довга арифметика та оптимізації

При обчисленні чисел Люка з великими індексами виникають три основні алгоритмічні аспекти, які вимагають ретельної уваги розробника.

Першим аспектом є обмеження стандартних цілочисельних типів даних. Оскільки числа Люка зростають експоненційно зі швидкістю степенів золотого перерізу, дев'яносто друге число Люка є найбільшим членом, який поміщається у шістдесятичотирибітне ціле число без знаку. Для індексів, більших за дев'яносто два, вимагається використання алгоритмів довгої арифметики, де числа подаються як динамічні масиви машинних слів.

Другим аспектом є оптимізація ділення за модулем у тесті простоти Люка–Лемера. При обчисленні за модулем числа Мерсенна стандартне ділення замінюється швидким маскуванням. Зсув розрядів та побітове додавання дозволяють обчислювати остачу за дві швидкодійні бітові операції без виклику важкої інструкції ділення процесора. Це робить тест Люка–Лемера в сотні разів швидшим за довільні криптографічні методи тестування.

Третім аспектом є паралельне обчислення на процесорних векторах та графічних прискорювачах. Оскільки піднесення до квадрата у формулі подвоєння не залежить від сусідніх потоків, обчислення багатьох послідовностей Люка можна ефективно векторнізувати за допомогою SIMD інструкцій процесора або виконувати на графічних ядрах у обчислювальних мережах.

Загальна часова складність обчислення з урахуванням довгого множення визначається швидкістю базового множника та логарифмом індексу. При використанні швидкого перетворення Фур'є для множення надвеликих чисел час обчислення прямує до майже лінійного від кількості цифр підсумкового результату.
