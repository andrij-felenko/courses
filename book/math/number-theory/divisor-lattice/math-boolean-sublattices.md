# 🧮 Булеві підалгебри решітки дільників

Коли ми досліджуємо алгебраїчну структуру решітки дільників натурального числа n (її часто позначають як D_n), ми виявляємо, що її геометрична та логічна форма дуже сильно залежить від того, чи присутні в розкладі числа n на прості множники однакові прості числа. Найбільш елегантний, математично багатий і важливий випадок виникає тоді, коли число n є вільним від квадратів. Це означає, що в його канонічному розкладі на прості множники кожен простий дільник зустрічається рівно один раз (тобто у першому степені). Наприклад, число n = 30 = 2 · 3 · 5 є вільним від квадратів, оскільки жоден простий множник не повторюється. Натомість число n = 12 = 2² · 3 таким не є, бо містить квадрат числа 2.

Якщо n — вільне від квадратів число, яке складається з k різних простих множників p₁, p₂, ..., p_k, то кожен його можливий дільник однозначно визначається тим, які саме з цих простих множників увійшли до його складу. Це фундаментальне спостереження означає, що ми можемо встановити строгу взаємно однозначну відповідність (бієкцію) між кожним дільником числа n та підмножиною базової множини його простих множників P = {p₁, p₂, ..., p_k}. 

Розглянемо це на конкретному прикладі для n = 30 (множина P = {2, 3, 5}):
- Дільник 1 (одиниця) не містить жодних простих множників, тому він відповідає порожній підмножині ∅.
- Прості дільники 2, 3 та 5 відповідають одноелементним підмножинам {2}, {3} та {5} відповідно.
- Складені дільники, такі як 15 (це 3 · 5), відповідають двоелементним підмножинам, у даному випадку {3, 5}.
- Саме число 30 відповідає повній множині всіх своїх простих дільників {2, 3, 5}.

Завдяки такій природній відповідності (яка в математиці називається ізоморфізмом), усі алгебраїчні операції над дільниками ідеально збігаються з теоретико-множинними операціями над підмножинами:
- Найбільший спільний дільник (НСД, або точна нижня грань, infimum) двох дільників повністю відповідає операції перетину їхніх відповідних підмножин.
- Найменше спільне кратне (НСК, або точна верхня грань, supremum) двох дільників відповідає операції об'єднання підмножин.
- Відношення подільності a | b (число a ділить число b) означає, що множина простих дільників числа a є підмножиною множини простих дільників числа b (тобто виконується строге включення множин A ⊆ B).

Коли будь-яка частково впорядкована множина має таку досконалу структуру, вона називається булевою решіткою або булевою алгеброю. Найважливішою ознакою і вимогою булевої алгебри є наявність унікального доповнення для кожного її елемента. У решітці дільників вільного від квадратів числа доповненням до будь-якого дільника d є число n / d (результат ділення всього числа на цей дільник). 

Наприклад, для того ж числа n = 30, доповненням до дільника 6 (який складається з {2, 3}) є число 30 / 6 = 5 (яке відповідає {5}). Ці два числа, d та n/d, не мають жодних спільних дільників окрім 1. Це означає, що їхній НСД завжди дорівнює 1. Одночасно з цим, їхнє НСК завжди дорівнює самому максимальному числу n. У термінах теорії множин це означає, що підмножина та її доповнення не мають жодних спільних елементів (не перетинаються), але разом, при об'єднанні, вони утворюють усю початкову базову множину.

Крім того, геометрично діаграма Гассе для такої решітки завжди має форму гіперкуба розмірності k. Для числа з двома простими множниками (наприклад, 6 = 2 · 3) решітка є квадратом. Для трьох простих множників (як 30) — це тривимірний куб, де вершинами є дільники. Для чотирьох (наприклад, 210 = 2 · 3 · 5 · 7) — це чотиривимірний тесеракт. Така геометрична відповідність дозволяє візуалізувати складні теоретико-числові відношення через наочні просторові фігури.

Що ж відбувається з числами, які містять квадрати або вищі степені простих чисел? Для них загальна решітка дільників вже не є булевою алгеброю. Візьмемо для прикладу число n = 12 = 2² · 3. Якщо ми спробуємо знайти доповнення до числа 2, природно подумати, що це 12 / 2 = 6. Проте НСД(2, 6) = 2, а не 1. Це порушує аксіому про те, що перетин елемента та його доповнення має дорівнювати найменшому елементу решітки (одиниці). Тобто тут немає справжнього булевого доповнення для всіх елементів, і структура є лише дистрибутивною решіткою, а не булевою.

Однак, навіть у таких випадках, всередині будь-якої такої складної решітки завжди можна знайти ідеально симетричну булеву підалгебру. Ця булева підалгебра — це решітка дільників так званого радикалу числа n (позначається rad(n)), що є найбільшим вільним від квадратів дільником цього числа. Для n = 12 радикалом є rad(12) = 2 · 3 = 6. Решітка дільників числа 6 (що містить 1, 2, 3, 6) утворює повноцінну булеву підалгебру всередині загальної решітки дільників числа 12. 

Ця математична гармонія дуже яскраво демонструє глибокий зв'язок між різними розділами математики. Вона показує, що булева алгебра — це далеко не просто абстрактна логіка нулів та одиниць або правила роботи логічних вентилів у комп'ютерах. Це фундаментальний структурний патерн, універсальна форма симетрії, яка природним чином керує навіть найбільш базовими концепціями — звичайним множенням та подільністю натуральних чисел у теорії чисел.
