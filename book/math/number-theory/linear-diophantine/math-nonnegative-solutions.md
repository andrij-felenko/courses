# 🧮 Скільки є невід'ємних розв'язків

Цілу розв'язність рівняння a·x + b·y = c припустимо вже перевіреною, а всю родину його цілих розв'язків — знайденою; лишилось питання, яке ставлять справжні задачі про предмети: скільки серед цих розв'язків тих, де обидві невідомі невід'ємні, і як полічити їх, не перебираючи по одному.

Домовмося про знаки одразу, бо від них залежить кожна нерівність нижче. Числа a, b, c беремо додатними — це задачі, де рахують предмети (марки, монети, коробки), а не борги, тому «мінус монета» тут заборонена з самого початку. Тоді d = [НСД(a, b)](book:math/gcd-euclidean) додатний, і обидва кроки родини — b/d та a/d — теж додатні. Сама родина всіх цілих розв'язків, занумерована цілим t, виглядає так:

```
x = x₁ + (b/d)·t
y = y₁ − (a/d)·t
```

де (x₁, y₁) — якийсь один уже знайдений розв'язок. Питання «скільки невід'ємних?» дослівно означає: при скількох цілих t жодна з двох координат не стає від'ємною?

## Дві нерівності стягують t у відрізок

Підставмо родину в обидві умови невід'ємності й подивімося, які t їх витримують.

З умови x ≥ 0 маємо x₁ + (b/d)·t ≥ 0. Крок b/d додатний, тож ділити на нього можна, не перевертаючи знак нерівності:

```
x ≥ 0   →   t ≥ −x₁·d/b        назвімо цю нижню межу L
```

З умови y ≥ 0 маємо y₁ − (a/d)·t ≥ 0, тобто (a/d)·t ≤ y₁. Крок a/d знову додатний:

```
y ≥ 0   →   t ≤ y₁·d/a         назвімо цю верхню межу R
```

Дві умови тягнуть t у протилежні боки, і це не випадковість. Зі зростанням t координата x росте — тому надто мала t заборонена, знизу з'являється стінка L. А y при цьому падає — тому надто велика t заборонена, згори опускається стеля R. Дозволені ті t, що витримують обидва тиски водночас:

```
L ≤ t ≤ R,     L = −x₁·d/b,     R = y₁·d/a
```

Нескінченна низка цілих розв'язків уздовж прямої стягнулася в один відрізок [L, R] на осі параметра. Скільки в цьому відрізку цілих значень t — стільки й невід'ємних розв'язків у самого рівняння. Задачу про предмети зведено до найпростішого: полічити цілі точки на відрізку прямої осі.

## Кількість — це число цілих у проміжку

А цілі в [L, R] лічаться без жодного перебору. Найменше ціле, не менше за L, — це ⌈L⌉, округлення вгору; найбільше ціле, не більше за R, — це ⌊R⌋, округлення вниз. Усі цілі від ⌈L⌉ до ⌊R⌋ включно й лежать у відрізку, а їх рівно

```
N = ⌊R⌋ − ⌈L⌉ + 1        (коли ⌊R⌋ ≥ ⌈L⌉;  інакше N = 0)
```

Одиниця в кінці — бо кінці враховуємо обидва: з третього поверху на сьомий не чотири прольоти сходів, а п'ять поверхів. Якщо ж округлена стеля впала нижче за округлену стінку, ⌊R⌋ < ⌈L⌉, то у відрізок не вміщається жодне ціле — відповідь нуль. І це не окреме правило для «немає розв'язків», а той самий підрахунок, що просто дав недодатне число. Два округлення й віднімання — і кількість готова, хоч би скільки тих розв'язків виявилось.

> 🔧 **Навіщо це.** [Розширений алгоритм Евкліда](book:math/gcd-euclidean/math-bezout.md) видає перший розв'язок (x₁, y₁) за кілька ділень; після нього кількість невід'ємних варіантів — це два округлення й одне віднімання, тобто миттєво, без побудови жодного варіанта. Тому на питання «чи здійсненне замовлення взагалі і скільки в нього розкладок» відповідають, не виписуючи жодної: спершу перевіряють d | c (розв'язок є), потім рахують N (скільки їх серед невід'ємних). У задачах розкрою, пакування й видачі решти саме це число — є варіанти чи ні — важить найбільше.

## Наближено — це рівно довжина відрізка

Скільки ж розв'язків приблизно, без округлень? Число цілих у відрізку близьке до його довжини, тож порахуймо R − L:

```
R − L = y₁·d/a − (−x₁·d/b)
      = d·(y₁/a + x₁/b)
      = d·(a·x₁ + b·y₁)/(a·b)
```

А в чисельнику проступає власний доданок задачі: a·x₁ + b·y₁ = c, бо (x₁, y₁) — розв'язок. Отже довжина відрізка

```
R − L = c·d/(a·b)
```

Погляньте, що зникло: конкретний перший розв'язок (x₁, y₁). Хоч який його взяти, зсуви x₁ та y₁ у різниці скоротилися — довжина вікна залежить тільки від a, b, c, а не від того, з чого ми почали. Число ж цілих у відрізку довжини ℓ завжди дорівнює ⌊ℓ⌋ або ⌊ℓ⌋ + 1 — не менше й не більше. Тому

```
N ≈ c·d/(a·b),   точно — це число або на одиницю більше
```

Кількість невід'ємних розв'язків росте пропорційно до c: удвічі більша сума — удвічі більше способів її скласти, з точністю до одиниці, яку вирішує лише те, як лягли кінці відрізка на цілі поділки.

## Три приклади: один, два, жоден

**Марки по 5 і 8 копійок на 43 — скільки способів?**
Візьмімо охайний розв'язок (7, 1); тоді родина x = 7 + 8t, y = 1 − 5t.
```
d = НСД(5, 8) = 1
x ≥ 0:   7 + 8t ≥ 0   →   t ≥ −7/8 = −0.875 = L
y ≥ 0:   1 − 5t ≥ 0   →   t ≤ 1/5  =  0.2   = R
N = ⌊0.2⌋ − ⌈−0.875⌉ + 1 = 0 − 0 + 1 = 1
```
У відрізок [−0.875, 0.2] попадає єдине ціле t = 0, а воно дає (7, 1): сім п'ятикопійчаних марок і одна восьмикопійчана. Довжина вікна 43/40 = 1.075 — і справді рівно один розв'язок.

**Ті самі марки на 40 — уже два.**
Один розв'язок видно з ходу: 8·5 = 40, тобто (0, 5). Родина x = 8t, y = 5 − 5t.
```
x ≥ 0:   8t ≥ 0       →   t ≥ 0 = L
y ≥ 0:   5 − 5t ≥ 0   →   t ≤ 1 = R
N = ⌊1⌋ − ⌈0⌉ + 1 = 1 − 0 + 1 = 2
```
Два цілі, t = 0 і t = 1, дають (0, 5) і (8, 0). Тут варто спинитись, бо приклад показує саму «одиницю похибки» наближення. Довжина вікна 40/40 = 1.000, а розв'язків два, не один. Річ у кінцях: обидва, L = 0 і R = 1, самі цілі, а відрізок довжини 1 із цілими кінцями накриває дві цілі точки, не одну. Гола довжина ℓ = 1 підказала б «один» — і тільки точна формула з округленнями бачить обидва кінці.

**Ті самі марки на 6 — жодного.**
Ділення проходить: НСД = 1 ділить 6, тож цілі розв'язки існують. Але чи є серед них невід'ємний? З рівності Безу 5·(−3) + 8·2 = 1, помноживши на 6, дістаємо (−18, 12); родина x = −18 + 8t, y = 12 − 5t.
```
x ≥ 0:   −18 + 8t ≥ 0   →   t ≥ 18/8 = 2.25   →   ⌈2.25⌉ = 3
y ≥ 0:   12 − 5t ≥ 0    →   t ≤ 12/5 = 2.4    →   ⌊2.4⌋  = 2
N = ⌊2.4⌋ − ⌈2.25⌉ + 1 = 2 − 3 + 1 = 0
```
Проміжок [2.25, 2.4] цілком реальний, але надто вузький — він поміщається між сусідніми цілими 2 і 3, не зачепивши жодного (довжина ж бо 6/40 = 0.15). Шести копійок цими марками не набрати без решти; 6 — одне з тих «нескладних» чисел, про які скажемо наприкінці.

## Тенденція: більший c — більше способів

Три приклади вичерпали всю вилку — нуль, один, багато. Загальний хід теж видно: чим більше c, тим довший відрізок і тим більше цілих у ньому. Ось кілька сум тими самими марками 5 і 8:

```
   c     ℓ = c/40     N (точно)
   6       0.15          0
   8       0.20          1
  16       0.40          1
  40       1.00          2
  43       1.075         1
  80       2.00          3
 101       2.525         3
 200       5.00          6
```

N тримається коло ℓ = c/40, гуляючи навколо на одиницю туди-сюди залежно від того, як кінці відрізка лягли на цілі. Зростання не строго монотонне — 43 дало менше за 40, бо на 40 обидва кінці сіли на вузли, — але в середньому воно лінійне: більша сума дає більше способів її зібрати, і що більший c, то точніше N наближається до c·d/(a·b).

## Геометрична картина

Кожне ціле t — це вузол цілої сітки на прямій a·x + b·y = c, а сусідні t відрізняються рівно на крок (b/d, −a/d), один «стрибок» уздовж прямої. Умова невід'ємності лишає від нескінченної прямої тільки відрізок у першому квадранті. Спроєктувавши цей похилий відрізок на вісь параметра t, дістаємо відрізок [L, R] на прямій осі — і питання «скільки вузлів на похилому відрізку» стає питанням «скільки цілих поділок помістилось між L і R».

*Невід'ємність двома нерівностями стягує параметр t у відрізок [L, R]; кількість невід'ємних розв'язків — це число цілих поділок у цьому відрізку. Ліворуч 5·x + 8·y = 43: вікно [−7⁄8, 1⁄5] ловить одне ціле t = 0 — один спосіб. Праворуч 5·x + 8·y = 40: вікно [0, 1] тієї самої довжини, але з цілими кінцями, ловить два, t = 0 і t = 1 — два способи.*

## Межа: коли невід'ємних немає зовсім

Один випадок вартий окремого слова — коли невід'ємних розв'язків нуль, хоч цілі й існують. Для взаємно простих a і b (тобто d = 1) таких «нескладних» сум лише скінченно багато: від певного місця вгору кожна сума вже складається. Найбільшу суму, яку не набрати, і кількість усіх таких сум дав ще Джеймс Джозеф Сильвестр 1882 року:

```
найбільше нескладане c        = a·b − a − b
кількість усіх нескладаних c   = (a − 1)·(b − 1)/2
```

Для марок 5 і 8: найбільша неможлива сума — 5·8 − 5 − 8 = 27, а всього таких сум (5 − 1)·(8 − 1)/2 = 14, і наші 6 копійок серед них. Понад 27 копійок будь-яка сума цими марками складається завжди — вікно [L, R] стає досить довгим, щоб напевно накрити ціле. Ця межа — лише вхід до окремої, значно глибшої задачі: для трьох і більше номіналів формули на «найбільше нескладане» не знають досі, а сам підрахунок стає обчислювально важким. Її звуть [числом Фробеніуса, або задачею про монети](book:math/frobenius-number).
