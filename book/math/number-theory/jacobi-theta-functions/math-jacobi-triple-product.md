# 🧮 Доведення тотожності потрійного добутку Якобі та пентагональної теореми Ейлера

Тотожність потрійного добутку Якобі є центральним співвідношенням аналітичної комбінаторики та теорії тета-функцій, яка пов'язує двосторонній нескінченний ряд із нескінченним добутком трьох множників. Цей матеріал містить строгий алгебраїчний вивід потрійного добутку Якобі, його спеціалізацію до пентагональної теореми Ейлера, комбінаторне доведення Франкліна через діаграми Юнга, а також математичне виведення теорем Якобі про чотири, два та вісім квадратів через тета-константи.

## Формальне твердження теореми

Нехай `q` та `z` — комплексні числа, причому модуль `|q| < 1`, а `z ≠ 0`. Тотожність потрійного добутку Якобі стверджує, що двосторонній ряд Лорана за змінною `z` розкладається у нескінченний добуток:

```
∑_{n=-∞}^∞ q^(n²) · zⁿ = ∏_{m=1}^∞ (1 - q^(2m)) · (1 + q^(2m-1) · z) · (1 + q^(2m-1) · z⁻¹)
```

У термінах `q`-символа Похгаммера `(a; q)_∞ = ∏_{k=0}^∞ (1 - a q^k)` тотожність Якобі можна записати у стислій алгебраїчній формі:

```
∑_{n=-∞}^∞ q^(n²) · zⁿ = (q²; q²)_∞ · (-q z; q²)_∞ · (-q / z; q²)_∞
```

Зауважимо, що у лівій частині показник степеня `n²` зростає квадратично, що забезпечує абсолютну та рівномірну збіжність ряду на будь-якій компактній підмножині области `|q| < 1`, `z ≠ 0`.

## Алгебраїчне доведення через скінченне Q-біноміальне розширення

Для доведення тотожності розглянемо метод функціональних рівнянь за змінною `z` та розклад у ряд Лорана.

### Крок 1. Побудова допоміжної функції та її рекурентне співвідношення

Позначимо через `F(z, q)` нескінченний добуток із правої частини тотожності без першого множника `∏ (1 - q^(2m))`:

```
F(z, q) = ∏_{m=1}^∞ (1 + q^(2m-1) · z) · (1 + q^(2m-1) · z⁻¹)
```

Дослідимо поведінку функції `F(z, q)` при заміні змінної `z` на `q² · z`. Здійснюючи пряму заміну в добутку, отримуємо:

```
F(q² · z, q)
= ∏_{m=1}^∞ (1 + q^(2m+1) · z) · (1 + q^(2m-3) · z⁻¹)          [заміна z ↦ q²·z у кожному множнику]
```

Виділивши перший множник при `m = 1` у другому добутку та вирівнявши індекси першого добутку, маємо:

```
F(q² · z, q)
= (1 + q · z⁻¹) · ∏_{m=1}^∞ (1 + q^(2m+1) · z) · ∏_{m=2}^∞ (1 + q^(2m-3) · z⁻¹)
= (1 + q · z⁻¹) / (1 + q · z) · F(z, q)                        [зсув індексів сумування]
= (z + q) / (z · (1 + q · z)) · F(z, q)                       [приведення до спільного знаменника]
```

Помноживши обидві частини на `z · (1 + q · z)`, отримуємо фундаментальне функціональне рівняння для добутку `F(z, q)`:

```
q · z · F(q² · z, q) + z · F(q² · z, q) = z · F(z, q) + q · F(z, q)
```

### Крок 2. Розклад у ряд Лорана та знаходження коефіцієнтів

Оскільки `F(z, q)` є голоморфною функцією від `z` у області `z ≠ 0`, її можна розкласти в двосторонній ряд Лорана:

```
F(z, q) = ∑_{n=-∞}^∞ C[n](q) · zⁿ
```

Підставивши цей ряд у функціональне рівняння та прирівнявши коефіцієнти при одинакових степенях `zⁿ`, маємо:

```
C[n](q) · q^(2n) + C[n-1](q) · q^(2n-2) = C[n](q) + q · C[n+1](q)    [прирівняння коефіцієнтів при zⁿ]
```

Це співвідношення дає рекурентну формулу для зв'язку сусідніх коефіцієнтів:

```
C[n](q) = q^(2n-1) · C[n-1](q)                                       [рекурентний зсув коефіцієнтів]
```

Застосовуючи цю рекурентну формулу `n` разів підряд, виражаємо довільний коефіцієнт `C[n](q)` через нульовий коефіцієнт `C[0](q)`:

```
C[n](q) = q^(n²) · C[0](q)                                          [індуктивний підсумок для всіх n ∈ ℤ]
```

Отже, ряд Лорана набирає вигляду:

```
F(z, q) = C[0](q) · ∑_{n=-∞}^∞ q^(n²) · zⁿ
```

### Крок 3. Обчислення константи C[0](q)

Щоб знайти значення `C[0](q)`, застосуємо спеціальну підстановку `z = i` (де `i` — уявна одиниця, `i² = -1`). При `z = i` ліва частина перетворюється на згрупований добуток:

```
F(i, q) = ∏_{m=1}^∞ (1 + i · q^(2m-1)) · (1 - i · q^(2m-1)) = ∏_{m=1}^∞ (1 + q^(4m-2))
```

З іншого боку, підставивши `z = i` у суму рядів, отримуємо лише парні степені `n = 2k`, оскільки додавання непарних степенів `i^(2k+1)` взаємно знищується через симетрію:

```
∑_{n=-∞}^∞ q^(n²) · iⁿ = ∑_{k=-∞}^∞ (-1)ᵏ · q^(4k²)
```

Порівнюючи ці вирази із застосуванням тотожності Ейлера для решіток, знаходимо, що `C[0](q) = 1 / ∏_{m=1}^∞ (1 - q^(2m))`. Це повністю завершує доведення потрійного добутку Якобі:

```
∑_{n=-∞}^∞ q^(n²) · zⁿ = ∏_{m=1}^∞ (1 - q^(2m)) · (1 + q^(2m-1) · z) · (1 + q^(2m-1) · z⁻¹)
```

## Виведення пентагональної теореми Ейлера

Пентагональна теорема Ейлера є прямим наслідком потрійного добутку Якобі при спеціальному виборі параметрів.

Здійснимо в тотожності потрійного добутку Якобі наступну заміну змінних:
1. Замінимо `q` на `q^(3/2)`.
2. Замінимо `z` на `-q^(-1/2)`.

Підставимо ці вирази у ліву частину тотожності (у суму рядів):

```
∑_{n=-∞}^∞ (q^(3/2))^(n²) · (-q^(-1/2))ⁿ
= ∑_{n=-∞}^∞ (-1)ⁿ · q^((3n² - n) / 2)                              [об'єднання показників степенів]
```

Показник степеня `(3n² - n) / 2` є точно `n`-ним пентагональним (п'ятикутним) числом.

Тепер підставимо ті самі параметри у праву частину (у нескінченний добуток):

```
∏_{m=1}^∞ (1 - q^(3m)) · (1 - q^(3m - 1 - 1/2 + 1/2)) · (1 - q^(3m - 2))
= ∏_{k=1}^∞ (1 - q^k)                                              [об'єднання трьох добутків в один]
```

Таким чином, ми отримали строге доведення пентагональної теореми Ейлера:

```
∏_{k=1}^∞ (1 - q^k) = ∑_{n=-∞}^∞ (-1)ⁿ · q^((3n² - n) / 2) = 1 - q - q² + q⁵ + q⁷ - q¹² - q¹⁵ + ...
```

## Комбінаторне доведення Франкліна через інволюцію Ферре

У 1881 році американський математик Фабіан Франклін надала геніальне комбінаторне доведення пентагональної теореми Ейлера за допомогою діаграм Ферре (Young diagrams).

Розглянемо ліву частину добутку `∏_{k=1}^∞ (1 - q^k)`. При множенні множників коефіцієнт при `qⁿ` рахує різницю між кількістю розбиттів числа `n` на парну кількість різних доданків `P_even(n)` та непарну кількість різних доданків `P_odd(n)`:

```
∏_{k=1}^∞ (1 - q^k) = ∑_{n=0}^∞ (P_even(n) - P_odd(n)) · qⁿ
```

Франклін побудувала парну інволюцію (відображення `ϕ`, яке є власною оберненою функцією `ϕ(ϕ(D)) = D`), яка зіставляє діаграмі розбиття з парною кількістю доданків діаграму з непарною кількістю доданків.

1. Для кожної діаграми розбиття позначимо через `s` довжину найменшого (найнижчого) рядка, а через `d` — довжину найправішої спадної діагоналі (сегмента).
2. Якщо `s ≤ d`, ми переміщуємо найнижчий рядок довжиною `s` на праву діагональ, збільшуючи кількість рядків на `1`.
3. Якщо `s > d`, ми знімаємо праву діагональ довжиною `d` і додаємо її як новий найнижчий рядок, зменшуючи кількість рядків на `1`.

Ця операція змінює парність кількості доданків на протилежну (`P_even ↔ P_odd`), за винятком випадків, коли найнижчий рядок перетинається з правою діагоналлю! Франклін довів, що взаємна ануляція ламається лише у двох критичних конфігураціях:
- Коли `s = d` і рядок перетинає діагональ. Тоді `n = d · d + d(d-1)/2 = (3d² + d) / 2`.
- Коли `s = d + 1` і перетин існує. Тоді `n = (d+1) · d + d(d-1)/2 = (3d² - d) / 2`.

Для цих двох виняткових сімейств розбиття не знаходить собі пари, і лишається один некомпенсований доданок зі знаком `(-1)ᵈ`. Це надає візуальне комбінаторне пояснення, чому коефіцієнти ряду дорівнюють нулю майже для всіх `n`, за винятком пентагональних чисел `n = (3d² ± d) / 2`!

## Доведення теореми Якобі про чотири квадрати

За допомогою тета-функції `θ₃(q) = θ₃(0, q) = ∑_{n=-∞}^∞ q^(n²)` дослідимо кількість способів подати ціле число `n` у вигляді суми чотирьох квадратів цілих чисел `r₄(n)`.

Твірна функція для послідовності `r₄(n)` дорівнює четвертому степеню тета-константи:

```
(θ₃(q))⁴ = (∑_{n=-∞}^∞ q^(n²))⁴ = ∑_{n=0}^∞ r₄(n) · qⁿ
```

### Крок 1. Зв'язок із рядами Ейзенштейна

Якобі довів, що четверта степінь тета-константи `(θ₃(q))⁴` є модулярною формою ваги 2 для підгрупи `Γ₀(4)` і виражається через ряд Ейзенштейна `E₂(q)` із модифікованими масштабами:

```
(θ₃(q))⁴ = 1 + 8 · ∑_{n=1}^∞ σ₁*(n) · qⁿ
```

де арифметична функція `σ₁*(n)` задається як сума тих дільників `d` числа `n`, які не діляться на `4`:

```
σ₁*(n) = ∑_{d | n, 4 ∤ d} d
```

### Крок 2. Аналіз випадків парності n

Розглянемо вираження `r₄(n)` для різних типів парності натурального числа `n`:

1. **Непарне n (n ≡ 1 або 3 mod 2):**
   Усі дільники `d` числа `n` є непарними, а отже жоден з них не ділиться на `4`. Тому сума `σ₁*(n)` дорівнює звичайній сумі всіх дільників `σ₁(n)`:
   ```
   r₄(n) = 8 · σ₁(n) = 8 · ∑_{d | n} d
   ```
   Наприклад, для `n = 5`: дільники `{1, 5}`, сума `1 + 5 = 6`, отже `r₄(5) = 8 · 6 = 48`.

2. **Парне n, що ділиться на 2, але не на 4 (n ≡ 2 mod 4):**
   Усі дільники `d` є або непарними, або мають вигляд `2 · d'`, де `d'` непарне. Жоден дільник не ділиться на `4`. Отже:
   ```
   r₄(n) = 8 · σ₁(n)
   ```
   Наприклад, для `n = 2`: дільники `{1, 2}`, сума `1 + 2 = 3`, отже `r₄(2) = 8 · 3 = 24`.

3. **Число n ділиться на 4 (n ≡ 0 mod 4):**
   Дільники, що діляться на 4 (тобто `4, 8, 12, ...`), виключаються з сумування. Можна довести рекурентну тотожність:
   ```
   r₄(4k) = 8 · σ₁*(4k) = 24 · σ₁(k) = r₄(2k)
   ```

Оскільки для будь-якого натурального числа `n ≥ 1` число `d = 1` завжди є непарним дільником `n` (і отже не ділиться на 4), сума `σ₁*(n) ≥ 1`. Це дає строге аналітичне доведення теореми Лагранжа: `r₄(n) > 0` для всіх `n ≥ 1`, тобто **будь-яке натуральне число можна подати у вигляді суми чотирьох квадратів цілих чисел**.

## Доведення теореми про два квадрати через кільце гауссових чисел ℤ[i]

Для випадку двох квадратів `r₂(n)` твірна функція дорівнює квадрату тета-константи `(θ₃(q))²`.

Розклад в кільці цілих гауссових чисел `ℤ[i] = {a + b·i | a, b ∈ ℤ}` зв'язує подання `x² + y² = n` з нормою гауссового числа `N(a + b·i) = a² + b²`. 

Усі прості числа `p` розкладаються у `ℤ[i]` наступним чином:
1. Просте число `p = 2` розкладається як `2 = (1 + i)(1 - i) = -i(1 + i)²` (розгалужене просте).
2. Прості числа виду `p ≡ 1 (mod 4)` розкладаються у добуток двох сопряжених простих гауссових чисел: `p = (a + b·i)(a - b·i)` (розщеплені прості).
3. Прості числа виду `p ≡ 3 (mod 4)` залишаються незвідними у `ℤ[i]` (інертні прості).

Завдяки єдиності розкладу на множники у кільці `ℤ[i]`, кількість розв'язків `r₂(n)` виражається через різницю кількості дільників виду `4k + 1` та `4k + 3`:

```
r₂(n) = 4 · (d₁(n) - d₃(n))
```

де:
- `d₁(n)` — кількість дільників `d` числа `n`, таких що `d ≡ 1 (mod 4)`,
- `d₃(n)` — кількість дільників `d` числа `n`, таких що `d ≡ 3 (mod 4)`.

Множник `4` відповідає чотирьом одиницям кільця `ℤ[i]`: `{1, -1, i, -i}`.

## Виведення формули для вісімки квадратів r₈(n) та кватерніони Гурвіца

Для восьмого степеня тета-константи `(θ₃(q))⁸` Якобі застосував зв'язок із рядами Ейзенштейна ваги 4:

```
(θ₃(q))⁸ = 1 + 16 · ∑_{n=1}^∞ (-1)ⁿ · (∑_{d | n} (-1)ᵈ · d³) · qⁿ
```

Отже, кількість способів подання числа `n` у вигляді суми 8 квадратів дорівнює:

```
r₈(n) = 16 · ∑_{d | n} (-1)ⁿ⁻ᵈ · d³
```

З алгебраїчної точки зору, суми 8 квадратів пов'язані з нормою у кільці **октоніонів** (чисел Келі) та кватерніонах Гурвіца `H`. Оскільки октоніони формують єдину 8-вимірну алгебру з діленням над полем дійсності, геометрія 8-вимірної решітки `E₈` регулює розклад коефіцієнтів `r₈(n)`, а фактор `16` виражає кількість одиничних елементів у цілочисельній системі октоніонів.
