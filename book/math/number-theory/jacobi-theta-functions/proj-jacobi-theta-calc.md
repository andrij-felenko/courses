# ⚙️ Високоточний алгоритм обчислення тета-функцій Якобі та AGM-редукція

Обчислення тета-функцій Якобі `θ₃(z, q)` та тета-констант для довільних параметрів `q` у діапазоні `0 ≤ q < 1` вимагає адаптивного обчислювального підходу. При малих значеннях нома `q` ряд `∑ q^(n²)` збігається надзвичайно швидко за експоненціально-квадратичним законом. Однак при наближенні `q → 1⁻` (наприклад, у задачах криптографії на еліптичних кривих або при обчисленні еліптичних інтегралів високого модуля `k → 1⁻`) пряме підсумовування вимагає тисяч доданків через вкрай повільне спадання членів ряду, що призводить до втрати обчислювальної точності через накопичення похибок округлення. 

Цей матеріал містить аналіз алгоритмічної складності, математичні засади редукції, а також практичні високоточні алгоритми обчислення тета-функцій мовами C та C++ із застосуванням модулярного перетворення Якобі `τ ↦ -1/τ` та алгоритму арифмето-геометричного середнього (AGM) Ґаусса.

## Алгоритмічний аналіз та математичні засади редукції

Для побудови стійкого чисельного алгоритму необхідно розділити область визначення нома `q ∈ [0, 1)` на дві основні зони: зону прямого підсумовування та зону модулярної редукції.

### 1. Зона прямого підсумовування (малі та середні номи q ≤ 0.6)

Для нома `q ≤ 0.6` показник степеня `n²` забезпечує стрімке зменшення величини членів ряду `a_n = 2 · q^(n²)`. Розглянемо верхню оцінку залишку ряду `R_N = ∑_{n=N+1}^∞ 2 · q^(n²)`:

```
R_N = 2 · ∑_{n=N+1}^∞ q^(n²)
    < 2 · q^((N+1)²) · ∑_{k=0}^∞ q^k
    = (2 · q^((N+1)²)) / (1 - q)
```

Якщо обрати поріг точності подвійної дійсності `eps = 10⁻¹⁵` (машинний нуль для типу `double` стандарту IEEE 754), то при `q = 0.5` уже для `N = 7` маємо:

```
a_7 = 2 · (0.5)⁴⁹ ≈ 2 · 1.77 · 10⁻¹⁵ ≈ 3.55 · 10⁻¹⁵
```

Таким чином, для підсумовування з машинною точністю потрібно виконати менше ніж 8 ітерацій циклу. Чисельна стійкість прямого додавання у цьому діапазоні є максимальною, оскільки всі доданки є строго додатними, а катастрофічна ануляція значущих розрядів повністю відсутня.

### 2. Зона модулярної редукції Якобі (великі номи q > 0.6)

Коли ном `q` наближається до одиниці (`q → 1⁻`), кутова швидкість спадання доданків `q^(n²)` стає критично малою. Наприклад, якщо `q = 0.9999`, член ряду `q^(1000²)` дорівнює `(0.9999)¹⁰⁰⁰⁰⁰⁰ ≈ e⁻¹⁰⁰ ≈ 3.7 · 10⁻⁴⁴`, що означає необхідність обчислення понад 1000 доданків. Додавання тисяч малих чисел до суми порядку `1` призводить до швидкого накопичення похибок округлення у молодших розрядах мантиси.

Для розв'язання цієї проблеми застосовується модулярне перетворення Якобі, яке випливає з формули підсумовування Пуассона. Нехай `q = e^(-π t)`, де параметр `t` виражається через логарифм:

```
t = -ln(q) / π
```

Оскільки `q → 1⁻`, параметр `t` прагне до нуля (`t → 0⁺`). Застосовуючи функціональне рівняння Якобі для тета-константи, переходимо до двоїстого нома `q'`:

```
θ₃(q) = (1 / √t) · θ₃(q')
```

де новий двоїстий ном `q'` дорівнює:

```
q' = e^(-π / t) = e^(-π² / ln(1/q))
```

Розглянемо ефект цього перетворення для `q = 0.9999`:
1. Обчислюємо параметр `t = -ln(0.9999) / π ≈ 0.000100005 / 3.14159 ≈ 3.183 · 10⁻⁵`.
2. Обчислюємо двоїстий ном `q' = e^(-π / (3.183 · 10⁻⁵)) = e^(-98696) ≈ 10⁻⁴²863`!

Новий ном `q'` виявляється настільки мізерно малим, що доданок `q'¹` є меншим за будь-яке число, яке може бути представлене у форматі плаваючої крапки. Отже, у двоїстому просторі значення тета-константи `θ₃(q')` з абсолютною точністю дорівнює **1.0**, і вся формула зводиться до єдиної арифметичної операції:

```
θ₃(q) ≈ 1 / √t = √(π / ln(1/q))
```

Завдяки цьому модулярному перетворенню складна задача підсумовування тисяч доданків розв'язується за 1-2 арифметичні операції з нульовою втратою точності.

### 3. Обчислення повного еліптичного інтеграла K(k) методом AGM

Повний еліптичний інтеграл першого роду `K(k)` виражається через тета-константу за формулою `K(k) = (π / 2) · (θ₃(q))²`, де модуль `k = (θ₂(q) / θ₃(q))²`.

Для безпосереднього обчислення `K(k)` без знаходження нома `q` застосовується квадрично-збіжний алгоритм арифмето-геометричного середнього (AGM) Ґаусса. Початкові значення задаються як:

```
a_0 = 1,   b_0 = √(1 - k²)
```

На кожному кроці `n ≥ 0` обчислюються нові значення за правилом:

```
a_{n+1} = (a_n + b_n) / 2
b_{n+1} = √(a_n · b_n)
```

Послідовності `a_n` та `b_n` монотонно збігаються до спільного граничного значення `AGM(1, √(1 - k²))`. Гранична швидкість збіжності є квадричною: кількість правильних десяткових знаків подвоюється на кожному кроці. Для обчислення інтеграла з точністю `10⁻¹⁵` достатньо виконати не більше ніж 4–5 ітерацій. Повний інтеграл обчислюється за формулою:

```
K(k) = π / (2 · AGM(1, √(1 - k²)))
```

## Реалізація обчислювального модуля (C та C++)

Нижче наведено ідіоматичні реалізації обчислювального модуля мовами C (стандарт C11) та C++ (стандарт C++20). 

У версії для C++ використовуються сучасні концепти мови: математичні константи з простору назв `std::numbers`, система обробки помилок через винятки `std::invalid_argument` та константна оптимізація.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <stdbool.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

/* Пряме підсумовування тета-константи theta3(q) для малих q */
double theta3_direct(double q, double eps) {
    if (q <= 0.0) return 1.0;
    
    double sum = 1.0;
    double term;
    int n = 1;
    
    do {
        term = 2.0 * pow(q, (double)(n * n));
        sum += term;
        n++;
    } while (term > eps && n < 1000);
    
    return sum;
}

/* Адаптивне обчислення theta3(q) з модулярним перетворенням Якобі */
double theta3_adaptive(double q, double eps) {
    if (q <= 0.0) return 1.0;
    if (q >= 1.0) return INFINITY;
    
    /* Якщо q > 0.6, виконуємо перетворення Якобі t -> 1/t */
    if (q > 0.6) {
        double t = -log(q) / M_PI;
        double q_prime = exp(-M_PI / t);
        double theta_prime = theta3_direct(q_prime, eps);
        return (1.0 / sqrt(t)) * theta_prime;
    }
    
    return theta3_direct(q, eps);
}

/* Обчислення повного еліптичного інтеграла K(k) через AGM */
double elliptic_k_agm(double k, double eps) {
    if (k < 0.0 || k >= 1.0) return INFINITY;
    
    double a = 1.0;
    double b = sqrt(1.0 - k * k);
    
    while (fabs(a - b) > eps) {
        double a_next = 0.5 * (a + b);
        double b_next = sqrt(a * b);
        a = a_next;
        b = b_next;
    }
    
    return M_PI / (2.0 * a);
}

int main(void) {
    double q_values[] = {0.1, 0.5, 0.9, 0.999, 0.99999};
    size_t count = sizeof(q_values) / sizeof(q_values[0]);
    double eps = 1e-15;
    
    printf("=== Обчислення тета-константи theta3(q) ===\n");
    for (size_t i = 0; i < count; i++) {
        double q = q_values[i];
        double res = theta3_adaptive(q, eps);
        printf("q = %-8.5f | theta3(q) = %-18.12f\n", q, res);
    }
    
    printf("\n=== Перевірка еліптичного інтеграла K(k) через AGM ===\n");
    double k = 0.5;
    double K_val = elliptic_k_agm(k, eps);
    printf("k = %.2f | K(k) = %.12f\n", k, K_val);
    
    return 0;
}
```

```cpp
#include <iostream>
#include <cmath>
#include <vector>
#include <numbers>
#include <iomanip>
#include <stdexcept>

class JacobiThetaCalculator {
public:
    static constexpr double default_eps = 1e-15;

    // Обчислення theta3(q) з використанням модулярного перетворення Якобі
    static double theta3(double q, double eps = default_eps) {
        if (q < 0.0 || q >= 1.0) {
            throw std::invalid_argument("Параметр q повинен належати [0, 1)");
        }
        if (q == 0.0) return 1.0;

        // Модулярна редукція при q > 0.6
        if (q > 0.6) {
            const double t = -std::log(q) / std::numbers::pi;
            const double q_prime = std::exp(-std::numbers::pi / t);
            const double theta_prime = theta3_direct(q_prime, eps);
            return (1.0 / std::sqrt(t)) * theta_prime;
        }

        return theta3_direct(q, eps);
    }

    // Обчислення повного еліптичного інтеграла K(k) через AGM
    static double elliptic_K(double k, double eps = default_eps) {
        if (k < 0.0 || k >= 1.0) {
            throw std::invalid_argument("Модуль k повинен належати [0, 1)");
        }

        double a = 1.0;
        double b = std::sqrt(1.0 - k * k);

        while (std::abs(a - b) > eps) {
            const double a_next = 0.5 * (a + b);
            const double b_next = std::sqrt(a * b);
            a = a_next;
            b = b_next;
        }

        return std::numbers::pi / (2.0 * a);
    }

private:
    static double theta3_direct(double q, double eps) {
        double sum = 1.0;
        double term = 0.0;
        int n = 1;

        do {
            term = 2.0 * std::pow(q, static_cast<double>(n * n));
            sum += term;
            ++n;
        } while (term > eps && n < 1000);

        return sum;
    }
};

int main() {
    try {
        const std::vector<double> test_q = {0.1, 0.5, 0.9, 0.999, 0.99999};

        std::cout << std::fixed << std::setprecision(12);
        std::cout << "=== Обчислення theta3(q) (C++) ===\n";
        for (double q : test_q) {
            double val = JacobiThetaCalculator::theta3(q);
            std::cout << "q = " << std::setw(8) << q << " | theta3(q) = " << val << '\n';
        }

        std::cout << "\n=== Обчислення K(k) через AGM (C++) ===\n";
        double k = 0.5;
        double K_val = JacobiThetaCalculator::elliptic_K(k);
        std::cout << "k = " << k << " | K(k) = " << K_val << '\n';
    } 
    catch (const std::exception& ex) {
        std::cerr << "Помилка: " << ex.what() << '\n';
        return 1;
    }

    return 0;
}
```

## Покроковий розбір обчислювального алгоритму

Для розуміння архітектури представлених програм розглянемо ключові елементи реалізації та їхню роль у забезпеченні обчислювальної стійкості:

1. **Функція `theta3_direct`:**
   Виконує пряме підсумовування ряду `1 + 2 ∑ q^(n²)`. Цикл за змінною `n` продовжується до тих пір, поки поточний доданок `term` перевищує заданий поріг `eps`. Захисна умова `n < 1000` запобігає безкінечному зацикленню у випадку некоректних вхідних даних або переповнення плаваючої крапки.

2. **Адаптивний селектор `theta3_adaptive` / `JacobiThetaCalculator::theta3`:**
   Аналізує величину входжуваного значення `q`. Якщо `q ≤ 0.6`, виклики спрямовуються безпосередньо в модуль прямого додавання. Якщо ж `q > 0.6`, алгоритм автоматично обчислює параметр `t = -ln(q) / π`, знаходить двоїстий ном `q'`, обчислює значення двоїстого ряду `theta_prime` та здійснює нормувальне множення на `1 / √t`.

3. **Функція `elliptic_k_agm` / `JacobiThetaCalculator::elliptic_K`:**
   Реалізує ітераційний процес AGM. На кожному кроці створюється середня арифметична величина `a_next = (a + b) / 2` та середня геометрична величина `b_next = √(a · b)`. Ітерації завершуються, коли абсолютна різниця `|a - b|` стає меншою за `eps`. Отримане значення `a` використовується у знаменнику підсумкової формули `π / (2 a)`.

## Оцінка обчислювальної складності та чисельні тести

Проведемо порівняльний аналіз кількості операцій з рухомою крапкою (FLOPs) та швидкості збіжності для двох алгоритмічних підходів при обчисленні `θ₃(q)` з точністю `10⁻¹⁵`:

| Параметр нома `q` | Прямий алгоритм (кількість ітерацій) | Адаптивний алгоритм Якобі (кількість ітерацій) | Прискорення (коефіцієнт) |
| :--- | :--- | :--- | :--- |
| `q = 0.1` | 4 ітерації | 4 ітерації | 1.0× (прямий режим) |
| `q = 0.5` | 7 ітерацій | 7 ітерацій | 1.0× (прямий режим) |
| `q = 0.9` | 19 ітерацій | 2 ітерації (після редукції `q' ≈ 10⁻⁴²`) | 9.5× |
| `q = 0.999` | 186 ітерацій | 1 ітерація (після редукції `q' ≈ 10⁻⁴²⁸⁶`) | 186× |
| `q = 0.99999` | 1860 ітерацій | 1 ітерація (після редукції `q' ≈ 0`) | 1860× |

Як видно з порівняльної таблиці, при наближенні `q` до одиниці адаптивний алгоритм з модулярним перетворенням Якобі дає прискорення понад **1800 разів**, знижуючи кількість арифметичних операцій з тисяч до одиниць та гарантуючи повну відсутність накопиченої похибки округлення.

## Очищення крайових випадків та чисельна стійкість

Під час проектування математичних бібліотек вищої точності розробник повинен враховувати наступні крайові режими та аномалії чисельного середовища:

### 1. Поведінка при від'ємному номі (q < 0)

Хоча у фізичних задачах термодинаміки параметр `q = e^(-π t)` є строго додатним (`q > 0`), у комплексній аналітиці від'ємні номи відповідають зміщенню комплексного параметра `τ` на одиницю (`τ ↦ τ + 1`). При від'ємних `q` ряд `θ₃(-|q|)` стає альтернаючим за степенями:

```
θ₃(-|q|) = 1 - 2|q| + 2|q|⁴ - 2|q|⁹ + 2|q|¹⁶ - ... = θ₄(|q|)
```

Отже, значення третьої тета-константи з від'ємним номом тотожно дорівнює значенню четвертої тета-константи з додатним номом `θ₄(|q|)`. Опрацювання цієї симетрії дозволяє уникнути від'ємних логарифмів та обчислювальних збоїв при переході до комплексних значень.

### 2. Захист від втрати значущих розрядів (Cancellation Error)

При додаванні доданків з однаковими знаками катастрофічна ануляція (втрата точних цифр при відніманні двох майже рівних великих чисел) не виникає. Однак для тета-константи `θ₄(q) = 1 - 2q + 2q⁴ - 2q⁹ + ...` при `q → 1⁻` значення функції прямує до нуля. Обчислення за прямим альтернаючим рядом призводить до того, що підсумкова сума віднімається від `1`, і всі 15 точних десяткових цифр типом `double` повністю губляться.

Використання модулярного перетворення Якобі для `θ₄(q)` повністю вирішує цю проблему через двоїсту формулу:

```
θ₄(e^(-π t)) = (1 / √t) · θ₂(e^(-π / t))
```

Оскільки `θ₂(q')` є строго додатною та збігається згори без жодного віднімання, модулярне перетворення гарантує збереження всіх 16 значущих цифр навіть для `q = 0.999999999`.

### 3. Оптимізація обчислення еліптичних кривих та періодів маятника

У класичній механіці точний період коливань фізичного маятника з кутовою амплітудою `θ_max` виражається через повний еліптичний інтеграл `K(k)`:

```
T = T_0 · (2 / π) · K(sin(θ_max / 2))
```

де `T_0 = 2π √(L / g)` — малоамплітудний гармонічний період. Використання представленої функції `elliptic_k_agm` дозволяє розраховувати період коливань маятника при будь-яких кутах аж до `θ_max = 179.99°` з машинною точністю менш ніж за 6 ітерацій AGM.

Така універсальність робить тета-функції Якобі незамінним математичним ядром для чисельних симуляцій, астрономічних обчислень та сучасної прикладної фізики.
