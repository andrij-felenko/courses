# Доведення формули Сильвестра

Джеймс Джозеф Сильвестр у 1884 році опублікував елегантне рішення задачі Фробеніуса для випадку двох базових елементівів. Він довів, що найбільша сума, яку неможливо виразити у вигляді комбінації генераторів базових елементівми a та b (де a та b взаємно прості, тобто gcd(a, b) = 1), дорівнює:
g(a, b) = a·b − a − b

Це надзвичайно красивий та компактний результат. Але чому він правильний? Як можна бути впевненим, що формула працює для будь-якої пари взаємно простих чисел a та b? Існує кілька способів доведення, але один із найвідоміших та найглибших використовує концепцію **твірних функцій** (generating functions) або структурних властивостей залишків. Ми розглянемо доведення через граф залишків (або множини лишків), яке найбільш природно витікає з розуміння задачі.

## Ідея доведення: розбиття на класи залишків

Уявимо, що ми хочемо сформувати суму N, використовуючи лише генераторів a та b. Наше завдання полягає в тому, щоб знайти невід'ємні цілі числа x та y такі, що:
N = a·x + b·y

Замість того, щоб намагатися підібрати x та y для кожного числа N окремо, давайте класифікуємо всі числа за їхньою остачею від ділення на одне з чисел, скажімо, a. 
Будь-яке ціле число N можна записати у вигляді N = a·q + r, де q — частка, а r — остача від 0 до a−1. Існує рівно a таких класів (або залишків): 0, 1, 2, ..., a−1.

Оскільки b та a взаємно прості, числа b, 2·b, 3·b, ..., (a−1)·b дають *всі можливі різні остачі* при діленні на a. Жодна з них не ділиться на a без остачі, і жодні дві з них не мають однакову остачу (інакше їхня різниця ділилася б на a, що неможливо). 

Отже, для будь-якої остачі r, існує єдине число y₀ (де 0 ≤ y₀ < a), таке, що b·y₀ має остачу r при діленні на a. Це найменше число, яке можна утворити лише з генераторів b і яке має остачу r.

## Формування будь-якої суми

Якщо ми можемо утворити суму S = b·y₀, яка має остачу r при діленні на a, то ми можемо утворити й будь-яку більшу суму з такою ж остачею! Як? Просто додаючи генераторів базових елементівм a. 
Суми з такою ж остачею мають вигляд S, S+a, S+2·a, S+3·a і так далі. 
Отже, будь-яке число N з остачею r, яке є більшим або рівним b·y₀, може бути виражене як:
N = b·y₀ + a·x, де x ≥ 0.

Таким чином, для конкретної остачі r, **найбільше число, яке НЕ можна виразити**, це просто число, яке на a менше за b·y₀.
Невиражене число = b·y₀ − a.

Оскільки це працює для кожної остачі r, найбільше число, яке взагалі неможливо виразити жодним чином — це максимум серед усіх цих «найбільших невиражених чисел» для кожного класу.

## Знаходження максимуму

Наше завдання звелося до того, щоб знайти максимальне значення виразу b·y₀ − a, коли y₀ пробігає всі можливі значення від 0 до a−1. 
Очевидно, що цей вираз буде максимальним, коли значення y₀ є найбільшим можливим. Найбільше можливе значення y₀ в нашому діапазоні — це (a − 1).

Підставимо y₀ = a − 1 у вираз:
Максимальне невиражене число = b·(a − 1) − a
= a·b − b − a

Перепишемо це у звичному вигляді:
g(a, b) = a·b − a − b

Ось і все! Ми математично точно знайшли найбільшу суму, яку не можна набрати двома базових елементівми a та b.

## Приклад

Перевіримо формулу на вже знайомому нам прикладі з генераторівми базових елементівм 3 та 5.
Тут a = 3, b = 5.
За формулою Сильвестра:
g(3, 5) = 3·5 − 3 − 5 = 15 − 8 = 7.
Це точно збігається з нашим попереднім результатом. 

Також формула показує кількість неможливих до сплати сум, яка розраховується як:
N(a, b) = (a−1)·(b−1) ÷ 2.
Для 3 та 5 це (3−1)·(5−1) ÷ 2 = 2·4 ÷ 2 = 4. І справді, числа 1, 2, 4 та 7 неможливо набрати. Формула Сильвестра є надійною основою теорії, хоча для трьох і більше базових елементівів подібної універсальної закритої формули вже не існує.
