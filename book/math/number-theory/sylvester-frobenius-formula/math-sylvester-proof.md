# Строге доведення формули Сильвестра

Щоб математично довести, що g(a,b) = a·b - a - b є найбільшим цілим числом, яке не можна подати як a·x + b·y (де x ≥ 0, y ≥ 0 і gcd(a,b)=1), скористаємося властивостями залишків від ділення.

## Крок 1. Аналіз залишків

Будь-яке ціле число можна подати у вигляді q·a + r, де r — залишок від ділення на a (0 ≤ r < a).
Розглянемо множину чисел B = {0, b, 2·b, 3·b, ..., (a-1)·b}. 
У цій множині рівно a елементів. Оскільки a та b взаємно прості, усі ці числа дають різні залишки при діленні на a. Якби два числа m·b та n·b (де 0 ≤ m < n < a) давали однаковий залишок, їхня різниця (n - m)·b ділилася б на a. Але gcd(a,b)=1, отже (n - m) має ділитися на a. Це неможливо, оскільки 0 < n - m < a.

Отже, елементи множини B покривають усі можливі залишки від 0 до a-1 при діленні на a.

## Крок 2. Найменші представимі числа для кожного залишку

Для будь-якого залишку r (від 0 до a-1) існує єдине число з множини B, яке дає такий самий залишок. Нехай це число y·b. Воно є найменшим числом з таким залишком, яке можна подати у вигляді a·x + b·y з невід'ємними коефіцієнтами. Чому найменше? Бо якщо ми віднімемо від нього a, то отримаємо число y·b - a. Оскільки y < a, ми не зможемо компенсувати це віднімання через доданок a·x з невід'ємним x, не зробивши коефіцієнт при b від'ємним.

## Крок 3. Знаходження найбільшого непредставимого числа

Найбільше непредставиме число буде на a меншим за найбільше з цих "мінімальних" чисел у множині B.
Найбільше число у множині B відповідає y = a - 1. Це число:
M = (a - 1)·b = a·b - b.

Будь-яке число, більше за M або рівне йому, що має такий самий залишок від ділення на a, як і M, можна подати як M + k·a (де k ≥ 0).
Число, яке має такий самий залишок як M, але на a менше (тобто M - a), не можна подати.

Отже, найбільше непредставиме число загалом — це:
g(a,b) = M - a = a·b - b - a = a·b - a - b.

## Обчислення кількості непредставимих чисел N(a,b)

Кожне число y·b з множини B є межею. Усі невід'ємні числа, що мають такий самий залишок як y·b і є меншими за нього, не можна подати. Таких чисел рівно y (бо вони йдуть з кроком a, починаючи від y·b - a аж до залишку).

Отже, загальна кількість непредставимих чисел N(a,b) дорівнює сумі y для всіх y від 0 до a-1:
N(a,b) = 0 + 1 + 2 + ... + (a - 1)

Використовуючи формулу суми арифметичної прогресії:
N(a,b) = (a - 1)·a / 2.

Зачекайте, це працює лише якщо ми рахуємо кроки по a. Точніше, кількість чисел, менших за y·b і додатних, що мають той самий залишок. Для конкретного y таких чисел y·b // a. Оскільки y·b можна записати як q·a + r, кількість недосяжних додатних чисел дорівнює q. 
Точніший симетричний метод доведення базується на тому, що сума g(a,b) - n та n має таку властивість: з кожної пари рівно одне число є представимим. Оскільки чисел від 0 до g(a,b) включно є a·b - a - b + 1, то рівно половина з них є представимими, а половина - ні.
N(a,b) = (a·b - a - b + 1) / 2 = (a - 1)·(b - 1) / 2.
Що й треба було довести.
