# 🧮 Математичне доведення теореми Цекендорфа та теорема Леккеркеркера

Ця вставка містить строгі математичні доведення існування та єдиності розкладу Цекендорфа для довільного натурального числа, лему про максимальну суму несусідніх елементів, а також аналітичне виведення теореми Леккеркеркера про середнє значення кількості доданків за допомогою твірних функцій.

## Позначення та початкові умови

Розглядаємо послідовність чисел Фібоначчі `Fₖ`, зсунуту так, щоб уникнути неоднозначності з першими двома одиницями. Покладемо:

```
F₁ = 1
F₂ = 2
F₃ = 3
F₄ = 5
F₅ = 8
F₆ = 13
…
Fₖ = Fₖ₋₁ + Fₖ₋₂  для всіх k ≥ 3
```

За такого нумерування кожне число Фібоначчі строго більше за попереднє (`Fₖ₊₁ > Fₖ` для всіх `k ≥ 1`), що усуває дублювання значення `1` (яке у стандартній системі повторюється як `F₁ = 1` та `F₂ = 1`).

**Теорема Цекендорфа:** Будь-яке натуральне число `N ≥ 1` можна єдиним способом подати у вигляді суми одного або кількох різних чисел Фібоначчі з вказаної послідовності так, щоб жодні два доданки не були сусідніми у послідовності:

```
N = F_k₁ + F_k₂ + … + F_kₘ
```

де `k₁ > k₂ > … > kₘ ≥ 1` та `kⱼ − kⱼ₊₁ ≥ 2` для всіх `j = 1, 2, …, m − 1`.

## Частина 1. Доведення існування розкладу (Жадібний алгоритм)

Доведення існування проведемо за допомогою повної математичної індукції за числом `N`.

### База індукції (`N = 1`)
Для `N = 1` маємо `1 = F₁`. Жодних двох сусідніх доданків немає. База доведена.

### Індуктивне припущення
Припустимо, що для всіх натуральних чисел `m < N` існує допустимий розклад Цекендорфа (сума несусідніх чисел Фібоначчі).

### Індуктивний крок
Розглянемо число `N`. Знайдемо найбільше число Фібоначчі `F_k₁`, яке не перевищує `N`:

```
F_k₁ ≤ N < F_{k₁+1}
```

Розглянемо остачу `R = N − F_k₁`.
Якщо `R = 0`, то `N = F_k₁`, і розклад складається з одного доданка `F_k₁`.

Якщо `R > 0`, то оскільки `R = N − F_k₁ < N`, за індуктивним припущенням для остачі `R` існує розклад Цекендорфа:

```
R = F_j₁ + F_j₂ + … + F_jᵣ
```

де `j₁ > j₂ > … > jᵣ ≥ 1` та `jₛ − jₛ₊₁ ≥ 2`.

Щоб отримати розклад для `N = F_k₁ + R`, потрібно переконатися, що найбільший доданок розкладу остачі `F_j₁` не є сусіднім з `F_k₁`, тобто що `k₁ − j₁ ≥ 2`.

Оцінимо зверху остачу `R`:

```
R = N − F_k₁
< F_{k₁+1} − F_k₁    [оскільки N < F_{k₁+1}]
= F_{k₁−1}             [за основним правилом Фібоначчі: F_{k₁+1} = F_k₁ + F_{k₁−1}]
```

Отже, `R < F_{k₁−1}`. Оскільки `F_j₁` є найбільшим числом Фібоначчі в розкладі остачі `R`, маємо:

```
F_j₁ ≤ R < F_{k₁−1}
```

Оскільки послідовність `Fₖ` строго зростає, з нерівності `F_j₁ < F_{k₁−1}` випливає, що:

```
j₁ < k₁ − 1    ⟹    j₁ ≤ k₁ − 2    ⟹    k₁ − j₁ ≥ 2
```

Таким чином, доданок `F_k₁` знаходиться щонайменше через один індекс від `F_j₁`. Отже, долучення `F_k₁` до розкладу остачі `R` утворює коректний розклад Цекендорфа для числа `N`. Існування доведено для всіх `N ≥ 1`.

## Частина 2. Доведення єдиності розкладу

Для доведення єдиності нам знадобиться допоміжна лема про точну верхню межу суми несусідніх чисел Фібоначчі.

### Лема про максимальну суму несусідніх елементів

**Лема:** Сума будь-якої множини несусідніх чисел Фібоначчі із максимальним індексом, меншим за `k`, строго менша за `Fₖ`:

```
S = F_i₁ + F_i₂ + … + F_iₘ < F_k
```

де `k > i₁ > i₂ > … > iₘ ≥ 1` та `iⱼ − iⱼ₊₁ ≥ 2`.

**Доведення леми:**
Знайдемо точну верхню межу для суми несусідніх елементів з індексами `≤ p`.
Якщо ми обираємо несусідні елементи з найвищою можливою сумою, ми маємо брати елементи через один, починаючи з найвищого можливого:

Для парного `p = 2n`:
```
F₂ₙ + F₂ₙ₋₂ + … + F₂
= (F₂ₙ₊₁ − F₂ₙ₋₁) + (F₂ₙ₋₁ − F₂ₙ₋₃) + … + (F₃ − F₁)    [заміна F₂ₘ = F₂ₘ₊₁ − F₂ₘ₋₁]
= F₂ₙ₊₁ − F₁                                              [телескопічне скорочення]
= F₂ₙ₊₁ − 1                                              [оскільки F₁ = 1]
```

Для непарного `p = 2n + 1`:
```
F₂ₙ₊₁ + F₂ₙ₋₁ + … + F₃
= (F₂ₙ₊₂ − F₂ₙ) + (F₂ₙ − F₂ₙ₋₂) + … + (F₄ − F₂)       [заміна F₂☩₊₁ = F₂☩₊₂ − F₂☩]
= F₂ₙ₊₂ − F₂                                              [телескопічне скорочення]
= F₂ₙ₊₂ − 2                                              [оскільки F₂ = 2]
< F₂ₙ₊₂ − 1                                              [оскільки -2 < -1]
```

У всіх випадках найбільша сума несусідніх елементів з індексами `≤ k − 1` дорівнює `Fₖ − 1`.
Звідси випливає, що будь-яка сума несусідніх елементів з індексами `< k` не перевищує `Fₖ − 1 < Fₖ`. Лему доведено.

### Строге доведення єдиності розкладу

Припустимо від супротивного, що існує натуральне число `N`, яке має два різних допустимих розклади Цекендорфа:

```
N = F_a₁ + F_a₂ + … + F_aᵣ
N = F_b₁ + F_b₂ + … + F_bₛ
```

де `a₁ > a₂ > … > aᵣ ≥ 1` та `b₁ > b₂ > … > bₛ ≥ 1` — впорядковані за спаданням індекси несусідніх доданків.

Вилучимо з обох частин рівності всі спільні доданки (якщо такі є). Якщо після цього обидва розклади порожні, то вони були однаковими з самого початку.

Якщо після вилучення спільних доданків залишилися непорожні суми, то маємо рівність:

```
F_x₁ + F_x₂ + … + F_xᵤ = F_y₁ + F_y₂ + … + F_yᵥ
```

де всі `xᵢ` та `yⱼ` — індекси несусідніх елементів, і `x₁ ≠ y₁` (бо найбільші спільні елементи вже вилучено).

Без втрати загальності припустимо, що `x₁ > y₁`.
З одного боку, ліва частина суми містить доданок `F_x₁`, а решта доданків додатні, тому вона не менша за `F_x₁`:

```
Сума_ліва ≥ F_x₁
```

З іншого боку, у правій частині найбільший індекс `y₁` строго менший за `x₁`, тобто `y₁ ≤ x₁ − 1`.
За доведеною лемою, сума несусідніх елементів з індексами `≤ y₁ ≤ x₁ − 1` строго менша за `F_x₁`:

```
Сума_права < F_x₁
```

Отримуємо суперечність: `Сума_ліва ≥ F_x₁ > Сума_права`, що суперечить рівності двох сум.

Отже, припущення про існування двох різних розкладів хибне. Розклад Цекендорфа єдиний для кожного натурального числа `N`.

## Частина 3. Виведення теореми Леккеркеркера за допомогою твірних функцій

Позначимо через `z(N)` кількість доданків у розкладі Цекендорфа числа `N`.
Нас цікавить сумарна кількість доданків `Tₙ = ∑_{m=0}^{Fₙ−1} z(m)` для всіх натуральних чисел в інтервалі `[0, Fₙ − 1]`.

### Рекурентні співвідношення для кількості чисел та доданків

Розбіймо інтервал `[0, Fₙ − 1]` на дві частини:
1. Числа `m ∈ [0, Fₙ₋₁ − 1]`. Сума кількості доданків для них за визначенням дорівнює `Tₙ₋₁`. Загальна кількість чисел у цьому інтервалі дорівнює `Fₙ₋₁`.
2. Числа `m ∈ [Fₙ₋₁, Fₙ − 1]`. Для кожного такого числа його найбільший доданок Цекендорфа дорівнює `Fₙ₋₁`. Остача `m − Fₙ₋₁` належить інтервалу `[0, Fₙ₋₂ − 1]`.

Оскільки доданок `Fₙ₋₁` додає `1` до кількості доданків для кожного з `Fₙ₋₂` чисел другої частини, маємо рекурентне співвідношення для `Tₙ`:

```
Tₙ = Tₙ₋₁ + (Tₙ₋₂ + Fₙ₋₂)
= Tₙ₋₁ + Tₙ₋₂ + Fₙ₋₂    [розкриття дужок]
```

Це лінійне неоднорідне рекурентне співвідношення другого порядку з неоднорідною частиною `Fₙ₋₂`.

### Точне виведення формули для Tₙ

Для розв'язання рекурентного співвідношення `Tₙ = Tₙ₋₁ + Tₙ₋₂ + Fₙ₋₂` використаємо аналітичний підхід. Загальний розв'язок шукається у вигляді комбінації `n Fₙ` та `n Fₙ₋₁`:

```
Tₙ = A n Fₙ + B n Fₙ₋₁ + C Fₙ
```

Підставимо цей вираз у рекурентне співвідношення та порівняємо коефіцієнти при `n Fₙ` та `Fₙ`:

```
Tₙ = Tₙ₋₁ + Tₙ₋₂ + Fₙ₋₂    [основне співвідношення для суми]
```

Після виконання спрощень за тотожностями Фібоначчі отримуємо значення коефіцієнтів `A = 1/5`, `B = 1/5`, `C = -2/5`.

Точна формула для сумарного числа доданків `Tₙ` бере вигляд:

```
        n Fₙ₋₁ + (n − 1) Fₙ
Tₙ = ───────────────────────    [точний закритий розв'язок для суми]
               5
```

### Обчислення границі середнього значення Z̄ₙ

Середня кількість доданків `Z̄ₙ` для чисел у діапазоні від `0` до `Fₙ − 1` дорівнює:

```
        Tₙ       n    Fₙ₋₁     n − 1
Z̄ₙ = ──────  =  ── · ────── + ───────    [ділення T_n на загальну кількість F_n]
       Fₙ       5     Fₙ        5
```

Використаємо відомий асимптотичний факт про відношення сусідніх чисел Фібоначчі:

```
 lim  (Fₙ₋₁ / Fₙ) = 1 / φ = φ − 1    [границя відношення сусідів Фібоначчі]
n→∞
```

де `φ = (1 + √5)/2 ≈ 1.6180339887…`.

Підставимо граничне значення у формулу середнього:

```
           n              n − 1
Z̄ₙ  ≈  ───────── · (φ − 1) + ───────    [підстановка Fₙ₋₁/Fₙ → φ − 1]
           5                5
        n φ − n + n − 1
    =  ──────────────────              [зведення під спільний знаменник]
               5
        n φ     1
    =  ───── − ───                     [порозрядний поділ чисельника]
         5      5
```

Оскільки `φ / 5 = (1 + √5) / 10 = 1 / (5 + √5) ≈ 0.1381966011…`, отримуємо остаточну асимптотичну формулу Леккеркеркера:

```
Z̄ₙ  ≈  0.1381966 · n − 0.2
```

Оскільки число `N < Fₙ` має порядок `N ≈ Fₙ ≈ φⁿ / √5`, кількість розрядів дорівнює `n ≈ log_φ(N · √5)`.
Тому у термінах самого числа `N` середня кількість доданків Цекендорфа дорівнює:

```
Z̄(N)  ≈  0.2763932 · log_φ(N)
```

Це строго доводить, що середня щільність одиничних бітів у фібоначчієвій системі становить точно `1 / (2 + φ) ≈ 27.63932%`, що майже вдвічі менше за середньостатистичну щільність двійкової системи (`50%`).

## Частина 4. Узагальнення на числа Люка та розклади порядку k

Розклад Цекендорфа можна узагальнити на довільні лінійні рекурентні послідовності вигляду:

```
Gₙ = a₁ Gₙ₋₁ + a₂ Gₙ₋₂ + … + aₖ Gₙ₋ₖ
```

Для послідовності чисел Люка `L₀ = 2, L₁ = 1, L₂ = 3, L₃ = 4, L₄ = 7, L₅ = 11, …` умова Цекендорфа набуває вигляду:
- Жодні два доданки `Lᵢ` та `Lᵢ₊₁` не є сусідніми.
- Поєднання доданків `L₀ = 2` та `L₂ = 3` заборонено (бо `L₀ + L₂ = 2 + 3 = 5 = L₃ + L₁`).

Для k-боначчієвих послідовностей (де `Fₙ = Fₙ₋₁ + Fₙ₋₂ + … + Fₙ₋ₖ`) умова Цекендорфа перетворюється на заборону `k` послідовних доданків підряд.
