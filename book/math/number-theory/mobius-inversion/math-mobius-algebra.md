# 🧮 Алгебраїчна структура та узагальнення обернення Мьобіуса

Цей математичний розбір будує строгий алгебраїчний фундамент формули обернення Мьобіуса. У ньому виводяться фундаментальні тотожності згортки Діріхле, описується матрична інтерпретація на скінченних решітках подільності та доводиться загальна теорема Джана-Карло Рота про інцидентні алгебри частково впорядкованих множин.

## 1. Строге виведення класичного обернення Мьобіуса

Нехай `f: ℤ⁺ → ℂ` — довільна arithmetic функція, яка зіставляє кожному натуральному числу комплексне значення. Побудуємо нову арифметичну функцію `g(n)` шляхом підсумовування значень `f(d)` по всіх дільниках `d`, які ділять число `n`:

```
g(n) = ∑_{d|n} f(d)
```

Сформулюємо та доведемо теорему про можливість точного відновлення вихідних значень `f(n)` через знаковперемінну суму значень `g`:

```
f(n) = ∑_{d|n} μ(d) · g(n/d) = ∑_{d|n} μ(n/d) · g(d)
```

### Крок 1: Підстановка прямої формули
Розгорнемо значення `g(n/d)` у правій частині виразу через його базове означення суми по дільниках. Оскільки аргументом є `n/d`, дільники цієї частки позначимо через `m`:

```
∑_{d|n} μ(d) · g(n/d)
= ∑_{d|n} μ(d) · [ ∑_{m | (n/d)} f(m) ]        [підстановка означення g(n/d)]
```

### Крок 2: Перегрупування подвійної суми
Проаналізуємо структуру пар дільників `(d, m)`. Умова `d | n` означає існування цілого `k₁` такого, що `d · k₁ = n`. Внутрішня умова `m | (n/d)` означає існування цілого `k₂` такого, що `m · k₂ = n / d`, що еквівалентно тотожності `d · m · k₂ = n`.

Це співвідношення є цілком симетричним відносно дільників `d` та `m`. Умова, що `d` ділить `n`, а `m` ділить частку `n/d`, повністю рівносильна умові, що `m` ділить `n`, а `d` ділить частку `n/m`.

Змінимо порядок підсумовування, зробивши зовнішньою змінною дільник `m`, а внутрішньою — дільник `d`:

```
∑_{d|n} μ(d) · [ ∑_{m | (n/d)} f(m) ]
= ∑_{m|n} f(m) · [ ∑_{d | (n/m)} μ(d) ]        [зміна порядку підсумовування за дільниками]
```

### Крок 3: Аналіз внутрішньої суми коефіцієнтів
Розглянемо внутрішній доданок `S(n/m) = ∑_{d | (n/m)} μ(d)`. Позначимо частку `k = n/m`. Оскільки `m` є дільником `n`, частка `k` обов'язково є натуральним числом `k ≥ 1`.

Згадайємо фундаментальну властивість підсумовування функції Мьобіуса по решітці дільників:

```
∑_{d|k} μ(d) = [k == 1] = { 1,  якщо k = 1
                          { 0,  якщо k > 1
```

Застосуємо цю властивість до нашої внутрішньої суми, де `k = n/m`:
- Для всіх `m < n` частка `n/m > 1`, тому внутрішня сума `S(n/m) = 0`.
- Для єдиного значення `m = n` частка `n/n = 1`, тому внутрішня сума `S(1) = μ(1) = 1`.

### Крок 4: Фінальне спрощення
Враховуючи обнулення всіх доданків при `m < n`, подвійна сума згортається у єдиний ненульовий доданок:

```
∑_{m|n} f(m) · [ ∑_{d | (n/m)} μ(d) ]
= ∑_{m|n} f(m) · [n/m == 1]                     [застосування тотожності суми μ]
= f(n) · 1 + ∑_{m < n, m|n} f(m) · 0             [виділення єдиного ненульового доданка при m = n]
= f(n)                                           [підсумкове спрощення]
```

Теорему доведено строго й повністю.

## 2. Кільце згортки Діріхле та векторні простори

Арифметика числових функцій набуває цілісної алгебраїчної форми, якщо розглядати множину всіх відображень `A = { f: ℤ⁺ → ℂ }` як алгебраїчну структуру.

Множина `A` утворює нескінченновимірний векторний простір над полем комплексних чисел `ℂ` відносно поелементного додавання `(f + g)(n) = f(n) + g(n)` та множення на скаляр `(c · f)(n) = c · f(n)`.

Додатково на цьому просторі вводиться операція внутрішнього множення — **згортка Діріхле**:

```
(f * g)(n) = ∑_{d|n} f(d) · g(n/d) = ∑_{a · b = n} f(a) · g(b)
```

### Алгебраїчні властивості згортки:
1. **Комутативність:** `f * g = g * f` для будь-яких арифметичних функцій.
2. **Асоціативність:** `(f * g) * h = f * (g * h)`.
3. **Дистрибутивність:** `f * (g + h) = f * g + f * h`.
4. **Нейтральний елемент:** функція `e(n) = [n == 1]` виконує роль алгебраїчної одиниці, оскільки `f * e = e * f = f`.
5. **Мультиплікативна замкненість:** згортка двох мультиплікативних функцій завжди є мультиплікативною функцією.

У цій алгебрі функція `g(n) = ∑_{d|n} f(d)` записується як `g = f * u`, де `u(n) = 1` є постійною одиничною функцією.

Тотожність `∑_{d|n} μ(d) = [n == 1]` мовою алгебри функцій виражається точним співвідношенням:

```
μ * u = e
```

Це означає, що функція Мьобіуса `μ` є оберненим елементом до постійної функції `u` у кільці арифметичних функцій: `u⁻¹ = μ`.

Таким чином, процес обернення Мьобіуса описується як множення рівняння `g = f * u` на обернений елемент `μ`:

```
g * μ = (f * u) * μ
= f * (u * μ)                                   [закон асоціативності]
= f * e                                         [підстановка u * μ = e]
= f                                             [властивість нейтрального елемента]
```

Це показує, що обернення Мьобіуса є універсальним алгебраїчним інверсуванням у кільці згортки.

## 3. Матричне представлення та оператори на решітках

Для будь-якого фіксованого натурального числа `n` розглянемо впорядковану множину всіх його дільників: `D_n = {d₁, d₂, ..., d_N}`, де `d₁ = 1`, а `d_N = n`.

Будь-яку арифметичну функцію `f` можна обмежити на множину `D_n` й подати у вигляді `N`-вимірного вектора-стовпчика `F = [f(d₁), f(d₂), ..., f(d_N)]ᵀ`.

Операція підсумовування по дільниках `g(d_i) = ∑_{d_j | d_i} f(d_j)` є лінійним оператором, який перетворює вектор `F` на вектор `G = [g(d₁), g(d₂), ..., g(d_N)]ᵀ`.

У матричній формі це перетворення виражається множенням на нижньотрикутну матрицю подільності `Z` (дзета-матрицю):

```
G = Z · F
```

де елементи матриці `Z` розміру `N × N` визначаються як:

```
Z_{i, j} = { 1,  якщо d_j ділить d_i
           { 0,  інакше
```

Оскільки дільники впорядковані за зростанням, матриця `Z` є строго нижньотрикутною, а її діагональні елементи `Z_{i, i} = 1` (оскільки кожне число ділить саме себе).

Отже, детермінант матриці дорівнює добутку діагональних елементів `det(Z) = 1 ≠ 0`. Це гарантує існування єдиної оберненої матриці `M = Z⁻¹`.

Елементи оберненої матриці `M` виражаються безпосередньо через значення функції Мьобіуса:

```
M_{i, j} = { μ(d_i / d_j),  якщо d_j ділить d_i
           { 0,             інакше
```

Формула обернення Мьобіуса на скінченній решітці дільників набуває прозорого лінійно-алгебраїчного змісту:

```
F = Z⁻¹ · G = M · G
```

Це доводить, що обернення Мьобіуса є результатом явно побудованої оберненої матриці для оператора подільності.

## 4. Інцидентні алгебри та загальна теорія Джана-Карло Рота

У 1964 році Джан-Карло Рота узагальнив поняття обернення Мьобіуса на довільні частково впорядковані множини (посети), створивши теорію **інцидентних алгебр**.

Нехай `(P, ≤)` — локально скінченний посет (тобто для будь-яких `x ≤ y` у `P` інтервал `[x, y] = { z ∈ P : x ≤ z ≤ y }` містить скінченну кількість елементів).

### Означення інцидентної алгебри
**Інцидентною алгеброю** `I(P)` називається множина всіх функцій двох змінних `h: P × P → ℂ`, для яких `h(x, y) = 0`, якщо `x ≰ y`.

Операція множення у цій алгебрі визначається як згортка по інтервалу:

```
(h₁ * h₂)(x, y) = ∑_{x ≤ z ≤ y} h₁(x, z) · h₂(z, y)
```

Одиницею інцидентної алгебри є дельта-функція Кронекера `δ(x, y) = [x == y]`.

### Дзета-функція та функція Мьобіуса посету
**Дзета-функцією посету** називається елемент `ζ ∈ I(P)`, визначений як:

```
ζ(x, y) = { 1,  якщо x ≤ y
          { 0,  інакше
```

**Функцією Мьобіуса посету** називається елемент `μ ∈ I(P)`, який є оберненим до `ζ` відносно згортки: `μ * ζ = ζ * μ = δ`.

Це дає фундаментальне рекурентне співвідношення для обчислення `μ(x, y)` на довільному посеті:

```
1. μ(x, x) = 1                            для всіх x ∈ P
2. μ(x, y) = - ∑_{x ≤ z < y} μ(x, z)      для всіх x < y
```

### Теорема про обернення Рота
Для довільних функцій `f, g: P → ℂ` на посеті справджується двостороння еквівалентність:

```
Пряма форма:     g(y) = ∑_{x ≤ y} f(x)
Обернена форма:  f(y) = ∑_{x ≤ y} g(x) · μ(x, y)
```

### Важливі випадки інцидентних алгебр:
1. **Решітка дільників `(D_n, |)`:** дає класичну формулу Мьобіуса, де `μ(x, y) = μ(y/x)`.
2. **Булева решітка підмножин `(2^S, ⊆)`:** дає Принцип включень-виключень (PIE), де `μ(A, B) = (-1)^{|B| - |A|}`.
3. **Решітка розбиттів множини `Π_n`:** дає формули для обчислення хроматичних многочленів графів та чисел Стірлінга другого роду.
