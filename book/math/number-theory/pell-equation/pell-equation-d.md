> 🔧 **Навіщо це.**
> Рівняння Пелля `x² - d·y² = 1` є центральним об'єктом класичної теорії чисел, який поєднує алгебраїчні розширення кілець, геометрію діофантових наближень та теорію неперервних дробів. Воно є ключем до обчислення регуляторів та чисел класів дійсних квадратичних полів, розкладання великих цілих чисел на множники (алгоритм Shanks' SQSFO) та побудови криптографічних протоколів на основі арифметики квадратичних кривих.

Якщо спробувати побудувати прямокутний трикутник з однаковими цілочисельними катетами `y` та `y`, то за теоремою Піфагора його гіпотенуза `x` має задовольняти співвідношення `x² = 2·y²`. Оскільки квадратний корінь `√2` є ірраціональним числом (числом, що не виражається точним відношенням двох цілих чисел), точного цілочисельного розв'язку цього рівняння у натуральних числах не існує. Однак, якщо послабити умову й шукати таку цілочисельну пару `(x, y)`, для якої квадрат гіпотенузи відрізняється від подвоєного квадрата катета лише на одиницю, ми отримуємо класичне квадратичне діофантове рівняння `x² - 2·y² = 1`.

Найменша позитивна пара `(3, 2)` дає значення `3² - 2·2² = 9 - 8 = 1`. Відношення цих чисел `3 / 2 = 1.5` слугує першим раціональним наближенням до значення `√2 ≈ 1.41421356`. Наступною цілочисельною парою є `(17, 12)`, для якої `17² - 2·12² = 289 - 288 = 1`, а відповідне раціональне число `17 / 12 ≈ 1.41666` дає значно точніше наближення. Послідовне знаходження таких пар дозволяє будувати якнайточніші раціональні наближення до ірраціональних квадратних коренів.

Узагальнення цієї проблеми для довільного заданого додатного цілого числа `d` (лат. *determinans* — визначник) задається класичним **рівнянням Пелля**:

```
x² - d·y² = 1
```

де невідомими є шукані цілі числа `x` та `y`.

Якщо параметр `d` є точним квадратом цілого числа (`d = k²` для деякого `k ∈ Z`), рівняння легко розкладається на множники за формулою різниці квадратів:

```
(x - k·y)·(x + k·y) = 1
```

Оскільки єдиними цілими дільниками одиниці у кільці цілих чисел є `1` та `-1`, отримана система лінійних рівнянь має лише тривіальні розв'язки `x = ±1` та `y = 0`. Оскільки випадки точних квадратів є тривіальними й не несуть ірраціональної структури, надалі **параметр `d` завжди вважається додатним цілим числом, яке не є точним квадратом**.

## 1. Геометрична природа: Дискретні вузли на гіперболах

З точки зору аналітичної геометрії рівняння `x² - d·y² = 1` описує на декартовій площині `R²` гладку двовіткову гіперболу (грец. *hyperbole* — надлишок, вихід за межі), яка симетрична відносно початку координат та осей координатної системи.

![Дискретні розв'язки рівняння Пелля на гіперболі](/book/math/number-theory/pell-equation/img/pell-hyperbola.svg)
*Дискретні цілочисельні розв'язки (x, y) на ветві гіперболи x² - 2y² = 1 та їхнє віддалення уздовж асимптоти.*

Гіпербола складається з двох симетричних віток, які перетинають вісь абсцис `X` у вершинах з координатами `(1, 0)` та `(-1, 0)`. При прямуванні змінних `x` та `y` до нескінченності вітки гіперболи асимптотично наближаються до прямих асимптот, які задаються рівняннями:

```
y = ± x / √d
```

Задача пошуку цілочисельних розв'язків рівняння Пелля геометрично відповідає знаходженню вузлів цілочисельної решітки `Z²` (тобто точок на площині з цілими координатами `(x, y)`), які розташовані точно на поверхні цієї гіперболи.

Поділивши обидві частини рівняння `x² - d·y² = 1` на `y²` (при `y ≠ 0`), отримуємо співвідношення:

```
(x / y)² - d = 1 / y²
```

Перенесши `d` у праву частину та добувши квадратний корінь, маємо:

```
x / y = √(d + 1 / y²) = √d · √(1 + 1 / (d·y²))
```

Застосовуючи формулу біноміального розкладу Тейлора для малої величини `1 / (d·y²)`, отримуємо наближення:

```
x / y ≈ √d · (1 + 1 / (2·d·y²)) = √d + 1 / (2·√d·y²)
```

Отже, різниця між раціональним дробом `x / y` та ірраціональним числом `√d` оцінюється як:

```
|x / y - √d| ≈ 1 / (2·√d·y²) < 1 / (2·y²)
```

Ця нерівність є фундаментальною: вона показує, що кожен цілочисельний розв'язок `(x, y)` рівняння Пелля дає надзвичайно точне раціональне наближення `x / y` до ірраціонального числа `√d`, причому похибка наближення спадає обернено пропорційно квадрату знаменника `y²`. Що далі дискретний розв'язок віддаляється вздовж гіперболи, то ближче точка підходить до асимптоти і то вищою є точність відповідного дробу.

Геометрично множина дійсних розв'язків гіперболи `x² - d·y² = 1` утворює неперервну однопараметричну групу Лі, яка ізоморфна мультиплікативній групі дійсних чисел або групі гіперболічних поворотів (перетворень Лоренца). Дискретні цілочисельні розв'язки утворюють дискретну підгрупу цієї групи, що генерується єдиним фундаментальним елементом.

## 2. Алгебраїчний фундамент: Норма та група одиниць у кільці Z[√d]

Найбільш глибоке й математично строге пояснення внутрішньої структури розв'язків рівняння Пелля дає абстрактна алгебра та теорія алгебраїчних чисел.

Розглянемо квадратне розширення кільця цілих чисел `Z`, утворене приєднанням ірраціонального елемента `√d`. Множина виразів виду:

```
Z[√d] = {a + b·√d | a, b ∈ Z}
```

утворює комутативне кільце відносно стандартних операцій додавання та множення дійсних чисел.

Для кожного елемента `α = a + b·√d` виділяють спряжений елемент `ᾱ = a - b·√d`. **Алгебраїчна норма** (лат. *norma* — косинець, норматив) елемента `α` визначається як добуток елемента на його спряжений:

```
N(α) = α·ᾱ = (a + b·√d)·(a - b·√d) = a² - d·b²
```

Норма володіє ключовою властивістю **мультиплікативності**: для будь-яких двох елементів `α, β ∈ Z[√d]` норма їхнього добутку дорівнює добутку їхніх норм:

```
N(α·β) = N(α)·N(β)
```

Перевіримо цю властивість безпосереднім розкриттям дужок. Для `α = a₁ + b₁·√d` та `β = a₂ + b₂·√d`:

```
α·β = (a₁·a₂ + d·b₁·b₂) + (a₁·b₂ + a₂·b₁)·√d
```

Обчислюючи норму добутку `N(α·β)`, маємо:

```
N(α·β)
= (a₁·a₂ + d·b₁·b₂)² - d·(a₁·b₂ + a₂·b₁)²      [визначення норми елемента]
= a₁²·a₂² + 2·d·a₁·a₂·b₁·b₂ + d²·b₁²·b₂² - d·a₁²·b₂² - 2·d·a₁·a₂·b₁·b₂ - d·a₂²·b₁² [розкриття квадратів]
= a₁²·a₂² + d²·b₁²·b₂² - d·a₁²·b₂² - d·a₂²·b₁²  [скорочення подвоєних добутків]
= a₁²·(a₂² - d·b₂²) - d·b₁²·(a₂² - d·b₂²)       [винесення спільних множників]
= (a₁² - d·b₁²)·(a₂² - d·b₂²)                  [факторизація]
= N(α)·N(β)                                    [підстановка норм]
```

З цієї властивості випливає фундаментальний алгебраїчний зміст рівняння Пелля: **знаходження цілочисельних розв'язків (x, y) рівняння `x² - d·y² = 1` еквівалентне знаходженню елементів `α = x + y·√d` у кільці `Z[√d]`, алгебраїчна норма яких дорівнює точно одиниці (`N(α) = 1`)**.

Множина всіх елементів кільця, які мають обернений елемент відносно множення, називається **групою одиниць** кільця і позначається `U(Z[√d])`. Елемент `α ∈ Z[√d]` є оборотним (одиницею кільця) тоді і тільки тоді, коли його норма дорівнює `±1`:

```
N(α) = ±1
```

За теоремою Діріхле про одиниці (Peter Gustav Lejeune Dirichlet, 1805–1859) для дійсних квадратичних полів, група одиниць `U(Z[√d])` є мультиплікативною групою, яка ізоморфна прямому добутку скінченної групи знаків `{±1}` та нескінченної нескінченної циклічної групи:

```
U(Z[√d]) ≅ {±1} × Z
```

Це означає, що серед усіх додатних розв'язків, відмінних від тривіального `(1, 0)`, існує єдиний найменший розв'язок `(x₁, y₁)` з `x₁ > 1, y₁ > 0`, який утворює **фундаментальну одиницю** кільця:

```
ε₁ = x₁ + y₁·√d
```

Усі інші цілочисельні розв'язки `(xₙ, yₙ)` рівняння Пелля утворюються шляхом піднесення фундаментальної одиниці `ε₁` до натуральних степенів `n ∈ N`:

```
xₙ + yₙ·√d = (x₁ + y₁·√d)ⁿ
```

Детальний аналіз історичної плутанини навколо назви рівняння, ролі Леонарда Ейлера, Джона Пелля та Вільяма Брункера наведено у вставці [Історичний екскурс про плутанину Ейлера та індійські корені рівняння Пелля](book:math/pell-equation/hist-pell-name.md).

### Явні рекурентні формули генерування розв'язків

Розкриваючи степінь `(xₙ + yₙ·√d) = (xₙ₋₁ + yₙ₋₁·√d)·(x₁ + y₁·√d)`, ми отримуємо явні рекурентні формули для послідовного обчислення всіх розв'язків:

```
xₙ = x₁·xₙ₋₁ + d·y₁·yₙ₋₁
yₙ = y₁·xₙ₋₁ + x₁·yₙ₋₁
```

з початковими базовими значеннями `x₀ = 1` та `y₀ = 0`.

Альтернативно, послідовності `xₙ` та `yₙ` задовольняють однакову лінійну однорідну рекурентність другого порядку з характеристичним рівнянням, корінням якого є `ε₁` та `ε₁̄`:

```
xₙ = 2·x₁·xₙ₋₁ - xₙ₋₂
yₙ = 2·x₁·yₙ₋₁ - yₙ₋₂
```

Проілюструємо це на конкретному числовому прикладі для `d = 2`.

Для `d = 2` найменшим нетривіальним розв'язком є `(x₁, y₁) = (3, 2)`, оскільки `3² - 2·2² = 9 - 8 = 1`. Відповідна фундаментальна одиниця дорівнює `ε₁ = 3 + 2·√2`.

Обчислимо наступні члени послідовності розв'язків:
1. `n = 1`: `(x₁, y₁) = (3, 2)`. Перевірка: `3² - 2·2² = 1`.
2. `n = 2`: `(3 + 2·√2)² = 9 + 8 + 12·√2 = 17 + 12·√2`  ⇒  `(x₂, y₂) = (17, 12)`.
   Перевірка: `17² - 2·12² = 289 - 288 = 1`.
   За формулою рекурентності: `x₂ = 2·3·3 - 1 = 17`, `y₂ = 2·3·2 - 0 = 12`.
3. `n = 3`: `(17 + 12·√2)·(3 + 2·√2) = (17·3 + 2·12·2) + (17·2 + 12·3)·√2 = 99 + 70·√2`  ⇒  `(x₃, y₃) = (99, 70)`.
   Перевірка: `99² - 2·70² = 9801 - 9800 = 1`.
   За формулою рекурентності: `x₃ = 2·3·17 - 3 = 102 - 3 = 99`, `y₃ = 2·3·12 - 2 = 72 - 2 = 70`.

З алгебраїчної теореми випливає, що якщо знайдено хоча б один фундаментальний розв'язок `(x₁, y₁)`, то існує **нескінченна множина цілочисельних розв'язків**, значення яких зростають як геометрична прогресія зі знаменником `ε₁`.

## 3. Теорія неперервних дробів та теорема Лагранжа

Знаходження фундаментального розв'язку `(x₁, y₁)` вимагає ефективного та строгого обчислювального алгоритму. Простий послідовний перебір `y = 1, 2, 3, ...` з перевіркою, чи є значення `1 + d·y²` точним квадратом, є абсолютно практично непридатним: навіть для невеликих значення `d` (наприклад, `d = 61` або `d = 109`) мінімальний фундаментальний розв'язок містить багатозначні числа, до яких прямий перебір здійснюватиметься мільярди років.

Універсальним інструментом для знаходження фундаментального розв'язку для будь-якого `d` є **теорія неперервних (ланцюгових) дробів**.

![Збіжність підхідних дробів неперервного дробу](/book/math/number-theory/pell-equation/img/continued-fractions-convergents.svg)
*Послідовність підхідних дробів pₙ/qₙ для √3, які почергово перевершують та недооцінюють значення √3, утворюючи розв'язки рівняння Пелля.*

Квадратний ірраціонал `√d` завжди розкладається у нескінченний періодичний неперервний дріб виду:

```
√d = a₀ + 1 / (a₁ + 1 / (a₂ + 1 / (a₃ + ...))) = [a₀; (a₁, a₂, ..., a_k)]
```

де `a₀ = ⌊√d⌋` є цілою частиною, а послідовність `(a₁, a₂, ..., a_k)` становить період довжиною `k`. Характерною властивістю такого розкладу є симетрія внутрішньої частини періоду (`a₁ = a_{k-1}`, `a₂ = a_{k-2}` тощо) та умова `a_k = 2·a₀`.

Зрізаючи неперервний дріб на кроці `n`, ми отримуємо раціональний дріб `pₙ / qₙ`, який називається **підхідним дробом** (convergent). Чисельники `pₙ` та знаменники `qₙ` обчислюються за рекурентними формулами:

```
p₋₂ = 0,   p₋₁ = 1,   pₙ = aₙ·pₙ₋₁ + pₙ₋₂
q₋₂ = 1,   q₋₁ = 0,   qₙ = aₙ·qₙ₋₁ + qₙ₋₂
```

### Теорема Лагранжа про розв'язання рівняння Пелля

У 1768 році Жозеф-Луї Лагранж (Joseph-Louis Lagrange, 1736–1813) надав строгий доказ наступних фундаментальних фактів:

1. **Будь-який цілочисельний розв'язок `(x, y)` рівняння `x² - d·y² = 1` обов'язково є одним із підхідних дробів `pₙ / qₙ` розкладу `√d` у неперервний дріб.**
2. Для кожного підхідного дробу виконується тотожність `pₙ² - d·qₙ² = (-1)ⁿ⁺¹·cₙ`, де `cₙ` — послідовність обмежених цілих чисел.
3. Фундаментальний розв'язок `(x₁, y₁)` досягається точно на кінці першого або другого періоду неперервного дробу:
   - Якщо довжина періоду `k` є **парною**, то фундаментальний розв'язок відповідає підхідному дробу на кроці `n = k - 1`:

```
x₁ = p_{k-1},   y₁ = q_{k-1}
```

   - Якщо довжина періоду `k` є **непарною**, то на кроці `n = k - 1` ми отримуємо розв'язок негативного рівняння `x² - d·y² = -1`, а фундаментальний розв'язок для `+1` досягається на подвоєному періоді при `n = 2k - 1`:

```
x₁ = p_{2k-1},   y₁ = q_{2k-1}
```

### Покроковий приклад для d = 3

Розкладемо `√3` у неперервний дріб:
1. `a₀ = ⌊√3⌋ = 1`. Залишок: `√3 - 1 = 1 / ((√3 + 1) / 2)`.
2. `a₁ = ⌊(√3 + 1) / 2⌋ = 1`. Залишок: `(√3 + 1) / 2 - 1 = (√3 - 1) / 2 = 1 / (√3 + 1)`.
3. `a₂ = ⌊√3 + 1⌋ = 2 = 2·a₀`. Цикл замкнувся!

Розклад має період довжиною `k = 2`: `√3 = [1; (1, 2)]`.

Обчислимо підхідні дроби `pₙ / qₙ`:
- `n = 0`: `a₀ = 1`  ⇒  `p₀ / q₀ = 1 / 1`.
  Перевірка: `1² - 3·1² = -2 ≠ 1`.
- `n = 1`: `a₁ = 1`  ⇒  `p₁ = 1·1 + 1 = 2`, `q₁ = 1·1 + 0 = 1`  ⇒  `p₁ / q₁ = 2 / 1`.
  Перевірка: `2² - 3·1² = 4 - 3 = 1`.

Оскільки період `k = 2` є парним, перший розв'язок досягається при `n = k - 1 = 1`.
Отже, фундаментальним розв'язком для `d = 3` є пара **`(x₁, y₁) = (2, 1)`**.

## 4. Циклічний метод Чукравала та тотожність Брахмагупти

За пів тисячоліття до праць Лагранжа та Ейлера індійські математики Брахмагупта (628 н. е.) та Бхаскара II (1150 н. е.) розробили винятково оригінальний та ефективний альтернативний метод розв'язання рівняння Пелля, який взагалі не вимагав знання неперервних дробів.

![Схема циклічного методу Чукравала](/book/math/number-theory/pell-equation/img/chakravala-cycle.svg)
*Логіка ітераційного циклу Чукравала для мінімізації норми та побудови фундаментального розв'язку.*

В основі методу лежить **тотожність Брахмагупти** (санскр. *Samasa* — комбінування):

```
(a₁·a₂ + d·b₁·b₂)² - d·(a₁·b₂ + a₂·b₁)² = (a₁² - d·b₁²)·(a₂² - d·b₂²)
```

Якщо маємо два початкових розв'язки допоміжних рівнянь `a₁² - d·b₁² = k₁` та `a₂² - d·b₂² = k₂`, тотожність Брахмагупти дозволяє конструювати новий розв'язок для добутку вільних членів `k₁·k₂`.

Бхаскара II об'єднав цю тотожність із циклічним ітераційним алгоритмом мінімізації норми (метод **Чукравала**, від санскр. *Chakra* — коло або цикл). Починаючи з підбору довільної близької трійки `(a₀, b₀, k₀)`, алгоритм на кожному кроці знаходить таке ціле число `m`, яке мінімізує `|m² - d|` за умови подільності `(a + b·m)` на `|k|`. Це дозволяє швидко зменшувати значення `k` до досягнення `k = 1`.

Детальний алгебраїчний вивід тотожності Брахмагупти та покроковий розбір методу Чукравала наведено у вставці [Математичний метод Чукравала та тотожність Брахмагупти](book:math/pell-equation/math-chakravala.md).

## 5. Негативне та узагальнене рівняння Пелля

### Негативне рівняння Пелля

Рівняння вида:

```
x² - d·y² = -1
```

називається **негативним рівнянням Пелля**. На відміну від класичного рівняння `x² - d·y² = 1`, яке завжди має ненульові розв'язки для будь-якого неквадратного `d`, негативне рівняння Пелля має розв'язки **лише для окремих значень `d`**.

Необхідні та достатні умови існування цілочисельних розв'язків рівняння `x² - d·y² = -1`:
1. Довжина періоду `k` розкладу `√d` у неперервний дріб має бути **непарною**.
2. Усі прості дільники числа `d` виду `p ≡ 3 (mod 4)` повинні входити до розкладу `d` у парному степені. Це випливає з теорії квадратичних залишків: якщо `x² + 1 = d·y²`, то число `-1` має бути квадратичним лишком за модулем будь-якого непарного простого дільника `x² + 1`.

Наприклад:
- Для `d = 2`: розклад `√2 = [1; (2)]` має період довжиною `k = 1` (непарне). Негативне рівняння `x² - 2·y² = -1` має розв'язок `(1, 1)` (`1² - 2·1² = -1`).
- Для `d = 5`: розклад `√5 = [2; (4)]` має період `k = 1`. Негативне рівняння `x² - 5·y² = -1` має розв'язок `(2, 1)` (`2² - 5·1² = -1`).
- Для `d = 3`: розклад `√3 = [1; (1, 2)]` має період `k = 2` (парне). Негативне рівняння `x² - 3·y² = -1` **не має жодного цілочисельного розв'язку**.

Якщо `(x̃₁, ỹ₁)` є мінімальним розв'язком негативного рівняння `x² - d·y² = -1`, то фундаментальний розв'язок класичного рівняння `x₁ + y₁·√d` утворюється як квадрат негативного розв'язку:

```
x₁ + y₁·√d = (x̃₁ + ỹ₁·√d)² = (x̃₁² + d·ỹ₁²) + 2·x̃₁·ỹ₁·√d
```

### Узагальнене рівняння Пелля

Рівняння вида:

```
x² - d·y² = n
```

де `n` — довільне ціле число (`n ≠ 0, 1, -1`), називається **узагальненим рівнянням Пелля**.

Якщо узагальнене рівняння має хоча б один частковий розв'язок `(u, v)`, то множення елемента `u + v·√d` на всі можливі степені фундаментальної одиниці `(x₁ + y₁·√d)ᵏ` утворює нескінченну послідовність розв'язків того самого рівняння.

Однак узагальнене рівняння може мати **кілька незалежних класів розв'язків** або не мати їх взагалі. Для знаходження представників усіх класів використовуються межі Нагеля-Люнггрена (Trygve Nagell, Wilhelm Ljunggren), які обмежують область пошуку фундаментальних представників кожного класу:

```
|u| ≤ √(|n|·(x₁ + 1) / 2)
|v| ≤ √(|n|·(x₁ + 1) / (2·d))
```

де `(x₁, y₁)` — фундаментальний розв'язок відповідного класичного рівняння `x² - d·y² = 1`.

## 6. Застосування у сучасній математиці та інженерії

Теорія рівняння Пелля має глибокі застосування у сучасній обчислювальній математиці, теорії чисел та інженерії захисту інформації.

### 1. Обчислення регуляторів та аналітична теорія чисел
У теорії алгебраїчних чисел фундаментальний розв'язок `(x₁, y₁)` визначає **регулятор** `R = ln(x₁ + y₁·√d)` дійсного квадратичного поля `Q(√d)`. Регулятор входить до аналітичної формули числа класів Діріхле, яка пов'язує значення L-функцій зі структурою групи класів ідеалів кільця.

### 2. Алгоритми факторизації великих чисел (Shanks' SQSFO)
У 1975 році Деніел Шанкс (Daniel Shanks) розробив ефективний алгоритм розкладання цілих чисел на множники — SQSFO (Square Forms Factorization). Алгоритм моделює відновлення циклу у групі класів квадратних форм `a·x² + b·x·y + c·y²` вздовж періоду неперервного дробу для `√N`. Це дозволяє знаходити нетривіальні дільники числа `N` за час `O(N^(1/4))`.

### 3. Криптографія на основі пеллівських кривих
У сучасній криптографії аналогічно до групи точок еліптичних кривих використовуються так звані криві Пелля над скінченними полями `F_p` або кільцями лишків `Z / N Z`. Криптосистеми на основі послідовностей Люка та точок пеллівських кривих забезпечують високий рівень криптостійкості при виконанні протоколів обміну ключами (Діффі-Геллман) та електронного цифрового підпису.

Детальну алгоритмічну реалізацію пошуку фундаментального розв'язку мовами C та C++ з аналізом 64-бітного переповнення наведено у вставці [Обчислювальний алгоритм розв'язання рівняння Пелля мовами C та C++](book:math/pell-equation/proj-pell-solver.md).
