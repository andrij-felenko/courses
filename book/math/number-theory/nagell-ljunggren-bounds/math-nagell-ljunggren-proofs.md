# 🧮 Математичні доведення та оцінки Нагеля–Люнггрена

Ця вставка містить детальні алгебраїчні доведення, аналітичні оцінки та структури розкладу, на які спирається дослідження діофантового рівняння Нагеля–Люнггрена:

```
(xⁿ - 1) / (x - 1) = y^q
```

для цілих чисел `x > 1`, `y > 1`, `n > 2` та `q ≥ 2`.

Ми розглянемо алгебраїчний розклад реп'юніта через кругові многочлени, арифметику примітивних простих дільників (теорема Зігмонді), доведення Люнггрена для точних квадратів (`q = 2`), а також побудову логарифмічних форм Бейкера та p-адичні оцінки Бюжо–Міньотта для встановлення аналітичних меж.

## 1. Алгебраїчні спрощення та розклад на кругові многочлени

Першим кроком аналізу є алгебраїчне спрощення рівняння. Ліва частина `N_n(x) = (xⁿ - 1)/(x - 1)` являє собою суму геометричної прогресії:

```
N_n(x) = 1 + x + x² + ... + xⁿ⁻¹
```

Якщо показник `n` є складеним числом і розкладається у добуток двох множників `n = a · b` (де `a > 1` та `b > 1`), то реп'юніт факторизується за допомогою алгебраїчної тотожності наступним чином:

```
(xⁿ - 1) / (x - 1)
= [ ( (xᵃ)ᵇ - 1 ) / (xᵃ - 1) ] · [ (xᵃ - 1) / (x - 1) ]
= N_b(xᵃ) · N_a(x)
```

З цієї тотожності випливає важливий алгебраїчний висновок: якщо реп'юніт `N_n(x)` є точним `q`-им степенем `y^q`, то його складові співмножники `N_b(xᵃ)` та `N_a(x)` також мусять бути "майже точними `q`-ми степенями", за винятком можливого спільного дільника, який ділить показник `b`.

### Розклад через кругові многочлени `Φ_d(x)`

У загальному випадку многочлен `xⁿ - 1` розкладається над полем раціональних чисел у добуток непривідних кругових многочленів (циклотомічних поліномів) `Φ_d(x)` для всіх дільників `d` числа `n`:

```
xⁿ - 1 = ∏_{d | n} Φ_d(x)
```

Оскільки `x - 1 = Φ₁(x)`, реп'юніт `N_n(x)` розкладається у добуток кругових многочленів для всіх дільників `d > 1`:

```
N_n(x) = (xⁿ - 1) / (x - 1) = ∏_{d | n, d > 1} Φ_d(x)
```

Наприклад, при непарному простому `n = p` розклад є максимально простим — реп'юніт збігається з єдиним круговим многочленом `Φ_p(x)`:

```
N_p(x) = Φ_p(x) = xᵖ⁻¹ + xᵖ⁻² + ... + x + 1
```

Для складеного числа `n = 6` розклад містить три кругові многочлени:

```
N_₆(x) = Φ₂(x) · Φ₃(x) · Φ₆(x) = (x + 1) · (x² + x + 1) · (x² - x + 1)
```

Для вивчення подільності кругових многочленів ключову роль відіграє оцінка їхнього найбільшого спільного дільника (НСД) у цілочисельних точках `x`.

### Доведення теореми про НСД кругових многочленів

Сформулюємо та доведемо строге твердження щодо спільного дільника кругових многочленів.

**Теорема:** Нехай `a` та `b` — два різні натуральні числа, `a > b ≥ 1`. Тоді для будь-якого цілого `x > 1` найбільший спільний дільник `D = НСД(Φ_a(x), Φ_b(x))` має наступні властивості:
1. Якщо відношення `a/b` не є степенем простого числа, то `D = 1`.
2. Якщо відношення `a/b = pᵏ` для деякого простого `p`, то `D` дорівнює `p` або `1`.

**Доведення:** Розглянемо вираз `xᵃ - 1` та `xᵇ - 1`. Їхній спільний дільник у кільці многочленів дорівнює `x^(НСД(a, b)) - 1`. Нехай `g = НСД(a, b)`. Оскільки `Φ_a(x)` ділить `(xᵃ - 1) / (xᵍ - 1)`, а `Φ_b(x)` ділить `xᵇ - 1`, то будь-який спільний простий дільник `q` чисел `Φ_a(x)` та `Φ_b(x)` повинен ділити вираз:

```
R(x) = (xᵃ - 1) / (xᵍ - 1) = 1 + xᵍ + x²ᵍ + ... + x^( (a/g - 1)g )
```

У точці `x`, де `xᵍ ≡ 1 (mod q)`, кожен член суми `xᵏᵍ` є порівнянним із `1 (mod q)`. Сума містить точно `a/g` доданків, отже:

```
R(x) ≡ a/g (mod q)
```

Таким чином, простий дільник `q` обов'язково ділить число `a/g`. Якщо `a/g` не є степенем простого числа `p`, спільних дільників бути не може, що й доводить `D = 1`.

З цієї теореми випливає, що у добутку `N_n(x) = ∏ Φ_d(x)` множники `Φ_d(x)` є **майже взаємно простими**: кожен простий множник числа `y`, який не ділить `n`, може входити лише в **один-єдиний** круговий многочлен `Φ_d(x)`.

Оскільки весь добуток є точним `q`-им степенем `y^q`, кожен окремий многочлен `Φ_d(x)` повинен задовольняти строгій умові:

```
Φ_d(x) = c_d · (z_d)^q
```

де `c_d` — множник, складений виключно з простих дільників числа `n`. Для великих `n` та `q ≥ 2` ця система рівностей утворює наджорстку систему діофантових обмежень, оскільки многочлени `Φ_d(x)` зростають з різними швидкостями і не можуть одночасно набувати значень, близьких до точних `q`-их степеней.

## 2. Теорема Зігмонді та примітивні прості дільники

Потужним арифметичним інструментом аналізу рівняння Нагеля–Люнггрена є теорема К. Зігмонді (K. Zsigmondy, 1892), яка дає строгу характеристику простих дільників послідовностей вигляду `aⁿ - bⁿ`.

### Формулювання теореми Зігмонді

Для будь-яких цілих взаємно простих чисел `a > b ≥ 1` та будь-якого натурального `n > 1` існує принаймні один **примітивний простий дільник** `p` виразу `aⁿ - bⁿ` (тобто такий простий дільник `p`, який ділить `aⁿ - bⁿ`, але не ділить `aᵏ - bᵏ` для жодного невід'ємного `k < n`), за винятком точно двох відомих винятків:
1. `2⁶ - 1⁶ = 63 = 3² · 7` (тут `a = 2, b = 1, n = 6`, примітивного дільника немає, бо 7 ділить `2³ - 1 = 7`, а 3 ділить `2² - 1 = 3`);
2. `a + b = 2ᵏ` при `n = 2` (наприклад, `(2ᵃ - 1)² - 1²`).

### Застосування до рівняння Нагеля–Люнггрена

Для реп'юніта `N_n(x) = (xⁿ - 1)/(x - 1)` будь-який примітивний простий дільник `p` виразу `xⁿ - 1` обов'язково задовольняє дві фундаментальні арифметичні умови:

```
p ≡ 1 (mod n)
```

та `p` ділить останній круговий многочлен `Φ_n(x)`.

Доведення властивості `p ≡ 1 (mod n)` випливає з теорії мультиплікативного порядку: якщо `p` ділить `xⁿ - 1`, але не ділить `xᵏ - 1` для `k < n`, то мультиплікативний порядок числа `x` за модулем `p` дорівнює точно `n` (`ord_p(x) = n`). За малою теоремою Ферма `xᵖ⁻¹ ≡ 1 (mod p)`, отже `ord_p(x)` повинен ділити `p - 1`, що й дає `n | (p - 1)`, тобто `p ≡ 1 (mod n)`.

Якщо `N_n(x) = y^q`, то цей примітивний простий дільник `p` входить у канонічний розклад числа `y^q` з показником, кратним `q`. Отже:

```
p^q | N_n(x)
```

Оскільки `p ≡ 1 (mod n)`, то `p ≥ n + 1`. Це означає, що примітивний дільник `p` є відносно великим порівняно з `n`. Якщо `q ≥ 2`, то `p^q ≥ (n + 1)²,` що дає змогу будувати строгі нижні оцінки для величини `y^q` через `x` та `n`.

## 3. Доведення Люнггрена для точних квадратів (`q = 2`)

Випадок `q = 2` відповідає діофантовому рівнянню:

```
(xⁿ - 1) / (x - 1) = y²
```

Вільгельм Люнггрен у 1943 році повністю розв'язав це рівняння. Нижче наведено розгорнуту схему його доведення для випадку, коли `n` є простим непарним числом `p`.

### Крок 1: Перетворення у квадратичну форму

Записавши реп'юніт для простого `n = p`, ми маємо:

```
xᵖ⁻¹ + xᵖ⁻² + ... + x + 1 = y²
```

Помножимо обидві частини рівняння на `4`:

```
4 · (xᵖ - 1) / (x - 1) = (2y)²
```

Використовуючи тотожність Якобсталя–Ландау для кругового полінома при непарному простому `p`, можна записати алгебраїчну факторизацію у розширенні `ℚ(√x)` або `ℚ(√((-1)ᵖ⁻¹⁾/² · p))`:

```
4 · Φ_p(x) = A(x)² - (-1)^( (p-1)/2 ) · p · x · B(x)²
```

де `A(x)` та `B(x)` — спеціальні многочлени з цілими коефіцієнтами, які задовольняють співвідношенню ступенів `deg A = (p-1)/2` та `deg B = (p-3)/2`.

Явні вирази для найменших простих чисел `p`:
- Для `p = 3`: `4(x² + x + 1) = (2x + 1)² + 3 · 1²` (де `A(x) = 2x + 1, B(x) = 1`).
- Для `p = 5`: `4(x⁴ + x³ + x² + x + 1) = (2x² + x + 2)² - 5x(x + 1)²` (де `A(x) = 2x² + x + 2, B(x) = x + 1`).

### Крок 2: Зведення до рівнянь типу Пелля

Оскільки `Φ_p(x) = y²`, підставивши це у квадратичну тотожність, ми отримуємо діофантову рівність:

```
(2y)² - A(x)² = ± p · x · B(x)²
```

Розкладаючи ліву частину як різницю квадратів `(2y - A(x))(2y + A(x))`, Люнггрен довів, що дільники цього виразу зв'язуються у систему рівнянь типу Пелля у кільці цілих чисел квадратичного поля `ℚ(√p)` або `ℚ(√(p x))`.

### Крок 3: Аналіз одиниць та висновок Люнггрена

Люнггрен застосував теорему про структуру групи одиниць алгебраїчних полів (теорема Діріхле про одиниці). Всі розв'язки рівняння Пелля виражаються через степені фундаментальної одиниці `ε = u + v √D`.

Аналізуючи висоти та p-адичний порядок степеней `εᵏ`, Люнггрен довів, що рівність між степенями фундаментальних одиниць можлива лише у двох виключних випадках:
1. `p = 5`, `x = 3`: `(3⁵ - 1)/(3 - 1) = 121 = 11²`.
2. `p = 3` (із розширенням до `n = 4`), `x = 7`: `(7⁴ - 1)/(7 - 1) = 400 = 20²`.

Для всіх інших комбінацій `x > 1` та `n > 2` при `q = 2` системі рівнянь Пелля відповідають фундаментальні одиниці, які не можуть дати цілі значення для `y`, що повністю закриває випадок `q = 2`.

## 4. Метод Бейкера: лінійні форми у логарифмах та аналітичні межі

Для довільних показників `q ≥ 3` класичні алгебраїчні методи не дають змоги обмежити `q` та `n`. Тут застосовується аналітичний метод Алана Бейкера.

### Запис логарифмічної форми

Розглянемо вихідне рівняння:

```
(xⁿ - 1) / (x - 1) = y^q
```

Виділимо головний член при великих `x` та `n`:

```
xⁿ / (x - 1) - 1 / (x - 1) = y^q
```

Поділимо обидві частини на `xⁿ / (x - 1)`:

```
1 - 1 / xⁿ = (y^q · (x - 1)) / xⁿ
```

Прологарифмуємо отриману рівність. Оскільки `1 / xⁿ` є дуже малим числом при `n ≥ 3`, використавши розклад логарифма у ряд Тейлора `log(1 - ε) = - ε - ε²/2 - ... ≈ - ε`, отримуємо:

```
log( (y^q · (x - 1)) / xⁿ ) = log(1 - 1/xⁿ) ≈ - 1/xⁿ
```

За властивостями логарифма розкриємо ліву частину:

```
q · log y + log(x - 1) - n · log x ≈ - 1/xⁿ
```

Введемо лінійну форму від трьох логарифмів:

```
Λ = q · log y - n · log x + 1 · log(x - 1)
```

з цілими коефіцієнтами `b₁ = q`, `b₂ = -n`, `b₃ = 1` та алгебраїчними числами `α₁ = y`, `α₂ = x`, `α₃ = x - 1`.

### Верхня та нижня межі для `|Λ|`

1. **Зі звичайного аналізу (верхня межа):**
   Оскільки `Λ` дорівнює малій величині розкладу логарифма:
   ```
   |Λ| < 2 / xⁿ
   ```

2. **З теореми Бейкера (нижня межа):**
   Фундаментальна теорема Бейкера про лінійні форми у логарифмах стверджує, що якщо `Λ ≠ 0`, то існує обчислювана константа `C > 0`, яка залежить лише від логарифмів чисел `x` та `y`, така що:
   ```
   |Λ| > exp( - C · log q · log n )
   ```

### Виведення обмежень на `q` та `n`

Поєднуючи верхню та нижню межі для `|Λ|`, отримуємо нерівність:

```
exp( - C · log q · log n ) < |Λ| < 2 / xⁿ
```

Логарифмуємо обидві частини нерівності:

```
- C · log q · log n < log 2 - n · log x
```

Переносимо члени і ділимо на `log x`:

```
n < (C / log x) · log q · log n + (log 2 / log x)
```

Оскільки ліва частина `n` зростає набагато швидше за логарифмічну функцію `log n` у правій частині, ця нерівність не може виконуватися для як завгодно великих `n`.

Звідси випливає фундаментальний результат Торкеля Тійдемана та Т. Н. Шорі:
**Для будь-якої фіксованої основи `x > 1` існують суто обчислювані константи `N_max(x)` та `Q_max(x)`, такі що:**

```
n ≤ N_max(x)   та   q ≤ Q_max(x)
```

Це доводить, що при кожному `x` рівняння Нагеля–Люнггрена має лише **скінченну кількість** цілочисельних розв'язків `(n, y, q)`.

## 5. Модулярні оцінки Бюжо–Міньотта–Анро

Сучасний розвиток теорії чисел дозволив суттєво уточнити межі Бейкера завдяки p-адичним логарифмам та зв'язку з круговими полями `ℚ(ζ_q)`.

### Теорема Бюжо–Міньотта (2002)

Якщо `(x, n, y, q)` є розв'язком рівняння Нагеля–Люнггрена з простим показником `q ≥ 3`, то:
1. `q` обов'язково ділить число класів ідеалів `h_q` кругового поля `ℚ(ζ_q)` або `x ≡ 1 (mod q)`.
2. Якщо `x ≡ 1 (mod q)`, то `n ≡ 1 (mod q)`.

Оскільки число класів ідеалів `h_q` зростає порівняно повільно і підпорядковується жорстким аналітичним формулам (формула числа класів Діріхле), це правило дозволяє комп'ютерним методом повністю виключити майже всі значення `q` для заданої основи `x`.

### Численне підтвердження для конкретних прикладів

Розглянемо числовий приклад перевірки для основи `x = 3`:

```
(3ⁿ - 1) / 2 = y^q
```

- При `n = 3`: `(3³ - 1)/2 = 13`. Число 13 не є точним степенем `y^q` при `q ≥ 2`.
- При `n = 4`: `(3⁴ - 1)/2 = 40`. Число 40 = 2³ · 5 не є точним степенем.
- При `n = 5`: `(3⁵ - 1)/2 = 121 = 11²`. Це відомий розв'язок Люнггрена `(x=3, n=5, y=11, q=2)`.
- При `n = 6`: `(3⁶ - 1)/2 = 364 = 4 · 7 · 13` — не є точним степенем.
- Для `n > 5` за теоремою Бюжо–Міньотта та оцінками p-адичних логарифмів показник `q` мусить перевищувати `10⁸`, але аналітична верхня межа Бейкера для `x = 3` дає `q < 10⁸`, що створює повну суперечність і доводить відсутність інших розв'язків для `x = 3`.

Таким чином, об'єднання алгебраїчного розкладу, теореми Зігмонді, аналізу пеллівських одиниць Люнггрена та логарифмічних меж Бейкера утворює цілісну математичну теорію, яка пояснює унікальність відомих розв'язків Нагеля–Люнггрена.
