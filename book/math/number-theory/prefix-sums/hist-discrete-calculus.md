# 📜 Історія дискретного числення та кінцевих різниць

Вивчаючи неперервний математичний аналіз, студент зазвичай бачить похідні та інтеграли як гладкі, неперервні границі, де прирости прагнуть до нуля. Однак історично числення скінченних різниць (англ. *calculus of finite differences*) розвивалося паралельно із диференціальним численням, а в багатьох аспектах навіть передувало йому. Поняття префіксних сум і різницевих операторів виникло з практичної потреби обчислювати суми послідовностей, табулювати складні астрономічні й навігаційні таблиці та знаходити площі дискретних фігур. Цей матеріал відстежує еволюцію дискретного аналізу — від давніх сум степенів натуральних чисел до систематичних праць Брука Тейлора, Джеймса Стірлінга, Якоба Бернуллі, Леонгарда Ойлера та Нільса Генріка Абеля.

### Від підрахунку пірамідальних чисел до ранньої алгебри

Витоки ідеї накопичувального підсумовування сягають давньогрецької та індійської математики. Піфагорійці у VI столітті до н. е. досліджували так звані «фігурні числа» (англ. *figurate numbers*) — трикутні, квадратні та пірамідальні. Сума перших `N` натуральних чисел утворює трикутне число:

```
T(N) = 1 + 2 + 3 + ... + N = N · (N + 1) / 2
```

Послідовність трикутних чисел `1, 3, 6, 10, 15, 21, ...` являє собою не що інше, як масив префіксних сум для послідовності натуральних чисел `1, 2, 3, 4, 5, 6, ...`. Якщо ж узяти префіксні суми вже від самих трикутних чисел, утвориться послідовність тетраедральних (пірамідальних) чисел.

У III столітті н. е. грецький математик Діофант Александрійський (*Diophantus of Alexandria*) у праці «Арифметика» вже вільно користувався сумуванням послідовностей для розв'язування квадратних і кубічних задач. Незалежно від нього в Індії математик Аріабхата (*Aryabhata*, 476–550 н. е.) у трактаті «Аріабхатія» навів точні формули для сум квадратів та кубів натуральних чисел. Аріабхата помітив, що сума квадратів виражається через префіксні суми перших чисел, поклавши початок тотожностям дискретного підсумовування.

Однак аж до XVII століття ці результати сприймалися як ізольовані ремісничі трюки для конкретних степенів, а не як єдиний аналітичний метод.

### Склепіння Якоба Бернуллі: суми степенів та числа Бернуллі

Справжній математичний прорив у підсумовуванні послідовностей відбувся 1713 року, коли посмертно вийшла праця швейцарського математика Якоба Бернуллі (*Jacob Bernoulli*, 1655–1705) під назвою «Мистецтво припущень» (*Ars Conjectandi*).

Бернуллі поставив перед собою фундаментальне завдання: знайти загальну формулу для префіксної суми степенів `p` перших `N` натуральних чисел:

```
S_p(N) = 1ᵖ + 2ᵖ + 3ᵖ + ... + Nᵖ
```

Для `p = 1` формула була відома ще Піфагорові, для `p = 2` та `p = 3` — Аріабхаті й Архімеду. Але Бернуллі прагнув єдиного закону для довільного `p`. Аналізуючи таблиці коефіцієнтів, він відкрив дивовижну послідовність раціональних чисел, які тепер носять його ім'я — **числа Бернуллі** `B_k`. За допомогою цих чисел він записав єдину замкнену формулу для суми будь-якого степеня:

```
S_p(N) = (1 / (p + 1)) · ∑_{k=0}^p C(p+1, k) · B_k · N^{p+1-k}
```

У своєму щоденнику Бернуллі з гордістю писав, що за допомогою цієї формули він менш ніж за чверть години обчислив суму 10-х степенів перших 1000 чисел, отримавши 91-значне число. Відкриття Бернуллі довело: префіксна сума степенів полінома ступеня `p` завжди виражається поліномом ступеня `p + 1`. Це був перший чіткий сигнал того, що дискретне підсумовування поводиться точнісінько так само, як інтегрування степенів `xᵖ dx = x^{p+1} / (p + 1)`.

### Брук Тейлор та народження оператора скінченних різниць

Поки швейцарські математики досліджували суми степенів, в Англії та континентальній Європі активно розвивалася практична техніка кінцевих різниць. Ще до появи диференціального числення астроном Йоганн Кеплер (*Johannes Kepler*, 1571–1630) та математик Генрі Бріґґз (*Henry Briggs*, 1561–1630) — автор перших таблиць десяткових логарифмів — використовували таблиці послідовних різниць для інтерполяції рухів планет і проміжних значень логарифмів. Обчислювачі виписували стовпчики чисел, поруч вираховували різниці сусідніх елементів, від них — різниці другого порядку, і так далі. Якщо різниці `k`-го порядку ставали постійними, це означало, що вихідну послідовність можна точно описати поліномом степеня `k`, а зворотний рух — додавання накопичених різниць — давав змогу заповнювати прогалини в таблицях без трудомісткого множення.

У 1715 році англійський математик Брук Тейлор (*Brook Taylor*, 1685–1731) надав усім цим практичним спостереженням строгої аналітичної форми у своїй праці *Methodus Incrementorum Directa et Inversa* («Прямий та обернений метод приростів»).

Тейлор увів у математику прямий різницевий оператор Δ (грецька літера дельта):

```
Δ A[i] = A[i + 1] − A[i]
```

Він показав, що цей оператор є прямим дискретним аналогом взяття похідної `d/dx`. Відповідно, оператор префіксного підсумовування ∑ виступає оберненим оператором до Δ:

```
∑ (Δ A[i]) = A[i + 1] − A[0]
```

Це було перше строге формулювання **основної теореми дискретного числення**: операція префіксного сумування та операція взяття послідовних різниць є взаємно оберненими алгебраїчними перетвореннями.

Тейлор побудував аналог формули Тейлора для дискретних функцій, використовуючи замість звичайних степеней `xⁿ` так звані спадні факторіальні степені `x^{(n)} = x · (x − 1) · ... · (x − n + 1)`. Для спадних степеней дія різницевого оператора виявилася дивовижно чистою:

```
Δ x^{(n)} = n · x^{(n - 1)}
```

Це відкриття дозволило підсумовувати будь-які комбінаторні й поліноміальні послідовності так само легко, як табличні інтеграли в неперервному аналізі.

### Джеймс Стірлінг та розділені різниці Ньютона

Паралельно з Тейлором над цією проблемою працював шотландський математик Джеймс Стірлінг (*James Stirling*, 1692–1770). У книзі *Methodus Differentialis* (1730) Стірлінг заглибився в алгебраїчний зв'язок між звичайними степенями `xⁿ` та спадними степенями `x^{(n)}`. Для переходу між ними він увів коефіцієнти, які сьогодні відомі як **числа Стірлінга першого та другого роду**.

Числа Стірлінга другого роду `S(n, k)` показують, як розкласти звичайну суму префіксів степенів через суми спадних степеней. Завдяки працям Стірлінга та Ісаака Ньютона (*Isaac Newton*, 1642–1727), який розвинув метод розділених різниць для астрономічної інтерполяції, кінцеві різниці та префіксні суми стали головним обчислювальним інструментом математики XVIII століття. Табулювання логарифмів, тригонометричних функцій і таблиць морської навігації здійснювалося саме методом послідовних різниць і сумування.

### Формула Ойлера — Маклорена: міст між дискретним і неперервним

Найглибший синтез дискретного підсумовування та неперервного інтегрування здійснили незалежно один від одного великий швейцарський математик Леонгард Ойлер (*Leonhard Euler*, 1707–1783) у 1736 році та шотландський математик Колін Маклорен (*Colin Maclaurin*, 1698–1746) у 1742 році.

Сформульована ними **формула підсумовування Ойлера — Маклорена** пов'язує дискретну префіксну суму значень функції `f(k)` із неперервним інтегралом від цієї ж функції:

```
∑_{k=1}^N f(k) = ∫_1^N f(x) dx + (f(1) + f(N)) / 2 + ∑_{j=1}^m (B_{2j} / (2j)!) · (f^{(2j-1)}(N) − f^{(2j-1)}(1)) + R_m
```

Де `B_{2j}` — це парні числа Бернуллі, а `f^{(2j-1)}` — непарні похідні функції. Ця формула показала, що дискретна префіксна сума дорівнює неперервному інтегралу плюс поправкові члени, пропорційні похідним на межах відрізка. За допомогою формули Ойлера — Маклорена Ойлер обчислив точне значення сталої Ойлера — Маскероні `γ`, довів розбіжність гармонічного ряду та знайшов асимптотику для факторіала (відому як формула Стірлінга).

### Нільс Генрік Абель та дискретне інтегрування частинами

На початку XIX століття норвезький математичний геній Нільс Генрік Абель (*Niels Henrik Abel*, 1802–1829) застосував префіксні суми для дослідження збіжності нескінченних рядів. У праці 1826 року про біноміальний ряд Абель сформулював перетворення, яке сьогодні називають **дискретним інтегруванням частинами** (або перетворенням Абеля).

Ідея Абеля полягала в тому, щоб замість добутку двох послідовностей `a_k · b_k` виразити суму через префіксні суми `P_k = a_1 + ... + a_k` першого множника та різниці `Δ b_k = b_{k+1} − b_k` другого множника:

```
∑_{k=1}^N a_k · b_k = P_N · b_N − ∑_{k=1}^{N-1} P_k · (b_{k+1} − b_k)
```

Це перетворення стало дискретним точним двійником неперервної формули інтегрування частинами `∫ u dv = u·v − ∫ v du`. Дискретне перетворення Абеля дозволило доводити ознаки збіжності Діріхле та Абеля для знакопочередних і комплексних рядів, що стало основою для всієї аналітичної теорії чисел XIX та XX століть.

### Від мануальних таблиць до алгоритмів комп'ютерної епохи

З появою електронно-обчислювальних машин у XX столітті префіксні суми змінили свій статус із суто аналітичного інструмента на один із базових алгоритмічних патернів. У 1950-х роках із розвитком машинної графіки та обробки сигналів виникла потреба миттєво обчислювати суми пікселів на прямокутних областях кадру.

У 1984 році Френк Кроу (*Frank Crow*) запропонував концепцію *Summed-Area Tables* (таблиць підсумованих областей) для текстурування у тривимірній графіці, що є не чим іншим, як двовимірними префіксними сумами. У 1990-х роках Пол Віола (*Paul Viola*) та Майкл Джонс (*Michael Jones*) застосували двовимірні префіксні суми під назвою «інтегральне зображення» (*Integral Image*) у своєму знаменитому алгоритмі виявлення облич Віоли — Джонса, зробивши аналіз відеопотоку реального часу можливим на звичайних процесорах.

Паралельно у 1980–1990-х роках у галузі паралельних обчислень Гай Блеллок (*Guy Blelloch*) розробив ефективні паралельні алгоритми обчислення префіксних сум (*Parallel Prefix Scan*) для багатоядерних архітектур і графічних процесорів (GPU), довівши, що префіксні суми можна будувати за логарифмічний час `O(log N)` на паралельних системах.

Таким чином, пройшовши шлях від піфагорійських фігурних чисел та формул Бернуллі до операторів Тейлора й паралельних сканувань Блеллока, префіксні суми зберегли свою головну суть: вони поєднують дискретну алгебру з неперервною інтуїцією, перетворюючи важке лінійне накопичення на миттєву арифметичну дію.
