# 🧮 Алгебраїчна структура кільця арифметичних функцій та строге обернення Мебіуса

Для глибокого розуміння природи цілих чисел та співвідношень між арифметичними функціями необхідно розглянути їх не просто як окремі обчислювальні правила, а як елементи впорядкованої алгебраїчної структури. Множина всіх комплекснозначних функцій, визначених на додатних цілих числах, утворює комутативне кільце відносно точкового додавання та згортки Діріхле. Нижче наведено строгі доведення алгебраїчних властивостей цієї структури, побудову оберненого елемента, метод степенних рядів Белла та виведення формули Мебіуса.

## 1. Аксіоми кільця арифметичних функцій

Нехай `A = {f: ℤ⁺ → ℂ}` — множина всіх арифметичних функцій. Визначимо на `A` дві бінарні операції:

1. **Точкове додавання:** `(f + g)(n) = f(n) + g(n)` для кожного `n ∈ ℤ⁺`.
2. **Згортка Діріхле:** `(f * g)(n) = ∑_{d|n} f(d) g(n/d) = ∑_{a · b = n} f(a) g(b)`.

Множина `A` із цими операціями утворює комутативне кільце з одиницею. Крім того, це кільце є цілісним доменом (областю цілісності): якщо згортка двох функцій `f * g = 0` дорівнює тотожному нулю, то принаймні одна з функцій `f` або `g` має бути тотожним нулем.

Доведемо базові алгебраїчні властивості згортки.

### Комутативність

Комутативність випливає із симетрії пари дільників `(a, b)` відносно множення у полі комплексних чисел. Для будь-яких функцій `f, g ∈ A` та будь-якого `n ≥ 1`:

```
(f * g)(n)
= ∑_{a·b = n} f(a) g(b)          [означення згортки через пари (a,b)]
= ∑_{b·a = n} g(b) f(a)          [комутативність множення в C]
= (g * f)(n)                     [висновок: f * g = g * f]
```

### Асоціативність

Асоціативність означає, що при згортці трьох функцій порядок групування дужок не має значення. Потрійний добуток розкладається у суму по всіх впорядкованих трійках натуральних чисел `(a, b, c)`, добуток яких `a · b · c = n`. Для будь-яких трьох функцій `f, g, h ∈ A`:

```
((f * g) * h)(n)
= ∑_{d·c = n} (f * g)(d) h(c)                      [згортка (f * g) з h]
= ∑_{d·c = n} ( ∑_{a·b = d} f(a) g(b) ) h(c)        [розгортка внутрішньої згортки]
= ∑_{a·b·c = n} f(a) g(b) h(c)                      [об'єднання суми за всіма трійками (a,b,c)]
= ∑_{a·e = n} f(a) ( ∑_{b·c = e} g(b) h(c) )        [перегрупування за e = b·c]
= (f * (g * h))(n)                                  [за означенням згортки з (g * h)]
```

### Одиничний елемент

Визначимо функцію `ε(n) = [n = 1]`, тобто `ε(1) = 1` та `ε(n) = 0` для всіх `n > 1`. Ця функція виконує роль алгебраїчної одиниці відносно операції згортки. Для будь-якої арифметичної функції `f`:

```
(f * ε)(n)
= ∑_{d|n} f(d) ε(n/d)            [усі доданки з n/d > 1 дорівнюють 0]
= f(n) · ε(1)                    [єдиний ненульовий доданок при d = n]
= f(n) · 1 = f(n)                [підстановка ε(1) = 1]
```

Отже `ε` виступає двостороннім нейтральним (одиничним) елементом відносно згортки: `f * ε = ε * f = f`.

## 2. Група оборотних елементів та алгоритм побудови оберненого

Елемент `f ∈ A` називається оборотним відносно згортки, якщо існує така функція `f⁻¹ ∈ A`, що `f * f⁻¹ = ε`.

**Теорема.** Функція `f ∈ A` має обернену відносно згортки тоді й лише тоді, коли `f(1) ≠ 0`. При цьому обернена функція `f⁻¹` є єдиною.

### Доведення (конструктивне за сильною індукцією)

Необхідно задовольнити умову `(f * f⁻¹)(n) = ε(n)` для всіх `n ≥ 1`.

**База індукції (`n = 1`):**
Для першого елемента маємо:
```
(f * f⁻¹)(1) = ε(1)
f(1) · f⁻¹(1) = 1                [бо єдиний дільник 1 — це 1]
f⁻¹(1) = 1 / f(1)               [можливо тоді й лише тоді, коли f(1) ≠ 0]
```

**Крок індукції (`n > 1`):**
Для `n > 1` за означенням маємо `ε(n) = 0`. Запишемо розгортку суми дільників:

```
(f * f⁻¹)(n) = 0                 [умова нейтральності при n > 1]
∑_{d|n} f(d) f⁻¹(n/d) = 0        [розгортка суми згортки]
f(1) f⁻¹(n) + ∑_{d|n, d > 1} f(d) f⁻¹(n/d) = 0 [виділення першого доданоку d=1]
```

Оскільки при `d > 1` аргумент `n/d < n`, за припущенням математичної індукції значення `f⁻¹(n/d)` вже є однозначно обчисленими на попередніх кроках. Переносячи суму в праву частину й ділячи на `f(1) ≠ 0`, отримуємо точну рекурентну формулу для значення оберненої функції в точці `n`:

```
f⁻¹(n) = − (1 / f(1)) · ∑_{d|n, d > 1} f(d) f⁻¹(n/d)      [для n > 1]
```

Ця формула одночасно гарантує існування оберненого елемента та доводить його абсолютну єдиність.

### Обернена функція для абсолютно мультиплікативних функцій

Якщо функція `f` є абсолютно (повністю) мультиплікативною, її обернений елемент набуває надзвичайно простої та елегантної форми.

**Теорема.** Якщо `f` є абсолютно мультиплікативною функцією та `f(1) = 1`, то її обернена функція за згорткою дорівнює точковому добутку з функцією Мебіуса:
`f⁻¹(n) = μ(n) · f(n)`.

**Доведення:**
Перевіримо значення згортки `f * (μ · f)` в довільній точці `n`:

```
(f * (μ · f))(n)
= ∑_{d|n} f(d) · μ(n/d) f(n/d)   [підстановка за означенням згортки]
= ∑_{d|n} μ(n/d) · (f(d) f(n/d)) [перестановний закон у C]
= ∑_{d|n} μ(n/d) · f(n)          [абсолютна мультиплікативність: f(d)f(n/d) = f(n)]
= f(n) · ∑_{d|n} μ(n/d)          [винесення спільного множника f(n)]
= f(n) · ε(n)                    [властивість функції Мебіуса: ∑ μ(d) = ε(n)]
= ε(n)                          [бо f(1)·ε(1) = 1, а при n>1 ε(n)=0]
```

Отже для абсолютно мультиплікативної функції `f` її обернена функція утворюється просто множенням на функцію Мебіуса: `f⁻¹ = μ · f`.

## 3. Степенні ряди Белла та локальний аналіз над простими числами

Для аналізу мультиплікативних функцій видатний американський математик Ерік Темпл Белл ввів апарат локальних степенних рядів.

Для будь-якої мультиплікативної функції `f` та фіксованого простого числа `p` визначимо **ряд Белла** `f_p(x)` як формальний степенний ряд від змінної `x` над полем `ℂ`:

```
f_p(x) = ∑_{k=0}^∞ f(p^k) x^k = f(1) + f(p) x + f(p²) x² + f(p³) x³ + …
```

Оскільки мультиплікативна функція повністю визначається своїми значеннями на степенях простих чисел `f(p^k)`, набір усіх її рядів Белла `f_p(x)` для всіх простих `p` повністю ізоморфно описує початкову арифметичну функцію.

**Головна властивість ряду Белла:**
Згортка двох мультиплікативних функцій `h = f * g` у просторі рядів Белла відповідає звичайному точковому множенню формальних степенних рядів для кожного простого `p`:

```
h_p(x) = (f * g)_p(x) = f_p(x) · g_p(x)
```

Це дозволяє перетворити згортку арифметичних функцій на просте алгебраїчне множення многочленів або степенних рядів над кожним простим числом.

### Обчислення ряду Белла для базових функцій

1. **Для нейтрального елемента `ε`:**
   Оскільки `ε(1) = 1`, а `ε(p^k) = 0` для `k ≥ 1`, маємо:
   ```
   ε_p(x) = 1 + 0·x + 0·x² + … = 1
   ```

2. **Для постійної одиничної функції `1(n) = 1`:**
   Оскільки `1(p^k) = 1` для всіх `k`, маємо суму нескінченної спадної геометричної прогресії:
   ```
   1_p(x) = 1 + x + x² + x³ + … = 1 / (1 - x)
   ```

3. **Для функції Мебіуса `μ(n)`:**
   Оскільки `μ * 1 = ε`, маємо `μ_p(x) · 1_p(x) = ε_p(x) = 1`. Звідси:
   ```
   μ_p(x) = 1 / 1_p(x) = 1 - x = 1 + (-1)·x + 0·x² + 0·x³ + …
   ```
   Зверніть увагу: коефіцієнт при `x⁰` дорівнює `1`, при `x¹` дорівнює `-1`, а при `x^k` (для `k ≥ 2`) дорівнює `0`. Це дає найпростіший алгебраїчний доказ значень `μ(p) = -1` та `μ(p^k) = 0` при `k ≥ 2` без використання складних сумаційних індукцій.

4. **Для тотожної функції `id(n) = n`:**
   Оскільки `id(p^k) = p^k`, отримуємо геометричну прогресію зі знаменником `p x`:
   ```
   id_p(x) = 1 + p·x + p²·x² + p³·x³ + … = 1 / (1 - p·x)
   ```

5. **Для функції Ейлера `φ = id * μ`:**
   Множимо відповідні ряди Белла для `id` та `μ`:
   ```
   φ_p(x) = id_p(x) · μ_p(x)
   = (1 - x) / (1 - p·x)            [множення рядів id_p(x) та μ_p(x)]
   = (1 - x) · (1 + p·x + p²·x² + …) [розгортка геометричної прогресії]
   = 1 + (p - 1)·x + p(p - 1)·x² + … [зведення подібних членів при x^k]
   ```
   Коефіцієнт при `x^k` дає класичну формулу `φ(p^k) = p^k - p^{k-1} = p^{k-1}(p - 1)`.

## 4. Доведення теореми про обернення Мебіуса

**Теорема.** Нехай `f` та `g` — дві арифметичні функції. Тоді співвідношення
`g(n) = ∑_{d|n} f(d)`
виконується для всіх `n ≥ 1` тоді й лише тоді, коли
`f(n) = ∑_{d|n} μ(d) g(n/d)`.

### Строге алгебраїчне доведення

Перепишемо вихідну умову `g(n) = ∑_{d|n} f(d)` у компактній алгебраїчній формі згортки Діріхле:
`g = f * 1`.

**Пряме твердження:**
Припустимо, що `g = f * 1`. Застосуємо операцію згортки з функцією Мебіуса `μ` до обох частин цієї рівності:

```
g * μ
= (f * 1) * μ                    [підстановка g = f * 1]
= f * (1 * μ)                    [за асоціативністю згортки]
= f * ε                          [бо 1 * μ = ε]
= f                              [бо f * ε = f]
```

**Обернене твердження:**
Припустимо, що `f = g * μ`. Застосуємо операцію згортки з постійною одиничною функцією `1`:

```
f * 1
= (g * μ) * 1                    [підстановка f = g * μ]
= g * (μ * 1)                    [за асоціативністю згортки]
= g * ε                          [бо μ * 1 = 1 * μ = ε]
= g                              [бо g * ε = g]
```

Завдяки введенню операції згортки громіздкі суми з подвійними індексами дільників згорнулися у дворядковий алгебраїчний висновок.

## 5. Збереження мультиплікативності при згортці

**Теорема.** Якщо арифметичні функції `f` та `g` є мультиплікативними, то їхня згортка `h = f * g` також є мультиплікативною функцією.

### Доведення

Нехай `m` та `n` — два натуральних числа такі, що `gcd(m, n) = 1`. Потрібно довести, що `h(m n) = h(m) h(n)`.

Будь-який дільник `d` добутку `m n` за умови `gcd(m, n) = 1` однозначно розкладається у добуток двох взаємно простих дільників `d = d₁ d₂`, де `d₁ | m`, `d₂ | n`, причому `gcd(d₁, d₂) = 1` та `gcd(m/d₁, n/d₂) = 1`. Запишемо згортку в точці `m n`:

```
h(m n)
= ∑_{d | m n} f(d) g( (m n) / d )                    [за означенням згортки]
= ∑_{d₁ | m} ∑_{d₂ | n} f(d₁ d₂) g( (m/d₁) · (n/d₂) ) [факторизація дільників d = d₁ d₂]
= ∑_{d₁ | m} ∑_{d₂ | n} f(d₁) f(d₂) g(m/d₁) g(n/d₂)  [за мультиплікативністю f та g]
= ( ∑_{d₁ | m} f(d₁) g(m/d₁) ) · ( ∑_{d₂ | n} f(d₂) g(n/d₂) ) [розділення незалежних сум]
= h(m) · h(n)                                        [висновок доведення]
```

Це доведення підтверджує, що підмножина мультиплікативних функцій утворює підгрупу в групі оборотних арифметичних функцій відносно згортки Діріхле.

## 6. Логарифмічна похідна та функція ман Гольдта

Розглянемо натуральний логарифм `ln(n)` як арифметичну функцію. Логарифм перетворює добуток чисел на суму `ln(m n) = ln(m) + ln(n)`, тобто є абсолютно адитивною арифметичною функцією.

Запитаємо: яка функція `Λ(n)` задовольняє алгебраїчну тотожність `Λ * 1 = ln`?

Застосувавши обернення Мебіуса до цієї рівності, виразимо `Λ` в явній формі:
`Λ = ln * μ ⇔ Λ(n) = ∑_{d|n} μ(d) ln(n/d) = ∑_{d|n} μ(d) (ln n - ln d) = - ∑_{d|n} μ(d) ln d`.

Обчислимо значення функції `Λ(n)` на простих степенях `p^k`:

```
Λ(p^k)
= ∑_{i=0}^k μ(p^i) ln(p^{k-i})                       [розгортка згортки ln * μ на p^k]
= μ(1) ln(p^k) + μ(p) ln(p^{k-1}) + 0 + … + 0        [бо μ(p^i) = 0 при i ≥ 2]
= 1 · k ln p + (-1) · (k - 1) ln p                  [підстановка μ(1)=1 та μ(p)=-1]
= ln p                                               [спрощення: k ln p - (k-1) ln p]
```

Якщо ж число `n` має принаймні два різних простих множники `n = p₁^{k₁} p₂^{k₂}`, розклад дає `Λ(n) = 0`.

Ця функція `Λ(n)` називається **функцією ман Гольдта**. Вона відіграє ключову роль у аналітичній теорії чисел, оскільки пов'язує логарифмічну похідну дзета-функції Рімана `-ζ'(s) / ζ(s) = ∑_{n=1}^∞ Λ(n) / n^s` із розподілом простих чисел.
