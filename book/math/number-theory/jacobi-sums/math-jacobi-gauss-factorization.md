# 𝔮 Точна факторизація та p-адичні нормалізації сум Якобі

Ця вставка містить суворий математичний вивід фундаментальної зв'язуючої тотожності між сумами Гаусса та сумами Якобі над скінченним полем `𝔽_q`, доведення модуля `|J| = √q`, числові приклади обчислення для полів `𝔽_7` та `𝔽_{13}`, а також точну формулу Штікельбергера для `p`-адичного порядку ідеалу суми Якобі.

## 1. Фундаментальна тотожність факторизації

Нехай `𝔽_q` — скінченне поле з `q = p^f` елементів. Нехай `χ₁, χ₂: 𝔽_q* → ℂ*` — мультиплікативні характери, які продовжено на zero умовою `χ(0) = 0` для нетривіальних характерів, та `ψ: 𝔽_q → ℂ*` — нетривіальний адитивний характер.

Сума Гаусса для характеру `χ` задається формулою:

```
g(χ, ψ) = ∑_{x ∈ 𝔽_q} χ(x) · ψ(x)
```

Сума Якобі для двох характерів `χ₁` та `χ₂` задається формулою:

```
J(χ₁, χ₂) = ∑_{t ∈ 𝔽_q} χ₁(t) · χ₂(1 - t)
```

### Теорема 1 (Факторизаційна формула Якобі–Гаусса)

Якщо характери `χ₁`, `χ₂` та їхній добуток `χ₁ · χ₂` є нетривіальними, то має місце тотожність:

```
g(χ₁, ψ) · g(χ₂, ψ) = J(χ₁, χ₂) · g(χ₁ · χ₂, ψ)
```

### Доведення

Запишемо добуток двох сум Гаусса у вигляді подвійного сумування по незалежних змінних `x, y ∈ 𝔽_q`:

```
g(χ₁, ψ) · g(χ₂, ψ)
= ( ∑_{x ∈ 𝔽_q} χ₁(x) ψ(x) ) · ( ∑_{y ∈ 𝔽_q} χ₂(y) ψ(y) )
= ∑_{x, y ∈ 𝔽_q} χ₁(x) χ₂(y) ψ(x + y)    [мультиплікативність ψ(x+y) = ψ(x)ψ(y)]
```

Здійснимо заміну змінних `u = x + y` (адитивна зсувна змінна) та `x = u · t` для `u ≠ 0`. Тоді `y = u - u·t = u(1 - t)`.

Розглянемо два випадки для значення `u`:

**Випадок 1: `u = 0`.** Якщо `x + y = 0`, то `y = -x`. Доданок під сумою набуває вигляду:

```
χ₁(x) χ₂(-x) ψ(0) = χ₁(x) χ₂(-x) · 1 = χ₂(-1) (χ₁ χ₂)(x)
```

Сума за всіма `x ∈ 𝔽_q` від `(χ₁ χ₂)(x)` дорівнює `0`, оскільки за умовою теореми добуток характерів `χ₁ χ₂` не є тривіальним. Отже, внесок від `u = 0` дорівнює точно нулю.

**Випадок 2: `u ≠ 0`.** Зафіксуємо `u ∈ 𝔽_q*` і покладемо `x = u · t`, звідки `t = x / u`. Оскільки `x` пробігає всі значення в `𝔽_q`, зміна `t` також пробігає всі значення в `𝔽_q`. Підставимо `x = u·t` та `y = u(1 - t)` у суму:

```
∑_{x, y ∈ 𝔽_q} χ₁(x) χ₂(y) ψ(x + y)
= ∑_{u ∈ 𝔽_q*} ∑_{t ∈ 𝔽_q} χ₁(u·t) χ₂(u(1 - t)) ψ(u)                [підстановка x=ut та y=u(1-t)]
= ∑_{u ∈ 𝔽_q*} ∑_{t ∈ 𝔽_q} χ₁(u) χ₁(t) χ₂(u) χ₂(1 - t) ψ(u)    [мультиплікативність χ(ut) = χ(u)χ(t)]
= ∑_{u ∈ 𝔽_q*} (χ₁ χ₂)(u) ψ(u) · ( ∑_{t ∈ 𝔽_q} χ₁(t) χ₂(1 - t) )  [групування доданків за u та t]
= g(χ₁ · χ₂, ψ) · J(χ₁, χ₂)                                    [за означеннями сум Гаусса та Якобі]
```

Оскільки сума Гаусса `g(χ₁ · χ₂, ψ)` для нетривіального характеру `χ₁ χ₂` є ненульовою, ділення обох частин на `g(χ₁ · χ₂, ψ)` дає шукану частку:

```
J(χ₁, χ₂) = (g(χ₁, ψ) · g(χ₂, ψ)) / g(χ₁ · χ₂, ψ)
```

Теорему доведено. `■`

## 2. Модуль та комплексна геометрія суми Якобі

### Теорема 2 (Модуль нетривіальної суми Якобі)

Якщо `χ₁`, `χ₂` та `χ₁ · χ₂` є нетривіальними характерами над `𝔽_q`, то комплексний модуль суми Якобі дорівнює точно:

```
|J(χ₁, χ₂)| = √q
```

### Доведення

Відомо з теорії сум Гаусса, що для будь-якого нетривіального мультиплікативного характеру `χ` та нетривіального адитивного характеру `ψ` модуль суми Гаусса дорівнює:

```
|g(χ, ψ)| = √q
```

Застосуємо операцію взяття комплексного модуля до обох частин факторизаційної формули Теореми 1:

```
|J(χ₁, χ₂)|
= |g(χ₁, ψ) · g(χ₂, ψ) / g(χ₁ · χ₂, ψ)|          [вжиття модуля від частки сум]
= (|g(χ₁, ψ)| · |g(χ₂, ψ)|) / |g(χ₁ · χ₂, ψ)|    [властивість модуля частки та добутку]
= (√q · √q) / √q                                 [підстановка модулів сум Гаусса]
= q / √q                                         [спрощення чисельника]
= √q                                             [скорочення на √q]
```

Теорему доведено. `■`

### Доведення для сопряженого характеру `J(χ, χ̄)`

Якщо `χ₂ = χ̄₁ = χ₁⁻¹`, то добуток характерів є тривіальним `χ₁ · χ₂ = χ₀`. Факторизаційна формула в цьому випадку не застосовується безпосередньо через обнулення знаменника. Доведемо точне значення аналітично:

```
J(χ, χ̄)
= ∑_{t ≠ 0, 1} χ(t) χ̄(1 - t)        [виділення нетривіальних доданків t ≠ 0, 1]
= ∑_{t ≠ 0, 1} χ( t / (1 - t) )      [підстановка сопряженого характеру χ̄(b) = χ⁻¹(b)]
```

Заміна `u = t / (1 - t)` є бієкцією між `𝔽_q \ {0, 1}` та `𝔽_q \ {0, -1}`. Тоді:

```
J(χ, χ̄)
= ∑_{u ≠ 0, -1} χ(u)                        [заміна змінної u = t/(1-t)]
= ( ∑_{u ∈ 𝔽_q} χ(u) ) - χ(0) - χ(-1)        [виділення точок 0 та -1]
= 0 - 0 - χ(-1)                             [ортогональність ∑ χ(u) = 0]
= -χ(-1)                                    [остаточне значення]
```

Отже, модуль сопряженої суми Якобі дорівнює `|J(χ, χ̄)| = |-χ(-1)| = 1`.

## 3. Числівний приклад 1: Обчислення сум Якобі на полі 𝔽_7

Проілюструємо теореми на конкретному простому модулі `p = 7`.

Мультиплікативна група `𝔽_7* = {1, 2, 3, 4, 5, 6}` є циклічною групою порядку `6`. Первісним коренем за модулем `7` є `g = 3`:

```
3¹ = 3,  3² = 2,  3³ = 6,  3⁴ = 4,  3⁵ = 5,  3⁶ = 1 (mod 7)
```

### Крок 1. Побудова характерів

Розглянемо кубічний характер `χ` (порядок `3`), визначений умовою `χ(3) = e^{2π i / 3} = ω`, де `ω = -1/2 + i √3 / 2`. Значення характеру `χ(x)` для `x ∈ 𝔽_7*`:

```
x = 1: χ(1) = 3⁰ mod 3 → ω⁰ = 1
x = 2: χ(2) = 3² mod 3 → ω² = -1/2 - i √3 / 2
x = 3: χ(3) = 3¹ mod 3 → ω¹ = -1/2 + i √3 / 2
x = 4: χ(4) = 3⁴ mod 3 → ω¹ = -1/2 + i √3 / 2
x = 5: χ(5) = 3⁵ mod 3 → ω² = -1/2 - i √3 / 2
x = 6: χ(6) = 3³ mod 3 → ω⁰ = 1
```

### Крок 2. Обчислення суми Якобі J(χ, χ)

Формула розгортається у суму для `t ∈ {2, 3, 4, 5, 6}` (бо при `t = 0` та `t = 1` доданки дорівнюють `0`):

```
J(χ, χ) = ∑_{t = 2}^{6} χ(t) · χ(1 - t)
```

Обчислимо кожен доданок окремо (пам'ятаючи, що від'ємні значення розглядаються mod `7`):

```
t = 2: χ(2) · χ(-1) = χ(2) · χ(6) = ω² · 1 = ω²
t = 3: χ(3) · χ(-2) = χ(3) · χ(5) = ω¹ · ω² = ω³ = 1
t = 4: χ(4) · χ(-3) = χ(4) · χ(4) = ω¹ · ω¹ = ω²
t = 5: χ(5) · χ(-4) = χ(5) · χ(3) = ω² · ω¹ = ω³ = 1
t = 6: χ(6) · χ(-5) = χ(6) · χ(2) = 1 · ω² = ω²
```

Просумуємо отримані п'ять доданків:

```
J(χ, χ)
= ω² + 1 + ω² + 1 + ω²           [сума доданків t = 2,3,4,5,6]
= 2 + 3 ω²                       [групування дійсних і кубічних коренів]
= 2 + 3 (-1/2 - i √3 / 2)        [підстановка ω² = -1/2 - i √3/2]
= 2 - 3/2 - i 3√3 / 2            [розкриття дужок]
= 1/2 - i 3√3 / 2                [обчислення дійсної частини 2 - 3/2 = 1/2]
```

### Крок 3. Перевірка комплексного модуля

Обчислимо квадрат модуля отриманого значення `J(χ, χ)`:

```
|J(χ, χ)|²
= (1/2)² + (-3√3 / 2)²    [сума квадратів дійсної та уявної частин]
= 1/4 + 27/4              [піднесення до квадрата: (1/2)²=1/4, (-3√3/2)²=27/4]
= 28/4                    [додавання дробів 1/4 + 27/4]
= 7 = p                   [скорочення 28/4 = 7]
```

Отже, `|J(χ, χ)| = √7`, що точно підтверджує Теорему 2!

## 4. Числівний приклад 2: Квартична сума Якобі на полі 𝔽_13

Розглянемо просте число `p = 13 ≡ 1 (mod 4)`. Мультиплікативна група `𝔽_13*` має порядок `12`. Первісним коренем за модулем `13` є `g = 2`.

Побудуємо квартичний характер `χ` (порядок `4`), для якого `χ(2) = i = √{-1}`.

Таблиця індексів `ind_2(x)` та значення `χ(x)`:

```
x = 1: ind_2(1) = 0   ⇒  χ(1) = i⁰ = 1
x = 2: ind_2(2) = 1   ⇒  χ(2) = i¹ = i
x = 3: ind_2(3) = 4   ⇒  χ(3) = i⁴ = 1
x = 4: ind_2(4) = 2   ⇒  χ(4) = i² = -1
x = 5: ind_2(5) = 9   ⇒  χ(5) = i⁹ = i
x = 6: ind_2(6) = 5   ⇒  χ(6) = i⁵ = i
x = 7: ind_2(7) = 11  ⇒  χ(7) = i¹¹ = -i
x = 8: ind_2(8) = 3   ⇒  χ(8) = i³ = -i
x = 9: ind_2(9) = 8   ⇒  χ(9) = i⁸ = 1
x = 10: ind_2(10) = 10 ⇒ χ(10) = i¹⁰ = -1
x = 11: ind_2(11) = 7  ⇒ χ(11) = i⁷ = -i
x = 12: ind_2(12) = 6  ⇒ χ(12) = i⁶ = -1
```

Обчислимо суму Якобі `J(χ, χ) = ∑_{t=2}^{12} χ(t) · χ(1 - t)`:

```
t = 2:  χ(2) χ(12)  = i · (-1) = -i
t = 3:  χ(3) χ(11)  = 1 · (-i) = -i
t = 4:  χ(4) χ(10)  = (-1) · (-1) = 1
t = 5:  χ(5) χ(9)   = i · 1 = i
t = 6:  χ(6) χ(8)   = i · (-i) = 1
t = 7:  χ(7) χ(7)   = (-i) · (-i) = -1
t = 8:  χ(8) χ(6)   = (-i) · i = 1
t = 9:  χ(9) χ(5)   = 1 · i = i
t = 10: χ(10) χ(4)  = (-1) · (-1) = 1
t = 11: χ(11) χ(3)  = (-i) · 1 = -i
t = 12: χ(12) χ(2)  = (-1) · i = -i
```

Просумуємо всі доданки:

```
J(χ, χ)
= (-i) + (-i) + 1 + i + 1 + (-1) + 1 + i + 1 + (-i) + (-i)    [підстановка доданків t = 2..12]
= (1 + 1 - 1 + 1 + 1) + (-i - i + i + i - i - i)              [групування дійсної та уявної частин]
= 3 - 2i                                                       [обчислення 3 і -2i]
```

Перевіримо квадрат модуля суми Якобі:

```
|J(χ, χ)|² = 3² + (-2)² = 9 + 4 = 13 = p
```

Сума Якобі `J(χ, χ) = 3 - 2i` лежить у кільці цілих гауссових чисел `ℤ[i]` і розкладає просте число `13` у суму квадратів: `13 = 3² + 2²`. Це безпосередньо підтверджує результат Гаусса про розклад простих чисел `p ≡ 1 (mod 4)` через суми Якобі!

## 5. Дія групи Galois та автоморфізми кругових полів

Кожна сума Якобі `J(χᵃ, χᵇ)` є елементом кругового поля `ℚ(ζ_m)`. Група Galois розширення `ℚ(ζ_m)/ℚ` є абелевою і ізоморфною мультиплікативній групі рештків `(ℤ/mℤ)*`. Автоморфізми групи Galois діють на суми Якобі шляхом піднесення характерів до степеня `k`:

```
σ_k ( J(χᵃ, χᵇ) ) = J(χ^{k·a}, χ^{k·b})
```

для кожного `k ∈ (ℤ/mℤ)*`.

Ця інваріантність за діянням автоморфізмів Galois означає, що орбіта суми Якобі під діянням групи `Galois(ℚ(ζ_m)/ℚ)` утворює цілий незвідний многочлен із раціональними коефіцієнтами. Коефіцієнти цього многочлена виражають кількості точок на алгебраїчних кривих і є повністю інваріантними відносно вибору первісного кореня `g`.

## 6. Теорема Штікельберга про p-адичну факторизацію ідеалу

У круговому полі `K = ℚ(ζ_p)` кільцем цілих є `𝒪_K = ℤ[ζ_p]`. Просте число `p` є повністю розгалуженим у `K`: `(p) = (1 - ζ_p)^{p-1}`.

Нехай `𝔭 = (1 - ζ_p)` — унікальний просторний ідеал, що лежить над `p`.

### Теорема 3 (Штікельбергер)

Нехай `a, b` — цілі числа такі, що `a, b, a + b ≢ 0 (mod p - 1)`. Тоді `p`-адичний порядок ідеалу суми Якобі `(J(χᵃ, χᵇ))` у розкладі за просторним ідеальним фактором `𝔭` задовольняє тотожність:

```
v_𝔭( J(χᵃ, χᵇ) ) = s_p(a) + s_p(b) - s_p(a + b)
```

де `s_p(k)` позначає суму цифр числа `k` у `p`-адичному розкладі:

```
k = d₀ + d₁ p + d₂ p² + ... + d_r p^r  ⇒  s_p(k) = ∑_{i=0}^{r} d_i
```

### Наслідок про кількість перенесень розрядів

Оскільки для будь-яких цілих `a, b` різниця `s_p(a) + s_p(b) - s_p(a + b)` є точно кратною `(p - 1)` і дорівнює кількості перенесень розрядів одиниці при додаванні `a + b` у `p`-адичній системі числення, помноженій на `(p - 1)`, порядок ідеалу суми Якобі характеризує комбінаторне перенесення розрядів в арифметиці модулярного поля.

Теорема Штікельбергера гарантує, що показник степеня простого ідеалу визначається виключно p-адичною арифметикою показників характерів. Це фундаментальне співвідношення лежить в основі точного підрахунку точок на різноманітностях Вейля, розв'язання законів взаємності та побудови детермінованих квазіполіноміальних тестів простоти.

У загальному випадку кругового поля `ℚ(ζ_m)` для довільного `m` ідеал Штікельбергера визначається діянням автоморфізмів Galois `σ_t: ζ_m ↦ ζ_m^t`, а відповідна сума Якобі розкладається на просторні множники `𝔭_t^{γ(t)}`, де `γ(t) = ⌊(⟨t·a⟩_m + ⟨t·b⟩_m)/m⌋`.
