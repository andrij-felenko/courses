Коли ми намагаємося порахувати точну кількість розв'язків алгебраїчного рівняння `xⁿ + yⁿ = 1` над скінченним полем `𝔽_q`, звичайне перебирання пар `(x, y)` швидко виявляється непридатним для великих модулів `q`. Пряма заміна змінних `u = xⁿ` та `v = yⁿ` зводить задачу до лінійного співвідношення `u + v = 1`, але змушує враховувати, скільки саме степенів `n`-го порядку `x` та `y` відображаються у вибрані значення `u` та `v`. Оскільки індикаторний вираз для кількості розв'язків рівняння `xⁿ = u` природним чином розкладається у суму по всіх мультиплікативних характерах порядку `n`, кількість розв'язків початкового діофантового рівняння точно розпадається на головний член `q` та згортку двох характерів за умови `u + v = 1`. Ця сума фазових зсувів двох характерів дістала назву **суми Якобі**.

Суми Якобі займають унікальне місце на межі між дискретною арифметикою скінченних полів, геометрією алгебраїчних кривих та p-адичним аналізом. Вони слугують інструментом для доведення вищих законів взаємності (кубічного та квартичного), виражають локальні дзета-функції різноманітностей Вейля та лежать в основі квазіполіноміального тесту простоти чисел APR-CL.

## 1. Конструкція індикаторних функцій та виникнення суми Якобі

Щоб зрозуміти, чому виникає сума Якобі, розглянемо завдання підрахунку точок на алгебраїчній кривій Ферма (лат. *curva*, що позначає лінію, задану алгебраїчним рівнянням):

```
xⁿ + yⁿ = 1
```

де `x, y ∈ 𝔽_q`, а порядок `n` ділить `q - 1`.

Мультиплікативна група скінченного поля `𝔽_q*` є циклічною групою порядку `q - 1`. Оскільки група є циклічною, вона має точно `q - 1` мультиплікативних характерів `χ: 𝔽_q* → ℂ*`. Множина усіх таких характерів утворює циклічну групу характерів `X(𝔽_q*)`, ізоморфну самій групі `𝔽_q*`.

Для будь-якого елемента `u ∈ 𝔽_q*` кількість розв'язків рівняння `xⁿ = u` виражається тотожністю через характери, порядок яких ділить `n`:

```
N(xⁿ = u) = ∑_{χⁿ = χ₀} χ(u)
```

де `χ₀` — тривіальний характер (що приймає значення `1` для всіх ненульових елементів поля), а сумування здійснюється по всіх `n` характерах `χ`, що задовольняють умову `χⁿ = χ₀`.

Якщо `u` є `n`-им степенем у `𝔽_q*` (тобто `u = wⁿ`), то для кожного характеру `χ` із `χⁿ = χ₀` маємо `χ(u) = χ(wⁿ) = χⁿ(w) = 1`. Сума `n` одиниць дає точно `n` розв'язків. Якщо ж `u` не є `n`-им степенем, сума характерів дорівнює `0` внаслідок ортогональності характерів над циклічною групою.

Застосуємо цю індикаторну формулу одночасно для змінних `u = xⁿ` та `v = yⁿ` при умові `u + v = 1`:

```
N(xⁿ + yⁿ = 1)
= ∑_{u + v = 1} N(xⁿ = u) · N(yⁿ = v)                              [розклад за значеннями u та v]
= ∑_{u + v = 1} ( ∑_{χ₁ⁿ = χ₀} χ₁(u) ) · ( ∑_{χ₂ⁿ = χ₀} χ₂(v) )   [підстановка характерового індикатора]
= ∑_{χ₁ⁿ = χ₀} ∑_{χ₂ⁿ = χ₀} ( ∑_{u + v = 1} χ₁(u) · χ₂(v) )       [перестановка порядку сумування]
```

У цій подвійній сумі кожен внутрішній доданок зафіксований для пари характерів `χ₁` та `χ₂` і має вигляд згортки:

```
∑_{u + v = 1} χ₁(u) · χ₂(v) = ∑_{u ∈ 𝔽_q} χ₁(u) · χ₂(1 - u)
```

Саме ця комбінаторна згортка двох мультиплікативних характерів за адитивною умовою `u + v = 1` і називається **сумою Якобі**.

## 2. Формальне означення та граничні властивості

Нехай `𝔽_q` — скінченне поле з `q = p^f` елементів, а `χ₁, χ₂: 𝔽_q* → ℂ*` — два мультиплікативні характери. Продовжимо характери на нульовий елемент поля за стандартним правилом: `χ(0) = 0` для будь-якого нетривіального характеру `χ ≠ χ₀`, та `χ₀(0) = 1` для тривіального характеру.

### Означення

**Двовимірною сумою Якобі** (нім. *Jacobi-Summe*, на честь Карла Густава Якобі) для характерів `χ₁` та `χ₂` називається комплекснозначне число:

```
J(χ₁, χ₂) = ∑_{t ∈ 𝔽_q} χ₁(t) · χ₂(1 - t)
```

Загалом для `m` характерів `χ₁, χ₂, ..., χ_m` **багатовимірна сума Якобі** визначається підсумовуванням по гіперплощині `t₁ + t₂ + ... + t_m = 1`:

```
J(χ₁, χ₂, ..., χ_m) = ∑_{t₁ + t₂ + ... + t_m = 1} χ₁(t₁) · χ₂(t₂) · ... · χ_m(t_m)
```

### Повна класифікація граничних випадків

Значення `J(χ₁, χ₂)` повністю характеризується залежно від тривіальності характерів-аргументів:

1. **Обидва характери тривіальні (`χ₁ = χ₀`, `χ₂ = χ₀`):**
   Сума містить `q` доданків, кожен з яких дорівнює `1 · 1 = 1`:
   ```
   J(χ₀, χ₀) = ∑_{t ∈ 𝔽_q} 1 = q
   ```

2. **Один характер нетривіальний (`χ₁ ≠ χ₀`), а інший тривіальний (`χ₂ = χ₀`):**
   Оскільки `χ₂(1 - t) = 1` для всіх `t`, а `χ₁(0) = 0`, маємо:
   ```
   J(χ₁, χ₀) = ∑_{t ∈ 𝔽_q} χ₁(t) = 0
   ```
   Це прямий наслідок ортогональності характерів над скінченною групою: сума значень будь-якого нетривіального характеру по всьому полю дорівнює нулю.

3. **Характери є сопряженими (`χ₂ = χ̄₁ = χ₁⁻¹`, тобто `χ₁ · χ₂ = χ₀` при `χ₁ ≠ χ₀`):**
   У цьому випадку доданок при `t = 0` дорівнює `0`, при `t = 1` дорівнює `0`. Для решти `t ≠ 0, 1` маємо `χ₂(1 - t) = χ₁⁻¹(1 - t)`. Перетворимо вираз під сумою:
   ```
   J(χ₁, χ̄₁)
   = ∑_{t ≠ 0, 1} χ₁(t) · χ₁⁻¹(1 - t)    [підстановка протилежного характеру χ̄]
   = ∑_{t ≠ 0, 1} χ₁( t / (1 - t) )      [мультиплікативна властивість χ(a)χ⁻¹(b) = χ(a/b)]
   ```
   Зробимо заміну змінних `u = t / (1 - t)`. Оскільки `t` пробігає всі елементи `𝔽_q \ {0, 1}`, змінна `u` пробігає всі елементи `𝔽_q \ {0, -1}`. Отже:
   ```
   J(χ₁, χ̄₁)
   = ∑_{u ≠ 0, -1} χ₁(u)                                  [заміна змінної u = t/(1-t)]
   = ( ∑_{u ∈ 𝔽_q} χ₁(u) ) - χ₁(0) - χ₁(-1)                [виділення виключених точок 0 та -1]
   = 0 - 0 - χ₁(-1)                                       [ортогональність ∑ χ(u) = 0 та χ(0) = 0]
   = -χ₁(-1)                                              [остаточний висновок]
   ```
   Зокрема, якщо `χ₁` є квадратичним характером (символом Лежандра `(t/p)`), то `J(χ, χ) = -χ(-1) = -(-1)^{(p-1)/2}`.

4. **Загальний нетривіальний випадок (`χ₁ ≠ χ₀`, `χ₂ ≠ χ₀` та `χ₁ · χ₂ ≠ χ₀`):**
   Сума Якобі є нетривіальним комплекснозначним числом із фіксованим модулем `|J(χ₁, χ₂)| = √q`.

Докладніше про історичний контекст висунення цих тотожностей Гауссом та Якобі описано у вставці [📜 Історія виникнення та розвитку сум Якобі](book:math/number-theory/jacobi-sums/hist-jacobi-sums.md).

## 3. Міст до сум Гаусса та комплексна геометрія

Найважливішим математичним властивістю нетривіальних сум Якобі є їхній тісний зв'язок із сумами Гаусса. Нехай `ψ: 𝔽_q → ℂ*` — нетривіальний адитивний характер (наприклад, `ψ(x) = exp(2π i · Tr(x) / p)`). 

Сума Гаусса для характеру `χ` задається формулою:

```
g(χ, ψ) = ∑_{x ∈ 𝔽_q} χ(x) · ψ(x)
```

Якщо характери `χ₁`, `χ₂` та їхній добуток `χ₁ · χ₂` є нетривіальними, сума Якобі розкладається у частку трьох сум Гаусса:

```
J(χ₁, χ₂) = (g(χ₁, ψ) · g(χ₂, ψ)) / g(χ₁ · χ₂, ψ)
```

### Доведення тотожності факторизації

Розглянемо добуток двох сум Гаусса `g(χ₁, ψ) · g(χ₂, ψ)`:

```
g(χ₁, ψ) · g(χ₂, ψ)
= ( ∑_{x ∈ 𝔽_q} χ₁(x) ψ(x) ) · ( ∑_{y ∈ 𝔽_q} χ₂(y) ψ(y) )           [за означенням сум Гаусса]
= ∑_{x, y ∈ 𝔽_q} χ₁(x) χ₂(y) ψ(x + y)                              [мультиплікативність ψ(x+y) = ψ(x)ψ(y)]
```

Здійснимо заміну змінних `u = x + y` та `x = u · t`. Оскільки `u` може приймати будь-які значення з `𝔽_q`, розіб'ємо суму на дві частини:

- **Частина `u = 0`:** Якщо `x + y = 0`, то `y = -x`. Внесок дорівнює:
  ```
  ∑_{x ∈ 𝔽_q} χ₁(x) χ₂(-x) ψ(0) = χ₂(-1) ∑_{x ∈ 𝔽_q} (χ₁ χ₂)(x) = 0
  ```
  оскільки `χ₁ χ₂ ≠ χ₀` за умовою.

- **Частина `u ≠ 0`:** Покладемо `x = u · t`, звідки `y = u(1 - t)`. Оскільки `u ≠ 0`, при фіксованому `u` змінна `t` пробігає весь `𝔽_q`. Підставимо ці вирази у суму:
  ```
  ∑_{u ∈ 𝔽_q*} ∑_{t ∈ 𝔽_q} χ₁(u·t) χ₂(u(1-t)) ψ(u)
  = ∑_{u ∈ 𝔽_q*} (χ₁ χ₂)(u) ψ(u) · ( ∑_{t ∈ 𝔽_q} χ₁(t) χ₂(1-t) )      [групування за u та t]
  = g(χ₁ · χ₂, ψ) · J(χ₁, χ₂)                                      [факторизація на суму Гаусса та Якобі]
  ```

Отже, `g(χ₁, ψ) · g(χ₂, ψ) = J(χ₁, χ₂) · g(χ₁ · χ₂, ψ)`. Оскільки сума Гаусса нетривіального характеру `g(χ₁ · χ₂, ψ)` є ненульовою, ділення обох частин на `g(χ₁ · χ₂, ψ)` доводить факторизаційну формулу.

### Обчислення комплексного модуля

Ця формула дозволяє негайно обчислити точний комплексний модуль суми Якобі. Оскільки модуль будь-якої нетривіальної суми Гаусса дорівнює `|g(χ, ψ)| = √q`, маємо:

```
|J(χ₁, χ₂)|
= |g(χ₁, ψ) · g(χ₂, ψ) / g(χ₁ · χ₂, ψ)|          [вжиття модуля від факторизаційної формули]
= (|g(χ₁, ψ)| · |g(χ₂, ψ)|) / |g(χ₁ · χ₂, ψ)|    [властивість модуля частки та добутку]
= (√q · √q) / √q                                 [підстановка значень модулів сум Гаусса]
= √q                                             [скорочення на √q]
```

![Геометрія суми Якобі в комплексній площині](/book/math/number-theory/jacobi-sums/img/jacobi-sum-circle.svg)
*Геометричне представлення суми Якобі J(χ₁, χ₂) як зсуву векторів фаз на колі радіуса √q в комплексній площині ℂ.*

Геометричний зміст цієї теореми вражає: хоча сума Якобі `J(χ₁, χ₂)` складається з `q` векторів одиничної довжини, повернутих на різні кути, їхній підсумковий вектор не хаотичний. Він завжди розташований точно на колі радіуса `√q` у комплексній площині `ℂ`.

![Структурний міст між сумами Гаусса, Якобі та точками на кривих](/book/math/number-theory/jacobi-sums/img/jacobi-gauss-bridge.svg)

## 4. Редукція багатовимірних сум Якобі та зв'язок із розширеннями полів

Для довільного числа `m ≥ 2` характерів `χ₁, χ₂, ..., χ_m` багатовимірна сума Якобі задовольняє аналогічну факторизаційну формулу через суми Гаусса:

```
J(χ₁, χ₂, ..., χ_m) = ( g(χ₁, ψ) · g(χ₂, ψ) · ... · g(χ_m, ψ) ) / g(χ₁ · χ₂ · ... · χ_m, ψ)
```

якщо добуток `χ₁ · χ₂ · ... · χ_m ≠ χ₀`.

Якщо ж добуток усіх характерів є тривіальним `χ₁ · χ₂ · ... · χ_m = χ₀`, але жоден із характерів `χ_i` не є тривіальним, то багатовимірна сума Якобі пов'язана з виміром `m - 1` тотожністю:

```
J(χ₁, χ₂, ..., χ_m) = -χ_m(-1) · J(χ₁, χ₂, ..., χ_{m-1})
```

### Теорема підйому Девенпорта–Хассе для сум Якобі

При розширенні скінченного поля `𝔽_{q^s} / 𝔽_q` характери піднімаються через норму: `χ' = χ ∘ Norm_{𝔽_{q^s}/𝔽_q}`. Співвідношення Девенпорта–Хассе (Davenport-Hasse relation) для сум Гаусса визначає відповідну формулу підйому для сум Якобі у розширенні `𝔽_{q^s}`:

```
J(χ₁', χ₂') = (-1)^{s-1} ( J(χ₁, χ₂) )^s
```

Ця тотожність показує, що при підйомі поля значення суми Якобі підноситься до `s`-го степеня з точністю до знакового множника `(-1)^{s-1}`. Це є ключовим інструментом для вираження коефіцієнтів локальної дзета-функції Вейля через власні значення Фробеніуса.

## 5. Підрахунок точок на кривих та Гіпотези Вейля

Використовуючи суми Якобі, точний підрахунок кількості розв'язків рівняння Ферма `xⁿ + yⁿ = 1` в `𝔽_q` можна записати у вигляді строгої формули.

Нехай `χ` — генератор групи характерів, порядок яких ділить `n`. Тоді кількість точок `N` дорівнює:

```
N(xⁿ + yⁿ = 1) = q + ∑_{i=1}^{n-1} ∑_{j=1}^{n-1} J(χⁱ, χʲ)
```

### Аналіз доданків та оцінка Вейля

Розділимо суму на дві частини залежно від тривіальності добутку характерів `χⁱ · χʲ = χ^{i+j}`:

1. **Випадок `i + j ≡ 0 (mod n)`:** Добуток характерів є тривіальним. Оскільки `χⁱ ≠ χ₀`, доданок дорівнює `J(χⁱ, χ̄ⁱ) = -χⁱ(-1)`. Кількість таких пар дорівнює `n - 1`.
2. **Випадок `i + j ≢ 0 (mod n)`:** Отримуємо `(n - 1)(n - 2)` нетривіальних сум Якобі, модуль кожної з яких дорівнює `|J(χⁱ, χʲ)| = √q`.

Застосуємо нерівність трикутника для модуля суми:

```
|N - q|
= | ∑_{i=1}^{n-1} ∑_{j=1}^{n-1} J(χⁱ, χʲ) |
≤ ∑_{i+j ≡ 0} | -χⁱ(-1) | + ∑_{i+j ≢ 0} | J(χⁱ, χʲ) |
= (n - 1) · 1 + (n - 1)(n - 2) √q
≤ (n - 1)(n - 2) √q    [для q ≥ 4]
```

Величина `g = (n - 1)(n - 2) / 2` є точним алгебраїчним родом (лат. *genus*) гладкої кривої Ферма. Таким чином, оцінка Вейля набуває класичного вигляду:

```
|N - (q + 1)| ≤ 2 g √q
```

Це доводить аналог Гіпотези Рімана для діагональних кривих над скінченними полями: усі нулі локальної дзета-функції `Z(T)` лежать на критичній прямій `Re(s) = 1/2`.

Крім кривих Ферма, суми Якобі застосовуються для підрахунку точок у сімействі Лежандра еліптичних кривих `y² = x(x - 1)(x - λ)` та для діагональних гіперповерхонь у проєктивних просторах `c₁ x₁^{n₁} + ... + c_k x_k^{n_k} = 0`.

### Повний приклад підрахунку точок на кубічній кривій над 𝔽_7

Проілюструємо застосування суми Якобі для рівняння `x³ + y³ = 1` над полем `𝔽_7` (`q = 7, n = 3`).

1. Порядок `n = 3` ділить `p - 1 = 6`. Нехай `χ` — кубічний характер над `𝔽_7`.
2. Члени суми мають виглядати так:
   ```
   N = 7 + J(χ¹, χ¹) + J(χ¹, χ²) + J(χ², χ¹) + J(χ², χ²)
   ```
3. Оскільки `χ¹ · χ² = χ³ = χ₀`, то діагональні члени дорівнюють `J(χ¹, χ²) = J(χ², χ¹) = -χ¹(-1) = -χ¹(6) = -1`.
4. Для нетривіальних сум `J(χ¹, χ¹)` та `J(χ², χ²)` ми обчислили раніше:
   ```
   J(χ¹, χ¹) = 1/2 - i 3√3 / 2
   J(χ², χ²) = J(χ̄¹, χ̄¹) = 1/2 + i 3√3 / 2
   ```
5. Сумуємо всі значення:
   ```
   N
   = 7 + (1/2 - i 3√3 / 2) + (-1) + (-1) + (1/2 + i 3√3 / 2)   [підстановка обчислених сум Якобі]
   = 7 + 1 - 2                                                 [взаємне скорочення уявних частин]
   = 6                                                         [остаточний точний підрахунок точок]
   ```
Отже, кубічне рівняння `x³ + y³ = 1 (mod 7)` має точно `6` розв'язків. Перевіримо прямим підрахунком пар `(x, y)` mod `7`:
- Куби в `𝔽_7`: `0³ = 0`, `1³ = 1`, `2³ = 1`, `3³ = 6`, `4³ = 1`, `5³ = 6`, `6³ = 6`.
- Пара `x³ + y³ = 1`: `(0, 1), (0, 2), (0, 4), (1, 0), (2, 0), (4, 0)` — разом точно 6 розв'язків!

## 6. Арифметична факторизація Штікельберга

Сума Якобі `J(χ₁, χ₂)` є не просто комплексним числом, а цілим алгебраїчним числом, що належить круговому полю `K = ℚ(ζ_m)`, де `m` — спільний порядок характерів `χ₁` та `χ₂`.

У 1890 році Людвіг Штікельбергер довів, що головний ідеал `(J(χᵃ, χᵇ))`, породжений сумою Якобі в кільці цілих `ℤ[ζ_m]`, розкладається на просторні ідеали `𝔭_t` за формулою:

```
(J(χᵃ, χᵇ)) = ∏_{t ∈ (ℤ/mℤ)*} (𝔭_t)^{γ(t)}
```

Показник степеня `γ(t)` дорівнює кількості перенесень розрядів одиниці при додаванні `t·a + t·b` у `p`-адичній системі числення:

```
γ(t) = ⌊ (⟨t·a⟩_m + ⟨t·b⟩_m) / m ⌋
```

![Розклад Штікельберга ідеалу суми Якобі](/book/math/number-theory/jacobi-sums/img/stickelberger-decomposition.svg)
*Факторизація головного ідеалу суми Якобі у круговому полі через перенесення розрядів p-адичних цифр.*

Ця факторизація Штікельбергера визначає точну структуру ідеалів у кругових розширеннях і відіграє вирішальну роль у доведенні вищих законів взаємності (кубічного та квартичного законів взаємності Ейзенштейна та Гаусса).

## 7. Рівномірний розподіл Сато–Тейта та фази сум Якобі

Оскільки модуль кожної нетривіальної суми Якобі дорівнює `|J(χ₁, χ₂)| = √q`, нормалізоване значення `J(χ₁, χ₂) / √q` є комплексним числом одиничного модуля і може бути записане у формі `exp(i θ_q)`.

Теорема Каца–Сарнака (Katz-Sarnak) стверджує, що при варіюванні характерів або модуля `q` кути фаз `θ_q` розподіляються за відповідною мірою Хаара на компактній групі Лі `Lie(G)` (для еліптичних кривих це група `SU(2)` або `U(1)`). Це дає точний аналог гіпотези Сато–Тейта для фаз сум Якобі та дозволяє застосовувати їх у спектральному аналізі випадкових матриць та квантовому хаосі.

## 8. Алгоритми та обчислювальні застосування

На практиці суми Якобі широко використовуються у двох сферах обчислювальної математики:

1. **Алгебраїчна геометрія та криптографія:** Для швидкого обчислення кількості точок на еліптичних та гіпереліптичних кривих над скінченними полями `𝔽_{p^f}` та визначення вагової структури циклічних кодів у теорії кодування.
2. **Детермінований тест простоти APR-CL:** Алгоритм Адлемана–Померанса–Румелі–Коена–Ленстри перевіряє простоту великого числа `N` шляхом перевірки степеневих порівнянь для сум Якобі в кільцях `ℤ[ζ_m] / (N)`. Якщо `N` є простим, суми Якобі задовольняють співвідношення Штікельбергера за модулем `N`. Це дозволяє перевіряти простоту чисел розміром понад 1000 біт за квазіполіноміальний час `O((\log N)^{c \log \log \log N})`.
