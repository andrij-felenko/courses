## 1. Аліквотна сума та три класи Нікомаха Гераського

Розглянемо натуральне число `n`. Кожне таке число має множину додатних дільників. Серед них особливе місце посідають **власні дільники** (або аліквотні частини) — це всі дільники числа `n`, крім самого числа `n`.

У теорії чисел класична арифметична функція `σ(n)` (сигма-функція) визначається як сума всіх додатних дільників числа `n`. Сума власних дільників, яку позначають як `s(n)`, обчислюється відніманням самого числа `n` від загальної суми дільників:

```
s(n) = σ(n) - n      [сума власних дільників]
```

Приблизно у 100 році нашої ери давньогрецький філософ і математик Нікомах Гераський у своїй праці «Вступ до арифметики» запропонував порівнювати суму власних дільників `s(n)` із самим числом `n`. На основі цього порівняння всі натуральні числа, більші за одиницю, розбиваються на три класи, що не перетинаються:

1. **Досконалі числа** (perfect numbers) — числа, сума власних дільників яких точно дорівнює самому числу: `s(n) = n` (що еквівалентно `σ(n) = 2 · n`).
2. **Недостатні числа** (deficient numbers) — числа, сума власних дільників яких менша за саме число: `s(n) < n` (що еквівалентно `σ(n) < 2 · n`).
3. **Надлишкові числа** (abundant numbers) — числа, сума власних дільників яких перевищує саме число: `s(n) > n` (що еквівалентно `σ(n) > 2 · n`).

Для кількісної оцінки міри надлишковості чи недостатності вводять поняття **індексу надлишковості** (або відносного індексу дільників) `I(n)`, який є відношенням суми всіх дільників до самого числа:

```
I(n) = σ(n) / n      [індекс надлишковості]
```

Використовуючи індекс `I(n)`, три класи Нікомаха записуються у вигляді нерівностей:
- Недостатні числа: `I(n) < 2`.
- Досконалі числа: `I(n) = 2`.
- Надлишкові числа: `I(n) > 2`.

Абсолютна різниця між сумою власних дільників та самим числом називається **числовим надлишком** (або просто надлишком) `a(n)`:

```
a(n) = s(n) - n = σ(n) - 2 · n      [числовий надлишок]
```

Якщо `a(n) > 0`, число є надлишковим на величину `a(n)`. Якщо `a(n) < 0`, число є недостатнім, а величина `|a(n)|` називається його дефіцитом.

Обчислимо суми дільників та індекси надлишковості для кількох характерних натуральних чисел:

- Для числа `n = 6`:
  Дільниками є `{1, 2, 3, 6}`. Власні дільники — `{1, 2, 3}`.
  Сума власних дільників `s(6) = 1 + 2 + 3 = 6`.
  Індекс надлишковості `I(6) = (1 + 2 + 3 + 6) / 6 = 12 / 6 = 2`.
  Число `6` є найменшим досконалим числом.

- Для числа `n = 8`:
  Дільниками є `{1, 2, 4, 8}`. Власні дільники — `{1, 2, 4}`.
  Сума власних дільників `s(8) = 1 + 2 + 4 = 7`.
  Оскільки `7 < 8`, число `8` є недостатнім. Його дефіцит дорівнює `8 - 7 = 1`, а індекс `I(8) = 15 / 8 = 1.875 < 2`.

- Для числа `n = 12`:
  Дільниками є `{1, 2, 3, 4, 6, 12}`. Власні дільники — `{1, 2, 3, 4, 6}`.
  Сума власних дільників `s(12) = 1 + 2 + 3 + 4 + 6 = 16`.
  Оскільки `16 > 12`, число `12` є найменшим надлишковим числом. Його надлишок дорівнює `16 - 12 = 4`, а індекс `I(12) = 28 / 12 = 7 / 3 ≈ 2.333 > 2`.

- Для числа `n = 945`:
  Власні дільники включають `{1, 3, 5, 7, 9, 15, 21, 27, 35, 45, 63, 105, 135, 189, 315}`.
  Сума власних дільників `s(945) = 975`.
  Оскільки `975 > 945`, число `945` є надлишковим. Це найменше непарне надлишкове число.

## 2. Аналітичні властивості індексу надлишковості та спадковість

Сума дільників `σ(n)` є мультиплікативною арифметичною функцією. Це означає, що для будь-яких взаємно простих чисел `a` та `b` (для яких `gcd(a, b) = 1`) виконується тотожність:

```
σ(a · b) = σ(a) · σ(b)      [мультиплікативність сигма-функції]
```

Оскільки `I(n) = σ(n) / n`, індекс надлишковості також збереже властивість мультиплікативності для взаємно простих аргументів:

```
I(a · b) = σ(a · b) / (a · b)
         = (σ(a) / a) · (σ(b) / b)      [розклад множників]
         = I(a) · I(b)                  [мультиплікативність індексу]
```

Використовуючи канонічний розклад натурального числа `n` на прості множники відповідно до Основної теореми арифметики:

```
n = p₁ᵃ¹ · p₂ᵃ² · ... · pₖᵃᵏ      [канонічний розклад n]
```

ми отримуємо явну формулу для обчислення індексу надлишковості `I(n)`:

```
I(n) = ∏_{i=1}^k (1 + 1/pᵢ + 1/pᵢ² + ... + 1/pᵢᵃⁱ)      [сума геометричної прогресії для кожного простого]
```

Згортаючи кожну суму геометричної прогресії за формулою `(pᵢᵃⁱ⁺¹ - 1) / (pᵢ - 1)`, отримуємо компактний добуток:

```
I(n) = ∏_{i=1}^k (pᵢᵃⁱ⁺¹ - 1) / (pᵢᵃⁱ · (pᵢ - 1))      [точна формула індексу надлишковості]
```

З цієї формули негайно випливає важлива верхня оцінка для індексу `I(n)`. Оскільки для кожного простого множника `pᵢ` сума нескінченно спадної геометричної прогресії дорівнює `1 / (1 - 1/pᵢ) = pᵢ / (pᵢ - 1)`, маємо сувору нерівність:

```
I(n) < ∏_{p | n} p / (p - 1)      [верхня межа індексу через прості дільники]
```

Ця нерівність показує, що індекс надлишковості числа `n` обмежений зверху величиною, яка залежить виключно від того, які саме прості числа входять до розкладу `n`, але не залежить від їхніх степенів `aᵢ`.

Розглянемо спеціальний клас чисел — **прайморіали** (числа вигляду `p_k# = p₁ · p₂ · ... · pₖ`, які є добутком перших `k` простих чисел). Оскільки прайморіали містять найменші можливі прості множники, вони забезпечують максимально швидкий ріст індексу `I(n)` відносно кількості множників. Обчислимо індекси `I(n)` для перших кількох прайморіалів:
- `I(2#) = I(2) = 1.5`
- `I(3#) = I(6) = 2.0` (найменше досконале число)
- `I(5#) = I(30) = (3/2) · (4/3) · (6/5) = 2.4 > 2` (надлишкове)
- `I(7#) = I(210) = 2.4 · (8/7) = 19.2 / 7 ≈ 2.7428`
- `I(11#) = I(2310) = 2.7428 · (12/11) ≈ 2.992`

Цікавим арифметичним інваріантом є дуальний зв'язок між сигма-функцією `σ(n)` та функцією Ейлера `φ(n)`. Для будь-якого натурального числа `n > 1` виконується сувора дуальна нерівність:

```
(σ(n) / n) · (φ(n) / n) < 1      [дуальна нерівність Ейлера-сигма]
```

Це означає, що високі значення індексу надлишковості `I(n)` автоматично тягнуть за собою низькі значення відносного тотієнта `φ(n) / n`. Оскільки надлишкові числа мають багату множину дільників, більшість чисел, менших за `n`, мають спільні дільники з `n`, через що кількість взаємно простих чисел `φ(n)` є відносно малою.

У 1913 році німецький математик Томас Грюнваль (Ґронволл) встановив точну асимптотичну верхню межу зростання індексу `I(n)` для великих чисел:

```
limsup_{n → ∞} I(n) / (e^γ · log(log(n))) = 1      [теорема Ґронволла]
```

де `γ ≈ 0.577215` — стала Ейлера–Маскероні. Ця теорема доводить, що хоча індекс надлишковості може зростати як завгодно високо, швидкість його зростання обмежена подвійним логарифмом `log(log(n))`.

### Теорема про монотонність (спадковість) надлишковості

Фундаментальною властивістю індексу надлишковості є його строга монотонність відносно кратності.

**Теорема.** Якщо натуральне число `n` є надлишковим або досконалим (`I(n) ≥ 2`), то будь-яке число `m = k · n`, яке є кратним `n` при `k > 1`, є **строго надлишковим** (`I(k · n) > 2`).

*Доведення.* Розглянемо суму дільників числа `m = k · n`. Оскільки кожен дільник `d` числа `n` при множенні на `k` дає дільник `k · d` числа `m`, множина дільників `m` містить принаймні всі елементи вигляду `k · d` для кожного `d | n`. Крім того, якщо `k > 1`, число `m` має додаткові дільники, які не належать цій множині (наприклад, дільник `1`, оскільки `1` не ділиться на `k`). 

Отже, для суми дільників маємо строгу нерівність:

```
σ(k · n) > k · σ(n)      [строга нерівність для суми дільників кратного]
```

Поділивши обидві частини нерівності на `k · n`, отримуємо:

```
σ(k · n) / (k · n) > k · σ(n) / (k · n)      [ділення на k·n]
I(k · n) > I(n)                              [спадковість індексу надлишковості]
```

Якщо `I(n) ≥ 2`, то `I(k · n) > 2`, що й доводить надлишковість числа `k · n`. Q.E.D.

З цієї теореми випливають два фундаментальні арифметичні наслідки:

1. **Контрапозиція для недостатності:** Якщо число `n` є недостатнім (`I(n) < 2`), то кожен його власний дільник `d | n` також обов'язково є **недостатнім**. Якби якийсь дільник `d` був надлишковим або досконалим, то за теоремою про монотонність саме число `n` (як кратне `d`) було б строго надлишковим, що суперечить умові.
2. **Існування первинних надлишкових чисел:** Оскільки кратне будь-якого надлишкового числа є надлишковим, природно виділити мінімальні «генератори» надлишковості. Число `n` називається **первинним (або примітивним) надлишковим числом**, якщо воно є надлишковим, але кожен його власний дільник є недостатнім.

Першими первинними надлишковими числами є `12, 18, 20, 30, 42, 56, 70, 78, 88, 102, 104, 114, 126, 138, 150, 945`. Будь-яке інше надлишкове число є кратним принаймні одного з первинних надлишкових чисел. Множина всіх первинних надлишкових чисел є нескінченною, що довів Пал Ердеш у 1934 році.

### Недостатність простих чисел, їхніх степенів та криптографічних модулів RSA

Застосуємо формулу індексу `I(n)` до простих чисел, їхніх степенів та напівпростих чисел.

Для будь-якого простого числа `p` його єдиними дільниками є `{1, p}`. Тому:

```
s(p) = 1 < p              [сума власних дільників простого числа]
I(p) = (p + 1) / p = 1 + 1/p ≤ 1.5 < 2      [індекс надлишковості простого числа]
```

Таким чином, **усі прості числа є недостатніми**.

Розглянемо степені простих чисел `n = pᵏ` для `k ≥ 1`. Дільниками `pᵏ` є `{1, p, p², ..., pᵏ}`. Сума власних дільників обчислюється як:

```
s(pᵏ) = 1 + p + p² + ... + pᵏ⁻¹ = (pᵏ - 1) / (p - 1)      [сума геометричної прогресії]
```

Порівняємо `s(pᵏ)` із `pᵏ`:

```
s(pᵏ) = (pᵏ - 1) / (p - 1) ≤ (pᵏ - 1) / 1 = pᵏ - 1 < pᵏ      [оцінка суми дільників степеня простого]
```

Звідси випливає, що `s(pᵏ) < pᵏ` для всіх простих `p` та всіх натуральних показників `k ≥ 1`. Отже, **усі степені простих чисел є недостатніми**.

Розглянемо **напівпрості числа** (semiprimes) вигляду `N = p · q`, де `p` та `q` — різні прості числа (типова структура публічного ключа в криптосистемі RSA).
Оскільки `p` та `q` є взаємно простими, використаємо мультиплікативність індексу надлишковості:

```
I(N) = I(p) · I(q) = (1 + 1/p) · (1 + 1/q) = 1 + 1/p + 1/q + 1/(p · q)      [індекс надлишковості напівпростого числа]
```

Оскільки для найменших непарних простих чисел `p = 3, q = 5` отримаємо `I(15) = (4/3) · (6/5) = 24 / 15 = 1.6 < 2`, а для парного випадку `p = 2, q = 3` отримаємо `I(6) = (3/2) · (4/3) = 2.0` (досконале число), для всіх непарних напівпростих чисел `N = p · q` маємо:

```
I(N) ≤ (4 / 3) · (6 / 5) = 1.6 < 2      [сувора дефіцитність непарних криптомодулів RSA]
```

Таким чином, **усі непарні криптографічні модулі RSA є строго недостатніми числами**, причому їхній індекс надлишковості дуже близький до `1.0` для великих криптографічних простих чисел `p` та `q`.

### Теорема Евкліда–Ейлера про досконалі та надлишкові числа

Вивчення парних досконалих чисел дає ключ до розуміння граничного випадку між недостатніми та надлишковими числами.

**Теорема Евкліда–Ейлера.** Парне число `n` є досконалим тоді й лише тоді, коли воно має вигляд:

```
n = 2ᵖ⁻¹ · (2ᵖ - 1)      [формула парних досконалих чисел]
```

де `2ᵖ - 1` є простим числом (простим числом Мерсенна `M_p`).

*Доведення (Пряме — Евклід).* Нехай `M_p = 2ᵖ - 1` є простим числом. Розглянемо число `n = 2ᵖ⁻¹ · M_p`. Оскільки `2ᵖ⁻¹` та `M_p` є взаємно простими, використаємо мультиплікативність сигма-функції:

```
σ(n) = σ(2ᵖ⁻¹) · σ(M_p)                      [мультиплікативність]
     = (2ᵖ - 1) · (M_p + 1)                 [сигма для степеня двійки та простого M_p]
     = (2ᵖ - 1) · (2ᵖ - 1 + 1) = (2ᵖ - 1) · 2ᵖ  [підстановка M_p = 2^p - 1]
     = 2 · (2ᵖ⁻¹ · (2ᵖ - 1)) = 2 · n        [отримання 2·n]
```

Отже, `σ(n) = 2 · n`, що доводить досконалість числа `n`. Q.E.D.

*Доведення (Обернене — Ейлер).* Нехай парне число `n` є досконалим (`σ(n) = 2 · n`). Запишемо `n` у вигляді `n = 2ᵏ⁻¹ · q`, де `k ≥ 2`, а `q` — непарне число.
Оскільки `gcd(2ᵏ⁻¹, q) = 1`, застосуємо мультиплікативність:

```
σ(n) = σ(2ᵏ⁻¹) · σ(q) = (2ᵏ - 1) · σ(q)      [вираження сигма-функції через складові]
```

Оскільки `n` є досконалим, маємо тотожність:

```
(2ᵏ - 1) · σ(q) = 2ᵏ · q      [рівняння досконалості]
```

Звідси випливає, що `2ᵏ - 1` ділить `2ᵏ · q`. Оскільки `2ᵏ - 1` та `2ᵏ` є взаємно простими (`gcd(2ᵏ - 1, 2ᵏ) = 1`), то `2ᵏ - 1` мусить ділити `q`. Тобто існує таке ціле число `c`, що `q = c · (2ᵏ - 1)`.
Підставляючи це у рівняння досконалості:

```
(2ᵏ - 1) · σ(q) = 2ᵏ · c · (2ᵏ - 1)      [підстановка q]
σ(q) = 2ᵏ · c                            [скорочення на (2^k - 1)]
```

Розглянемо дільники числа `q`. Число `q` має принаймні два дільники: `c` та сам `q = c · (2ᵏ - 1)`. Сума цих двох дільників дорівнює:

```
q + c = c · (2ᵏ - 1) + c = c · 2ᵏ = σ(q)      [сума двох відомих дільників q]
```

Якщо `q` мало б додаткові дільники, то сума `σ(q)` була б строго більшою за `q + c`. Але оскільки `σ(q)` точно дорівнює `q + c`, число `q` не має жодних інших дільників! Це означає, що `c` мусить дорівнювати `1`, а число `q = 2ᵏ - 1` є простим числом. Позначаючи `k = p`, отримуємо `n = 2ᵖ⁻¹ · (2ᵖ - 1)`, де `2ᵖ - 1` — просте число Мерсенна. Q.E.D.

Якщо ж у цій формулі замість простого числа Мерсенна взяті більші степені двійки або додаткові прості множники, отримані числа негайно стають **надлишковими**. Наприклад:
- Для `p = 2`: `M₂ = 3` (просте). `n = 2¹ · 3 = 6` (досконале). Якщо помножити `6` на `2`, отримаємо `12` — надлишкове число.
- Для `p = 3`: `M₃ = 7` (просте). `n = 2² · 7 = 28` (досконале). Якщо помножити `28` на `2`, отримаємо `56` — надлишкове число.

## 3. Геометричний розподіл, щільність та парність

Вивчення розподілу надлишкових та недостатніх чисел у натуральному ряді розкриває глибоку асиметрію між цими двома класами.

### Непарні надлишкові числа та їх структура

Оскільки `12 = 2² · 3` є найменшим надлишковим числом, виникає питання: чи існують непарні надлишкові числа?

З аналізу випливає, що непарне число не може бути надлишковим, якщо воно має лише один або два різні прості множники.
Справді, якщо `n = pᵃ · qᵇ`, де `p` та `q` — непарні прості числа (причому `p ≥ 3`, `q ≥ 5`), то верхня межа індексу надлишковості становить:

```
I(n) < (p / (p - 1)) · (q / (q - 1))      [верхня оцінка індексу для двох простих дільників]
I(n) ≤ (3 / 2) · (5 / 4) = 15 / 8 = 1.875 < 2      [максимальне значення для двох непарних дільників]
```

Отже, будь-яке непарне число з одним або двома простими дільниками є обов'язково недостатнім. Щоб непарне число могло стати надлишковим, воно повинно мати принаймні **три різні прості дільники**, причому найменшими можливими простими множниками є `3`, `5` та `7`.

Обчислимо граничне значення добутку для перших трьох непарних простих чисел:

```
(3 / 2) · (5 / 4) · (7 / 6) = 105 / 48 = 35 / 16 = 2.1875 > 2      [поріг трьох непарних простих]
```

Оскільки `2.1875 > 2`, при достатньо великих степенях чисел `3`, `5` та `7` непарне число може подолати поріг надлишковості `2`.

Найменшим непарним надлишковим числом є **`945`**. Його канонічний розклад дорівнює `945 = 3³ · 5 · 7`. Обчислимо його індекс надлишковості точечно:

```
I(945) = I(3³) · I(5) · I(7)                  [мультиплікативність]
       = ((3⁴ - 1) / (3³ · 2)) · (6 / 5) · (8 / 7)
       = (80 / 54) · (6 / 5) · (8 / 7)         [обчислення факторів]
       = (40 / 27) · (6 / 5) · (8 / 7)
       = 1920 / 945 = 128 / 63 ≈ 2.0317 > 2    [перевищення порогу 2]
```

Числовий надлишок для `945` становить `a(945) = 975 - 945 = 30`.

Розглянемо випадок непарних надлишкових чисел, які **не діляться на 3**. Скільки простих дільників повинно мати таке число?
Якщо `3 ∤ n`, то найменшими можливими непарними простими множниками є `5, 7, 11, 13, 17, 19, 23`.
Обчислимо верхню межу індексу `I(n)` для непарного числа з 5 простими дільниками, що не діляться на 3:

```
I_max = (5 / 4) · (7 / 6) · (11 / 10) · (13 / 12) · (17 / 16)
      = (5 · 7 · 11 · 13 · 17) / (4 · 6 · 10 · 12 · 16)
      = 85085 / 46080 ≈ 1.8464 < 2      [п'яти непарних простих без 3 недостатньо]
```

Додамо шостий просто множник `19`:

```
I_max_6 = 1.8464 · (19 / 18) = 1.8464 · 1.05556 ≈ 1.949 < 2      [шести непарних простих без 3 недостатньо]
```

Додамо сьомий просто множник `23`:

```
I_max_7 = 1.949 · (23 / 22) = 1.949 · 1.04545 ≈ 2.037 > 2      [сім непарних простих без 3 долають поріг 2]
```

Отже, **будь-яке непарне надлишкове число, не кратне 3, повинно мати принаймні 7 різних простих множників!** Це пояснює, чому такі числа є надзвичайно рідкісними в натуральному ряді (найменше таке число перевищує 10¹4).

### Асимптотична щільність надлишкових чисел

Позначимо через `A(x)` кількість надлишкових чисел, що не перевищують `x`:

```
A(x) = |{n ∈ N : n ≤ x, I(n) > 2}|      [лічильник надлишкових чисел]
```

Поняття **асимптотичної щільності** `D_A` визначається як границя відношення `A(x) / x` при `x → ∞`:

```
D_A = lim_{x → ∞} A(x) / x      [асимптотична щільність]
```

Довгий час залишалося відкритим питання про те, чи існує ця границя взагалі. У 1933 році польський математик Юзеф Марцинкевич та британський математик Гарольд Давенпорт довели фундаментальну теорему:

**Теорема Марцинкевича–Давенпорта.** Асимптотична щільність надлишкових чисел `D_A` існує і є строго додатною величиною. Неперервна функція розподілу `F(t) = lim_{x → ∞} (1/x) · |{n ≤ x : I(n) ≤ t}|` є строго монотонною на проміжку `[1, ∞)`.

Сучасні високоточні чисельні та аналітичні обчислення (зокрема роботи Марка Делегліза, 1998) дають наступні суворі межі для щільності надлишкових чисел:

```
0.2474 < D_A < 0.2480      [чисельні межі щільності Давенпорта]
```

Це означає, що приблизно **24.76%** усіх натуральних чисел є надлишковими, близько **75.24%** є недостатніми, а досконалі числа мають асимптотичну щільність точно **`0`** (оскільки їх вкрай мало).

Строге математичне виведення теореми Давенпорта через функцію розподілу індексу дільників та метод моментів наведено у вставці [🧮 Аналітичне доведення існування та меж асимптотичної щільності надлишкових чисел](book:math/number-theory/abundant-deficient-numbers/math-density-proof.md).

### Сума двох надлишкових чисел

У 1930-х роках математик Рене Давенпорт та Пал Ердеш досліджували питання про те, які числа можна подати у вигляді суми двох надлишкових чисел.

У 1974 році було остаточно доведено, що кожне ціле число, більше за **`20161`**, може бути записано як сума двох надлишкових чисел. Число `20161` є найбільшим цілим числом, яке неможливо подати у вигляді суми двох надлишкових чисел.

## 4. Таксономія надлишкових чисел: напівдосконалі, дивні та інші класи

Надлишкові числа не є однорідним класом. Внутрішня структура їхніх дільників дозволяє розділити їх на кілька специфічних підкатегорій, як показано на діаграмі нижче.

![Класифікація натуральних чисел за індексом надлишковості](/book/math/number-theory/abundant-deficient-numbers/img/fig-number-classification.svg)
*Діаграма ієрархічної класифікації натуральних чисел за значенням індексу надлишковості I(n) та внутрішньою структурою власних дільників.*

### Напівдосконалі та дивні числа

Оскільки для надлишкового числа `n` сума всіх його власних дільників `s(n)` строго більша за `n`, виникає природне питання: чи можна вибрати **підмножину** власних дільників, сума елементів якої точно дорівнює `n`?

1. **Напівдосконалі числа** (semiperfect numbers, або pseudoperfect numbers) — це надлишкові числа, які дорівнюють сумі деяких (або всіх) своїх власних дільників.
   *Приклад:* Число `12` є надлишковим (`s(12) = 16`). Власні дільники `12` — це `{1, 2, 3, 4, 6}`. Ми можемо вибрати підмножину `{2, 4, 6}`, сума якої дорівнює `2 + 4 + 6 = 12`. Отже, `12` є напівдосконалим числом. Переважна більшість відомих надлишкових чисел є напівдосконалими.

2. **Дивні числа** (weird numbers) — це надлишкові числа, які **не є напівдосконалими**. Тобто це числа, для яких `s(n) > n`, але **жодна** підмножина власних дільників у сумі не дає точно `n`.

Найменшим дивним числом є **`70`**.
Перевіримо його властивості:
- Власні дільники `70`: `{1, 2, 5, 7, 10, 14, 35}`.
- Сума всіх власних дільників: `s(70) = 1 + 2 + 5 + 7 + 10 + 14 + 35 = 74`.
- Оскільки `74 > 70`, число `70` є надлишковим.
- Якщо ми переберемо всі можливі 127 підмножин власних дільників `70`, жодна з них не дасть у сумі точно `70`.

Другим дивним числом є **`836`**.
Канонічний розклад `836` дорівнює `2² · 11 · 19`.
Його власними дільниками є `{1, 2, 4, 11, 19, 22, 44, 76, 209, 418}`.
Сума власних дільників `s(836) = 985 > 836`. Аналіз підмножин показує, що жодна комбінація не дає в сумі точно `836`.

Наступними дивними числами є `4030`, `5830`, `7192`, `7912`. Дивні числа зустрічаються вкрай рідко, і чи існують непарні дивні числа — одна з відкритих проблем сучасної теорії чисел.

У 1977 році Бенакоцер і Крамер довели, що якщо `n` є дивним числом, а `p` — простим числом, більшим за `σ(n)`, то `p · n` також є дивним числом. З цього випливає, що множина дивних чисел є нескінченною.

### Гіпердосконалі числа як узагальнення

Узагальненням поняття досконалості та напівдосконалості є `k`-гіпердосконалі числа (k-hyperperfect numbers).
Число `n` називається **`k`-гіпердоскональним**, якщо воно задовольняє рівність:

```
n = 1 + k · (s(n) - 1)      [рівняння k-гіпердосконалості]
```

або у термінах сигма-функції: `k · σ(n) = (k + 1) · n + (k - 1)`.
Якщо `k = 1`, це рівняння набуває вигляду `n = 1 + 1 · (s(n) - 1) ⇒ n = s(n)`, що відповідає класичним досконалим числам.
Для `k = 2` першим 2-гіпердосконалим числом є `21`: `s(21) = 1 + 3 + 7 = 11`, а `1 + 2 · (11 - 1) = 21`.

### Високонадлишкові та сверхнадлишкові числа

Поняття надлишковості можна узагальнити шляхом порівняння зростання сигма-функції відносно величини самого числа:

- **Високонадлишкове число** (highly abundant number) — це натуральне число `n`, для якого сума дільників `σ(n)` строго більша, ніж для будь-якого меншого натурального числа:
  `σ(n) > σ(m)` для всіх `m < n`.
  Першими високонадлишковими числами є `1, 2, 3, 4, 6, 12, 24, 36, 48, 60, 120`.

- **Сверхнадлишкове число** (superabundant number) — це натуральне число `n`, для якого індекс надлишковості `I(n)` строго більший, ніж для будь-якого меншого натурального числа:
  `I(n) > I(m)` для всіх `m < n`.
  Першими сверхнадлишковими числами є `1, 2, 4, 6, 12, 24, 36, 48, 60, 120, 180, 240, 360, 720`.

Сверхнадлишкові числа мають глибокий зв'язок із гіпотезою Рімана. У 1984 році Гай Робін довів, що гіпотеза Рімана еквівалентна твердженню, що нерівність `I(n) < e^γ · log(log(n))` виконується для всіх `n > 5040`, де `γ ≈ 0.57721` — стала Ейлера–Маскероні. Сверхнадлишкові числа виступають як критичні тестові точки для перевірки нерівності Робіна, оскільки саме на них індекс надлишковості `I(n)` досягає своїх локальних максимумів відносно величини `n`.

### Трохи надлишкові числа (Квазідосконалі числа)

У теорії чисел існує знаменита гіпотеза про існування чисел з екстремально малим надлишком:

- **Майже досконале число** (almost perfect number) — число, для якого `s(n) = n - 1` (дефіцит дорівнює 1). Усі відомі майже досконалі числа є степенями двійки: `2⁰, 2¹, 2², 2³, ...` (наприклад, `s(16) = 1 + 2 + 4 + 8 = 15 = 16 - 1`).
- **Трохи надлишкове число** (slightly abundant number, або квазідосконале число) — число, для якого `s(n) = n + 1` (надлишок дорівнює точно 1).

На сьогодні **не відомо жодного трохи надлишкового числа**. У 1951 році Паоло Каттанео довів, що парних квазідосконалих чисел не існує. Якщо квазідосконале число `n` існує, то `σ(n) = 2 · n + 1` має бути непарним числом. Оскільки сигма-функція `σ(n)` є непарною тоді й лише тоді, коли `n` є точним квадратом або подвоєним точним квадратом, а парний випадок виключено, квазідосконале число `n` обов'язково повинно бути непарним точним квадратом, що перевищує `10³⁵`, і мати принаймні 7 різних простих множників.

## 5. Динаміка аліквотних послідовностей та відкриті проблеми

Поняття суми власних дільників `s(n)` дозволяє побудувати динамічну систему на множині натуральних чисел.

### Означення аліквотної послідовності

Для будь-якого початкового натурального числа `a₀ = n` **аліквотна послідовність** (aliquot sequence) задається рекурентним співвідношенням:

```
aₖ₊₁ = s(aₖ) = σ(aₖ) - aₖ      [рекурентне правило аліквотної послідовності]
```

Вивчення траєкторій цієї динамічної системи демонструє чотири типи поведінки:

1. **Фінітна збіжність до нуля:** Послідовність потрапляє в просте число `p`, для якого `s(p) = 1`, а на наступному кроці `s(1) = 0`, де система зупиняється.
   *Приклад для n = 12:* `12 → 16 → 15 → 9 → 4 → 3 → 1 → 0`.
2. **Нерухомі точки (неперіодичні стаціонарні стани):** Послідовність потрапляє в досконале число `P`, для якого `s(P) = P`. Послідовність стає постійною: `P → P → P → ...`.
   *Приклад для n = 6:* `6 → 6 → 6 → ...`.
3. **Періодичні цикли довжини 2 (Дружні числа):** Послідовність потрапляє в пару чисел `(a, b)`, де `s(a) = b` та `s(b) = a`.
   *Приклад для n = 220:* `220 → 284 → 220 → 284 → ...`. Найменшою такою парою є числа `220` та `284`.
4. **Періодичні цикли довжини k ≥ 3 (Соціологічні числа):** Послідовність утворює замкнений цикл із `k` елементів. Наприклад, п'ятикроковий цикл підходить для числа `1264460`:
   `1264460 → 1547860 → 1727636 → 1305184 → 1264460`. Найдовший з відомих соціологічних циклів має довжину `28` і починається з числа `14316`.

На малюнку нижче зображено граф переходів аліквотних послідовностей для малих чисел.

![Дерево аліквотних послідовностей та їхні динамічні траєкторії](/book/math/number-theory/abundant-deficient-numbers/img/fig-aliquot-tree.svg)
*Граф переходів аліквотних послідовностей для невеликих чисел, що демонструє збіжність до нуля, фіксовані точки (досконалі числа) та класичні цикли (дружні числа).*

З точки зору теорії графів, відображення `s: N → N` задає нескінченний орієнтований граф, у якому кожна вершина `u` має рівно одну вихідну дугу `(u, s(u))`. При цьому кількість вхідних дуг може бути довільною: існують числа, що не мають жодного «предка» в аліквотному графі. Подібні натуральні числа називаються **неаліквотними числами** (untouchable numbers, або незображуваними числами).
Першими неаліквотними числами є `2, 5, 52, 88, 96, 120, 124, 146, 162, 188, 206, 210`.

Доведемо, що число `5` є неаліквотним. Якби існувало число `m`, для якого `s(m) = 5`, то `σ(m) = m + 5`.
- Якщо `m` — просте `p`, то `s(p) = 1 ≠ 5`.
- Якщо `m = p²` (квадрат простого), то `s(p²) = p + 1 = 5 ⇒ p = 4`, що суперечить простоті `p`.
- Якщо `m = p · q` (добуток двох простих), то `s(p · q) = p + q + 1 = 5 ⇒ p + q = 4`. Єдиною можливістю є `p = 2, q = 2`, звідки `m = 4`, але `s(4) = 1 + 2 = 3 ≠ 5`.
- Якщо `m` має 3 чи більше простих множників або вищі степені, сума власних дільників `s(m)` строго перевищує `5`.
Отже, не існує жодного цілого числа `m`, для якого `s(m) = 5`, що й доводить неаліквотність числа `5`. Q.E.D.

### Гіпотеза Каталана–Диксона проти гіпотези Гая–Селфріджа

Головне відкрите питання щодо аліквотних послідовностей полягає у тому, чи існує початкове число `n`, аліквотна послідовність якого є **необмеженою** (прямує до нескінченності).

- **Гіпотеза Каталана–Диксона (1888, 1913):** Будь-яка аліквотна послідовність є обмеженою і зрештою закінчується нулем або потрапляє в періодичний цикл (досконале, дружнє або соціологічне число).
- **Гіпотеза Гая–Селфріджа (1975):** Існують початкові числа, аліквотні послідовності яких зростають до нескінченності.

Найменшим початковим числом, для якого доля аліквотної послідовності залишається невідомою, є **`276`**.
Станом на 2026 рік аліквотну послідовність для `276` було обчислено на сотні кроків (де значення досягають чисел з понад 45 десятковими знаками), але вона досі не зупинилася і не потрапила в жоден відомий цикл. Іншими подібними «невирішеними» початковими числами (так званими Lehmer-п'ятіркою) є `564`, `660`, `816` та `1074`.

## 6. Обчислювальна складність та практичний аналіз

Аналіз надлишковості цілих чисел є важливим інструментом при розробці чисельних алгоритмів теорії чисел.

### Алгоритмічні підходи

1. **Точечна перевірка числа n:**
   Пряме обчислення суми дільників `σ(n)` шляхом перебору потенційних дільників до `√n` має часову складність `O(√n)` і просторову складність `O(1)`. Оптимізований алгоритм спочатку знаходить канонічний розклад `n` на прості множники, а потім обчислює `σ(n)` за формулою добутку геометричних прогресій.

2. **Діапазонна класифікація для всіх чисел до N:**
   Для обчислення `σ(n)` для всіх чисел `1 ≤ n ≤ N` застосування точечного алгоритму вимагало б `O(N · √N)` операцій. Використання модифікованого Решета Ератосфена дозволяє накопичувати суму дільників для всього діапазону за час `O(N · log(log(N)))` або `O(N · log(N))` при простій реалізації.
   Застосування **лінійного решета** (Linear Sieve) дозволяє обчислити `σ(n)` для всього діапазону `1..N` за строго лінійний час `O(N)` і просторову складність `O(N)`. Під час виконання решета для кожного числа `n` зберігається його найменший простий множник `lp[n]` та сума геометричної прогресії `σ(pᵃ)` для найбільшого степеня `pᵃ`, що ділить `n`. Завдяки мультиплікативності `σ(n)` обчислюється за один перехід без ділення.

3. **Розпізнавання дивних чисел (проблема Subset Sum):**
   Перевірка того, чи є надлишкове число `n` дивним, вимагає розв'язання задачі про суму підмножини (Subset Sum Problem) для множини його власних дільників. Алгоритм динамічного програмування створює булевий масив `DP` розміру `n + 1`, де `DP[w]` показує, чи можна сформувати суму `w` з доступних власних дільників `d₁ < d₂ < ... < dₘ`.
   Часова складність становить `O(m · n)`, а просторова — `O(n)`. Якщо `DP[n]` залишається `false` після обробки всіх дільників, а `s(n) > n`, число `n` класифікується як дивне.

Зведемо аналіз обчислювальної складності ключових задач теорії надлишковості в підсумкову таблицю:

| Задача | Алгоритм | Часова складність | Просторова складність | Характер складності |
|---|---|---|---|---|
| Перевірка надлишковості `n` | Факторизація `√n` | `O(√n)` | `O(1)` | P (Поліноміальна від `n`) |
| Сума дільників на `1..N` | Модифіковане решето | `O(N log log N)` | `O(N)` | Майже лінійна |
| Сума дільників на `1..N` | Лінійне решето | `O(N)` | `O(N)` | Строго лінійна |
| Розпізнавання дивних чисел | Динамічне програмування | `O(m · n)` | `O(n)` | Псевдополіноміальна |
| Генерація аліквотного графа | Покроковий перебір | `O(K · √A_max)` | `O(K)` | Обмежена довжиною `K` |
