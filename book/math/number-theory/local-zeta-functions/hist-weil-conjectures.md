# 📜 Гіпотези Вейля та народження локальних дзета-функцій

Історія виникнення локальних Дзета-функцій відображає один із найвеличніших проривів у математиці XX століття — синтез класичної теорії чисел, алгебраїчної топології та алгебраїчної геометрії. Ідея перенесення аналітичних методів Бернгарда Рімана та Леонарда Ейлера на діофантові рівняння над скінченними полями пройшла шлях від спостережень над квадратними лишками до геометричної теорії когомологій Гротендіка.

## 1. Спроби Еміля Артіна та аналогія з числовими полями (1924)

У 1924 році молодий австрійсько-американський математик Еміль Артін у своїй докторській дисертації запропонував аналог дзета-функції для функціональних полів алгебраїчних кривих над скінченними полями. Артін прагнув побудувати арифметику для полів раціональних функцій `𝔽_q(x)` та їхніх скінченних розширень за аналогією з полем раціональних чисел `ℚ` та полем алгебраїчних чисел.

Артін помітив, що якщо розглядати скінченне поле `𝔽_q` і плоску криву, задану рівнянням над `𝔽_q`, то кількості рішень рівняння в розширеннях `𝔽_qⁿ` поводяться подібним чином до розподілу простих чисел у теорії числових полів. Він формально визначил твірну функцію через добуток по простих ідеалах кільця функцій кривої (Ейлерів добуток):

```
Z(t) = ∏_{p} 1 / (1 - t^{deg(p)})
```

Артін висловив гіпотезу, що ця функція завжди є раціональним дробом від `t = q⁻ˢ` і задовольняє функціональне рівняння, аналогічне дзета-функції Рімана. Більше того, для понад сорока конкретних квадратичних кривих малого роду Артін вручну обчислив нулі чисельника і виявив, що всі вони лежать на критичній прямій `Re(s) = 1/2` (або на колі радіуса `|t| = q⁻¹/²`). Це було першим формулюванням Гіпотези Рімана для кривих над скінченними полями.

Проте інструментарій 1920-х років не дозволяв довести цю гіпотезу навіть для еліптичних кривих (роду `g = 1`). Артін не мав у своєму розпорядженні апарату алгебраїчної геометрії, алгебраїчних точок та геометрії дивізорів.

## 2. Прорив Гельмута Хассе для еліптичних кривих (1933–1936)

Упродовж 1933–1936 років німецький математик Гельмут Хассе здійснив вирішальний крок вперед, довівши аналог Гіпотези Рімана для всіх еліптичних кривих над скінченними полями (`g = 1`).

Хассе усвідомив, що кількість точок `N₁` на еліптичній кривій `E/𝔽_q` тісно пов'язана з ендоморфізмом Фробеніуса:

```
Frob_q: (x, y) ↦ (x^q, y^q)
```

Точки кривої над `𝔽_q` — це саме ті точки, які лишаються нерухомими під дією Фробеніуса, тобто лежать у ядрі ендоморфізму `1 - Frob_q`. Хассе використав алгебраїчну теорію комплексного множення, інволюцію Розі та квадратичні форми на кільці ендоморфізмів `End(E)`.

У листуванні з Луїсом Морделлом та Харольдом Девенпортом Хассе детально описував побудову інваріантної метрики на кільці ендоморфізмів. Центральним елементом доведення Хассе була позитивна визначеність степеня ендоморфізма (позитивність норми Вейля): для будь-якого ненульового ендоморфізма `ψ ∈ End(E)` його ступінь є строго додатним цілим числом `deg(ψ) > 0`.

З цього випливало нелінійне квадратичне обмеження на слід ендоморфізму Фробеніуса `a = q + 1 - N₁`:

```
|a| ≤ 2 · √q
```

Це обмеження отримало назву **оцінки Хассе**. Воно гарантувало, що нулі квадратного тричлена `P(t) = 1 - a·t + q·t²` є комплексно спряженими числами `α, ᾱ` з абсолютним значенням `|α| = √q`. Тим самим аналог Гіпотези Рімана для кривих роду 1 був повністю доведений.

## 3. Анрі Вейль: Руанська в'язниця та загальні гіпотези (1940–1948)

Під час Другої світової війни французький математик Андре Вейль (брат відомої філософки Сімони Вейль) опинився у в'язниці міста Руан через відмову від призову до військової служби у формі пацифістського протесту. Перебуваючи у камері військової тюрми на початку 1940 року, Вейль мав час для неперервних інтенсивних роздумів над математичною структурою Дзета-функцій.

У знаменитому листі з в'язниці до своєї сестри Сімони Вейль описував математичне натхнення як відчуття злиття різноманітних світів: моста між теорією чисел, де панують скінченні поля, та комплексною аналітичною топологією Ріманових поверхонь. Вейль зрозумів, що доведення Хассе для еліптичних кривих можна узагальнити на криві довільного роду `g ≥ 1`, якщо розробити строгу алгебраїчну геометрію над полями довільної характеристики без використання топології евклідового простору `ℂ`.

Після звільнення з ув'язнення Вейль у 1940–1948 роках опублікував серію фундаментальних праць, у яких:
1. Переписав основи алгебраїчної геометрії, ввівши поняття абстрактних многовидів та орієнтованих перетинів дивізорів у своїй книзі *"Foundations of Algebraic Geometry"* (1946).
2. Побудував багатовимірний многовид Якобі `J(C)` для кривої `C` роду `g` і довів позитивність геометричного спарювання на Якобіані.
3. Довів Гіпотезу Рімана для всіх гладких проективних кривих довільного роду `g`:

```
|N_n - (qⁿ + 1)| ≤ 2g · q^{n/2}
```

У 1949 році у своїй знаменитій статті *"Numbers of solutions of equations in finite fields"* у журналі Bulletin of the American Mathematical Society Вейль сформулював чотири грандіозні гіпотези для локальних дзета-функцій алгебраїчних многовидів довільної розмірності `n` над скінченними полями `𝔽_q`:

1. **Раціональність:** `Z(V/𝔽_q, t)` є раціональною функцією від `t`.
2. **Функціональне рівняння:** `Z(V, 1/(qⁿ·t)) = ± q^{e/2} · tᵉ · Z(V, t)`, де `e` — ейлерова характеристика.
3. **Топологічна інваріантність:** Ступені поліномів у чисельнику та знаменнику `Z(V, t)` визначаються числами Бетті `B_k` відповідного комплексного многовиду.
4. **Аналог Гіпотези Рімана:** Нулі та полюси `Z(V, t)` лежать на колах радіусів `q^{-k/2}` для цілих `k`.

Ці твердження отримали назву **Гіпотез Вейля** і стали основним дороговказом для розвитку всієї алгебраїчної геометрії другої половини XX століття.

## 4. Бернард Дворк та p-адичний аналіз (1960)

Тривалий час перша гіпотеза Вейля — раціональність дзета-функції — залишалася відкритою для многовидів розмірності `n ≥ 2`. Першим, хто довів раціональність `Z(V, t)` у загальному випадку, був американський математик Бернард Дворк у 1960 році.

Підхід Дворка здивував сучасників: він не використовував абстрактну топологію чи когомології, а застосував p-адичний аналіз та теорію p-адичних аналітичних функцій (аналіз на полі p-адичних чисел `ℚ_p`). Дворк виразив кількість точок через p-адичний характер `exp(π(x - x^p))` і застосував p-адичний аналог теореми Бореля про раціональність формальних степеневих рядів з цілими коефіцієнтами.

Доведення Дворка показало, що раціональність є наслідком p-адичної аналітичності. Проте методами p-адичного аналізу на той час не вдавалося довести функціональне рівняння та аналог Гіпотези Рімана.

## 5. Олександр Гротендік, ℓ-адичні когомології та П'єр Делінь (1965–1974)

Для повного вирішення гіпотез Вейля потрібен був фундаментально новий математичний апарат, здатен поєднати топологічні уявлення про простір із характеристикою `p`. Його створив видатний математик Олександр Гротендік разом зі своїми співробітниками у Західному інституті вищих наукових досліджень (IHES) поблизу Парижа.

Гротендік зрозумів, що класичні топологічні числа Бетті та формулу нерухомих точок Лефшеца можна перенести в алгебраїчну геометрію характеристики `p`, якщо відмовитися від класичної топології і побудувати **етальні когомології** (ет-когомології) з коефіцієнтами у полі ℓ-адичних чисел `ℚ_ℓ` (де `ℓ ≠ p`).

У рамках теорії етальних когоморій локальна дзета-функція багатовимірного многовиду виражається як альтернований добуток визначників оператора Фробеніуса:

```
Z(V/𝔽_q, t) = ∏_{i=0}^{2n} [ det(1 - t · Frob_q | Hⁱ_et(V_bar, ℚ_ℓ)) ]^{(-1)^{i+1}}
```

Ця формула автоматично доводила Раціональність, Функціональне рівняння та Топологічну інваріантність гіпотез Вейля для алгебраїчних многовидів довільної розмірності.

Останню і найважчу частину — аналог Гіпотези Рімана про оцінку власних значень Фробеніуса `|α_{i,j}| = q^{i/2}` — довів у 1974 році учень Гротендіка П'єр Делінь у знаменитій праці *"La conjecture de Weil. I"*. Делінь поєднав когомологічну теорію Гротендіка з оцінками сум Ранкіна–Сельберга та оптимізованою теорією модулярних форм. 

Доведення Деліня було сприйнято математичною спільнотою як справжній тріумф етальних когомологій та теорії мотиваційних модулярних форм. Воно продемонструвало, що найглибші арифметичні властивості розв'язків діофантових рівнянь над скінченними полями визначаються геометричною топологією відповідних комплексних многовидів та їхніх автоморфізмів Фробеніуса.

Як знаменитий побічний результат доведення Гіпотез Вейля, Делінь розв'язав давню Гіпотезу Рамануджана (1916) про коефіцієнти модулярної параболічної форми Рамануджана `τ(n)` ваги 12. Делінь довів, що `|τ(p)| ≤ 2 · p^{11/2}` для будь-якого простого `p`. За це видатне досягнення Делінь був нагороджений Філдсівською премією 1978 року та премією Абеля 2013 року.

Хронологія ключових відкриттів у розвитку локальних дзета-функцій:

## 6. Асимптотичний розподіл фазових кутів: Гіпотеза Сато–Тейта

Доведення Гіпотези Вейля для еліптичних кривих відкрило шлях до дослідження статистичного розподілу власних чисел Фробеніуса `α_p, ᾱ_p = √p · e^{± i θ_p}` при варіюванні простого числа `p`.

Оскільки `|α_p| = √p`, слід Фробеніуса виражається через кут `θ_p ∈ [0, π]`:

```
a_p = p + 1 - N₁(E/𝔽_p) = 2 · √p · cos(θ_p)
```

У 1960-х роках Мікіо Сато та Джон Тейт незалежно висловили гіпотезу, що для еліптичної кривої `E/ℚ` без комплексного множення кути `θ_p` розподілені на відрізку `[0, π]` не рівномірно, а за законом міри Сато–Тейта з щільністю `(2/π) · sin²(θ) dθ`:

```
P(a ≤ θ_p ≤ b) = (2 / π) · ∫_a^b sin²(θ) dθ
```

Цю фундаментальну арифметико-геометричну гіпотезу було повністю доведено у 2006–2011 роках завдяки працям Річарда Тейлора, Лорана Клозеля, Майкла Гарріса та Ніколаса Шеперда-Баррона через побудову симетричних степенів автоморфних узагальнених L-функцій.

Розвиток теорії локальних дзета-функцій трансформував чисту числову арифметику на сучасну арифметичну геометрію, яка нині лежить в основі еліптичної криптографії, ізогенних протоколів та zero-knowledge доведень (zk-SNARKs у протоколах Zcash та Ethereum).
