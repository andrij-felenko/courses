# 🧮 Доведення інваріантів розширеного алгоритму Евкліда

Математичне доведення того, чому розширений алгоритм Евкліда працює правильно, будується на підтримці певних незмінних властивостей (інваріантів) на кожному кроці циклу. Наша мета — довести, що послідовності чисел `x_i` та `y_i`, які ми генеруємо паралельно з остачами `r_i`, дійсно задовольняють рівняння `a * x_i + b * y_i = r_i` для будь-якого кроку `i`.

Розглянемо стан алгоритму. Ми починаємо з двох початкових чисел `a` та `b`.
На нульовому кроці ми маємо:
`r_0 = a`
`x_0 = 1`
`y_0 = 0`

Підставимо ці значення в наше шукане рівняння:
`a * 1 + b * 0 = a`. Це дорівнює `r_0`, отже, для нульового кроку інваріант виконується.

На першому кроці ми маємо:
`r_1 = b`
`x_1 = 0`
`y_1 = 1`

Підставляємо:
`a * 0 + b * 1 = b`. Це дорівнює `r_1`, тому для першого кроку інваріант також виконується.

Тепер застосуємо метод математичної індукції. Припустимо, що наш інваріант виконується для двох попередніх кроків, `i-1` та `i`:
1) `a * x_{i-1} + b * y_{i-1} = r_{i-1}`
2) `a * x_i + b * y_i = r_i`

Нам потрібно довести, що він виконується і для наступного кроку `i+1`.

За визначенням алгоритму Евкліда, наступна остача `r_{i+1}` обчислюється як залишок від ділення `r_{i-1}` на `r_i`. Якщо ми позначимо частку від цього ділення як `q_i`, то ми можемо записати:
`r_{i+1} = r_{i-1} - q_i * r_i`

Так само, за правилами розширеного алгоритму Евкліда, наступні коефіцієнти `x_{i+1}` та `y_{i+1}` обчислюються за тими самими формулами:
`x_{i+1} = x_{i-1} - q_i * x_i`
`y_{i+1} = y_{i-1} - q_i * y_i`

Тепер давайте перевіримо, чи виконується інваріант для кроку `i+1`. Ми хочемо показати, що вираз `a * x_{i+1} + b * y_{i+1}` дійсно дорівнює `r_{i+1}`.

Підставимо формули для `x_{i+1}` та `y_{i+1}` у вираз:
`a * (x_{i-1} - q_i * x_i) + b * (y_{i-1} - q_i * y_i)`

Розкриємо дужки:
`a * x_{i-1} - a * q_i * x_i + b * y_{i-1} - b * q_i * y_i`

Перегрупуємо члени, зібравши разом ті, що відносяться до кроку `i-1`, і ті, що відносяться до кроку `i`:
`(a * x_{i-1} + b * y_{i-1}) - q_i * (a * x_i + b * y_i)`

За нашим припущенням індукції, вираз у перших дужках дорівнює `r_{i-1}`, а вираз у других дужках дорівнює `r_i`. Підставимо ці значення:
`r_{i-1} - q_i * r_i`

Але цей вираз — це саме визначення `r_{i+1}`! Отже, ми отримали:
`a * x_{i+1} + b * y_{i+1} = r_{i+1}`

Ми довели, що якщо рівняння виконується для будь-яких двох послідовних кроків, воно обов'язково виконуватиметься і для наступного кроку. Оскільки воно виконується для початкових кроків 0 та 1, воно виконуватиметься для всіх наступних кроків до самого кінця алгоритму. 

Коли алгоритм зупиняється на кроці `k`, де остача `r_k = 0`, попередній крок `k-1` містить шуканий найбільший спільний дільник: `r_{k-1} = gcd(a, b)`. І за нашим доведеним інваріантом, відповідні коефіцієнти задовольняють:
`a * x_{k-1} + b * y_{k-1} = gcd(a, b)`
Що і доводить тотожність Безу конструктивним шляхом.
