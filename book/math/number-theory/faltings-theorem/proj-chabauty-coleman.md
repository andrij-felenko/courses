# ⚙️ Обчислення раціональних точок методом Чабауті–Коулмана

Алгоритм Чабауті–Коулмана здійснює явне обчислення раціональних точок на гіпереліптичних кривих роду `g = 2` у випадку, коли ранг Якобіана задовольняє умову `r = rank(J(ℚ)) < g`. Обчислювальна схема на мовах C++ та Python локалізує `p`-адичні нулі степенних рядів Коулмана й знаходить усі раціональні розв'язки рівняння кривої.

---

## 1. Конструктивність проти неефективності Фальтінгса

Головне обмеження загальної теореми Фальтінгса полягає у її **неефективності**: вона гарантує, що множина раціональних точок `C(ℚ)` на кривій роду `g ≥ 2` є скінченною, проте її доведення не дає жодної верхньої межі для арифметичної висоти точок `P ∈ C(ℚ)` і не пропонує процедури для їх пошуку.

Коли математик має конкретну криву — наприклад, гіпереліптичну криву роду 2:

```
y² = x⁶ + 1
```

доведення Фальтінгса стверджує, що раціональних точок скінченна кількість, але не дає відповіді, чи вичерпується множина розв'язків видимими точками `(0, ±1), (±1, ±√2)∉ℚ`, чи десь на висоті `10¹⁰⁰` ховається гігантський раціональний розв'язок.

Алгоритм **Чабауті–Коулмана** (Michael Chabauty, 1938; Robert Coleman, 1985) заповнює цей прогалин для широкого класу кривих, у яких ранг Якобіана є меншим за рід кривої:

```
r = rank(J(ℚ)) < g
```

Для таких кривих метод перетворює `p`-адичне інтегрування на явну обчислювальну процедуру, яка знаходить **усі без винятку** раціональні точки.

---

## 2. Математична схема та аналітичні деталі алгоритму

Розглянемо гладку гіпереліптичну криву роду `g = 2`, задану канонічним рівнянням:

```
C: y² = f(x) = a₆·x⁶ + a₅·x⁵ + a₄·x⁴ + a₃·x³ + a₂·x² + a₁·x + a₀
```

де `f(x)` — поліном без кратних коренів (з дискримінантом `Δ ≠ 0`) з цілими коефіцієнтами.

### Крок 1. Базис голоморфних диференціалів та періодні інтеграли

Простір голоморфних 1-форм `H⁰(C, Ω¹)` на кривій роду 2 має вимір `g = 2`. Його стандартний канонічний базис формують дві диференціальні форми першого роду:

```
ω₁ = dx / (2·y),   ω₂ = x·dx / (2·y)
```

Будь-яка диференціальна форма першого роду є лінійною комбінацією `ω = c₁·ω₁ + c₂·ω₂`.

### Крок 2. Зведення до `p`-адичного інтегрування Коулмана

Нехай `p ≥ 3` — просте число **хорошої редукції** (тобто `p ∤ Δ(f)`). Позначимо через `C(𝔽ₚ)` множину точок кривої над скінченним полем остач `𝔽ₚ`.

Природне відображення редукції `red_p: C(ℚ) → C(𝔽ₚ)` розбиває простір раціональних точок `C(ℚ)` на скінченну кількість локальних `p`-адичних дисків (куль):

```
C(ℚ) = ⋃_{P̄ ∈ C(𝔽ₚ)} U_{P̄}
```

де `U_{P̄} = { P ∈ C(ℚₚ) : red_p(P) = P̄ }` — локальний `p`-адичний диск над точкою `P̄`.

### Крок 3. Знаходження анулюючого диференціала (Annihilating Differential)

За теоремою Морделла–Вейля, група раціональних точок Якобіана `J(ℚ)` має ранг `r`. Якщо `r = 1 < g = 2`, то топологічне замикання раціональних точок `J̅(ℚ)` у `p`-адичній групі Лі `J(ℚₚ)` має вимір 1.

Оскільки простір інваріантних `p`-адичних диференціалів на `J(ℚₚ)` має вимір `g = 2`, існує принаймні одна ненульова форма `ω_ann = c₁·ω₁ + c₂·ω₂` (із коефіцієнтами `c₁, c₂ ∈ ℤₚ`), інтеграл Коулмана якої дорівнює нулю на всій підгрупі `J(ℚ)`:

```
∫_{P₀}^{P} ω_ann = 0      для всіх P ∈ C(ℚ)
```

де `P₀ ∈ C(ℚ)` — обрана базова раціональна точка.

### Крок 4. Локальний степенний ряд біля точки `P̄`

У кожному локальному диску `U_{P̄}` розглядаємо `p`-адичний параметр `t`.

- Якщо `ȳ ≠ 0 (mod p)` (невієрштрасова точка), за параметр обирають `t = x − x₀`.
- Якщо `ȳ ≡ 0 (mod p)` (точка Вієрштрасса), за параметр обирають `t = y`.

Розкладаємо координати `x(t)` та `y(t)` у локальні Тейлорівські степенні ряди за параметром `t`:

```
x(t) = x₀ + t
y(t) = √( f(x₀ + t) ) = y₀ · √( 1 + (f'(x₀)/f(x₀))·t + (f''(x₀)/(2·f(x₀)))·t² + … )
```

Підставляючи ці ряди у підінтегральний вираз `ω_ann`, дістаємо степенний ряд для диференціала:

```
ω_ann(t) = ( α₀ + α₁·t + α₂·t² + α₃·t³ + … ) dt
```

де коефіцієнти `α_k ∈ ℚₚ` обчислюються алгебраїчно через коефіцієнти полінома `f(x)` та вектор `(c₁, c₂)`.

Інтегруючи член за членом, отримуємо **степенний ряд Коулмана**:

```
I(t) = ∫₀ᵗ ω_ann = α₀·t + (α₁ / 2)·t² + (α₂ / 3)·t³ + (α₃ / 4)·t⁴ + …
```

### Крок 5. Аналіз нулів за полігоном Ньютона (Newton Polygon)

Кожна раціональна точка `P ∈ C(ℚ) ∩ U_{P̄}` відповідає `p`-адичному цілому значенням параметра `t ∈ p·ℤₚ`, у якому ряд Коулмана перетворюється на нуль: `I(t) = 0`.

За лемою Коулмана про `p`-адичні степенні ряди, якщо первинний коефіцієнт `v_p(α₀ / 1) = 0` (тобто `α₀ ≢ 0 mod p`), то степенний ряд `I(t)` має **строго один нуль** у вихідному диску `p·ℤₚ` (а саме `t = 0`).

Якщо ж `α₀ ≡ 0 (mod p)`, кількість нулів визначається нижніми гранями багатокутника Ньютона. Коулман довів, що кількість нулів у диску `U_{P̄}` не перевищує `1 + ⌊ (2·g − 2) / (p − 1) ⌋`.

Підсумовуючи межі по всіх локальних дисках `P̄ ∈ C(𝔽ₚ)`, отримуємо точну **явну оцінку Коулмана**:

```
|C(ℚ)| ≤ |C(𝔽ₚ)| + (2·g − 2)
```

Для кривої роду `g = 2` при `p > 2`:

```
|C(ℚ)| ≤ |C(𝔽ₚ)| + 2
```

## 3. Повний практичний приклад з числовим розбором

Розглянемо криву роду `g = 2`:

```
C: y² = x⁶ + 1
```

Обчислимо раціональні точки за допомогою модуля `p = 5`.

1. **Редукція over `𝔽₅`:**
   Перебираємо всі значення `x ∈ {0, 1, 2, 3, 4} (mod 5)`:
   - `x = 0 ⇒ y² = 1 ⇒ y = ±1` → точки `(0, 1), (0, 4)`.
   - `x = 1 ⇒ y² = 2 (mod 5)` (квадратичний нелишнишок) → немає точок.
   - `x = 2 ⇒ y² = 65 ≡ 0 (mod 5)` → точка `(2, 0)`.
   - `x = 3 ⇒ y² = 730 ≡ 0 (mod 5)` → точка `(3, 0)`.
   - `x = 4 ⇒ y² = 4097 ≡ 2 (mod 5)` → немає точок.
   
   Додаючи 2 нескінченно віддалені точки `∞⁺, ∞⁻`, отримуємо `|C(𝔽₅)| = 6`.

2. **Верхня оцінка Коулмана:**
   ```
   |C(ℚ)| ≤ |C(𝔽₅)| + 2·g − 2 = 6 + 2 = 8
   ```

3. **Перевірка раціональних точок:**
   Очевидні раціональні точки: `(0, 1), (0, -1), ∞⁺, ∞⁻`.
   Аналіз `p`-адичних рядів у точках `(2, 0)` та `(3, 0)` показує, що локальні `p`-адичні нулі `t ∈ 5·ℤ₅` не є раціональними числами.
   Таким чином, алгоритм точно підтверджує, що родина раціональних точок кривої `y² = x⁶ + 1` складається строго з 4 точок!

#include <iostream>
#include <vector>
#include <cmath>
#include <optional>
#include <numeric>
#include <algorithm>
#include <span>
#include <iomanip>

// Арифметика в скінченному полі F_p
class FieldFp {
public:
    long long p;
    constexpr explicit FieldFp(long long prime) : p(prime) {}

    [[nodiscard]] long long add(long long a, long long b) const {
        long long r = (a + b) % p;
        return r < 0 ? r + p : r;
    }

    [[nodiscard]] long long sub(long long a, long long b) const {
        long long r = (a - b) % p;
        return r < 0 ? r + p : r;
    }

    [[nodiscard]] long long mul(long long a, long long b) const {
        long long r = (a * b) % p;
        return r < 0 ? r + p : r;
    }

    [[nodiscard]] long long power(long long base, long long exp) const {
        long long res = 1;
        base %= p;
        if (base < 0) base += p;
        while (exp > 0) {
            if (exp % 2 == 1) res = (res * base) % p;
            base = (base * base) % p;
            exp /= 2;
        }
        return res;
    }

    [[nodiscard]] std::optional<long long> inv(long long n) const {
        n %= p;
        if (n == 0) return std::nullopt;
        return power(n, p - 2);
    }
};

// Точка у полі F_p
struct PointFp {
    long long x;
    long long y;
    bool is_infinity{false};
};

// Гіпереліптична крива y^2 = f(x) роду 2
class HyperellipticCurveGenus2 {
public:
    std::vector<long long> poly_f; // a0 + a1*x + ... + a6*x^6

    explicit HyperellipticCurveGenus2(std::vector<long long> coeffs) 
        : poly_f(std::move(coeffs)) {}

    [[nodiscard]] long long eval_f(long long x, const FieldFp& F) const {
        long long res = 0;
        long long x_pow = 1;
        for (long long coeff : poly_f) {
            long long term = F.mul(coeff % F.p, x_pow);
            res = F.add(res, term);
            x_pow = F.mul(x_pow, x);
        }
        return res;
    }

    // Алгебраїчна похідна f'(x)
    [[nodiscard]] long long eval_f_derivative(long long x, const FieldFp& F) const {
        long long res = 0;
        long long x_pow = 1;
        for (size_t i = 1; i < poly_f.size(); ++i) {
            long long term = F.mul((poly_f[i] * static_cast<long long>(i)) % F.p, x_pow);
            res = F.add(res, term);
            x_pow = F.mul(x_pow, x);
        }
        return res;
    }

    [[nodiscard]] std::vector<PointFp> find_points_Fp(const FieldFp& F) const {
        std::vector<PointFp> pts;
        for (long long x = 0; x < F.p; ++x) {
            long long rhs = eval_f(x, F);
            for (long long y = 0; y < F.p; ++y) {
                if (F.mul(y, y) == rhs) {
                    pts.push_back({x, y, false});
                }
            }
        }
        // Нескінченні точки if deg(f) == 6 та a6 є квадратом
        if (poly_f.size() == 7) {
            long long a6 = poly_f[6] % F.p;
            if (a6 < 0) a6 += F.p;
            for (long long y = 0; y < F.p; ++y) {
                if (F.mul(y, y) == a6) {
                    pts.push_back({0, y, true}); // inf+ та inf-
                }
            }
        }
        return pts;
    }
};

// Аналізатор аналітичного ряду Коулмана
class ChabautyColemanSolver {
private:
    HyperellipticCurveGenus2 curve;
    long long prime_p;
    FieldFp F;

public:
    ChabautyColemanSolver(HyperellipticCurveGenus2 c, long long p)
        : curve(std::move(c)), prime_p(p), F(p) {}

    // Обчислення Тейлорівського степенного ряду I(t) біля точки P0
    [[nodiscard]] std::vector<double> compute_coleman_series(
        PointFp P0, double c1, double c2, int max_degree) const 
    {
        std::vector<double> coeff(max_degree + 1, 0.0);
        if (P0.is_infinity) return coeff;

        double x0 = static_cast<double>(P0.x);
        double y0 = static_cast<double>(P0.y);

        if (std::abs(y0) < 1e-9) {
            // Точка Вієрштрасса (y = 0): параметр t = y
            coeff[1] = c1;
            return coeff;
        }

        // Невієрштрасова точка: параметр t = x - x0
        // ω_ann = (c1 + c2*(x0 + t)) / (2 * y(t)) dt
        double inv_2y0 = 1.0 / (2.0 * y0);
        double alpha0 = (c1 + c2 * x0) * inv_2y0;
        double alpha1 = c2 * inv_2y0;

        coeff[1] = alpha0;                     // ∫ alpha0 dt = alpha0 * t
        if (max_degree >= 2) coeff[2] = alpha1 / 2.0; // ∫ alpha1*t dt = (alpha1/2) * t^2

        return coeff;
    }

    void run_chabauty_analysis(double c1, double c2) const {
        std::cout << "====================================================\n";
        std::cout << " АНАЛІЗ ЧАБАУТІ–КОУЛМАНА ДЛЯ МОДУЛЯ p = " << prime_p << "\n";
        std::cout << "====================================================\n";

        auto pts = curve.find_points_Fp(F);
        std::cout << "Кількість точок редукції |C(F_" << prime_p << ")| = " << pts.size() << "\n";

        long long bound = static_cast<long long>(pts.size()) + 2; // |C(F_p)| + 2g - 2
        std::cout << "Верхня оцінка Коулмана: |C(Q)| <= " << bound << " раціональних точок.\n\n";

        std::cout << std::left << std::setw(12) << "Точка P" 
                  << std::setw(16) << "Тип диску" 
                  << "Ряд Тейлора I(t)\n";
        std::cout << "----------------------------------------------------\n";

        for (size_t i = 0; i < pts.size(); ++i) {
            std::string pt_str;
            if (pts[i].is_infinity) {
                pt_str = "Inf_" + std::to_string(i);
            } else {
                pt_str = "(" + std::to_string(pts[i].x) + "," + std::to_string(pts[i].y) + ")";
            }

            auto series = compute_coleman_series(pts[i], c1, c2, 3);

            std::string disc_type = (pts[i].y == 0) ? "Вієрштрасса" : "Основницький";
            std::cout << std::left << std::setw(12) << pt_str 
                      << std::setw(16) << disc_type
                      << "I(t) = " << std::setprecision(4) << series[1] << "*t + " 
                      << series[2] << "*t^2 + ...\n";
        }
        std::cout << "====================================================\n\n";
    }
};

int main() {
    // Крива роду 2: y^2 = x^6 + 1
    HyperellipticCurveGenus2 curve({1, 0, 0, 0, 0, 0, 1});

    // Хороше просте p = 5
    ChabautyColemanSolver solver5(curve, 5);
    solver5.run_chabauty_analysis(1.0, -0.5);

    // Хороше просте p = 7
    ChabautyColemanSolver solver7(curve, 7);
    solver7.run_chabauty_analysis(1.0, -0.5);

    return 0;
}

# Python реалізація аналізу Чабауті–Коулмана для гіпереліптичних кривих
import math

class FieldFp:
    def __init__(self, p):
        self.p = p

    def add(self, a, b): return (a + b) % self.p
    def sub(self, a, b): return (a - b) % self.p
    def mul(self, a, b): return (a * b) % self.p
    def power(self, base, exp): return pow(base, exp, self.p)

class HyperellipticCurveGenus2:
    def __init__(self, poly_coeffs):
        # poly_coeffs: [a0, a1, a2, a3, a4, a5, a6]
        self.coeffs = poly_coeffs

    def eval_f(self, x, F):
        res = 0
        x_pow = 1
        for c in self.coeffs:
            res = F.add(res, F.mul(c, x_pow))
            x_pow = F.mul(x_pow, x)
        return res

    def find_points_Fp(self, F):
        pts = []
        for x in range(F.p):
            rhs = self.eval_f(x, F)
            for y in range(F.p):
                if F.mul(y, y) == rhs:
                    pts.append((x, y))
        return pts

def chabauty_coleman_bound(coeffs, p, c1=1.0, c2=-0.5):
    F = FieldFp(p)
    curve = HyperellipticCurveGenus2(coeffs)
    pts = curve.find_points_Fp(F)
    
    bound = len(pts) + 2  # |C(F_p)| + 2g - 2 при g=2
    print(f"=== Модуль p = {p} ===")
    print(f"Точки редукції над F_{p}: {pts}")
    print(f"Оцінка Коулмана: |C(Q)| <= {bound} раціональних точок.")
    
    print("\nАналіз рядів Тейлора Коулмана:")
    for pt in pts:
        x0, y0 = pt
        if y0 != 0:
            inv_2y0 = 1.0 / (2.0 * y0)
            alpha0 = (c1 + c2 * x0) * inv_2y0
            alpha1 = c2 * inv_2y0
            print(f" Точка {pt} -> I(t) = {alpha0:.4f}*t + {alpha1/2.0:.4f}*t^2 + ...")
        else:
            print(f" Точка Вієрштрасса {pt} -> I(t) = {c1:.4f}*t + ...")
    print("-" * 50)
    return pts, bound

if __name__ == "__main__":
    # y^2 = x^6 + 1
    coeffs = [1, 0, 0, 0, 0, 0, 1]
    chabauty_coleman_bound(coeffs, p=5)
    chabauty_coleman_bound(coeffs, p=7)

## 5. Практичні пастки та розбір крайових випадків

Під час застосування алгоритму Чабауті–Коулмана у обчислювальній теорії чисел необхідно враховувати чотири фундаментальні пастки:

1. **Точки поганої редукції (`p ∣ Δ`):**
   Алгоритм вимагає, щоб просте число `p` було числовим модулем **хорошої редукції** (тобто не ділило дискримінант кривої `Δ`). Якщо `p` є дільником дискримінанта, крива `C(𝔽ₚ)` стає особливою (з'являються вузли або каспи), диференціальна форма `dx / 2y` набуває неконтрольованих полюсів, і стандартний ряд Тейлора втрачає збіжність у диску `p·ℤₚ`.

2. **Пастка вищого рангу (`r ≥ g`):**
   Якщо ранг Якобіана `r ≥ g`, простого підпростору анулюючих диференціалів `ω_ann` у `p`-адичних 1-формах **не існує**. У цьому випадку класичний метод Чабауті–Коулмана втрачає силу. 
   
   Для подолання цієї перешкоди у XXI столітті Мінхьон Кім (Minhyong Kim) розробив **неабелів метод Чабауті**, який замінює абелів Якобіан вежею фундаментальних груп Уайтхеда–Нільсена `π₁(C)` та `p`-адичними зображеннями Галуа. Це дозволяє будувати анулюючі `p`-адичні інтеграли вищих степеней (ітерировані інтеграли за Вольтеррою–Івасавою).

3. **Дурні нулі (Spurious `p`-adic zeros):**
   Не кожен нуль `p`-адичного інтеграла `I(t) = 0` відповідає дійсному раціональному розв'язку `P ∈ C(ℚ)`. Степенний ряд `I(t)` може мати локальні `p`-адичні нулі `t ∈ ℤₚ`, які не піднімаються до глобальних раціональних точок `ℚ`. 
   
   Для відсіювання таких самозванців застосовують перевірку за кількома простими модулями `p₁, p₂` або аналіз арифметичних висот за допомогою алгоритмів 2-спуску на Якобіанах.

4. **Обчислення рангу Якобіана `r = rank(J(ℚ))`:**
   Для запуску алгоритму необхідно заздалегідь знати ранг `r`. Його обчислюють за допомогою алгоритму **2-спуску на Якобіані** (2-descent on Jacobians), реалізованого у системах комп'ютерної алгебри MAGMA, SageMath або бібліотеці FLINT/NTL.
