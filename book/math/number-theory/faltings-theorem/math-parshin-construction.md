# 🧮 Конструкція Кодайри–Паршина та висота Фальтінгса

Ця математична вставка містить точне алгебро-геометричне виведення редукції Паршина, яка зводить гіпотезу Морделла про скінченність раціональних точок `C(K)` до гіпотези Шафаревича про скінченність класів ізоморфізму абелевих многовидів, а також алгебраїчний апарат висоти Фальтінгса.

---

## 1. Геометричний задум редукції

Основна складність гіпотези Морделла полягає у відсутності прямої алгебраїчної структури на множині раціональних точок `C(K)` алгебраїчної кривої `C` роду `g ≥ 2`. На відміну від еліптичних кривих (`g = 1`), на кривих вищого роду точки не можна додавати або множити.

Ідея Олексія Паршина (базована на геометричній конструкції Куніхіко Кодайри) полягає у тому, щоб кожній раціональній точці `P ∈ C(K)` зіставити **геометричний об'єкт вищого рівня** — нерозгалужене покриття кривої `Cₚ → C`, а потім перейти до його **Якобіана** `A_P = Jac(Cₚ)`. 

Цей перехід трансформує поштучний аналіз точок `P` у фундаментальну проблему алгебраїчної геометрії — вивчення сімейства абелевих многовидів `A_P` фіксованого виміру та з обмеженим розгалуженням.

---

## 2. Конструкція Кодайри–Паршина: від точки до покриття

Нехай `C` — гладка неподільна проективна крива роду `g ≥ 2`, визначена над числовим полем `K`.

Фіксуємо просте число `ℓ ≥ 2` (зазвичай обирають `ℓ = 2` або `ℓ = 3`).

Для кожної раціональної точки `P ∈ C(K)` ми будуємо скінченне дволисте або `ℓ`-листе покриття `π_P: C_P → C`, яке задовольняє такі жорсткі геометро-топологічні умови:

1. **Множина розгалуження:** Морфізм `π_P` є гладким нерозгалуженим покриттям над усім простором `C \ {P}`, а в самій точці `P` має строго фіксований індекс розгалуження `ℓ`.
2. **Гарантований рід:** Рід кривої `C_P` є фіксованим числом `g' > g`, що залежить лише від `g` та `ℓ`, і не залежить від вибору конкретної точки `P`.

### Алгебраїчна побудова через лінійні пучки

Побудова покриття `C_P → C` реалізується через циклічні розширення функціонального поля `K(C)`.

Розглянемо дивизор `[P]` раціональної точки `P ∈ C(K)`. За теоремою про структуру пучків існує лінійний пучок `ℒ = 𝒪_C(P)` та елемент `s ∈ H⁰(C, ℒ^ℓ)` такий, що схема нулів `(s)₀ = ℓ·P`.

Тоді покриття `C_P` визначається як спектр алгебри sheaves:

```
C_P = Spec_C( 𝒪_C ⊕ ℒ⁻¹ ⊕ ℒ⁻² ⊕ … ⊕ ℒ^{-(ℓ-1)} )
```

з законом множення, заданим перерізом `s`. Це гарантує, що `π_P: C_P → C` є гладким `ℓ`-листим покриттям, яке розгалужується виключно над точкою `P`.

### Формула Рімана–Гурвіца та обчислення роду `g'`

Зв'язок між родом вихідної кривої `g = genus(C)` та родом покриття `g' = genus(C_P)` задається класичною формулою Рімана–Гурвіца. Якщо степень покриття дорівнює `d = deg(π_P)`, то:

```
2·g' − 2 = d · (2·g − 2) + R
```

де `R` — степінь дивизора розгалуження (дифракції). Оскільки розгалуження відбувається лише над точкою `P` з індексом `ℓ`, то точка `P` має `d / ℓ` прообразів `Q₁, …, Q_{d/ℓ}` у кривій `C_P`, і в кожному з них ветвіння дорівнює `ℓ − 1`.

Тоді сумарний внесок розгалуження обчислюється як:

```
R = (d / ℓ) · (ℓ − 1) = d · (1 − 1 / ℓ)
```

Підставивши значення `R` у формулу Рімана–Гурвіца, отримуємо точне значення для роду покровної кривої `g'`:

```
2·g' − 2 = d · (2·g − 2 + 1 − 1 / ℓ) = d · (2·g − 1 − 1 / ℓ)
```

Звідси рід покровної кривої становить:

```
g' = 1 + (d / 2) · (2·g − 1 − 1 / ℓ)
```

Оскільки `g ≥ 2` та `ℓ ≥ 2`, то значення `2·g − 1 − 1 / ℓ > 0`, і рід `g'` є строго більшим за `g`. Найважливіше: **значення `g'` є константою для всіх точок `P ∈ C(K)`**.

---

## 3. Якобіані та Кондуктор: від `C_P` до абелевого многовиду `A_P`

Кожній побудованій кривій `C_P` роду `g'` ми зіставляємо її **Якобіан**:

```
A_P = Jac(C_P)
```

Це гладкий поляризований абелів многовид розмірності `dim(A_P) = g'`.

### Контроль розгалуження та обмеженість провідника (Conductor)

Нехай `S` — скінченна множина простих ideals числового поля `K`, у яких вихідна крива `C` має **погану редукцію** (тобто розгалужується або стає особливою), об'єднана з простими дільниками числа `ℓ` та архімедовими нормами.

Оскільки покриття `C_P → C` розгалужене тільки у точці `P ∈ C(K)`, усі нові особливості або розгалуження кривої `C_P` повністю контролюються арифметикою точки `P`. 

Паршин довів, що абелевий многовид `A_P = Jac(C_P)` має хорошу редукцію поза розширеною скінченною множиною простих ideals `S'`, яка **не залежить від точки `P`**.

Це означає, що провідник (conductor) `N(A_P)` абелевого многовиду `A_P` є арифметично обмеженим за модулем фіксованого дивизора `D_S'`:

```
N(A_P) ∣ D_S'
```

## 4. Гіпотеза Шафаревича та Теорема Тореллі

Тепер вступає в дію гіпотеза Шафаревича (доведена Фальтінгсом):

> **Гіпотеза Шафаревича (Теорема Фальтінгса I):** Множина класів ізоморфізму абелевих многовидів `A` фіксованого виміру `g'` над числовим полем `K`, які мають хорошу редукцію поза фіксованою скінченною множиною простих ideals `S'`, є **скінченною**.

Позначимо цю скінченну множину класів ізоморфізму через:

```
ℳ_{g', S'} = { [A₁], [A₂], …, [A_N] }
```

### Замикання ланцюга через теорему Тореллі

Для завершення доведення потрібно показати, що скінченність класів абелевих многовидів `A_P` тягне за собою скінченність вихідних точок `P ∈ C(K)`:

1. **Теорема Тореллі (Torelli's Theorem):** Алгебраїчна крива `C_P` повністю й однозначно відновлюється (з точністю до ізоморфізму) за своїм канонічно поляризованим Якобіаном `(Jac(C_P), Θ)`.
2. Оскільки поляризованих абелевих многовидів `A_P` існує лише скінченна кількість класів ізоморфізму, то й покровних кривих `C_P` (з точністю до `K`-ізоморфізму) існує лише **скінченна кількість**.
3. Для кожної фіксованої покровної кривої `C_P` існує лише скінченна кількість морфізмів покриття `π: C_P → C` степеня `d` (за теоремою де Франкіса про скінченність неконстантних відображень між кривими роду `g ≥ 2`).
4. Кожна точка `P ∈ C(K)` відновлюється як єдина образна точка розгалуження морфізму `π_P: C_P → C`.

Отже, множина вихідних раціональних точок `C(K)` складається з об'єднання скінченного числа скінченних множин, і тому **є скінченною**:

```
|C(K)| < ∞
```

## 5. Алгебраїчна машинерія Фальтінгса: Висота Фальтінгса

Щоб довести гіпотезу Шафаревича, Ґерду Фальтінгсу знадобилося ввести арифметичну міру складності абелевого многовиду — **висоту Фальтінгса** (модулярну висоту).

Нехай `A` — абелів многовид розмірності `g'` над числовим полем `K`, і нехай `𝒜 → Spec(𝒪_K)` — його мінімальна модель Нейрона над кільцем цілих `𝒪_K`.

Розглянемо пучок інваріантних диференціальних форм найвищого степеня вздовж нуля (нульового перетину `e: Spec(𝒪_K) → 𝒜`):

```
ω_{A/𝒪_K} = Det( e* Ω¹_{𝒜/𝒪_K} )
```

Це інвертований `𝒪_K`-модуль (одновимірний арифметичний пучок).

### Формула висоти Фальтінгса

Мотивова **висота Фальтінгса** `h_F(A)` визначається через арифметичний степінь Аракелова цього пучка:

```
h_F(A) = − (1 / [K : ℚ]) · deg_Arakelov( ω_{A/𝒪_K} )
```

Розгортаючи степінь Аракелова на неархімедових (усі прості ideals `𝔭 ∈ Spec(𝒪_K)`) та архімедових нормуваннях (`σ: K ↪ ℂ`), отримуємо точний вираз:

```
h_F(A) = − (1 / [K : ℚ]) · ( ∑_{𝔭} log |N(𝔭)| · val_𝔭(ω) − ∑_{σ} log ‖∫_{A_σ(ℂ)} α ∧ ᾱ‖ )
```

де `α` — канонічна база простору диференціальних 1-форм `H⁰(A_σ, Ω¹)` над комплексними числами.

### Доведення теореми про ізогенії та напівпростоту

Ключовим теоретико-числовим проривом Фальтінгса стало доведення **напівпростоти зображень Галуа** на модулях Тейта.

Нехай `T_p(A) = lim_← A[p^n]` — `p`-адичний модуль Тейта абелевого многовиду `A`. Група Галуа `G_K = Gal(K̄/K)` природно діє на векторному просторі `V_p(A) = T_p(A) ⊗_ℤ_p ℚ_p` виміру `2·g'`.

Фальтінгс довів такі фундаментальні факти:

1. **Напівпростота (Semi-simplicity):** Векторний простір `V_p(A)` є **напівпростим `G_K`-модулем** (тобто розкладається у пряму суму незвідних зображень Галуа).
2. **Теорема про ізогенії (Isogeny Theorem):** Природний гомоморфізм обмеження:
   ```
   Hom_K(A, B) ⊗ ℤ_p ≅ Hom_{G_K}( T_p(A), T_p(B) )
   ```
   є **ізоморфізмом**. Це означає, що алгебраїчні морфізми між абелевими многовидами повністю відновлюються за їхніми зображеннями Галуа.
3. **Скінченність висоти (Faltings' Finiteness Theorem):** Для будь-якої фіксованої константи `C > 0` існує лише **скінченна кількість** класів ізоморфізму поляризованих абелевих многовидів `A` над `K` розмірності `g'`, висота Фальтінгса яких обмежена:
   ```
   h_F(A) ≤ C
   ```
4. **Обмеженість висоти при ізогеніях:** Якщо `f: A → B` є `K`-ізогенією абелевих многовидів степеня `N`, то різниця їхніх висот Фальтінгса обмежена арифметичним логарифмом степеня:
   ```
   | h_F(A) − h_F(B) | ≤ (1 / 2) · log(N)
   ```

Зі скінченності висоти та доведення ізоморфізму Тейта прямо випливає гіпотеза Шафаревича, а з неї — через конструкцію Кодайри–Паршина — **Теорема Фальтінгса (гіпотеза Морделла)**.
