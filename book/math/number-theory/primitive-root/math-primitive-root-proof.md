# 🧮 Повний математичний доказ існування та критерію Ґаусса для первісного кореня

Ця математична вставка містить виведення теореми про існування первісного кореня за простим модулем p, доказ його підйому на степені p^k та 2·p^k, а також суворе обґрунтування того, чому для решти модулів первісні корені не існують.

## Частина 1. Існування первісного кореня за простим модулем p

Нехай p — просте число. Мультиплікативна група класу лишків (ℤ/pℤ)* складається з p − 1 елементів: {1, 2, ..., p − 1}.
Ми доведемо, що ця група є циклічною, тобто існує елемент g порядку p − 1.

### Лема 1 (Про кількість коренів многочлена над полем ℤ/pℤ)
Нехай f(x) = a_d · x^d + ... + a₁ · x + a₀ — ненульовий многочлен степеня d з цілими коефіцієнтами, і p — просте число. Тоді порівняння f(x) ≡ 0 (mod p) має не більше ніж d несумірних за модулем p розв'язків.

**Доказ.** Доведення ведеться індукцією за степенем d.
Для d = 0 порівняння a₀ ≡ 0 (mod p) не має розв'язків, бо a₀ не ділиться на p.
Припустимо, що твердження правильне для всіх многочленів степеня d − 1.
Якщо f(x) ≡ 0 (mod p) не має коренів, то їх кількість 0 ≤ d, і лема виконується.
Якщо ж існує корінь x = r, тобто f(r) ≡ 0 (mod p), то за теоремою про ділення многочленів з остачею:

```
f(x) - f(r) 
= a_d · (x^d - r^d) + ... + a₁ · (x - r)
= (x - r) · g(x)     [де g(x) має степінь d - 1]
```

Отже f(x) = (x − r) · g(x) + k · p. Якщо x = s — інший корінь f(x), несумірний з r (тоді s − r ≢ 0 (mod p)), то:

```
f(s) = (s - r) · g(s) ≡ 0 (mod p)
```

Оскільки p — просте число, з (s − r) · g(s) ≡ 0 (mod p) та s − r ≢ 0 (mod p) випливає, що g(s) ≡ 0 (mod p).
За припущенням індукції многочлен g(x) степеня d − 1 має не більше ніж d − 1 коренів. Разом з коренем r многочлен f(x) має не більше ніж 1 + (d − 1) = d коренів. Лему доведено.

### Лема 2 (Про кількість розв'язків x^d ≡ 1 (mod p))
Якщо d ділить p − 1, то порівняння x^d ≡ 1 (mod p) має **точно d** різних розв'язків за модулем p.

**Доказ.** Оскільки d ділить p − 1, розкладемо різницю степенів:

```
x^(p - 1) - 1 = (x^d - 1) · h(x)
```

де h(x) = x^(p − 1 − d) + x^(p − 1 − 2d) + ... + 1 є многочленом степеня p − 1 − d.
За малою теоремою Ферма порівняння x^(p − 1) − 1 ≡ 0 (mod p) має точно p − 1 розв'язків (це всі числа 1, 2, ..., p − 1).
За Лемою 1 многочлен h(x) має не більше ніж p − 1 − d коренів.
Але будь-який корінь x^(p − 1) − 1 ≡ 0 (mod p), який не є коренем h(x), мусить бути коренем x^d − 1 ≡ 0 (mod p).
Тому кількість коренів x^d − 1 ≡ 0 (mod p) не менша ніж (p − 1) − (p − 1 − d) = d.
З іншого боку, за Лемою 1 ця кількість не більша за d. Отже, коренів **точно d**.

### Лема 3 (Підрахунок елементів точного порядку d)
Для кожного дільника d числа p − 1 позначаємо через N(d) кількість елементів в (ℤ/pℤ)*, які мають мультиплікативний порядок рівний d.
Тоді либо N(d) = 0, либо N(d) = φ(d).

**Доказ.** Якщо N(d) = 0, лема тривіально справджується.
Якщо ж N(d) > 0, то існує елемент a порядку d (ord_p(a) = d).
Степені a⁰, a¹, a², ..., a^(d−1) є несумірними за модулем p і всі є розв'язками порівняння x^d ≡ 1 (mod p).
За Лемою 2 порівняння x^d ≡ 1 (mod p) має точно d розв'язків. Отже, **всі** розв'язками x^d ≡ 1 (mod p) є саме степені a^k (для k = 0, ..., d − 1).
Порядок степеня a^k дорівнює d / gcd(k, d).
Тому a^k має порядок рівний d тоді й лише тоді, коли gcd(k, d) = 1.
Кількість таких показників k у межах від 0 до d − 1 за означенням дорівнює φ(d).
Таким чином, якщо існує бодай один елемент порядку d, то їх існує точно φ(d).

### Теорема 1 (Існування первісного кореня за модулем p)
Для кожного простого числа p існує точно φ(p − 1) первісних коренів за модулем p.

**Доказ.** Кожен з p − 1 елементів групи (ℤ/pℤ)* має свій порядок d, який є дільником p − 1 (за теоремою Лагранжа для груп).
Тому сума кількостей елементів усіх можливих порядків дорівнює всьому розміру групи:

```
∑_{d | (p - 1)} N(d) = p - 1
```

З іншого боку, відома класична тотожність для функції Ейлера:

```
∑_{d | (p - 1)} φ(d) = p - 1
```

Віднімаючи дві рівності одна від одної, отримуємо:

```
∑_{d | (p - 1)} ( φ(d) - N(d) ) = 0
```

За Лемою 3 для кожного d різниця φ(d) − N(d) дорівнює либо 0 (якщо N(d) = φ(d)), либо φ(d) > 0 (якщо N(d) = 0).
Сума невід'ємних доданків дорівнює нулю тоді й лише тоді, коли кожен доданок дорівнює нулю!
Отже, для **всіх** дільників d числа p − 1 виконується N(d) = φ(d).
Поклавши d = p − 1, отримуємо, що кількість елементів порядку p − 1 дорівнює **N(p − 1) = φ(p − 1)**.
Оскільки φ(p − 1) ≥ 1, принаймні один первісний корінь існує завжди. Теорему доведено.

### Лема 4 (Порядок добутку двох елементів із взаємно простими порядками)
Якщо ord_n(a) = r, ord_n(b) = s і gcd(r, s) = 1, то ord_n(a · b) = r · s.

**Доказ.** Позначимо k = ord_n(a · b).

Спершу покажемо, що k ділить r · s:

```
(a · b)^(r · s) = (a^r)^s · (b^s)^r ≡ 1^s · 1^r ≡ 1   (mod n)
```

Тепер зворотний бік. З (a·b)^k ≡ 1 (mod n) піднесемо обидві частини до степеня r:

```
(a · b)^(k · r) 
= (a^r)^k · b^(k · r) 
≡ 1^k · b^(k · r) 
≡ b^(k · r)   (mod n)
```

Ліва частина дорівнює 1, отже b^(k·r) ≡ 1 (mod n), а тому s ділить k · r. Оскільки gcd(r, s) = 1, звідси s ділить k. Симетрично, підносячи (a·b)^k ≡ 1 до степеня s, дістаємо, що r ділить k. Два взаємно прості числа ділять k, отже їхній добуток r · s теж ділить k.
Разом із першим кроком це дає k = r · s.

### Наслідок (конструктивний шлях до генератора)
Теорема 1 доводить, що первісний корінь є, але не показує, як його скласти. Лема 4 показує.

Нехай p − 1 = q₁^e₁ · q₂^e₂ · ... · q_t^e_t. Для кожного простого степеня q^e у цьому розкладі елемент точного порядку q^e існує: за Лемою 2 порівняння x^(q^e) ≡ 1 (mod p) має точно q^e розв'язків, а порівняння x^(q^(e−1)) ≡ 1 (mod p) — лише q^(e−1) з них. Різниця не порожня, і будь-який елемент із неї має порядок рівно q^e.

Візьмімо по одному такому елементу g₁, g₂, ..., g_t. Їхні порядки — степені різних простих, тобто попарно взаємно прості, тож за Лемою 4 (застосованою послідовно) добуток має порядок

```
ord_p(g₁ · g₂ · ... · g_t) = q₁^e₁ · q₂^e₂ · ... · q_t^e_t = p − 1
```

Це і є первісний корінь, зібраний із частин замість наосліп знайденого перебором.

## Частина 2. Підйом первісного кореня на степені p^k та 2·p^k

### Теорема 2 (Підйом до p²)
Якщо g — первісний корінь за модулем p (де p — непарне просте), то принаймні одне з чисел g або g + p є первісним коренем за модулем p².

**Доказ.** Порядок g за модулем p² ділить φ(p²) = p · (p − 1).
Оскільки g^ord_p²(g) ≡ 1 (mod p²) ⇒ g^ord_p²(g) ≡ 1 (mod p), порядок ord_p²(g) мусить бути кратним ord_p(g) = p − 1.
Єдині можливі дільники p · (p − 1), які кратні p − 1, це p − 1 та p · (p − 1).
Отже, ord_p²(g) дорівнює либо p − 1, либо p · (p − 1).

Припустимо, що ord_p²(g) = p − 1, тобто g^(p−1) ≡ 1 (mod p²).
Розглянемо число g' = g + p. Воно також є первісним коренем за модулем p (бо g' ≡ g (mod p)).
За біномом Ньютона:

```
(g + p)^(p - 1)
= g^(p - 1) + (p - 1) · g^(p - 2) · p + [доданки з p²]
≡ 1 - p · g^(p - 2)   (mod p²)      [бо g^(p-1) ≡ 1 mod p²]
```

Оскільки g ≢ 0 (mod p), маємо p · g^(p−2) ≢ 0 (mod p²).
Отже, (g + p)^(p−1) ≢ 1 (mod p²).
Це означає, що порядок ord_p²(g + p) не може дорівнювати p − 1.
Тому ord_p²(g + p) = p · (p − 1) = φ(p²), і g + p є первісним коренем за модулем p².

### Теорема 3 (Індуктивний підйом до p^k)
Якщо g — первісний корінь за модулем p², то g є первісним коренем за модулем p^k для всіх k ≥ 2.

**Доказ (індукція за k).** 
База k = 2 за умовою. Припустимо, g є первісним коренем за модулем p^k.
Тоді g^(φ(p^(k−1))) = 1 + c · p^(k−1), де c ≢ 0 (mod p) (це наслідок того, що g не має меншого порядку).
Піднесемо цю рівність до p-го степеня:

```
g^(φ(p^k))
= (1 + c · p^(k - 1))^p
= 1 + p · c · p^(k - 1) + (p · (p - 1) / 2) · c² · p^(2k - 2) + ...
= 1 + c · p^k + d · p^(k + 1)     [для k ≥ 2 маємо 2k - 2 ≥ k + 1]
≡ 1 + c · p^k   (mod p^(k + 1))
```

Оскільки c ≢ 0 (mod p), маємо g^(φ(p^k)) ≢ 1 (mod p^(k+1)).
Аналогічно до попередньої теореми, порядок ord_p^(k+1)(g) ділить φ(p^(k+1)) = p^k · (p − 1) і ділиться на ord_p^k(g) = p^(k−1) · (p − 1).
Єдині два претенденти — це p^(k−1) · (p − 1) та p^k · (p − 1).
Оскільки g^(φ(p^k)) ≢ 1 (mod p^(k+1)), перший варіант відпадає.
Отже, ord_p^(k+1)(g) = φ(p^(k+1)), що й доводить індукційний крок.

### Теорема 4 (Перехід до 2·p^k)
Якщо g — первісний корінь за модулем p^k (де p — непарне просте), то непарне з чисел {g, g + p^k} є первісним коренем за модулем 2·p^k.

**Доказ.** Нехай g₀ — непарне число серед g та g + p^k. Оскільки p^k непарне, одне з них непарне.
Тоді gcd(g₀, 2·p^k) = 1.
Оскільки φ(2·p^k) = φ(2) · φ(p^k) = φ(p^k), маємо:

```
g₀^m ≡ 1 (mod 2 · p^k)  ⟺  g₀^m ≡ 1 (mod 2)  і  g₀^m ≡ 1 (mod p^k)
```

Оскільки g₀ непарне, g₀^m ≡ 1 (mod 2) виконується автоматично для будь-якого m ≥ 1.
Тому порядок g₀ за модулем 2·p^k точно дорівнює порядку g₀ за модулем p^k, тобто φ(p^k) = φ(2·p^k).
Отже, g₀ є первісним коренем за модулем 2·p^k.

## Частина 3. Неіснування первісних коренів для решти модулів

### Теорема 5 (Аномалія степенів двійки 2^k при k ≥ 3)
Для модулів n = 2^k (де k ≥ 3) первісного кореня не існує.

**Доказ.** Доведемо індукцією, що для кожного непарного числа a і k ≥ 3 виконується:

```
a^(2^(k - 2)) ≡ 1 (mod 2^k)
```

**База k = 3:** φ(8) = 4. Для будь-якого непарного a = 2m + 1 маємо:
a² = 4m² + 4m + 1 = 4m(m + 1) + 1. Оскільки m(m + 1) завжди парне, 4m(m + 1) ділиться на 8. Отже a² ≡ 1 (mod 8).
Тут 2^(3−2) = 2¹ = 2. Базу доведено.

**Крок індукції:** Припустимо a^(2^(k−2)) = 1 + q · 2^(k−1). Піднесемо до квадрата:

```
a^(2^(k - 1))
= (1 + q · 2^(k - 1))²
= 1 + 2 · q · 2^(k - 1) + q² · 2^(2k - 2)
= 1 + q · 2^k + q² · 2^(2k - 2)
≡ 1   (mod 2^(k + 1))      [бо для k ≥ 3 маємо 2k - 2 ≥ k + 1]
```

Отже, максимальний порядок будь-якого елемента за модулем 2^k дорівнює λ(2^k) = 2^(k−2).
Але φ(2^k) = 2^(k−1). Оскільки 2^(k−2) < 2^(k−1), жоден елемент не досягає порядку φ(2^k).
Первісного кореня не існує.

### Теорема 6 (Складені модулі з кількома простішими множниками)
Якщо n = a · b, де gcd(a, b) = 1 та a > 2, b > 2, то первісного кореня за модулем n не існує.

**Доказ.** Оскільки a > 2 та b > 2, значення φ(a) та φ(b) обидва є парними числами.
Нехай L = lcm(φ(a), φ(b)). Оскільки φ(a) та φ(b) мають спільний дільник 2:

```
L = lcm(φ(a), φ(b)) 
= (φ(a) · φ(b)) / gcd(φ(a), φ(b))    [вираження НСК через НСД]
≤ (φ(a) · φ(b)) / 2                   [бо gcd(φ(a), φ(b)) ≥ 2 через парність φ для a,b > 2]
= φ(n) / 2                           [мультиплікативність функції Ейлера]
```

Для будь-якого x, взаємно простого з n:
x^L ≡ (x^φ(a))^(L/φ(a)) ≡ 1^(L/φ(a)) ≡ 1 (mod a)
x^L ≡ (x^φ(b))^(L/φ(b)) ≡ 1^(L/φ(b)) ≡ 1 (mod b)

За китайською теоремою про залишки x^L ≡ 1 (mod n).
Оскільки L ≤ φ(n) / 2 < φ(n), порядок будь-якого елемента x не перевищує L, що суворо менше за φ(n).
Жоден елемент не може мати порядок φ(n). Первісного кореня не існує.

## Висновок (Критерій Ґаусса)
Об'єднуючи Частини 1, 2 та 3, отримуємо повну класифікацію Ґаусса:
Первісний корінь за модулем n існує **тоді й лише тоді**, коли n належить до однієї з чотирьох категорій:
1. n = 2
2. n = 4
3. n = p^k  (де p — непарне просте, k ≥ 1)
4. n = 2 · p^k  (де p — непарне просте, k ≥ 1)
