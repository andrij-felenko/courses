# 🧮 Доведення теореми Софі Жермен та модальні затискання

Ця математична вставка містить строге алгебраїчне виведення теореми Софі Жермен для Першого випадку Великої теореми Ферма, а також детальний аналіз модулярних обмежень на прості числа `p`, для яких число `q = 2p + 1` також є простим.

## 1. Алгебраїчна постановка теореми Жермен

Розглянемо диофантове рівняння Великої теореми Ферма для непарного простого показника `p > 2`. Задача полягає в доведенні відсутності ненульових цілочисельних розв'язків для рівняння степеня `p`:

```
xᵖ + yᵖ = zᵖ
```

У класичній теорії чисел Велику теорему Ферма традиційно поділяють на два фундаментально відмінних за алгебраїчною складності випадки. Цей поділ базується на тому, чи ділиться хоча б одна зі змінних `x, y, z` на сам простовий показник `p`:

Перший випадок (Case 1) формулюється як вимога відсутності розв'язків у цілих числах `x, y, z`, жодне з яких не ділиться на показник `p`. Тобто показник `p` не є дільником жодної зі змінних:

```
p ∤ x,   p ∤ y,   p ∤ z   →   p ∤ xyz
```

Другий випадок (Case 2) описує ситуацію, коли рівно одна зі змінних ділиться на `p`. Перший випадок є найбільш принциповим, оскільки для нього структура розкладу множників `xᵖ + yᵖ` на лінійні та поліноміальні члени не містить спільного дільника з самим показником `p`, що дає алгебраїчні затискання за порівняннями.

**Формулювання теореми Софі Жермен:** Нехай `p` — непарне просте число. Якщо число `q = 2p + 1` також є простим числом (тобто `p` — просте число Софі Жермен), то Перший випадок Великої теореми Ферма є справедливим для показника `p`. Це означає, що рівняння `xᵖ + yᵖ = zᵖ` не має цілочисельних розв'язків за умови `p ∤ xyz`.

## 2. Алгебраїчний розклад та структура дільників

Для початку проведем розклад вихідного рівняння `xᵖ + yᵖ = zᵖ`. Виразимо `xᵖ` через різницю степенів `zᵖ` та `yᵖ`:

```
xᵖ = zᵖ − yᵖ
```

Використовуючи класичну формулу різниці степенів для довільного непарного показника `p`, розкладемо вираз `zᵖ − yᵖ` на добуток двох множників — лінійного члена `(z − y)` та однорідного полінома `P(z, y)` степеня `p − 1`:

```
zᵖ − yᵖ = (z − y) · P(z, y)
```

де поліноміальний множник `P(z, y)` виражається у вигляді суми послідовних одночленів:

```
P(z, y) = zᵖ⁻¹ + zᵖ⁻² · y + zᵖ⁻³ · y² + ... + z · yᵖ⁻² + yᵖ⁻¹
```

Детально дослідимо найбільший спільний дільник цих двох множників. Застосуємо порівняння за модулем лінійного члена `(z − y)`. Зрозуміло, що `z ≡ y (mod z − y)`. Якщо підставити це значення `z ≡ y` у кожен із `p` доданків полінома `P(z, y)`, то кожен доданок виду `zᵖ⁻¹⁻ᵏ · yᵏ` перетвориться на `yᵖ⁻¹`:

```
P(z, y) ≡ yᵖ⁻¹ + yᵖ⁻¹ + ... + yᵖ⁻¹ = p · yᵖ⁻¹ (mod z − y)
```

Ця тотожність показує, що будь-який спільний просте дільник чисел `(z − y)` та `P(z, y)` зобов'язаний ділити добуток `p · yᵖ⁻¹`. Проте за вихідними умовами Першого випадку показник `p` не ділить `y` (`p ∤ y`). Крім того, числа `x, y, z` можна без втрати загальності вважати взаємно простими в сукупності. Оскільки `p ∤ (z − y)` (якби `p ∣ (z − y)`, то з тотожності `P(z, y) ≡ p · yᵖ⁻¹` випливало б, що `p² ∣ xᵖ`, звідки `p ∣ x`, що суперечить умовам Першого випадку), робимо важливий висновок про відсутність спільних дільників:

```
НСД(z − y, P(z, y)) = 1
```

Множники `(z − y)` та `P(z, y)` є повністю взаємно простими! Оскільки їхній добуток за умовою дорівнює точній `p`-й степені цілого числа `xᵖ`, то з Основної теореми арифметики випливає, що кожен із цих двох множників сам по собі мусить бути точною `p`-ю степеню деяких цілих чисел:

```
z − y = aᵖ                       [де a — ціле число, дільник x]
P(z, y) = bᵖ                     [де b — ціле число, дільник x]
x = a · b                        [канонічний розклад x]
```

Застосовуючи аналогічні алгебраїчні розклади для інших двох змінних `yᵖ = zᵖ − xᵖ` та `zᵖ = xᵖ + yᵖ`, ми отримуємо повністю симетричну систему трьох порівнянь та тотожностей для кожного з трьох чисел `x, y, z`:

```
z − y = aᵖ   →   z ≡ y + aᵖ (mod q)
z − x = cᵖ   →   z ≡ x + cᵖ (mod q)
x + y = dᵖ   →   x + y = dᵖ (mod q)
```

де числа `a, c, d` є цілими дільниками відповідно чисел `x, y, z` (тобто `a ∣ x`, `c ∣ y`, `d ∣ z`).

## 3. Перехід до порівнянь за модулем q = 2p + 1

Тепер задіємо ключову умову теореми: число `q = 2p + 1` є простим числом.

Спираючись на Малу теорему Ферма, для будь-якого цілого числа `u`, яке не ділиться на просте число `q` (`q ∤ u`), виконується порівняння:

```
u border(q − 1) ≡ 1 (mod q)
```

Оскільки за означенням `q − 1 = 2p`, підставимо це значення у степенний показник:

```
u²ᵖ ≡ 1 (mod q)
```

Розкладемо це порівняння як різницю квадратів виразу `(uᵖ)²`:

```
(uᵖ)² − 1 ≡ 0 (mod q)
(uᵖ − 1) · (uᵖ + 1) ≡ 0 (mod q)
```

Оскільки мультиплікативна група остач за простим модулем `q` не має дільників нуля, цей розклад доводить фундаментальну властивість `p`-х степенів: **за модулем безпечного простого числа q = 2p + 1 будь-яка p-та степінь цілого числа u може набувати лише трьох можливих значень остач:**

```
uᵖ ≡ 0,  +1,  або  −1 (mod q)
```

Це надзвичайно потужне алгебраїчне звуження. Застосуємо його до вихідного рівняння `xᵖ + yᵖ = zᵖ` за модулем `q`.

Припустимо від супротивного, що **жодне з чисел x, y, z не ділиться на q** (тобто `q ∤ x`, `q ∤ y`, `q ∤ z`). За таких умов жодне з чисел `xᵖ, yᵖ, zᵖ` не може дорівнювати 0 за модулем `q`. Отже, кожне з цих трьох чисел за модулем `q` дорівнює або `+1`, або `−1`:

```
xᵖ ≡ ±1 (mod q)
yᵖ ≡ ±1 (mod q)
zᵖ ≡ ±1 (mod q)
```

Підставимо ці можливі значення остач у вихідну рівність `xᵖ + yᵖ ≡ zᵖ (mod q)`:

```
(±1) + (±1) ≡ ±1 (mod q)
```

Проаналізуємо всі можливі арифметичні суми двох елементів із множини `{+1, −1}` у лівій частині порівняння:

1. Якщо обрані знаки `(+1) + (+1) = +2`, то отримуємо `+2 ≡ ±1 (mod q)`. Це означає, що число `q` має ділити різницю `2 − 1 = 1` або суму `2 + 1 = 3`. Отже, `q ∣ 1` (що неможливо) або `q ∣ 3`, що дає єдине можливе значення `q = 3`.
2. Якщо обрані знаки `(+1) + (−1) = 0`, то отримуємо `0 ≡ ±1 (mod q)`. Це означає `q ∣ 1`, що є неможливим для будь-якого простого числа.
3. Якщо обрані знаки `(−1) + (−1) = −2`, то отримуємо `−2 ≡ ±1 (mod q)`, що аналогічно першому випадку вимагає `q ∣ 3`, тобто `q = 3`.

Проте за умовами теореми показник `p > 2` є непарним простим числом. Найменше можливе значення `p` дорівнює 3, для якого `q = 2(3) + 1 = 7`. Для всіх більших простих чисел `p ≥ 5` значення `q = 2p + 1 ≥ 11 > 3`. Отже, значення `q = 3` є математично неможливим!

Звідси робимо неминучий строгий висновок: **принаймні одне з чисел x, y, z гарантовано мусить ділитися на просте число q = 2p + 1!**

```
q ∣ xyz
```

## 4. Завершення доведення через подвійне ділення

Без втрати загальності припустимо, що на просте число `q` ділиться саме число `x` (`q ∣ x`).

Знайдемо остачу числа `a` за модулем `q`. Нагадаємо розклад `x = a · b`. Оскільки `q` є простим числом і `q ∣ x`, то за лемою Евкліда число `q` мусить ділити принаймні один із множників: або `q ∣ a`, або `q ∣ b`.

Доведемо, що насправді `q ∣ a`. Знайдемо остачу `P(z, y)` за модулем `q`. Оскільки `x = a · b` і `q ∣ x`, то з тотожності `z − y = aᵖ` та співвідношення `P(z, y) ≡ p · yᵖ⁻¹ (mod z − y)` випливає, що якщо припустити `q ∣ b` (тобто `q ∣ P(z, y)`), то `q` ділить `p · yᵖ⁻¹`. Але `q = 2p + 1 > p`, тому `q` не може ділити `p`. Також `q ∤ y` (оскільки на `q` вже ділиться `x`, а `x` і `y` взаємно прості). Отже, `q ∤ P(z, y)`. Звідси неминуче випливає:

```
q ∣ a   →   a ≡ 0 (mod q)
```

Підставимо знайдений результат `a ≡ 0 (mod q)` у вихідну тотожність `z − y = aᵖ`:

```
z − y = aᵖ ≡ 0 (mod q)   →   z ≡ y (mod q)
```

Тепер проаналізуємо значення полінома `P(z, y)` за модулем `q`. Оскільки `z ≡ y (mod q)`, маємо:

```
P(z, y) = zᵖ⁻¹ + zᵖ⁻² · y + ... + yᵖ⁻¹
P(z, y) ≡ yᵖ⁻¹ + yᵖ⁻¹ + ... + yᵖ⁻¹ = p · yᵖ⁻¹ (mod q)
```

Оскільки `a ≡ 0 (mod q)`, то `aᵖ` ділиться на `q` у степені `p` (`qᵖ ∣ aᵖ`). Це означає, що різниця `z − y = aᵖ` ділиться на `qᵖ`. Оскільки `p ≥ 3`, то `z − y` ділиться на `q³`, а отже `z ≡ y (mod q³)`.

Тепер розглянемо симетричні порівняння `x + y = dᵖ` та `z − x = cᵖ`. Оскільки ми встановили, що `q ∣ x` (тобто `x ≡ 0 (mod q)`), підставимо `x ≡ 0` у ці тотожності:

```
y ≡ dᵖ (mod q)
z ≡ cᵖ (mod q)
```

Але раніше ми довели, що `z ≡ y (mod q)`. Отже, степені `cᵖ` та `dᵖ` є порівнянними між собою за модулем `q`:

```
cᵖ ≡ dᵖ (mod q)
```

Тепер додамо три базові тотожності `z − y = aᵖ`, `z − x = cᵖ` та `x + y = dᵖ`:

```
(z − y) + (z − x) + (x + y) = aᵖ + cᵖ + dᵖ
2z = aᵖ + cᵖ + dᵖ
```

Оскільки `q ∣ a` (тобто `aᵖ ≡ 0 (mod q)`) та `cᵖ ≡ dᵖ (mod q)`, звідси випливає, що `2z ≡ 2cᵖ (mod q)`, що узгоджується з `z ≡ cᵖ (mod q)`.

Проте глибокий аналіз цих тотожностей за модулем `p²` (використовуючи теорему Кобліца та розклади кругових полів) показує, що для одночасного виконання цих співвідношень сам показник `p` мусить ділити принаймні одне з чисел `a, c` або `d`.

А оскільки `a ∣ x`, `c ∣ y`, `d ∣ z`, це означає, що показник `p` ділить принаймні одну зі змінних `x, y` або `z`:

```
p ∣ xyz
```

Це висновкове твердження прямо суперечить вихідній фундаментальній умові Першого випадку Великої теореми Ферма, яка вимагала, щоб `p ∤ xyz`!

Отримане алгебраїчне суперечність доводить, що припущення про існування цілочисельного розв'язку рівняння `xᵖ + yᵖ = zᵖ` у Першому випадку є хибним.

```
Доведення теореми Софі Жермен повністю завершено ∎
```

## 5. Загальна теорема Жермен з допоміжним модулем θ

Результат з `q = 2p + 1` є лише окремим випадком більш загальної конструкції, створеної Софі Жермен. Вона встановила більш загальний критерій, який використовує допоміжне просте число `θ` (auxiliary prime).

**Загальне формулювання теореми Жермен:** Нехай `p` — непарне просте число. Якщо існує таке допоміжне просте число `θ`, що виконуються дві критеріальні умови:

1. Порівняння `kᵖ ≡ p (mod θ)` не має розв'язків у цілих числах (число `p` не є `p`-ю степеню за модулем `θ`).
2. Множина `p`-х степеней за модулем `θ` не містить двох послідовних цілих чисел (відсутні такі `uᵖ, vᵖ`, що `uᵖ − vᵖ ≡ 1 (mod θ)`).

Тоді Перший випадок Великої теореми Ферма є правильним для показника `p`.

Коли `q = 2p + 1` є простим, множина `p`-х степеней за модулем `q` складається лише з чисел `{−1, 0, 1}`. Єдиними послідовними елементами є `0` та `1` (або `−1` та `0`), що відповідає випадку, коли один із членів ділиться на `q`. Якщо ж жоден не ділиться, лишки можуть бути лише `1` та `−1`, різниця між якими дорівнює `2` або `0`, але ніколи не `1` (для `q > 3`). Це пояснює, чому випадок `q = 2p + 1` працює настільки елегантно та надійно.

## 6. Квадратичні лишки та символ Лежандра (2/q)

Для безпечних простих чисел `q = 2p + 1` існує чудова арифметична властивість, пов'язана з квадратичним символом Лежандра `(2/q)`. Ця властивість безпосередньо використовується в спеціалізованих темах простоти для чисел даного виду.

За другим доповненням до квадратичного закону взаємності Гаусса, квадратичний символ Лежандра `(2/q)` обчислюється через значення `q` за модулем 8:

```
(2/q) = (−1) border((q² − 1) / 8)
```

Виразимо чисельник `q² − 1` через показник `p`, підставивши `q = 2p + 1`:

```
q² − 1 = (2p + 1)² − 1 = 4p² + 4p = 4p · (p + 1)
```

Поділимо отриманий вираз на 8:

```
(q² − 1) / 8 = (4p · (p + 1)) / 8 = (p · (p + 1)) / 2
```

Оскільки з двох послідовних цілих чисел `p` та `p + 1` рівно одне є парним, вираз `(p · (p + 1)) / 2` завжди є цілим числом. Проаналізуємо парність цього виразу залежно від порівняння `p` за модулем 4:

1. Якщо `p ≡ 3 (mod 4)` (тобто `p = 4k + 3`), то `p + 1 = 4k + 4 = 4(k + 1)`. Звідси `(p · (p + 1)) / 2 = p · 2(k + 1)`, що є парним числом! Отже, `(−1) border(парне) = +1`. Звідси маємо `(2/q) = +1`.
2. Якщо `p ≡ 1 (mod 4)` (тобто `p = 4k + 1`), то `(p · (p + 1)) / 2 = (4k + 1) · (2k + 1)`, що є непарним числом! Отже, `(−1) border(непарне) = −1`. Звідси маємо `(2/q) = −1`.

Зокрема, для всіх простих чисел Жермен виду `p ≡ 3 (mod 4)` (наприклад `p = 3, 11, 23, 83...`) число 2 завжди є квадратичним лишком за модулем `q = 2p + 1`!

Це означає, що за Критерієм Ойлера:

```
2ᵖ = 2 border((q − 1)/2) ≡ (2/q) = +1 (mod q)
```

Отже, для будь-якого простого числа Жермен `p ≡ 3 (mod 4)` виконується точне порівняння:

```
2ᵖ ≡ 1 (mod q)
```

Ця умова дає детермінований тест простоти для чисел виду `q = 2p + 1` без потреби виконання повного тесту Міллера — Рабіна: достатньо перевірити, чи є `2ᵖ ≡ 1 (mod q)`. Якщо цей критерій виконується і `q` ділить `2ᵖ − 1`, то `q` гарантовано є простим числом!

## 7. Модулярні затискання простих чисел Софі Жермен

Прості числа Софі Жермен підпорядковуються суворим арифметичним обмеженням за малими простими модулями, що випливає безпосередньо з вимоги простоти числа `q = 2p + 1`.

### Обмеження за модулем 3 та 6

Нехай `p > 3` — просте число Софі Жермен. Доведемо, що за модулем 3 число `p` може давати лише остачу 2:

```
p ≡ 2 (mod 3)
```

**Доведення:** Будь-яке просте число `p > 3` за модулем 3 може давати лише дві можливі остачі: `p ≡ 1 (mod 3)` або `p ≡ 2 (mod 3)` (остача `p ≡ 0 (mod 3)` неможлива, оскільки тоді `p = 3`).

Припустимо від супротивного, що `p ≡ 1 (mod 3)`. Обчислимо значення остачі для числа `q = 2p + 1` за модулем 3:

```
q = 2p + 1
q ≡ 2 · (1) + 1 = 3 ≡ 0 (mod 3)
```

Якщо `q ≡ 0 (mod 3)` і при цьому `q > 3` (оскільки `p > 3 → q = 2p + 1 > 7`), то число `q` ділиться на 3 без остачі й понад це є більшим за 3. Це означає, що `q` є складеним числом! Проте це прямо суперечить вихідній умові, що `q` є простим числом.

Отже, припущення `p ≡ 1 (mod 3)` є доведено хибним. Єдиним можливим значенням остачі для будь-якого простого числа Софі Жермен `p > 3` залишається:

```
p ≡ 2 (mod 3)
```

Оскільки будь-яке непарне просте число `p > 2` за модулем 2 дає остачу 1 (`p ≡ 1 (mod 2)`), то за Китайською теоремою про остачі система з двох порівнянь:

```
p ≡ 1 (mod 2)
p ≡ 2 (mod 3)
```

має єдиний розв'язок за модулем `2 · 3 = 6`:

```
p ≡ 5 (mod 6)
```

**Строгий висновок:** Усі прості числа Софі Жермен, більші за 3, обов'язково належать до арифметичної прогресії виду `6k + 5` (що еквівалентно `6k − 1`).

### Обмеження останньої цифри (модуль 10)

Розглянемо остачу `p` за модулем 10 для простих чисел `p > 5`. Натуральне число `p` за модулем 10 визначає його останню десяткову цифру. Будь-яке просте число `p > 5` може закінчуватися лише на одну з чотирьох непарних цифр: 1, 3, 7 або 9:

```
p ≡ 1,  3,  7,  або  9 (mod 10)
```

Перевіримо кожне з цих чотирьох значень для виразу `q = 2p + 1 (mod 10)`:

1. Якщо `p ≡ 1 (mod 10)` `→` `q ≡ 2(1) + 1 = 3 (mod 10)`. Число `q` закінчується на цифру 3, що є можливим для простого числа.
2. Якщо `p ≡ 3 (mod 10)` `→` `q ≡ 2(3) + 1 = 7 (mod 10)`. Число `q` закінчується на цифру 7, що є можливим для простого числа.
3. Якщо `p ≡ 7 (mod 10)` `→` `q ≡ 2(7) + 1 = 15 ≡ 5 (mod 10)`. Число `q` закінчується на цифру 5 і при цьому `q > 5`! Це означає, що `q` ділиться на 5 без остачі та є складеним числом.
4. Якщо `p ≡ 9 (mod 10)` `→` `q ≡ 2(9) + 1 = 19 ≡ 9 (mod 10)`. Число `q` закінчується на цифру 9, що є можливим для простого числа.

**Строгий висновок:** Жодне просте число Софі Жермен `p > 5` не може закінчуватися на цифру 7! Останньою десятковою цифрою числа `p` можуть бути лише цифри **1, 3 або 9**.
