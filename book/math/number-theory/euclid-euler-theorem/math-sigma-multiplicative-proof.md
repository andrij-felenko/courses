# Мультиплікативність функції суми дільників

Функція σ(n), яка визначає суму всіх додатних дільників натурального числа n, має надзвичайно корисну властивість: вона є мультиплікативною. Це означає, що для будь-яких двох взаємно простих натуральних чисел a та b (тобто таких, що їхній найбільший спільний дільник НСД(a, b) = 1) виконується рівність σ(a · b) = σ(a) · σ(b). Розуміння цього факту є ключовим для доведення теореми Евкліда — Ейлера.

Щоб довести цю властивість, розглянемо структуру дільників числа N = a · b, де a та b взаємно прості. Нехай a має дільники d₁, d₂, ..., dₖ, а b має дільники c₁, c₂, ..., cₘ. Оскільки a та b не мають спільних простих множників, будь-який дільник D числа a · b можна однозначно подати у вигляді добутку одного дільника числа a та одного дільника числа b, тобто D = dᵢ · cⱼ для деяких i та j.

Спробуємо виписати суму всіх дільників D числа N:
σ(a · b) = ∑ (dᵢ · cⱼ), де підсумовування ведеться по всіх можливих комбінаціях 1 ≤ i ≤ k та 1 ≤ j ≤ m.

Якщо ми розгорнемо цей подвійний сум, ми побачимо, що його можна згрупувати. Наприклад, винесемо c₁:
(d₁ · c₁ + d₂ · c₁ + ... + dₖ · c₁) + (d₁ · c₂ + d₂ · c₂ + ... + dₖ · c₂) + ...
= c₁ · (d₁ + d₂ + ... + dₖ) + c₂ · (d₁ + d₂ + ... + dₖ) + ... + cₘ · (d₁ + d₂ + ... + dₖ)

Вираз у дужках (d₁ + d₂ + ... + dₖ) є не чим іншим, як сумою всіх дільників числа a, тобто σ(a). Отже, ми можемо винести σ(a) за дужки:
σ(a · b) = σ(a) · (c₁ + c₂ + ... + cₘ).

А вираз у других дужках — це сума всіх дільників числа b, тобто σ(b). Таким чином, ми отримуємо:
σ(a · b) = σ(a) · σ(b).

Цей елегантний доказ спирається виключно на дистрибутивний закон арифметики та основну теорему арифметики (однозначність розкладу на прості множники), яка гарантує, що жоден дільник не буде пропущений або порахований двічі, оскільки a та b взаємно прості.

Для наочності розглянемо приклад: a = 4, b = 3. Ці числа взаємно прості (НСД(4, 3) = 1).
Дільники 4: 1, 2, 4. Їхня сума σ(4) = 1 + 2 + 4 = 7.
Дільники 3: 1, 3. Їхня сума σ(3) = 1 + 3 = 4.
Добуток a · b = 12. Дільники 12: 1, 2, 3, 4, 6, 12.
Їхня сума σ(12) = 1 + 2 + 3 + 4 + 6 + 12 = 28.
Перевіримо мультиплікативність: σ(4) · σ(3) = 7 · 4 = 28. Як бачимо, σ(12) = σ(4) · σ(3).

Завдяки мультиплікативності, обчислення суми дільників зводиться до обчислення σ(pⁿ) для простих чисел p, що надзвичайно спрощує аналіз досконалих чисел.
