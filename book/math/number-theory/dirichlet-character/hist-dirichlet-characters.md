# 📜 Від дільників до спектра: винайдення характерів Діріхле

Навесні 1837 року тридцятидворічний німецький математик Петер Ґустав Лежен Діріхле подав до Прусської академії наук у Берліні праці, яка назавжди змінила обличчя теорії чисел. Стаття мала назву «Доведення теореми про те, що кожна нескінченна арифметична прогресія, перший член і різниця якої не мають спільних дільників, містить нескінченно багато простих чисел». Щоб розв'язати цю проблему, над якою понад пів століття безрезультатно билися найвидатніші розуми Європи, Діріхле довелося створити принципово новий математичний апарат — арифметичні характери та аналітичні ряди, що пізніше отримали його ім'я.

Цей історичний екскурс простежує шлях від епохальних спостережень П'єра де Ферма та Леонарда Ейлера через фундаментальну праці Карла Фрідріха Ґаусса до аналітичного відкриття Діріхле і подальшого розквіту теорії груп у працях Дедекінда, Вебера та Понтрягіна.

## 1. Спадщина Ґаусса та глухий кут комбінаторики

Початок XIX століття у теорії чисел пройшов під знаком фундаментальної праці Карла Фрідріха Ґаусса *Disquisitiones Arithmeticae* (1801). Ґаусс систематизував теорію порівнянь за модулем, ввів уявлення про приведені системи залишків, побудував теорію квадратичних лишків та довів квадратичний закон взаємності за допомогою символу Лежандра.

Символ Лежандра `(a/p)`, винайдений Адрієном-Марі Лежандром у 1798 році, показував, чи є число `a` квадратичним лишком за простим модулем `p`:

```
(a/p) =  1,  якщо a ≡ x² (mod p) для деякого x ≢ 0 (mod p)
(a/p) = -1,  якщо a не є квадратичним лишком (mod p)
(a/p) =  0,  якщо a ≡ 0 (mod p)
```

Цей символ мав надзвичайно важливу алгебраїчну властивість — він був повністю мультиплікативним: `(ab/p) = (a/p) · (b/p)`. Крім того, він мав період `p` за аргументом `a`. Фактично символ Лежандра був першим історичним прикладом дійснозначного нетривіального характера Діріхле за простим модулем.

Однак символ Лежандра розрізняв лише два класи залишків — квадратичні лишки та нелишки. Коли математики намагалися дослідити розподіл простих чисел у довільних арифметичних прогресіях `a + k·q`, елементарні комбінаторні методи виявлялися безсилими.

Евклідове доведення нескінченності простих чисел спиралося на алгебраїчну конструкцію `N = p₁ · p₂ · ... · pₖ + 1`. Двома століттями пізніше це доведення вдалося адаптувати для прогресії `4k + 3` (розглядаючи `N = 4 p₁...pₖ - 1`) та для прогресії `3k + 2`. Проте вже для дзеркального класу `4k + 1` елементарна побудова зазнавала краху, бо добуток двох чисел вигляду `4k + 3` знову дає остаток `1 (mod 4)`:

```
(4x + 3)(4y + 3) = 16xy + 12x + 12y + 9 = 4(4xy + 3x + 3y + 2) + 1 ≡ 1 (mod 4)
```

Отже, складене число вигляду `4k + 1` могло не мати жодного простого дільника вигляду `4k + 1`. Загальний випадок прогресії `a + k·q` для довільних взаємно простих чисел `a` та `q` вимагав принципово іншої ідеї.

## 2. Ідея Ейлера та аналітичний прорив Діріхле

У 1737 році Леонард Ейлер здійснив перший аналітичний прорив, навчившись лічити прості числа за допомогою нескінченних рядів. Ейлер довів, що сума обернених величин усіх простих чисел розбігається:

```
∑_{p ∈ P} 1 / p = ∞
```

Це доведення спиралося на знамениту тотожність Ейлерового добутку для дзета-функції:

```
ζ(s) = ∑_{n=1}^∞ 1 / nˢ = ∏_{p ∈ P} (1 - 1 / pˢ)⁻¹
```

Мультиплікативність функції `f(n) = 1` дозволяла розкласти суму за всіма натуральними числами у нескінченний добуток за простими числами. Але коли Діріхле спробував застосувати підхід Ейлера до конкретної прогресії `a + k·q`, він зіткнувся з нездоланною перешкодою.

Щоб виділити лише ті прості числа `p`, які при діленні на `q` дають остаток `a`, природно підставити в ряд дельта-функцію остачі `δ(n ≡ a mod q)`:

```
F(s) = ∑_{n=1}^∞ δ(n ≡ a mod q) / nˢ
```

Але індикатор класу остач **не є мультиплікативним**. Для двох чисел `m` та `n` значення `δ(m·n ≡ a)` аж ніяк не дорівнює `δ(m ≡ a) · δ(n ≡ a)`. Наприклад, при `q = 4`, `a = 1` числа `m = 3` та `n = 3` самі не належать до класу `1 (mod 4)` (для них індикатор дорівнює 0), але їхній добуток `3 · 3 = 9 ≡ 1 (mod 4)` належить до цього класу (індикатор дорівнює 1).

Втрата мультиплікативності означала руйнування Ейлерового добутку. Без розкладу на множники за простими числами аналітичний ряд втрачав будь-який зв'язок із простими дільниками.

Геніальна здогадка Діріхле полягала у застосуванні ідей гармонічного аналізу (Фурьє) до скінченних абелевих груп. Жан-Батіст Жозеф Фур'є у 1822 році показав, що будь-яку періодичну функцію на відрізку можна розкласти у суму синусів і косинусів. Діріхле зрозумів: дельта-функцію на скінченній групі залишків `(ℤ/qℤ)*` можна розкласти у лінійну комбінацію періодичних та **повністю мультиплікативних** комплексних функцій!

## 3. Народження характерів та L-функцій

Діріхле назвав ці функції «спеціальними множниками» (*besondere Factoren*). Лише пізніше Ріхард Дедекінд увів для них сучасний термін **характер** (від грецького *charaktēr* — карб, відбиток, ознака).

Діріхле побудував характери за допомогою первісних коренів Ґаусса. Якщо модуль `q` має первісний корінь `g`, то будь-яке взаємно просте з `q` число `n` можна однозначно подати через дискретний логарифм (індекс): `n ≡ gⁱ (mod q)`. Тоді Діріхле визначив `φ(q)` різних характерів через комплексні корені з одиниці:

```
χₖ(n) = exp(2 π i · k · ind_g(n) / φ(q))
```

Ці функції володіли двома магічними властивостями одночасно:
1. Вони були повністю мультиплікативними: `χ(m·n) = χ(m)·χ(n)`.
2. Вони задовольняли співвідношення ортогональності, що дозволяло виразити дельта-функцію класу залишків як рівномірну суму за всіма характерами:

```
δ(n ≡ a mod q) = (1 / φ(q)) · ∑_{χ mod q} χ̄(a) · χ(n)
```

Завдяки цьому підстановка дельта-функції в аналітичний ряд більше не руйнувала Ейлерів добуток. Ряд розпадався на комбінацію нових функцій, які Діріхле назвав `L`-рядами:

```
L(s, χ) = ∑_{n=1}^∞ χ(n) / nˢ = ∏_{p ∈ P} (1 - χ(p) / pˢ)⁻¹
```

Головною важкістю доведення Діріхле було довести, що для будь-якого нетривіального характера `χ ≠ χ₀` значення ряду в точці `s = 1` не дорівнює нулю: `L(1, χ) ≠ 0`. Для комплексних характерів Діріхле довів це аналітично через логарифмування, а для дійснозначних нетривіальних характерів — обчисливши зв'язок `L(1, χ)` із числом класів квадратичних форм (знаменита *Dirichlet class number formula*). Оскільки `L(1, χ) ≠ 0`, сума обернених величин простих чисел у прогресії `a + k·q` виявилася розбіжною:

```
∑_{p ≡ a mod q} 1 / p = ∞
```

Це остаточно довело нескінченність кількості простих чисел у кожній допустимій арифметичній прогресії.

## 4. Від аркуша Діріхле до дуальності Понтрягіна

Праця Діріхле 1837 року стала заставою створення аналітичної теорії чисел. Однак алгебраїчна краса створеного ним інструменту виявилася значно ширшою за початкову задачу про прості числа.

У 1879 році Ріхард Дедекінд у своїх доповненнях до «Лекцій з теорії чисел» Діріхле зробив важливий узагальнювальний крок. Він звільнив означення характера від прив'язки до чисел і дискретних логарифмів, визначивши характер як гомоморфізм з довільної скінченної абелевої групи `G` у мультиплікативну групу комплексних чисел `ℂ*`.

На початку XX століття Генріх Вебер розробив загальну теорію характерів для скінченних абелевих груп, довівши, що множина всіх характерів утворює двоїсту групу `Ĝ`, яка ізоморфна самій групі `G`.

У 1930-х роках Лев Понтрягін поширив поняття характера на нескінченні локально компактні абелеві групи (двоїстість Понтрягіна). Виявилося, що характери Діріхле — це лише найпростіший випадок гармонічного аналізу на топологічних групах:
* Для кола `S¹` характерами є степені `e^{i n θ}` (класичні ряди Фур'є).
* Для дійсної прямої `ℝ` характерами є експоненти `e^{i ω x}` (перетворення Фур'є).
* Для скінченної групи залишків `(ℤ/qℤ)*` характерами є саме характери Діріхле.

Таким чином, винайдення характерів Діріхле у 1837 році не лише розв'язало столітню арифметичну проблему, а й заклало фундамент абстрактної алгебри, спектральної теорії груп та сучасного гармонічного аналізу, що лежить в основі обробки сигналів, квантової механіки та криптографії.
