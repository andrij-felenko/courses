# 🧮 Алгебраїчні властивості, модуль та доведення знаку сум Гаусса

Сума Ґаусса є фундаментальним алгебраїчним об'єктом теорії чисел та гармонічного аналізу над скінченними полями. Вона поєднує мультиплікативні характери `χ` групи лишків `𝔽ₚ*` із адитивними характерами `ψ(a) = e^(2π i a / p)`.

У цій вставці наведено детальні й строгі алгебраїчні виведення головних властивостей сум Ґаусса: виведення модуля `|g(χ)| = √p`, визначення значення квадрата суми `g(1, p)² = p*`, повне доведення квадратичного закону взаємності, алгебраїчний розбір знаку суми Ґаусса, а також співвідношення Девенпорта–Хассе для розширень полів.

---

### 1. Поняття характерів та ортогональність над скінченними полями

Нехай `p` — непарне просте число, а `𝔽ₚ = ℤ/pℤ` — скінченне поле з `p` елементів. Мультиплікативна група `𝔽ₚ* = {1, 2, ..., p - 1}` є циклічною групою порядку `p - 1`.

- **Мультиплікативний характер** `χ: 𝔽ₚ* → ℂ*` є гомоморфізмом груп, який задовольняє `χ(a · b) = χ(a) · χ(b)` для всіх `a, b ∈ 𝔽ₚ*`. Оскільки `a^(p-1) ≡ 1 mod p`, усі значення `χ(a)` є коренями `(p-1)`-го степеня з одиниці в комплексному полі `ℂ`.
- Доповнимо характер на все поле `𝔽ₚ`, поклавши `χ(0) = 0` для будь-якого нетривіального характеру, та `χ₀(0) = 1` для тривіального характеру `χ₀(a) = 1`.
- **Сопряжений характер** `χ̄` задається формулою `χ̄(a) = χ(a)⁻¹ = χ(a)*` (де `*` означає комплексне спряження).

Фундаментальною властивістю характерів є їхні **співвідношення ортогональності**:

```
∑_{a ∈ 𝔽ₚ*} χ(a) = { p - 1,  якщо χ = χ₀ (тривіальний характер)
                   { 0,      якщо χ ≠ χ₀ (нетривіальний характер)
```

Аналогічно, для адитивного характеру `ψ(a) = e^(2π i a / p)` сума по всьому полю дорівнює:

```
∑_{a ∈ 𝔽ₚ} e^(2π i a n / p) = { p,  якщо n ≡ 0 (mod p)
                               { 0,  якщо n ≢ 0 (mod p)
```

### 2. Модуль загальної суми Ґаусса: строге виведення |g(χ)| = √p

Сума Ґаусса для мультиплікативного характеру `χ` та адитивної фази задається формулою:

```
g(χ) = ∑_{a ∈ 𝔽ₚ} χ(a) · e^(2π i a / p)
```

**Теорема 1.** Для будь-якого нетривіального характеру `χ mod p` модуль суми Ґаусса дорівнює `√p`, а саме:

```
g(χ) · g(χ̄) = χ(-1) · p    ⇒    |g(χ)|² = p
```

#### Покрокове виведення:

Розглянемо добуток двох сум `g(χ)` та `g(χ̄)`:

```
g(χ) · g(χ̄)
= ( ∑_{a ∈ 𝔽ₚ} χ(a) · e^(2π i a / p) ) · ( ∑_{b ∈ 𝔽ₚ} χ̄(b) · e^(2π i b / p) )
  [визначення добутку двох сум]

= ∑_{a ∈ 𝔽ₚ} ∑_{b ∈ 𝔽ₚ} χ(a) · χ̄(b) · e^(2π i (a + b) / p)
  [розкриття дужок і об'єднання у подвійну суму]
```

Оскільки `χ(0) = 0`, значення `b = 0` не дає внеску в суму. Для кожного ненульового `b ∈ 𝔽ₚ*` зробимо заміну змінної підсумовування `a = t · b` у групі `𝔽ₚ*`. Оскільки `b` є оборотним за модулем `p`, при фіксованому `b` елемент `t` однозначно визначається як `t = a · b⁻¹`. Коли `t` пробігає всі ненульові елементи `𝔽ₚ*`, `a = t · b` також пробігає `𝔽ₚ*` підряд без повторень:

```
= ∑_{t ∈ 𝔽ₚ*} ∑_{b ∈ 𝔽ₚ*} χ(t·b) · χ̄(b) · e^(2π i (t·b + b) / p)
  [заміна змінної підсумовування a = t · b]

= ∑_{t ∈ 𝔽ₚ*} ∑_{b ∈ 𝔽ₚ*} χ(t) · χ(b) · χ̄(b) · e^(2π i b (t + 1) / p)
  [використання мультиплікативності характеру χ(t·b) = χ(t) · χ(b)]

= ∑_{t ∈ 𝔽ₚ*} χ(t) · ( ∑_{b ∈ 𝔽ₚ*} χ(b)·χ̄(b) · e^(2π i b (t + 1) / p) )
  [винесення множника χ(t) за дужки внутрішньої суми по b]

= ∑_{t ∈ 𝔽ₚ*} χ(t) · ( ∑_{b ∈ 𝔽ₚ*} 1 · e^(2π i b (t + 1) / p) )
  [умова нормування характерів: χ(b) · χ̄(b) = |χ(b)|² = 1 для будь-якого b ≠ 0]
```

Розглянемо внутрішню суму `S(t) = ∑_{b ∈ 𝔽ₚ*} e^(2π i b (t + 1) / p)`.

Згадаймо ортогональність суми експонент по повному полю `𝔽ₚ`:
- Якщо `t + 1 ≡ 0 (mod p)` (тобто `t = -1`), то `e^(2π i b · 0 / p) = 1`. Сума по всіх `b ∈ 𝔽ₚ*` містить `p - 1` доданків, кожен з яких дорівнює 1. Отже, `S(-1) = p - 1`.
- Якщо `t + 1 ≢ 0 (mod p)` (тобто `t ≠ -1`), то сума по всьому полю від `b = 0` до `p - 1` дорівнює нулю. Віднімаючи доданок для `b = 0` (який дорівнює 1), отримуємо `S(t) = 0 - 1 = -1`.

Підставимо ці два значення `S(t)` у зовнішню суму по `t`:

```
g(χ) · g(χ̄)
= χ(-1) · S(-1) + ∑_{t ≠ -1, t ∈ 𝔽ₚ*} χ(t) · S(t)
  [відокремлення додатка t = -1 від решти сум]

= χ(-1) · (p - 1) + ∑_{t ≠ -1, t ∈ 𝔽ₚ*} χ(t) · (-1)
  [підстановка обчислених значень S(-1) = p - 1 та S(t) = -1]

= χ(-1) · (p - 1) - ∑_{t ≠ -1, t ∈ 𝔽ₚ*} χ(t)
  [винесення знака мінус за суму]
```

Оскільки характер `χ` є нетривіальним, його повна сума по всіх елементах `𝔽ₚ*` дорівнює нулю: `∑_{t ∈ 𝔽ₚ*} χ(t) = 0`.
Звідси сума без одного елемента `t = -1` дорівнює:

```
∑_{t ≠ -1, t ∈ 𝔽ₚ*} χ(t) = -χ(-1)
```

Підставимо це вираження:

```
= χ(-1) · (p - 1) - ( -χ(-1) )
  [підстановка суми решти елементів]

= χ(-1) · (p - 1) + χ(-1)
  [спрощення знаків]

= χ(-1) · (p - 1 + 1)
  [винесення спільне χ(-1) за дужки]

= χ(-1) · p
  [остаточний алгебраїчний результат]
```

Оскільки `χ̄(a) = χ(a)*`, маємо `g(χ̄) = χ(-1) · g(χ)*` (де `*` — комплексне спряження).
Тоді:

```
g(χ) · χ(-1) · g(χ)* = χ(-1) · p    ⇒    g(χ) · g(χ)* = p    ⇒    |g(χ)|² = p
```

Теорему 1 доведено повністю. ∎

### 3. Квадратична сума Ґаусса та обчислення її квадрата g(1, p)²

Розглянемо випадок, коли характер `χ` є квадратичним символом Лежандра `χ(a) = (a/p)`.
Сума Ґаусса для квадратичного характеру записується як:

```
g(1, p) = ∑_{n=0}^{p-1} e^(2π i n² / p)
```

Покажемо еквівалентність подання через квадрати `n²` та через символ Лежандра `(a/p)`:

```
∑_{n=0}^{p-1} e^(2π i n² / p)
= e⁰ + ∑_{a — лишок} 2 · e^(2π i a / p) + ∑_{b — нелишок} 0 · e^(2π i b / p)
  [кожен лишок a має 2 корені n, нелишки мають 0 коренів]

= ∑_{a=0}^{p-1} (1 + (a/p)) · e^(2π i a / p)
  [підстановка формули кількості розв'язків 1 + (a/p)]

= ∑_{a=0}^{p-1} e^(2π i a / p) + ∑_{a=0}^{p-1} (a/p) · e^(2π i a / p)
  [розбиття на дві суми]

= 0 + ∑_{a=1}^{p-1} (a/p) · e^(2π i a / p)
  [перша сума дорівнює 0, а (0/p) = 0]
```

Оскільки для квадратичного характеру `(a/p) ∈ {-1, 1} ⊂ ℝ`, характер збігається зі своїм спряженим `χ̄ = χ`.
Застосовуючи Теорему 1, маємо:

```
g(1, p)² = (a/p)(-1) · p = (-1)^((p-1)/2) · p = p*
```

Де позначають:
- `p* = p`, якщо `p ≡ 1 (mod 4)`.
- `p* = -p`, якщо `p ≡ 3 (mod 4)`.

### 4. Алгебраїчне доведення квадратичного закону взаємності

Нехай `p` та `q` — два різних непарних простих числа. Розглянемо квадратичну суму Ґаусса `g = g(1, p)` як елемент кільця цілих алгебраїчних чисел `R = ℤ[ζ_p]`, де `ζ_p = e^(2π i / p)`.

Ми знаємо, що `g² = p* = (-1)^((p-1)/2) · p`.

#### Крок 1. Піднесення g до степеня q за модулем q

Розглянемо вираз `g^q (mod q R)`. За першою властивістю бінома Ньютона за простим модулем `q`, для довільних елементів `x, y ∈ R` маємо `(x + y)^q ≡ x^q + y^q (mod q R)`:

```
g^q = ( ∑_{a=1}^{p-1} (a/p) · ζ_pᵃ )^q
≡ ∑_{a=1}^{p-1} (a/p)^q · ζ_pᵃ·ʲ (mod q R)
  [піднесення суми до степеня q за модулем q]

= ∑_{a=1}^{p-1} (a/p) · ζ_pᵃ·ʲ
  [оскільки (a/p) = ±1, маємо (a/p)^q = (a/p) для будь-якого непарного q]
```

Зробимо заміну змінної `x = a · q (mod p)` у групі `𝔽ₚ*`. Оскільки `q` та `p` взаємно прості, елемент `x` пробігає `𝔽ₚ*` підряд:

```
= ∑_{x=1}^{p-1} (x·q⁻¹ / p) · ζ_pˣ
  [підстановка a = x · q⁻¹ mod p]

= (q⁻¹ / p) · ∑_{x=1}^{p-1} (x/p) · ζ_pˣ
  [винесення мультиплікативного фактора (q⁻¹/p) за суму]

= (q/p) · g
  [оскільки (q⁻¹/p) = (q/p) ∈ {-1, 1}]
```

#### Крок 2. Зв'язок із малою теоремою Ферма

З іншого боку, перегрупуємо `g^q` через `g²`:

```
g^q = g · (g²)^((q-1)/2) = g · (p*)^((q-1)/2)
```

За критерієм Ейлера для символу Лежандра `(p*/q) ≡ (p*)^((q-1)/2) (mod q)`:

```
g^q ≡ g · (p*/q) (mod q R)
```

#### Крок 3. Зведення тотожностей

Порівняємо обидва вирази для `g^q` за модулем `q R`:

```
g · (q/p) ≡ g · (p*/q) (mod q R)
```

Помножимо обидві частини порівняння на `g`. Оскільки `g² = p*`, маємо:

```
p* · (q/p) ≡ p* · (p*/q) (mod q R)
```

Оскільки `p*` взаємно просте з `q`, ми можемо скоротити на `p*`:

```
(q/p) ≡ (p*/q) (mod q R)
```

Обидва символи Лежандра `(q/p)` та `(p*/q)` належать множині `{-1, 1}`. Для будь-якого непарного простого числа `q ≥ 3`, різниця між `1` та `-1` дорівнює `2`, що не ділиться на `q`. Отже, порівняння за модулем `q` означає **точну рівність**:

```
(q/p) = (p*/q) = ( (-1)^((p-1)/2) · p / q ) = (-1)^((p-1)/2 · (q-1)/2) · (p/q)
```

Помноживши обидві частини на `(p/q)`, ми отримуємо класичний **квадратичний закон взаємності**:

```
(p/q) · (q/p) = (-1)^((p-1)/2 · (q-1)/2)
```

Квадратичний закон взаємності доведено повністю. ∎

### 5. Доведення точного знаку Ґаусса (метод визначника Вандермонда)

Точний знак суми Ґаусса визначає, яка саме з двох можливих гілок квадратного кореня реалізується:

```
g(1, p) = { +√p,     якщо p ≡ 1 (mod 4)
          { +i·√p,   якщо p ≡ 3 (mod 4)
```

#### Схема доведення Коші–Кронекера:

Розглянемо матрицю Вандермонда `V` розміру `p × p`, побудовану на степенях примітивного кореня `ζ = e^(2π i / p)`:

```
V_jk = ζ^(j·k),    де 0 ≤ j, k ≤ p-1
```

1. **Квадрат визначника:**
   Обчисливши добуток `V · Vᵀ`, можна прямо переконатися, що `det(V)² = (-1)^(p(p-1)/2) · pᵖ`.

2. **Формула Вандермонда через добуток різниць:**
   За класичною формулою для визначника Вандермонда:
   ```
   det(V) = ∏_{0 ≤ j < k ≤ p-1} (ζᵏ - ζʲ)
   ```

3. **Виділення фази синусів:**
   Перегрупувавши множники `(ζᵏ - ζʲ) = ζʲ · (ζ^(k-j) - 1) = 2 i · ζ^((j+k)/2) · sin(π(k-j)/p)`, добуток розбивається на дійсну додатну частину (добуток синусів кутів з першої півплощини) та фазовий множник.

Оскільки для всіх `1 ≤ m < p/2` кути `π m / p` лежать у першій чверті `(0, π/2)`, значення `sin(π m / p) > 0` є строго додатними. Це однозначно фіксує знак комплексного аргументу, доводячи, що сума Ґаусса `g(1, p)` завжди має **додатний знак** уздовж відповідної дійсної або уявної півосі.

### 6. Співвідношення між сумами Якобі та сумами Ґаусса

Нехай `χ₁` та `χ₂` — два нетривіальних мультиплікативних характери за модулем `p`.
**Сума Якобі** визначена формулою:

```
J(χ₁, χ₂) = ∑_{a=0}^{p-1} χ₁(a) · χ₂(1 - a)
```

**Теорема 2.** Якщо характер `χ₁ · χ₂` також нетривіальний, то сума Якобі виражається через суми Ґаусса:

```
J(χ₁, χ₂) = ( g(χ₁) · g(χ₂) ) / g(χ₁ · χ₂)
```

#### Доведення:

Обчислимо добуток двох сум Ґаусса `g(χ₁) · g(χ₂)`:

```
g(χ₁) · g(χ₂)
= ( ∑_{x ∈ 𝔽ₚ} χ₁(x) · e^(2π i x / p) ) · ( ∑_{y ∈ 𝔽ₚ} χ₂(y) · e^(2π i y / p) )
  [визначення суми Ґаусса]

= ∑_{x ∈ 𝔽ₚ} ∑_{y ∈ 𝔽ₚ} χ₁(x) · χ₂(y) · e^(2π i (x + y) / p)
  [об'єднання у подвійну суму]
```

Зробимо заміну змінних `k = x + y`. Тоді `y = k - x`.
Якщо `k = 0`, доданок перетворюється на `∑_x χ₁(x) · χ₂(-x) = χ₂(-1) · ∑_x (χ₁·χ₂)(x) = 0`, бо `χ₁·χ₂` нетривіальний.
Якщо `k ≠ 0`, зробимо заміну `x = k · a`. Тоді `y = k · (1 - a)`:

```
= ∑_{k ∈ 𝔽ₚ*} ∑_{a ∈ 𝔽ₚ} χ₁(k·a) · χ₂(k·(1 - a)) · e^(2π i k / p)
  [заміна змінних x = k·a, y = k·(1-a)]

= ∑_{k ∈ 𝔽ₚ*} (χ₁·χ₂)(k) · e^(2π i k / p) · ( ∑_{a ∈ 𝔽ₚ} χ₁(a) · χ₂(1 - a) )
  [винесення факторів по k за дужки внутрішньої суми по a]

= g(χ₁ · χ₂) · J(χ₁, χ₂)
  [за означенням сум Ґаусса та Якобі]
```

Поділивши обидві частини на `g(χ₁ · χ₂)` (що можливо, бо `|g(χ₁ · χ₂)| = √p ≠ 0`), отримуємо шукану тотожність. ∎

Внаслідок цього зв'язку модуль суми Якобі для нетривіального добутку характерів дорівнює:

```
|J(χ₁, χ₂)| = ( |g(χ₁)| · |g(χ₂)| ) / |g(χ₁ · χ₂)| = ( √p · √p ) / √p = √p
```

### 7. Тотожність Девенпорта–Хассе для розширень полів

У 1934 році Гарольд Девенпорт (*Harold Davenport*) та Гельмут Хассе (*Helmut Hasse*) довели фундаментальну тотожність, яка пов'язує суму Гаусса над основним полем `𝔽_q` із сумою Гаусса над його розширенням `𝔽_{q^s}`.

Нехай `𝔽_q` — скінченне поле з `q = p^f` елементів, `χ` — мультиплікативний характер поля `𝔽_q`, а `g(χ)` — його сума Гаусса над `𝔽_q`.
Розглянемо розширення `𝔽_{q^s}` степеня `s`. Підйом характеру `χ'` на поле `𝔽_{q^s}` задається через норму `N_{q^s/q}` як `χ'(α) = χ(N_{q^s/q}(α))`.

**Теорема (Девенпорта–Хассе).** Сума Гаусса `g(χ')` над розширеним полем `𝔽_{q^s}` виражається точним степенем суми Гаусса над основним полем:

```
-g(χ') = (-g(χ))^s
```

Ця тотожність є фундаментальним алгебраїчним фундаментом підрахунку кількості точок на алгебраїчних різновидах над скінченними полями і доведення гіпотез Вейля для дзета-функцій.
