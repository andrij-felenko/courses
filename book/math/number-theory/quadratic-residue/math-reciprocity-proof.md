# 🧮 Одна лема — три теореми: −1, двійка й закон взаємності

Основна тема лишила три борги. Вона сказала, що −1 буває квадратом за модулем p рівно тоді, коли p ≡ 1 (mod 4); що двійка буває квадратом рівно тоді, коли p ≡ ±1 (mod 8); і що для двох непарних простих p, q добуток символів Лежандра (p|q)·(q|p) дорівнює (−1)^(((p−1)/2)·((q−1)/2)). Перший факт вона довела критерієм Ейлера, а два інші відклала «на окреме доведення». Виявляється, це окреме доведення для всіх трьох — одне-єдине: досить навчитися рахувати, скільки кратних a·k, зведених за модулем p, **перескакують** за половину модуля. Цей рахунок і є лема Гаусса; з неї в один-два рядки падають обидва доповнення, а її решіткова версія дає закон взаємності цілком.

## Лема Гаусса: скільки кратних падає у верхню половину

Візьмімо непарне просте p і число a, не кратне p. Погляньмо на перші (p−1)/2 кратних числа a:

```
a·1,  a·2,  a·3,  …,  a·((p−1)/2)
```

Зведімо кожне за модулем p до звичайного лишку в проміжку від 1 до p−1. Тепер єдине, що нас цікавитиме: скільки з цих лишків опинилося у **верхній** половині — тобто перевищило p/2. Позначмо це число μ. Лема Гаусса каже:

```
(a | p) = (−1)^μ
```

Знак символу Лежандра — це просто парність кількості перескоків. Ніяких піднесень до великого степеня, ніякого перебору квадратів: полічи, скільки кратних перевалило за середину, і парність відповіді дає знак.

**Приклад під рукою.** Нехай a = 3, p = 11. Кратні 3·1, …, 3·5 це 3, 6, 9, 12, 15, а їхні лишки за модулем 11 — **3, 6, 9, 1, 4**. Понад 5.5 перескочили двоє: 6 і 9. Отже μ = 2, і (3|11) = (−1)² = +1 — трійка справді квадрат (5² ≡ 3).

**Чому це правда.** Кожен лишок r у проміжку 1…p−1 лежить або в нижній половині (r < p/2), або у верхній (r > p/2). Для верхнього візьмімо його «дзеркало» p − r — воно вже нижнє. Домовмося записувати кожне кратне так:

```
a·k ≡ ε_k · t_k   (mod p),   де  t_k ∈ {1, …, (p−1)/2},   ε_k = ±1
```

Тут ε_k = +1, коли лишок числа a·k сам був нижній (і тоді t_k — цей лишок), і ε_k = −1, коли він був верхній (і тоді t_k = p − лишок). За побудовою μ — це кількість індексів k, для яких ε_k = −1.

Уся вага доведення — в одному спостереженні: величини t₁, …, t_{(p−1)/2} — це рівно числа 1, 2, …, (p−1)/2, лише переставлені. Кожне t_k лежить у цьому проміжку за побудовою; лишається показати, що вони **попарно різні** — тоді (p−1)/2 різних чисел вичерпають усі (p−1)/2 місць.

Припустімо, що t_j = t_k. Тоді a·j ≡ ±a·k (mod p). Число a не кратне p, тож [за простим модулем на нього можна скоротити](book:math/prime-numbers) (у a є обернений), і лишається j ≡ ±k (mod p). Але j і k обидва в проміжку від 1 до (p−1)/2, тож їхня сума менша за p і не дорівнює нулю за модулем p — варіант j ≡ −k відпадає. Лишається j ≡ k, тобто j = k. Отже склеїтися можуть лише однакові індекси: усі t різні, і справді переставляють 1…(p−1)/2. 

Тепер перемножмо всі (p−1)/2 конгруенцій:

```
∏ (a·k)  ≡  ∏ (ε_k · t_k)   (mod p)

a^((p−1)/2) · ∏ k  ≡  (∏ ε_k) · (∏ t_k)
```

Ліворуч ∏ k = ((p−1)/2)!. Праворуч ∏ ε_k = (−1)^μ (мінус на кожен верхній), а ∏ t_k = ((p−1)/2)! — бо t лише переставляють ті самі числа. Скоротімо спільний множник ((p−1)/2)!; він не кратний p, тож це законно:

```
a^((p−1)/2)  ≡  (−1)^μ   (mod p)
```

А ліва частина — це рівно **критерій Ейлера**, доведений в основній темі: a^((p−1)/2) ≡ (a|p). Обидві сторони — це ±1, а за непарного p вони різні між собою за модулем, тож рівність за модулем стає рівністю самих чисел:

```
(a | p) = (−1)^μ                                                   ∎
```

Знак символу — це парність кількості синіх стрілок; тут їх дві, тож (3|11) = +1.*

## Найлегша здобич: коли −1 квадрат

Найпростіше застосування — a = −1. Кратні −1·k це просто −1, −2, …, −(p−1)/2, а їхні лишки за модулем p — це p−1, p−2, …, (p+1)/2. Усі до одного більші за p/2: кожне перескочило. Отже μ = (p−1)/2, і без жодної згадки про степені лема одразу видає

```
(−1 | p) = (−1)^((p−1)/2)
```

Показник (p−1)/2 парний за p ≡ 1 (mod 4) і непарний за p ≡ 3 (mod 4), тож −1 квадрат рівно за простих вигляду 4k + 1. Це той самий результат, що основна тема дістала критерієм Ейлера, — тут він випав як розминка леми, перше й найдешевше її застосування.

## Двійка: рахунок, якого критерій не давав у лоб

Для двійки критерій Ейлера безсилий: 2^((p−1)/2) не спрощується так само легко, як (y²)^((p−1)/2). А от лема Гаусса рахує двійку так само механічно, як і все інше — бо кратні двійки не треба навіть зводити за модулем.

Кратні 2·k це 2, 4, 6, …, p−1 — усі парні числа до p−1, усі менші за p, тож вони самі собі лишки. Скільки з них перескочило за p/2? Умова 2k > p/2 означає k > p/4. Серед k = 1, …, (p−1)/2 таких рівно

```
μ = (p−1)/2 − ⌊p/4⌋
```

(⌊·⌋ — ціла частина; від усіх (p−1)/2 значень відняли ті ⌊p/4⌋, що не дотягли до p/4). Тепер знак (−1)^μ залежить лише від остачі p за модулем 8, бо і (p−1)/2, і ⌊p/4⌋ визначаються нею. Непарне просте дає одну з чотирьох остач — пройдімо всі:

```
p = 8m+1:   (p−1)/2 = 4m,     ⌊p/4⌋ = 2m,     μ = 2m     парне   → (2|p) = +1
p = 8m+3:   (p−1)/2 = 4m+1,   ⌊p/4⌋ = 2m,     μ = 2m+1   непарне → (2|p) = −1
p = 8m+5:   (p−1)/2 = 4m+2,   ⌊p/4⌋ = 2m+1,   μ = 2m+1   непарне → (2|p) = −1
p = 8m+7:   (p−1)/2 = 4m+3,   ⌊p/4⌋ = 2m+1,   μ = 2m+2   парне   → (2|p) = +1
```

Отже двійка квадрат за p ≡ 1, 7 (mod 8) і нелишок за p ≡ 3, 5 — тобто квадрат рівно за p ≡ ±1 (mod 8). Ці чотири рядки згортаються в одну формулу. Величина (p²−1)/8 ціла (бо p²−1 = (p−1)(p+1) — добуток двох сусідніх парних, кратний 8), і вона парна рівно тоді, коли p ≡ ±1 (mod 8); саме цю парність і дають чотири рядки вище. Тому

```
(2 | p) = (−1)^((p²−1)/8)
```

Перевірмо на робочому модулі 11: (p−1)/2 = 5, ⌊11/4⌋ = 2, μ = 3 — непарне, (2|11) = −1. А (11²−1)/8 = 120/8 = 15 — теж непарне, теж −1. Двійка нелишок за модулем 11, як і має бути. Ось і все «хитре групування», що його основна тема відклала: воно виявилося простою лічбою парних кратних, які перевалили за середину.

## Від перескоків до підлоги: лема Айзенштайна

Ґратка ще попереду, і місток до неї — ще одна форма того самого рахунку. Перескоки можна лічити не прямо, а через **цілу частину** (підлогу) ділення, і саме підлога заведе нас у геометрію. Твердження таке: для непарного a, взаємно простого з p,

```
(a | p) = (−1)^T,   де  T = Σ_{k=1}^{(p−1)/2} ⌊ka/p⌋
```

Доведімо, що показник T тут тієї ж парності, що й μ. Поділімо кожне ka з остачею: ka = p·⌊ka/p⌋ + r_k, де 0 < r_k < p. Просумуймо по k = 1, …, (p−1)/2:

```
a · Σk  =  p · Σ⌊ka/p⌋  +  Σr_k
```

Позначмо Σk = 1 + 2 + … + (p−1)/2 = (p²−1)/8 через Σ₀. Тепер згадаймо згортання з леми Гаусса: для нижніх k лишок r_k = t_k, а для верхніх r_k = p − t_k. Отже кожен із μ верхніх додає до суми лишків p і міняє +t на −t:

```
Σr_k  =  Σ₀  +  μ·p  −  2·S       (S — сума t_k по верхніх k)
```

Підставмо це у попередню рівність і зберімо доданки з Σ₀ ліворуч:

```
a·Σ₀  =  p·T  +  Σ₀  +  μp  −  2S
(a − 1)·Σ₀  =  p·T  +  μp  −  2S
```

І тут найпростіший хід — глянути на рівність за модулем 2. Число a непарне, тож a − 1 парне і ліва частина парна. Праворуч доданок 2S зникає, p непарне, тож p·T ≡ T і μp ≡ μ. Лишається

```
0 ≡ T + μ   (mod 2)      ⇒      μ ≡ T   (mod 2)
```

Отже (a|p) = (−1)^μ = (−1)^T: знак перескоків і знак суми підлог — одне й те саме. (Тут суттєво, що a непарне — інакше a − 1 не парне; для двійки ми вже впоралися напряму, тож обмеження нічого не забирає.) Цю форму леми запровадив Ґотгольд Айзенштайн, звівши третє з Гаусових доведень до чистої лічби.

## Ґратка Айзенштайна: закон взаємності як рахунок точок

Тепер беремо два непарні прості p і q. Застосуймо щойно доведену формулу двічі — з a = q за модулем p, і з a = p за модулем q (обидва прості непарні, тож умова виконана):

```
(q | p) = (−1)^N,   N = Σ_{k=1}^{(p−1)/2} ⌊kq/p⌋
(p | q) = (−1)^M,   M = Σ_{j=1}^{(q−1)/2} ⌊jp/q⌋
```

Перемножмо:

```
(p | q)·(q | p) = (−1)^(M + N)
```

Усе звелося до одного питання: чому дорівнює M + N. І ось де вступає геометрія.

Намалюймо **ґратку** (решітку) цілих точок (x, y), де x пробігає 1…(p−1)/2, а y пробігає 1…(q−1)/2. Це прямокутник, у ньому рівно

```
(p−1)/2 · (q−1)/2
```

точок. Проведімо крізь нього діагональ — пряму py = qx, тобто y = (q/p)·x із похилом q/p.

Спершу переконаймося, що **жодна точка ґратки не лежить на діагоналі**. Якби py = qx для наших цілих x, y, то p ділило б qx; а що p і q — різні прості (взаємно прості), то p ділило б x, а це неможливо, бо 1 ≤ x ≤ (p−1)/2 < p. Отже кожна точка або строго нижче, або строго вище діагоналі — проміжного стану немає.

Полічимо точки **нижче** діагоналі, по стовпцях. У стовпці x = k нижче лінії лежать ті точки, де y < qk/p, тобто y = 1, 2, …, ⌊qk/p⌋ (цілу частину беремо саме тому, що qk/p — не ціле, лінія жодного вузла не чіпає). Стовпець дає ⌊qk/p⌋ точок, а всі стовпці разом —

```
Σ_{k=1}^{(p−1)/2} ⌊qk/p⌋  =  N
```

Так само точки **вище** діагоналі порахуймо по рядках: у рядку y = j вище лінії (тобто ліворуч від неї, x < pj/q) лежить ⌊pj/q⌋ точок, а всього M. (Варто перевірити, що жоден такий підрахунок не вилазить за прямокутник: для k ≤ (p−1)/2 маємо qk/p < q/2, тож ⌊qk/p⌋ ≤ (q−1)/2 — усі пораховані точки таки в межах.)

Кожна точка ґратки — або нижче, або вище, і полічена рівно один раз. Тому

```
N + M  =  (p−1)/2 · (q−1)/2
```

Підставмо це в добуток символів — і ось він, закон взаємності, здобутий чистим рахунком точок:

```
(p | q)·(q | p)  =  (−1)^(N + M)  =  (−1)^( ((p−1)/2)·((q−1)/2) )       ∎
```

*Прямокутник (p−1)/2 × (q−1)/2 цілих точок для p = 11, q = 7. Діагональ 11y = 7x проходить повз усі вузли, розтинаючи ґратку на дві частини. Зелені нижче (по стовпцях їх N = 0+1+1+2+3 = 7), сині вище (по рядках M = 1+3+4 = 8), а разом — усі 15 = 5·3 точок прямокутника. Звідси N + M = 15, тобто (7|11)(11|7) = (−1)¹⁵ = −1.*

**Порахуймо повністю на p = 11, q = 7.** Прямокутник має (p−1)/2 = 5 стовпців і (q−1)/2 = 3 рядки, разом 15 точок.

```
нижче (стовпці):  N = ⌊7/11⌋ + ⌊14/11⌋ + ⌊21/11⌋ + ⌊28/11⌋ + ⌊35/11⌋
                    = 0 + 1 + 1 + 2 + 3 = 7        →  (7|11) = (−1)⁷ = −1
вище (рядки):     M = ⌊11/7⌋ + ⌊22/7⌋ + ⌊33/7⌋
                    = 1 + 3 + 4 = 8               →  (11|7) = (−1)⁸ = +1
разом:            N + M = 15 = 5·3               →  (7|11)(11|7) = (−1)¹⁵ = −1
```

Обидва прості тут вигляду 4k + 3 (11 ≡ 3, 7 ≡ 3), і закон дає −1: символи протилежні. Так воно й є — 7 не квадрат за модулем 11, зате 11 ≡ 4 = 2² квадрат за модулем 7. Уся суть закону взаємності стиснулась у просту рівність: точки під діагоналлю плюс точки над нею дають увесь прямокутник.

**Перевірка машиною.** Ні лема, ні решітковий рахунок не спираються на щасливий вибір чисел — обидві рівності можна прогнати на всіх малих простих:

```py
def is_prime(n):
    return n > 1 and all(n % d for d in range(2, int(n ** 0.5) + 1))

def legendre(a, p):                     # символ Лежандра через критерій Ейлера
    r = pow(a % p, (p - 1) // 2, p)
    return r - p if r > 1 else r         # p−1 ↦ −1, інакше 0 або 1

def mu(a, p):                           # скільки кратних a·k перескочило за p/2
    half = (p - 1) // 2
    return sum((a * k) % p > p / 2 for k in range(1, half + 1))

def lattice(p, q):                      # цілі точки під діагоналлю прямокутника
    return sum((q * k) // p for k in range(1, (p - 1) // 2 + 1))

primes = [n for n in range(3, 300) if is_prime(n)]

for p in primes:                        # лема Гаусса: (a|p) = (−1)^μ
    for a in range(1, p):
        assert legendre(a, p) == (-1) ** mu(a, p)

for p in primes:                        # закон взаємності — рахунком точок
    for q in primes:
        if p == q:
            continue
        N, M = lattice(p, q), lattice(q, p)
        assert N + M == ((p - 1) // 2) * ((q - 1) // 2)          # решітка ділиться навпіл
        assert legendre(p, q) * legendre(q, p) == (-1) ** (N + M)
```

Обидва цикли проходять мовчки: перескоки дають символ Лежандра на кожному простому й кожному a, а точки під двома діагоналями завжди складаються в добуток сторін прямокутника.

> 🔧 **Навіщо це.** Три різні на вигляд твердження — про −1, про двійку, про пару простих — виявилися однією теоремою про лічбу: скільки кратних перескочило за половину модуля, скільки точок лежить під діагоналлю. Це не лише економія доведень. Аргумент, що спирається тільки на поділ з остачею й перелік вузлів ґратки, не має жодної «магії», якої не можна перенести деінде, — саме тому решітковий рахунок став взірцем для вищих законів взаємності, де замість двох квадратів беруть куби й вищі степені, а замість прямокутника — тонші області. Здобувши закон однією лемою про перескоки, ми заразом дістали шаблон, за яким будують цілий поверх сучасної теорії чисел.
