# 🧮 Доведення теореми фон Штаудта — Клаузена та порівнянь Куммера

Теорема фон Штаудта — Клаузена повністю описує арифметичну структуру знаменників чисел Бернуллі, стверджуючи, що для будь-якого парного індексу `2k ≥ 2` різниця `B₂ₖ + ∑ (1/p)` по всіх простих числах `p`, для яких `(p−1)` ділить `2k`, є цілим числом. Ця вставка містить строге математичне доведення теореми фон Штаудта — Клаузена за допомогою p-адичного аналізу, детальний розбір конкретних прикладів, алгебраїчне виведення порівнянь Куммера, доведення рекурентних тотожностей Рамануджана, аналіз многочленів Бернуллі та асимптотичні оцінки зростання чисельників.

## 1. p-адичний порядок та кільце p-цілих чисел

Щоб аналізувати подільність дробових і раціональних чисел на довільне просте число `p`, використаємо класичний апарат p-адичного порядку та p-адичних нормувань.

Для будь-якого ненульового раціонального числа `x = a / b` (де `a` та `b` — цілі числа, `b ≠ 0`) існує єдиний розклад на прості множники у вигляді `x = pᵛ · (r / s)`, де ані чисельник `r`, ані знаменник `s` не діляться на `p`. Ціле число `v = v_p(x)` називається **p-адичним порядком** (або p-адичним валентуванням) числа `x`.

- Якщо `v_p(x) > 0`, чисельник числа `x` ділиться на `p` (у такому разі кажуть, що `x` ділиться на `p` у p-адичному сенсі).
- Якщо `v_p(x) = 0`, то ані чисельник, ані знаменник раціонального числа `x` у скороченому вигляді не діляться на `p`.
- Якщо `v_p(x) < 0`, то знаменник числа `x` містить `p⁻ᵛ` як множник, тобто число має `p` у знаменнику.

Формально визначимо локальне кільце **p-цілих раціональних чисел** `ℤ_{(p)}`:

```
ℤ_{(p)} = { x ∈ ℚ : v_p(x) ≥ 0 }
```

Це множина всіх раціональних чисел, знаменники яких у скороченому вигляді взаємно прості з `p`. Для кожного елемента `x ∈ ℤ_{(p)}` повністю коректно визначено операцію зведення за модулем `p`: якщо `x = a/b` із `gcd(b, p) = 1`, то `x ≡ a · b⁻¹ (mod p)`, де `b⁻¹` означає мультиплікативно обернений елемент до `b` у скінченному полі остач `ℤ/pℤ`.

Основні арифметичні властивості p-адичного порядку:
1. **Порядок добутку:** `v_p(x · y) = v_p(x) + v_p(y)` для будь-яких ненульових `x, y ∈ ℚ`.
2. **Нерівність трикутника (ультраметрична властивість):** `v_p(x + y) ≥ min(v_p(x), v_p(y))`.
3. **Строга рівність для різних порядків:** Якщо `v_p(x) ≠ v_p(y)`, то ультраметрична нерівність стає строгою рівністю: `v_p(x + y) = min(v_p(x), v_p(y))`.

Саме ця третя властивість є вирішальною у дослідженнях знаменників: якщо один доданок має `p` у знаменнику (`v_p < 0`), а всі інші доданки є p-цілими (`v_p ≥ 0`), то їхня сума гарантовано лишається дробом із `p` у знаменнику.

## 2. Фундаментальна лема про суми степенів за модулем p

Ключовим технічним кроком усього доведення є точне обчислення суми однакових степенів усіх ненульових остач у скінченному полі `ℤ/pℤ`.

**Лема.** Нехай `p` — довільне просте число, а `m ≥ 1` — цілий додатний показник. Розглянемо суму степенів `S_m(p) = ∑ (від j=0 до p−1) jᵐ = 0ᵐ + 1ᵐ + 2ᵐ + … + (p−1)ᵐ`. Тоді за модулем `p` має місце порівняння:

```
S_m(p) ≡ -1 (mod p),   якщо (p − 1) ділитm m
S_m(p) ≡  0 (mod p),   якщо (p − 1) не ділить m
```

### Покрокове алгебраїчне доведення леми

Розглянемо два взаємно виключні випадки залежно від подільності `m` на `p − 1`:

**Випадок 1: Умова `(p − 1)` ділить `m`.**

За Малою теоремою Ферма, для кожного ненульового елемента `j ∈ {1, 2, …, p−1}` має місце порівняння `jᵖ⁻¹ ≡ 1 (mod p)`. 

Оскільки за умовою `m` є кратним `p − 1`, ми можемо записати `m = c · (p − 1)` для деякого цілого коефіцієнта `c ≥ 1`. Піднесемо обидві частини порівняння Ферма до степеня `c`:

```
jᵐ = j^(c·(p−1)) = (jᵖ⁻¹)ᶜ ≡ 1ᶜ ≡ 1 (mod p)      [за Малою теоремою Ферма]
```

Тепер обчислимо суму `S_m(p)` за модулем `p`. Вона складається з одного першого нуля (`0ᵐ = 0` при `m ≥ 1`) та `p − 1` однакових доданків, кожен з яких дорівнює `1` за модулем `p`:

```
S_m(p)
= 0ᵐ + ∑ (j=1..p-1) jᵐ
≡ 0 + ∑ (j=1..p-1) 1             [заміна jᵐ ≡ 1 (mod p)]
= (p − 1) · 1
= p − 1
≡ −1 (mod p)                     [бо p − 1 ≡ −1 (mod p)]
```

Перший випадок леми повністю доведено.

**Випадок 2: Умова `(p − 1)` не ділить `m`.**

Оскільки мультиплікативна група остач `(ℤ/pℤ)ˣ = {1, 2, …, p−1}` є циклічною групою порядку `p − 1`, у ній завжди існує принаймні один первісний корінь `g` за модулем `p` (генератор групи).

Умова того, що `(p − 1)` не ділить `m`, означає, що степінь `gᵐ` не дорівнює одиниці за модулем `p`:

```
gᵐ ≢ 1 (mod p)
```

Оскільки `gcd(g, p) = 1`, множення кожного елемента множини `{1, 2, …, p−1}` на `g` здійснює бієктивну перестановку цієї множини за модулем `p`. Отже, сума `m`-их степенів усіх елементів не змінюється від домноження кожного додатка на `gᵐ`:

```
S_m(p) = ∑ (j=1..p-1) jᵐ ≡ ∑ (j=1..p-1) (g · j)ᵐ   (mod p)
```

Винесемо спільний множник `gᵐ` за дужки:

```
S_m(p)
≡ gᵐ · ∑ (j=1..p-1) jᵐ          [винесення спільного множника gᵐ]
= gᵐ · S_m(p)                   [за означенням суми S_m(p)]
```

Перенесемо всі доданки в ліву частину порівняння та розкладемо на множники:

```
(gᵐ − 1) · S_m(p) ≡ 0 (mod p)
```

Оскільки `gᵐ ≢ 1 (mod p)`, елемент `(gᵐ − 1)` є ненульовим у полі остач `ℤ/pℤ`, а отже, має мультиплікативно обернений елемент `(gᵐ − 1)⁻¹ (mod p)`. Домноживши порівняння на цей обернений елемент, остаточно дістаємо:

```
S_m(p) ≡ 0 (mod p)
```

Лемму повністю і строго доведено для всіх випадків.

## 3. Доведення теореми фон Штаудта — Клаузена

Тепер застосуємо знайдену лему до дослідження знаменників парних чисел Бернуллі `B₂ₖ`.

**Теорема (К. фон Штаудт, Т. Клаузен, 1840).** Для будь-якого цілого парного індексу `2k ≥ 2` сума

```
B₂ₖ + ∑ (з умовою (p−1)|2k) (1 / p)
```

є цілим числом, де сумування проводиться по всіх простих числах `p`, для яких `(p − 1)` є дільником `2k`.

### Доведення теореми

За формулою Фаульгабера для `n = p`, сума `S₂ₖ(p) = ∑ (j=0..p-1) j²ᵏ` виражається як багаточлен від `p` з коефіцієнтами Бернуллі:

```
S₂ₖ(p) = (1 / (2k + 1)) · ∑ (від j=0 до 2k) C(2k + 1, j) · B_j · p²ᵏ⁺¹⁻ʲ
```

Розгорнемо цю суму та окремо виділимо два її останні терми — для `j = 2k` та для `j = 2k − 1`:

- Для `j = 2k`: доданок дорівнює `(1 / (2k + 1)) · C(2k + 1, 2k) · B₂ₖ · p¹ = (2k + 1) / (2k + 1) · B₂ₖ · p = p · B₂ₖ`.
- Для `j = 2k − 1`: оскільки `B₂ₖ₋₁ = 0` для всіх `2k − 1 ≥ 3` (і `B₁ = −½` для `2k = 2`), цей член вивчається окремо й дає впевнений внесок у знаменник не вище `p²`.

Для всіх попередніх доданків `j < 2k − 1` член містить множник `p²ᵏ⁺¹⁻ʲ` з показником степеня `2k + 1 − j ≥ 2`.

За індуктивним припущеннням (або аналізом p-адичних порядків), знаменники чисел Бернуллі `B_j` для всіх менших індексів `j < 2k` не містять `p` у степені вище ніж 1, тобто їхній p-адичний порядок задовольняє нерівність `v_p(B_j) ≥ −1`.

Тому для кожного `j < 2k − 1` оцінимо p-адичний порядок відповідного доданка:

```
v_p( C(2k+1, j) · B_j · p²ᵏ⁺¹⁻ʲ )
≥ v_p(C(2k+1, j)) + v_p(B_j) + (2k + 1 − j)
≥ 0 + (−1) + 2
= 1 > 0
```

Отже, абсолютно всі доданки розкладу Фаульгабера, крім останнього члена `p · B₂ₖ`, є p-цілими числами, які до того ж діляться на `p` (тобто дорівнюють `0` за модулем `p`)!

Поділивши вираз Фаульгабера на `p` за модулем `p`, ми дістаємо фундаментальне p-адичне порівняння:

```
p · B₂ₖ ≡ S₂ₖ(p) (mod p)
```

Тепер застосуємо до правого боку доведену у §2 Лему для `m = 2k`:

1. **Перший випадок: Умова `(p − 1)` ділить `2k`.**
   За лемою, `S₂ₖ(p) ≡ −1 (mod p)`.
   Тоді `p · B₂ₖ ≡ −1 (mod p)`. 
   Це означає, що існує таке p-ціле число `c ∈ ℤ_{(p)}`, що:
   
   ```
   p · B₂ₖ = c · p − 1  ⇒  B₂ₖ = c − (1 / p)
   ```
   
   Отже, сума `B₂ₖ + 1/p` є p-цілим числом (`v_p(B₂ₖ + 1/p) ≥ 0`), а сам p-адичний порядок дорівнює `v_p(B₂ₖ) = −1`.

2. **Другий випадок: Умова `(p − 1)` не ділить `2k`.**
   За лемою, `S₂ₖ(p) ≡ 0 (mod p)`.
   Тоді `p · B₂ₖ ≡ 0 (mod p)`. 
   Це означає, що сам дріб `B₂ₖ` є p-цілим числом (`v_p(B₂ₖ) ≥ 0`), і знаменник `B₂ₖ` взагалі не ділиться на `p`.

Тепер розглянемо підсумкову суму `K = B₂ₖ + ∑_((p−1)|2k) (1 / p)`.

Перевіримо її p-адичний порядок для абсолютно кожного простого числа `q`:
- Якщо `(q − 1)` ділить `2k`, то доданок `1/q` входить до складу суми. Конструкція `B₂ₖ + 1/q` є q-цілим числом, а всі інші доданки `1/p` для `p ≠ q` взаємно прості з `q`. Отже, `v_q(K) ≥ 0`.
- Якщо `(q − 1)` не ділить `2k`, то член `1/q` не входить до суми, але саме число `B₂ₖ` є q-цілим, і жоден із доданків `1/p` не має `q` у знаменнику (бо `p ≠ q`). Отже, знову `v_q(K) ≥ 0`.

Оскільки `v_q(K) ≥ 0` для **всіх без винятку простих чисел `q`**, раціональне число `K` має скорочений знаменник, який не ділиться ні на одне просте число.

За фундаментальною теоремою арифметики, єдиним раціональним числом з таким знаменником є **ціле число**.

Теорему фон Штаудта — Клаузена повністю доведено.

### Детальні обчислювальні приклади

Простежмо роботу теореми фон Штаудта — Клаузена на конкретних числах Бернуллі:

- **Для `B₂ = ⅙` (`2k = 2`):**
  Прості числа `p`, для яких `(p − 1)` ділить 2: це `p = 2` (бо `2−1 = 1 | 2`) та `p = 3` (бо `3−1 = 2 | 2`).
  Сума дробив: `1/2 + 1/3 = 5/6`.
  Перевірка теореми: `B₂ + 1/2 + 1/3 = 1/6 + 5/6 = 6/6 = 1 ∈ ℤ`.
  Знаменник: `den(B₂) = 2 · 3 = 6`.

- **Для `B₄ = −⅓₀` (`2k = 4`):**
  Прості числа `p`, для яких `(p − 1)` ділить 4: це `p = 2` (`1|4`), `p = 3` (`2|4`), `p = 5` (`4|4`).
  Сума дробив: `1/2 + 1/3 + 1/5 = 31/30`.
  Перевірка теореми: `B₄ + 1/2 + 1/3 + 1/5 = −1/30 + 31/30 = 30/30 = 1 ∈ ℤ`.
  Знаменник: `den(B₄) = 2 · 3 · 5 = 30`.

- **Для `B₆ = 1/42` (`2k = 6`):**
  Прості `p`, для яких `(p − 1)` ділить 6: це `p = 2` (`1|6`), `p = 3` (`2|6`), `p = 7` (`6|6`).
  Знаменник: `den(B₆) = 2 · 3 · 7 = 42`.
  Сума: `B₆ + 1/2 + 1/3 + 1/7 = 1/42 + 41/42 = 42/42 = 1 ∈ ℤ`.

- **Для `B₁₂ = −691 / 2730` (`2k = 12`):**
  Прості `p`, для яких `(p − 1)` ділить 12: це `p = 2, 3, 5, 7, 13`.
  Знаменник: `den(B₁₂) = 2 · 3 · 5 · 7 · 13 = 2730`.
  Сума: `B₁₂ + 1/2 + 1/3 + 1/5 + 1/7 + 1/13 = −691/2730 + 3421/2730 = 2730/2730 = 1 ∈ ℤ`.

## 4. Структура чисельників та порівняння Куммера

Якщо теорема фон Штаудта — Клаузена дає вичерпну відповідь щодо знаменників чисел Бернуллі, то їхні чисельники `num(B₂ₖ)` приховують куди тонші та глибші p-адичні зв'язки.

Німецький математик Ернст Куммер (Ernst Kummer, 1810–1893) під час роботи над Великою теоремою Ферма виявив, що чисельники чисел Бернуллі підкоряються модульним співвідношенням неперервності.

**Теорема (Порівняння Куммера).** Нехай `p` — просте число, а `2k` та `2m` — парні додатні індекси такі, що `2k ≢ 0 (mod p − 1)` та `2m ≢ 0 (mod p − 1)`. Якщо `2k ≡ 2m (mod p − 1)`, то має місце p-адичне порівняння:

```
(B₂ₖ / 2k) ≡ (B₂☤ / 2m) (mod p)
```

де нормування `B₂ₖ / 2k` вважається елементом кільця `ℤ_{(p)}`.

Більше того, якщо порівняння індексів виконується за вищим модулем `2k ≡ 2m (mod pᵃ · (p − 1))`, то порівняння чисел Бернуллі посилюється до модуля `pᵃ⁺¹`:

```
(1 − p²ᵏ⁻¹) · (B₂ₖ / 2k) ≡ (1 − p²ᵐ⁻¹) · (B₂☤ / 2m) (mod pᵃ⁺¹)
```

### Пряма обчислювальна перевірка порівнянь Куммера

Перевіримо порівняння Куммера на конкретних числах для простих `p = 5` та `p = 7`:

**Перевірка для `p = 5`:**
Умова `2k ≢ 0 (mod 4)` означає, що розглядатимемо індекси `2k ≡ 2 (mod 4)`, наприклад `2k = 2` та `2m = 6`.
- Для `2k = 2`: `B₂ = ⅙`. Обчислимо `B₂ / 2 = 1/12`. За модулем 5: `12 ≡ 2 (mod 5)`, обернений елемент `2⁻¹ ≡ 3 (mod 5)`, тому `1/12 ≡ 3 (mod 5)`.
- Для `2m = 6`: `B₆ = 1/42`. Обчислимо `B₆ / 6 = 1/252`. За модулем 5: `252 ≡ 2 (mod 5)`, обернений елемент `2⁻¹ ≡ 3 (mod 5)`, тому `1/252 ≡ 3 (mod 5)`.
Порівняння підтверджено: `B₂ / 2 ≡ B₆ / 6 ≡ 3 (mod 5)`.

**Перевірка для `p = 7`:**
Умова `2k ≢ 0 (mod 6)`. Розглянемо `2k = 2` та `2m = 8` (`2 ≡ 8 (mod 6)`).
- Для `2k = 2`: `B₂ / 2 = 1/12`. За модулем 7: `12 ≡ 5 (mod 7)`, обернений елемент `5⁻¹ ≡ 3 (mod 7)`, тому `1/12 ≡ 3 (mod 7)`.
- Для `2m = 8`: `B₈ = −1/30`. Обчислимо `B₈ / 8 = −1/240`. За модулем 7: `−240 ≡ −2 ≡ 5 (mod 7)`, обернений елемент `5⁻¹ ≡ 3 (mod 7)`, тому `−1/240 ≡ 3 (mod 7)`.
Порівняння підтверджено: `B₂ / 2 ≡ B₈ / 8 ≡ 3 (mod 7)`.

## 5. Тотожності Рамануджана для прискореного обчислення

Видатний індійський математик Шрініваса Рамануджан у своїй першій опублікованій праці 1911 року довів низку дивовижних рекурентних співвідношень між числами Бернуллі, які дозволяють пропускати обчислення більшості проміжних елементів.

Зокрема, Рамануджан вивів тотожності, які пов'язують кожне третє парне число Бернуллі:

```
C(n+3, m) · Bₙ — 20 · C(n+3, m−6) · Bₙ₋₆ + … = (n + 3) / 3
```

Один із найвідоміших наслідків формул Рамануджана стверджує, що якщо `n` є парним і кратним 6 (`n = 6k`), то чисельник числа Бернуллі `B₆ₖ` підкоряється конкретній подільності на 6:

```
num(B₆ₖ / (6k)) ≡ 1 (mod 2)
```

Формули Рамануджана дозволяють обчислити `B₂ₖ`, знаючи лише третину попередніх значень чисел Бернуллі, що суттєво прискорює комп'ютерний алгоритм для великих індексів `2k`.

## 6. Многочлени Бернуллі та їхні алгебраїчні властивості

Числа Бернуллі природним чином узагальнюються до **многочленів Бернуллі** `B_n(x)`, які визначаються за допомогою експоненціальної твірної функції:

```
(t · eˣᵗ) / (eᵗ − 1) = ∑ (від n=0 до ∞) B_n(x) · tⁿ / n!
```

Явна формула для многочленів Бернуллі має вигляд:

```
B_n(x) = ∑ (від k=0 до n) C(n, k) · B_k · xⁿ⁻ᵏ
```

Звідси видно, що числа Бернуллі є просто вільними членами многочленів Бернуллі: `B_n = B_n(0)`.

Особливо важливими в аналізі є чотири фундаментальні властивості многочленів Бернуллі:

1. **Похідна многочлена:** Похідна `B_n(x)` дорівнює `B_n'(x) = n · B_{n-1}(x)`. Це показує, що багаточлени Бернуллі утворюють послідовність Аппеля.
2. **Інтегральна властивість:** Інтеграл на відрізку `[0, 1]` для всіх `n ≥ 1` дорівнює нулю: `∫ (від 0 до 1) B_n(x) dx = 0`.
3. **Симетрія:** `B_n(1 − x) = (-1)ⁿ · B_n(x)`. Завдяки цій симетрії для парних `n` маємо `B_{2k}(1) = B_{2k}(0) = B_{2k}`.
4. **Спеціальні значення в середині відрізка:** Для `x = 1/2` багаточлени Бернуллі виражаються прямо через числа Бернуллі:

```
B_n(1/2) = (2¹⁻ⁿ − 1) · B_n
```

Зокрема, для парних `n = 2k` маємо `B₂ₖ(1/2) = (2¹⁻²ᵏ − 1) · B₂ₖ`, а для `x = 1/4` значення виражаються через так звані числа Ейлера `E_n`.

### Теорема множення для многочленів Бернуллі

Для будь-якого цілого додатного числа `m ≥ 1` многочлени Бернуллі задовольняють тотожність розбиття:

```
B_n(m · x) = mⁿ⁻¹ · ∑ (від k=0 до m−1) B_n(x + k/m)
```

Ця формула використовується у сучасній теорії чисел для побудови p-адичних мір Мазура та інтегрування по p-адичних цілих числах `ℤ_p`.

Значення многочленів Бернуллі в раціональних точках `x = r / q` дозволяють обчислювати спеціальні значення L-функцій Діріхле у від'ємних цілих точках, зв'язуючи алгебраїчні многочлени з характеристиками арифметичних прогресій.

Ці тотожності відіграють фундаментальну роль у теорії модульних форм та аналітичної теорії чисел, оскільки вони дозволяють виразити коефіцієнти Фурьє Eisenstein-рядів через значення многочленів Бернуллі у відповідних раціональних аргументах.

## 7. Оцінки зростання чисельників та знак B₂ₖ

На відміну від перших кількох чисел Бернуллі (`B₂ = ⅙`, `B₄ = −⅓₀`, `B₆ = 1/42`), модуль чисел Бернуллі починає зростати надзвичайно швидко для великих індексів.

Використовуючи формулу Ейлера, що пов'язує числа Бернуллі із дзета-функцією Рімана `ζ(2k) = ∑ 1/n²ᵏ`:

```
|B₂ₖ| = 2 · (2k)! · ζ(2k) / (2π)²ᵏ
```

Оскільки `ζ(2k) → 1` при `k → ∞`, для великих `k` ми отримуємо точну асимптотичну формулу:

```
|B₂ₖ| ≈ 2 · (2k)! / (2π)²ᵏ
```

За формулою Стірлінга для факторіала `(2k)! ≈ √(4πk) · (2k / e)²ᵏ`, звідки видно, що `|B₂ₖ|` зростає швидше за будь-яку експоненціальну функцію! Наприклад:
- `|B₂₀| = 558441 / 30 ≈ 18614.7`
- `|B₅₀| ≈ 4.95 × 10¹¹`
- `|B₁₀₀| ≈ 1.90 × 10³⁰`

Знак парних чисел Бернуллі `B₂ₖ` строго чергується: `B₂ > 0`, `B₄ < 0`, `B₆ > 0`, `B₈ < 0`, … Загальна формула знака має вигляд:

```
sign(B₂ₖ) = (-1)ᵏ⁻¹
```

Це чергування знаків є безпосереднім наслідком того, що `ζ(2k) > 0` для всіх додатних дійсних `k`.

### Значення для сучасної теорії чисел

Порівняння Куммера показують, що значення нормованих чисел Бернуллі `(1 − p²ᵏ⁻¹) · (B₂ₖ / 2k)` можна p-адично інтерполювати до єдиної неперервної функції на множині p-адичних цілих чисел `ℤ_p`.

У 1964 році японські математики Томойосі Кубота та Генріх Леопольдт використали порівняння Куммера для побудови **p-адичних L-функцій Куботи — Леопольдта** `L_p(s, χ)`. Ці функції є p-адичними аналогами дзета-функції Рімана і відіграють центральну роль у сучасній теорії Івасави, що пов'язує арифметику кругових полів із модулями Івасави.

Чисельники чисел Бернуллі також відіграють вирішальну роль у класифікації простих чисел. Просте число `p` називається **регулярним простим числом**, якщо `p` не ділить чисельник жодного з чисел Бернуллі `B₂, B₄, B₆, …, Bₚ₋₃`. 

У 1850 році Куммер довів свою знамениту теорему: для всіх регулярних простих чисел `p` Велика теорема Ферма (`xᵖ + yᵖ = zᵖ` не має розв'язків у цілих ненульових числах) є **істинною**. 

Перші нерегулярні прості числа — це 37, 59, 67, 101, 131, 149, 157, 691. Кожне з них ділить чисельник відповідного числа Бернуллі:
- `37` ділить чисельник `B₃₂`
- `59` ділить чисельник `B₄₄`
- `691` ділить чисельник `B₁₂ = −691 / 2730`

Таким чином, числа Бернуллі є містком між чистою комбінаторикою, p-адичним аналізом та діофантовими рівняннями.
