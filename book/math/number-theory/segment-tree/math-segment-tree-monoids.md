# 🧮 Алгебраїчна структура дерева відрізків: моноїди, асоціативність та інтервальна комбінаторика

Математичний фундамент дерева відрізків спирається на абстрактну алгебру, а саме на поняття моноїда. Дерево відрізків перетворює послідовність елементів довільного моноїда на ієрархічну обчислювальну мережу, де кожен внутрішній вузол зберігає результат бінарного об'єднання піддерев. Цей матеріал детально виводить формальні вимоги до алгебраїчних операцій, доводить теорему про логарифмічне розбиття інтервалів, обґрунтовує інтервальні комбінаторні інваріанти та будує алгебру відкладених оновлень через ендоморфізми.

## Формальне означення моноїда та алгебраїчні інваріанти

Алгебраїчна структура `(S, ⊗, e)` називається **моноїдом**, якщо для множини `S` та бінарної операції `⊗: S × S → S` виконано дві базові аксіоми:

1. **Асоціативність:** Для будь-яких елементів `a, b, c ∈ S` справджується тотожність:
```
(a ⊗ b) ⊗ c = a ⊗ (b ⊗ c)
```
2. **Існування нейтрального елемента:** Існує унікальний елемент `e ∈ S` такий, що для кожного `a ∈ S`:
```
a ⊗ e = e ⊗ a = a
```

### Чому асоціативність є необхідною та достатньою умовою

Розглянемо впорядкований підмасив елементів `(a[L], a[L+1], ..., a[R])`. Повний асоціативний добуток усіх елементів цього підмасиву визначається як:
```
S([L, R]) = a[L] ⊗ a[L+1] ⊗ ... ⊗ a[R]
```

Завдяки аксіомі асоціативності порядок встановлення дужок у цьому виразі не впливає на кінцевий результат. Це дозволяє розбити послідовне обчислення `(R - L + 1)` елементів на будь-яке бінарне дерево групування. 

Зокрема, якщо зафіксувати точку розбиття `M = ⌊(L + R) / 2⌋`, то вираз однозначно розпадається на об'єднання двох лівого та правого підінтервалів:
```
S([L, R])
= (a[L] ⊗ ... ⊗ a[M]) ⊗ (a[M+1] ⊗ ... ⊗ a[R])    [асоціативність: групування лівого та правого блоків]
= S([L, M]) ⊗ S([M+1, R])                         [за означенням інтервальних агрегатів]
```

Якщо операція `⊗` не є асоціативною (наприклад, віднімання `a - b` або піднесення до степеня `aᵇ`), то вираз `(a - b) - c` не дорівнює `a - (b - c)`. У такому разі групування елементів за бінарним деревом дає результат, що відрізняється від лінійного послідовного проходу. Отже, **асоціативність є суворо необхідною та достатньою умовою** для побудови дерева відрізків.

Нейтральний елемент `e` відіграє роль граничного значення для порожніх інтервалів. При обчисленні запиту на діапазоні `[l, r]`, якщо поточний вузол дерева `[tl, tr]` повністю лежить поза межами запиту (тобто `[tl, tr] ∩ [l, r] = ∅`), вузол повертає елемент `e`. Згідно з другою аксіомою моноїда, об'єднання результату з `e` не змінює накопиченого значення:
```
acc ⊗ e = acc
```

## Числово-теоретичні екземпляри моноїдів

Дерево відрізків є універсальним інструментом у числово-теоретичних задачах завдяки різноманіттю моноїдних структур над множиною цілих чисел `ℤ` або кільцем лишків `ℤ_m`.

### 1. Моноїд найбільшого спільного дільника (Range GCD)

Для обчислення НСД на відрізку масиву використовується структура:
```
(ℕ₀, gcd, 0)
```
- **Операція:** `a ⊗ b = gcd(a, b)`.
- **Асоціативність:** `gcd(gcd(a, b), c) = gcd(a, gcd(b, c)) = gcd(a, b, c)`.
- **Нейтральний елемент:** `e = 0`, оскільки для будь-якого цілого `a ∈ ℕ₀` за означенням дільників маємо `gcd(a, 0) = a`.

### 2. Моноїд найменшого спільного кратного (Range LCM)

Для обчислення НСК на динамічних інтервалах:
```
(ℕ, lcm, 1)
```
- **Операція:** `a ⊗ b = lcm(a, b) = (a · b) / gcd(a, b)`.
- **Асоціативність:** `lcm(lcm(a, b), c) = lcm(a, lcm(b, c))`.
- **Нейтральний елемент:** `e = 1`, оскільки `lcm(a, 1) = a`.

### 3. Моноїд матричного множення для лінійних рекурентностей

Для швидкого знаходження значень лінійних рекурентних послідовностей (наприклад, чисел Фібоначчі або послідовностей Люка) на інтервалі коефіцієнтів застосовується моноїд квадратних матриць розмірності `K × K` над кільцем `ℤ_m`:
```
(Matₖ(ℤ_m), ×, Iₖ)
```
- **Операція:** матричне множення `A × B`.
- **Асоціативність:** `(A × B) × C = A × (B × C)`.
- **Нейтральний елемент:** одинична матриця `Iₖ`.

### 4. Арифметичний моноїд для лінійних комбінацій та модулярних добутків

У задачах модулярної арифметики часто потрібно обчислювати інтервальні добутки з динамічним модулем:
```
(ℤ_m, ×_m, 1)
```
де `a ×_m b = (a · b) mod m`. Ця структура є моноїдом, якщо `m > 1`. Вона дозволяє підтримувати префіксні добутки у скінченних полях з можливістю точкової заміни будь-якого множника.

## Теорема про логарифмічне покриття інтервалу

Сформулюємо та доведемо фундаментальну теорему про обчислювальну складність інтервального запиту.

**Теорема:** Для будь-якого інтервалу `[l, r] ⊆ [0, N - 1]` підмножина вузлів дерева відрізків, яка мінімально та точно покриває `[l, r]` без перетинів, містить не більше ніж `4 · ⌈log₂ N⌉` вузлів.

**Доведення:**

Розглянемо процес рекурсивного спуску `query(v, tl, tr, l, r)` від кореня дерева `[0, N - 1]`. На кожному рівні дерева висоти `H = ⌈log₂ N⌉ + 1` вузли класифікуються за трьома типами відносно запиту `[l, r]`:
1. **Зовнішні вузли:** `[tl, tr] ∩ [l, r] = ∅`. Базовий випадок, рекурсія негайно зупиняється й повертає `e`.
2. **Повні вузли (покриваючі):** `[tl, tr] ⊆ [l, r]`. Базовий випадок, рекурсія зупиняється й повертає значення вузла `val[v]`.
3. **Часткові вузли:** `[tl, tr] ∩ [l, r] ≠ ∅` та `[tl, tr] ⊈ [l, r]`. Рекурсія продовжується в обидва дочірні вузли.

Ключове спостереження полягає в тому, що на будь-якій фіксованій глибині дерева `h` (де `0 ≤ h ≤ H`) може існувати **не більше 2 часткових вузлів**.

Припустимо від супротивного, що на рівні `h` існує 3 або більше часткових вузлів. Оскільки всі вузли на рівні `h` утворюють впорядковане покриття відрізка `[0, N - 1]`, між двома крайніми частковими вузлами має лежати щонайменше один внутрішній вузол `V_int`. 

Оскільки крайній лівий частковий вузол містить ліву межу запиту `l`, а крайній правий містить праву межу `r`, увесь внутрішній вузол `V_int` повністю належить відрізку `[l, r]`. Але тоді `V_int` є **повним вузлом**, а не частковим. Суперечність.

Отже, на кожному рівні дерева `h` рекурсія розгалужується максимум у 2 часткових вузлах. Кожен із цих 2 часткових вузлів генерує не більше 2 дочірніх вузлів на рівні `h + 1`. Таким чином, на кожному рівні відвідується не більше 4 вузлів.

Сумарна кількість відвіданих вузлів на всіх `H` рівнях дерева обмежується величиною:
```
N_nodes ≤ 4 · H = 4 · (⌈log₂ N⌉ + 1) = O(log N)
```
Що й треба було довести. ∎

## Алгебра відкладеної пропогації (Lazy Propagation)

Техніка відкладеної пропогації вимагає формалізації зв'язку між двома алгебраїчними структурами: моноїдом значений `(S, ⊗, e)` та множиною операцій оновлення `F`, яка утворює алгебру **ендоморфізмів** `F ⊆ {f: S → S}`.

### Аксіоми дистрибутивності та композиції

Щоб групове оновлення функцією `f ∈ F` було коректним, вимагається дотримання трьох алгебраїчних умов:

1. **Дистрибутивність відносно моноїдної операції:** Для будь-якої функції оновлення `f ∈ F` та елементів `a, b ∈ S`:
```
f(a ⊗ b) = f(a) ⊗ f(b)
```
*Зауваження:* Якщо оновлення залежить від довжини інтервалу `len` (як у випадку додавання константи до суми `sum' = sum + len · v`), операція `f` розглядається як параметризована довжиною: `f_{len}(a ⊗ b) = f_{len1}(a) ⊗ f_{len2}(b)`.

2. **Замикання відносно композиції (Композиція lazy-прапорців):** Для будь-яких двох послідовних оновлень `f₁, f₂ ∈ F` їхня послідовна дія має еквівалентуватися єдиною операцією `g = f₂ ∘ f₁ ∈ F`:
```
(f₂ ∘ f₁)(a) = f₂(f₁(a))
```

3. **Тотожне перетворення (Нейтральний прапорець):** Існує нейтральне оновлення `id ∈ F` таке, що:
```
id(a) = a
```

### Покроковий математичний вивід відкладеної модифікації

Розглянемо виведення для моноїда суми `(ℤ, +, 0)` та операції додавання константи на відрізку `f_v(x) = x + len · v`.

Простежимо обчислення нового значення вузла `[L, R]` довжини `len = R - L + 1` при застосуванні двох послідовних відкладених оновлень `+v₁` та `+v₂`:

```
S_new
= f_v2(f_v1(S_old))             [послідовне застосування двох оновлень]
= f_v2(S_old + len · v1)        [розгортання першої функції f_v1]
= (S_old + len · v1) + len · v2 [розгортання другої функції f_v2]
= S_old + len · (v1 + v2)       [дистрибутивність множення та асоціативність додавання]
= f_{v1 + v2}(S_old)            [еквівалентна композиція прапорців lazy_new = lazy_old + v]
```

Цей висновок показує, що замість повторного проходу по дереву відкладені прапорці акумулюються у вузлі через звичайне додавання: `lazy[v] = lazy[v] + v_add`.

### Композиція для присвоєння та додавання (Affine Lazy Transformations)

У складних афінних оновленнях елементи замінюються за правилом `x' = a · x + b`. Для таких оновлень відкладений прапорець зберігає пару `(a, b)`. 

Композиція двох афінних оновлень `(a₁, b₁)` та `(a₂, b₂)` виводиться як:
```
x''
= a₂ · (a₁ · x + b₁) + b₂       [послідовне застосування двох афінних перетворень]
= (a₂ · a₁) · x + (a₂ · b₁ + b₂) [раціональне групування за асоціативністю кільця]
```

Отже, нова пара відкладених прапорців дорівнює:
```
a_new = a₂ · a₁
b_new = a₂ · b₁ + b₂
```

Це доводить, що афінні перетворення на відрізках також утворюють замиканий моноїд ендоморфізмів, який зберігає логарифмічну складність оновлення.

## Числовий приклад: Динамічний НСД та точкове оновлення

Продемонструємо роботу моноїда `(ℕ₀, gcd, 0)` на конкретному числовому масиві з 4 елементів:
```
A = [24, 36, 60, 48]
```

### 1. Побудова дерева відрізків (Build)

Вузли розраховуються знизу вгору за правилом `val[v] = gcd(val[2v], val[2v+1])`:

- **Листя:**
  - `v=4: [0, 0] = A[0] = 24`
  - `v=5: [1, 1] = A[1] = 36`
  - `v=6: [2, 2] = A[2] = 60`
  - `v=7: [3, 3] = A[3] = 48`

- **Внутрішні вузли:**
  - `v=2: [0, 1] = gcd(24, 36) = 12`
  - `v=3: [2, 3] = gcd(60, 48) = 12`
  - `v=1: [0, 3] = gcd(val[2], val[3]) = gcd(12, 12) = 12`

### 2. Запит НСД на відрізку query(1, 2)

Необхідно обчислити `gcd(A[1], A[2]) = gcd(36, 60) = 12`.

1. Запит у корінь `v=1 [0, 3]`: частковий перетин. Розгалуження в `v=2` та `v=3`.
2. Запит у `v=2 [0, 1]`: частковий перетин із `[1, 2]`. Розгалуження в `v=4 [0, 0]` (поза межами → повертає `0`) та `v=5 [1, 1]` (повний перетин → повертає `36`). Результат `v=2`: `gcd(0, 36) = 36`.
3. Запит у `v=3 [2, 3]`: частковий перетин із `[1, 2]`. Розгалуження в `v=6 [2, 2]` (повний перетин → повертає `60`) та `v=7 [3, 3]` (поза межами → повертає `0`). Результат `v=3`: `gcd(60, 0) = 60`.
4. Комбінація на рівні кореня: `gcd(36, 60) = 12`.

### 3. Точкове оновлення update(1, 18)

Змінюємо елемент `A[1] = 18`.

1. Оновлюємо листок `v=5 [1, 1]`: `val[5] = 18`.
2. Перераховуємо батька `v=2 [0, 1]`: `val[2] = gcd(val[4], val[5]) = gcd(24, 18) = 6`.
3. Перераховуємо корінь `v=1 [0, 3]`: `val[1] = gcd(val[2], val[3]) = gcd(6, 12) = 6`.

Після точкового оновлення за `O(log N)` дерево відновило всі алгебраїчні інваріанти.
