# 🧮 Доведення теореми Ферма: метод нескінченного спуску та алгебра ℤ[i]

Ця вставка розгортає суворі математичні доведення теореми Ферма про суму двох квадратів, поєднуючи класичний конструктивний метод нескінченного спуску Леонарда Ейлера, геометрію чисел Германа Мінковського, комбінаторне доведення Дона Загіра та структурний алгебраїчний підхід Карла Фрідріха Ґаусса через кільце цілих комплексних чисел.

## Частина 1. Існування квадратичного лишку та початкове діленне

Перш ніж будувати конкретне подання простого числа у вигляді суми двох квадратів, необхідно довести існування допоміжного цілочислового виразу, який ділиться на це просте число. Нехай `p` — довільне непарне просте число виду `p ≡ 1 (mod 4)`. Задача полягає в тому, щоб знайти таке ціле число `x`, для якого сума `x² + 1` ділиться на `p` без остачі.

За малою теоремою Ферма, для будь-якого цілого числа `a`, яке не ділиться на `p`, справджується фундаментальне порівняння:

```
a^(p - 1) ≡ 1 (mod p)      [мала теорема Ферма]
```

Оскільки просте число `p` дає залишок `1` при діленні на `4`, показник степеня `p - 1` є кратним `4`. Запишемо його у вигляді `p - 1 = 4k`, де `k` — додатне ціле число. Скориставшись формулою різниці квадратів, розкладемо вираз `a^(4k) - 1` на два множники:

```
a^(4k) - 1
= (a^(2k) - 1)(a^(2k) + 1)      [різниця квадратів: A² - B² = (A - B)(A + B)]
= (a^((p-1)/2) - 1)(a^((p-1)/2) + 1)
```

За критерієм Ейлера для квадратичних залишків, значення символу Лежандра `(-1/p)` визначається порівнянням за модулем `p`. Оскільки `(p - 1)/2 = 2k` є парним числом, ми отримуємо:

```
(-1/p)
≡ (-1)^((p-1)/2) (mod p)      [критерій Ейлера для квадратичного залишку]
= (-1)^(2k)                   [показник 2k є парним]
= 1 (mod p)                   [піднесення -1 до парного степеня дає +1]
```

Отже, значення `-1` є квадратичним залишком за модулем `p`. Це означає, що серед цілих чисел від `1` до `(p - 1)/2` обов'язково існує принаймні одне таке число `x`, квадрат якого порівнянний з `-1` за модулем `p`:

```
x² ≡ -1 (mod p)      [існування розв'язку рівняння за модулем p]
```

Додавши `1` до обох частин порівняння, ми бачимо, що вираз `x² + 1` ділиться на `p` без остачі. Це означає існування такого додатного цілого числа `m`, що:

```
m · p = x² + 1²      [кратність: x² + 1 є сумою двох квадратів]
```

Оцінимо величину множника `m`. Оскільки `x` вибирається в інтервалі `1 ≤ x ≤ (p - 1)/2 < p/2`, ми можемо записати нерівність для `m · p`:

```
m · p
= x² + 1               [підстановка виразу для m·p]
≤ (p/2)² + 1           [верхня оцінка x < p/2]
= p²/4 + 1             [піднесення до квадрата]
< p²                   [строга нерівність для p ≥ 5]
```

Поділивши обидві частини нерівності на `p`, отримуємо важливе обмеження на множник `m`:

```
m < p      [початковий множник m строго менший за p]
```

Ми встановили, що завжди існує додатне ціле число `m < p`, таке що кратне `m · p` подається у вигляді суми двох квадратів `x² + 1²`. Якщо виявиться, що `m = 1`, то теорему для даного `p` вже доведено. Якщо ж `m > 1`, вступає в дію конструктивний механізм зменшення множника `m`, відомий як метод нескінченного спуску.

## Частина 2. Крок нескінченного спуску Ейлера

Припустимо, що на певному етапі ми маємо рівність, у якій добуток `m · p` подано у вигляді суми двох квадратів цілих чисел `a` та `b`, де `1 < m < p`:

```
m · p = a² + b²      [припущення поточного кроку спуску]
```

Головна мета кроку спуску полягає в тому, щоб за значеними числами `a`, `b` та `m` сконструювати нові цілі числа `a'`, `b'` та новий множник `r`, який задовольняє дві фундаментальні умови: по-перше, `1 ≤ r < m` (множник строго зменшується), і по-друге, добуток `r · p` також виражається сумою двох квадратів `a'² + b'²`.

Для побудови таких чисел розглянемо ділення `a` та `b` на `m` з остачею в найменших за абсолютною величиною лишках. Це означає, що ми вибираємо цілі числа `u` та `v` у симетричному інтервалі від `-m/2` до `m/2` так, щоб справджувалися порівняння:

```
u ≡ a (mod m),     де -m/2 < u ≤ m/2      [найменший лишок числа a за модулем m]
v ≡ b (mod m),     де -m/2 < v ≤ m/2      [найменший лишок числа b за модулем m]
```

Розглянемо суму квадратів цих лишків `u² + v²` та дослідимо її подільність на `m`:

```
u² + v²
≡ a² + b² (mod m)      [заміна u на a та v на b за модулем m]
= m · p (mod m)        [оскільки a² + b² = m · p]
≡ 0 (mod m)            [m · p ділиться на m без остачі]
```

Оскільки сума `u² + v²` є кратною `m`, існує ціле неот'ємне число `r`, таке що:

```
m · r = u² + v²      [визначення нового множника r]
```

Оцінимо зверху значення `r`, використовуючи обмеження на лишки `|u| ≤ m/2` та `|v| ≤ m/2`:

```
m · r
= u² + v²              [значення суми квадратів лишків]
≤ (m/2)² + (m/2)²      [оцінка квадратів лишків]
= m²/4 + m²/4          [обчислення квадратів]
= m²/2                 [сума не перевищує m²/2]
```

Поділивши обидві частини на `m > 0`, отримуємо сувору верхню оцінку для `r`:

```
r ≤ m/2 < m      [новий множник r строго менший за поточний множник m]
```

Тепер важливо перевірити, чи може `r` дорівнювати нулю. Випадок `r = 0` означав би, що `u² + v² = 0`, що для дійсних цілих чисел можливо лише за умови `u = 0` та `v = 0`. Проте якщо `u = 0` і `v = 0`, це означає, що і `a`, і `b` діляться на `m` без остачі: `a = k₁ · m` та `b = k₂ · m`. Підставивши ці значення в початкове рівняння `m · p = a² + b²`, ми б отримали:

```
m · p
= (k₁ · m)² + (k₂ · m)² [підстановка a = k₁·m та b = k₂·m]
= m² · (k₁² + k₂²)       [винесення спільного множника m²]
```

Поділивши на `m`, маємо `p = m · (k₁² + k₂²)`. Оскільки `p` — просте число, а за умовою `1 < m < p`, вираз `p` не може мати власних дільників, крім `1` та `p`. Це створює суперечність із припущенням `1 < m < p`. Отже, `r` не може дорівнювати нулю:

```
1 ≤ r ≤ m/2 < m      [значення r є додатним цілим числом, строго меншим за m]
```

Тепер перемножимо дві рівності `m · p = a² + b²` та `m · r = u² + v²`:

```
(m · p)(m · r)
= (a² + b²)(u² + v²)      [перемноження виразів]
```

Застосуємо класичну тотожність Брахмагупти-Фібоначчі до правої частини цієї рівності:

```
m² · p · r
= (au + bv)² + (av - bu)²      [тотожність: (a²+b²)(u²+v²) = (au+bv)² + (av-bu)²]
```

Доведемо, що додатки `au + bv` та `av - bu` діляться на `m` без остачі. Заставивши порівняння `u ≡ a` та `v ≡ b (mod m)`, отримуємо:

```
au + bv
≡ a · a + b · b (mod m) [заміна u на a та v на b mod m]
= a² + b² (mod m)       [алгебраїчна підстановка]
= m · p (mod m)         [оскільки a² + b² = m·p]
≡ 0 (mod m)             [вираз au + bv ділиться на m]
```

Аналогічно перевіряємо другий вираз:

```
av - bu
≡ a · b - b · a (mod m) [заміна u на a та v на b mod m]
= 0 (mod m)             [вираз av - bu ділиться на m]
```

Оскільки обидва вирази `au + bv` та `av - bu` є кратними `m`, ми можемо визначити нові цілі числа `a'` та `b'`:

```
a' = (au + bv) / m      [ціле число a']
b' = (av - bu) / m      [ціле число b']
```

Підставивши `au + bv = m · a'` та `av - bu = m · b'` у рівняння з тотожністю Брахмагупти, отримуємо:

```
m² · p · r
= (m · a')² + (m · b')² [підстановка au+bv = m·a' та av-bu = m·b']
= m² · (a'² + b'²)      [винесення m² за дужки]
```

Скоротивши обидві частини на `m² > 0`, маємо остаточну формулу кроку спуску:

```
r · p = a'² + b'²      [подання r·p у вигляді суми двох квадратів]
```

Ми побудували нову суму квадратів для `r · p` з новим множником `1 ≤ r < m`. Якщо `r = 1`, процес завершено, і ми отримали `p = a'² + b'`. Якщо ж `r > 1`, ми повторюємо описувану процедуру для `r` замість `m`. Оскільки послідовність натуральних чисел `m > r > r₁ > r₂ > ... ≥ 1` є строго спадною і обмеженою знизу одиницею, цей процес не може тривати нескінченно. За скінченне число кроків ми неодмінно досягнемо значення `r = 1`, що доводить виражуваність `p` у вигляді суми двох квадратів.

## Частина 3. Практичний числовий приклад методу спуску для p = 73

Щоб зробити механізм нескінченного спуску Ейлера повністю прозорим та унаочнити обчислення, простежимо його покроково на конкретному числовому прикладі для простого числа `p = 73`.

Перевіримо порівнянність цього числа за модулем 4: `73 = 4 · 18 + 1`, тобто `73 ≡ 1 (mod 4)`.

Крок 1. Знайдемо число `x` таке, що `x² ≡ -1 (mod 73)`. Шляхом перевірки або за допомогою піднесення до степеня `g^((p-1)/4) mod p` для генератора `g = 5`, отримуємо `x = 27`, оскільки:

```
27² = 729 = 10 · 73 - 1 ≡ -1 (mod 73)      [27 є квадратним коренем з -1 mod 73]
```

Обчислимо початкову суму квадратів та початковий множник `m`:

```
27² + 1² = 729 + 1 = 730 = 10 · 73      [початкове значення: a = 27, b = 1, m = 10]
```

Отже, маємо `m = 10` та `10 · 73 = 27² + 1²`. Оскільки `m = 10 > 1`, виконуємо перший крок алгоритму спуску.

Крок 2. Знайдемо лишки `u` та `v` при діленні `a = 27` та `b = 1` на `m = 10` у симетричному інтервалі `[-5, 5]`:

```
u ≡ 27 ≡ 7 ≡ -3 (mod 10),     отже u = -3      [найменший лишок для a = 27]
v ≡ 1 (mod 10),               отже v = 1       [найменший лишок для b = 1]
```

Обчислимо суму квадратів лишків `u² + v²` та новий зменшений множник `r`:

```
u² + v² = (-3)² + 1² = 9 + 1 = 10 = 10 · 1      [отже r = 1]
```

Новий множник `r = 1` строго менший за початковий множник `m = 10`. Застосуємо тотожність Брахмагупти для обчислення нових цілих чисел `a'` та `b'`:

```
au + bv = 27 · (-3) + 1 · 1 = -81 + 1 = -80
av - bu = 27 · 1 - 1 · (-3) = 27 + 3 = 30
```

Поділимо обидва отриманих значення на значення `m = 10`:

```
a' = (-80) / 10 = -8
b' = 30 / 10 = 3
```

Перевіримо підсумкову суму квадратів для знайдених чисел `a'` та `b'`:

```
a'² + b'² = (-8)² + 3² = 64 + 9 = 73      [отримано розклад 73 = 8² + 3²]
```

Метод спуску Ейлера завершився всього за один крок, давши точний і суворий розклад `73 = 3² + 8²`.

## Частина 4. Доведення через лему Тюе та геометрію чисел

Існує інший, не менш елегантний спосіб доведення теореми Ферма, який повністю уникає ітеративного нескінченного спуску й базується на комбінаторному принципі Діріхле (принцип коробки) або геометрії чисел Германа Мінковського.

Центральним інструментом цього підходу є лема Тюе (названа на честь норвезького математика Акселя Тюе, норв. Axel Thue). Вона стверджує: якщо `p` — просте число, а `z` — довільне ціле число, не кратне `p`, то обов'язково існують такі цілі числа `x` та `y`, що:

```
z · x ≡ y (mod p),     де 0 < |x|, |y| < √p      [лема Тюе]
```

Доведемо лему Тюе за допомогою принципу Діріхле. Покладемо `k = ⌊√p⌋`. Розглянемо множину впорядкованих пар цілих чисел `(u, v)`, де `0 ≤ u ≤ k` та `0 ≤ v ≤ k`. Кількість таких пар у даній множині дорівнює `(k + 1)²`.

Оскільки `k = ⌊√p⌋`, випливає сувора нерівність `k + 1 > √p`, а отже `(k + 1)² > p`.

Для кожної пари `(u, v)` обчислимо значення лінійного виразу `z · u - v (mod p)`. Оскільки всього ми маємо `(k + 1)² > p` різних пар, а можливих залишків за модулем `p` існує лише `p` штук (від `0` до `p - 1`), за принципом Діріхле знаходяться принаймні дві різні пари `(u₁, v₁)` та `(u₂, v₂)`, які дають одинаковий залишок при діленні на `p`:

```
z · u₁ - v₁ ≡ z · u₂ - v₂ (mod p)      [співпадання залишків за принципом Діріхле]
```

Перегрупуємо доданки в цьому порівнянні:

```
z · (u₁ - u₂) ≡ v₁ - v₂ (mod p)        [перенесення елементів]
```

Покладемо `x = u₁ - u₂` та `y = v₁ - v₂`. Оскільки вихідні пари `(u₁, v₁)` та `(u₂, v₂)` є різними, числа `x` та `y` не можуть одночасно дорівнювати нулю. Крім того, оскільки `0 ≤ u₁, u₂ ≤ k < √p` та `0 ≤ v₁, v₂ ≤ k < √p`, маємо суворі оцінки для абсолютних величин:

```
0 < |x| < √p,     0 < |y| < √p         [оцінка величин x та y]
```

Якщо припустити `x = 0`, то `y ≡ 0 (mod p)`, що разом із нерівністю `|y| < √p < p` давало б `y = 0` — що суперечить умові відмінності пар. Отже, `x ≠ 0` та `y ≠ 0`. Лему Тюе повністю доведено.

Тепер застосуємо лему Тюе безпосередньо до доведення теореми Ферма. Як показано у Частині 1, для `p ≡ 1 (mod 4)` існує таке `z`, що `z² ≡ -1 (mod p)`. За лемою Тюе, знайдуться цілі числа `x` та `y`, такі що `z · x ≡ y (mod p)` з `0 < |x|, |y| < √p`.

Піднесемо це порівняння до квадрата:

```
z² · x² ≡ y² (mod p)      [піднесення до квадрата]
```

Оскільки `z² ≡ -1 (mod p)`, підставимо `-1` замість `z²`:

```
-x² ≡ y² (mod p)          [підстановка z² ≡ -1]
x² + y² ≡ 0 (mod p)       [сума квадратів ділиться на p]
```

Отже, сума `x² + y²` є кратною `p`. Оцінимо величину цієї суми квадратів зверху та знизу:

```
0 < x² + y² < (√p)² + (√p)² = 2p      [оцінка суми квадратів]
```

Єдиним цілим числом, яке ділиться на `p` і строго лежить у відкритому інтервалі між `0` та `2p`, є саме число `p`! Це означає, що:

```
x² + y² = p      [прямий розклад p у суму двох квадратів]
```

Це доведення за допомогою леми Тюе є набагато коротшим за метод нескінченного спуску і безпосередньо дає конструктивне подання.

## Частина 5. Комбінаторне однореченнєве доведення Дона Загіра

У 1990 році Дон Загір запропонував дивовижно стисле комбінаторне доведення, що спирається на інволюції (самообернені відображення) на скінченній множині цілочислових трійок.

Нехай `p = 4k + 1` — просте число. Розглянемо скінченну множину трійок додатних цілих чисел `x, y, z`:

```
S = {(x, y, z) ∈ ℕ³ | x² + 4yz = p}      [скінченна множина трійок]
```

Оскільки `x`, `y`, `z` є додатними цілими числами, з рівняння `x² < p` випливає, що множина `S` є скінченною. Визначимо на `S` відображення `f: S → S` за такою кусково-лінійною формулою:

```
f(x, y, z) = (x + 2z, z, y - x - z)      при x < y - z
f(x, y, z) = (2z - x, z, x - y + z)      при y - z < x < 2z
f(x, y, z) = (x - 2z, x - y + z, z)      при x > 2z
```

Шляхом прямої алгебраїчної перевірки можна пересвідчитися, що `f` переводить кожну трійку `(x, y, z) ∈ S` у іншу трійку з `S`, і при цьому `f(f(x, y, z)) = (x, y, z)`. Тобто `f` є інволюцією на множині `S`.

Знайдемо нерухомі точки цієї інволюції, тобто такі трійки, для яких `f(x, y, z) = (x, y, z)`. Рівність можлива лише у другому випадку визначення `f`, коли `x = 2z - x`, що дає `x = z`. Тоді з умов другого випадку `y - z < z < 2z` випливає `y = 2z - (x - y + z)`, тобто `y = x = z`.

Підставивши `x = y = z` у рівняння множини `S`, отримуємо:

```
x² + 4x² = 5x² = p      [що неможливо для простого p ≡ 1 mod 4, крім p = 5]
```

Для довільного простого `p ≡ 1 (mod 4)` єдиною нерухомою точкою інволюції `f` є трійка `(1, 1, k)`, де `k = (p - 1)/4`. Оскільки `f` має рівно одну нерухому точку, а решта елементів `S` розбиваються на неперетинні пари вида `{s, f(s)}`, загальна кількість елементів у множині `S` є непарним числом!

Тепер розглянемо другу, набагато простішу інволюцію `g` на множині `S`:

```
g(x, y, z) = (x, z, y)      [перестановка другої та третьої компонент]
```

Оскільки потужність множини `S` є непарним числом, будь-яка інволюція на `S` обов'язково повинна мати принаймні одну нерухому точку! Адже якби `g` не мала нерухомих точок, усі елементи `S` розбилися б на пари вида `{s, g(s)}`, що вимагало б парності загальної кількості елементів `|S|`.

Нерухома точка для інволюції `g` означає існування трійки `(x, y, z) ∈ S`, для якої `g(x, y, z) = (x, y, z)`, тобто `y = z`.

Підставивши `y = z` у рівняння множини `S`, отримуємо шуканий розклад:

```
x² + 4y² = x² + (2y)² = p      [отримано розклад p у суму двох квадратів]
```

Це покладає край комбінаторному доведенню: додатні цілі числа `a = x` та `b = 2y` дають суворий розклад `p = a² + b²`.

## Частина 6. Алгебраїчний підхід Ґаусса через цілі числа ℤ[i]

Альтернативний структурний підхід спирається на теорію кілець. Розглянемо множину комплексних чисел вида `ℤ[i] = {a + bi | a, b ∈ ℤ}`, звану кільцем цілих чисел Ґаусса.

Для кожного елемента `α = a + bi ∈ ℤ[i]` визначається норма `N(α)` як квадрат його комплексного модуля:

```
N(α)
= α · ᾱ
= (a + bi)(a - bi)
= a² + b²               [норма в ℤ[i] дорівнює сумі квадратів]
```

Норма є строго мультиплікативною функцією: для будь-яких двох чисел Ґаусса `α, β ∈ ℤ[i]` справджується тотожність `N(α · β) = N(α) · N(β)`. Ця властивість безпосередньо еквівалентна тотожності Брахмагупти-Фібоначчі.

Кільце `ℤ[i]` є Евклідовим доміном відносно норми `N`. Це означає, що для будь-яких двох елементів `α, β ∈ ℤ[i]` при `β ≠ 0` існують такі елементи `q, r ∈ ℤ[i]`, що:

```
α = q · β + r,     де N(r) < N(β)      [ділення з остачею в ℤ[i]]
```

З евклідовості випливає, що `ℤ[i]` є факторіальним кільцем (доміном головних ідеалів), у якому справджується основна теорема арифметики: кожен елемент єдиним чином (з точністю до множення на дільники одиниці `±1, ±i`) розкладається на прості множники Ґаусса.

Застосуємо факторіальність `ℤ[i]` для доведення теореми Ферма:

1. Нехай `p ≡ 1 (mod 4)`. З Частини 1 відомо, що існує ціле `x`, таке що `x² + 1` ділиться на `p` у `ℤ`.
2. У кільці `ℤ[i]` вираз `x² + 1` розкладається на множники:

```
x² + 1 = (x + i)(x - i)      [розклад на множники в ℤ[i]]
```

3. Отже, дійсне просте число `p` ділить добуток `(x + i)(x - i)` у кільці `ℤ[i]`.
4. Якби `p` було простим (незвідним) елементом у `ℤ[i]`, то за лемою Евкліда воно повинно було б ділити принаймні один із множників: `(x + i)` або `(x - i)`.
5. Проте ділення `(x + i) / p = (x/p) + (1/p)i` не дає цілого числа Ґаусса, оскільки уявна частина `1/p` не є цілим числом.
6. Отже, `p` НЕ є простим елементом у `ℤ[i]`. Воно є складеним у `ℤ[i]` і розкладається на добуток двох недишифрованих елементів `π₁` та `π₂`:

```
p = π₁ · π₂      [розклад p на множники Ґаусса]
```

7. Застосуємо норму `N` до обох частин цієї рівності:

```
N(p) = N(π₁) · N(π₂)
p² = N(π₁) · N(π₂)      [оскільки N(p) = p² для дійсного числа p]
```

8. Оскільки `π₁` та `π₂` не є одиницями кільця (іхні норми строго більші за `1`), єдиним можливим значенням норм для цих множників у натуральних числах є:

```
N(π₁) = p,     N(π₂) = p      [норма множника Ґаусса дорівнює p]
```

9. Нехай `π₁ = a + bi`. За визначенням норми в `ℤ[i]`, маємо:

```
N(π₁) = a² + b² = p      [знаходження розкладу p у суму двох квадратів]
```

Це повністю завершує алгебраїчне доведення Ґаусса.

## Частина 7. Єдиність розкладу p = a² + b²

Наостанок доведемо, що для будь-якого простого числа `p ≡ 1 (mod 4)` розклад у суму двох квадратів `p = a² + b²` є єдиним з точністю до порядку доданків та знаків `a` і `b`.

Нехай існують два розклади у додатних цілих числах `a, b, c, d > 0`:

```
p = a² + b² = c² + d²      [два припущені розклади для p]
```

Перемножимо обидва вирази та застосуємо тотожність Брахмагупти-Фібоначчі в обох її формах:

```
p²
= (a² + b²)(c² + d²)           [добуток двох рівностей для p]
= (ac - bd)² + (ad + bc)²      [перша форма тотожності]
= (ac + bd)² + (ad - bc)²      [друга форма тотожності]
```

Також розглянемо добуток `(ac - bd)(ac + bd)`:

```
(ac - bd)(ac + bd)
= a²c² - b²d²                  [різниця квадратів]
= a²c² + a²d² - a²d² - b²d²    [додавання і віднімання a²d²]
= a²(c² + d²) - d²(a² + b²)    [групування доданків]
= a² · p - d² · p              [підстановка a²+b²=p та c²+d²=p]
= p · (a² - d²)                [винесення спільного множника p]
```

Оскільки `p` — просте число, воно мусить ділити один із множників: `ac - bd` або `ac + bd`.

Якщо `p` ділить `ac - bd`, оскільки `|ac - bd| < p`, єдиною можливістю є `ac - bd = 0`. Звідси `ac = bd`. Оскільки `gcd(a, b) = 1` та `gcd(c, d) = 1`, це вимагає `a = d` та `b = c`.

Якщо ж `p` ділить `ac + bd`, то `ac + bd = p`. Тоді з рівняння `p² = (ac + bd)² + (ad - bc)²` маємо `p² = p² + (ad - bc)²`, звідки `ad - bc = 0`, що означає `ad = bc` та дає `a = c` і `b = d`.

Отже, розклад `p = a² + b²` є єдиним з точністю до перестановки та знаків.
