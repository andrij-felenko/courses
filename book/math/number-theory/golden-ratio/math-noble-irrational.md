# 🧮 Найшляхетніша ірраціональність: теорема Гурвіца та розклад у ланцюговий дріб

У теорії діофантових наближень золотий перетин `φ = (1 + √5)/2` посідає виняткове становище. Воно є «найгіршим» ірраціональним числом для наближення раціональними дробами — тобто звичайними дробами вигляду `p/q`. Ця властивість, яка на перший погляд здається недоліком у чисельних обчисленнях, виявляється вирішальною перевагою у теорії хаосу, небесній механіці та ботанічному фалотаксисі: саме вона створює максимальне ухилення від резонансних збурень. Ця вставка виводить повний розклад `φ` у ланцюговий дріб, детально доводить теорему Гурвіца про фундаментальну межу наближень, описує дерево Маркова–Лагранжа та будує доведення евклідової арифметики в квадратичному кільці `ℤ[φ]`.

## Розклад у ланцюговий дріб: нескінченна піраміда з одиниць

Будь-яке дійсне число `x` можна подати у вигляді нескінченного ланцюгового (або неперервного) дробу `x = [a₀; a₁, a₂, a₃, ...]`, що будується за алгоритмом відокремлення цілої частини та обернення дробового залишку:

```
x = a₀ + ──────────────1──────────────
         a₁ + ──────────1──────────
              a₂ + ──────1──────
                   a₃ + ──1──
                        ...
```

де `a₀ ∈ ℤ` — ціла частина числа, а `a₁, a₂, a₃, ... ∈ ℕ` — натуральні числа, які називають неповними частками.

Для золотого перетину `φ` вихідним алгебраїчним співвідношенням є тотожність `φ - 1 = 1/φ`, або еквівалентно:

```
φ = 1 + 1/φ
```

Оскільки `φ ≈ 1.618`, його ціла частина дорівнює `a₀ = ⌊φ⌋ = 1`, а дробова частина становить `φ - 1 = 1/φ`. Підставимо сам вираз `1 + 1/φ` замість `φ` у знаменник дробового доданка:

```
φ = 1 + ──────1──────
        1 + ──1──
             φ
```

Повторюючи цю процедуру заміни `φ` на `1 + 1/φ` нескінченну кількість разів, ми отримуємо строго впорядкований ланцюговий дріб:

```
φ = 1 + ────────────────1────────────────
        1 + ────────────1────────────
            1 + ────────1────────
                1 + ────1────
                    1 + ...
```

У компактній записові це виглядає як `φ = [1; 1, 1, 1, ...]`. Оскільки всі неповні частки дорівнюють одиниці — найменшому з можливих натуральних чисел, — цей ланцюговий дріб є найпростішим за структурою і водночас найповільніше збіжним з усіх можливих нескінченних ланцюгових дробів.

Обчислимо послідовність підхідних дробів `pₙ/qₙ`, які утворюються шляхом обриву нескінченного ланцюгового дробу на `n`-му кроці:

```
n = 0:  p₀/q₀ = 1 / 1 = 1.000000...
n = 1:  p₁/q₁ = 1 + 1/1 = 2/1 = 2.000000...
n = 2:  p₂/q₂ = 1 + 1/(1 + 1/1) = 3/2 = 1.500000...
n = 3:  p₃/q₃ = 1 + 1/(1 + 1/(1 + 1/1)) = 5/3 ≈ 1.666667...
n = 4:  p₄/q₄ = 8/5 = 1.600000...
n = 5:  p₅/q₅ = 13/8 = 1.625000...
n = 6:  p₆/q₆ = 21/13 ≈ 1.615385...
n = 7:  p₇/q₇ = 34/21 ≈ 1.619048...
```

Доведемо за індукцією, що `pₙ = Fₙ₊₂` та `qₙ = Fₙ₊₁`.
Для `n = 0`: `p₀ = 1 = F₂`, `q₀ = 1 = F₁`.
Для `n = 1`: `p₁ = 2 = F₃`, `q₁ = 1 = F₂`.
Рекурентні формули підхідних дробів для `aₙ₊₁ = 1`:

```
pₙ₊₁ = 1 · pₙ + pₙ⋁₁ = Fₙ₊₂ + Fₙ₊₁ = Fₙ₊₃
qₙ₊₁ = 1 · q♙ + q♙⋁₁ = Fₙ₊₁ + F♙   = Fₙ₊₂
```

Таким чином, підхідні дроби золотого перетину — це точні відношення сусідніх чисел Фібоначчі `Fₙ₊₂ / Fₙ₊₁`.

## Геометрична інтерпретація на цілочисельній ґратці ℤ²

Геометричний зміст наближень `p/q` розкривається на цілочисельній площині `ℤ²`. Розглянемо пряму променю `y = φ · x`.
Будь-яка точка з цілими координатами `(q, p) ∈ ℤ²` лежить на деякій відстані від цього променя. Відстань по вертикалі від точки `(q, p)` до прямої становить `|p − φ q| = q · |φ − p/q|`.

Завдяки тому, що всі неповні частки `φ` дорівнюють 1, пряма `y = φ x` проходить у двовимірному просторі так, що вона оминає цілочисельні вузли ґратки `ℤ²` на максимально можливих відстанях. Жоден цілочисельний вектор `(q, p)` не лежить близько до прямої, за винятком векторів Фібоначчі `(Fₙ₊₁, Fₙ₊₂)`.

Для порівняння, пряма `y = π x` проходить дуже близько до вузла `(113, 355)`, оскільки неповна частка `a₄ = 292` підводить пряму майже впритул до цілочисельної точки ґратки.

## Чому одиниці роблять наближення найповільнішим

У класичній теорії ланцюгових дробів відстань між дійсним числом `α` та його `n`-м підхідним дробом `pₙ/qₙ` обмежується суворим виразом:

```
│      pₙ │           1
│ α − ────│  =  ─────────────────
│      qₙ │     q♙ (a♙₊₁ q♙ + q♙⋁₁)
```

Розберемо знаменник цього виразу. Щоб підхідний дріб `pₙ/qₙ` опинився якомога ближче до `α`, величина в знаменнику `aₙ₊₁ q♙ + q♙⋁₁` має бути якнайбільшою. Якщо чергова неповна частка `aₙ₊₁` виявляється великим числом (наприклад, `aₙ₊₁ = 100` або `aₙ₊₁ = 1000`), то знаменник стрибкоподібно зростає, і похибка `|α - pₙ/qₙ|` миттєво зменшується в сотні або тисячі разів. Саме так поводиться розклад числа `π = [3; 7, 15, 1, 292, ...]`, де неповна частка `a₄ = 292` забезпечує надзвичайно точний дріб `355/113`.

Проте для золотого перетину `φ` всі неповні частки дорівнюють мінімально можливому натуральному значенню `aₙ₊₁ = 1`. Знаменник зростає виключно за рахунок додавання двох попередніх знаменників: `q♙ (1·q♙ + q♙⋁₁) = q♙ q♙₊₁`. Тому похибка зменшується з найменшою можливою швидкістю серед усіх ірраціональних чисел.

Дослідимо нормовану похибку наближення, помноживши абсолютну різницю на `qₙ²`:

```
              1               1             1
qₙ² │φ − pₙ/qₙ│  =  ─────────────  =  ─────────────
                     aₙ₊₁ + q♙⋁₁/q♙     1 + F♙/F♙₊₁
```

Оскільки відношення знаменників підхідних дробів прямує до оберненого золотого перетину `F♙/F♙₊₁ → 1/φ = φ − 1` при `n → ∞`, ми можемо обчислити точну Границю нормованої похибки:

```
         1           1           1
lim ───────────  =  ───────  =  ────  ≈  0.44721359...
n→∞  1 + (φ − 1)       φ        √5
```

Це означає, що для золотого перетину нормована похибка наближення раціональними дробами тулиться до граничної межі `1 / (√5 qₙ²)`.

## Загальна константа Лагранжа для періодичних ланцюгових дробів

Узагальнимо цей результат для довільного чисто періодичного ланцюгового дробу вигляду `α☿ = [k; k, k, k, ...]`, де `k ∈ ℕ` — натуральне число (металева пропорція):

```
α☿ = k + 1/α☿   ⟹   α☿² − k α☿ − 1 = 0   ⟹   α☿ = (k + √(k² + 4)) / 2
```

Граничне значення константи Лагранжа `L(α☿) = lim_{n→∞} qₙ² |α☿ − pₙ/qₙ|` обчислюється як:

```
L(α☿) = 1 / √(k² + 4)
```

- Для `k = 1` (золотий перетин): `L(φ) = 1 / √5 ≈ 0.447214` (найвищий поріг похибки).
- Для `k = 2` (срібна пропорція `1 + √2`): `L(δ_S) = 1 / √8 = 1 / (2√2) ≈ 0.353553`.
- Для `k = 3` (бронзова пропорція): `L(M₃) = 1 / √13 ≈ 0.277350`.

Цей розрахунок наочно показує, що при зростанні `k` неповні частки збільшуються, і якість раціонального наближення покращується, роблячи `k = 1` (золотий перетин) абсолютно унікальним піком діофантової упертості.

## Породжувальна функція та радіус збіжності

Розглянемо аналітичну породжувальну функцію (*generating function*) для послідовності чисел Фібоначчі:

```
G(x) = F₀ + F₁ x + F₂ x² + F₃ x³ + ... = ∑ Fₙ xⁿ
```

Підставивши рекурентне співвідношення `Fₙ = Fₙ⋁₁ + Fₙ⋁₂`, отримуємо алгебраїчну рівність:

```
G(x) − x G(x) − x² G(x) = x   ⟹   G(x) (1 − x − x²) = x
```

Отже, породжувальна функція має вигляд раціонального дробу:

```
          x
G(x) = ─────────
       1 − x − x²
```

Полюси цієї функції — це корені знаменника `1 − x − x² = 0`, які дорівнюють:

```
x₁ = −φ ≈ −1.618034,      x₂ = 1/φ = φ − 1 ≈ 0.618034
```

Найближчим до початку координат полюсом є `x₂ = 1/φ`. Згідно з теоремою Коші–Адамара, **радіус збіжності** степеневого ряду `G(x)` дорівнює відстані до найближчого полюса:

```
R = │x₂│ = 1 / φ ≈ 0.6180339887...
```

Степіновий ряд збігається при `|x| < 1/φ` і розбігається при `|x| ≥ 1/φ`.

## Діофантове рівняння типу x² − x y − y² = ±1 та інваріантність квадратичної форми

Розглянемо класичне квадратне діофантове рівняння відносно двох цілих невідомих `x` та `y`:

```
x² − x · y − y² = ±1
```

Перепишемо це рівняння у вигляді `(x/y)² − (x/y) − 1 = ±1/y²`.
При великих `y` права частина `±1/y²` прямує до нуля, а отже відношення `x/y` мусить прямувати до додатного кореня `φ`.

Зберігання цієї квадратичної форми описується матрицею переходу `M = [[1, 1], [1, 0]]`. Для вектора `v = [x, y]ᵀ` перетворення `v' = M v = [x + y, x]ᵀ` дає:

```
Q(x + y, x) = (x + y)² − (x + y) x − x² = x² + 2xy + y² − x² − xy − x² = y² + xy − x² = −Q(x, y)
```

Отже, оператор зсуву переставляє знак інваріантної квадратичної форми `Q(x, y)` на кожному кроці!

Згідно з теоремою про розв'язки квадратних форм з дискримінантом `D = 5`, **усі без винятку цілі додатні розв'язки** цього діофантового рівняння виражаються через послідовні члени Фібоначчі:

```
(x, y) = (Fₙ₊₁, Fₙ)
```

Підставивши `x = Fₙ₊₁` та `y = Fₙ`, отримуємо лівий бік рівняння: `Fₙ₊₁² − Fₙ₊₁ Fₙ − Fₙ² = Fₙ₊₁ (Fₙ₊₁ − Fₙ) − Fₙ² = Fₙ₊₁ Fₙ⋁₁ − Fₙ² = (−1)ⁿ`.
Це дає ще один фундаментальний доказ того, що числа Фібоначчі є єдиними цілими числами, чиї квадратичні форми мінімізують норму відстані до золотого перетину.

## Строге доведення теореми Гурвіца

Сформулюємо та доведемо теорему Адольфа Гурвіца (1891):

> **Теорема Гурвіца.** Для будь-якого ірраціонального числа `α` існує нескінченно багато підхідних дробів `p/q` таких, що:
>
> ```
> │      p │       1
> │ α − ───│  < ────────
> │      q │    √5 · q²
> ```

**Доведення:**
Розглянемо три послідовні підхідні дроби `pₙ⋁₁/qₙ⋁₁`, `pₙ/qₙ`, `pₙ₊₁/qₙ₊₁` ланцюгового дробу числа `α`. Припустимо супротивне: жоден із цих трьох дробів не задовольняє нерівність Гурвіца, тобто для всіх трьох `i ∈ {n-1, n, n+1}` виконується протилежна нерівність:

```
│      pᵢ │       1
│ α − ────│  ≥ ────────
│      qᵢ │    √5 · qᵢ²
```

Оскільки підхідні дроби лежать по різні боки від числа `α`, сума двох сусідніх похибок дорівнює відстані між дробами:

```
│ pᵢ    pᵢ₊₁ │   │      pᵢ │   │      pᵢ₊₁ │
│ ── − ──────│ = │ α − ────│ + │ α − ──────│
│ qᵢ    qᵢ₊₁ │   │      qᵢ │   │      qᵢ₊₁ │
```

З основного співвідношення підхідних дробів відомо, що `|pᵢ qᵢ₊₁ − pᵢ₊₁ qᵢ| = 1`. Отже:

```
    1         │      pᵢ │   │      pᵢ₊₁ │       1         1
────────── =  │ α − ────│ + │ α − ──────│  ≥ ──────── + ─────────
qᵢ · qᵢ₊₁     │      qᵢ │   │      qᵢ₊₁ │    √5 · qᵢ²   √5 · qᵢ₊₁²
```

Помноживши обидва боки рівняння на `√5 · qᵢ · qᵢ₊₁`, дістаємо нерівність для відношення знаменників `rᵢ = qᵢ₊₁ / qᵢ`:

```
       1
rᵢ + ─── ≤ √5
      rᵢ
```

Розв'язавши квадратне рівняння `rᵢ² − √5 rᵢ + 1 ≤ 0`, знаходимо межі для `rᵢ`:

```
√5 − 1          √5 + 1
──────  ≤  rᵢ  ≤ ──────
  2               2
```

Тобто `1/φ ≤ rᵢ ≤ φ`. Оскільки `rᵢ = qᵢ₊₁ / qᵢ = aᵢ₊₁ + 1/rᵢ⋁₁`, підставивши `aᵢ₊₁ ≥ 1` та проперши нерівності для трьох послідовних значень `i`, ми доходимо до строгого протиріччя `rᵢ > φ`, яке спростовує припущення.

Таким чином, **принаймні один із трьох послідовних підхідних дробів обов'язково задовольняє нерівність Гурвіца**, що доводить наявність нескінченної кількості таких дробів.

Для `α = φ` відношення знаменників `qᵢ₊₁ / qᵢ = Fᵢ₊₂ / Fᵢ₊₁` строго прямує до `φ`, досягаючи границі `1 / (√5 q²)`. Отже, константу `√5` неможливо збільшити для золотого перетину.

## Дерево Маркова та спектр Лагранжа

Зв'язок між теоремою Гурвіца та квадратичними формами відкрив Андрій Марков у 1879 році. Розглянемо рівняння Маркова для цілих додатних чисел:

```
x² + y² + z² = 3 · x · y · z
```

Розв'язки цього рівняння утворюють нескінченне **дерево Маркова**. Якщо трійка `(x, y, z)` задовольняє рівняння при `x ≤ y ≤ z`, то нова сусідня трійка утворюється заміною найбільшого елемента `z` на `z' = 3 x y − z`:

```
                    (1, 1, 1)
                        │
                    (1, 1, 2)
                        │
                    (1, 2, 5)
                  ┌─────┴─────┐
              (1, 5, 13)  (2, 5, 29)
              ┌───┴───┐    ┌───┴───┐
         (1,13,34) ...   ...   ...
```

Перші числа Маркова: `1, 2, 5, 13, 29, 34, 89, 169, 194, 233, 433…` Зверніть увагу: кожне друге число Фібоначчі `F₂ₙ₊₁` (наприклад, 1, 2, 5, 13, 34, 89, 233) є числом Маркова з гілки `(1, F₂ₙ⋁₁, F₂ₙ₊₁)`!

Кожне число Маркова `z` породжує виключну константу наближення у так званому **спектрі Маркова–Лагранжа**:

```
c☿ = √(9 − 4/z²)
```

- Для найпершого числа Маркова `z = 1`: `c₁ = √(9 − 4/1) = √5 ≈ 2.236068` (відповідає `φ = [1; 1, 1, 1, ...]`).
- Для другого числа Маркова `z = 2`: `c₂ = √(9 − 4/4) = √8 = 2√2 ≈ 2.828427` (відповідає `√2 = [1; 2, 2, 2, ...]`).
- Для третього числа Маркова `z = 5`: `c₃ = √(9 − 4/25) = √221 / 5 ≈ 2.973214` (відповідає `[1; 2, 2, 1, 1, 2, 2, ...]`).

Значення `c₁ = √5` становить абсолютну нижню межу спектра Лагранжа. Золотий перетин `φ` стоїть на самій вершині цього спектра як найбільш уперте та найменш раціональне число в усій дійсно числовій прямій.

## Теорема про три довжини Штейнгауза

Поведінка дробових частин `{n φ}` описується витонченою геометричною теоремою Штейнгауза (1958):

> **Теорема Штейнгауза (про три довжини).** Нехай `α` — ірраціональне число, `N ∈ ℕ`. Розмістимо точки `{α}, {2α}, {3α}, ..., {N α}` на коло одиничної довжини `[0, 1)`. Ці точки розбивають коло на `N + 1` інтервалів, довжини яких набувають **щонайбільше трьох різних значень**.

Коли `α = φ`, підхідні дроби `Fₙ₊₁ / Fₙ` задають моменти, коли один із трьох інтервалів ділиться у золотому відношенні. Співвідношення між довжинами трьох типів інтервалів завжди становить `1 : φ : φ²`.

Зручно порівняти це з послідовністю Кронекера `{n α}`, де для `α = φ` коефіцієнт нерівномірності (дискрепація) набуває теоретичного мінімуму `O(log N / N)`, роблячи золотий перетин ідеальним вибором для детермінованого низькодискрепантного семплювання у обчислювальних симуляціях.

Ця властивість гарантує, що послідовність `{n φ}` має найменшу можливу розбіжність (*discrepancy*) серед усіх послідовностей на колі, розкидаючи точки без жодних локальних скупчень.

## Розклад на прості множники у кільці ℤ[φ] та контраст із ℤ[√-5]

Розглянемо поводження звичайних простих цілих чисел `p ∈ ℤ` при переході в розширене кільце `ℤ[φ]`.
Оператор норми `N(u + v φ) = u² + u v − v²` визначає, які числа розкладаються на прості множники:

1. **Число 5 (Розгалуження):**
   Оскільки `(2φ − 1)² = 4φ² − 4φ + 1 = 4(φ + 1) − 4φ + 1 = 5`, число 5 перестає бути простим елементом у `ℤ[φ]`. Воно розкладається на квадрат простого елемента `√5 = 2φ − 1`:
   ```
   5 = (2φ − 1)²
   ```
2. **Числа p ≡ ±1 (mod 5) (Розклад):**
   Розглянемо `p = 11`: порівняння `11 ≡ 1 (mod 5)` показує, що 5 є квадратичним лишком за модулем 11. Норма елемента `α = 3 + 2φ` становить:
   ```
   N(3 + 2φ) = 3² + 3·2 − 2² = 9 + 6 − 4 = 11
   ```
   Отже, число 11 розкладається на два спряжені прості множники `11 = (3 + 2φ)(3 + 2ψ) = (3 + 2φ)(5 − 2φ)`.
   Аналогічно для `p = 19`: `19 = (5 + 3φ)(5 + 3ψ) = (5 + 3φ)(8 − 3φ)`.
3. **Числа p ≡ ±2 (mod 5) (Інертність):**
   Розглянемо `p = 7`: порівняння `7 ≡ 2 (mod 5)` показує, що рівняння `u² + u v − v² = ±7` не має розв'язків у цілих числах `u, v ∈ ℤ`.
   Отже, число 7 залишається **простим елементом** у кільці `ℤ[φ]`.

Слід зауважити, що слід елементів кільця `Tr(u + v φ) = (u + v φ) + (u + v ψ) = 2u + v` задає точну суму коренів. Для степенів `φⁿ` слід дорівнює відповідному числу Люка: `Tr(φⁿ) = Lₙ`.

Квадратичний тричлен `x² - x - 1 = 0` має дискримінант `D = 5 ≡ 1 (mod 4)`, тому кільце цілих чисел квадратичного поля `ℚ(√5)` складається з елементів `u + v φ`, де `u, v ∈ ℤ`.

Контраст із кільцем `ℤ[√-5]` з від'ємним дискримінантом `D = -20` наочно демонструє алгебраїчну досконалість `ℤ[φ]`: у `ℤ[√-5]` єдиність розкладу на прості множники розвалюється (`6 = 2 · 3 = (1 + √-5)(1 − √-5)`), оскільки класове число `h(-20) = 2`. Натомість у `ℤ[φ]` завдяки `D = +5 > 0` класове число `h(5) = 1`, що гарантує єдиність розкладу!

Ця евклідовість норми розповсюджується на всі кільця цілих квадратичних полів із дискримінантом `D ∈ {5, 8, 12, 13, 17, 21, 29, 33, 37, 41, 57, 73}`.

## Евклідова арифметика та доведення норми в кільці ℤ[φ]

Дійсні числа, чий розклад у ланцюговий дріб починаючи з деякого місця `k` складається виключно з одиниць:

```
x = [a₀; a₁, a₂, ..., aₖ, 1, 1, 1, ...]
```

називають **шляхетними числами** (*noble numbers*). Усі шляхетні числа тісно пов'язані із золотим перетином через дробово-лінійні перетворення з цілими коефіцієнтами:

```
       a · φ + b
x  =  ─────────── ,      де a, b, c, d ∈ ℤ  і  │a·d − b·c│ = 1
       c · φ + d
```

Ці перетворення утворюють модулярну групу `SL(2, ℤ)`. З погляду алгебраїчної теорії чисел, `φ` є цілим алгебраїчним числом — додатним коренем квадратного многочлена `x² - x - 1 = 0` з дискримінантом `D = 5`.

Класове число поля `ℚ(√5)` дорівнює `h(5) = 1`, що означає відсутність будь-яких нетривіальних ідеальних класів і повну збіжність кільця `ℤ[φ]` з кільцем головних ідеалів.

Множина чисел вигляду `u + v·φ`, де `u, v ∈ ℤ`, утворює **кільце цілих чисел** `ℤ[φ]` квадратичного поля `ℚ(√5)`. Завдяки фундаментальній тотожності `φ² = φ + 1` будь-який вищий степінь `φⁿ` лінійно виражається через `φ` та `1`:

```
φ² = φ + 1
φ³ = 2φ + 1
φ⁴ = 3φ + 2
...
φⁿ = Fₙ φ + Fₙ⋁₁
```

Множення двох елементів кільця `ℤ[φ]` здійснюється за правилом:

```
(u₁ + v₁ φ) · (u₂ + v₂ φ) = (u₁ u₂ + v₁ v₂) + (u₁ v₂ + v₁ u₂ + v₁ v₂) φ
```

Норма елемента `α = u + v φ` задається як добуток спряжених елементів `N(α) = (u + v φ)(u + v ψ)`, де `ψ = (1 - √5)/2` — другий корінь рівняння `x² - x - 1 = 0`:

```
N(u + v φ) = u² + u v − v²
```

Норма є мультиплікативною функцією: `N(α · β) = N(α) · N(β)`. Елемент `α ∈ ℤ[φ]` є оборотним (одиницею кільця) тоді й лише тоді, коли його норма дорівнює `±1`. Степені `φⁿ` утворюють нескінченну групу оборотних елементів, оскільки `N(φ) = −1`, а отже `N(φⁿ) = (−1)ⁿ`.

Доведемо строго, що кільце `ℤ[φ]` є **евклідовим відносно норми**.
Для цього достатньо показати, що для будь-якого дійсного елемента `z = x + y φ ∈ ℚ(√5)` існує цілий елемент `q = u + v φ ∈ ℤ[φ]` такий, що `|N(z − q)| < 1`.

Виберемо цілі `v` та `u` як найближчі цілі числа до `y` та `x`:
`|y − v| ≤ 1/2`, `|x − u| ≤ 1/2`.
Позначимо дробові залишки `dy = y − v`, `dx = x − u`.
Норма різниці дорівнює `N(dx + dy φ) = dx² + dx dy − dy²`.
Оцінимо максимум цієї квадратичної форми при `|dx| ≤ 1/2`, `|dy| ≤ 1/2`:

```
│dx² + dx dy − dy²│  ≤  (1/2)² + (1/2)(1/2) + (1/2)²  =  1/4 + 1/4 + 1/4  =  3/4  <  1
```

Оскільки `3/4 < 1`, в `ℤ[φ]` завжди існує ділення з остачею! Це доводить, що `ℤ[φ]` є **евклідовим кільцем**, а отже у ньому виконується фундаментальна теорема арифметики про єдиність розкладу на прості множники.

Проілюструємо ділення з остачею чисельним прикладом у `ℤ[φ]`:
Нехай `α = 7 + 4φ`, `β = 2 + 3φ`. Знайдемо частку у повному полі `ℚ(√5)`:

```
 α     7 + 4φ     (7 + 4φ)(2 + 3ψ)     14 + 21ψ + 8φ + 12(φψ)
─── = ──────── = ────────────────── = ─────────────────────────
 β     2 + 3φ          N(β)                 4 + 6 − 9 = 1
```

Оскільки `N(2 + 3φ) = 2² + 2·3 − 3² = 4 + 6 − 9 = 1`, дріб ділиться без остачі прямо в кільці `ℤ[φ]`: частка є цілим елементом `q = 23 - 13φ`, `r = 0`.

Саме алгебраїчна норма `N(φⁿ) = u² + u v - v² = ±1` лежить у основі доведення класичної тотожності Кассіні для чисел Фібоначчі: `F♙₊₁ F♙⋁₁ - F♙² = (−1)ⁿ`.

Алгебраїчні властивості норми та евклідового ділення в кільці `ℤ[φ]` підтверджують унікальну теоретико-числову цілісність золотого перетину.
