# Математичне доведення тотожності [Алгоритм та рекодування Бута](book:math/booth-algorithm)

Математична сутність алгоритму Бута полягає в хитромудрому перекодуванні двійкового множника. Це перекодування базується на тотожності, яка дозволяє замінити серію додавань (для блоку одиниць) на одне додавання і одне віднімання. Щоб переконатися, що [Алгоритм та рекодування Бута](book:math/booth-algorithm) дійсно працює і дає правильний результат для будь-яких чисел (зокрема і для від'ємних у доповняльному коді), ми повинні довести його математично.

Розглянемо n-бітне число Y, представлене у доповняльному коді. Його значення (Y) можна записати як суму ваг кожного біта:

Y = - y_{n-1} 2^{n-1} + y_{n-2} 2^{n-2} + ... + y₁ 2¹ + y₀ 2⁰

Зверніть увагу на старший біт y_{n-1}. У доповняльному коді він несе від'ємну вагу (- 2^{n-1}). Всі інші біти мають додатні ваги, що відповідають ступеням двійки.

Ідея Бута полягає в тому, щоб перетворити кожен біт y_i на нове значення z_i, таке що:

z_i = y_{i-1} - y_i

При цьому ми вводимо фіктивний біт y₋₁ = 0.
Тепер давайте підставимо цей вираз у загальну формулу суми, що представляє наше перекодоване число. Назвемо цю нову суму Y':

Y' = ∑_{i=0}^{n-1} z_i 2^i
Y' = ∑_{i=0}^{n-1} (y_{i-1} - y_i) 2^i

Давайте розпишемо цю суму по членах, щоб побачити, що з нею відбувається. Почнемо з наймолодших розрядів (i = 0):

Для i = 0: (y₋₁ - y₀) 2⁰ = (0 - y₀) 2⁰ = - y₀ 2⁰
Для i = 1: (y₀ - y₁) 2¹ = y₀ 2¹ - y₁ 2¹
Для i = 2: (y₁ - y₂) 2² = y₁ 2² - y₂ 2²
...
Для i = n-2: (y_{n-3} - y_{n-2}) 2^{n-2} = y_{n-3} 2^{n-2} - y_{n-2} 2^{n-2}
Для i = n-1: (y_{n-2} - y_{n-1}) 2^{n-1} = y_{n-2} 2^{n-1} - y_{n-1} 2^{n-1}

Тепер додамо всі ці члени разом. Виникає ефект "телескопічної суми" (telescoping sum), коли багато членів взаємно знищуються!

Давайте згрупуємо члени з однаковими індексами y_i:

Y' = - y₀ 2⁰ + y₀ 2¹ - y₁ 2¹ + y₁ 2² - y₂ 2² + ... + y_{n-2} 2^{n-1} - y_{n-1} 2^{n-1}

Перегрупуємо відносно y_i:

Y' = y₀ (-2⁰ + 2¹) + y₁ (-2¹ + 2²) + y₂ (-2² + 2³) + ... + y_{n-2} (-2^{n-2} + 2^{n-1}) - y_{n-1} 2^{n-1}

Зверніть увагу на вирази в дужках. 
-2ⁱ + 2^{i+1} = 2^{i+1} - 2ⁱ = 2ⁱ (2 - 1) = 2ⁱ.

Отже, кожна дужка дорівнює просто 2ⁱ! 
Підставимо це назад у нашу суму:

Y' = y₀ 2⁰ + y₁ 2¹ + y₂ 2² + ... + y_{n-2} 2^{n-2} - y_{n-1} 2^{n-1}

Перепишемо в звичному порядку від найстаршого до наймолодшого біта:

Y' = - y_{n-1} 2^{n-1} + y_{n-2} 2^{n-2} + ... + y₁ 2¹ + y₀ 2⁰

Але погляньте! Це ж в точності визначення значення числа Y у доповняльному коді, з якого ми починали!
Ми щойно довели, що Y' = Y.

Це доведення має фундаментальне значення. Воно показує, що якщо замість оригінальних бітів y_i ми будемо використовувати перекодовані значення z_i = y_{i-1} - y_i для визначення того, чи треба додавати, віднімати, чи ігнорувати множене на кожному кроці, сумарний результат буде математично ідентичним до множення на оригінальне число Y.

Давайте подивимося, яких значень може набувати z_i = y_{i-1} - y_i:
Якщо (y_i, y_{i-1}) = (0, 0), то z_i = 0 - 0 = 0. (Нічого не додаємо).
Якщо (y_i, y_{i-1}) = (0, 1), то z_i = 1 - 0 = +1. (Додаємо множене).
Якщо (y_i, y_{i-1}) = (1, 0), то z_i = 0 - 1 = -1. (Віднімаємо множене).
Якщо (y_i, y_{i-1}) = (1, 1), то z_i = 1 - 1 = 0. (Нічого не додаємо).

Саме ці значення z_i і є тими діями, які ми бачили в таблиці операцій алгоритму Бута. Математика ідеально підтверджує логіку алгоритму: віднімання старшого біта автоматично враховує його від'ємну вагу в доповняльному коді.
