# Доведення Тотожності Безу через алгоритм Евкліда

Тотожність Безу стверджує, що для будь-яких цілих чисел a та b існують такі цілі x та y, що a·x + b·y = gcd(a, b). Її можна строго довести за допомогою розширеного алгоритму Евкліда.

## Крок 1. Зворотний хід алгоритму Евкліда

Нехай ми застосовуємо стандартний алгоритм Евкліда для знаходження найбільшого спільного дільника чисел a та b (припустимо, що a > b):

a = b·q₁ + r₁
b = r₁·q₂ + r₂
r₁ = r₂·q₃ + r₃
...
rₙ₋₂ = rₙ₋₁·qₙ + rₙ
rₙ₋₁ = rₙ·qₙ₊₁ + 0

Остання ненульова остача rₙ і є gcd(a, b). З передостаннього рівняння ми можемо виразити rₙ:

rₙ = rₙ₋₂ − rₙ₋₁·qₙ

Підставляючи rₙ₋₁ з попереднього рівняння (rₙ₋₃ = rₙ₋₂·qₙ₋₁ + rₙ₋₁), ми отримаємо rₙ як лінійну комбінацію rₙ₋₃ та rₙ₋₂. Продовжуючи цей процес від низу до гори, замінюючи кожну остачу на вираз через попередні, ми зрештою виразимо rₙ через початкові a та b.

## Крок 2. Формальне доведення індукцією

Доведемо формально, що на кожному кроці k остачу rₖ можна подати у вигляді a·xₖ + b·yₖ, де xₖ, yₖ — цілі числа.

База індукції:
Для зручності позначимо r₋₁ = a і r₀ = b.
Тоді:
a = a·1 + b·0  (x₋₁ = 1, y₋₁ = 0)
b = a·0 + b·1  (x₀ = 0, y₀ = 1)

Крок індукції:
Припустимо, що твердження істинне для всіх індексів менших за k. За алгоритмом ділення з остачею маємо:
rₖ₋₂ = rₖ₋₁·qₖ + rₖ

Звідси виражаємо rₖ:
rₖ = rₖ₋₂ − rₖ₋₁·qₖ

За припущенням індукції ми вже знаємо, що:
rₖ₋₂ = a·xₖ₋₂ + b·yₖ₋₂
rₖ₋₁ = a·xₖ₋₁ + b·yₖ₋₁

Підставимо ці вирази у формулу для rₖ:
rₖ = (a·xₖ₋₂ + b·yₖ₋₂) − (a·xₖ₋₁ + b·yₖ₋₁)·qₖ
rₖ = a·(xₖ₋₂ − xₖ₋₁·qₖ) + b·(yₖ₋₂ − yₖ₋₁·qₖ)

Отже, якщо ми позначимо:
xₖ = xₖ₋₂ − xₖ₋₁·qₖ
yₖ = yₖ₋₂ − yₖ₋₁·qₖ

тоді отримаємо rₖ = a·xₖ + b·yₖ. Оскільки на кожному кроці xₖ та yₖ утворюються множенням і відніманням цілих чисел, вони також є цілими. Твердження доведено.

## Висновок

Оскільки остання ненульова остача rₙ є найбільшим спільним дільником (gcd(a, b)), вона також може бути подана у такому вигляді:

gcd(a, b) = a·xₙ + b·yₙ

Цей конструктивний доказ не тільки гарантує існування розв'язку x та y (тотожність Безу), але й дає чіткий алгоритм їх знаходження — це так званий розширений алгоритм Евкліда. Тоді, коли a і b є взаємно простими, gcd(a, b) = 1, і ми отримуємо важливий окремий випадок: a·x + b·y = 1.
