# 📜 Історія виникнення гіпотези Шпіро

У середині 1970-х років математичний аналіз діофантових рівнянь опинився у стані глибокого застою. Класичні методи алгебраїчної теорії чисел та наближення алгебраїчних чисел (такі як метод Бейкера) дозволяли отримувати лише надзвичайно слабкі, "астрономічні" обмежувальні оцінки для розв'язків діофантових систем. Для кардинального прориву у вивченні арифметики цілих чисел потрібен був принципово новий погляд, який зв'язав би розклади цілих чисел на прості множники з геометрією алгебраїчних кривих.

Французький математик Люсьєн Шпіро (Lucien Szpiro), працюючи в Національному центрі наукових досліджень Франції (CNRS) та університеті Париж-Південь (Орсе), досліджував геометрію алгебраїчних поверхонь та еліптичних розшарувань. У 1981 році Шпіро опублікував фундаментальний результат для об'єктів над функціональними полями. Він досліджував еліптичні криві, коефіцієнти яких є не раціональними числами, а раціональними функціями на гладкій алгебраїчній кривій `C` над полем комплексних чисел.

Для еліптичної поверхні над кривою `C` роду `g(C)` із `s` особливими шарами (точками поганої редукції) Шпіро довів строгу геометричну нерівність для степеня пучка мінімального дискримінанта:

```
deg(Δ) ≤ 6 · (2 · g(C) - 2 + s)
```

Ця формула стала справжнім триумфом геометричної теорії інваріантів. Вона показала, що глобальний геодезичний розмір дискримінанта `Δ` еліптичного розшарування цілком контролюється кількістю та топологічною структурою його особливих шарів `s`. Число 6 у цій нерівності виникло не випадково: воно є наслідком аналізу класу Кодаіри-Спенсера та градуйованої структури кільця модулярних форм, де дискримінант має вагу 12, а перший пучок модулярних форм відповідає вазі 2 (`12 / 2 = 6`).

У 1983 році на математичній конференції в Ганновері Люсьєн Шпіро зробив сміливий крок. Він висунув гіпотезу, що аналогічний строго обмежений зв'язок повинен існувати й у світі цілих чисел — над полем раціональних чисел `Q`. У числовому контексті роль алгебраїчної кривої `C` виконує спектр кільця цілих чисел, роль особливих шарів `s` відіграють прості числа поганої редукції (провідник `N_E`), а степінь дискримінанта замінюється логарифмом абсолютного значення мінімального дискримінанта `log |Δ_E|`.

Шпіро сформулював нерівність, яка пізніше отримала його ім'я: для будь-якого `ε > 0` існує така константа `C(ε) > 0`, що для довільної еліптичної кривої `E` над `Q` виконується співвідношення:

```
|Δ_E| ≤ C(ε) · N_E⁶⁺ᵉ
```

Формулювання цієї гіпотези мало ефект вибуху в числовій арифметиці. До 1983 року математики вважали, що локальна арифметика простих дільників кривої не здатна жорстко обмежувати її глобальну алгебраїчну складність. Гіпотеза Шпіро вперше проголосила існування універсального законного бар'єра для глобальних арифметичних інваріантів.

У 1985 році французький математик Жозеф Остерле (Joseph Oesterlé) та швейцарський математик Девід Массер (David Masser), аналізуючи доповідь Шпіро, спробували перекласти геометричне твердження Шпіро мовою чистої елементарної арифметики натуральних чисел. Вони поставили питання: що станеться з нерівністю Шпіро, якщо припустити існування найпростішого діофантового співвідношення `a + b = c`?

У 1986 році німецький математик Ґергард Фрей (Gerhard Frey) побудував фундаментальний арифметичний міст. Для довільної взаємно простої трійки натуральних чисел `a + b = c` Фрей запропонував розглядати спеціальну еліптичну криву, яка пізніше отримала назву кривої Фрея:

```
y² = x · (x - a) · (x + b)
```

Прямий обчислювальний розрахунок показав, що дискримінант цієї кривої виражається як `Δ = 16 · (a · b · c)²`, а її провідник дорівнює добутку усіх різних простих дільників чисел `a`, `b` та `c` — тобто радикалу `rad(a · b · c)`. Якщо підставити інваріанти кривої Фрея у нерівність Шпіро, то з неї негайно випливає нерівність `c ≤ C' · (rad(a · b · c))¹⁺ᵉ`. Саме так Остерле та Массер сформулювали славетну **гіпотезу ABC**.

Завдяки побудові кривої Фрея з'ясувалося, що гіпотеза Шпіро є "геометричною матір'ю" гіпотези ABC. Більше того, Фрей висловив гіпотезу, що якби існував контрприклад до Великої теореми Ферма (`xⁿ + yⁿ = zⁿ`), то відповідна крива Фрея володіла б настільки аномальними арифметичними властивостями, що вона не могла б бути модулярною і водночас порушувала б обмеження Шпіро.

У 1986–1990 роках Кеннет Рібет (Kenneth Ribet) довів гіпотезу Серра про epsilon-редукцію, підтвердивши міркування Фрея: модулярність кривих Фрея справді тягне за собою Велику теорему Ферма. У 1995 році Ендрю Вайлс (Andrew Wiles) за участю Річарда Тейлора довів модулярність напівстабільних еліптичних кривих, що остаточно закрило Велику теорему Ферма. Однак Велика теорема Ферма була лише одним з багатьох наслідків гіпотези Шпіро. Загальна нерівність Шпіро `|Δ_E| ≤ C(ε) · N_E⁶⁺ᵉ` залишилася нерозв'язаною для поля раціональних чисел.

Протягом 1990-х та 2000-х років проводилися інтенсивні обчислювальні експерименти під керівництвом Джино Местра (Jean-François Mestre), Ендрю Кремони (Andrew Cremona) та Абдеррахіма Нітажа (Abderrahmane Nitaj). Вони шукали криві з максимальним індексом Шпіро `σ(E) = log |Δ_E| / log N_E`. Найвищий виявлений індекс сягнув значення `σ(E) ≈ 7.95` для кривих із малими провідниками. Ці результати підтвердили, що для малих значень `N_E` можливі локальні спалахи, але асимптотична межа 6 залишається непорушним арифметичним порогом при `N_E → ∞`.

У серпні 2012 року японський математик Шінічі Мочізукі (Shinichi Mochizuki) з Університету Кіото опублікував серію з чотирьох великих праць загальним обсягом понад 500 сторінок, у яких проголосив доведення гіпотези Шпіро та гіпотези ABC в рамках створеної ним **Міжвсесвітньої теорії Тейхмюллера** (Inter-Universal Teichmüller Theory, IUT). Теорія Мочізукі базується на радикальній перебудові арифметичної геометрії, де звичні схеми Ґротендіка замінюються "голоморфними логарифмічними пучками" та "арифметичними аналогами теорії Тейхмюллера".

У 2018 році математики Петер Шольце (Peter Scholze) та Якоб Стікс (Jakob Stix) відвідали Кіото для детального аналізу тексту Мочізукі. Після тижневих дискусій вони опублікували звіт, у якому вказали на конкретну непереборну прогалину у Наслідку 3.12 (Corollary 3.12) праць IUT, стверджуючи, що спрощення вимірювальних нерівностей у теорії Мочізукі робить підсумкову оцінку недієздатною. Мочізукі не погодився з цією критикою, заявивши про непорозуміння його термінології. Станом на сьогодні математична спільнота не вважає гіпотезу Шпіро доведеною для полів чисел, і вона залишається одним із найвеличніших відкритих викликів сучасної математики.
