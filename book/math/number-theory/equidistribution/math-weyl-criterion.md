# 🧮 Математичний апарат рівномірного розподілу: від індикаторів до експоненціальних сум

Ця математична вставка містить строгі доведення критерію Вейля, еквівалентності означень рівномірного розподілу через неперервні функції, виведення сум для ірраціональних ротаторів та точне виведення нерівності Ердеша — Турана.

---

## 1. Еквівалентність означень: від відрізків до неперервних функцій

Розглянемо послідовність чисел `(xₙ)_{n=1}^∞` із напівінтервалу `[0, 1)`.

**Означення 1 (індикаторне / мірно-теоретичне).** Послідовність `(xₙ)` називається **рівномірно розподіленою за модулем 1**, якщо для будь-якого підінтервалу `[a, b) ⊆ [0, 1)` виконується співвідношення:

```
lim_{N → ∞} (1 / N) · ∑_{n=1}^N I_[a,b)(xₙ) = b − a
```

де `I_[a,b)(x)` — індикаторна (характеристична) функція напівінтервалу:

```
I_[a,b)(x) = 1, якщо x ∈ [a, b)
I_[a,b)(x) = 0, якщо x ∉ [a, b)
```

**Означення 2 (функціональне / інтегральне).** Послідовність `(xₙ)` є рівномірно розподіленою mod 1 тоді й лише тоді, коли для будь-якої неперервної на `[0, 1]` комплекснозначної функції `f(x)` із рівними значеннями на кінцях `f(0) = f(1)` має місце границя:

```
lim_{N → ∞} (1 / N) · ∑_{n=1}^N f(xₙ) = ∫₀¹ f(t) dt
```

### Строге доведення еквівалентності двох означень

Доведемо, що Означення 1 та Означення 2 є математично еквівалентними.

#### Крок A: З Означення 2 випливає Означення 1 (Достатність інтегрального критерію)

Зафіксуємо довільний підінтервал `[a, b) ⊂ [0, 1)` та обране мале число `ε > 0` таке, що `a + ε < b − ε`.

Збудуємо дві неперервні трапецієподібні функції `g⁻(x)` та `g⁺(x)`, які підпирають індикаторну функцію `I_[a,b)(x)` відповідно знизу та зверху на відрізку `[0, 1]`:

1. Нижня неперервна функція `g⁻(x)` задовольняє умови:
   - `g⁻(x) = 1` для `x ∈ [a + ε, b − ε]`.
   - `g⁻(x) = 0` для `x ∉ (a, b)`.
   - На відрізках `[a, a + ε]` та `[b − ε, b]` функція `g⁻(x)` є лінійною.
   - `0 ≤ g⁻(x) ≤ I_[a,b)(x) ≤ 1`.

2. Верхня неперервна функція `g⁺(x)` задовольняє умови:
   - `g⁺(x) = 1` для `x ∈ [a, b)`.
   - `g⁺(x) = 0` для `x ∉ (a − ε, b + ε)`.
   - На відрізках `[a − ε, a]` та `[b, b + ε]` функція `g⁺(x)` є лінійною.
   - `I_[a,b)(x) ≤ g⁺(x) ≤ 1`.

Обчислимо точні значення інтегралів Рімана від побудованих неперервних функцій `g⁻` та `g⁺`:

```
∫₀¹ g⁻(t) dt = (b − a) − ε
∫₀¹ g⁺(t) dt = (b − a) + ε
```

Оскільки `g⁻(x) ≤ I_[a,b)(x) ≤ g⁺(x)` для всіх `x ∈ [0, 1)`, підсумуємо ці нерівності по всіх `n` від `1` до `N` і поділимо на `N`:

```
(1 / N) · ∑_{n=1}^N g⁻(xₙ)
≤ (1 / N) · ∑_{n=1}^N I_[a,b)(xₙ)
≤ (1 / N) · ∑_{n=1}^N g⁺(xₙ)
```

Перейдемо до нижньої та верхньої границь при `N → ∞`. Оскільки функції `g⁻` та `g⁺` є неперервними, за Означенням 2 для них існують границі, які дорівнюють відповідним інтегралам:

```
(b − a) − ε
= ∫₀¹ g⁻(t) dt                                   [за інтегруванням трапеції]
= lim_{N → ∞} (1 / N) · ∑_{n=1}^N g⁻(xₙ)          [за Означенням 2 для неперервної функції g⁻]
≤ liminf_{N → ∞} (1 / N) · ∑_{n=1}^N I_[a,b)(xₙ)  [за нерівністю підпори g⁻ ≤ I]
≤ limsup_{N → ∞} (1 / N) · ∑_{n=1}^N I_[a,b)(xₙ)  [за властивістю liminf ≤ limsup]
≤ lim_{N → ∞} (1 / N) · ∑_{n=1}^N g⁺(xₙ)          [за нерівністю мажорування I ≤ g⁺]
= ∫₀¹ g⁺(t) dt                                   [за Означенням 2 для неперервної функції g⁺]
= (b − a) + ε                                     [за інтегруванням трапеції]
```

Оскільки нерівність `(b − a) − ε ≤ liminf ≤ limsup ≤ (b − a) + ε` виконується для довільного малого `ε > 0`, спрямувавши `ε → 0`, отримуємо:

```
liminf_{N → ∞} (1 / N) · ∑_{n=1}^N I_[a,b)(xₙ)
= limsup_{N → ∞} (1 / N) · ∑_{n=1}^N I_[a,b)(xₙ)  [за теоремою про двох міліціонерів при ε → 0]
= b − a                                            [підстановка границі розтискання]
```

Це доводить існування границі та її точну рівність `b − a`, що збігається з Означенням 1.

#### Крок B: З Означення 1 випливає Означення 2 (Необхідність)

З Означення 1 випливає, що границя `(1/N) ∑ s(xₙ) = ∫₀¹ s(t) dt` виконується для будь-якої східчастої функції `s(x)`, яка є скінченною лінійною комбінацією індикаторів відрізків:

```
s(x) = ∑_{k=1}^M cₖ · I_[aₖ, bₖ)(x)
```

За теоремою про інтеграл Рімана, будь-яку неперервну на `[0, 1]` функцію `f(x)` можна рівномірно наблизити східчастими функціями `s(x)` так, що `sup_{x ∈ [0, 1]} |f(x) − s(x)| < ε / 2`. 

Застосовуючи стандартне `ε`-міркування, отримуємо виконання граничного співвідношення для довільної неперервної функції `f(x)`.

## 2. Повне строге доведення критерію Вейля

**Теорема (Герман Вейль, 1916).** Послідовність `(xₙ) ⊂ [0, 1)` є рівномірно розподіленою mod 1 тоді й лише тоді, коли для кожного цілого ненульового числа `h ≠ 0` виконується:

```
lim_{N → ∞} (1 / N) · ∑_{n=1}^N e²ᵖⁱ ⁱ ʰ ˣⁿ = 0
```

### Доведення (Прямий бік: Необхідність ⇒)

Припустимо, що послідовність `(xₙ)` є рівномірно розподіленою за модулем 1. 

Розглянемо комплекснозначну функцію `f_h(x) = e²ᵖⁱ ⁱ ʰ ˣ` для фіксованого цілого `h ≠ 0`. Ця функція є неперервною на відрізку `[0, 1]` і задовольняє граничну умову періодичності `f_h(0) = e⁰ = 1` та `f_h(1) = e²ᵖⁱ ⁱ ʰ = 1`.

Оскільки умову Означення 2 виконано для всіх неперервних періодичних функцій, підставимо `f_h(x)` у функціональне означення:

```
lim_{N → ∞} (1 / N) · ∑_{n=1}^N e²ᵖⁱ ⁱ ʰ ˣⁿ
= ∫₀¹ e²ᵖⁱ ⁱ ʰ ᵗ dt                 [за функціональним означенням]
= [ (1 / (2π i h)) · e²ᵖⁱ ⁱ ʰ ᵗ ]₀¹   [формула Ньютона — Лейбніца]
= (1 / (2π i h)) · (e²ᵖⁱ ⁱ ʰ − e⁰)    [підстановка верхньої та нижньої меж]
= (1 / (2π i h)) · (1 − 1)           [оскільки e²ᵖⁱ ⁱ ʰ = 1 для будь-якого цілого h ≠ 0]
= 0                                 [висновок]
```

Необхідність повністю доведено.

### Доведення (Обернений бік: Достатність ⇐)

Припустимо, що граничне співвідношення `lim_{N → ∞} (1 / N) ∑ e²ᵖⁱ ⁱ ʰ ˣⁿ = 0` виконується для всіх цілих `h ≠ 0`.

Розглянемо довільну неперервну періодичну функцію `f(x)` з періодом `1`. За аппроксимаційною теоремою Вейєрштрасса для тригонометричних поліномів, для будь-якого обраного `ε > 0` існує скінченний тригонометричний поліном `P_K(x)` степеня `K`:

```
P_K(x) = ∑_{h=-K}^K c_h · e²ᵖⁱ ⁱ ʰ ˣ
```

такий, що рівномірна норма відхилення не перевищує `ε / 3`:

```
sup_{x ∈ [0, 1]} | f(x) − P_K(x) | < ε / 3
```

Оцінимо абсолютну різницю між дискретним середнім функції `f` та її точним інтегралом Рімана:

```
| (1 / N) · ∑_{n=1}^N f(xₙ) − ∫₀¹ f(t) dt |
≤ | (1 / N) · ∑_{n=1}^N (f(xₙ) − P_K(xₙ)) |
  + | (1 / N) · ∑_{n=1}^N P_K(xₙ) − ∫₀¹ P_K(t) dt |
  + | ∫₀¹ (P_K(t) − f(t)) dt |
```

Поклітинно оцінимо кожен із трьох доданків:

1. **Перший доданок:**
   ```
   | (1 / N) · ∑_{n=1}^N (f(xₙ) − P_K(xₙ)) |
   ≤ (1 / N) · ∑_{n=1}^N | f(xₙ) − P_K(xₙ) |
   < (1 / N) · N · (ε / 3) = ε / 3
   ```

2. **Третій доданок:**
   ```
   | ∫₀¹ (P_K(t) − f(t)) dt |
   ≤ ∫₀¹ | P_K(t) − f(t) | dt
   < ∫₀¹ (ε / 3) dt = ε / 3
   ```

3. **Другий доданок:** Розкриємо тригонометричний поліном `P_K(x)` за базисними гармоніками:
   ```
   (1 / N) · ∑_{n=1}^N P_K(xₙ) − ∫₀¹ P_K(t) dt
   = (1 / N) · ∑_{n=1}^N ( c₀ + ∑_{0 < |h| ≤ K} c_h e²ᵖⁱ ⁱ ʰ ˣⁿ ) − c₀  [підстановка формули P_K та інтеграла від сталого c₀]
   = ∑_{0 < |h| ≤ K} c_h · ( (1 / N) · ∑_{n=1}^N e²ᵖⁱ ⁱ ʰ ˣⁿ )          [винесення сталих коефіцієнтів c_h за знак суми]
   ```

   Оскільки сума містить **скінченну** кількість `2K` доданків з фіксованими коефіцієнтами `c_h`, а за умовою теореми кожна сума Вейля `(1/N) ∑_{n=1}^N e²ᵖⁱ ⁱ ʰ ˣⁿ → 0` при `N → ∞`, знайдеться таке `N₀`, що для всіх `N > N₀`:

   ```
   | ∑_{0 < |h| ≤ K} c_h · ( (1 / N) · ∑_{n=1}^N e²ᵖⁱ ⁱ ʰ ˣⁿ ) | < ε / 3
   ```

Підставляючи всі три оцінки назад, отримуємо, що для всіх `N > N₀`:

```
| (1 / N) · ∑_{n=1}^N f(xₙ) − ∫₀¹ f(t) dt | < (ε / 3) + (ε / 3) + (ε / 3) = ε
```

Оскільки `ε > 0` довільне, границя існує і точно дорівнює `∫₀¹ f(t) dt`. 

Достатність критерію Вейля повністю доведено.

## 3. Математичний аналіз ірраціонального ротатора nα

Розглянемо суму Вейля `S_N(h)` для послідовності `xₙ = n α mod 1` при фіксованому цілому `h ≠ 0`:

```
S_N(h) = ∑_{n=1}^N e²ᵖⁱ ⁱ ʰ (n ᵃ) = ∑_{n=1}^N (e²ᵖⁱ ⁱ ʰ ᵃ)ⁿ
```

Позначимо комплексне число `q = e²ᵖⁱ ⁱ ʰ ᵃ`. За припущенням, `α` є ірраціональним числом. Оскільки `h ≠ 0` є цілим, добуток `h α` **ніколи не може бути цілим числом**. Звідси випливає, що `q = e²ᵖⁱ ⁱ ʰ ᵃ ≠ 1`.

Застосуємо формулу суми скінченної геометричної прогресії із першим членом `a₁ = q` та знаменником `q`:

```
S_N(h) = q · ( (1 − qᴺ) / (1 − q) )
= e²ᵖⁱ ⁱ ʰ ᵃ · ( (1 − e²ᵖⁱ ⁱ ʰ ᴺ ᵃ) / (1 − e²ᵖⁱ ⁱ ʰ ᵃ) )
```

Оцінимо модуль чисельника за нерівністю трикутника:

```
| 1 − e²ᵖⁱ ⁱ ʰ ᴺ ᵃ | ≤ |1| + |e²ᵖⁱ ⁱ ʰ ᴺ ᵃ| = 1 + 1 = 2
```

Оцінимо модуль знаменника через тригонометричну тотожність для хорди кола `|1 − eⁱ ⁱθ| = 2 |sin(θ / 2)|`:

```
| 1 − e²ᵖⁱ ⁱ ʰ ᵃ | = 2 · |sin(π h α)|
```

Оскільки `h α ∉ ℤ`, маємо `|sin(π h α)| > 0`. Знаменник є суворо додатним і не залежить від `N`.

Підставляючи оцінки в модуль суми Вейля:

```
|S_N(h)| = |e²ᵖⁱ ⁱ ʰ ᵃ| · ( |1 − e²ᵖⁱ ⁱ ʰ ᴺ ᵃ| / |1 − e²ᵖⁱ ⁱ ʰ ᵃ| )
≤ 1 · ( 2 / (2 |sin(π h α)|) )
= 1 / |sin(π h α)| = C(h) < ∞
```

Поділивши обидві частини на `N`, маємо:

```
(1 / N) · |S_N(h)| ≤ C(h) / N
```

Спрямувавши `N → ∞`:

```
lim_{N → ∞} (1 / N) · |S_N(h)| ≤ lim_{N → ∞} (C(h) / N) = 0
```

Умову критерію Вейля виконано для будь-якого `h ≠ 0`. Це доводить, що послідовність `{n α}` є рівномірно розподіленою mod 1 тоді й лише тоді, коли `α` ірраціональне.

## 4. Виведення нерівності Ердеша — Турана

Критерій Вейля описує якісну збіжність при `N → ∞`. Для кількісної оцінки дискрепантності `D_N*` на скінченній вибірці `N` застосовують нерівність Ердеша — Турана (1941).

**Теорема (Ердеш — Туран).** Для будь-якого набору точок `x₁, ..., x_N ∈ [0, 1)` та любого цілого `M ≥ 1` зіркова дискрепантність `D_N*` задовольняє нерівність:

```
D_N* ≤ C · ( (1 / M) + ∑_{h=1}^M (1 / h) · | (1 / N) · ∑_{n=1}^N e²ᵖⁱ ⁱ ʰ ˣⁿ | )
```

де `C` — абсолютна математична константа (`C = 6` за оцінкою Тейлора та Ваалера).

### Ідея доведення через ядра згладжування (Сельберга / Ваалера)

Пряме обчислення `D_N*` вимагає знаходження максимуму розривної функції `I_[0,x)(t) − x`. 

Замість розривного індикатора побудуємо гладкий тригонометричний поліном `K_M(t)` степеня `M` (ядро Сельберга — Ваалера), який оптимально наближає індикатор `I_[0,x)(t)` у нормі `L₁`:

```
K_M(t) = x + ∑_{1 ≤ |h| ≤ M} c_h(M) · e²ᵖⁱ ⁱ ʰ ᵗ
```

де коефіцієнти `c_h(M)` задовольняють оцінку `|c_h(M)| ≤ C / |h|`.

Замінивши індикатор на ядро `K_M(t)` та підставивши точки `xₙ`, різниця між емпіричним середнім та інтегралом розкладається на два компоненти:

1. **Залишковий член згладжування:** Похибка наближення індикатора поліномом степеня `M` дає вклад порядку `O(1 / M)`.
2. **Тригонометрична частина:** Сума за гармоніками від `1` до `M`, кожна з яких зважується коефіцієнтом `1 / h` та модулем відповідної суми Вейля `|(1/N) ∑ e²ᵖⁱ ⁱ ʰ ˣⁿ|`.

Мінімізуючи сумарну праворуч частину по відношенню до вибору параметра `M`, отримують точні кількісні оцінки дискрепантності для чисельних послідовностей.
