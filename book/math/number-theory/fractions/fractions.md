> 🔧 **Навіщо це.**
> Звичайні дроби дозволяють виконувати точне ділення цілих чисел у тих випадках, коли ділення з остачею не дає цілочисельного результату. Вони є основою раціональних чисел Q, забезпечуючи абсолютно точні обчислення без накопичення помилок округлення.

## 1. Що таке звичайний дріб

У цілих числах Z ділення 7 на 3 не має цілого розв'язку: число 3 не ділить 7 без остачі. Щоб записати точний результат ділення будь-яких двох цілих чисел, використовують **звичайний дріб**:

`a / b`,  де `b ≠ 0`.

Число `a` називається **чисельником**, а число `b` — **знаменником**. Знаменник `b` показує, на скільки рівних частин поділено цілу одиницю, а чисельник `a` лічить, скільки таких частин узято.

### Правильні, неправильні та мішані дроби

За співвідношенням чисельника та знаменника дроби поділяються на три види:
1. **Правильний дріб:** чисельник менший за знаменник (`|a| < b`). Такий дріб за модулем завжди менший за одиницю (наприклад, `2/3`, `7/10`).
2. **Неправильний дріб:** чисельник більший або дорівнює знаменнику (`|a| ≥ b`). Такий дріб за модулем більший або дорівнює одиниці (наприклад, `5/3`, `12/7`).
3. **Мішане число:** запис неправильного дробу у вигляді цілої частини та правильного дробу. Для виділення цілої частини чисельник ділять на знаменник з остачею:
```
17 / 5 = 3 + 2/5 = 3 2/5            [виділення цілої частини]
```

### Правила знаків та нуль у дробах

1. **Нуль у чисельнику:** Якщо чисельник дорівнює нулю (`0 / b`), то значення дробу дорівнює 0 (для будь-якого `b ≠ 0`).
2. **Нуль у знаменнику:** Знаменник не може дорівнювати нулю (`b ≠ 0`), оскільки ділення на нуль є математично невизначеним.
3. **Правило знаків:** Від'ємний дріб можна записати трьома еквівалентними способами:
```
-(a / b) = (-a) / b = a / (-b)      [перенос знака мінуса]
(-a) / (-b) = a / b                [скорочення двох мінусів]
```

Одне й те саме раціональне число можна записати нескінченною кількістю різних пар:
```
1/2 = 2/4 = 3/6 = 5/10             [еквівалентні записи одного дробу]
```

Усі ці пари є рівнозначними (еквівалентними), оскільки для них справджується тотожність хрестового множення: `1 · 4 = 2 · 2`. Історію того, як людство відкривало дроби від стародавніх єгипетських аліквотних сум до сучасної риски дробу, описано у [Історія виникнення концепції дробу](topic:math/fractions/hist-fraction-concept.md).

## 2. Основна властивість дробу та скорочення

Значення дробу не зміниться, якщо його чисельник і знаменник помножити або поділити на одне й те саме ненульове ціле число `k`:
```
a / b = (a · k) / (b · k)         [основна властивість дробу]
```

Це співвідношення називається **основною властивістю дробу**.

Ділення чисельника і знаменника на їхній спільний дільник називається **скороченням дробу**. Якщо чисельник і знаменник діляться на свій найбільший спільний дільник `g = gcd(a, b)`, то отримують **нескоротний дріб** `p/r`, у якому чисельник і знаменник є взаємно простими числами (`gcd(p, r) = 1`):
```
p = a / gcd(a, b)                 [скорочений чисельник]
r = b / gcd(a, b)                 [скорочений знаменник]
```

```
Приклад скорочення дробу 24 / 36:
1. Пошук НСД: gcd(24, 36) = 12.
2. Ділення чисельника: 24 / 12 = 2.
3. Ділення знаменника: 36 / 12 = 3.

Канонічний нескоротний дріб: 2 / 3.
```

Кожне раціональне число має **єдине канонічне представлення** у вигляді нескоротного дробу `p/r` із додатним знаменником `r > 0`.

## 3. Арифметика звичайних дробів

### Додавання та віднімання
Додавати й віднімати можна лише дроби з однаковими знаменниками. Якщо знаменники різні, дроби попередньо зводять до спільного знаменника, яким є найменше спільне кратне (НСК) знаменників:
```
M = lcm(b, d) = (b · d) / gcd(b, d)   [найменший спільний знаменник]
```

Формула додавання:
```
a/b + c/d = (a · (M/b) + c · (M/d)) / M   [формула додавання дробів]
```

```
Приклад: 5/6 + 3/8
1. НСД знаменників: gcd(6, 8) = 2.
2. Спільний знаменник: M = lcm(6, 8) = (6 · 8) / 2 = 24.
3. Додаткові множники: 24 / 6 = 4  та  24 / 8 = 3.
4. Додавання чисельників: (5 · 4 + 3 · 3) / 24 = (20 + 9) / 24 = 29 / 24.
```

### Множення
Щоб помножити два дроби, чисельник множать на чисельник, а знаменник — на знаменник:
```
(a / b) · (c / d) = (a · c) / (b · d)   [формула множення дробів]
```

Перед обчисленням добутків чисельники й знаменники доцільно скоротити на спільні дільники, щоб уникнути великих чисел.

### Ділення
Щоб поділити дріб `a/b` на ненульовий дріб `c/d`, перший дріб множать на обернений дріб `d/c`:
```
(a / b) / (c / d) = (a / b) · (d / c) = (a · d) / (b · c)   [формула ділення дробів]
```

## 4. Порівняння звичайних дробів

Для порівняння двох звичайних дробів `a/b` та `c/d` застосовують три основні методи:

1. **Зведення до спільного знаменника:** порівнюють чисельники отриманих дробів із однаковими знаменниками.
2. **Перехресне множення:** якщо знаменники `b > 0` та `d > 0`, то `a/b < c/d` тоді і тільки тоді, коли `a · d < b · c`.
3. **Порівняння з проміжним числом:** порівняння кожного з дробів із `1/2` або `1`.

## 5. Перетворення у десяткові дроби та зворотне перетворення

Будь-який звичайний дріб `p/q` можна перетворити у десятковий дріб шляхом ділення чисельника на знаменник куточком. Результат завжди буде або скінченним, або нескінченним періодичним десятковим дробом:

1. **Скінченний десятковий дріб:** утворюється тоді і тільки тоді, коли знаменник нескоротного дробу не має інших простих дільників, крім 2 та 5. Наприклад, `3/8 = 0.375` (оскільки `8 = 2³`).
2. **Періодичний десятковий дріб:** утворюється тоді, коли знаменник містить інші прості дільники (3, 7, 11 тощо). Остачі від ділення починають повторюватися, формуючи період. Наприклад, `1/3 = 0.333... = 0.(3)`, а `1/7 = 0.(142857)`.

### Зворотне перетворення періодичного дробу у звичайний

Щоб перетворити чисто періодичний дріб у звичайний, у чисельнику записують період, а у знаменнику — число з дев'яток, кількість яких дорівнює довжині періоду. Якщо дріб змішаний періодичний вида `0.a(b)`, то чисельник дорівнює різниці числа, сформованого предперіодом разом із періодом, та числа предперіоду `ab - a`, а знаменник складається з дев'яток (за кількістю цифр у періоді) та нулів (за кількістю цифр у предперіоді):

```
0.(142857) = 142857 / 999999 = 1 / 7   [перетворення чисто періодичного дробу]
0.58(3) = (583 - 58) / 900 = 525 / 900 = 7 / 12   [перетворення змішаного дробу]
```

### Практичне значення точних дробів
У комп'ютерних системах звичайні дроби гарантують відсутність накопичення похибки округлення при багаторазових додаваннях та множеннях, що є фундаментальним для бухгалтерського обліку, комп'ютерної графіки та точних геометричних обчислень.
