# 📜 Історія діофантових наближень та шлях до теореми Рота

Завдання наближення дійсних чисел раціональними дробами виникло з практичної потреби вимірювання та астрономічних обчислень, але у XIX–XX століттях воно перетворилося на один із найглибших розділів теорії чисел. Центральним питанням цього напряму є фундаментальна межа точності: наскільки добре раціональний дріб `p / q` із малим знаменником `q` може підійти до заданого дійсного числа `α`?

У 1842 році німецький математик Петер Ґустав Лежен Діріхле (Peter Gustav Lejeune Dirichlet) заклав фундамент математичної теорії наближень, довівши свій знаменитий принцип ящиків (принцип Діріхле). За допомогою цього принципу він встановив, що для **будь-якого** ірраціонального числа `α` існує нескінченно багато раціональних дробів `p / q` (у несократному вигляді, `q > 0`), які задовольняють нерівність:

```
|α - p/q| < 1 / q²
```

Показник степеня 2 у знаменнику є універсальним для всіх дійсних ірраціональних чисел. Проте постало природне запитання: що відбувається, якщо ми звужуємо клас чисел `α` до алгебраїчних (лат. algebraicus, від араб. الجبر / al-jabr) — тобто коренів многочленів із цілими коефіцієнтами?

## Перший прорив: Жозеф Ліувіль та трансцендентні числа (1844)

До середини XIX століття математики знали про існування ірраціональних чисел (таких як `√2` чи `π`), але не знали, чи існують дійсні числа, які взагалі не є коренями жодного многочлена з цілими коефіцієнтами — так звані трансцендентні (лат. transcendens — той, що виходить за межі) числа.

У 1844 році французький математик Жозеф Ліувіль (Joseph Liouville) зробив перший фундаментальний крок у вивченні алгебраїчних чисел, представивши свій результат Паризькій академії наук. Він довів, що алгебраїчне число `α` ступеня `d ≥ 2` принципово **неможливо** наближати раціональними числами краще, ніж із показником `d`. Для кожного такого `α` існує обчислювана константа `c(α) > 0`, така що для всіх раціональних дробів `p / q` виконується нерівність:

```
|α - p/q| > c(α) / qᵈ
```

Цей результат дозволив Ліувілю вперше в історії математики сконструювати явно задані трансцендентні числа — так звані числа Ліувіля. Розглянемо число:

```
L = ∑ 10^(-k!) = 0.1100010000000000000000010...
```

Для кожного натурального `N` часткова сума `p_N / q_N = ∑_{k=1}^N 10^(-k!)` має знаменник `q_N = 10^(N!)`. Відстань від числа `L` до `p_N / q_N` задається залишком ряду, перший член якого дорівнює `10^(-(N+1)!) = (10^(N!))^(-(N+1)) = q_N^(-(N+1))`. 

Отже, для будь-якого фіксованого ступеня `d` можна обрати `N > d`, для якого `|L - p_N / q_N| < 1 / q_N^(d+1)`. Це суперечить теоремі Ліувіля для алгебраїчних чисел ступеня `d`, а отже число `L` зобов'язане бути трансцендентним!

Однак теорема Ліувіля давала дуже слабке обмеження для алгебраїчних чисел високих ступенів. Наприклад, для алгебраїчного числа ступеня `d = 100` Ліувіль стверджував лише відсутність наближень із показником `100`, хоча експериментальні дані показували, що алгебраїчні числа поводяться набагато ближче до межі Діріхле `2`.

## Ера багатовимірних многочленів: Аксель Тюе (1909)

Протягом шести десятиліть після праці Ліувіля не вдавалося зменшити показник `d` для жодного алгебраїчного числа ступеня `d ≥ 3`.

У 1909 році норвезький математик Аксель Тюе (Axel Thue), працюючи у Крістіанії (нині Осло), здійснив концептуальну революцію. Тюе зрозумів, що одновимірні многочлени `P(x)`, які використовував Ліувіль, вичерпали свої можливості. Замість них Тюе запропонував використовувати **допоміжні многочлени двох змінних** `P(x, y)` високого ступеня, які мають високий порядок обнулення в точці `(α, α)`.

За допомогою цього методу Тюе довів, що для алгебраїчного числа `α` ступеня `d ≥ 3` показник `d` можна зменшити до:

```
μ = d / 2 + 1 + ε
```

Нерівність `|α - p/q| < 1 / q^(d/2 + 1 + ε)` має лише **скінченне число** розв'язків у цілих числах `p, q`.

Цей результат мав колосальне значення для діофантова аналізу: Тюе застосував його для доведення скінченності кількості цілих розв'язків однорідних рівнянь `F(x, y) = m` ступеня `n ≥ 3` (які згодом отримали назву рівнянь Тюе).

## Етап Зігеля, Ґельфонда та Дайсона (1921–1947)

Результат Тюе відкрив шлях до серії послідовних покращень показника наближення, кожен з яких вимагав ускладнення алгебраїчного апарату:

1. **Карл Людвіг Зігель (1921):** Німецький математик Карл Зігель у своїй докторській дисертації у Франкфурті узагальнив метод Тюе, розглянувши многочлени `m` змінних. Щоб оцінити коефіцієнти таких многочленів, Зігель сформулював фундаментальну алгебраїчну лему (лему Зігеля) про розв'язок систем лінійних рівнянь із цілими коефіцієнтами. Це дозволило йому знизити показник наближення до:

```
μ = 2 √(d) + ε
```

Крім того, у 1929 році Зігель застосував ці результати для доведення своєї знаменитої теореми про скінченність цілих точок на алгебраїчних кривих роду `g ≥ 1`.

2. **Олександр Ґельфонд та Фрімен Дайсон (1947):** Радянський математик Олександр Ґельфонд у Москві та видатний англо-американський фізик і математик Фрімен Дайсон у Кембриджі незалежно розробили точніші аналітичні оцінки похідних багатовимірних многочленів. Вони опиралися на фундаментальну лему Дайсона про обнулення багатовимірних многочленів на сітці точок, що дозволило знизити показник до:

```
μ = √(2d) + ε
```

Попри ці успіхи, межа `2` залишалася недосяжною. Для кубічного алгебраїчного числа (`d = 3`) межа Дайсона давала `√(6) + ε ≈ 2.449 + ε`, але для великих `d` показник `√(2d)` все одно зростав разом зі ступенем поля.

## Тріумф Клауса Рота та Філдсівська премія (1955–1958)

Остаточний крок у цій столітній епопеї зробив англійський математик Клаус Петер Рот (Klaus Peter Roth). Народившись у Бреслау у 1925 році, Рот емігрував до Великої Британії і працював в Університетському коледжі Лондона (UCL) під керівництвом Гарольда Давенпорта.

У 1955 році в часописі *Mathematika* Рот опублікував 22-сторінкову статтю під назвою «Rational approximations to algebraic numbers». У цій праці Рот довів фундаментальну теорему: для будь-якого алгебраїчного ірраціонального числа `α` та будь-якого `ε > 0` нерівність:

```
|α - p/q| < 1 / q²⁺ᵉ
```

має лише скінченне число розв'язків у цілих числах `p, q`.

Доведення Рота вимагало принципово нових комбінаторних та аналітичних ідей. Рот розглянув многочлени `m` змінних при `m → ∞` і сформулював складну арифметико-аналітичну лему (лему Рота), яка доводить, що многочлен із цілими коефіцієнтами помірної висоти **не може мати високий індекс обнулення** у раціональних точках із різко зростаючими знаменниками.

У 1958 році на Міжнародному конгресі математиків в Единбурзі Клаусу Роту за це відкриття було вручено найвищу математичну нагороду — **Філдсівську премію** (Fields Medal).

## Подальший розвиток та сучасний стан

Відкриття Рота не зупинило розвиток галузі, а відкрило нові напрями досліджень:

1. **Теорема Шмідта про підпростори (1972):** Американський математик Вольфганг М. Шмідт узагальнив теорему Рота на багатовимірний випадок. Замість наближення одного алгебраїчного числа раціональними дробами Шмідт розглянув одночасне наближення системи лінійних форм від `n` змінних з алгебраїчними коефіцієнтами.
2. **Неефективність та метод Бейкера (1966):** Оскільки доведення Рота було неефективним (не давало межі для розміру знаменників), Алан Бейкер розробив метод логарифмічних форм у комплексній та p-адичній областях, який надав ефективні межі для рівнянь Тюе, Морделла та Каталана.
3. **Діофантова геометрія Пол Войта (1987):** Пол Войт побудував глибоку аналогію між теоремою Рота в теорії чисел та теоремами про розподіл значень (теорією Неванлінни) у комплексному аналізі, що об'єднало діофантові наближення з теорією алгебраїчних поверхонь.
