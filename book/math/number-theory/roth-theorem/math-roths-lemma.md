# 🧮 Лема Рота та індекс багатовимірного многочлена

Фундаментальне доведення Клауса Рота спирається на глибоку арифметичну властивість багатовимірних многочленів із цілими коефіцієнтами. Ключовим математичним інструментом, який дозволив подолати обмеження попередніх методів Тюе, Зігеля та Дайсона, є поняття **індексу многочлена** та **лема Рота**.

## 1. Поняття індексу многочлена

Нехай `P(X₁, X₂, ..., X_m)` — многочлен від `m` змінних із дійсними або комплексними коефіцієнтами, ступінь якого за змінною `Xᵢ` не перевищує `rᵢ` (де `r₁, ..., r_m` — додатні цілі числа).

Для кожної впорядкованої шестірки похідних `i = (i₁, i₂, ..., i_m)` позначимо нормовану частинну похідну (похідну Тейлора) як:

```
P^(i)(X₁, ..., X_m) = (1 / (i₁! i₂! ... i_m!)) · (∂^(i₁+...+i_m) P / ∂X₁ⁱ¹ ∂X₂ⁱ² ... ∂X_mⁱᵐ)
```

Ділення на факторіали гарантує, що якщо многочлен `P` має цілі коефіцієнти, то всі його нормовані похідні `P^(i)` також залишаються многочленами з цілими коефіцієнтами.

### Формальне означення індексу

Індексом многочлена `P` у точці `x = (x₁, x₂, ..., x_m)` відносно вагових степенів `r = (r₁, r₂, ..., r_m)` називається найменше значення раціональної суми:

```
I_P(x; r) = min { (i₁ / r₁) + (i₂ / r₂) + ... + (i_m / r_m) }
```

взяте за всіма мультиіндексами `i = (i₁, ..., i_m)`, для яких частинна похідна не перетворюється на нуль у точці `x`:

```
P^(i)(x₁, x₂, ..., x_m) ≠ 0
```

Якщо `I_P(x; r) ≥ σ`, це означає, що **всі** частинні похідні `P^(i)(x)`, чия зважена сума порядку `∑ (i_k / r_k)` менша за `σ`, тотожно дорівнюють нулю. Тобто індекс вимірює мультиплікативний порядок обнулення многочлена `P` у точці `x`.

### Численний приклад розрахунку індексу

Розглянемо многочлен двох змінних (`m = 2`):

```
P(X₁, X₂) = X₁³ X₂ - 2 X₁² X₂² + X₁ X₂³
```

Нехай вагові ступені дорівнюють `r₁ = 3, r₂ = 3`. Обчислимо індекс `I_P` у точці `(0, 0)`:

1. Сама функція у точці `(0,0)` дорівнює нулю: `P(0, 0) = 0`.
2. Перші частинні похідні:
   - `∂P / ∂X₁ = 3 X₁² X₂ - 4 X₁ X₂² + X₂³` ⇒ у точці `(0,0)` дорівнює `0`.
   - `∂P / ∂X₂ = X₁³ - 4 X₁² X₂ + 3 X₁ X₂²` ⇒ у точці `(0,0)` дорівнює `0`.
3. Другі частинні похідні:
   - `∂²P / ∂X₁² = 6 X₁ X₂ - 4 X₂²` ⇒ у точці `(0,0)` дорівнює `0`.
   - `∂²P / ∂X₁ ∂X₂ = 3 X₁² - 8 X₁ X₂ + 3 X₂²` ⇒ у точці `(0,0)` дорівнює `0`.
   - `∂²P / ∂X₂² = -4 X₁² + 6 X₁ X₂` ⇒ у точці `(0,0)` дорівнює `0`.
4. Треті частинні похідні:
   - `∂³P / ∂X₁³ = 6 X₂` ⇒ у точці `(0,0)` дорівнює `0`.
   - `∂³P / ∂X₁² ∂X₂ = 6 X₁ - 8 X₂` ⇒ у точці `(0,0)` дорівнює `0`.
   - `∂³P / ∂X₁ ∂X₂² = -8 X₁ + 6 X₂` ⇒ у точці `(0,0)` дорівнює `0`.
   - `∂³P / ∂X₂³ = 6 X₁` ⇒ у точці `(0,0)` дорівнює `0`.
5. Четверті частинні похідні:
   - `∂⁴P / ∂X₁³ ∂X₂ = 6 ≠ 0`. Співвідношення порядку для мультиіндексу `(3, 1)`:
   
```
(i₁ / r₁) + (i₂ / r₂) = 3 / 3 + 1 / 3 = 4 / 3
```

   - `∂⁴P / ∂X₁² ∂X₂² = -8 ≠ 0`. Співвідношення порядку для мультиіндексу `(2, 2)`:
   
```
(i₁ / r₁) + (i₂ / r₂) = 2 / 3 + 2 / 3 = 4 / 3
```

Отже, найменша зважена сума порядків невироджених похідних у точці `(0,0)` дорівнює `4 / 3`. 

Індекс даного многочлена становить `I_P((0,0); (3,3)) = 4 / 3 ≈ 1.3333`.

## 2. Лема Зігеля про побудову допоміжного многочлена

Першим етапом доведення теореми Рота є побудова ненульового многочлена `P(X₁, ..., X_m)` із цілими коефіцієнтами, який має надзвичайно високий індекс у точці `(α, α, ..., α)`.

Для цього використовується фундаментальна алгебраїчна лема Карла Зігеля.

**Лема Зігеля (1929):**
Нехай маємо систему з `M` лінійних однорідних рівнянь із `N` невідомими `x₁, x₂, ..., x_N` та цілими коефіцієнтами `a_{ij}`:

```
∑_{j=1}^N a_{ij} x_j = 0    (для i = 1, 2, ..., M)
```

Припустимо, що кількість невідомих суворо більша за кількість рівнянь (`N > M`). Нехай `A = max |a_{ij}| ≥ 1` — максимум модулів коефіцієнтів системи. 

Тоді існує ненульовий цілочисельний розв'язок `(x₁, x₂, ..., x_N) ∈ ℤᴺ \ {0}`, модуль векторної норми якого обмежений величиною:

```
max |x_j| ≤ (N · A)^(M / (N - M))
```

### Застосування леми Зігеля у доведенні Рота

Розглянемо невідомі коефіцієнти многочлена `P(X₁, X₂, ..., X_m)` ступеня `r_k` за змінною `X_k`. 

- Загальна кількість коефіцієнтів (кількість невідомих `N`) дорівнює:

```
N = (r₁ + 1) (r₂ + 1) ... (r_m + 1)
```

- Умова обнулення похідних `P^(i)(α, ..., α) = 0` для всіх мультиіндексів із зваженою сумою `∑ (i_k / r_k) < σ` задає систему лінійних рівнянь над алгебраїчним полем `ℚ(α)`. За допомогою базису поля ця система зводиться до системи `M` рівнянь над `ℤ`, де:

```
M ≈ d · N · (об'єм багатовимірного симплекса порядку σ)
```

Якщо обрати `σ = (m / 2) · (1 - δ)`, то об'єм симплекса у багатовимірному просторі стає суворо меншим за `1 / d`. 

Це гарантує, що кількість невідомих `N` суворо більша за кількість рівнянь `M` (`N > M`).

Отже, за лемою Зігеля існує ненульовий многочлен `P(X₁, ..., X_m)` із цілими коефіцієнтами, який задовольняє дві умови:

1. **Високий індекс у точці кореня:**
```
I_P(α, ..., α; r) ≥ σ = (m / 2) · (1 - δ)
```
2. **Обмежена наївна висота коефіцієнтів:**
```
H(P) = max |C_{m₁,...,m_m}| ≤ B^r₁
```
де `B = q₁` — знаменник першого наближення.

## 3. Перенесення обнулення у раціональну точку

Нехай `p₁/q₁, p₂/q₂, ..., p_m/q_m` — `m` раціональних наближень до алгебраїчного числа `α`, які задовольняють нерівність:

```
|α - p_k / q_k| < 1 / q_k^(2 + ε)
```

Розкладемо похідні многочлена `P^(i)` у багатовимірний ряд Тейлора в околі точки `(α, α, ..., α)` і обчислимо їхнє значення у раціональній точці `(p₁/q₁, ..., p_m/q_m)`:

```
P^(i)(p₁/q₁, ..., p_m/q_m) = ∑_{j} P^(i+j)(α, ..., α) · (p₁/q₁ - α)ʲ¹ ... (p_m/q_m - α)ʲᵐ
```

Оскільки за побудовою Зігеля `P^(i+j)(α, ..., α) = 0` для всіх порядків із зваженою сумою, меншою за `σ`, у сумі Тейлора залишаються лише доданки з високими степенями відхилення `|p_k/q_k - α|`.

Оскільки `|p_k/q_k - α| < q_k^-(2+ε)`, оцінка залишкового члена показує, що для всіх мультиіндексів із зваженою сумою `∑ (i_k / r_k) < σ - ε'` значення похідної за модулем суворо менше за знаменник:

```
|P^(i)(p₁/q₁, ..., p_m/q_m)| < 1 / (q₁ʳ¹ q₂ʳ² ... q_mʳᵐ)
```

Проте число `P^(i)(p₁/q₁, ..., p_m/q_m)` є раціональним дробом із спільним знаменником `q₁ʳ¹ q₂ʳ² ... q_mʳᵐ`. 

Якщо раціональний дріб `A / (q₁ʳ¹ ... q_mʳᵐ)` за модулем менший за `1 / (q₁ʳ¹ ... q_mʳᵐ)`, то його цілий чисельник `A` зобов'язаний дорівнювати нулю (`A = 0`)!

Отже, високий індекс обнулення у точці `(α, ..., α)` автоматично переноситься у раціональну точку:

```
I_P(p₁/q₁, ..., p_m/q_m; r) ≥ σ' ≈ m / 2
```

## 4. Формулювання та доведення Леми Рота

Тут Клаус Рот застосовує свій фундаментальний комбінаторно-арифметичний бар'єр.

**Лема Рота (1955):**
Нехай `P(X₁, X₂, ..., X_m)` — ненульовий многочлен від `m` змінних із цілими коефіцієнтами, ступені якого не перевищують `r₁, r₂, ..., r_m`. Нехай `p₁/q₁, ..., p_m/q_m` — раціональні числа у несократному вигляді, знаменники яких задовольняють умови експоненціально швидкого зростання:

```
q₁ʳ¹ ≤ q₂ʳ² ≤ ... ≤ q_mʳᵐ
```

та

```
q_k^(r_k) ≥ (e^(r₁))^(1 / ω)
```

де `ω > 0` — малий параметр. Якщо наївна висота многочлена обмежена як `H(P) ≤ q₁^(r₁ ω)`, то індекс многочлена `P` у точці `(p₁/q₁, ..., p_m/q_m)` задовольняє строгу верхню межу:

```
I_P(p₁/q₁, ..., p_m/q_m; r) ≤ ω
```

де `ω` може бути зроблено довільно малим при виборі достатньо великої кількості змінних `m`.

### Ідея комбінаторного доведення Леми Рота

Доведення леми Рота виконується індукцією за кількістю змінних `m`. 

Якщо припустити, що індекс `I_P(p₁/q₁, ..., p_m/q_m; r) > ω`, це означає існування великої кількості послідовних обнулень похідних `P^(i)`. За допомогою операцій проектування та побудови визначників Вронського (вронськіанів) відносно послідовності змінних, Рот конструює новий многочлен меншого числа змінних `P'(X₁, ..., X_{m-1})` з цілими коефіцієнтами.

Проте умови експоненціального зростання знаменників `q_k` гарантують, що на кожному кроці індукційного скорочення висота коефіцієнтів нового многочлена не зростає надто швидко. На останньому кроці (`m = 1`) виходить ненульовий однодетермінантний многочлен від однієї змінної, який має порядок обнулення у раціональній точці `p₁ / q₁`, що перевищує його власний ступінь `r₁`. 

Оскільки ненульовий многочлен ступеня `r₁` не може мати більше за `r₁` коренів, це дає остаточну арифметичну суперечність.

## 5. Завершення доведення теореми Рота

Об'єднання аналітичного перенесення Зігеля та арифметичного обмеження Рота створює підсумкову двосторонню пастку:

1. **Нижня оцінка індексу (Зігель + Тейлор):** Припустивши існування `m` дуже хороших наближень з `|α - p_k/q_k| < 1 / q_k^(2+ε)`, ми побудували многочлен `P`, для якого:

```
I_P(p₁/q₁, ..., p_m/q_m; r) ≥ m / 2 - ε'
```

2. **Верхня оцінка індексу (Лема Рота):** Для тих самих раціональних точок зі швидко зростаючими знаменниками `q₁ ≪ q₂ ≪ ... ≪ q_m` лема Рота дає:

```
I_P(p₁/q₁, ..., p_m/q_m; r) ≤ ω
```

Образивши `m = 100` та `ω = 0.1`, ми отримуємо нерівність:

```
45 ≤ 0.1   [АРИФМЕТИЧНА СУПЕРЕЧНІСТЬ!]
```

Отримана суперечність доводить, що припущення про існування `m` послідовних раціональних наближень з показником `2 + ε` є хибним.

Отже, кількість розв'язків нерівності `|α - p/q| < 1 / q²⁺ᵉ` не може перевищувати `m - 1`, а отже є **скінченною**.
