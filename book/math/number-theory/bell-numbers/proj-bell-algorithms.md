# ⚙️ Практичні алгоритми обчислення чисел Белла та генерування розбиттів

Обчислення чисел Белла та алгоритмічна генерація усіх можливих розбиттів скінченних множин є фундаментальними завданнями прикладної комбінаторики, обчислювальної теорії графів та системного програмування. Оскільки числа Белла зростають надзвичайно швидко (наприклад, `B₂₀ = 51 724 158 235 372`, що перевищує межу 32-бітного цілого числа, а `B₂₆ = 27 644 437 000 000 000 000` виходить за межі стандартного 64-бітного беззнакового типу `uint64_t`), розробка обчислювальних алгоритмів вимагає ретельного вибору типів даних, оптимізації пам'яті та врахування специфіки конкретної прикладної задачі.

Практичні алгоритми для роботи з числами Белла поділяються на три основні обчислювальні класи:
1. **Точне обчислення послідовності `B₀ … B_n` через трикутник Ейткена:** часова складність `O(n²)`, просторова складність `O(n)`. Метод є оптимальним для табулювання невисоких степенів `n ≤ 25` без використання довгої арифметики.
2. **Швидке обчислення `B_n (mod p)` за порівнянням Тушара:** часова складність `O(p² + n)`, просторова складність `O(p)`. Алгоритм дозволяє миттєво обчислювати остачу від ділення `B_n` на довільне просте число `p` навіть для гігантських `n = 10⁹`, повністю уникаючи потреби у довгоарифметичних обчисленнях.
3. **Вичерпна генерація розбиттів у форматі рядків обмеженого зростання (Restricted Growth Strings, RGS):** часова складність `O(B_n)`, просторова складність `O(n)`. Алгоритм будує всі можливі розбиття множини у строгому лексикографічному порядку через пошук з поверненням (backtracking).

У цій вставці наведено розлогий аналіз алгоритмів, детальний простежувальний аналіз станів пам'яті та вичерпні, готові до компіляції реалізації усіх трьох підходів мовами C та C++.

## 1. Обчислення за трикутником Ейткена: оптимізація O(n²) часу та O(n) пам'яті

Найпростішим та найстійкішим способом точного обчислення послідовності `B₀, B₁, …, B_n` є побудова трикутника Ейткена (трикутника Белла).

### Алгоритмічний аналіз та оптимізація пам'яті

Наївна побудова двовимірної таблиці Ейткена вимагає збереження матриці розміром `n × n`, що потребує `O(n²)` пам'яті. Проте для обчислення кожного нового `i`-го рядка потрібні лише значення з попереднього `(i-1)`-го рядка.

Ми можемо скоротити витрати пам'яті з `O(n²)` до `O(n)`, використавши єдиний одновимірний буферний масив `row` розміром `n + 1`. Під час обробки `i`-го рядка ми оновлюємо елементи масиву `row` зліва направо, зберігаючи попереднє значення в тимчасовій змінній `prev`, щоб запобігти передчасному перезапису даних.

Алгоритм працює за наступною покроковою схемою:
1. Ініціалізуємо буферний масив `row[0] = 1`, `bell[0] = 1`.
2. На кожному зовнішньому кроці `i` від `1` до `n`:
   - Зберігаємо перший елемент попереднього рядка у змінну `prev = row[0]`.
   - Записуємо новий перший елемент поточного рядка з останнього елемента попереднього рядка: `row[0] = row[i - 1]`.
   - Фіксуємо значення числа Белла `bell[i] = row[0]`.
   - У внутрішньому циклі `j` від `1` до `i` виконуємо перерахунок елементів: `temp = row[j]`, `row[j] = row[j - 1] + prev`, `prev = temp`.
   - Наприкінці кроку `i` перший елемент `row[0]` містить чисельне значення `B_i`, а крайній елемент `row[i]` — значення `B_{i+1}`.

### Простеження станів пам'яті для n = 3

Простежимо вміст масиву `row` на кожній ітерації для `n = 3`:

```
Старт (i = 0):  row = [1, 0, 0, 0]             ==> B_0 = 1
Крок i = 1:     prev = 1, row[0] = 1
                j = 1: row[1] = row[0] + 1 = 2  ==> row = [1, 2, 0, 0], B_1 = 1
Крок i = 2:     prev = 1, row[0] = 2
                j = 1: row[1] = row[0] + 1 = 3
                j = 2: row[2] = row[1] + 2 = 5  ==> row = [2, 3, 5, 0], B_2 = 2
Крок i = 3:     prev = 2, row[0] = 5
                j = 1: row[1] = row[0] + 2 = 7
                j = 2: row[2] = row[1] + 3 = 10
                j = 3: row[3] = row[2] + 5 = 15 ==> row = [5, 7, 10, 15], B_3 = 5
```

### Захист від переповнення та межі типів

Для 64-бітного цілого типу без знака (`uint64_t` у C/C++) максимальне значення дорівнює `2⁶⁴ − 1 ≈ 1.84 × 10¹⁹`. 
Число `B₂₅ = 4 638 590 332 229 999 353` є останнім числовим значенням, яке повністю вміщується у тип `uint64_t`. Значення `B₂₆ = 27 644 437 000 000 000 000` вже викликає арифметичне переповнення. Для обчислення `B_n` при `n ≥ 26` масив `row` має зберігати об'єкти довгої арифметики (BigInt) на основі вектора `std::vector<uint32_t>` з основою `10⁹`.

Нижче наведено вичерпні, готові до компіляції реалізації мовами C та C++.

:::tabs
```c
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

/* Обчислення чисел Белла від B_0 до B_n у буфер out_bell (розмір n + 1).
   Оптимізовано за пам'яттю до O(n).
   Повертає 0 у разі успіху, -1 у разі помилки виділення пам'яті, -2 якщо n > 25 */
int compute_bell_numbers(size_t n, uint64_t *out_bell) {
    if (!out_bell) return -1;
    if (n > 25) {
        /* B_26 перевищує межу 64-бітного цілого uint64_t */
        return -2;
    }

    uint64_t *row = (uint64_t *)malloc((n + 1) * sizeof(uint64_t));
    if (!row) return -1;

    row[0] = 1;
    out_bell[0] = 1;

    for (size_t i = 1; i <= n; ++i) {
        /* Перший елемент нового рядка дорівнює останньому елементу попереднього */
        uint64_t prev = row[0];
        row[0] = row[i - 1];
        out_bell[i] = row[0];

        for (size_t j = 1; j <= i; ++j) {
            uint64_t temp = row[j];
            row[j] = row[j - 1] + prev;
            prev = temp;
        }
    }

    free(row);
    return 0;
}

int main(void) {
    const size_t N = 15;
    uint64_t bell[16];

    if (compute_bell_numbers(N, bell) == 0) {
        printf("Перші 16 чисел Белла:\n");
        for (size_t i = 0; i <= N; ++i) {
            printf("B_%-2zu = %llu\n", i, (unsigned long long)bell[i]);
        }
    }
    return 0;
}
```
```cpp

#include <vector>
#include <cstdint>
#include <stdexcept>

// Генерація перших n + 1 чисел Белла B_0 ... B_n
std::vector<std::uint64_t> compute_bell_numbers(std::size_t n) {
    if (n > 25) {
        throw std::overflow_error("Значення n > 25 викликає переповнення std::uint64_t");
    }

    std::vector<std::uint64_t> bell(n + 1);
    std::vector<std::uint64_t> row(n + 1);

    row[0] = 1;
    bell[0] = 1;

    for (std::size_t i = 1; i <= n; ++i) {
        std::uint64_t prev = row[0];
        row[0] = row[i - 1];
        bell[i] = row[0];

        for (std::size_t j = 1; j <= i; ++j) {
            std::uint64_t temp = row[j];
            row[j] = row[j - 1] + prev;
            prev = temp;
        }
    }

    return bell;
}

int main() {
    try {
        constexpr std::size_t N = 15;
        const auto bell = compute_bell_numbers(N);

        std::cout << "Перші 16 чисел Белла:\n";
        for (std::size_t i = 0; i <= N; ++i) {
            std::cout << "B_" << i << " = " << bell[i] << "\n";
        }
    } catch (const std::exception& e) {
        std::cerr << "Помилка: " << e.what() << "\n";
        return 1;
    }
    return 0;
}
```

## 2. Швидке обчислення B_n (mod p) за порівнянням Тушара

Для великих `n` (наприклад, `n = 10⁹`) точне обчислення `B_n` вимагатиме зберігання масивів із мільйонами знаків довгої арифметики. Проте в теорії чисел, алгоритмах хешування та криптографії зазвичай вимагається обчислити остачу `B_n (mod p)` для даного простого `p`.

### Застосування лінійної рекурентності Тушара та кільцевого буфера

За порівнянням Тушара для довільного простого `p` маємо:

```
B_{k+p} ≡ B_{k+1} + B_k (mod p)
```

Це лінійне рекурентне рівняння порядку `p` дозволяє знайти будь-яке `B_n (mod p)` за лінійну кількість операцій `O(p² + n)`, зберігаючи в пам'яті кільцевий буфер розміром строго `p + 1` елемент!

Схема алгоритму:
1. За допомогою трикутника Ейткена за модулем `p` обчислюємо перші `p + 1` значень `B₀, B₁, …, B_p (mod p)` за час `O(p²)`.
2. Створюємо кільцевий буфер `b` розміром `p + 1`.
3. Для всіх `k` від `1` до `n - p` обчислюємо `b[(k + p) % (p + 1)] = (b[(k + 1) % (p + 1)] + b[k % (p + 1)]) % p`.
4. Повертаємо елемент `b[n % (p + 1)]`.

Цей алгоритм виконує обчислення для `n = 10⁹` та `p = 10007` за частки мілісекунди без використання довгої арифметики.

:::tabs
```c
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

/* Обчислення B_n mod p для простого p за допомогою рекурентності Тушара.
   Часова складність: O(p^2 + n), пам'ять O(p) */
uint64_t bell_mod_p(uint64_t n, uint64_t p) {
    if (p <= 1) return 0;
    if (n == 0 || n == 1) return 1 % p;

    /* Базовий масив розміром p + 1 для зсуву Тушара */
    uint64_t *b = (uint64_t *)calloc(p + 1, sizeof(uint64_t));
    if (!b) return 0;

    /* Крок 1. Обчислюємо перші p + 1 чисел Белла за модулем p через трикутник */
    uint64_t *row = (uint64_t *)calloc(p + 1, sizeof(uint64_t));
    if (!row) { free(b); return 0; }

    row[0] = 1;
    b[0] = 1 % p;

    for (uint64_t i = 1; i <= p; ++i) {
        uint64_t prev = row[i - 1];
        row[0] = prev;
        for (uint64_t j = 1; j <= i; ++j) {
            uint64_t temp = row[j];
            row[j] = (row[j - 1] + prev) % p;
            prev = temp;
        }
        b[i] = row[i];
    }
    free(row);

    /* Крок 2. Якщо n <= p, повертаємо готовий результат */
    if (n <= p) {
        uint64_t res = b[n];
        free(b);
        return res;
    }

    /* Крок 3. Використовуємо порівняння Тушара: B_{k+p} = (B_{k+1} + B_k) mod p */
    size_t cap = (size_t)(p + 1);
    for (uint64_t k = 1; k <= n - p; ++k) {
        size_t idx_kp = (size_t)((k + p) % cap);
        size_t idx_k1 = (size_t)((k + 1) % cap);
        size_t idx_k  = (size_t)(k % cap);

        b[idx_kp] = (b[idx_k1] + b[idx_k]) % p;
    }

    uint64_t result = b[n % cap];
    free(b);
    return result;
}

int main(void) {
    uint64_t n = 100;
    uint64_t p = 7;
    printf("B_%llu mod %llu = %llu\n", (unsigned long long)n, (unsigned long long)p,
           (unsigned long long)bell_mod_p(n, p));
    return 0;
}
```
```cpp
#include <iostream>
#include <vector>
#include <cstdint>

// Обчислення B_n mod p за допомогою рекурентності Тушара
std::uint64_t bell_mod_p(std::uint64_t n, std::uint64_t p) {
    if (p <= 1) return 0;
    if (n <= 1) return 1 % p;

    // Крок 1. Обчислюємо B_0 ... B_p mod p
    std::vector<std::uint64_t> b(p + 1, 0);
    std::vector<std::uint64_t> row(p + 1, 0);

    row[0] = 1;
    b[0] = 1 % p;

    for (std::size_t i = 1; i <= p; ++i) {
        std::uint64_t prev = row[i - 1];
        row[0] = prev;
        for (std::size_t j = 1; j <= i; ++j) {
            std::uint64_t temp = row[j];
            row[j] = (row[j - 1] + prev) % p;
            prev = temp;
        }
        b[i] = row[i];
    }

    if (n <= p) return b[n];

    // Крок 2. Кільцевий буфер за порівнянням Тушара
    const std::size_t cap = p + 1;
    for (std::uint64_t k = 1; k <= n - p; ++k) {
        b[(k + p) % cap] = (b[(k + 1) % cap] + b[k % cap]) % p;
    }

    return b[n % cap];
}

int main() {
    std::uint64_t n = 100;
    std::uint64_t p = 7;
    std::cout << "B_" << n << " mod " << p << " = " << bell_mod_p(n, p) << "\n";
    return 0;
}
```

## 3. Генерація розбиттів у вигляді рядків обмеженого зростання (RGS)

У багатьох практичних задачах (перебір кластерних моделей, аналіз комбінаторних систем, аналіз алгоритмів розфарбування графів) вимагається не просто порахувати число `B_n`, а згенерувати абсолютно всі розбиття множини `{0, 1, …, n-1}`.

### Концепція рядків обмеженого зростання (RGS) та алгебраїчна бієкція

Найзручнішим способом канонічного подання розбиття множини є **рядок обмеженого зростання** (Restricted Growth String, RGS). 

Рядок цілих чисел `a[0], a[1], …, a[n-1]` називається RGS, якщо він задовольняє наступні два фундаментальні інваріанти:
1. `a[0] = 0`;
2. Для кожного `i ≥ 1`: `0 ≤ a[i] ≤ max(a[0], a[1], …, a[i-1]) + 1`.

Значення `a[i]` задає номер блоку (класу еквівалентності), до якого належить `i`-й елемент. Оскільки перший елемент завжди створює блок 0, а кожен наступний елемент може або увійти до одного з вже існуючих блоків, або створити новий блок із номером `max + 1`, існує точна взаємно однозначна бієкція між RGS довжини `n` та всіма розбиттями `n`-елементної множини.

Наприклад, RGS `(0, 1, 0, 2)` описує розбиття 4-елементної множини `{0, 1, 2, 3}` на 3 блоки:
- Елементи 0 та 2 мають значення `0`, отже належать до першого блоку `{0, 2}`;
- Елемент 1 має значення `1`, отже належить до другого блоку `{1}`;
- Елемент 3 має значення `2`, отже належить до третього блоку `{3}`.

Кількість усіх можливих RGS довжини `n` строго дорівнює числу Белла `B_n`. 

Нижче наведено алгоритм пошуку з поверненням (backtracking) Дональда Кнута (Алгоритм H з 4-го тому «Мистецтва програмування») для генерації всіх RGS у строгому лексикографічному порядку.

:::tabs
```c
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

typedef void (*partition_callback)(const int *a, size_t n, void *user_data);

/* Генерація всіх розбиттів n-множини у форматі RGS (Алгоритм H Дональда Кнута) */
static void generate_rgs_rec(size_t idx, size_t n, int *a, int *m,
                             partition_callback cb, void *user_data) {
    if (idx == n) {
        cb(a, n, user_data);
        return;
    }

    int max_prev = m[idx - 1];
    for (int v = 0; v <= max_prev + 1; ++v) {
        a[idx] = v;
        m[idx] = (v > max_prev) ? v : max_prev;
        generate_rgs_rec(idx + 1, n, a, m, cb, user_data);
    }
}

void generate_all_partitions(size_t n, partition_callback cb, void *user_data) {
    if (n == 0 || !cb) return;

    int *a = (int *)malloc(n * sizeof(int));
    int *m = (int *)malloc(n * sizeof(int));
    if (!a || !m) { free(a); free(m); return; }

    a[0] = 0;
    m[0] = 0;

    generate_rgs_rec(1, n, a, m, cb, user_data);

    free(a);
    free(m);
}

static void print_partition(const int *a, size_t n, void *user_data) {
    size_t *count = (size_t *)user_data;
    (*count)++;

    printf("[%2zu] RGS: (", *count);
    for (size_t i = 0; i < n; ++i) {
        printf("%d%s", a[i], (i + 1 < n) ? ", " : "");
    }
    printf(")\n");
}

int main(void) {
    size_t count = 0;
    const size_t N = 4;
    printf("Усі розбиття для n = 4 (усього B_4 = 15):\n");
    generate_all_partitions(N, print_partition, &count);
    return 0;
}
```
```cpp
#include <iostream>
#include <vector>
#include <functional>
#include <algorithm>

// Генерація всіх розбиттів n-елементної множини у форматі RGS
void generate_all_partitions(std::size_t n,
                             const std::function<void(const std::vector<int>&)>& callback) {
    if (n == 0) return;

    std::vector<int> a(n, 0);
    std::vector<int> m(n, 0);

    auto backtrack = [&](auto& self, std::size_t idx) -> void {
        if (idx == n) {
            callback(a);
            return;
        }

        int max_prev = m[idx - 1];
        for (int v = 0; v <= max_prev + 1; ++v) {
            a[idx] = v;
            m[idx] = std::max(v, max_prev);
            self(self, idx + 1);
        }
    };

    backtrack(backtrack, 1);
}

int main() {
    std::size_t count = 0;
    constexpr std::size_t N = 4;

    std::cout << "Усі розбиття для n = 4 (усього B_4 = 15):\n";
    generate_all_partitions(N, [&](const std::vector<int>& rgs) {
        ++count;
        std::cout << "[" << count << "] RGS: (";
        for (std::size_t i = 0; i < rgs.size(); ++i) {
            std::cout << rgs[i] << (i + 1 < rgs.size() ? ", " : "");
        }
        std::cout << ")\n";
    });

    return 0;
}
```

## 4. Підсумкова порівняльна характеристика алгоритмів

Нижче наведено підсумкову порівняльну характеристику трьох розглянутих практичних алгоритмів для роботи з числами Белла:

| Алгоритм | Часова складність | Пам'ять | Призначення та практичні обмеження |
|---|---|---|---|
| **Трикутник Ейткена (DP)** | `O(n²)` | `O(n)` | Точне обчислення послідовності `B₀…B_n`. Обмежено `n ≤ 25` для 64-бітних цілих. |
| **Порівняння Тушара (Mod p)** | `O(p² + n)` | `O(p)` | Обчислення остач `B_n (mod p)` для гігантських `n` (наприклад `n = 10⁹`). Уникає довгої арифметики. |
| **Генерація RGS (Кнут)** | `O(B_n)` | `O(n)` | Повний перебір та генерація усіх `B_n` розбиттів. Обмежено вибіркою `n ≤ 15` через вибуховий ріст `B_n`. |
