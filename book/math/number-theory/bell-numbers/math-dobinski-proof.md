# 🧮 Доведення формули Добінського та порівняння Тушара

Формула Добінського та модульне порівняння Тушара є двома найважливішими теоретичними стовпами, на яких тримається аналітична та арифметична теорія чисел Белла. Формула Добінського пов'язує дискретний комбінаторний підрахунок розбиттів із підсумком нескінченного аналітичного ряду та теорією ймовірностей, тоді як порівняння Тушара відкриває глибинну арифметичну періодичність чисел Белла за довільним простим модулем. Ця вставка містить вичерпне, покрокове алгебраїчне виведення обох фундаментальних результатів з усіма проміжними обґрунтуваннями.

---

## 1. Операторний метод та строге виведення формули Добінського

Формула Добінського, опублікована Ґжеґожем Добінським у 1877 році, стверджує, що `n`-е число Белла `B_n` задається підсумком нескінченного аналітичного ряду:

```
B_n = (1 / e) · ∑ (від k=0 до ∞) (kⁿ / k!)
```

Для її доведення скористаємося методом формальних диференціальних операторів у просторі гладких функцій.

### Крок 1. Аналітичний розклад експоненти та оператор диференціювання

Розглянемо стандартний розклад функції `f(x) = eˣ` у ряд Тейлора в околі нуля. Цей ряд є абсолютно збіжним для всіх дійсних та комплексних чисел `x`:

```
eˣ = ∑ (від k=0 до ∞) (xᵏ / k!)   [стандартний розклад експоненти у степеневий ряд]
```

Запровадимо лінійний диференціальний оператор `Θ = x · (d/dx)`. Дія цього оператора на довільну степеневу функцію `xᵏ` полягає у диференціюванні з наступним множенням на `x`, що еквівалентно множенню одночлена на його показник степеня `k`:

```
Θ(xᵏ) = x · (d/dx)(xᵏ) = x · (k · xᵏ⁻¹) = k · xᵏ   [дія оператора Θ на одночлен xᵏ]
```

Оскільки оператор `Θ` є лінійним, його дія на степеневий ряд здійснюється почленно. Застосуємо оператор `Θ` послідовно `n` разів до обох частин розкладу функції `eˣ`:

```
Θⁿ(eˣ) = ∑ (від k=0 до ∞) (kⁿ · xᵏ / k!)   [n-разове застосування оператора Θ під знаком суми]
```

Це рівняння показує, що застосування `Θⁿ` до `eˣ` породжує у чисельнику кожного доданку коефіцієнт `kⁿ`.

### Крок 2. Зв'язок дифоператора з числами Стірлінга другого роду

З іншого боку, звичайні вищі похідні експоненціальної функції задовольняють інваріантність `(dᵏ/dxᵏ)(eˣ) = eˣ`. Це дозволяє виразити степені оператора `Θⁿ` через звичайні похідні `dᵏ/dxᵏ` та числа Стірлінга другого роду `S(n, k)`.

В операторному числі доводиться фундаментальна тотожність для степенів оператора `Θⁿ`:

```
Θⁿ = ∑ (від k=0 до n) S(n, k) · xᵏ · (dᵏ / dxᵏ)   [операторна тотожність для степенів Θⁿ]
```

Застосуємо цю операторну формулу безпосередньо до аналітичної функції `eˣ`:

```
Θⁿ(eˣ)
= ∑ (від k=0 до n) S(n, k) · xᵏ · (dᵏ/dxᵏ)(eˣ)    [підстановка функції eˣ в операторну тотожність]
= ∑ (від k=0 до n) S(n, k) · xᵏ · eˣ              [оскільки k-та похідна dᵏ(eˣ)/dxᵏ дорівнює eˣ]
= eˣ · ∑ (від k=0 до n) S(n, k) · xᵏ              [винесення спільного множника eˣ за дужки]
```

### Крок 3. Підстановка x = 1 та остаточне виведення

Прирівняємо два вирази для `Θⁿ(eˣ)`, отримані на Кроці 1 та Кроці 2:

```
∑ (від k=0 до ∞) (kⁿ · xᵏ / k!) = eˣ · ∑ (від k=0 до n) S(n, k) · xᵏ   [прирівнювання двох форм Θⁿ(eˣ)]
```

Ця тотожність виконується для всіх `x`. Підставимо у неї значення `x = 1`:

```
∑ (від k=0 до ∞) (kⁿ / k!)
= e¹ · ∑ (від k=0 до n) S(n, k) · 1ᵏ              [підстановка значення x = 1]
= e · ∑ (від k=0 до n) S(n, k)                    [спрощення 1ᵏ = 1 та e¹ = e]
= e · B_n                                         [оскільки сума S(n,k) за всіма k від 0 до n дорівнює B_n]
```

Поділивши обидві частини отриманого рівняння на число Ейлера `e`, маємо остаточну формулу Добінського:

```
B_n = (1 / e) · ∑ (від k=0 до ∞) (kⁿ / k!)
```

Першу частину доведення завершено.

## 2. Друге доведення формули Добінського через експоненціальну твірну функцію

Існує альтернативне аналітичне доведення формули Добінського, яке опирається безпосередньо на експоненціальну твірну функцію чисел Белла `B(x) = e^(eˣ − 1)`.

Розкладемо зовнішню експоненту `e^(eˣ − 1) = e⁻¹ · e^(eˣ)` у ряд Тейлора:

```
B(x)
= e⁻¹ · e^(eˣ)                                    [винесення постійного множника e⁻¹]
= e⁻¹ · ∑ (від k=0 до ∞) ((eˣ)ᵏ / k!)             [розклад зовнішньої експоненти за показником eˣ]
= e⁻¹ · ∑ (від k=0 до ∞) (e^(k·x) / k!)           [застосування властивості степеня (eˣ)ᵏ = e^(k·x)]
```

Тепер розкладемо внутрішню експоненту `e^(k·x)` у власний ряд Тейлора за зміною `x`:

```
e^(k·x) = ∑ (від n=0 до ∞) ((k·x)ⁿ / n!) = ∑ (від n=0 до ∞) (kⁿ · xⁿ / n!)   [розклад e^(k·x) у степеневий ряд]
```

Підставимо цей розклад у попереднє вираження та зміниємо порядок підсумовування (це дозволено за теоремою Фубіні завдяки абсолютній збіжності рядів):

```
B(x)
= e⁻¹ · ∑ (від k=0 до ∞) (1 / k!) · [ ∑ (від n=0 до ∞) (kⁿ · xⁿ / n!) ]
= ∑ (від n=0 до ∞) [ (1 / e) · ∑ (від k=0 до ∞) (kⁿ / k!) ] · (xⁿ / n!)   [перегрупування доданків за степенями xⁿ / n!]
```

З іншого боку, за означенням експоненціальної твірної функції:

```
B(x) = ∑ (від n=0 до ∞) B_n · (xⁿ / n!)   [означення експоненціальної твірної функції]
```

Зіставляючи коефіцієнти при однакових степенях `xⁿ / n!` в обох рядах, негайно отримуємо формулу Добінського `B_n = (1 / e) · ∑ (від k=0 до ∞) (kⁿ / k!)`.

## 3. Імовірнісне доведення через моменти розподілу Пуассона

Третій спосіб осмислення формули Добінського дає теорія ймовірностей. 

Нехай випадкова величина `X` має розподіл Пуассона з параметром інтенсивності `λ = 1`. Ймовірність того, що `X` набуде дискретного значення `k ∈ {0, 1, 2, …}`, дорівнює:

```
P(X = k) = (1ᵏ · e⁻¹) / k! = e⁻¹ / k!   [функція маси ймовірності Пуассона з λ = 1]
```

За означенням математичного сподівання, `n`-й початковий момент випадкової величини `X` обчислюється як:

```
E[Xⁿ] = ∑ (від k=0 до ∞) kⁿ · P(X = k) = ∑ (від k=0 до ∞) kⁿ · (e⁻¹ / k!) = (1 / e) · ∑ (від k=0 до ∞) (kⁿ / k!)
```

Порівнюючи це з формулою Добінського, отримуємо фундаментальний імовірнісний факт: **`n`-е число Белла `B_n` дорівнює `n`-му початковому моменту пуассонівської випадкової величини з параметром `λ = 1`**.

Моментогенеруюча функція `M_X(t)` для пуассонівської випадкової величини з `λ = 1` дорівнює:

```
M_X(t) = E[e^(t·X)] = exp(1 · (eᵗ − 1)) = e^(eᵗ − 1)
```

Оскільки моментогенеруюча функція випадкової величини `X` тотожно збігається з експоненціальною твірною функцією чисел Белла `B(t)`, її `n`-та похідна у точці `t = 0` строго дорівнює `E[Xⁿ] = B_n`.

## 4. Строге виведення модульного порівняння Тушара

Порівняння Тушара (Жак Тушар, 1939) встановлює фундаментальну арифметичну рекурентність чисел Белла за модулем довільного простого числа `p`:

```
B_{n+p} ≡ B_{n+1} + B_n (mod p)
```

### Крок 1. Застосування Малої теореми Ферма до формули Добінського

За Малою теоремою Ферма, для будь-якого простого числа `p` та довільного цілого `k` виконується порівняння:

```
kᵖ ≡ k (mod p)   [Мала теорема Ферма для простого p]
```

Помножимо обидві частини цього порівняння на `kⁿ`:

```
kⁿ⁺ᵖ = kⁿ · kᵖ ≡ kⁿ · k = kⁿ⁺¹ (mod p)   [множення на kⁿ]
```

Це означає, що для кожного цілого `k ≥ 0` різниця `kⁿ⁺ᵖ − kⁿ⁺¹` є кратною `p`, тобто `kⁿ⁺ᵖ − kⁿ⁺¹ = p · m_k` для деякого цілого `m_k`.

### Крок 2. Перетворення чисельного ряду для B_{n+p}

Запишемо формулу Добінського для `(n + p)`-го числа Белла `B_{n+p}`:

```
B_{n+p} = (1 / e) · ∑ (від k=0 до ∞) (kⁿ⁺ᵖ / k!)   [застосування формули Добінського для n + p]
```

Використовуючи алгебраїчну тотожність `kⁿ⁺ᵖ = (kⁿ⁺ᵖ − kⁿ⁺¹ − kⁿ) + kⁿ⁺¹ + kⁿ`, розіб'ємо суму на три частини за лінійністю:

```
e · B_{n+p}
= ∑ (від k=0 до ∞) (kⁿ⁺ᵖ / k!)                                                                   [домноження формули Добінського для B_{n+p} на e]
= ∑ (від k=0 до ∞) ((kⁿ⁺ᵖ − kⁿ⁺¹ − kⁿ) / k!) + ∑ (від k=0 до ∞) (kⁿ⁺¹ / k!) + ∑ (від k=0 до ∞) (kⁿ / k!)   [розклад чисельника kⁿ⁺ᵖ на доданки за лінійністю суми]
```

Зауважимо, що за формулою Добінського друге та третє доданки дорівнюють відповідно `e · B_{n+1}` та `e · B_n`:

```
e · B_{n+p} = ∑ (від k=0 до ∞) ((kⁿ⁺ᵖ − kⁿ⁺¹ − kⁿ) / k!) + e · B_{n+1} + e · B_n
```

### Крок 3. Подільність першої суми на p та завершення доведення

Розглянемо першу суму `S = ∑ (від k=0 до ∞) ((kⁿ⁺ᵖ − kⁿ⁺¹ − kⁿ) / k!)`. Завдяки тотожності `kⁿ⁺ᵖ − kⁿ⁺¹ ≡ 0 (mod p)` у кільці p-адичних цілих чисел ця сума дорівнює `p · E`, де `E` — ціле p-адичне число.

Поділивши обидві частини рівняння на `e`:

```
B_{n+p} − B_{n+1} − B_n = (1 / e) · ∑ (від k=0 до ∞) ((kⁿ⁺ᵖ − kⁿ⁺¹ − kⁿ) / k!)
```

Оскільки ліва частина є різницею цілих чисел, вона мусить бути цілим числом. А оскільки кожна терма чисельника кратне `p`, сама різниця ділиться на `p`:

```
B_{n+p} − B_{n+1} − B_n ≡ 0 (mod p)
```

Отже:

```
B_{n+p} ≡ B_{n+1} + B_n (mod p)
```

Це повністю завершує строге алгебраїчне доведення порівняння Тушара.

## 5. Доведення теореми Радемахера-Левіна про довжину періоду

З порівняння Тушара випливає, що послідовність остач `(B_n mod p)` утворює однорідну лінійну рекурентну послідовність порядку `p` над скінченним полем `F_p = Z/pZ`.

Характеристичний многочлен цієї рекурентності має вигляд:

```
P(x) = xᵖ − x − 1 ∈ F_p[x]   [характеристичний многочлен рекурентності Тушара]
```

За властивостями скінченних полів, багаточлен `P(x) = xᵖ − x − 1` є неприводним над `F_p` для будь-якого простого `p`. Усі його корені лежать у розширенні поля `F_{pᵖ}` степеня `p`.

Оскільки мультиплікативна група розширення `F_{pᵖ}*` має порядок `pᵖ − 1`, порядок будь-якого кореня характеристичного многочлена ділить `pᵖ − 1`. Більше того, оскільки корені задовольняють `αᵖ = α + 1`, маємо `α^((pᵖ − 1)/(p − 1)) = 1` у полі `F_{pᵖ}`.

Отже, найменший період `N_p` послідовності чисел Белла за модулем `p` строго ділить число:

```
N_p | ((pᵖ − 1) / (p − 1))
```

Це доводить теорему Радемахера-Левіна про межу довжини періоду чисел Белла за модулем простого числа `p`.
