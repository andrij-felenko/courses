# 🧮 Математичний апарат дерева Фенвіка та алгебра побітових інтервалів

Математичний фундамент дерева Фенвіка спирається на двоїсте двовимірне розбиття цілочисельного інтервалу `(0, N]` за допомогою двійкового представлення позиційних індексів. Цей апарат дозволяє перетворити лінійне накопичення сум на алгебру ортогональних двійкових відрізків, де кожна префіксна сума обчислюється як диз'юнктне об'єднання не більше ніж `log_2(N)` двоічних півінтервалів. У цьому розділі наведено строге математичне виведення властивостей функції LSB, аналіз ієрархічної топології дерева, алгебраїчну двоїстість різницевих розкладів для операцій на відрізках та геометричне узагальнення на багатовимірні простори.

### 1. Двійкове розкладання та строге доведення властивостей LSB

Нехай `i` — додатне ціле число, яке задає 1-індексовану позицію елемента у послідовності (`1 ≤ i ≤ N`). Представимо число `i` у двійковій системі числення у вигляді послідовності бітів:

```
i = (b_k b_{k-1} ... b_1 b_0)_2 = ∑_{m=0}^k b_m · 2^m,  де b_m ∈ {0, 1}
```

Наймолодшим встановленим бітом (Least Significant Bit, або **LSB**) називають позицію наймолодшої одиниці у двійковому записі числа `i`. Формально це число `2^r`, де `r` — найменший цілочисельний індекс біта, для якого `b_r = 1`. Тобто `b_r = 1`, а для всіх `m < r` виконується `b_m = 0`.

Формально математична функція `LSB(i)` визначається виразом:

```
LSB(i) = 2^{min { m | b_m = 1 }}
```

У комп'ютерній арифметиці із використанням доповняльного коду (Two's Complement) від'ємне ціле число `-i` отримують шляхом побітового заперечення всіх бітів числа `i` (операція Logical NOT, позначається `~i`) з наступним додаванням арифметичної одиниці:

```
-i = (~i) + 1
```

Проаналізуємо структуру бітів числа `-i` детальніше. Нехай двійковий запис числа `i` має вигляд:

```
i = (b_k ... b_{r+1} 1 0 0 ... 0)_2
```

Тоді побітове заперечення `~i` інвертує кожен біт незалежно:

```
~i = (b̄_k ... b̄_{r+1} 0 1 1 ... 1)_2
```

При додаванні одиниці до `~i` відбувається каскадний перенос (carry-over) через усі молодші `1`-біти. Перша ж одиниця додається до наймолодшого біта, перетворюючи послідовність молодших одиниць `1 1 ... 1` на нулі `0 0 ... 0`, а біт у позиції `r` (який був `0` після заперечення) приймає значення `1`. При цьому всі старші біти `m > r` залишаються без змін у своєму інвертованому стані `b̄_m`:

```
-i = (~i) + 1 = (b̄_k ... b̄_{r+1} 1 0 0 ... 0)_2
```

Тепер обчислимо побітове logical AND між початковим числом `i` та його від'ємним представленням `-i`:

1. Для всіх старших бітів `m > r` значення біта дорівнює `b_m & b̄_m = 0` за законом виключеного третього у булевій алгебрі.
2. Для позиції `r` значення біта дорівнює `1 & 1 = 1`.
3. Для всіх молодших бітів `m < r` значення біта дорівнює `0 & 0 = 0`.

Зведемо результати побітового І у підсумковий вираз:

```
i         = (b_k ... b_{r+1}  1  0  0 ... 0)_2        [двійковий запис числа i з наймолодшою 1 у позиції r]
~i        = (b̄_k ... b̄_{r+1}  0  1  1 ... 1)_2        [побітове заперечення: інверсія всіх бітів]
-i        = (~i) + 1                                  [доповняльний код від'ємного числа]
          = (b̄_k ... b̄_{r+1}  1  0  0 ... 0)_2        [перенос одиниці через молодші 1-біти]

i & (-i)  = (b_k & b̄_k ...  1&1  0&0 ... 0&0)_2      [побітове І між i та -i]
          = (0   ... 0       1    0   ... 0)_2        [b_m & b̄_m = 0 для всіх m > r, 0 & 0 = 0 для m < r]
          = 2^r = LSB(i)                              [наймолодший встановлений біт 2^r]
```

Отже, доведено, що для будь-якого цілого `i > 0` побітова операція `i & (-i)` виділяє наймолодший одиничний біт `LSB(i)` за один такт процесора ALU без жодних додаткових операцій чи розгалужень.

### 2. Покриття півінтервалів та ієрархічна топологія дерева

Кожен елемент `T[i]` масиву дерева Фенвіка зберігає суму елементів вихідної послідовності `A` на лівовідкритому півінтервалі цілих чисел:

```
T[i] = ∑_{k = i - LSB(i) + 1}^i A[k] = Sum(A(i - LSB(i), i])
```

Довжина півінтервалу строго дорівнює величині `LSB(i) = 2^r`. Проаналізуємо структури покриття для різних позицій `i`:

- Якщо `i` — непарне число, то `r = 0` і `LSB(i) = 1`. Вузол `T[i]` зберігає суму лише одного елемента `A[i]`.
- Якщо `i` ділиться на `2`, але не ділиться на `4` (наприклад, `i = 2, 6, 10`), то `LSB(i) = 2`. Вузол `T[i]` покриває відрізок з двох елементів `A[i-1] + A[i]`.
- Якщо `i` ділиться на `4`, але не ділиться на `8` (наприклад, `i = 4, 12, 20`), то `LSB(i) = 4`. Вузол `T[i]` покриває суму 4 елементів `A[i-3] + ... + A[i]`.
- Якщо `i = 2^m` (чиста степінь двійки), то `LSB(i) = i`. Вузол `T[i]` відповідає префіксній сумі всього масиву від `A[1]` до `A[i]`.

#### Алгебра обходу при обчисленні префіксної суми

Для обчислення префіксної суми `Pref(i) = A[1] + A[2] + ... + A[i]` цілочисельний інтервал `(0, i]` розкладається у диз'юнктне об'єднання неперетинних двоічних півінтервалів:

```
(0, i] = (i_1 - LSB(i_1), i_1] ∪ (i_2 - LSB(i_2), i_2] ∪ ... ∪ (0, i_m]
```

Перехід від поточного індексу `i_k` до наступного `i_{k+1}` здійснюється відніманням наймолодшого біта:

```
i_{k+1} = i_k − LSB(i_k) = i_k − (i_k & (-i_k))
```

З алгебраїчної точки зору, віднімання `LSB(i)` послідовно скидає наймолодший встановлений біт числа `i` в нуль. Кількість кроків до повного обнулення `i = 0` строго дорівнює кількості одиничних бітів у двійковому записі числа `i` — вазі Геммінга `popcount(i)`.

Оскільки двійковий запис будь-якого числа `i ≤ N` містить не більше ніж `⌊log_2 N⌋ + 1` одиничних бітів, кількість доданок у префіксній сумі строго обмежена логарифмічною величиною `O(log N)`.

#### Алгебра обходу при точковому оновленні

При зміні значення елемента `A[i]` на величину `v` (операція `A[i] += v`) необхідно оновити всі вузли `T[j]`, півінтервали яких покривають позицію `i`.

Формальною умовою того, що інтервал `(j - LSB(j), j]` містить елемент `i`, є виконання подвійної нерівності:

```
j − LSB(j) < i ≤ j
```

Мінімальним індексом `j`, який задовольняє цю умову для позиції `i`, є сам індекс `j = i`. Наступний за старшинством вузол, що перекриває цей інтервал, отримують додаванням наймолодшого біта:

```
j_{next} = j + LSB(j) = j + (j & (-j))
```

Додавання `LSB(j)` викликає перенос одиниці у старші розряди, збільшуючи загальний охоплюваний інтервал. Процес обходу продовжується доти, доки `j` не перевищить розмір масиву `N`. Довжина цього шляху підйому до батьківських вузлів також строго обмежена величиною `O(log N)`.

### 3. Двоїстість операцій та двохмасивний розклад для інтервалів

Завдяки лінійності оператора сумування, дерево Фенвіка дозволяє виконувати інтервальні оновлення та інтервальні запити через двоїсті алгебраїчні перетворення.

#### Інтервальне оновлення та точковий запит (Range Update, Point Query)

Розглянемо різницевий масив `D[i] = A[i] − A[i-1]` (при цьому вважаємо `A[0] = 0`). Тоді сам елемент `A[i]` дорівнює префіксній сумі різницевого масиву:

```
A[i] = ∑_{k=1}^i D[k]
```

Оновлення відрізка `A[l..r] += v` вимагає модифікації лише двох елементів масиву `D`:
- `D[l] += v` (збільшує всі наступні префіксні суми від `l` до `N`).
- `D[r + 1] -= v` (компенсує зміну для всіх префіксних сум від `r + 1` до `N`).

Якщо зберігати масив `D` у дереві Фенвіка `T_D`, то:
- Оновлення відрізка виконується як дві точкові модифікації: `T_D.Add(l, v)` та `T_D.Add(r + 1, -v)`.
- Точковий запит значення `A[i]` виконується як обчислення префіксної суми: `T_D.Query(i)`.

#### Інтервальне оновлення та інтервальний запит (Range Update, Range Query)

Виведемо алгебраїчну формулу для префіксної суми `Pref_A(p) = ∑_{i=1}^p A[i]` через елементи різницевого масиву `D`:

```
Pref_A(p) = ∑_{i=1}^p A[i] 
          = ∑_{i=1}^p ( ∑_{j=1}^i D[j] )
```

Змінимо порядок підсумовування у подвійній сумі. Кожен елемент `D[j]` входить у загальну суму стільки разів, скільки індексів `i` задовольняють умову `j ≤ i ≤ p`. Кількість таких індексів строго дорівнює `p - j + 1`.

Розкриємо та розгрупуємо цей вираз:

```
Pref_A(p) = ∑_{j=1}^p D[j] · (p − j + 1)
          = ∑_{j=1}^p D[j] · (p + 1)  −  ∑_{j=1}^p D[j] · (j − 1)
          = (p + 1) · ∑_{j=1}^p D[j]  −  ∑_{j=1}^p D[j] · (j − 1)
```

Для підтримки цієї формули вимагаються два окремі дерева Фенвіка:
1. Дерево `T_1`, яке зберігає чисто різницеві значення `D[j]`.
2. Дерево `T_2`, яке зберігає зважені значення `D[j] · (j − 1)`.

При оновленні відрізка `A[l..r] += v`:
- У дерево `T_1` додаємо: `T_1.Add(l, v)` та `T_1.Add(r + 1, -v)`.
- У дерево `T_2` додаємо: `T_2.Add(l, v · (l − 1))` та `T_2.Add(r + 1, -v · r)`.

Тоді обчислення суми префікса `Pref_A(p)` розраховується за логарифмічний час:

```
Pref_A(p) = (p + 1) · T_1.Query(p) − T_2.Query(p)
```

Сума на довільному відрізку `A[l..r]` обчислюється як різниця двох префіксних сум: `Pref_A(r) − Pref_A(l - 1)`.

### 4. Двовимірне дерево Фенвіка (2D Fenwick Tree)

Для двовимірної матриці `A[1..N][1..M]` двовимірне дерево Фенвіка `T[i][j]` зберігає суму елементів у прямокутній області:

```
T[i][j] = ∑_{x = i - LSB(i) + 1}^i  ∑_{y = j - LSB(j) + 1}^j  A[x][y]
```

Обхід здійснюється за допомогою двох вкладених циклів по індексах `i` та `j`. 

Точкове оновлення `A[x][y] += v` піднімається по обидвох координатах:

```
для i = x; i ≤ N; i += LSB(i):
    для j = y; j ≤ M; j += LSB(j):
        T[i][j] += v
```

Обчислення префіксної суми прямокутника від `(1,1)` до `(x,y)` згортається по двох координатах:

```
Pref2D(x, y) = ∑_{i=x; i>0; i-=LSB(i)}  ∑_{j=y; j>0; j-=LSB(j)}  T[i][j]
```

За принципом включень-виключень, сума елементів у довільному прямокутнику з протилежними кутами `(r1, c1)` та `(r2, c2)` дорівнює:

```
Sum2D(r1, c1, r2, c2) = Pref2D(r2, c2) − Pref2D(r1 - 1, c2) − Pref2D(r2, c1 - 1) + Pref2D(r1 - 1, c1 - 1)
```

Часова складність точкового оновлення та прямокутного запиту у 2D дереві Фенвіка складає `O(log N · log M)`.
