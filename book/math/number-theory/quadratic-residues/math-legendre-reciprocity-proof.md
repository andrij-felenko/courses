# 🧮 Виведення критерію Ейлера, леми Ґаусса та закону квадратичної взаємності

Ця математична вставка містить строгі алгебраїчні та геометричні доведення фундаментальних теорем про квадратичні лишки: критерію Ейлера, леми Ґаусса, геометричного доведення закону взаємності Айзенштайна, геометрії сум Ґаусса, а також розширення на символ Якобі та Кронекера з деталізованими покроковими прикладами обчислень.

### 1. Критерій Ейлера та структура квадратичного гомоморфізму

Нехай `p` — непарне просте число, а `a` — ціле число, взаємно просте з `p` (тобто `a ≢ 0 mod p`). Критерій Ейлера є головним алгебраїчним інструментом, який дозволяє визначити, чи існує розв'язок порівняння `x² ≡ a (mod p)`, без прямого перебору коренів.

**Теорема (Критерій Ейлера).** Число `a` є квадратичним лишком за модулем `p` тоді й лише тоді, коли:

```
a^((p-1)/2) ≡ 1 (mod p)
```

Якщо ж `a` є квадратичним нелишком за модулем `p`, то виконується порівняння:

```
a^((p-1)/2) ≡ -1 (mod p)
```

#### Доведення

З Малої теореми Ферма відомо, що для будь-якого елемента `a ≢ 0 (mod p)` виконується тотожність `a^(p-1) ≡ 1 (mod p)`. Скориставшись формулою різниці квадратів, ми можемо розкласти цей вираз на множники у полі залишків `ℤₚ`:

```
a^(p-1) - 1 = (a^((p-1)/2) - 1) · (a^((p-1)/2) + 1) ≡ 0 (mod p)    [різниця квадратів для x = a^((p-1)/2)]
```

Оскільки поле залишків `ℤₚ` (де `p` — просте число) є цілісним кільцем і не містить дільників нуля, добуток двох виразів може дорівнювати нулю за модулем `p` лише тоді, коли принаймні один із множників ділиться на `p`. Це означає, що для будь-якого `a` значення `a^((p-1)/2)` за модулем `p` може дорівнювати лише `1` або `-1` (що еквівалентно `p - 1`).

**Випадок 1: Доведення для квадратичних лишків.**
За означенням квадратичного лишку, існує таке ціле число `x`, що `x² ≡ a (mod p)`. Підставимо цей квадрат у наш вираз:

```
a^((p-1)/2) ≡ (x²)^((p-1)/2)      [підстановка a ≡ x² mod p]
            ≡ x^(p-1)             [за правилом піднесення степеня до степеня]
            ≡ 1 (mod p)           [за Малою теоремою Ферма для x]
```

Отже, для кожного квадратичного лишку `a` значення `a^((p-1)/2)` тотожно дорівнює `1 (mod p)`.

**Випадок 2: Доведення для нелишків та єдиність розв'язків.**
Розглянемо многочлен `f(x) = x^((p-1)/2) - 1` над полем `ℤₚ`. За теоремою Лагранжа про корені многочлена над полем, дане рівняння степеня `(p-1)/2` може мати не більше ніж `(p-1)/2` різних коренів у полі `ℤₚ`.

З іншого боку, згортальне відображення піднесення до квадрата `x ↦ x² mod p` показує, що у непарній мультиплікативній групі `ℤₚ*` існує рівно `(p-1)/2` квадратичних лишків (оскільки пари `x` та `p - x` дають однаковий квадрат). Оскільки всі ці `(p-1)/2` лишків вже виявилися коренями многочлена `x^((p-1)/2) - 1 ≡ 0 (mod p)`, жоден із решти `(p-1)/2` квадратичних нелишків не може задовольняти це порівняння.

Оскільки значення `a^((p-1)/2) mod p` має дорівнювати `1` або `-1`, а для нелишків воно не може дорівнювати `1`, робимо висновок: для всіх квадратичних нелишків значення `a^((p-1)/2)` мусить дорівнювати `-1 (mod p)`.

#### Алгебраїчний гомоморфізм

Критерій Ейлера показує, що відображення `f: ℤₚ* → {+1, -1}`, визначене формулою `f(a) = a^((p-1)/2) mod p`, є гомоморфізмом груп. Ядром цього гомоморфізму `Ker(f)` є підгрупа квадратичних лишків `QRₚ`. За теоремою про ізоморфізми класів, фактор-група `ℤₚ* / QRₚ` є циклічною групою порядку 2, що пояснює тотожні правила множення лишків та нелишків:

```
(a·b / p) = (a/p) · (b/p)
```

Критерій Ейлера повністю доведено. █

### 2. Лема Ґаусса та підрахунок знаків

Лема Ґаусса надає елегантний комбінаторний спосіб обчислення символу Лежандра `(a/p)` через підрахунок кількості лишків, які після множення на `a` потрапляють у верхній інтервал `(p/2, p)`.

Нехай `p` — непарне просте число, `a ≢ 0 (mod p)`. Розглянемо множину з `(p-1)/2` цілих чисел:

```
S = { a, 2a, 3a, …, ((p-1)/2)·a }
```

Зведемо кожний елемент цієї множини до найменшого додатного залишку при діленні на `p`. Нехай `μ` — кількість елементів множини `S`, чиї залишки перевищують `p/2` (тобто лежать у проміжку `(p/2, p)`).

**Лема Ґаусса.** Символ Лежандра дорівнює:

```
(a/p) = (-1)^μ
```

#### Доведення

Позначимо через `r₁, r₂, …, r_μ` ті залишки ділення елементів `S` на `p`, які строго більші за `p/2`, а через `s₁, s₂, …, s_ν` — ті залишки, які менші за `p/2`. Загальна кількість елементів у двох множинах дорівнює `μ + ν = (p-1)/2`.

Розглянемо додатні числа `p - r₁, p - r₂, …, p - r_μ`. Усі вони за визначенням лежать у межах інтервалу `(0, p/2)`.

Покажемо, що множина `{ p - r₁, …, p - r_μ, s₁, …, s_ν }` точно збігається з множиною послідовних цілих чисел `{ 1, 2, …, (p-1)/2 }`.

1. Усі елементи даної множини є додатними й не перевищують `(p-1)/2`.
2. Загальна кількість елементів дорівнює `μ + ν = (p-1)/2`.
3. Жодні два елементи не збігаються між собою. Справді, якби `p - rᵢ = sⱼ` для деяких `i` та `j`, то ми мали б `rᵢ + sⱼ = p`. Це означало б, що `u·a + v·a ≡ 0 (mod p)` для деяких числових коефіцієнтів `1 ≤ u, v ≤ (p-1)/2`, тобто `(u + v)·a ≡ 0 (mod p)`. Проте `1 < u + v < p` та `НСД(a, p) = 1`, що створює суперечність з простістю `p`.

Перемножимо всі елементи об'єднаної множини:

```
(p - r₁) · (p - r₂) ··· (p - r_μ) · s₁ · s₂ ··· s_ν ≡ 1 · 2 ··· ((p-1)/2) (mod p)
```

З іншого боку, за модулем `p` маємо порівняння `p - rᵢ ≡ -rᵢ (mod p)`. Підставимо це значення у добуток:

```
(-r₁) · (-r₂) ··· (-r_μ) · s₁ · s₂ ··· s_ν ≡ (-1)^μ · (r₁ ··· r_μ · s₁ ··· s_ν) (mod p)
```

Але добуток усіх залишків `r₁ ··· r_μ · s₁ ··· s_ν` за визначенням дорівнює добутку вихідних елементів множини `S = {a, 2a, …, ((p-1)/2)a}`:

```
r₁ ··· r_μ · s₁ ··· s_ν ≡ a · (2a) · (3a) ··· (((p-1)/2)a)
                       ≡ a^((p-1)/2) · ((p-1)/2)! (mod p)
```

Підставивши цей вираз у загальне порівняння, маємо:

```
(-1)^μ · a^((p-1)/2) · ((p-1)/2)! ≡ ((p-1)/2)! (mod p)
```

Оскільки факторіал `((p-1)/2)!` складається з множників, менших за `p`, він є взаємно простим із `p`. Скоротивши обидві частини порівняння на цей факторіал, отримуємо:

```
(-1)^μ · a^((p-1)/2) ≡ 1 (mod p)
```

Помноживши обидві частини на `(-1)^μ` та застосувавши критерій Ейлера `a^((p-1)/2) ≡ (a/p) (mod p)`, знаходимо:

```
(a/p) ≡ (-1)^μ (mod p)
```

Оскільки обидві частини рівності можуть набувати лише значень `+1` або `-1`, порівняння за модулем непарного простого `p ≥ 3` перетворюється на точну цілочисельну рівність `(a/p) = (-1)^μ`. █

#### Числові приклади обчислення за лемою Ґаусса

**Приклад 1: Обчислення (3/11).**
- Маємо `p = 11`, `a = 3`, `(p-1)/2 = 5`.
- Формуємо множину `S = { 1·3, 2·3, 3·3, 4·3, 5·3 } = { 3, 6, 9, 12, 15 }`.
- Знаходимо залишки за модулем 11:
  - `3 mod 11 = 3` (менше за 11/2 = 5.5)
  - `6 mod 11 = 6` (більше за 5.5)
  - `9 mod 11 = 9` (більше за 5.5)
  - `12 mod 11 = 1` (менше за 5.5)
  - `15 mod 11 = 4` (менше за 5.5)
- Залишки, що перевищують `p/2 = 5.5`: це `{ 6, 9 }`.
- Кількість таких залишків `μ = 2`.
- Отже, `(3/11) = (-1)² = 1`. Число 3 є квадратичним лишком за модулем 11 (справді, `5² ≡ 25 ≡ 3 mod 11`).

**Приклад 2: Обчислення (5/13).**
- Маємо `p = 13`, `a = 5`, `(p-1)/2 = 6`.
- Формуємо множину `S = { 5, 10, 15, 20, 25, 30 }`.
- Знаходимо залишки за модулем 13:
  - `5 mod 13 = 5` (менше за 13/2 = 6.5)
  - `10 mod 13 = 10` (більше за 6.5)
  - `15 mod 13 = 2` (менше за 6.5)
  - `20 mod 13 = 7` (більше за 6.5)
  - `25 mod 13 = 12` (більше за 6.5)
  - `30 mod 13 = 4` (менше за 6.5)
- Залишки, що перевищують 6.5: це `{ 10, 7, 12 }`.
- Кількість таких залишків `μ = 3`.
- Отже, `(5/13) = (-1)³ = -1`. Число 5 є квадратичним нелишком за модулем 13.

### 3. Перший та другий доповняльні закони

З критерію Ейлера та леми Ґаусса випливають точні формули для знаків символів `(-1/p)` та `(2/p)`.

#### Доповняльний закон для -1

```
(-1/p) = (-1)^((p-1)/2)
```

Це значення безпосередньо випливає з критерію Ейлера підстановкою `a = -1`:
- Якщо `p ≡ 1 (mod 4)`, то `(p-1)/2` є парним числом, тому `(-1/p) = 1`.
- Якщо `p ≡ 3 (mod 4)`, то `(p-1)/2` є непарним числом, тому `(-1/p) = -1`.

#### Доповняльний закон для 2

```
(2/p) = (-1)^((p²-1)/8)
```

#### Доведення через лему Ґаусса

Застосуємо лему Ґаусса для `a = 2`. Множина `S` має вигляд:

```
S = { 2·1, 2·2, 2·3, …, 2·((p-1)/2) }
```

Усі елементи цієї множини лежать у проміжку від `2` до `p - 1`. Нам потрібно обчислити кількість елементів `μ`, які перевищують `p/2`.

Умова `2·k > p/2` еквівалентна нерівності `k > p/4`.
Отже, індекс `k` змінюється в межах `⌊p/4⌋ < k ≤ (p-1)/2`.
Кількість таких елементів дорівнює різниці меж:

```
μ = ((p-1)/2) - ⌊p/4⌋
```

Розглянемо чотири можливі класи лишків для непарного простого `p` за модулем 8:
1. `p = 8k + 1`: `μ = 4k - 2k = 2k` (парне число) `⇒ (2/p) = 1`
2. `p = 8k + 3`: `μ = (4k + 1) - k = 3k + 1` (непарне при парному k) `⇒ (2/p) = -1`
3. `p = 8k + 5`: `μ = (4k + 2) - (k + 1) = 3k + 1` `⇒ (2/p) = -1`
4. `p = 8k + 7`: `μ = (4k + 3) - (2k + 1) = 2k + 2` (парне число) `⇒ (2/p) = 1`

Перевіривши значення квадратичного виразу `(p² - 1)/8 mod 2`, легко переконатися, що він тотожно дає парне значення при `p ≡ 1, 7 (mod 8)` та непарне значення при `p ≡ 3, 5 (mod 8)`.

Отже, формула `(2/p) = (-1)^((p²-1)/8)` доведена повністю. █

### 4. Геометричне доведення Айзенштайна для закону квадратичної взаємності

Нехай `p` та `q` — два різних непарних простих числа.

**Теорема (Закон квадратичної взаємності Ґаусса).**

```
(p/q) · (q/p) = (-1)^(((p-1)/2) · ((q-1)/2))
```

#### Доведення Айзенштайна

Розглянемо прямокутник на двовимірній декартовій площині `(x, y)` з вершинами у точках `(0, 0)`, `(p/2, 0)`, `(p/2, q/2)`, `(0, q/2)`.

Усередині цього прямокутника розглянемо двовимірну сітку цілочисельних точок `(x, y)`, координати яких задовольняють нерівності:

```
1 ≤ x ≤ (p-1)/2,    1 ≤ y ≤ (q-1)/2
```

Загальна кількість цілочисельних точок у даній сітці строго дорівнює добутку її геометричних розмірів:

```
N = ((p-1)/2) · ((q-1)/2)
```

Провівши пучок прямих і зокрема діагональ `y = (q/p) · x` з початку координат `(0, 0)` до верхнього кута `(p/2, q/2)`, ми розіб'ємо прямокутник на два трикутники.

Звернемо увагу: жодна цілочисельна точка решітки не може лежати на самій діагоналі `y = (q/p) · x`. Справді, якщо `y = (q/p) · x`, то виконується рівність `p·y = q·x`. Оскільки `p` та `q` є різними простими числами (`НСД(p, q) = 1`), число `p` мусило б ділити `x`. Проте це неможливо, оскільки за умовою `1 ≤ x ≤ (p-1)/2 < p`.

Отже, діагональна лінія чітко розбиває множину `N` точок на дві неперетинні частини:

1. **Множина точок нижче діагоналі (`y < (q/p)·x` або `p·y < q·x`):**
Для кожного фіксованого значення `x` (від `1` до `(p-1)/2`) координата `y` може набувати цілих значень від `1` до `⌊q·x / p⌋`.
Сумуючи по всіх `x`, отримуємо кількість точок у нижньому трикутнику:

```
μ₁ = ∑_{x=1}^((p-1)/2) ⌊ (q·x) / p ⌋
```

2. **Множина точок вище діагоналі (`y > (q/p)·x` або `p·y > q·x`):**
Міняючи ролями координати `x` та `y`, аналогічно отримуємо, що для кожного фіксованого `y` (від `1` до `(q-1)/2`) кількість відповідних значень `x` дорівнює `⌊p·y / q⌋`.
Сумуючи по всіх `y`, маємо кількість точок у верхньому трикутнику:

```
μ₂ = ∑_{y=1}^((q-1)/2) ⌊ (p·y) / q ⌋
```

Оскільки кожна з `N` точок решітки потрапляє або в нижній, або у верхній трикутник, сума точок строго дорівнює площі сітки:

```
μ₁ + μ₂ = ((p-1)/2) · ((q-1)/2)
```

З іншого боку, узагальнюючи лему Ґаусса за допомогою підсумкового аналізу Айзенштайна, можна довести тотожності для символів Лежандра:

```
(q/p) = (-1)^μ₁,    (p/q) = (-1)^μ₂
```

Перемноживши ці два значення, отримуємо:

```
(q/p) · (p/q) = (-1)^μ₁ · (-1)^μ₂                  [підстановка значень з леми Ґаусса]
              = (-1)^(μ₁ + μ₂)                      [за властивістю додавання показників степеня]
              = (-1)^(((p-1)/2) · ((q-1)/2))        [за геометричною рівністю площі прямокутника]
```

Закон квадратичної взаємності Ґаусса повністю доведено. █

### 5. Суми Ґаусса та алгебраїчна природа символу

Четверте доведення Ґаусса використовує комплексні суми, які є аналогом перетворення Фур'є над скінченними полями.

Нехай `χ(a) = (a/p)` — квадратичний характер за модулем `p`, а `ζ = e^(2πi / p)` — примітивний корінь `p`-го степеня з одиниці в комплексному полі `ℂ`.

**Означення.** Сумою Ґаусса називається комплексне число:

```
G(χ) = ∑_{x=1}^{p-1} χ(x) · ζ^x
```

#### Фундаментальна властивість квадратичної суми Ґаусса

Обчислимо квадрат модуля суми Ґаусса:

```
|G(χ)|² = G(χ) · G(χ)̄
        = ∑_{x=1}^{p-1} ∑_{y=1}^{p-1} (x/p) · (y/p) · ζ^(x - y)
```

Здійснивши заміну змінних `y ≡ t·x (mod p)`, маємо `(x/p)·(y/p) = (x/p)·(t·x/p) = (x²/p)·(t/p) = (t/p)`:

```
|G(χ)|² = ∑_{t=1}^{p-1} (t/p) · ∑_{x=1}^{p-1} ζ^(x·(1 - t))
```

Внутрішня сума `∑_{x=1}^{p-1} ζ^(x·(1 - t))` дорівнює `p - 1`, якщо `t ≡ 1 (mod p)`, і дорівнює `-1`, якщо `t ≢ 1 (mod p)`.

Підставивши ці значення, маємо:

```
|G(χ)|² = (1/p)·(p - 1) + ∑_{t=2}^{p-1} (t/p)·(-1)   [розбиття суми на t=1 та решту t]
        = (p - 1) - ∑_{t=2}^{p-1} (t/p)               [спрощення першого додатка]
        = (p - 1) - (-1)                              [бо сума всіх символів Лежандра дорівнює 0]
        = p                                           [алгебраїчне підсумовування]
```

Отже, квадрат квадратичної суми Ґаусса точно дорівнює:

```
G(χ)² = (-1)^((p-1)/2) · p
```

Це дивовижне рівняння показує, що квадратне розширення `ℚ(√p)` або `ℚ(√-p)` завжди міститься всередині циклотомічного поля `ℚ(e^(2πi/p))`. Саме ця алгебраїчна залежність є основою четвертого доведення Ґаусса та теореми Артіна.

### 6. Символ Якобі та обчислювальний алгоритм

Символ Лежандра вимагає знання факторизації знаменника `p`. У 1837 році К. Якобі узагальнив цей символ на довільні непарні додатні числа `n`.

#### Означення

Нехай `n` — непарне ціле число з канонічним розкладом на прості множники `n = p₁^e₁ · p₂^e₂ ··· pₖ^eₖ`. Для довільного цілого `a` символ Якобі `(a/n)` визначається як добуток відповідних символів Лежандра:

```
(a/n) = (a/p₁)^e₁ · (a/p₂)^e₂ ··· (a/pₖ)^eₖ
```

Якщо `НСД(a, n) > 1`, за визначенням вважається `(a/n) = 0`.

⚠️ **Важлива алгебраїчна відмінність:** Якщо символ Якобі `(a/n) = -1`, число `a` **гарантовано є квадратичним нелишком** за модулем `n`. Проте якщо `(a/n) = 1`, це **НЕ гарантує**, що `a` є квадратичним лишком! Наприклад, `(2/9) = (2/3)·(2/3) = (-1)·(-1) = 1`, але порівняння `x² ≡ 2 (mod 9)` не має жодного розв'язку.

#### Властивості символу Якобі

Символ Якобі задовольняє всі фундаментальні закони взаємності для довільних непарних додатних чисел `m` та `n`:

```
1. (a·b / n) = (a/n) · (b/n)
2. (a / m·n) = (a/m) · (a/n)
3. Якщо a ≡ b (mod n), то (a/n) = (b/n)
4. (-1 / n) = (-1)^((n-1)/2)
5. (2 / n)  = (-1)^((n²-1)/8)
6. (m / n)  = (n / m) · (-1)^(((m-1)/2) · ((n-1)/2))     [Закон взаємності Якобі]
```

#### Покроковий приклад обчислення символу Якобі

Обчислимо символ Якобі `(159 / 713)` без розкладання чисел на прості множники:

```
(159 / 713)
= (-1)^(((159-1)/2) · ((713-1)/2)) · (713 / 159)   [оскільки 159 ≡ 3 mod 4 та 713 ≡ 1 mod 4, знак +1]
= (713 / 159)                                      [спрощення множника знаку]
= (713 mod 159 / 159)                              [бо 713 = 4·159 + 77]
= (77 / 159)                                       [підстановка залишку 77]
= (-1)^(((77-1)/2) · ((159-1)/2)) · (159 / 77)     [оскільки 77 ≡ 1 mod 4, знак +1]
= (159 / 77)                                       [застосування взаємності]
= (159 mod 77 / 77)                                [бо 159 = 2·77 + 5]
= (5 / 77)                                         [підстановка залишку 5]
= (-1)^(((5-1)/2) · ((77-1)/2)) · (77 / 5)         [оскільки 5 ≡ 1 mod 4, знак +1]
= (77 / 5)                                         [застосування взаємності]
= (77 mod 5 / 5) = (2 / 5)                         [бо 77 = 15·5 + 2]
= (-1)^((5²-1)/8) = (-1)^(24/8) = (-1)³ = -1       [за доповняльним законом для 2]
```

Висновок: `(159 / 713) = -1`. Число 159 є квадратичним нелишком за модулем 713, і цей результат отримано без жодної спроби факторизувати 713!

### 7. Символ Кронекера-Лежандра та узагальнення на всі цілі числа

Для роботи у довільних числових полях та кільцях алгебраїчних цілих чисел Леопольд Кронекер (Leopold Kronecker) у 1885 році розширив символ Якобі на довільні від'ємні та парні знаменники `n ∈ ℤ`.

#### Означення символу Кронекера `(a/n)`

Нехай `n` — довільне ціле число, `n ≠ 0`. Запишемо `n` у вигляді `n = u · 2^e₀ · p₁^e₁ · p₂^e₂ ··· pₖ^eₖ`, де `u = ±1`, `pᵢ` — непарні прості числа.

Тоді символ Кронекера `(a/n)` визначається як добуток базових символів:

```
(a/n) = (a/u) · (a/2)^e₀ · (a/p₁)^e₁ ··· (a/pₖ)^eₖ
```

де значення базових компонентів задаються правилами:
1. **Для u = 1:** `(a/1) = 1`.
2. **Для u = -1:** `(a/-1) = 1`, якщо `a ≥ 0`, та `(a/-1) = -1`, якщо `a < 0`.
3. **Для компоненти 2:**
   - `(a/2) = 0`, якщо `a` парне.
   - `(a/2) = 1`, якщо `a ≡ 1` або `a ≡ 7 (mod 8)`.
   - `(a/2) = -1`, якщо `a ≡ 3` або `a ≡ 5 (mod 8)`.

Завдяки розширенню Кронекера символ `(a/n)` задовольняє закон взаємності для довільних цілих дискримінантів. Це дозволяє аналізувати розклад простих ідеалів у квадратичних полях `ℚ(√d)`, визначати класи квадратичних форм та будувати L-функції Діріхле `L(s, χ)` без жодних винятків для парних та від'ємних дискримінантів `d`.

### 8. Альтернативні алгоритми: Критерій Чиполли

Поряд із алгоритмом Тонеллі-Шенкса існує альтернативний детермінований після вибору нелишку алгоритм Чиполли (Cipolla's algorithm, 1907) для розв'язування `x² ≡ a (mod p)`.

Алгоритм підбирає таке ціле `t`, щоб вираз `ω = t² - a` виявився квадратичним нелишком за модулем `p` (тобто `((t² - a)/p) = -1`).
Оскільки `ω` не має квадратного кореня в початковому полі `𝔽ₚ`, ми переходимо до розширення поля `𝔽ₚ² = 𝔽ₚ[√ω]`, яке аналогічне розширенню комплексних чисел `ℝ[i]`.

У цьому розширеному полі квадратний корінь з `a` виражається точної тотожністю:

```
x ≡ (t + √ω)^((p+1)/2) (mod p)
```

#### Математична ідея доведення Чиполли

Сформуємо елемент `α = t + √ω` у полі `𝔽ₚ²`. Скориставшись біномом Ньютона та властивістю автоморфізму Фробеніуса `(u + v)^p ≡ u^p + v^p (mod p)`, маємо:

```
α^p = (t + √ω)^p ≡ t^p + (√ω)^p (mod p)
```

За Малою теоремою Ферма `t^p ≡ t (mod p)`. Для радикала `(√ω)^p`:

```
(√ω)^p = √ω · (√ω)^(p-1) = √ω · (ω)^((p-1)/2) ≡ √ω · (ω/p) ≡ -√ω (mod p)
```

Підставивши це значення, отримуємо `α^p ≡ t - √ω (mod p)`.
Тоді квадрат виразу `α^((p+1)/2)` дорівнює:

```
(α^((p-1)/2) · α)² = α^(p+1) = α · α^p             [за тотожністю показника степеня]
                   ≡ (t + √ω) · (t - √ω)          [підстановка елементів Фробеніуса]
                   ≡ t² - ω                        [різниця квадратів у 𝔽ₚ²]
                   ≡ t² - (t² - a)                [підстановка виразу ω = t² - a]
                   ≡ a (mod p)                     [спрощення алгебраїчної різниці]
```

Алгоритм Чиполли потребує `O(log p)` множень у розширеному полі `𝔽ₚ²`, що робить його дуже зручним для розробки криптографічних бібліотек та обчислень над скінченними полями великих характеристик. Існування двох різних підходів (Тонеллі-Шенкса через 2-групу та Чиполли через розширення полів) підкреслює глибоку алгебраїчну багаторакурсність квадратного кореня mod p.
