# 𝑞 Алгебраїчний механізм доведення Міхайлеску

Доведення теореми Міхайлеску перетворює діофантове рівняння `xᵖ - y𝑞 = 1` з ізольованого арифметичного завдання на об'єкт дослідження алгебраїчної теорії полів ділення кола `Q(ζₚ)`. Головна алгебраїчна ідея полягає у факторизації лівого боку рівняння над кільцем цілих комплексних чисел `Z[ζₚ]`, де `ζₚ = e^(2πi/p)` є первісним коренем степеня `p` з одиниці. Якщо припустити існування нетривіального розв'язку для непарних простих показників `p` та `q`, то розклад на множники вступить у нездоланну суперечність із відносними розмірами кругових одиниць, вимірністю фактор-просторів класів ідеалів та умовою подвійної подільності.

## Крок 1. Факторизація у круговому полі та аналіз НСД дужок

Записавши початкове рівняння у вигляді `xᵖ - 1 = y𝑞`, розкладемо многочлен `xᵖ - 1` на `p` лінійних множників у розширенні `Q(ζₚ)`:

```
(x - 1) · (x - ζₚ) · (x - ζₚ²) · … · (x - ζₚᵖ⁻¹) = y𝑞
```

Многочлен ділення кола `Φₚ(x) = xᵖ⁻¹ + xᵖ⁻² + … + x + 1` визначає факторизацію виразу `(xᵖ - 1)/(x - 1)`:

```
Φₚ(x) = ∏_(j=1)^(p-1) (x - ζₚʲ) = (xᵖ - 1) / (x - 1)
```

Усі співмножники `(x - ζₚʲ)` для `j = 1, 2, …, p - 1` належать до кільця цілих чисел `O_K = Z[ζₚ]`. Щоб зрозуміти, як степінь `y𝑞` розподіляється між цими дужками, необхідно з'ясувати їхню взаємну простоту в `Z[ζₚ]`.

Розглянемо різницю між двома довільними дужками для `1 ≤ i < j ≤ p - 1`:

```
(x - ζₚⁱ) - (x - ζₚʲ)
= ζₚʲ - ζₚⁱ
= ζₚⁱ · (ζₚʲ⁻ⁱ - 1)       [винесено спільний множник ζₚⁱ]
```

Оскільки `ζₚⁱ` є дільником одиниці в `Z[ζₚ]`, взаємна простота дужок залежить від елемента `(ζₚᵏ - 1)`. Відомо, що нормою елемента `(1 - ζₚ)` у полі `Q(ζₚ)` є саме просте число `p`:

```
N_(Q(ζₚ)/Q)(1 - ζₚ) = ∏_(k=1)^(p-1) (1 - ζₚᵏ) = Φₚ(1) = p
```

Отже, ідеал `mathfrak{p} = (1 - ζₚ) · Z[ζₚ]` є єдиним простим ідеалом у `Z[ζₚ]`, що лежить над числом `p`, причому `p · Z[ζₚ] = mainfrak{p}^(p-1)`. Це означає, що будь-які дві різні дужки `(x - ζₚⁱ)` та `(x - ζₚʲ)` можуть мати спільний простий ідеал лише у випадку, якщо цей ідеал ділить `mathfrak{p}`.

Якщо основа `y` не ділиться на `p`, то всі дужки `(x - ζₚʲ)` є попарно взаємно простими в `Z[ζₚ]`. Проте Джон Касселс довів, що для непарних простих показників `p` та `q` основа `y` обов'язково є кратною `p` (`p | y`), а основа `x` є кратною `q` (`q | x`).

## Крок 2. Співвідношення подільності Касселса та p-адичні показники

Доведення Касселса спирається на аналіз точних степенів `p`, які входять у множники `(x - 1)` та `Φₚ(x)`. Тотожність `xᵖ - 1 = (x - 1) Φₚ(x) = y𝑞` вимагає оцінки порядку `v_p(x - 1)`.

Оскільки `x ≡ 1 (mod p)` (бо `xᵖ ≡ x ≡ y𝑞 + 1 ≡ 1 mod p`), розкладемо `x` як `x = 1 + k · pʳ` з `gcd(k, p) = 1` та `r ≥ 1`. Тоді за формулою бінома Ньютона:

```
Φₚ(x) = ∏_(j=1)^(p-1) (1 + k · pʳ - ζₚʲ)
= p + k · pʳ · (p - 1) · p / 2 + … 
≡ p (mod p^(r+1))
```

Отже, `v_p(Φₚ(x)) = 1`. Підставивши це у рівність `v_p(x - 1) + v_p(Φₚ(x)) = v_p(y𝑞) = q · v_p(y)`, дістаємо:

```
v_p(x - 1) + 1 = q · v_p(y)
```

Звідси випливає, що `v_p(x - 1)` мусить задовольняти порівняння `v_p(x - 1) ≡ -1 (mod q)`. Оскільки `v_p(x - 1) ≥ 1`, найменшим можливим значенням є `v_p(x - 1) = q - 1`.

Це дає точні алгебраїчні формули подільності Касселса:

```
x - 1 = p^(𝑞⁻¹) · a𝑞      [де a — ціле число, не кратне p]
y + 1 = 𝑞^(ᵖ⁻¹) · bᵖ      [де b — ціле число, не кратне q]
```

Крім того, вираз `Φₚ(x)/p` ділиться на `q` у першому степені і є взаємно простим із `a`. Ці формули показують, що числа `x` та `y` не просто великі, а експоненціально зростають залежно від значень `p` та `q`.

## Крок 3. Виведення парних умов простих Віферіха

Встановлена подільність дозволяє задіяти модульну арифметику другого порядку за модулями `q²` та `p²`.

Розглянемо рівність `x - 1 = p^(q-1) a^q`. Оскільки `q | x` (за теоремою Касселса), ми маємо `x ≡ 0 (mod q)`. Дослідимо лишок `x` за вищим модулем `q²`.

Преда Міхайлеску довів, що лишок `x mod q²` дорівнює нулю: `x ≡ 0 (mod q²)`.

Підставивши `x ≡ 0 (mod q²)` у формулу Касселса, маємо:

```
x - 1 = p^(𝑞⁻¹) · a𝑞
0 - 1 ≡ p^(𝑞⁻¹) · a𝑞 (mod 𝑞²)       [підстановка x ≡ 0 mod q²]
-1 ≡ p^(𝑞⁻¹) · (-1)𝑞 (mod 𝑞²)       [оскільки a ≡ -1 mod q, a𝑞 ≡ -1 mod q²]
-1 ≡ - p^(𝑞⁻¹) (mod 𝑞²)
1 ≡ p^(𝑞⁻¹) (mod 𝑞²)
```

Це порівняння є визначенням **простого числа Віферіха** з основою `p` за модулем `q²`:

```
p^(𝑞⁻¹) ≡ 1 (mod 𝑞²)
```

Завдяки повній арифметичній симетрії початкового рівняння, яке можна переписати для другого показника як `y𝑞 + (-x)ᵖ = 1`, аналогічний розвиток для пари `(y, x)` за модулем `p²` дає протилежне порівняння:

```
𝑞^(ᵖ⁻¹) ≡ 1 (mod ᵖ²)
```

Отже, будь-яка потенційна пара непарних простих показників `(p, q)` у рівнянні Каталана зобов'язана утворювати **взаємну пару простих Віферіха**. Такі числа є надзвичайно рідкісними феноменами теорії чисел.

## Крок 4. Дія ідеалу Стікельберґера у груповому кільці Z[G]

Щоб перетворити дробові ідеали кругового поля на головні ідеали, Міхайлеску задіяв алгебраїчний апарат групи Ґалуа `G = Galois(Q(ζₚ)/Q)`. Група `G` є циклічною порядком `p - 1` і складається з автоморфізмів `σₐ: ζₚ ↦ ζₚᵃ` для `a ∈ (Z/pZ)*`.

Згідно з тотожністю `(x - 1) Φₚ(x) = y𝑞`, ідеал `(x - ζₚ) · O_K` у кільці цілих `O_K = Z[ζₚ]` після ізолювання дільника `mathfrak{p}` стає точним `q`-м степенем деякого ідеалу `𝔞`:

```
(x - ζₚ) · O_K = 𝔞𝑞
```

Це означає, що клас ідеалу `[𝔞]` у групі класів ідеалів `Cl(Q(ζₚ))` має порядок, який ділить `q`.

Двома головними інструментами для дослідження класу `[𝔞]` є **ідеал Стікельберґера** `S` та **теорема Тейна**. Елемент Стікельберґера `θ` у груповому кільці `Z[G]` визначається як:

```
θ = ∑_(a=1)^(p-1) ⟨ a / p ⟩ · σₐ⁻¹
```

де `⟨a/p⟩` — дробова частина числа `a/p`. Теорема Стікельберґера стверджує, що для будь-якого елемента `θ ∈ S` розширений ідеал `𝔞^θ` є **головним ідеалом** у `O_K`:

```
𝔞^θ = (α) · O_K      [де α ∈ Z[ζₚ]]
```

Піднісши рівність `(x - ζₚ) · O_K = 𝔞𝑞` до степеня `θ`, дістаємо співвідношення для елементів поля:

```
(x - ζₚ)^θ = u · α𝑞
```

де `u ∈ O_K*` є деякою **круговою одиницею** (cyclotomic unit) поля `Q(ζₚ)`.

## Крок 5. Алгебраїчні фактор-простори та оцінка вимірності

Отримана рівність `(x - ζₚ)^θ = u · α𝑞` зв'язує кругові одиниці `u` та алгебраїчний елемент `α`. Міхайлеску перевів це співвідношення на мову векторних просторів над скінченним полем `F_q = Z/qZ`.

Розглянемо фактор-простір `V = O_K* / (O_K*)^q` кругових одиниць за модулем `q`-х степенів. Структура `V` як модуля над груповим кільцем `F_q[G]` детально описується за допомогою теореми Тейна про анулятори класів ідеалів.

Міхайлеску розглянув підпростір `V⁻`, що відповідає непарній частині групи Ґалуа (де дія комплексно спряженого автоморфізму `σ_(-1)` еквівалентна множенню на `-1`).

Якщо припустити, що `p ≢ 1 (mod q)`, то вимірність підпростору ануляторів у `F_q[G]` виявляється суворо меншою за необхідний розмір для компенсації кругової одиниці `u`.

З іншого боку, зважена комплексна норма виразу `|(x - ζₚ)^θ|` може бути оцінена аналітично. Оскільки `x` є гігантським числом за формулами Касселса (`x > p^(q-1)`), значення `|(x - ζₚ)^θ|` зростає як поліном від `x`. Проте якщо `α` є нетривіальним алгебраїчним цілим числом, норма `|α𝑞| = |α|^q` зростає значно швидше за `|(x - ζₚ)^θ|`.

Єдиний спосіб узгодити алгебраїчну вимірність простору `V⁻` з комплексними нормами — це вимога, щоб одиниця `u` була тривіальною у `F_q[G]`. А це можливе лише за умови жорсткої ділової сумісності простих показників:

```
p ≡ 1 (mod 𝑞)
```

## Крок 6. Остаточне алгебраїчне заперечення

Останній крок доведення завершує всю будову логичним замиканням.

Оскільки вихідне діофантове рівняння `xᵖ - y𝑞 = 1` є алгебраїчно симетричним (його можна еквівалентно переписати відносно другої пари як `y𝑞 + (-x)ᵖ = 1`), уся побудована теорія для кругового поля `Q(ζ_q)` та ідеалу Стікельберґера у кільці `Z[Galois(Q(ζ_q)/Q)]` дає дзеркальний висновок для показника `q`:

```
𝑞 ≡ 1 (mod p)
```

Зберемо обидва висунуті порівняння в єдину систему для непарних простих чисел `p` та `q`:

```
p ≡ 1 (mod 𝑞)   ⇒   p = k · 𝑞 + 1   (k ≥ 1)   ⇒   p > 𝑞
𝑞 ≡ 1 (mod p)   ⇒   𝑞 = m · p + 1   (m ≥ 1)   ⇒   𝑞 > p
```

Ми отримали суперечливий ланцюг строгих нерівностей для натуральних чисел:

```
p > 𝑞   та одночасно   𝑞 > p
```

Отримане заперечення повністю унеможливлює існування розв'язків діофантова рівняння `xᵖ - y𝑞 = 1` для будь-якої пари непарних простих показників `(p, q)`.

Зважаючи на те, що всі випадки за участю парного показника 2 були повністю закриті раніше Ойлером (`x² - y³ = 1`), Лебегом (`x² - y𝑞 = 1`) та Чао Ко (`xᵖ - y² = 1`), доведення Предою Міхайлеску цієї підсумкової суперечності 2002 року остаточно завершило доведення гіпотези Каталана як теореми.
