# 🧮 Алгебра згортки Діріхле та дуальність рядів

Ця математична вставка містить строге виведення алгебраїчної теорії згортки Діріхле, доводить збереження мультиплікативності при згортці, встановлює ізоморфізм між кільцем арифметичних функцій та формальними рядами Діріхле, описує апарат степеневих рядів Белла та розбирає обчислювальні приклади обернення Мебіуса і степенів Дзета-функції.

## 1. Кільцева структура та алгебраїчні властивості

Арифметичною функцією називається будь-яке відображення `f: ℕ → ℂ`, яке кожному натуральному числу `n ∈ {1, 2, 3, ...}` ставить у відповідність комплексне число `f(n)`. Множина всіх арифметичних функцій утворює комутативне кільце відносно двох операцій: звичайного точкового додавання `(f + g)(n) = f(n) + g(n)` та **згортки Діріхле** `(f * g)(n)`.

**Визначення згортки Діріхле:** Згорткою Діріхле (англ. *Dirichlet convolution*) двох арифметичних функцій `f` та `g` називається нова арифметична функція `h = f * g`, значення якої для кожного `n ∈ ℕ` обчислюється як сума за всіма додатними дільниками `d` числа `n`:

```
(f * g)(n) = ∑_{d|n} f(d) · g(n/d) = ∑_{a · b = n} f(a) · g(b)
```

Згортка Діріхле задовольняє фундаментальні алгебраїчні закони:

1. **Комутативність:** `f * g = g * f`.
   Рівність `a · b = n` є симетричною відносно множників, тому сума `∑_{a·b=n} f(a)g(b)` не змінюється при перестановці функцій `f` та `g`.

2. **Асоціативність:** `(f * g) * h = f * (g * h)`.
   Для довільного `n` обидві частини дорівнюють сумі за всіма впорядкованими трійками натуральних чисел `(a, b, c)` такими, що `a · b · c = n`:

```
((f * g) * h)(n) = ∑_{a · b · c = n} f(a) · g(b) · h(c)
```

3. **Нейтральний елемент:** Існує функція `ε(n)` (одинична функція), визначена як:

```
ε(n) = 1,  якщо n = 1
ε(n) = 0,  якщо n > 1
```

Для будь-якої функції `f` виконується `(f * ε)(n) = f(1) · ε(n) + f(n) · ε(1) = f(n)`.

4. **Дистрибутивність відносно додавання:** `f * (g + h) = (f * g) + (f * h)`.

5. **Існування оберненого елемента:** Арифметична функція `f` має обернену відносно згортки функцію `f⁻¹` (таку, що `f * f⁻¹ = ε`) тоді й лише тоді, коли `f(1) ≠ 0`.

Значення оберненої функції `f⁻¹(n)` обчислюються за рекурентною формулою:

```
f⁻¹(1) = 1 / f(1)                                             [база рекуренсії]

f⁻¹(n) = - (1 / f(1)) · ∑_{d|n, d > 1} f(d) · f⁻¹(n/d)        [для n > 1]
```

Ця формула виводиться безпосередньо з умови `(f * f⁻¹)(n) = 0` для всіх `n > 1`:

```
∑_{d|n} f(d) · f⁻¹(n/d) = f(1) · f⁻¹(n) + ∑_{d|n, d > 1} f(d) · f⁻¹(n/d) = 0
```

Виразивши `f⁻¹(n)`, отримуємо наведену рекурентність. Множина всіх арифметичних функцій з `f(1) ≠ 0` утворює абелеву групу відносно згортки Діріхле.

## 2. Теорема про збереження мультиплікативності

Арифметична функція `f` називається **мультиплікативною**, якщо `f(1) = 1` і для будь-якої пари взаємно простих чисел `n` та `m` (тобто `НСД(n, m) = 1`) виконується тотожність `f(n · m) = f(n) · f(m)`.

**Теорема (про збереження мультиплікативності):** Якщо арифметичні функції `f` та `g` є мультиплікативними, то їхня згортка Діріхле `h = f * g` також є мультиплікативною функцією.

### Строге алгебраїчне доведення:

Нехай `n` та `m` — дві взаємно прості натуральні числа (`НСД(n, m) = 1`). Дослідимо суму для `h(n · m)`:

```
h(n · m) = ∑_{d | (n · m)} f(d) · g((n · m) / d)
```

Оскільки `НСД(n, m) = 1`, кожен дільник `d` числа `n · m` однозначно розкладається у добуток `d = d₁ · d₂`, де `d₁ | n` та `d₂ | m`, причому `НСД(d₁, d₂) = 1` та `НСД(n/d₁, m/d₂) = 1`.

Розпишемо суму через паралельні дільники `d₁` та `d₂`:

```
h(n · m) = ∑_{d₁|n} ∑_{d₂|m} f(d₁ · d₂) · g( (n/d₁) · (m/d₂) )      [розклад дільників]
         = ∑_{d₁|n} ∑_{d₂|m} f(d₁) · f(d₂) · g(n/d₁) · g(m/d₂)      [мультиплікативність f та g]
         = [ ∑_{d₁|n} f(d₁) · g(n/d₁) ] · [ ∑_{d₂|m} f(d₂) · g(m/d₂) ] [факторизація сум]
         = h(n) · h(m)                                               [за визначенням h = f * g]
```

Таким чином, згортка мультиплікативних функцій завжди є мультиплікативною функцією. Це означає, що значення згортки `(f * g)(n)` повністю визначається її поведінкою на степенях простих чисел `pᵏ`.

## 3. Ряди Белла та локальний аналіз згортки

Для глибшого алгебраїчного аналізу мультиплікативних функцій використовують **ряди Белла** (англ. *Bell series*), названі на честь математика Еріка Темпла Белла.

Нехай `f` — мультиплікативна арифметична функція, а `p` — фіксоване просте число. Рядом Белла функції `f` за простою основою `p` називається формальний степеневий ряд:

```
f_p(x) = ∑_{k=0}^∞ f(pᵏ) xᵏ = f(1) + f(p) x + f(p²) x² + f(p³) x³ + ...
```

Головна перевага рядів Белла полягає у тому, що згортка двох мультиплікативних функцій `h = f * g` локально відповідає звичайному множенню їхніх рядів Белла:

```
h_p(x) = f_p(x) · g_p(x)
```

Проілюструємо це на фундаментальних прикладах:

1. **Константна одиниця `1(n) = 1`:** Для будь-якого `p` маємо `1_p(x) = 1 + x + x² + x³ + ... = 1 / (1 - x)`.
2. **Число дільників `d = 1 * 1`:** Ряд Белла дорівнює добутку `d_p(x) = 1_p(x) · 1_p(x) = 1 / (1 - x)² = 1 + 2x + 3x² + 4x³ + ...`. Коефіцієнт при `xᵏ` дорівнює `k + 1 = d(pᵏ)`.
3. **Функція Мебіуса `μ`:** Оскільки `μ(1) = 1`, `μ(p) = -1`, а `μ(pᵏ) = 0` для `k ≥ 2`, ряд Белла є многочленом `μ_p(x) = 1 - x`. Добуток `1_p(x) · μ_p(x) = (1 / (1 - x)) · (1 - x) = 1` підтверджує тотожність `1 * μ = ε`.

## 4. Дуальність із множенням рядів Діріхле

Головне теоретичне значення рядів Діріхле полягає у точній відповідності між звичайним множенням рядів та згорткою їхніх коефіцієнтів.

**Теорема (про множення рядів Діріхле):** Нехай `F(s) = ∑_{n=1}^∞ a[n] / nˢ` та `G(s) = ∑_{m=1}^∞ b[m] / mˢ` — два ряди Діріхле, які абсолютно збігаються в деякій півплощині `Re(s) > σ₀`. Тоді їхній добуток `H(s) = F(s) · G(s)` є рядом Діріхле вигляду:

```
H(s) = ∑_{k=1}^∞ c[k] / kˢ
```

коефіцієнти якого `c[k]` дорівнюють згортці Діріхле коефіцієнтів `a` та `b`:

```
c[k] = (a * b)(k) = ∑_{d|k} a[d] · b[k/d]
```

### Виведення теореми:

Перемножимо два абсолютно збіжні ряди член за членом:

```
F(s) · G(s)
= ( ∑_{n=1}^∞ a[n] / nˢ ) · ( ∑_{m=1}^∞ b[m] / mˢ )   [розгортання визначення]
= ∑_{n=1}^∞ ∑_{m=1}^∞ (a[n] · b[m]) / (n · m)ˢ        [групування знаменників]
```

Оскільки ряд збігається абсолютно, ми маємо право згрупувати доданки за значенням добутку знаменників `k = n · m`:

```
= ∑_{k=1}^∞ [ ∑_{n · m = k} a[n] · b[m] ] / kˢ         [згрупували за k = n · m]
= ∑_{k=1}^∞ [ ∑_{d|k} a[d] · b[k/d] ] / kˢ            [заміна змінної n = d, m = k/d]
= ∑_{k=1}^∞ (a * b)(k) / kˢ                           [за визначенням згортки]
```

Отже, алгебра формальних рядів Діріхле є ізоморфною кільцю арифметичних функцій відносно згортки Діріхле.

## 5. Тотожності фундаментальних арифметичних функцій

Розглянемо найважливіші приклади згортки та їхній аналітичний вигляд через Дзета-функцію Рімана `ζ(s) = ∑_{n=1}^∞ 1 / nˢ`.

### 1. Число дільників `d(n)` та сума дільників `σ_a(n)`
Нехай `1(n) = 1` для всіх `n ∈ ℕ`. Згортка `(1 * 1)(n) = ∑_{d|n} 1 = d(n)` обчислює кількість додатних дільників числа `n`.
Відповідно до теореми про множення:

```
ζ(s) · ζ(s) = ( ∑_{n=1}^∞ 1 / nˢ )² = ∑_{n=1}^∞ d(n) / nˢ
```

Узагальнюючи, для функції степенів дільників `σ_a(n) = ∑_{d|n} dᵃ`, яка є згорткою тотожної степені `Nᵃ(n) = nᵃ` та одиниці `1(n)`, отримуємо добуток Дзета-функцій зі зсувом:

```
ζ(s) · ζ(s - a) = ∑_{n=1}^∞ σ_a(n) / nˢ
```

### 2. Функція Мебіуса `μ(n)` та оберненість Дзета-функції
Функція Мебіуса `μ(n)` визначається як:
- `μ(1) = 1`;
- `μ(n) = (-1)ʳ`, якщо `n` є добутком `r` різних простих чисел (без квадратів);
- `μ(n) = 0`, якщо `n` ділиться на квадрат будь-якого простого числа (`p² | n`).

Функція Мебіуса є оберненою до константної функції `1(n)` відносно згортки Діріхле: `(1 * μ)(n) = ε(n)`.
Отже:

```
ζ(s) · ( ∑_{n=1}^∞ μ(n) / nˢ ) = 1   ⇒   1 / ζ(s) = ∑_{n=1}^∞ μ(n) / nˢ
```

### 3. Функція Ейлера `φ(n)`
За теоремою Гаусса сума функцій Ейлера дільників дорівнює самому числу `∑_{d|n} φ(d) = n`, що у термінах згортки записується як `(φ * 1)(n) = n`.

Оскільки ряд для степені `N(n) = n` дорівнює `∑ n / nˢ = ζ(s - 1)`, маємо:

```
( ∑_{n=1}^∞ φ(n) / nˢ ) · ζ(s) = ζ(s - 1)   ⇒   ∑_{n=1}^∞ φ(n) / nˢ = ζ(s - 1) / ζ(s)
```

Застосувавши формулу обернення Мебіуса до тотожності Гаусса `(φ * 1) = N`, отримуємо прямий розклад функції Ейлера через функцію Мебіуса:

```
φ(n) = (N * μ)(n) = ∑_{d|n} d · μ(n/d) = n · ∑_{d|n} μ(d) / d
```

## 6. Обчислювальний приклад формули обернення Мебіуса

З алгебраїчної властивості `(1 * μ) = ε` випливає **класична формула обернення Мебіуса**:

```
g(n) = ∑_{d|n} f(d)   ⟺   f(n) = ∑_{d|n} g(d) · μ(n/d)
```

Продемонструємо роботу цієї формули на прикладі числа `n = 12`.

Дільники числа `12` є множиною `{1, 2, 3, 4, 6, 12}`.
Перевіримо рівність Гаусса `g(12) = ∑_{d|12} φ(d)`:

```
g(12) = φ(1) + φ(2) + φ(3) + φ(4) + φ(6) + φ(12)
      = 1 + 1 + 2 + 2 + 2 + 4 = 12
```

Тепер застосуємо обернену формулу Мебіуса для відновлення значення `φ(12)` за відомою функцією `g(d) = d`:

```
φ(12) = ∑_{d|12} d · μ(12/d)
      = 1·μ(12) + 2·μ(6) + 3·μ(4) + 4·μ(3) + 6·μ(2) + 12·μ(1)
```

Обчислимо значення функції Мебіуса для співмножників `12/d`:
- `μ(12) = μ(2² · 3) = 0` (містить квадрат `2²`);
- `μ(6) = μ(2 · 3) = (-1)² = 1` (добуток двох різних простих);
- `μ(4) = μ(2²) = 0` (містить квадрат `2²`);
- `μ(3) = (-1)¹ = -1` (одне просте число);
- `μ(2) = (-1)¹ = -1` (одне просте число);
- `μ(1) = 1` (базове значення).

Підставимо отримані значення у суму:

```
φ(12) = 1·(0) + 2·(1) + 3·(0) + 4·(-1) + 6·(-1) + 12·(1)
      = 0 + 2 + 0 - 4 - 6 + 12 = 4
```

Значення `φ(12) = 4` повністю збігається з дійсною кількістю чисел від 1 до 12, які не мають спільних дільників з 12 (це числа 1, 5, 7, 11).

Алгебра згортки Діріхле забезпечує строгий та елегантний підхід до перетворення арифметичних функцій і є фундаментальним інструментом аналітичної теорії чисел.
