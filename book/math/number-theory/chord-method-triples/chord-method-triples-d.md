Метод хорди показує дивовижний геометричний механізм: якщо ми маємо хоча б один раціональний розв'язок на кривій, ми можемо провести через нього пряму з раціональним нахилом — і вона гарантовано перетне криву в іншій раціональній точці. Ця ідея не лише повністю й вичерпно розв'язує задачу пошуку всіх Піфагорових трійок (a² + b² = c²), але й закладає фундамент для сучасної алгебраїчної геометрії, зокрема теорії еліптичних кривих та криптографії на їхній основі.

## Геометрія чисел

Коли ми чуємо про Піфагорові трійки, наша перша думка — це прямокутні трикутники з цілими сторонами. Найвідоміший приклад: 3, 4 та 5 (оскільки 3² + 4² = 9 + 16 = 25 = 5²). Інші приклади: 5, 12, 13 або 8, 15, 17. Їх існує нескінченно багато. Але як знайти їх усі? Якщо ми будемо просто перебирати числа, ми ніколи не будемо впевнені, що знайшли всі можливі структури, і тим більше не зрозуміємо їхньої природи. 

Алгебраїчно ми шукаємо розв'язки рівняння:
a² + b² = c²
де a, b, c — натуральні числа. 

Рівняння виглядає суто алгебраїчним, але його форма дуже нагадує щось знайоме з геометрії. Якщо ми поділимо обидві частини на c² (а ми можемо це зробити, адже c не дорівнює нулю), ми отримаємо:
(a/c)² + (b/c)² = 1.

Позначимо x = a/c та y = b/c. Тоді наше рівняння перетворюється на:
x² + y² = 1.

Це рівняння одиничного кола на координатній площині з центром у початку координат (0, 0) та радіусом 1. Оскільки a, b, c — цілі числа, то x та y — раціональні числа (дроби). Отже, задача пошуку Піфагорових трійок еквівалентна задачі пошуку всіх точок на одиничному колі, які мають раціональні координати! 

Цей простий перехід від цілих чисел до раціональних дробів — це колосальний прорив. Він переводить задачу з дискретної теорії чисел у неперервну геометрію. Тепер ми не шукаємо якісь загадкові числа в нескінченному морі цілих чисел; ми шукаємо точки на конкретній геометричній фігурі — одиничному колі.

## Метод хорди: суть ідеї

Як знайти всі раціональні точки на колі? Тут на сцену виходить неймовірно красивий та потужний інструмент — метод хорди (або метод січних). 

Ідея полягає в наступному. Припустімо, ми знаємо хоча б одну раціональну точку на колі. На одиничному колі x² + y² = 1 таких точок очевидно кілька: (1, 0), (0, 1), (-1, 0), (0, -1). Візьмемо точку P = (-1, 0). Вона лежить на колі, адже (-1)² + 0² = 1 + 0 = 1.

Тепер проведемо через цю точку P будь-яку пряму лінію. Пряма, що проходить через точку (-1, 0), задається рівнянням:
y = t · (x - (-1))
y = t · (x + 1)
де t — це нахил прямої (кутовий коефіцієнт).

Ця пряма обов'язково перетне коло в якійсь іншій точці Q (крім випадку, коли пряма є вертикальною дотичною, але це відповідає нахилу t, що прямує до нескінченності). Що ми знаємо про цю точку Q? Її координати є розв'язком системи рівнянь:
1) x² + y² = 1
2) y = t · (x + 1)

Ключовий момент методу хорди полягає у наступному твердженні: якщо нахил t є раціональним числом, то точка перетину Q також матиме раціональні координати. І навпаки, якщо точка Q має раціональні координати, то пряма, що проходить через раціональні точки P(-1, 0) та Q, обов'язково матиме раціональний нахил t.

Це означає, що ми отримуємо взаємно однозначну відповідність між усіма раціональними числами t та всіма раціональними точками Q на колі (окрім самої точки P). Кожне раціональне число t дає нам унікальну раціональну точку Q, а отже, унікальну Піфагорову трійку!

## Алгебраїчне виведення параметризації

Давайте підставимо рівняння прямої у рівняння кола, щоб знайти координати точки Q явно через параметр t.
x² + (t · (x + 1))² = 1
x² + t² · (x + 1)² = 1
x² + t² · (x² + 2x + 1) = 1
x² + t²x² + 2t²x + t² - 1 = 0
x²(1 + t²) + 2t²x + (t² - 1) = 0

Ми отримали квадратне рівняння щодо x. Здавалося б, треба застосовувати формулу дискримінанта. Але ми вже знаємо один корінь цього рівняння! Ми знаємо, що пряма перетинає коло в точці P з координатою x = -1. Це означає, що x = -1 гарантовано є коренем цього рівняння. 

Згадаємо теорему Вієта. Для квадратного рівняння Ax² + Bx + C = 0 суттєвим є те, що добуток коренів дорівнює C/A. 
Нехай корені нашого рівняння — це x₁ та x₂. Ми знаємо, що x₁ = -1. Тоді:
x₁ · x₂ = (t² - 1) / (1 + t²)
-1 · x₂ = (t² - 1) / (1 + t²)
x₂ = (1 - t²) / (1 + t²)

Ось ми й знайшли x-координату нашої точки Q! Це неймовірно просто, оскільки знання одного розв'язку (геометрично очевидного) дозволило знайти другий без обчислення коренів квадратного рівняння. 

Тепер знайдемо y-координату точки Q, підставивши x₂ у рівняння прямої:
y = t · (x + 1)
y = t · ((1 - t²) / (1 + t²) + 1)
Зведемо до спільного знаменника в дужках:
y = t · ((1 - t² + 1 + t²) / (1 + t²))
y = t · (2 / (1 + t²))
y = 2t / (1 + t²)

Отже, будь-яка раціональна точка на одиничному колі має координати:
x = (1 - t²) / (1 + t²)
y = 2t / (1 + t²)
для деякого раціонального числа t.

Ця пара рівнянь називається раціональною параметризацією кола. Вона каже, що координати x та y виражаються як відношення поліномів від t.

## Від кола до Піфагорових трійок

Тепер повернемося до Піфагорових трійок. Ми знаємо, що t — це раціональне число. Позначимо його як нескоротний дріб:
t = m / n
де m та n — цілі числа, причому НСД(m, n) = 1 (тобто вони не мають спільних дільників більше 1).

Підставимо t = m / n у наші формули для x та y:
x = (1 - (m/n)²) / (1 + (m/n)²) = ( (n² - m²)/n² ) / ( (n² + m²)/n² ) = (n² - m²) / (n² + m²)
y = 2(m/n) / (1 + (m/n)²) = ( 2mn/n² ) / ( (n² + m²)/n² ) = 2mn / (n² + m²)

Згадаймо, що x = a/c та y = b/c. Тоді ми маємо:
a/c = (n² - m²) / (n² + m²)
b/c = 2mn / (n² + m²)

Очевидно, що ми можемо покласти:
a = n² - m²
b = 2mn
c = n² + m²

Ці формули (часто відомі як формули Евкліда) генерують Піфагорові трійки! Якщо ми візьмемо будь-які два натуральні числа m та n (де n > m), ми отримаємо цілі значення для a, b та c, які задовольняють a² + b² = c².

Наприклад:
- Якщо n = 2, m = 1: a = 4 - 1 = 3, b = 2·1·2 = 4, c = 4 + 1 = 5 (трійка 3, 4, 5).
- Якщо n = 3, m = 2: a = 9 - 4 = 5, b = 2·2·3 = 12, c = 9 + 4 = 13 (трійка 5, 12, 13).
- Якщо n = 4, m = 1: a = 16 - 1 = 15, b = 2·1·4 = 8, c = 16 + 1 = 17 (трійка 15, 8, 17).

Щоб трійки були примітивними (тобто числа a, b, c не мали спільного дільника, крім 1), необхідно і достатньо, щоб m та n були взаємно простими та мали різну парність (одне парне, інше непарне). Якщо вони обидва непарні, то a, b, c будуть усі парними, тобто матимуть спільний дільник 2.

## Стереографічна проекція

Те, що ми зробили, проводячи прямі через точку (-1, 0), насправді має глибокий геометричний зміст, який виходить за межі алгебри. Ця конструкція називається стереографічною проекцією. 

Уявімо коло як одномірну сферу. Ми обрали на ній «південний полюс» — точку (-1, 0). Ми провели січну через полюс до перетину з віссю Y. Вісь Y тут виступає як «екватор» або проекційна площина. Кожній точці Q на колі відповідає рівно одна точка перетину січної з віссю Y. Ця точка має координати (0, t).

Стереографічна проекція відображає коло (за винятком однієї точки - полюса) на пряму лінію. Це відображення є взаємно однозначним. Оскільки пряма лінія (вісь Y) має нескінченну кількість раціональних точок, ми отримуємо спосіб перенести їх усі на коло. Це показує, чому раціональних точок на колі так багато, і чому вони розподілені усюди щільно (між будь-якими двома точками кола можна знайти раціональну точку).

## Еліптичні криві та сучасна алгебраїчна геометрія

Метод хорди не обмежується одиничним колом. Цей же метод працює для будь-якої кривої другого порядку (коніки) — еліпса, гіперболи, параболи. Якщо ви знайдете хоча б одну раціональну точку на такій кривій, ви зможете знайти їх усі за допомогою прямих із раціональним нахилом. 

Але що буде, якщо крива має вищий порядок? Наприклад, рівняння третього степеня, таке як y² = x³ + Ax + B? Такі криві називаються еліптичними кривими. Метод хорди для них працює інакше, але він все ще є фундаментом! Якщо ви проведете пряму через ДВІ раціональні точки на еліптичній кривій, вона перетне криву в ТРЕТІЙ раціональній точці. Це дозволяє вводити операцію «додавання» точок на еліптичній кривій, створюючи алгебраїчну групу. 

Розуміння методу хорди на колі — це перший і найважливіший крок до розуміння еліптичних кривих, на яких сьогодні тримається вся сучасна криптографія, блокчейн-технології та електронні цифрові підписи. Коли ваш браузер встановлює безпечне з'єднання з сервером, він використовує математику, прямим предком якої є цей самий геометричний трюк, що дозволив древнім математикам знайти Піфагорові трійки.

## Підсумок

Метод хорди демонструє неперевершену елегантність математики, де найскладніші алгебраїчні рівняння піддаються простому геометричному аналізу. Зведення пошуку цілих розв'язків a² + b² = c² до раціональних точок на колі, а потім до проектування цих точок на пряму за допомогою січної лінії, показує, як глибоко пов'язані між собою алгебра, геометрія та теорія чисел.


Додатково, давайте розглянемо, чому саме такий підхід став революційним для математики античності та середньовіччя. Класичний перебір не міг гарантувати вичерпного списку розв'язків. Метод хорди, з іншого боку, дає генератор. Цей генератор охоплює абсолютно всі розв'язки. Якщо ми хочемо знайти розв'язки для більш загального рівняння, наприклад a² - 2b² = 1 (рівняння Пелля), ми можемо застосувати схожі міркування, шукаючи раціональні точки на гіперболі x² - 2y² = 1.

Важливість раціональної параметризації неможливо переоцінити. Вона дозволяє нам генерувати не просто розв'язки, а нескінченні сімейства розв'язків, які інакше не мали б очевидного алгебраїчного зв'язку. Власне, коли ми маємо справу з будь-якою кривою, перше питання алгебраїчної геометрії полягає у тому: чи допускає вона раціональну параметризацію? Для кривих другого степеня відповідь завжди позитивна, за умови наявності хоча б однієї раціональної точки. Для кривих вищих степенів ситуація набагато складніша, що і робить теорію еліптичних кривих такою цікавою та складною.

Зокрема, варто відзначити, що цей підхід ідеально демонструє силу заміни змінних. Перехід від a, b, c до x, y радикально змінив ландшафт задачі. Замість дискретного простору цілих чисел, ми почали працювати у неперервному просторі координат, де можемо застосувати інструменти геометрії — прямі, перетини, нахили. Це перехід від арифметики до геометрії, який є серцевиною алгебраїчної геометрії.

Коли ми підставляли y = t(x+1) у x² + y² = 1, ми використали той факт, що точка (-1, 0) лежить на перетині прямої та кола. Цей перетин дає корінь рівняння x = -1. Теорема Вієта дозволила нам миттєво знайти другий корінь. Це не просто трюк; це глибокий наслідок того факту, що пряма перетинає коніку не більше ніж у двох точках. Оскільки одна точка відома і раціональна, коефіцієнти квадратного рівняння раціональні, то і другий корінь обов'язково має бути раціональним.

Тому метод хорди є не лише інструментом розв'язання, але й фундаментальною теоремою про природу конічних перерізів. Будь-яка невироджена коніка (еліпс, парабола, гіпербола), що містить хоча б одну раціональну точку, може бути повністю параметризована раціональними функціями. Це твердження становить одну з перших великих перемог на шляху об'єднання геометрії та алгебри.

У наступних розділах ми побачимо, як ці ідеї узагальнюються. Але навіть на цьому етапі, маючи лише формули Евкліда, ми можемо досліджувати глибокі властивості цілих чисел, їхню подільність, розподіл простих чисел у Піфагорових трійках та багато іншого. Метод хорди — це яскравий приклад того, як абстрактна математична ідея стає потужним інструментом для вирішення конкретних і складних задач.

Дослідження геометричної природи чисел відкриває шлях до глибоких математичних відкриттів. Метод хорди, показаний вище, слугує яскравим прикладом того, як неперервні концепції можуть пролити світло на дискретні структури. Звертаючись до історії, ми бачимо, що кожен великий крок у теорії чисел супроводжувався аналогічним переосмисленням. Коли ми розглядаємо площину не як набір незалежних точок, а як простір, де діють алгебраїчні закони, ми здобуваємо нові інструменти. Раціональна параметризація, отримана через метод хорди, не є унікальною для одиничного кола. Вона застосовна до широкого класу об'єктів. Зокрема, гіперболічні криві, еліпсоїди, параболічні дзеркала - усі вони мають схожі алгебраїчні властивості, що дозволяють шукати цілочисельні рішення через їхні геометричні аналоги.
