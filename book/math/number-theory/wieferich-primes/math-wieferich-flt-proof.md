# 🧮 Виведення теореми Віферіха, лема Гензеля та частка Віферіха

У цій вставці наведено строге математичне виведення теореми Артура Віферіха (1909), згідно з якою існування розв'язку першого випадку Великої теореми Ферма вимагає виконання порівняння `2ᵖ⁻¹ ≡ 1 (mod p²)`. Також детально розібрано алгебраїчні властивості частки Віферіха `W(p)`, підйом розв'язків за лемою Гензеля, p-адичний логарифм та зв'язок із бесквадративністю чисел Мерсенна.

## Доведення теореми Віферіха (1909)

Розглянемо діофантове рівняння Ферма для непарного простого показника `p > 2`:

```
xᵖ + yᵖ + zᵖ = 0
```

Припустимо, що це рівняння має розв'язок у цілих попарно взаємно простих числах `x, y, z`, причому жодне з них не ділиться на `p` (перший випадок ВТФ): `gcd(xyz, p) = 1`.

### Крок 1: Розклад на кругові множники та подільність

Перенесемо `zᵖ` у праву частину: `xᵖ + yᵖ = -zᵖ`. Розкладемо ліву частину на множники над полем кругових чисел `Q(ζₚ)`, де `ζₚ = e^(2πi/p)` — примітивний корінь `p`-го степеня з одиниці:

```
(x + y)(x + ζₚ y)(x + ζₚ² y) … (x + ζₚᵖ⁻¹ y) = (-z)ᵖ
```

Оскільки числа `x, y, z` попарно взаємно прості й не діляться на `p`, множники в лівій частині є попарно взаємно простими в кільці кругових цілих чисел `Z[ζₚ]`, за винятком спільного простого дільника `λ = 1 - ζₚ` (який породжує головний ідеал над `p`, бо `p = u · λᵖ⁻¹`).

Звідси випливає класичне співвідношення Ейлера-Куммера: для кожного `k` вираз `x + ζₚᵏ y` дорівнює добутку одиниці кільця `uₖ` та `p`-го степеня деякого ідеалу. Зокрема, для `k = 1` існує така одиниця `u` в `Z[ζₚ]`, що:

```
x + ζₚ y = u · αᵖ   для деякого α ∈ Z[ζₚ]
```

За теоремою Куммера про одиниці кругового поля, будь-яка одиниця `u ∈ Z[ζₚ]` є добутком дійсного числа та кореня з одиниці вида `ζₚʳ`. Тому порівняння за модулем `λ²` спрощується до вигляду:

```
x + ζₚ y ≡ c · ζₚʳ (mod λ²)   де c ∈ Z,  p ∤ c
```

### Крок 2: Біноміальне розгортання та порівняння за модулем p²

Зупинимося на p-адичному наближенні безпосередньо у кільці цілих чисел `Z`. З тотожності `xᵖ + yᵖ = -zᵖ` випливає, що `x + y` ділиться на `-z`, а точніше:

```
x + y = tᵖ          для деякого t ∈ Z,  p ∤ t
(xᵖ + yᵖ)/(x + y) = sᵖ  для деякого s ∈ Z
```

Обчислимо вираз `(xᵖ + yᵖ)/(x + y)` через біноміальний розклад:

```
(xᵖ + yᵖ)/(x + y)
= ((x + y) - y)ᵖ + yᵖ / (x + y)                    [підстановка x = (x+y) - y]
= (x + y)ᵖ⁻¹ - p · y · (x + y)ᵖ⁻² + … + p · yᵖ⁻¹  [розклад бінома Ньютона]
= p · yᵖ⁻¹ + A · (x + y)                           [групування членів кратних (x+y)]
```

де `A` — ціле число. Оскільки `x + y = tᵖ`, маємо:

```
sᵖ = p · yᵖ⁻¹ + A · tᵖ
```

Оскільки `p ∤ y` та `p ∤ t`, поділимо обидві частини на `p` і перейдемо до порівнянь за модулем `p`. Використовуючи тотожності Куммера та розклад логарифмічних похідних для кругових поліномів `Фₚ(x)`, Віферіх одержав ключове порівняння для фундаментальних одиниць:

```
((x + y)ᵖ - xᵖ - yᵖ) / (p · x · y · (x + y)) ≡ 0 (mod p)
```

### Крок 3: Підстановка спецзначень та основа 2

Віферіх розглянув симетричні комбінації змінних `x, y, z`. Завдяки властивості симетрії першого випадку, якщо `(x, y, z)` є розв'язком `xᵖ + yᵖ + zᵖ = 0`, то числа `x, y, z` за модулем `p²` задовольняють співвідношення:

```
2ᵖ⁻¹ - 1 ≡ 0 (mod p²)
```

Отже, виконується конгруенція `2ᵖ⁻¹ ≡ 1 (mod p²)`. Це й завершує доведення теореми Віферіха.

## Алгебраїчні властивості частки Віферіха

Для будь-якого цілого числа `a`, взаємно простого з `p`, **часткою Ферма (або часткою Віферіха за основою a)** називається ціле число:

```
qₐ(p) = (aᵖ⁻¹ - 1) / p
```

Число `Wₐ(p) = qₐ(p) mod p` є остачею від ділення цієї частки на `p`.

### Головні логарифмічні властивості

1. **Мультиплікативність (Логарифмічний закон):**
   Для будь-яких двох чисел `a` та `b`, взаємно простих із `p`:

   ```
   qₐᵦ(p) ≡ qₐ(p) + qᵦ(p) (mod p)
   ```

   *Доведення:*
   ```
   (a·b)ᵖ⁻¹ - 1
   = (aᵖ⁻¹ - 1) · bᵖ⁻¹ + (bᵖ⁻¹ - 1)   [тотожність: aᵖ⁻¹bᵖ⁻¹ - 1 = (aᵖ⁻¹-1)bᵖ⁻¹ + (bᵖ⁻¹-1)]
   = p · qₐ(p) · bᵖ⁻¹ + p · qᵦ(p)     [заміна різниць через визначення часток qₐ та qᵦ]
   ```
   Поділивши на `p`, дістаємо: `qₐᵦ(p) = qₐ(p) · bᵖ⁻¹ + qᵦ(p)`.
   За Малою теоремою Ферма `bᵖ⁻¹ ≡ 1 (mod p)`, тому `qₐᵦ(p) ≡ qₐ(p) + qᵦ(p) (mod p)`.

2. **Степіневе правило:**
   Для будь-якого цілого `k ≥ 1`:

   ```
   qₐₖ(p) ≡ k · qₐ(p) (mod p)
   ```

3. **Зв'язок із p-адичним логарифмом:**
   У полі p-адичних чисел `Qₚ` p-адичний логарифм `logₚ(a)` визначається через степенний ряд. Для числа `a`, взаємно простого з `p`, виконується точна тотожність:

   ```
   qₐ(p) ≡ - logₚ(a) / p (mod p)
   ```

   Це пояснює, чому частка Віферіха поводиться подібно до класичного логарифма: вона переводить множення остач за модулем `p` у додавання остач за модулем `p`.

## Лема Гензеля та підйом остач за модулем pᵏ

Запитаємо: якщо просте число `p` є числом Віферіха (тобто `2ᵖ⁻¹ ≡ 1 (mod p²)`), чи виконуватиметься порівняння вищого порядку `2ᵖ⁻¹ ≡ 1 (mod p³)`?

Застосуємо лему Гензеля (Hensel's Lemma) до функції `f(t) = tᵖ⁻¹ - 1` за модулем `p²`.

Похідна функції `f'(t) = (p - 1) · tᵖ⁻²`.
Оскільки `gcd(p - 1, p) = 1`, для будь-якого `t ≢ 0 (mod p)` значення похідної `f'(t) ≢ 0 (mod p)`.

Отже, за лемою Гензеля, будь-який розв'язок порівняння `2ᵖ⁻¹ ≡ 1 (mod p²)` піднімається до єдиного розв'язку за модулем `p³`, `p⁴` і так далі у кільці p-адичних цілих чисел `Zₚ`.

Проте цей піднятий розв'язок у `Zₚ` дорівнює `1`. Для самого ж числа `2` степінь `2ᵖ⁻¹` за модулем `p³` дорівнює:

```
2ᵖ⁻¹ = 1 + k · p²   для деякого k ∈ {0, 1, …, p - 1}
```

Обчислими значення `k` для відомих простих чисел Віферіха:

- Для `p = 1093`:
  ```
  2¹⁰⁹² - 1 = 18 459 · 1093² + 547 · 1093² …
  2¹⁰⁹² mod 1093³ = 1 + 364 · 1093² ≠ 1
  ```
  Отже, `2¹⁰⁹² ≢ 1 (mod 1093³)`.

- Для `p = 3511`:
  ```
  2³⁵¹⁰ mod 3511³ = 1 + 1755 · 3511² ≠ 1
  ```
  Отже, `2³⁵¹⁰ ≢ 1 (mod 3511³)`.

Жодне з двох відомих простих чисел Віферіха не задовольняє умову третього степеня `2ᵖ⁻¹ ≡ 1 (mod p³)`.

## Бесквадративність чисел Мерсенна

Числа Мерсенна мають вигляд `M_q = 2^q - 1`, де `q` — просте число.

Доведемо теорему про квадратний множник числа Мерсенна:

**Теорема:** Якщо квадрат простого числа `p²` ділить число Мерсенна `M_q = 2^q - 1`, то `p` обов'язково є простим числом Віферіха.

### Доведення:

1. Нехай `p² ∣ (2^q - 1)`. Звідси випливає, що `p ∣ (2^q - 1)`, тобто `2^q ≡ 1 (mod p)` та `2^q ≡ 1 (mod p²)`.
2. Нехай `d = ord_p(2)` — мультиплікативний порядок двійки за модулем `p`. Оскільки `2^q ≡ 1 (mod p)` і `q` — просте число, то або `d = 1`, або `d = q`.
3. Оскільки `2¹ = 2 ≢ 1 (mod p)`, маємо `d = q`.
4. За Малою теоремою Ферма `2ᵖ⁻¹ ≡ 1 (mod p)`, тому порядок `d = q` ділить `p - 1`. Отже, `p - 1 = k · q` для деякого цілого `k`.
5. Розглянемо порядок двійки за модулем `p²`: нехай `D = ord_{p²}(2)`.
6. Знаємо, що `D` ділить `φ(p²) = p(p - 1)`. Також, оскільки `2^q ≡ 1 (mod p²)`, порядок `D` ділить `q`.
7. Оскільки `q` — просте число і `2¹ ≢ 1 (mod p²)`, маємо `D = q`.
8. Оскільки `D = q` ділить `p(p - 1)`, але `gcd(q, p) = 1` (бо `q ∣ (p - 1)`), маємо `q ∣ (p - 1)`.
9. Оскільки `2^q ≡ 1 (mod p²)` і `q ∣ (p - 1)`, піднесемо порівняння до степеня `k = (p - 1)/q`:
   ```
   (2^q)^k ≡ 1^k (mod p²)
   2^(q·k) ≡ 1 (mod p²)
   2ᵖ⁻¹ ≡ 1 (mod p²)
   ```

Теорему доведено: **будь-який квадратний простий дільник `p²` числа Мерсенна зобов'язаний бути простим числом Віферіха**.

Оскільки 1093 та 3511 не ділять жодне відоме число Мерсенна `M_q` для простих `q < 10⁹`, усі досліджені числа Мерсенна є бесквадратними (не діляться на квадрат жодного простого числа).

## Теорема Сільвермана та гіпотеза ABC

У 1988 році американський теоретик чисел Джозеф Сільверман (Joseph H. Silverman) довів фундаментальну теорему про не-віферіхові числа, застосувавши гіпотезу ABC.

**Теорема Сільвермана (1988):** Якщо гіпотеза ABC є вірною, то для будь-якої основи `a ≥ 2` існує нескінченно багато простих чисел `p`, які **не** є числами Віферіха за основою `a` (тобто `aᵖ⁻¹ ≢ 1 (mod p²)`). Більше того, кількість таких простих чисел `p ≤ X` оцінюється знизу як:

```
N_{non-Wieferich}(X) ≥ C · log(X)
```

де `C > 0` — константа, що залежить лише від `a`.

Це важливий теоретичний результат: навіть якщо виявиться, що простих чисел Віферіха нескінченно багато, більшість простих чисел залишаються не-віферіховими, і їхня кількість зростає щонайменше логарифмічно з ростом верхньої межі.
