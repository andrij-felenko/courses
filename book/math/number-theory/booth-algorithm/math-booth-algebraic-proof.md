# 🧮 Алгебраїчне доведення тотожності Бута

Алгоритм множення Бута ґрунтується на перекодуванні двійкових розрядів множника з метою зменшення кількості додань в апаратній реалізації. Замість обробки кожного окремого біта `y_i` зі значеннями `0` або `1`, алгоритм обчислює різниці сусідніх бітів `d_i = y_{i-1} - y_i`. Щоб обчислювальний блок працював коректно, таке перекодування не повинно змінювати підсумкове значення числа.

Математичним підґрунтям цієї заміни є фундаментальна алгебраїчна тотожність:

```
∑_{i=0}^{n-1} y_i 2^i = ∑_{i=0}^{n-1} (y_{i-1} - y_i) 2^i
```

де за умовою `y₋₁ = 0` — фіктивний розряд праворуч від наймолодшого біта. Ця тотожність гарантує, що сума розрядів із новими коефіцієнтами `d_i` дає точно те саме число, що й початковий двійковий запис.

## Інтуїція: телескопічний зсув ваг

На інтуїтивному рівні тотожність Бута використовує властивість телескопічної суми для двійкових розрядів. Якщо у двійковому числі є послідовна група одиниць вигляду `01110` (що відповідає десятковому числу 14), то звичайне множення вимагає трьох додань: `2³ + 2² + 2¹ = 8 + 4 + 2 = 14`.

Однак те саме число 14 можна подати як різницю `16 - 2`, тобто `2⁴ - 2¹`. Замість того щоб додавати кожну одиницю всередині суцільного блоку, ми можемо виконати лише дві дії: відняти множене на початку блоку (на розряді `2¹`) і додати зсунуте множене одразу після закінчення блоку (на розряді `2⁴`).

У загальному випадку для суцільної групи одиниць від розряду `m` до розряду `k` (де `k ≥ m`) справджується тотожність:

```
2^k + 2^{k-1} + ... + 2^m = 2^{k+1} - 2^m
```

Кожен внутрішній біт `1` у цій групі створює два протилежні внески на сусідніх кроках: додавання ваги від попереднього розряду та віднімання на власному розряді. У результаті всі проміжні члени взаємно знищуються, і в сумі залишаються тільки межі блоку.

## Алгебраїчне доведення тотожності

Для строгого обґрунтування перетворимо праву частину тотожності. Позначимо її через `S`:

```
S = ∑_{i=0}^{n-1} (y_{i-1} - y_i) 2^i
```

Розкриємо дужки під знаком суми та розділимо її на два окремі доданки:

```
S = ∑_{i=0}^{n-1} y_{i-1} 2^i - ∑_{i=0}^{n-1} y_i 2^i         [дистрибутивність: розбиття суми на дві]
```

Розглянемо першу суму `∑_{i=0}^{n-1} y_{i-1} 2^i`. Зробимо заміну індексу підсумовування `j = i - 1`, звідки `i = j + 1`. Коли індекс `i` змінюється від `0` до `n-1`, новий індекс `j` змінюється від `-1` до `n-2`:

```
∑_{i=0}^{n-1} y_{i-1} 2^i
= ∑_{j=-1}^{n-2} y_j 2^{j+1}                                  [заміна індексу j = i - 1]
= y₋₁ 2⁰ + ∑_{j=0}^{n-2} y_j 2^{j+1}                          [виділення члена при j = -1]
= 0 + ∑_{j=0}^{n-2} y_j 2^{j+1}                               [крайова умова: y₋₁ = 0]
= ∑_{i=0}^{n-2} y_i 2^{i+1}                                   [повернення позначення індексу i]
```

Підставимо знайдений вираз першої суми назад у формулу для `S`:

```
S = ∑_{i=0}^{n-2} y_i 2^{i+1} - ∑_{i=0}^{n-1} y_i 2^i          [підстановка видобутої суми]
```

Тепер відокремимо останній член при `i = n-1` із другої суми:

```
S = ∑_{i=0}^{n-2} y_i 2^{i+1} - ( ∑_{i=0}^{n-2} y_i 2^i + y_{n-1} 2^{n-1} )   [виділення члена при i = n-1]
= ∑_{i=0}^{n-2} y_i 2^{i+1} - ∑_{i=0}^{n-2} y_i 2^i - y_{n-1} 2^{n-1}         [розкриття дужок]
= ∑_{i=0}^{n-2} y_i (2^{i+1} - 2^i) - y_{n-1} 2^{n-1}                        [групування за коефіцієнтами y_i]
```

Звернемо увагу на вираз у дужках для кожного `y_i`. Закони показників степеня дозволяють спростити цю різницю:

```
2^{i+1} - 2^i
= 2^i · 2 - 2^i
= 2^i (2 - 1)
= 2^i                                                         [спрощення різниці степенів двоєчки]
```

Підставляючи це спрощення у вираз для `S`, одержуємо остаточний результат:

```
S = ∑_{i=0}^{n-2} y_i 2^i - y_{n-1} 2^{n-1}                    [остаточна згрупована сума]
```

## Доповняльний код і практичне значення

Отриманий вираз `S = - y_{n-1} 2^{n-1} + ∑_{i=0}^{n-2} y_i 2^i` тотожно дорівнює алгебраїчному значенню `n`-бітного числа у доповняльному коді. 

У доповняльному коді старший знаковий біт `y_{n-1}` має від'ємну вагу `-2^{n-1}`. Перекодування Бута автоматично та природним шляхом враховує цю від'ємну вагу через різницю `d_{n-1} = y_{n-2} - y_{n-1}`, не вимагаючи окремого алгоритмічного розгалуження для від'ємних множників.

Для беззнакових чисел (або при знакорозширенні бітом `y_n = y_{n-1}`) підсумкова сума збігається із класичним поданням `∑_{i=0}^{n-1} y_i 2^i`. Таким чином, тотожність доведена повністю: перекодування Бута зберігає точне значення числа для довільного двійкового множника.
