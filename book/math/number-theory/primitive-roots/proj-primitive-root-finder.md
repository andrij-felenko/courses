# Проєкт: Пошук первісного кореня

На практиці для використання у криптографічних протоколах, таких як алгоритм Діффі-Геллмана, часто потрібно знайти генератор мультиплікативної групи (Z/pZ)*, тобто первісний корінь за модулем простого числа p. Цей проєкт містить практичну реалізацію мовою C++17 алгоритму пошуку найменшого первісного кореня.

## Ідея алгоритму

Число g є первісним коренем за простим модулем p тоді й лише тоді, коли його мультиплікативний порядок дорівнює p - 1. Згідно з теоремою Лагранжа, порядок будь-якого елемента ділить порядок групи. Оскільки порядок групи (Z/pZ)* дорівнює p - 1, то для того, щоб g було генератором, достатньо перевірити, що жоден степінь, менший за p - 1, не дає одиницю. Більше того, достатньо перевірити лише степені (p - 1) / q для всіх простих дільників q числа p - 1. Якщо для всіх таких q виконується g^((p-1)/q) ≢ 1 (mod p), то g — первісний корінь.

## 1. Заголовки та допоміжні функції

Для початку нам знадобляться базові бібліотеки вводу-виводу, векторів та алгоритмів.

```cpp
#include <iostream>
#include <vector>
#include <cstdint>

// Функція модулярного піднесення до степеня a^b mod m
uint64_t power_mod(uint64_t base, uint64_t exp, uint64_t mod) {
    uint64_t res = 1;
    base %= mod;
    while (exp > 0) {
        if (exp % 2 == 1) res = (res * base) % mod;
        base = (base * base) % mod;
        exp /= 2;
    }
    return res;
}
```

Ця функція працює за час O(log(exp)) за допомогою алгоритму двійкового піднесення до степеня, що є критично важливим для великих значень p.

## 2. Факторизація

Наступний крок — знайти всі прості дільники числа p - 1. Оскільки ми розглядаємо p, що поміщається у стандартні типи даних (наприклад, 64-бітне ціле), ми можемо скористатись звичайним алгоритмом перебору дільників до кореня.

```cpp
// Функція для знаходження простих дільників числа n
std::vector<uint64_t> get_prime_factors(uint64_t n) {
    std::vector<uint64_t> factors;
    for (uint64_t i = 2; i * i <= n; ++i) {
        if (n % i == 0) {
            factors.push_back(i);
            while (n % i == 0) {
                n /= i;
            }
        }
    }
    if (n > 1) {
        factors.push_back(n);
    }
    return factors;
}
```

Цей алгоритм працює за O(√n), що цілком прийнятно для знаходження первісного кореня у навчальних цілях або для p < 2⁶⁴.

## 3. Перевірка кандидата

Тепер реалізуємо функцію, яка перевіряє, чи є число g первісним коренем за простим модулем p.

```cpp
// Перевірка чи є g первісним коренем за модулем p
bool is_primitive_root(uint64_t g, uint64_t p, const std::vector<uint64_t>& factors) {
    uint64_t phi = p - 1;
    for (uint64_t q : factors) {
        if (power_mod(g, phi / q, p) == 1) {
            return false;
        }
    }
    return true;
}
```

## 4. Пошук найменшого кореня

Оскільки первісних коренів існує φ(p - 1), ймовірність того, що випадково обране число буде первісним коренем, досить висока. Тому ми можемо просто перебирати числа g = 2, 3, 4, ..., поки не знайдемо шукане. Найменший первісний корінь зазвичай дуже малий.

```cpp
// Знаходження найменшого первісного кореня
uint64_t find_smallest_primitive_root(uint64_t p) {
    std::vector<uint64_t> factors = get_prime_factors(p - 1);
    for (uint64_t g = 2; g < p; ++g) {
        if (is_primitive_root(g, p, factors)) {
            return g;
        }
    }
    return 0; // Якщо не знайдено (не повинно статись для простого p)
}
```

## 5. Головна програма

Об'єднаємо все разом у функції main. Програма зчитує просте число p та виводить його найменший первісний корінь.

```cpp
int main() {
    uint64_t p;
    std::cout << "Введіть просте число p: ";
    if (std::cin >> p) {
        uint64_t root = find_smallest_primitive_root(p);
        if (root != 0) {
            std::cout << "Найменший первісний корінь: " << root << "\n";
        } else {
            std::cout << "Первісних коренів не знайдено.\n";
        }
    }
    return 0;
}
```

Завдяки оптимізованій перевірці за допомогою простих дільників p - 1, цей код швидко знаходить результат. Наприклад, для p = 1000000007 (відоме просте число) найменшим первісним коренем є 5.
