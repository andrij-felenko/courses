# 🧮 Математичне обґрунтування абсолютної збіжності добутку Ейлера

Доведення тотожності Ейлера вимагає суворого обґрунтування перестановки доданків та переходу від скінченних добутків до нескінченного добутку в області комплексної площини.

## 1. Абсолютна збіжність рядів та добутків

Для дійсного s > 1 або для комплексного s з Re(s) > 1 ряд Дзета-функції Ейлера:
ζ(s) = ∑_{n=1}^∞ 1 / n^s = 1 + 1/2^s + 1/3^s + 1/4^s + ...

є мажорованим інтегралом ∫₁^∞ x^{-Re(s)} dx = 1 / (Re(s) - 1), а отже абсолютно та рівномірно збігається на будь-якому компакті в півплощині Re(s) > 1.

Нескінченний добуток ∏_p (1 - p^{-s})⁻¹ збігається тоді і тільки тоді, коли збігається ряд із логарифмів його множників:
ln( ∏_p (1 - p^{-s})⁻¹ ) = - ∑_p ln(1 - p^{-s}).

Використовуючи розклад логарифма у степеневий ряд ln(1 - x) = - ∑_{k=1}^∞ x^k / k для |x| = |p^{-s}| < 1:
- ln(1 - p^{-s}) = ∑_{k=1}^∞ p^{-k·s} / k = p^{-s} + p^{-2s}/2 + p^{-3s}/3 + ...

Підставляючи це у суму по всіх простих p:
∑_p -ln(1 - p^{-s}) = ∑_p p^{-s} + ∑_p ∑_{k=2}^∞ p^{-k·s} / k.

Другий доданок мажорується геометричною прогресією:
∑_{k=2}^∞ p^{-k·s} / k < ∑_{k=2}^∞ p^{-k·s} = p^{-2s} / (1 - p^{-s}) ≤ 2 · p^{-2s}.

Оскільки ∑_p p^{-2s} ≤ ∑_{n=1}^∞ n^{-2s} збігається для Re(s) > 1/2, то абсолютна збіжність нескінченного добутку ∏_p (1 - p^{-s})⁻¹ повністю визначається збіжністю ряду ∑_p p^{-s}.

## 2. Логарифмічна похідна та підрахунок простих чисел

Взявши логарифмічну похідну від дзета-функції Ейлера через добуток, отримуємо фундаментальний аналітичний інструмент:
- ζ'(s) / ζ(s) = ∑_p (ln p) / (p^s - 1) = ∑_{n=1}^∞ Λ(n) / n^s,

де Λ(n) — функція Мангольдта, яка дорівнює ln p, якщо n = p^k, і 0 в протилежному випадку.

Ця тотожність лежить в основі аналітичного доведення теореми про розподіл простих чисел Адамара та Валле-Пуссена (1896 рік). Шляхом інтегрування логарифмічної похідної вздовж контуру у комплексній площині отримується точна асимптотика для функції розподілу простих чисел π(x) ≈ Li(x).

## 3. Аналітичне продовження та функціональне рівняння

У півплощині Re(s) ≤ 1 ряд та добуток розбігаються, однак Дзета-функція має унікальне мероморфне продовження на всю комплексну площину C з єдиним простим полюсом у точці s = 1 із лишком Res(ζ, 1) = 1.

Це аналітичне продовження задовольняє функціональне рівняння Рімана:
ζ(s) = 2^s · π^{s-1} · sin(π·s / 2) · Γ(1 - s) · ζ(1 - s),

де Γ(z) — гамма-функція Ейлера. Нескінченний добуток Ейлера задає аналітичну структуру Дзета-функції у фундаментальній області Re(s) > 1.
