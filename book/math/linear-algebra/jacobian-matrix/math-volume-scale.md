# 🧮 Звідки у заміні змінних береться множник |det J|

Коли [кратний інтеграл](book:math/multiple-integral) переписують у зручніших координатах, під знаком інтеграла нізвідки з'являється множник |det J| — і тут він виводиться від початку: з площі образу однієї маленької клітинки, через граничний перехід, аж до готових формул для полярних, циліндричних і сферичних координат.

## Що саме треба показати

Одновимірна підстановка виглядає настільки звично, що множник у ній уже й не помічають: із x = g(u) інтеграл ∫ f(x) dx перетворюється на ∫ f(g(u))·g′(u) du. А множник там є, і причина проста: відрізок довжиною du переходить у відрізок довжиною |g′|·du. Підстановка розтягує вісь, тому довжина не переноситься сама собою.

У двох вимірах те саме, але розтяг тепер різний у різних напрямках, і одним числом «наскільки довше» його не описати. Треба знати інше: наскільки більшою стала **площа**.

Постановка така. Є область D\* у площині параметрів (u, v) і відображення

```
Φ(u, v) = ( x(u, v) , y(u, v) )
```

яке переводить D\* на область D у площині (x, y). Треба виразити ∫∫ f(x, y) dx dy по D через інтеграл по D\*.

## Крок перший: образ однієї клітинки

Поріжемо D\* сіткою на прямокутнички зі сторонами Δu та Δv й візьмімо один із них, із ближньою вершиною в точці (u₀, v₀). Куди відображення переносить його чотири вершини? Відповідь дає [розклад Тейлора](book:math/taylor-series) — наближення функції її похідними в точці:

```
Φ(u₀+Δu, v₀)     ≈ Φ(u₀,v₀) + Δu·∂Φ/∂u
Φ(u₀, v₀+Δv)     ≈ Φ(u₀,v₀) + Δv·∂Φ/∂v
Φ(u₀+Δu, v₀+Δv)  ≈ Φ(u₀,v₀) + Δu·∂Φ/∂u + Δv·∂Φ/∂v
```

У кожному рядку відкинуте — другого порядку малості. Позначмо два вектори, уздовж яких роз'їхалися сусідні вершини:

```
a = Δu · ∂Φ/∂u = Δu · ( ∂x/∂u , ∂y/∂u )
b = Δv · ∂Φ/∂v = Δv · ( ∂x/∂v , ∂y/∂v )
```

Четверта вершина поїхала на a + b. Чотири точки, з яких дальня зсунута рівно на суму зсувів двох сусідніх, — це вершини паралелограма. Отже, образ клітинки з точністю до другого порядку є паралелограмом на a і b.

Тепер найголовніше в усьому виведенні: ∂Φ/∂u і ∂Φ/∂v — це рівно перший і другий стовпці якобіана. **Ребра образу — стовпці J, помножені на кроки сітки.** Жодного нового об'єкта тут не з'явилося, тільки ті самі частинні похідні, зібрані стовпцями.

## Крок другий: площа паралелограма — це модуль визначника

Лишилось порахувати площу паралелограма на a = (a₁, a₂) і b = (b₁, b₂). За основу візьмімо a; висота — це та складова b, що перпендикулярна до a, тобто |b|·sin α, де α — кут між векторами. Отже S = |a|·|b|·sin α. Піднесімо це до квадрата й скористаймося тотожністю Лаґранжа:

```
(a₁b₁ + a₂b₂)²  +  (a₁b₂ − a₂b₁)²  =  (a₁² + a₂²)·(b₁² + b₂²)
```

Розкрийте дужки — подвійні добутки в лівій частині взаємно знищаться, лишиться рівно права. Перший доданок ліворуч — це квадрат скалярного добутку, тобто |a|²·|b|²·cos²α, а праворуч стоїть |a|²·|b|². Отже другий доданок дорівнює

```
(a₁b₂ − a₂b₁)² = |a|²·|b|²·(1 − cos²α) = ( |a|·|b|·sin α )² = S²
```

А вираз a₁b₂ − a₂b₁ — це визначник матриці, у стовпцях якої стоять a і b. Тому

```
S = | a₁b₂ − a₂b₁ | = | det [ a  b ] |
```

Підставмо сюди a = Δu·(перший стовпець J) і b = Δv·(другий стовпець J). Спільний множник цілого стовпця виноситься з-під визначника, тож

```
det [ a  b ] = Δu · Δv · det J

площа образу клітинки ≈ | det J(u₀, v₀) | · Δu · Δv
```

Це і є відповідь на «звідки взявся визначник». Його не підбирали й не вводили окремо: це та сама [формула площі через визначник](book:math/matrix-determinant), застосована до стовпців J.

## Крок третій: від суми по клітинках до інтеграла

[Інтеграл](book:math/integral) — це границя сум, у яких значення функції множиться на площу шматочка. Ріжемо D\* сіткою; якщо Φ взаємно однозначне, образи клітинок не налазять один на одного й покривають D. Беремо в кожній клітинці точку (u_k, v_k):

```
∫∫ f(x,y) dx dy   ≈   Σₖ f( Φ(u_k, v_k) ) · площа образу клітинки k
 по D

                  ≈   Σₖ f( Φ(u_k, v_k) ) · | det J(u_k, v_k) | · Δu · Δv
```

Права частина — уже звичайна інтегральна сума, тільки для функції f(Φ(u,v))·|det J(u,v)| і по області D\* у площині параметрів. Спрямляємо сітку до нуля й дістаємо

```
∫∫ f(x, y) dx dy  =  ∫∫ f( x(u,v), y(u,v) ) · | det J(u,v) | · du dv
  по D                по D*
```

Один крок тут варто перевірити, а не проковтнути: чи не назбирується відкинута похибка. На кожній клітинці ми знехтували величиною порядку Δ³ — площа порядку Δ² з відносною похибкою порядку Δ. Клітинок приблизно (площа D\*)/(Δu·Δv), тобто порядку Δ⁻². Добуток дає Δ: сумарна похибка спадає разом із кроком, а не лишається сталою. Саме тому граничний перехід чинний. Тонкість, на яку це міркування мовчки спирається, — рівномірність: відносна похибка має бути мала одразу на всіх клітинках, а не на кожній зокрема. Це забезпечує неперервність частинних похідних на замкненій області.

Скорочений запис того самого — правило перерахунку елемента площі й об'єму:

```
dx dy      = | det J | · du dv          (J розміру 2×2)
dx dy dz   = | det J | · du dv dw       (J розміру 3×3)
```

Тривимірне виведення повторюється слово в слово: образ клітинки — паралелепіпед на трьох стовпцях J, а його об'єм дорівнює модулю визначника 3×3.

## Приклад із лінійною заміною: u = x + y, v = x − y

Почнімо з випадку, де жодних наближень немає: лінійне відображення однакове в кожній точці, тому паралелограм — не наближення, а точний образ. Хай нові змінні задані через старі:

```
u = x + y
v = x − y
```

Це відображення веде від (x, y) до (u, v), тож його якобіан складено з похідних u і v за x та y:

```
        ⎡ ∂u/∂x   ∂u/∂y ⎤   ⎡ 1    1 ⎤
J₍ᵤᵥ₎ = ⎢               ⎥ = ⎢        ⎥      det = 1·(−1) − 1·1 = −2
        ⎣ ∂v/∂x   ∂v/∂y ⎦   ⎣ 1   −1 ⎦
```

Але у формулі заміни змінних потрібен якобіан **протилежного** напрямку — від параметрів до старих координат. Розв'яжімо систему відносно x і y:

```
x = (u + v)/2
y = (u − v)/2

    ⎡ 1/2    1/2 ⎤
J = ⎢            ⎥      det J = (1/2)·(−1/2) − (1/2)·(1/2) = −1/2
    ⎣ 1/2   −1/2 ⎦

dx dy = |−1/2| · du dv = ½ · du dv
```

Два визначники, −2 і −1/2, — обернені один до одного, і це не збіг. Одне за одним ці два відображення дають тотожне, а визначник добутку матриць дорівнює добутку визначників — отже, (−2)·(−1/2) мусить дорівнювати одиниці. Практично це економить роботу: якщо похідні зручніше виписати «в інший бік», порахуйте той визначник і візьміть обернене число.

Перевірмо на площі. Ромб |x| + |y| ≤ 1 має діагоналі 2 і 2, тобто площу 2. Куди він переходить? Для будь-яких p і q справджується (|p+q| + |p−q|)/2 = max(|p|, |q|), а тут |x| + |y| = (|u+v| + |u−v|)/2, отже |x| + |y| = max(|u|, |v|). Умова ромба перетворилася на квадрат −1 ≤ u ≤ 1, −1 ≤ v ≤ 1 із площею 4. І справді: 2 = ½ · 4.

**Чому саме модуль.** Визначник вийшов від'ємний, а площа від'ємною не буває — тому у формулу входить модуль. Але знак не марний: він каже, що ця заміна містить віддзеркалення — пара векторів, яка була «проти годинникової стрілки», стала «за». Для площі це байдуже.

## Полярні координати

Найвідоміший випадок і найкоротший рахунок — з нього далі виростуть обидва просторові.

```
x = r·cos φ ,  y = r·sin φ

    ⎡ ∂x/∂r   ∂x/∂φ ⎤   ⎡ cos φ   −r·sin φ ⎤
J = ⎢               ⎥ = ⎢                  ⎥
    ⎣ ∂y/∂r   ∂y/∂φ ⎦   ⎣ sin φ    r·cos φ ⎦

det J = cos φ · (r·cos φ) − (−r·sin φ) · sin φ
      = r·(cos²φ + sin²φ) = r

dx dy = r · dr dφ
```

Найдешевша перевірка — площа круга радіуса R, для якої відповідь відома наперед:

```
∫ dφ · ∫ r dr        φ: 0 → 2π ,  r: 0 → R

= 2π · R²/2 = π·R²
```

## Циліндричні координати

Тут до полярних додається третя координата, яка переходить сама в себе без жодних змін. Параметри — (ρ, φ, z):

```
x = ρ·cos φ ,  y = ρ·sin φ ,  z = z

    ⎡ cos φ   −ρ·sin φ   0 ⎤
J = ⎢ sin φ    ρ·cos φ   0 ⎥
    ⎣   0         0      1 ⎦
```

Розкладаємо за останнім рядком: два його елементи нульові, тож лишається один доданок зі знаком (−1)³⁺³ = +1.

```
det J = 1 · [ cos φ · (ρ·cos φ) − (−ρ·sin φ) · sin φ ] = ρ

dx dy dz = ρ · dρ dφ dz
```

Мінор 2×2 у лівому верхньому куті — це рівно полярний якобіан. Змістовно нового нічого й не мало з'явитися: вісь z не розтягується, тому множник збігається з плоским.

## Сферичні координати

Кут θ рахуємо від осі z (0 ≤ θ ≤ π), кут φ — навколо осі (0 ≤ φ < 2π):

```
x = r·sin θ·cos φ ,  y = r·sin θ·sin φ ,  z = r·cos θ
```

Дев'ять частинних похідних:

```
∂x/∂r = sin θ·cos φ    ∂x/∂θ =  r·cos θ·cos φ    ∂x/∂φ = −r·sin θ·sin φ
∂y/∂r = sin θ·sin φ    ∂y/∂θ =  r·cos θ·sin φ    ∂y/∂φ =  r·sin θ·cos φ
∂z/∂r = cos θ          ∂z/∂θ = −r·sin θ          ∂z/∂φ =  0
```

Розкладаємо за третім рядком — саме там є нуль, отже й роботи менше:

```
det J = (+1)·(cos θ)·M₃₁  +  (−1)·(−r·sin θ)·M₃₂  +  (+1)·0·M₃₃
```

де M₃ⱼ — визначник матриці 2×2, що лишається після викреслення третього рядка й j-го стовпця:

```
      ⎡ r·cos θ·cos φ   −r·sin θ·sin φ ⎤
M₃₁ = ⎢                                ⎥
      ⎣ r·cos θ·sin φ    r·sin θ·cos φ ⎦

    = (r·cos θ·cos φ)·(r·sin θ·cos φ) − (−r·sin θ·sin φ)·(r·cos θ·sin φ)
    = r²·sin θ·cos θ·cos²φ + r²·sin θ·cos θ·sin²φ
    = r²·sin θ·cos θ

      ⎡ sin θ·cos φ   −r·sin θ·sin φ ⎤
M₃₂ = ⎢                              ⎥
      ⎣ sin θ·sin φ    r·sin θ·cos φ ⎦

    = (sin θ·cos φ)·(r·sin θ·cos φ) − (−r·sin θ·sin φ)·(sin θ·sin φ)
    = r·sin²θ·cos²φ + r·sin²θ·sin²φ
    = r·sin²θ
```

Складаємо докупи:

```
det J = cos θ · (r²·sin θ·cos θ)  +  (r·sin θ) · (r·sin²θ)
      = r²·sin θ·cos²θ + r²·sin³θ
      = r²·sin θ·(cos²θ + sin²θ)
      = r²·sin θ
```

На проміжку 0 ≤ θ ≤ π синус невід'ємний, тому модуль тут нічого не змінює: dx dy dz = r²·sin θ · dr dθ dφ.

Той самий результат читається з малюнка, без жодної алгебри. Ребра клітинки — це три рухи від точки. Рух уздовж променя дає ребро довжиною dr. Рух по меридіану — дуга кола радіуса r, тобто довжина r·dθ. А рух по паралелі — дуга кола, радіус якого не r, а відстань від точки до осі z, тобто r·sin θ; звідси третє ребро r·sin θ·dφ. Три ребра майже перпендикулярні, тож об'єм — їхній добуток.

![Ліворуч меридіанний переріз із відстанню r·sin θ до осі z, праворуч клітинка з трьома підписаними ребрами](/book/math/linear-algebra/jacobian-matrix/img/sphere-cell.svg)

*Визначник підтвердив те, що видно оком: біля полюсів паралелі коротшають, і клітинка з тими самими dθ і dφ там займає менший об'єм.*

Перевірка — об'єм кулі радіуса R:

```
∫ dφ · ∫ sin θ dθ · ∫ r² dr      φ: 0 → 2π ,  θ: 0 → π ,  r: 0 → R

= 2π · 2 · R³/3 = (4/3)·π·R³
```

## Знак визначника й точки, де він нульовий

**Знак.** Визначник має знак, а об'єм не має — тому у формулі стоїть модуль, і на цьому кроці частина відомостей губиться свідомо. Вона не завжди зайва: det J > 0 означає, що відображення зберігає орієнтацію, det J < 0 — що перевертає її. Там, де сам інтеграл орієнтований — потік крізь поверхню з вибраним боком, робота вздовж напрямленого шляху, інтеграли [зовнішніх форм](book:math/exterior-product) — знак несе зміст, і заміна змінних із від'ємним визначником міняє знак результату. У формулі для площі та об'єму він не потрібен саме тому, що площа за побудовою невід'ємна.

**Нуль.** Де det J = 0, виведення розсипається на першому ж кроці. Стовпці J стають лінійно залежними, паралелограм на них сплющується у відрізок, площа образу в першому наближенні нульова — а це означає, що відкинуті доданки другого порядку більше не поправки, вони і є вся відповідь. Наближення «образ клітинки ≈ паралелограм» втрачає силу, бо порівнювати вже нема з чим.

Заразом гине й взаємна однозначність, на якій трималося «образи клітинок не налазять». Полярні координати — найпростіший приклад: при r = 0 визначник нульовий, і справді, увесь відрізок значень φ переходить в одну-єдину точку. Сферичні мають ту саму біду вздовж усієї осі z: при θ = 0 і при θ = π визначник r²·sin θ обертається в нуль, а кут φ перестає щось означати.

Чому ж тоді полярними координатами спокійно рахують інтеграли по кругу, який містить центр? Бо погана множина дрібна. Формула вимагає взаємної однозначності й ненульового визначника не всюди, а всюди поза множиною нульової площі — точкою, кривою, у трьох вимірах поверхнею. Такий виняток нічого не важить під інтегралом: викиньте з круга центр — інтеграл не зміниться. Тому r = 0 і вісь z не заважають. Заважало б інше — ділянка ненульової площі, на якій визначник тотожно нульовий: там координати справді злипаються, і жодна формула цього не врятує.

А твердження в протилежний бік ще корисніше: якщо det J(p) ≠ 0 і частинні похідні неперервні, то в деякому околі точки p відображення оборотне — це [теорема про обернену функцію](book:math/inverse-function-theorem). Тобто ненульовий визначник не просто дозволяє множити на |det J|; він гарантує, що вибрані [криволінійні координати](book:math/curvilinear-coordinates) справді є координатами — кожній точці околу відповідає рівно один набір параметрів.
