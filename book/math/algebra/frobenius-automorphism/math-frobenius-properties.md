# 🧮 Алгебра та геометрія відображення Фробеніуса: від теорії Галуа до межі Хассе

Відображення піднесення до степеня характеристики у комутативних кільцях та полях володіє винятковими алгебраїчними властивостями, які не мають аналогів у класичному аналізі над дійсними чи комплексними числами. Якщо у полі дійсних чисел піднесення до степеня є нелінійною операцією, яка спотворює суму двох чисел, то у полях простої характеристики `p` операція `x ↦ x^p` перетворюється на точний ендоморфізм кільця, що зберігає як множення, так і додавання.

Розглянемо послідовне строге математичне обґрунтування властивостей цього відображення: від фундаментальної леми про подільність біноміальних коефіцієнтів до структури групи Галуа скінченних розширень, слідів лінійних операторів на модулях Тейта, критерію Хассе для звичайних та суперсингулярних кривих, теорії Серра — Тейта, кристалічних когомологій Дьєдонне, дзета-функцій Вейля та геометричного доведення теореми Хассе про кількість точок на еліптичних кривих.

### 1. Лема про подільність біноміальних коефіцієнтів та «мрія першокурсника»

Нехай `p` — фіксоване просте натуральне число (`p ∈ {2, 3, 5, 7, 11, ...}`). Розглянемо біноміальний коефіцієнт `C(p, k)`, який визначає кількість способів обрати `k` елементів із множини обсягом `p` без урахування порядку:

```
C(p, k) = p! / (k! · (p - k)!)
```

де знак оклику `!` позначає факторіал — добуток усіх натуральних чисел від `1` до заданого числа.

**Лема (про подільність біноміальних коефіцієнтів).** Для будь-якого простого числа `p` та для кожного цілого індексу `k`, який задовольняє подвійну нерівність `1 ≤ k ≤ p - 1`, біноміальний коефіцієнт `C(p, k)` ділиться на просте число `p` націло:

```
C(p, k) ≡ 0 (mod p)   при 1 ≤ k ≤ p - 1
```

**Доведення.**
Розпишемо факторіальну формулу біноміального коефіцієнта, явно виділивши множник `p` у чисельнику:

```
C(p, k) · k! · (p - k)!
= p!                          [означення біноміального коефіцієнта]
= p · (p - 1)!                [винесення старшого множника p з факторіала]
```

Звідси отримуємо рівність цілих чисел:

```
k! · (p - k)! · C(p, k) = p · (p - 1)!
```

Оскільки просте число `p` ділить праву частину цієї рівності (`p | p · (p - 1)!`), воно зобов'язане ділити і ліву частину:

```
p | (k! · (p - k)! · C(p, k))
```

За основною властивістю простих чисел (лема Евкліда), якщо просте число `p` ділить добуток кількох цілих множників, воно має ділити хоча б один із них. Дослідимо окремо факторіали `k!` та `(p - k)!`:

1. Факторіал `k! = 1 · 2 · 3 · … · k` є добутком натуральних чисел, кожне з яких строго менше за `p` (оскільки за умовою `k ≤ p - 1`). Оскільки всі множники менші за просте число `p`, число `p` є взаємно простим із кожним із них, а отже, `p` не може ділити `k!` (найбільший спільний дільник `НСД(p, k!) = 1`).
2. Аналогічно, факторіал `(p - k)! = 1 · 2 · 3 · … · (p - k)` складається з множників, найбільший з яких дорівнює `p - k ≤ p - 1 < p`. Отже, `НСД(p, (p - k)!) = 1`, тобто `p` не ділить `(p - k)!`.

Оскільки `p` не ділить ані `k!`, ані `(p - k)!`, єдиним множником у лівій частині, який може містити простий дільник `p`, є сам біноміальний коефіцієнт `C(p, k)`. Отже, `p` ділить `C(p, k)` націло: `C(p, k) = p · M`, де `M` — ціле число. Лему доведено.

**Теорема (Адитивність піднесення до степеня p).** Нехай `R` — комутативне кільце з простою характеристикою `p` (тобто для будь-якого елемента `x ∈ R` сума `p` копій `x + x + … + x = p · x = 0`). Тоді для будь-яких двох елементів `a, b ∈ R` виконується рівність:

```
(a + b)^p = a^p + b^p
```

**Доведення.**
Оскільки кільце `R` є комутативним, застосуємо класичну формулу бінома Ньютона:

```
(a + b)^p
= ∑ₖ₌₀ᵖ C(p, k) · a^(p - k) · b^k           [біноміальна теорема у комутативному кільці]
= C(p, 0)·a^p + (∑ₖ₌₁ᵖ⁻¹ C(p, k)·a^(p-k)·b^k) + C(p, p)·b^p  [виділення першого та останнього доданків]
= 1·a^p + (∑ₖ₌₁ᵖ⁻¹ (p · Mₖ)·a^(p-k)·b^k) + 1·b^p               [застосування леми про подільність C(p, k) = p·Mₖ]
= a^p + (∑ₖ₌₁ᵖ⁻¹ Mₖ·a^(p-k)·b^k · (p · 1_R)) + b^p           [винесення множника p за дистрибутивністю]
= a^p + (∑ₖ₌₁ᵖ⁻¹ Mₖ·a^(p-k)·b^k · 0) + b^p                   [характеристика кільця char(R) = p, отже p·1_R = 0]
= a^p + 0 + b^p                                              [множення на нуль кільця]
= a^p + b^p
```

Рівність доведено. Відображення `σ: R → R`, задане правилом `σ(x) = x^p`, є ендоморфізмом кільця `R`.

### 2. Структура групи Галуа скінченних полів та породжуючий автоморфізм

Нехай `K = GF(p)` — просте скінченне поле з `p` елементів (поле лишків `ℤ/pℤ`), а `E = GF(pⁿ)` — його скінченне розширення степеня `n = [E : K]`. Кількість елементів поля `E` дорівнює `q = pⁿ`.

Розглянемо відображення Фробеніуса `σ: E → E`, `σ(x) = x^p`.

**Властивість 1 (Ін'єктивність та сюр'єктивність).** Відображення `σ` є автоморфізмом поля `E`.
*Доведення.* Оскільки `E` є полем, будь-який гомоморфізм полів `σ: E → E` є строго ін'єктивним, оскільки поле не має нетривіальних ідеалів (якщо `σ(x) = 0`, то `x^p = 0`, звідки через відсутність дільників нуля `x = 0`, тобто ядро `Ker(σ) = {0}`). Оскільки множина `E` є скінченною, будь-яке ін'єктивне відображення скінченної множини в себе є бієктивним (сюр'єктивним). Отже, `σ` є ізоморфізмом поля `E` на себе, тобто автоморфізмом: `σ ∈ Aut(E)`.

**Властивість 2 (Фіксоване поле).** Елемент `x ∈ E` задовольняє рівність `σ(x) = x` тоді й лише тоді, коли `x ∈ K = GF(p)`.
*Доведення.* Рівність `σ(x) = x` еквівалентна поліноміальному рівнянню `x^p - x = 0`. За малою теоремою Ферма кожен із `p` елементів простого поля `GF(p)` є коренем цього рівняння: `c^p = c` для всіх `c ∈ GF(p)`. Оскільки многочлен `X^p - X` степеня `p` над полем `E` може мати не більше ніж `p` коренів, усі його корені вичерпуються елементами базового поля `GF(p)`. Отже, поле фіксованих точок:

```
Fix(σ) = {x ∈ E : σ(x) = x} = GF(p)
```

**Теорема (Циклічність групи Галуа розширення скінченних полів).** Розширення `E/K = GF(pⁿ)/GF(p)` є нормальним і сепарабельним (тобто розширенням Галуа). Група Галуа `Gal(E/K)` є циклічною групою порядку `n`, яка породжується автоморфізмом Фробеніуса:

```
Gal(GF(pⁿ)/GF(p)) = ⟨σ⟩ = {id, σ, σ², σ³, …, σⁿ⁻¹}
```

**Доведення.**
Розглянемо степені автоморфізму `σ` в групі `Aut(E)`:
Для довільного натурального числа `k ≥ 1` дія `k`-ї ітерації `σᵏ` на елемент `x ∈ E` має вигляд:

```
σᵏ(x) = x^(pᵏ)
```

Поле фіксованих точок автоморфізму `σᵏ` складається з коренів многочлена `X^(pᵏ) - X = 0`. Цей многочлен має рівно `pᵏ` різних коренів, які утворюють підполе `GF(pᵏ) ⊆ E`.

Якщо `k < n`, то степінь `pᵏ < pⁿ`, отже підполе `GF(pᵏ)` є строгою підмножиною поля `E`. Це означає, що існують елементи `y ∈ E \ GF(pᵏ)`, для яких `σᵏ(y) = y^(pᵏ) ≠ y`. Отже, відображення `σᵏ` не є тотожним: `σᵏ ≠ id` при `1 ≤ k < n`.

Коли ж `k = n`, за властивістю скінченних полів мультиплікативна група `E* = GF(pⁿ) \ {0}` має порядок `pⁿ - 1`. За теоремою Лагранжа для кожного ненульового елемента `x ∈ E*` виконується `x^(pⁿ - 1) = 1`, звідки множенням на `x` отримуємо `x^(pⁿ) = x`. Для нульового елемента `0^(pⁿ) = 0`. Отже, для всіх без винятку `x ∈ E`:

```
σⁿ(x) = x^(pⁿ) = x   ⇒   σⁿ = id
```

Таким чином, порядок автоморфізму `σ` в групі `Aut(E)` дорівнює точно `n`.

З іншого боку, за фундаментальною теоремою теорії полів порядок групи автоморфізмів розширення степеня `n` не може перевищувати степінь розширення: `|Gal(E/K)| ≤ [E : K] = n`.
Оскільки циклічна підгрупа `⟨σ⟩ = {id, σ, σ², …, σⁿ⁻¹}` уже містить `n` різних автоморфізмів, уся група Галуа складається виключно зі степенів `σ`:

```
Gal(GF(pⁿ)/GF(p)) = ⟨σ⟩ ≅ ℤ/nℤ
```

Теорему доведено.

### 3. Слід та норма через ітерації Фробеніуса

Для скінченного розширення Галуа `E/K = GF(pⁿ)/GF(p)` операції сліду `Tr_{E/K}` та норми `N_{E/K}` визначаються як сума та добуток усіх спряжених елементів під дією групи Галуа:

```
Tr_{E/K}(x) = ∑ᵢ₌₀ⁿ⁻¹ σⁱ(x) = x + x^p + x^(p²) + … + x^(pⁿ⁻¹)
N_{E/K}(x)  = ∏ᵢ₌₀ⁿ⁻¹ σⁱ(x) = x · x^p · x^(p²) · … · x^(pⁿ⁻¹)
```

За законами дій зі степенями згортаємо добуток для норми:

```
N_{E/K}(x)
= x^(1 + p + p² + … + pⁿ⁻¹)          [додавання показників степенів при множенні]
= x^((pⁿ - 1) / (p - 1))             [формула суми геометричної прогресії]
```

**Теорема (Властивості сліду та норми):**
1. Для будь-якого `x ∈ E` значення `Tr_{E/K}(x) ∈ GF(p)` та `N_{E/K}(x) ∈ GF(p)`.
2. Слід є лінійним відображенням над `GF(p)`: `Tr(a·x + b·y) = a·Tr(x) + b·Tr(y)` для `a, b ∈ GF(p)`.
3. Слід є невиродженим: відображення `Tr_{E/K}: E → GF(p)` є сюр'єктивним, і його ядро має розмірність `n - 1` як векторний простір над `GF(p)`.

*Доведення інваріантності під дією Фробеніуса:*
Застосуємо автоморфізм Фробеніуса `σ` до значення сліду:

```
σ(Tr_{E/K}(x))
= (x + x^p + x^(p²) + … + x^(pⁿ⁻¹))^p                [означення сліду]
= x^p + (x^p)^p + … + (x^(pⁿ⁻¹))^p + x^(pⁿ)          [адитивність Фробеніуса]
= x^p + x^(p²) + … + x^(pⁿ) + x                      [оскільки x^(pⁿ) = x]
= x + x^p + x^(p²) + … + x^(pⁿ⁻¹)                    [перестановка доданків]
= Tr_{E/K}(x)
```

Оскільки `σ(Tr(x)) = Tr(x)`, за властивістю фіксованого поля значення сліду належить базовому полю: `Tr_{E/K}(x) ∈ Fix(σ) = GF(p)`.

### 4. Дія Фробеніуса на модулях Тейта та характеристичний многочлен

Для еліптичної кривої `E` над скінченним полем `GF(q)` найглибше розуміння ендоморфізму Фробеніуса `π: (x, y) ↦ (x^q, y^q)` досягається через його дію на точках скінченного кручення.

Для будь-якого простого числа `l`, не рівного характеристиці поля `char(GF(q)) = p`, група точок `lⁿ`-кручення над алгебраїчним замиканням ізоморфна прямому добутку двох циклічних груп: `E[lⁿ] ≅ (ℤ/lⁿℤ) × (ℤ/lⁿℤ)`. Проективна границя цих груп за всіма степенями `n` утворює **модуль Тейта**:

```
T_l(E) = lim E[lⁿ] ≅ ℤ_l × ℤ_l
```

Модуль Тейта `T_l(E)` є вільним модулем рангу 2 над кільцем `l`-адичних цілих чисел `ℤ_l`. Ендоморфізм Фробеніуса `π` діє на `T_l(E)` як лінійний оператор, який у фіксованому базисі задається матрицею розміру `2 × 2` з `l`-адичними коефіцієнтами:

```
[π] = [ a   b ]
      [ c   d ]    де a, b, c, d ∈ ℤ_l
```

Характеристичний многочлен цього лінійного оператора має вигляд:

```
P(T) = det(T · I - [π]) = T² - Tr(π) · T + det(π) = T² - t · T + q
```

де:
- Слід матриці `Tr(π) = a + d = t` є звичайним цілим числом `t ∈ ℤ`, яке не залежить від вибору простого числа `l`.
- Визначник матриці `det(π) = ad - bc = deg(π) = q` дорівнює степеню відображення Фробеніуса.

За класичною теоремою Гамільтона — Келі будь-який лінійний оператор задовольняє свій власний характеристичний многочлен. Звідси випливає фундаментальне операторне рівняння на кільці ендоморфізмів `End(E)`:

```
π² - t · π + q = 0
```

Цей результат пов'язує лінійну алгебру модулів Тейта з геометрією кривої. Кількість точок кривої над базовим полем виражається через визначник оператора `id - π`:

```
#E(GF(q)) = det(I - [π]) = 1 - Tr(π) + det(π) = q + 1 - t
```

### 5. Критерій Хассе, канонічні підйоми Серра — Тейта та кристалічні модулі

Дія автоморфізму Фробеніуса на просторі регулярних диференціалів `H⁰(E, Ω¹)` дозволяє розділити всі еліптичні криві в характеристиці `p` на два принципово різні класи:

1. **Звичайні криві (ordinary curves)**: криві, для яких слід Фробеніуса не ділиться на характеристику поля: `t ≢ 0 (mod p)`. Для таких кривих група точок `p`-кручення над алгебраїчним замиканням ізоморфна циклічній групі `E[p] ≅ ℤ/pℤ`. Кільце ендоморфізмів `End(E)` є порядком в уявному квадратичному числовому полі.
2. **Суперсингулярні криві (supersingular curves)**: криві, для яких слід Фробеніуса ділиться на `p`: `t ≡ 0 (mod p)`. Для таких кривих група точок `p`-кручення є тривіальною: `E[p] = {𝒪}`. Кільце ендоморфізмів над алгебраїчним замиканням є максимальним порядком у тілі кватерніонів рангу 4 над `ℚ`.

Гельмут Хассе довів, що для еліптичної кривої `y² = x³ + Ax + B` над полем `GF(p)` (при `p ≥ 5`) слід Фробеніуса за модулем `p` визначається коефіцієнтом при `x^(p - 1)` у многочлені `(x³ + Ax + B)^((p - 1) / 2)`:

```
t ≡ - [коефіцієнт при x^(p - 1) у (x³ + Ax + B)^((p - 1) / 2)] (mod p)
```

Цей елегантний критерій дозволяє миттєво визначати суперсингулярність кривої через алгебраїчний розклад біноміальних коефіцієнтів без обчислення координат окремих точок.

У теорії деформацій Серра — Тейта для звичайних еліптичних кривих доведено існування єдиного **канонічного підйому** (англ. *canonical lift*) кривої `E` з поля характеристики `p` у поле нульової характеристики (кільце векторів Вітта `W(GF(q))`), на якому ендоморфізм Фробеніуса комутує з усіма ендоморфізмами вихідної кривої. Для суперсингулярних кривих такого канонічного підйому не існує, що відображає максимальну неабелеву симетрію їхніх кватерніонних кілець ендоморфізмів.

У теорії кристалічних когомологій Дьєдонне над кільцем векторів Вітта `W(GF(q))` оператор Фробеніуса діє на модулі Дьєдонне `M(E)` рангу 2. Характеристичний многочлен цього кристалічного оператора в точності дорівнює `T² - t·T + q`, що доводить повну узгодженість між `l`-адичними когомологіями етального типу та `p`-адичною диференціальною теорією.

### 6. Локальні дзета-функції Вейля та гіпотеза Рімана для кривих

Локальна дзета-функція кривої `E` над полем `GF(q)` визначається як формальний степеневий ряд, що кодує кількість точок кривої у всіх можливих скінченних розширеннях `GF(qⁿ)`:

```
Z(E/GF(q), T) = exp( ∑ₙ₌₁^∞ #E(GF(qⁿ)) · Tⁿ / n )
```

Нехай `α` та `β` — корені характеристичного многочлена `T² - t·T + q = 0` у полі комплексних чисел. За теоремою Вієта:

```
α + β = t,       α · β = q
```

Тоді кількість точок кривої над полем розширення `GF(qⁿ)` виражається через степені власних значень Фробеніуса:

```
#E(GF(qⁿ)) = qⁿ + 1 - (αⁿ + βⁿ)
```

Підставимо цей вираз у степеневий ряд дзета-функції:

```
∑ₙ₌₁^∞ #E(GF(qⁿ)) · Tⁿ / n
= ∑ₙ₌₁^∞ (qⁿ + 1 - αⁿ - βⁿ) · Tⁿ / n                              [підстановка кількості точок через власні значення]
= ∑ₙ₌₁^∞ (qT)ⁿ/n + ∑ₙ₌₁^∞ Tⁿ/n - ∑ₙ₌₁^∞ (αT)ⁿ/n - ∑ₙ₌₁^∞ (βT)ⁿ/n   [розбиття на окремі степеневі ряди]
= -ln(1 - qT) - ln(1 - T) + ln(1 - αT) + ln(1 - βT)               [розклад логарифма -ln(1 - u) = ∑ uⁿ/n]
```

Взявши експоненту від обох частин рівності, отримуємо раціональний дріб:

```
Z(E/GF(q), T) = (1 - αT)(1 - βT) / ((1 - T)(1 - qT)) = (1 - t·T + q·T²) / ((1 - T)(1 - qT))
```

Це доводить першу гіпотезу Вейля (раціональність дзета-функції). Знаменник `(1 - T)(1 - qT)` відповідає тривіальним когомологіям розмірностей 0 та 2, а чисельник `1 - t·T + q·T²` є характеристичним многочленом автоморфізму Фробеніуса на просторі перших когомологій `H¹(E)`.

### 7. Доведення нерівності Хассе через додатність квадратичної форми

**Теорема Хассе (Нільс Гельмут Хассе, 1934).** Слід ендоморфізму Фробеніуса `t` на еліптичній кривій над `GF(q)` задовольняє фундаментальну нерівність:

```
|t| ≤ 2 · √q
```

звідки кількість точок кривої обмежена інтервалом Хассе:

```
q + 1 - 2·√q ≤ #E(GF(q)) ≤ q + 1 + 2·√q
```

**Доведення.**
Степінь будь-якого ненульового ендоморфізму еліптичної кривої є строго додатним цілим числом: `deg(ψ) > 0` для всіх `ψ ≠ 0`.
Розглянемо лінійну комбінацію ендоморфізмів у кільці `End(E)`:

```
ψ = r · π + s · id
```

де `r` та `s` — довільні цілі числа, не рівні нулю одночасно (`(r, s) ≠ (0, 0)`).

Обчислимо степінь ендоморфізму `ψ`:

```
deg(r·π + s·id)
= (r·π + s·id) · (r·π̂ + s·id)               [добуток із дуальним ендоморфізмом]
= r² · (π · π̂) + r·s · (π + π̂) + s² · id     [дистрибутивне розкриття дужок]
= r² · [deg(π)] + r·s · [Tr(π)] + s² · [1]   [заміна на інваріанти Фробеніуса]
= r² · q + r · s · t + s²                    [підстановка степеня та сліду]
```

Оскільки степінь `deg(ψ) ≥ 0` для будь-якої комбінації цілих чисел `r, s`:

```
q · r² + t · r · s + s² ≥ 0
```

Покладемо `s ≠ 0` і поділимо всю нерівність на додатне дійсне число `s²`. Введемо дійсну змінну `λ = r / s ∈ ℚ`:

```
q · λ² + t · λ + 1 ≥ 0
```

Оскільки ця квадратична функція від дійсної змінної `λ` є невід'ємною на всій множині раціональних чисел `ℚ`, за неперервністю вона невід'ємна для всіх дійсних чисел `λ ∈ ℝ`.

Квадратний тричлен `A·λ² + B·λ + C` з додатним старшим коефіцієнтом `A = q > 0` є невід'ємним для всіх дійсних значень `λ` тоді й лише тоді, коли його дискримінант `Δ` є недодатним (`Δ ≤ 0`):

```
Δ = B² - 4·A·C = t² - 4 · q · 1 ≤ 0
```

Розв'яжемо нерівність відносно `t`:

```
t² ≤ 4 · q
|t| ≤ √(4 · q) = 2 · √q
```

Нерівність Хассе повністю доведено.

### 8. Числові розрахунки: приклади над GF(5) та GF(7)

**Приклад 1: Еліптична крива над GF(5).**
Розглянемо криву:

```
E₁: y² = x³ + x + 1 (mod 5)
```

Перевіримо всі можливі значення `x ∈ {0, 1, 2, 3, 4}` та знайдемо всі розв'язки `(x, y)`:
1. `x = 0`: `y² = 0 + 0 + 1 = 1` → `y = 1` або `y = 4` (дві точки: `(0, 1)`, `(0, 4)`).
2. `x = 1`: `y² = 1 + 1 + 1 = 3` → числа 3 немає серед квадратів у `GF(5)` (`0²=0, 1²=1, 2²=4, 3²=4, 4²=1`), точок немає.
3. `x = 2`: `y² = 8 + 2 + 1 = 11 ≡ 1` → `y = 1` або `y = 4` (дві точки: `(2, 1)`, `(2, 4)`).
4. `x = 3`: `y² = 27 + 3 + 1 = 31 ≡ 1` → `y = 1` або `y = 4` (дві точки: `(3, 1)`, `(3, 4)`).
5. `x = 4`: `y² = 64 + 4 + 1 = 69 ≡ 4` → `y = 2` або `y = 3` (дві точки: `(4, 2)`, `(4, 3)`).

Додавши нейтральну точку на нескінченності `𝒪`, отримуємо загальну кількість точок:

```
#E₁(GF(5)) = 2 + 0 + 2 + 2 + 2 + 1 = 9 точок
```

Обчислимо слід ендоморфізму Фробеніуса:

```
t = q + 1 - #E₁(GF(5)) = 5 + 1 - 9 = -3
```

Перевіримо межу Хассе:

```
2 · √5 ≈ 2 · 2.236 = 4.472
|-3| = 3 ≤ 4.472    [виконується]
```

Характеристичне рівняння Фробеніуса для цієї кривої має вигляд:

```
π² + 3·π + 5 = 0
```

Тепер обчислимо кількість точок цієї самої кривої у квадратичному розширенні `GF(5²) = GF(25)` без прямого підрахунку 25 координат!
За формулою Вейля для розширення степеня `n = 2`:

```
#E₁(GF(5²)) = 5² + 1 - (λ₁² + λ₂²)
```

Обчислимо суму квадратів коренів через теорему Вієта (`λ₁ + λ₂ = -3`, `λ₁ · λ₂ = 5`):

```
λ₁² + λ₂²
= (λ₁ + λ₂)² - 2 · λ₁ · λ₂                  [виділення повного квадрата суми]
= (-3)² - 2 · 5                             [підстановка значень суми та добутку коренів]
= 9 - 10                                    [піднесення до квадрата та перемноження]
= -1                                        [віднімання чисел]
```

Отже, кількість точок над `GF(25)`:

```
#E₁(GF(25)) = 25 + 1 - (-1) = 27 точок
```

**Приклад 2: Еліптична крива над GF(7).**
Розглянемо криву:

```
E₂: y² = x³ + 2 (mod 7)
```

Знайдемо квадрати у полі `GF(7)`: `0² = 0, 1² = 1, 2² = 4, 3² = 2, 4² = 2, 5² = 4, 6² = 1`. Множина квадратичних лишків: `{0, 1, 2, 4}`.

Перевіримо всі координати `x ∈ {0, 1, 2, 3, 4, 5, 6}`:
1. `x = 0`: `y² = 2` → `y = 3` або `y = 4` (2 точки: `(0, 3)`, `(0, 4)`).
2. `x = 1`: `y² = 1 + 2 = 3` → не є квадратом, 0 точок.
3. `x = 2`: `y² = 8 + 2 = 10 ≡ 3` → не є квадратом, 0 точок.
4. `x = 3`: `y² = 27 + 2 = 29 ≡ 1` → `y = 1` або `y = 6` (2 точки: `(3, 1)`, `(3, 6)`).
5. `x = 4`: `y² = 64 + 2 = 66 ≡ 3` → не є квадратом, 0 точок.
6. `x = 5`: `y² = 125 + 2 = 127 ≡ 1` → `y = 1` або `y = 6` (2 точки: `(5, 1)`, `(5, 6)`).
7. `x = 6`: `y² = 216 + 2 = 218 ≡ 1` → `y = 1` або `y = 6` (2 точки: `(6, 1)`, `(6, 6)`).

Разом із точкою на нескінченності `𝒪`:

```
#E₂(GF(7)) = 2 + 0 + 0 + 2 + 0 + 2 + 2 + 1 = 9 точок
```

Слід Фробеніуса:

```
t = 7 + 1 - 9 = -1
```

Перевірка межі Хассе: `|-1| = 1 ≤ 2·√7 ≈ 5.291` (виконується).

Характеристичний многочлен:

```
π² + π + 7 = 0
```

Обчислимо кількість точок у кубічному розширенні `GF(7³) = GF(343)`:
Сума кубів коренів через формули Ньютона — Жірара:

```
λ₁³ + λ₂³
= (λ₁ + λ₂)³ - 3 · λ₁ · λ₂ · (λ₁ + λ₂)      [алгебраїчний розклад суми кубів]
= (-1)³ - 3 · 7 · (-1)                      [підстановка суми λ₁+λ₂ = -1 та добутку λ₁λ₂ = 7]
= -1 + 21                                   [перемноження чисел]
= 20                                        [додавання чисел]
```

Отже, кількість точок над `GF(343)`:

```
#E₂(GF(343)) = 7³ + 1 - (λ₁³ + λ₂³) = 343 + 1 - 20 = 324 точки
```

Ці розрахунки наочно підтверджують, що автоморфізм Фробеніуса та його характеристичний многочлен є найпотужнішим інструментом точного обчислення структурних характеристик еліптичних кривих у будь-яких розширеннях полів.
