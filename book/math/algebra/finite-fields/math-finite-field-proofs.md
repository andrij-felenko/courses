# 🧮 Математичні основи скінченних полів: теореми класифікації та циклічності

Скінченні поля є унікальними алгебраїчними об'єктами, структура яких повністю та однозначно визначається лише двома цілими числами: простою характеристикою `p` та показником розширення `n`. Нижче наведено строгі математичні доведення фундаментальних теорем, що лежать в основі класифікації, циклічної будови та єдиності полів Ґалуа.

---

### Теорема 1: Проста характеристика та степеневий порядок поля

> **Теорема:** Нехай `𝔽` — довільне скінченне поле. Тоді:
> 1. Характеристика поля `char(𝔽)` є простим числом `p`.
> 2. Кількість елементів поля `|𝔽| = q` обов'язково дорівнює цілому степеню простого числа: `q = pⁿ`, де `n = [𝔽 : 𝔽_p] ≥ 1`.

#### Доведення простоти характеристики
Розглянемо канонічний кільцевий гомоморфізм `ψ: ℤ → 𝔽`, що зіставляє кожному цілому числу `k ∈ ℤ` суму `k` копій одиниці поля `1_𝔽`:
```
ψ(k) = k · 1_𝔽 = 1_𝔽 + 1_𝔽 + ... + 1_𝔽   (k разів)
```

Оскільки поле `𝔽` є скінченним, гомоморфізм `ψ` не може бути ін'єктивним (нескінченна множина `ℤ` відображається у скінченну множину `𝔽`). За принципом Діріхле існують такі два цілі числа `k₁ > k₂`, що `ψ(k₁) = ψ(k₂)`. Віднявши одне від одного, отримуємо:
```
ψ(k₁ - k₂) = (k₁ - k₂) · 1_𝔽 = 0_𝔽
```

Множина цілих чисел `k > 0`, для яких `k · 1_𝔽 = 0_𝔽`, є непорожньою. Найменше таке додатне число називається **характеристикою поля** `p = char(𝔽)`.

Припустимо від супротивного, що число `p` є складеним, тобто розкладається на добуток двох менших натуральних чисел `p = a · b`, де `1 < a < p` та `1 < b < p`. Тоді в полі `𝔽` виконується рівність:
```
(a · 1_𝔽) · (b · 1_𝔽)
= (a · b) · (1_𝔽 · 1_𝔽)    [дистрибутивність та асоціативність поля]
= p · 1_𝔽                  [визначення p = a · b]
= 0_𝔽                      [визначення характеристики поля]
```

Оскільки `𝔽` — поле, у ньому відсутні дільники нуля: добуток двох елементів дорівнює нулю тоді й тільки тоді, коли хоча б один із множників дорівнює нулю. Звідси випливає, що або `a · 1_𝔽 = 0_𝔽`, або `b · 1_𝔽 = 0_𝔽`. Але це прямо суперечить тому, що `p` було обрано як *найменше* додатне число з такою властивістю (адже `a < p` та `b < p`). Отже, характеристика `p` обов'язково є простим числом.

#### Доведення порядку q = pⁿ через лінійну алгебру
Оскільки `p` — просте число, образ гомоморфізму `ψ(ℤ)` є підполем поля `𝔽`, ізоморфним простому полю лишків `ℤ/pℤ ≅ 𝔽_p`. Це підполе називається **простим підполем** поля `𝔽`.

Поле `𝔽` можна розглядати як векторний простір над своїм підполем `𝔽_p`. Операція додавання векторів — це додавання елементів у полі `𝔽`, а множення вектора на скаляр — це множення елемента з `𝔽` на елемент із `𝔽_p`.

Оскільки саме поле `𝔽` є скінченним, цей векторний простір має скінченну розмірність над `𝔽_p`. Позначимо цю розмірність як `n = dim_{𝔽_p}(𝔽)`.

Нехай `{e₁, e₂, ..., eₙ}` — довільний лінійний базис простору `𝔽` над `𝔽_p`. Тоді кожен елемент `v ∈ 𝔽` однозначно записується у вигляді лінійної комбінації базисних векторів:
```
v = c₁ · e₁ + c₂ · e₂ + ... + cₙ · eₙ,   де c_i ∈ 𝔽_p
```

Кожен із `n` коефіцієнтів `c_i` можна обрати незалежно серед `p` елементів простого поля `𝔽_p`. За комбінаторним правилом добутку, загальна кількість різних елементів у полі `𝔽` строго дорівнює:
```
|𝔽| = p · p · ... · p (n разів) = pⁿ = q
```
Теорему доведено.

### Теорема 2: Циклічність мультиплікативної групи поля

> **Теорема:** Мультиплікативна група будь-якого скінченного поля `𝔽_q^\times = 𝔽_q \ {0}` є циклічною групою порядку `q - 1`:
> ```
> 𝔽_q^\times ≅ C_{q-1}
> ```
> У полі `𝔽_q` існує щонайменше один елемент `α` (примітивний елемент), степені якого `α⁰, α¹, α², ..., α^(q-2)` вичерпують усі ненульові елементи поля.

#### Алгебраїчна лема про кількість коренів
> **Лема:** Нехай `K` — довільне поле. Многочлен `f(x) ∈ K[x]` ненульового степеня `d = deg(f)` має не більше ніж `d` різних коренів у полі `K`.

*Доведення леми:* Застосуємо математичну індукцію за степенем многочлена `d`.
- База індукції: При `d = 1` многочлен має вигляд `f(x) = a x + b` (де `a ≠ 0`). Рівняння `a x + b = 0` має єдиний корінь `x = -a⁻¹ b`.
- Індукційний крок: Припустимо, що твердження вірне для всіх степенів, менших за `d`. Нехай `f(x)` має корінь `r ∈ K`. За теоремою Безу, многочлен `f(x)` ділиться на `(x - r)` без остачі:
  ```
  f(x) = (x - r) · g(x)
  ```
  де `g(x)` — многочлен степеня `d - 1`. Якщо `s ∈ K` — будь-який інший корінь многочлена `f(x)`, тобто `f(s) = 0`, то:
  ```
  (s - r) · g(s) = 0
  ```
  Оскільки в полі немає дільників нуля і `s ≠ r` (звідки `s - r ≠ 0`), обов'язково виконується `g(s) = 0`. Отже, будь-який інший корінь `f(x)` є коренем `g(x)`. За припущенням індукції, `g(x)` має не більше ніж `d - 1` коренів. Разом із коренем `r` многочлен `f(x)` має щонайбільше `(d - 1) + 1 = d` коренів.

#### Доведення циклічності через функцію Ейлера
Нехай `G = 𝔽_q^\times` — мультиплікативна група поля порядку `N = q - 1`. Група `G` є комутативною (абелевою) скінченною групою.

Для кожного дільника `d` числа `N` (`d | N`) визначимо:
- `ψ(d)` — кількість елементів у групі `G`, які мають порядок строго `d`.

Якщо в групі `G` існує хоча б один елемент `a` порядку `d`, то він породжує циклічну підгрупу `⟨a⟩ = {a⁰, a¹, ..., a^(d-1)}` порядку `d`. Кожен елемент цієї підгрупи задовольняє рівняння:
```
xᵈ = 1 ⟺ xᵈ - 1 = 0
```
За наведеною вище лемою, многочлен `xᵈ - 1` степеня `d` над полем `𝔽_q` може мати не більше ніж `d` коренів. Оскільки всі `d` елементів циклічної підгрупи `⟨a⟩` вже є різними коренями цього многочлена, **інших коренів рівняння `xᵈ - 1 = 0` у всьому полі не існує**.

Це означає, що будь-який елемент групи `G`, порядок якого ділить `d`, обов'язково належить підгрупі `⟨a⟩`.

У будь-якій циклічній групі порядку `d` кількість елементів, що мають точний порядок `d` (тобто є генераторами цієї циклічної підгрупи), строго дорівнює значенню функції Ейлера `φ(d)`. Отже:
- Якщо в `G` немає елементів порядку `d`, то `ψ(d) = 0`.
- Якщо в `G` є хоча б один елемент порядку `d`, то `ψ(d) = φ(d)`.

У будь-якому випадку маємо нерівність:
```
ψ(d) ≤ φ(d)   для кожного d | N
```

Оскільки кожен елемент скінченної групи має певний однозначно визначений порядок `d`, що за теоремою Лагранжа ділить порядок групи `N`, сума кількостей елементів за всіма дільниками `d` повинна дорівнювати загальній кількості елементів групи:
```
∑_{d | N} ψ(d) = N
```

З класичної теорії чисел відома тотожність Ґаусса для функції Ейлера:
```
∑_{d | N} φ(d) = N
```

Порівнюючи дві суми:
```
∑_{d | N} ψ(d) = ∑_{d | N} φ(d) = N
```
Оскільки для кожного доданка виконується `ψ(d) ≤ φ(d)`, а їхні повні суми збігаються, знак нерівності ні для одного дільника не може бути строгим. Отже, для **кожного** дільника `d | N` обов'язково виконується точна рівність:
```
ψ(d) = φ(d)
```

Зокрема, для `d = N = q - 1`:
```
ψ(q - 1) = φ(q - 1)
```
Оскільки для будь-якого натурального `N ≥ 1` значення функції Ейлера `φ(N) ≥ 1`, кількість елементів максимального порядку `q - 1` є строго додатною:
```
ψ(q - 1) ≥ 1
```
У групі `𝔽_q^\times` гарантовано існує елемент порядку `q - 1`. Отже, група є циклічною.

### Теорема 3: Поле розкладу x^q - x та єдиність поля Ґалуа

> **Теорема:** 
> 1. Кожен елемент `a ∈ 𝔽_q` є коренем многочлена `x^q - x = 0`.
> 2. Поле `𝔽_q` є полем розкладу многочлена `f(x) = x^q - x` над простим полем `𝔽_p`.
> 3. Будь-які два скінченні поля однакового порядку `q = pⁿ` є ізоморфними між собою.

#### Доведення тотожності a^q = a
Нехай `a ∈ 𝔽_q`. 
- Якщо `a = 0`, то `0^q = 0`, рівність виконується тривіально.
- Якщо `a ≠ 0`, то `a ∈ 𝔽_q^\times`. Оскільки порядок мультиплікативної групи дорівнює `q - 1`, за теоремою Лагранжа для скінченних груп порядок будь-якого елемента ділить порядок групи. Звідси:
  ```
  a^(q - 1) = 1
  ```
  Помноживши обидві частини на `a`, отримуємо:
  ```
  a^q = a ⟺ a^q - a = 0
  ```
Таким чином, усі `q` різних елементів поля `𝔽_q` є коренями многочлена `x^q - x`.

Оскільки степінь многочлена `x^q - x` дорівнює `q`, він має не більше ніж `q` коренів. Оскільки ми вже знайшли `q` різних коренів (усі елементи поля `𝔽_q`), цей многочлен повністю розпадається на лінійні множники над `𝔽_q`:
```
x^q - x = ∏_{a ∈ 𝔽_q} (x - a)
```

#### Доведення єдиності з точністю до ізоморфізму
Нехай `𝔽` та `𝕂` — два довільні скінченні поля порядку `q = pⁿ`.
1. Обидва поля мають характеристику `p` і містять просте підполе `𝔽_p ≅ ℤ/pℤ`.
2. В обох полях усі елементи є коренями одного й того самого многочлена `f(x) = x^q - x ∈ 𝔽_p[x]`.
3. Обидва поля породжуються над `𝔽_p` коренями цього многочлена, тобто є полями розкладу `f(x)` над `𝔽_p`.

З фундаментальної теореми абстрактної алгебри про поля розкладу (теорема Кронекера — Стейнберга) відомо, що **поле розкладу будь-якого многочлена над фіксованим полем існує і є єдиним з точністю до ізоморфізму**. 

Отже, існує кільцевий ізоморфізм `θ: 𝔽 → 𝕂`. Це доводить, що структура поля `GF(pⁿ)` є абсолютно однозначною.
