# 🧮 Алгоритм Евкліда, тотожність Безу та факторизація в кільці многочленів F[x]

Цей математичний розбір містить строгі алгебраїчні доведення фундаментальних властивостей кільця многочленів над полем `F`: існування та єдиності ділення з остачею, алгоритму Евкліда, поліноміальної тотожності Безу, леми Евкліда для незвідних елементів, теореми про єдиність розкладу на множники (факторіальності кільця `F[x]`), леми Ґаусса про примітивні многочлени, критерію Ейзенштейна для незвідності над полем раціональних чисел `ℚ` та диференціального критерію виявлення кратних коренів. Розуміння цих доведень необхідне для строгого аналізу надійності кодів виправлення помилок (Рід — Соломон, CRC), криптографічних протоколів на еліптичних кривих і побудови розширень полів Ґалуа.

---

### 1. Теорема про ділення многочленів з остачею

Нехай `F` — довільне числове поле (наприклад, поле раціональних чисел `ℚ`, дійсних чисел `ℝ`, комплексних чисел `ℂ` або скінченне поле `𝔽_p`). Розглянемо кільце многочленів від однієї змінної `F[x]`.

**Теорема (про ділення з остачею):**
Для будь-яких двох многочленів `A(x)` та `B(x)` з кільця `F[x]`, де дільник `B(x)` не є нульовим многочленом (`B(x) ≠ 0`), існує єдина пара многочленів `Q(x)` (частка) та `R(x)` (остача) з того самого кільця `F[x]`, для яких виконується рівність:

```
A(x) = Q(x) · B(x) + R(x)
```

де або `R(x) = 0` (ділення без остачі), або степінь остачі строго менший за степінь дільника: `deg R < deg B`.

**Доведення існування (індукція за степенем діленого):**
Нехай степінь дільника дорівнює `deg B = m ≥ 0`, а його старший коефіцієнт позначимо як `bₘ ≠ 0`. Запишемо `B(x)` у розгорнутому вигляді:

```
B(x) = bₘ·xᵐ + bₘ₋₁·xᵐ⁻¹ + … + b₁·x + b₀
```

Якщо `A(x) = 0` або `deg A < m`, твердження тривіально виконується: обираємо `Q(x) = 0` та `R(x) = A(x)`. Тоді рівність `A(x) = 0 · B(x) + A(x)` істинна, а умова `deg R < deg B` забезпечена.

Припустимо тепер, що твердження істинне для всіх многочленів зі степенем, строго меншим за `n` (де `n ≥ m`). Розглянемо многочлен `A(x)` степеня `deg A = n`:

```
A(x) = aₙ·xⁿ + aₙ₋₁·xⁿ⁻¹ + … + a₁·x + a₀    (aₙ ≠ 0)
```

Сконструюємо одночлен `M(x) = (aₙ / bₘ) · xⁿ⁻ᵐ`. Оскільки коефіцієнти належать полю `F`, а `bₘ ≠ 0`, ділення коефіцієнтів `aₙ / bₘ` завжди коректно визначене в полі `F`.

Помножимо `B(x)` на `M(x)`:

```
M(x) · B(x)
= ((aₙ / bₘ) · xⁿ⁻ᵐ) · (bₘ·xᵐ + bₘ₋₁·xᵐ⁻¹ + … + b₀)   [підстановка одночлена M(x) та многочлена B(x)]
= aₙ·xⁿ + (aₙ · bₘ₋₁ / bₘ)·xⁿ⁻¹ + …                   [розкриття дужок: (aₙ/bₘ)·bₘ = aₙ, додавання степенів]
```

Старший член утвореного добутку дорівнює `aₙ·xⁿ`, що точно збігається зі старшим членом многочлена `A(x)`. Розглянемо різницю:

```
A₁(x) = A(x) - M(x) · B(x)
```

При відніманні старші члени `aₙ·xⁿ - aₙ·xⁿ = 0` взаємно знищуються. Отже, степінь нового многочлена задовольняє нерівність `deg A₁ ≤ n - 1 < n`.

За індукційним припущенням, для многочлена `A₁(x)` нижчого степеня вже існують частка `Q₁(x)` та остача `R(x)` такі, що:

```
A₁(x) = Q₁(x) · B(x) + R(x)    [де deg R < deg B або R = 0]
```

Підставимо вираз для `A₁(x)` у початкову формулу:

```
A(x) - M(x) · B(x) = Q₁(x) · B(x) + R(x)
A(x) = (M(x) + Q₁(x)) · B(x) + R(x)
```

Позначивши повну частку як `Q(x) = M(x) + Q₁(x)`, отримуємо шуканий розклад `A(x) = Q(x) · B(x) + R(x)`. Існування доведено.

**Доведення єдиності:**
Припустимо, що існують дві різні пари часток та остач `(Q₁, R₁)` та `(Q₂, R₂)`, які задовольняють умови теореми:

```
A(x) = Q₁(x) · B(x) + R₁(x)    [з умовою deg R₁ < deg B або R₁ = 0]
A(x) = Q₂(x) · B(x) + R₂(x)    [з умовою deg R₂ < deg B або R₂ = 0]
```

Прирівняємо обидва вирази для `A(x)`:

```
Q₁(x) · B(x) + R₁(x) = Q₂(x) · B(x) + R₂(x)
(Q₁(x) - Q₂(x)) · B(x) = R₂(x) - R₁(x)
```

Припустимо від супротивного, що `Q₁(x) ≠ Q₂(x)`. Тоді різниця `Q₁(x) - Q₂(x)` є ненульовим многочленом зі степенем `deg(Q₁ - Q₂) ≥ 0`.

Оскільки `F` є полем, у кільці `F[x]` відсутні дільники нуля, і для добутку ненульових многочленів степінь дорівнює сумі степенів:

```
deg((Q₁ - Q₂) · B) = deg(Q₁ - Q₂) + deg B ≥ deg B
```

З іншого боку, права частина є різницею двох остач `R₂(x) - R₁(x)`. Оскільки степені обох остач строго менші за `deg B`, степінь їхньої різниці також строго менший за `deg B`:

```
deg(R₂ - R₁) ≤ max(deg R₁, deg R₂) < deg B
```

Маємо очевидну суперечність: вираз у лівій частині має степінь `≥ deg B`, тоді як тотожно рівний йому вираз у правій частині має степінь `< deg B`.

Ця суперечність доводить, що припущення `Q₁(x) ≠ Q₂(x)` було хибним. Отже, `Q₁(x) - Q₂(x) = 0`, тобто `Q₁(x) = Q₂(x)`.

Звідси негайно випливає:

```
R₂(x) - R₁(x) = 0 · B(x) = 0  ⇒  R₁(x) = R₂(x)
```

Єдиність частки та остачі повністю доведено.

### 2. Алгоритм Евкліда та тотожність Безу в F[x]

Оскільки для довільних многочленів визначено ділення з остачею, кільце `F[x]` є евклідовим кільцем (і, як наслідок, кільцем головних ідеалів).

**Означення НСД:**
Найбільшим спільним дільником двох многочленів `A(x)` та `B(x)` (позначається `gcd(A, B)`) називається унітарний многочлен `D(x)` (старший коефіцієнт якого дорівнює `1`), який ділить `A(x)` та `B(x)` без остачі, і ділиться на будь-який інший спільний дільник цих многочленів.

**Алгоритм Евкліда:**
Застосуємо послідовне ділення з остачею, починаючи з `R₀(x) = A(x)` та `R₁(x) = B(x)`:

```
R₀(x) = Q₁(x) · R₁(x) + R₂(x)        [deg R₂ < deg R₁]
R₁(x) = Q₂(x) · R₂(x) + R₃(x)        [deg R₃ < deg R₂]
R₂(x) = Q₃(x) · R₃(x) + R₄(x)        [deg R₄ < deg R₃]
…
Rₖ₋₂(x) = Qₖ₋₁(x) · Rₖ₋₁(x) + Rₖ(x)   [deg Rₖ < deg Rₖ₋₁]
Rₖ₋₁(x) = Qₖ(x) · Rₖ(x) + 0          [остача дорівнює нулю]
```

Оскільки послідовність натуральних чисел `deg R₁ > deg R₂ > deg R₃ > … ≥ 0` строго спадає, процес гарантовано завершується за скінченну кількість кроків `k ≤ deg B + 1`. Остання ненульова остача `Rₖ(x)` (після нормування на свій старший коефіцієнт) є шуканим найбільшим спільним дільником `gcd(A, B)`.

**Теорема (Поліноміальна тотожність Безу):**
Для будь-яких двох многочленів `A(x), B(x) ∈ F[x]` існують такі многочлени `U(x), V(x) ∈ F[x]`, що:

```
A(x) · U(x) + B(x) · V(x) = gcd(A(x), B(x))
```

**Доведення через розширений алгоритм Евкліда (зворотний хід):**
З передостаннього рядка алгоритму Евкліда виразимо останню ненульову остачу `Rₖ(x)`:

```
Rₖ(x) = Rₖ₋₂(x) - Qₖ₋₁(x) · Rₖ₋₁(x)
```

З попереднього рядка виразимо `Rₖ₋₁(x) = Rₖ₋₃(x) - Qₖ₋₂(x) · Rₖ₋₂(x)` і підставимо замість `Rₖ₋₁`:

```
Rₖ(x)
= Rₖ₋₂(x) - Qₖ₋₁(x) · (Rₖ₋₃(x) - Qₖ₋₂(x) · Rₖ₋₂(x))           [підстановка виразу для Rₖ₋₁ з попереднього кроку]
= (1 + Qₖ₋₁(x) · Qₖ₋₂(x)) · Rₖ₋₂(x) - Qₖ₋₁(x) · Rₖ₋₃(x)       [розкриття дужок і винесення спільного множника Rₖ₋₂]
```

Повторюючи цю процедуру підстановки крок за кроком вгору до початкових `R₀ = A` та `R₁ = B`, на фінальному кроці отримуємо лінійну комбінацію:

```
Rₖ(x) = A(x) · U₀(x) + B(x) · V₀(x)
```

Нормуючи многочлен `Rₖ(x)` діленням на його старший коефіцієнт `c` (де `c ∈ F, c ≠ 0`), покладемо `D(x) = Rₖ(x) / c`, `U(x) = U₀(x) / c`, `V(x) = V₀(x) / c`. Отримуємо тотожність Безу: `A(x)·U(x) + B(x)·V(x) = D(x)`.

### 3. Лема Евкліда та єдиність факторизації в F[x]

**Означення незвідного многочлена:**
Многочлен `P(x) ∈ F[x]` степеня `deg P ≥ 1` називається **незвідним** (англ. *irreducible*) над полем `F`, якщо його неможливо розкласти у добуток двох многочленів `A(x) · B(x)` нижчих степенів (`deg A ≥ 1`, `deg B ≥ 1`) з коефіцієнтами з того самого поля `F`.

**Лема Евкліда для многочленів:**
Якщо незвідний многочлен `P(x)` ділить добуток двох многочленів `A(x) · B(x)`, то `P(x)` ділить принаймні один із множників: або `P(x) | A(x)`, або `P(x) | B(x)`.

**Доведення:**
Припустимо, що `P(x)` не ділить `A(x)`. Оскільки `P(x)` є незвідним, його єдиними дільниками є константи поля або многочлени, асоційовані з `P(x)`. Оскільки `P` не ділить `A`, їхній спільний дільник може бути лише константою:

```
gcd(P(x), A(x)) = 1
```

За тотожністю Безу існують многочлени `U(x), V(x) ∈ F[x]` такі, що:

```
P(x) · U(x) + A(x) · V(x) = 1
```

Помножимо обидві частини цієї рівності на многочлен `B(x)`:

```
B(x) · P(x) · U(x) + B(x) · A(x) · V(x) = B(x)
P(x) · (B(x) · U(x)) + (A(x) · B(x)) · V(x) = B(x)
```

Розглянемо ліву частину:
1. Перший доданок `P(x) · (B(x) · U(x))` очевидно ділиться на `P(x)`.
2. Другий доданок `(A(x) · B(x)) · V(x)` ділиться на `P(x)`, оскільки за початковою умовою `P(x) | (A(x) · B(x))`.

Отже, вся ліва частина ділиться на `P(x)`. Звідси випливає, що й права частина повинна ділитися на `P(x)`:

```
P(x) | B(x)
```

Лему доведено.

**Основна теорема арифметики для F[x] (Єдиність факторизації):**
Будь-який ненульовий многочлен `A(x) ∈ F[x]` степеня `deg A ≥ 1` єдиним чином (з точністю до порядку співмножників) розкладається у добуток вигляду:

```
A(x) = c · P₁(x) · P₂(x) · … · Pₖ(x)
```

де `c ∈ F` — старший коефіцієнт многочлена `A(x)`, а `P₁(x), …, Pₖ(x)` — унітарні незвідні многочлени над полем `F`.

**Доведення єдиності:**
Припустимо, що існують два розклади:

```
c · P₁(x) · P₂(x) · … · Pₖ(x) = c · Q₁(x) · Q₂(x) · … · Qₘ(x)
P₁(x) · P₂(x) · … · Pₖ(x) = Q₁(x) · Q₂(x) · … · Qₘ(x)
```

Незвідний многочлен `P₁(x)` ділить ліву частину, а отже ділить і добуток `Q₁(x) · … · Qₘ(x)`. За узагальненою лемою Евкліда `P₁(x)` повинен ділити один із множників `Qⱼ(x)`. Без обмеження загальності переставимо множники так, щоб `j = 1`, тобто `P₁(x) | Q₁(x)`.

Оскільки `Q₁(x)` також є незвідним та унітарним многочленом, його єдиним унітарним дільником є він сам:

```
P₁(x) = Q₁(x)
```

Скоротимо обидві частини рівності на `P₁(x)`:

```
P₂(x) · … · Pₖ(x) = Q₂(x) · … · Qₘ(x)
```

Повторюючи процедуру для решти множників за індукцією, отримуємо `k = m` та `Pᵢ(x) = Qᵢ(x)` для всіх `i = 1, …, k`. Єдиність факторизації доведено.

### 4. Лема Ґаусса та критерій Ейзенштейна над ℚ

Як практично з'ясувати, чи є многочлен незвідним над полем раціональних чисел `ℚ`? Зв'язок між факторизацією над цілими числами `ℤ` та над полем `ℚ` встановлює класична лема Ґаусса.

**Означення вмісту та примітивного многочлена:**
Для многочлена з цілими коефіцієнтами `A(x) = aₙ·xⁿ + … + a₀ ∈ ℤ[x]` його **вмістом** (англ. *content*, позначається `cont(A)`) називається найбільший спільний дільник усіх його коефіцієнтів:

```
cont(A) = gcd(aₙ, aₙ₋₁, …, a₁, a₀)
```

Многочлен називається **примітивним**, якщо його вміст дорівнює одиниці: `cont(A) = 1`. Будь-який многочлен `A(x) ∈ ℤ[x]` можна подати як `A(x) = cont(A) · A*(x)`, де `A*(x)` є примітивним.

**Лема Ґаусса:**
Добуток двох примітивних многочленів `A(x)` та `B(x)` у кільці `ℤ[x]` є примітивним многочленом:

```
cont(A · B) = cont(A) · cont(B) = 1
```

**Доведення:**
Припустимо від супротивного, що добуток `C(x) = A(x) · B(x)` не є примітивним. Тоді існує деяке просте число `p`, яке ділить усі коефіцієнти многочлена `C(x)`.

Розглянемо канонічний гомоморфізм редукції за модулем `p`: `π: ℤ[x] → 𝔽_p[x]`, який замінює кожен цілий коефіцієнт на його остачу в полі `𝔽_p`.
Оскільки `p` ділить усі коефіцієнти `C(x)`, редукція добутку дорівнює нулю в кільці `𝔽_p[x]`:

```
π(A) · π(B) = π(A · B) = π(C) = 0
```

Оскільки `𝔽_p` є полем, кільце многочленів `𝔽_p[x]` є областю цілісності (не містить дільників нуля). Отже, або `π(A) = 0`, або `π(B) = 0`.
Рівність `π(A) = 0` означає, що число `p` ділить усі коефіцієнти многочлена `A(x)`, що суперечить умові його примітивності (`cont(A) = 1`). Аналогічно для `B(x)`. Суперечність доводить, що добуток примітивних многочленів є примітивним.

**Головний наслідок леми Ґаусса:**
Якщо многочлен `A(x) ∈ ℤ[x]` є незвідним у кільці цілих многочленів `ℤ[x]`, то він є незвідним і в полі раціональних многочленів `ℚ[x]`.

**Критерій незвідності Ейзенштейна:**
Нехай задано многочлен із цілими коефіцієнтами:

```
P(x) = aₙ·xⁿ + aₙ₋₁·xⁿ⁻¹ + … + a₁·x + a₀    (aₙ ≠ 0)
```

Якщо існує таке просте число `p`, що одночасно виконуються три умови:
1. Просте `p` ділить усі коефіцієнти, крім старшого: `p | aᵢ` для всіх `i = 0, 1, …, n - 1`;
2. Просте `p` не ділить старший коефіцієнт: `p ∤ aₙ`;
3. Квадрат простого числа `p²` не ділить вільний член: `p² ∤ a₀`,

то многочлен `P(x)` є **незвідним** над полем раціональних чисел `ℚ`.

**Доведення критерію Ейзенштейна:**
Припустимо від супротивного, що `P(x)` розкладається над `ℚ`. За наслідком леми Ґаусса він повинен розкладатися і над `ℤ`:

```
P(x) = (bᵣ·xʳ + … + b₀) · (cₛ·xˢ + … + c₀)    (де r + s = n, r ≥ 1, s ≥ 1)
```

Розглянемо вільний член: `a₀ = b₀ · c₀`.
За умовою 1 просте `p | a₀`, тому `p` повинно ділити або `b₀`, або `c₀`. За умовою 3 число `p²` не ділить `a₀`, тому `p` не може ділити обидва множники одночасно. Нехай для визначеності `p | b₀` та `p ∤ c₀`.

Оскільки `p ∤ aₙ = bᵣ · cₛ`, маємо `p ∤ bᵣ`. Отже, не всі коефіцієнти першого многочлена діляться на `p`. Нехай `bₖ` — перший коефіцієнт (найменший індекс `k ≤ r`), який не ділиться на `p`: тобто `p | b₀, p | b₁, …, p | bₖ₋₁`, але `p ∤ bₖ`.

Розглянемо коефіцієнт `aₖ` у добутку:

```
aₖ = (bₖ · c₀) + (bₖ₋₁ · c₁ + bₖ₋₂ · c₂ + … + b₀ · cₖ)
```

Оскільки `k ≤ r < n`, за умовою Ейзенштейна `p | aₖ`. Усі доданки в другій дужці `bₖ₋ᵢ · cᵢ` діляться на `p` за вибором індексу `k`. Отже, доданок `bₖ · c₀ = aₖ - (…) ` також зобов'язаний ділитися на `p`.

Проте `p ∤ bₖ` і `p ∤ c₀`, що суперечить простоті числа `p`. Суперечність доводить, що многочлен `P(x)` неможливо розкласти над `ℚ`.

**Приклад:** многочлен `P(x) = x⁵ - 2` задовольняє критерій Ейзенштейна при `p = 2` (`2 | -2`, `2 ∤ 1`, `4 ∤ -2`), тому він є незвідним над `ℚ`. Аналогічно для будь-якого `n ≥ 1` многочлени `xⁿ - 2` незвідні над `ℚ`, що доводить наявність у `ℚ[x]` незвідних многочленів довільно високого степеня.

### 5. Критерій кратності коренів через формальну похідну

**Означення формальної похідної:**
Для многочлена `P(x) = ∑ₖ aₖ · xᵏ` формальною похідною називається многочлен:

```
P′(x) = ∑ₖ k · aₖ · xᵏ⁻¹
```

Це означення є чисто алгебраїчним і не спирається на аналітичні границі, що робить його чинним над будь-яким полем `F` (включно зі скінченними полями `𝔽_p`).

**Теорема про кратні корені:**
Елемент `r ∈ F` є кратним коренем многочлена `P(x)` (тобто `(x - r)² | P(x)`) тоді й лише тоді, коли `r` є одночасно коренем самого многочлена та його похідної:

```
P(r) = 0   і   P′(r) = 0
```

**Доведення:**
За теоремою Безу, якщо `r` є коренем кратності `m ≥ 1`, многочлен можна подати у вигляді:

```
P(x) = (x - r)ᵐ · Q(x)    [де Q(r) ≠ 0]
```

Обчислимо формальну похідну за правилом диференціювання добутку:

```
P′(x)
= m · (x - r)ᵐ⁻¹ · Q(x) + (x - r)ᵐ · Q′(x)      [правило Лейбніца]
= (x - r)ᵐ⁻¹ · (m · Q(x) + (x - r) · Q′(x))     [винесення спільного множника]
```

Розглянемо два випадки:
1. Якщо корінь простий (`m = 1`):
   `P′(x) = 1 · Q(x) + (x - r) · Q′(x)`.
   Підставимо `x = r`:
   `P′(r) = Q(r) + 0 · Q′(r) = Q(r) ≠ 0`.
   Похідна у простому корені не дорівнює нулю.

2. Якщо корінь кратний (`m ≥ 2`):
   Вираз для похідної містить множник `(x - r)ᵐ⁻¹` зі степенем `m - 1 ≥ 1`.
   Підставимо `x = r`:
   `P′(r) = (r - r)ᵐ⁻¹ · (…) = 0 · (…) = 0`.
   Похідна у кратному корені гарантовано обнуляється.

**Наслідок (Виділення безквадратного розкладу):**
Многочлен `P(x)` не має кратних коренів (усі його корені прості) тоді й лише тоді, коли він взаємно простий зі своєю похідною:

```
gcd(P(x), P′(x)) = 1
```

Якщо ж `gcd(P(x), P′(x)) = D(x)` зі степенем `deg D ≥ 1`, то многочлен `P(x) / D(x)` містить рівно ті самі корені, що й `P(x)`, але кожен корінь входить до нього з одиничною кратністю. Ця властивість дозволяє алгоритмічно усувати кратні корені безпосередньо через алгоритм Евкліда без обчислення самих значень коренів.
