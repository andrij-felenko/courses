# 🧮 Математичне доведення коректності, аналіз помилок та матричне узагальнення

У цій математичній вставці наведено строге алгебраїчне доведення теореми про ділення многочлена з остачею через схему Горнера, аналіз обчислювальної оптимальності Островського, розвернутий аналіз похибок у комп'ютерній арифметиці за Вількінсоном, а також детальний опис матричного алгоритму Патерсона — Стокмаєра.

## 1. Алгебраїчні підвалини та тотожність синтетичного ділення

Розглянемо кільце многочленів `K[x]` від однієї змінної `x` над довільним комутативним кільцем `K` з одиницею (наприклад, кільцем цілих чисел `ℤ`, полем раціональних чисел `ℚ`, дійсних чисел `ℝ`, комплексних чисел `ℂ` або скінченним полем `GF(q)`).

Довільний многочлен степеня `n` записується у вигляді формальної суми:

```
P(x) = aₙ xⁿ + aₙ₋₁ xⁿ⁻¹ + aₙ₋₂ xⁿ⁻² + ... + a₁ x + a₀,    aₙ ≠ 0
```

Теорема про ділення з остачею стверджує, що для будь-якого елемента `x₀ ∈ K` існує єдина пара, що складається з многочлена-частки `Q(x) ∈ K[x]` степеня `n - 1` та елемента-остачі `R ∈ K`, таких що виконується тотожність:

```
P(x) = (x - x₀) Q(x) + R
```

Схема Горнера визначає коефіцієнти частки `Q(x) = bₙ xⁿ⁻¹ + bₙ₋₁ xⁿ⁻² + ... + b₂ x + b₁` та остачу `R = b₀` за допомогою рекурентного співвідношення:

```
bₙ = aₙ
bₖ = aₖ + x₀ · bₖ₊₁      [загальна формула для k = n - 1, n - 2, ..., 0]
```

### Строге алгебраїчне доведення

Для доведення тотожності підставимо вираз для `Q(x)` та `b₀` у праву частину рівняння і виконаємо пряме множення багаточленів у кільці `K[x]`:

```
  (x - x₀) · (bₙ xⁿ⁻¹ + bₙ₋₁ xⁿ⁻² + ... + b₁ x + b₁) + b₀
= x · (bₙ xⁿ⁻¹ + bₙ₋₁ xⁿ⁻² + ... + b₁) - x₀ · (bₙ xⁿ⁻¹ + bₙ₋₁ xⁿ⁻² + ... + b₁) + b₀  [дистрибутивність: розкриваємо множення на (x - x₀)]
= bₙ xⁿ + bₙ₋₁ xⁿ⁻¹ + ... + b₁ x - (x₀ bₙ xⁿ⁻¹ + x₀ bₙ₋₁ xⁿ⁻² + ... + x₀ b₁ x) + b₀ [дистрибутивність: множимо x та x₀ на кожен доданок]
```

Згрупуємо всі доданки за однаковими степенями змінної `x`:

```
= bₙ xⁿ + (bₙ₋₁ - x₀ bₙ) xⁿ⁻¹ + (bₙ⁻₂ - x₀ bₙ₋₁) xⁿ⁻² + ... + (b₁ - x₀ b₂) x + (b₀ - x₀ b₁)
```

Використаємо вихідні рекурентні рівності Горнера, виразивши різниці `bₖ - x₀ bₖ₊₁`:

```
З рівності bₙ = aₙ                 маємо  bₙ = aₙ
З рівності bₙ₋₁ = aₙ₋₁ + x₀ bₙ     маємо  bₙ₋₁ - x₀ bₙ = aₙ₋₁
З рівності bₙ₋₂ = aₙ₋₂ + x₀ bₙ₋₁   маємо  bₙ₋₂ - x₀ bₙ₋₁ = aₙ₋₂
...
З рівності b₁ = a₁ + x₀ b₂         маємо  b₁ - x₀ b₂ = a₁
З рівності b₀ = a₀ + x₀ b₁         маємо  b₀ - x₀ b₁ = a₀
```

Підставляючи ці вирази у згрупований многочлен, переконуємося, що коефіцієнт при кожному степені `xᵏ` точно дорівнює `aₖ`:

```
= aₙ xⁿ + aₙ₋₁ xⁿ⁻¹ + aₙ₋₂ xⁿ⁻² + ... + a₁ x + a₀ = P(x)
```

Таким чином, доведено, що рекурентний процес Горнера тотожно відновлює вихідний многочлен `P(x)`.

За теоремою Безу про остачу, підстановка значення `x = x₀` у тотожність `P(x) = (x - x₀) Q(x) + b₀` перетворює доданок `(x₀ - x₀) Q(x₀)` на нуль, звідки випливає, що `b₀ = P(x₀)`. Доведення повністю завершено.

## 2. Теорема Островського про обчислювальну оптимальність

Важливим питанням обчислювальної складності є визначення теоретичного мінімуму арифметичних операцій, необхідних для обчислення значення довільного полінома.

**Теорема (Олександр Островський, 1954):**
Для обчислення значення загального многочлена степеня `n` із неозначеними коефіцієнтами у довільній точці необхідно виконати щонайменше `n` операцій множення та `n` операцій додавання, якщо не дозволено попереднє обчислення коефіцієнтів, які залежать лише від вихідного многочлена.

### Алгебраїчна схема доведення Островського

Доведення базується на розгляді алгоритму як послідовності шарів арифметичних операцій над елементами поля `K(a₀, a₁, ..., aₙ, x)`.

1. **База індукції (`n = 1`):** Для линейного многочлена `P(x) = a₁ x + a₀` потрібно мінімум 1 множення `a₁ · x` та 1 додавання `+ a₀`. Оскільки `a₁` та `x` є алгебраїчно незалежними змінними над полем `K`, зменшити цю кількість неможливо.
2. **Індукційний крок (`n - 1 → n`):** Припустимо, що будь-який алгоритм оцінки многочлена степеня `n - 1` вимагає щонайменше `n - 1` множень. У загальному алгоритмі оцінки `P(x)` перша операція множення, що залучає змінну `x`, має вигляд:

```
M₁(a, x) = L₁(a, x) · L₂(a, x)
```

де `L₁` та `L₂` є афінними комбінаціями змінних. Щоб отримати максимальний степінь `xⁿ` у кінцевому результаті для довільних коефіцієнтів `aₖ`, ця операція множення вилучає лише один ступінь вільностей щодо змінної `x`. Зафіксувавши значення цієї операції, ми зменшуємо розмірність обчислювального простору до багаточлена степеня `n - 1`, який за припущенням індукції вимагає щонайменше `n - 1` множень.

Отже, загальна кількість множень для многочлена степеня `n` виражається нерівністю `N_mult ≥ 1 + (n - 1) = n`.

Оскільки схема Горнера виконує рівно `n` множень та `n` додавань, вона досягає абсолютної нижньої межі обчислювальної складності для неструктованих многочленів.

## 3. Аналіз чисельної стійкості у комп'ютерній арифметиці (Вількінсон)

При виконанні обчислень на ЕОМ у стандарті арифметики з плаваючою крапкою IEEE 754 кожна арифметична операція додавання або множення виконується з відносною похибкою, що не перевищує машинного епсилон `u` (`u = 2⁻⁵³ ≈ 1.11 × 10⁻¹⁶` для формату `double` подвійної точності):

```
fl(x ⊙ y) = (x ⊙ y) (1 + δ),    де |δ| ≤ u,  ⊙ ∈ {+, ·}
```

Проаналізуємо накопичення похибок при виконанні кроків схеми Горнера. Нехай `b̂ₖ` позначує фактичне обчислене значення з урахуванням похибок округлення на кроці `k`:

```
b̂ₙ = aₙ
b̂ₖ = fl(aₖ + fl(x₀ · b̂ₖ₊₁)) = (aₖ + x₀ b̂ₖ₊₁ (1 + αₖ)) (1 + βₖ),    де |αₖ|, |βₖ| ≤ u
```

Розкриваючи рекурентні співвідношення та нехтуючи членами вищих порядків `O(u²)`, отримаємо підсумкове обчислене значення:

```
fl(P(x₀)) = P(x₀) + E(x₀)
```

де абсолютна похибка обчислення `E(x₀)` описується нерівністю зворотної стійкості Вількінсона (James H. Wilkinson):

```
|E(x₀)| ≤ γ₂ₙ · P̃(|x₀|)
```

тут `P̃(x)` — многочлен, складений із абсолютних величин коефіцієнтів:

```
P̃(x) = |aₙ| xⁿ + |aₙ₋₁| xⁿ⁻¹ + ... + |a₁| x + |a₀|
```

а коефіцієнт збурення `γ₂ₙ` визначається як:

```
γ₂ₙ = (2n u) / (1 - 2n u) = 2n u + O(u²)
```

### Число обумовленості та явище катастрофічного скасування

Відносна похибка обчислення значення многочлена дорівнює:

```
|fl(P(x₀)) - P(x₀)| / |P(x₀)| ≤ 2n u · (P̃(|x₀|) / |P(x₀)|) = 2n u · cond(P, x₀)
```

де `cond(P, x₀) = P̃(|x₀|) / |P(x₀)|` — число обумовленості задачі обчислення значення багаточлена у точці `x₀`.

1. **Добре обумовлені задачі (`cond(P, x₀) ≈ 1`):** Якщо всі коефіцієнти `aₖ` мають однаковий знак і `x₀ > 0`, маємо `P̃(|x₀|) = |P(x₀)|`. У цьому випадку число обумовленості дорівнює `1`, і відносна похибка обчислення за схемою Горнера не перевищує `2n u`. Це гарантує високу чисельну стійкість: похибка зростає лише лінійно зі степенем многочлена.
2. **Погано обумовлені задачі (`cond(P, x₀) ≫ 1`):** Якщо многочлен має альтернативні знаки коефіцієнтів, а точка `x₀` розташована близько до кореня многочлена, значення `|P(x₀)|` прямує до нуля, тоді як `P̃(|x₀|)` залишається великим числом. Виникає катастрофічне скасування доданків (catastrophic cancellation), при якому точні значущі розряди втрачаються через віднімання близьких чисел.

## 4. Матричне узагальнення: алгоритм Патерсона — Стокмаєра

Якщо аргументом многочлена `P(x)` є квадратна матриця `A` розміру `m × m`, пряме застосування схеми Горнера вимагає `n - 1` операцій множення матриці на матрицю:

```
P(A) = (...((aₙ A + aₙ₋₁ I) A + aₙ₋₂ I) A ... + a₁ I) A + a₀ I
```

Оскільки множення двох матриць розміру `m × m` вимагає `O(m³)` операцій, загальна складність стандартної схеми Горнера для матриць становить `O(n m³)`.

Алгоритм Патерсона — Стокмаєра (Paterson–Stockmeyer, 1973) скорочує кількість матричних множень із `n - 1` до `O(√n)`.

### Математичний вивід алгоритму Патерсона — Стокмаєра

Оберемо параметр блокування `k = ⌈√n⌉`. Запишемо многочлен `P(A)` у вигляді розкладу за степенями блоки-матриці `M = Aᵏ`:

```
P(A) = Bₛ (A) (Aᵏ)ˢ + Bₛ₋₁ (A) (Aᵏ)ˢ⁻¹ + ... + B₁ (A) Aᵏ + B₀ (A)
```

де кожен блок `Bⱼ (A)` є матричним многочленом степеня менше `k`:

```
Bⱼ (A) = aⱼₖ₊ₖ₋₁ Aᵏ⁻¹ + aⱼₖ₊ₖ₋₂ Aᵏ⁻² + ... + aⱼₖ I
```

і `s = ⌊n / k⌋`.

### Етапи виконання алгоритму Патерсона — Стокмаєра

1. **Етап 1 (Попередній розрахунок степенів):** Обчислюємо та зберігаємо в оперативній пам'яті степені матриці `A², A³, ..., Aᵏ⁻¹`. Це вимагає строго **`k - 2`** матричних множень.
2. **Етап 2 (Обчислення блокових матриць `Bⱼ(A)`):** Кожен блок `Bⱼ(A)` формується як лінійна комбінація вже збережених матриць `I, A, A², ..., Aᵏ⁻¹`. Обчислення всіх блоків вимагає лише множень матриць на скалярні коефіцієнти `aₖ` та додавань матриць, що виконується за `O(m²)` операцій і **не вимагає жодного множення матриці на матрицю**.
3. **Етап 3 (Обчислення степеня блоку `Aᵏ`):** Обчислюємо матрицю `M = Aᵏ = Aᵏ⁻¹ · A`, що потребує **`1`** матричного множення.
4. **Етап 4 (Збирання за схемою Горнера для блоків):** Застосовуємо схему Горнера до блоків `Bⱼ(A)` за аргументом `M = Aᵏ`:

```
P(A) = (...((Bₛ(A) M + Bₛ₋₁(A)) M + Bₛ₋₂(A)) M ... + B₁(A)) M + B₀(A)
```

Це вимагає **`s`** матричних множень.

### Підсумок обчислювальної складності

Загальна кількість операцій множення матриці на матрицю становить:

```
N_mult = (k - 2) + 1 + s = k + s - 1 = k + ⌊n / k⌋ - 1
```

Мінімум цієї суми досягається при `k = ⌈√n⌉`. 

Для многочлена степеня `n = 100`:
- Стандартна схема Горнера вимагає **99** множень матриць.
- Алгоритм Патерсона — Стокмаєра при `k = 10` вимагає лише `10 + 10 - 1 =` **19** множень матриць.

Це дає прискорення обчислень матричних многочленів у 5 разів, зберігаючи при цьому повну математичну точність.
