# Інтерполяція Лагранжа

<preknowlist>
- [Кільця](book:math/rings) — кільця многочленів `K[x]` над полем: багаточлени утворюють алгебраїчну структуру з додаванням і множенням.
- [Системи лінійних рівнянь](book:math/linear-systems) — матричні системи `V·c = y`: відновлення коефіцієнтів многочлена еквівалентне розв'язанню лінійної системи з матрицею Вандермонда.
- [Поліноми Чебишова](book:math/chebyshev-polynomials) — мінімізація похибки інтерполяції та запобігання феномену Рунге.
</preknowlist>

Коли керівний контролер робототехнічної системи отримує серію дискретних вимірів від сенсорів — наприклад, температуру двигуна чи просторові координати маніпулятора у моменти часу `t₀, t₁, …, t╙` — йому необхідно розрахувати значення фізичної величини у проміжній точці `t`, де пряме вимірювання не проводилося. Просте кусково-лінійне з'єднання точок відрізками створює у вузлах злами, де перша похідна (швидкість) зазнає стрибків, а друга похідна (прискорення) прямує до нескінченності. Згідно з другим законом Ньютона (`F = m·a`), такий рух вимагав би нескінченних сил та спричиняв би руйнівні удари в механічних вузлах. 

Але спроба побудувати гладку неперервну траєкторію шляхом розв'язання прямої системи лінійних рівнянь для коефіцієнтів багаточлена `c₀ + c₁ x + … + c╙ xⁿ = y` негайно впирається у чисельну катастрофу. Матриця цієї системи, відома як матриця Вандермонда, має експоненціально зростаюче число обумовленості `cond(V) ~ eⁿ`. Вже при 10–15 вузлах похибки заокруглення у плавуючій комі спотворюють коефіцієнти до цілковитого хаосу.

Щоб оминути обчислювальний крах обернення матриць, видатний французький математик Жозеф-Луї Лагранж запропонував алгебраїчний хід: замість пошуку глобальних коефіцієнтів многочлена побудувати базис з «індикаторних» многочленів, кожен з яких набуває значення одиниці у власному вузлі й перетворюється на нуль у всіх інших.

### 1. Алгебраїчна концепція базисних многочленів Лагранжа

Уявімо дискретний аналог імпульсного відгуку у теорії сигналів та цифрової обробки даних. Нехай нам надано `n + 1` парувато різних вузлів `x₀, x₁, …, x╙` та відповідні значення `y₀, y₁, …, y╙`. Ми прагнемо знайти многочлен `P(x)` степеня не вище `n`, який задовольняє умови `P(x╖) = y╖` для всіх `k = 0, 1, …, n`.

Представимо шуканий многочлен у вигляді лінійної комбінації:

```
P(x) = y₀·L₀(x) + y₁·L₁(x) + … + y╙·L╙(x) = ∑ y╖ · L╖(x)
```

де `L╖(x)` — допоміжні багаточлени степеня `n`.

Щоб ця сума тотожно відтворювала `y╟` у кожному вузлі `x╟`, базисні многочлени `L╖(x)` повинні задовольняти дискретну умову дельта-символу Кронекера:

```
L╖(x╟) = 1,  якщо k = i
L╖(x╟) = 0,  якщо k ≠ i
```

Сконструюємо багаточлен `L╖(x)`, задовольняючи ці дві умови по черзі:

1. **Забезпечення нулів у всіх сторонніх вузлах (`i ≠ k`):**
   Многочлен степеня `n`, який перетворюється на нуль у `n` точках `x₀, …, x╖₋₁, x╖₊₁, …, x╙`, обов'язково ділиться на добуток відповідних лінійних множників:

   ```
   L╖(x) ~ (x - x₀)·…·(x - x╖₋₁)·(x - x╖₊₁)·…·(x - x╙) = ∏ (x - xⱼ)    (j ≠ k)
   ```

2. **Нормування до одиниці у власному вузлі (`i = k`):**
   При підставці `x = x╖` підрахований добуток дорівнює `∏ (x╖ - xⱼ)`. Щоб отримати значення `1`, поділимо чисельник на це числове значення:

   ```
   L╖(x) = ∏ (x - xⱼ) / (x╖ - xⱼ)    (для всіх j від 0 до n, де j ≠ k)
   ```

Формула (1) є **канонічним базисним многочленом Лагранжа**.

![Базисні поліноми Лагранжа](/book/math/algebra/lagrange-interpolation/img/lagrange-basis-polynomials.svg)
*Базисні многочлени Лагранжа L₀(x), L₁(x), L₂(x) для трьох вузлів x₀=1, x₁=2, x₂=4. Кожен базис дорівнює 1 у власному вузлі та 0 в усіх інших.*

Завдяки такій конструкції повний інтерполяційний многочлен збирається як проста суперпозиція:

```
P(x) = ∑ y╖ · ∏ (x - xⱼ) / (x╖ - xⱼ)    (j ≠ k)
```

### 2. Крок за кроком: Числовий приклад інтерполяції для 3 вузлів

Проведемо повний числове розрахунок інтерполянта для трьох виміряних точок експерименту:

```
(x₀, y₀) = (1, 2)
(x₁, y₁) = (2, 3)
(x₂, y₂) = (4, 11)
```

Кількість точок `n + 1 = 3`, отже шуканий многочлен `P(x)` має степінь `n = 2` (квадратична парабола).

#### Крок 1. Обчислення базисного многочлена `L₀(x)` для вузла `x₀ = 1`:

```
L₀(x)
= ((x - x₁) · (x - x₂)) / ((x₀ - x₁) · (x₀ - x₂))  [канонічна формула базису]
= ((x - 2) · (x - 4)) / ((1 - 2) · (1 - 4))          [підстановка вузлів x₀=1, x₁=2, x₂=4]
= (x² - 6x + 8) / ((-1) · (-3))                     [розкриття дужок чисельника та знаменника]
= (x² - 6x + 8) / 3                                 [знаменник (-1)·(-3) = 3]
```

Перевірка значення:
- `L₀(1) = (1 - 6 + 8)/3 = 3/3 = 1`
- `L₀(2) = (4 - 12 + 8)/3 = 0/3 = 0`
- `L₀(4) = (16 - 24 + 8)/3 = 0/3 = 0`

#### Крок 2. Обчислення базисного многочлена `L₁(x)` для вузла `x₁ = 2`:

```
L₁(x)
= ((x - x₀) · (x - x₂)) / ((x₁ - x₀) · (x₁ - x₂))  [канонічна формула базису]
= ((x - 1) · (x - 4)) / ((2 - 1) · (2 - 4))          [підстановка вузлів x₀=1, x₁=2, x₂=4]
= (x² - 5x + 4) / ((1) · (-2))                      [розкриття дужок чисельника та знаменника]
= -(x² - 5x + 4) / 2                                [знаменник (1)·(-2) = -2]
```

Перевірка значення:
- `L₁(1) = -(1 - 5 + 4)/2 = 0`
- `L₁(2) = -(4 - 10 + 4)/2 = -(-2)/2 = 1`
- `L₁(4) = -(16 - 20 + 4)/2 = 0`

#### Крок 3. Обчислення базисного многочлена `L₂(x)` для вузла `x₂ = 4`:

```
L₂(x)
= ((x - x₀) · (x - x₁)) / ((x₂ - x₀) · (x₂ - x₁))  [канонічна формула базису]
= ((x - 1) · (x - 2)) / ((4 - 1) · (4 - 2))          [підстановка вузлів x₀=1, x₁=2, x₂=4]
= (x² - 3x + 2) / ((3) · (2))                       [розкриття дужок чисельника та знаменника]
= (x² - 3x + 2) / 6                                 [знаменник (3)·(2) = 6]
```

Перевірка значення: `L₂(1) = 0`, `L₂(2) = 0`, `L₂(4) = 6/6 = 1`.

#### Крок 4. Збирання підсумкового многочлена `P(x)`:

```
P(x)
= y₀·L₀(x) + y₁·L₁(x) + y₂·L₂(x)                                         [суперпозиція базисів]
= 2 · [(x² - 6x + 8)/3] + 3 · [-(x² - 5x + 4)/2] + 11 · [(x² - 3x + 2)/6] [підстановка L₀, L₁, L₂]
```

Зведемо до спільного знаменника `6`:

```
P(x)
= [ 4(x² - 6x + 8) - 9(x² - 5x + 4) + 11(x² - 3x + 2) ] / 6  [зведення до знаменника 6]
= [ (4 - 9 + 11)x² + (-24 + 45 - 33)x + (32 - 36 + 22) ] / 6  [групування за степенями x]
= [ 6x² - 12x + 18 ] / 6                                      [обчислення коефіцієнтів]
= x² - 2x + 3                                                 [ділення на 6]
```

Отримали квадратний тричлен `P(x) = x² - 2x + 3`.

Перевіримо точний збіг у кожному з вихідних вузлів:
- `P(1) = 1² - 2(1) + 3 = 2` (збігається з `y₀`)
- `P(2) = 2² - 2(2) + 3 = 3` (збігається з `y₁`)
- `P(4) = 4² - 2(4) + 3 = 11` (збігається з `y₂`)

#### Крок 5. Аналіз похідних та інтегрування побудованого многочлена:
Отриманий поліном `P(x) = x² - 2x + 3` дозволяє легко обчисляти аналітичні похідні та інтеграли на всьому інтервалі `[1, 4]`:
- Швидкість зміни: `P′(x) = 2x - 2`. У точці `x = 1` швидкість дорівнює `0` (вершина параболи).
- Прискорення: `P″(x) = 2` (постійне позитивне прискорення).
- Площа під кривою (визначений інтеграл):
  ```
  ∫₁⁴ (x² - 2x + 3) dx = [ x³/3 - x² + 3x ]₁⁴ = (64/3 - 4) - 7/3 = 57/3 - 4 = 19 - 4 = 15
  ```
Багаточлен відновлено ідеально без жодного матричного обернення.

### 3. Векторний простір багаточленів та дуальність базисів

З точки зору абстрактної алгебри, множина многочленів `Pₙ[x]` степеня не вище `n` утворює векторний простір розмірності `dim(Pₙ[x]) = n + 1` над полем `K`.

Канонічним базисом цього простору є мономи `{1, x, x², …, xⁿ}`. Проте для заданої множини вузлів `x₀, x₁, …, x╙` базисні многочлени Лагранжа `{L₀(x), L₁(x), …, L╙(x)}` утворюють **альтернативний базис** простору `Pₙ[x]`.

#### Лінійні функціонали та дуальний простір:
Розглянемо `n + 1` лінійних функціоналів обчислення значення `ϕ╟: Pₙ[x] → K`, які діють за правилом:
```
ϕ╟(P) = P(x╟)
```
Ці функціонали утворюють базис у дуальному просторі `Pₙ[x]*`. Співвідношення `ϕ╟(L╖) = L╖(x╟) = δ╖╟` доводить, що базис Лагранжа `{L╖}` є точним дуальним базисом до функціоналів обчислення значення у вузлах.

Матриця переходу від канонічного базису мономів до базису Лагранжа вимагає обернення матриці Вандермонда, але представлена у вигляді суперпозиції Лагранжа, вона дає розклад вектора `P(x)` за базисом `{L╖}` з коефіцієнтами, які збігаються з виміряними координатами `y╖` без жодних додаткових матричних перетворень.

### 4. Матричний вимір: Матриця Вандермонда та єдиність розв'язку

Щоб глибоко збагнути зв'язок між алгеброю многочленів та лінійною алгеброю, розглянемо проблему побудови полінома через систему рівнянь відносно його класичних коефіцієнтів `P(x) = c₀ + c₁ x + c₂ x² + … + c╙ xⁿ`.

Підставивши `n + 1` вузлів `(x╖, y╖)`, отримуємо СЛАР розмінності `(n + 1) × (n + 1)`:

```
[ 1  x₀  x₀²  …  x₀ⁿ ]   [ c₀ ]   [ y₀ ]
[ 1  x₁  x₁²  …  x₁ⁿ ] · [ c₁ ] = [ y₁ ]
[ …  …   …    …  …   ]   [ …  ]   [ …  ]
[ 1  x╙  x╙²  …  x╙ⁿ ]   [ c╙ ]   [ y╙ ]
```

Матриця `V` цієї системи називається **матрицею Вандермонда** (на честь французького математика Александра-Теофіла Вандермонда).

![Матриця Вандермонда проти суперпозиції Лагранжа](/book/math/algebra/lagrange-interpolation/img/vandermonde-matrix-system.svg)
*Порівняння обчислення полінома: пряме обернення матриці Вандермонда проти явного базису Лагранжа.*

Визначник матриці Вандермонда обчислюється за відомою алгебраїчною формулою:

```
det(V) = ∏ (xⱼ - x╖)    (для всіх 0 ≤ k < j ≤ n)
```

Якщо всі вузли `x╖` є **парувато різними** (`x╖ ≠ xⱼ`), то жодна з різниць `(xⱼ - x╖)` не дорівнює нулю. Отже, `det(V) ≠ 0`, матриця `V` є неелементарною (невиродженою), і система має **єдиний розв'язок**.

Це доводить важливу алгебраїчну теорему: у кільці многочленів `K[x]` над полем `K` існує **один і тільки один** многочлен степеня `≤ n`, який проходить через `n + 1` точок з різними х-координатами.

Формула Лагранжа є не чимось іншим, як явним виразом для розв'язку цієї системи, який оминає процедуру обернення матриці за методом Гаусса. Детальний математичний доведення єдиності інтерполянта у довільному полі розібрано в окремій довідці: роздивіться [математичний вивід барицентричної форми та оцінку похибки](book:math/lagrange-interpolation/math-barycentric-derivation.md).

### 5. Барицентрична революція: Від `O(n²)` до `O(n)` за викликом

Незважаючи на красиву алгебраїчну симетрію, канонічна формула Лагранжа має суттєвий обчислювальний недолік. Якщо обчислювати значення `P(x)` у кожній новій точці «з нуля», обчислення `n + 1` базисів `L╖(x)` вимагає `O(n²)` арифметичних операцій.

У 1904 році математики трансформували формулу Лагранжа до виключно стійкої та швидкої **другої барицентричної форми**.

#### 1. Попереднє обчислення барицентричних ваг `w╖`:
Визначимо для кожного вузла `x╖` ваговий коефіцієнт `w╖`:

```
w╖ = 1 / ∏ (x╖ - xⱼ)    (для всіх j ≠ k)
```

Ці ваги `w╖` залежать **тільки від координат вузлів `x╖`** і не залежать ні від значень `y╖`, ні від точки оцінки `x`. Вони обчислюються один раз за `O(n²)` операцій.

#### 2. Друга барицентрична формула:
Враховуючи винесення спільного вузлового многочлена `ω(x) = ∏ (x - xⱼ)`, інтерполяційний многочлен подається у вигляді відношення двох сум:

```
P(x) = [ ∑ ( w╖ · y╖ / (x - x╖) ) ] / [ ∑ ( w╖ / (x - x╖) ) ]
```

![Механізм оновлення барицентричних вагових коефіцієнтів](/book/math/algebra/lagrange-interpolation/img/barycentric-weights-update.svg)
*Структура обчислень у барицентричній формі другої родини та механізм додавання нових точок за O(n).*

#### 3. Повне числове простеження барицентричної оцінки у точці `x = 3.0`:
Розглянемо вихідний приклад з трьома вузлами `(1, 2)`, `(2, 3)`, `(4, 11)` і обчислимо `P(3.0)` за другою барицентричною формулою:

- **Обчислення ваг `w╖`:**
  - `w₀ = 1 / ((1 - 2)(1 - 4)) = 1 / ((-1)(-3)) = 1/3 ≈ 0.333333`
  - `w₁ = 1 / ((2 - 1)(2 - 4)) = 1 / ((1)(-2)) = -1/2 = -0.500000`
  - `w₂ = 1 / ((4 - 1)(4 - 2)) = 1 / ((3)(2)) = 1/6 ≈ 0.166667`

- **Обчислення доданків чисельника у точці `x = 3.0`:**
  - `Term₀ = (w₀ · y₀) / (3.0 - 1.0) = (1/3 · 2) / 2.0 = 1/3 ≈ 0.333333`
  - `Term₁ = (w₁ · y₁) / (3.0 - 2.0) = (-1/2 · 3) / 1.0 = -1.500000`
  - `Term₂ = (w₂ · y₂) / (3.0 - 4.0) = (1/6 · 11) / (-1.0) = -11/6 ≈ -1.833333`
  - Сума чисельника: `Num = 1/3 - 3/2 - 11/6 = (2 - 9 - 11)/6 = -18/6 = -3.0`

- **Обчислення доданків знаменника у точці `x = 3.0`:**
  - `Den₀ = w₀ / (3.0 - 1.0) = (1/3) / 2.0 = 1/6 ≈ 0.166667`
  - `Den₁ = w₁ / (3.0 - 2.0) = (-1/2) / 1.0 = -1/2 = -0.500000`
  - `Den₂ = w₂ / (3.0 - 4.0) = (1/6) / (-1.0) = -1/6 ≈ -0.166667`
  - Сума знаменника: `Denom = 1/6 - 1/2 - 1/6 = -1/2 = -0.5`

- **Результат відношення:**
  ```
  P(3.0) = Num / Denom = (-3.0) / (-0.5) = 6.0
  ```

Перевіримо за раніше знайденою канонічною параболою `P(x) = x² - 2x + 3`:
`P(3.0) = 3² - 2(3) + 3 = 9 - 6 + 3 = 6.0`. Результати збігаються точнісінько до останньої цифри!

#### Головні переваги барицентричного підходу:

1. **Швидкодія `O(n)` на точку:** Після того, як ваги `w╖` обчислені, обчислення `P(x)` у будь-якій новій точці `x` вимагає лише `n + 1` ділень та по `n` додавань у чисельнику й знаменнику — тобто всього `O(n)` операцій!
2. **Динамічне оновлення за `O(n)`:** Якщо до системи надходить новий виміряний вузол `(xₙ₊₁, yₙ₊₁)`, усі попередні ваги оновлюються за простим правилом `w╖′ = w╖ / (x╖ - xₙ₊₁)` за час `O(n)`, без повного перерахунку.
3. **Чисельна стабільність (доведення Гайема):** Повний вузловий добуток `ω(x)` скоротився. Видатний фахівець з чисельного аналізу Ніколас Гайем (англ. *Nicholas Higham*) довів, що друга барицентрична форма має зворотну чисельну стабільність, співставну з найкращими алгоритмами сплайнового наближення.

Повний алгоритмічний код барицентричного інтерполятора мовами C, C++ та Python доступний у практичній інструкції: перегляньте [практичну реалізацію барицентричного інтерполятора мовами C та C++](book:math/lagrange-interpolation/proj-lagrange-algorithm.md).

### 6. Залишковий член похибки та феномен Рунге

Якщо многочлен Лагранжа `Pₙ(x)` будується для наближення неперервної функції `f(x)`, виникає питання: яка похибка цього наближення у точках між вузлами?

За допомогою послідовного застосування теореми Ролля до допоміжної функції доводиться формула **залишкового члена похибки**:

```
f(x) - Pₙ(x) = ( fⁿ⁺¹⁾(ξ) / (n + 1)! ) · ωₙ₊₁(x)
```

де `ξ` — деяка невідома проміжна точка всередині інтервалу інтерполяції, а `ωₙ₊₁(x) = ∏ (x - x╖)` — вузловий многочлен.

Похибка є добутком двох факторів:
1. `fⁿ⁺¹⁾(ξ) / (n + 1)!` — залежить від швидкості зростання вищих похідних функції `f(x)`.
2. `ωₙ₊₁(x) = (x - x₀)(x - x₁)…(x - x╙)` — залежить виключно від геометрії розташування вузлів `x╖`.

#### Пастка рівномірної сітки: Феномен Рунге
Природне прагнення розставити вузли `x╖` рівномірно з кроком `h = (b - a)/n` призводить до катастрофічного результату при збільшенні `n`. 

Для функції `f(x) = 1 / (1 + 25x²)` на відрізку `[-1, 1]` при зростанні степеня `n` добуток `ωₙ₊₁(x)` біля меж відрізка `x = ±1` починає утворювати величезні сплески. Похибка інтерполяції на краях не зменшується, а прямує до нескінченності! Цю руйнівну поведінку називають **феноменом Рунге** (англ. *Runge's phenomenon*).

![Феномен Рунге на рівномірній сітці проти вузлів Чебишова](/book/math/algebra/lagrange-interpolation/img/runge-phenomenon-vs-chebyshev.svg)
*Феномен Рунге для функції 1/(1+25x²): дикі осциляції на краях рівномірної сітки проти ідеального наближення на вузлах Чебишова.*

#### Порятунок: Вузли Чебишова
Щоб мінімізувати максимальне значення многочлена `ωₙ₊₁(x)` на відрізку `[-1, 1]`, вузли необхідно згущувати до країв відрізка за косинусоїдальним законом:

```
x╖ = cos( ((2k + 1) · π) / (2n + 2) )    (k = 0, 1, …, n)
```

Геометрично вузли Чебишова являють собою ортогональні проекції рівномірно розташованих точок верхньої півкола одиничного радіуса на горизонтальну вісь `X`.

Вибір вузлів Чебишова повністю нейтралізує феномен Рунге, забезпечуючи рівномірну та чисельно стійку збіжність інтерполянта Лагранжа для будь-якої гладкої функції. Детальніше про історію відкриття та протистояння наукових шкіл XVIII–XIX століть читайте у хроніці: відкрийте [історію виникнення інтерполяційної формули Лагранжа](book:math/lagrange-interpolation/hist-lagrange.md).

### 7. Систематичне порівняння з іншими методами апроксимації

Для правильного вибору обчислювального алгоритму в інженерній практиці необхідно чітко розуміти межі застосовності та порівняльні характеристики різних методів наближення функцій:

#### 1. Інтерполяція Лагранжа проти інтерполяції Ньютона:
- **Лагранж:** Явний базис, симетрія відносно всіх точок, ідеально підходить для теорії, аналітичних формул, криптографії та другої барицентричної форми.
- **Ньютон:** Використовує розділені різниці `f[x₀, …, x╟]`, зручний при ручному додаванні точок у табличному численні без барицентричних ваг.

#### 2. Інтерполяція Лагранжа проти інтерполяції Ерміта:
- **Лагранж:** Узгоджує лише значення функції `P(x╖) = y╖`.
- **Ерміт:** Узгоджує як значення функції `P(x╖) = y╖`, так і значення її похідних `P′(x╖) = y╖′`, що вимагає базисних многочленів подвійного степеня `2n + 1`.

#### 3. Інтерполяція Лагранжа проти Кубічних Сплайнів:
- **Глобальний Лагранж:** Побудованого єдиного многочлена степеня `n` на всьому відрізку. Забезпечує нескінченну гладкість `C^∞`, але чутливий до феномену Рунге при рівномірній сітці.
- **Кубічні Сплайни:** Кусково-поліноміальне наближення гладкості `C²`. Кожна ланка має кубічний степінь. Забезпечує локальну стійкість, але втрачає глобальну аналітичну форму багаточлена.

### 8. Застосування у криптографії: Схема розділення секрету Шаміра

Інтерполяція Лагранжа не обмежена дійсними числами `ℝ`. Вона працює над будь-яким алгебраїчним полем, зокрема над скінченними полями Галуа `GF(p)`, де `p` — просте число.

У 1979 році видатний криптограф Аді Шамір (англ. *Adi Shamir*) опирався на інтерполяцію Лагранжа для створення фундаментального протоколу **порогового розділення секрету `(k, n)`** (англ. *Shamir's Secret Sharing*).

#### Принцип роботи схеми Шаміра:

1. **Генерація секрету:** Нехай секретом є число `S ∈ GF(p)`. Офіцер безпеки обирає випадковий багаточлен степеня `k - 1`:

   ```
   P(x) = S + a₁ x + a₂ x² + … + a╟₋₁ xᵏ⁻¹ (mod p)
   ```

   Вільний член многочлена `P(0) = S` зберігає секрет.

2. **Видача часток:** Для `n` учасників обчислюються значення `y╖ = P(x╖) mod p` у точках `x╖ = 1, 2, …, n`. Кожен учасник отримує одну пару `(x╖, y╖)`.
3. **Відновлення секрету:** Будь-які `k` учасників зі своїми частками об'єднують дані і відновлюють значення `P(0)` за допомогою спрощеної формули Лагранжа:

   ```
   S = P(0) = ∑ y╖ · ∏ ( -xⱼ / (x╖ - xⱼ) ) (mod p)    (для j ≠ k)
   ```

Якщо збирається менше ніж `k` учасників (наприклад, `k - 1`), система лінійних рівнянь залишається недовизначеною: для кожного можливого значення секрету `S′ ∈ GF(p)` існує рівно один многочлен степеня `k - 1`, який узгоджується з наявними `k - 1` частками. Секрет захищено з точковою математичною досконалістю у сенсі теорії інформації Шеннона.

Детально специфікація C/C++ бібліотечного контракту та таблиця алгоритмічної складності систематизована у довіднику: перегляньте [інтерфейс бібліотеки поліноміальної інтерполяції](book:math/lagrange-interpolation/api-interpolator.md). Про конкретні криптографічні застосування порогових схем читайте у тематичному матеріалі: [Схема розбиття секрету Шаміра](book:math/shamir-secret-sharing).
