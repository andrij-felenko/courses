# ⚙️ Обчислення та маніпуляції з твірними функціями

Математичні тотожності формальних степеневі рядів набувають практичної сили тоді, коли їх перетворюють на алгоритми та комп'ютерні програми. Символьні обчислення над твірними функціями дозволяють автоматично отримувати коефіцієнти розкладу, обчислювати дискретну згортку послідовностей, знаходити обернені ряди `1 / A(x)` та розв'язувати лінійні й квадратичні рекурентності без ручного алгебраїчного виведення.

У цьому практичному проєкті ми створимо повноцінний клас **формального степенного ряду** (Formal Power Series, FPS) з обмеженою точністю до `N` членів. Ми детально розберемо алгоритми додавання, дискретної згортки (множення), алгебраїчного обернення та диференціювання рядів, після чого застосуємо цей клас для автоматичного обчислення чисел Фібоначчі та чисел Каталана.

### 1. Алгоритмічний кістяк та математичні операції над рядами

У комп'ютерній алгебрі нескінченний формальний степеней ряд `A(x) = a₀ + a₁·x + a₂·x² + …` зберігається у пам'яті як скінченний масив коефіцієнтів `[a₀, a₁, a₂, …, aₙ₋₁]` із фіксованим відтинанням за модулем `xᴺ`. Усі степені `x` від `N` і вище відкидаються, оскільки для обчислення перших `N` членів послідовності вищі степені не беруть участі.

#### Множення рядів (дискретна згортка)

Перемноження двох твірних функцій `C(x) = A(x) · B(x) mod xᴺ` відповідає обчисленню дискретної згортки двох послідовностей. Кожен коефіцієнт `cₖ` при степені `xᵏ` утворюється сумою всіх можливих добутків `aᵢ · bⱼ`, де індекси `i + j = k`:

```
cₖ = ∑ aᵢ · bₖ₋ᵢ    (сума по i від 0 до k)
```

В алгоритмічному втіленні це реалізується двома вкладеними циклами. Зовнішній цикл перебирає індекс `i` від `0` до `N - 1`, а внутрішній цикл перебирає індекс `j` від `0` до `N - 1 - i`. Таке обмеження внутрішнього циклу гарантує, що ми обчислюємо лише ті коефіцієнти, чий підсумковий степінь `i + j` не перевищує межу відтинання `N - 1`. Складність прямого обчислення дискретної згортки становить `O(N²)`.

#### Алгебраїчне обернення ряду 1 / A(x)

Операція обернення відповідного ряду полягає у пошуку нового ряду `B(x) = b₀ + b₁·x + b₂·x² + …` такого, що виконується тотожність:

```
A(x) · B(x) = 1 mod xᴺ
```

Розпишемо добуток рядів `A(x)` та `B(x)` почленно й прирівняємо коефіцієнти при однакових степенях `x` до коефіцієнтів одиничного ряду `1 + 0·x + 0·x² + …`:

```
При x⁰:  a₀ · b₀ = 1  ⇒  b₀ = 1 / a₀
При x¹:  a₀ · b₁ + a₁ · b₀ = 0  ⇒  b₁ = - (a₁ · b₀) / a₀
При x²:  a₀ · b₂ + a₁ · b₁ + a₂ · b₀ = 0  ⇒  b₂ = - (a₁ · b₁ + a₂ · b₀) / a₀
При xᵏ:  ∑ aᵢ · bₖ₋ᵢ = 0   (сума по i від 0 до k)
```

Виділивши в останній сумі доданок `a₀ · bₖ` для `i = 0`, ми отримуємо трикутну рекурентну формулу для послідовного знаходження коефіцієнтів оберненого ряду:

```
bₖ = - (1 / a₀) · ∑ aᵢ · bₖ₋ᵢ    (сума по i від 1 до k)
```

Цей трикутний алгоритм дозволяє послідовно обчислити всі `N` коефіцієнтів оберненого ряду за `O(N²)` операцій. Єдиною обов'язковою умовою існування оберненого ряду є ненульове значення вільного члена: `a₀ ≠ 0`. Якщо `a₀ = 0`, дріб `1 / a₀` не існує в основному полі, і такий ряд не є оберненим у кільці `K[[x]]`.

#### Простеження обернення на прикладі знаменника Фібоначчі

Розглянемо простеження алгоритму обернення для знаменника твірної функції Фібоначчі `Q(x) = 1 - x - x²`. Тобто `a₀ = 1`, `a₁ = -1`, `a₂ = -1`, а решта `aᵢ = 0`.

Обчислимо перші коефіцієнти оберненого ряду `B(x) = 1 / Q(x)` за нашою рекурентною формулою:

```
b₀ = 1 / a₀ = 1 / 1 = 1
b₁ = - (1/1) · (a₁·b₀) = - (-1 · 1) = 1
b₂ = - (1/1) · (a₁·b₁ + a₂·b₀) = - (-1 · 1 + -1 · 1) = 2
b₃ = - (1/1) · (a₁·b₂ + a₂·b₁) = - (-1 · 2 + -1 · 1) = 3
b₄ = - (1/1) · (a₁·b₃ + a₂·b₂) = - (-1 · 3 + -1 · 2) = 5
```

Як видно, коефіцієнти оберненого ряду `B(x) = 1 + 1·x + 2·x² + 3·x³ + 5·x⁴ + …` є зсунутими числами Фібоначчі! Множення ряду `B(x)` на чисельник `P(x) = x` додає вільний нуль і дає канонічний ряд Фібоначчі: `F(x) = 0 + 1·x + 1·x² + 2·x³ + 3·x⁴ + 5·x⁵ + …`.

#### Формальне диференціювання та ймовірнісні характеристики

Операція формального диференціювання ряду `A'(x)` виконується за звичайними правилами алгебри степенів: степінь `xⁿ` переходить у `n · xⁿ⁻¹`. Тобто новий коефіцієнт на позиції `i - 1` дорівнює `i · aᵢ`. Вільний член `a₀` при диференціюванні зникає.

У теорії ймовірностей для ймовірнісних твірних функцій (PGF) `P(x) = ∑ pₖ · xᵏ` формальна похідна `P'(x)` при `x = 1` дозволяє миттєво обчислювати математичне сподівання дискретної випадкової величини `E[X] = P'(1)`, а друга похідна `P''(1)` дає можливість обчислити дисперсію `Var(X) = P''(1) + P'(1) - (P'(1))²`.

### 2. Реалізація формальних рядів мовами Python та C++

Наведена нижче програма містить повну реалізацію формальних степеневі рядів з автоматичним усіченням до `N` членів. Для демонстрації практичного застосування програма розв'язує дві класичні задачі:
1. **Числа Фібоначчі:** обчислюються шляхом обернення знаменника `Q(x) = 1 - x - x²` та множення результату на чисельник `P(x) = x`.
2. **Числа Каталана:** обчислюються шляхом ітераційного застосування функціонального рівняння `C_{k+1}(x) = 1 + x · C_k(x)²`.

```py
# -*- coding: utf-8 -*-
"""Модуль обчислення формальних степеневі рядів (Formal Power Series) мовою Python."""

class FormalPowerSeries:
    def __init__(self, coeffs, degree=16):
        """Ініціалізація ряду вектором коефіцієнтів із відтинанням до степеня degree."""
        self.deg = degree
        # Заповнюємо або усікаємо масив коефіцієнтів до довжини degree
        self.c = [float(x) for x in coeffs[:degree]]
        if len(self.c) < degree:
            self.c.extend([0.0] * (degree - len(self.c)))

    def __add__(self, other):
        """Почленне додавання двох рядів: C(x) = A(x) + B(x)."""
        res = [self.c[i] + other.c[i] for i in range(self.deg)]
        return FormalPowerSeries(res, self.deg)

    def __sub__(self, other):
        """Почленне віднімання двох рядів: C(x) = A(x) - B(x)."""
        res = [self.c[i] - other.c[i] for i in range(self.deg)]
        return FormalPowerSeries(res, self.deg)

    def __mul__(self, other):
        """Дискретна згортка (множення рядів): C(x) = A(x) * B(x) mod x^N."""
        res = [0.0] * self.deg
        for i in range(self.deg):
            for j in range(self.deg - i):
                res[i + j] += self.c[i] * other.c[j]
        return FormalPowerSeries(res, self.deg)

    def invert(self):
        """Алгебраїчне обернення ряду 1 / A(x). Вимагає A[0] != 0."""
        if abs(self.c[0]) < 1e-12:
            raise ValueError("Вільний член A[0] дорівнює 0, обернений ряд не існує.")
        
        b = [0.0] * self.deg
        b[0] = 1.0 / self.c[0]
        
        for k in range(1, self.deg):
            acc = 0.0
            for i in range(1, k + 1):
                acc += self.c[i] * b[k - i]
            b[k] = -acc / self.c[0]
            
        return FormalPowerSeries(b, self.deg)

    def derivative(self):
        """Формальне диференціювання: A'(x) = sum(n * a_n * x^(n-1))."""
        res = [0.0] * self.deg
        for i in range(1, self.deg):
            res[i - 1] = float(i) * self.c[i]
        return FormalPowerSeries(res, self.deg)


def solve_fibonacci(degree=12):
    """Обчислення чисел Фібоначчі за допомогою твірної функції F(x) = x / (1 - x - x^2)."""
    # Знаменник Q(x) = 1 - x - x^2
    q_coeffs = [1.0, -1.0, -1.0]
    Q = FormalPowerSeries(q_coeffs, degree)
    
    # Знаходимо 1 / Q(x)
    Q_inv = Q.invert()
    
    # Чисельник P(x) = x
    P = FormalPowerSeries([0.0, 1.0], degree)
    
    # F(x) = P(x) * (1 / Q(x))
    F = P * Q_inv
    return [round(x) for x in F.c]


def solve_catalan(degree=10):
    """Обчислення чисел Каталана через ітерацію C(x) = 1 + x * C(x)^2."""
    # Починаємо з наближення C_0(x) = 1
    C = FormalPowerSeries([1.0], degree)
    
    # Застосовуємо ітерацію фіксованої точки N разів
    for _ in range(degree):
        # C_{k+1}(x) = 1 + x * C_k(x)^2
        C_sq = C * C
        # Множення на x відповідає зсуву коефіцієнтів праворуч
        x_C_sq_coeffs = [0.0] + C_sq.c[:-1]
        x_C_sq = FormalPowerSeries(x_C_sq_coeffs, degree)
        
        one = FormalPowerSeries([1.0], degree)
        C = one + x_C_sq
        
    return [round(x) for x in C.c]


if __name__ == "__main__":
    print("Числа Фібоначчі через твірну функцію x/(1-x-x^2):")
    fibs = solve_fibonacci(12)
    for n, val in enumerate(fibs):
        print(f"F[{n}] = {val}")

    print("\nЧисла Каталана через твірну функцію C(x) = 1 + x*C(x)^2:")
    cats = solve_catalan(8)
    for n, val in enumerate(cats):
        print(f"C[{n}] = {val}")
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <stdexcept>
#include <iomanip>

/**
 * @brief Клас формального степенного ряду (Formal Power Series) мовою C++.
 * Реалізує обчислення коефіцієнтів ряду за модулем x^N (з усіченням до N).
 */
class FormalPowerSeries {
private:
    std::size_t degree_;
    std::vector<double> coeffs_;

public:
    explicit FormalPowerSeries(const std::vector<double>& coeffs, std::size_t degree = 16)
        : degree_(degree), coeffs_(degree, 0.0) {
        std::size_t limit = std::min(coeffs.size(), degree_);
        for (std::size_t i = 0; i < limit; ++i) {
            coeffs_[i] = coeffs[i];
        }
    }

    [[nodiscard]] std::size_t degree() const noexcept { return degree_; }
    [[nodiscard]] const std::vector<double>& coeffs() const noexcept { return coeffs_; }
    [[nodiscard]] double operator[](std::size_t idx) const { return coeffs_.at(idx); }

    FormalPowerSeries operator+(const FormalPowerSeries& other) const {
        std::vector<double> res(degree_, 0.0);
        for (std::size_t i = 0; i < degree_; ++i) {
            res[i] = coeffs_[i] + other.coeffs_[i];
        }
        return FormalPowerSeries(res, degree_);
    }

    FormalPowerSeries operator-(const FormalPowerSeries& other) const {
        std::vector<double> res(degree_, 0.0);
        for (std::size_t i = 0; i < degree_; ++i) {
            res[i] = coeffs_[i] - other.coeffs_[i];
        }
        return FormalPowerSeries(res, degree_);
    }

    /// Дискретна згортка коефіцієнтів O(N^2)
    FormalPowerSeries operator*(const FormalPowerSeries& other) const {
        std::vector<double> res(degree_, 0.0);
        for (std::size_t i = 0; i < degree_; ++i) {
            for (std::size_t j = 0; j < degree_ - i; ++j) {
                res[i + j] += coeffs_[i] * other.coeffs_[j];
            }
        }
        return FormalPowerSeries(res, degree_);
    }

    /// Обчислення оберненого ряду 1 / A(x)
    FormalPowerSeries invert() const {
        if (std::abs(coeffs_[0]) < 1e-12) {
            throw std::invalid_argument("Вільний член A[0] дорівнює 0, обернений ряд не існує.");
        }

        std::vector<double> b(degree_, 0.0);
        b[0] = 1.0 / coeffs_[0];

        for (std::size_t k = 1; k < degree_; ++k) {
            double acc = 0.0;
            for (std::size_t i = 1; i <= k; ++i) {
                acc += coeffs_[i] * b[k - i];
            }
            b[k] = -acc / coeffs_[0];
        }

        return FormalPowerSeries(b, degree_);
    }
};

int main() {
    constexpr std::size_t N = 12;

    // Обчислення Фібоначчі: F(x) = x / (1 - x - x^2)
    FormalPowerSeries Q({1.0, -1.0, -1.0}, N);
    FormalPowerSeries P({0.0, 1.0}, N);
    
    FormalPowerSeries Q_inv = Q.invert();
    FormalPowerSeries F = P * Q_inv;

    std::cout << "Числа Фібоначчі через твірну функцію C++:\n";
    for (std::size_t i = 0; i < 10; ++i) {
        std::cout << "F[" << i << "] = " << std::llround(F[i]) << "\n";
    }

    // Обчислення чисел Каталана через ітерацію C = 1 + x*C^2
    FormalPowerSeries C({1.0}, 8);
    FormalPowerSeries one({1.0}, 8);

    for (std::size_t iter = 0; iter < 8; ++iter) {
        FormalPowerSeries C_sq = C * C;
        std::vector<double> x_C_sq_coeffs(8, 0.0);
        for (std::size_t i = 0; i < 7; ++i) {
            x_C_sq_coeffs[i + 1] = C_sq[i];
        }
        FormalPowerSeries x_C_sq(x_C_sq_coeffs, 8);
        C = one + x_C_sq;
    }

    std::cout << "\nЧисла Каталана через твірну функцію C++:\n";
    for (std::size_t i = 0; i < 8; ++i) {
        std::cout << "C[" << i << "] = " << std::llround(C[i]) << "\n";
    }

    return 0;
}
```

### 3. Оптимізація обернення рядів за методом Ньютона

Прямий трикутний алгоритм обернення рядів має складність `O(N²)`. У комп'ютерній алгебрі для великих порядків `N ≥ 10⁴` використовують **метод подвоєння Ньютона** (англ. *Newton's iteration*).

Шукаючи нуль підінтегральної функції `f(B) = 1 / B - A`, формула Ньютона має вигляд:

```
B_{k+1}(x) = B_k(x) · (2 - A(x) · B_k(x)) mod x^(2^(k+1))
```

Починаючи з базового розв'язку `B₀(x) = 1 / a₀ mod x¹`, кожна ітерація Ньютона подвоює кількість точних коефіцієнтів ряду! Поєднуючи множення рядів через швидке перетворення Фур'є (FFT) за `O(N log N)`, метод Ньютона дозволяє знаходити обернений ряд `1 / A(x)` загалом за `O(N log N)` операцій.

### 4. Практичні пастки та обмеження обчислень

При роботі з програмними реалізаціями формальних степеневі рядів слід уникати трьох поширених помилок:

1. **Втрата точності та числове переповнення:**
   Комбінаторні послідовності (наприклад, числа Фібоначчі `F[n]` чи числа Каталана `C[n]`) зростають експоненціально або суперфакторіально. У стандартному типі `double` розрядна сітка мантиси становить 53 біти, що забезпечує точність цілих чисел лише до `2⁵³ ≈ 9 · 10¹⁵`. При `n > 78` числа Фібоначчі перевищують цю межу і втрачають точні молодші розряди. У промислових алгоритмах обчислення твірних функцій виконують у кільці лишків за модулем `Z / pZ` (де `p` — велике просте число, наприклад `998244353`) або з використанням бібліотек довгої арифметики довільної точності.

2. **Перевірка умов оберненості:**
   Якщо вільний член `a₀` дорівнює нулю, спроба обчислити `1 / A(x)` призводить до ділення на нуль. У такому разі ряд необхідно факторизувати: `A(x) = xᵐ · Ã(x)`, де `ã₀ ≠ 0`. Тоді `1 / A(x) = x⁻ᵐ · (1 / Ã(x))`, що переходить у простір формальних рядів Лорана.

3. **Незбіжність ітерацій фіксованої точки:**
   При обчисленні чисел Каталана за допомогою рівняння `C_{k+1}(x) = 1 + x · C_k(x)²` кожна ітерація додає рівно один новий точний коефіцієнт `C[n]`. Для обчислення `N` коефіцієнтів потрібно виконати рівно `N` ітерацій. Використання ж методу Ньютона для нелінійних рівнянь рядів дозволяє отримувати точні коефіцієнти квадратично швидше.
