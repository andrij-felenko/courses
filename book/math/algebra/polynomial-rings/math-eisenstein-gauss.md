# 🧮 Критерій Ейзенштейна, лема Ґаусса та головні ідеали: алгебраїчні доведення

Безпосередня перевірка многочлена на незвідність шляхом перебору всіх можливих дільників стає нездійсненною вже для помірних степенів, а доведення факторіальності кілець вимагає суворого аналізу структури ідеалів. Алгебраїчні інструменти Ґаусса та Ейзенштейна дають прямі критерії незвідності та встановлюють фундаментальні властивості кілець многочленів.

---

### 1. Доведення: кільце многочленів над полем K[x] є кільцем головних ідеалів (PID)

Нехай `K` — довільне поле, а `I ⊆ K[x]` — довільний ідеал у кільці многочленів. Необхідно довести, що існує такий єдиний зведений многочлен `d(x) ∈ K[x]`, що весь ідеал складається виключно з його кратних: `I = (d(x)) = { q(x) · d(x) | q(x) ∈ K[x] }`.

**Доведення:**

1. Якщо ідеал є тривіальним `I = {0}`, то твердження виконується автоматично для нульового многочлена `d(x) = 0`.

2. Нехай `I` містить ненульові елементи. Розглянемо множину степенів усіх ненульових многочленів із цього ідеалу:
```
S = { deg(f) | f(x) ∈ I, f(x) ≠ 0 } ⊆ ℕ ∪ {0}
```

3. Оскільки множина `S` є непорожньою підмножиною невід'ємних цілих чисел, за принципом найменшого елемента в ній існує мінімальне значення `n = min(S)`.

4. Оберімо в ідеалі `I` будь-який многочлен `d(x)`, степінь якого дорівнює цьому мінімуму: `deg(d) = n`. Помноживши його на обернений до старшого коефіцієнта скаляр з поля `K`, зробимо `d(x)` унітарним (зведеним). Оскільки ідеал замкнений щодо множення на скаляри, `d(x) ∈ I`.

5. Візьмемо довільний многочлен `f(x) ∈ I`. За теоремою про ділення з остачею в `K[x]` поділимо `f(x)` на `d(x)`:
```
f(x) = q(x) · d(x) + r(x)      [ділення з остачею в K[x]]
```
де частка `q(x) ∈ K[x]`, а для остачі виконується: `deg(r) < deg(d) = n` або `r(x) = 0`.

6. Виразимо остачу з цієї рівності:
```
r(x) = f(x) − q(x) · d(x)      [перенесення доданка]
```

7. Оскільки `f(x) ∈ I`, а `d(x) ∈ I`, добуток `q(x) · d(x)` також належить `I` (за означенням ідеалу: замкненість щодо множення на елементи кільця). Різниця двох елементів ідеалу належить `I`, отже:
```
r(x) ∈ I
```

8. Якби остача `r(x)` була ненульовою, її степінь задовольняв би нерівність `deg(r) < n`. Проте `n` було обрано як строго мінімальний степінь серед усіх ненульових елементів `I`. Отримане протиріччя доводить, що:
```
r(x) = 0
```

9. Звідси випливає рівність `f(x) = q(x) · d(x)`, тобто довільний елемент `f(x) ∈ I` є кратним `d(x)`. Це доводить, що `I = (d(x))`. Оскільки кожен ідеал породжується одним елементом, кільце `K[x]` є кільцем головних ідеалів.

### 2. Лема Ґаусса про примітивні многочлени

Для многочлена з цілими коефіцієнтами `f(x) = aₙxⁿ + … + a₁x + a₀ ∈ ℤ[x]` його **вмістом** `cont(f)` називають найбільший спільний дільник усіх його коефіцієнтів: `cont(f) = НСД(aₙ, …, a₁, a₀)`. Многочлен називають **примітивним**, якщо його вміст дорівнює одиниці: `cont(f) = 1`.

**Формулювання леми:**
Добуток двох примітивних многочленів `f(x), g(x) ∈ ℤ[x]` є примітивним многочленом, тобто `cont(f · g) = 1`.

**Доведення від супротивного:**

1. Припустимо, що добуток `h(x) = f(x) · g(x)` не є примітивним. Це означає, що існує деяке просте число `p`, яке ділить усі коефіцієнти многочлена `h(x)`.

2. Розглянемо гомоморфізм редукції коефіцієнтів за модулем простого числа `p`:
```
ψ_p : ℤ[x] → 𝔽_p[x],   де c · xᵏ ↦ (c mod p) · xᵏ
```

3. Оскільки редукція поважає операції додавання та множення многочленів, маємо:
```
ψ_p(f · g) = ψ_p(f) · ψ_p(g)      [гомоморфізм кілець]
```

4. За нашим припущенням число `p` ділить усі коефіцієнти добутку `h(x) = f(x) · g(x)`. Це означає, що редукований многочлен тотожно дорівнює нулю в `𝔽_p[x]`:
```
ψ_p(f) · ψ_p(g) = 0 ∈ 𝔽_p[x]
```

5. Оскільки `p` — просте число, поле лишків `𝔽_p` є числовим полем, а отже кільце многочленів `𝔽_p[x]` є **областю цілісності** (не містить дільників нуля).

6. Якщо добуток двох елементів в області цілісності дорівнює нулю, то принаймні один із множників зобов'язаний дорівнювати нулю:
```
ψ_p(f) = 0   або   ψ_p(g) = 0
```

7. Рівність `ψ_p(f) = 0` означає, що просте число `p` ділить усі коефіцієнти многочлена `f(x)`, що суперечить умові його примітивності (`cont(f) = 1`). Аналогічно, рівність `ψ_p(g) = 0` суперечить примітивності `g(x)`.

8. Отримане протиріччя доводить, що жодне просте число `p` не може ділити всі коефіцієнти добутку `f(x) · g(x)`. Отже, `cont(f · g) = 1`.

**Важливий наслідок:** Многочлен `f(x) ∈ ℤ[x]` розкладається на множники в кільці раціональних многочленів `ℚ[x]` тоді й лише тоді, коли він розкладається на множники тих самих степенів у цілочисловому кільці `ℤ[x]`.

### 3. Критерій незвідності Ейзенштейна

Нехай задано многочлен із цілими коефіцієнтами:
```
f(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀ ∈ ℤ[x],   де deg(f) = n ≥ 1
```

Якщо існує таке просте число `p`, що одночасно виконуються три умови:
1. `p` ділить усі коефіцієнти, крім старшого: `p | aᵢ` для всіх `i ∈ {0, 1, …, n - 1}`;
2. `p` не ділить старший коефіцієнт: `p ∤ aₙ`;
3. Квадрат простого числа `p²` не ділить вільний член: `p² ∤ a₀`,

то многочлен `f(x)` є незвідним над полем раціональних чисел `ℚ` (і в кільці `ℤ[x]`, якщо `cont(f) = 1`).

**Доведення від супротивного:**

1. Припустимо, що `f(x)` є звідним над `ℚ`. За наслідком із леми Ґаусса він розкладається на два многочлени додатних степенів із цілими коефіцієнтами:
```
f(x) = g(x) · h(x)
```
де:
```
g(x) = bₖxᵏ + … + b₁x + b₀,   deg(g) = k ≥ 1
h(x) = cₘxᵐ + … + c₁x + c₀,   deg(h) = m ≥ 1
k + m = n = deg(f)
```

2. Застосуємо редукцію коефіцієнтів за модулем `p`. Оскільки `p` ділить усі коефіцієнти `a₀, a₁, …, aₙ₋₁`, у полі `𝔽_p` редукований многочлен має лише старший член:
```
ψ_p(f(x)) = (aₙ mod p) · xⁿ ≠ 0      [оскільки p ∤ aₙ]
```

3. З іншого боку, редукція добутку дає:
```
ψ_p(f(x)) = ψ_p(g(x)) · ψ_p(h(x)) = (aₙ mod p) · xⁿ
```

4. У кільці многочленів над полем `𝔽_p[x]` єдиними дільниками монома `xⁿ` є мономи виду `c · xʲ`. Це означає, що редуковані многочлени `ψ_p(g)` та `ψ_p(h)` також зобов'язані бути чистими мономами степенів `k` та `m`:
```
ψ_p(g(x)) = (bₖ mod p) · xᵏ
ψ_p(h(x)) = (cₘ mod p) · xᵐ
```

5. Звідси випливає, що всі молодші коефіцієнти обох многочленів при редукції стають нулями. Зокрема, їхні вільні члени діляться на `p`:
```
p | b₀   та   p | c₀
```

6. Розглянемо тепер вільний член вихідного многочлена `f(x)` у кільці `ℤ`:
```
a₀ = b₀ · c₀      [вільний член добутку двох многочленів]
```

7. Оскільки `p | b₀` (тобто `b₀ = p · u`) та `p | c₀` (тобто `c₀ = p · v`), отримуємо:
```
a₀ = (p · u) · (p · v) = p² · (u · v)
```
Це означає, що `p² | a₀`.

8. Рівність `p² | a₀` прямо суперечить третій умові критерію Ейзенштейна (`p² ∤ a₀`). Отримане протиріччя доводить, що розклад `f(x) = g(x) · h(x)` на многочлени менших додатних степенів неможливий. Многочлен `f(x)` є незвідним над `ℚ`.

### 4. Застосування: незвідність кругових многочленів

Розглянемо круговий многочлен для простого числа `p`:
```
Φ_p(x) = (xᵖ − 1) / (x − 1) = xᵖ⁻¹ + xᵖ⁻² + … + x + 1
```

Безпосередньо застосувати критерій Ейзенштейна до `Φ_p(x)` не можна, оскільки всі його коефіцієнти дорівнюють одиниці (`1` не ділиться на жодне просте число).

Виконаємо алгебраїчну заміну змінної `x = y + 1`:
```
f(y) = Φ_p(y + 1) = ((y + 1)ᵖ − 1) / y
```

Розкриємо чисельник за біномом Ньютона:
```
(y + 1)ᵖ = yᵖ + C(p, 1)·yᵖ⁻¹ + C(p, 2)·yᵖ⁻² + … + C(p, p - 1)·y + 1
```

Віднімаючи одиницю та ділячи на `y`, отримуємо многочлен від змінної `y`:
```
f(y) = yᵖ⁻¹ + C(p, 1)·yᵖ⁻² + C(p, 2)·yᵖ⁻³ + … + C(p, p - 1)
```

Перевіримо умови критерію Ейзенштейна за тим самим простим числом `p`:
1. Старший коефіцієнт дорівнює `1` (не ділиться на `p`).
2. Кожен біноміальний коефіцієнт `C(p, k) = p! / (k! · (p - k)!)` для `1 ≤ k ≤ p - 1` містить просте число `p` у чисельнику, яке не скорочується зі знаменником, отже `p | C(p, k)`.
3. Вільний член `a₀ = C(p, p - 1) = p` ділиться на `p`, але `p² = p² ∤ p` (не ділиться на квадрат).

Усі умови Ейзенштейна виконано, отже `f(y) = Φ_p(y + 1)` є незвідним над `ℚ`. Оскільки зсув змінної `x ↦ y + 1` є ізоморфізмом кілець `ℚ[x] ≅ ℚ[y]`, вихідний круговий многочлен `Φ_p(x)` також є строго незвідним над полем раціональних чисел.
