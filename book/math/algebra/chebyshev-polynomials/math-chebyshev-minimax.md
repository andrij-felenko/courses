# 🧮 Доведення мінімаксної властивості поліномів Чебишова

В даній математичній вставці розглядається суворе алгебраїчне доведення теореми Чебишова про найменше відхилення від нуля. Це доведення пояснює, чому серед усіх нормованих многочленів степеня `n` на відрізку `[-1, 1]` саме поліном Чебишова першого роду, поділений на `2ⁿ⁻¹`, має найменшу можливу чебишовську норму (максимальне абсолютне значення). Без цього математичного підґрунтя мінімаксний характер вузлів Чебишова у чисельній інтерполяції сприймався б як випадковий числовий збіг.

### 1. Постановка задачі та чебишовська норма

Розглянемо простір усіх дійсних поліномів степеня `n` зі старшим коефіцієнтом, рівним одиниці (так звані **приведені або нормовані многочлени**, англ. *monic polynomials*):

```
Pₙ(x) = xⁿ + aₙ₋₁ · xⁿ⁻¹ + aₙ₋₂ · xⁿ⁻² + … + a₁ · x + a₀
```

Для довільної неперервної функції `f(x)` на відрізку `I = [-1, 1]` визначимо **чебишовську норму** (або рівномірну норму, `L_∞`-норму) як максимальне абсолютне значення функції на цьому відрізку:

```
║f║_∞ = max |f(x)|    (по всіх x від -1 до 1)
```

Задача оптимізації полягає у знаходженні такого нормованого многочлена `Pₙ*(x)`, який мінімізує значення чебишовської норми `║Pₙ║_∞`:

```
║Pₙ*║_∞ = min ║Pₙ║_∞    (по всіх нормованих многочленах Pₙ степеня n)
```

Ця задача має принципове значення для обчислювальної математики: якщо ми наближаємо довільну неперервну функцію `f(x)` інтерполяційним многочленом Лагранжа степеня `n - 1` по вузлах `x₁, x₂, …, xₙ`, то похибка інтерполяції має вигляд:

```
f(x) - Lₙ₋₁(x) = (fⁿ⁽xi⁾ / n!) · ∏ (x - x╟)    (добуток по k від 1 до n)
```

Фактор `ωₙ(x) = ∏ (x - x╟)` є нормованим многочленом степеня `n`. Отже, мінімізація максимального відхилення інтерполяційної похибки еквівалентна мінімізації норми `║ωₙ║_∞` серед усіх нормованих многочленів.

### 2. Нормований поліном Чебишова та його екстремальні точки

Згадаємо тригонометричне означення полінома Чебишова першого роду `Tₙ(x)` для `x = cos(θ) ∈ [-1, 1]`:

```
Tₙ(cos θ) = cos(n θ)
```

Знайдемо старший коефіцієнт многочлена `Tₙ(x)` при `xⁿ` для `n ≥ 1`. Скористаємося тригонометричним тотожністю Де Муавра:

```
cos(n θ) + i · sin(n θ) = (cos θ + i · sin θ)ⁿ
```

Розкриваючи біном Ньютона і виділяючи дійсну частину, бачимо, що старший доданок виникає при `(cos θ)ⁿ` зі старшим коефіцієнтом `2ⁿ⁻¹` для `n ≥ 1`:

```
T₀(x) = 1                              [старший коефіцієнт дорівнює 1]
T₁(x) = x                              [старший коефіцієнт дорівнює 1 = 2⁰]
T₂(x) = 2·x² - 1                       [старший коефіцієнт дорівнює 2 = 2¹]
T₃(x) = 4·x³ - 3·x                     [старший коефіцієнт дорівнює 4 = 2²]
T₄(x) = 8·x⁴ - 8·x² + 1                [старший коефіцієнт дорівнює 8 = 2³]
Tₙ(x) = 2ⁿ⁻¹ · xⁿ + …                  [старший коефіцієнт дорівнює 2ⁿ⁻¹]
```

Побудуємо нормований поліном Чебишова `T̃ₙ(x)`, поділивши `Tₙ(x)` на його старший коефіцієнт `2ⁿ⁻¹`:

```
T̃ₙ(x) = (1 / 2ⁿ⁻¹) · Tₙ(x)
```

Оскільки `║Tₙ║_∞ = max |cos(n θ)| = 1`, чебишовська норма нормованого полінома `T̃ₙ(x)` дорівнює:

```
║T̃ₙ║_∞ = 1 / 2ⁿ⁻¹
```

Розглянемо значення `T̃ₙ(x)` у спеціально вибраних `n + 1` точках відрізка `[-1, 1]`, які відповідають екстремумам функції `cos(n θ)`:

```
θₖ = k · π / n    (для k від 0 до n)
xₖ = cos(k · π / n)
```

Зауважимо, що `x₀ = 1`, `xₙ = -1`, і точки `x₀ > x₁ > x₂ > … > xₙ` впорядковані за спаданням на відрізку `[-1, 1]`. Знайдемо значення `T̃ₙ(xₖ)` у цих точках:

```
T̃ₙ(xₖ) = (1 / 2ⁿ⁻¹) · Tₙ(cos(k · π / n))
       = (1 / 2ⁿ⁻¹) · cos(n · k · π / n)        [за тригонометричним означенням Tₙ]
       = (1 / 2ⁿ⁻¹) · cos(k · π)                [скоротили n у чисельнику й знаменнику]
       = (-1)ᵏ / 2ⁿ⁻¹                           [оскільки cos(k·π) дорівнює (-1)ᵏ]
```

Таким чином, у `n + 1` точках `xₖ` нормований поліном Чебишова `T̃ₙ(x)` послідовно набуває значений із чергуванням знаків:

```
T̃ₙ(x₀) = +1 / 2ⁿ⁻¹
T̃ₙ(x₁) = -1 / 2ⁿ⁻¹
T̃ₙ(x₂) = +1 / 2ⁿ⁻¹
…
T̃ₙ(xₙ) = (-1)ⁿ / 2ⁿ⁻¹
```

Ці `n + 1` точок утворюють так званий **альтернанс Чебишова**.

### 3. Суворе доведення методом від супротивного

Сформулюємо головне твердження теореми:

> **Теорема Чебишова.** Для будь-якого дійсного нормованого многочлена `Pₙ(x) = xⁿ + …` степеня `n ≥ 1` на відрізку `[-1, 1]` виконується нерівність `║Pₙ║_∞ ≥ 1 / 2ⁿ⁻¹`. Рівність досягається тоді й лише тоді, коли `Pₙ(x) = T̃ₙ(x)`.

Доведемо це твердження від супротивного кроками.

**Крок 1. Припущення супротивного.**
Припустимо, що існує якийсь дійсний нормований многочлен `Qₙ(x) = xⁿ + bₙ₋₁ · xⁿ⁻¹ + … + b₀` степеня `n`, чебишовська норма якого суворо менша за `1 / 2ⁿ⁻¹`:

```
║Qₙ║_∞ < 1 / 2ⁿ⁻¹
```

Це означає, що для всіх `x ∈ [-1, 1]` виконується сувора подвійна нерівність:

```
-1 / 2ⁿ⁻¹ < Qₙ(x) < 1 / 2ⁿ⁻¹
```

**Крок 2. Побудова допоміжного многочлена різниці.**
Розглянемо різницю двох нормованих многочленів:

```
R(x) = T̃ₙ(x) - Qₙ(x)
```

Оскільки обидва многочлени `T̃ₙ(x)` та `Qₙ(x)` є нормованими степеня `n`, їхні старші члени `xⁿ` абсолютно однакові й при відніманні взаємно знищуються:

```
R(x) = (xⁿ + aₙ₋₁·xⁿ⁻¹ + …) - (xⁿ + bₙ₋₁·xⁿ⁻¹ + …)
     = (aₙ₋₁ - bₙ₋₁)·xⁿ⁻¹ + (aₙ₋₂ - bₙ₋₂)·xⁿ⁻² + …
```

Отже, многочлен `R(x)` має степінь **не більше `n - 1`** (`deg(R) ≤ n - 1`).

**Крок 3. Дослідження знаків різниці R(x) у точках альтернансу.**
Обчислимо значення допоміжного многочлена `R(x)` у точках альтернансу `xₖ = cos(k · π / n)` для `k = 0, 1, 2, …, n`:

```
R(xₖ) = T̃ₙ(xₖ) - Qₙ(xₖ) = ((-1)ᵏ / 2ⁿ⁻¹) - Qₙ(xₖ)
```

Проаналізуємо знак виразу `R(xₖ)` окремо для парних та непарних індексів `k`:

1. **Для парних індексів `k` (k = 0, 2, 4, …):**
   Сума `(-1)ᵏ = +1`, тому `T̃ₙ(xₖ) = +1 / 2ⁿ⁻¹`.
   Згідно з припущенням, `Qₙ(xₖ) < 1 / 2ⁿ⁻¹`. Звідси:
   ```
   R(xₖ) = (1 / 2ⁿ⁻¹) - Qₙ(xₖ) > 0
   ```

2. **Для непарних індексів `k` (k = 1, 3, 5, …):**
   Сума `(-1)ᵏ = -1`, тому `T̃ₙ(xₖ) = -1 / 2ⁿ⁻¹`.
   Згідно з припущенням, `Qₙ(xₖ) > -1 / 2ⁿ⁻¹`. Звідси:
   ```
   R(xₖ) = (-1 / 2ⁿ⁻¹) - Qₙ(xₖ) < 0
   ```

Таким чином, знак значення `R(xₖ)` суворо збігається зі знаком `(-1)ᵏ`:

```
R(x₀) > 0
R(x₁) < 0
R(x₂) > 0
R(x₃) < 0
…
R(xₙ) має знак (-1)ⁿ
```

**Крок 4. Застосування теореми Больцано-Коші та підрахунок коренів.**
Многочлен `R(x)` є неперервною функцією на відрізку `[-1, 1]`. На кінцях кожного з `n` послідовних інтервалів `(x₁, x₀), (x₂, x₁), (x₃, x₂), …, (xₙ, xₙ₋₁)` значення `R(x)` мають протилежні знаки.

За теоремою Больцано-Коші про проміжні значення неперервної функції, всередині кожного з цих `n` відкритих інтервалів існує принаймні один дійсний корінь многочлена `R(x)`.

Оскільки всі `n` інтервалів не перетинаються між собою, многочлен `R(x)` має **щонайменше `n` різних дійсних коренів**.

**Крок 5. Отримання суперечності.**
Ми отримали два твердження щодо многочлена `R(x)`:
1. З Кроку 2: степінь `R(x)` не перевищує `n - 1` (`deg(R) ≤ n - 1`).
2. З Кроку 4: `R(x)` має щонайменше `n` різних коренів.

За основною теоремою алгебри, ненульовий многочлен степеня `d` може мати не більше `d` коренів. Многочлен степеня не більше `n - 1` не може мати `n` коренів, якщо тільки він не є **тотожним нулем**:

```
R(x) ≡ 0    на всьому відрізку [-1, 1]
```

Але якщо `R(x) ≡ 0`, то `T̃ₙ(x) - Qₙ(x) ≡ 0`, звідки випливає, що `Qₙ(x) ≡ T̃ₙ(x)`.

Це тотожне збігання повністю суперечить нашому вихідному припущенню про те, що `║Qₙ║_∞ < 1 / 2ⁿ⁻¹`, оскільки норма `T̃ₙ(x)` дорівнює точно `1 / 2ⁿ⁻¹`.

**Висновок:** Припущення було хибним. Жоден нормований многочлен степеня `n` не може мати чебишовську норму, меншу за `1 / 2ⁿ⁻¹`. Теорему повністю доведено. `■`

### 4. Єдиність оптимального многочлена

Виникає природне питання: а чи не існує якогось **іншого** нормованого многочлена `Sₙ(x) ≠ T̃ₙ(x)`, норма якого була б **точно рівною** `1 / 2ⁿ⁻¹`?

Доведемо єдиність оптимального многочлена:

Припустимо, що існує нормований многочлен `Sₙ(x) ≠ T̃ₙ(x)` такий, що `║Sₙ║_∞ = 1 / 2ⁿ⁻¹`.
Розглянемо півсуму двох оптимальних многочленів:

```
M(x) = (1 / 2) · (T̃ₙ(x) + Sₙ(x))
```

Многочлен `M(x)` також є нормованим степеня `n`, оскільки обидва доданки мали старші члени `xⁿ`. З нерівності трикутника для норм випливає:

```
║M║_∞ ≤ (1 / 2) · (║T̃ₙ║_∞ + ║Sₙ║_∞) = 1 / 2ⁿ⁻¹
```

Оскільки `║T̃ₙ║_∞ = 1 / 2ⁿ⁻¹` є мінімально можливою нормою, то `║M║_∞` також має дорівнювати `1 / 2ⁿ⁻¹`.
Але в точках альтернансу `xₖ`, де `T̃ₙ(xₖ) = (-1)ᵏ / 2ⁿ⁻¹`, значення `M(xₖ)` може досягати норми `1 / 2ⁿ⁻¹` лише за умови, що `Sₙ(xₖ) = T̃ₙ(xₖ)`.

Це означає, що різниця `D(x) = T̃ₙ(x) - Sₙ(x)` дорівнює нулю у всіх `n + 1` точках альтернансу `xₖ`.
Оскільки `deg(D) ≤ n - 1`, а число коренів дорівнює `n + 1`, многочлен `D(x)` тотожно дорівнює нулю (`Sₙ(x) ≡ T̃ₙ(x)`).

Отже, нормований поліном Чебишова `T̃ₙ(x)` є **єдиним** нормованим многочленом степеня `n`, який мінімізує `L_∞`-норму на `[-1, 1]`.

### 5. Числовий розбір для випадку n = 3

Щоб остаточно закріпити алгебраїчну інтуїцію доведення, простежимо всі величини на конкретному числовому прикладі для степеня `n = 3`.

Загальний вигляд нормованого кубічного многочлена:

```
P₃(x) = x³ + a₂ · x² + a₁ · x + a₀
```

Знайдемо нормований поліном Чебишова `T̃₃(x)`:

```
T₃(x) = 4 · x³ - 3 · x
T̃₃(x) = T₃(x) / 4 = x³ - (3 / 4) · x
```

Точна чебишовська норма `T̃₃(x)` на `[-1, 1]` дорівнює:

```
║T̃₃║_∞ = 1 / 2³⁻¹ = 1 / 4 = 0.25
```

Знайдемо `n + 1 = 4` точок альтернансу `xₖ = cos(k · π / 3)` для `k = 0, 1, 2, 3`:

```
x₀ = cos(0) = 1.0
x₁ = cos(π / 3) = 0.5
x₂ = cos(2π / 3) = -0.5
x₃ = cos(π) = -1.0
```

Обчислимо значення `T̃₃(x)` у цих точках:

```
T̃₃(1.0)  = (1.0)³ - 0.75 · (1.0)  =  1.0  - 0.75 =  0.25
T̃₃(0.5)  = (0.5)³ - 0.75 · (0.5)  =  0.125 - 0.375 = -0.25
T̃₃(-0.5) = (-0.5)³ - 0.75 · (-0.5) = -0.125 + 0.375 =  0.25
T̃₃(-1.0) = (-1.0)³ - 0.75 · (-1.0) = -1.0  + 0.75 = -0.25
```

Порівняємо `T̃₃(x)` з іншими популярними нормованими кубічними многочленами:

1. **Простий моном `P(x) = x³`:**
   Його норма `║P║_∞ = max |x³| = 1.0` на `[-1, 1]`.
   Відхилення монома `x³` у 4 рази гірше (1.0 проти 0.25), ніж у полінома Чебишова `T̃₃(x)`.

2. **Спроба зменшити локальний екстремум `Q(x) = x³ - 0.5 · x`:**
   Знайдемо критичні точки `Q'(x) = 3x² - 0.5 = 0 ⟹ x = ±√(1/6) ≈ ±0.4082`.
   Значення у внутрішній критичній точці:
   ```
   Q(0.4082) = (0.4082)³ - 0.5 · (0.4082) ≈ 0.068 - 0.2041 = -0.1361
   ```
   Внутрішній сплеск за модулем маленький (`0.1361 < 0.25`). Однак перевіримо межу відрізка при `x = 1.0`:
   ```
   Q(1.0) = (1.0)³ - 0.5 · (1.0) = 0.5
   ```
   Чебишовська норма `║Q║_∞ = max(0.1361, 0.5) = 0.5`.
   Спроба покращити поведінку всередині відрізка призвела до викиду похибки на межі до `0.5`, що вдвічі гірше за результат Чебишова `0.25`.

Зведена порівняльна таблиця випробовуваних нормованих кубічних многочленів:

| Многочлен `P₃(x)` | `P(0.5)` | `P(1.0)` | `║P₃║_∞` | Співвідношення з Чебишовим |
|---|---|---|---|---|
| **`T̃₃(x) = x³ - 0.75·x`** | **-0.25** | **+0.25** | **0.25** | **1.0 (оптимум)** |
| `P(x) = x³` | +0.125 | +1.0 | 1.00 | у 4.0 рази гірше |
| `Q(x) = x³ - 0.5·x` | -0.125 | +0.5 | 0.50 | у 2.0 рази гірше |
| `S(x) = x³ - 0.9·x` | -0.325 | +0.1 | 0.325 | у 1.3 рази гірше |

Цей числовий розрахунок наочно показує механізм рівноколиваності (equiripple): поліном Чебишова розподіляє відхилення абсолютно рівномірно між усіма екстремумами, не залишаючи жодної «слабкої зони», де похибка могла б вирости.
