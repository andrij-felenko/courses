# Поліноми Чебишова

<preknowlist>

- [Формула Ейлера](book:math/euler-formula) — зв'язок тригонометрії та комплексної експоненти: дає змогу швидко виводити співвідношення для косинусів кратних кутів.
- [Твірні функції](book:math/generating-functions) — упаковка послідовностей у степеневі ряди: твірна функція поліномів Чебишова компактно кодує рекурентні співвідношення.
</preknowlist>

Коли обчислювальна система намагається обчислити значення неперервної функції `f(x)` на відрізку `[-1, 1]` — наприклад, косинус, експоненту чи траєкторію робота — за допомогою звичайного інтерполяційного многочлена Лагранжа з рівновіддаленими вузлами `x╟ = -1 + 2k/n`, вона швидко потрапляє у катастрофічну пастку. Зі збільшенням степеня полінома `n` наближення не покращується, а навпаки, починає дико осцилювати поблизу меж відрізка `x = ±1`. Похибка на межах зростає експоненційно, перетворюючи обчислення на хаос. Цю руйнівну поведінку називають **феноменом Рунге** (англ. *Runge's phenomenon*, на честь німецького математика Карла Рунге).

Причина цього провалу криється у формулі похибки інтерполяції Лагранжа:

```
f(x) - Pₙ₋₁(x) = (fⁿ⁾(ξ) / n!) · ωₙ(x)
```

Де фактор `ωₙ(x) = (x - x₁)·(x - x₂)·…·(x - xₙ)` є добутком вузлових різниць. Якщо вузли `x╟` розміщено рівномірно, вираз `ωₙ(x)` на краях відрізка утворює величезні «піки», через які максимальне відхилення інтерполянта прагне до нескінченності.

Щоб повністю придушити феномен Рунге, необхідно вибрати вузли `x╟` таким чином, щоб нормований многочлен `ωₙ(x)` мав **найменше можливе максимальне значення** на всьому відрізку `[-1, 1]`. Єдиною алгебраїчною родиною поліномів, яка мінімізує це відхилення, є **поліноми Чебишова** (англ. *Chebyshev polynomials*, на честь видатного математика Пафнутія Чебишова, родом із франко-грецької традиції математичного аналізу). А про те, як прикладне інженерне завдання вдосконалення парових машин Джеймса Ватта у XVIII столітті спричинило відкриття цих многочленів — розписано в окремому історичному нарисі: [історію виникнення поліномів Чебишова](book:math/algebra/chebyshev-polynomials/hist-chebyshev.md).

### 1. Еволюція апроксимації: чому Тейлор і Лагранж ламаються на межах

Щоб збагнути фундаментальну необхідність поліномів Чебишова, проаналізуємо два класичні підходи до наближення функцій — розклад у ряд Тейлора та інтерполяцію Лагранжа на рівномірній сітці.

**1. Недоліки розкладу Тейлора (локальність проти глобальності):**
Ряд Тейлора проектує функцію `f(x)` в околі однієї точки `x₀` (найчастіше `x₀ = 0`):

```
f(x) = f(x₀) + f′(x₀)·(x - x₀) + (f″(x₀)/2!)·(x - x₀)² + …
```

Многочлен Тейлора забезпечує ідеальний збіг похідних у точці `x₀`. Однак у міру віддалення від `x₀` похибка зростає з катастрофічною швидкістю. Для таких функцій, як `f(x) = 1 / (1 + 25x²)`, радіус збіжності ряду Тейлора в околі нуля дорівнює всього `R = 1/5 = 0.2` через наявність комплексних полюсів `x = ±i/5`. Навіть якщо взяти 100 членів ряду Тейлора, у точках `x = ±0.9` результат буде абсолютно хибним. Ряд Тейлора є суворо локальним інструментом, оскільки він намагається зібрати всю інформацію про функцію в одній точці за допомогою її вищих похідних.

**2. Недоліки інтерполяції Лагранжа на рівномірній сітці (константа Лебега):**
Прагнучи рівномірно охопити весь відрізок `[-1, 1]`, природно розбити його на `n` рівних частин `x╟ = -1 + 2k/n`. Побудований інтерполяційний поліном Лагранжа має вигляд:

```
Lₙ₋₁(x) = ∑ f(x╟) · ℓ╟(x)    (сума по k від 1 до n)
```

де `ℓ╟(x) = ∏ (x - xⱼ) / (x╟ - xⱼ)` (для `j ≠ k`) — базисні поліноми Лагранжа.

Точність такої інтерполяції контролюється так званою **константою Лебега** (англ. *Lebesgue constant*) `Λₙ`:

```
║f - Lₙ₋₁║_∞ ≤ (1 + Λₙ) · Eₙ₋₁(f)
```

де `Eₙ₋₁(f)` — найкраще можливе наближення многочленом степеня `n - 1`.

Для рівномірної сітки вузлів константа Лебега зростає експоненційно:

```
Λₙ ~ 2ⁿ / (e · n · ln n)    (при n → ∞)
```

Це означає, що зі збільшенням кількості рівномірних вузлів похибка інтерполяції не прямує до нуля, а розганяється до нескінченності. Видатні математики Фелікс Бернштейн та Ґеорґ Фабер довели теорему про те, що не існує такої послідовності інтерполяційних вузлів, для якої константа Лебега залишалася б обмеженою числом (`Λₙ = O(1)`).

Проведемо порівняльний аналіз зростання константи Лебега `Λₙ` залежно від кількості вузлів `N` для двох типів сіток у зведеній таблиці:

| Кількість вузлів `N` | Рівномірна сітка `Λₙ` | Сітка вузлів Чебишова `Λₙ` | Співвідношення покращення |
|---|---|---|---|
| `N = 5` | `3.10` | `1.99` | у 1.6 разів краще |
| `N = 10` | `29.9` | `2.42` | у 12.3 разів краще |
| `N = 15` | `512` | `2.67` | у 191 раз краще |
| `N = 20` | `10 986` | `2.85` | у 3 854 разів краще |
| `N = 30` | `6.8 × 10⁶` | `3.11` | у 2.1 × 10⁶ разів краще |
| `N = 50` | `3.1 × 10¹²` | `3.44` | у 9.0 × 10¹¹ разів краще |

Ця таблиця наочно демонструє обчислювальний крах рівномірної сітки: вже при 50 вузлах похибка рівномірної інтерполяції підсилюється у три трильйони разів, тоді як для вузлів Чебишова підсилення не перевищує 3.44!

Проведемо конкретний числовий розрахунок для функції Рунге `f(x) = 1 / (1 + 25x²)` при `N = 11` вузлах на точці `x = 0.95`:

```
Рівномірні вузли:   x╟ = -1.0, -0.8, -0.6, …, 0.8, 1.0
Значення Лагранжа:  L₁₀(0.95) ≈ 0.174
Точне значення:     f(0.95) ≈ 0.0424
Абсолютна похибка:  |f - L₁₀| ≈ 0.1316  (похибка перевищує 300%!)
```

Причиною такої розбіжності є поведінка базисного полінома `ℓ₁₀(x)` на межі: при наближенні до `x = 1.0` коефіцієнти знаменника `(x╟ - xⱼ)` стають дрібними, а чисельник `(x - xⱼ)` накопичує добуток від усіх 10 сусідніх точок, створюючи величезне підсилення похибки.

Однак постає питання: **який розподіл вузлів забезпечує повільне, мінімально можливе зростання константи Лебега?**

Відповідь дають вузли Чебишова: для коренів полінома Чебишова константа Лебега зростає логарифмічно:

```
Λₙ ~ (2 / π) · ln(n) + C    (при n → ∞)
```

Логарифмічне зростання `ln(n)` є асимптотично найповільнішим із усіх можливих у математиці. Вузли Чебишова є практично ідеальним розподілом точок для глобальної інтерполяції.

### 2. Два обличчя поліномів Чебишова першого роду: тригонометрія та рекурентність

Фундаментальна ідея Пафнутія Чебишова полягала у тому, щоб пов'язати степені алгебраїчної змінної `x` із косинусами кратних кутів. Нехай змінна `x` належить відрізку `[-1, 1]`. Тоді її завжди можна подати у вигляді косинуса декількох кутів `θ ∈ [0, π]`:

```
x = cos(θ)    ⟹    θ = arccos(x)
```

Визначимо **поліном Чебишова першого роду** `Tₙ(x)` степеня `n` як косинус `n`-кратного кута `n·θ`:

```
Tₙ(x) = cos(n · θ) = cos(n · arccos(x))
```

На перший погляд, вираз `cos(n · arccos(x))` здається трансцендентною функцією, а не многочленом. Однак завдяки тригонометричним формулам зведення косинус кратних кутів завжди розкладається у чисто алгебраїчний поліном від `x = cos(θ)`.

Простежимо зв'язок із комплексною формулою Де Муавра. З формули Ейлера випливає:

```
cos(n θ) + i · sin(n θ) = (cos θ + i · sin θ)ⁿ = (x + i · √(1 - x²))ⁿ
```

Виділяючи дійсну частину цього бінома, отримуємо явне алгебраїчне подання для `Tₙ(x)` у вигляді комбінаторної суми:

```
Tₙ(x) = (n / 2) · ∑ [ (-1)╟ / (n - k) ] · (n - k choose k) · (2x)ⁿ⁻²╟    (сума по k від 0 до ⌊n/2⌋)
```

Простежимо перші дванадцять степенів `n` крок за кроком у зведеній таблиці:

| Степінь `n` | Вираз полінома Чебишова `Tₙ(x)` | Старший коефіцієнт `2ⁿ⁻¹` |
|---|---|---|
| `n = 0` | `T₀(x) = 1` | `1` |
| `n = 1` | `T₁(x) = x` | `1` |
| `n = 2` | `T₂(x) = 2·x² - 1` | `2` |
| `n = 3` | `T₃(x) = 4·x³ - 3·x` | `4` |
| `n = 4` | `T₄(x) = 8·x⁴ - 8·x² + 1` | `8` |
| `n = 5` | `T₅(x) = 16·x⁵ - 20·x³ + 5·x` | `16` |
| `n = 6` | `T₆(x) = 32·x⁶ - 48·x⁴ + 18·x² - 1` | `32` |
| `n = 7` | `T₇(x) = 64·x⁷ - 112·x⁵ + 56·x³ - 7·x` | `64` |
| `n = 8` | `T₈(x) = 128·x⁸ - 256·x⁶ + 160·x⁴ - 32·x² + 1` | `128` |
| `n = 9` | `T≀(x) = 256·x⁹ - 576·x⁷ + 432·x⁵ - 120·x³ + 9·x` | `256` |
| `n = 10` | `T₁₀(x) = 512·x¹⁰ - 1280·x⁸ + 1120·x⁶ - 400·x⁴ + 50·x² - 1` | `512` |
| `n = 11` | `T₁₁(x) = 1024·x¹¹ - 2816·x⁹ + 2816·x⁷ - 1232·x⁵ + 220·x³ - 11·x` | `1024` |
| `n = 12` | `T₁₂(x) = 2048·x¹² - 6144·x¹⁰ + 6912·x⁸ - 3584·x⁶ + 840·x⁴ - 72·x² + 1` | `2048` |

Для довільного `n ≥ 1` вивести загальну формулу дозволяє тригонометрична тотожність для суми та різниці кутів:

```
cos((n + 1)·θ) = cos(n·θ)·cos(θ) - sin(n·θ)·sin(θ)
cos((n - 1)·θ) = cos(n·θ)·cos(θ) + sin(n·θ)·sin(θ)
```

Додавши ці дві рівності почленно, тригонометричні доданки із синусами скорочуються:

```
cos((n + 1)·θ) + cos((n - 1)·θ) = 2 · cos(θ) · cos(n·θ)
```

Заменивши `cos(n·θ)` на `Tₙ(x)`, отримуємо фундаментальне **тричленне рекурентне співвідношення** (англ. *three-term recurrence relation*):

```
Tₙ₊₁(x) + Tₙ₋₁(x) = 2 · x · Tₙ(x)
Tₙ₊₁(x) = 2 · x · Tₙ(x) - Tₙ₋₁(x)    [ізольовано Tₙ₊₁(x)]
```

> 🔧 **Навіщо це.** Тричленна рекурентність дозволяє обчислювати значення полінома Чебишова будь-якого вищого степеня `Tₙ₊₁(x)` за лінійний час без виклику обчислювально дорогих тригонометричних функцій `cos` чи `arccos`.

Розглянемо властивості парності поліномів Чебишова. Оскільки `cos(n(π - θ)) = (-1)ⁿ · cos(nθ)`, виконується співвідношення парності:

```
Tₙ(-x) = (-1)ⁿ · Tₙ(x)
```

Це означає, що для парних `n` поліном `Tₙ(x)` є парною функцією (містить лише парні степені `x²`, `x⁴`, …), а для непарних `n` — непарною функцією (містить лише непарні степені `x`, `x³`, …).

Обчислимо значення поліномів Чебишова у ключових точках:

```
Tₙ(1) = cos(n · 0) = 1
Tₙ(-1) = cos(n · π) = (-1)ⁿ
T₂ₖ(0) = cos(2k · π/2) = cos(kπ) = (-1)ᵏ
T₂ₖ₊₁(0) = cos((2k+1) · π/2) = 0
```

Згадаємо зв'язок із числами Фібоначчі `Fₙ` та Люка `Lₙ`: підставивши у поліноми Чебишова уявний аргумент `x = i/2`, отримуємо числа Люка:

```
2 · Tₙ(i / 2) = iⁿ · Lₙ
```

З рекурентного співвідношення одразу видно важливу алгебраїчну властивість старших коефіцієнтів: при кожному переході від `Tₙ` до `Tₙ₊₁` старший член множиться на `2x`. Отже, для будь-якого `n ≥ 1` старший коефіцієнт полінома `Tₙ(x)` при `xⁿ` дорівнює точно **`2ⁿ⁻¹`**:

```
Tₙ(x) = 2ⁿ⁻¹ · xⁿ + lower_terms
```

Окрім рекурентного співвідношення, поліноми Чебишова володіють унікальною **властивістю суперпозиції (композиційного комутування)**:

```
Tₘ(Tₙ(x)) = Tₘ·ₙ(x)
```

Наприклад, `T₂(T₃(x)) = 2·(4x³ - 3x)² - 1 = 2·(16x⁶ - 24x⁴ + 9x²) - 1 = 32x⁶ - 48x⁴ + 18x² - 1 = T₆(x)`. Видатні математики Джозеф Рітт та Гастон Жюліа довели, що поліноми Чебишова та звичайні степені `xⁿ` є **єдиними поліномами в алгебрі**, які комутують відносно операції композиції (`P(Q(x)) = Q(P(x))`).

Твірна функція (англ. *generating function*) для послідовності поліномів Чебишова першого роду має вигляд:

```
g_T(t, x) = ∑ Tₙ(x) · tⁿ = (1 - t·x) / (1 - 2·t·x + t²)    (сума по n від 0 до ∞)
```

Оскільки `Tₙ(cos θ) = cos(n θ)`, область значень полінома `Tₙ(x)` на відрізку `x ∈ [-1, 1]` суворо обмежена одиницею:

```
-1 ≤ Tₙ(x) ≤ 1    (для всіх x ∈ [-1, 1])
```

Многочлен `Tₙ(x)` торкається верхньої та нижньої меж `+1` та `-1` точно `n + 1` разів. Ці точки називають **точками екстремумів або точками альтернансу**:

```
x′╟ = cos(k · π / n)    (для k від 0 до n)
Tₙ(x′╟) = (-1)╟
```

Корені полінома `Tₙ(x)` (тобто точки, де `Tₙ(x) = 0`), що називаються **вузлами Чебишова** (англ. *Chebyshev nodes*), знаходяться з умови `cos(n θ) = 0`:

```
n · θ╟ = (2k - 1) · π / 2 ⟹ θ╟ = (2k - 1)·π / (2n)
x╟ = cos( (2k - 1)·π / (2n) )    (для k від 1 до n)
```

Простежимо числовий розрахунок вузлів Чебишова для степеня `n = 4`:

```
θ₁ = π/8   ⟹ x₁ = cos(π/8)   ≈ +0.92388
θ₂ = 3π/8  ⟹ x₂ = cos(3π/8)  ≈ +0.38268
θ₃ = 5π/8  ⟹ x₃ = cos(5π/8)  ≈ -0.38268
θ₄ = 7π/8  ⟹ x₄ = cos(7π/8)  ≈ -0.92388
```

Зверніть увагу на згущення вузлів: біля центра `x = 0` відстань між вузлами `x₂` та `x₃` дорівнює `0.7654`, тоді як біля меж відрізка відстань між `x₁` та межею `1.0` становить всього `0.0761` (у 10 разів менше!). Саме це згущення вузлів на краях компенсує зростання чисельника у формулі Лагранжа.

### 3. Поліноми Чебишова другого роду U_n(x) та їх алгебраїчна система

Окрім поліномів першого роду `Tₙ(x)`, у математичному аналізі та алгебрі виникає супутнє сімейство — **поліноми Чебишова другого роду** `Uₙ(x)`. Якщо поліноми першого роду пов'язані з косинусом кратних кутів, то поліноми другого роду пов'язані з відношенням синусів.

Для `x = cos(θ) ∈ (-1, 1)` поліном Чебишова другого роду `Uₙ(x)` степеня `n` визначається як:

```
Uₙ(cos θ) = sin((n + 1) · θ) / sin(θ)
```

Обчислимо перші п'ять степенів `Uₙ(x)`:

1. **Для `n = 0`:**
   ```
   U₀(cos θ) = sin(θ) / sin(θ) = 1    ⟹    U₀(x) = 1
   ```

2. **Для `n = 1`:**
   ```
   U₁(cos θ) = sin(2θ) / sin(θ) = (2·sin θ·cos θ) / sin θ = 2·cos θ    ⟹    U₁(x) = 2·x
   ```

3. **Для `n = 2`:**
   Застосуємо формулу синуса потрійного кута `sin(3θ) = 3·sin θ - 4·sin³ θ`:
   ```
   U₂(cos θ) = (3·sin θ - 4·sin³ θ) / sin θ = 3 - 4·sin²(θ) = 3 - 4·(1 - cos² θ) = 4·cos² θ - 1
   U₂(x) = 4·x² - 1
   ```

4. **Для вищих степенів `n = 3, 4, 5, 6, 7, 8`:**
   ```
   U₃(x) = 8·x³ - 4·x
   U₄(x) = 16·x⁴ - 12·x² + 1
   U₅(x) = 32·x⁵ - 32·x³ + 6·x
   U₆(x) = 64·x⁶ - 80·x⁴ + 24·x² - 1
   U₇(x) = 128·x⁷ - 192·x⁵ + 80·x³ - 8·x
   U₈(x) = 256·x⁸ - 448·x⁶ + 240·x⁴ - 40·x² + 1
   ```

Поліноми Чебишова другого роду `Uₙ(x)` задовольняють **абсолютно таке ж тричленне рекурентне співвідношення**, що й поліноми першого роду `Tₙ(x)`:

```
Uₙ₊₁(x) = 2 · x · Uₙ(x) - Uₙ₋₁(x)
```

Відмінність між ними полягає лише у **початкових умовах**: для `Tₙ` початкова пара `(T₀ = 1, T₁ = x)`, а для `Uₙ` — `(U₀ = 1, U₁ = 2x)`. Старший коефіцієнт `Uₙ(x)` при `xⁿ` дорівнює **`2ⁿ`**.

Твірна функція для поліномів Чебишова другого роду має компактний вигляд:

```
g_U(t, x) = ∑ Uₙ(x) · tⁿ = 1 / (1 - 2·t·x + t²)    (сума по n від 0 до ∞)
```

Знайдемо похідну полінома Чебишова першого роду за допомогою правила диференціювання складеної функції:

```
Tₙ′(x) = (d / dx) cos(n · arccos(x))
       = -sin(n · arccos(x)) · (d / dx) arccos(x)    [диференціювання зовнішньої функції cos(u)]
       = -sin(n · θ) · (-1 / √(1 - x²))              [похідна арккосинуса (arccos x)′ = -1/√(1-x²)]
       = n · (sin(n · θ) / sin(θ))                   [мінус на мінус дає плюс, sin(θ) = √(1-x²)]
       = n · Uₙ₋₁(x)                                 [за означенням Uₙ₋₁(cos θ) = sin(nθ)/sin(θ)]
```

Ця чудова формула показує, що похідна полінома Чебишова першого роду пропорційна поліному Чебишова другого роду нижчого степеня:

```
Tₙ′(x) = n · Uₙ₋₁(x)
```

Повний список диференціальних та алгебраїчних тотожностей між `Tₙ` та `Uₙ`:

```
(1 - x²) · Uₙ₋₁(x) = x · Tₙ(x) - Tₙ₊₁(x)
2 · Tₙ(x) = Uₙ(x) - Uₙ₋₂(x)
Tₙ(x) = Uₙ(x) - x · Uₙ₋₁(x)
```

Окрім `Tₙ` та `Uₙ`, у математичній фізиці іноді виникають поліноми Чебишова третього роду `Vₙ(x)` та четвертого роду `Wₙ(x)`:

```
Vₙ(cos θ) = cos((n + 1/2)θ) / cos(θ / 2)
Wₙ(cos θ) = sin((n + 1/2)θ) / sin(θ / 2)
```

Ці чотири роди поліномів утворюють повну алгебраїчну систему ортогональних поліномів з якорними вагами на відрізку `[-1, 1]`.

Геометричний зміст коренів Чебишова наочно демонструє ортогональна проєкція точок із кола на діаметр:

![Геометрична проєкція вузлів Чебишова з півкола](/book/math/algebra/chebyshev-polynomials/img/chebyshev-nodes-projection.svg)
*Геометричний зміст вузлів Чебишова для n = 5: рівномірний розподіл точок уздовж дуги півкола після ортогональної проєкція на діаметр утворює згущення вузлів на краях відрізка [-1, 1].*

### 4. Ортогональність, вагові простори L^2 та косинусні перетворення

У лінійній алгебрі та функціональному аналізі два вектори `u` та `v` називаються ортогональними, якщо їх скалярний добуток дорівнює нулю. Для неперервних функцій скалярний добуток задається через інтеграл із деякою додатною **ваговою функцією** `w(x)` (англ. *weight function*):

```
⟨f, g⟩_w = ∫ f(x) · g(x) · w(x) dx    (інтеграл від -1 до 1)
```

Поліноми Чебишова утворюють **ортогональний базис** у відповідних вагових гіпопросторах `L²`.

**1. Ортогональність поліномів першого роду Tₙ(x):**
Для `Tₙ(x)` вагова функція має вигляд `w(x) = 1 / √(1 - x²)`:

```
∫ (Tₘ(x) · Tₙ(x) / √(1 - x²)) dx    (інтеграл від -1 до 1)
```

Доведемо цю ортогональність за допомогою заміни змінних `x = cos(θ)`. Тоді `dx = -sin(θ) dθ`, а `√(1 - x²) = sin(θ)`:

```
∫ (Tₘ(cos θ) · Tₙ(cos θ) / sin θ) · (sin θ dθ)    (інтеграл від 0 до π)
= ∫ cos(m·θ) · cos(n·θ) dθ                        (інтеграл від 0 до π)
```

Застосуємо формулу перетворення добутку косинусів у суму: `cos(mθ)·cos(nθ) = (1/2)·[cos((m+n)θ) + cos((m-n)θ)]`.

Проінтегруємо цей вираз окремо для `m ≠ n`:

```
∫ cos(m·θ) · cos(n·θ) dθ = (1/2) · ∫ [cos((m+n)θ) + cos((m-n)θ)] dθ
= (1/2) · [ sin((m+n)θ)/(m+n) + sin((m-n)θ)/(m-n) ]    (від 0 до π)
= 0    [оскільки sin(k·π) = 0 для всіх цілих k]
```

При `m = n > 0`:

```
∫ cos²(n·θ) dθ = (1/2) · ∫ [1 + cos(2nθ)] dθ = (1/2) · [ π + 0 ] = π / 2
```

При `m = n = 0`:

```
∫ 1 dθ = π
```

Отже, норми та скалярні добутки мають вигляд:

```
∫ (T☿(x) · Tₙ(x) / √(1 - x²)) dx = 0          [при m ≠ n]
                                 = π / 2      [при m = n > 0]
                                 = π          [при m = n = 0]
```

**2. Ортогональність поліномів другого роду Uₙ(x):**
Для `Uₙ(x)` вагова функція дорівнює `w(x) = √(1 - x²)`:

```
∫ U☿(x) · Uₙ(x) · √(1 - x²) dx = 0        [при m ≠ n]
                               = π / 2    [при m = n]
```

**3. Дискретна ортогональність на сітці вузлів:**
Окрім неперервної інтегральної ортогональності, поліноми Чебишова володіють рідкісною властивістю **дискретної ортогональності** на скінченній сітці з `N` вузлів Чебишова `x╟ = cos((2k - 1)π / (2N))`:

```
∑ T☿(x╟) · Tₙ(x╟) = 0           [при m ≠ n та m + n < 2N]
                   = N / 2       [при 0 < m = n < N]
                   = N           [при m = n = 0]
```

Ця дискретна ортогональність лежить в основі дискретного косинусного перетворення (DCT-II), яке використовується у стисненні зображень JPEG та аудіо MP3/AAC.

Завдяки властивості ортогональності довільну функцію `f(x)` можна розкласти у **ряд Фурьє-Чебишова**:

```
f(x) = (c₀ / 2) + ∑ cₖ · Tₖ(x)    (сума по k від 1 до ∞)
```

Коефіцієнти розкладу `cₖ` обчислюються за явними інтегральними формулами:

```
cₖ = (2 / π) · ∫ (f(x) · Tₖ(x) / √(1 - x²)) dx    (інтеграл від -1 до 1)
```

Для аналітичних функцій коефіцієнти ряду Чебишова `cₖ` спадають з геометричною прогресією `O(ρ⁻▖)` (де `ρ > 1` — радіус еліпса Бернштейна в комплексній площині), що забезпечує колосальну швидкість збіжності порівняно зі звичайними рядами Тейлора.

### 5. Мінімаксна властивість та економізація Ланцоша

Головна характеристика поліномів Чебишова, яка робить їх унікальними серед усіх інших ортогональних багаточленів (Лежандра, Ерміта, Лаґерра), полягає у **мінімаксній властивості** (від лат. *minimum* — найменше та *maximum* — найбільше, *minimax property*).

Сформулюємо задачу: серед усіх дійсних нормованих многочленів `Pₙ(x) = xⁿ + aₙ₋₁·xⁿ⁻¹ + …` степеня `n` (у яких коефіцієнт при `xⁿ` дорівнює 1), знайти той, який має найменшу **чебишовську норму** (максимальне абсолютне значення) на відрізку `[-1, 1]`:

```
║Pₙ║_∞ = max |Pₙ(x)|    (по всіх x ∈ [-1, 1])
```

> **Теорема Чебишова.** Нормований поліном Чебишова першого роду `T̃ₙ(x) = (1 / 2ⁿ⁻¹) · Tₙ(x)` є **єдиним** нормованим многочленом степеня `n`, який мінімізує чебишовську норму на відрізку `[-1, 1]`. При цьому точне значення мінімального відхилення дорівнює:
> ```
> min ║Pₙ║_∞ = ║T̃ₙ║_∞ = 1 / 2ⁿ⁻¹
> ```

Доведення цієї теореми спирається на метод від супротивного та властивість альтернансу (існування `n + 1` точок, де `T̃ₙ(x)` послідовно набуває значень `±1 / 2ⁿ⁻¹` зі зміною знака). Детальне крокове виведення з розбором суперечності через теорему Больцано-Коші наведено в окремому матеріалі: [математичне доведення мінімаксної властивості](book:math/algebra/chebyshev-polynomials/math-chebyshev-minimax.md).

З цієї теореми випливає знаменитий метод **економізації степеневих рядів Корнеліуса Ланцоша** (англ. *Lanczos economization*).

Простежимо приклад економізації для функції `f(x) = exp(x)` на відрізку `[-1, 1]`. Розклад Тейлора степеня 5 має вигляд:

```
P₅(x) = 1 + x + (1/2)·x² + (1/6)·x³ + (1/24)·x⁴ + (1/120)·x⁵
```

Замінимо степені `xᵏ` їх виразами через поліноми Чебишова:

```
1 = T₀
x = T₁
x² = (T₀ + T₂) / 2
x³ = (3·T₁ + T₃) / 4
x⁴ = (3·T₀ + 4·T₂ + T₄) / 8
x⁵ = (10·T₁ + 5·T₃ + T₅) / 16
```

Підставивши ці вирази у розклад `P₅(x)` та згрупувавши доданки при `Tₖ(x)`, отримуємо:

```
P₅(x) = 1.266066 · T₀(x) + 1.130208 · T₁(x) + 0.271484 · T₂(x)
        + 0.044271 · T₃(x) + 0.005469 · T₄(x) + 0.000521 · T₅(x)
```

Зверніть увагу на коефіцієнт при `T₅(x)`: він дорівнює всього `0.000521`. Оскільки `║T₅║_∞ = 1`, відкидання члена `0.000521 · T₅(x)` призведе до похибки не більше `0.000521` по всьому відрізку `[-1, 1]`. Ми зменшили степень многочлена з 5 до 4, зберігши високу точність. Якби ми просто відкидали моном `x⁵ / 120` у ряді Тейлора, похибка на межі `x = 1` була б у 16 разів більшою (`1/120 ≈ 0.00833`).

Для практичного знаходження багаточленів найкращого рівномірного наближення для довільних складних функцій застосовують ітераційний **алгоритм Ремеза** (розроблений київським математиком Євгенем Ремезом у 1934 році):

1. Задається початкова сітка з `n + 2` точок `x₀ < x₁ < … < xₙ₊₁`.
2. Розв'язується лінійна система `P(x╟) - f(x╟) = (-1)╟ · E` відносно коефіцієнтів полінома `P` та величини альтернансного відхилення `E`.
3. Обчислюється функція похибки `e(x) = P(x) - f(x)` та знаходяться її нові локальні екстремуми, які замінюють попередні точки сітки.
4. Процедура повторюється до досягнення точної рівності модулів похибки у всіх точках альтернансу.

### 6. Обчислювальний алгоритм Кленшоу та чисельна стійкість

На практиці для обчислення значення ряду Чебишова у точці `x` ніколи не використовують розгортання поліномів у степені `xⁿ` і не викликають тригонометричні функції. Замість цього застосовують **алгоритм Кленшоу** (англ. *Clenshaw algorithm*).

Нехай маємо суму Чебишова:

```
f(x) = (c₀ / 2) + c₁ · T₁(x) + c₂ · T₂(x) + … + cₙ · Tₙ(x)
```

Алгоритм Кленшоу виконує зворотну рекурентну процедуру:

1. Покладаємо `bₙ₊₂ = 0` та `bₙ₊₁ = 0`.
2. Для `k` від `N` назад до `1` обчислюємо:
   ```
   b▖ = 2 · x · b▖₊₁ - b▖₊₂ + c▖
   ```
3. Остаточне значення суми дорівнює:
   ```
   f(x) = x · b₁ - b₂ + (c₀ / 2)
   ```

Польна програмна реалізація алгоритму Кленшоу, генерація вузлів Чебишова та чисельне тестування на функції Рунге мовами Python, C та C++ наведені в окремому розборі: [практичну реалізацію алгоритму Кленшоу та інтерполяції](book:math/algebra/chebyshev-polynomials/proj-clenshaw-algorithm.md).

### 7. Диференціальне рівняння Чебишова, спектральні методи та застосування

Поліноми Чебишова виникають як розв'язки лінійного диференціального рівняння другого порядку, яке називається **диференціальним рівнянням Чебишова**:

```
(1 - x²) · y″ - x · y′ + n² · y = 0
```

У самоспряженій формі Штурма-Ліувілля це рівняння записується як:

```
(d / dx) [ √(1 - x²) · y′ ] + (n² / √(1 - x²)) · y = 0
```

Власними значеннями цієї крайової задачі є `λₙ = n²`, а власними функціями — поліноми Чебишова `Tₙ(x)`.

Завдяки своїм унікальним властивостям поліноми Чебишова знаходять застосування у найрізноманітніших галузях:

1. **Спектральні методи розв'язання ДРЧП:** У чисельному моделюванні турбулентності, гідродинаміки та квантової механіки розв'язки диференціальних рівнянь розкладають у швидко збіжні ряди Чебишова (методи псевдоспектрів), що дає експоненційну точність (спектральну точність) порівняно зі звичайними скінченно-різницевими сітками.
2. **Цифрова обробка сигналів (DSP):** У теорії фільтрації широко використовуються **фільтри Чебишова** (англ. *Chebyshev filters*). Амплітудно-частотна характеристика (АЧХ) фільтрів Чебишова першого роду розраховується на основі `Tₙ(ω)`:
   ```
   |H(i·ω)|² = 1 / [ 1 + ε² · Tₙ²(ω / ω₀) ]
   ```
   Це забезпечує найгостріший спад частотної характеристики в смузі переходу за рахунок рівномірних пульсацій (equiripple) у смузі пропускання.
3. **Економізація степеневих рядів Ланцоша:** При проектуванні мікропроцесорів та математичних бібліотек розклади Тейлора високих степенів замінюють на коротші ряди Чебишова, що дозволяє зменшити кількість обчислювальних операцій FPU в 2–4 рази без втрати точності.

### 8. Підсумковий синтез

Поліноми Чебишова являють собою унікальний алгебраїчний міст між чотирма фундаментальними розділами математики:
- **Тригонометрією:** через тотожність `Tₙ(cos θ) = cos(n θ)`.
- **Алгеброю:** через тричленне рекурентне співвідношення `Tₙ₊₁ = 2x Tₙ - Tₙ₋₁`.
- **Функціональним аналізом:** як ортогональний базис у просторі `L²` з вагою `1 / √(1 - x²)`.
- **Теорією наближень та чисельним аналізом:** як єдині многочлени, що забезпечують мінімаксне (рівномірне) наближення та придушують феномен Рунге.

Розуміння механізму поліномів Чебишова перетворює важкі обчислювальні проблеми на витончений і стійкий алгоритмічний інструмент цифрової епохи.
