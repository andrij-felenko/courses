# 🧮 Головна теорема теорії Ґалуа: повна відповідність між підгрупами та проміжними полями

Головна теорема теорії Ґалуа розв'язує фундаментальну проблему алгебри: як досліджувати складні числові поля, які мають нескінченно багато елементів. Замість безпосереднього перебору нескінченних числових множин теорема встановлює точний двосторонній місток між проміжними полями розширення та скінченною групою симетрій — групою Ґалуа. Уся складна, неперервна структура числових полів виявляється дзеркальним відбитком скінченної комбінаторної структури підгруп.

### Поля, розширення та їхня розмірність

Нехай задано базове числове поле `F` (наприклад, поле раціональних чисел `Q`). Якщо ми додаємо до `F` нові числа (наприклад, корені деякого многочлена), ми отримуємо більше поле `K`, яке містить `F` як підмножину. Таку пару називають **розширенням поля** і позначають `K / F` (читається «K над F»).

Поле `K` можна розглядати як векторний простір над базовим полем `F`: елементи `K` можна додавати між собою та множити на коефіцієнти (скаляри) з поля `F`. Розмірність цього векторного простору називають **степенем розширення** і позначають `[K : F]`.

Якщо степінь `[K : F]` скінченний, розширення називають скінченним. Наприклад, якщо до поля раціональних чисел `Q` приєднати число `√2`, кожне число нового поля `Q(√2)` записується у вигляді `a + b·√2`, де `a` і `b` — раціональні числа. Базис цього простору складається з двох елементів `{1, √2}`, тому степінь розширення дорівнює 2:

```
[Q(√2) : Q] = 2      [базис складається з двох елементів 1 та √2]
```

Для вежі розширень `F ⊆ E ⊆ K` діє фундаментальне **правило добутку степенів**: розмірність усього простору дорівнює добутку проміжних розмірностей.

```
[K : F] = [K : E] · [E : F]      [теорема про вежу векторних просторів]
```

Доведення цього правила є прямим: якщо `{u₁, ..., uₘ}` — базис поля `E` над `F`, а `{v₁, ..., vₙ}` — базис поля `K` над `E`, то множина всіх попарних добутків `{uᵢ · vⱼ}` із `m·n` елементів утворює базис поля `K` над базовим полем `F`. Будь-який елемент `x ∈ K` єдиним чином записується через коефіцієнти з `E`, а кожен коефіцієнт з `E` — єдиним чином через коефіцієнти з `F`.

Це правило відіграє роль закону збереження розмірності: воно жорстко обмежує можливі проміжні поля. Наприклад, якщо `[K : F] = 6`, то будь-яке проміжне поле `E` може мати степінь над `F` лише 1, 2, 3 або 6 — жодних підполів степеня 4 чи 5 існувати не може.

### Автоморфізми та поле розкладу

**Автоморфізмом** поля `K` над полем `F` називають взаємно однозначне відображення (біекцію) `σ` поля `K` на себе, яке зберігає операції додавання й множення та лишає кожен елемент базового поля `F` нерухомим. Для будь-яких елементів `x` та `y` із поля `K` і для кожного елемента `c` із базового поля `F` виконуються три умови:

```
σ(x + y) = σ(x) + σ(y)      [збереження операції додавання]
σ(x · y) = σ(x) · σ(y)      [збереження операції множення]
σ(c)     = c                [фіксація кожного елемента базового поля F]
```

Множина всіх таких автоморфізмів утворює групу щодо операції послідовного виконання (композиції відображень). Цю групу позначають `Aut(K/F)`.

Ключовий факт полягає в тому, як автоморфізм діє на корені многочлена. Нехай многочлен `f(x)` має коефіцієнти з поля `F`, і нехай `α` — його корінь у полі `K`, тобто `f(α) = 0`. Застосуємо автоморфізм `σ` до цієї рівності:

```
f(α) = 0                                       [за умовою: α є коренем f(x)]
σ(f(α)) = σ(0)                                 [застосували відображення σ до обох частин]
σ(aₙ·αⁿ + ... + a₁·α + a₀) = 0                 [розписали многочлен за степенями]
σ(aₙ)·σ(α)ⁿ + ... + σ(a₁)·σ(α) + σ(a₀) = 0     [автоморфізм зберігає суму, добуток і степені]
aₙ·(σ(α))ⁿ + ... + a₁·(σ(α)) + a₀ = 0         [коефіцієнти aᵢ належать F, тому σ(aᵢ) = aᵢ]
f(σ(α)) = 0                                    [за означенням многочлена f]
```

Звідси випливає фундаментальний висновок: **будь-який автоморфізм обов'язково переводить корінь многочлена в інший корінь того самого многочлена**. Автоморфізми не створюють нових значень — вони лише переставляють корені між собою.

Розширення `K / F` називають **розширенням Ґалуа** (або нормальним і сепарабельним розширенням), якщо виконуються дві природні умови:
1. **Нормальність**: поле `K` є полем розкладу многочлена `f(x)`, тобто містить усі його корені без винятку.
2. **Сепарабельність**: усі корені многочлена є різними (немає кратних коренів). Над числовими полями характеристики 0 (як-от `Q`, `R`, `C`) кожен незвідний многочлен автоматично сепарабельний.

Для скінченних розширень Ґалуа кількість елементів групи автоморфізмів точно дорівнює степеню розширення поля:

```
|Aut(K/F)| = [K : F]      [критерій розширення Ґалуа]
```

У цьому випадку групу `Aut(K/F)` називають **групою Ґалуа** розширення `K/F` і позначають `Gal(K/F)`.

### Фіксовані поля та лема Дедекінда

Для кожної підгрупи `H` групи Ґалуа `Gal(K/F)` розглянемо множину елементів поля `K`, які залишаються нерухомими під дією абсолютно всіх автоморфізмів із `H`. Цю множину позначають `Kᴴ` і називають **фіксованим полем** (або інваріантним полем) підгрупи `H`:

```
Kᴴ = { x ∈ K | ∀ σ ∈ H: σ(x) = x }      [означення фіксованого поля підгрупи H]
```

Множина `Kᴴ` завжди є підполем поля `K` і містить у собі базове поле `F`. Справді, якщо `x` та `y` нерухомі, то їхня сума `σ(x + y) = σ(x) + σ(y) = x + y` і добуток `σ(x·y) = σ(x)·σ(y) = x·y` також нерухомі.

Щоб встановити точну розмірність фіксованого поля, Еміль Артін застосував знамениту лему Ріхарда Дедекінда про лінійну незалежність характерів.

**Лема Дедекінда про лінійну незалежність автоморфізмів.** Будь-який скінченний набір різних автоморфізмів `σ₁, σ₂, ..., σₘ` поля `K` є лінійно незалежним над `K`. Тобто якщо для всіх `x ∈ K` виконується лінійна комбінація:

```
c₁·σ₁(x) + c₂·σ₂(x) + ... + cₘ·σₘ(x) = 0      [лінійна комбінація з коефіцієнтами cᵢ ∈ K]
```

то всі коефіцієнти обов'язково дорівнюють нулю: `c₁ = c₂ = ... = cₘ = 0`.

Доведемо це методом математичної індукції за кількістю автоморфізмів `m`.
База індукції: при `m = 1` рівність `c₁·σ₁(x) = 0` для `x = 1` дає `c₁·1 = 0`, звідки `c₁ = 0`.
Припустимо, що твердження істинне для `m - 1` автоморфізмів. Припустимо від супротивного, що існує нетривіальна нульова комбінація з мінімальною кількістю ненульових коефіцієнтів (нехай це `m` доданків і всі `cᵢ ≠ 0`):

```
c₁·σ₁(x) + c₂·σ₂(x) + ... + cₘ·σₘ(x) = 0      [рівність 1: для всіх x ∈ K]
```

Оскільки автоморфізми `σ₁` та `σₘ` різні, знайдеться такий елемент `y ∈ K`, що `σ₁(y) ≠ σₘ(y)`. Підставимо в рівність 1 замість `x` добуток `x·y`:

```
c₁·σ₁(x·y) + c₂·σ₂(x·y) + ... + cₘ·σₘ(x·y) = 0
c₁·σ₁(y)·σ₁(x) + c₂·σ₂(y)·σ₂(x) + ... + cₘ·σₘ(y)·σₘ(x) = 0   [рівність 2: розкрили σᵢ(x·y)]
```

Тепер помножимо початкову рівність 1 на `σₘ(y)` і віднімемо її від рівності 2:

```
c₁·(σ₁(y) − σₘ(y))·σ₁(x) + ... + cₘ₋₁·(σₘ₋₁(y) − σₘ(y))·σₘ₋₁(x) + 0 = 0   [рівність 3: різниця]
```

Останній доданок із `σₘ` повністю скоротився, бо `cₘ·σₘ(y) − cₘ·σₘ(y) = 0`. Водночас перший коефіцієнт `c₁·(σ₁(y) − σₘ(y)) ≠ 0`, оскільки `c₁ ≠ 0` та `σ₁(y) ≠ σₘ(y)`. Ми отримали нетривіальну лінійну залежність лише для `m - 1` автоморфізмів, що суперечить припущенню про мінімальність довжини `m`. Лему Дедекінда доведено.

### Теорема Артіна про фіксовані поля

Спираючись на лему Дедекінда, доведемо теорему Артіна: якщо `H = {σ₁ = e, σ₂, ..., σₙ}` — скінченна підгрупа автоморфізмів поля `K`, а `E = Kᴴ` — її фіксоване поле, то степінь розширення `[K : E]` в точності дорівнює порядку підгрупи `|H| = n`.

Доведення складається з двох нерівностей:

**Крок 1. Доведення, що `[K : E] ≥ n`.**
Припустимо від супротивного, що `[K : E] = m < n`. Нехай `{ω₁, ω₂, ..., ωₘ}` — базис векторного простору `K` над полем `E`. Розглянемо однорідну систему з `m` лінійних рівнянь з `n` невідомими `(x₁, x₂, ..., xₙ)`:

```
σ₁(ω₁)·x₁ + σ₂(ω₁)·x₂ + ... + σₙ(ω₁)·xₙ = 0
σ₁(ω₂)·x₁ + σ₂(ω₂)·x₂ + ... + σₙ(ω₂)·xₙ = 0
...
σ₁(ωₘ)·x₁ + σ₂(ωₘ)·x₂ + ... + σₙ(ωₘ)·xₙ = 0      [система m рівнянь з n невідомими]
```

Оскільки кількість невідомих `n` строго більша за кількість рівнянь `m`, за теоремою лінійної алгебри ця система має ненульовий розв'язок `(c₁, c₂, ..., cₙ)` у полі `K`.
Візьмемо довільний елемент `α ∈ K`. Оскільки `{ωᵢ}` — базис, `α` записується як `α = e₁·ω₁ + ... + eₘ·ωₘ`, де коефіцієнти `eᵢ` належать фіксованому полю `E`. Оскільки всі `σⱼ` залишають елементи поля `E` нерухомими (`σⱼ(eᵢ) = eᵢ`), обчислимо:

```
c₁·σ₁(α) + ... + cₙ·σₙ(α)
= c₁·σ₁(∑ eᵢ·ωᵢ) + ... + cₙ·σₙ(∑ eᵢ·ωᵢ)           [підставили розклад α за базисом]
= ∑ eᵢ · (σ₁(ωᵢ)·c₁ + ... + σₙ(ωᵢ)·cₙ)            [перегрупували за коефіцієнтами eᵢ]
= ∑ eᵢ · 0 = 0                                    [кожна дужка дорівнює 0 за системою]
```

Отримали, що `c₁·σ₁(α) + ... + cₙ·σₙ(α) = 0` для абсолютно всіх `α ∈ K`. Це означає нетривіальну лінійну залежність автоморфізмів `σ₁, ..., σₙ`, що прямо суперечить лемі Дедекінда! Отже, наше припущення хибне, і `[K : E] ≥ n`.

**Крок 2. Доведення, що `[K : E] ≤ n`.**
Припустимо від супротивного, що `[K : E] > n`. Тоді в полі `K` існують `n + 1` лінійно незалежних над `E` елементів `{α₁, α₂, ..., αₙ₊₁}`.
Складемо однорідну систему з `n` рівнянь з `n + 1` невідомими:

```
σⱼ(α₁)·y₁ + σⱼ(α₂)·y₂ + ... + σⱼ(αₙ₊₁)·yₙ₊₁ = 0   [для кожного j від 1 до n]
```

Ця система має ненульовий розв'язок `(y₁, ..., yₙ₊₁)`. Серед усіх ненульових розв'язків оберемо той, що має найменшу кількість ненульових компонентів (нехай це `r` ненульових компонентів). Перенумерувавши змінні, можемо вважати, що `y₁ ≠ 0, ..., yᵣ ≠ 0`, а решта дорівнюють нулю. Поділивши всі рівняння на `yᵣ`, отримаємо розв'язок, де `yᵣ = 1`.

Якщо всі `yᵢ` належать полю `E`, то перше рівняння системи (для `σ₁ = e`) дає:
`α₁·y₁ + α₂·y₂ + ... + αᵣ₋₁·yᵣ₋₁ + αᵣ·1 = 0`, що суперечить лінійній незалежності `{αᵢ}` над `E`.
Якщо ж якийсь коефіцієнт (наприклад, `y₁`) не належить `E = Kᴴ`, то знайдеться такий автоморфізм `σₖ ∈ H`, що `σₖ(y₁) ≠ y₁`. Застосувавши `σₖ` до всієї системи та віднявши результат від початкового розв'язку, ми отримаємо новий розв'язок системи, де коефіцієнт при `yᵣ` перетворився на `1 − 1 = 0`, а перший коефіцієнт `y₁ − σₖ(y₁) ≠ 0`. Цей новий розв'язок має менше ніж `r` ненульових компонентів, що суперечить вибору `r` як мінімального!

Отже, `[K : E] ≤ n`. Поєднуючи обидві нерівності, маємо точну рівність:

```
[K : Kᴴ] = |H|      [теорема Артіна про розмірність фіксованого поля]
```

### Формулювання Головної теореми теорії Ґалуа

Нехай `K / F` — скінченне розширення Ґалуа з групою Ґалуа `G = Gal(K/F)`.

Головна теорема стверджує існування взаємно однозначної відповідності (бієкції) між двома множинами:
1. Множиною всіх проміжних підполів `E`, таких що `F ⊆ E ⊆ K`.
2. Множиною всіх підгруп `H` групи Ґалуа `G = Gal(K/F)`.

Ця відповідність задається парою взаємно обернених відображень:
- Кожному підполю `E` ставиться у відповідність підгрупа автоморфізмів, що фіксують `E`:
  `E ↦ Gal(K/E) = { σ ∈ G | ∀ x ∈ E: σ(x) = x }`.
- Кожній підгрупі `H` ставиться у відповідність її фіксоване поле:
  `H ↦ Kᴴ = { x ∈ K | ∀ σ ∈ H: σ(x) = x }`.

Ця відповідність має чотири фундаментальні властивості:

**1. Інверсія порядку включення (антиізоморфізм ґраток).**
Більшому полю відповідає менша підгрупа, і навпаки:

```
E₁ ⊆ E₂   ⇔   Gal(K/E₂) ≤ Gal(K/E₁)      [інверсія відношення включення]
H₁ ≤ H₂   ⇔   Kᴴ² ⊆ Kᴴ¹                  [інверсія для фіксованих полів]
```

Найбільшому полю `K` відповідає найменша (тривіальна) підгрупа `{e}`, а найменшому базовому полю `F` відповідає вся група `G = Gal(K/F)`.

**2. Збереження степенів та індексів.**
Для будь-якого проміжного поля `E` розмірність розширення дорівнює порядку відповідної підгрупи, а степінь над базовим полем дорівнює індексу підгрупи в групі `G`:

```
[K : E] = |Gal(K/E)|                           [степінь верхнього розширення дорівнює порядку підгрупи]
[E : F] = [G : Gal(K/E)] = |G| / |Gal(K/E)|   [степінь нижнього розширення дорівнює індексу підгрупи]
```

**3. Критерій нормальності розширення.**
Проміжне розширення `E / F` є нормальним (тобто само є розширенням Ґалуа над `F`) тоді й тільки тоді, коли відповідна підгрупа `H = Gal(K/E)` є **нормальною підгрупою** групи `G` (позначається `H ⊲ G`).

У цьому випадку група Ґалуа проміжного розширення `Gal(E/F)` ізоморфна фактор-групі:

```
Gal(E/F) ≅ Gal(K/F) / Gal(K/E)                 [головний ізоморфізм теорії Ґалуа]
```

Доведення цього факту прозоре: кожен автоморфізм `σ ∈ Gal(K/F)` переводить поле `E` у спряжене поле `σ(E)`. Поле `E` є нормальним над `F` тоді й тільки тоді, коли воно містить усі спряжені елементи, тобто `σ(E) = E` для всіх `σ ∈ G`. А умова `σ(E) = E` еквівалентна умові `σ H σ⁻¹ = H` для підгрупи `H = Gal(K/E)`, що є класичним означенням нормальної підгрупи!

### Розібраний приклад: поле розкладу x⁴ − 2 над Q

Щоб побачити теорему в дії на нетривіальному прикладі, розглянемо многочлен `f(x) = x⁴ − 2` над полем раціональних чисел `Q`.

Його корені на комплексній площині дорівнюють `α₁ = ⁴√2`, `α₂ = i·⁴√2`, `α₃ = −⁴√2`, `α₄ = −i·⁴√2`.
Поле розкладу `K` утворюється приєднанням дійсного кореня `⁴√2` та уявної одиниці `i`:

```
K = Q(⁴√2, i)      [поле розкладу x⁴ − 2 над Q]
```

Обчислимо степінь цього розширення за правилом вежі:

```
[Q(⁴√2) : Q] = 4              [мінімальний многочлен x⁴ − 2 незвідний за критерієм Ейзенштейна для p=2]
[K : Q(⁴√2)] = 2              [мінімальний многочлен x² + 1 над дійсним полем]
[K : Q] = 4 · 2 = 8           [правило добутку степенів: 4 · 2 = 8]
```

Отже, група Ґалуа `G = Gal(K/Q)` має порядок `|G| = 8`. Вона породжується двома автоморфізмами:
1. Поворот `σ` порядку 4: `σ(⁴√2) = i·⁴√2`, `σ(i) = i`.
2. Комплексне спряження `τ` порядку 2: `τ(⁴√2) = ⁴√2`, `τ(i) = −i`.

Між ними виконується співвідношення `τ · σ · τ = σ⁻¹`, що означає: група Ґалуа `Gal(K/Q)` ізоморфна **групі діедра** `D₄` (групі симетрій квадрата з 8 елементів).

Ґратка підгруп групи `D₄` налічує рівно 10 підгруп, і за Головною теоремою Ґалуа їм відповідає рівно 10 проміжних полів:

1. **Підгрупи порядку 4 (індекс 2 над Q) ↔ квадратичні підполя степеня 2 над Q:**
   - Нормальна циклічна підгрупа `⟨σ⟩ = {e, σ, σ², σ³}` ↔ фіксоване поле `Q(i)` (степінь 2 над `Q`, нормальне).
   - Нормальна підгрупа `⟨σ², τ⟩ = {e, σ², τ, σ²τ}` ↔ фіксоване поле `Q(√2)` (степінь 2 над `Q`, нормальне).
   - Нормальна підгрупа `⟨σ², στ⟩ = {e, σ², στ, σ³τ}` ↔ фіксоване поле `Q(i√2)` (степінь 2 над `Q`, нормальне).

2. **Підгрупи порядку 2 (індекс 4 над Q) ↔ підполя степеня 4 над Q:**
   - Центр групи `Z(D₄) = ⟨σ²⟩ = {e, σ²}` (нормальна) ↔ `Q(√2, i)` (степінь 4 над `Q`, нормальне).
   - Ненормальні підгрупи `{e, τ}` ↔ `Q(⁴√2)` (дійсне кубічне підполе, не нормальне).
   - Ненормальні підгрупи `{e, σ²τ}` ↔ `Q(i·⁴√2)` (не нормальне).
   - Ненормальні підгрупи `{e, στ}` ↔ `Q((1+i)·⁴√2)` (не нормальне).
   - Ненормальні підгрупи `{e, σ³τ}` ↔ `Q((1−i)·⁴√2)` (не нормальне).

3. **Крайні випадки:**
   - Вся група `D₄` (порядок 8) ↔ базове поле `Q` (степінь 1).
   - Тривіальна підгрупа `{e}` (порядок 1) ↔ повне поле `K = Q(⁴√2, i)` (степінь 8).

Цей приклад наочно демонструє красу двоїстості Ґалуа: три нормальні підгрупи порядку 4 відповідають трьом квадратичним нормальним розширенням, а ненормальні підгрупи порядку 2 відповідають полям, що містять лише один із чотирьох коренів.

### Радикальні вежі та розв'язні групи

Тепер ми маємо весь апарат, щоб пояснити, чому одні многочлени розв'язуються в радикалах, а інші ні.

Що означає «розв'язати рівняння в радикалах» мовою полів? Це означає, що всі корені многочлена можна отримати, послідовно приєднуючи корені степеня `n` із раніше знайдених виразів. Мовою розширень полів це означає існування **радикальної вежі**:

```
F = K₀ ⊂ K₁ ⊂ K₂ ⊂ ... ⊂ Kₘ      [ланцюжок послідовних розширень полів]
Kᵢ₊₁ = Kᵢ(αᵢ),  де αᵢⁿⁱ ∈ Kᵢ      [на кожному кроці приєднується корінь aᵢ = ⁿⁱ√bᵢ]
```

Якщо базове поле містить відповідні корені з одиниці, кожне елементарне приєднання кореня `α = ⁿ√b` породжує розширення поля з **циклічною групою Ґалуа** `Zₙ`: автоморфізми просто множать корінь `α` на первісний корінь з одиниці `ωʲ`.

За Головною теоремою Ґалуа, вежі розширень полів `K₀ ⊂ K₁ ⊂ ... ⊂ Kₘ` із циклічними проміжними розширеннями відповідає ланцюжок підгруп групи Ґалуа:

```
G = G₀ ⊳ G₁ ⊳ G₂ ⊳ ... ⊳ Gₘ = {e}      [нормальний ряд підгруп]
Gᵢ / Gᵢ₊₁ ≅ Zₚ                         [кожна фактор-група є простою циклічною]
```

Групу, яку можна розкласти в такий спадний ланцюжок нормальних підгруп, де кожна фактор-група `Gᵢ / Gᵢ₊₁` є абелевою (циклічною), називають **розв'язною групою** (фр. *groupe résoluble*, термін увів сам Ґалуа).

**Критерій Ґалуа розв'язності рівнянь.** Многочлен `f(x)` розв'язується в радикалах тоді й тільки тоді, коли його група Ґалуа `Gal(f/F)` є розв'язною групою.

### Нерозв'язність загального рівняння 5-го степеня

Група перестановок `n` елементів позначається `Sₙ` і має порядок `n!`. Усі парні перестановки утворюють нормальну підгрупу `Aₙ` (знакозмінну групу) порядку `n! / 2`.

Розглянемо групи симетрій для малих степенів:
- При `n = 2`: `S₂ ≅ Z₂` — група циклічна й абелева (квадратне рівняння розв'язується через звичайний квадратний корінь).
- При `n = 3`: ланцюжок `S₃ ⊳ A₃ ⊳ {e}`, де `S₃ / A₃ ≅ Z₂` та `A₃ ≅ Z₃`. Усі фактори циклічні, тому `S₃` розв'язна (формула Кардано).
- При `n = 4`: ланцюжок `S₄ ⊳ A₄ ⊳ V₄ ⊳ Z₂ ⊳ {e}`, де `V₄ ≅ Z₂ × Z₂` — четвірна група Клейна. Усі фактори `Z₂, Z₃, Z₂, Z₂` циклічні, тому `S₄` розв'язна (метод Феррарі).

Але при `n = 5` ситуація зазнає катастрофічної зміни. Група `S₅` має порядок `5! = 120`. Її єдина нетривіальна нормальна підгрупа — це знакозмінна група `A₅` порядку 60.

**Теорема про простоту групи A₅.** Знакозмінна група `A₅` є **простою групою** (не містить жодної власної нормальної підгрупи, крім `{e}` та самої `A₅`).

Доведемо простоту `A₅` через аналіз класів спряженості. Два елементи групи спряжені тоді й тільки тоді, коли вони мають однакову циклічну структуру. Група `A₅` складається з 60 парних перестановок 5 елементів, які розпадаються на 5 класів спряженості:
1. Тотожна перестановка `e`: 1 елемент.
2. Добутки двох незалежних транспозицій `(a b)(c d)`: кількість дорівнює `(5! / (2·2·2!)) = 15` елементів.
3. Трійкові цикли `(a b c)`: кількість дорівнює `(5! / (3·2)) = 20` елементів.
4. П'ятіркові цикли `(a b c d e)`: у групі `S₅` їх 24, але в `A₅` вони розпадаються на два класи спряженості по 12 елементів кожний (залежно від парності перестановки, що їх спрягає).

Будь-яка нормальна підгрупа `N ⊲ A₅` зобов'язана разом із будь-яким своїм елементом містити весь його клас спряженості, а також обов'язково містити одиничний елемент `e`. Отже, порядок `|N|` має бути сумою числа 1 та деяких чисел із набору `{15, 20, 12, 12}`. Водночас за теоремою Лаґранжа порядок `|N|` зобов'язаний бути дільником числа 60 (тобто приймати значення 1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30 або 60).

Перевіримо всі можливі суми:
- `1 + 12 = 13` (не ділить 60)
- `1 + 15 = 16` (не ділить 60)
- `1 + 20 = 21` (не ділить 60)
- `1 + 12 + 12 = 25` (не ділить 60)
- `1 + 12 + 15 = 28` (не ділить 60)
- `1 + 12 + 20 = 33` (не ділить 60)
- `1 + 15 + 20 = 36` (не ділить 60)
- `1 + 12 + 12 + 15 = 40` (не ділить 60)
- `1 + 12 + 12 + 20 = 45` (не ділить 60)
- `1 + 12 + 15 + 20 = 48` (не ділить 60)
- `1 + 12 + 12 + 15 + 20 = 60` (ділить 60, це вся група `A₅`)

Єдині можливі порядки нормальної підгрупи — це 1 (тривіальна підгрупа `{e}`) та 60 (вся група `A₅`). Жодних проміжних нормальних підгруп не існує.

Оскільки `A₅` є неабелевою простою групою, її неможливо розбити на простіші абелеві фактори. Нормальний ряд групи `S₅` обривається на першому ж кроці:

```
S₅ ⊳ A₅ ⊳ {e}      [ряд завершено: A₅ проста й неабелева, далі розкласти неможливо]
```

Фактор `S₅ / A₅ ≅ Z₂` є абелевим, але наступний фактор `A₅ / {e} ≅ A₅` не є абелевим. Тому група `S₅` **не є розв'язною**.

Будь-який многочлен 5-го степеня, чия група Ґалуа над `Q` збігається з повною групою перестановок `S₅` (наприклад, многочлен `f(x) = x⁵ − 4x + 2`), принципово неможливо розв'язати у радикалах. Цей результат остаточно пояснює трьохсотлітню загадку алгебри та демонструє неперевершену силу структурного підходу Евариста Ґалуа.
