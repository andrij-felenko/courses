Коли сучасна система комп'ютерної алгебри — як-от SymPy, Maple, Mathematica, Singular чи GiNaC — розкладає на множники цілочисельний многочлен п'ятдесятого степеня `f(x)` у кільці `ℤ[x]`, вона ніколи не намагається ділити його на всі можливі комбінації дільників у кільці цілих чисел. Прямий перебір цілих коренів і коефіцієнтів методом Кронекера вимагає побудови інтерполяційних сіток і має комбінаторну складність, яка вже для помірних степенів перевищує час життя Всесвіту.

Замість безнадійного перебору в нескінченній множині цілих чисел комп'ютерна алгебра обирає модулярний обхід: зводить коефіцієнти многочлена за невеликим простим модулем `p` у скінченне поле `𝔽ₚ[x]`. Над скінченним полем факторизація виконується за швидкий поліноміальний час завдяки алгоритмам Берлекампа або Кантора — Цассенгауза. Далі отримані модулярні дільники покроково піднімають до вищих степенів модуля `p², p⁴, p⁸, …, pᵏ` за допомогою леми Гензеля, що діє як квадратичний метод Ньютона для p-адичних чисел.

Але тут виникає вирішальне інженерне питання: **на якому саме степені `k` слід зупинити підйом Гензеля?** Модулярний дільник дає коефіцієнти як лишки за модулем `pᵏ`. Щоб однозначно відновити справжні цілі коефіцієнти шуканого дільника `g(x) ∈ ℤ[x]`, модуль `pᵏ` повинен перевищувати подвоєне абсолютне значення будь-якого коефіцієнта будь-якого можливого цілочисельного дільника `f(x)`. Якщо зупинитися занадто рано, відновлені коефіцієнти виявляться модулярним шумом. Якщо піднімати занадто довго, довга арифметика над гігантськими числами споживе всю пам'ять і процесорний час.

Гарантовану верхню оцінку на величину коефіцієнтів будь-якого дільника многочлена дає **межа Міньотта** (англ. *Mignotte's bound*, названа на честь французького математика Моріса Міньотта, який сформулював її у 1974 році). Про те, як алгебраїсти й творці перших систем комп'ютерної алгебри пройшли шлях від наївних оцінок коренів до точних аналітичних нерівностей, розказано в окремому нарисі: [історія виникнення межі Міньотта](book:math/algebra/mignotte-bound/hist-mignotte.md).

![Конвеєр модулярної факторизації та роль межі Міньотта](/book/math/algebra/mignotte-bound/img/modular-lifting-pipeline.svg)
*Конвеєр модулярної факторизації цілочисельних многочленів: від редукції за простим модулем p через підйом Гензеля з критерієм зупинки за межею Міньотта до відновлення точних множників у кільці ℤ[x].*

### 1. Парадокс коефіцієнтів дільника: чому дільник може бути більшим за ділене

У звичайній арифметиці цілих чисел властивість ділення інтуїтивно проста: якщо натуральне число `b` ділить натуральне число `a`, то дільник ніколи не перевищує саме число (`b ≤ a`).

Проте у кільці многочленів `ℤ[x]` ця інтуїція повністю руйнується. **Коефіцієнти многочлена-дільника `g(x)` можуть бути в десятки й сотні разів більшими за коефіцієнти вихідного многочлена `f(x)`.**

Розглянемо класичний приклад з круговими многочленами (поліномами поділу кола). Нехай маємо двочлен восьмого степеня:

```
f(x) = x⁸ - 1
```

Усі його ненульові коефіцієнти за модулем дорівнюють одиниці: висота многочлена `||f||_∞ = 1`. Розкладемо цей многочлен на незвідні множники над кільцем цілих чисел `ℤ[x]`:

```
x⁸ - 1 = (x⁴ + 1) · (x² + 1) · (x + 1) · (x - 1)
```

Усі ці множники мають коефіцієнти `±1`. Проте якщо ми розглянемо 105-й круговий многочлен `Φ₁₀₅(x)` (який є дільником двочлена `x¹⁰⁵ - 1` із коефіцієнтами `1` та `-1`):

```
Φ₁₀₅(x) = x⁴⁸ + x⁴⁷ + x⁴⁶ - x⁴³ - x⁴² - 2 x⁴¹ - x⁴⁰ - x³⁹ + x³⁶ + x³⁵ + 2 x³⁴ + … + 1
```

у ньому несподівано з'являється коефіцієнт `-2` при `x⁴¹` та `+2` при `x³⁴`. Для вищих порядків (якщо порядок числа `n` містить добуток трьох і більше різних непарних простих чисел) коефіцієнти кругових многочленів починають експоненціально зростати: для `n = 105` з'являється `2`, для `n = 385` коефіцієнти досягають `3`, для `n = 1365` — перевищують `23`, а для степенів порядку кількох тисяч коефіцієнти дільників вимірюються мільйонами.

Ще яскравіше цей ефект проявляється над полем дійсних чисел `ℝ`. Розглянемо многочлен четвертого степеня з одиничними коефіцієнтами:

```
f(x) = x⁴ + 1
```

Його дійсні незвідні множники мають вигляд:

```
x⁴ + 1 = ( x² - √2 x + 1 ) · ( x² + √2 x + 1 )
```

Коефіцієнт при першому степені дорівнює `√2 ≈ 1.4142`, що строго більше за найбільший коефіцієнт самого многочлена `f(x)` (`1.4142 > 1`).

Причина цього явища криється у взаємному розташуванні комплексних коренів. Коли ми перемножуємо лінійні множники `(x - αᵢ)`, доданки з протилежними знаками можуть взаємно знищуватися при розкритті дужок, утворюючи малі коефіцієнти у фінальному многочлені `f(x)`. Але в окремо взятому дільнику `g(x)` (який містить лише частину коренів `αᵢ`) такого повного взаємного гасіння не відбувається, і суми добутків коренів розростаються до значних величин.

Саме тому система комп'ютерної алгебри не має права припустити, що коефіцієнти дільників обмежені висотою самого многочлена. Нам потрібна сувора математична теорема, яка вкаже абсолютну гарантовану стелю для будь-якого можливого дільника.

### 2. Норми многочленів та геометрична довжина коефіцієнтів

Щоб кількісно виміряти «розмір» многочлена без обчислення його значень у кожній точці, алгебра розглядає многочлен як вектор його коефіцієнтів у лінійному просторі. Нехай нам задано довільний ненульовий многочлен `f(x)` степеня `n` із дійсними або комплексними коефіцієнтами:

```
f(x) = aₙ xⁿ + aₙ₋₁ xⁿ⁻¹ + … + a₁ x + a₀
```

де старший коефіцієнт при `xⁿ` позначимо `aₙ ≠ 0`, а вільний член позначимо `a₀`.

Множину коефіцієнтів `(a₀, a₁, …, aₙ)` можна охарактеризувати кількома різними векторними нормами (від латинського *norma* — правило, мірило):

1. **Висота многочлена (`L_∞`-норма):**
   Максимальний за абсолютною величиною коефіцієнт многочлена, який позначимо `||f||_∞`:

   ```
   ||f||_∞ = max( |a₀|, |a₁|, …, |aₙ| )
   ```

2. **Мангеттенська норма (`L₁`-норма):**
   Сума абсолютних значень усіх коефіцієнтів многочлена, яку позначимо `||f||₁`:

   ```
   ||f||₁ = |a₀| + |a₁| + … + |aₙ| = ∑ |aᵢ|    [сума по i від 0 до n]
   ```

3. **Евклідова норма (`L₂`-норма):**
   Квадратний корінь із суми квадратів модулів усіх коефіцієнтів многочлена, яку позначимо `||f||₂`:

   ```
   ||f||₂ = √( |a₀|² + |a₁|² + … + |aₙ|² ) = √( ∑ |aᵢ|² )    [сума по i від 0 до n]
   ```

Між цими трьома нормами існує ланцюжок фундаментальних нерівностей, який випливає з класичної геометрії просторів:

```
||f||_∞ ≤ ||f||₂ ≤ ||f||₁ ≤ (n + 1) · ||f||_∞
```

Чому саме евклідова норма `||f||₂` виявилася найзручнішою для аналізу коефіцієнтів дільників? Причина полягає в тотожності Парсеваля з гармонічного аналізу. Якщо розглянути значення многочлена `f(z)` на одиничному колі комплексної площини `z = e^(i·θ)` (де `i` — уявна одиниця, а кут `θ` пробігає значення від `0` до `2π`), то середній інтегральний квадрат модуля функції точно дорівнює квадрату евклідової норми коефіцієнтів:

```
(1 / 2π) ∫ |f(e^(i·θ))|² dθ
= (1 / 2π) ∫ ( ∑ aₖ e^(i·k·θ) ) · ( ∑ āₘ e^(-i·m·θ) ) dθ    [розклад на суми]
= ∑ |aₖ|²                                                     [ортогональність експонент]
= ||f||₂²                                                     [означення L₂-норми]
```

Оскільки функції `e^(i·k·θ)` утворюють ортонормований базис на відрізку `[0, 2π]`, інтеграл від добутку `e^(i·k·θ) · e^(-i·m·θ)` дорівнює нулю при `k ≠ m` і дорівнює `2π` при `k = m`. Усі перехресні доданки тотожно зникають, залишаючи чисту суму квадратів коефіцієнтів `∑ |aₖ|²`. Цей результат перетворює алгебраїчну евклідову норму на аналітичний інтеграл за контуром, що дозволяє застосовувати потужний апарат теорії функцій комплексної змінної.

### 3. Комплексні корені та міра Малера

За основною теоремою алгебри кожен многочлен `f(x)` степеня `n` із комплексними коефіцієнтами повністю розкладається над полем комплексних чисел `ℂ` на `n` лінійних множників:

```
f(x) = aₙ · (x - α₁) · (x - α₂) · … · (x - αₙ) = aₙ · ∏ (x - αᵢ)    [добуток по i від 1 до n]
```

де числа `α₁, α₂, …, αₙ` — це комплексні корені многочлена `f(x)`.

Як оцінити загальний «масштаб» цих коренів? Якщо брати простий добуток модулів коренів `|α₁ · … · αₙ|`, то за формулами Вієта він дорівнює `|a₀ / aₙ|`. Проте якщо деякі корені прямують до нуля, цей добуток стає як завгодно малим і втрачає інформацію про великі корені, що лежать далеко від початку координат. Навпаки, якщо оцінювати кожен корінь через класичну межу Коші `|αᵢ| ≤ 1 + ||f||_∞ / |aₙ|`, ми отримуємо грубу оцінку, яка вважає, що всі `n` коренів можуть одночасно досягати максимального радіуса, що для реальних многочленів є неможливим через взаємні обмеження коефіцієнтів.

Щоб точно врахувати лише ті корені, які реально роздмухують значення многочлена на одиничному крузі, австралійський математик Курт Малер (*Kurt Mahler*) у 1960 році ввів спеціальну функціональну величину.

**Мірою Малера** многочлена `f(x)`, яку позначимо `M(f)`, називають добуток старшого коефіцієнта `|aₙ|` на максимуми між одиницею та модулями кожного з коренів:

```
M(f) = |aₙ| · ∏ max( 1, |αᵢ| )    [добуток по всім кореням i від 1 до n]
```

![Геометричний зміст міри Малера](/book/math/algebra/mignotte-bound/img/mahler-measure-roots.svg)
*Геометричне тлумачення міри Малера M(f) на комплексній площині: корені всередині одиничного круга |z| ≤ 1 входять у добуток з вагою 1, тоді як корені поза одиничним кругом |z| > 1 множать міру на свій радіус |αᵢ|.*

Кожен корінь `αᵢ` робить свій внесок у міру Малера за простим геометричним правилом:
* якщо корінь лежить усередині або на межі одиничного круга (`|αᵢ| ≤ 1`), він вносить у добуток нейтральний множник `1`;
* якщо корінь лежить строго зовні одиничного круга (`|αᵢ| > 1`), він множить міру на свою абсолютну величину `|αᵢ|`.

Аналітичний зміст міри Малера розкривається через знамениту **формулу Єнсена** (*Jensen's formula*) з комплексного аналізу. Для довільного лінійного множника `x - α` інтеграл від логарифма модуля на одиничному колі дає дивовижний розривний результат:

```
(1 / 2π) ∫₀²π ln |e^(i·θ) - α| dθ = ln( max( 1, |α| ) )
```

Цей результат доводиться розглядом двох випадків:
1. Якщо `|α| < 1`, функція `ln |z - α|` є гармонічною всередині одиничного круга `|z| ≤ 1`, і за теоремою про середнє значення гармонічної функції її інтеграл по межі круга точно дорівнює значенню в центрі `ln |0 - α| = ln |α|` при виколотому нулі, а інтегрування за формулою Пуассона дає точний нуль `ln(1) = 0`.
2. Якщо `|α| > 1`, ми виносимо множник `α` за дужки: `ln |e^(i·θ) - α| = ln |α| + ln |1 - e^(i·θ)/α|`. Оскільки `|1/α| < 1`, другий доданок є гармонічною функцією і його середнє значення на колі дорівнює нулю, залишаючи чистий внесок `ln |α|`.

Підсумовуючи інтеграли для всіх `n` коренів та додаючи старший коефіцієнт `ln |aₙ|`, отримуємо точну аналітичну формулу для логарифма міри Малера:

```
ln M(f) = ln |aₙ| + ∑ ln( max( 1, |αᵢ| ) ) = (1 / 2π) ∫₀²π ln |f(e^(i·θ))| dθ
```

З алгебраїчного означення міри Малера миттєво випливає її найважливіша фундаментальна властивість — **сувора мультиплікативність**.

Якщо многочлен `f(x)` розкладається на добуток двох многочленів `g(x)` та `h(x)`:

```
f(x) = g(x) · h(x)
```

то корені `f(x)` є точним об'єднанням коренів `g(x)` та `h(x)`, а старший коефіцієнт дорівнює добутку їхніх старших коефіцієнтів (`aₙ = bₖ · cₘ`). Отже:

```
M(f) = M(g) · M(h)
```

Ця мультиплікативність дає ключ до оцінки дільників. Для будь-якого цілочисельного многочлена `h(x) ∈ ℤ[x]` з ненульовим вільним членом `h(0) ≠ 0` його міра Малера задовольняє нерівність `M(h) ≥ 1`. Справді, добуток усіх коренів многочлена `h(x)` за теоремою Вієта дорівнює `|c₀ / cₘ|`, звідки:

```
M(h) = |cₘ| · ∏ max( 1, |γⱼ| ) ≥ |cₘ| · ∏ |γⱼ| = |cₘ| · |c₀ / cₘ| = |c₀| ≥ 1
```

Звідси маємо вирішальний висновок: **міра Малера будь-якого цілочисельного дільника `g(x)` ніколи не перевищує міри Малера самого вихідного многочлена `f(x)`**:

```
M(g) = M(f) / M(h) ≤ M(f)      [оскільки M(h) ≥ 1 для h(x) ∈ ℤ[x]]
```

### 4. Нерівність Ландау: місток між коренями та коефіцієнтами

Міра Малера `M(f)` чудово поводиться при множенні та діленні многочленів, але вона визначена через корені `αᵢ`, точні значення яких для полінома високого степеня знайти аналітично неможливо. Щоб перетворити міру Малера на практичний алгоритмічний інструмент, її необхідно оцінити зверху через величини, які обчислюються безпосередньо за коефіцієнтами многочлена.

Цю задачу ще у 1905 році розв'язав німецький математик Едмунд Ландау (*Edmund Landau*).

**Нерівність Ландау (1905)** стверджує, що для будь-якого комплексного многочлена `f(x)` його міра Малера не перевищує евклідової норми його коефіцієнтів:

```
M(f) ≤ ||f||₂
```

Ідея доведення цієї фундаментальної нерівності спирається на елегантну конструкцію з комплексного аналізу — добуток Бляшке (*Blaschke product*).

Нехай корені `α₁, …, αₘ` лежать поза одиничним кругом (`|αᵢ| > 1`), а решта коренів `α_{m+1}, …, αₙ` лежать усередині або на колі (`|αᵢ| ≤ 1`). Тоді міра Малера за означенням дорівнює `M(f) = |aₙ| · |α₁ · … · αₘ|`.

Розглянемо допоміжний многочлен `f*(z)`, у якому кожен «зовнішній» корінь `αᵢ` замінено на його дзеркальне відбиття всередину одиничного круга `1 / āᵢ`:

```
f*(z) = f(z) · ∏ ( (1 - āᵢ · z) / (z - αᵢ) )    [добуток по i від 1 до m]
```

Кожен дробово-раціональний множник `(1 - āᵢ · z) / (z - αᵢ)` є множником Бляшке. На одиничному колі `|z| = 1` модуль цього множника тотожно дорівнює одиниці:

```
| (1 - āᵢ · e^(i·θ)) / (e^(i·θ) - αᵢ) | = | e^(-i·θ) · (e^(i·θ) - āᵢ⁻¹) | / | e^(i·θ) - αᵢ | = 1
```

Оскільки на одиничному колі модуль `|f*(e^(i·θ))|` тотожно збігається з `|f(e^(i·θ))|`, їхні інтегральні середні квадратичні норми однакові. За тотожністю Парсеваля маємо рівність евклідових норм коефіцієнтів:

```
||f*||₂² = (1 / 2π) ∫₀²π |f*(e^(i·θ))|² dθ = (1 / 2π) ∫₀²π |f(e^(i·θ))|² dθ = ||f||₂²
```

З іншого боку, старший коефіцієнт нового многочлена `f*(z)` за абсолютною величиною точно дорівнює добутку `|aₙ| · |α₁ · … · αₘ| = M(f)`. А оскільки евклідова норма будь-якого многочлена `||f*||₂ = √( |a*ₙ|² + … + |a*₀|² )` не менша за модуль його старшого коефіцієнта `|a*ₙ|`, ми миттєво отримуємо:

```
M(f) = |a*ₙ| ≤ ||f*||₂ = ||f||₂
```

Сенс цієї нерівності вражає: складний нелінійний добуток модулів коренів, що лежать за межами одиничного кола, виявляється обмеженим простою геометричною довжиною вектора коефіцієнтів `√( ∑ |aᵢ|² )` у просторі `ℂⁿ⁺¹`.

Поєднавши мультиплікативність міри Малера з нерівністю Ландау, ми отримуємо головну нерівність для будь-якого дільника `g(x)` многочлена `f(x)` у кільці `ℤ[x]`:

```
M(g) ≤ M(f) ≤ ||f||₂
```

Тепер, знаючи оцінку міри Малера дільника `M(g) ≤ ||f||₂`, ми можемо повернутися до коефіцієнтів самого дільника `g(x)` за допомогою теореми Вієта.

Детальне крокове виведення формули Єнсена та строге доведення нерівності Ландау через інтегрування та визначники Адамара подано в окремому розборі: [математичне доведення нерівності Ландау та межі Міньотта](book:math/algebra/mignotte-bound/math-mignotte-proof.md).

### 5. Виведення межі Міньотта через теорему Вієта

Нехай многочлен `g(x)` степеня `k ≤ n` є дільником цілочисельного многочлена `f(x)` степеня `n` у кільці `ℤ[x]`:

```
g(x) = bₖ xᵏ + bₖ₋₁ xᵏ⁻¹ + … + b₁ x + b₀
```

де коефіцієнти `bⱼ` — невідомі нам цілі числа, які ми прагнемо обмежити зверху.

За теоремою Вієта кожен коефіцієнт `bⱼ` (при степені `xʲ`) виражається через старший коефіцієнт `bₖ` та суму добутків коренів дільника `β₁, β₂, …, βₖ`, узятих по `k - j` штук:

```
bⱼ = bₖ · (-1)ᵏ⁻ʲ · ∑ ( β_{i₁} · β_{i₂} · … · β_{i_{k-j}} )
```

де сума містить рівно стільки доданків, скількома способами можна вибрати `k - j` коренів із загальної кількості `k` наявних коренів. Кількість таких комбінацій задається біноміальним коефіцієнтом:

```
C(k, k - j) = C(k, j) = k! / ( j! · (k - j)! )
```

Оцінимо кожен окремий доданок у цій сумі за абсолютною величиною. Для будь-якого набору індексів `i₁, …, i_{k-j}` добуток відповідних коренів обмежується добутком усіх коренів дільника, модуль яких перевищує одиницю:

```
| β_{i₁} · … · β_{i_{k-j}} | ≤ ∏ max( 1, |βᵢ| ) = M(g) / |bₖ|    [оскільки |βᵢ| ≤ max(1, |βᵢ|)]
```

Підставимо цю оцінку в суму Вієта, застосувавши нерівність трикутника:

```
|bⱼ|
= |bₖ| · | ∑ ( β_{i₁} · … · β_{i_{k-j}} ) |      [модуль виразу Вієта]
≤ |bₖ| · ∑ | β_{i₁} · … · β_{i_{k-j}} |          [нерівність трикутника]
≤ |bₖ| · C(k, j) · ( M(g) / |bₖ| )               [оцінка кожного доданка через міру]
= C(k, j) · M(g)                                 [скорочення старшого коефіцієнта |bₖ|]
≤ C(k, j) · ||f||₂                               [застосування нерівності Ландау M(g) ≤ ||f||₂]
```

Ми отримали просте й красиве співвідношення: кожен окремий коефіцієнт `bⱼ` дільника `g(x)` обмежений біноміальним коефіцієнтом `C(k, j)`, помноженим на евклідову норму вхідного многочлена `||f||₂`.

Оскільки біноміальні коефіцієнти `C(k, j)` симетричні та досягають свого максимуму в центрі при `j = ⌊k / 2⌋`, максимальний коефіцієнт дільника (його висота `||g||_∞`) не перевищує центрального бінома:

```
||g||_∞ ≤ C( k, ⌊k / 2⌋ ) · ||f||₂
```

А оскільки сума всіх біноміальних коефіцієнтів одного рядка дорівнює `∑ C(k, j) = 2ᵏ`, груба експоненційна верхня оцінка записується як:

```
||g||_∞ ≤ 2ᵏ · ||f||₂
```

У своїй класичній праці 1974 року Моріс Міньотт уточнив цю оцінку, врахувавши степінь `n` вхідного многочлена `f(x)` та його старший коефіцієнт `aₙ`. Якщо відокремити один корінь і застосувати індукцію за степенем, то біноміальні коефіцієнти розщеплюються на суму за степенями `n - 1`:

**Теорема Міньотта (1974):**
Якщо многочлен `g(x) = bₖ xᵏ + … + b₀ ∈ ℤ[x]` ділить многочлен `f(x) = aₙ xⁿ + … + a₀ ∈ ℤ[x]`, то для кожного коефіцієнта `bⱼ` дільника виконується нерівність:

```
|bⱼ| ≤ C( n - 1, k - 1 ) · ||f||₂ + C( n - 1, k ) · |aₙ|
```

Якщо степінь шуканого дільника `k` заздалегідь невідомий, але ми шукаємо нетривіальний дільник (степінь якого не перевищує `⌊n / 2⌋`), то універсальна межа Міньотта для факторизації задається величиною:

```
B(f) = C( n, ⌊n / 2⌋ ) · ||f||₂ ≈ ( 2ⁿ / √( π · n / 2 ) ) · ||f||₂
```

Оцінка за формулою Стірлінга `C(n, n/2) ≈ 2ⁿ / √(π n / 2)` показує, що порівняно з наївною експонентою `2ⁿ` межа Міньотта дає додаткове поліноміальне стиснення знаменником `√(n)`, що для степенів `n = 50..100` економить десятки бітів у довгій арифметиці.

### 6. Порівняльний аналіз класичних меж дільників

Щоб зрозуміти місце межі Міньотта в комп'ютерній алгебрі, порівняємо її з іншими історичними оцінками, що розроблялися математиками протягом XX століття.

| Оцінка та автор | Рік | Формула верхньої межі `B(f)` | Асимптотика за `n` | Характеристика методу |
| :--- | :---: | :--- | :---: | :--- |
| **Оцінка Коші** | 1829 | `C(k, k/2) · (1 + \|\|f\|\|_∞ / \|aₙ\|)ᵏ` | `O( (2 R)ⁿ )` | Груба оцінка через максимальний радіус коренів `R` |
| **Гельфонд** | 1960 | `eⁿ · \|\|f\|\|_∞` | `O( 2.718ⁿ · \|\|f\|\|_∞ )` | Контурні інтеграли на колі `R = 1 + 1/n` |
| **Дорварт — Оре** | 1933 | `2ⁿ · \|\|f\|\|_∞` | `O( 2ⁿ · \|\|f\|\|_∞ )` | Рекурентні суми степеневих сум Ньютона |
| **Міньотт (класична)** | 1974 | `C(n, n/2) · \|\|f\|\|₂` | `O( 2ⁿ / √n · \|\|f\|\|₂ )` | Міра Малера + нерівність Ландау |
| **Міньотт (уточнена)** | 1974 | `C(n-1, k-1)·\|\|f\|\|₂ + C(n-1, k)·\|aₙ\|` | `O( C(n, k) · \|\|f\|\|₂ )` | Врахування степеня конкретного дільника `k` |
| **Бозамі (Bombieri)** | 1990 | `(3^(3/4) / 2√(π n)) · 2ⁿ/² · [f]₂` | `O( 1.414ⁿ / √n · [f]₂ )` | Зважена норма Бомб'єрі, найщільніша |

Головний стрибок точності, здійснений Міньоттом, полягає у переході від оцінки кожного окремого кореня `|αᵢ| ≤ R` до спільної інтегральної оцінки всього ансамблю коренів через міру Малера `M(f) ≤ ||f||₂`. Завдяки цьому зник множник `Rⁿ`, який перетворював наївні оцінки на гігантські астрономічні числа.

### 7. Покроковий розбір двох числових прикладів

Розглянемо практичний розрахунок меж коефіцієнтів на двох прикладах: навчальному многочлені 4-го степеня та многочлені 6-го степеня з контрольним розкладом на множники.

#### Приклад 1: Многочлен 4-го степеня
Нехай задано цілочисельний многочлен:

```
f(x) = 2 x⁴ - 3 x³ + 5 x² - 4 x + 6
```

Параметри: `n = 4`, `a₄ = 2`, `a₀ = 6`. Вектор коефіцієнтів: `(2, -3, 5, -4, 6)`.

1. **Обчислення висоти многочлена `||f||_∞`:**
   ```
   ||f||_∞ = max( |2|, |-3|, |5|, |-4|, |6| ) = 6
   ```

2. **Обчислення евклідової норми `||f||₂`:**
   ```
   ||f||₂² = 2² + (-3)² + 5² + (-4)² + 6²    [сума квадратів коефіцієнтів]
           = 4 + 9 + 25 + 16 + 36             [обчислення квадратів]
           = 90                               [значення суми]
   ||f||₂ = √90 ≈ 9.48683                     [вилучення кореня]
   ```

3. **Оцінка дільників степеня k = 1 (`g(x) = b₁ x + b₀`):**
   * Вільний член `b₀` (`j = 0`):
     ```
     |b₀| ≤ C( 3, 0 ) · √90 + C( 3, 1 ) · 2    [формула Міньотта для j=0, k=1, n=4]
          = 1 · 9.48683 + 3 · 2                 [підстановка значень біномів]
          = 9.48683 + 6                         [виконання множення]
          = 15.48683  →  |b₀| ≤ 15              [округлення до цілого зверху]
     ```
   * Старший коефіцієнт `b₁` (`j = 1`):
     Оскільки `b₁ | a₄` у кільці `ℤ`, маємо точну межу `|b₁| ≤ 2`.

4. **Оцінка дільників степеня k = 2 (`g(x) = b₂ x² + b₁ x + b₀`):**
   * Середній коефіцієнт `b₁` (`j = 1`):
     ```
     |b₁| ≤ C( 3, 1 ) · √90 + C( 3, 2 ) · 2    [формула Міньотта для j=1, k=2, n=4]
          = 3 · 9.48683 + 3 · 2                 [підстановка значень біномів]
          = 28.4605 + 6                         [виконання множення]
          = 34.4605  →  |b₁| ≤ 34               [округлення до цілого зверху]
     ```

#### Порівняння з наївною оцінкою Коші
Наївна оцінка коренів Коші дає круг радіуса `R = 1 + ||f||_∞ / |a₄| = 1 + 6/2 = 4`. Для коефіцієнта `b₁` квадратичного дільника наївна формула дає:

```
|b₁| ≤ C( 2, 1 ) · |b₂| · R² = 2 · 2 · 4² = 64
```

Межа Міньотта дає `34` замість `64`, скорочуючи простір пошуку практично вдвічі вже для 4-го степеня.

#### Приклад 2: Многочлен 6-го степеня з контрольним розкладом
Візьмемо многочлен, утворений множенням двох незвідних кубічних многочленів:

```
g(x) = x³ + 2 x - 3
h(x) = x³ - x² + 4
f(x) = g(x) · h(x) = x⁶ - x⁵ + 2 x⁴ + x³ - 8 x² + 8 x - 12
```

Параметри вхідного многочлена `f(x)`:
* степінь `n = 6`, старший коефіцієнт `a₆ = 1`, вільний член `a₀ = -12`;
* вектор коефіцієнтів: `(1, -1, 2, 1, -8, 8, -12)`;
* висота многочлена `||f||_∞ = 12`.

1. **Обчислення евклідової норми `||f||₂`:**
   ```
   ||f||₂² = 1² + (-1)² + 2² + 1² + (-8)² + 8² + (-12)²    [сума квадратів коефіцієнтів]
           = 1 + 1 + 4 + 1 + 64 + 64 + 144                 [обчислення степенів]
           = 279                                           [значення суми]
   ||f||₂ = √279 ≈ 16.7033                                 [вилучення кореня]
   ```

2. **Обчислення межі Міньотта для дільника степеня k = 3:**
   Для кубічного дільника центральний біноміальний коефіцієнт дорівнює `C(3, 1) = 3` або `C(6, 3) = 20` для універсальної межі:
   ```
   B(f) = C( 6, 3 ) · ||f||₂ = 20 · 16.7033 = 334.066  →  B(f) = 334
   ```
   За уточненою формулою Міньотта для `k = 3`:
   ```
   |bⱼ| ≤ C( 5, 2 ) · √279 + C( 5, 3 ) · 1 = 10 · 16.7033 + 10 · 1 = 177.033  →  |bⱼ| ≤ 177
   ```

3. **Перевірка на справжніх коефіцієнтах:**
   Коефіцієнти дільника `g(x) = x³ + 0 x² + 2 x - 3` за модулем не перевищують `3`.
   Коефіцієнти дільника `h(x) = x³ - x² + 0 x + 4` за модулем не перевищують `4`.
   Обидва значення `3` та `4` значно менші за межу `177`, тобто умова гарантовано виконується.

4. **Визначення глибини підйому Гензеля:**
   Необхідна умова відновлення цілих коефіцієнтів: `pᵏ > 2 · B(f) = 2 · 177 = 354`.
   Якщо ми обрали просте число `p = 5` (оскільки `5 ∤ a₆` і `disc(f) mod 5 ≠ 0`):
   * `5¹ = 5 < 354`
   * `5² = 25 < 354`
   * `5³ = 125 < 354`
   * `5⁴ = 625 > 354`  ← **Критерій зупинки виконано при k = 4!**

Достатньо підняти розклад за модулем `5` до модуля `5⁴ = 625`, щоб однозначно відновити справжні цілі множники `g(x)` та `h(x)`.

### 8. Зупинка підйому Гензеля та алгоритмічний конвеєр

Як знайдена межа `B(f)` керує роботою алгоритму факторизації? Розглянемо крок за кроком алгоритмічний ланцюжок системи комп'ютерної алгебри:

```
Вхідний многочлен: f(x) ∈ ℤ[x], степінь n, примітивний (НСД коефіцієнтів = 1)
 1. Обчислити евклідову норму ||f||₂ та розрахувати межу дільників B(f)
 2. Підібрати мале просте число p таке, що p ∤ aₙ та f(x) mod p є вільним від квадратів
 3. Розкласти f(x) mod p на незвідні множники в 𝔽ₚ[x]:
    f(x) ≡ aₙ · g₁(x) · g₂(x) … gᵣ(x)  (mod p)
 4. Розрахувати необхідний степінь підйому k:
    pᵏ > 2 · |aₙ| · B(f)
 5. Виконати квадратичний підйом Гензеля:
    p → p² → p⁴ → p⁸ → … → pᵏ
 6. Рекомбінація Цассенгауза:
    Для підмножин S ⊆ {1, 2, …, r} сформувати потенційний дільник:
    G_S(x) ≡ aₙ · ∏_{i ∈ S} gᵢ(x)  (mod pᵏ)
 7. Симетричне відображення коефіцієнтів G_S(x) у діапазон (-pᵏ/2, pᵏ/2]
 8. Перевірити діленням у ℤ[x]: якщо G_S(x) ділить aₙ · f(x), виділити справжній множник
```

#### Вибір «гарного» простого числа p
Вибір модуля `p` є першим критичним кроком. Система комп'ютерної алгебри вимагає виконання двох умов:
1. `p ∤ aₙ`: старший коефіцієнт не повинен обнулятися за модулем `p`, інакше степінь багаточлена в `𝔽ₚ[x]` штучно зменшиться.
2. `p ∤ disc(f)` (дискримінант багаточлена): многочлен `f(x) mod p` не повинен мати кратних множників (повинен бути вільним від квадратів, англ. *square-free*).

Чому друга умова обов'язкова? Підйом Гензеля спирається на розв'язання співвідношення Безу в `𝔽ₚ[x]`:

```
s(x) · g(x) + t(x) · h(x) ≡ 1  (mod p)
```

де `s(x)` та `t(x)` знаходяться за допомогою розширеного алгоритму Евкліда. Якщо многочлени `g(x)` та `h(x)` мають спільний дільник (що відбувається при кратності коренів), їхній найбільший спільний дільник `НСД(g, h) ≠ 1`, одиниця в правій частині недосяжна, і підйом Гензеля зазнає незворотного краху через спробу ділення на необоротний нульовий дільник у кільці лишків.

Щоб перевірити цю умову без прямого обчислення гігантського дискримінанта `disc(f)`, система алгебри просто бере похідну `f'(x) mod p` і перевіряє умову `НСД( f mod p, f' mod p ) == 1` безпосередньо в полі `𝔽ₚ[x]`. Якщо степінь спільного дільника більший за нуль, модуль `p` відкидається і алгоритм бере наступне просте число (`p = 3, 5, 7, 11, 13, …`).

#### Симетричне зведення за модулем pᵏ
Ключовим є крок 7: симетричне зведення за модулем `pᵏ`.

Коли підйом Гензеля знаходить коефіцієнт `cⱼ` дільника як лишок за модулем `pᵏ`, цей лишок належить стандартному додатному діапазону `[0, pᵏ - 1]`. Але справжній цілочисельний коефіцієнт `bⱼ` може бути як додатним, так і від'ємним.

Щоб однозначно визначити знак, ми виконуємо симетричне зведення:

```
bⱼ = cⱼ,            якщо cⱼ ≤ pᵏ / 2
bⱼ = cⱼ - pᵏ,       якщо cⱼ > pᵏ / 2
```

Якщо `pᵏ > 2 · B(f)`, то довжина інтервалу `(-pᵏ / 2, pᵏ / 2]` строго більша за `2 · B(f)`. Оскільки справжній коефіцієнт гарантовано задовольняє нерівність `-B(f) ≤ bⱼ ≤ B(f)`, він потрапляє в цей симетричний інтервал в єдиний спосіб, і модулярна неоднозначність повністю зникає.

З погляду p-адичного аналізу, цей процес має прозору топологічну інтерпретацію. Ультраметрична куля радіуса `p^(-k)` у полі p-адичних чисел `ℚₚ` стягується зі зростанням `k`. Щойно її радіус стає меншим за `1 / (2 B(f))`, вона містить **рівно одне** ціле раціональне число з архімедового відрізка `[-B(f), B(f)]`. Таким чином, аналітична збіжність за неархімедовою нормою Гензеля однозначно фіксує класичну евклідову координату.

#### Раннє відсіювання Еббота (Early Abort)
Навіть якщо підйом виконано, перевірка діленням многочленів у кільці `ℤ[x]` для кожної з `2ʳ` підмножин є обчислювально дорогою операцією. У 1990-х роках Джон Еббот (*John Abbott*) запропонував евристику раннього відсіювання: обчислити значення многочлена в кількох цілих точках (наприклад, `x = 2` та `x = -3`). Якщо комбінація модулярних дільників `G_S(2)` не ділить число `f(2)` у кільці цілих чисел `ℤ`, то многочлен `G_S(x)` гарантовано не є дільником `f(x)`, і дороге ділення многочлена «в стовпчик» навіть не починається.

Практичну реалізацію факторизації многочленів за алгоритмом Цассенгауза, підйом Гензеля та симетричне відновлення цілих коефіцієнтів мовами Python, C та C++ подано у проектному розборі: [алгоритм підйому Гензеля та факторизація многочленів](book:math/algebra/mignotte-bound/proj-hensel-zassenhaus.md).

### 9. Межа Міньотта для многочленів від багатьох змінних

У сучасних системах комп'ютерної алгебри переважна більшість прикладних задач вимагає факторизації многочленів не від однієї, а від багатьох змінних: `f(x₁, x₂, …, xₘ) ∈ ℤ[x₁, …, xₘ]`.

Як узагальнюється межа Міньотта на багатовимірний випадок?

Нехай многочлен `f(x₁, …, xₘ)` має степінь `nᵢ` за кожною змінною `xᵢ`. Щоб звести багатовимірну факторизацію до одновимірної, класичний підхід Кронекера застосовує степеневу підстановку змінних:

```
x₂ = y^(d₁),  x₃ = y^(d₁ · d₂),  …,  xₘ = y^(d₁ · … · d_{m-1})
```

де степені `dᵢ > nᵢ` вибираються так, щоб степені різних одночленів не перекривалися.

Узагальнена багатовимірна межа Міньотта стверджує, що для будь-якого дільника `g(x₁, …, xₘ)` його евклідова норма задовольняє нерівність:

```
||g||₂ ≤ ( ∏ C( nᵢ, ⌊nᵢ / 2⌋ ) ) · ||f||₂    [добуток по всім змінним від 1 до m]
```

А для максимального коефіцієнта дільника `||g||_∞` у кільці `ℤ[x₁, …, xₘ]` виконується строга верхня межа:

```
||g||_∞ ≤ 2^( ∑ nᵢ ) · ||f||₂
```

Це співвідношення гарантує, що системи комп'ютерної алгебри можуть застосовувати модулярний підйом Гензеля і для багатовимірних задач, по черзі піднімаючи змінні від однієї точки оцінки до повної символьної форми.

### 10. Межі точності, поліноми Міньотта та редукція ґраток LLL

Чи можна вважати межу Міньотта абсолютно точною, чи існують многочлени, на яких вона завищує оцінку?

Сам Моріс Міньотт показав, що існують спеціальні родини многочленів, для яких коефіцієнти дільників справді експоненціально великі порівняно з коефіцієнтами самого многочлена. Ці многочлени сьогодні називають **поліномами Міньотта** (англ. *Mignotte polynomials*):

```
f(x) = xⁿ - 2 · (a x - 1)²
```

де `a ≥ 2` — ціле число.

Многочлен `f(x)` має дуже малі коефіцієнти (найбільший коефіцієнт дорівнює `2 a²`). Проте він має два комплексні корені, які розташовані надзвичайно близько один до одного: відстань між ними дорівнює приблизно:

```
|α₁ - α₂| ≈ 2 · a^(-(n+2)/2)
```

Через таку близькість коренів їхній добуток утворює дільники над `ℂ`, коефіцієнти яких досягають величини порядку `2ⁿ · a²,` практично впритул наближаючись до теоретичної межі Міньотта. Це доводить, що експоненційний вигляд оцінки `2ⁿ` є принципово непереборним у найгіршому випадку.

![Порівняння оцінок зростання коефіцієнтів дільників](/book/math/algebra/mignotte-bound/img/coefficient-bounds-growth.svg)
*Порівняння швидкості зростання логарифма верхньої межі коефіцієнтів дільника log₂(B) для різних методів: від наївних оцінок Коші та Гельфонда до межі Міньотта та асимптотично найщільнішої межі Бозамі.*

Для загальних випадків у 1990-х роках французький математик Бернар Бозамі (*Bernard Beauzamy*) запропонував ще тоншу оцінку на основі зваженої норми Бомб'єрі:

```
[f]₂ = √( ∑ |aᵢ|² / C(n, i) )
```

Межа Бозамі дає асимптотичне покращення порядку `2ⁿ/² / √(π · n)`, що дозволяє заощадити ще кілька кроків підйому Гензеля для многочленів високих степенів.

#### Зведення до ґраток: Алгоритм LLL
Хоча межа Міньотта гарантує зупинку підйому Гензеля, на етапі комбінування модулярних множників класичний алгоритм Цассенгауза стикається з комбінаторним вибухом: якщо многочлен розпався на `r` модулярних множників у `𝔽ₚ[x]`, кількість підмножин для перевірки дорівнює `2ʳ`. Якщо `r = 60` (що нерідко трапляється для складних складених многочленів), перебір `2⁶⁰ ≈ 1.15 · 10¹⁸` варіантів стає нездійсненним.

Цю комбінаторну проблему у 1982 році остаточно розв'язали Ар'єн Ленстра, Гендрік Ленстра та Ласло Ловас, створивши знаменитий **алгоритм LLL** (редукція базису ґраток).

Замість перебору `2ʳ` комбінацій алгоритм LLL будує цілочисельну ґратку в просторі `ℤ^{d+k}`, базисні вектори якої кодують коефіцієнти модулярного дільника `g(x) mod pᵏ`. Шуканий справжній дільник у кільці `ℤ[x]` відповідає надзвичайно короткому вектору в цій ґратці, оскільки його коефіцієнти обмежені межею Міньотта `B(f)`. Алгоритм LLL знаходить майже найкоротший вектор за строго поліноміальний час `O(n¹² + n⁹ log³ ||f||_∞)`, перетворюючи факторизацію многочленів на гарантовано швидку поліноміальну процедуру.

### Підсумок: міст від аналізу до дискретної алгебри

Межа Міньотта — це яскравий приклад того, як абстрактна неперервна математика (комплексний аналіз, контурний інтеграл Єнсена на одиничному колі, тотожність Парсеваля та нерівність Ландау) розв'язує суто дискретну інженерну проблему комп'ютерної алгебри. 

Обмежуючи геометричний розмір коренів через евклідову норму коефіцієнтів, межа Міньотта перетворює нескінченний простір пошуку дільників у кільці `ℤ[x]` на компактну скінченну задачу, створюючи надійний критерій зупинки для p-адичних алгоритмів сучасної символьної математики.
