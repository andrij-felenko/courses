# Біноміальна теорема: від комбінаторного розкладу до нескінченних степеневих рядів

<preknowlist>
- [Кільця](book:math/rings) — комутативні кільця, додавання та множення: біноміальна теорема виконується в будь-якому комутативному кільці з одиницею.
- [Твірні функції](book:math/generating-functions) — згортка та степені многочленів: зв'язок біноміальних коефіцієнтів із формальними степенними рядами.
</preknowlist>

Уявіть, що перед вами стоїть задача знайти точний коефіцієнт при `x⁸` у розкладі багаточлена `(2x - 3)¹²` або швидко обчислити значення `(1.01)¹⁰` з точністю до десятого знака після коми без прямих числовомістких множень. Якщо намагатися розкривати дужки у виразі `(a + b)¹²` послідовно — множенням дужки на дужку крок за кроком, ви миттєво опиняєтеся перед деревом з `2¹² = 4096` окремих доданків, які потрібно вручну групувати, зводити та перевіряти індекси. Пряме послідовне множення двочленів має експоненціальну складність відносно показника степеня `n`, що робить ручні алгебраїчні виведення та числові обчислення практично неможливими при зростанні `n`.

Проілюструємо цю складність на числовому прикладі. Припустимо, що нам потрібно обчислити точне значення виразу `(1 + 0.02)⁶` з високою точністю. Множення шість разів поспіль числа `1.02` вимагає п'яти послідовних операцій множення дробових чисел з багаторазовим накопиченням округлень. Натомість, володіючи формулою розкладу двочлена, ми можемо за лічені секунди виписати перші доданки: `1 + 6·(0.02) + 15·(0.02)² + 20·(0.02)³ + … = 1 + 0.12 + 0.006 + 0.00016 = 1.12616`, отримавши точне значення практично без обчислювальних зусиль.

Аналогічна задача виникає у комбінаториці та теорії ймовірностей: якщо монету кидають 10 разів, то скількома способами можна отримати точно 4 герби? Відповіддю є коефіцієнт при `a⁶ b⁴` у розкладі `(a + b)¹⁰`, який дорівнює `C(10, 4) = 210`.

Фундаментальним розв'язком проблеми послідовного множення двочленів є **біноміальна теорема** (англ. *binomial theorem*, нім. *Binomischer Lehrsatz*). Термін *біном* походить від латинського *bis* («двічі») та грецького *νόμος* / латинізованого *nomen* («назва, член», тобто «двочлен»). Теорема дає точну, замкнену алгебраїчну формулу для подання будь-якого натурального степеня суми `(a + b)ⁿ` у вигляді скінченної суми окремих доданків без проведення послідовних множень.

Замість того щоб розгортати дерева виборів, біноміальна теорема доводить, що коефіцієнт при кожному доданку `aⁿ⁻ᵏ · bᵏ` повністю визначається кількістю способів вибрати `k` елементів із `n` доступних позицій без урахування порядку — тобто комбінаторним числом `C(n, k) = n! / (k! · (n - k)!)`. Про те, як цей алгебраїчний інструмент пройшов шлях від стародавньої індійської поетики та середньовічних східних алгоритмів добування коренів до відкриття нескінченних рядів Ісааком Ньютоном, розписано в окремому історичному матеріалі: [історія виникнення біноміальної теореми](book:math/algebra/binomial-theorem/hist-binomial-theorem.md).

### 1. Комбінаторне походження: чому коефіцієнти дорівнюють C(n, k)

Щоб зрозуміти внутрішній механізм біноміальної теореми, простежимо процес піднесення двочлена `(a + b)` до натурального степеня `n`. За означенням степеня ми множимо `n` одинакових дужок:

```
(a + b)ⁿ = (a + b)₁ · (a + b)₂ · (a + b)₃ · … · (a + b)♙
```

За дистрибутивним законом алгебри при розкритті цих `n` дужок кожен окремий доданок у підсумковій сумі утворюється шляхом вибору **одного з двох елементів** (`a` або `b`) з кожної дужки. Якщо ми вирішуємо вибрати елемент `b` з точно `k` дужок, ми вимушені вибрати елемент `a` з решти `n - k` дужок. Перемноження цих елементів дає одночлен вигляду `aⁿ⁻ᵏ · bᵏ`.

Оскільки в комутативній алгебрі порядок множення елементів не має значення (`a·b = b·a`), усі одночлени, які містять однакову кількість `k` множників `b`, є подібними доданками і додаються один до одного.

Загальний коефіцієнт при доданку `aⁿ⁻ᵏ · bᵏ` дорівнює кількості комбінаторних способів обрати `k` дужок із загальної кількості `n` дужок, з яких буде взято саме елемент `b`. За означенням комбінаторики кількість способів вибрати `k`-елементну підмножину з `n`-елементної множини без урахування порядку є комбінаторним числом сполучень `C(n, k)` (також позначається `(n choose k)` або `Cₙᵏ`).

Проілюструємо цей процес для випадку `n = 3`:

```
(a + b)³ = (a + b)₁ · (a + b)₂ · (a + b)₃
```

Кожен із 8 підсумкових доданків утворюється вибором літери з першої, другої та третьої дужок:
- `a·a·a = a³` (1 спосіб: вибір `b` з 0 дужок, `C(3, 0) = 1`)
- `a·a·b + a·b·a + b·a·a = 3·a²b` (3 способи: вибір `b` з 1 дужки, `C(3, 1) = 3`)
- `a·b·b + b·a·b + b·b·a = 3·ab²` (3 способи: вибір `b` з 2 дужок, `C(3, 2) = 3`)
- `b·b·b = b³` (1 спосіб: вибір `b` з 3 дужок, `C(3, 3) = 1`)

![Дерево комбінаторних виборів при розкритті двочлена (a + b)³](/book/math/algebra/binomial-theorem/img/combinatorial-tree.svg)
*Дерево комбінаторних виборів при розкритті (a + b)³. Кожна гілка відповідає вибору елемента a або b з відповідної дужки. Усі 8 підсумкових доданків групуються за кількістю виборів b у 4 коефіцієнти трикутника Паскаля.*

Оскільки кількість виборів `b` може становити будь-яке ціле число від `k = 0` (з жодної дужки не взято `b`) до `k = n` (з усіх дужок взято `b`), повна сума розкладу являє собою суму `n + 1` доданків.

### 2. Формулювання для натуральних степенів та трикутник Паскаля

Сформулюємо класичну біноміальну теорему для натуральних показників степеня.

Для будь-якого цілого невід'ємного числа `n ∈ ℕ₀` та довільних елементів `a` і `b`, які комутують між собою (`a·b = b·a`), виконується тотожність:

```
(a + b)ⁿ = ∑ₖ₌₀ⁿ C(n, k) · aⁿ⁻ᵏ · bᵏ
         = C(n, 0)·aⁿ + C(n, 1)·aⁿ⁻¹·b + C(n, 2)·aⁿ⁻²·b² + … + C(n, n)·bⁿ
```

де біноміальний коефіцієнт `C(n, k)` визначається через факторіали:

```
C(n, k) = n! / (k! · (n - k)!)    (при 0 ≤ k ≤ n)
```

#### Фундаментальні властивості біноміальних коефіцієнтів

Біноміальні коефіцієнти володіють низкою глибоких симетрій та алгебраїчних тотожностей:

1. **Симетрія коефіцієнтів:**
   ```
   C(n, k) = C(n, n - k)
   ```
   Алгебраїчно це випливає з симетрії факторіальної формули `n! / (k! · (n - k)!)`, а комбінаторно означає, що вибір `k` елементів `b` тотожний вибору `n - k` елементів `a`, які залишаються.

2. **Тотожність Паскаля (рекурентна формула):**
   ```
   C(n, k) = C(n - 1, k - 1) + C(n - 1, k)    (для 1 ≤ k ≤ n - 1)
   ```
   Ця тотожність лежить в основі побудови арифметичного трикутника Паскаля: кожне число всередині трикутника дорівнює сумі двох чисел, розташованих безпосередньо над ним у попередньому рядку.

![Трикутник Паскаля та рекурентне правило додавання елементів](/book/math/algebra/binomial-theorem/img/pascal-triangle.svg)
*Трикутник Паскаля для рядків від n = 0 до n = 5. Підсвічено додавання двох сусідніх коефіцієнтів C(4, 1) = 4 та C(4, 2) = 6, які утворюють коефіцієнт C(5, 2) = 10 у наступному рядку.*

3. **Загальна сума коефіцієнтів рядка (підстановка a = 1, b = 1):**
   ```
   ∑ₖ₌₀ⁿ C(n, k) = C(n, 0) + C(n, 1) + C(n, 2) + … + C(n, n) = 2ⁿ
   ```
   Комбінаторний зміст цієї тотожності полягає в тому, що сума кількостей підмножин усіх можливих розмірів `k` дорівнює загальній кількості всіх підмножин (булеану) множини з `n` елементів.

4. **Знакопочережна сума коефіцієнтів (підстановка a = 1, b = -1):**
   ```
   ∑ₖ₌₀ⁿ (-1)ᵏ · C(n, k) = C(n, 0) - C(n, 1) + C(n, 2) - C(n, 3) + … = 0    (для n ≥ 1)
   ```
   Це означає, що кількість підмножин парного розміру точно дорівнює кількості підмножин непарного розміру для будь-якої скінченної множини.

5. **Вважена сума біноміальних коефіцієнтів:**
   Продиференціюємо біноміальний розклад `(1 + x)ⁿ = ∑ C(n, k) · xᵏ` по `x`:
   ```
   n · (1 + x)ⁿ⁻¹ = ∑ₖ₌₁ⁿ k · C(n, k) · xᵏ⁻¹
   ```
   Підставивши `x = 1`, отримуємо важливу комбінаторну тотожність:
   ```
   ∑ₖ₌₁ⁿ k · C(n, k) = 1·C(n, 1) + 2·C(n, 2) + 3·C(n, 3) + … + n·C(n, n) = n · 2ⁿ⁻¹
   ```

6. **Тотожність ключки для гольфу (Hockey-stick Identity):**
   Сума коефіцієнтів вздовж діагоналі трикутника Паскаля згортається в один коефіцієнт наступного рядка:
   ```
   ∑ᵢ₌ᵣⁿ C(i, r) = C(r, r) + C(r + 1, r) + … + C(n, r) = C(n + 1, r + 1)
   ```

Повні математичні доведення біноміальної теореми алгебраїчним методом індукції та аналітичним методом Тейлора подано у розборі: [строгі доведення біноміальної теореми](book:math/algebra/binomial-theorem/math-binomial-proofs.md).

### 3. Біноміальна теорема в абстрактній алгебрі: комутативні кільця та характеристика p

У загальній абстрактній алгебрі додаванки `a` і `b` не обов'язково є звичайними дійсними чи комплексними числами. Нехай `R` — довільне **комутативне кільце з одиницею** (наприклад, кільце многочленів `K[x]`, кільце лишків `ℤ/mℤ` або кільце формальних степеневі рядів `K[[x]]`). Біноміальна теорема є суворою тотожністю в будь-якому комутативному кільці.

#### Що відбувається у некомутативних алгебраїчних структурах?

Якщо елементи `a` і `b` належать некомутативному кільцю (наприклад, кільцю квадратних матриць `Mₙ(K)` або кільцю диференціальних операторів), де `a·b ≠ b·a`, класична формула біноміальної теореми **не виконується**.

Розглянемо квадрат суми двох некомутативних матриць `A` та `B`:

```
(A + B)² = (A + B) · (A + B) = A² + A·B + B·A + B²
```

Оскільки в загальному випадку `A·B ≠ B·A`, ми не можемо згрупувати середні доданки у `2A·B`. Для куба `(A + B)³` розклад містить 8 окремих доданків з урахуванням порядку множників: `A³ + A²B + ABA + AB² + BA² + BAB + B²A + B³`.

В алгебрах Лі та квантовій механіці некомутативність описується за допомогою **комутатора** `[A, B] = A·B - B·A`. Якщо комутатор `[A, B]` комутує із самими операторами `A` та `B` (тобто `[A, [A, B]] = 0` та `[B, [A, B]] = 0`), використовують спеціальну тотожність Бейкера — Кемпбелла — Хаусдорфа:

```
eᴬ · e⠃ = e^{A + B + (1/2)·[A, B]}
```

Біноміальна теорема є застосовною для матриць та операторів у класичному вигляді лише за умови їхньої строгої **комутативності** (`A·B = B·A`).

#### Кільця характеристики p та ендоморфізм Фробеніуса

Особливо потужні алгебраїчні наслідки біноміальна теорема має у кільцях і полях характеристики `p`, де `p` — просте число (наприклад, скінченні поля `GF(p)` або `GF(pᵐ)`).

Розглянемо біноміальний коефіцієнт `C(p, k)` для будь-якого проміжного індексу `0 < k < p`:

```
C(p, k) = p! / (k! · (p - k)!) = [ p · (p - 1) · … · (p - k + 1) ] / [ 1 · 2 · … · k ]
```

Чисельник містить просте число `p`. Оскільки знаменник складається з добутку чисел `1, 2, …, k`, кожне з яких строго менше за просте число `p`, знаменник не містить множника `p` і не може скоротити його. Отже, у кільці цілих чисел для всіх `0 < k < p` біноміальний коефіцієнт `C(p, k)` **ділиться на p без остачі**:

```
C(p, k) ≡ 0 (mod p)    (для всіх 0 < k < p)
```

Завдяки цьому у кільці характеристики `p` абсолютно всі проміжні доданки у розкладі бінома `(a + b)ᵖ` тотожно перетворюються на нуль!

![Ендоморфізм Фробеніуса у кільці характеристики p](/book/math/algebra/binomial-theorem/img/frobenius-endomorphism.svg)
*Знищення проміжних доданків у кільці характеристики p = 5. Коефіцієнти C(5, 1)=5, C(5, 2)=10, C(5, 3)=10, C(5, 4)=5 діляться на 5 і перетворюються на 0 mod 5, залишаючи лишь крайні члени a⁵ + b⁵.*

Це дає фундаментальне співвідношення у модулярній алгебрі:

```
(a + b)ᵖ ≡ aᵖ + bᵖ (mod p)
```

Завдяки індукції це співвідношення поширюється на будь-які степені вигляду `pᵐ`:

```
(a + b)^{pᵐ} ≡ a^{pᵐ} + b^{pᵐ} (mod p)
```

Алгебраїчне відображення `F: R → R`, задане формулою `F(x) = xᵖ`, зберігає додавання та множення і називається **ендоморфізмом Фробеніуса** (англ. *Frobenius endomorphism*).

> 🔧 **Навіщо це.** У криптографії на еліптичних кривих та арифметиці скінченних полів `GF(2ᵐ)` ендоморфізм Фробеніуса дозволяє розкривати степені сум абсолютно лінійно без обчислення проміжних крос-добутків, що прискорює модулярне піднесення до степеня у тисячі разів.

### 4. Узагальнена біноміальна теорема Ньютона для дійсних та від'ємних степенів

Класичний розклад `(a + b)ⁿ` обмежується цілими невід'ємними степенями `n`, оскільки кількість доданків у підсумковій сумі має бути скінченною. У 1665 році Ісаак Ньютон узагальнив біноміальну теорему для довільного дійсного (або комплексного) показника степеня `α ∈ ℝ`.

Винесемо `a` за дужки: `(a + b)α = aα · (1 + x)α`, де `x = b / a`. Для виразу `(1 + x)α` введемо **узагальнений біноміальний коефіцієнт**:

```
C(α, k) = α · (α - 1) · (α - 2) · … · (α - k + 1) / k!    (де k ∈ ℕ₀, і C(α, 0) = 1)
```

Зверніть увагу: якщо `α = n` є натуральним числом, то при `k > n` один із множників чисельника `(n - n) = 0`, і всі коефіцієнти починаючи з `k = n + 1` стають тотожними нулями (ряд обривається на `n + 1` члені). Якщо ж `α` не є цілим невід'ємним числом, жоден множник у чисельнику не перетворюється на нуль, і розклад перетворюється на **нескінченний степеней ряд**:

```
(1 + x)α = ∑ₖ₌₀∞ C(α, k) · xᵏ
         = 1 + α·x + [α(α - 1)/2!]·x² + [α(α - 1)(α - 2)/3!]·x³ + …
```

#### Область збіжності ряду Ньютона

Оскільки узагальнений розклад є нескінченним рядом, постає питання про область його математичної збіжності. За ознакою Даламбера відношення модулів двох сусідніх членів ряду прямує до `|x|`:

```
lim_{k → ∞} | [ C(α, k + 1) · xᵏ⁺¹ ] / [ C(α, k) · xᵏ ] | = |x|
```

Нескінченний біноміальний ряд Ньютона **абсолютно збігається при |x| < 1** (тобто коли `|b| < |a|`).

![Збіжність узагальненого біноміального ряду Ньютона для sqrt(1 + x)](/book/math/algebra/binomial-theorem/img/newton-series-convergence.svg)
*Наближення функції f(x) = √(1 + x) багаточленами Тейлора P₁(x), P₂(x), P₃(x). Усередині інтервалу |x| < 1 наближення стрімко збігається до точної кривої.*

#### Важливі окремі випадки ряду Ньютона

1. **Від'ємний цілий степінь α = -1 (Геометрична прогресія):**
   Обчислимо узагальнений коефіцієнт для `α = -1`:
   `C(-1, k) = (-1) · (-2) · … · (-k) / k! = (-1)ᵏ · k! / k! = (-1)ᵏ`
   Підставивши цей коефіцієнт у ряд для `(1 - x)⁻¹`:
   ```
   (1 - x)⁻¹ = 1 / (1 - x) = 1 + x + x² + x³ + x⁴ + …    (при |x| < 1)
   ```

2. **Степінь α = -2:**
   `C(-2, k) = (-2) · (-3) · … · (-k - 1) / k! = (-1)ᵏ · (k + 1)`
   ```
   (1 - x)⁻² = 1 / (1 - x)² = 1 + 2x + 3x² + 4x³ + 5x⁴ + …
   ```

3. **Квадратний корінь α = 1/2:**
   Обчислимо перші коефіцієнти для `α = 1/2`:
   `C(1/2, 0) = 1`
   `C(1/2, 1) = 1/2`
   `C(1/2, 2) = (1/2)·(-1/2) / 2! = -1/8`
   `C(1/2, 3) = (1/2)·(-1/2)·(-3/2) / 3! = 1/16`
   `C(1/2, 4) = (1/2)·(-1/2)·(-3/2)·(-5/2) / 4! = -5/128`

   Це дає класичну формулу наближеного добування квадратного кореня:
   ```
   √(1 + x) = (1 + x)¹/² = 1 + (1/2)·x - (1/8)·x² + (1/16)·x³ - (5/128)·x⁴ + …
   ```

4. **Обернений квадратний корінь α = -1/2:**
   `C(-1/2, k) = (-1)ᵏ · (2k)! / (4ᵏ · (k!)²)`
   ```
   1 / √(1 + x) = (1 + x)⁻¹/² = 1 - (1/2)·x + (3/8)·x² - (5/16)·x³ + …
   ```

> 🔧 **Навіщо це.** У релятивістській фізиці кінетична енергія тіла дорівнює `E_k = m₀·c² · (1 / √(1 - v²/c²) - 1)`. При низьких швидкостях `v ≪ c` (де `x = -v²/c²`) застосовують узагальнений біноміальний розклад для `α = -1/2`: `1 / √(1 - v²/c²) ≈ 1 + (1/2)·(v²/c²) + (3/8)·(v⁴/c⁴)`. Перший член розкладу видає класичну ньютонівську формулу `E_k ≈ (1/2)·m₀·v²`, а наступні члени дають релятивістські поправки.

### 5. Мультиноміальна теорема: піднесення до степеня суми m доданків

Біноміальну теорему можна узагальнити з двочлена `(a + b)` на суму довільної кількості `m` доданків: `(x₁ + x₂ + … + xₘ)ⁿ`. Отриманий розклад називають **мультиноміальною теоремою** (англ. *multinomial theorem*).

Розкриваючи `n` дужок `(x₁ + x₂ + … + xₘ)ⁿ`, ми обираємо доданок `x₁` з `k₁` дужок, доданок `x₂` з `k₂` дужок, і так далі, аж до `xₘ` з `kₘ` дужок, де сума показників задовольняє умову:

```
k₁ + k₂ + … + kₘ = n    (при kᵢ ≥ 0)
```

Кількість способів розбити `n` елементів на `m` груп розмірами `k₁, k₂, …, kₘ` визначається **мультиноміальним коефіцієнтом**:

```
C(n; k₁, k₂, …, kₘ) = n! / (k₁! · k₂! · … · kₘ!)
```

Загальна формула мультиноміального розкладу має вигляд:

```
(x₁ + x₂ + … + xₘ)ⁿ = ∑_{k₁+k₂+…+kₘ=n} [ n! / (k₁! · k₂! · … · kₘ!) ] · x₁^{k₁} · x₂^{k₂} · … · xₘ^{kₘ}
```

Наприклад, розклад куба тричлена `(a + b + c)³` містить `C(3 + 3 - 1, 3) = 10` різних комбінацій доданків:

```
(a + b + c)³ = a³ + b³ + c³ + 3a²b + 3a²c + 3ab² + 3ac² + 3b²c + 3bc² + 6abc
```

Зверніть увагу на коефіцієнт при доданій комбінації `abc`: він дорівнює мультиноміальному коефіцієнту `3! / (1! · 1! · 1!) = 6`.

Мультиноміальні коефіцієнти відіграють центральну роль у мультиноміальному розподілі ймовірностей в математичній статистиці, де оцінюють ймовірність випадання комбінацій з `m` різних результатів у `n` незалежних випробуваннях.

### 6. Біноміальний розподіл ймовірностей та випробування Бернуллі

У теорії ймовірностей біноміальна теорема забезпечує фундаментальну нормувальну основу для **біноміального розподілу**.

Розглянемо послідовність з `n` незалежних випробувань Бернуллі, у кожному з яких подія настає з ймовірністю `p` (упіх) та не настає з ймовірністю `q = 1 - p` (невдача).

Ймовірність того, що у `n` незалежних випробуваннях подія настане точно `k` разів, дорівнює:

```
P(X = k) = C(n, k) · pᵏ · (1 - p)ⁿ⁻ᵏ
```

Завдяки біноміальній теоремі сума ймовірностей для всіх можливих результатів `k = 0, 1, …, n` гарантовано дорівнює 1 (умова нормування ймовірнісного простору):

```
∑ₖ₌₀ⁿ P(X = k) = ∑ₖ₌₀ⁿ C(n, k) · pᵏ · (1 - p)ⁿ⁻ᵏ = (p + (1 - p))ⁿ = 1ⁿ = 1
```

Математичне сподівання `E[X]` та дисперсія `Var(X)` біноміального розподілу також обчислюються безпосередньо за допомогою похідних біноміального розкладу:

```
E[X] = ∑ₖ₌₀ⁿ k · C(n, k) · pᵏ · (1 - p)ⁿ⁻ᵏ = n · p
Var(X) = n · p · (1 - p)
```

При великомасштабних випробуваннях (`n → ∞`) при фіксованій середній інтенсивності `λ = n·p` біноміальний розподіл у границі перетворюється на **розподіл Пуассона**, а при `n·p · (1 - p) ≫ 1` наближається до неперервного **нормального (гаусового) розподілу** за локальною граничною теоремою Муавра — Лапласа.

### 7. Числові алгоритми та практичне обчислення коефіцієнтів

У комп'ютерній алгебраїчній реалізації пряме обчислення біноміальних коефіцієнтів через формулу `n! / (k! · (n - k)!)` є неприпустимим через вибухове зростання факторіала. Вже число `21!` дорівнює `51 090 942 171 709 440 000`, що перевищує максимальне значення 64-бітного беззнакового цілого числа `UINT64_MAX` (`18.4 × 10¹⁸`).

Для обчислення `C(n, k)` у коді використовують три основні алгоритмічні підходи:

1. **Мультиплікативна формула без переповнення (O(k) часу, O(1) пам'яті):**
   `C(n, k) = ∏ᵢ₌₁ᵏ (n - k + i) / i`
   На кожному кроці добуток `(n - k + i)` ділиться на `i` без остачі, що дозволяє проводити обчислення повністю у 64-бітних цілих числах без використання довгої арифметики для `n ≤ 62`.

2. **Динамічне програмування за трикутником Паскаля (O(n·k) часу, O(k) пам'яті):**
   Будується одновимірний масив `dp[k]`, який послідовно оновлюється справа наліво: `dp[j] = dp[j] + dp[j - 1]`. Цей спосіб ідеальний для обчислення в кільцях лишків або при відсутності операції ділення.

3. **Модулярні комбінації за Малою теоремою Ферма (O(1) на запит після O(N) преобчислення):**
   У комбінаторних алгоритмах відповідь шукають за модулем великого простого числа `p`. Ділення на `k!` замінюється множенням на обернений елемент `(k!)ᵖ⁻² mod p`.

Готові реалізації цих алгоритмів мовами Python, C та C++ з використанням сучасних паттернів безпеки пам'яті та `constexpr` наведено у матеріалі: [алгоритми обчислення біноміальних коефіцієнтів](book:math/algebra/binomial-theorem/proj-binomial-coefficients.md).

### 8. Межі застосовності та підводні камені

Біноміальна теорема є надзвичайно гнучким інструментом, проте при її застосуванні слід пам'ятати про три основні обмеження:

#### Межа 1: Некомутативність елементів

Застосування формули `(a + b)ⁿ = ∑ C(n, k) · aⁿ⁻ᵏ · bᵏ` вимагає обов'язкової комутативності `a·b = b·a`. Якщо алгебраїчні об'єкти не комутують (матриці, оператори диференціювання, елементи некомутативних груп), біноміальна теорема у класичній формі не працює. Необхідно враховувати всі `2ⁿ` окремих послідовностей операторів або шукати спеціальні комутаторні тотожності (наприклад, формулу Бейкера — Кемпбелла — Хаусдорфа у фізиці квантових операторів).

#### Межа 2: Область збіжності нескінченного ряду Ньютона

При використанні узагальненої біноміальної теореми для нецілих степенів `α` степенний ряд `(1 + x)α = ∑ C(α, k) · xᵏ` збігається лише при `|x| < 1`. Якщо `|x| > 1`, ряд є розбіжним, і його підсумовування дає беззмістовні результати. На межі `|x| = 1` збіжність залежить від значення показника `α`:
- При `α > 0` ряд збігається абсолютно в точках `x = ±1`.
- При `-1 < α < 0` ряд збігається у точці `x = 1`, але розбігається у `x = -1`.
- При `α ≤ -1` ряд розбігається в обох точках `x = ±1`.

#### Межа 3: Обчислювальна стійкість та проміжне переповнення

При чисельному розкладі виразів з великими значеннями `n` біноміальні коефіцієнти в середині рядка `C(n, n/2)` досягають гігантських розмірів (за формулою Стірлінга `C(n, n/2) ≈ 2ⁿ / √(πn/2)`). Обчислення таких коефіцієнтів у плаваючій арифметиці (`double`) може призводити до втрати точності через віднімання близьких великих чисел при обчисленні знакопочережних сум. У таких випадках рекомендується переходити до логарифмів біноміальних коефіцієнтів `ln C(n, k) = ln Γ(n + 1) - ln Γ(k + 1) - ln Γ(n - k + 1)`.
