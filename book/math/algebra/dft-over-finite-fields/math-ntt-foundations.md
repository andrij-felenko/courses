# 🧮 Алгебраїчні засади числового перетворення Фур'є

Числове перетворення Фур'є (Number Theoretic Transform, або NTT) є строгим абстрактно-алгебраїчним узагальненням класичного дискретного перетворення Фур'є з поля комплексних чисел `ℂ` на довільні комутативні кільця та скінченні поля Галуа `GF(q)`. Цей математичний апарат спирається на циклічну будову мультиплікативних груп скінченних полів, властивості коренів із одиниці, ортогональність геометричних прогресій та ізоморфізм Китайської теореми про залишки.

---

### Мультиплікативна група скінченного поля та первісні корені

Нехай `GF(q)` — скінченне поле Галуа, що складається з `q = pᵐ` елементів, де `p` — просте характеристичне число, а `m ≥ 1` — степінь розширення (для простого поля `GF(p)` маємо `m = 1`). 

Множина всіх ненульових елементів поля разом з операцією множення утворює **мультиплікативну групу поля**, яка позначається як `GF(q)*`:

```
GF(q)* = GF(q) \ {0} = {x ∈ GF(q) | x ≠ 0}
```

Порядок цієї групи (кількість її елементів) дорівнює `|GF(q)*| = q - 1`. 

Фундаментальна теорема вищої алгебри стверджує: **мультиплікативна група будь-якого скінченного поля є строго циклічною**. Це означає, що у групі `GF(q)*` завжди існує хоча б один елемент-генератор `g` (який називають первісним елементом поля), степені якого послідовно породжують усі ненульові елементи поля:

```
GF(q)* = {g⁰, g¹, g², ..., g^(q-2)},   де g^(q-1) = 1
```

Кількість первісних елементів у полі `GF(q)` визначається функцією Ейлера `φ(q - 1)` від порядку мультиплікативної групи. Кожен такий генератор породжує всю групу без пропусків і повторень до досягнення степеня `q - 1`.

#### Алгоритмічний критерій перевірки первісного кореня
Щоб перевірити, чи є обраний ненульовий елемент `g` генератором усієї групи `GF(q)*`, не обов'язково обчислювати всі `q - 1` його степенів. Достатньо факторизувати число `q - 1` на прості дільники:

```
q - 1 = r₁^(e₁) · r₂^(e₂) · ... · r_s^(e_s)
```

де `r₁, r₂, ..., r_s` — попарно різні прості числа.

> **Критерій генератора.** Елемент `g ∈ GF(q)*` є первісним коренем поля тоді й тільки тоді, коли для кожного простого дільника `r_i` порядку групи виконується умова:
> ```
> g^((q - 1) / r_i) ≢ 1 (mod q),   для всіх i ∈ {1, 2, ..., s}
> ```

**Доведення коректності критерію:**
1. За малою теоремою Ферма (або теоремою Лагранжа для скінченних груп) для будь-якого ненульового елемента `g` завжди виконується `g^(q - 1) ≡ 1 (mod q)`.
2. Порядок елемента `d = ord(g)` зобов'язаний ділити порядок групи `q - 1`.
3. Якщо елемент `g` не є генератором всієї групи, то його порядок `d` є строгим власним дільником `q - 1` (`d < q - 1`).
4. Тоді число `(q - 1) / d` має хоча б один простий дільник `r_i`. Отже, `d` ділить число `(q - 1) / r_i`.
5. Це означає, що степінь `g^((q - 1) / r_i)` був би кратним порядку `d`, тобто `g^((q - 1) / r_i) = (g^d)^k = 1^k = 1`.
6. Таким чином, якщо жоден зі степенів `g^((q - 1) / r_i)` не дорівнює `1`, порядок елемента не може бути меншим за `q - 1`, отже `ord(g) = q - 1`. ∎

### Первісні корені з одиниці степеня n

Для побудови `n`-точкового дискретного перетворення Фур'є нам потрібен спеціальний алгебраїчний елемент — **первісний корінь з одиниці степеня `n`**.

> **Означення.** Елемент `ω` поля `GF(q)` називається **первісним коренем з одиниці степеня `n`** (позначається `ω_n`), якщо виконуються дві умови:
> 1. Його `n`-й степінь дорівнює одиниці: `ωⁿ = 1`.
> 2. Жоден менший додатний степінь не дорівнює одиниці: `ωᵏ ≠ 1` для всіх цілих `1 ≤ k < n`.
> 
> Інакше кажучи, порядок елемента `ω` у мультиплікативній групі `GF(q)*` строго дорівнює `n`: `ord(ω) = n`.

#### Теорема про умову існування кореня
Елемент порядку `n` існує в полі `GF(q)` тоді й тільки тоді, коли число `n` є дільником порядку мультиплікативної групи поля:

```
n | (q - 1)
```

**Доведення [за теоремою Лагранжа для скінченних груп]:**
1. Якщо такий елемент `ω` існує, то його степені `{1, ω, ω², ..., ωⁿ⁻¹}` утворюють підгрупу порядку `n` у групі `GF(q)*`. За теоремою Лагранжа порядок будь-якої підгрупи ділить порядок усієї групи, отже `n | (q - 1)`.
2. Навпаки, оскільки група `GF(q)*` є циклічною порядку `q - 1` із генератором `g`, то елемент, визначений як:
   ```
   ω_n = g^((q - 1) / n)
   ```
   має порядок `ord(ω_n) = (q - 1) / gcd(q - 1, (q - 1) / n) = n`. Отже, `ω_n` є шуканим первісним коренем степеня `n`. ∎

### Побудова коренів у полях розширення GF(pᵐ)

Якщо в базовому простому полі `GF(p)` потрібний розмір перетворення `n` не ділить число `p - 1`, ми не можемо знайти первісний корінь степеня `n` серед простих залишків. Проте ми завжди можемо перейти у **поле розширення Галуа `GF(pᵐ)`**, де такий корінь гарантовано існує.

#### Умова існування кореня в розширенні
У полі розширення `GF(pᵐ)` мультиплікативна група має порядок `pᵐ - 1`. Отже, первісний корінь степеня `n` існує тоді й тільки тоді, коли:

```
n | (pᵐ - 1)  ⟺  pᵐ ≡ 1 (mod n)
```

Мінімальний степінь розширення `m`, для якого виконується ця умова, називається **мультиплікативним порядком числа `p` за модулем `n`** і позначається як `m = ord_n(p)`.

#### Алгебраїчна побудова поля розширення:
1. Знаходимо незвідний (ірредуцибельний) многочлен `P(x)` степеня `m` над полем `GF(p)`.
2. Будуємо фактор-кільце:
   ```
   GF(pᵐ) = GF(p)[x] / (P(x))
   ```
3. Елементи поля `GF(pᵐ)` представляються як многочлени від формальної змінної `α` (де `P(α) = 0`) степеня, строго меншого за `m`:
   ```
   v = c₀ + c₁ α + c₂ α² + ... + c_(m-1) α^(m-1),   де c_i ∈ GF(p)
   ```
4. Додавання елементів виконується порозрядним додаванням коефіцієнтів у `GF(p)`.
5. Множення елементів виконується як звичайне множення поліномів із подальшим взяттям залишку від ділення на незвідний многочлен `P(α)`.

#### Автоморфізм Фробеніуса та спряжені корені
У скінченному полі `GF(pᵐ)` діє фундаментальний алгебраїчний автоморфізм — **відображення Фробеніуса**:

```
Φ : GF(pᵐ) → GF(pᵐ),    Φ(y) = yᵖ
```

Завдяки біному Ньютона в характеристиці `p` (де всі проміжні біноміальні коефіцієнти діляться на `p`), відображення Фробеніуса зберігає додавання та множення:
```
(y₁ + y₂)ᵖ = y₁ᵖ + y₂ᵖ,    (y₁ · y₂)ᵖ = y₁ᵖ · y₂ᵖ
```

Якщо `ω` є первісним коренем степеня `n` у полі `GF(pᵐ)`, то його фробеніусові образи `ωᵖ, ω^(p²), ω^(p³), ...` також є коренями степеня `n`. Множина степенів, пов'язаних множенням на `p` за модулем `n`:

```
C_s = {s, s·p mod n, s·p² mod n, ...}
```

називається **циклотомічним класом залишків за модулем `n`**. Добуток лінійних множників за елементами одного циклотомічного класу утворює незвідний многочлен із коефіцієнтами строго з базового поля `GF(p)`.

### Фундаментальні алгебраїчні леми про корені з одиниці

Для роботи алгоритму швидкого перетворення Кулі — Тьюкі необхідне виконання чотирьох базових лем редукції степенів:

#### 1. Лема про скорочення степеня (Cancellation Lemma)
Для будь-яких цілих чисел `n ≥ 1`, `k ≥ 0` та довільного множника `d ≥ 1`:
```
ω_(d·n)^(d·k) = ω_n^k
```
**Доведення:** 
```
ω_(d·n)^(d·k)
= (g^((q - 1) / (d·n)))^(d·k)    [за означенням первісного кореня через генератор g]
= g^(((q - 1) · d · k) / (d·n))  [властивість степеня числа]
= g^(((q - 1) · k) / n)          [скорочення множника d у чисельнику та знаменнику]
= (g^((q - 1) / n))^k            [винесення показника k]
= ω_n^k                          [за означенням кореня ω_n] ∎
```

#### 2. Лема про подвоєння (Halving Lemma)
Якщо `n > 0` — парне число, то квадрати `n` коренів степеня `n` утворюють множину `n/2` коренів степеня `n/2`:
```
(ω_n^k)² = ω_(n/2)^k
```
**Доведення:** Безпосередньо випливає з леми про скорочення при `d = 2`:
```
(ω_n^k)² = ω_n^(2k) = ω_(2·(n/2))^(2·k) = ω_(n/2)^k ∎
```

#### 3. Лема про протилежний елемент (Negation Lemma)
Якщо `n` — парне число і характеристика поля `char(GF(q)) ≠ 2`, то зсув степеня на половину періоду `n/2` відповідає множенню на `-1`:
```
ω_n^(k + n/2) = -ω_n^k
```
**Доведення:**
```
ω_n^(k + n/2)
= ω_n^k · ω_n^(n/2)              [властивість добутку степенів]
= ω_n^k · ω_(2·(n/2))^(n/2)      [запис n у вигляді 2 · (n/2)]
= ω_n^k · ω_2¹                   [за лемою про скорочення при d = n/2]
= ω_n^k · (-1)                   [єдиним ненульовим коренем ω_2 у полі є корінь x² - 1 = (x - 1)(x + 1) = 0, де x ≠ 1 ⟹ x = -1]
= -ω_n^k ∎
```

#### 4. Властивість оберненого елемента
Оберненим елементом до `ω_n^k` у полі є `ω_n^(n - k)`:
```
ω_n^k · ω_n^(n - k) = ω_n^n = 1  ⟹  (ω_n^k)⁻¹ = ω_n^(-k) = ω_n^(n - k)
```

### Теорема про суму та ортогональність коренів

Ортогональність є математичним «двигуном» будь-якого перетворення Фур'є. Вона дозволяє виділити окремі частотні компоненти під час прямого перетворення та точно компенсувати їх під час оберненого.

> **Теорема про ортогональність.** Нехай `ω_n` — первісний корінь з одиниці степеня `n` у полі `GF(q)`. Тоді для будь-якого цілого показника `k` сума степенів дорівнює:
> ```
> ∑_{j=0}^{n-1} (ω_n^k)ʲ = { n,  якщо k ≡ 0 (mod n)
>                          { 0,  якщо k ≢ 0 (mod n)
> ```

**Покрокове доведення:**

**Випадок 1: `k ≡ 0 (mod n)`.**
Якщо `k` ділиться на `n` без залишку, то `k = m · n` для деякого цілого `m`.
Тоді для кожного доданка `j`:
```
(ω_n^k)ʲ = (ω_n^(m·n))ʲ = ((ω_nⁿ)ᵐ)ʲ = (1ᵐ)ʲ = 1
```
Сума складається з `n` доданків, кожен із яких дорівнює `1`:
```
∑_{j=0}^{n-1} 1 = 1 + 1 + ... + 1 (n разів) = n · 1 = n ∈ GF(q)
```

**Випадок 2: `k ≢ 0 (mod n)`.**
Оскільки `k` не ділиться на `n`, а `ω_n` є первісним коренем порядку `n`, елемент `ω_n^k` не дорівнює одиниці поля:
```
ω_n^k ≠ 1  ⟹  (1 - ω_n^k) ≠ 0
```
Позначимо шукану суму як `S`:
```
S = ∑_{j=0}^{n-1} (ω_n^k)ʲ = 1 + ω_n^k + (ω_n^k)² + ... + (ω_n^k)ⁿ⁻¹
```
Помножимо всю суму `S` на елемент `ω_n^k`:
```
S · ω_n^k = ω_n^k + (ω_n^k)² + (ω_n^k)³ + ... + (ω_n^k)ⁿ
```
Віднімемо від першого виразу другий:
```
S - S · ω_n^k = 1 - (ω_n^k)ⁿ
```
Перетворимо обидві частини рівності:
```
S · (1 - ω_n^k)
= 1 - (ω_n^n)^k                  [перегрупування показників степеня]
= 1 - (1)^k                      [оскільки ω_n^n = 1 за означенням]
= 1 - 1                          [1 у будь-якому степені дорівнює 1]
= 0                              [віднімання в полі GF(q)]
```
Оскільки `(1 - ω_n^k) ≠ 0`, ми маємо право помножити обидві частини рівності на обернений елемент `(1 - ω_n^k)⁻¹`:
```
S = 0 · (1 - ω_n^k)⁻¹ = 0
```
Отже, при `k ≢ 0 (mod n)` сума строго дорівнює `0`. ∎

### Матричне формулювання та доведення оберненого перетворення

Пряме числове перетворення Фур'є вектора `a = (a₀, a₁, ..., aₙ₋₁)ᵀ` у спектральний вектор `A = (A₀, A₁, ..., Aₙ₋₁)ᵀ` можна записати як матрично-векторний добуток:

```
A = F_n · a
```

де `F_n` — симетрична матриця Вандермонда розміру `n × n`, складена зі степенів первісного кореня `ω_n`:

```
F_n = [ 1       1          1          ...   1               ]
      [ 1       ω          ω²         ...   ωⁿ⁻¹            ]
      [ 1       ω²         ω⁴         ...   ω²⁽ⁿ⁻¹⁾         ]
      [ ...     ...        ...        ...   ...             ]
      [ 1       ωⁿ⁻¹       ω²⁽ⁿ⁻¹⁾    ...   ω⁽ⁿ⁻¹⁾⁽ⁿ⁻¹⁾     ]
```

Елемент матриці на перетині рядка `k` та стовпця `j` (де індексація починається з нуля) дорівнює:
```
(F_n)_{k, j} = ω_n^(k · j)
```

Обернена матриця `F_n⁻¹` визначається формулою:
```
(F_n⁻¹)_{j, k} = (1/n) · ω_n^(-j · k)
```

#### Доведення оборотності матриці перетворення
Доведемо, що добуток `F_n⁻¹ · F_n` дорівнює одиничній матриці `I_n`:

Обчислимо елемент добутку матриць на позиції `(r, c)` (рядок `r`, стовпець `c`):
```
(F_n⁻¹ · F_n)_{r, c}
= ∑_{k=0}^{n-1} (F_n⁻¹)_{r, k} · (F_n)_{k, c}   [за правилом множення матриць]
= ∑_{k=0}^{n-1} ((1/n) · ω_n^(-r · k)) · (ω_n^(k · c))  [підстановка елементів матриць]
= (1/n) · ∑_{k=0}^{n-1} ω_n^(k · (c - r))       [винесення скаляра 1/n та додавання степенів]
```
Застосуємо теорему про ортогональність до показника `k' = (c - r)`:
1. Якщо `r = c` (діагональний елемент), то `c - r = 0 ≡ 0 (mod n)`:
   ```
   (F_n⁻¹ · F_n)_{r, r} = (1/n) · n = 1
   ```
2. Якщо `r ≠ c` (позадіагональний елемент), оскільки `0 ≤ r, c < n`, різниця `-(n - 1) ≤ c - r ≤ n - 1` є ненульовою, тобто `c - r ≢ 0 (mod n)`:
   ```
   (F_n⁻¹ · F_n)_{r, c} = (1/n) · 0 = 0
   ```
Таким чином:
```
F_n⁻¹ · F_n = I_n
```
Матриця `F_n` є строго невиродженою, а формула відновлення вихідного вектора:
```
a_j = (1/n) · ∑_{k=0}^{n-1} A_k · ω_n^(-j · k)
```
є математично точною тотожністю без будь-яких припущень чи наближень. ∎

### Алгебраїчний розклад алгоритму Кулі — Тьюкі: DIT та DIF

Швидкість перетворення Фур'є досягається завдяки факторизації матриці `F_n` у добуток `log₂ n` розріджених блочно-діагональних матриць. Існує два дуальні підходи до такого розкладу:

#### 1. Проріджування за часом (Decimation-in-Time, DIT)
Розглянемо суму перетворення для полінома `a(x) = ∑_{j=0}^{n-1} a_j xʲ` у точках `x = ω_n^k`.
Розділимо суму на парні та непарні індекси коефіцієнтів:
```
A_k
= ∑_{j=0}^{n-1} a_j · ω_n^(k · j)                                                                           [означення прямого NTT]
= ∑_{m=0}^{n/2 - 1} a_(2m) · ω_n^(k · 2m)  +  ∑_{m=0}^{n/2 - 1} a_(2m+1) · ω_n^(k · (2m+1))               [розбиття індексів j на парні 2m та непарні 2m+1]
= ∑_{m=0}^{n/2 - 1} a_(2m) · (ω_n^2)^(k · m)  +  ω_n^k · ∑_{m=0}^{n/2 - 1} a_(2m+1) · (ω_n^2)^(k · m)     [винесення спільного множника ω_n^k та перегрупування степенів]
```
За лемою про подвоєння `ω_n^2 = ω_(n/2)`. Позначимо два перетворення половинного розміру `n/2`:
- `E_k = ∑_{m=0}^{n/2 - 1} a_(2m) · ω_(n/2)^(k · m)` (перетворення парних коефіцієнтів);
- `O_k = ∑_{m=0}^{n/2 - 1} a_(2m+1) · ω_(n/2)^(k · m)` (перетворення непарних коефіцієнтів).

Отримуємо базове рівняння DIT:
```
A_k = E_k + ω_n^k · O_k
```
Для другої половини спектральних коефіцієнтів (індекси `k + n/2`):
```
A_(k + n/2)
= E_(k + n/2) + ω_n^(k + n/2) · O_(k + n/2)   [підстановка індексу k + n/2]
= E_k - ω_n^k · O_k                           [оскільки E_k та O_k періодичні з періодом n/2, а ω_n^(k + n/2) = -ω_n^k]
```
Пара формул:
```
A_k         = E_k + ω_n^k · O_k
A_(k + n/2) = E_k - ω_n^k · O_k
```
утворює класичний **метелик DIT**. На кожному кроці пара значень обчислюється за 1 множення на поворотний коефіцієнт `ω_n^k`, 1 додавання та 1 віднімання у полі `GF(q)`.

#### 2. Проріджування за частотою (Decimation-in-Frequency, DIF / алгоритм Джентльмена — Сенде)
У підході DIF розбиття виконується не за парністю індексів, а за першою та другою половиною вхідного вектора:
```
A_k = ∑_{j=0}^{n/2 - 1} a_j · ω_n^(k · j)  +  ∑_{j=0}^{n/2 - 1} a_(j + n/2) · ω_n^(k · (j + n/2))   [розбиття суми на першу та другу половини масиву]
    = ∑_{j=0}^{n/2 - 1} (a_j + a_(j + n/2) · ω_n^(k · n/2)) · ω_n^(k · j)                            [винесення спільного степеня ω_n^(k · j)]
```
Розглянемо парні індекси спектра `k = 2m`:
```
A_(2m)
= ∑_{j=0}^{n/2 - 1} (a_j + a_(j + n/2) · (ω_n^(n/2))^(2m)) · ω_n^(2m · j)    [підстановка парного індексу k = 2m]
= ∑_{j=0}^{n/2 - 1} (a_j + a_(j + n/2) · (-1)^(2m)) · ω_(n/2)^(m · j)        [застосування леми про протилежний елемент ω_n^(n/2) = -1]
= ∑_{j=0}^{n/2 - 1} (a_j + a_(j + n/2)) · ω_(n/2)^(m · j)                    [оскільки (-1)^(2m) = 1 та за лемою про скорочення ω_n^(2m·j) = ω_(n/2)^(m·j)]
```
Це `(n/2)`-точкове NTT від поелементної суми половин `u_j = a_j + a_(j + n/2)`.

Розглянемо непарні індекси спектра `k = 2m + 1`:
```
A_(2m + 1)
= ∑_{j=0}^{n/2 - 1} (a_j + a_(j + n/2) · (ω_n^(n/2))^(2m+1)) · ω_n^((2m+1) · j)   [підстановка непарного індексу k = 2m + 1]
= ∑_{j=0}^{n/2 - 1} (a_j + a_(j + n/2) · (-1)) · ω_n^j · ω_(n/2)^(m · j)           [оскільки (-1)^(2m+1) = -1 та винесення ω_n^j]
= ∑_{j=0}^{n/2 - 1} ((a_j - a_(j + n/2)) · ω_n^j) · ω_(n/2)^(m · j)                [перегрупування доданків під знаком суми]
```
Це `(n/2)`-точкове NTT від зваженої різниці половин `v_j = (a_j - a_(j + n/2)) · ω_n^j`.

Метелик DIF спочатку виконує додавання й віднімання, а потім множить різницю на поворотний коефіцієнт.

### Ізоморфізм Китайської теореми про залишки (CRT)

Глибока алгебраїчна природа NTT стає очевидною, якщо поглянути на перетворення через призму фактор-кілець поліномів.

Розглянемо поліноміальне кільце `R = GF(q)[x] / (xⁿ - 1)`.
Многочлен `xⁿ - 1` над полем `GF(q)`, у якому існує первісний корінь `ω_n`, повністю розкладається на `n` лінійних множників:

```
xⁿ - 1 = ∏_{k=0}^{n-1} (x - ω_n^k)
```

Оскільки всі корені `ω_n^k` попарно різні, лінійні многочлени `(x - ω_n^k)` є попарно взаємно простими в кільці `GF(q)[x]`.

За **Китайською теоремою про залишки для кілець многочленів (Polynomial CRT)** існує канонічний кільцевий ізоморфізм:

```
GF(q)[x] / (xⁿ - 1)  ≅  ∏_{k=0}^{n-1} (GF(q)[x] / (x - ω_n^k))  ≅  (GF(q))ⁿ
```

Цей ізоморфізм зіставляє кожному многочлену `a(x)` вектор його залишків за модулями `(x - ω_n^k)`. 
За теоремою Безу залишок від ділення полінома `a(x)` на лінійний двочлен `(x - α)` є просто значенням полінома в точці `α`:

```
a(x) mod (x - ω_n^k) = a(ω_n^k) = A_k
```

Отже, **числове перетворення Фур'є — це точний ізоморфізм між кільцем поліномів за модулем `(xⁿ - 1)` та прямим добутком `n` числових полів `GF(q)`**. 

Множення двох поліномів у кільці `GF(q)[x] / (xⁿ - 1)` відповідає поелементному множенню векторів у прямому добутку `(GF(q))ⁿ`. Це пояснює, чому теорема про згортку працює бездоганно: це прямий наслідок фундаментального кільцевого ізоморфізму.

### Багатовимірні числові перетворення та відображення Гуда — Томаса

Коли розмір перетворення `n` є добутком двох взаємно простих множників `n = n₁ · n₂` (де `gcd(n₁, n₂) = 1`), алгоритм можна факторизувати без використання додаткових проміжних поворотних коефіцієнтів (Twiddle factors).

Це робиться за допомогою **відображення Гуда — Томаса (Good-Thomas Prime Factor Algorithm, PFA)**, яке спирається на класичну цілочисельну Китайську теорему про залишки:

1. **Ізоморфізм індексів:** Кожен одновимірний індекс `j ∈ {0, 1, ..., n-1}` однозначно зіставляється з парою двовимірних індексів `(j₁, j₂)`:
   ```
   j₁ = j mod n₁,    j₂ = j mod n₂
   ```
2. **Відновлення індексу частоти:** Для вихідного частотного індексу `k` використовується зважене представлення Безу:
   ```
   k = (k₁ · n₂ · (n₂⁻¹ mod n₁) + k₂ · n₁ · (n₁⁻¹ mod n₂)) mod n
   ```
3. Тоді добуток індексів у показнику степеня розкладається на чисту суму без перехресних членів:
   ```
   ω_n^(j · k) = ω_(n₁)^(j₁ · k₁) · ω_(n₂)^(j₂ · k₂)
   ```

Це перетворює одновимірне перетворення довжини `n` на чисте двовимірне перетворення розміру `n₁ × n₂`. Обчислюються спочатку `n₂` незалежних одновимірних NTT довжини `n₁` над рядками матриці, а потім `n₁` незалежних одновимірних NTT довжини `n₂` над її стовпцями. Між проходами не потрібно множити на жоден поворотний коефіцієнт, що зменшує загальну кількість множень у полі.

### Теорема про дискретну згортку над скінченними полями

Головним практичним призначенням перетворення Фур'є є швидке обчислення згортки послідовностей.

Нехай задано два вектори `a = (a₀, ..., aₙ₋₁)` та `b = (b₀, ..., bₙ₋₁)`. Їхня **циклічна згортка** `c = a ⊛ b` визначається як вектор довжини `n`, компоненти якого обчислюються за правилом:

```
c_m = ∑_{j=0}^{n-1} a_j · b_((m - j) mod n)
```

> **Теорема про згортку.** Образ NTT циклічної згортки двох векторів дорівнює поточковому (адамаровому) добутку їхніх індивідуальних образів NTT:
> ```
> NTT(a ⊛ b) = NTT(a) ⊙ NTT(b)
> ```
> де `(NTT(a) ⊙ NTT(b))_k = A_k · B_k`.

**Строге доведення:**

Обчислимо `k`-й компонент образу NTT вектора згортки `c`:
```
C_k
= ∑_{m=0}^{n-1} c_m · ω_n^(k · m)                      [означення прямого NTT]
= ∑_{m=0}^{n-1} (∑_{j=0}^{n-1} a_j · b_((m-j) mod n)) · ω_n^(k · m)  [підстановка формули згортки]
= ∑_{j=0}^{n-1} a_j · (∑_{m=0}^{n-1} b_((m-j) mod n) · ω_n^(k · m))  [перестановка порядку сумування]
```
Виконаємо заміну індексу підсумовування у внутрішній дужці: нехай `l = (m - j) mod n`. 
Коли `m` пробігає всі значення від `0` до `n - 1`, індекс `l` також пробігає повну систему лишків від `0` до `n - 1`. 
При цьому `m ≡ j + l (mod n)`, отже `ω_n^(k · m) = ω_n^(k · (j + l)) = ω_n^(k · j) · ω_n^(k · l)`.

Підставимо заміну індексу у вираз:
```
C_k
= ∑_{j=0}^{n-1} a_j · (∑_{l=0}^{n-1} b_l · ω_n^(k · (j + l)))   [заміна індексу m на l]
= ∑_{j=0}^{n-1} a_j · ω_n^(k · j) · (∑_{l=0}^{n-1} b_l · ω_n^(k · l))  [винесення множника ω_n^(k·j)]
= (∑_{j=0}^{n-1} a_j · ω_n^(k · j)) · (∑_{l=0}^{n-1} b_l · ω_n^(k · l))  [факторизація подвійної суми]
= A_k · B_k                                            [за означеннями A_k = NTT(a)_k та B_k = NTT(b)_k]
```
Рівність доведено: `NTT(a ⊛ b)_k = A_k · B_k`. ∎

### Негациклічне перетворення (Twisted NTT) у поліноміальних кільцях

У постквантовій криптографії (схеми Kyber та Dilithium) та гомоморфному шифруванні множення виконується не за модулем `xⁿ - 1` (яке дає циклічну згортку), а в кільці:

```
R_q = GF(q)[x] / (xⁿ + 1)
```

де редукція многочлена здійснюється за правилом `xⁿ ≡ -1`. Це породжує **негациклічну згортку**:
```
c_m = ∑_{j=0}^{m} a_j · b_(m - j)  -  ∑_{j=m+1}^{n-1} a_j · b_(n + m - j)
```

Щоб обчислювати негациклічну згортку за `O(n log n)` без подвоєння довжини вектора нулями, використовується **зважене перетворення Фур'є (Twisted NTT)**.

#### Алгебраїчний механізм Twisted NTT:
Нехай у полі `GF(q)` існує корінь `ψ` степеня `2n`, такий що:
```
ψ² = ω_n  ⟹  ψⁿ = -1
```
Розглянемо заміну змінної `x = ψ · y`. Тоді:
```
xⁿ + 1 = (ψ · y)ⁿ + 1 = ψⁿ · yⁿ + 1 = (-1) · yⁿ + 1 = -(yⁿ - 1)
```
Це перетворює негациклічний модуль `xⁿ + 1` на звичайний циклічний модуль `yⁿ - 1`!

**Алгоритм негациклічного множення:**
1. **Зважування коефіцієнтів:** Масиви `a` та `b` множаться на степені `ψ`:
   ```
   a'_j = a_j · ψʲ mod q,    b'_j = b_j · ψʲ mod q
   ```
2. **Звичайне пряме NTT:**
   ```
   A' = NTT(a'),    B' = NTT(b')
   ```
3. **Поточкове множення:**
   ```
   C'_k = A'_k · B'_k mod q
   ```
4. **Звичайне обернене INTT:**
   ```
   c' = INTT(C')
   ```
5. **Зняття зважування (Unweighting):**
   ```
   c_j = c'_j · ψ⁻ʲ mod q
   ```

Отриманий вектор `c` є точним добутком `a(x) · b(x) mod (xⁿ + 1)` у кільці `R_q`. Завдяки Twisted NTT операція множення поліномів у ґратковій криптографії виконується за один каскад `n`-точкового перетворення замість подвоєного `2n`.
