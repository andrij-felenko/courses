# Напіврешітка

<preknowlist>

- [Решітка дільників](book:math/divisor-lattice) — приклад порядкової структури на числах за відношенням подільності.
- [Конфліктно-вільні репліковані типи даних](book:algorithms/crdt) — розподілені структури без централізованого блокування.
</preknowlist>

Уявімо розподілену систему з десятків незалежних вузлів, які обслуговують записи користувачів без центрального координатора. Кожен вузол локально змінює свій стан, після чого надсилає оновлення сусідам через ненадійну мережу. Пакети затримуються, приходять у довільному порядку, дублюються через повторні спроби передачі або прибувають пачками різного розміру. Якщо об'єднання двох станів залежить від черговості прибуття повідомлень, система потоне в розбіжностях: один вузол застосує правки в порядку `A`, потім `B`, інший — у порядку `B`, потім `A`, і їхні бази даних назавжди розійдуться.

Щоб гарантувати детерміновану збіжність до однакового результату без блокувань і двофазних комітів, операція злиття станів `merge(x, y)` повинна мати три залізобетонні властивості:

1. **Комутативність:** `merge(x, y) = merge(y, x)` — результат не залежить від того, який пакет прилетів першим.
2. **Асоціативність:** `merge(merge(x, y), z) = merge(x, merge(y, z))` — результат не залежить від того, як повідомлення згруповані у мережеві батчі.
3. **Ідемпотентність:** `merge(x, x) = x` — повторне отримання вже застосованого пакета не спотворює збережених даних.

Ця трійка алгебраїчних законів визначає структуру, яку в математиці називають **напіврешіткою** (англ. *semilattice*, від лат. *semi-* — напів та *latis* — ґратка, каркас). Одночасно напіврешітка є фундаментом теорії порядку: кожна така операція нерозривно пов'язана з частковим порядком, у якому для будь-якої пари елементів гарантовано існує єдина найближча спільна грань.

### 1. Алгебраїчне означення: напівгрупа самопоглинання

В ієрархії абстрактної алгебри напіврешітка займає особливе місце між напівгрупами та повними решітками. На відміну від груп чи полів, де кожна операція обов'язково є оборотною (для кожного елемента існує симетричний протилежний або обернений елемент), напіврешітка моделює незворотні операції накопичення інформації, злиття або відсікання значень.

Формально **алгебраїчною напіврешіткою** називається пара `(S, ⋆)`, де `S` — непорожня множина, а `⋆ : S × S → S` — бінарна операція, яка для будь-яких елементів `a, b, c ∈ S` задовольняє три обов'язкові аксіоми:

```
(a ⋆ b) ⋆ c = a ⋆ (b ⋆ c)      [асоціативність: довільне розставлення дужок]
a ⋆ b = b ⋆ a                  [комутативність: незалежність від порядку операндів]
a ⋆ a = a                      [ідемпотентність: результат множення елемента на самого себе є ним самим]
```

З погляду загальної алгебри напіврешітка — це **комутативна ідемпотентна напівгрупа**. 

Ідемпотентність (лат. *idem* — той самий + *potens* — здатний, могутній) є визначальним бар'єром, що відрізняє напіврешітки від класичних адитивних чи мультиплікативних систем. У групі цілих чисел `(ℤ, +)` операція додавання є комутативною та асоціативною, але не є ідемпотентною, оскільки `a + a = 2·a ≠ a` (для всіх `a ≠ 0`). Якщо спробувати додати до напіврешітки операцію взяття оберненого елемента `-a`, структура негайно вироджується в одноелементну:

```
a
= a ⋆ a                        [за аксіомою ідемпотентності]
= (a ⋆ a) ⋆ (-a)               [якщо існує обернений елемент -a]
= a ⋆ (a ⋆ (-a))               [за асоціативністю]
= a ⋆ e                        [де e — нейтральний елемент]
= e                            [єдиний можливий елемент — це нейтральний]
```

Саме тому напіврешітки принципово не містять нетривіальних обернених елементів. Натомість операції взяття максимуму `max(a, a) = a`, взяття мінімуму `min(a, a) = a`, об'єднання множин `A ∪ A = A`, перетину множин `A ∩ A = A`, взяття логічного «І» (`∧`), логічного «АБО» (`∨`) та найбільшого спільного дільника `НСД(a, a) = a` задовольняють ідемпотентність і перетворюють відповідні множини на напіврешітки.

```
max(3, 5) = 5
max(5, 3) = 5                  [комутативність: порядок не має значення]
max(max(2, 5), 7) = 7
max(2, max(5, 7)) = 7          [асоціативність: групування не має значення]
max(5, 5) = 5                  [ідемпотентність: повтори зникають]
```

#### Довільні скінченні згортки та незалежність від мультимножин

Безпосереднім наслідком комутативності, асоціативності та ідемпотентності є те, що результат обчислення операції `⋆` над будь-яким скінченним набором елементів `x₁, x₂, ..., xₙ` залежить виключно від **множини** унікальних значень, а не від порядку їхнього запису чи кількості дублікатів:

```
⋆(x₁, x₂, ..., xₙ) = ⋆(y ∈ {x₁, x₂, ..., xₙ})
```

Якщо обчислювати бінарний згорток над масивом із мільйона чисел, де є лише три унікальні значення `{2, 5, 8}`, результат операції `⋆` буде строго тотожним результату `2 ⋆ 5 ⋆ 8`. Ця властивість усуває потребу зберігати історію повторних операцій: для напіврешітки будь-яка мультимножина природно збігається зі своєю базовою множиною.

#### Обмежені напіврешітки та моноїди

Якщо в множині `S` існує елемент `e ∈ S`, який є нейтральним відносно операції `⋆`, тобто для кожного `a ∈ S` виконується:

```
a ⋆ e = a
```

тоді структура `(S, ⋆, e)` називається **обмеженою напіврешіткою** (англ. *bounded semilattice*), або **комутативним ідемпотентним моноїдом**. 

Залежно від змісту операції нейтральний елемент має різне геометричне значення:
- Якщо операція обчислює об'єднання або супремум (join), нейтральним елементом є **найменший елемент** (позначається `⊥`, читається «bottom» або «дно»), для якого `a ⋆ ⊥ = a`. Для числових максимумів на `ℕ` це число `0`, для множин — порожня множина `∅`.
- Якщо операція обчислює перетин або інфімум (meet), нейтральним елементом є **найбільший елемент** (позначається `⊤`, читається «top» або «вершина»), для якого `a ⋆ ⊤ = a`. Для булевої логіки це константа `True` (істина), для дільників фіксованого числа `N` — саме число `N`.

#### Тропічні напівкільця та алгебра оптимізації

Окремим визначним випадком застосування напіврешіток є **тропічна алгебра** (названа на честь бразильського математика угорського походження Імре Сімона). У тропічному напівкільці `(ℝ ∪ {+∞}, min, +)` операція «додавання» насправді є взяттям мінімуму `min(a, b)`, а «множення» — звичайним арифметичним додаванням `a + b`.

Оскільки тропічне додавання є ідемпотентним (`min(a, a) = a`), адитивна складова тропічного напівкільця утворює чисту meet-напіврешітку з нейтральним елементом `+∞`. Це дозволяє перетворювати задачі пошуку найкоротших шляхів у графах (алгоритм Флойда — Воршелла), динамічного програмування та аналізу мереж на розв'язання лінійних матричних рівнянь над напіврешітками.

Про те, [як розвивалася теорія решіток від логічних праць Чарльза Пірса та Ріхарда Дедекінда до сучасних розподілених сховищ](book:math/semilattice/hist-semilattice-origins.md), детально розповідає історичний нарис.

### 2. Порядкове означення: еквівалентність частково впорядкованій множині

Алгебраїчні операції над напіврешітками не є випадковими формальними правилами: вони є точним відображенням просторових ієрархій. Будь-яку напіврешітку можна розглядати не як набір рівнянь, а як геометричний об'єкт — частково впорядковану множину (посет, англ. *partially ordered set*, poset).

Нагадаємо, що бінарне відношення `≤` на множині `S` називається **частковим порядком**, якщо для всіх елементів `a, b, c ∈ S` виконуються три класичні аксіоми:

```
a ≤ a                          [рефлексивність: кожен елемент порівнянний із собою]
a ≤ b і b ≤ a  ⇒  a = b       [антисиметричність: взаємне слідування означає тотожність]
a ≤ b і b ≤ c  ⇒  a ≤ c       [транзитивність: порядок передається ланцюжком]
```

На відміну від лінійного порядку (як на числовій прямій ℝ), у частковому порядку деякі пари елементів можуть бути **непорівнянними**: ані `a ≤ b`, ані `b ≤ a` не виконується (наприклад, множини `{1, 2}` та `{2, 3}` не містяться одна в одній).

```
          Порядкова структура напіврешітки
          
      Верхня (Join, ⊔)             Нижня (Meet, ⊓)
     Точна верхня грань           Точна нижня грань
     
           a ⊔ b                        a
          /     \                      / \
         /       \                    /   \
        a         b              a ⊓ b     b
        
     sup{a, b} = a ⊔ b            inf{a, b} = a ⊓ b
    найменший спільний           найбільший спільний
         нащадок                       предок
```

#### Нижня напіврешітка (Meet-Semilattice)

Частково впорядкована множина `(S, ≤)` називається **нижньою напіврешіткою** (англ. *meet-semilattice*, від англ. *meet* — зустріч, перетин), якщо для будь-яких двох елементів `a, b ∈ S` існує їхня **найбільша нижня грань** (інфімум, infimum / greatest lower bound, позначається `inf{a, b}` або `a ∧ b`, `a ⊓ b`).

Інфімум `m = a ⊓ b` однозначно визначається двома умовами:
1. `m` лежить нижче обох елементів: `m ≤ a` та `m ≤ b`.
2. `m` є найбільшим серед усіх таких спільних нижніх елементів: якщо існує `c ∈ S` такий, що `c ≤ a` і `c ≤ b`, то обов'язково `c ≤ m`.

Зв'язок між порядком і алгебраїчною операцією інфімуму задається формулою:

```
a ≤ b  ⇔  a ⊓ b = a
```

Якщо перетин двох множин `A ∩ B` дорівнює `A`, це означає, що множина `A` повністю міститься всередині `B` (`A ⊆ B`).

#### Верхня напіврешітка (Join-Semilattice)

Частково впорядкована множина `(S, ≤)` називається **верхньою напіврешіткою** (англ. *join-semilattice*, від англ. *join* — об'єднання, з'єднання), якщо для будь-якої пари `a, b ∈ S` існує їхня **найменша верхня грань** (супремум, supremum / least upper bound, позначається `sup{a, b}` або `a ∨ b`, `a ⊔ b`).

Супремум `s = a ⊔ b` визначається двома дзеркальними умовами:
1. `s` лежить вище обох елементів: `a ≤ s` та `b ≤ s`.
2. `s` є найменшим серед усіх спільних верхніх елементів: якщо існує `c ∈ S` такий, що `a ≤ c` і `b ≤ c`, то обов'язково `s ≤ c`.

Зв'язок між порядком і операцією об'єднання виражається так:

```
a ≤ b  ⇔  a ⊔ b = b
```

Якщо об'єднання двох множин `A ∪ B` дорівнює `B`, це свідчить, що `B` уже містить у собі весь вміст `A`.

#### Теорема про фундаментальний ізоморфізм

Алгебраїчне та порядкове означення є взаємно еквівалентними:

1. Нехай `(S, ⋆)` — алгебраїчна напіврешітка. Тоді бінарне відношення `a ≤ b ⇔ a ⋆ b = a` є частковим порядком на `S`, причому `a ⋆ b = inf{a, b}`.
2. Нехай `(S, ≤)` — порядкова нижня напіврешітка. Тоді операція `a ∧ b = inf{a, b}` задовольняє аксіоми асоціативності, комутативності та ідемпотентності.
3. Ці дві конструкції є взаємно оберненими: перехід від алгебри до порядку, а потім від отриманого порядку назад до операції повертає початкову структуру без змін.

Строгий покроковий виклад усіх лем та [повне математичне доведення рефлексивності, антисиметричності й транзитивності породженого порядку](book:math/semilattice/math-semilattice-poset-equivalence.md) винесено в окрему математичну вставку.

### 3. Діаграми Хассе: візуалізація порядкових структур

Найпростішим способом дослідження скінченних напіврешіток є їхнє графічне зображення за допомогою **діаграм Хассе** (нім. *Hasse-Diagramm*, названих на честь німецького математика Гельмута Хассе).

Діаграма Хассе будується на основі **відношення безпосереднього покриття** (англ. *covering relation*). Елемент `b` покриває елемент `a` (позначають `a ⋖ b`), якщо:
1. `a < b` (тобто `a ≤ b` і `a ≠ b`).
2. Не існує такого проміжного елемента `x ∈ S`, щоб `a < x < b`.

У діаграмі Хассе кожен елемент зображується точкою на площині. Якщо `a ⋖ b`, точка `b` розміщується строго вище за точку `a`, і між ними проводиться відрізок. Транзитивні ребра (наприклад, між `a` та `c`, якщо `a ⋖ b ⋖ c`) не малюються.

```
          Діаграма Хассе для булеана множини {x, y, z}
          
                       {x, y, z}  (⊤)
                      /    |    \
                     /     |     \
             {x, y}     {x, z}    {y, z}
              /   \     /    \    /   \
             /     \   /      \  /     \
           {x}      {y}        {z}
             \       |        /
              \      |       /
                     ∅  (⊥)
```

За діаграмою Хассе легко перевірити структуру напіврешітки:

1. **Пошук Meet (⊓):** Рухаємося від точок `a` та `b` вниз усіма можливими шляхами. Знаходимо всі точки, які лежать нижче або на рівні обох елементів (спільні предки). Якщо серед них є одна точка, яка лежить вище за всі інші спільні предки, вона і є `a ⊓ b`.
2. **Пошук Join (⊔):** Рухаємося від `a` та `b` вгору. Якщо серед усіх спільних верхніх точок є єдина найнижча, вона є `a ⊔ b`.

#### Порівняння: напіврешітка, решітка та непорівнянний посет

Не кожна частково впорядкована множина є напіврешіткою:

1. **Join-напіврешітка:** Будь-яка пара елементів має єдиний супремум, але деякі пари не мають інфімуму (наприклад, дерево, що розгалужується догори, або ліс без спільного кореня).
2. **Meet-напіврешітка:** Будь-яка пара має єдиний інфімум, але деякі пари не мають спільного супремуму (наприклад, дерево папок файлової системи, де корінь `/` є спільним предком `⊥`, а спільний предок двох файлів — це їхній найближчий спільний каталог, але об'єднати два незалежні файли у спільну гілку неможливо).
3. **Повна решітка (Lattice):** Структура є одночасно і join-, і meet-напіврешіткою. Будь-яка пара `{a, b}` має і точну нижню грань `a ⊓ b`, і точну верхню грань `a ⊔ b`. Прикладом є решітка дільників числа або булеан множини.
4. **Посет, що НЕ є напіврешіткою:** Якщо для пари елементів `{x, y}` існують дві різні мінімальні верхні межі `m₁` та `m₂`, між якими немає відношення порядку (жодна з них не менша за іншу), то операція `x ⊔ y` не визначена, оскільки вибір між ними неоднозначний.

![Діаграми Хассе для різних порядкових структур](/book/math/algebra/semilattice/img/hasse-diagrams-semilattices.svg)
*Різновиди частково впорядкованих множин: напіврешітки відрізняються від довільних посетів строгою гарантією єдиності найближчої грані для будь-якої пари вузлів.*

### 4. Алгебраїчна анатомія: фільтри, ідеали, конгруенції та вільні напіврешітки

Глибше розуміння внутрішньої структури напіврешіток дає апарат теорії ідеалів, конгруенцій та універсальних властивостей.

#### Ідеали та головні ідеали

Нехай `(S, ⊔)` — join-напіврешітка. Підмножина `I ⊆ S` називається **ідеалом**, якщо:
1. `I` є непорожньою множиною, спрямованою вниз: якщо `x ∈ I` і `y ≤ x`, то `y ∈ I` (ідеал містить усі менші елементи).
2. `I` замкнена відносно операції злиття: якщо `x, y ∈ I`, то `x ⊔ y ∈ I`.

Якщо ідеал породжений одним елементом `a ∈ S`, тобто `I = {x ∈ S : x ≤ a}`, він називається **головним ідеалом** і позначається `↓a`.

#### Фільтри та головні фільтри

Дуальним до ідеалу є поняття **фільтра**. Для meet-напіврешітки `(S, ⊓)` підмножина `F ⊆ S` називається фільтром, якщо:
1. `F` спрямована вгору: якщо `x ∈ F` і `x ≤ y`, то `y ∈ F`.
2. `F` замкнена відносно інфімуму: якщо `x, y ∈ F`, то `x ⊓ y ∈ F`.

Головний фільтр, породжений елементом `a`, позначається `↑a = {x ∈ S : a ≤ x}`. Фільтри формалізують поняття «множини станів, що містять принаймні заданий рівень знань».

#### Конгруенції та фактор-напіврешітки

Бінарне відношення еквівалентності `θ ⊆ S × S` називається **конгруенцією напіврешітки** `(S, ⋆)`, якщо воно узгоджується з бінарною операцією: для будь-яких `a, b, c ∈ S` з умови `a ≡ b (mod θ)` випливає:

```
(a ⋆ c) ≡ (b ⋆ c) (mod θ)
```

Фактор-множина класів еквівалентності `S / θ` разом із факторизованою операцією `[a]_θ ⋆ [b]_θ = [a ⋆ b]_θ` сама утворює коректну напіврешітку.

За класичною **теоремою про гомоморфізми**: для будь-якого гомоморфізму напіврешіток `f : S → T` його ядро `ker(f) = {(x, y) ∈ S × S : f(x) = f(y)}` є конгруенцією на `S`, а образ гомоморфізму `Im(f)` канонічно ізоморфний фактор-напіврешітці:

```
S / ker(f) ≅ Im(f)
```

#### Теорема представлення Біркгофа для напіврешіток

Фундаментальна теорема стверджує: **будь-яка напіврешітка ізоморфна піднапіврешітці деякого булеана множин**.
- Будь-яка meet-напіврешітка `(S, ⊓)` вкладається в булеан `(P(S), ∩)` через відображення `a ↦ ↑a`. Перетин двох головних фільтрів є головним фільтром їхнього інфімуму:
  ```
  ↑(a ⊓ b) = ↑a ∩ ↑b
  ```
- Будь-яка join-напіврешітка `(S, ⊔)` вкладається в булеан `(P(S), ∪)` через відображення `a ↦ ↓a`, де об'єднання ідеалів визначає супремум.

#### Вільні напіврешітки

Якщо ми маємо довільну базову множину генераторів (символів) `X`, **вільна напіврешітка** над `X` (позначається `Free(X)`) — це структура, яка містить усі можливі скінченні комбінації елементів `X` без жодних додаткових обмежень, окрім асоціативності, комутативності та ідемпотентності.

Теорема універсальної алгебри стверджує, що вільна join-напіврешітка `Free(X)` ізоморфна системі всіх непорожніх скінченних підмножин `P_fin(X)` з операцією теоретико-множинного об'єднання `∪`:

```
Free(X) ≅ (P_fin(X), ∪)
```

Універсальна властивість вільної напіврешітки полягає в тому, що будь-яке відображення множини генераторів `g : X → S` у довільну напіврешітку `(S, ⊔)` однозначно продовжується до єдиного гомоморфізму напіврешіток `h : Free(X) → S`, де для будь-якої скінченної підмножини `{x₁, ..., xₖ}`:

```
h({x₁, ..., xₖ}) = g(x₁) ⊔ ... ⊔ g(xₖ)
```

Це пояснює універсальну роль об'єднання множин: будь-яке обчислення над напіврешіткою є гомоморфним образом простого об'єднання скінченних наборів міток.

### 5. Повні напіврешітки та теорія нерухомих точок

У багатьох розділах математики та комп'ютерних наук виникає потреба обчислювати грані не лише для двох елементів, але й для нескінченних наборів станів.

Частково впорядкована множина `(S, ≤)` називається **повною напіврешіткою** (англ. *complete semilattice*), якщо кожна її непорожня підмножина `X ⊆ S` (зокрема нескінченна) має точну нижню грань `inf(X)` (для нижньої напіврешітки) або точну верхню грань `sup(X)` (для верхньої напіврешітки).

Якщо повна нижня напіврешітка має найбільший елемент `⊤`, вона автоматично стає **повною решіткою** (англ. *complete lattice*), оскільки супремум будь-якої підмножини `X` можна визначити як інфімум множини всіх її верхніх меж:

```
sup(X) = inf{y ∈ S : ∀ x ∈ X, x ≤ y}
```

#### Теорема Кнастера — Тарського

Одним із найпотужніших результатів теорії повних напіврешіток і решіток є теорема Броніслава Кнастера та Альфреда Тарського (1928, 1955).

Нехай `L` — повна решітка (або повна напіврешітка з екстремальними елементами), а функція `f : L → L` є **монотонним відображенням**, тобто:

```
x ≤ y  ⇒  f(x) ≤ f(y)
```

**Теорема:** Множина всіх нерухомих точок функції `f` (тобто таких `x ∈ L`, що `f(x) = x`) є непорожньою і сама утворює повну решітку. Зокрема, функція `f` має однозначну найменшу нерухому точку `x_min` та найбільшу нерухому точку `x_max`:

```
x_min = inf{x ∈ L : f(x) ≤ x}
x_max = sup{x ∈ L : x ≤ f(x)}
```

#### Домени Скотта та денотаційна семантика

У теоретичній інформатиці повні напіврешітки, спрямовані за підмножинами (dcpo — *directed-complete partial orders*), утворюють основу **доменної теорії Дани Скотта**.

Обчислення рекурсивної функції розглядається як монотонний оператор над доменом часткової інформації:
- Стан `⊥` позначає відсутність результату (незавершену ітерацію).
- Кожен крок рекурсії обчислює наближення `x_{k+1} = f(x_k)`.
- Нескінченна границя `sup_{k} x_k` за теоремою Скотта збігається до найменшої нерухомої точки оператора `f`, що дає детерміновану семантику рекурсивним алгоритмам у мовах функційного програмування (Haskell, OCaml).

#### Значення для статичного аналізу коду та оптимізації компіляторів

Теорема Тарського лежить в основі роботи компіляторних оптимізаторів (LLVM, GCC) та систем статичного аналізу коду (інтервальний аналіз, виявлення мертвого коду, поширення констант).

Компілятор представляє знання про можливі значення змінних у кожній точці програми як елементи напіврешітки. Наприклад, для інтервального аналізу змінної `x`:
- `⊥` — код недосяжний (значень немає).
- `[1, 5]` — змінна набуває значень від 1 до 5.
- `[-∞, +∞]` (або `⊤`) — повна невизначеність (будь-яке значення).

Кожна інструкція програми розглядається як монотонна функція `f`, що трансформує простір напіврешітки. Компілятор починає зі стану `⊥` і ітеративно обчислює значення `x_{k+1} = x_k ⊔ f(x_k)`. Завдяки властивостям повної напіврешітки цей процес гарантовано зупиняється за скінченну кількість кроків у найменшій нерухомій точці, надаючи компілятору максимально точну й безпечну інформацію для оптимізації інструкцій без ризику зациклення аналізатора.

### 6. Напіврешітки у розподілених системах: фундамент CRDT

Найяскравішим сучасним практичним застосуванням напіврешіток є проектування розподілених баз даних та систем спільної роботи, що використовують **конфліктно-вільні репліковані типи даних** ([CRDT](book:algorithms/crdt), англ. *Conflict-free Replicated Data Types*).

У класичних розподілених системах для підтримки єдиного стану використовують алгоритми консенсусу (Raft, Paxos). Вони вимагають, щоб більшість вузлів (кворум) погодила кожен запис. Якщо мережа між дата-центрами розривається (network partition), система блокує запис, втрачаючи доступність (Availability у теоремі CAP).

CRDT на основі стану (State-based CRDTs, або **CvRDT**) розв'язують цю задачу інакше: вони дозволяють кожному вузлу миттєво приймати локальні записи в офлайн-режимі. Усі репліки збігаються до абсолютно однакового стану автоматично, коли знову отримують зв'язок.

Математичним фундаментом CvRDT є **обмежена join-напіврешітка** `(S, ⊔, ⊥)`:

1. Стан кожної репліки є елементом множини `S`.
2. Початковий стан репліки — це найменший елемент `⊥`.
3. Локальні оновлення переводять стан `s` у новий стан `s'`, причому мутація є монотонно зростаючою: `s ≤ s'`.
4. Обмін інформацією між репліками полягає в надсиланні свого стану `s_A` сусідній репліці `B`, яка виконує операцію злиття: `s_B_new = s_B ⊔ s_A`.

```
                    Схема злиття реплік у CvRDT
                    
       Репліка A                           Репліка B
  +------------------+                +------------------+
  |  Стан s₁ = ⟨3, 1⟩ |                |  Стан s₂ = ⟨1, 4⟩ |
  +------------------+                +------------------+
            \                                  /
             \        Мережевий обмін         /
              \    (затримки, дублікати)     /
               v                            v
             +--------------------------------+
             |    Злиття напіврешітки:        |
             |   s₁ ⊔ s₂ = ⟨max(3,1), max(1,4)⟩ |
             |           = ⟨3, 4⟩             |
             +--------------------------------+
```

#### Чому закони напіврешітки гарантують узгодженість без блокувань

Кожна з трьох алгебраїчних аксіом напіврешітки закриває конкретну фізичну проблему ненадійних мереж передачі даних:

1. **Комутативність (`a ⊔ b = b ⊔ a`):** Якщо репліка `A` надіслала оновлення репліці `C`, а репліка `B` одночасно надіслала своє, порядок надходження пакетів на `C` (`A` потім `B` чи `B` потім `A`) не має значення. Стан на `C` буде однаковим.
2. **Асоціативність (`(a ⊔ b) ⊔ c = a ⊔ (b ⊔ c)`):** Повідомлення можуть об'єднуватися проміжними серверами або маршрутизаторами в довільні пакети чи ретранслюватися деревоподібно (госип-протоколи). Результат злиття залишається незмінним.
3. **Ідемпотентність (`a ⊔ a = a`):** Якщо протокол повторно надіслав той самий пакет через таймаут або розрив TCP-з'єднання, повторне виконання `merge(s, s)` не збільшить лічильники й не продублює записи.

#### Монотонність і теорема CALM

У розподілених системах критичним є питання: чи потрібна координація (блокування) для виконання конкретного обчислення?

Відповідь дає **теорема CALM** (*Consistency As Logical Monotonicity*, Джозеф Геллерштейн, Пітер Альваро):
> Програма може бути узгодженою в розподіленому середовищі без використання блокувань і координаційних бар'єрів тоді й тільки тоді, коли її логіка є **монотонною**.

Монотонність означає, що надходження нової інформації може лише збільшити обсяг знань системи, але ніколи не скасовує раніше зроблені висновки. Оскільки в join-напіврешітці операція злиття завжди задовольняє умову:

```
s ≤ s ⊔ Δs
```

стан системи невпинно рухається вгору вздовж часткового порядку `≤`. Це гарантує **сильну кінцеву узгодженість** (Strong Eventual Consistency, SEC): будь-які два вузли, які отримали однаковий набір повідомлень (незалежно від черговості доставки), перебувають у строго ідентичному стані.

#### Дельта-мутації (δ-CRDT): стиснення мережевого трафіку

Класичний CvRDT вимагає надсилання повного стану репліки `S` при кожному обміні, що створює значне мережеве навантаження `O(N)` при зростанні розміру даних.

Для розв'язання цієї проблеми використовують **дельта-напіврешітки** (англ. *delta-state CRDTs*, δ-CRDT). Замість повного стану вузол надсилає лише мінімальну дельта-мутацію `d ∈ S`, яка представляє свіжу зміну:

```
s_new = s ⊔ d
```

Оскільки операція злиття залишається операцією join-напіврешітки, проміжне накопичення дельт у буферах `d₁ ⊔ d₂ ⊔ ... ⊔ dₖ` зберігає всі властивості комутативності та ідемпотентності, зменшуючи трафік до `O(1)` для більшості повсякденних операцій.

![Join-напіврешітка як основа сильної кінцевої узгодженості](/book/math/algebra/semilattice/img/crdt-join-semilattice-merge.svg)
*Злиття станів розподілених реплік як обчислення супремуму над простором станів join-напіврешітки. Монотонний підйом порядком `≤` забезпечує детерміновану збіжність.*

### 7. Класичні розподілені структури даних (CRDT)

Розглянемо, як базові абстрактні структури даних відображаються на мову напіврешіток.

#### 1. G-Counter (Grow-Only Counter)

Розподілений лічильник, значення якого може лише збільшуватися.
- **Простір станів:** Вектор невід'ємних цілих чисел `V = ⟨v₁, v₂, ..., vₙ⟩`, де `n` — кількість вузлів у системі. Вузол `i` має право збільшувати лише свою компоненту `vᵢ`.
- **Початковий стан:** `⊥ = ⟨0, 0, ..., 0⟩`.
- **Операція злиття (Join):** Покомпонентний максимум двох векторів:
  ```
  (V ⊔ U)ᵢ = max(Vᵢ, Uᵢ)
  ```
- **Значення лічильника:** Сума всіх компонент вектора: `value(V) = ∑ Vᵢ`.

Оскільки `(ℕⁿ, max)` є прямою декартовою сумою `n` join-напіврешіток `(ℕ, max)`, вона сама є коректною join-напіврешіткою.

#### 2. PN-Counter (Positive-Negative Counter)

Лічильник, який підтримує як операцію збільшення (інкремент), так і операцію зменшення (декремент).
- **Проблема:** Пряме зменшення числа порушує монотонність (`s - 1 < s`).
- **Алгебраїчне рішення:** Представити стан як прямий добуток двох незалежних G-лічильників: `⟨P, N⟩`, де `P` накопичує всі додатні операції, а `N` — усі від'ємні.
- **Операція злиття:** Попарне злиття обох напіврешіток:
  ```
  ⟨P₁, N₁⟩ ⊔ ⟨P₂, N₂⟩ = ⟨P₁ ⊔ P₂, N₁ ⊔ N₂⟩
  ```
- **Значення:** `value = value(P) - value(N)`.

Обидві внутрішні координати монотонно зростають, що зберігає структуру напіврешітки, хоча результуюча різниця може як збільшуватися, так і зменшуватися.

#### 3. LWW-Element-Set (Last-Write-Wins Element Set)

Множина елементів із розв'язанням конфліктів за найновішою міткою часу.
- **Механізм:** Для кожного елемента `x` зберігається мітка часу додавання `t_add(x)` та мітка часу видалення `t_rem(x)`.
- **Операція злиття:** Поточковий максимум часових міток для кожного елемента:
  ```
  t_add_new(x) = max(t_add₁(x), t_add₂(x))
  t_rem_new(x) = max(t_rem₁(x), t_rem₂(x))
  ```
- **Присутність:** Елемент вважається активним, якщо `t_add(x) > t_rem(x)`.

Ця структура також є строгою join-напіврешіткою, оскільки злиття зводиться до взяття максимуму дійсних чисел або годинників Лампорта.

#### 4. OR-Set (Observed-Remove Set)

Множина елементів із підтримкою додавання та видалення на основі унікальних тегів.
- **Механізм:** Кожне додавання елемента `x` генерує унікальний ідентифікатор події (тег або UUID) `(x, tag)`. Стан складається з двох множин:
  1. `AddSet`: множина пар `(x, tag)`.
  2. `RemoveSet`: множина видалених тегів `tag`.
- **Операція злиття:** Теоретико-множинне об'єднання:
  ```
  ⟨AddSet₁, RemoveSet₁⟩ ⊔ ⟨AddSet₂, RemoveSet₂⟩ = ⟨AddSet₁ ∪ AddSet₂, RemoveSet₁ ∪ RemoveSet₂⟩
  ```
- **Читання:** Елемент `x` належить множині, якщо існує хоча б один тег `t` такий, що `(x, t) ∈ AddSet` і `t ∉ RemoveSet`.

Об'єднання множин `(P(U), ∪)` є канонічною join-напіврешіткою на булеані. Докладні алгоритми, структуру пам'яті та [повну робочу реалізацію G-Counter, PN-Counter та OR-Set мовами C++ та Python](book:math/semilattice/proj-crdt-semilattice.md) наведено у практичній вставці.

#### 5. Векторні версії та причинний порядок

Векторні годинники та версійні вектори (Version Vectors), що використовуються в Amazon DynamoDB, Riak та CouchDB, є нічим іншим, як join-напіврешіткою векторів натуральних чисел `(ℕⁿ, ≤, ⊔)`.

Два вектори `V₁` та `V₂` порівнюються покомпонентно:
- `V₁ ≤ V₂`, якщо `∀ i : V₁[i] ≤ V₂[i]`. Це означає, що стан `V₁` причинно передував стану `V₂`.
- Якщо ані `V₁ ≤ V₂`, ані `V₂ ≤ V₁` не виконується, вектори є непорівнянними (`V₁ || V₂`). Це математично сигналізує про виникнення конкурентного оновлення (конфлікту гілок).
- Злиття векторів `V₁ ⊔ V₂ = ⟨max(V₁[1], V₂[1]), ..., max(V₁[n], V₂[n])⟩` миттєво обчислює стан, який покриває історію обох конкурентних гілок.

#### Від напіврешітки до решітки: закони поглинання

Якщо об'єднати нижню напіврешітку `(S, ∧)` та верхню напіврешітку `(S, ∨)` на одній множині так, щоб їхні порядки узгоджувалися, ми отримуємо **решітку** (англ. *lattice*). Узгодженість двох операцій гарантується **законами поглинання** (англ. *absorption laws*):

```
a ∧ (a ∨ b) = a                [нижня грань елемента a та більшого за нього a ∨ b є a]
a ∨ (a ∧ b) = a                [верхня грань елемента a та меншого за нього a ∧ b є a]
```

Ці закони гарантують, що обидві операції визначають один і той самий частковий порядок:

```
a ≤ b  ⇔  a ∧ b = a  ⇔  a ∨ b = b
```
