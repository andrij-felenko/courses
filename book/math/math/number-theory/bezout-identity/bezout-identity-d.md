# Тотожність Безу

<preknowlist>
- Найбільший спільний дільник (НСД/GCD) та його базові властивості.
- Звичайний алгоритм Евкліда для знаходження НСД.
- Базові навички роботи з лінійними рівняннями.
</preknowlist>

Тотожність Безу — це фундаментальна теорема в теорії чисел, яка стверджує, що для будь-яких двох цілих чисел `a` та `b`, які не дорівнюють нулю одночасно, існують такі цілі числа `x` та `y`, що виконується рівняння:

```
a * x + b * y = gcd(a, b)
```

де `gcd(a, b)` — це найбільший спільний дільник чисел `a` та `b`.

> 🔧 **Навіщо це.**
> Тотожність Безу лежить в основі багатьох алгоритмів криптографії (наприклад, RSA), де її застосовують для пошуку оберненого елемента за модулем. Крім того, вона дозволяє розв'язувати лінійні діофантові рівняння (рівняння, в яких змінні можуть набувати лише цілих значень).

## 1. Суть і фізична інтуїція

Уявімо, що ви маєте дві мірні посудини: одна об'ємом `a` літрів, інша — `b` літрів. Ви можете нескінченно довго наливати або виливати воду за допомогою цих посудин. Найменший можливий позитивний об'єм води, який ви можете відміряти таким чином, завжди дорівнює `gcd(a, b)`. 

Будь-який інший об'єм, який ви можете виміряти, обов'язково буде кратним цьому числу `gcd(a, b)`. Коефіцієнти `x` та `y` показують, скільки разів вам потрібно наповнити або спустошити першу та другу посудину відповідно. Знак мінус означає, що воду виливають.

## 2. Як знайти коефіцієнти: Розширений алгоритм Евкліда

Звичайний алгоритм Евкліда дозволяє швидко знайти НСД двох чисел шляхом послідовного ділення з остачею. Розширений алгоритм Евкліда виконує ті самі кроки, але також відстежує, як кожна остача виражається через початкові числа `a` та `b`.

### Метод зворотної підстановки (Backward Substitution)

Нехай ми шукаємо НСД чисел 73 та 22. Проведемо алгоритм Евкліда:
1. 73 = 3 * 22 + 7  => 7 = 73 - 3 * 22
2. 22 = 3 * 7 + 1   => 1 = 22 - 3 * 7
3. 7 = 7 * 1 + 0    => НСД дорівнює 1.

Тепер почнемо з передостаннього рядка і виразимо 1 через початкові числа 73 та 22:
```
1 = 22 - 3 * 7
```
Тепер підставимо вираз для остачі 7 з першого кроку (7 = 73 - 3 * 22):
```
1 = 22 - 3 * (73 - 3 * 22)
1 = 22 - 3 * 73 + 9 * 22
1 = 10 * 22 - 3 * 73
```
Тобто:
```
-3 * 73 + 10 * 22 = 1
```
Тут `x = -3`, `y = 10`, а `gcd(a, b) = 1`.

### Матричний метод

Зворотна підстановка зручна для ручного обчислення, але для програмування зручніше записувати розширений алгоритм Евкліда у вигляді матричних операцій або підтримуючи два набори змінних паралельно до ділення. Цей метод обчислює `x` та `y` на льоту, не вимагаючи зберігання всієї історії остач.

Уявімо це як систему рівнянь. На кожному кроці `i` ми маємо:
```
r_i = a * x_i + b * y_i
```
Для початкових кроків ми беремо:
```
r_0 = a, x_0 = 1, y_0 = 0
r_1 = b, x_1 = 0, y_1 = 1
```
Наступні значення обчислюються як:
```
q_i = r_{i-1} / r_i  (цілочисельне ділення)
r_{i+1} = r_{i-1} - q_i * r_i
x_{i+1} = x_{i-1} - q_i * x_i
y_{i+1} = y_{i-1} - q_i * y_i
```
Процес зупиняється, коли `r_{i+1} = 0`. Поточні `r_i`, `x_i` та `y_i` міститимуть НСД та коефіцієнти Безу відповідно.

## 3. Геометрична сітка

![Геометрична сітка тотожності Безу та розширеного алгоритму Евкліда](/book/math/number-theory/bezout-identity/img/fig-bezout-identity.svg)

Геометрично, рівняння `a * x + b * y = c` є рівнянням прямої на площині координат (x, y). Тотожність Безу гарантує, що якщо `c` кратно `gcd(a, b)`, пряма пройде принаймні через одну точку з цілими координатами (вузол цілочисельної сітки).

Якщо ми знайшли один розв'язок `(x_0, y_0)`, ми можемо знайти всі інші розв'язки. Вони будуть розташовані вздовж тієї самої прямої на рівних відстанях одне від одного. Відстань між розв'язками залежить від чисел `a` та `b`.

Формули для всіх розв'язків:
```
x = x_0 + k * (b / gcd(a, b))
y = y_0 - k * (a / gcd(a, b))
```
де `k` — будь-яке ціле число.

## 4. Застосування тотожності Безу

### Обернений елемент за модулем

У модульній арифметиці нам часто потрібно знайти таке число `x`, щоб виконувалося рівняння:
```
a * x mod m = 1
```
Таке рівняння має розв'язок тоді і тільки тоді, коли числа `a` та `m` взаємно прості, тобто `gcd(a, m) = 1`. 

За тотожністю Безу існують коефіцієнти `x` та `y`, такі що:
```
a * x + m * y = 1
```
Якщо ми візьмемо залишок від ділення обох частин на `m`, доданок `m * y` зникне, оскільки він кратний `m`. Отримаємо:
```
(a * x) mod m = 1
```
Отже, знайдений коефіцієнт `x` і є нашим оберненим елементом за модулем `m`.

### Лінійні діофантові рівняння

Діофантове рівняння `a * x + b * y = c` має цілі розв'язки тоді і тільки тоді, коли `c` ділиться без остачі на `gcd(a, b)`. 
Для знаходження розв'язку:
1. За допомогою розширеного алгоритму Евкліда знаходимо `x_0` та `y_0` для рівняння `a * x_0 + b * y_0 = gcd(a, b)`.
2. Оскільки `c` кратно `gcd(a, b)`, ми можемо помножити обидві частини на `k = c / gcd(a, b)`.
3. Отримуємо: `a * (x_0 * k) + b * (y_0 * k) = c`. Отже, розв'язком є пара `(x_0 * k, y_0 * k)`.

## Висновок

Тотожність Безу — це не просто абстрактна теорема, а міст між безперервною лінійною алгеброю та дискретною теорією чисел. Розширений алгоритм Евкліда дає нам швидкий, конструктивний спосіб знайти коефіцієнти цієї тотожності, забезпечуючи фундамент для сучасних криптографічних систем.
