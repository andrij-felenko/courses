# ⚙️ Симуляція решета Ейлера (C++)

Цей скрипт демонструє, як процес викреслювання, використаний Ейлером, працює на практиці для скінченної кількості доданків. Ми створюємо масив дробів і послідовно застосовуємо решето, множачи і віднімаючи.

```cpp
#include <iostream>
#include <vector>
#include <iomanip>

// Симуляція перших кроків тотожності Ейлера
// Показує, як віднімання рядів прибирає складені знаменники.

int main() {
    const int N = 20; // Кількість доданків для симуляції
    std::vector<bool> active(N + 1, true); // Чи активний доданок 1/n
    
    std::vector<int> primes = {2, 3, 5};
    
    std::cout << "Початковий ряд: ";
    for (int i = 1; i <= N; ++i) {
        std::cout << "1/" << i << " + ";
    }
    std::cout << "..." << std::endl;
    
    for (int p : primes) {
        std::cout << "\nПісля викреслювання кратних " << p << ":" << std::endl;
        for (int i = p; i <= N; i += p) {
            active[i] = false;
        }
        
        std::cout << "Залишок: ";
        for (int i = 1; i <= N; ++i) {
            if (active[i]) {
                std::cout << "1/" << i << " + ";
            }
        }
        std::cout << "..." << std::endl;
    }
    
    return 0;
}
```

Код просто ілюструє ідею. Кожен прохід циклу по простих числах імітує множення ряду на `(1 - 1/p)` і віднімання результату, що призводить до видалення всіх доданків, знаменники яких кратні поточному простому числу. У нескінченній межі залишається лише перший доданок — одиниця.
