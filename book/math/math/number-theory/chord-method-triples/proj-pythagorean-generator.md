# ⚙️ Генератор Піфагорових трійок на C++

Розуміння методу хорди дозволяє нам перетворити алгебраїчну теорію на дієвий алгоритм. Замість того, щоб всліпу перебирати числа a та b, перевіряючи, чи є сума їхніх квадратів повним квадратом, ми можемо генерувати трійки напряму. Формули a = m² - n², b = 2mn, c = m² + n² дозволяють нам отримувати Піфагорові трійки, просто перебираючи цілі числа m та n.

Щоб трійки були примітивними (тобто не мали спільного дільника, як-от 6, 8, 10, що є подвоєною 3, 4, 5), числа m та n повинні задовольняти три прості умови:
1. m > n > 0 (щоб довжини сторін були додатними).
2. m та n є взаємно простими (їхній найбільший спільний дільник дорівнює 1).
3. m та n мають різну парність (одне парне, інше непарне; інакше всі три сторони a, b, c будуть парними).

Нижче наведено реалізацію генератора примітивних Піфагорових трійок на C++17, який використовує ці правила.

```cpp
#include <iostream>
#include <numeric>
#include <vector>

// Структура для зберігання Піфагорової трійки
struct PythagoreanTriple {
    long long a;
    long long b;
    long long c;
};

// Функція для генерації трійок з обмеженням на максимальне значення c
std::vector<PythagoreanTriple> generatePrimitiveTriples(long long max_c) {
    std::vector<PythagoreanTriple> triples;
    
    // Перебираємо m починаючи з 2
    for (long long m = 2; m * m <= max_c; ++m) {
        // Перебираємо n від 1 до m-1
        for (long long n = 1; n < m; ++n) {
            
            // Умова 1: m та n повинні мати різну парність
            if ((m % 2) == (n % 2)) {
                continue;
            }
            
            // Умова 2: m та n повинні бути взаємно простими
            if (std::gcd(m, n) != 1) {
                continue;
            }
            
            // Обчислюємо сторони за формулами методу хорди
            long long a = m * m - n * n;
            long long b = 2 * m * n;
            long long c = m * m + n * n;
            
            // Якщо гіпотенуза перевищує ліміт, переходимо до наступного m
            if (c > max_c) {
                break;
            }
            
            triples.push_back({a, b, c});
        }
    }
    return triples;
}

int main() {
    long long max_hypotenuse = 100;
    auto triples = generatePrimitiveTriples(max_hypotenuse);
    
    std::cout << "Примітивні Піфагорові трійки з гіпотенузою до " << max_hypotenuse << ":
";
    for (const auto& t : triples) {
        std::cout << "(" << t.a << ", " << t.b << ", " << t.c << ")
";
    }
    
    return 0;
}
```

Цей код демонструє елегантність алгоритмічного мислення, побудованого на математичному фундаменті. Функція `std::gcd` з бібліотеки `<numeric>` виконує перевірку на взаємну простоту. Замість кубічної або квадратичної складності перебору, ми маємо субквадратичний алгоритм, який безпосередньо генерує лише правильні відповіді, уникаючи марних обчислень. Це і є справжня міць алгебраїчної параметризації в програмуванні.
