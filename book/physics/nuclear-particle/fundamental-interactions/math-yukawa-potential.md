# 🧮 Математичний вивід потенціалу Юкави та радіуса взаємодії

Вивід потенціалу Юкави виходить із рівняння Клейна — Ґордона для масивного скалярного поля і встановлює прямий зв'язок між масою віртуального калібрувального бозона та характерним радіусом дії фундаментальної взаємодії.

## Рівняння Клейна — Ґордона для масивного переносника

У релятивістській квантовій теорії поля безмасове електромагнітне поле описується рівнянням Д'Аламбера для потенціалу, а масивне скалярне або векторне поле носія взаємодії з масою `m` задовольняє рівняння Клейна — Ґордона. У присутності стаціонарного точкового джерела колірного або ядерного заряду `g`, розташованого на початку координат, рівняння поля має вигляд:

```
(1/c²) · ∂²ϕ/∂t² - ∇²ϕ + (m·c / ħ)²·ϕ = g · δ³(r)
```

Для стаціонарного поля похідна по часу дорівнює нулю (`∂ϕ/∂t = 0`). Введемо параметр оберненої довжини хвилі Комптона для носія поля:

```
μ = m·c / ħ
```

Тоді тривимірне стаціонарне рівняння поля спрощується до еліптичного рівняння Гельмгольца зі знаковим коефіцієнтом:

```
-∇²ϕ(r) + μ²·ϕ(r) = g · δ³(r)
```

## Метод Ґрінових функцій та фур'є-перетворення

Дієвим математичним методом розв'язання рівняння Гельмгольца є перехід у імпульсний простір за допомогою тривимірного перетворення Фур'є. Запишемо шуканий потенціал `ϕ(r)` та дельта-функцію `δ³(r)` через їхні фур'є-образи `ϕ̃(q)`:

```
ϕ(r) = (1 / (2π)³) · ∫ ϕ̃(q) · exp(i q·r) d³q
δ³(r) = (1 / (2π)³) · ∫ exp(i q·r) d³q
```

Підставляємо фур'є-розклад у стаціонарне рівняння Гельмгольца. Оскільки дія оператора Лапласа `∇²` у імпульсному просторі зводиться до множення на `-q²`, маємо:

```
∫ [ q² + μ² ] · ϕ̃(q) · exp(i q·r) d³q = g · ∫ exp(i q·r) d³q
```

Оскільки це співвідношення виконується для всіх `r`, підінтегральні вирази мають бути рівними для кожного хвильового вектора `q`:

```
[ q² + μ² ] · ϕ̃(q) = g
= ϕ̃(q) = g / (q² + μ²)
```

Отже, фур'є-образ потенціалу Юкави дорівнює пропагатору масивного скалярного поля `1 / (q² + μ²)`. Для знаходження вихідного потенціалу в координатному просторі виконуємо обернене перетворення Фур'є у сферичних координатах імпульсного простору:

```
ϕ(r) = (g / (2π)³) · ∫ [ 1 / (q² + μ²) ] · exp(i q·r) d³q
```

Записуємо елемент об'єму в сферичних координатах `d³q = q² dq sin(θ_q) dθ_q dϕ_q` та інтегруємо по кутах:

```
∫ exp(i q r cos θ_q) sin θ_q dθ_q = (2 / (q r)) · sin(q r)
```

Після кутового інтегрування залишається одновимірний інтеграл по модулю хвильового вектора `q`:

```
ϕ(r) = (g / (2π² r)) · ∫₀^∞ [ q · sin(q r) / (q² + μ²) ] dq
```

Використовуючи метод лишків комплексного аналізу для парної функції `q sin(q r) / (q² + μ²)`, обчислюємо інтеграл уздовж замкненого контуру у верхній півплощині з полюсом у точці `q = i μ`:

```
∫₀^∞ [ q · sin(q r) / (q² + μ²) ] dq = (π / 2) · exp(-μ r)
```

Підставляючи цей результат, отримуємо аналітичний розв'язок у координатному просторі:

```
ϕ(r) = (g / (4π r)) · exp(-μ r)
```

## Розв'язок у сферично-симетричній системі координат

Альтернативний вивід полягає у прямому розв'язанні диференціального рівняння в сферичних координатах. Поза точкою розташування джерела (при `r > 0`) дельта-функція Дірака дорівнює нулю (`δ³(r) = 0`). З огляду на сферичну симетрію джерела, оператор Лапласа в сферичних координатах залежить лише від радіальної координати `r`:

```
∇²ϕ = (1/r) · d²/dr² (r·ϕ)
```

Підставляємо оператор Лапласа в стаціонарне рівняння поля:

```
- (1/r) · d²/dr² (r·ϕ) + μ²·ϕ = 0    [множимо обидві частини на (-r)]
= d²/dr² (r·ϕ) - μ²·(r·ϕ) = 0
```

Виконуємо заміну підінтегральної функції `u(r) = r · ϕ(r)`:

```
d²u(r) / dr² - μ² · u(r) = 0
```

Це лінійне однорідне диференціальне рівняння другого порядку зі сталими коефіцієнтами. Його характеристичне рівняння має вигляд `λ² - μ² = 0`, корені якого дорівнюють `λ = ± μ`. Загальний розв'язок має вигляд суми двох експонент:

```
u(r) = C₁ · exp(-μ·r) + C₂ · exp(μ·r)
```

Повертаємося до початкового потенціалу `ϕ(r) = u(r) / r`:

```
ϕ(r) = C₁ · exp(-μ·r) / r + C₂ · exp(μ·r) / r
```

## Фізичні граничні умови та нормування

Для визначення довільних сталих `C₁` та `C₂` застосовуємо фізичні граничні умови:

1. **Умова на нескінченності (`r → ∞`):** Потенціал фізичного поля повинен бути обмеженим і прагнути до нуля при віддаленні від джерела. Оскільки доданок `exp(μ·r) / r` необмежено зростає при `r → ∞`, його коефіцієнт мусить дорівнювати нулю:

```
C₂ = 0
```

2. **Кулонівська границя при `m → 0` (`μ → 0`):** У граничному випадку безмасового носія (`m = 0`), експонента перетворюється на одиницю `exp(0) = 1`, а рівняння поля переходить у класичне рівняння Пуассона електростатики:

```
-∇²ϕ = g · δ³(r)
```

Розв'язком цього рівняння є класичний потенціал Кулона:

```
ϕ(r) = - g / (4·π·r)
```

Порівнюючи граничний розв'язок із формою `ϕ(r) = C₁ / r`, отримуємо значення константи нормування:

```
C₁ = - g / (4·π)
```

## Остаточна формула потенціалу Юкави та потенціальна енергія

Підставляючи знайдені сталі `C₁` та `C₂`, отримуємо скалярний потенціал Юкави:

```
ϕ(r) = - g · exp(-μ·r) / (4·π·r)
```

Потенціальна енергія `V(r)` взаємодії двох частинок із зарядами `g₁` та `g₂`, що знаходяться на відстані `r`, обчислюється як добуток другого заряду на потенціал, створений першим:

```
V(r) = - g₁·g₂ · exp(-μ·r) / (4·π·r)
     = - g₁·g₂ · exp(-m·c·r / ħ) / (4·π·r)    [підстановка μ = m·c / ħ]
```

Формула Юкави містить два множники:
- **Геометричний спад `1/r`**, спільний для всіх тривимірних полів (закон обернених квадратів);
- **Експоненційний зріз `exp(-μ·r)`**, зумовлений наявністю ненульової маси `m` у квантового носія поля.

## Тензорні та спін-залежні компоненти ядерних сил

У дійсній фізиці ядерних сил між нуклонами (протонами й нейтронами) взаємодія описується не лише простим скалярним потенціалом Юкави, а сумою псевдоскалярного (`π`), векторного (`ρ, ω`) та тензорного полів.

Повний псевдоскалярний потенціал Однопіонного обміну (OPEP — One-Pion Exchange Potential) має вигляд:

```
V_OPEP(r) = (g_π² / 12π) · (m_π / M_N)² · (τ₁ · τ₂) · [ (σ₁ · σ₂) + S₁₂ · (1 + 3/(μ r) + 3/(μ r)²) ] · exp(-μ r) / r
```

де:
- `(τ₁ · τ₂)` — ізоспіновий оператор взаємодії (ізоспіновий добуток);
- `(σ₁ · σ₂)` — спін-спінова взаємодія двох нуклонів;
- `S₁₂ = 3 (σ₁ · r̂)(σ₂ · r̂) - (σ₁ · σ₂)` — тензорний оператор, відповідальний за квадрупольний момент дейтрона та нецентральність ядерних сил;
- `M_N` — маса нуклона (протона чи нейтрона).

Присутість векторного `ω`-мезона з масою `m_ω ≈ 782` МеВ/c² створює коротку відштовхувальну серцевину (Repulsive Core) на відстанях `r < 0.5` фм, яка запобігає колапсу атомних ядер під дією сильного притягання.

## Розрахунок радіуса взаємодії для конкретних носіїв

Характерний радіус дії взаємодії `r₀` (довжина екранування) визначається відстані, на якій потенціал зменшується в `e` разів (приблизно в 2.718 раза) швидше, ніж кулонівський:

```
r₀ = 1 / μ = ħ / (m·c)
```

Обчислимо конкретні значення для трьох типів фундаментальних носіїв:

### 1. Ядерні сили (обмін піонами, m_π ≈ 140 МеВ/c²)
Маса пі-мезона `m_π = 140 · 10⁶ · 1.602 · 10⁻¹⁹ Дж / (3 · 10⁸ м/с)² ≈ 2.49 · 10⁻²⁸ кг`.

```
r₀ = (1.055 · 10⁻³⁴ Дж·с) / (2.49 · 10⁻²⁸ кг · 3 · 10⁸ м/с)
   ≈ 1.41 · 10⁻¹⁵ м = 1.41 фм
```

Радіус дії ефективних ядерних сил становить близько 1.4 фемтометра, що збігається з розміром нуклонів та радіусом дії ядерного притягання.

### 2. Слабка взаємодія (обмін W-бозоном, m_W ≈ 80.4 ҐеВ/c²)
Маса `W`-бозона у 574 рази більша за масу піона (`m_W ≈ 80.4 · 10⁹ еВ`).

```
r₀ = (1.055 · 10⁻³⁴ Дж·с) / (1.43 · 10⁻²⁵ кг · 3 · 10⁸ м/с)
   ≈ 2.45 · 10⁻¹⁸ м = 0.00245 фм
```

Ультракороткий радіус слабкої взаємодії (`~ 10⁻¹⁸` м) робить її практично точковою на масштабах атомних ядер.

### 3. Електромагнетизм та гравітація (m_γ = 0, m_g = 0)
Оскільки маса фотона та ґравітона суворо дорівнює нулю (`m = 0`), маємо `μ = 0`.
Відповідно, радіус взаємодії прагне до нескінченності:

```
r₀ = lim_(m→0) [ħ / (m·c)] = ∞
```

Експоненційний множник `exp(0) = 1` зникає, і потенціал стає чисто кулонівським (або ньютонівським), що забезпечує нескінченний радіус дії електромагнітних та гравітаційних сил.
