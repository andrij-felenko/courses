# 🧮 Математичний вивід та статистика розпаду

Ця вставка містить строгий математичний вивід експоненціального закону радіоактивного розпаду з перших принципів квантової ймовірності, зв'язок сталої розпаду з періодом напіврозпаду та середнім часом життя, вивід пуассонівської статистики відліків детектора, асимптотику апроксимації Гаусса та аналітичний розв'язок рівнянь Бейтмана для багатоланкових ланцюгів радіоактивних перетворень.

## 1. Строгий вивід експоненціального закону розпаду

Нехай `N(t)` — кількість нестабільних ядер даного типу в зразку в момент часу `t`. 

Основний постулат теорії розпаду полягає в тому, що кожне нестабільне ядро має однакову й сталу в часі ймовірність `w` розпастися за одиницю часу. Ця ймовірність називається **сталою розпаду** `λ` (вимірюється в с⁻¹).

Ймовірність `dP` того, що конкретне ядро розпадеться за нескінченно малий інтервал часу `dt`, є прямо пропорційною тривалості цього інтервалу:

```
dP = λ · dt
```

Якщо в зразку міститься `N(t)` однакових незалежних ядер, то очікувана зміна кількості ядер `dN` за інтервал `dt` дорівнює добутку кількості ядер на ймовірність розпаду кожного з них. Оскільки розпад зменшує кількість ядер, зміна `dN` є від'ємною:

```
dN = -N(t) · dP = -λ · N(t) · dt
```

Отримане диференціальне рівняння першого порядку зі відокремлюваними змінними розв'язується кроками:

```
dN / dt = -λ · N(t)
dN / N  = -λ · dt                   [відокремлення змінних: ділення на N, множення на dt]
∫ (1/N) dN = ∫ (-λ) dt              [інтегрування лівої та правої частин]
ln(N)   = -λ · t + C                [взяття первісних, C — константа інтегрування]
N(t)    = e^(-λ · t + C)            [експоненціювання обох частин]
N(t)    = C' · e^(-λ · t)           [позначення C' = e^C]
```

Для визначення константи `C'` скористаємося початковою умовою: при `t = 0` кількість ядер дорівнює `N(0) = N₀`. Підставляючи `t = 0` у рівняння, отримуємо `N(0) = C' · e⁰ = C' = N₀`.

Отже, остаточний **закон радіоактивного розпаду Резерфорда — Содді**:

```
N(t) = N₀ · e^(-λ · t)
```

Кількість розпадених ядер `N_d(t)` до моменту часу `t` визначається різницею:

```
N_d(t) = N₀ - N(t) = N₀ · (1 - e^(-λ · t))
```

Фізичний зміст цього розв'язку полягає у відсутності пам'яті у квантових систем. Ймовірність розпастися протягом наступної секунди не залежить від того, скільки часу ядро вже проіснувало. В математичній теорії ймовірностей показано, що експоненціальний розподіл є єдиним неперервним розподілом із цією властивістю.

## 2. Період напіврозпаду та середній час життя

### Вивід періоду напіврозпаду T₁/₂

За визначенням, **період напіврозпаду** `T₁/₂` — це інтервал часу, протягом якого кількість нестабільних ядер зменшується вдвічі, тобто `N(T₁/₂) = N₀ / 2`.

Підставимо це значення в закон розпаду:

```
N₀ / 2 = N₀ · e^(-λ · T₁/₂)
1 / 2  = e^(-λ · T₁/₂)              [скорочення на N₀]
e^(λ · T₁/₂) = 2                    [перевертання обох частин]
λ · T₁/₂ = ln(2)                    [логарифмування за основою e]
T₁/₂ = ln(2) / λ ≈ 0.693147 / λ     [вираження періоду напіврозпаду]
```

Завдяки цьому зв'язку закон розпаду можна переписати через основу 2:

```
N(t) = N₀ · e^(-(ln(2)/T₁/₂) · t) = N₀ · (e^ln(2))^(-t / T₁/₂) = N₀ · 2^(-t / T₁/₂)
```

### Вивід середнього часу життя τ та його дисперсії

**Середній час життя** `τ` нестабільного ядра — це математичне сподівання тривалості існування ядра до моменту його розпаду.

Ймовірність того, що ядро доживе до моменту `t` і розпадеться в інтервалі `[t, t + dt]`, дорівнює добутку ймовірності не розпастися до часу `t` на ймовірність розпастися в інтервалі `dt`:

```
p(t) dt = (N(t) / N₀) · (λ dt) = e^(-λ · t) · λ dt
```

Функція `p(t) = λ · e^(-λ · t)` є щільністю ймовірності тривалості життя ядра. Обчислимо математичне сподівання:

```
τ = ∫₀^∞ t · p(t) dt = ∫₀^∞ t · λ · e^(-λ · t) dt
```

Обчислюємо інтеграл по частинах: покладемо `u = t` (`du = dt`), `dv = λ · e^(-λ · t) dt` (`v = -e^(-λ · t)`):

```
τ = [-t · e^(-λ · t)]₀^∞ + ∫₀^∞ e^(-λ · t) dt
τ = 0 + [- (1/λ) · e^(-λ · t)]₀^∞
τ = 0 - (0 - (1/λ)) = 1 / λ
```

Таким чином, **середній час життя дорівнює оберненій величині сталої розпаду**:

```
τ = 1 / λ
```

Зв'язок між періодом напіврозпаду `T₁/₂` та середнім часом життя `τ`:

```
T₁/₂ = τ · ln(2) ≈ 0.693147 · τ
τ = T₁/₂ / ln(2) ≈ 1.442695 · T₁/₂
```

Обчислимо також друге центральне примітивне значення — дисперсію тривалості життя ядра `Var(t) = E[t²] - (E[t])²`:

```
E[t²] = ∫₀^∞ t² · λ · e^(-λ · t) dt = 2 / λ²
Var(t) = (2 / λ²) - (1 / λ)² = 1 / λ² = τ²
```

Стандартне відхилення тривалості життя окремого ядра `σ_t = τ` дорівнює самому середньому часу життя `τ`. Це означає, що розкид часу існування окремих ядер є надзвичайно великим: деякі ядра розпадаються за мікросекунди, а інші живуть у кілька разів довше за середній час `τ`.

## 3. Статистика Пуассона та апроксимація Гаусса

Оскільки розпад кожного ядра є незалежною випадковою подією з малою ймовірністю `p = λ · dt`, кількість розпадів `k`, зареєстрованих детектором за фіксований інтервал часу `Δt`, підпорядковується **розподілу Пуассона**.

Граничний перехід біноміального розподілу `B(N, p)` при `N → ∞` та `p → 0` за умови, що середня кількість розпадів `μ = N · p = const`, дає ймовірність зареєструвати саме `k` розпадів:

```
P(k) = (μ^k / k!) · e^(-μ)
```

Обчислимо математичне сподівання `E[k]` та дисперсію `Var(k)` пуассонівського розподілу:

### Математичне сподівання:
```
E[k] = ∑ₖ₌₀^∞ k · P(k) = ∑ₖ₌₁^∞ k · (μ^k / k!) · e^(-μ)
     = μ · e^(-μ) · ∑ₖ₌₁^∞ (μ^(k-1) / (k-1)!)
     = μ · e^(-μ) · e^μ = μ
```

### Дисперсія:
Для знаходження дисперсії `Var(k) = E[k²] - (E[k])²` спочатку знайдемо `E[k(k-1)]`:

```
E[k(k-1)] = ∑ₖ₌₂^∞ k(k-1) · (μ^k / k!) · e^(-μ)
          = μ² · e^(-μ) · ∑ₖ₌₂^∞ (μ^(k-2) / (k-2)!) = μ²
E[k²] = E[k(k-1)] + E[k] = μ² + μ
Var(k) = (μ² + μ) - μ² = μ
```

Отже, головна властивість пуассонівського розподілу радіоактивних розпадів: **дисперсія кількості розпадів дорівнює їхньому середньому значенню**:

```
Var(k) = σ² = μ = <N_decay>
σ = √<N_decay>                       [стандартне відхилення]
```

### Перехід до нормального розподілу Гаусса при великих N

Згідно з центральною граничною теоремою теорії ймовірностей, при великих значеннях середньої кількості відліків (`μ = <N> >> 20`) пуассонівський розподіл асимптотично наближається до нормального розподілу Гаусса з параметрами `N(μ, σ = √μ)`:

```
P(k) ≈ (1 / √(2 · π · μ)) · e^(-0.5 · ((k - μ)² / μ))
```

Це наближення дозволяє використовувати стандартні довірчі інтервали Гаусса:
- В інтервалі `[μ - σ, μ + σ]` лежить 68.27% усіх вимірювань;
- В інтервалі `[μ - 2σ, μ + 2σ]` лежить 95.45% усіх вимірювань;
- В інтервалі `[μ - 3σ, μ + 3σ]` лежить 99.73% усіх вимірювань.

### Відносна похибка та тривалість вимірювання

Відносна статистична похибка `δ` вимірювання активності або кількості відліків радіаційного детектора виражається як:

```
δ = σ / <N_decay> = √<N_decay> / <N_decay> = 1 / √<N_decay>
```

Це фундаментальний закон ядерної метрології:
- Щоб отримати похибку `10%` (`0.10`), потрібно зареєструвати `N = 1 / 0.10² = 100` відліків.
- Щоб отримати похибку `1%` (`0.01`), потрібно накопичити `N = 1 / 0.01² = 10 000` відліків.
- Щоб отримати похибку `0.1%` (`0.001`), необхідно накопичити `N = 1 000 000` відліків.

## 4. Аналітичні рівняння Бейтмана для ланцюга розпадів A → B → C

Розглянемо послідовний розпад 3-ланкового ланцюга: материнське ядро `A` з константою `λ_A` розпадається в дочірнє ядро `B` з константою `λ_B`, яке в свою чергу розпадається в стабільне ядро `C` (`λ_C = 0`).

```
A  --(λ_A)-->  B  --(λ_B)-->  C (стабільне)
```

Баланс кількостей ядер описується системою диференціальних рівнянь Гаррі Бейтмана (1910 рік):

```
dN_A / dt = -λ_A · N_A
dN_B / dt = λ_A · N_A - λ_B · N_B
dN_C / dt = λ_B · N_B
```

Нехай у момент `t = 0` маємо `N_A(0) = N_A0`, `N_B(0) = 0`, `N_C(0) = 0`.

1. Розв'язок для `N_A(t)`:
```
N_A(t) = N_A0 · e^(-λ_A · t)
```

2. Підставляємо `N_A(t)` у рівняння для `N_B(t)`:
```
dN_B / dt + λ_B · N_B = λ_A · N_A0 · e^(-λ_A · t)
```

Це лінійне неоднорідне диференціальне рівняння 1-го порядку. Шукаємо розв'язок методом інтегруючого множника `e^(λ_B · t)`:

```
d/dt [N_B · e^(λ_B · t)] = λ_A · N_A0 · e^((λ_B - λ_A) · t)
N_B · e^(λ_B · t) = [λ_A · N_A0 / (λ_B - λ_A)] · e^((λ_B - λ_A) · t) + C
N_B(t) = [λ_A · N_A0 / (λ_B - λ_A)] · e^(-λ_A · t) + C · e^(-λ_B · t)
```

З початкової умови `N_B(0) = 0`:
```
0 = [λ_A · N_A0 / (λ_B - λ_A)] + C  ⇒  C = - [λ_A · N_A0 / (λ_B - λ_A)]
```

Остаточна **формула Бейтмана для дочірнього ядра**:

```
N_B(t) = N_A0 · [ λ_A / (λ_B - λ_A) ] · ( e^(-λ_A · t) - e^(-λ_B · t) )
```

### Час досягнення максимальної активності дочірнього ядра

Щоб знайти момент часу `t_max`, коли кількість дочірніх ядер `N_B` (та їхня активність `A_B = λ_B · N_B`) є максимальною, прирівняємо похідну `dN_B / dt` до нуля:

```
dN_B / dt = 0  ⇒  λ_A · e^(-λ_A · t_max) = λ_B · e^(-λ_B · t_max)
e^((λ_B - λ_A) · t_max) = λ_B / λ_A
(λ_B - λ_A) · t_max = ln(λ_B / λ_A)
t_max = ln(λ_B / λ_A) / (λ_B - λ_A)
```

### Граничний випадок: Вікова рівновага (Secular Equilibrium)

Якщо материнський ізотоп є дуже довгоживучим порівняно з дочірнім (`T₁/₂ (A) >> T₁/₂ (B)`, тобто `λ_A << λ_B`), то при великих часах `t >> 1 / λ_B`:
- `e^(-λ_B · t) → 0`;
- `λ_B - λ_A ≈ λ_B`.

Тоді формула для `N_B(t)` спрощується до:

```
N_B(t) ≈ N_A0 · (λ_A / λ_B) · e^(-λ_A · t) = (λ_A / λ_B) · N_A(t)
```

Помноживши обидві частини на `λ_B`, отримуємо рівність активностей:

```
A_B(t) = λ_B · N_B(t) ≈ λ_A · N_A(t) = A_A(t)
```

Це стан **вікової радіоактивної рівноваги**: активність дочірнього нукліда стає рівною активності материнського нукліда і надалі спадає з повільним періодом напіврозпаду материнського ядра.
