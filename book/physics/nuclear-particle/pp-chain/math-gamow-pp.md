# 🧮 Квантово-механічний розрахунок фактора Ґамова та перерізу pp-реакції

Ця математична вставка містить строге квантово-механічне виведення ймовірності тунелювання протонів крізь кулонівський потенціальний бар'єр у наближенні Вентцеля — Крамерса — Бріллюена (ВКБ), аналітичний розрахунок форми та ширини енергетичного вікна Ґамова у термоядерній плазмі, теорію астрофізичного S-фактора слабої взаємодії та кількісну оцінку середнього часу життя протона в ядрі Сонця.

## Кулонівський потенціал та класична точка повороту

Розглянемо зіткнення двох протонів із однаковими масами `m₁ = m₂ = m_p` у просторі центрів мас. Зведена маса дворівневої системи двох однакових нуклонів дорівнює:

```
μ = (m_p · m_p) / (m_p + m_p) = m_p / 2 ≈ 469.44 МЕв/c²
```

Кулонівський потенціал електростатичного відштовхування між двома точковими позитивними зарядами `Z₁ = 1` та `Z₂ = 1` залежно від відстані між їхніми центрами `r` задається виразом:

```
V(r) = (Z₁ · Z₂ · e²) / (4 · π · ε₀ · r) = α · ħ · c · (Z₁ · Z₂ / r)
```

Де `α = e² / (4·π·ε₀·ħ·c) ≈ 1/137.036` — константа тонкої структури електромагнітної взаємодії, а добуток `ħ · c ≈ 197.327 МЕв · фм`.

Класична точка повороту `r_c` — це відстань найменшого зближення частинок із відносною кінетичною енергією `E` в системі центру мас, при якій уся кінетична енергія повністю переходить у потенціальну енергію електростатичного відштовхування (`V(r_c) = E`):

```
r_c = (Z₁ · Z₂ · e²) / (4 · π · ε₀ · E)      [умова зупинки: V(r_c) = E]
    = (α · ħ · c · Z₁ · Z₂) / E              [через константу тонкої структури α]
```

Для типових кінетичних енергій протонів у сонячному ядрі `E = 10 кЕв = 0.010 МЕв` класична точка повороту становить:

```
r_c = (197.327 МЕв · фм / 137.036) / 0.010 МЕв   [підстановка фізичних констант]
    = 1.440 МЕв · фм / 0.010 МЕв                 [спрощення чисельника]
    = 144 фм                                     [обчислення радіуса повороту]
```

Оскільки радіус ефективної дії привабливих сильних ядерних сил `r_n` (радіус притягання ядерного потенціалу) становить лише близько `1.4 фм`, протони в класичній фізиці розділені нездоланним потенціальним бар'єром шириною понад `140 фм`. У класичній механіці Ньютона злиття за таких умов є абсолютно неможливим.

## Квантово-механічне тунелювання у ВКБ-наближенні

За квантовою механікою хвильова функція частинки `Ψ(r)` під бар'єром задовільняє радіальне рівняння Шредінґера для s-хвилі (з нульовим орбітальним моментом `l = 0`):

```
(d²Ψ / dr²) + (2·μ / ħ²) · [E - V(r)] · Ψ = 0
```

У підбар'єрній області (`r_n < r < r_c`) величина `V(r) > E`, тому хвильова функція загасає експоненційно. Наближення Вентцеля — Крамерса — Бріллюена (ВКБ) дає коефіцієнт проникності бар'єра `P(E)` як квадрат відношення амплітуди хвильової функції на виході з бар'єра до амплітуди на вході:

```
P(E) = exp(-2 · G)
```

Де інтеграл дій Ґамова `G` обчислюється вздовж усієї підбар'єрної траєкторії:

```
G = (1/ħ) · ∫ [від r_n до r_c] √(2·μ·(V(r) - E)) dr
```

Підставляючи вираз для кулонівського потенціалу `V(r) = E · (r_c / r)`, отримуємо:

```
G = (1/ħ) · √(2·μ·E) · ∫ [від r_n до r_c] √((r_c / r) - 1) dr
```

Оскільки ширина ядерної ями `r_n ≈ 1.4 фм` значно менша за радіус повороту `r_c ≈ 144 фм` (`r_n / r_c < 0.01`), нижню межу інтегрування можна укласти до нуля `r_n → 0` без втрати точності. Застосуємо тригонометричну заміну змінної:

```
r = r_c · cos²(θ),   dr = -2 · r_c · cos(θ) · sin(θ) dθ
```

Інтеграл перетворюється до вигляду:

```
∫ [від 0 до r_c] √((r_c / r) - 1) dr = 2 · r_c · ∫ [від 0 до π/2] sin²(θ) dθ
                                     = 2 · r_c · (π / 4)
                                     = (π / 2) · r_c     [обчислення геометрії бар'єра]
```

Підставляючи отримане значення геометрії назад у вираз для `G`:

```
G = (π/2) · (r_c / ħ) · √(2·μ·E)                                  [заміна інтеграла]
  = (π/2) · (e² / (4·π·ε₀·E·ħ)) · √(2·μ·E)                         [підстановка r_c]
  = (π · Z₁ · Z₂ · e²) / (4 · π · ε₀ · ħ · v)                    [використано v = √(2E/μ)]
```

Вводячи безрозмірний параметр Зоммерфельда `η(E)`:

```
η(E) = (Z₁ · Z₂ · e²) / (4 · π · ε₀ · ħ · v) = α · Z₁ · Z₂ · (c / v)
```

Отримуємо підсумкову формулу Ґамова для ймовірності квантового тунелювання:

```
P(E) = exp(-2 · π · η(E))
```

Виразимо показник `2·π·η` безпосередньо через кінетичну енергію `E` у кілоелектронвольтах (кЕв) для двох протонів (`Z₁ = Z₂ = 1`, `μ = m_p / 2`):

```
2 · π · η(E) = π · α · √(2 · μ · c² / E)                           [підстановка параметрів]
             = b / √E                                              [визначення константи b]
```

Знаходимо чисельне значення коефіцієнта Ґамова `b`:

```
b = π · (1 / 137.036) · √(2 · 469.44 · 10³ кЕв)                   [підстановка маси й констант]
  = (3.14159 / 137.036) · √(938.88 · 10³ кЕв)                      [обчислення підкореневого виразу]
  = 0.022925 · 968.96 кЕв¹/²                                      [добуток множників]
  = 31.28 кЕв¹/²                                                  [остаточний коефіцієнт b]
```

Таким чином, ймовірність тунелювання двох протонів при кінетичній енергії `E` (у кЕв) описується строгою квантовою формулою:

```
P(E) = exp(-31.28 / √E)
```

## Математичне виведення піку Ґамова та його ширини

У термодинамічно рівноважній плазмі за температури `T` швидкість реакції на одиницю об'єму пропорційна інтегралу від добутку густини Максвелл-Больцманівського розподілу частинок за швидкостями `f(E)` на квантовий переріз тунелювання `σ(E)`:

```
⟨σ·v⟩ = ∫ [від 0 до ∞] σ(E) · v(E) · f(E) dE
```

Оскільки `σ(E) ∝ (1/E) · exp(-b / √E)` та `f(E) ∝ E · exp(-E / (k_B · T))`, підінтегральна функція містить добуток двох протилежно спрямованих експонент:

```
I(E) = exp( - E / (k_B · T) - b / √E )
```

Знайдемо максимум цієї функції — енергію `E₀` (центр енергетичного вікна Ґамова). Беремо першу похідну від показника експоненти по енергії `E` та прирівнюємо її до нуля:

```
d/dE [ - E / (k_B · T) - b · E⁻¹/² ] = 0                           [умова екстремуму]
- 1 / (k_B · T) + (b / 2) · E⁻³/² = 0                             [взято похідну]
b / (2 · E₀³/²) = 1 / (k_B · T)                                   [перенесення членів]
E₀³/² = (b · k_B · T) / 2                                         [вираження E0]
E₀ = [ (b · k_B · T) / 2 ]²/³                                     [піднесення до степеня 2/3]
```

Для центрів зір типу Сонця за температури `T = 15.7 · 10⁶ К`:

```
k_B · T = (8.61733 · 10⁻⁵ еВ/К) · (15.7 · 10⁶ К)                   [конвертація у кЕв]
        = 1352.9 еВ = 1.3529 кЕв                                  [теплова енергія плазми]
```

Підставимо значення `b = 31.28 кЕв¹/²` та `k_B · T = 1.3529 кЕв`:

```
E₀ = [ (31.28 · 1.3529) / 2 ]²/³                                  [підстановка числових даних]
   = [ 42.318 / 2 ]²/³                                            [добуток чисельника]
   = [ 21.159 ]²/³                                                [ділення на 2]
   = 5.922 кЕв                                                    [остаточний центр піку Ґамова]
```

Для визначення ефективної ширини вікна Ґамова `ΔE` розкладемо показник експоненти `ϕ(E) = - E / (k_B · T) - b / √E` у ряд Тейлора поблизу точки максимуму `E₀`:

```
ϕ(E) ≈ ϕ(E₀) + (1/2) · ϕ''(E₀) · (E - E₀)²
```

Обчислимо другу похідну `ϕ''(E₀)`:

```
ϕ''(E) = d²/dE² [ - E / (k_B · T) - b · E⁻¹/² ] = - (3/4) · b · E⁻⁵/²
ϕ''(E₀) = - (3/4) · b · E₀⁻⁵/²                                    [друга похідна в точці E0]
```

Використовуючи співвідношення `b / (2 · E₀³/²) = 1 / (k_B · T)`, спрощуємо другу похідну:

```
ϕ''(E₀) = - (3/2) · (1 / (k_B · T · E₀))                         [підстановка умови максимуму]
```

Тоді підінтегральна функція апроксимується Гаусовою кривою:

```
I(E) ≈ I(E₀) · exp[ - (E - E₀)² / (2 · σ_G²) ]
```

Де дисперсія Гаусового піку `σ_G` дорівнює:

```
1 / (2 · σ_G²) = (3/4) · (1 / (k_B · T · E₀))
σ_G = √ ( (2 · k_B · T · E₀) / 3 )
```

Ефективна ширина Ґамового вікна `ΔE` визначається як ширина Гаусової кривої на висоті `1/e` (що відповідає `2 · √2 · σ_G` або апроксимативно `4 · σ_G / √2`):

```
ΔE = 4 · √( (E₀ · k_B · T) / 3 )                                  [формула ширини вікна]
   = 4 · √( (5.922 · 1.3529) / 3 )                                [підстановка значень]
   = 4 · √( 8.012 / 3 )                                           [добуток під коренем]
   = 4 · √2.6706                                                  [ділення на 3]
   = 4 · 1.634 = 6.536 кЕв                                        [остаточна ширина вікна]
```

## Астрофізичний S-фактор та квантовий розрахунок перерізу

Переріз ядерної реакції `σ(E)` параметризується виділенням двох відомих енергетичних залежностей: геометричного фактора де-бройлівської довжини хвилі `1/E` та фактора кулонівського тунелювання `exp(-2·π·η)`:

```
σ(E) = (S(E) / E) · exp(-2·π·η)
```

Величина `S(E)` називається астрофізичним S-фактором. Для ядерних реакцій, що протікають за рахунок сильної ядерної взаємодії (без зміни ізотопічного спіну), S-фактор слабко залежить від енергії і має масштаб `S(0) ~ 100 кЕв · барн`.

Проте реакція `p + p → ²H + e⁺ + νₑ` є реакцією слабої взаємодії. Перетворення протона на нейтрон регулюється фермієвським та ґамов-теллерівським операторами бета-розпаду. Теоретичний розрахунок малого S-фактора при нульовій енергії `S₁₁(0)` базується на квантово-механічному розрахунку матричного елемента переходу:

```
S₁₁(0) = (8·π / c) · G_F² · g_A² · (m_p · c²) · (ħ / (m_p · c))³ · |Λ|²
```

Де:
- `G_F ≈ 1.16637 · 10⁻⁵ ГЕв⁻²` — константа Фермі слабої взаємодії;
- `g_A ≈ 1.2754` — аксіально-векторна константа зв'язку нуклонів у ядрі;
- `|Λ|² ≈ 6.0` — квадратичний матричний елемент перекриття хвильових функцій початкового незв'язаного протон-протонного стану `³S₁` та кінцевого зв'язаного стану дейтерію `³S₁ + ³D₁`.

Чисельне значення S-фактора для первинної реакції pp-ланцюжка становить:

```
S₁₁(0) = 4.01 · 10⁻²² кЕв · барн = 4.01 · 10⁻²⁵ МЕв · барн
```

Розрахуємо мікроскопічний переріз реакції `σ(E₀)` безпосередньо в центрі піку Ґамова `E₀ = 5.922 кЕв`:

```
P(E₀) = exp(-31.28 / √5.922) = exp(-31.28 / 2.4335)
      = exp(-12.854) ≈ 2.615 · 10⁻⁶                               [імовірність тунелювання]

σ(E₀) = (4.01 · 10⁻²² кЕв · барн / 5.922 кЕв) · (2.615 · 10⁻⁶)    [підстановка у формулу]
      = (6.771 · 10⁻²³ барн) · (2.615 · 10⁻⁶)                     [розрахунок S/E]
      = 1.771 · 10⁻²⁸ барн = 1.771 · 10⁻⁵² см²                    [переріз реакції в см²]
```

## Кількісний розрахунок часу життя протона у ядрі Сонця

Визначимо концентрацію протонів `n_p` у центрі Сонця при густині `ρ = 150 г/см³ = 150 · 10³ кг/м³` та масовій частці водню `X = 0.35`:

```
n_p = (ρ · X) / m_p                                               [формула концентрації]
    = (150 · 10³ кг/м³ · 0.35) / (1.67262 · 10⁻²⁷ кг)             [підстановка параметрів Сонця]
    = 52.5 · 10³ кг/м³ / (1.67262 · 10⁻²⁷ кг)                     [добуток маси водню в м³]
    = 3.1388 · 10³¹ м⁻³ = 3.1388 · 10²⁵ см⁻³                      [концентрація у см⁻³]
```

Усереднений по Максвелл-Больцманівському розподілу добуток перерізу на відносну швидкість `⟨σ·v⟩₁₁` обчислюється аналітично інтегруванням піку Ґамова:

```
⟨σ·v⟩₁₁ = √(8 / (π · μ)) · (1 / (k_B · T)³/²) · S₁₁(0) · ∫ [від 0 до ∞] exp(-E/(k_B T) - b/√E) dE
```

За температур Сонця `T = 15.7 МК` чисельне значення інтеграла дає:

```
⟨σ·v⟩₁₁ ≈ 1.18 · 10⁻⁴³ см³/с
```

Середній час очікування `τ_p` конкретного протона до моменту його успішного злиття в дейтерій дорівнює:

```
τ_p = 1 / (n_p · ⟨σ·v⟩₁₁)                                        [середній час життя]
    = 1 / (3.1388 · 10²⁵ см⁻³ · 1.18 · 10⁻⁴³ см³/с)              [підстановка обчислених величин]
    = 1 / (3.7038 · 10⁻¹⁸ с⁻¹)                                   [частота зіткнень на 1 протон]
    = 2.700 · 10¹⁷ секунд                                        [час у секундах]
```

Переведемо отриманий результат у роки:

```
τ_p = 2.700 · 10¹⁷ с / (3.15576 · 10⁷ с/рік)                      [переведення в роки]
    = 8.556 · 10⁹ років ≈ 8.6 мільярдів років                     [остаточний час життя протона]
```

Отже, математичний розрахунок підтверджує: саме квантово-механічна природа слабої взаємодії та кулонівський бар'єр роблять час життя протона порівнянним із загальним часом еволюції Всесвіту, забезпечуючи стабільну життєдіяльність Сонця.
