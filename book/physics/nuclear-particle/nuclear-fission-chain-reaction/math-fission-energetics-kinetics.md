# 🧮 Математична модель деформаційного бар'єра та кінетики нейтронів

Математичний опис поділу атомного ядра та ланцюгової реакції спирається на дві теоретичні системи: макроскопічну краплинну модель Бора–Вілера, яка описує термодинаміку й геометрію деформаційного бар'єра ядра, та систему диференціальних рівнянь точкової кінетики реактора, що визначає часову динаміку щільності нейтронного потоку з урахуванням запізнілих нейтронів.

---

### 1. Краплинна модель Бора–Вілера та параметр дільності

Масова енергетика атомного ядра у краплинній моделі визначається напівемпіричною формулою Вайцзеккера для енергії зв'язку `E_B(A, Z)`:

```
E_B(A, Z) = a_v · A - a_s · A^(2/3) - a_c · (Z² / A^(1/3)) - a_a · ((A - 2Z)² / A) + δ(A, Z)
```

де значення коефіцієнтів становлять:
- `a_v ≈ 15.78 МеВ` (об'ємна енергія взаємодії сусідніх нуклонів);
- `a_s ≈ 17.80 МеВ` (поверхнева енергія ненасичених нуклонів на кордоні ядра);
- `a_c ≈ 0.71 МеВ` (кулонівська енергія відштовхування протонів);
- `a_a ≈ 23.70 МеВ` (асиметрична енергія нерівності чисел протонів і нейтронів);
- `δ(A, Z)` — член спарування однаково орієнтованих спінів однакових нуклонів.

При передачі ядру енергії збудження воно виходить зі сферичної форми. Відхилення форми від сфери паразитується за допомогою розкладу радіуса поверхні `R(θ)` у ряд за поліномами Лежандра `P_n(cos θ)`. Для опису видовження еліпсоїда обертання достатньо врахувати квадрупольну деформацію з малим безрозмірним параметром `ε`:

```
R(θ) = R_0 · (1 + ε · P_2(cos θ))
```

де `R_0 = r_0 · A^(1/3)` (при `r_0 ≈ 1.2` фм) — радіус еквівалентної сфери.

Умова незмінності об'єму несжимаємої ядерної рідини при квадрупольній деформації виконується автоматично у другому порядку по `ε`. Зміна площі поверхні ядра `S(ε)` та середньої відстані між зарядами супроводжується коригуванням поверхневої `E_S` та кулонівської `E_C` енергій:

```
E_S(ε) = E_S0 · (1 + (2/5) · ε²)
E_C(ε) = E_C0 · (1 - (1/5) · ε²)
```

де `E_S0 = a_s · A^(2/3)` та `E_C0 = a_c · (Z² / A^(1/3))` — енергетичні значення сферичного ядра.

Різниця потенціальної енергії `ΔE(ε)` між деформованим та початковим сферичним станом ядра становить:

```
ΔE(ε) = [E_S(ε) + E_C(ε)] - [E_S0 + E_C0]
       = E_S0 · (2/5) · ε² - E_C0 · (1/5) · ε²
       = (1/5) · ε² · (2 · E_S0 - E_C0)
```

Сферична конфігурація ядра є стійкою відносно малих деформацій лише доти, доки коефіцієнт при `ε²` залишається позитивним (`ΔE(ε) > 0`), що вимагає виконання нерівності:

```
2 · E_S0 > E_C0
```

Якщо кулонівське відштовхування перевищує подвійну поверхневу енергію (`E_C0 ≥ 2 · E_S0`), ядро втрачає стійкість і спонтанно розривається без жодного бар'єра. Умовою повної втрати деформаційного бар'єра є досягнення **параметром дільності** `x` значення одиниці:

```
x = E_C0 / (2 · E_S0) = (a_c · Z² / A^(1/3)) / (2 · a_s · A^(2/3)) = (a_c / (2 · a_s)) · (Z² / A)
```

Підставляючи числові значення емпіричних коефіцієнтів `a_c = 0.71 МеВ` та `a_s = 17.8 МеВ`:

```
(Z² / A)_crit = (2 · a_s) / a_c ≈ (2 · 17.8) / 0.71 ≈ 50.13
```

Таким чином, параметр дільності `x` записується через вираз:

```
x = (Z² / A) / 50.13
```

Для ядра урану-235 `Z = 92`, `A = 235`, що дає `Z² / A ≈ 35.98`, а параметр дільності `x ≈ 0.718`. Оскільки `x < 1`, існує скінченний деформаційний бар'єр поділу `E_b`.

Для обчислення точної висоти бар'єра поділу `E_b` Бор і Вілер розклали потенціальну енергію деформації до кубічного члена по `(1 - x)`:

```
E_b = E_S0 · (98 / 105) · (1 - x)³ ≈ 0.725 · A^(2/3) · (1 - x)³  [МеВ]
```

Для ядра `²³⁵U` це формула дає виражене значення бар'єра `E_b ≈ 5.8 МеВ`.

### 2. Диференціальні рівняння точкової кінетики реактора

Часова поведінка щільності нейтронів `n(t)` у локально нерухомому середовищі описується системою зв'язаних звичайних диференціальних рівнянь точкової кінетики. Система враховує миттєве розмноження та внесок `M = 6` груп запізнілих нейтронів:

```
dn / dt = ((ρ(t) - β) / l*) · n(t) + ∑ [ λ_i · C_i(t) ]    (i = 1 ... 6)

dC_i / dt = (β_i / l*) · n(t) - λ_i · C_i(t)                (i = 1 ... 6)
```

Позначення та фізична розмірність усіх змінних моделі:
- `n(t)` — щільність нейтронів у середовищі [`см⁻³`], пропорційна тепловій потужності реактора `P(t)`;
- `C_i(t)` — об'ємна концентрація ядер-попередників `i`-ї групи запізнілих нейтронів [`см⁻³`];
- `ρ(t) = (k_eff - 1) / k_eff` — реактивність середовища [безрозмірна величина];
- `β_i` — парціальна частка запізнілих нейтронів `i`-ї групи (`β = ∑ β_i`);
- `λ_i` — стала розпаду ядер-попередників `i`-ї групи [`с⁻¹`], зв'язана з періодом піврозпаду `λ_i = ln 2 / T_1/2,i`;
- `l*` — середній час життя одного покоління миттєвих нейтронів [`с`].

### 3. Рівняння зворотного часу (Inhour Equation) та аналіз коренів

Розглянемо аналітичний розв'язок системи для випадку стрибкоподібного введення постійної реактивності `ρ = const` при `t = 0`. Оскільки система рівнянь є лінійною зі сталими коефіцієнтами, її розв'язок шукають у вигляді суми експоненціальних компонент:

```
n(t) = ∑ [ A_k · exp(ω_k · t) ]
C_i(t) = ∑ [ C_(i,k) · exp(ω_k · t) ]
```

Підставляючи окрему гармоніку `n(t) = A · exp(ω · t)` та `C_i(t) = C_(0,i) · exp(ω · t)` у друге рівняння системи:

```
ω · C_(0,i) = (β_i / l*) · A - λ_i · C_(0,i)
```

Звідси виражаємо амплітуду концентрації ядер-попередників через амплітуду нейтронного потоку `A`:

```
C_(0,i) = (β_i / (l* · (ω + λ_i))) · A
```

Підставляючи це значення у перше рівняння кінетики для `dn / dt`:

```
ω · A = ((ρ - β) / l*) · A + ∑ [ λ_i · (β_i / (l* · (ω + λ_i))) · A ]
```

Скорочуючи ненульову амплітуду `A` та множачи обидві частини рівняння на час життя покоління `l*`:

```
ω · l* = ρ - β + ∑ [ (λ_i · β_i) / (ω + λ_i) ]
```

Переносячи `ρ` в ліву частину та групуючи доданки за допомогою тотожності `β = ∑ β_i`:

```
ρ = ω · l* + β - ∑ [ (λ_i · β_i) / (ω + λ_i) ]
  = ω · l* + ∑ [ β_i - (λ_i · β_i) / (ω + λ_i) ]
  = ω · l* + ∑ [ (β_i · (ω + λ_i - λ_i)) / (ω + λ_i) ]
  = ω · l* + ∑ [ (ω · β_i) / (ω + λ_i) ]
```

Виражаючи період розгону реактора як `τ = 1 / ω`, отримуємо класичне **рівняння зворотного часу (Inhour Equation)**:

```
ρ = (l* / τ) + ∑ [ β_i / (1 + λ_i · τ) ]
```

Це рівняння має `M + 1 = 7` дійсних коренів `ω_k`. При позитивній реактивності `ρ > 0` шість коренів є негативними (вони відповідають швидко згасаючим переходним процесам), і лише один корінь `ω₀ > 0` є позитивним. Саме він визначає головну сталу асимптотичного експоненціального розгону реактора:

```
n(t) → A₀ · exp(t / τ_asymptotic)
```

### 4. Фізичні граничні режими розгону реактора

Математичний аналіз рівняння зворотного часу дозволяє отримати спрощені асимптотичні співвідношення для двох фундаментальних практичних режимів:

#### Режим запізнілої надкритичності (`0 < ρ < β`)
У цьому діапазоні реактивність є меншою за частку запізнілих нейтронів. Швидкість зростання потоку є малою, тому `ω ≪ λ_i` для всіх `i`. Розкладаючи знаменник дробу у ряд Тейлора:

```
1 / (1 + λ_i · τ) ≈ 1 - (1 / (λ_i · τ))
```

Підставляючи це розкладення у рівняння зворотного часу:

```
ρ ≈ (l* / τ) + ∑ [ β_i · (1 - 1 / (λ_i · τ)) ]
  = (l* / τ) + β - β + ∑ [ β_i / (λ_i · τ) ]
  = (1 / τ) · [ l* + ∑ (β_i / λ_i) ]
```

Величина у дужках являє собою ефективний час життя нейтронного покоління `⟨l⟩`:

```
⟨l⟩ = l* + ∑ (β_i / λ_i) ≈ l* + β · ⟨T_delayed⟩
```

Для урану-235 `∑ (β_i / λ_i) ≈ 0.083` с, тому `⟨l⟩ ≈ 0.083` с. Період розгону реактора визначається виразом:

```
τ ≈ ⟨l⟩ / ρ ≈ 0.083 / ρ  [с]
```

При позитивній реактивності `ρ = 0.001` (`0.1% Δk/k` або `100 pcm`), період реактора становить `τ ≈ 83` секунди. Це дає достатньо часу для роботи системи керування та захисту.

#### Режим миттєвої надкритичності (`ρ ≥ β`)
Коли реактивність дорівнює або перевищує частку запізнілих нейтронів (`ρ ≥ β`), реактор розганяється на миттєвих нейтронах. Для значення `ω ≫ λ_max` дріб під сумою прямує до нуля, і рівняння спрощується до:

```
ρ - β ≈ ω · l*  ⇒  ω ≈ (ρ - β) / l*
```

Асимптотичний період реактора падає до:

```
τ = l* / (ρ - β)
```

При `l* = 10⁻⁴` с та реактивності `ρ = 0.008` (`ρ - β = 0.0015`):

```
τ = 10⁻⁴ / 0.0015 ≈ 0.067 с = 67 мілісекунд
```

Потужність реактора за одну секунду зростає у `exp(1 / 0.067) = exp(15) ≈ 3.2 · 10⁶` разів, що призводить до руйнування активної зони.
