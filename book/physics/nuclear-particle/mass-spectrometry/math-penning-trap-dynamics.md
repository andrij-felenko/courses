# 🧮 Аналітична динаміка іона в пастці Пеннінга та інваріантні частоти

Ця математична вставка містить аналітичне виведення рівнянь руху заряду у квадрупольному електростатичному та однорідному магнітному полях пастки Пеннінга, розкладання руху на фундаментальні власні моди та доведення теореми інваріантності Брауна — Ґабріельсе. Це виведення є фундаментальним підґрунтям прецизійної мас-спектрометрії, оскільки воно показує, як прецизійне вимірювання трьох незалежних частот дає змогу виключити систематичні похибки від неідеальності електричного поля та отримати масу ядра з відносною точністю вище `10⁻¹⁰`.

---

### 1. Конструкція електромагнітного потенціалу та фізична мотивація

Для довготривалого утримання поодиноких charged частинок у обмеженій області вакуумного об'єму необхідно створити тривимірну потенціальну яму. Однак теорема Ірншоу (*Earnshaw's theorem*) підтверджує, що суто статичне електростатичне поле не здатне забезпечити стійку тривимірну рівновагу для вільного заряду, оскільки дивергенція електричного поля у порожньому просторі дорівнює нулю `∇·E = 0`, що унеможливлює існування тривимірного мінімуму електростатичного потенціалу `V(x,y,z)`.

Щоб подолати це фундаментальне обмеження, пастка Пеннінга поєднує два незалежні електромагнітні поля:
1. Однорідне стаціонарне магнітне поле `B = B₀ · k̂`, спрямоване вздовж вертикальної осі симетрії `z`.
2. Двопорожнинний квадрупольний електростатичний потенціал `V(x, y, z)`, створений системним поєднанням трьох гіперболічних електродів — одного центрального кільцевого електрода та двох торцевих електродів-ковпачків (*endcaps*).

Математична форма квадрупольного потенціалу задається виразом:

```
V(x, y, z) = U₀ / (2 · d²) · (2 · z² - x² - y²)
```

де `U₀` означає потенціальну різницю напруг між торцевими та кільцевим електродами, а `d` — характерний геометричний параметр пастки, визначений через мінімальну відстань від центра пастки до торцевих електродів `z₀` та радіус кільцевого електрода `r₀`:

```
d² = (1 / 2) · (z₀² + (1 / 2) · r₀²)
```

Напруженість електричного поля `E = -∇V` отримується диференціюванням потенціалу за відповідними просторовими координатами:

```
E_x = -∂V/∂x = (U₀ / d²) · x      [диференціювання V за координатами x]
E_y = -∂V/∂y = (U₀ / d²) · y      [диференціювання V за координатами y]
E_z = -∂V/∂z = -2 · (U₀ / d²) · z  [диференціювання V за координатами z]
```

Фізичний зміст цього поля полягає у тому, що вздовж осі `z` створюється гармонічна фокусувальна сила `F_z = q · E_z = -2 · q · (U₀ / d²) · z`, яка повертає позитивний заряд `q` до центра пастки (при `U₀ > 0`). Проте у радіальній площині `(x, y)` електричне поле є дефокусувальним: сила `F_r = q · (U₀ / d²) · r` відштовхує частинку геть від центральної осі. Для запобігання втечі частинки на кільцевий електрод накладається сильне магнітне поле `B₀`, яке змушує частинку здійснювати швидке циклотронне обертання у радіальній площині.

### 2. Рівняння руху та відокремлення аксіальної координати

Динаміка іона з масою спокою `m` та електричним зарядом `q` описується рівнянням векторної сили Лоренца `F = q · (E + v × B)` у рамках другого закону Ньютона:

```
m · d²r/dt² = q · [ E + (dr/dt) × B₀ · k̂ ]
```

Обчислимо векторний добуток для швидкості `v = ẋ · î + ẏ · ĵ + ż · k̂` та магнітного поля `B = B₀ · k̂`:

```
v × B = (ẋ · î + ẏ · ĵ + ż · k̂) × (B₀ · k̂) = -ẋ · B₀ · ĵ + ẏ · B₀ · î
```

Підставляючи компонентні значення електричного та магнітного полів у вихідне рівняння руху, отримуємо систему трьох зв'язаних диференціальних рівнянь другого порядку:

```
m · ẍ - q · B₀ · ẏ - (q · U₀ / d²) · x = 0     [проекція руху на вісь X]
m · ÿ + q · B₀ · ẋ - (q · U₀ / d²) · y = 0     [проекція руху на вісь Y]
m · z̈ + (2 · q · U₀ / d²) · z = 0              [проекція руху на вісь Z]
```

Для спрощення математичного аналізу введемо фундаментальні фізичні частоти системи:
- Вільна циклотронна частота частинки у чистому магнітному полі: `ω_c = q · B₀ / m`.
- Аксіальна частота осциляцій у гармонічному електричному потенціалі: `ω_z = √( 2 · q · U₀ / (m · d²) )`.

Поділивши кожне рівняння на масу частинки `m`, зводимо систему до канонічного вигляду:

```
ẍ - ω_c · ẏ - (1 / 2) · ω_z² · x = 0           [рівняння радіальної осі X]
ÿ + ω_c · ẋ - (1 / 2) · ω_z² · y = 0           [рівняння радіальної осі Y]
z̈ + ω_z² · z = 0                              [рівняння аксіальної осі Z]
```

### 3. Аналіз аксіального руху частинки

Рівняння для координати `z` виявляється повністю відокремленим від радіальних змінних `x` та `y`. Воно являє собою рівняння класичного гармонічного осцилятора без демпфування:

```
z̈ + ω_z² · z = 0
```

Загальний розв'язок цього рівняння задається гармонічною функцією з амплітудою `A_z` та початковою фазою `φ_z`:

```
z(t) = A_z · cos(ω_z · t + φ_z)
```

Частота аксіального руху `ω_z` визначається виключно масою іона, його зарядом та геометричною градієнтністю електричного поля `U₀ / d²`. Вона є абсолютно незалежною від величини магнітного поля `B₀` і в експериментальних пастках знаходиться у кілогерцовому діапазоні (`100...500 кГц`).

### 4. Комплексний аналіз радіального руху та розрахунок власних частот

Для розв'язання системи двох зв'язаних диференціальних рівнянь другого порядку для координат `x(t)` та `y(t)` застосуємо метод комплексної координати. Введемо комбіновану комплексну змінну радіального положення частинки:

```
u(t) = x(t) + i · y(t)
```

Помножимо рівняння для осі `Y` на уявну одиницю `i` і додамо його до рівняння для осі `X`:

```
(ẍ + i · ÿ) + i · ω_c · (ẋ + i · ẏ) - (1 / 2) · ω_z² · (x + i · y) = 0
```

Використовуючи визначення змінної `u(t)` та її часових похідних `u̇ = ẋ + i · ẏ` і `ü = ẍ + i · ÿ`, ми перетворюємо систему двох реальних рівнянь на єдине комплексне диференціальне рівняння другого порядку з постійними коефіцієнтами:

```
ü + i · ω_c · u̇ - (1 / 2) · ω_z² · u = 0
```

Шукаємо частковий розв'язок цього рівняння у вигляді гармонічної комплексної експоненти `u(t) = u₀ · e^(-i · ω · t)`, де `ω` — невідома власна частота обертання частинки у радіальній площині.

Обчислимо першу та другу похідну від обраного анзацу:

```
u̇ = -i · ω · u₀ · e^(-i · ω · t) = -i · ω · u
ü = (-i · ω)² · u₀ · e^(-i · ω · t) = -ω² · u
```

Підставляючи вирази похідних у комплексне диференціальне рівняння, отримуємо:

```
-ω² · u + i · ω_c · (-i · ω · u) - (1 / 2) · ω_z² · u = 0
```

Оскільки `i · (-i) = -i² = 1`, а `u(t) ≠ 0`, скорочуємо на `u` і отримуємо секулярне характеристичне рівняння для частоти `ω`:

```
-ω² + ω_c · ω - (1 / 2) · ω_z² = 0
```

Помноживши обидві частини на `-1`, зводимо його до стандартного квадратного рівняння:

```
ω² - ω_c · ω + (1 / 2) · ω_z² = 0
```

Розв'яжемо це квадратне рівняння через дискримінант `D = ω_c² - 4 · 1 · (1/2) · ω_z² = ω_c² - 2 · ω_z²`:

```
ω = ( ω_c ± √( ω_c² - 2 · ω_z² ) ) / 2
```

Виносячи множник `1/2` під корінь як `1/4`, отримуємо точні аналітичні вирази для двох власних радіальних частот руху частинки у пастці Пеннінга:

```
ω_+ = (1 / 2) · ω_c + √( (1 / 4) · ω_c² - (1 / 2) · ω_z² )  [модифікована циклотронна частота]
ω_- = (1 / 2) · ω_c - √( (1 / 4) · ω_c² - (1 / 2) · ω_z² )  [магнетронна частота]
```

Для забезпечення стабільного утримання частинки в радіальному напрямку вираз під коренем обов'язково має бути додатним `(1/4)·ω_c² > (1/2)·ω_z²`. Це накладає фундаментальну критеріальну умову стабільності пастки Пеннінга:

```
B₀² > 4 · m · U₀ / (q · d²)
```

Якщо магнітне поле слабше за це критичне значення, електростатичне відштовхування переважає силу Лоренца, і частинка негайно викидається на стінку кільцевого електрода.

### 5. Алгебраїчні тотожності та теорема інваріантності Брауна — Ґабріельсе

Зв'язок між власне вимірюваними частотами у пастці та фундаментальною масою частинки ґрунтується на математичних властивостях коренів характеристичного квадратного рівняння. За теоремою Вієта для рівняння `ω² - ω_c · ω + (1/2)·ω_z² = 0` виконуються два співвідношення:

```
ω_+ + ω_- = ω_c                              [перше співвідношення Вієта: сума частот]
ω_+ · ω_- = (1 / 2) · ω_z²                   [друге співвідношення Вієта: добуток частот]
```

Застосуємо тотожність для суми квадратів двох величин `a² + b² = (a + b)² - 2·a·b` до власних частот `ω_+` та `ω_-`:

```
ω_+² + ω_-²
= (ω_+ + ω_-)² - 2 · ω_+ · ω_-               [алгебраїчна тотожність розкладання]
= ω_c² - 2 · [ (1 / 2) · ω_z² ]             [підстановка виразів Вієта]
= ω_c² - ω_z²
```

Перенісши `ω_z²` у ліву частину рівняння, отримуємо **теорему інваріантності Брауна — Ґабріельсе**:

```
ω_c² = ω_+² + ω_-² + ω_z²
```

#### Глибокий фізичний зміст інваріантної формули
У реальних експериментальних умовах досягти ідеальної симетрії електродів неможливо: наявні геометричні недосконалості виготовлення, локальні вакуумні забруднення, а також неминучий кутовий нахил магнітного поля `B₀` відносно геометричної осі пастки `z` на малий кут `θ`. 

Ці дефекти призводять до того, що прості суми `ω_+ + ω_-` починають сильно залежати від напруги `U₀` та просторового положення частинки. Проте Чарльз Браун та Джеральд Ґабріельсе у 1982 році математично довели, що у першому порядку теорії збурень за малими кутами нахилу `θ` та неквадрупольностями потенціалу (квадрупольна еліптичність, октупольні гармоніки) сума квадратів трьох реальних власних частот `ω_+² + ω_-² + ω_z²` залишається строго рівною квадрату вільної циклотронної частоти `ω_c² = (q·B₀ / m)²`.

Завдяки цьому вимірювання трьох окремих частот `(ω_+, ω_-, ω_z)` дає змогу вичислити фундаментальну масу ядра `m` абсолютно незалежно від дефектів геології електродів пастки.

### 6. Структура іонних орбіт, енергетичні характеристики та радіочастотне збудження

Повний часовий рух іона є суперпозицією трьох незалежних геометричних рухів у тривимірному просторі:

```
x(t) = r_+ · cos(ω_+ · t + φ_+) + R_- · cos(ω_- · t + φ_-)
y(t) = -r_+ · sin(ω_+ · t + φ_+) - R_- · sin(ω_- · t + φ_-)
z(t) = A_z · cos(ω_z · t + φ_z)
```

Траєкторія частинки у радіальній площині є складною епіциклоїдою: швидке циклотронне коло радіуса `r_+` дрейфує вздовж повільного магнетронного кола радіуса `R_-`, одночасно здійснюючи вертикальні аксіальні коливання з амплітудою `A_z`.

Важливо підкреслити енергетичні риси кожної з трьох мод. Кінетична енергія модифікованого циклотронного руху `E_k(+) = (1/2) · m · ω_+² · r_+²` є повністю додатною і зростає зі збільшенням радіуса `r_+`. Аксіальна енергія осцилятора `E_z = (1/2) · m · ω_z² · A_z²` також є додатною.

Натомість повна потенціальна та кінетична енергія магнетронного руху у кулонівському потенціалі є **від'ємною**:

```
E_- = (1 / 2) · m · (ω_-² - (1 / 2) · ω_z²) · R_-² ≈ - (1 / 2) · m · ω_+ · ω_- · R_-²
```

Це означає, що магнетронний рух є метастабільним. Якщо частинка втрачає енергію (наприклад, за рахунок зіткнень із залишками нейтрального газу або випромінювання), магнетронний радіус `R_-` не зменшується, а навпаки — зростає! Частинка повільно віддаляється від центра пастки у напрямку до кільцевого електрода. 

Для виправлення цього ефекту перед кожним вимірюванням застосовують активне **буферне газове охолодження** (*buffer-gas cooling*): квадрупольне радіочастотне поле перекачує енергію з метастабільного магнетронного руху `ω_-` у циклотронний `ω_+`, де вона швидко дисипується через зіткнення з легкими атомами гелію (`⁴He`) при тиску `10⁻⁴ мбар`. Це дає змогу сконцентрувати всі іони у точковому центрі пастки перед початком резонансного вимірювання.

Для конверсії одного типу руху в інший застосовують квадрупольне радіочастотне поле із частотою `ω_rf = ω_c = ω_+ + ω_-`. Таке ВЧ-поле викликає зв'язані періодичні осциляції між модифікованим циклотронним та магнетронним рухом. Через певний час збудження `T_conv = π / (2 · g)` (де `g` — амплітуда ВЧ-поля) магнетронна мода повністю переходить у циклотронну. Оскільки радіальна кінетична енергія циклотронного руху набагато більша за магнетронну `E_k(+) / E_k(-) = ω_+ / ω_- ≈ 1000`, таке конвертування різко збільшує радіальну енергію іона, що уможливлює його реєстрацію за часом прольоту до детектора (метод TOF-ICR).
