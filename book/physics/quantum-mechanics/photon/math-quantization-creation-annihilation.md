# 🧮 Квантування електромагнітного поля та фоківські стани

Математична формалізація концепції фотона спирається на процедуру канонічного вторинного квантування вільних електромагнітних хвиль у вакуумі. Опис фотонів як частинок виникає внаслідок розкладу класичного векторного потенціалу поля за нормальними коливальними модами та заміни гармонічних амплітуд операторами народження й знищення у Фоківському просторі станів.

## 1. Канонічний формалізм класичного електромагнітного поля

Розглянемо вільне електромагнітне поле у кубічній порожнині об'ємом `V = L³` зі періодичними граничними умовами Борна — фон Кармана. У відсутності вільних зарядів (`ρ = 0`) та струмів (`j = 0`) векторний потенціал `A(r, t)` у поперечному калібруванні Кулона задовольняє умову соленоїдальності:

```
∇ · A(r, t) = 0
```

При цьому скалярний потенціал тотожно дорівнює нулю (`Φ = 0`). Рівняння руху для векторного потенціалу, що випливає з рівнянь Максвелла, зводиться до однорідного хвильового рівняння:

```
∇² A(r, t) - (1 / c²) · (∂² A(r, t) / ∂ t²) = 0
```

Для переходу до канонічних змінних розкладемо векторний потенціал `A(r, t)` у потрійний ряд Фур'є за ортонормованими плоскими монохроматичними хвилями:

```
u_{k,λ}(r) = (1 / √V) · ε_{k,λ} · exp(i · k · r)
```

де `k = (2π/L) · (n_x, n_y, n_z)` — хвильовий вектор (`n_x, n_y, n_z ∈ ℤ`), a `ε_{k,λ}` (`λ ∈ {1, 2}`) — два ортогональні одиничні вектори поляризації, які задовольняють умови ортогональності та повноти у калібруванні Кулона:

```
k · ε_{k,λ} = 0
ε_{k,λ} · ε_{k,λ'} = δ_{λ,λ'}
```

Частота моди з хвильовим вектором `k` визначається дисперсійним співвідношенням у вакуумі `ω_k = c · |k|`.

Розклад векторного потенціалу `A(r, t)` та напруженостей електричного `E(r, t)` і магнітного `B(r, t)` полів через комплексно-спряжені амплітуди `a_{k,λ}(t)` має вигляд:

```
A(r, t) = ∑_{k,λ} √( ℏ / (2 · ε_0 · V · ω_k) ) · [ a_{k,λ}(t) · ε_{k,λ} · exp(i · k · r) + a*_{k,λ}(t) · ε*_{k,λ} · exp(-i · k · r) ]
```

Напруженості полів виражаються через векторний потенціал за стандартними формулами електродинаміки:

```
E(r, t) = - ∂A / ∂t = i · ∑_{k,λ} √( (ℏ · ω_k) / (2 · ε_0 · V) ) · [ a_{k,λ}(t) · ε_{k,λ} · exp(i · k · r) - a*_{k,λ}(t) · ε*_{k,λ} · exp(-i · k · r) ]
```

```
B(r, t) = ∇ × A = i · ∑_{k,λ} √( ℏ / (2 · ε_0 · V · ω_k) ) · [ a_{k,λ}(t) · (k × ε_{k,λ}) · exp(i · k · r) - a*_{k,λ}(t) · (k × ε*_{k,λ}) · exp(-i · k · r) ]
```

Повний класичний Гамільтоніан електромагнітного поля у вакуумі виражається інтегралом від густини енергії по всьому об'єму порожнини `V`:

```
H = (1 / 2) · ∫_V [ ε_0 · |E(r, t)|² + (1 / μ_0) · |B(r, t)|² ] d³r
```

Підставляючи розклади для `E` та `B` в інтеграл і використовуючи умови ортонормованості плоских хвиль `∫_V exp(i · (k - k') · r) d³r = V · δ_{k,k'}`, а також співвідношення `c² = 1 / (ε_0 · μ_0)` та `|(k × ε_{k,λ})|² = |k|² = ω_k² / c²`, перехресні добутки доданків скасовуються, і Гамільтоніан зводиться до суми енергій незалежних комплексних гармонічних осциляторів:

```
H = ∑_{k,λ} ℏ · ω_k · a*_{k,λ}(t) · a_{k,λ}(t)
```

Для переходу до дійсних канонічних змінних Гамільтона (узагальненої координати `q_{k,λ}` та узагальненого імпульсу `p_{k,λ}`) введеться канонічна заміна:

```
q_{k,λ} = √( ℏ / (2 · ω_k) ) · ( a_{k,λ} + a*_{k,λ} )
```

```
p_{k,λ} = -i · √( (ℏ · ω_k) / 2 ) · ( a_{k,λ} - a*_{k,λ} )
```

Виразивши комплексно-спряжені амплітуди `a` та `a*` через `q` і `p`:

```
a_{k,λ} = (1 / √(2 · ℏ · ω_k)) · ( ω_k · q_{k,λ} + i · p_{k,λ} )
```

```
a*_{k,λ} = (1 / √(2 · ℏ · ω_k)) · ( ω_k · q_{k,λ} - i · p_{k,λ} )
```

Гамільтоніан набуває канонічного вигляду суми стандартних речовинних гармонічних осциляторів маси `m = 1`:

```
H = ∑_{k,λ} [ (1 / 2) · p_{k,λ}² + (1 / 2) · ω_k² · q_{k,λ}² ]
```

Канонічні дужки Пуассона для класичних польових змінних задовольняють умови:

```
{ q_{k,λ}, p_{k',λ'} }_PB = δ_{k,k'} · δ_{λ,λ'}
```

```
{ q_{k,λ}, q_{k',λ'} }_PB = { p_{k,λ}, p_{k',λ'} }_PB = 0
```

## 2. Перехід до квантової теорії: канонічні комутаційні співвідношення

Згідно з канонічним квантуванням за Діраком, узагальнені координати `q` та імпульси `p` замінюються ермітовими квантовомеханічними операторами `q̂` та `p̂`, а дужка Пуассона замінюється комутатором за правилом `{A, B}_PB → (1 / (i · ℏ)) · [Â, B̂]`:

```
[ q̂_{k,λ}, p̂_{k',λ'} ] = i · ℏ · δ_{k,k'} · δ_{λ,λ'}
```

```
[ q̂_{k,λ}, q̂_{k',λ'} ] = [ p̂_{k,λ}, p̂_{k',λ'} ] = 0
```

Відповідно, комплексно-спряжені амплітуди `a_{k,λ}` та `a*_{k,λ}` стають сопряженими квантовими операторами: оператором знищення `â_{k,λ}` та оператором народження `â⁺_{k,λ}`.

Обчислимо комутатор між операторами `â` та `â⁺` для однієї й тієї ж моди, випустивши для стислості індекси `(k, λ)`:

```
[â, â⁺] = â · â⁺ - â⁺ · â
= [ (1 / √(2 ℏ ω)) · (ω q̂ + i p̂) ] · [ (1 / √(2 ℏ ω)) · (ω q̂ - i p̂) ] - [ (1 / √(2 ℏ ω)) · (ω q̂ - i p̂) ] · [ (1 / √(2 ℏ ω)) · (ω q̂ + i p̂) ]
= (1 / (2 ℏ ω)) · [ (ω q̂ + i p̂)(ω q̂ - i p̂) - (ω q̂ - i p̂)(ω q̂ + i p̂) ]
= (1 / (2 ℏ ω)) · [ -i ω q̂ p̂ + i ω p̂ q̂ - (i ω q̂ p̂ - i ω p̂ q̂) ]
= (1 / (2 ℏ ω)) · [ - 2 i ω (q̂ p̂ - p̂ q̂) ]
= (1 / (2 ℏ ω)) · [ - 2 i ω (i ℏ) ]      [оскільки [q̂, p̂] = i ℏ]
= (1 / (2 ℏ ω)) · ( 2 ℏ ω )
= 1
```

Таким чином, для операторів народження та знищення мод електромагнітного поля встановлено **бозонні канонічні комутаційні співвідношення**:

```
[ â_{k,λ}, â⁺_{k',λ'} ] = δ_{k,k'} · δ_{λ,λ'}
```

```
[ â_{k,λ}, â_{k',λ'} ] = [ â⁺_{k,λ}, â⁺_{k',λ'} ] = 0
```

Підставляючи вирази операторів `q̂` та `p̂` у квантовий Гамільтоніан, отримуємо оператор енергії:

```
Ĥ = (1 / 2) · ∑_{k,λ} [ p̂_{k,λ}² + ω_k² · q̂_{k,λ}² ]
= (1 / 2) · ∑_{k,λ} ℏ · ω_k · ( â_{k,λ} · â⁺_{k,λ} + â⁺_{k,λ} · â_{k,λ} )
```

Використовуючи комутатор `â_{k,λ} · â⁺_{k,λ} = â⁺_{k,λ} · â_{k,λ} + 1`, зводимо Гамільтоніан до остаточного вигляду:

```
Ĥ = ∑_{k,λ} ℏ · ω_k · ( â⁺_{k,λ} · â_{k,λ} + 1/2 ) = ∑_{k,λ} ℏ · ω_k · ( N̂_{k,λ} + 1/2 )
```

де `N̂_{k,λ} = â⁺_{k,λ} · â_{k,λ}` — ермітів оператор числа фотонів у моді `(k, λ)`.

## 3. Побудова Фоківського простору станів та алгебра операторів

Розглянемо одну моду поля з операторами `â`, `â⁺` та `N̂ = â⁺ â`.

Оскільки оператор `N̂` є ермітовим (`N̂⁺ = (â⁺ â)⁺ = â⁺ (â⁺)⁺ = â⁺ â = N̂`), його власні значення `n` є дійсними числами, а власні вектори `|n⟩` утворюють повний ортонормований базис у Гільбертовому просторі станів:

```
N̂ |n⟩ = n |n⟩
```

```
⟨n|m⟩ = δ_{n,m}
```

Обчислимо дії комутаторів `[N̂, â]` та `[N̂, â⁺]`:

```
[N̂, â] = (â⁺ â) â - â (â⁺ â) = â⁺ â² - (â⁺ â + 1) â = - â
```

```
[N̂, â⁺] = (â⁺ â) â⁺ - â⁺ (â⁺ â) = â⁺ (â⁺ â + 1) - â⁺² â = + â⁺
```

Застосуємо оператор `N̂` до вектора `â |n⟩`:

```
N̂ (â |n⟩) = (â N̂ + [N̂, â]) |n⟩ = (â n - â) |n⟩ = (n - 1) (â |n⟩)
```

Отже, якщо `|n⟩` є власним станом з власним значенням `n`, то `â |n⟩` є власним станом з власним значенням `n - 1`. Тобто оператор `â` знижує кількість фотонів на одиницю, звідки й походить його назва — **оператор знищення**.

Аналогічно для оператора `â⁺`:

```
N̂ (â⁺ |n⟩) = (â⁺ N̂ + [N̂, â⁺]) |n⟩ = (â⁺ n + â⁺) |n⟩ = (n + 1) (â⁺ |n⟩)
```

Оператор `â⁺` збільшує власне значення `n` на одиницю і є **оператором народження** фотона.

Норма вектора `â |n⟩` у гіпофізовому просторі квантових станів мусить бути невід'ємною:

```
||â |n⟩||² = ⟨n| â⁺ â |n⟩ = ⟨n| N̂ |n⟩ = n · ⟨n|n⟩ = n ≥ 0
```

Оскільки `n ≥ 0`, послідовне знищення фотонів оператором `â` не може тривати нескінченно. Має існувати нижній граничний стан з `n = 0`, для якого дія оператора знищення дає нульовий вектор:

```
â |0⟩ = 0
```

Цей стан `|0⟩` називається **вакуумним станом** (або квантовим вакуумом). З умови `n ≥ 0` випливає, що спектр власних значень оператора числа фотонів `N̂` складається з усіх цілих невід'ємних чисел:

```
n ∈ {0, 1, 2, 3, ...}
```

Визначимо нормувальні коефіцієнти `C_n` та `D_n` для операторів `â |n⟩ = C_n |n-1⟩` та `a⁺ |n⟩ = D_n |n+1⟩`:

```
|C_n|² = ⟨n| â⁺ â |n⟩ = n  ⇒  C_n = √n
```

```
|D_n|² = ⟨n| â â⁺ |n⟩ = ⟨n| (â⁺ â + 1) |n⟩ = n + 1  ⇒  D_n = √(n + 1)
```

Отже, дія операторів народження та знищення на фоківські стани описується точними тотожностями:

```
â |n⟩ = √n |n-1⟩
```

```
â⁺ |n⟩ = √(n + 1) |n+1⟩
```

Будь-який n-фотонний фоківський стан `|n⟩` можна явним чином побудувати дією `n` операторів народження `â⁺` на вакуумний стан `|0⟩`:

```
|n⟩ = ( (â⁺)ⁿ / √(n!) ) |0⟩
```

Багатомодовий фоківський простір (простір Фока) `ℋ_Fock` утворюється як ортогональна пряма сума n-фотонних секторів:

```
ℋ_Fock = ⨁_{n=0}^∞ ℋ_n
```

де кожен n-фотонний стан утворюється прямим тензорним добутком одномодових станів:

```
|n_{k_1,λ_1}, n_{k_2,λ_2}, ...⟩ = ∏_{i} ( ((â⁺_{k_i,λ_i})^{n_i}) / √(n_i!) ) |0⟩
```

Власне значення Гамільтоніана для даного стану дорівнює:

```
E = ∑_{i} ℏ · ω_{k_i} · ( n_i + 1/2 )
```

## 4. Алгебра оператора зсуву та когерентні стани Глаубера

Фоківські стани `|n⟩` описують квантові стани зі строго фіксованою кількістю частинок, проте середня напруженість електричного поля для них дорівнює нулю: `⟨n| E(r, t) |n⟩ = 0`. Вони не мають класичного аналога.

Для опису випромінювання класичного лазера з визначеною амплітудою та фазою Рой Глаубер у 1963 році ввів **когерентні стани** `|α⟩`.

Когерентний стан `|α⟩` визначається як власний стан оператора знищення `â` з комплексним власним значенням `α = |α| · exp(i · ϕ)`:

```
â |α⟩ = α |α⟩
```

Оскільки оператор `â` не є ермітовим (`â ≠ â⁺`), його власні значення `α` можуть бути довільними комплексними числами на комплексній фазовій площині.

Для побудови розкладу когерентного стану за базисом фоківських станів `|n⟩` представимо `|α⟩` у вигляді суми:

```
|α⟩ = ∑_{n=0}^∞ c_n |n⟩
```

Діючи оператором `â` на обидві частини рівняння:

```
â |α⟩ = ∑_{n=0}^∞ c_n · â |n⟩ = ∑_{n=1}^∞ c_n · √n |n-1⟩ = α · ∑_{n=0}^∞ c_n |n⟩
```

Зробивши заміну індексу підсумовування у лівій частині `m = n - 1`:

```
∑_{m=0}^∞ c_{m+1} · √(m+1) |m⟩ = ∑_{m=0}^∞ α · c_m |m⟩
```

Прирівнюючи коефіцієнти при однакових фоківських станах `|m⟩`:

```
c_{m+1} = ( α / √(m+1) ) · c_m
```

Послідовно виражаючи всі коефіцієнти `c_m` через `c_0`:

```
c_1 = α · c_0
c_2 = (α / √2) · c_1 = (α² / √2) · c_0
c_3 = (α / √3) · c_2 = (α³ / √6) · c_0
...
c_n = ( αⁿ / √(n!) ) · c_0
```

Коефіцієнт `c_0` визначається з умови нормування вектора стану `⟨α|α⟩ = 1`:

```
⟨α|α⟩ = ∑_{n=0}^∞ |c_n|² = |c_0|² · ∑_{n=0}^∞ ( (|α|²)ⁿ / n! ) = |c_0|² · exp(|α|²) = 1
```

Звідси визначаємо `c_0` з точністю до довільної фази:

```
c_0 = exp( - |α|² / 2 )
```

Таким чином, явний вираз для **когерентного стану Глаубера** за фоківським базисом має вигляд:

```
|α⟩ = exp( - |α|² / 2 ) · ∑_{n=0}^∞ ( αⁿ / √(n!) ) |n⟩
```

Когерентний стан також можна отримати дією унітарного **оператора зсуву** (дисплейсменту) `D̂(α)` на вакуумний стан `|0⟩`:

```
|α⟩ = D̂(α) |0⟩
```

де оператор зсуву визначений виразом:

```
D̂(α) = exp( α · â⁺ - α* · â )
```

Використовуючи формулу Бейкера — Кемпбелла — Гаусдорфа (BCH) для операторів, комутатор яких є c-числом (`[A, B] = c`):

```
exp(Â + B̂) = exp(Â) · exp(B̂) · exp( - (1 / 2) · [Â, B̂] )
```

Підставляючи `Â = α â⁺` та `B̂ = - α* â`, обчислимо комутатор `[Â, B̂] = - |α|² [â⁺, â] = |α|²`:

```
D̂(α) = exp( α â⁺ - α* â ) = exp( α â⁺ ) · exp( - α* â ) · exp( - |α|² / 2 )
```

Унітарний оператор зсуву `D̂(α)` має важливі алгебраїчні властивості:
1. `D̂⁺(α) = D̂⁻¹(α) = D̂(-α)`
2. `D̂⁺(α) · â · D̂(α) = â + α`
3. `D̂⁺(α) · â⁺ · D̂(α) = â⁺ + α*`

Завдяки цим тотожностям оператор `D̂(α)` здійснює трансляцію канонічних операторів у фазовому просторі на вектор `α`.

## 5. Математична теорія стиснутих станів вакууму (Squeezed States)

Для досягнення точності вимірювань, що перевищує стандартну квантову межу когерентного стану, застосовуються **стиснуті стани світла**.

Стиснутий вакуумний стан `|ζ⟩` утворюється дією унітарного **оператора стиснення** `Ŝ(ζ)` на вакуумний стан `|0⟩`:

```
|ζ⟩ = Ŝ(ζ) |0⟩
```

де оператор стиснення `Ŝ(ζ)` визначається квадратним оператором за комплексною амплітудою `ζ = r · exp(i · θ)` (де `r ≥ 0` — параметр стиснення, а `θ` — кут стиснення):

```
Ŝ(ζ) = exp( (1 / 2) · ( ζ* · â² - ζ · (â⁺)² ) )
```

Знайдемо унітарне перетворення оператора знищення `â` під дією `Ŝ(ζ)`:

```
â' = Ŝ⁺(ζ) · â · Ŝ(ζ) = â · cosh(r) - â⁺ · exp(i · θ) · sinh(r)
```

```
â'⁺ = Ŝ⁺(ζ) · â⁺ · Ŝ(ζ) = â⁺ · cosh(r) - â · exp(-i · θ) · sinh(r)
```

Це перетворення належить до класичних перетворень Боголюбова.

Обчислимо дисперсії квадратурних операторів `X̂_1 = (â + â⁺)/2` та `X̂_2 = (â - â⁺)/(2i)` для стиснутого вакууму при `θ = 0`:

```
⟨ζ| X̂_1² |ζ⟩ = (1 / 4) · ⟨0| Ŝ⁺(r) (â + â⁺)² Ŝ(r) |0⟩ = (1 / 4) · ( cosh(r) - sinh(r) )² = (1 / 4) · exp(- 2 · r)
```

```
⟨ζ| X̂_2² |ζ⟩ = (1 / 4) · ⟨0| Ŝ⁺(r) (i â⁺ - i â)² Ŝ(r) |0⟩ = (1 / 4) · ( cosh(r) + sinh(r) )² = (1 / 4) · exp(+ 2 · r)
```

Добуток невизначеностей квадратур залишається на інваріантній мінімальній межі:

```
ΔX_1 · ΔX_2 = √( (1/4) exp(-2r) ) · √( (1/4) exp(+2r) ) = 1 / 4
```

Однак флуктуація однієї з квадратур `ΔX_1` експоненціально пригнічується в `exp(r)` разів за рахунок експоненціального зростання флуктуацій ортогональної квадратури `ΔX_2`.

Розклад стиснутого вакуумного стану `|ζ⟩` за фоківським базисом показує несподівану властивість: він містить **строго парні числа фотонів**:

```
|ζ⟩ = ( 1 / √(cosh r) ) · ∑_{n=0}^∞ ( √( (2n)! ) / ( 2ⁿ · n! ) ) · ( exp(i θ) · tanh r )ⁿ |2n⟩
```

Імовірність виявити непарне число фотонів у стиснутому вакуумі тотожно дорівнює нулю (`P(2n+1) = 0`), а ймовірність парних фотонних пар `P(2n)` дорівнює:

```
P(2n) = ( (2n)! / ( 2²ⁿ · (n!)² ) ) · ( (tanh r)²ⁿ / cosh r )
```

Середня кількість фотонів у стиснутому вакуумі становить `⟨N⟩ = sinh²(r)`. Суб-пуассонівські та стиснуті стани слугують ключовим математичним інструментом квантової оптики.
