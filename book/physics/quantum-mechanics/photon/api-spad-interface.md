# 📋 Інтерфейс та характеристики однофотонного лавинного фотодіода (SPAD)

Однофотонний лавинний фотодіод (Single-Photon Avalanche Diode, SPAD) — це надчутливий напівпровідниковий фотодетектор на основі p-n переходу, призначений для реєстрації поодиноких фотонів методом лавинного розмноження носіїв заряду.

На відміну від звичайного p-n фотодіода (який працює без підсилення з коефіцієнтом `M = 1`) або класичного лавинного фотодіода APD (який працює у лінійному режимі під напругою нижче напруги пробою з коефіцієнтом підсилення `M = 10–100`), SPAD функціонує у так званому **ґейгерівському режимі** (Geiger-mode). У цьому режимі на p-n перехід подається зворотна зміщена напруга `V_bias`, яка перевищує напругу пробою `V_BR` на величину понаднапруги `V_over = V_bias - V_BR` (типове значення `V_over` становить від 2 V до 7 V).

Під дією понаднапруги `V_over` напряженість електричного поля у збідненій зоні напівпровідника досягає критичних значень `E > 3 × 10⁵ V/cm`. За таких умов поглинання навіть поодинокого падаючого фотона з утворенням однієї первинної електрон-діркової пари викликає самопідтримувану лавину ударної іонізації: прискорені полем носії іонізують атоми кристалічної ґратки, створюючи нові пари, які в свою чергу викликають подальшу іонізацію. За час менше 1 ns струм через диод стрибкоподібно зростає від пікоамперного рівня до макроскопічного значення 1–10 mA, утворюючи швидко наростаючий імпульс напруги.

Цей довідник описує фізичні, електричні, структурно-реєстрові та програмні інтерфейси SPAD-модулів (типу Excelitas SPCM, Hamamatsu S13360 / C10508, MPD PDM series) та карт часового кореляційного підрахунку фотонів (TCSPC).

## 1. Паспортні фізико-технічні характеристики (Hardware Specifications)

При виборі та експлуатації SPAD-модулів ключове значення мають метрологічні параметри детектора, які визначають його квантову ефективність, часову точність та рівень внутрішніх шумів.

| Параметр | Символ | Типовий діапазон | Одиниці | Опис та фізичне значення |
| :--- | :--- | :--- | :--- | :--- |
| Напруга пробою | `V_BR` | 25.0 – 160.0 | V | Порогова зворотна напруга, за якої коефіцієнт помноження носіїв стає нескінченним. Залежить від температури та профілю легування кристала. |
| Понаднапруга | `V_over` | 1.5 – 7.0 | V | `V_bias - V_BR`. Визначає напряженість поля в p-n переході. Збільшення `V_over` підвищує `PDE`, але одночасно зростає рівень шумів `DCR`. |
| Квантова ефективність | `PDE` | 35 – 80 | % | Фотонна ефективність детектування (Photon Detection Efficiency): ймовірність того, що падаючий фотон викличе вимірювану лавину. `PDE = η_abs · P_av`. |
| Темновий рахунок | `DCR` | 10 – 1000 | cps (Hz) | Частота темнового шуму (Dark Count Rate): спонтанні лавини в повній темряві за рахунок термогенерації та тунелювання Зенера. |
| Часовий джитер | `Δt_jitter` | 35 – 250 | ps | Невизначеність моменту формування вихідного логічного імпульсу відносно точного часу поглинання фотона. |
| Мертвий час | `τ_dead` | 10.0 – 50.0 | ns | Інтервал часу після лавини, протягом якого детектор гаситься та відновлюється і є нечутливим до нових фотонів. |
| Ймовірність післяімпульсів | `P_after` | 0.1 – 3.0 | % | Ймовірність появи хибної лавини за рахунок вивільнення носіїв, захоплених глибокими пастками під час попереднього лавинного імпульсу. |
| Температурний коефіцієнт | `γ_temp` | 0.05 – 0.15 | V/°C | Величина зсуву напруги пробою при зміні температури напівпровідника (`dV_BR / dT`). Вимагає термостимуляції. |

### Деталізований фізичний аналіз параметрів

1. **Фотонна ефективність детектування (PDE):**
   Параметр `PDE(λ, V_over)` є добутком двох незалежних ймовірностей:
   ```
   PDE = η_abs(λ) · P_av(V_over)
   ```
   де `η_abs(λ)` — коефіцієнт поглинання світла з довжиною хвилі `λ` у робочому об'ємі кремнію або арсеніду галію, а `P_av(V_over)` — ймовірність того, що згенерована електрон-діркова пара уникне рекомбінації і започаткує лавину. Для кремнієвих SPAD пік `PDE` (до 70–80%) припадає на спектральний діапазон 500–700 nm, а для InGaAs/InP детекторів (для телекомунікаційних довжин хвиль 1310 nm та 1550 nm) `PDE` становить 20–35%.

2. **Часовий джитер (Timing Jitter):**
   Часовий джитер визначає інструментальну флуктуованість часових міток і обмежує граничну роздільну здатність у флуоресцентній мікроскопії (FLIM) та квантовій томографії. Джитер виникає через варіацію глибини поглинання фотона в шарі напівпровідника та скінченну швидкість дрейфу носіїв до зони високого поля. Для ультрашвидких кремнієвих SPAD із тонким збідненим шаром джитер становить менше 35 ps (FWHM).

3. **Післяімпульси (Afterpulsing):**
   Під час макроскопічного лавинного струму (проходження `10⁶–10⁷` електронів) частина носіїв захоплюється дефектами та глибокими імпульсними пастками у забороненій зоні. Вивільнення цих носіїв через час `t > τ_dead` під дією відновленої напруги `V_bias` викликає повторний хибний імпульс (післяімпульс). Зменшення післяімпульсів досягається збільшенням мертвого часу та оптимізацією технологічного очищення кремнію.

## 2. Апаратний інтерфейс роз'ємів та виводів (Pinout & Wiring Interface)

Завершений законтурний SPAD-модуль оснащується силовим інтерфейсом високої та низької напруги, системою термостабілізації на елементі Пельтьє (TEC), ланцюгами керування стробуванням та високошвидкісними логічними виходами.

```
       ┌─────────────────────────────────────────────────────────┐
       │                SPAD DETECTOR MODULE                     │
       │                                                         │
 [NC] ─┤ 1  HV_BIAS (+50..+250V)        TTL_OUT (50Ω SMA) ──────┼─> [Fast Pulse]
 [NC] ─┤ 2  VCC (+5V DC, 1.5A)          NIM_OUT (50Ω SMA) ──────┼─> [Fast NIM]
 [NC] ─┤ 3  GND (Power Ground)          GATE_IN (SMA / TTL) ─────┼─< [Gate Enable]
 [NC] ─┤ 4  TEC_VCC (+3.3V TEC)                                │
 [NC] ─┤ 5  TEMP_SENSE (NTC 10kΩ)                                │
 [NC] ─┤ 6  QUENCH_DISABLE (TTL)                                 │
       └─────────────────────────────────────────────────────────┘
```

### Деталізоване призначення контактів та електричні контракти

1. **`HV_BIAS` (High Voltage Input Pin):**
   Вхід високої зворотної напруги зміщення. Напруга вимагає надвисокої стабільності: рівень пульсацій не повинен перевищувати `1 mV_p-p`, оскільки флуктуація напруги на `10 mV` викликає зміну темнової частоти `DCR` на 2–5%. Вхід захищено послідовним баластним резистором `R_bias = 100 kΩ`.

2. **`VCC / GND` (Low Voltage Power Rail):**
   Основна шина живлення аналогових та цифрових кіл модуля (`+5.0 V ± 2% DC`). Струм споживання у штатному режимі становить `350 mA`, а під час активної термостабілізації Пельтьє може досягати `1.5 A`. GND є спільною землею для сигналу та живлення.

3. **`TEC_VCC / TEMP_SENSE` (Thermal Control Interface):**
   Контакти внутрішнього двокаскадного термоелектричного охолоджувача Пельтьє (TEC) та платинового термістора NTC `10 kΩ` (при `25 °C`). Зовнішній PID-контролер вимірює опір термістора `R_th` і керує струмом TEC. Перерахунок опору в температуру виконується за рівнянням Стейнхарта — Харта:
   ```
   1 / T = A + B · ln(R_th) + C · (ln(R_th))³
   ```
   Зниження температури кристала до `-20 °C` зменшує темновий шум `DCR` у 100–300 разів за рахунок виморожування теплової генерації носіїв.

4. **`TTL_OUT` / `NIM_OUT` (Fast Timing Signal Outputs):**
   Виходи для реєстрації імпульсів підрахунку:
   - **`TTL_OUT`:** Швидкісний вихід логіки TTL/CMOS на роз'ємі SMA. При навантаженні `50 Ω` амплітуда імпульсу становить `V_high = +3.3 V`, `V_low = 0 V`, тривалість імпульсу `10 ns ± 1 ns`, час наростання фронту `t_rise < 1.2 ns`.
   - **`NIM_OUT`:** Вихід швидкої від'ємної логіки NIM (Nuclear Instrument Modules) для підключення до стандартних ядерних конверторів часових інтервалів. При навантаженні `50 Ω` логічний нуль відповідає `0 V`, а логічна одиниця — від'ємному напруговому рівню `-0.8 V` (`-16 mA`), тривалість імпульсу `5 ns`.

5. **`GATE_IN` (Fast Gating Control Input):**
   Вхід швидкого стробування на роз'ємі SMA. Дозволяє імпульсно вмикати детектор у ґейгерівський режим лише на короткі проміжки часу (вікно від 2 ns до 100 ns), синхронізовані з зовнішнім пікосекундним лазером. У проміжках між стробами напруга знижується нижче `V_BR`, що повністю усуває темновий шум у паузах.

## 3. Фізичні схеми гасіння лавини (Quenching & Reset Architectures)

Після виникнення лавинного пробою струм у перехідній області має бути негайно припинений (згашений), щоб запобігти перегріву та руйнуванню кристала, а також дати змогу рекомбінувати захопленим носіям.

```
       Пасивне гасіння (PQC)                       Активне гасіння (AQC)

          HV_BIAS (+200V)                            HV_BIAS (+200V)
                │                                          │
                ├───────┐                                  ├───────┐
                │       │                                  │       │
               ┌┴┐     ┌┴┐                                ┌┴┐     ┌┴┐
               │R│     │C│                                │R│     │C│  (Sense)
               └┬┘     └┬┘                                └┬┘     └┬┘
                │       │                                  │       │
                ├───────┴──────┐                           ├───────┴───────┐
                │              │                           │               │
             ───┴───         ───┴───                    ───┴───         ───┴───
              \   / SPAD      \   / SPAD                 \   / SPAD      \   / SPAD
               \ /             \ /                        \ /             \ /
             ───┬───         ───┬───                    ───┬───         ───┬───
                │              │                           │               │
                ├──────────────┘                           ├───────────────┼─────> [Comparator]
                │                                          │               │          │
               ┌┴┐ R_Quench                                ├───┐          ┌┴┐         │ (Fast Switch)
               │ │ (100kΩ)                                 │   │          │ │         ▼
               └┬┘                                       ┌─┴─┐ │ MOSFET   └┬┘    ┌─────────┐
                │                                        │   │ │ Switch    │     │ Driver  │
               GND                                       └─┬─┘ │           │     └─────────┘
                                                           │   │           │
                                                          GND ─┴───────────┴─> GND
```

### 3.1 Пасивне гасіння (Passive Quenching Circuit, PQC)
Включає послідовний високоомний баластний резистор `R_q ≈ 100–470 kΩ`.
- **Принцип дії:** При виникненні лавини струм `I_av` зростає, на резисторі `R_q` виникає падіння напруги `V_drop = I_av · R_q`. Це приводить до падіння зворотної напруги на самому фотодіоді до рівня `V_spad = V_bias - I_av · R_q < V_BR`. Лавина гасне.
- **Відновлення:** Після гасіння напруга повертається до `V_bias` за законами розряду паразитної ємності кристала `C_p ≈ 2–5 pF` через `R_q` із часовою константою `τ_reset = R_q · C_p ≈ 200–500 ns`.
- **Оцінка:** Проста конструкція, проте великий мертвий час та високий рівень післяімпульсів.

### 3.2 Активне гасіння (Active Quenching Circuit, AQC)
Застосовує швидкий електронний компаратор та низькоомний комбінований ключ на MOSFET-транзисторах.
- **Принцип дії:** Компаратор фіксує наростання лавинного струму при досягненні порогу ~100 μA (протягом 500 ps) і видає сигнал на відкриття швидкого транзисторного ключа, який примусово приєднує анод фотодіода до високої напруги, знижуючи `V_bias` нижче `V_BR` за `1 ns`.
- **Витримка та відновлення:** Напруга утримується нижче `V_BR` протягом фіксованого мертвого часу `τ_dead` (10–20 ns), після чого активна схема підтяжки швидко заряджає ємність кристала назад до `V_bias`.
- **Оцінка:** Мінімальний фіксований мертвий час `τ_dead ≈ 10 ns`, максимальна швидкість підрахунку до `100 MHz`, значне пригнічення післяімпульсів.

## 5. C/C++ Програмний інтерфейс драйвера (API Driver Specifications)

Програмний інтерфейс драйвера надає низькорівневі C-функції для керування модулем SPAD та платою TCSPC, а також високорівневі C++ обгортки для безпечного використання в ідіомах RAII.

### 5.1 Специфікація типів даних та заголовочний файл (`spad_driver.h`)

```cpp
#pragma once
#include <stdint.h>
#include <stdbool.h>

#ifdef __cplusplus
extern "C" {
#endif

typedef enum {
    SPAD_OK = 0,
    SPAD_ERR_NOT_FOUND = -1,
    SPAD_ERR_HV_OUT_OF_RANGE = -2,
    SPAD_ERR_TEC_TIMEOUT = -3,
    SPAD_ERR_FIFO_OVERFLOW = -4,
    SPAD_ERR_INVALID_PARAM = -5,
    SPAD_ERR_COMMUNICATION = -6
} spad_status_t;

typedef struct {
    float bias_voltage_v;     // Напруга зміщення V_bias (V)
    float discriminator_mv;   // Поріг дискримінатора (mV)
    uint32_t dead_time_ns;    // Заданий мертвий час (ns)
    float target_temp_c;      // Цільова температура Пельтьє (°C)
    bool enable_gating;       // Прапорець зовнішнього стробування
    uint32_t coinc_window_ps; // Часове вікно совпадінь (ps)
} spad_config_t;

typedef struct {
    uint64_t total_counts_a;  // Накопичені відліки каналу A
    uint64_t total_counts_b;  // Накопичені відліки каналу B
    uint64_t coincidences;    // Кількість зафіксованих совпадінь
    float current_dcr_hz;     // Поточний темновий рахунок (Hz)
    float actual_temp_c;      // Поточна температура кристала (°C)
    bool high_voltage_active; // Стан високої напруги
} spad_metrics_t;

/**
 * @brief Ініціалізація та відкриття з'єднання з детектором SPAD / платою TCSPC
 * @param device_index Індекс пристрою в системі (0, 1...)
 * @param handle Повертає вказівник на хендл сесії
 */
spad_status_t spad_init(int device_index, void** handle);

/**
 * @brief Завантаження конфігурації (напруга, поріг, мертвий час)
 */
spad_status_t spad_configure(void* handle, const spad_config_t* config);

/**
 * @brief Ввімкнення/вимкнення джерела високої напруги HV_BIAS
 */
spad_status_t spad_enable_high_voltage(void* handle, bool enable);

/**
 * @brief Зчитування поточних метрологічних метрик детектора
 */
spad_status_t spad_read_metrics(void* handle, spad_metrics_t* metrics);

/**
 * @brief Зчитування масиву 64-бітних пікосекундних часових міток (Time-Tagging Mode)
 * @param handle Хендл пристрою
 * @param buffer Масив для запису міток
 * @param max_tags Максимальна кількість міток
 * @param actual_read Повертає кількість реально прочитаних міток
 */
spad_status_t spad_read_timetags(void* handle, uint64_t* buffer, uint32_t max_tags, uint32_t* actual_read);

/**
 * @brief Безпечне вимкнення високої напруги та закриття сесії
 */
spad_status_t spad_close(void* handle);

}
```

### 5.2 Об'єктно-орієнтована реалізація C++17 RAII Обгортки

```cpp
#include <iostream>
#include <vector>
#include <chrono>
#include <thread>
#include <stdexcept>
#include <memory>

class SpadDevice {
public:
    explicit SpadDevice(int dev_idx) {
        spad_status_t st = spad_init(dev_idx, &handle_);
        if (st != SPAD_OK) {
            throw std::runtime_error("Не вдалося ініціалізувати SPAD пристрій! Код помилки: " + std::to_string(st));
        }
    }

    ~SpadDevice() noexcept {
        if (handle_) {
            spad_enable_high_voltage(handle_, false);
            spad_close(handle_);
            handle_ = nullptr;
        }
    }

    // Заборона копіювання для запобігання подвійному закриттю хендла
    SpadDevice(const SpadDevice&) = delete;
    SpadDevice& operator=(const SpadDevice&) = delete;

    // Дозвіл переміщення (Move Semantics)
    SpadDevice(SpadDevice&& other) noexcept : handle_(other.handle_) {
        other.handle_ = nullptr;
    }

    SpadDevice& operator=(SpadDevice&& other) noexcept {
        if (this != &other) {
            if (handle_) {
                spad_enable_high_voltage(handle_, false);
                spad_close(handle_);
            }
            handle_ = other.handle_;
            other.handle_ = nullptr;
        }
        return *this;
    }

    void setup(float bias_v, float thresh_mv, uint32_t dead_ns, float temp_c = -20.0f) {
        spad_config_t cfg{};
        cfg.bias_voltage_v = bias_v;
        cfg.discriminator_mv = thresh_mv;
        cfg.dead_time_ns = dead_ns;
        cfg.target_temp_c = temp_c;
        cfg.enable_gating = false;
        cfg.coinc_window_ps = 1000; // 1 ns вікно збігів

        spad_status_t st = spad_configure(handle_, &cfg);
        if (st != SPAD_OK) {
            throw std::runtime_error("Помилка конфігурації SPAD! Код: " + std::to_string(st));
        }
    }

    void start_high_voltage() {
        spad_status_t st = spad_enable_high_voltage(handle_, true);
        if (st != SPAD_OK) {
            throw std::runtime_error("Помилка увімкнення високої напруги! Код: " + std::to_string(st));
        }
    }

    void stop_high_voltage() {
        spad_status_t st = spad_enable_high_voltage(handle_, false);
        if (st != SPAD_OK) {
            throw std::runtime_error("Помилка вимкнення високої напруги!");
        }
    }

    [[nodiscard]] spad_metrics_t get_metrics() const {
        spad_metrics_t m{};
        spad_status_t st = spad_read_metrics(handle_, &m);
        if (st != SPAD_OK) {
            throw std::runtime_error("Помилка зчитування метрологічних метрик!");
        }
        return m;
    }

    [[nodiscard]] std::vector<uint64_t> read_timetags(uint32_t max_count) const {
        std::vector<uint64_t> buffer(max_count);
        uint32_t actual_read = 0;
        spad_status_t st = spad_read_timetags(handle_, buffer.data(), max_count, &actual_read);
        if (st != SPAD_OK) {
            throw std::runtime_error("Помилка читання часових міток!");
        }
        buffer.resize(actual_read);
        return buffer;
    }

private:
    void* handle_ = nullptr;
};
```
