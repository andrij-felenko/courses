# 🧮 Математичний апарат детермінанта Слейтера та обмінної взаємодії

Строгий квантовомеханічний опис системи з `N` тотожних частинок вимагає побудови багаточастинкового гіперпростору станів, який задовольняє постулату симетризації. У квантовій механіці тотожність частинок означає, що перестановка координат і спінів будь-якої пари частинок `i` та `j` не змінює жодної фізично спостережуваної величини. Звідси випливає фундаментальна вимога до хвильової функції: густина ймовірності `|Ψ(x_1, x_2, ..., x_N)|²` повинна залишатися строго інваріантною відносно будь-якої перестановки аргументів `x_i = (r_i, s_i)`.

Для ферміонів ця вимога звужується до умови строгої антисиметричності хвильової функції щодо перестановки будь-якої пари аргументів. Нижче наведено математичне виведення конструкції детермінанта Слейтера, доведення принципу заборони Паулі, систематику правил Слейтера — Кондона, варіаційне виведення рівнянь Гартрі — Фока та детальний розрахунок матричних елементів двочастинкової кулонівської й обмінної взаємодії.

## 1. Оператор перестановки, група S_N та симетризаційні проєктори

Розглянемо двочастинковий оператор транспозиції `P_{ij}`, який діє на квантовомеханічний стан системи `N` частинок шляхом взаємного обміну всіма просторовими та спіновими координатами `x_i` та `x_j`:

```
P_{ij} Ψ(x_1, ..., x_i, ..., x_j, ..., x_N) = Ψ(x_1, ..., x_j, ..., x_i, ..., x_N)
```

Оскільки дворазове застосування оператора транспозиції повертає систему у вихідний стан, квадратичне значення оператора дорівнює одиничному оператору:

```
P_{ij}² = I  ⇒  (P_{ij} - I) (P_{ij} + I) = 0
```

Звідси власні значення оператора перестановки `P_{ij}` можуть дорівнювати лише `+1` або `-1`. Оскільки всі квантовомеханічні ферміони мають півцілий спін (`s = 1/2, 3/2, ...`), стан багаточастинкової системи описується власною функцією з власним значенням `-1`:

```
P_{ij} Ψ_A = -1 · Ψ_A
```

Множина всіх перестановок `N` елементів утворює симетричну групу `S_N`, яка містить `N!` елементів. Довільна перестановка `π ∈ S_N` може бути розкладена у добуток `k` елементарних транспозицій двох елементів. Парність перестановки визначається вектором знак-множника:

```
sgn(π) = (-1)^k
```

де `sgn(π) = +1` для парних перестановок та `sgn(π) = -1` для непарних перестановок.

Для побудови повністю антисиметричної хвильової функції з довільного добутку одночастинкових станів використовується формальний **оператор антисиметризації** `A`:

```
A = (1 / N!) · ∑_{π ∈ S_N} sgn(π) · P_π
```

Оператор `A` володіє властивостями ортогонального проєктора у гіперпросторі станів:

```
1. Ідемпотентність: A² = A
2. Ермітовість:     A^† = A
3. Комутація з H:   [A, H] = 0  (якщо гамільтоніан H є симетричним відносно перестановок)
```

### 1.1. Класифікація Незвідних Представлень Групи Перестановок та Таблиці Юнга

У математичній теорії груп перестановок розклад гіперпростору станів за типами симетрії описується за допомогою **схем Юнга** (Alfred Young). Для системи з `N` частинок кожне незвідне представлення групи `S_N` однозначно відповідає діаграмі Юнга, складеній з `N` квадратних комірок.

1. **Повністю симетричний стан (Бозони)**: описується однорядковою діаграмою Юнга довжиною `N`. Перестановка будь-якої пари частинок не змінює знак хвильової функції.
2. **Повністю антисиметричний стан (Ферміони)**: описується одностовпчиковою діаграмою Юнга висотою `N`. Будь-яка перестановка у стовпчику змінює знак на протилежний.

Оскільки спінові стани електрона (`s = 1/2`) мають лише дві доступні орієнтації (`m_s = ±1/2`), спінова частина хвильової функції не може містити більше ніж дві комірки у одному стовпчику діаграми Юнга. Це математично доводить, що просторова частина хвильової функції багатоелектронної системи може описуватися лише тими діаграмами Юнга, які містять не більше ніж два стовпчики. Всі інші типи симетрії строго заборонені принципом Паулі.

## 2. Формалізм детермінанта Слейтера та алгебраїчний доказ принципу Паулі

Нехай маємо впорядкований набір `N` ортонормованих одночастинкових квантових станів (орбіталей) `{φ_1(x), φ_2(x), ..., φ_N(x)}`, де кожна орбіталь `φ_k(x)` описує стан частинки з урахуванням її просторових координат `r` та спінового стану `s`:

```
∫ φ_i*(x) · φ_j(x) dx = δ_{ij}
```

Тут інтегрування означає сумування за дискретними спіновими змінними та інтегрування за просторовим об'ємом: `dx = d³r · ∑_{s_z}`.

Простий гартріївський добуток одночастинкових станів `Ψ_Hartree = φ_1(x_1) · φ_2(x_2) · ... · φ_N(x_N)` не має властивості антисиметрії, оскільки прив'язує частинку 1 до стану 1, частинку 2 до стану 2 і так далі. Застосовуючи оператор антисиметризації `A` до гартріївського добутку та враховуючи нормування `1 / √(N!)`, отримуємо **детермінант Слейтера**:

```
Ψ(x_1, x_2, ..., x_N) 
= (1 / √(N!)) · Det | φ_1(x_1)  φ_2(x_1)  ...  φ_N(x_1) |
                    | φ_1(x_2)  φ_2(x_2)  ...  φ_N(x_2) |
                    |   ⋮          ⋮       ⋱      ⋮     |
                    | φ_1(x_N)  φ_2(x_N)  ...  φ_N(x_N) |
```

Або у компактній математичній формі через суму за елементами групи перестановок `S_N`:

```
Ψ(x_1, ..., x_N) = (1 / √(N!)) · ∑_{π ∈ S_N} sgn(π) · ∏_{i=1}^{N} φ_{π(i)}(x_i)
```

### 2.1. Доведення строгого нормування детермінанта Слейтера

Обчислимо скалярний добуток хвильової функції детермінанта Слейтера сам на себе `⟨Ψ|Ψ⟩`:

```
⟨Ψ|Ψ⟩ = (1 / N!) · ∑_{π ∈ S_N} ∑_{σ ∈ S_N} sgn(π) · sgn(σ) · ∏_{i=1}^{N} ∫ φ_{π(i)}*(x_i) · φ_{σ(i)}(x_i) dx_i
```

Завдяки ортонормованості одночастинкових орбіталей `∫ φ_a*(x) φ_b(x) dx = δ_{ab}`, інтеграл дорівнює 1 лише тоді, коли перестановки `π` та `σ` повністю збігаються (`π = σ`). Для всіх інших пар перестановок добуток інтегралів тотожно занулюється. Оскільки `sgn(π)² = 1`, сума зводиться до підрахунку кількості елементів групи перестановок `S_N`:

```
⟨Ψ|Ψ⟩ = (1 / N!) · ∑_{π ∈ S_N} 1  =  (1 / N!) · N!  =  1
```

Це строго доводить, що нормувальний множник `1 / √(N!)` робить детермінант Слейтера ортонормованим квантовомеханічним станом.

### 2.2. Алгебраїчний висновок принципу Паулі з властивостей детермінанта

Фундаментальний принцип заборони Паулі є прямою алгебраїчною властивістю детермінанта Слейтера:

1. **Перестановка частинок `x_i ↔ x_j`**: відповідає перестановці двох **рядків** у детермінанті. За фундаментальною теоремою лінійної алгебри, перестановка двох рядків матриці змінює знак детермінанта на протилежний (`Det -> -Det`). Отже, `Ψ(..., x_j, ..., x_i, ...) = - Ψ(..., x_i, ..., x_j, ...)`.
2. **Заняття двох однакових станів `φ_a = φ_b`**: відповідає появі двох строго **однакових стовпчиків** у детермінанті Слейтера. Матриця з двома однаковими стовпчиками є лінійно залежною і має детермінант, тотожно рівний нулю:

```
Det = 0  ⇒  Ψ(x_1, x_2, ..., x_N) ≡ 0
```

Якщо хвильова функція тотожно дорівнює нулю, густина ймовірності виявлення такої фізичної системи `|Ψ|² = 0`. Це означає, що квантовий стан із двома ферміонами у збіжних одночастинкових станах фізично не існує.

## 3. Правила Слейтера — Кондона для обчислення матричних елементів

Для опису багатоелектронних систем гамільтоніан `H` складається з одночастинкових операторів `h(i)` (кінетична енергія та приваблення до ядер) та двочастинкових операторів `v(i, j)` (кулонівське відштовхування електронів):

```
H = F_1 + F_2 = ∑_{i=1}^{N} h(i) + ∑_{i < j}^{N} v(i, j)
```

Матричні елементи операторів між антисиметричними станами Слейтера `|Ψ_A⟩` та `|Ψ_B⟩` обчислюються за допомогою **правил Слейтера — Кондона**:

### 1. Одночастинкові оператори `F_1 = ∑ h(i)`

- **Діагональний елемент (стан `|Ψ_A⟩ = |Ψ_B⟩`)**:
```
⟨Ψ_A| ∑_{i=1}^{N} h(i) |Ψ_A⟩ = ∑_{i=1}^{N} ⟨φ_i| h |φ_i⟩ = ∑_{i=1}^{N} I_i
```
- **Відрізняються однією орбіталлю (`φ_m` у `Ψ_A` замінено на `φ_p` у `Ψ_B`)**:
```
⟨Ψ_A| ∑_{i=1}^{N} h(i) |Ψ_B⟩ = ⟨φ_m| h |φ_p⟩
```
- **Відрізняються двома або більше орбіталями**:
```
⟨Ψ_A| ∑_{i=1}^{N} h(i) |Ψ_B⟩ = 0
```

### 2. Двочастинкові оператори `F_2 = ∑ v(i, j)`

- **Діагональний елемент (стан `|Ψ_A⟩ = |Ψ_B⟩`)**:
```
⟨Ψ_A| ∑_{i < j}^{N} v(i, j) |Ψ_A⟩ = ∑_{i < j}^{N} ( J_{ij} - K_{ij} )
```
де `J_{ij}` — кулонівський інтеграл, `K_{ij}` — обмінний інтеграл.

- **Відрізняються однією орбіталлю (`φ_m` замінено на `φ_p`)**:
```
⟨Ψ_A| ∑_{i < j}^{N} v(i, j) |Ψ_B⟩ = ∑_{k=1}^{N} ( ⟨m k| v |p k⟩ - ⟨m k| v |k p⟩ )
```

- **Відрізняються двома орбіталями (`φ_m, φ_n` замінено на `φ_p, φ_q`)**:
```
⟨Ψ_A| ∑_{i < j}^{N} v(i, j) |Ψ_B⟩ = ⟨m n| v |p q⟩ - ⟨m n| v |q p⟩
```

- **Відрізняються більше ніж двома орбіталями**:
```
⟨Ψ_A| ∑_{i < j}^{N} v(i, j) |Ψ_B⟩ = 0
```

## 4. Явний вираз для кулонівського та обмінного інтегралів

Для двох електронів у станах `φ_i(x_1)` та `φ_j(x_2)` двочастинковий матричний елемент кулонівського відштовхування розкладається на два члени:

### 1. Прямий кулонівський інтеграл `J_{ij}`

Описує класичне електростатичне відштовхування між двома розмазаними хмарами густини заряду `|φ_i(r_1)|²` та `|φ_j(r_2)|²`:

```
J_{ij} = ∫ ∫ |φ_i(r_1)|² · ( e² / (4πε₀ |r_1 - r_2|) ) · |φ_j(r_2)|² d³r_1 d³r_2
```

Значення `J_{ij}` є строго додатним (`J_{ij} > 0`) для будь-яких орбіталей і завжди збільшує загальну енергію системи.

### 2. Обмінний інтеграл `K_{ij}`

Виникає виключно завдяки вимозі антисиметрії детермінанта Слейтера відносно перестановки координат:

```
K_{ij} = ∫ ∫ φ_i*(r_1) φ_j*(r_2) · ( e² / (4πε₀ |r_1 - r_2|) ) · φ_j(r_1) φ_i(r_2) d³r_1 d³r_2 · ⟨χ_i|χ_j⟩
```

Скалярний добуток спінових функцій `⟨χ_i|χ_j⟩` забезпечує точне збереження спінового відбору:

```
⟨χ_i|χ_j⟩ = 1  при паралельних спінах  (s_1 = s_2)
⟨χ_i|χ_j⟩ = 0  при антипаралельних спінах (s_1 ≠ s_2)
```

Отже, **обмінний інтеграл `K_{ij}` відрізняється від нуля лише для електронів з однаковим напрямком спіну**.

## 5. Метод Гартрі — Фока та ефективний інтегрально-диференціальний оператор Фока

Застосовуючи варіаційний принцип Ритца до мінімізації повної енергії `E = <Ψ| H |Ψ>` на класі однодетермінантних хвильових функцій Слейтера з умовою збереження ортонормованості орбіталей `⟨φ_i|φ_j⟩ = δ_{ij}` за допомогою множників Лагранжа `ε_{ij}`, отримуємо одночастинкові **рівняння Гартрі — Фока**:

```
F φ_i(r_1) = ε_i φ_i(r_1)
```

де `F` — одночастинковий **оператор Фока**:

```
F = h(1) + ∑_{j=1}^{N} ( J_j(1) - K_j(1) )
```

Дія прямого кулонівського оператора `J_j(1)` є локальною і зводиться до множення на класичний кулонівський потенціал `V_J(r_1)`:

```
J_j(1) φ_i(r_1) = [ ∫ |φ_j(r_2)|² · ( e² / (4πε₀ |r_1 - r_2|) ) d³r_2 ] · φ_i(r_1)
```

Дія обмінного оператора `K_j(1)` є **нелокальною** і задається інтегральним перетворенням, у якому орбіталі `φ_i` та `φ_j` міняються аргументами:

```
K_j(1) φ_i(r_1) = [ ∫ φ_j*(r_2) · ( e² / (4πε₀ |r_1 - r_2|) ) · φ_i(r_2) d³r_2 ] · φ_j(r_1)
```

Нелокальний характер обмінного потенціалу означає, що значення обмінного поля у точці `r_1` залежить від значення хвильової функції `φ_i(r_2)` у всьому об'ємі простору `r_2`. Цей нелокальний обмінний член є прямим математичним втіленням принципу заборони Паулі у самоузгодженому полі атома або молекули.

### 5.1. Теорема Купманса та значення власних чисел ε_i

Згідно з **теоремою Купманса** (Tjalling Koopmans, 1934 рік), власне значення оператора Фока `ε_i` має точний фізичний зміст: негативне значення `- ε_i` дорівнює вертикальній енергії іонізації електрона при його видаленні з `i`-ї орбіталі без релаксації решти орбіталей:

```
I_i = - ε_i = - ⟨φ_i| F |φ_i⟩
```

Це робить метод Гартрі — Фока базовим математичним апаратом квантової хімії, спектроскопії та фотоелектронної фізики.

## 6. Обчинний розрахунок для атома Гелію: Синглетний та Триплетний стани

Проілюструємо фізичне значення обмінного інтеграла `K` на прикладі атома Гелію у збудженому стані з конфігурацією `1s¹ 2s¹`. У цьому стані електрони мають два варіанти спінової впорядкованості:

1. **Синглетний стан (парагелій, S = 0)**: спіни антипаралельні. Просторова частина хвильової функції є симетричною, а спінова — антисиметричною:
```
Ψ_singlet = (1 / √2) · [ φ_1s(r_1) φ_2s(r_2) + φ_2s(r_1) φ_1s(r_2) ] · (1 / √2) · [ α(1) β(2) - β(1) α(2) ]
```

2. **Триплетний стан (ортогелій, S = 1)**: спіни паралельні. Просторова частина хвильової функції є антисиметричною, а спінова — симетричною:
```
Ψ_triplet = (1 / √2) · [ φ_1s(r_1) φ_2s(r_2) - φ_2s(r_1) φ_1s(r_2) ] · спіновий спінор (S=1)
```

Обчислення середняка гамільтоніана `H = h(1) + h(2) + e² / (4πε₀ r_12)` для обох станів дає:

```
E_singlet = I_1s + I_2s + J_{1s, 2s} + K_{1s, 2s}  [вищий рівень енергії]
E_triplet = I_1s + I_2s + J_{1s, 2s} - K_{1s, 2s}  [нижчий рівень енергії]
```

Величина обмінного розщеплення між синглетним та триплетним рівнями становить:

```
ΔE = E_singlet - E_triplet = 2 · K_{1s, 2s} > 0
```

Оскільки обмінний інтеграл `K_{1s, 2s}` для атомних орбіталей є строго додатним (`K > 0`), триплетний стан з паралельними спінами завжди розташований **нижче за енергією**, ніж синглетний стан з антипаралельними спінами. Це математично доводить перше правило Гунда в атомній спектроскопії.

### 6.1. Заборони у Спектрах Гелію: Відсутність Основного Триплетного Стану

Принцип Паулі пояснює важливу особливість спектрів атома Гелію: для конфігурації основного стану `1s²` існує лише синглетний терм `1¹S₀`. Триплетний стан `1³S₁` для конфігурації `1s²` математично заборонений детермінантом Слейтера, оскільки за наявності двох електронів на одній 1s-орбіталі просторова частина функція повинна бути симетричною `φ_1s(r_1) φ_1s(r_2)`, що вимагає строго антисиметричного спінового стану (синглету). Спроба записати триплетний стан для `1s²` приводить до `Det ≡ 0`.

У результаті атом Гелію існує у двох ізольованих формах — парагелій (синглети) та ортогелій (триплети), оптичні переходи між якими за відсутності спін-орбітальної взаємодії строго заборонені за правилами відбору за спіном (`ΔS = 0`).
