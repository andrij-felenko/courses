# 🧮 Математичний апарат матриць Паулі та алгебра спінорів

Ця математична вставка розкриває алгебраїчний формалізм матриць Паулі, структуру двовимірного простору спінорів `ℂ²`, алгебру Лі `su(2)`, тензорні добутки для двоспінових систем та топологічні властивості унітарної групи обертань `SU(2)`.

## 1. Векторний простір спінорів Паулі та базисні стани

У квантовій механіці внутрішній стан спіну електрона зі значенням `s = 1/2` описується двокомпонентним комплексним вектором у Гільбертовому просторі `ℂ²` — спінором Паулі:

```
|Ψ⟩ = α |↑⟩ + β |↓⟩ = [ α ]
                      [ β ]
```

де `α, β ∈ ℂ` — комплексні амплітуди ймовірності, які задовольняють умову нормування `|α|² + |β|² = 1`. 

Ермітово-спряжений вектор-рядок (бра-вектор) має вигляд:

```
⟨Ψ| = [ α*  β* ]
```

Скалярний добуток двох спінорів `|Ψ₁⟩ = (α₁, β₁)ᵀ` та `|Ψ₂⟩ = (α₂, β₂)ᵀ` визначається як звичайний комплексний скалярний добуток векторів у просторі `ℂ²`:

```
⟨Ψ₁|Ψ₂⟩ = α₁* · α₂ + β₁* · β₂
```

Якщо спінори нормалізовані, то величина `|⟨Ψ₁|Ψ₂⟩|²` визначає ймовірність перехода між цими квантовими станами.

Базові власні стани оператора проєкції спіну `S_z` утворюють ортонормований базис у `ℂ²`:

```
|↑⟩ = [ 1 ]    (спін «вгору», власне значення S_z = +ℏ/2)
      [ 0 ]

|↓⟩ = [ 0 ]    (спін «вниз», власне значення S_z = -ℏ/2)
      [ 1 ]
```

Для цих станів виконуються умови ортонормованості `⟨↑|↑⟩ = 1`, `⟨↓|↓⟩ = 1` та `⟨↑|↓⟩ = 0`, а також умова повноти базису у просторі `ℂ²`:

```
|↑⟩⟨↑| + |↓⟩⟨↓| = [ 1  0 ] + [ 0  0 ] = [ 1  0 ] = I
                  [ 0  0 ]   [ 0  1 ]   [ 0  1 ]
```

## 2. Матриці Паулі та їх фундаментальні алгебраїчні властивості

Оператор трьох компонент вектора спіну `S = (S_x, S_y, S_z)` пов'язаний із трьома безрозмірними матрицями Паулі `σ = (σ_x, σ_y, σ_z)` тотожністю `S = (ℏ / 2) · σ`. У канонічному Z-представленні матриці Паулі мають вигляд:

```
σ_x = [ 0  1 ]
      [ 1  0 ]

σ_y = [ 0 -i ]
      [ i  0 ]

σ_z = [ 1  0 ]
      [ 0 -1 ]
```

Разом із 2×2 одиничною матрицею `I`:

```
I = [ 1  0 ]
    [ 0  1 ]
```

чотири матриці `{I, σ_x, σ_y, σ_z}` утворюють повний ортогональний базис у просторі усіх ермітових 2×2 матриць `M₂(ℂ)`. Це означає, що будь-який ермітів оператор `A` (фізична величина у двовимірній спіновій системі) може бути унікально розкладений у вигляді:

```
A = a₀ · I + a_x · σ_x + a_y · σ_y + a_z · σ_z = a₀ · I + (a · σ)
```

де коефіцієнти `a₀ = (1/2) trace(A)` та `a_i = (1/2) trace(A · σ_i)` є дійсними числами.

Основні алгебраїчні властивості матриць Паулі:

1. **Ермітовість та унітарність:** Кожна з трьох матриць є самоспряженою (`σ_i^† = σ_i`) та унітарною (`σ_i^† · σ_i = I`), звідки негайно випливає, що їхні квадрати дорівнюють одиничній матриці:
```
σ_x² = σ_y² = σ_z² = I
```

2. **Детермінант та шпур (след):**
```
det(σ_x) = det(σ_y) = det(σ_z) = -1
trace(σ_x) = trace(σ_y) = trace(σ_z) = 0
```

3. **Власні значення та власні вектори:** Кожна з матриць Паулі має два власні значення `λ = ±1`. Власні стани у відповідних базисах мають вигляд:
   - Для `σ_z`: `|↑_z⟩ = (1, 0)ᵀ` (для `+1`), `|↓_z⟩ = (0, 1)ᵀ` (для `-1`).
   - Для `σ_x`: `|↑_x⟩ = (1/√2) (1, 1)ᵀ` (для `+1`), `|↓_x⟩ = (1/√2) (1, -1)ᵀ` (для `-1`).
   - Для `σ_y`: `|↑_y⟩ = (1/√2) (1, i)ᵀ` (для `+1`), `|↓_y⟩ = (1/√2) (1, -i)ᵀ` (для `-1`).

4. **Антикомутаційні співвідношення:**
```
{σ_i, σ_j} = σ_i · σ_j + σ_j · σ_i = 2 · δ_ij · I
```

5. **Комутаційні співвідношення:**
```
[σ_i, σ_j] = σ_i · σ_j - σ_j · σ_i = 2 · i · ε_ijk · σ_k
```

де `δ_ij` — символ Кронекера, а `ε_ijk` — повністю антисиметричний тензор Леві-Чивіти (`ε₁₂₃ = 1`).

Поєднуючи комутатор та антикомутатор, отримуємо фундаментальну формулу для добутку двох довільних матриць Паулі:

```
σ_i · σ_j = δ_ij · I + i · ε_ijk · σ_k
```

## 3. Векторні тотожності Паулі та алгебра Лі su(2)

Генератори спінових обертань `T_a = (1/2) · σ_a` задовольняють алгебру Лі `su(2)`:

```
[T_a, T_b] = i · ε_abc · T_c
```

Структурні константи цієї алгебри Лі збігаються зі структурними константами алгебри `so(3)` для тривимірних просторових обертань, що підтверджує локальний ізоморфізм алгебр Лі `su(2) ≅ so(3)`.

Для довільних тривимірних векторів `a` та `b` скалярний добуток `(a · σ) = a_x σ_x + a_y σ_y + a_z σ_z` володіє важливою теоремою про згортку:

```
(a · σ) · (b · σ)
= ∑_i ∑_j (a_i σ_i) (b_j σ_j)                      [розклад по компонентах 3D-векторів]
= ∑_i ∑_j a_i b_j (δ_ij I + i ε_ijk σ_k)          [застосування тотожності добутку σ_i σ_j = δ_ij I + i ε_ijk σ_k]
= (a · b) · I + i · (a × b) · σ                    [групування скалярного a·b та векторного a×b добутків]
```

Звідси випливають важливі наслідки:
1. Якщо вектори паралельні (`a ∥ b`), то `a × b = 0`, і добуток перетворюється на скаляр: `(a · σ)(b · σ) = (a · b) I`.
2. Якщо вектор `n` є одиничним (`|n| = 1`), то тотожність спрощується до квадрованості одиниці:
```
(n · σ)² = (n · n) · I = I
```

Оператор проєкції спіну на довільний напрямок, заданий одиничним вектором `n = (sin θ cos φ, sin θ sin φ, cos θ)`, має власні стани, які виражаються через кути сфери Блоха:

```
(n · σ) |Ψ_n⁺⟩ = +1 · |Ψ_n⁺⟩
(n · σ) |Ψ_n⁻⟩ = -1 · |Ψ_n⁻⟩
```

де власні вектори задаються формулами:

```
|Ψ_n⁺⟩ = cos(θ/2) |↑⟩ + exp(i φ) sin(θ/2) |↓⟩
|Ψ_n⁻⟩ = sin(θ/2) |↑⟩ - exp(i φ) cos(θ/2) |↓⟩
```

## 4. Оператор обертання та 4п-топологічна фаза

Оскільки квадрат оператора `(n · σ)² = I`, парні степені матриці дорівнюють одиничній матриці `I`, а непарні — самій матриці `(n · σ)`. Це дозволяє обчислити матричну експоненту для оператора унітарного обертання спінора на скінченний кут `θ` навколо осі `n`:

```
U(n, θ) = exp(-i · (θ / 2) · (n · σ))
```

Розкладаючи експоненціальний оператор у ряд Тейлора:

```
exp(-i (θ/2) (n · σ))
= ∑_{k=0}^∞ (-i θ/2)^k / k! · (n · σ)^k                             [розклад експоненціала у ряд Тейлора]
= I · ∑_{p=0}^∞ (-1)^p (θ/2)^{2p} / (2p)! - i (n · σ) · ∑_{p=0}^∞ (-1)^p (θ/2)^{2p+1} / (2p+1)!  [розділення на парні та непарні степені за тотожністю (n·σ)² = I]
= I · cos(θ / 2) - i · (n · σ) · sin(θ / 2)                         [використання ряду Маклорена для косинуса й синуса]
```

Остаточний вигляд матриці обертання для вектор-напрямку `n = (n_x, n_y, n_z)` має вигляд:

```
U(n, θ) = [ cos(θ/2) - i n_z sin(θ/2)     (-i n_x - n_y) sin(θ/2)     ]
          [ (-i n_x + n_y) sin(θ/2)      cos(θ/2) + i n_z sin(θ/2)     ]
```

Простежимо результат обертання спінора на один повний кутовий оберт `θ = 2π` (360°):

```
U(n, 2π)
= I · cos(π) - i (n · σ) sin(π)       [підстановка кута θ = 2π у вираз U(n, θ)]
= I · (-1) - i (n · σ) · 0             [обчислення значений cos(π) = -1 та sin(π) = 0]
= -I                                   [алгебраїчне спрощення до мінус одиничної матриці]
```

При обертанні на 360° хвильова функція ферміона змінює свій знак на протилежний (`|Ψ⟩ → -|Ψ⟩`). Щоб повернути спіновий стан у вихідне значення без зміни фазового знака, необхідне обертання на **720° (4π)**:

```
U(n, 4π) = I · cos(2π) - i (n · σ) sin(2π) = +I
```

Геометрично це пов'язано з тим, що група Lie `SU(2)` є однозв'язною компактною групою Лі, яка топологічно є 3-сферою `S³`, і слугує універсальним дволистам накриттям для групи 3D-обертань `SO(3) ≅ RP³`.

При трансформуванні самого спінового оператора `σ_i` під дією обертання `U(n, θ)` виконується закон перетворення 3D-векторів:

```
U^†(n, θ) · σ_i · U(n, θ) = ∑_j R_ij(n, θ) · σ_j
```

де `R_ij(n, θ)` — стандартна 3×3 ортогональна матриця обертання групи `SO(3)`.

## 5. Двоспінові системи, тензорні добутки та заплутані стани

Для опису квантових систем із двох електронів (наприклад, у молекулі водню або гелієподібних атомах) Гільбертів простір утворюється як тензорний добуток двох двовимірних просторів:

```
H = ℂ² ⊗ ℂ² ≅ ℂ⁴
```

Базисні стани такої 4-вимірної системи будуються з тензорних добутків одночастинкових спінових станів:

```
|↑↑⟩ = |↑⟩ ⊗ |↑⟩ = [ 1, 0, 0, 0 ]ᵀ
|↑↓⟩ = |↑⟩ ⊗ |↓⟩ = [ 0, 1, 0, 0 ]ᵀ
|↓↑⟩ = |↓⟩ ⊗ |↑⟩ = [ 0, 0, 1, 0 ]ᵀ
|↓↓⟩ = |↓⟩ ⊗ |↓⟩ = [ 0, 0, 0, 1 ]ᵀ
```

Оператори спіну першої та другої частинки діють на відповідні підпростори:

```
S₁ = (ℏ / 2) · (σ ⊗ I)
S₂ = (ℏ / 2) · (I ⊗ σ)
```

Оператор сумарного спіну двох електронів дорівнює `S = S₁ + S₂`. Його квадрат `S² = (S₁ + S₂)² = S₁² + S₂² + 2 (S₁ · S₂)` має два можливих квантових значення сумарного спінового числа: `S_total = 0` (синглетний стан) та `S_total = 1` (триплетний стан).

4-вимірний базис можна перетворити на спін-симетричні та антисиметричні власні стани сумарного спіну:

1. **Синглетний стан (S = 0, M_S = 0):** повністю антисиметричний при перестановці частинок станів заплутаного типу (Беллівський стан):
```
|Singlet⟩ = (1 / √2) · ( |↑↓⟩ - |↓↑⟩ )
```
Для синглетного стану `S² |Singlet⟩ = 0` та `(S₁ · S₂) |Singlet⟩ = - (3/4) ℏ² |Singlet⟩`.

2. **Триплетні стани (S = 1):** повністю симетрична трійка станів:
```
|Triplet, M_S = +1⟩ = |↑↑⟩
|Triplet, M_S =  0⟩ = (1 / √2) · ( |↑↓⟩ + |↓↑⟩ )
|Triplet, M_S = -1⟩ = |↓↓⟩
```
Для триплетних станів `S² |Triplet⟩ = 2 ℏ² |Triplet⟩` та `(S₁ · S₂) |Triplet⟩ = + (1/4) ℏ² |Triplet⟩`.

Гейзенбергівська обмінна взаємодія між двома спінами описується гамільтоніаном `H_ex = - 2 J_ex (S₁ · S₂)`. Енергетична різниця між триплетним та синглетним станами дорівнює:

```
E_triplet - E_singlet = - 2 · J_ex · ( (1/4) ℏ² - (-3/4) ℏ² ) = - 2 · J_ex · ℏ²
```

Якщо обмінний інтеграл `J_ex > 0`, триплетний стан із паралельними спінами є енергетично вигіднішим, що є причиною виникнення **феромагнетизму**. Якщо `J_ex < 0`, вигіднішим є синглетний антипаралельний стан — виникає **антиферомагнетизм**.

## 6. Матриця густини Паулі та змішані спінові стани

Для опису ансамблю спінів у змішаному (некогерентному) квантовому стані використовується 2×2 **матриця густини Паулі** `ρ`.

Довільна матриця густини для спіну `s = 1/2` виражається через дійсний 3D-вектор поляризації `P` (вектор Блоха), де `|P| ≤ 1`:

```
ρ = (1 / 2) · (I + P · σ) = (1 / 2) · [ 1 + P_z       P_x - i P_y ]
                                       [ P_x + i P_y   1 - P_z     ]
```

Компоненти вектора поляризації визначаються як середня проєкція спіну `P_i = 2 ⟨S_i⟩ / ℏ = trace(ρ · σ_i)`.

Властивості матриці густини:
1. `trace(ρ) = 1` (умова нормування сумарної ймовірності).
2. `ρ^† = ρ` (ермітовість).
3. `ρ ≥ 0` (невід'ємна визначеність власних значень).
4. `trace(ρ²) = (1 + |P|²) / 2`.
   - Для **чистого стану** `|P| = 1`, тому `trace(ρ²) = 1` і `ρ² = ρ` (проектор).
   - Для **повністю хаотичного (неполяризованого) стану** `P = 0`, тому `ρ = (1/2) I`, `trace(ρ²) = 1/2`, а ентропія фон Неймана досягає максимуму `S = ln(2)`.

Квантова томографія спінового стану зводиться до вимірювання середніх значень трьох матриць Паулі `⟨σ_x⟩`, `⟨σ_y⟩`, `⟨σ_z⟩` на ідентично підготовленому ансамблі частинок, що дозволяє повністю відновити вихідну матрицю густини `ρ`.

Середнє квантовомеханічне значення довільної фізичної величини `A = a₀ I + (a · σ)` для змішаного стани обчислюється як:

```
⟨A⟩ = trace(ρ · A) = a₀ + (P · a)
```

Цей математичний апарат є точним інструментом для опису спінових вентилів, квантової томографії та квантової інформатики.
