У лютому 1922 року під час дослідження відхилення вузького пучка нейтральних атомів Срібла у сильно неоднорідному магнітному полі фізики Отто Штерн і Вальтер Ґерлах виявили явище, яке повністю зламало уявлення тогочасної класичної та ранньої квантової фізики. За класичною електродинамікою, атоми з довільно орієнтованими магнітними моментами мали б залишати на детекторній пластині суцільну розмиту смугу. Проте на склі утворилися дві виразні, симетрично віддалені вузькі лінії з порожнечею посередині.

Спроба пояснити цей результат у межах теорії Бора — Зоммерфельда через квантування просторової орієнтації орбітального моменту імпульсу `L` виявилася неможливою. Для атома Срібла в основному стані єдиний валентний електрон знаходиться на s-орбіталі з нульовим орбітальним моментом (`l = 0`). Число можливих проєкцій орбітального моменту завжди визначається квантовим числом `m_l ∈ {-l, -l+1, ..., +l}` і дорівнює непарній кількості станів `2l + 1` (для `l = 0` це 1 стан, для `l = 1` — 3 стани, для `l = 2` — 5 станів). Отримати парне число 2 за допомогою орбітального моменту геометрично неможливо, адже це вимагало б півцілого значення `l = 1/2`, що суперечить однозначності просторових хвильових функцій `Y_lm(θ, φ)`.

![Дослід Штерна — Ґерлаха](/book/physics/quantum-mechanics/electron-spin/img/fig1-stern-gerlach.svg)
*Експериментальна установка Штерна — Ґерлаха: пучок атомів Срібла під дією градієнта неоднорідного магнітного поля розщеплюється на два дискретних стани.*

Ця експериментальна суперечність знайшла пояснення лише у 1925 році, коли було сформульовано концепцію спіну як фундаментального внутрішнього ступеня вільності частинки.

Детальний аналіз історичного шляху від перших дослідів Франкфуртської лабораторії до створення релятивістської теорії викладено у вставці [📜 Історія відкриття спіну та експерименту Штерна — Ґерлаха](book:physics/quantum-mechanics/electron-spin/hist-stern-gerlach.md).

## 1. Неможливість класичного опису та механізм досліду Штерна — Ґерлаха

Для того щоб зрозуміти фундаментальність відкриття Штерна та Ґерлаха, необхідно проаналізувати механіку руху атома через неоднорідне магнітне поле.

Для експерименту було обрано атоми Срібла (`Ag`, атомний номер `Z = 47`). Електронна конфігурація атома Срібла у підподібній систематиці описується виразом `[Kr] 4d¹⁰ 5s¹`. Сорок шість внутрішніх електронів утворюють повністю заповнені сферично симетричні оболонки з нульовим сумарним орбітальним моментом `L_core = 0` та нульовим спіновим моментом `S_core = 0`. Отже, усі магнітні й механічні моменти атома Срібла в цілому визначаються виключно єдиним зовнішнім 5s-електроном.

Оскільки для s-орбіталі квантове число орбітального моменту дорівнює нулю (`l = 0`), просторовий хвильовий розподіл електронної хмари є строго сферично симетричним. Класичний магнітний момент орбітального руху дорівнює нулю:

```
μ_L = - (e / (2 · m_e)) · L = 0
```

При проходженні колімованого пучка таких атомів уздовж осі `Y` крізь простір між полюсами магніту, орієнтованими так, що градієнт поля спрямований уздовж осі `Z` (`dB_z / dz ≠ 0`), на кожний атом діє дефлексійна сила:

```
F_z = ∂(μ · B) / ∂z = μ_z · (dB_z / dz)
```

де `μ_z` — проєкція сумарного магнітного моменту атома на напрямок градієнта поля `Z`.

Якщо б магнітний момент був класичним вектором, який виникає від обертання зарядів і може орієнтуватися під довільним кутом `θ` до осі `Z`, то `μ_z = |μ| · cos(θ)` приймав би суцільний неперервний спектр значень від `-|μ|` до `+|μ|`. Кутове відхилення атомів у пучку підкорялося б розподілу швидкостей Максвелла — Больцмана у печі:

```
f(v) ∝ v³ · exp(- m_Ag · v² / (2 · k_B · T))
```

і на вихідному екрані утворилася б єдина безперервна смуга осадженого Срібла.

Проте експеримент показав суворе розділення пучка на два симетричних струмені, відхилених на кути, що відповідають проєкціям магнітного моменту:

```
μ_z = ± μ_B
```

де `μ_B = e ℏ / (2 m_e)` — магнетон Бора. Оскільки кількість відхилених ліній дорівнює 2, число можливих проєкцій моментів підкоряється виразу `2s + 1 = 2`, що однозначно визначає квантове число спіну `s = 1/2`.

## 2. Гіпотеза Уленбека — Ґоудсміта та релятивістський парадокс обертання

У листопаді 1925 року Джордж Уленбек та Семюел Ґоудсміт запропонували гіпотезу: електрон володіє власним внутрішнім моментом імпульсу `S` (від англійського *spin* — обертання), не пов'язаним з його переносним рухом у просторі. Квантове число цього власного моменту становить:

```
s = 1/2
```

А проєкція спінового моменту на довільно обрану вісь (наприклад, вісь `Z`) приймає два дискретних значення:

```
S_z = m_s · ℏ = ± (1/2) · ℏ
```

де `m_s = ±1/2` — спінове квантове число, а `ℏ = h / (2π)` — зведена стала Планка. Модуль вектора власного моменту імпульсу визначається загальним квантовомеханічним правилом для моментів:

```
|S| = √(s · (s + 1)) · ℏ = √(1/2 · 3/2) · ℏ = (√3 / 2) · ℏ
```

Першою природною спробою наочного тлумачення спіну було уявлення електрона як суцільної або порожнистої зарядженої кульки радіуса `r_e`, що обертається навколо власної осі. Проте ця класична механічна аналогія негайно приводить до фундаментального релятивістського парадоксу.

Якщо припустити, що маса електрона `m_e` та його заряд `e` рівномірно розподілені у сфері радіуса `r_e` (експериментальні межі для класичного радіуса електрона оцінюються як `r_e ≤ 10⁻¹⁸ m`), то класичний момент інерції суцільної кулі становить `I = (2/5) · m_e · r_e²`. Прирівняємо класичний момент обертання до квантового значення `ℏ / 2`:

```
I · ω = (2/5) · m_e · r_e² · ω = ℏ / 2
```

Звідси екваторіальна лінійна швидкість обертання `v_eq = ω · r_e` дорівнює:

```
v_eq = (5 / 4) · (ℏ / (m_e · r_e))
```

Підставляючи масу електрона `m_e = 9.11 × 10⁻³¹ kg` та експериментальну верхню межу радіуса `r_e = 10⁻¹⁸ m`, отримуємо:

```
v_eq ≈ 1.45 × 10¹¹ m/s ≈ 480 · c
```

Екватор кулі мусив би обертатися зі швидкістю, що майже у 500 разів перевищує швидкість світла у вакуумі `c`. 

У межах сучасної квантової теорії поля електрон описується як точкова фундаментальна частинка без внутрішньої просторової структури. Вимірювання у фізиці високих енергій на коллайдерах обмежують розмір електрона величиною `r < 10⁻¹⁸ m`.

Це означає, що спін **не є результатом фізичного обертання класичного тіла в тривимірному просторі**. Спін є внутрішньою, нерозривною релятивістською квантовою властивістю частинки — математично він виникає з незвідних нетривіальних представлень `(1/2, 0) ⊕ (0, 1/2)` групи Пуанкаре та групи Лоренца `SO(3,1)`.

## 3. Математичний апарат спінорів Паулі та 4п-топологія обертань

Оскільки спіновій змінній відповідають лише два можливих квантових стани («спін вгору» та «спін вниз»), простір спінових станів електрона є двовимірним комплексним Гільбертовим простором `ℂ²`. Повний стан електрона описується двокомпонентною комплексною хвильовою функцією — **спінором Паулі**:

```
Ψ(r, t) = [ ψ_up(r, t)   ] = ψ_up(r, t) · |↑⟩ + ψ_down(r, t) · |↓⟩
          [ ψ_down(r, t) ]
```

де базисні вектор-стовпчики мають вигляд:

```
|↑⟩ = [ 1 ]    (власний стан S_z із значенням +ℏ/2)
      [ 0 ]

|↓⟩ = [ 0 ]    (власний стан S_z із значенням -ℏ/2)
      [ 1 ]
```

Нормувальне співвідношення для спінора вимагає, щоб сума квадратів модулів компонент давала повну ймовірність виявлення частинки:

```
∫ (|ψ_up(r)|² + |ψ_down(r)|²) d³r = 1
```

Три компоненти векторного оператора спіну `S = (S_x, S_y, S_z)` виражаються через ермітові 2×2 **матриці Паулі** `σ = (σ_x, σ_y, σ_z)`:

```
S_x = (ℏ / 2) · [ 0  1 ]
                [ 1  0 ]

S_y = (ℏ / 2) · [ 0 -i ]
                [ i  0 ]

S_z = (ℏ / 2) · [ 1  0 ]
                [ 0 -1 ]
```

Оператори спіну задовольняють ті самі комутаційні співвідношення, що й оператори звичайного орбітального моменту імпульсу, що відображає фундаментальну симетрію обертань у фізиці:

```
[S_x, S_y] = i · ℏ · S_z
[S_y, S_z] = i · ℏ · S_x
[S_z, S_x] = i · ℏ · S_y
```

Зручним геометричним способом візуалізації чистого спінового стану є **сфера Блоха**. Довільний нормований спінор унікально задається двома сферичними кутами `θ` (полярний кут) та `φ` (азимутальний кут):

```
|Ψ⟩ = cos(θ / 2) · |↑⟩ + exp(i · φ) · sin(θ / 2) · |↓⟩
```

![Сфера Блоха та обертання спінора](/book/physics/quantum-mechanics/electron-spin/img/fig2-spinor-rotation.svg)
*Геометричне представлення спінового стану на сфері Блоха та зміна знаку хвильової функції при обертанні на 360° (2π).*

Оператор скінченного обертання спінового стану на кут `θ` навколо одиничного вектора осі `n` задається унітарним матричним експоненціалом:

```
U(n, θ) = exp(-i · (θ / 2) · (n · σ)) = I · cos(θ / 2) - i · (n · σ) · sin(θ / 2)
```

де `I` — 2×2 одинична матриця. Розглянемо результат застосування оператора обертання на один повний оберт у 360° (`θ = 2π`):

```
U(n, 2π) = I · cos(π) - i · (n · σ) · sin(π) = -I
```

Отже, при обертанні системи координат на 360° хвильова функція ферміона **змінює свій знак на протилежний**:

```
|Ψ(2π)⟩ = -|Ψ(0)⟩
```

Щоб повністю повернути спінор у початковий квантовий стан (з точністю до вихідної фази), необхідно здійснити обертання на кут **4π (720°)**:

```
U(n, 4π) = I · cos(2π) - 0 = +I
```

Математично це пов'язано з тим, що група симетрії спіну `SU(2)` є дволистам накриттям тривимірної групи обертань `SO(3)`. Цей ефект не є просто математичним формалізмом: зміну знаку хвильової функції нейтронів і електронів при 360°-геометричному обертанні у магнітному полі було безпосередньо виміряно в нейтронній інтерферометрії (досліди Рауха, Вернера й Гассі у 1975 році).

Повний алгебраїчний розрахунок добутків, комутаторів та векторних тотожностей матриць Паулі винесено у вставку [🧮 Математичний апарат матриць Паулі та алгебра спінорів](book:physics/quantum-mechanics/electron-spin/math-pauli-matrices.md).

## 4. Магнітний момент електрона, рівність Дірака та QED-поправки

Із наявністю моменту імпульсу пов'язане існування власних магнітних властивостей електрона. Для орбітального руху зв'язок між магнітним моментом `μ_L` та орбітальним моментом `L` задається через магнетон Бора `μ_B`:

```
μ_L = - (e / (2 · m_e)) · L = - (μ_B / ℏ) · L
```

де **магнетон Бора** є природною квантовою одиницею магнітного моменту:

```
μ_B = (e · ℏ) / (2 · m_e) ≈ 9.27401 × 10⁻²⁴ J / T
```

Для спінового магнітного моменту `μ_S` аналогічна пропорційність містить безрозмірний коефіцієнт — **гіромагнітне відношення (g-фактор)**:

```
μ_S = - g_e · (e / (2 · m_e)) · S = - g_e · (μ_B / ℏ) · S
```

З точки зору класичної електродинаміки для обертального поверхневого заряду сфери `g_e = 1`. Проте експерименти з ефекту Зеємана показали, що для спіну електрона `g_e ≈ 2`. 

Таємницю подвоєння g-фактора розкрив Поль Дірак у 1928 році. Створивши релятивістське хвильове рівняння першого порядку для 4-компонентного спінора `Ψ_D`:

```
(i · ℏ · γ^μ · ∂_μ - m_e · c) · Ψ_D = 0
```

де `γ^μ` — 4×4 матриці Дірака, він виявив, що при розкладі у нерелятивістському граничному наближенні (трансформація Фолді — Ваутхойзена) у зовнішньому електромагнітному полі природно виникає взаємодія Зеємана:

```
H_Z = (e · ℏ / (2 · m_e)) · (σ · B) = 2 · (μ_B / ℏ) · (S · B)
```

Також з рівняння Дірака автоматично виникає Дарвінівський член `H_Darwin = (ℏ² / (8 m_e² c²)) ∇²V(r)`, який описує швидкі релятивістські тремтіння електрона (*zitterbewegung*). Таким чином, релятивістська квантова механіка Дірака без жодних додаткових гіпотез теоретично вивела точне значення `g_e = 2`.

Подальший розвиток **квантової електродинаміки (QED)** у 1940-х роках показав, що значення `g_e` не є строго рівним 2 через флуктуації квантового вакууму (постійне випромінювання та поглинання електроном віртуальних фотонів і народження віртуальних електрон-позитронних пар). Першу радіаційну поправку обчислив Джуліан Швінгер у 1948 році:

```
a_e = (g_e - 2) / 2 = α / (2 · π) ≈ 0.0011614
```

де `α = e² / (4 π ε₀ ℏ c) ≈ 1 / 137.036` — стала тонкої структури. 

Сучасні багатопетлеві розрахунки в QED та вимірювання в одноелектронних пастках Пеннінга дають вражаючу точність узгодження до 12 значущих цифр:

```
g_e = 2.00231930436256
```

Це робить аномальний магнітний момент електрона найточніше перевіреним теоретичним передбаченням у всій історії природничих наук.

Енергетичний розклад підрівнів електрона у зовнішньому постійному магнітному полі `B_z` (ефект Зеємана) визначається виразом:

```
E_Z = - μ_S · B = g_e · μ_B · B_z · m_s = ± (1/2) · g_e · μ_B · B_z
```

Величина розщеплення між двома спіновими станами становить:

```
ΔE = g_e · μ_B · B_z
```

Вакуумні ефекти QED викликають також зсув Лемба (Lamb shift) — експериментально виявлене Лембом та Резерфордом у 1947 році тонке розщеплення між енергетичними рівнями `2S_1/2` та `2P_1/2` атома Водню (частота 1057 MHz). У теорії Дірака ці рівні мали строго однакову енергію, але флуктуації вакуумного електромагнітного поля трохи розмивають позицію електрона, що змінює взаємодію s-електронів із ядром.

## 5. Динаміка спіну у зовнішніх полях: ларморова прецесія та осциляції Рабі

Еволюція спінового стану у часі описується часовим рівнянням Шредінгера з гамільтоніаном Зеємана:

```
i · ℏ · (d|Ψ(t)⟩ / dt) = H_Z · |Ψ(t)⟩ = (g_e · μ_B / 2) · (σ · B(t)) · |Ψ(t)⟩
```

Розглянемо випадок однорідного постійного магнітного поля, спрямованого вздовж осі `Z`: `B = (0, 0, B_z)`. Гамільтоніан є діагональним у Z-базисі:

```
H_Z = (ℏ · ω_L / 2) · σ_z = [  ℏ · ω_L / 2        0         ]
                              [       0         - ℏ · ω_L / 2 ]
```

де `ω_L` — **частота Лармора**:

```
ω_L = (g_e · μ_B · B_z) / ℏ = γ_e · B_z
```

де `γ_e` — гіромагнітне відношення електрона. Розв'язок рівняння для довільного початкового спінового стану `|Ψ(0)⟩ = α₀ |↑⟩ + β₀ |↓⟩` має вигляд:

```
|Ψ(t)⟩ = α₀ · exp(-i · ω_L · t / 2) · |↑⟩ + β₀ · exp(+i · ω_L · t / 2) · |↓⟩
```

Обчислимо середні значення проєкцій спінового моменту як функції часу:

```
⟨S_z⟩(t) = ⟨Ψ(t)| S_z |Ψ(t)⟩ = (ℏ / 2) · (|α₀|² - |β₀|²) = const
⟨S_x⟩(t) = ⟨Ψ(t)| S_x |Ψ(t)⟩ = S_⊥ · cos(ω_L · t + φ₀)
⟨S_y⟩(t) = ⟨Ψ(t)| S_y |Ψ(t)⟩ = S_⊥ · sin(ω_L · t + φ₀)
```

де `S_⊥ = ℏ · |α₀ β₀|` — поперечна складова спіну.

![Прецесія Лармора](/book/physics/quantum-mechanics/electron-spin/img/fig3-larmor-precession.svg)
*Ларморова прецесія вектора середнього значення спіну ⟨S⟩ навколо напрямку магнітного поля B_z та часові осциляції поперечних компонент.*

Вектор середнього спіну `⟨S⟩` здійснює конічне обертання (прецесію Лармора) навколо векторного напрямку магнітного поля `B_z` зі сталою кутовою швидкістю `ω_L`.

Якщо окрім постійного поля `B_z` прикласти слабке перпендикулярне змінне радіочастотне поле `B_x(t) = B_1 · cos(ω · t)`, то при наближенні частоти зовнішнього поля до резонансу (`ω ≈ ω_L`) виникає явище **магнітного резонансу**. Спіновий вектор починає здійснювати додаткові перекидання між станами `|↑⟩` та `|↓⟩` — **осциляції Рабі** з резонансною частотою:

```
Ω_R = (g_e · μ_B · B_1) / (2 · ℏ)
```

Імовірність виявити електрон у перекинутому стані через час `t` при точному резонансі дорівнює:

```
P_{↑→↓}(t) = sin²(Ω_R · t / 2)
```

## 6. Спін-орбітальна взаємодія, Томасівська прецесія та тонка структура

У релятивістській квантовій механіці рух електрона в центральному кулонівському електричному полі ядра `E(r)` супроводжується важливою внутрішньою взаємодією між його спіновим і орбітальним моментами.

У власній супутній системі відліку електрона, який рухається зі швидкістю `v` у стаціонарному електричному полі `E = - (1/e) · (r / r) · (dV/dr)`, відповідно до перетворень Лоренца виникає ефективне магнітне поле:

```
B_eff = - (v × E) / c² = (1 / (e · c²)) · (1 / r) · (dV / dr) · (v × r)
```

Зважаючи на те, що класичний вектор орбітального моменту дорівнює `L = r × p = m_e · (r × v)`, поле приймає вигляд:

```
B_eff = - (1 / (e · m_e · c²)) · (1 / r) · (dV / dr) · L
```

Магнітний спіновий момент `μ_S` взаємодіє з цим ефективним полем. Урахування точного релятивістського ефекту Томасівської прецесії (кінематична поправка зв'язана з неінерційністю обертальної системи відліку електрона, яка дає множник `1/2` через кінематику Wigner-обертань при неколінеарних лоренцівських бустах) приводить до оператора **спін-орбітальної взаємодії**:

```
H_SO = (1 / (2 · m_e² · c²)) · (1 / r) · (dV / dr) · (L · S) = ξ(r) · (L · S)
```

Для водневоподібного атома з зарядом ядра `Z` кулонівський потенціал дорівнює `V(r) = - Z e² / (4 π ε₀ r)`, тому радіальна функція спін-орбітального зв'язку становить:

```
ξ(r) = (Z · e²) / (8 · π · ε₀ · m_e² · c² · r³)
```

Оскільки `H_SO` містить скалярний добуток `L · S`, окремі оператори `L_z` та `S_z` більше не комутують із повним гамільтоніаном атома і не є збережуваними величинами. Збережуваним є **повний момент імпульсу атома**:

```
J = L + S
```

Зведемо добуток `L · S` до операторів квадратів моментів. Підносимо вектор `J` до квадрата:

```
J² = (L + S)² = L² + S² + 2 · (L · S)
```

Звідси оператор скалярного добутку виражається тотожністю:

```
L · S = (1 / 2) · (J² - L² - S²)
```

Власні значення операторів `J²`, `L²` та `S²` дорівнюють `ℏ² j(j+1)`, `ℏ² l(l+1)` та `ℏ² s(s+1)` відповідно. Отже, енергетичний зсув рівнів за рахунок спін-орбітального зв'язку становить:

```
ΔE_SO = (ℏ² / 2) · ⟨ξ(r)⟩ · [ j(j+1) - l(l+1) - s(s+1) ]
```

Для заданого орбітального числа `l > 0` повне квантове число `j` може набувати двох значений: `j = l + 1/2` (спін і орбітальний момент паралельні) та `j = l - 1/2` (антипаралельні).

![Спін-орбітальне розщеплення](/book/physics/quantum-mechanics/electron-spin/img/fig4-spin-orbit-splitting.svg)
*Схема тонкої структури енергетичних рівнів атома під дією спін-орбітального зв'язку L·S та подальше розщеплення Зеємана у зовнішньому магнітному полі.*

Наприклад, для стану `2P` атома Водню (`l = 1, s = 1/2`):
1. При `j = 3/2`: `j(j+1) - l(l+1) - s(s+1) = 15/4 - 2 - 3/4 = +1`. Рівень `2P_3/2` зсувається вгору за енергією.
2. При `j = 1/2`: `j(j+1) - l(l+1) - s(s+1) = 3/4 - 2 - 3/4 = -2`. Рівень `2P_1/2` зсувається вниз за енергією.

У слабких магнітних полях розщеплення рівнів описується формулою Ланде через g-фактор Ланде:

```
g_J = 1 + [ j(j+1) + s(s+1) - l(l+1) ] / [ 2 · j(j+1) ]
```

Спін-орбітальна взаємодія знімає виродження і розщеплює одну спектральну лінію на дублет — утворюється **тонка структура спектральних ліній**. Класичним прикладом є дублет жовтої лінії Натрію (D-лінії Натрію): переходи `3P_3/2 → 3S_1/2` (лінія `D_2`, `589.0 nm`) та `3P_1/2 → 3S_1/2` (лінія `D_1`, `589.6 nm`).

Окрім тонкої структури, існує також **наднадтонка структура (hyperfine structure)**, яка викликана взаємодією спінового магнітного моменту електрона `S` з магнітним моментом ядра атома `I`. Гамільтоніан наднадтонкого зв'язку містить так званий контактний член Фермі `H_hf ∝ (S · I) δ³(r)`. У найпростішому атомі Водню (основни стан `1S_1/2`) спин електрона `s = 1/2` взаємодіє зі спином протона `i = 1/2`. Це розщеплює основний рівень на два наднадтонких підрівні зі значеннями повного спіну `F = 1` (триплет) та `F = 0` (синглет). Перехід між цими рівнями супроводжується випромінюванням радіохвилі довжиною **21 см (частота 1420.405 MHz)** — найважливішої радіолінії астрофізики для картографування нейтрального водню у Всесвіті.

## 7. Теорема спіну-статистики та фундаментальна стабільність матерії

Значення спіну визначає принципово новий тип квантової симетрії для систем багатьох тотожних частинок — **теорему спіну-статистики**, сформульовану Вольфгангом Паулі та Маркусом Фірцом у 1939–1940 роках на основі релятивістської квантової теорії поля:

1. Частинки з півцілим спіном (`s = 1/2, 3/2, 5/2, ...`) є **ферміонами** і підпорядковуються статистиці Фермі — Дірака. Загальна хвильова функція системи тотожних ферміонів є **антисиметричною** відносно перестановки будь-якої пари частинок:
```
Ψ(x₁, x₂) = - Ψ(x₂, x₁)
```

2. Частинки з цілим спіном (`s = 0, 1, 2, ...`) є **бозонами** і підпорядковуються статистиці Бозе — Ейнштейна. Їхня хвильова функція є **симетричною**:
```
Ψ(x₁, x₂) = + Ψ(x₂, x₁)
```

Безпосереднім наслідком антисиметрії хвильової функції ферміонів є **принцип заборони Паулі**: дві тотожні частинки з півцілим спіном (зокрема два електрони) не можуть одночасно перебувати у тотожному квантовому стані, описуваному однаковим набором чотирьох квантових чисел `(n, l, m_l, m_s)`:

```
Ψ(x, x) = - Ψ(x, x)  ⇒  Ψ(x, x) = 0
```

Саме цей принцип пояснює оболонкову структуру електронних шарів у багатоелектронних атомах, періодичний закон Дмитра Менделєєва, структуру хімічних зв'язків та існування стійких молекул. Якби електрон мав спін `s = 0` (тобто був бозоном), усі електрони атома упали б на найнижчий `1s`-орбітальний рівень, унеможлививши існування складної хімії та живих організмів.

Крім того, спіновий стан електронів визначає квантовомеханічну **обмінну взаємодію** між ними. Через вимогу антисиметрії хвильової функції підсумковий електростатичний кулонівський розвиток між двома електронами залежить від відносної орієнтації їхніх спінів (скалярного добутку `S_1 · S_2`):

```
H_ex = - 2 · J_ex · (S_1 · S_2)
```

де `J_ex` — обмінний інтеграл перекриття просторових хвильових функцій. Якщо `J_ex > 0`, енергетично вигідним стає паралельне розташування спінів — виникає **феромагнетизм** у залізі, нікелі та кобальті. 

Зв'язок між намагніченістю феромагнетика та спіновим моментом електронів був експериментально доведений у класичних дослідах Альберта Ейнштейна та Ворта де Гааза (ефект Ейнштейна — де Гааза, 1915 рік), а також у дослідах Самюеля Барнетта (ефект Барнетта, 1915 рік), де закручування тіла викликало його намагнічування.

У системі з двох електронів (наприклад, атом Гелію у стані `1s 2s`) взаємодія ділить стани на парагелій (синглетний стан зі спіном `S = 0`) та ортогелій (триплетний стан зі спіном `S = 1`). Оскільки оптичні випромінювальні переходи відбуваються без зміни сумарного спіну (`ΔS = 0`), переходи між ортогелієм та парагелієм є строго забороненими у дипольному наближенні.

## 8. Інженерні та квантово-технологічні застосування

Знання та контроль спінового стану електронів сформували цілий пласт сучасних високих технологій:

1. **Електронний парамагнітний резонанс (ЕПР):** Використовується в хімії, біології та матеріалознавстві для дослідження вільних радикалів, дефектів у кристалах і точної структури білкових комплексів шляхом вимірювання резонансного поглинання мікрохвильового випромінювання у магнітному полі.

2. **Спінтроніка (спінова електроніка):** Технологічний напрям, у якому для перенесення й обробки інформації використовується не лише заряд електрона, а й його спіновий момент. 
   - *Гігантський магнітоопір (GMR)*: Відкритий Альбертом Фертом та Петером Ґрюнбергом у 1988 році (Нобелівська премія 2007 року). Зміна орієнтації спінів у багатошарових феромагнітних і тонкоплівкових структурах змінює електричний опір на десятки відсотків, що дозволило створити надчутливі зчитувальні головки для жорстких дисків HDD.
   - *Тунельний магнітоопір (TMR)* та *MRAM*: Використання магнітних тунельних переходів у спіновій оперативній пам'яті (STT-MRAM) забезпечує створення енергонезалежних масивів пам'яті з наносекундною швидкістю доступу та нескінченним ресурсом перезапису.
   - *Спіновий ефект Холла (Spin Hall Effect, SHE)* та *спін-орбітальний крутильний момент (SOT)*: Дозволяють генерувати чисто спінові струми у важких металах (Pt, Ta, W) за рахунок спін-орбітального розсіяння електронів без перенесення заряду, що дає змогу перемикати магнітні осередки пам'яті при наднизькому енергоспоживанні.

3. **Квантові обчислення та спінові кубіти:** Окремий електрон, утримуваний у напівпровідниковій квантовій точці (на базі кремнію `Si` або арсеніду галію `GaAs`) чи в азотно-вакансійному центрі (NV-центрі) в алмазі, слугує двохрівневим квантовим кубітом. Спінові стани `|↑⟩` та `|↓⟩` мають надзвичайно довгий час когерентності (до секунд у збагаченому ізотопом `²⁸Si` кремнії), що робить їх одним із найбільш перспективних кандидатів для побудови масштабованих квантових комп'ютерів.

> 🔧 **Навіщо це.** Спін електрона перестав бути абстрактною теоретичною концепцією квантової фізики і перетворився на фундамент сучасної мікроелектроніки та накопичення даних. Відкриття гігантського магнітоопору (GMR) дозволило збільшити щільність запису на жорстких дисках у сотні разів, а спінтроніка нового покоління (MRAM) створює енергонезалежну оперативну пам'ять із необмеженим ресурсом перезапису та часом доступу в наносекунди. Без урахування спіну та матриць Паулі неможливо розрахувати ані магнітно-резонансний томограф, ані напівпровідникові квантові процесори на спінових кубітах.
