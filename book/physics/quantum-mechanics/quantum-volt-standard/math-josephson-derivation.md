# 🧮 Математичний вивід рівнянь Джозефсона та квантування напруги

Ця математична вставка містить суворий квантовомеханічний вивід стаціонарного й нестаціонарного рівнянь Джозефсона з двохстанкової системи Шредінгера, математичний аналіз калібрувально-інваріантної фази у магнітному полі (ефект Фраунгофера), вивід енергії Джозефсонівського зв'язку через функціонал Гінзбурга — Ландау, а також вивід квантованих сходинок Шапіро через розклад фази у ряд Бесселя.

### Двохстанкова модель слабозв'язаних надпровідників

Розглянемо систему з двох надпровідних електродів, розділених тонким ізолюючим діелектричним бар'єром. Нехай `Ψ_1` та `Ψ_2` — макроскопічні хвильові функції бозе-конденсату куперівських пар у першому й другому надпровідниках відповідно. Кожна з цих функцій володіє власною амплітудою (квадрат якої дорівнює густині пар `n`) та макроскопічною фазою `θ`:

```
Ψ_1 = √n_1 · e^(i · θ_1)
Ψ_2 = √n_2 · e^(i · θ_2)
```

де `n_1, n_2` — густини куперівських пар у об'ємі першого й другого надпровідників, а `θ_1, θ_2` — їхні макроскопічні квантові фази.

Зв'язок між двома квантовими станами через тонкий бар'єр описується системою зв'язаних часових рівнянь Шредінгера. Цей підхід є узагальненням феноменологічної моделі Фейнмана для двох зчеплених квантових осциляторів:

```
i · ℏ · (dΨ_1 / dt) = U_1 · Ψ_1 + K · Ψ_2
i · ℏ · (dΨ_2 / dt) = U_2 · Ψ_2 + K · Ψ_1
```

де `U_1, U_2` — потенціальні енергії куперівських пар у відповідних надпровідних електродах, а `K` — коефіцієнт квантового тунельного зв'язку через бар'єр (матричний елемент взаємодії).

### Вивід стаціонарного та нестаціонарного рівнянь

Прикладемо до тунельного контакту зовнішню електричну напругу `V`. Оскільки кожна куперівська пара складається з двох електронів і має електричний заряд `q = 2e`, різниця потенціальних енергій між двома надпровідниками становить `U_1 - U_2 = 2e · V`.

Оберемо нульовий рівень відліку енергії симетрично посередині бар'єра так, щоб `U_1 = e · V`, а `U_2 = -e · V`. Підставимо вирази для хвильових функцій `Ψ_1` та `Ψ_2` у систему часових рівнянь Шредінгера:

```
i · ℏ · d(√n_1 · e^(i·θ_1)) / dt = e · V · √n_1 · e^(i·θ_1) + K · √n_2 · e^(i·θ_2)
i · ℏ · d(√n_2 · e^(i·θ_2)) / dt = -e · V · √n_2 · e^(i·θ_2) + K · √n_1 · e^(i·θ_1)
```

Виконуємо диференціювання лівої частини за правилом добутку складних функцій:

```
d(√n_1 · e^(i·θ_1)) / dt = (dn_1/dt) / (2·√n_1) · e^(i·θ_1) + i · (dθ_1/dt) · √n_1 · e^(i·θ_1)
```

Поділимо обидві частини першого рівняння на експоненціальний фазовий множник `e^(i·θ_1)`, а другого рівняння — на `e^(i·θ_2)`. Введемо головну динамічну змінну системи — різницю квантових фаз `Δφ = θ_2 - θ_1`:

```
i · ℏ · [ (dn_1/dt) / (2·√n_1) + i · (dθ_1/dt) · √n_1 ] = e · V · √n_1 + K · √n_2 · e^(i·Δφ)
i · ℏ · [ (dn_2/dt) / (2·√n_2) + i · (dθ_2/dt) · √n_2 ] = -e · V · √n_2 + K · √n_1 · e^(-i·Δφ)
```

Використовуючи формулу Ейлера для комплексної експоненти `e^(i·Δφ) = cos(Δφ) + i · sin(Δφ)`, розділимо дійсні та уявні частини обох рівнянь.

З уявних частин систем отримуємо рівняння неперервності для швидкості зміни густини носіїв заряду в кожному з надпровідників:

```
dn_1 / dt =  (2 · K / ℏ) · √(n_1 · n_2) · sin(Δφ)
dn_2 / dt = -(2 · K / ℏ) · √(n_1 · n_2) · sin(Δφ)
```

Оскільки надпровідні електроди є однаковими за матеріалом (`n_1 ≈ n_2 = n`), загальна густина носіїв залишається постійною, а зміна кількості частинок у часі описує макроскопічний тунельний надструм `I = q · (dn_1/dt) · A = 2e · (dn_1/dt) · A` через ефективну площу контакта `A`:

```
I = (2e · A) · (2 · K · n / ℏ) · sin(Δφ) = I_c · sin(Δφ)
```

де `I_c = 4e · K · n · A / ℏ` — **критичний струм Джозефсона**. Це виражає **стаціонарне рівняння Джозефсона**: макроскопічний надструм визначається синусом різниці квантових фаз.

З дійсних частин системи рівнянь отримуємо швидкості зміни індивідуальних фаз у кожному з надпровідників:

```
dθ_1 / dt = -(e · V / ℏ) - (K / ℏ) · √(n_2 / n_1) · cos(Δφ)
dθ_2 / dt =  (e · V / ℏ) - (K / ℏ) · √(n_1 / n_2) · cos(Δφ)
```

Віднімаючи перше рівняння від другого при рівних густинах `n_1 = n_2`, члени з косинусом взаємно скорочуються, даючи закон часової еволюції різниці фаз:

```
d(Δφ) / dt = d(θ_2 - θ_1) / dt = 2e · V / ℏ = (2π · 2e / h) · V
```

Це і є **нестаціонарне рівняння Джозефсона**, яке показує, що електрична напруга є прямим мірилом швидкості зміни квантової фази.

### Енергія Джозефсонівського зв'язку та функціонал Гінзбурга — Ландау

Робота, яка виконується зовнішнім джерелом струму при зміні фази `Δφ`, накопичується у вигляді квантової енергії фазового зв'язку переходу `E_J`. Обчислимо цю енергію шляхом інтегрування електричної потужності `P(t) = I(t) · V(t)` за часом:

```
E_J = ∫ I(t) · V(t) dt = ∫ I_c · sin(Δφ) · (ℏ / 2e) · (d(Δφ)/dt) dt
    = (ℏ · I_c / 2e) · ∫ sin(Δφ) d(Δφ) = (ℏ · I_c / 2e) · (1 - cos(Δφ))
```

Цей вираз доводить, що потенціальна енергія Джозефсонівського контакта досягає мінімуму при `Δφ = 0` і є періодичною функцією фази з періодом `2π`. Величина `E_J0 = ℏ · I_c / 2e` характеризує енергію когерентного зв'язку куперівських пар у бар'єрі.

### Калібрувально-інваріантна фаза та магнітна дифракція Фраунгофера

У присутності зовнішнього магнітного поля з векторним потенціалом `A` імпульс куперівської пари модифікується виразом `p = 2m · v + 2e · A`. Щоб канонічна фаза залишалася інваріантною відносно калібрувальних перетворень електромагнітного поля, вводиться калібрувально-інваріантна різниця фаз `γ`:

```
γ = Δφ - (2e / ℏ) · ∫ A · dl
```

де інтеграл береться вздовж шляху тунелювання крізь бар'єр.

При прикладенні однорідного магнітного поля `B` у площині контакту ширина діелектрика `d` та глубина проникання поля в надпровідники `λ_L` визначають ефективне перетин `d_eff = d + 2 · λ_L`. Магнітний потік крізь перехід дорівнює `Φ = B · L · d_eff`.

Інтегрування густини струму по ширині контакту `L` дає модульований критичний струм:

```
I_c(B) = I_{c0} · | sin(π · Φ / Φ_0) / (π · Φ / Φ_0) |
```

де `Φ_0 = h / 2e ≈ 2.067833 × 10⁻¹⁵` Вб — **квант магнітного потоку**. Ця дифракційна залежність точно відповідає оптичній дифракції на одній щілині (картині Фраунгофера) і слугує найсуворішим доказом макроскопічної квантової когерентності тунелювання.

### Математичний вивід сходинок Шапіро через ряд Бесселя

Розглянемо випадок, коли до контакта Джозефсона подано суму постійної напруги зсуву `V_dc` та високочастотної змінної напруги `V_rf · cos(ω · t)` від зовнішнього СВЧ генератора з частотою `ω = 2π · f`. Загальна напруга на бар'єрі дорівнює:

```
V(t) = V_dc + V_rf · cos(ω · t)
```

Проінтегруємо нестаціонарне рівняння Джозефсона за часом `t`:

```
Δφ(t) = Δφ_0 + ∫ (2e / ℏ) · [V_dc + V_rf · cos(ω · t)] dt
      = Δφ_0 + ω_J · t + (2e · V_rf / (ℏ · ω)) · sin(ω · t)
```

де `ω_J = (2e / ℏ) · V_dc` — кутова частота власної Джозефсонівської генерації.

Введемо безрозмірний параметр амплітуди СВЧ модуляції `z = 2e · V_rf / (ℏ · ω) = 2e · V_rf / (h · f)`. Підставимо отриману вище часову залежність фази у стаціонарне рівняння надструму:

```
I(t) = I_c · sin[ Δφ_0 + ω_J · t + z · sin(ω · t) ]
```

Використовуючи тригонометричну формулу синуса суми двох аргументів та фундаментальну комплексну тотожність Якобі — Ангера для розкладу комплексної експоненти у нескінченний ряд за функціями Бесселя першого роду `J_n(z)`:

```
e^(i · z · sin(ω·t)) = ∑_{n=-∞}^{+∞} J_n(z) · e^(i · n · ω · t)
```

отримуємо розклад тунельного надструму на повний спектр гармонічних складових:

```
I(t) = I_c · ∑_{n=-∞}^{+∞} (-1)^n · J_n(z) · sin(Δφ_0 + (ω_J - n · ω) · t)
```

Обчислимо постійну складову струму `I_dc = <I(t)>` шляхом усереднення виразу за часом. Оскільки середнє значення гармонічного синуса за період дорівнює нулю, постійний струм зникає для всіх частот, за винятком тих умов, коли аргумент під синусом перестає залежати від часу. Це відповідає умові резонансу (фазового захоплення):

```
ω_J = n · ω   ⇒   (2e / ℏ) · V_dc = n · (2π · f)
```

Скорочуючи `2π`, отримуємо квантоване значення напруги на `n`-ій сходинці Шапіро:

```
V_dc = n · (h · f / 2e) = n · (f / K_J)
```

При виконанні резонансного співвідношення постійний струм на сходинці може набувати будь-якого значення залежно від довільної фазової константи `Δφ_0` у межах інтервалу:

```
ΔI_n = 2 · I_c · |J_n( 2e · V_rf / (h · f) )|
```

Це математично доводить, що напруга на сходинці є суворо квантованою і залишається абсолютно стабільною при будь-яких флуктуаціях струму зсуву в межах ширини сходинки `ΔI_n`.
