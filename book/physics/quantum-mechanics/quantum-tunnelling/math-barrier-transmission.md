# 🧮 Математичний вивід коефіцієнта прозорості потенціального бар'єра

Цей математичний аналіз містить строге виведення коефіцієнта прозорості (коефіцієнта тунелювання) для прямокутного потенціального бар'єра, аналіз явищ надбар'єрного відбивання та резонансного проходження, а також розрахунок напівкласичного наближення Вентцеля — Крамерса — Бріллюена (ВКБ) для потенціальних бар'єрів довільної гладкої форми.

## 1. Постановка задачі для одновимірного рівняння Шредінгера

Розглянемо квантовомеханічний рух стаціонарної частинки масою `m` із фіксованою енергією `E`, яка поширюється вздовж координатної осі `x` у потенціальному полі `V(x)`. Просторова поведінка квантового стану описується комплексною хвильовою функцією `ψ(x)`, що задовольняє одновимірне стаціонарне рівняння Шредінгера:

```
- (ℏ² / (2 m)) (d²ψ(x) / dx²) + V(x) ψ(x) = E ψ(x)
```

Задамо прямокутний потенціальний бар'єр скінченної ширини `a` та висоти `V₀`:

```
V(x) = 0,   при x < 0          (Область I: простір перед бар'єром)
V(x) = V₀,  при 0 ≤ x ≤ a      (Область II: потенціальний бар'єр)
V(x) = 0,   при x > a          (Область III: простір за бар'єром)
```

У цьому математичному виводі спочатку детально розглядається випадок тунелювання, коли енергія частини є меншою за висоту потенційного бар'єра: `0 < E < V₀`.

## 2. Загальні розв'язки рівняння Шредінгера у трьох областях

Оскільки у кожній із трьох областей потенціал `V(x)` є сталою величиною, диференціальне рівняння Шредінгера являє собою лінійне диференціальне рівняння другого порядку зі сталими коефіцієнтами. Загальний розв'язок у кожній області записується у вигляді лінійної комбінації експоненціальних функцій.

### Область I (`x < 0`)
У цій області потенціал дорівнює нулю `V(x) = 0`. Рівняння Шредінгера набуває вигляду:

```
d²ψ_I / dx² + (2 m E / ℏ²) ψ_I = 0
```

Введемо дійсний хвильовий вектор падаючої частинки `k`:

```
k = √(2 m E) / ℏ
```

Загальний розв'язок є суперпозицією двох монохроматичних хвиль — падаючої хвилі, що рухається у додатному напрямку осі `x` з амплітудою `A`, та відбитої хвилі, що рухається у зворотному напрямку з амплітудою `B`:

```
ψ_I(x) = A exp(i k x) + B exp(-i k x)
```

### Область II (`0 ≤ x ≤ a`)
Усередині бар'єра потенціальна енергія перевищує повну енергію частинки `V(x) = V₀ > E`. Перепишемо рівняння Шредінгера у вигляді:

```
d²ψ_II / dx² - (2 m (V₀ - E) / ℏ²) ψ_II = 0
```

Оскільки дефіцит енергії `V₀ - E > 0` є додатною величиною, введемо дійсний коефіцієнт згасання хвильової функції `κ`:

```
κ = √(2 m (V₀ - E)) / ℏ
```

Розв'язком рівняння у класично забороненій області є не осцилююча хвиля, а сума двох дійсних експоненціальних функцій зі спадною та зростаючою амплітудами:

```
ψ_II(x) = C exp(-κ x) + D exp(κ x)
```

Додатна експонента `exp(κ x)` із коефіцієнтом `D` виникає внаслідок наявності правої межі бар'єра `x = a`, на якій відбувається внутрішнє відбивання хвилі, що загасає.

### Область III (`x > a`)
За бар'єром потенціал знову дорівнює нулю `V(x) = 0`. Рівняння аналогічне Області I:

```
d²ψ_III / dx² + k² ψ_III = 0
```

Оскільки за бар'єром відсутні будь-які неоднорідності або джерела відбивання, хвильова функція містить лише пройдену (тунельовану) хвилю, яка поширюється праворуч з амплітудою `F`:

```
ψ_III(x) = F exp(i k x)
```

## 3. Фізичний зміст неперервності та граничні умови

Закони квантової механіки вимагають, щоб густина ймовірності `ρ(x) = |ψ(x)|²` та вектор густини потоку ймовірності `J(x)` були неперервними у всьому просторі. Вектор густини потоку ймовірності визначається формулою:

```
J(x) = (ℏ / (2 m i)) [ ψ*(x) (dψ(x) / dx) - ψ(x) (dψ*(x) / dx) ] = (ℏ / m) Im[ ψ*(x) (dψ(x) / dx) ]
```

Для забезпечення неперервності потоку хвильова функція `ψ(x)` та її перша похідна по координаті `dψ(x)/dx` мають бути строго неперервними у точках розриву потенціалу `x = 0` та `x = a`.

Сформулюємо систему з чотирьох лінійних алгебраїчних рівнянь.

На першій межі `x = 0`:

```
ψ_I(0) = ψ_II(0)              ⇒  A + B = C + D                          [Рівняння 1]
(dψ_I/dx)|_0 = (dψ_II/dx)|_0   ⇒  i k (A - B) = κ (-C + D)               [Рівняння 2]
```

На другій межі `x = a`:

```
ψ_II(a) = ψ_III(a)            ⇒  C exp(-κ a) + D exp(κ a) = F exp(i k a)               [Рівняння 3]
(dψ_II/dx)|_a = (dψ_III/dx)|_a ⇒  κ (-C exp(-κ a) + D exp(κ a)) = i k F exp(i k a)     [Рівняння 4]
```

## 4. Алгебраїчний вивід коефіцієнта прозорості T

Коефіцієнт прозорості `T` (коефіцієнт передачі) визначається як відношення модуля густини потоку ймовірності пройденої хвилі до падаючої хвилі:

```
T = |J_transmitted| / |J_incident| = ( (ℏ k / m) |F|² ) / ( (ℏ k / m) |A|² ) = |F|² / |A|²
```

Для знаходження відношення `A / F` розв'яжемо систему рівнянь [3] та [4] відносно коефіцієнтів `C` та `D` через амплітуду пройшовши хвилі `F`.

Поділимо Рівняння 4 на `κ`:

```
-C exp(-κ a) + D exp(κ a) = (i k / κ) F exp(i k a)
```

Додаючи та віднімаючи це рівняння з Рівнянням 3, виражаємо коефіцієнти `C` та `D`:

```
2 C exp(-κ a) = (1 - i k / κ) F exp(i k a)  ⇒  C = (1/2) (1 - i k / κ) F exp((i k + κ) a)
2 D exp(κ a)  = (1 + i k / κ) F exp(i k a)  ⇒  D = (1/2) (1 + i k / κ) F exp((i k - κ) a)
```

Тепер підставимо отримані вирази для `C` та `D` у Рівняння 1 та Рівняння 2:

```
A + B = C + D = (1/2) F exp(i k a) [ (1 - i k / κ) exp(κ a) + (1 + i k / κ) exp(-κ a) ]
```

Для Рівняння 2 виразимо різницю `A - B`:

```
A - B = (κ / (i k)) (-C + D) = (1/2) F exp(i k a) [ (κ / (i k)) ( (1 + i k / κ) exp(-κ a) - (1 - i k / κ) exp(κ a) ) ]
```

Додамо вирази для `(A + B)` та `(A - B)`, щоб виключити амплітуду відбитої хвилі `B`:

```
2 A = (1/2) F exp(i k a) [ (1 - i k / κ) exp(κ a) + (1 + i k / κ) exp(-κ a) + (κ / (i k)) (1 + i k / κ) exp(-κ a) - (κ / (i k)) (1 - i k / κ) exp(κ a) ]
```

Згрупуємо доданки при експонентах `exp(κ a)` та `exp(-κ a)`:

```
2 A = (1/2) F exp(i k a) [ exp(κ a) ( 1 - i k / κ - κ / (i k) + 1 ) + exp(-κ a) ( 1 + i k / κ + κ / (i k) + 1 ) ]
```

Ураховуючи, що `- κ / (i k) = i κ / k`, спростимо дужки:

```
2 A = (1/2) F exp(i k a) [ exp(κ a) ( 2 - i (k / κ - κ / k) ) + exp(-κ a) ( 2 + i (k / κ - κ / k) ) ]
```

Використаємо означення гіперболічних функцій `cosh(y) = (exp(y) + exp(-y)) / 2` та `sinh(y) = (exp(y) - exp(-y)) / 2`:

```
2 A = F exp(i k a) [ 2 cosh(κ a) + i (κ / k - k / κ) sinh(κ a) ]
```

Поділивши обидві частини на 2, отримуємо відношення амплітуд `A / F`:

```
A / F = exp(i k a) [ cosh(κ a) + i ((κ² - k²) / (2 k κ)) sinh(κ a) ]
```

Обчислимо квадрат модуля комплексної величини `|A / F|²`:

```
|A / F|² = (A / F) (A / F)* = cosh²(κ a) + ((κ² - k²) / (2 k κ))² sinh²(κ a)
```

Застосуємо фундаментальну гіперболічну тотожність `cosh²(κ a) = 1 + sinh²(κ a)`:

```
|A / F|² = 1 + sinh²(κ a) + ((κ² - k²) / (2 k κ))² sinh²(κ a) = 1 + [ 1 + (κ² - k²)² / (4 k² κ²) ] sinh²(κ a)
```

Зведем дріб у дужках до спільного знаменника:

```
1 + (κ² - k²)² / (4 k² κ²) = (4 k² κ² + κ⁴ - 2 k² κ² + k⁴) / (4 k² κ²) = (κ² + k²)² / (4 k² κ²)
```

Підставимо вирази для хвильового вектора `k² = 2 m E / ℏ²` та коефіцієнта згасання `κ² = 2 m (V₀ - E) / ℏ²`:

```
κ² + k² = (2 m / ℏ²) [ (V₀ - E) + E ] = 2 m V₀ / ℏ²
```

Обчислимо відношення:

```
(κ² + k²)² / (4 k² κ²) = (2 m V₀ / ℏ²)² / [ 4 (2 m E / ℏ²) (2 m (V₀ - E) / ℏ²) ] = V₀² / (4 E (V₀ - E))
```

Підставляючи цей коефіцієнт, отримуємо **точну формулу для коефіцієнта прозорості прямокутного бар'єра**:

```
T = |F / A|² = 1 / [ 1 + (V₀² / (4 E (V₀ - E))) sinh²(κ a) ]
```

## 5. Граничний випадок високого або широкого бар'єра

У фізичних додатках (наприклад, альфа-розпад чи автоелектронна емісія) параметр загасання `κ a` значно перевищує одиницю (`κ a >> 1`). За цієї умови гіперболічний синус розкладається через головну експоненту:

```
sinh(κ a) = (exp(κ a) - exp(-κ a)) / 2 ≈ (1/2) exp(κ a) >> 1
```

Квадрат гіперболічного синуса дорівнює:

```
sinh²(κ a) ≈ (1/4) exp(2 κ a) >> 1
```

Оскільки другий доданок у знаменнику формули для `T` значно більший за одиницю, одиницею у знаменнику можна знехтувати:

```
T ≈ 1 / [ (V₀² / (4 E (V₀ - E))) · (1/4) exp(2 κ a) ] = 16 (E / V₀) (1 - E / V₀) exp(-2 κ a)
```

Головним чинником, що визначає експоненціальне зменшення ймовірності тунелювання, є показник загасання `exp(-2 κ a)`. Підставивши значення `κ`, отримуємо:

```
T ∝ exp( - (2 a / ℏ) √(2 m (V₀ - E)) )
```

## 6. Надбар'єрне відбивання та резонансне проходження (E > V₀)

Якщо енергія частинки перевищує висоту бар'єра (`E > V₀`), за класичною механікою частинка зі 100% ймовірністю проходить над бар'єром. У квантовій механіці хвильова функція відчуває стрибок потенціалу у точках `x = 0` та `x = a`, що приводить до **надбар'єрного відбивання**.

Усередині бар'єра хвильовий вектор залишається дійсним:

```
k₂ = √(2 m (E - V₀)) / ℏ
```

Замінивши у точній формулі `κ` на `-i k₂`, гіперболічний синус перетворюється у тригонометричний синус `sinh(i k₂ a) = i sin(k₂ a)`. Формула прозорості для надбар'єрного руху набуває вигляду:

```
T = 1 / [ 1 + (V₀² / (4 E (E - V₀))) sin²(k₂ a) ]
```

Аналіз цієї формули показує два важливих явища:

1. **Надбар'єрне відбивання:** Навіть при `E > V₀` коефіцієнт прозорості є меншим за одиницю `T < 1`. Частина квантової хвилі відбивається від потенціального стрибка.
2. **Резонансне проходження (ефект Рамзауера — Таунсенда):** Коли на ширині бар'єра вкладається ціле число напівхвиль `k₂ a = n π` (де `n = 1, 2, 3...`), тригонометричний синус перетворюється на нуль `sin(n π) = 0`. При цьому коефіцієнт прозорості стає суворо рівним одиниці:
   ```
   T = 1.0  (100% проходження без відбивання)
   ```
   Це явище є квантовою інтерференційною аналогією оптичного просвітлення лінз у багатошарових оптичних покриттях.

## 7. Напівкласичне наближення ВКБ для бар'єрів довільної форми

Для гладких потенціальних бар'єрів `V(x)` довільної форми (наприклад, параболічних чи кулонівських) аналітичне розв'язання рівняння Шредінгера виконують у напівкласичному наближенні Вентцеля — Крамерса — Бріллюена (ВКБ).

Представимо хвильову функцію у вигляді:

```
ψ(x) = exp( (i / ℏ) S(x) )
```

де `S(x)` — комплексний аналог класичної дії. Розкладаючи дію `S(x)` у степеневий ряд за малим параметром `ℏ`:

```
S(x) = S₀(x) + ℏ S₁(x) + ...
```

у нульовому наближенні отримуємо класичний імпульс частинки `p(x) = √(2 m (E - V(x)))`.

У класично забороненій області між точками повороту `x₁` та `x₂` (де `V(x₁) = V(x₂) = E`), імпульс стає уявною величиною `p(x) = i ℏ κ(x)`, де локальний коефіцієнт згасання дорівнює:

```
κ(x) = √(2 m (V(x) - E)) / ℏ
```

Розбиваючи довільний бар'єр на нескінченно малі прямокутні смужки шириною `dx` та інтегруючи показник загасання уздовж класично забороненого шляху від `x₁` до `x₂`, отримуємо безрозмірний **інтеграл Ґамова (фактор Ґамова `G`)**:

```
G = 2 ∫_{x₁}^{x₂} κ(x) dx = (2 / ℏ) ∫_{x₁}^{x₂} √(2 m (V(x) - E)) dx
```

Підсумковий коефіцієнт прозорості бар'єра довільної форми в наближенні ВКБ описується загальною формулою:

```
T ≈ exp(-G) = exp( - (2 / ℏ) ∫_{x₁}^{x₂} √(2 m (V(x) - E)) dx )
```

Ця формула лежить в основі розрахунків періодів напіврозпаду атомних ядер, автоелектронної емісії з мікроіголок та коефіцієнтів протекання термоядерних реакцій у надрах зірок.
