# 📜 Історичний прорив: від ультрафіолетової катастрофи до моделі Бора

Наприкінці XIX століття фізична картина світу здавалася майже завершеною. Класична механіка Ісаака Ньютона, електродинаміка Джеймса Клерка Максвелла та термодинаміка Людвіга Больцмана й Вільгельма Віна утворювали стрункий теоретичний фундамент. Більшість фізиків вважала, що всі фундаментальні закони вже відкрито, а майбутні дослідження зведуться лише до уточнення вимірювальних сталих у наступних знаках після коми. Проте саме на стику класичної електродинаміки та термодинаміки виникла фундаментальна суперечність, яка розвалила будівлю класичної фізики й поклала початок квантовій революції.

### Криза класичної теорії випромінювання

Головним випробувальним полігоном класичної фізики стала задача про спектральний розподіл енергії випромінювання абсолютно чорного тіла — замкненої порожнини з нагрітими стінками, що перебуває у стан термодинамічної рівноваги зі своїм внутрішнім електромагнітним полем.

Закони класичної статистичної фізики, зокрема теорема Больцмана про рівнорозподіл енергії за ступенями вільності (лат. *aequus* — рівний, *distributio* — розподіл), стверджували: на кожну гармонічну моду (стоячу хвилю) електромагнітного поля у порожнині в середньому припадає теплова енергія:

```
⟨E⟩ = k_B · T      [де k_B — стала Больцмана, T — абсолютна температура]
```

Підраховуючи кількість стоячих хвиль на одиницю об'єму порожнини у вузькому інтервалі частот від `ν` до `ν + dν`, англійські фізики Лорд Релей (Джон Вільям Стратт) та Джеймс Джинс у 1900–1905 роках вивели класичну формулу для спектральної об'ємної густини енергії випромінювання `u(ν)`:

```
u(ν) dν = (8π · ν² / c³) · k_B · T dν      [закон Релея — Джинса]
```

З цієї формули випливав катастрофічний для фізики висновок. Оскільки кількість модальних коливань у порожнині зростає пропорційно квадрату частоти `ν²`, то зі збільшенням частоти (тобто при переході до ультрафіолетової та рентгенівської областей спектра) густина випромінюваної енергії мала б прямувати до нескінченності:

```
u(ν) → ∞   при   ν → ∞
```

Це означало б, що будь-яке нагріте тіло за будь-якої температури, відмінної від абсолютного нуля, має миттєво випромінити всю свою внутрішню теплову енергію у вигляді високочастотних ультрафіолетових та гамма-квантів. У реальності ж розжарене тіло випромінює максимуми в інфрачервоному або оптичному діапазонах, а на високих частотах інтенсивність спадає до нуля. Опитуючи цю нездоланну розбіжність між класичною теорією та дослідом, австрійський фізик Пауль Еренфест у 1911 році дав їй влучну назву — **ультрафіолетова катастрофа** (нім. *Ultraviolettkatastrophe*).

### «Акт розчарування» Макса Планка (1900 рік)

Вихід із глухого кута знайшов німецький фізик-теоретик Макс Планк. Досліджуючи випромінювання чорного тіла, Планк прагнув об'єднати закон Релея — Джинса, який добре працював на низьких частотах (у довгохвильовій інфрачервоній області), із напівемпіричним законом Вільгельма Віна, який правильно описував спад інтенсивності на високих частотах (`u(ν) ~ ν³ · e^(-aν/T)`).

восени 1900 року Планку вдалося підібрати математичну формулу, яка ідеально узгоджувалася з експериментальними вимірюваннями Генріха Рубенса та Фердинанда Курльбаума в усьому діапазоні частот. Проте сам Планк як послідовний прихильник класичної термодинаміки розумів: формула потребує фізичного обґрунтування з першопричин.

14 грудня 1900 року на засіданні Німецького фізичного товариства в Берліні Планк представив доповідь, яка вважається днем народження квантової фізики. Щоб вивести свою формулу, Планк змушений був висунути революційну гіпотезу, яку сам пізніше називав «актом розчарування» (нім. *Akt des Verzweifelns*), адже вона повністю суперечила класичній фізичній інтуїції:

> **Гіпотеза Планка:** Атомні осцилятори стінок порожнини випромінюють і поглинають електромагнітну енергію не безперервно (як вимагала класична електродинаміка Максвелла), а дискретними порціями — **квантами** (лат. *quantum* — скільки, порція). Енергія одного кванта прямо пропорційна частоті випромінювання:

```
E = h · ν = ℏ · ω      [де h — стала Планка, ℏ = h / (2π)]
```

Введена Планком фундаментальна константа `h = 6.626·10⁻³⁴ Дж·с` має розмірність дії (енергія, помножена на час) і відтоді зветься **квантом дії**.

Завдяки припущенню про дискретність енергетичних рівнів осциляторів `E_n = n · h·ν` (де `n = 0, 1, 2, 3...`), середня енергія осцилятора обчислюється не за класичною інтегральною статистикою Больцмана, а через дискретну суму за розподілом Гіббса:

```
⟨E⟩ = ∑ (n·hν) · e^(-n·hν / k_B T) / ∑ e^(-n·hν / k_B T)
    = (h·ν) / (e^(h·ν / k_B T) - 1)
```

Підставляючи цю квантову середню енергію замість класичного значення `k_B T`, Планк отримав свій знаменитий закон випромінювання:

```
u(ν) dν = (8π h ν³ / c³) · 1 / (e^(h·ν / k_B T) - 1) dν      [закон Планка]
```

За низьких частот (`h·ν « k_B T`) експоненту в знаменнику можна розкласти у ряд Тейлора (`e^x ≈ 1 + x`), і формула Планка тотожно переходить у класичний закон Релея — Джинса. Проте за високих частот (`h·ν » k_B T`) експоненціальний член стрімко зростає, гасячи квадрат частоти у чисельнику та прямуючи до нуля при `ν → ∞`. Квантування енергії усунуло ультрафіолетову катастрофу: високі енергетичні кванти `h·ν` виявилися занадто «дорогими» для звичайного теплового збудження за помірних температур, тому високочастотні моди просто не заселяються.

### Розвиток ідеї кванта: Ейнштейн та світлові корпускули (1905 рік)

Спочатку сам Планк вважав квантування суто математичним прийомом, притаманним лише специфічному механізму взаємодії світла з матерією у стінках порожнини. Проте Альберт Ейнштейн у 1905 році зробив наступний вирішальний крок. Досліджуючи фотоелектричний ефект (вибивання електронів із металу під дією світла), Ейнштейн показав, що дискретним є не лише процес випромінювання чи поглинання, а й **саме світлове поле**.

Світло поширюється у просторі у вигляді локалізованих порцій енергії та імпульсу — фотонів (гр. *phōs* — світло). Кожен фотон несе енергію `E = h·ν` та імпульс `p = h / λ`. Рівняння Ейнштейна для фотоефекту:

```
h · ν = A_out + (mₑ · v²_max / 2)      [де A_out — робота виходу електрона з металу]
```

Ця формула пояснила дивну класичну загадку фотоефекту: чому кінетична енергія вибитих електронів залежить виключно від **частоти** світла `ν`, а не від його інтенсивності (яка визначає лише кількість вибитих електронів за секунду).

### Експериментальне підтвердження: Дослід Франка — Ґерлаха (1914 рік)

Попри успіх у поясненні фотоефекту та теплоємності твердих тіл, гіпотеза про дискретність атомних енергетичних рівнів потребувала прямого механічного доказу. У 1914 році німецькі фізики Джеймс Франк та Густав Ґерц провели елегантний експеримент, який безпосередньо продемонстрував квантування внутрішньої енергії атомів.

Франк і Ґерц бомбардували розріджену пару ртуті (`Hg`) у триелектродній лампі електронами, прискореними регульованою електричною напругою `V`. Вчені вимірювали анодний струм залежно від прискорювальної напруги:

1. Доки кінетична енергія електронів `E_kin = e·V` була меншою за декілька електронвольт, зіткнення електронів з атомами ртуті були **абсолютно пружними**. Оскільки маса атома ртуті у 360 000 разів більша за масу електрона, електрон відскокував майже без втрати кінетичної енергії, і струм монотонно зростав.
2. Щойно прискорювальна напруга досягала критичного значення `V = 4.9 В`, кінетична енергія електрона досягала `4.9 еВ`. У цей момент відбувалися **непружні зіткнення**: електрон повністю віддавав свою кінетичну енергію атому ртуті, переводячи його з основного стану у перший збуджений. Втративши швидкість, електрони більше не могли подолати затримувальний потенціал перед анодом, і анодний струм різко падав майже до нуля.
3. При подальшому збільшенні напруги струм знову зростав, аж поки при `V = 9.8 В` (тобто `2 × 4.9 В`) електрон не зазнавав двох послідовних непружних зіткнень із двома атомами ртуті.

Водночас оптичні вимірювання показали, що збуджені атоми ртуті, повертаючись в основний стан, випромінювали ультрафіолетову лінію з довжиною хвилі `λ = 253.7 нм`. Енергія відповідного світлового кванта строго дорівнювала втраченій енергії електрона:

```
ΔE = h · c / λ = (6.626·10⁻³⁴ · 3·10⁸ / 253.7·10⁻⁹) Дж ≈ 4.9 еВ
```

Дослід Франка — Ґерлаха наочно довів: енергетичний спектр атома не є неперервним. Атом може поглинати та віддавати енергію лише дискретними порціями, що строго відповідають відстані між його внутрішніми квантовими рівнями.

### Модель атома Бора та стаціонарні стани (1913 рік)

Паралельно з цими відкриттями розгорталася криза планетарної моделі атома. Після дослідів Ернеста Резерфорда (1911) з розсіяння альфа-частинок стало зрозуміло, що атом складається з масивного позитивного ядра та легких електронів, що обертаються навколо нього. Проте згідно з класичною електродинамікою Максвелла, електрон, рухаючись по коловій орбіті з доцентровим прискоренням, мусить безперервно випромінювати електромагнітні хвилі. Втрачаючи енергію на випромінювання, електрон мав би за нікчемну частку секунди (`~10⁻¹¹ с`) по спіралі впасти на ядро. Реальні ж атоми виявилися абсолютно стабільними, а їхні спектри складалися з тонких дискретних ліній, а не суцільного спектра.

У 1913 році данський фізик Нільс Бор запропонував напівкласичну модель атома водню, об’єднавши планетарну модель Резерфорда з квантовими ідеями Планка та Ейнштейна у вигляді трьох постулатів:

1. **Існування стаціонарних станів:** В атомі існують особливі стаціонарні орбіти, рухаючись якими електрон, попри наявність прискорення, **не випромінює** енергії. У цих станах атом має дискретні значення енергії `E_1, E_2, E_3...`.
2. **Правило квантування орбітального моменту:** Дозволеними є лише ті орбіти, на яких момент імпульсу електрона `L` є кратним зведеній сталій Планка `ℏ`:

```
L = mₑ · v · r = n · ℏ      [де n = 1, 2, 3... — головне квантове число]
```

3. **Умова квантових переходів:** Випромінювання або поглинання світла атомом відбувається лише при переході електрона з одного стаціонарного стану `n_2` в інший `n_1`. Енергія випроміненого або поглинутого фотона дорівнює різниці енергій цих рівнів:

```
ΔE = E_(n_2) - E_(n_1) = h · ν
```

Комбінуючи правило квантування моменту імпульсу з класичним рівнянням руху електрона у кулонівському полі ядра (`mₑ v² / r = e² / (4πε₀ r²)`), Бор вивів формулу для радіусів дозволених стаціонарних орбіт:

```
r_n = (4π ε₀ ℏ² / (mₑ e²)) · n² = a₀ · n²      [де a₀ ≈ 0.529 Å — борівський радіус]
```

Звідси Бор безпосередньо отримав квантований спектр енергетичних рівнів атома водню:

```
E_n = - (mₑ e⁴ / (32 π² ε₀² ℏ²)) · (1 / n²) = - (13.6 еВ / n²)
```

Ця формула блискуче пояснила відомі з ХІХ століття емпіричні спектральні серії водню (серію Лаймана в ультрафіолеті, Бальмера у видимому світлі, Пашена в інфрачервоній області). Бор точно обчислив константу Рідберга `R_∞` через фундаментальні фізичні сталі:

```
1 / λ = R_∞ · (1/n₁² - 1/n₂²)      [формула Рідберга — Бора]
```

### Значення історичного прориву

Модель Бора була видатним триумфом, проте вона мала тимчасовий, гібридний характер. Вона комбінувала класичні закони механіки Ньютона для руху електрона по колу з вольовими квантовими постулатами. Вона не могла пояснити спектри складніших багатоелектронних атомів (навіть гелію) та інтенсивності спектральних ліній.

Проте саме історичний ланцюжок від Планка до Бора зруйнував класичне латинське прислів'я *Natura non facit saltus* («Природа не робить стрибків»). Він навчив фізиків того, що на мікроскопічному рівні дискретність енергетичних станів є глибоким фундаментальним законом природи, який у 1925–1926 роках дістав своє остаточне математичне обґрунтування у квантовій механіці Вернера Гейзенберга та Ервіна Шредінгера.
