# 🧮 Математична теорія квантування: власні значення оператора Гамільтона

Дискретність енергетичних рівнів у квантовій механіці виникає не як штучно доданий постулат, а як строгий математичний наслідок спектральної теорії диференціальних операторів у функціональному просторі Гільберта. У класичній механіці стан системи описується точкою у фазовому просторі, а її енергія є неперервною функцією координат та імпульсів. У квантовій механіці стан мікрочастинки описується хвильовою функцією `ψ(x)`, а стаціонарні енергетичні стани є власними функціями оператора енергії — гамільтоніана `Ĥ`.

### Операторний формалізм та гільбертів простір

Усі можливі фізичні стани квантової системи належать комплексному гільбертовому простору `L²(a, b)` квадратично інтегровних функцій. Скалярний добуток двох станів `ψ(x)` та `ϕ(x)` визначається як:

```
⟨ψ | ϕ⟩ = ∫ ψ*(x) · ϕ(x) dx      [де ψ*(x) — комплексно-спряжена функція]
```

Фізично реалізований стан `ψ(x)` мусить задовольняти умову нормування (сумарна ймовірність знайти частинку у всьому просторі дорівнює одиниці):

```
||ψ||² = ⟨ψ | ψ⟩ = ∫ |ψ(x)|² dx = 1
```

Динаміка стаціонарних станів описується стаціонарним рівнянням Шредінгера, яке є математичною задачею на власні значення та власні функції оператора Гамільтона `Ĥ`:

```
Ĥ · ψ(x) = E · ψ(x)
```

В одновимірному випадку оператор Гамільтона має вигляд:

```
Ĥ = - (ℏ² / (2m)) · (d² / dx²) + U(x)
```

Оператор `Ĥ` є самоспряженим (ермітовим) оператором у просторі `L²`. Зі спектральної теореми для самоспряжених операторів випливають дві фундаментальні властивості:
1. Усі власні значення енергії `E` є дійсними числами (`E ∈ ℝ`).
2. Власні функції `ψ_n(x)` та `ψ_m(x)`, що відповідають різним власним значенням `E_n ≠ E_m`, є ортогональними: `⟨ψ_n | ψ_m⟩ = 0`.

Квантування енергії (тобто існування точкового, дискретного спектра власних значень `E_n`) виникає тоді й лише тоді, коли крайова задача для рівняння Шредінгера має фізично допустимі розв'язки з простору `L²` лише при певних виділених значеннях параметра `E`.

### Одновимірна потенціальна яма з нескінченними стінками

Розглянемо найпростішу модель квантованої системи: частинку маси `m`, обмежену в одновимірній потенціальній ямі шириною `L` з абсолютно непроникними стінками:

```
U(x) = 0        при   0 < x < L
U(x) = +∞       при   x ≤ 0  або  x ≥ L
```

Оскільки потенціал поза інтервалом `(0, L)` прямує до нескінченності, ймовірність знаходження частинки зовні дорівнює нулю. Це задає жорсткі крайові умови для хвильової функції:

```
ψ(0) = 0   та   ψ(L) = 0      [крайові умови Дирихле]
```

Всередині ями (`0 < x < L`) потенціал `U(x) = 0`, і стаціонарне рівняння Шредінгера набуває вигляду диференціального рівняння гармонічного осцилятора:

```
- (ℏ² / (2m)) · (d²ψ / dx²) = E · ψ(x)
(d²ψ / dx²) + k² · ψ(x) = 0      [де хвильове число k = √(2mE) / ℏ > 0]
```

Загальний розв'язок цього лінійного диференціального рівняння другого порядку є лінійною комбінацією синуса та косинуса:

```
ψ(x) = A · sin(k·x) + B · cos(k·x)      [де A та B — довільні сталі]
```

Застосуємо першу крайову умову при `x = 0`:

```
ψ(0) = A · sin(0) + B · cos(0) = B = 0      ⇒   B = 0
```

Таким чином, розв'язок спрощується до `ψ(x) = A · sin(k·x)`. Тепер застосуємо другу крайову умову при `x = L`:

```
ψ(L) = A · sin(k·L) = 0
```

Оскільки тривіальний розв'язок `A = 0` означав би `ψ(x) ≡ 0` (відсутність частинки взагалі, що суперечить нормуванню), рівняння має нетривіальні розв'язки лише тоді, коли аргумент синуса є кратним `π`:

```
k · L = n · π      ⇒   k_n = n · π / L      [де n = 1, 2, 3...]
```

Випадок `n = 0` відкидається, оскільки при `k = 0` хвильова функція `ψ(x) = A · sin(0) = 0` не нормується. Від'ємні значення `n = -1, -2...` не дають нових фізичних станів, оскільки `sin(-y) = -sin(y)` описує той самий стан із точністю до неістотного фазового множника `-1`.

Виражаючи енергію через квантоване хвильове число `k_n`, отримуємо точну формулу для дискретного енергетичного спектра частинки в ямі:

```
E_n = (ℏ² · k_n²) / (2m) = (n² · π² · ℏ²) / (2 · m · L²)      [де n = 1, 2, 3...]
```

Нормувальна стала `A` визначається з умови `∫₀ᴸ |ψ_n(x)|² dx = 1`:

```
A² · ∫₀ᴸ sin²(n·π·x / L) dx = A² · (L / 2) = 1   ⇒   A = √(2 / L)
```

Отже, власні стани частинки в нескінченній ямі описуються ортонормованою системою стоячих хвиль:

```
ψ_n(x) = √(2 / L) · sin(n · π · x / L)
```

**Математичний підсумок:** Квантування виникло внаслідок того, що крайові умови `ψ(0) = 0` та `ψ(L) = 0` перетворили рівняння Шредінгера на задачу Штурма — Ліувілля. Дискретні енергетичні рівні зростають квадратично з номером стану (`E_n ~ n²`), а найнижчий рівень `E_1 = (π² ℏ²) / (2m L²)` є строго більшим за нуль (енергія нульових коливань).

### Скінченна потенціальна яма глибиною `U_0`

У реальних фізичних системах (наприклад, електрон у напівпровідниковій квантовій точці чи протон у ядерному потенціалі) потенціальний бар'єр має скінченну висоту `U_0`. Розглянемо симетричну потенціальну яму:

```
U(x) = 0        при   |x| < L/2     [область II]
U(x) = U_0      при   |x| ≥ L/2     [області I та III]
```

Шукаємо зв'язані стани з енергією `0 < E < U_0`. Розділимо простір на три області:

1. **Всередині ями (`|x| < L/2`):** Рівняння має вигляд `ψ'' + k² ψ = 0`, де `k = √(2mE) / ℏ`.
2. **Поза ямою (`|x| ≥ L/2`):** Рівняння має вигляд `ψ'' - κ² ψ = 0`, де `κ = √(2m(U_0 - E)) / ℏ > 0`.

Щоб хвильова функція належила простору `L²`, експоненціально зростаючі розв'язки на нескінченності мають бути відкинуті:

```
ψ_I(x)   = C · e^(κ·x)             при   x ≤ -L/2
ψ_III(x) = D · e^(-κ·x)            при   x ≥ L/2
```

Всередині ями внаслідок симетрії потенціалу `U(-x) = U(x)` оператор Гамільтона комутує з оператором парності `P̂`. Тому власні функції розпадаються на два незалежні класи парності:

- **Парні стани (`ψ(-x) = ψ(x)`):** `ψ_II(x) = A · cos(k·x)`
- **Непарні стани (`ψ(-x) = -ψ(x)`):** `ψ_II(x) = B · sin(k·x)`

Зшиваємо хвильову функцію та її першу похідну (вимога неперервності та гладкості `ψ` і `dψ/dx`) на межі `x = L/2`:

```
Для парних станів:
1) ψ_II(L/2) = ψ_III(L/2)     ⇒   A · cos(k L / 2) = D · e^(-κ L / 2)
2) ψ'_II(L/2) = ψ'_III(L/2)   ⇒  -A k · sin(k L / 2) = -D κ · e^(-κ L / 2)
```

Ділячи друге рівняння на перше, отримуємо **трансцендентне рівняння для парних станів**:

```
k · tan(k L / 2) = κ      [парні стани]
```

Аналогічно для **непарних станів**:

```
k · cot(k L / 2) = -κ     [непарні стани]
```

Увівши безрозмірні змінні `ξ = k L / 2` та `η = κ L / 2`, зауважимо, що `ξ² + η² = R²`, де фундаментальний параметр ями `R = (L/2) · √(2m U_0) / ℏ`. Рівняння для рівнів енергії набувають прозорого геометричного вигляду перетину кола радіуса `R` з тригонометричними кривими:

```
η = ξ · tan(ξ)      [для парних станів]
η = -ξ · cot(ξ)     [для непарних станів]
```

**Математичні висновки для скінченної ями:**
1. Дискретний спектр енергій `E_n` існує лише в інтервалі `0 < E < U_0`. Кількість дискретних рівнів є **скінченною** і визначається радіусом `R`.
2. За будь-якої, навіть як завгодно малої глибини `U_0 > 0`, одновимірна симетрична яма завжди містить принаймні **один парний дискретний рівень**.
3. На відміну від нескінченної ями, хвильова функція поза ямою `ψ_III(x) ~ e^(-κ x)` є ненульовою: електрон з імовірністю, відмінною від нуля, заходить під потенціальний бар'єр (квантове просочування / тунелювання).
4. При `E > U_0` крайові умови загасання на нескінченності зникають, і спектр стає **суцільним** (вільний рух над ямою).

### Квантовий гармонічний осцилятор: Алгебраїчний метод Дірака

Гармонічний осцилятор описується параболічним потенціалом `U(x) = (1/2) m ω² x²`. Рівняння Шредінгера має вигляд:

```
- (ℏ² / (2m)) · (d²ψ / dx²) + (1/2) m ω² x² · ψ(x) = E · ψ(x)
```

Замість розв'язання цього дифрівняння через многочлени Ерміта, застосуємо елегантний алгебраїчний метод Поль Дірака за допомогою **операторів знищення (`a`) та створення (`a⁺`)**.

Введемо безрозмірну координату `x̂_0 = x · √(mω / ℏ)` та імпульс `p̂_0 = p / √(m·ℏ·ω)`. Визначимо оператори:

```
a  = (1 / √2) · (x̂_0 + i · p̂_0) = √(mω / 2ℏ) · (x̂ + i p̂ / (mω))      [оператор знищення]
a⁺ = (1 / √2) · (x̂_0 - i · p̂_0) = √(mω / 2ℏ) · (x̂ - i p̂ / (mω))      [оператор створення]
```

Обчислимо комутатор `[a, a⁺]`, використовуючи основне канонічне комутаційне співвідношення `[x̂, p̂] = i·ℏ`:

```
[a, a⁺] = a a⁺ - a⁺ a = (1 / 2) · [x̂_0 + i p̂_0,  x̂_0 - i p̂_0]
        = (1 / 2) · ( -i [x̂_0, p̂_0] + i [p̂_0, x̂_0] )
        = -i · [x̂_0, p̂_0] = -i · (i) = 1
```

Отже, **основний комутатор алгебри осцилятора**:

```
[a, a⁺] = 1
```

Перепишемо гамільтоніан `Ĥ` через оператори `a` та `a⁺`. Оскільки `a⁺ a = (1/2) (x̂_0² + p̂_0² - 1)`, отримуємо:

```
Ĥ = ℏ·ω · (a⁺ a + 1/2) = ℏ·ω · (N̂ + 1/2)
```

де `N̂ = a⁺ a` — самоспряжений **оператор числа квантів**.

Знайдемо власні значення оператора `N̂`. Нехай `|n⟩` — власний вектор оператора `N̂` з власним значенням `n`:

```
N̂ |n⟩ = n |n⟩
```

Знайдемо, як оператори `a` та `a⁺` діють на власний вектор `|n⟩`. Обчислимо комутатори `N̂` з `a` та `a⁺`:

```
[N̂, a]  = [a⁺ a, a]  = [a⁺, a] a = -a
[N̂, a⁺] = [a⁺ a, a⁺] = a⁺ [a, a⁺] = +a⁺
```

Звідси випливають операторні тотожності:

```
N̂ (a |n⟩)  = (a N̂ - a) |n⟩  = a (n |n⟩) - a |n⟩  = (n - 1) · (a |n⟩)
N̂ (a⁺ |n⟩) = (a⁺ N̂ + a⁺) |n⟩ = a⁺ (n |n⟩) + a⁺ |n⟩ = (n + 1) · (a⁺ |n⟩)
```

Це означає:
- Вектор `a|n⟩` є власним вектором оператора `N̂` з власним значенням `(n - 1)`. Оператор `a` **знижує** число квантів на одиницю.
- Вектор `a⁺|n⟩` є власним вектором оператора `N̂` з власним значенням `(n + 1)`. Оператор `a⁺` **підвищує** число квантів на одиницю.

Тепер обчислимо квадрат норми вектора `a|n⟩`:

```
||a |n⟩||² = ⟨n | a⁺ a | n⟩ = ⟨n | N̂ | n⟩ = n · ⟨n | n⟩ = n ≥ 0
```

Оскільки норма будь-якого вектора у гільбертовому просторі є неотрицальною (`||a|n⟩||² ≥ 0`), власні значення `n` мають задовольняти умову `n ≥ 0`.

Якби `n` не було цілим числом, послідовне застосування оператора зниження `a` утворювало б ланцюжок станів `|n-1⟩, |n-2⟩, |n-3⟩...`, і рано чи пізно ми отримали б стан із від'ємним значенням `n`, що призвело б до від'ємної норми (математична суперечність).

Єдиним способом зупинити цей нескінченний ланцюжок униз є умова, що `n` є **цілим неотрицальним числом** (`n = 0, 1, 2, 3...`), а найнижчий стан `|0⟩` (основний стан або квантовий вакуум) обнуляється під дією оператора знищення:

```
a |0⟩ = 0      [умова виродження вакууму]
```

Звідси випливає, що власні значення оператора `N̂` є цілими числами `n ∈ {0, 1, 2, 3...}`.

Підставляючи власні значення `n` у формулу для Гамільтоніана `Ĥ = ℏω (N̂ + 1/2)`, отримуємо строго квантований енергетичний спектр квантового гармонічного осцилятора:

```
E_n = ℏ · ω · (n + 1/2)      [де n = 0, 1, 2, 3...]
```

#### Виведення явних хвильових функцій осцилятора
Для знаходження хвильової функції основного стану `ψ_0(x)` виходимо з операторного рівняння `a|0⟩ = 0`:

```
(x + (ℏ / (mω)) · (d / dx)) · ψ_0(x) = 0
(dψ_0 / dx) = - (mω / ℏ) · x · ψ_0(x)
```

Інтегруючи це дифрівняння з урахуванням нормування, отримуємо гауссів пакет:

```
ψ_0(x) = (mω / (π ℏ))^(1/4) · e^(-mω x² / (2ℏ))
```

Вищі збуджені стани `ψ_n(x)` будуються послідовною дією оператора створення `a⁺` на вакуумний стан `|0⟩`:

```
|n⟩ = (1 / √(n!)) · (a⁺)ⁿ |0⟩
ψ_n(x) = N_n · H_n(x · √(mω/ℏ)) · e^(-mω x² / (2ℏ))      [де H_n — многочлени Ерміта]
```

### Порівняльне зведення точних розв'язків

| Система | Потенціал `U(x)` | Енергетичний спектр `E_n` | Проміжок між рівнями `ΔE` | Енергія нульового стану `E_0` / `E_1` |
|---|---|---|---|---|
| **Нескінченна яма** | `0` при `x ∈ (0,L)`, `∞` зовні | `(n² π² ℏ²) / (2m L²)` (`n=1,2...`) | Зростає: `~ (2n+1)` | `(π² ℏ²) / (2m L²) > 0` |
| **Скінченна яма (`U_0`)** | `0` при `|x|<L/2`, `U_0` зовні | Скінченна кількість `E_n < U_0` | Залежить від `U_0` та `n` | `0 < E_1 < E_1^inf` |
| **Гармонічний осцилятор** | `(1/2) m ω² x²` | `ℏω · (n + 1/2)` (`n=0,1...`) | Еквідистантний: `ℏω` | `(1/2) ℏω > 0` |

Алгебраїчний метод Дірака показує, що рівновіддаленість (еквідистантність) рівнів гармонічного осцилятора `ΔE = ℏω` є прямою вимогою комутаційного співвідношення `[a, a⁺] = 1`, яке випливає з канонічного квантування імпульсу та координати `[x̂, p̂] = i·ℏ`.
