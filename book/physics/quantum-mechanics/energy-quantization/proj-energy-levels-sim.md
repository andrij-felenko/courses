# ⚙️ Чисельний розрахунок квантованих рівнів енергії рівнянням Шредінгера

Аналітичний розв'язок стаціонарного рівняння Шредінгера можливий лише для вузького класу ідеалізованих потенціалів (нескінченна прямокутна яма, симетричний гармонічний осцилятор, кулонівський потенціал атома водню). Проте у реальних фізичних та інженерних задачах — наприклад, при проектуванні гетероструктур напівпровідникових лазерів, квантових точок чи аналізі ангармонічних молекулярних коливань — потенціал `U(x)` має складну математичну форму, для якої точних аналітичних рішень у замкненому вигляді не існує.

У таких випадках дискретні енергетичні рівні `E_n` та відповідні стаціонарні хвильові функції `ψ_n(x)` знаходять чисельними методами на обчислювальних сітках. У цій статті ми глибоко розберемо два фундаментальні алгоритмічні підходи до розв'язання квантової задачі на власні значення та реалізуємо їх робочим кодом.

### Математична постановка чисельної задачі та масштабування

Розглядається одновимірне стаціонарне рівняння Шредінгера для частинки маси `m` у довільному потенціальному полі `U(x)`:

```
- (ℏ² / (2m)) · (d²ψ(x) / dx²) + U(x) · ψ(x) = E · ψ(x)
```

Безпосереднє обчислення у фізичних одиницях СІ (де маса електрона `m⑺ ≈ 9.1·10⁻³¹ кг`, а стала Планка `ℏ ≈ 1.05·10⁻³⁴ Дж·с`) призводить до чисел порядку `10⁻³⁴` та `10⁻¹⁹`, що викликає переповнення або втрату точності з плаваючою крапкою (англ. *underflow / precision loss*).

Тому першим обов'язковим інженерним кроком є обезрозмірення рівняння. Уведемо характерну просторову шкалу `x_0` (наприклад, `x_0 = 1 нм` для квантових ям або `x_0 = √(ℏ / mω)` для осцилятора) та характерну одиницю енергії `E_0 = ℏ² / (m · x_0²)`. Позначивши безрозмірну координату `z = x / x_0`, безрозмірний потенціал `v(z) = U(x) / E_0` та безрозмірне значення енергії `ε = E / E_0`, отримуємо чисельно стійке рівняння:

```
(d²ψ(z) / dz²) + 2 · (ε - v(z)) · ψ(z) = 0
```

Для зв'язаних станів фізичні крайові умови вимагають квадратного інтегрування та експоненціального спадання хвильової функції у класично забороненій зоні:

```
ψ(z) → 0   при   z → ±∞
```

Чисельний розрахунок виконується у скінченній просторовій області `[z_min, z_max]`. Межі обираються достатньо далеко в класично забороненій зоні (де потенціал значно перевищує енергію `v(z) » ε`), так щоб фізичні крайові умови можна було без втрати точності замінити однорідними крайовими умовами Дирихле:

```
ψ(z_min) = 0   та   ψ(z_max) = 0
```

### Алгоритм 1: Метод стрільби (Shooting Method) та інтегрування Нумерова

Метод стрільби перетворює крайову задачу на серію задач Коші (з початковими умовами на лівій межі). Ми задаємо пробне значення енергії `ε`, інтегруємо диференціальне рівняння від лівої межі `z_min` до правої `z_max` і перевіряємо, чи виконується умова `ψ(z_max) = 0`.

Оскільки рівняння Шредінгера є диференціальним рівнянням другого порядку без першої похідної (`y''(z) = f(z) · y(z)`), застосовувати стандартні методи Рунге — Кутти неоптимально. Натомість використовують спеціалізований **алгоритм Нумерова** (англ. *Numerov's method*), який забезпечує високу 4-ту локальну точність `O(h⁴)` відносно кроку сітки `h`.

Дискретизуємо координату рівномірною сіткою з кроком `h`: `z_i = z_min + i · h` (для `i = 0, 1 ... N`). Позначивши `g_i = 2 · (ε - v(z_i))`, ітераційна формула Нумерова виводиться з розкладу в ряд Тейлора до 5-го порядку і має вигляд:

```
(1 + (h² / 12) · g_(i+1)) · ψ_(i+1) = 2 · (1 - (5 h² / 12) · g_i) · ψ_i
                                      - (1 + (h² / 12) · g_(i-1)) · ψ_(i-1)
```

#### Схема та особливості розрахунку методом стрільби
1. Фіксуємо діапазон пошуку енергії `[ε_low, ε_high]`.
2. Для кожного пробного значення `ε` задаємо початкові умови на лівій межі: `ψ_0 = 0`, `ψ_1 = 10⁻⁵` (довільна мала початкова амплітуда).
3. За формулою Нумерова послідовно обчислюємо значення `ψ_2, ψ_3 ... ψ_N` на всій сітці аж до правої межі `z_max`.
4. Значення незшивки на правій межі `F(ε) = ψ_N(ε)` слугує скалярною функцією помилки. Власні значення енергії відповідають точним нулям цієї функції: `F(ε_n) = 0`.
5. Пошук коренів `F(ε) = 0` здійснюється ітераційно методом бісекції (ділення навпіл) або методом січних.

#### Стійкість та стрільба з двох боків (Match Point)
Для високолеглих рівнів або глибоких потенціальних бар'єрів пряма стрільба зліва направо у класично забороненій зоні стає чисельно нестійкою: експоненціально зростаючі розв'язки викривляють хвильову функцію внаслідок нагромадження помилок округлення.

Для вирішення цієї проблеми застосовують **стрільбу з двох боків** до точки зшивання `z_match` (зазвичай точки повороту `v(z_match) = ε`). Інтегрування здійснюється зліва направо `ψ_L(z)` та справа наліво `ψ_R(z)`. Умові квантування відповідає рівність логарифмічних похідних обох розв'язків у точці зшивання:

```
(ψ'_L / ψ_L)|_z_match = (ψ'_R / ψ_R)|_z_match
```

### Алгоритм 2: Дискретизація на сітці та тридіагональна матриця Гамільтоніана

Альтернативним і більш універсальним підходом є зведення диференціального оператора Гамільтона до матричної задачі на власні значення методом скінченних різниць.

Розглянемо рівномірну сітку з `N` внутрішніх точок `z_i` (для `i = 1 ... N`) з кроком `h = (z_max - z_min) / (N + 1)`. Апроксимуємо другу похідну центральною різницею 2-го порядку точності `O(h²)`:

```
ψ''(z_i) ≈ (ψ_(i+1) - 2 ψ_i + ψ_(i-1)) / h²
```

Підставляючи це у безрозмірне рівняння Шредінгера, отримуємо систему `N` лінійних алгебраїчних рівнянь:

```
- (1 / (2 h²)) · ψ_(i-1) + (1 / h² + v(z_i)) · ψ_i - (1 / (2 h²)) · ψ_(i+1) = ε · ψ_i
```

Ця система еквівалентна алгебраїчному матричному рівнянню на власні значення `H_mat · Ψ = ε · Ψ`, де матриця Гамільтоніана `H_mat` розміром `N × N` є **симетричною тридіагональною матрицею**:

```
Головна діагональ:   H_(i, i)   = 1 / h² + v(z_i)
Бічні діагоналі:     H_(i, i±1) = - 1 / (2 h²)
```

#### Матричні розв'язувачі та переваги сіткового методу
Знаходження власних значень такої матриці є класичною задачею лінійної алгебри. Оскільки матриця є розрідженою та тридіагональною, застосування спеціалізованих алгоритмів (наприклад, QR-алгоритму з зсувами або процедури Ланцоша для розріджених матриць `eigsh`) дає розв'язок за час `O(N²)`.

Перевага сіткового методу полягає у тому, що він **одночасно знаходить усе сімейство квантованих рівнів** `ε_0, ε_1 ... ε_k` та відповідні ортогональні власні вектори `Ψ_n` без ризику пропустити рівні чи потреби вгадувати початкові пошукові інтервали.

### Практична реалізація

Нижче наведено повноцінні робочі реалізації обох алгоритмів. Приклади розраховують квантовані рівні енергії для **ангармонічного осцилятора з четвертним потенціалом**:

```
v(z) = (1/2) · z² + λ · z⁴      [при λ = 0.1]
```

Цей потенціал описує ангармонізм молекулярних коливань та є стандартним тестом для квантово-механічних чисельних методів.

```py
import numpy as np
from scipy.sparse import diags
from scipy.sparse.linalg import eigsh

def solve_schrodinger_grid(v_func, z_min=-6.0, z_max=6.0, N=1200, num_levels=5):
    """
    Чисельне знаходження власних значень та хвильових функцій рівняння Шредінгера
    за допомогою сіткового методу скінченних різниць.
    """
    z = np.linspace(z_min, z_max, N)
    h = z[1] - z[0]
    
    # Побудова тридіагональних діагоналей матриці Гамільтоніана H
    diag_main = 1.0 / (h**2) + v_func(z[1:-1])
    diag_off = -0.5 / (h**2) * np.ones(N - 3)
    
    # Збирання розрідженої тридіагональної матриці
    H_matrix = diags([diag_off, diag_main, diag_off], [-1, 0, 1], format='csr')
    
    # Пошук найменших власних значень (SA = Smallest Algebraic)
    energies, wavefunctions = eigsh(H_matrix, k=num_levels, which='SA')
    
    # Додавання нульових крайових умов та чисельне нормування хвильових функцій
    normalized_wfs = []
    for idx in range(num_levels):
        wf = np.pad(wavefunctions[:, idx], (1, 1), mode='constant')
        norm = np.sqrt(np.trapz(wf**2, z))
        normalized_wfs.append(wf / norm)
        
    return z, energies, normalized_wfs

# Потенціал ангармонічного осцилятора
v_anharmonic = lambda z: 0.5 * z**2 + 0.1 * z**4

z_grid, E_vals, psi_funcs = solve_schrodinger_grid(v_anharmonic, z_min=-6.0, z_max=6.0, N=1200, num_levels=5)

print("=== Рівні енергії ангармонічного осцилятора (Python Grid Method) ===")
for n, E in enumerate(E_vals):
    print(f"Рівень n={n}: E_{n} = {E:.6f}")
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <iomanip>
#include <algorithm>

// Потенціал ангармонічного осцилятора: V(z) = 0.5*z^2 + 0.1*z^4
double potential(double z) {
    return 0.5 * z * z + 0.1 * std::pow(z, 4);
}

// Послідовне інтегрування Нумерова для заданого E
double numerov_integrate(double E, double z_min, double z_max, int N) {
    double h = (z_max - z_min) / N;
    double h2 = h * h;
    
    auto g = [E](double z) { return 2.0 * (E - potential(z)); };
    
    double psi_prev = 0.0;           // ψ(z_min) = 0
    double psi_curr = 1e-5;          // Мала початкова амплітуда
    
    for (int i = 1; i < N; ++i) {
        double z_prev = z_min + (i - 1) * h;
        double z_curr = z_min + i * h;
        double z_next = z_min + (i + 1) * h;
        
        double g_prev = g(z_prev);
        double g_curr = g(z_curr);
        double g_next = g(z_next);
        
        double term_curr = 2.0 * (1.0 - (5.0 * h2 / 12.0) * g_curr) * psi_curr;
        double term_prev = (1.0 + (h2 / 12.0) * g_prev) * psi_prev;
        double term_next_denom = 1.0 + (h2 / 12.0) * g_next;
        
        double psi_next = (term_curr - term_prev) / term_next_denom;
        
        psi_prev = psi_curr;
        psi_curr = psi_next;
    }
    return psi_curr; // Значення незшивки на правій межі
}

// Знаходження власного значення енергії методом бісекції
double find_energy_level(double E_low, double E_high, double z_min, double z_max, int N, double tol = 1e-7) {
    while ((E_high - E_low) > tol) {
        double E_mid = 0.5 * (E_low + E_high);
        double f_low = numerov_integrate(E_low, z_min, z_max, N);
        double f_mid = numerov_integrate(E_mid, z_min, z_max, N);
        
        if (f_low * f_mid <= 0.0) {
            E_high = E_mid;
        } else {
            E_low = E_mid;
        }
    }
    return 0.5 * (E_low + E_high);
}

int main() {
    std::cout << std::fixed << std::setprecision(6);
    std::cout << "=== Рівні енергії ангармонічного осцилятора (C++ Shooting Method) ===\n";
    
    double z_min = -6.0, z_max = 6.0;
    int N = 2000;
    
    // Пошукові інтервали для перших чотирьох рівнів
    std::vector<std::pair<double, double>> intervals = {
        {0.4, 0.7},   // n = 0
        {1.2, 1.6},   // n = 1
        {2.2, 2.7},   // n = 2
        {3.4, 4.0}    // n = 3
    };
    
    for (size_t n = 0; n < intervals.size(); ++n) {
        double E_n = find_energy_level(intervals[n].first, intervals[n].second, z_min, z_max, N);
        std::cout << "Рівень n=" << n << ": E_" << n << " = " << E_n << "\n";
    }
    
    return 0;
}
```

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

double c_potential(double z) {
    return 0.5 * z * z + 0.1 * z * z * z * z;
}

double c_numerov_shoot(double E, double z_min, double z_max, int N) {
    double h = (z_max - z_min) / N;
    double h2 = h * h;
    double psi_prev = 0.0;
    double psi_curr = 1e-5;

    for (int i = 1; i < N; ++i) {
        double z_prev = z_min + (i - 1) * h;
        double z_curr = z_min + i * h;
        double z_next = z_min + (i + 1) * h;

        double g_prev = 2.0 * (E - c_potential(z_prev));
        double g_curr = 2.0 * (E - c_potential(z_curr));
        double g_next = 2.0 * (E - c_potential(z_next));

        double num = 2.0 * (1.0 - (5.0 * h2 / 12.0) * g_curr) * psi_curr - (1.0 + (h2 / 12.0) * g_prev) * psi_prev;
        double den = 1.0 + (h2 / 12.0) * g_next;
        double psi_next = num / den;

        psi_prev = psi_curr;
        psi_curr = psi_next;
    }
    return psi_curr;
}

int main(void) {
    double z_min = -6.0, z_max = 6.0;
    int N = 2000;
    printf("=== Рівні енергії ангармонічного осцилятора (C Shooting Method) ===\n");

    double bounds[4][2] = {{0.4, 0.7}, {1.2, 1.6}, {2.2, 2.7}, {3.4, 4.0}};
    for (int n = 0; n < 4; ++n) {
        double low = bounds[n][0], high = bounds[n][1];
        while ((high - low) > 1e-7) {
            double mid = 0.5 * (low + high);
            if (c_numerov_shoot(low, z_min, z_max, N) * c_numerov_shoot(mid, z_min, z_max, N) <= 0.0) {
                high = mid;
            } else {
                low = mid;
            }
        }
        printf("Рівень n=%d: E_%d = %.6f\n", n, n, 0.5 * (low + high));
    }
    return 0;
}
```

### Порівняльний аналіз чисельних підходів та крайові випадки

1. **Порівняння обчислювальної складності:**
   - **Метод Нумерова (Shooting Method):** має точність `O(h⁴)`. Складність одного прогону сіткою є строго лінійною `O(N)`. При бісекції на `K` ітерацій сумарна складність становить `O(K · N)`. Це робить його найшвидшим підходом для точного розрахунку конкретного вибраного рівня енергії.
   - **Сітковий тридіагональний метод (Grid Method):** має точність `O(h²)`. Оскільки обчислення власних значень розрідженої тридіагональної матриці вимагає часу `O(N²)`, метод є виліковно важчим для надвеликих сіток. Проте він знаходить **усі дискретні рівні одночасно** і не зауважує пасток із пропусканням рівнів.

2. **Вибір просторових меж `z_min` та `z_max`:**
   Якщо вибрати межі сітки занадто вузькими (близько до класичних точок повороту `z_turn`, де `v(z_turn) = ε`), штучна крайова умова `ψ = 0` примусово зріже експоненціальні «хвости» підбар'єрного тунелювання. Це призведе до штучного «затискання» хвильової функції й чисельного підвищення обчислених значень енергії `E_n`.
   Добре налаштована сітка повинна перекривати класичні точки повороту `z_turn` із запасом у `3...4` класичні довжини загасання `1 / κ = 1 / √(2(v - ε))`.

3. **Аналіз виродження та подвійні потенціальні ями:**
   Для симетричної подвійної потенціальної ями `v(z) = V_0 · (z² - a²)²` чисельний розрахунок виявляє два майже вироджені енергетичні рівні (дублет тунельного розщеплення `E_0` та `E_1`). Для такого потенціалу метод Нумерова вимагає високої точності `tol < 10⁻¹⁰`, оскільки енергетичний проміжок між парним та непарним станами прямує до нуля при зростанні висоти бар'єра `V_0`.
