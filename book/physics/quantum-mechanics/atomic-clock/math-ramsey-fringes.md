# 🧮 Квантовомеханічне виведення інтерференції Рамзі

Ця вставка містить розширене квантовомеханічне виведення оператора еволюції дворівневої квантової системи в зоні розділених осцилюючих полів, геометричний опис руху вектора Блоха на сфері Блоха, усереднення за тепловим розподілом швидкостей та математичне обґрунтування звуження лінії спектрального відгуку Рамзі.

## 1. Квантовий стан дворівневого атома та гамільтоніан взаємодії

Розглянемо атом із двома вибраними квантовими рівнями: основним станом `|g⟩` з енергією `E_g` та збудженим станом `|e⟩` з енергією `E_e`. Резонансна квантова частота переходу дорівнює:

```
ω₀ = (E_e - E_g) / ℏ
```

У довільний момент часу `t` хвильовий стан атома `|Ψ(t)⟩` представляється суперпозицією двох власних станів:

```
|Ψ(t)⟩ = c_g(t) · e^(-i·E_g·t / ℏ) |g⟩ + c_e(t) · e^(-i·E_e·t / ℏ) |e⟩
```

де `c_g(t)` та `c_e(t)` — комплексні амплітуди ймовірностей знаходження атома у відповідних станах, що задовольняють умову нормування `|c_g(t)|² + |c_e(t)|² = 1`.

При наявності зовнішнього монохроматичного НВЧ електромагнітного поля з частотою `ω` та фазою `φ` електричний або магнітний вектор поля діє на атом. Гамільтоніан системи приймає вигляд:

```
H = H₀ + V(t)
```

де `H₀` — незбурений атомний гамільтоніан, а `V(t)` — оператор дипольної взаємодії:

```
V(t) = - μ · B₀ · cos(ω·t + φ)
```

Матричні елементи оператора взаємодії у базисі `{ |g⟩, |e⟩ }` дорівнюють `V_gg = V_ee = 0` (внаслідок парності хвильових функцій) та `V_ge = V_eg* = - ℏ · Ω_R · cos(ω·t + φ)`, де `Ω_R` — частота Рабі, що характеризує силу зв'язку атома з полем:

```
Ω_R = |⟨e| μ |g⟩| · B₀ / ℏ
```

Частота Рабі `Ω_R` вимірюється в радіанах за секунду й визначає швидкість перекачування квантової населеності між основним та збудженим станами під дією резонансного поля.

## 2. Наближення обертальної хвилі (RWA) та матриця еволюції зони Рабі

Підставляючи стан `|Ψ(t)⟩` у часове рівняння Шредінгера `i·ℏ · ∂|Ψ⟩/∂t = H |Ψ⟩`, отримуємо систему зв'язаних диференціальних рівнянь для амплітуд:

```
i · (dc_g / dt) = (1/2) · Ω_R · [ e^(i·(ω - ω₀)·t + i·φ) + e^(-i·(ω + ω₀)·t - i·φ) ] · c_e
i · (dc_e / dt) = (1/2) · Ω_R · [ e^(-i·(ω - ω₀)·t - i·φ) + e^(i·(ω + ω₀)·t + i·φ) ] · c_g
```

Застосовуючи наближення обертальної хвилі (Rotating Wave Approximation, RWA), ми нехтуємо швидкоосцилюючими членами з частотою `(ω + ω₀)`, оскільки при `ω ≈ ω₀` їхній усереднений внесок за час взаємодії є нехтовно малим (порядок `1 / (2·ω₀) ≈ 5 · 10⁻¹¹` с). Позначивши розбудову частоти (відхилення) як `δ = ω - ω₀`, диференціальні рівняння спрощуються:

```
dc_g / dt = i · (Ω_R / 2) · e^(i·δ·t + i·φ) · c_e
dc_e / dt = i · (Ω_R / 2) · e^(-i·δ·t - i·φ) · c_g
```

Переходячи у систему відліку, що обертається з частотою `ω`, задамо вектор стану як `C(t) = [c_g(t), c_e(t)]ᵀ`. За час дії НВЧ-імпульсу тривалості `τ` еволюція стану описується матричним оператором `U_Rabi(τ, δ, φ)`:

```
U_Rabi(τ, δ, φ) = 
[ cos(Ω_eff·τ / 2) - i·(δ / Ω_eff)·sin(Ω_eff·τ / 2)     ,   -i·(Ω_R / Ω_eff)·e^(i·φ)·sin(Ω_eff·τ / 2)   ]
[ -i·(Ω_R / Ω_eff)·e^(-i·φ)·sin(Ω_eff·τ / 2)           ,   cos(Ω_eff·τ / 2) + i·(δ / Ω_eff)·sin(Ω_eff·τ / 2) ]
```

де `Ω_eff = √(Ω_R² + δ²)` — ефективна частота Рабі з урахуванням розбудови.

Для точного резонансу (`δ = 0`) та ідеального `π/2`-імпульсу (`Ω_R · τ = π/2`), матриця збудження набирає максимально простого вигляду:

```
U_π/2(φ) = (1 / √2) · 
[  1       ,  -i·e^(i·φ) ]
[ -i·e^(-i·φ) ,   1       ]
```

## 3. Геометрична інтерпретація на сфері Блоха

Еволюція дворівневої квантової системи володіє виокремленою геометричною наочністю у термінах вектора Блоха `r⃗ = (u, v, w)ᵀ`. Компоненти вектора Блоха пов'язані з елементами матриці густини `ρ = |Ψ⟩⟨Ψ|`:

```
u = 2 · Re(c_g* · c_e)    [поперечна квантова поляризація по осі X]
v = 2 · Im(c_g* · c_e)    [поперечна квантова поляризація по осі Y]
w = |c_e|² - |c_g|²       [інверсія населеності по осі Z]
```

Рівняння руху вектора Блоха має вигляд рівняння прецесії магнітного моменту:

```
d r⃗ / dt = W⃗ × r⃗
```

де вектор крутного моменту дорівнює `W⃗ = (-Ω_R · cos(φ), -Ω_R · sin(φ), -δ)ᵀ`.

Геометрія методом Рамзі на сфері Блоха відбувається у три послідовні етапи:
1. **Початковий стан:** Вектор Блоха перебуває на південному полюсі сфери `r⃗₀ = (0, 0, -1)ᵀ` (чистий основний стан `|g⟩`).
2. **Перший `π/2`-імпульс:** Під дією поля з фазою `φ₁ = 0` вектор `r⃗` повертається навколо осі X на кут `90°` і лягає точно на екватор сфери Блоха у точку `r⃗₁ = (0, 1, 0)ᵀ`. Це відповідає утворенню максимальної квантової когерентності (суперпозиції).
3. **Вільний дрейф:** У зоні вільного дрейфу тривалості `T` НВЧ-поле відсутнє (`Ω_R = 0`), тому вектор `W⃗ = (0, 0, -δ)ᵀ` спрямований строго уздовж осі Z. Вектор Блоха обертається в екваторіальній площині XY з кутовою швидкістю розбудови `δ = ω - ω₀`. За час `T` вектор повертається на кут `ΔΦ = δ · T`:
   ```
   r⃗₂ = ( sin(δ·T), cos(δ·T), 0 )ᵀ
   ```
4. **Другий `π/2`-імпульс:** Друге НВЧ-поле здійснює другий поворот вектора навколо осі X на кут `90°`. Підсумкова координата Z вектора Блоха визначає населеність збудженого стану:
   ```
   w_final = cos(δ · T)
   P_ge = (w_final + 1) / 2 = (1/2) · [ 1 + cos(δ · T) ]
   ```

Якщо розбудова частоти суворо дорівнює нулю (`δ = 0`), вектор Блоха за час дрейфу залишається нерухомим на екваторі, і другий імпульс повертає його прямо на північний полюс `r⃗_final = (0, 0, +1)ᵀ` (`P_ge = 1`). Якщо ж розбудова така, що `δ · T = π`, вектор повертається назад на південний полюс (`P_ge = 0`).

## 4. Матриця вільної прецесії та повний оператор Рамзі

У просторі вільного дрейфу між двома НВЧ-зонами довжиною `L` атоми рухаються зі швидкістю `v` впродовж часу `T = L / v`. У цій зоні НВЧ-поле відсутнє (`Ω_R = 0`), тому оператор взаємодії дорівнює нулю.

Проте через наявність розбудови частоти `δ = ω - ω₀` квантові фази станів `|g⟩` та `|e⟩` еволюціонують із різною швидкістю у системі відліку, що обертається. Матриця вільної еволюції `U_drift(T)` за час `T` є діагональною:

```
U_drift(T) = 
[ e^(i·δ·T / 2)  ,       0         ]
[       0        ,  e^(-i·δ·T / 2) ]
```

За час вільного прольоту `T` квантова система накопичує фазовий зсув `ΔΦ = δ · T = (ω - ω₀) · T`.

Розглянемо повний цикл проходження атома крізь метод розділених осцилюючих полів Рамзі:
1. Початковий стан: Атом входить у першу зону у чистому основному стані `C(0) = [1, 0]ᵀ`.
2. Дія першої НВЧ-зони тривалості `τ` з фазою початкового поля `φ₁ = 0`: застосовується `U_Rabi(τ, δ, 0)`.
3. Вільний дрейф тривалості `T`: застосовується `U_drift(T)`.
4. Дія другої НВЧ-зони тривалості `τ` з фазою поля `φ₂`: застосовується `U_Rabi(τ, δ, φ₂)`.

Повний вектор стану на виході з другої зони дорівнює добутку трьох матриць:

```
C_final = U_Rabi(τ, δ, φ₂) · U_drift(T) · U_Rabi(τ, δ, 0) · C(0)
```

Для аналізу точної фізики розрахуємо підсумкову амплітуду збудженого стану `c_e(final)` у наближенні коротких зон взаємодії (`τ ≪ T`), коли зсувом фази усередині самих зон `δ·τ` можна знехтувати порівняно з накопиченим фазовим зсувом `δ·T`.

Для двох ідеальних `π/2`-імпульсів (`Ω_R · τ = π/2`) перемноження матриць дає підсумковий вектор:

```
C_final
= (1 / 2) · [ 1 , -i·e^(i·φ₂) ; -i·e^(-i·φ₂) , 1 ] · [ e^(i·δ·T/2) , 0 ; 0 , e^(-i·δ·T/2) ] · [ 1 ; -i ]  [добуток матриць зон та дрейфу]
= (1 / 2) · [ e^(i·δ·T/2) - e^(-i·δ·T/2 + i·φ₂) ; -i · (e^(i·δ·T/2) + e^(-i·δ·T/2 - i·φ₂)) ]                   [амплітуди |g⟩ та |e⟩]
```

Підносячи модуль амплітуди `|c_e(final)|` до квадрата, отримуємо фундаментальне рівняння ймовірності переходу Рамзі `P_ge(δ)`:

```
P_ge(δ)
= |c_e(final)|²                                                        [квадрат модуля амплітуди стану |e⟩]
= (1 / 4) · | e^(i·δ·T/2) + e^(-i·δ·T/2 - i·φ₂) |²                      [радіальний фазовий фактор]
= (1 / 4) · (2 + 2 · cos(δ·T + φ₂))                                   [формула Ейлера для суми експонент]
= cos²( (δ·T + φ₂) / 2 )                                              [тригонометрична тотожність половинного кута]
```

У разі однаковості фаз обох полів (`φ₂ = 0`) підсумкова ймовірність знаходження атома у збудженому стані дорівнює:

```
P_ge(ω) = cos²( (ω - ω₀) · T / 2 ) = (1 / 2) · [ 1 + cos((ω - ω₀) · T) ]
```

Ураховуючи обвідну збудження скінченної тривалості зон `τ` (профіль Рабі), точна вищенаведена формула приймає вигляд:

```
P_ge(δ) = 4 · (Ω_R² / Ω_eff²) · sin²(Ω_eff·τ / 2) · [ cos(Ω_eff·τ / 2)·cos(δ·T / 2) - (δ / Ω_eff)·sin(Ω_eff·τ / 2)·sin(δ·T / 2) ]²
```

## 5. Вплив фазового різниці між НВЧ-зонами

У практичних вимірювальних системах фаза другого НВЧ-поля `φ₂` може відрізнятися від фази першого поля `φ₁ = 0` на величину `Δφ = φ₂ - φ₁`. 

Підставляючи зсув фази `Δφ` у вираз для ймовірності, отримуємо:

```
P_ge(δ, Δφ) = cos²( (δ · T + Δφ) / 2 ) = (1/2) · [ 1 + cos(δ · T + Δφ) ]
```

Цей результат показує, що штучний зсув фази НВЧ-поля `Δφ` призводить до зсуву всієї картинки інтерференційних смуг Рамзі вздовж осі частот на величину `Δω_shift = - Δφ / T`. 

Цей ефект володіє двома фундаментальними метрологічними застосуваннями:
* **Квадратурне переключення фази (Phase Modulation Discriminator):** Швидка зміна фази другого поля між `+π/2` та `-π/2` дозволяє переключати робочу точку між лівим та правим схилами центральної смуги Рамзі без зміни частоти генератора.
* **Калібрування геометричних зсувів резонатора (End-to-End Cavity Phase Shift):** Вимірювання частоти при розвороті атомного фонтана або заміні напрямку прольоту дозволяє відокремити справжній квантовий резонанс `ω₀` від паразитного зсуву фаз між отворами резонатора.

## 6. Вплив неоднорідності статичного магнітного поля

У зоні вільного дрейфу тривалості `T` на атом діє статичне магнітне поле `B₀(z)`, яке внаслідок технічних недосконалостей соленоїда чи екранів має мікроскопічну просторову неоднорідність `δB(z) = B₀(z) - B̄₀`.

Квадратичний ефект Зеемана змінює миттєву частоту годинникового переходу під час прольоту:

```
ω_inst(z) = ω₀ + 2 · π · K_Z · [ B̄₀ + δB(z) ]²
```

Фаза, накопичена за час вільного прольоту `T`, визначається лінійним інтегралом уздовж траєкторії руху атома `z(t)`:

```
ΔΦ_total = ∫₀^T ( ω_inst(z(t)) - ω ) dt = ( ω̄_0 - ω ) · T
```

де `ω̄_0` — усереднена вздовж траєкторії атомного прольоту частота переходу:

```
ω̄_0 = ω₀ + 2 · π · K_Z · ⟨ B₀²(z) ⟩
```

Оскільки в атомному фонтані траєкторія параболічного руху `z(t) = v_launch · t - (g/2) · t²` є симетричною щодо апогею, атоми проводять більше часу у верхній частині вакуумної камери (біля апогею, де швидкість `v ≈ 0`). Тому верхня область C-поля дає ваговіше значення в усереднене поле `⟨ B₀²(z) ⟩`, ніж нижня зона біля резонатора.

## 7. Модель декогеренції та загасання контрастності смуг

У реальній експериментальній установці когерентна суперпозиція двох квантових станів зазнає поступового руйнування (декогеренції) внаслідок стохастичних флуктуацій полів та міжномінальних зіткнень.

Феноменологічно декогеренція описується зменшенням довжини вектора Блоха у площині XY з часом заперечного загасання `T₂*` (часом поперечної релаксації):

```
r_XY(t) = e^(-t / T₂*)
```

Матриця густини у зоні вільного дрейфу з урахуванням релаксації `T₂*` приймає вигляд:

```
ρ_drift(T) = 
[ |c_g|²                      ,  c_g·c_e* · e^(i·δ·T - T/T₂*) ]
[ c_g*·c_e · e^(-i·δ·T - T/T₂*) ,  |c_e|²                       ]
```

Підсумковий спектральний сигнал Рамзі з урахуванням декогеренції описується формулою зі зменшеною контрастністю `V(T) = e^(-T / T₂*)`:

```
P_ge(δ) = (1/2) · [ 1 + V(T) · cos(δ · T) ]
```

Якщо час вільного прольоту `T` значно перевищує час релаксації `T₂*` (`T ≫ T₂*`), видимість інтерференційних смуг падає до нуля (`V → 0`), і сигнал перетворюється на неінформативне постійне плато `P_ge = 0.5`. Для підтримки `V(T) > 0.9` у цезієвому фонтані час поперечної релаксації `T₂*` підтримується на рівні понад `5` секунд за рахунок надвисокого вакууму та глибокого магнітного екранування.

## 8. Атомно-інтерферометрична схема Рамзі — Борде та вимірювання прискорення `g`

Розширенням класичної двоімпульсної схеми Рамзі є чотирьохімпульсний інтерферометр Рамзі — Борде (Ramsey-Bordé Interferometer), де використовуються чотири послідовні лазерні імпульси `π/2 - π/2 - π/2 - π/2` з передачею фотонного імпульсу `ℏ·k`.

Матрична послідовність еволюції хвильової функції атома створює дві просторово розділені параболічні траєкторії хвильових пакетів Де Бройля, що утворюють замкнену квантову петлю площами `A_loop`.

Накопичена фазова різниця між двома плечима інтерферометра залежить від прискорення вільного падіння `g`:

```
ΔΦ_Borde = k_laser · g · T_drift² + (ω₁ - 2·ω₂ + ω₃) · T_drift
```

де `k_laser = 2·π / λ` — хвильове число лазера, а `T_drift` — час вільного польоту між імпульсами.

Цей вираз лежить в основі роботи абсолютних атомних гравіметрів, дозволяючи вимірювати прискорення вільного падіння `g` з відносною точністю `10⁻⁹` (`1` мікрогал), що забезпечує прямий зв'язок між фундаментальною квантовою фазою та локальним гравітаційним полем.

## 9. Квантова томографія матриці густини після імпульсів Рамзі

Повний квантовий опис ансамблю атомів на виході з второго резонатора Рамзі надається оператором матриці густини `ρ = |Ψ⟩⟨Ψ|`:

```
ρ_final = 
[  cos²(δ·T / 2)             ,   (i / 2) · sin(δ·T)  ]
[ -(i / 2) · sin(δ·T)        ,   sin²(δ·T / 2)       ]
```

Елементи матриці густини несуть чіткий фізичний зміст:
* **Діагональні елементи `ρ_gg = cos²(δ·T/2)` та `ρ_ee = sin²(δ·T/2)`:** Визначають населеності основного та збудженого станів відповідно.
* **Недіагональні елементи `ρ_ge = (i/2)·sin(δ·T)`:** Визначають квантову когерентність (поперечну поляризацію атома).

Вимірювання недіагональних елементів матриці густини шляхом квантової томографії дозволяє оцінити чистоту квантового стану `Tr(ρ²) = 1` та виявити наявність теплового змішування станів. Томографічна реконструція підтверджує створення чистих суперпозиційних станів із високим ступенем когерентності.

## 10. Вплив теплового розподілу швидкостей та контрастність смуг

У термальних пучкових годинниках атоми цезію рухаються з різними швидкостями `v`, описаними розподілом Максвелла — Больцмана для ефузійного атомного пучка:

```
f(v) = (2 / v_p⁴) · v³ · e^(-v² / v_p²)
```

де `v_p = √(2·k_B·T_temp / m)` — найімовірніша швидкість атомів при температурі джерела `T_temp`.

Оскільки час вільного прольоту залежить від швидкості `T(v) = L / v`, атоми з різними швидкостями накопичують різну фазу `δ · T(v)`. Підсумковий спектральний сигнал є інтегральним усередненням по всьому ансамблю атомів:

```
P_measured(δ) = ∫₀^∞ P_ge(δ, v) · f(v) dv
```

Це усереднення призводить до того, що бічні інтерференційні піки (High-order Ramsey fringes) швидко розмиваються та загасають при віддаленні від резонансу, тоді як центральний пік при `δ = 0` залишається чітким і контрастним для всіх атомів незалежно від їхньої швидкості, оскільки `δ · T(v) = 0` для будь-якого `v`.

У сучасних атомних фонтанах завдяки лазерному охолодженню розкид швидкостей `Δv` є надзвичайно малим (`Δv / v_launch < 0.001`), завдяки чому контрастність смуг Рамзі досягає майже ідеальних `100%`.

## 11. Дробовий атомний шум та межа чутливості за принципом невизначеності

При вимірюванні квантового стану ансамблю з `N` незаплутаних атомів фундаментальна точність фіксації фази обмежена квантовим дробовим шумом (Standard Quantum Limit, SQL).

Оскільки стан кожного атома вимірюється незалежно, проекція спінового вектора підряжається біноміальному розподілу. Дисперсія вимірювання кількості атомів становить `σ_N² = N · P · (1 - P)`. 

Відповідна невизначеність фіксації квантової фази `ΔΦ` за один цикл вимірювання обмежена виразом:

```
ΔΦ_min = 1 / √N
```

Підставляючи цей поріг у вираз для фазового зсуву Рамзі `ΔΦ = (ω - ω₀) · T`, отримуємо фундаментальну межу вимірювання частоти за один цикл тривалості `T`:

```
Δω_min = 1 / ( T · √N )
```

Для атомного фонтана з `N = 10⁶` атомів та часом дрейфу `T = 0.5` с ця фундаментальна квантова межа становить `Δω_min = 2 · 10⁻³` рад/с, що відповідає відносній точності `Δν / ν₀ ≈ 3 · 10⁻¹⁴` за один поодинокий запуск.

## 12. Математичний розрахунок ширини лінії та крутизни дискримінатора

З аналізу отриманого виразу випливають три фундаментальних метрологічних висновки:

1. **Ширина центрального піку (FWHM):**
Центральний резонансний максимум досягається при точній рівності частот `ω = ω₀`, де `P_ge = 1`. Перші нулі ймовірності з обох боків центрального піку виникають при `(ω - ω₀)·T / 2 = ± π / 2`, тобто при `ω - ω₀ = ± π / T`.

Напівширина центрального інтерференційного піку на рівні половинної амплітуди (`P_ge = 0.5`) визначається умовою `(ω - ω₀)·T / 2 = π / 4`, звідки повна ширина лінії за частотою `Δν_Ramsey` дорівнює:

```
Δν_Ramsey = 1 / (2 · T)
```

Порівняємо це із шириною лінії Рабі для однієї зони тривалості `τ`: `Δν_Rabi ≈ 1 / τ`. Оскільки у практичних атомних годинниках простір дрейфу в сотні разів довший за зону НВЧ-поля (`T ≫ τ`), ширина лінії Рамзі є у `T / τ` разів вужчою за ширину лінії Рабі.

2. **Крутизна спектрального дискримінатора:**
Для роботи сервоконтуру автопідстроювання генератор налаштовують на точки максимальної крутизни похибки, де `(ω - ω₀)·T = ± π / 2`. У цих точках `P_ge = 0.5`, а похідна ймовірності за частотою `dP / dω` сягає максимуму:

```
|dP / dω|_max = T / 2
```

Чим довший час прольоту `T`, тим більша зміна сигналу флуоресценції виникає при найменшому зсуві частоти `dω`, що забезпечує колосальну чутливість системи автопідстроювання.

3. **Стійкість до неоднорідностей поля:**
Оскільки у просторі вільного дрейфу довжиною `L` НВЧ-поле відсутнє, будь-які фазові та амплітудні неоднорідності електромагнітного поля усередині камери не спотворюють фазу `δ·T`. Єдине вимоге полягає у підтримці однорідного статичного магнітного поля `B₀` для збереження квантового стану Зеемана.
