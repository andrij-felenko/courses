# ⚙️ Чисельний розрахунок сили Казимира та нульових флуктуацій

У цій практичній вставці подано детальний аналіз та обчислювальний алгоритм розрахунку макроскопічної сили Казимира між паралельними пластинами у вакуумі. Описано практичне застосування теорії у наноінженерії, розібрано явище небажаного прилипання (stiction) в мікроелектромеханічних системах (MEMS), а також реалізовано обчислювальну модель мовами Python та C++ із урахуванням реальних параметрів електронної плазми металів за теорією Ліфшиця.

## Практичне значення сили Казимира у мікро- та нанотехнологіях

У макроскопічному світі фундаментальні сили гравітації та електростатики відіграють вирішальну роль у механічному русі тіл. Проте при зменшенні геометричних розмірів систем до нанометрових масштабів (`1 nm – 100 nm`) ситуація докорінно змінюється. Електромагнітні нульові коливання вакууму викликають притягальні сили Казимира та ван дер Ваальса, які стають домінуючими у мікроелектромеханічних приладах (MEMS та NEMS).

При розробці наноактюаторів, кремнієвих кантилеверів для атомно-силових мікроскопів, високочастотних мікрорезонаторів та оптичних перемикачів інженери зіштовхуються з явищем так званого "stiction" (спонтанного прилипання). Коли рухомий кремнієвий елемент (наприклад, консоль товщиною `100 nm`) наближається до нерухомої підкладки на відстань менше `50 nm`, упруга сила відновлення консолі стає меншою за виниклу сила Казимира. У результаті консоль миттєво притягується і намертво прилипає до підкладки, незворотно виводячи мікросхему з ладу.

Для запобігання прилипання інженери застосовують кілька обчислювальних методів:
1. **Нанесення спеціальних покриттів**: нанесення моношарів із низькою електронною густиною (наприклад, флуорованих самозбірних моношарів SAM) зменшує плазмову частоту металу та знижує силу Казимира.
2. **Текстурування поверхонь**: створення наноструктурованого рельєфу (масиву наностовпчиків або сітки) зменшує ефективну площу взаємодії та змінює спектр вакуумних мод.
3. **Використання репульсивних середовищ**: заповнення зазору між тілами рідким діелектриком із певною діелектричною проникністю дозволяє перетворити притягальну силу Казимира на відштовхувальну за теорією Ліфшиця.

## Фізична модель: Від ідеального провідника до теорії Ліфшиця

Ідеальна формула Казимира `F / A = - (π² · ℏ · c) / (240 · d⁴)` виведена за припущення, що граничні поверхні є ідеальними провідниками з нескінченною провідністю на всіх частотах електромагнітного спектра.

Проте для реальних металів (золото `Au`, алюміній `Al`, мідь `Cu`) на малих відстанях `d < 100 nm` це припущення порушується. Високочастотні вакуумні моди з довжиною хвилі, коротшою за плазмову довжину хвилі електронів у металі (`λ_p ≈ 136 nm` для золота), починають проникати всередину металу. Діелектрична проникність металу на уявних частотах `i·ξ` описується моделлю Друде:

```
ε(i·ξ) = 1 + ω_p² / (ξ · (ξ + γ))
```

де `ω_p` — плазмова частота електронів провідності (`ω_p ≈ 1.37e16 rad/s`), a `γ` — частота зіткнень електронів.

Євген Ліфшиць у 1956 році створив загальну квантово-статистичну теорію флуктуаційних сил, яка враховує реальні оптичні властивості матеріалів. У теорії Ліфшиця сила Казимира обчислюється через суму по дискретних частотах Мацубари `ξ_n = 2·π·n·k_B·T / ℏ` та коефіцієнти відбиття полярнізацій `r_{TM}` і `r_{TE}`. Для двох напівбезкінечних середовищ загальний вираз має вигляд:

```
F(d) / A = - (k_B·T / π) · ∑_{n=0}^∞' ∫₀^∞ q_n · k_⊥ · dk_⊥ [ (r_{TM}⁻² · e^{2 q_n d} - 1)⁻¹ + (r_{TE}⁻² · e^{2 q_n d} - 1)⁻¹ ]
```

де `q_n = √(k_⊥² + ξ_n² / c²)`.

На мікроскопічних відстанях `d << λ_p` поправковий коефіцієнт Ліфшиця `η_Lifshitz(d)` суттєво зменшує силу Казимира:

```
η_Lifshitz(d) ≈ 1 / (1 + 1.2 · (c / (ω_p · d)))
```

На відстанях порядка `10 nm` реальна сила притягання між золотими поверхнями становить лише `5–8%` від величини, розрахованої за ідеальною формулою Планка — Казимира.

## Метрологія та вимірювальні проблеми

Експериментальне обчислення сили Казимира вимагає урахування двох критичних системних факторів:

* **Електростатичні плями (patch potentials)**: нерівномірність роботи виходу електрона на кристалічних гранях металу створює локальні електричні потенціали флуктуаційного походження. Для їх нейтралізації в експериментах прикладають компенсаційну напругу зсуву `V_bias`.
* **Шорсткість поверхонь**: шорсткість золотих плівок на рівні `1–3 nm` змінює локальну відстань між пластинами. Для врахування шорсткості використовують наближення проформованих поверхонь (Proximity Force Approximation, PFA).

## Реалізація обчислювального алгоритму

Нижче подано повний робочий код мовами Python та C++, який розраховує ідеальний тиск Казимира, реальний тиск з поправкою Ліфшиця, а також еквівалентний тиск у Паскалях та атмосферах для діапазону відстаней від `10 nm` до `5 µm`.

```py
import math

def casimir_ideal_pressure(d_meters: float) -> float:
    """Обчислення ідеального тиску Казимира між провідниками у Паскалях."""
    hbar = 1.054571817e-34  # Дж·с (зменшена стала Планка)
    c = 299792458.0         # м/с (швидкість світла у вакуумі)
    factor = (math.pi ** 2) * hbar * c / 240.0
    return - factor / (d_meters ** 4)

def lifshitz_correction_factor(d_meters: float, plasma_wave_nm: float = 136.0) -> float:
    """Обчислення коефіцієнта поправки Ліфшиця для золота (Au)."""
    lambda_p = plasma_wave_nm * 1e-9
    # Наближення Друде-Ліфшиця для малих і середніх відстаней
    return 1.0 / (1.0 + 1.2 * (lambda_p / d_meters))

def analyze_casimir_range():
    distances_nm = [10.0, 20.0, 50.0, 100.0, 200.0, 500.0, 1000.0, 5000.0]
    pascal_to_atm = 1.01325e5
    
    print(f"{'d (nm)':>8} | {'P_ideal (Pa)':>14} | {'P_real (Pa)':>14} | {'P_real (atm)':>14} | {'Factor η':>10}")
    print("-" * 72)
    
    for d_nm in distances_nm:
        d_m = d_nm * 1e-9
        p_ideal = casimir_ideal_pressure(d_m)
        eta = lifshitz_correction_factor(d_m)
        p_real = p_ideal * eta
        p_real_atm = abs(p_real) / pascal_to_atm
        
        print(f"{d_nm:8.1f} | {abs(p_ideal):14.4e} | {abs(p_real):14.4e} | {p_real_atm:14.4e} | {eta:10.4f}")

if __name__ == "__main__":
    analyze_casimir_range()
```
```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <iomanip>

class CasimirCalculator {
public:
    static constexpr double hbar = 1.054571817e-34; // Зменшена стала Планка (Дж·с)
    static constexpr double c    = 299792458.0;        // Швидкість світла у вакуумі (м/с)
    static constexpr double atm  = 1.01325e5;          // 1 атмосфера у Паскалях

    // Розрахунок ідеального тиску Казимира у Паскалях (Н/м²)
    static double idealPressure(double d_meters) {
        constexpr double pi = 3.14159265358979323846;
        double factor = (pi * pi) * hbar * c / 240.0;
        return - factor / (d_meters * d_meters * d_meters * d_meters);
    }

    // Розрахунок коефіцієнта поправки Ліфшиця для золота (Au)
    static double lifshitzFactor(double d_meters, double plasma_wave_nm = 136.0) {
        double lambda_p = plasma_wave_nm * 1e-9;
        return 1.0 / (1.0 + 1.2 * (lambda_p / d_meters));
    }
};

int main() {
    std::vector<double> distances_nm = {10.0, 20.0, 50.0, 100.0, 200.0, 500.0, 1000.0, 5000.0};

    std::cout << std::setw(8) << "d (nm)" << " | "
              << std::setw(14) << "P_ideal (Pa)" << " | "
              << std::setw(14) << "P_real (Pa)" << " | "
              << std::setw(14) << "P_real (atm)" << " | "
              << std::setw(10) << "Factor η" << "\n";
    std::cout << std::string(72, '-') << "\n";

    for (double d_nm : distances_nm) {
        double d_m = d_nm * 1e-9;
        double p_ideal = std::abs(CasimirCalculator::idealPressure(d_m));
        double eta = CasimirCalculator::lifshitzFactor(d_m);
        double p_real = p_ideal * eta;
        double p_real_atm = p_real / CasimirCalculator::atm;

        std::cout << std::scientific << std::setprecision(4)
                  << std::setw(8) << d_nm << " | "
                  << std::setw(14) << p_ideal << " | "
                  << std::setw(14) << p_real << " | "
                  << std::setw(14) << p_real_atm << " | "
                  << std::fixed << std::setprecision(4)
                  << std::setw(10) << eta << "\n";
    }

    return 0;
}
```

## Крок за кроком: Аналіз коду та практичні висновки

Алгоритм працює за наступною логікою:

1. **Функція `casimir_ideal_pressure` / `idealPressure`**: обчислює теоретичне значення тиску за формулою Казимира `F/A = - π²·ℏ·c / (240·d⁴)`. Використовує фундаментальні константи `ℏ` та `c`. Значення повертається у Паскалях (`N/m²`).
2. **Функція `lifshitz_correction_factor` / `lifshitzFactor`**: обчислює поправковий коефіцієнт `η(d)` для золота з плазмовою довжиною хвилі `λ_p = 136 nm`. Коефіцієнт показує, яка частка ідеальної сили зберігається на даній відстані.
3. **Головний цикл `analyze_casimir_range` / `main`**: перебирає заздалегідь визначений вектор відстаней від `10 nm` до `5000 nm` (`5 µm`), обчислює тиск у Паскалях та перераховує його у фізичні атмосфери.

Результати чисельного моделювання розкривають драматичну залежність вакуумних сил від відстані та оптичних властивостей матеріалів:

* **Масштаб `10 nm`**: ідеальний тиск Казимира сягає величезної величини `1.3e5 Pa` (`1.3` атмосфери). З урахуванням скінченної провідності золота поправка Ліфшиця знижує тиск до `7.5e3 Pa` (`0.074` атм), що все одно становить критичне зусилля для мікроконсолей.
* **Масштаб `100 nm`**: тиск падає до `13 Pa`, що відповідає межі чутливості сучасних лазерних датчиків переміщення. На цій відстані поправка Ліфшиця відновлюється до `η ≈ 0.38`.
* **Масштаб `1 µm (1000 nm)`**: вакуумний тиск падає до `1.3e-3 Pa` (`10⁻⁸` атм). На таких відстанях сила Казимира поступається іншим класичним збуренням.

Температурні поправки при `T = 300 K` виникають за рахунок теплових фотонів із довжиною хвилі `λ_thermal = ℏc / (k_B T) ≈ 7.6 µm`. Для відстаней `d << λ_thermal` квантові нульові коливання повністю домінують над тепловими фотонами.

Отже, розрахунок вакуумних нульових флуктуацій є необхідним етапом проектування будь-якого наноелектронного або нанооптичного пристрою.
