# ⚙️ Числовий розрахунок рівняння стану та масово-радіусного профілю білого карлика

Ця вставка містить детальний алгоритм, математичне обґрунтування та програмну реалізацію чисельного інтегрування рівняння гідростатичної рівноваги зорі (рівняння Лейна — Емдена та релятивістського рівняння стану Чандрасекара) для побудови залежності радіуса білого карлика від його маси та вирахування межі Чандрасекара.

## 1. Фізична постановка задачі та системи диференціальних рівнянь

Внутрішня структура сферично-симетричного білого карлика у стані макроскопічного спокою описується двома фундаментальними рівняннями астрофізики — рівнянням гідростатичної рівноваги Ньютона та рівнянням збереження маси:

```
dP / dr = - (G · M(r) · ρ(r)) / r²
dM / dr = 4 π · r² · ρ(r)
```

де:
- `r` — радіальна відстань від геометричного центра зорі;
- `P(r)` — тиск виродженого електронного газу на відстані `r`;
- `M(r)` — сумарна маса речовини, замкнена всередині сфери радіуса `r`;
- `ρ(r)` — масова густина речовини на відстані `r`;
- `G = 6.67430 × 10⁻¹¹ m³ kg⁻¹ s⁻²` — гравітаційна стала.

Фізичний зміст першого рівняння полягає у тому, що градієнт тиску `dP / dr`, спрямований назовні, мусить у кожному шарці зорі товщиною `dr` строго врівноважувати направлену до центра силу гравітаційного притягання, що діє на одиницю об'єму речовини `ρ · g(r) = ρ · (G M / r²)`. Друге рівняння описує накопичення маси в елементарній сферичній оболонці об'ємом `dV = 4π r² dr`.

Для замикання цієї системи диференціальних рівнянь необхідно додати рівняння стану речовини `P = P(ρ)`, яке пов'язує тиск із густиною.

## 2. Релятивістське рівняння стану Чандрасекара

У холодному виродженому зоряному ядрі при абсолютному нулю `T = 0 K` тиск створюється повністю виродженим електронним газом. Оскільки електрони у центрі масивних білих карликів можуть рухатися зі релятивістськими швидкостями, вираз для тиску має враховувати точну релятивістську кінематику `E(p) = √(p² c² + m_e² c⁴) - m_e c²`.

Записуючи імпульс Фермі через безрозмірний параметр `x = p_F / (m_e c)`, тиск `P(x)` та масова густина `ρ(x)` задаються параметричними виразами:

```
ρ(x) = B · x³
P(x) = A · f(x)
```

де функція `f(x)` описується строгому тотожністю:

```
f(x) = x · (2 x² - 3) · √(1 + x²) + 3 · ln(x + √(1 + x²))
```

А коефіцієнти `A` та `B` виражаються через масу електрона `m_e`, швидкість світла `c`, сталу Планка `h`, масу нуклона `m_u` та середню кількість нуклонів на один електрон `μ_e`:

```
A = (π m_e⁴ c⁵) / (3 h³) ≈ 6.002 × 10²² Pa
B = (8 π m_e³ c³ μ_e m_u) / (3 h³) ≈ 9.81 × 10⁵ g/cm³ · μ_e
```

Для типового вуглецево-кисневого білого карлика, утвореного в результаті еволюції зірок середньої маси, середня молекулярна маса на один електрон дорівнює `μ_e = 2.0` (оскільки для nuclei Carbon-12 та Oxygen-16 відношення числа нуклонів `A` до числа електронів `Z` становить `A / Z = 2`). Для чистого гелію `μ_e = 2.0`, а для заліза `μ_e ≈ 2.15`.

Проаналізуємо асимптотичні границі функції `f(x)`:
1. **Нерелятивістська границя (`x ≪ 1`, тобто `ρ ≪ 10⁶ g/cm³`):** розклад розкладом у ряд Тейлора дає `f(x) ≈ (8/15) x⁵`, звідки `P ∝ x⁵ ∝ ρ⁵/³` (політропа з показником `n = 1.5`).
2. **Ультрарелятивістська границя (`x ≫ 1`, тобто `ρ ≫ 10⁶ g/cm³`):** розклад дає `f(x) ≈ 2 x⁴`, звідки `P ∝ x⁴ ∝ ρ⁴/³` (політропа з показником `n = 3`).

## 3. Граничні умови та математичні складнощі в центрі

Для розв'язання диференціальної системи необхідно задати граничні умови:
1. **У центрі зорі (`r = 0`):**
   - `M(0) = 0` (у точки без об'єму немає маси);
   - `ρ(0) = ρ_c` (задана центральна густина);
   - `x(0) = (ρ_c / B)¹/³`;
   - `P(0) = P(x(0))`.
2. **На поверхні зорі (`r = R`):**
   - `P(R) = 0` ⇒ `ρ(R) = 0`, що визначає фізичний радіус зорі `R`. Повна маса зорі обчислюється як `M_total = M(R)`.

Оскільки у точці `r = 0` вираз для градієнта тиску `dP / dr = - G M ρ / r²` містить невизначеність `0 / 0`, чисельне інтегрування не можна починати безпосередньо з `r = 0`. Застосовуємо розклад у ряд Тейлора поблизу центра при малій відстані `r = Δr`:

```
ρ(r) ≈ ρ_c - C_1 · r²
M(r) ≈ (4/3) π ρ_c · r³
P(r) ≈ P_c - (2/3) π G ρ_c² · r²
```

Інтегрування починається з першого кроку `r = Δr`, де маса і тиск обчислюються за цими асимптотичними формулами, а далі виконується чисельний алгоритм.

## 4. Алгоритм Рунге — Кутти 4-го порядку та обрахунок оберненої функції

Оскільки диференціальні рівняння виражені через похідні за тиском та масою, на кожному кроці за радіусом `r` необхідно за відомим поточним тиском `P` знаходити відповідний параметр `x`, а з нього — густину `ρ(x)`.

Оскільки функція `P(x)` містить нелінійні неалгебраїчні додатки (`ln(x + √(1 + x²))`), обернена функція `x(P)` не виражається в елементарних функціях. У чисельному коді застосовується метод Ньютона — Рафсона:

```
x_{k+1} = x_k - (P(x_k) - P_target) / (dP / dx (x_k))
```

де похідна обчислюється за точною формулою `dP / dx = 8 A x⁴ / √(1 + x²)`. Завдяки монотонності та опуклості функції `P(x)` метод Ньютона збігається за 3–5 ітерацій із високою точністю `10⁻¹²`.

Після знаходження `ρ(r)` обчислюються чотири вектори коефіцієнтів Рунге — Кутти 4-го порядку (`k_1, k_2, k_3, k_4`) для системи `(dM/dr, dP/dr)` та виконується крок по радіусу `r ➔ r + Δr`. Інтегрування зупиняється, коли тиск падає нижче `10⁻⁶ P_c`.

```py
import numpy as np

# Фундаментальні фізичні сталі у системі SI
G = 6.67430e-11          # Гравітаційна стала, m^3 kg^-1 s^-2
C = 2.99792458e8         # Швидкість світла, m/s
M_SUN = 1.98847e30       # Маса Сонця, kg
M_E = 9.1093837e-31      # Маса електрона, kg
M_U = 1.660539066e-27    # Атомна одиниця маси, kg
HBAR = 1.054571817e-34   # Зведена стала Планка, J s

# Параметри речовини білого карлика (вуглець/кисень, mu_e = 2.0)
MU_E = 2.0
B_CONST = (8.0 * np.pi * (M_E * C)**3 * MU_E * M_U) / (3.0 * (2.0 * np.pi * HBAR)**3)  # kg/m^3
A_CONST = (np.pi * M_E**4 * C**5) / (3.0 * (2.0 * np.pi * HBAR)**3)                     # Pa

def eos_density(x):
    """Обчислює масову густину rho(x) за імпульсом Фермі x."""
    return B_CONST * (x**3)

def eos_pressure(x):
    """Точний релятивістський тиск Чандрасекара P(x)."""
    if x < 1e-4:
        return (8.0 / 15.0) * A_CONST * (x**5)
    return A_CONST * (x * (2.0 * x**2 - 3.0) * np.sqrt(1.0 + x**2) + 3.0 * np.arcsinh(x))

def inv_eos_x(p_target):
    """Знаходить безрозмірний імпульс x за заданим тиском P методом Ньютона."""
    if p_target <= 0:
        return 0.0
    x = (15.0 * p_target / (8.0 * A_CONST))**0.2
    for _ in range(25):
        p_val = eos_pressure(x)
        dp_dx = 8.0 * A_CONST * (x**4) / np.sqrt(1.0 + x**2)
        diff = p_val - p_target
        if abs(diff) < 1e-9 * p_target:
            break
        x -= diff / dp_dx
        if x < 0:
            x = 1e-10
    return x

def solve_white_dwarf(rho_center, dr=500.0):
    """
    Чисельно інтегрує рівняння рівноваги від центра до поверхні.
    Повертає масу (в одиницях M_sun) та радіус (в кілометрах).
    """
    x_center = (rho_center / B_CONST)**(1.0 / 3.0)
    p_center = eos_pressure(x_center)
    
    r = dr
    m = (4.0 / 3.0) * np.pi * (r**3) * rho_center
    p = p_center - (2.0 / 3.0) * np.pi * G * (rho_center**2) * (r**2)
    
    while p > 1e-7 * p_center and r < 5e7:
        def derivatives(r_val, m_val, p_val):
            if p_val <= 0:
                return 0.0, 0.0
            x_val = inv_eos_x(p_val)
            rho_val = eos_density(x_val)
            dp_dr = - (G * m_val * rho_val) / (r_val**2)
            dm_dr = 4.0 * np.pi * (r_val**2) * rho_val
            return dm_dr, dp_dr

        dm1, dp1 = derivatives(r, m, p)
        dm2, dp2 = derivatives(r + 0.5 * dr, m + 0.5 * dr * dm1, p + 0.5 * dr * dp1)
        dm3, dp3 = derivatives(r + 0.5 * dr, m + 0.5 * dr * dm2, p + 0.5 * dr * dp2)
        dm4, dp4 = derivatives(r + dr, m + dr * dm3, p + dr * dp3)

        m += (dr / 6.0) * (dm1 + 2.0 * dm2 + 2.0 * dm3 + dm4)
        p += (dr / 6.0) * (dp1 + 2.0 * dp2 + 2.0 * dp3 + dp4)
        r += dr

    return m / M_SUN, r / 1000.0

if __name__ == "__main__":
    densities = [1e8, 1e9, 1e10, 1e11, 1e12, 1e13]  # kg/m^3
    print(f"{'Центральна густина (г/см³)':>28} | {'Маса (M_☉)':>10} | {'Радіус (км)':>11}")
    print("-" * 57)
    for rho_c in densities:
        m_star, r_star = solve_white_dwarf(rho_c)
        print(f"{(rho_c / 1000.0):28.1e} | {m_star:10.3f} | {r_star:11.1f}")
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <iomanip>
#include <utility>

constexpr double G_CONST = 6.67430e-11;
constexpr double C_SPEED = 2.99792458e8;
constexpr double M_SUN   = 1.98847e30;
constexpr double M_E     = 9.1093837e-31;
constexpr double M_U     = 1.660539066e-27;
constexpr double HBAR    = 1.054571817e-34;
constexpr double PI_VAL  = 3.14159265358979323846;

constexpr double MU_E    = 2.0;
const double B_CONST     = (8.0 * PI_VAL * std::pow(M_E * C_SPEED, 3) * MU_E * M_U) / (3.0 * std::pow(2.0 * PI_VAL * HBAR, 3));
const double A_CONST     = (PI_VAL * std::pow(M_E, 4) * std::pow(C_SPEED, 5)) / (3.0 * std::pow(2.0 * PI_VAL * HBAR, 3));

struct WhiteDwarfResult {
    double mass_solar;
    double radius_km;
};

double eos_pressure(double x) {
    if (x < 1e-4) {
        return (8.0 / 15.0) * A_CONST * std::pow(x, 5);
    }
    return A_CONST * (x * (2.0 * x * x - 3.0) * std::sqrt(1.0 + x * x) + 3.0 * std::asinh(x));
}

double eos_dp_dx(double x) {
    return 8.0 * A_CONST * std::pow(x, 4) / std::sqrt(1.0 + x * x);
}

double inv_eos_x(double p_target) {
    if (p_target <= 0.0) return 0.0;
    double x = std::pow(15.0 * p_target / (8.0 * A_CONST), 0.2);
    for (int iter = 0; iter < 25; ++iter) {
        double p_val = eos_pressure(x);
        double diff = p_val - p_target;
        if (std::abs(diff) < 1e-9 * p_target) break;
        x -= diff / eos_dp_dx(x);
        if (x < 0.0) x = 1e-10;
    }
    return x;
}

double eos_density(double x) {
    return B_CONST * std::pow(x, 3);
}

WhiteDwarfResult solve_white_dwarf(double rho_center, double dr = 500.0) {
    double x_center = std::pow(rho_center / B_CONST, 1.0 / 3.0);
    double p_center = eos_pressure(x_center);

    double r = dr;
    double m = (4.0 / 3.0) * PI_VAL * std::pow(r, 3) * rho_center;
    double p = p_center - (2.0 / 3.0) * PI_VAL * G_CONST * (rho_center * rho_center) * (r * r);

    auto derivatives = [](double r_val, double m_val, double p_val) -> std::pair<double, double> {
        if (p_val <= 0.0) return {0.0, 0.0};
        double x_val = inv_eos_x(p_val);
        double rho_val = eos_density(x_val);
        double dp_dr = - (G_CONST * m_val * rho_val) / (r_val * r_val);
        double dm_dr = 4.0 * PI_VAL * (r_val * r_val) * rho_val;
        return {dm_dr, dp_dr};
    };

    while (p > 1e-7 * p_center && r < 5e7) {
        auto [dm1, dp1] = derivatives(r, m, p);
        auto [dm2, dp2] = derivatives(r + 0.5 * dr, m + 0.5 * dr * dm1, p + 0.5 * dr * dp1);
        auto [dm3, dp3] = derivatives(r + 0.5 * dr, m + 0.5 * dr * dm2, p + 0.5 * dr * dp2);
        auto [dm4, dp4] = derivatives(r + dr, m + dr * dm3, p + dr * dp3);

        m += (dr / 6.0) * (dm1 + 2.0 * dm2 + 2.0 * dm3 + dm4);
        p += (dr / 6.0) * (dp1 + 2.0 * dp2 + 2.0 * dp3 + dp4);
        r += dr;
    }

    return {m / M_SUN, r / 1000.0};
}

int main() {
    const std::vector<double> densities = {1e8, 1e9, 1e10, 1e11, 1e12, 1e13};
    std::cout << std::setw(28) << "Центральна густина (г/см³)"
              << " | " << std::setw(10) << "Маса (M_☉)"
              << " | " << std::setw(11) << "Радіус (км)" << "\n";
    std::cout << std::string(57, '-') << "\n";

    for (double rho_c : densities) {
        WhiteDwarfResult res = solve_white_dwarf(rho_c);
        std::cout << std::scientific << std::setprecision(1) << std::setw(28) << (rho_c / 1000.0)
                  << " | " << std::fixed << std::setprecision(3) << std::setw(10) << res.mass_solar
                  << " | " << std::setprecision(1) << std::setw(11) << res.radius_km << "\n";
    }
    return 0;
}
```

## 6. Фізичний аналіз та інтерпретація обчислених результатів

Результати чисельного розрахунку показують фундаментальні фізичні закономірності структури вироджених зірок:

1. **Залежність маси від густини:** При зростанні центральної густини `ρ_c` від `10⁵ g/cm³` до `10¹⁰ g/cm³` маса білого карлика зростає монотонно, але зі швидким виположенням. При `ρ_c = 10⁵ g/cm³` маса становить `M ≈ 0.40 M_☉`, при `ρ_c = 10⁷ g/cm³` — `M ≈ 1.08 M_☉`, при `ρ_c = 10⁹ g/cm³` — `M ≈ 1.38 M_☉`, а при `ρ_c ➔ ∞` асимптотично прямує до `1.44 M_☉`.
2. **Зменшення радіуса зі зростанням маси:** На відміну от звичайних зірок головної послідовності, білі карлики зменшуються у розмірах при збільшенні маси. Для легкого білого карлика (`0.4 M_☉`) радіус становить близько `11 000 km` (більше за Землю), тоді як для масивного карлика (`1.38 M_☉`) радіус зменшується до `2 200 km`.
3. **Наближення до межі Чандрасекара:** Оскільки при `ρ_c > 10⁶ g/cm³` електрони стають ультрарелятивістськими, рівняння стану пом'якшується до `P ∝ ρ⁴/³`. У цьому режимі приріст тиску недостатній для компенсації гравітаційного стиснення при збільшенні маси. Радіус падає до нуля при досягненні граничної маси `M_Ch ≈ 1.44 M_☉`.
4. **Ефекти ядерного захоплення електронів та вибуху:** При густинах `ρ_c > 10⁹ g/cm³` у дійсних зорях вмикаються ефекти пікноядерних реакцій та електронного захоплення на ядрах Вуглецю й Кисню, що зменшує концентрацію вільних електронів `n` та викликає передчасний термоядерний спалах або колапс ядра.
