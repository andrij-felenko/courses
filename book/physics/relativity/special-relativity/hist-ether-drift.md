# 📜 Ефірний вітер та криза класичної фізики

Історія пошуку світлоносного ефіру є одним із найпочальніших розділів науки. Вона демонструє, як логічна, візуально зрозуміла й натурфілософськи природна концепція протягом кількох десятиліть спрямовувала теоретичну думку провідних фізиків світла хибним шляхом, а виниклий експериментальний тупик зрештою відкрив шляхи до глибокої революції у наших уявленнях про простір, час та структуру Всесвіту.

## 1. Хвильова оптика XIX століття та концепція всепроникного середовища

Наприкінці XIX століття фізична наука перебувала у стані тріумфального піднесення. Створення Джеймсом Клерком Максвеллом класичної електродинаміки об'єднало у єдину математичну систему електричні, магнітні та оптичні явища. Згідно з рівняннями Максвелла, світло являє собою електромагнітну хвилю, яка поширюється у вакуумі зі сталою фазовою швидкістю:

```
c = 1 / √(ε₀·μ₀) ≈ 2.99792·10⁸ м/с
```

де `ε₀` — електрична стала, а `μ₀` — магнітна стала вакууму.

Проте для наукової спільноти того часу уявлення про хвилю, яка поширюється у «нічому», було абсолютно неприйнятним. Звукові хвилі потребують для поширення пружного середовища — повітря, води чи твердого тіла; хвилі на поверхні океану неможливі без самої води. Відповідно, вважалося самоочевидним, що й світлові хвилі є коливаннями гіпотетичного, всепроникного, невагомого та надзвичайно пружного середовища — світлоносного ефіру (*англ. luminiferous aether*).

Припущення про існування ефіру породжувало серйозну фізичну проблему при спробі опису руху матеріальних тіл крізь це середовище. Виникло три основні конкуруючі гіпотези:

1. **Непорушний (абсолютний) ефір Огюстена Френеля (1818):** Ефір заповнює весь Всесвіт і перебуває у стані абсолютного спокою. Матеріальні тіла рухаються крізь нього без тертя, але заломлюючі прозорі середовища частково захоплюють ефір зі коефіцієнтом захоплення `f = 1 - 1/n²` (де `n` — показник заломлення). Цю гіпотезу блискуче підтвердив експеримент Армана Фізо 1851 року з вимірювання швидкості світла у рухомій воді.
2. **Повністю захоплюваний ефір Джорджа Ґабріеля Стокса (1845):** Ефір повністю захоплюється рухомою Землею у її поверхневих шарах через в'язкість, тому біля поверхні Землі ефір перебуває у спокої відносно нашої планети.
3. **Ефір, що підпорядковується принципу відносності Ґалілея:** Швидкість світла дорівнює `c` лише відносно джерела світла чи ефіру, прив'язаного до джерела.

Фундаментальна суперечність виникла при спробі узгодити електродинаміку Максвелла з класичною механікою Ньютона. За принципом відносності Ґалілея, якщо в інерціальній системі відліку `S` (прив'язаній до ефіру) світловий промінь поширюється зі швидкістю `c`, то у системі відліку `S'`, що рухається зі швидкістю `v`, швидкість світла має дорівнювати `c' = c - v`. Проте у рівняннях Максвелла швидкість `c` входила як абсолютна фундаментальна константа, яка взагалі не містила параметра швидкості спостерігача `v` відносно ефіру!

Це означало неминучу дилему:
- Або рівняння Максвелла помилкові та мають бути скориговані при переході у рухомі системи відліку;
- Або принцип відносності взагалі не діє для електромагнітних явищ, і існує лише єдина привілейована («абсолютна») система відліку, у якій ефір нерухомий;
- Або класичні перетворення Ґалілея для координат і часу є помилковими.

## 2. Експеримент Майкельсона — Морлі: пошук ефірного вітру

Оскільки Земля рухається навколо Сонця з орбітальною швидкістю близько `v ≈ 30` км/с, на її поверхні мав би спостерігатися потік ефіру — так званий **«ефірний вітер»** відповідної швидкості. Якщо абсолютний ефір існує, то швидкість світла, виміряна на Землі вздовж напрямку орбітального руху, має відрізнятися від швидкості світла у перпендикулярному напрямку.

Першу спробу виявити цей зсув зробив американський фізик Альберт Майкельсон у 1881 році під час стажування в Берліні та Потсдамі. Отримавши невизначений результат через вібрації приладу, Майкельсон удосконалив експериментальну установку і в 1887 році у Клівленді (США) разом із хіміком Едвардом Морлі провів знаменитий експеримент.

Інтерферометр Майкельсона складався з масивної плити (яка плавала у чаші з ртуттю для усунення вібрацій та забезпечення плавного обертання) та системи дзеркал. Напівпрозоре дзеркало ділило промінь світла від одного джерела на два взаємно перпендикулярні плечі однакової довжини `L ≈ 11` метрів (шлях світла було подовжено багаторазовим відбиттям).

Розрахунок різниці часу проходження двох променів базувався на класичній кінематиці:

1. **Промінь вздовж ефірного вітру:** При русі туди промінь долає шлях зі швидкістю `c - v` відносно приладу, а при русі назад — зі швидкістю `c + v`. Загальний час становить:

```
t_parallel
= L / (c - v) + L / (c + v)
= (2·L·c) / (c² - v²)
= (2·L / c) / (1 - v² / c²)                 [час проходу вздовж руху]
```

Використовуючи розклад у степеневий ряд для `v << c`:

```
t_parallel ≈ (2·L / c)·(1 + v² / c²)
```

2. **Промінь перпендикулярно до ефірного вітру:** Світло змушене рухатися під кутом, аби компенсувати знос ефірним потоком. За теоремою Піфагора швидкість світла відносно приладу дорівнює `√(c² - v²)`, а загальний час становить:

```
t_perpendicular
= 2·L / √(c² - v²)
= (2·L / c) / √(1 - v² / c²)               [час проходу поперек руху]
```

Розклад у степеневий ряд дає:

```
t_perpendicular ≈ (2·L / c)·(1 + v² / (2·c²))
```

Різниця в часі між двома променями дорівнювала:

```
Δt = t_parallel - t_perpendicular ≈ (L / c)·(v² / c²)
```

При повороті інтерферометра на `90` градусів плечі мінялися місцями, тому очікуваний часовий зсув подвоювався: `2·Δt = (2·L / c)·(v² / c²)`. Для довжини хвилі світла `λ ≈ 590` нм очікуваний зсув інтерференційних смуг становив `ΔN ≈ 0.4` смуги. Чутливість установки дозволяла надійно зафіксувати зсув навіть у `0.01` смуги (що відповідало швидкості ефірного вітру всього у `1-2` км/с).

Проте експеримент Майкельсона — Морлі дав **абсолютно нульовий результат**. Жодного зсуву інтерференційних смуг виявити не вдалося в жодну пору доби та в жодний сезон року. Світло долало обома плечима приладу абсолютно однаковий час, ніби Земля була повністю нерухомою у Всесвіті.

## 3. Криза теоретичної фізики та компенсаційні гіпотези

Нульовий результат експерименту Майкельсона — Морлі поставив теоретичну фізику перед катастрофічним глухим кутом. Гіпотеза повністю захоплюваного ефіру Стокса заперечувалася явищем астрономічної аберації світла зірок (відкритим Джеймсом Бредлі у 1728 році), яке вимагало, щоб ефір поблизу Землі не захоплювався. Виникала суперечність: аберація вимагала непорушного ефіру, а експеримент Майкельсона — Морлі заперечував існування руху відносно нього.

Щоб врятувати гіпотезу ефіру, науковці почали висувати «депешні» компенсаційні гіпотези:

- **Гіпотеза скорочення Фіцджеральда — Лоренца (1889, 1892):** Ірландський фізик Джордж Фіцджеральд та нідерландський теоретик Гендрік Лоренц незалежно припустили, що будь-яке тверде тіло, яке рухається крізь ефір зі швидкістю `v`, механічно скорочується у напрямку свого руху в `γ` разів:

```
L(v) = L₀·√(1 - v² / c²)
```

Якщо поздовжнє плече інтерферометра скорочується саме у стільки разів, час проходження променя `t_parallel` зменшується і стає суворо рівним `t_perpendicular`, що автоматично пояснює нульовий результат експерименту!

- **Електронна теорія Лоренца (1895–1904):** Лоренц розробив глибоку математичну модель, у якій речовина складалася з заряджених частинок (електронів). Він показав, що електромагнітні сили між атомами при русі крізь ефір змінюються таким чином, що структура тіла справді має скорочуватися. У 1904 році Лоренц записав повну систему перетворень координат і часу, які залишали рівняння Максвелла інваріантними.

- **Місцевий час та внесок Анрі Пуанкаре (1900–1904):** Видатний французький математик Анрі Пуанкаре дав фізичну інтерпретацію введеної Лоренцом математичної величини `t' = t - v·x / c²` як «місцевого часу» (*англ. local time*), який вимірюється годинниками, синхронізованими за допомогою світлових сигналів. У 1904 році у промові на Науковому конгресі в Сент-Луїсі Пуанкаре вперше сформулював **Загальний принцип відносності**: жодний фізичний експеримент (як механічний, так і електромагнітний) не здатний виявити абсолютний рух системи відліку відносно ефіру.

Проте і Лоренц, і Пуанкаре залишалися полоненими класичної парадигми. Вони вважали ефір реальною фізичною субстанцією, а скорочення довжини та зміну часу — лише штучними «динамічними ефектами» деформації атомарної структури приладів під дією ефірного вітру.

## 4. Революція Айнштайна 1905 року

Оточення фізиків сприймало скорочення Лоренца як штучну компенсаційну гіпотезу, вигадану спеціально для пояснення одного-єдиного експерименту. Вирішальний прорив здійснив 26-річний експерт швейцарського патентного бюро в Берні Альберт Айнштайн.

У своїй фундаментальній праці 1905 року «До електродинаміки тіл, що рухаються» (*нім. Zur Elektrodynamik bewegter Körper*) Айнштайн розрубав гордіїв вузол класичної фізики радикальним кроком: **він повністю відкинув гіпотезу ефіру як фізично беззмістовну та непотрібну**.

Айнштайн збагнув, що якщо світлоносний ефір неможливо виявити жодним експериментом, то він не є фізичною реальністю. Замість того щоб конструювати складні гіпотетичні механізми стискання атомів у невідомому середовищі, Айнштайн поклав у основу Спеціальної теорії відносності два базові постулати:

1. **Принцип відносності:** Усі інерціальні системи відліку є абсолютно рівноправними для опису всіх без винятку фізичних явищ.
2. **Сталість швидкості світла:** Швидкість світла у вакуумі `c` є однаковою в усіх інерціальних системах відліку.

Геніальність підходу Айнштайна полягала у зміні причино-наслідкового зв'язку:
- Для Лоренца скорочення довжини та уповільнення часу були *наслідком* складних динамічних деформацій тіл при русі крізь реальний ефір.
- Для Айнштайна скорочення довжини та уповільнення часу стали *первинними кінематичними властивостями самого простору і часу*, які випливають із фундаментальної структури простору-часу та сталості швидкості світла.

Експеримент Майкельсона — Морлі перестав бути загадкою чи інженерним дивом. Він виявився природним підтвердженням того, що швидкість світла у вакуумі є абсолютним інваріантом нашого Всесвіту, а концепція абсолютного простору та абсолютного часу Ньютона — лише наближенням, справедливим для малих швидкостей.

У подальші десятиліття нульовий результат Майкельсона — Морлі було перевірено з колосальною точністю (наприклад, експеримент Кеннеді — Торндайка 1932 року, сучасні дослідження з використанням оптичних кріогенних резонаторів). Спеціальна теорія відносності Айнштайна остаточно закрила епоху світлоносного ефіру й відкрила нову еру релятивістської фізики.
