# 🧮 Математичний аналіз ККД та оптимізація втрат

Ця вставка містить строгі математичні виведення співвідношень для коефіцієнта корисної дії (ККД) в електричних та електромагнітних системах. Загальний опис принципів дає якісну картину, проте без алгебраїчного аналізу неможливо довести теорему Якобі про узгодження навантаження, обчислити оптимальний коефіцієнт навантаження трансформатора, вивести точну формулу глибини скін-шару або довести квадратичне падіння втрат у лініях високої напруги.

## Частина 1. Виведення ККД кола постійного струму та теорема Якобі

Розглянемо замкнене електричне коло, що складається з джерела постійної ЕРС `E` з внутрішнім опором `r` та активного навантаження з опором `R_L`.

За законом Ома для замкненого кола струм дорівнює:

```
I = E / (R_L + r)              [закон Ома для замкненого кола]
```

Повна потужність, яка генерується джерелом:

```
P_tot = I · E                  [означення повної потужності джерела]
= (E / (R_L + r)) · E          [підстановка струму I = E / (R_L + r)]
= E² / (R_L + r)              [алгебраїчне перемноження чисельників]
```

Корисна потужність, що виділяється на опорі навантаження `R_L`:

```
P_L = I² · R_L                  [закон Джоуля — Ленца для навантаження]
= (E / (R_L + r))² · R_L        [підстановка струму I = E / (R_L + r)]
= E² · R_L / (R_L + r)²        [піднесення до квадрата та підстановка]
```

Звідси виражаємо ККД кола `η` як відношення корисної потужності до повної:

```
η = P_L / P_tot                [означення коефіцієнта корисної дії]
= (E² · R_L / (R_L + r)²) / (E² / (R_L + r))  [підстановка виразів P_L та P_tot]
= (E² · R_L · (R_L + r)) / (E² · (R_L + r)²)   [перетворення багатоповерхового дробу]
= R_L / (R_L + r)              [скорочення спільних множників E² та (R_L + r)]
```

Розділивши чисельник і знаменник на `r` та ввівши безрозмірний параметр відносного опору `x = R_L / r`, отримуємо функцію ККД:

```
η(x) = (R_L / r) / ((R_L / r) + (r / r))  [ділення чисельника і знаменника на r]
= x / (x + 1)                   [підстановка безрозмірної змінної x = R_L / r]
= x / (1 + x)                   [перестановка доданків у знаменнику]
```

Аналіз граничних значень функції `η(x)`:
- При `x → 0` (`R_L << r`, коротке замикання): `η → 0`. Уся енергія виділяється всередині джерела.
- При `x = 1` (`R_L = r`, узгоджений режим): `η = 1 / (1 + 1) = 0.5` (50%).
- При `x → ∞` (`R_L >> r`, режим холостого ходу): `η → 1` (100%).

Доведемо тепер теорему про максимальну потужність. Для знаходження екстремуму корисної потужності `P_L(R_L)` беремо першу похідну по `R_L` і прирівнюємо її до нуля:

```
dP_L / dR_L = d/dR_L [ E² · R_L · (R_L + r)⁻² ]  [запис виразу потужності для диференціювання]
= E² · [ 1 · (R_L + r)⁻² + R_L · (-2) · (R_L + r)⁻³ ]  [правило диференціювання добутку]
= E² · (R_L + r)⁻³ · [ (R_L + r) - 2 · R_L ]          [винесення спільного множника (R_L + r)⁻³]
= E² · (r - R_L) / (R_L + r)³                        [зведення подібних доданків у дужках]
```

Прирівнюючи похідну до нуля:

```
E² · (r - R_L) / (R_L + r)³ = 0                      [умова екстремуму функції]
⇒ r - R_L = 0                                       [чисельник дорівнює нулю при скінченному знаменнику]
⇒ R_L = r                                           [розв'язок рівняння для точки максимуму]
```

Значення максимальної корисної потужності в точці Якобі (`R_L = r`):

```
P_max = E² · r / (r + r)²                            [підстановка R_L = r у вираз для P_L]
= E² · r / (2·r)²                                   [додавання опорів у знаменнику]
= E² · r / (4 · r²)                                 [піднесення до квадрата]
= E² / (4 · r)                                      [скорочення на r]
```

Отже, корисна потужність сягає абсолютного максимуму `P_max = E² / (4·r)` строго при `R_L = r`. Проте підстановка `R_L = r` у вираз для ККД дає `η = 50%`. Це доводить математичну суперечність між задачею максимізації переданої потужності та задачею максимізації ККД.

## Частина 2. Залежність втрат у лінії електропередачі від напруги та коефіцієнта потужності

Нехай лінія з опором провідників `R_line` передає активну потужність `P` споживачу при напрузі `V`, коефіцієнті потужності `cos φ` та коефіцієнті гармонійних спотворень струму `THD_i`.

Дійсне значення повного струму в лінії становить:

```
I_rms = P / (V · cos φ · √(1 / (1 + THD_i²)))        [вираз для розрахунку повного струму лінії]
```

При нехтуванні гармонійними спотвореннями (`THD_i = 0`):

```
I = P / (V · cos φ)                                  [струм активної та реактивної складової]
```

Потужність втрат на джоулевий нагрів провідників лінії:

```
P_loss = I² · R_line                                 [закон Джоуля — Ленца для провідників]
= (P / (V · cos φ))² · R_line                        [підстановка виразу для струму I]
= (P² · R_line) / (V² · cos² φ)                      [піднесення до квадрата та підстановка]
```

Обчислимо відносні втрати `ΔP = P_loss / P`:

```
ΔP = P_loss / P                                      [визначення відносних втрат лінії]
= ((P² · R_line) / (V² · cos² φ)) / P                [підстановка виразу для P_loss]
= (P · R_line) / (V² · cos² φ)                       [скорочення на потужність P]
```

Звідси ККД лінії електропередачі дорівнює:

```
η_line = P / (P + P_loss)                            [визначення ККД через вхідну та втрачену потужності]
= P / (P + (P² · R_line) / (V² · cos² φ))            [підстановка виразу P_loss]
= 1 / (1 + (P · R_line) / (V² · cos² φ))             [ділення чисельника і знаменника на P]
= 1 / (1 + ΔP)                                       [підстановка відносних втрат ΔP]
```

Розглянемо аналітичний приклад: збільшення напруги лінії `V` у `N = 10` разів (наприклад, з 220 В до 2200 В) за незмінної переданої потужності `P` та опору `R_line`:
- Струм `I` зменшується у 10 разів.
- Потужність втрат `P_loss` зменшується у `N² = 100` разів.
- Відносні втрати `ΔP` падають у 100 разів, а ККД `η_line` наближається до 100%.

Крім того, формула показує роль коефіцієнта потужності `cos φ`: при падінні `cos φ` з 1.0 до 0.707 струм зростає у `√2` разів, що подвоює джоулеві втрати `P_loss` у дрітах лінії при тій самій корисній потужності `P`.

## Частина 3. Оптимізація ККД трансформатора та точка оптимуму навантаження

У силових трансформаторах загальні втрати потужності `P_loss` діляться на дві категорії:
1. Постійні втрати в магнітопроводі (у сталі) `P_0`: вихрові струми та гістерезис, які не залежать від струму навантаження, а лише від напруги й частоти.
2. Змінні втрати в обмотках (у міді) `P_Cu`: джоулевий нагрів обмоток, пропорційний квадрату коефіцієнта навантаження `k = S / S_n` (де `S` — поточна повна потужність, `S_n` — номінальна потужність).

```
P_Cu(k) = k² · P_sc                                  [модель змінних втрат у міді]
```

де `P_sc` — втрати короткого замикання при номінальному струмі (`k = 1`).

Повна вихідна активна потужність трансформатора при коефіцієнті навантаження `k` та коефіцієнті потужності `cos φ`:

```
P_out(k) = k · S_n · cos φ                          [активна потужність навантаження]
```

ККД трансформатора як функція коефіцієнта навантаження `k`:

```
η(k) = P_out(k) / (P_out(k) + P_0 + P_Cu(k))         [визначення ККД трансформатора]
= (k · S_n · cos φ) / (k · S_n · cos φ + P_0 + k² · P_sc)  [підстановка компонентів втрат]
```

Для знаходження коефіцієнта навантаження `k_opt`, при якому ККД сягає максимуму, перетворимо вираз, розділивши чисельник і знаменник на `k · S_n · cos φ`:

```
η(k) = 1 / (1 + (P_0 / (k · S_n · cos φ)) + (k · P_sc / (S_n · cos φ)))  [ділення чисельника й знаменника на P_out]
```

ККД буде максимальним тоді, коли знаменник буде мінімальним. Оскільки одиниця та `S_n · cos φ` є константами, мінімізації підлягає функція втрат у знаменнику `f(k)`:

```
f(k) = (P_0 / k) + k · P_sc                           [виділена функція втрат для мінімізації]
```

Візьмемо похідну `df / dk` і прирівняємо її до нуля:

```
df / dk = d/dk [ P_0 · k⁻¹ + P_sc · k ]              [запис для диференціювання по k]
= -P_0 · k⁻² + P_sc                                  [застосування правила степеневої похідної]
= -P_0 / k² + P_sc = 0                               [прирівнювання похідної до нуля]
⇒ P_0 / k² = P_sc                                    [перенесення доданку зі знаком плюс]
⇒ k² = P_0 / P_sc                                    [множення на k² та ділення на P_sc]
⇒ k_opt = √(P_0 / P_sc)                              [добування квадратного кореня]
```

Фізичний висновок: **ККД трансформатора сягає абсолютного максимуму при такому коефіцієнті навантаження `k_opt`, за якого постійні втрати в сталі `P_0` дорівнюють змінним втратам у міді `k² · P_sc`**.

Розрахунковий приклад:
Якщо для трансформатора потужністю `S_n = 1000 кВА` постійні втрати становлять `P_0 = 2 кВт`, а втрати короткого замикання `P_sc = 8 кВт`:

```
k_opt = √(2 / 8) = √0.25 = 0.5  (50% від номіналу)
```

Це пояснює, чому силові трансформатори в енергомережах проектують із розрахунком на максимум ККД при навантаженні 50–70% від номіналу, оскільки більшу частину часу вони працюють у режимі часткового навантаження.

## Частина 4. Виведення глибини скін-шару з рівнянь Максвелла

Для аналізу омічних втрат на високих частотах виведемо точний вираз для глибини скін-шару `δ`. Згортаючи [рівняння Максвелла](topic:physics/faraday-law-differential) для провідного середовища з провідністю `σ` та магнітною проникністю `μ`:

```
∇ × E = -∂B / ∂t                                     [закон Фарадея у диференціальній формі]
∇ × H = J = σ · E                                    [закон Ампера у плоскому провіднику]
```

Взявши ротор від обох частин першого рівняння:

```
∇ × (∇ × E) = -∂(∇ × B) / ∂t                         [застосування оператора ротора]
⇒ ∇(∇ · E) - ∇²E = -μ · σ · (∂E / ∂t)                [векторна тотожність та підстановка J = σ E]
```

У монохроматичному синусоїдальному режимі з частотою `ω = 2·π·f` часова похідна `∂/∂t` замінюється на `j·ω`. Для однорідного плоского провідника без об'ємного заряду (`∇ · E = 0`):

```
∇²E = j · ω · μ · σ · E                              [рівняння Гельмгольца для поля в провіднику]
```

Позначивши комплексне хвильове число `k² = -j · ω · μ · σ` і враховуючи, що `√j = (1 + j) / √2`:

```
k = (1 - j) / δ                                       [комплексна стала поширення в металі]
```

де глибина скін-шару `δ` виражається як:

```
δ = √(2 / (ω · μ · σ)) = √(1 / (π · f · μ · σ))       [остаточна формула глибини скін-шару]
```

При заглибленні в провідник на відстань `z = δ` амплітуда густини струму спадає в `e ≈ 2.718` раза, а густина джоулевих втрат `p(z) = J(z)² / σ` спадає в `e² ≈ 7.39` раза.

## Частина 5. Математична модель вихрових втрат Прі та Біна (Pry & Bean)

Для пластинчастого магнітопроводу з товщиною пластини `d`, питомим опором `ρ` та густиною матеріалу `ρ_m` точний розрахунок втрат Фуко на одиницю маси при гармонійному перемагнічуванні виводиться інтегруванням вихрових струмів по перерізу пластини:

```
P_e = (1 / T) · ∫₀ᵀ [ (1 / d) · ∫₋d/₂⁺d/₂ (J_e(z,t)² / σ) dz ] dt  [інтеграл дисипації потужності Фуко]
```

Розв'язок рівняння для тонкої пластини (`d << δ`):

```
P_e = (π² · f² · B_max² · d²) / (6 · ρ · ρ_m)         [класична формула втрат Фуко для пластини]
```

Ця формула математично пояснює квадратичний вплив товщини пластини `d²`: зменшення товщини пластин електротехнічної сталі удвічі (наприклад, з 0.5 мм до 0.25 мм) зменшує вихрові втрати у 4 рази.
