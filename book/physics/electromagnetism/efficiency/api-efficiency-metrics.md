# 📋 Стандарти та метрики вимірювання ККД

Цей довідник містить технічну специфікацію міжнародних стандартів, класів енергоефективності, методик розділення втрат та протоколів вимірювання ККД для електромагнітного та силового обладнання. Матеріал структуровано у вигляді табличних даних і нормативних формул, необхідних для проєктування, сертифікації та випробувань пристроїв у промисловості.

## 1. Класи ефективності електродвигунів (IEC 60034-30-1 / IEEE 112)

Міжнародний стандарт **IEC 60034-30-1** визначає п'ять гармонізованих класів енергоефективності для трифазних асинхронних і синхронних двигунів промислової частоти (50/60 Гц) потужністю від 0.12 кВт до 1000 кВт. Класифікують двигуни від IE1 (найнижча допустима ефективність) до IE5 (ультра-преміальна ефективність). Кожен наступний клас вимагає зменшення загальних втрат приблизно на 15–20% порівняно з попереднім.

### Протокол вимірювання та розділення втрат (IEC 60034-2-1)

Для суворого визначення ККД використовують прямий вимірювальний метод або метод підсумовування окремих втрат (*Summation of Losses Method*). Метод прямого вимірювання (навантажувальний гальмовий стенд) вимірює вхідну електричну потужність `P_in` та вихідну механічну потужність на валу `P_out = T · ω` (де `T` — обертальний момент у Н·м, `ω` — кутова швидкість у рад/с). Проте прямий метод має високу похибку вимірювання (до ±1–2%).

Тому стандарт IEC 60034-2-1 надає перевагу методу підсумовування втрат, за яким загальна потужність втрат `P_loss` розкладається на п'ять окремих вимірюваних складових:

```
P_loss = P_s + P_r + P_fe + P_fw + P_ll
```

Опис та фізичний механізм кожної складової наведено в наступному нормативному реєстрі:

| Позначення | Назва складової втрат | Фізичний механізм виникнення | Метод вимірювання / розрахунку |
| :--- | :--- | :--- | :--- |
| `P_s` | Втрати в обмотці статора | Джоулеве нагрівання обмотки статора `I_s² · R_s` | Вимірювання опору постійному струму `R_s` із термокомпенсацією |
| `P_r` | Втрати в роторі | Джоулеве нагрівання струмами ротора `I_r² · R_r` | Розрахунок через коефіцієнт ковзання `s`: `P_r = s · (P_in - P_s - P_fe)` |
| `P_fe` | Втрати в залізі (осерді) | Гістерезис та вихрові струми у сталі статора | Дослід холостого ходу при змінній напрузі з екстраполяцією |
| `P_fw` | Механічні втрати | Тертя в підшипниках та вентиляційне гальмування | Дослід холостого ходу при нульовій магнітній індукції |
| `P_ll` | Додаткові втрати під навантаженням | Високочастотні пульсації поля у зубах та зазорі | Вимірювання при виключених основних втратах за методом EH-STAR |

### Температурне коригування опору обмоток

Оскільки опір металевих провідників зростає з температурою, активні втрати статора `P_s` та ротора `P_r` повинні приводитися до еталонної базової температури випробувань (зазвичай 75 °C або 115 °C залежно від класу ізоляції). Формула приведення опору `R(T_ref)` від виміряного значення при температурі `T_meas`:

```
R(T_ref) = R(T_meas) · (k + T_ref) / (k + T_meas)
```

де значення температурної константи `k` становить `k = 235` для мідних обмоток та `k = 225` для алюмінієвих обмоток або литої роторної клітки.

Формула розрахунку ККД за методом підсумовування втрат:

```
η = (P_in - P_loss) / P_in = 1 - (P_s + P_r + P_fe + P_fw + P_ll) / P_in
```

## 2. Стандарти випробувань силових трансформаторів (IEC 60076 / IEEE C57.12)

Сертифікація ККД силових та розподільчих трансформаторів спирається на вимірювання втрат у двох нормативних випробувальних режимах. Вони дозволяють відокремити постійні втрати перемагнічування в сталі від змінних втрат у мідних обмотках.

### Таблиця 2. Нормативні випробувальні режими трансформаторів

| Параметр випробування | Дослід холостого ходу (No-Load Test) | Дослід короткого замикання (Short-Circuit Test) |
| :--- | :--- | :--- |
| **Вхідна напруга** | Номінальна напруга `V_n` на первинній обмотці | Понижена напруга короткого замикання `V_sc` (4–10% від `V_n`) |
| **Стан другої обмотки** | Розімкнена (`I_2 = 0`) | Замикнена накоротко (`V_2 = 0`) |
| **Струм у первинній обмотці** | Малий струм намагнічування `I_0` (0.5–2% від номіналу) | Номінальний струм `I_n` |
| **Вимірювана величина** | Постійні втрати в сталі `P_0` (кВт) | Повні втрати в міді `P_sc` (кВт) при номінальному струмі |

### Нормативні допуски вимірювального обладнання

Під час випробувань трансформаторів великої потужності за стандартом IEC 60076-1 вимірювальні вимірювальні трансформатори струму (ТС), трансформатори напруги (ТН) та аналізатори потужності повинні мати клас точності не гірший ніж 0.1 (похибка не більше ±0.1%). Гранично допустиме відхилення виміряних втрат від паспортних даних виробника становить:
- Для загальних втрат `P_tot`: не більше +10%;
- Для окремих втрат `P_0` чи `P_sc`: не більше +15% при збереженні обмеження +10% на загальні втрати.

### Формула розрахунку ККД трансформатора для довільного навантаження

На основі отриманих у двох дослідах втрат `P_0` та `P_sc` розраховують ККД трансформатора для будь-якого коефіцієнта навантаження `k` та температурного режиму:

```
η(k, cos φ) = (k · S_n · cos φ) / (k · S_n · cos φ + P_0 + k² · P_sc · (T_real + 235) / (T_ref + 235))
```

де:
- `k = S / S_n` — коефіцієнт навантаження (відношення повної потужності навантаження до номінальної);
- `S_n` — номінальна повна потужність трансформатора, кВА;
- `cos φ` — коефіцієнт потужності навантаження;
- `P_0` — втрати холостого ходу, кВт;
- `P_sc` — втрати короткого замикання при базовій температурі, кВт;
- `T_real`, `T_ref` — реальна та базова температура обмоток (зазвичай 75 °C для класу ізоляції F, константа 235 відповідає температурному коефіцієнту міді).

## 3. Специфікація блоків живлення 80 PLUS (ATX / Server Power Supplies)

Стандарт **80 PLUS** регламентує вимоги до ККД внутрішніх блоків живлення комп'ютерного та серверного обладнання при трьох або чотирьох фіксованих рівнях навантаження (10%, 20%, 50%, 100%). Норматив вимагає, щоб блок живлення мав ККД не нижче 80% при будь-якому робочому навантаженні від 20% до 100%.

Серверні блоки живлення (категорія *Internal Redundant*) випробовуються при напрузі мережі 230 В змінного струму. Такий вибір пояснюється тим, що при вищій напрузі 230 В порівняно з 115 В струм споживання при тій самій потужності менший удвічі, що знижує втрати на вхідному мостовому випрямлячі та підвищує ККД блоку живлення на 1.5–2.0%.

| :--- | :--- | :--- | :--- | :--- | :--- |

Додатково стандарт обмежує енергоспоживання у режимі очікування (Standby Power): для відповідності екологічним директивам ErP Lot 6 споживання блоку живлення у режимі Standby не повинно перевищувати 0.5 Вт.

## 4. Зважені метрики ККД для сонячних інверторів (Euro / CEC Efficiency)

Оскільки сонячні фотоелектричні інвертори працюють при мінливій сонячній інсоляції, оцінка ККД за одним номінальним значенням є нерепрезентативною. Для цього застосовують інтегральні зважені показники **Європейського ККД (`η_euro`)** та **ККД Каліфорнійської енергетичної комісії (`η_cec`)**. Ці методики надають різну вагу виміряним значенням ККД при різних рівнях потужності відповідно до статистичного розподілу сонячного випромінювання.

Окремо вимірюють стачний та динамічний ККД відстеження точки максимальної потужності **MPPT** (*Maximum Power Point Tracking Efficiency*, стандарт EN 50530):

```
η_MPPT = ∫ P_dc_in(t) dt / ∫ P_pv_max(t) dt
```

Динамічний ККД MPPT перевіряє, наскільки швидко цифровий контролер інвертора знаходить оптимальну точку на вольт-амперній характеристиці сонячної панелі при різких змінах освітленості (наприклад, при проходженні хмар зі швидкістю зміни інсоляції від 10 до 100 Вт/м²/с). У сучасних інверторах `η_MPPT` перевищує 99.5%.

### Формули зваженої ефективності

Європейська формула `η_euro` розрахована на середньоєвропейський клімат із більшою часткою хмарних днів, тому найбільша вага (48%) надається навантаженню 50%:

```
η_euro = 0.03 · η_5% + 0.06 · η_10% + 0.13 · η_20% + 0.10 · η_30% + 0.48 · η_50% + 0.20 · η_100%
```

Американська формула `η_cec` розрахована на сонячні південні регіони (Каліфорнія, Аризона), тому найбільшу вагу (53%) отримало навантаження 75%:

```
η_cec = 0.04 · η_10% + 0.05 · η_20% + 0.12 · η_30% + 0.21 · η_50% + 0.53 · η_75% + 0.05 · η_100%
```

| Рівень навантаження (P_in / P_n) | Вага в європейській метриці (η_euro) | Вага в американській метриці (η_cec) |
| :--- | :--- | :--- |

Отриманий зважений коефіцієнт описує реальну середньорічну енерговіддачу сонячної електростанції з урахуванням добового та сезонного руху Сонця.
