# 🧮 Математичний вивід рівняння індукції та теорема Коулінґа

Рівняння індукції магнітної гідродинаміки (МГД) є фундаментальним рівнянням, що описує часову еволюцію магнітного поля у рухомому суцільному провідному середовищі. Воно поєднує рівняння електродинаміки Максвелла із кінематикою суцільних середовищ. Нижче наведено послідовний вивід цього рівняння, аналіз безрозмірного магнітного числа Рейнольдса, теорію середніх полів та математичне доведення теореми Коулінґа про неможливість вісесиметричного динамо.

## 1. Вивід рівняння індукції з рівнянь Максвелла

Розглянемо вихрове середовище з електропровідністю `σ` та магнітною проникністю `μ₀` (немагнітне середовище), яке рухається зі швидкістю `v`. У квазістаціонарному наближенні МГД струмами зсуву `∂D/∂t` нехтують, оскільки характерні швидкості рідини `U` набагато менші за швидкість світла `c` (`U << c`).

Вихідна система рівнянь має вигляд:

1. Закон індукції Фарадея:
   `∇ × E = -∂B/∂t`

2. Закон Ампера без струму зсуву:
   `∇ × B = μ₀ J`

3. Відсутність магнітних монополів:
   `∇ · B = 0`

4. Узагальнений закон Ома для середовища, що рухається зі швидкістю `v`:
   `J = σ · (E + v × B)`

Розв'яжемо закон Ома відносно напрямленості електричного поля `E`:

```
E = (1/σ)·J - v × B      [ділення на σ та перенос v × B]
```

Підставимо густину струму `J = (1/μ₀) · (∇ × B)` із закону Ампера у вираз для електричного поля `E`:

```
E = (1 / (μ₀·σ)) · (∇ × B) - v × B      [підстановка J = (1/μ₀)·(∇ × B)]
```

Введемо коефіцієнт магнітної дифузійності `η` (вимірюється в м²/с):

```
η = 1 / (μ₀ · σ)                         [означення магнітної дифузійності]
```

Тоді вираз для електричного поля набуває вигляду:

```
E = η · (∇ × B) - v × B                  [підстановка η]
```

Тепер підставимо отриманий вираз для `E` у закон індукції Фарадея `∇ × E = -∂B/∂t`:

```
-∂B/∂t = ∇ × (η · (∇ × B) - v × B)       [підстановка E у закон Фарадея]
```

Помножимо обидві частини на `-1` та розкриємо ротор різниці:

```
∂B/∂t = ∇ × (v × B) - ∇ × (η · (∇ × B))  [лінійність оператора ротора]
```

Якщо електропровідність середовища однорідна (`η = const`), коефіцієнт `η` виноситься з-під знака ротора:

```
∂B/∂t = ∇ × (v × B) - η · ∇ × (∇ × B)    [винесення константи η]
```

Застосуємо відому векторну тотожність для подвійного ротора `∇ × (∇ × B) = ∇(∇ · B) - ∇²B`:

```
∂B/∂t = ∇ × (v × B) - η · (∇(∇ · B) - ∇²B)  [векторна тотожність]
```

Оскільки за третім рівнянням Максвелла `∇ · B = 0` (магнітне поле соленоїдальне), перший доданок у дужках перетворюється на нуль:

```
∂B/∂t = ∇ × (v × B) + η · ∇²B            [враховано ∇ · B = 0]
```

Отримане рівняння і є **фундаментальним рівнянням індукції МГД**.

## 2. Фізичний зміст та безрозмірне магнітне число Рейнольдса

Рівняння індукції складається з двох конкуруючих членів у правій частині:

1. **Адвективний (генераційний) член `∇ × (v × B)`**: описує захоплення, витягування та підсилення силових ліній магнітного поля рухом провідної рідини.
2. **Дифузійний (дисипативний) член `η · ∇²B`**: описує омічне згасання струмів та дифузію магнітного поля крізь рідину.

Для оцінки відносного внеску цих двох процесів зведемо рівняння до безрозмірного вигляду. Нехай `L` — характерний просторовий масштаб системи (наприклад, товщина рідкого ядра Землі `L ~ 10⁶ м`), `U` — характерна швидкість потоку (`U ~ 10⁻⁴ м/с`), а `B₀` — напруженість поля.

Введемо безрозмірні змінні:
`r' = r / L`, `v' = v / U`, `t' = t / (L / U)`.

Підставивши їх у рівняння індукції, отримуємо:

```
(U·B₀ / L) · (∂B'/∂t') = (U·B₀ / L) · ∇' × (v' × B') + (η·B₀ / L²) · ∇'²B'
```

Поділимо обидві частини рівняння на масштабний множник дифузії `(η·B₀ / L²)`:

```
(U·L / η) · (∂B'/∂t') = (U·L / η) · ∇' × (v' × B') + ∇'²B'
```

Безрозмірний коефіцієнт при адвективних членах називається **магнітним числом Рейнольдса (Rm)**:

```
Rm = (U · L) / η = μ₀ · σ · U · L        [означення магнітного числа Рейнольдса]
```

Розглянемо граничні режими:

- **Граничний режим `Rm << 1` (дифузійний режим)**:
  Адвективний член малий порівняно з дифузією. Рівняння спрощується до рівняння теплопровідності `∂B/∂t ≈ η · ∇²B`. Будь-яке початкове магнітне поле згасає за характерний час дифузії `τ_diff = L² / η`. Для ядра Землі при `L ≈ 2·10⁶ м` та `η ≈ 1.5 м²/с` час омічного диференційного згасання становить:
  `τ_diff ≈ (2·10⁶)² / 1.5 ≈ 2.7·10¹² с ≈ 85 000 років`.
  Без постійного підкачування енергії магнітне поле Землі зникло б за кілька десятків тисяч років.

- **Граничний режим `Rm >> 1` (режим «вмороженого» поля, теорема Альфвена)**:
  Дифузійний член малий `∂B/∂t ≈ ∇ × (v × B)`. Магнітні силові лінії поводяться так, ніби вони нерозривно вморожені в елементи об'єму рідини і рухаються разом із ними. Для рідкого ядра Землі `Rm ≈ 100 - 1000 >> 1`, що є необхідною умовою для існування геодинамо.

## 3. Магнітна спіральність та інваріанти Вольтєра

У середовищі без дисипації (`η = 0`, ідеальна МГД) геометрія магнітних силових ліній описується так званими топологічними інваріантами. Головним із них є **магнітна спіральність (Magnetic Helicity)** `H_m`, визначена як об'ємний інтеграл:

```
H_m = ∫_V (A · B) dV
```

де `A` — магнітний векторний потенціал (`B = ∇ × A`).

Магнітна спіральність вимірює ступінь зачеплення, скрученості та вузлуватості силових ліній магнітного поля. За теоремою Вольтєра (Woltjer, 1958), в ідеальній МГД магнітна спіральність є строго збережуваною величиною:

```
dH_m / dt = 0  при η = 0
```

При наявності малої дисипації (`η > 0`) магнітна спіральність дисипує набагато повільніше за магнітну енергію `E_m = ∫ (B² / (2 μ₀)) dV`. Це створює ефект зворотного каскаду: дрібномасштабна турбулентна спіральність, що створюється Альфа-ефектом, самоорганізується у великомасштабне когерентне дипольне поле планетного масштабу.

## 4. Вивід Альфа-ефекту в електродинаміці середніх полів

Для опису турбулентних конвективних потоків використовується метод усереднення за статистичним ансамблем або просторовим об'ємом (розклад Штеенбека-Краузе-Редлера). Розкладемо швидкість `v` та магнітне поле `B` на великомасштабні усереднені компоненти `(V, B₀)` та дрібномасштабні турбулентні пульсації `(v', b')`:

```
v = V + v',   <v'> = 0
B = B₀ + b',  <b'> = 0
```

Підставимо цей розклад у рівняння індукції та усереднимо його:

```
∂B₀/∂t = ∇ × (V × B₀) + ∇ × E_m + η · ∇²B₀
```

де `E_m = <v' × b'>` — **середня турбулентна електрорушійна сила (ЕРС)**.

Для знаходження ЕРС `E_m` випишемо рівняння пульсацій полем `b'`. У наближенні першого порядку (First-Order Smoothing Approximation, FOSA, або `Rm' << 1` для пульсацій):

```
∂b'/∂t - η·∇²b' ≈ (B₀ · ∇)v' - (v' · ∇)B₀
```

Розв'язуючи це рівняння відносно `b'` через тензор Гріна та підставляючи у вираз для `E_m`, отримуємо тензорний розклад:

```
E_m,i = α_ij · B₀,j + β_ijk · ∂B₀,j / ∂x_k
```

У разі ізотропної псевдоскалярної турбулентності тензори спрощуються до двох скалярних коефіцієнтів:

```
E_m = α · B₀ - β · (∇ × B₀)
```

Коефіцієнт Альфа-ефекту `α` прямо пропорційний кінематичній спіральності турбулентних вихорів:

```
α = -(1/3) · τ_corr · <v' · (∇ × v')>
```

де `τ_corr` — час кореляції турбулентних вихорів, `<v' · (∇ × v')>` — середня кінематична спіральність. Саме від'ємна спіральність у Північній півкулі та додатна у Південній півкулі забезпечують генерацію меридіонального поля з тороїдального.

Коефіцієнт `β` описує турбулентну магнітну дифузію:

```
β = (1/3) · τ_corr · <v'²>
```

Турбулентна дифузія `β` зазвичай на кілька порядків перевищує молекулярну дифузію `η`, запевняючи швидке переперемішування та самоорганізацію магнітних петель.

## 5. Математичне доведення антидинамо-теореми Коулінґа

Теорема Коулінґа (1933) стверджує: **строго вісесиметричне магнітне поле не може підтримуватися в стаціонарному стані вісесиметричним рухом провідної рідини.**

Доведемо цю теорему методом від супротивного.

Нехай існує стаціонарне (`∂B/∂t = 0`) вісесиметричне магнітне поле `B` та вісесиметричний швидкісний потік `v`. У циліндричній або сферичній системі координат `(r, θ, φ)` вісесиметрія означає, що жодна величина не залежить від азимутального кута `φ` (`∂/∂φ = 0`).

Розкладемо вісесиметричне магнітне поле на полоїдальну (меридіональну) `B_pol` та тороїдальну (широтну) `B_tor` компоненти:

```
B = B_pol + B_tor = ∇ × (A(r,θ) · e_φ) + B_φ(r,θ) · e_φ
```

де `A(r,θ)` — магнітний векторний потенціал полоїдального поля, `e_φ` — орт азимутального напрямку.

Силові лінії полоїдального поля `B_pol` лежать у меридіональних площинах `(r, θ)` і утворюють замкнені концентричні петлі. Усередині кожної такої замкненої петлі у меридіональній площині існує принаймні одна точка (або кільце в 3D просторі), де полоїдальне поле дорівнює нулю:

```
B_pol = 0  на O-подібній нейтральній лінії L
```

Розглянемо азимутальну `φ`-компоненту закону Ома `J = σ · (E + v × B)` вздовж цієї нейтральної лінії `L`:

```
J_φ = σ · (E_φ + (v × B)_φ)
```

Обчислимо векторний добуток `(v × B)_φ` на нейтральній лінії `L`. Розкриємо компоненти:

```
(v × B)_φ = v_r · B_θ - v_θ · B_r
```

Оскільки на нейтральній лінії `L` за визначенням `B_r = 0` та `B_θ = 0` (компоненти `B_pol` дорівнюють нулю), векторний добуток на нейтральній лінії строго перетворюється на нуль:

```
((v × B)_φ)_L = 0                        [бо B_r = B_θ = 0 на лінії L]
```

Отже, на нейтральній лінії `L` азимутальний струм визначається виключно азимутальним електричним полем:

```
(J_φ)_L = σ · (E_φ)_L
```

Застосуємо теорему Стокса до циркуляції електричного поля `E` вздовж замкненої нейтральної лінії `L` радіуса `R_L`:

```
∮_L E · dl = ∫_S (∇ × E) · dS            [теорема Стокса]
```

Оскільки поле стаціонарне (`∂B/∂t = 0`), за законом Фарадея `∇ × E = -∂B/∂t = 0`. Отже, циркуляція електричного поля вздовж нейтральної лінії дорівнює нулю:

```
2·π·R_L · (E_φ)_L = 0  ⇒  (E_φ)_L = 0
```

Звідси випливає, що на нейтральній лінії азимутальний електричний струм строго дорівнює нулю:

```
(J_φ)_L = 0
```

Проте за законом Ампера азимутальний струм `J_φ` пов'язаний із ротором полоїдального магнітного поля:

```
J_φ = (1/μ₀) · (∇ × B_pol)_φ = -(1/μ₀) · ∇²A
```

На нейтральній лінії `L`, де замкнені силові лінії `B_pol` охоплюють максимум потенціалу `A`, друга похідна (лапласіан `∇²A`) є строго від'ємною або додатною величинами, тобто `∇²A ≠ 0`. Це означає, що для підтримки замкненого полоїдального поля на нейтральній лінії **необхідний ненульовий струм** `J_φ ≠ 0`, який би компенсував омічне розсіювання.

Виникла математична суперечність:
1. З індукційного механізму та стаціонарності випливає `(J_φ)_L = 0`.
2. З наявності замкненого полоїдального поля за законом Ампера випливає `(J_φ)_L ≠ 0`.

Отже, припущення про існування стаціонарного вісесиметричного динамо є хибним. Для подолання заборони Коулінґа необхідні **тривимірні невісесиметричні рухи рідини** (`∂/∂φ ≠ 0`), які створюють додаткові тривимірні ЕРС індукції за рахунок спіральності турбулентних вихорів (Альфа-ефект).
