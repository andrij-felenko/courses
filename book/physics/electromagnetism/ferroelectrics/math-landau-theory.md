# 🧮 Теорія Ландау-Девоншира для сегнетоелектричних фазових переходів

Феноменологічна теорія фазових переходів Ландау описує сегнетоелектричний перехід без заглиблення у мікроскопічну атомну структуру кристала. Вона базується на розкладі вільної енергії кристала у степеневий ряд за параметром порядку. Для сегнетоелектриків параметром порядку є вектор спонтанної поляризації `P`. У випадку одновісного кристала поляризацію можна розглядати як скалярну величину `P`, що відповідає зсуву зарядів уздовж виділеної сегнетоелектричної осі.

Цей документ містить повний математичний вивід термодинамічного потенціалу Ландау-Девоншира, розрахунок термодинамічного коерцитивного поля, аналіз пружно-стрикційної взаємодії та варіант теорії Ландау-Гінзбурга для просторово-неоднорідних доменних стінок.

## 1. Термодинамічний потенціал та його розклад

Вільна енергія Гіббса одиниці об'єму кристала `F(P, T, E)` поблизу точки фазового переходу розкладається у парний ряд за ступенями поляризації `P` через міркування інваріантності щодо інверсії простору (у симетричній високотемпературній фазі стани з `+P` та `-P` є енергетично еквівалентними). Модифікація теорії Ландау для сегнетоелектриків, розроблена Афтоном Девонширом, враховує члени до шостого ступеня включно:

```
F(P, T, E) = F_0 + (1/2)·α·P² + (1/4)·β·P⁴ + (1/6)·γ·P⁶ - E·P
```
[де F_0 — вільна енергія неполяризованої фази, α, β, γ — коефіцієнти розкладу, E — зовнішнє електричне поле]

Основне припущення теорії Ландау полягає у тому, що коефіцієнт `α` лінійно залежить від температури `T` і змінює знак при проходженні критичної температури `T_0`:

```
α = α_0·(T - T_0)      [α_0 > 0 — додатна константа, T_0 — температура Кюрі-Вейсса]
```

Знак другого коефіцієнта `β` визначає рід фазового переходу:
- Якщо `β > 0`, відбуваються фазові переходи другого роду (неперервна зміна поляризації).
- Якщо `β < 0` (при `γ > 0`), відбуваються фазові переходи першого роду (стрибкоподібна зміна поляризації).

## 2. Фазовий перехід другого роду (β > 0)

У разі відсутності зовнішнього поля (`E = 0`) рівноважне значення поляризації відповідає мінімуму вільної енергії `dF/dP = 0`:

```
dF/dP = α·P + β·P³ = 0
```
[знаходимо стаціонарні точки термодинамічного потенціалу]

Це рівняння має два розв'язки залежно від температури:

1. Вище температури Кюрі (`T > T_0`, де `α > 0`):
   Єдиний дійсний мінімум відповідає неполяризованому стану:
```
P_s = 0                 [параелектрична фаза]
```

2. Нижче температури Кюрі (`T < T_0`, де `α < 0`):
   Нульовий розв'язок `P = 0` стає нестійким максимумом, а мінімуми формуються у двох симетричних точках:
```
α·P + β·P³ = 0
= P·(α + β·P²) = 0      [виносимо P за дужки]
⇒ P_s² = -α / β
= α_0·(T_0 - T) / β     [підставляємо α = α_0·(T - T_0)]
⇒ P_s = ± √[ α_0·(T_0 - T) / β ]
```

Спонтанна поляризація `P_s` зростає від нуля за кореневым законом `P_s ∝ √(T_0 - T)` при охолодженні нижче критичної температури.

### Діелектрична сприйнятливість та закон Кюрі-Вейсса

Обернена діелектрична сприйнятливість `χ⁻¹` визначається другою похідною вільної енергії за поляризацією:

```
χ⁻¹ = d²F / dP² = α + 3·β·P²
```

Розглянемо сприйнятливість у двох фазах:

- У параелектричній фазі (`T > T_0`, де `P_s = 0`):
```
χ⁻¹ = α = α_0·(T - T_0)
⇒ χ = 1 / [ α_0·(T - T_0) ]
= C / (T - T_0)          [де C = 1/α_0 — константа Кюрі-Вейсса]
```
Це всесвітньо відомий закон Кюрі-Вейсса: при наближенні до критичної температури зверху діелектрична сприйнятливість і проникність прямують до нескінченності.

- У сегнетоелектричній фазі (`T < T_0`, де `P_s² = α_0·(T_0 - T) / β`):
```
χ⁻¹ = α + 3·β·[ α_0·(T_0 - T) / β ]
= α_0·(T - T_0) + 3·α_0·(T_0 - T)
= 2·α_0·(T_0 - T)
⇒ χ = 1 / [ 2·α_0·(T_0 - T) ]
= C / [ 2·(T_0 - T) ]
```

Коефіцієнт `2` у знаменнику відомий як закон «двійки» Ландау: нахил графіку оберненої сприйнятливості `χ⁻¹(T)` у сегнетоелектричній фазі вдвічі крутіший, ніж у параелектричній.

### Стрибок теплоємності при фазовому переході другого роду

Аномалія теплоємності `C_p` при фазовому переході розраховується з другого диференціала вільної енергії за температурою:

```
S = - dF / dT
= S_0 - (1/2)·(dα/dT)·P_s²
= S_0 - (1/2)·α_0·P_s²     [оскільки dα/dT = α_0]
```

Підставляючи розв'язок для `P_s² = α_0·(T_0 - T) / β` нижче `T_0`, отримуємо ентропію сегнетоелектричної фази:

```
S_ferro = S_0 - (1/2)·α_0²·(T_0 - T) / β
```

Стрибок питомої теплоємності `ΔC_p = T_0 · (dS/dT)` у точці `T = T_0` становить:

```
ΔC_p = T_0 · α_0² / (2·β)
```
Це показує, що при переході другого роду теплоємність зазнає скінченного стрибка без виділення прихованої теплоти.

## 3. Теоретичне коерцитивне поле в моделі Ландау

У наявності зовнішнього електричного поля `E ≠ 0` рівняння стану набуває вигляду:

```
dF/dP = α·P + β·P³ - E = 0
⇒ E(P) = α·P + β·P³
```

Залежність `E(P)` має ділянку з від'ємною диференціальною сприйнятливістю `dE/dP < 0`, яка є нестійкою. Межа стійкості (точка біфуркації або катастрофи) відповідає умовам `dE/dP = 0`:

```
dE/dP = α + 3·β·P² = 0
⇒ P_crit² = -α / (3·β)
= (1/3)·P_s²
⇒ P_crit = ± P_s / √3
```

Підставляючи критичне значення поляризації `P_crit` у рівняння для поля `E(P)`, отримуємо термодинамічне коерцитивне поле Ландау `E_c`:

```
E_c = | α·(P_s / √3) + β·(P_s / √3)³ |
= | -β·P_s²·(P_s / √3) + (1/3)·β·P_s³ / √3 |
= (2/3)·β·P_s³ / √3
= (2 / (3·√3)) · |α| · √[ |α| / β ]
```

Це значення називається термодинамічним коерцитивним полем. У реальних кристалах експериментально виміряне коерцитивне поле є на два-три порядки меншим за `E_c`. Ця розбіжність пояснюється тим, що real переполяризація відбувається не шляхом однорідного повороту всіх диполів кристала одночасно, а за рахунок гетерогенного зародження мікроскопічних доменів протилежної полярності на дефектах та їхнього швидкого розростання.

## 4. Фазовий перехід першого роду (β < 0, γ > 0)

Якщо коефіцієнт `β` від'ємний, член четвертого ступеня створює додатковий мінімум вільної енергії, і для стабільності системи необхідний додатний член шостого ступеня `γ > 0`. Рівняння стану при `E = 0` має вигляд:

```
dF/dP = α·P - |β|·P³ + γ·P⁵ = 0
= P·(α - |β|·P² + γ·P⁴) = 0
```

При критичній температурі фазового переходу `T_c > T_0` вільні енергії параелектричної фази (`P = 0`) та сегнетоелектричної фази (`P = P_s ≠ 0`) стають рівними: `F(0) = F(P_s)`:

```
F(P_s) - F(0) = (1/2)·α_c·P_s² - (1/4)·|β|·P_s⁴ + (1/6)·γ·P_s⁶ = 0
```

Сумісне розв'язання рівнянь рівноваги та рівності енергій дає кінцевий стрибок спонтанної поляризації `ΔP_s` у точці переходу:

```
P_s²(T_c) = 3·|β| / (4·γ)  [стрибок поляризації при T = T_c]
T_c = T_0 + 3·β² / (16·α_0·γ)
```

При фазовому переході першого роду спонтанна поляризація з'являється не нулем, а стрибком від `0` до `P_s(T_c)`. Це супроводжується виділенням або поглинанням прихованої теплоти переходу `q = T_c · ΔS` та температурним гістерезисом: температура переходу при нагріванні вища за температуру переходу при охолодженні. Типовим прикладом сегнетоелектрика з фазовим переходом першого роду є титанат барію (`BaTiO3`).

## 5. Теорія Ландау-Гінзбурга для просторово-неоднорідних доменних стінок

У реальних сегнетоелектричних кристалах поляризація змінюється у просторі `P = P(x)` при переході через доменну стінку. Для опису просторово-неоднорідних систем Віталій Гінзбург додав до термодинамічного потенціалу градієнтний член, пропорційний квадрату просторової похідної `(dP/dx)²`:

```
F_total = ∫ [ F_0 + (1/2)·α·P² + (1/4)·β·P⁴ + (1/2)·δ·(dP/dx)² ] dx
```
[де δ — градієнтний коефіцієнт (δ > 0), який враховує енергетичну ціну нерівномірності поляризації]

Вар'ювання функціоналу вільної енергії за поляризацією `δF_total / δP = 0` приводить до диференціального рівняння Ейлера-Лагранжа для профілю доменної стінки:

```
α·P + β·P³ - δ · (d²P / dx²) = 0
```

Для 180-градусної доменної стінки з межевими умовами `P(x → -∞) = -P_s` та `P(x → +∞) = +P_s` це рівняння має точний аналітичний розв'язок:

```
P(x) = P_s · tanh(x / d_w)
```
[де P_s = √(-α / β) — спонтанна поляризація всередині домену, d_w — ефективна товщина доменної стінки]

Характерний розмір (товщина) сегнетоелектричної доменної стінки `d_w` визначається співвідношенням градієнтного коефіцієнта `δ` та коефіцієнта `α`:

```
d_w = √[ 2·δ / (-α) ]
= √[ 2·δ / (α_0·(T_0 - T)) ]
```

Поверхнева енергія 180-градусної доменної стінки `σ_dw` (енергія на одиницю площі межі доменів) розраховується шляхом інтегрування надлишкової вільної енергії вздовж осі `x`:

```
σ_dw = ∫ [ (1/2)·α·(P² - P_s²) + (1/4)·β·(P⁴ - P_s⁴) + (1/2)·δ·(dP/dx)² ] dx
= (4/3) · P_s³ · √(β · δ / 2)
= (4/3) · [ α_0·(T_0 - T) / β ]^(3/2) · √(β · δ / 2)
```

Цей результат пояснює, чому при наближенні до температури Кюрі `T → T_0` як товщина стінки `d_w`, так і її поверхнева енергія `σ_dw` прямують до нуля: кристалічна гратка втрачає анізотропію, і межа між доменами розмивається.

## 6. Врахування пружно-стрикційної взаємодії

У реальних кристалах фазовий перехід супроводжується механічною деформацією (ефектом спонтанної електрострикції). Повний термодинамічний потенціал із урахуванням деформації тензора `u_ij` та пружних модулів `c_ijkl` має вигляд:

```
F(P, u) = F_P(P) + Q_ijkl · u_ij · P_k · P_l + (1/2) · c_ijkl · u_ij · u_kl
```
[де Q_ijkl — тензор електрострикційних коефіцієнтів, c_ijkl — тензор модулів пружності]

Мінімізація потенціалу за тензором деформації `dF/du_ij = 0` дозволяє виразити спонтанну деформацію через квадрат поляризації:

```
u_ij^sp spontaneous = - q_ijkl · P_k · P_l
```
[де q_ijkl — ефективні стрикційні коефіцієнти]

Виключення пружних ступенів вільності з термодинамічного потенціалу приводить до перевизначення коефіцієнта `β` при четвертому ступені поляризації:

```
β_eff = β - 2 · q² / c
```

Це явище називається релаксацією пружних напружень. Якщо у вільному кристалі коефіцієнт `β` був додатним (`β > 0`), то у затиснутому кристалі або за наявності сильного пружного зв'язку ефекти стрикції можуть зробити `β_eff < 0`. У результаті пружна взаємодія здатна змінювати рід фазового переходу з другого на перший, що спостерігається у багаторазово затиснутих тонких плівках сегнетоелектриків на жорстких підкладках.
