# 🧮 Математичний вивід фазової швидкості та ефективної проникності

У цій вставці наведено строгий математичний вивід фазової та групової швидкостей електромагнітної хвилі з векторних рівнянь Максвелла, доведення незалежності швидкості в коаксіалі від його радіусів, розрахунок ефективної діелектричної проникності відкритих мікросмужкових ліній за методом Вілера-Шнайдера та числовий приклад розрахунку міжканального розсинхронізму.

## 1. Хвильове рівняння у діелектрику та фазова швидкість

Поширення електромагнітного поля у лінійному однорідному немагнітному діелектрику описується системою векторних рівнянь Максвелла без вільних зарядів та струмів провідності:

```
∇ × E = −∂B / ∂t
∇ × H = ∂D / ∂t
∇ · D = 0
∇ · B = 0
```

Матеріальні співвідношення для діелектрика з відносною проникністю `ε[r]` та магнітною проникністю `μ[r] = 1.0` мають вигляд:

```
D = ε₀ · ε[r] · E
B = μ₀ · H
```

Застосуємо оператор ротора `∇ ×` до обох частин першого рівняння Максвелла:

```
∇ × (∇ × E) = ∇ × (−∂B / ∂t) = −∂/∂t (∇ × B) = −μ₀ · ∂/∂t (∇ × H)
```

Підставляючи вираз для `∇ × H = ∂D / ∂t = ε₀·ε[r] · ∂E / ∂t`, отримуємо:

```
∇ × (∇ × E) = −μ₀·ε₀·ε[r] · ∂²E / ∂t²
```

Використовуючи векторну тотожність `∇ × (∇ × E) = ∇(∇ · E) − ∇²E` і враховуючи, що в однорідному діелектрику без вільних зарядів `∇ · E = 0`, отримуємо тривимірне однорідне **хвильове рівняння**:

```
∇²E − μ₀·ε₀·ε[r] · ∂²E / ∂t² = 0
```

Канонічна форма тривимірного хвильового рівняння для скалярного компонента поля `ψ` має вигляд:

```
∇²ψ − (1 / v²) · ∂²ψ / ∂t² = 0
```

Зіставляючи коефіцієнти при другій похідній за часом, отримуємо формулу фазової швидкості хвилі `v`:

```
1 / v² = μ₀·ε₀·ε[r]
v = 1 / √(μ₀·ε₀ · ε[r]) = (1 / √(μ₀·ε₀)) · (1 / √(ε[r])) = c / √(ε[r])
```

Звідси коефіцієнт укорочення хвилі дорівнює:

```
VF = v / c = 1 / √(ε[r])
```

## 2. Фазова та групова швидкості у середовищі з дисперсією

Якщо діелектрична проникність середовища залежить від частоти `ε[r](ω)`, фазова швидкість монохроматичного компонента обчислюється як:

```
v[p] = ω / k = c / √(ε[r](ω))
```

де `k = (ω / c) · √(ε[r](ω))` — хвильове число у діелектрику.

Знайдемо повну похідну хвильового числа за частотою за правилом диференціювання добутку:

```
dk / dω = d/dω [ (ω / c) · √(ε[r](ω)) ]                            [визначення хвильового числа k]
        = (1 / c) · √(ε[r](ω)) + (ω / c) · (1 / (2·√(ε[r](ω)))) · (dε[r] / dω) [похідна добутку]
        = (1 / v[p]) · [ 1 + (ω / (2 · ε[r])) · (dε[r] / dω) ]     [винесення 1/v[p] за дужки]
```

Підставляючи одержану похідну у визначення групової швидкості `v[g] = dω / dk`, маємо точний зв'язок між фазовою та груповою швидкістю в діелектрику:

```
v[g] = v[p] / [ 1 + (ω / (2 · ε[r])) · (dε[r] / dω) ]
```

Аналіз цього співвідношення показує:
1. Якщо діелектрична проникність не залежить від частоти `(dε[r]/dω = 0)`, дисперсія відсутня, і групова швидкість точно дорівнює фазовій `(v[g] = v[p])`.
2. При нормальній дисперсії `(dε[r]/dω > 0)` діелектрична проникність зростає з частотою, тому знаменник більший за одиницю, і групова швидкість виявляється меншою за фазову `(v[g] < v[p])`.
3. Оскільки переносом енергії та передачею сигналів у рефлектометрії TDR керує саме обвідна імпульсу, для точного вимірювання відстаней слід використовувати груповий коефіцієнт укорочення `VF[g] = v[g] / c`.

## 3. Телеграфні рівняння та аналіз погонних параметрів

Поширення хвилі вздовж будь-якої двопровідної або коаксіальної лінії описується телеграфними рівняннями Гевісайда у часовій та частотній областях. Лінія характеризується чотирма первинними погонними параметрами: погонним опором `R'` (Ом/м), погонною індуктивністю `L'` (Гн/м), погонною провідністю ізоляції `G'` (См/м) та погонною ємністю `C'` (Ф/м).

Комплексна константа поширення `γ` визначається через первинні параметри:

```
γ = α + i·β = √((R' + i·ω·L') · (G' + i·ω·C'))
```

де `α` — коефіцієнт згасання (Нп/м), а `β` — коефіцієнт фази (рад/м). У режимі малих втрат на високих частотах, коли `ω·L' ≫ R'` та `ω·C' ≫ G'`, коефіцієнт фази спрощується до виразу:

```
β ≈ ω · √(L' · C')
```

Фазова швидкість поширення хвилі в лінії зв'язку прямо пов'язана з коефіцієнтом фази:

```
v = ω / β = 1 / √(L' · C')
```

Цей висновок доводить: фазова швидкість хвилі у будь-якому хвилеводі або кабелі повністю задається добутком його погонної індуктивності та погонної ємності.

## 4. Строгий розрахунок коаксіальної лінії

У коаксіальному кабелі з внутрішнім радіусом провідника `a` та внутрішнім радіусом зовнішнього екрана `b`, простір між якими суцільно заповнений діелектриком `ε[r]`, поширюється чиста поперечна електромагнітна хвиля (TEM-мода).

Розв'яжемо двовимірне рівняння Лапласа `∇²Φ = 0` для електростатичного потенціалу в циліндричних координатах `(r, φ)` при симетрії за кутом `φ`:

```
(1 / r) · d/dr (r · dΦ / dr) = 0
```

Інтегруючи це рівняння, отримуємо розподіл потенціалу та електричного поля `E(r)` між провідниками:

```
E(r) = −dΦ / dr = U / (r · ln(b / a))
```

де `U` — напруга між центральною жилою та екраном.

Погонна ємність коаксіального кабелю `C'` визначається як відношення заряду `Q'` на одиницю довжини до напруги `U`:

```
C' = Q' / U = (2·π · ε₀·ε[r]) / ln(b / a)
```

Застосовуючи теорему про циркуляцію магнітного поля (закон Ампера), знайдемо розподіл магнітного поля `H(r)` при струмі `I`:

```
H(r) = I / (2·π · r)
```

Погонна індуктивність `L'` визначається як відношення магнітного потоку `Φ'` на одиницю довжини до струму `I`:

```
L' = (μ₀·μ[r] / (2·π)) · ln(b / a)
```

Обчислимо добуток погонних параметрів `L' · C'`:

```
L' · C' = [ (μ₀·μ[r] / (2·π)) · ln(b / a) ] · [ (2·π · ε₀·ε[r]) / ln(b / a) ] [добуток індуктивності та ємності]
        = ε₀·ε[r] · μ₀·μ[r]                                             [скорочення логарифма та 2π]
```

Оскільки логарифмічний фактор геометрії `ln(b / a)` у добутку повністю скорочується, підстановка у формулу швидкості `v = 1 / √(L'·C')` дає:

```
v = 1 / √(ε₀·ε[r] · μ₀·μ[r]) = c / √(ε[r] · μ[r])
```

Математично доведено: швидкість хвилі у суцільному коаксіальному кабелі залежить виключно від діелектричних властивостей ізолятора і взагалі не залежить від товщини жил або зовнішнього діаметра кабелю. Геометричне співвідношення `b / a` впливає лише на хвильовий опір `Z₀ = √(L'/C')`.

## 5. Розрахунок ефективної проникності відкритих і закритих смужкових ліній

У мікросмужковій лінії (Microstrip), яка складається з провідної смужки шириною `w` на діелектричній підкладці товщиною `h`, поле розподілене між діелектриком підкладки `ε[r]` та повітрям `ε[air] = 1` над платою. Хвиля є квазі-поперечною (квазі-TEM).

Для врахування неоднорідності середовища вводиться **ефективна діелектрична проникність** `ε[eff]`, яка відповідає проникності еквівалентного суцільного діелектрика, що забезпечує таку саму фазову швидкість.

За класичною аналітичною апроксимацією Гарольда Вілера та Еванса Шнайдера, для ліній із `w / h ≥ 1`:

```
ε[eff] = ((ε[r] + 1) / 2) + ((ε[r] − 1) / 2) · (1 / √(1 + 12·(h / w)))
```

Проаналізуємо граничні фізичні випадки даної формули:
1. При `w / h → ∞` (дуже широка смужка) крайові поля в повітрі стають знехтовно малими, доданок `1 / √(1 + 12·h/w) → 1`, звідки `ε[eff] → ε[r]`. Сигнал рухається так само повільно, як у суцільному діелектрику.
2. При `w / h → 0` (нескінченно тонка нитка) половина силових ліній замикається через повітря, а половина через підкладку, тому `ε[eff] → (ε[r] + 1) / 2`.

Для повністю закритої **смужкової лінії (Stripline)**, де провідник розміщений між двома заземленими площинами й повністю оточений діелектриком `ε[r]`, повітряні крайові поля відсутні:

```
ε[eff] = ε[r]
v = c / √(ε[r])
```

Саме тому в багатошарових друкованих платах сигнал у внутрішніх шарах (Stripline) поширюється повільніше (`VF ≈ 0.48` для FR-4), ніж у зовнішніх мікросмужкових шарах Microstrip (`VF ≈ 0.55...0.60`).

## 6. Числовий приклад розрахунку мікросмужкової лінії та часового зсуву

**Практична задача:** На друкованій платі з матеріалу FR-4 (`ε[r] = 4.4`) необхідно розрахувати затримку поширення сигналу `t[pd]` та коефіцієнт укорочення `VF` для двох типів трас:
- Зовнішня мікросмужкова лінія (Microstrip) з параметрами `h = 0.2 мм`, `w = 0.4 мм`.
- Внутрішня смужкова лінія (Stripline) у товщі діелектрика.
Також визначити міжпровідниковий часовий зсув (skew) при довжині трас `L = 15 см`.

**Розв'язання:**

**Частина А. Розрахунок зовнішньої мікросмужкової лінії (Microstrip):**

**Крок 1.** Обчислюємо геометрію траси:

```
w / h = 0.4 / 0.2 = 2.0     [оскільки w/h ≥ 1, формулу Шнайдера застосовно]
```

**Крок 2.** Обчислюємо поправку на крайові поля:

```
F(w/h) = 1 / √(1 + 12 · (h / w))       [формула геометрії Шнайдера]
       = 1 / √(1 + 12 · (1 / 2.0))     [підстановка співвідношення w/h = 2.0]
       = 1 / √(1 + 6)                  [обчислення 12 ÷ 2.0]
       = 1 / √7                        [додавання 1 + 6]
       = 1 / 2.64575                   [добування квадратного кореня з 7]
       = 0.37796                       [ділення 1 на 2.64575]
```

**Крок 3.** Знаходимо ефективну діелектричну проникність `ε[eff]`:

```
ε[eff] = ((4.4 + 1) / 2) + ((4.4 − 1) / 2) · 0.37796  [підстановка ε[r] = 4.4 та F(w/h)]
       = 2.70 + 1.70 · 0.37796                        [обчислення базових доданків]
       = 2.70 + 0.64253                               [множення 1.70 на 0.37796]
       = 3.3425                                       [підсумкова ефективна проникність]
```

**Крок 4.** Знаходимо коефіцієнт укорочення `VF` та швидкість `v`:

```
VF[microstrip] = 1 / √(ε[eff]) = 1 / √3.3425 = 1 / 1.8282 = 0.5470 [коефіцієнт укорочення]

v[microstrip] = c · VF = 2.9979·10⁸ м/с · 0.5470 = 1.6398·10⁸ м/с = 16.40 см/нс [фазова швидкість]
```

**Крок 5.** Знаходимо погонну затримку `t[pd]` та повний час проходження `T[microstrip]`:

```
t[pd, microstrip] = 1 / v[microstrip] = 1 / 0.16398 м/нс = 6.098 нс/м [погонна затримка]

T[microstrip] = L · t[pd] = 0.15 м · 6.098 нс/м = 0.9147 нс = 914.7 пс [час проходження 15 см]
```

**Частина Б. Розрахунок внутрішньої смужкової лінії (Stripline):**

**Крок 1.** Для закресленої лінії `ε[eff] = ε[r] = 4.4`:

```
VF[stripline] = 1 / √(ε[r]) = 1 / √4.4 = 1 / 2.0976 = 0.4767 [коефіцієнт укорочення]

v[stripline] = c · VF = 2.9979·10⁸ м/с · 0.4767 = 1.4291·10⁸ м/с = 14.29 см/нс [фазова швидкість]
```

**Крок 2.** Знаходимо погонну затримку та повний час проходження `T[stripline]`:

```
t[pd, stripline] = 1 / v[stripline] = 1 / 0.14291 м/нс = 6.997 нс/м [погонна затримка]

T[stripline] = L · t[pd] = 0.15 м · 6.997 нс/м = 1.0495 нс = 1049.5 пс [час проходження 15 см]
```

**Частина В. Розрахунок міжканального розсинхронізму (skew):**

```
ΔT[skew] = T[stripline] − T[microstrip] [різниця затримок трас]
         = 1049.5 пс − 914.7 пс          [підстановка значень часу]
         = 134.8 пс                      [підсумковий часовий розсинхронізм]
```

Висновок: якщо один із паралельних сигналів шини даних (наприклад, шини пам'яті DDR4/DDR5) розрахований на зовнішньому шарі Microstrip, а інший — на внутрішньому Stripline при однаковій фізичній довжині `15 см`, сигнал на внутрішньому шарі запізниться на `134.8 пікосекунди`. На частотах шини `3.2 ГГц` це перевищує тривалість цілого бітового інтервалу, що вимагає штучного подовження зовнішньої траси за допомогою меандрових вигинів.
