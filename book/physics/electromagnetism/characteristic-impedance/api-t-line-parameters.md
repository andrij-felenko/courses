# 📋 Специфікація параметрів ліній передачі

Ця довідкова вставка містить інженерні таблиці параметрів стандартних коаксіальних кабелів, геометрії друкованих доріжок, специфікації високошвидкісних цифрових шин даних, класифікацію радіочастотних роз'ємів, а також розрахункові співвідношення для вибору конструктивних параметрів ліній передачі.

## Геометричні розрахункові співвідношення ліній передачі

У таблиці наведено аналітичні формули для розрахунку характеристичного імпедансу `Z_0`, погонної індуктивності `L_0`, погонної ємності `C_0` та ефективної діелектричної проникності `ε_eff` для основних конструктивних типів ліній передачі.

| Тип лінії передачі | Поперечна геометрія | Формула характеристичного імпедансу `Z_0` (Ом) | Ефективна проникність `ε_eff` |
| :--- | :--- | :--- | :--- |
| **Коаксіальний кабель** | Центральна жила `d`, внутрішній екран `D` | `Z_0 = (60 / √(ε_r)) · ln(D / d)` | `ε_eff = ε_r` (однорідний діелектрик) |
| **Симетрична двопровідна пара** | Два провідника `d`, відстань між центрами `D` | `Z_0 = (120 / √(ε_r)) · cosh⁻¹(D / d)` | `ε_eff = ε_r` |
| **Мікросмужка поверхнева (Microstrip)** | Ширина `W`, товщина `t`, висота діелектрика `h` | `Z_0 = (87 / √(ε_r + 1.41)) · ln((5.98 · h) / (0.8 · W + t))` | `ε_eff ≈ (ε_r + 1)/2 + ((ε_r - 1)/2) / √(1 + 12h/W)` |
| **Мікросмужка занурена (Embedded Microstrip)** | Доріжка під шаром паяльної маски товщиною `d_m` | `Z_0 = (87 / √(ε_r + 1.41)) · ln((5.98 · h) / (0.8 · W + t)) · (1 / √(1 + (d_m / h)))` | Вплив маски зменшує `Z_0` на 2...4 Ом |
| **Симетрична смужка (Stripline)** | Доріжка між двома шарами землі на відстані `H` | `Z_0 = (60 / √(ε_r)) · ln((4 · H) / (0.67 · π · (0.8 · W + t)))` | `ε_eff = ε_r` (суцільний діелектрик) |
| **Копланарний хвилевід (CPW)** | Доріжка `W` із зазорами `s` до бічних земель | `Z_0 = (30 · π / √(ε_eff)) · (K(k') / K(k))`, де `k = W / (W + 2s)` | `ε_eff = (ε_r + 1) / 2` |
| **Диференціальна мікросмужка** | Дві доріжки `W`, відстань між ними `S` | `Z_diff ≈ 2 · Z_0 · (1 - 0.48 · e^(-0.96 · S / h))` | Залежить від непарної моди `Z_odd` |

Для мікросмужкових ліній значення ефективної діелектричної проникності `ε_eff` завжди менше за статичну діелектричну проникність ізолятора плати `ε_r`. Це пояснюється тим, що силові лінії електричного поля розподіляються між склотекстолітом під доріжкою та повітрям над нею. Внаслідок цього фазова швидкість електромагнітної хвилі в поверхневій мікросмужці вища, ніж у симетричній внутрішній смужці (Stripline), де весь простір довкола провідника заповнений однорідним діелектриком.

Параметр «фактор швидкості» (Velocity Factor, `v/c`) показує відношення швидкості поширення хвилі у кабелі до швидкості світла у вакуумі. Для кабелів із суцільним поліетиленовим діелектриком (PE, `ε_r = 2.25`) фактор швидкості становить `1 / √2.25 ≈ 0.66`, що відповідає затримці близько 5.0 пікосекунд на один міліметр довжини. Застосування спіненого поліетилену, насиченого бульбашками азоту (`ε_r ≈ 1.4`), дозволяє підняти фактор швидкості до `0.83...0.87` та суттєво зменшити згасання сигналу.

## Параметри парних мод у диференціальних лініях

При аналізі зв'язаних провідників (наприклад, диференціальної пари мікросмужок) сигнальне збудження розкладається на дві фундаментальні моди:

1. **Непарна мода (Odd Mode)**: провідники порушуються у протифазі (`V_1 = -V_2`).
   - Погонна ємність зростає за рахунок взаємної ємності: `C_odd = C_0 + 2 · C_12`.
   - Непарний імпеданс: `Z_odd = √(L_odd / C_odd) < Z_0`.
   - Диференціальний імпеданс: `Z_diff = 2 · Z_odd`.

2. **Парна мода (Even Mode)**: провідники порушуються синфазно (`V_1 = V_2`).
   - Погонна ємність зменшується: `C_even = C_0`.
   - Парний імпеданс: `Z_even = √(L_even / C_even) > Z_0`.
   - Синфазний імпеданс (Common Mode): `Z_comm = Z_even / 2`.

Співвідношення між диференціальним та синфазним імпедансами визначає коефіцієнт послаблення синфазних завад (CMRR — Common Mode Rejection Ratio).

## Технологічні норми та матеріали друкованих плат

При розробці друкованих плат із контрольованим імпедансом необхідно враховувати фізичні властивості діелектричних субстратів та товщину мідного покриття.

### 1. Характеристики поширених діелектричних матеріалів

- **FR-4 Standard (E-glass)**: відносна діелектрична проникність `ε_r = 4.2 ... 4.6` на частоті 1 ГГц; тангенс кута втрат `tan(δ) ≈ 0.020`. Використовується в загальній електроніці до частот 1.5–2 ГГц.
- **FR-4 High-Tg / Low-Dk**: `ε_r = 3.8 ... 4.0`; `tan(δ) ≈ 0.009`. Підходить для шин DDR4/PCIe Gen3.
- **Rogers RO4003C / RO4350B**: керамонаповнений вуглеводневий ламінат; `ε_r = 3.38 ± 0.05` на частоті 10 ГГц; `tan(δ) = 0.0027`. Застосовується в СВЧ-техніці та радарах 24–77 ГГц.
- **Panasonic Megtron 6**: наднизьковтратний діелектрик; `ε_r = 3.7`; `tan(δ) = 0.002`. Стандарт для обладнання 100GbE / 400GbE та PCIe Gen5/Gen6.

### 2. Товщина мідного фольгування та вага міді

- **1/2 oz (0.5 унції)**: номінальна товщина міді `t = 17.5 мкм` (після гальванічного міднення доріжок у наскрізних отворах фактична товщина становить `~ 30–35 мкм`). Рекомендовано для високочастотних внутрішніх шарів з вузькими доріжками.
- **1 oz (1 унція)**: номінальна товщина міді `t = 35 мкм` (фактична `~ 45–50 мкм`). Стандарт для зовнішніх шарів плати.
- **2 oz (2 унції)**: номінальна товщина `t = 70 мкм`. Використовується у силових шарах живлення; не рекомендовано для високошвидкісних доріжок із контрольованим імпедансом через підтрачування бічних стінок.

### 3. Правила контролю імпедансу при розведенні (PCB Layout Rules)

1. **Суцільність заземлювального шару (Ground Reference)**: сигнальна доріжка з контрольованим імпедансом повинна мати суцільний безперервний шар заземлення безпосередньо під собою на всій довжині. Розрізи, щілини чи отвори у земляному шарі під доріжкою різко збільшують погонну індуктивність `L_0`, викликаючи сплеск імпедансу до 80–100 Ом та сильне випромінювання завад.
2. **Вплив паяльної маски (Solder Mask Impact)**: нанесення захисної паяльної маски товщиною 15–25 мкм із `ε_r ≈ 3.5` поверх поверхневих мікросмужок збільшує паразитну ємність і зменшує характеристичний імпеданс `Z_0` на 2.0...3.5 Ом. Обов'язково додавайте маску у розрахунки в САПР (Altium Designer, KiCad, Allegro).
3. **Правило 3W для зменшення перехресних наводок (Crosstalk)**: відстань між центрами двох паралельних незв'язаних сигнальних доріжок з характеристичним імпедансом `Z_0` повинна бути не меншою за потрійну ширину доріжки (`S ≥ 3 · W`). Це зменшує взаємну ємність та індуктивність між доріжками, знижуючи рівень наводки менше ніж -26 дБ (5%).
