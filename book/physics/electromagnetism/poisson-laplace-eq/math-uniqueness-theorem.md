# 🧮 Доведення єдиності розв'язку та властивості гармонічних функцій

Математична строгість теорії потенціалу спирається на інтегральні співвідношення векторного аналізу, введені Джорджем Гріном. У цьому матеріалі наведено повне доведення теореми єдиності розв'язку рівняння Пуассона для умов Діріхле, Неймана та Робена, виведено теорему про середнє значення для гармонічних функцій, доведено принцип максимуму, розглянуто метод відокремлення змінних, мультипольний розклад, теорію функцій Гріна та Неймана, умови на межі розділу середовищ, метод конформних відображень та варіаційний принцип Діріхле, а також виведено вирази оператора Лапласа у циліндричній та сферичній системах координат.

## Перша та друга формули (тотожності) Гріна

Нехай `V` — обмежена область простору з достатньо гладкою замкненою межею `S`, а `n` — зовнішня одинична нормаль до поверхні `S`. Розглянемо дві скалярні функції `U(x, y, z)` та `W(x, y, z)`, які мають неперервні перші та другі частинні похідні в замкненій області `V + S`.

Застосуємо операцію дивергенції до векторного поля `U · ∇W`:

```
∇ · (U · ∇W) = ∇U · ∇W + U · (∇ · ∇W)
             = ∇U · ∇W + U · ∇²W       [правило диференціювання добутку]
```

Інтегруємо отриманий вираз по всьому об'єму `V` та застосовуємо теорему Гаусса-Остроградського (`∫_V (∇ · A) dV = ∮_S (A · n) dS`):

```
∫_V ∇ · (U · ∇W) dV = ∮_S (U · ∇W) · n dS
                    = ∮_S U · (∂W / ∂n) dS    [оскільки ∇W · n = ∂W / ∂n]
```

Об'єднуючи два вирази, отримуємо **першу формулу Гріна**:

```
∫_V (∇U · ∇W + U · ∇²W) dV = ∮_S U · (∂W / ∂n) dS
```

Записавши аналогічний вираз, де функції `U` та `W` поміняні місцями, та віднявши його від першої формули Гріна, отримуємо **другу формулу Гріна**:

```
∫_V (U · ∇²W − W · ∇²U) dV = ∮_S (U · (∂W / ∂n) − W · (∂U / ∂n)) dS
```

Ці дві формули є фундаментальним інструментом для вивчення властивостей диференціальних рівнянь електростатики.

## Доведення теореми єдиності розв'язку

Розглянемо крайову задачу для рівняння Пуассона у замкненій області `V` із заданою об'ємною густиною заряду `ρ(x, y, z)`:

```
∇²φ = −ρ / ε₀      всередині області V
```

### 1. Крайова умова Діріхле (перша крайова задача)

Нехай на межі `S` задано значення потенціалу: `φ|S = g(s)`.

Припустимо від зворотного, що існують два різних розв'язки цієї задачи: `φ₁(x, y, z)` та `φ₂(x, y, z)`. Обидва розв'язки задовольняють рівнянню Пуассона всередині `V` та крайовій умові на `S`:

```
∇²φ₁ = −ρ / ε₀,   φ₁|S = g(s)
∇²φ₂ = −ρ / ε₀,   φ₂|S = g(s)
```

Введемо функцію різниці двох розв'язків: `ψ(x, y, z) = φ₁(x, y, z) − φ₂(x, y, z)`.

За лінійністю оператора Лапласа функція `ψ` задовольняє:
1. Рівнянню Лапласа усередині `V`: `∇²ψ = ∇²φ₁ − ∇²φ₂ = (−ρ/ε₀) − (−ρ/ε₀) = 0`.
2. Однорідній крайовій умові на межі `S`: `ψ|S = g(s) − g(s) = 0`.

Застосуємо **першу формулу Гріна**, поклавши `U = ψ` та `W = ψ`:

```
∫_V (∇ψ · ∇ψ + ψ · ∇²ψ) dV = ∮_S ψ · (∂ψ / ∂n) dS
```

Підставимо у цю тотожність відомі значення `∇²ψ = 0` усередині `V` та `ψ = 0` на межі `S`:

```
∫_V |∇ψ|² dV + 0 = 0    [оскільки ∮_S 0 · (∂ψ / ∂n) dS = 0]
```

Отже:

```
∫_V |∇ψ|² dV = 0
```

Підінтегральний вираз `|∇ψ|² = (∂ψ/∂x)² + (∂ψ/∂y)² + (∂ψ/∂z)²` є невід'ємною неперервною функцією усередині `V`. Інтеграл від невід'ємної функції по об'єму дорівнює нулю тоді й лише тоді, коли підінтегральний вираз тотожно дорівнює нулю у кожній точці області:

```
|∇ψ|² = 0   =>   ∇ψ = 0   всередині V
```

Рівність нулю градієнта `∇ψ = 0` означає, що функція `ψ` є константою у всій області `V`: `ψ(x, y, z) = C`.

Оскільки на межі `S` функція дорівнює нулю (`ψ|S = 0`), ця константа дорівнює нулю: `C = 0`. Звідси випливає:

```
ψ(x, y, z) = 0   =>   φ₁(x, y, z) = φ₂(x, y, z)   в усій області V
```

Теорему доведено: **розв'язок рівняння Пуассона з крайовими умовами Діріхле є єдиним**.

### 2. Крайова умова Неймана (друга крайова задача)

Нехай на межі `S` задано нормальну похідну потенціалу (напруженість електричного поля): `(∂φ / ∂n)|S = h(s)`.

Аналогічно припускаємо існування двох розв'язків `φ₁` та `φ₂`, і формуємо різницю `ψ = φ₁ − φ₂`. На межі `S` маємо: `(∂ψ / ∂n)|S = h(s) − h(s) = 0`.

Застосовуючи першу формулу Гріна для `ψ`, отримуємо:

```
∫_V |∇ψ|² dV = ∮_S ψ · (∂ψ / ∂n) dS = ∮_S ψ · 0 dS = 0
```

Звідси знову випливає `∇ψ = 0`, що дає `ψ(x, y, z) = C` (константа). 

Отже:

```
φ₁(x, y, z) = φ₂(x, y, z) + C
```

Теорему доведено: **розв'язок рівняння Пуассона з крайовими умовами Неймана є єдиним з точністю до довільної адитивної константи `C`**. Фізично це означає, що фіксування напруженості поля визначає розподіл потенціалу з точністю до вибору відлікового рівня («землі»).

### 3. Крайова умова Робена (третя крайова задача)

Нехай на межі `S` задано лінійну комбінацію потенціалу та його нормальної похідної: `[a · φ + b · (∂φ / ∂n)]|S = k(s)`, де коефіцієнти `a > 0` та `b > 0` мають однаковий знак на всій поверхні `S`.

Формуючи різницю двох припущених розв'язків `ψ = φ₁ − φ₂`, на межі `S` отримуємо:

```
a · ψ + b · (∂ψ / ∂n) = 0   =>   ∂ψ / ∂n = −(a / b) · ψ
```

Застосовуємо першу формулу Гріна для `ψ`:

```
∫_V |∇ψ|² dV = ∮_S ψ · (∂ψ / ∂n) dS         [перша формула Гріна для ∇²ψ = 0]
             = ∮_S ψ · (−(a / b) · ψ) dS    [підстановка умови Робена ∂ψ/∂n = −(a/b) ψ]
             = − ∮_S (a / b) · ψ² dS        [спрощення підінтегрального добутку]
```

Переносимо контурний інтеграл у ліву частину рівності:

```
∫_V |∇ψ|² dV + ∮_S (a / b) · ψ² dS = 0
```

Оскільки обидва доданки є інтегралами від невід'ємних функцій (`|∇ψ|² ≥ 0` та `(a/b) ψ² ≥ 0`), сума може дорівнювати нулю лише за умови, що обидва доданки дорівнюють нулю окремо. З рівності нулю об'ємного інтеграла випливає `∇ψ = 0` (тобто `ψ = C`), а з рівності нулю поверхневого інтеграла випливає `ψ|S = 0`. Поєднуючи це, маємо `C = 0`, що означає `ψ(x, y, z) = 0` в усій області.

Теорему доведено: **розв'язок рівняння Пуассона з крайовими умовами Робена є строго єдиним**.

## Теорема про середнє значення для гармонічних функцій

Нехай `φ` — гармонічна функція у відкритій області `V` (`∇²φ = 0`). Візьмемо довільну точку `x₀ ∈ V` і опишемо навколо неї сферу `S_R` радіуса `R`, яка повністю лежить усередині `V`.

Застосуємо другу формулу Гріна в області між сферою `S_R` та малою сферою `S_ε` радіуса `ε → 0` навколо `x₀`. В якості другої функції візьмемо фундаментальний розв'язок рівняння Лапласа в тривимірному просторі: `W(r) = 1 / r`, де `r` — відстань від точки `x₀`.

Оскільки `∇²(1/r) = 0` всюди при `r ≠ 0`, друга формула Гріна на сфері `S_R` дає:

```
∮_{S_R} ( φ · ∂(1/r)/∂n − (1/r) · ∂φ/∂n ) dS = 0
```

Обчислимо нормальну похідну `∂(1/r)/∂n` на зовнішній сфері радіуса `R` (зовнішня нормаль напрямлена вздовж радіуса `r`):

```
∂(1/r) / ∂r = −1 / R²
```

Підставляємо цей вираз в інтеграл:

```
∮_{S_R} φ · (−1 / R²) dS − (1 / R) ∮_{S_R} (∂φ / ∂n) dS = 0
```

За теоремою Гаусса для гармонічної функції `φ` потік градієнта через замкнену сферу дорівнює нулю: `∮_{S_R} (∂φ / ∂n) dS = ∫_{V_R} ∇²φ dV = 0`. Другий доданок зникає, і залишається:

```
(1 / R²) ∮_{S_R} φ dS = 4π · φ(x₀)
```

Виражаємо потенціал у центрі `φ(x₀)`:

```
φ(x₀) = (1 / 4π R²) ∮_{S_R} φ dS
```

**Теорема про середнє значення:** Значення гармонічної функції в точці `x₀` дорівнює середньому арифметичному її значень на довільній сфері радіуса `R` з центром у точці `x₀`.

Для кулі `B_R` радіуса `R` інтегруванням по радіусу від `0` до `R` отримуємо об'ємну форму теореми про середнє значення:

```
φ(x₀) = (3 / 4π R³) ∫_{B_R} φ dV
```

## Принцип максимуму та мінімуму і теорема Ірншоу

З теореми про середнє значення безпосередньо випливає **принцип максимуму та мінімуму** для гармонічних функцій:

> Якщо функція `φ` є гармонічною і неелементарною (не константою) в обмеженій зв'язній області `V`, вона не може досягати свого строго локального максимуму або мінімуму у жодній внутрішній точці області `V`. Максимум і мінімум досягаються виключно на межі `S`.

**Доведення:** Припустимо, що у внутрішній точці `x₀ ∈ V` функція `φ` має локальний максимум, тобто для всіх точок у кулі `B_R(x₀)` виконується `φ(x) ≤ φ(x₀)`. Якщо хоча б в одній точці цієї кулі нерівність є строгою (`φ(x) < φ(x₀)`), то інтеграл середнього значення по кулі буде строго меншим за `φ(x₀)`:

```
(3 / 4π R³) ∫_{B_R} φ dV < φ(x₀)
```

Це суперечить теоремі про середнє значення, за якою інтеграл має дорівнювати точно `φ(x₀)`. Отже, `φ(x)` мусить бути константою в усій кулі. Поширюючи ці кулі на всю зв'язну область `V`, отримуємо, що `φ` є константою в усьому об'ємі. 

### Фізичний наслідок: Теорема Ірншоу (1842)

У 1842 році англійський математик Семюель Ірншоу (англ. *Samuel Earnshaw*) застосував принцип максимуму потенціалу до електростатики:

> Точкова система нерухомих електричних зарядів не може перебувати у стані стійкої рівноваги під дією лише електростатичних кулонівських сил.

**Доведення:** Для стійкої рівноваги точкового заряду `q > 0` потенціальна енергія `W = q · φ` повинна мати строгий мінімум у точці рівноваги `x₀`. Це вимагає, щоб потенціал `φ` мав строгий мінімум у точці `x₀`. Проте у вакуумі (`ρ = 0`) потенціал задовольняє рівнянню Лапласа `∇²φ = 0`, яке забороняє існування внутрішніх мінімумів чи максимумів. 

Оскільки поле не може створити потенціальну яму в порожньому просторі, будь-який відхил заряду створюватиме сили, які виштовхують його з точки рівноваги щонайменше в одному напрямку. Стійка левітація у статичному електричному або магнітному полі для діамагнетиків або провідників без зовнішніх сил чи динамічної зворотного зв'язку є неможливою.

## Умови на межі розділу двох діелектричних середовищ

Коли область `V` складається з двох різних діелектричних середовищ з відносними проникностями `ε₁` та `ε₂`, розділених поверхнею `S₁₂`, рівняння Пуассона доповнюється стикувальними межевими умовами для потенціалу та нормальної складової індукції:

1. **Неперервність потенціалу (відсутність нескінченних полів):** `φ₁(s) = φ₂(s)` на межі `S₁₂`.
2. **Скачок нормальної похідної за наявності поверхневого заряду `σ`:**

```
ε₁ · (∂φ₁ / ∂n) − ε₂ · (∂φ₂ / ∂n) = − σ / ε₀
```

Якщо вільний поверхневий заряд відсутній (`σ = 0`), нормальна складова вектора індукції `D_n = −ε ε₀ (∂φ/∂n)` залишається неперервною: `ε₁ (∂φ₁/∂n) = ε₂ (∂φ₂/∂n)`. 

Ці умови визначають заломлення силових ліній електричного поля на межах діелектриків відповідно до закону тангенсів: `tan(θ₁) / tan(θ₂) = ε₁ / ε₂`.

## Метод відокремлення змінних (метод Фур'є)

Для аналітичного розв'язання рівняння Лапласа в прямокутних областях застосовують метод відокремлення змінних. Розглянемо прямокутну 2D область `0 ≤ x ≤ L`, `0 ≤ y ≤ H` з межевими умовами:
- `φ(0, y) = 0`, `φ(L, y) = 0`, `φ(x, 0) = 0`
- `φ(x, H) = V₀ · sin(π x / L)`

Шукаємо розв'язок у вигляді добутку двох функцій однієї змінної: `φ(x, y) = X(x) · Y(y)`.

Підставляємо у 2D рівняння Лапласа `∂²φ/∂x² + ∂²φ/∂y² = 0`:

```
X''(x) · Y(y) + X(x) · Y''(y) = 0
```

Ділимо обидві частини на `X(x) · Y(y)`:

```
X''(x) / X(x) = − Y''(y) / Y(y) = − λ²
```

Оскільки ліва частина залежить лише від `x`, а права — лише від `y`, вони можуть бути рівними лише константі відокремлення `−λ²`. Отримуємо два звичайні диференціальні рівняння:

```
1. X''(x) + λ² · X(x) = 0
2. Y''(y) − λ² · Y(y) = 0
```

Загальний розв'язок для `X(x)`: `X(x) = A · sin(λ x) + B · cos(λ x)`. 
Підставивши крайові умови `X(0) = 0` та `X(L) = 0`, маємо `B = 0` та `λ_n = n π / L` для `n = 1, 2, 3...`.

Загальний розв'язок для `Y(y)` при `λ = λ_n`: `Y_n(y) = C_n · sinh(λ_n y) + D_n · cosh(λ_n y)`. 
З умови `Y(0) = 0` випливає `D_n = 0`.

Результуючий розв'язок у вигляді ряду:

```
φ(x, y) = ∑_{n=1}^{∞} C_n · sin(n π x / L) · sinh(n π y / L)
```

Для заданої умови при `y = H` маємо `C₁ · sinh(π H / L) = V₀` (інші `C_n = 0`), що дає точний розв'язок:

```
φ(x, y) = V₀ · sin(π x / L) · [ sinh(π y / L) / sinh(π H / L) ]
```

## Теорія функцій Гріна та Неймана для рівняння Пуассона

Функція Гріна `G(r, r')` для обмеженої області `V` — це потенціал, створений одиничним точковим зарядом у точці `r'`, за умови виконання однорідних крайових умов на межі `S`. За визначенням вона задовольняє рівнянню:

```
∇² G(r, r') = − δ(r − r')
```

де `δ(r − r')` — тривимірна дельта-функція Дірака. 

У двовимірному просторі 2D фундаментальний розв'язок для нескінченного середовища має логарифмічний вигляд:

```
G_{2D}(r, r') = − (1 / (2π)) · ln |r − r'|
```

У тривимірному просторі 3D фундаментальний розв'язок дорівнює:

```
G_{3D}(r, r') = 1 / (4π |r − r'|)
```

Для обмеженої області з межею `S` функцію Гріна шукають у вигляді суми фундаментального розв'язку та гармонічної поправки `F(r, r')`:

```
G(r, r') = (1 / (4π |r − r'|)) + F(r, r')
```

де `F` задовольняє рівнянню Лапласа `∇² F = 0` усередині `V` та компенсує значення `G_0` на межі `S` так, щоб `G(r, r')|S = 0` (для умов Діріхле).

За допомогою другої формули Гріна загальний розв'язок рівняння Пуассона `∇²φ = −ρ / ε₀` виражається в інтегральній формі через об'ємні джерела та контурний потенціал на межі:

```
φ(r) = (1 / ε₀) ∫_V ρ(r') · G(r, r') dV' − ∮_S g(r') · [ ∂G(r, r') / ∂n' ] dS'
```

Цей вираз показує, що знання однієї функції Гріна `G(r, r')` для даної геометрії дозволяє миттєво обчислити потенціал для довільного об'ємного заряду `ρ` та довільних граничних напруг `g(s)`.

Для задач Неймана функція Неймана `N(r, r')` задовольняє умові на межі `∂N / ∂n' = −1 / S_total` (для збереження потоку). Потенціал обчислюється через інтегрування нормального поля:

```
φ(r) = (1 / ε₀) ∫_V ρ(r') · N(r, r') dV' + ∮_S h(r') · N(r, r') dS' + C
```

де `h(r') = (∂φ / ∂n')|S` — задана напруженість на межі, а `C` — довільна константа рівня відліку.

## Метод конформних відображень у двох вимірах

У двовимірних електростатичних задачах (де потенціал залежить лише від `x` та `y`) рівняння Лапласа тісно пов'язане з теорією функцій комплексної змінної.

Нехай `z = x + i y` — комплексна координата на площині. Комплексний потенціал задається аналітичною функцією `W(z)`:

```
W(z) = φ(x, y) + i ψ(x, y)
```

де `φ(x, y)` — скалярний електростатичний потенціал, а `ψ(x, y)` — силова функція (лінії рівня `ψ = const` збігаються з силовими лініями векторного поля `E`).

З умов Коші-Рімана (`∂φ/∂x = ∂ψ/∂y` та `∂φ/∂y = −∂ψ/∂x`) випливає, що обидві функції `φ` та `ψ` є гармонічними:

```
∇²φ = ∂²φ / ∂x² + ∂²φ / ∂y² = 0
∇²ψ = ∂²ψ / ∂x² + ∂²ψ / ∂y² = 0
```

Будь-яка конформна (конформно-однакова) функція `w = f(z)` відображає одну складну область на простішу (наприклад, верхню півплощину або круг), зберігаючи гармонічність потенціалу. Це дозволяє розв'язувати рівняння Лапласа для складних форм проводів і зазорів шляхом аналітичного перетворення координат.

## Варіаційний принцип Діріхле

Рівняння Лапласа `∇²φ = 0` еквівалентне мінімізації функціонала повної електростатичної енергії поля. Розглянемо інтеграл енергії (інтеграл Діріхле):

```
J[φ] = ½ ε₀ ∫_V |∇φ|² dV
```

серед усіх неперервно диференційованих функцій `φ`, які на межі `S` приймають задане значення `φ|S = g(s)`.

За принципом варіаційного числення, надамо функціоналу варіацію `φ → φ + α · η`, де `η|S = 0` — довільна гладка функція, що зникає на межі. Обчислимо першу варіацію `δ J`:

```
δ J = ε₀ ∫_V ∇φ · ∇η dV = 0
```

Застосовуючи першу формулу Гріна до `∇φ · ∇η`:

```
∫_V ∇φ · ∇η dV = ∮_S η · (∂φ / ∂n) dS − ∫_V η · ∇²φ dV
```

Оскільки `η|S = 0`, поверхневий інтеграл зникає. Умова `δ J = 0` для довільної варіації `η` вимагає:

```
∫_V η · ∇²φ dV = 0   =>   ∇²φ = 0   всередині V
```

**Принцип Діріхле:** Функція `φ`, яка мінімізує повну електростатичну енергію поля, є єдиним розв'язком рівняння Лапласа з заданими крайовими умовами. Цей принцип утворює математичну основу для чисельного методу скінченних елементів (FEM).

## Мультипольний розклад потенціалу

Для обчислення потенціалу `φ(r)` на великих відстанях від замкненого об'єму `V'`, заповненого зарядом `ρ(r')`, вираз для потенціалу розкладають у ряд за степенями `(r' / r) < 1`:

```
φ(r) = (1 / 4π ε₀) ∫_{V'} (ρ(r') / |r − r'|) dV'
```

Використовуючи розклад оберненої відстані через поліноми Лежандра `P_l(cos θ)`:

```
1 / |r − r'| = (1 / r) ∑_{l=0}^{∞} (r' / r)^l · P_l(cos θ)
```

Отримуємо **мультипольний розклад**:

```
φ(r) = (1 / 4π ε₀) [ (Q / r) + (p · r̂ / r²) + (1 / 2 r³) ∑_{i,j} Q_{i,j} r̂_i r̂_j + ... ]
```

де моменти розподілу заряду визначені як:
1. **Монопольний момент (повний заряд):** `Q = ∫_{V'} ρ(r') dV'`. Поле спадає як `1/r`.
2. **Дипольний момент:** `p = ∫_{V'} r' ρ(r') dV'`. Поле спадає як `1/r²`.
3. **Квадрупольний момент:** `Q_{i,j} = ∫_{V'} (3 x'_i x'_j − (r')² δ_{i,j}) ρ(r') dV'`. Поле спадає як `1/r³`.

Цей розклад є основою для аналізу полів антен, молекулярних дипольних взаємодій та атомної фізики.

## Виведення оператора Лапласа в криволінійних системах координат

Узагальнений вираз оператора Лапласа в ортогональних криволінійних координатах `(u₁, u₂, u₃)` з коефіцієнтами Ламе `h₁, h₂, h₃` обчислюється через дивергенцію градієнта:

```
∇²φ = (1 / (h₁ h₂ h₃)) · [ ∂/∂u₁ ((h₂ h₃ / h₁) · ∂φ/∂u₁) +
                           + ∂/∂u₂ ((h₁ h₃ / h₂) · ∂φ/∂u₂) +
                           + ∂/∂u₃ ((h₁ h₂ / h₃) · ∂φ/∂u₃) ]
```

### 1. Циліндрична система координат `(r, θ, z)`

Зв'язок з декартовими координатами: `x = r cos θ`, `y = r sin θ`, `z = z`.

Коефіцієнти Ламе: `h_r = 1`, `h_θ = r`, `h_z = 1`.

Підставляємо коефіцієнти у загальну формулу:

```
∇²φ = (1 / (1 · r · 1)) · [ ∂/∂r ((r · 1 / 1) · ∂φ/∂r) + ∂/∂θ ((1 · 1 / r) · ∂φ/∂θ) + ∂/∂z ((1 · r / 1) · ∂φ/∂z) ]
    = (1 / r) · ∂/∂r (r · ∂φ/∂r) + (1 / r²) · ∂²φ/∂θ² + ∂²φ/∂z²
```

Розкриваючи похідну добутку `∂/∂r (r · ∂φ/∂r) = ∂φ/∂r + r · ∂²φ/∂r²`, отримуємо:

```
∇²φ = ∂²φ / ∂r² + (1 / r) · ∂φ / ∂r + (1 / r²) · ∂²φ / ∂θ² + ∂²φ / ∂z²
```

У випадку осьової симетрії (потенціал не залежить від кута `θ` та координати `z`):

```
(1 / r) · d/dr (r · dφ/dr) = 0   =>   r · dφ/dr = C₁   =>   φ(r) = C₁ · ln(r) + C₂
```

Це дає логарифмічний розподіл потенціалу в циліндричному конденсаторі та коаксіальному кабелі.

### 2. Сферична система координат `(r, θ, ψ)`

Зв'язок з декартовими координатами: `x = r sin θ cos ψ`, `y = r sin θ sin ψ`, `z = r cos θ`.

Коефіцієнти Ламе: `h_r = 1`, `h_θ = r`, `h_ψ = r sin θ`.

Підставляємо коефіцієнти у загальну формулу:

```
∇²φ = (1 / (r² sin θ)) · [ ∂/∂r (r² sin θ · ∂φ/∂r) + ∂/∂θ (sin θ · ∂φ/∂θ) + ∂/∂ψ ((1 / sin θ) · ∂φ/∂ψ) ]
    = (1 / r²) · ∂/∂r (r² · ∂φ/∂r) + (1 / (r² sin θ)) · ∂/∂θ (sin θ · ∂φ/∂θ) + (1 / (r² sin² θ)) · ∂²φ / ∂ψ²
```

У випадку сферичної симетрії (потенціал залежить тільки від радіуса `r`):

```
(1 / r²) · d/dr (r² · dφ/dr) = 0   =>   r² · dφ/dr = −C₁   =>   φ(r) = (C₁ / r) + C₂
```

Це дає класичний кулонівський потенціал точкового або сферичного заряду `φ(r) = q / (4π ε₀ r)`.
