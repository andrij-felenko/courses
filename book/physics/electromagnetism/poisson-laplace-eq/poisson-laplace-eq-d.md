При розробці високовольтних вимикачів змінного струму на напругу `330` кВ пробій діелектричного проміжку виникає в точках, де локальна напруженість електричного поля перевищує критичний поріг `3` МВ/м. Проектування форми металевих електродів та конфігурації керамічних ізоляторів вимагає точного знання просторового розподілу електричного потенціалу в усій тривимірній області між контактами. Безпосереднє обчислення поля шляхом підсумовування кулонівських внесків від мільярдів зв'язаних і вільних зарядів у діелектрику є математично неможливим. Замість цього задачу зводять до розв'язання диференціальних рівнянь у частинних похідних — **рівняння Пуассона** (при наявності об'ємного заряду) та **рівняння Лапласа** (у порожнечі або нейтральному діелектрику).

## Від закону Гаусса до скалярного потенціалу

Математичний фундамент електростатики спирається на дві основоположні властивості статичного електричного поля: його джерельний характер та його потенціальність. 

По-перше, фундаментальний закон Гаусса у диференціальній формі стверджує, що джерелами електричного поля `E` є електричні заряди з об'ємною густиною `ρ`:

```
∇ · E = ρ / ε₀
```

де `∇ · E` — **дивергенція** (від латинського *divergere* — розходитися) вектора напруженості електричного поля, яка визначає питому потужність джерел поля в даній точці простору, а `ε₀ ≈ 8.854 · 10⁻¹²` Ф/м — електрична стала.

Для наочного розуміння оператора дивергенції розглянемо нескінченно малий паралелепіпед з об'ємом `dV = dx dy dz`. Потік вектора `E` через його граничні грані за теоремою Гаусса-Остроградського дорівнює алгебраїчній сумі зарядів усередині об'єму. Ділення цього потоку на `dV` при прямуванні розмірів комірочки до нуля дає точне локальне визначення `∇ · E`.

По-друге, в електростатиці (а також у квазістаціонарному наближенні при повільно змінних магнітних полях `∂B/∂t ≈ 0`) електростатичне поле є суворо потенціальним. Робота з переміщення пробного заряду по будь-якому замкненому контуру дорівнює нулю, що математично виражається рівністю нулю ротора вектора напруженості:

```
∇ × E = 0
```

Оскільки ротор градієнта будь-якої скалярної функції тотожно дорівнює нулю (`∇ × (∇φ) ≡ 0`), вектор напруженості поля `E` можна виразити через **градієнт** (від латинського *gradiens* — той, що крокує) скалярного електричного потенціалу `φ`:

```
E = −∇φ
```

Знак мінус у цьому співвідношенні має чіткий фізичний зміст: вектор напруженості електричного поля спрямований у бік найшвидшого зменшення скалярного потенціалу, від точок із високим потенціалом до точок із низьким.

Підставляємо вираз для напруженості поля `E = −∇φ` у диференціальне рівняння закону Гаусса:

```
∇ · (−∇φ) = ρ / ε₀   =>   ∇ · (∇φ) = −ρ / ε₀
```

Скалярний добуток оператора Гамільтона самого на себе `∇ · ∇` утворює скалярний диференціальний оператор второго порядку — **лапласіан** (англ. *Laplacian*, названий на честь французького математика П'єра-Симона Лапласа), який позначається як `∇²` або `Δ`. Таким чином, ми отримуємо **рівняння Пуассона** (назване на честь французького фізика й математика Симеона-Дені Пуассона):

```
∇²φ = −ρ / ε₀
```

Якщо електростатичне поле розглядається у середовищі з відносною діелектричною проникністю `ε_r(r)`, яка може змінюватися від точки до точки, закон Гаусса записується через вектор електричного зміщення `D = ε₀ · ε_r · E`:

```
∇ · (ε₀ · ε_r · ∇φ) = −ρ(r)
```

У випадку ізотропного й однорідного діелектрика (`ε_r = const`) скалярну величину `ε = ε₀ · ε_r` можна винести за знак дивергенції, що дає узагальнене рівняння Пуассона для суцільного діелектричного середовища:

```
∇²φ = −ρ / ε
```

У багатьох практичних задачах електростатики — між електродами вакуумних приладів, у міжелектродних зазорах конденсаторів, навколо високочастотних ліній передачі — об'ємний вільний заряд у досліджуваній області відсутній (`ρ = 0`). У цьому випадку рівняння Пуассона спрощується до **рівняння Лапласа**:

```
∇²φ = 0
```

![Порівняння областей застосування рівнянь Пуассона та Лапласа](/book/physics/electromagnetism/poisson-laplace-eq/img/poisson-vs-laplace.svg)
*Рис. 1. Схема застосування рівнянь електростатики: рівняння Пуассона описує області з об'ємним зарядом (наприклад, шар просторового заряду в напівпровіднику), а рівняння Лапласа — незаряджений діелектричний або вакуумний простір між провідниками.*

Фізична різниця між цими двома рівняннями полягає у наявності локальних джерел поля. Рівняння Пуассона є неоднорідним диференціальним рівнянням, права частина якого `−ρ / ε` описує локальне викривлення потенціалу під дією просторового заряду. Рівняння Лапласа є однорідним рівнянням, що описує гладкий розподіл потенціалу в просторі, який повністю визначається геометричною конфігурацією та потенціалами на зовнішніх межах області.

Цікаво відзначити, що математичний оператор Лапласа `∇²` зустрічається не лише в електростатиці, а й у квантовій механіці: стаціонарне рівняння Шредінгера `−(ℏ² / 2m) ∇²Ψ + V Ψ = E Ψ` містить саме кінетичний оператор Лапласа, що підкреслює універсальний фундаментальний характер лапласіана у теоретичній фізиці.

## Варіаційний принцип Діріхле та електростатична енергія

Альтернативне формулювання крайових задач електростатики спирається на функціонал електростатичної енергії системи. Повна потенціальна енергія електричного поля `W_e` в області `Ω` виражається інтегралом:

```
W[φ] = ½ ∭_Ω ε · |∇φ|² dV − ∭_Ω ρ · φ dV
```

Перший доданок описує об'ємну густину енергії електричного поля `w_e = ½ ε |E|² = ½ ε |∇φ|²`, а другий доданок відповідає потенціальній енергії взаємодії об'ємного заряду з полюсом.

Згідно з **варіаційним принципом Діріхле** (англ. *Dirichlet's Principle*), фізично реалізований розподіл потенціалу `φ(r)` надає функціоналу енергії `W[φ]` строгий абсолютний мінімум серед усіх можливих двічі неперервно диференційовних функцій, що задовольняють ті самі граничні умови на `∂Ω`.

Варіюючи функціонал `W[φ]` за потенціалом `φ → φ + δφ` з умовою `δφ = 0` на межі `∂Ω`:

```
δW = ∭_Ω [ ε · ∇φ · ∇(δφ) − ρ · δφ ] dV = 0
```

Застосовуючи першу формулу Гріна для інтегрування частинами:

```
δW = ∭_Ω [ −∇ · (ε · ∇φ) − ρ ] · δφ dV + ∮_{∂Ω} ε · (∂φ / ∂n) · δφ dS = 0
```

Оскільки варіація `δφ` усередині області `Ω` є довільною, рівність нулю інтеграла можлива лише при виконанні диференціального рівняння:

```
∇ · (ε · ∇φ) = −ρ
```

Таким чином, рівняння Пуассона є безпосереднім рівнянням Ейлера-Лагранжа для варіаційної задачі мінімізації електростатичної енергії. Це принципово важливо для методів чисельного моделювання: метод скінченних елементів (FEM) спирається саме на варіаційну мінімізацію енергетичного функціонала Діріхле.

### Електростатичний тиск та тензор напружень Максвелла

Знайдений з рівняння Пуассона розподіл потенціалу дозволяє обчислити механічні сили, які діють на провідники та діелектрики у полях. Поверхнева густина силового впливу на провідну межу (електростатичний тиск `P_{es}`) прямо пропорційна квадрату напруженості поля:

```
P_{es} = ½ ε₀ · E_n² = ½ σ² / ε₀
```

Цей тиск завжди спрямований за зовнішньою нормаллю до поверхні провідника, намагаючись розтягнути його у бік електричного поля. У загальному випадку тривимірного середовища сили обчислюються як дивергенція **тензора напружень Максвелла** (англ. *Maxwell stress tensor*) `T_{ij} = ε (E_i E_j − ½ δ_{ij} E²)`.

### Розрахунок матриці часткових ємностей Максвелла

У багатопровідникових системах (наприклад, багатожильні кабелі чи паралельні сигнальні лінії на друкованій платі) рівняння Лапласа дозволяє розрахувати повну матрицю міжелектродних ємностей `C_{ij}`. 

Для цього послідовно розв'язують рівняння Лапласа з граничними умовами, коли потенціал `j`-го провідника дорівнює `1` В, а потенціали всіх інших провідників дорівнюють `0` В. Сумарний індукований заряд на `i`-му провіднику дає відповідний коефіцієнт часткової ємності:

```
C_{ij} = ∮_{Γ_i} ε · (∂φ^{(j)} / ∂n) dS
```

Завдяки симетрії оператора Лапласа та тотожностям Гріна матриця ємностей завжди є строго симетричною: `C_{ij} = C_{ji}`.

## Оператор Лапласа у різних системах координат

Форма запису лапласіана `∇²φ` залежить від вибору системи координат. У загальних ортогональних криволінійних координатах `(u₁, u₂, u₃)` з метричними коефіцієнтами Ламе `h₁, h₂, h₃` оператор Лапласа обчислюється за формулою:

```
∇²φ = (1 / (h₁ h₂ h₃)) · [ ∂/∂u₁ ((h₂ h₃ / h₁) · ∂φ/∂u₁) + ∂/∂u₂ ((h₁ h₃ / h₂) · ∂φ/∂u₂) + ∂/∂u₃ ((h₁ h₂ / h₃) · ∂φ/∂u₃) ]
```

Оскільки геометрія реальних фізичних об'єктів (сферичні електроди, циліндричні кабелі, плоскі пластини) диктує вибір природної системи відліку, запишемо рівняння Пуассона у трьох найпоширеніших системах координат та виведемо з них фундаментальні фізичні співвідношення.

### 1. Декартова система координат (Cartesian Coordinates)

У декартових координатах `(x, y, z)` метричні коефіцієнти дорівнюють одиниці (`h_x = h_y = h_z = 1`). Оператор Лапласа є простою сумою других частинних похідних за кожною з координатних осей:

```
∇²φ = ∂²φ / ∂x² + ∂²φ / ∂y² + ∂²φ / ∂z²
```

Рівняння Пуассона набуває вигляду:

```
∂²φ / ∂x² + ∂²φ / ∂y² + ∂²φ / ∂z² = −ρ(x, y, z) / ε
```

Для одновимірної плоскопаралельної геометрії (наприклад, плоский конденсатор з незарядженим діелектриком товщиною `d`), коли потенціал змінюється лише вздовж осі `x`, рівняння Лапласа спрощується до двох послідовних інтегрувань:

```
d²φ / dx² = 0   =>   dφ / dx = C₁   =>   φ(x) = C₁ · x + C₂
```

Використовуючи граничні умови `φ(0) = 0` та `φ(d) = V₀`, знаходимо сталі інтегрування `C₂ = 0` та `C₁ = V₀ / d`. Це дає строго лінійний розподіл потенціалу `φ(x) = V₀ · (x / d)` та однорідне електричне поле `E = −dφ/dx = −V₀ / d` між паралельними пластинами.

### 2. Циліндрична система координат (Cylindrical Coordinates)

Для систем із осьовою симетрією (коаксіальні кабелі, циліндричні пучки електронів, круглі провідники) використовують циліндричні координати `(r, θ, z)`, де `r` — радіальна відстань, `θ` — азимутальний кут, `z` — осьова координата. Метричні коефіцієнти Ламе дорівнюють `h_r = 1`, `h_θ = r`, `h_z = 1`:

```
∇²φ = (1 / r) · ∂/∂r (r · ∂φ / ∂r) + (1 / r²) · (∂²φ / ∂θ²) + ∂²φ / ∂z²
```

Використовуючи правило диференціювання добутку, першу радіальну складову можна розкрити:

```
∇²φ = ∂²φ / ∂r² + (1 / r) · (∂φ / ∂r) + (1 / r²) · (∂²φ / ∂θ²) + ∂²φ / ∂z²
```

У випадку одновимірної радіальної симетрії нескінченного коаксіального конденсатора з радіусом внутрішньої жили `R₁` і внутрішнім радіусом зовнішнього екрана `R₂` (`∂φ/∂θ = 0`, `∂φ/∂z = 0`) рівняння Лапласа набуває вигляду:

```
(1 / r) · d/dr (r · dφ / dr) = 0   =>   r · dφ / dr = C₁   =>   dφ / dr = C₁ / r
```

Інтегруючи за радіусом `r`, отримуємо логарифмічний розподіл потенціалу:

```
φ(r) = C₁ · ln(r) + C₂
```

Підставляючи граничні умови `φ(R₁) = V₁` та `φ(R₂) = 0`, знаходимо сталі інтегрування:

```
φ(r) = V₁ · ln(R₂ / r) / ln(R₂ / R₁)
```

Звідси випливає формула для напруженості електричного поля в коаксіальному кабелі: `E(r) = −dφ/dr = V₁ / (r · ln(R₂ / R₁))`. Інтегруванням густини енергії по об'єму легко виводиться формула погонної ємності коаксіальної лінії: `C' = 2 π ε / ln(R₂ / R₁)`.

### 3. Сферична система координат (Spherical Coordinates)

Для систем із центральною симетрією (точечні заряди, заряджені провідні кулі, сферичні конденсатори, атомні ядра) застосовують сферичні координати `(r, θ, ϕ)`, де `r` — радіус, `θ` — зенітний (полярний) кут, `ϕ` — азимутальний кут. Коефіцієнти Ламе: `h_r = 1`, `h_θ = r`, `h_ϕ = r · sin θ`:

```
∇²φ = (1 / r²) · ∂/∂r (r² · ∂φ / ∂r) + (1 / (r² · sin θ)) · ∂/∂θ (sin θ · ∂φ / ∂θ) + (1 / (r² · sin² θ)) · (∂²φ / ∂ϕ²)
```

При відокремленні змінних у сферичних координатах кутова частина рівняння Лапласа зводиться до відомого у математичній фізиці диференціального рівняння Лежандра для полярного кута `θ`:

```
(1 / sin θ) · d/dθ (sin θ · dP_l / dθ) + l (l + 1) P_l(cos θ) = 0
```

де `P_l(cos θ)` — поліноми Лежандра порядку `l`.

У випадку сферично-симетричного розподілу заряду (`∂φ/∂θ = 0`, `∂φ/∂ϕ = 0`) рівняння Пуассона залежить лише від радіуса `r`:

```
(1 / r²) · d/dr (r² · dφ / dr) = −ρ(r) / ε
```

Для сферичного конденсатора з радіусами обкладок `R₁` та `R₂` поза зарядами (`ρ = 0`) рівняння Лапласа має вигляд:

```
d/dr (r² · dφ / dr) = 0   =>   r² · dφ / dr = C₁   =>   dφ / dr = C₁ / r²
```

Інтегруючи це рівняння, отримуємо потенціал кулонівського типу:

```
φ(r) = −C₁ / r + C₂
```

Враховуючи граничні умови `φ(R₁) = V₁` та `φ(R₂) = 0`, отримуємо повний розподіл потенціалу:

```
φ(r) = V₁ · (1/r − 1/R₂) / (1/R₁ − 1/R₂)
```

Звідси негайно виводиться точна формула ємності сферичного конденсатора: `C = 4 π ε R₁ R₂ / (R₂ − R₁)`.

## Фундаментальні властивості гармонічних функцій

Будь-яка двічі неперервно диференційовна функція `φ`, яка задовольняє рівняння Лапласа `∇²φ = 0` у певній області `Ω`, називається **гармонічною функцією** (англ. *harmonic function*). Гармонічні функції володіють рядом унікальних математичних властивостей, які визначають поведінку електростатичних полів.

### 1. Теорема про середнє значення (Mean-Value Theorem)

Значення гармонічної функції у будь-якій внутрішній точці `r₀` області `Ω` дорівнює середньому арифметичному її значень на довільній сферичній поверхні `S_R` радіуса `R` з центром у точці `r₀` (за умови, що куля радіуса `R` повністю лежить усередині області `Ω`):

```
φ(r₀) = (1 / (4 π R²)) ∮_{S_R} φ(r) dS
```

Аналогічно, значення `φ(r₀)` дорівнює середньому об'ємному значенню усередині цієї кулі `V_R`:

```
φ(r₀) = (1 / ((4/3) π R³)) ∭_{V_R} φ(r) dV
```

![Геометрична інтерпретація теореми про середнє значення](/book/physics/electromagnetism/poisson-laplace-eq/img/mean-value-property.svg)
*Рис. 2. Геометрична інтерпретація теореми про середнє значення: потенціал гармонічної функції у центральній точці `x₀` точно дорівнює інтегральному середньому значенню потенціалу на будь-якій навколишній сфері.*

Теорема про середнє значення дає глибше розуміння фізики електростатичного поля: у порожньому просторі потенціал не може утворювати локальних «горбів» чи «ям», а завжди є гладким середнім від оточуючих значень.

### 2. Принцип максимуму та мінімуму (Maximum/Minimum Principle)

Безпосереднім наслідком теореми про середнє значення є те, що гармонічна функція `φ`, яка не є константою, **не може мати локальних максимумів або мінімумів усередині обчислювальної області `Ω`**. 

Усі екстремуми (найбільше та найменше значення) гармонічної функції досягаються **виключно на зовнішній граничній поверхні `∂Ω`**.

З фізичної точки зору це означає:
- В електростатичному полі без вільних зарядів не існує точок стійкої рівноваги для пробного заряду.
- **Теорема Ірншоу (Earnshaw's Theorem):** Своєрідна система нерухомих точкових електричних зарядів не може перебувати у стані стійкої механічної рівноваги лише під дією кулонівських сил.

Якщо пробний позитивний заряд розмістити у точці, де потенціал має локальний мінімум, будь-яке відхилення створювало б повернувну силу. Проте, оскільки мінімуму всередині порожнечі бути не може, завжди знайдеться напрямок, уздовж якого потенціал зменшується, і заряд вискочить із цієї точки.

### 3. Мультипольний розклад гармонічних полів

У сферичних координатах загальний розв'язок рівняння Лапласа можна розкласти у ряд за сферичними гармоніками `Y_{lm}(θ, ϕ)` та поліномами Лежандра `P_l(cos θ)`:

```
φ(r, θ, ϕ) = ∑_{l=0}^∞ ∑_{m=-l}^l [ A_{lm} · r^l + B_{lm} / r^{l+1} ] · Y_{lm}(θ, ϕ)
```

Перші члени цього розкладу відповідають базовим фізичним конфігураціям:
- `l = 0` (монополь): Потенціал точкового заряду `~ 1/r`.
- `l = 1` (диполь): Потенціал електричного диполя `~ 1/r²`.
- `l = 2` (квадруполь): Потенціал квадрупольного розподілу `~ 1/r³`.

Цей розклад є основою аналітичного розрахунку полів у складних атомних і молекулярних системах.

### 4. Нескінченна гладкість (Analyticity)

Будь-який розв'язок рівняння Лапласа є не просто двічі диференційовним, а нескінченно диференційовним (`C^∞`) і аналітичним усередині області `Ω`. Це означає, що гармонічне електричне поле не може мати раптових зламів або стрибків у порожнечі — усі негладкості поля утворюються виключно на поверхнях провідників або межах розділу діелектриків.

## Узагальнені аналогії: Теплопровідність та стаціонарні струми

Рівняння Пуассона та Лапласа описують широкий клас стаціонарних фізичних процесів різної природи, що виражається у принципі математичного ізоморфізму.

### 1. Теплопровідність у стаціонарному режимі

Стаціонарний розподіл температури `T(r)` у твердому тілі з коефіцієнтом теплопровідності `k` за наявності об'ємних джерел тепла `q_v` описується диференціальним рівнянням:

```
∇ · (k · ∇T) = −q_v
```

При постійній теплопровідності `k = const` це рівняння тотожно збігається з рівнянням Пуассона `∇²T = −q_v / k`. Вектор густини теплового потоку `q = −k ∇T` аналогічний вектору напруженості електричного поля `E = −∇φ`.

### 2. Стаціонарний електричний струм у провідному середовищі

Закон збереження електричного заряду для стаціонарного постійного струму вимагає рівності нулю дивергенції густини струму `J`:

```
∇ · J = 0
```

Використовуючи диференціальну форму закону Ома `J = σ · E = −σ · ∇φ` (де `σ` — питома електрична провідність середовища), отримуємо диференціальне рівняння стаціонарного поля струму:

```
∇ · (σ · ∇φ) = 0
```

У однорідному середовищі (`σ = const`) потенціал електричного струму строго задовольняє рівняння Лапласа `∇²φ = 0`. Це дозволяє моделювати складні електростатичні поля за допомогою електролітичних ванн та електропровідного паперу (метод електрогідродинамічної аналогії ЕГДА).

### 3. Заряджений екрануючий шар Дебая-Хюккеля у плазмі та електролітах

У розчинах електролітів та плазмі вільні носії заряду перерозподіляються навколо введеного потенціалу, утворюючи екрануючу хмару. Рівняння Пуассона-Больцмана у лінійному наближенні слабкого поля перетворюється на **екрановане рівняння Гельмгольца** (або модифіковане рівняння Пуассона-Дебая):

```
∇²φ = κ² · φ
```

де `1/κ = λ_D` — дебаївський радіус екранування. Розв'язком цього рівняння для точкового заряду у сферичних координатах є експоненціально спадаючий потенціал Юкави-Дебая: `φ(r) = (q / (4 π ε r)) · exp(−κ r)`.

## Крайові задачі електростатики та теорема єдиності

Оскільки рівняння Пуассона та Лапласа є диференціальними рівняннями у частинних похідних, вони мають нескінченну множину розв'язків. Щоб виділити єдиний фізично правильний розв'язок, необхідно задати додаткові умови на межі області — **крайові (граничні) умови**.

Область `Ω` разом із заданими граничними умовами на її межі `∂Ω` формує **крайову задачу** (англ. *boundary value problem*, BVP).

![Типи крайових умов електростатики](/book/physics/electromagnetism/poisson-laplace-eq/img/boundary-conditions.svg)
*Рис. 3. Три фундаментальні типи крайових умов електростатики: умова Діріхле (фіксований потенціал), умова Неймана (фіксований потік / похідна) та змішана умова Робена.*

### Типи крайових умов

1. **Задача Діріхле (Перша крайова задача):** На межі `∂Ω` задається точне значення електричного потенціалу `φ(r) = V₀(r)`. Це відповідає випадку, коли межами області є провідники з відомими потенціалами (наприклад, заземлені корпуси або електроди під напругою).
2. **Задача Неймана (Друга крайова задача):** На межі `∂Ω` задається нормальна похідна потенціалу `∂φ / ∂n = −E_n(r)`. Фізично це означає завдання поверхневої густини заряду `σ = ε · E_n` або відсутність потоку поля через ізольовану межу чи площину симетрії (`∂φ / ∂n = 0`).
3. **Задача Робена (Змішана крайова задача):** На межі задається лінійна комбінація потенціалу та його нормальної похідної: `a · φ + b · (∂φ / ∂n) = c`.
4. **Умова на незаземленому (плаваючому) провіднику:** Потенціал провідника `V_float` є невідомим, але однаковим у всіх його точках, і додатково задано сумарний заряд провідника `Q = ∮ ε (∂φ/∂n) dS`.

На межах розділу двох різних діелектричних середовищ `ε₁` та `ε₂` з рівняння Пуассона випливають граничні умови заломлення ліній напруженості:

```
φ₁ = φ₂,    ε₁ · (∂φ₁ / ∂n) − ε₂ · (∂φ₂ / ∂n) = −σ_{free}
```

Це дає відомий закон заломлення векторних ліній електричного поля на межі розділу діелектриків: `tan(θ₁) / tan(θ₂) = ε₁ / ε₂`, де `θ₁` та `θ₂` — кути між вектором поля та нормаллю до поверхні.

Для формалізації інтерфейсів та контракту програмних модулів чисельних розв'язувачів уведено структурний опис типів даних у довіднику [api-boundary-conditions.md](book:physics/electromagnetism/poisson-laplace-eq/api-boundary-conditions.md).

### Теорема єдиності розв'язку (Uniqueness Theorem)

Фундаментальним результатом математичної физики є **теорема єдиності**:

> Якщо в обмеженій області `Ω` задано об'ємний розподіл заряду `ρ(r)`, а на межі `∂Ω` визначено граничні умови Діріхле, Неймана або Робена, то розв'язок рівняння Пуассона `∇²φ = −ρ / ε` існує і є єдиним (для задачі Неймана — з точністю до довільної доданої константи).

Суворе математичне доведення теореми єдиності спирається на першу та другу **тотожності Гріна** (англ. *Green's identities*). Якщо припустити існування двох різних розв'язків `φ₁` та `φ₂`, то їх різниця `u = φ₁ − φ₂` задовольняє однорідне рівняння Лапласа `∇²u = 0` з нульовими граничними умовами. Застосування інтегральної тотожності Гріна до функції `u` дає:

```
∭_Ω |∇u|² dV = ∮_{∂Ω} u · (∂u / ∂n) dS = 0
```

Оскільки інтеграл від квадрата градієнта `|∇u|² ≥ 0` дорівнює нулю, то `∇u = 0` в усій області. Це означає `u = const`, тобто `φ₁` та `φ₂` тотожно збігаються.

Детальний математичний вивід першої та другої тотожностей Гріна, а також суворе доведення теореми єдиності наведено у спеціалізованому матеріалі [math-uniqueness-theorem.md](book:physics/electromagnetism/poisson-laplace-eq/math-uniqueness-theorem.md).

Теорема єдиності має величезне практичне значення: вона гарантує, що якщо ми знайшли розв'язок рівняння Пуассона будь-яким методом (вгадуванням, методом дзеркальних зображень, чисельним розрахунком), цей розв'язок є **єдиним можливим фізичним розв'язком**.

## Аналітичні методи розв'язання

Аналітичні розв'язки рівнянь Пуассона та Лапласа існують лише для відносно простих симетричних геометрій. Розглянемо чотири головні аналітичні прийоми електростатики.

### 1. Метод відокремлення змінних (Метод Фур'є)

Метод відокремлення змінних полягає у пошуку розв'язку 2D або 3D рівняння Лапласа у вигляді добутку функцій, кожна з яких залежить лише від однієї координати:

```
φ(x, y) = X(x) · Y(y)
```

Підставляючи цей добуток у рівняння Лапласа `∂²φ/∂x² + ∂²φ/∂y² = 0` та ділячи на `X(x) · Y(y)`, отримуємо:

```
(1 / X) · (d²X / dx²) + (1 / Y) · (d²Y / dy²) = 0
```

Оскільки перший доданок залежить лише від `x`, а що другого — лише від `y`, їх сума може дорівнювати нулю для всіх `x, y` лише тоді, коли кожен доданок є константою. Це зводить диференціальне рівняння у частинних похідних до системи двох звичайних диференціальних рівнянь другого порядку:

```
d²X / dx² + k² X = 0,    d²Y / dy² − k² Y = 0
```

Розв'язками цих рівнянь є тригонометричні та гіперболічні (або показникові) функції. Загальний розв'язок записується у вигляді нескінченного ряду Фур'є, коефіцієнти якого визначаються з граничних умов.

### 2. Метод дзеркальних зображень (Method of Images)

Метод дзеркальних зображень дозволяє розраховувати поле точкових зарядів поблизу провідних поверхонь без безпосереднього розв'язання рівняння Пуассона. Ідея методу полягає у заміні реальної провідної поверхні штучним фиктивним зарядом-зображенням, розміщеним поза обчислювальною областю так, щоб сумарний потенціал на межі дорівнював заданому значення (наприклад, `φ = 0`).

Історичний розвиток теорії потенціалу та методів зображень детально описано у матеріалі [hist-poisson-laplace.md](book:physics/electromagnetism/poisson-laplace-eq/hist-poisson-laplace.md).

Класичний приклад — точковий заряд `+q`, розміщений на відстані `d` від нескінченної заземленої металевої площини (`z = 0`). Замінимо площину фиктивним зарядом `−q`, розміщеним у точці `z = −d`. Потенціал у верхній півплощині `z > 0` дорівнює:

```
φ(x, y, z) = (q / (4 π ε₀)) · [ 1 / √(x² + y² + (z − d)²) − 1 / √(x² + y² + (z + d)²) ]
```

На площині `z = 0` обидва доданки взаємно знищуються, що дає `φ(x, y, 0) = 0`. Оскільки рівняння Пуассона задоволено у верхній півплощині, а умова Діріхле `φ = 0` виконана на межі, за теоремою єдиності цей вираз є точним розв'язком задачі.

Для сферичної провідної поверхні радіуса `a`, заземленої при `V = 0`, точковий заряд `q`, розміщений на відстані `d > a` від центра кулі, індукує зображення-заряд `q' = −q · (a / d)`, розташоване всередині кулі на відстані `d' = a² / d` від її центра.

### 3. Конформні відображення (Conformal Mapping)

У двовимірних задачах електростатики (`∂φ/∂z = 0`) комплексний потенціал `W(z) = φ(x, y) + i · ψ(x, y)` є аналітичною функцією комплексної змінної `z = x + i y`. Дійсна частина `φ` являє собою скалярний потенціал, а уявна частина `ψ` — силову функцію (лінії електричного поля є ізолініями `ψ = const`). 

Завдяки умовам Коші-Рімана, обидві функції `φ` та `ψ` автоматично задовольняють 2D рівняння Лапласа: `∇²φ = 0` та `∇²ψ = 0`. Метод конформних відображень за допомогою інтеграла Шварца-Крістоффеля `dz/dw = C ∏ (w − w_k)^{−α_k / π}` дозволяє викривляти складні полігональні кутові межі електродів у простий прямокутник або півплощину.

### 4. Функції Гріна (Green's Functions)

Функція Гріна `G(r, r')` являє собою потенціал у точці `r`, створений одиничним точковим зарядом, розміщеним у точці `r'`:

```
∇² G(r, r') = −δ(r − r')
```

де `δ(r − r')` — тривимірна дельта-функція Дірака.

Якщо функція Гріна для даної геометрії з нульовими граничними умовами відома, розв'язок неоднорідного рівняння Пуассона для довільного розподілу заряду `ρ(r')` знаходять шляхом інтегрування (суперпозиції):

```
φ(r) = (1 / ε₀) ∭_Ω ρ(r') · G(r, r') dV' + ∮_{∂Ω} V₀(r') · (∂G / ∂n') dS'
```

Метод функцій Гріна є потужним математичним апаратом, що лежить в основі аналітичного моделювання складних фізичних систем.

## Чисельні методи розв'язання на сітках

У реальних інженерних задачах геометрія електродів та корпусу приладу є надто складною для аналітичних методів. У таких випадках застосовують чисельні методи, найпоширенішим з яких є **метод скінченних різниць** (англ. *Finite Difference Method*, FDM), **метод скінченних елементів** (англ. *Finite Element Method*, FEM) та **метод граничних елементів** (англ. *Boundary Element Method*, BEM).

### 5-точковий скінченно-різницевий шаблон

Розглянемо двовимірну область `(x, y)`, покриту рівномірною сіткою з кроком `h`. Позначимо значення потенціалу у вузлі сітки з індексами `(i, j)` як `φ_{i,j} = φ(i·h, j·h)`.

Запишемо апроксимацію других похідних за допомогою центральних скінченних різниць другого порядку точності `O(h²)`:

```
∂²φ / ∂x² ≈ (φ_{i+1,j} − 2 φ_{i,j} + φ_{i-1,j}) / h²
∂²φ / ∂y² ≈ (φ_{i,j+1} − 2 φ_{i,j} + φ_{i,j-1}) / h²
```

![5-точковий скінченно-різницевий шаблон на 2D сітці](/book/physics/electromagnetism/poisson-laplace-eq/img/fdm-5point-stencil.svg)
*Рис. 4. Структура 5-точкового хрестоподібного шаблону: потенціал у центральному вузлі `(i, j)` обчислюється через значення потенціалу в чотирьох сусідніх вузлах.*

Підставляючи різницеві наближення в рівняння Пуассона `∂²φ/∂x² + ∂²φ/∂y² = −ρ / ε`, отримуємо алгебраїчний **5-точковий шаблон**:

```
(φ_{i+1,j} + φ_{i-1,j} + φ_{i,j+1} + φ_{i,j-1} − 4 φ_{i,j}) / h² = −ρ_{i,j} / ε
```

Виражаємо потенціал у центральному вузлі `φ_{i,j}`:

```
φ_{i,j} = ¼ (φ_{i+1,j} + φ_{i-1,j} + φ_{i,j+1} + φ_{i,j-1}) + ¼ h² (ρ_{i,j} / ε)
```

Це рівняння дає скінченно-різницеву формулу ітераційної релаксації: потенціал будь-якого внутрішнього вузла дорівнює середньому арифметичному чотирьох його сусідів плюс поправка на джерело заряду. Точність розв'язку визначається кроком дискретизації `h` та порядком апроксимації шаблону.

### Метод скінченних елементів (FEM) та граничних елементів (BEM)

Для складної тривимірної геометрії з криволінійними межами FDM поступається методом скінченних елементів (FEM). У FEM область `Ω` розбивається на тривимірні тетраедри або призми. Потенціал апроксимується базисними функціями `N_i(r)` усередині кожного елемента: `φ(r) = ∑ φ_i · N_i(r)`. Зведення до варіаційної формуляції Діріхле дає систему СЛАУ з глобальною матрицею жорсткості `K_{ij} = ∭ ε · ∇N_i · ∇N_j dV`.

У задачах із відкритими нескінченними межами ефективним є метод граничних елементів (BEM). За допомогою інтегральних тотожностей Гріна розмірність задачі зменшується з 3D об'єму до 2D поверхні межі `∂Ω`. Дискретизація поверхні елементарними панелями зменшує кількість невідомих вузлів, хоча утворює щільну (не розріджену) матрицю.

### Алгоритми ітераційної релаксації (Jacobi, Gauss-Seidel, SOR, Multigrid)

Дискретизація дає велику систему лінійних алгебраїчних рівнянь `A · Φ = B` з розрідженою матрицею. Для її розв'язання застосовують ітераційні методи:
- **Метод Якобі:** Нові значення `φ_{i,j}^{(k+1)}` обчислюються виключно за даними з попереднього кроку `k`.
- **Метод Гаусса-Зейделя:** Оновлені значення вузлів використовуються негайно в поточному ж обході сітки, що прискорює збіжність у 2 рази.
- **Метод послідовної верхньої релаксації (SOR):** Вносить оптимальний коефіцієнт екстраполяції `ω ∈ (1, 2)`, що зменшує кількість необхідних ітерацій з `O(N²)` до `O(N)`.
- **Багатосітковий метод (Multigrid):** Переносить залишок похибки з дрібної сітки `h` на серію грубих сіток `2h`, `4h`, що забезпечує збіжність за оптимальний час `O(N_total)`.
