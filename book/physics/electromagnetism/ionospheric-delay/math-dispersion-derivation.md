# 🧮 Дисперсія плазми: виведення формули затримки та двочастотного компенсатора

Ця математична вставка містить строге мікроскопічне виведення діелектричної проникності холодної іонізованої плазми з рівнянь руху електрона, отримання показників заломлення для фазової та групової швидкості, виведення інваріанта затримки через повний електронний вміст (TEC), а також алгебраїчне виведення безіоносферної комбінації двочастотного приймача GNSS з детальним аналізом трансформування вимірювального шуму.

Математичний апарат плазмової дисперсії лежить в основі сучасної радіофізики та супутникової геодезії. Він пояснює, чому високочастотні радіохвилі розщеплюються за швидкістю поширення залежно від частоти і як цей ефект дозволяє вимірювати та компенсувати вплив космічної плазми.

### 1. Мікроскопічна динаміка електрона у хвильовому полі

Розглянемо високочастотну електромагнітну хвилю з коловою частотою `ω = 2π f`, що поширюється крізь розріджену плазму іоносфери. Іоносферна плазма складається з вільних електронів, позитивно заряджених іонів (переважно `O⁺`, `NO⁺`, `O₂⁺`) та нейтральних атомів і молекул. Оскільки маса найлегшого іона (протона) перевищує масу електрона більш ніж у 1836 разів, а маса іона кислорода `O⁺` — у 29 300 разів, зміщенням важких іонів під дією високочастотного змінного поля радіохвилі (`f > 100 МГц`) можна знехтувати. Головний внесок у поляризацію середовища роблять легкі вільні електрони.

Записуємо другий закон Ньютона для вільного електрона маси `m_e` та заряду `-e` у гармонічному електричному полі хвилі `E(t) = E₀ · e^(i ω t)`. Для високочастотних сигналів супутникової навігації (`f ≈ 1.2–1.6 ГГц`) силу Лоренца від власного магнітного поля хвилі `v × B` можна відкинути, оскільки її амплітуда менша за електричну силу в відношенні `v / c << 10⁻⁴`. Частотою зіткнень електронів із нейтральними частинками `ν_e` на висотах шару F2 (`h > 200 км`) також нехтуємо, бо `ν_e ≈ 10³ Гц << ω`:

```
m_e · (d²x / dt²) = -e · E₀ · e^(i ω t)
```

Інтегруючи це диференціальне рівняння двічі за часом `t`, отримуємо швидкість `dx/dt` та зміщення електрона `x(t)` від положення рівноваги:

```
dx / dt = i · (e / (m_e · ω)) · E₀ · e^(i ω t)
x(t)    = (e / (m_e · ω²)) · E₀ · e^(i ω t)
```

Зміщений з положення рівноваги електрон разом із нерухомим іонним фоном утворює елементарний електричний диполь із дипольним моментом `p = -e · x(t)`. При об'ємній концентрації вільних електронів `N_e` (вимірюється у кількості електронів на кубічний метр, `e⁻/м³`) макроскопічний вектор поляризації плазми `P` дорівнює макроскопічній сумі дипольних моментів в одиниці об'єму:

```
P = N_e · p
  = -N_e · e · x(t)                            [підстановка дипольного моменту p = -e · x]
  = - (N_e · e² / (m_e · ω²)) · E              [підстановка зміщення x(t)]
```

Зверніть увагу на від'ємний знак у формулі поляризації: наведене зміщення електронів відбувається у протифазі до електричного поля хвилі. Це принципово відрізняє плазму від звичайних діелектриків, де поляризація збігається за напрямком із зовнішнім полем.

### 2. Ефективна діелектрична проникність та плазмова частота

Згідно з рівняннями Максвелла, вектор електричного зсуву `D` у матеріальному середовищі з поляризацією `P` зв'язаний з вектором електричного поля `E` співвідношенням:

```
D = ε₀ · E + P
  = ε₀ · E - (N_e · e² / (m_e · ω²)) · E       [підстановка поляризації P]
  = ε₀ · (1 - (N_e · e² / (ε₀ · m_e · ω²))) · E [винесення електричної сталої ε₀]
```

Звідси випливає, що відносна діелектрична проникність плазми `ε_r(ω)` є функцією частоти `ω`:

```
ε_r(ω) = 1 - (ω_p² / ω²)
```

де `ω_p` — **власна плазмова (лєнґмюрівська) частота** поздовжніх коливань електронного газу:

```
ω_p = √(N_e · e² / (ε₀ · m_e))
```

Плазмова частота є фундаментальною характеристикою плазмового середовища. Вона визначає природну частоту, з якою електронний газ коливається відносно іонного остову при зсуві балансу зарядів.

Підставивши у формулу значення фундаментальних фізичних констант:
- Заряд електрона: `e ≈ 1.60217663 × 10⁻¹⁹ Кл`
- Маса електрона: `m_e ≈ 9.1093837 × 10⁻³¹ кг`
- Електрична стала вакууму: `ε₀ ≈ 8.8541878 × 10⁻¹² Ф/м`

Отримуємо чисельну формулу для плазмової частоти в герцах `f_p = ω_p / (2π)`:

```
f_p = (1 / (2π)) · √(N_e · e² / (ε₀ · m_e))
    ≈ 8.9788 · √(N_e)  [Гц]
```

Наприклад, для характерних умов іоносферного шару F2 у денний час при концентрації `N_e = 1.0 × 10¹² м⁻³` плазмова частота становить:

```
f_p ≈ 8.98 · √(10¹²) = 8.98 × 10⁶ Гц = 8.98 МГц
```

Якщо частота радіохвилі `f` менша за плазмову частоту `f_p`, відносна діелектрична проникність `ε_r` стає від'ємною, хвильове число стає чисто уявним, і хвиля експоненційно згасає вглиб середовища, повністю віддзеркалюючись від плазмової межі. Якщо ж частота `f >> f_p` (як для сигналів GNSS `1.2–1.6 ГГц`), плазма є прозорою, а діелектрична проникність трохи менша за одиницю.

### 3. Строге виведення фазового та групового показників заломлення

Для немагнітного плазмового середовища (`μ_r = 1`) фазовий показник заломлення `n_p(f)` визначається співвідношенням:

```
n_p(f) = √(ε_r(f)) = √(1 - f_p² / f²)
```

Оскільки для навігаційних частот L-діапазону `(f_p / f)² ≈ (10 МГц / 1500 МГц)² ≈ 4.4 × 10⁻⁵ << 1`, розкладемо квадратний корінь у биноміальний ряд Тейлора:

```
n_p(f) = (1 - f_p² / f²)^(1/2)
       = 1 - (1/2) · (f_p² / f²) - (1/8) · (f_p⁴ / f⁴) - ...
       ≈ 1 - (1/2) · (f_p² / f²)
```

Підставивши вираз для `f_p² = (N_e · e²) / (4π² · ε₀ · m_e)`, отримуємо наближення першого порядку:

```
n_p(f) ≈ 1 - (e² / (8π² · ε₀ · m_e)) · (N_e / f²)
       ≈ 1 - (40.308 · N_e) / f²
```

Оскільки `n_p < 1`, фазова швидкість несучої хвилі `v_p = c / n_p` є більшою за швидкість світла у вакуумі:

```
v_p ≈ c · (1 + (40.308 · N_e) / f²) > c
```

Для визначення швидкості поширення обвідної сигналу (кодових міток часу) використаємо визначення групового показника заломлення `n_g(f)` через похідну фазового показника за частотою:

```
n_g(f) = d / df (f · n_p(f))
       = n_p(f) + f · (dn_p / df)
```

Обчислимо похідну `dn_p / df` від наближеного виразу `n_p ≈ 1 - 40.3 · N_e · f⁻²`:

```
dn_p / df = d / df (1 - 40.3 · N_e · f⁻²)
          = + 2 · (40.3 · N_e) · f⁻³
```

Підставимо отриману похідну у формулу групового показника заломлення:

```
n_g(f) = (1 - (40.3 · N_e) / f²) + f · (2 · (40.3 · N_e) / f³)
       = 1 + (40.3 · N_e) / f²
```

Отже, **груповий показник заломлення більший за одиницю** (`n_g > 1`), а групова швидкість `v_g = c / n_g` є меншою за швидкість світла:

```
v_g ≈ c · (1 - (40.308 · N_e) / f²) < c
```

Це математично доводить фізичний парадокс плазмової дисперсії: фазові гребені хвилі прискорюються, а обвідна сигнального пакета затримується на одну й ту саму абсолютну величину.

### 4. Інтегрування вздовж променя та визначення Total Electron Content (TEC)

Розглянемо поширення сигнального пакета від супутника до приймача вздовж просторової траєкторії `S`. Виміряна кодова псевдодалькість `R_g` дорівнює добутку швидкості світла на виміряний час прольоту `τ_g`:

```
R_g = c · τ_g = ∫₀ˢ n_g(s) ds
```

Підставляючи груповий показник заломлення `n_g(s)`:

```
R_g = ∫₀ˢ n_g(s) ds
    = ∫₀ˢ (1 + (40.3 · N_e(s)) / f²) ds        [підстановка групового показника n_g(s)]
    = ∫₀ˢ 1 ds + (40.3 / f²) · ∫₀ˢ N_e(s) ds   [лінійність інтегрування]
    = ρ + ΔR_g                                  [позначення геометричного шляху ρ та затримки ΔR_g]
```

де `ρ = ∫₀ˢ ds` — геометрична відстань між антенами у вакуумі, а `ΔR_g` — **кодова іоносферна затримка**:

```
ΔR_g = (40.3 / f²) · STEC  [метрів]
```

Величина `STEC` (Slant Total Electron Content) виражає похилий повний електронний вміст:

```
STEC = ∫₀ˢ N_e(s) ds  [електронів / м²]
```

У практичних обчисленнях STEC подають у стандартних одиницях `TECU` (`1 TECU = 10¹⁶ e⁻/м²`). Тоді кодова затримка `ΔR_g` (у метрах) для частоти `f` (у ГГц) дорівнює:

```
ΔR_g = (0.40308 / f_ГГц²) · STEC_TECU
```

Аналогічно обчислимо псевдодалькість за фазою несучої хвилі `R_p`:

```
R_p = ∫₀ˢ n_p(s) ds
    = ∫₀ˢ (1 - (40.3 · N_e(s)) / f²) ds        [підстановка фазового показника n_p(s)]
    = ρ - (40.3 / f²) · STEC                    [інтегрування електронного вмісту STEC]
    = ρ + ΔR_p                                  [позначення фазового прискорення ΔR_p]
```

де `ΔR_p = - (40.3 / f²) · STEC` — **фазове прискорення** несучої (фазовий зсув зі знаком мінус).

### 5. Виведення коефіцієнтів двочастотного компенсатора (Ionosphere-Free)

Розглянемо двочастотний приймач GNSS, що виконує одночасні кодові вимірювання `P_1` та `P_2` на двох різних носійних частотах `f_1` та `f_2`:

```
P_1 = ρ + (40.3 / f_1²) · STEC + e_1
P_2 = ρ + (40.3 / f_2²) · STEC + e_2
```

де `e_1, e_2` — апаратурні шуми та затримки приймача й супутника.

Знайдемо вагової лінійну комбінацію `P_IF = α · P_1 + β · P_2`, яка повністю скасовує іоносферний член `STEC`:

```
P_IF = α · (ρ + (40.3 / f_1²) · STEC) + β · (ρ + (40.3 / f_2²) · STEC)
     = (α + β) · ρ + (α / f_1² + β / f_2²) · 40.3 · STEC
```

Щоб отримати несміщену геометричну відстань `ρ` без іоносферного члена, коефіцієнти `α` та `β` повинні задовольняти систему з двох лінійних рівнянь:

```
1) α + β = 1
2) α / f_1² + β / f_2² = 0
```

З другого рівняння виражаємо `β`:

```
β = - α · (f_2² / f_1²)
```

Підставляємо в перше рівняння:

```
α - α · (f_2² / f_1²) = 1
α · (1 - f_2² / f_1²) = 1
α · ((f_1² - f_2²) / f_1²) = 1
α = f_1² / (f_1² - f_2²)
```

Відповідно, коефіцієнт `β`:

```
β = 1 - α = 1 - f_1² / (f_1² - f_2²) = - f_2² / (f_1² - f_2²)
```

Таким чином, підсумкова формула **без іоносферної комбінації псевдодальності (Ionosphere-Free, IF)** має вигляд:

```
P_IF = (f_1² · P_1 - f_2² · P_2) / (f_1² - f_2²)
```

Позначивши квадрат відношення частот `γ = (f_1 / f_2)²`, коефіцієнти можна переписати як:

```
α = γ / (γ - 1)
β = - 1 / (γ - 1)
```

Для сигналів системи GPS L1 (`f_1 = 1575.42 МГц`) та L2 (`f_2 = 1227.60 МГц`):

```
γ = (1575.42 / 1227.60)² = (1.283333)² ≈ 1.646944

α = 1.646944 / 0.646944 ≈ + 2.54573
β = - 1 / 0.646944      ≈ - 1.54573
```

Підставляючи коефіцієнти, отримуємо розрахункову формулу:

```
P_IF = 2.54573 · P_1 - 1.54573 · P_2
```

### 6. Аналіз трансформування вимірювального шуму у IF-комбінації

Оцінимо дисперсію випадкового шуму отриманої безіоносферної комбінації `σ_IF²`. За законом поширення помилок для лінійної комбінації некорельованих випадкових величин `P_1` та `P_2` з дисперсіями `σ_1²` та `σ_2²`:

```
σ_IF² = α² · σ_1² + β² · σ_2²
```

Якщо шуми кодових вимірювань на двох частотах однакові `σ_1 = σ_2 = σ_P`:

```
σ_IF² = α² · σ_1² + β² · σ_2²
      = (2.5457)² · σ_P² + (-1.5457)² · σ_P²   [підстановка коефіцієнтів α, β та σ_1 = σ_2 = σ_P]
      = (6.4806 + 2.3892) · σ_P²               [піднесення коефіцієнтів до квадрата]
      = 8.8698 · σ_P²                          [додавання складових дисперсії]
```

Беручи квадратний корінь, маємо:

```
σ_IF = √(8.8698) · σ_P ≈ 2.978 · σ_P
```

Таке зростання вимірювального шуму (майже втричі) є математичною платою за усунення системної іоносферної затримки. У практичних навігаційних алгоритмах це компенсується згладжуванням кодових вимірів за допомогою фази несучої хвилі (фільтр Хетча) або використанням фазових комбінацій IF у Kalman-фільтрах.
