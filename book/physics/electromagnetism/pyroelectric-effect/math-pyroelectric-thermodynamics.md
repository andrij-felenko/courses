# 🧮 Термодинаміка та феноменологія піроелектричного ефекту

Цей математичний огляд розгортає повну термодинамічну теорію піроелектричного ефекту, розділення на первинну та вторинну компоненти, розрахунок часового відгуку теплового балансу та частотну характеристику чутливості еквівалентної електричної схеми.

## Термодинамічний потенціал Гіббса для кристала

Феноменологічний опис взаємозв'язку між тепловими, механічними та електричними властивостями діелектричного кристала будується на основі термодинамічного потенціалу Гіббса `G(T, \sigma, E)`. У цій формації незалежними змінними стану виступають абсолютна температура `T`, тензор другого рангу механічних напружень `\sigma_{jk}` та вектор електричного поля `E_k`.

Повний диференціал потенціалу Гіббса для одиниці об'єму анізотропного діелектричного середовища записаний у тензорному вигляді:

```
d G = -S d T - S_{jk} d \sigma_{jk} - D_i d E_i
```

де `S` — питома ентропія діелектрика, `S_{jk}` — тензор механічних деформацій, а `D_i` — вектор електричного зсуву (індукції).

Оскільки `d G` являє собою повний диференціал гладкої функції стану, фізичні властивості матеріалу визначаються другими частковими похідними потенціалу Гіббса за відповідними незалежними змінними. Розкладаючи вектор електричного зсуву `D_i(T, \sigma, E)` у малій околиці опорного стану у багатовимірний ряд Тейлора та утримуючи лише лінійні за збуреннями члени, отримуємо феноменологічне рівняння стану поляризованого кристала:

```
d D_i
= (∂ D_i / ∂ E_j) d E_j + (∂ D_i / ∂ \sigma_{jk}) d \sigma_{jk} + (∂ D_i / ∂ T) d T     [диференціювання D_i за незалежними змінними E, \sigma, T]
= \varepsilon_{ij}^\sigma d E_j + d_{ijk}^T d \sigma_{jk} + p_i^\sigma d T              [введення тензорів диелектричної проникності, п'єзомодулів та піроелектричних коефіцієнтів]
```

У цьому термодинамічному рівнянні коефіцієнти розкладу мають чітко визначений фізичний зміст матеріальних тензорів:
- `\varepsilon_{ij}^\sigma = (\partial D_i / \partial E_j)_{\sigma, T}` — симетричний тензор другого рангу діелектричної проникності середовища за постійних механічних напружень та постійної температури;
- `d_{ijk}^T = (\partial D_i / \partial \sigma_{jk})_{E, T}` — тензор третього рангу п'єзоелектричних модулів за постійного напруженості електричного поля та температури;
- `p_i^\sigma = (\partial D_i / \partial T)_{E, \sigma} = (\partial P_{s,i} / \partial T)_{E, \sigma}` — вектор (тензор першого рангу) піроелектричних коефіцієнтів вільного кристала за відсутності зовнішнього поля та постійного механічного напруження `\sigma = 0`.

У нотації Фойгта (Voigt notation) тензор третього рангу `d_{ijk}` згортається у матрицю `d_{i\alpha}` розміром `3 \times 6`, де індекс `\alpha \in \{1, 2, 3, 4, 5, 6\}` відповідає симетричним комбінаціям тензорних індексів напруження.

```
Незалежні змінні стану: (T, \sigma, E)
 ├── (∂D / ∂E)  → Тензор діелектричної проникності ε_ij (2-й ранг)
 ├── (∂D / ∂σ) → Тензор п'єзоелектричних модулів d_ijk (3-й ранг)
 └── (∂D / ∂T) → Вектор піроелектричних коефіцієнтів p_i (1-й ранг)
```

## Розділення на первинний та вторинний піроелектричні ефекти

Піроелектричний коефіцієнт `p_i^\sigma`, виміряний на вільній від механічних закріплень кристалічній пластині (яка може вільно змінювати свої геометрічні розміри під час нагрівання), є сумою двох фізично різних внесків: первинного (внутрішнього атомарного) та вторинного (п'єзоелектричного деформаційного).

Щоб математично розділити ці внески, виберемо як незалежну механічну змінну тензор деформацій `S_{jk}` замість напружень `\sigma_{jk}`. При такій зміні термодинамічного потенціалу феноменологічне рівняння для електричного зсуву набирає вигляду:

```
d D_i = \varepsilon_{ij}^S d E_j + e_{ijk}^T d S_{jk} + p_i^S d T
```

де `p_i^S = (\partial D_i / \partial T)_{E, S}` — первинний піроелектричний коефіцієнт механічно повністю затиснутого кристала (за умови фіксованої деформації `S = 0`), а `e_{ijk}^T` — тензор п'єзоелектричних коефіцієнтів напруження.

Використовуючи термодинамічний зв'язок між деформацією, напруженням та температурою через тензор четвертого рангу пружної жорсткості `c_{jklm}^E` та тензор другого рангу анізотропного теплового розширення `\alpha_{lm}^E`, запишемо повний диференціал деформації:

```
d S_{jk}
= s_{jklm}^{E,T} d \sigma_{lm} + \alpha_{jk}^E d T                      [розклад деформації на механічну та термічну складові]
```

За умови повністю вільного кристала механічні напруження відсутні (`d \sigma_{lm} = 0`), тому деформація кристалічної ґратки зводиться суто до термічного розширення: `d S_{jk} = \alpha_{jk}^E d T`. Підставляючи цей вираз у феноменологічне рівняння для `d D_i`, отримуємо:

```
d D_i
= \varepsilon_{ij}^S d E_j + e_{ijk}^T (\alpha_{jk}^E d T) + p_i^S d T  [підстановка d S через термічне розширення \alpha d T]
= \varepsilon_{ij}^S d E_j + (p_i^S + e_{ijk}^T \alpha_{jk}^E) d T      [групування членів при d T]
```

Порівнюючи отримане співвідношення з рівнянням вільного кристала `d D_i = \varepsilon_{ij}^\sigma d E_j + p_i^\sigma d T`, отримуємо фундаментальну формулу розщеплення піроелектричного коефіцієнта:

```
p_i^\sigma
= p_i^S + p_i^{(2)}                                                      [розділення на первинний та вторинний ефекти]
= p_i^S + e_{ijk}^T \alpha_{jk}^E                                       [вираження вторинного ефекту через п'єзомодулі e та розширення \alpha]
= p_i^S + c_{jklm}^E d_{i j k}^T \alpha_{lm}^E                          [перехід від коефіцієнтів e до п'єзомодулів d та пружності c]
```

Фізичний зміст та механізми обох складових:
1. **Первинний піроелектричний ефект `p_i^S`:** Викликаний зміною поляризованості асиметричних іонних комірок ґратки за рахунок зміщення електронних хмарок та агармонізму квантових теплових коливань іонів у потенціальних ямах за суворо незмінних об'єму та форми кристала (`S = 0`);
2. **Вторинний піроелектричний ефект `p_i^{(2)}`:** Викликаний тим, що анізотропне термічне розширення кристала `\alpha_{lm}` змінює відстані між елементарними комірками, що призводить до механічної деформації ґратки `S_{jk}`. Ця деформація через внутрішній п'єзоелектричний ефект `d_{ijk}` створює додаткову поляризацію поверхні.

У сегнетоелектричній кераміці (наприклад, `\text{PZT}`) або монокристалах танталату літію `\text{LiTaO}_3` вторинний ефект становить від 15% до 45% від сумарного піроелектричного сигналу. Якщо кристал нагрівається нерівномірно, виникають локальні температурні градієнти `\nabla T`, що створюють просторово неднорідні внутрішні напруження `\sigma_{jk}(r)`. Це породжує третинний (просторовий) піроелектричний ефект.

```
Повний піроелектричний коефіцієнт p^σ
 ├── Первинний ефект p^S (Зсув іонів за фіксованого об'єму S = 0)
 ├── Вторинний ефект p^(2) = c · d · α (Теплове розширення → П'єзодеформація)
 └── Третинний ефект p^(3) (Локальні температурні градієнти ∇T і напруження)
```

## Динаміка теплового балансу піроелектричного детектора

Розглянемо тонкий піроелектричний пластинчастий елемент площею `A` та товщиною `d`, підданий дії синусоїдально модульованого потоку оптичного або інфрачервоного випромінювання потужністю `P(t) = P_0 e^{i \omega t}`.

Тепловий баланс детектора у лінійному наближенні описується диференціальним рівнянням теплопровідності та теплообміну:

```
C_{th} (d \Delta T / d t) + G_{th} \Delta T = \eta P_0 e^{i \omega t}
```

де позначено:
- `\Delta T(t) = T(t) - T_0` — миттєве перевищення температури піроелектричного елемента над температурою навколишнього середовища чи термостата `T_0`;
- `C_{th} = c_v \cdot A \cdot d` — повна теплоємність елемента (`c_v` — об'ємна теплоємність матеріалу, Дж/(м³·К));
- `G_{th}` — сумарна теплова провідність зв'язку елемента з підкладкою та корпусом за рахунок теплопровідності та випромінювання (Вт/К);
- `\eta` — коефіцієнт поглинання інфрачервоного випромінювання поверхневим чорним покриттям (золота чернь або оксиди металів, `0 < \eta \le 1`);
- `\omega = 2 \pi f` — колова частота оптичної модуляції випромінювання.

Шукаємо стаціонарний розв'язок теплового рівняння у вигляді гармонічних коливань температури `\Delta T(t) = \Delta T_0 e^{i \omega t}`:

```
(i \omega C_{th} + G_{th}) \Delta T_0 e^{i \omega t} = \eta P_0 e^{i \omega t}
= (G_{th} + i \omega C_{th}) \Delta T_0 = \eta P_0                     [скорочення часового множника e^{i \omega t}]
= \Delta T_0 = \eta P_0 / (G_{th} + i \omega C_{th})                  [вираження комплексної амплітуди температури]
```

Модуль амплітуди коливань температури елемента дорівнює:

```
|\Delta T(\omega)|
= \eta P_0 / \sqrt{G_{th}^2 + \omega^2 C_{th}^2}                       [обчислення модуля комплексного числа]
= (\eta P_0 / G_{th}) / \sqrt{1 + \omega^2 \tau_{th}^2}               [введення теплової сталої часу \tau_{th} = C_{th} / G_{th}]
```

де `\tau_{th} = C_{th} / G_{th}` — теплова стала часу детектора, яка визначає інерційність теплообміну (для тонкоплівкових елементів `\tau_{th} \approx 10 \dots 100` мс, для масивних монокристалів `\tau_{th} \approx 0.5 \dots 2.0` с).

Аналіз граничних режимів теплового балансу детектора:
- **Низькочастотний режим (`\omega \ll 1/\tau_{th}`):** `|\Delta T| \approx \eta P_0 / G_{th}`. Температура кристала повністю встигає відстежувати зміни падаючого теплового потоку, але швидкість зміни температури `d T / d t` дуже мала;
- **Високочастотний (адіабатичний) режим (`\omega \gg 1/\tau_{th}`):** `|\Delta T| \approx \eta P_0 / (\omega C_{th})`. Теплообмін із корпусом не встигає відбутися, амплітуда коливань температури спадає обернено пропорційно частоті модуляції `1/\omega`.

```
Коливання температури ΔT(ω):
 ├── High G_th, low ω (f < 1/2πτ_th) → ΔT = η P_0 / G_th (Стаціонарний кондуктивний режим)
 └── High C_th, high ω (f > 1/2πτ_th) → ΔT = η P_0 / (ω C_th) (Адіабатичний режим накопичення)
```

## Генерація піроелектричного струму та частотна характеристика електричного кола

Зміна спонтанної поляризації кристала при зміні температури викликає зміну зв'язаного поверхневого заряду `Q_b(t) = A \cdot P_s(t) = A \cdot p \cdot \Delta T(t)`. Переміщення вільних компенсаційних зарядів між металевими електродами генерує у зовнішньому колі питомий піроелектричний струм:

```
i_p(t)
= d Q_b / d t
= A \cdot p \cdot (d \Delta T / d t)                                   [диференціювання заряду за часом]
= A \cdot p \cdot i \omega \Delta T_0 e^{i \omega t}                    [підстановка гармонічної похідної d/dt → i \omega]
```

Підставляючи комплексний розв'язок для амплітуди температури `\Delta T_0`, отримуємо комплексний піроелектричний струм:

```
i_p(\omega)
= i \omega A p \eta P_0 / (G_{th} + i \omega C_{th})                    [підстановка комплексної температури]
= (i \omega A p \eta P_0 / G_{th}) / (1 + i \omega \tau_{th})           [приведення до нормованого вигляду з \tau_{th}]
```

Модуль амплітуди генерованого піроелектричного струму:

```
|i_p(\omega)|
= (\omega A p \eta P_0) / \sqrt{G_{th}^2 + \omega^2 C_{th}^2}          [обчислення модуля струму]
= (A p \eta P_0 / C_{th}) \cdot (\omega \tau_{th} / \sqrt{1 + \omega^2 \tau_{th}^2}) [виділення високочастотного плато струму]
```

У еквівалентній електричній схемі піроелектричний сенсор представляє собою джерело струму `i_p(\omega)`, зашунтоване власною ємністю кристала `C_s` та опором витоку діелектрика `R_s`, яке ввімкнене на вхідний опір затвора підсилювача `R_{in}` та ємність монтажу `C_{in}`.

Загальний еквівалентний опір та ємність вхідного вузла дорівнюють:

```
R_e = (R_s \cdot R_{in}) / (R_s + R_{in}) \approx R_{in}                 [паралельне з'єднання опорів, оскільки R_s >> R_{in}]
C_e = C_s + C_{in}                                                      [паралельне з'єднання ємностей]
```

Еквівалентний комплексний імпеданс вхідного паралельного кола:

```
Z_e(\omega) = R_e / (1 + i \omega R_e C_e) = R_e / (1 + i \omega \tau_e)
```

де `\tau_e = R_e C_e` — електрична стала часу кола (для високоомного затвора JFET `R_{in} \approx 50` ГОм, `C_e \approx 10` пФ, отже `\tau_e \approx 0.5` с).

Вихідна напруга підсилювального каскаду `V_{out}(\omega) = i_p(\omega) \cdot Z_e(\omega)`:

```
V_{out}(\omega)
= [(i \omega A p \eta P_0 / G_{th}) / (1 + i \omega \tau_{th})] \cdot [R_e / (1 + i \omega \tau_e)] [множення струму на імпеданс]
= (i \omega A p \eta P_0 R_e / G_{th}) / [(1 + i \omega \tau_{th}) (1 + i \omega \tau_e)]            [об'єднання знаменників]
```

Вольтова чутливість детектора (Voltage Responsivity) `R_v(\omega) = |V_{out}(\omega)| / P_0` становить:

```
R_v(\omega)
= (\omega A p \eta R_e / G_{th}) / [\sqrt{1 + \omega^2 \tau_{th}^2} \sqrt{1 + \omega^2 \tau_e^2}]   [модуль вольтової чутливості В/Вт]
```

Аналіз трьох характерних частотних областей чутливості `R_v(\omega)`:

1. **Область низьких частот (`\omega < 1/\tau_{th}`):** `R_v(\omega) \propto \omega`. Чутливість лінійно зростає зі швидкістю `+20` дБ/декаду завдяки фактору похідної температури `d \Delta T / d t`;
2. **Робоча область середніх частот (`1/\tau_{th} < \omega < 1/\tau_e`):** `R_v(\omega) \approx \text{const}`. Чутливість виходить на максимальне плато:
   ```
   R_{v, \text{max}} = (A p \eta R_e) / (C_{th} R_e / \tau_e) = (\eta p) / (c_v d C_e / A)
   ```
3. **Область високих частот (`\omega > 1/\tau_e`):** `R_v(\omega) \propto 1/\omega`. Чутливість спадає зі швидкістю `-20` дБ/декаду через шунтування сигналу вхідною ємністю `C_e`.

```
Частотний діапазон вольтової чутливості R_v:
 ├── f < f_th (f < 1/2πτ_th)   → Підйом +20 дБ/дек (Низька швидкість зміни T)
 ├── f_th < f < f_e             → Плато R_v,max = (η p)/(c_v · d · C_e) (Робочий діапазон)
 └── f > f_e (f > 1/2πτ_e)    → Спад -20 дБ/дек (Шунтування ємністю C_e)
```

## Добротність матеріалів (Figures of Merit, FOM) та аналіз шумів

Для об'єктивного порівняння ефективності різних піроелектричних матеріалів у конкретних схемотехнічних режимах підсилення використовуються три термодинамічні показники якості (Figures of Merit):

1. **Добротність за струмовою чутливістю `F_i`:**
   Застосовується під час роботи детектора з трансімпедансним підсилювачем струму (з низьким вхідним опором `R_{in} \to 0`):
   ```
   F_i = p / c_v                                                        [відношення піроелектричного коефіцієнта до об'ємної теплоємності]
   ```

2. **Добротність за вольтовою чутливістю `F_v`:**
   Застосовується під час роботи з підсилювачем напруги на базі польового транзистора (з високим вхідним опором `R_{in} \gg 1` ГОм):
   ```
   F_v = p / (c_v \cdot \varepsilon_r \varepsilon_0)                     [нормування на діелектричну проникність матеріалу]
   ```
   Матеріали з відносно низькою діелектричною проникністю `\varepsilon_r` (такі як `\text{LiTaO}_3` або `\text{PVDF}`) забезпечують значно вищу напругу сигналу при тому самому тепловому потоці, ніж високоефективна кераміка `\text{PZT}` з високим значенням `\varepsilon_r`.

3. **Добротність за виявною здатністю `F_m` (з урахуванням діелектричних втрат):**
   Визначає граничне відношення сигналу до теплового шуму Джонсона-Найквіста в діелектрику (визначеного тангенсом кута діелектричних втрат `\tan \delta`):
   ```
   F_m = p / (c_v \sqrt{\varepsilon_r \varepsilon_0 \tan \delta})       [максимізація відношення сигнал/шум]
   ```

Порівняльний розрахунок добротності `F_v` для двох типових матеріалів:
- **Танталат літію (`\text{LiTaO}_3`):** `p = 2.3 \cdot 10^{-4}` Кл/(м²·К), `c_v = 3.2 \cdot 10^6` Дж/(м³·К), `\varepsilon_r = 47`.
  ```
  F_v = (2.3 \cdot 10^{-4}) / (3.2 \cdot 10^6 \cdot 47 \cdot 8.854 \cdot 10^{-12}) = 0.173 м²/Кл
  ```
- **Сегнетокераміка PZT-5H:** `p = 11.0 \cdot 10^{-4}` Кл/(м²·К), `c_v = 2.7 \cdot 10^6` Дж/(м³·К), `\varepsilon_r = 3400`.
  ```
  F_v = (11.0 \cdot 10^{-4}) / (2.7 \cdot 10^6 \cdot 3400 \cdot 8.854 \cdot 10^{-12}) = 0.0135 м²/Кл
  ```

Отже, незважаючи на вп'ятеро вищий піроелектричний коефіцієнт `p` у кераміки PZT, монокристал танталату літію `\text{LiTaO}_3` забезпечує у 12.8 разів вищу вольтову чутливість завдяки низькій діелектричній проникності `\varepsilon_r`.

Гранична еквівалентна потужність шуму (Noise Equivalent Power, `NEP`) визначається квадратичною сумою трьох джерел шумів:
```
NEP_{\text{total}} = \sqrt{NEP_{\text{th}}^2 + NEP_{\text{dielectric}}^2 + NEP_{\text{amplifier}}^2}
```
де `NEP_{\text{th}} = \sqrt{4 k_B T^2 G_{th}} / \eta` — фундаментальна межа теплових флуктуацій фону.
