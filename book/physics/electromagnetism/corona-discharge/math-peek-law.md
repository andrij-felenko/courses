# 🧮 Математика коронного розряду: розподіл полів, закони Піка та умови Таунсенда

Ця вставка містить виведення математичних співвідношень, що описують коронний розряд: розподіл електричного поля у циліндричній та площинній геометріях, умову самопідтримання Таунсенда для неоднорідного газу, фізичне обґрунтування та розрахунок порогового поля за емпіричними формулами Піка, а також кількісний аналіз втрат потужності у високовольтних мережах.

### 1. Розподіл електричного поля та потенціалу у циліндричній геометрії

Розглянемо коаксіальну систему з двох циліндричних електродів: внутрішній дріт радіуса `r₀` та зовнішній заземлений циліндр радіуса `R`. До дроту прикладено напругу `U` відносно циліндра.

За теоремою Гаусса для лінійної густини заряду `λ` на одиницю довжини дроту потік вектора електричної напруженості через циліндричну поверхню радіуса `r` (`r₀ ≤ r ≤ R`) довжиною `L` дорівнює:

```
∮ E · dA = E(r) · (2 · π · r · L) = (λ · L) / ε₀
```

Звідси напруженість електричного поля на відстані `r` від осі дорівнює:

```
E(r) = λ / (2 · π · ε₀ · r)
```

Різниця потенціалів (напруга) `U` між внутрішнім дротом та зовнішнім циліндром визначається інтегруванням напруженості поля від поверхні дроту `r₀` до поверхні циліндра `R`:

```
U = ∫ [r₀..R] E(r) dr = (λ / (2 · π · ε₀)) · ∫ [r₀..R] (1 / r) dr
U = (λ / (2 · π · ε₀)) · ln(R / r₀)
```

Виражаючи лінійну густину заряду `λ = (2 · π · ε₀ · U) / ln(R / r₀)` та підставляючи її у вираз для `E(r)`, отримуємо розподіл поля:

```
E(r) = U / (r · ln(R / r₀))
```

Максимальна напруженість досягається безпосередньо на поверхні внутрішнього провідника при `r = r₀`:

```
E_max = E(r₀) = U / (r₀ · ln(R / r₀))
```

Розподіл потенціалу `φ(r)` відносно заземленого зовнішнього циліндра (`φ(R) = 0`) має вигляд:

```
φ(r) = U · ln(R / r) / ln(R / r₀)
```

Ємність такої циліндричної системи на одиницю довжини становить:

```
C_len = λ / U = (2 · π · ε₀) / ln(R / r₀)
```

#### Поле у геометрії «дріт над заземленою площиною»

Для лінії електропередачі з дротом радіуса `r₀`, розміщеним на висоті `h >> r₀` над заземленою землею, застосовується метод дзеркальних зображень. Вплив заземленої поверхні замінюється фіктивним провідником із протилежним зарядом `-λ` на глибині `-h`.

Напруженість поля в точці на поверхні дроту, найближчій до землі, становить:

```
E_max = U / (r₀ · ln(2h / r₀))
```

А напруженість електричного поля безпосередньо на поверхні землі під дротом у точці `x = 0` дорівнює:

```
E_ground = (2 · U) / (h · ln(2h / r₀))
```

Оскільки `h >> r₀`, напруженість поля на поверхні землі `E_ground` у сотні разів менша за напруженість на поверхні дроту `E_max`. Це пояснює, чому коронний розряд виникає виключно біля дроту, а простір біля землі залишається безпечною зоною слабкого поля.

### 2. Критерій самопідтримання розряду Таунсенда у неоднорідному полі

У нерівномірному полі коефіцієнт об'ємної іонізації Таунсенда `α` залежить від локального значення напруженості `E(r)`. Зростання кількості електронів `N(r)` уздовж силової лінії від поверхні катода `r₀` до межі чехла корони `r_i` визначається інтегралом:

```
N(r_i) = N(r₀) · exp( ∫ [r₀..r_i] α(E(r)) dr )
```

Умова самопідтримання коронного розряду полягає у тому, що вторинні електрони, утворені фотоіонізацією газу або емісією з катода з коефіцієнтом `γ`, повинні повністю відновлювати початкову кількість електронів:

```
γ · [ exp( ∫ [r₀..r_i] α(E(r)) dr ) - 1 ] = 1
```

Логарифмуючи це співвідношення, отримуємо інтегральний критерій коронування:

```
∫ [r₀..r_i] α(E(r)) dr = ln(1 + 1 / γ) = K_ion
```

де `K_ion ≈ 8...10` для повітря при атмосферному тиску. Межа чехла корони `r_i` знаходиться з умови, що на відстані `r_i` локальне поле опускається до значення `E(r_i) = E_c`, при якому `α(E_c) = 0`.

Для повітря коефіцієнт Таунсенда `α` добре апроксимується емпіричною формулою Таунсенда-Шона:

```
α / p = A_gas · exp( -B_gas · p / E )
```

де для повітря `A_gas ≈ 15 см⁻¹·мм рт. ст.⁻¹ = 1125 м⁻¹·кПа⁻¹`, а `B_gas ≈ 365 В/(см·мм рт. ст.) = 27375 В/(м·кПа)`.

Підстановка цього виразу в інтегральний критерій дає аналітичний зв'язок між радіусом дроту `r₀` та критичним полем запалювання `E_c`.

### 3. Емпіричний закон Піка для порогової напруженості

Американський інженер Френсіс Пік на основі тисяч вимірювань вивів аналітичний вираз для критичної напруженості виникнення корони `E_c` на циліндричному дроті радіуса `r₀`:

```
E_c = m₀ · E₀ · δ · (1 + K / √(δ · r₀))
```

де:
- `E₀ = 3.1 × 10⁶ В/м` (або `31 кВ/см`) — пробійна міцність однорідного поля у повітрі,
- `K = 0.0308 м¹/²` (або `0.308 см¹/²`) — емпіричний масштабний коефіцієнт,
- `δ` — відносна густина повітря, що залежить від тиску `P` (мм рт. ст.) та температури `T` (°C):

```
δ = (293 / (273 + T)) · (P / 760)
```

- `m₀` — коефіцієнт шорсткості поверхні провідника (`0.30 ≤ m₀ ≤ 1.0`).

#### Фізичний зміст поправки Піка `1 / √(r₀)`

Причина, чому критичне поле `E_c` для тонкого дроту вище за `E₀`, полягає у вимозі до мінімальної довжини іонізаційного шляху. Для того щоб електронна лавина досягла критичного розміру `N_crit ≈ 10⁸` електронів (критерій Стримера), електрон мусить пройти у надпороговому полі `E > E₀` певну мінімальну відстань `Δr = r_i - r₀`.

Біля товстого дроту поле спадає повільно, тому при `E(r₀) = E₀` зона надпорогового поля вже є достатньо широкою для розвитку лавини. Біля дуже тонкого дроту поле спадає настільки стрімко, що при `E(r₀) = E₀` товщина надпорогової зони становить лише кілька мікронів — цього недостатньо для формування лавини. Щоб розширити чехол іонізації до необхідної товщини `Δr`, напруженість на самій поверхні дроту мусить бути піднята вище `E₀`. Емпіричний член `K / √(r₀)` у формулі Піка якраз кількісно враховує цю додаткову напруженість, необхідну для формування критичної лавини у вузькому шарі.

Порогова напруга запалювання корони `U_c` отримується множенням `E_c` на геометричний чинник `r₀ · ln(R / r₀)`:

```
U_c = E_c · r₀ · ln(R / r₀)
```

#### Числовий приклад 1: Розрахунок порогової напруги для дроту

Обчислити порогову напругу запалювання корони `U_c` для багатожильного дроту радіуса `r₀ = 1.2 см` (`0.012 м`), натягнутого всередині циліндра радіуса `R = 2.0 м` при температурі `T = 20 °C`, тиску `P = 760 мм рт. ст.` та коефіцієнті шорсткості `m₀ = 0.85`.

Крок 1: Розрахунок відносної густини повітря `δ`:

```
δ = (293 / (273 + 20)) · (760 / 760) = 1.00
```

Крок 2: Обчислення критичної напруженості Піка `E_c`:

```
E_c = 0.85 · 3.1 × 10⁶ · 1.00 · (1 + 0.0308 / √(0.012))
E_c = 2.635 × 10⁶ · (1 + 0.0308 / 0.10954)
E_c = 2.635 × 10⁶ · (1 + 0.2812)
E_c = 2.635 × 10⁶ · 1.2812 ≈ 3.376 × 10⁶ В/м = 33.76 кВ/см
```

Крок 3: Розрахунок порогової напруги `U_c`:

```
ln(R / r₀) = ln(2.0 / 0.012) = ln(166.67) ≈ 5.116
U_c = E_c · r₀ · ln(R / r₀)
U_c = 3.376 × 10⁶ · 0.012 · 5.116 ≈ 207 240 В ≈ 207.2 кВ
```

### 4. Розрахунок втрат потужності на коронування за формулою Піка

Втрати потужності `P_{loss}` на один кілометр довжини однієї фази ЛЕП при напрузі фаза–земля `U > U_c` та частоті `f` задаються формулою Піка:

```
P_{loss} = (242.2 / δ) · (f + 25) · √(r₀ / D) · (U - U_c)² · 10⁻⁵   [кВт / км]
```

де:
- `f` — частота мережі (Гц),
- `D` — міжфазна відстань (м),
- `U` — діюча фазна напруга (кВ),
- `U_c` — фазна напруга запалювання корони (кВ).

#### Числовий приклад 2: Втрати потужності у ЛЕП 500 кВ під час зливи

Лінія електропередачі напругою `U_line = 500 кВ` (діюча лінійна напруга) працює на частоті `f = 50 Гц`. 
Фазна напруга становить `U = U_line / √3 = 500 / 1.732 ≈ 288.7 кВ`.
Відстань між фазами `D = 10 м`, радіус провідника `r₀ = 1.5 см` (`0.015 м`).

Припустимо, що у суху погоду (`m₀ = 0.88`) порогова напруга становить `U_c = 320 кВ`. Оскільки `U (288.7 кВ) < U_c (320 кВ)`, втрати в суху погоду дорівнюють нулю.

Під час сильного дощу краплі знижують коефіцієнт шорсткості до `m₀ = 0.45`.
Нове значення критичного поля `E_c` знижується пропорційно `0.45 / 0.88`:

```
U_c_rain = 320 кВ · (0.45 / 0.88) ≈ 163.6 кВ
```

Тепер фазна напруга `U = 288.7 кВ` значно перевищує поріг `U_c_rain = 163.6 кВ`.

Обчислимо втрати потужності на 1 км однієї фази при `δ = 1`:

```
ΔU = U - U_c_rain = 288.7 - 163.6 = 125.1 кВ
(ΔU)² = 125.1² ≈ 15 650 кВ²

√(r₀ / D) = √(0.015 / 10) = √0.0015 ≈ 0.03873

P_{loss} = (242.2 / 1) · (50 + 25) · 0.03873 · 15 650 · 10⁻⁵
P_{loss} = 242.2 · 75 · 0.03873 · 0.1565
P_{loss} = 18 165 · 0.03873 · 0.1565 ≈ 110.1 кВт / км на фазу
```

Для трьох фаз трифазної лінії 500 кВ загальні втрати під час дощу становлять:

```
P_total = 3 · 110.1 кВт/км ≈ 330.3 кВт / км
```

На трасі довжиною 300 км загальні втрати потужності в атмосферу становлять близько **99 МВт**, що еквівалентно потужності цілої електростанції!

### 5. Еквівалентне розщеплення фаз: розрахунок еквівалентного радіуса

Для пригнічення коронування на лініях 500 кВ і вище кожну фазу виконують у вигляді пучка з `n` проводів радіуса `r₀`, розташованих по колу радіуса `R_bundle` (відстань між сусідніми проводами `a`).

Еквівалентний радіус розщепленого пучка `r_eq` обчислюється за формулою:

```
r_eq = ( n · r₀ · R_bundle^(n-1) )^(1/n)
```

#### Числовий приклад 3: Еквівалентний радіус фази з 3 проводів

Нехай фаза складається з `n = 3` проводів радіуса `r₀ = 1.3 см` (`0.013 м`), розташованих у вершинах рівностороннього трикутника зі стороною `a = 40 см` (`0.4 м`).
Радіус кола розщеплення `R_bundle = a / √3 = 0.4 / 1.732 ≈ 0.2309 м`.

Обчислимо еквівалентний радіус `r_eq`:

```
r_eq = ( 3 · 0.013 · (0.2309)² )^(1/3)
r_eq = ( 0.039 · 0.05331 )^(1/3)
r_eq = ( 0.002079 )^(1/3) ≈ 0.1276 м = 12.76 см
```

Завдяки розщепленню ефективний радіус фази зріс із `1.3 см` до `12.76 см` (майже в 10 разів!).
Завдяки цьому напруженість поля на поверхнях проводів падає далеко нижче критичного порога Піка `E_c`, повністю усуваючи втрати на коронування в суху погоду.
