# 📋 Специфікація коронного розряду: параметри, геометрія та межі стійкості

Ця вставка є технічним довідником та специфікацією параметрів коронного розряду. Вона містить аналітичні геометрії електродів, фізичні сталі іонізації та дрейфу іонів у повітрі, порівняльні характеристики додатної та від'ємної корони, інженерний інтерфейс високовольтних джерел живлення, стандартизовану карту реєстрів Modbus RTU для керування перетворювачами, а також санітарні й електромагнітні нормативи.

### 1. Геометричні конфігурації електродних систем

Розрахунок початкової напруженості коронування `E_c` та порогової напруги `U_c` залежить від просторової симетрії полів. Електричне поле у зазорі визначається розв'язком рівняння Лапласа для скалярного потенціалу з відповідними граничними умовами на поверхнях провідників. У таблиці нижче зведено аналітичні формули для чотирьох базових геометричних конфігурацій, що найчастіше застосовуються у високовольтній техніці та лабораторних дослідженнях.

| Конфігурація електродів | Електричне поле на поверхні `E_max` | Порогова напруга запалювання `U_c` | Ємність на одиницю довжини `C_len` | Типовий сфера застосування |
| :--- | :--- | :--- | :--- | :--- |
| **Коаксіальні циліндри** (дріт радіуса `r₀` у циліндрі `R`) | `E_max = U / (r₀ · ln(R / r₀))` | `U_c = E_c · r₀ · ln(R / r₀)` | `C = 2·π·ε₀ / ln(R / r₀)` | Електрофільтри, газові лічильники Гейгера, труби ESP |
| **Дріт над площиною** (дріт `r₀` на висоті `h >> r₀`) | `E_max ≈ U / (r₀ · ln(2h / r₀))` | `U_c = E_c · r₀ · ln(2h / r₀)` | `C = 2·π·ε₀ / ln(2h / r₀)` | Одноланцюгові ЛЕП, коротрони лазерних принтерів |
| **Два паралельні дроти** (радіус `r₀`, відстань `D >> r₀`) | `E_max ≈ U / (2 r₀ · ln(D / r₀))` | `U_c = E_c · 2 r₀ · ln(D / r₀)` | `C = π·ε₀ / ln(D / r₀)` | Двопровідні лінії передачі, високовольтні шини |
| **Вістря — площина** (радіус вістря `r₀`, відстань `d >> r₀`) | `E_max ≈ 2 U / (r₀ · ln(4d / r₀))` | `U_c ≈ 0.5 E_c · r₀ · ln(4d / r₀)` | `C ≈ 4·π·ε₀ · r₀` | Іонізатори повітря, розрядники, голки озонізаторів |

Аналітичні співвідношення для геометричних конфігурацій виводяться за припущення про суху й чисту поверхню провідників. У коаксіальній циліндричній системі радіальне поле спадає суворо за законом `1/r`. Завдяки радіальній симетрії ця конфігурація є найбільш стійкою для точного вимірювання фізичних характеристик газу. При цьому напруженість на поверхні внутрішнього дроту досягає абсолютного максимуму `E_max`. Як бачимо з формули, зменшення радіуса дроту `r₀` при фіксованій напрузі `U` підвищує поверхневе поле, але одночасно зменшує об'єм чехла корони, що підвищує чинну пробійну міцність `E_c` за формулою Піка.

У конфігурації «дріт над площиною» поле розраховується методом дзеркальних зображень. Вплив заземленої плоскої поверхні враховується введенням фіктивного дзеркального провідника з протилежним знаком заряду на глибині `-h` під площиною. Для високовольтних ліній передачі це співвідношення дає змогу оцінити порогову напругу фаза-земля.

Конфігурація «вістря–площина» створює найсильнішу тривимірну неоднорідність поля. На відміну від двовимірного циліндричного поля, де напруженість спадає як `1/r`, біля сферичного кінчика вістря поле спадає значно швидше — як `1/r²`. Це означає, що чехол корони на вістрі є ще тоншим, ніж на дроті того самого радіуса, а струм корони з вістря спалахує при нижчих загальних напругах `U_c`.

Практичний вибір матеріалу коронуючого електрода визначає його довговічність. У промислових озонізаторах та електрофільтрах використовують голки та дроти з нержавіючої сталі (AISI 316L), титану чи платинованого вольфраму. М'які метали (мідь, алюміній) під дією бомбардування іонами та корозійного впливу озону швидко втрачають гладкість, що призводить до неконтрольованого падіння порогової напруги коронування.

### 2. Фізичні та кінетичні параметри іонів у повітрі

У зоні дрейфу коронного розряду електронні лавини відсутні, а струм переноситься повільним транспортом іонів, які взаємодіють із нейтральними молекулами азоту `N₂`, кисню `O₂` та водяної пари `H₂O`. У таблиці наведено стандартні кінетичні характеристики носіїв заряду при сухій атмосфері, температурі `T = 20 °C` (`293 K`) та тиску `P = 101.3 кПа` (`760 мм рт. ст.`).

| Параметр | Позначення | Додатні іони (`O₂⁺`, `N₂⁺`, `H₃O⁺`) | Від'ємні іони (`O₂⁻`, `CO₃⁻`, `O₃⁻`) | Вільні електрони (`e⁻`) |
| :--- | :--- | :--- | :--- | :--- |
| **Рухливість носіїв** | `K` (або `μ`) | `1.37 ... 1.60 × 10⁻⁴ м²/(В·с)` | `1.80 ... 2.15 × 10⁻⁴ м²/(В·с)` | `0.04 ... 0.12 м²/(В·с)` (в 300 разів вища) |
| **Дрейфова швидкість при `E = 3 кВ/см`** | `v_d = K · E` | `41.1 ... 48.0 м/с` | `54.0 ... 64.5 м/с` | `1.2 ... 3.6 × 10⁴ м/с` |
| **Коефіцієнт дифузії** | `D_diff` | `2.8 ... 3.2 × 10⁻⁶ м²/с` | `3.5 ... 4.2 × 10⁻⁶ м²/с` | `0.01 ... 0.03 м²/с` |
| **Середній час приєднання до `O₂`** | `τ_attach` | не застосовується | `10 ... 50 нс` (при `1 атм`) | перетворення на `O₂⁻` за `~20 нс` |
| **Коефіцієнт рекомбінації іон-іон** | `α_rec` | `1.4 ... 2.0 × 10⁻¹² м³/с` | `1.4 ... 2.0 × 10⁻¹² м³/с` | не застосовується |

Фізична природа відмінностей у рухливості іонів полягає у процесі сольватації та гідратації. Коли молекула кисню чи азоту втрачає електрон і перетворюється на додатний іон `O₂⁺` або `N₂⁺`, її сильне електричне поле притягує й орієнтує дипольні молекули водяної пари `H₂O`, що завжди присутні у повітрі. Навколо первинного іона за мікросекунди формується міцний кластерний шар із 3–6 молекул води — так званий іонний комплекс `H₃O⁺(H₂O)_n`. Через більші масу й ефективний газокінетичний діаметр цей важкий кластер випробовує сильніший опір при зіткненнях із нейтральним газом, тому його рухливість `K₊` становить лише `1.4 × 10⁻⁴ м²/(В·с)`.

Від'ємні іони `O₂⁻` утворюються шляхом захоплення вільного електрона нейтральною молекулою кисню у зоні слабкого поля. Процес приєднання перебігає через проміжний збуджений стан `(O₂⁻)*`, який стабілізується при зіткненні з третьою молекулою газу (тритілесне приєднання). Від'ємні іони менш схильні до утворення великих гідратних оболонок, тому їх середня рухливість `K₋` вища і досягає `1.9 × 10⁻⁴ м²/(В·с)`. Це означає, що при однаковій напрузі та геометрії від'ємний коронний розряд забезпечує на 25–30% вищий струм переносу, ніж додатний.

Вільні електрони мають масу в десятки тисяч разів меншу за масу іонів, тому їх рухливість досягає `0.05 ... 0.12 м²/(В·с)`. У чистих інертних газах (аргон, гелій) чи азоті, де немає електронегативних молекул кисню, електрони не приєднуються і пролітають увесь зазор на величезній швидкості. У таких газах коронний розряд є вкрай нестійким і негайно переходить у стримерний або дуговий пробій. Наявність кисню в атмосфері є природним регулятором, що «гальмує» електрони, перетворюючи їх на повільні негативні іони й роблячи повітряну корону стабільною.

Температурна залежність рухливості іонів задається співвідношенням Ланжевена: `K(T, P) = K₀ · (P₀ / P) · (T / T₀)`. При підвищенні температури газу середня довжина вільного пробігу молекул зростає, що підвищує рухливість іонів та збільшує струм корони. При зниженні тиску (наприклад, у високогірній місцевості на висоті 3000–4000 метрів над рівнем моря) густина повітря `δ` зменшується, що призводить до пропорційного зниження порогової напруги запалювання корони `U_c`. Інженери розраховують високогірні ЛЕП із додатковим запасом за діаметром проводів.

### 3. Порівняльний контрактивний аналіз додатної та від'ємної корони

Зовнішній вигляд, спектральний склад сяйва, рівень генерації озону та часова динаміка струму коронного розряду принципово залежать від полярності високовольтного провідника. Нижче наведено розширений порівняльний аналіз двох режимів.

| Характеристика розряду | Додатна корона (+ на вістрі/дроті) | Від'ємна корона (− на вістрі/дроті) |
| :--- | :--- | :--- |
| **Основний механізм підтримки** | Об'ємна фотоіонізація газу ультрафіолетом | Вторинна електронна емісія з катода |
| **Просторова структура сяйва** | Однорідне, суцільне, рівномірне блакитне сяйво | Плямисте, плямисті «намистини», переривчасті точки |
| **Часова структура струму** | Стаціонарний, безперервний струм без пульсацій | Автоколивальний режим, імпульси Трічеля (100 кГц–2 МГц) |
| **Частота імпульсів Трічеля** | Відсутні | `f_pulse = A · I_corona` (`100 кГц` при 10 мкА, до `3 МГц`) |
| **Тривалість фронту імпульсу** | Не застосовується | `t_rise = 1.5 ... 3.5 нс`, `t_decay = 40 ... 100 нс` |
| **Генерація озону `O₃`** | Низька (`0.01 ... 0.05 г / кВт·год`) | Висока (`0.2 ... 0.8 г / кВт·год`, у 5–10 разів більша) |
| **Рівень радіозавад (RI)** | Низький, переважно білий шум | Високий, виражені гармоніки в діапазоні `0.1 ... 30 МГц` |
| **Механічна стабільність до дуги** | Висока (стійка проти іскрового пробою) | Менша (легше переходить у стримерну дугу) |
| **Основне промислове використання** | Озонізатори, зарядка барабанів принтерів | Електрофільтри (ESP), обробка пластикових плівок |

При додатній полярності коронуючий дріт працює як анод. Електрони, розганяючись до дроту, викликають інтенсивну іонізацію газу у чехлі. Збуджені атоми азоту випромінюють фотони ультрафіолетового діапазону (довжини хвиль 98–102 нм), які мають достатню енергію для іонізації сусідніх молекул кисню в об'ємі чехла. Цей процес фотоіонізації відбувається рівномірно по всьому об'єму чехла, забезпечуючи стабільну генерацію нових первинних електронів без прив'язки до конкретних мікрогеометричних дефектів поверхні металу. Саме тому додатна корона палає як суцільний, гладкий, оксамитовий фіолетовий шар без тріску й пульсацій.

При від'ємній полярності коронуючий дріт є катодом. Лавини ростуть від поверхні металу назовні. Початкові електрони вибиваються безпосередньо з металу під дією бомбардування позитивними іонами. Оскільки поверхня будь-якого реального дроту має мікроскопічні нерівності, подряпини чи оксидні плівки з різною роботою виходу електрона, катодна емісія локалізується у конкретних активних центрах. Розряд розпадається на окремі світні «намистини» чи язички, які постійно хаотично пересуваються вздовж провідника.

Утворення імпульсів Трічеля у від'ємній короні є яскравим прикладом саморегульованих автоколивань плазми. Кожен імпульс починається з вильоту первинного електрона з катода. У високому полі біля вістря він породжує швидкозростаючу лавину. Легкі електрони швидко вилітають за межі чехла, де захоплюються молекулами кисню, утворюючи негативні іони `O₂⁻`. Важкі позитивні іони `N₂⁺` та `O₂⁺` залишаються біля катода. Через деякий час від'ємні іони формують просторовий шар заряду на відстані кількох міліметрів від вістря. Цей шар створює власне поле, напрямлене проти зовнішнього поля катода. Напруженість на кінчику вістря падає нижче критичного значення `E_c`, і лавинне розмноження припиняється. Струм падає до нуля. Розряд «чекає», поки зовнішнє поле не відтягне хмару `O₂⁻` далі до анода. Як тільки просторовий шар розсіюється, поле на вістрі знову піднімається вище `E_c`, і спалахує наступний імпульс.

### 4. Інженерний інтерфейс високовольтного джерела живлення корони

У таблиці наведено специфікацію параметрів керування та електричного контракту промислового джерела живлення для систем коронного розряду (наприклад, для електростатичного фільтра або лабораторного озонізатора).

| Параметр / Інтерфейс | Діапазон / Специфікація | Опис та інженерні вимоги |
| :--- | :--- | :--- |
| **Вихідна напруга `U_out`** | `0 ... 30.0 кВ DC` (полярність визначається замовленням) | Плавне регулювання ШІМ із точністю не гірше 0.5% |
| **Вихідний струм `I_out`** | `0 ... 2.00 мА` (постійний струм) | Захист від перевантаження за струмом та ПІД-стабілізація |
| **Частота пульсацій напруги** | `< 0.5%` при повному навантаженні | Вбудований високовольтний RC-фільтр згладжування |
| **Швидкодія захисту від пробою `t_trip`** | `< 10 мкс` (апаратна відсічка) | Негайне блокування ШІМ при переході корони у дугу |
| **Час відновлення після пробою** | `20 ... 100 мс` (програмований) | Автоматичний Soft-start після згасання іскрового каналу |
| **Інтерфейс аналогового керування** | `0 ... 10 В` або `4 ... 20 мА` | `0 В = 0 кВ`, `10 В = 30 кВ` (вхідний опір `100 кОм`) |
| **Інтерфейс цифрового зв'язку** | RS-485 / Modbus RTU або CANopen | Зчитування виміряних напруги, струму, лічильника дуг |
| **Аналоговий вихід моніторингу струму** | `0 ... 5 В` (масштаб `1 В = 400 мкА`) | Гальванічно розв'язаний вихід для підключення осцилографа |
| **Робочий діапазон температур** | `-20 °C ... +50 °C` | Примусове повітряне охолодження радіаторів ключових FET |

Проєктування високовольтного джерела живлення коронного розряду вимагає врахування нелінійного характеру навантаження. До досягнення порогової напруги `U_c` коронна система поводиться як чисто ємнісне навантаження з опором витоку понад 100 Гігаом. Як тільки напруга перевищує `U_c`, еквівалентний опір зазору різко падає, і струм починає зростати за квадратичним законом Таунсенда.

Джерело живлення мусить працювати у двох комбінованих режимах: стабілізації напруги (CV) на етапі підходу до порога та стабілізації струму (CC) у робочому режимі коронування. Для промислових електрофільтрів найбільш ефективним є режим роботи на самій межі іскроутворення (*peak-seeking control*). Автоматика джерела повільно піднімає напругу до появи поодиноких мікроіскор, після чого швидко скидає напругу на 3–5% і підтримує максимальний можливий струм корони для забезпечення найвищого заряду частинок пилу.

Важливим технічним вузлом джерела є схема гасіння зворотного викиду енергії при згасанні іскри. При виникненні мікропробою накопичена в ємності високовольтного кабелю та помножувача енергія `E_cap = 0.5 · C · U²` скидається у пробійний канал. Джерело мусить містити обмежувальний високовольтний безинудктивний резистор (наприклад, 10–50 кОм), який лімітує амплітуду розрядного струму й захищає високовольтні діоди помножувача від деградації.

### 5. Специфікація реєстрів Modbus RTU для джерела живлення корони

Для інтеграції високовольтного джерела у промислові системи АСУ ТП (Scada) використовується стандартний протокол Modbus RTU над інтерфейсом RS-485 (швидкість 9600–115200 бод, 8N1). У таблиці нижче наведено карту оперативних реєстрів зберігання (*Holding Registers*, функція `0x03` читання, `0x06` / `0x16` запис).

| Адреса реєстру (Hex / Dec) | Назва параметра | Тип даних | Одиниці вимірювання | Опис та діапазон значень |
| :--- | :--- | :--- | :--- | :--- |
| `0x0000` (0) | `REG_CONTROL_WORD` | `uint16` | бітова маска | Біт 0: `1` = Увімкнути HV, `0` = Вимкнути HV;<br>Біт 1: `1` = Скинути помилку пробою (Reset Fault);<br>Біт 2: `1` = Увімкнути автоперезапуск після дуги. |
| `0x0001` (1) | `REG_SETPOINT_VOLTAGE` | `uint16` | `0.1 кВ` | Цільова напруга `0 ... 300` (відповідає `0.0 ... 30.0 кВ`). |
| `0x0002` (2) | `REG_SETPOINT_CURRENT` | `uint16` | `1 мкА` | Цільовий ліміт струму `10 ... 2000` мкА. |
| `0x0003` (3) | `REG_TRIP_CURRENT_LIMIT` | `uint16` | `1 мкА` | Поріг апаратної відсічки дуги `500 ... 2500` мкА. |
| `0x0004` (4) | `REG_RECOVERY_TIME_MS` | `uint16` | `1 мс` | Пауза відновлення після пробою `10 ... 1000` мс. |
| `0x0010` (16) | `REG_MEASURED_VOLTAGE` | `uint16` | `0.1 кВ` | Фактична виміряна напруга (read-only). |
| `0x0011` (17) | `REG_MEASURED_CURRENT` | `uint16` | `1 мкА` | Фактичний виміряний струм корони (read-only). |
| `0x0012` (18) | `REG_STATUS_WORD` | `uint16` | бітова маска | Біт 0: HV активна;<br>Біт 1: Режим ПІД-стабілізації струму;<br>Біт 2: Спрацював захист від дуги (Arc Trip);<br>Біт 3: Перегрів радіатора (`T > 75 °C`). |
| `0x0013` (19) | `REG_ARC_COUNTER_LOW` | `uint16` | лічильник | Молодше слово лічильника дугових спалахів. |
| `0x0014` (20) | `REG_ARC_COUNTER_HIGH` | `uint16` | лічильник | Старше слово лічильника дугових спалахів. |

Програмна керуюча система верхнього рівня опитує реєстри `REG_MEASURED_VOLTAGE` та `REG_MEASURED_CURRENT` із періодом 10–50 мілісекунд для побудови вольт-амперних характеристик (ВАХ) коронного розряду у реальному часі. Зміна нахилу ВАХ дає змогу оцінити ступінь забруднення осаджувальних пластин у електрофільтрі або знос коронуючих голок в озонізаторі. Реєстри лічильника пробоїв `REG_ARC_COUNTER` дозволяють вести статистику аварійних подій за зміну й сигналізувати про необхідність технічного обслуговування.

При побудові промислових систем керування декількома високовольтними блоками джерел живлення Modbus-шину об'єднують у захищений екранована кручена пара з термінуючими резисторами 120 Ом на кінцях лінії. Оскільки високовольтні мікророзряди можуть створювати потужні імпульсні завади на шині RS-485, трансивери зв'язку оснащують оптронами гальванічної розв'язки з ізоляційною міцністю не менше 2.5 кіловольт та TVS-діодами для захисту диференційних ліній A і B.

### 6. Нормативні обмеження радіозавад та санітарні норми озону

Експлуатація обладнання з коронним розрядом регулюється суворими міжнародними стандартами електромагнітної сумісності (EMC) та екологічної безпеки.

#### Граничні рівні радіозавад (Стандарт CISPR 18-2 / IEEE 430)

Високовольтні лінії електропередачі та високовольтні установки піддаються вимірюванню квазіпіковим детектором на відстані 10 метрів від крайнього провідника:

```
Частота 0.5 МГц:  граничний рівень RI ≤ 45 дБмкВ/м (у суху погоду)
Частота 1.0 МГц:  граничний рівень RI ≤ 40 дБмкВ/м
Частота 10.0 МГц: граничний рівень RI ≤ 30 дБмкВ/м
```

*Примітка:* Рівень завад вимірюється у децибелах відносно 1 мікровольта на метр: `дБмкВ/м = 20 · log₁₀(E_uv / 1 мкВ/м)`.

Вимірювання радіозавад від коронного розряду проводиться за допомогою вимірювального приймача з квазіпіковим детектором, що має постійну часу заряду 1 мс та постійну часу розряду 160 мс згідно зі специфікацією CISPR 16. Оскільки імпульси Трічеля у від'ємній короні мають тривалість фронту всього 1.5–3 наносекунди, їх спектральна щільність охоплює радіодіапазони від 150 кілогерц до 30 мегагерц, створюючи завади для амплітудно-модульованого (AM) радіомовлення та службового радіозв'язку.

#### Санітарно-гігієнічні норми концентрації озону `O₃`

Озон є токсичним газом першого класу небезпечності. При роботі побутових іонізаторів, копирувальної техніки та промислових озонізаторів концентрація озону у робочій зоні регулюється стандартами OSHA (США) та ДСН України:

```
Гранично допустима концентрація (ГДК) у робочій зоні:  0.1 мг/м³ (0.05 ppm)
Максимально разова ГДК у атмосферному повітрі:       0.16 мг/м³
Середньодобова ГДК у житлових приміщеннях:            0.03 мг/м³ (0.015 ppm)
Поріг відчуття запаху озону людиною:                  0.02 мг/м³ (0.01 ppm)
```

При перевищенні концентрації `0.2 мг/м³` озон викликає подразнення дихальних шляхів, кашель та головний біль. Саме тому всі сучасні лазерні принтери та озонізатори оснащуються каталітичними вугільними фільтрами розкладу озону (`2 O₃ → 3 O₂`).

### 7. Приклад розрахунку струму корони за формулою Таунсенда

Струм коронного розряду `I` у циліндричній геометрії при напрузі `U`, що перевищує порогову напругу `U_c`, описується класичною формулою Таунсенда:

```
I = A · U · (U - U_c)
```

де `A` — геометрично-динамічна стала розряду:

```
A = (8 · π · ε₀ · K) / (R² · ln(R / r₀))
```

де `K` — рухливість іонів у газі (`м²/(В·с)`), `R` — радіус зовнішнього електрода, `r₀` — радіус короновучого дроту.

#### Числовий розрахунок для лаборатоного озонізатора

Нехай дріт радіуса `r₀ = 0.2 мм` (`2 × 10⁻⁴ м`) розміщено по осі циліндричної труби радіуса `R = 2.0 см` (`0.02 м`).
Довжина труби `L = 0.5 м`. Рухливість негативних іонів `K = 1.9 × 10⁻⁴ м²/(В·с)`.
Порогова напруга корони для даного дроту становить `U_c = 6.2 кВ`.
Прикладено робочу від'ємну напругу `U = 10.0 кВ`.

Обчислимо сталу `A` на одиницю довжини:

```
ln(R / r₀) = ln(0.02 / 0.0002) = ln(100) ≈ 4.605
R² = (0.02)² = 0.0004 м²

8 · π · ε₀ · K = 8 · 3.14159 · 8.854 × 10⁻¹² · 1.9 × 10⁻⁴
= 4.228 × 10⁻¹⁴   [А·м / В²]

A_len = 4.228 × 10⁻¹⁴ / (0.0004 · 4.605)
A_len = 4.228 × 10⁻¹⁴ / 0.001842 ≈ 2.295 × 10⁻¹¹   [А / В² на метр]
```

Для всієї довжини `L = 0.5 м`:

```
A_total = A_len · L = 2.295 × 10⁻¹¹ · 0.5 ≈ 1.148 × 10⁻¹¹   [А / В²]
```

Тепер обчислимо струм корони `I`:

```
U = 10 000 В
U - U_c = 10 000 - 6 200 = 3 800 В

I = A_total · U · (U - U_c)
I = 1.148 × 10⁻¹¹ · 10 000 · 3 800
I = 1.148 × 10⁻¹¹ · 38 000 000
I ≈ 4.36 × 10⁻⁴ А = 436 мкА
```

Потужність, що виділяється у коронному розряді озонізатора:

```
P = U · I = 10 000 В · 4.36 × 10⁻⁴ А = 4.36 Вт
```

Цей розрахунок показує, що при напрузі 10 кВ струм корони досягає сотень мікроампер, створюючи стабільне споживання потужності в кілька ватів при абсолютній відсутність високотемпературного дугового пробою.
