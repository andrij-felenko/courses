# 🔌 Давачі магнітного поля на магнітоопорі: від містка Уітстона до компенсованого струму

Магніторезистивні давачі (AMR, GMR та TMR) перетворюють вектор магнітного поля на електричний сигнал із чутливістю, яка у 10–100 разів перевищує класичні напівпровідникові давачі Холла. Проте створення точного й стабільного давача вимагає вирішення трьох складних інженерних задач: температурного дрейфу опору, нелінійності залежності від кута та магнітного гістерезису феромагнетика. У цьому матеріалі розглянуто типову архітектуру та схемотехнічні прийоми побудови магніторезистивних компонентів.

---

### 1. Міст Уітстона як основа термокомпенсації

Поодинокий магніторезистивний елемент має власний електричний опір `R0` (зазвичай від 1 кОм до 100 кОм) і позитивний температурний коефіцієнт опору (ТКО) металу (близько `+0.4% / °C`). Оскільки корисна зміна опору в полях геомагнітного масштабу (десятки мікротесла) становить лише частки відсотка, температурна зміна опору в десятки разів перевищує магнітний сигнал.

Для вилучення синфазного температурного зсуву 4 резистивні елементи об'єднують у **повний вимірювальний міст Уітстона**:

```
           +V_supply
              │
       ┌──────┴──────┐
       │             │
     [R1]          [R2]  (AMR елементи)
       ├─────[V+]    ├─────[V-]
     [R3]          [R4]
       │             │
       └──────┬──────┘
              │
             GND
```

Резистори розміщують на одному силіцієвому кристалі в безпосередній близькості, що забезпечує ідеальну теплову симетрію. Намагніченість елементів `R1` та `R4` орієнтують так, щоб під дією зовнішнього поля їхній опір зростав (`R0 + ΔR`), а елементів `R2` та `R3` — зменшувався (`R0 - ΔR`).

Диференціальна вихідна напруга мосту `V_out = V+ - V-`:

```
V_out = V_supply · [ (R0 + ΔR) / (2·R0) - (R0 - ΔR) / (2·R0) ]
      = V_supply · (ΔR / R0)
```

Завдяки мостовій схемі абсолютне значення `R0` та його температурний дрейф повністю скорочуються у першому наближенні, залишаючи на виході лише відносну магнітну зміну `ΔR / R0`.

### 2. Лінеаризація за допомогою смуг Барбера (Barber Poles)

Анізотропний магнітоопір (AMR) описується квадратичною залежністю від кута `θ` між струмом `I` та намагніченістю `M`:

```
R(θ) = R_perp + ΔR_max · cos²(θ)
```

Поблизу `θ = 0°` або `θ = 90°` похідна `dR / dθ = 0`, що означає нульову чутливість до малих змін поля та сильні нелінійні спотворення.

Щоб змістити робочу точку в область максимальної чутливості та лінійності (`θ = 45°`), застосовують технологію **смуг Барбера** (*Barber pole layout*). На поверхню тонкої пермалоєвої смуги (`Ni80Fe20`) під кутом `45°` напилюють похилі золоті смужки. 

Оскільки питомий опір золота приблизно у 100 разів менший за опір пермалою, електричний струм «вибирає» найкоротший шлях між золотими провідниками і тече перпендикулярно до золотих смуг — тобто точно під кутом `45°` до осі пермалою.

При відхиленні намагніченості на малий кут `Δθ` під дією зовнішнього поля `B_ext` опір змінюється строго лінійно:

```
R(B_ext) ≈ R_45° + K · B_ext
```

### 3. Проблема гістерезису та контур Set/Reset

Феромагнітна плівка пермалою під дією сильних зовнішніх магнітних завад (наприклад, при наближенні постійного магніту чи сильного струмового кабелю) розпадається на хаотичну багатодоменну структуру. Це призводить до двох важких наслідків:
1. Виникнення **магнітного гістерезису** (давач видає різні свідчення при зміні поля "зверху вниз" і "знизу вгору").
2. Втрати калібрування нульового зсуву (zero-field offset).

Для боротьби з цим на кристалі давача поверх вимірювального мосту інтегрують металеву плоску обмотку — **контур Set/Reset** (*Set/Reset strap*).

#### Алгоритм роботи Set/Reset:
1. На обмотку подається короткий потужний імпульс струму (амплітуда 1–3 А, тривалість 1–10 мкс).
2. Імпульс генерує сильне внутрішнє магнітне поле (понад 10–20 мТл), яке примусово впорядковує всі магнітні домени пермалою в єдиний монодомен вздовж осі легкого намагнічення.
3. Процедуру повторюють періодично перед кожним вимірюванням, поочергово подаючи позитивний імпульс (**SET**) та негативний імпульс (**RESET**).

Вимірявши вихідну напругу моста після імпульсу SET (`V_SET`) та після імпульсу RESET (`V_RESET`), отримують корисний сигнал та зсув нульової точки:

```
V_signal = (V_SET - V_RESET) / 2     [чистий корисний сигнал без offset]
V_offset = (V_SET + V_RESET) / 2     [паразитний зсув підсилювача та мосту]
```

Цей метод повністю виключає температурний зсув операційного підсилювача та магнітний гістерезис матеріалу.

### 4. Компенсація поля у замкненому контурі (Closed-loop)

Для найвищих вимог до точності (наприклад, у прецизійних компасах та струмових трансформаторах) застосовують режим **компенсації поля** (*closed-loop mode*). 

На кристал наносять ще одну обмотку — **компенсаційну** (*Offset/Feedback strap*). Вихідний сигнал мосту через інтегратор керує струмом у цій обмотці, яка створює магнітне поле `B_comp`, строго протилежне зовнішньому полю `B_ext`.

Система автоматичного регулювання утримує підсумкове поле всередині давача строго рівним нулю:

```
B_net = B_ext + B_comp = 0  ⇒  B_comp = - B_ext
```

Вимірювальною величиною в цьому випадку є струм у компенсаційній обмотці. Оскільки магніторезистивний елемент завжди працює в нульовій точці, нелінійність та температурна нестабільність самого AMR/GMR матеріалу взагалі не впливають на результат вимірювання.

---

### 5. Магнітні концентратори та екранування

Для розширення діапазону вимірювання чи захисту від паразитного вертикального поля на кристал давача напилюють концентратори магнітного потоку з м'якого феромагнетика (наприклад, му-металу чи пермалою).

Концентратори перенаправляють лінії магнітної індукції з вертикального напрямку `B_z` у горизонтальну площину кристала `B_xy`, підсилюючи локальне поле у 10–50 разів. Це дає змогу вимірювати 3D вектор поля, використовуючи лише планарні резистивні елементи.
