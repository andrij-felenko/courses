# 🧮 Релятивістська кінетика, імпульс і природні одиниці в електронвольтах

Цей математичний аналіз виводить точні співвідношення між кінетичною енергією частинки в електронвольтах, її релятивістською швидкістю, імпульсом, де Бройлівською довжиною хвилі та еквівалентними фізичними величинами (масою, довжиною хвилі фотона та температурою).

## 1. Класична механіка та межа її застосовності

У класичній ньютонівській механіці кінетична енергія частинки масою `m`, прискореної в електричному полі з потенціалом `U`, дорівнює роботі електростатичного поля. Цей вираз ґрунтується на припущенні, що маса частинки залишається незмінною константою незалежно від швидкості руху:

```
Eₖ = (1/2)·m·v² = e·U      [класична кінетична енергія]
```

Виражаючи швидкість частинки `v` через напругу `U` та масу `m`:

```
v = √( 2·e·U / m )          [класична швидкість через потенціал]
```

Для електрона з масою `mₑ ≈ 9.1093837 × 10⁻³¹ кг` та прискорювальною напругою `U = 1 В` розрахуємо точне чисельне значення швидкості:

```
v = √( 2 · 1.602176634×10⁻¹⁹ Дж / 9.1093837×10⁻³¹ кг )
  = √( 3.51756×10¹¹ м²/с² )
  ≈ 5.93084 × 10⁵ м/с       [близько 0.1978% від швидкості світла c]
```

При зростанні прискорювального потенціалу класична механіка передбачає необмежене зростання швидкості пропорційно квадратному кореню з напруги. Якщо розглянути послідовність збільшення напруги на електродах вакуумного приладу:

- При `U = 100 В`: швидкість електрона збільшується у 10 разів і становить `v ≈ 5.931 × 10⁶ м/с` (`1.978% c`).
- При `U = 10 кВ` (`10 кеВ`): швидкість сягає `v ≈ 5.931 × 10⁷ м/с` (`19.78% c`).
- При `U = 256 кВ` (`256 кеВ`): класична формула дає `v ≈ 3.001 × 10⁸ м/с` (`100.1% c` — нефізичний результат, оскільки швидкість перевищує швидкість світла у вакуумі `c`).

Суперечність виникає через те, що Ньютонівська механіка не враховує зростання релятивістського імпульсу та маси зі збільшенням швидкості частинки.

## 2. Релятивістська кінетика Ейнштейна та фактор Лоренца

У спеціальній теорії відносності Ейнштейна повна енергія частинки `E_total` складається з енергії спокою `E₀ = m·c²` та кінетичної енергії `Eₖ`, набутої у прискорювальному полі:

```
E_total = γ·m·c² = m·c² + Eₖ      [повна релятивістська енергія]
```

де `γ` — безрозмірний фактор Лоренца, який визначає ступінь релятивістських ефектів та уповільнення власного часу частинки:

```
γ = 1 / √( 1 - v²/c² )             [фактор Лоренца через швидкість]
```

Виражаючи фактор Лоренца безпосередньо через кінетичну енергію в електронвольтах `Eₖ` та енергію спокою `E₀ = m·c²`:

```
γ = 1 + Eₖ / E₀ = 1 + Eₖ / (m·c²)   [фактор Лоренца через Eₖ]
```

Безрозмірна швидкість `β = v / c` виводиться з фактора Лоренца шляхом алгебраїчних перетворень:

```
1 - β² = 1 / γ²
β² = 1 - 1 / γ² = (γ² - 1) / γ²
β = √( 1 - 1 / γ² ) = √( 1 - 1 / (1 + Eₖ / (m·c²))² )    [точна релятивістська швидкість]
```

Ця формула показує, що при нескінченному зростанні кінетичної енергії `Eₖ → ∞` фактор Лоренца прямує до нескінченності `γ → ∞`, а безрозмірна швидкість асимптотично наближається до одиниці `β → 1` (`v → c`), ніколи її не перевищуючи.

### Чисельний аналіз релятивістських режимів електрона

Для електрона енергія спокою становить `E₀ = mₑ·c² ≈ 510.99895 кеВ` (або `0.511 МеВ`). Проаналізуємо чотири фундаментальні енергетичні режими.

#### Низькоенергетичний режим (`Eₖ = 10 кеВ << mₑ c²`)

У цьому режимі кінетична енергія становить малу частку від енергії спокою:

```
ε = Eₖ / E₀ = 10 / 510.999 ≈ 0.0195695
γ = 1 + 0.0195695 = 1.0195695
β = √( 1 - 1 / (1.0195695)² ) = √( 1 - 0.962007 ) ≈ 0.19492
v ≈ 0.19492 c ≈ 5.8436 × 10⁷ м/с
```

Відносна похибка класичної формули при `10 кеВ` становить лише `1.5%`, що дозволяє використовувати класичні рівняння для опису низковольтних електронних приладів.

#### Субрелятивістський режим (`Eₖ = 100 кеВ`)

При енергії `100 кеВ` кінетична енергія досягає помітної частки від маси спокою:

```
ε = 100 / 510.999 ≈ 0.195695
γ = 1.195695
β = √( 1 - 1 / (1.195695)² ) = √( 1 - 0.69945 ) ≈ 0.54823
v ≈ 0.54823 c ≈ 1.6435 × 10⁸ м/с
```

Тут класична формула давала `0.625 c`, тобто похибка Ньютонівської механіки зростає до `14%`. Для проектирования електронних мікроскопів урахування релятивістської поправки є обов'язковим.

#### Межа рівності кінетичної енергії та маси спокою (`Eₖ = 510.999 кеВ = mₑ c²`)

При прискорювальній напрузі `511 кВ` набута кінетична енергія електрона дорівнює його масі спокою:

```
γ = 1 + 1 = 2.0
β = √( 1 - 1/4 ) = √(3)/2 ≈ 0.866025
v ≈ 0.866025 c ≈ 2.5962 × 10⁸ м/с
```

При цій енергії релятивістська маса електрона подвоюється порівняно з масою спокою (`m_rel = 2 · mₑ`), а швидкість досягає `86.6%` від швидкості світла.

#### Ультрарелятивістський режим (`Eₖ = 10 МеВ >> mₑ c²`)

Для високоенергетичних медичних прискорювачів та синхротронів:

```
γ = 1 + 10000 / 511 ≈ 20.5695
β = √( 1 - 1 / (20.5695)² ) ≈ 0.998818
v ≈ 0.998818 c ≈ 2.99438 × 10⁸ м/с
```

Швидкість електрона практично прямує до швидкості світла, а подальше збільшення енергії витрачається майже виключно на зростання релятивістського імпульсу та маси, а не швидкості.

## 3. Математичний розклад для низьких енергій та запобігання втраті точності

При чисельному розрахунку `β` для малих кінетичних енергій (`Eₖ / E₀ < 10⁻⁵`) пряме використання формули `β = √(1 - 1/γ²)` призводить до втрати значущих цифр через обчислювальну операцію віднімання близьких до одиниці чисел `1 - 1/γ²` в стандартній арифметиці з плаваючою комою IEEE 754.

Для вирішення цієї проблеми застосуємо біноміальний розклад Тейлора за малим параметром `ε = Eₖ / E₀`:

```
1 / γ² = (1 + ε)⁻² = 1 - 2·ε + 3·ε² - 4·ε³ + O(ε⁴)
1 - 1 / γ² = 2·ε - 3·ε² + 4·ε³ - O(ε⁴)
```

Підставляючи цей розклад у квадратний корінь:

```
β = √( 2·ε · (1 - (3/2)·ε + 2·ε² - ...) )
  = √(2·ε) · √( 1 - (3/2)·ε + 2·ε² )
  ≈ √(2·ε) · ( 1 - (3/8)·ε + (5/16)·ε² - ... )      [розклад для малого ε]
```

Перший член розкладу `√(2·ε) = √(2·Eₖ / (m·c²))` точно відповідає класичній швидкості Ньютона `v_class / c`. Другий член `-(3/8)·ε` задає першу релятивістську поправку. Ця формула забезпечує високу чисельну точність розрахунку швидкості до 16 значущих цифр без катастрофічного скасування мантиси при будь-яких малих напругах.

## 4. Релятивістський імпульс та зв'язок дисперсії

У релятивістській механіці імпульс `p` визначається як добуток релятивістської маси на швидкість `p = γ·m·v`. З фундаментального інваріанта чотириімпульсу випливає співвідношення дисперсії:

```
E_total² = (p·c)² + (m·c²)²               [квадрат чотириімпульсу]
(p·c)² = E_total² - (m·c²)²
       = (Eₖ + m·c²)² - (m·c²)²
       = Eₖ² + 2·Eₖ·(m·c²)                [квадрат релятивістського імпульсу]
```

Звідси добуток імпульсу на швидкість світла `p·c` (який вимірюється в одиницях енергії `еВ`) дорівнює:

```
p·c = √( Eₖ · (Eₖ + 2·m·c²) )             [точна формула імпульсу]
```

### Граничні випадки імпульсу

1. **Нерелятивістський граничний випадок (`Eₖ << m·c²`)**:
   ```
   p·c ≈ √( 2·Eₖ·m·c² )  ⇒  p ≈ √( 2·m·Eₖ )      [класичний імпульс]
   ```

2. **Ультрарелятивістський граничний випадок (`Eₖ >> m·c²`)**:
   ```
   p·c ≈ Eₖ  ⇒  p [ГеВ/c] ≈ Eₖ [ГеВ]             [релятивістський імпульс]
   ```

Для протона (`m_p·c² = 0.938272 ГеВ`) з кінетичною енергією `7 ТеВ` (`7000 ГеВ`) у Великому адронному коллайдері:

```
p·c = √( 7000 · (7000 + 2·0.938272) ) = √( 49000000 + 13135.8 ) ≈ 7000.938 ГеВ
p ≈ 7000.938 ГеВ/c
```

### Магнітна жорсткість траєкторії

У магнітному полі з індукцією `B` релятивістська частинка із зарядом `q = e` рухається по колу радіуса `R`. Магнітна жорсткість `B·R` зв'язана з імпульсом `p·c` співвідношенням:

```
B · R = p / e = (p·c) / (e·c)
```

Якщо `p·c` виражено в `ГеВ`, а `B` у теслах, радіус повороту пучка у магнітному полі становить:

```
R [м] ≈ p [ГеВ/c] / ( 0.29979 · B [Тл] )
```

Ця формула використовується при розрахунку геометрії поворотних магнітів у синхротронах.

## 5. Квантово-механічні хвильові властивості частки

Згідно з гіпотезою де Бройля, кожній частинці з імпульсом `p` відповідає хвиля з довжиною `λ_dB`:

```
λ_dB = h / p = (h·c) / (p·c)              [довжина хвилі де Бройля]
```

Підставляючи виведене співвідношення для `p·c`:

```
λ_dB = (h·c) / √( Eₖ · (Eₖ + 2·m·c²) )     [релятивістська довжина хвилі де Бройля]
```

Використовуючи значення фундаментальної константи `h·c ≈ 1239.84198 еВ·нм`:

Для електрона у нерелятивістській області (`Eₖ << 511 кеВ`):

```
λ_dB [нм] ≈ 1.22643 / √( Eₖ [еВ] )
```

Зведена таблиця довжини хвилі де Бройля електрона для різних прискорювальних напруг:

| Напруга U (В) | Кінетична енергія Eₖ | Фактор Лоренца γ | Швидкість v/c | Довжина хвилі λ_dB (нм) |
|---|---|---|---|---|
| `1 еВ` | `1 еВ` | 1.000002 | 0.00198 | `1.2264 нм` |
| `100 еВ` | `100 еВ` | 1.000196 | 0.01978 | `0.1226 нм` (атомний масштаб) |
| `10 кеВ` | `10 кеВ` | 1.019570 | 0.19492 | `0.0122 нм` (рентгенівський масштаб) |
| `100 кеВ` | `100 кеВ` | 1.195695 | 0.54823 | `0.00370 нм` (просвічувальна електронна мікроскопія) |
| `1 МеВ` | `1 МеВ` | 2.956952 | 0.94107 | `0.00087 нм` (субядерний масштаб) |

Аналіз показує, що при підвищенні прискорювальної напруги до `100 кеВ` довжина хвилі електрона зменшується до `0.0037 нм`, що на два порядки менше за розмір атома і дозволяє досягати атомарної роздільної здатності в електронних мікроскопах.

## 6. Термодинамічна еквівалентність та статистика Больцмана

У статистичній фізиці й термодинаміці середня кінетична енергія хаотичного руху на один ступінь вільностей дорівнює `(1/2)·k_B·T`. Характерний енергетичний масштаб теплових процесів визначається добутком `k_B·T`.

Зв'язок між температурою в Кельвінах та енергією в електронвольтах визначається формулою:

```
E_th = k_B · T
T = E_th / k_B = (E_th [еВ] · 1.602176634×10⁻¹⁹ Дж/еВ) / (1.380649×10⁻²³ Дж/К)
  ≈ E_th [еВ] · 11604.518 К/еВ
```

Наприклад, для термоядерної плазми з температурою `T = 100 × 10⁶ К` (100 мільйонів Кельвінів):

```
E_th = (100 × 10⁶ К) / 11604.518 К/еВ ≈ 8617 еВ = 8.617 кеВ
```

Розподіл Максвелла — Больцмана за швидкостями для частинок масою `m` при температурі `T` (вираженій у електронвольтах як `θ = k_B·T`) набуває вигляду:

```
f(Eₖ) dEₖ = 2 · √( Eₖ / π ) · ( 1 / θ )^(3/2) · exp( - Eₖ / θ ) dEₖ
```

Ці математичні виведення є основою для розрахунку параметрів систем у вакуумній електроніці, плазмофізиці, ядерній енергетиці та спектроскопії.
