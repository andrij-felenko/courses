# ⚙️ Чисельне моделювання поверневого заряду та електричного поля провідника

Чисельний аналіз поверхневих зарядів у складних геометричних конфігураціях (вигини мікросмукових ліній, стики провідників із різною питомою провідністю, кутові з'єднання) базується на сіткових методах розв'язання рівняння Лапласа й рівняння неперервності. Ця вставка містить детальний алгоритм та реалізації методом сіток (метод релаксації / скінченно-різницевий метод, FDM) для розрахунку розподілу електричного потенціалу `V(x, y)` та витягування поверхневої густини заряду `σ_surf` вздовж меж провідного каналу.

### Математична модель скінченно-різницевого солівера

Для двовимірної області розрахунку рівняння Лапласа для скалярного електричного потенціалу `V(x, y)` у діелектрику навколо провідника має вигляд:

```
∂²V / ∂x² + ∂²V / ∂y² = 0       [рівняння Лапласа для електростатичного потенціалу]
```

Усередині однорідного провідника зі стаціонарним струмом потенціал задовольняє те саме рівняння Лапласа, а на межах провідника задаються крайові умови Діріхле (значення потенціалу `V`) або Неймана (нормальна похідна `∂V / ∂n`).

Для чисельного розв'язання неперервна область дискретизується прямокутною сіткою з кроком `h` по осі X та осі Y. Застосовуючи розклад у ряд Тейлора для других похідних з точністю другого порядку `O(h²)`, отримаємо 5-точковий аппроксимаційний шаблон (хрестоподібний шаблон):

```
(V[i+1][j] - 2·V[i][j] + V[i-1][j]) / h² + (V[i][j+1] - 2·V[i][j] + V[i][j-1]) / h² = 0 [дискретний Лапласіан]
```

Звідси виражаємо значення потенціалу у центральному вузлі `V[i][j]` через середнє арифметичне потенціалів чотирьох сусідніх вузлів:

```
V[i][j] = 0.25 · (V[i+1][j] + V[i-1][j] + V[i][j+1] + V[i][j-1]) [середнє значення 4 сусідів]
```

Після обчислення сіткового поля потенціалів `V[i][j]` поверхнева густина заряду `σ_surf` на кожній грані граничного вузла обчислюється за теоремою Гаусса через стрибок нормальної похідної потенціалу:

```
σ_surf = - ε0 · (∂V / ∂n_ext - ∂V / ∂n_int) [теорема Гаусса для граничних вузлів]
```

Оскільки всередині провідника нормальна компонента поля дорівнює нулю (`∂V / ∂n_int = 0`), поверхневий заряд визначається виключно зовнішньою односторонньою різницею у бік діелектрика: `σ_surf = - ε0 · (V_ext - V_surf) / h`.

### Крайові умови Неймана для нескінченного простору

При чисельному моделюванні провідника у відкритому просторі зовнішня межа сітки `NX × NY` не повинна спотворювати природний спад електричного поля. Для імітації віддаленого діелектрика на зовнішніх гранях сітки задаються однорідні крайові умови Неймана:

```
∂V / ∂n_outer = 0               [умова Неймана на зовнішній межі розрахункового домену]
```

У скінченно-різницевому вигляді це означає, що потенціал фіктивного вузла за межею сітки прирівнюється до потенціалу крайнього внутрішнього вузла (`V[0][j] = V[1][j]` та `V[NX-1][j] = V[NX-2][j]`). Це усуває штучний відбиток поля від меж обчислювальної зони та забезпечує правильне спадання потенціалу `V(r) ∝ ln(r)` на великих відстанях від дроту.

### Спектральний радіус та швидкість збіжності SOR

Матричне формулювання ітераційного процесу має вигляд `V^{(k+1)} = M · V^{(k)} + b`. Швидкість збіжності визначається спектральним радіусом `ρ(M)` ітераційної матриці (максимальним за модулем власним значенням):

- Для звичайного методу Якобі спектральний радіус дорівнює `ρ_J = cos(π / NX) ≈ 1 - π² / (2 · NX²)`. Для сітки $100 \times 100$ це дає `ρ_J ≈ 0.9995`, що вимагає понад 15 000 ітерацій.
- Для методу Гаусса-Зайделя `ρ_GS = ρ_J² ≈ 1 - π² / NX²`, що зменшує кількість ітерацій удвічі.
- Для методу SOR з оптимальним параметром `ω_opt = 2 / (1 + sqrt(1 - ρ_J²))` спектральний радіус різко падає до `ρ_SOR = ω_opt - 1 ≈ 1 - 2·π / NX`. Для сітки $100 \times 100$ це дає `ρ_SOR ≈ 0.938`, скорочуючи кількість необхідних ітерацій до 150–200 кроків (прискорення у 100 разів!).

### Алгоритм розв'язання (метод Гаусса-Зайделя з верхньою релаксацією, SOR)

Звичайна ітерація Якобі чи Гаусса-Зайделя вимагає тисяч кроків для збіжності на великих сітках, оскільки помилка потенціалу поширюється лише на один вузол за ітерацію. Для прискорення розрахунку застосовується метод послідовної верхньої релаксації (Successive Over-Relaxation, SOR).

Алгоритм SOR вводить коефіцієнт релаксації `ω` ($1.0 < \omega < 2.0$), який екстраполює зміну потенціалу на кожному кроці:

1. **Ініціалізація сітки:** Створення двовимірного масиву потенціалів розміром `NX × NY` та заповнення початковим наближенням `0.0`.
2. **Фіксація крайових умов:** Задання постійних потенціалів Діріхле на контактних площадках (вхідний дріт `V = V_in`, вихідний заземлений дріт `V = 0`).
3. **Ітераційний цикл:** Прохід по всіх внутрішніх вузлах сітки. Для кожного вільного вузла обчислюється цільове середнє значення `target`, після чого потенціал оновлюється за формулою:

```
target = 0.25 · (V[i+1][j] + V[i-1][j] + V[i][j+1] + V[i][j-1]) [цільове середнє значення]
V_new = V_old + ω · (target - V_old)                             [ітераційне формулювання SOR]
```

4. **Контроль збіжності:** Обчислення максимального модуля різниці `max |V_new - V_old|` по всіх вузлах за прохід. Якщо розбіжність менша за поріг `tolerance` (наприклад, $10^{-6}$ В), ітерації зупиняються.
5. **Вилучення поверневого заряду:** Розрахунок поверхневої густини заряду `σ_surf` на зовнішньому та внутрішньому радіусі повороту провідника за допомогою односторонніх похідних.

Нижче наведено повні робочі реалізації двовимірного солівера поверневого заряду мовами C++ та C. Код будує сітку для вигнутого провідника під кутом 90 градусів, розраховує стаціонарне поле потенціалу та виводить обчислені значення поверхневої густини заряду на зовнішньому та внутрішньому вигині каналу.

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <iomanip>
#include <stdexcept>

// Електрична стала ε0 (Ф/м)
constexpr double EPSILON_0 = 8.854187817e-12;

enum class NodeKind {
    Free,       // Вільний вузол діелектрика або внутрішнього провідника
    Conductor,  // Внутрішній вузол провідника
    Boundary,   // Вузол бічної поверхні провідника
    Source,     // Вхідний електрод джерела (V = V_in)
    Ground      // Вихідний заземлений електрод (V = 0)
};

struct SimulationConfig {
    std::size_t nx{80};
    std::size_t ny{80};
    double grid_step{1e-3};      // Крок сітки (1 мм)
    double v_in{10.0};           // Вхідна напруга (10 В)
    double omega{1.85};          // Параметр верхньої релаксації (SOR)
    double tolerance{1e-6};     // Поріг збіжності
    std::size_t max_iterations{5000};
};

class SurfaceChargeSolver {
public:
    explicit SurfaceChargeSolver(SimulationConfig cfg)
        : config_(cfg),
          v_(cfg.nx, std::vector<double>(cfg.ny, 0.0)),
          kind_(cfg.nx, std::vector<NodeKind>(cfg.ny, NodeKind::Free)) {
        setup_geometry();
    }

    void solve() {
        std::size_t iter = 0;
        double max_diff = 0.0;
        do {
            max_diff = 0.0;
            for (std::size_t i = 1; i < config_.nx - 1; ++i) {
                for (std::size_t j = 1; j < config_.ny - 1; ++j) {
                    if (kind_[i][j] == NodeKind::Source || kind_[i][j] == NodeKind::Ground) {
                        continue;
                    }
                    const double old_val = v_[i][j];
                    const double target = 0.25 * (v_[i + 1][j] + v_[i - 1][j] + v_[i][j + 1] + v_[i][j - 1]);
                    const double updated = old_val + config_.omega * (target - old_val);
                    v_[i][j] = updated;
                    const double diff = std::abs(updated - old_val);
                    if (diff > max_diff) {
                        max_diff = diff;
                    }
                }
            }
            ++iter;
        } while (max_diff > config_.tolerance && iter < config_.max_iterations);

        std::cout << "Солівер збігся за " << iter << " ітерацій. Залишкова неузгодженість: " 
                  << max_diff << " В\n";
    }

    // Обчислення нормального поля та поверхневої густини заряду у вузлі (x, y)
    double compute_surface_charge(std::size_t i, std::size_t j, int normal_dx, int normal_dy) const {
        if (i == 0 || i >= config_.nx - 1 || j == 0 || j >= config_.ny - 1) {
            return 0.0;
        }
        // Одностороння похідна нормального поля у бік діелектрика
        const double v_surf = v_[i][j];
        const double v_ext = v_[i + normal_dx][j + normal_dy];
        const double e_normal = -(v_ext - v_surf) / config_.grid_step;
        return EPSILON_0 * e_normal;
    }

    void print_corner_charge_results() const {
        std::cout << "\n--- РЕЗУЛЬТАТИ ОБЧИСЛЕННЯ ПОВЕРХНЕВОГО ЗАРЯДУ НА ВИГИНІ ---\n";
        // Зовнішній кут провідника (x=20, y=20)
        const double sigma_outer = compute_surface_charge(20, 20, -1, -1);
        // Внутрішній кут провідника (x=40, y=40)
        const double sigma_inner = compute_surface_charge(40, 40, 1, 1);

        std::cout << std::scientific << std::setprecision(4);
        std::cout << "Густина заряду на зовнішньому куті (поперечний поворот): " 
                  << sigma_outer << " Кулон/м²\n";
        std::cout << "Густина заряду на внутрішньому куті: " 
                  << sigma_inner << " Кулон/м²\n";
    }

private:
    void setup_geometry() {
        // Формування L-подібного провідника у сітці 80х80
        // Вхідний канал (x від 20 до 40, y від 0 до 40)
        // Вихідний канал (x від 20 до 80, y від 20 до 40)
        for (std::size_t i = 20; i <= 40; ++i) {
            for (std::size_t j = 0; j <= 20; ++j) {
                kind_[i][j] = NodeKind::Conductor;
                v_[i][j] = config_.v_in * (1.0 - static_cast<double>(j) / 80.0);
            }
        }
        for (std::size_t i = 20; i <= 80; ++i) {
            for (std::size_t j = 20; j <= 40; ++j) {
                kind_[i][j] = NodeKind::Conductor;
                v_[i][j] = config_.v_in * (1.0 - static_cast<double>(i + j) / 120.0);
            }
        }
        // Початкові електроди
        for (std::size_t i = 20; i <= 40; ++i) {
            kind_[i][0] = NodeKind::Source;
            v_[i][0] = config_.v_in;
        }
        for (std::size_t j = 20; j <= 40; ++j) {
            kind_[80 - 1][j] = NodeKind::Ground;
            v_[80 - 1][j] = 0.0;
        }
    }

    SimulationConfig config_;
    std::vector<std::vector<double>> v_;
    std::vector<std::vector<NodeKind>> kind_;
};

int main() {
    try {
        SimulationConfig cfg;
        cfg.nx = 81;
        cfg.ny = 81;
        cfg.grid_step = 1e-3;
        cfg.v_in = 12.0;

        SurfaceChargeSolver solver(cfg);
        solver.solve();
        solver.print_corner_charge_results();

    } catch (const std::exception& e) {
        std::cerr << "Помилка обчислень: " << e.what() << '\n';
        return 1;
    }
    return 0;
}
```

@tab C (Стандарт C11)
```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define NX 81
#define NY 81
#define EPSILON_0 8.854187817e-12

typedef enum {
    NODE_FREE = 0,
    NODE_CONDUCTOR,
    NODE_SOURCE,
    NODE_GROUND
} NodeKind;

typedef struct {
    double v[NX][NY];
    NodeKind kind[NX][NY];
    double grid_step;
    double v_in;
    double omega;
    double tolerance;
    int max_iterations;
} GridSolver;

void grid_init(GridSolver *s, double v_in, double step) {
    s->grid_step = step;
    s->v_in = v_in;
    s->omega = 1.85;
    s->tolerance = 1e-6;
    s->max_iterations = 5000;

    for (int i = 0; i < NX; ++i) {
        for (int j = 0; j < NY; ++j) {
            s->v[i][j] = 0.0;
            s->kind[i][j] = NODE_FREE;
        }
    }

    // Геометрія L-подібного вигину провідника
    for (int i = 20; i <= 40; ++i) {
        for (int j = 0; j <= 20; ++j) {
            s->kind[i][j] = NODE_CONDUCTOR;
            s->v[i][j] = v_in * (1.0 - (double)j / 80.0);
        }
    }
    for (int i = 20; i <= 80; ++i) {
        for (int j = 20; j <= 40; ++j) {
            s->kind[i][j] = NODE_CONDUCTOR;
            s->v[i][j] = v_in * (1.0 - (double)(i + j) / 120.0);
        }
    }

    // Задання напруги джерела та землі
    for (int i = 20; i <= 40; ++i) {
        s->kind[i][0] = NODE_SOURCE;
        s->v[i][0] = v_in;
    }
    for (int j = 20; j <= 40; ++j) {
        s->kind[NX - 1][j] = NODE_GROUND;
        s->v[NX - 1][j] = 0.0;
    }
}

void grid_solve(GridSolver *s) {
    int iter = 0;
    double max_diff = 0.0;
    do {
        max_diff = 0.0;
        for (int i = 1; i < NX - 1; ++i) {
            for (int j = 1; j < NY - 1; ++j) {
                if (s->kind[i][j] == NODE_SOURCE || s->kind[i][j] == NODE_GROUND) {
                    continue;
                }
                double old_v = s->v[i][j];
                double target = 0.25 * (s->v[i + 1][j] + s->v[i - 1][j] + s->v[i][j + 1] + s->v[i][j - 1]);
                double updated = old_v + s->omega * (target - old_v);
                s->v[i][j] = updated;

                double diff = fabs(updated - old_v);
                if (diff > max_diff) {
                    max_diff = diff;
                }
            }
        }
        iter++;
    } while (max_diff > s->tolerance && iter < s->max_iterations);

    printf("C-солівер виконано за %d ітерацій. Неузгодженість: %.2e В\n", iter, max_diff);
}

double compute_charge(const GridSolver *s, int i, int j, int ndx, int ndy) {
    if (i <= 0 || i >= NX - 1 || j <= 0 || j >= NY - 1) return 0.0;
    double v_surf = s->v[i][j];
    double v_ext = s->v[i + ndx][j + ndy];
    double e_norm = -(v_ext - v_surf) / s->grid_step;
    return EPSILON_0 * e_norm;
}

int main(void) {
    GridSolver solver;
    grid_init(&solver, 12.0, 1e-3);
    grid_solve(&solver);

    double sigma_outer = compute_charge(&solver, 20, 20, -1, -1);
    double sigma_inner = compute_charge(&solver, 40, 40, 1, 1);

    printf("Поверхневий заряд на зовнішньому куті: %.4e Кл/м²\n", sigma_outer);
    printf("Поверхневий заряд на внутрішньому куті: %.4e Кл/м²\n", sigma_inner);

    return 0;
}
```

### Пастки чисельної реалізації та методи їх усунення

1. **Сингулярності на гострих кутах провідника:** У фізичних провідниках із гострими прямокутними кутами (радіус заокруглення `r → 0`) чисельний розрахунок дає штучний сплеск поверхневої густини заряду `σ_surf → ∞`. Для уникнення аномалій у сітці слід задавати реалістичний радіус скруглення (технологічний фасет `R >= 0.2` мм), розгладжуючи кутові вузли сітки.
2. **Вибір параметра релаксації (SOR):** Оптимальне значення `ω` для прямокутної сітки `NX × NY` обчислюється як `ω_opt = 2 / (1 + sin(π / NX))`. При значенні `ω >= 2.0` алгоритм стає чисельно нестійким і розбігається до безкінечності.
3. **Вплив штучних зовнішніх меж:** Якщо обчислювальний домен занадто малий, штучне заземлення зовнішньої межі спотворює зовнішнє електричне поле та змінює значення поверхневого заряду більш ніж на 15%. Відстань від провідника до зовнішньої межі домену повинна перевищувати ширину провідника щонайменше в 6-10 разів.
4. **Вибір точного порядку обчислення похідної:** Проста одностороння різниця першого порядку має похибку `O(h)`. Для високоточного екстрагування заряду слід застосовувати триточкову односторонню різницю другого порядку: `∂V / ∂n ≈ (-3·V0 + 4·V1 - V2) / (2·h)`.
