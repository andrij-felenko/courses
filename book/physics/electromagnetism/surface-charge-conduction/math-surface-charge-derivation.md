# 🧮 Математичне виведення розподілу поверхневого заряду та вектора Пойнтінга

Математичний апарат опису поверхневих зарядів у провідниках зі струмом базується на рівняннях Максвелла у стаціонарному наближенні та диференціальній формі закону Ома. Нижче наведено строгі виведення чотирьох ключових співвідношень: відсутності об'ємного заряду в однорідному середовищі, витворення об'ємного заряду у неоднорідному середовищі, появи міжфазного заряду на межі двох провідників, профілю поверхневого заряду циліндричного дроту та балансу енергії за допомогою вектора Пойнтінга.

### 1. Доведення відсутності об'ємного заряду в однорідному провіднику

Розглянемо провідне середовище з питомою електричною провідністю `σ` та діелектричною проникністю `ε`. У стаціонарному режимі за відсутності накопичення заряду часова похідна густини заряду дорівнює нулю (`∂ρ / ∂t = 0`).

З рівняння неперервності струму випливає:

```
div(J) = 0                       [рівняння неперервності для стаціонарного струму]
```

Використовуючи диференціальну форму закону Ома `J = σ · E` для однорідного провідника, де провідність `σ = const`:

```
div(J)
= div(σ · E)                    [заміна J на σ · E за законом Ома]
= σ · div(E)                    [винесення константи σ за знак дивергенції]
= 0                             [прирівнювання до нуля за рівнянням неперервності]
```

Оскільки провідність металу ненульова (`σ > 0`), отримаємо `div(E) = 0`. За теоремою Гаусса у диференціальній формі `div(E) = ρ / ε0`, де `ρ` — об'ємна густина заряду, а `ε0` — електрична стала:

```
ρ / ε0
= div(E)                        [теорема Гаусса в диференціальній формі]
= 0                             [результат виведення для div(E)]
```

Отже, об'ємна густина заряду всередині будь-якого однорідного ізотропного провідника зі стаціонарним струмом строго дорівнює нулю:

```
ρ = 0                           [об'ємний заряд усередині однорідного провідника відсутній]
```

Це означає, що всі макроскопічні заряди, які формують поздовжнє електричне поле в кола зі струмом, можуть розташовуватися **виключно на зовнішній поверхні** провідника або на межах поділу різних матеріалів.

### 2. Випадок неоднорідного середовища: поява внутрішнього об'ємного заряду

Для повноти математичного опису розглянемо провідник із плавно змінюваною провідністю `σ(r)` (наприклад, напівпровідник із градієнтом легування або нагрітий металевий стержень з перепадом температур).

Розпишемо дивергенцію густини струму `J = σ(r) · E(r)` за правилом диференціювання добутку скаляра на вектор:

```
div(J)
= div(σ · E)                    [диференціювання добутку σ на E]
= σ · div(E) + E · grad(σ)      [правило векторного аналізу для div(f·A)]
= 0                             [рівняння неперервності стаціонарного струму]
```

Виразимо дивергенцію поля `div(E)` з отриманого рівняння:

```
σ · div(E) = - E · grad(σ)       [перенесення доданку з градієнтом у праву частину]
div(E) = - (E · grad(σ)) / σ    [ділення обох частин на провідність σ]
```

За теоремою Гаусса `div(E) = ρ / ε0`, тому об'ємна густина заряду `ρ` у неоднорідному середовищі дорівнює:

```
ρ
= - ε0 · (E · grad(σ)) / σ      [об'ємна густина заряду через градієнт провідності]
= - ε0 · E · grad(ln(σ))        [заміна grad(σ)/σ на градієнт логарифма провідності]
```

Ця формула показує, що якщо провідність середовища змінюється у просторі (`grad(σ) ≠ 0`), всередині об'єму виникає некомпенсований об'ємний заряд `ρ`. Якщо ж середовище однорідне (`grad(σ) = 0`), то вираз обертається на нуль `ρ = 0`.

### 3. Виведення міжфазної густини поверневого заряду на межі двох середовищ

Розглянемо прямий провідник зі змінною провідністю, складений з двох циліндричних брусків однакової площі перерізу `S`. Перша частина має провідність `σ1`, друга — `σ2`. Крізь систему протікає постійний струм `I`.

Густина струму `J` у двійці середовищ дорівнює:

```
J = I / S                       [визначення густини струму для плоского перерізу S]
```

Оскільки струм неперервний, густина струму по обидва боки межі однакова: `J1 = J2 = J`. З диференціального закону Ома знаходимо напруженість електричного поля всередині кожного з провідників:

```
E1 = J / σ1                     [поздовжнє поле у першому провіднику]
E2 = J / σ2                     [поздовжнє поле у другому провіднику]
```

Запишемо теорему Гаусса для плоского циліндра (гауссової таблетки) нескінченно малої висоти, що охоплює межу поділу двох провідників. Нормалі спрямовані уздовж осі провідника в напрямку протікання струму:

```
E2n - E1n
= E2 - E1                       [оскільки вектори полів перпендикулярні до площини межі]
= J / σ2 - J / σ1               [заміна E1 та E2 через густину струму J та провідності]
= J · (1 / σ2 - 1 / σ1)         [винесення спільного множника J за дужки]
```

З граничних умов електростатики стрибок нормальної компоненти вектора напруженості електричного поля на межі двох середовищ пов'язаний з поверхневою густиною заряду `σ_surf`:

```
E2n - E1n = σ_surf / ε0          [гранична умова для нормальної компоненти поля E]
```

Прирівнюючи обидва вирази для стрибка поля, отримаємо формулу для міжфазної густини поверневого заряду:

```
σ_surf / ε0
= J · (1 / σ2 - 1 / σ1)         [прирівнювання граничної умови до стрибка полів]

σ_surf
= ε0 · J · (1 / σ2 - 1 / σ1)     [множення обох частин рівняння на ε0]
= (ε0 · I / S) · (1 / σ2 - 1 / σ1) [заміна J на I / S]
```

Аналіз отриманого виразу:
1. Якщо `σ2 < σ1` (струм переходить із високопровідної міді у низькопровідний вуглецевий резистор), то `1 / σ2 > 1 / σ1`. Тоді `σ_surf > 0`: на вхідній межі резистора накопичується **позитивний** поверхневий заряд.
2. На виході з резистора назад у мідний дріт `σ2 > σ1`, тому `σ_surf < 0`: на вихідній межі накопичується **негативний** поверхневий заряд.

### 4. Профіль поверхневого заряду довгого циліндричного провідника

Розглянемо довгий циліндричний дріт радіуса `a` та довжини `L`, розміщений уздовж осі `z`. Дріт підключено до джерела напруги `V0`, причому кінець `z = L` заземлено (`V(L) = 0`), а на кінці `z = 0` потенціал дорівнює `V(0) = V0`.

Для однорідного провідника стаціонарне електричне поле всередині дроту є рівномірним і спрямованим уздовж осі `z`:

```
Ez = V0 / L                     [напруженість поздовжнього електричного поля у дроті]
```

Потенціал всередині та на поверхні дроту змінюється за лінійним законом:

```
V(z) = V0 · (1 - z / L)         [лінійний розподіл потенціалу вздовж довжини провідника]
```

Якщо дріт знаходиться у коаксіальному екрані радіуса `R` або на відстані `h` від заземленої площини, потенціал у зовнішньому просторі `V_ext(r, z)` задовольняє рівняння Лапласа `ΔV = 0` з межовою умовою `V_ext(a, z) = V(z)`.

Для циліндрично-симетричної системи розв'язок для радіальної компоненти поля безпосередньо біля поверхні дроту `Er(a, z)` пропорційний місцевому потенціалу `V(z)`:

```
Er(a, z)
= V(z) / (a · ln(R / a))        [радіальне поле у коаксіальному простір на поверхні r = a]
```

За теоремою Гаусса для поверхні провідника в діелектричному середовищі бічна поверхнева густина заряду `σ_surf(z)` дорівнює:

```
σ_surf(z)
= ε0 · Er(a, z)                 [гранична умова для радіального поля на поверхні r = a]
= (ε0 · V(z)) / (a · ln(R / a))  [підстановка радіального поля Er(a, z)]
= (ε0 · V0 · (1 - z / L)) / (a · ln(R / a)) [підстановка лінійного профілю потенціалу V(z)]
```

Отже, поверхнева густина заряду на бічній стінці провідника **лінійно спадає** від максимального позитивного значення на високовольтному кінці `z = 0` до нуля на заземленому кінці `z = L`.

### 5. Розрахунок потоку вектора Пойнтінга та енергетичного балансу

Доведемо, що Джоулева потужність, яка виділяється у провіднику опором `R`, повністю надходить з навколишнього простору через потік вектора Пойнтінга крізь бічну поверхню.

Розглянемо ділянку циліндричного провідника радіуса `a` та довжини `L`, котрою протікає струм `I`. Опір ділянки дорівнює `R = L / (σ · π · a^2)`.

Напруженість електричного поля на бічній поверхні дроту `r = a` має поздовжню компоненту `Ez`:

```
Ez = I / (σ · π · a^2)           [поздовжнє електричне поле за законом Ома]
```

Індукція магнітного поля `B` на бічній поверхні провідника `r = a`, створена струмом `I` за законом Ампера:

```
B_φ = (μ0 · I) / (2 · π · a)     [тангенціальне магнітне поле на поверхні циліндра]
```

Вектор Пойнтінга `S` у системі СІ визначається як:

```
S = (1 / μ0) · (E × B)           [визначення вектора густини потоку електромагнітної енергії]
```

Оскільки вектор `E` спрямований уздовж осі `z`, а вектор `B` — по колу `φ`, їхній векторний добуток `E × B` спрямований радіально **всередину** провідника (у напрямку `-r`). Модуль вектора Пойнтінга дорівнює:

```
Sr
= - (1 / μ0) · Ez · B_φ         [радіальна компонента вектора Пойнтінга, знак мінус означає вхід усередину]
= - (1 / μ0) · (I / (σ · π · a^2)) · ((μ0 · I) / (2 · π · a)) [підстановка виразів для Ez та B_φ]
= - (I^2) / (2 · π^2 · a^3 · σ) [скорочення магнітної сталої μ0 та впорядкування множників]
```

Обчислимо повний потік вектора Пойнтінга `P_in` крізь замкнену бічну поверхню циліндра площею `A_surf = 2 · π · a · L`:

```
P_in
= |Sr| · A_surf                 [потік вектора Пойнтінга крізь бічну поверхню]
= ((I^2) / (2 · π^2 · a^3 · σ)) · (2 · π · a · L) [підстановка модуля Sr та площі бічної поверхні]
= (I^2 · L) / (σ · π · a^2)     [скорочення 2, π та a]
= I^2 · (L / (σ · π · a^2))     [групування геометричних та фізичних параметрів провідника]
= I^2 · R                       [підстановка опору провідника R = L / (σ · π · a^2)]
```

Отримана рівність `P_in = I^2 · R` показує строгий математичний баланс: **вся енергія**, що перетворюється на тепло всередині провідника за законом Джоуля-Ленца, входить у дріт з навколишнього простору у формі електромагнітного поля, сформованого саме поверхневими зарядами провідника.
