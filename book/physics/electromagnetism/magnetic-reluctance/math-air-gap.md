# 🧮 Математичний розрахунок магнітного кола з повітряним зазором

Ця вставка містить строгий математичний вивід формул для розрахунку магнітного опору, магнітного потоку, індуктивності, накопиченої енергії, механічної сили притягання та граничного струму насичення у замкненому магнітопроводі з повітряним зазором. Наведено також аналіз ефекту випучування магнітних ліній за допомогою конформних відображень та чисельний розрахунок для силового феритового осердя.

---

### 1. Фізична модель і повний магнітний опір кола з зазором

Розглянемо замкнений магнітопровід із серединною довжиною лінії `l_core`, площею поперечного перерізу `A`, відносною магнітною проникністю `μ_r` та повітряним зазором довжиною `l_g`. Загальний геометричний шлях поділяється на дві послідовні ділянки: феромагнітне осердя та повітряний зазор.

Магнітний опір феромагнітного осердя `R_m,core` розраховується з перших принципів шляхом інтегрування напруженості поля вздовж лінії осердя:

```
R_m,core = l_core / (μ_0 · μ_r · A)
```

Магнітний опір повітряного зазору `R_m,gap` обчислюється аналогічно:

```
R_m,gap = l_g / (μ_0 · A_eff)
```

де `μ_0 = 4π · 10⁻⁷` Гн/м — магнітна стала, а `A_eff` — ефективна площа зазору з урахуванням ефекту випучування (*fringing effect*).

Ефект випучування виникає через те, що магнітні силові лінії при виході з заліза у повітря зазнають взаємного бічного відштовхування. У результаті потік зайнятиме більший об'єм, ніж геометричний переріз заліза. Для прямокутного перерізу зі сторонами `w` та `h` за моделлю Маклаймана (*McLyman model*) ефективна площа дорівнює:

```
A_eff = (w + l_g) · (h + l_g)
```

Більш точний аналітичний вивід за допомогою конформних відображень Шварца — Крістоффеля враховує геометрію обмотки та віддаленість зазору від каркаса котушки. За цією моделлю поправка до площі виражається логарифмічним доданком:

```
A_eff = A · (1 + (l_g / √A) · ln(2 · D / l_g))
```

де `D` — відстань до найближчого мідного провідника обмотки.

Оскільки осердя та зазор з'єднані послідовно, магнітний потік `Φ` проходить крізь обидва елементи без змін (за законом збереження потоку `∇ · B = 0`). Повний магнітний опір кола `R_m,total` становить алгебраїчну суму окремих опорів:

```
R_m,total = R_m,core + R_m,gap
= l_core / (μ_0 · μ_r · A) + l_g / (μ_0 · A_eff)    [послідовне додавання опорів]
= (1 / (μ_0 · A)) · (l_core / μ_r + l_g · (A / A_eff))    [винесення спільного множника]
```

При малих зазорах `l_g << √A` вважаємо `A_eff ≈ A`, тоді формула спрощується до вигляду:

```
R_m,total ≈ (1 / (μ_0 · A)) · (l_g + l_core / μ_r)
```

Звідси видно, що еквівалентна відносна проникність магнітного кола `μ_eq` падає від початкового значення `μ_r` до значення, що визначається геометрією зазору:

```
μ_eq = l_core / (l_core / μ_r + l_g) = μ_r / (1 + μ_r · (l_g / l_core))
```

Якщо `μ_r = 2200`, а `l_g / l_core = 0.01` (1% зазору), еквівалентна проникність `μ_eq` обвалюється з `2200` до всього `95.2`.

### 2. Залежність індуктивності від повітряного зазору

За законом Гопкінсона магнітний потік `Φ`, створений котушкою з `N` витків при струмі `I`, дорівнює:

```
Φ = F / R_m,total = (N · I) / R_m,total
```

Повний потокозчеплення обмотки `Ψ`:

```
Ψ = N · Φ = (N² · I) / R_m,total
```

За означенням індуктивності `L = Ψ / I`:

```
L = N² / R_m,total
= N² · μ_0 · A / (l_g + l_core / μ_r)    [підстановка R_m,total у формулу індуктивності]
```

Оскільки `μ_r >> 1` (для феритів `μ_r ≈ 2000...5000`), доданок `l_core / μ_r` стає нехтовно малим порівняно з `l_g` навіть при зазорах порядку `0.5...1` мм. У цьому випадку індуктивність майже повністю визначається товщиною повітряного зазору:

```
L ≈ (N² · μ_0 · A) / l_g
```

Це рівняння показує, що індуктивність стає майже інваріантною до температурних коливань проникності заліза `μ_r(T)`, оскільки термічне розширення та нестабільність проникності фериту більше не впливають на `L`.

### 3. Розподіл накопиченої магнітної енергії та механічні сили

Повна магнітна енергія `W_m`, накопичена у колі, обчислюється шляхом інтегрування потужності за часом намагнічування:

```
W_m = (1/2) · L · I²
= (1/2) · (N² / R_m,total) · I²              [підстановка L = N² / R_m]
= (1/2) · (N · I)² / R_m,total               [перегрупування множників]
= (1/2) · Φ² · R_m,total                     [підстановка Φ = N·I / R_m]
= (1/2) · Φ² · (R_m,core + R_m,gap)          [розкриття суми опорів]
= W_core + W_gap                             [розподіл енергії по елементах]
```

Визначимо частку енергії `W_gap`, яка зберігається безпосередньо у повітряному зазорі:

```
W_gap / W_m = R_m,gap / R_m,total
= (l_g / A_eff) / (l_g / A_eff + l_core / (μ_r · A))    [підстановка виразів опорів]
```

Розглянемо відношення густини енергії `w = dW/dV` у зазорі та в осерді при однаковій магнітній індукції `B`:

```
w_gap = B² / (2 · μ_0)                        [густина енергії в повітрі]
w_core = B² / (2 · μ_0 · μ_r)                 [густина енергії у фериті]

w_gap / w_core = μ_r                          [співвідношення густин енергії]
```

Оскільки `μ_r = 2200`, густина магнітної енергії у повітряному зазорі у 2200 разів вища, ніж у тілі феритового осердя. Повітряний зазор накопичує понад `95%` всієї електромагнітної енергії системи.

У зворотньоходових перетворювачах живлення ця енергія накопичується протягом прямого ходу відкривання силового ключа, а під час зворотного ходу передається у вторинне коло навантаження. Здатність зазору накопичувати велику енергію без насичення заліза робить його основними елементом силової імпульсної техніки.

Наявність високої густини енергії у зазорі створює механічну тиск (магнітне напруження Максвелла) на торці залізних полюсів. Механічна сила притягання `F_mech` між двома полюсами в зазорі обчислюється за формулою:

```
F_mech = (B² · A) / (2 · μ_0)
```

При індукції `B = 1.0` Тл магнітний тиск на полюси сягає `3.98` бар (`398` кПа), що створює значні механічні напруження та акустичний шум (писк дроселя) на частоті перемикання.

### 4. Критичний струм насичення I_sat з урахуванням температури

Феромагнітне осердя входить у насичення при досягненні граничної індукції `B_sat` (для силових феритів `B_sat ≈ 0.35...0.45` Тл при підвищеній температурі `100°C`). Оскільки потік `Φ = B · A`, максимальний потік до насичення становить `Φ_sat = B_sat · A`.

Обчислимо максимальний струм `I_sat`, при якому осердя досягає межі насичення:

```
I_sat = (Φ_sat · R_m,total) / N
= (B_sat · A · R_m,total) / N                            [підстановка Φ_sat = B_sat · A]
= (B_sat · A / N) · (1 / (μ_0 · A)) · (l_g + l_core / μ_r) [підстановка виразу R_m,total]
= (B_sat / (N · μ_0)) · (l_g + l_core / μ_r)              [скорочення площі A]
```

Температурна залежність індукції насичення `B_sat(T)` вимагає проведення розрахунку `I_sat` для найгіршого випадку (при максимальній робочій температурі осердя `T = 100°C`). Для фериту N87 значення `B_sat` падає з `0.49` Тл при `25°C` до `0.39` Тл при `100°C`, що зменшує допустимий струм на `20%`. Введення зазору `l_g` пропорційно збільшує максимальний робочий струм індуктивності `I_sat`, запобігаючи аварійному стрибку струму через силовий транзистор.

### 5. Покроковий чисельний приклад розрахунку для осердя ETD49

Розрахуємо параметри магнітного кола силового індуктора на базі популярного феритового осердя ETD49 (матеріал N87 від Epcos):
- Довжина магнітної лінії `l_core = 114` мм = `0.114` м
- Ефективна площа перерізу `A = 211` мм² = `2.11 · 10⁻⁴` м²
- Початкова відносна проникність `μ_r = 2200`
- Індукція насичення `B_sat = 0.39` Тл (при 100°C)
- Кількість витків обмотки `N = 28`
- Довжина повітряного зазору `l_g = 1.2` мм = `0.0012` м

**Крок 1. Обчислення магнітного опору осердя `R_m,core`:**

```
R_m,core = 0.114 / (4π · 10⁻⁷ · 2200 · 2.11 · 10⁻⁴)
= 0.114 / (5.833 · 10⁻⁷)               [обчислення знаменника]
= 195 439 А·вт/Вб                      [ділення чисельника на знаменник]
```

**Крок 2. Обчислення магнітного опору повітряного зазору `R_m,gap` (без урахування випучування):**

```
R_m,gap = 0.0012 / (4π · 10⁻⁷ · 2.11 · 10⁻⁴)
= 0.0012 / (2.651 · 10⁻¹⁰)              [обчислення знаменника зазору]
= 4 525 765 А·вт/Вб                    [остаточний опір зазору]
```

**Крок 3. Повний магнітний опір `R_m,total` та частка зазору:**

```
R_m,total = 195 439 + 4 525 765 = 4 721 204 А·вт/Вб
Частка зазору = 4 525 765 / 4 721 204 = 0.9585 (95.85%)
```

**Крок 4. Розрахунок індуктивності `L`:**

```
L = N² / R_m,total
= 28² / 4 721 204                      [підстановка кількості витків N=28]
= 784 / 4 721 204                      [зведення N у квадрат]
= 1.660 · 10⁻⁴ Гн = 166.0 мкГн         [обчислення індуктивності]
```

**Крок 5. Обчислення струму насичення `I_sat`:**

```
I_sat = (B_sat · A · R_m,total) / N
= (0.39 · 2.11 · 10⁻⁴ · 4 721 204) / 28 [підстановка чисельних значень]
= 388.51 / 28                          [перемноження чисельника]
= 13.88 А                              [ділення на кількість витків]
```

Без повітряного зазору (`l_g = 0`) повний опір дорівнював би лише `195.4` кА·вт/Вб, індуктивність становила б `4.01` мГн, але струм насичення дорівнював би всього `0.57` А. Введення зазору `1.2` мм збільшило допустимий робочий струм у 24.3 рази, забезпечуючи стабільну роботу силової схеми.
