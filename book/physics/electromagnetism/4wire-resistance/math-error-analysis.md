# 🧮 Математичний аналіз похибок вимірювання опору та еквівалентні схеми

Точність вимірювання електричного опору обмежується не лише роздільною здатністю аналого-цифрового перетворювача (АЦП) чи часовою стабільністю джерела струму, а й паразитними параметрами самого вимірювального кола. У цьому розділі наведено строгий математичний аналіз еквівалентних схем для двопровідного та чотирипровідного методів, оцінено вплив скінченного вхідного опору вольтметра, опору провідників, вихідного опору джерела струму та термоелектрорушійної сили (термо-ЕРС), що виникає в місцях контакту різнорідних металів.

### 1. Аналіз еквівалентної схеми 2-провідного вимірювання

У двопровідній схемі вимірювання те саме електричне коло використовується і для подачі струму збудження `I`, і для вимірювання спаду напруги `V_m`. Позначимо опір досліджуваного резистора як `R_x`, а паразитно послідовні опори двох з'єднувальних дротів та їхніх контактних затискачів як `R_w1` та `R_w2`.

Припустимо спочатку, що вольтметр є ідеальним (його вхідний опір `R_v = ∞`). Тоді весь струм джерела `I` повністю проходить через послідовний ланцюг із двох дротів та об'єкта `R_x`:

```
V_m = I · (R_w1 + R_x + R_w2)
```

Обчислений вимірювальним приладом опір `R_calc` за законами електротехніки становить:

```
R_calc = V_m / I
       = R_x + R_w1 + R_w2     [підставили V_m зі схеми]
       = R_x + R_wire          [групування: R_wire = R_w1 + R_w2]
```

Абсолютна похибка вимірювання `ΔR` у двопровідній схемі дорівнює сумарному опору провідників і затискачів:

```
ΔR = R_calc − R_x
   = R_wire                    [різниця між R_calc та R_x]
```

Відносна похибка двопровідного вимірювання `e_rel_2w` за означенням дорівнює:

```
e_rel_2w = ΔR / R_x
         = R_wire / R_x        [ділення абсолютної похибки на R_x]
```

Розгляньмо кілька числових прикладів для оцінки масштабу проблеми:

1. **Вимірювання середнього опору (`R_x = 100` Ом):**
   Якщо опір двох стандартних лабораторних щупів `R_wire = 0.2` Ом, відносна похибка становить:
   ```
   e_rel_2w = 0.2 / 100
            = 0.002            [обчислення частки: 0.2%]
   ```
   Така похибка є цілком припустимою для багатьох побутових задач.

2. **Вимірювання низькоомного шунта (`R_x = 0.01` Ом = 10 мОм):**
   При тих самих щупах відносна похибка зростає до:
   ```
   e_rel_2w = 0.2 / 0.01
            = 20               [переведення у відсотки: 2000%]
   ```
   Результат вимірювання перевищує істинне значення у 21 раз.

3. **Вимірювання прецизійного мікроомного шунта (`R_x = 0.0001` Ом = 100 мкОм):**
   ```
   e_rel_2w = 0.2 / 0.0001
            = 2000             [переведення у відсотки: 200000%]
   ```
   У цьому випадку прилад показує майже виключно опір власних щупів, а корисний сигнал становить менше `0.05%` від виміряного значення.

### 2. Аналіз еквівалентної схеми 4-провідного вимірювання (Kelvin Sensing)

У чотирипровідній схемі струм збудження `I` подається через силову пару дротів `Force+` та `Force-` (опори `R_w1` та `R_w4`). Вимірювання напруги здійснюється через окрему сигнальну пару дротів `Sense+` та `Sense-` (опори `R_w2` та `R_w3`), підключених безпосередньо до висновків `R_x`.

Побудуємо повну еквівалентну схему з урахуванням скінченного вхідного опору вольтметра `R_v`. Повний опір сигнальної вітки вимірювача напруги становить:

```
R_sense_loop = R_w2 + R_v + R_w3
```

Оскільки сигнальна вітка включена паралельно до досліджуваного опору `R_x`, за правилом дільника струму у вузлах підключення `Sense`, струм `I_sense`, який відгалужується у вимірювальні дроти до вольтметра, дорівнює:

```
I_sense = I · (R_x / (R_x + R_w2 + R_v + R_w3))
```

Спад напруги `V_m`, який фіксує вольтметр безпосередньо на своїх вхідних клемах:

```
V_m = I_sense · R_v
    = I · R_x · (R_v / (R_x + R_w2 + R_w3 + R_v))     [підставили I_sense]
```

Поділивши `V_m` на відомий струм джерела `I`, отримуємо обчислений опір `R_calc`:

```
R_calc = V_m / I
       = R_x · (R_v / (R_x + R_w2 + R_w3 + R_v))       [ділення V_m на струм I]
       = R_x · (1 / (1 + (R_x + R_w2 + R_w3) / R_v))   [поділили чисельник і знаменник на R_v]
```

Оскільки вхідний опір сучасних прецизійних цифрових вольтметрів `R_v ≥ 10` Гігаом (`10¹⁰` Ом), а сумарний опір сигнальних дротів та об'єкта `R_x + R_w2 + R_w3 ≤ 10` Ом, відношення `(R_x + R_w2 + R_w3) / R_v` є мізерно малим значенням:

```
ε = (R_x + R_w2 + R_w3) / R_v
  ≤ 10 / 10¹⁰
  = 10⁻⁹                       [підстановка числових параметрів R_v]
```

Застосувавши Тейлорівське наближення першого порядку `1 / (1 + ε) ≈ 1 − ε` для `ε ≪ 1`, отримуємо вираз для обчисленого опору:

```
R_calc ≈ R_x · (1 − (R_x + R_w2 + R_w3) / R_v)
```

Абсолютна похибка чотирипровідної схеми `ΔR_4w` становить:

```
ΔR_4w = R_calc − R_x
      = − R_x · (R_x + R_w2 + R_w3) / R_v             [підставили R_calc]
```

Відповідно, відносна похибка чотирипровідного вимірювання `e_rel_4w` дорівнює:

```
e_rel_4w = ΔR_4w / R_x
         = − (R_x + R_w2 + R_w3) / R_v                [скоротили R_x]
```

Проаналізуємо отриманий фундаментальний результат:
1. Опори силових дротів `R_w1` та `R_w4` **взагалі не входять** до рівняння похибки. Вони не впливають на точність вимірювання.
2. Вплив опорів сигнальних дротів `R_w2` та `R_w3` ослабляється у `R_v` разів (у `10¹⁰` разів).

Обчислимо похибку чотирипровідної схеми для низькоомного шунта `R_x = 0.01` Ом при `R_w2 = R_w3 = 0.5` Ом та `R_v = 10` Гігаом:

```
e_rel_4w = − (0.01 + 0.5 + 0.5) / 10¹⁰
         = − 1.01 / 10¹⁰                               [додавання опорів у чисельнику]
         = − 1.01 · 10⁻¹⁰                              [ділення на 10¹⁰: відповідає −0.0000000101%]
```

Порівняно з двопровідною схемою (де похибка становила `2000%`), чотирипровідний метод зменшує похибку від опору дротів на **11 порядків** (у сто мільярдів разів).

### 3. Вплив вихідного опору джерела струму (Compliance Voltage)

Реальне джерело струму збудження не є ідеальним. Воно має скінченний вихідний опір `R_s` та обмежену максимальну напругу на клемах — напругу відповідності (*Compliance Voltage*) `V_comp`.

Повний опір силового контуру дорівнює:

```
R_force_loop = R_w1 + R_x + R_w4
```

Струм, який здатне видати джерело, обмежений умовою:

```
I_actual = I_target,   якщо  I_target · R_force_loop ≤ V_comp
```

Якщо опір силових дротів `R_w1 + R_w4` виявиться надто великим (наприклад, при використанні надто тонких або довгих кабелів живлення), падіння напруги на силовій петлі перевищить `V_comp`. Джерело вийде з режиму генерації стабільного струму (*Constant Current Mode*) у режим обмеження напруги (*Constant Voltage Mode*), і струм `I` впаде нижче розрахункового значення.

Відносна похибка струму збудження через скінченний вихідний опір джерела `R_s` описується формулою:

```
e_I = − R_force_loop / R_s
```

Тому у високоточних вимірювачах джерело струму має вихідний опір `R_s > 10` Мегаом, а напруга відповідності `V_comp` вибирається на рівні `10...20` Вольт.

### 4. Похибка від термо-ЕРС та математика компенсації (Offset Compensated Ohms)

У місцях контакту різнорідних металів (наприклад, мідного провідника щупа та латунного висновку деталі або припою) внаслідок термоелектричного ефекту Зеебека виникає термо-ЕРС `V_emf`.

За наявності температурного градієнта `ΔT` між двома з'єднаннями паразитна напруга описується інтегральним рівнянням Зеебека:

```
V_emf = ∫ [α_A(T) − α_B(T)] dT
```

Для невеликих температурних різниць вираз спрощується до лінійного:

```
V_emf = α_S · ΔT
```

де `α_S` — диференційний коефіцієнт Зеебека для даної парии металів.

При вимірюванні надмалого опору `R_x = 100` мкОм (`10⁻⁴` Ом) струмом `I = 100` мА корисний спад напруги становить лише:

```
V_signal = I · R_x
         = 0.1 А · 10⁻⁴ Ом
         = 10 мкВ                                     [обчислення корисного сигналу]
```

Паразитна термо-ЕРС величиною `V_emf = 5` мкВ (яка виникає при різниці температур всього у `0.2` °C між контактами) дає абсолютну похибку вимірювання напруги `50%`.

Для усунення цієї похибки застосовують **алгоритм двофазного реверсування струму** (*Offset Compensated Ohms*).

#### Формульний вивід методів компенсації:

**Етап 1 (Прямий струм `+I`):**
Джерело подає струм `+I`. Вольтметр вимірює напругу `V_1`:
```
V_1 = + I · R_x + V_emf
```

**Етап 2 (Зворотний струм `−I`):**
Джерело змінює полярність струму на `−I`. Вольтметр вимірює напругу `V_2`:
```
V_2 = − I · R_x + V_emf
```

Віднімаючи друге рівняння від першого, вилучаємо паразитний доданок `V_emf`:

```
V_1 − V_2 = (+ I · R_x + V_emf) − (− I · R_x + V_emf)
          = 2 · I · R_x                                [скорочення V_emf]
```

Звідси корисний опір `R_x` обчислюється за формулою:

```
R_x = (V_1 − V_2) / (2 · I)
```

Оцінити величину самої паразитної термо-ЕРС у колі можна шляхом додавання двох виміряних сигналів:

```
V_emf = (V_1 + V_2) / 2
```

#### Компенсація часового дрейфу термо-ЕРС (Триточковий алгоритм):
Якщо температура контактів змінюється у часі з лінійною швидкістю `k_t` (`V_emf(t) = V_0 + k_t · t`), двоточкове віднімання залишає нескомпенсований залишок. У цьому випадку застосовують триточкове опитування через однакові інтервали часу `Δt`:

1. `V_1 = + I · R_x + V_0`
2. `V_2 = − I · R_x + V_0 + k_t · Δt`
3. `V_3 = + I · R_x + V_0 + 2 · k_t · Δt`

Точне значення опору без похибки від лінійного дрейфу температури обчислюється за триточковою комбінованою формулою:

```
R_x = (V_1 − 2·V_2 + V_3) / (4 · I)
```

Завдяки цьому алгоритму чотирипровідні цифрові вимірювальні системи здатні вимірювати опори аж до одиниць наноома (`10⁻⁹` Ом) навіть у умовах нестабільної температури навколишнього середовища.
