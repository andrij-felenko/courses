## Математичне підґрунтя та метод скінченних різниць

Для розрахунку статичного електричного поля в об'ємі використовується сітковий метод скінченних різниць (Finite Difference Method, FDM). Попередня безперервна область простору дискретизується рівномірною кубічною сіткою з однаковим кроком по всіх трьох просторових осях: `dx = dy = dz = h`.

### 1. 7-точковий шаблон апроксимації оператора Лапласа

Диференціальний оператор Лапласа `∇²V = ∂²V/∂x² + ∂²V/∂y² + ∂²V/∂z²` у тривимірному просторі розкладається у ряд Тейлора для значень потенціалу в сусідніх вузлах. Для кожної з осей частинна друга похідна апроксимується центральною різницею другого порядку точності `O(h²)`:

```
∂²V / ∂x² ≈ (V[i+1, j, k] - 2 · V[i, j, k] + V[i-1, j, k]) / h²
∂²V / ∂y² ≈ (V[i, j+1, k] - 2 · V[i, j, k] + V[i, j-1, k]) / h²
∂²V / ∂z² ≈ (V[i, j, k+1] - 2 · V[i, j, k] + V[i, j, k-1]) / h²
```

Додаючи ці три співвідношення, отримуємо класичний 7-точковий шаблон скінченних різниць («просторовий хрест»):

```
∇²V[i, j, k] ≈ (V[i+1, j, k] + V[i-1, j, k] +
                V[i, j+1, k] + V[i, j-1, k] +
                V[i, j, k+1] + V[i, j, k-1] - 6 · V[i, j, k]) / h²
```

Підставляючи отримане наближення у рівняння Пуассона `∇²V = -ρ / ε₀`, виражаємо значення потенціалу в центрі шаблону `V[i, j, k]` через значення у шести сусідніх вузлах та місцеву густину електричного заряду `ρ[i, j, k]`:

```
V[i, j, k] = (1 / 6) · (V[i+1, j, k] + V[i-1, j, k] +
                        V[i, j+1, k] + V[i, j-1, k] +
                        V[i, j, k+1] + V[i, j, k-1] + (h² · ρ[i, j, k]) / ε₀)
```

Це рівняння утворює велику систему лінійних алгебраїчних рівнянь (СЛАУ) із розрідженою стрічковою матрицею. Для сітки розміром `N × N × N` кількість невідомих становить `N³`, що для стандартного розрізнення `100 × 100 × 100` дає мільйон невідомих. Прямі методи розв'язання (наприклад, метод Гаусса) вимагають `O(N⁹)` операцій, що є неприйнятним. Тому використовуються ефективні ітераційні методи.

### 2. Ітераційний метод послідовної верхньої релаксації (SOR)

Проста ітерація Гаусса-Зейделя послідовно оновлює потенціал у вузлах, відразу використовуючи вже обчислені нові значення у вузлах `(i-1, j, k)`, `(i, j-1, k)` та `(i, j, k-1)`. Для прискорення збіжності застосовується метод послідовної верхньої релаксації (Successive Over-Relaxation, SOR).

Нове значення потенціалу `V^{t+1}[i, j, k]` на ітерації `t+1` обчислюється як лінійна комбінація старого значення `V^t[i, j, k]` та проміжного значення за Гауссом-Зейделем `V_GS`:

```
V_GS = (1 / 6) · (V^{t+1}[i-1, j, k] + V^t[i+1, j, k] +
                  V^{t+1}[i, j-1, k] + V^t[i, j+1, k] +
                  V^{t+1}[i, j, k-1] + V^t[i, j, k+1] + (h² · ρ[i, j, k]) / ε₀)

V^{t+1}[i, j, k] = (1 - ω) · V^t[i, j, k] + ω · V_GS
```

де `ω` — екстраполяційний параметр релаксації:
- При `ω = 1` метод SOR точно збігається зі стандартним методом Гаусса-Зейделя.
- При `1 < ω < 2` маємо верхню релаксацію (Over-Relaxation), яка екстраполює напрямок зміни потенціалу й суттєво зменшує кількість необхідних ітерацій.
- При `ω ≥ 2` ітераційний процес втрачає стійкість і розбігається.

Для кубічної сітки зі строго нульовими граничними умовами Діріхле спектральний радіус матриці ітерацій відомий аналітично, що дозволяє обчислити оптимальне значення `ω_opt`:

```
μ_max = (cos(π / Nx) + cos(π / Ny) + cos(π / Nz)) / 3
ω_opt = 2 / (1 + √(1 - μ_max²))
```

Для сітки розміром `41 × 41 × 41` значення `ω_opt ≈ 1.62`, що зменшує кількість ітерацій від понад 15 000 (для методу Якобі) до всього 300–400 ітерацій.

### 3. Граничні умови Діріхле та Неймана

Солвер підтримує два типи фізичних граничних умов:

1. **Граничні умови Діріхле**: На межах або поверхнях провідників задається фіксоване значення скалярного потенціалу `V = V_bound`. У коді це реалізовано прапорцем `fixed[i, j, k] = true`, який запобігає обчисленню нового значення потенціалу в цих вузлах.
2. **Граничні умови Неймана**: На площинах симетрії або ізольованих границях задається нормальна похідна потенціалу `∂V / ∂n = 0` (що означає нульову нормальну компоненту електричного поля `E_n = 0`). На сітці це реалізується дзеркальним копіюванням потенціалу у фіктивні крайні вузли: `V[0, j, k] = V[2, j, k]`.

### 4. Червоно-чорне розфарбування (Red-Black Order) для паралелізації

У послідовному алгоритмі Гаусса-Зейделя оновлення вузла `(i, j, k)` залежить від вже оновленого значення лівого та нижнього сусідів, що створює інформаційну залежність даних і заважає прямій паралелізації циклів через OpenMP або на GPU.

Для усунення цієї залежності застосовують **червоно-чорне розфарбування** (Red-Black Ordering), аналогічне шаховій дошці. Усі вузли сітки поділяють на дві групи залежно від парності суми індексів `(i + j + k)`:
1. **Червоні вузли** (`(i + j + k) % 2 == 0`): Усі сусідні вузли для червоних комірок є чорними.
2. **Чорні вузли** (`(i + j + k) % 2 == 1`): Усі сусідні вузли для чорних комірок є червоними.

Кожна ітерація розбивається на два незалежні напівкроки:
- На першому напівкроці паралельно оновлюються тільки червоні вузли (використовуючи старі значення чорних сусідів).
- На другому напівкроці паралельно оновлюються тільки чорні вузли (використовуючи нові обчислені значення червоних сусідів).

Це усуває конфлікти запису в пам'ять і дозволяє досягти масштабування швидкості розрахунку на багатоядерних процесорах та відеокартах CUDA з лінійною ефективністю.

### 5. Порівняльна характеристика ефективності ітераційних методів

Вибір ітераційного алгоритму визначає швидкість обчислень при проектуванні складних електростатичних систем:

| Метод розв'язання | Складність 1 ітерації | Кількість ітерацій для N=100 | Втрата стійкості | Особливості реалізації |
| :--- | :--- | :--- | :--- | :--- |
| **Якобі (Jacobi)** | `O(N³)` | `~15 000` | Ні (`ω = 1`) | Потребує 2 масиви потенціалу, легко паралелиться |
| **Гаусс-Зейдель (GS)** | `O(N³)` | `~7 500` | Ні (`ω = 1`) | 1 масив пам'яті, послідовний доступ |
| **SOR (Верхня релаксація)**| `O(N³)` | `~350` | Так (`при ω ≥ 2.0`) | Оптимальне `ω` різко прискорює розрахунок |
| **Red-Black SOR** | `O(N³)` | `~360` | Так (`при ω ≥ 2.0`) | Повна паралелізація OpenMP / GPU |
| **Багатосітковий метод (Multigrid)**| `O(N³)` | `~10-20` | Ні | Складна ієрархія сіток (V-цикли, W-цикли) |

### 6. Обчислення компонент електричного поля E = -∇V

Після досягнення необхідної точності за скалярним потенціалом (критерій зупинки: `max|V^{t+1} - V^t| < tol`) вектор напруженості електричного поля `E = (Ex, Ey, Ez)` обчислюється як мінус градієнт потенціалу `E = -∇V`.

У кожному внутрішньому вузлі `(i, j, k)` компоненти поля розраховуються за допомогою центральних різниць второго порядку точності:

```
Ex[i, j, k] = - (V[i+1, j, k] - V[i-1, j, k]) / (2 · h)
Ey[i, j, k] = - (V[i, j+1, k] - V[i, j-1, k]) / (2 · h)
Ez[i, j, k] = - (V[i, j, k+1] - V[i, j, k-1]) / (2 · h)
```

На зовнішніх межах сітки центральна різниця замінюється односторонніми різницями першого або другого порядку.

### 7. Дискретна перевірка закону Гаусса: ∮ E · dA = Q / ε₀

Ключовим етапом фізичної верифікації розрахованого поля є обчислення потоку електричного поля `Φ_E` через замкнену дискретну поверхню Гаусса `S`.

Як гауссову поверхню `S` обирають прямокутний паралелепіпед, сформований гранями комірок сітки між індексами `i1..i2`, `j1..j2`, `k1..k2`. Поверхня складається з шести плоских граней:

1. **Ліва та права грані (перпендикулярні до осі X)**:
   ```
   Φ_x = ∑ (j, k) (-Ex[i1, j, k] + Ex[i2, j, k]) · h²
   ```
2. **Нижня та верхня грані (перпендикулярні до осі Y)**:
   ```
   Φ_y = ∑ (i, k) (-Ey[i, j1, k] + Ey[i, j2, k]) · h²
   ```
3. **Ближня та далека грані (перпендикулярні до осі Z)**:
   ```
   Φ_z = ∑ (i, j) (-Ez[i, j, k1] + Ez[i, j, k2]) · h²
   ```

Сумарний чисельний потік `Φ_E = Φ_x + Φ_y + Φ_z` порівнюється з точним значенням сумарного заряду `Q_enclosed = ∑ ρ[i,j,k] · h³`, що міститься усередині вибраного паралелепіпеда. Відносна похибка обчислюється як:

```
Error = |Φ_E - Q_enclosed / ε₀| / (Q_enclosed / ε₀) · 100%
```

Така перевірка дозволяє оцінити чисельну дисипацію та похибки апроксимації на конкретному сітковому розрізненні `h`. При зменшенні кроку сітки `h` вдвічі похибка обчислення потоку спадає квадратично `O(h²)`.

### 8. Обчислення ємності та енергії поля за допомогою закону Гаусса

Отримані розв'язки потенціалу та поля дозволяють обчислити фундаментальні інтегральні характеристики електростатичної системи:

1. **Енергія електростатичного поля**:
   Обчислюється шляхом об'ємного підсумовування квадратів полів по всіх комірках сітки:
   ```
   W = (ε₀ / 2) · ∑ (i,j,k) (Ex²[i,j,k] + Ey²[i,j,k] + Ez²[i,j,k]) · h³
   ```
2. **Власна ємність провідника**:
   Для заданого потенціалу провідника `V_cond` потік вектора поля `∮ E · dA` через гауссову поверхню навколо провідника дає повний індукований заряд `Q_total`. Звідси електрична ємність обчислюється як:
   ```
   C = Q_total / V_cond = (ε₀ · ∮ E · dA) / V_cond
   ```

## Врахування гетерогенних діелектричних середовищ

Якщо об'єм розрахунку містить межі поділу двох діелектриків із різною відносною діелектричною проникністю `ε1` та `ε2`, закон Гаусса у диференціальній формі записується через вектор електричного зсуву `∇ · (ε_r(r) · ∇V) = -ρ / ε₀`.

На межі комірок різниця проникностей враховується шляхом застосування **середнього гармонійного** значення коефіцієнта провідності між сусідніми вузлами:

```
ε_eff(i+1/2) = (2 · ε_r[i] · ε_r[i+1]) / (ε_r[i] + ε_r[i+1])
```

Використання середнього гармонійного (замість середнього арифметичного) є строго обов'язковим: воно гарантує неперервність нормальної компоненти вектора зсуву `D_n = ε_r · E_n` на межі двох середовищ та відсутність штучних фіктивних зарядів на сітці.

## Розподіл пам'яті та кеш-оптимізація 3D-масивів

При роботі з тривимірними масивами великого розміру критично важливо забезпечити послідовний доступ до пам'яті для ефективного використання кешу процесора (L1/L2 Cache) та векторних інструкцій (AVX-2 / AVX-512 / NEON).

Динамічний тривимірний масив розгортається у суцільний одновимірний вектор пам'яті розміром `Nx * Ny * Nz`. Індексація виконується за формою Row-Major (найшвидше змінюється останній індекс `k`):

```
index(i, j, k) = i · (Ny · Nz) + j · Nz + k
```

Внутрішні цикли за індексами організовуються у порядку `i → j → k`. Це забезпечує прямий лінійний прохід по пам'яті із кроком у 1 елемент (`stride-1`), що активує апаратну превибірку даних (hardware prefetcher) процесора й підвищує швидкість розрахунку в 3–5 разів порівняно з неоптимальним порядком циклів `k → j → i`.

## Повний вихідний код солвера (C та C++)

Нижче наведено робочу реалізацію 3D-солвера електростатики мовами C та C++. Обидві версії є незалежними й ідіоматичними реалізаціями того самого алгоритму.

:::tabs
```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <stdbool.h>

#define EPSILON_0 8.854187817e-12 // Електрична стала (Ф/м)

typedef struct {
    int nx, ny, nz;
    double h;           // Крок сітки (м)
    double *v;          // Скалярний потенціал V (Вольт)
    double *rho;        // Об'ємна густина заряду (Кл/м³)
    double *ex;         // Компонента поля Ex (В/м)
    double *ey;         // Компонента поля Ey (В/м)
    double *ez;         // Компонента поля Ez (В/м)
    bool *fixed;        // Граничні умови Діріхле (true = фіксований потенціал)
} Grid3D;

// Отримання лінійного індексу в плоскому масиві 3D
static inline int idx(const Grid3D *g, int i, int j, int k) {
    return i * (g->ny * g->nz) + j * g->nz + k;
}

// Створення та ініціалізація сітки
Grid3D* grid_create(int nx, int ny, int nz, double h) {
    Grid3D *g = (Grid3D*)malloc(sizeof(Grid3D));
    if (!g) return NULL;

    g->nx = nx;
    g->ny = ny;
    g->nz = nz;
    g->h = h;

    size_t num_cells = (size_t)nx * ny * nz;
    g->v = (double*)calloc(num_cells, sizeof(double));
    g->rho = (double*)calloc(num_cells, sizeof(double));
    g->ex = (double*)calloc(num_cells, sizeof(double));
    g->ey = (double*)calloc(num_cells, sizeof(double));
    g->ez = (double*)calloc(num_cells, sizeof(double));
    g->fixed = (bool*)calloc(num_cells, sizeof(bool));

    if (!g->v || !g->rho || !g->ex || !g->ey || !g->ez || !g->fixed) {
        free(g->v); free(g->rho); free(g->ex); free(g->ey); free(g->ez); free(g->fixed);
        free(g);
        return NULL;
    }
    return g;
}

// Звільнення пам'яті
void grid_free(Grid3D *g) {
    if (!g) return;
    free(g->v);
    free(g->rho);
    free(g->ex);
    free(g->ey);
    free(g->ez);
    free(g->fixed);
    free(g);
}

// Задання точкового або об'ємного заряду
void grid_add_charge(Grid3D *g, int i, int j, int k, double q_coulombs) {
    if (i >= 0 && i < g->nx && j >= 0 && j < g->ny && k >= 0 && k < g->nz) {
        double cell_volume = g->h * g->h * g->h;
        g->rho[idx(g, i, j, k)] += q_coulombs / cell_volume;
    }
}

// Ітераційний розв'язувач Пуассона методом SOR
int grid_solve_poisson(Grid3D *g, double tol, int max_iter, double omega) {
    double h2 = g->h * g->h;
    double inv_eps = 1.0 / EPSILON_0;

    for (int iter = 0; iter < max_iter; iter++) {
        double max_diff = 0.0;

        for (int i = 1; i < g->nx - 1; i++) {
            for (int j = 1; j < g->ny - 1; j++) {
                for (int k = 1; k < g->nz - 1; k++) {
                    int curr = idx(g, i, j, k);
                    if (g->fixed[curr]) continue;

                    double v_old = g->v[curr];
                    double sum_neighbors = g->v[idx(g, i+1, j, k)] + g->v[idx(g, i-1, j, k)] +
                                           g->v[idx(g, i, j+1, k)] + g->v[idx(g, i, j-1, k)] +
                                           g->v[idx(g, i, j, k+1)] + g->v[idx(g, i, j, k-1)];

                    double v_gs = (sum_neighbors + h2 * g->rho[curr] * inv_eps) / 6.0;
                    double v_new = (1.0 - omega) * v_old + omega * v_gs;

                    g->v[curr] = v_new;
                    double diff = fabs(v_new - v_old);
                    if (diff > max_diff) max_diff = diff;
                }
            }
        }

        if (max_diff < tol) {
            return iter + 1; // Успішна збіжність
        }
    }
    return max_iter;
}

// Обчислення векторного поля E = -grad(V)
void grid_compute_electric_field(Grid3D *g) {
    double inv_2h = 1.0 / (2.0 * g->h);

    for (int i = 1; i < g->nx - 1; i++) {
        for (int j = 1; j < g->ny - 1; j++) {
            for (int k = 1; k < g->nz - 1; k++) {
                int id = idx(g, i, j, k);
                g->ex[id] = -(g->v[idx(g, i+1, j, k)] - g->v[idx(g, i-1, j, k)]) * inv_2h;
                g->ey[id] = -(g->v[idx(g, i, j+1, k)] - g->v[idx(g, i, j-1, k)]) * inv_2h;
                g->ez[id] = -(g->v[idx(g, i, j, k+1)] - g->v[idx(g, i, j, k-1)]) * inv_2h;
            }
        }
    }
}

// Чисельна перевірка закону Гаусса: інтегрування потоку ∮ E · dA
double grid_verify_gauss_law(const Grid3D *g, int i1, int i2, int j1, int j2, int k1, int k2, double *out_q_enclosed) {
    double flux = 0.0;
    double area_elem = g->h * g->h;
    double q_sum = 0.0;

    // Підсумовування вільних зарядів усередині кубоїда
    for (int i = i1; i <= i2; i++) {
        for (int j = j1; j <= j2; j++) {
            for (int k = k1; k <= k2; k++) {
                q_sum += g->rho[idx(g, i, j, k)] * (g->h * g->h * g->h);
            }
        }
    }
    *out_q_enclosed = q_sum;

    // Грані X (ліва та права)
    for (int j = j1; j <= j2; j++) {
        for (int k = k1; k <= k2; k++) {
            flux += -g->ex[idx(g, i1, j, k)] * area_elem; // Ліва грань (нормаль -X)
            flux +=  g->ex[idx(g, i2, j, k)] * area_elem; // Права грань (нормаль +X)
        }
    }

    // Грані Y (нижня та верхня)
    for (int i = i1; i <= i2; i++) {
        for (int k = k1; k <= k2; k++) {
            flux += -g->ey[idx(g, i, j1, k)] * area_elem; // Нижня грань (нормаль -Y)
            flux +=  g->ey[idx(g, i, j2, k)] * area_elem; // Верхня грань (нормаль +Y)
        }
    }

    // Грані Z (ближня та далека)
    for (int i = i1; i <= i2; i++) {
        for (int j = j1; j <= j2; j++) {
            flux += -g->ez[idx(g, i, j, k1)] * area_elem; // Ближня грань (нормаль -Z)
            flux +=  g->ez[idx(g, i, j, k2)] * area_elem; // Далека грань (нормаль +Z)
        }
    }

    return flux;
}

int main(void) {
    int n = 41;         // Розмір сітки 41x41x41
    double h = 0.05;    // Крок сітки 5 см (розмір області 2x2x2 м)
    Grid3D *g = grid_create(n, n, n, h);
    if (!g) {
        fprintf(stderr, "Помилка виділення пам'яті!\n");
        return 1;
    }

    // Поміщаємо заряд +1 нКл в центр сітки
    int center = n / 2;
    double charge_q = 1.0e-9; // 1 нКл
    grid_add_charge(g, center, center, center, charge_q);

    // Встановлюємо нульові граничні умови на межах області (V = 0)
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            g->fixed[idx(g, i, j, 0)] = true; g->v[idx(g, i, j, 0)] = 0.0;
            g->fixed[idx(g, i, j, n-1)] = true; g->v[idx(g, i, j, n-1)] = 0.0;
            g->fixed[idx(g, i, 0, j)] = true; g->v[idx(g, i, 0, j)] = 0.0;
            g->fixed[idx(g, i, n-1, j)] = true; g->v[idx(g, i, n-1, j)] = 0.0;
            g->fixed[idx(g, 0, i, j)] = true; g->v[idx(g, 0, i, j)] = 0.0;
            g->fixed[idx(g, n-1, i, j)] = true; g->v[idx(g, n-1, i, j)] = 0.0;
        }
    }

    printf("Розв'язання рівняння Пуассона (SOR)... ");
    int iters = grid_solve_poisson(g, 1.0e-5, 2000, 1.6);

    double q_enc = 0.0;

                                           center - margin, center + margin,
                                           center - margin, center + margin, &q_enc);

    double rel_error = fabs(flux - expected_flux) / expected_flux * 100.0;

    printf("\n=== РЕЗУЛЬТАТИ ЧИСЕЛЬНОЇ ПЕРЕВІРКИ ЗАКОНУ ГАУССА ===\n");
    printf("Внутрішній заряд Q_enclosed : %.4e Кл\n", q_enc);
    printf("Обчислений потік ∮ E · dA   : %.4e В·м\n", flux);
    printf("Теоретичний потік Q / eps0  : %.4e В·м\n", expected_flux);
    printf("Відносна похибка сітки     : %.2f%%\n", rel_error);

    grid_free(g);
    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <memory>
#include <expected>
#include <system_error>
#include <iomanip>

constexpr double EPSILON_0 = 8.854187817e-12; // Електрична стала (Ф/м)

enum class SolverError {
    InvalidDimensions,
    MemoryAllocationFailed,
    ConvergenceFailed
};

class ElectrostaticSolver3D {
private:
    int nx_, ny_, nz_;
    double h_;
    std::vector<double> v_;
    std::vector<double> rho_;
    std::vector<double> ex_;
    std::vector<double> ey_;
    std::vector<double> ez_;
    std::vector<bool> fixed_;

    [[nodiscard]] inline size_t idx(int i, int j, int k) const noexcept {
        return static_cast<size_t>(i) * (ny_ * nz_) + j * nz_ + k;
    }

public:
    ElectrostaticSolver3D(int nx, int ny, int nz, double h)
        : nx_(nx), ny_(ny), nz_(nz), h_(h),
          v_(nx * ny * nz, 0.0),
          rho_(nx * ny * nz, 0.0),
          ex_(nx * ny * nz, 0.0),
          ey_(nx * ny * nz, 0.0),
          ez_(nx * ny * nz, 0.0),
          fixed_(nx * ny * nz, false) {}

    void addCharge(int i, int j, int k, double coulombs) {
        if (i >= 0 && i < nx_ && j >= 0 && j < ny_ && k >= 0 && k < nz_) {
            double cell_vol = h_ * h_ * h_;
            rho_[idx(i, j, k)] += coulombs / cell_vol;
        }
    }

    void setBoundaryDirichlet(int i, int j, int k, double potential_volts) {
        size_t id = idx(i, j, k);
        v_[id] = potential_volts;
        fixed_[id] = true;
    }

    [[nodiscard]] std::expected<int, SolverError> solvePoisson(double tol = 1e-5, int max_iter = 2000, double omega = 1.5) {
        if (nx_ < 3 || ny_ < 3 || nz_ < 3) {
            return std::unexpected(SolverError::InvalidDimensions);
        }

        const double h2 = h_ * h_;
        const double inv_eps = 1.0 / EPSILON_0;

        for (int iter = 0; iter < max_iter; ++iter) {
            double max_diff = 0.0;

            for (int i = 1; i < nx_ - 1; ++i) {
                for (int j = 1; j < ny_ - 1; ++j) {
                    for (int k = 1; k < nz_ - 1; ++k) {
                        size_t curr = idx(i, j, k);
                        if (fixed_[curr]) continue;

                        double v_old = v_[curr];
                        double sum_nbrs = v_[idx(i + 1, j, k)] + v_[idx(i - 1, j, k)] +
                                          v_[idx(i, j + 1, k)] + v_[idx(i, j - 1, k)] +
                                          v_[idx(i, j, k + 1)] + v_[idx(i, j, k - 1)];

                        double v_gs = (sum_nbrs + h2 * rho_[curr] * inv_eps) / 6.0;
                        double v_new = (1.0 - omega) * v_old + omega * v_gs;

                        v_[curr] = v_new;
                        max_diff = std::max(max_diff, std::abs(v_new - v_old));
                    }
                }
            }

            if (max_diff < tol) {
                return iter + 1;
            }
        }
        return std::unexpected(SolverError::ConvergenceFailed);
    }

    void computeElectricField() {
        const double inv_2h = 1.0 / (2.0 * h_);
        for (int i = 1; i < nx_ - 1; ++i) {
            for (int j = 1; j < ny_ - 1; ++j) {
                for (int k = 1; k < nz_ - 1; ++k) {
                    size_t id = idx(i, j, k);
                    ex_[id] = -(v_[idx(i + 1, j, k)] - v_[idx(i - 1, j, k)]) * inv_2h;
                    ey_[id] = -(v_[idx(i, j + 1, k)] - v_[idx(i, j - 1, k)]) * inv_2h;
                    ez_[id] = -(v_[idx(i, j, k + 1)] - v_[idx(i, j, k - 1)]) * inv_2h;
                }
            }
        }
    }

    struct GaussResult {
        double flux;
        double q_enclosed;
        double expected_flux;
        double relative_error_percent;
    };

    [[nodiscard]] GaussResult verifyGaussLaw(int i1, int i2, int j1, int j2, int k1, int k2) const {
        double flux = 0.0;
        double area_elem = h_ * h_;
        double q_sum = 0.0;

        for (int i = i1; i <= i2; ++i) {
            for (int j = j1; j <= j2; ++j) {
                for (int k = k1; k <= k2; ++k) {
                    q_sum += rho_[idx(i, j, k)] * (h_ * h_ * h_);
                }
            }
        }

        for (int j = j1; j <= j2; ++j) {
            for (int k = k1; k <= k2; ++k) {
                flux += -ex_[idx(i1, j, k)] * area_elem;
                flux +=  ex_[idx(i2, j, k)] * area_elem;
            }
        }

        for (int i = i1; i <= i2; ++i) {
            for (int k = k1; k <= k2; ++k) {
                flux += -ey_[idx(i, j1, k)] * area_elem;
                flux +=  ey_[idx(i, j2, k)] * area_elem;
            }
        }

        for (int i = i1; i <= i2; ++i) {
            for (int j = j1; j <= j2; ++j) {
                flux += -ez_[idx(i, j, k1)] * area_elem;
                flux +=  ez_[idx(i, j, k2)] * area_elem;
            }
        }

        double expected = q_sum / EPSILON_0;
        double err = std::abs(flux - expected) / expected * 100.0;
        return {flux, q_sum, expected, err};
    }
};

    } else {
```

## Практичні пастки та розбір чисельної похибки

Під час розробки та застосування сіткових солверів електростатики виникають чотири типові проблеми, пов'язані з фізичними обмеженнями та дискретизацією:

1. **Сингулярність точкового заряду**: Точковий заряд має нульовий об'єм, тому його об'ємна густина `ρ = q / dV` прямує до нескінченності при `h → 0`. У дискретній сітці заряд розмазується по об'єму однієї комірки `h³`, що породжує чисельну похибку дискретизації потенціалу поблизу джерела. Для зниження цієї похибки застосовують згладжування заряду за допомогою функції Гаусса чи сплайнів (Particle-In-Cell, PIC).
2. **Параметр релаксації `ω`**: Якщо вибрати `ω ≥ 2.0`, ітераційний процес SOR стає нестійким і розбігається до нескінченності. При `ω < 1.0` (нижня релаксація) збіжність стає надто повільною. Для квадратних і кубічних сіток оптимальне `ω` лежить у межах `1.4–1.8`.
3. **Вибір гауссової поверхні інтегрування**: Для точного обчислення потоку `∮ E · dA` поверхня інтегрування повинна проходити через центри осередків сітки, де компоненти `Ex, Ey, Ez` обчислені з максимальною точністю `O(h²)`. Якщо поверхня перетинає саму комірку з джерелом заряду, похилка різницева апроксимація призводить до суттєвого спотворення результату.
4. **Вплив зовнішніх меж (граничні умови)**: Якщо границі сітки розташовані занадто близько до джерела зарядів, штучна нульова гранична умова `V = 0` викривляє сферичну симетрію поля. Для моделювання нескінченного відкритого простору відстань від джерела до межі сітки повинна щонайменше у 5–10 разів перевищувати характерний розмір зарядженої області, або ж застосовуються заглиблені граничні умови (Absorbing Boundary Conditions чи поглинальні шари PML).
