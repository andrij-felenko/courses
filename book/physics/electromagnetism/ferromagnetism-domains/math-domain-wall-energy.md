# 🧮 Точний розрахунок структури та енергії доменної стінки Блоха

Ця вставка містить детальний варіаційний розрахунок конфігурації спінів, ефективної товщини та поверхневої густини енергії 180-градусної доменної стінки Блоха у монокристалічному феромагнетику на основі мінімізації функціонала вільної енергії Ландау — Ліфшиця.

## 1. Постановка математичної задачі та енергетичний функціонал

Розглянемо масивний тривимірний монокристал одноосьового феромагнетика. Нехай легка вісь намагнічування збігається з віссю `z`, а доменна стінка розташована в площині `yz` (нормаль до стінки спрямована вздовж осі `x`).

Зліва від стінки (`x → -∞`) домен намагнічений вздовж осі `z` (`M_z = +M_s`, `θ = 0`), а справа від стінки (`x → +∞`) — проти осі `z` (`M_z = -M_s`, `θ = π`). Кут `θ(x)` визначає відхилення вектора намагніченості `M` від позитивного напрямку осі `z` у площині стінки `yz`.

У стінці Блоха вектор `M` повертається у площині `yz`, тому `M_x = 0`, `M_y = M_s · sin(θ(x))`, `M_z = M_s · cos(θ(x))`. Оскільки `M_x = 0`, об'ємні магнітні заряди `ρ_m = -div(M) = -d(M_x)/dx = 0` відсутні, і магнітостатична енергія дорівнює нулю.

Повна поверхнева густина енергії стінки `γ_w` (Дж/м²) є сумою густини обмінної енергії та енергії магнітокристалічної анізотропії:

```
γ_w = ∫ [ w_ex(x) + w_k(x) ] dx                  [поверхнева густина енергії]
```

1. **Густина обмінної енергії `w_ex(x)`:**
   При континуальному описі середовища з неперервною зміною кута `θ(x)` енергія непаралельності сусідніх спінів записується через феноменологічний параметр обмінної жорсткості `A` (вимірюється в Дж/м):

```
w_ex(x) = A · ( dθ / dx )²                       [густина обмінної енергії]
```

2. **Густина енергії магнітокристалічної анізотропії `w_k(x)`:**
   Для одноосьового кристала з константою анізотропії `K` (Дж/м³) потенціальний бар'єр при відхиленні вектора намагніченості від легкої осі `z` описується функцією:

```
w_k(x) = K · sin²(θ(x))                           [густина енергії анізотропії]
```

Таким чином, математичне завдання зводиться до знаходження такої гладкої функції `θ(x)`, яка мінімізує наступний варіаційний інтегральний функціонал `E[θ]`:

```
γ_w = ∫ [ A · ( dθ / dx )² + K · sin²(θ) ] dx      [повний функціонал енергії стінки]
```

із граничними умовами: `θ(-∞) = 0`, `θ(+∞) = π`, та `dθ/dx → 0` при `x → ±∞`.

## 2. Варіаційне рівняння Ейлера — Лагранжа та його перша інтеграція

Для знаходження екстремуму функціонала `γ_w = ∫ L(θ, θ') dx`, де подинтегральна функція Лагранжа `L(θ, θ') = A · (θ')² + K · sin²(θ)`, застосуємо стандартне рівняння Ейлера — Лагранжа з варіаційного числення:

```
∂L / ∂θ - d/dx ( ∂L / ∂θ' ) = 0                   [рівняння Ейлера — Лагранжа]
```

Обчислимо часткові похідні функціонала:

```
∂L / ∂θ = 2 · K · sin(θ) · cos(θ)

∂L / ∂θ' = 2 · A · θ'
```

Підставляючи похідні у рівняння Ейлера — Лагранжа, отримуємо диференціальне рівняння другого порядку для профілю стінки:

```
2 · K · sin(θ) · cos(θ) - 2 · A · ( d²θ / dx² ) = 0

A · ( d²θ / dx² ) = K · sin(θ) · cos(θ)          [диференціальне рівняння стінки]
```

Фізичний зміст цього рівняння полягає у точній рівності двох протилежних механічних моментів сил: обмінного моменту `τ_ex = A · (d²θ/dx²)`, який прагне розтягнути стінку, та моменту сил анізотропії `τ_k = K · sin(θ) · cos(θ)`, який прагне стиснути її.

Оскільки підінтегральна функція Лагранжа `L(θ, θ')` не залежить явно від координати `x`, для неї виконується перший інтеграл механіки Гамільтона (збереження енергії / іваріант Бельтрамі):

```
L - θ' · ( ∂L / ∂θ' ) = const

A · (θ')² + K · sin²(θ) - 2 · A · (θ')² = const

K · sin²(θ) - A · ( dθ / dx )² = const            [перший інтеграл системи]
```

З огляду на граничні умови при `x → ±∞` (де `θ → 0` або `π`, а похідна `dθ/dx → 0`), стала інтегрування `const` строго дорівнює нулю.

Звідси отримуємо фундаментальне локальне співвідношення між обмінною енергією та енергією анізотропії в кожній точці стінки:

```
A · ( dθ / dx )² = K · sin²(θ)                    [локальна рівність густин енергій]

dθ / dx = √( K / A ) · sin(θ)                     [похідна кута повороту спінів]
```

Це рівняння показує, що у будь-якій точці доменної стінки Блоха густина обмінної енергії точно дорівнює густині енергії анізотропії.

## 3. Аналітичний профіль обертання спінів

Розділимо змінні у першому диференціальному інтегралі і виконаємо пряме інтегрування:

```
dθ / sin(θ) = √( K / A ) · dx                    [ділення змінних]
```

Використовуючи класичний табличний інтеграл `∫ dθ / sin(θ) = ln| tan(θ/2) |`, знаходимо:

```
ln [ tan(θ/2) ] = √( K / A ) · x + C_0            [результат інтегрування]
```

Вибираючи початок координат `x = 0` у центрі доменної стінки, де кут повороту `θ(0) = π/2` (а отже `tan(π/4) = 1` і `ln(1) = 0`), отримуємо соленоїдну сталу `C_0 = 0`.

Потенціюючи отримане вираження, маємо точну аналітичну формулу профілю обертання спінів Блохівської стінки:

```
tan(θ/2) = exp( x / x_0 )

θ(x) = 2 · arctan [ exp( x / x_0 ) ]             [профіль 180-градусної стінки Блоха]
```

де параметр `x_0 = √( A / K )` має розмірність довжини і характеризує характерний просторовий масштаб центральної частини доменної стінки.

Знайдемо розподіл похідної кута `dθ/dx`, яка характеризує швидкість повороту вектора намагніченості у просторі:

```
dθ / dx = ( 1 / x_0 ) · sech( x / x_0 )          [швидкість обертання спінів]
```

де `sech(u) = 1 / cosh(u)` — гіперболічний секанс. Максимальна швидкість обертання спінів досягається строго в центрі стінки (`x = 0`) і дорівнює `(dθ/dx)_max = 1 / x_0 = √(K/A)`.

## 4. Розрахунок товщини доменної стінки

Оскільки асимптотичний розворот кута від `0` до `π` у функції `2·arctan(exp(x/x_0))` відбуваються формально на всьому інтервалі від `-∞` до `+∞`, у фізиці магнетизму використовують два довідкові означення товщини стінки:

### 1. Визначення за дотичною Ліфшиця (Lilley / Lifshitz definition)
Ефективна товщина стінки `δ_w` визначається як відстань між точками перетину дотичної, проведеної до профілю `θ(x)` у її центрі (`x = 0`), з асимптотичними значеннями `θ = 0` та `θ = π`:

```
δ_w = π / ( dθ / dx )_max

δ_w = π · √( A / K )                              [ефективна товщина стінки Блоха]
```

### 2. Експериментальне визначення (90% повного кута)
Товщина шарніра, на якому кут зміщується від `0.05·π` до `0.95·π`, дорівнює приблизно `Δx ≈ 3.5 · √(A/K)`.

## 5. Обчислення поверхневої густини енергії стінки

Для обчислення повної поверхневої енергії `γ_w` підставимо рівність `A·(dθ/dx)² = K·sin²(θ)` у функціонал енергії:

```
γ_w = ∫ [ A · ( dθ / dx )² + K · sin²(θ) ] dx

γ_w = 2 · ∫ K · sin²(θ) dx                       [перехід до інтегрування по куту]
```

Перейдемо від інтегрування по координаті `x` до інтегрування по куту `θ`, використовуючи заміну `dx = √(A/K) · dθ / sin(θ)`:

```
γ_w = 2 · ∫ [ K · sin²(θ) · √( A / K ) / sin(θ) ] dθ

γ_w = 2 · √( A · K ) · ∫ sin(θ) dθ               [інтеграл від 0 до π]
```

Інтеграл від синуса дорівнює `∫₀^π sin(θ) dθ = [ -cos(θ) ]₀^π = 1 - (-1) = 2`.

Підставляючи це значення, маємо точну аналітичну формулу поверхневої густини енергії 180-градусної стінки Блоха:

```
γ_w = 4 · √( A · K )                              [поверхнева енергія стінки Блоха]
```

## 6. Чисельний розрахунок та порівняння для реальних феромагнетиків

Підставимо експериментальні значення параметрів обміну `A` та анізотропії `K` для трьох класичних феромагнетиків та одного сучасного рідкісноземельного матеріалу:

1. **Альфа-залізо (`α-Fe`):**
   - `A = 2.0 · 10⁻¹¹` Дж/м, `K_1 = 4.8 · 10⁴` Дж/м³;
   - `x_0 = √( 2.0·10⁻¹¹ / 4.8·10⁴ ) ≈ 2.04 · 10⁻⁸` м (`20.4` нм);
   - `δ_w = π · x_0 ≈ 64.1` нм;
   - `γ_w = 4 · √( 2.0·10⁻¹¹ · 4.8·10⁴ ) ≈ 3.92 · 10⁻³` Дж/м².

2. **Гексагональний кобальт (`Co`):**
   - `A = 1.05 · 10⁻¹¹` Дж/м, `K_1 = 4.1 · 10⁵` Дж/м³ (висока одноосьова анізотропія);
   - `x_0 = √( 1.05·10⁻¹¹ / 4.1·10⁵ ) ≈ 5.06 · 10⁻⁹` м (`5.06` нм);
   - `δ_w = π · x_0 ≈ 15.9` нм (значно тонша стінка через високу анізотропію);
   - `γ_w = 4 · √( 1.05·10⁻¹¹ · 4.1·10⁵ ) ≈ 8.30 · 10⁻³` Дж/м².

3. **Нікель (`Ni`):**
   - `A = 0.9 · 10⁻¹¹` Дж/м, `K_1 = 4.5 · 10³` Дж/м³ (слабка анізотропія);
   - `δ_w ≈ 140` нм;
   - `γ_w ≈ 0.80 · 10⁻³` Дж/м².

4. **Магнітотвердий сплав `Nd₂Fe₁₄B`:**
   - `A = 0.77 · 10⁻¹¹` Дж/м, `K_1 = 4.9 · 10⁶` Дж/м³ (надвисока кристалічна анізотропія);
   - `δ_w ≈ 3.9` нм (усього близько 7-8 атомних шарів);
   - `γ_w ≈ 24.5 · 10⁻³` Дж/м².

Отже, чим вища константа магнітокристалічної анізотропії `K`, тим тоншою є доменна стінка і тим більша її поверхнева енергія `γ_w`.
