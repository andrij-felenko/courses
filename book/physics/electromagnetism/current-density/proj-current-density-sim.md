# ⚙️ Моделювання розподілу щільності струму методом кінцевих різниць

Розробка чисельного солвера методом кінцевих різниць (FDM) дає змогу розрахувати двовимірне поле потенціалу `V(x, y)` та вектор щільності струму `J(x, y) = -σ · ∇V` у металевій пластині зі звуженням або отвором.

## 1. Фізичне підґрунтя та математична формулювання моделі

При проективанні силових шин інверторів, вимірювальних струмових шунтів та друкованих плат високочастотних пристроїв інженерам необхідно знати не лише загальний опір провідника, а й детальний двовимірний або тривимірний розподіл вектора щільності струму `J(x, y)`. Наявність отворів, звужень або внутрішніх вирізів призводить до згущення ліній струму, виникнення локальних гарячих точок (hotspots) та ризику термічного руйнування матеріалу.

У стаціонарному режимі проходження постійного струму через однорідну ізотропну металеву пластину з питомою провідністю `σ` виконуються два фундаментальні співвідношення електродинаміки суцільних середовищ:

1. **Диференціальний закон Ома:**
   Вектор щільності струму прямо пропорційний градієнту скалярного електричного потенціалу `V`:
   ```
   J = -σ · ∇V
   ```
2. **Диференціальне рівняння неперервності:**
   За відсутності внутрішніх джерел або накопичення заряду дивергенція вектора щільності струму дорівнює нулю:
   ```
   ∇ · J = 0
   ```

Підставляючи диференціальний закон Ома у рівняння неперервності та враховуючи постійність питомої провідності `σ = const`, отримуємо двовимірне **рівняння Лапласа** для скалярного електростатичного потенціалу `V(x, y)`:

```
∇ · (-σ · ∇V) = 0  ⇒  ∇²V = ∂²V/∂x² + ∂²V/∂y² = 0
```

Отже, розрахунок розподілу струму розбивається на два послідовні етапи:
1. Знаходження розв'язку рівняння Лапласа для скалярного поля потенціалу `V(x, y)` у заданій геометрії з відповідними граничними умовами.
2. Чисельне диференціювання отриманого поля потенціалу для обчислення компонентів вектора щільності струму `J_x = -σ · ∂V/∂x` та `J_y = -σ · ∂V/∂y`.

## 2. Дискретизація методом кінцевих різниць на прямокутній сітці

Для чисельного розв'язання рівняння Лапласа прямокутну область провідника розміром `L_x × L_y` покривають рівномірною сіткою вузлів розміром `NX × NY`. Крок сітки по обох координатах вибирається однаковим: `h = Δx = Δy`.

Другі часткові похідні потенціалу в кожному внутрішньому вузлі сітки `(i, j)` апроксимуються за допомогою центральних кінцевих різниць другого порядку точності:

```
∂²V/∂x² ≈ [ V(i+1, j) - 2·V(i, j) + V(i-1, j) ] / h²
∂²V/∂y² ≈ [ V(i, j+1) - 2·V(i, j) + V(i, j-1) ] / h²
```

Підставляючи ці кінцево-різницеві оператори у рівняння Лапласа `∂²V/∂x² + ∂²V/∂y² = 0` та скорочуючи на `h²`, отримуємо класичний 5-точковий різницевий шаблон «хрест»:

```
V(i+1, j) + V(i-1, j) + V(i, j+1) + V(i, j-1) - 4·V(i, j) = 0
```

Виражаючи потенціал у центральному вузлі `V(i, j)`, отримуємо базову ітераційну формулу: значення потенціалу у даному вузлі дорівнює средньому арифметичному значень потенціалу у чотирьох сусідніх вузлах:

```
V(i, j) = 0.25 · [ V(i+1, j) + V(i-1, j) + V(i, j+1) + V(i, j-1) ]
```

Ця формула лежить в основі релаксаційного ітераційного методу Гаусса–Зайделя, у якому розв'язок уточнюється циклічним обходом усіх вузлів сітки до досягнення потрібної точності.

## 3. Обробка граничних умов та геометрії провідника

Для моделювання провідника зі звуженнями, вирізами або отворами вводять двовимірну матрицю маски `mask[j][i]`:
- `mask[j][i] = 1` — вузол належить металевому провіднику.
- `mask[j][i] = 0` — вузол належить діелектрику (повітрю або вирізу).

Граничні умови діляться на два типи:

1. **Граничні умови Дирихле (фіксований потенціал):**
   На точках контакту із зовнішнім джерелом живлення задаються постійні значення потенціалу. На лівій межі `i = 0` підключається потенціал `V = V_in = 10.0` В, на правому виході `i = NX - 1` задається потенціал `V = 0.0` В.

2. **Граничні умови Неймана (ізольовані межі):**
   На внутрішніх і зовнішніх межах контакту провідника з повітрям нормальна складова струму повинна дорівнювати нулю (`J_n = 0`). За законом Ома це означає відсутність нормального градієнта потенціалу `∂V / ∂n = 0`.
   У різницеві алгоритми це впроваджують шляхом адаптивного усереднення: потенціал вузла обчислюється як середнє значення лише по тих сусідніх вузлах, які також лежать всередині провідника (`mask == 1`).

Після завершення ітераційного процесу Гаусса–Зайделя складові вектора щільності струму `J_x(i, j)` та `J_y(i, j)` обчислюються чисельним диференціюванням поля `V`:

```
J_x(i, j) = -σ · [ V(i+1, j) - V(i-1, j) ] / (2 · h)
J_y(i, j) = -σ · [ V(i, j+1) - V(i, j-1) ] / (2 · h)
```

Модуль вектора щільності струму визначається за теоремою Піфагора: `J_mag = √( J_x² + J_y² )`.

## 4. Реалізація розв'язувача (C та C++)

Нижче наведено робочі чисельні розв'язувачі мовами C та C++ для сітки `64×32` з геометрією провідника, що має прямокутне звуження в центральній частині.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define NX 64
#define NY 32
#define MAX_ITER 5000
#define TOL 1e-5
#define SIGMA 5.8e7  /* Питома провідність міді [См/м] */

typedef struct {
    double v[NY][NX];
    double jx[NY][NX];
    double jy[NY][NX];
    int mask[NY][NX];  /* 1 - провідник, 0 - отвір / повітря */
} FieldGrid;

void init_grid(FieldGrid *g) {
    int i, j;
    for (j = 0; j < NY; j++) {
        for (i = 0; i < NX; i++) {
            g->v[j][i] = 0.0;
            g->jx[j][i] = 0.0;
            g->jy[j][i] = 0.0;
            g->mask[j][i] = 1;
            
            /* Створюємо прямокутне звуження (вирізи зверху й знизу в центрі) */
            if (i >= 24 && i <= 40) {
                if (j < 10 || j > 21) {
                    g->mask[j][i] = 0; /* виріз */
                }
            }
        }
    }
    
    /* Граничні умови Дирихле: Вхід V = 10.0 В (i=0), Вихід V = 0.0 В (i=NX-1) */
    for (j = 0; j < NY; j++) {
        if (g->mask[j][0]) g->v[j][0] = 10.0;
        if (g->mask[j][NX-1]) g->v[j][NX-1] = 0.0;
    }
}

void solve_potential(FieldGrid *g) {
    int iter, i, j;
    double max_diff;

    for (iter = 0; iter < MAX_ITER; iter++) {
        max_diff = 0.0;
        for (j = 1; j < NY - 1; j++) {
            for (i = 1; i < NX - 1; i++) {
                if (!g->mask[j][i]) continue;

                double old_v = g->v[j][i];
                double sum = 0.0;
                int count = 0;

                /* Ураховуємо диференціальні межі з ізолятором */
                if (g->mask[j][i+1]) { sum += g->v[j][i+1]; count++; }
                if (g->mask[j][i-1]) { sum += g->v[j][i-1]; count++; }
                if (g->mask[j+1][i]) { sum += g->v[j+1][i]; count++; }
                if (g->mask[j-1][i]) { sum += g->v[j-1][i]; count++; }

                if (count > 0) {
                    g->v[j][i] = sum / (double)count;
                    double diff = fabs(g->v[j][i] - old_v);
                    if (diff > max_diff) max_diff = diff;
                }
            }
        }
        if (max_diff < TOL) break;
    }
}

void compute_current_density(FieldGrid *g, double h) {
    int i, j;
    for (j = 1; j < NY - 1; j++) {
        for (i = 1; i < NX - 1; i++) {
            if (!g->mask[j][i]) continue;

            double dv_dx = (g->v[j][i+1] - g->v[j][i-1]) / (2.0 * h);
            double dv_dy = (g->v[j+1][i] - g->v[j-1][i]) / (2.0 * h);

            g->jx[j][i] = -SIGMA * dv_dx;
            g->jy[j][i] = -SIGMA * dv_dy;
        }
    }
}

int main(void) {
    FieldGrid *grid = (FieldGrid *)calloc(1, sizeof(FieldGrid));
    if (!grid) return 1;

    init_grid(grid);
    solve_potential(grid);
    compute_current_density(grid, 0.001); /* крок сітки h = 1 мм */

    /* Виводимо значення щільності струму у центрі звуження (i=32, j=16) */
    double j_mag = sqrt(grid->jx[16][32] * grid->jx[16][32] + grid->jy[16][32] * grid->jy[16][32]);
    printf("Розрахунок завершено.\n");
    printf("Щільність струму у звуженні J(32,16) = %.3e А/м²\n", j_mag);

    free(grid);
    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <memory>
#include <iomanip>

constexpr std::size_t NX = 64;
constexpr std::size_t NY = 32;
constexpr std::size_t MAX_ITER = 5000;
constexpr double TOL = 1e-5;
constexpr double SIGMA = 5.8e7; // См/м

struct Vector2D {
    double x{0.0};
    double y{0.0};
    [[nodiscard]] double magnitude() const noexcept {
        return std::hypot(x, y);
    }
};

class CurrentDensitySolver {
public:
    CurrentDensitySolver(std::size_t nx, std::size_t ny, double grid_step)
        : m_nx(nx), m_ny(ny), m_h(grid_step),
          m_v(ny, std::vector<double>(nx, 0.0)),
          m_j(ny, std::vector<Vector2D>(nx)),
          m_mask(ny, std::vector<bool>(nx, true)) 
    {
        init_geometry();
    }

    void solve() {
        for (std::size_t iter = 0; iter < MAX_ITER; ++iter) {
            double max_diff = 0.0;
            for (std::size_t j = 1; j < m_ny - 1; ++j) {
                for (std::size_t i = 1; i < m_nx - 1; ++i) {
                    if (!m_mask[j][i]) continue;

                    double old_v = m_v[j][i];
                    double sum = 0.0;
                    int count = 0;

                    if (m_mask[j][i + 1]) { sum += m_v[j][i + 1]; count++; }
                    if (m_mask[j][i - 1]) { sum += m_v[j][i - 1]; count++; }
                    if (m_mask[j + 1][i]) { sum += m_v[j + 1][i]; count++; }
                    if (m_mask[j - 1][i]) { sum += m_v[j - 1][i]; count++; }

                    if (count > 0) {
                        m_v[j][i] = sum / count;
                        max_diff = std::max(max_diff, std::abs(m_v[j][i] - old_v));
                    }
                }
            }
            if (max_diff < TOL) break;
        }

        compute_field();
    }

    [[nodiscard]] Vector2D current_density(std::size_t i, std::size_t j) const {
        return m_j.at(j).at(i);
    }

private:
    void init_geometry() {
        for (std::size_t j = 0; j < m_ny; ++j) {
            for (std::size_t i = 0; i < m_nx; ++i) {
                if (i >= 24 && i <= 40) {
                    if (j < 10 || j > 21) {
                        m_mask[j][i] = false; // Звуження
                    }
                }
            }
        }

        // Граничні умови
        for (std::size_t j = 0; j < m_ny; ++j) {
            if (m_mask[j][0]) m_v[j][0] = 10.0;
            if (m_mask[j][m_nx - 1]) m_v[j][m_nx - 1] = 0.0;
        }
    }

    void compute_field() {
        for (std::size_t j = 1; j < m_ny - 1; ++j) {
            for (std::size_t i = 1; i < m_nx - 1; ++i) {
                if (!m_mask[j][i]) continue;

                double dv_dx = (m_v[j][i + 1] - m_v[j][i - 1]) / (2.0 * m_h);
                double dv_dy = (m_v[j + 1][i] - m_v[j - 1][i]) / (2.0 * m_h);

                m_j[j][i] = {-SIGMA * dv_dx, -SIGMA * dv_dy};
            }
        }
    }

    std::size_t m_nx, m_ny;
    double m_h;
    std::vector<std::vector<double>> m_v;
    std::vector<std::vector<Vector2D>> m_j;
    std::vector<std::vector<bool>> m_mask;
};

int main() {
    CurrentDensitySolver solver(NX, NY, 0.001); // h = 1 мм
    solver.solve();

    auto j_center = solver.current_density(32, 16);
    std::cout << std::scientific << std::setprecision(3);
    std::cout << "C++ Солвер успішно виконано.\n";
    std::cout << "Модуль щільності струму J у звуженні: " << j_center.magnitude() << " А/м²\n";

    return 0;
}
```

## 5. Практичні інженерні пастки чисельного моделювання

1. **Граничні умови Неймана на складному контурі:** У наведеному коді межа ізоляції врахована через підрахунок сусідніх провідних вузлів. Для складних криволінійних поверхонь (круглі отвори, заокруглення доріжок) слід застосовувати метод занурених меж (Immersed Boundary Method) або зсунуті сітки, інакше на східчастих межах виникають хибні локальні осциляції та штучне концентрація струму.
2. **Швидкість збіжності на великих сітках:** Простий метод Гаусса–Зайделя має кількість ітерацій `N_iter ∝ N²`, де `N` — кількість вузлів по одній осі. Для детальних сіток розміром `1024×1024` метод Гаусса–Зайделя вимагатиме сотень тисяч ітерацій. Щоб прискорити обчислення у 100–1000 разів, застосовують метод послідовної верхньої релаксації (SOR) з оптимальним параметром релаксації `ω_opt = 2 / (1 + sin(π / N))`, або мультисіткові розв'язувачі (Multigrid solvers).
3. **Обчислення локального тепловиділення:** Після обчислення поля `J_x(i, j)` та `J_y(i, j)` питоме тепловиділення у кожній комірці розраховується за формулою `w(i, j) = ( J_x² + J_y² ) / σ`. Отримане скалярне поле `w(i, j)` слугує джерелом тепла для розв'язання стаціонарного або динамічного рівняння теплопровідності `-k_th · ∇²T = w`, що дозволяє отримати повну самоузгоджену електро-теплову модель плати.
4. **Перевірка фізичного балансу струму:** Обов'язковим тестом правильності чисельного розв'язку є інтегрування чисельного потоку струму `I = ∑ J_x · h` по різних вертикальних перерізах плати (на широкій ділянці та у звуженні). Сумарний струм через будь-який переріз повинен зберігатися з точністю до порогу збіжності `TOL`.
