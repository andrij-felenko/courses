# 📜 Історія відкриття закону неперервності струму

Історичний шлях становлення концепції векторної щільності струму та диференціального закону збереження електричного заряду пролягав від перших макроскопічних дослідів Андре-Марі Ампера та Ґеорґа Ома до векторної електродинаміки Джеймса Клерка Максвелла, електронної теорії Пауля Друде та квантово-механічного опису струмів.

## 1. Довекторна ера: струм як рідина у макроскопічних провідниках

У першій третині XIX століття, після знаменитого відкриття Ганса Крістіана Ерстеда у 1820 році про відхилення магнітної стрілки поблизу провідника зі струмом, електрика почала стрімко перетворюватися з науки про статичні заряди на динамічну дисципліну. Французький фізик Андре-Марі Ампер заклав основи електродинаміки, ввівши фундаментальне поняття сили струму та сформулювавши закон взаємодії двох елементів струму.

Проте в епоху Ампера електричний струм уявлявся вченими як виключно макроскопічна величина — «гальванічний потік», що протікає по всій товщі металевого дроту подібно до нестисливої рідини у трубі. Ампер і його сучасники вимірювали лише загальну силу струму `I`, оскільки тогочасні вимірювальні прилади (прості магнітні стрілки, гальваноскопи та мультиплікатори Швейгера) інтегрували магнітну дію по всьому перерізу провідника і не мали змоги розрізнити просторову неоднорідність усередині об'єму.

У 1826 році німецький шкільний вчитель фізики Ґеорґ Симон Ом опублікував результати своїх прецизійних експериментів із термоелектричними колами. Ом математично сформулював знаменитий закон `I = V / R`, пов'язавши силу струму у колі з електрорушійною силою джерела та опором провідника. Дослід Ома мав колосальне практичне значення, але він описував лише суцільний провідник постійного перерізу. Поведінка струму всередині складних тривимірних тіл — металевих блоків, кулей, рідинних електролітів чи поверхонь складної форми — залишалася повнісінькою таємницею.

## 2. Поява векторного опису: внесок Ґустава Кірхгофа

Перший вирішальний крок від макроскопічного струму `I` до локального просторового опису зробив у 1845 році 21-річний німецький фізик Ґустав Роберт Кірхгоф. Досліджуючи проходження струму через металеві пластини довільної форми, Кірхгоф зрозумів, що опис через єдину скалярну величину `I` є абсолютно непридатним для двовимірних і тривимірних середовищ.

Кірхгоф уперше ввів у науковий вжиток поняття локальної щільності струму `J` як вектору, спрямованого уздовж лінії протікання заряду у даній точці простору. Впровадивши потенціал електричного поля усередині суцільного провідника `V(x, y, z)`, Кірхгоф узагальнив закон Ома у диференціальній формі:

```
J = -σ · ∇V
```

де `σ` — питома провідність речовини. Далі, застосувавши принцип збереження заряду до елементарного об'єму речовини, Кірхгоф вивів диференціальне рівняння для стаціонарного струму у тривимірному провіднику:

```
∇ · J = ∇ · (-σ · ∇V) = 0
```

Для однорідного середовища це співвідношення трансформувалося у знамените рівняння Лапласа для потенціалу `∇²V = 0`. Праці Кірхгофа стали теоретичним фундаментом, на якому постала вся теорія роподілу струмів у об'ємних провідниках, заземлювачах та електролітичних ваннах. Знамениті два правила Кірхгофа для електричних кіл виявилися лише дискретним частковим випадком цього диференціального закону неперервності.

## 3. Максвелл і струм зміщення: повнота електродинаміки

У 1860–1873 роках шотландський фізик-теоретик Джеймс Клерк Максвелл створив класичну електродинаміку суцільних середовищ. Узагальнюючи накопичені експериментальні факти у вигляд системи диференціальних рівнянь поля, Максвелл зіткнувся з глибокою фундаментальною суперечністю у законі повного струму Ампера `∇ × H = J`.

Завдяки математичній тотожності, дивергенція ротора будь-якого векторного поля тотожно дорівнює нулю (`∇ · (∇ × H) = 0`). Це означало, що з закону Ампера автоматично випливає умова `∇ · J = 0`, тобто векторне поле щільності струму завжди має бути соленоїдальним (без джерел і стоків). Проте при проходженні змінного струму через коло з конденсатором густина заряду на обкладках змінюється в часі (`∂ρ / ∂t ≠ 0`), і за закон збереження заряду `∇ · J = -∂ρ / ∂t` щільність струму провідності `J` на межі діелектрика обривається!

Щоб подолати цей розрив і зберегти фізичну узгодженість теорії, Максвелл зробив один із найвеличніших теоретичних кроків у історії фізики. Він припустив, що змінне електричне поле у діелектрику або вакуумі діє подібно до електричного струму і викликає таке саме вихрове магнітне поле. Максвелл дав цьому явищу назву **струм зміщення** (displacement current) і визначив його щільність як часткову похідну вектора електричного зсуву по часу:

```
J_d = ∂D / ∂t = ε_0 · ∂E / ∂t + ∂P / ∂t
```

Додавши щільність струму зміщення до щільності струму провідності `J_c`, Максвелл отримав вектор повної щільності струму:

```
J_total = J_c + ∂D / ∂t
```

Для повної щільності струму рівняння неперервності виконувалося тотожно у будь-яких середовищах і на будь-яких частотах. Це гіпотетичне припущення Максвелла математично передбачило існування електромагнітних хвиль, що згодом було блискуче підтверджено експериментами Генріха Герца у 1887 році.

## 4. Мікроскопічні моделі: Друде, Лоренц та квантова фізика

Наприкінці XIX століття відкриття електрона Джозефом Джоном Томсоном (1897 рік) поставило перед фізиками завдання вивести макроскопічний вектор `J` з руху елементарних носіїв заряду.

У 1900 році німецький фізик Пауль Друде сформулював класичну електронну теорію металів. Друде припустив, що металевий провідник містить газ вільних електронів, які хаотично рухаються між важкими позитивними іонами кристалічної ґратки. Під дією електричного поля електрони набувають дрейфової швидкості `v_d`. Друде вперше вивів мікроскопічну формулу щільності струму `J = n · q · v_d` та пояснив диференціальний закон Ома на основі середнього часу між зіткненнями `τ`.

Нідерландський фізик Хендрік Антон Лоренц розширив модель Друде, побудувавши мікроскопічну електронну теорію. Лоренц показав, що макроскопічні вектори `J` та `ρ` у рівняннях Максвелла є результатом статистичного усереднення по просторових мікрооб'ємах руху колосальної кількості окремих точкових зарядів.

З появою квантової механіки у 1920-х роках уявлення про щільність струму набуло нового змісту. В квантовій механіці електрон описується хвильовою функцією `Ψ(r, t)`. У 1926 році Макс Борн та Ервін Шредінґер ввели поняття вектора густини потоку ймовірності `J_prob`, який описує перенесення ймовірності виявлення частинки у просторі:

```
J_prob = ( ħ / (2 · m · j) ) · [ Ψ* · ∇Ψ - Ψ · ∇Ψ* ]
```

Множення квантового вектора `J_prob` на заряд частинки `q` дає квантово-механічний вектор щільності електричного струму. У 1928 році Арнольд Зоммерфельд застосував статистику Фермі–Дірака до електронного газу, пояснивши, чому при проходженні струму беруть участь лише електрони з енергіями, близькими до рівня Фермі. На основі цього Фелікс Блох вивів теорію зонної структури твердих тіл, розкривши природу різниці між провідниками, напівпровідниками та діелектриками.

У 1935 році німецькі фізики брати Фріц та Хайнц Лондон, досліджуючи явище надпровідності, сформулювали феноменологічні рівняння Лондонів, які пов'язали густину надпровідного струму `J_s` безпосередньо з векторним потенціалом магнітного поля `A`:

```
J_s = - A / ( μ_0 · λ_L² )
```

це пояснило ефект Мейснера–Оксенфельда — виштовхування магнітного поля з об'єму надпровідника.

Сьогодні концепція векторної щільності струму є фундаментальною у релятивістській фізиці (де струм і густина заряду об'єднуються у 4-вектор струму `J^μ = (cρ, J)`), теорії плазми, астрофізиці та квантової наноелектроніці.
