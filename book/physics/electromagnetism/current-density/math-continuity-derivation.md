# 🧮 Виведення рівняння неперервності та тензорного закону Ома

Ця вставка містить строгі математичні виведення диференціального рівняння неперервності заряду, алгоритм перетворення тензора провідності анізотропного середовища при повороті системи координат, диференціальне виведення рівняння скінового шару з повного комплексу рівнянь Максвелла, а також інтегральне представлення потенціалу через функції Ґріна.

## 1. Строгий вивід диференціального рівняння неперервності

Розглянемо замкнену область простору об'ємом `V`, обмежену гладкою поверхнею `S = ∂V`. Повний електричний заряд `Q(t)` усередині цього об'єму визначається об'ємним інтегралом від скалярного поля густини заряду `ρ(x, y, z, t)`:

```
Q(t) = ∭_V ρ(x, y, z, t) · dx dy dz
```

Поточний макроскопічний струм `I_out`, який витікає з об'єму `V` через зовнішню поверхню `S`, дорівнює поверхневому інтегралу від вектора щільності струму `J`:

```
I_out = ∬_S J · dA = ∬_S (J_x · dy dz + J_y · dx dz + J_z · dx dy)
```

Згідно з фундаментальним законом збереження заряду, швидкість зменшення заряду усередині об'єму `-dQ/dt` має точно дорівнювати сумарному витікаючому струму `I_out`:

```
∬_S J · dA = - d/dt ( ∭_V ρ · dV )
```

Оскільки об'єм `V` є фіксованим у просторі та не змінюється в часі, операцію диференціювання по часовій змінній `t` під інтегралом можна перетворити на часткову похідну підінтегральної функції:

```
- d/dt ( ∭_V ρ · dV ) = ∭_V ( - ∂ρ / ∂t ) · dV
```

Застосуємо математичну теорему Гаусса–Остроградського (теорему про дивергенцію) для векторного поля `J`. Для будь-якого неперервно диференційовного векторного поля потік через замкнену поверхню дорівнює об'ємному інтегралу від його дивергенції по обмеженому цією поверхнею об'єму:

```
∬_S J · dA = ∭_V ( ∇ · J ) · dV
```

Прирівнюючи ліву і праву частини інтегральної рівності, отримуємо:

```
∭_V ( ∇ · J ) · dV = ∭_V ( - ∂ρ / ∂t ) · dV
```

Перенесемо всі доданки в ліву частину під спільний знак об'ємного інтеграла:

```
∭_V ( ∇ · J + ∂ρ / ∂t ) · dV = 0      [рівняння для довільного об'єму V]
```

Оскільки це співвідношення виконується для абсолютно довільної області `V`, підінтегральна функція повинна тотожно дорівнювати нулю в кожній точці простору:

```
∇ · J + ∂ρ / ∂t = 0
```

У декартовій системі координат оператор дивергенції розгортається у суму часткових похідних по трьох просторових координатах:

```
∂J_x / ∂x + ∂J_y / ∂y + ∂J_z / ∂z + ∂ρ / ∂t = 0
```

Для стаціонарного струму розподіл густини заряду в часі не змінюється (`∂ρ / ∂t = 0`), що дає рівняння безджерельного векторного поля:

```
∇ · J = 0
```

## 2. Тензор провідності та діагоналізація при повороті осей

У анізотропному кристалі зв'язок між векторами `J` та `E` записується через тензор питомої провідності `σ̂`:

```
J_i = ∑_{j=1}³ σ_ij · E_j
```

При переході від початкової системи координат `(x, y, z)` до нової повернутої системи `(x', y', z')` за допомогою ортогональної матриці повороту `R` (де `R^T · R = I` та `det(R) = 1`) вектори електричного поля та щільності струму перетворюються за законами векторного числення:

```
E' = R · E
J' = R · J
```

Підставляючи диференціальний закон Ома `J = σ̂ · E` у вираз для повернутого вектора струму `J'`:

```
J' = R · ( σ̂ · E )
   = R · σ̂ · ( R^T · E' )      [оскільки E = R^T · E']
   = ( R · σ̂ · R^T ) · E'
```

Отже, тензор провідності у новій повернутій системі координат перетворюється за законом тензорного спряження:

```
σ̂' = R · σ̂ · R^T
```

Згідно з математичною теоремою про спектральний розклад симетричних матриць (співвідношення Онсагера гарантують симетрію `σ_ij = σ_ji` за відсутності магнітного поля), завжди існує така орієнтація базисних осей (головні осі кристала), у якій недіагональні елементи тензора перетворюються на нуль, а матриця набуває строго діагонального вигляду:

```
┌ σ_xx'   0      0   ┐
σ̂' = │   0    σ_yy'   0   │
└   0      0    σ_zz' ┘
```

У головних осях анізотропного середовища диференціальний закон Ома розпадається на три незалежні скалярні рівняння:

```
J_x' = σ_xx' · E_x'
J_y' = σ_yy' · E_y'
J_z' = σ_zz' · E_z'
```

Головні значення `σ_xx'`, `σ_yy'`, `σ_zz'` характеризують власні провідності кристала уздовж його симетричних напрямків.

## 3. Диференціальне виведення рівняння скінового ефекту

Для виведення просторового розподілу щільності змінного струму `J(z)` всередині однорідного провідника з питомим опором `ρ_e = 1 / σ` та магнітною проникністю `μ = μ_0 · μ_r` використаємо повний комплекс рівнянь Максвелла у квазістаціонарному наближенні.

Запишемо диференціальні рівняння Максвелла для провідного середовища (нехтуючи струмом зміщення `∂D / ∂t` порівняно зі струмом провідності `J` для частот `f < 10¹¹` Гц):

```
1) ∇ × E = - ∂B / ∂t = - μ · ∂H / ∂t    [Закон електромагнітної індукції Фарадея]
2) ∇ × H = J                             [Закон повного струму Ампера]
3) J = σ · E                             [Диференціальний закон Ома]
```

Застосуємо векторний оператор ротора `∇ ×` до обох частин диференціального закону Ома (3):

```
∇ × J = σ · ( ∇ × E )
```

Підставимо у праву частину цього виразу закон індукції Фарадея (1):

```
∇ × J = - σ · μ · ( ∂H / ∂t )
```

Тепер візьмемо часткову похідну по часу від обох частин закону Ампера (2):

```
∂/∂t ( ∇ × H ) = ∇ × ( ∂H / ∂t ) = ∂J / ∂t
```

Застосуємо оператор ротора ще раз до рівняння для `∇ × J`:

```
∇ × ( ∇ × J ) = - σ · μ · ∇ × ( ∂H / ∂t ) = - σ · μ · ( ∂J / ∂t )
```

Скористаємося відомою векторною тотожністю для подвійного ротора довільного векторного поля:

```
∇ × ( ∇ × J ) = ∇( ∇ · J ) - ∇² J
```

Оскільки у однорідному ізотропному провіднику вільний об'ємний заряд відсутній (`ρ = 0`), з диференціального рівняння неперервності випливає `∇ · J = 0`. Звідси ліва частина спрощується до `-∇² J`:

```
- ∇² J = - σ · μ · ( ∂J / ∂t )
```

або у формі класичного дифузійного рівняння для векторного поля щільності струму:

```
∇² J = σ · μ · ( ∂J / ∂t )              [Дифузійне рівняння для J]
```

Розглянемо плоский масивний провідник, що займає півпростір `z ≥ 0`. Нехай струм спрямований уздовж осі `X` (`J = J_x(z, t) · î`), а його амплітуда змінюється за гармонічним законом із круговою частотою `ω = 2π f`:

```
J_x(z, t) = Re[ Ĵ_x(z) · e^(j·ω·t) ]
```

Підставляючи часову похідну `∂ / ∂t → j·ω` у дифузійне рівняння:

```
d² Ĵ_x / dz² = j · ω · μ · σ · Ĵ_x
```

Введемо комплексне хвильове число `γ`:

```
γ² = j · ω · μ · σ
```

Скористаємося тотожністю для квадратного кореня з уявної одиниці `√j = (1 + j) / √2`:

```
γ = √(j · ω · μ · σ) = (1 + j) · √( ω · μ · σ / 2 )
```

Позначимо величину `δ = √( 2 / (ω · μ · σ) ) = √( ρ_e / (π · f · μ) )`. Тоді комплексне хвильове число записується як `γ = (1 + j) / δ`.

Загальний математичний розв'язок отриманого диференціального рівняння другого порядку має вигляд суми двох експонент:

```
Ĵ_x(z) = C₁ · e^(-γ · z) + C₂ · e^(+γ · z)
```

З фізичної умови скінченності струму глибині провідника (`Ĵ_x → 0` при `z → ∞`) випливає, що константа `C₂ = 0`. Константа `C₁ = J_0` дорівнює амплітуді щільності струму безпосередньо на поверхні `z = 0`.

Підставляючи значення `γ` та переходячи до дійсної частини комплексного виразу, отримуємо остаточний математичний закон скінового ефекту:

```
J_x(z, t) = J_0 · e^(-z / δ) · cos( ω·t - z / δ )
```

Цей розв'язок показує, що щільність струму спадає вглиб провідника за експоненційним законом із характеристичним масштабом `δ` (скіношаром), а фаза коливань струму зсувається на кут `z / δ` рад пропорційно глибині занурення.

## 4. Функція Ґріна для розподілу потенціалу у об'ємному провіднику

При чисельному та аналітичному розрахунку розподілу струмів у тривимірних середовищах із заданими точковими джерелами струму (наприклад, при розрахунку опору заземлювальних електродів або 4-зондовому вимірюванні опору напівпровідникових пластин) розв'язують неоднорідне рівняння Пуассона для потенціалу:

```
∇² V = - I_in / σ · δ(r - r_0)
```

де `δ(r - r_0)` — тривимірна дельта-функція Дірака, що описує точковий вхід струму `I_in` у точці `r_0`.

Функція Ґріна `G(r, r_0)` для нескінченного однорідного середовища задовольняє рівняння `∇² G = -δ(r - r_0)` і має вигляд:

```
G(r, r_0) = 1 / ( 4π · |r - r_0| )
```

Звідси потенціал, створений точковим джерелом струму `I_in` у нескінченному провідному середовищі, дорівнює:

```
V(r) = ( I_in / (4π · σ) ) · ( 1 / |r - r_0| )
```

Вектор щільності струму `J(r)` у будь-якій точці об'єму обчислюється як градієнт цього потенціалу:

```
J(r) = -σ · ∇V = ( I_in / (4π) ) · ( (r - r_0) / |r - r_0|³ )
```

Для півпростору (наприклад, при подачі струму на поверхню землі або металевого блоку) застосовують метод дзеркальних зображень, що дає подвоєну щільність струму на поверхні: `J(r) = ( I_in / (2π) ) · (1 / r²)`.
