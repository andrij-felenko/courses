# 🧮 Математика перетворення та втрат у лініях HVDC

Ця вставка містить кількісний математичний розрахунок фізичних процесів у лініях передачі постійного струму високої напруги (HVDC). Наведено рівняння ємнісного струму заряду кабелю, математичну модель 6- та 12-пульсного вентильного мосту LCC із урахуванням кута комутаційного перекриття, а також виведення формули для економічної точки рівноцінності (Break-even distance).

---

### 1. Фізична межа AC-кабелю: ємнісний струм заряду

Підводний або підземний кабель має високу погонну ємність `C_km` через малу товщину діелектрика між центральною жилою та заземленим металевим екраном (типове значення `C_km = 0.2 ... 0.35 мкФ/км`).

Для трифазної лінії змінного струму частотою `f = 50 Гц` (`ω = 2·π·f = 314.16 рад/с`) та фазною напругою `U_ph = U / √3` ємнісний струм заряду на кожен кілометр лінії становить:

```
I_c_km = ω · C_km · U_ph = ω · C_km · (U / √3)
```

На довжині кабелю `L` сумарний ємнісний струм дорівнює:

```
I_C(L) = L · I_c_km = L · ω · C_km · (U / √3)
```

Оскільки кабель має граничний термічний струм `I_max` (за умовою нагріву жили), повний струм `I_total` є геометричною сумою активного струму передачі потужності `I_P` та реактивного ємнісного струму `I_C`:

```
I_total = √(I_P² + I_C²) ≤ I_max
```

Звідси максимально допустимий активний струм, що залишається для передачі корисної потужності:

```
I_P(L) = √(I_max² - I_C(L)²)
```

Критична довжина кабелю `L_crit` настає тоді, коли ємнісний струм повністю заповнює допустиму пропускну здатність провідника (`I_C(L_crit) = I_max`), і для корисної потужності залишається нуль (`I_P = 0`):

```
L_crit = (√3 · I_max) / (ω · C_km · U)
```

**Чисельний приклад (AC кабель 220 кВ):**
Нехай `U = 220 кВ` (`U_ph = 127 кВ`), `C_km = 0.25 мкФ/км`, `I_max = 800 А`, `f = 50 Гц`.

```
I_c_km = 314.16 · (0.25 · 10⁻⁶) · (220 000 / √3)
       = 314.16 · 0.00000025 · 127 017
       ≈ 9.98 А/км

L_crit = 800 / 9.98 ≈ 80.1 км
```

На відстані 80 км підводний кабель змінного струму 220 кВ виходить на повну термічну межу **лише за рахунок власної ємності**, навіть якщо на іншому кінці не підключено жодного споживача.

У лініях HVDC напруга постійна (`f = 0` ⇒ `ω = 0`), тому в усталеному режимі ємнісний струм `I_C = 0`. Довжина кабелю HVDC не обмежена реактивним зарядом, і весь струм `I_max` використовується для передачі активної потужності:

```
I_P_DC = I_max      [незалежно від довжини L]
```

### 2. Математика вентильного випрямляча LCC: напруга та комутація

Класичний 6-пульсний міст випрямляча (схема Ларіонова на тиристорах) живиться від трифазної напруги з лінійним значенням `U_LL`.

#### Ідеальна середня випрямлена напруга без навантаження (при куті відкривання тиристорів α)

Середнє значення напруги на виході 6-пульсного мосту визначається інтегруванням огинаючої синусоїди:

```
U_dc0 = (3 · √2 / π) · U_LL · cos α
      ≈ 1.350 · U_LL · cos α
```

Для біполярного 12-пульсного перетворювача (два 6-пульсні мости, з'єднані послідовно та живлені від трансформатора з обмотками «зірка» та «трикутник» зі зсувом 30°):

```
U_dc0_12 = (6 · √2 / π) · U_LL · cos α
         ≈ 2.701 · U_LL · cos α
```

де `α` — кут відмикання тиристорів (`0° ≤ α < 90°` у режимі випрямляча, `90° < α < 180°` у режимі інвертора).

#### Комутаційне перекриття та падіння напруги під навантаженням

У реальному перетворювачі обмотки трансформатора мають індуктивний опір розсіювання (комутаційний опір `X_c = ω·L_c`). Через індуктивність струм у вентилі не може змінитися миттєво з 0 до `I_dc`. Під час перемикання струму з одного тиристора на інший обидва тиристори деякий час замкнені одночасно. Цей проміжок вимірюється **кутом комутаційного перекриття `μ`**.

Рівняння комутаційного процесу зв'язує струм `I_dc`, напругу `U_LL`, кут відмикання `α` та кут перекриття `μ`:

```
cos(α + μ) = cos α - (2 · X_c · I_dc) / (√2 · U_LL)
```

Через комутаційне перекриття середня випрямлена напруга падає на величину `ΔU_dc`:

```
ΔU_dc = (3 / π) · X_c · I_dc
```

Повне рівняння випрямленої напруги LCC навантаженої підстанції:

```
U_dc = (3·√2 / π) · U_LL · cos α - (3 / π) · X_c · I_dc
     = 1.35 · U_LL · cos α - R_eq · I_dc
```

де `R_eq = (3 / π) · X_c` — ефективний еквівалентний опір комутації (який викликає падіння напруги, але не виділяє тепла!).

#### Режим інвертора та кут погасання γ

На приймальній підстанції перетворювач працює як інвертор (`DC ➔ AC`). Кут керування `α > 90°`. Замість `α` описують процес через **кут погасання `γ`** (*extinction angle*):

```
γ = 180° - (α + μ)
```

Кут `γ` відповідає часу, який залишається тиристору після відновлення замикальної здатності до того, як напруга на ньому стане позитивною. Якщо `γ` впаде нижче критичного значення `γ_min ≈ 15° ... 18°`, тиристор не встигне відновити ізоляційні властивості й завуглецюється зворотною напругою — виникає **збій комутації** (*commutation failure*), що призводить до короткого замикання DC-полюса.

### 3. Економічна точка рівноцінності (Break-even distance)

Вибір між AC та HVDC визначається порівнянням повних зведених витрат `C_total` на будівництво й експлуатацію протягом терміну служби (типово 30–40 років).

Функція вартості проєкту для лінії довжиною `L` (км):

```
C_total(L) = C_station + c_line · L + C_loss(L)
```

де:
- `C_station` — капітальні витрати на спорудження кінцевих підстанцій (грн/USD);
- `c_line` — вартість будівництва 1 км лінії/кабелю (грн/км);
- `C_loss(L)` — вартість втраченої електроенергії в провідниках за термін експлуатації.

#### Порівняльний аналіз компонентів для AC та DC

1. **Вартість підстанцій:**
   `C_station_DC >> C_station_AC`. Підстанція HVDC містить складні вентильні блоки, випрямні трансформатори, фільтри гармонік та системи керування, тому коштує у 3–5 разів дорожче за підстанцію AC тотожної потужності.

2. **Вартість лінії (матеріали та опори):**
   `c_line_DC < c_line_AC`. Трифазна лінія AC вимагає щонайменше 3 силові проводи (і більше фазних розщеплень), тоді як біполярна лінія HVDC вимагає лише 2 провідники (`+U_dc` та `-U_dc`). Це зменшує масу металу на 33%, знижує висоту та масу опор, а також звужує зону відчуження землі (*right-of-way*) на 30–40%.

3. **Втрати електроенергії:**
   Втрати в лінійних провідниках залежать від опору. На постійному струмі відсутній скін-ефект (`R_dc < R_ac`) та відсутні реактивні втрати на заряд ємності lines:
   `c_loss_DC < c_loss_AC`.

#### Рівняння точки рівноцінності L_be

Точка рівноцінності `L_be` задовольняє рівності сумарних витрат:

```
C_station_AC + c_line_AC · L_be + C_loss_AC(L_be)
= C_station_DC + c_line_DC · L_be + C_loss_DC(L_be)
```

Виразимо `L_be` алгебраїчно, об'єднавши вартість будівництва лінії та втрат у питому характеристику `k_line = c_line + c_loss_km`:

```
C_station_AC + k_line_AC · L_be = C_station_DC + k_line_DC · L_be
```

```
L_be = (C_station_DC - C_station_AC) / (k_line_AC - k_line_DC)
```

Оскільки чисельник позитивний (`C_station_DC > C_station_AC`), а знаменник також позитивний (`k_line_AC > k_line_DC`), розв'язок `L_be > 0` існує завжди.

#### Типові числові межі точки рівноцінності

```
Тип лінії                | Точка рівноцінності L_be
-------------------------+-------------------------
Повітряні ЛЕП (Overhead)  | 600 – 800 км
Підводний кабель (Subsea) | 40 – 60 км
Підземний кабель (Earth)  | 50 – 70 км
```

Для підводних кабелів `L_be` настає вже на відстанях 40–50 км не лише через економію коштів, а й через фізичну неможливість роботи AC кабелю поза межею `L_crit`.
