# 🧮 Математична модель атмосферної провідності, профілю полів та опору колони

Атмосферне електричне коло в областях гарної погоди можна математично описати як стаціонарну тривимірну електродинамічну систему із просторово неоднорідною провідністю середовища. Оскільки швидкість зміни процесів гарної погоди є набагато повільнішою за характерний час проходження світла крізь атмосферу, електричне поле описується потенціальним квазістаціонарним наближенням рівнянь Максвелла.

Ця математична модель дозволяє з перших принципів вивести профілі електричного поля та потенціалу, розрахувати опір атмосферної колони, загальний опір Землі як сферичного конденсатора, вивести ефект приземного електрода, математичну теорію геоелектромагнітних резонансів Шумана та проаналізувати крайові фізичні фактори атмосферних збурень.

### 1. Мікроскопічна теорія іонізаційного балансу та провідність газу

Електропровідність газу `σ(z)` визначається концентрацією позитивних `n₊` і негативних `n₋` легких іонів та їхньою рухливістю `b₊` і `b₋`:

```
σ(z) = e · [n₊(z)·b₊(z) + n₋(z)·b₋(z)]
```

де `e = 1.602·10⁻¹⁹ Кл` — елементарний заряд. Рухливість іонів `b(z)` описує середню дрейфову швидкість іонів у розрахунку на одиницю напруженості електричного поля: `v_drift = b · E`. За законом Ланжевена рухливість іона є обернено пропорційною густині повітря `ρ(z)` та нормалізованій температурі. Оскільки густина повітря з висотою спадає за барометричною формулою `ρ(z) = ρ₀ · exp(−z / h_atm)` (де висота однорідної атмосфери `h_atm ≈ 8.0 км`), рухливість іонів стрімко зростає при підйомі вгору.

Концентрація легких іонів у стаціонарному стані визначається рівнянням іонізаційного балансу Томсона:

```
dq / dt = q_ion(z) − α · n₊ · n₋ − β · n · N_aerosol = 0
```

де `q_ion(z)` — швидкість утворення іонних пар під дією космічних променів та радіоактивного розпаду радону (вимірюється в парах іонів на кубічний сантиметр за секунду, `іон/см³·с`), `α ≈ 1.6·10⁻⁶ см³/с` — коефіцієнт рекомбінації легких іонів між собою, а `β` — коефіцієнт приєднання легких іонів до нейтральних аерозольних частинок із концентрацією `N_aerosol`.

У чистому повітрі (над океанами та на великих висотах), де концентрація аерозолів нехтовно мала (`N_aerosol → 0`), стаціонарна концентрація іонів задається квадратним коренем від швидкості іонізації: `n = √(q_ion / α)`. У сильно забрудненому чи міському повітрі приєднання до аерозолів переважає над рекомбінацією, тому `n ≈ q_ion / (β · N_aerosol)`, що призводить до стрімкого падіння провідності приземного шару.

Для висот від поверхні Землі (`z = 0`) до межі іоносфери (`z = h_ion ≈ 60 км`) провідність `σ(z)` з високою точністю описується експоненціальною моделлю з характерною висотою однорідності `h_σ ≈ 6.0 км`:

```
σ(z) = σ₀ · exp(z / h_σ)
```

де `σ₀ ≈ 2.0·10⁻¹⁴ См/м` (або `Ом⁻¹·м⁻¹`) — питома провідність повітря біля поверхні Землі в умовах чистого океанічного чи сільського повітря.

Для більш точних практичних розрахунків використовують двопараметричну модель, що враховує два основних джерела іонізації — радон біля поверхні (`0–2 км`) та космічні промені у тропосфері та стратосфері (`2–60 км`):

```
σ(z) = σ₁ · exp(z / h₁) + σ₂ · exp(z / h₂)
```

де `σ₁ ≈ 1.2·10⁻¹⁴ См/м`, `h₁ ≈ 4.5 км`, `σ₂ ≈ 0.8·10⁻¹⁴ См/м`, `h₂ ≈ 9.0 км`.

### 2. Загальне рівняння транспорту носіїв та розпушування поля

У найзагальнішому випадку повний вертикальний атмосферний струм `J_total` складається з трьох фізичних компонент: струму провідності (дрейфу в електричному полі), конвективного струму (механічного перенесення заряду повітряними потоками) та дифузійного струму (перенесення носіїв через градієнт концентрації):

```
J_total = σ(z) · E_z + ρ_space · v_wind − D_ion · (dρ_space / dz)
```

де `ρ_space` — об'ємна густина заряду, `v_wind` — вертикальна швидкість конвекційного повітряного потоку, а `D_ion` — коефіцієнт дифузії іонів у газі. В областях гарної погоди за відсутності сильних турбулентних восхідних потоків конвективний та дифузійний доданки є у сотні разів меншими за струм провідності, тому рівняння неперервності струму з високою точністю спрощується до стаціонарної форми:

```
∇ · J = 0
```

Оскільки електричне поле в атмосфері напрямлене переважно вертикально вздовж осі `z` (напрямок від іоносфери до землі), вектор густини струму має лише вертикальну компоненту `J_z`:

```
dJ_z / dz = 0
```

Звідси випливає фундаментальна умова стаціонарності струму гарної погоди: густина вертикального струму витоку `J_z` є строго постійною по всій висоті атмосферного стовпа. 

За законом Ома в диференціальній формі зв'язок між густиною струму `J_z`, провідністю `σ(z)` та вертикальною компонентою електричного поля `E_z(z)` має вигляд:

```
J_z = σ(z) · E_z(z)
```

Підставляючи експоненціальний профіль провідності `σ(z) = σ₀ · exp(z / h_σ)`, отримуємо розрахунок вертикального електричного поля:

```
E_z(z)
= J_z / σ(z)                      [закон Ома в диференціальній формі]
= J_z / (σ₀ · exp(z / h_σ))       [підставили експоненціальний профіль σ(z)]
= (J_z / σ₀) · exp(−z / h_σ)      [властивість показника степеня exp(−x) = 1/exp(x)]
= E₀ · exp(−z / h_σ)              [позначили E₀ = J_z / σ₀ — поле біля поверхні]
```

де `E₀ = E_z(0)` — напруженість електричного поля біля самої поверхні Землі.

Підставивши числові значення густини струму `J_z = −2.5·10⁻¹² А/м²` та початкової провідності `σ₀ = 2.0·10⁻¹⁴ См/м`, знайдемо напруженість поля біля землі:

```
E₀
= J_z / σ₀                                          [закон Ома для поверхні]
= (−2.5·10⁻¹² А/м²) / (2.0·10⁻¹⁴ См/м)             [підставили числові значення]
= −125 В/м                                         [обчислили частку від ділення]
```

Отже, оскільки провідність атмосфери експоненціально росте з висотою, напруженість електричного поля `E_z(z)` експоненціально спадає з висотою:
- На поверхні (`z = 0`): `|E_z| ≈ 125–130 В/м`.
- На висоті `z = 12 км` (висота польоту пасажирських літаків): `|E_z| = 125 · exp(−12 / 6) = 125 · exp(−2) ≈ 17 В/м`.
- На висоті `z = 30 км` (стратосфера): `|E_z| = 125 · exp(−5) ≈ 0.84 В/м`.
- На висоті `z = 60 км` (межа D-шару іоносфери): `|E_z| = 125 · exp(−10) ≈ 5.7·10⁻³ В/м = 5.7 мВ/м`.

### 3. Ефект приземного електрода та об'ємний заряд у граничному шарі

Фізично важливим наслідком неоднорідності провідності та наявності провідної поверхні Землі є виникнення **приземного об'ємного заряду** (*electrode effect*). Згідно з рівнянням Пуассона `∇ · E = ρ / ε₀`, зміна електричного поля з висотою породжує об'ємну густину заряду `ρ(z)` у повітрі:

```
ρ(z)
= ε₀ · dE_z / dz                       [одновимірне рівняння Пуассона]
= ε₀ · d/dz [ E₀ · exp(−z / h_σ) ]     [похідна від експоненціальної функції d/dz exp(−z/h) = −1/h exp(−z/h)]
= − (ε₀ · E₀ / h_σ) · exp(−z / h_σ)   [винесли константу за знак похідної]
```

Оскільки електричне поле напрямлене вниз (`E₀ < 0`), коефіцієнт `−E₀ / h_σ` є додатним. Це означає, що **у приземній атмосфері завжди існує додатний об'ємний заряд**:

```
ρ₀
= − ε₀ · E₀ / h_σ                                          [формула Пуассона на поверхні]
= − (8.854·10⁻¹² Ф/м · (−130 В/м)) / 6000 м               [підставили числові значення]
= + 1.92·10⁻¹² Кл/м³ = + 1.92 пКл/м³                        [обчислили густину заряду]
```

Мікроскопічна причина ефекту електрода полягає у граничних умовах на твердій поверхні: позитивні іони під дією поля гарної погоди дрейфують зверху вниз і осідають на землю, тоді як від'ємні іони рухаються вгору і вилітають убік тропосфери. Оскільки сама земля не випромінює від'ємних іонів у повітря, у найнижчому шарі товщиною 1–10 метрів виникає дефіцит від'ємних іонів і значний надлишок позитивних іонів.

### 4. Вертикальний профіль електричного потенціалу

Зв'язок між напруженістю поля `E_z` та потенціалом `V(z)` задається градієнтом `E_z = −dV/dz`. Приймаючи потенціал поверхні Землі за нуль (`V(0) = 0 В`), обчислимо потенціал точки на висоті `z`:

```
V(z)
= − ∫ [0..z] E_z(z') dz'                 [визначення потенціалу через інтеграл поля]
= − ∫ [0..z] [E₀ · exp(−z' / h_σ)] dz'   [підставили профіль поля E_z(z')]
= − E₀ · [−h_σ · exp(−z' / h_σ)] [0..z]  [первісна від exp(−z/h) дорівнює −h·exp(−z/h)]
= E₀ · h_σ · [1 − exp(−z / h_σ)]         [підставили межі інтегрування 0 та z]
```

Оскільки напруженість поля біля поверхні прямо пов'язана з потенціалом іоносфери `V_ion` при `z → ∞`:

```
V_ion
= lim [z → ∞] V(z)                        [граничний перехід при z до нескінченності]
= E₀ · h_σ · [1 − 0]                      [значення експоненти exp(−inf) дорівнює 0]
= E₀ · h_σ                                [спростили добуток]
```

Підставляючи числові значення `E₀ = 130 В/м` та `h_σ = 6.0 км = 6000 м`:

```
V_ion
= 130 В/м · 6000 м                        [підставили значення поля біля поверхні]
= 780 000 В = 780 кВ                      [обчислили потенціал іоносфери]
```

(У реальній атмосфері з урахуванням вищого шару іонізації та двопараметричної моделі провідності потенціал іоносфери становить `V_ion ≈ +250–500 кВ`).

Тоді профіль потенціалу через `V_ion` записується у формі:

```
V(z) = V_ion · [1 − exp(−z / h_σ)]
```

### 5. Опір атмосферного стовпа (колони) та гірський ефект

Розглянемо вертикальний атмосферний стовп одиничного перерізу `S = 1 м²`, що простягається від землі (`z = z_surf`) до іоносфери (`z = h_ion`). Опір такого стовпа описується інтегралом:

```
R_col
= ∫ [z_surf..h_ion] dz / σ(z)                [визначення опору неоднорідного провідника]
= ∫ [z_surf..h_ion] dz / (σ₀ · exp(z / h_σ)) [підставили експоненціальну провідність σ(z)]
= (h_σ / σ₀) · exp(−z_surf / h_σ) · [1 − exp(−(h_ion − z_surf) / h_σ)]  [обчислили інтеграл]
```

Для рівня моря (`z_surf = 0`) опір колони спрощується до знакомої формули `R_col ≈ h_σ / σ₀ ≈ 3.0·10¹⁷ Ом·м²`.

Проте для високих гірських масивів та плато виникає потужний геометричний **гірський ефект** (*mountain effect*). Наприклад, для високогорного спостережного пункту на вершині Мауна-Лоа (Гаваї) або на Тибетському плато з висотою `z_surf ≈ 3.6 км`:

```
R_col(3.6 км)
= R_col(0) · exp(−3.6 / 6.0)              [підставили висоту поверхні у відносний закон]
= R_col(0) · exp(−0.6)                    [обчислили показник степеня]
≈ 0.548 · R_col(0)                        [підставили значення e^(-0.6)]
```

Оскільки опір атмосферної колони над високою горою вдвічі менший, ніж над рівнем моря, за умови однакової потенціальної різниці `V_ion` вертикальний струм провідності над гірською вершиною `J_z,mountain = V_ion / R_col(z_surf)` виявляється майже у два рази більшим за густину струму над океаном! Це приводить до сильної концентрації електричних ліній поля біля гірських піків та вираженого зростання напряженості поля біля високих скель.

Розрахуємо загальний опір усієї атмосфери Землі в областях гарної погоди `R_global`. Знаючи опір однієї колони `R_col` та загальну площу поверхні Землі `S_earth = 4 · π · R_E² = 5.10·10¹⁴ м²`:

```
R_global
= R_col / S_earth                      [опір паралельного з'єднання однакових елементів]
= (1.3·10¹⁷ Ом·м²) / (5.10·10¹⁴ м²)    [підставили значення опору колони та площі]
≈ 255 Ом                               [обчислили підсумковий планетний опір]
```

Отже, еквівалентний електричний опір усієї атмосфери Землі між іоносферою та поверхнею становить лише близько 150–250 Ом. Це вражаюче мале значення зумовлене величезною площею паралельного з'єднання атмосферних колон.

Загальний струм розрядки глобального кола `I_global` при потенціалі іоносфери `V_ion = 250 кВ`:

```
I_global
= V_ion / R_global                     [закон Ома для ділянки кола]
= 250 000 В / 200 Ом                   [підставили потенціал і опір]
= 1250 А                               [знайшли загальний струм розрядки]
```

### 6. Ємність сферичного конденсатора Земля-Іоносфера та енергія поля

Земну поверхню та нижню межу іоносфери можна розглядати як сферичний конденсатор із радіусом внутрішньої обкладинки `R_E = 6371 км` та зовнішньої `R_ion = R_E + h_ion` (де `h_ion ≈ 60 км`).

Оскільки товщина атмосферного діелектрика `h_ion` набагато менша за радіус Землі (`h_ion ≪ R_E`), ємність сферичного конденсатора визначається формулою плоского конденсатора з площею `S_earth`:

```
C_earth
= ε₀ · S_earth / h_eff                 [формула ємності тонкого сферичного конденсатора]
```

де `h_eff` — ефективна товщина діелектричного шару з урахуванням профілю провідності: `h_eff ≈ h_σ ≈ 6.0 км`.

Обчислимо електричну ємність системи Земля-Іоносфера:

```
C_earth
= (8.854·10⁻¹² Ф/м) · (5.10·10¹⁴ м²) / 6000 м  [підставили ε₀, площу та товщину]
= 4.515·10³ / 6000                             [перемножили чисельник]
≈ 0.75 Ф                                       [обчислили підсумкову ємність]
```

Якщо ж оцінювати ємність за геометричною висотою D-шару іоносфери (`h = 60 км`):

```
C_geom
= (8.854·10⁻¹² Ф/м) · (5.10·10¹⁴ м²) / 60 000 м [підставили геометричну висоту 60 км]
≈ 0.075 Ф = 75 мФ                              [обчислили ємність]
```

Повний зв'язаний негативний заряд на поверхні Землі `Q_earth` за теоремою Гаусса через напруженість поля біля поверхні `E₀ = 130 В/м`:

```
Q_earth
= − ε₀ · E₀ · S_earth                  [теорема Гаусса для поверхневого заряду]
= − (8.854·10⁻¹² Ф/м) · (130 В/м) · (5.10·10¹⁴ м²)  [підставили фізичні константи]
= − 1.151·10⁻⁹ Кл/м² · 5.10·10¹⁴ м²     [обчислили поверхневу густину]
≈ −587 000 Кл = −587 кКл               [обчислили повний планетний заряд]
```

Повна енергія електричного поля, запасена у сферичному конденсаторі Земля-Іоносфера `W_electric`:

```
W_electric
= (1 / 2) · C_geom · V_ion²            [формула енергії зарядженого конденсатора]
= (1 / 2) · 0.075 Ф · (250 000 В)²     [підставили ємність та потенціал]
= 0.0375 · 6.25·10¹⁰ Дж                [піднесли потенціал до квадрата]
≈ 2.34·10⁹ Дж = 2.34 ГДж               [підсумкова енергія планетного поля]
```

### 7. Характерний час релаксації заряду атмосфери

Локальний час релаксації електричного заряду `τ(z)` у середовищі з діелектричною проникністю `ε ≈ ε₀` та провідністю `σ(z)` визначається співвідношенням:

```
τ(z) = ε₀ / σ(z)
```

Обчислимо значення часу релаксації на різних висотах:

1. **Біля поверхні Землі (`z = 0`):**
```
τ₀
= (8.854·10⁻¹² Ф/м) / (2.0·10⁻¹⁴ См/м)   [підставили ε₀ та поверхневу провідність]
= 442.7 секунди ≈ 7.4 хвилини           [обчислили поверхневий час релаксації]
```
(У запиленому чи міському повітрі, де `σ₀` впаде до `0.5·10⁻¹⁴ См/м`, `τ₀` досягає 30–40 хвилин).

2. **У стратосфері (`z = 18 км`):**
   Оскільки `σ(18 км) = σ₀ · exp(18/6) = σ₀ · e³ ≈ 20.08 · σ₀ ≈ 4.0·10⁻¹³ См/м`:
```
τ(18 км) = 442.7 / 20.08 ≈ 22 секунди
```

3. **В іоносфері (`z = 60 км`):**
   Тут `σ(60 км) ≈ 10⁻⁷ См/м`:
```
τ(60 км) = (8.854·10⁻¹² Ф/м) / 10⁻⁷ См/м ≈ 8.8·10⁻⁵ с = 88 мікросекунд
```

Якби всі грозові генератори Землі раптово припинили свою роботу, нейтралізація поверхневого заряду Землі `Q_earth` під дією постійного струму витоку `I_global` відбувалася б за експоненціальним законом:

```
Q(t) = Q_earth · exp(−t / τ_global)
```

де характерний час розрядки планетного конденсатора `τ_global`:

```
τ_global
= R_global · C_geom                    [добуток опору на ємність кола]
= 250 Ом · 0.075 Ф                     [підставили глобальний опір та ємність]
= 18.75 секунд                         [обчислили планетний час розрядки]
```

Цей дивовижний результат означає: без неперервної роботи грозових хмар по всьому світу електричне поле гарної погоди Землі практично повністю зникло б менш ніж за хвилину! Стійке існування атмосферної електрики протягом мільйонів років є прямим наслідком безперервної глобальної грозової діяльності.

### 8. Електродинаміка вимірювання поля датчиком із обертовою пластиною (Field Mill)

Для точного вимірювання електричного поля гарної погоди без спотворення через власний заряд вимірювача використовують датчик типу **обертовий флуксметр** (*field mill*). Прилад складається з заземленого секторного ротора, який обертається з кутовою швидкістю `ω` і почергово перекриває та відкриває ізольовані вимірювальні електроди площею `S_sensor`.

Зміна відкритої площі вимірювального електрода описується гармонічною функцією:

```
S_eff(t) = (S_sensor / 2) · [1 + cos(N_sectors · ω · t)]
```

Індукований електричним полем `E_z` на поверхні електрода заряд `q_ind(t)` дорівнює:

```
q_ind(t) = ε₀ · E_z · S_eff(t)
```

Звідси струм індукції `i_ind(t) = dq_ind / dt`, що протікає через вимірювальний опір `R_m` на землю:

```
i_ind(t)
= d/dt [ ε₀ · E_z · (S_sensor / 2) · (1 + cos(N_sectors · ω · t)) ]  [похідна індукованого заряду]
= − ε₀ · E_z · (S_sensor / 2) · N_sectors · ω · sin(N_sectors · ω · t)  [обчислили похідну від косинуса]
```

Амплітуда змінної напруги на виході вимірювача `U_out` є строго пропорційною напруженості атмосферного електричного поля `E_z`:

```
U_max = ε₀ · S_sensor · N_sectors · ω · R_m · E_z
```

Ця формульна залежність лежить в основі калібрування всіх сучасних метеорологічних наземних та авіаційних вимірювачів напруженості атмосферного електричного поля.

### 9. Математична теорія резонансів Шумана в сферичному резонаторі

Порожнина між провідною поверхнею Землі та провідною іоносферою створює сферичний хвилеводний резонатор для наднизькочастотних (ELF) електромагнітних хвиль. Для обчислення власних частот стоячих хвиль розв'язується векторне рівняння Гельмгольца для електромагнітного поля у сферичних координатах `(r, θ, φ)` з межевими умовами ідеального провідника при `r = R_E` та `r = R_E + h`:

```
∇² E + k² · E = 0
```

де `k = ω / c` — хвильове число. Розділення змінних у сферичних координатах приводить до приєднаних функцій Лежандра `P_n^m(cos θ)`. Умова існування нетривіального розв'язку визначає власні значення `k_n`:

```
k_n · R_E = √(n · (n + 1))
```

де `n = 1, 2, 3...` — номер гармоніки. Використовуючи співвідношення `ω_n = c · k_n`, виводимо теоретичну формулу власних частот резонансів Шумана для безвтратного сферичного резонатора:

```
f_n
= ω_n / (2 · π)                                   [зв'язок циклічної частоти та звичайної]
= (c / (2 · π · R_E)) · √(n · (n + 1))             [підставили власне значення хвильового числа k_n]
```

Підставивши швидкість світла `c = 2.998·10⁸ м/с` та радіус Землі `R_E = 6.371·10⁶ м`, обчислимо фундаментальну частоту згасання хвилі вздовж екватора:

```
f_base
= c / (2 · π · R_E)                               [теоретична базова частота]
= (2.998·10⁸ м/с) / (2 · 3.14159 · 6.371·10⁶ м)   [підставили швидкість світла та радіус]
= (2.998·10⁸) / (4.003·10⁷)                       [перемножили знаменник]
≈ 7.49 Гц                                         [підсумкова базова частота]
```

Тоді для перших гармонік отримуємо теоретичні частоти без урахування дисипації в іоносфері:
- **Для першої гармоніки (`n = 1`):** `f₁ = 7.49 · √(1 · 2) = 7.49 · √2 = 7.49 · 1.414 ≈ 10.6 Гц`.
- **Для другої гармоніки (`n = 2`):** `f₂ = 7.49 · √(2 · 3) = 7.49 · √6 = 7.49 · 2.449 ≈ 18.3 Гц`.
- **Для третьої гармоніки (`n = 3`):** `f₃ = 7.49 · √(3 · 4) = 7.49 · √12 = 7.49 · 3.464 ≈ 25.9 Гц`.

У реальній атмосфері кінцева провідність іоносфери та витоки в тропосфері створюють комплексний коефіцієнт заломлення `n_eff ≈ √(1 − i · σ / (ε₀ · ω))`. Врахування скінченної товщини скінченно провідного шару іоносфери за моделлю Грінберга-Гейла зменшує резонансні частоти приблизно на 25–30%, зміщуючи експериментальні піки до спостережуваних значень:

```
f₁ = 7.83 Гц,   f₂ = 14.3 Гц,   f₃ = 20.8 Гц,   f₄ = 27.3 Гц,   f₅ = 33.8 Гц
```

Добротність сферичного резонатора `Q = f_n / Δf_n ≈ 4–6`, що вказує на сильне згасання хвилі, проте неперервні розряди блискавок по всьому світу (близько 50 розрядів щосекунди) створюють постійне квазістаціонарне збудження цих стоячих хвиль.

### 10. Вплив зовнішніх геофізичних факторіальних збурень

Математична модель глобального кола зазнає тимчасових модифікацій під дією зовнішніх космічних та глобальних метеорологічних факторів. Розглянемо два основних збурювальних механізми.

#### Сонячні протоно-події (Solar Proton Events, SPE)

Під час потужних спалахів на Сонці потоки високоенергетичних протонів (`E > 10 МЕВ`) досягають геомагнітних полярних шапок Землі. Вони проникють глибоко в мезосферу та стратосферу (на висоти `z ≈ 20–50 км`), створюючи сплеск іонізації `q_ion(z)`, який зростає на 2–3 порядки.

У математичній моделі це виражається локальним зменшенням опору полярної колони:

```
R_col,polar(SPE) = ∫ [0..h_ion] dz / (σ₀ · exp(z / h) + Δσ_SPE(z))
```

Внаслідок зниження опору полярних колон загальний опір планетного кола `R_global` падає на 5–15%, що призводить до тимчасового зростання загального глобального струму `I_global` та зміщення потенціалу іоносфери `V_ion` вниз.

#### Вулканічні викиди та ядерні випробування

Викиди пилу та виражених вулканічних аерозолів (зокрема діоксиду сірки `SO₂`, що перетворюється на крапельки сірчаної кислоти `H₂SO₄` у стратосфері) різко збільшують концентрацію аерозолів `N_aerosol`. За рівнянням Томсона це підвищує приєднання легких іонів і зменшує провідність `σ(z)` у стратосфері у кілька разів.

У результаті опір атмосферної колони `R_col` над регіоном вулканічного плюму локально зростає, викликаючи різке підняття напруженості приземного електричного поля `E_z` на поверхні під хмарою аерозолю. Розрахунок таких збурень вимагає чисельного розв'язання тривимірного рівняння Пуассона `∇ · (σ(x,y,z) · ∇V) = 0` за допомогою методів скінченних елементів.
