# 🧮 Виведення радіуса дебаївського екранування у плазмі

Дебаївське екранування — це фундаментальна математична основа квазінейтральності плазми. Вона детально пояснює, чому кулонівське поле зовнішнього пробного заряду в іонізованому середовищі згасає не за повільним класичним законом оберненого квадрата відстані `1/r²`, а експоненціально стрімко. У цій вставці наведено повне математичне виведення дебаївського радіуса `λ_D`, отримано екранований потенціал `Φ(r)` на основі рівняння Пуассона та статистичного розподілу Больцмана, а також розібрано випадок двокомпонентної плазми з гарячими іонами, кулонівський логарифм та межі застосовності лінійного наближення.

### 1. Постановка фізичної задачі й вихідні рівняння

Розглянемо безмежну, однорідну й ізотропну плазму. У незбуреному стані концентрація вільних електронів дорівнює `n_0`, а концентрація однозарядних позитивних іонів — `n_0`. Загальна макроскопічна електронейтральність середовища за відсутності зовнішніх полів забезпечує строгу рівновагу зарядів:

```
n_i0 = n_e0 = n_0
```

Помістимо в точку з координатами `r = 0` точковий додатний пробний заряд `+Q`. Цей заряд порушує первинну однорідність і створює в навколишньому просторі сферично симетричний електричний потенціал `Φ(r)`.

Під дією виниклого електричного поля позитивні іони починають відштовхуватися від точкового джерела `+Q`, а рухливі електрони — притягуватися до нього. У результаті навколо точкового заряду формується сферично симетрична хмара збагачення від'ємним зарядом (сфера Дебая). 

Сумарна об'ємна густина заряду `ρ(r)` у будь-якій точці середовища на відстані `r` дорівнює:

```
ρ(r) = e · n_i(r) - e · n_e(r)
```

Зв'язок між просторовим розподілом електричного потенціалу `Φ(r)` та підсумковою об'ємною густиною заряду `ρ(r)` описується фундаментальним **рівнянням Пуассона**:

```
∇² Φ(r) = - ρ(r) / ε₀      [рівняння Пуассона]
```

Оскільки система володіє повною сферичною симетрією відносно початку координат, потенціал залежить лише від радіальної відстані `r`. Оператор Лапласа у сферичній системі координат спрощується до одновимірної радіальної форми:

```
(1 / r²) · (d / dr) [ r² · (dΦ / dr) ] = - ρ(r) / ε₀
```

### 2. Статистичний розподіл електронів та іонів у потенціальному полі

Завдяки величезній різниці у масах (`m_i / m_e ≥ 1836`) легкі електрони реагують на зміну потенціалу набагато швидше за іони. У найпростішій моделі однокомпонентного екранування іони вважаються нерухомим однорідним фоном із постійною концентрацією `n_i(r) = n_0`.

Електрони знаходяться у стані хаотичного теплового руху з електронною температурою `T_e`. Їхня місцева концентрація `n_e(r)` у потенціальному полі `Φ(r)` описується **розподілом Больцмана** для частинок у зовнішньому потенціальному полі:

```
n_e(r) = n_0 · exp( e · Φ(r) / (k_B · T_e) )
```

де `e` — елементарний заряд, `k_B` — стала Больцмана, `T_e` — абсолютна електронна температура в кельвінах.

Підставимо концентрації у вираз для об'ємної густини заряду `ρ(r)`:

```
ρ(r) = e · n_0 - e · n_0 · exp( e · Φ(r) / (k_B · T_e) )
ρ(r) = e · n_0 · [ 1 - exp( e · Φ(r) / (k_B · T_e) ) ]
```

Підставляючи цей вираз у рівняння Пуассона, отримуємо нелінійне диференціальне рівняння другого порядку відносно потенціалу `Φ(r)`:

```
(1 / r²) · (d / dr) [ r² · (dΦ / dr) ] = - (e · n_0 / ε₀) · [ 1 - exp( e · Φ(r) / (k_B · T_e) ) ]
```

### 3. Лінеаризація Дебая — Гюккеля для слабкого потенціалу

Аналітичний розв'язок нелінійного рівняння Пуассона — Больцмана у загальному вигляді є надзвичайно складним. Проте у більшості плазмових систем на відстанях, порівняних із радіусом екранування, потенціальна енергія взаємодії електрона з полем `e · Φ(r)` є значно меншою за його середню кінетичну енергію теплового руху `k_B · T_e`:

```
e · Φ(r) << k_B · T_e
```

Це дозволяє розкласти експоненціальну функцію у степеневий ряд Тейлора за малим безрозмірним параметром `x = e · Φ(r) / (k_B · T_e)` і обмежитися першими двома членами розкладу:

```
exp(x) ≈ 1 + x
```

Підставляємо наближений розклад експоненти у вираз для об'ємної густини заряду `ρ(r)`:

```
ρ(r) ≈ e · n_0 · [ 1 - (1 + e · Φ(r) / (k_B · T_e)) ]
ρ(r) = - (n_0 · e² / (k_B · T_e)) · Φ(r)
```

Бачимо, що у лінійному наближенні об'ємна густина наведеного заряду виявляється прямо пропорційною потенціалу `Φ(r)` зі знаком мінус.

### 4. Виведення формули для радіуса Дебая

Підставимо лінеаризовану густину заряду `ρ(r)` у рівняння Пуассона:

```
(1 / r²) · (d / dr) [ r² · (dΦ / dr) ] = - [ - (n_0 · e² / (k_B · T_e)) · Φ(r) ] / ε₀
(1 / r²) · (d / dr) [ r² · (dΦ / dr) ] = [ n_0 · e² / (ε₀ · k_B · T_e) ] · Φ(r)
```

Множник у квадратних дужках має розмірність квадрата оберненої довжини `1 / м²`. Уведемо фундаментальну величину — **електронний радіус дебаївського екранування** `λ_De`:

```
1 / λ_De² = (n_0 · e²) / (ε₀ · k_B · T_e)
```

Взявши квадратний корінь, отримуємо остаточну класичну формулу для радіуса Дебая:

```
λ_De = √( (ε₀ · k_B · T_e) / (n_0 · e²) )
```

Завдяки цьому введенню диференціальне рівняння Пуассона набуває стандартної лінійної форми диференціального рівняння Гельмгольца у сферичних координатах:

```
(1 / r²) · (d / dr) [ r² · (dΦ / dr) ] = (1 / λ_De²) · Φ(r)
```

### 5. Інтегрування диференціального рівняння та граничні умови

Щоб розв'язати отримане рівняння, зробимо стандартну заміну невідомої функції `u(r) = r · Φ(r)`. Знайдемо похідні від потенціалу:

```
Φ(r) = u(r) / r
dΦ / dr = (1 / r) · (du / dr) - (u / r²)
r² · (dΦ / dr) = r · (du / dr) - u
(d / dr) [ r² · (dΦ / dr) ] = (du / dr) + r · (d²u / dr²) - (du / dr) = r · (d²u / dr²)
```

Підставляємо ліву частину в диференціальне рівняння:

```
(1 / r²) · [ r · (d²u / dr²) ] = (1 / λ_De²) · (u / r)
(1 / r) · (d²u / dr²) = (1 / λ_De²) · (u / r)
d²u / dr² = (1 / λ_De²) · u
```

Ми отримали найпростіше лінійне однорідне диференціальне рівняння другого порядку зі сталими коефіцієнтами. Його загальний розв'язок є сумою двох експонент:

```
u(r) = C_1 · exp(- r / λ_De) + C_2 · exp(+ r / λ_De)
```

Переходячи назад від допоміжної функції `u(r)` до потенціалу `Φ(r) = u(r) / r`, маємо:

```
Φ(r) = (C_1 / r) · exp(- r / λ_De) + (C_2 / r) · exp(+ r / λ_De)
```

Значення довільних констант `C_1` та `C_2` визначаються з фізичних граничних умов:

1. **Умова на безмежності (`r → ∞`):** Електричний потенціал у безмежно віддалених точках середовища повинен залишатися скінченним і прямувати до нуля: `Φ(r) → 0`. Оскільки друга експонента `exp(+ r / λ_De)` безмежно зростає при `r → ∞`, єдиним способом задовольнити цю умову є покласти константу `C_2 = 0`.
2. **Умова впритул до точкового заряду (`r → 0`):** На дуже малих відстанях `r << λ_De` екранувальна хмара електронів ще не встигає повністю сформуватися, і потенціал повинен переходити у звичайний вакуумний кулонівський потенціал точкового заряду `+Q`:

```
lim_{r → 0} Φ(r) = Q / (4 π ε₀ r)
```

Оскільки при `r → 0` експонента `exp(- r / λ_De) → 1`, то `(C_1 / r) · 1 = Q / (4 π ε₀ r)`, що дає константу `C_1 = Q / (4 π ε₀)`.

Остаточно підставляємо константи й отримуємо потенціал Дебая — Гюккеля:

```
Φ(r) = (Q / (4 π ε₀ r)) · exp(- r / λ_De)
```

### 6. Узагальнення: екранування гарячими іонами та двокомпонентний дебаївський радіус

У попередній моделі ми вважали іони нерухомим фоном. Це наближення є абсолютно точним для високочастотних процесів або коли температура іонів значно менша за температуру електронів (`T_i << T_e`).

Проте якщо плазма є ізотермічною (`T_i ≈ T_e`) і розглядається стаціонарний або повільний процес, іони також встигають перерозподілитися за больцманівським законом:

```
n_i(r) = n_0 · exp( - e · Φ(r) / (k_B · T_i) )
```

У цьому випадку лінеаризована об'ємна густина заряду враховує внесок обох компонент:

```
ρ(r) ≈ - e² · n_0 · [ (1 / (k_B · T_e)) + (1 / (k_B · T_i)) ] · Φ(r)
```

Тоді повний **двокомпонентний радіус Дебая** `λ_D` обчислюється через суму квадратів обернених електронного `λ_De` та іонного `λ_Di` радіусів:

```
1 / λ_D² = 1 / λ_De² + 1 / λ_Di²

λ_D = √( (ε₀ · k_B) / (e² · n_0 · [(1/T_e) + (1/T_i)]) )
```

Якщо `T_i = T_e`, то `1 / λ_D² = 2 / λ_De²`, звідки двокомпонентний дебаївський радіус виявляється в `√2 ≈ 1.41` раза меншим за чисто електронний через додатковий внесок іонізаційної рухливості.

### 7. Межі застосовності наближення та кулонівський логарифм

При виведенні ми використали припущення про малість потенціалу `e · Φ(r) << k_B · T_e`. З'ясуємо, де саме це припущення порушується.

Впритул до точкового заряду потенціал дорівнює `Φ(r) ≈ Q / (4 π ε₀ r)`. Умова застосовності лінеаризації виконується лише на відстанях `r`, що перевищують **відстань найближчого зближення** (прицільний параметр відхилення на 90°) `b_0`:

```
b_0 = e² / (4 π ε₀ · k_B · T_e)
```

Отже, концепція дебаївського екранування і суцільного середовища є коректною лише тоді, коли відстань найближчого кулонівського зіткнення `b_0` є значно меншою за дебаївський радіус `λ_D`:

```
b_0 << λ_D
```

Відношення цих двох характерних масштабів визначає знаменитий **кулонівський логарифм** (*Coulomb logarithm*, `ln Λ`):

```
Λ = λ_D / b_0 = (4 π · ε₀ · k_B · T_e · λ_D) / e² = 9 · N_D

ln Λ = ln( λ_D / b_0 )
```

У більшості лабораторних та астрофізичних плазмових систем значення `ln Λ` лежить у діапазоні від 10 до 20. Велике значення кулонівського логарифма є математичним доказом того, що далекі кулонівські зіткнення з малими кутами відхилення у сукупності дають набагато більший внесок у розсіювання частинок, ніж рідкісні близькі зіткнення з великими кутами.

Таким чином, математичний апарат Дебая — Гюккеля доводить: плазма є самоузгодженим середовищем, де кожен заряд оточений згладжувальною екранувальною оболонкою, яка перетворює довгосяжну кулонівську взаємодію у короткосяжну на масштабах `λ_D`.
