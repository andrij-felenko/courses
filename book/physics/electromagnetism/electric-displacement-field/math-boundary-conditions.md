# 🧮 Виведення теореми Гаусса для вектора D та граничних умов на межі діелектриків

Ця математична вставка містить строгі аналітичні виведення теореми Гаусса для вектора електричного зсуву `D`, математичний доказ зв'язку між поляризацією `P` та зв'язаними зарядами `ρ_bound`, строге виведення граничних умов на інтерфейсах, а також розв'язання фундаментальних задач електростатики діелектриків методом зображень та тензорним аналізом.

---

### 1. Зв'язок поляризації P та зв'язаного заряду ρ_bound

Розглянемо макроскопічний об'єм діелектрика `V`, обмежений замкненою поверхнею `S`. Кожен мікроскопічний елементарний диполь `p_i = q_i · d_i` в об'ємі `dV` створює дипольний момент `dP = P · dV`.

При нерівномірній поляризації позитивні та негативні заряди всередині об'єму зміщуються. Обчислимо сумарний вільний заряд, який перетинає елемент поверхні `dA`. Якщо вектор поляризації дорівнює `P`, то заряд `dQ`, що виходить з об'єму `V` крізь елементарну площадку `dA` із зовнішньою нормаллю `n`, дорівнює проекції вектора `P` на нормаль:

```
dQ_exit = P · dA = (P · n) dA           [заряд, що виходить крізь площадку dA]
```

Інтегруючи по всій замкненій поверхні `S`, отримуємо повний заряд `Q_exit`, який вийшов із внутрішнього об'єму `V`:

```
Q_exit = ∯_S P · dA                     [повний заряд, що залишив об'єм V]
```

Оскільки вихід позитивного заряду залишає всередині некомпенсований негативний зв'язаний заряд `Q_bound_inside`, за законом збереження заряду маємо:

```
Q_bound_inside = - Q_exit = - ∯_S P · dA [повний зв'язаний заряд всередині V]
```

Застосуємо теорему Гауса — Остроградського до поверхневого інтеграла `∯_S P · dA`:

```
∯_S P · dA = ∭_V (∇ · P) dV            [перехід від поверхневого інтеграла до об'ємного]
```

З іншого боку, повний зв'язаний заряд можна виразити через його об'ємну густину `ρ_bound`:

```
Q_bound_inside = ∭_V ρ_bound dV        [об'ємний інтеграл густини зв'язаного заряду]
```

Порівнюючи підінтегральні вирази для довільного об'єму `V`, отримуємо точне диференціальне співвідношення:

```
ρ_bound = - ∇ · P                      [фундаментальна диференціальна формула зв'язаного заряду]
```

Якщо на поверхні діелектрика поляризація `P` скачком падає до нуля (на межі з вакуумом), то інтегруванням у тонкому поверхневому шарі товщиною `δ → 0` отримуємо поверхневу густину зв'язаного заряду `σ_bound`:

```
σ_bound = P · n = P_n                   [поверхнева густина зв'язаного заряду]
```

### 2. Диференціальне та інтегральне виведення теореми Гаусса для D

Запишемо мікроскопічне рівняння Максвелла для напруженості електричного поля `E` у середовищі:

```
∇ · E = ρ_total / ε₀ = (ρ_free + ρ_bound) / ε₀
```

Помножимо обидві частини на `ε₀`:

```
ε₀ · (∇ · E) = ρ_free + ρ_bound        [підстановка двох типів зарядів]
```

Замінимо `ρ_bound` виразом `- ∇ · P`:

```
ε₀ · (∇ · E) = ρ_free - (∇ · P)        [заміна густини зв'язаного заряду]
```

Перенесемо `∇ · P` у ліву частину:

```
ε₀ · (∇ · E) + ∇ · P = ρ_free
∇ · (ε₀ · E + P) = ρ_free              [винесення оператора дивергенції]
```

Визначаючи вектор електричного зсуву `D` як:

```
D ≡ ε₀ · E + P                         [визначення вектора D]
```

отримуємо диференціальну форму теореми Гаусса для речовини:

```
∇ · D = ρ_free                         [теорема Гаусса для вектора D]
```

Проінтегруємо це рівняння по об'єму `V`, обмеженому поверхнею `S`:

```
∭_V (∇ · D) dV = ∭_V ρ_free dV
```

Застосовуючи теорему Гауса — Остроградського до лівої частини та розпізнаючи повний вільний заряд `Q_free` у правій частині:

```
∯_S D · dA = Q_free                    [інтегральна форма теореми Гаусса для вектора D]
```

### 3. Строге виведення граничних умов для D_n та E_t

Розглянемо межу поділу двох діелектричних середовищ із проникностями `ε_1` та `ε_2`. 

```
                       Середовище 1 (ε_1)
        ──────────────────────────────────────────────
         n ↑    ┌────────────────────────┐  h (висота циліндра)
        ────────│─────── Гаусів ─────────│──────────── (Межа поділу)
                │       циліндр          │  h → 0
        ────────└────────────────────────┘
                       Середовище 2 (ε_2)
```

#### 1. Нормальна компонента D_n:
Побудуємо Гаусів циліндр («гаусову таблетку») площею основ `ΔS`, нижня основа якого лежить у середовищі 2, а верхня — у середовищі 1. Висота циліндра `h → 0`.

Потік вектора `D` крізь бічну поверхню прямує до нуля при `h → 0`. Потік крізь основи дорівнює:

```
Φ_D = (D_1 · n) ΔS - (D_2 · n) ΔS = (D_1n - D_2n) ΔS
```

За теоремою Гаусса цей потік дорівнює вільному заряду усередині циліндра `Q_free = σ_free · ΔS`:

```
(D_1n - D_2n) ΔS = σ_free · ΔS
D_1n - D_2n = σ_free                   [стрибок нормальної компоненти D]
```

За відсутності вільних поверхневих зарядів (`σ_free = 0`):

```
D_1n = D_2n  ⇒  ε_1 · E_1n = ε_2 · E_2n [гранична умова для нормальних компонент]
```

#### 2. Тангенціальна компонента E_t:
Побудуємо прямокутний контур Стокса довжиною `L` вздовж межі та шириною `h → 0` перпендикулярно до межі.

```
       E_1t ───>   ┌────────────────────────┐
                   │    Контур Стокса L     │  h → 0
       E_2t ───>   └────────────────────────┘
```

За потенціальністю електричного поля циркуляція вектора `E` по замкненому контуру дорівнює нулю:

```
∮ E · dl = E_1t · L - E_2t · L = 0
E_1t = E_2t                            [неперервність тангенціальної компоненти E]
```

Враховуючи `D_t = ε · E_t`, виражаємо стрибок тангенціальної компоненти `D_t`:

```
D_1t / ε_1 = D_2t / ε_2                [стрибок тангенціальної компоненти D]
```

### 4. Метод зображень для точкового заряду біля плоскої межі діелектрика

Розглянемо точковий вільний заряд `q`, розміщений у першому середовищі (з діелектричною проникністю `ε_1`) на відстані `d` від плоскої межі з другим середовищем (з діелектричною проникністю `ε_2`).

```
    Середовище 1 (ε_1)               |  Середовище 2 (ε_2)
                                     |
           + q  (x = -d)             | (x = 0)
            •                        |
                                     |
   Фіктивний заряд q'                |  Фіктивний заряд q''
    • (у x = +d для полів у 1)      |   • (у x = -d для полів у 2)
```

Завдяки граничним умовам неперервності `D_n` та `E_t` на межі `x = 0`, потенціал полів можна обчислити за допомогою фіктивних точкових зарядів-зображень.

#### Потенціал у першому середовищі (x < 0):
Потенціал створюється справжнім зарядом `q` та фіктивним зарядом-зображенням `q'`, розміщеним у точці `x = +d` другого середовища:

```
φ₁(r) = (1 / (4π · ε₀ · ε_1)) · [ (q / r₁) + (q' / r₂) ]
```

де `r₁ = √((x + d)² + y² + z²)` та `r₂ = √((x - d)² + y² + z²)`.

#### Потенціал у другому середовищі (x > 0):
Потенціал створюється ефективним фіктивним зарядом `q''`, розміщеним у точці `x = -d` першого середовища:

```
φ₂(r) = (1 / (4π · ε₀ · ε_2)) · [ q'' / r₁ ]
```

#### Застосування граничних умов при x = 0:
При `x = 0` маємо `r₁ = r₂ = R = √(d² + y² + z²)`.

1. Неперервність потенціалу `φ₁(0) = φ₂(0)` (гранична умова для тангенціального поля `E_t`):

```
(1 / ε_1) · (q + q') = (1 / ε_2) · q''   [умова 1]
```

2. Неперервність нормальної компоненти електричного зсуву `D_1n = D_2n` (де `D_n = - ε · (∂φ / ∂x)`):

Обчислимо похідні по `x` при `x = 0`:

```
∂(1/r₁)/∂x = - d / R³
∂(1/r₂)/∂x = + d / R³
```

Звідси `D_1x(0) = D_2x(0)` дає:

```
- ε_1 · (1 / ε_1) · [ - q · (d / R³) + q' · (d / R³) ] = - ε_2 · (1 / ε_2) · [ - q'' · (d / R³) ]
q - q' = q''                           [умова 2]
```

#### Розв'язання системи рівнянь:
Підставляючи `q'' = q - q'` у перше рівняння:

```
(1 / ε_1) · (q + q') = (1 / ε_2) · (q - q')
ε_2 · (q + q') = ε_1 · (q - q')
q' · (ε_1 + ε_2) = q · (ε_1 - ε_2)
```

Звідси отримуємо точні формули для зарядів-зображень:

```
q'  = - q · [ (ε_2 - ε_1) / (ε_2 + ε_1) ]   [заряд-зображення для першого середовища]
q'' = q · [ (2 · ε_2) / (ε_1 + ε_2) ]      [ефективний заряд для другого середовища]
```

#### Фізичний аналіз результату:
1. Якщо `ε_2 > ε_1` (заряд знаходиться у менш щільному діелектрику біля більш щільного, наприклад повітря біля води):
   Заряд-зображення `q'` має протилежний знак до `q` (`q' < 0`). Заряд `q` притягується до діелектрика із силою `F = |q · q'| / (4π · ε₀ · ε_1 · (2d)²)`.
2. Якщо `ε_2 < ε_1` (заряд у більш щільному діелектрику біля межі з повітрям):
   Заряд-зображення `q'` має той самий знак (`q' > 0`). Заряд `q` відштовхується від межі!

### 5. Повний математичний розрахунок двошарового циліндричного коаксіального кабелю

Розглянемо коаксіальний кабель, що складається з центральної металевої жили радіуса `a`, на яку подано лінійну густину вільного заряду `λ_free` (Кл/м). Жила оточена двома концентричними діелектричними шарами:
- Перший шар: `a < r < b`, відносна проникність `ε_r1`.
- Другий шар: `b < r < c`, відносна проникність `ε_r2`.
- Зовнішня заземлена металева оболонка при `r = c`.

```
                    Оболонка (r = c)
                ┌───────────────────────┐
                │ Шар 2 (ε_r2, b<r<c)   │
                │   ┌───────────────┐   │
                │   │ Шар 1 (ε_r1)  │   │
                │   │   ┌───────┐   │   │
                │   │   │ Жила  │   │   │
                │   │   │ (r=a) │   │   │
```

#### Крок 1. Обчислення вектора D(r)
Вибираємо замкнену циліндричну поверхню Гаусса радіуса `r` та довжини `L`. За симетрією потік вектора `D` має тільки радіальну компоненту `D_r(r)`:

```
∯ D · dA = D_r(r) · (2π · r · L) = Q_free = λ_free · L
D_r(r) = λ_free / (2π · r)             [значення D однакове для всіх a < r < c!]
```

#### Крок 2. Обчислення напруженості електричного поля E(r)
```
• Для Шар 1 (a < r < b):
  E_r1(r) = D_r(r) / (ε₀ · ε_r1) = λ_free / (2π · ε₀ · ε_r1 · r)

• Для Шар 2 (b < r < c):
  E_r2(r) = D_r(r) / (ε₀ · ε_r2) = λ_free / (2π · ε₀ · ε_r2 · r)
```

#### Крок 3. Обчислення різниці потенціалів (напруги U)
Напруга між центральною жилою та зовнішньою оболонкою дорівнює інтегралу від `E_r(r)`:

```
U = ∫ₐᶜ E_r(r) dr 
  = ∫ₐᵇ E_r1(r) dr + ∫_bᶜ E_r2(r) dr
  = [ λ_free / (2π · ε₀) ] · [ (1 / ε_r1) · ln(b / a) + (1 / ε_r2) · ln(c / b) ]
```

#### Крок 4. Ємність на одиницю довжини C/L
Використовуючи визначення ємності `C/L = λ_free / U`:

```
C / L = (2π · ε₀) / [ (1 / ε_r1) · ln(b / a) + (1 / ε_r2) · ln(c / b) ]  [ємність коаксіального кабелю]
```

#### Крок 5. Зв'язаний поверхневий заряд на межі діелектриків r = b
Вектор поляризації в першому шарі біля межі: `P_1(b) = D(b) · (ε_r1 - 1) / ε_r1`.
Вектор поляризації у другому шарі біля межі: `P_2(b) = D(b) · (ε_r2 - 1) / ε_r2`.

Сумарна поверхнева густина зв'язаного заряду `σ_bound(b)` дорівнює:

```
σ_bound(b) = P_1r(b) - P_2r(b)
           = D_r(b) · [ (ε_r1 - 1) / ε_r1 - (ε_r2 - 1) / ε_r2 ]
           = [ λ_free / (2π · b) ] · [ (1 / ε_r2) - (1 / ε_r1) ]
```

### 6. Тензорні перетворення D_i у кристалічних середовищах

У анізотропному кристалі зв'язок задається тензором `ε_ij`:

```
D_i = ∑_{j=1}³ ε_ij · E_j               [тензорний вираз у довільній системі координат]
```

Тензор `ε_ij` є симетричним (`ε_ij = ε_ji`) завдяки закону збереження енергії. Існує головна система координат кристала `(X', Y', Z')`, у якій тензор діагоналізується:

```
┌ D_x' ┐   ┌ ε_xx'   0      0   ┐   ┌ E_x' ┐
│ D_y' │ = │  0    ε_yy'    0   │ · │ E_y' │
└ D_z' ┘   └  0      0    ε_zz' ┘   └ E_z' ┘
```

При повороті системи координат на матрицю повороту `R` компоненти вектора зсуву змінюються як `D' = R · D`, а новий тензор діелектричної проникності обчислюється як:

```
ε' = R · ε · Rᵀ                        [тензорне перетворення при повороті координат]
```

Ці математичні співвідношення лежать в основі кристаллооптики та розрахунку кристалічних п'єзокомпенсаторів і кристалів для нелінійної оптичної лазерної техніки.
