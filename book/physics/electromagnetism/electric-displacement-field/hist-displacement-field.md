# 📜 Історія відкриття та еволюції вектора електричного зсуву

Вектор електричного зсуву `D` описує макроскопічне електричне поле з урахуванням поляризації середовища, а його формалізм розвивався від перших експериментів Майкла Фарадея з діелектриками та механічної ефірної моделі Джеймса Клерка Максвелла до електронного синтезу Хендріка Лоренца та спеціальної теорії відносності Альберта Ейнштейна.

---

### 1. Досвід Фарадея та індукційна ємність (1837)

До тридцятих років XIX століття електростатика розвивалася в рамках ньютонівської концепції дальнодії. Вважалося, що електричні заряди взаємодіють безпосередньо через порожнечу за законом Кулона, а речовина між ними (повітря, скло, олія) є лише пасивним ізолятором, який заважає стіканню заряду.

У 1837 році англійський физико-хімік Майкл Фарадей здійснив серію фундаментальних експериментів, які повністю зруйнували цю концепцію. Фарадей сконструював прилад з двох концентричних металевих сфер. Внутрішню суцільну сферу радіуса `R₁` він закріпив на ізолюючому стержні, а зовнішню порожнисту сферу радіуса `R₂` зробив розбірною, з двох півсфер.

```
                  ┌───────────────────────────────┐
                  │    Зовнішня сфера (R₂)        │
                  │   ┌───────────────────────┐   │
                  │   │ Внутрішня сфера (R₁)  │   │
                  │   │        (+Q)           │   │
                  │   └───────────────────────┘   │
                  │  Простір заповнювали олією,   │
                  │   сіркою або смолою (ε_r)     │
                  └───────────────────────────────┘
```

Фарадей заряджав внутрішню сферу зарядом `Q` у повітрі й вимірював різницю потенціалів `V` за допомогою золотоокисного електрометра. Потім він заповнював простір між сферами розплавленою сіркою, смолою чи очищеним скипидаром і виявив, що при тому самому заряді `Q` потенціал `V` зменшувався у кілька разів!

Фарадей зробив два геніальних висновки:
1. Ізолятори не є пасивними — вони активно беруть участь у передачі електричної взаємодії. Вона передається не через дальнодію, а через послідовний натяг суміжних частинок середовища. Фарадей назвав ці ізолятори **діелектриками** (*dielectrics*, від грецького *dia* — через, наскрізь).
2. Здатність середовища передавати електричну дію Фарадей назвав **специфічною індуктивною ємністю** (*specific inductive capacity*), що стало прямим попередником сучасної діелектричної проникності `ε_r`. Він сформулював гіпотезу, що діелектрик поляризується під дією поля, утворюючи орієнтовані молекулярні диполі.

### 2. Пружний зсув ефіру у математичній моделі Максвелла (1861–1865)

Шотландський фізик Джеймс Клерк Максвелл поставив собі за мету надати ідеям Фарадея про силові лінії строгої математичної форми.

У праці «Про фізичні лінії сили» (*On Physical Lines of Force*, 1861–1862) Максвелл запропонував механічну модель світового ефіру. Ефір уявлявся як пружне середовище, що складається з обертових молекулярних вихорів, розділених шаром дрібних сферичних «коліщаток» (електронів).

```
   ┌─────────────────────────────────────────────────────────────┐
   │             МЕХАНІЧНА МОДЕЛЬ ЕФІРУ МАКСВЕЛЛА                │
   │                                                             │
   │    ( Вихор 1 )  →  [Коліщатко]  →  ( Вихор 2 )             │
   │    Обертання        Зсув вправо    Обертання                │
   │    магнітного       струм D        магнітного               │
   │    поля H                          поля H                   │
   └─────────────────────────────────────────────────────────────┘
```

Коли в такому середовищі створювалася електрична сила (напруженість `E`), пружні елементи ефіру зміщувалися зі своїх положень рівноваги. Відстань зміщення ефірної матерії Максвелл назвав **електричним зсувом** (*electric displacement*) і позначив вектором `D`.

Формула Максвелла мала вигляд:

```
D = (1 / 4π) · ε · E                   [у системах одиниць Гаусса/Максвелла]
```

#### Народження струму зсуву та епохальна праця 1865 року
Звідси Максвелл зробив свій найголовніший теоретичний прорив. У праці «Динамічна теорія електромагнітного поля» (*A Dynamical Theory of the Electromagnetic Field*, 1865) він усвідомив: якщо зміщення `D` змінюється з часом, то сам процес зміщення ефірної матерії являє собою рух зарядів — тобто повноцінний електричний струм зсуву `J_d`:

```
J_d = ∂D / ∂t                          [густина струму зсуву Максвелла]
```

Додавши цей струм зсуву до закону Ампера, Максвелл отримав замкнену систему з 20 рівнянь для 20 змінних, з якої прямо випливало існування електромагнітних хвиль, що поширюються зі швидкістю `c = 1 / √(ε₀ · μ₀)`.

### 3. Суперечки шкіл: Максвелл проти Гельмгольца та Герца

Концепція вектора `D` Максвелла сприймалася континентальною Європою з великою недовірою понад 20 років. У Німеччині та Франції панувала школа Вільгельма Вебера, Франца Ноймана та Густава Кірхгофа, яка пояснювала всі явища дією миттєвих сил між зарядами з залежністю від швидкості.

Видатний німецький фізик Герман фон Гельмгольц намагався створити компромісну теорію, в якій ефір поляризувався потенційними силами. Гельмгольц запропонував премію Берлінської академії наук тому, хто експериментально доведе існування струму зсуву та поляризаційних ефектів у діелектриках.

Цю задачу взявся розв'язати учень Гельмгольца Генріх Герц. У 1886–1888 роках у Карлсруе Герц не лише створив іскровий передавач та вібратор, але й виміряв заломлення ліній електричного поля при проходженні радіохвиль крізь величезні призми з асфальту та парафіну масою у кілька тонн!

```
    [Іскровий вібратор] ───> [Парафінова призма] ───> [Приймач Герца]
    (Генерація хвилі)        (Заломлення по лініях D)  (Резонансна іскра)
```

Експерименти Герца довели, що хвилі електричного зсуву заломлюються за тими самими законами `tan(θ₁) / tan(θ₂) = ε_r1 / ε_r2`, що й світло. Теорія Максвелла й вектор `D` здобули остаточну триумфальну перемогу.

Протім сам Герц висунув критику механічної моделі Максвелла. Герц викинув вихори та коліщатка, зауваживши: *«Теорія Максвелла — це система рівнянь Максвелла»*. З цього моменту вектор `D` перестали розглядати як деформацію механічних осередків ефіру.

### 4. Електронний синтез Хендріка Лоренца (1892–1909)

Остаточне фізичне розшифрування вектора `D` відбулося після відкриття електрона та створення **електронної теорії** голландським фізиком Хендріком Антоном Лоренцом (Нобелівська премія 1902 року).

Лоренц розділив електродинаміку на два фундаментальні рівні:
1. **Мікроскопічний рівень (рівняння Лоренца — Максвелла):** Існують лише вакуумне електричне поле `e` та вакуумне магнітне поле `b`. Їхніми джерелами є мікроскопічні заряди електронів та ядер `ρ_micro`. У порожнечі між атомами вектора `D` не існує — там є лише вакуумне поле `e`.
2. **Макроскопічний рівень (просторове усереднення):** Проводячи математичне усереднення мікроскопічних полів по фізично нескінченно малому об'єму `ΔV` (який містить мільйони атомів), Лоренц показав, що усереднене поле `⟨e⟩ = E`, а усереднений дипольний момент атомів дає вектор поляризації `P = ⟨ρ_micro · r⟩`.

Лоренц математично вивів вектор `D` як комбінацію:

```
D = ε₀ · E + P                         [електронний вивід Лоренца]
```

Крім того, Лоренц обчислив локальне діюче поле на окремий атом у кристалі (поле Лоренца `E_loc = E + P / (3·ε₀)`), що дозволило пояснити зв'язок між показником заломлення та діелектричною проникністю (формула Клаузіуса — Моссотті). Це результат остаточно позбавив вектор `D` будь-якого містичного чи ефірного відтінку: `D` є макроскопічним полем, яке враховує як вакуумний внесок `ε₀·E`, так і реальний фізичний відгук електронних оболонок речовини `P`.

### 5. Спеціальна теорія відносності та 4-тензорне формулювання

З появою спеціальної теорії відносності Альберта Ейнштейна у 1905 році виникло питання: як вектори `D` та `E` перетворюються при переході між інерціальними системами відліку?

У 1908 році німецький математик Герман Мінковський об'єднав вектори `D` та `H` у єдиний **4-тензор індукції** `H^μν`, а вектори `E` та `B` — у **4-тензор напруженостей** `F_μν`:

```
┌ 0     -D_x   -D_y   -D_z ┐
│ D_x    0     -H_z    H_y │
H^μν = │ D_y   H_z     0    -H_x │     [релятивістський тензор індукцій Мінковського]
└ D_z  -H_y    H_x     0   ┘
```

Релятивістські перетворення Лоренца довели, що при русі середовища зі швидкістю `v` вектор `D` у рухомій системі залежить не лише від електричного поля `E`, але й від магнітного поля `H`:

```
D' = D + (v × H) / c²                  [релятивістський зсув у рухомому середовищі]
```

Це довело, що електричний зсув `D` та магнітне поле `H` є двома боками єдиної 4-вимірної геометричної сутності простору-часу.

### 6. Квантово-механічний опис (XX століття)

У другій половині XX століття з розвитком фізики твердого тіла та теорії поляризації фізики Р. Реста та Д. Вандербільт (Сучасна теорія поляризації, 1993) довели, що вектор `D` у періодичних кристалах пов'язаний із геометричною фазою Беррі хвильових функцій блохівських електронів.

Вектор електричного зсуву виявився тотожно рівним варіації квантової фази електронного стану при прикладанні зовнішніх полів.

### 7. Підсумок еволюції концепції

| Епоха / Вчений | Розуміння вектора D | Модель середовища |
|---|---|---|
| **М. Фарадей (1837)** | Натяг індукційних ліній | Діелектрична поляризація молекул |
| **Дж. К. Максвелл (1861)** | Механічний зсув комірок | Пружний світовий ефір |
| **Г. Герц (1888)** | Абстрактний вектор поля | Математичні рівняння |
| **Х. А. Лоренц (1892)** | `D = ε₀·E + P` (макро-середнє) | Атоми та електрони у вакуумі |
| **Г. Мінковський (1908)** | Компонента 4-тензора `H^μν` | 4-вимірний простір-час |
| **Р. Реста, Д. Вандербільт (1993)** | Квантова фаза Беррі | Заповнені електронні зони Блоха |

Історія вектора електричного зсуву демонструє дивовижний шлях науки: математична формула `D = ε₀·E + P`, виведена Максвеллом із хибної механічної моделі ефіру, виявилася абсолютно точною й незмінною і в сучасній квантовій електродинаміці.
