# 🧮 Векторний потенціал, мультипольний розклад і магнітний диполь

Математична теорія магнітного моменту базується на мультипольному розкладі векторного потенціалу електромагнітного поля. Для довільного локалізованого розподілу стаціонарних струмів ця теорія дає змогу виділити головний (дипольний) внесок на великих відстанях, а також строго вивести формули сил, моментів та енергії взаємодії з перших принципів векторного аналізу.

---

### Мультипольний розклад векторного потенціалу

Розглянемо замкнений розподіл струмів із густиною j(r'), зосереджений у деякій обмеженій області простору V' поблизу початку координат. У стаціонарному випадку магнітне поле описується векторним потенціалом A(r), який за законом Біо — Савара — Лапласа виражається через інтеграл за об'ємом джерела:

```
A(r) = (μ₀ / 4π) · ∫ [ j(r') / |r − r'| ] d³r'
```

Якщо точка спостереження 
 розташована набагато далі від початку координат, ніж розміри системи струмів (|r| >> |r'|), ми можемо розкласти скалярний множник 1 / |r − r'| у ряд Тейлора за малим параметром 
' / r:

```
1 / |r − r'| 
= 1 / r + (r · r') / r³ + ½ · [ 3 · (r · r')² − r² · r'² ] / r⁵ + O(r'³ / r⁴)
```

Підставивши цей розклад у вираз для векторного потенціалу, отримуємо розбиття A(r) на суму мультипольних членів:

```
A(r) = A[mono](r) + A[dip](r) + A[quad](r) + ...
```

#### 1. Монопольний член (відсутність магнітних зарядів)
Перший доданок розкладу відповідає монопольному внеску:

```
A[mono](r) = (μ₀ / (4π · r)) · ∫ j(r') d³r'
```

Доведемо строго, що для будь-якого стаціонарного замкненого струму справджується векторна тотожність ∫ j(r') d³r' = 0. Доведення базується на законі збереження заряду у стаціонарному режимі (∇ · j = 0).

Розглянемо k-ту компоненту векторного інтеграла ∫ j[k] d³r'. Скористаємося тотожністю диференціювання добутку скаляра на вектор:

```
∇' · (x'[k] · j) 
= x'[k] · (∇' · j) + j · (∇' x'[k])
= 0 + j · e[k]                       [оскільки ∇'·j = 0 та ∇'x'[k] = e[k]]
= j[k]
```

Інтегруючи ліву та праву частини за об'ємом V', який охоплює весь струм, та застосовуючи теорему Гаусса (теорему про дивергенцію):

```
∫ j[k] d³r' 
= ∫ ∇' · (x'[k] · j) d³r'
= ∮ (x'[k] · j) · dS'                [теорема Гаусса]
= 0                                  [струм не виходить за межі об'єму, j|S' = 0]
```

Таким чином, **магнітний монопольний член тотожно дорівнює нулю**: A[mono](r) = 0. Це безпосередньо відображає фундаментальний фізичний факт відсутності точкових магнітних зарядів у класичній електродинаміці.

#### 2. Дипольний член та означення магнітного моменту
Другий доданок розкладу визначає дипольний векторний потенціал:

```
A[dip](r) = (μ₀ / (4π · r³)) · ∫ (r · r') · j(r') d³r'
```

Для перетворення підінтегрального виразу скористаємося тотожністю для векторного добутку. Рівність (r · r') · j можна подати як суму симетричної та антисиметричної частин за індексами 
' та j:

```
(r · r') · j 
= ½ · [ (r · r') · j + (r · j) · r' ] + ½ · [ (r · r') · j − (r · j) · r' ]
```

Інтеграл від симетричної частини ∫ [ (r · r') · j + (r · j) · r' ] d³r' для стаціонарних локалізованих струмів дорівнює нулю за аналогією з доведенням монопольного члена. Антисиметрична частина перетворюється за допомогою тотожності «бац мінус цап» ( × (b × c) = b(a·c) − c(a·b)):

```
(r' × j) × r = (r · r') · j − (r · j) · r'   [векторний подвійний добуток]
```

Підставляючи це значення в інтеграл, виносимо сталий вектор 
 за знак інтегрування за штрихованими координатами:

```
A[dip](r) 
= (μ₀ / (4π · r³)) · ½ · ∫ [ (r' × j(r')) × r ] d³r'
= (μ₀ / (4π · r³)) · [ ( ½ · ∫ (r' × j(r')) d³r' ) × r ]
```

Це дозволяє ввести фундаментальне загальне означення **векторного магнітного моменту** μ для довільного тривимірного розподілу струмів:

```
μ = ½ · ∫ (r' × j(r')) d³r'                  [векторний магнітний момент]
```

Тоді дипольний векторний потенціал набуває компактної векторної форми:

```
A[dip](r) = (μ₀ / (4π · r³)) · (μ × r) = (μ₀ / 4π) · (μ × r̂) / r²
```

Для тонкого плоского замкненого контуру зі струмом I, де елемент струму j d³r' = I dl', інтеграл спрощується до геометрії контуру:

```
μ = ½ · I · ∮ (r' × dl') 
= I · S · n                                   [перехід від інтеграла до площини S]
```

де S — площа контуру, а 
 — одиничний вектор нормалі, узгоджений зі струмом за правилом правої руки.

### Розрахунок магнітного поля диполя

Магнітна індукція диполя B(r) обчислюється через ротор векторного потенціалу: B(r) = ∇ × A[dip](r).

```
B(r) 
= ∇ × [ (μ₀ / 4π) · (μ × r) / r³ ]
= (μ₀ / 4π) · [ (μ · ∇)(r / r³) − μ · (∇ · (r / r³)) + (r / r³)(∇ · μ) − (r / r³) × (∇ × μ) ]
```

Оскільки вектор μ є сталим щодо координат точки спостереження 
, похідні від μ дорівнюють нулю. Використовуючи співвідношення ∇ · (r / r³) = 0 для 
 ≠ 0 та (μ · ∇)(r / r³) = 3 (μ · r) r / r⁵ − μ / r³, отримуємо вираз для індукції поля диполя:

```
B(r) = (μ₀ / (4π · r³)) · [ 3 · (μ · r̂) · r̂ − μ ]
```

де 
̂ = r / r — одиничний вектор у напрямку точки спостереження.

#### Вираз у сферичних координатах та рівняння силових ліній
У сферичній системі координат (r, θ, φ), де вектор μ спрямований уздовж осі Z (θ = 0), компоненти поля мають вигляд:

```
B[r] = (μ₀ / (2π · r³)) · μ · cos θ          [радіальна компонента]
B[θ] = (μ₀ / (4π · r³)) · μ · sin θ          [кутова компонента]
B[φ] = 0                                      [азимутальна компонента]
```

Рівняння силових ліній описується співвідношенням dr / (r dθ) = B[r] / B[θ] = 2 cos θ / sin θ. Інтегрування дає рівняння сімейства силових ліній у площині меридіана:

```
r = r₀ · sin² θ
```

де 
₀ — максимальне віддалення силової лінії від початку координат на екваторі (θ = 90°).

### Сили, моменти та потенціальна енергія у зовнішньому полі

Розглянемо магнітний диполь μ, розміщений у зовнішньому магнітному полі B[ext](r).

#### 1. Обертальний момент
Результуючий момент сил Ампера, що діють на елементи струму j d³r' у полі B[ext]:

```
τ = ∫ (r' × dF) 
= ∫ r' × (j(r') × B[ext](r')) d³r'
```

Розкладаючи зовнішнє поле поблизу початку координат B[ext](r') ≈ B[ext](0) (однорідне поле) та інтегруючи за тими самими векторними тотожностями, що й для потенціалу, отримуємо:

```
τ = μ × B[ext]                               [обертальний момент]
```

#### 2. Потенціальна енергія
Робота, яку необхідно виконати проти обертального моменту для зміни орієнтації диполя від кута θ₁ до θ₂:

```
W = ∫ τ dθ = ∫ (μ · B[ext] · sin θ) dθ = − μ · B[ext] · cos θ |[θ₁]^[θ₂]
```

Визначаючи потенціальну енергію U з точністю до довільної сталої (вважаючи U = 0 при θ = 90°), отримуємо скалярний добуток:

```
U = − μ · B[ext]                             [потенціальна енергія диполя]
```

#### 3. Сила у неоднорідному полі
У неоднорідному полі (∇B[ext] ≠ 0) на протилежні боки контуру діють неоднакові сили Ампера. Результуюча сила обчислюється як градієнт потенціальної енергії, узятий із протилежним знаком:

```
F = − ∇ U = ∇ (μ · B[ext])                   [сила в неоднорідному полі]
```

Використовуючи тотожність векторного аналізу для градієнта скалярного добутку при жорсткому диполі (μ = const):

```
F = (μ · ∇) B[ext] + μ × (∇ × B[ext])
```

Для стаціонарного зовнішнього поля у вакуумі (де немає зовнішніх струмів у точці розташування диполя, тобто ∇ × B[ext] = 0), сила виражається як:

```
F = (μ · ∇) B[ext]                           [сила на фіксований диполь]
```

Якщо поле спрямоване уздовж осі Z і змінюється лише уздовж цієї осі (B = B[z](z) ẑ), формула спрощується до скалярної форми:

```
F[z] = μ[z] · (∂B[z] / ∂z)                   [проектна сила в градієнтному полі]
```

Ця фундаментальна формула пояснює силову взаємодію у досліді Штерна — Герлаха та механізм притягання феромагнетиків до полюсів магніту.
