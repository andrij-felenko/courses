# 🧮 Математичний апарат кривини Беррі та аномальної швидкості носіїв

Опис руху квантового електрона в періодичному кристалічному потенціалі при наявності спін-орбітальної взаємодії вимагає виходу за межі стандартного напівкласичного наближення Зоммерфельда-Блоха. Оскільки квантова фаза блохівської хвильової функції залежить від квазіімпульсу, простір енергетичних зон володіє власною квантовою геометрією. Математичне виведення напівкласичних рівнянь руху із варіаційного принципу найменшої дії природним чином породжує узагальнений векторний потенціал та кривину Беррі у просторі імпульсів, які визначають аномальну швидкість носіїв, тензор квантової метрики та квантування аномальної провідності за формулою Кубо.

---

### Напівкласичний лагранжіан квантового хвильового пакета

У квантовій теорії твердого тіла електрон у провіднику описується не нескінченною пласкою хвилею, а локалізованим у просторі та квазіімпульсі хвильовим пакетом. Для `n`-ї енергетичної зони цей хвильовий пакет конструюється з блохівських функцій `Ψ_n,k(r) = exp(i · k · r) · u_n,k(r)` навколо середніх координат `r_0` та квазіімпульсу `k_0`.

Еволюція центра мас хвильового пакета під дією зовнішніх полів описується принципом найменшої дії для квантового лагранжіана `L(r, ṙ, k, k̇)`:

```
L = ⟨Ψ | i · ℏ · (∂/∂t) - H | Ψ⟩
```

Підставивши у цей лагранжіан розклад хвильового пакета за періодичними блохівськими множниками `u_n,k(r)`, отримуємо розгорнутий вираз лагранжіана через параметри `r` та `k`:

```
L(r, ṙ, k, k̇) = ℏ · k · ṙ + e · φ(r) - e · ṙ · A(r) - E_n(k) + ℏ · k̇ · A_n(k)
```

де:
- `φ(r)` та `A(r)` — макроскопічні скалярний та векторний потенціали електромагнітного поля у звичайному просторі,
- `E_n(k)` — енергія зони Блоха (дисперсія носіїв),
- `A_n(k)` — **векторний потенціал (зв'язність) Беррі** у просторі імпульсів:

```
A_n(k) = i · ⟨u_n(k) | ∇_k u_n(k)⟩
```

Зсув потенціалу `A_n(k)` виникає природним чином через часову похідну блохівського множника: `(∂/∂t) u_n,k = k̇ · ∇_k u_n,k`.

### Виведення напівкласичних рівнянь Ейлера — Лагранжа

Застосуємо рівняння Ейлера-Лагранжа для змінних `r` та `k`:

```
(d/dt) (∂L / ∂ṙ) - (∂L / ∂r) = 0
(d/dt) (∂L / ∂k̇) - (∂L / ∂k) = 0
```

Обчислимо частинні похідні лагранжіана:

```
∂L / ∂ṙ = ℏ · k - e · A(r)
∂L / ∂r = e · ∇φ - e · ∇(ṙ · A)
∂L / ∂k̇ = ℏ · A_n(k)
∂L / ∂k = ℏ · ṙ - ∇_k E_n(k) + ℏ · ∇_k (k̇ · A_n)
```

Підставивши обчислені похідні у рівняння Ейлера-Лагранжа, після застосування векторного тотожностей `∇(A · B) = (A · ∇)B + (B · ∇)A + A × (∇ × B) + B × (∇ × A)` отримуємо систему двох напівкласичних рівнянь руху:

```
ℏ · k̇ = -e · E - e · (ṙ × B)
ṙ = (1/ℏ) · ∇_k E_n(k) - k̇ × Ω_n(k)
```

де `E = -∇φ - ∂A/∂t` — електричне поле, `B = ∇ × A` — магнітна індукція, а `Ω_n(k)` — **кривина Беррі** (*Berry curvature*), визначена як ротор зв'язності Беррі в просторі імпульсів:

```
Ω_n(k) = ∇_k × A_n(k)
```

Перше рівняння описує зміну квазіімпульсу під дією сили Лоренца. Друге рівняння описує швидкість електрона `v_n(k) = ṙ`. Воно складається з двох компонент:

```
v_n(k) = v_group + v_anom
v_group = (1/ℏ) · ∇_k E_n(k)        [класична групова швидкість]
v_anom  = -k̇ × Ω_n(k)                 [аномальна швидкість Беррі]
```

За відсутності зовнішнього магнітного поля (`B = 0`), сила дорівнює `ℏ · k̇ = -e · E`. Підставивши цей вираз в аномальну швидкість, отримуємо:

```
v_anom = (e / ℏ) · E × Ω_n(k)
```

Аномальна швидкість є строго перпендикулярною до прикладеного електричного поля `E` і прямо пропорційною кривині Беррі `Ω_n(k)`.

### Калібрувальна інваріантність та диференціальна геометрія Беррі

Проаналізуємо калібрувальні властивості зв'язності `A_n(k)` та кривини `Ω_n(k)`.

Помножимо періодичну частину блохівської хвильової функції `|u_n(k)⟩` на локальний фазовий множник `exp(i · ϕ(k))`, де `ϕ(k)` — довільна гладка функція квазіімпульсу:

```
|u_n'(k)⟩ = exp(i · ϕ(k)) · |u_n(k)⟩
```

Обчислимо нову зв'язність Беррі `A_n'(k)` після фазового перетворення:

```
A_n'(k) = i · ⟨u_n'(k) | ∇_k u_n'(k)⟩
        = i · ⟨u_n(k) · exp(-i·ϕ) | [∇_k exp(i·ϕ)] · u_n(k) + exp(i·ϕ) · ∇_k u_n(k)⟩
        = i · ⟨u_n(k) | i · (∇_k ϕ) · u_n(k) + ∇_k u_n(k)⟩
        = A_n(k) - ∇_k ϕ(k)
```

Отже, зв'язність Беррі `A_n(k)` під час фазового перетворення хвильової функції змінюється на градієнт фазової функції `∇_k ϕ(k)`. Це є повною математичною аналогією калібрувального перетворення векторного потенціалу `A → A + ∇λ` у класицій електродинаміці!

Тепер обчислимо ротор від нової зв'язності `A_n'(k)`:

```
Ω_n'(k) = ∇_k × A_n'(k)
        = ∇_k × [A_n(k) - ∇_k ϕ(k)]
        = ∇_k × A_n(k) - ∇_k × (∇_k ϕ(k))
        = Ω_n(k)                       [оскільки ∇ × ∇ϕ = 0]
```

Таким чином, кривина Беррі `Ω_n(k)` є строго **калібрувально-інваріантною величинами**, яка не залежить від вибору фази блохівських функцій. Вона описує об'єктивну внутрішню геометрію квантового фазового простору енергетичної зони.

#### Фаза Беррі вздовж замкненого контура
Інтеграл від зв'язності Беррі `A_n(k)` вздовж замкненого контура `C` у просторі імпульсів визначає макроскопічну квантову **фазу Беррі** `γ_n(C)`:

```
γ_n(C) = ∮_C A_n(k) · dk
```

За теоремою Стокса, циркуляція векторного потенціалу `A_n(k)` по замкненому контуру `C` дорівнює потоку його ротора (кривини Беррі `Ω_n(k)`) через поверхню `S`, обмежену цим контуром:

```
γ_n(C) = ∬_S (∇_k × A_n(k)) · d²S = ∬_S Ω_n(k) · d²S
```

Цей результат пов'язує локальну диференціальну кривину Беррі у кожній точці квазіімпульсного простору з глобальною геометричною фазою, яку накопичує електрон під час замкненого руху в зоні Бріллюена.

### k·p теорія збурень та міжзонові матричні елементи

Для практичного розрахунку кривини Беррі `Ω_n(k)` у реальних кристалах використовують `k·p` теорію збурень та оператор швидкості.

Одночастинковий гамільтоніан електрона в кристалі з урахуванням спін-орбітальної взаємодії має вигляд:

```
H = p² / (2m) + V(r) + [ℏ / (4m²c²)] · (∇V × p) · σ
```

Підставивши блохівську хвильову функцію `Ψ_n,k(r) = exp(i · k · r) · u_n,k(r)`, отримуємо гамільтоніан для періодичних множників `u_n,k`:

```
H(k) = exp(-i·k·r) · H · exp(i·k·r)
     = H_0 + (ℏ/m) · k · p̂_k
```

де `p̂_k = p + [ℏ / (4mc²)] · (σ × ∇V)` — ефективний оператор імпульсу.

Оператор швидкості електрона визначається як похідна гамільтоніана по квазіімпульсу:

```
v̂ = (1/ℏ) · ∇_k H(k) = (1/m) · p̂_k
```

Застосовуючи першу та другу квантову теорію збурень за змінною `k`, можна виразити градієнти хвильової функції `|∇_k u_n(k)⟩` через матричні елементи оператора швидкості між різними енергетичними зонами `m ≠ n`:

```
|∇_k u_n(k)⟩ = ℏ · ∑_{m ≠ n} [ |u_m(k)⟩ · ⟨u_m(k)| v̂ |u_n(k)⟩ ] / (E_n(k) - E_m(k))
```

Підставивши цей вираз у тензорну формулу кривини Беррі `Ω_n,z(k) = i · [ ⟨∂u_n/∂k_x|∂u_n/∂k_y⟩ - ⟨∂u_n/∂k_y|∂u_n/∂k_x⟩ ]`, отримуємо знамениту **формулу сумування за зонами**:

```
Ω_n,z(k) = -2 · ℏ² · Im ∑_{m ≠ n} [ ⟨n,k| v̂_x |m,k⟩ · ⟨m,k| v̂_y |n,k⟩ ] / (E_m(k) - E_n(k))²
```

З отриманої формули випливають важливі фізичні висновки:
1. **Джерело кривини — міжзонові переходи**: Поодинока ізольована параболічна зона без взаємодії з іншими зонами має нульову кривину Беррі. Кривина виникає лише завдяки квантовій міжзоновій взаємодії під дією спін-орбітального зв'язку.
2. **Знаменник різниці енергій**: Квадрат різниці енергій `(E_m - E_n)²` у знаменнику означає, що кривина Беррі стає максимально великою у тих областях імпульсного простору, де енергетичні зони максимально зближуються між собою. Точки антиперетину зон (*avoided level crossings*), дираківські вузли та вейлівські точки є головними джерелами великого аномального ефекту Холла.

### Розрахунок для двовимірного гамільтоніана Рашби — Дрессельгауза

Розглянемо двовимірну напівпровідникову гетероструктуру у площині `xy` із двома типами спін-орбітальної взаємодії: Рашби (через структурну асиметрію потенціалу ями `E_z`) та Дрессельгауза (через інверсійну асиметрію решітки).

Загальний гамільтоніан системи приймає вигляд:

```
H = [ℏ² · (k_x² + k_y²) / (2m*)] · I + α · (σ_x · k_y - σ_y · k_x) + β · (σ_x · k_x - σ_y · k_y) + h_z · σ_z
```

де `α` — константа Рашби, `β` — константа Дрессельгауза, `h_z = (1/2) · g* · μ_B · B_z + J · M_z` — ефективне зееманівське/обмінне розщеплення.

Векторну структуру гамільтоніана можна записати у вигляді `H(k) = E_0(k) · I + d(k) · σ`, де складові вектора `d(k)` дорівнюють:

```
d_x(k) =  α · k_y + β · k_x
d_y(k) = -α · k_x - β · k_y
d_z(k) =  h_z
```

Обчислимо частинні похідні вектора `d(k)` по `k_x` та `k_y`:

```
∂d / ∂k_x = ( β, -α,  0)
∂d / ∂k_y = ( α, -β,  0)
```

Векторний добуток похідних дорівнює:

```
(∂d/∂k_x) × (∂d/∂k_y) = (0, 0, -β² + α²) = (0, 0, α² - β²)
```

Тепер обчислимо скалярний добуток із вектором `d(k)`:

```
d · [(∂d/∂k_x) × (∂d/∂k_y)] = h_z · (α² - β²)
```

Підставимо отримане значення у фундаментальну формулу для кривини Беррі нижньої підзони спінового розщеплення:

```
Ω_z(k) = (1/4) · [d · (∂d/∂k_x × ∂d/∂k_y)] / |d(k)|³
       = (1/4) · h_z · (α² - β²) / [ (α² + β²)·k² + 4αβ·k_x·k_y + h_z² ]³/²
```

З отриманої формули для моделі Рашби-Дрессельгауза випливають важливі фізичні висновки:
1. **Топологічне відображення на сферу Блоха**: Якщо ввести одиничний вектор `n(k) = d(k) / |d(k)|`, який задає напрямок спінового поля у кожній точці простору квазіімпульсів, кривина Беррі прямо дорівнює півсумі площі елементарної сфери: `Ω_z(k) = (1/2) · n · (∂ n / ∂k_x × ∂ n / ∂k_y)`. Інтегрування цього виразу по заповнених станах дає ступінь топологічного відображення (число Скірміона) квазіімпульсної площини на двовимірну сферу спінів.
2. **Інтерференція Рашби та Дрессельгауза**: Якщо константи Рашби та Дрессельгауза є однаковими за модулем (`|α| = |β|`), векторне поле `d(k) = (α(k_y + k_x), -α(k_x + k_y), h_z)` вироджується: його векторний добуток `(∂d/∂k_x) × (∂d/∂k_y)` точно дорівнює нулю у всіх точках квазіімпульсного простору. В результаті кривина Беррі `Ω_z(k) = 0` зникає, а аномальний ефект Холла повністю скасовується завдяки появі додаткової суметрії персистентного спінового спірального стану.
3. **Перевага одного з механізмів**: Для спостереження максимального аномального ефекту Холла необхідно, щоб один із типів спін-орбітальної взаємодії суттєво переважав інший (`α >> β` або `β >> α`), що розгортає структуру спінового текстурування у 2D-зоні.

### Точний розрахунок для двокомпонентної моделі Дійрака

Розглянемо ефективний двовимірний гамільтоніан Дійрака з масовим членом `m` (який описує 2D феромагнетик або топологічний ізолятор зі спін-орбітальним розщепленням):

```
H(k) = d_x(k) · σ_x + d_y(k) · σ_y + d_z(k) · σ_z
```

де `σ_x, σ_y, σ_z` — матриці Паулі, а вектор компонент дорівнює `d(k) = (v_F · k_x, v_F · k_y, m)`.

Власні значення енергії цього гамільтоніана описують валентну зону `-` та зону провідності `+`:

```
E_±(k) = ± |d(k)| = ± √(v_F² · k_x² + v_F² · k_y² + m²)
```

Для двокомпонентної системи тензор кривини Беррі `Ω_z(k)` нижньої (валентної) зони обчислюється за витонченою геометричною формулою:

```
Ω_z(k) = (1 / 4) · [d · (∂d/∂k_x × ∂d/∂k_y)] / |d|³
```

Обчислимо частинні похідні вектора `d(k)` по `k_x` та `k_y`:

```
∂d / ∂k_x = (v_F, 0, 0)
∂d / ∂k_y = (0, v_F, 0)
```

Векторний добуток похідних дорівнює:

```
(∂d/∂k_x) × (∂d/∂k_y) = (0, 0, v_F²)
```

Тепер обчислимо скалярний добуток із вектором `d = (v_F·k_x, v_F·k_y, m)`:

```
d · [(∂d/∂k_x) × (∂d/∂k_y)] = m · v_F²
```

Підставивши цей результат у формулу кривини Беррі, отримуємо остаточний аналітичний вираз:

```
Ω_z(k) = (1 / 2) · (m · v_F²) / (v_F² · k² + m²)³/²
```

З отриманої формули видно ключові фізичні риси кривини Беррі:
1. **Знак маси визначає знак кривини**: Якщо змінити знак масового члена `m → -m` (що відповідає інверсії напрямку спонтанної намагніченості `M_z → -M_z`), кривина Беррі змінює свій знак на протилежний.
2. **Пик у центрі зони**: Кривина Беррі досягає свого максимуму в центрі дираківського конуса (`k = 0`), де вона дорівнює `Ω_z(0) = v_F² / (2 · m²)`, і спадає як `1/k³` при великих квазіімпульсах.

### Інтегрування кривини Беррі та Обчислення аномальної провідності Холла

Для обчислення макроскопічної аномальної провідності Холла `σ_xy^AH` необхідно проінтегрувати кривину Беррі `Ω_z(k)` по усій площині квазіімпульсів для заповненої валентної зони (при `T = 0` К рівень Фермі знаходиться в енергетичній щілині `|E_F| < m`):

```
σ_xy^AH = -(e² / h) · [1 / (2π)] · ∬ d²k · Ω_z(k)
```

Перейдемо до полярних координат у площині імпульсів (`d²k = 2π · k · dk` від `k = 0` до `k → ∞`):

```
∬ d²k · Ω_z(k) = 2π · ∫₀^∞ k dk · [ (1/2) · m · v_F² / (v_F² · k² + m²)³/² ]
```

Зробимо заміну змінної `u = v_F² · k² + m²`, звідси `du = 2 · v_F² · k dk`:

```
∫₀^∞ k dk / (v_F² · k² + m²)³/²
= [1 / (2 · v_F²)] · ∫_{m²}^∞ du / u³/²
= [1 / (2 · v_F²)] · [ -2 / √u ]_{m²}^∞
= [1 / (2 · v_F²)] · [ 0 - (-2 / |m|) ]
= 1 / (v_F² · |m|)
```

Підставимо отриманий інтеграл назад у формулу провідності:

```
σ_xy^AH
= -(e² / h) · [1 / (2π)] · 2π · [ (1/2) · m · v_F² · (1 / (v_F² · |m|)) ]
= -(e² / h) · (1/2) · (m / |m|)
= -(e² / 2h) · sgn(m)
```

Отриманий результат є математично дивовижним: аномальна провідність Холла двовимірного масивного дираківського ферміона дорівнює **точно половині кванта провідності** `e² / (2h)` зі знаком, що визначається напрямком намагніченості `sgn(m)`!

#### Залежність провідності від рівня Фермі та температури
У випадку, коли рівень хімічного потенціалу `E_F` перетинає зону провідності (`|E_F| > |m|`), межа інтегрування змінюється від `k = 0` до імпульсу Фермі `k_F = √(E_F² - m²) / v_F`. 

Тоді інтеграл дорівнює:

```
σ_xy^AH(E_F) = -(e² / 2h) · m · [ (1 / |m|) - (1 / |E_F|) ] = -(e² / 2h) · sgn(m) · [ 1 - |m| / |E_F| ]
```

При підйомі рівня Фермі глибоко в зону провідності (`|E_F| >> |m|`) внески від станів з протилежною кривиною Беррі поступово компенсуються, і аномальна провідність згасає як `1 / |E_F|`.

Коли система складається з двох дзеркальних дираківських конусів (як у топологічному ізоляторі з двома поверхнями), їхні внески додаються, утворюючи точний цілочисельний квантовий аномальний ефект Холла зі значенням провідності `σ_xy^AH = e² / h` без жодного зовнішнього магнітного поля.

### Зв'язок із формалізмом Кубо — Стради

У квантовій статистичній фізиці провідність обчислюється через функцію відгуку струму на електричне поле за формулою Кубо-Стради:

```
σ_xy = (i / V) · ∑_{m ≠ n} (f_n - f_m) · [ ⟨n| ĵ_x |m⟩ · ⟨m| ĵ_y |n⟩ ] / [ (E_n - E_m) · (E_n - E_m + i·η) ]
```

де `ĵ = -e · v̂` — оператор густини струму, `V` — об'єм системи, а `η → 0⁺` описує адіабатичне включення поля.

Взявши антисиметричну частину тензора провідності `σ_xy^AH = (σ_xy - σ_yx) / 2` та випустивши грандичену граничну область `η → 0`, вираз Кубо точно зводиться до:

```
σ_xy^AH = -(e² / ℏ) · ∑_n ∫ [d³k / (2π)³] · f(E_n(k)) · Ω_n,z(k)
```

Це доводить сувору еквівалентність між лінійним відгуком Кубо у квантовій теорії багатьох тіл та напівкласичним інтегруванням кривини Беррі Карплуса-Латтінджера.

### Квантовий геометричний тензор та риманова метрика простору Блоха

Кривина Беррі є лише уявною частиною більш загального квантового об'єкта — **квантового геометричного тензора** (*Quantum Geometric Tensor*, QGT), також відомого як тензор Проді — Преспрейгера — Фубіні — Штуді.

Розглянемо безкоординатну відстань між двома близькими за квазіімпульсом блохівськими станами `|u_n(k)⟩` та `|u_n(k + dk)⟩`:

```
dS² = 1 - |⟨u_n(k) | u_n(k + dk)⟩|²
```

Розкладаючи цей вираз у ряд Тейлора до другого порядку за малим зсувом квазіімпульсу `dk_i`, отримуємо квадратичну форму `dS² = ∑_{i,j} Q_ij^n(k) · dk_i · dk_j`, де комплексний квантовий геометричний тензор `Q_ij^n(k)` визначено як:

```
Q_ij^n(k) = ⟨∂_i u_n(k) | (1 - |u_n(k)⟩⟨u_n(k)|) | ∂_j u_n(k)⟩
```

де `∂_i ≡ ∂ / ∂k_i`.

Розділивши тензор `Q_ij^n(k)` на дійсну та уявну частини:

```
Q_ij^n(k) = g_ij^n(k) - (i / 2) · F_ij^n(k)
```

отримуємо дві фундаментальні геометрії простору квантових станів:

1. **Квантова метрика Фубіні — Штуді `g_ij^n(k)`** (дійсна симетрична частина):
   ```
   g_ij^n(k) = Re [ Q_ij^n(k) ] = (1/2) · [ ⟨∂_i u_n | ∂_j u_n⟩ + ⟨∂_j u_n | ∂_i u_n⟩ ] - A_i^n · A_j^n
   ```
   Вона визначає ріманову метрику та квантову відстань `dS² = g_ij · dk_i · dk_j` між енергетичними станами в зоні Бріллюена, задаючи межі квантової роздільної здатності, локалізації хвильових пакетів Ванньє та квантового затухання хвильових пакетів у зонних ізоляторах і надпровідниках. Інтеграл від квантової метрики по всій зоні Бріллюена встановлює фізичну нижню межу для просторового поширення функцій Ванньє.

2. **Тензор кривини Беррі `F_ij^n(k)`** (уявна антисиметрична частина):
   ```
   F_ij^n(k) = -2 · Im [ Q_ij^n(k) ] = ∂_i A_j^n - ∂_j A_i^n
   ```
   У тривимірному просторі псевдовектор кривини Беррі пов'язаний із тензором співвідношенням `Ω_k^n = (1/2) · ε_kij · F_ij^n`.

Квантова метрика `g_ij(k)` відіграє ключову роль у дисипативному транспорті, оптичному поглинанні та нелінійних квантових явищах, тоді як кривина `F_ij(k)` повністю контролює бездисипативний поперечний аномальний струм Холла.

### Диполь кривини Беррі та математика нелінійного аномального ефекту Холла

У нецентричносиметричних кристалах зі збереженою симетрією інверсії часу (`T`) кривина Беррі є непарною функцією квазіімпульсу: `Ω_n(-k) = -Ω_n(k)`. В результаті сумарний лінійний інтеграл провідності за заповненими станами строго дорівнює нулю:

```
σ_xy^AH = -(e² / ℏ) · ∫ [d³k / (2π)³] · f_0(E_k) · Ω_z(k) = 0
```

Проте розклад квазірівноважної функції розподілу Фермі — Дірака у другому порядку за зовнішнім електричним полем `E = Re[E_0 · exp(i·ω·t)]` дає квантову поправку `f^(2)(k)`. 

Нелінійний поперечний струм другої гармоніки `j_i^(2ω) = χ_ijk · E_j · E_k` описується тензором нелінійної провідності:

```
χ_ijk = -(e³ · τ / (2 · ℏ² · (1 + i·ω·τ))) · D_jk
```

де `D_jk` — **тензор диполя кривини Беррі** (*Berry curvature dipole*), визначений як градієнт кривини Беррі по простору імпульсів на поверхні Фермі:

```
D_jk = ∑_n ∫ [d³k / (2π)³] · (∂f_0 / ∂E_n) · (∂Ω_n,k / ∂k_j) = - ∑_n ∫ [d³k / (2π)³] · f_0(E_n) · (∂Ω_n,k / ∂k_j)
```

Математичні властивості диполя кривини Беррі:
1. **Інтегрування по поверхні Фермі**: Оскільки `∂f_0 / ∂E = -δ(E - E_F)`, диполь `D_jk` вимірюється виключно на поверхні Фермі, що робить його надзвичайно чутливим до зміни рівня хімічного потенціалу та легування.
2. **Точкова симетрія кристала**: Диполь кривини Беррі може бути ненульовим лише у кристалічних гратках із низькою точковою симетрією (полярні кристали, моноклінні та триклінні структури, двовимірні матеріали `WTe_2` та `TaIrTe_4`), де дзеркальні площини не компенсують векторну суму градієнтів кривини. Це відкриває математичне підґрунтя для нелінійного перетворення терагерцових сигналів та генерації постійного фотоструму у квантових наноматеріалах без зовнішнього магнітного поля.
