# 📐 Довідник: Інженерний калькулятор та співвідношення полів диполя Герца

Цей довідник містить повне зведення інженерних формул, розрахункових коефіцієнтів та меж застосовності для елементарного електричного диполя Герца довжиною `dl ≪ λ`. Документ призначено для швидкого використання при проектуванні бездротових систем, розрахунку радіоліній (Link Budget) та оцінці випромінюваних завад (EMC).

---

## 1. Фундаментальні константи та база розрахунку

При обчисленні полів та параметрів випромінювання у вільному просторі (вакуумі) використовуються такі фундаментальні фізичні сталі:

- **Швидкість світла у вакуумі:** `c = 2.997 924 58 × 10⁸ м/с`
- **Електрична стала:** `ε₀ = 8.854 187 81 × 10⁻¹² Ф/м`
- **Магнітна стала:** `μ₀ = 4π × 10⁻⁷ Гн/м ≈ 1.2566 × 10⁻⁶ Гн/м`
- **Хвильовий імпеданс вакууму:** `η₀ = √(μ₀ / ε₀) = 120π ≈ 376.730313 Ом`

Хвильове число `k` та довжина хвилі `λ` пов'язані з коловою частотою `ω = 2π·f` базовими співвідношеннями `λ = c / f` та `k = 2π / λ = ω / c`.

## 2. Аналітичний розклад компонент полів у сферичних координатах

Для елементарного диполя з гармонічним струмом `I(t) = I₀ · sin(ω·t)` компоненти електромагнітного поля у сферичній системі координат `(r, θ, φ)` обчислюються за виразами:

1. **Радіальна компонента електричного поля `E_r`:**
   ```
   E_r = (2 · I₀ · dl / (4π · ε₀ · ω)) · cos(θ) · [ (cos(ω · t') / r³) − (k · sin(ω · t') / r²) ]
   ```
   У ближній зоні (`kr ≪ 1`) ця компонента домінує за законом `1/r³`, а у дальній зоні (`kr ≫ 1`) вона прямує до нуля, забезпечуючи строго поперечний характер хвилі.

2. **Меридіональна компонента електричного поля `E_θ`:**
   ```
   E_θ = (I₀ · dl / (4π · ε₀ · ω)) · sin(θ) · [ (cos(ω · t') / r³) − (k · sin(ω · t') / r²) − (k² · cos(ω · t') / r) ]
   ```
   У дальній зоні виживає лише третій доданок, що спадає за законом `1/r`.

3. **Азимутальна компонента магнітного поля `H_φ`:**
   ```
   H_φ = (I₀ · dl / (4π)) · sin(θ) · [ (sin(ω · t') / r²) + (k · cos(ω · t') / r) ]
   ```
   У ближній зоні поле згасає за законом Біо-Савара `1/r²`, а у дальній зоні — за хвильовим законом `1/r`.

## 3. Межі просторових зон та імпеданс полів

Увесь простір навколо осцилятора розділяють на три ключові інженерні зони:

- **Реактивна ближня зона (`r < λ / (2π) ≈ 0.159 · λ`):** У цій області фази електричного й магнітного полів зсунуті на 90 градусів. Хвильовий імпеданс поля `Z_wave = |E_θ / H_φ| ≈ η₀ / (k·r)` значно перевищує 377 Ом, утворюючи високоомне реактивне поле.
- **Проміжна зона індукції (`r ≈ λ / (2π)`):** Зонний перехід, у якому зсув фаз між полями зменшується від 90 до 0 градусів.
- **Дальня хвильова зона (`r > 2 · λ`):** Область вільної хвилі, де поля сінфазні, а хвильовий імпеданс дорівнює хвильовому опору вакууму `Z_wave = η₀ ≈ 377 Ом`.

## 4. Специфікація випромінювальних параметрів диполя Герца

Нижче наведено зведення інженерних параметрів елементарного випромінювача:

- **Потужність випромінювання `P_rad`:** Обчислюється як `P_rad = 40 · π² · (dl / λ)² · I₀²` для амплітудного струму `I₀`, або `P_rad = I_rms² · R_rad` для діючого струму.
- **Опір випромінювання `R_rad`:** Еквівалентний опір випромінювача дорівнює `R_rad = 80 · π² · (dl / λ)²` Ом.
- **Максимальна спрямованість `D_max`:** Коефіцієнт спрямованості становить `D_max = 1.5` (що відповідає `1.76 dBi`) у напрямку екваторіальної площини `θ = 90°`.
- **Ефективна апертура `A_eff`:** Максимальна площа поглинання падаючої хвилі становить `A_eff = (3 / 8π) · λ² ≈ 0.11937 · λ²`.
- **Ширина діаграми спрямованості (HPBW):** У меридіональній площині `E` ширина становить `90°`, а в азимутальній площині `H` діаграма є круговою (`360°`).

## 5. Розрахунок теплових втрат та коефіцієнта корисної дії (ККД)

Для реального металевого провідника радіуса `a` з питомою провідністю `σ` (для міді `σ = 5.8 × 10⁷ См/м`) високочастотний омічний опір втрат `R_loss` обумовлений скін-ефектом.

Глибина скін-шару `δ_skin` обчислюється за формулою:

```
δ_skin = √(2 / (ω · μ₀ · σ))
```

Опір втрат провідника довжиною `dl` становить:

```
R_loss = (dl / (2π · a)) · √(ω · μ₀ / (2 · σ))
```

Повний ККД випромінювання антени `η_rad` визначається як відношення опору випромінювання `R_rad` до сумарного опору `R_rad + R_loss`:

```
η_rad = R_rad / (R_rad + R_loss) = [ 80·π²·(dl/λ)² ] / [ 80·π²·(dl/λ)² + R_loss ]
```

При скороченні довжини диполя `dl ≪ 0.01 λ` опір `R_rad` прямує до нульових значень (міліоми), що призводить до катастрофічного падіння ККД антени до часток відсотка.

## 6. Зведення характеристик на стандартних бездротових частотах

Розглянемо параметри елементарного диполя Герца фіксованої відносної довжини `dl = 0.02 λ` на чотирьох популярних частотах бездротового зв'язку:

1. **Діапазон 13.56 МГц (NFC / RFID):**
   Довжина хвилі `λ = 22.11 м`, довжина диполя `dl = 0.442 м`. Опір випромінювання становить `R_rad = 0.316 Ом`, межа реактивної ближньої зони `r_near = 3.52 м`, а ефективна апертура `A_eff = 58.3 м²`. На цих частотах безконтактні зчитувачі завжди працюють виключно у ближній реактивній зоні.

2. **Діапазон 433 МГц (Sub-GHz IoT / ISM):**
   Довжина хвилі `λ = 0.693 м`, довжина диполя `dl = 1.39 см`. Опір випромінювання дорівнює `R_rad = 0.316 Ом`, межа ближньої зони `r_near = 11 см`, а ефективна апертура `A_eff = 0.0573 м²`.

3. **Діапазон 2.45 ГГц (Wi-Fi / Bluetooth):**
   Довжина хвилі `λ = 0.122 м`, довжина диполя `dl = 2.45 мм`. Опір випромінювання `R_rad = 0.316 Ом`, межа ближньої зони `r_near = 1.95 см`, ефективна апертура `A_eff = 0.00179 м²`.

4. **Діапазон 28 ГГц (5G mmWave):**
   Довжина хвилі `λ = 10.7 мм`, довжина диполя `dl = 0.214 мм`. Опір випромінювання `R_rad = 0.316 Ом`, межа ближньої зони `r_near = 1.70 мм`, ефективна апертура `A_eff = 1.37 × 10⁻⁵ м²`.

## 7. Чисельний приклад інженерного розрахунку: 433 МГц

Проведемо покроковий розрахунок полів та потужності для бездротового датчика IoT на частоті `f = 433.92 МГц`.

### Вихідні дані:
- Струм у диполі: `I_rms = 100 мА = 0.1 А` (`I₀ = 0.1414 А`)
- Довжина диполя: `dl = 1.38 см = 0.0138 м`
- Відстань спостереження: `r = 10 м`
- Кут спостереження: `θ = 90°` (екваторіальна площина)

### Крок 1. Розрахунок хвильових параметрів
Довжина хвилі становить `λ = 299792458 / 433.92e6 ≈ 0.6909 м`, а хвильове число `k = 2π / 0.6909 ≈ 9.094 рад/м`. Відношення `dl / λ = 0.0138 / 0.6909 ≈ 0.02` підтверджує елементарність випромінювача (`dl ≪ λ`).

### Крок 2. Розрахунок опору випромінювання та випроміненої потужності
Опір випромінювання становить:
```
R_rad = 80 · π² · (0.02)² ≈ 789.57 · 0.0004 ≈ 0.3158 Ом
```
Повна випромінювана потужність дорівнює:
```
P_rad = I_rms² · R_rad = (0.1)² · 0.3158 ≈ 0.003158 Вт ≈ 3.16 мВт (5.0 dBm)
```

### Крок 3. Визначення зони спостереження
Межа ближньої зони дорівнює `r_boundary = λ / (2π) = 0.6909 / (2π) ≈ 0.110 м` (11 см). Оскільки точка спостереження розташована на відстані `r = 10 м ≫ 0.11 м`, вона лежить глибоко у дальній хвильовій зоні.

### Крок 4. Обчислення амплітуд полів на відстані 10 метрів
Меридіональне електричне поле становить:
```
E_θ = (η₀ · k · I₀ · dl / (4π · r)) · sin(90°)
= (376.73 · 9.094 · 0.1414 · 0.0138 / (4π · 10)) · 1.0 ≈ 0.0532 В/м (53.2 мВ/м)
```
Азимутальне магнітне поле дорівнює:
```
H_φ = E_θ / η₀ = 0.0532 / 376.73 ≈ 1.412 × 10⁻⁴ А/м (141.2 мкА/м)
```

### Крок 5. Обчислення густини потоку Пойнтінга
```
⟨S_r⟩ = E_θ² / (2 · η₀) = (0.0532)² / (2 · 376.73) ≈ 3.756 × 10⁻⁶ Вт/м²
```
Напруженість електричного поля у логарифмічних одиницях вимірювання становить:
```
E_dB = 20 · log₁₀(0.0532 / 1e-6) ≈ 94.5 dBµV/m
```

## 8. Схеми узгодження короткого диполя (Matching Networks)

Оскільки опір випромінювання короткого диполя `R_rad` є вкрай малим (`< 1 Ом`), а його власна ємність `C_in ≈ π · ε₀ · dl / ln(dl/a)` створює високий реактивний опір `X_in = −1 / (ω·C_in)`, пряме підключення диполя до 50-омного кабелю призведе до майже повного відбиття сигналу.

Для узгодження імпедансів використовують такі інженерні рішення:

- **Послідовна подовжувальна котушка (Loading Coil):** Включення індуктивності `L_match = 1 / (ω² · C_in)` для компенсації ємнісного опору антени.
- **Трансформаторний автотрансформатор чи балун (Balun 1:N):** Трансформація низького активного опору `R_rad` до стандартного опору тракту `50 Ом`.
- **L-подібна узгоджувальна ланцюжка (L-Match Section):** Двоелементна LC-мережа, де паралельний конденсатор підвищує активний опір, а послідовна індуктивність нейтралізує залишковий реактанс.

## 9. Порівняльний аналіз диполя Герца з класичними антенами

Розглянемо порівняння параметрів елементарного диполя з іншими типами антен:

- **Диполь Герца (`dl ≪ λ`):** Рівномірний струм `I₀ = const`, опір випромінювання `R_rad = 80·π²·(dl/λ)²`, спрямованість `D = 1.50` (`1.76 dBi`), ефективна апертура `A_eff = 0.119 · λ²`.
- **Короткий диполь (`L < 0.1 λ`):** Трикутний розподіл струму зі спаданням до 0 на кінцях, опір випромінювання `R_rad = 20·π²·(L/λ)²`, спрямованість `D = 1.50` (`1.76 dBi`), апертура `A_eff = 0.119 · λ²`.
- **Півхвильовий диполь (`L = 0.5 λ`):** Синусоїдальний розподіл струму, опір випромінювання `R_rad = 73.1 Ом`, спрямованість `D = 1.64` (`2.15 dBi`), апертура `A_eff = 0.130 · λ²`.
- **Хвильовий диполь (`L = 1.0 λ`):** Повний синусоїдальний розподіл струму, опір випромінювання `R_rad = 199 Ом`, спрямованість `D = 2.41` (`3.82 dBi`), апертура `A_eff = 0.191 · λ²`.
- **Мала магнітна петля (`R ≪ λ`):** Рівномірний струм у колі, опір випромінювання `R_rad = 320·π⁴·(S/λ²)²`, спрямованість `D = 1.50` (`1.76 dBi`), апертура `A_eff = 0.119 · λ²`.

## 10. Методика вимірювання полів диполя у безвідлунній камері

При проведенні сертифікаційних випробувань радіоелектронного обладнання на електромагнітну сумісність (EMC) та визначення калібрувального фактора антен виконують вимірювання полів у безвідлунній камері (Anechoic Chamber).

Основними етапами методики є:

1. **Калібрування антенного фактора (Antenna Factor, AF):**
   Антенний фактор пов'язує напруженість електричного поля `E` у точці розташування антени з напругою `V_rx` на 50-омному вході вимірювального приймача:
   ```
   AF = E / V_rx = (9.73 / λ) / √D_max  [1/м]
   ```
   У логарифмічних одиницях: `AF_dB = 20·log₁₀(AF)`. Для елементарного диполя Герца з `D = 1.5` антенний фактор дорівнює `AF_dB = 20·log₁₀(7.94 / λ)`.

2. **Оцінка крос-поляризаційної розв'язки (Cross-Polar Discrimination, XPD):**
   При обертанні приймальної дипольної антени на 90 градусів відносно передавальної антени рівень прийнятого сигналу повинен зменшуватися щонайменше на 30–40 дБ. Втрата крос-поляризаційної розв'язки свідчить про наявність паразитного відбиття від стін або нерівномірність амплітудно-фазового розподілу струму.

3. **Вимірювання комплексного коефіцієнта відбиття S11:**
   За допомогою векторного аналізатора кіл (VNA) вимірюють параметр `S₁₁` у часовій області із застосуванням часових воротаря (Time-Domain Gating) для виключення паразитного впливу кабелів підведення живлення.

## 11. Поширення полів у середовищах із втратами та електромагнітне екранування

Коли диполь Герца випромінює у середовищі з ненульовою провідністю `σ` (наприклад, морська вода, ґрунт або біологічні тканини), комплексна діелектрична проникність набуває вигляду:

```
ε_complex = ε − j · (σ / ω)
```

Внаслідок виникнення струмів провідності хвилеве число `k` стає комплексним: `k_complex = β − j·α`, де `α` — коефіцієнт згасання, а `β` — коефіцієнт фази:

```
α = ω · √( (μ·ε/2) · [ √(1 + (σ/(ω·ε))²) − 1 ] )
β = ω · √( (μ·ε/2) · [ √(1 + (σ/(ω·ε))²) + 1 ] )
```

У дальній зоні амплітуда полів спадає за експоненційним законом `E(r) ∝ (1/r) · e^(−α·r)`.

Для розрахунку коефіцієнта екранування `SE` (Shielding Effectiveness) металевого екрана у ближній зоні диполя вираховують суму трьох складових: поглинання у товщі металу `A_shield`, відбиття від межі `R_shield` та багаторазових внутрішніх відбиттів `M_shield`:

```
SE_dB = A_shield + R_shield + M_shield
```

Оскільки у ближній зоні електричного диполя імпеданс поля `Z_wave ≫ 377 Ом`, відбиття електричного поля від високопровідних металевих листів (мідь, алюміній) є надзвичайно ефективним (`R_shield > 100 dB`), що дозволяє надійно екранувати високовольтні елементи за допомогою тонких фольгованих екранів.
