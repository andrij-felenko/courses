# 🧮 Математика: Повний вивід полів та випромінювання диполя Герца

Розглянемо математичну модель елементарного електричного диполя Герца — тонкого прямолінійного провідника довжиною `dl`, розташованого уздовж осі `z` у початку координат сферичної системи `(r, θ, φ)`.

Головна умова елементарності диполя полягає в тому, що його довжина `dl` є нехтовно малою порівняно з довжиною випромінюваної хвилі `λ` (`dl ≪ λ`). Завдяки цьому струм `I(t)` вздовж усього провідника можна вважати строго однаковим за амплітудою й фазою у кожен момент часу:

```
I(t) = I₀ · sin(ω · t)
```

Заряди на кінцях диполя змінюються за гармонічним законом:

```
q(t) = −q₀ · cos(ω · t)
```

причому зв'язок амплітуди струму й заряду задається співвідношенням `I₀ = dq/dt = q₀ · ω`. Електричний дипольний момент системи дорівнює:

```
p(t) = q(t) · dl = p₀ · cos(ω · t)
```

де `p₀ = q₀ · dl` — амплітуда електричного дипольного моменту.

## 1. Потенціали електромагнітного поля та умова калібрування Лоренца

У класичній електродинаміці для розрахунку змінних полів застосовується апарат електромагнітних потенціалів: скалярного потенціалу `Φ` та векторного потенціалу `A`. Вони пов'язані з напруженостями електричного `E` та магнітного `B` полів відомими співвідношеннями:

```
B = ∇ × A
E = −∇Φ − ∂A/∂t
```

Щоб однозначно визначити потенціали, накладають умову калібрування Лоренца, яка зв'язує просторові похідні векторного потенціалу з часовою похідною скалярного потенціалу:

```
div(A) + (1 / c²) · ∂Φ/∂t = 0
```

Завдяки цьому рівняння Максвелла зводяться до двох незалежних хвильових рівнянь Даламбера для скалярного й векторного потенціалів.

Оскільки струм орієнтований виключно вздовж осі `z`, густина струму `J` має лише z-компоненту. Отже, векторний потенціал `A` у всьому просторі має лише одну ненульову компоненту `A_z`. У точці спостереження на відстані `r` з урахуванням запізнення сигналу зі швидкістю світла `c` виражаємо векторний потенціал через запізнілий струм:

```
A_z(r, t) = (μ₀ / (4π · r)) · I₀ · dl · sin(ω · (t − r/c))
```

Для зручності введемо хвильове число `k = ω / c = 2π / λ` та запізнілу фазу `t' = t − r/c`. Тоді z-компонента потенціалу набуває вигляду:

```
A_z(r, t) = (μ₀ · I₀ · dl / (4π · r)) · sin(ω · t')
```

Перейдемо від декартової системи до сферичних координат `(r, θ, φ)`. Оскільки вісь `z` утворює кут `θ` з радіус-вектором `r`, проєкції векторного потенціалу дорівнюють:

```
A_r = A_z · cos(θ) = (μ₀ · I₀ · dl / (4π · r)) · sin(ω · t') · cos(θ)
A_θ = −A_z · sin(θ) = −(μ₀ · I₀ · dl / (4π · r)) · sin(ω · t') · sin(θ)
A_φ = 0
```

## 2. Строгий розрахунок магнітного поля H = (1/μ₀) · (∇ × A)

Магнітна індукція визначається через ротор векторного потенціалу: `B = ∇ × A`, а напруженість магнітного поля у вакуумі становить `H = B / μ₀`.

У сферичних координатах із врахуванням осесиметрії системи відносно осі `z` (`∂/∂φ = 0` та `A_φ = 0`) єдиною ненульовою компонентою ротора є азимутальна компонента `H_φ`:

```
H_φ = (1 / μ₀) · (1 / r) · [ ∂(r · A_θ)/∂r − ∂A_r/∂θ ]
```

Підставимо складові `A_r` та `A_θ`:

```
∂A_r/∂θ = −(μ₀ · I₀ · dl / (4π · r)) · sin(ω · t') · sin(θ)
```

Обчислимо похідну по радіусу `r` від добутку `r · A_θ`:

```
r · A_θ = −(μ₀ · I₀ · dl / 4π) · sin(ω · t') · sin(θ)
```

Зважаючи на те, що аргумент `t' = t − r/c` залежить від `r`, застосовуємо правило диференціювання складеної функції:

```
∂(sin(ω · (t − r/c))) / ∂r = −(ω / c) · cos(ω · t') = −k · cos(ω · t')
```

Тоді:

```
∂(r · A_θ) / ∂r = (μ₀ · I₀ · dl / 4π) · k · cos(ω · t') · sin(θ)
```

Збираємо обидва доданки для `H_φ`:

```
H_φ(r, θ, t)
= (1 / μ₀ · r) · [ (μ₀ · I₀ · dl / 4π) · k · cos(ω · t') · sin(θ) + (μ₀ · I₀ · dl / (4π · r)) · sin(ω · t') · sin(θ) ]
= (I₀ · dl / (4π)) · sin(θ) · [ (sin(ω · t') / r²) + (k · cos(ω · t') / r) ]      [факт розкладу на квазістатичне та випромінювальне поля]
```

Остаточний вираз для магнітного поля містить два доданки з різною залежністю від відстані:

```
H_φ(r, θ, t) = (I₀ · dl / (4π)) · sin(θ) · [ (sin(ω · t') / r²) + (k · cos(ω · t') / r) ]
```

Перший доданок `1/r²` являє собою звичайне індукційне поле Біо-Савара-Лапласа, а другий доданок `k/r` — це випромінювальне поле хвилі.

## 3. Розрахунок скалярного потенціалу та напруженості електричного поля

Для знаходження електричного поля можна скористатися прямим розрахунком через скалярний `Φ` та векторний `A` потенціали: `E = −∇Φ − ∂A/∂t`.

Скалярний потенціал `Φ` обчислюється з умови калібрування Лоренца `∂Φ/∂t = −c² · div(A)`. Для точкового диполя з моментом `p(t')` скалярний потенціал дорівнює:

```
Φ(r, θ, t) = (1 / (4π · ε₀)) · [ (p(t') / r²) + (1 / (c · r)) · ∂p(t')/∂t ] · cos(θ)
```

Підставляючи `p(t') = p₀ · cos(ω · t')`, отримуємо:

```
Φ(r, θ, t) = (p₀ · cos(θ) / (4π · ε₀)) · [ (cos(ω · t') / r²) − (k · sin(ω · t') / r) ]
```

### Диференціювання скалярного потенціалу для знаходження компонент електричного поля

Електричне поле має дві складові у сферичних координатах:

```
E_r = −∂Φ/∂r − ∂A_r/∂t
E_θ = −(1 / r) · ∂Φ/∂θ − ∂A_θ/∂t
```

Обчислимо похідні по радіусу `r` та куту `θ`. Диференціювання виразу `Φ` по `r` дає доданки із трьома степенями відстані (`1/r³`, `1/r²` та `1/r`). Після додавання часової похідної векторного потенціалу `−∂A_r/∂t` доданок `1/r` у радіальній компоненті строго взаємно скорочується!

В результаті радіальна компонента `E_r` не містить випромінювального члена `1/r`:

```
E_r(r, θ, t) = (2 · I₀ · dl / (4π · ε₀ · ω)) · cos(θ) · [ (cos(ω · t') / r³) − (k · sin(ω · t') / r²) ]
```

А меридіональна компонента `E_θ` зберігає всі три степені відстані:

```
E_θ(r, θ, t) = (I₀ · dl / (4π · ε₀ · ω)) · sin(θ) · [ (cos(ω · t') / r³) − (k · sin(ω · t') / r²) − (k² · cos(ω · t') / r) ]
```

## 4. Фізичний аналіз полів у трьох просторових зонах

Співвідношення між доданими степенями `1/r³`, `1/r²` та `1/r` визначається безрозмірним параметром `k · r = (2π / λ) · r`.

### Ближня (реактивна) зона: k · r ≪ 1 (r ≪ λ / (2π))

У ближній зоні домінують доданки з найвищими степенями відстані `1/r³` для `E` та `1/r²` для `H`:

```
E_r ≈ (2 · p₀ · cos(θ) / (4π · ε₀ · r³)) · cos(ω · t')
E_θ ≈ (p₀ · sin(θ) / (4π · ε₀ · r³)) · cos(ω · t')
H_φ ≈ (I₀ · dl · sin(θ) / (4π · r²)) · sin(ω · t')
```

Зверніть увагу на фазовий зсув: `E` змінюється за законом `cos(ω · t')`, а `H` — за законом `sin(ω · t')`. Зсув фаз становить `90°` (`π/2`). Це означає, що середня потужність, яка передається у цій зоні, дорівнює нулю: енергія лише коливається між джерелом і полем, як у звичайному реактивному `LC`-контурі.

### Проміжна зона (зона індукції): k · r ~ 1 (r ≈ λ / (2π))

У цій зоні доданки всіх степенів стають співмірними. Зсув фаз між `E` та `H` починає плавно зміщуватися від `90°` до `0°`, викристалізовуючи хвильовий фронт.

### Дальня (випромінювальна) зона: k · r ≫ 1 (r ≫ λ / (2π))

Збережемо лише доданки, що згасають найповільніше — за законом `1/r`:

```
E_r ≈ 0
E_θ ≈ −(I₀ · dl · ω / (4π · ε₀ · c² · r)) · sin(θ) · cos(ω · t')
    = −(k² · I₀ · dl / (4π · ε₀ · ω · r)) · sin(θ) · cos(ω · t')
H_φ ≈ −(k · I₀ · dl / (4π · r)) · sin(θ) · cos(ω · t')
```

Обидва поля `E_θ` та `H_φ` коливаються в **однаковій фазі** `cos(ω · t')`. Їхнє відношення становить:

```
E_θ / H_φ = k / (ε₀ · ω) = ω / (c · ε₀ · ω) = 1 / (c · ε₀) = √(μ₀ / ε₀) = η₀ ≈ 377 Ом
```

Це фундаментальна величина — **хвильовий імпеданс вакууму** `η₀`.

## 5. Потік Пойнтінга та вивід формули Лармора

Миттєва густина потоку енергії задається вектором Пойнтінга `S = E × H`. У дальній зоні вектор `S` орієнтований радіально за межі диполя:

```
S_r = E_θ · H_φ = (η₀ · k² · I₀² · dl² / (16π² · r²)) · sin²(θ) · cos²(ω · t')
```

Усереднивши по часу за період коливань `T` (`⟨cos²(ω · t')⟩ = 1/2`), отримуємо середню густину потоку енергії:

```
⟨S_r⟩ = (η₀ · k² · I₀² · dl² / (32π² · r²)) · sin²(θ)
```

Для знаходження повної випромінюваної потужності `P_rad` проінтегруємо `⟨S_r⟩` по замкненій сфері радіуса `r`:

```
P_rad = ∫₀²ᵖⁱ dφ ∫₀ᵖⁱ ⟨S_r⟩ · r² · sin(θ) dθ
= 2π · (η₀ · k² · I₀² · dl² / (32π²)) · ∫₀ᵖⁱ sin³(θ) dθ       [інтегрування по азимуту φ дає 2π]
= 2π · (η₀ · k² · I₀² · dl² / (32π²)) · (4 / 3)             [обчислення інтеграла ∫₀ᵖⁱ sin³(θ)dθ = 4/3]
= (η₀ · k² · I₀² · dl²) / (12π)                             [спрощення коефіцієнтів (2π·4/3) / 32π² = 1/12π]
```

Підставимо значення `η₀ = 120π Ом` та `k = 2π / λ`:

```
P_rad
= (120π · (2π / λ)² · I₀² · dl²) / (12π)                   [підставляємо значення η₀ = 120π та k = 2π/λ]
= 10 · (4π² / λ²) · I₀² · dl²                              [скорочення 120π / 12π = 10]
= 40 · π² · (dl / λ)² · I₀²                                [розкриття квадрата (2π/λ)² = 4π²/λ²]
```

Отриманий вираз є прямолінійним аналогом **формули Лармора** для прискореного заряду:

```
P_rad = (2 / 3) · (q₀² · a₀² / (4π · ε₀ · c³))
```

де `a₀ = ω² · (dl/2)` — амплітуда прискорення заряду.

## 6. Тензор напружень Максвелла та імпульс випромінювання

Поряд із перенесенням енергії електромагнітна хвиля, випромінювана диполем, несе імпульс `g = S / c²`. Густина імпульсу поставляє механічний тиск випромінювання на віддалені тіла.

Для розрахунку сил, що діють у полі диполя, застосовують **тензор напружень Максвелла** `T_ij`:

```
T_ij = ε₀ · E_i · E_j + μ₀ · H_i · H_j − (1/2) · δ_ij · (ε₀ · E² + μ₀ · H²)
```

Інтегрування тензора напружень `T_ij` по закритій поверхні довкола диполя підтверджує, що внаслідок симетрії випромінювання `sin²(θ)` сумарний реактивний імпульс, відданий диполю за період, дорівнює нулю. Однако при наявності зовнішнього відбивача (наприклад, металевого екрана) випромінювання стає асиметричним, що призводить до виникнення реальної механічної сили реактивної віддачі (тиску світла), яка діє на випромінювач.

## 7. Вивід опору випромінювання R_rad

Потужність, яка безповоротно випромінюється диполем у простір, можна подати через діюче значення струму `I_rms = I₀ / √2` та еквівалентний **опір випромінювання** `R_rad`:

```
P_rad = I_rms² · R_rad = (1 / 2) · I₀² · R_rad
```

Прирівняємо два вирази для потужності:

```
(1 / 2) · I₀² · R_rad = 40 · π² · (dl / λ)² · I₀²
```

Звідси отримуємо класичну формулу для опору випромінювання диполя Герца:

```
R_rad = 80 · π² · (dl / λ)²  [Ом]
```

## 8. Принцип дуальності: Елементарний магнітний диполь (рамка зі струмом)

Математичний апарат диполя Герца є дуально симетричним. Замість електричного диполя довжиною `dl` розглянемо плоску мікроскопічну рамку площею `S` зі змінним струмом `I(t) = I₀ · sin(ω · t)`. Такий елемент називається **елементарним магнітним диполем** з магнітним моментом `m(t) = I(t) · S`.

Згідно з принципом дуальності Максвелла, поля магнітного диполя отримуються шляхом заміни:

```
E → η₀ · H
H → −E / η₀
p₀ → m₀ / c
```

Поля магнітного диполя у дальній зоні мають вигляд:

```
H_θ ≈ −(k² · I₀ · S / (4π · r)) · sin(θ) · cos(ω · t')
E_φ ≈ (η₀ · k² · I₀ · S / (4π · r)) · sin(θ) · cos(ω · t')
```

Опір випромінювання елементарного магнітного диполя (малої петлі) дорівнює:

```
R_rad_mag = 320 · π⁴ · (S / λ²)²  [Ом]
```

## 9. Аналіз комплексного вектора Пойнтінга у проміжній зоні

Для довільної точки простору обчислимо комплексний вектор Пойнтінга `S_c = (1/2) · E × H*`, де `H*` — комплексно-спряжена напруженість магнітного поля.

Використовуючи комплексні амплітуди полів у сферичних координатах:

```
E_θ(r, θ) = (j · η₀ · k · I₀ · dl / (4π · r)) · sin(θ) · [ 1 + 1/(j·k·r) − 1/(k²·r²) ] · e^(−j·k·r)
H_φ(r, θ) = (j · k · I₀ · dl / (4π · r)) · sin(θ) · [ 1 + 1/(j·k·r) ] · e^(−j·k·r)
```

Перемноживши `E_θ` на `H_φ*`, отримуємо вираз для радіальної компоненти комплексного вектора Пойнтінга:

```
S_r(r, θ) = (1 / 2) · E_θ · H_φ*
= (η₀ · k² · I₀² · dl² / (32π² · r²)) · sin²(θ) · [ 1 − j / (k³ · r³) ]
```

Розділимо комплексний потік на дійсну й уявну частини:

```
Re(S_r) = (η₀ · k² · I₀² · dl² / (32π² · r²)) · sin²(θ)
Im(S_r) = −(η₀ · k² · I₀² · dl² / (32π² · r² · (k³ · r³))) · sin²(θ) = −(η₀ · I₀² · dl² / (32π² · k · r⁵)) · sin²(θ)
```

## 10. Інтегрування реактивної енергії та добротність за Чу

Обчислимо повний запас електричної реактивної енергії `W_e`, накопиченої у ближній зоні диполя в межах сфери радіуса `a`:

```
W_e = (1 / 4) · ε₀ · ∫_V |E_near|² dV
= (1 / 4) · ε₀ · ∫_a^(λ/2π) r² dr ∫₀²ᵖⁱ dφ ∫₀ᵖⁱ [ |E_r|² + |E_θ|² ] · sin(θ) dθ
```

Використовуючи асимптотику ближнього поля `E_near ∝ p₀ / (4π·ε₀·r³)`:

```
W_e ≈ (p₀² / (48π · ε₀ · a³)) = (I₀² · dl² / (48π · ε₀ · ω² · a³))
```

Добротність антени `Q` за визначенням дорівнює відношенню накопиченої реактивної енергії `W_e` до випроміненої енергії за один радіан періоду `P_rad / ω`:

```
Q = ω · W_e / P_rad = 3 / (k · a)³
```

## 11. Математичний розв'язок хвильового рівняння через функцію Ґріна

Для більш глибокого розуміння походження запізнілих потенціалів розглянемо оператор Даламбера `□ = ∇² − (1/c²) · ∂²/∂t²`:

```
□ A_z(r, t) = −μ₀ · J_z(r, t)
```

Загальний розв'язок дається скалярною функцією Ґріна:

```
G(r, t | r', t') = (1 / (4π · |r − r'|)) · δ(t − t' − |r − r'| / c)
```

Інтегрування показує, що довільний часовий розподіл струму `I(t)` створює потенціал `A_z`, аргументом якого є тільки запізнілий час `t' = t − r/c`.

---

## 12. Спектральний розклад за Фур'є та випромінювання довільного імпульсу

Якщо струм у диполі `I(t)` є негармонічним, його розкладають в інтеграл Фур'є:

```
I(t) = (1 / 2π) · ∫_−∞^+∞ I(ω) · e^(j · ω · t) dω
```

Спектральна густина випроміненої енергії дорівнює:

```
dE / dω = (μ₀ · ω⁴ · |p(ω)|²) / (6π · c) = (η₀ · k² · |I(ω)|² · dl²) / (6π)
```

## 13. Вивід ефективної апертури A_eff та теорема взаємності

Розглянемо диполь Герца у режимі приймальної антени, на яку падає плоска електромагнітна хвиля з напруженістю `E_inc`.

Згідно з **теоремою взаємності Лоренца**, характеристики антени в режимі передавання та в режимі приймання є ідентичними. Ефективна апертура (поглинальна площа) `A_eff` визначається відношенням максимальної потужності `P_rec`, відданої у погоджене навантаження `R_load = R_rad`, до густини потоку падаючої енергії `S_inc`:

```
P_rec = (1 / 8) · |E_inc · dl|² / R_rad
```

Підставляючи `R_rad = 80 · π² · (dl / λ)²` та `S_inc = |E_inc|² / (2 · η₀)`:

```
A_eff = P_rec / S_inc = [ (1/8) · |E_inc|² · dl² / (80 · π² · dl² / λ²) ] / [ |E_inc|² / (240 · π) ]
= (3 / (8π)) · λ² ≈ 0.119 · λ²
```

Цей фундаментальний вивод доводить: **ефективна апертура точкового диполя Герца не залежить від його геометричної довжини `dl`**, а визначається виключно квадратом довжини хвилі `λ²`! Навіть мікроскопічний диполь здатний збирати енергію падаючої хвилі з площі розміром приблизно `0.119 · λ²`.

## 14. Модифікація випромінювання у мікрорезонаторах: Ефект Парселла

У квантовій нанофотоніці та оптиці диполь Герца моделює випромінювання поодинокого квантового випромінювача (квантової точки або молекули), розміщеного у мікроструктурованому середовищі.

Коли диполь вміщено всередину мікрорезонатора з об'ємом моди `V_m` та добротністю `Q_cav`, локальна густина оптичних станів (LDOS) змінюється. Це призводить до зміни опору випромінювання та прискорення спонтанного випромінювання у **`F_P` разів** (фактор Парселла, *Purcell factor*):

```
F_P = R_rad_cav / R_rad_vacuum = (3 / (4π²)) · (λ / n)³ · (Q_cav / V_m)
```

Якщо резонатор налаштовано в резонанс із частотою диполя, випромінювальний перехід прискорюється в сотні разів, а якщо частота диполя потрапляє у заборонену фотонну зону, випромінювання диполя Герца стає повністю пригніченим.
