# 🧮 Рівняння Лондонів: математичний вивід глибини проникнення та квантування потоку

Математичний опис електродинаміки надпровідників вимагає виходу за межі стандартних рівнянь Максвелла для звичайних суцільних середовищ. У звичайному провіднику зі скінченною електричною провідністю `σ` густина струму `j` визначається локальною напруженістю електричного поля `E` за допомогою класичного закону Ома у диференціальній формі `j = σ · E`. Проте спроба формально покласти `σ → ∞` у рівняннях електродинаміки призводить до математичного та фізичного парадоксу: будь-яке мікроскопічне електричне поле викликало б нескінченне прискорення носіїв заряду, а зовнішнє магнітне поле заморожувалося б у довільному початковому стані, залежному від історії охолодження зразка.

Для подолання цієї суперечності та створення суворої математичної теорії брати Фріц та Хайнц Лондон у 1935 році запропонували дві фундаментальні диференціальні рівності, які описують макроскопічну квантову динаміку надпровідних носіїв заряду.

---

### Перше рівняння Лондонів: бездисипативне прискорення та відсутність опору

Уявімо надпровідник як дворідинну систему, у якій частина електронів перебуває у нормальному стані з густиною `n_n`, а частина — у надпровідному стані з густиною `n_s`. Надпровідні носії (куперівські пари з ефективною масою `m*` та зарядом `q = 2e`) рухаються під дією електричного поля `E` без жодного тертя чи розсіювання на кристалічній ґратці.

На відміну від звичайного металу, де дрейфова швидкість встановлюється балансом між електричною силою та дією сили в'язкого тертя, у надпровіднику діє лише електрична сила. Напишемо другий закон Ньютона для одного надпровідного носія зі швидкістю `v_s`:

```
m* · (d v_s / dt) = q · E          [другий закон Ньютона для куперівської пари]
```

Помножимо обидві частини рівняння на об'ємну концентрацію надпровідних носіїв `n_s` та на їхній заряд `q`. Оскільки густина макроскопічного надпровідного струму за означенням дорівнює добутку `j_s = n_s · q · v_s`, отримуємо перше рівняння Лондонів у часові формі:

```
d j_s / dt = (n_s · q² / m*) · E   [перше рівняння Лондонів]
```

Для куперівських пар `q = 2e`, а ефективна маса `m* = 2 m_e`. Для зручності математичних перетворень введемо феноменологічний лондонівський коефіцієнт індуктивності середовища `Λ = m* / (n_s · q²)`. Завдяки цьому перше рівняння Лондонів набуває стислої векторної форми:

```
E = Λ · (d j_s / dt)              [перше рівняння Лондонів через коефіцієнт Λ]
```

Це рівняння виявляє фундаментальну відмінність надпровідника від звичайного металу:
1. У звичайному провіднику електричне поле пропорційне самóй густині струму (`E = j / σ`);
2. У надпровіднику електричне поле пропорційне **похідній струму по часу** (`E = Λ · dj_s/dt`).

Якщо стаціонарне електричне поле всередині надпровідника дорівнює нулю (`E = 0`), то густина надпровідного струму не зникає, а залишається строго сталою у часі (`d j_s / dt = 0`). Це математично пояснює феномен незагасаючих незатухаючих струмів.

### Друге рівняння Лондонів та математичний вивід ефекту Мейснера

Перше рівняння Лондонів пояснює відсутність опору, але воно все ще припускає можливість заморожування довільного постійного магнітного поля всередині зразка (бо при `E = 0` полем може бути будь-яке стале `B`). Щоб описувати експериментально відкритий ефект Мейснера — Оксенфельда, брати Лондон об'єднали перше рівняння із диференціальним законом електромагнітної індукції Фарадея `rot E = - d B / dt`:

```
rot E = - d B / dt                                  [закон индукції Фарадея]
rot (Λ · d j_s / dt) = - d B / dt                   [підставили перше рівняння Лондонів]
d / dt (Λ · rot j_s + B) = 0                        [винесли часову похідну]
```

Інтегрування цього виразу по часу дає вираз `Λ · rot j_s + B = C(r)`, де `C(r)` — стала інтегрування, що залежить лише від просторових координат. Для опису ідеального провідника ця стала визначалася б початковим полем до охолодження.

Брати Лондон зробили вирішальний фізичний постулат: для надпровідного стану ця стала дорівнює **строго нулю** (`C(r) ≡ 0`). Це припущення становить зміст другого рівняння Лондонів:

```
rot j_s = - (1 / Λ) · B                             [друге рівняння Лондонів]
```

або у розгорнутому вигляді через мікроскопічні параметри носіїв:

```
rot j_s = - (n_s · q² / m*) · B                     [друге рівняння Лондонів розгорнуто]
```

#### Вивід рівняння екранування Гельмгольца
Тепер об'єднаємо друге рівняння Лондонів із четвертим рівнянням Максвелла для стаціонарного випадку `rot B = μ_0 · j_s` (квазістаціонарне наближення, у якому струмом зміщення `ε_0 · dE/dt` нехтують):

```
rot (rot B) = rot (μ_0 · j_s)                        [взяли ротор від обох частин]
rot (rot B) = μ_0 · rot j_s                         [винесли сталу μ_0]
rot (rot B) = - (μ_0 / Λ) · B                        [підставили друге рівняння Лондонів]
```

Скористаємося відомою векторною тотожністю для подвійного ротора довільного тривимірного векторного поля: `rot (rot B) = grad (div B) - ∇² B`.

Оскільки за першим рівнянням Максвелла магнітні монополі відсутні в природі (`div B = 0`), градієнт дивергенції перетворюється на нуль `grad (div B) ≡ 0`. У результаті отримуємо фундаментальне диференціальне рівняння для розподілу магнітного поля всередині надпровідного середовища:

```
∇² B = (μ_0 / Λ) · B                                [диференціальне рівняння поля]
```

Введемо характерну просторову константу `λ_L = √(Λ / μ_0) = √(m* / (μ_0 · n_s · q²))`. Тоді диференціальне рівняння набуває стандартного вигляду векторного рівняння Гельмгольца:

```
∇² B = (1 / λ_L²) · B                               [рівняння Лондонів для поля B]
```

де параметр `λ_L` називається **лондонівською глибиною проникнення** (*London penetration depth*).

### Точний розв'язок для плоского межі та аналіз проникнення поля

Розглянемо плоску межу масивного надпровідника, розташовану у площині `y-z`. Сам надпровідник займає півпростір `x ≥ 0`, а зовнішнє однорідне магнітне поле `B_0` спрямоване вздовж осі `z` у порожньому півпросторі `x < 0`.

Оскільки геометрія системи є однорідною вздовж осей `y` та `z`, вектор індукції залежить лише від однієї координати `x` і має лише `z`-складову (`B = (0, 0, B_z(x))`). Оператор Лапласа `∇²` спрощується до другої похідної по скалярній змінній `x`:

```
d² B_z / dx² = (1 / λ_L²) · B_z                    [одномірне диференціальне рівняння]
```

Загальний математичний розв'язок цього лінійного однорідного диференціального рівняння другого порядку із сталими коефіцієнтами шукаємо у вигляді суми двох експонент:

```
B_z(x) = C_1 · exp(-x / λ_L) + C_2 · exp(x / λ_L)   [загальний розв'язок]
```

Сформулюємо фізичні граничні умови:
1. При `x → ∞` (у глибині масивного надпровідника) магнітна індукція мусить залишатися скінченною величиною й прямувати до нуля (`B_z → 0`). Звідси коефіцієнт біля зростаючої експоненти мусить дорівнювати нулю: `C_2 = 0`.
2. На поверхні зразка при `x = 0` магнітна індукція дорівнює зовнішньому полю `B_0`. Це дає `C_1 = B_0`.

Остаточний розподіл магнітного поля всередині надпровідника набуває вигляду закону експоненціального згасання:

```
B_z(x) = B_0 · exp(-x / λ_L)                        [закон згасання поля B(x)]
```

#### Розподіл поверхневих экрануючих струмів
Знайдемо розподіл густини екрануючих струмів, що циркулюють у приповерхневому шарі. Скористаємося рівнянням Максвелла `j_s = (1 / μ_0) · rot B`. Оскільки вектор `B` має лише складову `B_z(x)`, ротор дорівнює `rot B = (0, -dB_z/dx, 0)`.

Продиференціюємо знайдений розв'язок поля по координаті `x`:

```
d B_z / dx = - (B_0 / λ_L) · exp(-x / λ_L)         [похідна поля по координаті x]
```

Підставивши похідну в вираз для струму, отримуємо розподіл густини надпровідного струму, що тече вздовж осі `y`:

```
j_sy(x) = (B_0 / (μ_0 · λ_L)) · exp(-x / λ_L)       [розподіл экрануючого струму j_s(x)]
```

Математичний аналіз отриманих розв'язків доводить:
1. Магнітне поле не переривається раптово на межі розділу фаз, а проникне у надпровідник на характерну глибину `λ_L`;
2. У глибині масивного зразка (`x ≫ λ_L`) поле та екрануючі струми згасають строго до нуля, що й доводить ефект Мейснера;
3. Повний поверхневий струм, проінтегрований від поверхні `x = 0` до нескінченності, дорівнює `I_surface = ∬ j_sy dx = B_0 / μ_0`, що повністю компенсує та гасить зовнішнє магнітне поле всередині зразка.

### Калібрувальна інваріантність та лондонівське калібрування (London Gauge)

Векторний потенціал магнітного поля `A` визначений з точністю до градієнта довільної скалярної функції `χ(r)` (калібрувальне перетворення `A' = A + ∇χ`). Щоб перше та друге рівняння Лондонів набули повністю калібрувально-інваріантної форми, векторний потенціал фіксують за допомогою **лондонівського калібрування** (*London gauge*):

```
div A = 0                              [лондонівська умово кулонівського типу]
A_n = 0 на поверхні                    [нормальна складова потенціалу на поверхні]
```

У лондонівському калібруванні обоє рівнянь Лондонів об'єднуються в єдине алгебраїчне співвідношення між векторним потенціалом та густиною надпровідного струму:

```
j_s = - (1 / Λ) · A = - (n_s · q² / m*) · A  [закон Лондона в лондонівському калібруванні]
```

Взявши ротор від обох частин цієї рівності (`rot j_s = - (1/Λ) rot A = - (1/Λ) B`), ми негайно отримуємо друге рівняння Лондонів, а взявши похідну по часу (`dj_s/dt = - (1/Λ) dA/dt = (1/Λ) E`, оскільки `E = -dA/dt`) — перше рівняння Лондонів.

### Рівняння Гінзбурга — Ландау та характеристичні довжини

Феноменологічна теорія Гінзбурга — Ландау (1950 рік) узагальнила рівняння Лондонів, описавши надпровідний стан за допомогою комплексного параметра порядку `Ψ(r) = |Ψ(r)| · exp(i·φ(r))`. Квадрат модуля цього параметра пропорційний об'ємній густині надпровідних пар: `|Ψ(r)|² = n_s(r) / 2`.

Вільна енергія Гіббса надпровідника у зовнішньому полі раскладається в ряд по малим значенням параметра порядку поблизу `T_c`:

```
F_s = F_n + α · |Ψ|² + (β / 2) · |Ψ|⁴ + (1 / (2m*)) · |(-i·ħ·∇ - q·A) Ψ|² + B² / (2μ_0)
```

де `α = α_0 · (T - T_c)`, `β > 0`, а `A` — векторний потенціал магнітного поля (`B = rot A`).

Мінімізація функціонала вільної енергії шляхом варіювання по `Ψ*` та по `A` дає два фундаментальні рівняння Гінзбурга — Ландау.

#### Перше рівняння Гінзбурга — Ландау (для параметра порядку)
```
(1 / (2m*)) · (-i·ħ·∇ - q·A)² Ψ + α · Ψ + β · |Ψ|² Ψ = 0   [перше рівняння Г-Л]
```

Це рівняння аналогічне нелінійному стаціонарному рівнянню Шредінгера. За відсутності магнітного поля (`A = 0`) однорідний розв'язок у глибині надпровідника дорівнює `|Ψ_0|² = -α / β = (α_0 / β) · (T_c - T)`.

Якщо у певній точці (наприклад, на межі із нормальним металом) параметр порядку відхиляється від рівноважного значення `Ψ_0`, відстань, на якій він відновлюється до `Ψ_0`, визначається **довжиною когерентності Гінзбурга — Ландау** `ξ(T)`:

```
ξ(T) = ℏ / √(2 m* · |α(T)|) = ξ(0) / √(1 - T / T_c)       [довжина когерентності Г-Л]
```

#### Друге рівняння Гінзбурга — Ландау (для надпровідного струму)
Варіювання функціонала вільної енергії по векторному потенціалу `A` дає квантовий вираз для густини надпровідного струму:

```
j_s = (q·ħ / (2m*·i)) · (Ψ* · ∇Ψ - Ψ · ∇Ψ*) - (q² / m*) · |Ψ|² · A  [друге рівняння Г-Л]
```

Підставивши модуль і фазу `Ψ(r) = |Ψ(r)| · exp(i·φ(r))`, вираз для струму набуває вигляду:

```
j_s = (q / m*) · |Ψ|² · (ħ · ∇φ - q · A)                   [струм через градієнт фази]
```

### Математичний вивід верхнього критичного поля `B_c2`

За допомогою першого рівняння Гінзбурга — Ландау виведемо точний вираз для верхнього критичного поля `B_c2`, при якому надпровідність остаточно зникає.

Поблизу `B_c2` параметр порядку `Ψ` прямує до нуля (`|Ψ| → 0`), тому нелінійним членом `β · |Ψ|² Ψ` у першому рівнянні Г-Л можна знехтувати. Лінеаризоване рівняння набуває вигляду:

```
(1 / (2m*)) · (-i·ħ·∇ - q·A)² Ψ = - α · Ψ                  [лінеаризоване рівняння Г-Л]
```

Це рівняння математично збігається з рівнянням Шредінгера для квантового гармонічного осцилятора (частинки заряду `q` в однорідному магнітному полі `B`). Власними значеннями енергії цієї системи є рівні Ландау:

```
E_n = (n + 1/2) · ħ · ω_c = (n + 1/2) · (ħ · q · B / m*)  [рівні Ландау]
```

Найнижче власне значення (при `n = 0`) дорівнює `E_0 = (1/2) · (ħ · q · B / m*)`.

Прирівнюючи найнижче власне значення до правого боку лінеаризованого рівняння `-α = ħ² / (2 m* · ξ²)`, отримуємо:

```
(1/2) · (ħ · q · B_c2 / m*) = ħ² / (2 m* · ξ²)             [рівність енергій Ландау]
```

Скорочуючи масу `m*` та сталу `ħ`, отримуємо точний вираз для верхнього критичного поля `B_c2`:

```
B_c2 = ħ / (q · ξ²) = (h / (2π · 2e)) / ξ² = Ф_0 / (2π · ξ²) [формула для B_c2]
```

Ця формула має глибокий фізичний зміст: верхнє критичне поле `B_c2` досягається тоді, коли нормальні серцевини вихорів Абрикосова радіуса `ξ` перекриваються одна з одною, заповнюючи весь об'єм зразка.

### Розрахунок енергії вихору Абрикосова та поля `B_c1`

Магнітний вихор Абрикосова містить один квант потоку `Ф_0`. Просторовий розподіл індукції поля одного ізольованого вихору у надпровіднику II роду (`λ_L ≫ ξ`) описується модифікованим рівнянням Лондонів з дельта-функцією у центрі:

```
B(r) - λ_L² · ∇² B(r) = Ф_0 · δ(r)                        [рівняння ізольованого вихору]
```

Розв'язком цього рівняння у циліндричних координатах є функція Макдональда (модифікована функція Бесселя другого роду нулевого порядку): `B(r) = (Ф_0 / (2π λ_L²)) · K_0(r / λ_L)`.
- На відстані `r ≫ λ_L` поле згасає за експонентою: `B(r) ≈ (Ф_0 / (2π λ_L²)) · √(π λ_L / 2r) · exp(-r / λ_L)`;
- На відстанях `ξ ≪ r ≪ λ_L` поле спадає за логарифмічним законом: `B(r) ≈ (Ф_0 / (2π λ_L²)) · [ln(λ_L / r) + 0.12]`.

Повна енергія вихору на одиницю довжини `ε_v` складається з магнітної енергії поля та кінетичної енергії обертальних надпровідних струмів:

```
ε_v = (Ф_0 / (4π · μ_0 · λ_L²)) · ln(λ_L / ξ)              [енергія вихору Абрикосова]
```

Умова входу першого вихору в надпровідник визначає значення нижнього критичного поля `B_c1`:

```
B_c1 = (Ф_0 / (4π · λ_L²)) · [ln(λ_L / ξ) + 0.5]           [формула для поля B_c1]
```

Співвідношення двох критичних полів дорівнює `B_c2 / B_c1 ≈ 2 κ² / ln(κ)`. Для матеріалів із великим параметром `κ ≈ 100` (наприклад, YBCO), верхнє поле `B_c2` перевищує нижнє поле `B_c1` у десятки тисяч разів.

### Математичний вивід розподілу транспортного струму у циліндричному провіднику

Розглянемо масивний циліндричний надпровідний дріт радіуса `a`, по якому тече повний транспортний струм `I`. У звичайному провіднику на постійному струмі густина струму `j` розподілена рівномірно по всьому поперечному перерізу `A = π a²`. У надпровіднику ефект Мейснера та рівняння Лондонів вимагають, щоб магнітне поле всередині об'єму дорівнювало нулю.

Розв'яжемо векторне рівняння Лондонів `∇² B = (1 / λ_L²) · B` у циліндричній системі координат `(r, θ, z)`. Власне магнітне поле струму має лише азимутальну складову `B = (0, B_θ(r), 0)`, а струм спрямований вздовж осі циліндра `j = (0, 0, j_z(r))`.

Рівняння Гельмгольца для азимутальної складової магнітного поля `B_θ(r)` набуває вигляду модифікованого диференціального рівняння Бесселя першого порядку:

```
d² B_θ / dr² + (1 / r) · d B_θ / dr - (1 / r² + 1 / λ_L²) · B_θ = 0 [рівняння Бесселя]
```

Загальний розв'язок цього рівняння виражається через модифіковану функцію Бесселя першого роду першого порядку `I_1(x)`:

```
B_θ(r) = B_surface · (I_1(r / λ_L) / I_1(a / λ_L)) [польовий розв'язок у циліндрі]
```

де `B_surface = μ_0 · I / (2π a)` — магнітна індукція на поверхні дроту за законом Повної Напруги.

Використовуючи рівняння Максвелла `j_z(r) = (1 / μ_0) · (1/r) · d(r B_θ)/dr` та тотожність для похідної функцій Бесселя `d(x I_1(x))/dx = x I_0(x)`, знаходимо просторовий розподіл густини транспортного струму по радіусу циліндра:

```
j_z(r) = (I / (2π a λ_L)) · (I_0(r / λ_L) / I_1(a / λ_L)) [розподіл густини струму j_z(r)]
```

Аналіз отриманого розв'язку для масивного дроту (`a ≫ λ_L`) із використанням асимптотики функцій Бесселя `I_n(x) ≈ exp(x) / √(2π x)` дає:

```
j_z(r) ≈ (I / (2π a λ_L)) · exp(-(a - r) / λ_L)    [асимптотика струму біля поверхні]
```

Цей результат доводить фундаментальну властивість надпровідних провідників:
1. Транспортний струм **не тече в об'ємі** провідника, а повністю зосереджений у тонкому приповерхневому шарі товщиною `λ_L`;
2. У центрі масивного провідника (`r = 0`) густина струму експоненціально прямує до нуля `j_z(0) ≈ 0`;
3. Ефективна площа перерізу, по якій тече струм, дорівнює не всій площі `π a²`, а лише вузькому кільцю `A_eff ≈ 2π a λ_L`.

Саме цим пояснюється необхідність виготовлення надпровідних кабелів у вигляді тонких багатожильних дротів із діаметром окремих жил порядку `λ_L` або `ξ`, щоб максимально ефективно використовувати весь об'єм надпровідного матеріалу.

### Топологічний вивід квантування магнітного потоку

Розглянемо надпровідне кільце (двозв'язну область) із наскрізним отвором, через який проходить магнітне поле `B`.

Виразимо градієнт квантової фази `∇φ` із другого рівняння Гінзбурга — Ландау:

```
∇φ = (q / ħ) · A + (m* / (q · ħ · |Ψ|²)) · j_s              [градієнт фази]
```

Проінтегруємо цей вираз по замкненому контуру `C`, який проходить глибоко всередині об'єму надпровідного кільця на відстані `x ≫ λ_L` від усіх поверхонь. У цій області екрануючі поверхневі струми повністю згасли (`j_s ≡ 0`). Контурний інтеграл спрощується до вигляду:

```
∮_C ∇φ · dl = (q / ħ) · ∮_C A · dl                         [інтегрування по контуру]
```

Розглянемо ліву та праву частини цієї рівності:
1. За теоремою Стокса циркуляція векторного потенціалу `A` по замкненому контуру `C` дорівнює повному магнітному потоку `Ф`, що пронизує поверхню `S`, обмежену контуром:
   ```
   ∮_C A · dl = ∬_S (rot A) · dS = ∬_S B · dS = Ф          [теорема Стокса]
   ```
2. З іншого боку, щоб макроскопічна хвильова функція `Ψ(r) = |Ψ(r)| · exp(i·φ(r))` була однозначною скалярною функцією в кожній точці кільця, набіг фази `Δφ` при повному обході замкненого контуру `C` мусить бути кратим `2π`:
   ```
   ∮_C ∇φ · dl = 2π · n                                    [умова однозначності фази, n ∈ ℤ]
   ```

Прирівнюючи ліву та праву частини, отримуємо фундаментальне співвідношення квантування магнітного потоку:

```
(q / ħ) · Ф = 2π · n                                        [рівність набігу фази]
Ф = n · (2π · ħ / q) = n · (h / q)                          [дискретні рівні потоку]
```

Підставивши заряд куперівської пари `q = 2e`, отримуємо значення **кванту магнітного потоку** `Ф_0`:

```
Ф_0 = h / (2e) ≈ 2.067833848 × 10⁻¹⁵ Втб                   [квант магнітного потоку]
```

Якщо ж контур `C` проходить по ділянці, де густина струму `j_s` не дорівнює нулю, квантується не сам магнітний потік `Ф`, а фундаментальна величина — **флоксоїд** (*fluxoid*) Лондона:

```
Ф' = ∬_S B · dS + μ_0 · λ_L² · ∮_C j_s · dl = n · Ф_0       [квантування флоксоїда]
```

Це співвідношення є основою роботи надпровідних квантових інтерферометрів (СКВІД) та цифрової швидкодіючої логіки на одиничних квантах потоку (RSFQ-логіки).
