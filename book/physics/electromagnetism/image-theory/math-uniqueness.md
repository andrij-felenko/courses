# 🧮 Математичне обґрунтування: теорема єдиності та сферична інверсія

Метод дзеркальних зображень спирається на дві фундаментальні математичні підвалини теоретичної фізики: теорему єдиності розв'язку рівняння Пуассона з граничними умовами Діріхле та геометричне перетворення сферичної інверсії. Нижче наведено детальні суворі виведення обох математичних положень, розширення для плоских двовимірних систем та повний інтегральний розрахунок індукованого поверхневого заряду.

### 1. Строге доведення теореми єдиності (гранична задача Діріхле)

Розглянемо довільну замкнену область простору `V`, обмежену гладкою поверхнею `S`. Усередині цієї області задано відомий розподіл вільних електричних зарядів із об'ємною густиною `ρ(x, y, z)`. На самій граничній поверхні `S` строго зафіксовано значення електричного потенціалу `V|S = f(S)` (це умова, відома як перша крайова задача або гранична умова Діріхле).

Припустимо від супротивного, що існують два різних розв'язки `V₁(x,y,z)` та `V₂(x,y,z)`, які задовольняють диференціальне рівняння Пуассона в частинних похідних усередині області `V` та однакові граничні умови на поверхні `S`:

```
∇²V₁ = −ρ / ε₀      [усередині об'єму V]
∇²V₂ = −ρ / ε₀      [усередині об'єму V]
V₁|S = f(S)          [на граничній поверхні S]
V₂|S = f(S)          [на граничній поверхні S]
```

Для аналізу різниці цих розв'язків введемо допоміжну скалярну функцію `U`, яка дорівнює різниці двох гіпотетичних потенціалів:

```
U(x, y, z) = V₁(x, y, z) − V₂(x, y, z)
```

Знайдемо рівняння та відповідні граничні умови, яким задовольняє функція `U`. Оскільки оператор Лапласа `∇²` є лінійним диференціальним оператором, застосуємо його до функції `U`:

```
∇²U = ∇²V₁ − ∇²V₂ = (−ρ/ε₀) − (−ρ/ε₀) = 0     [рівняння Лапласа всередині V]
U|S = V₁|S − V₂|S = f(S) − f(S) = 0            [однорідна гранична умова на S]
```

Це означає, що функція різниці `U` задовольняє однорідне рівняння Лапласа `∇²U = 0` всередині об'єму `V` і дорівнює нулю на всій замкненій границі `S`.

Скористаємося першою векторною тотожністю Гріна, яка пов'язує об'ємні інтеграли від оператора Лапласа з поверхневими інтегралами від нормальних похідних. Підставимо в тотожність Гріна функції `ψ = U` та `φ = U`:

```
∫_V (U·∇²U + |∇U|²) dV = ∮_S (U · ∂U/∂n) dS
```

Підставимо в отримати формулу відомі властивості функції `U`: `∇²U = 0` всередині `V` та `U = 0` на граничній поверхні `S`:

```
∫_V (U · 0 + |∇U|²) dV = ∮_S (0 · ∂U/∂n) dS
= ∫_V |∇U|² dV = 0
```

Розглянемо підінтегральний вираз у лівій частині отриманого співвідношення. Квадрат модуля градієнта є строго невід'ємною величиною у кожній точці простору:

```
|∇U|² = (∂U/∂x)² + (∂U/∂y)² + (∂U/∂z)² ≥ 0
```

Якщо інтеграл від невід'ємної неперервної функції по об'єму дорівнює нулю, то сама підінтегральна функція мусить дорівнювати нулю у кожній внутрішній точці даного об'єму `V`:

```
|∇U|² = 0  ⇒  ∇U = 0  ⇒  U(x, y, z) = const
```

Оскільки на границі `S` функція `U` за умовами дорівнює нулю, ця стала може бути тільки нулем:

```
U(x, y, z) = 0  ⇒  V₁(x, y, z) = V₂(x, y, z)     [розв'язок є єдиним]
```

**Фундаментальний фізичний висновок:** Гранична задача Діріхле для рівняння Пуассона має **строго єдиний розв'язок**. Якщо за допомогою штучно підібраної конфігурації дзеркальних зарядів вдається задовольнити рівняння Пуассона в області розрахунку та забезпечити потрібне значення потенціалу на граничній поверхні провідника, то отримане розраховане поле є **абсолютно істинним і єдино можливим**.

### 2. Геометрія сферичної інверсії та доказ пропорційності відстаней

Розглянемо заземлену провідну сферу радіуса `R` з центром у початку координат `O(0, 0, 0)`. Ззовні сфери на відстані `d` від центра (`OA = d > R`) знаходиться точковий заряд `q` у точці `A`.

Помістимо дзеркальний заряд `q'` у точку `A'` на тій самій лінії `OA` усередині сфери на відстані `d'` від центра (`OA' = d' < R`).

Розглянемо довільну точку `P` на поверхні сфери (`OP = R`). Позначимо відстані від точки `P` до зарядів:
* `r₁ = AP` — відстань від точці `P` на сфері до реального зовнішнього заряду `q`;
* `r₂ = A'P` — відстань від точці `P` на сфері до внутрішнього дзеркального заряду `q'`.

Електричний потенціал у точці `P` від суперпозиції двох зарядів дорівнює:

```
V(P) = (1 / 4·π·ε₀) · [ (q / r₁) + (q' / r₂) ]
```

Для того щоб потенціал `V(P)` дорівнював нулю у будь-якій довільній точці на поверхні сфери, необхідно виконувати умова пропорційності відстаней:

```
(q / r₁) + (q' / r₂) = 0  ⇒  (r₁ / r₂) = −q / q' = const
```

Розглянемо два трикутники: зовнішній трикутник `△OPA` та внутрішній трикутник `△OA'P`. Зверніть увагу, що у них є спільний кут при вершині `O` (позначимо цей кут як `θ`).

Застосуємо класичну теорему косинусів для розрахунку квадратів сторін `r₁` та `r₂` в обох трикутниках:

```
r₁² = R² + d² − 2·R·d·cos(θ)       [у трикутнику △OPA]
r₂² = R² + d'² − 2·R·d'·cos(θ)     [у трикутнику △OA'P]
```

Тепер виконаємо алгебраїчне перетворення виразу для `r₂²`, підставивши геометричне співвідношення сферичної інверсії `d' = R² / d`:

```
r₂² = R² + (R² / d)² − 2·R·(R² / d)·cos(θ)    [підстановка значення d']
= R² + (R⁴ / d²) − 2·(R³ / d)·cos(θ)          [розкриття степенів]
= (R² / d²) · [ d² + R² − 2·R·d·cos(θ) ]      [винесення множника (R²/d²)]
= (R² / d²) · r₁²                             [заміна на вираз для r₁²]
```

Здійснюючи добування квадратного кореня з обох частин рівності, отримуємо ключове співвідношення:

```
r₂ = (R / d) · r₁  ⇒  (r₁ / r₂) = d / R = const
```

Це виключне співвідношення показує, що для абсолютно **всіх точок `P` на поверхні сфери** відношення відстаней `r₁ / r₂` дорівнює одній і тій самій сталій величині `d / R`.

Звідси негайно знаходимо вираз для величини дзеркального заряду `q'`:

```
−q / q' = d / R  ⇒  q' = −q · (R / d)
```

Математичний доказ повністю завершено: дзеркальний заряд `q' = -q·(R/d)`, розташований у точці інверсії `d' = R²/d`, забезпечує строго нульовий потенціал `V = 0` по всій поверхні заземленої провідної сфери.

### 3. Двовимірні дзеркальні зображення для лінійних зарядів та циліндрів

У багатьох практичних задачах електротехніки (розрахунок двопровідних ліній передачі, коаксіальних кабелів та проводів ЛЕП) джерела полів можна вважати нескінченно довгими паралельними лінійними зарядами з погонною густиною `τ` [Кл/м].

Для двовимірного випадку логарифмічний потенціал лінійного заряду `τ` на відстані `r` має вигляд:

```
V(r) = −[τ / (2·π·ε₀)] · ln(r) + C
```

Якщо прямолінійний провідник із зарядом `+τ` знаходиться на відстані `d` від нескінченної заземленої провідної площини, дзеркальним зображенням є паралельний ниткоподібний заряд `-τ`, розташований симетрично за площиною на відстані `-d`.

Для заземленого провідного циліндра радіуса `R` та паралельної зарядженої нитки `+τ` на відстані `d` від осі циліндра, дзеркальна нитка `-τ` розташовується всередині циліндра на інверсійній відстані `d' = R² / d`. На відміну від тривимірної сфери, де величина дзеркального заряду зменшується (`q' = -q·R/d`), у двовимірній логарифмічній геометрії погонний заряд зображення **дорівнює за модулем реальному заряду**: `τ' = -τ`. Це випливає з логарифмічної природи потенціалу в 2D-просторі.

### 4. Розрахунок густини індукованого заряду та інтеграл по сфері

Обчислимо нормальну компоненту електричного поля `E_r` на поверхні заземленої сфери радіуса `R`, щоб знайти густину поверхневого заряду `σ(θ)`.

Потенціал у довільній зовнішній точці з сферичними координатами `(r, θ)` дорівнює:

```
V(r, θ) = (q / 4·π·ε₀) · [ 1/√(r² + d² − 2·r·d·cos θ) − (R/d) / √(r² + d'² − 2·r·d'·cos θ) ]
```

Знайдемо радіальну похідну потенціалу `∂V / ∂r` при `r = R`:

```
(∂V / ∂r)|_(r=R) = −(q / 4·π·ε₀) · [ (R − d·cos θ) / r₁³ − (R/d)·(R − d'·cos θ) / r₂³ ]
```

Підставимо співвідношення `r₂ = (R/d)·r₁` та `d' = R²/d`:

```
(∂V / ∂r)|_(r=R) = −(q / 4·π·ε₀·r₁³) · [ (R − d·cos θ) − (d²/R²)·(R − (R²/d)·cos θ) ]
                 = −(q / 4·π·ε₀·r₁³) · [ R − d·cos θ − (d²/R) + d·cos θ ]
                 = −(q / 4·π·ε₀·r₁³) · [ R − (d²/R) ]
                 = (q / 4·π·ε₀·r₁³) · [ (d² − R²) / R ]
```

Отже, густина індукованого поверхневого заряду `σ(θ)` на сфері дорівнює:

```
σ(θ) = −ε₀ · (∂V / ∂r)|_(r=R)
     = −[q · (d² − R²)] / [4·π · R · (R² + d² − 2·R·d·cos θ)^(3/2)]
```

Проінтегруємо густину `σ(θ)` по всій поверхні сфери, де елемент площі дорівнює `dS = 2·π·R²·sin(θ) dθ`:

```
Q_ind = ∫₀^π σ(θ) · 2·π·R² · sin(θ) dθ
      = −[q·R·(d² − R²) / 2] · ∫₀^π [sin(θ) / (R² + d² − 2·R·d·cos θ)^(3/2)] dθ
```

Зробимо заміну змінної `u = R² + d² − 2·R·d·cos(θ)`, тоді `du = 2·R·d·sin(θ) dθ`:

```
∫₀^π [sin(θ) / u^(3/2)] dθ = (1 / 2·R·d) · ∫_(d−R)²^(d+R)² u^(−3/2) du
                           = (1 / 2·R·d) · [ −2 / √u ]|_(d−R)²^(d+R)²
                           = (1 / R·d) · [ 1/(d − R) − 1/(d + R) ]
                           = (1 / R·d) · [ 2·R / (d² − R²) ] = 2 / [d · (d² − R²)]
```

Підставимо первісну у вираз для `Q_ind`:

```
Q_ind = −[q·R·(d² − R²) / 2] · [ 2 / (d · (d² − R²)) ]
      = −q · (R / d) = q'
```

Інтегрування строго підтверджує: **сумарний індукований заряд на заземленій сфері точно дорівнює величині дзеркального заряду `q'`**.
