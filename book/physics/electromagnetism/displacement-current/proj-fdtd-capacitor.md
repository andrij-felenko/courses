# ⚙️ Чисельне моделювання поля конденсатора методом FDTD (Yee Grid)

Чисельне моделювання часової динаміки електромагнітних полів на основі диференціальних рівнянь Максвелла є основним інструментом сучасного інженерного проектування високочастотних пристроїв, систем бездротового зв'язку, високошвидкісних друкованих плат та мікрохвильових компонентів. Серед різноманітних чисельних методів обчислювальної електродинаміки найширшого практичного застосування набув **метод скінченних різниць у часовій області** (Finite-Difference Time-Domain, FDTD), запропонований американським ученим Каней Єе (Kane Yee) у 1966 році.

Метод FDTD розв'язує диференціальні рівняння Максвелла шляхом прямої дискретизації часових похідних струму зміщення та просторових роторів полів на просторово-часовій сітці Єе зі зсунутими вузлами. Обчислювальний процес спирається на суворе дотримання критерію чисельної стійкості Куранта-Фрідріхса-Леві (CFL), а практична реалізація симулятора мовами Python, C++ та C дозволяє безпосередньо простежити поширення електромагнітної хвилі й передачу енергії струмом зміщення у проміжку плоского конденсатора.

## 1. Схема сітки Єе (Yee Grid) та дискретизація рівнянь Максвелла

Для одновимірного (1D) випадку електромагнітна хвиля, що поширюється вздовж осі `x`, описується двома скалярними компонентами полів: вертикальною компонентою електричного поля `E_z(x, t)` та горизонтальною компонентою магнітного поля `H_y(x, t)`. Система неперервних диференціальних рівнянь Максвелла у середовищі з діелектричною проникністю `ε = ε₀ · ε_r` та магнітною проникністю `μ = μ₀ · μ_r` має вигляд:

```
∂E_z / ∂t =  (1 / ε) · (∂H_y / ∂x)     [струм зміщення генерує E_z]
∂H_y / ∂t =  (1 / μ) · (∂E_z / ∂x)     [індукційне поле генерує H_y]
```

Перше рівняння описує закон Максвелла-Ампера у вакуумі чи діелектрику за відсутності струмів провідності (`J = 0`): часова зміна електричного поля `∂E_z/∂t` (струм зміщення) визначається просторовим ротором (просторовою похідною `∂H_y/∂x`) магнітного поля. Друге рівняння описує закон електромагнітної індукції Фарадея: часова зміна магнітного поля `∂H_y/∂t` визначається просторовою похідною електричного поля `∂E_z/∂x`.

Ідея Каней Єе полягає у тому, щоб обчислювати компоненти електричного й магнітного полів не в одних і тих самих точках простору та часу, а зсунути їх відносно один одного на півкроку по просторовій координаті (`Δx / 2`) та на півкроку по часовій осі (`Δt / 2`).

```
                Схема розташування вузлів 1D сітки Єе (Yee Grid)

       Простір:   E_z[0]     H_y[0]     E_z[1]     H_y[1]     E_z[2]
                    o──────────x──────────o──────────x──────────o
                    |<-- Δx/2 ->|
       Час:       t = n·Δt              t = (n + 1/2)·Δt
```

За такої дискретизації всі центральні скінченні різниці для часових та просторових похідних мають другий порядок точності `O(Δx², Δt²)`:

```
∂E_z / ∂t |_(k, n+1/2)  ≈  (E_zⁿ⁺¹[k] − E_zⁿ[k]) / Δt
∂H_y / ∂x |_(k, n)      ≈  (H_yⁿ⁺¹/²[k] − H_yⁿ⁺¹/²[k-1]) / Δx
```

Застосувавши ці скінченно-різницеві апроксимації до систем рівнянь Максвелла, ми отримуємо **явну схему оновлення полів (Interleaved Explicit Time-Stepping)**. На кожному часовому кроці обчислення виконуються у два послідовних етапи:

### Етап 1: Оновлення магнітного поля `H_y` на півкроку часу `t = (n + 1/2)·Δt`

Нове значення магнітного поля у вузлі `k` обчислюється на основі його попереднього значення та різниці електричних полів у сусідніх просторових вузлах `k` та `k+1`:

```
H_yⁿ⁺¹/²[k] = H_yⁿ⁻¹/²[k] + (Δt / (μ[k] · Δx)) · (E_zⁿ[k+1] − E_zⁿ[k])
```

### Етап 2: Оновлення електричного поля `E_z` на цілому кроку часу `t = (n + 1)·Δt`

Нове значення електричного поля (яке прямо враховує струм зміщення) обчислюється на основі попереднього значення електричного поля та просторової різниці щойно оновлених магнітних полів:

```
E_zⁿ⁺¹[k] = E_zⁿ[k] + (Δt / (ε[k] · Δx)) · (H_yⁿ⁺¹/²[k] − H_yⁿ⁺¹/²[k-1])
```

Отриманий алгоритм є винятково елегантним: він не потребує розв'язування складних систем лінійних алгебраїчних рівнянь чи інвертування матриць. Обчислення у кожному вузлі сітки виконуються локально, що робить FDTD ідеально придатним для паралельних обчислень на графічних процесорах (GPU) та суперкомп'ютерах.

## 2. Критерій чисельної стійкості Куранта-Фрідріхса-Леві (CFL)

Оскільки схема FDTD є явною чисельною схемою, для забезпечення математичної стійкості обчислень необхідно строго дотримуватися умові Куранта-Фрідріхса-Леві (CFL Condition).

Фізичний зміст умови Куранта полягає у тому, що числова швидкість поширення інформації по сітці `v_num = Δx / Δt` не повинна бути меншою за реальну фізичну швидкість поширення електромагнітної хвилі у середовищі `c = 1 / √(μ · ε)`. Якщо часовий крок `Δt` обрати занадто великим, чисельна хвиля не встигатиме за фізичною, що призведе до миттєвого вибухового зростання амплітуд полів до нескінченності (чисельна нестійкість).

Математичне формулювання умови стійкості CFL для `D`-вимірного простору має вигляд:

```
Δt ≤ Δx / (c_max · √D)
```

де `c_max = 1 / √(μ₀ · ε₀)` — максимальна швидкість світла у вакуумі.

Для одновимірного простору (`D = 1`):

```
Δt ≤ Δx / c₀
```

У практичних обчислювальних програмах часовий крок обирають із невеликим запасом стійкості, вводячи безрозмірний фактор Куранта `S ≤ 1.0` (зазвичай `S = 0.5 .. 0.99`):

```
Δt = S · (Δx / c₀)
```

## 3. Граничні умови та моделювання діелектричного конденсатора

При використанні скінченно-різницевої сітки обчислювальна область обмежена певним числом вузлів `nx`. На крайніх вузлах сітки (`k = 0` та `k = nx - 1`) необхідно задавати граничні умови:

1. **Ідеально провідна границя (Perfect Electric Conductor, PEC):** Електричне поле на межі фіксується нулем (`E_z[0] = 0`, `E_z[nx-1] = 0`). Це відповідає відбиванню хвилі від ідеальної металевої стінки.
2. **Поглинаючі граничні умови (Absorbing Boundary Conditions, ABC / PML):** Дозволяють електромагнітній хвилі безвільно виходити за межі сітки без відбивання, імітуючи нескінченний відкритий простір.

У нашій моделі ми створюємо область простору з `nx = 200` вузлів. У центральній частині сітки (вузли від `80` до `120`) розташовується шар діелектрика з відносною діелектричною проникністю `ε_r = 4.0` (що відповідає керамічному чи скляному конденсатору). В інших вузлах сітки знаходиться сухий вакуум (`ε_r = 1.0`).

Генерація електромагнітного сигналу здійснюється введенням м'якого гауссового імпульсу електричного поля у вузлі `k = 30`:

```
Pulse(t) = exp( − ((t − t₀) / τ)² )
```

## 4. Повноцінні робочі реалізації методу FDTD

Нижче наведено робочі реалізації симулятора FDTD трьома мовами програмування: Python (з оптимізованою векторизацією NumPy), C++ (з дотриманням ідіом RAII та контейнерів `std::vector`) та мовою C (з явним керуванням пам'яттю).

```py
import math
import numpy as np

def run_fdtd_simulation():
    # Параметри простору й часу
    nx = 200             # Кількість просторових вузлів сітки
    max_steps = 400      # Кількість часових кроків моделювання
    c0 = 299792458.0     # Швидкість світла у вакуумі (м/с)
    dx = 1e-3            # Простокрок сітки Δx = 1 мм
    dt = dx / (2.0 * c0) # Часовий крок Δt за критерієм Куранта (S = 0.5)

    # Масиви діелектричних властивостей середовища (eps_r)
    eps_r = np.ones(nx)
    # Розміщуємо діелектрик конденсатора між вузлами 80 та 120
    eps_r[80:120] = 4.0   # ε_r = 4.0 (кераміка)

    eps0 = 8.854187817e-12
    mu0 = 4.0 * math.pi * 1e-7

    # Поля Ez та Hy
    Ez = np.zeros(nx)
    Hy = np.zeros(nx - 1)

    # Постійні коефіцієнти оновлення полів
    ch = dt / (mu0 * dx)
    ce = dt / (eps0 * eps_r * dx)

    print(f"Запуск симуляції FDTD (Python): dx={dx*1e3:.1f}мм, dt={dt*1e12:.2f}пс, кроків={max_steps}")

    # Головний часовий цикл
    for t_step in range(max_steps):
        # 1. Оновлення магнітного поля H_y
        Hy += ch * (Ez[1:] - Ez[:-1])

        # 2. Оновлення електричного поля E_z (струм зміщення)
        Ez[1:-1] += ce[1:-1] * (Hy[1:] - Hy[:-1])

        # 3. Гауссів імпульсний генератор у вузлі 30
        pulse = math.exp(-((t_step - 40.0) / 12.0) ** 2)
        Ez[30] += pulse

    max_ez_in_cap = np.max(np.abs(Ez[80:120]))
    print(f"Симуляцію успішно завершено. Макс. амплітуда Ez у конденсаторі: {max_ez_in_cap:.4f} В/м")

if __name__ == "__main__":
    run_fdtd_simulation()
```
```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>

class Fdtd1DSimulator {
public:
    Fdtd1DSimulator(std::size_t nx, double dx)
        : nx_(nx), dx_(dx),
          c0_(299792458.0),
          eps0_(8.854187817e-12),
          mu0_(4.0 * M_PI * 1e-7),
          dt_(dx / (2.0 * c0_)),
          Ez_(nx, 0.0),
          Hy_(nx - 1, 0.0),
          eps_r_(nx, 1.0)
    {
        // Встановлюємо діелектричний шар конденсатора (вузли 80..120)
        for (std::size_t i = 80; i < 120 && i < nx_; ++i) {
            eps_r_[i] = 4.0;
        }
    }

    void step(std::size_t t_step) {
        const double ch = dt_ / (mu0_ * dx_);

        // 1. Оновлення магнітного поля Hy
        for (std::size_t k = 0; k < nx_ - 1; ++k) {
            Hy_[k] += ch * (Ez_[k + 1] - Ez_[k]);
        }

        // 2. Оновлення електричного поля Ez (враховуючи струм зміщення)
        for (std::size_t k = 1; k < nx_ - 1; ++k) {
            double ce = dt_ / (eps0_ * eps_r_[k] * dx_);
            Ez_[k] += ce * (Hy_[k] - Hy_[k - 1]);
        }

        // 3. Джерело гауссового імпульсу у вузлі 30
        double pulse = std::exp(-std::pow((static_cast<double>(t_step) - 40.0) / 12.0, 2));
        Ez_[30] += pulse;
    }

    double getMaxEzInCapacitor() const {
        double max_val = 0.0;
        for (std::size_t i = 80; i < 120 && i < nx_; ++i) {
            max_val = std::max(max_val, std::abs(Ez_[i]));
        }
        return max_val;
    }

    double getDt() const { return dt_; }

private:
    std::size_t nx_;
    double dx_;
    double c0_;
    double eps0_;
    double mu0_;
    double dt_;
    std::vector<double> Ez_;
    std::vector<double> Hy_;
    std::vector<double> eps_r_;
};

int main() {
    constexpr std::size_t NX = 200;
    constexpr std::size_t STEPS = 400;
    constexpr double DX = 1e-3;

    Fdtd1DSimulator solver(NX, DX);
    std::cout << "Запуск симулятора FDTD (C++): dt = " << solver.getDt() * 1e12 << " пс\n";

    for (std::size_t t = 0; t < STEPS; ++t) {
        solver.step(t);
    }

    std::cout << "Макс. амплітуда Ez у конденсаторі: " << solver.getMaxEzInCapacitor() << " В/м\n";
    return 0;
}
```
```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define NX 200
#define STEPS 400

typedef struct {
    double Ez[NX];
    double Hy[NX - 1];
    double eps_r[NX];
    double dx;
    double dt;
    double ch;
} Fdtd1DCContext;

void fdtd_init(Fdtd1DCContext* ctx, double dx) {
    const double c0 = 299792458.0;
    const double eps0 = 8.854187817e-12;
    const double mu0 = 4.0 * M_PI * 1e-7;

    ctx->dx = dx;
    ctx->dt = dx / (2.0 * c0);
    ctx->ch = ctx->dt / (mu0 * dx);

    for (int i = 0; i < NX; ++i) {
        ctx->Ez[i] = 0.0;
        ctx->eps_r[i] = (i >= 80 && i < 120) ? 4.0 : 1.0;
    }
    for (int i = 0; i < NX - 1; ++i) {
        ctx->Hy[i] = 0.0;
    }
}

void fdtd_step(Fdtd1DCContext* ctx, int t_step) {
    const double eps0 = 8.854187817e-12;

    /* 1. Оновлення поля Hy */
    for (int k = 0; k < NX - 1; ++k) {
        ctx->Hy[k] += ctx->ch * (ctx->Ez[k + 1] - ctx->Ez[k]);
    }

    /* 2. Оновлення поля Ez (урахування струму зміщення) */
    for (int k = 1; k < NX - 1; ++k) {
        double ce = ctx->dt / (eps0 * ctx->eps_r[k] * ctx->dx);
        ctx->Ez[k] += ce * (ctx->Hy[k] - ctx->Hy[k - 1]);
    }

    /* 3. Гауссів імпульсний джерельний сигнал */
    double pulse = exp(-pow(((double)t_step - 40.0) / 12.0, 2));
    ctx->Ez[30] += pulse;
}

int main(void) {
    Fdtd1DCContext ctx;
    fdtd_init(&ctx, 1e-3);

    printf("Запуск симулятора FDTD (C): dt = %.2f пс\n", ctx.dt * 1e12);

    for (int t = 0; t < STEPS; ++t) {
        fdtd_step(&ctx, t);
    }

    double max_ez = 0.0;
    for (int i = 80; i < 120; ++i) {
        if (fabs(ctx.Ez[i]) > max_ez) {
            max_ez = fabs(ctx.Ez[i]);
        }
    }

    printf("Максимальна амплітуда Ez у конденсаторі: %.4f В/м\n", max_ez);
    return 0;
}
```

## 5. Фізичний аналіз результатів моделювання

Аналіз просторово-часового розподілу полів `Ez` та `Hy` за результатами виконання програми розкриває фундаментальні фізичні закономірності:

1. **Заповільнення фазової швидкості у діелектрику:** Під час входження хвилі у шар конденсатора (`x ∈ [80, 120]`), де `ε_r = 4.0`, фазова швидкість електромагнітної хвилі падає строго вдвічі:
   ```
   v = c₀ / √ε_r = c₀ / √4 = c₀ / 2
   ```
   Довжина хвилі в діелектрику стискається удвічі (`λ = λ₀ / 2`), що виразно видно по ущільненню осциляцій поля на сітці.
2. **Скачок хвильового імпедансу та часткове відбивання:** Волновой імпеданс вакууму дорівнює `η₀ = √(μ₀/ε₀) ≈ 377` Ом. У діелектрику конденсатора імпеданс падає до `η = η₀ / √ε_r ≈ 188.5` Ом. На межі `k = 80` виникає стрибок імпедансу, внаслідок чого коефіцієнт відбивання становить:
   ```
   Γ = (η − η₀) / (η + η₀) = (188.5 − 377) / (188.5 + 377) = − 1 / 3
   ```
   Третина амплітуди падаючої хвилі відбивається назад у формі протифазного відбитого імпульсу, а дві третини проникають всередину діелектрика у формі прохідної хвилі.
3. **Роль струму зміщення у передачі сигналу:** Усередині діелектричного проміжку електричне поле `E_z` постійно створює струм зміщення `J_d = ε₀ · ε_r · (∂E_z/∂t)`. Саме цей струм зміщення генерує магнітне поле `H_y`, підтримуючи безперервний потік електромагнітної енергії крізь конденсатор без участі реальних носіїв заряду.
