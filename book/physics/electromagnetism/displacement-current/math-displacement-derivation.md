# 🧮 Строгий математичний вивід струму зміщення та поля у конденсаторі

Ця вставка містить повний математичний вивід доданку струму зміщення з фундаментальних законів збереження заряду й електростатики, векторний аналіз соленоїдальності повного струму, доведення незалежності циркуляції магнітного поля від вибору геометрії інтегрування, а також розрахунок вихрового магнітного поля `H(r)` і вектора Пойнтінга `S` всередині та зовні плоского круглого конденсатора з урахуванням високих частот і крайових ефектів.

---

## 1. Математичний вивід із рівняння безперервності та закону Гаусса

Розглянемо локальну форму закону збереження електричного заряду, яка описується рівнянням безперервності для об'ємних зарядів і струмів у просторі:

```
∇ · J + ∂ρ/∂t = 0
```

де `J` — вектор густини струму провідності (А/м²), `ρ` — об'ємна густина електричного заряду (Кл/м³).

Згідно із законом Гаусса для вектора електричного зміщення `D` (Кл/м²), об'ємна густина вільних електричних зарядів пов'язана з дивергенцією поля:

```
∇ · D = ρ
```

Підставимо вираз для `ρ` із закону Гаусса у рівняння безперервності:

```
∇ · J + ∂/∂t (∇ · D) = 0
```

Оскільки просторові похідні (оператор `∇ = (i·∂/∂x + j·∂/∂y + k·∂/∂z)`) та часова похідна `∂/∂t` є неперервними й взаємно незалежними математичними операціями для гладких полів, ми можемо поміняти порядок диференціювання:

```
∇ · J + ∇ · (∂D/∂t) = 0
```

Використовуючи лінійність оператора дивергенції, об'єднаємо обидва доданки під один спільний оператор `∇ ·`:

```
∇ · (J + ∂D/∂t) = 0      [фундаментальна умова бездивергентності повного струму]
```

Векторну величину `J_d = ∂D/∂t` називають **густиною струму зміщення**. Векторна сума `J_total = J + J_d = J + ∂D/∂t` являє собою **повну густину струму**, яка є математично соленоїдальною (бездивергентною) у будь-якій точці простору за будь-яких динамічних умов:

```
∇ · J_total = 0
```

У математичному аналізі (теорема Гельмгольца про розклад векторних полів) існує фундаментальна тотожність: дивергенція ротора будь-якого двічі диференційовного векторного поля `H` тотожно дорівнює нулю (`∇ · (∇ × H) ≡ 0`). Звідси випливає, що соленоїдальне векторне поле `J_total` завжди можна подати як ротор деякого векторного поля `H`:

```
∇ × H = J + ∂D/∂t        [диференціальна форма рівняння Максвелла-Ампера]
```

## 2. Теорема Стокса та незалежність циркуляції від геометричної поверхні

Проінтегруємо диференціальне рівняння Максвелла-Ампера по довільній відкритій орієнтованій поверхні `S`, натягнутій на замкнений контур `L`. Застосувавши математичну теорему Стокса для ротора векторного поля, перетворимо поверхневий інтеграл від `∇ × H` у лінійний інтеграл циркуляції уздовж замкненого контуру `L`:

```
∬_S (∇ × H) · dA = ∫_L H · dl
```

Отже, інтегральна форма узагальненого закону Ампера має вигляд:

```
∫_L H · dl = ∬_S (J + ∂D/∂t) · dA = I_c + I_d
```

Доведемо математично, що величина інтеграла у правій частині не залежить від вибору поверхні `S`, натягнутої на контур `L`.

Нехай `S₁` та `S₂` — дві довільні відкриті поверхні, обмежені одним і тим самим замкненим контуром `L`. Об'єднання цих двох поверхонь `S_closed = S₁ ∪ S₂` утворює замкнену тривимірну поверхню, що обмежує деякий об'єм `V`.

Застосуємо теорему Остроградського-Гаусса для вектора повної густини струму `J_total = J + ∂D/∂t` по замкненому об'єму `V`:

```
∯_S_closed J_total · dA = ∭_V (∇ · J_total) dV
```

Оскільки `∇ · J_total = 0` у кожній точці простору, об'ємний інтеграл строго дорівнює нулю:

```
∯_S_closed J_total · dA = ∬_S₁ J_total · dA − ∬_S₂ J_total · dA = 0
```

(Знак «мінус» виникає через протилежну орієнтацію зовнішніх нормалей поверхонь `S₁` та `S₂` відносно напрямку обходу контуру `L`). Звідси негайно випливає:

```
∬_S₁ J_total · dA = ∬_S₂ J_total · dA
```

Величина повної циркуляції магнітного поля `∫_L H · dl` є строго однаковою для будь-якої поверхні `S`, натягнутої на контур `L`! Математичний парадокс роззіяного кола розв'язано остаточно й беззаперечно.

## 3. Точний розрахунок полів у плоскому конденсаторі у циліндричних координатах

Розглянемо круглий плоский конденсатор з пластинами радіуса `R`, розташованими на відстані `h` одна від одної в ідеальному діелектричному середовищі з проникністю `ε = ε₀ · ε_r`. Конденсатор заряджається струмом `I(t)`, підведеним по тонких провідниках вздовж осі `z`.

Введемо циліндричну систему координат `(r, φ, z)`, де вісь `z` збігається з віссю симетрії конденсатора.

```
       Плоский круглий конденсатор у циліндричній системі координат (r, φ, z)

              Пластина 1 (+Q)               Пластина 2 (−Q)
                 ┌──────┐                     ┌──────┐
       ──I(t)───►│      │ ════ E_z(t) ══════► │      │ ───I(t)───►
                 └──────┘                     └──────┘
                     ◄────────── h ──────────►
```

### 1. Розрахунок у низькочастотному наближенні (`h ≪ R`, `λ ≫ R`)

Нехай електричне поле між пластинами є однорідним й орієнтованим строго вздовж осі `z`: `E = (0, 0, E_z)`. Напруженість електричного поля та електричне зміщення дорівнюють:

```
E_z(t) = Q(t) / (ε · π · R²)
D_z(t) = ε · E_z(t) = Q(t) / (π · R²)
```

Густина струму зміщення між пластинами:

```
J_d,z = ∂D_z / ∂t = (1 / (π · R²)) · (dQ/dt) = I(t) / (π · R²)
```

У циліндричній системі координат оператор ротора для вектора `H = (0, H_φ, 0)` має лише `z`-компоненту:

```
(∇ × H)_z = (1/r) · ∂(r · H_φ) / ∂r
```

Прирівнюємо ротор до густини струму зміщення `J_d,z`:

```
(1/r) · ∂(r · H_φ) / ∂r = I(t) / (π · R²)
```

Проінтегруємо це диференціальне рівняння по радіусу `r`:

```
∂(r · H_φ) / ∂r = (I(t) / (π · R²)) · r

r · H_φ(r) = ∫ [ (I(t) / (π · R²)) · r ] dr = (I(t) / (2 · π · R²)) · r² + C
```

З умови симетрії та обмеженості поля на осі (`r = 0`) константа інтегрування дорівнює нулю (`C = 0`). Поділивши на `r`, отримуємо розподіл напруженості магнітного поля всередині конденсатора:

```
H_φ(r) = (I(t) · r) / (2 · π · R²)        [для r ≤ R]
```

Магнітна індукція `B_φ(r) = μ₀ · μ_r · H_φ(r)` всередині конденсатора лінійно зростає від нуля на осі `r = 0` до максимуму на краю обкладок `r = R`:

```
B_max = (μ₀ · μ_r · I(t)) / (2 · π · R)
```

Поза обкладками (`r ≥ R`) струм зміщення відсутній (`J_d = 0`), тому диференціальне рівняння набуває вигляду:

```
(1/r) · ∂(r · H_φ) / ∂r = 0  =>  r · H_φ = const = I(t) / (2·π)

H_φ(r) = I(t) / (2 · π · r)               [для r ≥ R]
```

Цей вираз повністю збігається з магнітним полем нескінченного прямого провідника (закон Біо-Савара-Лапласа).

### 2. Точний розрахунок у високочастотному режимі (хвильові функції Бесселя)

Коли частота коливань струму `ω` зростає до рівня, за якого довжина електромагнітної хвилі в діелектрику `λ = 2·π / k` стає порівнянною з радіусом пластин `R` (`k · R ~ 1`), низькочастотне припущення про однорідність електричного поля `E_z` ламається.

Вихрове магнітне поле `H_φ`, породжене первинним струмом зміщення `∂E_z/∂t`, у свою чергу створює вторинне електричне поле за законом Фарадея `∇ × E = −μ · (∂H/∂t)`. Напруженість електричного поля стає неоднорідною по радіусу `E_z(r, t)`.

Диференціальне рівняння для `E_z(r)` у гармонічному режимі набуває вигляду рівняння Бесселя нульового порядку:

```
d²E_z/dr² + (1/r) · dE_z/dr + k² · E_z = 0
```

де `k = ω · √(μ · ε)` — хвильове число у діелектрику.

Точний точний розв'язок описується бесселевою функцією першого роду нульового порядку `J₀`:

```
E_z(r, t) = E₀ · J₀(k · r) · cos(ω · t)
H_φ(r, t) = E₀ · √(ε / μ) · J₁(k · r) · sin(ω · t)
```

де `J₁` — функція Бесселя першого порядку.

При низьких частотах (`k · r ≪ 1`) ми можемо розкласти функції Бесселя у степеневі ряди: `J₀(kr) ≈ 1 − (kr)²/4`, `J₁(kr) ≈ kr/2`. Співвідношення для `H_φ` негайно переходить у виведену раніше квазістаціонарну формулу `H_φ ∝ r`. При високих частотах у конденсаторі виникає хвильовий резонанс (стоячі електромагнітні хвилі).

## 4. Теорема Пойнтінга та інтегральний енергетичний баланс

Дослідимо баланс енергії електромагнітного поля у циліндричному об'ємі конденсатора `V = π · R² · h`.

Закон збереження електромагнітної енергії у диференціальній формі (теорема Пойнтінга) описується рівнянням:

```
− ∇ · S = ∂u/∂t + J · E
```

де `S = E × H` — вектор Пойнтінга (Вт/м²), `u = (1/2)·ε·E² + (1/2)·μ·H²` — об'ємна густина енергії електромагнітного поля (Дж/м³), `J · E` — питома потужність джоулевих втрат.

Проінтегруємо рівняння по всьому об'єму конденсатора `V` та застосуємо теорему Остроградського-Гаусса до лівої частини:

```
− ∯_A S · dA = d/dt ∭_V u dV + ∭_V (J · E) dV
```

Оскільки удеальному діелектрику струми провідності відсутні (`J = 0`), останній доданок дорівнює нулю.

Обчислимо вектор Пойнтінга на бічній поверхні циліндра `r = R`:

```
E_z = V(t) / h
H_φ(R) = I(t) / (2 · π · R)

S_r(R) = − E_z · H_φ(R) = − [ V(t) · I(t) ] / (2 · π · R · h)
```

Вектор `S_r` орієнтований від'ємно по радіусу (вперед всередину об'єму). Повний потік енергії, що входить крізь бічну поверхню площею `A_side = 2 · π · R · h`:

```
P_in = − ∬_A_side S_r · dA = |S_r| · (2 · π · R · h) = V(t) · I(t)
```

Обчислимо швидкість зміни накопиченої енергії електричного поля `W_e` всередині об'єму:

```
W_e = ∭_V ((1/2) · ε · E_z²) dV = (1/2) · ε · (V/h)² · (π · R² · h) = (1/2) · C · V²
```

де `C = ε · π · R² / h` — ємність плоского конденсатора.

Часова похідна накопиченої енергії дорівнює:

```
dW_e / dt = d/dt [ (1/2) · C · V²(t) ] = C · V(t) · (dV/dt) = V(t) · I(t)
```

Повний потік вектора Пойнтінга `P_in` строго й тотожно дорівнює часовій похідній накопиченої енергії електричного поля `dW_e/dt`:

```
P_in = dW_e / dt = V(t) · I(t)
```

Математичний баланс енергії доведено з абсолютною строгістю.
