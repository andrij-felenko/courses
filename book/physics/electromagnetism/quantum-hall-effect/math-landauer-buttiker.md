# 🧮 Квантування провідності через хіральні крайкові канали та формалізм Ландауера-Бюттікера

Математична строгість квантового ефекту Холла спирається на два видатні теоретичні досягнення: формалізм транспорту Ландауера-Бюттікера (*Landauer-Büttiker formalism*) для балістичних квантових каналів та концепцію топологічних інваріантів (чисел Черна / інваріанта TKNN). Нижче наведено детальний математичний розбір та послідовні виведення квантування провідності Холла та зникання дисипативного опору.

---

### 1. Одномірний квантовий транспорт та формула Ландауера

Розглянемо одномірний квантовий дріт (або окремий крайковий канал), підключений між двома макроскопічними електронними резервуарами: лівим (`L`) та правим (`R`). Резервуари перебувають у стані локальної термодинамічної рівноваги з хімічними потенціалами `μ_L` та `μ_R`, відповідно.

При прикладанні малої напруги `ΔV` різниця хімічних потенціалів становить:

```
μ_L - μ_R = e · ΔV
```

Електрони в лівому резервуарі заповнюють енергетичні стани відповідно до розподілу Фермі-Дірака `f_L(E) = f(E - μ_L)`, а у правому — `f_R(E) = f(E - μ_R)`.

#### Густина станів та швидкість носіїв у 1D каналі

У кожному одномірному квантовому каналі енергія носія задається дисперсійною кривою `E(k)`. Густина станів для одного напрямку руху у хвильовому просторі `k` дорівнює `d N / d k = 1 / (2π)`.

Переходячи від імпульсного простору до енергетичного спектра за допомогою похідної `d E / d k = ℏ · v(E)` (де `v(E)` — група швидкість електрона), отримуємо одновимірну густину станів за енергією для одного напрямку руху:

```
d N / d E
= (d N / d k) · (d k / d E)                 [диференціювання за складною функцією E(k)]
= (1 / (2π)) · (1 / (ℏ · v(E)))             [підстановка значення d N / d k = 1 / 2π]
= 1 / (h · v(E))                            [використання зв'язку h = 2π · ℏ]
```

Звернемо увагу на дивовижну математичну властивість: одновимірна густина станів `d N / d E` є обернено пропорційною швидкості носіїв `v(E)`.

#### Розрахунок результуючого струму

Повний результуючий струм `I`, що протікає крізь канал, дорівнює різниці потоків електронів, що рухаються праворуч від лівого резервуара, та електронів, що рухаються ліворуч від правого резервуара:

```
I = e · ∫ [f_L(E) - f_R(E)] · v(E) · (d N / d E) · T(E) dE
```

де `T(E)` — ймовірність проходження (коефіцієнт трансмісії) електрона крізь канал.

Підставляючи виражену густину станів `d N / d E = 1 / (h · v(E))`, ми бачимо повне скорочення швидкості електрона `v(E)` у чисельнику та знаменнику:

```
I
= (e / h) · ∫ [f_L(E) - f_R(E)] · T(E) dE   [скорочення швидкості v(E) у чисельнику та знаменнику]
= (e² / h) · T · ΔV                        [інтегрування у вікні ΔE = e·ΔV при сталій трансмісії T]
```

Відношення струму до напруги дає квантово-механічну провідність одного каналу:

```
G = I / ΔV = (e² / h) · T
```

Якщо канал є повністю балістичним (без зворотного розсіювання), коефіцієнт проходження ідеально дорівнює одиниці `T = 1`. У цьому випадку провідність каналу дорівнює фундаментальному кванту провідності:

```
G_0 = e² / h ≈ 38.7407 мкСм  (1 / G_0 = h / e² ≈ 25812.81 Ом)
```

### 2. Більгатоконтактний формалізм Бюттікера та матриця трансмісії

Маркус Бюттікер розширив формулу Ландауера на випадок складних геометрій із `N` макроскопічними контактами (таких як вимірювальний місток Холла).

У багатконтактній системі кожен контакт `m` слугує резервуаром електронів з власною напругою `V_m` та хімічним потенціалом `μ_m = e · V_m`. Струм `I_m`, що втікає із контакту `m` у систему, описується матричним рівнянням Бюттікера:

```
I_m = (e² / h) · ∑_n [ T_nm · V_m - T_mn · V_n ]
```

де `T_mn` — сумарний коефіцієнт трансмісії (імовірність переходу) носіїв із контакту `n` до контакту `m`.

Завдяки фундаментальному закону збереження кількості частинок (числу електронів) та унітарності матриці розсіювання (`S`-матриці), сума ймовірностей переходу з контакту `m` в усі інші контакти `n` дорівнює кількості вихідних каналів `N_m`:

```
∑_n T_nm = N_m
```

Звідси рівняння Бюттікера можна переписати у компактній формалізованій формі:

```
I_m = (e² / h) · [ N_m · V_m - ∑_n T_mn · V_n ]
```

### 3. Гамільтоніан 2DEG у магнітному полі та параболічне квантування меж

Розглянемо квантово-механічний гамільтоніан електрона в площині `xy` у наявності перпендикулярного магнітного поля `B = (0, 0, B)`.

У калібруванні Ландау векторний потенціал має вигляд `A = (0, B·x, 0)`. Гамільтоніан двовимірного газу при наявності обмежувального потенціалу зразка `V(x)` записується як:

```
H = (1 / 2m*) · [ p_x² + (p_y + e · B · x)² ] + V(x)
```

Оскільки гамільтоніан не залежить явно від координати `y`, оператор імпульсу `p_y` комутує з гамільтоніаном `[H, p_y] = 0`. Отже, хвильову функцію можна шукати у вигляді плоских хвиль вздовж осі `y`:

```
Ψ(x, y) = exp(i · k_y · y) · χ(x)
```

Підставляючи оператор `p_y = ℏ · k_y` у рівняння Шредінгера `H · Ψ = E · Ψ`, отримуємо одномірне рівняння для нормованої функції `χ(x)`:

```
[ -(ℏ² / 2m*) · (d² / dx²) + (1/2) · m* · ω_c² · (x - x_0)² + V(x) ] χ(x) = E · χ(x)
```

де `ω_c = e·B / m*` — циклотронна частота, а `x_0 = - (ℏ · k_y) / (e · B) = - l_B² · k_y` — центр зміщення циклотронної орбіти (поточечний центр квантового гармонічного осцилятора).

#### Формування крайкових станів на межі зразка

У товщі (bulk) зразка обмежувальний потенціал є константним `V(x) = 0`. Рівняння зводиться до звичайного гармонічного осцилятора із власними значеннями енергії:

```
E_n(k_y) = ℏ · ω_c · (n + 1/2)  = const  (не залежить від k_y)
```

Проте на межі зразка (наприклад, при `x → +L/2` та `x → -L/2`) обмежувальний потенціал `V(x)` стрімко зростає до нескінченності, утворюючи жорстку стінку кристала.

```
       Енергія E
          │
          │    Крайовий канал             Об'єм (Bulk)             Крайовий канал
          │    (рух праворуч)            (ізолятор)                (рух ліворуч)
          │            \                      │                      /
          │             \                     │                     /
  E_F ────┼──────────────\────────────────────┼────────────────────/──────────── Рівень Фермі
          │               \                   │                   /
          │                └─── E_1(k_y) ─────┼────── E_1(k_y) ──┘
          │                   (Рівень Ландау) │  (Рівень Ландау)
          │
          └───────────────────────────────────┴───────────────────────────────── Центр орбіти x_0
                           -L/2                                     +L/2
```

Для центрів орбіт `x_0`, що лежать близько до межі, потенціал `V(x_0)` додається до осциляторної енергії. Це змушує рівні Ландау `E_n(k_y)` стрімко загинатися вгору біля меж зразка.

Групова швидкість електрона вздовж межі визначається як похідна дисперсійної кривої за хвильовим вектором:

```
v_y
= (1 / ℏ) · (d E_n(k_y) / d k_y)              [визначення групової швидкості хвильового пакета]
= (1 / ℏ) · (d E_n / d x_0) · (d x_0 / d k_y)  [цепне правило диференціювання складеної функції x_0(k_y)]
= - (l_B² / ℏ) · (d E_n / d x_0)              [підстановка похідної d x_0 / d k_y = -l_B²]
```

Звідси випливає фундаментальний математичний висновок:
- На лівій межі зразка (`x_0 ≈ -L/2`) потенціал зростає при зменшенні `x_0`, тож похідна `d E_n / d x_0 < 0`. Відповідно, швидкість `v_y > 0` — електрони рухаються строго вгору/праворуч.
- На правій межі зразка (`x_0 ≈ +L/2`) потенціал зростає при збільшенні `x_0`, тож похідна `d E_n / d x_0 > 0`. Відповідно, швидкість `v_y < 0` — електрони рухаються строго вниз/ліворуч.

Знак швидкості строго фіксований похідною обмежувального потенціалу. Це є математичним доказом хіральності крайкових каналів.

### 4. Точний розрахунок опорів для 6-контактного містка Холла

Розглянемо стандартний 6-контактний місток Холла, у якому заповнено `i` рівнів Ландау (тобто існує `i` хіральних крайкових каналів).

Контакти 1 та 4 служать для подачі та відведення струму (`I_1 = I`, `I_4 = -I`), а контакти 2, 3, 5, 6 є потенціальними щупами, підключеними до вольтметрів із нескінченним вхідним опором:

```
I_2 = I_3 = I_5 = I_6 = 0
```

#### Матриця трансмісії Бюттікера

Завдяки строгості хіральності, електрони з контакту 1 потрапляють лише на контакт 2 (`T_21 = i`), з 2 на 3 (`T_32 = i`), з 3 на 4 (`T_43 = i`), з 4 на 5 (`T_54 = i`), з 5 на 6 (`T_65 = i`), та з 6 на 1 (`T_16 = i`). Усі інші елементи матриці трансмісії є тотожно нульовими (`T_mn = 0`).

Запишемо систему рівнянь Бюттікера для потенціальних контактів:

1. **Для контакту 2**:
```
I_2 = (e² / h) · i · (V_2 - V_1) = 0          [умова нескінченного вхідного опору вольтметра I_2 = 0]
⇒  V_2 = V_1
```

2. **Для контакту 3**:
```
I_3 = (e² / h) · i · (V_3 - V_2) = 0          [рівняння Бюттікера для контакту 3 з T_32 = i]
⇒  V_3 = V_2 = V_1
```

3. **Для контакту 5**:
```
I_5 = (e² / h) · i · (V_5 - V_4) = 0          [рівняння Бюттікера для контакту 5 з T_54 = i]
⇒  V_5 = V_4
```

4. **Для контакту 6**:
```
I_6 = (e² / h) · i · (V_6 - V_5) = 0          [рівняння Бюттікера для контакту 6 з T_65 = i]
⇒  V_6 = V_5 = V_4
```

Отже, потенціали контактів на верхній межі повністю дорівнюють потенціалу інжекуючого контакту 1 (`V_2 = V_3 = V_1`), а потенціали контактів на нижній межі дорівнюють потенціалу стокового контакту 4 (`V_5 = V_6 = V_4`).

#### Розрахунок струму та опорів

Запишемо рівняння Бюттікера для повного струму `I`, що втікає через контакт 1:

```
I_1
= (e² / h) · [ i · V_1 - T_16 · V_6 ]         [підстановка N_1 = i та підсумку трансмісії T_16 = i]
= (e² / h) · i · (V_1 - V_4)
```

Звідси зв'язок між струмом та різницею потенціалів становить:

```
V_1 - V_4 = [ h / (i · e²) ] · I
```

Тепер обчислимо обидва макроскопічні опори зразка:

1. **Поздовжній опір `R_xx`**:
Поздовжня напруга вимірюється між двома контактами на **одному й тому самому** краї зразка (наприклад, між контактами 2 та 3):

```
V_xx = V_2 - V_3 = V_1 - V_1 = 0
R_xx = V_xx / I = 0 / I = 0
```

Поздовжній опір тотожно дорівнює нулю.

2. **Поперечний опір Холла `R_xy`**:
Поперечна напруга Холла вимірюється між контактами на **протилежних** краях зразка (наприклад, між контактом 3 на верхній межі та контактом 5 на нижній межі):

```
V_xy = V_3 - V_5 = V_1 - V_4
```

Підставляючи вираз для `(V_1 - V_4)`, отримуємо точний квантований опір Холла:

```
R_xy
= V_xy / I                                     [визначення опору Холла за законом Ома]
= (V_1 - V_4) / [ (e² / h) · i · (V_1 - V_4) ]  [підстановка виразу для струму I_1]
= h / (i · e²)                                [скорочення різниці потенціалів V_1 - V_4]
```

Цей послідовний вивід показує: квантування опору Холла `R_xy = h / (i · e²)` та нульовий поздовжній опір `R_xx = 0` є прямою математичною наслідком формалізму Бюттікера для хіральних крайкових каналів.

### 5. Топологічне виведення інваріанта TKNN та чисел Черна

Для доведення незалежності квантування від дефектів та геометричної форми розпишемо топологічне виведення Таулесса, Комото, Найтінгела та ден Nijs (інваріант TKNN).

За формулою Кубо, компонента тензора провідності `σ_xy` для системи безвзаємодіючих електронів у періодичному потенціалі описується лінійною реакцією:

```
σ_xy = (i · ℏ · e² / A) · ∑_(E_n < E_F) ∑_(E_m > E_F) [ (v_x)_nm · (v_y)_mn - (v_y)_nm · (v_x)_mn ] / (E_m - E_n)²
```

де `|n⟩` та `|m⟩` — зайняті та вільні блохівські стани з енергіями `E_n` та `E_m`, а `A` — площа системи.

Переходячи від операторів швидкості `v = (1/ℏ) · ∇_k H(k)` до хвильових функцій Блоха `|u_n(k)⟩`, цей вираз перетворюється на інтеграл по двовимірній зоні Бріллюена:

```
σ_xy = (e² / h) · (1 / 2π) · ∑_n ∬_BZ [ ∇_k × A_n(k) ]_z d²k
```

де `A_n(k)` — **векторний потенціал Беррі** (Berry connection) у просторі імпульсів:

```
A_n(k) = i · ⟨u_n(k) | ∇_k u_n(k)⟩
```

А ротор векторного потенціалу `Ω_n(k) = ∇_k × A_n(k)` називається **кривиною Беррі** (*Berry curvature*).

Згідно з теоремою Гаусса-Бонне та математичною теорією топологічних векторних розшарувань, інтеграл від кривини Беррі по будь-якому замкненому двовимірному многовиду (зоні Бріллюена `T²`) є квантованим цілим числом:

```
C_n = (1 / 2π) · ∬_BZ Ω_n(k) d²k  ∈  ℤ
```

Число `C_n` є **числом Черна** для `n`-ї заповненої підзони.

Сумуючи внески від усіх `i` заповнених рівнів Ландау, отримуємо точне квантування макроскопічної провідності Холла:

```
σ_xy = (e² / h) · ∑_(n=1)^i C_n = i · (e² / h)
```

Оскільки число Черна `C_n` є топологічним інваріантом, воно не може змінюватися при будь-яких неперервних деформаціях гамільтоніана `H(k)`, якщо тільки енергетична щілина між зонами не закривається. Це завершує математичний доказ топологічної стійкості квантового ефекту Холла.
