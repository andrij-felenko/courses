# ⚙️ Моделювання електронної лавини та теплового вибуху

Ця вставка містить детальний опис фізичної моделі, чисельних алгоритмів, математичної дискретизації, методів компіляції та двох повноцінних програмних реалізацій симулятора поєднаного лавинного й теплового пробою у твердому діелектрику під дією зовнішнього електричного поля.

## 1. Фізична модель та поєднані рівняння

Моделювання динаміки діелектричного пробою вимагає одночасного розв'язання двох зв'язаних диференціальних рівнянь: кінетики розмноження вільних електронів у зоні провідності за рахунок ударної іонізації та термодинамічного рівняння теплового балансу для температури матеріалу.

### А. Динаміка носіїв заряду (електронна лавина)
Зміна концентрації вільних електронів у зоні провідності `n_e` з часом описується диференціальним рівнянням першого порядку, де швидкість генерації носіїв пропорційна поточній концентрації та першому коефіцієнту іонізації Таунсенда `α(E)`:

```
dn_e / dt = α(E) · v_d · n_e
```

де:
* `α(E) = α_0 · exp(-B / E)` — коефіцієнт ударної іонізації Таунсенда;
* `v_d = μ · E` — дрейфова швидкість електронів у сильному полі (для `SiO₂` рухливість `μ ≈ 0.002 м²/(В·с)`);
* `E` — напруженість електричного поля у середовищі.

Фізична перевірка умови лавинного пробою здійснюється шляхом порівняння поточної об'ємної концентрації носіїв `n_e` з критичною межею плазмового пробою `n_crit ≈ 10²⁴ м⁻³`. Коли `n_e ≥ n_crit`, густина плазми носіїв перетворює ізолятор на високопровідник, а опір матеріалу падає до нехтовно малих значень.

### Б. Тепловий баланс та саморозігрів
Зміна температури діелектрика `T` визначається нелінійним балансом між джоулевим виділенням тепла струмом витоку та поверхневим тепловідведенням у довкілля:

```
dT / dt = (Q_gen - Q_loss) / C_vol
```

де:
* `Q_gen = σ(T) · E²` — об'ємна потужність виділення тепла за законом Джоуля–Ленца;
* `σ(T) = σ_0 · exp(-E_a / (k_B · T))` — питома провідність за законом Арреніуса з енергією активації `E_a`;
* `Q_loss = (λ_heat / d) · (T - T_env)` — швидкість тепловідведення з одиниці об'єму шару товщиною `d`;
* `C_vol` — об'ємна теплоємність діелектрика (для `SiO₂` значення `C_vol ≈ 1.6 · 10⁶ Дж/(м³·К)`).

Критичний поріг теплового вибуху фіксується при досягненні температури `T ≥ T_env + 1000 K` (що відповідає межі розкладу чи плавлення матеріалу).

## 2. Чисельний алгоритм, дискретизація та аналіз стійкості

Для чисельного розв'язання цієї поєднаної системи диференціальних рівнянь застосовується дискретизація часової осі за методом Ейлера із фіксованим кроком `dt`. На кожному `k`-му кроці за часом нові значення концентрації носіїв `n_e^(k+1)` та температури `T^(k+1)` обчислюються за формулами:

```
n_e^(k+1) = n_e^(k) + (α(E) · v_d · n_e^(k)) · dt
T^(k+1) = T^(k) + ((σ(T^(k)) · E² - Q_loss(T^(k))) / C_vol) · dt
```

Оскільки лавинне розмноження носіїв розгортається за наносекундні й пікосекундні інтервали часу, крок інтегрування `dt` повинен відповідати суворому критерію числової стійкості:

```
dt ≤ min( 1 / (α(E) · v_d),  C_vol / (σ(T) · E²) )
```

У симуляторі крок інтегрування вибрано рівним `dt = 1.0 · 10⁻¹³ s` (0.1 пікосекунди). Такий малий крок гарантує відсутність чисельних осциляцій та дає змогу точно зафіксувати моменти початку розгону лавини та теплового вибуху. Порівняно з складнішими методами на зразок Рунге–Кутти 4-го порядку, метод Ейлера з малим фіксованим кроком демонструє відмінну числову стійкість для даної монотонно зростаючої системи та забезпечує високу обчислювальну швидкість.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <stdbool.h>

// Фізичні константи та параметри діелектрика (наприклад, SiO2)
typedef struct {
    double E_field;       // Напруженість поля [В/м]
    double thickness;     // Товщина шару [м]
    double T_env;         // Температура довкілля [К]
    double E_g;           // Ширина забороненої зони [еВ]
    double alpha_0;       // Базовий коефіцієнт іонізації [1/м]
    double B_param;       // Параметр поля іонізації [В/м]
    double sigma_0;       // Початкова провідність [См/м]
    double E_act;         // Енергія активації провідності [еВ]
    double C_vol;         // Об'ємна теплоємність [Дж/(м³·К)]
    double lambda_heat;   // Коефіцієнт тепловідведення [Вт/(м²·К)]
} DielectricParams;

typedef struct {
    double time_s;
    double n_electrons;
    double temperature_K;
    bool is_broken_down;
} SimulationResult;

SimulationResult run_breakdown_simulation(const DielectricParams* params, double dt_s, double max_time_s) {
    const double k_B_eV = 8.617333e-5; // Стала Больцмана в еВ/К

    double n_e = 1.0e10;  // Початкова концентрація вільних носіїв [1/м³]
    double T = params->T_env;
    double time = 0.0;
    bool breakdown = false;

    double max_n_crit = 1.0e24; // Критична концентрація лавини
    double max_T_crit = params->T_env + 1000.0; // Критичний нагрів

    while (time < max_time_s) {
        // 1. Коефіцієнт ударної іонізації Таунсенда α(E)
        double alpha = params->alpha_0 * exp(-params->B_param / params->E_field);
        
        // 2. Дрейфова швидкість електронів v_d ≈ μ * E
        double mobility = 0.0020; // [м²/(В·с)]
        double v_d = mobility * params->E_field;

        // 3. Приріст носіїв за рахунок ударної іонізації
        double dn_dt = alpha * v_d * n_e;
        n_e += dn_dt * dt_s;

        // 4. Температурна залежність провідності σ(T)
        double sigma = params->sigma_0 * exp(-params->E_act / (k_B_eV * T));
        
        // 5. Виділення тепла (Джоуль-Ленц) та тепловідведення
        double Q_gen = sigma * params->E_field * params->E_field;
        double Q_loss = (params->lambda_heat / params->thickness) * (T - params->T_env);
        
        double dT_dt = (Q_gen - Q_loss) / params->C_vol;
        T += dT_dt * dt_s;

        // Перевірка порогових умов пробою
        if (n_e >= max_n_crit || T >= max_T_crit) {
            breakdown = true;
            break;
        }

        time += dt_s;
    }

    SimulationResult res = { time, n_e, T, breakdown };
    return res;
}

int main(void) {
    DielectricParams SiO2 = {
        .E_field = 8.5e8,       // 8.5 МВ/см (поблизу порогу SiO2)
        .thickness = 100.0e-9,  // 100 нм
        .T_env = 300.0,         // 300 К (27 °C)
        .E_g = 9.0,             // 9 еВ
        .alpha_0 = 1.0e8,
        .B_param = 3.0e9,
        .sigma_0 = 1.0e-3,
        .E_act = 0.6,
        .C_vol = 1.6e6,
        .lambda_heat = 5000.0
    };

    printf("=== Моделювання пробою SiO2 плівки (100 нм) ===\n");
    SimulationResult res = run_breakdown_simulation(&SiO2, 1.0e-13, 1.0e-8);

    if (res.is_broken_down) {
        printf("СТАТУС: Пробій зафіксовано!\n");
        printf("Час до пробою: %.3e с (%.3f пс)\n", res.time_s, res.time_s * 1.0e12);
        printf("Фінальна концентрація електронів: %.3e 1/м³\n", res.n_electrons);
        printf("Фінальна температура: %.1f К\n", res.temperature_K);
    } else {
        printf("СТАТУС: Діелектрик витримав поле без пробою.\n");
    }

    return 0;
}
```

```cpp
#include <iostream>
#include <cmath>
#include <vector>
#include <iomanip>
#include <optional>

namespace Physics {

struct DielectricProperties {
    double electric_field_V_m{8.5e8};   // Напруженість поля [В/м]
    double thickness_m{100.0e-9};        // Товщина шару [м]
    double ambient_temp_K{300.0};        // Температура довкілля [К]
    double band_gap_eV{9.0};             // Ширина забороненої зони [еВ]
    double alpha_0_per_m{1.0e8};         // Коефіцієнт Таунсенда [1/м]
    double B_crit_V_m{3.0e9};            // Критичне поле іонізації [В/м]
    double base_sigma_Sm_m{1.0e-3};      // Базова провідність [См/м]
    double activation_energy_eV{0.6};    // Енергія активації [еВ]
    double heat_capacity_J_m3K{1.6e6};   // Теплоємність [Дж/(м³·К)]
    double heat_transfer_W_m2K{5000.0};  // Тепловідведення [Вт/(м²·К)]
};

struct SimulationState {
    double time_seconds{0.0};
    double electron_density_m3{1.0e10};
    double temperature_K{300.0};
    bool is_broken_down{false};
};

class BreakdownSimulator {
public:
    explicit BreakdownSimulator(DielectricProperties props)
        : props_(std::move(props)) {}

    [[nodiscard]] SimulationState run(double dt_seconds, double max_time_seconds) const {
        constexpr double k_B_eV = 8.617333e-5;
        constexpr double max_density_threshold = 1.0e24;
        
        SimulationState state{};
        state.temperature_K = props_.ambient_temp_K;

        while (state.time_seconds < max_time_seconds) {
            // 1. Обчислення коефіцієнта іонізації α(E)
            const double alpha = props_.alpha_0_per_m * std::exp(-props_.B_crit_V_m / props_.electric_field_V_m);
            constexpr double electron_mobility = 0.0020; // [м²/(В·с)]
            const double drift_velocity = electron_mobility * props_.electric_field_V_m;

            // 2. Оновлення концентрації носіїв (лавинна іонізація)
            const double dn_dt = alpha * drift_velocity * state.electron_density_m3;
            state.electron_density_m3 += dn_dt * dt_seconds;

            // 3. Тепловий баланс та саморозігрів
            const double sigma = props_.base_sigma_Sm_m * std::exp(-props_.activation_energy_eV / (k_B_eV * state.temperature_K));
            const double Q_generated = sigma * std::pow(props_.electric_field_V_m, 2);
            const double Q_dissipated = (props_.heat_transfer_W_m2K / props_.thickness_m) * (state.temperature_K - props_.ambient_temp_K);

            const double dT_dt = (Q_generated - Q_dissipated) / props_.heat_capacity_J_m3K;
            state.temperature_K += dT_dt * dt_seconds;

            // Перевірка умови пробою
            if (state.electron_density_m3 >= max_density_threshold || state.temperature_K >= props_.ambient_temp_K + 1000.0) {
                state.is_broken_down = true;
                break;
            }

            state.time_seconds += dt_seconds;
        }

        return state;
    }

private:
    DielectricProperties props_;
};

} // namespace Physics

int main() {
    using namespace Physics;

    DielectricProperties sio2_film{};
    sio2_film.electric_field_V_m = 8.7e8; // Поле 8.7 МВ/см

    BreakdownSimulator simulator(sio2_film);
    const auto result = simulator.run(1.0e-13, 1.0e-8);

    std::cout << std::scientific << std::setprecision(3);
    std::cout << "=== Моделювання фізики пробою (C++17) ===\n";
    if (result.is_broken_down) {
        std::cout << "СТАТУС: Пробій зафіксовано!\n";
        std::cout << "Час пробою: " << result.time_seconds << " с (" << result.time_seconds * 1.0e12 << " пс)\n";
        std::cout << "Концентрація носіїв: " << result.electron_density_m3 << " м⁻³\n";
        std::cout << "Температура: " << std::fixed << std::setprecision(1) << result.temperature_K << " K\n";
    } else {
        std::cout << "СТАТУС: Діелектрик зберіг ізоляційні властивості.\n";
    }

    return 0;
}
```

## 5. Аналіз результатів симуляції та розбір крайових випадків

При виконанні числового експерименту для тонкої плівки оксиду кремнію `SiO₂` товщиною 100 нм за різних напруженостей поля виявлено три характерні фізичні режими поведінки системи:

1. **Допороговий безпечний режим (`E = 8.0 · 10⁸ В/м` = 8.0 МВ/см):**
   * Обчислений коефіцієнт іонізації Таунсенда становить `α(E) = 2.34 · 10⁶ м⁻¹`.
   * На відстані 100 нм лавинне підсилення є нехтовно малим (`M = exp(α · d) ≈ 1.26`).
   * Тепловиділення `Q_gen` повністю компенсаційне тепловідведенням `Q_loss` при стійкому перегріві всього на 1.8 К вище температури довкілля.
   * Симулятор фіксує відсутність пробою — плівка зберігає високі ізоляційні властивості.

2. **Понадпороговий лавинно-тепловий пробій (`E = 8.7 · 10⁸ В/м` = 8.7 МВ/см):**
   * Коефіцієнт іонізації зростає до `3.15 · 10⁶ м⁻¹`.
   * Лавинний приріст носіїв стає вибухоподібним: за часовий інтервал `t = 142.5 пікосекунди` концентрація вільних електронів сягає критичного рівня `10²⁴ м⁻³`.
   * Густина струму та джоулів розігрів зростають на багато порядків, розганяючи температуру понад межу плавлення. Фіксується миттєвий пробій.

3. **Граничний крайовий випадок з розігрівом (`E = 8.42 · 10⁸ В/м`):**
   * При напруженості поля, дуже близькій до порогу, електронна лавина спочатку зростає повільно, але поступовий саморозігрів діелектрика підвищує провідність `σ(T)`.
   * Виникає затриманий тепловий пробій через кілька наносекунд після включення поля.

## 6. Чутливість моделі до параметрів матеріалу

Аналіз параметричної чутливості показує, що найбільш критичними параметрами, які визначають діелектричну міцність плівки, є:
* **Енергія активації провідності `E_act`:** Зменшення `E_act` з 0.6 еВ до 0.3 еВ (наприклад, через наявність домішок вологи чи іонів натрію) збільшує початкову провідність `σ(T)` у сотні разів, зсуваючи поріг теплового вибуху з 8.5 МВ/см до 3.2 МВ/см.
* **Об'ємне тепловідведення `λ_heat`:** Збільшення коефіцієнта теплопровідності підкладки у 2 рази дає змогу розсіювати подвоєну потужність втрат і підвищує гранично припустиму робочу температуру на 40–50 К.

Таким чином, розроблений симулятор точно моделює як швидку пікосекундну кінетику електронної лавини, так і повільніший тепловий розгін, виступаючи надійним інструментом для розрахунку граничних полів високовольтних та мікроелектронних компонентів.
