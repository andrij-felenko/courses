# 🧮 Математичний вивід та інтегрування закону Біо–Савара

Ця математична вставка містить детальні аналітичні виведення виразів для магнітного поля `B` фундаментальних геометрій струму на основі диференціального закону Біо — Савара — Лапласа. Кожен крок інтегрування супроводжується поясненням застосованих тригонометричних, алгебраїчних та векторних заміни змінних.

Вихідною точкою усіх розрахунків є диференціальна векторна формула для внеску `dB` елемента струму `I · dl` у точці спостереження `P`, визначеній радіус-вектором `r`:

```
dB = (μ₀ / (4·π)) · (I · dl × r̂) / r²
```

де:
- `μ₀ = 4·π · 10⁻⁷ Гн/м` — магнітна стала (магнітна проникність вакууму);
- `dl` — векторний елемент довжини провідника за напрямком струму;
- `r̂ = r / r` — одиничний вектор від елемента струму до точки спостереження `P`;
- `r = |r|` — відстань між елементом струму та точкою спостереження.

## 1. Загальний формалізм у векторній та декартовій формах

У декартовій системі координат `(x, y, z)` елемент струму розташований у точці `r' = (x', y', z')`, а точка спостереження — у точці `r_p = (x, y, z)`. Вектор відстані дорівнює:

```
r = r_p - r' = (x - x', y - y', z - z')
```

Його модуль виражається як:

```
r = |r_p - r'| = √[(x - x')² + (y - y')² + (z - z')²]
```

Компоненти векторного добутку `dl' × r` виражаються через декартові проекції та символи Леві-Чивіта:

```
(dl' × r)_x = dy' · (z - z') - dz' · (y - y')
(dl' × r)_y = dz' · (x - x') - dx' · (z - z')
(dl' × r)_z = dx' · (y - y') - dy' · (x - x')
```

Підставляючи ці компоненти у диференціальний закон Біо — Савара, отримуємо скалярну систему трьох декартових інтегралів для проекцій вектора індукції `B = (B_x, B_y, B_z)`:

```
B_x = (μ₀ · I / (4·π)) · ∫[L] [dy' · (z - z') - dz' · (y - y')] / [(x - x')² + (y - y')² + (z - z')²]^(3/2)
B_y = (μ₀ · I / (4·π)) · ∫[L] [dz' · (x - x') - dx' · (z - z')] / [(x - x')² + (y - y')² + (z - z')²]^(3/2)
B_z = (μ₀ · I / (4·π)) · ∫[L] [dx' · (y - y') - dy' · (x - x')] / [(x - x')² + (y - y')² + (z - z')²]^(3/2)
```

## 2. Прямолінійний провідник: скінченний, нескінченний та напівнескінченний

Розглянемо прямолінійний провідник зі струмом `I`, розташований уздовж осі `Z`. Потрібно обчислити магнітну індукцію `B` у точці спостереження `P`, яка перебуває на перпендикулярній відстані `R` від провідника на осі `X` з координатами `(R, 0, 0)`.

### 2.1. Геометричні співвідношення та підготовка інтеграла

Елемент провідника розташований у точці `(0, 0, z)` і має векторний елемент довжини `dz = (0, 0, dz)`.

Вектор від елемента `dz` до точки `P` дорівнює:

```
r = (R, 0, -z)
```

Модуль відстані:

```
r = √(R² + z²)
```

Обчислюємо векторний добуток `dz × r`:

```
dz × r = (0, 0, dz) × (R, 0, -z) = (0, R · dz, 0)
```

Векторний добуток спрямований строго уздовж осі `Y`. Це означає, що поле має лише одну декартову компоненту `B_y`, яка огинає провідник за правилом правої руки.

Модуль диференціальної індукції `dB`:

```
dB = (μ₀ · I / (4·π)) · (R · dz) / (R² + z²)^(3/2)
```

### 2.2. Заміна змінних через кути спостереження

Для обчислення інтеграла здійснимо заміну змінної `z` на кут `α` між перпендикуляром `R` та радіус-вектором `r`. З прямокутного трикутника маємо:

```
z = R · tan α                                   [визначення тангенса кута α = z/R]
dz = R · dα / cos² α                            [диференціювання: d(tan α) = dα / cos² α]
r = R / cos α                                   [визначення косинуса: cos α = R / r]
```

Підставляємо ці три вирази у диференціал `dB`:

```
dB = (μ₀ · I / (4·π)) · [R · (R · dα / cos² α)] / [(R / cos α)³]
= (μ₀ · I / (4·π)) · (R² · dα / cos² α) / (R³ / cos³ α)           [піднесення до куба знаменника]
= (μ₀ · I / (4·π · R)) · cos α · dα                               [спрощення дробу: R²/R³ = 1/R та cos³α/cos²α = cos α]
```

### 2.3. Інтегрування для скінченного відрізка провідника

Нехай прямолінійний провідник починається під кутом `α₁` та закінчується під кутом `α₂` відносно перпендикуляра `R`. Інтегруємо отриманий диференціал:

```
B = ∫[від α₁ до α₂] dB
= (μ₀ · I / (4·π · R)) · ∫[від α₁ до α₂] cos α · dα               [винесення сталих за знак інтеграла]
= (μ₀ · I / (4·π · R)) · (sin α₂ - sin α₁)                         [первісна cos α = sin α]
```

Якщо перепозначити геометрію через внутрішні кути трикутника `θ₁` та `θ₂` між напрямком струму та напрямком на краї провідника (`α = θ - 90°`, `sin α = -cos θ`), формула набуває вигляду:

```
B = (μ₀ · I / (4·π · R)) · (cos θ₁ - cos θ₂)
```

### 2.4. Граничний перехід до нескінченного провідника

Для нескінченно довгого провідника краї прямують до нескінченності: `z₁ -> -∞` та `z₂ -> +∞`. Відповідно кути напрямку прямують до `α₁ -> -π/2` та `α₂ -> +π/2` (або `θ₁ -> 0` та `θ₂ -> π`).

Обчислюємо різницю синусів:

```
sin(+π/2) - sin(-π/2) = 1 - (-1) = 2
```

Підставляємо значення в інтегральну формулу:

```
B = (μ₀ · I / (4·π · R)) · 2                                       [підстановка різниці синусів]
= (μ₀ · I) / (2·π · R)                                             [скорочення 2 / 4 = 1/2]
```

Це фундаментальна формула Біо — Савара для магнітного поля нескінченного прямого струму.

### 2.5. Напівнескінченний провідник (струмовий промінь)

Якщо провідник починається у точці `z = 0` (`α₁ = 0`) і прямує до нескінченності `z -> +∞` (`α₂ = π/2`), поле на торці провідника дорівнює:

```
B = (μ₀ · I / (4·π · R)) · (sin(π/2) - sin(0))
= (μ₀ · I) / (4·π · R)
```

Поле напівнескінченного струму становить точно половину від поля нескінченного провідника.

### 2.6. Квадратний контур та правильні багатокутники

- **Квадратний контур зі стороною `a`:** Точка спостереження у центрі квадрата міститься на перпендикулярній відстані `R = a / 2` від усіх 4 сторін. Кожна сторона видно під кутами `α₁ = -45°` та `α₂ = +45°`.
  ```
  B_side = (μ₀ · I / (4·π · (a/2))) · (sin 45° - sin(-45°))
  = (μ₀ · I / (2·π · a)) · (√2/2 - (-√2/2))    [підстановка значень синусів: sin 45° = √2/2 та sin(-45°) = -√2/2]
  = (μ₀ · I / (2·π · a)) · √2                  [спрощення виразу в дужках: √2/2 - (-√2/2) = √2]
  ```
  Підсумовуючи внески від 4 сторін:
  ```
  B_square = 4 · B_side
  = 4 · [(μ₀ · I / (2·π · a)) · √2]            [підстановка значень B_side для однієї сторони]
  = (2·√2 · μ₀ · I) / (π · a)                  [скорочення коефіцієнтів 4 / 2 = 2]
  ```

- **Правильний n-кутник:** Для багатокутника з `n` сторонами, вписаного в коло радіуса `R`, перпендикулярна відстань до сторони `R_p = R · cos(π/n)`, а сторона видно під кутами `α₁ = -π/n` та `α₂ = +π/n`.
  ```
  B_n = n · [(μ₀ · I / (4·π · R · cos(π/n))) · (2 · sin(π/n))]
  = (n · μ₀ · I / (2·π · R)) · tan(π/n)                             [використання sin(π/n) / cos(π/n) = tan(π/n)]
  ```
  При `n -> ∞` за першою чудовою границею `n · tan(π/n) -> π`, тому `B_n -> (μ₀ · I) / (2 · R)`, що точно збігається з полем колового витка.

## 3. Коловий виток та колові дуги

Розглянемо коловий виток радіуса `R`, розташований у площині `XY` з центром у початку координат. Провідником протікає постійний струм `I`.

### 3.1. Розрахунок поля на осі симетрії Z

Розглянемо точку спостереження `P(0, 0, z)` на осі симетрії витка.

Елемент довжини витка у циліндричних координатах дорівнює `dl = R · dφ`, а вектор від елемента до точки `P` має модуль `r = √(R² + z²)`.

Оскільки елемент витка `dl` лежить у площині `XY`, а вектор `r` має осьову та радіальну компоненти, кут між ними завжди дорівнює `90°`. Тому модуль векторного добутку:

```
|dl × r̂| = dl · 1 · sin(90°) = dl = R · dφ
```

Модуль диференціальної індукції від елемента:

```
dB = (μ₀ · I / (4·π)) · (R · dφ) / (R² + z²)
```

Вектор `dB` спрямований перпендикулярно до `r` і утворює з віссю `Z` кут `γ`. З подібності прямокутних трикутників `sin γ = R / r = R / √(R² + z²)`.

Розкладемо `dB` на осьову `dB_z` та радіальну `dB_⊥` компоненти:

```
dB_z = dB · sin γ = (μ₀ · I · R / (4·π)) · (R · dφ) / (R² + z²)^(3/2)
dB_⊥ = dB · cos γ
```

Завдяки осьовій симетрії контуру при інтегруванні по повному куту `φ` від `0` до `2·π` радіальні компоненти від діаметрально протилежних елементів взаємно компенсуються:

```
∫[від 0 до 2π] dB_⊥ = 0
```

Для осьової компоненти `B_z` інтегруємо вираз по куту `φ`:

```
B_z = ∫[від 0 до 2π] dB_z
= (μ₀ · I · R² / (4·π · (R² + z²)^(3/2))) · ∫[від 0 до 2π] dφ    [підстановка dB_z та винесення констант]
= (μ₀ · I · R² / (4·π · (R² + z²)^(3/2))) · (2·π)              [інтеграл по куту dφ = 2·π]
= (μ₀ · I · R²) / [2 · (R² + z²)^(3/2)]                        [скорочення 2·π / (4·π) = 1/2]
```

### 3.2. Центр витка та дипольне наближення

1. **У центрі витка (`z = 0`):**
   ```
   B(0) = (μ₀ · I · R²) / (2 · (R²)^(3/2))                        [підстановка z = 0: (R²)^(3/2) = R³]
   = (μ₀ · I) / (2 · R)                                           [скорочення R² / R³ = 1/R]
   ```

2. **Далеке поле (`z >> R`):**
   У знаменнику нехтуємо `R²` порівняно з `z²`: `(R² + z²)^(3/2) ≈ z³`.
   ```
   B_z ≈ (μ₀ · I · R²) / (2 · z³)
   ```
   Помножимо чисельник і знаменник на `π`:
   ```
   B_z ≈ (μ₀ · (I · π · R²)) / (2·π · z³)
   = (μ₀ · p_m) / (2·π · z³)                                      [введення магнітного моменту p_m = I · S = I · π · R²]
   ```

### 3.3. Магнітна індукція дуги кола під кутом `θ`

Для провідника у формі дуги кола радіуса `R` із центральним кутом `θ` (у радіанах) усе поле у центрі спрямоване вздовж осі `Z`.

Оскільки довжина дуги дорівнює `L = R · θ`:

```
B_center = (μ₀ · I / (4·π · R²)) · (R · θ)                        [підстановка довжини дуги L = R·θ]
= (μ₀ · I · θ) / (4·π · R)                                         [скорочення R / R² = 1/R]
```

Зокрема:
- Для чверті кола (`θ = π/2`): `B = (μ₀ · I) / (8 · R)`;
- Для півкола (`θ = π`): `B = (μ₀ · I) / (4 · R)`;
- Для повного витка (`θ = 2·π`): `B = (μ₀ · I) / (2 · R)`.

### 3.4. Поле витка поза віссю симетрії через еліптичні інтеграли

У довільній точці поза віссю з циліндричними координатами `(r_radial, φ, z)` векторний потенціал `A` має лише азимутальну компоненту `A_φ`:

```
A_φ(r_radial, z) = (μ₀ · I / π) · √(R / r_radial) · [ ( (1 - k²/2) · K(k) - E(k) ) / k ]
```

де `K(k)` та `E(k)` — повні еліптичні інтеграли першого та другого роду:

```
K(k) = ∫[від 0 до π/2] dθ / √(1 - k² · sin² θ)
E(k) = ∫[від 0 до π/2] √(1 - k² · sin² θ) · dθ
```

з модулем еліптичного інтеграла `k`:

```
k² = (4 · R · r_radial) / [(R + r_radial)² + z²]
```

Вектор індукції `B = ∇ × A` отримують вирахуванням ротора у циліндричних координатах: `B_r = -∂A_φ / ∂z` та `B_z = (1 / r_radial) · ∂(r_radial · A_φ) / ∂r_radial`.

## 4. Соленоїд та котушки Гельмгольца

### 4.1. Поле на осі скінченного соленоїда

Розглянемо циліндричний соленоїд радіуса `R` та довжиною `L`, на який щільно намотано `N` витків. Густина намотування дорівнює `n = N / L` витків на метр.

Соленоїд можна подати як сукупність диференціальних колових струмів `dI = I · n · dz'`, розташованих уздовж осі `Z`.

Внесок диференційного шару товщиною `dz'` у поле на осі дорівнює:

```
dB_z = (μ₀ · (I · n · dz') · R²) / [2 · (R² + (z - z')²)^(3/2)]
```

Здійснюємо заміну змінної `z - z' = R · cot θ`, що дає `dz' = R · dθ / sin² θ`. Після інтегрування від кута `θ₁` до `θ₂` (під якими видно краї соленоїда з точки спостереження) отримуємо:

```
B_z = (μ₀ · n · I / 2) · (cos θ₁ - cos θ₂)
```

Для нескінченно довгого соленоїда (`L >> R`) у внутрішніх точках `θ₁ -> 0` (`cos θ₁ -> 1`) та `θ₂ -> π` (`cos θ₂ -> -1`):

```
B_solenoid = (μ₀ · n · I / 2) · (1 - (-1))                          [підстановка cos 0 = 1 та cos π = -1]
= μ₀ · n · I                                                        [скорочення 2 / 2 = 1]
```

### 4.2. Математичний доказ оптимальності котушок Гельмгольца

Котушки Гельмгольца складаються з двох однакових співвісних витків радіуса `R`, розташованих на відстані `d` одна від одної, якими струм протікає в одному напрямку.

Поле у точці на середині між котушками (`z = 0`) дорівнює сумі полів двох витків, розташованих у точках `z = -d/2` та `z = +d/2`:

```
B_total(z) = (μ₀ · I · R² / 2) · [1 / (R² + (z + d/2)²)^(3/2) + 1 / (R² + (z - d/2)²)^(3/2)]
```

Розкладемо функцію `B_total(z)` у ряд Тейлора біля центральної точки `z = 0`:

```
B_total(z) = B(0) + (1/2!) · B''(0) · z² + (1/4!) · B''''(0) · z⁴ + ...
```

Завдяки симетрії системи перша похідна `B'(0) = 0` та всі непарні похідні дорівнюють нулю для будь-якої відстані `d`.

Обчислимо другу похідну `B''(z)` у точці `z = 0`:

```
B''(0) = (3 · μ₀ · I · R² / 2) · (4·d² - R²) / (R² + d²/4)^(7/2)   [диференціювання виразу по z]
```

Прирівнюючи другу похідну до нуля `B''(0) = 0`, отримуємо умову обнулення:

```
4·d² - R² = 0  =>  d = R                                           [розв'язок алгебраїчного рівняння]
```

При відстані між котушками `d = R` одночасно обнуляються і перша, і друга, і третя похідні поля за координатою `z` (`B'(0) = 0`, `B''(0) = 0`, `B'''(0) = 0`). Першим ненульовим членом розкладу Тейлора стає лише четверта похідна `z⁴`, що забезпечує винятково плоский платоподібний профіль однорідності магнітного поля поблизу центра системи.
