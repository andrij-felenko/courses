# 🧮 Математичний вивід диференціальної форми та симетрії закону Ампера

Ця математична вставка містить строге виведення фундаментальної еквівалентності між інтегральною та диференціальною формами закону Ампера, а також пряме векторне виведення диференціального рівняння `∇ × B = μ₀ · J` з первинного диференціального закону Біо — Савара для магнетостатичних полів у тривимірному евклідовому просторі `ℝ³`.

---

## 1. Перехід від інтегральної до диференціальної форми через теорему Стокса

Розглянемо математичний апарат диференціальних форм і векторного аналізу, що пов'язує циркуляцію векторного поля з його локальною ротаційною густиною (ротором).

Нехай `L` — довільний гладкий або шматочно-гладкий замкнений орієнтований контур у тривимірному просторі, а `S` — довільна двовимірна орієнтована поверхня, край якої збігається з контуром `L` (тобто `∂S = L`). Позитивний напрямок нормалі `n` до поверхні `S` узгоджено з напрямком обходу контуру `L` за правилом правого гвинта.

Інтегральний закон Ампера для стаціонарного електричного струму стверджує, що циркуляція магнітного поля вздовж контуру `L` дорівнює добутку магнітної сталої `μ₀` на сумарний охоплений струм:

```
∮_L B · dl = μ₀ · I_охоп
```

Повний електричний струм `I_охоп`, що протікає через поверхню `S`, за визначенням виражається через поверхневий інтеграл від вектора густини струму `J`:

```
I_охоп = ∬_S J · dS = ∬_S (J · n) dS
```

За математичною **теоремою Стокса**, криволінійний інтеграл другого роду від гладкого векторного поля `B` вздовж замкненого контуру `L` тотожно дорівнює поверхневому інтегралу від ротора (*curl*) цього поля по поверхні `S`, що спирається на контур `L`:

```
∮_L B · dl = ∬_S (∇ × B) · dS
```

Зіставивши теорему Стокса із формулюванням закону Ампера, отримуємо рівність двох поверхневих інтегралів:

```
∬_S (∇ × B) · dS = μ₀ · ∬_S J · dS
```

Перенесемо обидва доданки в один бік і об'єднаємо під одним знаком поверхневого інтеграла:

```
∬_S ( (∇ × B) − μ₀ · J ) · dS = 0
```

Оскільки це рівняння має виконуватися для **довільного** вибору замкненого контуру `L` та **довільної** вимірюваної поверхні `S`, натягнутої на цей контур, підінтегральний векторний вираз у кожній точці простору повинен тотожно дорівнювати нулю. 

Звідси строго випливає локальна **диференціальна форма закону Ампера**:

```
∇ × B = μ₀ · J                      [диференціальна форма закону Ампера]
```

Цей результат означає, що значення ротора магнітної індукції у будь-якій локальній точці простору повністю визначається лише значенням густини електричного струму у цій самій точці.

## 2. Пряме векторне виведення з диференціального закону Біо — Савара

Доведемо рівняння `∇ × B = μ₀ · J` безпосередньо з інтеграла Біо — Савара для неперервного об'ємного розподілу струмів, не спираючись на інтегральну форму закону Ампера як на вихідне припущення.

Вектор магнітної індукції `B(r)` у точці спостереження `r = (x, y, z)`, створений об'ємним розподілом струму з густиною `J(r')` у точках джерела `r' = (x', y', z')`, виражається об'ємним інтегралом по всій області зайнятій струмами `V'`:

```
B(r) = (μ₀ / (4·π)) · ∭_V' ( J(r') × (r − r') / |r − r'|³ ) dV'
```

Скористаємося векторним співвідношенням для градієнта оберненої відстані між точкою спостереження `r` та точкою джерела `r'`:

```
∇ ( 1 / |r − r'| ) = − (r − r') / |r − r'|³
```

де оператор Набла `∇` діє виключно за координатами точки спостереження `r = (x, y, z)`, тоді як змінними інтегрування є штриховані координати джерела `r' = (x', y', z')`.

Перепишемо вираз для магнітної індукції через градієнт оберненої відстані:

```
B(r) = − (μ₀ / (4·π)) · ∭_V' ( J(r') × ∇( 1 / |r − r'| ) ) dV'
     = (μ₀ / (4·π)) · ∭_V' ∇ × ( J(r') / |r − r'| ) dV'
```

Тут ми використали векторну тотожність `∇ × (f · A) = f · (∇ × A) + (∇ f) × A` та врахували, що вектор `J(r')` не залежить від нештрихованих координат `r`, тому `∇ × J(r') ≡ 0`.

Тепер застосуємо оператор ротора `∇ ×` за координатами точки спостереження до обох частин рівняння:

```
∇ × B(r) = (μ₀ / (4·π)) · ∇ × ( ∇ × ∭_V' ( J(r') / |r − r'| ) dV' )
```

Оскільки інтегрування виконується за координатами `r'`, а диференціювання за координатами `r`, ми можемо внести оператори подвійного ротора під знак об'ємного інтеграла. Скористаємося фундаментальною векторною тотожністю для подвійного ротора довільного векторного поля `A`:

```
∇ × (∇ × A) = ∇(∇ · A) − ∇² A
```

Поклавши `A(r) = J(r') / |r − r'|`, підставимо цю тотожність під знак інтеграла:

```
∇ × B(r) = (μ₀ / (4·π)) · ∇ ( ∭_V' J(r') · ∇( 1 / |r − r'| ) dV' )
           − (μ₀ / (4·π)) · ∭_V' J(r') · ∇²( 1 / |r − r'| ) dV'
```

Розглянемо та обчислимо обидва доданки послідовно.

---

### 2.1. Доведення обнулення першого доданка (Дивергентний член)

Розглянемо підінтегральний вираз першого доданка. Оскільки диференціювання за нештрихованими координатами та за штрихованими координатами пов'язані співвідношенням `∇( 1 / |r − r'| ) = −∇'( 1 / |r − r'| )`, перепишемо градієнт:

```
∭_V' J(r') · ∇( 1 / |r − r'| ) dV' = − ∭_V' J(r') · ∇'( 1 / |r − r'| ) dV'
```

Застосуємо формулу дивергенції добутку скаляра на вектор `∇' · (f · J) = f · (∇' · J) + J · (∇' f)`:

```
− ∭_V' J(r') · ∇'( 1 / |r − r'| ) dV' = − ∭_V' ∇' · ( J(r') / |r − r'| ) dV' + ∭_V' ( ∇' · J(r') ) / |r − r'| dV'
```

1. **Перший інтеграл** за теоремою Остроградського — Гаусса перетворюється на поверхневий інтеграл по зовнішній межі `∂V'` області джерел:

```
∭_V' ∇' · ( J(r') / |r − r'| ) dV' = ∬_∂V' ( J(r') / |r − r'| ) · dS'
```

Оскільки об'єм `V'` можна обрати достатньо великим, щоб увесь струм був зосереджений усередині нього, на межі `∂V'` густина струму дорівнює нулю (`J(r') = 0`), отже поверхневий інтеграл тотожно обнуляється.

2. **Другий інтеграл** містить дивергенцію густини струму `∇' · J(r')`. За умовою стаціонарності магнетостатичного поля та закону збереження електричного заряду, дивергенція стаціонарного струму тотожно дорівнює нулю (`∇' · J(r') ≡ 0`).

Таким чином, перший доданок у виразі для `∇ × B` повністю і тотожно дорівнює нулю!

---

### 2.2. Обчислення другого доданка (Лапласіан та Дельта-функція)

У другому доданку присутній оператор Лапласа `∇²` від оберненої відстані. З математичної фізики та теорії узагальнених функцій відомо фундаментальне співвідношення для лапласіана кулонівського потенціалу через тривимірну дельта-функцію Дірака `δ(r − r')`:

```
∇² ( 1 / |r − r'| ) = −4·π · δ(r − r')
```

Підставимо це вираження у другий доданок:

```
∇ × B(r)
= − (μ₀ / (4·π)) · ∭_V' J(r') · ( −4·π · δ(r − r') ) dV'     [підстановка лапласіана через дельта-функцію]
= μ₀ · ∭_V' J(r') · δ(r − r') dV'                             [скорочення коефіцієнта 4·π]
= μ₀ · J(r)                                                 [властивість фільтрації дельта-функції Дірака]
```

Отже, доведено, що з закону Біо — Савара математично безумовно випливає диференціальне рівняння Ампера:

```
∇ × B = μ₀ · J
```

## 3. Оператор ротора у циліндричних координатах та поле всередині провідника

У практичних інженерних та фізичних задачах з циліндричною симетрією (круглі провідники, коаксіальні кабелі, соленоїди) застосовується циліндрична система координат `(r, θ, z)`.

Векторний оператор ротора `∇ × A` у циліндричній системі координат виражається через компоненти `(A_r, A_θ, A_z)` наступним чином:

```
(∇ × A)_r = (1 / r) · (∂A_z / ∂θ) − (∂A_θ / ∂z)

(∇ × A)_θ = (∂A_r / ∂z) − (∂A_z / ∂r)

(∇ × A)_z = (1 / r) · (∂ / ∂r)(r · A_θ) − (1 / r) · (∂A_r / ∂θ)
```

### Застосування до товстого провідника з нерівномірним струмом

Розглянемо циліндричний провідник радіуса `R`, орієнтований уздовж осі `z`, яким протікає струм із нерівномірним параболічним розподілом густини струму `J_z(r) = J_0 · (1 − r² / R²)`.

За симетрією системи магнітне поле має лише тангенціальну компоненту `B_θ(r)`, що залежить тільки від радіуса `r` (`B_r = 0`, `B_z = 0`).

Тоді єдиною ненульовою компонентою ротора поля є `z`-компонента:

```
(∇ × B)_z = (1 / r) · (d / dr)(r · B_θ(r))
```

Підставимо це у диференціальний закон Ампера `(∇ × B)_z = μ₀ · J_z(r)`:

```
(1 / r) · (d / dr)(r · B_θ(r)) = μ₀ · J_0 · (1 − r² / R²)
```

Помножимо обидві частини на `r` та проінтегруємо по `r` від `0` до `r`:

```
d / dr (r · B_θ(r)) = μ₀ · J_0 · (r − r³ / R²)

r · B_θ(r) = μ₀ · J_0 · ∫₀^r (r' − r'³ / R²) dr'
           = μ₀ · J_0 · ( r² / 2 − r⁴ / (4 · R²) )
```

Поділивши на `r`, отримуємо точний аналітичний розподіл магнітного поля всередині провідника з параболічним струмом:

```
B_θ(r) = μ₀ · J_0 · r · ( 1/2 − r² / (4 · R²) )
```

Цей приклад демонструє, як диференціальна форма закону Ампера дозволяє легко знаходити розподіл магнітного поля для складних нерівномірних розподілів струму, де пряме застосування інтегральної форми було б ускладненим.
