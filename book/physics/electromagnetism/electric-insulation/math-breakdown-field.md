# 🧮 Математична модель розподілу поля та пробою ізоляції

Розрахунок надійності електричної ізоляції базується на математичному моделюванні розподілу напруженості електричного поля в об'ємі діелектрика та аналізі критеріїв його електричного і теплового пробою. Фізичний стан ізолятора визначається рівнянням Лапласа для скалярного потенціалу, геометричною конфігурацією провідників та характеристиками матеріалу під дією електричного і теплового навантажень.

## Рівняння поля у коаксіальному діелектричному шарі

Для циліндричного провідника радіуса `r_1`, оточеного однорідним ізоляційним шаром із зовнішнім радіусом `r_2` та покритим заземленим екраном, скалярний електричний потенціал `φ(r)` за відсутності об'ємного вільного заряду задовольняє рівняння Лапласа в циліндричних координатах:

```
∇² φ = 0
```

З огляду на осьову та осьово-симетричну геометрію кабелю, потенціал залежить лише від радіальної координати `r`. У радіальній формі рівняння Лапласа набуває вигляду:

```
(1 / r) · (d / dr) (r · (dφ / dr)) = 0
```

Множення обох частин на `r` при `r ≠ 0` дає:

```
(d / dr) (r · (dφ / dr)) = 0
```

Інтегрування цього виразу за координатою `r` приводить до першої константи інтегрування `C_1`:

```
r · (dφ / dr) = C_1            [перше інтегрування рівняння Лапласа]
dφ / dr = C_1 / r              [ділення на радіус r]
```

Зв'язок між вектором напруженості електричного поля `E(r)` та градієнтом потенціалу задається співвідношенням `E(r) = -dφ / dr`. Звідси напрямок радіальної напруженості становить:

```
E(r) = -C_1 / r
```

Повторне інтегрування виразу для `dφ / dr` визначає розподіл потенціалу `φ(r)`:

```
φ(r) = ∫ (C_1 / r) dr
= C_1 · ln(r) + C_2            [друге інтегрування]
```

Значення констант `C_1` та `C_2` знаходяться з крайових умов на межах діелектрика. На поверхні внутрішнього провідника `r = r_1` потенціал дорівнює напрузі джерела `U`, а на зовнішньому екрані `r = r_2` потенціал дорівнює нулю:

```
φ(r_1) = C_1 · ln(r_1) + C_2 = U [крайова умова на внутрішній жилі]
φ(r_2) = C_1 · ln(r_2) + C_2 = 0 [крайова умова на зовнішньому екрані]
```

Віднімання другого рівняння від першого виключає константу `C_2`:

```
C_1 · ln(r_1) - C_1 · ln(r_2) = U
C_1 · (ln(r_1) - ln(r_2)) = U    [винесення C_1 за дужки]
C_1 · ln(r_1 / r_2) = U          [властивість логарифма: ln(a) - ln(b) = ln(a/b)]
-C_1 · ln(r_2 / r_1) = U         [перевертання аргументу: ln(a/b) = -ln(b/a)]
C_1 = -U / ln(r_2 / r_1)         [визначення константи C_1]
```

Підстановка знайденої константи `C_1` у формулу для напруженості поля `E(r) = -C_1 / r` дає остаточний розподіл напруженості електричного поля по товщині ізоляції:

```
E(r) = -(-U / ln(r_2 / r_1)) / r
= U / (r · ln(r_2 / r_1))        [остаточний розподіл поля E(r)]
```

Напруженість досягає свого абсолютного максимуму `E_max` на поверхні внутрішнього провідника при `r = r_1`:

```
E_max = U / (r_1 · ln(r_2 / r_1))
```

Мінімальне значення напруженості `E_min` спостерігається біля зовнішнього заземленого екрана при `r = r_2`:

```
E_min = U / (r_2 · ln(r_2 / r_1))
```

Співвідношення між максимальним та мінімальним полем у шарі діелектрика становить:

```
E_max / E_min = r_2 / r_1
```

## Поле у двошаровій концентричній ізоляції

Якщо ізоляційний шар складається з двох різних діелектриків із проміжним радіусом межі розділу `r_m`, відносними проникностями `ε_1` (внутрішній шар) та `ε_2` (зовнішній шар), граничні умови вимагають неперервності нормальної компоненти вектора електричного зсуву `D_r1 = D_r2`:

```
ε_0 · ε_1 · E_1(r_m) = ε_0 · ε_2 · E_2(r_m)
ε_1 · E_1(r_m) = ε_2 · E_2(r_m)
```

Звідси випливає, що напруженості поля у двох шарах зв'язані співвідношенням:

```
E_1(r) = C / (ε_1 · r)
E_2(r) = C / (ε_2 · r)
```

Інтегрування напруженості по двох шарах визначає загальну прикладну напругу `U`:

```
U = ∫ [r_1 to r_m] E_1(r) dr + ∫ [r_m to r_2] E_2(r) dr
= (C / ε_1) · ln(r_m / r_1) + (C / ε_2) · ln(r_2 / r_m)
```

Константа `C` виражається через напругу `U`:

```
C = U / ((1 / ε_1) · ln(r_m / r_1) + (1 / ε_2) · ln(r_2 / r_m))
```

Отже, напруженість поля на поверхні внутрішньої жили становить:

```
E_max = U / (ε_1 · r_1 · ((1 / ε_1) · ln(r_m / r_1) + (1 / ε_2) · ln(r_2 / r_m)))
```

Цей результат використовується при градієнтному конструюванні високовольтних кабелів: вибираючи внутрішній шар із вищою проникністю `ε_1 > ε_2`, можна суттєво зменшити питому напруженість поля `E_max` біля жили.

## Розподіл поля у сферичній геометрії електродів

Для порівняльного аналізу розлянемо сферичний ізолятор, у якому сферичний провідник радіуса `r_1` оточений сферичним ізолюючим шаром із зовнішнім радіусом `r_2`. Рівняння Лапласа в сферичних координатах за відсутності кутової залежності має вигляд:

```
(1 / r²) · (d / dr) (r² · (dφ / dr)) = 0
(d / dr) (r² · (dφ / dr)) = 0
```

Інтегрування дає:

```
r² · (dφ / dr) = C_1
dφ / dr = C_1 / r²
E(r) = -C_1 / r²
```

Після другого інтегрування та застосування крайових умов `φ(r_1) = U`, `φ(r_2) = 0` вираз для напруженості поля сферичного ізолятора набуває вигляду:

```
E_sphere(r) = (U · r_1 · r_2) / (r² · (r_2 - r_1))
```

Максимальна напруженість на поверхні внутрішньої сфери при `r = r_1` дорівнює:

```
E_max_sphere = (U · r_2) / (r_1 · (r_2 - r_1))
```

Порівняння з циліндричною геометрією показує, що сферична конфігурація демонструє значно крутіше спадання поля пропорційно `1 / r²` (на відміну від `1 / r` у циліндрі), що спричиняє вищу локальну концентрацію напруженості поля `E_max` при аналогічних радіусах.

У плоских паралельних електродах товщиною `d` напруженість є однорідною по всій товщині: `E_flat = U / d`. Порівнюючи три конфігурації при однаковій товщині ізоляції `d = r_2 - r_1`, спостерігаємо найвищу напруженість у сферичній геометрії, проміжну в циліндричній і найнижчу в плоскій.

## Оптимізація геометрії кабелю за критерієм мінімуму E_max

Під час проектирования високовольтних кабелів та вводів виникає задача: при фіксованому зовнішньому радіусі ізоляції `r_2` та заданій робочій напрузі `U` підібрати радіус внутрішньої жили `r_1` так, щоб питома електрична напруженість на поверхні жили `E_max` була мінімальною.

Для пошуку екстремуму знайдемо похідну `E_max` за змінною `r_1` та прирівняємо її до нуля:

```
E_max(r_1) = (U / ln(r_2 / r_1)) · (1 / r_1)
```

Застосуємо правило диференціювання частки `d/dx (1 / f(x)) = -f'(x) / (f(x))²`, де `f(r_1) = r_1 · ln(r_2 / r_1)`:

```
d E_max / d r_1 = -U · (d/d r_1 [r_1 · ln(r_2 / r_1)]) / (r_1 · ln(r_2 / r_1))²
```

Знайдемо похідну добутку `d/d r_1 [r_1 · ln(r_2 / r_1)]`:

```
d/d r_1 [r_1 · ln(r_2 / r_1)]
= 1 · ln(r_2 / r_1) + r_1 · (d/d r_1 [ln(r_2) - ln(r_1)]) [диференціювання за добутком]
= ln(r_2 / r_1) + r_1 · (0 - 1 / r_1)                      [похідна ln(r_1) дорівнює 1/r_1]
= ln(r_2 / r_1) - 1                                        [спрощення r_1 · (1/r_1) = 1]
```

Прирівнюючи похідну до нуля, отримуємо умову оптимальності:

```
ln(r_2 / r_1) - 1 = 0
ln(r_2 / r_1) = 1                [перенос одиниці]
r_2 / r_1 = e¹                   [потенціювання за основою е]
r_2 / r_1 = e ≈ 2.71828          [оптимальне геометричне співвідношення]
```

Отже, для мінімізації напруженості поля на поверхні провідника зовнішній радіус ізоляції має бути більшим за радіус внутрішнього провідника в `e` разів (приблизно в 2.718 раза). При цьому мінімально можлива напруженість поля становить:

```
E_max_opt = U / (r_1 · 1) = U / r_1 = e · U / r_2
```

## Теплова стійкість та критерій теплового пробою

Під дією змінної напруги з частотою `ω = 2 · π · f` в об'ємі діелектрика виділяється теплова потужність внаслідок наскрізного струму провідності та явищ дипольної поляризації. Об'ємна густина теплових втрат `q_v` (Вт/м³) визначається виразом:

```
q_v = E² · σ_eff
= E² · (σ_dc + ω · ε_0 · ε_r · tan(δ))
```

Тут `σ_dc` — питома електрична провідність постійного струму, `ε_0 ≈ 8.854 · 10⁻¹²` Ф/м — електрична стала, `ε_r` — відносна діелектрична проникність, `tan(δ)` — тангенс кута діелектричних втрат.

Експоненціальна залежність питомої провідності та втрат від температури `T` описується законом Арреніуса-Фреліха:

```
σ_eff(T) = σ_0 · exp(α · (T - T_0))
```

де `α` — температурний коефіцієнт зростання провідності (K⁻¹), `T_0` — початкова температура навколишнього середовища.

Виділення тепла `Q_gen(T)` в об'ємі ізоляції та тепловідведення `Q_dis(T)` у навколишнє середовище через коефіцієнт теплопередачі `k_th` задовольняють системи:

```
Q_gen(T) = V_ins · E² · σ_0 · exp(α · (T - T_0))
Q_dis(T) = k_th · A_surf · (T - T_0)
```

Теплова рівновага можлива лише доти, доки крива генерації тепла перетинається з прямою тепловідведення. Гранична критична напруга теплового пробою `U_th` визначається умовою дотику цих функцій `d Q_gen / d T = d Q_dis / d T`:

```
d/dT [V_ins · E² · σ_0 · exp(α · (T - T_0))] = k_th · A_surf
α · Q_gen(T_crit) = k_th · A_surf
```

Звідси критичний температурний перегрів перед тепловим вибухом становить:

```
ΔT_crit = T_crit - T_0 = 1 / α
```

Якщо температура ізоляції перевищує критичне значення `T_0 + 1 / α`, швидкість генерації тепла неминуче перевищує максимальну здатність конструкції до охолодження. Це викликає лавиноподібне саморозігрівання, плавлення та обвуглення діелектрика — тепловий пробій.
