### Фізичний коментар до табличних даних

Табличні дані наочно ілюструють фундаментальний фізичний принцип: час релаксації заряду визначається перш за все провідністю `σ`, тоді як діелектрична проникність `ε` змінюється у відносно вузьких межах (від 1 до 80).

У металах зверхвисока провідність забезпечує аттосекундний час розсмоктування, що гарантує відсутність внутрішнього об'ємного заряду в стаціонарних умовах. У напівпровідниках час релаксації пропорційний концентрації носіїв заряду, змінюючись від пікосекунд у легованому кремнії до сотень наносекунд у власному. У полімерах та високоомних діелектриках (наприклад, фторопласті) зверхнизька провідність створює часи релаксації порядку місяців, що пояснює їхню здатність довго утримувати статики.

У розрахунках слід враховувати температурну залежність: провідність рідин та діелектриків зростає з підвищенням температури, що пропорційно скорочує час релаксації `τ_m`.

## 2. Нормативні класифікації антистатичних матеріалів (IEC 61340 / ANSI ESD S20.20)

Згідно з міжнародними стандартами електростатичного захисту в електронній промисловості, матеріали класифікуються за поверхневим опором `R_s` (Ом/кв) та часом стекання заряду `t_decay` від `1000 В` до `100 В` (`10%` від початкового):

```
       10²          10⁵          10¹¹ (Ом/кв)
───|────────────|────────────|────────────|───> Поверхневий опір R_s
   Провідні     Розсіювальні    Ізоляційні
 (Conductive)   (Dissipative)   (Insulative)
```

1. **Провідні матеріали (Conductive):**
   - Поверхневий опір: `R_s < 10⁵ Ом/кв`.
   - Час релаксації: `τ_m < 1 мкс`.
   - Фізична поведінка: Заряд розряджається практично миттєво.
   - Застосування: Заземлювальні шини, антистатичні браслети, провідна тара для транспортування чутливих плата.

2. **Статично розсіювальні матеріали (Static Dissipative):**
   - Поверхневий опір: `10⁵ Ом/кв ≤ R_s < 10¹¹ Ом/кв`.
   - Час релаксації / час зливу: `1 мс ≤ t_decay ≤ 2.0 с`.
   - Фізична поведінка: Заряд стікає плавно, без утворення високоамплітудних спалахів струму.
   - Застосування: Робочі поверхні столів ESD, килимки, покриття підлоги, одяг операторів та антистатичні пакети.

3. **Ізоляційні матеріали (Insulative):**
   - Поверхневий опір: `R_s ≥ 10¹¹ Ом/кв`.
   - Час релаксації: `τ_m > 100 с` (до місяців).
   - Фізична поведінка: Заряд зберігається тривалий час і створює високі статичні потенціали.
   - Застосування: Стандартний пластик (акрил, ПВХ без модифікаторів). Заборонені в зонах EPA (ESD Protected Area).

## 3. Норми безпеки при перекачуванні нафтопродуктів (ASTM D4865 / NFPA 77)

При заправці літаків та транспортуванні палива діють суворі технологічні обмеження на питому провідність `σ` для запобігання пожежам та вибухам:

- **Мінімальна безпечна провідність палива:** `σ_min = 50 pSm/m` (`5.0 × 10⁻¹¹ См/м`).
- **Відповідний максимум часу релаксації:** `τ_max = (2.0 · 8.854 × 10⁻¹²) / (5.0 × 10⁻¹¹) = 0.354 с`.
- **Мінімальний час відстою у релаксаційній ємності:** `t_rest ≥ 100 · τ_m ≈ 30 ... 100 с` перед впорскуванням палива у резервуар.

## 4. Лабораторні методи вимірювання та діагностичні стандарти

Експериментальне вимірювання часу релаксації `τ_m` та стекання заряду у промислових матеріалах проводиться за допомогою спеціалізованого метрологічного обладнання відповідно до міжнародних стандартів.

Для статично розсіювальних матеріалів основним методом перевірки є використання **монітора зарядженої пластини (Charge Plate Monitor, CPM)** відповідно до IEC 61340-4-1. Тестова металева пластина ємністю `20 пФ` заряджається високовольтним джерелом до потенціалу `+1000 В` або `-1000 В`. Після відключення джерела пластина контактує з досліджуваним матеріалом, і безконтактний електрометр реєструє графік спаду напруги `V(t)`. За графіком визначається час стекання `t_decay` (від `1000 В` до `100 В`). Якщо `t_decay ≤ 2.0 с`, матеріал визнається повністю придатним для ESD-захищених зон (EPA).

Для рідин та рідких нафтопродуктів вимірювання проводиться у лабораторній комірці за допомогою **коаксіального вимірювача провідності (ASTM D2624)**. Паливо випробовується на низькій частоті (`10 Гц ... 1 кГц`) під постійною напругою `10 В` для виключення явищ поляризації електродів. Якщо виміряна провідність `σ < 50 pSm/m`, додавання антистатичних компонентів вважається обов'язковим технічним регламентом перед подачею палива у магістральний паливопровід.

## 5. Розрахункові приклади та числові інженерні кейси

Для практичного використання API наведемо два характерних інженерних розрахунки:

1. **Розрахунок часу розрядки людини в ESD-зоні:**
   Припустимо, що оператор має на собі потенціал `V_initial = 5000 В`. Дозволений залишковий потенціал для роботи з чутливою компонентою становить `V_target = 50 В`. Робоче покриття підлоги виготовлено зі статично розсіювального матеріалу з провідністю `σ = 2.0 × 10⁻⁷ См/м` та проникністю `ε_r = 4.0`.
   Виклик `cr_calculate_esd_decay_time` дає:
   - `τ_m = (4.0 × 8.854 × 10⁻¹²) / (2.0 × 10⁻⁷) = 0.177 мс`.
   - `t_decay = 0.177 мс × ln(5000 / 50) = 0.177 мс × ln(100) ≈ 0.815 мс`.
   Отриманий час стекання (`< 1 мс`) гарантує повну безпеку оператора під час роботи.

2. **Розрахунок міжфазного заряду у двошаровому конденсаторі:**
   Конденсатор складається з шару скла (`εr1 = 6.0`, `σ1 = 10⁻¹² См/м`, `d1 = 1 мм`) та шару полімеру (`εr2 = 2.5`, `σ2 = 10⁻¹⁴ См/м`, `d2 = 1 мм`). При прикладенні напруги `V0 = 1000 В` виклик `cr_calculate_maxwell_wagner` розраховує:
   - Час міжфазної релаксації `τ_MW ≈ 5.75 с`.
   - Стаціонарний міжфазний заряд `σ_f(∞) ≈ 4.82 × 10⁻⁵ Кл/м²`.

## 6. Специфікація програмного інтерфейсу (API) розрахункового модуля

Нижче наведено специфікацію C та C++ API бібліотеки `charge_relaxation_calc` для інженерного розрахунку часу релаксації, зливу статичного заряду та параметрів міжфазного шару Максвелла-Вагнера.

Обчислювальний модуль забезпечує високу точність розрахунків, підтримує обробку помилок (нульова провідність, від'ємні товщини) та розроблений для застосування у промислових симуляторах.

```cpp
//
// charge_relaxation_api.hpp — C++20 API розрахунку параметрів релаксації
//

#ifndef CHARGE_RELAXATION_API_HPP
#define CHARGE_RELAXATION_API_HPP

#include <cmath>
#include <expected>
#include <system_error>
#include <string_view>

namespace physics::electromagnetism {

inline constexpr double EPSILON_0 = 8.854187817e-12;

enum class RelaxationError {
    InvalidParam,
    ZeroConductivity,
    NegativeThickness
};

struct Material {
    double relative_permittivity{1.0};
    double conductivity_sm_per_m{0.0};
};

struct RelaxationMetrics {
    double tau_maxwell_seconds;
    double half_life_seconds;
    double decay_99_percent_seconds;
};

struct MaxwellWagnerMetrics {
    double tau_mw_seconds;
    double interface_charge_density_c_per_m2;
};

class ChargeRelaxationCalculator {
public:
    [[nodiscard]] static std::expected<RelaxationMetrics, RelaxationError>
    calculate_relaxation(const Material& mat) noexcept {
        if (mat.conductivity_sm_per_m <= 0.0 || mat.relative_permittivity <= 0.0) {
            return std::unexpected(RelaxationError::ZeroConductivity);
        }

        const double eps = mat.relative_permittivity * EPSILON_0;
        const double tau = eps / mat.conductivity_sm_per_m;
        const double half_life = tau * std::log(2.0);
        const double decay_99 = tau * std::log(100.0);

        return RelaxationMetrics{
            .tau_maxwell_seconds = tau,
            .half_life_seconds = half_life,
            .decay_99_percent_seconds = decay_99
        };
    }

    [[nodiscard]] static std::expected<double, RelaxationError>
    calculate_esd_decay_time(const Material& mat, double v_initial, double v_target) noexcept {
        if (v_initial <= 0.0 || v_target <= 0.0 || v_target >= v_initial) {
            return std::unexpected(RelaxationError::InvalidParam);
        }

        auto res = calculate_relaxation(mat);
        if (!res) return std::unexpected(res.error());

        return res->tau_maxwell_seconds * std::log(v_initial / v_target);
    }

    [[nodiscard]] static std::expected<MaxwellWagnerMetrics, RelaxationError>
    calculate_maxwell_wagner(const Material& mat1, double d1,
                             const Material& mat2, double d2,
                             double voltage) noexcept {
        if (d1 <= 0.0 || d2 <= 0.0) {
            return std::unexpected(RelaxationError::NegativeThickness);
        }
        if (mat1.conductivity_sm_per_m < 0.0 || mat2.conductivity_sm_per_m < 0.0) {
            return std::unexpected(RelaxationError::ZeroConductivity);
        }

        const double eps1 = mat1.relative_permittivity * EPSILON_0;
        const double eps2 = mat2.relative_permittivity * EPSILON_0;

        const double denom_cond = mat1.conductivity_sm_per_m * d2 + mat2.conductivity_sm_per_m * d1;
        if (denom_cond <= 0.0) {
            return std::unexpected(RelaxationError::ZeroConductivity);
        }

        const double tau_mw = (eps1 * d2 + eps2 * d1) / denom_cond;
        const double sigma_f = voltage * (mat1.conductivity_sm_per_m * eps2 - mat2.conductivity_sm_per_m * eps1) / denom_cond;

        return MaxwellWagnerMetrics{
            .tau_mw_seconds = tau_mw,
            .interface_charge_density_c_per_m2 = sigma_f
        };
    }
};

} // namespace physics::electromagnetism

#endif // CHARGE_RELAXATION_API_HPP
```

## 7. Інтеграційні вказівки та обробка виняткових ситуацій

При використанні представленого API в інженерних проектах слід враховувати наступні правила:

1. **Валідація провідності:** Якщо провідність середовища дорівнює нулю (`σ = 0`), функція `calculate_relaxation` повертає помилку `ZeroConductivity`. На практиці для ідеальних діелектриків рекомендується задавати мінімальну провідність витікання (наприклад, `σ = 10⁻¹⁷ См/м`).
2. **Товщини шарів у моделі Максвелла-Вагнера:** Функція `calculate_maxwell_wagner` вимагає суворо додатних значень товщин `d1 > 0` та `d2 > 0`. При виявленні від'ємних чи нульових товщин повертається код помилки `NegativeThickness`.
3. **Потокобезпечність (Thread Safety):** Інтерфейсні функції є повністю статичними і не мають внутрішнього стану (stateless), що гарантує їхню безпечність для багатопотокових обчислень у сучасних C++20 середовищах.

Описаний API дозволяє інтегрувати модуль розрахунку релаксації в інженерні САПР системи трасування друкованих плат, засоби моделювання пожежної безпеки паливних резервуарів та системи контролю ESD-захисту в сучасній мікроелектроніці.
