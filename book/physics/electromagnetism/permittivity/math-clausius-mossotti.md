# 🧮 Мікроскопічна теорія: виведення рівняння Клаузіуса — Моссотті та комплексна проникність

Ця вставка містить детальний математичний вивід зв'язку між мікроскопічною поляризованістю атомів і макроскопічною діелектричною проникністю середовища (локальне поле Лоренца, теорія Онсагера та рівняння Клаузіуса — Моссотті), а також строгий аналіз кінетики діелектричної релаксації Дебая, комплексної проникності, діаграм Коул — Коула та енергії електричного поля у середовищі.

### 1. Виведення локального поля Лоренца

У макроскопічній електродинаміці середнє електричне поле в діелектрику дорівнює `E`. Проте дійсне поле `E_loc`, яке діє на окремо взяту молекулу в точці її розташування, відрізняється від макроскопічного `E`, оскільки власне поле цієї молекули не діє на неї саму, а ближні сусідні молекули створюють сильний дискретний мікрорельеф поля.

Для розрахунку `E_loc` за методом Лоренца умовно вирізають навколо вибраної молекули сферичну порожнину радіусом `R`, який набагато більший за міжмолекулярну відстань, але малий у макроскопічному масштабі. Сумарне локальне поле подають як суму чотирьох внесків:

```
E_loc = E_ext + E₁ + E₂ + E₃
```

де:
* `E_ext` — зовнішнє поле, створене вільними зарядами на електродах;
* `E₁` — поле зв'язаних зарядів на зовнішніх поверхнях діелектрика;
* `E₂` — поле зв'язаних зарядів, що виникають на внутрішній поверхні уявної сфери Лоренца;
* `E₃` — поле дискретних диполів усередині самої сфери.

Сума `E_ext + E₁` за визначенням дорівнює макроскопічному середньому полю `E` у середовищі.

#### Доказ обнулення поля внутрішніх диполів E₃
Електричне поле, створене у центрі сфери диполем `p⃗_k`, розташованим у точці `r⃗_k`, описується тензором диполь-дипольної взаємодії:

```
E⃗_k = (1 / (4·π·ε₀)) · (3·(p⃗_k · r⃗_k)·r⃗_k - r_k² · p⃗_k) / r_k⁵
```

Для кубічної кристалічної ґратки (проста кубічна, гранецентрована чи об'ємноцентрована) або абсолютно хаотичного розподілу частинок у рідині чи газі сумування по всіх вузлах усередині сфери дає строго нульовий результат завдяки просторовій симетрії та парності інтегралів:

```
E₃ = ∑_k E⃗_k = 0                         [симетрія кубічної ґратки / ізотропного середовища]
```

#### Розрахунок поверхневого поля сфери E₂
Поле `E₂` розраховують інтегруванням поверхневої густини зв'язаного заряду `σ_b = -P · cos θ` по внутрішній поверхні сфери радіуса `R`. Елемент площі сфери дорівнює `dA = 2·π·R² · sin θ dθ`. Елементарне поле вздовж осі поля становить:

```
dE₂ = (1 / (4·π·ε₀)) · (-σ_b · dA / R²) · cos θ                          [закон Кулона для поверхневого елемента]
    = (1 / (4·π·ε₀)) · (P · cos θ / R²) · (2·π·R² · sin θ dθ) · cos θ   [підстановка σ_b = P·cos(θ) та dA = 2πR²sin(θ)dθ]
    = (P / (2·ε₀)) · cos² θ · sin θ dθ                                 [скорочення R² та 2π/4π = 1/2]
```

Здійснюємо інтегрування по куту `θ` від `0` до `π`:

```
E₂ = (P / (2·ε₀)) · ∫₀ᵖⁱ cos² θ · sin θ dθ
   = (P / (2·ε₀)) · [-cos³ θ / 3]₀ᵖⁱ      [інтегрування за кутом θ]
   = (P / (2·ε₀)) · (1/3 - (-1/3))
   = P / (3·ε₀)                          [результат інтегрування по сферичній поверхні]
```

Таким чином, **локальне поле Лоренца** (*Lorentz local field*) дорівнює:

```
E_loc = E + P / (3·ε₀)
```

### 2. Строгий вивід рівняння Клаузіуса — Моссотті

Дипольний момент окремої молекули `p` прямо пропорційний локальному полю:

```
p = α · E_loc
```

де `α` — коефіцієнт мікроскопічної поляризованості. Поляризація одиниці об'єму `P` за концентрації молекул `N` становить:

```
P = N · p = N · α · E_loc
```

Підставляємо значення `E_loc` з виразу Лоренца:

```
P = N · α · (E + P / (3·ε₀))             [підстановка E_loc]
P · (1 - N·α / (3·ε₀)) = N · α · E        [групування членів з P]
P = (N · α · E) / (1 - N·α / (3·ε₀))
```

З іншого боку, з макроскопічного визначення електричної сприйнятливості `χₑ = εᵣ - 1`:

```
P = ε₀ · (εᵣ - 1) · E
```

Прирівнюємо обидва вирази для поляризації `P`:

```
ε₀ · (εᵣ - 1) · E = (N · α · E) / (1 - N·α / (3·ε₀))
ε₀ · (εᵣ - 1) = (N · α) / (1 - N·α / (3·ε₀))     [скорочення на поле E]
```

Ділимо обидві частини на `ε₀`:

```
εᵣ - 1 = (N · α / ε₀) / (1 - N·α / (3·ε₀))
```

Позначимо `y = N · α / (3·ε₀)`. Тоді рівняння набуває вигляду:

```
εᵣ - 1 = 3·y / (1 - y)
(εᵣ - 1) · (1 - y) = 3·y                 [множення на (1-y)]
εᵣ - 1 - y·εᵣ + y = 3·y
εᵣ - 1 = y · (εᵣ + 2)                    [зведення подібних членів з y]
y = (εᵣ - 1) / (εᵣ + 2)                  [вираження y через εᵣ]
```

Підставляючи назад `y = N · α / (3·ε₀)`, отримуємо класичне **рівняння Клаузіуса — Моссотті**:

```
(εᵣ - 1) / (εᵣ + 2) = (N · α) / (3 · ε₀)
```

Для оптичних частот, де `εᵣ ≈ n²` (за законом Максвелла для немагнітних середовищ `μᵣ = 1`), вираз перетворюється на **формулу Лоренца — Лоренца**:

```
(n² - 1) / (n² + 2) = (N · α_el) / (3 · ε₀)
```

де `n` — показник заломлення світла, а `α_el` — електронна поляризованість.

### 3. Модель Онсагера для густих полярних рідин

Рівняння Клаузіуса — Моссотті передбачає «діелектричну катастрофу»: при `N · α / (3·ε₀) = 1` значення `εᵣ` прямує до безкінечності, що означало б спонтанну поляризацію середовища. Для полярних рідин із великим дипольним моментом `μ` (наприклад, вода) формула давала абсурдні результати.

Ларс Онсагер (1936) розвів локальне поле на дві складові: **порожнинне поле** `G⃗` (*cavity field*) та **поле реакції** `R⃗` (*reaction field*).

Порожнинне поле утворюється зовнішніми джерелами у сферичній порожнині радіуса `a`:

```
G⃗ = (3·εᵣ / (2·εᵣ + 1)) · E⃗
```

Поле реакції створюється самим диполем `μ⃗`, який поляризує оточуючий діелектрик і створює зворотне поле в точці свого розташування:

```
R⃗ = (1 / (4·π·ε₀)) · (2·(εᵣ - 1) / (2·εᵣ + 1)) · (μ⃗ / a³)
```

Оскільки поле реакції `R⃗` завжди паралельне самому диполю `μ⃗`, воно не створює обертального моменту і не сприяє орієнтації диполя! Враховуючи лише порожнинне поле `G⃗` в орієнтаційному члені, Онсагер вивів рівняння для полярних рідин:

```
(εᵣ - ε_∞) · (2·εᵣ + ε_∞) / (εᵣ · (ε_∞ + 2)²) = (N · μ²) / (9 · ε₀ · k_B · T)
```

де `ε_∞ ≈ n²` — деформаційна (електронна + іонна) діелектрична проникність. Це рівняння точного описує діелектричні властивості води, спиртів та полярних розчинників без жодних штучних катастроф.

Фізична причина успіху моделі Онсагера полягає в тому, що вона чітко розрізняє внутрішнє поле, яке викликає пружну деформацію електронної хмари, та статистичне середовище, яке перешкоджає орієнтаційному повороту жорсткого диполя. Для неасоційованих полярних рідин (таких як хлороформ чи нітробензол) теорія Онсагера дає збіг із експериментальними значеннями `εᵣ` з точністю до 2–5%.

### 4. Динаміка релаксації Дебая та діаграми Коул — Коула

У змінному електричному полі `E(t) = E₀ · e^(i·ω·t)` часова зміна орієнтаційної поляризації `P_dip(t)` описується диференціальним рівнянням першого порядку:

```
dP_dip / dt = - (P_dip(t) - P_eq(t)) / τ
```

де `τ` — час діелектричної релаксації, а `P_eq(t) = ε₀ · (ε_s - ε_∞) · E(t)` — рівноважна поляризація.

Шукаємо розв'язок у вигляді `P_dip(t) = P₀ · e^(i·ω·t)`:

```
i · ω · P₀ = - (P₀ - ε₀ · (ε_s - ε_∞) · E₀) / τ
P₀ · (1 + i · ω · τ) = ε₀ · (ε_s - ε_∞) · E₀
P₀ = (ε₀ · (ε_s - ε_∞) · E₀) / (1 + i · ω · τ)
```

Додаючи деформаційний внесок `ε_∞`, отримуємо формулу **комплексної діелектричної проникності Дебая**:

```
ε(ω) = ε_∞ + (ε_s - ε_∞) / (1 + i · ω · τ)
```

Розділимо вираз на дійсну `ε'` та уявну `ε''` частини, помноживши чисельник і знаменник на сопряжене комплексне число `(1 - i·ω·τ)`:

```
ε(ω) = ε_∞ + (ε_s - ε_∞) · (1 - i · ω · τ) / (1 + ω² · τ²)
```

Звідси отримуємо рівняння дисперсії Дебая:

```
ε'(ω) = ε_∞ + (ε_s - ε_∞) / (1 + ω² · τ²)           [дійсна частина проникності]
ε''(ω) = (ε_s - ε_∞) · ω · τ / (1 + ω² · τ²)        [уявна частина / втрати]
```

Тангенс кута втрат `tan δ` становить:

```
tan δ = ε'' / ε' = ((ε_s - ε_∞) · ω · τ) / (ε_s + ε_∞ · ω² · τ²)
```

Максимум втрат `ε''_max = (ε_s - ε_∞) / 2` спостерігається на резонансній круговій частоті `ω_max = 1 / τ`.

#### Геометрія півкола Коул — Коула
Виключивши параметр `ω·τ` із систем рівнянь для `ε'` та `ε''`, можна отримати геометричне співвідношення на комплексній площині `(ε', ε'')`:

```
(ε' - (ε_s + ε_∞) / 2)² + (ε'')² = ((ε_s - ε_∞) / 2)²
```

Це рівняння **кола** з центром у точці `((ε_s + ε_∞) / 2, 0)` та радіусом `R = (ε_s - ε_∞) / 2`. Графік `ε''(ε')` у напівплощині `ε'' ≥ 0` називається **діаграмою Коул — Коула** (*Cole-Cole plot*). Вона слугує головним інструментом для визначення часу релаксації `τ` та аналізу розподілу часів релаксації у полімерах та складних біологічних середовищах.

### 5. Повний баланс струмів та виділення тепла

У реальному діелектрику із комплексною проникністю `ε(ω) = ε' - i·ε''` та наскрізною питомою провідністю `σ` повна густина струму описується як сума струму провідності та струму зміщення:

```
j_total = j_cond + ∂D/∂t
        = σ · E + ∂(ε · ε₀ · E)/∂t              [закон Ома та вираження D = ε·ε₀·E]
        = σ · E + i · ω · (ε' - i·ε'') · ε₀ · E   [диференціювання e^(i·ω·t) по часу t]
        = (σ + ω · ε₀ · ε'') · E + i · ω · ε₀ · ε' · E [розкриття дужок та урахування i² = -1]
```

Отриманий вираз показує, що активна (синфазна з напругою) густина струму складається із двох частин: наскрізної провідності `σ · E` та діелектричних релаксаційних втрат `ω · ε₀ · ε'' · E`. 

Ефективна уявна частина діелектричної проникності, що враховує обоє джерел активних втрат, визначається як:

```
ε''_eff = ε''_relax + σ / (ω · ε₀)
```

Середня потужність тепла `p` (Вт/м³), що розсіюється в одиниці об'єму діелектрика під дією гармонічного поля амплітудою `E₀`, обчислюється через інтегрування за період:

```
p = (1 / 2) · Re{j_total · E*}
  = (1 / 2) · ω · ε₀ · ε''_eff · E₀²              [усереднення активної потужності за період]
  = (1 / 2) · ω · ε₀ · ε' · tan δ · E₀²            [підстановка визначення tan δ = ε''/ε']
```

Квадратична залежність потужності від напруженості поля `E₀²` та лінійна залежність від частоти `ω` підтверджують, що при збільшенні частоти навіть діелектрики з надзвичайно малими втратами `tan δ` починають інтенсивно нагріватися, що вимагає застосування спеціальних термостійких високочастотних ламінатів у НВЧ-техніці.

### 6. Густина енергії поля та пондеромоторні сили

Енергія електричного поля, накопичена в одиниці об'єму діелектрика, обчислюється через інтегрування роботи при зміні поляризації:

```
w = ∫ E⃗ · dD⃗ = ∫ E⃗ · d(ε · E⃗) = (1 / 2) · ε · E² = (1 / 2) · εᵣ · ε₀ · E²
```

Якщо у простір між обкладками плоского конденсатора, підключеного до джерела постійної напруги `V`, частково всунуто діелектричну пластину товщиною `d` та шириною `w` на глибину `x`, повна енергія системи становить:

```
W(x) = (1 / 2) · C(x) · V²
```

де ємність як функція глибини `x` дорівнює:

```
C(x) = (ε₀ / d) · (εᵣ · w · x + w · (L - x))
```

Повну втягуючу **пондеромоторну силу** (*ponderomotive force*), що діє на діелектрик з боку поля, обчислюють як похідну від енергії при постійному потенціалі `V`:

```
F = ∂W / ∂x = (1 / 2) · V² · (dC / dx)
  = (1 / 2) · (εᵣ - 1) · ε₀ · (w / d) · V²
```

Позитивний знак сили підтверджує, що електричне поле завжди прагне втягнути діелектрик із вищою проникністю `εᵣ` в область максимальної напруженості поля.
