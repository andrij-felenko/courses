# 📋 Параметри та розрахунок індукційного гальмування

Цей довідник містить інженерні параметри, вирази, специфікації матеріалів та розрахункові співвідношення для проектування індукційних (вихрострумових) гальмівних систем, магнітних демпферів та засобів захисту від перенапруг на основі правила Ленца. Документ призначений для розробників приводів, розрахункових інженерів і фізиків, які моделюють електродинамічну протидію в масивних провідниках.

## 1. Фізичні та інженерні параметри системи

Розрахунок електродинамічного гальмування за правилом Ленца вимагає врахування комплексного набору електромагнітних, геометричних та теплофізичних параметрів. Кожна з цих величин безпосередньо впливає на величину гальмівного моменту, термодинамічну стійкість і точність сповільнення.

- **Магнітна індукція у робочому зазорі (`B`, Тл)**: Основний енергетичний параметр електромагніту або постійного магніту. Гальмівне зусилля залежить від індукції квадратично (`F_brake ∝ B²`), тому збільшення поля у два рази зрощує гальмівний момент у чотири рази. У промислових системах використовують поля від `0.3 Тл` (постійні феритні магніти) до `1.5 Тл` (насичені електромагніти зі сталевими полюсами) або понад `2.5 Тл` у надпровідних магнітних системах.
- **Питома електропровідність провідника (`σ`, См/м)**: Визначає активний електричний опір контурів вихрових струмів. Висока провідність металу знижує опір `R` і дозволяє індукувати струми більшої амперної сили, що збільшує гальмівний момент. Проте висока провідність також прискорює температурну деградацію при нагріванні.
- **Товщина провідного елемента (`d`, м)**: Впливає на об'ємний опір та глибину проникнення поля. Для тонких пластин (`d < 2·δ`) гальмівна сила зростає лінійно з товщиною; для товстих роторів збільшення товщини понад подвійну глибину скін-шару `2·δ` не дає приросту моменту, а лише збільшує масу та інерцію системи.
- **Геометричний фактор замикання вихрових струмів (`C_shape`)**: Безрозмірний коефіцієнт (діапазон `0.15 ... 0.50`), що характеризує додатковий опір, який виникає при обтіканні вихровими струмами зовнішніх країв ротора. Чим ближче магнітний полюс розташований до краю диска, тим сильніше деформуються струмові контури й тим нижчим є значення `C_shape`.
- **Кутова швидкість обертання (`ω`, рад/с)**: Швидкість зміни магнітного потоку. При низьких і помірних швидкостях гальмівний момент зростає лінійно з кутовою швидкістю (`T_brake ∝ ω`). На високих швидкостях через поверхневий скін-ефект і реакцію вихрових струмів момент досягає максимуму `T_max` при критичній швидкості `ω_crit`, після чого починає повільно спадати пропорційно `1 / √ω`.

## 3. Математичні формули розрахунку дискових та лінійних гальм

### 3.1. Розрахунок гальмівного моменту дискового затримувача

Для дискового вихрострумового гальма з прямокутними або круглими полюсними наконечниками площа кожного полюса дорівнює `A_p`. Полюси розміщено симетрично на середньому радіусі `r_m` від осі обертання.

Гальмівний момент `T_brake` обчислюється за виразом:

```
T_brake = N_poles · C_shape · σ · d · A_p · B² · r_m² · ω
```

де:
- `N_poles` — кількість пар магнітних полюсів, розміщених по колу диска;
- `C_shape` — безрозмірний крайовий коефіцієнт;
- `σ` — поточна питома провідність матеріалу диска з урахуванням нагріву, См/м;
- `d` — товщина диска, м;
- `A_p` — площа перетину одного магнітного полюса, м²;
- `B` — середня магнітна індукція у проміжку між полюсом і диском, Тл;
- `r_m` — радіус встановлення центрів полюсів, м;
- `ω` — кутова швидкість обертання диска, рад/с.

### 3.2. Обчислення крайового коефіцієнта (Модель Вангеля)

Для диска зовнішнім радіусом `R_outer` при розміщенні круглих полюсів радіусом `r_p = √(A_p / π)` на радіусі `r_m` крайовий коефіцієнт `C_shape` обчислюється за емпіричною формулою Вангеля:

```
C_shape = 0.5 · [1 - (1 / (4 · (r_m / r_p))) · (1 / (1 + (R_outer - r_m) / r_p)²)]
```

Ця формула показує, що для досягнення максимального моменту край магнітного полюса повинен відступати від зовнішнього краю диска щонайменше на один радіус полюса (`R_outer - r_m ≥ r_p`). Наближення полюса впритул до краю диска зменшує `C_shape` на `40–50%` через різке звуження шляхів протікання зворотних вихрових струмів.

### 3.3. Глибина проникнення поля та частотна характеристика (Скін-ефект)

При високочастотному обертанні вихрові струми створюють власне магнітне поле, яке розмагнічує товщу ротора і витісняє зовнішнє поле на поверхню. Ефективна глибина проникнення (товщина скін-шару `δ`) обчислюється як:

```
δ = √(2 / (ω_e · μ_0 · μ_r · σ))
```

де:
- `ω_e` — кругова частота зміни поля відносно матеріалу диска (`ω_e = N_poles · ω`);
- `μ_0 = 4π × 10⁻⁷` Гн/м — магнітна стала;
- `μ_r` — відносна магнітна проникність диска (для міді й алюмінію `μ_r = 1.0`).

Якщо товщина диска перевищує подвійну глибину скін-шару (`d > 2·δ`), виникає ефект насичення гальмівного моменту. Критична кутова швидкість `ω_crit`, при якій момент досягає абсолютного максимуму:

```
ω_crit = 2 / (N_poles · μ_0 · σ · d²)
```

При перевищенні `ω_crit` гальмівний момент спадає за законом:

```
T_brake(ω) = T_max · (2 · (ω / ω_crit) / (1 + (ω / ω_crit)²))
```

## 4. Тепловий розрахунок та охолодження

Оскільки уся механічна робота сповільнення за правилом Ленца перетворюється на тепло у роторі, розрахунок системи охолодження є критично важливим для запобігання термічному руйнуванню гальма.

### 4.1. Адіабатичне нагрівання при екстреному гальмуванні

При короткочасному аварійному зупиненні об'єкта масою `M_train`, що рухався зі швидкістю `V_init`, виділяється теплова енергія:

```
Q_total = 0.5 · M_train · V_init²
```

Якщо гальмування триває короткий час `t_b < 5 с`, віддачею тепла у повітря можна знехтувати. Приріст температури гальмівного диска `ΔT` становить:

```
ΔT = Q_total / (m_disk · c_p)
```

Щоб приріст температури алюмінієвого диска не перевищував `150 °C` (початок втрати механічної міцності сплаву 6061-T6), маса активної зони диска повинна задовольняти умову:

```
m_disk ≥ Q_total / (150 · c_p)
```

### 4.2. Усталений температурний режим при безперервному гальмуванні

При тривалій роботі у режимі сповільнення (наприклад, при спуску вантажного автомобіля на тривалому ухилі) теплова потужність `P_brake` повинна повністю відводитися конвективним охолодженням:

```
P_brake = h_conv · S_cool · (T_disk - T_air)
```

де:
- `h_conv` — коефіцієнт конвективної тепловіддачі, Вт/(м²·K) (для обертального диска `h_conv ≈ 15 + 0.6 · v_disk` Вт/(м²·K));
- `S_cool` — повна площа поверхні охолодження диска, м²;
- `T_disk` — температура диска у сталого режимі, °C;
- `T_air` — температура навколишнього повітря, °C.

## 5. Типові інженерні проблеми та способи їх усунення

У практичній експлуатації вихрострумових гальмівних систем на основі правила Ленца виникають типові інженерні проблеми, зведені у таблиці нижче.

| Проблема / Симптом | Фізична причина (Закон Ленца) | Інженерне рішення |
| :--- | :--- | :--- |
| **Падіння гальмівного зусилля при тривалій роботі** | Нагрівання диска → зменшення провідності `σ(T)` за законом `σ = σ_0 / (1 + α ΔT)`. | Застосування внутрішнього примусового обдування; використання алюмінієво-мідних биметалевих дискових композитів. |
| **Низька ефективність на малих швидкостях** | Гальмівна сила прямує до нуля при `v → 0` (`F_brake ∝ v`). | Поєднання індукційного гальма з механічним стояночним гальмом фіксації. |
| **Перегрів та жолоблення диска** | Нерівномірний розподіл вихрових струмів по радіусу `r_m` → термічні напруження. | Виконання радіальних теплових прорізів у диску для компенсації температурного розширення. |
| **Зменшення моменту на надвисоких швидкостях** | Витіснення магнітного поля скін-ефектом (`d > 2·δ`) та реакція вихрових струмів. | Зменшення товщини диска `d`; застосування баготочкових дрібних магнітних полюсів `N_poles`. |
