# ⚙️ Моделювання часового відгуку лінії передачі (TDR)

Часова рефлектометрія (англійська *Time-Domain Reflectometry*, TDR) є основним методом діагностики, оцінки характеристичного імпедансу та локалізації пошкоджень у кабельних мережах та швидкісних друкованих платах. Принцип роботи рефлектометра полягає у подачі на вхід лінії передачі надшвидкого прямокутного імпульсу або ступені напруги з коротким часом наростання фронту (від 10 до 100 пікосекунд) та реєстрації відбитого сигналу як функції часу на осцилографі. За часовою затримкою та полярністю відбитого луна-сигналу інженер визначає точну відстань до дефекту, тип неузгодженості та локальне значення імпедансу доріжки.

У цьому проєкті реалізовано повноцінний чисельний симулятор лінії передачі мовами C та C++, який розв'язує систему телеграфних рівнянь у часовій області методом скінченних різниць (1D-FDTD) та моделює часовий відгук напруги для довільного імпедансу навантаження `Z_L`.

## Чисельний метод FDTD на рознесеній сітці Йі (1D Yee Grid)

Для чисельного розв'язку системи телеграфних рівнянь у часовій області використовується метод скінченних різниць у часовій області (1D Finite-Difference Time-Domain, FDTD), запропонований Кейном Йі у 1966 році.

Телеграфні рівняння у частинних похідних описують взаємозв'язок напруги `V(z,t)` та струму `I(z,t)`:

```
∂V / ∂z = - R_0 · I - L_0 · (∂I / ∂t)
∂I / ∂z = - G_0 · V - C_0 · (∂V / ∂t)
```

Для забезпечення другого порядку точності дискретизації за простором і часом `O(Δz² + Δt²)` вузли обчислення напруги та струму розносяться у просторі й часі на півкроку:

1. **Просторова сітка**: напруга `V[i]` обчислюється в цілих вузлах `i · Δz` (де `i = 0, 1, ..., N-1`), а струм `I[i]` обчислюється у напівцілих вузлах `(i + 1/2) · Δz` (де `i = 0, 1, ..., N-2`).
2. **Часова сітка**: напруга `V` оновлюється на цілих часових кроках `n · Δt`, а струм `I` — на напівцілих кроках `(n + 1/2) · Δt`.

Замінивши частинні похідні на центральні скінченні різниці, отримуємо явні різницеві схеми для оновлення полів на кожному часовому кроці:

```
I[i]^{n+1/2} = (1 - (R_0·Δt / (2·L_0))) / (1 + (R_0·Δt / (2·L_0))) · I[i]^{n-1/2} 
               - (Δt / (L_0 · Δz · (1 + (R_0·Δt / (2·L_0))))) · (V[i+1]^{n} - V[i]^{n})

V[i]^{n+1}   = (1 - (G_0·Δt / (2·C_0))) / (1 + (G_0·Δt / (2·C_0))) · V[i]^{n} 
               - (Δt / (C_0 · Δz · (1 + (G_0·Δt / (2·C_0))))) · (I[i]^{n+1/2} - I[i-1]^{n+1/2})
```

## Умова стійкості Куранта — Фрідріхса — Леві (CFL)

Явна різницева схема FDTD є умовно стійкою. Для запобігання чисельної нестійкості (коли чисельна хвиля наростає нескінченно) часовий крок `Δt` повинен задовольняти критерій Куранта (CFL condition):

```
Δt ≤ Δz / v = Δz · √(L_0 · C_0)
```

Фізичний зміст умови Куранта полягає у тому, що чисельна інформація не може поширюватися по сітці повільніше за реальну фізичну електромагнітну хвилю. У нашому симуляторі часовий крок обирається з безпечним запасом стійкості: `Δt = 0.9 · (Δz / v)`. Якщо порушити умову Куранта (обрати `Δt > Δz / v`), чисельна помилка округлення починає експоненційно зростати на кожному часовому кроці, і за кілька десятків кроків значення напруги прямують до нескінченності `±NaN`.

Для запобігання чисельної дисперсії (коли короткохвильові компоненти розмиваються через дискретність сітки) просторовий крок `Δz` обирається таким чином, щоб найменша довжина хвилі у спектрі сигналу `λ_min` покривалася щонайменше 10–20 вузлами сітки: `Δz ≤ λ_min / 10`.

## Граничні умови та чисельна термінація

На лівому кінці лінії (`z = 0`, `i = 0`) підключено генератор з внутрішнім опором `R_src` та ЕРС `E_src(t)`. Зміна напруги у першому вузлі підкоряється еквівалентній схемі з джерелом:

```
V[0]^{n+1} = V[0]^{n} - (2·Δt / (C_0·Δz)) · (I[0]^{n+1/2} - (E_src - V[0]^{n}) / R_src)
```

На правому кінці лінії (`z = L`, `i = N-1`) підключено навантаження `Z_L`. Граничні умови для напруги в останньому вузлі залежать від типу навантаження:

1. **Узгоджене або довільне омічне навантаження `Z_L`**: струм останнього сегмента створює спад напруги `V[N-1] = I[N-2] · Z_L`.
2. **Холостий хід (`Z_L → ∞`)**: струм на кінці дорівнює нулю `I[N-1] = 0`. Напруга в останньому вузлі заряджається струмом `I[N-2]`: `V[N-1] += (2·Δt / (C_0·Δz)) · I[N-2]`.
3. **Коротке замикання (`Z_L = 0`)**: напруга в останньому вузлі жорстко зафіксована на нулі `V[N-1] = 0`.
4. **Ємнісне навантаження `C_L` (наприклад, вхідний контакт мікросхеми)**: ємність підключається паралельно останньому вузлу. У перший момент стрибка напруги конденсатор розряджений і поводиться як коротке замикання (`V(L) → 0`), а в міру заряджання напруга зростає за експонентою до рівня холостого ходу з постійною часу `τ = Z_0 · C_L`.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define NUM_NODES 200
#define TOTAL_STEPS 600

typedef struct {
    double z0;          /* Характеристичний імпеданс лінії, Ом */
    double v_prop;      /* Фазова швидкість поширення хвилі, м/с */
    double length;      /* Фізична довжина лінії передачі, м */
    double r0;          /* Погонний опір втрат у металі, Ом/м */
    double g0;          /* Погонна провідність витоку діелектрика, См/м */
    double z_load;      /* Опір навантаження на кінці лінії, Ом */
    double r_src;       /* Внутрішній опір генератора сигналу, Ом */
} tline_config_t;

void run_tline_simulation(const tline_config_t *cfg, double *v_in_history) {
    double dz = cfg->length / (NUM_NODES - 1);
    double l0 = cfg->z0 / cfg->v_prop;
    double c0 = 1.0 / (cfg->z0 * cfg->v_prop);
    double dt = 0.9 * (dz / cfg->v_prop); /* Умова Куранта CFL */

    double V[NUM_NODES] = {0.0};
    double I[NUM_NODES - 1] = {0.0};

    /* Коефіцієнти загасання для схеми FDTD */
    double c_i1 = (1.0 - (cfg->r0 * dt / (2.0 * l0))) / (1.0 + (cfg->r0 * dt / (2.0 * l0)));
    double c_i2 = (dt / (l0 * dz)) / (1.0 + (cfg->r0 * dt / (2.0 * l0)));

    double c_v1 = (1.0 - (cfg->g0 * dt / (2.0 * c0))) / (1.0 + (cfg->g0 * dt / (2.0 * c0)));
    double c_v2 = (dt / (c0 * dz)) / (1.0 + (cfg->g0 * dt / (2.0 * c0)));

    for (int t = 0; t < TOTAL_STEPS; t++) {
        /* 1. Генерирація ступені напруги генератора 1.0 В з часом наростання */
        double e_src = (t < 10) ? (1.0 * t / 10.0) : 1.0;

        /* 2. Оновлення струмів у напівцілих вузлах сітки */
        for (int i = 0; i < NUM_NODES - 1; i++) {
            double dV = V[i + 1] - V[i];
            I[i] = c_i1 * I[i] - c_i2 * dV;
        }

        /* 3. Оновлення внутрішніх напруг у цілих вузлах */
        for (int i = 1; i < NUM_NODES - 1; i++) {
            double dI = I[i] - I[i - 1];
            V[i] = c_v1 * V[i] - c_v2 * dI;
        }

        /* 4. Гранична умова на вхідному кінці z = 0 (включаючи джерело) */
        double i_in_src = (e_src - V[0]) / cfg->r_src;
        V[0] = V[0] + (2.0 * dt / (c0 * dz)) * (i_in_src - I[0]);

        /* 5. Гранична умова на вихідному кінці z = L (навантаження Z_L) */
        if (cfg->z_load > 1e6) {
            /* Холостий хід: струм відсутній, шар заряду накопичується */
            V[NUM_NODES - 1] += (2.0 * dt / (c0 * dz)) * I[NUM_NODES - 2];
        } else if (cfg->z_load < 1e-3) {
            /* Коротке замикання: напруга дорівнює нулю */
            V[NUM_NODES - 1] = 0.0;
        } else {
            /* Омічне навантаження */
            V[NUM_NODES - 1] = I[NUM_NODES - 2] * cfg->z_load;
        }

        /* Запис осцилограми вхідної напруги для аналізу TDR */
        v_in_history[t] = V[0];
    }
}

int main(void) {
    tline_config_t cfg = {
        .z0 = 50.0,
        .v_prop = 2.0e8,  /* 200,000 км/с */
        .length = 10.0,   /* 10 метрів */
        .r0 = 0.02,       /* Втрати в міді */
        .g0 = 0.0,
        .z_load = 100.0,  /* Неузгоджене навантаження 100 Ом */
        .r_src = 50.0     /* Узгоджений опір генератора 50 Ом */
    };

    double history[TOTAL_STEPS];
    run_tline_simulation(&cfg, history);

    printf("=== Симуляція часової рефлектометрії TDR (C-реалізація) ===\n");
    printf("Крок 50  (падаюча хвиля V_in): %.3f В\n", history[50]);
    printf("Крок 250 (відбита хвиля V_ref): %.3f В\n", history[250]);

    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <span>
#include <cmath>
#include <expected>
#include <string>
#include <algorithm>

struct TransmissionLineConfig {
    double characteristic_impedance{50.0}; // Ом
    double phase_velocity{2.0e8};          // м/с
    double line_length{10.0};              // м
    double resistance_per_m{0.02};         // Ом/м
    double conductance_per_m{0.0};         // См/м
    double load_impedance{100.0};          // Ом
    double source_resistance{50.0};        // Ом
};

class TimeDomainReflectometerSim {
public:
    explicit TimeDomainReflectometerSim(TransmissionLineConfig cfg, std::size_t spatial_nodes = 200)
        : config_(cfg), nodes_count_(spatial_nodes) {}

    [[nodiscard]] std::expected<std::vector<double>, std::string> execute(std::size_t total_time_steps) const {
        if (nodes_count_ < 3) {
            return std::unexpected("Кількість вузлів сітки повинна бути не менше 3");
        }

        const double dz = config_.line_length / static_cast<double>(nodes_count_ - 1);
        const double l0 = config_.characteristic_impedance / config_.phase_velocity;
        const double c0 = 1.0 / (config_.characteristic_impedance * config_.phase_velocity);
        const double dt = 0.9 * (dz / config_.phase_velocity); // Умова Куранта

        std::vector<double> voltage(nodes_count_, 0.0);
        std::vector<double> current(nodes_count_ - 1, 0.0);
        std::vector<double> input_voltage_waveform(total_time_steps, 0.0);

        const double c_i1 = (1.0 - (config_.resistance_per_m * dt / (2.0 * l0))) / (1.0 + (config_.resistance_per_m * dt / (2.0 * l0)));
        const double c_i2 = (dt / (l0 * dz)) / (1.0 + (config_.resistance_per_m * dt / (2.0 * l0)));

        const double c_v1 = (1.0 - (config_.conductance_per_m * dt / (2.0 * c0))) / (1.0 + (config_.conductance_per_m * dt / (2.0 * c0)));
        const double c_v2 = (dt / (c0 * dz)) / (1.0 + (config_.conductance_per_m * dt / (2.0 * c0)));

        for (std::size_t t = 0; t < total_time_steps; ++t) {
            // Фронт напруги джерела 1.0 В з наростанням за 10 кроків
            const double e_src = (t < 10) ? (static_cast<double>(t) / 10.0) : 1.0;

            // Оновлення струмів
            for (std::size_t i = 0; i < nodes_count_ - 1; ++i) {
                const double dV = voltage[i + 1] - voltage[i];
                current[i] = c_i1 * current[i] - c_i2 * dV;
            }

            // Оновлення напруг у внутрішніх вузлах
            for (std::size_t i = 1; i < nodes_count_ - 1; ++i) {
                const double dI = current[i] - current[i - 1];
                voltage[i] = c_v1 * voltage[i] - c_v2 * dI;
            }

            // Вхідна гранична умова з урахуванням опору джерела
            const double i_src = (e_src - voltage[0]) / config_.source_resistance;
            voltage[0] += (2.0 * dt / (c0 * dz)) * (i_src - current[0]);

            // Вихідна гранична умова навантаження
            if (config_.load_impedance > 1e6) {
                voltage[nodes_count_ - 1] += (2.0 * dt / (c0 * dz)) * current[nodes_count_ - 2];
            } else if (config_.load_impedance < 1e-3) {
                voltage[nodes_count_ - 1] = 0.0;
            } else {
                voltage[nodes_count_ - 1] = current[nodes_count_ - 2] * config_.load_impedance;
            }

            input_voltage_waveform[t] = voltage[0];
        }

        return input_voltage_waveform;
    }

private:
    TransmissionLineConfig config_;
    std::size_t nodes_count_;
};

int main() {
    TransmissionLineConfig config{
        .characteristic_impedance = 50.0,
        .phase_velocity = 2.0e8,
        .line_length = 10.0,
        .resistance_per_m = 0.02,
        .conductance_per_m = 0.0,
        .load_impedance = 100.0,
        .source_resistance = 50.0
    };

    TimeDomainReflectometerSim simulator(config, 200);
    auto simulation_result = simulator.execute(600);

    if (simulation_result) {
        std::cout << "=== Симуляція TDR (C++23 реалізація) ===\n";
        std::cout << "Крок 50  (падаюча хвиля V_in): " << (*simulation_result)[50] << " В\n";
        std::cout << "Крок 250 (відбита хвиля V_ref): " << (*simulation_result)[250] << " В\n";
    } else {
        std::cerr << "Помилка виконання симуляції: " << simulation_result.error() << '\n';
    }

    return 0;
}
```

## Фізичний розбір осцилограми та інженерні висновки

Отримані в результаті симуляції осцилограми дозволяють провести повний фізичний аналіз поширення хвильового фронту:

1. **Етап 1: Формування падаючої хвилі (`0 < t < T_delay`)**:
   Генератор із внутрішнім опором `R_src = 50 Ом` подає на вхід стрибок ЕРС `E = 1.0 В`. У перший момент часу хвиля «бачить» лише характеристичний імпеданс лінії `Z_0 = 50 Ом`. Оскільки опір джерела та імпеданс лінії утворюють дільник напруги `Z_0 / (R_src + Z_0) = 50 / (50 + 50) = 0.5`, на вхід лінії передається падаюча хвиля амплітудою точно `V⁺ = 0.5 В`. Осцилограф реєструє стабільну напругу `0.5 В`.

2. **Етап 2: Проліт хвилі вздовж лінії (`t = T_delay`)**:
   Хвиля долає відстань 10 метрів зі швидкістю `2·10⁸ м/с` за час `t_prop = 10 / 2·10⁸ = 50 наносекунд`.

3. **Етап 3: Відбиття від навантаження та повернення луна-сигналу (`t = 2 · T_delay`)**:
   На правому кінці хвиля зустрічає навантаження `Z_L = 100 Ом`. Коефіцієнт відбиття дорівнює:
   ```
   Γ = (Z_L - Z_0) / (Z_L + Z_0) = (100 - 50) / (100 + 50) = + 1/3 ≈ +0.333
   ```
   Відбита хвиля амплітудою `V⁻ = Γ · V⁺ = 0.333 · 0.5 = 0.167 В` повертається назад до генератора і досягає входу через подвійний час затримки `2 · t_prop = 100 наносекунд` (що відповідає кроку 250 у симуляції).

4. **Етап 4: Реєстрація сумарного рівня**:
   Напруга на вході лінії стрибкоподібно зростає до суми падаючої та відбитої хвиль:
   ```
   V_total = V⁺ + V⁻ = 0.500 + 0.167 = 0.667 В
   ```
   Оскільки опір джерела узгоджений з лінією (`R_src = Z_0`), відбита хвиля повністю поглинається на джерелі і не відбивається вдруге. Напруга залишається стабільною на рівні `0.667 В`.

При ємнісному або індуктивному навантаженні осцилограма TDR набуває експоненціальної форми. Якщо на кінці кабелю присутня паразитна ємність (наприклад, вхідний контакт мікросхеми), стрибок напруги спочатку просідає до нуля (конденсатор коротить коло у перший момент), після чого експоненційно наростає з постійною часу `τ = Z_0 · C_parasitic`. Якщо ж у лінії присутня послідовна індуктивність (наприклад, перехідний отвір PCB або довгий вивід компонента), осцилограф спочатку реєструє вузький позитивний сплеск напруги `V_peak = L_parasitic · (dI / dt)`, після чого сигнал спадає до стабільного рівня.

Саме цей чисельний алгоритм лежить в основі портативних індустріальних рефлектометрів, які дозволяють зв'язківцям із точністю до сантиметрів визначати місце обриву або короткого замикання оптичних та мідних кабелів довжиною у десятки кілометрів.
