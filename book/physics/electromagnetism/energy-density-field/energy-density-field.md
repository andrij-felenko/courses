# Густина енергії електромагнітного поля

<preknowlist>
- [Рівняння Максвелла](topic:physics/maxwell-equations) — диференціальні рівняння електродинаміки.
- [Електростатичне поле](topic:physics/electromagnetism/electrostatic-field) — потенціал та напруженість E.
- [Магнітна індукція](topic:physics/electromagnetism/magnetic-induction) — вектор індукції B та струми.
</preknowlist>

Коли електричні заряди притягуються або відштовхуються, система виконує механічну роботу. У класичній фізиці першої половини XIX століття тривалий час вважали, що ця потенціальна енергія належить безпосередньо самій системі зарядів як абстрактній сукупності точок, а взаємодія передається миттєво через порожнечу (концепція дальнодії). Проте електродинаміка доводить: зміна стану одного заряду викликає зміну поля, яка поширюється у просторі зі скінченною швидкістю — швидкістю світла `c`.

Протягом часу, поки сигнал поширюється від одного заряду до іншого, випромінена енергія вже залишила перший заряд, але ще не досягла другого. Єдиним можливим носієм цієї енергії у проміжному стані є саме **електромагнітне поле**. Поле є самостійною формою матерії, що володіє об'ємною густиною енергії, імпульсом та масою у кожній точці простору.

---

## 1. Енергія електричного поля

Під час заряджання плоскопаралельного конденсатора зовнішнє джерело живлення виконує роботу з перенесення зарядів між пластинами проти сил утвореного електричного поля. Повна накопичена енергія конденсатора ємністю `C`, зарядженого до напруги `U`, дорівнює:

```
W = ½ · C · U²
```

Виразивши ємність плаского конденсатора через його геометричні параметри `C = ε₀ · ε · S / d` (де `S` — площа пластин, `d` — відстань між ними), а напругу через напруженість однорідного електричного поля `U = E · d`, отримаємо вираз для повної енергії у зазорі:

```
W = ½ · (ε₀ · ε · S / d) · (E · d)² = ½ · ε₀ · ε · E² · (S · d) = ½ · ε₀ · ε · E² · V
```

де `V = S · d` — фізичний об'єм простору між пластинами конденсатора, в якому локалізоване однорідне електричне поле.

Поділивши повну накопичену енергію `W` на об'єм зазору `V`, отримуємо **об'ємну густину енергії електричного поля** `w_e`:

```
w_e = ½ · ε₀ · ε · E² = ½ · E · D
```

де `D = ε₀ · ε · E` — вектор електричного зсуву (індукції). 

Головний фізичний висновок полягає у тому, що густина енергії `w_e` визначена виключно значеннями полів `E` та `D` у даній точці простору і не залежить від того, якими саме геометричними тілами чи формами провідників це поле було створене. Вона показує, скільки джоулів енергії міститься в одному кубічному метрі простору, заповненому електричним полем. У середовищах із діелектричною поляризацією частина цієї енергії зберігається у деформації атомних оболонок речовини.

## 2. Енергія магнітного поля

Аналогічно, для створення електричного струму `I` у котушці індуктивності `L` джерело живлення повинно виконати роботу проти ЕРС самоіндукції, яка виникає під час зміщення магнітного потоку. Повна накопичена магнітна енергія котушки становить:

```
W = ½ · L · I²
```

Для довгого соленоїда об'ємом `V` індуктивність `L` та струм `I` виражаються через напруженість магнітного поля `H` та індукцію `B`:

```
L = μ₀ · μ · N² · S / l
H = N · I / l
```

Підставивши ці параметри у формулу енергії котушки та поділивши її на внутрішній об'єм порожнини соленоїда `V = S · l`, отримуємо **об'ємну густину енергії магнітного поля** `w_m`:

```
w_m = ½ · μ₀ · μ · H² = ½ · B · H
```

де `B = μ₀ · μ · H` — вектор магнітної індукції. Фізично густина магнітної енергії характеризує енергію, збережену в орієнтації мікроскопічних струмів та пружній деформації магнітного поля у просторі. У феромагнетиках частина магнітної енергії дисипує на тепло через нелінійні явища гістерезису.

## 3. Сумарна густина енергії та вектор Пойнтінга

Коли у просторі одночасно присутні і електричне, і магнітне поля, сумарна об'ємна густина енергії `w` дорівнює алгебраїчній сумі обидвох складових:

```
w = w_e + w_m = ½ · (E · D + B · H)
```

Для вакууму (`ε = 1`, `μ = 1`):

```
w = ½ · (ε₀ · E² + (1 / μ₀) · B²)
```

### Потік енергії та вектор Пойнтінга

Енергія електромагнітного поля не залишається нерухомою — вона може переноситися з однієї області простору в іншу. Напрямок та густину потоку енергії визначає **вектор Пойнтінга** `S`:

```
S = E × H
```

Модуль вектора Пойнтінга вимірюється у ватах на квадратний метр (Вт/м²) і показує, яка кількість електромагнітної енергії протікає через одиничну площадку за одиницю часу.

Закон збереження електромагнітної енергії у локальній диференціальній формі виражається **теоремою Пойнтінга**:

```
∂w/∂t + ∇ · S = − j · E
```

Ця формула стверджує: швидкість зміни густини енергії в точці `∂w/∂t` та витікання потоку енергії `∇ · S` компенсуються роботою поля над зарядами `j · E` (наприклад, перетворенням енергії поля на джоулеве тепло у провіднику зі струмом).

## 4. Енергія в електромагнітній хвилі та постійних колах

У плоскій електромагнітній хвилі, що поширюється у вакуумі зі швидкістю світла `c`, густини електричної та магнітної енергій у будь-який момент часу є тотожно рівними між собою (`w_e = w_m`).

Повна густина енергії хвилі дорівнює `w = ε₀ · E²`, а модуль вектора Пойнтінга пов'язаний із густиною енергії простим співвідношенням:

```
S = c · w
```

Електромагнітна хвиля переносить енергію у напрямку свого поширення зі швидкістю світла `c`. Середнє значення потоку енергії за період коливань називається інтенсивністю хвилі `I = ⟨S⟩ = ½ · ε₀ · c · E₀²`, де `E₀` — амплітуда електричного поля. Разом із енергією хвиля переносить імпульс із густиною `g = S / c²`, що призводить до існування механічного тиску світла на поверхні.

### Парадокс передачі енергії у провідниках

Принциповим наслідком теореми Пойнтінга є те, що вона працює і для кіл постійного струму. У постійному колі або коаксіальному кабелі енергія джерела живлення тече не всередині металу провідника, а у діелектричному просторі довкола нього, входячи в провідник збоку через бічну поверхню у вигляді потоку Пойнтінга. Провідники слугують лише граничними умовами, які спрямовують векторні поля `E` та `H` у навколишньому діелектрику за допомогою поверхневих зарядів.
