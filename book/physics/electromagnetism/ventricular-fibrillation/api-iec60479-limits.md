# 📋 Електричні пороги ураження серця та стандарт IEC 60479-1

Ця вставка є структурованим технічним довідником фізичних порогів ураження серцевого м'яза електричним струмом, описує криві небезпеки за стандартом IEC 60479-1, розраховує коефіцієнти серцевого струму для різних шляхів проходження, містить параметри електричного опору тіла людини, пояснює феномени макрошоку та мікрошоку, подає стандарти витоку струмів IEC 60601-1 та містить повну специфікацію електричних характеристик імпульсів сучасних дефібриляторів.

### Зони впливу змінного струму частотою 50/60 Гц (IEC 60479-1, Розділ 4)

Стандарт IEC 60479-1 («Вплив струму на людей та свійську худобу») класифікує фізіологічні реакції людського організму при проходженні змінного струму частотою 50/60 Гц за шлях «рука — ліва нога» на чотири основні зони.

| Позначення зони | Діапазон струму `I` та тривалості `t` | Фізіологічні ефекти та вплив на міокард | Ризик фібриляції шлуночків |
| :--- | :--- | :--- | :--- |
| **AC-1** | `I ≤ 0.5` мА (незалежно від часу) | Струм не відчувається. Відсутність м'язових реакцій або больових відчуттів. | 0% |
| **AC-2** | `0.5 мА < I ≤ 10` мА | Відчутне пощипування, мимовільні судоми кистей рук. Судоми не перешкоджають розтисканню руки (нижче порогу невідпускання). | 0% |
| **AC-3** | `10 мА < I ≤ I_c1` | Сильні мимовільні скорочення м'язів рук та грудної клітки. **Поріг невідпускання (Let-go threshold)**. Затруднення дихання. Зміни в провідності серця обратимі. | < 0.1% |
| **AC-4.1** | Понад криву `c1` до кривої `c2` | Сильні судоми, зупинка дихання. Порушення утворення та проведення імпульсу в міокарді. | **Низький (< 5%)** |
| **AC-4.2** | Понад криву `c2` до кривої `c3` | Важкі аритмії, патологічна реполяризація T-зубця. | **Середній (до 50%)** |
| **AC-4.3** | Понад криву `c3` (`I > 500` мА при `t > 0.5` с) | Масивний розпад автохвильових фронтів у шлуночках. | **ВИСОКИЙ (> 50%)** |

#### Фізіологічна характеристика зон впливу струму

1. **Зона AC-1 (Невідчутний струм):** При струмах до 0.5 мА густина струму у тканинах шкіри є занадто малою для деполяризації тактильних рецепторів та нервових закінчень. Струм не викликає жодних відчуттів.
2. **Зона AC-2 (Поріг відчуття):** У діапазоні від 0.5 до 10 мА виникає чітке відчуття нагріву та пощипування. При струмах 5–8 мА виникають мимовільні судоми м'язів передпліччя, проте людина зберігає повний вольовий контроль над м'язами і здатна самостійно розтиснути руку і звільнитися від провідника.
3. **Зона AC-3 (Поріг невідпускання):** При струмах вище 10–15 мА відбувається тетанічний спазматичний скорочувальний ефект згинальних м'язів пальців та передпліччя. Сила мимовільного стискання долоні перевищує максимальне вольове зусилля людини. Потерпілий фізично не здатний відпустити затиснутий у руці провідник під напругою. Додатково виникає спазм дихальної мускулатури грудної клітки, що без надання допомоги призводить до асфіксії протягом 2–3 хвилин.
4. **Зона AC-4 (Зона фібриляції):** Проходження струму понад криву `c1` безпосередньо впливає на іонні канали кардіоміоцитів. Порушується синусовий ритм, виникають передчасні шлуночкові екстрасистоли, які при тривалості струму понад 100 мс заходять у вразливий період реполяризації і спричиняють незворотну фібриляцію шлуночків.

#### Математичні рівняння кривих межі фібриляції (Крива `c1`)

Пороговий струм виникнення фібриляції шлуночків `I_VF` залежить від тривалості проходження струму `t`. Для інтервалу тривалості від `t = 10` мс до `t = 5000` мс межа зони AC-4 (крива `c1`) описується експериментальним рівнянням Чарльза Далзіла (*Charles Dalziel*):

```
I_VF(t) = k / √t
```

де:
- `t` — тривалість проходження струму у секундах (`0.01 ≤ t ≤ 5` с);
- `k` — константа порогу тканини. За стандартом IEC 60479-1 для 5% ймовірності фібриляції `k = 116` мА·с^0.5 (для маси тіла 50 кг) та `k = 157` мА·с^0.5 (для маси тіла 70 кг).

При тривалостях проходження струму, що перевищують один період серцевого циклу (`t > 0.75` с), поріг фібриляції асимптотично наближається до стаціонарного значення:

```
I_VF_long ≈ 30 ... 50 мА (RMS)
```

При коротких ударах (`t < 100` мс) поріг фібриляції різко зростає і стає суттєво залежним від фази серцевого циклу: якщо удар тривалістю 20 мс припадає поза зубцем T, поріг становить `I > 500` мА; якщо ж той самий удар потрапляє точно у вразливий період зубця T, поріг знижується до `I ≈ 50` мА.

### Коефіцієнт серцевого струму (`F`) для різних шляхів проходження

Небезпека виникнення фібриляції шлуночків залежить від того, яка саме частка загального струму тіла проходить безпосередньо через м'язовий масив серця. Стандарт IEC 60479-1 вводить безрозмірний **коефіцієнт серцевого струму** `F` (*Heart Current Factor*).

Еквівалентний струм серця `I_heart`, що викликає однаковий ризик фібриляції порівняно зі стандартним шляхом «ліва рука — стопи», обчислюється за формулою:

```
I_heart = I_total · F
```

| Шлях проходження струму через тіло | Коефіцієнт серцевого струму `F` | Відносна небезпека для серця |
| :--- | :--- | :--- |
| **Ліва рука — ліва стопа (або обидві стопи)** | **1.0** | **Базовий еталон порівняння** |
| **Права рука — обидві стопи** | 0.8 | Середня (струм оминає верхівку серця) |
| **Ліва рука — грудна клітка (передньо-задній)** | **1.5** | **МАКСИМАЛЬНА (весь струм іде через міокард)** |
| **Рука — рука (ліва рука — права рука)** | 0.4 | Помірний ризик (горизонтальний шлях) |
| **Спина — права рука** | 0.3 | Низький ризик |
| **Стопа — стопа (ліва нога — права нога)** | **0.04** | **Мінімальний ризик (крокова напруга)** |

Значення `F = 0.04` для шляху «стопа — стопа» пояснює фізичну природу крокової напруги: при проходженні струму між ногами майже весь струм тече через таз і нижні кінцівки, оминаючи грудну клітку, що робить ризик фібриляції мінімальним (головною небезпекою при кроковій напрузі є падіння людини, яке переводить шлях струму у небезпечну конфігурацію «рука — нога»).

### Макрошок vs Мікрошок: фундаментальна фізична відмінність

В інженерній біомедицині розрізняють два принципово різних режими електричного ураження серця:

1. **Макрошок (Macroshock):** Електричний струм прикладається до зовнішньої поверхні тіла (через шкіру рук або грудної клітки). Шкіра, кістки та легені створюють високий паразитний опір і розсіюють струм. Лише близько 0.5–1% від загального струму тіла потрапляє у міокард. Поріг фібриляції при макрошоку становить `I_macro ≈ 50 ... 100` мА.
2. **Мікрошок (Microshock):** Електричний струм подається безпосередньо у порожнину серця через інвазивний медичний провідник (наприклад, внутрішньосерцевий катетер, електрод електрокардіостимулятора або датчик тиску). У цьому випадку опір шкіри відсутній, а вся густина струму фокусується на малій площі дотику з ендокардом (`S ≈ 1 ... 2` мм²).

#### Поріг мікрошокової фібриляції та граничні струми витоку (IEC 60601-1)

При мікрошоку поріг виникнення фібриляції шлуночків падає у 1000 разів:

```
I_micro_VF ≈ 20 ... 100 мкА (0.02 ... 0.1 мА)
```

Через екстремально низький поріг мікрошоку стандарт медичної безпеки IEC 60601-1 жорстко нормує граничні **струми витоку (Leakage Current)** для медичного обладнання залежно від типу робочої частини (*Applied Part*):

| Клас робочої частини (IEC 60601-1) | Сфера застосування | Максимально припустимий струм витоку на пацієнта (Норма) | Струм витоку при першій неправності (Single Fault) |
| :--- | :--- | :--- | :--- |
| **Type B (Body)** | Загальне обладнання без контакту з серцем (оглядові кушетки, грелки) | 100 мкА | 500 мкА |
| **Type BF (Body Floating)** | Обладнання з тривалим зовнішнім контактом (ЕКГ, ЕЕГ, пупьсоксиметри) | 100 мкА | 500 мкА |
| **Type CF (Cardiac Floating)** | **Інвазивні прилади з прямим контактом із серцем (катетери, стимулятори)** | **< 10 мкА** | **< 50 мкА** |

Робочі частини типу CF вимагають подвійної гальванічної розв'язки з міжкаскадною ємністю трансформаторів менше 10 пікофарад, що гарантує струм витоку менше 10 мкА навіть при використанні високочастотних імпульсних джерел живлення.

#### Стандарти випробування захисного заземлення та еквіпотенціального з'єднання

Для запобігання мікрошоку у кардіохірургічних операційних застосовують систему додаткового еквіпотенціального з'єднання (*Equipotential Bonding*). Усі металеві корпуси медичних приладів, операційний стіл та металеві конструкції кімнати з'єднуються мідними шинами перерізом не менше 6 мм² до єдиної шини заземлення. 

Стандарт IEC 60601-1 вимагає, щоб опір захисного заземлення між вилкою живлення та будь-якою доступною металевою частиною корпусу не перевищував:

```
R_ground ≤ 0.1 Ом (без кабелю)   або   R_ground ≤ 0.2 Ом (із знімним шнуром живлення)
```

Це гарантує, що при виникненні аварійного струму витоку різниця потенціалів між корпусом приладу та заземленим пацієнтом не перевищить безпечного порогу у 10 мВ.

#### Методика лабораторного випробування струмів витоку на пацієнта (IEC 60601-1, Розділ 8.7)

При атестації біомедичного обладнання вимірювання витоку струму виконується за допомогою еквівалентного вимірювального пристрою MD (*Measuring Device*), який імітує електричний опір людини. Пристрій складається з резистора 1000 Ом, зашунтованого послідовним ланцюгом із резистора 10 кОм та конденсатора 0.015 мкФ, що створює спад амплітудно-частотної характеристики на частотах понад 1 кГц. 

Випробування проводять у чотирьох комбінаціях аварійних станів (Single Condition Faults):
1. Обрив захисного заземлення (`PE Open`);
2. Переворот фаз живлення мережі (`Phase Reversal`);
3. Обрив одного з провідників живлення (`Neutral Open`);
4. Подача мережевої напруги 240 В безпосередньо на ізольовану робочу частину типу CF (`Voltage on Applied Part`). 

Прилад вважається безпечним лише у разі, якщо у кожній із цих комбінацій струм витоку не перевищує 50 мкА.

### Порівняльна характеристика дії постійного струму (DC)

Для постійного струму (DC) порогові значення струму ураження є значно вищими, ніж для змінного струму 50/60 Гц. Це пояснюється тим, що постійний струм не викликає безперервної високочастотної стимуляції мембранних іонних каналів з частотою 50 разів на секунду.

| Порівняльний параметр | Змінний струм 50 Гц (AC) | Постійний струм (DC) | Коефіцієнт відношення (DC / AC) |
| :--- | :--- | :--- | :--- |
| **Поріг відчуття (`I_percept`)** | 0.5 мА | 2.0 мА | 4.0 |
| **Поріг невідпускання (`I_letgo`)** | 10 мА | 300 мА | 30.0 |
| **Поріг фібриляції (`t > 1` с, 5% ймовірності)** | 35 мА (RMS) | 150 мА | 4.3 |
| **Поріг фібриляції (`t < 0.1` с)** | 500 мА | 500 мА (при замиканні) | 1.0 |

Критична особливість постійного струму полягає у тому, що небезпека фібриляції виникає переважно у момент **включення або виключення (колізії)** струму, коли похідна `dI/dt` є максимальною і викликає швидкий деполяризаційний стимул.

### Електричний опір тіла людини (`Z_body`) та феномен електропорації

Струм `I`, який проходить через серце потерпілого при контакті з джерелом напруги `U`, визначається повним електричним опором тіла `Z_body`.

Еквівалентна електрична схема тіла людини складається з трьох послідовних елементів:
```
Z_body(U) = R_skin1(U, S, state) + R_internal + R_skin2(U, S, state)
```

де:
- `R_internal` — внутрішній опір органів, крові та м'язів (`R_internal ≈ 500 ... 700` Ом, практично не залежить від напруги);
- `R_skin1`, `R_skin2` — опори епідермісу шкіри у точках входу та виходу струму. Опір шкіри є нелінійним: при зростанні напруги `U` тонкий шар рогового епідермісу зазнає електричного пробою (мікропорації), і його опір падає майже до нуля.

#### Фізика електропорації рогового шару шкіри

Роговий шар епідермісу (*stratum corneum*) товщиною 10–50 мкм складається із відмерлих лусочок, насичених ліпідами, і має високий питомий опір `ρ ≈ 10^5` Ом·м. 

При прикладанні зовнішньої напруги понад 50–100 В напруженість електричного поля у тонкому ліпідному шарі епідермісу досягає критичних значення `E ≈ 10^6` В/м. Відбувається **електропорація** — утворення мікроскопічних водних пор у диелектричній мембрані шкіри. В результаті опір шкіри `R_skin` стрибкоподібно падає з 100 000 Ом до кількох сотень Ом, і струм тіла обмежується виключно внутрішнім опором тканин `R_internal`.

#### Таблиця залежності опору тіла `Z_body` від прикладеної напруги (для 50% популяції, суха шкіра, площа контакту 80 см²)

| Прикладена напруга `U` (В) | Опір сухої шкіри `R_skin` (Ом) | Сумарний опір тіла `Z_body` (Ом) | Розрахунковий струм 50 Гц `I` (мА) |
| :--- | :--- | :--- | :--- |
| **25 В** | 2500 | 3250 | 7.7 мА (AC-2) |
| **50 В** | 1200 | 1850 | 27.0 мА (AC-3, поріг невідпускання) |
| **100 В** | 700 | 1350 | 74.0 мА (AC-4.1) |
| **230 В (побутова мережа)** | 250 | **1000** | **230.0 мА (AC-4.2, ВИСОКИЙ РИЗИК ФШ)** |
| **400 В (промислова мережа)** | 100 | 700 | 571.0 мА (AC-4.3) |
| **1000 В** | 0 (пробій) | 500 | 2000.0 мА (тяжкі опіки, зупинка серця) |

У вологому середовищі або при зануренні у воду (солона вода) опір шкіри `R_skin → 0`. У цьому випадку сумарний опір тіла становить `Z_body ≈ 500 ... 700` Ом навіть при низькій напрузі 12–24 В.

### Параметри дефібриляційних імпульсів (IEC 60601-2-4)

Стандарт IEC 60601-2-4 регулює вимоги до безпеки та ефективності медичних дефібриляторів.

#### 1. Однофазний зрізаний експоненційний імпульс (MTE, Monophasic Truncated Exponential)

В історичних приладах розряд накопичувального конденсатора ємністю `C` через опір тіла пацієнта `R_patient` описується формулою:

```
V(t) = V_0 · e^(-t / (R_patient · C))
I(t) = (V_0 / R_patient) · e^(-t / (R_patient · C))
```

Енергія розряду `E`, що передається пацієнту за час імпульсу `T_pulse`, обчислюється як:

```
E = ∫_0^(T_pulse) V(t) · I(t) dt = (1/2) · C · V_0² · [1 - e^(-2·T_pulse / (R_patient · C))]
```

Типові параметри однофазного імпульсу MTE:
- Початкова напруга розряду `V_0 = 3000 ... 5000` В;
- Накопичена енергія `E = 200 ... 360` Дж;
- Тривалість імпульсу `T_pulse = 6 ... 12` мс;
- Піковий струм розряду `I_peak = 40 ... 80` А.

#### 2. Двофазний зрізаний експоненційний імпульс (BTE, Biphasic Truncated Exponential)

Сучасні дефібрилятори застосовують двофазні хвилі, які деполяризують міокард першою позитивною фазою, а потім перемикають полярність на зворотну за допомогою H-мостової схеми ключових транзисторів.

| Параметр імпульсу BTE | Перша фаза (деполяризація) | Друга фаза (зняття поляризації) |
| :--- | :--- | :--- |
| **Полярність на електродах** | Пряма (електрод 1: +, електрод 2: -) | Зворотна (електрод 1: -, електрод 2: +) |
| **Початкова напруга `V_start`** | `1500 ... 2200` В | `400 ... 600` В |
| **Тривалість фази `t_phase`** | `4.0 ... 6.0` мс | `2.0 ... 4.0` мс |
| **Відносне зрізання імпульсу (Tilt)** | `50% ... 65%` | `40% ... 50%` |
| **Достатня дефібрилююча енергія `E`** | **150 ... 200 Дж** | **150 ... 200 Дж** |

Загальний спад напруги імпульсу (коефіцієнт Tilt) визначається формулою:

```
Tilt = (V_start - V_end) / V_start
```

Ніусяжність BTE-імпульсу полягає у тому, що друга хвиля протилежної полярності видаляє поляризаційні іони на зовнішніх поверхонь мембран кардіоміоцитів. Це знижує поріг дефібриляції у 2 рази порівняно з MTE, дозволяючи зменшити енергію розряду з 360 Дж до 150 Дж та запобігти термічному некрозу тканини.

#### 3. Алгоритм адаптації до опору пацієнта (Impedance Compensation)

Опір грудної клітки людини під дефібриляційними електродами варіюється у діапазоні від `R_patient = 25` Ом (повні пацієнти з великими електродами) до `R_patient = 175` Ом (худорляві пацієнти з поганим контактом).

Сучасні АЗД вимірюють опір `R_patient` за допомогою вимірювального високочастотного підпорогового струму (30 кГц) безпосередньо перед розрядом і автоматично коригують тривалість фаз `t_1` та `t_2`:
- При низькому опорі (`R = 30` Ом) часовий крок фази скорочується (`t_1 = 3.5` мс), щоб запобігти надмірному струму `I_peak > 60` А.
- При високому опорі (`R = 150` Ом) тривалість фази збільшується (`t_1 = 9.0` мс), щоб залишкова напруга встигла доставити необхідну щільність заряду до міокарда.

#### 4. Алгоритми автокласифікації ЕКГ у автоматичних зовнішніх дефібриляторах (АЗД)

Автоматичний дефібрилятор самостійно аналізує вхідний ЕКГ-сигнал пацієнта перед подачею команди на розряд. Алгоритм витягує три основні часові та частотні характеристики:

1. **Морфологічна частота розтягування (VF Leak Rate):** Обчислюється середня швидкість перебування сигналу поза базовою ізолінією. Сигнал ЕКГ оцифровується з частотою дискретизації 500 Гц. Якщо амплітуда відхилення від нуля перевищує поріг 0.05 мВ, комірка вважається активною. Для нормального синусового ритму сигнал перебуває на ізолінії понад 70% часу. При фібриляції шлуночків ізолінія повністю зникає, і показник витоку перевищує 80%.
2. **Частотний аналіз Швидкого Перетворення Фур'є (FFT Spectrum):** Обчислюється спектральна щільність потужності ЕКГ на вікні розміром 1024 точок (2.05 секунди). Спектральний масив аналізується на наявність домінуючого спектрального піку. Якщо понад 80% загальної енергії сигналу зосереджено у вузькій частотній смузі від 3 Гц до 9 Гц (домінуюча частота тріпотіння та фібриляції шлуночків), алгоритм класифікує ритм як дефібрилябельний (*Shockable Rhythm*).
3. **Оцінка амплітуди пилки (VF Peak-to-Peak Amplitude):** Дрібнохвильова фібриляція з піковою амплітудою менше 0.1 мВ відокремлюється від асистолії (повної відсутності електричної активності). При асистолії дефібриляційний розряд є неефективним і протипоказаним, оскільки він додатково пошкоджує виснажений міокард; в цьому випадку прилад рекомендує негайно розпочати серцево-легеневу реанімацію.
