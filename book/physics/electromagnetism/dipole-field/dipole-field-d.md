</preknowlist>

Коли незаряджений шматок пластику чи краплина води притягується до наелектризованого гребінця на відстані кількох сантиметрів, сумарний електричний заряд цієї краплини дорівнює нулю з точністю до одного електрона. Якби взаємодія описувалася виключно кулонівським полем одиночних зарядів, електронейтральні тіла залишалися б повністю байдужими до зовнішніх електричних полів. Проте у реальному фізичному світі позитивні та негативні заряди всередині атомів і молекул не збігаються в одній точці абсолютного нуля: вони зміщені один відносно одного на субнанометрові відстані. Ця фундаментальна незбіжність центрів ваги зарядів утворює електричний диполь — найпростішу нейтральну систему, здатну створювати власне поле у просторі та реагувати на зовнішні електричні сили.

Термін «диполь» походить від грецьких слів *δίς* (dis — двічі, подвійно) та *πόλος* (polos — вісь, полюс), що буквально означає «двополюсник». Електричний диполь є фундаментальною цеглиною електродинаміки суцільних середовищ, молекулярної фізики та хімії. Без урахування дипольної структури речовини неможливо пояснити ні високу діелектрична проникність води, ні поширення радіохвиль антенами, ні роботу мікрохвильової печі, ні механізми міжмолекулярного зчеплення у біологічних мембранах.

## 1. Концептуальна сутність та векторний момент диполя

У найпростішій точковій моделі електричний диполь являє собою сукупність двох точкових зарядів, рівних за величиною `q` і протилежних за знаком (`+q` та `−q`), розташованих на фіксованій відстані `d` один від одного. Відстань `d` розглядається як вектор плеча диполя, спрямований від негативного заряду `−q` до позитивного заряду `+q`.

Головною характеристикою такої системи є вектор електричного дипольного моменту `p`. За означенням, він дорівнює добутку величини позитивного заряду `q` на вектор плеча `d`:

```
p = q · d      [векторний дипольний момент]
```

Одиницею вимірювання дипольного моменту в Міжнародній системі одиниць SI є кулон-метр (`C·m`). У атомній та молекулярній фізиці величина `1 C·m` є колосально великою, тому практично завжди використовують позасистемну одиницю дебай (на честь фізика Петера Дебая, [Історія дослідження диполів](book:physics/electromagnetism/dipole-field/hist-dipole-concept.md)):

```
1 D = 3.33564 · 10⁻³⁰ C·m      [значення одиниці дебай у SI]
```

Для прикладу, молекула води `H₂O` має постійний дипольний момент `p = 1.85 D` (`6.17 · 10⁻³⁰ C·m`), що виникає через високу електронегативність атома кислороду та кутову геометричну форму молекули (кут між зв'язками `O-H` становить `104.5°`). Молекула хлороводню `HCl` має момент `1.08 D`, молекула аміаку `NH₃` — `1.47 D`, ацетону `(CH₃)₂CO` — `2.88 D`, а йонні парні молекули солі `NaCl` у газовій фазі володіють велетенським моментом `9.0 D`. Натомість повністю симетричні молекули, такі як метан `CH₄`, вуглекислий газ `CO₂` чи бензол `C₆H₆`, мають строго нульовий постійний дипольний момент (`p = 0`).

![Геометрія електричного диполя](/book/physics/electromagnetism/dipole-field/img/dipole-vector-setup.svg)
*Геометрія двох точкових зарядів протилежного знака та векторний розрахунок потенціалу в точці P.*

Якщо система складається не з двох зарядів, а з довільного розподілу за об'ємом із густиною заряду `ρ(r)`, загальне математичне означення дипольного моменту набуває вигляду інтеграла по всьому об'єму `V`:

```
p = ∫ r · ρ(r) · dV      [дипольний момент довільного розподілу заряду]
```

Важливою властивістю дипольного моменту є його інваріантність відносно вибору початку координат: якщо сумарний заряд системи дорівнює нулю (`Q = ∑ qᵢ = 0`), вектор `p` не залежить від того, в якій точці простору вибрано початок відліку. Це робить дипольний момент об'єктивною внутрішньою характеристикою нейтральної системи.

Доведемо цю інваріантність математично. Нехай початок координат змістився на постійний вектор `r₀`, тоді нові радіус-вектори зарядів дорівнюють `rᵢ' = rᵢ − r₀`. Обчислимо дипольний момент у новій системі координат:

```
p'
= ∑ qᵢ · (rᵢ − r₀)                                           [зміщення початку координат]
= ∑ qᵢ · rᵢ − r₀ · (∑ qᵢ)                                    [розкриття дужок]
= p − r₀ · Q                                                 [підстановка сумарного заряду Q]
```

Якщо система є нейтральною (`Q = 0`), другий доданок зникає, і `p' = p`. Якщо ж сумарний заряд системи не дорівнює нулю (`Q ≠ 0`), значення дипольного моменту залежить від вибору початку координат, тому для заряджених систем дипольний момент зазвичай обчислюють відносно центру мас або центру зарядів.

## 2. Електричний потенціал дипольного поля

Оскільки диполь складається з двох протилежних зарядів, створюване ним електричне поле обчислюється як векторна сума полів кожного із зарядів за принципом суперпозиції. Проте, на відміну від одиночного точкового заряду (монополя), чий потенціал спадає обернено пропорційно першому степеню відстані (`φ ~ 1/r`), потенціал диполя спадає значно швидше — обернено пропорційно квадрату відстані (`φ ~ 1/r²`).

Розглянемо точку спостереження `P`, розташовану на відстані `r` від центру диполя під полярним кутом `θ` до осі диполя. Якщо відстань `r` значно перевищує розміри самого диполя (`r >> d`), можна застосувати розклад у ряд Тейлора за малим параметром `d / r` ([Математичний вивід потенціалу та поля](book:physics/electromagnetism/dipole-field/math-dipole-derivation.md)):

```
φ(r, θ)
= (1 / (4·π·ε₀)) · (q / r₊ − q / r₋)                         [суперпозиція кулонівських потенціалів]
= (1 / (4·π·ε₀)) · (p · cos θ) / r²                          [наближення далекого поля r >> d]
```

У векторній формі, через скалярний добуток дипольного моменту `p` на одиничний радіус-вектор `r̂ = r / r`:

```
φ(r) = (1 / (4·π·ε₀)) · (p · r̂) / r² = (1 / (4·π·ε₀)) · (p · r) / r³      [інваріантний потенціал диполя]
```

Причиною прискореного спадання потенціалу є взаємне гасіння (компенсація) полів позитивного та негативного зарядів. На великих відстанях заряди `+q` та `−q` бачаться практично з одного кута, тому їхні потенціали майже повністю віднімаються. Лише незначна просторова зсунутість `d` залишає ненульовий залишок, який залежить від орієнтації диполя в просторі.

Аналіз формули потенціалу розкриває важливі фізичні властивості:
1. **На осі диполя (`θ = 0` або `θ = π`)**: потенціал приймає максимальні за модулем значення `φ = ± (1 / (4πε₀)) · (p / r²)`. З боку позитивного заряду потенціал додатний, з боку негативного — від'ємний.
2. **На екваторіальній площині (`θ = π/2`)**: полярний кут `cos(π/2) = 0`, тому потенціал на всій площині симетрії строго дорівнює нулю (`φ = 0`). Будь-яка точка цієї площини знаходиться на однаковій відстані від `+q` та `−q`, тому потенціали двох зарядів повністю компенсують один одного.

З практичної точки зору це означає, що еквіпотенціальні поверхні диполя утворюють дві замкнені сфероподібні каплиноподібні частки, розділені нульовою екваторіальною площиною. Перетин цих поверхонь площиною малюнка створює дві сімейства замкнених ліній потенціалу різного знака.

## 3. Напруженість поля диполя: радіальна та кутова компоненти

Напруженість електричного поля `E` є від'ємним градієнтом скалярного потенціалу (`E = −∇φ`). Обчислюючи градієнт у сферичній системі координат `(r, θ, φ)` для азимутально симетричного потенціалу, отримуємо ортогональні компоненти поля:

```
E_r = −∂φ / ∂r = (1 / (4·π·ε₀)) · (2·p · cos θ) / r³         [радіальна компонента напруженості]
E_θ = −(1/r) · ∂φ / ∂θ = (1 / (4·π·ε₀)) · (p · sin θ) / r³    [полярна кутова компонента напруженості]
E_φ = 0                                                       [азимутальна компонента через симетрію]
```

Модуль повного вектора напруженості `E = √(E_r² + E_θ²)` виражається формулою:

```
E(r, θ) = (1 / (4·π·ε₀)) · (p / r³) · √(1 + 3·cos² θ)        [модуль поля диполя у довільній точці]
```

Зверніть увагу на закон спадання поля: напруженість дипольного поля спадає обернено пропорційно кубу відстані (`E ~ 1/r³`), на відміну від монопольного поля Кулона (`E ~ 1/r²`). Це означає, що поле диполя є набагато більш локалізованим у просторі: при подвоєнні відстані поле точкового заряду зменшується у `4` рази, а поле диполя — у `8` разів.

![Силові лінії поля диполя](/book/physics/electromagnetism/dipole-field/img/dipole-field-lines.svg)
*Картина силових ліній поля диполя та порівняння напрямку напруженості на полюсах і екваторі.*

Розглянемо два граничні випадки геометрії поля:
- **На полюсі (полярна вісь, `θ = 0` або `θ = π`)**: кутова компонента дорівнює нулю (`E_θ = 0`), а радіальна компонента є максимальною:
  ```
  E_полюс = (1 / (4·π·ε₀)) · (2·p) / r³                      [напруженість на осі диполя]
  ```
  Вектор поля `E` на осі спрямований паралельно дипольному моменту `p` (на північному полюсі) або протилежно йому (на південному полюсі).
- **На екваторі (екваторіальна площина, `θ = π/2`)**: радіальна компонента дорівнює нулю (`E_r = 0`), а кутова компонента дорівнює:
  ```
  E_екватор = (1 / (4·π·ε₀)) · p / r³                        [напруженість на екваторі]
  ```
  Вектор поля `E` на екваторі спрямований строго антипаралельно дипольному моменту `p`.

Порівняння двох геометрій демонструє характерну асиметрію: на однаковій відстані `r` поле на полюсі вдвічі сильніше за поле на екваторі (`E_полюс = 2 · E_екватор`).

Для довільної системи координат вектор поля диполя записується у компактній безкоординатній (інваріантній) формі:

```
E(r) = (1 / (4·π·ε₀·r³)) · [ 3 · (p · r̂) · r̂ − p ]           [векторне рівняння поля диполя]
```

Ця формула є базовою при розрахунку взаємодії між декількома диполями у молекулярній динаміці та чисельному моделюванні ([Чисельне моделювання поля диполя](book:physics/electromagnetism/dipole-field/proj-dipole-field-sim.md)).

Кут `α` між радіус-вектором `r` та вектором напруженості електричного поля `E` визначається через співвідношення компонент:

```
tg α = E_θ / E_r = (p sin θ / r³) / ((2p cos θ) / r³) = (1/2) · tg θ     [зв'язок кутів напрямку поля]
```

Це геометричне правило дозволяє будувати силові лінії поля безпосередньо: рівняння силової лінії у полярних координатах виражається як `r(θ) = C · sin² θ`, де `C` — константа, що характеризує конкретну силову лінію. Усі силові лінії виходять із позитивного заряду `+q` та входять у негативний заряд `−q`, утворюючи характерну пелюсткову структуру.

## 4. Поведінка диполя у зовнішньому однорідному електричному полі

Коли диполь вміщують у зовнішнє електричне поле `E_зовн`, кожен із його зарядів зазнає дії електростатичних сил Кулона: на позитивний заряд діє сила `F₊ = q · E_зовн`, а на негативний — сила `F₋ = −q · E_зовн`.

Якщо зовнішнє поле є **однорідним** (напруженість однакова у всіх точках), сумарна рівнодійна сила, що діє на диполь як ціле, дорівнює нулю:

```
F_сумарна = F₊ + F₋ = q · E_зовн − q · E_зовн = 0            [рівнодійна сила в однорідному полі]
```

Це означає, що однорідне електричне поле не викликає поступального прискорення нейтрального диполя. Проте оскільки сили `F₊` та `F₋` прикладені до різних точок, рознесених на відстань `d`, вони утворюють пару сил з ненульовим обертальним моментом (механічним моментом сил) `τ`.

![Диполь у зовнішньому полі](/book/physics/electromagnetism/dipole-field/img/dipole-torque-energy.svg)
*Обертальний момент сил у зовнішньому однорідному полі та потенціальна енергія як функція полярного кута.*

Вектор обертального моменту `τ` дорівнює векторному добутку дипольного моменту `p` на вектор зовнішнього поля `E_зовн`:

```
τ = p × E_зовн      [векторний обертальний момент]
```

Модуль обертального моменту дорівнює `τ = p · E_зовн · sin θ`, де `θ` — кут між вектором диполя та напрямком поля. Цей момент прагне розвернути диполь так, щоб вектор `p` збігся за напрямком із зовнішнім полем `E_зовн` (тобто зменшити кут `θ` до нуля).

Потенціальна енергія `U` диполя у зовнішньому полі визначається роботою, яку необхідно виконати проти обертального моменту при повороті диполя від нейтрального стану (`θ = π/2`):

```
U(θ) = −p · E_зовн = −p · E_зовн · cos θ                    [потенціальна енергія диполя в полі]
```

Аналіз стану енергії показує два аналітичні екстремуми:
1. **Стійка рівновага (`θ = 0`, `p ∥ E_зовн`)**: диполь орієнтований уздовж поля. Енергія є мінімальною (`U_min = −p · E`), обертальний момент дорівнює нулю (`τ = 0`). Будь-яке мале відхилення викликає повертальний момент.
2. **Нестійка рівновага (`θ = π`, `p ⇈ −E_зовн`)**: диполь спрямований проти поля. Енергія є максимальною (`U_max = +p · E`), обертальний момент дорівнює нулю (`τ = 0`). Проте найменший поштовх виводить диполь із цього стану, змушуючи його перевернутися у положення `θ = 0`.

> 🔧 **Навіщо це.** На явищі повороту диполів у зовнішньому змінному полі базується дія мікрохвильових печей. Вплив високочастотного електромагнітного поля із частотою `2.45 GHz` змушує молекули води в їжі переорієнтовуватися `4.9 · 10⁹` разів на секунду. Мікроскопічне тертя між молекулами при орієнтаційному обертанні перетворює енергію поля на теплову енергію, швидко розігріваючи матеріал по всьому об'єму.

Якщо диполь відхилити від стану стійкої рівноваги `θ = 0` на малий кут `θ << 1`, обертальний момент можна наблизити як `τ ≈ −p · E · θ`. Уподібнюючи це рівняння до закону Гука для обертального руху, отримуємо диференціальне рівняння гармонічних коливань диполя з моментом інерції `I`:

```
I · (d²θ / dt²) + p · E · θ = 0                              [коливальне рівняння диполя]
```

Звідси кругова частота власних малих коливань диполя у полі дорівнює `ω₀ = √(p·E / I)`.

## 5. Статистична механіка Ланжевена для системи диполів

У реальних газах та рідинах диполі знаходяться у безперервному тепловому русі за температури `T`. Електричне поле намагається впорядкувати диполі уздовж свого напрямку, тоді як хаотичні теплові поштовхи дезорієнтують їх. Згідно зі статистичною механікою Больцмана, ймовірність `dP` того, що вектор диполя утворює кут у інтервалі `[θ, θ + dθ]` із полем `E`, визначається енергетичним фактором:

```
dP(θ) = C · exp( (p · E · cos θ) / (k_B · T) ) · sin θ dθ     [розподіл Больцмана по кутах]
```

де `k_B` — стала Больцмана, а `C` — нормувальна константа. Середнє значення проекції дипольного моменту на напрямок поля `⟨p_z⟩ = p · ⟨cos θ⟩` описується класичною функцією Ланжевена `L(x)`:

```
⟨cos θ⟩ = L(x) = cth(x) − (1 / x)                             [функція Ланжевена, де x = p·E / (k_B·T)]
```

Для більшості полярних рідин та газів за кімнатної температури електрична енергія є значно меншою за теплову (`x << 1`). Розкладаючи функцію Ланжевена у ряд Тейлора `L(x) ≈ x / 3`, отримуємо середній орієнтаційний момент однієї молекули:

```
⟨p_z⟩ ≈ (p² · E) / (3 · k_B · T)                              [середній дипольний момент за високих температур]
```

Цей вираз пояснює, чому орієнтаційна поляризація зменшується обернено пропорційно абсолютній температурі (`P ~ 1/T`), що становить зміст відомого експериментального закону Кюрі — Дебая.

## 6. Диполь у неоднорідному полі: сила та діелектрофорез

Якщо зовнішнє електричне поле є **неоднорідним** (значення напруженості змінюється від точки до точки), поле на позитивному заряді `E(r + d)` не дорівнює полю на негативному заряді `E(r)`. У цьому випадку рівнодійна сила вже не дорівнює нулю!

Розкладаючи поле у ряд Тейлора поблизу розташування диполя, отримуємо вираз для втягуючої сили:

```
F = (p · ∇)E      [сила, що діє на диполь у неоднорідному полі]
```

У декартових координатах компоненти сили виражаються скалярним добутком вечора `p` на градієнти відповідних компонент поля:

```
F_x = p_x · (∂E_x / ∂x) + p_y · (∂E_x / ∂y) + p_z · (∂E_x / ∂z)
F_y = p_x · (∂E_y / ∂x) + p_y · (∂E_y / ∂y) + p_z · (∂E_y / ∂z)
F_z = p_x · (∂E_z / ∂x) + p_y · (∂E_z / ∂y) + p_z · (∂E_z / ∂z)
```

Якщо диполь вже встиг орієнтуватися уздовж силових ліній поля (`p ∥ E`), формула спрощується до градієнта модуля напруженості:

```
F = ∇(p · E) = p · ∇E      [сила орієнтованого диполя в напрямку градієнта поля]
```

Цей результат пояснює фундамент ефекту: **орієнтований диполь завжди притягується в область сильнішого електричного поля**, незалежно від знака вихідного джерела поля! 

Саме ця сила змушує незаряджений шматочок паперу або струмінь води притягуватися до наелектризованої палички. Паличка створює неоднорідне поле, яке спочатку орієнтує молекулярні диполі паперу, а потім втягує їх у зону максимальної напруженості поблизу палички. У сучасній мікрофлюїдиці та біотехнологіях це явище називається **діелектрофорезом** (dielectrophoresis) і використовується для сортування та уловлювання окремих живих клітин, ДНК та вірусів у неоднорідних мікроелектродних полях.

При діелектрофорезі сила, що діє на сферичну мікрочастинку радіуса `a`, занурену у середовище з діелектричною проникністю `ε_m`, виражається через фактор Клаузіуса — Моссотті `K(ω)`:

```
F_DEP = 2 · π · ε₀ · ε_m · a³ · Re[K(ω)] · ∇|E_rms|²        [середня сила діелектрофорезу]
```

Залежно від знака дійсної частини фактора Клаузіуса — Моссотті `Re[K(ω)]`, частинки можуть або втягуватися в області сильного поля (позитивний діелектрофорез), або виштовхуватися з них (негативний діелектрофорез), що дозволяє безконтактно розділяти біологічні клітини з високою точністю.

## 7. Поляризація речовини та діелектричні середовища

Коли сукупність великої кількості молекул вміщується в електричне поле, їхні індивідуальні дипольні моменти підпорядковуються макроскопічному закону поляризації. Макроскопічним параметром стану діелектрика є **вектор поляризованості** (вектор поляризації) `P`, який визначається як дипольний момент одиниці об'єму речовини:

```
P = (1 / ΔV) · ∑ pᵢ = N · ⟨p⟩      [вектор поляризації об'єму]
```

де `N` — концентрація молекул в одиниці об'єму, а `⟨p⟩` — середній дипольний момент однієї молекули.

![Орієнтаційна поляризація діелектрика](/book/physics/electromagnetism/dipole-field/img/dielectric-polarization.svg)
*Хаотичний тепловий рух молекулярних диполів за відсутності поля та їхня впорядкованість під дією зовнішнього електричного поля.*

Розрізняють два основні механізми поляризації діелектриків:
1. **Деформаційна (електронна та атомна) поляризація**: виникає у неполярних молекулах, де під дією зовнішнього поля електронні хмари зміщуються відносно ядер, індукуючи тимчасовий дипольний момент `p_індук = α · E_зовн` (де `α` — електронна поляризовності).
2. **Орієнтаційна (дипольна) поляризація**: властива полярним речовинам з постійними дипольними моментами `p₀`. Зовнішнє поле орієнтує хаотично спрямовані диполі, долаючи опір теплового руху.

Поляризований діелектрик створює всередині себе власне протилежно спрямоване електричне поле `E_внутр`, яке послаблює зовнішнє поле у `ε_r` разів (де `ε_r` — відносна діелектрична проникність середовища):

```
E_середовище = E_зовн / ε_r      [послаблення поля в діелектрику]
```

Зв'язок між вектором поляризованості `P`, напруженістю `E` та вектором електричного зсуву (індукції) `D` описується базовими співвідношеннями електродинаміки суцільних середовищ:

```
D = ε₀ · E + P = ε₀ · ε_r · E      [вектор електричного зсуву в середовищі]
```

Зв'язаний поверхневий заряд `σ_b`, що виникає на межі поляризованого діелектрика, строго дорівнює нормальній компоненті вектора поляризації `σ_b = P · n̂`. Саме цей поверхневий заряд створює розпровіднювальне поле, що зменшує напруженість усередині конденсатора.

## 8. Дипольні взаємодії у біофізиці та міжмолекулярних силах

Диполь-дипольні взаємодії лежать в основі міжмолекулярних сил Ван-дер-Ваальса, що визначають температури кипіння рідин, просторову структуру білків та згортання ланцюгів ДНК. Розрізняють три типи дипольних сил:

1. **Орієнтаційні сили (сили Кеезома)**: виникають між двома полярними молекулами з постійними дипольними моментами `p₁` та `p₂`. Усереднена по теплових орієнтаціях енергія притягання спадає як шостий степінь відстані:
   ```
   U_Keesom = −(2 / 3) · (p₁² · p₂²) / ((4·π·ε₀)² · k_B · T · r⁶)       [енергія взаємодії Кеезома]
   ```
2. **Індукційні сили (сили Дебая)**: виникають між полярною молекулою `p₁` та неполярною молекулою з поляризовністю `α₂`. Полярна молекула індукує диполь у сусідній, що створює постійне притягання `U_Debye = −(2 · α₂ · p₁²) / ((4·π·ε₀)² · r⁶)`.
3. **Дисперсійні сили (сили Лондона)**: виникають між двома неполярними молекулами через миттєві флуктуації електронної густини, які створюють короткочасні флуктуючі дипольні моменти `U_London ~ 1 / r⁶`.

У структурній біології пептидний зв'язок `C=O...N-H` у білках володіє значним дипольним моментом `p ≈ 3.5 D`. При формуванні спиралі (α-helix) усі пептидні диполі орієнтуються в одному напрямку вздовж осі спіралі, утворюючи макроскопічний **макродиполь білка** з моментом у `20–50 D`. Цей макродиполь відіграє ключову роль у ферментативному каталізі та орієнтації субстратів у активних центрах ферментів.

## 9. Динамічна дисперсія та модель Дебая

У змінних електричних полях високої частоти орієнтація диполів перестає миттєво встигати за зміною поля через в'язке тертя середовища. Цей релаксаційний процес описується динамічною діелектричною проникністю у комплексному вигляді:

```
ε*(ω) = ε_inf + (ε_s − ε_inf) / (1 + j · ω · τ_D)           [комплексна формула Дебая]
```

де `ε_s` — статична діелектрична проникність на низьких частотах, `ε_inf` — оптична діелектрична проникність на високих частотах (де встигає діяти лише електронна поляризація), `τ_D` — час дипольної релаксації Дебая, а `ω` — кругова частота поля.

Уявна частина комплексної діелектричної проникності `Im[ε*(ω)]` характеризує діелектричні втрати — перетворення енергії електромагнітного поля на тепло. Максимум діелектричних втрат спостерігається на частоті релаксації `f_D = 1 / (2·π·τ_D)`. Для рідкої води при кімнатній температурі час релаксації становить `τ_D ≈ 8.3 ps`, що відповідає частоті `f_D ≈ 19.2 GHz`.

## 10. Елементарний диполь Герца та радіовипромінювання

Якщо дипольний момент змінюється в часі (`p = p(t)`), такий диполь перестає бути чисто електростатичним об'єктом і перетворюється на джерело електромагнітних хвиль — **випромінювальний диполь Герца**.

На великих відстанях (у дальній зоні випромінювання, `r >> λ`) амплітуда поля хвилі спадає повільніше за статичне поле — як `1 / r`:

```
E_хвиля(r, θ, t) = (1 / (4·π·ε₀·c²)) · (p̈(t − r/c) · sin θ) / r   [поле випромінювання диполя Герца]
```

де `p̈` — друга похідна дипольного моменту по часу (прискорення зарядів), `c` — швидкість світла, а `λ` — довжина хвилі.

Полна середня потужність `I`, що випромінюється диполем Герца у простір, описується знаменитою формулою Лармора:

```
I = (1 / (6 · π · ε₀ · c³)) · ⟨p̈²⟩                           [формула Лармора для потужності випромінювання]
```

Цей результат є фундаментальним у радіотехніці та антенах: будь-яка антена (від найпростішого симетричного диполя Надененка до складних антен мобільних телефонів) працює на принципі збудження гармонічного дипольного моменту.

## 11. Мультипольний розклад та вищі електричні моменти

Диполь є лише другим членом нескінченного математичного розкладу потенціалу довільної системи зарядів по степенях `1/r`, який називається **мультипольним розкладом** (від лат. *multus* — численний та грец. *πόλος* — полюс).

Загальний розклад потенціалу складного розподілу зарядів у точці на великій відстані `r` має вигляд:

```
φ(r)
= φ_монополь + φ_диполь + φ_квадруполь + φ_октуполь + ...   [мультипольний розклад потенціалу]
= (1 / (4·π·ε₀)) · [ Q / r + (p · r̂) / r² + (1/2) · (r̂ · Q̂_квадр · r̂) / r³ + ... ]
```

Аналіз членів мультипольного розкладу:
- **Монопольний член (`1/r`)**: визначається сумарним зарядом системи `Q = ∑ qᵢ`. Якщо `Q ≠ 0`, на великих відстанях цей член є домінуючим.
- **Дипольний член (`1/r²`)**: визначається дипольним моментом `p = ∑ qᵢ · rᵢ`. Для електронейтральних систем (`Q = 0`) цей член стає головним доданком початкового поля.
- **Квадрупольний член (`1/r³`)**: визначається тензором квадрупольного моменту `Q̂_квадр` (система з двох зустрічних диполів із сумарним зарядом і сумарним дипольним моментом, рівними нулю, наприклад, молекула `CO₂`).
- **Октупольний член (`1/r⁴`)**: описує ще вищу симетрію розподілу зарядів (наприклад, кубічне розташування 8 зарядів).

Мультипольний розклад дозволяє з високою точністю розраховувати складні міжмолекулярні взаємодії у квантовій хімії та кристалографії, замінюючи мільйони взаємодій окремих електронів і ядер кількома головними мультипольними моментами.

## 12. Програмний інтерфейс розрахунку диполя

При практичній реалізації фізичних симуляцій, обчисленні молекулярних структур або аналізі сигналів антен виникає потреба в описі обчислювального API. Спеціалізована вставка розглядає архітектуру програмного контракту мовами C та C++ ([Специфікація обчислювального API](book:physics/electromagnetism/dipole-field/api-dipole-calc.md)).

Ключовими вимогами до чисельного програмного забезпечення є:
- Захист від ділення на нуль у точках розташування зарядів за допомогою параметрів згладжування (`cutoff`).
- Сувора відповідність системі одиниць SI чи атомарним одиницям (Hartree/Bohr).
- Використання векторних типів даних та контейнерів із гарантією пам'яті (RAII у C++).

Електричний диполь залишається фундаментальним містком, який з'єднує мікроскопічний світ атомних зарядів із макроскопічними законами електродинаміки суцільних середовищ.
