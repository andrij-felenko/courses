# 📋 Довідник операторів, потенціалів та компонент закону Фарадея

Цей довідник містить систематизовані математичні таблиці фізичних величин, системних операторів векторного аналізу у декартових, циліндричних та сферичних координатах, релятивістські тензорні тотожності та граничні умови для диференціального закону Фарадея `∇ × E = −∂B/∂t`.

## 1. Систематичний огляд фізичних величин та векторних операторів

Закон електромагнітної індукції Фарадея у диференційній формі є фундаментальним векторним рівнянням у частинних похідних першого порядку. Для суворого застосування цього рівняння у фізичних розрахунках, аналізі полів та чисельному моделюванні необхідно чітко розрізняти скалярні й векторні характеристики електромагнітного поля, їхні розмірності у міжнародній системі одиниць СІ та їхні безпосередні фізичні функції.

Диференціальна форма описує стан поля локально у кожній нескінченно малій точці простору. Вона пов'язує просторову вихровість (ротор) напруженості електричного поля з часовою швидкістю зміни магнітної індукції.

У наведеній нижче довідковій таблиці підсумовано розмірності СІ, базові математичні вирази, векторні оператори та фізичну роль усіх величин, що входять до диференціального закону Фарадея та його потенціального розкладу Гельмгольца.

| Фізична величина / Оператор | Символ у СІ | Одиниця вимірювання (СІ) | Математичний вираз | Фізичний зміст та роль у системі |
| :--- | :--- | :--- | :--- | :--- |
| Напруженість електричного поля | `E` | Вольт на метр (В/м) | `E = −∇φ − ∂A/∂t` | Силове поле, що діє на електричний заряд `F = q E` |
| Магнітна індукція | `B` | Тесла (Тл = Вб/м²) | `B = ∇ × A` | Силове поле, що описує магнітний потік та силу Лоренца |
| Векторний потенціал магнітного поля | `A` | Вебер на метр (Вб/м) | `B = ∇ × A` | Векторне поле, часова зміна якого `−∂A/∂t` створює вихрове поле `E` |
| Скалярний електричний потенціал | `φ` | Вольт (В) | `E_кулон = −∇φ` | Потенціальна енергія одиничного заряду у статичному полі |
| Ротор напруженості електричного поля | `∇ × E` | Вольт на квадратний метр (В/м²) | `det(∇, E)` | Міра локальної замкненості (вихровості) силових ліній поля `E` |
| Часова похідна магнітної індукції | `∂B / ∂t` | Тесла за секунду (Тл/с) | `lim[Δt->0] ΔB / Δt` | Локальне джерело вихровості електричного поля зі знаком мінус |
| Магнітний потік | `Φ_B` | Вебер (Вб = Тл·м²) | `∬ [S] B · dA` | Повний макроскопічний потік силових ліній `B` через поверхню `S` |
| Електрорушійна сила (ЕРС) | `ЕРС` | Вольт (В) | `∮ [∂S] E · dl` | Повна робота вихрового поля по замкненому контуру `∂S` |

## 2. Скалярний розклад рівняння Фарадея у трьох ортогональних системах координат

У практичних інженерних та фізичних задачах розв'язання векторного рівняння `∇ × E = −∂B/∂t` зводиться до аналізу трьох скалярних диференціальних рівнянь у відповідній просторовій системі координат. Вибір системи координат визначається геометрією джерел та межами аналізованої системи.

Математично ротор векторного поля `E` у довільних ортогональних криволінійних координатах `(u₁, u₂, u₃)` з коефіцієнтами Ламе `(h₁, h₂, h₃)` обчислюється через визначник:

```
∇ × E = (1 / (h₁ h₂ h₃)) · |  h₁ e₁     h₂ e₂     h₃ e₃   |
                           | ∂/∂u₁     ∂/∂u₂     ∂/∂u₃   |
                           | h₁ E₁     h₂ E₂     h₃ E₃   |
```

### Декартові ортогональні координати `(x, y, z)`

У декартовій системі координат коефіцієнти Ламе є одиничними (`h_x = 1, h_y = 1, h_z = 1`), а базисні орти `(e_x, e_y, e_z)` є постійними за модулем і напрямком у всіх точках простору. Векторне рівняння `∇ × E = −∂B/∂t` розкладається на три незалежні проекції:

1. **Проекція на вісь X**:
   ```
   ∂E_z / ∂y − ∂E_y / ∂z = − ∂B_x / ∂t
   ```
   Ця компонента описує, як градієнт поля `E_z` уздовж осей `y` та `E_y` уздовж `z` породжує зміну магнітного поля `B_x`.

2. **Проекція на вісь Y**:
   ```
   ∂E_x / ∂z − ∂E_z / ∂x = − ∂B_y / ∂t
   ```
   Ця компонента описує просторовий зсув поля `E` у площині `xz`, який викликає часову динаміку магнітного поля `B_y`.

3. **Проекція на вісь Z**:
   ```
   ∂E_y / ∂x − ∂E_x / ∂y = − ∂B_z / ∂t
   ```
   Ця компонента описує вихровість електричного поля у горизонтальній площині `xy`, яка створює вертикальну зміну магнітного поля `B_z`.

Ці три скалярні рівняння є основою класичних 1D, 2D та 3D FDTD чисельних алгоритмів обчислювальної електродинаміки.

### Циліндричні координати `(r, θ, z)`

Для систем із вираженою осьовою симетрією (соленоїди, коаксіальні кабелі, кругові хвилеводи, індукційні печі) використовують циліндричні координати `(r, θ, z)`. Через залежність азимутального орта `e_θ` від кута `θ`, коефіцієнти Ламе дорівнюють `h_r = 1, h_θ = r, h_z = 1`.

Скалярні компоненти диференціального закону Фарадея у циліндричних координатах мають вигляд:

1. **Радіальна компонента `e_r`**:
   ```
   (1 / r) · (∂E_z / ∂θ) − ∂E_θ / ∂z = − ∂B_r / ∂t
   ```
2. **Азимутальна компонента `e_θ`**:
   ```
   ∂E_r / ∂z − ∂E_z / ∂r = − ∂B_θ / ∂t
   ```
3. **Аксиальна компонента `e_z`**:
   ```
   (1 / r) · (∂ / ∂r) (r · E_θ) − (1 / r) · (∂E_r / ∂θ) = − ∂B_z / ∂t
   ```

У випадку чистої аксіальної симетрії (`∂/∂θ = 0`), якщо електричне поле має лише азимутальну компоненту `E_θ(r, t)`, третє рівняння спрощується до класичного виразу `(1/r) ∂(r E_θ)/∂r = −∂B_z/∂t`.

### Сферичні координати `(r, θ, ϕ)`

Для систем із центральною симетрією (точкове випромінювання антен, дифракція світла на сферичних частинках, сферичні резонатори) використовують сферичні координати `(r, θ, ϕ)`. Коефіцієнти Ламе дорівнюють `h_r = 1, h_θ = r, h_ϕ = r sin θ`.

Скалярні компоненти диференційного рівняння Фарадея:

1. **Радіальна компонента `e_r`**:
   ```
   (1 / (r sin θ)) · [ ∂ / ∂θ (sin θ · E_ϕ) − ∂E_θ / ∂ϕ ] = − ∂B_r / ∂t
   ```
2. **Зенітна кутова компонента `e_θ`**:
   ```
   (1 / r) · [ (1 / sin θ) · (∂E_r / ∂ϕ) − ∂ / ∂r (r · E_ϕ) ] = − ∂B_θ / ∂t
   ```
3. **Азимутальна кутова компонента `e_ϕ`**:
   ```
   (1 / r) · [ ∂ / ∂r (r · E_θ) − ∂E_r / ∂θ ] = − ∂B_ϕ / ∂t
   ```

## 3. Релятивістське тензорне формулювання у 4D-просторі

У спеціальній теорії відносності 3-вектори `E` та `B` об'єднуються у єдиний чотиривимірний антисиметричний тензор напруженостей поля `F_{μν}` другого рангу у просторі Мінковського з часовоподібною метрикою `η_{μν} = diag(+1, −1, −1, −1)`.

Тензорна формулювання дозволяє виразити диференціальний закон Фарадея у коваріантному вигляді, який є абсолютно однаковим у всіх інерціальних системах відліку.

### Структура тензора полів `F_{μν}` та його дуального тензора `*F^{μν}`

Компоненти 4-тензора `F_{μν} = ∂_μ A_ν − ∂_ν A_μ` у матричному покомпонентному зображенні мають вигляд:

```
F_{μν} = |    0       E_x/c    E_y/c    E_z/c  |
         | −E_x/c       0     −B_z      B_y    |
         | −E_y/c      B_z       0     −B_x    |
         | −E_z/c     −B_y      B_x       0    |
```

Дуальний тензор напруженостей `*F^{μν} = (1/2) ε^{μναβ} F_{αβ}` (де `ε^{μναβ}` — 4D символ Леві-Чивіта) отримують за допомогою Hodge-двоїстості (заміна `E/c -> B` та `B -> −E/c`):

```
*F^{μν} = |    0      −B_x    −B_y    −B_z   |
          |   B_x       0     E_z/c  −E_y/c  |
          |   B_y    −E_z/c     0     E_x/c  |
          |   B_z     E_y/c  −E_x/c     0    |
```

### Коваріантні рівняння Максвелла та диференціальні форми

За допомогою дуального тензора однорідна пара рівнянь Максвелла (закон Фарадея `∇ × E = −∂B/∂t` та закон відсутності монополів `∇ · B = 0`) записується у вигляді єдиного 4-векторного диференціального рівняння:

```
∂_μ *F^{μν} = 0
```

Або у тензорних індексах через тотожність Б'янкі:

```
∂_α F_{βγ} + ∂_β F_{γα} + ∂_γ F_{αβ} = 0
```

Мовою зовнішніх диференціальних форм Картана закон Фарадея узагальнюється тотожністю для 2-форми поля `F = (1/2) F_{μν} dx^μ ∧ dx^ν`:

```
dF = 0
```

Умова `dF = 0` означає, що 2-форма електромагнітного поля є **замкненою**. За теоремою Пуанкаре у будь-якій однозв'язній області простору-часу замкнена форма є **точною**, тобто існує 1-форма 4-потенціалу `A = A_μ dx^μ`, така що:

```
F = dA
```

Це надає строгий топологічний фундамент потенціальному опису електродинаміки.

Крім того, 4-тензор `F_{μν}` формує два релятивістські інваріанти, які зберігають свої значення при будь-яких перетвореннях Лоренца:

1. **Перший інваріант поля**: `I₁ = B² − (E² / c²)`
2. **Другий інваріант поля**: `I₂ = E · B`

Якщо у деякій системі відліку вектори `E` та `B` є взаємно перпендикулярними (`E · B = 0`, як у плоскій електромагнітній хвилі), вони залишаться ортогональними у будь-якій іншій інерціальній системі відліку.

## 4. Довідник граничних умов та векторних тотожностей

Нижче наведено граничні умови для компонент поля на межі розділу середовищ та ключові тотожності векторного аналізу.

### Граничні умови на стаціонарній межі середовищ

На межі розділу двох фізичних середовищ 1 та 2 із векторними нормалями `n` диференціальні рівняння інтегрують по нескінченно малому об'єму або контуру:

- **Тангенціальна компонента напруженості електричного поля**:
  ```
  n × ( E₂ − E₁ ) = 0   ⇒   E_{1t} = E_{2t}
  ```
  Тангенціальна компонента `E_t` завжди є суворо неперервною при переході через межу двох середовищ, оскільки поверхневий магнітний струм у природі відсутній.

- **Нормальна компонента магнітної індукції**:
  ```
  n · ( B₂ − B₁ ) = 0   ⇒   B_{1n} = B_{2n}
  ```
  Нормальна компонента `B_n` завжди неперервна через відсутність магнітних монополів.

- **Гранична умова на поверхні ідеального провідника**:
  Оскільки всередині ідеального провідника поле `E = 0` та `B = 0`, на його зовнішній поверхні тангенціальна компонента електричного поля дорівнює нулю:
  ```
  E_t = 0
  ```

### Основні тотожності векторного аналізу

1. Дивергенція ротора від довільного векторного поля тотожно дорівнює нулю:
   ```
   ∇ · ( ∇ × E ) ≡ 0   ⇒   ∇ · ( − ∂B / ∂t ) = − ∂ / ∂t ( ∇ · B ) = 0
   ```
   Ця тотожність гарантує узгодженість закону Фарадея із законом відсутності магнітних зарядів `∇ · B = 0`.

2. Ротор градієнта від довільного скалярного потенціалу тотожно дорівнює нулю:
   ```
   ∇ × ( ∇φ ) ≡ 0
   ```
   Це підтверджує, що кулонівська складова електричного поля `−∇φ` не дає жодного внеску у вихровість поля `∇ × E`.

3. Тотожність подвійного ротора для вектора (розклад Лапласіана):
   ```
   ∇ × ( ∇ × E ) = ∇( ∇ · E ) − ∇² E
   ```
   Ця тотожність є ключем для виведення тривимірного хвильового рівняння для електричного поля з рівнянь Максвелла.

4. Ротор від векторного добутку:
   ```
   ∇ × ( v × B ) = (B · ∇)v − (v · ∇)B + v(∇ · B) − B(∇ · v)
   ```
   Ця формула використовується для опису конвективної індукції у рухомих середовищах та магнітній гідродинаміці (МГД).
