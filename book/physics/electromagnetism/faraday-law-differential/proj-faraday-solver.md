# ⚙️ Чисельне моделювання вихрового електричного поля на сітці (FDTD)

Ця програма показує чисельне розв'язання закону індукції Фарадея у диференційній формі `∇ × E = −∂B/∂t` за допомогою методу скінченних різниць у часовій області (Finite-Difference Time-Domain, FDTD) на шахматній сітці Йі (Yee Grid). Вставка містить детальний алгоритмічний розбір чисельної схеми, математичний аналіз стійкості Куранта, оцінку чисельної дисперсії та готові робочі реалізації мовами C та C++.

## 1. Математична схема та просторово-часова сітка Йі

Чисельне моделювання локального диференціального закону Фарадея є основним інструментом обчислювальної електродинаміки та комп'ютерного проектування радіоелектронних систем. Розглянемо одномірну плоскополяризовану електромагнітну хвилю, яка поширюється у просторі вздовж осі `z`. Електричне поле має лише азимутальну або трансляційну компоненту `E_y(z, t)`, а магнітне поле — компоненту `B_x(z, t)`.

У цій конфігурації диференційне рівняння Фарадея `∇ × E = −∂B/∂t` спрощується до однієї скалярної похідної у частинних похідних першого порядку:

```
∂B_x / ∂t = ∂E_y / ∂z
```

Для чисельного розв'язання цього рівняння застосовують метод скінченних різниць на сітці Йі (Yee Cell Grid), винайдений Кейном Йі у 1966 році. Ключовою ідеєю сітки Йі є **просторово-часове зсунення (стіггеринг)** компонент полів `E` та `B` відносно одна одної:
- Компоненти електричного поля `E_y` обчислюються у цілочисельних просторових вузлах сітки `z_k = k · Δz` у цілочисельні моменти часу `t^n = n · Δt`.
- Компоненти магнітного поля `B_x` обчислюються у напівцілих просторових вузлах `z_{k+1/2} = (k + 1/2) · Δz` у проміжні моменти часу `t^{n+1/2} = (n + 1/2) · Δt`.

Замінивши часткові похідні центральними скінченними різницями другого порядку точності `O(Δz², Δt²)`, отримуємо дискретне рівняння оновлення магнітного поля:

```
( B_x^{n+1/2}(k) − B_x^{n-1/2}(k) ) / Δt = ( E_y^{n}(k+1) − E_y^{n}(k) ) / Δz
```

Звідси отримуємо явну формулу крокового перерахунку (Leapfrog Scheme) для магнітної індукції:

```
B_x^{n+1/2}(k) = B_x^{n-1/2}(k) + (Δt / Δz) · ( E_y^{n}(k+1) − E_y^{n}(k) )
```

Ця формула показує, що нове значення магнітного поля `B_x` у вузлі `k+1/2` обчислюється виключно через попереднє значення `B_x` та просторову різницю сусідніх компонент електричного поля `E_y` у вузлах `k` та `k+1`.

Аналогічно, для перерахунку електричного поля з диференційного закону Ампера-Максвелла `∂E_y / ∂t = (1 / (μ₀ ε₀)) · (∂B_x / ∂z)` виводиться формула для `E_y`:

```
E_y^{n+1}(k) = E_y^{n}(k) + (c² · Δt / Δz) · ( B_x^{n+1/2}(k) − B_x^{n+1/2}(k-1) )
```

де `c = 1 / √(μ₀ ε₀)` — швидкість світла у вакуумі.

Перевагою сітки Йі є те, що вона природно зберігає фундаментальні векторні тотожності `∇ · B = 0` та `∇ · D = 0` на дискретному рівні з точністю до машинної машини без створення штучних магнітних монополів.

## 2. Аналіз чисельної стійкості та дисперсії

Для забезпечення правильної фізичної поведінки алгоритму FDTD та запобігання неконтрольованому зростанню помилок округлення необхідно суворо дотримуватися мовних та чисельних обмежень.

### Умова стійкості Куранта — Фрідріхса — Леві (CFL Condition)

Застосування спектрального аналізу фон Неймана до перехідної матриці крокової схеми показує, що алгоритм FDTD залишається математично стійким лише у тому випадку, коли область залежності чисельної схеми повністю покриває фізичну область залежності хвильового рівняння.

Для 1D-простору умова Куранта має вигляд:

```
S = c · Δt / Δz ≤ 1.0
```

де `S` — безрозмірне число Куранта. Якщо обрати `S > 1.0`, амплітуда полів починає експоненціально зростати у часі, що призводить до негайного переповнення чисельних типів даних (`NaN` / `Infinity`). На практиці зазвичай обирають `S = 0.99`.

Для 2D та 3D просторів умова стійкості Куранта узагальнюється виразом:

```
Δt ≤ 1 / ( c · √( (1/Δx²) + (1/Δy²) + (1/Δz²) ) )
```

### Оцінка чисельної дисперсії

Через дискретизацію простору скінченними різницями фазова швидкість поширення коротких хвиль на сітці трохи відхиляється від фізичної швидкості світла `c`. Відносне чисельне дисперсійне співвідношення для 1D FDTD описується формулою:

```
sin²(ω Δt / 2) = (c Δt / Δz)² · sin²(k Δz / 2)
```

Щоб мінімізувати паразитна чисельну дисперсію і забезпечити точність моделювання вихрового поля, просторовий крок сітки `Δz` обирають таким чином, щоб на мінімальну довжину хвилі припадало не менше 10–20 комірок сітки: `Δz ≤ λ_min / 10`.

## 3. Програмна реалізація мовами C та C++

Нижче наведено повністю працездатні програмні реалізації 1D FDTD розв'язувача закону індукції Фарадея, які моделюють поширення гаусового імпульсу електричного поля та виникнення індукованого вихрового магнітного поля у просторі.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define GRID_SIZE 200
#define NUM_STEPS 300
#define C_SPEED 3.0e8    /* швидкість світла у вакуумі (м/с) */
#define DZ 0.001         /* просторовий крок 1 мм */

/* Оновлення магнітного поля B за диференційним законом Фарадея */
void update_magnetic_field(double* Bx, const double* Ey, int size, double dt, double dz) {
    for (int k = 0; k < size - 1; ++k) {
        /* Bx[k] відповідає вузлу k + 1/2 */
        Bx[k] += (dt / dz) * (Ey[k + 1] - Ey[k]);
    }
}

/* Оновлення електричного поля E за законом Ампера-Максвелла */
void update_electric_field(double* Ey, const double* Bx, int size, double dt, double dz) {
    double c2 = C_SPEED * C_SPEED;
    for (int k = 1; k < size - 1; ++k) {
        Ey[k] += (c2 * dt / dz) * (Bx[k] - Bx[k - 1]);
    }
}

int main(void) {
    double dt = 0.99 * DZ / C_SPEED; /* крок по часу з умови Куранта */
    
    double* Ey = (double*)calloc(GRID_SIZE, sizeof(double));
    double* Bx = (double*)calloc(GRID_SIZE, sizeof(double));
    
    if (!Ey || !Bx) {
        fprintf(stderr, "Помилка виділення пам'яті!\n");
        return 1;
    }

    printf("Крок часу dt = %.3e с, просторовий крок dz = %.3e м\n", dt, DZ);

    /* Головний часовий цикл симуляції */
    for (int t = 0; t < NUM_STEPS; ++t) {
        /* Джерело гаусового імпульсу в центрі сітки */
        Ey[GRID_SIZE / 2] += exp(-pow((t - 40.0) / 12.0, 2.0));

        /* Крок 1: оновлення B з ротора E (Закон Фарадея) */
        update_magnetic_field(Bx, Ey, GRID_SIZE, dt, DZ);

        /* Крок 2: оновлення E з ротора B (Закон Ампера-Максвелла) */
        update_electric_field(Ey, Bx, GRID_SIZE, dt, DZ);
    }

    printf("Симуляцію успішно завершено. Поле Ey у центрі: %.4f B/м\n", Ey[GRID_SIZE / 2]);

    free(Ey);
    free(Bx);
    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <span>
#include <memory>

class FaradayFdtdSolver {
public:
    FaradayFdtdSolver(std::size_t gridSize, double dz)
        : gridSize_(gridSize), dz_(dz), cSpeed_(3.0e8) {
        dt_ = 0.99 * dz_ / cSpeed_;
        ey_.resize(gridSize_, 0.0);
        bx_.resize(gridSize_, 0.0);
    }

    /* Оновлення магнітного поля B з ротора E (диференціальний закон Фарадея) */
    void updateMagneticField() noexcept {
        double coeff = dt_ / dz_;
        for (std::size_t k = 0; k < gridSize_ - 1; ++k) {
            bx_[k] += coeff * (ey_[k + 1] - ey_[k]);
        }
    }

    /* Оновлення електричного поля E з ротора B (закон Ампера-Максвелла) */
    void updateElectricField() noexcept {
        double coeff = (cSpeed_ * cSpeed_) * dt_ / dz_;
        for (std::size_t k = 1; k < gridSize_ - 1; ++k) {
            ey_[k] += coeff * (bx_[k] - bx_[k - 1]);
        }
    }

    void injectGaussianSource(std::size_t location, double timeStep, double width) {
        if (location < gridSize_) {
            ey_[location] += std::exp(-std::pow((timeStep - 40.0) / width, 2.0));
        }
    }

    void step(double timeStep) {
        injectGaussianSource(gridSize_ / 2, timeStep, 12.0);
        updateMagneticField();
        updateElectricField();
    }

    [[nodiscard]] double getEy(std::size_t index) const { return ey_.at(index); }
    [[nodiscard]] double getBx(std::size_t index) const { return bx_.at(index); }
    [[nodiscard]] double getDt() const noexcept { return dt_; }

private:
    std::size_t gridSize_;
    double dz_;
    double cSpeed_;
    double dt_;
    std::vector<double> ey_;
    std::vector<double> bx_;
};

int main() {
    constexpr std::size_t kGridSize = 200;
    constexpr double kDz = 0.001; // 1 мм

    FaradayFdtdSolver solver(kGridSize, kDz);

    std::cout << "Ініціалізація C++20 FDTD розв'язувача laws Faraday...\n";
    std::cout << "Крок часу dt = " << solver.getDt() << " с\n";

    for (int t = 0; t < 300; ++t) {
        solver.step(static_cast<double>(t));
    }

    std::cout << "Розрахунок завершено. Ey[100] = " << solver.getEy(100) << " В/м\n";
    return 0;
}
```

## 4. Практичні пастки та оптимізація обчислень

При практичній розробці промислових САПР для чисельного моделювання закону Фарадея інженери вирішують чотири основні обчислювальні проблеми:

1. **Граничні умови поглинання (Absorbing Boundary Conditions, ABC)**: На краях розрахункової сітки (`k = 0` та `k = GRID_SIZE - 1`) фіксовані нульові значення викликають повне відбивання хвиль назад у розрахунковий об'єм. Для імітації безмежного вільного простору на межах застосовують поглинаючі граничні умови першого порядку Мур (Mur ABC) або розщеплені поглинаючі шари Гедді (Perfectly Matched Layers, PML), які експоненціально гасять енергію вихрового поля без паразтичних відбитків.
2. **Оптимізація пам'яті та квод-векторизація**: У 3D-моделюванні сітки містять сотні мільйонів комірок. Для прискорення перерахунку роторів за законом Фарадея застосовують векторизацію AVX-512 / NEON та паралелізм OpenMP/CUDA, групуючи обчислення компонент `(Ex, Ey, Ez)` у неперервні блоки пам'яті для мінімізації промахів кнів процесора.
3. **Моделювання дисперсійних діелектриків**: У біологічних тканинах та металах проникність залежить від частоти `ε(ω)`. У цьому випадку диференціальний закон Фарадея об'єднують із додатковими диференційними рівняннями поляризації (метод ADE FDTD) або дробовими похідними у часовій області.
4. **Реалізація методів загального джерела (TFSF)**: Для моделювання падіння зовнішньої електромагнітної хвилі на складний об'єкт розраховувану область ділять на Total Field (зону повного поля) та Scattered Field (зону розсіяного поля) за допомогою спеціальної віртуальної границі TFSF. На цій границі дискретне диференціальне рівняння Фарадея коригується шляхом додавання аналітичного значення падаючого вихрового поля, що запобігає зворотним чисельним відбиванням джерела.
