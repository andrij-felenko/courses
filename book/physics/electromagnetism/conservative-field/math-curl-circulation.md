# 🧮 Математична еквівалентність циркуляції та ротора

У векторному аналізі й математичній фізиці властивість консервативності векторного поля визначається за кількома зовні відмінними критеріями: інтегральним (через циркуляцію по контуру), шляховим (через незалежність роботи від траєкторії), скалярним (через існування потенціалу) та локальним диференціальним (через тотожне дорівнювання нулю ротора). У цьому математичному розборі наведено строге доведення еквівалентності цих чотирьох критеріїв для векторного поля, заданого в однозв'язній області тривимірного евклідового простору, а також розкрито граничні умови, координатній системи, мультипольній розклад, варіаційне формулювання, дифенціальні форми де Рама, енергію поля, розклад Гельмгольца та зв'язок із принципними рівняннями Гамільтона-Якобі.

## Чотири еквівалентні критерії консервативного поля

Нехай `E(r) = (E_x(x,y,z), E_y(x,y,z), E_z(x,y,z))` — неперервно диференційовне векторне поле в однозв'язній області `D ⊂ ℝ³`. Наступні чотири твердження є математично еквівалентними:

1. **Циркуляційний критерій**: Циркуляція поля `E` вздовж будь-якого гладкого замкненого контуру `C ⊂ D` дорівнює нулю:
   `∮ [C] E · dl = 0`.
2. **Шляховий критерій**: Криволінійний інтеграл другого роду `∫ [A->B] E · dl` між будь-якими двома точками `A, B ∈ D` залежить лише від кінцевих точок `A` і `B` і не залежить від форми траєкторії `L ⊂ D`.
3. **Потенціальний критерій**: Існує гладке скалярне поле `φ(x,y,z)` (скалярний потенціал) таке, що у кожній точці області `D` векторне поле дорівнює градієнту скалярної функції з протилежним знаком:
   `E = −∇φ  ⇒  (E_x = −∂φ/∂x,  E_y = −∂φ/∂y,  E_z = −∂φ/∂z)`.
4. **Диференціальний критерій (безвихоровий)**: Ротор векторного поля `E` тотожно дорівнює нулю в усіх точках області `D`:
   `∇ × E = 0  ⇒  rot E = 0`.

Доведемо імплікації за колом `1 ⇒ 2 ⇒ 3 ⇒ 4 ⇒ 1`, що гарантує повну математичну еквівалентність усіх чотирьох формулювань.

## Крок 1: Доведення еквівалентності 1 ⇒ 2 (Циркуляція → Незалежність від шляху)

Нехай умова (1) виконується: для будь-якого замкненого контуру циркуляція дорівнює нулю.

Розглянемо дві довільні точки `A` і `B` в області `D` та два довільні гладкі шляхи `L₁` і `L₂`, що з'єднують точку `A` з точкою `B`.

Складемо з цих двох шляхів один замкнений контур `C`, який складається з руху від `A` до `B` уздовж шляху `L₁` та зворотного руху від `B` до `A` уздовж шляху `L₂` (позначимо його `-L₂`):

```
C = L₁ ∪ (−L₂)
```

Обчислимо циркуляцію поля `E` по цьому замкненому контуру `C`:

```
∮ [C] E · dl
= ∫ [L₁] E · dl + ∫ [−L₂] E · dl       [властивість лінійності інтеграла]
= ∫ [L₁] E · dl − ∫ [L₂] E · dl       [зміна напрямку обходу змінює знак інтеграла]
```

Оскільки за умовою (1) циркуляція по замкненому контуру `C` дорівнює нулю (`∮ [C] E · dl = 0`), отримуємо:

```
∫ [L₁] E · dl − ∫ [L₂] E · dl = 0
∫ [L₁] E · dl = ∫ [L₂] E · dl          [інтеграли вздовж L₁ та L₂ однакові]
```

Отже, криволінійний інтеграл від точки `A` до точки `B` дійсно не залежить від обраного шляху, що й доводить твердження (2).

Аналогічно, якщо припустити виконання твердження (2), то для будь-якого замкненого контуру `C` ми можемо розбити його точками `A` і `B` на дві дуги `L₁` і `L₂`. Оскільки `∫ [L₁] E · dl = ∫ [L₂] E · dl`, то `∮ [C] E · dl = ∫ [L₁] E · dl − ∫ [L₂] E · dl = 0`, що доводить зворотний перехід `2 ⇒ 1`.

## Крок 2: Доведення імплікації 2 ⇒ 3 (Незалежність від шляху → Існування потенціалу)

Нехай інтеграл `∫ [A->B] E · dl` залежить лише від початкової точки `A` та кінцевої точки `B`.

Фіксуємо в області `D` довільну початкову точку `O(x₀, y₀, z₀)` як базову точку відліку потенціалу. Для будь-якої змінної точки `P(x, y, z) ∈ D` визначимо скалярну функцію `φ(x, y, z)` за допомогою інтеграла:

```
φ(x, y, z) = − ∫ [O->P] E · dl
```

Знак мінус вибрано за фізичною угодою електростатики (напруженість поля спрямована в бік спадання потенціалу). Оскільки за умовою (2) інтеграл не залежить від шляху між `O` і `P`, значення `φ(x,y,z)` є однозначно визначеним у кожній точці `P`.

Знайдемо часткову похідну функції `φ` за координатою `x` у точці `P(x, y, z)`. Надамо координаті `x` приросту `Δx`, перемістившись у точку `P'(x + Δx, y, z)`. Шлях від `O` до `P'` виберемо у вигляді траєкторії від `O` до `P`, а потім прямолінійного відрізка від `P` до `P'`:

```
φ(x + Δx, y, z) − φ(x, y, z)
= − ∫ [O->P'] E · dl − (− ∫ [O->P] E · dl)   [визначення скалярної функції]
= − ∫ [P->P'] E · dl                          [адитивність криволінійного інтеграла]
```

На прямолінійному відрізку `P->P'` вектор елементарного переміщення має лише `x`-компоненту: `dl = (dx, 0, 0)`. Тому скалярний добуток `E · dl = E_x dx`. За теоремою про середнє для визначеного інтеграла:

```
− ∫ [x -> x + Δx] E_x(t, y, z) dt = − E_x(x + θ·Δx, y, z) · Δx     [де 0 < θ < 1]
```

Поділимо обидві частини на `Δx` та спрямуємо `Δx → 0`:

```
∂φ/∂x = lim [Δx -> 0] (φ(x + Δx, y, z) − φ(x, y, z)) / Δx
= lim [Δx -> 0] (− E_x(x + θ·Δx, y, z))
= − E_x(x, y, z)                       [неперервність E_x]
```

Аналогічно, варіюючи координати `y` та `z`, отримуємо:

```
∂φ/∂y = − E_y(x, y, z)
∂φ/∂z = − E_z(x, y, z)
```

Об'єднуючи часткові похідні у векторний градієнт, маємо:

```
∇φ = (∂φ/∂x) i + (∂φ/∂y) j + (∂φ/∂z) k = − E_x i − E_y j − E_z k = − E
E = − ∇φ                               [векторне поле є градієнтом скалярного потенціалу]
```

Таким чином, існування потенціалу (3) повністю доведено.

## Крок 3: Доведення імплікації 3 ⇒ 4 (Градієнт потенціалу → Нульовий ротор)

Нехай існує дворазово неперервно диференційовна функція `φ(x,y,z)` така, що `E = −∇φ`.

Обчислимо ротор векторного поля `E` за формулою розгортання детермінанта оператора Набла `∇ × E`:

```
∇ × E = det |   i       j       k   |
            | ∂/∂x    ∂/∂y    ∂/∂z  |
            |  E_x     E_y     E_z  |

= i · (∂E_z/∂y − ∂E_y/∂z) + j · (∂E_x/∂z − ∂E_z/∂x) + k · (∂E_y/∂x − ∂E_x/∂y)
```

Підставимо компоненти поля через часткові похідні потенціалу `E_x = −∂φ/∂x`, `E_y = −∂φ/∂y`, `E_z = −∂φ/∂z`:

```
∂E_z/∂y − ∂E_y/∂z
= ∂/∂y (−∂φ/∂z) − ∂/∂z (−∂φ/∂y)        [підстановка компонент E_z та E_y]
= − ∂²φ/(∂y ∂z) + ∂²φ/(∂z ∂y)          [за теоремою Шварца про рівність мішаних похідних]
= 0                                     [мішані похідні неперервної функції однакові]
```

Аналогічно для `y`- та `z`-компонент ротора:

```
∂E_x/∂z − ∂E_z/∂x = − ∂²φ/(∂z ∂x) + ∂²φ/(∂x ∂z) = 0
∂E_y/∂x − ∂E_x/∂y = − ∂²φ/(∂x ∂y) + ∂²φ/(∂y ∂x) = 0
```

Отже, ротор градієнта будь-якого дворазово гладкого скалярного поля тотожно дорівнює нулю:

```
∇ × (−∇φ) ≡ 0  ⇒  rot E = 0
```

Це доводить імплікацію (4).

## Крок 4: Доведення імплікації 4 ⇒ 1 (Теорема Стокса: Нульовий ротор → Нульова циркуляція)

Нехай умова (4) виконується: `∇ × E = 0` у всій області `D`.

Розглянемо довільний замкнений гладкий контур `C ⊂ D`. Оскільки область `D` за умовою є **однозв'язною** (не має наскрізних отворів чи вилучених ліній), на цей контур можна натягнути орієнтовану гладку поверхню `S ⊂ D`, межею якої є контур `C` (`∂S = C`).

За теоремою Стокса, циркуляція векторного поля `E` по замкненому контуру `C` дорівнює потоку ротора цього поля через поверхню `S`:

```
∮ [C] E · dl = ∬ [S] (∇ × E) · dS
```

Підставимо умову нульового ротора `∇ × E = 0`:

```
∬ [S] (∇ × E) · dS = ∬ [S] 0 · dS = 0
∮ [C] E · dl = 0                       [циркуляція тотожно дорівнює нулю]
```

Це замикає коло імплікацій `1 ⇒ 2 ⇒ 3 ⇒ 4 ⇒ 1` і повністю доводить рівносильність усіх чотирьох умов консервативності поля.

## Критерій у криволінійних системах координат

У практичних фізичних задачах розрахунок ротора та градієнта часто проводять у криволінійних системах координат (сферичній та циліндричній).

### 1. Циліндрична система координат (r, θ, z)

Градієнт скалярного поля:

```
∇φ = (∂φ/∂r) e_r + (1/r) (∂φ/∂θ) e_θ + (∂φ/∂z) e_z
```

Комппоненти ротора векторного поля `E = E_r e_r + E_θ e_θ + E_z e_z`:

```
(∇ × E)_r = (1/r) (∂E_z/∂θ) − ∂E_θ/∂z
(∇ × E)_θ = ∂E_r/∂z − ∂E_z/∂r
(∇ × E)_z = (1/r) [ ∂(r E_θ)/∂r − ∂E_r/∂θ ]
```

Потенціальне поле вимагає дорівнювання нулю всіх трьох компонент: `(∇ × E)_r = 0`, `(∇ × E)_θ = 0`, `(∇ × E)_z = 0`.

### 2. Сферична система координат (r, θ, ϕ)

Градієнт скалярного поля:

```
∇φ = (∂φ/∂r) e_r + (1/r) (∂φ/∂θ) e_θ + (1 / (r sin θ)) (∂φ/∂ϕ) e_ϕ
```

Комппоненти ротора в сферичних координатах:

```
(∇ × E)_r = (1 / (r sin θ)) [ ∂(sin θ E_ϕ)/∂θ − ∂E_θ/∂ϕ ]
(∇ × E)_θ = (1/r) [ (1/sin θ) (∂E_r/∂ϕ) − ∂(r E_ϕ)/∂r ]
(∇ × E)_ϕ = (1/r) [ ∂(r E_θ)/∂r − ∂E_r/∂θ ]
```

Для сферично симетричного поля `E = E_r(r) e_r` маємо `E_θ = 0` та `E_ϕ = 0`. Усі три компоненти ротора тотожно дорівнюють нулю, що математично доводить консервативність будь-якого центрально-симетричного поля.

## Розрахунок роботи в кулонівському полі вздовж спіралі

Покажемо обчислення роботи переміщення точкового заряду `q` в полі центрального заряду `Q` вздовж складної просторової спіралі `L`, заданої у сферичних координатах як `r(t) = r₁ + (r₂ − r₁)·t`, `θ(t) = π/2`, `ϕ(t) = 4π t`, де `t ∈ [0, 1]`.

Потенціал кулонівського поля має вигляд `φ(r) = Q / (4π ε₀ r)`. Напруженість поля дорівнює:

```
E(r) = − ∇φ = (Q / (4π ε₀ r²)) e_r
```

Елемент переміщення вздовж спіралі у сферичних координатах:

```
dl = dr e_r + r dθ e_θ + r sin θ dϕ e_ϕ
```

Обчислимо скалярний добуток `E · dl`:

```
E · dl = [ (Q / (4π ε₀ r²)) e_r ] · [ dr e_r + r dθ e_θ + r sin θ dϕ e_ϕ ]
       = (Q / (4π ε₀ r²)) dr           [оскільки e_r · e_θ = 0 та e_r · e_ϕ = 0]
```

Зверніть увагу: кутова складова руху `dϕ` повністю випадає зі скалярного добутку завдяки ортогональності напруженості поля до кутових напрямків! Інтегруємо від `r₁` до `r₂`:

```
W = q ∫ [L] E · dl = q ∫ [r₁ -> r₂] (Q / (4π ε₀ r²)) dr
  = (q Q / (4π ε₀)) · [ −1/r ] [r₁ -> r₂]
  = (q Q / (4π ε₀)) · (1/r₁ − 1/r₂)
  = q · [ φ(r₁) − φ(r₂) ]
```

Результат залежить виключно від початкового та кінцевого радіусів `r₁` та `r₂` і абсолютно не залежить від кількості витків спіралі `ϕ(t)`.

## Критерій у термінах повного диференціала

В умовах тривимірного аналізу скалярний добуток `E · dl` є підінтегральним виразом криволінійного інтеграла:

```
E · dl = E_x dx + E_y dy + E_z dz
```

Вираз `E_x dx + E_y dy + E_z dz` є **повним диференціалом** деякої функції `-φ(x,y,z)` тоді й лише тоді, коли виконуються умови симетрії часткових похідних (умови Ейлера-Клеро):

```
∂E_x/∂y = ∂E_y/∂x
∂E_y/∂z = ∂E_z/∂y
∂E_z/∂x = ∂E_x/∂z
```

Ці три скалярні рівняння є не що інше, як рівність нулю трьох компонент вектора `∇ × E = 0`. Якщо ці умови виконуються у однозв'язній області, то існує така функція `φ`, що:

```
dφ = − E_x dx − E_y dy − E_z dz
```

І обчислення криволінійного інтеграла зводиться до найпростішої формули Ньютона-Лейбніца для полів:

```
∫ [A->B] E · dl = − ∫ [A->B] dφ = φ(A) − φ(B)
```

## Енергетична густина потенціального поля

Консервативне електричне поле володіє накопиченою потенціальною енергією `W_el`. Виведем зв'язок між скалярним потенціалом `φ` та густиною енергії поля `w`. Повна потенціальна енергія системи розподілених зарядів `ρ(r)` дорівнює:

```
W_el = (1/2) ∭ [V] ρ(r) φ(r) dV
```

Підставимо густину заряду з рівняння Пуассона-Гаусса `ρ = ε₀ (∇ · E) = − ε₀ ∇²φ`:

```
W_el = (1/2) ∭ [V] (− ε₀ ∇²φ) φ dV = − (ε₀ / 2) ∭ [V] φ (∇ · ∇φ) dV
```

Скористаємося векторографічною тотожністю `∇ · (φ ∇φ) = (∇φ)² + φ ∇²φ`:

```
W_el = − (ε₀ / 2) ∭ [V] [ ∇ · (φ ∇φ) − (∇φ)² ] dV
     = (ε₀ / 2) ∭ [V] (∇φ)² dV − (ε₀ / 2) ∬ [S] (φ ∇φ) · dS
```

Застосувавши теорему Остроградського-Гаусса до поверхневого інтеграла по нескінченно віддаленій сфері `S`, де `φ ∼ 1/r` та `∇φ ∼ 1/r²`, бачимо, що поверхневий інтеграл спадає як `1/r` і прямує до нуля при `r → ∞`. Підставивши `E = −∇φ`, отримуємо підсумковий вираз для енергії поля:

```
W_el = ∭ [V] ( (1/2) ε₀ E² ) dV
```

Об'ємна густина енергії потенціального поля `w = (1/2) ε₀ E²` є додатно визначеною величиною у кожній точці простору.

## Мультипольний розклад потенціалу та збереження безвихоровості

Розглянемо довільний локалізований розподіл електричного заряду з густиною `ρ(r')` всередині обмеженого об'єму `V'`. Потенціал у зовнішній точці `r` розкладається у ряд за степенями `1/r` (мультипольний розклад):

```
φ(r) = (1 / 4π ε₀) · ∭ [V'] ρ(r') / |r − r'| dV'
     = φ_mono(r) + φ_dip(r) + φ_quad(r) + ...
```

Де:
- **Монопольний доданок**: `φ_mono(r) = Q_total / (4π ε₀ r)` — потенціал точкового заряду.
- **Дипольний доданок**: `φ_dip(r) = (p · r) / (4π ε₀ r³)`.
- **Квадрупольний доданок**: `φ_quad(r) = (1 / 8π ε₀ r⁵) · ∑ [i,j] Q_ij x_i x_j`, де `Q_ij = ∭ (3 x'_i x'_j − r'² δ_ij) ρ(r') dV'`.

Оскільки кожен член мультипольного розкладу `φ_k(r)` є неперервно диференційовною скалярною функцією в області `r > R_max`, відповідний внесок у векторне поле `E_k = −∇φ_k` задовольняє умову:

```
∇ × E_k = ∇ × (−∇φ_k) ≡ 0
```

Завдяки лінійності оператора ротора, сума будь-якої кількості мультипольних членів зберігає точну безвихоровість `∇ × E = 0`. Суперпозиція довільного числа консервативних полів є завжди консервативним полем.

## Варіаційне формулювання та зв'язок із рівнянням Гамільтона-Якобі

Потенціальність поля має глибинний зв'язок із класичною механікою Гамільтона. Для зарядженої частинки масою `m` і зарядом `q`, яка рухається в статичному потенціальному полі `E = −∇φ`, функція Лагранжа має вигляд:

```
L(r, v) = (1/2) m v² − q φ(r)
```

Умова консервативності поля `∇ × E = 0` гарантує, що повна механічна енергія системи збережена:

```
H = (1/2) m v² + q φ(r) = E_total = const
```

Скорочена дія Якобі `S_0(r)` для руху частинки з фіксованою енергією `E_total` визначається інтегралом:

```
S_0(r) = ∫ [r₀ -> r] p · dr = ∫ [r₀ -> r] √(2m (E_total − q φ(r'))) dr'
```

Оскільки вектор імпульсу `p = ∇S_0`, оборотний рух частинки у потенціальному полі утворює поле траєкторій, для якого циркуляція векторного імпульсу по будь-якій замкненій лінії станів дорівнює нулю: `∮ p · dr = 0`. Це є основою для інваріантів Пуанкаре-Картана в гамільтоновій механіці та квантування Бора-Зоммерфельда.

## Диференціальні форми та когомології де Рама

Сучасна диференціальна геометрія трактує векторне поле `E` як 1-форму диффереціювання `ω = E_x dx + E_y dy + E_z dz`.

Оператор ротора відповідає зовнішньому диффереціюванню `d`:

```
dω = (∂E_y/∂x − ∂E_x/∂y) dx ∧ dy + (∂E_z/∂y − ∂E_y/∂z) dy ∧ dz + (∂E_x/∂z − ∂E_z/∂x) dz ∧ dx
```

Умова безвихоровості `∇ × E = 0` еквівалентна закротості 1-форми `dω = 0`. Лема Пуанкаре стверджує, що в будь-якій стягуваній (однозв'язній) області кожна замкнена форма є точною: `ω = −dφ`, що означає існування скалярного потенціалу `φ`. Якщо область має топологічні «отвори», когомологічна група де Рама `H¹(D, ℝ) ≠ 0` вимірює перешкоду до того, щоб кожне безвихорове поле було потенціальним.

## Застосування циркуляції до виведення граничних умов на межі двох середовищ

Консервативність статичного електричного поля (`∮ E · dl = 0`) є основним математичним інструментом для виведення граничних умов для тангенціальних компонент напруженості та неперервності скалярного потенціалу на межі поділу двох різних діелектричних середовищ `1` і `2`.

Побудуємо вузький прямокутний контур `C` довжиною `h` і висотою `δ`, який перетинає межу поділу середовищ. Довгі сторони `h` розташовані паралельно межі (одна в середовищі `1`, друга в середовищі `2`), а короткі бокові сторони `δ` проходять перпендикулярно межі.

Запишемо циркуляцію напруженості вздовж цього контуру `C`:

```
∮ [C] E · dl = E_{1t} · h − E_{2t} · h + O(δ) = 0
```

Спрямуємо висоту контуру до нуля (`δ → 0`). Внесок бокових сторін зникає, і ми отримуємо:

```
(E_{1t} − E_{2t}) · h = 0
E_{1t} = E_{2t}                        [тангенціальні компоненти однакові]
```

З неперервності тангенціальної компоненти напруженості безпосередньо випливає неперервність самого скалярного потенціалу при переході через межу: `φ₁(r_{surface}) = φ₂(r_{surface})`. Якби потенціал мав стрибок `Δφ` на гладкій поверхні, його градієнт напруженості містив би дельта-подібну безкінечність, що викликало б нескінченно великі струми перерозподілу.

Отже, з нульової циркуляції прямо випливає **неперервність тангенціальної компоненти напруженості електричного поля** та **неперервність скалярного потенціалу** на будь-якій межі поділу середовищ. На відміну від нормальної компоненти `D_n`, яка має стрибок при наявності поверхневого заряду, тангенціальна компонента `E_t` залишається неперервною завжди, поки поле є статичним і потенціальним.

## Теорема Гельмгольца: Розклад векторного поля

Узагальненням теорії потенціальних полів є **теорема Гельмгольца** (теорема про розклад векторного поля). Вона стверджує, що будь-яке достатньо гладке векторне поле `F(r)`, яке швидко спадає на нескінченності, можна однозначно подати у вигляді суми двох компонент: потенціальної (безвихорової) та соленоїдальної (безджерельної):

```
F(r) = F_pot(r) + F_sol(r)
F(r) = − ∇φ(r) + ∇ × A(r)
```

Де:
- `φ(r)` — скалярний потенціал, який описує джерела поля (`∇ · F_pot = ρ`, `∇ × F_pot = 0`).
- `A(r)` — векторний потенціал, який описує вихори поля (`∇ · F_sol = 0`, `∇ × F_sol = J`).

Скалярний потенціал `φ` та векторний потенціал `A` обчислюються через об'ємні інтеграли від дивергенції та ротора вихідного поля `F`:

```
φ(r) = (1 / 4π) ∭ [V] (∇' · F(r')) / |r − r'| dV'
A(r) = (1 / 4π) ∭ [V] (∇' × F(r')) / |r − r'| dV'
```

Теорема Гельмгольца показує, що потенціальне поле є лише однією з двох фундаментальних ортогональних складових загального електромагнітного поля.

## Топологічна пастка: Роль однозв'язності простору

При доведенні імплікації `4 ⇒ 1` критично важливою була передумова про **однозв'язність** області `D`. Якщо область `D` містить «отвори» або вилучені лінії (є багатозв'язною), локальна умова `∇ × E = 0` **не гарантує** нульової циркуляції по контурах, які охоплюють ці отвори!

Класичним математичним прикладом є двовимірне векторне поле вихору:

```
V(x, y) = ( −y / (x² + y²),  x / (x² + y²),  0 )
```

Обчислимо ротор цього поля в будь-якій точці `(x, y) ≠ (0, 0)`:

```
∂V_y/∂x = ∂/∂x (x / (x² + y²)) = (1·(x² + y²) − x·2x) / (x² + y²)² = (y² − x²) / (x² + y²)²
∂V_x/∂y = ∂/∂y (−y / (x² + y²)) = (−1·(x² + y²) − (−y)·2y) / (x² + y²)² = (y² − x²) / (x² + y²)²

rot_z V = ∂V_y/∂x − ∂V_x/∂y = (y² − x²) / (x² + y²)² − (y² − x²) / (x² + y²)² = 0
```

Отже, в усіх точках поза віссю `z` (тобто при `x² + y² > 0`) ротор дорівнює нулю: `∇ × V = 0`.

Однак обчислимо циркуляцію цього поля по коловому контуру `C` радіуса `R` з центром у початку координат (`x = R cos θ`, `y = R sin θ`, `dl = (−R sin θ dθ, R cos θ dθ)`):

```
∮ [C] V · dl = ∫ [0 -> 2π] [ (−R sin θ)/(R²) · (−R sin θ) + (R cos θ)/(R²) · (R cos θ) ] dθ
= ∫ [0 -> 2π] [ (R² sin² θ + R² cos² θ) / R² ] dθ
= ∫ [0 -> 2π] 1 dθ = 2π ≠ 0
```

Циркуляція по контуру, що охоплює початок координат, дорівнює `2π`, незважаючи на те, що у кожній точці самого контуру `rot V = 0`!

**Математична причина**: область визначення поля `D = ℝ³ \ {вісь z}` є **багатозв'язною**. Контур `C` неможливо безперервно стягнути в точку, не перенувши вісь `z` (де поле має особливість і де ротор не визначений). Натягнути гладку поверхню `S ⊂ D` на контур `C` неможливо, тому теорема Стокса до цього контуру в області `D` незастосовна.

У фізиці цей приклад описує магнітне поле провідника зі струмом (`B = (μ₀ I / 2π r) e_θ`), де циркуляція по контуру навколо струму дорівнює `μ₀ I ≠ 0`, а ротор дорівнює нулю скрізь поза самим провідником. Це чітко розмежовує **локальну безвихоровість** (`rot E = 0`) та **глобальну консервативність** (`∮ E · dl = 0`).
