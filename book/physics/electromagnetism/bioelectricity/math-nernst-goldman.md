# 🧮 Виведення рівнянь Нернста та Ґольдмана-Годжкіна-Катца

Ця вставка містить суворе фізико-хімічне виведення двох фундаментальних рівнянь біоелектрики — рівняння рівноважного потенціалу Нернста та рівняння стаціонарного потенціалу мембрани Ґольдмана-Годжкіна-Катца (GHK). Без цих математичних співвідношень неможливо кількісно виміряти та розрахувати електричні напруги клітинних мембран.

## 1. Термодинамічні основи електрохімічного потенціалу

Жива клітинна мембрана розділяє два водні розчини електролітів. Усередині клітини (у цитоплазмі) та зовні (у міжклітинній рідині) містяться іони натрію `Na⁺`, калію `K⁺`, хлору `Cl⁻` та аніони білків. Оскільки іони мають масу, теплову енергію та електричний заряд, на них одночасно діють дві фундаментальні сили:
1. **Хаотичний тепловий рух (дифузія)**, що прагне вирівняти концентрації іона по обидва боки мембрани від більшої концентрації до меншої.
2. **Електростатичне поле**, що жене заряджені частинки за напрямком або проти напрямку силових ліній поля залежно від знаку заряду іона.

Для кількісного опису обох сил у фізичній хімії використовують концепцію **польного електрохімічного потенціалу** `μ̃_i` (Дж/моль), який виражає зміну вільної енергії Ґіббса системи при додаванні одного моля іона сорту `i`:

```
μ̃_i = μ_i⁰ + R·T·ln(a_i) + z_i·F·Φ
```

де `μ_i⁰` — стандартний хімічний потенціал речовини при заданій температурі та тиску, `R` — універсальна газова стала (`8.314 Дж/(моль·К)`), `T` — абсолютна температура в кельвінах (К), `a_i` — термодинамічна активність іона (у розведених біологічних розчинах активність з високою точністю дорівнює молярній концентрації `C_i`), `F` — стала Фарадея (`96485 Кулон/моль`, заряд одного моля однозарядних катіонів), `z_i` — валентність іона зі своїм знаком (`+1` для `Na⁺` та `K⁺`; `+2` для `Ca²⁺`; `-1` для `Cl⁻`), `Φ` — локальний електричний потенціал середовища в точці перебування іона (В).

Перші два доданки `μ_i⁰ + R·T·ln(C_i)` описують хімічну складову (концентраційний градієнт), а третій доданок `z_i·F·Φ` описує електричну потенціальну енергію заряду в полі.

### Співвідношення Ейнштейна між дифузією та рухливістю

Для виведення кінетики іонного переносу пов'яжемо коефіцієнт дифузії іона `D_i` (м²/с) із його електрофоретичною рухливістю `μ_i` (м²/(В·с)).
На іон під дією електричного поля `E = -dΦ/dx` діє сила `F_elec = z_i · e · E`. У в'язкому рідкому середовищі встановиться стала швидкість дрейфу `v_drift = μ_i · E`.
З іншого боку, вільна енергія дифузійного руху дає впорядковувальну силу `F_diff = -(k_B · T / C_i) · (dC_i / dx)`. Зрівнюючи дрейфовий потік `J_drift = C_i · v_drift` та дифузійний потік Фіка `J_diff = -D_i · (dC_i / dx)` у термодинамічній рівновазі, отримуємо **співвідношення Ейнштейна**:

```
D_i = μ_i · (k_B · T / e) = μ_i · (R · T / F)
```

Це співвідношення показує, що тепловий коефіцієнт дифузії та дрейфова рухливість в полі пов'язані через фундаментальний термічний потенціал `φ_t = R·T / F ≈ 26.7 мВ`.

## 2. Рівняння Нернста: термодинамічна рівновага одного іона

Розглянемо спрощену модель клітини, мембрана якої є повністю проникною лише для одного сорту іона `i` (наприклад, для калію `K⁺`) і непроникною для всіх інших іонів та води.

Нехай концентрації іона всередині та зовні клітини дорівнюють `C_in` та `C_out` відповідно, а електричні потенціали цитоплазми та міжклітинного середовища становлять `Φ_in` та `Φ_out`.

У стані термодинамічної рівноваги результуючий потік іона крізь мембрану зупиняється. Це означає, що електрохімічний потенціал іона всередині клітини мусить точно дорівнювати його електрохімічному потенціалу зовні:

```
μ̃_i,in = μ̃_i,out
```

Запишемо це рівняння у розгорнутому вигляді:

```
μ_i⁰ + R·T·ln(C_in) + z_i·F·Φ_in = μ_i⁰ + R·T·ln(C_out) + z_i·F·Φ_out
```

Оскільки стандартний хімічний потенціал `μ_i⁰` однаковий по обидва боки (одне й те саме розчинне середовище — вода), скоротимо його з обох частин рівності:

```
R·T·ln(C_in) + z_i·F·Φ_in = R·T·ln(C_out) + z_i·F·Φ_out
```

Перенесемо електричні члени в ліву частину, а концентраційні логарифми — у праву:

```
z_i·F·(Φ_in - Φ_out) = R·T·ln(C_out) - R·T·ln(C_in)   [групування електричних та хімічних доданків]
z_i·F·V_m = R·T·ln(C_out / C_in)                     [введення напруги V_m = Φ_in - Φ_out та різниця логарифмів]
V_m = (R·T / (z_i·F)) · ln(C_out / C_in)              [ділення обох частин на (z_i·F)]
```

Різницю електричних потенціалів `V_m = Φ_in - Φ_out` називають **трансмембранним потенціалом** (напругою мембрани). Рівноважне значення цієї напруги для даного іона називають **потенціалом Нернста** `E_i`:

```
E_i = (R·T / (z_i·F)) · ln(C_out / C_in)
```

### Фізичний зміст рівняння Нернста:
Потенціал Нернста — це така електрична напруга на мембрані, яка створює електричне поле, здатне **повністю врівноважити** прагнення іонів дифундувати за градієнтом концентрації. Якщо реальна напруга на мембрані `V_m` дорівнює `E_i`, то сумарний струм даного іона через відкриті канали дорівнює нулю.

### Числовий розрахунок коефіцієнтів для біологічних температур:

Для переходу від натурального логарифма `ln` до десяткового `lg` помножимо вираз на `ln(10) ≈ 2.302585`.
Підставимо значення фізичних констант при нормальній температурі людського тіла `T = 37 °C = 310.15 K`:

```
R = 8.31446 Дж/(моль·К)                                            [універсальна газова стала]
F = 96485.3 Кулон/моль                                             [стала Фарадея]
(R · T / F) · ln(10) = (8.31446 · 310.15 / 96485.3) · 2.302585     [підстановка констант при T = 310.15 K]
                    = 0.026713 В · 2.302585                        [обчислення термічного потенціалу R·T/F у вольтах]
                    = 0.06151 В = 61.51 мВ                         [множник для десяткового логарифма]
```

Отже, робоча формула для одновалентного катіона (`z_i = +1`) набуває прозорого вигляду:

```
E_i = 61.51 мВ · lg(C_out / C_in)
```

### Точні обчислення рівноважних потенціалів для ссавцевого нейрона:

```
Калій (K⁺):    C_out = 5 мМ,   C_in = 140 мМ, z = +1
E_K = 61.51 мВ · lg(5 / 140) = 61.51 мВ · lg(0.03571) = 61.51 мВ · (-1.44715) = -89.01 мВ   [потенціал калію]

Натрій (Na⁺):  C_out = 145 мМ, C_in = 15 мМ,  z = +1
E_Na = 61.51 мВ · lg(145 / 15) = 61.51 мВ · lg(9.6667) = 61.51 мВ · (+0.98527) = +60.60 мВ [потенціал натрію]

Хлор (Cl⁻):    C_out = 110 мМ, C_in = 10 мМ,  z = -1
E_Cl = (61.51 / (-1)) мВ · lg(110 / 10) = -61.51 мВ · lg(11.0) = -61.51 мВ · (+1.04139) = -64.05 мВ [потенціал хлору]

Кальцій (Ca²⁺): C_out = 1.5 мМ, C_in = 0.0001 мМ, z = +2
E_Ca = (61.51 / 2) мВ · lg(1.5 / 0.0001) = 30.755 мВ · lg(15000) = 30.755 мВ · (+4.17609) = +128.43 мВ [потенціал кальцію]
```

## 3. Рівняння Електродифузії Нернста-Планка

У реальній мембрані струм несуть кілька іонів одночасно, і система перебуває не в повній рівновазі, а у **стаціонарному стані**. Щоб вивести напругу такого стану, треба описати рух іона всередині самої мембрани.

Густина потоку іона `J_i` (моль/(м²·с)) уздовж осі `x` (напрямок від внутрішнього боку `x = 0` до зовнішнього `x = d`) складається з дифузійного потоку (законом Фіка) та електричного дрейфового потоку (законом Ома):

```
J_diff  = -D_i · (dC_i / dx)                             [дифузія за градієнтом концентрації]
J_drift = -μ_i · z_i · C_i · (dΦ / dx)                   [дрейф в електричному полі]
```

де `D_i` — коефіцієнт дифузії іона в ліпідному середовищі мембрани (м²/с), `μ_i` — електрофоретична рухливість іона. За співвідношенням Ейнштейна рухливість пов'язана з коефіцієнтом дифузії виразом: `μ_i = D_i · F / (R · T)`.

Підставивши співвідношення Ейнштейна у сумарний потік, отримуємо **рівняння Нернста-Планка**:

```
J_i = -D_i · [ dC_i/dx + (z_i·F / (R·T)) · C_i · (dΦ/dx) ]
```

## 4. Наближення постійного поля Ґольдмана та інтегрування потоку

У 1943 році Девід Ґольдман запропонував спрощення: припустити, що електричне поле всередині тонкої біологічної мембрани товщиною `d ≈ 7 нм` є однорідним (постійним):

```
E = -dΦ/dx = (Φ_in - Φ_out) / d = V_m / d = const
```

Екранування заряду у водних розчинах оцінюється **Дебаївською довжиною екранування** `λ_D`:

```
λ_D = √( (ε₀ · ε_water · k_B · T) / (2 · N_A · e² · I_ionic) )
```

У фізіологічному розчині з іонною силою `I_ionic ≈ 0.15 М` Дебаївська довжина становить `λ_D ≈ 0.8 нм`. Оскільки товщина мембрани `d = 7 нм` значно перевищує `λ_D`, подвійний шар電荷ів зосереджений виключно на поверхнях мембрани, а в товщі ліпідного ядра напруженість поля з високою точністю є постійною.

Введемо безрозмірну напругу мембрани: `u = z_i · F · V_m / (R · T)`. Тоді градієнт потенціалу стає рівним: `dΦ/dx = -V_m / d`.

Рівняння Нернста-Планка набуває вигляду:

```
J_i = -D_i · [ dC_i/dx - (u / d) · C_i ]
```

Це лінійне диференціальне рівняння першого порядку відносно `C_i(x)`. Розв'яжемо його методом інтегрувального множника. Помножимо обидві частини на `exp(-u · x / d)`:

```
J_i · exp(-u · x / d) = -D_i · d/dx [ C_i(x) · exp(-u · x / d) ]
```

Проінтегруємо цей вираз уздовж усієї товщини мембрани від `x = 0` (цитоплазма, `C_i(0) = β_i · C_in`) до `x = d` (зовнішній розчин, `C_i(d) = β_i · C_out`), де `β_i` — коефіцієнт розподілу іона між водою та ліпідом:

```
∫₀ᵈ J_i · exp(-u·x / d) dx = -D_i · [ C_i(d)·exp(-u) - C_i(0) ]
J_i · (d / u) · (1 - exp(-u)) = D_i · β_i · [ C_in - C_out·exp(-u) ]
```

Виразимо густину потоку `J_i`:

```
J_i = (D_i · β_i / d) · u · ( C_in - C_out·exp(-u) ) / ( 1 - exp(-u) )
```

Введемо коефіцієнт **проникності мембрани** для іона `P_i = D_i · β_i / d` (м/с). Помноживши потік `J_i` на заряд моля іонів `z_i · F`, отримуємо **площинну густину трансмембранного струму Ґольдмана (GHK current equation)**:

```
I_i = P_i · z_i² · (F² · V_m / (R · T)) · [ C_in - C_out·exp(-z_i·F·V_m / (R·T)) ] / [ 1 - exp(-z_i·F·V_m / (R·T)) ]
```

### Диференційна хордова провідність (GHK chord conductance)

Оскільки рівняння струму Ґольдмана є нелінійним відносно напруги `V_m`, іонний канал поводиться як нелінійний діодний випрямляч (**випрямлення Ґольдмана**). Диференційна провідність `g_i = dI_i / dV_m` залежить від напрямку струму: при `C_out >> C_in` вхідний струм є більшим за вихідний при тій самій за величиною різниці напруг.

## 5. Виведення напруги Ґольдмана-Годжкіна-Катца (GHK voltage equation)

У стаціонарному стані спокою мембрана клітини є накопичувачем, струм крізь який у сумі дорівнює нулю. Якщо основними носіями є іони натрію `Na⁺`, калію `K⁺` та хлору `Cl⁻`, сумарна густина струму дорівнює:

```
I_total = I_K + I_Na + I_Cl = 0
```

Для одновалентних катіонів `K⁺` та `Na⁺` (`z = +1`) введемо позначення `w = F · V_m / (R · T)`. Для аніона хлору `Cl⁻` (`z = -1`) знак у показникові експоненти та в знаменнику змінюється на протилежний, що еквівалентно перестановці місцями зовнішньої та внутрішньої концентрацій у чисельнику.

Підставимо вирази для струмів усіх трьох іонів у сумарне рівняння:

```
(F²·V_m / (R·T)) / (1 - exp(-w)) · [
  P_K · ( [K⁺]_in - [K⁺]_out·exp(-w) ) +
  P_Na · ( [Na⁺]_in - [Na⁺]_out·exp(-w) ) +
  P_Cl · ( [Cl⁻]_out - [Cl⁻]_in·exp(-w) )
] = 0
```

Оскільки множник перед дужками не дорівнює нулю при реальних напругах, вираз у квадратних дужках мусит тотожно дорівнювати нулю:

```
P_K·[K⁺]_in + P_Na·[Na⁺]_in + P_Cl·[Cl⁻]_out - exp(-w) · ( P_K·[K⁺]_out + P_Na·[Na⁺]_out + P_Cl·[Cl⁻]_in ) = 0
```

Виразимо показникову функцію `exp(-w)`:

```
exp(-w) = ( P_K·[K⁺]_in + P_Na·[Na⁺]_in + P_Cl·[Cl⁻]_out ) / ( P_K·[K⁺]_out + P_Na·[Na⁺]_out + P_Cl·[Cl⁻]_in )
```

Беремо обернену величину `exp(w) = 1 / exp(-w)` і логарифмуємо обидві частини рівняння:

```
exp(w) = ( P_K·[K⁺]_out + P_Na·[Na⁺]_out + P_Cl·[Cl⁻]_in ) / ( P_K·[K⁺]_in + P_Na·[Na⁺]_in + P_Cl·[Cl⁻]_out )
w = ln[ ( P_K·[K⁺]_out + P_Na·[Na⁺]_out + P_Cl·[Cl⁻]_in ) / ( P_K·[K⁺]_in + P_Na·[Na⁺]_in + P_Cl·[Cl⁻]_out ) ]
```

Згадавши, що `w = F · V_m / (R · T)`, отримуємо остаточне **рівняння стаціонарного потенціалу Ґольдмана-Годжкіна-Катца**:

```
V_m = (R·T / F) · ln[ ( P_K·[K⁺]_out + P_Na·[Na⁺]_out + P_Cl·[Cl⁻]_in ) / ( P_K·[K⁺]_in + P_Na·[Na⁺]_in + P_Cl·[Cl⁻]_out ) ]
```

### Фізичний розбір гранічних випадків рівняння GHK:

1. **Граничний випадок Нернста**: Якщо мембрана проникна лише для калію (`P_Na = 0`, `P_Cl = 0`), вираз скорочується до `V_m = (R·T/F) · ln([K⁺]_out / [K⁺]_in) = E_K`. Рівняння GHK природно включає рівняння Нернста як свій окремий випадок.
2. **Пік потенціалу дії**: Під час деполяризації відкриваються натрієві канали, і проникність для натрію зростає у сто разів: `P_Na >> P_K`. У цьому разі натрієві члени повністю домінують у чисельнику й знаменнику: `V_m ≈ (R·T/F) · ln([Na⁺]_out / [Na⁺]_in) = E_Na ≈ +60 мВ`. Напруга мембрани перемикається від калієвого рівноважного потенціалу до натрієвого.
