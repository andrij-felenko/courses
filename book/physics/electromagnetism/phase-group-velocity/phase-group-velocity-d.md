- [Швидкість сигналу](book:physics/electromagnetism/signal-speed) — скінченна швидкість поширення електромагнітного імпульсу та фронту хвилі.
</preknowlist>

Коли прямокутний металевий хвилевід прямокутного перерізу марки WR-90 шириною 22.86 міліметра передає НВЧ-імпульс на частоті 10 гігагерц або коли короткий радіосплав проходить крізь плазму іоносфери Землі, вимірювання швидкості поширення дає два парадоксальні значення. Якщо виміряти швидкість зміщення окремих горбів і западин електричного поля всередині імпульсу, вона виявиться більшою за швидкість світла у вакуумі — приблизно `1.32 · c` (близько 395 000 кілометрів на секунду). Складається враження, що порушується постулат спеціальної теорії відносності про граничну швидкість руху матерії. Проте сам імпульс як цілісний згусток енергії та амплітудна огинаюча хвилі долає ту саму відстань зі швидкістю лише `0.76 · c` (227 000 кілометрів на секунду). Це розходження є результатом існування двох різних фізичних величин — фазової та групової швидкості.

Причиною розбіжності між цими швидкостями є дисперсія — залежність швидкості поширення гармонічної хвилі від її частоти. У бездисперсному вакуумі всі електромагнітні хвилі рухаються з однаковою швидкістю `c`, тому фазова й групова швидкості тотожно збігаються. Проте в будь-якому матеріальному середовищі або обмеженій провідній структурі різні частотні складові хвильового пакета поширюються з різними швидкостями. Внаслідок цього сумарний хвильовий профіль змінює свою форму, а фаза коливань всередині пакета зміщується відносно його амплітудного максимуму.

## Фазова швидкість монохроматичної хвилі та межа її інформативності

Розглянемо ідеальну нескінченну монохроматичну хвилю, що поширюється вздовж осі `x`. Електричне поле такої хвилі описується гармонічною функцією двох змінних — часу `t` та координати `x`:

```
E(x, t) = E_0 · cos(ω·t - k·x + φ_0)
```

де `E_0` — амплітуда коливань, `ω` — колова (кутова) частота, `k = 2π / λ` — хвильове число, що показує кількість радіан фазового набігу на один метр довжини, а `φ_0` — початкова фаза.

У тривимірному просторі плоска хвиля описується хвильовим вектором `k_vec`, напрямок якого збігається з напрямком поширення хвильового фронту, а модуль дорівнює `k = |k_vec| = 2π / λ`. Тоді фаза хвилі в точці з радіус-вектором `r_vec` визначається скалярним добутком:

```
Φ(r_vec, t) = ω·t - k_vec · r_vec + φ_0
```

Вираз `Φ(x, t) = ω·t - k·x + φ_0` називається повній фазою хвилі. Щоб простежити за рухом точки з певною фіксованою фазою (наприклад, самого вершечка хвильового гребеня, де `Φ = 0` або `Φ = 2π`), зафіксуємо умову `Φ(x, t) = const`. Взявши повний диференціал від цього виразу за часом, отримуємо:

```
d(ω·t - k·x + φ_0) = 0
⇒ ω·dt - k·dx = 0
```

Звідси швидкість переміщення точки фіксованої фази — фазова швидкість `v_p` — визначається як відношення колової частоти до хвильового числа:

```
v_p = dx / dt = ω / k
```

Оскільки хвильове число пов'язане з довжиною хвилі `λ` у середовищі та частотою `f = ω / (2π)`, фазову швидкість можна записати у звичній формі:

```
v_p = (2π · f) / (2π / λ) = f · λ
```

Пов'язавши хвильове число з показником заломлення середовища `n(ω)`, де `k = (ω / c) · n(ω)`, маємо фундаментальне співвідношення для фазової швидкості в речовині:

```
v_p = c / n(ω)
```

### Мікроскопічна природа показника заломлення та модель Лоренца

Залежність фазової швидкості від частоти `v_p(ω)` у матеріальних діелектриках пояснюється мікроскопічною моделлю осцилятора Лоренца. Згідно з цією моделлю, електрони в атомах зв'язані з ядрами квазіпружними силами з власною частотою `ω_0`. Під дією змінного електричного поля світлової хвилі `E(t) = E_0 · cos(ω·t)` зв'язані електрони здійснюють вимушені коливання, рівняння яких має вигляд:

```
m_e · (d²x / dt² + γ · dx / dt + ω_0² · x) = e · E_0 · cos(ω·t)
```

де `m_e` — маса електрона, `e` — заряд електрона, а `γ` — коефіцієнт згасання (дисипації).

Зміщені електрони утворюють змінні мікроскопічні дипольні моменти, які випромінюють вторинні електромагнітні хвилі тієї самої частоти `ω`. Внаслідок інтерференції падаючої первинної хвилі із вторинним випромінюванням атомів підсумкова хвиля в середовищі набуває додаткового фазового зсуву. Комплексна діелектрична проникність середовища `ε(ω)` стає частотно-залежною:

```
ε(ω) = 1 + (n_a · e² / (ε_0 · m_e)) / (ω_0² - ω² + j·γ·ω)
```

де `n_a` — об'ємна концентрація атомів. Оскільки показник заломлення є корінним значенням діелектричної проникності `n(ω) = √ε(ω)`, фазова швидкість `v_p(ω) = c / n(ω)` неминуче змінюється з частотою, що й утворює оптичну дисперсію.

Для практичних розрахунків у діапазонах прозорості діелектриків (де дисипаційним згасанням `γ` можна знехтувати) модель Лоренца з кількома власними резонансними частотами перетворюється на емпіричну формулу Сельмейєра:

```
n²(λ) = 1 + ∑_{i=1}^{N} (B_i · λ²) / (λ² - C_i)
```

де `λ` — довжина хвилі у вакуумі, `B_i` — сили осциляторів, а `√C_i` — резонансні довжини хвиль поглинання в ультрафіолетовому та інфрачервоному діапазонах. Саме зсув між УФ-резонансами електронів та ІЧ-резонансами атомних коливань ґратки визначає точку нульової дисперсії (Zero Dispersion Wavelength, ZDW), у якій друга похідна `d²n / dλ² = 0`, а групова швидкість досягає свого локального екстремуму.

### Чому монохроматична хвиля не передає інформацію

Фазова швидкість `v_p` описує швидкість руху геометричного стану (фази) безкінечного періодичного синусоїдального процесу. Проте суворо монохроматична хвиля не здатна передати жодного біта інформації або сформувати сигнал.

Щоб передати інформацію (початок відліку часу, цифровий біт, звуковий сигнал чи світловий спалах), необхідно змінити параметр хвилі — її амплітуду, частоту чи фазу. Проте монохроматична хвиля існує від `t = -∞` до `t = +∞` з незмінною амплітудою `E_0`. Приймач, який реєструє таку хвилю, у будь-який момент часу бачить абсолютно однаковим гармонічне коливання. У ньому немає жодної позначки, фронту чи зміни, за якою можна було б зафіксувати момент передачі повідомлення.

Інформацію передає не сама хвиля, а **модуляція** хвилі — утворення локалізованого в просторі та часі хвильового пакета або імпульсу. А будь-який хвильовий пакет, згідно з теоремою Фур'є, складається зі спектра різних частот.

## Інтерференція та утворення хвильового пакета

Найпростішою фізичною моделлю хвильового пакета є біття — результат додавання (інтерференції) двох монохроматичних хвиль однаковою амплітудою `E_0` з близько розташованими частотами `ω_1 = ω_0 + Δω` та `ω_2 = ω_0 - Δω` та відповідно близькими хвильовими числами `k_1 = k_0 + Δk` та `k_2 = k_0 - Δk`.

Сумарне електричне поле двох хвиль дорівнює:

```
E(x, t) = E_0 · cos((ω_0 + Δω)·t - (k_0 + Δk)·x) + E_0 · cos((ω_0 - Δω)·t - (k_0 - Δk)·x)
```

Застосовуючи тригонометричну формулу перетворення суми косинусів у добуток `cos A + cos B = 2 · cos((A - B)/2) · cos((A + B)/2)`, отримуємо розкладання сумарного поля на дві складові:

```
E(x, t) = 2·E_0 · cos(Δω·t - Δk·x) · cos(ω_0·t - k_0·x)
```

Цей вираз описує високочастотне несуче коливання `cos(ω_0·t - k_0·x)`, амплітуда якого повільно модулюється огинаючою функцією `A(x, t) = 2·E_0 · cos(Δω·t - Δk·x)`.

![Фазова й групова швидкість у біттях двох хвиль](/book/physics/electromagnetism/phase-group-velocity/img/phase-vs-group-waves.svg)
*_Інтерференція двох близьких гармонік: швидкі коливання всередині пакета рухаються з фазовою швидкістю, тоді як амплітудна огинаюча переміщується з груповою швидкістю._*

У цьому інтерференційному малюнку виразно проявляються два незалежні рухи:

1. **Рух несучих гребенів.** Внутрішня синусоїда `cos(ω_0·t - k_0·x)` рухається зі швидкістю `v_p = ω_0 / k_0`. Це швидкість, з якою переміщуються індивідуальні максимуми всередині хвильового згустку.
2. **Рух амплітудної огинаючої (пакета).** Максимуми й вузли огинаючої `cos(Δω·t - Δk·x)` переміщуються зі швидкістю, яка фіксує фазу модуляції `Δω·t - Δk·x = const`:

```
v_g = Δω / Δk
```

При прямуванні інтервалу частот до нуля (`Δω → 0`) відношення приростів прямує до похідної. Це вираження називається формулою Релея для групової швидкості:

```
v_g = dω / dk
```

Групова швидкість `v_g` — це швидкість переміщення огинаючої групи хвиль (хвильового пакета), яка задає швидкість транспортування енергії та інформації у прозорих середовищах із слабкою дисперсією.

### Транспорт енергії та вектор Пойнтінга

Фізичний зміст групової швидкості як швидкості переносу енергії підтверджується усередненим за часом вектором Пойнтінга `S_vec = E_vec × H_vec` та густиною електромагнітної енергії `u = (1/2) · (ε·E² + μ·H²)`.

Для прозорого середовища без дисипації швидкість переносу енергії `v_u` визначається відношенням середнього потоку енергії до середньої об'ємної густини запасеної енергії:

```
v_u = <S> / <u>
```

Строгий теоремо-енергетичний аналіз електродинаміки суцільних середовищ доводить, що для хвильового пакета у прозорому середовищі швидкість переносу енергії тотожно дорівнює груповій швидкості:

```
v_u = v_g = dω / dk
```

Детальний математичний вивід розкладу хвильового числа у ряд Тейлора та аналіз еволюції спектральних компонент наведено у вставці [🧮 Математичний аналіз хвильового пакета та хроматичної дисперсії](book:physics/electromagnetism/phase-group-velocity/math-wave-packet.md).

Історичний шлях від досліджень призм Ньютоном до розв'язання парадоксів надсвітлових швидкостей Релеєм, Зоммерфельдом та Бріллюеном висвітлено у вставці [📜 Історія дослідження дисперсії та парадоксу надсвітлових швидкостей](book:physics/electromagnetism/phase-group-velocity/hist-dispersion.md).

## Дисперсійне співвідношення та типи середовищ

Фундаментальною характеристикою будь-якої хвилеведучої системи або матеріального середовища є дисперсійне співвідношення — математична залежність колової частоти від хвильового числа `ω(k)` або хвильового числа від частоти `k(ω)`.

Геометричний зміст обидвох швидкостей легко побачити безпосередньо з графіка кривої `ω(k)`:

- **Фазова швидкість `v_p = ω / k`** дорівнює тангенсу кута нахилу січної лінії, проведеної з початку координат `(0,0)` до обраної точки `P(k_0, ω_0)` на дисперсійній кривій.
- **Групова швидкість `v_g = dω / dk`** дорівнює тангенсу кута нахилу дотичної лінії, проведеної до дисперсійної кривої у тій самій точці `P(k_0, ω_0)`.

![Дисперсійні співвідношення ω(k) та типи середовищ](/book/physics/electromagnetism/phase-group-velocity/img/dispersion-curves.svg)
*_Дисперсійні криві ω(k): нахил січної від початку координат визначає фазову швидкість v_p, а нахил дотичної в точці відповідає груповій швидкості v_g._*

Залежно від характеру похідних `dω / dk` та `dn / dλ`, матеріали та хвильоводні системи поділяють на три основні типи.

### 1. Бездисперсне середовище

У вакуумі діелектрична та магнітна проникності є універсальними константами. Залежність `ω(k)` є чисто лінійною:

```
ω = c · k
```

Оскільки лінія є прямою, нахил січної та нахил дотичної збігаються в усіх точках:

```
v_p = ω / k = c
v_g = d(c·k) / dk = c
⇒ v_p = v_g = c
```

У бездисперсному середовищі хвильовий пакет будь-якої складної форми рухається без найменших викривлень, а всі фазові гребені залишаються жорстко прив'язаними до амплітудної огинаючої.

### 2. Нормальна дисперсія

Середовище називається середовищем із нормальною дисперсією, якщо зі зростанням частоти `ω` показник заломлення `n(ω)` зростає (`dn / dω > 0`), а зі зростанням довжини хвилі `λ` — зменшується (`dn / dλ < 0`). Це типова поведінка для більшості прозорих діелектриків (скла, води, кварцу) у видимому й ближньому інфрачервоному діапазонах, віддалених від смуг власного поглинання.

Оскільки синій колір має коротшу довжину хвилі, ніж червоний, у склі `n(синій) > n(червоний)`. Виразимо групову швидкість через показник заломлення та довжину хвилі у вакуумі:

```
v_g = c / n_g
```

де `n_g` — груповий показник заломлення (group index):

```
n_g = n - λ · (dn / dλ)
```

Оскільки для нормальної дисперсії `dn / dλ < 0`, доданок `-λ · (dn / dλ)` є додатним. Отже, `n_g > n`. Це дає фундаментальну нерівність нормальної дисперсії:

```
v_g < v_p < c
```

Розглянемо чисельний приклад для плавленого кварцового скла (fused silica), з якого виготовляють оптичні волокна. На довжині хвилі `λ = 800` нанометрів (початок інфрачервоного діапазону):

- Звичайний фазовий показник заломлення скла дорівнює `n = 1.4533`.
- Похідна по довжині хвилі складає `dn / dλ = -0.027` мкм⁻¹.
- Розрахунок групового індексу дає: `n_g = 1.4533 - 0.800 · (-0.027) = 1.4749`.
- Фазова швидкість світла у склі дорівнює: `v_p = c / 1.4533 = 206 280` кілометрів на секунду.
- Групова швидкість світла у склі складає: `v_g = c / 1.4749 = 203 260` кілометрів на секунду.

Різниця між фазовою та груповою швидкістю у склі складає понад 3000 кілометрів на секунду.

У середовищі з нормальною дисперсією огинаюча хвильового імпульсу рухається повільніше за окремі фазові гребені. При цьому спостерігається характерний ефект: фазові синусоїди зароджуються біля заднього хвоста хвильового пакета, рухаються вперед крізь огинаючу зі швидкістю `v_p`, досягають максимуму в центрі пакета і згасають на його передньому фронті.

### 3. Аномальна дисперсія

Аномальною дисперсією називають режим, у якому показник заломлення зменшується зі зростанням частоти (`dn / dω < 0` або `dn / dλ > 0`). Такий ефект виникає у спектральних областях, які лежать всередині або в безпосередній близькості від ліній резонансного поглинання або підсилення атомами речовини.

У цій зоні доданок `-λ · (dn / dλ)` стає від'ємним, що робить груповий показник заломлення меншим за звичайний показник заломлення (`n_g < n`). У результаті виникає співвідношення:

```
v_g > v_p
```

За певних умов значення `n_g` може прямувати до нуля або ставати від'ємним, що призводить до формальних значень `v_g > c` або навіть `v_g < 0`. Фізичні наслідки цього режиму детально розібрано далі.

## Дисперсія хвиль у гідродинаміці та квантовій механіці

Явище відмінності фазової й групової швидкостей є універсальною властивістю хвильових процесів довільної фізичної природи — від хвиль на поверхні води до квантово-механічних хвиль де Бройля.

### Поверхневі хвилі на воді: гравітаційні та капілярні

Для хвиль на поверхні глибокої води дисперсійне співвідношення враховує як силу тяжіння `g`, так і коефіцієнт поверхневого натягу `γ` та густину рідини `ρ`:

```
ω² = g·k + (γ / ρ) · k³
```

Залежно від довжини хвилі переважає один із двох механізмів:

1. **Гравітаційні хвилі на глибокій воді (`λ >> 2` см).** Членом поверхневого натягу можна знехтувати: `ω² = g·k ⇒ ω = √(g·k)`.
   - Фазова швидкість: `v_p = ω / k = √(g / k) = √(g·λ / 2π)`. Довгі хвилі (брижі від шторму) рухаються швидше за короткі.
   - Групова швидкість: `v_g = dω / dk = (1/2) · √(g / k) = (1/2) · v_p`.
   У гравітаційних хвилях на воді групова швидкість дорівнює точно половині фазової. Коли рятувальний катер створює хвильовий пакет, окремі гребені рухаються уперед удвічі швидше за сам пакет, з'являючись ззаду й зникаючи спереду.
2. **Капілярні хвилі (дрібні брижі, `λ << 1` см).** Переважає поверхневий натяг: `ω² = (γ / ρ) · k³ ⇒ ω = √(γ/ρ) · k^(3/2)`.
   - Фазова швидкість: `v_p = ω / k = √(γ·k / ρ)`.
   - Групова швидкість: `v_g = dω / dk = (3/2) · √(γ·k / ρ) = (3/2) · v_p`.
   У дрібних капілярних брижах групова швидкість в півтора раза перевищує фазову: огинаюча обганяє окремі гребені.

### Хвилі де Бройля у квантовій механіці

У квантовій механіці кожна мікрочастинка маси `m` з імпульсом `p` та кінетичною енергією `E` описується хвилею де Бройля з частотою `ω = E / ℏ` та хвильовим числом `k = p / ℏ`.

Для нерелятивістської частинки `E = p² / (2·m) = ℏ²·k² / (2·m)`. Звідси дисперсійне співвідношення квантової хвилі матерії дорівнює:

```
ω(k) = ℏ · k² / (2·m)
```

Знайдемо фазову та групову швидкості хвилі де Бройля:

- **Фазова швидкість:** `v_p = ω / k = ℏ·k / (2·m) = p / (2·m) = v_particle / 2`.
- **Групова швидкість:** `v_g = dω / dk = d(ℏ·k² / (2·m)) / dk = ℏ·k / m = p / m = v_particle`.

Цей результат є тріумфом хвильово-частинкового дуалізму: фазова швидкість квантової хвилі дорівнює лише половині класичної швидкості частинки, але групова швидкість хвильового пакета де Бройля суворо дорівнює класичній механічній швидкості руху самої частинки `v_particle`. Уся матерія переміщується у просторі саме з груповою швидкістю свого квантового пакета.

## Електромагнітні хвилеводи та плазма: v_p > c та співвідношення v_p · v_g = c²

Яскравим прикладом систем, де фазова швидкість суттєво перевищує швидкість світла у вакуумі, є металеві радіохвилеводи та розріджена незамагнічена плазма (наприклад, іоносфера Землі).

### Дисперсія в іоносферній плазмі

При поширенні електромагнітної хвилі в іоносфері вільні електрони плазми здійснюють вимушені коливання під дією електричного поля. Дисперсійне співвідношення для плазми з плазмовою частотою `ω_p = √(n_e · e² / (ε_0 · m_e))` має вигляд:

```
ω² = ω_p² + c² · k²
```

де `n_e` — концентрація вільних електронів, `e` — заряд електрона, `m_e` — маса електрона.

Визначимо фазову швидкість `v_p = ω / k` з цього рівняння:

```
k = (1 / c) · √(ω² - ω_p²)
⇒ v_p = ω / ( (1 / c) · √(ω² - ω_p²) )
⇒ v_p = c / √(1 - ω_p² / ω²)
```

Оскільки для частот `ω > ω_p` вираз під коренем `√(1 - ω_p² / ω²)` завжди менший за одиницю, фазова швидкість у плазмі є строго більшою за швидкість світла у вакуумі:

```
v_p > c
```

Тепер знайдемо групову швидкість `v_g = dω / dk`. Продиференціюємо дисперсійне рівняння `ω² = ω_p² + c² · k²` по `k`:

```
d(ω²) / dk = d(ω_p² + c² · k²) / dk
⇒ 2·ω · (dω / dk) = 2·c² · k
⇒ dω / dk = c² · (k / ω)
⇒ v_g = c² / v_p
```

Звідси випливає знаменита **теорема про добуток швидкостей** у плазмі та повноводних металевих хвилеводах:

```
v_p · v_g = c²
```

Оскільки `v_p > c`, то групова швидкість обов'язково виявляється меншою за швидкість світла:

```
v_g = c · √(1 - ω_p² / ω²) < c
```

### Дисперсія у прямокутному металевому хвилеводі

Розглянемо поширення хвилі типу `TE_{10}` у прямокутному металевому хвилеводі з шириною широкої стінки `a`. Для існування хвилі частота коливань має перевищувати критичну частоту відсічки (cutoff frequency):

```
f_c = c / (2·a)
```

Для хвилеводу марки WR-90 з шириною `a = 22.86` мм критична частота дорівнює `f_c = 3.00 * 10^8 / (2 * 0.02286) = 6.56` гігагерц. Якщо подати сигнал на частоті `f = 10` гігагерц:

```
√(1 - (f_c / f)²) = √(1 - (6.56 / 10.0)²) = √(1 - 0.430) = 0.755
```

Розрахунок дає наступні значення швидкостей:

- Фазова швидкість у хвилеводі: `v_p = c / 0.755 = 1.324 · c = 397 000` км/с.
- Групова швидкість у хвилеводі: `v_g = c · 0.755 = 0.755 · c = 226 500` км/с.
- Добуток швидкостей: `v_p · v_g = (1.324 · c) · (0.755 · c) = c²`.

| Параметр хвилі | Режим у плазмі / хвилеводі (`ω > ω_p`) |
| :--- | :--- |
| **Фазова швидкість (`v_p`)** | `v_p = c / √(1 - ω_p²/ω²) > c` (рух фазового гребеня) |
| **Групова швидкість (`v_g`)** | `v_g = c · √(1 - ω_p²/ω²) < c` (рух згустку енергії) |
| **Добуток швидкостей** | `v_p · v_g = c²` |

### Чому v_p > c не порушує теорію відносності

Парадокс `v_p > c` є виключно уявним. Фазова швидкість вимірює швидкість переміщення математичної точки, в якій фаза коливання дорівнює певному значенню. Проте сама по собі фаза не є ані матеріальним об'єктом, ані носієм енергії, ані сигналом.

Уявимо похиле падіння плоскої електромагнітної хвилі з плоским фронтом на плоску металеву стіну під кутом `θ` до нормалі. Точка перетину фронту хвилі зі стіною рухається вздовж поверхні зі швидкістю `v_spot = c / sin(θ)`. При майже дотичному падінні (`θ → 0`) ця швидкість прямує до нескінченності. Проте жоден електрон у стіні не передає енергію або імпульс своєму сусіду зі швидкістю `v_spot`: кожен атом лише почергово здригається від прибуття хвильового фронту з простору.

Точно так само у хвилеводі надсвітлова фазова швидкість є результатом геометричного перетину двох плоских хвиль, що відбиваються від протилежних стінок. Жоден реальний фотон чи згусток електромагнітного поля не рухається швидше за `c`. Енергетичні процеси (перенесення енергії) відбуваються з груповою швидкістю `v_g`, яка завжди лишається строго нижчою за `c`.

### Практичне застосування у супутниковій навігації: двочастотна компенсація GNSS

Розбіжність між фазовою та груповою швидкістю в іоносферній плазмі прямо впливає на точність роботи глобальних навігаційних супутникових систем (GPS, Galileo, BeiDou).

Супутник посилає на Землю два типи вимірювальних сигналів:
1. **Дальномірний цифровий код (псевдодальність за кодом).** Кодові імпульси передаються модуляцією несучої, тому вони поширюються з груповою швидкістю `v_g < c`. Іоносфера спричиняє затримку кодового сигналу на величину `Δt_g = (40.3 / (c · f²)) · TEC`, де `TEC` — сумарний електронний вміст іоносфери (Total Electron Content).
2. **Фаза несучої частоти (псевдодальність за фазою).** Несуча синусоїда поширюється з фазовою швидкістю `v_p > c`. Іоносфера викликає фазовий випереджальний зсув (прискорення фази) на тотожну за модулем величину: `Δt_p = - (40.3 / (c · f²)) · TEC`.

Оскільки затримка коду та прискорення фази залежать від квадрата частоти `1 / f²`, двочастотні навігаційні приймачі вимірюють затримку на двох частотах (`f_1 = 1575.42` МГц та `f_2 = 1227.60` МГц). Формуючи безіоносферну комбінацію вимірювань (Ionosphere-Free Combination):

```
P_{IF} = (f_1² · P_1 - f_2² · P_2) / (f_1² - f_2²)
```

приймач повністю компенсує дисперсійну затримку іоносфери першого порядку, знижуючи похибку визначення координат з 10–15 метрів до кількох сантиметрів.

## Розпливання хвильового пакета та дисперсія групової швидкості (GVD)

Досі ми припускали, що групова швидкість є константою. Проте у реальних середовищах сама групова швидкість залежить від частоти. Це описується другою похідною хвильового числа по частоті:

```
β_2 = d²k / dω² = d(1 / v_g) / dω
```

Величина `β_2` називається параметром хроматичної дисперсії або дисперсією групової швидкості (Group Velocity Dispersion, GVD). У волоконній оптиці також використовують параметр дисперсії `D`, виражений через довжину хвилі:

```
D = d(1 / v_g) / dλ = - (2π·c / λ²) · β_2 = - (λ / c) · (d²n / dλ²)
```

Параметр `D` вимірюється у пікосекундах на нанометр на кілометр (пс/(нм·км)).

![Розпливання хвильового імпульсу у дисперсійному середовищі](/book/physics/electromagnetism/phase-group-velocity/img/wave-packet-broadening.svg)
*_Розпливання Гаусового імпульсу в середовищі з хроматичною дисперсією: утворення частотного чирпу та розпливання амплітудного пакета._*

Коли короткий світловий імпульс (наприклад, оптичний фемтосекундний або пікосекундний імпульс у волоконно-оптичному кабелі) входить у середовище з `β_2 ≠ 0`, його спектральні складові починають розходитися у просторі:

- Якщо `β_2 > 0` (нормальна дисперсія GVD): високочастотні (сині) складові рухаються повільніше за низькочастотні (червоні). Червоний передній фронт імпульсу обганяє синій задній хвіст.
- Внаслідок цього тривалість імпульсу `τ(z)` зростає з відстанню `z` за законом `τ(z) = τ_0 · √(1 + (z / L_D)²)`, а всередині імпульсу виникає фазова модуляція частоти (чирп; англійською *chirp* — щебетання).

### Оптичні солітони та підсилення ультракоротких імпульсів

У нелінійній оптиці хроматична дисперсія групової швидкості може вступати у взаємодію з нелінійним ефектом самофазової модуляції (Self-Phase Modulation, SPM), який виникає через залежність показника заломлення від інтенсивності світла `n(I) = n_0 + n_2 · I`.

Цей процес описується нелінійним рівнянням Шредінгера (Nonlinear Schrödinger Equation, NLSE):

```
j · (∂A / ∂z) - (β_2 / 2) · (∂²A / ∂T²) + γ · |A|² · A = 0
```

Якщо середовище має аномальну дисперсію (`β_2 < 0`), чирп від нелінійного ефекту спрямований протилежно до чирпу від хроматичної дисперсії. При точній рівності амплітуд виникає фундаментальний оптичний солітон — хвильовий пакет із профілем `A(z, T) = A_0 · sech(T / τ_0)`, який здатний поширюватися на тисячі кілометрів волокна без жодної зміни своєї амплітудної форми.

У надпотужних лазерних системах використовують зворотний принцип — підсилення чирпованих імпульсів (Chirped Pulse Amplification, CPA; Нобелівська премія з фізики 2018 року, Жерар Муру та Донна Стрікленд). Короткий фемтосекундний імпульс навмисно пропускають крізь дисперсійну систему з великим `β_2`, розтягуючи його у часі в тисячі разів. Це знижує пікову потужність і запобігає руйнуванню оптичних кристалів під час підсилення. Після підсилення імпульс стискають назад у фемтосекундний пакет за допомогою дифракційних ґраток з протилежним знаком дисперсії.

Чисельну модель розпливання Гаусового імпульсу методом швидкого перетворення Фур'є та програмну реалізацію на Python та C++ наведено у вставці [⚙️ Чисельне моделювання фазової та групової швидкості](book:physics/electromagnetism/phase-group-velocity/proj-phase-group-sim.md).

> 🔧 **Навіщо це.** У магістральних волоконно-оптичних лініях зв'язку (наприклад, міжконтинентальних підводних кабелях) дисперсія групової швидкості `β_2` є головним ворогом швидкості передачі даних. Якщо передавати імпульси зі швидкістю 40 гігабіт на секунду (тривалість біта 25 пікосекунд), через декілька десятків кілометрів кварцового волокна імпульси розпливаються, накладаються на сусідні часові інтервали й створюють міжсимвольну інтерференцію (Inter-Symbol Interference, ISI). Для боротьби з цим інженери розробляють спеціальні волокна з компенсованою дисперсією (Dispersion Compensating Fibers, DCF), оптичні солітони (стійкі хвильові пакети, в яких дисперсійне розпливання точно компенсується нелінійним самофокусуванням), а також використовують довжину хвилі «нульової дисперсії» (Zero Dispersion Wavelength, ZDW) близько 1.31 мкм у стандартному кварцовому волокні.

## Аномальна дисперсія, надсвітлові й від'ємні групові швидкості та межі швидкості сигналу

У середовищах із вузькими смугами поглинання або індукованого підсилення (наприклад, у газах атомів цезію або рубідію при лазерному накачуванні) виникає екстремально крута аномальна дисперсія. У цьому випадку похідна `dn / dω` стає негативною і дуже великою за модулем.

Розрахунок за формулою Релея `v_g = c / (n + ω·(dn/dω))` дає вирази, де знаменник прямує до нуля або стає від'ємним. Це призводить до двох дивовижних режимів:

1. **Надсвітлова групова швидкість (`v_g > c` або `v_g → ∞`).** Пік огинаючої імпульсу виходить із середовища швидше, ніж він пройшов би ту саму відстань у вакуумі.
2. **Від'ємна групова швидкість (`v_g < 0`).** Пік вихідного імпульсу з'являється на виході з середовища ще **до того**, як максимум вхідного імпульсу увійшов у вхідне вікно середовища.

### Чому це не порушує принцип причинності

Це явище здається часовим парадоксом лише доти, доки імпульс вважають неподільною точковістю. У дійсній фізиці хвильовий імпульс має скінченну тривалість і похилі фронти (передній та задній хвости).

У середовищі з аномальною дисперсією та підсиленням відбувається не фізичне перенесення матерії чи енергії з майбутнього у минуле, а **амплітудна переформатизація (reshaping) імпульсу**:

- Середовище діє як вибірковий часовий підсилювач. Воно експоненційно підсилює самі перші, ледь помітні «молекули» переднього хвоста імпульсу, які увійшли в середовище раніше.
- Одночасно задній хвіст імпульсу сильно поглинається або зрізається деструктивною інтерференцією.
- У результаті максимум підсумкової огинаючої зміщується на самий передній край. Створюється враження, ніби імпульс вискочив уперед, хоча насправді вихідний максимум було «виліплено» з ранньої передньої частини вхідного імпульсу.

### Закон причинності та фронтова швидкість Зоммерфельда

Німецький фізик Арнольд Зоммерфельд довів, що жоден фізичний сигнал не може бути переданий зі швидкістю, вищою за `c`.

Будь-яка спроба передати повідомлення вимагає наявності чіткого початку — ступінчастого фронту (так званого розриву ступені), до моменту `t_0` якого поле дорівнювало суворо нулю `E = 0`. Зоммерфельд та Бріллюен показали, що спектральний розклад такого фронту містить нескінченно високі частоти (`ω → ∞`).

При поширенні такого ступінчастого сигналу крізь середовище поле на виході розкладається на три чіткі компоненти:

1. **Передвісник Зоммерфельда (Sommerfeld precursor).** Високочастотні гармоніки (`ω → ∞`), які прибувають першими строго в момент часу `t = z / c`. Оскільки на нескінченно високих частотах атоми не встигають реагувати, `n(∞) = 1`, і швидкість фронту завжди дорівнює `v_f = c`.
2. **Передвісник Бріллюена (Brillouin precursor).** Низькочастотні гармоніки, які прибувають пізніше й формують плавну осциляцію.
3. **Основне тіло сигналу.** Головна частина імпульсу, яка прибуває зі швидкістю `v_g` або `v_s` (сигнальною швидкістю).

Оскільки жодна атомна система не здатна реагувати миттєво через інерцію маси електронів, на нескінченно високих частотах будь-яка речовина поводиться як вакуум:

```
lim_{ω → ∞} n(ω) = 1
```

Тому швидкість поширення самого першого фронту сигналу — **фронтова швидкість** (front velocity `v_f`) — у будь-якому матеріальному середовищі завжди суворо дорівнює швидкості світла у вакуумі:

```
v_f = lim_{ω → ∞} (c / n(ω)) = c
```

Ніхто не може дізнатися про наявність сигналу до прибуття його переднього фронту. А оскільки цей фронт завжди рухається зі швидкістю `v_f = c`, спеціальна теорія відносності та принцип причинності залишаються непорушними за будь-яких дисперсійних режимів.
