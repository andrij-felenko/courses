# 🧮 Математичний формалізм взаємодія струмових контурів

Ця вставка містить суворий математичний вивід взаємодії між двома провідниками довільної геометрії та формулювання дифференціального закону Ампера у векторній формі. Починаючи від взаємодії двох точкових елементів струму, ми проведемо послідовне інтегрування для знаходження результуючого вектора сили та механічного моменту, що діють між двома скінченними й нескінченно довгими провідниками у тривимірному просторі.

---

### Диференціальна форма закону Ампера для елементів струму

Розглянемо два довільні тонкі провідники у вакуумі, якими течуть постійні струми `I₁` та `I₂`. Виділимо орієнтовані елементи довжини `dI₁` (вздовж першого провідника у точці `r₁`) та `dI₂` (вздовж второго провідника у точці `r₂`). Вектор радіус-вектора від першого елемента до другого позначимо через `r₁₂ = r₂ - r₁`, а його модуль — через `r₁₂ = |r₁₂|`.

Згідно із законом Біо — Савара — Лапласа, елемент струму `I₁ dI₁` створює у точці розташування второго елемента `r₂` елементарну магнітну індукцію `dB₁`:

```
dB₁ = (μ₀ · I₁ / (4·π)) · (dI₁ × r₁₂) / r₁₂³
```

За законом Ампера, на елемент струму `I₂ dI₂`, що перебуває в магнітному полі `dB₁`, діє диференціальна сила `d²F₁₂`:

```
d²F₁₂ = I₂ · dI₂ × dB₁
```

Підставляючи вираз для `dB₁`, отримуємо диференціальну формулу Ампера для взаємодії двох елементів струму:

```
d²F₁₂ = (μ₀ · I₁ · I₂ / (4·π)) · (dI₂ × (dI₁ × r₁₂)) / r₁₂³
```

Застосовуємо відому векторну тотожність подвійного векторного добутку `A × (B × C) = B · (A · C) - C · (A · B)`:

```
dI₂ × (dI₁ × r₁₂)
= dI₁ · (dI₂ · r₁₂) - r₁₂ · (dI₁ · dI₂)      [векторна тотожність «БАЦ мінус ЦАБ»]
```

Отже, диференціальна сила розкладається на дві складові:

```
d²F₁₂ = (μ₀ · I₁ · I₂ / (4·π · r₁₂³)) · [ dI₁ · (dI₂ · r₁₂) - r₁₂ · (dI₁ · dI₂) ]
```

Зверніть увагу: перший доданок спрямований вздовж елемента `dI₁`, а второй — вздовж сполучної лінії `r₁₂`. Через наявність першого доданка диференціальна сила `d²F₁₂` взагалі кажучи **не є центральною** і не задовольняє Третьому закону Ньютона для ізольованих елементів струму (`d²F₁₂ ≠ -d²F₂₁`). Проте незамкнених елементів струму в природі не існує через закон збереження заряду (`div j = 0`). При інтегруванні по замкнених контурах асиметричні доданки перетворюються на нуль, і загальна сила задовольняє Третій закон Ньютона!

### Інтегральна сила між двома замкненими контурами та формула Ноймана

Повна сила `F₁₂`, з якою перший контур `L₁` діє на дедругий контур `L₂`, визначається подвійним криволінійним інтегралом по обох замкнених контурах:

```
F₁₂ = (μ₀ · I₁ · I₂ / (4·π)) · ∮_L₁ ∮_L₂ (dI₂ × (dI₁ × r₁₂)) / r₁₂³
```

Застосуємо векторний розклад до подвійного інтеграла. Розглянемо першу частину інтеграла:

```
∮_L₁ ∮_L₂ dI₁ · (dI₂ · r₁₂ / r₁₂³)
= ∮_L₁ dI₁ · ∮_L₂ (dI₂ · ∇₂(1 / r₁₂))        [заміна підінтегрального виразу через grad(1/r)]
```

Оскільки градієнт `∇₂(1/r₁₂)` є повним диференціалом скалярної функції по координатах второго контура, інтеграл від повного диференціала по замкненому контуру `L₂` тотожно дорівнює нулю:

```
∮_L₂ dI₂ · ∇₂(1 / r₁₂) = 0                   [циркуляція градієнта по замкненому контуру дорівнює 0]
```

В результаті неузгоджений неосьовий доданок повністю зникає, і для замкнених контурів формула сили набуває симетричного вигляду Грассмана:

```
F₁₂ = - (μ₀ · I₁ · I₂ / (4·π)) · ∮_L₁ ∮_L₂ (dI₁ · dI₂) · r₁₂ / r₁₂³
```

Ця інтегральна формула чітко показує:
1. Сила `F₁₂ = -F₂₁` строго задовольняє Третій закон Ньютона.
2. Сила є центральною для замкнених контурів — вона спрямована вздовж лінії, що з'єднує елементи контурів.
3. Сила пропорційна скалярному добутку елементів `dI₁ · dI₂ = dL₁ · dL₂ · cos(θ)`, де `θ` — кут між напрямами струмів.

Взаємна індуктивність `M₁₂` двох замкнених контурів описується відомою формулою Ноймана:

```
M₁₂ = (μ₀ / (4·π)) · ∮_L₁ ∮_L₂ (dI₁ · dI₂) / r₁₂
```

Обчислюючи градієнт від взаємної індуктивності `M₁₂` по зміщенню одного з контурів, ми отримуємо ту саму симетричну силу Грассмана: `F = I₁ · I₂ · ∇ M₁₂`. Це доводить еквівалентність силового та енергетичного підходів у математичній електродинаміці.

### Повний розклад потенціалу й вивід сили для контурів довільної орієнтації у векторному аналізі

У тривимірному математичному моделюванні взаємодії довільних струмових котушок векторний потенціал `A(r)` слугує базовою скалярно-векторною функцією. Магнітна індукція створюється як ротор векторного потенціалу: `B = rot A`.

Для першого контура векторний потенціал `A₁(r₂)` у точці розташування второго контура має вигляд:

```
A₁(r₂) = (μ₀ · I₁ / (4·π)) · ∮_L₁ dI₁ / r₁₂
```

Тоді магнітна енергія взаємодії двох контурів `W_m` виражається через контурний інтеграл від векторного потенціалу:

```
W_m = I₂ · ∮_L₂ A₁(r₂) · dI₂
```

Підставляючи вираз для `A₁(r₂)`, отримуємо формулу Ноймана для енергії взаємодії. Механічна сила, яка діє на другий контур, дорівнює градієнту цієї енергії по просторовому переміщенню `r₂`:

```
F₂ = I₂ · ∮_L₂ dI₂ × rot A₁(r₂)
```

Цей підхід через векторний потенціал є основим у математичній фізиці для розрахунку сили взаємодії між надпровідними соленоїдами у томографах та магнітних пастках.

### Енергетичний формалізм Лагранжа для елементів електродинамічних систем

У загальному випадку аналізу електромеханічних систем зі струмами (наприклад, ротори електричних машин, рухомі якорі реле, струмові ваги Кельвіна) механічна сила може бути отримана через функцію Лагранжа електродинамічної системи.

Нехай узагальнена механічна координата системи дорівнює `x`. Магнітна енергія системи `W_m(x, I₁, I₂)` виражається через власні та взаємні індуктивності:

```
W_m = (1/2) · L₁(x) · I₁² + M₁₂(x) · I₁ · I₂ + (1/2) · L₂(x) · I₂²
```

Узагальнена механічна сила `F_x`, що діє за координатою `x`, визначається за формулою Лагранжа — Максвелла при фіксованих струмах `I₁` та `I₂`:

```
F_x = ∂W_m(x, I) / ∂x = (1/2) · I₁² · (dL₁ / dx) + I₁ · I₂ · (dM₁₂ / dx) + (1/2) · I₂² · (dL₂ / dx)
```

Для жорстких прямолінійних провідників власні індуктивності `L₁` та `L₂` не залежать від координати відстані `x = r`, тому перші два доданки дорівнюють нулю. Лишається лише похідна від взаємної індуктивності:

```
F_r = I₁ · I₂ · (dM₁₂ / dr)
```

Цей енергетичний формалізм є надзвичайно потужним, оскільки дозволяє знаходити сили без безпосереднього інтегрування векторних полів Біо — Савара — достатньо знати аналітичну залежність індуктивності системи від просторових координат.

### Вплив магнітного екранування та суміжних феромагнітних середовищ

Якщо два провідники зі струмами розміщені поблизу товстої феромагнітної плити (наприклад, сталевого каркаса розподільчої шафи) з відносною магнітною проникністю `μ_r >> 1`, сила між ними змінюється через появу ефекту магнітних зображень.

Метод магнітних зображень дозволяє замінити вплив феромагнітної стінки додаванням фіктивного дзеркального провідника зі струмом:

```
I' = I · (μ_r - 1) / (μ_r + 1)
```

розташованого на такій самій відстані за поверхнею розділу середовищ. Сила притягання до фіктивного провідника додається векторно до сили Ампера між основними шинами, збільшуючи загальне навантаження на ізолятори на 10–15%.

### Чисельні методи обчислення сил у складних 3D конфігураціях провідників

Коли геометрична конфігурація струмоводів виходить за межі простих паралельних ліній або витків (наприклад, просторові котушки Токамака, гвинтові індуктори, трифазні шинопроводи зі складними вигинами у трьох площинах), аналітичне інтегрування за формулами Біо — Савара або Грассмана стає неможливим.

У таких випадках застосовують дискретизацію провідників на `N` скінченних елементів прямолінійних відрізків `ΔL_k`. Сумарна сила на `m`-й елемент обчислюється векторним сумуванням:

```
F_m = I_m · ΔL_m × ∑_{k ≠ m} [ (μ₀ · I_k / (4·π)) · (ΔL_k × r_km) / r_km³ ]
```

Цей алгоритм дискретного сумування реалізовано в інженерних розрахункових модулях для швидкого розрахунку сил короткого замикання у тривимірних модельних каркасах розподільчих щитів.

### Вивід внутрішнього магнітного тиску у суцільному циліндричному провіднику

Розглянемо суцільний циліндричний провідник радіусом `R`, яким протікає постійний струм `I`, рівномірно розподілений по його перерізу з густиною `j = I / (π · R²)`.

Всередині провідника на відстані `r < R` від його центральної осі індукція магнітного поля обчислюється за теоремою про циркуляцію:

```
B(r) = μ₀ · j · r / 2 = μ₀ · I · r / (2·π · R²)
```

Елементарний струм, що протікає у циліндричному шарі радіусом `r` та товщиною `dr`, відчуває дію магнітного поля `B(r)`. Це створює стискальне радіальне зусилля, спрямоване до осі провідника. Диференціал радіального тиску `dp`:

```
dp = j · B(r) · dr = (μ₀ · I² · r / (2·π² · R⁴)) · dr
```

Інтегруючи від поверхні провідника (`r = R`, де тиск `p = 0`) до центру (`r = 0`), отримуємо вираз для максимального внутрішнього магнітного тиску `p_max` у центрі струмоведучого провідника:

```
p_max = ∫_{0}^{R} dp = μ₀ · I² / (4·π² · R²) = μ₀ · j² · R² / 4
```

Цей результат показує, що навіть одиночний провідник зі струмом піддається внутрішньому магнітному самостисканню (пінч-ефект у твердих тілах та плазмі). У металевих провідниках при струмах короткого замикання цей внутрішній тиск сягає десятків атмосфер, що викликає пластичні деформації поверхні шини.

### Тензор напружень Максвелла та поверхневе інтегрування

Альтернативним та математично більш універсальним методом обчислення сил у магнітному полі є застосування тензора напружень Максвелла `T_ij`. Компоненти тензора у тривимірному декартовому просторі визначаються виразом:

```
T_ij = (1 / μ₀) · [ B_i · B_j - (1/2) · δ_ij · B² ]
```

де `δ_ij` — символ Кронекера (`δ_ij = 1` при `i = j` та `δ_ij = 0` при `i ≠ j`).

Результуюча механічна сила `F_i`, яка діє на будь-яке тіло у магнітному полі, обчислюється шляхом інтегрування вектора напружень по будь-якій замкненій поверхні `S`, що повністю охоплює це тіло:

```
F_i = ∮_S T_ij · n_j · dS
```

де `n_j` — компоненти зовнішньої нормалі до поверхні `S`.

Розглянемо вибір поверхні у формі нескінченного циліндра, який охоплює один із паралельних провідників. На внутрішній боковій поверхні циліндра (у зазорі між дротами) магнітна індукція дорівнює `B_gap = B₁ - B₂`, тоді як на зовнішній поверхні `B_out = B₁ + B₂`.

Нормальні компоненти тензора напружень на внутрішній та зовнішній поверхнях:

```
T_nn(внутр) = (B₁ - B₂)² / (2·μ₀)
T_nn(зовн)  = (B₁ + B₂)² / (2·μ₀)
```

Віднімаючи нормальні тиски, отримуємо результуючий тиск на провідник:

```
Δp = T_nn(зовн) - T_nn(внутр) = (2 · B₁ · B₂) / μ₀
```

Інтегрування цього різницевого тиску по колу перерізу провідника з урахуванням кутового розподілу вектора `B` точно дає формулу Ампера `f = μ₀ · I₁ · I₂ / (2·π · r)`. Поверхневе інтегрування тензора Максвелла є основним методом чисельного обчислення сил у сучасних пакетах скінченно-елементного аналізу (ANSYS, COMSOL, FEMM).

### Строгий вивід для двох паралельних провідників скінченної довжини

Розглянемо два прямолінійні паралельні провідники завдовжки `L`, розташовані на відстані `r` один від одного вздовж осі `Z` (від `z = -L/2` до `z = +L/2`).

Спершу знайдемо індукцію магнітного поля `B₁(r)`, створену першим провідником струму `I₁` у точці на відстані `r`:

```
B₁(r) = (μ₀ · I₁ / (4·π)) · ∫_{-L/2}^{+L/2} (dz · r) / (r² + z²)³/²
```

Виконаємо підстановку змінної `z = r · tg(α)`, звідки `dz = r · dα / cos²(α)` та `(r² + z²)¹/² = r / cos(α)`:

```
∫ dz / (r² + z²)³/²
= ∫ (r · dα / cos²(α)) / (r³ / cos³(α))      [підстановка z = r·tg(α) та dz = r·dα/cos²(α)]
= (1 / r²) · ∫ cos(α) dα                      [спрощення дробу: скорочення r та cos²(α)]
= (1 / r²) · sin(α)                            [первісна від cos(α) дорівнює sin(α)]
```

Межі інтегрування по куту `α`: від `α₁ = -arctg(L / (2·r))` до `α₂ = +arctg(L / (2·r))`. Оскільки `sin(arctg(x)) = x / √(1 + x²)`, маємо:

```
sin(α₂) - sin(α₁)
= (L / 2) / √(r² + (L/2)²) - (- (L / 2) / √(r² + (L/2)²))  [підстановка верхньої та нижньої меж]
= L / √(r² + (L/2)²)                                      [зведення подібних доданків]
```

Підставляючи це у вираз для індукції, отримуємо точну формулу поля скінченного провідника:

```
B₁(r) = (μ₀ · I₁ / (2·π · r)) · (L / √(4·r² + L²))
```

Тепер знайдемо силу Ампера, з якою це поле діє на другий паралельний провідник довжини `L`, яким тече струм `I₂`:

```
F₁₂ = B₁(r) · I₂ · L
= (μ₀ · I₁ · I₂ · L / (2·π · r)) · (L / √(4·r² + L²))     [підстановка B₁(r) у силу Ампера]
```

Розглянемо граничний перехід для нескінченно довгого провідника (`L >> r`):

```
lim_{L → ∞} [ L / √(4·r² + L²) ]
= lim_{L → ∞} [ 1 / √(4·(r/L)² + 1) ]        [ділення чисельника й знаменника на L]
= 1                                          [граничне значення при (r/L) -> 0]
```

В результаті отримуємо класичну формулу сили на одиницю довжини `f = F / L`:

```
f = F / L = μ₀ · I₁ · I₂ / (2·π · r)           [формула Ампера для паралельних струмів]
```

### Розрахунок взаємодії для пластинчастих прямокутних шин

Для прямокутних шин товщиною `b` та висотою `h`, розташованих на відстані `a` між осями, формула Біо — Савара для нескінченно тонких ніток дає дещо завищені значення сили при малій відстані `a`.

Сила взаємодії між двома прямокутними провідниками обчислюється чотирикратним інтегруванням по площах перерізів `S₁` та `S₂`:

```
f_strip = (μ₀ · I₁ · I₂ / (S₁ · S₂ · 2·π)) · ∬_S₁ ∬_S₂ (1 / √((x₂ - x₁)² + (y₂ - y₁)²)) dx₁ dy₁ dx₂ dy₂
```

Аналітичне розв'язання цього інтеграла призводить до поправкового коефіцієнта формації `k_ij`:

```
f_strip = f_thin · k_ij
```

Значення `k_ij` визначається через геометричні співвідношення `h/a` та `b/a`:

```
k_ij = 1 - (1/π) · [ (2·a/h) · arctg(h/(2·a)) - (a/h)² · ln(1 + (h/(2·a))²) ]
```

Для більшості стандартних шинопроводів значення `k_ij` становить від 0.75 до 0.95. Ця математична поправка закладена в основу стандартів розрахунку електродинамічної стійкості IEC 60865-1.

### Розрахунок взаємодії для зсунутих та нерівних провідників

У практичній інженерії провідники нерідко мають різну довжину `L₁ ≠ L₂` або зсунуті один відносно одного вздовж осі `Z` на відстань `z₀`.

Розглянемо провідник 1 довжиною `L₁` (від `z = 0` до `z = L₁`) та провідник 2 довжиною `L₂` (від `z = z₀` до `z = z₀ + L₂`). Сила взаємодії обчислюється подвійним інтегруванням:

```
F₁₂ = (μ₀ · I₁ · I₂ / (4·π)) · ∫_{0}^{L₁} dz₁ ∫_{z₀}^{z₀+L₂} dz₂ / (r² + (z₂ - z₁)²)³/²
```

Виконуючи послідовне інтегрування по `z₂` та `z₁`, отримуємо точний аналітичний вираз:

```
F₁₂ = (μ₀ · I₁ · I₂ / (4·π)) · [ N(z₀ + L₂ - L₁) - N(z₀ + L₂) - N(z₀ - L₁) + N(z₀) ]
```

де допоміжна функція `N(u)` має вигляд:

```
N(u) = √(u² + r²) / r
```

Цей аналітичний розробок використовується у програмних реєстрах інженерних САПР для розрахунку сили взаємодії між шинами різної довжини у трансформаторних підстанціях та розподільчих шафах.

### Взаємодія двох коаксіальних колових витків зі струмом

Щечним класичним розрахунковим випадком є взаємодія двох колових витків радіусами `R₁` та `R₂`, розташованих паралельно у коаксіальних площинах на відстані `x` один від одного.

Взаємна індуктивність `M₁₂` двох таких витків виражається через повні еліптичні інтеграли першого `K(k)` та другого `E(k)` роду:

```
M₁₂ = μ₀ · √(R₁ · R₂) · [ (2/k - k) · K(k) - (2/k) · E(k) ]
```

де модуль еліптичного інтеграла `k`:

```
k = √[ (4 · R₁ · R₂) / ((R₁ + R₂)² + x²) ]
```

Сила взаємодії між витками обчислюється як похідна від взаємної індуктивності по відстані `x`:

```
F_x = I₁ · I₂ · (∂M₁₂ / ∂x)
```

Диференціюючи вираз з еліптичними інтегралами, отримуємо точну аналітичну формулу сили притягання або відштовхування витків:

```
F_x = (μ₀ · I₁ · I₂ · x / √((R₁ + R₂)² + x²)) · [ -K(k) + ((R₁² + R₂² + x²) / ((R₁ - R₂)² + x²)) · E(k) ]
```

Для витків малого радіусного розриву (`|R₁ - R₂| << R₁`) або малого віддалення (`x << R₁`) еліптичний модуль `k` наближається до одиниці (`k -> 1`). Еліптичний інтеграл другого роду `E(k) -> 1`, а перший інтеграл `K(k)` прямує до логарифмічної особливості `K(k) ≈ ln(4 / √(1 - k²))`. В цьому логарифмічному граничному наближенні взаємна індуктивність та сила притягання близьких коаксіальних витків переходять у класичну логарифмічну формулу взаємодії паралельних прямолінійних провідників довжиною `2·π·R₁`.

### Розрахунок взаємодії непаралельних провідників під кутом

Якщо два провідники не є паралельними, а перетинаються (або минають один одного) під кутом `θ`, сила між ними зменшується, і додатково виникає **обертальний момент сили** `M`, який прагне розвернути провідники паралельно один до одного.

Розглянемо два довгі провідники, що лежать у паралельних площинах на відстані `d` і розвернуті на кут `θ`. Елемент сили `dF` між елементами `dz₁` та `dz₂` інтегрується з урахуванням скалярного добутку напрямків:

```
f(θ) = (μ₀ · I₁ · I₂ / (2·π · d)) · cos(θ)
```

Обертальний момент `M`, що діє на другий провідник відносно осі симетрії:

```
M = (μ₀ · I₁ · I₂ / (2·π)) · ctg(θ) · ln(L / d)
```

У граничному випадку, коли провідники лежать в одній площині і утворюють малий кут `θ -> 0`, котангенс прямує до нескінченності `ctg(θ) ≈ 1 / θ`, а сила на довжині `L` переходить у класичний вираз для паралельних провідників. Таким чином, кутова формула Грассмана описує безперервний фізичний перехід від паралельного притягання/відштовхування до крутильного розвороту скрещених струмів у тривимірному просторі. Отриманий аналітичний формалізм векторного інтегрування Ампера та Біо — Савара є фундаментальною основою математичної теорії електромагнітного поля.
