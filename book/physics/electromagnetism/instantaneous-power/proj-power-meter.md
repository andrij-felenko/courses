# ⚙️ Цифровий лічильник: обчислення миттєвої, активної та реактивної потужності

Вимірювання параметрів електроспоживання в сучасних інтелектуальних лічильниках електроенергії (смарт-лічильниках), цифрових аналізаторах якості мережі та реле захисту спирається на безперервне високошвидкісне оцифрування аналогових сигналів напруги й струму за допомогою аналогово-цифрових перетворювачів (АЦП). Замість аналогового перемножування та фільтрації мікроконтролер проганяє дискретні відліки `v[n]` та `i[n]` крізь алгоритми дискретного інтегрування в часовій області.

У цьому матеріалі докладно розібрано архітектуру цифрового вимірювача миттєвої, активної, реактивної та повної потужності, проаналізовано пастки дискретизації, апаратного узгодження, фазової калібровки, спектрального аналізу, автопереключення діапазонів, алгоритми апаратного захисту, обробку у фіксованій точці та квантування, а також наведено повні робочі реалізації мовами C та C++.

---

### 1. Фізичні принципи дискретизації та апаратний тракт

Перш ніж аналоговий сигнал потрапить у математичний алгоритм, він проходить крізь апаратний тракт узгодження. Сигнал високої напруги мережі (230 В) зменшується за допомогою резистивного дільника або вимірювального трансформатора напруги. Сигнал великого струму (до десятків амперів) перетворюється на безпечну напругу за допомогою струмового трансформатора (CT), шунта або датчика Холла.

Отримані аналогові сигнали подаються на входи АЦП. Для забезпечення належної точності згідно з теоремою Найквіста-Шеннона частота дискретизації `fₛ` повинна як мінімум удвічі перевищувати найвищу гармоніку сигналу. У промислових лічильниках частота дискретизації становить від `3200 Гц` до `10240 Гц` (що відповідає від 64 до 2048 відліків на один період мережі `50 Гц`).

Перед АЦП обов'язково встановлюють аналоговий антиаліасинговий фільтр низьких частот (Anti-Aliasing Filter, AAF), який зрізає частоти, вищі за півчастоти дискретизації (`fₛ / 2`). Без такого фільтра високочастотні завади від імпульсних джерел живлення «накладаються» на основну частоту мережі, створюючи хибні коливання виміряної миттєвої потужності.

### 2. Математика дискретного алгоритму вимірювання

Нехай `fₛ` — частота дискретизації АЦП, а `N` — кількість відліків, що відповідає точно цілій кількості періодів мережі (для 1 періоду 50 Гц при `fₛ = 5000 Гц` маємо `N = 100`).

На кожному кроці дискретного часу `n` АЦП видає два оцифровані й відкалібровані значення: `v[n]` (миттєва напруга у вольтах) та `i[n]` (миттєвий струм в амперах).

Алгоритм обчислення розділено на дві принципово різні часові фази:

#### Фаза 1. Високочастотна обробка на кожному такті АЦП (High-speed interrupt loop)

На кожному такті оцифрування мікроконтролер виконує мінімальну кількість швидких арифметичних операцій:

1. Обчислює миттєву потужність даного відліку:

```
p[n] = v[n] · i[n]
```

2. Накопичує значення у трьох скалярних суматорах (аккумуляторах):

```
sum_p  = sum_p  + p[n]
sum_v2 = sum_v2 + v[n]²
sum_i2 = sum_i2 + i[n]²
```

3. Оновлює відстеження екстремумів миттєвої потужності:

```
якщо p[n] > p_max, то p_max = p[n]
якщо p[n] < p_min, то p_min = p[n]
```

#### Фаза 2. Періодичний підсумковий розрахунок (Low-speed periodic loop)

Після накопичення `N` відліків (завершення вимірювального вікна) виконавець обчислює підсумкові метрики:

```
P = (1 / N) · sum_p                              [Активна потужність, Вт]
Vᵣₘ⛛ = √ ( (1 / N) · sum_v2 )                      [RMS напруга, В]
Iᵣₘ⛛ = √ ( (1 / N) · sum_i2 )                      [RMS струм, А]
S = Vᵣₘ⛛ · Iᵣₘ⛛                                    [Повна потужність, В·А]
Q = √ ( S² − P² )                                 [Реактивна потужність, вар]
PF = P / S                                        [Коефіцієнт потужності]
```

### 3. Тонкощі реалізації, калібрування та крайові випадки

На шляху від теоретичних формул до реального приладу інженер зіштовхується з низкою практичних проблем.

#### 1. Компенсація постійного зміщення (DC Offset Removal)

Аналогові підсилювачі та сам АЦП завжди мають невеликий технологічний дрейф нуля `V_offset` та `I_offset`. Навіть за повної відсутності струму напруга зміщення створює хибний добуток `V_offset · I_offset` та спотворює RMS-значення.

Для усунення DC-зміщення кожен відлік перед накопиченням проганяють крізь цифровий фільтр високих частот (High-Pass Filter, HPF) першого порядку з передавальною функцією:

```
y[n] = x[n] − x[n−1] + α · y[n−1]
```

де `α ≈ 0.995` визначає постійну часу фільтрації (зазвичай близько `0.5–1 Гц`). Фільтр повністю вирізає постійну складову, залишаючи лише чисто змінний сигнал.

#### 2. Компенсація апаратного зсуву фази (Phase Calibration)

Вимірювальні трансформатори струму (CT) за своєю природою вводять невеличкий кутовий зсув фази `Δφ` (зазвичай від `0.5°` до `3.0°`) між первинним та вторинним струмом. Оскільки активна потужність залежить від `cos(φ + Δφ)`, цей невеликий кут створює величезну відносну похибку вимірювання при низьких коефіцієнтах потужності (`cos φ < 0.2`).

Для компенсації цього зсуву в алгоритм вправляють інверсний фазовий зсув напруги через лінійну інтерполяцію між сусідніми відліками:

```
v_cal[n] = v[n] + K_phase · (v[n] − v[n−1])
```

де `K_phase` — коефіцієнт фазового калібрування, який підбирають під час еталонного повіряння приладу.

#### 3. Вимірювання реактивної потужності: метод квадратури проти методу RMS

У кодах нижче реактивна потужність обчислюється через геометричну різницю `Q = √(S² − P²)`. Це універсальний спосіб, що працює для будь-яких лінійних навантажень.

Проте існує й другий спосіб — пряме вимірювання через зсув напруги на `90°` (`N / 4` відліків):

```
Q_quad = (1 / N) · ∑ₙ₌₀ᴺ⁻¹ ( v[n − N/4] · i[n] )
```

Метод квадратурного зсуву дозволяє обчислити знак реактивної потужності (`Q > 0` для індуктивного навантаження та `Q < 0` для ємнісного), тоді як формулі `√(S² − P²)` потрібен окремий аналіз знака.

### 4. Архітектура подвійного буферизування DMA у мікроконтролерах

У реальних вбудованих системах (на базі мікроконтролерів ARM Cortex-M0+/M4 або ESP32) обробка відліків АЦП не повинна блокувати ядро процесора на кожному оцифруванні. Для цього застосовують апаратну контролю за допомогою прямого доступу до пам'яті (Direct Memory Access, DMA) та подвійного буфера (Ping-Pong Buffers).

1. **Буфер Ping (канал АЦП)**: DMA-контролер у фоновому режимі (без участі CPU) заповнює сирими кодами АЦП перший масив `v_ping[N]` та `i_ping[N]`.
2. **Переривання DMA Half-Complete / Full-Complete**: як тільки буфер Ping повністю заповнено, контролер DMA автоматично переключається на заповнення буфера Pong (`v_pong[N]`, `i_pong[N]`) і генерує швидке переривання.
3. **Обробка CPU**: у той час як DMA тихо заповнює буфер Pong, процесор у фоновому потоці з низьким пріоритетом виконує алгоритм обчислення метрик `compute_power_metrics` над готовим буфером Ping.

Ця архітектура гарантує 100% відсутність пропущених відліків і дозволяє мікроконтролеру витрачати менше 5% обчислювальної потужності ядра на розрахунки електроенергії.

### 5. Автоматичне перемикання підсилення (Dynamic Auto-Ranging / PGA)

У реальних мережах діапазон вимірюваних струмів може змінюватися у 10 000 разів: від струму чергового режиму побутової техніки (5 мА) до максимального навантаження електроплити чи зварювального апарата (50 А).

Для збереження високого співвідношення сигнал/шум (SNR) та точності вимірювання на малих струмах у каналі струму використовують аналоговий підсилювач із керованим коефіцієнтом підсилення (Programmable Gain Amplifier, PGA) з коефіцієнтами `×1, ×2, ×8, ×16, ×32`.

Алгоритм автоперемикання діапазону постійно стежить за амплітудою відліків струму:
- Якщо піковий струм `I_peak` у буфері становить менше 10% від повної шкали АЦП, мікроконтролер переключається PGA на вищий ступінь підсилення (`×8`) та коригує коефіцієнт `K_i`.
- Якщо струм зростає й наближається до 90% від шкали АЦП, PGA миттєво повертається на базове підсилення (`×1`), аби запобігти апаратному обмеженню (Clipping) сигналу.

### 6. Апаратний захист за миттєвою потужністю (Instantaneous Trip Protection)

Сучасні смарт-лічильники та цифрові автоматичні вимикачі використовують розраховану на кожному такті миттєву потужність `p[n] = v[n] · i[n]` не лише для обліку енергії, а й для ультрашвидкого захисту мережі від коротких замикань та іскріння (Arc Fault Circuit Interrupter, AFCI).

1. **Захист від надструму й короткого замикання**: якщо миттєвий струм `|i[n]|` перевищує уставку аварійного вимкнення (наприклад, 100 А), компаратор переривання вимикає силовий симистор або реле відсічки за час менше `100 мікросекунд`, не чекаючи завершення розрахунку RMS-значення за весь період.
2. **Виявлення дугового пробою (AFCI)**: при дуговому іскрінні в контактах розетки миттєва потужність `p[n]` набуває хаотичних високочастотних сплесків. Алгоритм аналізує дисперсію відхилень миттєвої потужності `Var(p)` між сусідніми відліками:

```
Var(p) = (1 / N) · ∑ ( p[n] − p_avg )²
```

Якщо `Var(p)` перевищує порогове значення при стабільному RMS-струмі, прилад діагностує небезпечне іскріння контакту та розмикає коло, запобігаючи пожежі.

### 7. Обчислення у фіксованій точці (Fixed-Point Math Q15 / Q31)

У дешевих мікроконтролерах без апаратного модуля плаваючої крапки (Hardware FPU, наприклад ARM Cortex-M0+) використання типів `float` або `double` призводить до підключення програмної емуляції та суттєвого сповільнення роботи.

Тому у промислових лічильниках числа з плаваючою крапкою замінюють на цілочисельну арифметику у форматі з фіксованою точкою `Q15` або `Q31`:
- Відлік АЦП зі знаковим 16-бітним розділенням подається у форматі `Q15` (діапазон `[-1.0, +0.9999]`, де `1.0 = 32768`).
- Множення двох значень `Q15` дає 32-бітний результат `Q30`, який зсувається праворуч на 15 бітів: `p_inst = (int32_t)v * i >> 15`.
- Накопичення суми виконується у 64-бітному цілому суматорі `int64_t sum_p`, що унеможливлює переповнення навіть при накопиченні мільйона відліків.
- Взаємно витягання квадратного кореня `sqrt` виконується через цілочисельний алгоритм вавилонського методу або табличний метод з інтерполяцією.

### 8. Спектральний розклад (FFT) та вимірювання гармонік

У сучасних аналізаторах якості електроенергії (Power Quality Analyzers) окрім обчислення загальної активної та реактивної потужності виконується гармонійний аналіз струму й напруги за допомогою швидкого перетворення Фур'є (Fast Fourier Transform, FFT).

Алгоритм FFT приймає буфер із `N = 64, 128, 256` відліків за 1 або 2 періоди мережі та розкладає сигнали на гармонійні складові аж до 50-ї гармоніки (2500 Гц).

На базі спектрального розкладу аналізатор обчислює:
1. **Сумарний коефіцієнт гармонійних спотворень напруги та струму (THD)**:

```
THD_v = √ ( ∑ₖ₌₂⁵⁰ Vₖ² ) / V₁
THD_i = √ ( ∑ₖ₌₂⁵⁰ Iₖ² ) / I₁
```

2. **Активну потужність окремих гармонік**:

```
Pₖ = Vₖ · Iₖ · cos(φₖ)
```

Це дозволяє інженерам точно визначити джерело вищих гармонік у мережі (наприклад, з'ясувати, який саме імпульсний блок живлення чи частотний інвертор спотворює мережу) та обрати правильну схему фільтрації.

### 9. Калібрування смарт-лічильників на виробничому стенді

Перед випуском з конвеєра кожен смарт-лічильник проходить процедуру двопотокового калібрування на автоматизованому метрологічному стенді з еталонним джерелом напруги й струму класи точності 0.02.

Процедура складається з двох послідовних кроків:

1. **Калібрування підсилення (Gain Calibration at cos φ = 1.0)**:
   - Стенд подає ідеальну синусоїдну напругу `V_ref = 230.0 В` та струм `I_ref = 5.0 А` без фазового зсуву (`φ = 0°`).
   - Мікроконтролер обчислює сирі накопичені значення `sum_v2_raw` та `sum_i2_raw`.
   - Обчислюються калібрувальні коефіцієнти підсилення:

```
K_v = V_ref / √ ( sum_v2_raw / N )
K_i = I_ref / √ ( sum_i2_raw / N )
```

2. **Калібрування фазового кута (Phase Calibration at cos φ = 0.5 L)**:
   - Стенд подає напругу `230.0 В` та струм `5.0 А` з фазовим зсувом `φ = 60°` (індуктивне навантаження, `cos φ = 0.5`).
   - Очікувана активна потужність дорівнює `P_ref = 230 · 5 · 0.5 = 575.0 Вт`.
   - Прилад обчислює сиру активну потужність `P_raw`. Якщо через фазову похибку трансформатора струму `Δφ` обчислене значення відрізняється від `575.0 Вт`, мікроконтролер коригує параметр `K_phase` доти, доки відносна похибка не стане меншою за `0.05%`.

Калібрувальні коефіцієнти `K_v`, `K_i` та `K_phase` записуються у про енергонезалежну пам'ять EEPROM / Flash мікроконтролера та контролюються контрольною сумою CRC16 для відстеження цілісності.

### 10. Збереження накопиченої енергії у Flash/EEPROM та Wear-Leveling

Смарт-лічильники зобов'язані вести неперервний облік спожитої електроенергії у кіловат-годинах (`кВт·год`), яка обчислюється шляхом накопичення активної потужності в часі:

```
E_active = ∑ ( P_avg · Δt )
```

Оскільки енергонезалежна пам'ять Flash має обмежений ресурс запису (близько 100 000 циклів перезапису на сектор), записати значення лічильника на кожній секунді безпосередньо у Flash неможливо — пам'ять вийде з ладу за кілька днів.

Для розв'язання цієї проблеми в архітектурі вбудованого ПЗ застосовують трирівневу схему:
1. **Оперативна пам'ять RAM**: енергія накопичується у 64-бітному лічильнику імпульсів або джоулів кожні 20 мс.
2. **Конденсаторна резервна енергія (Power-Down Detector)**: при раптовому зникненні зовнішньої напруги спеціальний компаратор залізобетонно перериває мікроконтролер. Енергії згладжувального конденсатора живлення вистачає на 10-20 мілісекунд — достатньо для того, щоб CPU встиг зберегти підсумковий стан лічильника у Flash.
3. **Алгоритм вирівнювання зносу (Wear-Leveling)**: поточні дані записуються кільцевим буфером у різні адреси Flash-пам'яті із заголовком структури та контрольною сумою CRC32.

### 11. Робочий код: мови C та C++

Наведено повні реалізації вимірювального модуля двома мовами. Код призначено для обробки готового буфера відліків за один або кілька періодів.

:::tabs
```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>
#include <stddef.h>

/* Структура результатів вимірювання електроенергії */
typedef struct {
    double active_power;      /* P, Активна потужність (Вт) */
    double reactive_power;    /* Q, Реактивна потужність (вар) */
    double apparent_power;    /* S, Повна потужність (В·А) */
    double v_rms;             /* Vrms, Діюча напруга (В) */
    double i_rms;             /* Irms, Діючий струм (А) */
    double power_factor;      /* PF, Коефіцієнт потужності (cos φ) */
    double p_max;             /* Пікова миттєва потужність (Вт) */
    double p_min;             /* Мінімальна миттєва потужність (Вт) */
} power_metrics_t;

/**
 * Обчислення метрик потужності за буферами дискретних відліків.
 *
 * @param vbuf      Масив відліків напруги (В)
 * @param ibuf      Масив відліків струму (А)
 * @param count     Кількість відліків у буфері
 * @param result    Структура для запису обчислених результатів
 * @return true у разі успішного розрахунку, false при помилці аргументів
 */
bool compute_power_metrics(const double *vbuf, const double *ibuf, size_t count, power_metrics_t *result) {
    if (!vbuf || !ibuf || !result || count == 0) {
        return false;
    }

    double sum_p = 0.0;
    double sum_v2 = 0.0;
    double sum_i2 = 0.0;
    double p_max = -1e9;
    double p_min = 1e9;

    /* Поточкове накопичення суматорів у часовій області */
    for (size_t n = 0; n < count; ++n) {
        double v = vbuf[n];
        double i = ibuf[n];
        double p_inst = v * i;

        sum_p += p_inst;
        sum_v2 += v * v;
        sum_i2 += i * i;

        if (p_inst > p_max) p_max = p_inst;
        if (p_inst < p_min) p_min = p_inst;
    }

    double inv_count = 1.0 / (double)count;
    double active_p = sum_p * inv_count;
    double v_rms = sqrt(sum_v2 * inv_count);
    double i_rms = sqrt(sum_i2 * inv_count);
    double apparent_s = v_rms * i_rms;

    /* Обчислення Q із захистом від від'ємного підкореневого виразу через округлення */
    double reactive_q = 0.0;
    double s2_minus_p2 = (apparent_s * apparent_s) - (active_p * active_p);
    if (s2_minus_p2 > 0.0) {
        reactive_q = sqrt(s2_minus_p2);
    }

    /* Захист від ділення на нуль та обмеження діапазону PF [-1.0, 1.0] */
    double pf = 1.0;
    if (apparent_s > 1e-6) {
        pf = active_p / apparent_s;
        if (pf > 1.0) pf = 1.0;
        if (pf < -1.0) pf = -1.0;
    }

    result->active_power   = active_p;
    result->reactive_power = reactive_q;
    result->apparent_power = apparent_s;
    result->v_rms          = v_rms;
    result->i_rms          = i_rms;
    result->power_factor   = pf;
    result->p_max          = p_max;
    result->p_min          = p_min;

    return true;
}
```

```cpp
namespace emeter {

struct PowerMetrics {
    double active_power{0.0};      // P, Активна потужність (Вт)
    double reactive_power{0.0};    // Q, Реактивна потужність (вар)
    double apparent_power{0.0};    // S, Повна потужність (В·А)
    double v_rms{0.0};             // Vrms, Діюча напруга (В)
    double i_rms{0.0};             // Irms, Діючий струм (А)
    double power_factor{1.0};      // PF, Коефіцієнт потужності
    double p_max{0.0};             // Пікова миттєва потужність (Вт)
    double p_min{0.0};             // Мінімальна миттєва потужність (Вт)
};

class PowerMeter {
public:
    // Обчислення метрологічних показників з використанням C++20 std::span
    [[nodiscard]] static std::optional<PowerMetrics> calculate(
        std::span<const double> voltages,
        std::span<const double> currents) noexcept 
    {
        if (voltages.empty() || voltages.size() != currents.size()) {
            return std::nullopt;
        }

        const size_t count = voltages.size();
        double sum_p = 0.0;
        double sum_v2 = 0.0;
        double sum_i2 = 0.0;
        double p_max = -1e9;
        double p_min = 1e9;

        for (size_t n = 0; n < count; ++n) {
            const double v = voltages[n];
            const double i = currents[n];
            const double p_inst = v * i;

            sum_p += p_inst;
            sum_v2 += v * v;
            sum_i2 += i * i;

            p_max = std::max(p_max, p_inst);
            p_min = std::min(p_min, p_inst);
        }

        const double inv_count = 1.0 / static_cast<double>(count);
        PowerMetrics m;
        m.active_power = sum_p * inv_count;
        m.v_rms = std::sqrt(sum_v2 * inv_count);
        m.i_rms = std::sqrt(sum_i2 * inv_count);
        m.apparent_power = m.v_rms * m.i_rms;

        const double diff = (m.apparent_power * m.apparent_power) - (m.active_power * m.active_power);
        m.reactive_power = (diff > 0.0) ? std::sqrt(diff) : 0.0;

        if (m.apparent_power > 1e-6) {
            m.power_factor = std::clamp(m.active_power / m.apparent_power, -1.0, 1.0);
        } else {
            m.power_factor = 1.0;
        }

        m.p_max = p_max;
        m.p_min = p_min;

        return m;
    }
};

} // namespace emeter
```

### 12. Порівняльний аналіз реалізацій C та C++

Обидві наведені реалізації обчислюють математично тотожні енергетичні параметри, проте використовують різні архітектурні підходи відповідних мов програмування.

#### 1. Безпека передачі даних та вказівників

У C-версії функція приймає два незалежні сирі вказівники `const double *vbuf` та `const double *ibuf` і окремий параметр довжини `size_t count`. Якщо розробник випадково передасть буфери різного розміру або переплутає порядок аргументів, програма ризикує вийти за межі масиву (Out-of-bounds read) або спричинити аварійне завершення. Усі перевірки вказівників на `NULL` виконуються явно.

У C++20 використовується сучасна концепція `std::span<const double>`, яка є безпечною неволодіючою обгорткою над неперервною ділянкою пам'яті (масивом або `std::vector`). Об'єкт `span` бере на себе контроль довжини. Перевірка `voltages.size() != currents.size()` заздалегідь відсікає помилки узгодження розмірів буферів. Повертане значення огортається у `std::optional<PowerMetrics>`, що змушує викликаючий код явно перевірити наявність результату.

#### 2. Захист від виключень та оптимізація обчислень

Обидві функції гарантують відсутність виключень під час виконання. В реалізації C++ це явно підтверджено специфікатором `noexcept` та атрибутом `[[nodiscard]]`, який забороняє ігнорувати обчислене значення.

З погляду продуктивності процесора обидва цикли не містять викликів сторонніх функцій усередині тіла `for`. Використання оператора `std::max` / `std::min` у C++ та розгалужень у C дозволяє компіляторам (GCC/Clang) здійснювати автовекторизацію (Auto-vectorization) за допомогою інструкцій SIMD (AVX2, FMA). Завдяки цьому 64-бітний процесор здатен обробляти 4 відліки типу `double` паралельно за один векторний такт.

### 13. Покроковий обчислювальний приклад на базі синтетичного буфера

Проілюструємо роботу алгоритму на конкретному обчислювальному прикладі для короткого буфера з 4 відліків напівперіоду (`N = 4`).

Нехай оцифровані значення напруги й струму становлять:
- `v = [ 325.27,  230.0,    0.0,  -230.0 ]` Вольт
- `i = [   7.07,   14.14,  12.25,    0.0  ]` Ампер

#### Крок 1. Обчислення миттєвих продуктів на кожному такті

1. **Такт `n = 0`**:
   `p[0] = 325.27 · 7.07 = 2299.66 Вт`
   `v²[0] = 325.27² = 105800.57`
   `i²[0] = 7.07² = 49.98`

2. **Такт `n = 1`**:
   `p[1] = 230.0 · 14.14 = 3252.20 Вт`
   `v²[1] = 230.0² = 52900.0`
   `i²[1] = 14.14² = 199.94`

3. **Такт `n = 2`**:
   `p[2] = 0.0 · 12.25 = 0.0 Вт`
   `v²[2] = 0.0`
   `i²[2] = 12.25² = 150.06`

4. **Такт `n = 3`**:
   `p[3] = -230.0 · 0.0 = 0.0 Вт`
   `v²[3] = 52900.0`
   `i²[3] = 0.0`

#### Крок 2. Підсумовування аккумуляторів

```
sum_p  = 2299.66 + 3252.20 + 0.0 + 0.0 = 5551.86
sum_v2 = 105800.57 + 52900.0 + 0.0 + 52900.0 = 211600.57
sum_i2 = 49.98 + 199.94 + 150.06 + 0.0 = 400.0
```

#### Крок 3. Остаточний розрахунок метрик (`N = 4`)

```
Active Power P  = 5551.86 / 4 = 1387.96 Вт
V_rms           = √(211600.57 / 4) = √52900.14 = 230.00 В
I_rms           = √(400.0 / 4) = √100.0 = 10.00 А
Apparent Power S = 230.00 · 10.00 = 2300.00 В·А
Reactive Power Q = √(2300² − 1387.96²) = √(5290000 − 1926433) = √3363567 = 1834.00 вар
Power Factor PF = 1387.96 / 2300.00 = 0.6034
```

Цей числовий розрахунок наочно показує, як алгоритм дискретного підсумовування миттєвих продуктів перетворює масиви розрізнених відліків АЦП на точні підсумкові показники споживання електроенергії. Завдяки високій точності дискретного інтегрування та компенсації системних зсувів сучасні цифрові лічильники забезпечують метрологічний клас точності 0.5S та 0.2S, що є стандартною суворою вимогою для комерційного та промислового обліку потужності в енергосистемах будь-якої складності. Вони дозволяють оперативно виявляти витоки енергії та оптимізувати режим роботи електричних мереж.
