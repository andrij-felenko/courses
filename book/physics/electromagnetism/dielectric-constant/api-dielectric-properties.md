# 📋 Інженерна довідка: параметри та вибір діелектричних матеріалів

Ця інженерна довідка містить зведені фізико-технічні характеристики, електродинамічні параметри та нормативні критерії вибору діелектричних матеріалів. Наведені дані широко застосовуються в силовій електротехніці, високовольтній ізоляції, виробництві керамічних та плівкових конденсаторів, розробці друкованих плат (PCB) для радіоелектроніки, надвисокочастотних (НВЧ) систем та сучасній наноелектроніці.

Усі параметри стандартизовано згідно з міжнародними методиками вимірювання та контролю діелектриків (стандарти ASTM D150, IEC 60250, IPC-TM-650 та IEEE Std 286).

---

### 1. Методологія вимірювання та фізичний зміст параметрів

Під час вибору діелектричного матеріалу для електронних схем інженер оперує чотирма ключовими електродинамічними величинами:

1. **Відносна діелектрична проникність (`εᵣ`):** безрозмірний коефіцієнт, який показує збільшення ємності конденсатора при заповненні його зазору даним матеріалом порівняно з ідеальним вакуумом. У високочастотних колах проникність визначає хвильовий імпеданс ліній передачі та швидкість поширення електромагнітної хвилі.
2. **Тангенс кута діелектричних втрат (`tan δ`):** характеризує частку електромагнітної енергії, яка незворотно перетворюється на тепловий рух молекул та атомних ґраток за один період коливань. Чим менший тангенс втрат, тим якіснішим є діелектрик і тим менше згасає сигнал.
3. **Електрична міцність (`E_bd`, від *breakdown field*):** гранична напруженість електричного поля (вимірювана в кіловольтах на міліметр, кВ/мм), при перевищенні якої всередині діелектрика виникає лавинна або теплова іонізація, що призводить до незворотного електричного пробою матеріалу та утворення провідного каналу.
4. **Температурний коефіцієнт діелектричної проникності (`TCε`):** показує відносну зміну проникності при зміні температури на один градус Цельсія (вимірюється в мільйонних частках на градус, або `ppm/°C`). Додатний `TCε` означає зростання проникності при нагріванні, а від'ємний — її падіння.

### 3. Детальний аналіз категорій діелектричних матеріалів

В електродинаміці та напівпровідниковій мікроелектроніці матеріали класифікують за величиною відносної діелектричної проникності та характером поляризаційного відгуку.

```
                         [Класифікація діелектриків]
                                      |
       +------------------------------+------------------------------+
       |                              |                              |
[Low-k матеріали]             [High-k матеріали]            [Сегнетоелектрики]
εᵣ < 3.0                      εᵣ = 10 ... 40                εᵣ > 1000
Призначення:                  Призначення:                  Призначення:
• Провідники PCB (Rogers)     • Затвори MOSFET (HfO₂)      • Надкомпактні MLCC
• Міжкомпонентна ізоляція    • DRAM-конденсатори           • П'єзоактюатори
• Мінімізація затримок τ_pd   • Зменшення тунелювання       • Енергонезалежна пам'ять
```

#### 1. Низькопроникні матеріали та Low-k полімери (`εᵣ < 3.0`)
Матеріали цієї групи володіють мінімальною діелектричною проникністю та надзвичайно низьким тангенсом втрат. 

Основна мета застосування Low-k матеріалів полягає у мінімізації паразитної міжпровідникової ємності `C = εᵣ · ε₀ · A / d` та забезпеченні максимальної швидкості поширення електромагнітних сигналів `v = c / √εᵣ`. У надшвидких мікросхемах це дає змогу усунути затримку розповсюдження `t_pd = √εᵣ / c` та перехресні завади між сусідніми шинами даних.

Найважливішим представником цієї групи є політетрафторетилен (PTFE, або тефлон) із проникністю `εᵣ = 2.10` та тангенсом втрат `tan δ = 0.0002`. Тефлон володіє винятковою хімічною інертністю, широким діапазоном робочих температур (від −200°C до +260°C) та стабільністю електродинамічних параметрів у діапазоні від постійного струму до 100 ГГц. На його основі виготовляють підкладки для надвисокочастотних друкованих плат (наприклад, Rogers RO3003) та діелектричне наповнення гнучких коаксіальних кабелів.

Для міжкомпонентної ізоляції мідних провідників у сучасних інтегральних мікросхемах викрористовують спеціально розроблені пористі орган-силікатні стекла (OSG, або SiCOH), у яких діелектрична проникність знижена до `εᵣ ≈ 2.2 ... 2.5` за рахунок введення нанопористої структури із повітряними включеннями.

#### 2. Матеріали помірної проникності та керамічні підкладки (`εᵣ = 3.5 ... 10`)
До цієї категорії належать класичні ізоляційні матеріали, що становлять основу сучасної радіоелектронної апаратури та оптоелектроніки.

Аморфний діоксид кремнію (кварцове скло, `SiO₂`) володіє проникністю `εᵣ = 3.80`, високою пробійною міцністю та мізерними діелектричними втратами в оптичному діапазоні. Завдяки цьому кварц є основним матеріалом для виготовлення волоконно-оптичних ліній зв'язку, літографічних фотошаблонів та підзатворного діелектрика мікросхем попередніх поколінь.

Склотекстоліт марки FR-4 є найбільш поширеним матеріалом підкладки друкованих плат у світі. Він являє собою композит із тканого скляного волокна, просоченого епоксидною смолою. FR-4 має відносну проникність `εᵣ = 4.20 ... 4.70` та тангенс втрат `tan δ = 0.015 ... 0.025`. Хоча FR-4 чудово підходить для низькочастотної та помірно високочастотної цифрової техніки (до 1 ГГц), на частотах вище 2–3 ГГц його високі діелектричні втрати викликають швидке згасання сигналів.

Кераміка на основі оксиду алюмінію (Alumina, `Al₂O₃`, `εᵣ = 9.80`) та нітриду алюмінію (AlN, `εᵣ = 8.90`) застосовується в гібридних мікросхемах, високопотужних світлодіодах та силових напівпровідникових модулях. Нітрид алюмінію володіє унікальним поєднанням високої електричної ізоляції та колосальної теплопровідності (до 180 Вт/(м·К)), що порівняно з теплопровідністю металевого алюмінію.

#### 3. High-k діелектрики для наноелектроніки (`εᵣ = 10 ... 40`)
Розвиток нанотехнологій та згортання розмірів польових транзисторів FinFET/GAAFET до масштабу 3 нм – 7 нм поставили фізиків перед проблемою квантового тунелювання. При зменшенні товщини традиційного затвора з `SiO₂` нижче 1.2 нм електрони починають вільно тунелювати крізь потенціальний бар'єр діелектрика, викликаючи неконтрольований струм витоку й перегрів мікросхеми.

Рішенням проблеми стало впровадження **High-k діелектриків** — матеріалів із високою діелектричною проникністю, перш за все діоксиду гафнію (`HfO₂`, `εᵣ ≈ 25`), діоксиду цирконію (`ZrO₂`, `εᵣ ≈ 25`) та оксиду танталу (`Ta₂O₅`, `εᵣ ≈ 26`).

Використання `HfO₂` дає змогу обчислити так звану еквівалентну товщину оксиду (EOT, *Equivalent Oxide Thickness*):

```
EOT = d_high-k · (ε_SiO₂ / ε_high-k)
```

Завдяки тому, що проникність `HfO₂` у 6.4 раза вища за проникність `SiO₂`, фізична товщина підзатворного шару `d_high-k` може бути зроблена у 6.4 раза більшою за збереження тієї самої електричної ємності затвора `C = ε · A / d`. Це дозволило зупинити тунельний струм витоку на п'ять порядків і забезпечило подальший прогрес багатоядерних мікропроцесорів.

#### 4. Сегнетоелектричні матеріали та High-Permittivity кераміки (`εᵣ > 1000`)
Матеріали цієї категорії володіють гігантськими значеннями діелектричної проникності за рахунок наявності спонтанної поляризації або фазових переходів у кристалічній ґратці.

Найважливішим представником є титанат барію (`BaTiO₃`), який належить до кристалічної структури перовськіту. У діапазоні температур нижче точки Кюрі (`T_c = 120°C`) іон титану `Ti⁴⁺` зміщується відносно центру кисневого октаедра, створюючи спонтанний дипольний момент. Відносна проникність чистих та мофікованих керамік `BaTiO₃` становить від `1500` до `10 000`.

На основі титанату барію виготовляють багатошарові керамічні конденсатори (MLCC, *Multi-Layer Ceramic Capacitors*). Сучасні технології дають змогу спікати альтернативні шари кераміки товщиною менше 500 нанометрів та металевих електродів, створюючи конденсатори ємністю до 100 мкФ у крихітному корпусі розміром 1.0 × 0.5 мм (0402).

Проте сегнетоелектричні кераміки мають суттєві інженерні недоліки:
- **DC Bias Effect (залежність від напруги):** при прикладанні постійної напруги зміщення орієнтація сегнетоелектричних доменів заклинюється, що призводить до падіння реальної проникності та ємності конденсатора на 50–80% від номіналу.
- **П'єзоелектричний ефект:** під дією змінної напруги кераміка змінює свої фізичні розміри (мікрофонний ефект), що може спричиняти акустичний писк друкованої плати.

### 4. Комплексний інженерний алгоритм вибору матеріалу для PCB

Під час проектування високочастотних та швидкісних цифрових друкованих плат інженер-розробник дотримується наступного покрокового алгоритму вибору матеріалу підкладки:

```
[Алгоритм вибору матеріалу підкладки PCB]

  1. Визначення максимальної частоти сигналу f_max
                        │
                        ▼
  Чи перевищує частота f_max значення 1.5 ГГц?
       ├───── НІ ───► Вибір стандартного текстоліту FR-4 (εᵣ ≈ 4.3, tan δ ≈ 0.02)
       │
       └───── ТАК ──► Оцінка довжини сигнальної траси L
                        │
                        ▼
  Чи перевищує втрата сигналу допуск в 3 дБ?
       ├───── НІ ───► Вибір покращеного Mid-Loss FR-4 (εᵣ ≈ 4.1, tan δ ≈ 0.010)
       │
       └───── ТАК ──► Вибір High-Frequency ламінату (Rogers / PTFE, tan δ < 0.003)
```

#### Розрахунок параметрів лінії передачі:
1. **Швидкість поширення сигналу `v` та затримка `t_pd`:**
   ```
   v = c / √ε_eff  (м/с)
   ```
   ```
   t_pd = √ε_eff / c ≈ 3.33 · √ε_eff  (нс/м)
   ```
   На платах із FR-4 (`ε_eff ≈ 3.5`) затримка становить `6.23 нс/м`, а на тефлонових платах Rogers RO3003 (`ε_eff ≈ 2.6`) затримка знижується до `5.37 нс/м`.

2. **Розрахунок діелектричного згасання в лінії:**
   Загальне згасання електромагнітного сигналу на довжині `L` (у метрах) на частоті `f` обчислюється як сума втрат у міді та втрат у діелектрику:
   ```
   α_total = α_cond + α_diel
   ```
   ```
   α_diel ≈ 27.3 · (f / c) · √ε_r,eff · tan δ  (дБ/м)
   ```
   При виборі матеріалу підкладки необхідно стежити, щоб сумарні втрати на найвищій робочій частоті не перевищували допустимий бюджет втрат каналу зв'язку (зазвичай не більше −12 дБ до −28 дБ для стандартних специфікацій PCIe та Ethernet).
