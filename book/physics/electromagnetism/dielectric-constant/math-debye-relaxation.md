# 🧮 Математична теорія релаксації Дебая та комплексного відгуку

У змінному електричному полі діелектричний відгук матеріального середовища втрачає миттєвий характер. Через інерцію електронних хмар, скінченну масу іонних кристалічних ґраток та в'язкий опір середовища повертанню молекулярних диполів вектор поляризації `P(t)` відстає за фазою від напруженості поля `E(t)`. Для опису цього запізнення вводиться апарат теорії лінійного відгуку, комплексної діелектричної проникності та фур'є-аналізу.

---

### 1. Функція відгуку та принцип причинності у часовій області

У лінійному неізотропному середовищі вектор поляризації `P(t)` у момент часу `t` визначається всією попередньою історією зміни електричного поля `E(t')` за принципом суперпозиції:

```
P(t) = ε₀ · ∫₀^∞ χ(t') · E(t − t') dt'
```

де `χ(t')` — причинна ядро-функція діелектричного відгуку (диференціальна електрична сприйнятливість у часовій області), а `t'` — час, що минув із моменту прикладання поля.

Принцип причинності вимагає, щоб наслідок не передував причині: середовище не може поляризуватися раніше, ніж на нього подіє електричне поле. Це означає, що імпульсна функція відгуку строго дорівнює нулю для від'ємних аргументів:

```
χ(t') = 0              [при t' < 0]
```

Якщо в момент часу `t = 0` скачкоподібно ввімкнути стале електричне поле `E₀` (ступінчаста дія), орієнтаційна поляризація полярного діелектрика наростає не миттєво, а за експоненціальним релаксаційним законом із характерним часом повертання молекул `τ`:

```
P(t) = P_static · (1 − e⁻ᵗ/ᵀ)        [для t ≥ 0]
```

де `P_static = ε₀ · (ε_s − ε_∞) · E₀` — рівноважна статична поляризація.

Диференціюючи цю вихідну ступенчату реакцію середовища за часом, отримуємо імпульсну функцію відгуку діелектрика `χ(t)`:

```
χ(t) = ( (ε_s − ε_∞) / τ ) · e⁻ᵗ/ᵀ    [при t ≥ 0]
χ(t) = 0                               [при t < 0]
```

де `ε_s` — низькочастотна статична проникність, а `ε_∞` — високочастотна оптична проникність.

### 2. Строгий вивід комплексної проникності Дебая

Подамо змінне гармонічне електричне поле у комплексній формі Ейлера:

```
E(t) = E₀ · eⁱʷᵗ
```

Підставимо це поле у загальний інтеграл причинного відгуку для поляризації `P(t)`:

```
P(t) = ε₀ · ∫₀^∞ ( (ε_s − ε_∞) / τ ) · e⁻ᵗ'/ᵀ · E₀ · eⁱʷ⁽ᵗ⁻ᵗ'⁾ dt'
```

Винесемо множники, які не залежать від змінної інтегрування `t'`, за знак інтеграла:

```
P(t) = ε₀ · E₀ · eⁱʷᵗ · ( (ε_s − ε_∞) / τ ) · ∫₀^∞ e⁻ᵗ' · (1/τ + iω) dt'
```

Оскільки `E₀ · eⁱʷᵗ = E(t)`, перепишемо вираз у вигляді:

```
P(t) = ε₀ · E(t) · ( (ε_s − ε_∞) / τ ) · I(ω)
```

де `I(ω)` — визначений інтеграл по часовій затримці `t'`:

```
I(ω) = ∫₀^∞ e⁻ᵗ' · (1/τ + iω) dt'
```

Обчислимо цей інтеграл за первісною експоненціальної функції:

```
I(ω) = [ − e⁻ᵗ' · (1/τ + iω) / (1/τ + iω) ]₀^∞
= 0 − [ − 1 / (1/τ + iω) ]                    [оскільки e⁻°° = 0 при Re(1/τ + iω) > 0]
= 1 / (1/τ + iω)
```

Помножимо чисельник і знаменник отриманого дробу на `τ`:

```
I(ω) = τ / (1 + iωτ)
```

Підставимо обчислений інтеграл `I(ω)` назад у вираз для поляризації `P(t)`:

```
P(t) = ε₀ · E(t) · ( (ε_s − ε_∞) / τ ) · ( τ / (1 + iωτ) )
= ε₀ · E(t) · [ (ε_s − ε_∞) / (1 + iωτ) ]
```

Повний вектор електричного зсуву `D(t)` враховує як швидку електронну поляризацію `P_fast = ε₀ · (ε_∞ − 1) · E(t)`, так і релаксаційну дипольну поляризацію `P(t)`:

```
D(t) = ε₀ · E(t) + P_fast(t) + P(t)
= ε₀ · E(t) · [ 1 + (ε_∞ − 1) + (ε_s − ε_∞) / (1 + iωτ) ]
= ε₀ · E(t) · [ ε_∞ + (ε_s − ε_∞) / (1 + iωτ) ]
```

Оскільки за визначенням `D(t) = ε₀ · ε*(ω) · E(t)`, отримуємо канонічне **рівняння комплексної діелектричної проникності Дебая**:

```
ε*(ω) = ε_∞ + (ε_s − ε_∞) / (1 + iωτ)
```

### 3. Розділення на дійсну та уявну частини

Для розділення комплексної проникності `ε*(ω) = ε'(ω) − i · ε''(ω)` на дійсну та уявну компоненти помножимо чисельник і знаменник дробу на комплексно-спряжений вираз `(1 − iωτ)`:

```
ε*(ω) = ε_∞ + [ (ε_s − ε_∞) · (1 − iωτ) ] / [ (1 + iωτ) · (1 − iωτ) ]
= ε_∞ + [ (ε_s − ε_∞) · (1 − iωτ) ] / (1 + ω²τ²)
```

Розкриємо дужки у чисельнику та розділимо дійсні й уявні доданки:

```
ε*(ω) = ε_∞ + (ε_s − ε_∞) / (1 + ω²τ²) − i · [ (ε_s − ε_∞) · ωτ / (1 + ω²τ²) ]
```

Звідси отримуємо відомі **дисперсійні формули Дебая**:

```
ε'(ω) = ε_∞ + (ε_s − ε_∞) / (1 + ω²τ²)         [дійсне ємнісне накопичення]
```

```
ε''(ω) = (ε_s − ε_∞) · ωτ / (1 + ω²τ²)          [уявні діелектричні втрати]
```

#### Математичні властивості дисперсійних кривих Дебая:

1. **Границя низьких частот (`ωτ ≪ 1`):**
   - `ε'(ω) ≈ ε_s` (диполі повністю встигають розвертатися за полем).
   - `ε''(ω) ≈ (ε_s − ε_∞) · ωτ → 0` (втрати прямують до нуля).

2. **Границя високих частот (`ωτ ≫ 1`):**
   - `ε'(ω) ≈ ε_∞` (диполі «заморожені» й не реагують на високочастотне поле).
   - `ε''(ω) ≈ (ε_s − ε_∞) / (ωτ) → 0` (втрати прямують до нуля).

3. **Точка релаксаційного максимуму (`ω₀ = 1 / τ`):**
   Обчислимо похідну уявної частини `dε'' / d(ωτ)` та прирівняємо її до нуля:

```
d/dx [ x / (1 + x²) ] = ( (1 + x²) − x · 2x ) / (1 + x²)² = (1 − x²) / (1 + x²)² = 0
```

Розв'язок рівняння `1 − x² = 0` дає екстремум при `x = ωτ = 1`.

У цій критичній точці `ω₀ = 1 / τ`:
- `ε'(ω₀) = ε_∞ + (ε_s − ε_∞) / 2 = (ε_s + ε_∞) / 2` (середнє значення проникності).
- `ε''__max = (ε_s − ε_∞) / 2` (амплітудний максимум поглинання енергії).

```
          [Дисперсійні криві Дебая]

   ε'  ^
  ε_s -+---\
       |    \  ε'(ω)
(ε_s+ε_∞)/2 -  - - \ - - - - - - - - -
       |            \
  ε_∞ -+-------------+-------------\---> log(ω)
       |             |
  ε''  ^             |  ε''(ω) [пік втрат]
 max  -+-- - - - - ( * ) - - - - -
       |          /     \
       +---------/-------\-------------> log(ω)
                ω₀ = 1/τ
```

### 4. Тангенс кута втрат та геометричний вивід півкола Коул — Коула

Тангенс кута діелектричних втрат `tan δ` дорівнює відношенню уявної частини проникності до дійсної:

```
tan δ = ε''(ω) / ε'(ω)
= [ (ε_s − ε_∞) · ωτ / (1 + ω²τ²) ] / [ ε_∞ + (ε_s − ε_∞) / (1 + ω²τ²) ]
= (ε_s − ε_∞) · ωτ / [ ε_s + ε_∞ · ω²τ² ]
```

Обчислимо частоту `ω_max`, на якій тангенс втрат `tan δ` досягає свого абсолютного максимуму. Диференціюючи вираз за `ωτ` та прирівнюючи похідну до нуля, отримуємо:

```
ω_max = (1 / τ) · √(ε_s / ε_∞)
```

Максимальне значення тангенса втрат дорівнює:

```
tan δ_max = (ε_s − ε_∞) / (2 · √(ε_s · ε_∞))
```

Це рівняння показує, що матеріал із великим діелектричним стрибком `ε_s − ε_∞` володіє колосальними втратами в зоні релаксації.

#### Вивід півкола Коул — Коула
Виключимо часовий параметр `ωτ` із системних рівнянь для `ε'(ω)` та `ε''(ω)`.

Позначимо `x = ε' − ε_∞` та `y = ε''`. Тоді:

```
x = (ε_s − ε_∞) / (1 + ω²τ²)
y = (ε_s − ε_∞) · ωτ / (1 + ω²τ²)
```

Поділимо `y` на `x`: `y / x = ωτ`. Підставимо `ωτ = y / x` у вираз для `x`:

```
x = (ε_s − ε_∞) / [ 1 + (y / x)² ]
= (ε_s − ε_∞) · x² / (x² + y²)
```

Скоротимо обидві частини на `x` (при `x ≠ 0`):

```
1 = (ε_s − ε_∞) · x / (x² + y²)
x² + y² = (ε_s − ε_∞) · x
```

Перенесемо доданок із `x` у ліву частину та доповнимо до повного квадрата:

```
x² − (ε_s − ε_∞) · x + [ (ε_s − ε_∞) / 2 ]² + y² = [ (ε_s − ε_∞) / 2 ]²
[ x − (ε_s − ε_∞) / 2 ]² + y² = [ (ε_s − ε_∞) / 2 ]²
```

Повертаючись до вихідної змінної `ε' = x + ε_∞`, отримуємо канонічне рівняння кола:

```
[ ε' − (ε_s + ε_∞) / 2 ]² + [ ε'' ]² = [ (ε_s − ε_∞) / 2 ]²
```

Це рівняння кола на комплексній площині `(ε', ε'')` з центром у точці `( (ε_s + ε_∞)/2, 0 )` та радіусом `R = (ε_s − ε_∞) / 2`. Оскільки діелектричні втрати завжди додатні `ε'' ≥ 0`, фізична діаграма являє собою верхнє півколо Коул — Коула.

```
                  [Діаграма Коул — Коула]

      ε'' ^
          |          * (ω = 1/τ, максимум втрат)
          |       /     \
          |      /       \
          |     /         \
          +----+-----------+---------> ε'
              ε_∞  Центр   ε_s
```

#### Розширені дробово-степеневі моделі релаксації:
У реальних полімерах, аморфних тілах та неупорядкованих діелектриках існує не один час релаксації `τ`, а неперервний спектр розподілу часів. Для їх опису математики та фізики розробили узагальнені релаксаційні моделі:

1. **Модель Коул — Коула (параметр `α`):**
   ```
   ε*(ω) = ε_∞ + (ε_s − ε_∞) / [ 1 + (i · ω · τ)¹⁻ᵃ ]    [0 ≤ α < 1]
   ```
   На комплексній площині параметр `α` приплюскує півколо, опускаючи його центр нижче дійсної осі `ε'`.

2. **Модель Коул — Девідсона (параметр `β`):**
   ```
   ε*(ω) = ε_∞ + (ε_s − ε_∞) / [ 1 + i · ω · τ ]ᵇ        [0 < β ≤ 1]
   ```
   Описує асиметричний розподіл втрат із розтягнутим високочастотним «хвостом».

3. **Узагальнена модель Гаврільяка — Негамі:**
   ```
   ε*(ω) = ε_∞ + (ε_s − ε_∞) / [ 1 + (i · ω · τ)¹⁻ᵃ ]ᵇ
   ```
   Об'єднує симетричне розширення `α` та асиметрію `β` для точної апроксимації спектрів складних біополімерів та рідких кристалів.

### 5. Інтегральні співвідношення Крамерса — Кроніґа

Дійсна частина `ε'(ω)` (диперсія) та уявна частина `ε''(ω)` (поглинання) не є незалежними функціями. Вони зв'язані між собою фундаментальними інтегральними співвідношеннями Крамерса — Кроніґа, які є прямим математичним наслідком принципу причинності у аналітичних функціях комплексного змінного.

```
ε'(ω) − ε_∞ = (2 / π) · P.V. ∫₀^∞ (x · ε''(x)) / (x² − ω²) dx
```

```
ε''(ω) = − (2 · ω / π) · P.V. ∫₀^∞ (ε'(x) − ε_∞) / (x² − ω²) dx
```

де `P.V.` (*Principal Value*) позначає інтеграл у сенсі головного значення за Коші.

#### Фізичні інваріанти та теорема про суму частот:
Зі співвідношень Крамерса — Кроніґа випливає важливий фундаментальний висновок: якщо відома повна крива поглинання матеріалу `ε''(ω)` на всіх частотах від `0` до `∞`, можна однозначно обчислити дійсне значення діелектричної проникності `ε'(ω)` на будь-якій частоті без проведення додаткових вимірювань.

Зокрема, інтегрування всієї смуги поглинання дає так зване **правило сум для частот плазмових коливань**:

```
∫₀^∞ x · ε''(x) dx = (π / 2) · ω_p² = (π / 2) · (N · e² / (m_e · ε₀))
```

де `ω_p` — плазмова частота електронів у середовищі. Це правило стверджує, що загальна інтегральна площа під кривою діелектричних втрат `ε''(ω)` визначається виключно повною концентрацією електронів у речовині `N` і є абсолютним фізичним інваріантом матеріалу.
