# Діелектрична проникність

<preknowlist>
- [Електричне поле](book:physics/electric-field) — напруженість поля E, векторна характеристика дії на заряд.
- [Закон Кулона](book:physics/coulomb-law) — сила між зарядами у вакуумі та електрична стала ε₀.
- [Електричний потенціал](book:physics/electric-potential) — потенціальна енергія та різниця потенціалів.
- [Електричний заряд](book:physics/electric-charge) — вільні та зв'язані заряди в речовині.
</preknowlist>

Якщо зарядити дві паралельні металеві пластини від акумулятора й від'єднати їх від джерела, між ними виникне постійна напруга `V₀`, обумовлена накопиченим вільним зарядом `Q₀`. Якщо тепер у зазор між пластинами засунути плиту з чистого політетрафторетилену (тефлону), вимірювач напруги покаже, що різниця потенціалів зменшилася рівно у `2.1` раза. Заряд `Q₀` на металевих обкладках при цьому лишився незмінним — тефлон є ідеальним ізолятором і не пропускає струму. Проте результуюче електричне поле всередині зазору ослабло у `2.1` раза порівняно з вакуумом.

Коефіцієнт, який показує, у скільки разів середовище послаблює зовнішнє електростатичне поле або скільки реактивної енергії воно здатне накопичити на одиницю об'єму, називається **діелектричною проникністю** (*dielectric permittivity*, від грецького *dia-* — крізь, та латинського *permittere* — пропускати).

Діелектрична проникність є однією з головних фундаментальних характеристик матерії у фізиці суцільних середовищ, електродинаміці та радіофізиці. Вона визначає не лише ємність конденсаторів, а й швидкість поширення електромагнітних хвиль у материнських платах, глибину проникнення радіосигналів у біологічні тканини, показник заломлення світла в оптиці та струми витоку в сучасних нанометрових транзисторах.

> 📜 **Історичний контекст.** Явище зростання ємності при введенні ізолятора вперше кількісно виміряв Майкл Фарадей у 1837 році за допомогою концентричних сферичних конденсаторів. Детальніше про хронологію відкриттів — у вставці [Історія відкриття діелектричної проникності](book:physics/electromagnetism/dielectric-constant/hist-dielectric-history.md).

### 1. Фізичний механізм: поляризація та вектор електричного зсуву D

Щоб зрозуміти, чому матерія послаблює внутрішнє поле, розгледимо мікроскопічну будову ізолятора. На відміну від металів, де вільні електрони можуть безперешкодно мандрувати по всьому об'єму, у діелектриках усі заряди є **зв'язаними** (*bound charges*) — електрони міцно утримуються біля своїх атомних ядер або в хімічних зв'язках.

Коли діелектрик потрапляє в зовнішнє електричне поле `E_ext`, на кожну позитивну й негативну частинку починає діяти сила Кулона `F⃗ = q · E⃗_ext`. Негативно заряджені електронні хмари трохи зміщуються проти напрямку вектора поля, а позитивно заряджені атомні ядра — за напрямком поля. У результаті кожен атом або молекула набуває індукованого електричного дипольного моменту `p⃗ = q · d⃗`.

Сумарний ефект зміщення мільярдів мікроскопічних диполів описується макроскопічним **вектором поляризації** `P⃗` (*polarization vector*), який визначається як дипольний момент одиниці об'єму речовини:

```
P⃗ = (1 / V) · ∑ p⃗_i
```

де `p⃗_i` — дипольний момент окремого атома чи молекули у мікроскопічному об'ємі `V`.

Усередині суцільної товщі діелектрика позитивні та негативні заряди сусідніх поляризованих атомів взаємно компенсують один одного. Проте на зовнішніх гранях бруса ця компенсація порушується:
- На лівій грані (поблизу позитивно зарядженої обкладки) виникає некомпенсований негативний поверхневий заряд з густиною `−σ_b`.
- На правій грані (поблизу негативно зарядженої обкладки) виникає позитивний поверхневий заряд `+σ_b`.

Ці зв'язані поверхневі заряди створюють всередині діелектрика власне внутрішнє поле `E_ind`, яке спрямоване строго назустріч зовнішньому полю `E_ext`:

```
E_ind = σ_b / ε₀
```

Результуюча напруженість поля всередині середовища `E` стає меншою за зовнішню:

```
E = E_ext − E_ind
```

```
           [Поляризація діелектрика у зовнішньому полі]

  +Q₀ [Пластина +]                                [Пластина −] −Q₀
  +----------------------------------------------------------+
  |                                                          |
  |   +--------------------------------------------------+   |
  |   | − σ_b                                      + σ_b |   |
  |   |  (−+)   (−+)   (−+)   (−+)   (−+)   (−+)   (−+)  |   |
  |   |  (−+)   (−+)   (−+)   (−+)   (−+)   (−+)   (−+)  |   |
  |   |  (−+)   (−+)   (−+)   (−+)   (−+)   (−+)   (−+)  |   |
  |   +--------------------------------------------------+   |
  |              <---------- E_ind                           |
  |   --------------------------------------------------->   |
  |                      E_ext (зовнішнє поле)               |
  +----------------------------------------------------------+
             Результуюче поле усередині: E = E_ext / εᵣ
```

Відношення напруженості зовнішнього поля у вакуумі `E_ext` до напруженості підсумкового поля у діелектрику `E` називається **відносною діелектричною проникністю** (`εᵣ`, *relative permittivity*):

```
εᵣ = E_ext / E
```

Оскільки результуюче поле `E` завжди менше за `E_ext`, для будь-якого ізоляційного середовища `εᵣ > 1` (для вакууму за визначенням `εᵣ = 1`). Для сухого повітря `εᵣ ≈ 1.0006`, для тефлону `εᵣ = 2.1`, для склотекстоліту FR-4 `εᵣ ≈ 4.5`, для чистої води `εᵣ ≈ 80`, а для сегнетоелектричної кераміки `εᵣ` сягає від 1500 до 10 000.

Добуток відносної проникності `εᵣ` на електричну сталу вакууму `ε₀` називається **абсолютною діелектричною проникністю** (`ε`):

```
ε = εᵣ · ε₀

ε₀ ≈ 8.854187817... × 10⁻¹² Ф/м  (або Кл² / (Н · м²))
```

Розмірність абсолютної проникності `ε` в системі СІ — фарад на метр (Ф/м). Вона показує, яка ємність утворюється між двома плоскими електродами площею 1 м², віддаленими на 1 метр один від одного в даному середовищі. Детальніше про зв'язок фундаментальних систем одиниць дивіться у статті про [абсолютну та відносну проникність](book:physics/electromagnetism/permittivity).

#### Вектор електричного зсуву D та макроскопічні рівняння
Оскільки зв'язані заряди `σ_b` самі залежать від підсумкового поля `E`, у теоретичній та прикладній електродинаміці впроваджують допоміжний **вектор електричного зсуву** `D⃗` (*electric displacement vector*, або електрична індукція):

```
D⃗ = ε₀ · E⃗ + P⃗
```

Для більшості лінійних та ізотропних діелектриків вектор поляризації прямо пропорційний напруженості поля `P⃗ = χₑ · ε₀ · E⃗`, де `χₑ` (*чи*) — безрозмірна **електрична сприйнятливість** (*electric susceptibility*). Звідси випливають фундаментальні співвідношення:

```
D⃗ = ε₀ · (1 + χₑ) · E⃗ = ε₀ · εᵣ · E⃗ = ε · E⃗
```

```
εᵣ = 1 + χₑ
```

Вектор зсуву `D⃗` має колосальну практичну цінність: його потік через будь-яку замкнену поверхню `S` визначається **виключно вільними зарядами** `Q_free`, які подаються від зовнішнього джерела живлення на електроди, і зовсім не залежить від макроскопічного складу діелектрика (перше рівняння Максвелла у матеріальному середовищі):

```
∮_S D⃗ · dA⃗ = Q_free
```

#### Енергія електричного поля та електромеханічні сили
При поляризації середовища зовнішнє поле виконує роботу зі зміщення зарядів проти внутрішніх атомних сил. Об'ємна густина енергії електричного поля `w` (вимірювана в Дж/м³) у діелектрику дорівнює:

```
w = (1 / 2) · D⃗ · E⃗ = (1 / 2) · ε₀ · εᵣ · E²
```

Заповнення зазору між обкладками конденсатора діелектриком із проникністю `εᵣ` при сталій напрузі `V` збільшує накопичену електричну енергію в `εᵣ` разів. Через це на межу діелектрика у неоднорідному полі діє всмоктувальна електромеханічна сила: край діелектричної плити завжди втягується в область сильнішого поля між електродами.

Сила `F`, яка втягує діелектричний брус шириною `w` у зазор плоского конденсатора з напругою `V` та відстанню між пластинами `d`, визначається похідною від накопиченої енергії за переміщенням `x`:

```
F = (1 / 2) · V² · (dC / dx) = (1 / 2) · ε₀ · (εᵣ − 1) · (w / d) · V²
```

### 2. Чотири мікроскопічні механізми поляризації

Значення діелектричної проникності `εᵣ` речовини повністю визначається її мікроскопічною будовою та хімічним складом. Існує чотири основні фізичні механізми, через які зовнішнє поле здатне зміщувати заряди.

![Чотири мікроскопічні механізми поляризації діелектриків](/book/physics/electromagnetism/dielectric-constant/img/dipole-mechanisms.svg)
*Чотири класи мікроскопічних механізмів поляризації (електронна, іонна, орієнтаційна та міжповерхнева) та їхні характерні частотні межі.*

#### 1. Електронна поляризація (деформаційна)
- **Мікроскопічна сутність:** під дією поля `E` центр негативно зарядженої електронної хмари зміщується відносно позитивного ядра атома на невелику відстань `d`.
- **Частотні межі:** притаманна абсолютно всім атомам та молекулам без винятку. Вона володіє найменшою інерцією серед усіх механізмів: зміщення електронної хмари відбувається за час близько `10⁻¹⁵` секунди. Електронна поляризація зберігається на частотах аж до оптичного та ультрафіолетового діапазонів (`10¹⁴ ... 10¹⁵` Гц).
- **Температурна залежність:** практично відсутня. Енергія зв'язку електронів в атомі (одиниці й десятки електронвольт) на кілька порядків перевищує середню енергію теплового руху `k_B · T` при кімнатних температурах, тому нагрівання не руйнує електронну поляризацію.

#### 2. Іонна поляризація
- **Мікроскопічна сутність:** спостерігається у кристалічних іонних гратках (наприклад, `NaCl`, `Al₂O₃`, `TiO₂`, `ZrO₂`). Зовнішнє поле зміщує позитивні іони (катіони `Na⁺`, `Ti⁴⁺`) за напрямком силових ліній, а негативні іони (аніони `Cl⁻`, `O²⁻`) — проти поля, деформуючи вихідну кристаллографічну комірку.
- **Частотні межі:** маси іонів у тисячі разів перевищують масу електрона, тому їхній відгук більш інерційний. Час встановлення іонної поляризації становить `10⁻¹³ ... 10⁻¹²` секунди. Цей механізм ефективно працює на частотах інфрачервоного діапазону (`10¹² ... 10¹³` Гц).
- **Температурна залежність:** слабка. При нагріванні амплітуда теплових коливань іонів зростає, а кристал трохи розширюється, що призводить до незначного падіння або зростання проникності залежно від симетрії кристала.

#### 3. Орієнтаційна (дипольна) поляризація
- **Мікроскопічна сутність:** виникає у речовинах, молекули яких мають власний постійний дипольний момент `p` навіть за відсутності зовнішнього поля через асиметрію хімічних зв'язків (наприклад, вода `H₂O`, аміак `NH₃`, спирти, полярні полімери). За відсутності поля хаотичний тепловий рух розкидає напрямки диполів у просторі, роблячи середню поляризацію нульовою (`P = 0`). Зовнішнє поле створює обертальний момент `M⃗ = p⃗ × E⃗`, намагаючись вишикувати молекулярні диполі уздовж силових ліній.
- **Частотні межі:** повертання цілих молекул у в'язкому рідкому або твердому середовищі вимагає подолання міжмолекулярного тертя. Час релаксації `τ` становить від `10⁻¹¹` с у низьков'язких рідинах до `10⁻³` с у полярних пластиках (частоти від кілогерц до гігагерц).
- **Температурна залежність:** дуже сильна. Згідно з класичною теорією Ланжевена — Дебая, орієнтаційна поляризовність обернено пропорційна абсолютній температурі:

```
α_o = p² / (3 · k_B · T)
```

При підвищенні температури інтенсивність хаотичного теплового руху зростає, що руйнує впорядкованість диполів та спричиняє стрімке падіння діелектричної проникності полярних рідин.

#### 4. Междуповерхнева (міграційна, або міжкристалітна) поляризація
- **Мікроскопічна сутність:** спостерігається у макроскопічно неоднорідних діелектриках, полікристалічних кераміках, шаруватих композитах та напівпровідниках. Середовище містить дефекти, межі зерен, пори або слабозв'язані іони домішок. Під дією поля вільні або напіввільні носії заряду повільно мігрують крізь об'єм і застрягають на межах розділу фаз, утворюючи об'ємні ділянки просторового заряду.
- **Частотні межі:** це найповільніший і найбільш інерційний механізм. Час формування міжповерхневого заряду становить від мілісекунд до десятків хвилин (частоти нижче `10³` Гц).
- **Температурна залежність:** зростає при нагріванні, оскільки підвищення температури полегшує термоіонну емісію та стрибкову провідність носіїв між пастками.

### 3. Локальне поле Лоренца та рівняння Клаузіуса — Моссотті

Макроскопічне електричне поле `E`, яке входить у загальні рівняння Максвелла, є величиною, усередненою по об'ємах, що містять мільйони атомів. Проте на окремий конкретний атом або іон у кристалічній ґратці діє не це усереднене поле `E`, а **локальне мікроскопічне поле** `E_loc`, яке утворюється зовнішніми джерелами та поляризованим оточенням цього атома.

Для обчислення `E_loc` Хендрік Лоренц запропонував метод концептуальної сфери: довкола досліджуваного атома подумки вирізається уявна сфера радіуса `R`, що значно перевищує міжвідстань атомів, але є малою порівняно з макроскопічними розмірами зразка.

![Сфера Лоренца та локальне поле](/book/physics/electromagnetism/dielectric-constant/img/local-field-clausius.svg)
*Модель уявної сфери Лоренца для розрахунку локального мікроскопічного поля E_loc та виведення співвідношення Клаузіуса — Моссотті.*

Сумарне локальне поле `E_loc` складається з трьох векторних компонентів:

```
E_loc = E + E_sphere + E_atomic
```

1. `E` — макроскопічне електричне поле у діелектрику (враховує вільні заряди на обкладках та макроскопічне поле зв'язаних зарядів на зовнішніх поверхнях зразка).
2. `E_sphere` — поле зв'язаних поверхневих зарядів, що виникають на внутрішній стінці вирізаної сфери Лоренца. Інтегруванням нормальної компоненти поляризації `P · cos θ` по поверхні сфери отримуємо точне значення: `E_sphere = P / (3 · ε₀)`.
3. `E_atomic` — мікроскопічне поле диполів, розташованих усередині вирізаної сфери Лоренца. Для середовищ із кубічною симетрією ґратки (або для хаотично розташованих атомів газу й рідини) ця сума строго дорівнює нулю: `E_atomic = 0`.

Таким чином, **локальне поле Лоренца** у кубічному кристалі або ізотропній рідині становить:

```
E_loc = E + P / (3 · ε₀)
```

Оскільки індукований дипольний момент атома пропорційний локальному полю `p = α · E_loc`, а макроскопічна поляризація об'єму дорівнює добутку концентрації атомів `N` на їхній середній дипольний момент `P = N · p = N · α · E_loc`, маємо:

```
P = N · α · ( E + P / (3 · ε₀) )
```

Підставивши вираз макроскопічної поляризації через електричну сприйнятливість `P = (εᵣ − 1) · ε₀ · E` та провівши алгебраїчні перетворення зі скороченням на `E`, отримуємо фундаментальне **рівняння Клаузіуса — Моссотті**:

```
(εᵣ − 1) / (εᵣ + 2) = (N · α) / (3 · ε₀)
```

#### Практичне значення співвідношення Клаузіуса — Моссотті:
Це рівняння є фундаментальним мостом між мікросвітом квантово-механічних поляризовностей атомів `α` та макроскопічною діелектричною проникністю матеріалу `εᵣ`. Воно пояснює, як змінюється проникність речовини при стисненні, фазових переходах або зміні густини `N`.

В оптичному діапазоні частот (`10¹⁴ ... 10¹⁵` Гц), де працює виключно електронна поляризація, згідно з електромагнітною теорією світла Максвелла виконується рівність `εᵣ = n²` (де `n` — показник заломлення світла). Підставляючи `εᵣ = n²`, отримуємо відому **формулу Лоренца — Лоренца**:

```
(n² − 1) / (n² + 2) = (N · α_e) / (3 · ε₀)
```

### 4. Динаміка у змінному полі: комплексна проникність і релаксація Дебая

При прикладані до діелектрика змінного гармонічного поля `E(t) = E₀ · eⁱʷᵗ` процес поляризації перестає бути миттєвим. На низьких частотах молекулярні диполі легко встигають розвертатися слідом за вектором `E`. Проте коли частота поля `ω` наближається до інверсійного часу релаксації `ω₀ = 1 / τ`, орієнтація диполів починає відставати за фазою на кут `δ`.

Для опису фазового зсуву та дисипації енергії у змінних полях діелектричну проникність подають у комплексній формі:

```
ε*(ω) = ε'(ω) − i · ε''(ω)
```

де `i = √(-1)` — уявна одиниця.

1. **Дійсна частина `ε'(ω)`** описує здатність діелектрика накопичувати енергію електричного поля (реактивна ємнісна складова). Вона визначає реальну ємність конденсатора у змінному колі: `C(ω) = ε'(ω) · C₀`.
2. **Уявна частина `ε''(ω)`** описує діелектричні втрати — незворотну дисипацію енергії електричного поля у тепло внаслідок внутрішнього міжмолекулярного тертя або провідності.

![Комплексна проникність та спектр Дебая](/book/physics/electromagnetism/dielectric-constant/img/complex-permittivity.svg)
*Дійсна частина ε'(ω) та уявна частина ε''(ω) комплексної проникності в зоні релаксації Дебая.*

Відношення уявної частини до дійсної називається **тангенсом кута діелектричних втрат** (*loss tangent*):

```
tan δ = ε''(ω) / ε'(ω)
```

Кут втрат `δ` характеризує відхилення зсуву фаз між струмом і напругою від ідеального квадратурного кута `90°`. В ідеальному безвтратному діелектрику `δ = 0` і `tan δ = 0`. У реальних ізоляторах питома теплова потужність втрат `p_loss` (у Вт/м³), що виділяється у вигляді тепла, дорівнює:

```
p_loss = ω · ε₀ · ε'(ω) · tan δ · E² = ω · ε₀ · ε''(ω) · E²
```

#### Класична модель релаксації Дебая
Згідно з теорією Дебая, комплексна проникність середовища з єдиним часом релаксації `τ` описується рівнянням:

```
ε*(ω) = ε_∞ + (ε_s − ε_∞) / (1 + i · ω · τ)
```

де `ε_s` — статична проникність (на постійному струмі `ω = 0`), `ε_∞` — високочастотна оптична проникність (`ωτ ≫ 1`), а `τ` — характерний час дезорієнтації диполів.

Розділивши це рівняння на дійсні та уявні доданки, отримуємо спектральні формули Дебая:

```
ε'(ω) = ε_∞ + (ε_s − ε_∞) / (1 + ω² · τ²)
```

```
ε''(ω) = (ε_s − ε_∞) · ω · τ / (1 + ω² · τ²)
```

Аналіз цих рівнянь показує, що дійсна частина `ε'(ω)` монотонно падає від `ε_s` до `ε_∞` при збільшенні частоти. Уявна частина `ε''(ω)` демонструє симетричний резонансно-подібний пік, досягаючи свого максимуму `ε''__max = (ε_s − ε_∞) / 2` строго на частоті релаксації `ω₀ = 1 / τ`.

> 🧮 **Математичне виведення та зв'язки.** Детальний крок-за-кроком вивід рівнянь Дебая, аналіз півкола на діаграмі Коул — Коула та інтегральні співвідношення Крамерса — Кроніґа наведено у вставці [Математична теорія релаксації Дебая](book:physics/electromagnetism/dielectric-constant/math-debye-relaxation.md).

#### Загадка діелектричної проникності води
Яскравим прикладом частотної дисперсії є дистильована вода:
- **На низьких частотах (`f < 1` ГГц):** діелектрична проникність води становить `εᵣ ≈ 80.1`. Це колосальне значення забезпечується вільним повертанням полярних молекул `H₂O` (орієнтаційна поляризація). Така висока проникність ослаблює кулонівське притягання між іонами у 80 разів, роблячи воду найсильнішим універсальним розчинником на Землі.
- **У мікрохвильовому діапазоні (`f = 2.45` ГГц, частота мікрохвильової печі):** частота поля наближається до релаксаційної `f₀ = 1 / (2πτ) ≈ 17` ГГц. Дійсна проникність знижується до `ε' ≈ 74`, а тангенс втрат `tan δ ≈ 0.14` досягає значної величини. Радіохвиля активного поглинається рідкою водою, перетворюючи електромагнітну енергію на тепловий рух молекул.
- **В оптичному діапазоні (видиме світло, `f ≈ 5 × 10¹⁴` Гц):** важкі молекули води взагалі не встигають повертатися за світловими коливаннями. Орієнтаційна поляризація повністю зникає. Залишається лише надшвидка електронна поляризація з `εᵣ ≈ 1.77`. Згідно із законом Максвелла, показник заломлення води дорівнює `n = √εᵣ = √1.77 ≈ 1.33`. Саме тому світло вільно проходить крізь воду, роблячи її прозорою для людського ока.

### 6. Термодинаміка поляризації та температурні коефіцієнти

Зміна температури суттєво впливає на діелектричні властивості речовини через два протилежні термодинамічні фактори: зміну об'ємної густини (теплове розширення) та зміну інтенсивності хаотичного теплового руху частинок.

#### Термодинамічні потенціали діелектриків
При описі термодинаміки діелектрика у зовнішньому полі об'ємна густина вільної енергії Гельмгольца `F` набуває додаткового польового доданка:

```
dF = − S · dT − p · dV + E⃗ · dD⃗
```

де `S` — ентропія, `T` — температура, а `E⃗ · dD⃗` — елементарна робота поля над діелектриком.

Зі зміни вільної енергії при ізотермічній поляризації випливає явище **електрокалоричного ефекту** — зміни температури діелектрика `ΔT` при адіабатичній зміні електричного поля `E`:

```
ΔT = − (T / (2 · ρ · C_p)) · (∂ε / ∂T) · E²
```

де `ρ` — густина речовини, а `C_p` — питома теплоємність. В речовинах із сильною залежністю проникності від температури `∂ε / ∂T` (наприклад, у сегнетоелектриках біля точки Кюрі) електрокалоричний ефект використовують для створення екологічних твердотільних систем охолодження без фреону.

#### Температурний коефіцієнт проникності (TCε)
Залежність проникності від температури описується температурним коефіцієнтом `TCε`:

```
TCε = (1 / εᵣ) · (dεᵣ / dT)
```

1. **Для неполярних газоподібних та рідких діелектриків:** `TCε` є від'ємним (`TCε < 0`). При нагріванні речовина розширюється, концентрація атомів в одиниці об'єму `N` падає, що згідно з рівнянням Клаузіуса — Моссотті спричиняє зменшення `εᵣ`.
2. **Для полярних рідин (водяні розчини, спирти):** `TCε` є сильно від'ємним (для води `TCε ≈ −4600 ppm/°C`). Це пояснюється тим, що зростання кінетичної енергії теплового руху `k_B · T` активно руйнує орієнтаційний порядок диполів.
3. **Для іонних кристалів (оксид алюмінію, діоксид титану):** `TCε` може бути додатним (`TCε > 0`). При нагріванні пом'якшуються оптичні фононі моди ґратки, що полегшує зсув іонів під дією поля й компенсує теплове розширення.

### 7. Методи експериментального вимірювання діелектричної проникності

Вибір методу вимірювання `ε*(ω)` повністю визначається частотним діапазоном дослідження:

```
                   [Частотні методи вимірювання εᵣ]

  0 Гц ... 10 МГц        10 МГц ... 1 ГГц        1 ГГц ... 100 ГГц       > 0.5 ТГц
  ┌──────────────┐       ┌──────────────┐       ┌──────────────┐       ┌──────────────┐
  │ RLC-мости,   │  ───► │ Вимірювачі   │  ───► │ Об'ємні      │  ───► │ Терагерцова  │
  │ імпедансні   │       │ добротності  │       │ резонатори,  │       │ часова спект-│
  │ аналізатори  │       │ (Q-метри)    │       │ зонди лінії  │       │ роскопія     │
  └──────────────┘       └──────────────┘       └──────────────┘       └──────────────┘
```

1. **Низькочастотний міст вимірювання імпедансу (10 Гц – 100 МГц):** зразок діелектрика у формі пластини вирізають і поміщають між металевими електродами, утворюючи вимірювальний конденсатор. За допомогою містка Зейбіна або RLC-метра вимірюють ємність `C` та активну провідність `G`. Проникаючі параметри обчислюють за формулами: `ε' = C / C₀` та `tan δ = G / (ω · C)`.
2. **Метод резонаторного збудження (1 ГГц – 40 ГГц):** досліджувану пластину діелектрика вміщують у високодобротний металевий об'ємний резонатор або НВЧ-коаксіальний зонд. За зміщенням резонансної частоти `Δf` обчислюють дійсну проникність `ε'`, а за розширенням смуги пропускання (зменшенням добротності `ΔQ`) — тангенс втрат `tan δ`.
3. **Терагерцова часова спектроскопія (THz-TDS, 0.1 ТГц – 10 ТГц):** крізь зразок пропускають короткий пікосекундний імпульс терагерцового випромінювання. Порівнюючи часову форму та фазовий зсув імпульсу, що пройшов крізь зразок та крізь вакуум, через фур'є-перетворення одночасно отримують повні спектри `ε'(ω)` та `ε''(ω)`.

### 8. Анізотропія, нелінійність та сегнетоелектрики

У багатьох практично важливих матеріалах зв'язок між векторами `D⃗` та `E⃗` є складнішим за просту скалярну пропорційність `D⃗ = ε₀ · εᵣ · E⃗`.

#### 1. Діелектрична анізотропія кристалів
У некубічних кристалах (кварц, сапфір, кальцит, турмалін) діелектрична проникність залежить від напрямку електричного поля відносно кристаллографічних осей. У таких середовищах проникність описується тензором другого рангу `ε_ij` з 9 компонентами:

```
D_x = ε_xx · E_x + ε_xy · E_y + ε_xz · E_z
D_y = ε_yx · E_x + ε_yy · E_y + ε_yz · E_z
D_z = ε_zx · E_x + ε_zy · E_y + ε_zz · E_z
```

Анізотропія проникності викликає явище **подвійного променезаломлення** (*birefringence*) в оптиці, коли світлова хвиля розщеплюється на ззвичайний та незвичайний промені, що рухаються з різними швидкостями `v_o = c / √ε_o` та `v_e = c / √ε_e`.

#### 2. Нелінійні діелектрики та сегнетоелектрики
У дуже сильних електричних полях (`E > 10⁶` В/м) вектор поляризації насичується, а проникність стає функцією напруженості поля `εᵣ(E)`.

Особливий клас нелінійних діелектриків становлять [сегнетоелектрики](book:physics/electromagnetism/ferroelectrics) (титанати барію `BaTiO₃`, цирконату-титанату свинцю PZT, сегнетова сіль). У цих матеріалах у певному температурному діапазоні виникає спонтанна поляризація середовища навіть за відсутності зовнішнього поля.

- **Гістерезис поляризації:** залежність `P(E)` має вигляд петлі гістерезису з залишковою поляризацією `P_r` та коерцитивним полем `E_c`.
- **Точка Кюрі (`T_c`):** при нагріванні вище температури Кюрі сегнетоелектрик здійснює фазовий перехід другого роду у звичайний параелектричний стан, а його проникність описується законом Кюрі — Вейсса:

```
εᵣ = C / (T − T_c)
```

де `C` — константа Кюрі. В околиці точки Кюрі відносна діелектрична проникність `εᵣ` сягає гігантських значень від 10 000 до 100 000.

### 9. Інженерні застосування: матеріали, конденсатори та НВЧ-плати

Знання діелектричної проникності та тангенса втрат є критичним фундаментом для проектирування електронних компонентів та високочастотних схем.

> 🔧 **Навіщо це.** Без урахування діелектричної проникності неможливо розрахувати ані розміри друкованої плати, ані товщину затвора транзистора, ані ємність керамічного конденсатора.

#### 1. Високочастотні друковані плати (PCB) та швидкість сигналу
Електромагнітна хвиля у смужковій або мікросмужковій лінії передачі на друкованій платі поширюється зі фазовою швидкістю `v`, що залежить від ефективної діелектричної проникності підкладки `ε_r,eff`:

```
v = c / √ε_r,eff
```

Затримка поширення сигналу `t_pd` (у наносекундах на метр) становить:

```
t_pd = (1 / v) = (√ε_r,eff / c) ≈ 3.33 · √ε_r,eff  (нс/м)
```

Для стандартного склотекстоліту FR-4 (`εᵣ ≈ 4.5`) швидкість поширення сигналу становить лише `v ≈ 14.1` см/нс (близько 47% від швидкості світла). Крім того, на частотах понад 1 ГГц високий тангенс втрат FR-4 (`tan δ ≈ 0.02`) призводить до значного згасання високих частотних компонентів імпульсу.

Для швидкісних цифрових шин (PCIe 5.0/6.0, USB4, Ethernet 400G, радіотракти 5G) застосовують спеціальні маловтратні ламінати на основі фторопласту або керамо-наповнених полімерів (наприклад, Rogers RO4003C, `εᵣ = 3.38`, `tan δ = 0.0027`), де втрати в 10 разів менші.

#### 2. Керамічні конденсатори MLCC: Class 1 проти Class 2
У конденсаторах діелектрична проникність безпосередньо визначає ємність: `C = εᵣ · ε₀ · A / d`.

- **Класс 1 (NP0 / C0G):** використовує діелектрики на основі оксиду титану `TiO₂` або оксидів неодиму (`εᵣ ≈ 30...100`). Вони мають помірну проникність, але надзвичайно високу стабільність: `tan δ < 0.001`, а ємність не залежить від прикладеної напруги та температури. Використовуються у точних резонансних LC-фільтрах та високочастотних колах.
- **Класс 2 (X7R, X5R, Y5V):** використовує [сегнетоелектрики](book:physics/electromagnetism/ferroelectrics) на основі титанату барію `BaTiO₃` (`εᵣ ≈ 1500...10 000`). Вони дають змогу створювати конденсатори ємністю 10–100 мкФ у крихітних корпусах. Проте ці матеріали мають сильну нелінійність: при прикладанні постійної напруги (DC bias effect) їхня реальна проникність та ємність можуть падати на 50–80%.

```
[Порівняння класів діелектриків конденсаторів]

  Характеристика             | Клас 1 (NP0/C0G)     | Клас 2 (X7R)
  ---------------------------+----------------------+---------------------
  Проникність εᵣ             | 30 – 100             | 1500 – 4000
  Тангенс втрат tan δ        | < 0.001 (мізерний)   | 0.015 – 0.025
  Стабільність від напруги   | Абсолютна (100%)     | Падіння до 70%
  Основне призначення        | Фільтри, ВЧ-кола     | Блокування живлення
```

#### 3. Наноелектроніка: High-k та Low-k матеріали
У сучасних мікропроцесорах розмір транзисторів становить всього кілька нанометрів. 
- **High-k діелектрики (`HfO₂`, `εᵣ ≈ 25`):** заступили класичний `SiO₂` (`εᵣ = 3.9`) у підзатворному ізоляторі польових транзисторів. Це дало змогу збільшити фізичну товщину ізоляційного шару у 6 разів за збереження тієї самої ємності затвора, що зупинило паразитний тунельний струм витоку.
- **Low-k діелектрики (`εᵣ < 2.5`):** застосовуються для ізоляції міжмікросхемних мідних провідників металізації, щоб зменшити паразитну міжпровідникову ємність та усунути перехресні завади (crosstalk).
