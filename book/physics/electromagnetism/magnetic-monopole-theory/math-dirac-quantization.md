# 🧮 Квантування Дірака, векторний потенціал та фаза Ааронова-Бома

Ця математична вставка містить точний векторний та квантовомеханічний вивід умови квантування Дірака, побудову векторного потенціалу магнітного монополя на сфері за допомогою карт покриття Ву-Янга, обчислення кривини Беррі та інтегрування моменту імпульсу електромагнітного поля Пойнтінга, збереженого у системі «електричний заряд + магнітний монополь». Вона розкриває точний алгебраїчний та топологічний механізм, завдяки якому гіпотеза про існування магнітного заряду вимагає квантування усього електричного заряду у Всесвіті.

## Магнітне поле монополя у сферичних координатах

Розглянемо нерухомий точковий магнітний монополь з магнітним зарядом `q[m]`, розташований у початку координат `r = 0`. Його магнітна індукція `B` має точкову кулонівську структуру зі строго радіальним напрямком у кожній точці тривимірного простору:

```
B(r) = (μ₀ q[m] / 4π r²) · r̂
```

де `r̂ = r / r` — одиничний радіус-вектор, а `μ₀` — магнітна стала вакууму (`4π × 10⁻⁷` Гн/м).

У сферичній системі координат `(r, θ, φ)` вектор магнітної індукції має лише один ненульовий радіальний компонент, тоді як полярний та азимутальний компоненти тотожно дорівнюють нулю:

```
B[r] = μ₀ q[m] / 4π r²
B[θ] = 0
B[φ] = 0
```

Спробуємо побудувати стандартний векторний потенціал `A` таким чином, щоб у кожній точці виконувалося співвідношення `B = ∇ × A`. Загальний вираз для ротора векторного поля `A = (A[r], A[θ], A[φ])` у сферичних координатах розкладається на три компоненти:

```
(∇ × A)[r] = (1 / r sinθ) · [∂(sinθ A[φ]) / ∂θ - ∂A[θ] / ∂φ]
(∇ × A)[θ] = (1 / r) · [(1 / sinθ) ∂A[r] / ∂φ - ∂(r A[φ]) / ∂r]
(∇ × A)[φ] = (1 / r) · [∂(r A[θ]) / ∂r - ∂A[r] / ∂θ]
```

Припустимо, що векторний потенціал має азимутальну симетрію, тобто `A[r] = 0`, `A[θ] = 0`, а єдиний компонент `A[φ](r, θ)` не залежить від кута `φ`. Тоді компоненти ротора `(∇ × A)[θ]` та `(∇ × A)[φ]` обнуляються за умови, що `A[φ]` спадає як `1/r`:

```
∂(r A[φ]) / ∂r = 0  ⇒  A[φ](r, θ) = f(θ) / r
```

Радіальне рівняння `(∇ × A)[r] = B[r]` привносить диференціальне рівняння для функції `f(θ)`:

```
(1 / r sinθ) · d(sinθ A[φ]) / dθ = μ₀ q[m] / 4π r²
```

Помножимо обидві частини рівняння на `r sinθ` та викличемо процедуру інтегрування за кутом `θ`:

```
d(sinθ A[φ]) / dθ = (μ₀ q[m] / 4π r) · sinθ             [множення на r sinθ]
sinθ A[φ] = -(μ₀ q[m] / 4π r) · cosθ + C                [інтегрування за кутом θ]
A[φ](r, θ) = (μ₀ q[m] / 4π r sinθ) · (C - cosθ)         [ділення на sinθ]
```

Константа інтегрування `C` визначає конкретний вибір калібрування векторного потенціалу. Однак при будь-якому дійсному значенні `C` функція `A[φ]` неминуче ділиться на `sinθ`, що створює математичні сингулярності на полюсах сфери, де `sinθ = 0` (тобто при `θ = 0` або `θ = π`).

Якщо виберемо `C = 1`, потенціал має вигляд:

```
A[1, φ](r, θ) = (μ₀ q[m] / 4π r) · (1 - cosθ) / sinθ = (μ₀ q[m] / 4π r) · tan(θ / 2)
```

Цей вираз сингулярний на Південному полюсі (`θ = π`), де `tan(π/2) → ∞`. Сингулярна лінія, що прямує від монополя вздовж від'ємної осі `Z`, утворює струну Дірака.

Якщо ж вибрати `C = -1`, потенціал набуває вигляду:

```
A[2, φ](r, θ) = -(μ₀ q[m] / 4π r) · (1 + cosθ) / sinθ = -(μ₀ q[m] / 4π r) · cot(θ / 2)
```

Цей потенціал є сингулярним на Північному полюсі (`θ = 0`), де `cot(0) → ∞`.

## Карти покриття Ву-Янга та усунення сингулярностей

Щоб уникнути появи нефізичних сингулярних ліній у просторі, Тай Цзун Ву та Чень Нін Янг у 1975 році запропонували описувати векторний потенціал за допомогою двох окремих математичних карт покриття. Сфера `S²` радіуса `r` розбивається на дві відкриті півкулі з перекриттям уздовж екваторіальної смуги:

1. **Північна карта `U[N]`**: охоплює область `0 ≤ θ < π` (усьому простору крім Південного полюса `θ = π`).
   Вибираючи `C = 1`, за тригонометричною тотожністю `(1 - cosθ) / sinθ = tan(θ / 2)` отримуємо:

```
A[N, φ](r, θ) = (μ₀ q[m] / 4π r) · (1 - cosθ) / sinθ
              = (μ₀ q[m] / 4π r) · tan(θ / 2)
```

Векторний потенціал `A[N]` є абсолютно гладким та скінченним на всій Північній півкулі та екваторі `θ = π/2` (де `A[N, φ] = μ₀ q[m] / 4π r`), але стає сингулярним при `θ → π` (на Південному полюсі).

2. **Південна карта `U[S]`**: охоплює область `0 < θ ≤ π` (усьому простору крім Північного полюса `θ = 0`).
   Вибираючи `C = -1`, за тотожністю `(-1 - cosθ) / sinθ = -cot(θ / 2)` отримуємо:

```
A[S, φ](r, θ) = -(μ₀ q[m] / 4π r) · (1 + cosθ) / sinθ
              = -(μ₀ q[m] / 4π r) · cot(θ / 2)
```

Векторний потенціал `A[S]` є регулярним на всій Південній півкулі та екваторі, але прямує до нескінченності при `θ → 0` (на Північному полюсі).

Обчислимо різницю векторних потенціалів у смузі перекриття обох карт на екваторі (`θ = π/2`):

```
A[S] - A[N] = -(μ₀ q[m] / 4π r sinθ) · [(1 + cosθ) + (1 - cosθ)] · φ̂
            = -(μ₀ q[m] / 2π r sinθ) · φ̂
```

У сферичних координатах градієнт скалярної функції `χ(φ)` має вигляд `∇ χ = (1 / r sinθ) · (∂χ / ∂φ) · φ̂`. Прирівнявши різницю потенціалів до `∇ χ`, отримуємо:

```
∂χ / ∂φ = -μ₀ q[m] / 2π
χ(φ) = -(μ₀ q[m] / 2π) · φ
```

Отже, на екваторі потенціали `A[N]` та `A[S]` пов'язані точним градієнтним калібрувальним перетворенням `A[S] = A[N] + ∇ χ`.

## Вивід умови квантування Дірака з однозначності хвильової функції

Розглянемо квантовомеханічну частинку (наприклад, електрон) із зарядом `q[e]`, хвильова функція якої описується рівнянням Шредінгера чи Дірака у зовнішньому калібрувальному полі.

При калібрувальному перетворенні векторного потенціалу `A → A + ∇ χ` комплексне значення хвильової функції `Ψ` перетворюється множенням на фазовий множник:

```
Ψ[S](r) = exp(i · q[e] · χ(φ) / ℏ) · Ψ[N](r)
```

Підставивши скалярну функцію калібрування `χ(φ) = -(μ₀ q[m] / 2π) · φ`, отримуємо зв'язок між хвильовими функціями на двох картах:

```
Ψ[S](r) = exp(-i · (q[e] μ₀ q[m] / 2π ℏ) · φ) · Ψ[N](r)
```

Фундаментальна вимога квантової механіки стверджує, що хвильова функція `Ψ` повинна бути фізично **однозначною** у кожній точці простору. Якщо квантова частинка здійснює один повний обхід навколо екватора сфери (зміна азимутального кута `φ` від `0` до `2π`), фізичний стан системи не може змінитися. Фазовий множник зобов'язаний повернутися до початкового значення `1`:

```
exp(-i · (q[e] μ₀ q[m] / 2π ℏ) · 2π) = 1
exp(-i · (q[e] μ₀ q[m] / ℏ)) = 1
```

Щоб експонента дорівнювала одиниці, її показник зобов'язаний бути цілим кратним від `2π i`:

```
q[e] · μ₀ · q[m] / ℏ = 2π · n        (де n ∈ ℤ, тобто n = 0, ±1, ±2, ...)
```

Переписавши це рівняння через стандартну сталу Планка `h = 2π ℏ`, отримуємо класичну **умову квантування Дірака**:

```
q[e] · q[m] = n · (h / μ₀)
```

У системі одиниць СГС (Гаусса), де `μ₀ = 4π / c`, умова квантування має вигляд:

```
q[e] · q[m] = n · (ℏ c / 2)
```

Виразимо фундаментальний квант магнітного заряду `q[m,0]` (при `n = 1`) через елементарний електричний заряд `e`:

```
q[m,0] = h / (μ₀ e) = (6.62607 × 10⁻³⁴ Дж·с) / ((4π × 10⁻⁷ Гн/м) · (1.60218 × 10⁻¹⁹ Кл))
       ≈ 4.1357 × 10⁻¹⁵ Вб (Вебер)
```

Цей результат підтверджує, що існування бодай одного магнітного монополя з зарядом `q[m,0]` автоматично робить електричний заряд всіх елементарних частинок Всесвіту строго квантованим цілими кратностями від `e`.

## Узагальнена умова квантування Швінгера-Цванцігера для діонів

Розглянемо двочастинкову систему, що складається з двох діонів із зарядами `(q[e1], q[m1])` та `(q[e2], q[m2])`.

Джуліан Швінгер та Деніел Цванцігер проаналізували фазовий набіг хвильової функції при відносному обході двох діонів. Кожен діон створює як електричне кулонівське поле `E`, так і магнітне поле `B`. Обчислення додаткового моменту імпульсу полів Пойнтінга дає вектор:

```
L[EM] = -(μ₀ / 4π) · (q[e1] q[m2] - q[e2] q[m1]) · r̂₁₂
```

Квантовомеханічна умова квантування проєкції моменту імпульсу на вісь, що з'єднує частинки, вимагає, щоб величина `|L[EM]|` була цілим або напівцілим кратним від `ℏ / 2`:

```
(μ₀ / 4π) · (q[e1] q[m2] - q[e2] q[m1]) = n · (ℏ / 2)
```

Помноживши обидві частини на `4π / μ₀`, отримуємо загальне **співвідношення Швінгера-Цванцігера**:

```
q[e1] q[m2] - q[e2] q[m1] = (2π ℏ / μ₀) · n = (h / μ₀) · n
```

Якщо перший об'єкт є чистим електроном `(q[e], 0)`, а другий — чистим монополем `(0, q[m])`, це рівняння точно повертає стандартну умову Дірака `q[e] q[m] = n h / μ₀`.

## Топологічний інваріант Черна та фаза Беррі

З точки зору диференціальної геометрії, магнітне поле монополя є кривиною 2-форми `F = dA` на `U(1)`-головному розшаруванні. Векторна кривина Беррі `F` дорівнює:

```
F = B[r] · r² sinθ dθ ∧ dφ = (μ₀ q[m] / 4π) · sinθ dθ ∧ dφ
```

Інтегрування кривини `F` по всій поверхні замкненої двовимірної сфери `S²` визначає перший **топологічний клас Черна** `c₁`:

```
c₁ = (1 / 2π) ∬[S²] F = (1 / 2π) · (μ₀ q[m] / 4π) ∫₀²π dφ ∫₀π sinθ dθ
   = (1 / 2π) · (μ₀ q[m] / 4π) · 2π · 2
   = μ₀ q[m] / 2π
```

При квантуванні заряду `c₁` мусить відповідати цілому числу квантових фазових обходів `n = (q[e] / ℏ) · c₁`, що дає `n = q[e] μ₀ q[m] / 2π ℏ`. Це підтверджує, що квантування заряду є прямою наслідком топологічної структури розшарування `U(1)` над сферою `S²`.

## Момент імпульсу електромагнітного поля Пойнтінга

Існування точкового магнітного монополя `q[m]` у початку координат та електричного заряду `q[e]` у точці `r[e]` створює власну густину імпульсу електромагнітного поля, яка виражається вектором Пойнтінга `S`:

```
g[EM] = ε₀ · (E × B)
```

Обчислимо повний момент імпульсу полів `L[EM]`, інтегруючи момент густини імпульсу по всьому тривимірному простору:

```
L[EM] = ∫ r × g[EM] d³r = ε₀ ∫ r × (E × B) d³r
```

Підставивши вираз для електричного поля `E(r) = (q[e] / 4π ε₀) · (r - r[e]) / |r - r[e]|³` та магнітного поля монополя `B(r) = (μ₀ q[m] / 4π r³) · r`, виконаємо інтегрування у сферичних координатах:

```
L[EM] = (ε₀ μ₀ q[e] q[m] / 16π²) ∫ [r × ((r - r[e]) × r)] / (|r - r[e]|³ r³) d³r
```

Застосувавши векторну тотожність `r × (A × r) = A r² - r (A · r)` та використавши інтегрування за об'ємом, отримуємо точний аналітичний результат:

```
L[EM] = -(μ₀ · q[e] · q[m] / 4π) · r̂[e]
```

де `r̂[e]` — одиничний вектор, спрямований від монополя до електричного заряду.

Повний збережуваний момент імпульсу системи `J` дорівнює сумі орбітального механічного моменту `L[mech] = m (r × v)` та моменту електромагнітного поля `L[EM]`:

```
J = m · (r × v) - (μ₀ q[e] q[m] / 4π) · r̂[e] = const
```

У квантовій механіці проєкція моменту імпульсу на напрямок вектору `r̂[e]` квантується цілими або напівцілими значеннями `n ℏ / 2`. Оскільки проєкція поля дорівнює `|L[EM]| = μ₀ q[e] q[m] / 4π`, отримуємо:

```
μ₀ q[e] q[m] / 4π = n ℏ / 2  ⇒  q[e] q[m] = (2π ℏ / μ₀) · n
```

Цей класичний векторний розрахунок Пойнтінга дає абсолютно тотожну умову квантування Дірака, підтверджуючи глибоку внутрішню узгодженість класичної електродинаміки та квантової теорії.

## Оцінка маси солітона т'Гоофта-Полякова у границі БПЗ

У солітонній теорії т'Гоофта-Полякова з групою `SU(2)` лагранжіан містить калібрувальні поля `A[a, μ]` та трикомпонентне скалярне поле Хіггса `Φ^a` у супряженому представленні:

```
L = -1/4 F^a_{μν} F^{a, μν} + 1/2 D[μ]Φ^a D^μ Φ^a - λ/4 (Φ^a Φ^a - v²)²
```

У границі Богомольного-Прасада-Зоммерфільда (БПЗ, *BPS limit*), де потенціал самодії Хіггса прямує до нуля `λ → 0`, гамільтоніан системи переписується у вигляді повної суми квадратів:

```
H = 1/2 ∫ d³x [ (E[i]^a)² + (B[i]^a - D[i]Φ^a)² + 2 B[i]^a D[i]Φ^a ]
```

Мінімальне значення енергії досягається при виконанні рівняння Богомольного:

```
B[i]^a = D[i] Φ^a
```

Тоді мінімальна маса солітонного монополя виражається точним інтегралом від точного дивергентного терму:

```
M[BPS] = ∫ d³x B[i]^a D[i]Φ^a = ∯ dS[i] (v · B[i]) = (4π v / g) · q[m]
```

де `g` — калібрувальна константа зв'язку групи `SU(2)`. Оскільки мінімальний магнітний заряд топологічного дефекту в `SU(2)` дорівнює `q[m] = 4π / g`, маса монополя становить:

```
M[BPS] = 4π v / g
```

Оскільки маса електрослабких калібрувальних векторних бозонів дорівнює `M[W] = g v / 2`, відношення маси солітонного монополя до маси векторного бозона становить:

```
M[monopole] / M[W] = 8π / g² = 2 / α[GUT]
```

Для теорій Великого Об'єднання, де `α[GUT] ≈ 1/40`, маса монополя стає у `~80` разів більшою за масштаб Великого Об'єднання `M[X] ~ 10¹⁵` ГеВ, даючи значення `M[monopole] ~ 10¹⁶ - 10¹⁷` ГеВ. Це повністю узгоджується з аналітичними теоретичними розрахунками фізики високих енергій.
