# 📋 Специфікація та стандарти трифазних мереж: інтерфейси, кодувальник і параметри

У цій довідковій вставці зведено міжнародні стандарти, специфікації роз'ємів, колірне маркування провідників, а також розширену карту регістрів спеціалізованих мікросхем вимірювання потужності та промислових протоколів передачі даних для трифазних мереж.

### Світові стандарти трифазних напруг, частот та систем заземлення

Промислові та побутові системи трифазного електропостачання стандартизовано на міжнародному рівні документами IEC 60038 (International Electrotechnical Commission) у Європі та ANSI C84.1 у Північній Америці. Основними критеріями класифікації є номінальне значення фазної та лінійної напруг, мережева частота (50 Гц або 60 Гц), а також режим заземлення нейтралі (системи TN-S, TN-C, TT, IT).

#### Класифікація систем заземлення нейтралі

- **Система TN-S (Terre-Neutre Sеparе):** нейтральний провідник N та захисний провідник PE розділені по всій довжині від джерела живлення (трансформаторної підстанції) до кінцевого електроприймача. Це найвищий рівень безпеки: струм робочої нейтралі не протікає по корпусах обладнання, виключаючи появу напруги на металевих частинах. Всі сучасні житлові та промислові об'єкти в Європі будуються за цим стандартом.
- **Система TN-C (Terre-Neutre Combinе):** нейтральний та захисний провідники об'єднані в один провідник PEN на всьому протязі мережі. Ця схема застосовувалася в застарілих радянських мережах. Вона є потенційно небезпечною, оскільки при обриві провідника PEN на корпусах ввімкненого однофазного обладнання виникає повна фазна напруга 230 В.
- **Система TN-C-S (Terre-Neutre Combinе-Sеparе):** у магістральній мережі від підстанції до ввідно-розподільчого пристрою (ВРП) будівлі використовується об'єднаний провідник PEN, який на головній заземлювальній шині (ГЗШ) розділяється на окремі провідники N та PE. Повторне заземлення шини PE на уводі є обов'язковим.
- **Система TT (Terre-Terre):** нейтраль джерела глухо заземлена, а відкриті провідні частини електроустановки споживача приєднані до власного заземлювача, електрично незалежного від заземлювача підстанції. Система обов'язково вимагає застосування пристроїв захисного відключення (ПЗВ / RCD).
- **Система IT (Isolе-Terre):** нейтраль джерела живлення ізольована від землі або заземлена через високий опір (більше 1000 Ом). Застосовується в мережах вугільних шахт, хімічних виробництв та медичних операційних блоків, де при першому однофазному замиканні на землю струм є мізерно малим, що дозволяє продовжувати роботу обладнання без миттєвого відключення.

У Північній Америці використовують дві паралельні системи: комерційну мережу `120 / 208 В` та важку промислову мережу `277 / 480 В`.

#### Категорії перенапруги та вимоги безпеки (IEC 61010-1)

При проєктуванні вимірювальних аналізаторів та електрообладнання враховують категорію перенапруги (Overvoltage Category) згідно зі стандартом IEC 61010-1:

- **CAT I:** вимірювання у вторинних електронних кола, захищених малопотужними джерелами живлення.
- **CAT II:** підключення побутових приладів до розеткової мережі.
- **CAT III:** розподільчі щити промислових підприємств, трифазні шинопроводи, стаціонарні двигуни (витримує короткочасні імпульси перенапруги до 6 кВ).
- **CAT IV:** ввідний щит будівлі, лічильники електроенергії на межі балансової належності, повітряні та підземні вводи (витримує імпульси до 8 кВ).

### Специфікація колірного маркування провідників (IEC 60446 / EN 60446 / NEC)

Колірне маркування силових кабелів є суворим стандартом з техніки безпеки. Помилка у визначенні фазного або нейтрального провідника при монтажі може призвести до короткого замикання, подачі напруги 400 В на корпуси обладнання або небезпечного зворотного обертання електродвигунів.

Згідно з європейським стандартом **IEC 60446** (впровадженим в Україні як ДСТУ EN 60446), для фазних провідників встановлено сувору колірну гаму: фаза **L1 — коричневий** (*Brown*), фаза **L2 — чорний** (*Black*), фаза **L3 — сірий** (*Grey*). Нейтральний провідник N завжди позначається **блакитним** коліром (*Blue*), а захисний провідник заземлення PE — комбінованим **жовто-зеленим** коліром (*Yellow-Green*).

При використанні застарілих радянських кабелів (маркування до 2011 року) фази позначали за буквеною схемою Ж-З-Ч: фаза A — жовтий, фаза B — зелений, фаза C — червоний. При реконструкції таких щитів обов'язково встановлюють колірні термоусаджувальні трубки сучасного стандарту IEC.

### Специфікація вимірювальних трансформаторів струму (IEC 61869-2)

Трансформатори струму (ТС), що підключаються до аналізаторів потужності, регламентуються міжнародним стандартом IEC 61869-2. Їх основними технічними характеристиками є:

- **Номінальний вторинний струм:** стандартизовано два значення — `5 А` (для класичних промислових шинопроводів та коротких дистанцій) та `1 А` (для дистанцій понад 50 метрів між ТС і лічильником для зменшення втрат на нагрів кабелів).
- **Класи точності:** для комерційного розрахунку електроенергії (компресорні, заводські цехи, дата-центри) використовують класи точності `0.2S` або `0.5S`. Індекс `S` означає розширену точність при малих струмах навантаження (від 1% до 120% номінального струму I_nom). Для технічного обліку допускаються класи `0.5` та `1.0`.
- **Номінальне навантаження (Burden):** максимальна потужність у вольт-амперах (`2.5 VA`, `5 VA`, `10 VA`), яку трансформатор може віддавати у вторинне коло без погіршення класу точності.

**Смертельна небезпека розмикання вторинного кола ТС:** при проходженні первинного струму через ТС розмикання його вторинної обмотки спричиняє зникнення розмагнічувального вторинного струму. Весь первинний струм починає намагнічувати осердя, утворюючи у вторинній обмотці високовольтні амплітудні піки напруги амплітудою `U > 1000...3000 В`. Це призводить до міжвиткового пробою ізоляції, вибуху ТС та створює смертельну загрозу електричного удару для персоналу. Для обслуговування приладів без зупинки мережі використовують спеціальні випробувальні коротиші (Test Terminal Blocks / ИСП), які автоматично закорочують вторинні обмотки ТС перед вийманням аналізатора.

### Специфікація промислових силових роз'ємів CEE (IEC 60309)

Для надійного підключення трифазного промислового обладнання, мобільних генераторів, будівельних механізмів та верстатів використовують штепсельні роз'єми стандарту **IEC 60309** (також відомі як роз'єми CEE-form або серія CEE).

Конструкція роз'ємів IEC 60309 виключає можливість помилкового підключення вилки в розетку з іншою напругою або струмом завдяки системі напрямних пазів та розташуванню штиря захисного заземлення PE (Clock Position / Положення ключа у годинах). Для стандартних трифазних мереж `380...415 В` штир PE розташований на позиції `6 годин` (6h), а корпус роз'єму має суворе **червоне колірне кодування**. Для трифазних мереж `200...250 В` штир PE розташований на позиції `9 годин` (9h), а корпус має **синій колір**.

Штир захисного заземлення PE завжди зроблено товстішим і довшим за фазні штирі L1, L2, L3 та нейтраль N. Це гарантує, що при вмиканні вилки першим замикається захисне заземлення PE, а при вимиканні воно розмикається останнім, забезпечуючи безпеку оператора.

У силових роз'ємах на струми `63 А` та `125 А` додатково встановлюють центральний допоміжний пінг-контакт Pilot Pin. Він є коротшим за основні силові контакти і використовується у колах керування аварійним контактором: при від'єднанні роз'єму під навантаженням контакт Pilot розмикається першим, відключаючи котушку контактора до того, як розійдуться силові піни, запобігаючи виникненню потужної електричної дуги.

### Карта регістрів мікросхеми вимірювання енергії ADE7880

Мікросхема **Analog Devices ADE7880** є високоточним трифазним аналогово-цифровим контролером вимірювання енергії класів `0.2S` та `0.5S`. Вона містить 7 сигма-дельта АЦП розрядністю 24 біти, апаратний цифровий сигнальний процесор (DSP) для обчислення True RMS напруг, струмів, активної, реактивної та повної потужностей, а також апаратний аналізатор вищих гармонік до 63-го порядку.

Зв'язок із зовнішнім мікроконтролером здійснюється по шині SPI або I2C. Дані у внутрішніх регістрах ADE7880 подаються у форматі 24-бітних цілих чисел із розширенням до 32 бітів зі знаком (Two's Complement). Для переведення значень із внутрішніх кодів АЦП (LSB) у фізичні одиниці (Вольти, Ампери, Вати) використовують масштабні коефіцієнти, які обчислюють під час метрологічного калібрування.

#### Детальний аналіз функціональних регістрів ADE7880

- **Регістри діючих значень напруг (`AVRMS`, `BVRMS`, `CVRMS`):** 24-бітні регістри без знаку, що оновлюються на частоті 8 кГц. Для переведення у Вольти значення множать на масштаб `V_scale = V_ref / 2³³`.
- **Регістри діючих значень струмів (`AIRMS`, `BIRMS`, `CIRMS`, `NIRMS`):** містять середньоквадратичне значення фазних струмів та струму нейтралі. При відсутності несиметрії значення `NIRMS` дорівнює нулю.
- **Калібрувальні фазові регістри (`APHCAL`, `BPHCAL`, `CPHCAL`):** 10-бітні регістри зі знаком, що дозволяють компенсувати власний кутовий зсув трансформаторів струму з дискретністю `0.02°` на LSB у діапазоні від `-5.6°` до `+4.0°`.
- **Конфігураційний регістр `COMPMODE`:** задає режим роботи цифрового інтегратора (включено для котушок Роговського або виключено для трансформаторів струму), а також вибирає алгоритм обчислення загальної потужності (сума фазних потужностей або 3-провідний метод Арона).

### Карта регістрів Modbus RTU для трифазного аналізатора (Holding Registers 4x)

Промисловий протокол **Modbus RTU** через фізичний інтерфейс RS-485 є стандартним способом передачі виміряних даних від аналізатора потужності до програмованих логічних контролерів (ПЛК / PLC), панелей оператора HMI та систем SCADA або АСКУЕ.

Для зчитання даних використовують функцію Modbus `0x03` (*Read Holding Registers*) або `0x04` (*Read Input Registers*). Оскільки стандартні регістри Modbus є 16-бітними, кожен 32-бітний параметр із плаваючою комою (Float32 за стандартом IEEE 754) передається двома послідовними 16-бітними регістрами. Порядок слів у 32-бітному значенні регулюється конфігурацією приладу (найчастіше застосовують формат `Big-Endian Float` з перестановкою байтів CDAB або ABCD).

Накопичена активна енергія передається у 64-бітному форматі з подвійною точністю (`Double64`), що займає чотири послідовні 16-бітні регістри Modbus і запобігає втраті точності при підсумовуванні великих значень протягом багатьох років експлуатації.

#### Структура кадру запиту Modbus RTU (Read Holding Registers 0x03)

Пакет запиту містить 8 байтів:
1. `Slave Address` (1 байт): мережева адреса приладу (1...247).
2. `Function Code` (1 байт): код функції `0x03`.
3. `Starting Address High / Low` (2 байти): початкова адреса регістру Modbus.
4. `Quantity of Registers High / Low` (2 байти): кількість регістрів для зчитання.
5. `CRC-16 Low / High` (2 байти): циклічна контрольна сума.

### Протоколи DLMS/COSEM (IEC 62056) та ідентифікатори OBIS

У сучасних автоматизованих системах комерційного обліку електроенергії (АСКУЕ / AMR / AMI) замість Modbus застосовують міжнародний стандарт **DLMS/COSEM** (Device Language Message Specification / Companion Specification for Energy Metering), регламентований стандартом IEC 62056.

Для адресації кожної виміряної величини у протоколі DLMS/COSEM використовують коди **OBIS** (Object Identification System), які складаються з 6 груп чисел `A.B.C.D.E.F`:

- `1.0.1.7.0.255` — миттєва сумарна активна потужність `P_total` (Вт).
- `1.0.21.7.0.255` — миттєва активна потужність фази L1 (Вт).
- `1.0.41.7.0.255` — миттєва активна потужність фази L2 (Вт).
- `1.0.61.7.0.255` — миттєва активна потужність фази L3 (Вт).
- `1.0.1.8.0.255` — сумарна накопичена активна енергія `E_active_import` (кВт·год).
- `1.0.31.7.0.255` — діючий струм фази L1 (А).
- `1.0.32.7.0.255` — діюча напруга фази L1 (В).

Використання об'єктно-орієнтованої структури COSEM дозволяє уніфікувати опитування лічильників будь-яких виробників через оптичні порти, радіомодулі LoRaWAN, NB-IoT або PLC-модеми.

### Конфігураційні бітові маски та прапори подій

Для швидкого діагностування нештатних та аварійних режимів трифазної мережі контролер виставляє відповідні бітові прапори у 16-бітному регістрі стану `System_Status` (адреса Modbus `40045`).

Система SCADA або керівний мікроконтролер виконує побітову логічну операцію `AND` з відповідною бітовою маскою для миттєвого виявлення аварії:

```
Bit 0:  0x0001 - Phase A Voltage Loss (просідання VA < 10% Vnom)
Bit 1:  0x0002 - Phase B Voltage Loss (просідання VB < 10% Vnom)
Bit 2:  0x0004 - Phase C Voltage Loss (просідання VC < 10% Vnom)
Bit 3:  0x0008 - Phase Sequence Error (неправильне чередування фаз A-C-B)
Bit 4:  0x0010 - Overcurrent Event (перевантаження струму I > Imax)
Bit 5:  0x0020 - Overvoltage Event (перенапруга V > 1.2 Vnom)
Bit 6:  0x0040 - Neutral Overcurrent (струм IN перевищив фазний струм)
Bit 7:  0x0080 - Reverse Active Power Flow (генерація енергії в мережу)
Bit 8:  0x0100 - THD Voltage Exceeded (THDV > 5%)
Bit 9:  0x0200 - Calibration Error (помилка CRC конфігурації EEPROM)
```

При виявленні біта `0x0008` (помилка чередування фаз) керуюча автоматика блокує запуск трифазних компресорів та насосів для запобігання зворотному обертанню механізмів. При виявленні біта `0x0040` (перевантаження нейтралі) сигналізується про загрозу пожежі нейтрального кабелю через вищі гармоніки. Всі аварійні події фіксуються в журналі подій з міткою часу RTC та зберігаються у неенергозалежній пам'яті NVM. Для очищення журналу подій у регістр стану записують спеціальну командну послідовність `0x55AA`. Програмні таймери затримки (Debounce Timers) запобігають хибним спрацьовуванням автоматики при короткочасних імпульсних завадах.
