Передача великих масивів електричної енергії на відстані десятків та сотень кілометрів за допомогою однофазного змінного струму наражається на нездоланний фізичний та економічний бар'єр. Однофазне коло змінного струму характеризується пульсуючим характером передачі потужності: з частотою 100 Гц (при мережевій частоті 50 Гц) миттєва потужність двічі за період падає до нуля. Для потужних промислових електроприводів це означає наявність сильного вібраційного механічного моменту на валу двигуна, який швидкісно руйнує підшипники, викликає шкідливі механічні резонанси та суттєво зменшує ККД установки. Більше того, транспортування тієї самої потужності однофазною лінією вимагає значно більшого перерізу мідних чи алюмінієвих провідників порівняно з багатофазними системами.

Виходом із цього технологічного глухого кута стало створення трифазної симетричної синусоїдальної системи. Детальніше про драматичну боротьбу наукових шкіл та концепцій XIX століття можна прочитати в [історії створення трифазних систем](book:physics/electromagnetism/three-phase-power/hist-tesla-ferraris.md).

### 1. Фізична мотивація та математична анатомія трифазного синусоїдального поля

Трифазна система є сукупністю трьох однофазних електричних кіл, у яких діють трьохфазні електрорушійні сили (ЕРС) одинакової частоти `f` та амплітуди `Vm`, зсунуті одна відносно одної по фазі на суворо визначений кут `2π / 3` (або `120°`).

Аналітично зсув на `120°` обумовлений просторовим розташуванням обмоток у статорі трифазного генератора: три однакові обмотки розміщено в пазах статора зі зсувом у просторі на `120°`. При обертанні ротора з постійною кутовою швидкістю `ω` магнітне поле ротора послідовно наводить у цих обмотках синусоїдальні ЕРС, зсунуті у часі на третину періоду `T / 3`.

Якщо обрати фазу A як початкову відлікову фазу, миттєві значення напруг трьох фаз `uA(t)`, `uB(t)` та `uC(t)` описуються гармонійними функціями часу:

```
uA(t) = Vm · sin(ω·t)
uB(t) = Vm · sin(ω·t − 120°)
uC(t) = Vm · sin(ω·t + 120°)
```

де `ω = 2π·f` — колова (кутова) частота синусоїдального сигналу (для 50 Гц `ω ≈ 314.16 рад/с`).

![Синусоїдальні напруги трифазної системи з фазовим зсувом 120°](/book/physics/electromagnetism/three-phase-power/img/three-phase-waveforms.svg)
*Часові діаграми трьох фазних напруг uA(t), uB(t), uC(t) зі зсувом 120°.*

Головною математичною властивістю симетричної трифазної системи є те, що в будь-який довільний момент часу `t` алгебраїчна сума миттєвих значень фазних напруг суворо дорівнює нулю:

```
uA(t) + uB(t) + uC(t) = 0
```

Для доведення цього тотожності використаємо тригонометричну формулу суми синусів:

```
sin(ω·t − 120°) + sin(ω·t + 120°) = 2 · sin(ω·t) · cos(120°)
```

Оскільки `cos(120°) = −0.5`, сума двох зсунутих синусоїд дає:

```
2 · sin(ω·t) · (−0.5) = −sin(ω·t)
```

Додаючи першу фазу `uA(t) = Vm · sin(ω·t)`, отримуємо тотожний нуль:

```
Vm · sin(ω·t) + [ −Vm · sin(ω·t) ] = 0
```

Саме ця фундаментальна обставина дозволяє об'єднати три незалежні однофазні кола (які вимагали б 6 окремих дротів) у єдину трифазну систему з 4 провідниками (система з нейтраллю) або навіть 3 провідниками (система без нейтралі).

#### Принцип формування кругового обертового магнітного поля

Трифазний струм володіє унікальною властивістю безпосереднього створення обертового магнітного поля у статорі електричної машини без застосування будь-яких механічних частин, колекторів чи електронних комутаторів.

Коли трифазна система струмів `iA(t)`, `iB(t)`, `iC(t)` протікає по трьох обмотках статора, просторово зсунутих на `120°`, кожна обмотка створює пульсуючу компоненту магнітної індукції `BA`, `BB`, `BC`. Згідно з принципом суперпозиції, результуючий вектор магнітної індукції `B_rot` обчислюється як векторна сума трьох компонент:

```
B_rot(t) = BA(t) + BB(t) + BC(t)
```

У векторній формі амплітуда результуючого поля є строго постійною величиною `B_rot = 1.5 · Bm`, а сам вектор `B_rot` обертається в просторі з кутовою швидкістю `ω_sync = 2π·f / p` (де `p` — кількість пар полюсів статора).

Для 2-полюсного двигуна (`p = 1`) при частоті 50 Гц синхронна швидкість обертання магнітного поля становить:

```
n_sync = 60 · f / p = 60 · 50 / 1 = 3000 об/хв
```

Для 4-полюсного двигуна (`p = 2`) синхронна швидкість дорівнює `1500 об/хв`, а для 6-полюсного (`p = 3`) — `1000 об/хв`. Це обертове поле наводить ЕРС у роторі асинхронного двигуна, створюючи струми ротора. Взаємодія струмів ротора з обертовим магнітним полем статора створює електромагнітний обертовий момент `T_em`. Відносне відставання ротора від поля характеризується величиною ковзання `s = (n_sync − n_rotor) / n_sync`, яке у номінальному режимі становить `2...5%`.

### 2. Схемотехнічні топології: Зірка (Y) та Трикутник (Δ)

Обмотки трифазного генератора або фазні обмотки навантаження можуть бути з'єднані між собою двома канонічними способами: за схемою **Зірка** (Star / Wye, позначення `Y`) або за схемою **Трикутник** (Delta, позначення `Δ`).

![Схеми з'єднання Зірка (Y) з нейтральним провідником та Трикутник (Δ)](/book/physics/electromagnetism/three-phase-power/img/star-delta-connections.svg)
*Схемотехнічні зв'язки генератора та навантаження у трифазних колах.*

Розрізняють два типи напруг та струмів у трифазних колах:
- **Фазні величини (`Vph`, `Iph`):** напруга між початком і кінцем однієї фазної обмотки та струм, що протікає через цю обмотку.
- **Лінійні величини (`VL`, `IL`):** напруга між двома лінійними провідниками фаз та струм, що протікає у лінійному провіднику лінії передачі.

#### Схема з'єднання «Зірка» (Y)

При з'єднанні у «Зірку» кінці трьох фазних обмоток з'єднують в одну спільну точку `N`, яка називається **нейтральною точкою** (або нейтраллю). Провідник, що з'єднує нейтральні точки генератора та навантаження, називається **нейтральним провідником** (N). Провідники, що відходять від початків обмоток A, B, C, називаються **лінійними провідниками**.

При з'єднанні у «Зірку»:
1. **Струм у лінійному провіднику суворо дорівнює струму у відповідній фазі:**
   ```
   IL = Iph
   ```
2. **Лінійна напруга `VL` між двома фазними провідниками є векторною різницею двох фазних напруг `Vph`:**
   ```
   U_AB = U_A − U_B
   ```

Геометрично з векторної діаграми (рівнобедрений трикутник з кутом `120°` при вершині) випливає співвідношення для діючих значень:
   ```
   VL = 2 · Vph · cos(30°) = 2 · Vph · (√3 / 2) = √3 · Vph ≈ 1.732 · Vph
   ```

Наприклад, у побутовій європейській мережі при фазній напрузі `Vph = 230 В` лінійна напруга між будь-якими двома фазами становить `VL = 230 · √3 ≈ 400 В`.

![Векторна діаграма напруг та струмів у трифазній мережі](/book/physics/electromagnetism/three-phase-power/img/phasor-diagram-power.svg)
*Векторні співвідношення між фазними й лінійними величинами та кутом зсуву фаз φ.*

#### Схема з'єднання «Трикутник» (Δ)

При з'єднанні у «Трикутник» кінець першої обмотки фази A з'єднують із початком другої обмотки фази B, кінець фази B — з початком фази C, а кінець фази C — з початком фази A. Вузлові точки підключають до трьох лінійних провідників.

При з'єднанні у «Трикутник»:
1. **Фазна напруга суворо дорівнює лінійній напрузі:**
   ```
   VL = Vph
   ```
2. **Лінійний струм `IL` у провіднику лінії є векторною різницею двох сусідніх фазних струмів:**
   ```
   I_L1 = I_AB − I_CA
   ```
   Для симетричного навантаження співвідношення діючих значень становить:
   ```
   IL = √3 · Iph ≈ 1.732 · Iph
   ```

#### Порівняльний аналіз та перемикання Зірка-Трикутник

Схема «Зірка» дозволяє мати в одній мережі дві різні напруги (230 В для однофазних побутових приладів та 400 В для трифазних приладів) та вимагає на `√3` менший фазний струм при тій самій лінійній напрузі. Схема «Трикутник» виключає потребу в нейтральному провіднику і широко використовується для живлення потужних трифазних електродвигунів та сильних силових трансформаторів.

Для зменшення пускових струмів асинхронних двигунів великої потужності використовують пуск за схемою **«Переключення зірки на трикутник»**: під час розгону ротора обмотки двигуна включають у «Зірку» (зменшуючи напругу на фазі у `√3` разів та пусковий струм у 3 рази), а після досягнення номінальних обертів автоматика переключає обмотки у «Трикутник» для роботи на повній потужності.

### 3. Феномен постійності миттєвої потужності

Головною фізичною перевагою симетричної трифазної системи перед будь-якою однофазною мережею є **постійність сумарної миттєвої потужності**.

У кожній окремій фазі миттєва потужність `pA(t)`, `pB(t)`, `pC(t)` є добутком миттєвої напруги на миттєвий струм. Для довільного кута фазового зсуву `φ` між напругою та струмом:

```
pA(t) = uA(t) · iA(t) = Vm · Im · sin(ω·t) · sin(ω·t − φ)
pB(t) = uB(t) · iB(t) = Vm · Im · sin(ω·t − 120°) · sin(ω·t − 120° − φ)
pC(t) = uC(t) · iC(t) = Vm · Im · sin(ω·t + 120°) · sin(ω·t + 120° − φ)
```

Застосовуючи тригонометричну формулу добутку синусів `sin(α)·sin(β) = (1/2)[cos(α − β) − cos(α + β)]`, кожну фазну потужність розкладають на дві складові:

```
pA(t) = (Vm · Im / 2) · [ cos(φ) − cos(2ω·t − φ) ]
pB(t) = (Vm · Im / 2) · [ cos(φ) − cos(2ω·t − 240° − φ) ]
pC(t) = (Vm · Im / 2) · [ cos(φ) − cos(2ω·t + 240° − φ) ]
```

Зверніть увагу: перша складова `(Vm · Im / 2) · cos(φ) = Vph · Iph · cos(φ)` є постійною величиною (середньою активною потужністю фази), а друга складова є синусоїдою подвоєної частоти `2ω`.

При додаванні миттєвих потужностей усіх трьох фаз гармонійні складові подвоєної частоти мають однакові амплітуди та взаємний зсув `120°` у часі (оскільки `240° = 2 · 120°`). Їхня сума у будь-який момент часу дорівнює суворо нулю:

```
cos(2ωt − φ) + cos(2ωt − 240° − φ) + cos(2ωt + 240° − φ) = 0
```

У результаті сумарна миттєва потужність симетричної трифазної системи не залежить від часу `t` і є строго постійною величиною:

```
ptotal(t) = pA(t) + pB(t) + pC(t) = 3 · Vph · Iph · cos(φ) = const
```

де `Vph` та `Iph` — діючі (RMS) значення фазної напруги та струму, а `φ` — кут зсуву фаз між напругою та струмом навантаження.

![Постійність сумарної миттєвої потужності симетричної трифазної системи](/book/physics/electromagnetism/three-phase-power/img/instantaneous-power-constancy.svg)
*Графік миттєвих потужностей окремих фаз pA(t), pB(t), pC(t) та їх постійної суми ptotal(t).*

Строге математичне виведення цієї фундаментальної тотожності для симетричних та несиметричних режимів наведено у [математичному виводі трифазної потужності](book:physics/electromagnetism/three-phase-power/math-three-phase-power.md).

Завдяки постійності `ptotal(t)` трифазний електродвигун створює на валу абсолютний рівномірний обертовий момент без найменших пульсацій та вібрацій. Це забезпечує долговічність турбін, генераторів, верстатів та промислових компресорів.

### 4. Активна, реактивна та повна потужності у трифазному колі

За аналогією з однофазними колами змінного струму, енергетичний процес у трифазному колі описують трьома скалярними величинами: активною потужністю `P`, реактивною потужністю `Q` та повною потужністю `S`.

> 🔧 **Навіщо це.**
> Знання розрахунку трифазної потужності є фундаментом розрахунку перерізу силових кабелів, вибору номіналів захисних автоматів, розрахунку компенсаторів реактивної потужності (косинусних батарей конденсаторів) та балансування навантаження по фазах на промислових підприємствах.

#### 1. Активна потужність (P)

Активна потужність характеризує швидкість безповоротного перетворення електричної енергії в інші види енергії (теплову, механічну, світлову) за одиницю часу. Вимірюється у Ватах (Вт / W) або кіловатах (кВт / kW).

Для симетричної трифазної системи активна потужність дорівнює потрійній активній потужності однієї фази:

```
P = 3 · Vph · Iph · cos(φ)
```

Для вираження через лінійні напруги `VL` та струми `IL` виконують заміну залежно від схеми з'єднання:

- **При з'єднанні у Зірку (Y):** `Vph = VL / √3`, `Iph = IL`.
  ```
  P = 3 · (VL / √3) · IL · cos(φ) = √3 · VL · IL · cos(φ)
  ```
- **При з'єднанні у Трикутник (Δ):** `Vph = VL`, `Iph = IL / √3`.
  ```
  P = 3 · VL · (IL / √3) · cos(φ) = √3 · VL · IL · cos(φ)
  ```

Виникає універсальна фундаментальна формула активної потужності трифазного кола, яка є **однаковою для обох схем з'єднання**:

```
P = √3 · VL · IL · cos(φ)
```

#### 2. Реактивна потужність (Q)

Реактивна потужність характеризує швидкість періодичного обміну електромагнітною енергією між джерелом живлення та реактивними елементами навантаження (магнітними полями обмоток двигунів, трансформаторів та електричними полями конденсаторів). Вимірюється у вольт-амперах реактивних (вар / var) або ковар (квар / kvar).

Універсальна формула реактивної потужності симетричної трифазної системи:

```
Q = √3 · VL · IL · sin(φ)
```

При індуктивному навантаженні (двигуни, трансформатори) `sin(φ) > 0`, і реактивна потужність споживається з мережі. При ємнісному навантаженні (конденсаторні установки) `sin(φ) < 0`, і реактивна потужність генерується у мережу.

#### 3. Повна потужність (S) та деформаційна потужність (D)

Повна потужність характеризує граничну геометричну потужність, яку здатні передати силова лінія, трансформатор або генератор при заданих діючих значеннях напруги та струму. Вимірюється у вольт-амперах (В·А / VA) або кіловольт-амперах (кВА / kVA).

Універсальна формула повної потужності симетричної трифазної системи:

```
S = √3 · VL · IL
```

При наявності вищих гармонік струму й напруги (нелінійне навантаження) загальна повна потужність описується обобоченою теоремою Будяну:

```
S = √( P² + Q1² + D² )
```

де `Q1` — реактивна потужність першої основної гармоніки (50 Гц), а `D` — деформаційна потужність (Distortion Power), зумовлена спотворенням форми сигналів.

#### 4. Теорія миттєвої потужності Акагі (Instantaneous p-q Theory)

Для швидкої цифрової компенсації реактивної потужності та нелінійних спотворень за допомогою активних силових фільтрів (APF / STATCOM) професор Гірофумі Акагі у 1983 році розробив теорію миттєвої потужності у непорушній ортогональній системі координат `α-β-0` (перетворення Кларка).

Трифазні напруги `vA, vB, vC` та струми `iA, iB, iC` перераховують у двокоординатну ортогональну систему `v_alpha, v_beta`:

```
v_alpha = √(2/3) · ( vA − 0.5·vB − 0.5·vC )
v_beta  = √(2/3) · ( (√3/2)·vB − (√3/2)·vC )
```

Миттєва активна потужність `p_inst` та миттєва реактивна потужність `q_inst` обчислюються в матричному вигляді:

```
p_inst = v_alpha · i_alpha + v_beta · i_beta
q_inst = v_beta · i_alpha − v_alpha · i_beta
```

Цей метод дозволяє мікроконтролеру силового інвертора обчислювати та компенсувати реактивний струм навантаження у реальному часі за частки мілісекунди (без очікування завершення повного періоду 20 мс).

#### 5. Компенсація реактивної потужності (cos φ)

Промислові підприємства споживають велику кількість реактивної потужності для створення магнітних полів в асинхронних двигунах та трансформаторах, що зменшує коефіцієнт потужності до `cos(φ) = 0.6...0.7`. Це призводить до марного перевантаження ліній передачі реактивним струмом `I_Q = IL · sin(φ)` та спричиняє спад напруги у кабелях:

```
ΔV = (P · R + Q · X) / VL
```

Для компенсації реактивної потужності паралельно трифазному навантаженню підключають установки компенсації реактивної потужності (УКРМ) на основі трифазних конденсаторних батарей, які генерують випереджаючий ємнісний струм. Це дозволяє підвищити `cos(φ)` до номінальних `0.95...0.98`, зменшити нагрів кабелів та усунути штрафні тарифні надбавки енергопостачальних організацій.

### 5. Несиметричні режими та роль нейтрального провідника

У реальних розподільчих мережах 0.4 кВ (наприклад, у багатоквартирному будинку або офісному центрі) однофазні споживачі розподілені по трьох фазах нерівномірно. Такий режим називається **несиметричним навантаженням**.

При несиметричному навантаженні фазні струми `IA`, `IB`, `IC` не дорівнюють один одному за модулем та мають фазові кути, відмінні від `120°`.

#### 1. Роль нейтрального провідника N

У чотирипровідній системі «Зірка з нейтраллю» струм у нейтральному провіднику `iN(t)` за першим законом Кірхгофа дорівнює геометричній сумі струмів трьох фаз:

```
iN(t) = iA(t) + iB(t) + iC(t)
```

У симетричному режимі `IA = IB = IC`, і струм `iN = 0`. При несиметрії навантаження по нейтральному провіднику протікає струм небалансу `iN ≠ 0`. Головна функція нейтрального провідника полягає у **фіксації потенціалу нейтральної точки навантаження `N'` на рівні потенціалу нейтралі генератора `N`**, завдяки чому фазні напруги на всіх трьох фазах споживачів залишаються строго однаковими і дорівнюють `230 В` незалежно від несиметрії струмів.

#### 2. Феномен 3-ї гармоніки у нейтральному провіднику

При живленні нелінійних навантажень (імпульсних джерел живлення комп'ютерів, LED-освітлення, частотних перетворювачів) фазні струми містять вищі гармонічні складові. Особливу небезпеку становлять гармоніки, кратні трьом (3-тя, 9-та, 15-та гармоніки, так звані Triplen Harmonics).

Оскільки фазовий кут 3-ї гармоніки у `3` рази більший за кут основної гармоніки, кутовий зсув між фазами для 3-ї гармоніки становить:

```
3 · 120° = 360° = 0°
```

Це означає, що 3-ті гармоніки струмів усіх трьох фаз совпадають за фазою (є синфазними). При додаванні у нейтральному провіднику вони не компенсують одна одну, а арифметично підсумовуються:

```
iN_3rd(t) = iA_3rd(t) + iB_3rd(t) + iC_3rd(t) = 3 · I_3rd
```

У сучасних офісних центрах струм у нейтральному провіднику може перевищувати фазний струм у `1.5...1.73` рази (`IN > Iphase`), що викликає небезпечний перегрів та пожежу нейтрального кабелю. Для запобігання цій аварії переріз нейтрального провідника вибирають удвічі більшим за фазний або застосовують трансформатори зі схемою з'єднання обмоток **«Трикутник-Зірка» (Dyn11)**. Первинна обмотка у вигляді Трикутника замикає струми 3-ї гармоніки всередині контуру трикутника, циркулюючи їх у вигляді кільцевого струму і не випускаючи у високовольтну мережу.

#### 3. Аварійний режим: обрив нейтрального провідника («Перекіс фаз»)

Якщо у чотирипровідній мережі з несиметричним навантаженням відбувається обрив нейтрального провідника (відгорання «нуля» у розподільчому щиті), нейтральна точка навантаження `N'` втрачає зв'язок із землею та зміщується у комплексній площині. Згідно з теоремою Мільмана, виникає напруга зсуву нейтралі `V_NN'`:

```
V_NN' = ( V_A · Y_A + V_B · Y_B + V_C · Y_C ) / ( Y_A + Y_B + Y_C )
```

де `Y_A, Y_B, Y_C` — комплексні провідності фаз навантаження.

У результаті фазна напруга на фазі з малим навантаженням (великим опором `Z`) підскакує майже до повної лінійної напруги `380...400 В`, що спричиняє вибух та згорання побутової техніки, імпульсних блоків живлення та електронних приладів. На фазі з великим навантаженням (малим опором `Z`) напруга просідає до `100...130 В`, зупиняючи роботу електродвигунів холодильників та насосів, що загрожує їхнім перегрівом та згорянням обмоток.

Докладніше про міжнародні стандарти мережевих напруг, колірне маркування фазних кабелів та типи силових роз'ємів дивіться у [специфікаціях та стандартах трифазних мереж](book:physics/electromagnetism/three-phase-power/api-three-phase-specs.md).

#### 4. Диференційний захист трифазних кіл (ПЗВ / RCD Типу B)

Для захисту людини від ураження електричним струмом та запобігання пожежам застосовують пристрої захисного відключення (ПЗВ / RCD). У трифазних колах крізь вікно диференційного трансформатора струму проходять усі чотири провідники (L1, L2, L3, N).

У справній електроустановці сума векторів струмів дорівнює нулю:

```
I_L1 + I_L2 + I_L3 + I_N = 0
```

При пробої ізоляції на корпус виникає струм витоку `I_leak` на землю. Геометрична сума струмів стає відмінною від нуля, наводячи ЕРС у вторинній котушці ПЗВ, що викликає спрацьовування механізму розчеплювача при струмах витоку `30 мА` протягом `20...40 мс`. Для захисту інверторних частотних приводів застосовують ПЗВ типу B (Type B RCD), які здатні виявляти як змінний, так і згладжений постійний струм витоку.

### 6. Симетричні складові Фортеск'ю для розрахунку аварійних режимів

Для аналізу складних несиметричних режимів (однофазних та двофазних коротких замикань, обривів фаз) використовують розроблений Чарльзом Фортеск'ю у 1918 році **метод симетричних складових**.

Будь-яку несиметричну трифазну систему векторів `VA, VB, VC` розкладають на суму трьох симетричних систем:

1. **Пряма послідовність (`V1`):** три вектори однакової амплітуди із прямим чередуванням фаз `A-B-C` (зсув `120°`). Створює корисний обертовий момент двигуна.
2. **Зворотна послідовність (`V2`):** три вектори однакової амплітуди зі зворотним чередуванням фаз `A-C-B` (зсув `120°`). Створює гальмівний момент, розігріває ротор та викликає вібрацію.
3. **Нульова послідовність (`V0`):** три однакові вектори, що збігаються за напрямком (зсув `0°`). Протікає через нейтральний провідник та землю при коротких замиканнях на землю.

Матричне перетворення Фортеск'ю з використанням комплексного оператора зсуву `a = e^(j120°) = −0.5 + j(√3/2)` має вигляд:

```
V0 = (1 / 3) · ( VA + VB + VC )
V1 = (1 / 3) · ( VA + a·VB + a²·VC )
V2 = (1 / 3) · ( VA + a²·VB + a·VC )
```

Визначення складових зворотної та нульової послідовностей дозволяє мікроконтролерним реле захисту миттєво виявляти обрив фази або замикання на землю та відключати силовий контактор.

### 7. Метрологія та вимірювання потужності: метод двох ваттметрів (Схема Арона)

Вимірювання активної потужності у трифазних колах залежить від наявності нейтрального провідника.

#### 1. Чотирипровідна мережа з нейтраллю (3 ваттметри)

У чотирипровідній мережі з нейтральним провідником загальну активну потужність `P` вимірюють за допомогою трьох ваттметрів, струмові обмотки яких вмикають послідовно у фазні провідники A, B, C, а обмотки напруги підключають між відповідною фазою та нейтраллю N. Загальна потужність дорівнює арифметичній сумі показів трьох приладів:

```
Ptotal = P1 + P2 + P3
```

#### 2. Трипровідна мережа без нейтралі: метод Арона (2 ваттметри)

У трипровідній трифазній мережі (без нейтрального провідника) за методом Арона загальну активну потужність будь-якої трифазної системи (як симетричної, так і несиметричної) можна виміряти **всього двома ваттметрами**.

![Схема вимірювання потужності за методом двох ваттметрів (схема Арона)](/book/physics/electromagnetism/three-phase-power/img/two-wattmeter-method.svg)
*Схема включення двох ваттметрів у трипровідну мережу без нейтрального провідника.*

У цій схемі струмові обмотки двох ваттметрів вмикають у будь-які два лінійні провідники (наприклад, фази A та C), а їхні обмотки напруги підключають до третього провідника (фази B).

Покази першого ваттметра `P1` та другого ваттметра `P2` описуються виразами:

```
P1 = V_AB · I_A · cos(30° − φ)
P2 = V_CB · I_C · cos(30° + φ)
```

Сума показів двох ваттметрів строго дорівнює повній активній потужності трифазного кола:

```
Ptotal = P1 + P2
```

Крім того, різниця показів двох ваттметрів дозволяє обчислити повну реактивну потужність симетричного трифазного кола:

```
Qtotal = √3 · (P1 − P2)
```

#### Аналіз режимів роботи ваттметрів за методом Арона

Залежно від характеру навантаження (`cos(φ)`), покази двох ваттметрів суттєво змінюються:

- **При суто активному навантаженні (`φ = 0°`, `cos(φ) = 1.0`):** `P1 = P2 = VL · IL · cos(30°) = (√3 / 2) · VL · IL`. Обидва ваттметри показують однакові додатні значення.
- **При індуктивному навантаженні з `φ = 60°` (`cos(φ) = 0.5`):** `P1 = VL · IL · cos(−30°) = (√3 / 2) · VL · IL`, а `P2 = VL · IL · cos(90°) = 0`. Перший ваттметр показує усю потужність кола, а другий показує нуль.
- **При індуктивному навантаженні з `φ > 60°` (`cos(φ) < 0.5`):** кут `30° + φ > 90°`, тому `cos(30° + φ) < 0`. Покази другого ваттметра `P2` стають від'ємними. У цьому випадку стрілка аналогового приладу відхиляється ліворуч від нуля. Для зняття показань необхідно переключити полярність обмотки напруги другого ваттметра, а отримане значення відняти від показів першого ваттметра: `Ptotal = P1 − |P2|`.

Ознайомитися з апаратною схемою узгодження сигналів, 6-канальним АЦП та алгоритмами розрахунку True RMS на мікроконтролері C/C++ можна у [практичній реалізації цифрового аналізатора потужності](book:physics/electromagnetism/three-phase-power/proj-power-meter.md).

### 8. Енергетичний баланс та економіка передачі електроенергії

Порівняємо економічну ефективність передачі однакової активної потужності `P` на одну й ту саму відстань `L` при однаковій лінійній напрузі `VL` та однакових втратах потужності у дротах `ΔP` для двох варіантів: однофазної лінії та трифазної трипровідної лінії.

1. **Однофазна лінія (2 провідники):**
   Струм у провідниках лінії `I_1ph = P / (VL · cos(φ))`. Втрати потужності на нагрів у двох дротах опором `R1` кожен:
   ```
   ΔP_1ph = 2 · I_1ph² · R1 = 2 · [ P / (VL · cos(φ)) ]² · (ρ · L / S1)
   ```
2. **Трифазна лінія (3 провідники):**
   Струм у лінійному провіднику `I_3ph = P / (√3 · VL · cos(φ))`. Втрати потужності у трьох дротах опором `R3` кожен:
   ```
   ΔP_3ph = 3 · I_3ph² · R3 = 3 · [ P / (√3 · VL · cos(φ)) ]² · (ρ · L / S3) = [ P / (VL · cos(φ)) ]² · (ρ · L / S3)
   ```

Прирівнюючи втрати потужності `ΔP_1ph = ΔP_3ph`, отримуємо співвідношення перерізів провідників:

```
2 / S1 = 1 / S3  ==>  S3 = 0.5 · S1
```

Сумарний об'єм (маса) металу провідників для всієї лінії:
- **Однофазна лінія:** `Vol_1ph = 2 · S1 · L`.
- **Трифазна лінія:** `Vol_3ph = 3 · S3 · L = 3 · (0.5 · S1) · L = 1.5 · S1 · L`.

Таким чином, масове співвідношення витрати кольорового металу (міді чи алюмінію) становить:

```
Vol_3ph / Vol_1ph = 1.5 / 2.0 = 0.75  (економія 25%)
```

Трифазна система передачі електроенергії дозволяє **заощадити 25% маси дорогоцінного провідникового металу** порівняно з однофазною лінією при збереженні того самого рівня втрат електроенергії. У масштабах світових енергетичних систем це означає економію мільйонів тонн алюмінію та міді щорічно.

#### Комутаційні перенапруги та перехідна відновлювана напруга (TRV)

При відключенні потужних трифазних навантажень (двигунів, трансформаторів) високовольтними вимикачами (вакуумними чи елегазовими SF6) у колах виникають високочастотні транзиєнтні комутаційні перенапруги. Перехідна відновлювана напруга (Transient Recovery Voltage, TRV) між контактами вимикача може перевищувати номінальну напругу мережі у `2...3` рази за лічені мікросекунди, зумовлюючи повторний пробій дугового проміжку. Для захисту ізоляції обмоток обладнання паралельно контактам або фазним виводам встановлюють обмежувачі перенапруг нелінійні (ОПН / MOV) на основі оксиду цинку.

### 9. Практичний інженерний розрахунок промислового об'єкта

Для ілюстрації практичного застосування наведених формул розрахуємо параметри живлення промислового цеху з активною потужністю навантаження `P = 100 кВт` при `cos(φ) = 0.8` (індуктивне навантаження) та лінійній напрузі `VL = 400 В`.

1. **Обчислення повної потужності:**
   ```
   S = P / cos(φ) = 100 кВт / 0.8 = 125 кВА
   ```
2. **Обчислення реактивної потужності:**
   `sin(φ) = √(1 − 0.8²) = 0.6`.
   ```
   Q = S · sin(φ) = 125 кВА · 0.6 = 75 квар
   ```
3. **Обчислення розрахункового лінійного струму:**
   ```
   IL = S / (√3 · VL) = 125000 В·А / (1.732 · 400 В) = 125000 / 692.8 ≈ 180.4 А
   ```
4. **Вибір перерізу кабелю та захисного автомата:**
   За таблицями ПУЕ для струму `180 А` вибирають чотирижильний мідний кабель перерізом `70 мм²` та автоматичний вимикач з номінальним струмом `200 А`.
5. **Розрахунок батареї компенсації реактивної потужності (УКРМ):**
   Для підвищення `cos(φ)` від `0.8` до `0.95` (`tg(φ1) = 0.75`, `tg(φ2) = 0.329`):
   ```
   Q_c = P · [ tg(φ1) − tg(φ2) ] = 100 кВт · (0.75 − 0.329) = 42.1 квар
   ```
   Встановлення конденсаторної батареї потужністю `45 квар` зменшує струм лінії з `180.4 А` до `151.9 А`, що знижує втрати на нагрів кабелю на `29%`.

### 10. Сучасний стан та перспективи трифазних систем

Трифазний змінний струм залишається фундаментальним стандартом виробництва та транспортування електроенергії на атомних, гідро- та теплових електростанціях. Сучасний розвиток енергетики привів до симбіозу трифазних мереж змінних струмів із високовольтними лініями постійного струму (HVDC / High Voltage Direct Current), які використовуються для міждержавних ліній передачі понад 1000 км та підводних силових кабелів.

Трифазні інвертори на основі силових IGBT та SiC транзисторів є серцем сучасних електромобілів (Tesla, Porsche Taycan), сонячних електростанцій та промислових частотних приводів. Інвертор перетворює постійну напругу акумуляторної батареї у трифазну синусоїдальну напругу регульованої частоти від 0 до 500 Гц, забезпечуючи плавну зміну обертів та рекуперативне гальмування з поверненням енергії у батарею. Впровадження широконозонових напівпровідників на основі нітриду галію (GaN) та карбіду кремнію (SiC) дозволяє підняти частоту комутації силових трифазних інверторів до `100...200 кГц`, що суттєво зменшує масогабаритні параметри згладжувальних дроселів та підвищує ККД перетворення електроенергії до `99%`.

Розвиток інтелектуальних мереж Smart Grid із цифровими лічильниками електроенергії та автоматичним перерозподілом навантаження по фазах гарантує високу надійність та якість електропостачання споживачів у XXI столітті.

### Підсумок

Трифазна система є основою сучасної електроенергетики. Поєднання постійності миттєвої потужності `ptotal(t) = const`, високої економічності передачі електроенергії та здатності створювати кругове обертове магнітне поле у простих і надійних асинхронних двигунах робить її незамінною технологічною платформою цивілізації.
