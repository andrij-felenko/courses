# 🧮 Математичний вивід рівняння квантування Дірака та розшарування Хопфа

Ця вставка містить строгий та детальний математичний вивід умови квантування електричного та магнітного зарядів, сформульованої Полем Діраком у 1931 році, а також її сучасне формулювання мовою топології диференціальних багатовидів. Вивід базується на математичному апараті векторного потенціалу, геометрії перекривних покриттів (патчів) у сферичних координатах, теорії головних `U(1)`-розшарувань, розшарування Хопфа та обчисленні першого класу Черна.

## 1. Поле точкового монополя та точна топологічна перешкода

Розглянемо нерухомий точковий магнітний монополь із магнітним зарядом `g`, розташований у початку координат 3D-простору `r = 0`. У сферичних координатах `(r, θ, ϕ)` створене ним магнітне поле індукції `B` є чисто радіальним, кулонівським та центрально-симетричним.

Вектор індукції магнітного поля у кожній точці простору записується у вигляді:

```
B(r) = (g / (4 · π · r²)) · r̂
```

де `r̂ = r / r` — одиничний вектор радіального напрямку, а `r = |r|` — відстань від початку координат до точки спостереження.

Обчислимо повний магнітний потік `Φ_B` крізь замкнену двовимірну сферу `S²` радіуса `R`, орієнтовану зовнішньою нормаллю, що охоплює початку координат:

```
Φ_B = ∬ [S²] B · dS
    = ∬ [S²] (g / (4 · π · R²)) · R² · sin θ · dθ · dϕ
    = (g / (4 · π)) · ∫₀^(2π) dϕ · ∫₀^π sin θ · dθ
    = (g / (4 · π)) · (2 · π) · 2
    = g
```

З іншого боку, згідно з класичною електродинамікою Максвелла, векторний потенціал `A` визначається так, що магнітна індукція є його ротором: `B = ∇ × A`. Якщо припустити, що векторний потенціал `A` визначений як гладке, гладко диференційовне та неперервне векторне поле на всій поверхні замкненої сфери `S²`, то за теоремою Стокса магнітний потік крізь цю поверхню без межі (`∂S² = ∅`) обов'язково дорівнює нулю:

```
Φ_B = ∬ [S²] (∇ × A) · dS = ∮ [∂S²] A · dr = 0
```

Виникає фундаментальна математична суперечність між значеннями `Φ_B = g` та `Φ_B = 0`. Звідси випливає строга теорема: єдиний глобальний, гладкий та неперервний векторний потенціал `A`, який задовольняє рівність `B = ∇ × A` на всій поверхні сфери `S²` навколо монополя, математично не існує. Відсутність глобального потенціалу є топологічною перешкодою, пов'язаною з нетривіальністю топології сфери з виколотою точкою.

## 2. Геометрія перекривних патчів (Північного та Південного)

Щоб обійти цю перешкоду і сформулювати коректний опис векторного потенціалу, застосуємо стандартний метод диференціальної геометрії — покриття сфери `S²` двома відкритими перекривними картами (патчами):
- **Північний патч** `U_N`: відкрита область сфери, що охоплює північний полюс і простягається нижче екватора (`0 ≤ θ < π − δ`), виключаючи південний полюс;
- **Південний патч** `U_S`: відкрита область сфери, що охоплює південний полюс і простягається вище екватора (`δ < θ ≤ π`), виключаючи північний полюс.

Параметр `δ > 0` забезпечує скінченну ширину екваторіальної зони перекриття `U_N ∩ U_S`.

У сферичних координатах `(r, θ, ϕ)` внаслідок азимутальної симетрії векторний потенціал має лише компонент `A_ϕ`. Запишемо вираз для ротора у сферичних координатах:

```
(∇ × A)_r = (1 / (r · sin θ)) · [ ∂(sin θ · A_ϕ) / ∂θ − ∂A_θ / ∂ϕ ]
```

Оскільки `A_θ = 0`, вимога `(∇ × A)_r = B_r = g / (4 · π · r²)` зводиться до диференціального рівняння:

```
∂(sin θ · A_ϕ) / ∂θ = (g / (4 · π · r)) · sin θ
```

Інтегруючи це рівняння по куту `θ`, отримуємо загальний розв'язок із довільною константою інтегрування `C`:

```
A_ϕ(θ) = (g / (4 · π · r · sin θ)) · (C − cos θ)
```

Для Північного патча `U_N` виберемо константу `C = 1`, щоб усунути сингулярність на північному полюсі `θ = 0`:

```
A_N = (g / (4 · π · r · sin θ)) · (1 − cos θ) · ϕ̂
```

Користуючись тригонометричною тотожністю `(1 − cos θ) / sin θ = tan(θ / 2)`, потенціал `A_N` можна переписати у вигляді:

```
A_N = (g / (4 · π · r)) · tan(θ / 2) · ϕ̂
```

При `θ → 0` маємо `tan(0) = 0`, тому векторний потенціал `A_N` є строго регулярним на північному полюсі. Проте при наближенні до південного полюса `θ → π` величина `tan(θ / 2) → ∞`, виникає променева сингулярність. Ця піввісь сингулярності вздовж від'ємної осі `z` і називається **струною Дірака**.

Для Південного патча `U_S` виберемо константу `C = −1`, щоб усунути сингулярність на південному полюсі `θ = π`:

```
A_S = − (g / (4 · π · r · sin θ)) · (1 + cos θ) · ϕ̂
    = − (g / (4 · π · r)) · cot(θ / 2) · ϕ̂
```

Потенціал `A_S` є гладким та регулярним на південному полюсі (`cot(π / 2) = 0`), але має струну сингулярності, спрямовану вгору до північного полюса `θ = 0`.Таким чином, на кожному з патчів існує свій власний регулярний потенціал, а сингулярність висунута за межі карти.

## 3. Калібрувальне перетворення у зоні перекриття екватора

У зоні перекриття патчів `U_N ∩ U_S` (на екваторі `θ ≈ π / 2`) обидва потенціали `A_N` та `A_S` дають абсолютно однакове фізичне магнітне поле `B`. Відповідно до принципів калібрувальної інваріантності, два векторні потенціали, що описують одне й те саме фізичне поле, повинні відрізнятися лише на градієнт скалярної калібрувальної функції `Λ`:

```
A_N − A_S = ∇ Λ
```

Обчислимо явну різницю між векторами `A_N` та `A_S` у зоні перекриття:

```
A_N − A_S = (g / (4 · π · r · sin θ)) · [ (1 − cos θ) + (1 + cos θ) ] · ϕ̂
          = (g / (2 · π · r · sin θ)) · ϕ̂
```

Оскільки градієнт скалярної функції у сферичних координатах має вигляд `∇ Λ = (1 / (r · sin θ)) · (∂Λ / ∂ϕ) · ϕ̂`, ми отримуємо диференціальне рівняння для калібрувальної функції `Λ`:

```
∂Λ / ∂ϕ = g / (2 · π)
```

Інтегруючи це рівняння вздовж азимутального кута `ϕ`, знаходимо явний вираз для функціональної залежності калібрувальної функції:

```
Λ(ϕ) = (g / (2 · π)) · ϕ
```

Зверніть увагу: функція `Λ(ϕ)` не є однозначною функцією на сфері, оскільки при повному обході навколо екватора від `ϕ = 0` до `ϕ = 2 · π` її значення збільшується на сталу величину `Δ Λ = g`.

## 4. Умова однозначності хвильової функції та квантування Дірака

Розглянемо тепер квантово-механічний опис частинки з електричним зарядом `q` та масою `m`, яка рухається в електромагнітному полі монополя. Хвильова функція цієї частинки у Північному патчі позначається як `Ψ_N`, а у Південному патчі — як `Ψ_S`.

У квантовій механіці зміна калібрування векторного потенціалу `A_S → A_N = A_S + ∇ Λ` супроводжується фазовим перетворенням хвильової функції частинки за допомогою локального унітарного елемента групи `U(1)`:

```
Ψ_N(r, θ, ϕ) = exp(i · q · Λ(ϕ) / ℏ) · Ψ_S(r, θ, ϕ)
             = exp(i · q · g · ϕ / (2 · π · ℏ)) · Ψ_S(r, θ, ϕ)
```

Фізична хвильова функція `Ψ_N` описує реальний стан частинки у просторі, а отже, вона обов'язково мусить бути однозначною функцією просторових координат `(r, θ, ϕ)`. При здійсненні одного повного обходу навколо екватора вздовж замкненого контуру (зміна кута від `ϕ = 0` до `ϕ = 2 · π`) значення хвильової функції має повертатися до вичаткового значення:

```
Ψ_N(r, θ, 2 · π) = Ψ_N(r, θ, 0)
```

Підставляючи унітарне фазове співвідношення, знаходимо:

```
exp(i · q · g · (2 · π) / (2 · π · ℏ)) · Ψ_S(r, θ, 2 · π) = exp(0) · Ψ_S(r, θ, 0)
```

Оскільки хвильова функція `Ψ_S` у Південному патчі також є однозначною (`Ψ_S(2 · π) = Ψ_S(0)`), ми отримуємо строгу квантову вимогу до фазового множника:

```
exp(i · q · g / ℏ) = 1
```

Комплексна експонента дорівнює одиниці тоді і тільки тоді, коли її уявний показник є цілим кратним числа `2 · π · i`:

```
q · g / ℏ = 2 · π · n     [де n ∈ ℤ = {0, ±1, ±2, ...}]
```

Переносячи константи, отримуємо знамените співвідношення **квантування Дірака**:

```
q · g = 2 · π · ℏ · n
```

Фізичний зміст цього результату глибокий: якщо у Всесвіті існує хоча б один магнітний монополь із зарядом `g`, то електричний заряд `q` абсолютно будь-якої частинки у Всесвіті обов'язково дискретизується і може приймати лише значення, кратні мінімальному заряду:

```
q_min = 2 · π · ℏ / g
```

Навпаки, якщо найменший у природі електричний заряд дорівнює заряду електрона `e`, то фундаментальний квант магнітного заряду (магнітний монополь Дірака) має величину:

```
g_min = 2 · π · ℏ / e = h / e
```

У міжнародній системі одиниць СІ це значення виражається через квант магнітного потоку `Φ₀ = h / (2 · e)`:

```
g_min = h / e = 2 · Φ₀ ≈ 4.1357 × 10⁻¹⁵ Wb  (або V·s)
```

## 5. Топологічна інтерпретація: расшарування Хопфа та перше число Черна

Сучасна математична фізика дає глибоку топологічну інтерпретацію виводу Дірака через теорію головних расшарувань та кобордизмів.

У цій формі електромагнітний векторний потенціал розглядається як диференціальна 1-форма зв'язності `A` у головному `U(1)`-расшаруванні над базовим двовимірним многовидом — сферою `S²`. Напруженість електромагнітного поля є 2-формою кривини `F = d A`.

Перехідна функція між картою `U_N` та картою `U_S` на екваторіальному колі `S¹` визначається елементом групи `U(1)`:

```
g_NS(ϕ) = exp(i · q · Λ(ϕ) / ℏ) = exp(i · n · ϕ)
```

Ця перехідна функція задає гладке відображення екваторіального кола `S¹` у групу симетрії `U(1) ≅ S¹`. Оскільки перша гомотопічна група кола дорівнює цілим числам (`π₁(U(1)) ≅ ℤ`), кожне таке розшарування характеризується топологічним інваріантом — **степенем відображення (числом обмотки)** `n ∈ ℤ`.

Топологічний інваріант расшарування обчислюється як інтеграл від 2-форми напруженості поля `F` по базовій сфері `S²`, що відповідає **першому класу Черна** `c₁`:

```
c₁ = (1 / (2 · π)) · ∬ [S²] F
   = (q / (2 · π · ℏ)) · ∬ [S²] B · dS
   = (q / (2 · π · ℏ)) · g
   = n ∈ ℤ
```

Найпростіший випадок нетривіального розшарування з `n = 1` відповідає знаменитому **розшаруванню Хопфа** `S³ → S²` з шаром `S¹`. 

Це доводить, що квантування магнітного заряду є не просто квантово-механічним ефектом, а фундаментальною топологічною властивістю простору-часу: магнітний заряд є строго квантованим топологічним числом Черна, яке є стійким відносно будь-яких неперервних деформацій поля.
