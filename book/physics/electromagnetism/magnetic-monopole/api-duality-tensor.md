# 📋 Довідник-інтерфейс: 4D-коваріантний дуальний тензор та диференціальні форми

Цей довідковий інтерфейс містить вичерпну та строгу специфікацію математичної структури чотиривимірної коваріантної дуально-симетричної електродинаміки за наявності магнітних зарядів та струмів. Розділ призначений для використання як систематичний довідник при теоретичному аналізі калібрувальних полів, диференційно-геометричних об'єктів, лоренц-інваріантів, перетворень дуальності та систем вимірювальних одиниць.

## 1. Тензор електромагнітного поля та його 4D-структура

У чотиривимірному псевдоевклідовому просторі-часі Мінковського з сигнатурою метричного тензора `η_μν = diag(+1, −1, −1, −1)` (де 4-індекси `μ, ν ∈ {0, 1, 2, 3}`, причому `0` відповідає часовій координаті `x⁰ = c · t`, а `1, 2, 3` — просторовим координатам `x¹, x², x³`) електромагнітне поле описується коваріантним антисиметричним тензором другого рангу `F_μν = ∂_μ A_ν − ∂_ν A_μ = − F_νμ`.

Діагональні компоненти тензора поля `F_μν` дорівнюють нулю через антисиметричність (`F₀₀ = F₁₁ = F₂₂ = F₃₃ = 0`). Шесть незалежних позадіагональних компонент повністю визначаються трьома компонентами вектора напруженості електричного поля `E = (E_x, E_y, E_z)` та трьома компонентами вектора індукції магнітного поля `B = (B_x, B_y, B_z)`.

Коваріантна матрична форма тензора `F_μν` виглядає так:

```
          ┌                                      ┐
          │    0       E_x / c   E_y / c   E_z / c │
          │ −E_x / c      0       −B_z       B_y  │
F_μν =    │ −E_y / c     B_z        0       −B_x  │
          │ −E_z / c    −B_y       B_x        0   │
          └                                      ┘
```

Контраваріантний тензор поля `F^μν` отримується підйомом обох індексів за допомогою інверсного метричного тензора Мінковського `F^μν = η^μα · η^νβ · F_αβ`. Оскільки підйом одного часового індексу змінює знак часових компонент `F⁰ⁱ`, контраваріантна матриця має вигляд:

```
          ┌                                      ┐
          │    0      −E_x / c  −E_y / c  −E_z / c │
          │  E_x / c      0       −B_z       B_y  │
F^μν =    │  E_y / c     B_z        0       −B_x  │
          │  E_z / c    −B_y       B_x        0   │
          └                                      ┘
```

Для аналізу симетрій електродинаміки вводиться **дуальний тензор поля** `F̃^μν` (у математичній фізиці часто позначається через зірку Ходжа `*F^μν`). Він згортається з вичатковим тензором через абсолютно антисиметричний символ Леві-Чивіта `ε^μναβ` у 4D (де за угодою прийнято `ε⁰¹²³ = +1`):

```
F̃^μν = (1 / 2) · ε^μναβ · F_αβ
```

Фізична операція дуального перетворення полягає у заміні компонент полів за правилом `E / c → B` та `B → −E / c`. Контраваріантний дуальний тензор `F̃^μν` записується у вигляді матриці:

```
          ┌                                      ┐
          │    0        −B_x      −B_y      −B_z  │
          │   B_x        0       E_z / c  −E_y / c│
F̃^μν =    │   B_y     −E_z / c      0      E_x / c│
          │   B_z      E_y / c  −E_x / c      0   │
          └                                      ┘
```

Повторне застосування дуального перетворення до тензора повертає вичатковий тензор із протилежним знаком (`F̃̃^μν = − F^μν`), що відображає псевдокомплексну структуру дуальних обертів полів на кут `π / 2`.

## 2. Коваріантні 4D-рівняння Максвелла з електричним та магнітним струмами

Гіпотеза про існування магнітного монополя відновлює повну математичну симетрію між електричним та магнітним секторами електродинаміки. Для цього у релятивістському формалізмі вводяться два незалежні чотиривектори густини струму:
- **Електричний 4-струм**: `J_e^μ = (c · ρ_e, J_e)`, де `ρ_e` — скалярна об'ємна густина електричного заряду, а `J_e = (J_ex, J_ey, J_ez)` — тривимірний вектор густини електричного струму;
- **Магнітний 4-струм**: `J_m^μ = (c · ρ_m, J_m)`, де `ρ_m` — псевдоскалярна об'ємна густина магнітного заряду, а `J_m = (J_mx, J_my, J_mz)` — тривимірний аксіальний вектор густини магнітного струму.

Система 4D-коваріантних рівнянь Максвелла за наявності обох джерел складається з двох чотиривимірних тензорних рівнянь першого порядку:

```
∂_μ F^μν = μ₀ · J_e^ν               [перша пара: електричні джерела]
∂_μ F̃^μν = (μ₀ / c) · J_m^ν         [друга пара: магнітні джерела]
```

При розгортанні за компонентами `ν = 0, 1, 2, 3` перша система дає часову частину (закон Гаусса для електричного поля `∇ · E = ρ_e / ε₀`) та просторову частину (розширений закон Ампера — Максвелла `∇ × B = μ₀ · J_e + (1 / c²) · ∂E / ∂t`).

Друга система при розгортанні за компонентами `ν = 0, 1, 2, 3` дає часову частину (закон Гаусса для магнітного поля `∇ · B = μ₀ · ρ_m`) та просторову частину (розширений закон індукції Фарадея з магнітним струмом `∇ × E = − μ₀ · J_m − ∂B / ∂t`).

Зі властивості антисиметрії тензорів `F^μν` та `F̃^μν` напряму випливають диференціальні тотожності `∂_ν (∂_μ F^μν) ≡ 0` та `∂_ν (∂_μ F̃^μν) ≡ 0`. Звідси автоматично випливають 4D-рівняння неперервності для обох типів зарядів:

```
∂_ν J_e^ν = 0  ⇒  ∂ρ_e / ∂t + ∇ · J_e = 0     [збереження електричного заряду]
∂_ν J_m^ν = 0  ⇒  ∂ρ_m / ∂t + ∇ · J_m = 0     [збереження магнітного заряду]
```

Це доводить, що за наявності магнітних монополів магнітний заряд є строго збережувальною величиною, а магнітний струм задовольняє власний точний закон збереження.

## 3. Формулювання у термінах диференціальних форм та операторів зовнішнього калібрування

У сучасній диференціальній геометрії електромагнітні поля та струми описуються мовою зовнішніх диференціальних форм на чотиривимірному орієнтованому гладкому багатовиді простору-часу `M⁴`.

Визначимо основні геометричні об'єкти:
- `A` — 1-форма потенціалу електромагнітного поля;
- `F = d A` — 2-форма напруженості поля;
- `*F` — дуальна 2-форма (зірка Ходжа від `F`);
- `j_e` — 3-форма густини електричного струму;
- `j_m` — 3-форма густини магнітного струму.

Система розширених рівнянь Максвелла мовою зовнішнього диференціала `d` та оператора зірки Ходжа `*` приймає надзвичайно витончену форму:

```
d F = * j_m                         [магнітні джерела]
d (*F) = j_e                        [електричні джерела]
```

Оскільки зовнішній диференціал нільпотентний (`d² = d ∘ d ≡ 0`), накреслення оператора `d` до обох частин рівнянь гарантує збереження струмів:

```
d (d F) = 0   ⇒   d (* j_m) = 0     [збереження 3-форми магнітного струму]
d (d *F) = 0  ⇒   d j_e = 0        [збереження 3-форми електричного струму]
```

Якщо магнітні заряди відсутні (`j_m = 0`), 2-форма `F` є замкненою (`d F = 0`). За лемою Пуанкаре це дозволяє виразити її через єдину 1-форму потенціалу `F = d A` на всьому багатовиді. При наявності монополів `d F ≠ 0`, тому 2-форма `F` не є замкненою, що робить неможливим існування єдиного гладкого потенціалу `A` на всьому просторі без урахування геометрії покриттів.

## 4. Калібрувальні інваріанти, лоренц-інваріанти та неперервні дуальні оберти

З тензора поля `F_μν` та його дуального тензора `F̃_μν` можна побудувати два фундаментальні скаляри відносно власних перетворень групи Лоренца:

```
I₁ = (1 / 2) · F_μν · F^μν = B² − (E² / c²)
I₂ = (1 / 4) · F_μν · F̃^μν = (1 / c) · (E · B)
```

При неперервних перетвореннях дуальної симетрії поля обертаються на довільний фазовий кут `α ∈ [0, 2π)`:

```
E' = E · cos α + c · B · sin α
c · B' = − E · sin α + c · B · cos α
```

При таких дуальних обертах лоренцівські скаляри `I₁` та `I₂` перетворюються як компоненти двовимірного вектора при поворотах плоскості:

```
I₁' = I₁ · cos(2 · α) + 2 · I₂ · sin(2 · α)
I₂' = − (1 / 2) · I₁ · sin(2 · α) + I₂ · cos(2 · α)
```

Квадратична сума двох інваріантів є абсолютною незмінною величиною відносно будь-яких лоренцівських бустів та дуальних поворотах полів:

```
(I₁)² + 4 · (I₂)² = (B² + E² / c²)² − (4 / c²) · |E × B|² = const
```

Це доводить, що електромагнітна інваріантність є розширеною симетрією, яка поєднує релятивістські перетворення простору-часу та дуальні перетворення полів.

## 7. Рівняння руху частинки з електричним та магнітним зарядами у 4D-формі

Рівняння руху частинки масою `m`, яка одночасно володіє електричним зарядом `q` та магнітним зарядом `g_p`, у зовнішньому електромагнітному полі `F_μν` у релятивістській 4D-формі записується так:

```
m · (d u^μ / dτ) = q · F^μν · u_ν + (g_p / c) · F̃^μν · u_ν
```

де `u^μ = (γ c, γ v)` — чотиришвидкість частинки, `τ` — її власний час, а `γ = 1 / √(1 − v² / c²)` — релятивістський лоренц-фактор.

Перший доданок у правій частині відповідає класичній силі Лоренца для електричного заряду, а другий доданок описує дуальну магнітну силу Лоренца, що діє на магнітний заряд `g_p`. Цей вираз завершує повну симетричну формулювання дуальної релятивістської електродинаміки частинок та полів.
