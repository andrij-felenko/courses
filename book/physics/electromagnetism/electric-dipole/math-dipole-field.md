# 🧮 Математичний вивід потенціалу, напруженості та сингулярного поля диполя

Ця вставка містить строгий математичний вивід електростатичного потенціалу, векторного поля напруженості та дельта-функціонального контактного члена електричного диполя. Матеріал розгортає причинно-наслідковий ланцюг від перших принципів (закону Кулона та мультипольного розкладу) до диференціальних операторів у сферичних та декартових координатах.

Вивід призначений для глибокого розуміння того, чому дипольне поле спадає саме пропорційно `1 / r³`, звідки виникає коефіцієнт `2` у радіальній компоненті та як розраховують сингулярне поле в самому центрі диполя, що застосовується у квантовій фізиці, атомній спектроскопії та теорії надтонкого розщеплення.

## 1. Мультипольний розклад потенціалу

Розглянемо неперервний розподіл заряду з об'ємною густиною `ρ(r')`, зосереджений у скінченній області простору `V'`. За принципом суперпозиції точний електростатичний потенціал `Φ(r)` у точці спостереження `r` дорівнює:

```
Φ(r) = (1 / (4·π·ε₀)) · ∫ [ ρ(r') / |r − r'| ] · dV'      [точний інтеграл потенціалу]
```

Припустимо, що точка спостереження `r` знаходиться далеко від системи зарядів (`r » r'`). Розкладемо функцію обратного модуля відстані `1 / |r − r'|` у ряд Тейлора за відносним зміщенням `r' / r`. 

Для цього виразимо модуль через скалярний добуток:

```
|r − r'| = √( (r − r') · (r − r') ) = √( r² − 2·r·r' + r'² ) = r · √( 1 − 2·(r·r')/r² + (r'/r)² )
```

Використовуючи формулу бінома Ньютона `(1 + x)⁻¹/² = 1 − (1/2)·x + (3/8)·x² − ...` для малого параметра `x = −2·(r·r')/r² + (r'/r)²`, маємо:

```
1 / |r − r'|
= (1 / r) · [ 1 − (1/2) · ( −2·(r·r')/r² + (r'/r)² ) + (3/8) · ( −2·(r·r')/r² )² + ... ]
= (1 / r) + (r · r') / r³ + ( 3·(r · r')² − r²·r'² ) / (2 · r⁵) + ...
```

Підставимо отриманий розклад у вихідний інтеграл потенціалу:

```
Φ(r)
= (1 / (4·π·ε₀)) · ∫ ρ(r') · [ (1 / r) + (r · r') / r³ + ... ] · dV'
= (1 / (4·π·ε₀)) · [ (1 / r) · ∫ ρ(r') dV' + (1 / r³) · r · ∫ r' ρ(r') dV' + ... ]
```

Означимо в інтегралах два перші мультипольні моменти системи:
1. **Повний заряд (монопольний момент)** `Q`:
   ```
   Q = ∫ ρ(r') · dV'
   ```
2. **Електричний дипольний момент** `p`:
   ```
   p = ∫ r' · ρ(r') · dV'
   ```

Отримуємо мультипольний розклад потенціалу:

```
Φ(r) = (1 / (4·π·ε₀)) · [ Q / r + (p · r) / r³ + ... ]     [мультипольний розклад]
```

Якщо система є нейтральною у цілому (`Q = 0`), монопольний член зникає, і головним домінуючим членом потенціалу на великих відстанях стає дипольний потенціал `Φ_dip(r)`:

```
Φ_dip(r) = (1 / (4·π·ε₀)) · (p · r) / r³ = (1 / (4·π·ε₀)) · (p · cos θ) / r²
```

Де `θ` — кут між вектором дипольного моменту `p` та радіус-вектором `r`.

Аналіз мультипольного розкладу дає фундаментальний фізичний висновок: на великих відстанях поле будь-якої нейтральної системи зарядів описується саме дипольним потенціалом. Вищі члени розкладу (квадрупольний, октупольний) спадають значно швидше (`1 / r³` та `1 / r⁴`) і дають лише малі поправки на відстанях, близьких до геометричних розмірів системи.

## 2. Градієнт потенціалу та вивід вектора поля у сферичних координатах

Напруженість електричного поля `E` пов'язана з електростатичним потенціалом `Φ` диференціальним співвідношенням `E = −∇Φ`.

Обчислимо компоненти поля у сферичній системі координат `(r, θ, φ)`, у якій вектор дипольного моменту `p` спрямований уздовж полярної осі `z` (`p = (0, 0, p)`). Оператор градієнта у сферичних координатах має вигляд:

```
∇ = r̂ · (∂ / ∂r) + θ̂ · (1 / r) · (∂ / ∂θ) + φ̂ · (1 / (r · sin θ)) · (∂ / ∂φ)
```

Застосуємо оператор градієнта до дипольного потенціалу `Φ(r, θ) = (1 / (4·π·ε₀)) · (p · cos θ / r²)`:

### Крок 2.1. Радіальна компонента `E_r`
Радіальна компонента напруженості відповідає швидкості зміни потенціалу при зміні відстані `r`:

```
E_r
= −∂Φ / ∂r
= −(p · cos θ / (4·π·ε₀)) · (∂ / ∂r) [ r⁻² ]
= −(p · cos θ / (4·π·ε₀)) · ( −2 · r⁻³ )
= (1 / (4·π·ε₀)) · (2 · p · cos θ / r³)               [радіальна компонента]
```

Звернемо увагу на множник `2` у чисельнику: він виникає саме через те, що дипольний потенціал спадає пропорційно `1 / r²`, і взяття похідної по `r` дає степенний коефіцієнт `−2`.

### Крок 2.2. Тангенціальна компонента `E_θ`
Тангенціальна компонента відповідає швидкості зміни потенціалу при відхиленні за полярним кутом `θ`:

```
E_θ
= −(1 / r) · ∂Φ / ∂θ
= −(p / (4·π·ε₀ · r³)) · (∂ / ∂θ) [ cos θ ]
= −(p / (4·π·ε₀ · r³)) · ( −sin θ )
= (1 / (4·π·ε₀)) · (p · sin θ / r³)                   [тангенціальна компонента]
```

Тангенціальна компонента досягає максимуму на екваторі (`θ = 90°`), де радіальна компонента дорівнює нулю, і спрямована протилежно напрямку дипольного моменту.

### Крок 2.3. Азимутальна компонента `E_φ`
Оскільки потенціал `Φ` не залежить від азимутального кута `φ` (всі точки на паралелі симетричні відносно осі `z`), часткова похідна дорівнює нулю:

```
E_φ = −(1 / (r · sin θ)) · ∂Φ / ∂φ = 0                [азимутальна компонента]
```

### Крок 2.4. Модуль векторного поля
Обчислимо модуль повного вектора напруженості:

```
|E(r, θ)|
= √( E_r² + E_θ² )
= (1 / (4·π·ε₀ · r³)) · √( (2 · p · cos θ)² + (p · sin θ)² )
= (p / (4·π·ε₀ · r³)) · √( 4·cos²θ + sin²θ )
= (p / (4·π·ε₀ · r³)) · √( 3·cos²θ + (cos²θ + sin²θ) )
= (p / (4·π·ε₀ · r³)) · √( 3·cos²θ + 1 )               [модуль напруженості]
```

Отримана формула показує, що напруженість досягає максимуму на полюсах (`θ = 0°` та `θ = 180°`), де `√(3 + 1) = 2`, і має мінімум на екваторі (`θ = 90°`), де `√(0 + 1) = 1`.

## 3. Інваріантне векторне виведення в декартових координатах

Доведемо безкоординатну векторну формулу для напруженості поля диполя `E(r) = (1 / (4·π·ε₀)) · (3·(p·r̂)·r̂ − p) / r³` за допомогою операцій векторного аналізу в декартових координатах.

Потенціал диполя запишемо у виді `Φ(r) = (1 / (4·π·ε₀)) · (p · r) · r⁻³`. Застосуємо оператор градієнта `∇` до добутку двох скалярно-векторних функцій `f = p · r` та `g = r⁻³`:

```
E(r)
= −∇Φ(r)
= −(1 / (4·π·ε₀)) · ∇ [ (p · r) · r⁻³ ]
= −(1 / (4·π·ε₀)) · [ r⁻³ · ∇(p · r) + (p · r) · ∇(r⁻³) ]     [правило Лейбніца для градієнта]
```

Обчислимо градієнти окремих множників:
1. **Градієнт скалярного добутку** `∇(p · r)` для постійного вектора `p`:
   ```
   ∇(p · r) = ∇(p_x · x + p_y · y + p_z · z) = (p_x, p_y, p_z) = p
   ```
2. **Градієнт степені радіуса** `∇(r⁻³)`:
   ```
   ∇(r⁻³) = (d / dr)[r⁻³] · ∇r = −3 · r⁻⁴ · r̂ = −3 · r / r⁵
   ```

Підставимо знайдені градієнти у вираз для поля:

```
E(r)
= −(1 / (4·π·ε₀)) · [ r⁻³ · p + (p · r) · (−3 · r / r⁵) ]
= −(1 / (4·π·ε₀)) · [ p / r³ − 3 · (p · r) · r / r⁵ ]
= (1 / (4·π·ε₀)) · [ 3 · (p · r) · r / r⁵ − p / r³ ]
= (1 / (4·π·ε₀)) · (3 · (p · r̂) · r̂ − p) / r³        [інваріантна векторна формула]
```

Отримана формула повністю збігається з результатом у сферичних координатах і діє для довільного напрямку векторів `p` та `r` у зовнішності диполя (`r > 0`).

## 4. Вивід сингулярного дельта-функціонального члена в центрі диполя

Вираз для поля `E(r)`, отриманий вище, має особливість (сингулярність) у точці `r = 0`. Якщо обчислити середнє значення поля усередині нескінченно малої кулі радіуса `R`, що містить точковий диполь у своєму центрі, регулярний вираз `(3(p·r̂)r̂ − p) / r³` внаслідок симетрії при інтегруванні за кутами дає нуль. Проте реальне фізичне поле двох близьких зарядів усередині диполя спрямоване від `+q` до `−q`, тобто строго протилежно до вектора дипольного моменту `p`.

Знайдемо середнє поле `⟨E⟩` усередині кулі `V_R` радіуса `R`, створене довільним розподілом зарядів `ρ(r)` усередині цієї кулі:

```
⟨E⟩ = (1 / V_R) · ∫_(V_R) E(r) · dV
```

Виразимо напруженість поля через потенціал `E = −∇Φ`:

```
∫_(V_R) E(r) · dV = −∫_(V_R) ∇Φ · dV
```

За теоремою Остроградського-Гаусса для градієнта скалярного поля, об'ємний інтеграл перетворюється на поверхневий інтеграл по сфері `S_R` радіуса `R` з зовнішньою нормаллю `n̂ = r̂`:

```
∫_(V_R) E(r) · dV = −∫_(S_R) Φ(r) · n̂ · dS
```

Підставимо в поверхневий інтеграл потенціал точкового диполя `Φ = (1 / (4·π·ε₀)) · (p · r̂) / R²` та елемент поверхні сфери `dS = R² · dΩ`:

```
∫_(V_R) E(r) · dV
= −∫_(S_R) [ (1 / (4·π·ε₀)) · (p · r̂) / R² ] · r̂ · (R² · dΩ)
= −(1 / (4·π·ε₀)) · ∫_(S_R) (p · r̂) · r̂ · dΩ
```

Обчислимо кутовий інтеграл від тензора `r̂_i · r̂_j` по повній сфері (де `∫ dΩ = 4π`):

```
∫ (p · r̂) · r̂ · dΩ = (4·π / 3) · p
```

Підставляючи кутовий інтеграл, отримуємо результат для об'ємного інтеграла поля по кулі:

```
∫_(V_R) E(r) · dV = −(1 / (4·π·ε₀)) · (4·π / 3) · p = −p / (3 · ε₀)   [інтеграл поля по кулі]
```

Зверніть увагу: результат інтеграла **не залежить від радіуса кулі `R`**! Навіть у границі, коли радіус кулі прямує до нуля (`R → 0`), інтеграл залишається строго постійним і дорівнює `−p / (3·ε₀)`.

Єдиною математичною функцією, об'ємний інтеграл від якої по як завгодно малому об'єму дає постійний вектор `−p / (3·ε₀)`, є тривимірна дельта-функція Дірака `δ³(r)`.

Таким чином, повне математичне рівняння для напруженості електричного поля точкового диполя, дійсне у всіх точках простору (включаючи `r = 0`), записують як:

```
E(r)
= E_regular(r) + E_delta(r)
= (1 / (4·π·ε₀)) · (3 · (p · r̂) · r̂ − p) / r³ − (p / (3 · ε₀)) · δ³(r)   [повне поле диполя]
```

Отриманий дельта-член `−(p / (3·ε₀)) · δ³(r)` є математично строгим результатом, який забезпечує виконання рівнянь Максвелла `∇ · E = ρ / ε₀` для точкового диполя на всьому просторі `ℝ³`.

## 5. Енергетичний аналіз та дипольні сили

Розглянемо вивід сили, що діє на диполь у неоднорідному полі `E(r)`. Робота `dW`, що виконується при малому переміщенні диполя `dr`, дорівнює зміні потенціальної енергії зі знаком мінус `dW = −dU`.

Потенціальна енергія диполя дорівнює `U = −p · E`. Обчислимо повний диференціал енергії при переміщенні та повороті диполя:

```
dU = −d(p · E) = −dp · E − p · dE
```

Якщо вектор дипольного моменту `p` є жорстким (модуль і напрямок не змінюються у власні системі координат диполя, `dp = 0`), зміна енергії зумовлена лише зміною поля у просторі:

```
dU = −p · dE = −p · (dr · ∇)E = −( (p · ∇)E ) · dr
```

Порівнюючи з формулою сили `dW = F · dr = −dU`, отримуємо поступальну силу:

```
F = (p · ∇) E                                          [поступальна сила]
```

Цей вивід показує математичний зв'язок між просторовим варіюванням зовнішнього поля та появою результуючої сили, яка втягує зорієнтований диполь у сильніше поле.
