# 🔌 Будова та робота комірки сегнетоелектричної пам'яті FeRAM та FeFET

Сегнетоелектрична оперативна пам'ять (FeRAM або FRAM) та сегнетоелектричні польові транзистори (FeFET) використовують бістабільну спонтанну поляризацію як носій енергонезалежної інформації. На відміну від звичайної динамічної оперативної пам'яті (DRAM), де електричний заряд стікає з конденсатора за мілісекунди і вимагає постійного регенераційного перезапису, сегнетоелектричний конденсатор зберігає поляризований стан без зовнішнього живлення десятиліттями. Фізика та електротехніка комірок 1T-1C FeRAM, 1T FeFET, тунельних сегнетоелектричних переходів (FTJ) охоплюють розрахунок вікна зчитування, а також мікроскопічні механізми деградації — втому та вдруковування.

### 1. Будова та схемотехніка комірки 1T-1C FeRAM

Класична архітектура комірки FeRAM багато в чому подібна до комірки DRAM і складається з одного адресної МОН-транзистора та одного сегнетоелектричного конденсатора (**1T-1C**). Проте замість звичайного параелектричного діелектрика (`SiO2` або `Ta2O5`), між металевими електродами конденсатора вміщено сегнетоелектрик — тонкоплівковий цирконат-титанат свинцю (`PZT`) або допований оксид гафнію (`HfO2`).

```
        Битова лінія (Bit Line, BL)
                  |
                 ---
                 | |  Адресний МОН-транзистор (N-MOS)
                 ---
                  |   Затворна лінія слова (Word Line, WL)
                  +---[===]
                  |
                -----  Сегнетоелектричний конденсатор C_fe (PZT / HfO₂)
                -----
                  |
        Пластинна лінія (Plate Line, PL)
```

Два стійкі стани залишкової поляризації кодують бінарну інформацію в комірці:
- Стан **`+P_r`** (вектор спонтанної поляризації спрямовано від верху до пластинної лінії PL) — логічний **«0»**.
- Стан **`-P_r`** (вектор спонтанної поляризації спрямовано від пластинної лінії PL вгору) — логічна **«1»**.

---

### 2. Запис інформації (Write Dynamics)

Для запису логічної «1» або «0» адресний транзистор відкривається подачею високої напруги на лінію слова (`V_WL = V_DD + V_th`). Після цього керуюча схема створює між битовою лінією (BL) та пластинною лінією (PL) імпульс напруги, амплітуда якого перевищує коерцитивну напругу комірки `V_c = E_c · d_fe`:

1. **Запис логічної «1»**: `V_BL = V_DD`, `V_PL = 0`. Електричне поле спрямоване від верхнього електрода до нижнього, що перемикає домени сегнетоелектрика у стан `-P_r`.
2. **Запис логічного «0»**: `V_BL = 0`, `V_PL = V_DD`. Електричне поле спрямоване від нижнього електрода до верхнього, що повертає домени у стан `+P_r`.

Завдяки малій товщині сегнетоелектричної плівки (`d_fe ~ 5–10 нм` для `HfO2`) коерцитивна напруга становить всього `V_c ≈ 0.8–1.2 В`. Час формування та проростання голок нових доменів у тонких плівках не перевищує **1 наносекунди**, що робить швидкість запису у FeRAM порівнянною зі статичною пам'яттю SRAM.

---

### 3. Схемотехніка та розрахунок руйнівного зчитування

Зчитування інформації у комірці 1T-1C є **руйнівним** *(destructive read)*. Схема завжди подає на пластинну лінію PL позитивний імпульс напруги `V_DD`, намагаючись переключити поляризацію конденсатора у стан `+P_r` (стан «0»):

#### Фізичні етапи розряджання на паразиту ємність битової лінії (C_BL)

Перед початком зчитування битова лінія розряджається до нуля (`V_BL = 0`), а її власна паразитна ємність становить `C_BL` (зазвичай `C_BL ≈ 100–300 фФ`, що значно перевищує лінійну ємність конденсатора комірки `C_cell ≈ 5–15 фФ`).

Коли подається імпульс на PL, електричний заряд перерозподіляється між коміркою та битовою лінією:

1. **Якщо у комірці зберігався «0» (`+P_r`)**: вектор поляризації вже збігається з напрямом зовнішнього поля. Спонтанна поляризація не змінює свій знак. На битову лінію протікає лише незначний заряд неперемикального лінійного перезаряджання ємності:
   `Q_0 = C_lin · (V_DD - V_BL0)`

2. **Якщо у комірці зберігалася «1» (`-P_r`)**: зовнішнє поле силоміць повертає вектор поляризації на 180°. На битову лінію додатково вивільняється величезний заряд перемикання спонтанної поляризації:
   `Q_1 = 2 · P_r · A_cell + C_lin · (V_DD - V_BL1)`   *(де A_cell — площа обкладок)*

```
Формування сигналу на битовій лінії:
V_BL ↑
     |        Заряд Q_1 (була «1»: перемикання P_s)
     |        /----------------------------- (V_BL1 = Q_1 / C_BL)
     |       /
     |      /   Вікно зчитування ΔV = V_BL1 - V_BL0
     |     /
     |    /   Заряд Q_0 (була «0»: лінійний заряд)
     |   /---------------------------------- (V_BL0 = Q_0 / C_BL)
     +----------------------------------------> t
```

Підсилювач зчитування *(Sense Amplifier)* порівнює напругу `V_BL` з опорним рівнем `V_ref = (V_BL0 + V_BL1) / 2`.
Якщо `V_BL > V_ref`, схема реєструє логічну «1». Оскільки зчитування скинуло стан комірки в «0», керуюча логика **негайно виконує зворотний цикл перезапису** «1» у прочитану комірку.

### 4. Архітектура безруйнівного зчитування: FeFET та FTJ

Необхідність перезапису після кожного зчитування в 1T-1C комірках обмежує ресурсоємність пам'яті. Новіші концепції реалізують **безруйнівне зчитування** *(non-destructive read)*.

#### 4.1. Сегнетоелектричний польовий транзистор (FeFET)

У FeFET сегнетоелектричний діелектрик (`HfO2`) вбудовано безпосередньо у затворний стек МОН-транзистора (структура Metal-Ferroelectric-Insulator-Semiconductor, MFIS).

```
       Затвор (Gate, WL)
           |
      [==========]  Металевий електрод
      [----------]  Сегнетоелектрик HfO₂ (P_s ↑ або P_s ↓)
      [..........]  Міжфазний шар SiO₂
  -----------------------
  [ n+ Витік ]  P-кремній  [ n+ Стік ]
  -----------------------
         |                    |
       Source               Drain (BL)
```

Поляризація сегнетоелектрика створює додатковий електростатичний потенціал на поверхні напівпровідника, змінюючи порогову напругу транзистора `V_th`:
- **Стан `+P_s` (поляризація до каналу)**: приваблює електрони, зсуваючи порогову напругу вниз (`V_th_low`). При читанні транзистор **відкритий** (високий струм стоку `I_on`).
- **Стан `-P_s` (поляризація від каналу)**: виштовхує електрони, зсуваючи порогову напругу вгору (`V_th_high`). При читанні транзистор **закритий** (низький струм стоку `I_off`).

Відношення струмів зчитування `I_on / I_off` досягає **`10³–10⁵`**, а стан зчитується вимірюванням струму каналу без подачі коерцитивної напруги на затвор.

#### 4.2. Сегнетоелектричний тунельний перехід (FTJ)

Сегнетоелектричний тунельний перехід *(Ferroelectric Tunnel Junction, FTJ)* складається з ультратонкого сегнетоелектричного бар'єра (1–3 нм), затиснутого між двома різними металевими електродами.

Через квантовомеханічне тунелювання електронів крізь ультратонкий діелектрик орієнтація поляризації зміщує висоту та форму потенціального бар'єра. Це викликає ефект **сегнетоелектричного тунельного опору** *(Electroresistance Effect)*: опір елемента змінюється у 10–100 разів залежно від напряму поляризації, дозволяючи будувати надщільні кросбар-матриці аналогової нейроморфної пам'яті для штучного інтелекту.

### 5. Фізичні механізми деградації: втома та вдруковування

Під дією повторюваних електричних полів сегнетоелектричний матеріал піддається фізичним деградаційним процесам:

1. **Поляризаційна втома** *(fatigue)*: поступове зменшення залишкової поляризації `P_r` після багаторазових циклів перемикання (`> 10¹²` циклів). Головним мікроскопічним механізмом втоми є міграція та загарбання заряду кисневими вакансіями (`V_O¨`). Під дією поля вакансії накопичуються на межах розподілу електрод/сегнетоелектрик та на доменних стінках. Вони створюють локальні електричні поля, які «запирають» доменні стінки і перешкоджають їх повертанню.

2. **Вдруковування** *(imprint)*: тенденція комірки «віддавати перевагу» одному зі станів поляризації, якщо вона тривалий час перебувала у ньому при підвищеній температурі. Внутрішній об'ємний шар іонів та орієнтованих диполів дефектів створює внутрішнє електричне поле `E_imp`. Це поле зсуває петлю гістерезису уздовж осі полів, через що коерцитивна напруга для одного зі станів зростає, роблячи його недосяжним для стандартного рівня `V_DD`.

### 6. Програмне моделювання кінетики зчитування та вікна сигналів FeRAM

Наведений нижче код реалізує точний розрахунок перезаряджання битової лінії та обчислення вікна зчитування `ΔV_BL` з урахуванням температурного зсуву коерцитивного поля.

```c
/* Simulation of 1T-1C FeRAM Read & Write Cycles in C99 */
#include <stdio.h>
#include <math.h>

typedef struct {
    double area_um2;       /* Cell capacitor area in um^2 */
    double P_r_uC_cm2;     /* Remanent polarization P_r at 25C */
    double C_cell_fF;      /* Linear capacitance of cell in fF */
    int stored_state;      /* 0: +Pr ('0'), 1: -Pr ('1') */
} FeramCell;

typedef struct {
    double C_bl_fF;        /* Bit Line parasitic capacitance in fF */
    double V_dd_volts;     /* Read/Write voltage V_DD */
} BitLine;

/* Calculates Signal Margin Delta V_BL in Volts */
double simulate_feram_read(FeramCell* cell, const BitLine* bl, double temp_C, double* v_bl_out) {
    /* Temperature degradation of polarization: P_r(T) = P_r_25 * (1 - 0.0015 * (T - 25)) */
    double p_r_eff = cell->P_r_uC_cm2 * (1.0 - 0.0015 * (temp_C - 25.0));
    if (p_r_eff < 0.0) p_r_eff = 0.0;
    
    double area_cm2 = cell->area_um2 * 1e-8;
    double Q_linear_pC = (cell->C_cell_fF * 1e-3) * bl->V_dd_volts;
    double Q_switch_pC = 0.0;
    
    if (cell->stored_state == 1) {
        /* Reversal of P_s from -Pr to +Pr releases 2 * P_r * Area */
        Q_switch_pC = 2.0 * p_r_eff * (area_cm2 * 1e6);
    }
    
    double Q_total_pC = Q_linear_pC + Q_switch_pC;
    /* V_BL = Q_total / (C_BL + C_cell) */
    double total_cap_fF = bl->C_bl_fF + cell->C_cell_fF;
    *v_bl_out = (Q_total_pC * 1e3) / (total_cap_fF * 1e-3);
    
    /* Destructive read resets cell to state 0 (+Pr) */
    cell->stored_state = 0;
    
    return *v_bl_out;
}

int main(void) {
    FeramCell cell_state_1 = { .area_um2 = 0.05, .P_r_uC_cm2 = 22.0, .C_cell_fF = 12.0, .stored_state = 1 };
    FeramCell cell_state_0 = { .area_um2 = 0.05, .P_r_uC_cm2 = 22.0, .C_cell_fF = 12.0, .stored_state = 0 };
    BitLine bl = { .C_bl_fF = 150.0, .V_dd_volts = 1.8 };
    
    double v_bl_1 = 0.0, v_bl_0 = 0.0;
    simulate_feram_read(&cell_state_1, &bl, 85.0, &v_bl_1); /* Read at 85 C */
    simulate_feram_read(&cell_state_0, &bl, 85.0, &v_bl_0);
    
    printf("FeRAM Read State '1' at 85C: V_BL1 = %.3f V\n", v_bl_1);
    printf("FeRAM Read State '0' at 85C: V_BL0 = %.3f V\n", v_bl_0);
    printf("Sense Window Delta V_BL = %.3f V\n", v_bl_1 - v_bl_0);
    return 0;
}
```

```cpp
// Simulation of 1T-1C FeRAM Read & Write Cycles in C++17
#include <iostream>
#include <iomanip>
#include <algorithm>

class FeramCell {
public:
    enum class State { Logic0, Logic1 };

    FeramCell(double area_um2, double P_r_uC_cm2, double C_cell_fF, State state)
        : area_um2_(area_um2), P_r_uC_cm2_(P_r_uC_cm2), C_cell_fF_(C_cell_fF), state_(state) {}

    [[nodiscard]] double read_destructive(double C_bl_fF, double V_dd_volts, double temp_C) {
        const double p_r_eff = std::max(0.0, P_r_uC_cm2_ * (1.0 - 0.0015 * (temp_C - 25.0)));
        const double area_cm2 = area_um2_ * 1e-8;

        const double Q_linear_pC = (C_cell_fF_ * 1e-3) * V_dd_volts;
        const double Q_switch_pC = (state_ == State::Logic1)
            ? (2.0 * p_r_eff * (area_cm2 * 1e6))
            : 0.0;

        const double Q_total_pC = Q_linear_pC + Q_switch_pC;
        const double total_cap_fF = C_bl_fF + C_cell_fF_;
        const double V_bl = (Q_total_pC * 1e3) / (total_cap_fF * 1e-3);

        // Destructive read resets cell to Logic0 (+Pr)
        state_ = State::Logic0;

        return V_bl;
    }

    [[nodiscard]] State get_state() const noexcept { return state_; }

private:
    double area_um2_;
    double P_r_uC_cm2_;
    double C_cell_fF_;
    State state_;
};

int main() {
    constexpr double C_bl_fF = 150.0;
    constexpr double V_dd = 1.8;
    constexpr double Temp = 85.0; // 85 C operating temperature

    FeramCell cell1(0.05, 22.0, 12.0, FeramCell::State::Logic1);
    FeramCell cell0(0.05, 22.0, 12.0, FeramCell::State::Logic0);

    const double v1 = cell1.read_destructive(C_bl_fF, V_dd, Temp);
    const double v0 = cell0.read_destructive(C_bl_fF, V_dd, Temp);

    std::cout << std::fixed << std::setprecision(3);
    std::cout << "FeRAM Read State '1' at 85C: V_BL1 = " << v1 << " V\n";
    std::cout << "FeRAM Read State '0' at 85C: V_BL0 = " << v0 << " V\n";
    std::cout << "Sense Margin ΔV_BL = " << (v1 - v0) << " V\n";

    return 0;
}
```
