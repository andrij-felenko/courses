# 🧮 Потенціал Ландау — Девоншира та термодинаміка сегнетоелектричних переходів

Феноменологічна теорія фазових переходів Ландау — Девоншира описує сегнетоелектричний стан без залучення складних мікроскопічних моделей кристалічної ґратки. Вона розглядає спонтанну поляризацію `P` як макроскопічний параметр порядку, а вільну енергію системи розкладає у степеневий ряд поблизу критичної температури. Ця вставка містить повний термодинамічний вивід рівнянь стану, аналіз фазових переходів першого та другого роду, виведення стрибка теплоємності, просторовий профіль 180-градусної доменної стінки Гінзбурга — Ландау та термодинаміку електрокалоричного ефекту.

### 1. Повний розклад вільної енергії Гіббса

У термодинамічно рівноважному стані за сталої температури `T` та напруженості зовнішнього електричного поля `E` густина вільної енергії Гіббса `F(P, T)` є функцією поляризації `P`. Оскільки у високотемпературній пароелектричній фазі кристал має центр симетрії, напрями `+P` та `-P` є абсолютно рівноправними. Це означає, що за відсутності поля (`E = 0`) вільна енергія містить лише парні степені поляризації (`P²`, `P⁴`, `P⁶`):

```
F(P, T) = F₀ + (1/2)·α·P² + (1/4)·β·P⁴ + (1/6)·γ·P⁶ - E·P
```

Тут `F₀` — вільна енергія неполяризованого пароелектричного кристала, а коефіцієнти `α`, `β`, `γ` залежать від температури та механічних напружень. За фундаментальною гіпотезою Ландау, головна температурна залежність зосереджена в найнижчому коефіцієнті `α`, який лінійно змінює знак при переході через температуру Кюрі — Вейсса `T₀`:

```
α(T) = α₀ · (T - T₀)    [де α₀ > 0 — стала матеріалу]
```

Знак коефіцієнта `β` визначає термічний характер і рід фазового переходу:
- Якщо `β > 0`, відбувається фазовий перехід **другого роду** (неперервний, без прихованої теплоти). Достатньо обмежитися членами до `P⁴`.
- Якщо `β < 0`, відбувається фазовий перехід **першого роду** (стрибкоподібний, з прихованою теплотою). Член `(1/6)·γ·P⁶` із `γ > 0` є обов'язковим для забезпечення математичної стійкості потенціалу при великих значеннях `P`.

```
          Фазовий перехід 2-го роду (β > 0)             Фазовий перехід 1-го роду (β < 0, γ > 0)
F(P) ↑                                         F(P) ↑
     |     T > T_C (один min при P=0)               |     T > T_h (один min при P=0)
     |    \________/                                |    \________/
     |                                              |
     |     T < T_C (два min при ±P_s)               |     T = T_C (три рівні min)
     |    __  /\  __                                |   __/\  __  /\__
     |   /  \/  \/  \                               |  /  \ \/  \/  \
     +-------------------> P                        +-------------------> P
       -P_s  0   +P_s                                 -P_s  0   +P_s
```

### 2. Фазовий перехід другого роду (`β > 0`)

Розглянемо детально випадок `β > 0` за відсутності зовнішнього поля (`E = 0`). Густина вільної енергії спрощується до вигляду:

```
F(P, T) = F₀ + (1/2)·α₀·(T - T₀)·P² + (1/4)·β·P⁴
```

Рівноважні значення поляризації знаходяться з умови екстремуму вільної енергії:

```
∂F / ∂P = 0
⇒ α₀·(T - T₀)·P + β·P³ = 0
⇒ P · [ α₀·(T - T₀) + β·P² ] = 0
```

Це рівняння має три математичні корені:
1. `P = 0` — пароелектричний стан.
2. `P_s² = - α₀·(T - T₀) / β = α₀·(T₀ - T) / β` — сегнетоелектричний стан.

Дослідимо другою похідною стійкість цих станів (`∂²F / ∂P² = α + 3·β·P²`):

- **При `T > T₀`**: `α > 0`. Для `P = 0` друга похідна `∂²F/∂P² = α > 0`, отже стан `P = 0` є єдиним мінімумом. Для `P_s²` вираз є від'ємним, тож уявні корені не існують.
- **При `T < T₀`**: `α < 0`. Для `P = 0` друга похідна `∂²F/∂P² = α < 0`, тобто нульовий стан стає нестійким локальним максимумом. Для `P_s` друга похідна стає додатною:
  `∂²F / ∂P² = α + 3·β · ( -α / β ) = -2·α = 2·α₀·(T₀ - T) > 0`

Отже, при `T < T₀` система самочинно обирає один із двох симетричних мінімумів спонтанної поляризації:

```
P_s(T) = ± √[ α₀ · (T_C - T) / β ]    [при T < T_C, де T_C = T₀]
```

### 3. Діелектрична сприйнятливість та «закон двійки»

Знайдемо макроскопічний відгук поляризації на слабке зовнішнє електричне поле `E`. Рівноважне рівняння стану під дією поля має вигляд:

```
∂F / ∂P = E
⇒ α·P + β·P³ = E
```

Диференціюючи це рівняння по `E`, знаходимо ізотермічну діелектричну сприйнятливість `χ = ∂P / ∂E = ε₀ · (ε - 1)`:

```
α · (∂P/∂E) + 3·β·P² · (∂P/∂E) = 1
⇒ χ(T) = 1 / ( α + 3·β·P² )
```

Обчислимо значення сприйнятливості у двох температурних фазах:

1. **Пароелектрична фаза (`T > T_C`)**, де `P = 0`:

```
χ(T) = 1 / α(T)
     = 1 / [ α₀ · (T - T_C) ]
     = C / (T - T_C)                 [де C = 1 / α₀ — стала Кюрі]
```

Це математичний вивід класичного **закону Кюрі — Вейсса**.

2. **Сегнетоелектрична фаза (`T < T_C`)**, де `P = P_s` та `P_s² = α₀·(T_C - T) / β`:

```
χ(T) = 1 / [ α₀·(T - T_C) + 3·β · (α₀·(T_C - T) / β) ]
     = 1 / [ - α₀·(T_C - T) + 3·α₀·(T_C - T) ]
     = 1 / [ 2 · α₀ · (T_C - T) ]
     = C / [ 2 · (T_C - T) ]
```

Порівнюючи нахили залежності оберненої сприйнятливості `1/χ(T)` вище та нижче точки Кюрі, ми отримуємо фундаментальний **«закон двійки» Ландау**:

```
[ ∂(1/χ)/∂T ]_{T > T_C}  =   α₀  =  1 / C
[ ∂(1/χ)/∂T ]_{T < T_C}  =  2·α₀  =  2 / C
```

Нахил графіку `1/χ(T)` у сегнетоелектричній фазі вдвічі більший, ніж у пароелектричній. Фізично це пояснюється більшою жорсткістю двох кристалічних джерел відновлювальної сили біля `±P_s` порівняно із пласким дном пароелектричного потенціалу.

```
1/χ ↑
    |       нахил 2·α₀             нахил α₀
    |         \                   /
    |          \                 /
    |           \               /
    +------------\-------------/---------> T
                T_C = T₀
```

### 4. Аномалія теплоємності (стрибок ΔC_p)

Фазовий перехід впливає не лише на електричні, а й на теплові властивості кристала. Обчислимо ентропію густини `S` та питому теплоємність `C_p`.

Ентропія визначається як мінус перша похідна вільної енергії за температурою:

```
S = - ( ∂F / ∂T )_P             [визначення ентропії з термодинаміки Гіббса]
  = S₀ - (1/2) · (∂α/∂T) · P²   [диференціювання розкладу Ландау F(P) за температурою]
  = S₀ - (1/2) · α₀ · P²        [враховано ∂α/∂T = α₀ згідно з α(T) = α₀(T - T₀)]
```

- **При `T > T_C`**: `P = 0`, тож ентропія `S = S₀` (дорівнює ентропії пароелектричної ґратки), а теплоємність `C_p = T · (∂S/∂T) = C_p0`.
- **При `T < T_C`**: `P_s² = α₀·(T_C - T) / β`, тож ентропія дорівнює:

```
S(T) = S₀ - (1/2) · α₀ · [ α₀·(T_C - T) / β ]   [підставлено вираз для P_s²(T)]
     = S₀ - (α₀² / 2·β) · (T_C - T)             [спрощення алгебраїчного виразу]
```

Диференціюючи ентропію за температурою, знаходимо теплоємність у сегнетоелектричній фазі:

```
C_p(T) = T · ( ∂S / ∂T )                        [визначення теплоємності з ентропії]
       = C_p0 + ( α₀² · T ) / ( 2 · β )         [підстановлено похідну ∂S/∂T = α₀²/(2β)]
```

У самій точці фазового переходу `T = T_C` спостерігається скачкоподібна **аномалія теплоємності (стрибок Дрезеля — Ландау)**:

```
ΔC_p = C_p(T_C⁻) - C_p(T_C⁺) = ( α₀² · T_C ) / ( 2 · β )
```

Цей стрибок є чисто електронно-ґратковим внеском від упорядкування іонних зміщень при переході другого роду.

### 5. Структура Гінзбурга — Ландау 180° доменній стінці

У реальному кристалі поляризація змінюється у просторі `P(x)`. Щоб врахувати енергетичну ціну просторової неоднорідності (градієнта поляризації), Віталій Гінзбург додав до термодинамічного потенціалу градієнтний член:

```
F(P, ∇P) = ∫ [ F₀ + (1/2)·α·P² + (1/4)·β·P⁴ + (1/2)·κ·(dP/dx)² ] dx
```

Де `κ > 0` — коефіцієнт градієнтної енергії (градієнтне жорсткість).

Знайдемо просторовий профіль 180° доменної стінки, яка розділяє домен із `-P_s` (при `x → -∞`) та домен із `+P_s` (при `x → +∞`). Рівняння Ейлера — Лагранжа має вигляд:

```
κ · (d²P / dx²) - α·P - β·P³ = 0
```

Враховуючи, що `α = -|α|` при `T < T_C` та `P_s² = |α|/β`, перепишемо рівняння:

```
κ · (d²P / dx²) + |α|·P · [ 1 - (P/P_s)² ] = 0
```

Точним аналітичним розв'язком цього диференціального рівняння є **профіль кінка (солітона)**:

```
P(x) = P_s · tanh( x / ( √2 · ξ ) )
```

Де `ξ` — **довжина кореляції (когерентності)**, яка визначає ефективну товщину доменної стінки:

```
ξ(T) = √[ κ / |α| ] = √[ κ / ( α₀ · (T_C - T) ) ]
```

При наближенні до точки Кюрі (`T → T_C`) довжина кореляції `ξ` прямує до нескінченності: доменна стінка розмивається і втрачає чітку межу.

Обчислимо поверхневу енергію 180° доменної стінки `σ_w` як надлишкову вільну енергію на одиницю площі:

```
σ_w = ∫_{-∞}^{+∞} [ F(P) - F(P_s) + (1/2)·κ·(dP/dx)² ] dx
    = ( 2 · √2 / 3 ) · [ ( κ · |α|³ )^(1/2) / β ]
    = ( 2 · √2 / 3 ) · κ^(1/2) · α₀^(3/2) · β⁻¹ · (T_C - T)^(3/2)
```

Мала товщина 180° стінки (`ξ ~ 0.5–1 нм`) пояснюється великим значенням `|α|` та відносно малою градієнтною енергією `κ` у перовськітах.

### 6. Електрокалоричний ефект (ECE)

Зміна орієнтації поляризації під дією зовнішнього поля викликає недіабатичний теплообмін. З термодинамічного співвідношення Максвелла:

```
( ∂S / ∂E )_T = ( ∂P / ∂T )_E
```

Адіабатична зміна температури кристала `ΔT` при вимкненні або прикладанні електричного поля `E` дорівнює:

```
ΔT = - ∫₀^{E} ( T / ( ρ · C_p ) ) · ( ∂P / ∂T )_E dE
```

Оскільки поблизу точки Кюрі похідна `|∂P/∂T|` досягає гігантських значень, прикладання поля викликає впорядкування диполів і виділення тепла, а його швидке зняття в адіабатичних умовах призводить до стрімкого охолодження кристала.

Використовуючи вираз Ландау `P_s = √[α₀(T_C - T)/β]`, отримуємо для електрокалоричної зміни температури:

```
( ∂P_s / ∂T ) = - α₀ / ( 2 · β · P_s )
⇒ ΔT_ECE ≈ ( α₀ · T_C / ( 2 · ρ · C_p · β ) ) · Δ(P²)
```

Цей ефект слугує основою для створення новітніх твердотільних охолоджувачів без фреону та рухомих механічних частин.

### 7. Фазовий перехід першого роду (`β < 0`)

Якщо `β < 0`, член `(1/4)·β·P⁴` сприяє нестійкості, і для забезпечення термодинамічної межі при великих поляризаціях необхідно додавати член `(1/6)·γ·P⁶` із `γ > 0`:

```
F(P) = F₀ + (1/2)·α₀·(T - T₀)·P² - (1/4)·|β|·P⁴ + (1/6)·γ·P⁶
```

Умови існування екстремумів `∂F/∂P = 0`:

```
P · [ α₀·(T - T₀) - |β|·P² + γ·P⁴ ] = 0
```

Рівняння має нульовий розв'язок `P = 0` та ненульові корені:

```
P_s² = [ |β| + √( β² - 4·α₀·γ·(T - T₀) ) ] / ( 2 · γ )
```

Температура термодинамічного фазового переходу `T_C` визначається умовою рівності вільних енергій пароелектричної та сегнетоелектричної фаз (`F(P_s) = F₀`):

```
(1/2)·α₀·(T_C - T₀)·P_s² - (1/4)·|β|·P_s⁴ + (1/6)·γ·P_s⁶ = 0
```

Сумісний розв'язок цих термодинамічних умов дає точні співвідношення для фазового переходу 1-го роду:

```
Температура фазового переходу:     T_C = T₀ + ( 3 · β² ) / ( 16 · α₀ · γ )
Стрибок спонтанної поляризації:    P_s²(T_C) = ( 3 · |β| ) / ( 4 · γ )
Межа перегріву сегнетофази:        T_h = T₀ + β² / ( 4 · α₀ · γ )
```

Таким чином, феноменологія Ландау — Девоншира надає повний і математично строгий апарат для обчислення термодинамічних, електричних, теплових та просторових характеристик сегнетоелектриків.
