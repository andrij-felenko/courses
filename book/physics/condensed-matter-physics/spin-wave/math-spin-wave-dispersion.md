# 🧮 Математика спінових хвиль: дисперсія та квантування

Квантово-механічний опис колективних спінових збуджень спирається на математичне перетворення операторів моменту імпульсу, які підпорядковуються некомутативній алгебрі Лі `su(2)`, у стандартні бозівські оператори народження та знищення. Цей формалізм дозволяє суворо розрахувати закони дисперсії спінових хвиль у феромагнетиках та антиферомагнетиках, провести діагоналізацію гамільтоніана Гейзенберга, врахувати диполь-дипольні поправки та проінтегрувати термодинамічні характеристики магнонного газу.

---

### 1. Класична прецесійна динаміка та рівняння Ландау — Ліфшиця

Розглянемо монокристалічний феромагнетик із просторовою решіткою, у вузлах якої розташовані атомні спінові моменти `S_i`. У класичному наближенні кожен спін розглядається як вектор постійної довжини `|S_i| = S`.

Ефективне магнітне поле `B_eff,i`, що діє на `i`-й спін з боку сусідів за рахунок обмінної взаємодії Гейзенберга, визначається мікроскопічною варіацією гамільтоніана за даним спіновим вектором:

```
H = -J · ∑ (S_i · S_j)    [сумування за найближчими сусідами]
```

```
B_eff,i = -(1 / (g · μ_B)) · (∂H / ∂S_i)
= (2 · J / (g · μ_B)) · ∑ S_i+δ
```

де `δ` — вектори, що з'єднують `i`-й вузол із його `z` найближчими сусідами, `g` — фактор Ланде, `μ_B` — магнетон Бора.

Динаміка векторів спінів описується прецесійним рівнянням Ландау — Ліфшиця без урахування дисипації:

```
d S_i / dt = -(g · μ_B / ħ) · (S_i × B_eff,i)
= (2 · J / ħ) · ∑ (S_i × S_i+δ)
```

Векторний добуток `(S_i × B_eff,i)` гарантує, що швидкість зміни спіна завжди перпендикулярна до самого вектора спіна. Це означає, що модуль кожного спінового вектора є строгим інтегралом руху (`d|S_i|²/dt = 0`), і спіновий вектор може лише змінювати свій напрямок у просторі, описуючи прецесійний конус навколо напрямку ефективного поля.

#### Лінеаризація для малих кутів відхилення
Нехай кристал магнітно впорядкований вздовж осі `Z` (`S_z,i ≈ S`). За умов низьких температур кут відхилення спінів від осі легкої намагніченості є дуже малим (`θ ≪ 1`). Розкладемо компоненти векторів на велику поздовжню частину та малі поперечні коливання:

```
S_i = (S_x,i, S_y,i, S - (S_x,i² + S_y,i²) / (2·S))
```

Ввівши комплексну циркулярну змінну `S_i^+ = S_x,i + i · S_y,i`, перепишемо векторний добуток `(S_i × S_i+δ)_x,y` у лінійному наближенні за малими поперечними амплітудами (`S_x, S_y ≪ S`):

```
d S_i^+ / dt = i · (2 · J · S / ħ) · ∑ (S_i^+ - S_i+δ^+)    [лінеаризоване рівняння прецесії]
```

#### Плоскохвильовий розв'язок і геометричні фактори ґраток
Шукаємо рішення лінеаризованого рівняння у вигляді делокалізованої хвилі прецесії:

```
S_i^+ = S_0^+ · exp(i · (q · r_i - ω · t))
```

Підставивши цей плоскохвильовий анзац у лінеаризоване рівняння прецесії, отримуємо комплексне алгебраїчне рівняння для власної частоти `ω`:

```
-i · ω · S_0^+ = i · (2 · J · S / ħ) · S_0^+ · ∑ (1 - exp(i · q · δ))
```

Оскільки кристал володіє центросиметрією (симетрією відносно інверсії `δ ↦ -δ`), сума уявних синусів перетворюється на нуль (`∑ sin(q · δ) = 0`). Дійсна частина косинусів дає квантовий закон дисперсії спінової хвилі:

```
ħ · ω(q) = 2 · J · S · ∑ (1 - cos(q · δ))
= 2 · J · S · z · (1 - γ_q)
```

де `z` — кількість найближчих сусідів, а `γ_q = (1/z) · ∑ exp(i · q · δ)` — геометричний фактор ґратки.

Розрахуємо явний вигляд геометричного фактора `γ_q` для трьох класичних типів тривимірних кубічних кристалічних ґраток:
1. **Проста кубічна ґратка (SC):** Вузол має `z = 6` найближчих сусідів на відстанях `(±a, 0, 0)`, `(0, ±a, 0)`, `(0, 0, ±a)`:
   ```
   γ_q^SC = (1 / 3) · [ cos(q_x · a) + cos(q_y · a) + cos(q_z · a) ]
   ```
2. **Об'ємноцентрирована кубічна ґратка (BCC):** Вузол має `z = 8` найближчих сусідів на відстанях `(±a/2, ±a/2, ±a/2)`:
   ```
   γ_q^BCC = cos(q_x · a / 2) · cos(q_y · a / 2) · cos(q_z · a / 2)
   ```
3. **Гранецентрирована кубічна ґратка (FCC):** Вузол має `z = 12` найближчих сусідів на відстанях `(±a/2, ±a/2, 0)` і циклічних перестановках:
   ```
   γ_q^FCC = (1 / 3) · [ cos(q_x·a/2)·cos(q_y·a/2) + cos(q_y·a/2)·cos(q_z·a/2) + cos(q_z·a/2)·cos(q_x·a/2) ]
   ```

В області малих хвильових векторів (`q·a ≪ 1`) розкладемо косинус у ряд Тейлора `cos(x) ≈ 1 - x² / 2`:

```
ħ · ω(q)
≈ 2 · J · S · a² · (q_x² + q_y² + q_z²)    [розклад cos(q_i·a) ≈ 1 - (q_i·a)² / 2]
= 2 · J · S · a² · q²                       [визначення модуля хвильового вектора q² = q_x² + q_y² + q_z²]
= D · q²                                   [позначення жорсткості спінової хвилі D = 2·J·S·a²]
```

де `D = 2 · J · S · a²` — **коефіцієнт жорсткості спінової хвилі** (*spin wave stiffness parameter*).

Для некубічних кристалографічних симетрій (наприклад, тетрагональних або гексагональних кристалів) обмінна жорсткість утворює анізотропний тензор другого рангу `D_αβ`. Дисперсійне співвідношення набуває вигляду суми `ħ·ω(q) = ∑ D_αβ · q_α · q_β`, де жорсткість уздовж осі анізотропії `D_zz` відрізняється від базисної жорсткості `D_xx = D_yy`.

У континуальному наближенні (при переході від дискретної решітки до неперервного середовища `a → 0`) розклад суми за сусідніми вузлами еквівалентний заміні різницевого оператора на просторовий лапласіан `∇²`. Лінеаризоване рівняння Ландау — Ліфшиця для комплексної намагніченості `m^+ = M_x + i·M_y` набуває вигляду диференціального рівняння в частинних похідних типу Шредінгера:

```
i · ħ · (∂ m^+ / ∂ t) = -D · ∇² m^+ + (g · μ_B · B_0 + K_an) · m^+
```

За наявності зовнішнього підмагнічувального поля `B_0` та магнітної анізотропії `K_an` до енергії додається постійна зееманівська щілина:

```
ħ · ω(q) = g · μ_B · B_0 + K_an + D · q²
```

#### Фазова та групова швидкості спінових хвиль
З отриманого закон дисперсії прямо виражаються кінематичні характеристики спінових хвиль:
- **Фазова швидкість (`v_p = ω / q`):** Для довгохвильових магнонів у феромагнетику `v_p = (D / ħ) · q`. Фазова швидкість зростає лінійно з ростом хвильового вектора.
- **Групова швидкість (`v_g = dω / dq`):** Для квадратичного спектра `v_g = (2 · D / ħ) · q = 2 · v_p`. Групова швидкість удвічі перевищує фазову, що призводить до характерного дисперсійного розпливання хвильових пакетів під час поширення.

### 2. Квантовий формалізм Гольштейна — Примакова та точні бозонізації

У квантовій механіці спінові оператори підпорядковуються некомутативним співвідношенням алгебри `su(2)`:

```
[S_i^x, S_j^y] = i · ħ · δ_ij · S_i^z
[S_i^+, S_j^-] = 2 · ħ · δ_ij · S_i^z
```

Оскільки ці оператори не задовольняють стандартним комутаційним співвідношенням для тотожних бозонів чи ферміонів, Теодор Гольштейн і Генрі Примаков у 1940 році висунули точне операторне перетворення, яке виражає спінові оператори через бозівські оператори народження `a_i^†` та знищення `a_i`, для яких виконується точне бозе-комутаційне співвідношення `[a_i, a_j^†] = δ_ij`:

```
S_i^+ = √(2·S) · √(1 - a_i^†·a_i / (2·S)) · a_i
S_i^- = √(2·S) · a_i^† · √(1 - a_i^†·a_i / (2·S))
S_i^z = S - a_i^†·a_i
```

Оператор `n_i = a_i^†·a_i` має значення власних чисел `0, 1, 2, ..., 2S` і показує кількість відхилень спіна (магнонів) на `i`-му вузлі.

Альтернативною точною бозонізацією спінів є **представлення Малєєва — Дайсона**, у якому відсутній квадратний корінь, але комутаційні оператори стають неермітовими:
```
S_i^+ = √(2·S) · (1 - a_i^†·a_i / (2·S)) · a_i
S_i^- = √(2·S) · a_i^†
S_i^z = S - a_i^†·a_i
```
Представлення Малєєва — Дайсона зручне для розрахунку діаграмних розкладів магнон-магнонного розсіювання у теорії збурень при високих температурах.

#### Низькотемпературне розкладання оператора
За умов низьких температур середня кількість магнонів на один атом мала (`⟨n_i⟩ ≪ 2·S`). Радикальний фактор можна розкласти в ряд за степенями `a_i^†·a_i / (2·S)`:

```
√(1 - a_i^†·a_i / (2·S)) = 1 - a_i^†·a_i / (4·S) - (a_i^†·a_i)² / (32·S²) - ... ≈ 1
```

Перший член розкладу (одиниця) описує наближення невзаємодіючих вільних магнонів, тоді як наступні члени розкладу описують ангармонічні магнон-магнонні взаємодії (чотиримагнонні та шестимагнонні процеси розсіювання).

У наближенні невзаємодіючих магнонів отримуємо лінійне Гольштейн-Примаковське перетворення:

```
S_i^+ ≈ √(2·S) · a_i
S_i^- ≈ √(2·S) · a_i^†
S_i^z = S - a_i^†·a_i
```

#### Квантування та діагоналізація гамільтоніана Гейзенберга
Підставимо наближені оператори Гольштейна — Примакова у гамільтоніан Гейзенберга. Зауважимо, що `S_i · S_j = S_i^z · S_j^z + (1/2) · (S_i^+ · S_j^- + S_i^- · S_j^+)`:

```
H = -J · ∑ [ (S - a_i^†·a_i)·(S - a_j^†·a_j) + S·(a_i·a_j^† + a_i^†·a_j) ]
```

Розкривши дужки та утримавши лише квадратичні за операторами терми:

```
H ≈ -J · N · z · S² + 2 · J · S · ∑ [ a_i^†·a_i - a_i^†·a_j ]
```

де `E_0 = -J · N · z · S²` — енергія основного феромагнітного стану.

Перейдемо до імпульсного простору за допомогою просторового перетворення Фур'є:

```
a_i = (1 / √N) · ∑ exp(i · q · r_i) · a_q
a_i^† = (1 / √N) · ∑ exp(-i · q · r_i) · a_q^†
```

Завдяки умові ортогональності плоских хвиль `∑_i exp(i · (q - q') · r_i) = N · δ_qq'`, підстановка перетворення Фур'є у гамільтоніан приводить його до строго діагонального вигляду:

```
H = E_0 + ∑ ħ·ω(q) · a_q^† · a_q
```

де оператор `a_q^† · a_q = n_q` — це оператор кількості магнонів у стані з хвильовим вектором `q`, а енергія одного квантованого збудження (магнона) дорівнює:

```
ħ·ω(q) = 2 · J · S · z · (1 - γ_q)
```

### 3. Спектр спінових хвиль в антиферомагнетиках (перетворення Боголюбова)

В антиферомагнетику кристалічна ґратка розбивається на дві вкладені підґратки `A` та `B` із протилежно орієнтованими спінами (`S_A` вгору, `S_B` вниз), а обмінний інтеграл `J < 0` від'ємний (`|J| = -J`).

Введемо оператори Гольштейна — Примакова окремо для кожної підґратки:
- Для підґратки `A` (спіни вгору): `S_A,i^z = S - a_i^†·a_i`, `S_A,i^+ ≈ √(2·S) · a_i`.
- Для підґратки `B` (спіни вниз): `S_B,j^z = -S + b_j^†·b_j`, `S_B,j^+ ≈ √(2·S) · b_j^†`.

Гамільтоніан взаємодії найближчих сусідів між підґратками набуває вигляду:

```
H = E_0 + 2·|J|·S·z · ∑ [ a_q^†·a_q + b_q^†·b_q + γ_q·(a_q·b_-q + a_q^†·b_-q^†) ]
```

Оскільки гамільтоніан містить недіагональні парні оператори `a_q·b_-q` (одночасне народження чи знищення двох магнонів на протилежних підґратках), його діагоналізація виконується за допомогою канонічного **перетворення Боголюбова**:

```
α_q = u_q · a_q - v_q · b_-q^†
β_q = u_q · b_-q - v_q · a_q^†
```

Для того щоб нові оператори `α_q` та `β_q` задовольняли точним бозівським комутаційним співвідношенням `[α_q, α_q'^†] = δ_qq'`, коефіцієнти боголюбовського міксингу повинні підпорядковуватись умові нормування:

```
u_q² - v_q² = 1
```

Використовуючи гіперболічну параметризацію `u_q = cosh(θ_q)` та `v_q = sinh(θ_q)`, мінімізація недіагональних термів гамільтоніана дає точний розв'язок для коефіцієнтів:

```
u_q = √[ (1 / (2 · √(1 - γ_q²))) + 1/2 ]
v_q = √[ (1 / (2 · √(1 - γ_q²))) - 1/2 ] · sgn(γ_q)
```

Після перетворення Боголюбова гамільтоніан антиферомагнетика набуває діагональної форми:

```
H = E_GS + ∑ ħ·ω_AFM(q) · (α_q^† · α_q + β_q^† · β_q)
```

Закон дисперсії антиферомагнітних магнонів дорівнює:

```
ħ·ω_AFM(q) = 2 · |J| · S · z · √(1 - γ_q²)
```

Для малих хвильових векторів (`q·a ≪ 1`), враховуючи `1 - γ_q² ≈ (2/3) · (q·a)²`:

```
ħ·ω_AFM(q) ≈ [ 2 · √2 · |J| · S · √(z / 3) · a ] · |q|
= ħ · v_s · |q|
```

де `v_s` — **швидкість антиферомагнітних спінових хвиль**.

#### Нульові квантові флуктуації та квантова заплутаність
Найважливішим математичним наслідком ненульового значення коефіцієнта `v_q` є те, що квантовий основний стан антиферомагнетика при `T = 0 K` не є повністю впорядкованим (`S_z = S`). Навіть за абсолютного нуля в антиферомагнетику існують **нульові квантові флуктуації спінів**, які зменшують спонтанну намагніченість кожної підґратки на величину:

```
ΔS_0 = (1 / N) · ∑ v_q²
```

Для простої кубічної ґратки чисельне інтегрування коефіцієнтів Боголюбова дає `ΔS_0 ≈ 0.078`. Це означає, що спонтанна намагніченість підґратки при `T = 0 K` становить `S - 0.078` замість точного цілочисельного спіна `S`.

Квантовий вакуумний стан антиферомагнетика `|Ω_AFM⟩` являє собою стиснений вакуум двомодових бозонів:

```
|Ω_AFM⟩ = ∏ (1 / u_q) · exp( (v_q / u_q) · a_q^† · b_-q^† ) |0_A, 0_B⟩
```

Математична форма цього стану вказує на наявність макроскопічної квантової заплутаності (квантового стиснення, *quantum spin squeezing*) між магнонними модами протилежних підґраток `A` та `B`.

### 4. Диполь-обмінна теорія Херпіна — Геррінга та магнітостатика

При врахуванні довгосяжної диполь-дипольної взаємодії між класичними магнітними моментами тензор магнітної сприйнятливості розраховується з рівнянь Максвелла в магнітостатичному наближенні:

```
∇ × H = 0    =>    H = -∇ Ψ_m
∇ · B = 0    =>    ∇ · (H + 4·π·M) = 0
```

Поєднуючи магнітостатичне рівняння Поассона `∇² Ψ_m = 4·π · (∇ · M)` із рівнянням прецесії Ландау — Ліфшиця, Херпін і Геррінг отримали точне диполь-обмінне дисперсійне співвідношення для плівок феромагнетика:

```
ħ · ω(q) = √[ (g·μ_B·B_0 + D·q²) · (g·μ_B·B_0 + D·q² + 4·π·g·μ_B·M_s · sin²(θ_q)) ]
```

де `θ_q` — кут між хвильовим вектором `q` та віссю намагніченості `M_s`.

Магнітостатичне поле розсіювання `H_d` розраховується за допомогою функції Гріна для тензора розсіювання:
```
H_d(r) = ∇ ∬ M(r') · ∇ (1 / |r - r'|) d³r'
```
У тонких плівках товщиною `d` граничні умови для потенціалу `Ψ_m` на верхній та нижній поверхнях створюють розмірне квантування дипольних мод, перетворюючи планарні магнонні хвилеводи на багатомодові магнонні канали.

Ця формула описує плавну трансформацію спектра:
- При `q > k_dipole = √(4·π·M_s / D)` (довжини хвиль `λ < 100 нм`) домінує квантовий обмін `D·q²`, і спектр стає суто квадратичним.
- При `q < k_dipole` (довжини хвиль `λ > 1 мкм`) домінує дипольний розщеплювальний фактор `sin²(θ_q)`, створюючи анізотропні магнітостатичні хвилі.

### 5. Ангармонічні магнон-магнонні взаємодії та нестійкість Сула

У вищому порядку розкладання оператора Гольштейна — Примакова гамільтоніан містить нелінійні члени четвертого порядку за магнонними операторами:

```
H_int = -(J / (2·N)) · ∑ V(1, 2; 3, 4) · a_1^† · a_2^† · a_3 · a_4 · δ(q_1 + q_2 - q_3 - q_4)
```

де `V(1, 2; 3, 4)` — амплітуда чотиримагнонного розсіювання.

При потужному параметричному мікрохвильовому накачуванні (коли амплітуда однорідної прецесії `a_0` перевищує поріг `h_th`), нелінійний взаємозв'язок викликає **параметричну нестійкість Сула першого порядку** (розпад однорідної прецесії на пару магнонів із протилежними імпульсами `q` та `-q` при `ω_0 = ω_q + ω_-q`) або **другого порядку** (пружне розсіювання двох однорідних магнонів у пару магнонів `q` та `-q` при `2·ω_0 = ω_q + ω_-q`).

Поріг нестійкості визначається коефіцієнтом дисипації Гільберта `α_G` та амплітудою підмагнічувального ВЧ-поля:

```
h_th = (ΔH_0 / 2) · √[ (2 · ω_q / ω_M)² + 1 ]
```

де `ω_M = γ · 4·π·M_s`. Цей нелінійний поріг обмежує максимальну потужність мікрохвильових феромагнітних пристроїв.

### 6. Спінові хвилі у періодичних та недіагональних спінових структурах

У спіральних магнетиках та гелікоїдах (наприклад, у кристалах `MnSi` чи `FeGe` із сильним DMI-взаємодією) основний стан спінів описується спіральною хвилею `S_i = S · (cos(Q · r_i), sin(Q · r_i), 0)`, де `Q` — вектор спіралі.

Діагоналізація гамільтоніана у спіральних фазах за допомогою узагальненого перетворення Боголюбова приводить до трьох гілок збуджень:
- Одна поздовжня магнонна мода (колебання модуля гелікоїда).
- Дві поперечні моди прецесії (фазові флуктуації орієнтації спіралі), дисперсія яких є асиметричною: `ħ·ω(q) ≠ ħ·ω(-q)`.

Ця асиметрія створює ефект **магнонного дихроїзму**, при якому коефіцієнт проходження спінової хвилі крізь кристал залежить від напрямку поширення. Крім того, у 2D кристалах із кіральною асиметрією виникають топологічно захищені крайні магнонні моди, математичний опис яких виражається через ненульовий індекс Черна `C_n ≠ 0` магнонної частотної смуги.

Аналітичний розрахунок топологічних магнонів спирається на інтегрування кривини Беррі `Ω(q)` по всій зоні Бріллюена:
```
C_n = (1 / (2·π)) · ∬ Ω_n(q) d²q
```
Ненульове значення `C_n` гарантує існування односпрямованих крайніх спінових хвиль, нечутливих до структурних дефектів, немагнітних домішок та розсіювання на краях кристала.

Фізична причина нечутливості крайніх магнонних мод полягає у тому, що зворотне розсіювання хвилі `q ↦ -q` є квантово-механічно забороненим через відсутність зворотного квантового стану із відповідною спіновою поляризацією. Це дозволяє проектувати надстійкі магнонні канали зв'язку для квантової обробки даних.

### 7. Термодинамічний інтеграл і підсумовування Блоха

Обчислимо макроскопічне зменшення намагніченості феромагнетика за температури `T`. Середня кількість збуджених магнонів визначається розподілом Бозе — Ейнштейна з нульовим хімічним потенціалом (`μ = 0`):

```
⟨n_q⟩ = 1 / [exp(ħ·ω(q) / (k_B·T)) - 1]
```

Сумарна втрата спонтанної намагніченості на одиницю об'єму кристала:

```
ΔM(T) = (g · μ_B / V) · ∑ ⟨n_q⟩
= (g · μ_B / (2·π)³) · ∫ d³q / [exp(D·q² / (k_B·T)) - 1]
```

Перейдемо до сферичних координат у `q`-просторі (`d³q = 4·π·q² dq`):

```
ΔM(T) = (g · μ_B / (2·π²)) · ∫₀^∞ [q² dq] / [exp(D·q² / (k_B·T)) - 1]
```

Зробимо безрозмірну заміну змінної `x = D·q² / (k_B·T)`, звідки `q = √(k_B·T / D) · √x`, `dq = (1/2) · √(k_B·T / D) · x^(-1/2) dx`:

```
q² dq = (1/2) · (k_B·T / D)³/² · √x dx
```

Підставивши вираз у термодинамічний інтеграл, винесемо температурний множник:

```
ΔM(T) = (g · μ_B / (4·π²)) · (k_B·T / D)³/² · ∫₀^∞ [√x dx] / [exp(x) - 1]
```

Еталонний безрозмірний інтеграл виражається через гамма-функцію Ейлера `Γ(z)` та дзета-функцію Рімана `ζ(z)`:

```
∫₀^∞ [x^(s-1) dx] / [exp(x) - 1] = Γ(s) · ζ(s)
```

Для нашого випадку `s = 3/2`:

```
Γ(3/2) = √π / 2 ≈ 0.8862
ζ(3/2) = ∑ (1 / n³/²) ≈ 2.6124
```

Отож, сумарне значення безрозмірного інтеграла дорівнює `0.8862 · 2.6124 ≈ 2.3151`.

Підставивши це значення у термодинамічний інтеграл, отримуємо остаточну формулу закону Блоха:

```
ΔM(T) / M(0) = [ ζ(3/2) / (32 · π³/²) ] · [ k_B · T / (2 · J · S) ]³/²
```

Числовий множник `ζ(3/2) / (32 · π³/²) ≈ 0.0587`.

#### Порівняльний аналіз для 1D, 2D та 3D систем (Теорема Мерміна — Вагнера)
Розглянемо вплив просторового виміру кристала `d` на термодинамічну стійкість магнітного порядку:
1. **Тривимірний кристал (3D):** Елемент об'єму `d³q ∝ q² dq`. Інтеграл при `q → 0` має вигляд `∫ (q² dq) / q² = ∫ dq`, який є абсолютно збіжним у нулі. Тривимірні магнетики володіють стійким феромагнетизмом при `T > 0 K`.
2. **Двовимірний кристал (2D):** Елемент площі `d²q ∝ q dq`. Інтеграл при `q → 0` має вигляд `∫ (q dq) / q² = ∫ dq / q = ln(q)|_0`. Інтеграл логарифмічно розбігається на нижній межі! Це означає, що при будь-якій ненульової температури `T > 0` кількість збуджених довгохвильових магнонів стає нескінченно великою, повністю руйнуючи спонтанну намагніченість.
3. **Одновимірний кристал (1D):** Елемент довжини `dq`. Інтеграл при `q → 0` має вигляд `∫ dq / q² = -1/q|_0`, який розбігається за степеневим законом `∝ 1/q`.

Цей результат математично пояснює сувору теорему Мерміна — Вагнера (1966): у 1D та 2D ізотропних магнітних системах із короткосяжною взаємодією спонтанний магнітний порядок за ненульових температур є неможливим. Наявність магнітної анізотропії `K_an > 0` вносить енергетичну щілину, яка зрізає розбіжність інтеграла на малій межі `q_min = √(K_an / D)`, роблячи двовимірний феромагнетизм можливим у дійсних 2D кристалах (таких як моношари `CrI_3`).
