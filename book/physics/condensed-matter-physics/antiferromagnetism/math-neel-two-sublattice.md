# 🧮 Двопідґраткова теорія середнього поля Нееля: математичний вивід температури Нееля, сприйнятливості та спін-флоп переходу

Ця вставка містить покроковий математичний вивід термодинамічних параметрів, рівнянь молекулярного поля, тензора магнітної сприйнятливості та критичних полів спінових фазових переходів для двопідґраткових антиферомагнетиків та феримагнетиків.

---

### 1. Ефективні молекулярні поля та вивід температури Нееля (T_N)

Розглянемо кристалічну ґратку, розділену на дві симетричні взаємопроникні кристалографічні підґратки `A` та `B`. Кожна підґратка містить `N / 2` магнітних іонів на одиницю об'єму із векторами спонтанної намагніченості `M_A` та `M_B`.

У наближенні середнього поля (молекулярного поля Вейсса — Нееля) ефективні магнітні поля `H_A` та `H_B`, що діють на спіни у вузлах відповідних підґраток за наявності зовнішнього поля `H_ext`, описуються рівняннями:

```
H_A = H_ext - λ_AB · M_B + λ_AA · M_A     [ефективне поле підґратки A]
H_B = H_ext - λ_AB · M_A + λ_BB · M_B     [ефективне поле підґратки B]
```

де:
- `λ_AB > 0` — безрозмірний коефіцієнт міжпідґраткового від'ємного (антиферомагнітного) обміну.
- `λ_AA = λ_BB > 0` — коефіцієнти внутрішньопідґраткового позитивного (феромагнітного) обміну між атомами однієї і тієї ж підґратки.

У парамагнітній області при високих температурах (`T > T_N`) намагніченості підґраток `M_A` та `M_B` є малими відгуками на зовнішнє поле й описуються класичним законом Кюрі:

```
M_A = (C / 2) · (H_A / T)                [закон Кюрі для підґратки A]
M_B = (C / 2) · (H_B / T)                [закон Кюрі для підґратки B]
```

де `C` — константа Кюрі для всієї системи на одиницю об'єму: `C = N · g² · μ_B² · S(S + 1) / (3 · k_B)`.

Підставивши вирази для ефективних полів `H_A` та `H_B` у рівняння закону Кюрі за відсутності зовнішнього магнітного поля (`H_ext = 0`), отримуємо лінійну систему двох однорідних рівнянь відносно підґраткових намагніченостей `M_A` та `M_B`:

```
M_A = (C / 2T) · (-λ_AB · M_B + λ_AA · M_A)
M_B = (C / 2T) · (-λ_AB · M_A + λ_AA · M_B)
```

Переносимо усі доданки в ліву частину й записуємо систему в матричному вигляді:

```
(T - (C / 2) · λ_AA) · M_A + ((C / 2) · λ_AB) · M_B = 0
((C / 2) · λ_AB) · M_A + (T - (C / 2) · λ_AA) · M_B = 0
```

Ненульовий спонтанний розв'язок для підґраткових намагніченостей `M_A` та `M_B` існує тоді і тільки тоді, коли детермінант цієї матриці дорівнює нулю:

```
det | T - (C / 2) · λ_AA       (C / 2) · λ_AB    |
    | (C / 2) · λ_AB       T - (C / 2) · λ_AA    | = 0
```

Розкриваємо детермінант:

```
(T - (C / 2) · λ_AA)² - ((C / 2) · λ_AB)² = 0
```

Добуваючи квадратний корінь, маємо два корені для температури:

```
T_1 = (C / 2) · (λ_AB + λ_AA)           [фізичний корінь: температура Нееля T_N]
T_2 = -(C / 2) · (λ_AB - λ_AA)          [нефізичний від'ємний корінь]
```

Найвища температура, при якій виникає ненульовий спонтанний антиферомагнітний порядок спінових підґраток, визначає **температуру Нееля** `T_N`:

```
T_N = (C / 2) · (λ_AB + λ_AA)           [температура Нееля]
```

### 2. Магнітна сприйнятливість у парамагнітній фазі (T > T_N)

При прикладанні зовнішнього магнітного поля `H_ext > 0` у парамагнітній фазі (`T > T_N`) підґратки намагнічуються симетрично: `M_A = M_B = M_net / 2`.

Підставляємо це у вираз для ефективного поля:

```
H_A = H_ext - λ_AB · (M_net / 2) + λ_AA · (M_net / 2)
```

Рівняння для сумарної намагніченості:

```
M_net / 2 = (C / 2T) · [ H_ext - (1/2) · (λ_AB - λ_AA) · M_net ]
```

Множимо обидві частини на 2 і виносимо `M_net`:

```
M_net · [ 1 + (C / 2T) · (λ_AB - λ_AA) ] = (C / T) · H_ext
```

Виражаємо парамагнітну сприйнятливість `χ = M_net / H_ext`:

```
χ = C / ( T + (C / 2) · (λ_AB - λ_AA) )
```

Отримуємо підсумковий **закон Кюрі — Вейсса для антиферомагнетика**:

```
χ = C / (T + θ_p)                        [закон Кюрі — Вейсса]
```

де **асимптотична температура Кюрі** `θ_p` виражається через константи обміну як:

```
θ_p = (C / 2) · (λ_AB - λ_AA)            [температура Вейсса]
```

Важливо підкреслити: знак плюс у знаменнику `(T + θ_p)` віддзеркалює антиферомагнітний характер обмінних сил (`λ_AB > 0`).

Співвідношення між асимптотичною температурою `θ_p` та температурою Нееля `T_N`:

```
θ_p / T_N = (λ_AB - λ_AA) / (λ_AB + λ_AA)
```

Якщо внутрішньопідґратковий обмін незначний (`λ_AA ≪ λ_AB`), то значення асимптотичної температури наближається до точки Нееля: `θ_p ≈ T_N`. Відхилення фактора фрустрації `f = θ_p / T_N` від 1.0 показує ступінь геометро-магнітного протиборства спінів у кристалічній ґратці.

### 3. Анізотропія сприйнятливості у впорядкованій фазі (T < T_N)

При охолодженні кристала нижче точки Нееля (`T < T_N`) відгук антиферомагнетика на зовнішнє поле є сильно анізотропним.

#### А. Перпендикулярне поле (H_ext ⊥ Easy Axis)

При прикладанні поля `H_ext` перпендикулярно до осі легкого намагнічування вектора `M_A` та `M_B` розвертаються на малий кут `φ` у напрямку поля.

Вільна енергія на одиницю об'єму у перпендикулярному полі:

```
F = λ_AB · (M_A · M_B) - H_ext · (M_A + M_B)_z
F = - λ_AB · M_0² · cos(2φ) - 2 · M_0 · H_ext · sin(φ)
```

Враховуючи малість кута `φ` (`cos(2φ) ≈ 1 - 2φ²`, `sin(φ) ≈ φ`):

```
F ≈ - λ_AB · M_0² + 2 · λ_AB · M_0² · φ² - 2 · M_0 · H_ext · φ
```

Мінімізуємо вільну енергію по куту `φ` (`dF / dφ = 0`):

```
4 · λ_AB · M_0² · φ - 2 · M_0 · H_ext = 0  ⇒  φ = H_ext / (2 · λ_AB · M_0)
```

Набута поперечна намагніченість:

```
M_perp = 2 · M_0 · sin(φ) ≈ 2 · M_0 · φ = H_ext / λ_AB
```

Звідси перпендикулярна сприйнятливість `χ_perp = M_perp / H_ext` є **абсолютно сталою і не залежить від температури**:

```
χ_perp = 1 / λ_AB = const                [перпендикулярна сприйнятливість]
```

#### Б. Паралельне поле (H_ext ∥ Easy Axis)

При прикладанні поля вздовж осі спінів вектор орієнтації не змінює свій кут, а поле лише трохи змінює модулі намагніченостей за рахунок температурного перерозподілу спінів:

```
M_parallel = M_A(H) - M_B(H)
```

Застосовуючи похідну функції Бріллюена `B_S'(x)` при `T → 0 K`, крутизна перерозподілу прямує до нуля, оскільки спіни жорстко зафіксовані внутрішнім обмінним полем `H_E`:

```
χ_parallel(0 K) = 0
χ_parallel(T_N) = χ_perp = 1 / λ_AB
```

#### В. Усереднення для полікристала

Для полікристалічного зразка із хаотично орієнтованими кристалітами середня сприйнятливість `χ_poly` становить:

```
χ_poly = (1/3) · χ_parallel + (2/3) · χ_perp
```

При `T = 0 K`, де `χ_parallel = 0`, сприйнятливість полікристала дорівнює точно **2/3** від максимуму при температурі Нееля:

```
χ_poly(0 K) = (2/3) · χ_perp
```

### 4. Точний вивід критичного поля спін-флоп переходу (H_sf)

Нехай зовнішнє поле `H_ext` прикладене паралельно до осі легкого намагнічування. Порівняємо вільні енергії двох можливих конфігурацій спінової системи.

1. **Паралельна (колінеарна) фаза:**
   Спіни залишаються паралельними осі анізотропії. Вільна енергія:
   ```
   F_par = - (1/2) · χ_parallel · H_ext² - K_anisotropy
   ```
   де `K_anisotropy` — енергія кристалографічної магнітної анізотропії.

2. **Перпендикулярна (спін-флоп) фаза:**
   Спіни повертаються майже перпендикулярно до осі поля. Вільна енергія:
   ```
   F_flop = - (1/2) · χ_perp · H_ext²
   ```

Спін-флоп перехід відбувається при рівності вільних енергій: `F_par = F_flop`:

```
- (1/2) · χ_parallel · H_sf² - K_anisotropy = - (1/2) · χ_perp · H_sf²
```

Виносимо квадрат критичного поля `H_sf²`:

```
(1/2) · (χ_perp - χ_parallel) · H_sf² = K_anisotropy
```

При низьких температурах (`T → 0 K`), де `χ_parallel → 0` та `χ_perp = 1 / λ_AB = M_0 / H_E`:

```
(1/2) · (M_0 / H_E) · H_sf² = K_anisotropy
```

Вводячи поле кристалографічної анізотропії `H_K = 2 · K_anisotropy / M_0`, отримуємо остаточну формулу для **поля спін-флоп переходу**:

```
H_sf = √(2 · H_E · H_K)                  [критичне поле спін-флоп]
```

де `H_E = λ_AB · M_0` — внутрішнє обмінне поле (порядок 100–1000 Тл), а `H_K` — поле анізотропії (порядок 0.1–1 Тл).

Спін-фліп перехід (повне схлопування підґраток у паралельний феромагнітний стан) відбувається у значно сильнішому полі:

```
H_flip = 2 · H_E + H_K ≈ 2 · H_E          [критичне поле спін-фліп]
```

### 5. Феримагнетизм: самоузгоджені рівняння та точка компенсації (T_comp)

Для феримагнетика з двома нееквівалентними підґратками `A` та `B` (з різними моментами насичення `M_A(0) ≠ M_B(0)` та різними коефіцієнтами обміну `λ_AA ≠ λ_BB`) самоузгоджені рівняння для підґраткових намагніченостей описуються функціями Бріллюена `B_S(x)`:

```
M_A(T) = M_A(0) · B_Sa( (g_a · μ_B · S_a / k_B T) · (λ_AB · M_B - λ_AA · M_A) )
M_B(T) = M_B(0) · B_Sb( (g_b · μ_B · S_b / k_B T) · (λ_AB · M_A - λ_BB · M_B) )
```

Оскільки функції `B_Sa(x)` та `B_Sb(x)` мають різну крутизну залежно від температури, криві намагніченостей підґраток `|M_A(T)|` та `|M_B(T)|` можуть перетинатися у внутрішній точці `T_comp < T_N`.

Умова виникнення **точки компенсації**:

```
|M_A(T_comp)| = |M_B(T_comp)|            [умова точки компенсації]
```

У точці компенсації `T_comp` результуюча спонтанна намагніченість речовини дорівнює нулю:

```
M_net(T_comp) = |M_A(T_comp) - M_B(T_comp)| = 0
```

при цьому мікроскопічний феримагнітний порядок та підґратки залишаються повністю збереженими.
