# 🧮 Квантовомеханічне виведення обмінного інтеграла та спінового гамільтоніана

Цей математичний вивід деталізує квантовомеханічний розрахунок двох-електронної системи на прикладі молекули водню (модель Гайтлера — Лондона), зв'язок із моделлю Габбарда для кінетичного та потенціального обміну, виведення спинової дисперсії магнонів у 1D та 3D ґратках через перетворення Гольштейна — Примакова та строгий алгебраїчний перехід від кулонівського інваріантного за спіном гамільтоніана до ефективного спінового гамільтоніана Гейзенберга — Дірака.

### 1. Постановка двоцентрової задачі двох електронів

Розглянемо два точкові ядра `A` та `B`, які закріплені у просторі на фіксованій міжатомній відстані `R_AB`, та два електрони `1` та `2`. Одночастинкові гамільтоніани для кожного електрона у полях відповідних ізольованих ядер мають вигляд:

```
Ĥ₀(1) = -ħ²/2m · ∇₁² - e² / (4π·ε₀ · r_A1)
Ĥ₀(2) = -ħ²/2m · ∇₂² - e² / (4π·ε₀ · r_B2)
```

де `r_A1` — відстань першого електрона від ядра `A`, а `r_B2` — відстань другого електрона від ядра `B`. Повний двох-електронний гамільтоніан системи враховує пряме кулонівське відштовхування електронів між собою, відштовхування двох позитивних ядер та перехресне притягання електронів до «чужих» ядер:

```
Ĥ = Ĥ₀(1) + Ĥ₀(2) + V̂_int
```

де оператор точечної електростатичної взаємодії `V̂_int` дорівнює:

```
V̂_int = e² / (4π·ε₀) · [ 1/r₁₂ + 1/R_AB - 1/r_A2 - 1/r_B1 ]
```

де `r₁₂ = |r₁ - r₂|` — відстань між електронами, `r_A2` — відстань від другого електрона до ядра `A`, а `r_B1` — відстань від першого електрона до ядра `B`.

### 2. Симетризовані просторові хвильові функції (Наближення Гайтлера — Лондона)

Позначимо нормовані одноелектронні атомарні орбіталі `φ_A(r)` та `φ_B(r)`. У наближенні Гайтлера — Лондона (корельований зв'язок valence bond) базис будується з вихідних добутків хвильових функцій:

```
ψ₁(r₁, r₂) = φ_A(r₁) · φ_B(r₂)      [електрон 1 біля ядра A, електрон 2 біля ядра B]
ψ₂(r₁, r₂) = φ_A(r₂) · φ_B(r₁)      [електрон 2 біля ядра A, електрон 1 біля ядра B]
```

Оскільки електрони є тотожними нерозрізними ферміонами, фізичні стани системи повинні володіти певною симетрією щодо оператора перестановки координат `P̂₁₂`. Власні просторові хвильові функції розбиваються на строго симетричну `ψ_S` та антисиметричну `ψ_A`:

```
ψ_S(r₁, r₂) = C_S · [ φ_A(r₁)·φ_B(r₂) + φ_A(r₂)·φ_B(r₁) ]
ψ_A(r₁, r₂) = C_A · [ φ_A(r₁)·φ_B(r₂) - φ_A(r₂)·φ_B(r₁) ]
```

Нормувальні константи `C_S` та `C_A` знаходяться з умов нормування `∬ |ψ|² d³r₁ d³r₂ = 1`:

```
C_S = 1 / √(2 · (1 + l²))      [нормування симетричної просторової функції]
C_A = 1 / √(2 · (1 - l²))      [нормування антисиметричної просторової функції]
```

де `l` — одночастинковий інтеграл перекриття електронних оболонок двох атомів:

```
l = ∫ φ_A*(r) · φ_B(r) d³r
```

Інтеграл перекриття `l` характеризує міру просторового накладання атомарних орбіталей. Для ізольованих атомів на великих відстанях `l → 0`, тоді як при зближенні атомів `l` зростає, досягаючи величин порядку `0.1 – 0.4`.

### 3. Точний розрахунок енергій та обмінного інтеграла

Обчислимо матричні елементи повного гамільтоніана `Ĥ = Ĥ₀(1) + Ĥ₀(2) + V̂_int`. Власні значення енергії `E_S` та `E_A` визначаються відповідними середніми інтегралами:

```
E_S = ⟨ψ_S| Ĥ |ψ_S⟩ = E₀ + (K + J) / (1 + l²)      [енергія синглетного стану S=0]
E_A = ⟨ψ_A| Ĥ |ψ_A⟩ = E₀ + (K - J) / (1 - l²)      [енергія триплетного стану S=1]
```

де `E₀ = E_A0 + E_B0` — сумарна енергія двох не взаємодіючих ізольованих атомів у їхніх основних станах. Математичні величини `K` та `J` є кулонівським та обмінним інтегралами відповідно:

- **Прямий кулонівський інтеграл `K`** (описує класичне електростатичне відштовхування між двома розпростертими електронними хмарами з густинами `|φ_A|²` та `|φ_B|²`):

```
K = ∬ |φ_A(r₁)|² · V̂_int · |φ_B(r₂)|² d³r₁ d³r₂
```

- **Квантовий обмінний інтеграл `J`** (описує кулонівське відштовхування перехресних інтерференційних густин `φ_A*(r₁)·φ_B(r₁)` та `φ_B*(r₂)·φ_A(r₂)`):

```
J = ∬ φ_A*(r₁)·φ_B*(r₂) · V̂_int · φ_A(r₂)·φ_B(r₁) d³r₁ d³r₂
```

Енергетичний розщеп між триплетним (`S = 1`) та синглетним (`S = 0`) станами дорівнює:

```
ΔE = E_A - E_S
   = [E₀ + (K - J)/(1 - l²)] - [E₀ + (K + J)/(1 + l²)]
   = [ (K - J)(1 + l²) - (K + J)(1 - l²) ] / (1 - l⁴)
   = [ K + K·l² - J - J·l² - K + K·l² - J + J·l² ] / (1 - l⁴)
   = -2 · [ J - K · l² ] / (1 - l⁴)                     [точна різниця енергій]
```

При малих інтегралах перекриття орбіталей `l ≪ 1` (що характерно для атомарних відстаней у кристалі) цей вираз спрощується до стандартної форми:

```
E_A - E_S ≈ -2 · J
```

Якщо обмінний інтеграл `J > 0`, енергія триплетного стану є нижчою (`E_A < E_S`), і системі енергетично вигідно мати паралельні спіни. При `J < 0` вигіднішим є синглетний стан з антипаралельними спінами.

### 4. Виведення спінового оператора Дірака та операторних тотожностей

За принципом Паулі повна хвильова функція системи двох електронів `Ψ(1, 2) = ψ_space(r₁, r₂) · χ_spin(s₁, s₂)` повинна бути строго антисиметричною. Для двох електронів зі спіном `1/2` існує 4 базисні спінові функції, утворені з одночастинкових спінорів Паулі `|↑⟩` та `|↓⟩`:

- **1 синглетний стан (`S = 0`, `M_S = 0`, антисиметричний):**

```
χ_S = 1/√2 · [ |↑⟩₁|↓⟩₂ - |↓⟩₁|↑⟩₂ ]
```

- **3 триплетні стани (`S = 1`, `M_S = +1, 0, -1`, симетричні):**

```
χ_T,+1 = |↑⟩₁|↑⟩₂
χ_T,0  = 1/√2 · [ |↑⟩₁|↓⟩₂ + |↓⟩₁|↑⟩₂ ]
χ_T,-1 = |↓⟩₁|↓⟩₂
```

Для знаходження оператора перестановки спінів `P̂₁₂^σ` розглянемо квадрат оператора повного спіну `Ŝ² = (Ŝ₁ + Ŝ₂)²`:

```
Ŝ² = Ŝ₁² + Ŝ₂² + 2 · (Ŝ₁ · Ŝ₂)
```

Оскільки для електрона зі спіном `1/2` власними значеннями квадрата одночастинкового спіну є `Ŝ₁² = Ŝ₂² = s(s + 1)·ħ² = 3/4 · ħ²`, маємо:

```
Ŝ² = 3/4·ħ² + 3/4·ħ² + 2·(Ŝ₁ · Ŝ₂)
   = 3/2·ħ² + 2·(Ŝ₁ · Ŝ₂)
```

Звідси підставляємо власні значення `Ŝ² = S(S + 1)·ħ²`:

```
(Ŝ₁ · Ŝ₂)_singlet = 1/2 · [ 0 - 3/2·ħ² ] = -3/4 · ħ²      [для S = 0]
(Ŝ₁ · Ŝ₂)_triplet = 1/2 · [ 2·ħ² - 3/2·ħ² ] = +1/4 · ħ²     [для S = 1]
```

Враховуючи, що оператор перестановки спінових координат `P̂₁₂^σ` діє на симетричний триплетний стан як `+1`, а на антисиметричний синглетний стан як `-1`, побудуємо лінійну комбінацію:

```
P̂₁₂^σ = A + B · (Ŝ₁ · Ŝ₂)
```

Складаємо систему з двох алгебраїчних рівнянь для синглету та триплету:

```
A + B · (-3/4 · ħ²) = -1      [умова для синглету]
A + B · (+1/4 · ħ²) = +1      [умова для триплету]
```

Віднімаючи перше рівняння від другого:

```
B · ħ² = 2  ⇒  B = 2 / ħ²
A = 1 - 2/ħ² · (1/4 · ħ²) = 1/2
```

Отримуємо фундаментальну **тотожність Поля Дірака**:

```
P̂₁₂^σ = 1/2 + 2/ħ² · (Ŝ₁ · Ŝ₂)
```

В матричній формі Паулі оператор скалярного добутку виражається через матриці Паулі `σ = (σ_x, σ_y, σ_z)`:

```
Ŝ₁ · Ŝ₂ = (ħ²/4) · (σ₁_x · σ₂_x + σ₁_y · σ₂_y + σ₁_z · σ₂_z)
```

### 5. Спіновий гамільтоніан Гейзенберга та зв'язок з моделлю Габбарда

Підставляючи проєкційні оператори на синглетний та триплетний стани `P̂_S = 1/4 - (Ŝ₁·Ŝ₂)/ħ²` та `P̂_A = 3/4 + (Ŝ₁·Ŝ₂)/ħ²` у вираз для ефективного оператора енергії `Ĥ_ex = E_S · P̂_S + E_A · P̂_A`, отримуємо:

```
Ĥ_ex = E_S · [ 1/4 - (Ŝ₁·Ŝ₂)/ħ² ] + E_A · [ 3/4 + (Ŝ₁·Ŝ₂)/ħ² ]
     = (E_S + 3·E_A)/4 - [(E_A - E_S)/ħ²] · (Ŝ₁ · Ŝ₂)
     = C - 2 · J_ex / ħ² · (Ŝ₁ · Ŝ₂)
```

де константа `C = (E_S + 3·E_A)/4` задає загальну зсунуту нульову точечну енергію, а обмінний параметр дорівнює `J_ex = (E_A - E_S) / 2`.

У багатоелектронних твердих тілах із сильною одновузловою кулонівською кореляцією `U` (модель Габбарда) обмінний інтеграл `J_eff` складається з двох конкуруючих внесків — потенціального обміну `J_pot > 0` та кінетичного обміну `J_kin < 0`:

```
J_eff = J_pot - 4·t² / U
```

де `t` — інтеграл перескоку (мобільності) електронів між сусідніми вузлами, а `U` — кулонівське відштовхування двох електронів на одному вузлі. Коли `U ≫ t` (мотт-хаббардівські діелектрики), кінетичний внесок `-4t²/U` стає домінуючим і створює сильний **антиферомагнітний** обмін.

### 6. Виведення дисперсії спинових хвиль (Магнонів) з гамільтоніана Гейзенберга

Проілюструємо потужність спинового гамільтоніана Гейзенберга на прикладі квантування магнонів у 1D та 3D феромагнітних кристалах. Розглянемо гамільтоніан:

```
Ĥ = -2 · J · ∑_i [ Ŝ_i^z · Ŝ_(i+1)^z + 1/2 · (Ŝ_i^+ · Ŝ_(i+1)^- + Ŝ_i^- · Ŝ_(i+1)^+) ]
```

де `Ŝ_i^± = Ŝ_i^x ± i·Ŝ_i^y` — підвищувальний та понижувальний оператори спіну.

За допомогою квантового **перетворення Гольштейна — Примакова** виражаємо спінові оператори через бозонні оператори народження `â_i†` та знищення `â_i` відхилень спіну:

```
Ŝ_i^z = S - â_i† · â_i
Ŝ_i^+ ≈ √(2S) · â_i
Ŝ_i^- ≈ √(2S) · â_i†
```

Підставляючи ці оператори в гамільтоніан та зберігаючи доданки другого порядку за бозонними операторами:

```
Ĥ ≈ -2·J·N·S² + 4·J·S · ∑_i â_i†·â_i - 2·J·S · ∑_i (â_i†·â_(i+1) + â_(i+1)†·â_i)
```

Переходячи до хвильового імпульсного простору за допомогою фур'є-перетворення `â_i = 1/√N · ∑_k exp(i·k·R_i) · â_k`:

```
Ĥ = E_G + ∑_k ħ·ω(k) · â_k† · â_k
```

де `E_G = -2·J·N·S²` — енергія основного стану (усі спіни паралельні), а закон дисперсії спінових хвиль (магнонів) `ħ·ω(k)` для 1D ланцюжка з періодом `a` дорівнює:

```
ħ·ω(k) = 4 · J · S · [ 1 - cos(k·a) ]
       = 8 · J · S · sin²(k·a / 2)
```

У тривимірній кубічній ґратці з координаційним числом `z = 6` та періодом `a` закони дисперсії поширюються на три виміри:

```
ħ·ω(k) = 2 · J · S · [ 6 - 2·cos(k_x·a) - 2·cos(k_y·a) - 2·cos(k_z·a) ]
```

При малих хвильових векторах `|k|·a ≪ 1` розклад тригонометричних функцій у ряд Тейлора дає квадратичну дисперсію магнонів у феромагнетику:

```
ħ·ω(k) ≈ (2 · J · S · a²) · k² = D · k²
```

де `D = 2·J·S·a²` — спинова жорсткість кристала.

Цей квантовий розрахунок доводить, що квазічастинки магнони є квантованими збудженнями спінових відхилень, чий закон дисперсії безпосередньо визначається величиною квантового обмінного інтеграла `J`.
