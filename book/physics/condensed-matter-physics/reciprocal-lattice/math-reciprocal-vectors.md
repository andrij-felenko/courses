# 🧮 Векторна алгебра та тотожності оберненої ґратки

Опис хвильових процесів у періодичних кристалічних структурах спирається на лінійну алгебру, тензорний аналіз та взаємну ортогональність векторних базисів прямого та оберненого просторів.

## Алгебраїчне означення базису оберненої ґратки

Нехай кристалічна ґратка у тривимірному евклідовому просторі координат `r` задається трьома некомпланарними вектором трансляції `a₁`, `a₂`, `a₃`. Об'єм примітивної елементарної комірки прямого простору визначається мішаним скалярно-векторним добутком:

```
V_cell = a₁ · (a₂ × a₃)
```

Базисні вектори оберненої ґратки `b₁`, `b₂`, `b₃` за означенням конструюються таким чином, щоб вектор `b₁` був строго ортогональним до площини векторів `a₂` та `a₃`, вектор `b₂` — до площини `a₃` та `a₁`, а вектор `b₃` — до площини `a₁` та `a₂`:

```
b₁ = 2π · (a₂ × a₃) / V_cell
b₂ = 2π · (a₃ × a₁) / V_cell
b₃ = 2π · (a₁ × a₂) / V_cell
```

Множник `2π` забезпечує фізичну розмірність хвильового вектора (рад/м) та прямо зв'язує імпульс частинки з її хвильовим вектором за формулою де Бройля `p = ℏ · k`. У деяких кристалографічних джерелах множник `2π` опускають (визначаючи `b₁ = (a₂ × a₃) / V_cell`), однак у фізиці твердого тіла та квантовій механіці використання множника `2π` є канонічним стандартом.

## Доведення фундаментальної умови дуальності

Скалярний добуток будь-якого базисного вектора реального простору `aᵢ` на базисний вектор оберненого простору `bⱼ` задовольняє умову Кронекера:

```
aᵢ · bⱼ = 2π · δᵢⱼ
```

де `δᵢⱼ = 1` при `i = j` та `δᵢⱼ = 0` при `i ≠ j`.

Строге виведення для діагонального елемента `a₁ · b₁`:

```
a₁ · b₁
= a₁ · (2π · (a₂ × a₃) / (a₁ · (a₂ × a₃)))    [застосовано алгебраїчне означення b₁]
= 2π · (a₁ · (a₂ × a₃)) / (a₁ · (a₂ × a₃))   [винесено скалярний множник 2π]
= 2π                                         [скорочено однаковий об'єм комірки V_cell]
```

Для позадіагонального елемента `a₁ · b₂`:

```
a₁ · b₂
= a₁ · (2π · (a₃ × a₁) / V_cell)             [застосовано алгебраїчне означення b₂]
= (2π / V_cell) · (a₁ · (a₃ × a₁))          [переставна властивість мішаного добутку]
= (2π / V_cell) · 0                         [векторний добуток a₃ × a₁ перпендикулярний до a₁]
= 0
```

Аналогічно доводиться ортогональність для усіх інших дев'яти комбінацій пар індексів `(i, j)`.

У матричній формі співвідношення між матрицею прямих векторів `A = [a₁  a₂  a₃]` (де базисні вектори записані у вигляді стовпчиків) та матрицею обернених векторів `B = [b₁  b₂  b₃]ᵀ` (де вектори записані у вигляді рядків) набуває вигляду:

```
B · A = 2π · I
```

де `I` — одинична матриця розміру `3 × 3`. Звідси випливає фундаментальний операторний зв'язок:

```
B = 2π · A⁻¹
```

Транспонована матриця обернених базисних векторів дорівнює оберненій матриці прямого базису, помноженій на `2π`.

## Зв'язок метричних тензорів прямого та оберненого просторів

У довільній косокутній системі координат геометричні властивості простору визначаються коваріантним метричним тензором прямої ґратки `g_ij`:

```
g_ij = aᵢ · aⱼ
```

Матриця метричного тензора `G_mat` має елементи:

```
G_mat = [
  a₁·a₁  a₁·a₂  a₁·a₃
  a₂·a₁  a₂·a₂  a₂·a₃
  a₃·a₁  a₃·a₂  a₃·a₃
]
```

Визначник цієї матриці дорівнює квадрату об'єму примітивної комірки: `det(G_mat) = (V_cell)²`.

Метричний тензор оберненої ґратки `g^ij` визначається як скалярний добуток векторів оберненого базису:

```
g^ij = bᵢ · bⱼ
```

Використовуючи матричне співвідношення `B = 2π · A⁻¹`, легко довести, що метричний тензор оберненої ґратки є строго оберненою матрицею до метричного тензора прямої ґратки з масштабуванням `(2π)²`:

```
g^ij = (2π)² · (g_ij)⁻¹
```

Це співвідношення є основою тензорного обчислення у кристаллографії та дозволяє легко обчислювати скалярні добутки векторів, скалярні квадрати та кути між векторами у косокутних кристалографічних системах.

## Зв'язок об'ємів елементарних комірок

Знайдемо об'єм примітивної комірки оберненого простору `V_BZ = b₁ · (b₂ × b₃)` через об'єм примітивної комірки реального простору `V_cell`:

```
b₂ × b₃
= (2π / V_cell)² · ((a₃ × a₁) × (a₁ × a₂))                     [підставлено означення b₂ та b₃]
= (2π / V_cell)² · (a₁ · (a₃ · (a₁ × a₂)) − a₂ · (a₃ · (a₁ × a₁))) [застосовано тотожність векторного добутку]
= (2π / V_cell)² · a₁ · (a₁ · (a₂ × a₃))                       [ураховано a₁ × a₁ = 0 та цикл зміщення]
= (2π / V_cell)² · a₁ · V_cell
= (2π / V_cell) · a₁
```

Помноживши скалярно на `b₁ = 2π · (a₂ × a₃) / V_cell`, отримуємо:

```
V_BZ
= b₁ · (b₂ × b₃)
= (2π · (a₂ × a₃) / V_cell) · ((2π / V_cell) · a₁)             [підставлено результати]
= (2π / V_cell)² · (a₁ · (a₂ × a₃))                            [перегруповано скалярні множники]
= (2π)³ / V_cell                                              [скорочено V_cell]
```

Отже, **об'єм елементарної комірки оберненої ґратки обернено пропорційний об'єму комірки прямого простору**:

```
V_BZ = (2π)³ / V_cell
```

## Ортогональність вектора G до атомних площин (hkl) та міжплощинна відстань

Нехай `G = h·b₁ + k·b₂ + l·b₃` — вектор оберненої ґратки з цілочисельними індексами Міллера `(hkl)`. Розглянемо сім'ю паралельних атомних площин у реальному просторі. Перша площина, що не проходит через початок координат, відтинає на осях трансляції відрізки `(1/h)·a₁`, `(1/k)·a₂`, `(1/l)·a₃`.

Побудуємо вектор `v₁₂`, який лежить у цій атомній площині, з'єднуючи точки перетину на осях `a₁` та `a₂`:

```
v₁₂ = (1/k)·a₂ − (1/h)·a₁
```

Обчислимо скалярний добуток вектора `G` на вектор `v₁₂`:

```
G · v₁₂
= (h·b₁ + k·b₂ + l·b₃) · ((1/k)·a₂ − (1/h)·a₁)
= (k/k) · (b₂ · a₂) − (h/h) · (b₁ · a₁)       [ураховано aᵢ · bⱼ = 0 при i ≠ j]
= 1 · 2π − 1 · 2π                              [застосовано aᵢ · bᵢ = 2π]
= 0
```

Оскільки скалярний добуток дорівнює нулю, **вектор оберненої ґратки `G[hkl]` строго перпендикулярний до атомних площин з індексами Міллера `(hkl)`**.

Міжплощинна відстань `d[hkl]` дорівнює проєкції вектора `(1/h)·a₁` на одиничний вектор нормалі `n = G / |G|`:

```
d[hkl]
= (1/h) · a₁ · (G / |G|)
= (1/h) · a₁ · ((h·b₁ + k·b₂ + l·b₃) / |G|)
= (1/h) · (h · 2π) / |G|                      [ураховано a₁ · b₁ = 2π]
= 2π / |G[hkl]|
```

Таким чином, міжплощинна відстань обернено пропорційна довжині вектора оберненої ґратки:

```
d[hkl] = 2π / |G[hkl]|
```

## Виведення формул міжплощинної відстані d[hkl] для різних кристалографічних сингоній

Завдяки формулі `d[hkl] = 2π / |G[hkl]|`, розрахунок міжплощинних відстаней для будь-якої кристалографічної системи зводиться до обчислення квадрата довжини вектора `|G[hkl]|² = G[hkl] · G[hkl]`.

### 1. Кубічна сингонія (`a = b = c`, `α = β = γ = 90°`)
Для кубічної ґратки вектори оберненого базису мають довжину `|b₁| = |b₂| = |b₃| = 2π / a` і є взаємно ортогональними. Скалярний квадрат вектора `G[hkl]` дорівнює:

```
|G[hkl]|²
= (h·b₁ + k·b₂ + l·b₃)²
= (2π / a)² · (h² + k² + l²)
```

Звідси отримуємо класичну формулу міжплощинної відстані кубічних кристалів:

```
1 / (d[hkl])² = (h² + k² + l²) / a²
```

### 2. Тетрагональна сингонія (`a = b ≠ c`, `α = β = γ = 90°`)
Вектори оберненого базису мають довжини `|b₁| = |b₂| = 2π / a` та `|b₃| = 2π / c`. Формула міжплощинної відстані:

```
1 / (d[hkl])² = (h² + k²) / a² + l² / c²
```

### 3. Орторомбічна сингонія (`a ≠ b ≠ c`, `α = β = γ = 90°`)
Вектори оберненого базису `|b₁| = 2π / a`, `|b₂| = 2π / b`, `|b₃| = 2π / c`. Формула міжплощинної відстані:

```
1 / (d[hkl])² = h² / a² + k² / b² + l² / c²
```

### 4. Гексагональна сингонія (`a = b ≠ c`, `α = β = 90°`, `γ = 120°`)
У реальному просторі кут між вектором `a₁` та `a₂` дорівнює 120°. В оберненому просторі кут між вектором `b₁` та `b₂` дорівнює 60°, а `|b₁| = |b₂| = 4π / (a · √3)`. Скалярний добуток `b₁ · b₂ = |b₁|·|b₂|·cos(60°) = (4π / (a · √3))² · 0.5`.

Обчислюємо квадрат довжини вектора `G[hkl]`:

```
|G[hkl]|²
= h² · |b₁|² + k² · |b₂|² + 2 h k · (b₁ · b₂) + l² · |b₃|²
= (16 π² / (3 a²)) · (h² + k² + h k) + (4 π² / c²) · l²
```

Поділивши на `4 π²`, отримуємо формулу міжплощинної відстані гексагональної сингонії:

```
1 / (d[hkl])² = (4 / 3) · (h² + h k + k²) / a² + l² / c²
```

## Перетворення ґраток SC, BCC та FCC у k-просторі

Розглянемо базиси оберненого простору для трьох кубічних кристалографічних систем із параметром ґратки `a`:

### 1. Проста кубічна ґратка (SC)
Прямий базис:
```
a₁ = a · (1, 0, 0)
a₂ = a · (0, 1, 0)
a₃ = a · (0, 0, 1)
```
За формулами Евальда обернений базис має вигляд:
```
b₁ = (2π / a) · (1, 0, 0)
b₂ = (2π / a) · (0, 1, 0)
b₃ = (2π / a) · (0, 0, 1)
```
Обернена ґратка до простої кубічної (SC) є також **простою кубічною (SC)** з параметром ґратки `2π / a`.

### 2. Об'ємноцентрована кубічна ґратка (BCC)
Примітивні вектори трансляції BCC у прямому просторі:
```
a₁ = (a / 2) · (−1, 1, 1)
a₂ = (a / 2) · (1, −1, 1)
a₃ = (a / 2) · (1, 1, −1)
```
Об'єм примітивної комірки `V_cell = a³ / 2`. Обчислимо `b₁`:
```
a₂ × a₃ = (a / 2)² · ((1, −1, 1) × (1, 1, −1)) = (a² / 4) · (0, 2, 2) = (a² / 2) · (0, 1, 1)
b₁ = 2π · ((a² / 2) · (0, 1, 1)) / (a³ / 2) = (2π / a) · (0, 1, 1)
```
Аналогічно отримуємо:
```
b₁ = (2π / a) · (0, 1, 1)
b₂ = (2π / a) · (1, 0, 1)
b₃ = (2π / a) · (1, 1, 0)
```
Ці вектори утворюють примітивний базис **гранецентрованої кубічної ґратки (FCC)** у `k`-просторі.

### 3. Гранецентрована кубічна ґратка (FCC)
Примітивні вектори трансляції FCC у прямому просторі:
```
a₁ = (a / 2) · (0, 1, 1)
a₂ = (a / 2) · (1, 0, 1)
a₃ = (a / 2) · (1, 1, 0)
```
Об'єм примітивної комірки `V_cell = a³ / 4`. За формулами Евальда обернені вектори мають вигляд:
```
b₁ = (2π / a) · (−1, 1, 1)
b₂ = (2π / a) · (1, −1, 1)
b₃ = (2π / a) · (1, 1, −1)
```
Обернена ґратка до гранецентрованої кубічної (FCC) є **об'ємноцентрованою кубічною ґраткою (BCC)** у `k`-просторі.

## Структурний фактор та правило погасання дифракційних рефлексів

Інтенсивність розсіяного випромінювання від складної елементарної комірки з декількома атомами пропорційна квадрату модуля **структурного фактора** `F[hkl]`:

```
F[hkl] = ∑ f_j · e^(i G[hkl] · r_j)
```

де `r_j = x_j · a₁ + y_j · a₂ + z_j · a₃` — відносні координати `j`-го атома в комірці, а `f_j` — атомний фактор розсіювання.

Використовуючи тотожність `G[hkl] · r_j = 2π · (h x_j + k y_j + l z_j)`, вираз для структурного фактора зводиться до суми:

```
F[hkl] = ∑ f_j · e^(i 2π (h x_j + k y_j + l z_j))
```

### 1. Згасання рефлексів для об'ємноцентрованої кубічної ґратки (BCC)
У звичайній кубічній комірці BCC присутні два однакові атоми з координатами `r₁ = (0, 0, 0)` та `r₂ = (1/2, 1/2, 1/2)`:

```
F[hkl]
= f · (1 + e^(i π (h + k + l)))
```

Оскільки `e^(i π N) = (-1)^N` для цілого `N`, маємо:
- Якщо сума `h + k + l` є **парним числом**: `F[hkl] = 2 f` (дифракційний рефлекс існує).
- Якщо сума `h + k + l` є **непарним числом**: `F[hkl] = 0` (рефлекс повністю гасне внаслідок деструктивної інтерференції).

### 2. Згасання рефлексів для гранецентрованої кубічної ґратки (FCC)
У комірці FCC присутні чотири однакові атоми з координатами `(0,0,0)`, `(1/2,1/2,0)`, `(1/2,0,1/2)`, `(0,1/2,1/2)`:

```
F[hkl] = f · (1 + e^(i π (h + k)) + e^(i π (h + l)) + e^(i π (k + l)))
```

Аналіз цієї суми дає правило згасання для FCC:
- Якщо індекси `h, k, l` є **однорідними** (усі парні або усі непарні): `F[hkl] = 4 f` (інтенсивний рефлекс).
- Якщо індекси `h, k, l` є **змішаними** (наприклад, один парний та два непарні): `F[hkl] = 0` (рефлекс повністю відсутній).

Таким чином, розрахунок структурного фактора в оберненій ґратці пояснює систематичні згасання дифракційних рефлексів у рентгеноструктурному аналізі монокристалів.
