# 🧮 Математичний вивід теорії середнього поля Вейсса та функції Бріллюена

Кількісний термодинамічний опис фазового переходу між парамагнітним та феромагнітним станами вимагає розв'язання задачі квантової статистичної механіки для ансамблю взаємодіючих атомних спінів. Оскільки точне врахування багатчасточкових обмінних кореляцій для тривимірної кристалічної ґратки є аналітично неможливим, теорія середнього поля Вейсса замінює складну багаточастинкову взаємодію одночастинковою задачею про рух квантового диполя у самоузгодженому ефективному полі `H_eff = H + λ · M`. Це дає змогу вивести аналітичні вирази для спонтанної намагніченості, парамагнітної сприйнятливості, критичного показника `β = 1/2` та скачка магнітної теплоємності при фазовому переході другого роду.

---

### 1. Квантовий гамільтоніан та одночастинкова статистична сума

Розглянемо макроскопічну систему `N` однакових магнітних іонів у одиниці об'єму кристалічної ґратки. Кожен іон володіє повним квантовим кутовим моментом `J` (або спіновим моментом `S`) та пов'язаним із ним магнітним дипольним моментом:

```
μ = g · μ_B · J
```

де `g` — безрозмірний фактор квантового розщеплення Ланде, а `μ_B = e · ħ / (2 · m_e)` — магнетон Бора.

У класичному наближенні Вейсса складний квантовий гамільтоніан Гейзенберга `H_ex = - 2 ∑_{i,j} J_{ij} (S_i · S_j)` замінюється на суму одночастинкових гамільтоніанів у зовнішньому та внутрішньому ефективному магнітному полі:

```
B_eff = μ_0 · H_eff = μ_0 · (H + λ · M)
```

де `H` — напруженість зовнішнього магнітного поля, `λ` — безрозмірний коефіцієнт молекулярного поля Вейсса, а `M` — локальна векторна намагніченість речовини.

Обираючи напрямок ефективного магнітного поля вздовж квантувальної осі `z`, зеєманівський гамільтоніан одиночного магнітного іона записується як:

```
H_1 = - (μ · B_eff) = - g · μ_B · m_J · B_eff
```

Квантове число проєкції кутового моменту `m_J` набуває `(2J + 1)` дискретних значень із кроком одиниця:

```
m_J ∈ { -J, -J + 1, ..., J - 1, J }
```

Згідно зі статистичною механікою Ґіббса, ймовірність `P(m_J)` того, що іон перебуває у стані з проєкцією `m_J` при температурі `T`, описується розподілом Больцмана:

```
P(m_J) = [ exp( (g · μ_B · m_J · B_eff) / (k_B · T) ) ] / Z_1
```

де `Z_1` — одночастинкова статистична сума ансамблю, яка є нормувальним множником:

```
Z_1 = ∑_{m_J = -J}^{J} exp( (g · μ_B · m_J · B_eff) / (k_B · T) )
```

Ввівши безрозмірний енергетичний параметр `x`, який дорівнює відношенню максимальної магнітної енергії спіна у полі `B_eff` до теплової енергії `k_B · T`:

```
x = (g · μ_B · J · B_eff) / (k_B · T) = [ g · μ_B · J · μ_0 · (H + λ · M) ] / [ k_B · T ]
```

Перепишемо статистичну суму `Z_1` через параметр `x`:

```
Z_1(x) = ∑_{m_J = -J}^{J} exp( (x / J) · m_J )
```

Ця сума являє собою скінченну симетричну геометричну прогресію з `(2J + 1)` членів із першим членом `a_1 = exp(-x)` та знаменником `r = exp(x / J)`. Застосовуючи формулу суми геометричної прогресії `S = a_1 · (r^{2J+1} - 1) / (r - 1)`:

```
Z_1(x) = exp(-x) · [ exp( (2J + 1) · x / J ) - 1 ] / [ exp( x / J ) - 1 ]
```

Помноживши чисельник і знаменник на `exp( - x / (2J) )` та використовуючи означення гіперболічного синуса `sinh(u) = (exp(u) - exp(-u)) / 2`, отримуємо точний вираз для статистичної суми:

```
Z_1(x) = [ sinh( (2J + 1) · x / (2J) ) ] / [ sinh( x / (2J) ) ]
```

### 2. Математичне виведення функції Бріллюена та граграничні випадки

Середній квантово-механічний магнітний момент іона `<μ_z>` уздовж напрямку поля обчислюється як статистичне середнє:

```
<μ_z> = ∑_{m_J = -J}^{J} (g · μ_B · m_J) · P(m_J)
```

У статистичній термодинаміці ця величина обчислюється значно простіше — через логарифмічну похідну статистичної суми по безрозмірному полю `B_eff`:

```
<μ_z> = k_B · T · ( ∂ ln Z_1 / ∂ B_eff ) = g · μ_B · J · [ (1 / J) · ( ∂ ln Z_1 / ∂ (x / J) ) ]
```

Обчислимо логарифмічну похідну `d/dx [ ln Z_1(x) ]`:

```
d/dx [ ln Z_1(x) ] = d/dx [ ln sinh( (2J + 1) · x / (2J) ) - ln sinh( x / (2J) ) ]
                    = [ (2J + 1) / (2J) ] · coth( (2J + 1) · x / (2J) ) - [ 1 / (2J) ] · coth( x / (2J) )
```

Ця фундаментальна математична комбінація гіперболічних котангенсів називається **функцією Бріллюена** `B_J(x)`:

```
B_J(x) = [ (2J + 1) / (2J) ] · coth( (2J + 1) · x / (2J) ) - [ 1 / (2J) ] · coth( x / (2J) )
```

Тоді макроскопічна намагніченість речовини `M`, яка дорівнює сумарному магнітному моменту всіх `N` іонів в одиниці об'єму, становить:

```
M(T, H) = N · <μ_z> = (N · g · μ_B · J) · B_J(x) = M_0 · B_J(x)
```

де `M_0 = N · g · μ_B · J` — намагніченість повного насичення при `T = 0 K`.

#### Аналіз граграничних випадків квантового моменту J

1. **Граничний випадок `J = 1/2` (чисто спіновий електронний магнетизм):**
   Підставивши `J = 1/2` у формулу Бріллюена:

   ```
   B_{1/2}(x) = [ 2 / 1 ] · coth( 2 · x / 1 ) - [ 1 / 1 ] · coth( x / 1 ) = 2 · coth(2x) - coth(x)
   ```

   Використовуючи тригонометричну тотожність для котангенса подвійного аргументу `coth(2x) = (1 + coth²(x)) / (2 · coth(x))`:

   ```
   B_{1/2}(x) = [ (1 + coth²(x)) / coth(x) ] - coth(x) = 1 / coth(x) = tanh(x)
   ```

   Отже, для спіна `J = 1/2` функція Бріллюена строго перетворюється на гіперболічний тангенс `tanh(x)`.

2. **Класичний граничний випадок `J → ∞` (класичний магнітний диполь Ланжевена):**
   У границі неперервного орієнтування класичного диполя (`J → ∞`) зробимо заміну `u = x`:

   ```
   lim_{J → ∞} B_J(x) = coth(x) - 1 / x = L(x)
   ```

   де `L(x)` — класична **функція Ланжевена**, яка описує орієнтацію класичних магнітних стрілок.

#### Степеневий розклад функції Бріллюена при малих полях (x << 1)

Для аналітичного аналізу парамагнітної фази розкладемо `coth(u)` у ряд Тейлора поблизу нуля:

```
coth(u) = 1 / u + u / 3 - u³ / 45 + (2 · u⁵) / 945 - ...
```

Підставивши цей розклад у функцію Бріллюена `B_J(x)` та звівши подібні члени:

```
B_J(x) = [ (J + 1) / (3 · J) ] · x - [ (J + 1) · ((2J + 1)² + 1) / (90 · J³) ] · x³ + O(x⁵)
```

Перший лінійний коефіцієнт `(J + 1) / (3J)` є ключовим для виведення закону Кюрі.

### 3. Точний математичний вивід закону Кюрі — Вейсса

Розглянемо парамагнітну область вище точки Кюрі (`T > T_C`) у слабких зовнішніх полях (`H << H_mol`). В цьому режимі намагніченість мала, тому безрозмірний параметр `x << 1`.

Обмежуючись першим лінійним членом розкладу функції Бріллюена:

```
M ≈ M_0 · [ (J + 1) / (3 · J) ] · x
```

Підставивши вирази для `M_0 = N · g · μ_B · J` та `x = [ g · μ_B · J · μ_0 · (H + λ · M) ] / [ k_B · T ]`:

```
M = (N · g · μ_B · J) · [ (J + 1) / (3 · J) ] · [ g · μ_B · J · μ_0 · (H + λ · M) / (k_B · T) ]
  = [ N · g² · μ_B² · J · (J + 1) · μ_0 / (3 · k_B · T) ] · (H + λ · M)
```

Ввівши квантову **константу Кюрі** `C`:

```
C = [ N · g² · μ_B² · J · (J + 1) · μ_0 ] / [ 3 · k_B ]
```

Рівняння для намагніченості набуває прозорого вигляду:

```
M = (C / T) · (H + λ · M)
```

Перенесемо члени з намагніченістю `M` у ліву частину та винесемо `M` за дужки:

```
M · T - C · λ · M = C · H
M · (T - C · λ) = C · H
```

Визначивши **парамагнітну температуру Кюрі** `T_C` як:

```
T_C = C · λ = [ N · g² · μ_B² · J · (J + 1) · μ_0 · λ ] / [ 3 · k_B ]
```

Розділивши обидві частини на `H`, отримуємо точний аналітичний вираз для магнітної сприйнятливості:

```
χ = M / H = C / (T - T_C)
```

### 4. Виведення критичного показника β та термодинамічного потенціалу Ландау

Нижче точки Кюрі (`T < T_C`) за відсутності зовнішнього поля (`H = 0`) в системі існує спонтанна намагніченість `M_s > 0`.

Для спіна `J = 1/2` рівняння самоузгодження має вигляд `m = tanh(m · T_C / T)`, де `m = M_s / M_0`.

Розглянемо граничний випадок безпосередньо поблизу точки Кюрі знизу (`T → T_C⁻`). У цьому інтервалі `m << 1`, тому розкладемо гіперболічний тангенс у ряд Тейлора до третього порядку:

```
tanh(y) = y - (1 / 3) · y³ + (2 / 15) · y⁵ - ...
```

Підставивши `y = m · (T_C / T)`:

```
m = (m · T_C / T) - (1 / 3) · m³ · (T_C / T)³
```

Оскільки впорядкований стан має `m ≠ 0`, розділимо обидві частини рівняння на `m`:

```
1 = (T_C / T) - (1 / 3) · m² · (T_C / T)³
```

Виразимо `(1 / 3) · m² · (T_C / T)³`:

```
(1 / 3) · m² · (T_C / T)³ = (T_C / T) - 1 = (T_C - T) / T
```

Поблизу критичної точки `(T_C / T) ≈ 1`, тому можна замінити `(T_C / T)³ ≈ 1` у лівій частині та `T ≈ T_C` у знаменнику правої частини:

```
(1 / 3) · m² ≈ (T_C - T) / T_C = 1 - T / T_C
```

Звідси отримуємо фундаментальний степеневий закон спонтанної намагніченості у теорії середнього поля:

```
m(T) = M_s(T) / M_0 = \sqrt{ 3 · (1 - T / T_C) }
```

Зіставляючи цей результат із загальним феноменологічним співвідношенням теорії фазових переходів `M_s ∝ (1 - T / T_C)^β`, виводимо точне значення **критичного показника**:

```
β = 1 / 2 = 0.5
```

#### Зв'язок із мікроскопічним розкладом вільної енергії Ландау

Обчислимо повну вільну енергію Гельмгольца `F(M, T)` одиниці об'єму у наближенні середнього поля. Вільна енергія дорівнює:

```
F(M, T) = - N · k_B · T · ln Z_1 + (1 / 2) · μ_0 · λ · M² - M · H
```

Розклавши `ln Z_1` у ряд по намагніченості `M` поблизу `M = 0`:

```
F(M, T) = F_0(T) + (1 / 2) · a_0 · (T - T_C) · M² + (1 / 4) · b · M⁴ - M · H
```

де феноменологічні коефіцієнти Ландау строго виражаються через мікроскопічні константи:

```
a_0 = μ_0 / C = [ 3 · k_B ] / [ N · g² · μ_B² · J · (J + 1) ]
b = [ 9 · k_B · T_C · ((2J + 1)² + 1) ] / [ 20 · N³ · g⁴ · μ_B⁴ · J² · (J + 1)² ]
```

Умова мінімуму вільної енергії `∂F / ∂M = 0` за відсутності поля (`H = 0`) дає:

```
a_0 · (T - T_C) · M + b · M³ = 0
```

- При `T > T_C` коефіцієнт перед `M` позитивний, єдиним мінімумом є `M = 0`.
- При `T < T_C` коефіцієнт від'ємний, виникає два симетричних мінімуми `M_s = ± \sqrt{ a_0 · (T_C - T) / b }`, що ідеально відповідає виведеному показнику `β = 1/2`.

### 5. Магнітна ентропія та скачок теплоємності

Магнітна ентропія `S_m` одиниці об'єму системи обчислюється як температурна похідна вільної енергії:

```
S_m = - ( ∂F / ∂T )
```

У високотемпературній парамагнітній фазі (`T >> T_C`) усі `(2J + 1)` квантових станів кожного іона є рівноймовірними, тому молярна магнітна ентропія досягає свого теоретичного максимуму:

```
S_max = N_A · k_B · ln(2J + 1) = R · ln(2J + 1)
```

При зниженні температури нижче `T_C` виникає внутрішнє молекулярне поле, яке впорядковує спіни. Ентропія спадає, і при `T → 0 K` прямує до нуля (`S_m = 0`), що строго відповідає третьому началу термодинаміки (теоремі Нернста).

Внутрішня магнітна енергія `E_m` одиниці об'єму у середньому полі дорівнює:

```
E_m = - (1 / 2) · μ_0 · λ · M²
```

Обчислимо магнітну теплоємність `C_m = dE_m / dT`:

- **Для `T > T_C`:** Спонтанна намагніченість `M = 0`, тому `E_m = 0` і `C_m = 0`.
- **Для `T → T_C⁻`:** Використовуючи розклад `M² ≈ M_0² · 3 · (1 - T / T_C)`:

```
d (M²) / dT = - 3 · M_0² / T_C
```

Підставивши це значення у вираз для теплоємності при `T → T_C⁻`:

```
C_m(T_C⁻) = - (1 / 2) · μ_0 · λ · ( - 3 · M_0² / T_C ) = (3 / 2) · [ μ_0 · λ · M_0² / T_C ]
```

Враховуючи, що `T_C = C · λ` та `C = [ N · g² · μ_B² · J · (J + 1) · μ_0 ] / [ 3 · k_B ]`, для спіна `J = 1/2` маємо `M_0 = (1/2) N g μ_B`. 

Підставивши ці параметри, отримуємо точне значення скачка молярної магнітної теплоємності при `T = T_C`:

```
ΔC_m = C_m(T_C⁻) - C_m(T_C⁺) = (3 / 2) · N_A · k_B = (3 / 2) · R
```

Наявність цього скінченного скачка `ΔC_m = 1.5 · R` без поглинання або виділення прихованої теплоти фазового переходу строго підтверджує, що наближення середнього поля Вейсса описує фазовий перехід другого роду.
