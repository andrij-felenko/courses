# Закон Кюрі — Вейсса та фазові переходи у феромагнетиках

<preknowlist>
- [Феромагнетизм](book:physics/condensed-matter-physics/ferromagnetism) — спонтанне паралельне впорядкування магнітних моментів у твердому тілі.
- [Точка Кюрі](book:physics/condensed-matter-physics/curie-temperature) — температура критичного переходу між феромагнітним та парамагнітним станами.
- [Обмінна взаємодія](book:physics/condensed-matter-physics/exchange-interaction) — квантово-механічна природа внутрішнього магнітного впорядкування.
</preknowlist>

Якщо нагріти зразок чистого нікелю (`Ni`) вище температури 354 °C (627 K) або заліза (`Fe`) понад 770 °C (1043 K), спонтанна намагніченість речовини повністю зникає. Метал перестає притягуватися до постійного магніту й поводиться як парамагнетик. Проте якщо помістити цей розжарений зразок у чутливий магнітометр і виміряти його магнітну сприйнятливість `χ` як функцію температури `T` у зовнішньому полі, виявиться вражаючий парадокс: речовина не підпорядковується класичному закону Кюрі `χ = C / T`, сформульованому для незалежних магнітних диполів. Графік оберненої сприйнятливості `1 / χ` утворює пряму лінію, але вона прямує до нуля не при абсолютному нулі (`0 K`), а перетинає вісь температур у додатній точці `θ_p ≈ T_C`. Гарячий парамагнітний кристал утримує мікроскопічну «пам'ять» про колективну взаємодію електронів, яка матеріалізується при охолодженні. Зсув знаменника з `T` на `(T - T_C)` виникає через внутрішнє позитивне зворотне значення — кооперативне поле, що підсилює зовнішнє збудження.

---

### 1. Від емпіричного закону Кюрі до молекулярного поля Вейсса

Магнітна сприйнятливість `χ` описує здатність речовини намагнічуватися під дією зовнішнього магнітного поля `H`:

```
M = χ · H
```

У 1895 році П'єр Кюрі в ході фундаментальних вимірювань магнітних властивостей речовин при різних температурах за допомогою крутильних терезів власної конструкції встановив, що для більшості парамагнітних матеріалів (таких як солі марганцю, хромові купороси або платина) магнітна сприйнятливість спадає обернено пропорційно абсолютній температурі:

```
χ = C / T
```

де `C` — фундаментальна константа Кюрі матеріалу, а `T` — абсолютна температура в Кельвінах.

Фізичний механізм класичного закону Кюрі спирається на неперервне змагання двох протилежних чинників:
1. Зовнішнє магнітне поле `H` створює орієнтувальний момент `E = - (μ · B)`, змушуючи вільні атомні магнітні моменти шикуватися уздовж силових ліній поля.
2. Хаотичний тепловий рух атомів кристалічної ґратки із середньою енергією `k_B · T` безперервно збиває цю орієнтацію, намагаючись перетворити систему на стан максимального термодинамічного хаосу.

У цій класичній картині самі атомні магнітики розглядаються як повністю ізольовані частинки, які орієнтуються у полі незалежно одна від одної. 

Проте спроба применити класичний закон Кюрі до речовин, здатних до феромагнетизму (заліза, нікелю, кобальту, гадолінію) у їхній високотемпературній парамагнітній фазі (`T > T_C`), зазнала цілковитого краху. Виміряна магнітна сприйнятливість парамагнітного заліза виявилася на кілька порядків вищою за значення, передбачені формулою Кюрі. Крім того, при зниженні температури й наближенні до критичної точки згори сприйнятливість `χ` зростала не за законною пропорцією `1 / T`, а розбігалася до нескінченності.

![Обернена магнітна сприйнятливість (1/χ) від температури (T)](/book/physics/condensed-matter-physics/curie-weiss-law/img/curie-vs-curie-weiss.svg)
*Обернена магнітна сприйнятливість (1/χ) від температури (T)*

У 1907 році французький фізик П'єр Вейсс запропонував вирішення цього фундаментального парадоксу. Він висунув гіпотезу, що у феромагнітних матеріалах атомні магнітні моменти не є незалежними: кожен атом перебуває під дією потужного внутрішнього **молекулярного поля** `H_mol`, яке створюється всіма оточуючими атомами кристала.

Вейсс припустив, що це внутрішнє поле прямо пропорційне локальній макроскопічній намагніченості речовини `M`:

```
H_mol = λ · M
```

де `λ` — феноменологічна константа молекулярного поля Вейсса (безрозмірний коефіцієнт міжсерцевого зв'язку).

Отже, повне ефективне магнітне поле `H_eff`, що діє на кожен атомний магнітний диполь усередині речовини, є сумою зовнішнього прикладеного поля `H` та внутрішнього молекулярного поля `H_mol`:

```
H_eff = H + H_mol = H + λ · M
```

Оскільки у парамагнітній області (`T > T_C`) відгук речовини на ефективне поле `H_eff` локально підпорядковується закону Кюрі, можна записати:

```
M = (C / T) · H_eff = (C / T) · (H + λ · M)
```

Помноживши обидві частини на температуру `T` та перенесши члени з намагніченістю `M` у ліву частину:

```
M · T = C · H + C · λ · M
M · (T - C · λ) = C · H
```

Розділивши на `H` та виразивши макроскопічну магнітну сприйнятливість `χ = M / H`:

```
χ = C / (T - C · λ)
```

Визначивши критичну температуру як добуток константи Кюрі на коефіцієнт Вейсса:

```
T_C = C · λ
```

Отримуємо фундаментальний **закон Кюрі — Вейсса**:

```
χ = C / (T - T_C)
```

Фізичний зміст закону Кюрі — Вейсса полягає у тому, що внутрішнє молекулярне поле створює позитивний зворотний зв'язок: зовнішнє поле намагнічує речовину, орієнтовані атоми генерують додаткове внутрішнє поле `λ · M`, яке ще сильніше повертає сусідні спіни. Коли температура знижується до `T_C`, знаменник `(T - T_C)` прямує до нуля. Це означає, що сприйнятливість `χ` прямує до нескінченності: система стає нескінченно чутливою до зовнішнього поля, і навіть нескінченно мале збудження викликає самочинну спонтанну намагніченість.

Важливо враховувати геометричний фактор зразка. У реальних експериментах внутрішнє магнітне поле всередині тіла зменшується через розмагнічувальне поле `H_demag = - N_d · M`, де `N_d` — розмагнічувальний фактор геометрії зразка (наприклад, `N_d = 1/3` для кулі, `N_d = 1` для тонкої пластини, `N_d → 0` для довгого тонкого циліндра уздовж поля). Тому виміряна зовнішня сприйнятливість `χ_ext` пов'язана з істинною внутрішньою сприйнятливістю речовини `χ_int` співвідношенням:

```
χ_ext = χ_int / (1 + N_d · χ_int)
```

При `T → T_C` внутрішня сприйнятливість `χ_int → ∞`, тоді як зовнішня сприйнятливість кулястого зразка досягає граничного значення `1 / N_d = 3`.

Детальний аналіз історії створення гіпотези Вейсса, суперечок із класичною статистичною фізикою Ланжевена та подальшого розшифрування природи молекулярного поля читайте у вставці [Історія відкриття молекулярного поля Вейсса та квантового обміну](book:physics/condensed-matter-physics/curie-weiss-law/hist-weiss-molecular-field.md).

### 2. Фізична природа молекулярного поля та квантовий обмін

Виведення закону Кюрі — Вейсса феноменологічно бездоганне, проте оцінка числового значення коефіцієнта Вейсса `λ` виявляє глибоку фізичну суперечність із класичною электродинамікою.

Оцінимо величину молекулярного поля для чистих феромагнітних металів. Для заліза (`Fe`) температура Кюрі становить `T_C = 1043 K`, а молярна константа Кюрі `C ≈ 2.1 K`. Звідси коефіцієнт Вейсса дорівнює:

```
λ = T_C / C ≈ 1043 / 2.1 ≈ 500
```

Оскільки насичена намагніченість заліза становить `M_0 ≈ 1.7 · 10⁶ А/м`, магнітна індукція внутрішнього поля Вейсса досягає гігантського значення:

```
B_mol = μ_0 · H_mol = μ_0 · λ · M_0
B_mol ≈ (4π · 10⁻⁷ Гн/м) · 500 · (1.7 · 10⁶ А/м) ≈ 1000 Тесла
```

Поле у 1000 Тесла перевершує найпотужніші лабораторні постійні магніти у сотні разів. Якщо ж обчислити класичне магнітне диполь-дипольне поле, яке створює один електронний магнітний момент `μ_B` на сусідньому атомі, розташованому на відстані `r ≈ 0.25 нм`, то отримуємо:

```
B_dipole ≈ (μ_0 / 4π) · (2 · μ_B / r³) ≈ 10⁻⁷ · (2 · 9.27 · 10⁻²⁴ / (0.25 · 10⁻⁹)³) ≈ 0.12 Тесла
```

Класичні магнітні сили між електронними диполями виявилися у **10 000 разів слабшими** за поле Вейсса. Якби феромагнетизм утримувався лише дипольними силами, теплові коливання зруйнували б магнітний порядок вже при кріогенній температурі понад **1 K**.

Справжньою фізичною основою молекулярного поля є чисто квантово-механічний ефект — **обмінна взаємодія** (*exchange interaction*). 

Згідно з принципом заборони Паулі, повна хвильова функція двох тотожних ферміонів (електронів) мусить бути антисиметричною щодо їхньої перестановки. Коли електронні хмаринки двох сусідніх атомів перекриваються у просторі, середня кулонівська енергія їхнього електричного відштовхування залежить від того, як орієнтовані їхні спіни:
- Якщо спіни паралельні (`↑↑`), просторова частина хвильової функції є антисиметричною, і електрони рідше опиняються поруч у просторі. Електрична енергія відштовхування зменшується.
- Якщо спіни антипаралельні (`↑↓`), електрони частіше зближуються, що збільшує електростатичну енергію.

Ця різниця в кулонівській енергії описується обмінним оператором Гейзенберга:

```
H_ex = - 2 · J · (S_i · S_j)
```

де `J` — **обмінний інтеграл** (*exchange integral*).

Зіставляючи обмінну енергію Гейзенберга із зеєманівською енергією спіна у молекулярному полі Вейсса `E = - μ · B_mol`, виражаємо коефіцієнт Вейсса `λ` через квантові параметри:

```
λ = (2 · z · J) / (N · g² · μ_B² · μ_0)
```

де `z` — кількість найближчих сусідів у кристалічній ґратці, `N` — атомна щільність.

Отже, «молекулярне поле Вейсса» — це взагалі не магнітне поле. Це **чисто кулонівська електрична взаємодія**, скоригована квантовою симетрією принципу Паулі. Оскільки електричні сили між зарядами на кілька порядків потужніші за класичні магнітні сили, це розгадує таємницю існування високих температур Кюрі аж до тисячі кельвінів.

Знак обмінного інтеграла визначає тип магнітного порядку:
1. Якщо `J > 0`, енергетично вигідним є паралельне шикування спінів (`↑↑`) — реалізується **феромагнетизм** із позитивною температурою Кюрі `T_C = C · λ > 0`.
2. Якщо `J < 0`, енергетично вигідним є антипаралельне шикування спінів (`↑↓`) — виникає **антиферомагнетизм** або **феримагнетизм**. Закон Кюрі — Вейсса у парамагнітній області описується від'ємною константою `θ_p < 0`:

```
χ = C / (T + |θ_p|)
```

Пряма `1 / χ(T)` перетинає вісь температур у від'ємній області `-|θ_p|`, що вказує на наявність міжпідґраткових антиферомагнітних сил.

У твердих тілах виділяють дві фундаментальні моделі магнетизму:
- **Модель локалізованих спінів (модель Гейзенберга):** Характерна для рідкісноземельних металів (Gd, Dy, Tb) та діелектричних оксидів, де магнітні моменти строго локалізовані на внутрішніх 4f- або 3d-оболонках і не беруть участі у електропровідності.
- **Модель колектизованого зоного магнетизму (модель Стонера):** Характерна для 3d-металів (Fe, Co, Ni), де незаповнені 3d-електрони утворюють зонні стани на рівні Фермі. Феромагнітний стан виникає при виконанні критерію Стонера `I · D(E_F) > 1`, де `I` — обмінне розщеплення зон, а `D(E_F)` — густина електронних станів.

### 3. Самоузгоджена теорія середнього поля та функція Бріллюена

Щоб описати поведінку феромагнетика у всьому діапазоні температур (як вище, так і нижче точки Кюрі), необхідно перейти від класичного розкладу Кюрі до точного квантово-механічного усереднення за статистикою Больцмана.

У наближенні середнього поля середня намагніченість одиниці об'єму для іонів із квантовим моментом `J` задається формулою:

```
M(T, H) = M_0 · B_J(x)
```

де `M_0 = N · g · μ_B · J` — намагніченість насичення при `T = 0 K`, а `B_J(x)` — **функція Бріллюена**:

```
B_J(x) = [ (2J + 1) / (2J) ] · coth( (2J + 1) · x / (2J) ) - [ 1 / (2J) ] · coth( x / (2J) )
```

Безрозмірний аргумент `x` описує відношення магнітної енергії спіна в ефективному полі до теплової енергії `k_B · T`:

```
x = [ g · μ_B · J · μ_0 · (H + λ · M) ] / [ k_B · T ]
```

Для чисто спінового магнетизму електронів (`J = 1/2`) функція Бріллюена спрощується до гіперболічного тангенса `B_{1/2}(x) = tanh(x)`. Для великих квантових чисел `J → ∞` вона переходить у класичну функцію Ланжевена `L(x) = coth(x) - 1/x`.

За відсутності зовнішнього поля (`H = 0`) ввівши відносну намагніченість `m = M / M_0`, отримуємо безрозмірне **рівняння самоузгодження Вейсса**:

```
m = tanh( m · T_C / T )
```

Змінна `m` входить у це рівняння нелінійно з двох боків.

![Графічне рішення рівняння самоузгодження Вейсса m = tanh(m · T_C / T)](/book/physics/condensed-matter-physics/curie-weiss-law/img/weiss-self-consistency.svg)
*Графічне рішення рівняння самоузгодження Вейсса m = tanh(m · T_C / T)*

Графічний розв'язок шукають як точки перетину прямої `y = m` та кривої `y = tanh(m · T_C / T)`:

1. **Режим `T > T_C` (Парамагнітна фаза):**
   Нахил гіперболічного тангенса у нулі дорівнює `d/dm [tanh(m · T_C / T)]_{m=0} = T_C / T < 1`. Пряма `y = m` і крива `y = tanh(...)` перетинаються лише в єдиній точці `m = 0`. Спонтанна намагніченість відсутня, речовина є парамагнетиком.

2. **Режим `T = T_C` (Критична точка):**
   Нахил кривої в нулі строго дорівнює 1 (`T_C / T = 1`). Пряма `y = m` є дотичною до кривої у нулі.

3. **Режим `T < T_C` (Феромагнітна фаза):**
   Нахил кривої в нулі більший за одиницю (`T_C / T > 1`). Пряма та крива перетинаються у **трьох точках**: `m = 0`, `+m_s(T)` та `-m_s(T)`.
   Аналіз вільної енергії Гельмгольца показує, що стан `m = 0` при `T < T_C` стає термодинамічно нестійким (максимум вільної енергії). Система спонтанно вибирає один із двох стійких станів `±m_s(T)` із нижчою енергією (мінімуми вільної енергії).

Форма кривої намагнічування `M(T)` залежить від значення квантового моменту `J`. Для рідкісноземельних елементів (наприклад, гадолінію `Gd³⁺` із `J = 7/2` або диспрозію `Dy³⁺` із `J = 15/2`) функція Бріллюена забезпечує стрімкіше зростання намагніченості при охолодженні нижче точки Кюрі порівняно зі спіном `J = 1/2`.

Повний математичний вивід статистичної суми, функції Бріллюена та аналітичне розкладання поблизу критичної точки дивіться у вставці [Математичний вивід теорії середнього поля Вейсса та функції Бріллюена](book:physics/condensed-matter-physics/curie-weiss-law/math-weiss-mean-field-derivation.md).

### 4. Фазові переходи другого роду, симетрія та критичні показники

Перехід від парамагнітного стану до феромагнітного при досягненні температури Кюрі є класичним прикладом **фазового переходу другого роду** в концепції Ландау.

Головні ознаки переходу другого роду у точці Кюрі:
- Спонтанна намагніченість `M_s(T)` (параметр порядку) змінюється безперервно, спадаючи до нуля при `T → T_C⁻`.
- Відсутня прихована теплота переходу (внутрішня енергія змінюється безперервно).
- Магнітна теплоємність `C_m` зазнає стрибкоподібного скачка `ΔC_m = (3/2) · N · k_B` при `T = T_C` (характерний λ-пік).
- Магнітна сприйнятливість `χ` розбігається до нескінченності за законом Кюрі — Вейсса.

![Температурна залежність спонтанної намагніченості M_s(T) / M_0](/book/physics/condensed-matter-physics/curie-weiss-law/img/spontaneous-magnetization-temp.svg)
*Температурна залежність спонтанної намагніченості M_s(T) / M_0*

З погляду фундаментальної симетрії:
- При `T > T_C` парамагнітний стан володіє повною інваріантністю щодо тривимірних обертань магнітних моментів у просторі та інверсії часу (`M = 0`).
- При `T < T_C` виникає **спонтанне порушення симетрії** (*spontaneous symmetry breaking*). Системний гамільтоніан лишається симетричним, але під дією нескінченно малого збудження вектор намагніченості `M` вибирає певний виділений напрямок у просторі, знижуючи симетрію стану.

У теорії Ландау вільна енергія `F(M, T)` розкладається у ряд по парних степенях параметра порядку `M`:

```
F(M, T) = F_0 + (1 / 2) · a_0 · (T - T_C) · M² + (1 / 4) · b · M⁴ + (1 / 2) · g · (∇ M)² - M · H
```

де `(1/2) g (∇ M)²` — градієнтний член Ґінзбурга — Ландау, який описує енергетичну ціну просторової неоднорідності намагніченості (формування доменних меж).

Умова мінімуму вільної енергії `∂F / ∂M = 0` за відсутності поля (`H = 0`) дає:

```
a_0 · (T - T_C) · M + b · M³ = 0
```

Для `T < T_C` ненульовий розв'язок має вигляд:

```
M_s(T) = \sqrt{ (a_0 / b) · (T_C - T) } = M_0 · \sqrt{ 3 · (1 - T / T_C) }
```

Звідси випливає значення критичного показника спонтанної намагніченості `β = 0.5`.

Якщо прикласти зовнішнє магнітне поле `H > 0` при `T = T_C`, то мінімум вільної енергії визначається рівнянням `b · M³ = H`, що дає критичну ізотерму `M ∝ H^{1/3}` із критичним показником `δ = 3.0`.

У загальній теорії фазових переходів поведінка термодинамічних величин поблизу критичної точки описується універсальними степеневими законами через **критичні показники** (*critical exponents*):

| Фізична величина | Степеневий закон поблизу `T_C` | Показник MFT (Вейсс) | Експеримент (3D Ising / Heisenberg) |
| :--- | :--- | :--- | :--- |
| Спонтанна намагніченість `M_s` (`T < T_C`) | `M_s ∝ (1 - T / T_C)^β` | `β = 1/2 = 0.5` | `β ≈ 0.32 - 0.365` |
| Сприйнятливість `χ` (`T > T_C`) | `χ ∝ (T / T_C - 1)^{-\gamma}` | `γ = 1.0` | `γ ≈ 1.24 - 1.39` |
| Критична ізотерма (`T = T_C`) | `M ∝ H^{1/\delta}` | `δ = 3.0` | `δ ≈ 4.8` |
| Магнітна теплоємність `C_m` | `C_m ∝ |T - T_C|^{-\alpha}` | `α = 0` (скачок) | `α ≈ 0.11` |

Теорія середнього поля Вейсса передбачає значення критичного показника намагніченості `β = 0.5` (параболічна залежність). Проте прецизійні експерименти на чистих феромагнетиках дають менші значення `β ≈ 0.33–0.36`. Ця відмінність пояснюється тим, що теорія Вейсса повністю нехтує флуктуаціями спінів поблизу точок фазових переходів.

### 5. Межі теорії Вейсса, спінові флуктуації та короткосяжний порядок

Попри вражаючий успіх закону Кюрі — Вейсса, наближення середнього поля є спрощенням реальної квантової картини.

Головне допущення теорії Вейсса полягає у тому, що кожен спін взаємодіє не з конкретними миттєвими орієнтаціями своїх сусідів, а з їхньою **середньою часовою та просторовою намагніченістю** `<M>`. Це припущення ідеально працює в двох крайніх випадках:
1. Високі температури (`T >> T_C`), де тепловий рух ефективно усереднює будь-які флуктуації.
2. Нескінченна кількість найближчих сусідів (`z → ∞`) або нескінченний радіус дії взаємодії (довгосяжні сили).

Проте у реальних тривимірних кристалах із короткосяжною обмінною взаємодією поблизу точки Кюрі (`T ≈ T_C`) це наближення ламається.

![Мікроскопічний магнітний порядок при різних температурах](/book/physics/condensed-matter-physics/curie-weiss-law/img/paramagnetic-domain-transition.svg)
*Мікроскопічний магнітний порядок при різних температурах*

При наближенні до точки Кюрі згори (`T → T_C⁺`) в парамагнітній фазі виникають потужні **критичні флуктуації спінів**. Хоча середня макроскопічна намагніченість дорівнює нулю (`M = 0`), електрони об'єднуються у динамічні корельовані кластери — області **короткосяжного магнітного порядку** (*short-range order*).

Просторовий розподіл кореляцій між двома спінами на відстані `r` описується функцією Орнштейна — Церніке:

```
G(r) = <S(0) · S(r)> ∝ [ exp( - r / ξ ) ] / r
```

де `ξ(T)` — радіус кореляції спінових флуктуацій.

При наближенні до точки Кюрі радіус кореляції `ξ` розбігається за степеневим законом `ξ(T) ∝ (T - T_C)^{-\nu}` (де `ν ≈ 0.63` для 3D моделей). Коли радіус кореляції `ξ` стає більшим за міжатомну відстань `a`, флуктуації починають домінувати над середнім значенням. 

Згідно з **критерієм Ґінзбурга**, наближення середнього поля Вейсса втрачає точність у вузькій узбічній критичній області:

```
|T - T_C| / T_C < Gi
```

де `Gi` — безрозмірне число Ґінзбурга (для 3D металевих феромагнетиків `Gi ≈ 10⁻² - 10⁻³`).

Експерименти з непружного малокутового розсіяння теплових нейтронів на кристалях заліза й нікелю поблизу `T_C` безпосередньо підтверджують існування критичного розсіяння нейтронів на спінових кластерах. У цій вузькій узбічній області класичний закон Кюрі — Вейсса `χ ∝ (T - T_C)⁻¹` замінюється флуктуаційною закономірністю `χ ∝ (T - T_C)⁻¹·²⁴`. Проте вже при відхиленні від точки Кюрі на 10–15 Кельвінів убік високих температур критичні флуктуації згасають, і класичний закон Кюрі — Вейсса стає експериментально точним.

### 6. Експериментальні методи, застосування та матеріальні константи

Вимірювання температурної залежності магнітної сприйнятливості `χ(T)` у парамагнітній області є головним експериментальним методом визначення фундаментальних магнітних характеристик нових матеріалів.

#### Визначення параметрів з експериментального графіка `1 / χ(T)`
Побудувавши експериментальні дані у координатах `(T, 1 / χ)`, проводять лінійну апроксимацію прямою `y = a · T + b`:
1. Точка перетину прямої з віссю температур визначає парамагнітну температуру Кюрі: `θ_p = - b / a`.
2. Обернений кутовий коефіцієнт визначає константу Кюрі: `C = 1 / a`.
3. За знайденою константою Кюрі обчислюють **ефективний магнітний момент іона** `μ_eff` у магнетонах Бора (`μ_B`):

```
μ_eff = \sqrt{ (3 · k_B · C) / (N_A · μ_0) } / μ_B ≈ 2.828 · \sqrt{ C_{mol} }
```

де `C_{mol}` — молярна константа Кюрі (в одиницях см³·К/моль).

Порівняння експериментального моменту `μ_eff` із теоретичним значенням для вільного іона `μ_th = g · \sqrt{J(J+1)}` дозволяє визначити ступінь заморожування орбітального моменту у кристалічному полі та валентний стан елемента.

#### Сучасні методи експериментальної магнітометрії
1. **SQUID-магнітометрія (Superconducting Quantum Interference Device):** Застосовує надпровідні квантові інтерферометри для вимірювання сприйнятливості мікрограмових зразків із точністю до `10⁻¹⁰` ЕМО у діапазоні температур від 1.8 K до 400 K.
2. **Вібраційна магнітометрія (VSM):** Зразок коливається у постійному магнітному полі, викликуючи ЕРС індукції у приймальних котушках. Дозволяє проводити високотемпературні вимірювання `1 / χ(T)` до 1200 K.
3. **Змінна магнітна сприйнятливість (AC Susceptibility):** Вимірює комплексну сприйнятливість `χ(ω) = χ' - i χ''`. Динамічний уявний відгук `χ''` дозволяє фіксувати релаксаційні процеси спінових склав та доменних меж у критичній точці.

#### Експериментальні магнітні константи обраних матеріалів

| Матеріал | Тип магнетизму | Експериментальна `T_C` або `T_N` (K) | Парамагнітна `θ_p` (K) | Константа Кюрі `C_{mol}` (см³·К/моль) | Ефективний момент `μ_eff` (`μ_B`) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Залізо (`Fe`) | Феромагнетик | 1043 | +1093 | 1.22 | 3.12 |
| Нікель (`Ni`) | Феромагнетик | 627 | +650 | 0.325 | 1.61 |
| Кобальт (`Co`) | Феромагнетик | 1388 | +1428 | 1.21 | 3.11 |
| Гадоліній (`Gd`) | Феромагнетик | 292 | +317 | 7.81 | 7.98 |
| Оксид марганцю (`MnO`) | Антиферомагнетик | 116 (`T_N`) | -610 | 4.38 | 5.92 |

#### Практичні застосування
1. **Магнітна термометрія:** При кріогенних температурах парамагнітні солі (наприклад, церій-магній-нітрат) з відомою константою Кюрі слугують еталонними термометрами для вимірювання температур у діапазоні від 0.001 K до 1 K.
2. **Розробка м'якомагнітних та жорсткомагнітних матеріалів:** Закон Кюрі — Вейсса дозволяє розраховувати температурний коефіцієнт стабільності трансформаторних сталей, високочастотних феритів для імпульсних джерел живлення та постійних неодимових магнітів (`Nd_2Fe_{14}B`) при нагріванні в силових електроустановках.
3. **Магнітокалоричне охолодження:** Речовини з точкою Кюрі поблизу кімнатної температури (наприклад, сплави `Gd_5(Si_2Ge_2)`) демонструють гігантський магнітокалоричний ефект (зміна температури при адіабатичному намагнічуванні), що застосовується у безфреонових холодильних системах нового покоління.
4. **Магнітна пам'ять MRAM та спінтроніка:** Ефект зміни точки Кюрі під дією електричного поля або спін-орбітального моменту слугує основою для енергонезалежних осередків пам'яті STT-MRAM.

Алгоритми числового розв'язання рівнянь Вейсса та програмний код апроксимації експериментальних даних наведено у вставці [Моделювання та апроксимація експериментальних даних закону Кюрі — Вейсса](book:physics/condensed-matter-physics/curie-weiss-law/proj-curie-weiss-fit.md).

### 7. Межа застосовності теорії та підсумок

Теорія середнього поля Вейсса є чесним наближенням, яке має чітко окреслену межу застосовності:
- Вона **не виводить** обмінний інтеграл з перших принципів электродинаміки, а приймає його феноменологічно через параметр `λ`.
- Вона **не враховує** спінові хвилі (магнони) при низьких температурах (`T << T_C`), де спонтанна намагніченість спадає за законом Блоха `M(T) = M_0 (1 - A · T^{3/2})`, а не за експоненційним законом Вейсса.
- Вона **ігнорує** просторові флуктуації спінів у безпосередній близькості до точок фазових переходів.

Попри ці межі, закон Кюрі — Вейсса лишається фундаментальним наріжним каменем фізики конденсованого стану. Він продемонстрував, як із мікроскопічної взаємодії окремих частинок виникає якісно новий макроскопічний стан речовини зі спонтанним порушенням симетрії, і заклав універсальну математичну основу для всієї сучасної теорії фазових переходів.
