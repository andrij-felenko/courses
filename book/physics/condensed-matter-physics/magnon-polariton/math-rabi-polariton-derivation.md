# 🧮 Математичне виведення рівняння магнон-поляритонів та матриці розсіювання S₂₁

Математична теорія магнон-поляритонів будується на квантуванні електромагнітного поля резонатора, лінеаризованому перетворенні Гольштейна — Примакова для макроскопічного спінового ансамблю, діагоналізації зв'язаного гамільтоніана за допомогою перетворення Гопфілда, а також на розв'язанні квантових рівнянь Гейзенберга — Ланжевена у рамках теорії входу-виходу (Input-Output Theory) для обчислення комплексного коефіцієнта проходження `S₂₁(ω)`.

---

### 1. Квантування електромагнітного поля резонатора та вакуумні флуктуації

Розглянемо високодобротний мікрохвильовий резонатор (наприклад, 3D мідну кавіті або надпровідний копланарний хвилевід). Класичне електромагнітне поле у резонаторі описується рівняннями Максвелла з відповідними межевими умовами на провідних стінках.

Згідно з вихідними рівняннями електродинаміки суцільних середовищ, векторний потенціал `A(r, t)` задовольняє хвильове рівняння `∇² A - (1/c²) ∂²A/∂t² = 0` при виконанні кулонівського калібрування `∇ · A = 0`. Для неконденсованого одномодового електромагнітного поля з власною частотою `ω_a` векторний потенціал `A(r, t)` квантується за допомогою операторів народження `a⁺` та знищення `a` фотона:

```
A(r, t) = √[ ℏ / (2 ε₀ ω_a V_eff) ] · u(r) · (a + a⁺)
```

де `u(r)` — безрозмірна просторова функція фотонної моди, яка визначається геометричною конфігурацією резонатора, а `V_eff = ∫ |u(r)|² dV` — ефективний об'єм моди. Оператори `a` та `a⁺` задовольняють стандартне бозонне комутаційне співвідношення `[a, a⁺] = 1`.

Магнітна компонента квантованого мікрохвильового поля визначається ротором векторного потенціалу `b_rf(r) = ∇ × A(r)`. У точці розташування магнітного зразка `r = r₀` оператор змінного магнітного поля записується через вакуумні флуктуації `b_zp`:

```
b_rf = b_zp · (a + a⁺)
```

Величина вакуумних флуктуацій магнітного поля `b_zp` знайдеться з умови, що середня енергія вакуумного стану фотона `1/2 ℏ ω_a` дорівнює інтегралу по об'єму резонатора від густини магнітної енергії `1/(2 μ₀) ∫ |b_rf|² dV`. Для прямокутного резонатора стоячої хвилі це дає вираз:

```
b_zp = √[ ℏ ω_a μ₀ / (2 V_eff) ]
```

Гамільтоніан вільного фотонного поля резонатора в умовах відсутності втрат має традиційний вигляд квантового гармонічного осцилятора:

```
H_photon = ℏ ω_a · (a⁺ a + 1/2)
```

### 2. Квантування спінового ансамблю: перетворення Гольштейна — Примакова

Розглянемо монокристалічний феромагнетик (ітрій-залізистий гранат, YIG) об'єму `V_sample`, який містить `N` неспарених електронних спінів `S = 1/2`. Усі спіни пов'язані між собою потужною обмінною взаємодією Гейзенберга `H_ex = -J ∑_<ij> S_i · S_j`, що створює макроскопічний вектор спонтанної намагніченості насичення `M_s = γ_e ℏ ρ_s S`.

Сумарні макроскопічні оператори спінового моменту кристала визначаються як сума операторів окремих вузлів:

```
S_x = ∑_j S_xj ,     S_y = ∑_j S_yj ,     S_z = ∑_j S_zj
```

Оператори підвищення та пониження спіна `S⁺` і `S⁻` описуються формулами:

```
S⁺ = S_x + i S_y ,     S⁻ = S_x - i S_y
```

Для переходу від точних спінових операторів, які задовольняють комутаційні співвідношення алгебри Lie `[S⁺, S⁻] = 2 S_z`, до бозонних операторів квазічастинок застосуємо точне перетворення Гольштейна — Примакова (1940 рік):

```
S⁺ = √(2 S N) · √(1 - m⁺ m / (2 S N)) · m
S⁻ = √(2 S N) · m⁺ · √(1 - m⁺ m / (2 S N))
S_z = S N - m⁺ m
```

де `m` та `m⁺` — бозонні оператори знищення та народження магнона однорідного FMR (`k = 0`), які задовольняють співвідношення `[m, m⁺] = 1`.

У режимі слабких спінових збуджень, коли середня кількість збуджених магнонів у зразку значно менша за повну кількість спінів (`⟨m⁺ m⟩ ≪ 2 S N`), квадратний корінь розкладається в ряд Тейлора `√(1 - x) ≈ 1 - x/2`. Нехтуючи ангармонічними членами вищих порядків, які відповідають взаємодії магнон-магнонному розсіюванню, отримуємо лінеаризовані співвідношення:

```
S⁺ ≈ √(2 S N) · m
S⁻ ≈ √(2 S N) · m⁺
```

Гамільтоніан магнонної підсистеми (однорідної моди Кіттеля) у постійному магнітному полі `H₀` з урахуванням розмагнічувальних факторів форми зразка набуває діагонального бозонного вигляду:

```
H_magnon = ℏ ω_m · m⁺ m
```

де `ω_m(H₀) = γ_e H_eff` — власна частота прецесії Кіттеля, керована зовнішнім магнітним полем.

### 3. Взаємодія підсистем та ефективна константа зв'язку

Магнітно-дипольна взаємодія між макроскопічною намагніченістю зразка `M(r)` та змінним магнітним полем резонатора `b_rf(r)` описується фундаментальним інтегральним гамільтоніаном:

```
H_int = - ∫ (M · b_rf) dV
```

Виразивши вектор намагніченості через поперечні спінові оператори `M_x = γ_e ℏ / V_sample · S_x` та підставивши вирази Гольштейна — Примакова, отримуємо оператор взаємодії:

```
H_int = - ℏ γ_e b_zp √(2 S N) / 2 · (m + m⁺) (a + a⁺)
```

Розкриваючи дужки у векторному добутку, маємо чотири доданки: `a m`, `a⁺ m⁺`, `a⁺ m` та `a m⁺`. Перші два доданки описують одночасне народження або знищення двох квазічастинок з сумарною частотою `≈ 2 ω_a`. У випадку, коли константа зв'язку є значно меншою за несучу частоту (`g_eff ≪ ω_a`), ці доданки швидко осцилюють у часі і в наближенні обертальної хвилі (Rotating Wave Approximation, RWA) їхній внесок усереднюється до нульового значення.

Зберігаючи лише резонансні члени `a⁺ m` та `a m⁺`, які описують когерентний перехід фотона у магнон і навпаки, отримуємо гамільтоніан Тавіса — Каммінгса:

```
H / ℏ = ω_a · a⁺ a  +  ω_m · m⁺ m  +  g_eff · (a⁺ m + a m⁺)
```

де `g_eff` — колективна константа зв'язку ансамблю Дикке:

```
g_eff = γ_e · b_zp · √(2 S N) / 2 = g₀ · √N_spins
```

Ця формула демонструє математичну суть підсилення Дикке: хоча мікроскопічний зв'язок одиночного спіна `g₀` є мізерним, колективний опис через оператори Гольштейна — Примакова дає множник `√N_spins`, що виводить систему у макроскопічний режим.

### 4. Діагоналізація гамільтоніана та перетворення Гопфілда

Для розв'язання задачі про власні значення гамільтоніана без урахування втрат застосуємо канонічне перетворення Гопфілда (1958 рік). Введемо нові поляритонні бозонні оператори `p_-` (нижня вітка, LMP) та `p_+` (верхня вітка, UMP):

```
p_- = u · a - v · m
p_+ = v · a + u · m
```

де `u` та `v` — дійсні амплітуди Гопфілда. Вимагаючи збереження бозонних комутаторів `[p_i, p_j⁺] = δ_ij`, отримуємо умову нормування:

```
u² + v² = 1
```

Параметризуємо коефіцієнти через кут змішування `θ ∈ [0, π/4]`:

```
u = cos(θ) ,     v = sin(θ)
```

Діагональна форма гамільтоніана має вигляд:

```
H / ℏ = ω_- · p_-⁺ p_-  +  ω_+ · p_+⁺ p_+
```

Підставляючи обернені вирази `a = cos(θ) p_- + sin(θ) p_+` та `m = -sin(θ) p_- + cos(θ) p_+` у гамільтоніан і вимагаючи зникання недіагональних членів `p_-⁺ p_+`, отримуємо рівняння для кута змішування `θ`:

```
tan(2 θ) = (2 g_eff) / (ω_m - ω_a) = (2 g_eff) / Δ
```

де `Δ = ω_m - ω_a` — частотна розстройка.

Власні частоти нижнього та верхнього магнон-поляритонів визначаються строгою формулою:

```
ω_± = (ω_a + ω_m) / 2  ±  √[ (ω_m - ω_a)² / 4  +  g_eff² ]
```

Амплітуди Гопфілда виражаються через розстройку `Δ`:

```
u² = 1/2 · [ 1 + Δ / √(Δ² + 4 g_eff²) ]
v² = 1/2 · [ 1 - Δ / √(Δ² + 4 g_eff²) ]
```

У точці точного резонансу (`Δ = 0`) маємо `θ = π/4`, звідки `u² = v² = 1/2`. Стан є рівноправною 50%-50% суперпозицією фотона та магнона, а розщеплення між вітками сягає мінімального значення — вакуумного розщеплення Рабі `Ω_R = 2 g_eff`.

### 5. Урахування дисипації: неермітів гамільтоніан

У реальних умовах фотони випромінюються з резонатора з декрементом `κ = κ₀ + κ_ext`, а магнони релаксують у ґратку з декрементом `γ = α ω_m`.

Для опису дисипативної системи введемо неермітів ефективний гамільтоніан:

```
H_eff = ℏ · [  (ω_a - i κ)     g_eff       ]
            [    g_eff      (ω_m - i γ)    ]
```

Секулярне рівняння `det(H_eff / ℏ - w I) = 0` виглядає так:

```
(ω_a - i κ - w) · (ω_m - i γ - w) - g_eff² = 0
```

Розв'язок дає комплексні власні значення `w_± = Re(w_±) + i Im(w_±)`:

```
w_± = (ω_a + ω_m) / 2 - i (κ + γ) / 2  ±  √[ g_eff² + ( (ω_m - ω_a) / 2 - i (γ - κ) / 2 )² ]
```

У точці точного резонансу (`ω_m = ω_a`) дійсна частина частоти `Re(w_±)` та декременти згасання `Im(w_±)` мають вигляд:

```
Re(w_±) = ω_a  ±  Re √[ g_eff² - (κ - γ)² / 16 ]
Im(w_±) = - (κ + γ) / 2  ±  Im √[ g_eff² - (κ - γ)² / 16 ]
```

Звідси випливає строгий фізичний критерій розмежування режимів:

1. **Режим сильного зв'язку (`g_eff > |κ - γ| / 4` та `g_eff > (κ + γ) / 2`):**
   Підкореневий вираз є додатним і дійсним. Виникає дійсне розщеплення частот (антиперетин) з вакуумним розщепленням Рабі `Ω_R = 2 √[ g_eff² - (κ - γ)² / 16 ]`. Згасання обох мод вирівнюється і дорівнює `(κ + γ) / 2`.
2. **Режим слабкого зв'язку (`g_eff < |κ - γ| / 4`):**
   Підкореневий вираз є від'ємним. Дійсні частоти мод не розщеплюються (`Re(w_+) = Re(w_-) = ω_a`), а розщеплюються декременти згасання. Система виявляє ефект Перселла (зміна ширини лінії та часу життя магнонного збудження).

### 6. Виведення амплітуди проходження S₂₁ у теорії входу-виходу

Для розрахунку вимірюваного коефіцієнта проходження `S₂₁(ω)` скористаємося квантовою теорією входу-виходу Керра та Коен-Таннуджі. 

Сформуємо квантові рівняння Гейзенберга — Ланжевена у часовій області для операторів полів `a(t)` та `m(t)` з урахуванням вхідних полів з вхідного порту `a_in1(t)` та вихідного порту `a_in2(t)`:

```
da/dt = -i ω_a a - κ a - i g_eff m + √(2 κ_ext1) a_in1 + √(2 κ_ext2) a_in2
dm/dt = -i ω_m m - γ m - i g_eff a
```

Застосувавши фур'є-перетворення `d/dt → -i ω`, переходимо до спектральної області:

```
-i ω a(ω) = (-i ω_a - κ) a(ω) - i g_eff m(ω) + √(2 κ_ext1) a_in1(ω)
-i ω m(ω) = (-i ω_m - γ) m(ω) - i g_eff a(ω)
```

З другого рівняння знаходимо зв'язок магнонного поля з фотонним:

```
m(ω) = [ -i g_eff / (-i ω + i ω_m + γ) ] a(ω) = [ g_eff / (ω - ω_m + i γ) ] a(ω)
```

Підставивши вираз для `m(ω)` у перше рівняння, отримуємо:

```
[ -i (ω - ω_a) + κ - i g_eff² / (ω - ω_m + i γ) ] a(ω) = √(2 κ_ext1) a_in1(ω)
```

Помноживши на `i`, виразимо амплітуду внутрішнього фотонного поля `a(ω)`:

```
a(ω) = [ i √(2 κ_ext1) a_in1(ω) ] / [ ω - ω_a + i κ - g_eff² / (ω - ω_m + i γ) ]
```

Згідно зі співвідношеннями входу-виходу, вихідне поле у порту 2 дорівнює `a_out2(ω) = √(2 κ_ext2) a(ω)`. Комплексний коефіцієнт проходження `S₂₁(ω) = a_out2(ω) / a_in1(ω)` виражається остаточною формулою:

```
S₂₁(ω) = [ -2 i √(κ_ext1 · κ_ext2) ] / [ ω - ω_a + i κ - g_eff² / (ω - ω_m + i γ) ]
```

Аналогічно, для коефіцієнта відбиття від вхідного порту `S₁₁(ω) = a_out1(ω) / a_in1(ω)` з урахуванням граничної умови `a_out1 = -a_in1 + √(2 κ_ext1) a` отримуємо:

```
S₁₁(ω) = -1  +  [ 2 i κ_ext1 ] / [ ω - ω_a + i κ - g_eff² / (ω - ω_m + i γ) ]
```

Отримані співвідношення `S₂₁(ω)` та `S₁₁(ω)` є точними аналітичними формулами, які застосовуються для апроксимації експериментальних спектрів векторних аналізаторів кіл (VNA) та витягування фізичних параметрів `g_eff`, `κ` та `γ`.
