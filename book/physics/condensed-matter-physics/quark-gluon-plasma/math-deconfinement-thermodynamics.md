# 🧮 Термодинаміка деконфайнменту та ґратчаста КХД

Термодинамічні співвідношення для безмасового газу кварків і глюонів у рамках моделі мішка MIT визначають критичну температуру деконфайнменту `T_c` та формалізм петлі Полякова у ґратчастій КХД.

## 1. Термодинаміка ідеального кварк-глюонного газу (Стефана-Больцмана)

Розглянемо кварк-глюонну плазму як рівноважний статистичний ансамбль безмасових глюонів та `N_f` флейворів легких кварків. У термодинамічній межі при високих температурах `T >> m_q` масами легких кварків `u`, `d`, `s` можна знехтувати порівняно з середньою кінетичною енергією частинок `⟨E⟩ ~ 3 T`.

Загальний термодинамічний тиск та густина енергії системи визначаються як сума бозонного (глюонного) та ферміонного (кварк-антикваркового) внесків у макроскопічний грандіозний канонічний потенціал `Ω = - P · V`.

### 1.1. Внесок глюонного поля (бозони)
Кожен глюон має `2` спінові поперечні поляризації та належить до приєднаного представлення неабелевої калібрувальної групи `SU(3)_c`, яка містить `N_c² - 1 = 3² - 1 = 8` колірних генераторів (матриць Ґелл-Манна). Загальна кількість глюонних ступенів вільності дорівнює:

```
g_gluon = 2_spin × 8_color = 16
```

Тиск релятивістського бозонного газу з `g_gluon` ступенями вільності при нульовому хімічному потенціалі глюонів `μ_g = 0` визначається тривимірним інтегруванням розподілу Бозе-Ейнштейна у фазовому просторі імпульсів `p`:

```
P_gluon = g_gluon · (1 / (2π³) ) · ∫ d³p / ( exp( p / T ) - 1 )
        = g_gluon · (4π / (2π³) ) · ∫₀^∞ ( p³ dp ) / ( exp( p / T ) - 1 )  [перехід до сферичних координат: d³p = 4π p² dp]
        = g_gluon · (1 / (2π²) ) · T⁴ · ∫₀^∞ ( x³ dx ) / ( exp(x) - 1 )    [заміна безрозмірної змінної x = p/T]
        = g_gluon · (1 / (2π²) ) · T⁴ · (π⁴ / 15)                          [інтегрування за імпульсами: ∫₀^∞ x³/(exp(x)-1) dx = π⁴/15]
        = g_gluon · (π² / 90) · T⁴                                        [спрощення коефіцієнтів: (1/2π²) · (π⁴/15) = π²/90]
        = 16 · (π² / 90) · T⁴                                            [підстановка значення g_gluon = 16]
```

### 1.2. Внесок кварків та антикварків (ферміони)
Для кожного з `N_f` флейворів кварків існує `2` спінові стани (спін 1/2), `N_c = 3` кольори, а також відповідні античастинки (антикварки). Загальна кількість ферміонних ступенів вільності становить:

```
g_quark = 2_spin × 2_particle-anti × 3_color × N_f = 12 · N_f
```

Для релятивістського ферміонного газу зі статистикою Фермі-Дірака та ненульовим кварковим хімічним потенціалом `μ_q = μ_B / 3` (де `μ_B` — баріонний хімічний потенціал) термодинамічний тиск обчислюється шляхом інтегрування ферміонних розподілів для кварків `(exp((p - μ_q)/T) + 1)⁻¹` та антикварків `(exp((p + μ_q)/T) + 1)⁻¹`:

```
P_quark = g_quark · (7π² / 360) · T⁴ + N_f · N_c · [ (1/6) · T² · μ_q² + (1 / (12π²) ) · μ_q⁴ ]
```

де перший доданок виникає з інтеграла Фермі-Дірака при `μ_q = 0` за допомогою співвідношення `∫₀^∞ x³/(exp(x) + 1) dx = (7/8) · (π⁴ / 15) = 7π⁴ / 120`.

При нульовому баріонному хімічному потенціалі `μ_q = 0` (що описує ранній Всесвіт або центральні зіткнення при максимальних енергіях LHC) ферміонний тиск спрощується до виразу:

```
P_quark(μ_q = 0) = (12 · N_f) · (7π² / 360) · T⁴      [підстановка g_quark = 12 N_f]
                 = N_f · (7π² / 30) · T⁴               [скорочення коефіцієнтів: 12 · 7 / 360 = 7 / 30]
```

### 1.3. Повний тиск Стефана-Больцмана та ефективні ступені вільності
Сумарний термодинамічний тиск виродженого неідеального газу виражається через ефективну кількість ступенів вільності `g_QGP`:

```
P_SB = P_gluon + P_quark                               [сумування глюонного та кваркового тиску]
     = (π² / 90) · g_QGP · T⁴                          [винесення спільного множника (π²/90) T⁴]
```

де `g_QGP` розраховується за формулою:

```
g_QGP = g_gluon + (7 / 8) · g_quark                    [сума бозонного та ферміонного внесків]
      = 16 + (7 / 8) · (12 · N_f)                      [підстановка g_gluon = 16 та g_quark = 12 N_f]
      = 16 + (21 / 2) · N_f                            [спрощення коефіцієнтів: (7/8)·12 = 21/2]
```

Для трьох активних легких флейворів (`N_f = 3`: `u`, `d`, `s`):

```
g_QGP = 16 + 10.5 · 3                                  [підстановка N_f = 3]
      = 47.5                                           [чисельний підрухунок: 16 + 31.5 = 47.5]
```

Густина енергії `ε_SB` та густина ентропії `s_SB` ідеального газу пов'язані з тиском стандартними термодинамічними тотожностями:

```
ε_SB = T · (∂P / ∂T) - P                               [термодинамічне визначення густини енергії]
     = 3 · P_SB                                        [диференціювання T⁴ виразу по T]
     = (π² / 30) · g_QGP · T⁴                          [множення на 3: 3 · (π²/90) = π²/30]

s_SB = ∂P / ∂T                                         [термодинамічне визначення густини ентропії]
     = (4π² / 90) · g_QGP · T⁴                         [диференціювання P_SB по T: d(T⁴)/dT = 4 T³]
```

Швидкість звуку `c_s` у релятивістському плазмовому середовищі визначається як похідна тиску за густиною енергії при постійній ентропії:

```
c_s² = dP / dε                                         [визначення квадрата швидкості звуку]
     = ( dP / dT ) / ( dε / dT )                       [правило диференціювання складеної функції]
     = ( (4π²/90) g_QGP T³ ) / ( (4π²/30) g_QGP T³ )   [підстановка похідних по T від тиску та густини енергії]
     = 1 / 3                                           [скорочення однакових співмножників: 30 / 90 = 1/3]
```

Отримане значення `c_s = 1 / √3 ≈ 0.577` відповідає теоретичній межі конформної релятивістської матерії.

## 2. Модель мішка MIT та розрахунок критичної температури T_c

У рамках феноменологічної моделі мішка MIT (MIT Bag Model) вакуум КХД розглядається як неперервне середовище з негативним тиском (константою мішка `B`). Константа `B` характеризує відносну різницю густини енергії між фізичним непертурбативним вакуумом (де конфайнмент утримує кварки усередині адронних оболонок) та пертурбативним вакуумом усередині адрона чи плазмової краплі.

Повний термодинамічний тиск деконфайнованої КГП-фази у моделі мішка дорівнює:

```
P_QGP(T, μ_B) = P_SB(T, μ_B) - B
```

Адронна фаза при низьких температурах `T < T_c` у першому наближенні описується газом безмасових піонів (`π⁺, π⁻, π⁰`), який має `g_hadron = 3` ступені вільності:

```
P_hadron(T) = g_hadron · (π² / 90) · T⁴ = 3 · (π² / 90) · T⁴
```

### 2.1. Алгебраїчний вивід критичної температури T_c при μ_B = 0
Умова термодинамічної рівноваги фаз визначається рівністю тисків `P_QGP(T_c) = P_hadron(T_c)`:

```
(π² / 90) · g_QGP · T_c⁴ - B = (π² / 90) · g_hadron · T_c⁴  [умова рівноваги тисків фаз P_QGP = P_hadron]
= (π² / 90) · (g_QGP - g_hadron) · T_c⁴ = B                 [перенесення B та групування доданків]
= T_c⁴ = (90 · B) / ( π² · (g_QGP - g_hadron) )            [вираження T_c⁴ через ділення]
= T_c = [ (90 · B) / ( π² · (g_QGP - g_hadron) ) ]^(1/4)   [добування кореня 4-го ступеня з обидвох частин]
```

Підставимо числові значення: `N_f = 2.5` (враховуючи масу `s`-кварка), `g_QGP ≈ 37`, `g_hadron = 3` та значення константи мішка `B^(1/4) ≈ 145 MeV`:

```
g_eff = g_QGP - g_hadron                                   [ефективна різниця ступенів вільності]
      = 37 - 3                                             [підстановка g_QGP=37 та g_hadron=3]
      = 34                                                 [обчислення різниці: 34]

T_c = [ (90) / (π² · 34) ]^(1/4) · B^(1/4)                  [підстановка g_eff = 34]
    = [ 90 / 335.5 ]^(1/4) · 145 MeV                       [обчислення знаменника π²·34 ≈ 335.5]
    = (0.268)^(0.25) · 145 MeV                             [ділення: 90 / 335.5 ≈ 0.268]
    = 0.719 · 145 MeV                                      [добування кореня (0.268)^0.25 ≈ 0.719]
    = 144 MeV                                              [підсумкове множення: 0.719 · 145 ≈ 144]
```

Отримане аналітичне значення `T_c ≈ 144-160 MeV` чудово узгоджується з точними чисельними розрахунками ґратчастої КХД (`T_c = 155 ± 9 MeV`).

### 2.2. Прихована теплота фазового переходу L
У фазовому переході першого роду прихована теплота переходу `L` виражається через стрибок густини ентропії `Δs = s_QGP - s_hadron`:

```
L = T_c · Δs                                                       [визначення прихованої теплоти фазового переходу]
  = T_c · ( s_QGP(T_c) - s_hadron(T_c) )                            [розгортання різниці густин ентропії фаз]
  = T_c · (4π² / 90) · ( g_QGP - g_hadron ) · T_c³                [підстановка термодинамічних формул s_QGP та s_hadron]
  = (4π² / 90) · g_eff · T_c⁴                                     [введення позначення g_eff = g_QGP - g_hadron]
  = 4 · B                                                         [підстановка виразу T_c⁴ через константу мішка B]
```

Отже, у моделі мішка прихована теплота деконфайнменту становить чотириразове значення константи мішка `4 B ≈ 1.5-2.0 GeV/fm³`.

## 3. Математичний формалізм петлі Полякова у ґратчастій КХД

На ґратці з часовим розміром `N_τ = 1 / (a · T)` (де `a` — крок ґратки) колірні калібрувальні поля `A_0(x)` описуються матричними змінними зв'язку `U_0(x, τ) ∈ SU(3)`.

### 3.1. Означення оператора петлі Полякова
Петля Полякова (Polyakov loop) являє собою замкнену лінію Уілсона в уявному часі, що обгортає періодичний часовий напрямок:

```
L(x) = (1 / N_c) · Tr [ P exp( i · g · ∫₀^(1/T) dτ A_0(x, τ) ) ]
     = (1 / N_c) · Tr [ ∏_{τ=1}^{N_τ} U_0(x, τ) ]           [дискретизація інтеграла на ґратці через матриці зв'язку]
```

де `P` — оператор впорядкування за часом.

Фізичний зміст середнього значення петлі Полякова `⟨L⟩` пов'язаний із вільною енергією `F_q` нескінченно важкого пробного кварка, поміщеного у тепловий термостат:

```
⟨L⟩ = exp( - F_q / T )                                     [зв'язок середнього значення L з вільною енергією]
```

### 3.2. Петля Полякова як параметр порядку фазового переходу
У чистій калібрувальній КХД без динамічних кварків (група `SU(3)` глюодинаміки) існує глобальна центр-симетрія `Z(N_c) = Z(3)`:

```
U_0(x, τ_fixed) → z · U_0(x, τ_fixed),  де z = exp( i · 2π · k / 3 ) ∈ Z(3)
```

Під дією цієї симетрії петля Полякова трансформується як `L(x) → z · L(x)`:

1. **Фаза конфайнменту (`T < T_c`):** Центр-симетрія `Z(3)` є точною та збереженою. Енергія поодинокого кольорового кварка нескінченна (`F_q → ∞`), оскільки його неможливо екранувати. Звідси випливає значення параметра порядку:
```
⟨L⟩ = exp(-∞) = 0   (стан конфайнменту)
```

2. **Деконфайнована фаза (`T > T_c`):** Центр-симетрія `Z(3)` спонтанно порушується. Вільна енергія поодинокого заряду в плазмі стає скінченною (`F_q < ∞`) завдяки хромоелектростатичному екрануванню Дебая. Parameter порядку отримує ненульове значення:
```
⟨L⟩ = exp(-F_q / T) > 0   (стан деконфайнменту)
```

Таким чином, у чистій глюодинаміці петля Полякова слугує строгим математичним параметром порядку фазового переходу деконфайнменту 1-го роду.

### 3.3. Сприйнятливість петлі Полякова та точна температура кросоверу
Для точного чисельного визначення критичної температури `T_c` у ґратковій КХД обчислюють **сприйнятливість петлі Полякова** (Polyakov loop susceptibility) `χ_L`:

```
χ_L = N_s³ · ( ⟨L²⟩ - ⟨L⟩² )
```

де `N_s³` — просторовий об'єм ґратки.

Максимум функції `χ_L(T)` задає точку найстімкішої зміни параметра порядку, що визначає критичну температуру кросоверу `T_c = 155 ± 9 MeV`. Одночасно аналізується **кіральний конденсат** `⟨qbar q⟩` та його сприйнятливість `χ_chiral`, максимуми яких збігаються з максимумом `χ_L`, підтверджуючи одночасність деконфайнменту та відновлення кіральної симетрії.
