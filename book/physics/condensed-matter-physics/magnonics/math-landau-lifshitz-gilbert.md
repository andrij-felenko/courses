# 🧮 Динаміка Ландау — Ліфшиця — Ґільберта та хвильова математика магнонних кристалів

Фізичною основою магноніки є нелінійна динаміка вектора намагніченості у феромагнітних та феримагнітних середовищах. На відміну від електродинаміки Максвелла, де поля поширюються у лінійному вакуумі, магнонні хвилі є коливаннями зв'язаної спінової підґратки, розповсюдження яких визначається рівнянням Ландау — Ліфшиця — Ґільберта (`LLG`) та тензором магнітної проникності Полдера.

У цій вставці наведено повний математичний вивід лінеаризованого рівняння `LLG`, розегнанно компоненти ефективного магнітного поля, розраховано тензор Полдера, отримано аналітичні дисперсійні співвідношення для магнітостатичних хвиль Деймона — Ешбаха, розраховано швидкість дисипації енергії через коефіцієнт затухання Ґільберта `α`, а також побудовано формалізм матриць переходу (Transfer Matrix Method) для розрахунку спектра і заборонених зон 1D магнонного кристала.

## 1. Рівняння Ландау — Ліфшиця — Ґільберта (LLG)

Макроскопічний стан феромагнетика описується вектором намагніченості `M(r, t)`, модуль якого в наближенні постійної температури нижче точки Кюрі залишається строго постійним і дорівнює намагніченості насичення `|M| = M_s`.

Динаміка вектора `M` під дією ефективного магнітного поля `H_eff` описується феноменологічним рівнянням Ландау — Ліфшиця — Ґільберта:

```
∂M/∂t = -γ · (M × H_eff) + (α / M_s) · (M × ∂M/∂t)
```

де:
- `γ = g · μ_B / ℏ ≈ 1.76 · 10¹¹ rad/(s·T)` — гіромагнітне відношення електронного спіна;
- `α` — безрозмірний коефіцієнт затухання Ґільберта (`10⁻⁴ ≤ α ≤ 10⁻²`);
- `H_eff` — ефективне магнітне поле, яке є варіаційною похідною повної вільної енергії системи `F[M]`.

### Компоненти ефективного поля H_eff

Повна вільна енергія феромагнетика враховує чотири ключові взаємодії: зеєманівську, обмінну, диполь-дипольну (демагнетизаційну) та магнітну анізотропію:

```
H_eff = - (1 / μ₀) · (δF / δM)
      = H_Zeeman + H_exchange + H_dipolar + H_anisotropy
```

Розпишемо кожен доданок окремо з їхніми фізичними коефіцієнтами:

1. **Зовнішнє зеєманівське поле:**
   ```
   H_Zeeman = H_0
   ```
   де `H_0` — постійне зовнішнє магнітне поле підмагнічування.

2. **Неоднорідне обмінне поле:**
   Виникає через квантову обмінну взаємодію між сусідніми спінами при просторовій неоднорідності напрямку намагніченості:
   ```
   H_exchange = (2 · A_ex / (μ₀ · M_s²)) · ∇² M
   ```
   де `A_ex` — константа обмінного зв'язку (`J/m`), `∇²` — оператор Лапласа.

3. **Магнітостатичне (диполь-дипольне) поле розсіювання:**
   Визначається рівняннями магнітостатики і залежить від геометричної форми зразка та об'ємних магнітних зарядів `ρ_m = -∇·M`:
   ```
   ∇ × H_dipolar = 0  ⇒  H_dipolar = -∇ Φ_m
   ∇ · B = 0  ⇒  ∇² Φ_m = ∇ · M
   ```

4. **Поле кристалографічної анізотропії (для одновісного кристала вздовж осі z):**
   ```
   H_anisotropy = (2 · K_u / (μ₀ · M_s²)) · M_z · e_z
   ```
   де `K_u` — константа одновісної анізотропії (`J/m³`).

## 2. Лінеаризація LLG та тензор магнітної проникності Полдера

Припустимо, що феромагнетик намагнічений до насичення вздовж осі `z` під дією поля `H_0 · e_z`. Малі динамічні відхилення намагніченості `m(r, t) = (m_x, m_y, 0)` задовольняють умову `|m| << M_s`, тому поздовжня компонента становить `M_z ≈ M_s - (m_x² + m_y²) / (2 · M_s) ≈ M_s`.

Підставимо розклад `M = m_x · e_x + m_y · e_y + M_s · e_z` у рівняння `LLG` та знехтуємо квадратичними за амплітудою доданими `O(m²)`:

```
∂m_x/∂t = -γ · (m_y · H_eff,z - M_s · H_eff,y) + α · (∂m_y/∂t)
∂m_y/∂t = -γ · (M_s · H_eff,x - m_x · H_eff,z) - α · (∂m_x/∂t)
```

Для гармонічної високочастотної хвилі `exp(-i · ω · t)` зв'язок між динамічною індукцією `b = μ₀ · (h + m)` та високочастотним магнітним полем `h` описується тензором магнітної проникності Полдера `μ̂`:

```
b = μ₀ · μ̂ · h
```

Тензор Полдера `μ̂` має анізотропну асиметричну структуру:

```
μ̂ = [  μ    i·κ   0  ]
    [ -i·κ   μ    0  ]
    [  0     0    1  ]
```

Компоненти тензора `μ` та `κ` виражаються через резонансні частоти спинової системи:

```
ω_0 = γ · μ₀ · H_0              [частота Лармора]
ω_M = γ · μ₀ · M_s              [характеристична магнонна частота]

μ = 1 + (ω_0 · ω_M) / (ω_0² - ω²)
κ = (ω · ω_M) / (ω_0² - ω²)
```

Наявність уявних офф-діагональних елементів `±i·κ` відображає гіротропну природу магнітного середовища: праві та ліві циркулярно поляризовані хвилі поширюються з різними фазовими швидкостями (ефект Фарадея для спінових хвиль).

## 3. Аналітичні моди магнітостатичних хвиль Деймона — Ешбаха

У тонких феромагнітних плівках товщиною `d` при низьких хвильових числах (`k < 10⁵ см⁻¹`) диполь-дипольна взаємодія домінує над обмінною. У цьому діапазоні існують три основні геометричні моди магнітостатичних хвиль.

### 1. Поверхневі магнітостатичні хвилі Деймона — Ешбаха (MSSW)

Поле підмагнічування `H_0` спрямоване у площині плівки вздовж осі `z`, а хвильовий вектор `k` перпендикулярний до поля і лежить у площині плівки (вздовж осі `y`).

Розв'язок рівняння Лапласа для магнітостатичного потенціалу `∇² Φ_m = 0` з урахуванням граничних умов неперервності тангенціального поля `h_y` та нормальної індукції `b_x` на поверхнях плівки `x = ±d/2` дає дисперсійне співвідношення Деймона — Ешбаха:

```
ω² = ω_0 · (ω_0 + ω_M) + (1 / 4) · ω_M² · (1 - exp(-2 · k · d))
```

Граничні частоти моди Деймона — Ешбаха виражаються аналітично:

```
ω_min = √[ ω_0 · (ω_0 + ω_M) ]          [при k → 0, дно моди FMR]
ω_max = ω_0 + (1 / 2) · ω_M             [при k → ∞, поверхнева межа]
```

Особливістю хвиль Деймона — Ешбаха є їхня **невзаємність (несимметрія):** хвиля, що поширюється у напрямку `+k`, локалізується біля верхньої поверхні плівки, а хвиля у напрямку `-k` — біля нижньої поверхні.

### 2. Прямі об'ємні магнітостатичні хвилі (MSFVW)

Поле підмагнічування `H_0` спрямоване перпендикулярно до площини плівки (вздовж осі `x`). Дисперсійне співвідношення має вигляд:

```
ω² = ω_0 · (ω_0 + ω_M · (1 - (1 - exp(-k · d)) / (k · d)))
```

Групова швидкість `v_g = ∂ω/∂k > 0` є позитивною (пряма хвиля), а фазова та групова швидкості співспрямовані.

### 3. Зворотні об'ємні магнітостатичні хвилі (MSBVW)

Поле `H_0` спрямоване у площині плівки паралельно до хвильового вектора `k` (вздовж осі `z`). Дисперсійне співвідношення:

```
ω² = ω_0 · (ω_0 + ω_M · ((1 - exp(-k · d)) / (k · d)))
```

Для цієї моди групова швидкість є від'ємною `v_g = ∂ω/∂k < 0`: фазова швидкість спрямована в один бік, а потік енергії (вектор Пойнтінга спінової хвилі) — у протилежний бік.

## 4. Дисипація енергії та коефіцієнт Ґільберта α

Коефіцієнт `α` визначає швидкість релаксації спінової системи до рівноважного стану. Розрахуємо швидкість втрати густини енергії спінової хвилі `w_m = -μ₀ · M · H_eff`:

```
dw_m / dt = -μ₀ · (∂M / ∂t) · H_eff
```

Виразимо поле `H_eff` з вихідного рівняння `LLG`, векторно помноживши його на `M`:

```
M × (∂M / ∂t) 
= -γ · M × (M × H_eff) + (α / M_s) · M × (M × ∂M / ∂t)
= γ · (M² · H_eff - (M · H_eff) · M) - α · M_s · (∂M / ∂t)
[використано тотожність векторного подвійного добутку A × (B × C) = B(A·C) - C(A·B)]
```

Скалярний добуток `(∂M/∂t) · H_eff` дає точний вираз для швидкості дисипації енергії в одиниці об'єму магнетика:

```
dw_m / dt = - (α · μ₀ / (γ · M_s)) · (∂M / ∂t)²
```

Звідси видно, що втрата енергії пропорційна квадрату швидкості зміни намагніченості `(∂M/∂t)²`. 

Час життя магнона `τ_m` та довжина його вільного пробігу `λ_prop` прямо зв'язані з коефіцієнтом Ґільберта:

```
τ_m = 1 / (α · ω)
λ_prop = v_g · τ_m = (∂ω / ∂k) / (α · ω)
```

У монокристалах залізо-ітрієвого гранату (`α ≈ 10⁻⁴`) при частоті `ω / (2π) = 10 ГГц` час життя становить `τ_m ≈ 1.6 мкс`, що при груповій швидкості `v_g = 10 км/с` дає пробіг хвилі `λ_prop ≈ 1.6 см`.

## 5. Матриці переходу (TMM) та 1D магнонні кристали

Розглянемо 1D магнонний кристал, у якому намагніченість насичення або товщина хвилеводу періодично змінюється вздовж осі `x` з періодом `a`: `M_s(x + a) = M_s(x)`.

Нехай один період складений з двох шарів (А та В) товщиною `d_A` та `d_B` (`a = d_A + d_B`).

Усередині кожного однорідного шару `j ∈ {A, B}` хвильове рівняння для обвідної магнонної хвилі `ψ(x) = m_x(x)` має вигляд:

```
d²ψ_j / dx² + k_j²(ω) · ψ_j = 0
```

де хвильове число у відповідній зоні визначається з локального дисперсійного співвідношення:

```
k_j(ω) = √[ (ω / (γ · μ₀) - H_0) · (μ₀ · M_s,j / (2 · A_ex)) ]
```

### Запис розв'язку через матрицю переходу

Розв'язок у шарі `j` є сумою падаючої та відбитої хвиль:

```
ψ_j(x) = C_j⁺ · exp(i · k_j · x) + C_j⁻ · exp(-i · k_j · x)
```

Вектор стану системи `v(x) = [ψ(x), (1 / k_j) · dψ/dx]ᵀ` при переході через шар товщиною `d_j` трансформується матрицею шару `M_j`:

```
v(x + d_j) = M_j · v(x)

M_j = [ cos(k_j · d_j)        sin(k_j · d_j) ]
      [ -sin(k_j · d_j)       cos(k_j · d_j) ]
```

При переході через межу розділу шарів A і B із константами обміну `A_ex,A` та `A_ex,B` умови неперервності спінового відхилення та спінового струму `J_s = A_ex · (dψ/dx)` задаються матрицею границі `T_AB`:

```
T_AB = [ 1                     0              ]
       [ 0         (A_ex,A · k_A) / (A_ex,B · k_B) ]
```

Матриця переходу за повний період кристала `M_unit` є добутком матриць шарів та границь:

```
M_unit = T_BA · M_B · T_AB · M_A
```

### Теорема Блоха та заборонені зони (Band Gaps)

Згідно з теоремою Блоха для періодичних структур, вектор стану на кінцях періоду зв'язаний блохівським хвильовим числом `K`:

```
v(x + a) = exp(i · K · a) · v(x)
```

Отже, `exp(i · K · a)` є власним значенням матриці періоду `M_unit`. Оскільки детермінант матриці `det(M_unit) = 1`, її характеристичне рівняння `λ² - Tr(M_unit) · λ + 1 = 0` дає дисперсійне співвідношення для магнонного кристала:

```
cos(K · a) = (1 / 2) · Tr(M_unit(ω))
```

Розберемо два фізичні випадки для значення слідів матриці `Tr(M_unit)`:

1. **Дозволена зона поширення (Pass Band):**
   ```
   |Tr(M_unit(ω))| ≤ 2  ⇒  K ∈ ℝ (дійсне хвильове число)
   ```
   Магнонна хвиля вільно поширюється крізь кристал без загасання амплітуди.

2. **Заборонена зона (Magnonic Band Gap):**
   ```
   |Tr(M_unit(ω))| > 2  ⇒  K = n · (π / a) + i · Im(K)
   ```
   Хвильове число стає комплексним. Амплітуда спінової хвилі експоненціально згасає вглиб кристала `|ψ(x)| ∝ exp(-Im(K) · x)` унаслідок конструктивної бреггівської інтерференції відбитого магнонного потоку. 

Ширина першої забороненої зони `Δω_gap` на межі зони Бріллюена `K = π / a` пропорційна контрасту намагніченості насичення двох шарів `(M_s,A - M_s,B) / (M_s,A + M_s,B)`.
