# ⚙️ Чисельне моделювання дисперсії магнонів у 1D магнонному кристалі

Розрахунок дисперсійних характеристик та меж заборонених зон магнонних кристалів є необхідним етапом проектування спін-хвильових фільтрів, затримок та логічних елементів. Оскільки аналітичні розв'язки існують лише для найпростіших східчастих профілів намагніченості у нескінченному магнетику, у реальній інженерній практиці застосовують чисельний формалізм матрицій переходу (Transfer Matrix Method, TMM), метод скінченних різниць у часовій області (MicroMagnetic FDTD) або часове інтегрування рівняння Ландау — Ліфшиця — Ґільберта (LLG).

У цій вставці наведено розширений математичний аналіз алгоритму, розбір принципів побудови обчислювальної сітки та робочу програму розрахунку коефіцієнта пропускання `T(ω)`, аналізу спектра та локалізації магнонних заборонених зон 1D магнонного кристала з періодичною модуляцією намагніченості насичення `M_s(x)`.

## 1. Алгоритм та математична модель чисельного розрахунку

Розглядається 1D магнонний кристал, складений з `N` періодів. Кожен період довжиною `a = d_A + d_B` складається з шару A (товщина `d_A`, намагніченість `M_s,A`) та шару B (товщина `d_B`, намагніченість `M_s,B`).

Формалізм матриць переходу базується на представленні хвильової функції спінової прецесії `ψ(x) = m_x(x)` у вигляді векторів стану, які трансформуються при переході через межі та товщину шарів.

Для заданого діапазону частот `ω ∈ [ω_min, ω_max]` алгоритм виконує такі послідовні обчислювальні кроки:

### Крок 1. Обчислення локальних хвильових чисел

Для кожного матеріального шару `j ∈ {A, B}` розраховується комплексне хвильове число `k_j(ω)` з урахуванням обмінного та зеєманівського внесків:

```
k_j(ω) = √[ (ω / (γ · μ₀) - H_0) · (μ₀ · M_s,j / (2 · A_ex)) ]
```

Якщо частота знаходиться нижче дна спін-хвильового спектра (`ω / (γ · μ₀) < H_0`), значення під коренем стає від'ємним, а хвильове число — чисто уявним `k_j = i · Im(k_j)`. Це описує згасаючі моди (evanescent waves), які не поширюються у хвилеводі, а створюють непередаване локальне поле прецесії біля входу.

### Крок 2. Формування матриць переходу шарів M_j

Усередині однорідного шару товщиною `d_j` зв'язок між амплітудою хвилі та її похідною задається матрицею розміром 2×2:

```
M_j = [ cos(k_j · d_j)           sin(k_j · d_j) / k_j ]
      [ -k_j · sin(k_j · d_j)    cos(k_j · d_j)       ]
```

Для запобігання втраті точності при діленні на близьке до нуля число `|k_j| → 0` застосовується граничний перехід `sin(k_j · d_j) / k_j → d_j`.

### Крок 3. Граничні умови та підсумкова матриця кристала

На кожній межі розподілу шарів A і B виконуються умови неперервності спінового відхилення та нормальної компоненти спінового струму:

```
ψ_A(x_int) = ψ_B(x_int)
A_ex,A · (dψ_A / dx) = A_ex,B · (dψ_B / dx)
```

З урахуванням граней розділу між шарами A та B, матриця одного періоду обчислюється як добуток локальних матриць шарів та меж:

```
M_cell = M_B · T_AB · M_A
```

Підсумкова матриця транспортування через весь кристал з `N` періодів обчислюється піднесенням матриці періоду до ступеня `N`:

```
M_total = (M_cell)ᴺ
```

В алгоритмі для забезпечення максимальної швидкодії піднесення до ступеня виконується методом бінарного піднесення (Binary Exponentiation) за час `O(log N)`.

### Крок 4. Розрахунок енергетичного пропускання T(ω)

З елементів підсумкової комплексної матриці `M_total = [[m₁₁, m₁₂], [m₂₁, m₂₂]]` обчислюється амплітудний коефіцієнт пропускання `t(ω)` та енергетичний коефіцієнт передачі сигналів `T(ω) = |t(ω)|²`:

```
t(ω) = 2 / ( m₁₁ + m₂₂ - i · (k_in · m₁₂ + m₂₁ / k_in) )
T(ω) = |t(ω)|²
```

де `k_in = k_A` — хвильове число у вхідному напівнескінченному хвилеводі.

Частотні інтервали, на яких енергетичне пропускання падає нижче порогового значення `T(ω) < 0.05` (згасання сигналу понад 13 дБ), класифікуються алгоритмом як **магнонні заборонені зони** (*magnonic band gaps*).

## 2. Порівняння TMM з мікромагнітним моделюванням FDTD / Mumax3

Поряд із матричним формалізмом `TMM`, для моделювання двовимірних та тривимірних магнонних кристалів застосовують чисельне часове інтегрування рівняння `LLG` методом скінченних різниць у часовій області (MicroMagnetic FDTD):

1. **Дискретизація простору:** Об'єм магнетика розбивається на ортогональні комірки розбиття розміром `Δx × Δy × Δz`. Розмір комірки не повинен перевищувати обмінну довжину матеріалу `l_ex = √(2·A_ex / (μ₀·M_s²))` (для YIG `l_ex ≈ 15 нм`, для пермалою `l_ex ≈ 5 нм`), інакше кут між сусідніми спінами буде розраховано з похибкою.
2. **Умова Куранта — Фрідріхса — Леві (CFL):** Крок за часом `Δt` обмежується максимальною частотою спінової прецесії та обмінною жорсткістю:
   ```
   Δt < (μ₀ · M_s · Δx²) / (4 · γ · A_ex)   [зазвичай Δt ≈ 10⁻¹⁴ – 10⁻¹³ с]
   ```
3. **Метод розрахунку спектра:** На вхід хвилевода подається короткий імпульс магнітного поля `h(t) = h_0 · sinc(ω_cut · t)`, який одночасно збуджує широкий спектр магнонів від `0` до `ω_cut`. Після проходження сигналу крізь кристал виконується двовимірне швидке перетворення Фур'є (2D FFT) часового та просторового розподілу намагніченості `m(x, t) → m(k, ω)`, що дає повну спектральну карту дисперсії.

Нижче наведено робочі програмні реалізації чисельного розрахунку спектра пропускання 1D магнонного кристала методом TMM.

```py
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
Чисельний розрахунок спектра пропускання та заборонених зон 1D магнонного кристала.
Метод: Матриці переходу (Transfer Matrix Method).
"""

import math
import cmath

def solve_magnonic_crystal():
    # Фізичні константи
    gamma = 1.76e11        # Гіромагнітне відношення (рад / (с · Тл))
    mu0 = 4.0 * math.pi * 1e-7 # Магнітна стала (Гн / м)
    A_ex = 3.7e-12         # Обмінна константа YIG (Дж / м)

    # Параметри підмагнічування та геометрія кристала
    H0 = 1000.0 * (1000.0 / (4.0 * math.pi)) # Поле підмагнічування (А/м, ~1000 Естед)
    
    # Шари періоду A та B
    Ms_A = 140.0 * 1e3    # Намагніченість шару A (А/м, чистий YIG)
    Ms_B = 100.0 * 1e3    # Намагніченість шару B (А/м, імплантований YIG)
    
    dA = 150e-9           # Товщина шару A (150 нм)
    dB = 150e-9           # Товщина шару B (150 нм)
    num_periods = 10      # Кількість періодів кристала

    # Частотний діапазон для сканування (від 3 до 10 ГГц)
    f_start = 3.0e9
    f_stop = 10.0e9
    num_steps = 350
    df = (f_stop - f_start) / num_steps

    print("=== Розрахунок магнонного кристала (TMM) ===")
    print(f"Періодів: {num_periods}, d_A = {dA*1e9:.0f} нм, d_B = {dB*1e9:.0f} нм")
    print("---------------------------------------------------------")
    print("Частота (ГГц) | Пропускання T(w) | Стан зони")
    print("---------------------------------------------------------")

    band_gaps = []
    in_gap = False
    gap_start = 0.0

    for i in range(num_steps + 1):
        f = f_start + i * df
        omega = 2.0 * math.pi * f

        # Обчислення хвильових чисел у шарах A та B
        val_A = (omega / gamma - mu0 * H0) * (mu0 * Ms_A / (2.0 * A_ex))
        val_B = (omega / gamma - mu0 * H0) * (mu0 * Ms_B / (2.0 * A_ex))

        k_A = cmath.sqrt(complex(val_A, 0.0))
        k_B = cmath.sqrt(complex(val_B, 0.0))

        # Матриця переходу для шару A
        m11_A = cmath.cos(k_A * dA)
        m12_A = cmath.sin(k_A * dA) / k_A if abs(k_A) > 1e-12 else complex(dA, 0)
        m21_A = -k_A * cmath.sin(k_A * dA)
        m22_A = cmath.cos(k_A * dA)

        # Матриця переходу для шару B
        m11_B = cmath.cos(k_B * dB)
        m12_B = cmath.sin(k_B * dB) / k_B if abs(k_B) > 1e-12 else complex(dB, 0)
        m21_B = -k_B * cmath.sin(k_B * dB)
        m22_B = cmath.cos(k_B * dB)

        # Перемноження матриць одного періоду M_cell = M_B * M_A
        c11 = m11_B * m11_A + m12_B * m21_A
        c12 = m11_B * m12_A + m12_B * m22_A
        c21 = m21_B * m11_A + m22_B * m21_A
        c22 = m21_B * m12_A + m22_B * m22_A

        # Зведення в ступінь N (кількість періодів)
        res11, res12 = complex(1, 0), complex(0, 0)
        res21, res22 = complex(0, 0), complex(1, 0)

        for _ in range(num_periods):
            n11 = res11 * c11 + res12 * c21
            n12 = res11 * c12 + res12 * c22
            n21 = res21 * c11 + res22 * c21
            n22 = res21 * c12 + res22 * c22
            res11, res12, res21, res22 = n11, n12, n21, n22

        # Коефіцієнт пропускання
        k_in = k_A
        denom = res11 + res22 - 1j * (k_in * res12 + res21 / k_in if abs(k_in) > 1e-12 else complex(0, 0))
        t_amp = 2.0 / denom if abs(denom) > 1e-12 else complex(0, 0)
        T_power = abs(t_amp) ** 2

        # Обмеження значення для коректного відображення
        T_power = min(1.0, max(0.0, T_power))

        is_gap = (T_power < 0.05)
        status = "ЗАБОРОНЕНА ЗОНА (GAP)" if is_gap else "Дозволена смуга"

        if i % 35 == 0:
            print(f"   {f/1e9:6.2f}    |     {T_power:6.4f}     | {status}")

        if is_gap and not in_gap:
            in_gap = True
            gap_start = f / 1e9
        elif not is_gap and in_gap:
            in_gap = False
            band_gaps.append((gap_start, f / 1e9))

    print("---------------------------------------------------------")
    print("Виявлені магнонні заборонені зони:")
    for idx, (g_s, g_e) in enumerate(band_gaps, 1):
        print(f"  Зона {idx}: від {g_s:.2f} ГГц до {g_e:.2f} ГГц (ширина: {(g_e - g_s)*1e3:.1f} МГц)")

if __name__ == "__main__":
    solve_magnonic_crystal()
```

```cpp
#include <iostream>
#include <vector>
#include <complex>
#include <cmath>
#include <iomanip>
#include <numbers>
#include <algorithm>

// Структура комплесної матриці 2x2 для TMM
struct Matrix2x2 {
    std::complex<double> m11{1.0, 0.0};
    std::complex<double> m12{0.0, 0.0};
    std::complex<double> m21{0.0, 0.0};
    std::complex<double> m22{1.0, 0.0};

    constexpr Matrix2x2 operator*(const Matrix2x2& rhs) const noexcept {
        return Matrix2x2{
            m11 * rhs.m11 + m12 * rhs.m21,
            m11 * rhs.m12 + m12 * rhs.m22,
            m21 * rhs.m11 + m22 * rhs.m21,
            m21 * rhs.m12 + m22 * rhs.m22
        };
    }
};

// Розрахунок піднесення матриці до цілочисельного ступеня N
Matrix2x2 matrix_power(Matrix2x2 base, std::size_t exp) {
    Matrix2x2 result;
    while (exp > 0) {
        if (exp & 1) {
            result = result * base;
        }
        base = base * base;
        exp >>= 1;
    }
    return result;
}

int main() {
    // Фізичні константи
    constexpr double gamma = 1.76e11;                           // Гіромагнітне відношення
    constexpr double mu0 = 4.0 * std::numbers::pi * 1e-7;       // Магнітна стала
    constexpr double A_ex = 3.7e-12;                            // Обмінна константа YIG

    // Параметри 1D кристала
    constexpr double H0 = 1000.0 * (1000.0 / (4.0 * std::numbers::pi)); // Поле підмагнічування
    constexpr double Ms_A = 140.0e3;                            // Намагніченість шару A
    constexpr double Ms_B = 100.0e3;                            // Намагніченість шару B
    constexpr double dA = 150e-9;                               // 150 нм
    constexpr double dB = 150e-9;                               // 150 нм
    constexpr std::size_t num_periods = 10;

    constexpr double f_start = 3.0e9;
    constexpr double f_stop = 10.0e9;
    constexpr std::size_t num_steps = 350;
    constexpr double df = (f_stop - f_start) / num_steps;

    std::cout << "=== C++20 Simulation of 1D Magnonic Crystal (TMM) ===\n";
    std::cout << std::fixed << std::setprecision(4);
    std::cout << "Periods: " << num_periods << ", dA: " << dA * 1e9 << " nm, dB: " << dB * 1e9 << " nm\n";
    std::cout << "---------------------------------------------------------\n";
    std::cout << "Freq (GHz) | Transmit T(w) | Band Status\n";
    std::cout << "---------------------------------------------------------\n";

    for (std::size_t i = 0; i <= num_steps; ++i) {
        const double f = f_start + i * df;
        const double omega = 2.0 * std::numbers::pi * f;

        const double val_A = (omega / gamma - mu0 * H0) * (mu0 * Ms_A / (2.0 * A_ex));
        const double val_B = (omega / gamma - mu0 * H0) * (mu0 * Ms_B / (2.0 * A_ex));

        const std::complex<double> k_A = std::sqrt(std::complex<double>(val_A, 0.0));
        const std::complex<double> k_B = std::sqrt(std::complex<double>(val_B, 0.0));

        // Матриця переходу для шару A
        const Matrix2x2 MA{
            std::cos(k_A * dA),
            std::abs(k_A) > 1e-12 ? (std::sin(k_A * dA) / k_A) : std::complex<double>(dA, 0),
            -k_A * std::sin(k_A * dA),
            std::cos(k_A * dA)
        };

        // Матриця переходу для шару B
        const Matrix2x2 MB{
            std::cos(k_B * dB),
            std::abs(k_B) > 1e-12 ? (std::sin(k_B * dB) / k_B) : std::complex<double>(dB, 0),
            -k_B * std::sin(k_B * dB),
            std::cos(k_B * dB)
        };

        const Matrix2x2 M_cell = MB * MA;
        const Matrix2x2 M_total = matrix_power(M_cell, num_periods);

        const std::complex<double> i_unit{0.0, 1.0};
        const std::complex<double> denom = M_total.m11 + M_total.m22 - i_unit * (k_A * M_total.m12 + M_total.m21 / k_A);
        const std::complex<double> t_amp = (std::abs(denom) > 1e-12) ? (2.0 / denom) : 0.0;
        
        double T_power = std::norm(t_amp); // |t|^2
        T_power = std::clamp(T_power, 0.0, 1.0);

        if (i % 35 == 0) {
            const char* status = (T_power < 0.05) ? "MAGNONIC BAND GAP" : "Passband";
            std::cout << "  " << std::setw(6) << std::setprecision(2) << (f / 1e9)
                      << "    |     " << std::setw(6) << std::setprecision(4) << T_power
                      << "     | " << status << "\n";
        }
    }
    std::cout << "---------------------------------------------------------\n";

    return 0;
}
```

## 4. Аналіз чисельної стійкості та граничних умов

При застосуванні чисельного формалізму `TMM` для моделювання реальних магнонних пристроїв виникає низка практичних та математичних нюансів, які необхідно враховувати:

### Проблема чисельної нестійкості у глибоких заборонених зонах

У межах забороненої зони хвильове число є комплексним із великою уявною частиною `Im(k) > 0`. При піднесенні матриці переходу до великих ступенів `N > 20` елементи матриці зростають пропорційно `exp(N · Im(k) · a)`.

Це призводить до комп'ютерного переповнення сітки чисел з плаваючою крапкою (Floating Point Overflow). Для усунення цієї проблеми в промислових пакетах симуляції (наприклад, Mumax3 або OOMMF) замість T-матриць транспортування застосовують **S-матричний формалізм розсіювання** (Scattering Matrix Method). В S-матрицях відбиті та пропущені хвилі зв'язуються так, що експоненціально зростаючі додані діляться і перетворюються на стабільні згасаючі експоненти `exp(-Im(k)·a)`.

### Урахування закріплення спінів на межах (Spin Pinning Boundary Conditions)

На зовнішніх поверхнях магнітного хвилеводу або на межі з металевим покриттям поверхнева магнітна анізотропія може створювати ефект закріплення спінів.

Умови закріплення описуються граничною умовою Радо — Віртмана:

```
A_ex · (∂m / ∂n) + K_s · m = 0
```

де `n` — нормаль до поверхні, а `K_s` — поверхнева константа анізотропії. При повному закріпленні (`K_s → ∞`) відхилення намагніченості на границі дорівнює нулю `m(0) = 0`, що зміщує межі заборонених зон убік вищих частот на 5–15%.
