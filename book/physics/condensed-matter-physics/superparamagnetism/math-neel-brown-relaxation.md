# 🧮 Математичне виведення часу релаксації Нееля — Брауна та функції Ланжевена

Математичний апарат теорії суперпарамагнетизму спирається на дві фундаментальні моделі: статистичну механіку макроспінів у зовнішньому магнітному полі (функція Ланжевена) та стохастичну кінетику подолання потенціального бар'єра анізотропії під дією теплових флуктуацій (модель Нееля — Брауна). Нижче наведено послідовний вивід ключових співвідношень для орієнтаційної намагніченості, часу релаксації, температури блокування та кривих охолодження ZFC/FC однодоменної наночастинки.

## 1. Термодинаміка макроспінів: виведення функції Ланжевена

Розглянемо ансамбль сферичних однодоменних наночастинок об'ємом `V` із рівноважною намагніченістю насичення `M_s`. Оскільки всі атомні спіни усередині частинки зв'язані між собою обмінною взаємодією, магнітний момент кожної частинки формує один велетенський вектор — макроспін `μ`:

```
μ = M_s · V
```

У зовнішньому однорідному магнітному полі `H`, спрямованому вздовж просторової осі `Z`, потенціальна зееманівська енергія макроспіна, який утворює кут `θ` з напрямком поля, визначається виразом:

```
E(θ) = -μ0 · μ · H · cos(θ)
```

За законами статистичної фізики Больцмана, ймовірність того, що макроспін орієнтований під кутом `θ` у межах елементарного тілесного кута `dΩ = 2π · sin(θ) dθ`, описується термодинамічною щільністю розподілу `P(θ) dθ`:

```
P(θ) dθ = C · exp(-E(θ) / (k_B · T)) · 2π · sin(θ) dθ
= C · exp(μ0 · μ · H · cos(θ) / (k_B · T)) · 2π · sin(θ) dθ
```

де `C` — нормувальна константа, `k_B` — константа Больцмана, а `T` — абсолютна температура.

Введемо безрозмірний магніто-тепловий параметр поля `x`, який визначає відношення магнітної енергії макроспіна в зовнішньому полі до теплової енергії хаотичного руху:

```
x = μ0 · μ · H / (k_B · T)
= μ0 · M_s · V · H / (k_B · T)
```

Середне математичне значення проекції магнітного моменту частинки на напрямок зовнішнього поля `⟨μ_z⟩` розраховується як інтегральне усереднення за всіма можливостями просторової орієнтації:

```
⟨μ_z⟩ = ∫[0..π] (μ · cos(θ) · exp(x · cos(θ)) · sin(θ) dθ) / ∫[0..π] (exp(x · cos(θ)) · sin(θ) dθ)
```

Здійснюємо заміну змінної інтегрування `u = cos(θ)`. При куті `θ = 0` маємо `u = 1`; при куті `θ = π` маємо `u = -1`; диференціал дорівнює `du = -sin(θ) dθ`. Підставляючи нову змінну в чисельник та знаменник, отримуємо:

```
⟨μ_z⟩ / μ = ∫[-1..1] u · exp(x · u) du / ∫[-1..1] exp(x · u) du
```

Спочатку обчислюємо знаменник цього виразу, який являє собою статистичну суму орієнтаційних станів `Z(x)`:

```
Z(x) = ∫[-1..1] exp(x · u) du
= (1 / x) · [exp(x · u)][-1..1]    [інтегрування показникової функції]
= (exp(x) - exp(-x)) / x           [підстановка меж інтегрування]
= 2 · sinh(x) / x                  [означення гіперболічного синуса]
```

Чисельник виразу для нормованої намагніченості є тотожним похідній від статистичної суми `Z(x)` по безрозмірному полю `x`:

```
∫[-1..1] u · exp(x · u) du = dZ/dx
= d/dx [(exp(x) - exp(-x)) / x]    [похідна частки функцій]
= ((exp(x) + exp(-x)) · x - (exp(x) - exp(-x))) / x²    [правило диференціювання]
= 2 · cosh(x) / x - 2 · sinh(x) / x²                   [спрощення виразу]
```

Тепер підставляємо знайдені вирази для чисельника та знаменника у вихідне відношення середної намагніченості:

```
⟨μ_z⟩ / μ = (dZ/dx) / Z(x)
= (2 · cosh(x) / x - 2 · sinh(x) / x²) / (2 · sinh(x) / x)    [підстановка чисельника та знаменника]
= (cosh(x) / sinh(x)) - (1 / x)                                [ділення кожного доданка]
= coth(x) - 1 / x                                              [означення гіперболічного котангенса]
```

Отримана функція `L(x) = coth(x) - 1/x` називається функцією Ланжевена. Для ансамблю з `N` однакових невзаємодіючих однодоменних частинок у одиниці об'єму суммарна намагніченість середовища `M(H)` описується рівнянням:

```
M(H) = N · ⟨μ_z⟩
= N · μ · L(x)                                                                      [підстановка середної орієнтації ⟨μ_z⟩ = μ · L(x)]
= M_sat · (coth(μ0 · M_s · V · H / (k_B · T)) - (k_B · T / (μ0 · M_s · V · H)))    [позначення M_sat = N · μ та підстановка L(x)]
```

Розглянемо гранічні асимптотичні випадки слабких та сильних магнітних полів.

У слабких полях (`x ≪ 1`), коли тепловий рух домінує над магнітною енергією, розкладаємо гіперболічні функції в ряд Тейлора поблизу нуля:

```
coth(x) = 1/x + x/3 - x³/45 + ...   [розклад у ряд Тейлора]
```

Підставляємо розклад у функцію Ланжевена:

```
L(x) = (1/x + x/3 - x³/45 + ...) - 1/x
= x / 3                             [скорочення 1/x та нехтування вищими ступенями]
```

Звідси початкова магнітна сприйнятливість суперпарамагнітного ансамблю `χ_sp` у слабких полях дорівнює:

```
χ_sp = (dM / dH)[H->0]
= N · μ · (μ0 · μ / (3 · k_B · T))                    [диференціювання по полю H]
= μ0 · N · M_s² · V² / (3 · k_B · T)                 [підстановка μ = M_s · V]
```

У сильних полях (`x ≫ 1`), коли магнітні моменти майже повністю вишикувані вздовж поля, гіперболічний котангенс прямує до одиниці `coth(x) ≈ 1`:

```
L(x) ≈ 1 - 1 / x                    [асимптотика граничного значення]
```

Намагніченість наближається до абсолютного насичення `M_sat = N · M_s · V`.

## 2. Кінетика релаксації Нееля — Брауна

Розглянемо однодоменну частинку з одновісною кристалографічною анізотропією. Енергетичний профіль анізотропії як функція кута `θ` між макроспіном та легкою віссю описується виразом:

```
E(θ) = K_u · V · sin²(θ)
```

Цей потенціал містить два симетричні мінімуми в точках `θ = 0` (стан `+M_z`) та `θ = π` (стан `-M_z`), відокремлені максимумом у точці `θ = π/2` (важка вісь):

```
ΔE = E(π/2) - E(0)
= K_u · V · sin²(π/2) - 0           [підстановка кутів θ = π/2 та θ = 0]
= K_u · V                           [sin(π/2) = 1: висота енергетичного бар'єра]
```

Нехай `N_+` — кількість частинок у стані `+M_z`, а `N_-` — кількість частинок у стані `-M_z`. Загальна кількість частинок `N = N_+ + N_-`. Кінетичне рівняння зміни заселеності станів визначається ймовірностями термофлуктуаційного перескоку в одиницю часу `w_+` та `w_-`:

```
dN_+ / dt = -w_+ · N_+ + w_- · N_-
```

За відсутності зовнішнього магнітного поля через симетрію потенціалу ймовірності перескоку в обидва боки однакові: `w_+ = w_- = w`. 

Введемо різницеву заселеність `n = N_+ - N_-`, яка пропорційна сумарній намагніченості ансамблю. Записуємо диференціальне рівняння для `n`:

```
dn / dt = d/dt (N_+ - N_-)
= 2 · dN_+ / dt                     [враховуючи умову N_+ + N_- = N = const]
= 2 · (-w · N_+ + w · N_-)           [підстановка похідної dN_+/dt]
= -2 · w · (N_+ - N_-)               [винесення спільного множника -2w]
= -2 · w · n                         [підстановка n = N_+ - N_-]
```

Розв'язком цього лінійного диференціального рівняння першого порядку є експоненціальний закон згасання намагніченості:

```
n(t) = n(0) · exp(-t / τ)
```

де характерний час релаксації Нееля — Брауна `τ` зв'язаний із частотою перескоку `w` співвідношенням:

```
τ = 1 / (2 · w)
```

За теорією Крамерса для активаційного подолання потенційного бар'єра під дією гауссівського білого шуму, частота переходу `w` описується законом Арреніуса:

```
w = (1 / (2 · τ_0)) · exp(-K_u · V / (k_B · T))
```

Підставляючи вираз для `w` у формулу часу релаксації, отримуємо фундаментальне співвідношення Нееля — Брауна:

```
τ = 1 / (2 · (1 / (2 · τ_0)) · exp(-K_u · V / (k_B · T)))    [підстановка частоти перескоку w]
= τ_0 · exp(K_u · V / (k_B · T))                              [скорочення множника 2]
```

## 3. Модель Брауна для періоду спроби (attempt time τ_0)

Вільям Фуллер Браун показав, що часовий префактор `τ_0` не є довільною константою, а визначається прецесійною динамікою макроспіна у внутрішньому ефективному полі анізотропії `H_k = 2 · K_u / M_s` з урахуванням згасання Ґільберта `α`.

Стохастичне рівняння Ландау — Ліфшиця — Ґільберта (sLLG) для вектора намагніченості має вигляд:

```
dm/dt = -γ' · (m × H_eff) - α · γ' · (m × (m × H_eff))
```

де `γ' = γ / (1 + α²)`, `H_eff = H_aniso + H_th(t)`.

Шляхом розв'язання відповідного двохмірного рівняння Фоккера — Планка для точок повороту макроспіна на сферичній поверхні Браун вивів аналітичну формулу для періоду спроб `τ_0` у режимі помірного та сильного згасання (`α > 0.01`):

```
τ_0 = (M_s · (1 + α²)) / (2 · γ · α · K_u) · √(π · k_B · T / (K_u · V))
```

Звідси випливає, що префактор `τ_0` має слабку температурну залежність `~ √T`, проте у розрахунках при сталому `T` його приймають постійним у діапазоні:

```
10⁻¹¹ s ≤ τ_0 ≤ 10⁻⁹ s
```

Для більшості практичних задач використовують стандартну оцінку `τ_0 ≈ 10⁻⁹` с.

## 4. Математичне визначення температури блокування T_B

Температура блокування `T_B` визначає межу між заблокованим та суперпарамагнітним станами частинки під час вимірювання з тривалістю `τ_meas`.

За означенням, при `T = T_B` час релаксації дорівнює часу вимірювання приладу:

```
τ(T_B) = τ_meas
```

Підставляємо закон Нееля — Брауна:

```
τ_0 · exp(K_u · V / (k_B · T_B)) = τ_meas
```

Логарифмуємо обидві частини рівняння:

```
ln(τ_0) + K_u · V / (k_B · T_B) = ln(τ_meas)
```

Переносимо логарифмічний доданок у праву частину:

```
K_u · V / (k_B · T_B) = ln(τ_meas) - ln(τ_0)
= ln(τ_meas / τ_0)
```

Виражаємо температуру блокування `T_B`:

```
T_B = K_u · V / (k_B · ln(τ_meas / τ_0))
```

Звідси також випливає критерій критичного суперпарамагнітного об'єму частинки `V_sp` для збереження заблокованості при заданій температурі `T`:

```
V_sp = (k_B · T · ln(τ_meas / τ_0)) / K_u
```

Для стандартних лабораторних вимірювань магнітометром (SQUID або VSM, де `τ_meas ≈ 100` с, `τ_0 ≈ 10⁻⁹` с):

```
ln(τ_meas / τ_0) = ln(100 / 10⁻⁹) = ln(10¹¹) ≈ 25.3
```

Отримуємо класичне практичне правило для температури блокування лабораторних вимірювань:

```
K_u · V ≈ 25 · k_B · T_B
```

Для довготривалого магнітного збереження даних на жорстких дисках (час збереження `t = 10` років, `τ_meas ≈ 3.15 · 10⁸` с):

```
ln(τ_meas / τ_0) = ln(3.15 · 10⁸ / 10⁻⁹) = ln(3.15 · 10¹⁷) ≈ 40.3
```

З урахуванням коефіцієнта запасу за диперсією розмірів зерен промисловий критерій стабільності біта запису дорівнює:

```
K_u · V ≥ 60 · k_B · T
```

Якщо енергетичний бар'єр зерна `K_u · V` стає меншим за `60 k_B T`, ймовірність спонтанного термофлуктуаційного розмагнічування біта протягом 10 років стає неприпустимо високою.

## 5. Моделювання кривих намагнічування ZFC/FC

Під час вимірювання намагніченості у режимах ZFC (Zero-Field-Cooled) та FC (Field-Cooled) аналітична залежність `M(T)` описується сумою внесків заблокованих та суперпарамагнітних частинок.

Нехай частинки мають розподіл за об'ємами `f(V)` (наприклад, логнормальний). Для кожної температури `T` існує критичний об'єм розблокування `V_b(T)`:

```
V_b(T) = (k_B · T · ln(τ_meas / τ_0)) / K_u
```

Частинки з об'ємом `V < V_b(T)` перебувають у суперпарамагнітному стані й дають орієнтаційний внесок за функцією Ланжевена `M_sp(T) ∝ 1 / T`. Частинки з об'ємом `V > V_b(T)` перебувають у заблокованому стані.

У режимі ZFC частинки охолоджуються в нульовому полі, тому заблоковані частинки мають хаотичну орієнтацію моментів. Загальна намагніченість `M_ZFC(T)` розраховується сумою двох інтегралів:

```
M_ZFC(T) = (μ0 · H / (3 · k_B · T)) · ∫[0..V_b(T)] M_s² · V² · f(V) dV + (μ0 · H / (3 · K_u)) · ∫[V_b(T)..∞] M_s² · V · f(V) dV
```

Перший доданок описує суперпарамагнітні частинки (що зростають із температурою через збільшення межі `V_b(T)`), а другий — термостійкі заблоковані частинки. Точка максимуму кривої `M_ZFC(T)` точно відповідає середній температурі блокування ансамблю `T_B`.

У режимі FC частинки охолоджуються безпосередньо у слабкому магнітному полі `H`. Нижче температури блокування макроспіни частинок заморожуються уздовж поля, формуючи високу термозалишкову намагніченість. Крива `M_FC(T)` описується рівнянням:

```
M_FC(T) = (μ0 · H / (3 · k_B · T)) · ∫[0..V_b(T)] M_s² · V² · f(V) dV + ∫[V_b(T)..∞] M_s · V · L(μ0 · M_s · V · H / (k_B · T_B(V))) · f(V) dV
```

При низьких температурах `(T -> 0 K)` крива `M_FC(T)` виходить на насичене плато, тоді як `M_ZFC(T)` спадає до нуля, створюючи характерну температурну розбіжність двох кривих (ZFC/FC splitting).

## 6. Динамічна магнітна сприйнятливість у змінному полі

При прикладанні змінного магнітного поля `H(t) = H_0 · exp(i · ω · t)` комплексне значення динамічної магнітної сприйнятливості `χ(ω) = χ'(ω) - i · χ"(ω)` описується рівнянням Дебая:

```
χ(ω) = χ_sp / (1 + i · ω · τ)
```

Дійсна `χ'(ω)` та уявна `χ"(ω)` частини комплексного виразу розраховуються як:

```
χ'(ω) = χ_sp / (1 + ω² · τ²)
χ"(ω) = χ_sp · (ω · τ) / (1 + ω² · τ²)
```

- Дійсна частина `χ'(ω)` характеризує зворотний магнітний відгук частинки на змінне поле.
- Уявна частина `χ"(ω)` описує дисипативні втрати енергії поля та його перетворення у тепло.

Максимум уявної частини сприйнятливості `χ"(ω)` (пік дисипації) спостерігається при виконанні резонансної умови Дебая `ω · τ(T) = 1`. Зміна частоти поля `f = ω / (2π)` зсуває температурне положення піку, що дозволяє експериментально визначати часовий префактор `τ_0` та розподіл висот енергетичних бар'єрів `K_u · V`.
