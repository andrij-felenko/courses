# 🧮 Повне математичне виведення рівняння Пуассона — Больцмана та потенціалу Дебая

Ця вставка містить строгий математичний вивід потенціалу Дебая — Гюккеля у сферичній геометрії, розрахунок повного екранованого заряду, електростатичної енергії дебаївської хмари, розв'язок нелінійного рівняння Пуассона — Больцмана для плоского інтерфейсу (модель Ґуї — Чапмана), квантово-механічний вивід довжини екранування Томаса — Фермі для виродженого електронного газу та межі застосовності через довжину Б'єррума.

### 1. Виведення радіального рівняння у сферично симетричному випадку

Розглянемо безмежне ізотропне середовище з діелектричною проникністю `ε = ε_r · ε₀`, що містить вільно рухливі носії заряду із зарядами `q_i` та середньою об'ємною концентрацією `n_{i0}`. У точку `r = 0` поміщено точковий пробний заряд `Q`.

Електростатичний потенціал `Φ(r)` за наявності об'ємного заряду `ρ(r)` описується рівнянням Пуассона:

```
∇² Φ(r) = - ρ(r) / ε      [рівняння Пуассона]
```

У сферичній системі координат для радіально симетричного потенціалу оператор Лапласа має вигляд:

```
(1 / r²) · (d / dr) [ r² · (dΦ / dr) ] = - ρ(r) / ε
```

Концентрація носіїв сорту `i` у потенціальному полі `Φ(r)` описується статистичним розподілом Больцмана:

```
n_i(r) = n_{i0} · exp( - q_i · Φ(r) / (k_B · T) )
```

Об'ємна густина заряду `ρ(r)` дорівнює сумі внесків усіх типів носіїв:

```
ρ(r) = ∑ [ q_i · n_i(r) ] = ∑ [ q_i · n_{i0} · exp( - q_i · Φ(r) / (k_B · T) ) ]
```

### 2. Лінеаризація Дебая — Гюккеля та введення довжини екранування

У випадку слабкого поля, коли потенціальна енергія частинки є набагато меншою за її теплову енергію (`|q_i · Φ(r)| << k_B · T`), експоненціальний множник можна розкласти у ряд Тейлора:

```
exp( - q_i · Φ / (k_B · T) ) ≈ 1 - (q_i · Φ) / (k_B · T)
```

Підставивши цей розклад у вираз для об'ємної густини заряду, отримуємо:

```
ρ(r) ≈ ∑ [ q_i · n_{i0} · (1 - (q_i · Φ) / (k_B · T)) ]
ρ(r) = ∑ [ q_i · n_{i0} ] - Φ · ∑ [ (n_{i0} · q_i²) / (k_B · T) ]
```

Перша сума `∑ (q_i · n_{i0}) = 0` дорівнює нулю внаслідок макроскопічної електронейтральності середовища за відсутності збурення. Отже, лінеаризована густина заряду набуває вигляду:

```
ρ(r) = - [ ∑ (n_{i0} · q_i²) / (k_B · T) ] · Φ(r)
```

Підставимо отриманий вираз у рівняння Пуассона:

```
(1 / r²) · (d / dr) [ r² · (dΦ / dr) ] = [ ∑ (n_{i0} · q_i²) / (ε · k_B · T) ] · Φ(r)
```

Величина у квадратних дужках має розмірність квадрата оберненої довжини `1 / λ_D²`. Визначаємо **дебаївську довжину екранування** `λ_D`:

```
λ_D = √[ (ε · k_B · T) / (∑ n_{i0} · q_i²) ]
```

Тоді диференціальне рівняння спрощується до канонічної форми:

```
(1 / r²) · (d / dr) [ r² · (dΦ / dr) ] = (1 / λ_D²) · Φ(r)
```

### 3. Точний розв'язок радіального рівняння (потенціал Юкави)

Щоб розв'язати отримане рівняння, виконаємо стандартну заміну змінної `u(r) = r · Φ(r)`. Знайдемо похідні:

```
dΦ / dr = (1 / r) · (du / dr) - (1 / r²) · u
r² · (dΦ / dr) = r · (du / dr) - u
(d / dr) [ r² · (dΦ / dr) ] = (du / dr) + r · (d²u / dr²) - (du / dr) = r · (d²u / dr²)
```

Підставляючи цей вираз у рівняння Пуассона, маємо:

```
(1 / r²) · [ r · (d²u / dr²) ] = (1 / λ_D²) · (u / r)
d²u / dr² = (1 / λ_D²) · u
```

Це лінійне однорідне диференціальне рівняння второго порядку з постійними коефіцієнтами. Його загальний розв'язок дорівнює:

```
u(r) = C₁ · exp( - r / λ_D ) + C₂ · exp( + r / λ_D )
```

Повертаючись до початкового потенціалу `Φ(r) = u(r) / r`:

```
Φ(r) = (C₁ / r) · exp( - r / λ_D ) + (C₂ / r) · exp( + r / λ_D )
```

Застосуємо граничні умови:
1. На нескінченності потенціал мусить залишатися скінченним і прямувати до нуля: `lim_{r→∞} Φ(r) = 0`. Звідси `C₂ = 0`.
2. Поблизу точкового заряду (`r → 0`) екранування іонною хмарою ще не встигає проявитися, тому потенціал повинен переходити у звичайний потенціал Кулона `Φ(r) → Q / (4 · π · ε · r)`.

Оскільки `exp(-r / λ_D) → 1` при `r → 0`, отримуємо сталу `C₁ = Q / (4 · π · ε)`.

Остаточний точний розв'язок описує **екранований потенціал Дебая — Гюккеля** (у фізиці високих енергій відомий як потенціал Юкави):

```
Φ(r) = [ Q / (4 · π · ε · r) ] · exp( - r / λ_D )
```

Знайдемо напруженість електричного поля `E(r) = - dΦ/dr` шляхом диференціювання потенціалу:

```
E(r) = - (d / dr) [ (Q / (4·π·ε·r)) · exp(-r / λ_D) ]
E(r) = [ Q / (4 · π · ε · r²) ] · [ 1 + (r / λ_D) ] · exp( - r / λ_D )
```

При `r << λ_D` напруженість переходить у кулонівський закон `E(r) ≈ Q / (4·π·ε·r²)`, тоді як при `r >> λ_D` поле згасає експоненціально стрімко.

### 4. Інтегрування наведеного заряду та енергії дебаївської сфери

Доведемо строге математичне твердження: сумарний індукований заряд `Q_ind`, збережений у всій дебаївській хмарі від `r = 0` до `r = ∞`, тотожно дорівнює початковому пробному заряду зі протилежним знаком (`Q_ind = -Q`).

Обчислимо об'ємний інтеграл від лінеаризованої густини заряду `ρ(r) = - (ε / λ_D²) · Φ(r)` по всьому тривимірному простору у сферичних координатах:

```
Q_ind = ∫₀^∞ ρ(r) · 4 · π · r² dr
Q_ind = ∫₀^∞ [ - (ε / λ_D²) · (Q / (4·π·ε·r)) · exp(-r / λ_D) ] · 4 · π · r² dr
Q_ind = - (Q / λ_D²) · ∫₀^∞ r · exp(-r / λ_D) dr
```

Застосуємо метод інтегрування частинами для табличного інтеграла `∫₀^∞ r · exp(-a·r) dr = 1 / a²`, де `a = 1 / λ_D`:

```
∫₀^∞ r · exp(-r / λ_D) dr = λ_D²
```

Підставляючи обчислений інтеграл у вираз для `Q_ind`:

```
Q_ind = - (Q / λ_D²) · λ_D² = - Q
```

Таким чином, доведено, що дебаївська хмара містить точно такий самий за модулем і протилежний за знаком заряд, повністю компенсуючи зовнішнє кулонівське поле пробної частинки на макроскопічних відстанях.

Обчислимо власну електростатичну енергію `U_self` взаємодії центрального заряду `Q` з індукованою ним іонною атмосферою. Потенціал, створюваний власне іонною хмарою у точці розташування заряду `r = 0`, дорівнює:

```
Φ_cloud(0) = lim_{r→0} [ Φ(r) - Q / (4·π·ε·r) ]
Φ_cloud(0) = lim_{r→0} [ (Q / (4·π·ε·r)) · (exp(-r / λ_D) - 1) ]
```

Розкладаючи експоненту `exp(-r/λ_D) ≈ 1 - r/λ_D`, отримуємо скінченне значення потенціалу атмосфери у центрі:

```
Φ_cloud(0) = - Q / (4 · π · ε · λ_D)
```

Термодинамічна робота утворення іонної атмосфери (її вільна енергія Ґіббса) отримується інтегруванням за процесом поступового заряджання `q` від `0` до `Q`:

```
U_cloud = ∫₀^Q Φ_cloud(0, q) dq = ∫₀^Q [ - q / (4·π·ε·λ_D) ] dq = - Q² / (8 · π · ε · λ_D)
```

Ця від'ємна енергія показує, що утворення дебаївської хмари є енергетично вигідним процесом, який знижує повну вільну енергію системи.

### 5. Нелінійне плоске рівняння Пуассона — Больцмана (модель Ґуї — Чапмана)

У разі сильних полів біля плоскої поверхні електрода або напівпровідника (одновимірна координата `x ≥ 0`) лінеаризація є неприпустимою. Розглянемо симетричний 1:1 електроліт (`q = ±e`, `n₀`), де потенціал на межі `x = 0` дорівнює `Φ(0) = Φ₀`.

Густина заряду описується точним виразом:

```
ρ(x) = e · n₀ · [ exp(-e·Φ / k_B·T) - exp(+e·Φ / k_B·T) ] = - 2 · e · n₀ · sinh( e·Φ / (k_B·T) )
```

Рівняння Пуассона в одновимірному випадку набуває вигляду:

```
d²Φ / dx² = (2 · e · n₀ / ε) · sinh( e·Φ / (k_B·T) )
```

Ввівши безрозмірний потенціал `y = e·Φ / (k_B·T)` та згадавши визначення `λ_D² = (ε · k_B · T) / (2 · n₀ · e²)`, переписуємо рівняння:

```
d²y / dx² = (1 / λ_D²) · sinh(y)
```

Помножимо обидві частини на `2 · (dy/dx)` та інтегруємо за `x`:

```
(dy / dx)² = (2 / λ_D²) · cosh(y) + C
```

З граничної умови на нескінченності (`x → ∞`: `y → 0`, `dy/dx → 0`) маємо `C = - 2 / λ_D²`, оскільки `cosh(0) = 1`:

```
(dy / dx)² = (2 / λ_D²) · [ cosh(y) - 1 ] = (4 / λ_D²) · sinh²(y / 2)
dy / dx = - (2 / λ_D) · sinh(y / 2)
```

Інтегруючи це першоподібне рівняння з граничною умовою `y(0) = y₀`, отримуємо точний розв'язок Ґуї — Чапмана:

```
tanh( y(x) / 4 ) = tanh( y₀ / 4 ) · exp( - x / λ_D )
```

У межі малого потенціалу `y₀ << 1` з огляду на `tanh(z) ≈ z` точний розв'язок переходить у класичний експоненціальний спад: `Φ(x) = Φ₀ · exp(-x / λ_D)`.

Знайдемо повний поверхневий заряд `σ_surf` на одиницю площі електрода за теоремою Гаусса `σ_surf = - ε · (dΦ/dx)|_{x=0}`:

```
σ_surf = ε · (2 · k_B · T / (e · λ_D)) · sinh( e · Φ₀ / (2 · k_B · T) )
σ_surf = √[ 8 · ε · n₀ · k_B · T ] · sinh( e · Φ₀ / (2 · k_B · T) )
```

Диференціальна ємність подвійного електричного шару `C_diff = dσ_surf / dΦ₀` дорівнює:

```
C_diff = (ε / λ_D) · cosh( e · Φ₀ / (2 · k_B · T) )
```

При малих потенціалах ємність дорівнює ємності плоского конденсатора з товщиною `λ_D` (`C₀ = ε / λ_D`), а при зростанні поверхневого потенціалу `Φ₀` ємність зростає експоненціально через накопичення протиіонного шару.

### 6. Квантова межа: виведення довжини Томаса — Фермі для виродженого газу

У металах електронний газ є повністю виродженим (`T << T_F`). Густина станів залежить від енергії як `g(E) = (1 / (2·π²)) · (2·m* / ℏ²)^(3/2) · √E`.

Зміна потенціалу `Φ(x)` зсуває локальне дно зони провідності, викликаючи зміну місцевої концентрації вільних електронів:

```
δn(x) = g(E_F) · e · Φ(x)      [зміщення фермієвського рівня]
```

Густина станів на рівні Фермі `g(E_F)` виражається через середню концентрацію `n₀` та енергію Фермі `E_F = (ℏ² / 2m*) · (3·π²·n₀)^(2/3)`:

```
g(E_F) = (3 / 2) · (n₀ / E_F)
```

Підставляючи індуковану густину заряду `ρ(x) = - e · δn(x) = - e² · g(E_F) · Φ(x)` у рівняння Пуассона `d²Φ / dx² = - ρ / ε₀`, отримуємо:

```
d²Φ / dx² = [ (e² · g(E_F)) / ε₀ ] · Φ(x) = (1 / λ_TF²) · Φ(x)
```

Звідси визначається **довжина екранування Томаса — Фермі** `λ_TF`:

```
λ_TF = √[ (ε₀ · E_F) / (e² · g(E_F)) ] = √[ (2 · ε₀ · E_F) / (3 · n₀ · e²) ]
```

Підставляючи вираз для `E_F`, отримуємо квантову залежність від концентрації носіїв:

```
λ_TF = √[ (ε₀ · ℏ² · π^(2/3)) / (m* · e² · (3·n₀)^(1/3)) ]
```

Збільшення густини електронного газу `n₀` приводить до скорочення квантового радіуса екранування як `n₀^(-1/6)`.

### 7. Межі застосовності теорії та довжина Б'єррума

Теорія Дебая — Гюккеля спирається на середньопольове наближення, яке припускає, що тепловий рух домінує над кулонівською взаємодією сусідніх частинок. Межа застосовності класичного дебаївського екранування визначається **довжиною Б'єррума** (*Bjerrum length*, `l_B`) — відстанню, на якій кулонівська енергія взаємодії двох однозарядних іонів дорівнює тепловій енергії `k_B T`:

```
l_B = e² / (4 · π · ε · k_B · T)
```

У воді за кімнатної температури (`ε_r ≈ 80`, `T = 300 K`) довжина Б'єррума становить `l_B ≈ 0.71 нм`.

Теорія Дебая є строго справедливою доти, доки дебаївська довжина суттєво перевищує довжину Б'єррума (`λ_D >> l_B`). Якщо ж концентрація іонів стає настільки високою, що `λ_D ≤ l_B`, кулонівське притягання перемагає тепловий рух, і у розчині виникають іонні пари (асоціати), а класична модель континуального екранування Пуассона — Больцмана втрачає чинність.
