### 2. Специфікація надпровідної магнітної системи ITER

Магнітна система токамака ITER є найбільшою та найскладнішою надпровідною конструкцією в історії фізичного приладобудування. Вона працює при температурі рідкого гелію `4.5 K` (`-268.65 °C`) і складається з чотирьох основних підсистем котушок:

1. **Котушки тороїдального поля (Toroidal Field, TF Coils):**
   - *Кількість:* 18 вертикальних D-подібних котушок.
   - *Матеріал надпровідника:* інтерметалід ніобій-олово (`Nb3Sn`), який зберігає надпровідність у високих магнітних полях до `12 Тл`.
   - *Робочий струм:* `68 000 А` на котушку.
   - *Максимальне магнітне поле на провіднику:* `11.8 Тл` (що забезпечує `5.3 Тл` у центрі плазмового шнура `R_0 = 6.2 м`).
   - *Маса системи TF:* `6540 тонн`.

2. **Центральний соленоїд (Central Solenoid, CS):**
   - *Конструкція:* 6 незалежних модульних секцій, зібраних у вертикальну колону висотою `13 м` та діаметром `4.3 м`.
   - *Матеріал надпровідника:* `Nb3Sn`.
   - *Максимальне поле на осі:* `13.0 Тл`.
   - *Запасний магнітний потік (індуктор):* `119 Вольт-секунд` (Вб), що забезпечує індукційний підйом та підтримку струму плазми `15 МА` протягом `400 секунд`.

3. **Котушки полоїдального поля (Poloidal Field, PF Coils):**
   - *Кількість:* 6 горизонтальних кілець діаметром від `8` до `24 метрів`, розташованих зовні TF-котушок.
   - *Матеріал надпровідника:* ніобій-титан (`NbTi`).
   - *Призначення:* керування положенням, витягнутістю `κ` та трикутністю `δ` плазмового шнура, формування X-точки та формування диверторної конфігурації.

4. **Котушки корекції (Correction Coils, CC):**
   - *Кількість:* 18 тонких прямокутних котушок, розсаджених на корпусі вакуумної камери.
   - *Призначення:* компенсація геометричних похибок монтажу магнітів та придушення помилкових магнітних полів (Error Fields), які можуть викликати замкнені дрейфові острови та зрив плазми.

### 3. Комплекс допоміжного нагріву та підтримки струму

Омічний нагрів плазми струмом `I_p` стає неефективним при досягненні температур `T_e > 2 ... 3 кеВ`, оскільки питомий електричний опір плазми Спітцера спадає з температурою за законом `η ∝ T_e^(-3/2)`. Для розігріву плазми ITER до термоядерної температури `15 кеВ` (`150 мільйонів K`) застосовується три незалежних системи додаткового нагріву сумарною потужністю `50 МВт`:

#### 1. Інжекція високоенергетичних нейтральних атомів (Neutral Beam Injection, NBI)
- *Принцип дії:* прискорені іони дейтерію проходять через газову обдирочну мішень, нейтралізуються і впорскуються у вакуумну камеру у вигляді пучка нейтральних атомів. Оскільки пучок нейтральний, він вільно перетинає периферичне магнітне поле, іонізується в центрі гарячої плазми і віддає свою кінетичну енергію іонам плазми при зіткненнях.
- *Енергія пучка:* `1.0 МеВ` (використовуються негативні іони дейтерію `D-`, оскільки при енергіях понад `100 кеВ` коефіцієнт нейтралізації позитивних іонів `D+` прямує до нуля).
- *Вхідна потужність:* 2 інжектори по `16.5 МВт` (всього `33 МВт`).

#### 2. Іонно-циклотронний резонансний нагрів (Ion Cyclotron Heating, ICRH)
- *Принцип дії:* антени у вакуумній камері випромінюють швидкі магнітозвукові хвилі на циклотронній частоті іонів дейтерію або тритію (`ω = ω_ci`). Хвиля резонансно поглинається іонами, збільшуючи їхню перпендикулярну швидкість `v_perp`.
- *Частотний діапазон:* `40–55 МГц`.
- *Вхідна потужність:* `20 МВт`.

#### 3. Електронно-циклотронний резонансний нагрів (Electron Cyclotron Heating, ECRH)
- *Принцип дії:* потужні генератори надвисокочастотного випромінювання (гіротрони) генерують звичайну або незвичайну хвилю на циклотронній частоті електронів (`ω = ω_ce`).
- *Частота випромінювання:* `170 ГГц` (довжина хвилі `1.76 мм`).
- *Вхідна потужність:* 24 гіротрони сумарною потужністю `20 МВт`.
- *Додаткова функція:* вузьконапрямлений пристінковий нагрів дозволяє стабілізувати неокласичні тирринг-моди (`3/2` та `2/1` магнітні острови) шляхом локальної генерації струму безпосередньо всередині магнітного острова (Electron Cyclotron Current Drive, ECCD).

### 4. Ключові фізичні межі та оперативні константи

При експлуатації установок магнітного утримання плазми діють суворі фізичні обмеження, виходи за межі яких призводить до розвитку нестійкостей та раптового скидання енергії (зриву):

#### 1. Межа бета Троона (Troyon Beta Limit)
Максимальне відношення тиску плазми до магнітного тиску у токамаку обмежене виникненням желобкових нестійкостей та роздуванням шнура:

```
β_max (%) = β_N · ( I_p / (a · B_0) )
```

де:
- `I_p` — струм плазми в мегаамперах (МА);
- `a` — малий радіус у метрах (м);
- `B_0` — тороїдальне магнітне поле в теслах (Тл);
- `β_N` — нормалізований коефіцієнт бета. Для стандартного H-режиму `β_N ≈ 2.8 ... 3.5`.

#### 2. Межа густини Ґрінвальда (Greenwald Density Limit)
Максимальна середня густина плазми `n_e` у токамаку, перевищення якої викликає охолодження краю та радіаційний зрив:

```
n_GW (10²⁰ м⁻³) = I_p / (π · a²)
```

Для ITER при `I_p = 15 MA` та `a = 2.0 m` межа Ґрінвальда становить `n_GW ≈ 1.2 · 10²⁰ м⁻³`.

#### 3. Коефіцієнт запасу стійкості на краю (Safety Factor `q_95`)
Полоїдальний крок викручування силової лінії на рівні 95% магнітного потоку. Для запобігання розвитку катастрофічної зовнішньої гвинтової нестійкості (Kink mode) повинна виконуватися умова:

```
q_95 = (5 · a² · B_0 / (R_0 · I_p)) · [ (1 + κ²) / 2 ] ≥ 3.0
```

#### 4. Граничні теплові навантаження на дивертор
Вузький шар відскрібання (Scrape-Off Layer, SOL) фокусує вихідну потужність плазми на пластини дивертора.
- **Нерегульований питомий тепловий потік:** `q_div > 50 МВт/м²` (що перевищує тепловий потік на поверхні Сонця);
- **Допустима стаціонарна інженерна межа вольфрамових диверторних моноблоків:** `q_eng ≤ 10 МВт/м²`;
- **Необхідна частка випромінювання домішками (Neon/Argon) у SOL:** `f_rad ≥ 80–90%`.

### 5. Потрійний добуток Лоусона та параметри горіння плазми

Для досягнення самопідтримуваної термоядерної реакції горіння плазми (ignition), де альфа-частинки повністю компенсують втрати тепла без зовнішнього нагріву (`Q → ∞`), потрійний добуток Лоусона повинен перевищувати порогове значення:

```
n_e · τ_E · T_i ≥ 3 · 10²¹  [ м⁻³ · с · кеВ ]
```

Для реакційного середовища дейтерій-тритій (D-T):
- Оптимальна іонна температура: `T_i ≈ 10 ... 20 кеВ` (`115 ... 230 мільйонів К`);
- Необхідний час утримання тепла для токамака розміру ITER: `τ_E ≈ 3.5 ... 4.0 с`;
- Вихід енергії на один акт реакції `D + T → ⁴He (3.5 МеВ) + n (14.1 МеВ)` становить `17.6 МеВ`. Енергія альфа-частинок `3.5 МеВ` залишається у плазмі для її самонагріву, а швидкі нейтрони `14.1 МеВ` вільно залишають магнітну пастку і поглинаються бланкетом першої стінки, де генерують тепло для парової турбіни та напрацьовують новий тритій з літію (`⁶Li + n → ⁴He + T`).
