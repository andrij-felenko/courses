# 🧮 Математичний вивід рівняння Града — Шафранова та дрейфових швидкостей

У цій вставці наведено строгий математичний вивід двох фундаментальних теоретичних опор магнітного утримання плазми: швидкостей дрейфу провідного центру в неоднорідному тороїдальному полі, теорії адіабатичних інваріантів руху, а також аксіально-симетричного рівняння МГД-рівноваги Града — Шафранова та його аналітичного розв'язку Соловйова.

---

### 1. Математика дрейфів провідного центру та адіабатичні інваріанти

У неоднорідному магнітному полі `B(r)` рух зарядженої частинки з масою `m` та зарядом `q` розкладається на швидке ларморівське обертання навколо силової лінії зі частотою `ω_c = (q · B) / m` та повільний рух її центру обертання — **провідного центру** (*guiding center*).

#### 1.1. Градієнтний дрейф (Grad-B drift)
Нехай магнітне поле напрямлене вздовж осі `Z`, а його модуль змінюється вздовж осі `X`: `B = B(x) · e_z`.
Лоренцева сила `F_L = q · (v × B)` змінюється вздовж орбіти: на ділянці з більшим `B` радіус кривизни орбіти `r_L = (m · v_perp) / (q · B)` менший, а на ділянці з меншим `B` — більший.

Розкладемо напруженість поля `B(x)` у ряд Тейлора навколо провідного центру `x_0`:

```
B(x) ≈ B(x_0) + (x - x_0) · (dB / dx)
```

Циклічне усереднення сили Лоренца за період ларморівського обертання `T = 2π / ω_c` дає середню силу, що діє на провідний центр:

```
⟨F_grad⟩
= - μ · ∇B
```

де `μ = (m · v_perp²) / (2 · B)` — перший адіабатичний інваріант (магнітний момент ларморівської орбіти частинки).
Підставляючи цю ефективну силу у формулу загального дрейфу під дією сили `F`: `v_drift = (F × B) / (q · B²)`, отримуємо швидкість градієнтного дрейфу:

```
v_grad
= ( (-μ · ∇B) × B ) / (q · B²)       [підстановка ефективної сили F_grad у формулу дрейфу]
= ( m · v_perp² · (B × ∇B) ) / (2 · q · B³) [підстановка значення μ = m·v_perp² / (2B)]
```

#### 1.2. Дрейф кривизни (Curvature drift)
При русі частинки вздовж викривленої силової лінії з радіусом кривизни `R_c` на частинку в її супутній системі відліку діє відцентрова сила:

```
F_curv
= (m · v_parallel² / R_c²) · R_c
```

Векторний добуток цієї сили з напрямком магнітного поля `B` дає швидкість дрейфу кривизни:

```
v_curv
= ( m · v_parallel² · (R_c × B) ) / (q · R_c² · B²)
```

У вакуумному тороїдальному полі без поздовжніх струмів виконується умова `∇ × B = 0`, з якої випливає співвідношення між градієнтом та кривизною: `(∇B) / B = -R_c / R_c²`. Сумарна швидкість дрейфу провідного центру дорівнює:

```
v_drift_sum
= v_grad + v_curv                    [сума градієнтного дрейфу та дрейфу кривизни]
= ( (m · (v_perp² / 2 + v_parallel²)) / (q · B³) ) · (B × ∇B) [групування спільних векторних множників]
```

**Ключовий висновок:** Напрямок дрейфу залежить від знаку заряду `q`. Для позитивних іонів (`q = +e`) вектор `B × ∇B` спрямований вгору, а для електронів (`q = -e`) — вниз. Це викликає вертикальне розділення зарядів у тороїдальній пастці.

#### 1.3. Поляризаційний дрейф (Polarisation drift)
Якщо електричне поле змінюється у часі `dE / dt ≠ 0`, виникає додатковий інерційний дрейф — **поляризаційний дрейф**:

```
v_pol
= (m / (q · B²)) · (dE / dt)
```

Оскільки поляризаційний дрейф пропорційний масі `m`, іони дрейфують у напрямку `dE / dt` значно швидше за електрони. Це призводить до виникнення поляризаційного струму плазми `j_pol = n_e · e · (v_pol_i - v_pol_e)`, який відіграє вирішальну роль у стабілізації низькочастотних МГД-колебань та формуванні диелектричної проникності плазми на низьких частотах `ε_perp = 1 + (c² / v_Alfvén²)`.

#### 1.4. Три адіабатичних інваріанти Гамільтона
Рух частинки у магнітній пастці характеризується трьома адіабатичними інваріантами (узагальненими діями Гамільтона `J_k = ∮ p_k dq_k`), які зберігаються з високою точністю, якщо зміни поля у часі та просторі є повільними порівняно з характерними періодами руху:

1. **Перший адіабатичний інваріант (Магнітний момент `μ`):**
   Пов'язаний з швидким ларморівським обертанням з частотою `ω_c`.

   ```
   μ = (m · v_perp²) / (2 · B) = const
   ```

   Збереження `μ` гарантує відбиття частинок у магнітних дзеркалах та формуванні бананових орбіт.

2. **Другий адіабатичний інваріант (Поздовжній інваріант `J`):**
   Пов'язаний з коливальним рухом запертої частинки між точками відбиття `s_1` та `s_2` вздовж силової лінії (поздовжні коливання з періодом `τ_bounce`):

   ```
   J = ∮ v_parallel ds = ∮ √ ( (2/m) · (E - μ · B(s)) ) ds = const
   ```

   Збереження `J` визначає прецесію бананових орбіт навколо тороїдальної осі пастки.

3. **Третій адіабатичний інваріант (Магнітний потік `Φ`):**
   Пов'язаний з повільною прецесією всієї бананової орбіти навколо осі тора з прецесійною частотою `ω_precession`. Магнітний потік `Φ`, що охоплюється дрейфовою поверхнею частинки, зберігається постійним при повільних змінах конфігурації поля.

### 2. Вивід рівняння рівноваги Града — Шафранова

В ідеальній магнітогідродинаміці (МГД) стаціонарна рівновага плазми описується балансом газокінетичного тиску `p` та амперівської сили `j × B`:

```
∇p = j × B
∇ · B = 0
μ₀ · j = ∇ × B
```

Розглянемо аксіально-симетричну тороїдальну систему у циліндричних координатах `(R, φ, Z)`, де `φ` — тороїдальний кут. Через аксіальну симетрію всі фізичні величини не залежать від `φ`: `∂ / ∂φ = 0`.

#### Крок 1. Полоїдальна функція магнітного потоку `ψ`
Оскільки `∇ · B = 0`, у циліндричних координатах маємо:

```
(1 / R) · (∂ / ∂R)(R · B_R) + (∂ B_Z / ∂Z) = 0
```

Це дозволяє виразити полоїдальне магнітне поле `B_pol = (B_R, 0, B_Z)` через скалярну функцію потоку `ψ(R, Z)`:

```
B_R = - (1 / R) · (∂ψ / ∂Z)
B_Z =   (1 / R) · (∂ψ / ∂R)
```

У векторній формі повне магнітне поле `B` записується як:

```
B = (1 / R) · (∇ψ × e_φ) + B_φ · e_φ
```

де `e_φ` — орт у тороїдальному напрямку. Для зручності вводять функцію струму `F(ψ) = R · B_φ`. Тоді:

```
B = (1 / R) · (∇ψ × e_φ) + (F(ψ) / R) · e_φ
```

#### Крок 2. Обчислення густини струму `j`
За законом Ампера `μ₀ · j = ∇ × B`. Обчислимо ротор від поля `B`:

```
μ₀ · j
= ∇ × [ (1 / R) · (∇ψ × e_φ) + (F / R) · e_φ ] [розкриття ротора суми полів]
= - (1 / R) · Δ*ψ · e_φ + (1 / R) · (∇F × e_φ) [обчислення диференціальних операторів]
```

де `Δ*` — диференціальний оператор Еліаса — Града — Шафранова:

```
Δ*ψ
= R · (∂ / ∂R) [ (1 / R) · (∂ψ / ∂R) ] + (∂²ψ / ∂Z²) [визначення оператора Еліаса — Града — Шафранова]
= (∂²ψ / ∂R²) - (1 / R) · (∂ψ / ∂R) + (∂²ψ / ∂Z²) [диференціювання добутку за правилом Лейбніца]
```

Оператор `Δ*` відрізняється від звичайного двохвимірного оператора Лапласа `∇² = (∂² / ∂R²) + (1 / R) · (∂ / ∂R) + (∂² / ∂Z²)` знаком перед першою похідною `-(1 / R) · (∂ / ∂R)`. Ця різниця виникає суто через геометрію криволінійних циліндричних координат та аксіальну симетрію тора.

Отже, компоненти густини струму дорівнюють:

```
j_pol = (1 / (μ₀ · R)) · (∇F × e_φ)
j_φ   = - (1 / (μ₀ · R)) · Δ*ψ
```

#### Крок 3. Підстановка у рівняння рівноваги `∇p = j × B`
Скалярний добуток `B · ∇p = B · (j × B) = 0` означає, що градієнт тиску перпендикулярний до магнітного поля `B`. Силові лінії магнітного поля лежать на поверхнях постійного тиску `p = const`. Отже, тиск плазми є функцією лише потоку `ψ`: `p = p(ψ)`.

Аналогічно, `j · ∇p = 0`, з чого випливає, що тороїдальна функція `F = R · B_φ` також є функцією лише `ψ`: `F = F(ψ)`.

Тепер обчислимо векторний добуток `j × B`:

```
j × B
= [ j_pol + j_φ · e_φ ] × [ B_pol + B_φ · e_φ ] [підстановка векторних компонент струму та поля]
= (j_pol × B_pol) + (j_pol × B_φ · e_φ) + (j_φ · e_φ × B_pol) [розкриття векторного добутку двочленів]
```

Підставляючи вирази для `B` та `j` через `ψ` та `F(ψ)`, отримуємо проекцію балансу сил на напрямок `∇ψ`:

```
∇p
= p'(ψ) · ∇ψ                         [похідна складеної функції p(ψ) за ланцюговим правилом]
= - (1 / (μ₀ · R²)) · Δ*ψ · ∇ψ - (1 / (μ₀ · R²)) · F(ψ) · F'(ψ) · ∇ψ [підстановка компонент j_pol та j_phi]
```

Скорочуючи ненульовий градієнт `∇ψ`, отримуємо класичне **рівняння Града — Шафранова**:

```
Δ*ψ = - μ₀ · R² · p'(ψ) - F(ψ) · F'(ψ)
```

Або у розгорнутому вигляді:

```
R · (∂ / ∂R) [ (1 / R) · (∂ψ / ∂R) ] + (∂²ψ / ∂Z²)
= - μ₀ · R² · (dp / dψ) - F(ψ) · (dF / dψ)
```

### 3. Точний аналітичний розв'язок Соловйова

Для перевірки чисельних кодів МГД-рівноваги та аналізу конфігурацій токамаків використовують аналітичний розв'язок Соловйова (на честь радянського фізика Л. С. Соловйова). Припускається, що профілі тиску та струму є лінійними функціями від `ψ`:

```
dp / dψ = C_1 = const
F · (dF / dψ) = C_2 = const
```

Тоді рівняння Града — Шафранова перетворюється на лінійне рівняння з постійними джерелами:

```
Δ*ψ = - μ₀ · R² · C_1 - C_2
```

Для D-подібного перерізу плазми розв'язок Соловйова приймає поліноміальну форму:

```
ψ(R, Z) = (ψ_0 / (a² · R_0²)) · [ (R² · Z² / κ²) + (1 / 4) · (R² - R_0²)² + δ · (R² - R_0³ / R_0) ]
```

де `κ` — витягнутість перерізу плазми (Elongation), `δ` — трикутність перерізу (Triangularity), `a` — малий радіус, `R_0` — великий радіус тора.

Цей розв'язок дозволяє аналітично обчислити магнітні поверхні, зсув магнітної осі та профілі полоїдального магнітного поля у токамаку, а також побудувати межу сепаратриси з X-точкою.

### 4. Фізика зсуву Шафранова (Shafranov Shift)

Рівняння Града — Шафранова показує, що праворуч стоїть джерело `-μ₀ · R² · p'(ψ)`. Оскільки тиск плазми максимальний на осі і спадає до краю (`p'(ψ) < 0`), джерельне значення пропорційне `R²`.

Це викликає геометричну асиметрію: магнітні поверхні розширюються на зовнішньому радіусі тора. Внутрішні магнітні поверхні виявляються зсунутими назовні відносно зовнішньої межі плазми. Цей зсув називається **зсувом Шафранова** `ΔR`.

Для кругового перерізу плазми малого радіуса `a` та великого радіуса `R_0` зсув Шафранова описується наближеною формулою:

```
ΔR ≈ (a² / (2 · R_0)) · [ β_p + (l_i / 2) ]
```

де:
- `β_p = (2 · μ₀ · ⟨p⟩) / B_pol²` — полоїдальне значення параметру бета;
- `l_i` — внутрішня індуктивність плазмового шнура на одиницю довжини (характеризує профіль струму).

Якщо тиск плазми стає надто високим (`β_p → R_0 / a`), зсув Шафранова зміщує магнітну вісь до самої зовнішньої стінки камери, що призводить до руйнування конфігурації поверхонь та обмеження максимального тиску плазми у токамаку.
