# 🧮 Математичний апарат п'єзоелектрики: тензорний формалізм, скорочення Фойгта та коефіцієнти зв'язку

Ця вставка містить повний аналітичний розв'язок феноменологічних рівнянь п'єзоелектрики, виведення скороченої нотації Фойгта для тензорів третього та четвертого рангів, термодинамічне обґрунтування симетрії п'єзомодулів та розрахунок коефіцієнтів електромеханічного зв'язку. Матеріал призначений для строгого розрахунку п'єзоакустичних пристроїв, актуаторів та SAW-структур.

---

## 1. Повний тензорний опис зв'язаних полів

П'єзоелектричний ефект є термодинамічно зв'язаним феноменом між механічними та електричними величинами. У загальному тривимірному випадку механічний стан середовища описується двома тензорами другого рангу:
- **Тензор механічних напружень** `T[ij]` (паскалі, Pa або N/m²).
- **Тензор деформацій** `S[ij]` (безрозмірна величина).

Електричний стан описується двома векторами (тензорами першого рангу):
- **Вектор напруженості електричного поля** `E[k]` (В/м, V/m).
- **Вектор електричного зсуву (індукції)** `D[i]` (Кл/м², C/m²).

Через симетрію тензорів напружень `T[ij] = T[ji]` та деформацій `S[ij] = S[ji]` вони мають по 6 незалежних компонент замість 9.

### Загальні лінійні зв'язані рівняння стану (у тензорній формі)

У наближенні малих деформацій та слабких електричних полів термодинамічний потенціал середовища (вільна енергія Гіббса або ентальпія) можна розкласти в ряд Тейлора. Це дає лінійні рівняння стану:

```
D[i] = ε[ij]^T · E[j] + d[ijk] · T[jk]        [прямий п'єзоефект]
S[ij] = d[kij] · E[k] + s[ijkl]^E · T[kl]      [зворотний п'єзоефект]
```

Тут використовуються тензорні величини:
- `d[ijk]` — **тензор п'єзоелектричних модулів** (прямий та зворотний п'єзомодуль), тензор 3-го рангу (містить 3 × 3 × 3 = 27 компонент).
- `ε[ij]^T` — **тензор діелектричної проникності** при постійному механічному напруженні `T = const`, тензор 2-го рангу (3 × 3 = 9 компонент).
- `s[ijkl]^E` — **тензор пружної податливості** при постійному електричному полі `E = const`, тензор 4-го рангу (3 × 3 × 3 × 3 = 81 компонента).

## 2. Скорочений матричний запис Фойгта (Voigt Notation)

Використання тензорних індексів 3-го та 4-го рангів у практичних інженерних розрахунках є громіздким. Оскільки тензори деформацій та напружень є симетричними (`T[jk] = T[kj]`, `S[ij] = S[ji]`), використовується **скорочена нотація Фойгта**, яка згортає пару симетричних тензорних індексів `(j, k)` в один матричний індекс `p ∈ {1, 2, 3, 4, 5, 6}`.

### Правило відповідності індексів Фойгта

```
Тензорна пара (j, k):    (1,1)  (2,2)  (3,3)  (2,3)=(3,2)  (1,3)=(3,1)  (1,2)=(2,1)
Матричний індекс p:        1      2      3         4            5            6
```

При цьому фізичні компоненти векторів напружень та деформацій записуються як 6-компонентні вектори-стовпці:

```
Напруження T[p]:  T₁ = T₁₁,  T₂ = T₂₂,  T₃ = T₃₃,  T₄ = T₂₃,  T₅ = T₁₃,  T₆ = T₁₂
Деформації S[q]:  S₁ = S₁₁,  S₂ = S₂₂,  S₃ = S₃₃,  S₄ = 2·S₂₃, S₅ = 2·S₁₃, S₆ = 2·S₁₂
```

*Примітка:* Зсувні компоненти деформацій `S₄, S₅, S₆` у нотації Фойгта помножуються на `2`, щоб зберегти рівність виконаної механічної роботи `W = 1/2 · ∑ T[p]·S[p]`.

### Матрична форма п'єзоелектричного тензора d[i, p]

Завдяки симетрії за останніми двома індексами `d[i, j, k] = d[i, k, j]`, тензор 3-го рангу розмірністю 3 × 3 × 3 = 27 перетворюється на прямокутну матрицю **d[i, p]** розміром **3 × 6** (3 рядки, 6 стовпчиків):

```
          [ d₁₁  d₁₂  d₁₃  d₁₄  d₁₅  d₁₆ ]
d[i,p] =  [ d₂₁  d₂₂  d₂₃  d₂₄  d₂₅  d₂₆ ]
          [ d₃₁  d₃₂  d₃₃  d₃₄  d₃₅  d₃₆ ]
```

Транспонована матриця `d[p, i]^t` розміром **6 × 3** описує зворотний п'єзоефект.

### Повна матрична система рівнянь п'єзоелектрики (d-форма)

У матричному вигляді лінійні рівняння стану приймають вигляд:

```
D[i] = ε[ij]^T · E[j] + ∑ (d[i,p] · T[p])      (i, j = 1..3; p = 1..6)
S[q] = ∑ (d[q,i]^t · E[i]) + s[qp]^E · T[p]     (q, p = 1..6; i = 1..3)
```

## 3. Чотири еквівалентні форми рівнянь стану

Залежно від того, які дві величини обирають як **незалежні змінні** (вхідні сили/поля), а які дві як **залежні** (вихідні відгуки), у міжнародному стандарті **IEEE Standard 176 on Piezoelectricity** визначено 4 фундаментальні форми рівнянь стану:

### 1. d-форма (Strain-Charge form: незалежні T та E)
Найчастіше застосовується для розрахунку сенсорів сили та низькочастотних актуаторів:
```
S = s^E · T + d^t · E
D = d · T + ε^T · E
```
- `d` — п'єзоелектрична стала заряду (Кл/Н або м/В).

### 2. e-форма (Stress-Charge form: незалежні S та E)
Використовується для аналізу високочастотних випромінювачів та чисельного аналізу методом скінченних елементів (FEM):
```
T = c^E · S - e^t · E
D = e · S + ε^S · E
```
- `c^E` — матриця жорсткості (`c = (s^E)⁻¹`).
- `e` — п'єзоелектрична стала напруження (Кл/м² або Н/(В·м)). `e = d · c^E`.

### 3. g-форма (Strain-Voltage form: незалежні T та D)
Застосовується для приймачів акустичних сигналів (гідрофонів), де важлива вихідна напруга при заданій силі:
```
S = s^D · T + g^t · D
E = -g · T + (β^T) · D
```
- `g` — п'єзоелектрична стала напруги (В·м/Н або м²/Кл). `g = d / ε^T`.
- `β^T` — непроникність діелектрика (`β = (ε^T)⁻¹`).

### 4. h-форма (Stress-Voltage form: незалежні S та D)
Використовується для аналізу швидкоплинних імпульсних процесів та високочастотних резонаторів:
```
T = c^D · S - h^t · D
E = -h · S + (β^S) · D
```
- `h` — п'єзоелектрична стала стиску (В/м або Н/Кл). `h = e / ε^S`.

## 4. Коефіцієнт електромеханічного зв'язку k²

Коефіцієнт електромеханічного зв'язку **k** (*electromechanical coupling factor*) є безрозмірною величиною, яка визначає ефективність перетворення енергії в п'єзоелектричному матеріалі за один цикл деформації.

За визначенням, квадрат коефіцієнта `k²` дорівнює відношенню накопиченої перетвореної енергії до повної підведеної енергії.

### Термодинамічний вивід для одноосьової деформації (мода 33)

Розглянемо п'єзопластину, до якої прикладено напруження `T₃` та електричне поле `E₃`. Повна густина внутрішньої енергії `U` середовища складається з трьох доданків:

```
U = U_мех + U_взаємодії + U_ел
U = 1/2 · s₃₃^E · (T₃)² + d₃₃ · T₃ · E₃ + 1/2 · ε₃₃^T · (E₃)²
```

Визначаємо відношення квадрантів енергії:

```
k₃₃² = (U_взаємодії)² / (4 · U_мех · U_ел)
     = (d₃₃ · T₃ · E₃)² / [4 · (1/2 · s₃₃^E · T₃²) · (1/2 · ε₃₃^T · E₃²)]   [підстановка складових]
     = (d₃₃)² · T₃² · E₃² / (s₃₃^E · T₃² · ε₃₃^T · E₃²)                      [скорочення 1/2 і 4]
     = (d₃₃)² / (s₃₃^E · ε₃₃^T)                                             [скорочення T₃² та E₃²]
```

Отримуємо фундаментальну формулу коефіцієнта електромеханічного зв'язку для поздовжньої моди:

```
k₃₃ = d₃₃ / √(s₃₃^E · ε₃₃^T)
```

Аналогічно для поперечної деформації (мода 31):

```
k₃₁ = d₃₁ / √(s₁₁^E · ε₃₃^T)
```

Оскільки коефіцієнт ккд перетворення енергії не може перевищувати 100%, значення `k` завжди задовольняє умову `0 ≤ k < 1`:
- Для кварцю: `k₃₃ ≈ 0.10` (низька ефективність перетворення, але висока стабільність).
- Для п'єзокераміки PZT-5H: `k₃₃ ≈ 0.75` (висока ефективність перетворення, `k² ≈ 0.56` або 56% енергії перетворюється за один хід).

## 5. Резонансна частота тонкого п'єзостержня (мода поздовжніх коливань)

Розглянемо п'єзоелектричний стержень довжиною `L`, шириною та товщиною `w, t ≪ L`, орієнтований уздовж осі `z = x₃`. Знайдемо його власну резонансну частоту механічних коливань при збудженні змінним електричним полем.

Диференціальне рівняння руху елемента об'єму середовища з густиною `ρ` (другий закон Ньютона у суцільному середовищі):

```
ρ · ∂²u₃/∂t² = ∂T₃/∂z
```

Виражаємо напруження `T₃` з d-форми рівнянь п'єзоелектрики:
`S₃ = ∂u₃/∂z = s₃₃^E · T₃ + d₃₃ · E₃`  =>  `T₃ = (1 / s₃₃^E) · (∂u₃/∂z - d₃₃ · E₃)`

Оскільки електричне поле `E₃` вздовж стержня однорідне (`∂E₃/∂z = 0`), підстановка `T₃` у рівняння руху дає класичне хвильове рівняння:

```
ρ · ∂²u₃/∂t² = (1 / s₃₃^E) · ∂²u₃/∂z²
```

Швидкість поширення акустичної хвилі в п'єзостержні дорівнює:

```
v = √(1 / (ρ · s₃₃^E))
```

Для вільних кінців стержня (`T₃(0) = T₃(L) = 0`) крайові умови дають умову стоячої хвилі, коли на довжині стержня вкладається півхвилі (`L = λ / 2`):

```
f_r = v / (2 · L) = 1 / (2 · L · √(ρ · s₃₃^E))
```

Ця формула зв'язує геометричні розміри п'єзоелемента `L`, густину `ρ` та пружну податливість `s₃₃^E` із першою резонансною частотою `f_r`, що є базовим рівнянням для розрахунку ультразвукових випромінювачів та кварцових резонаторів.
