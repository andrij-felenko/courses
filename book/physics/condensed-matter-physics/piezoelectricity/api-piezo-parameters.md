# 📋 Довідник фізико-механічних та електричних параметрів п'єзоматеріалів та матриць симетрії

Цей довідник містить повну систематизацію інженерних та фізико-хімічних параметрів п'єзоелектричних середовищ відповідно до міжнародного стандарту **IEEE Standard 176 on Piezoelectricity**. Довідник охоплює тензорні матриці п'єзомодулів для головних точкових груп симетрії, розширенні таблиці матеріалознавчих сталах, аналітичний розрахунок еквівалентних схем Баттерворта — Ван-Дайка (BVD), аналіз температурних коефіцієнтів розширення та частоти, а також класифікацію коефіцієнтів електромеханічного зв'язку для різних мод деформації.

## 1. Міжнародний стандарт IEEE Standard 176 та номенклатура величин

Стандарт IEEE 176 регулює вимірювання, математичний запис та специфікацію п'єзоелектричних монокристалів, керамік, тонких плівок та полімерів. Для уніфікації розрахунків використовується правобічна прямокутна декартова система координат `(X₁, X₂, X₃)` або `(X, Y, Z)`. У поляризованій сегнетокераміці вісь `X₃` (або `Z`) завжди суміщається з напрямком векторної високовольтної поляризації.

### Чотири фундаментальні форми рівнянь стану

Залежно від вибору незалежних змінних стандарт визначає 4 форми лінійних рівнянь:

1. **d-форма (Strain-Charge Form):**Незалежні змінні — механічне напруження `T` та електричне поле `E`. Використовується для розрахунку датчиків сили, ваги та низькочастотних актуаторів:
   ```
   S = s^E · T + d^t · E
   D = d · T + ε^T · E
   ```
   Де `d` — п'єзоелектричний модуль заряду (кулони на ньютон, C/N, або метри на вольт, m/V).

2. **e-форма (Stress-Charge Form):** Незалежні змінні — механічна деформація `S` та електричне поле `E`. Застосовується в обчислювальному аналізі методом скінченних елементів (FEM) та для затиснутих високочастотних випромінювачів:
   ```
   T = c^E · S - e^t · E
   D = e · S + ε^S · E
   ```
   Де `e` — п'єзоелектричний модуль напруження (кулони на квадратний метр, C/m²). Зв'язок із d-модулем: `e = d · c^E`.

3. **g-форма (Strain-Voltage Form):** Незалежні змінні — механічне напруження `T` та електрична індукція `D`. Використовується для високочутливих приймачів акустичних сигналів (гідрофонів), де вимірюється напруга холостого ходу:
   ```
   S = s^D · T + g^t · D
   E = -g · T + β^T · D
   ```
   Де `g` — п'єзоелектричний модуль напруги (вольт-метри на ньютон, V·m/N). Зв'язок: `g = d / ε^T`.

4. **h-форма (Stress-Voltage Form):** Незалежні змінні — механічна деформація `S` та електрична індукція `D`. Використовується для аналізу швидкоплинних імпульсних навантажень та ударних хвильових процесів:
   ```
   T = c^D · S - h^t · D
   E = -h · S + β^S · D
   ```
   Де `h` — п'єзоелектричний модуль стиску (вольти на метр, V/m). Зв'язок: `h = e / ε^S`.

## 2. Структура матриць п'єзомодулів d[i,p] за точковими групами симетрії

Матриця п'єзомодулів `d[i,p]` має розмірність 3 × 6 (3 рядки відповідають електричним осям `X₁, X₂, X₃`, a 6 стовпчиків — механічним компонентам нотації Фойгта `1, 2, 3, 4, 5, 6`). Внутрішня симетрія кристала обнуляє більшість компонент.

### 1. Гексагональний клас 6mm (Поляризована кераміка PZT, BaTiO₃, AlN, ZnO)
Вісь поляризації спрямована уздовж осі `Z (3)`. Матриця містить 5 ненульових елементів, з яких тільки 3 є незалежними (`d₃₁ = d₃₂`, `d₃₃`, `d₁₅ = d₂₄`):

```
          [   0     0     0     0    d₁₅     0   ]
d[i,p] =  [   0     0     0    d₁₅    0      0   ]
          [  d₃₁   d₃₁   d₃₃    0     0      0   ]
```

Фізичний зміст компонент:
- `d₃₃`: поздовжній стиск/розтяг вздовж осі поляризації під дією поля `E₃`.
- `d₃₁`: поперечне розширення/стиск у площині XY під дією поля `E₃`.
- `d₁₅`: зсувна деформація у площині XZ під дією поперечного поля `E₁`.

### 2. Тригональний клас 32 (Монокристалічний кварц α-SiO₂)
Кристал має 2 незалежні компоненти (`d₁₁` та `d₁₄`):

```
          [  d₁₁  -d₁₁    0    d₁₄    0      0   ]
d[i,p] =  [   0     0     0     0   -d₁₄  -2·d₁₁ ]
          [   0     0     0     0     0      0   ]
```

Зверніть увагу, що компонент `d₃₃ = 0`, тобто вздовж оптичної осі Z п'єзоелектричний ефект у кварці повністю відсутній.

### 3. Тригональний клас 3m (Ніобат літію LiNbO₃, Танталат літію LiTaO₃)
Матриця має 4 незалежні компоненти (`d₁₅`, `d₂₂`, `d₃₁`, `d₃₃`):

```
          [   0      0      0      0    d₁₅  -2·d₂₂ ]
d[i,p] =  [ -d₂₂    d₂₂     0     d₁₅    0      0    ]
          [  d₃₁    d₃₁    d₃₃     0     0      0    ]
```

### 4. Тетрагональний клас 4mm (Монокристалічний титанат барію BaTiO₃ при T < 120 °C)
Матриця має аналогічну структуру до класу `6mm` з 3 незалежними компонентами (`d₃₁`, `d₃₃`, `d₁₅`).

### 5. Ромбічний клас mm2 (П'єзополімер PVDF)
Плівка PVDF після витягування вздовж осі 1 та поляризації вздовж осі 3 має 3 незалежні п'єзомодулі `d₃₁`, `d₃₂`, `d₃₃` та 2 зсувні `d₁₅`, `d₂₄`:

```
          [   0     0     0     0    d₁₅     0   ]
d[i,p] =  [   0     0     0    d₂₄    0      0   ]
          [  d₃₁   d₃₂   d₃₃    0     0      0   ]
```

## 4. Класифікація мод коливань та коефіцієнтів електромеханічного зв'язку

Коефіцієнт електромеханічного зв'язку `k` залежить від напрямку прикладеного електричного поля та геометричного напрямку механічної деформації:

1. **Поздовжня мода (33 Mode):**
   Електричне поле `E₃` прикладено вздовж напрямку деформації `S₃`.
   ```
   k₃₃ = d₃₃ / √(s₃₃^E · ε₃₃^T)
   ```
   Застосовується у силових п'єзостеках, ультразвукових випромінювачах Ланжевена.

2. **Поперечна мода (31 Mode):**
   Електричне поле `E₃` прикладено по товщині, а деформація `S₁` відбувається вздовж довжини пластини.
   ```
   k₃₁ = d₃₁ / √(s₁₁^E · ε₃₃^T)
   ```
   Застосовується у консольних п'єзоелектричних біморфах, генераторах вібраційної енергії (energy harvesters).

3. **Планарна мода (Planar Mode k_p):**
   Радіальні коливання тонкого п'єзодиска під дією поля по товщині.
   ```
   k_p = k₃₁ · √(2 / (1 - ν))
   ```
   де `ν` — коефіцієнт Пуассона п'єзокераміки (`ν ≈ 0.31`).

4. **Зсувна мода (15 Shear Mode):**
   Електричне поле `E₁` прикладено перпендикулярно до осі поляризації 3, викликаючи зсув у площині XZ.
   ```
   k₁₅ = d₁₅ / √(s₅₅^E · ε₁₁^T)
   ```
   Володіє найвищим коефіцієнтом зв'язку у PZT (`k₁₅ ≈ 0.78`).

## 5. Параметри еквівалентної електричної схеми Баттерворта — Ван-Дайка (BVD)

Поблизу механічного резонансу п'єзоелектричний резонатор повністю еквівалентний двополюснику із чотирьох зосереджених електричних елементів:

```
           ┌───────[ L_m ]───────[ C_m ]───────[ R_m ]───────┐
─( Вхід )──┤                                                 ├──( Вихід )─
           └─────────────────────[ C_0 ]─────────────────────┘
```

### Фізична інтерпретація та формули розрахунку елементів BVD-схеми

1. **Паралельна статична ємність C₀:**
   Електрична ємність діелектричного шару між металевими електродами у «затиснутому» стані (без механічних коливань):
   ```
   C_0 = (ε₃₃^S · A) / d_0 = (ε₃₃^T · A / d_0) · (1 - k₃₃²)
   ```

2. **Послідовна динамічна ємність C_m:**
   Описує пружну податливість матеріалу (механічну гнучкість), перераховану в електричну ємність:
   ```
   C_m = C_0 · (8 / π²) · (k₃₃² / (1 - k₃₃²))
   ```

3. **Послідовна динамічна індуктивність L_m:**
   Описує інерційну масу п'єзоелемента, перераховану в електричну індуктивність:
   ```
   L_m = 1 / (4 · π² · f_r² · C_m) = (m_eff) / (2 · N² · d₃₃² · K_p²)
   ```

4. **Послідовний динамічний опір R_m:**
   Описує механічні втрати на внутрішнє тертя, випромінювання звуку та демпфування:
   ```
   R_m = (2 · π · f_r · L_m) / Q_m = 1 / (2 · π · f_r · C_m · Q_m)
   ```

### Точні рівняння резонансних частот

- **Послідовний резонанс f_s (Мінімум імпедансу Z):**
  Механічний резонанс, при якому реактивні опори `L_m` та `C_m` взаємно компенсуються:
  ```
  f_s = 1 / (2 · π · √(L_m · C_m))
  ```

- **Паралельний антирезонанс f_p (Максимум імпедансу Z):**
  Електричний паралельний резонанс між динамічною індуктивністю `L_m` та сумарною ємністю `(C_m · C_0) / (C_m + C_0)`:
  ```
  f_p = f_s · √(1 + C_m / C_0)
  ```

Вимірявши частоти `f_s` та `f_p` на імпедансному аналізаторі, коефіцієнт електромеханічного зв'язку `k₃₃` розраховується за стандартом IEEE 176:

```
k₃₃² = (π / 2) · (f_s / f_p) · tan[(π / 2) · ((f_p - f_s) / f_p)]
```

## 6. Температурні коефіцієнти розширення, частоти та стабільності

Зміна температури впливає на всі параметри п'єзоелемента: геометричні розміри, діелектричну проникність, пружні модулі та резонансну частоту.

### 1. Температурний коефіцієнт частоти (TCF)
Характеризує відносну зміну резонансної частоти при зміні температури на 1 °C:

```
TCF = (1 / f_0) · (df / dT)     (одиниці: ppm/°C або 10⁻⁶ / °C)
```

Для більшості п'єзокерамік PZT `TCF ≈ -200 ... -500 ppm/°C` (при нагріванні частота знижується через розм'якшення матеріалу). Для спеціально орієнтованих монокристалів (наприклад, **AT-зріз кварцю**) залежність `f(T)` має вигляд параболи з вершиною при 25 °C, де `TCF = 0 ppm/°C` у діапазоні від -10 °C до +60 °C.

### 2. Температурний коефіцієнт п'єзомодуля (TCd)
Характеризує температурну нестабільність коефіцієнта перетворення:

```
TCd = (1 / d₃₃) · (dd₃₃ / dT)
```
Для жорсткої кераміки PZT-4 `TCd ≈ +0.1% / °C`, тоді як для м'якої кераміки PZT-5H `TCd ≈ +0.4% / °C`.
