# 🧮 Термодинаміка та математична модель дрейфу опору аморфного халькогеніду

Аморфна фаза халькогенідного матеріалу `Ge₂Sb₂Te₅` (GST-225) знаходиться у термодинамічно метастабільному стані з підвищеною вільною енергією Гіббса. Оскільки аморфна структура утворюється шляхом надшвидкого загартування розплаву зі швидкістю понад $10^9$ K/с, атоми заморожуються у вимушених конфігураціях із відхиленнями кутів і довжин валентних зв'язків від оптимуму. З часом атоми в невпорядкованій сітці повільно релаксують до більш стійкого конфігураційного стану з нижчою потенціальною енергією. Ця атомна перебудова викликає систематичне зростання електричного опору комірки — явище **дрейфу опору** (*resistance drift*). У цій вставці виведено феноменологічний та мікроскопічний математичний апарат, який описує часову залежність опору та зміни енергетичного спектра пасток.

## 1. Термодинаміка аморфного стану та релаксація вільних об'ємів

Для розуміння фізичної природи дрейфу розглянемо конфігураційну енергію аморфного скла. Відразу після імпульсу RESET аморфний халькогенід містить високу концентрацію «вільного об'єму» (*free volume*) — залишкових міжмикроскопічних порожнин та розтягнутих валентних зв'язків.

Згідно з термодинамічною моделлю Коена — Тернбалла — Греста, релаксація аморфного стану є результатом коефіцієнтного стиснення вільного об'єму `v_f(t)` під дією термічних флуктуацій. Зменшення вільного об'єму виражається логарифмічним часовим законом:

```
v_f(t) = v_f0 - A_v · ln(t / t_0)
```

Де `v_f0` — початковий вільний об'єм у момент `t_0 = 1` s, а `A_v` — параметр кінетичної стисливості аморфного каркаса.

Паралельно відбувається локальне перегрупування координації атомів германію. У розплаві та свіжозагартованому аморфному стані значна частина атомів `Ge` перебуває у метастабільній чотирикоординованій тетраедричній конфігурації (sp³-гібридизація). З часом атоми `Ge` релаксують у енергетично вигіднішу трикоординовану або пірамідальну конфігурацію (p-подібні зв'язки), що характерно для октаедричного оточення кристалічної фази. Це впорядкування усуває розірвані зв'язки та зменшує щільність станів у забороненій зоні.

## 2. Степеневий закон часового дрейфу опору

Експериментально встановлено, що після завершення імпульсу RESET опір аморфної комірки `R` зростає з часом `t` за принципом феноменологічного степеневого закону.

```
R(t) = R_0 · (t / t_0)^v
```

Де `R_0` — опір комірки, виміряний у початковий момент часу `t_0` (зазвичай `t_0 = 1` секунда після закінчення імпульсу), а `v` — безрозмірний коефіцієнт дрейфу опору (*drift exponent*).

Логарифмування обох частин рівняння переводить залежність у лінійну форму в подвійних логарифмічних координатах:

```
ln(R(t))
= ln(R_0 · (t / t_0)^v)                  [властивість логарифма добутку]
= ln(R_0) + ln((t / t_0)^v)              [розкриття логарифма добутку]
= ln(R_0) + v · ln(t / t_0)              [винесення степеня v за знак логарифма]
```

Диференціювання логарифмічної форми за часовим аргументом `ln(t)` визначає коефіцієнт дрейфу `v` як тангенс кута нахилу характеристики:

```
v = d(ln(R)) / d(ln(t)) = (t / R) · (dR / dt)
```

Для повністю аморфного стану GST-225 значення `v` становить від 0.08 до 0.12 при кімнатній температурі. У кристалічній фазі (стан SET) конфігураційна релаксація повністю відсутня через наявність суворого дальнього порядку, тому `v ≈ 0.001`, і опір лишається стабільним протягом багатьох років.

```
Логарифм опору ln(R)
  ▲
  │       /  Аморфний стан RESET (v ≈ 0.10, R зростає у 10-100 разів за рік)
  │      /
  │     /  Проміжний стан MLC '01' (v ≈ 0.06)
  │    /
  │   /   Проміжний стан MLC '10' (v ≈ 0.03)
  │  /
  │ ───────────────────────────────── Кристалічний стан SET (v ≈ 0.001, опір стабільний)
  └────────────────────────────────────────────────────────► Час ln(t)
```

## 3. Мікроскопічна модель Poole-Frenkel та z-shift енергетичних пасток

Електрична провідність аморфного халькогеніду в підпороговому режимі описується ефектом Пулла — Френкеля (*Poole-Frenkel emission*), тобто термічною емісією електронів із кулонівських потенціальних ям (пасток заряду) у зону провідності під дією зовнішнього електричного поля `E`.

Густина струму `J` у підпороговому режимі виражається як:

```
J(E, T) = q · N_C · μ · E · exp(-(E_T - ΔE_PF) / (k_B · T))
```

Де:
- `q` — елементарний заряд електрона,
- `N_C` — ефективна щільність станів на дні зони провідності,
- `μ` — рухливість носіїв заряду,
- `E_T` — глибина потенціальної ями пастки відносно дна зони провідності,
- `k_B` — константа Больцмана,
- `T` — абсолютна температура в кельвінах,
- `ΔE_PF` — величина зниження кулонівського потенціального бар'єра пастки у зовнішньому полі `E`:

```
ΔE_PF = √(q³ · E / (π · ε_0 · ε_r))
```

Зв'язок між структурною релаксацією та дрейфом опору полягає в тому, що під час атомної релаксації локалізовані дефекти (розірвані зв'язки `Ge` та `Sb`) зміщують свої енергетичні рівні глибше у заборонену зону. Це явище отримало назву **z-зсуву пасток** (*z-shift of trap states*).

Енергетичний зсув пасток `E_T(t)` підпорядковується логарифмічному закону часової релаксації:

```
E_T(t) = E_T0 + ΔE_s · ln(t / t_0)
```

Де `E_T0` — початкова глибина пастки в момент `t_0`, а `ΔE_s` — коефіцієнт енергетичної релаксації аморфної матриці (для GST-225 `ΔE_s ≈ 12 - 20` меВ на декаду часу).

Виведемо математичну залежність опору комірки `R(t)` від часу через енергетичний зсув пасток:

```
R(t)
= R_const · exp(E_T(t) / (k_B · T))      [вираз опору через термоактивацію з пасток]
= R_const · exp((E_T0 + ΔE_s · ln(t / t_0)) / (k_B · T))   [підстановка закону z-зсуву E_T(t)]
= R_const · exp(E_T0 / (k_B · T)) · exp((ΔE_s / (k_B · T)) · ln(t / t_0)) [розкладання суми в показнику]
= R_0 · exp(ln((t / t_0)^(ΔE_s / (k_B · T)))) [використання властивості a · ln(x) = ln(x^a)]
= R_0 · (t / t_0)^(ΔE_s / (k_B · T))     [тотожність exp(ln(y)) = y]
```

Порівнюючи отримане мікроскопічне рівняння з феноменологічним степеневим законом `R(t) = R_0 · (t / t_0)^v`, виводимо фундаментальне співвідношення для коефіцієнта дрейфу `v`:

```
v(T) = ΔE_s / (k_B · T)
```

## 4. Температурна залежність коефіцієнта дрейфу та вплив на MLC

Отримане співвідношення показує явну температурну залежність дрейфу опору. При підвищенні температури термічна енергія носіїв `k_B · T` зростає, через що відносний вплив енергетичного зсуву пасток `ΔE_s` зменшується.

Проте при нагріванні вище температури релаксації `T > 350` K прискорюється сама термічна кінетика атомного впорядкування, що описується температурозалежним коефіцієнтом релаксації:

```
ΔE_s(T) = ΔE_0 + α_s · T
```

Повний вираз для коефіцієнта дрейфу у розширеному температурному діапазоні набуває вигляду:

```
v(T)
= (ΔE_0 + α_s · T) / (k_B · T)            [підстановка температурозалежного ΔE_s(T)]
= ΔE_0 / (k_B · T) + α_s / k_B            [розділення на суму двох дробів]
```

Ця формула пояснює фундаментальну складність створення багаторівневих осередків пам'яті (MLC / TLC PCRAM). У багаторівневих комірках інформація кодується не двома граничними станами (повний RESET та повний SET), а чотирма або вісьмома проміжними рівнями опору ($R_1, R_2, R_3, R_4$).

Оскільки проміжні стани являють собою суміш аморфного та кристалічного об'ємів із різною часткою аморфізації, кожен рівень має свій власний коефіцієнт дрейфу $v(R)$. З часом проміжні рівні опору дрейфують із різною швидкістю, що призводить до звуження та перекриття порогових вікон зчитування (*sensing window overlap*) і спричиняє масові бітові помилки при тривалому зберіганні даних.

## 5. Методи компенсації та стабілізації дрейфу

Для подолання негативного впливу дрейфу опору в сучасних контролерах PCRAM застосовуються три основні фізико-технічні підходи:

1. **Легування халькогеніду азотом та вуглецем (N-GST, C-GST):** Вкраплення атомів азоту або вуглецю утворює мікроскопічні аморфні нітридні/карбідні міжзеренні бар'єри, які блокують атомне переміщення германію та зменшують коефіцієнт дрейфу `v` з 0.10 до 0.02.
2. **Проекційне кодування (Projected PCM):** До осередку PCM паралельно приєднується металевий або нітридний резистор із низьким термостабільним опором. Під час зчитування струм протікає через паралельний провідний шунт, роблячи зчитуваний опір незалежним від дрейфу аморфного купола.
3. **Адаптивне відстеження порогових напруг (Tracking Read Voltages):** Контролер пам'яті періодично вимірює середній опір референтних осередків та логарифмічно зсуває порогові напруги компараторів зчитування у часі, компенсуючи коефіцієнт `v(t)`.
