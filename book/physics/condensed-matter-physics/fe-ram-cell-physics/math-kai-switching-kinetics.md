# 🧮 Кінетика перемикання поляризації: моделі Колмогорова — Аврамі — Ішібаші (KAI) та Ландау — Халатникова

Ця математична вставка містить аналітичне виведення феноменологічної теорії фазових переходів Ландау — Девоншира, рівняння динаміки перемикання Ландау — Халатникова, кінетичної моделі Колмогорова — Аврамі — Ішібаші (KAI), а також моделі нуклеації в полікристалічних тонких плівках (NLS) для розрахунку часової залежності перемикання поляризації та струму в сегнетоелектричному конденсаторі FeRAM.

Математичний апарат кінетики перемикання сегнетоелектричних доменів є необхідним інструментом для розрахунку динамічних параметрів швидкодії та зваженого заряду осередку пам'яті FeRAM. Опис опирається на термодинамічну теорію фазових переходів другого роду та статистичну фізику утворення й розростання нової фази в обмеженому об'ємі тонкої плівки.

---

### 1. Термодинамічний потенціал Ландау — Девоншира

Фундаментальний опис сегнетоелектричного стану базується на розкладі вільної енергії Гельмгольца `F` за ступенями параметра порядку — поляризації `P`. Для одновимірного кристала поблизу фазового переходу термодинамічний потенціал описується рівнянням Ландау — Девоншира:

```
F(P, E) = F₀ + (α/2)·P² + (β/4)·P⁴ + (γ/6)·P⁶ - E·P
```

де `α = α₀·(T - T_c)` — температура-залежний коефіцієнт (закон Кюрі — Вейсса), `β` та `γ` — феноменологічні коефіцієнти середовища, а `- E·P` — енергія взаємодії спонтанної поляризації з зовнішнім електричним полем `E`.

У рівноважному стані за відсутності зовнішнього поля (`E = 0`) стаціонарні значення поляризації шукаються з умови мінімуму вільної енергії `∂F/∂P = 0`:

```
∂F/∂P = α·P + β·P³ + γ·P⁵ = 0
```

Для фазового переходу 2-го роду (`β > 0`, `γ = 0`) ненульові розв'язки дають значення спонтанної поляризації `P_s`:

```
P_s = ± √(- α / β) = ± √[ α₀·(T_c - T) / β ]       [при T < T_c]
```

При додаванні зовнішнього електричного поля `E` рівноважне рівняння стану набирає вигляду:

```
E = α·P + β·P³
```

Графічний розв'язок цього рівняння задає класичну двоямну потенціальну криву з двома енергетично еквівалентними мінімумами при `P = +P_s` та `P = -P_s`, розділеними енергетичним бар'єром `ΔF_barrier = α² / (4β)`. Для того щоб розвернути поляризацію з одного мінімуму в інший, зовнішнє поле повинне вирівняти потенціальний бар'єр, що відповідає досягненню коерцитивного поля `E_c = (2/3) · α · √(- α / 3β)`.

### 2. Релаксаційне рівняння Ландау — Халатникова

Динаміка зміни поляризації `P(t)` у часі під дією зовнішнього електричного поля `E(t)` описується феноменологічним рівнянням Ландау — Халатникова (ЛХ), яке припускає, що швидкість релаксації `dP/dt` пропорційна термодинамічній рушійній силі `- ∂F/∂P`:

```
γ_LH · (dP / dt) = - ∂F / ∂P
```

де `γ_LH` — коефіцієнт згасання (коефіцієнт в'язкого тертя решітки).

Підставляючи розклад вільної енергії для фазового переходу 2-го роду, отримуємо нелінійне диференціальне рівняння динаміки поляризації:

```
γ_LH · (dP / dt) = E(t) - α·P - β·P³
```

#### Розрахунок малого відгуку біля стаціонарного стану

Розглянемо малі відхилення поляризації `δP(t)` від рівноважного значення `P₀` під дією слабкого поля `E(t)`:

```
P(t) = P₀ + δP(t)

γ_LH · (d(δP) / dt) = E(t) - (α + 3β·P₀²) · δP(t)   [лінеаризація по δP]
```

Означивши час релаксації `τ_LH = γ_LH / (α + 3β·P₀²)`, отримуємо диференціальне рівняння першого порядку:

```
d(δP) / dt + (1 / τ_LH) · δP = E(t) / γ_LH
```

Його розв'язок для східчастого включення поля `E(t) = E₀` при `t ≥ 0`:

```
δP(t) = (E₀ / γ_LH) · τ_LH · [ 1 - exp( - t / τ_LH ) ]
```

Рівняння Ландау — Халатникова описує однорідне когерентне об'ємне перемикання монодоменного кристала. Проте в реальних сегнетоелектричних конденсаторах перемикання відбуваються через зародкоутворення та рух доменних стінок.

### 3. Кінетична модель Колмогорова — Аврамі — Ішібаші (KAI)

Для опису неоднорідного перемикання доменів застосовується статично-геометрична теорія кристалізації Колмогорова — Аврамі, адаптована Ішібаші та Такагі для сегнетоелектриків (модель KAI).

#### А. Зародкоутворення та гетерогенний ріст

Нехай `dn/dt` — швидкість виникнення зародків нових доменів протилежної полярності в одиниці об'єму. Припускається, що зародки виникають випадковим чином у просторі й розростаються зі постійною швидкістю `v_s` у бічному напрямку та `v_f` у поздовжньому.

Умовна (протяжна) об'ємна частка переключеного матеріалу `μ_ext(t)` (без урахування перекриття сусідніх доменів) обчислюється як інтеграл за часом:

```
μ_ext(t) = ∫₀ᵗ C_dim · vⁿ · (t - τ)ⁿ · (dn / dτ) · dτ
```

де `C_dim` — геометричний коефіцієнт формфактора, `n` — просторова розмірність росту (`n = 2` для двовимірного бічного росту циліндричних доменів, `n = 3` для тривимірних сферичних доменів).

#### Б. Урахування перекриття доменів (Формула Колмогорова)

Реальна об'ємна частка переключеної фази `μ(t)` враховує те, що зародки не виникають у вже переключеному об'ємі. Зв'язок між диференціалами реальної та протяжної частки задається ймовірнісним співвідношенням:

```
dμ = (1 - μ) · dμ_ext

dμ / (1 - μ) = dμ_ext

- ln(1 - μ) = μ_ext(t)

μ(t) = 1 - exp[ - μ_ext(t) ]
```

Для випадку постійної швидкості нуклеації або її швидкого завершення на початкових етапах (`μ_ext(t) = (t / τ₀)ⁿ`), підсумкова формула KAI набуває вигляду:

```
μ(t) = 1 - exp[ - (t / τ₀)ⁿ ]
```

де `τ₀` — характерний часовий масштаб перемикання, а `n` — показник Аврамі (`1.5 ≤ n ≤ 3.0`).

### 4. Виведення часової залежності струму перемикання I_sw(t)

Повна поляризація `P(t)` у процесі перемикання від початкового стану `-Pᵣ` до кінцевого `+Pᵣ` виражається через частку переключеного об'єму `μ(t)`:

```
P(t) = - Pᵣ + 2 · Pᵣ · μ(t) = - Pᵣ + 2 · Pᵣ · { 1 - exp[ - (t / τ₀)ⁿ ] }
```

Згідно з рівнянням безперервності та електродинамікою Maxwell, струм перемикання `I_sw(t)` у зовнішньому колі конденсатора площею `A_cap` дорівнює:

```
I_sw(t) = A_cap · (dP / dt)
```

Обчислимо похідну від поляризації `P(t)` за часом `t`:

```
dP / dt = 2 · Pᵣ · (dμ / dt)

dμ / dt = d/dt { 1 - exp[ - (t / τ₀)ⁿ ] }
        = exp[ - (t / τ₀)ⁿ ] · (n / τ₀) · (t / τ₀)ⁿ⁻¹
```

Підставляючи похідну в формулу струму, отримуємо аналітичний вираз для струму перемикання KAI:

```
I_sw(t) = (2 · Pᵣ · A_cap · n / τ₀) · (t / τ₀)ⁿ⁻¹ · exp[ - (t / τ₀)ⁿ ]
```

#### Розрахунок часу досягнення максимуму струму t_peak

Для знаходження часу `t_peak`, при якому струм перемикання досягає максимального значення `I_max`, обчислимо похідну `d(I_sw)/dt` і прирівняємо її до нуля:

```
d/dt [ tⁿ⁻¹ · exp( - (t / τ₀)ⁿ ) ] = 0

(n - 1)·tⁿ⁻² · exp( - (t / τ₀)ⁿ ) - tⁿ⁻¹ · exp( - (t / τ₀)ⁿ ) · (n / τ₀ⁿ)·tⁿ⁻¹ = 0

(n - 1) - (n / τ₀ⁿ) · tⁿ = 0

t_peak = τ₀ · [ (n - 1) / n ]¹ᐟⁿ
```

Для типового випадку `n = 2` (двовимірний розріст циліндричних доменів):

```
t_peak = τ₀ · (1 / 2)¹ᐟ² = τ₀ / √2 ≈ 0.707 · τ₀

I_max = I_sw(t_peak) = (2 · Pᵣ · A_cap / τ₀) · √2 · exp(-1/2) ≈ 0.858 · (2 · Pᵣ · A_cap / τ₀)
```

### 5. Модель нуклеації, обмеженої локальними зародками (NLS)

У високодисперсних полікристалічних плівках `HfO₂` (HZO) розміри кристалічних зерен є дуже малими (`5–15 нм`). Бічний ріст доменних стінок швидко зупиняється на міжзернових межах. У таких системах перемикання обмежується не швидкістю руху доменної стінки, а часом очікування нуклеації зародка у кожному окремому зерні.

Модель NLS розглядає плівку як масив незалежних зерен з лоренцівським розподілом часів нуклеації `g(log τ)`:

```
g(log τ) = (A / π) · [ w / ( (log τ - log τ_med)² + w² ) ]
```

де `τ_med` — медіанний час нуклеації, `w` — ширина лоренцівського розподілу, а `A` — нормувальна константа.

Інтегральна частка переключеного об'єму NLS задається усередненням по всіх зернах:

```
μ_NLS(t) = ∫ [ 1 - exp( - t / τ ) ] · g(log τ) · d(log τ)
```

Струм перемикання в NLS-моделі демонструє широке плато та розтягнутий логарифмічний хвіст спадання, що точно описує експериментальні криві зчитування у нанорозмірних HZO-FeRAM конденсаторах.
