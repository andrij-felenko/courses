# 🧮 Математична модель кінетики іонного транспорту та росту містка

Кількісний опис фізичних процесів у комірці CBRAM вимагає математичного моделювання трьох взаємопов'язаних етапів: електрохімічної генерації катіонів на анодній межі, польового дрейфу іонів крізь твердий електроліт та теплового розчинення містка при стиранні.

## 1. Кінетика анодного окиснення: виведення рівняння Батлера — Фольмера

Перехід атома металу (наприклад, `Ag`) з активного анода у стан катіона `Ag⁺` у матриці твердого електроліту супроводжується подоланням поверхневого енергетичного бар'єра `E_ox`. При накладанні зовнішньої різниці потенціалів `V` електрохімічний потенціал на інтерфейсі зміщується, змінюючи висоту активаційного бар'єра.

Густина струму анодного окиснення `j_ox` задається рівнянням Батлера — Фольмера:

```
j_ox = j_0 · [ exp( (α · z · q · η) / (k_B · T) ) - exp( -((1 - α) · z · q · η) / (k_B · T) ) ]
```

де:
- `j_0` — густина струму обміну при рівновазі,
- `α` — коефіцієнт симетрії електронного переносу (зазвичай `α ≈ 0.5`),
- `z` — валентність катіона (`z = 1` для `Ag⁺`, `z = 2` для `Cu²⁺`),
- `q` — елементарний електричний заряд (`1.602 × 10⁻¹十九 Кл`),
- `η = V_interface - V_eq` — електрохімічне перенапруження на анодній межі,
- `k_B` — стала Больцмана (`1.381 × 10⁻²³ Дж/К`),
- `T` — абсолютна температура в келвінах.

Фізична природа коефіцієнта симетрії `α` полягає у розподілі падіння потенціалу вздовж подвійного електричного шару на інтерфейсі. Величина `α` показує, яка частина електричної енергії прикладеної напруги спрямовується на зниження потенціального бар'єра прямої реакції окиснення.

При сильних позитивних напругах (`η >> k_B T / (z q)`) зворотним потоком відновлення можна знехтувати, і рівняння спрощується до формули Тафеля:

```
j_ox ≈ j_0 · exp( (α · z · q · η) / (k_B · T) )
```

Електродне перенапруження `η` зв'язане з прикладеною напругою `V` та опірним падінням у товщі електроліту: `η = V - I · R_bulk`. Це створює нелінійний граничний режим інжекції катіонів.

## 2. Іонний дрейф Мотта — Герні під дією сильного електричного поля

Усередині аморфної матриці електроліту катіон перескочує між сусідніми потенційними ямами, віддаленими на середнє значення `a` (довжина стрибка, `a ≈ 0.3–0.5 нм`). За відсутності поля енергетичний бар'єр перескоку дорівнює `E_a`. Електричне поле напруженістю `E = V / d` знижує бар'єр для стрибка вздовж поля на величину `ΔE = z · q · E · a / 2`.

Частота стрибків іона у напрямку поля задається співвідношенням Мотта — Герні:

```
ν_forward = ν_0 · exp( -(E_a - z · q · E · a / 2) / (k_B · T) )
```

Зворотна частота стрибків проти поля дорівнює:

```
ν_backward = ν_0 · exp( -(E_a + z · q · E · a / 2) / (k_B · T) )
```

Результуюча густина іонного струму `j_ion`:

```
j_ion = z · q · n_ion · a · (ν_forward - ν_backward)
= 2 · z · q · n_ion · a · ν_0 · exp( -E_a / (k_B · T) ) · sinh( (z · q · E · a) / (2 · k_B · T) )
```

де `n_ion` — об'ємна концентрація вільних катіонів, `ν_0` — частота спроб (порядок теплових коливань ґратки, `ν_0 ≈ 10¹²–10¹³ Гц`).

Виведення цієї формули базується на підсумовуванні прямих і зворотних перескоків іона через активаційний бар'єр. Коли електричне поле відсутнє (`E = 0`), гіперболічний синус дорівнює нулю, і результуючий іонний струм `j_ion = 0`.

Для надвисоких полів (`E > 10⁶ В/см`), коли `z · q · E · a >> 2 k_B T`, гіперболічний синус переходить в експоненту:

```
j_ion ≈ z · q · n_ion · a · ν_0 · exp( -(E_a - z · q · E · a / 2) / (k_B · T) )
```

Звідси випливає експоненціальна залежність іонного струму та швидкості росту містка від прикладеної напруги. Ефективна рухливість катіонів у сильному полі стає функцією напруженості:

```
μ_eff(E) = (ν_0 · a / E) · exp( -E_a / (k_B · T) ) · sinh( (z · q · E · a) / (2 · k_B · T) )
```

Це пояснює, чому при напругах зчитування `V_READ ≈ 0.1 В` рухливість катіонів є мізерно малою, а при напрузі запису `V_SET ≈ 1.2 В` зростає на 8–10 порядків.

## 3. Диференціальне рівняння росту та розчинення нанопровідника

Нехай `h` — висота провідного містка від катода в напрямку анода (`0 ≤ h ≤ d`, де `d` — товщина електроліту). Зміна об'єму містка виражається через масоперенос Фарадея:

```
d V_fil / dt = (M / (z · F · d_metal)) · I_ion
```

де:
- `M` — молярна маса металу містка (`107.87 г/моль` для Ag, `63.55 г/моль` для Cu),
- `F = N_A · q` — стала Фарадея (`96485 Кл/моль`),
- `d_metal` — густина металу (`10.49 г/см³` для Ag, `8.96 г/см³` для Cu),
- `I_ion = j_ion · S_fil` — повний іонний струм.

Математичне виведення швидкості поздовжнього проростання фронту спирається на геометрію каналу. Якщо припустити конічну форму містка із постійним кутом конусності, швидкість поздовжнього росту фронту `dh/dt` дорівнює:

```
dh / dt = (M / (z · F · d_metal)) · j_ion(E(h), T)
```

Напруженість поля у зазорі між верхівкою містка та анодом дорівнює `E(h) = V / (d - h)`. Це створює позитивний зворотний зв'язок: у міру наближення містка до анода зазор `(d - h)` зменшується, поле `E(h)` зростає, прискорюючи ріст ураганним чином (лавиноподібний фазовий перехід SET).

Час переключення SET `t_SET` обчислюється інтегруванням зворотної швидкості:

```
t_SET = ∫ [ 1 / (dh/dt) ] dh  (від h = 0 до h = d)
```

Враховуючи експоненційне зростання поля в зазорі, основний час очікування витрачається на початкову фазу нуклеації зародка (`h < 0.2 d`), тоді як остаточне замикання зазору відбувається за частки пікосекунд.

## 4. Теплова модель RESET: 1D стаціонарне рівняння Джоулевого нагріву

Під час стирання (RESET) через металеве звуження площею `A_constriction` протікає високий електронний струм `I_RESET`. Стаціонарний розподіл температури вздовж містка `T(x)` описується одновимірним рівнянням теплопровідності з джерелом Джоулевого тепла:

```
- d/dx [ κ_th · dT/dx ] = j_el² · ρ(T)
```

де:
- `κ_th` — коефіцієнт теплопровідності металевого містка,
- `j_el = I_RESET / A_constriction` — густина електронного струму,
- `ρ(T) = ρ_0 · [ 1 + β_T · (T - T_0) ]` — питомий опір металу з температурою (`β_T ≈ 0.0038 K⁻¹`).

Інтегрування цього рівняння для містка довжиною `L` за межевих умов `T(0) = T(L) = T_env` дає максимум температури в центрі звуження:

```
T_max = T_env + (V_RESET² / (8 · L_Lorenz))
```

де `L_Lorenz = (π² / 3) · (k_B / q)² ≈ 2.44 × 10⁻⁸ В²/К²` — число Лоренца із закону Відемана — Франца.

Фізична краса цього виводу полягає у тому, що максимальна температура `T_max` не залежить прямо від геометричних розмірів містка (довжини чи радіуса), а визначається виключно прикладеною напругою `V_RESET` та числом Лоренца. Це фундаментально пояснює, чому напруга RESET є стабільною величиною для містків різної товщини.

Коли напруга стирання досягає `V_RESET ≈ 0.3–0.5 В`, максимальна температура в звуженні сягає значення `T_max ≈ 600–800 K`. При цій температурі термоактивована дифузія та електроперенос приводять до плавлення й швидкого термохімічного розриву містка за час менше `10 нс`.

Динаміка зменшення радіуса містка `r_fil` у найвужчому перерізі описується диференціальним рівнянням дифузійно-термічного стирання:

```
dr_fil / dt = - v_0 · exp( -(E_diff - z · q · E · a / 2) / (k_B · T_max) )
```

Висока температура `T_max` експоненціально прискорює швидкість звуження `dr_fil/dt`. Коли радіус `r_fil` стає меншим за атомарний радіус `r_atom ≈ 0.15 нм`, місток розривається, і опір осередку стрибкоподібно зростає до рівня HRS.

Капілярна нестійкість Релея додає додатковий термодинамічний тиск на циліндричний місток. При розм'якшенні металу поверхневий натяг викликає спонтанний розпад рідкого нанопровідника на ізольовані краплі, якщо довжина містка перевищує його периметр (`L > 2 π r_fil`).
