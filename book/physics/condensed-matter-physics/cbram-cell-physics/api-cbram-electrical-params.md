# 📋 Паспорт специфікацій та електрофізичних параметрів CBRAM

Провідна місткова оперативна пам'ять (CBRAM / ECM) є енергонезалежною технологією резистивної оперативної пам'яті. Нижче наведено зведені специфікації, електричні інтерфейси, часові діаграми, параметри надійності та принципи інтеграції осередків CBRAM для проектування інтегральних схем і нейроморфних обчислювальних архітектур.

## 1. Специфікація двополюсника та операційні параметри

Елемент CBRAM керується напругою або струмом, що прикладаються між активним анодом (Anode / Bit Line, BL) та інертним катодом (Cathode / Source Line, SL).

| Параметр | Позначення | Типове значення | Діапазон | Одиниці вимірювання | Умови та фізичний зміст |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Напруга замикання (SET)** | `V_SET` | `+1.2` | `+0.5 ... +2.5` | В | Позитивний імпульс на аноді, необхідний для утворення містка |
| **Напруга стирання (RESET)** | `V_RESET` | `-0.8` | `-0.3 ... -1.8` | В | Зворотний імпульс на аноді для теплового розчинення звуження |
| **Напруга зчитування** | `V_READ` | `+0.1` | `+0.05 ... +0.3` | В | Безпечна напруга зчитування без руйнування стану (`V_READ << V_SET`) |
| **Опір стан LRS (ON)** | `R_LRS` | `1 ... 10` | `0.1 ... 50` | кОм | Опір з замкненим металевим нанопровідником |
| **Опір стан HRS (OFF)** | `R_HRS` | `10 ... 100` | `1 ... 1000` | МОм | Опір матриці електроліту з розірваним містком |
| **Вікно опору (Window)** | `R_HRS / R_LRS` | `10⁴` | `10³ ... 10⁶` | — | Співвідношення сигналів «0» та «1» |
| **Струм комплайєнсу** | `I_CC` | `50` | `1 ... 500` | мкА | Обмеження струму при SET для контролю товщини містка |
| **Тривалість імпульсу SET** | `t_SET` | `10` | `1 ... 100` | нс | Час утворення неперервного провідного каналу |
| **Тривалість імпульсу RESET**| `t_RESET` | `20` | `2 ... 200` | нс | Час термічного та електрохімічного розриву містка |
| **Енергія на операцію** | `E_pulse` | `0.1 ... 1` | `0.01 ... 10` | пДж | Енергоспоживання при переключенні одиничної комірки |
| **Ресурс переключень** | `Endurance` | `10⁸` | `10⁶ ... 10¹⁰` | циклів | Кількість реверсивних циклів SET/RESET до деградації |
| **Час збереження даних** | `Retention` | `> 10` | `> 10` | років | Збереження стану при температурі `T = 85 °C` |

Операційна специфікація елемента визначає межі допустимих електричних впливів для стабільної роботи пам'яті. Зчитування стану здійснюється при малій напрузі `V_READ`, яка не викликує помітного іонного дрейфу в товщі диелектрика.

При використанні осередків у складі енергонезалежних масивів пам'яті критично важливо контролювати імпульсне навантаження. Подача напруг, що перевищують `V_SET` більш ніж на 50%, може викликати надмірну інжекцію металлу з анода та утворення занадто товстих містків, для стирання яких потрібні підвищені струми RESET.

## 2. Фізичне обґрунтування характеристичних напруг та часових інтервалів

Опис перехідних режимів осередку CBRAM спирається на нелінійний зв'язок між імпульсною напругою та іонною кінетикою.

### Напруга SET (`V_SET`)
Значення `V_SET` визначається напруженістю електричного поля, необхідною для зниження активаційного бар'єра іонного дрейфу `E_a` в товщі твердого електроліту. При напругах `V < V_SET` швидкість іонного дрейфу є мізерно малою, що забезпечує завадостійкість до шумів зчитування. Коли прикладена напруга сягає `V_SET`, полем створюється лавиноподібний приріст катіонної інжекції, і місток замикається за час менше `10 нс`.

Фізичний поріг замикання залежить від товщини шару диелектрика та температури. При підвищенні робочої температури середовища напруга `V_SET` незначно знижується внаслідок термоактивованого полегшення іонних стрибків.

### Напруга RESET (`V_RESET`)
Напруга стирання `V_RESET` має протилежну полярність відносно анодного електрода. Величина `V_RESET` вибирається такою, щоб струм через низькоомний місток `I = V_RESET / R_LRS` створював локальну потужність Джоулевого нагріву, достатню для підвищення температури атомарного звуження до `T_max ≈ 500 ... 700 K`. За таких температур виникає термічно прискорений електроперенос та капілярний розрив містка.

Процес RESET є самообмежувальним: як тільки в містку виникає нанорозрив, струм через комірку падає на кілька порядків, виділення Джоулевого тепла припиняється, а локальна температура миттєво повертається до кімнатної.

### Напруга зчитування (`V_READ`) та ліміт збурення (Read Disturb Margin)
Зчитування стану пам'яті здійснюється шляхом вимірювання струму при подачі низької напруги `V_READ ≈ 0.1 В`. Оскільки `V_READ` становить менше 10% від `V_SET`, іонний дрейф у матриці пригнічено на 10 порядків. Це забезпечує понад `10¹²` циклів зчитування без зміни значення опору.

Захист від збурення зчитування перевіряється в режимі довгих пачок імпульсів. Якщо напруга зчитування піднімається вище `0.3 В`, виникає ризик повільного підростання розірваного містка під дією накопиченого іонного дрейфу.

## 3. Діаграма станів та рівні квантування провідності

Завдяки атомарному масштабу перерізу нанопровідника провідність елемента в стані LRS не є довільною, а квантується відповідно до формули Ландауера для одновимірних балістичних провідників:

```
G = n · G_0 = n · (2 · e² / h)
```

де:
- `G_0 ≈ 77.48 мкСм` — квант провідності Ландауера,
- `R_0 = 1 / G_0 ≈ 12.91 кОм` — квантовий опір поодинокого атомарного контакту,
- `n` — кількість балістичних квантових каналів (число атомів у найвужчому перерізі містка, `n = 1, 2, 3, ...`).

### Таблиця багаторівневих станів для нейроморфної пам'яті (MLC / Synaptic)

| Логічний / Синаптичний стан | Кількість атомів у звуженні `n` | Провідність `G` (мкСм) | Еквівалентний опір `R` (кОм) | Режим струму обмеження `I_CC` | Фізична конфігурація звуження |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **HRS (OFF / Стан 00)** | `0` (розрив > 1 нм) | `< 0.1` | `> 10 000` | — | Тунельний зазор у матриці диелектрика |
| **MLC State 1 (Стан 01)** | `1` (один атом) | `77.5` | `12.91` | `I_CC ≈ 10 мкА` | Одиночний ланцюжок з 1 атома Ag/Cu |
| **MLC State 2 (Стан 10)** | `2` (два атоми) | `155.0` | `6.45` | `I_CC ≈ 25 мкА` | Точковий контакт з 2 атомів у перерізі |
| **MLC State 3 (Стан 11)** | `3` (три атоми) | `232.4` | `4.30` | `I_CC ≈ 40 мкА` | Три балістичні квантові канали |
| **LRS High (Суцільний конус)**| `n > 10` | `> 775` | `< 1.29` | `I_CC > 100 мкА` | Масивний металевий місток |

Дискретні рівні провідності забезпечують фізичне підґрунтя для запису 2 біт інформації в одну фізичну комірку пам'яті (MLC). Для програмування стану `01`, `10` або `11` на затвор селекторного транзистора подають відповідну градацію напруги обмеження, яка фіксує максимальний струм `I_CC` на етапі SET.

У нейроморфних застосуваннях дискретні квантові рівні працюють як ваги синапсів. Подача пачки однакових імпульсів напруги невеликої тривалості викликає поетапне додавання поодиноких атомів до звуження містка, поступово піднімаючи провідність елемента.

## 4. Матрична конфігурація та селекторні елементи

У великих масивах пам'яті (Crossbar Array) для усунення паразитного струму витоку (Parasite Sneak-Path Current) крізь сусідні незадіяні елементи комірка CBRAM об'єднується з селекторним приладом.

### Конфігурація 1T-1R (One Transistor — One CBRAM Cell)
- Включає послідовний NMOS транзистор-селектор.
- Затвор транзистора підключається до лінії слів (Word Line, WL), виклик адреси — через лінію бітів (Bit Line, BL) та лінію витоку (Source Line, SL).
- Забезпечує точне обмеження струму `I_CC` за рахунок регулювання напруги `V_WL` на затворі транзистора у режимі насичення: `I_CC ≈ (1/2) μ C_ox (W/L) (V_WL - V_th)²`.

Завдяки точному контролю `I_CC` конфігурація 1T-1R володіє найвищою ресурсоємністю (до `10⁹` циклів) та мінімальним розкидом опорів LRS.

### Конфігурація 1S-1R (One Selector — One CBRAM Cell)
- Включає двополюсний пороговий селектор (Ovonic Threshold Switch, OTS або оксидний селектор Mott).
- Забезпечує максимальну щільність пакування `4 F²` у тривимірних багатошарових матрицях (3D Crossbar).
- Селектор володіє нелінійною ВАХ: при `V < V_th` опір селектора є високим, блокуючи паразиційні струми витоку, а при `V > V_th` селектор відчиняється, пропускаючи струм переключення CBRAM.

Застосування селекторів 1S-1R є ключовою умовою побудови багатошарових кубів пам'яті високої ємності, де кілька поверхів кросбар-матриць розташовуються безпосередньо над CMOS-периферією.

## 5. Обмеження та правила експлуатації (Design Rules)

При проектуванні схем керування пам'яттю CBRAM обов'язково дотримуються таких інженерних обмежень:

1. **Заборона перевищення струму без комплайєнсу**: подача напруги `V > V_SET` без обмеження струму `I_CC` призводить до незворотного перегріву й запікання масивного металевого містка (Hard Breakdown), який неможливо розчинити зворотним імпульсом RESET.
2. **Суворе дотримання полярності**: замикання (SET) дозволене лише при позитивному потенціалі на активному аноді (`V_anode > V_cathode`). Зворотна полярність при високому опорі може спричинити деструктивний електротермічний пробій твердого електроліту.
3. **Контроль тривалості імпульсів**: подача імпульсів тривалістю `t > 1 мкс` при високих напругах знижує endurance ресурсоємність комірки через надмірний нагрів диелектричної матриці.
4. **Урахування термічного бюджету BEOL**: обробка мікросхем із вже сформованими осередками CBRAM на етапі збирання не повинна перевищувати `400 °C` тривалістю понад 30 хвилин для запобігання термічної кристалізації електроліту або термодифузії срібла.

Дотримання цих правил гарантує стабільне збереження інформаційного стану протягом понад 10 років при робочих температурах до `85 °C`.
