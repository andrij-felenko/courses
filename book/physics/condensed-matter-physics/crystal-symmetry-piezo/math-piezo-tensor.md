# 🧮 Термодинаміка та математична симетрія тензора п'єзомодулів

Ця вставка містить математичне виведення системних рівнянь п'єзоелектрики з чотирьох термодинамічних потенціалів, доведення симетрії тензора п'єзомодулів, процедуру скорочення Фойгта, закони тензорних перетворень при поворотах системи координат та строге обґрунтування заборони п'єзоефекту у центросиметричних і деяких високосиметричних кристалічних класах.

## Термодинамічне виведення зв'язаних рівнянь стану

П'єзоелектричні явища описують двосторонній електромеханічного зв'язок між механічними напруженнями `σ[jk]` (або деформаціями `ε[jk]`) та електричним полем `E[i]` (або вектором поляризації `P[i]` чи вектором електричного зміщення `D[i]`).

Для опису термодинамічної системи в умовах постійної температури (`dT = 0`) обрано незалежними змінними компоненти тензора механічних напружень `σ[jk]` та компоненти вектора напруженості електричного поля `E[i]`. Термодинамічним потенціалом цієї системи є узагальнений потенціал Гіббса `G(T, σ, E)`.

Повний диференціал потенціалу Гіббса одиниці об'єму суцільного п'єзоелектричного середовища описується виразом:

```
dG = -ε[jk] · dσ[jk] - D[i] · dE[i]      [перше начало термодинаміки для електромеханічного середовища]
```

Тут і далі за повторюваними тензорними індексами `i, j, k, l, m, n, o ∈ {1, 2, 3}` здійснюється автоматичне сумування за правилом Ейнштейна.

Оскільки `dG` є повним диференціалом стану, компоненти деформації `ε[jk]` та електричного зміщення `D[i]` визначаються як відповідні частинні похідні:

```
ε[jk] = -(∂G / ∂σ[jk])_{E, T}             [визначення деформації через частинну похідну G]
D[i] = -(∂G / ∂E[i])_{σ, T}              [визначення електричного зміщення через частинну похідну G]
```

Розкладемо потенціал Гіббса `G` у степеневий ряд Тейлора за незалежними змінними `σ[jk]` та `E[i]` поблизу природного неполяризованого та недеформованого стану (`σ = 0`, `E = 0`), обмежуючись квадратичними за амплітудою членами:

```
G(σ, E) = G₀ - (1/2) · s[jklm]ᵀ · σ[jk] · σ[lm] - d[ijk] · E[i] · σ[jk] - (1/2) · ε[ij]ˢ · E[i] · E[j]
```

Фізичний зміст коефіцієнтів розкладу наступний:
- `s[jklm]ᵀ` — тензор пружної піддатливості 4-го рангу за сталого електричного поля (`E = const`);
- `ε[ij]ˢ` — тензор диелектричної проникності 2-го рангу за сталого механічного напруження (`σ = const`);
- `d[ijk]` — тензор п'єзоелектричних модулів 3-го рангу (п'єзомодулів).

Продиференціюємо потенціал `G` за змінними `σ[jk]` та `E[i]`, щоб одержати лінійні рівняння стану п'єзоелектричного середовища:

```
ε[jk] = -∂G / ∂σ[jk]
= s[jklm]ᵀ · σ[lm] + d[ijk] · E[i]       [рівняння зворотного п'єзоелектричного ефекту]

D[i] = -∂G / ∂E[i]
= d[ijk] · σ[jk] + ε[ij]ˢ · E[j]          [рівняння прямого п'єзоелектричного ефекту]
```

Зауважимо, що коефіцієнт `d[ijk]` у зворотному п'єзоефекті тотожно дорівнює коефіцієнту `d[ijk]` у прямому п'єзоефекті. Це безпосередньо випливає з рівності других мішаних похідних гладкого термодинамічного потенціалу (теорема Шварца):

```
∂²G / (∂E[i] · ∂σ[jk]) = ∂²G / (∂σ[jk] · ∂E[i])
= -d[ijk]                                [доведення тотожності коефіцієнтів через симетрію Шварца]
```

Таким чином, прямий і зворотний п'єзоелектричні ефекти є термодинамічно спряженими проявами єдиного фундаментального зв'язку, що описується тими самими 18 коефіцієнтами `d[ijk]`.

## Чотири термодинамічні потенціали та системи рівнянь

Залежно від вибору незалежних змінних термодинамічний стан п'єзоелектрика описується одним з чотирьох потенціалів, кожен з яких зручний для певних граничних умов:

1. **Потенціал Гіббса `G(σ, E)` (незалежні `σ` та `E`):**
   Використовується, коли задані механічні напруження та напруга на електродах. Повний диференціал `dG = -ε[jk]·dσ[jk] - D[i]·dE[i]`.
   Дає `d`-форму рівнянь:
```
ε[jk] = s[jklm]ᵀ · σ[lm] + d[ijk] · E[i]  [зворотний d-ефект]
D[i] = d[ijk] · σ[jk] + ε[ij]ˢ · E[j]    [прямий d-ефект]
```

2. **Внутрішня енергія `U(ε, D)` (незалежні `ε` та `D`):**
   Використовується при заданій деформації та розімкнених електродах (`D = const`). Повний диференціал `dU = σ[jk]·dε[jk] + E[i]·dD[i]`.
   Дає `h`-форму рівнянь:
```
σ[jk] = c[jklm]ᴰ · ε[lm] - h[ijk] · D[i]  [зворотний h-ефект]
E[i] = -h[ijk] · ε[jk] + β[ij]ˢ · D[j]   [прямий h-ефект]
```

3. **Вільна енергія Гельмгольца `F(ε, E)` (незалежні `ε` та `E`):**
   Використовується при затиснутому кристалі (`ε = const`) та заданій напрузі. Повний диференціал `dF = σ[jk]·dε[jk] - D[i]·dE[i]`.
   Дає `e`-форму рівнянь:
```
σ[jk] = c[jklm]ᵀ · ε[lm] - e[ijk] · E[i]  [зворотний e-ефект]
D[i] = e[ikl] · ε[kl] + ε[ij]ˢ · E[j]    [прямий e-ефект]
```

4. **Електричний потенціал Гіббса `G₁(σ, D)` (незалежні `σ` та `D`):**
   Використовується при вільних механічних гранях і затиснутому заряді. Повний диференціал `dG₁ = -ε[jk]·dσ[jk] + E[i]·dD[i]`.
   Дає `g`-форму рівнянь:
```
ε[jk] = s[jklm]ᴰ · σ[lm] + g[ijk] · D[i]  [зворотний g-ефект]
E[i] = -g[ijk] · σ[jk] + β[ij]ˢ · D[j]   [прямий g-ефект]
```

Зв'язок між п'єзомодулями `d[ijk]` та п'єзоконстантними `e[ijk]` здійснюється через 4-ранговий тензор пружної жорсткості `c[jklm]`:

```
e[ijk] = d[imn] · c[mnjk]ᵀ               [перерахунок d-модулів у e-константи]
d[ijk] = e[imn] · s[mnjk]ᵀ               [зворотний перерахунок e-констант у d-модулі]
```

## Внутрішня симетрія та згортка Фойгта

За відсутності внутрішніх обертальних моментів тензор механічних напружень Коші `σ[jk]` є симетричним:

```
σ[jk] = σ[kj]                            [симетрія тензора напружень]
```

Оскільки вираз прямого п'єзоефекту `D[i] = d[ijk] · σ[jk]` згортається з симетричним тензором `σ[jk]`, антисиметрична частина `d[ijk]` за індексами `j` та `k` не робить внеску в поляризацію. Це вимагає внутрішньої симетрії тензора п'єзомодулів:

```
d[ijk] = d[ikj]                          [симетрія за індексами механічного напруження]
```

Загальна кількість компонент тензора 3-го рангу становить `3 × 3 × 3 = 27`. Враховуючи симетрію за двома останніми індексами `j` і `k`, кількість незалежних компонент зменшується до:

```
N_indep = 3 × (3 × (3 + 1) / 2) = 3 × 6 = 18 [кількість незалежних компонент у найнижчій симетрії]
```

Для зручності матричного запису пару симетричних індексів `(jk)` замінюють одним індексом `α ∈ {1, 2, 3, 4, 5, 6}` за правилом Фойгта:

```
(11) → 1  [нормальне напруження σ11 вздовж осі X]
(22) → 2  [нормальне напруження σ22 вздовж осі Y]
(33) → 3  [нормальне напруження σ33 вздовж осі Z]
(23) = (32) → 4  [зсувне напруження σ23 у площині YZ]
(13) = (31) → 5  [зсувне напруження σ13 у площині XZ]
(12) = (21) → 6  [зсувне напруження σ12 у площині XY]
```

Матриця п'єзомодулів `d[iα]` має розмірність 3 рядки на 6 стовпчиків:

```
        ┌                                  ┐
        │  d11  d12  d13  d14  d15  d16  │
d[iα] = │  d21  d22  d23  d24  d25  d26  │
        │  d31  d32  d33  d34  d35  d36  │
        └                                  ┘
```

У матричній нотації Фойгта співвідношення для деформацій та електричного зміщення набувають вигляду:

```
D[i] = d[iα] · σ[α]                      [прямий п'єзоефект: i = 1..3, α = 1..6]
ε[α] = d[iα] · E[i]                      [зворотний п'єзоефект для нормальних компонент α = 1, 2, 3]
γ[α] = 2 · d[iα] · E[i]                  [зворотний п'єзоефект для інженерних зсувів α = 4, 5, 6]
```

Множник 2 виникає тому, що інженерна зсувна деформація `γ[α]` удвічі більша за відповідну компоненту тензора деформацій `ε[jk]` (`γ[4] = 2·ε[23]`, `γ[5] = 2·ε[13]`, `γ[6] = 2·ε[12]`).

## Закон перетворення при зміні системи координат

При переході до нової декартової системи координат з матрицею повороту `R` (де `R[i,m]` — косинус кута між новою віссю `i` та старою віссю `m`) компоненти полярного тензора 3-го рангу перетворюються за законом:

```
d'[ijk] = R[i,m] · R[j,n] · R[k,o] · d[mno]   [закон перетворення тензора 3-го рангу]
```

Ортогональна матриця переходу `R` задовольняє умову ортогональності:

```
R[i,m] · R[j,m] = δ[ij]                   [умова ортогональності матриці повороту]
det(R) = +1  (для власних поворотів)
det(R) = -1  (для дзеркальних відображень та інверсії)
```

В кутах Ейлера `(φ, θ, ψ)` матриця повороту `R` є добутком трьох послідовних матриць поворотів навколо осей координат, що дозволяє обчислювати п'єзомодулі `d'_33(θ, φ)` для довільного кристалографічного зрізу.

**Принцип Неймана:** Точкова група симетрії будь-якої фізичної властивості кристала повинна включати в себе точкову групу симетрії самого кристала.

Якщо перетворення `R` є елементом симетрії точкової групи кристала, тензор п'єзомодулів у новій і старій системах координат зобов'язаний бути тотожним:

```
d'[ijk] = d[ijk]                         [вимога інваріантності Неймана]
R[i,m] · R[j,n] · R[k,o] · d[mno] = d[ijk] [система алгебраїчних рівнянь для компонент d[ijk]]
```

## Матриці перетворення Бонда для 3×6 матриць п'єзомодулів

Для прямих обчислень у матричній нотації Фойгта замість трикратного тензорного підсумовування `R[i,m]·R[j,n]·R[k,o]` застосовують формулізовані **матриці перетворення Бонда (Bond transformation matrices)**:

```
d'[iα] = R[i,j] · d[jβ] · M[βα](R)       [перетворення п'єзомодулів через матриці Бонда]
```

де `R` — стандартна 3×3 матриця повороту координат, а `M(R)` — 6×6 матриця Бонда для напружень, елементи якої виражаються через квадрати та подвійні добутки направляючих косинусів:

```
        ┌                                                                                    ┐
        │ R11²        R12²        R13²        2·R12·R13          2·R13·R11          2·R11·R12          │
        │ R21²        R22²        R23²        2·R22·R23          2·R23·R21          2·R21·R22          │
M(R) =  │ R31²        R32²        R33²        2·R32·R33          2·R33·R31          2·R31·R32          │
        │ R21·R31     R22·R32     R23·R33     R22·R33+R23·R32    R21·R33+R23·R31    R21·R32+R22·R31    │
        │ R31·R11     R32·R12     R33·R13     R12·R33+R13·R32    R13·R31+R11·R33    R11·R32+R12·R31    │
        │ R11·R21     R12·R22     R13·R23     R12·R23+R13·R22    R11·R23+R13·R21    R11·R22+R12·R21    │
        └                                                                                    ┘
```

Цей матричний підхід є основою програмного моделювання п'єзоактивних акустичних резонаторів у пакетах скінченних елементів (COMSOL Multiphysics, ANSYS).

## Строге доведення обнулення п'єзомодулів при наявності центра інверсії

Операція просторової інверсії `I` перетворює довільний радиус-вектор `r` у протилежний `-r`. Матриця перетворення просторової інверсії `R_I` має вигляд:

```
        ┌               ┐
        │ -1   0   0  │
R_I =   │  0  -1   0  │
        │  0   0  -1  │
        └               ┘
```

Аналітично елементи цієї матриці виражаються через дельта-символ Кронекера: `R_I[i,m] = -δ[im]`.

Підставимо матрицю інверсії `R_I` у закон тензорного перетворення п'єзомодулів:

```
d'[ijk] = R_I[i,m] · R_I[j,n] · R_I[k,o] · d[mno]
= (-δ[im]) · (-δ[jn]) · (-δ[ko]) · d[mno] [підстановка матриці інверсії]
= (-1)³ · (δ[im] · δ[jn] · δ[ko] · d[mno]) [винесення скалярних множників]
= -1 · d[ijk]                            [згортка з дельтами Кронекера]
```

Отже, при просторовій інверсії всі компоненти полярного тензора 3-го рангу змінюють знак на протилежний: `d'[ijk] = -d[ijk]`.

Якщо точкова група симетрії кристала містить центр інверсії (є центросиметричною), то згідно з принципом Неймана фізичні властивості кристала не змінюються при інверсії:

```
d'[ijk] = d[ijk]                         [інваріантність за принципом Неймана]
-d[ijk] = d[ijk]                         [поєднання математичного перетворення й фізичної симетрії]
2 · d[ijk] = 0                           [зведення подібних членів]
d[ijk] = 0  (для всіх i, j, k ∈ {1, 2, 3}) [єдино можливий математичний розв'язок]
```

**Строгий висновок:** Для будь-якої з 11 центросиметричних кристалографічних точкових груп усі 18 п'єзоелектричних модулів суворо дорівнюють нулю (`d[iα] = 0`). Наявність центру симетрії повністю забороняє існування п'єзоелектричного ефекту.

## Виведення матриці п'єзомодулів для тетрагонального класу 4mm (BaTiO3 / ЦТС)

Для глибшого розуміння роботи принципу Неймана виконаємо повне математичне виведення п'єзоелектричної матриці для тетрагонального класу `4mm` (симетрія титанату барію та поляризованої ЦТС-кераміки).

Клас `4mm` володіє поворотною віссю 4-го порядку `4 || Z` та чотирма вертикальними площинами відображення `m`, зокрема площинами `m ⊥ X` та `m ⊥ Y`.

1. **Застосування відображення в площині `m ⊥ X`:**
   Матриця дзеркального відображення має вигляд `R_mx = diag(-1, 1, 1)`.
   Застосуємо її до компоненти `d[111]` (`d11` у нотації Фойгта):

```
d'[111] = R[1,1] · R[1,1] · R[1,1] · d[111] = (-1)³ · d[111] = -d[111]
```

З вимоги інваріантності `d'[111] = d[111]` маємо `-d11 = d11 ⇒ d11 = 0`.
Аналогічно обнуляються всі компоненти з непарною кількістю індексів 1: `d12 = 0`, `d13 = 0`, `d26 = 0`, `d34 = 0`, `d35 = 0`.

2. **Застосування відображення в площині `m ⊥ Y`:**
   Матриця відображення `R_my = diag(1, -1, 1)` аналогічно обнуляє всі компоненти з непарною кількістю індексів 2: `d21 = 0`, `d22 = 0`, `d23 = 0`, `d16 = 0`.

3. **Застосування повороту на кут 90° навколо осі Z (C4z):**
   Матриця повороту `R_4z` перетворює координати за законом: `x' = y`, `y' = -x`, `z' = z`.
   Застосуємо її до компонент `d[311]` та `d[322]` (`d31` та `d32` у нотації Фойгта):

```
d'[311] = R[3,3] · R[1,2] · R[1,2] · d[322] = (1) · (-1) · (-1) · d[322] = d[322]
```

З вимоги інваріантності `d'[311] = d[311]` отримуємо жорстке співвідношення `d31 = d32`.

Аналогічний розрахунок для зсувних компонент `d[113]` та `d[223]` (`d15` та `d24` у нотації Фойгта) дає:

```
d'[113] = R[1,2] · R[1,2] · R[3,3] · d[223] = (-1) · (-1) · (1) · d[223] = d[223] ⇒ d15 = d24
```

У результаті з 18 початкових компонент ненульовими залишаються лише 3 незалежні п'єзомодулі (`d31`, `d33`, `d15`):

```
        ┌                                  ┐
        │    0    0    0    0  d15    0  │
d[iα] = │    0    0    0  d15    0    0  │   [матриця класу 4mm]
        │  d31  d31  d33    0    0    0  │
        └                                  ┘
```

Це пояснює структуру п'єзоелектричних властивостей титанату барію та сегнетокераміки: стискання вздовж осі поляризації `Z` викликає повздовжню поляризацію `P3 = d33 · σ3`, рівномірне стискання у перпендикулярній площині `XY` породжує поперечну поляризація `P3 = d31 · (σ1 + σ2)`, а зсувні напруження викликають поперечну поляризацію `P1 = d15 · σ5` та `P2 = d15 · σ4`.

## Виведення матриці п'єзомодулів для гексагонального класу 6mm (AlN / ZnO)

Гексагональний полярний клас `6mm` (`C6v`) володіє поворотною віссю 6-го порядку `C6z || Z` та шістьма площинами дзеркального відображення `m`.

1. **Застосування дзеркальних площин:**
   Як і у випадку тетрагонального класу `4mm`, наявність вертикальних площин `m ⊥ X` та `m ⊥ Y` обнуляє всі п'єзомодулі з непарною кількістю індексів `1` або `2`. Це одразу виключає елементи `d11, d12, d13, d14, d16, d21, d22, d23, d25, d26, d34, d35, d36`.

2. **Застосування повороту на кут 60° навколо осі Z (`C6z`):**
   Матриця повороту на 60° перетворює координати за законом: `x' = x/2 + y·√3/2`, `y' = -x·√3/2 + y/2`, `z' = z`.
   Застосуємо закон тензорного перетворення до компоненти `d[311]`:

```
d'[311] = (R[1,1]² · d[311] + R[1,2]² · d[322])
= (1/4) · d31 + (3/4) · d32              [вираження нової компоненти через суму]
```

З вимоги інваріантності `d'[311] = d[311]` маємо: `d31 = (1/4)·d31 + (3/4)·d32 ⇒ (3/4)·d31 = (3/4)·d32 ⇒ d31 = d32`.

Аналогічний розрахунок для зсувної компоненти `d[113]` вимагає `d15 = d24`.
Компонента `d[333]` (`d33`) є повністю інваріантною відносно будь-яких поворотів навколо осі `Z`.

У результаті матриця гексагонального класу `6mm` має повністю тотожну форму з матрицею тетрагонального класу `4mm`, містячи лише **3 незалежні коефіцієнти** (`d15`, `d31`, `d33`):

```
        ┌                                  ┐
        │    0    0    0    0  d15    0  │
d[iα] = │    0    0    0  d15    0    0  │   [матриця класу 6mm]
        │  d31  d31  d33    0    0    0  │
        └                                  ┘
```

## Виведення матриці п'єзомодулів для кубічного класу 4-bar 3m (GaAs / ZnS)

Розглянемо кубічний нецентросиметричний клас `4-bar 3m` (`Td`). Він володіє трьома інверсійно-поворотними осями 4-го порядку `4-bar` (уздовж осей `X, Y, Z`) та чотирма поворотно-дзеркальними осями 3-го порядку (уздовж головних діагоналей куба).

1. **Застосування інверсійного повороту `4-bar || Z`:**
   Матриця перетворення `R_4z_bar` перетворює координати за законом: `x' = y`, `y' = -x`, `z' = -z`.
   Застосуємо її до нормальної компоненти `d[333]` (`d33` у нотації Фойгта):

```
d'[333] = R[3,3] · R[3,3] · R[3,3] · d[333] = (-1)³ · d[333] = -d[333]
```

З вимоги `d'[333] = d[333]` одержуємо `-d33 = d33 ⇒ d33 = 0`.
Аналогічно інверсійні осі `4-bar || X` та `4-bar || Y` обнуляють усі нормальні коефіцієнти: `d11 = 0` та `d22 = 0`.

Розглянемо компоненту `d[311]` (`d31`):

```
d'[311] = R[3,3] · R[1,2] · R[1,2] · d[322] = (-1) · (-1) · (-1) · d[322] = -d[322]
```

Сумісне застосування осей обнуляє всі нормальні та поперечні коефіцієнти: `d31 = d32 = d12 = d13 = d21 = d23 = 0`.

2. **Аналіз зсувних компонент `d[123]`, `d[213]`, `d[312]` (`d14`, `d25`, `d36`):**
   Перетворення `R_4z_bar` дає:

```
d'[123] = R[1,2] · R[2,1] · R[3,3] · d[213] = (-1) · (1) · (-1) · d[213] = d[213] ⇒ d14 = d25
```

Застосування повороту на 120° навколо головної діагоналі куба `[111]` симетрично переставляє координатні осі `X → Y → Z → X`. Це зв'язує всі три зсувні модулі між собою: `d14 = d25 = d36`.

У результаті для класу `4-bar 3m` (зокрема для `GaAs` та `ZnS`) залишається виключно **1 незалежний коефіцієнт** `d14`:

```
        ┌                                  ┐
        │    0    0    0  d14    0    0  │
d[iα] = │    0    0    0    0  d14    0  │   [матриця класу 4-bar 3m]
        │    0    0    0    0    0  d14  │
        └                                  ┘
```

## Виведення матриці п'єзомодулів для ромбічного класу mm2 (PVDF / KNbO3)

Для закріплення методу Неймана проаналізуємо ромбічний полярний клас `mm2` (симетрія сегнетоелектричного полімеру PVDF та монокристалів ніобату калію).

Група `mm2` містить дві взаємно перпендикулярні площини дзеркального відображення `m1 ⊥ X` та `m2 ⊥ Y`, перетин яких утворює поворотну вісь 2-го порядку `C2z || Z`.

1. **Дзеркальне відображення в площині `m ⊥ X`:**
   Матриця перетворення має вигляд `R_mx = diag(-1, 1, 1)`.
   Застосуємо закон тензорного перетворення `d'[ijk] = R[i,m] · R[j,n] · R[k,o] · d[mno]`.
   Будь-яка компонента, що містить індекс `1` непарну кількість разів (1 або 3 рази), при множенні на елементи `R[1,1] = -1` змінює знак:

```
d'[111] = (-1)³ · d[111] = -d[111] ⇒ d11 = 0
d'[122] = (-1)·(1)² · d[122] = -d[122] ⇒ d12 = 0
d'[133] = (-1)·(1)² · d[133] = -d[133] ⇒ d13 = 0
d'[212] = (1)·(-1)·(1) · d[212] = -d[26] ⇒ d26 = 0
d'[323] = (1)·(1)·(1) · d[323] = d[34]  (компонента d34 залишається для m_x, але обнуляється при m_y)
```

2. **Дзеркальне відображення в площині `m ⊥ Y`:**
   Матриця перетворення має вигляд `R_my = diag(1, -1, 1)`.
   Аналогічно обнуляються всі компоненти з непарною кількістю індексів `2`: `d21 = 0`, `d22 = 0`, `d23 = 0`, `d16 = 0`, `d34 = 0`.

3. **Поворот навколо осі 2-го порядку `C2z || Z`:**
   Матриця повороту `R_2z = diag(-1, -1, 1)`.
   Ця операція обнуляє компоненти з непарною кількістю індексів `3` для невідповідних комбінацій.

У результаті для класу `mm2` ненульовими залишаються рівно 5 незалежних компонент: `d15`, `d24`, `d31`, `d32`, `d33`.

```
        ┌                                  ┐
        │    0    0    0    0  d15    0  │
d[iα] = │    0    0    0  d24    0    0  │   [матриця класу mm2]
        │  d31  d32  d33    0    0    0  │
        └                                  ┘
```

Відмінність класу `mm2` від тетрагонального класу `4mm` полягає у відсутності осей 4-го порядку. Через це у класі `mm2` коефіцієнти вздовж осей `X` та `Y` є незалежними між собою: `d31 ≠ d32` та `d15 ≠ d24`.

## Виведення матриці п'єзомодулів для тригонального класу 3m (LiNbO3 / LiTaO3)

Проаналізуємо популярний тригональний полярний клас `3m` (`C3v`), до якого належать монокристали ніобату літію (`LiNbO3`) та танталату літію (`LiTaO3`).

Група `3m` володіє поворотною віссю 3-го порядку `C3z || Z` та трьома дзеркальними площинами відображення `m`, одна з яких перпендикулярна до осі `Y` (`m ⊥ Y`).

1. **Площина дзеркального відображення `m ⊥ Y`:**
   Матриця відображення `R_my = diag(1, -1, 1)` обнуляє всі компоненти `d[ijk]`, що містять індекс `2` непарну кількість разів. У нотації Фойгта це дає: `d11 = 0`, `d14 = 0`, `d21 = 0`, `d22 = 0`, `d23 = 0`, `d25 = 0`, `d34 = 0`, `d36 = 0`.

2. **Поворот на 120° навколо осі `Z` (`C3z`):**
   Застосування матриці повороту `R_3z` зв'язує решту компонент співвідношеннями:
   - `d22 = -d21 = -d16 / 2`
   - `d24 = d15`
   - `d32 = d31`

У результаті матриця класу `3m` містить лише **4 незалежні коефіцієнти** (`d15`, `d22`, `d31`, `d33`):

```
        ┌                                            ┐
        │    0     0     0      0   d15  -2·d22  │
d[iα] = │ -d22   d22     0    d15     0       0  │   [матриця класу 3m]
        │  d31   d31   d33      0     0       0  │
        └                                            ┘
```

Це доведення пояснює структуру анізотропії ніобату літію: великий коефіцієнт `d15 ≈ 68 pC/N` робить його ідеальним для зсувних п'єзоакустичних перетворювачів.

## Виведення матриці п'єзомодулів для тригонального кварцу (група 32)

Для порівняння виконаємо розрахунок для тригонального кристала кварцу (`α-SiO2`), точкова група якого `32` (`D3` за Шенфлісом).

Група `32` містить поворотні вісь 3-го порядку вздовж осі `Z` (`C3z`) та три поворотні осі 2-го порядку в горизонтальній площині (`C2x`), одна з яких направлена вздовж осі `X`.

Матриця повороту на кут `180°` навколо осі `X` (`C2x`) має вигляд:

```
          ┌              ┐
          │  1   0   0  │
R_2x =    │  0  -1   0  │
          │  0   0  -1  │
          └              ┘
```

Застосуємо перетворення `R_2x` до компонент тензора `d[ijk]`:

```
d'[111] = R[1,1] · R[1,1] · R[1,1] · d[111] = (1)³ · d[111] = d[111]  (залишається)
d'[122] = R[1,1] · R[2,2] · R[2,2] · d[122] = (1) · (-1)² · d[122] = d[122]  (залишається)
d'[133] = R[1,1] · R[3,3] · R[3,3] · d[333] = (1) · (-1)² · d[133] = d[133]  (залишається)
d'[311] = R[3,3] · R[1,1] · R[1,1] · d[311] = (-1) · (1)² · d[311] = -d[311] ⇒ d[311] = 0
d'[333] = R[3,3] · R[3,3] · R[3,3] · d[333] = (-1)³ · d[333] = -d[333] ⇒ d[333] = 0
```

Матриця повороту на кут `120°` навколо осі `Z` (`C3z`) має вигляд:

```
          ┌                       ┐
          │ -1/2   √3/2      0   │
R_3z =    │ -√3/2  -1/2      0   │
          │   0      0       1   │
          └                       ┘
```

Сумісне застосування перетворень `C2x` та `C3z` дає такі жорсткі співвідношення між рештою компонент:

```
d12 = -d11                              [компонента d12 виражається через -d11]
d22 = -d11                              [компонента d22 дорівнює -d11]
d25 = -d14                              [компонента d25 виражається через -d14]
d16 = -2 · d22 = 2 · d11                 [компонента d16 дорівнює 2·d11 у нотації Фойгта]
d13 = 0, d23 = 0, d31 = 0, d32 = 0, d33 = 0, d34 = 0, d35 = 0, d36 = 0
```

У результаті матриця п'єзомодулів для кристалів групи `32` (зокрема кварцу) скорочується всього до **2 незалежних коефіцієнтів** (`d11` та `d14`):

```
        ┌                                            ┐
        │  d11   -d11     0     d14     0       0   │
d[iα] = │    0      0     0      0    -d14  -2·d11  │
        │    0      0     0      0     0       0   │
        └                                            ┘
```

Цей результат чітко пояснює експериментальні факти для кварцу:
1. При прикладанні стискального напруження вздовж електричної осі `X` (`σ1`) виникає повздовжня поляризація `P1 = d11 · σ1`.
2. При стисканні вздовж механічної осі `Y` (`σ2`) виникає поперечна поляризація протилежного знака `P1 = -d11 · σ2`.
3. При стисканні вздовж оптичної осі `Z` (`σ3`) поляризація взагалі не виникає (`P = 0`), оскільки весь третій рядок матриці складається з нулів (`d31 = d32 = d33 = 0`).

## Висновок щодо алгоритму аналізу симетрії тензора

Узагальнюючи математичний апарат, процедура аналізу тензора п'єзомодулів для будь-якої кристалографічної точкової групи складається з трьох послідовних кроків:
1. Запис точкових операцій симетрії `R` кристала у формі 3×3 ортогональних матриць.
2. Складання системи 18 алгебраїчних рівнянь за принципом Неймана `R[i,m]·R[j,n]·R[k,o]·d[mno] = d[ijk]`.
3. Перехід від індексної форми `d[ijk]` до скороченої матриці Фойгта `d[iα]` (3×6) для практичних обчислень.

Цей строгий алгоритм гарантує точне визначення кількості ненульових коефіцієнтів і дозволяє проектувати акустоелектронні пристрої з максимальним п'єзоелектричним відгуком.
