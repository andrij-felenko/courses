# 🧮 Математична фізика гальмування LSS та профілі імплантації

Фізичний розрахунок проникнення високоенергетичних іонів у тверде тіло спирається на аналіз втрат кінетичної енергії іона вздовж його траєкторії. Головним теоретичним фундаментом опису цих процесів у напівпровідниках є теорія Ліндгарда, Шарффа та Шіотта (LSS-теорія, *Lindhard, Scharff, Schiøtt*, 1963 рік). Вона розділяє загальну гальмівну здатність середовища на два незалежні компоненти: ядерне та електронне гальмування.

### Повна гальмівна здатність та диференціальний переріз

Гальмівна здатність середовища `S(E)` визначається як середня втрата кінетичної енергії іона `E` на одиницю довжини пробігу `x` у матеріалі з атомною щільністю `N` (для кремнію `N = 5.02 × 10²² см⁻³`):

```
S(E) = -dE/dx = N · ∫ T · dσ(E, T)
```

де `T` — енергія, передана атому мишені при поодинокому зіткненні, `dσ(E, T)` — диференціальний мікроскопічний переріз розсіювання.

За принципом суперпозиції аддитивних втрат, повна гальмівна здатність ділиться на ядерну `S_n(E)` та електронну `S_e(E)` складові:

```
S(E) = S_n(E) + S_e(E)
```

### Ядерне гальмування S_n(E): пружні зіткнення атомних ядер

Ядерне гальмування описує кулонівське розсіювання позитивно зарядженого ядра іона (заряд `Z₁·e`, маса `M₁`) на ядрах атомів ґратки (заряд `Z₂·e`, маса `M₂`), екранованих електронними хмарами атомів.

Для врахування електронного екранування кулонівський потенціал модифікують за допомогою функції екранування `Ф(r/a_TF)` (функція Томаса–Фермі або універсальний потенціал Зіглера–Бірсака–Літтмарка, ZBL):

```
V(r) = (Z₁ · Z₂ · e²) / (4 · π · ε₀ · r) · Ф(r / a_TF)
```

де `a_TF` — радіус екранування Томаса–Фермі:

```
a_TF = 0.8853 · a₀ / (Z₁⁰.²³ + Z₂⁰.²³)
```

тут `a₀ = 0.529 Å` — Борівський радіус атома водню.

У теорії LSS впроваджують безрозмірну знижену енергію `ε` та безрозмірний пробіг `ρ`:

```
ε = (a_TF · M₂) / (Z₁ · Z₂ · e² · (M₁ + M₂)) · E

ρ = N · 4 · π · a_TF² · (M₁ · M₂) / (M₁ + M₂)² · x
```

У цих безрозмірних змінних ядерна гальмівна здатність `s_n(ε) = dε/dρ` описується аналітичною напівемпіричною апроксимацією Зіглера:

```
s_n(ε) = (0.5 · ln(1 + 1.1383 · ε)) / (ε + 0.01321 · ε⁰.⁵⁷⁵³ + 0.19747 · ε⁰.⁴⁹739)
```

Перехід від безрозмірної гальмівної здатності `s_n(ε)` до фізичної гальмівної здатності `S_n(E)` здійснюється за перераховувальним співвідношенням:

```
S_n(E) = (4 · π · a_TF · Z₁ · Z₂ · e² · N · M₁) / (M₁ + M₂) · s_n(ε)
```

Асимптотична поведінка ядерного гальмування `S_n(E)` має виражений фізичний характер:
- При низьких енергіях (`ε < 0.1`) ядерне гальмування зростає з енергією як `S_n(E) ∝ E⁰.⁵`.
- Потім `S_n(E)` досягає свого абсолютного максимуму при `ε ≈ 0.35` (для Бору в кремнії це відповідає енергії `E ≈ 3 кеВ`, для Фосфору — `E ≈ 20 кеВ`, для Миш'яку — `E ≈ 100 кеВ`).
- При високих енергіях (`ε >> 1`) ядерний переріз спадає за законом Резерфорда: `S_n(E) ∝ 1/E`.

### Електронне гальмування S_e(E): неупруге в'язке тертя

Електронне гальмування виникає внаслідок неупругих зіткнень іона з вільними та зв'язаними електронами кристала. Оскільки маса електрона `m_e` у тисячі разів менша за масу іона `M₁`, кожен окремий акт розсіювання передає електрону мізерну частку енергії та майже не змінює напрямку руху іона.

У діапазоні швидкостей іона `v`, які є меншими за швидкість Фермі електронного газу кремнію (`v < v₀ · Z₁²ᐟ³`, де `v₀ ≈ 2.19 × 10⁸ см/с` — Борівська швидкість), теорія Ліндгарда та Шарффа доводить, що електронне гальмування пропорційне швидкості іона, а отже — квадратному кореню з його кінетичної енергії:

```
S_e(E) = k_e · E⁰.⁵ = k_e · √E
```

Коефіцієнт електронного гальмування `k_e` розраховується за формулою LSS:

```
k_e = C_e · (e² / (4 · π · ε₀)) · (Z₁²ᐟ³ · Z₂ / a_TF) · (m_e / M₁)⁰.⁵
```

де `C_e ≈ 1.21 · Z₁¹ᐟ⁶` — емпірична константа порядку одиниці.

При надвисоких енергіях (понад кілька МеВ), коли швидкість іона перевищує орбітальні швидкості внутрішніх електронів, електронне гальмування досягає максимуму й описується класичною формулою Бете–Блоха з залежністю `S_e(E) ∝ (1/E) · ln(const · E)`.

### Критична енергія E_c crossover

Точка перетину кривих ядерного та електронного гальмування `S_n(E_c) = S_e(E_c)` задає **критичну енергію** `E_c`:

```
S_n(E_c) = S_e(E_c)   ⇒   E_c
```

Фізичне значення `E_c`:
- Якщо початкова енергія іона `E₀ > E_c`, то на більшій частині шляху іон втрачає енергію через електронне гальмування. Він рухається практично прямолінійно, не викликаючи деформації кристалічної ґратки.
- Коли іон сповільнюється до енергії `E < E_c`, домінантним стає ядерне гальмування: іон починає сильно хаотично розсіюватися, створюючи наприкінці свого пробігу щільний каскад структурних дефектів.

| Домішка | Атомний номер Z₁ | Маса M₁ (а.о.м.) | Критична енергія E_c в Si |
| :--- | :--- | :--- | :--- |
| Бор (B) | 5 | 11 | 17 кеВ |
| Фосфор (P) | 15 | 31 | 140 кеВ |
| Миш'як (As) | 33 | 75 | 800 кеВ |
| Сурма (Sb) | 51 | 122 | 2000 кеВ |

Для легких іонів (Бор) електронне гальмування переважає майже у всьому діапазоні технологічних енергій (`> 17 кеВ`), тому профіль Бору залягає глибоко і має порівняно мало радіаційних дефектів. Для важких іонів (Миш'як, Сурма) домінує ядерне гальмування, що призводить до швидкої аморфізації поверхні на невеликих глибинах.

### Проектований пробіг R_p та страґлінг ΔR_p

Повний фізичний шлях іона вздовж його зигзагоподібної траєкторії називається повним пробігом `R`:

```
R = ∫₀^{E₀} dE / (S_n(E) + S_e(E))
```

Для технології мікроелектроніки важлива не довжина вигнутої траєкторії, а нормальна глибина проникнення від поверхні пластини — **проектований пробіг** `R_p` (*projected range*):

```
R_p = ∫₀^{E₀} cos(θ(E)) · dE / (S_n(E) + S_e(E))
```

де `θ(E)` — кут між миттєвим вектором швидкості іона та нормаллю до поверхні пластини.

У наближенні LSS співвідношення між повним пробігом `R` та проектованим пробігом `R_p` задається геологічно-геометричним фактором `M₂ / M₁`:

```
R_p ≈ R / (1 + (M₂ / (3 · M₁)))
```

Через статистичну природу зіткнень глибина зупинки кожного іона є випадковою величиною. Статистичний розкид глибин зупинки навколо середнього значення `R_p` описується аксіальним страґлінгом `ΔR_p` (*projected straggle*), а поздовжнє розмивання пучка в бокові боки під край маски — перпендикулярним (латеральним) страґлінгом `ΔR_⊥` (*transverse straggle*):

```
ΔR_p = √(⟨x²⟩ - ⟨x⟩²)

ΔR_⊥ = √(⟨y²⟩ + ⟨z²⟩)
```

### Математичні моделі просторового розподілу C(x)

#### 1. Одномірна Гауссова модель

У найпростішому наближенні аморфного середовища або при придушеному каналюванні просторовий профіль концентрації імплантованих іонів `C(x)` на глибині `x` описується симетричним нормальним розподілом Гаусса:

```
C(x) = (Ф / (√(2 · π) · ΔR_p)) · exp(- (x - R_p)² / (2 · ΔR_p²))
```

де `Ф` — доза імплантації (іонний флюенс, число іонів на одиницю площі, `см⁻²`).

Максимальна концентрація домішки `C_max` досягається строго на глибині `x = R_p`:

```
C_max = C(R_p) = Ф / (√(2 · π) · ΔR_p) ≈ 0.3989 · Ф / ΔR_p
```

Ширина профілю на висоті `C_max / e` дорівнює `2.828 · ΔR_p`, а повна ширина на напіввисоті (FWHM) становить:

```
FWHM = 2 · √(2 · ln(2)) · ΔR_p ≈ 2.355 · ΔR_p
```

#### 2. Розподіл Пірсона IV типу (Pearson IV)

Реальні експериментальні профілі домішок відхиляються від симетричного Гауссового дзвону через асиметрію ядерних зіткнень та наявність залишкового каналювання. Для їхнього точного опису в TCAD-симуляторах застосовують розподіл Пірсона IV типу, який враховує третій та четвертий статистичні моменти — асиметрію (ск'юнес, `γ₁`) та ексцес (куртозис, `β₂`):

```
γ₁ = μ₃ / (ΔR_p³)      [ск'юнес — асиметрія профілю]

β₂ = μ₄ / (ΔR_p⁴)      [куртозис — гостровершинність]
```

де `μ₃ = ⟨(x - R_p)³⟩` та `μ₄ = ⟨(x - R_p)⁴⟩` — третій та четвертий центральні моменти розподілу.

Диференціальне рівняння роду розподілів Пірсона має вигляд:

```
d(ln C(y)) / dy = - (y + a) / (b₀ + b₁ · y + b₂ · y²)
```

де `y = x - R_p`, а коефіцієнти `a`, `b₀`, `b₁`, `b₂` виражаються через моменти `ΔR_p`, `γ₁` та `β₂`:

```
b₀ = (4 · β₂ - 3 · γ₁²) · ΔR_p² / (10 · β₂ - 12 · γ₁² - 18)

a = b₁ = γ₁ · ΔR_p · (β₂ + 3) / (10 · β₂ - 12 · γ₁² - 18)

b₂ = (2 · β₂ - 3 · γ₁² - 6) / (10 · β₂ - 12 · γ₁² - 18)
```

Від'ємна асиметрія (`γ₁ < 0`, характерна для важких іонів, таких як Миш'як) означає, що профіль затягнутий у бік поверхні кристала. Додатна асиметрія (`γ₁ > 0`, характерна для легкого Бору) виникає через «хвіст» каналювання, затягуючи профіль углиб субстрату.

#### 3. Двомірний профіль під край маски

У крайки маскувального оксиду чи полікремнієвого затвора (`y = 0`) двомірний профіль `C(x, y)` розраховується як згортка з латеральним страґлінгом `ΔR_⊥`:

```
C(x, y) = (C_1D(x) / 2) · erfc(y / (√2 · ΔR_⊥))
```

де `erfc(z) = 1 - erf(z)` — додаткова функція помилок. Ця формула задає точний профіль підточування домішки під затвор, який у сучасних технологічних процесах є в кілька разів меншим за боковий зсув при термічній дифузії.

#### 4. Подвійний Гауссів розподіл для канальованого хвоста

Для швидкої технологічної апроксимації профілю Бору з урахуванням каналювання часто застосовують подвійну Гауссову функцію (Dual-Pearson / Dual-Gaussian):

```
C_tot(x) = (1 - r_c) · C_main(x, R_p, ΔR_p) + r_c · C_chan(x, R_chan, ΔR_chan)
```

де `r_c` — частка іонів, що потрапили в канал (`0.01 – 0.1`), `R_chan` та `ΔR_chan` — параметри глибинного канальованого хвостового розподілу. Ця модель дозволяє розраховувати глибину залегання p-n переходу `x_j` на рівні підкладкової концентрації `N_sub` без витрат обчислювального часу на повне Монте-Карло моделювання.
