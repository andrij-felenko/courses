# 🧮 Математичний вивід флуктуаційно-дисипаційної теореми Каллена — Велтона

Цей математичний вивід встановлює точний тотожний зв'язок між лінійним дисипативним відгуком квантової системи на зовнішнє збурення та спектральною густиною спонтанних рівноважних флуктуацій її фізичних величин. Теорема Каллена — Велтона закладає математичний фундамент для обчислення квантового шуму у будь-якому лінійному провіднику, резонаторі або дисипативній квантовій системі.

## Постановка задачі та квантовий гамільтоніан взаємодії

Розглянемо макроскопічну або мікроскопічну квантову систему з невираженим незбуреним гамільтоніаном `H_0`, яка знаходиться у стані термодинамічної рівноваги при абсолютній температурі `T`. Систему піддають зовнішньому часово-залежному збуренню (силі) `f(t)`, яке взаємодіє з ермітовим оператором спостережуваної фізичної величини `A`.

Загальний часово-залежний гамільтоніан системи приймає вигляд:

```
H(t) = H_0 - A · f(t)
```

Позначимо `|n⟩` та `E_n` як повний набір власних станів та власних значень енергії незбуреного гамільтоніана `H_0`:

```
H_0 |n⟩ = E_n |n⟩
```

У стані термодинамічної рівноваги матриця густини системи `ρ_0` є діагональною у базисі власних станів, а ймовірність знаходження системи у стані `|n⟩` визначається канонічним розподілом Больцмана:

```
w_n = ⟨n| ρ_0 |n⟩ = exp(-E_n / (k_B T)) / Z
Z = ∑_n exp(-E_n / (k_B T))       [статистична сума системи]
```

Статистична сума `Z` забезпечує нормування ймовірностей, так що сума всіх `w_n` дорівнює одиниці `∑_n w_n = 1`.

## Узагальнена сприйнятливість та поглинання енергії

Якщо зовнішня сила змінюється за гармонічним законом `f(t) = Re(f_0 · exp(-i ω t))`, то усереднене по квантовому ансамблю зміщення оператора `⟨A(t)⟩` у лінійному наближенні теорії відгуку описується комплексною узагальненою сприйнятливістю `χ(ω)`:

```
⟨A(ω)⟩ = χ(ω) · f(ω)
χ(ω) = χ'(ω) + i · χ''(ω)
```

Тут `χ'(ω)` — дійсна частина сприйнятливості, що описує реактивний (дисперсійний) відгук системи без безпосередніх втрат енергії, а `χ''(ω)` — уявна частина сприйнятливості, що відповідає за дисипативний (незворотний) зсув фази та поглинання енергії зовнішнього збурення.

Для обчислення середньої швидкості дисипації потужності `Q_dis` скористаємося квантовомеханічним рівнянням руху для середньої енергії системи:

```
Q_dis = ⟨d H / dt⟩ = - ⟨A(t)⟩ · df / dt
```

Підставляючи гармонічне збурення `f(t) = ½ (f_0 exp(-i ω t) + f_0* exp(i ω t))` та виконуючи усереднення по періоду коливань `2π / ω`, отримуємо точний вираз для дисипованої потужності через уяву частину сприйнятливості:

```
Q_dis = ½ · ω · χ''(ω) · |f_0|²
```

З іншого боку, обчислимо поглинання енергії за допомогою квантовомеханічної теорії збурень. За золотим правилом Фермі швидкість переходу квантової системи зі стану `|n⟩` у стан `|m⟩` під дією гармонічного збурення `A · f_0` дорівнює:

```
W_(n→m) = (π / (2 ħ)) · |⟨m|A|n⟩|² · |f_0|² · [δ(E_m - E_n - ħ ω) + δ(E_m - E_n + ħ ω)]
```

Повна середня поглинута потужність є результатом балансу між поглинанням квантів `ħ ω` (переходи з нижчих рівнів на вищі) та вимушеним випромінюванням (переходи з вищих рівнів на нижчі):

```
Q_dis = ∑_(n,m) w_n · W_(n→m) · (E_m - E_n)
= (π ω / 2) · |f_0|² · ∑_(n,m) (w_n - w_m) · |⟨m|A|n⟩|² · δ(E_m - E_n - ħ ω)
```

Зіставляючи феноменологічний вираз для `Q_dis` із квантовим розрахунком за правилом Фермі, отримуємо мікроскопічну формулу Кубо для уявної частини сприйнятливості `χ''(ω)`:

```
χ''(ω) = π · ∑_(n,m) (w_n - w_m) · |⟨m|A|n⟩|² · δ(E_m - E_n - ħ ω)    [Формула Кубо]
```

Ця формула показує, що дисипація визначається різницею заселеностей енергетичних рівнів `(w_n - w_m)` та матричними елементами оператора `A`.

## Спектральна густина рівноважних квантових флуктуацій

Розглянемо часову кореляційну функцію флуктуацій оператора `A(t)` у гейзенбергівській картині за відсутності зовнішнього збурення:

```
K_A(t) = ⟨A(t) A(0)⟩ = ∑_n w_n · ⟨n| exp(i H_0 t / ħ) A exp(-i H_0 t / ħ) A |n⟩
= ∑_(n,m) w_n · |⟨m|A|n⟩|² · exp(i (E_n - E_m) t / ħ)
```

За теоремою Вінера — Хінчина квантова спектральна густина шуму `S_A(ω)` визначається як перетворення Фур'є кореляційної функції:

```
S_A(ω) = ∫_(-∞)^(∞) K_A(t) · exp(i ω t) dt
= 2 π · ∑_(n,m) w_n · |⟨m|A|n⟩|² · δ(E_n - E_m + ħ ω)
```

Переставляючи індекси підсумовування `n` та `m` у виразі для дельта-функції `δ(E_n - E_m + ħ ω) = δ(E_m - E_n - ħ ω)`, отримуємо альтернативний запис спектральної густини:

```
S_A(ω) = 2 π · ∑_(n,m) w_m · |⟨n|A|m⟩|² · δ(E_m - E_n - ħ ω)
```

Скористаємося тим, що у стані рівноваги заселеності рівнів `w_n` та `w_m` пов'язані канонічним больцманівським множником:

```
w_m = w_n · exp(-ħ ω / (k_B T))
```

Звідси випливає фундаментальне співвідношення Кубо — Мартіна — Швінгера (KMS) для несиметричної квантової спектральної густини шуму на позитивних та негативних частотах:

```
S_A(-ω) = S_A(ω) · exp(-ħ ω / (k_B T))
```

Це співвідношення показує, що імовірність спонтанного поглинання кванта енергії з середовища підпорядковується больцманівському фактору придушення порівняно з імовірністю спонтанного випромінювання кванта в середовище.

Різниця больцманівських заселеностей `(w_n - w_m)` може бути виражена безпосередньо через больцманівський множник та саму заселеність `w_m`:

```
w_n - w_m = w_m · [exp(ħ ω / (k_B T)) - 1]
```

## Вивід квантової теореми Каллена — Велтона

Підставимо вираз для різниці заселеностей `(w_n - w_m)` у виведену раніше формулу Кубо для дисипативної частини сприйнятливості `χ''(ω)`:

```
χ''(ω) = π · ∑_(n,m) w_m · [exp(ħ ω / (k_B T)) - 1] · |⟨m|A|n⟩|² · δ(E_m - E_n - ħ ω)
= [exp(ħ ω / (k_B T)) - 1] · (½ · S_A(ω))
```

Виражаючи спектральну густину флуктуацій `S_A(ω)` через уяву частину узагальненої сприйнятливості `χ''(ω)`, отримуємо квантову флуктуаційно-дисипаційну теорему (ФДТ):

```
S_A(ω) = 2 ħ χ''(ω) · [ ½ + 1 / (exp(ħ ω / (k_B T)) - 1) ]
```

Використовуючи тригонометричну тотожність для гіперболічного котангенса:

```
½ + 1 / (exp(x) - 1) = ½ · (exp(x) + 1) / (exp(x) - 1) = ½ · coth(x / 2)
```

отримуємо остаточну компактну формулу Каллена — Велтона для квантової спектральної густини рівноважних флуктуацій:

```
S_A(ω) = ħ · χ''(ω) · coth(ħ ω / (2 k_B T))
```

## Зв'язок із квантовими коммутаторами кореляційних функцій

У квантовій теорії поля та статистичній фізиці дисипативна частина сприйнятливості `χ''(ω)` безпосередньо пов'язана з фур'є-перетворенням середнього значення квантового коммутатора оператора `A` у різні моменти часу:

```
χ''(t) = (i / (2 ħ)) · ⟨[A(t), A(0)]⟩
```

Дійсна частина кореляційної функції описує симетричний шум `S_A^sym(ω) = ½ (⟨A(ω) A(-ω)⟩ + ⟨A(-ω) A(ω)⟩)`, який вимірюється класичними детекторами. З теореми Каллена — Велтона випливає, що симетрична спектральна густина є прямо пропорційною фур'є-перетворенню антикоммутатора `⟨{A(t), A(0)}⟩`:

```
S_A^sym(ω) = ħ · χ''(ω) · coth(ħ ω / (2 k_B T))
```

Це доводить, що комутаційні властивості квантовомеханічних операторів визначають мінімальний рівень дисипації та шуму у будь-якій лінійній фізичній системі.

## Застосування до електричного резистора (Квантовий шум Джонсона — Найквіста)

Застосуємо сформульовану теорему до флуктуацій напруги `V` на двохполюснику з опором `R`. У цьому випадку роль величини `A` відіграє заряд `q`, а роль узагальненого імпедансу `Z(ω)` описує зв'язок напруги та струму.

Зв'язок між уявною частиною сприйнятливості заряду `χ_q''(ω)` та активним опором `R` має вигляд:

```
χ_q''(ω) = Re(Z(ω)) / ω = R / ω
```

Спектральна густина шуму напруги `S_V(ω)` пов'язана зі спектральною густиною шуму заряду `S_q(ω)` співвідношенням `S_V(ω) = ω² · S_q(ω)`:

```
S_V(ω) = ω² · [ ħ · (R / ω) · coth(ħ ω / (2 k_B T)) ]
= ħ R ω · coth(ħ ω / (2 k_B T))
```

Переходячи від циклової частоти `ω` до циклічної частоти `ν = ω / (2π)` та враховуючи симетричну спектральну густину для позитивних частот (`S_V,phys(ν) = 2 S_V(ω)`), отримуємо класично відому формулу квантового шуму Найквіста:

```
S_V,phys(ν) = 4 R · [ h ν / (exp(h ν / (k_B T)) - 1) + ½ h ν ]
= 2 R h ν · coth(h ν / (2 k_B T))
```

## Граничні фізичні режими

Формула Каллена — Велтона охоплює обидва граничні режими фізики флуктуацій:

1. **Низькочастотна / високотемпературна класична межа (`h ν ≪ k_B T`):**
При малих значеннях аргументу `x = h ν / (2 k_B T) ≪ 1` гіперболічний котангенс розкладається у ряд Тейлора `coth(x) ≈ 1/x + x/3`:
```
S_V(ν) ≈ 2 R h ν · (2 k_B T / (h ν)) = 4 R k_B T      [Класична формула Найквіста]
```

2. **Високочастотна / низькотемпературна квантова межа (`h ν ≫ k_B T`):**
При великих значеннях аргументу `x ≫ 1` гіперболічний котангенс прямує до одиниці `coth(x) → 1`:
```
S_V(ν) → 2 R h ν                                      [Нульові вакуумні флуктуації]
```

Таким чином, математичний вивід Каллена — Велтона доводить, що квантовий шум нульових коливань не є довільною добавкою, а суворо випливає з принципу фундаментального зв'язку між дисипацією та флуктуаціями у квантовій механіці.
