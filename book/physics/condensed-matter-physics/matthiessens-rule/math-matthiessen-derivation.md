# 🧮 Математична теорія та виведення адитивності швидкостей розсіяння

Ця вставка містить суворе квантово-кінетичне виведення правила Матіссена на основі рівняння переносу Больцмана в наближенні часу релаксації, виведення правила Нордгейма для залишкового опору розведених сплавів з перших принципів квантової механіки, а також математичний аналіз умов, за яких rule відхиляється від строгої адитивності (варіаційний принцип Колера та двозонна модель Зондгаймера).

## 1. Кінетичне рівняння Больцмана та лінеаризація функції розподілу

Розглянемо електронний газ у металі під дією слабкого стаціонарного однорідного електричного поля `E`. Хвильовий стан електрона характеризується квазіімпульсом `k` та енергією `ε(k)`. Функція розподілу `f(k, r, t)` визначає ймовірність знаходження електрона у стані `k` поблизу просторової точки `r`.

У стаціонарному й просторово-однорідному випадку кінетичне рівняння Больцмана описує баланс між дрейфом електронів під дією поля та їхнім розсіянням на мікроскопічних збуреннях кристала:

```
-(e / ℏ) · E · ∇_k f(k) = C[f(k)]
```

де `e` — елементарний заряд електрона, `ℏ` — зведена стала Планка, `∇_k` — градієнт у просторі квазіімпульсів, а `C[f(k)]` — інтегральний оператор зіткнень.

У слабких електричних полях відхилення функції розподілу від рівноважного розподілу Фермі–Дірака `f₀(ε_k)` є малим. Ми розкладаємо нерівноважну функцію розподілу `f(k)` у лінійний ряд за полем:

```
f(k) = f₀(ε_k) + g(k)
f₀(ε_k) = 1 / (exp((ε_k - ε_F) / (k_B T)) + 1)
```

де `ε_F` — енергія Фермі, `k_B` — стала Больцмана, а `g(k)` — мала нерівноважна добавка, пропорційна електричному полю `E`.

Підставляючи розклад у ліву (дрейфову) частину рівняння Больцмана та нехтуючи квадратичними за полем членами `O(E²)`, отримуємо:

```
-(e / ℏ) · E · ∇_k f₀(ε_k) = -e · E · v(k) · (∂f₀ / ∂ε_k)
```

де `v(k) = (1/ℏ) ∇_k ε_k` — вектор групи швидкості електрона у квазіімпульсному стані `k`.

Таким чином, лінеаризоване кінетичне рівняння Больцмана набуває вигляду:

```
-e · E · v(k) · (∂f₀ / ∂ε_k) = C[g(k)]
```

## 2. Оператор зіткнень та адитивність частот розсіяння

Інтегральний оператор зіткнень `C[f(k)]` визначається різницею між припливом електронів у стан `k` з усіх інших станів `k'` та відпливом зі стану `k` у стани `k'`:

```
C[f(k)] = ∫ ( W(k', k) · f(k') · [1 - f(k)] - W(k, k') · f(k) · [1 - f(k')] ) · (d³k' / (4π³))
```

де `W(k, k')` — ймовірність квантового переходу електрона зі стану `k` у стан `k'` за одиницю часу.

Якщо у кристалі діють два незалежних джерела розсіяння — статичні домішкові атоми (`imp`) та теплові фонони ґратки (`ph`), — загальна ймовірність переходу дорівнює сумі ймовірностей окремих процесів:

```
W(k, k') = W_imp(k, k') + W_ph(k, k')
```

Оскільки інтеграл є лінійним оператором щодо ймовірності `W`, оператор зіткнень розкладається у пряму суму двох незалежних операторів зіткнень:

```
C[g(k)] = C_imp[g(k)] + C_ph[g(k)]
```

### 2.1. Наближення часу релаксації (RTA)

У наближенні часу релаксації (Relaxation Time Approximation) припускається, що дія кожної групи розсіювачів повертає нерівноважну добавку `g(k)` до нуля з власною характерною швидкістю:

```
C_imp[g(k)] = -g(k) / τ_imp(k)
C_ph[g(k)]  = -g(k) / τ_ph(k)
```

де `τ_imp(k)` — час релаксації імпульсу на статичних домішках, а `τ_ph(k)` — час релаксації на фононах.

Підставляючи ці вирази в сумарний оператор зіткнень, отримуємо:

```
C[g(k)]
= C_imp[g(k)] + C_ph[g(k)]
= -g(k) · (1 / τ_imp(k) + 1 / τ_ph(k))
= -g(k) / τ_total(k)
```

Звідси випливає фундаментальна формула сумування зворотних часів релаксації (частот розсіяння):

```
1 / τ_total(k) = 1 / τ_imp(k) + 1 / τ_ph(k)
```

## 3. Обчислення тензора провідності та питомого опору

Густина електричного струму `j` обчислюється як інтеграл від добутку заряду, швидкості та нерівноважної функції розподілу `f(k)` по усій зоні Бріллюена:

```
j = -e · ∫ v(k) · f(k) · (d³k / (4π³))
  = -e · ∫ v(k) · g(k) · (d³k / (4π³))
```

Підставляючи розв'язок для `g(k) = -e · (∂f₀ / ∂ε_k) · τ_total(k) · (v(k) · E)`, отримуємо тензор електропровідності `σ_ij`:

```
j_i = σ_ij · E_j
σ_ij = e² · ∫ v_i(k) · v_j(k) · (-∂f₀ / ∂ε_k) · τ_total(k) · (d³k / (4π³))
```

Для кубічного кристала або ізотропної сферичної поверхні Фермі тензор провідності скаляризується (`σ_ij = σ · δ_ij`). Оскільки похідна `(-∂f₀ / ∂ε_k)` має гострий дельтаподібний пік поблизу рівня Фермі `ε_F` при низьких температурах, інтегрування дає вираз Друде–Зоммерфельда:

```
σ = (n · e² · τ_total(ε_F)) / m*
```

де `n` — об'ємна концентрація електронів провідності, `m*` — ефективна маса.

Виражаємо питомий опір `ρ_total = 1 / σ` і розгортаємо вираз за допомогою знайденого вище закону адитивності часів релаксації:

```
ρ_total
= m* / (n · e² · τ_total)                           [формула Друде для опору: ρ = 1 / σ]
= (m* / (n · e²)) · (1 / τ_imp + 1 / τ_ph)            [адитивність часів релаксації]
= (m* / (n · e² · τ_imp)) + (m* / (n · e² · τ_ph))  [розподільний закон розкриття дужок]
= ρ₀ + ρ_ph(T)                                      [визначення залишкового й фононного опору]
```

Це завершує суворе кінетичне виведення правила Матіссена для ізотропних систем у наближенні часу релаксації.

## 4. Квантовомеханічне виведення правила Нордгейма для залишкового опору

Розглянемо розведений двокомпонентний твердий розчин `A_(1-c) B_c`, де атоми домішки `B` випадковим чином заміщують атоми матриці `A` у вузлах кристалічної ґратки `R_n` з атомною концентрацією `c` (`c ≪ 1`).

Потенціал кристала `V(r)` можна подати як суму періодичного потенціалу усредненого кристала `V_avg(r)` та флуктуаційного потенціалу збурення `ΔV(r)`:

```
V(r) = V_avg(r) + ΔV(r)
V_avg(r) = (1 - c) · ∑_n V_A(r - R_n) + c · ∑_n V_B(r - R_n)
```

Збурення потенціалу у вузлі `R_n` залежить від того, який саме атом знаходиться у даному вузлі:
- Якщо у вузлі `R_n` знаходиться атом `A` (ймовірність `1 - c`), збурення дорівнює `V_A - V_avg = -c · (V_B - V_A)`.
- Якщо у вузлі `R_n` знаходиться атом `B` (ймовірність `c`), збурення дорівнює `V_B - V_avg = (1 - c) · (V_B - V_A)`.

Ймовірність розсіяння електрона зі стану `k` у стан `k'` розраховується у першому борнівському наближенні за допомогою Золотого правила Фермі:

```
W_imp(k, k') = (2π / ℏ) · ⟨|M_(k k')|²⟩_conf · δ(ε_k - ε_k')
M_(k k') = ⟨k'| ΔV(r) |k⟩ = ∫ ψ_k'*(r) · ΔV(r) · ψ_k(r) · d³r
```

Обчислюємо конфігураційне усереднення квадрата матричного елемента `⟨|M_(k k')|²⟩_conf` по випадковому розташуванню атомів `A` та `B`:

```
⟨|M_(k k')|²⟩_conf
= N_sites · [ (1 - c) · |-c · U_(k k')|² + c · |(1 - c) · U_(k k')|² ]
= N_sites · U_(k k')² · [ (1 - c) · c² + c · (1 - c)² ]
= N_sites · U_(k k')² · c · (1 - c) · [ c + (1 - c) ]
= N_sites · U_(k k')² · c · (1 - c)
```

де `U_(k k') = ⟨k'| V_B(r) - V_A(r) |k⟩` — атомний матричний елемент різниці потенціалів домішки й матриці, а `N_sites` — загальне число вузлів ґратки.

Оскільки час релаксації `τ_imp` обернено пропорційний ймовірності розсіяння `W_imp`, залишковий питомий опір `ρ₀` виявляється строго пропорційним конфігураційній фактор-функції `c · (1 - c)`:

```
ρ₀(c) = C_Nordheim · c · (1 - c)
```

Це співвідношення називається **правилом Нордгейма** (Lothar Nordheim, 1931). Для розведених твердих розчинів (`c ≪ 0.1`) множник `(1 - c) ≈ 1`, тому залишковий опір є лінійним щодо концентрації:

```
ρ₀(c) ≈ C_Nordheim · c = (Δρ / c) · c
```

де `Δρ / c` — питомий внесок 1 атомного відсотка домішки.

## 5. Варіаційний принцип Колера та анізотропні відхилення від правила Матіссена

У реальних кристалах поверхня Фермі має складну анізотропну форму, а час релаксації залежить від напрямку хвильового вектора `k`. Рівняння Больцмана можна записати в операторній формі:

```
X(k) = C[ϕ(k)]
X(k) = -e · E · v(k) · (∂f₀ / ∂ε_k)
```

де `ϕ(k)` — шукана нерівноважна добавка до функції розподілу (`g(k) = ϕ(k) · (∂f₀ / ∂ε_k)`).

Згідно з **варіаційним принципом Колера** (Max Kohler, 1949), точна функція розподілу `ϕ(k)` максимізує наступний функціонал електропровідності `K[u]`:

```
K[u] = ⟨u, X⟩² / ⟨u, C[u]⟩
```

де скалярний добуток виражається інтегралом по зоні Бріллюена: `⟨u, v⟩ = ∫ u(k) · v(k) · (d³k / (4π³))`.

Максимальне значення функціоналу дорівнює точній електропровідності системи: `K[ϕ_exact] = σ_exact`. Питомий опір є зворотною величиною `ρ = 1 / K[u]`, тому для будь-якої випробувальної функції `u(k)` розрахований опір є **більшим або рівним** справжньому опору:

```
ρ_calc[u] ≥ ρ_exact
```

Нехай `C_imp` та `C_ph` — оператори розсіяння на домішках та фононах відповідно, а `ϕ_imp` та `ϕ_ph` — точні розв'язки для кожного механізму окремо. Сумарний оператор зіткнень дорівнює `C_total = C_imp + C_ph`.

Якщо ми обчислимо сумарний опір за допомогою випробувальної функції, сформованої з розв'язків окремих механізмів, варіаційний принцип Колера гарантує, що справжній сумарний опір підпорядковується нерівності:

```
ρ_total ≤ ρ_Matthiessen
```

Однак якщо врахувати кутову анізотропію розсіяння по поверхні Фермі (наприклад, гарячі плями з високим розсіянням у шийках поверхні Фермі міді), фонони та домішки вирівнюють нерівноважну функцію розподілу в різних ділянках k-простору. Це перерозподілення носіїв між ділянками з різною рухливістю генерує додатковий нелінійний опір:

```
Δρ_DMR(T, c) = ρ_total(T, c) - (ρ₀(c) + ρ_ph(T)) ≥ 0
```

Це доводить, що через анізотропію поверхні Фермі відхилення від правила Матіссена **завжди є додатними** (`Δρ_DMR ≥ 0`).

## 6. Двозонна модель Зондгаймера–Вільсона

Для перехідних металів з двома зонами провідності (наприклад, `s`-зона з провідністю `σ_s` та `d`-зона з провідністю `σ_d`) повна провідність є сумою двох паралельних каналів:

```
σ_total = σ_s + σ_d = (1 / ρ_s) + (1 / ρ_d)
```

Питомий опір двозонної системи дорівнює:

```
ρ_total = (ρ_s · ρ_d) / (ρ_s + ρ_d)
```

Припустимо, що для кожної зони окремо правило Матіссена виконується строго:

```
ρ_s(T) = ρ_s0 + ρ_sph(T)
ρ_d(T) = ρ_d0 + ρ_dph(T)
```

Підставляючи ці вирази у формулу для `ρ_total` та віднімаючи суму непов'язаних опорів `ρ_Matthiessen = (ρ_s0 · ρ_d0 / (ρ_s0 + ρ_d0)) + (ρ_sph · ρ_dph / (ρ_sph + ρ_dph))`, після алгебраїчних перетворень отримуємо точний вираз для відхилення Зондгаймера–Вільсона:

```
Δρ_DMR(T) = ((ρ_s0 · ρ_dph - ρ_d0 · ρ_sph)²) / ((ρ_s0 + ρ_d0) · (ρ_s0 + ρ_sph + ρ_d0 + ρ_dph) · (ρ_sph + ρ_dph))
```

Оскільки чисельник являє собою квадрат дійсного числа `(ρ_s0 · ρ_dph - ρ_d0 · ρ_sph)² ≥ 0`, а знаменник складається з додатних величин опорів, відхилення від правила Матіссена у двозонних металах є **строго невід'ємним**:

```
Δρ_DMR(T) ≥ 0
```

Величина `Δρ_DMR(T)` дорівнює нулю лише за умови ідеальної пропорційності опорів зон (`ρ_s0 / ρ_d0 = ρ_sph / ρ_dph`). У всіх інших випадках двозонна провідність викликає додатний зсув питомого опору, який досягає максимуму при температурах, де фононий опір стає сумірним із залишковим опором.
