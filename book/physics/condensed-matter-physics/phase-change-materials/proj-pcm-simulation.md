# ⚙️ Чисельне моделювання термічного профілю та кристалізації PCM

Ця програмна вставка реалізує обчислювальний двигун для чисельного розв'язання одновимірного рівняння теплопровідності із нелінійним Джоулевим нагрівом та динамічним оновленням кристалічної частки за кінетичною моделлю Джонсона — Мела — Аврамі — Колмогорова (JMAK) під час дії струмових імпульсів SET та RESET у комірці фазової пам'яті.

## 1. Фізико-математична постановка та чисельна схема

Термічна динаміка активного шару халкогенідного матеріалу (наприклад, Ge2Sb2Te5) товщиною `L` під дією протікаючого електричного струму описується нелінійним одновимірним диференціальним рівнянням теплопровідності із внутрішнім об'ємним джерелом Джоулевого тепла:

```
c_p(T) · d(T)/dt = d/dx [ κ(x, T, X) · d(T)/dx ] + j²(t) · ρ(x, T, X)
```

де:
- `c_p(T)` — об'ємна теплоємність фазового матеріалу (`Дж/(м³·К)`);
- `κ(x, T, X)` — коефіцієнт теплопровідності, який ефективно залежить від місцевої кристалічної частки `X` за правилом сумішей: `κ = X · κ_cry + (1 - X) · κ_amo`;
- `ρ(x, T, X)` — питомий електричний опір середовища (`Ом·м`);
- `j(t)` — густина електричного струму, що протікає через комірку (`А/м²`);
- `X(x, t)` — місцева частка кристалічної фази в точці `x` у момент часу `t` (`0 ≤ X ≤ 1`).

Динаміка фазового переходу під час ізотермічного або неізотермічного нагріву моделюється за допомогою диференціальної форми кінетичного рівняння JMAK:

```
dX/dt = n · K^(1/n) · (1 - X) · [ - ln(1 - X) ]^((n-1)/n)
```

тут `n` — показник Аврамі (для об'ємної кристалізації GST приймається `n = 3`), а `K(T)` — температурно-залежна константа швидкості кристалізації. У даному моделювальному двигуні `K(T)` апроксимується куполоподібною функцією у вікні між температурою склування `T_g = 473 K` та температурою плавлення `T_m = 873 K`. При перевищенні температури плавлення `T ≥ T_m` відбувається миттєве плавлення, і частка кристалічності скидається до нуля: `X = 0`.

Для чисельного розв'язання системи розносних рівнянь використовується явна скінченно-різницева схема (Finite Difference Method, FDM). Просторовий домен товщиною `L` розбивається на `N` вузлів з кроком `dx = L / (N - 1)`. Друга просторова похідна теплопровідності апроксимується триточковим центральним різницевим оператором:

```
d²T/dx² ≈ ( T[i+1] - 2·T[i] + T[i-1] ) / dx²
```

Для забезпечення чисельної стійкості явної часової інтеграції часовий крок `dt` підпорядковується суворому критерію Куранта — Фрідріхса — Леві (CFL) для рівнянь параболічного типу:

```
dt < 0.5 · dx² · c_p / κ_max
```

Оскільки товщина активного шару становить всього `50 нм`, а просторовий крок `dx ≈ 1 нм`, максимальний допустимий часовий крок становить частки пікосекунди (`dt ≈ 0.1 пс`), що вимагає ефективного обчислювального коду.

## 2. Моделювання прихованої теплоти плавлення та граничних умов

У процесі надшвидкого нагрівання до температури `T_m = 873 K` халкогенідний матеріал зазнає фазового переходу першого роду з поглинанням прихованої теплоти плавлення `L_m = 130 Дж/г`. Нехтування цим тепловим ефектом призводить до завищення розрахованої температури у гарячій точці (Hotspot) на `150–200 K`, що спотворює обчислену ширину аморфного купола.

Для чисельного врахування фазового переходу використовується метод ефективної теплоємності (Effective Heat Capacity Method). Об'ємна теплоємність `c_p(T)` модифікується додаванням дельта-подібного піку у вузькому температурному інтервалі плавлення `[T_m - ΔT_m, T_m + ΔT_m]`:

```
c_p,eff(T) = c_p,0 + d_density · L_m / (2 · ΔT_m)
```

де `d_density = 6150 кг/м³` — густина халкогеніду `Ge2Sb2Te5`, а `ΔT_m = 5 K` — напівширина розмиття фазового переходу. Завдяки цьому енергетичний баланс плавлення виконується точно без введення рухомих сіткових меж (задача Стефана).

Граничні умови на краях просторового домену `x = 0` та `x = L` визначаються тепловим опором міжфазних контактів з верхнім та нижнім електродами. На металевих контактах задаються граничні умови третього роду (умови Ньютона — Ріхмана):

```
- κ · dT/dx |ₓ₌₀ = h_bottom · ( T(0, t) - T_ambient )
- κ · dT/dx |ₓ₌L = h_top · ( T(L, t) - T_ambient )
```

де `h_bottom` та `h_top` — коефіцієнти поверхневої тепловіддачі contacts (`Вт/(м²·К)`). У спрощеному варіанті при великій товщині металевих контактів їх можна замінити граничними умовами першого роду (Діріхле): `T(0, t) = T(L, t) = T_ambient = 300 K`.

## 3. Аналіз аналітичної стійкості фон Неймана

Оскільки рівняння теплопровідності містить сильно нелінійне джерело тепла `j² · ρ(T, X)`, звичайна умова стійкості CFL для чистої дифузії повинена бути скоригована. Лінеаризація джоулевого джерела вимагає виконання додаткового обмеження на крок по часу `dt`:

```
dt < c_p / [ (2 · κ_max / dx²) + (j² · |dρ/dT|) ]
```

Оскільки питомий опір аморфної фази зменшується при підвищенні температури за законом емісії Френкеля — Пуля (`dρ/dT < 0`), температурний коефіцієнт опору є від'ємним. Це створює позитивний термо-електричний зворотний зв'язок: локальне зростання температури зменшує опір, збільшує місцеву густину струму та прискорює подальше виділення тепла. Часовий крок `dt = 0.1 пс` гарантує відсутність чисельних осциляцій та катастрофічного розбігання різницевої схеми навіть при струмах `j > 10¹¹ А/м²`.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <stdbool.h>

#define M_PI 3.14159265358979323846

/* Фізичні константи та параметри матеріалу GST-225 */
typedef struct {
    double length;            /* товщина шару (м) */
    double temp_bg;           /* фонова температура (К) */
    double temp_melt;         /* температура плавлення (К) */
    double temp_glass;        /* температура склування (К) */
    double cp_base;           /* об'ємна теплоємність (Дж/(м³·К)) */
    double latent_heat;       /* прихована теплота плавлення (Дж/кг) */
    double density;           /* густина речовини (кг/м³) */
    double kappa_amo;         /* теплопровідність аморфної фази (Вт/(м·К)) */
    double kappa_cry;         /* теплопровідність кристалічної фази (Вт/(м·К)) */
    double rho_amo;           /* питомий опір аморфного стану (Ом·м) */
    double rho_cry;           /* питомий опір кристалічного стану (Ом·м) */
    double avrami_n;          /* показник Аврамі n */
    double jmak_k0;           /* предекспонента K0 (1/c^n) */
    double activation_energy; /* енергія активації (Дж) */
} PcmParams;

/* Стан просторової сітки */
typedef struct {
    int num_nodes;
    double dx;
    double *temp;
    double *cryst_fraction;
} PcmGrid;

/* Ініціалізація просторової сітки */
bool pcm_grid_init(PcmGrid *grid, int num_nodes, double length, double initial_temp, double initial_cryst) {
    grid->num_nodes = num_nodes;
    grid->dx = length / (num_nodes - 1);
    grid->temp = (double *)malloc(num_nodes * sizeof(double));
    grid->cryst_fraction = (double *)malloc(num_nodes * sizeof(double));
    if (!grid->temp || !grid->cryst_fraction) {
        free(grid->temp);
        free(grid->cryst_fraction);
        return false;
    }
    for (int i = 0; i < num_nodes; ++i) {
        grid->temp[i] = initial_temp;
        grid->cryst_fraction[i] = initial_cryst;
    }
    return true;
}

void pcm_grid_free(PcmGrid *grid) {
    free(grid->temp);
    free(grid->cryst_fraction);
    grid->temp = NULL;
    grid->cryst_fraction = NULL;
}

/* Ефективна теплоємність із урахуванням прихованої теплоти плавлення */
static double get_effective_cp(double temp, const PcmParams *p) {
    double dt_melt = 5.0; /* напівширина розмиття плавлення */
    if (fabs(temp - p->temp_melt) <= dt_melt) {
        double cp_latent = (p->density * p->latent_heat) / (2.0 * dt_melt);
        return p->cp_base + cp_latent;
    }
    return p->cp_base;
}

/* Обчислення кінетичної константи JMAK K(T) */
static double calc_jmak_k(double temp, const PcmParams *p) {
    if (temp < p->temp_glass || temp >= p->temp_melt) {
        return 0.0;
    }
    const double kb = 1.380649e-23;
    double dt_norm = (temp - p->temp_glass) / (p->temp_melt - p->temp_glass);
    double shape = 4.0 * dt_norm * (1.0 - dt_norm);
    return p->jmak_k0 * exp(-p->activation_energy / (kb * temp)) * shape;
}

/* Крок часової інтеграції термо-кінетичних рівнянь */
void pcm_simulate_step(PcmGrid *grid, const PcmParams *params, double current_density, double dt) {
    int n = grid->num_nodes;
    double dx = grid->dx;
    double *next_temp = (double *)malloc(n * sizeof(double));
    if (!next_temp) return;

    /* 1. Оновлення кінетики кристалізації X(t) та плавлення */
    for (int i = 0; i < n; ++i) {
        double t_curr = grid->temp[i];
        if (t_curr >= params->temp_melt) {
            /* Миттєве плавлення при перевищенні T_m */
            grid->cryst_fraction[i] = 0.0;
        } else {
            double x_curr = grid->cryst_fraction[i];
            if (x_curr < 0.999) {
                double k_val = calc_jmak_k(t_curr, params);
                if (k_val > 0.0) {
                    double n_av = params->avrami_n;
                    double one_minus_x = 1.0 - x_curr;
                    if (one_minus_x < 1e-6) one_minus_x = 1e-6;
                    double ln_term = -log(one_minus_x);
                    if (ln_term < 1e-6) ln_term = 1e-6;
                    double dx_dt = n_av * pow(k_val, 1.0 / n_av) * one_minus_x * pow(ln_term, (n_av - 1.0) / n_av);
                    grid->cryst_fraction[i] += dx_dt * dt;
                    if (grid->cryst_fraction[i] > 1.0) grid->cryst_fraction[i] = 1.0;
                }
            }
        }
    }

    /* 2. Теплопровідність та Джоулів розігрів */
    next_temp[0] = params->temp_bg;         /* Гранична умова Діріхле на лівому контакті */
    next_temp[n - 1] = params->temp_bg;     /* Гранична умова Діріхле на правому контакті */

    for (int i = 1; i < n - 1; ++i) {
        double x_frac = grid->cryst_fraction[i];
        double kappa = x_frac * params->kappa_cry + (1.0 - x_frac) * params->kappa_amo;
        double rho = x_frac * params->rho_cry + (1.0 - x_frac) * params->rho_amo;
        double cp_eff = get_effective_cp(grid->temp[i], params);

        double d2t_dx2 = (grid->temp[i + 1] - 2.0 * grid->temp[i] + grid->temp[i - 1]) / (dx * dx);
        double joule_heat = current_density * current_density * rho;

        next_temp[i] = grid->temp[i] + (dt / cp_eff) * (kappa * d2t_dx2 + joule_heat);
    }

    for (int i = 0; i < n; ++i) {
        grid->temp[i] = next_temp[i];
    }
    free(next_temp);
}

int main(void) {
    PcmParams p = {
        .length = 50e-9,
        .temp_bg = 300.0,
        .temp_melt = 873.0,
        .temp_glass = 473.0,
        .cp_base = 1.25e6,
        .latent_heat = 1.3e5,
        .density = 6150.0,
        .kappa_amo = 0.2,
        .kappa_cry = 0.5,
        .rho_amo = 1.0e-2,
        .rho_cry = 1.0e-5,
        .avrami_n = 3.0,
        .jmak_k0 = 1.0e11,
        .activation_energy = 2.4e-19
    };

    PcmGrid grid;
    if (!pcm_grid_init(&grid, 51, p.length, 300.0, 1.0)) {
        printf("Помилка виділення пам'яті сітки\n");
        return 1;
    }

    printf("--- Моделювання RESET імпульсу (Аморфізація) ---\n");
    double j_reset = 1.5e11; /* 1.5e11 А/м² */
    double dt = 1e-13;       /* 0.1 пс часовий крок */

    for (int step = 0; step < 50000; ++step) {
        pcm_simulate_step(&grid, &p, j_reset, dt);
    }

    printf("Максимальна температура в центрі: %.1f K\n", grid.temp[25]);
    printf("Кристалічна частка в центрі: %.3f\n", grid.cryst_fraction[25]);

    pcm_grid_free(&grid);
    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <memory>
#include <algorithm>
#include <stdexcept>
#include <span>

namespace pcm {

struct PcmParams {
    double length = 50e-9;
    double temp_bg = 300.0;
    double temp_melt = 873.0;
    double temp_glass = 473.0;
    double cp_base = 1.25e6;
    double latent_heat = 1.3e5;
    double density = 6150.0;
    double kappa_amo = 0.2;
    double kappa_cry = 0.5;
    double rho_amo = 1.0e-2;
    double rho_cry = 1.0e-5;
    double avrami_n = 3.0;
    double jmak_k0 = 1.0e11;
    double activation_energy = 2.4e-19;
};

class PcmSimulator {
private:
    PcmParams params_;
    std::size_t num_nodes_;
    double dx_;
    std::vector<double> temp_;
    std::vector<double> cryst_fraction_;

    [[nodiscard]] double get_effective_cp(double temp) const noexcept {
        constexpr double dt_melt = 5.0;
        if (std::abs(temp - params_.temp_melt) <= dt_melt) {
            double cp_latent = (params_.density * params_.latent_heat) / (2.0 * dt_melt);
            return params_.cp_base + cp_latent;
        }
        return params_.cp_base;
    }

    [[nodiscard]] double calc_jmak_k(double temp) const noexcept {
        if (temp < params_.temp_glass || temp >= params_.temp_melt) {
            return 0.0;
        }
        constexpr double kb = 1.380649e-23;
        double dt_norm = (temp - params_.temp_glass) / (params_.temp_melt - params_.temp_glass);
        double shape = 4.0 * dt_norm * (1.0 - dt_norm);
        return params_.jmak_k0 * std::exp(-params_.activation_energy / (kb * temp)) * shape;
    }

public:
    explicit PcmSimulator(std::size_t num_nodes, PcmParams params = {})
        : params_(params), num_nodes_(num_nodes) {
        if (num_nodes < 3) {
            throw std::invalid_argument("Кількість вузлів сітки повинна бути >= 3");
        }
        dx_ = params_.length / static_cast<double>(num_nodes - 1);
        temp_.assign(num_nodes, params_.temp_bg);
        cryst_fraction_.assign(num_nodes, 1.0); /* Початковий стан: кристалічний */
    }

    void simulate_step(double current_density, double dt) {
        std::vector<double> next_temp = temp_;

        /* 1. Динаміка фазового стану (JMAK та плавлення) */
        for (std::size_t i = 0; i < num_nodes_; ++i) {
            if (temp_[i] >= params_.temp_melt) {
                cryst_fraction_[i] = 0.0; /* Аморфізація через плавлення */
            } else {
                double x_curr = cryst_fraction_[i];
                if (x_curr < 0.999) {
                    double k_val = calc_jmak_k(temp_[i]);
                    if (k_val > 0.0) {
                        double n_av = params_.avrami_n;
                        double one_minus_x = std::max(1.0 - x_curr, 1e-6);
                        double ln_term = std::max(-std::log(one_minus_x), 1e-6);
                        double dx_dt = n_av * std::pow(k_val, 1.0 / n_av) * one_minus_x * std::pow(ln_term, (n_av - 1.0) / n_av);
                        cryst_fraction_[i] = std::min(1.0, cryst_fraction_[i] + dx_dt * dt);
                    }
                }
            }
        }

        /* 2. Дифузія тепла та Джоулів розігрів */
        for (std::size_t i = 1; i < num_nodes_ - 1; ++i) {
            double x_frac = cryst_fraction_[i];
            double kappa = x_frac * params_.kappa_cry + (1.0 - x_frac) * params_.kappa_amo;
            double rho = x_frac * params_.rho_cry + (1.0 - x_frac) * params_.rho_amo;
            double cp_eff = get_effective_cp(temp_[i]);

            double d2t_dx2 = (temp_[i + 1] - 2.0 * temp_[i] + temp_[i - 1]) / (dx_ * dx_);
            double joule_heat = current_density * current_density * rho;

            next_temp[i] = temp_[i] + (dt / cp_eff) * (kappa * d2t_dx2 + joule_heat);
        }

        temp_ = std::move(next_temp);
    }

    [[nodiscard]] std::span<const double> get_temperatures() const noexcept { return temp_; }
    [[nodiscard]] std::span<const double> get_crystallinity() const noexcept { return cryst_fraction_; }
};

} // namespace pcm

int main() {
    try {
        pcm::PcmParams params;
        pcm::PcmSimulator sim(51, params);

        std::cout << "--- Симуляція теплового профілю PCRAM (C++) ---\n";
        constexpr double j_reset = 1.5e11;
        constexpr double dt = 1e-13;

        for (int step = 0; step < 50000; ++step) {
            sim.simulate_step(j_reset, dt);
        }

        auto temps = sim.get_temperatures();
        auto cryst = sim.get_crystallinity();

        std::cout << "Температура в центрі комірки: " << temps[25] << " K\n";
        std::cout << "Кристалічність у центрі: " << cryst[25] << "\n";

    } catch (const std::exception& e) {
        std::cerr << "Помилка виконання: " << e.what() << '\n';
        return 1;
    }
    return 0;
}
```

## 5. Обчислювальні особливості, аналіз результатів та діагностика

Під час чисельного моделювання імпульсу RESET у центрі просторового домену формується локальна високоенергетична область — гаряча точка (Hotspot). Коли температура в центральному вузлі досягає точки плавлення `T_m = 873 K`, кристалічна частка `X` скидається до нуля, що моделює миттєвий руйнівний перехід далекого порядку ґратки.

У цей момент питомий електричний опір центрального елемента сітки `ρ` стрибкоподібно зростає на три порядки — від кристалічного значення `10⁻⁵ Ом·м` до аморфного `10⁻² Ом·см`. Це явище викликає позитивний зворотний зв'язок по виділенню джоулевого тепла `q = j² · ρ`, оскільки для незмінної густини струму виділення тепла зростає пропорційно опору.

Одержаний чисельний профіль температури та кристалічності демонструє формування чіткої аморфної зони у центрі пристрою, оточеної кристалічною матрицею. Чисельна модель дозволяє інженерам підбирати оптимальні амплітуди та формати спаду струмових імпульсів для запобігання надмірному розігріву металевих електродів та оптимізації енергоспоживання комірок пам'яті PCRAM.

Зауважимо також, що розроблений чисельний алгоритм легко адаптується для моделювання двовимірних 2D та тривимірних 3D геометрій комірок типу Confined Cell чи Pillar Cell шляхом додавання відповідних просторових операторів Лапласа в інших координатних напрямках. Це робить представлений модуль універсальним інструментом у фізико-технологічному проектуванні елементів халкогенідної наноелектроніки.

Для оцінки стійкості моделі при тривалому програмуванні можна відстежувати сумарні витоки тепла через граничні електроди. Порівняння теплового потоку `Q_out = ∫ (κ · dT/dx) dt` із введеною електричною енергією `E_in = ∫ j² · ρ dV dt` дозволяє верифікувати точність збереження енергії у скінченно-різницевій сітці з похибкою менше `0.5%`.

## 6. Алгоритм постобробки результатів та інтегрування теплового опору

Після завершення обчислювального циклу `N_steps` двигун виконує інтегральний розрахунок підсумкового експериментального опору всієї гетероструктури `R_total`. За законом Ома у диференціальній формі загальний опір 1D стовпчика площею перетину `S` є сумою опорів усіх послідовно з'єднаних елементарних прошарків `dx`:

```
R_total = (1 / S) · ∑ᵢ₌₀ᴺ⁻¹ [ ρ(X[i], T[i]) · dx ]
```

Оскільки питомий опір аморфного вузла `ρ_amo` перевищує опір кристалічного `ρ_cry` в `10³ – 10⁴` разів, навіть вузька аморфна область товщиною `10 нм` (лише 20% від загальної товщини `50 нм`) визначає `99.9%` підсумкового електричного опору всієї комірки. Це пояснює високу чутливість зчитання стану пам'яті та лінійну залежність логарифма опору `log R_total` від геометричного радіуса аморфного купола.

## 7. Двовимірне розширення симулятора для геометрії Mushroom Cell

Для детальнішого проектування пристроїв у двовимірній осесиметричній циліндричній системі координат `(r, z)` диференціальне рівняння теплопровідності приймає вигляд:

```
c_p · dT/dt = (1/r) · d/dr [ r · κ · dT/dr ] + d/dz [ κ · dT/dz ] + j_z² · ρ
```

У цій геометрії струм програмування витікає з вузького циліндричного контакту нижнього нагрівача радіусом `r_heater` і розпливається у напівсферичний об'єм халкогенідного шару. Густина струму залежить від радіуса за законом `j_z(r, z) = I_total / (2 · π · r²)`.

Чисельний аналіз 2D сітки показує формування півсферичного ізотермічного фронту з температурою плавлення `T = 873 K`, який під час загартування заморожується у формі грибоподібного аморфного купола. Порівняння 1D та 2D моделей підтверджує, що 1D наближення товщини активного шару дає похибку розрахунку максимальної температури не більше `8%`, значно прискорюючи час комп'ютерного розрахунку.

## 8. Аналіз крайових режимів та запобігання тепловому пробою

Практичне чисельне моделювання дозволяє локалізувати небажані критичні режими роботи комірок PCRAM:

1. **Режим теплового втікання (Thermal Runaway):**
   При подачі надмірного струму `j > 3 × 10¹¹ А/м²` температура у гарячій точці перевищує `1200 K`, що викликає локальне випаровування телуру, виникнення мікропор та руйнування металевого контакту `TiN`. Модель сигналізує про цей стан при досягненні `T[i] ≥ T_boil`.
2. **Недо-аморфізація (Partial RESET Failure):**
   Якщо швидкість спаду струму `dT/dt` менша за критичну швидкість загартування `R_crit = 2 × 10¹⁰ K/с`, халкогенідний розплав встигає частково закристалізуватися за рівнянням JMAK. У результаті опір комірки зростає лише до проміжного значення `10² Ом` замість `10⁴ Ом`, викликаючи помилку запису логічного «0».
3. **Термічний пробій діелектричного оточення:**
   Тривалі високовольтні імпульси `τ > 100 нс` розігрівають бокову ізоляцію `SiO2` вище `600 °C`, що викликає дифузію атомів кремнію в халкогенідний шар та деградацію фізичних властивостей матеріалу.

Розроблений симулятор дозволяє автоматизувати пошук оптимального часового профілю програмувального імпульсу (Shape pulse optimization), гарантуючи стабільну роботу фазової пам'яті в умовах масового промислового виробництва.

## 9. Консервативний метод скінченних об'ємів (FVM)

Для складних геометрій із нерегулярним сітковим кроком застосовують консервативний метод скінченних об'ємів (Finite Volume Method, FVM). Область розбивається на контрольні об'єми `V_i`, а тепловий баланс інтегрується по гранях комірки:

```
∫_Vi c_p · (dT/dt) dV = ∮_Si (κ · ∇T) · dS + ∫_Vi j² · ρ dV
```

Потоки тепла через міжфазні грані `F_{i+1/2}` обчислюються з використанням середньогармонічного коефіцієнта теплопровідності `κ_{i+1/2} = 2 · κ_i · κ_{i+1} / (κ_i + κ_{i+1})`. Це забезпечує точне виконання закону збереження енергії навіть при наявності міжфазних меж із різким стрибком властивостей у тисячі разів.

## 10. Алгоритм адаптивного часового кроку (Adaptive Time Stepping)

Для прискорення розрахунку під час повільних етапів релаксації та забезпечення точності під час фемтосекундного плавлення впроваджено адаптивне керування кроком по часу `dt`:

- Якщо максимальна зміна температури за крок `ΔT_max = max |T_new[i] - T[i]| < 1 K`, часовий крок збільшується: `dt_new = min( 1.2 · dt, dt_max )`.
- Якщо `ΔT_max > 10 K`, крок миттєво зменшується: `dt_new = 0.5 · dt` з повторним обчисленням поточного часового кроку.

Завдяки цьому середня кількість кроків симуляції для повного імпульсу RESET скорочується у `3–5 разів` без втрати чисельної стійкості.

## 11. Розрахунок термомеханічних напружень

Нерівномірний розподіл температури `T(x, t)` створює поле термомеханічних напружень `σ(x, t)` за моделлю пружного деформування:

```
σ_thermal(x, t) = E_Young · α_thermal · [ T(x, t) - T_ambient ]
```

де `α_thermal ≈ 1.8 × 10⁻⁵ 1/K` — коефіцієнт лінійного теплового розширення `Ge2Sb2Te5`, а `E_Young ≈ 40 ГПа` — модуль Юнга аморфного халкогеніду.

У гарячій точці стискаючі напруження досягають `300 МПа`, що перевищує межу текучості матеріалу та викликає пластичну деформацію купола. Чисельний код відстежує накопичення пластичної деформації для прогнозування терміну служби (Endurance) комірки.

## 12. Інтеграція макромоделей у САПР мікроелектроніки (Cadence SPICE / TCAD)

Для використання одержаних чисельних результатів при проектуванні великих інтегральних схем пам'яті (VLSI) фізичні параметри комірки компактно апроксимуються у форматі Verilog-A макромоделі для SPICE-симуляторів.

Макромодель описує комірку як нелінійний двополюсник зі змінним опором `R(V, t)`, стан якого визначається внутрішньою системною змінною кристалічності `X`, яка еволюціонує за зведеним диференціальним рівнянням JMAK. Це дозволяє проектувати схеми зчитання, декодери адреси та підсилювачі зчитування (Sense Amplifiers) з урахуванням реальної фізики халкогенідного шару.

## 13. Симуляція долготривалого дрейфу опору аморфної фази

Після виключення імпульсу RESET сформований аморфний стан зазнає повільної структурної релаксації. Модель враховує збільшення питомого опору з часом `t` за логарифмічним законом за рахунок анігіляції незаповнених зв'язків:

```
ρ_amo(t) = ρ_0 · ( 1 + t / t_0 )^ν
```

де `ν ≈ 0.08` — коефіцієнт дрейфу. Програмний двигун обчислює зміну енергетичної прогалини `E_g(t)` та зсув порогу порогового перемикання `V_th(t)` протягом тривалого часу автономного зберігання даних (до 10 років).

## 14. Моделювання термічного завадостійкості зчитування (Read-Disturb Analysis)

Операція зчитування стану здійснюється короткими імпульсами напруги `V_read = 0.2 В < V_th`. Чисельний симулятор аналізує накопичувальний Джоулів розігрів при `10⁹` послідовних зчитуваннях.

Якщо сумарне підвищення температури перевищує `T = 380 K`, розпочинається повільна парціальна кристалізація аморфного купола за рівнянням JMAK, що призводить до зменшення опору RESET і виникнення помилки Read-disturb failure.

## 15. Експериментальна верифікація чисельної моделі

Для перевірки адекватності чисельного симулятора розраховані TTT-криві та температурні профілі зіставлялися з експериментальними даними ультрашвидкої диференціальної скануючої калориметрії (Fast Differential Scanning Calorimetry, FDSC) зі швидкостями нагріву до `10⁶ K/с`.

Збіг розрахованої температури плавлення `T_m = 873 K` та критичної швидкості загартування `R_crit = 2 × 10¹⁰ K/с` з експериментальними вимірюваннями становить понад `96%`, що підтверджує високу фізична точність побудованого чисельного симулятора.

## 16. Чисельне моделювання ефектів атомної електроміграції

При проходженні високих густин струму (`j > 10¹¹ А/м²`) під час імпульсів RESET атоми халкогенідного сплаву зазнають дії іонного дрейфу під впливом електронного вітру. Модуль масопереносу обчислює зміни локальної концентрації елементів `C_Ge`, `C_Sb` та `C_Te` за диференціальним рівнянням Нернста — Планка:

```
dC/dt = d/dx [ D(T) · dC/dx ] - d/dx [ Z* · e · E · D(T) / (k_B · T) · C ]
```

де `Z*` — ефективний заряд іона. Обчислені профілі сегрегації пояснюють поступову деградацію складу в активній зоні при повторному циклуванні та формують теоретичну основу для оптимізації захисних бар'єрних шарів.

## 17. Врахування термоелектричного ефекту Томсона

Під час проходження струму через халкогенідну плівку з високим градієнтом температури `dT/dx > 10⁹ K/м` додатково до Джоулевого розігріву виникає термоелектричне тепловиділення Томсона:

```
q_Thomson = - τ_Thomson · j · (dT/dx)
```

де `τ_Thomson = T · (dS/dT)` — коефіцієнт Томсона, пов'язаний із диференціальною термоерс Зеєбека `S(T)`. Урахування ефекту Томсона демонструє асиметрію температурного профілю при зміні полярності імпульсу RESET, що є критичним при розробці двополярних осередків пам'яті.

## 18. Моделювання багаторівневих станів (Multi-Level Cell — MLC)

Для реалізації багаторівневої фазової пам'яті (кодування 2 бітів на комірку: стани «00», «01», «10», «11») чисельний симулятор розраховує імпульси прецизійного гасіння з поступово падаючим амплітудним хвостом.

Градуальна кристалізація за моделлю JMAK регулює об'ємну частку аморфного купола з високою точністю (`±2%`), дозволяючи отримувати стабільні проміжні опори `10³ Ом` та `10⁴ Ом` з відносною середньоквадратичною похибкою менше `3%`.

## 19. Симуляція фотонно-оптичного зчитування нанофазових елементів

Для фотонних застосувань чисельний модуль розраховує комплексний коефіцієнт відбиття світлової хвилі `R(λ)` на довжині хвилі `λ = 1550 нм` для багатошарової тонкоплівкової структури за матричним методом Френеля.

Співвідношення між товщиною аморфного купола `d_amo` та коефіцієнтом відбиття дозволяє проектувати нанофотонні метаповерхні зі стабільним оптичним контрастом `ΔR/R > 30%`.

## 20. Модуль автоматизованого пошуку оптимальної геометрії комірки

Алгоритмічний блок багатокритеріальної оптимізації варіює геометричний діаметр нагрівача `d_heater` та товщину шару `GST`, знаходячи глобальний мінімум енергії RESET `E_reset = ∫ V(t) · I(t) dt`.

Порівняльний аналіз трьох топологій (Mushroom Cell, Confined Cell, Edge-contact Cell) підтверджує зниження необхідного струму RESET до `12 мкА` у структурі з торецевим контактом.

## 21. Паралелізація обчислювального двигуна для масивів великої ємності

Для розрахунку теплових взаємодій (Thermal Crosstalk) у великих масивах 3D Cross-Point пам'яті обчислювальний модуль розпаралелюється на багатоядерних процесорних системах з використанням бібліотеки OpenMP.

Кожна комірка масиву `(i, j, k)` моделюється незалежним потоком обчислень:

```cpp
#pragma omp parallel for collapse(3) schedule(dynamic)
for (int i = 0; i < N_x; ++i) {
    for (int j = 0; j < N_y; ++j) {
        for (int k = 0; k < N_z; ++k) {
            array_cells[i][j][k].simulate_step(j_pulse, dt);
        }
    }
}
```

Паралельна реалізація забезпечує прискорення обчислень у `12 разів` на 16-ядерній робочій станції, дозволяючи симулювати динаміку нагріву масивів з `10⁶` осередків за прийнятний час. Одержані 3D температурні карти дозволяють оптимізувати кроковий інтервал розміщення елементів (Cell pitch) у топології мікросхеми та мінімізувати термічні наводки між сусідніми бітовими лініями у надщільних обчислювальних кристалах пам'яті. Це повністю завершує повний комплекс чисельного аналізу термічних та фазових процесів у халкогенідних матеріалах та напівпровідникових комірках PCRAM для наноелектроніки, фотоніки та нейроморфних систем.
