# 📋 Електричний інтерфейс та мостова топологія GMR-сенсора

Інтегральний магнітометричний датчик на основі гігантського магнітоопору випускається у вигляді чотириплечого вимірювального моста Вітстона, сформованого на єдиному силіцієвому кристалі. Чотири спінові клапани поєднані у містову схему з метою компенсації температурного дрейфу опору, усунення синфазного сигналу живильної напруги та забезпечення лінійної вихідної характеристики при вимірюванні слабких магнітних полів від десятків мікротесл до десятків мілітесл.

Використання мостової структури дозволяє перетворити відносно малу зміну опору окремого елемента на високоточний диференціальний напруговий сигнал. Оскільки всі чотири плечі моста виготовляються в єдиному технологічному циклі напилення і розташовані на відстані кількох десятків мікрометрів один від одного, вони володіють ідентичними температурними параметрами. Це дозволяє пригнічувати температурний дрейф опору першого порядку та забезпечувати високу стабільність нульового рівня в широкому діапазоні температур.

## Специфікація електричних та магнітних параметрів

У таблиці нижче наведено узагальнені технічні характеристики промислового GMR-сенсора (серія NVE AA002, NXP KMZ51 та Infineon TLI4971) для прецизійного вимірювання магнітного поля та безконтактного вимірювання струму:

| Параметр | Символ | Типове значення | Одиниці | Умови вимірювання |
| :--- | :--- | :--- | :--- | :--- |
| **Номінальний опір моста** | `R_0` | `5.0 ± 1.0` | кОм | `T = 25 °C`, `H = 0` |
| **Максимальна напруга живлення** | `V_cc(max)` | `12.0` | В | Постійний струм або імпульс |
| **Рекомендована напруга живлення** | `V_cc` | `3.3 – 5.0` | В | Для мінімізації самонагріву |
| **Магніточутливість** | `S` | `3.0 – 4.2` | мВ / В / мТл | Лінійна ділянка кривої |
| **Діапазон вимірюваних полів** | `H_range` | `± 1.5 – ± 10.0` | мТл | Лінійний режим (`< 1%` нелінійності) |
| **Поле насичення** | `H_sat` | `15.0` | мТл | Опір перестає змінюватися |
| **Гістерезис вихідного сигналу** | `H_hyst` | `< 0.05` | мТл | У межах робочого діапазону |
| **Температурний коефіцієнт опору** | `TCR` | `+ 0.14` | % / °C | `T = -40 °C … +125 °C` |
| **Температурний коефіцієнт чутливості** | `TCS` | `- 0.10` | % / °C | Потребує компенсації |
| **Верхня межа частотного діапазону** | `f_cut` | `1.0` | МГц | Обмежена ємністю мікросхеми |
| **Напруга зміщення нуля (Offset)** | `V_off` | `± 2.0` | мВ / В | При `H = 0` |

### Детальний фізичний зміст базових параметрів

1. **Номінальний опір моста (`R_0`):** Задає базовий рівень енергоспоживання датчика. Значення `5 кОм` забезпечує оптимальний баланс між низьким струмом споживання (близько `1 мА` при живленні `5 В`) та низьким рівнем теплового шуму Джонсона-Найквіста. Використання вищих опорів (понад `50 кОм`) призвело б до зростання спектральної густини шуму напруги.
2. **Магніточутливість (`S`):** Нормована величина вихідного сигналу на один вольт живлення при прикладанні поля в один мілітесла. Значення `4 мВ/В/мТл` означає, що при живленні `5 В` та полі `1 мТл` диференціальна напруга моста становить `20 мВ`, що у десятки разів перевищує чутливість датчиків Холла.
3. **Температурні коефіцієнти (`TCR` та `TCS`):** Позитивний `TCR` пояснюється зростанням фононного розсіювання електронів провідності при нагріванні. Від'ємний `TCS` пов'язаний із температурним розмиванням фермієвського розподілу та зменшенням коефіцієнта спінової асиметрії `β` через теплові збудження магнонів. Для точних вимірювань вимагається застосування компенсаційних схематотехнічних рішень.

## Топологія моста Вітстона та просторове розміщення елементів

Для перетворення ізотропної зміни опору `ΔR(H)` на симетричний диференціальний сигнал використовується специфічна просторова геометрія розміщення елементів моста на кристалі. 

```
                       ┌──────────────┐
                       │   V_cc (1)   │
                       └──────┬───────┘
                              │
               ┌──────────────┴──────────────┐
               │                             │
        ┌──────┴──────┐               ┌──────┴──────┐
        │  R1 (GMR)   │               │  R2 (GMR*)  │
        │ Активне R+  │               │ Екрановане  │
        └──────┬──────┘               └──────┬──────┘
               │                             │
               ├──────────────┐              ├──────────────┐
               │              │              │              │
        ┌──────┴──────┐ ┌─────┴──────┐ ┌─────┴──────┐ ┌─────┴──────┐
        │  Out- (4)   │ │  R3 (GMR*) │ │  Out+ (2)  │ │  R4 (GMR)  │
        └─────────────┘ │ Екрановане │ └────────────┘ │ Активне R+ │
                        └─────┬──────┘                └─────┬──────┘
                              │                             │
                              └──────────────┬──────────────┘
                                             │
                                      ┌──────┴──────┐
                                      │   GND (3)   │
                                      └─────────────┘
```

У цій схемі плечі `R1` та `R4` є відкритими магніточутливими елементами, в яких опір зростає при дії зовнішнього поля уздовж вісі чутливості: `R1 = R4 = R_0 + ΔR(H)`. Плечі `R2` та `R3` є елементами, захищеними товстим екраном із ферумо-нікелевого сплаву (му-метал), який перенаправляє магнітні силові лінії в обхід резисторів: `R2 = R3 = R_0`.

В альтернативній конфігурації (диференціальний міст) плечі `R2` та `R3` виготовляють із протилежним напрямком обмінного зсуву за допомогою подвійного відпалу у локальному магнітному полі. У цьому випадку при дії зовнішнього поля опір `R1` та `R4` зростає, а опір `R2` та `R3` зменшується: `R2 = R3 = R_0 - ΔR(H)`, що подвоює вихідну чутливість мостової схеми.

### Контракт підключення корпусних виводів (SOIC-8 / DFN-6)

| Номер виводу | Назва виводу | Напрямок | Опис та електричні вимоги |
| :--- | :--- | :--- | :--- |
| **1** | `V_CC` | Вхід живлення | Позитивний полюс живлення (`+3.3V` або `+5.0V`). Потребує керамічного блокиратора `100 nF` біля виводу. |
| **2** | `OUT+` | Вихід сигналу | Позитивний диференціальний вихід моста. Підключається до неінвертуючого входу інструментального підсилювача. |
| **3** | `GND` | Спільний | Заземлення та спільна шина живлення (`0V`). |
| **4** | `OUT-` | Вихід сигналу | Негативний диференціальний вихід моста. Підключається до інвертуючого входу інструментального підсилювача. |
| **5** | `SET+` | Вхід імпульсу | Позитивний вихід вбудованої котушки відновлення намагніченості (Set/Reset strap). |
| **6** | `SET-` | Вхід імпульсу | Негативний вихід вбудованої котушки відновлення намагніченості. |
| **7, 8** | `NC` | Не використовується | Внутрішньо не підключені виводи. |

## Математична модель вихідного сигналу та компенсація дрейфу

Диференціальна напруга між виводами `OUT+` та `OUT-` обчислюється за класичним формульним виразом для збалансованого моста:

```
V_out = V_(OUT+) - V_(OUT-)

V_(OUT+) = V_cc · [ R4 / (R2 + R4) ]
V_(OUT-) = V_cc · [ R3 / (R1 + R3) ]

V_out = V_cc · [ (R_0 + ΔR)/(2·R_0) - (R_0 - ΔR)/(2·R_0) ]
      = V_cc · [ (2·ΔR) / (2·R_0) ]
      = V_cc · [ ΔR(H) / R_0 ]
```

З урахуванням коефіцієнта чутливості `S` та температурної залежності виражаємо підсумкову вихідну напругу:

```
V_out(H, T) = V_cc · [ S · (1 + TCS·(T - 25)) · H + V_off/V_cc ]
```

тут `H` — проєкція зовнішнього магнітного поля на вісь чутливості датчика (у мілітеслах), `T` — температура навколишнього середовища (у °C).

Для компенсації температурного зсуву чутливості `TCS` застосовують схему живлення моста фіксованим струмом `I_cc` замість фіксованої напруги `V_cc`. Оскільки опір моста `R_0` зростає з температурою з коефіцієнтом `TCR = +0.14%/°C`, напруга на мості `V_cc(T) = I_cc · R_0(T)` самостійно збільшується при нагріванні. Оскільки `TCR` за модулем є трохи більшим за `TCS` (`-0.10%/°C`), напругове зростання живлення практично повністю нейтралізує температурний спад чутливості `S(T)`.

## Схема первинного підсилення та аналогового узгодження

Оскільки диференціальний вихідний сигнал моста при малих полях вимірюється у мілівольтах, для його оцифрування аналогово-цифровим перетворювачем (АЦП) вимагається використання високоточного інструментального підсилювача з високим коефіцієнтом пригнічення синфазного сигналу (CMRR > 100 дБ, наприклад AD8221, INA333 або MCP6N11).

```
                  ┌──────────────────────────────────────────────┐
                  │                 GMR SENSOR                   │
                  │                                              │
                  │   V_CC ───┐                                  │
                  │           │                                  │
                  │        ┌──┴──┐                               │
                  │        │  R  │                               │
                  │        └──┬──┘                               │
                  │           ├────────────── OUT+ (2) ──────┐   │
                  │        ┌──┴──┐                           │   │
                  │        │  R  │                           │   │
                  │        └──┬──┘                           │   │
                  │           │                              │   │
                  │          GND                             │   │
                  └──────────────────────────────────────────┼───┘
                                                             │
                                                             ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        ІНСТРУМЕНТАЛЬНИЙ ПІДСИЛЮВАЧ                     │
│                                                                        │
│   OUT+ ────────► ┌──────────┐                                          │
│                  │ IN+      │                                          │
│                  │          │     R_G                                  │
│                  │  AD8221  ├──────▒▒▒──────┐                          │
│                  │          │               │                          │
│   OUT- ────────► ┌──────────┤               │                          │
│                  │ IN-      │               ▼                          │
│                  └────┬─────┘          ┌─────────┐   V_ADC             │
│                       │                │ OUT     ├───► До входу АЦП    │
│                      REF               └─────────┘   (0.1 – 3.3 В)     │
│                       │                                                │
│                       ▼                                                │
│                     +1.65 В (V_cc / 2 для однополярного АЦП)           │
└────────────────────────────────────────────────────────────────────────┘
```

1. **Коефіцієнт підсилення (Gain):** Задається зовнішнім прецизійним резистором `R_G`: `G = 1 + (49.4 кОм / R_G)`. При `R_G = 499 Ом` коефіцієнт підсилення становить `G = 100`. Це масштабує діапазон сигналів `± 15 мВ` у комфортний для АЦП діапазон `± 1.5 В`.
2. **Зсув опорного рівня (Reference Voltage):** Вивід `REF` підсилювача підключається до прецизійного джерела опорної напруги `V_ref = V_cc / 2 = 1.65 В`. Це дозволяє вимірювати як позитивні, так і негативні магнітні поля при використанні однополярного живлення АЦП (`0 – 3.3 В`).
3. **Диференціальна та синфазна фільтрація:** На входах підсилювача встановлюється симетричний RC-фільтр низьких частот (конденсатори між входами та на землю) з частотою зрізу близько `10–50 кГц` для пригнічення високочастотних радіозавад, імпульсних наведень та шуму перемикання імпульсних джерел живлення.

## Процедура скидання гістерезису та усунення зміщення (Set/Reset Pulse)

Незважаючи на низьку коерцитивну силу вільного шару (`H_c < 0.5` мТл), сильні випадкові магнітні завади (`H > 50` мТл) можуть порушити монодоменну структуру вільного шару, утворивши локальні магнітні домени з розсіяною орієнтацією. Це викликає залишковий гістерезисний зсув точки нуля (зміщення нульової напруги на кілька мілівольт), що призводить до похибки вимірювання.

Для відновлення заводського калібрування та усунення гістерезису мікросхема оснащена вбудованою плоскою спіральною котушкою або струмовою шиною `SET+/SET-`, розміщеною безпосередньо над резисторами моста.

```
Схема генерації імпульсу відновлення (Set/Reset circuit):

 +5V ───┬───────────────┐
        │               │
       ┌┴┐             ┌┴┐
       │ │ R_charge    │ │ R_charge
       └┬┘             └┬┘
        │               │
        ├───────┐       ├───────┐
       ─── C1   │      ─── C2   │
       ─── 4.7u │      ─── 4.7u │
        │       ▼       │       ▼
       GND    ┌───┐    GND    ┌───┐
              │FET│           │FET│
              └─┬─┘           └─┬─┘
                │               │
                ▼               ▼
              SET+ ───▒▒▒▒▒─── SET-
                    Котушка
```

### Алгоритм виконання процедури відновлення

1. **Генерація позитивного імпульсу (SET):**
   Використовуючи H-міст або конденсаторний розрядник, через шину `SET` пропускають короткий струмовий імпульс тривалістю `1.0–2.0` мікросекунди та амплітудою `1.0–1.5` А. Імпульс створює потужне локальне магнітне поле (`H_set > 20` мТл), яке перемагнічує вільний шар до повного насичення уздовж осі легкого намагнічування, відновлюючи монодоменну структуру.

2. **Вимірювання вихідної напруги `V_SET`:**
   Мікроконтролер оцифровує вихідну напругу підсилювача після позитивного імпульсу: `V_SET = V_off + V_signal`.

3. **Генерація негативного імпульсу (RESET):**
   Через шину `SET` пропускають імпульс протилежної полярності, який розвертає намагніченість вільного шару на 180°.

4. **Вимірювання вихідної напруги `V_RESET`:**
   Мікроконтролер оцифровує вихідну напругу після негативного імпульсу: `V_RESET = V_off - V_signal`.

5. **Обчислення точного сигналу без похибки зміщення:**
   Корисний магнітний сигнал обчислюється як піврізниця двох вимірювань, що повністю виключає постійну складову напруги зміщення `V_off` та її температурний дрейф:

```
V_signal = (V_SET - V_RESET) / 2
V_offset = (V_SET + V_RESET) / 2
```

Такий підхід дозволяє досягти стабільності точки нуля на рівні `0.01 мТл` у широкому діапазоні робочих температур від `-40 °C` до `+125 °C`.

## Монтажні вимоги та компенсація паразитичних полів

При конструюванні друкованих плат із GMR-сенсорами необхідно дотримуватися суворих конструктивних правил для запобігання викривленню магнітного поля:

- **Заборона феромагнітних матеріалів:** У радіусі `15–20 мм` довкола сенсора заборонено розміщувати компоненти із вмістом заліза, нікелю або кобальту (наприклад, сталеві гвинти, феритні індуктивності, нікельовані роз'єми або стійки). Намагнічення цих елементів спотворює локальні силові лінії.
- **Орієнтація щодо високострумових провідників:** Сильнострумові шини живлення та провідники імпульсних перетворювачів генерують магнітні поля Біоте-Савара (`H = I / (2·π·r)`). Провідники мають розводитися перпендикулярно до осі чутливості датчика або на достатній відстані (`> 30 мм`).
- **Екранування від зовнішніх завад:** Для захисту від промислових магнітних полів частоти 50 Гц застосовують зовнішні екрани з пермалою або му-металу з прорізом уздовж вимірювальної осі.
- **Захист від статичної електрики (ESD):** Оскільки товщина немагнітної проміжки Cu становить лише `2 нм`, високовольтні імпульси статичної електрики можуть викликати локальний електричний пробій та зварювання металевих шарів. Сенсори вимагають стандартного захисту ESD (TVS-діоди на лініях живлення та виходах).
