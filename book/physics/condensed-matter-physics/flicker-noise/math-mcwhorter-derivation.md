# 🧮 Математичне виведення спектра 1/f

Ця вставка містить строге та послідовне математичне виведення спектральної щільності потужності фліккер-шуму `1/f` у конденсованих середовищах. Документ охоплює кінетичні рівняння балансу двопозиційного випадкового телеграфного сигналу (RTS), теорему Вінера — Хінчина для експоненціальної автокореляції, інтегрування за безперервним логарифмічно-рівномірним розподілом часів релаксації, крайові асимптотичні розклади рядів, квантовомеханічний ВКБ-розрахунок тунелювання МакВортера в оксидні пастки, термодинамічну теорію Дутти — Хорна для температурно-залежних нахилів спектра, нелінійну модель Лісона для фазового шуму `1/f³` у генераторах, математичне доведення пригнічення шуму через корельовану подвійну вибірку (CDS), виведення біспектрального критерію неґауссівськості, аналіз асиметрії та ексцесу RTS-пасток, а також спін-граткову релаксацію Орбаха з оптичною діагностикою спінового шуму в атомарних парах.

## 1. Кінетика двопозиційного сигналу та виведення лоренціана

Розглянемо локалізований дефект або квантову пастку в напівпровідниковій структурі, яка взаємодіє з носіями заряду провідного каналу. Пастка може перебувати лише у двох дискретних станах:
- Стан `0`: пастка вільна (нейтральна);
- Стан `1`: пастка захопила один електрон (заряджена).

Позначимо через `w_10 = 1 / τ_off` ймовірність захоплення електрона у смузі часу (частоту переходів `0 → 1`), а через `w_01 = 1 / τ_on` — ймовірність його вивільнення назад у зону провідності (частоту переходів `1 → 0`). Тимчасові інтервали перебування у станах є незалежними випадковими величинами з пуассонівським розподілом.

Кінетичні рівняння балансу для ймовірностей виявлення системи у стані `0` (`P_0(t)`) та стані `1` (`P_1(t)`) мають вигляд:

```
dP_1(t) / dt = -(1 / τ_on) · P_1(t) + (1 / τ_off) · P_0(t)      [диференціальне рівняння балансу]
P_0(t) + P_1(t) = 1                                              [умова нормування ймовірностей]
```

Підставляючи `P_0(t) = 1 - P_1(t)`, приводимо кінетичне рівняння до лінійного неоднорідного рівняння першого порядку:

```
dP_1(t) / dt + (1 / τ_on + 1 / τ_off) · P_1(t) = 1 / τ_off      [приведене кінетичне рівняння]
```

Введемо ефективний час релаксації двопозиційної системи `τ`:

```
1 / τ = 1 / τ_on + 1 / τ_off = (τ_on + τ_off) / (τ_on · τ_off)  [ефективна частота релаксації]
```

Стаціонарне рішення для рівноважних ймовірностей у межі `t → ∞` дорівнює:

```
P_1_eq = τ / τ_off = τ_on / (τ_on + τ_off)                      [рівноважна ймовірність стану 1]
P_0_eq = τ / τ_on = τ_off / (τ_on + τ_off)                      [рівноважна ймовірність стану 0]
```

Загальне рішення для умовної ймовірності знаходження системи у стані `1` у момент `t` за умови, що в момент `t = 0` вона перебувала у стані `1`, має вигляд:

```
P(1, t | 1, 0) = P_1_eq + (1 - P_1_eq) · exp(-t / τ)             [умовна ймовірність переходів]
```

Нехай захоплення електрона викликає дискретну зміну струму каналу на величину `ΔI`. Автокореляційна функція флуктуацій струму `δI(t) = I(t) - <I>` визначається як:

```
R(t) = <δI(t₀) · δI(t₀ + t)> = (ΔI)² · P_1_eq · (1 - P_1_eq) · exp(-|t| / τ)   [автокореляційна функція]
```

Визначаючи амплітуду флуктуації як `A² = (ΔI)² · P_1_eq · (1 - P_1_eq)`, запишемо автокореляцію у найпростішій формі:

```
R(t) = A² · exp(-|t| / τ)                                       [спрощений вигляд автокореляції]
```

Згідно з теоремою Вінера — Хінчина, спектральна щільність потужності (СЩП) є фур'є-перетворенням автокореляційної функції:

```
S_i(f) = 4 · ∫₀^∞ R(t) · cos(2π · f · t) dt                      [теорема Вінера — Хінчина]
```

Виконаємо подвійне інтегрування за частинами для обчислення інтеграла:

```
∫₀^∞ exp(-t / τ) · cos(2π f t) dt
= [ exp(-t / τ) · (sin(2π f t) / (2π f)) ]₀^∞ + (1 / (2π f τ)) · ∫₀^∞ exp(-t / τ) · sin(2π f t) dt   [крок 1]
= 0 + (1 / (2π f τ)) · [ -exp(-t / τ) · (cos(2π f t) / (2π f)) ]₀^∞ - (1 / (2π f τ)²) · ∫₀^∞ exp(-t / τ) · cos(2π f t) dt [крок 2]
= (1 / (2π f)² τ) - (1 / (2π f τ)²) · ∫₀^∞ exp(-t / τ) · cos(2π f t) dt [підстановка меж]
```

Переносячи шуканий інтеграл у ліву частину та виводячи спільний множник, маємо:

```
∫₀^∞ exp(-t / τ) · cos(2π f t) dt · [ 1 + 1 / (2π f τ)² ] = 1 / ((2π f)² · τ)   [алгебраїчне спрощення]
∫₀^∞ exp(-t / τ) · cos(2π f t) dt = τ / (1 + (2π · f · τ)²)                      [підсумковий інтеграл]
```

Помноживши отриманий результат на `4 A²`, маємо точну формулу для спектральної щільності Лоренца (лоренціана):

```
S_i(f) = 4 · A² · τ / (1 + (2π · f · τ)²)                       [спектральна щільність Лоренца]
```

Аналіз меж лоренціана:
- Для низьких частот (`f << 1 / (2π τ)`): `S_i(f) ≈ 4 A² τ = const` (пласке плато);
- Для високих частот (`f >> 1 / (2π τ)`): `S_i(f) ≈ 4 A² / ((2π f)² τ) ~ 1 / f²` (асимптотичний спад зі схилом -2).

## 2. Математичне виведення сумарного спектра 1/f та асимптотичні розклади

Розглянемо масив із великої кількості незалежних пасток, кожна з яких характеризується власним часом релаксації `τ`. Нехай функція щільності ймовірності часів релаксації дорівнює `P(τ)` на інтервалі `[τ_min, τ_max]`.

Сумарна спектральна щільність потужності шуму визначається інтегральною суперпозицією:

```
S(f) = ∫_{τ_min}^{τ_max} P(τ) · [ 4 · A² · τ / (1 + (2π · f · τ)²) ] dτ          [суперпозиція лоренціанів]
```

Припустимо, що розподіл часів є логарифмічно-рівномірним, тобто:

```
P(τ) = C / τ                                                    [логарифмічно-рівномірний розподіл]
```

Знайдемо нормувальний коефіцієнт `C` з умови нормування повного об'єму ймовірностей на одиницю:

```
∫_{τ_min}^{τ_max} P(τ) dτ = C · ∫_{τ_min}^{τ_max} (1 / τ) dτ = C · [ ln(τ_max) - ln(τ_min) ] = 1   [нормування]
C = 1 / ln(τ_max / τ_min)                                       [нормувальна константа C]
```

Підставляючи `P(τ) = C / τ` в інтеграл для СЩП, спостерігаємо скорочення часу `τ` у чисельнику:

```
S(f)
= ∫_{τ_min}^{τ_max} (C / τ) · [ 4 A² τ / (1 + (2π f τ)²) ] dτ
= 4 · A² · C · ∫_{τ_min}^{τ_max} [ 1 / (1 + (2π f τ)²) ] dτ      [скорочення змінного часу]
```

Виконаємо заміни змінної: `u = 2π · f · τ`, при цьому `dτ = du / (2π f)`:

```
S(f)
= (4 · A² · C / (2π · f)) · ∫_{2π f τ_min}^{2π f τ_max} [ 1 / (1 + u²) ] du       [заміна змінної u]
= (4 · A² · C / (2π · f)) · [ arctan(2π f τ_max) - arctan(2π f τ_min) ]           [первісна арктангенса]
```

Для аналізу відхилень від чистого спектра `1/f` на краях діапазону виконаємо асимптотичні розклади рядів Тейлора для функції арктангенса:
- Для малих аргументів (`y << 1`): `arctan(y) = y - y³ / 3 + y⁵ / 5 - …`
- Для великих аргументів (`y >> 1`): `arctan(y) = π / 2 - 1 / y + 1 / (3 y³) - …`

Застосуємо ці розклади до межевих аргументів `u_max = 2π f τ_max` та `u_min = 2π f τ_min`:

```
arctan(2π f τ_max) ≈ π / 2 - 1 / (2π f τ_max) + 1 / (3 (2π f τ_max)³) [розклад верхньої межі]
arctan(2π f τ_min) ≈ 2π f τ_min - (2π f τ_min)³ / 3                   [розклад нижньої межі]
```

Підставляючи розклади у вираз для СЩП, отримуємо уточнений математичний вираз для `S(f)` із крайовими поправками:

```
S(f) = ( A² / ln(τ_max / τ_min) ) · (1 / f) · [ 1 - (2 / π) · ( 1 / (2π f τ_max) + 2π f τ_min ) ]  [СЩП з крайовими поправками]
```

Цей розклад строго показує:
1. У глибокому інтервалі `1 / (2π τ_max) << f << 1 / (2π τ_min)` крайові поправки прямують до нуля, залишаючи чистий спектр `S(f) ~ 1/f`.
2. На низьких частотах поблизу `f ≈ 1 / (2π τ_max)` спектр починає відхилятися вниз від прямої `1/f`, плавно переходячи у константне плато.
3. На високих частотах поблизу `f ≈ 1 / (2π τ_min)` спектр починає спадати швидше, переходячи у квадратичну асимптоту `1/f²`.

Знайдемо повну дисперсію флуктуацій струму `σ²` шляхом інтегрування СЩП у смузі вимірювання від `f_min` до `f_max`:

```
σ² = ∫_{f_min}^{f_max} S(f) df = ( A² / ln(τ_max / τ_min) ) · ∫_{f_min}^{f_max} (1 / f) df
σ² = ( A² / ln(τ_max / τ_min) ) · ln(f_max / f_min)               [повна дисперсія флуктуацій]
```

Як видно з виразу, повна шумова потужність логарифмічно залежить від відношення крайніх частот вимірювання `f_max / f_min`.

## 3. Квантовомеханічна теорія тунелювання МакВортера

Обґрунтуємо походження розподілу `P(τ) ~ 1/τ` на основі хвильової механіки квантового тунелювання електронів крізь потенціальний бар'єр диелектрика `SiO₂` у МОН-структурі.

Згідно з квазікласичним наближенням Вентцеля — Крамерса — Бріллюена (ВКБ), ймовірність проходження електрона крізь прямокутний потенціальний бар'єр висотою `U₀` на відстань `x` углиб оксиду спадає за експоненціальним законом:

```
P_tunnel(x) = exp( -2 · ∫₀^x κ(x') dx' ) = exp(-2 · κ · x)         [ВКБ-коефіцієнт прозорості]
```

де `κ` — коефіцієнт згасання огинаючої хвильової функції електрона під бар'єром:

```
κ = √( 2 · m* · (U₀ - E_k) ) / ℏ                                 [коефіцієнт згасання]
```

тут `m*` — ефективна маса електрона в оксиді, `E_k` — його кінетична енергія, `ℏ` — зведена константа Планка.

Час релаксації пастки `τ(x)` обернено пропорційний ймовірності тунелювання:

```
τ(x) = τ₀ · exp(2 · κ · x)                                       [час релаксації пастки на глибині x]
```

де `τ₀` — характерний час атомарних коливань на межі розділу `Si/SiO₂` (`~ 10⁻¹⁰…10⁻¹² s`).

Прологарифмуємо отриманий вираз і виразимо глибину залягання пастки `x`:

```
ln(τ / τ₀) = 2 · κ · x  ⇒  x(τ) = (1 / (2 · κ)) · ln(τ / τ₀)       [залежність глибини від часу]
```

Знайдемо модуль похідної `dx / dτ`:

```
dx / dτ = 1 / (2 · κ · τ)                                        [обернена похідна]
```

Нехай просторовий розподіл пасток по глибині оксидного шару є просторово однорідним: `P_x(x) = N_t = const` (де `N_t` — об'ємна щільність пасток). За теоремою про перетворення щільності ймовірностей випадкової величини маємо:

```
P_τ(τ) = P_x(x(τ)) · | dx / dτ | = N_t / (2 · κ · τ)              [виведення розподілу 1/τ за МакВортером]
```

Оскільки коефіцієнти `N_t` та `κ` є сталими величиною, отримуємо суворе виведення закону:

```
P_τ(τ) = C_m / τ                                                [закон 1/τ МакВортера]
```

де `C_m = N_t / (2 κ)`.

Обчислимо часовий діапазон релаксаторів для оксидного шару товщиною `d = 3 nm` при `κ = 10⁸ cm⁻¹` та `τ₀ = 10⁻¹¹ s`:
- Для пастки на межі (`x = 0`): `τ_min = τ₀ = 10⁻¹¹ s`;
- Для пастки у глибині (`x = 3 nm = 3 · 10⁻⁷ cm`):
  `τ_max = 10⁻¹¹ · exp(2 · 10⁸ · 3 · 10⁻⁷) = 10⁻¹¹ · exp(60) ≈ 10⁻¹¹ · 1.14 · 10²⁶ ≈ 1.14 · 10¹⁵ s ≈ 36 млн років!`

Це обчислення показує дивовижну силу експоненціального тунельного ефекту: зміна глибини залягання пастки на лічені нанометри розширює діапазон часів релаксації на 26 порядків, гарантуючи виконання закону `1/f` у будь-яких мислимих вимірювальних експериментах.

Додатково врахуємо зв'язок між захопленням заряду та флуктуацією рухливості електронів (модель CNMF). Захоплений електрон створює кулонівський центр розсіювання, що зменшує локальну рухливість електронів у каналі:

```
μ(N_t) = μ₀ / (1 + α_sc · N_t) ≈ μ₀ · (1 - α_sc · N_t)           [вплив заряду пастки на рухливість]
```

де `α_sc` — коефіцієнт кулонівського розсіювання. Враховуючи флуктуації як кількості `δN_t`, так і рухливості `δμ`, сумарна флуктуація струму збільшується в `(1 + α_sc · μ₀ · C_ox · V_g)` разів, зберігаючи при цьому спектральну форму `1/f`.

## 4. Термодинамічна модель Дутти — Хорна та нелінійне диференціювання за температурою

У металевих провідниках флуктуації викликаються атомарними перескоками дефектів кристалічної ґратки між двома конфігураціями з енергією активації `E`. Згідно з термодинамічним законом Арреніуса, час релаксації дорівнює:

```
τ(E, T) = τ₀ · exp( E / (k_B · T) )                              [закон Арреніуса]
```

де `k_B` — константа Больцмана, `T` — температура.

Виразиємо енергію активації `E` через час `τ`:

```
E(τ, T) = k_B · T · ln(τ / τ₀)                                   [енергія активації через час]
dE = (k_B · T / τ) dτ                                           [диференціал енергії]
```

Нехай енергії активації дефектів мають безперервну функцію розподілу `D(E)`. Знайдемо відповідний розподіл часів релаксації:

```
P_τ(τ) = D(E(τ)) · | dE / dτ | = (k_B · T / τ) · D( k_B T ln(τ / τ₀) ) [розподіл часів через D(E)]
```

Підставляючи `P_τ(τ)` у вираз суперпозиції лоренціанів, маємо:

```
S(T, f) = ∫₀^∞ [ (k_B T / τ) · D(E(τ)) ] · [ 4 A² τ / (1 + (2π f τ)²) ] dτ       [СЩП у моделі Дутти — Хорна]
```

Оскільки лоренціан `4 A² / (1 + (2π f τ)²) ` поводиться як дельта-подібне вікно з максимумом на частоті `f = 1 / (2π τ)`, винесемо повільно змінювану функцію `D(E)` з-під знака інтеграла при значеннях енергії `E_f`:

```
E_f = -k_B · T · ln(2π · f · τ₀)                                 [активна енергія дефектів на частоті f]
```

Після інтегрування залишкової частини отримуємо апроксимацію спектральної щільності:

```
S(T, f) ≈ ( π · A² · k_B · T / f ) · D( E_f )                     [спектральна щільність за Дуттою — Хорном]
```

Прологарифмуємо отримане співвідношення для виведення спектрального нахилу `α(T, f) = - ∂ ln S / ∂ ln f`:

```
ln S(T, f) = ln(π A² k_B T) - ln f + ln D( E_f )                  [логарифм СЩП]
```

Враховуючи, що `∂ E_f / ∂ ln f = -k_B T`, маємо:

```
α(T, f) = - ∂ ln S / ∂ ln f = 1 - (∂ ln D(E_f) / ∂ E_f) · (∂ E_f / ∂ ln f)
α(T, f) = 1 + k_B · T · ( ∂ ln D(E_f) / ∂ E_f )                   [нахил спектра через похідну D(E)]
```

Тепер обчислимо температурну похідну логарифма СЩП `∂ ln S(T, f) / ∂ ln T`:

```
∂ ln S(T, f) / ∂ ln T = T · (∂ ln S / ∂ T) = 1 + T · (∂ ln D(E_f) / ∂ E_f) · (∂ E_f / ∂ T)   [температурна похідна]
```

Оскільки `∂ E_f / ∂ T = -k_B · ln(2π f τ₀) = E_f / T`, підставляємо її в похідну:

```
∂ ln S(T, f) / ∂ ln T = 1 - k_B · T · ln(2π f τ₀) · ( ∂ ln D(E_f) / ∂ E_f )    [диференціювання за температурою]
```

Виразиємо `k_B T (∂ ln D / ∂ E_f)` з отриманого рівняння:

```
k_B · T · ( ∂ ln D(E_f) / ∂ E_f ) = - ( (∂ ln S(T, f) / ∂ ln T) - 1 ) / ln(2π f τ₀)  [вираження похідної D(E)]
```

Підставляючи це значення у вираз для спектрального нахилу `α(T, f)`, отримуємо відоме співвідношення Дутти — Хорна:

```
α(T, f) = 1 - ( 1 / ln(1 / (2π · f · τ₀)) ) · ( ( ∂ ln S(T, f) / ∂ ln T ) - 1 )  [рівняння Дутти — Хорна]
```

Це рівняння строго пов'язує нахил спектра шуму `α` з його температурним коефіцієнтом, дозволяючи проводити точну спектроскопію атомарних дефектів у провідниках.

## 5. Виведення фазового шуму 1/f³ у генераторах (модель Лісона)

У радіочастотних генераторах (LC-колі, квантових та кварцових резонаторах) низькочастотний фліккер-шум транзисторів `1/f` взаємодіє з нелінійністю активного елемента, перетворюючись на низькочастотну амплітудну та фазову модуляцію несучого сигналу частотою `f₀`.

Розглянемо передавальне рівняння резонансного контуру з добротністю `Q`. Вихідний фазовий шум `L(Δf)` на відлаштуванні `Δf` від несучої частоти `f₀` визначається моделлю Дем'єна Лісона (D. B. Leeson):

```
L(Δf) = 10 · lg[ 1/2 · ( 1 + (f₀ / (2 · Q · Δf))² ) · ( 1 + f_c / Δf ) · (F · k_B · T / P_s) ]  [рівняння Лісона]
```

де `f_c` — кутова частота фліккер-шуму активного транзистора, `F` — коефіцієнт шуму підсилювача, `P_s` — потужність сигналу генератора.

Розкриємо дужки для аналізу частотних залежностей поблизу несучої частоти у зоні `Δf << f₀ / (2 Q)`:

```
( 1 + (f₀ / (2 Q Δf))² ) · ( 1 + f_c / Δf ) ≈ (f₀ / (2 Q Δf))² · ( 1 + f_c / Δf ) [наближення близького відлаштування]
= (f₀ / (2 Q Δf))² + (f₀² · f_c) / (4 · Q² · Δf³)                                [розподіл членів]
```

Отриманий вираз показує виникнення двох виразних спектральних областей фазового шуму:
1. **Область білого фазового шуму `1/f²` (`Δf > f_c`):**
   ```
   L_white(Δf) = (F · k_B · T / (2 · P_s)) · (f₀ / (2 · Q · Δf))² ~ 1 / Δf²       [фазовий шум 1/f²]
   ```
2. **Область фліккерного фазового шуму `1/f³` (`Δf < f_c`):**
   ```
   L_flicker(Δf) = (F · k_B · T / (2 · P_s)) · (f₀² · f_c) / (4 · Q² · Δf³) ~ 1 / Δf³ [фазовий шум 1/f³]
   ```

Математичне виведення Лісона пояснює, чому фліккер-шум `1/f` перетворюється на крутий спад фазових флуктуацій `1/Δf³` (схил -30 dB/декаду) безпосередньо біля несучої частоти радіопередавачів.

## 6. Математична теорія пригнічення шуму за допомогою CDS

Корельована подвійна вибірка (Correlated Double Sampling — CDS) є математичним методом усунення низькочастотного фліккер-шуму та дрейфу нуля в КМОН-сенсорах та аналогових інтеграторах.

Нехай вхідний сигнал шуму `x(t)` вимірюється у два моменти часу, розділені часовим інтервалом `T_s` (інтервал вибірки):
- Перший відлік (напруга скидання): `V_1 = x(t)`;
- Другий відлік (напруга сигналу з шумом): `V_2 = x(t + T_s)`.

Результатом CDS є різниця двох відліків:

```
y(t) = x(t + T_s) - x(t)                                        [різницевий сигнал CDS]
```

Знайдемо імпульсну перехідну характеристику дискретного фільтра CDS:

```
h_cds(t) = δ(t - T_s) - δ(t)                                    [імпульсна характеристика]
```

Передавальна функція фільтра у частотній області `H_cds(f)` є фур'є-перетворенням `h_cds(t)`:

```
H_cds(f) = exp(-j · 2π · f · T_s) - 1                            [передавальна функція CDS]
|H_cds(f)|² = | exp(-j 2π f T_s) - 1 |² = (cos(2π f T_s) - 1)² + sin²(2π f T_s)
|H_cds(f)|² = 2 - 2 · cos(2π · f · T_s) = 4 · sin²(π · f · T_s) [квадрат модуля передавальної функції]
```

Помножимо входжу спектральну щільність фліккер-шуму `S_in(f) = C / f` на квадрат модуля передавальної функції CDS-фільтра:

```
S_out(f) = S_in(f) · |H_cds(f)|² = (C / f) · 4 · sin²(π · f · T_s) [вихідна СЩП після CDS]
```

Дослідиємо поведінку вихідного спектра на низьких частотах (`f << 1 / T_s`). Розкладемо синус у ряд Тейлора (`sin(z) ≈ z`):

```
sin²(π · f · T_s) ≈ (π · f · T_s)²                               [розклад у ряд Тейлора]
S_out(f) ≈ (C / f) · 4 · (π · f · T_s)² = 4 · C · π² · T_s² · f ~ f [погашення 1/f шуму]
```

Строге математичне виведення доводить: завдяки відніманню двох близьких за часом відліків CDS змінює залежність спектра з оберненої (`1/f`) на прямо пропорційну (`~ f`). Як наслідок, спектральна щільність шуму на нульовій частоті дорівнює нулю (`lim_{f → 0} S_out(f) = 0`), що повністю усуває низькочастотний фліккер-шум та дрейф нуля.

## 7. Біспектральний аналіз і неґауссівський характер 1/f шуму

У класичній статистичній фізиці флуктуації вважають ґауссівським випадковим процессом, чий імовірнісний розподіл повністю задається першими двома моментами — середнім значенням та дисперсією (або автокореляційною функцією). Однак для фліккер-шуму, викликаного нелінійною взаємодією багатьох локалізованих релаксаторів або лавинними процесами, вищі статистичні моменти відхиляються від ґауссівського закону.

Для аналізу статистичних зв'язків між різними частотними компонентами використовують спектральні моменти вищого порядку, зокрема біспектр `B(f₁, f₂)`:

```
B(f₁, f₂) = lim_{T_obs → ∞} (1 / T_obs) · < X(f₁) · X(f₂) · X*(f₁ + f₂) >  [біспектр випадкового процесу]
```

де `X(f)` — комплексний коефіцієнт перетворення Фур'є сигналу `x(t)`.

Значення біспектра дозволяє фізично розрізнити два принципово різні механізми виникнення `1/f` шуму:
1. **Ансамбль повністю незалежних лоренціанів (модель МакВортера):**
   Оскільки окремі пастки не взаємодіють одна з одною, фази їхніх флуктуацій є випадковими та незалежними. У цьому випадку біспектр строго дорівнює нулю (`B(f₁, f₂) = 0`), і шум належить до стаціонарних ґауссівських процесів.
2. **Взаємодіючі мережі дефектів та лавинні системи (модель SOC):**
   Перескок одного дефекту змінює локальне поле напружень у кристалічній ґратці, викликаючи ланцюгову релаксацію сусідніх дефектів. Фази частотних компонент стають корельованими, що призводить до ненульового біспектра (`B(f₁, f₂) ≠ 0`).

Вимірювання нормованого біспектра (бікогерентності `b²(f₁, f₂)`) слугує тонким фізичним інструментом для ідентифікації наявності міждефектної взаємодії в конденсованих середовищах:

```
b²(f₁, f₂) = | B(f₁, f₂) |² / ( S(f₁) · S(f₂) · S(f₁ + f₂) )     [коефіцієнт бікогерентності]
```

Значення `b²(f₁, f₂) > 0` свідчить про кооперативну поведінку ансамблю дефектів та неґауссівську структуру рожевого шуму.

Для несиметричних випадкових телеграфних процесів із різними часами перебування у захопленому стані `τ_on` та вільному стані `τ_off` третій центральний момент `μ₃ = <(δI)³>` та четвертий центральний момент (ексцес `μ₄ = <(δI)⁴>`) відмінні від ґауссівських значень:

```
μ₃ = (ΔI)³ · (τ_on - τ_off) · τ_on · τ_off / (τ_on + τ_off)³     [третій центральний момент RTS]
μ₄ = (ΔI)⁴ · (τ_on · τ_off / (τ_on + τ_off)²) · [ 1 - 3 · (τ_on · τ_off / (τ_on + τ_off)²) ]  [четвертий момент]
```

Асиметрія третього моменту показує, що при напрямку `τ_on > τ_off` сигнал проводитиме більше часу на верхній поличці, що створює характеристичну асиметрію гістограми флуктуацій та відхилення від ґауссівської симетрії.

## 8. Спін-граткова релаксація Орбаха та спектр спінового шуму

У парамагнітних кристалах та спінових ансамблях на низьких температурах флуктуації намагніченості викликаються спін-гратковою релаксацією. Окрім прямого однофононного процесу та двофононного раманівського розсіювання, важливу роль відіграє трирівневий процес Орбаха — Амінова.

Нехай спіновий центр має два основних стани `|1>` та `|2>`, розділені малим зееманівським розщепленням `δ`, та збуджений стан `|3>`, віддалений на енергію `Δ >> δ`. Перескок між основними станами відбувається шляхом термодинамічного поглинання фонона з енергією `Δ` та наступного випромінювання фонона.

Час релаксації процесу Орбаха визначається формулою:

```
τ_orbach = τ₀ · ( exp(Δ / (k_B · T)) - 1 )                       [час релаксації Орбаха]
```

При низьких температурах (`k_B T << Δ`) маємо експоненціальну залежність `τ_orbach ≈ τ₀ · exp(Δ / (k_B T))`.

Якщо у впорядкованому кристалі існує розмиття енергій кристалічного поля `Δ` з функцією щільності `D(Δ) = const` у діапазоні `[Δ_min, Δ_max]`, то сумарний спектр спінового шуму отримують інтегруванням по рівноважному ансамблю:

```
S_M(f) = ∫_{Δ_min}^{Δ_max} D(Δ) · [ 4 · A_m² · τ_orbach(Δ) / (1 + (2π · f · τ_orbach(Δ))²) ] dΔ  [інтегрування Орбаха]
```

Оскільки `dτ_orbach / dΔ = τ_orbach / (k_B T)`, заміна змінних перетворює інтеграл на логарифмічно-рівномірну суперпозицію лоренціанів, яка знову формує спектр спінового фліккер-шуму `S_M(f) ~ 1/f` у низькочастотній області.

Для експериментального вимірювання спінового шуму `S_M(f)` використовують оптичну магнітометрію: лінійно поляризоване лазерне випромінювання проходить крізь парамагнітне середовище, і флуктуації спінів викликають повороти площини поляризації за рахунок ефекту Фарадея. Реєстрація квантових флуктуацій Фарадея в атомарних парах рубідію-87 та цезію-133 дозволяє відновлювати спектральну щільність спінового фліккер-шуму з високою точністю без застосування розширювального оптичного накачування. Це усуває польове розширення ліній і дає можливість спостерігати чистий спонтанний спіновий фліккер-шум атомного середовища у стані термодинамічної рівноваги.
