# 🧮 Термодинаміка розчинності та конвекційного масопереносу

Математичне формулювання та виведення рівнянь рівноважної розчинності кремнезему у водних лужних розчинах при високих температурах і тисках визначають рушійну силу пересиченості та параметри природної теплової конвекції в гідротермальному автоклаві.

---

### 1. Рівноважна розчинність кремнезему та рівняння Ван т Гоффа

Розчинення кварцю у лужному водному середовищі (наприклад, у розчині карбонату натрію `Na₂CO₃` або гідроксиду натрію `NaOH`) супроводжується хімічною взаємодією гідроксильних аніонів `OH⁻` із твердою фазою кремнезему `SiO₂`.

Головна хімічна реакція утворення розчинного мономерного силікатного комплексу описується рівнянням:

```
SiO₂ (твердий) + 2 OH⁻ (водний) ⇌ SiO₃²⁻ (водний) + H₂O (рідкий)
```

При підвищених концентраціях кремнезему утворюються також деполімеризовані димерні й тримерні комплекси:

```
3 SiO₂ (твердий) + 2 OH⁻ (водний) ⇌ Si₃O₇²⁻ (водний) + H₂O (рідкий)
```

У середовищі гідроксиду натрію `NaOH` основними іонними формами є гідроксисилікат-іони `[SiO(OH)₃]⁻` та `[SiO₂(OH)₂]²⁻`.

Термодинамічна константа рівноваги даного процесу `K_eq`:

```
K_eq = [SiO₃²⁻] / [OH⁻]²
```

Зв'язок константи рівноваги зі стандартною зміною вільної енергії Гіббса `ΔG_diss°`:

```
ΔG_diss° = - R · T · ln K_eq
ΔG_diss° = ΔH_diss° - T · ΔS_diss°
```

Звідси отримуємо рівняння Ван т Гоффа для температурної залежності рівноважної молярної розчинності `S` (у моль/л або масових відсотках `wt%`):

```
ln S = - (ΔH_diss° / (R · T)) + (ΔS_diss° / R)
```

де:
- `ΔH_diss°` — стандартна ентальпія розчинення кварцю (близько `25–35 кДж/моль` у лужних розчинах);
- `ΔS_diss°` — стандартна ентропія розчинення;
- `R = 8.314 Дж/(моль·К)` — універсальна газова стала;
- `T` — абсолютна температура в кельвінах (`K`).

Оскільки розчинення кремнезему є ендотермічним процесом (`ΔH_diss° > 0`), похідна розчинності за температурою є позитивною:

```
∂S / ∂T = (ΔH_diss° / (R · T²)) · S > 0
```

Це математично доводить, що при збільшенні температури розчинність `SiO₂` у водних лужних розчинах **зростає**.

#### Залежність розчинності від тиску та густини флюїду

У надкритичній та стиснутій субкритичній воді тиск `P` справляє фундаментальний вплив на розчинність через зміну густини флюїду `ρ_fluid`. Залежність розчинності від густини описується емпіричним рівнянням Кеннеді — Войткевича:

```
ln S = a + b · ln ρ_fluid - (ΔH_diss° / (R · T))
```

де `a` та `b` — емпіричні константи розчинника (для 0.8 M `Na₂CO₃` показник `b ≈ 2.0`).

Об'ємний ефект розчинення визначається парціальним мольним об'ємом розчиненого силікату `V_bar`:

```
(∂ (ln S) / ∂P)_T = - ΔV_diss / (R · T)
```

Оскільки при сольватації іонів `SiO₃²⁻` густина розчину зростає (`ΔV_diss < 0`), підвищення тиску збільшує розчинність `SiO₂`.

Збільшення тиску від 50 МПа до 150 МПа при `T = 380 °C` збільшує густину водного флюїду з 0.55 г/см³ до 0.75 г/см³, що підвищує рівноважну розчинність `SiO₂` від ~1.2 wt% до ~3.2 wt%.

### 2. Рівняння масопереносу та кінетики росту граней

У двозонному автоклаві нижня зона розчинення має вищу температуру `T_diss`, ніж верхня зона росту затравок `T_grow` (`T_diss > T_grow`).

Внаслідок ендотермічності розчинення концентрація насиченого розчину в зоні шихти `S(T_diss)` є вищою за рівноважну розчинність у зоні затравок `S(T_grow)`.

**Абсолютна пересиченість розчину `ΔC`** у зоні росту становить:

```
ΔC = S(T_diss) - S(T_grow) > 0
```

Відносна пересиченість `σ`:

```
σ = ΔC / S(T_grow) = (S(T_diss) - S(T_grow)) / S(T_grow)
```

У наближенні малого температурного перепаду `ΔT = T_diss - T_grow`:

```
ΔC ≈ (∂S / ∂T)_P · ΔT
```

#### Масовий потік та дифузійний примежовий шар

Перенос розчиненої маси до поверхні затравкової пластини описується першим законом Фіка та рівнянням масообміну Нернста:

```
J = (D_diff / δ_D) · (C_bulk - C_surf) = K_m · ΔC
```

де:
- `J` — масовий потік кремнезему, кг/(м²·с);
- `D_diff` — коефіцієнт дифузії силікатних іонів у надкритичній воді (`~10⁻⁸ м²/с`);
- `δ_D` — товщина гідродинамічного дифузійного примежового шару Нернста (`~50–100 мкм`);
- `K_m = D_diff / δ_D` — коефіцієнт масопереносу, м/с;
- `C_bulk = S(T_diss)` — концентрація кремнезему в об'ємі зони росту;
- `C_surf = S(T_grow)` — рівноважна концентрація на поверхні росту.

#### Лінійна швидкість нарощування грані

Пов'язуючи масовий потік `J` з густиною монокристалічного кварцю `ρ_cryst = 2650 кг/м³`, отримуємо вираз для лінійної швидкості росту грані `v_growth` (у м/с або мм/добу):

```
v_growth = J / ρ_cryst = (K_m / ρ_cryst) · ΔC
```

Підставляючи вираз для `ΔC` через температурний градієнт `ΔT`:

```
v_growth = (K_m / ρ_cryst) · (∂S / ∂T)_P · ΔT
```

Звідси випливає фундаментальний висновок: **лінійна швидкість росту кристала у першому наближенні прямо пропорційна величині температурного перепаду `ΔT` між зонами автоклава**.

### 3. Гідродинаміка теплової конвекції та число Райлея

Перенос розчиненого `SiO₂` з нижньої зони у верхню здійснюється шляхом природної теплової конвекції, викликаної температурною зміною густини водного флюїду.

Різниця густини флюїду між гарячим низом (`T_diss`) та прохолодним верхом (`T_grow`) становить:

```
Δρ = ρ_fluid · β · ΔT
```

де `β = - (1/ρ) · (∂ρ / ∂T)_P` — коефіцієнт об'ємного термічного розширення флюїду при робочому тиску.

#### Безрозмірне число Райлея (Ra)

Інтенсивність природної конвекції всередині циліндричного автоклава висотою `L` описується безрозмірним числом Райлея (`Ra`):

```
Ra = (g · β · ΔT · L³) / (ν · α_diff)
```

де:
- `g = 9.81 м/с²` — прискорення вільного падіння;
- `L` — характерна висота автоклава;
- `ν = μ / ρ_fluid` — кінематична в'язкість водного флюїду;
- `α_diff = k_th / (ρ_fluid · C_p)` — коефіцієнт температуропровідності.

Безрозмірне число Прандтля (`Pr`):

```
Pr = ν / α_diff
```

Безрозмірне число Грасгофа (`Gr`):

```
Gr = Ra / Pr = (g · β · ΔT · L³) / ν²
```

У типових промислових автоклавах висотою `L = 3–8 м` при `ΔT = 20–40 °C` та високому тиску (де кінематична в'язкість води `ν ≈ 1.5 · 10⁻⁷ м²/с` є надзвичайно малою) число Райлея сягає величин:

```
Ra ≈ 10¹⁰ – 10¹²
```

Поріг виникнення теплової конвекції в обмеженій циліндричній порожнині (критичне число Райлея) становить `Ra_crit ≈ 1708`. Оскільки фактичне число Райлея у `10⁷` разів перевищує критичне порогове значення, за відсутності дроселювання конвекційний режим всередині автоклава був би **розвиненим буйним турбулентним рухом**, який викликав би розмив граней кристала та хаотичні коливання пересиченості.

#### Гідродинаміка перфорованого бафла

Для стабілізації конвекції між зоною розчинення та зоною кристалізації встановлюють **перфоровану перегородку (бафл)** з відносним площинним відкриттям `f_baffle = A_holes / A_autoclave = 2–8%`.

Гідравлічний опір отворів бафла дроселює масовий потік і створює ламінаризовану центральну струминну конвекцію зі швидкістю підйому розчину `u_z`:

```
u_z ≈ C_d · f_baffle · √(2 · g · L · β · ΔT)
```

де `C_d ≈ 0.6–0.7` — коефіцієнт витрати перфорованого отвору.

Завдяки дроселюванню через бафл коефіцієнт масопереносу `K_m` масштабується як:

```
K_m ≈ K_m0 · f_baffle · √(ΔT)
```

### 4. Чисельний розрахунковий приклад для промислового синтезу

Для ілюстрації виведених рівнянь розглянемо чисельний розрахунок параметрів синтезу у промисловому 1000-літровому автоклаві:

#### Вхідні параметри:
- Температура розчинення: `T_diss = 395 °C (668.15 K)`
- Температура кристалізації: `T_grow = 355 °C (628.15 K)`
- Температурний градієнт: `ΔT = 40 °C`
- Робочий тиск: `P = 130 МПа`
- Розчинник: 0.8 M `Na₂CO₃` (густина флюїду `ρ_fluid = 1.073 г/см³`)
- Відкриття бафла: `f_baffle = 4.5%`

#### Покроковий розрахунок:
1. **Рівноважна розчинність:**
   - У зоні шихти: `S(T_diss) = 3.168 wt%`
   - У зоні затравок: `S(T_grow) = 2.419 wt%`
2. **Абсолютна пересиченість розчину:**
   - `ΔC = 3.168 - 2.419 = 0.749 wt%`
   - Переведення у об'ємну масову концентрацію: `ΔC_kg = (0.749 / 100) · 1073 кг/м³ = 8.04 кг/м³`
3. **Обчислення коефіцієнта масопереносу:**
   - `K_m = 1.2 · 10⁻⁶ · (4.5 / 5.0) · √(40 / 40) = 1.08 · 10⁻⁶ м/с`
4. **Масовий потік:**
   - `J = 1.08 · 10⁻⁶ м/с · 8.04 кг/м³ = 8.68 · 10⁻⁶ кг/(м²·с)`
5. **Лінійна швидкість нарощування Z-грані:**
   - `v_Z = (8.68 · 10⁻⁶ кг/(м²·с) / 2650 кг/м³) · 1000 мм/м · 86400 с/добу = 0.283 мм/добу`

Розрахунок показує, що за 60 діб безперервного росту товщина нарощеного шару монокристала на `Z`-затравці досягає `17 мм` з кожного боку (сумарна товщина кристала збільшується на `34 мм`), що ідеально узгоджується з промисловими спостереженнями.
