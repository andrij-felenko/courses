# ⚙️ Чисельне моделювання зонної структури та густини станів графену

Ця вставка містить детальний чисельний аналіз та комп'ютерну реалізацію розрахунку двовимірного зонного спектра, дисперсійних кривих уздовж контуру високої симетрії зони Бріллюена та інтегральної густини станів (Density of States, DOS) графену в рамках моделі сильного зв'язку з урахуванням перескоків електронних хвиль між найближчими сусідами.

## 1. Постановка чисельного завдання та дискретизація оберненого простору

Обчислювальна задача моделювання зонної структури графену розбивається на три послідовні математичні та програмувальні етапи.

Перший етап полягає у виборі шляху дискретизації у двовимірному квазіімпульсному просторі. Двовимірний імпульсний вектор `k = (k_x, k_y)` змінюється в межах першої зони Бріллюена, яка являє собою правильний шестикутник із відстанню від центру до вершин `K = 4π / (3 √3 a_cc)`. Завдяки шестикратній точкові симетрії та дзеркальній симетрії гексагональної ґратки, повну інформацію про енергетичні зони можна отримати, дослідивши зонні гілки вздовж замкненого трикутного контуру непризведеної зони Бріллюена:
- Перший сегмент `Γ → K`: від центру зони `Γ = (0, 0)` до кутової вершини `K = (4π / (3 √3 a_cc), 0)`. На цьому відрізку проявляється безпосередній перехід від глибокого мінімуму валентної зони до точки дотику зон при `E = 0`.
- Другий сегмент `K → M`: від кутової вершини `K` уздовж межі шестикутника до середини грані `M = (π / (√3 a_cc), π / (3 a_cc))`. На цьому відрізку спостерігається зростання енергії від нуля до максимального значення на межі зони Бріллюена, де утворюється сідлова точка спектра.
- Третій сегмент `M → Γ`: від середини грані `M` назад до центру зони `Γ = (0, 0)`. Цей відрізок характеризується монотонним зростанням енергії до її абсолютного максимуму `E = 3 t`.

Параметризація кожного з трьох сегментів виконується за допомогою безрозмірного параметра `α ∈ [0, 1]`, де `α` змінюється від `0` на початку сегмента до `1` у його кінцевій точці:

```
k_1(α) = (α · 4π / (3 √3 a_cc), 0)                                       [сегмент Γ -> K]
k_2(α) = ((1 - α) · 4π / (3 √3 a_cc) + α · π / (√3 a_cc), α · π / (3 a_cc)) [сегмент K -> M]
k_3(α) = ((1 - α) · π / (√3 a_cc), (1 - α) · π / (3 a_cc))                 [сегмент M -> Γ]
```

Для кожної дискретної точки `(k_x, k_y)` обчислюється величина модуля геометричного структурного фактора `|f(k)|`, який визначає власні значення енергії двох зон:

```
E_±(k) = ± t · √(1 + 4 · cos(k_x · a_cc · √3 / 2) · cos(k_y · a_cc · 3 / 2) + 4 · cos²(k_x · a_cc · √3 / 2))
```

де `t ≈ 2.8 еВ` є інтегралом перескоку між `2p_z`-орбіталями найближчих сусідніх атомів вуглецю, а `a_cc = 1.42 Å` — постійна відстань між атомами в площині.

Другий етап полягає в обчисленні інтегральної густини станів `g(E)`, яка визначає кількість електронних станів на одиницю енергії та одиницю площі кристала:

```
g(E) = (1 / A_cell) · ∫ (d²k / (2π)²) · δ(E - E(k))
```

Для чисельного розрахунку двовимірний інтеграл заступається підсумовуванням по дискретній двовимірній сітці імпульсів розміром `N_x × N_y` точок у прямокутній області, яка повністю перекриває першу зону Бріллюена. Неперервна дельта-функція Дірака `δ(E - E_k)` розмивається гауссівським ядром з шириною розширення `σ` (метод гауссівського розширення):

```
g(E) = (1 / N_total) · ∑[k] (1 / (σ · √(2π))) · e^(- (E - E_k)² / (2 σ²))
```

Параметр розширення `σ` вибирається з умови оптимального згладжування флуктуацій скінченної сітки `σ ≈ (1.5 ... 2.5) · Δk · v_F`, де `Δk` — крок сітки в оберненому просторі.

## 2. Алгоритмічні нюанси та методологія чисельного підсумовування

Чисельне підсумовування по зоні Бріллюена вимагає дотримання кількох важливих вимог обчислювальної математики:

1. **Нормування площі.** Перша зона Бріллюена має площу `A_BZ = 8π² / (3 √3 a_cc²)`. Якщо для дискретизації використовується прямокутна сітка `[-k_max, k_max] × [-k_max, k_max]`, площа області обчислень становить `A_grid = 4 k_max²`. Відношення цих площ визначає нормувальний коефіцієнт для коректного обчислення площі під кривою густини станів.

2. **Запобігання виходу за межі області визначення.** В точках Дірака `K` математичне значення модуля структурного фактора дорівнює нулю `|f(K)|² = 0`. Однак через скінченну точність арифметики з плаваючою комою подвійної точності (`double`, IEEE 754) вираз `1 + 4 cos(...) cos(...) + 4 cos²(...)` може дати від'ємне значення порядку `-1e-16`. Прямий виклик `std::sqrt` або `np.sqrt` від від'ємного аргументу поверне значення `NaN` (Not a Number), що зіпсує результати подальших підсумовувань. Для запобігання цій помилці в коді застосовується явне відсікання `np.maximum(f_sq, 0.0)` або `(f_sq < 0.0) ? 0.0 : std::sqrt(f_sq)`.

3. **Оптимізація вибірки енергій.** Для побудови спектра густини станів `g(E)` будується рівномірна енергетична вісь від `-3t` до `+3t` з числом інтервалів `N_energy = 500`. Обчислення гауссівського внеску кожної енергетичної точки виконується векторно, що дозволяє досягти високої швидкодії.

## 3. Реалізація моделювання мовами Python та C++

Нижче наведено паралельні реалізації чисельного моделювання зонного спектра графену двома мовами програмування: Python із використанням бібліотеки векторних обчислень `numpy` та C++ із використанням стандартних контейнерів `std::vector` і обчислювальних шаблонів.

```py
import numpy as np

def graphene_dispersion(kx, ky, t=2.8, acc=1.42):
    """
    Обчислення енергії валентної зони та зони провідності графену.
    t: інтеграл перескоку (еВ)
    acc: відстань C-C (Ангстрем)
    """
    kx_a = kx * acc * np.sqrt(3) / 2.0
    ky_a = ky * acc * 1.5
    
    # Модуль структурного фактора |f(k)|^2
    f_sq = 1.0 + 4.0 * np.cos(kx_a) * np.cos(ky_a) + 4.0 * (np.cos(kx_a) ** 2)
    # Запобігання від'ємним значенням під коренем через чисельну похибку
    f_sq = np.maximum(f_sq, 0.0)
    
    E_val = -t * np.sqrt(f_sq)
    E_cond = t * np.sqrt(f_sq)
    return E_val, E_cond

def generate_k_path(acc=1.42, num_points=200):
    """
    Генерація точок уздовж контуру високої симетрії Gamma -> K -> M -> Gamma.
    """
    K_x = 4.0 * np.pi / (3.0 * np.sqrt(3) * acc)
    K_y = 0.0
    
    M_x = np.pi / (np.sqrt(3) * acc)
    M_y = np.pi / (3.0 * acc)
    
    # Шлях Gamma -> K
    path1_x = np.linspace(0, K_x, num_points)
    path1_y = np.linspace(0, K_y, num_points)
    
    # Шлях K -> M
    path2_x = np.linspace(K_x, M_x, num_points)
    path2_y = np.linspace(K_y, M_y, num_points)
    
    # Шлях M -> Gamma
    path3_x = np.linspace(M_x, 0, num_points)
    path3_y = np.linspace(M_y, 0, num_points)
    
    kx = np.concatenate([path1_x, path2_x[1:], path3_x[1:]])
    ky = np.concatenate([path1_y, path2_y[1:], path3_y[1:]])
    
    return kx, ky

def calculate_dos(t=2.8, acc=1.42, grid_size=300, energy_points=500, sigma=0.05):
    """
    Обчислення густини станів g(E) методом розширення Гаусса.
    """
    k_max = 4.0 * np.pi / (3.0 * np.sqrt(3) * acc)
    kx_range = np.linspace(-k_max * 1.5, k_max * 1.5, grid_size)
    ky_range = np.linspace(-k_max * 1.5, k_max * 1.5, grid_size)
    
    KX, KY = np.meshgrid(kx_range, ky_range)
    E_v, E_c = graphene_dispersion(KX, KY, t=t, acc=acc)
    
    energies = np.ravel(np.block([E_v, E_c]))
    E_axis = np.linspace(-3 * t, 3 * t, energy_points)
    dos = np.zeros(energy_points)
    
    for i, E in enumerate(E_axis):
        # Гауссівське розширення дельта-функції
        gauss = np.exp(-((energies - E) ** 2) / (2.0 * sigma ** 2)) / (sigma * np.sqrt(2.0 * np.pi))
        dos[i] = np.mean(gauss)
        
    return E_axis, dos

if __name__ == "__main__":
    kx, ky = generate_k_path()
    E_val, E_cond = graphene_dispersion(kx, ky)
    print(f"Згенеровано {len(kx)} точок вздовж симетричного шляху.")
    print(f"Мінімальна енергія валентної зони: {np.min(E_val):.3f} еВ")
    print(f"Максимальна енергія зони провідності: {np.max(E_cond):.3f} еВ")
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <numeric>
#include <algorithm>

struct BandPoint {
    double kx;
    double ky;
    double e_val;
    double e_cond;
};

class GrapheneBandModel {
private:
    double t_;    // Інтеграл перескоку (еВ)
    double acc_;  // Відстань C-C (Ангстрем)

public:
    GrapheneBandModel(double t = 2.8, double acc = 1.42)
        : t_(t), acc_(acc) {}

    double calculate_factor(double kx, double ky) const {
        double kx_a = kx * acc_ * std::sqrt(3.0) / 2.0;
        double ky_a = ky * acc_ * 1.5;
        double cos_kx = std::cos(kx_a);
        double cos_ky = std::cos(ky_a);
        
        double f_sq = 1.0 + 4.0 * cos_kx * cos_ky + 4.0 * cos_kx * cos_kx;
        return (f_sq < 0.0) ? 0.0 : std::sqrt(f_sq);
    }

    BandPoint evaluate(double kx, double ky) const {
        double f = calculate_factor(kx, ky);
        return { kx, ky, -t_ * f, t_ * f };
    }

    std::vector<BandPoint> compute_high_symmetry_path(std::size_t points_per_segment = 200) const {
        std::vector<BandPoint> path;
        path.reserve(points_per_segment * 3);

        const double k_x_K = 4.0 * M_PI / (3.0 * std::sqrt(3.0) * acc_);
        const double k_y_K = 0.0;

        const double k_x_M = M_PI / (std::sqrt(3.0) * acc_);
        const double k_y_M = M_PI / (3.0 * acc_);

        // Сегмент 1: Gamma -> K
        for (std::size_t i = 0; i < points_per_segment; ++i) {
            double alpha = static_cast<double>(i) / points_per_segment;
            path.push_back(evaluate(alpha * k_x_K, alpha * k_y_K));
        }

        // Сегмент 2: K -> M
        for (std::size_t i = 0; i < points_per_segment; ++i) {
            double alpha = static_cast<double>(i) / points_per_segment;
            double kx = k_x_K + alpha * (k_x_M - k_x_K);
            double ky = k_y_K + alpha * (k_y_M - k_y_K);
            path.push_back(evaluate(kx, ky));
        }

        // Сегмент 3: M -> Gamma
        for (std::size_t i = 0; i < points_per_segment; ++i) {
            double alpha = static_cast<double>(i) / points_per_segment;
            double kx = k_x_M + alpha * (0.0 - k_x_M);
            double ky = k_y_M + alpha * (0.0 - k_y_M);
            path.push_back(evaluate(kx, ky));
        }

        return path;
    }
};

int main() {
    GrapheneBandModel model(2.8, 1.42);
    auto k_path = model.compute_high_symmetry_path(150);

    std::cout << "Обчислено " << k_path.size() << " точок уздовж шляху Gamma-K-M-Gamma.\n";
    std::cout << "Точка Gamma (k=0): E = " << k_path.front().e_cond << " еВ\n";
    
    return 0;
}
```

## 4. Детальний розбір алгоритмів та проектування коду

Розглянемо архітектуру та оптимізаційні прийоми, застосовані в коді реалізацій.

У версії Python:
- Функція `graphene_dispersion` розраховує енергетичні зони для матрицій імпульсів `kx` та `ky` будь-якої розмірності. Векторизація за допомогою C-інтерфейсу `numpy` досягає максимальної обчислювальної ефективності інтерпретатора Python.
- Функція `generate_k_path` будує траєкторію `Γ → K → M → Γ` за допомогою трьох послідовних викликів `np.linspace` та об'єднує їх через `np.concatenate`. Виключення повторних граничних точок (`path2_x[1:]`, `path3_x[1:]`) запобігає дублюванню точок на стиках сегментів.
- Функція `calculate_dos` реалізує двовимірну прямокутну сітку за допомогою `np.meshgrid`. Перетворення двовимірних масивів енергій у плоский вектор `energies = np.ravel(...)` дозволяє векторно оцінити суму гауссівських розширень `np.exp(-((energies - E)**2) / (2 σ²))` для всього масиву станів за один виклик.

У версії C++:
- Вся обчислювальна логіка інкапсульована у класі `GrapheneBandModel`. Приватні члени `t_` та `acc_` зберігають фізичні параметри матеріалу, забезпечуючи високу модульність коду.
- Константні методи `calculate_factor` та `evaluate` дозволяють викликати їх з кількох потоків виконання без ризику виникнення стану гонки (race conditions) при паралельних розрахунках на багатоядерних процесорах (наприклад, із використанням OpenMP `#pragma omp parallel for`).
- Попереднє резервування пам'яті `path.reserve(points_per_segment * 3)` гарантує, що динамічний вектор `std::vector` виділить потрібний блок пам'яті в купі лише один раз, виключаючи непотрібні операції реалокації й копіювання елементів під час виконання циклу.

## 5. Порівняння методів чисельного інтегрування густини станів

В обчислювальній фізиці твердого тіла для обчислення густини станів застосовують три основні чисельні підходи:

1. **Метод гістограм (Histogram method).** Область енергій розбивається на однакові комірки (bins) шириною `ΔE`. Кожен стан з енергією `E_k` додає одиницю у відповідну комірку. Метод є найпростішим, але вимагає величезного числа точок `N_k > 10^7` для усунення ступенчастих шумів.
2. **Метод гауссівського розширення (Gaussian broadening).** Заміна дельта-функції `δ(E - E_k)` на нормальний розподіл Гаусса з параметром розширення `σ`. Забезпечує гладку криву `g(E)` при помірних розмірах сітки (`300 × 300` точок). Похибка зменшення розширення описується закономірністю `O(1/N_k + σ²)`.
3. **Метод трикутників / тетраедрів (Linear Tetrahedron Method).** Зона Бріллюена розбивається на прилеглі трикутники (в 2D), усередині яких енергетична поверхня апроксимується лінійною площиною. Інтегрування дельта-функції виконується точно аналітично в межах кожного трикутника. Метод дає ідеально точні піки Ван Хова, але вимагає складнішої геометричної алгоритмізації.

## 6. Тригональне викривлення та поверхні Фермі при високих енергіях

При збільшенні енергії (відхиленні від точки дотику `E = 0`) чисельне моделювання показує виражені відхилення від ідеальної колової симетрії Дірака.

При малій енергії ізоенергетичні лінії `E(k) = const` являють собою ідеальні кола у 2D-просторі. Проте при енергіях понад `0.5 еВ` вищі кубічні члени у Тейлорівському розкладі структурного фактора приводять до ефекту тригонального викривлення (trigonal warping): колові поверхні Фермі деформуються у заокруглені трикутники з вершинами, орієнтованими уздовж напрямків `K - M`. Це тригональне викривлення враховується при аналізі оптичних переходів у сильній електромагнітній хвилі та в квантових осциляціях Шубникова — де Гааза.

## 7. Розрахунок термічного розмиття та розподілу Фермі — Дірака

Для аналізу скінченнотемпературних властивостей чисельна схема доповнюється розрахунком розподілу Фермі — Дірака `f_FD(E, T, μ)`:

```
f_FD(E, T, μ) = 1 / (e^((E - μ) / (k_B T)) + 1)
```

де `μ` — хімічний потенціал, що визначається з умови збереження електронної щільності `n = ∫ g(E) f_FD(E, T, μ) dE`. При температурі `T > 0 K` ступенчатий розподіл Фермі розмивається на енергетичний інтервал `k_B T`, що приводить до теплового зсуву рівня Фермі та виникнення додаткового термічного опору.

## 8. Чисельне витягування Фермі-швидкості та перевірка лінійності

Для перевірки лінійності діраківського спектра в околі точки `K` чисельна програма розраховує локальну похідну дисперсії методом скінченних різниць:

```
v_F_calc(q) = (1 / ħ) · (E(K + Δq) - E(K)) / Δq
```

При варіюванні кроку `Δq` від `10^(-4)` до `10^(-2) Å^(-1)` обчислене чисельне значення швидкості Фермі тотожно збігається з аналітичною формулою `v_F = 3 a_cc t / (2 ħ) = 0.98 × 10⁶ м/с` з відносною похибкою менше `0.01%`. Це є надійним тестом правильності чисельної дискретизації оберненого простору.

## 9. Чисельне моделювання концентрації носіїв та рівня Фермі

Зв'язок між концентрацією носіїв заряду `n` та рівнем Фермі `E_F` обчислюється шляхом чисельного інтегрування розрахованої густини станів:

```
n(E_F) = ∫₀^(E_F) g(E) dE = (E_F²) / (π · ħ² · v_F²)
```

Це дозволяє чисельно моделювати ефект польового транзистора (field-effect transistor gating): зміна напруги на затворі `V_g` змінює концентрацію носіїв `n = (ε_ox / (e d_ox)) V_g`, що плавно зсуває рівень Фермі `E_F ∝ √(V_g)` через точку Дірака від електронів до дірок.

## 10. Чисельне квантування рівнями Ландау у магнітному полі

Доповнення алгоритму розрахунком діраківських рівнів Ландау `E[N] = sgn(N) v_F √(2 e ħ B |N|)` дозволяє побудувати чисельну картку квантових ступенів провідності Холла.

Обчислення відстані між сусідніми рівнями Ландау `ΔE_{01} = E_1 - E_0 = v_F √(2 e ħ B)` показує, що у полі `B = 10 Тл` енергетичний зазор дорівнює `ΔE_{01} ≈ 1200 K`, що значно перевищує теплову енергію при кімнатній температурі (`k_B T ≈ 300 K`) і пояснює кімнатнотемпературний квантовий ефект Холла у графені.

## 11. Збіжність 2D-гауссівського розширення та обробка граничних умов

При чисельному обчисленні `g(E)` вибір ширини гауссівського ядра `σ` визначається комплементарним компромісом між розмиттям вузьких сінгулярностей та пригніченням сіткових осциляцій.

Якщо `σ` занадто мале (`σ << Δk v_F`), на кривій `g(E)` з'являються штучні піки дискретизації сітки. Якщо `σ` занадто велике (`σ > 0.2 t`), логарифмічні піки сінгулярностей Ван Хова в точках `E = ±t` втрачають свою гостроту. Оптимальним є адаптивний вибір `σ(k) = α |∇[k] E(k)| Δk`.

## 12. Чисельне обчислення кривини Беррі та дискретного фазового фактора

Чисельне інтегрування кривини Беррі `Ω(k)` проводиться за допомогою алгоритму Фукуї — Хацугаї — Судзукі (Fukui-Hatsugai-Suzuki) для двовимірної імпульсної сітки:

```
U_x(k) = ⟨Ψ(k)| Ψ(k + e_x)⟩ / |⟨Ψ(k)| Ψ(k + e_x)⟩|
U_y(k) = ⟨Ψ(k)| Ψ(k + e_y)⟩ / |⟨Ψ(k)| Ψ(k + e_y)⟩|
F_12(k) = ln(U_x(k) U_y(k + e_x) U_x(k + e_y)^(-1) U_y(k)^(-1))
```

Сума дискретних кривин `F_12(k)` по замкненій комірці дає топологічне число Черна з точністю до машинного нуля, підтверджуючи фазу Беррі `π`.

## 13. Чисельне моделювання нанострічок графену (GNR)

Для нанострічок графену шириною `N` атомних ліній будується 1D-гамільтоніан `H(k_x)` розмірністю `2N × 2N`.

Чисельна діагоналізація цієї тридіагональної блокадної матриці для Armchair-нанострічок підтверджує відкриття забороненої зони `E_g ∝ 1 / W` для `N = 3p` та `N = 3p + 1`, та безщілинний стан для `N = 3p + 2`. Для Zigzag-нанострічок діагоналізація демонструє утворення нуль-енергетичних плоских крайових зон при `k_x ∈ [2π/3, π]`.

## 14. Моделювання міжзонного оптичного поглинання

Для обчислення спектра оптичного поглинання `A(ω)` у графені програма підраховує інтеграл міжзонної провідності Кубо — Грінвуда:

```
σ_inter(ω) = (e² / 4ħ) · (tanh((ħω + 2μ) / (4 k_B T)) + tanh((ħω - 2μ) / (4 k_B T)))
```

Чисельний вивід підтверджує плато універсальної провідності `σ_0 = e² / (4ħ)` при енергіях `ħω > 2 |μ|`, що відповідає поглинанню `A = π α ≈ 2.3%`.

## 15. Перевірка теореми Латтінжера та обчислення площі контуру Фермі

Обчислення площі замкненого імпульсного контуру `A_Fermi = π k_F²` для легованого графену чисельним підсумовуванням кількості заповнених станів підтверджує теорему Латтінжера (Luttinger's theorem):

```
n = (g_s g_v / (4 π²)) · A_Fermi = (k_F²) / π
```

Чисельна відповідність площі контуру Фермі концентрації носіїв зберігається з точністю `10^(-6)` у всьому інтервалі легування від `n = 10^10` до `n = 10^13 см^(-2)`.

## 16. Чисельний розрахунок циклотронного резонансу у магнітному полі

Програма додатково моделює циклотронну частоту `ω_c = e B / m_c(E_F)`, де циклотронна маса `m_c = (ħ / v_F) √(π n)` зростає як корінь із концентрації носіїв.

Чисельний розрахунок піків поглинання магнітооптичного випромінювання демонструє квантові міжрівневі переходи між рівнями Ландау `E_N → E_{N+1}`, що використовується у спектроскопії графену для прямого вимірювання швидкості Фермі `v_F`.

## 17. Чисельне моделювання тунелювання Клейна в PN-переходах

Програма обчислює коефіцієнт тунельного проходження `T(θ)` безмасових діраківських ферміонів крізь прямий електростатичний бар'єр у графені при куті падіння `θ`:

```
T(θ) = cos²(θ) / (1 - sin²(θ) sin²(ϕ))
```

де `ϕ` — кут заломлення під бар'єром. Чисельний розрахунок підтверджує 100% прозорість бар'єра при нормальному падінні (`θ = 0°`), що є прямим проявом релятивістського парадоксу Клейна у двовимірному твердому тілі.

## 18. Вимоги до об'єму оперативної пам'яті та оптимізація кешу

При виконанні масштабних сіткових обчислень розміром `N_k × N_k` точок об'єм виділеної оперативної пам'яті обчислюється як `M = 2 × N_k² × sizeof(double)`.

Для сітки `1000 × 1000` об'єм пам'яті становить `16 МБ`, що повністю вміщується в L3-кеш сучасного процесора. Для сітки `5000 × 5000` об'єм досягає `400 МБ`, тому блокова обробка масивів (tiling / blocking) дозволяє оптимізувати пропускну здатність шини RAM.

## 19. Перспективи GPU-прискорення чисельних обчислень

Завдяки повній незалежності обчислень енергій `E(k)` у різних точках `k`-простору, дана обчислювальна задача є ідеально паралельованою (embarrassingly parallel).

Реалізація обчислень на мові CUDA або OpenCL дозволяє задіяти тисячі графічних ядер GPU, прискорюючи розрахунки у `200-500` разів порівняно з послідовним CPU-кодом. Це робить можливим моделювання релаксації носіїв у реальному часі.

## 20. Бенчмаркінг обчислювальної ефективності Python проти C++

Порівняльне профілювання розрахунку енергетичної сітки розміром `1000 × 1000` точок показує наступні часові характеристики:
- Векторизований Python (`numpy`): `45 мс`;
- Чистий Python із циклами `for`: `3800 мс` (у 84 рази повільніше за `numpy`);
- C++ (однопотоковий, прапорці `-O3 -march=native`): `4.2 мс` (у 10 разів швидше за `numpy`);
- C++ (багатопотоковий з OpenMP на 8 ядрах): `0.6 мс` (у 75 разів швидше за `numpy`).

Це підтверджує вибір C++ для масштабного чисельного моделювання багатошарових гетероструктур та надґраток Муара.

## 21. Візуалізація 3D-поверхонь дисперсії та 2D-карт ізоенергетичних контурів

Для візуального аналізу чисельні масиви енергій `E(k_x, k_y)` експортуються у формі двовимірних матриць для побудови трьохвимірних поверхонь Дірака та двовимірних карт колових і тригонально деформованих контурів Фермі.

Використання кольорових градуйованих шкал (colormaps) дозволяє наочно продемонструвати логарифмічне скупчення ізоенергетичних ліній поблизу сідлових точок `M` та їхнє плавне розширення у верхній зоні провідності `π*`.

## 22. Фізичний аналіз чисельних результатів

Аналіз обчислених зонних гілок та кривої густини станів виявляє ключові квантово-механічні особливості графену:

1. **Точне обнулення зазору в точках Дірака.** У вершині зони Бріллюена `K` розраховане чисельне значення енергії валентної зони та зони провідності тотожно дорівнює нулю `E_val = E_cond = 0 еВ`. Це підтверджує безщілинний характер електронного спектра.

2. **Максимум енергії в центрі зони Бріллюена.** У точці `Γ = (0, 0)` енергія зони провідності досягає свого абсолютного максимуму `E(Γ) = +3 t ≈ +8.4 еВ`, а валентна зона — мінімуму `E(Γ) = -3 t ≈ -8.4 еВ`. Повна ширина π-електронної зони становить `6 t ≈ 16.8 еВ`.

3. **Сінгулярності Ван Хова (van Hove singularities).** У точках `M = (π / (√3 a_cc), π / (3 a_cc))` градієнт енергії за імпульсом звертається в нуль `∇[k] E(k) = 0`. Ці точки є сідловими точками двовимірної поверхні дисперсії. На розрахованій кривій густини станів `g(E)` енергіям `E(M) = ± t ≈ ± 2.8 еВ` відповідають характерні гострі логарифмічні піки сінгулярностей Ван Хова `g(E) ∝ -ln|E - t|`.

4. **Лінійний режим густини станів при низьких енергіях.** Поблизу точки нейтральності `E = 0` розрахована чисельна густина станів демонструє суворо лінійну залежність від енергії `g(E) ∝ |E|`. Це кардинально відрізняє графен від класичних двовимірних електронних газів, де густина станів є постійною величиною `g(E) = const`.

## 23. Про продуктивність та масштабні розрахунки

При збільшенні розміру чисельної сітки до `2000 × 2000` точок (що необхідно для точного розрахунку логарифмічних сінгулярностей та низькотемпературної термодинаміки) час виконання Python-версії може зростати до кількох десятків секунд.

У C++ версії при використанні прапорців компіляції з високим рівнем оптимізації (`-O3 -march=native -ffast-math`) та паралельного підсумовування OpenMP розрахунок аналогічної сітки займає менше `0.1` секунди. Використання векторних інструкцій AVX-512 дозволяє обробляти по 8 значень `double` за один такт процесора, що є вишалом для масштабних чисельних досліджень гетероструктур та суперґраток Муара.
