# 📋 Довідник спектрометрії FMR: експериментальні методики та параметри тракту

Цей довідник систематизує методи НВЧ-спектрометрії феромагнітного резонансу — від класичних резонаторних установок до копланарних хвилеводів VNA-FMR — з описом вимірювальних параметрів, матриць розсіяння та джерел похибок.

---

### 1. Порівняльний аналіз експериментальних методир FMR

При виборі методу досліджень феромагнітного резонансу експериментатор спирається на вимоги до чутливості, частотного діапазону та геометрії зразка. Нижче наведено детальний огляд трьох головних класів FMR-спектрометрів.

#### 1. Резонаторний FMR (Cavity FMR)
У класичних резонаторних спектрометрах зразок розміщується всередині високодобротного прямокутного чи циліндричного НВЧ-резонатора (`Q ≈ 1000–5000`). Частота генератора зафіксована на моді резонатора (найчастіше X-діапазон 9.5 ГГц або Q-діапазон 35 ГГц). Сканування відбувається шляхом плавного вимірювання зовнішнього магнітного поля `H₀`. Для досягнення надвисокої чутливості магнітне поле модулюється низькою частотою (`100 кГц`), а сигнал детектується за допомогою синфазного підсилювача (Lock-in amplifier). Резонаторний FMR дає першу чисельну похідну лінії поглинання `dP/dH`. Він виступає найчутливішим методом для монокристалів та мікрозразків, проте обмежений строго фіксованими частотами резонатора.

#### 2. Широкосмуговий VNA-FMR (CPW)
Зразок укладається поверх копланарного хвилеводу (Coplanar Waveguide, CPW), підключеного до векторного аналізатора мереж (Vector Network Analyzer, VNA). Метод дозволяє проводити вимірювання в неперервному діапазоні частот від `100 МГц` до `50 ГГц`. Вимірюваними величинами є комплексні параметри розсіяння матриці `S₂₁` (коефіцієнт передачі) та `S₁₁` (коефіцієнт відбиття). Отримання залежності `ΔH(f)` у широкому діапазоні частот робить VNA-FMR основним ідивідуальним методом вимірювання параметра згасання Гільберта `α` та неоднорідного розширення `ΔH₀` для тонких плівок.

#### 3. Спін-обертальний ST-FMR (Spin-Torque FMR)
Використовується для нанорозмірних гетероструктур та мікромостиків. Високочастотний струм пропускається безпосередньо через наноструктуру, викликаючи прецесію намагніченості завдяки спін-орбітальним моментам (SOT/STT). Коли частота струму збігається з частотою прецесії, динамічний опір зразка змішується з НВЧ-струмом, ґенеруючи постійну напругу `V_DC`. Цей метод є унікальним інструментом для дослідження спін-орбітальної фізики у MRAM-структурах.

| Параметр / Характеристика | Резонаторний FMR (Cavity FMR) | Широкосмуговий VNA-FMR (CPW) | Спін-обертальний ST-FMR |
| :--- | :--- | :--- | :--- |
| **Фіксований параметр** | Частота `f` (X, Q-band) | Поле `H₀` або частота `f` | Частота `f` |
| **Параметр сканування** | Статичне поле `H₀` | Поле `H₀` або частота `f` | Статичне поле `H₀` |
| **Частотний діапазон** | 9.5 ГГц (X), 35 ГГц (Q) | 100 МГц — 50 ГГц (неперервний) | 1 ГГц — 30 ГГц |
| **Детектована величина** | Похідна `dP / dH` (Lock-in) | Комплексні `S₂₁`, `S₁₁` (ВНА) | Постійна напруга `V_DC` (змішування) |
| **Добротність системи Q** | Висока (`Q ≈ 1000–5000`) | Низька (`Q ≈ 1`) | Не застосовується |
| **Мінімальний об'єм зразка** | `~0.1 мм³` (монокристал) | Тонка плівка `> 1 мм²` | Мікромостік `< 10 мкм²` |
| **Первинне застосування** | Прецизійна лінія `ΔH`, YIG | Динаміка `α(f)`, гетероструктури | Спін-орбітальні моменти (SOT) |

### 2. Топологія копланарних хвилеводів (CPW) для VNA-FMR

Копланарний хвилевід являє собою трипровідникову металеву структуру, нанесену на діелектричну підкладку (ситал, кварц або арсенід ґалію). Вона складається з центральної струмоведучої жили шириною `w` та двох бічних заземлених площин, відокремлених зазором `s`.

Характеристичний хвильовий опір CPW проектується рівним `Z₀ = 50 Ом` для узгодження з трактом ВНА:

```
Z₀ = ( 30 · π / √ε_eff ) · ( K(k') / K(k) )
```

де `k = w / (w + 2 s)`, `K(k)` — повний еліптичний інтеграл першого роду, а `ε_eff` — ефективна діелектрична проникність підкладки.

Конструкція CPW обирається виходячи з розміру зразка:
* **Широка жила (`w = 200–500 мкм`):** Забезпечує високу однорідність НВЧ-магнітного поля `h_RF` по площі плівки, ідеально підходить для зразків розміром `3×3 мм²`.
* **Вузька мікрожила (`w = 10–50 мкм`):** Концентрує НВЧ-магнітне поле, створюючи високу амплітуду `h_RF` до `5–10 Ое`, що необхідно для вимірювання мікроструктур або вивчення нелінійних FMR-явищ.

Основними елементами високочастотного тракту VNA-FMR є:
1. **Калібрувальні підкладки та зондові станції:** Використовуються високочастотні GSG-зонди (Ground-Signal-Ground) із кроком між контактами `100–250 мкм` для подачі НВЧ-сигналу без перевідбиттів.
2. **Атенюатори та високочастотні підсилювачі:** Пристрої регулювання рівня НВЧ-потужності для відсутності нелінійного розширення лінії FMR при високих рівнях збудження.
3. **Кріогенні лінії передачі:** Напівжорсткі коаксіальні кабелі з берилієвої бронзи та сталі для проведення температурних вимірювань FMR у гелієвих кріостатах від `1.8 K` до `400 K`.

### 3. Експериментальні параметри та фізичні величини

Систематизація основних величин, що використовуються при аналізі FMR-спектрів, із зазначенням одиниць вимірювання та типових діапазонів для стандартних матеріалів:

| Символ | Фізична величина | Одиниці СІ | Одиниці СГС / Експеримент | Типові значення (YIG / Permalloy) |
| :--- | :--- | :--- | :--- | :--- |
| `M_s` | Намагніченість насичення | А / м | Гаус (Гс) / кГс | `140 кА/м` (YIG), `800 кА/м` (Py) |
| `g` | Фактор спектроскопічного розщеплення | безрозмірна | безрозмірна | `2.00–2.01` (YIG), `2.08–2.12` (Py) |
| `γ / (2π)` | Гіромагнітне співвідношення | ГГц / Тл | МГц / Ое | `28.0 ГГц/Тл` (`2.80 МГц/Ое`) |
| `α` | Параметр згасання Гільберта | безрозмірна | безрозмірна | `3·10⁻⁵` (YIG), `0.007` (Py) |
| `ΔH` | Ширина лінії поглинання (FWHM) | А / м / Тл | Ерстед (Ое) / мТл | `0.5 Ое` (YIG), `15–40 Ое` (Py) |
| `ΔH_pp` | Ширина лінії між екстремумами похідної | А / м / Тл | Ерстед (Ое) | `ΔH_pp = ΔH / √3` |
| `H_k` | Поле магнітної анізотропії | А / м / Тл | Ерстед (Ое) | `0–50 Ое` (кубічна), `>1 кОе` (уніаксіальна) |
| `S₂₁` | Коефіцієнт проходження НВЧ-сигналу | дБ / комплексне | безрозмірна | Амплітуда і фаза хвилі у CPW |

### 4. Протоколи калібрування VNA та обробка комплексних S-параметрів

Для усунення власних систематичних втрат ВНА та високочастотних кабелів використовується стандартне **SOLT-калібрування (Short-Open-Load-Thru)** або **TRL-калібрування (Thru-Reflect-Line)** безпосередньо на площині GSG-зондів.

Під час вимірювань за допомогою копланарного хвилеводу (CPW) та векторного аналізатора мереж (VNA) виміряний параметр `S₂₁(f, H)` містить сильний фоновий внесок немагнітних втрат НВЧ-тракту (опір кабелів, роз'ємів, діелектрика підкладки).

Для вилучення чистого магнітного сигналу застосовують протокол **фонового віднімання**:

1. **Референсне віднімання (Reference Subtraction):**
   Вимірюється матриця `S₂₁(f, H_ref)` при високому статичному полі `H_ref ≫ H_r`, де магнітний резонанс витіснений за межі частотного діапазону. Чистий резонансний сигнал обчислюється як:
   ```
   ΔS₂₁(f, H) = S₂₁(f, H) - S₂₁(f, H_ref)
   ```

2. **Відносне ділення (Complex Ratio):**
   Альтернативний метод полягає в діленні комплексного спектра на референсний: `S₂₁_norm(f, H) = S₂₁(f, H) / S₂₁(f, H_ref)`. Це дозволяє усунути амплітудну нерівномірність НВЧ-кабелів.

3. **Розділення фази та комплексної сприйнятливості:**
   Оскільки НВЧ-хвиля набуває фазового зсуву `φ(f)` вздовж лінії передачі, виміряна різниця `ΔS₂₁` являє собою суміш уявної та дійсної частин сприйнятливості:
   ```
   ΔS₂₁(H) = C · exp(i φ) · [ χ'(H) - i χ''(H) ]
   ```

4. **Корекція фазового кута `φ`:**
   Параметр `φ` підбирають так, щоб симетрична лоренцівська крива відповідала поглинанню `χ''(H)`, а антисиметрична — дисперсії `χ'(H)`.

5. **Метод двох полів (Field-Step Ratio):**
   Для усунення низькочастотних дрейфів ВНА застосовується вимірювання `S₂₁(H)` при двох близьких значеннях полів `H` та `H + ΔH_step`. Це створює аналог модуляційного детектування, підвищуючи співвідношення сигнал/шум у десятки разів.

### 5. Методика кріогенних та температурних вимірювань FMR

Температурні залежності частоти FMR та ширини лінії `ΔH(T)` дають важливу інформацію про фазові переходи, температурну динаміку намагніченості `M_s(T)` та загартування спін-орбітальних взаємодій.

Проведення вимірювань у кріостатах замкненого циклу (Gifford-McMahon) або рідинних гелієвих кріостатах вимагає дотримання особливих технологічних правил:
* **Монтаж зразка (Flip-Chip Technique):** Тонкоплівковий зразок укладається плівкою донизу безпосередньо на центральну жилу CPW. Для забезпечення теплового контакту та відсутності повітряного зазору використовується кріогенне мастило Apiezon N або вакуумний лак GE Varnish.
* **Термостабілізація та термопари:** Датчик температури (Cernox або Platinum RTD) монтується безпосередньо на масивній мідній основі CPW-плати.
* **Урахування температурного розширення кабелів:** При охолодженні від `300 K` до `4.2 K` фазовий зсув НВЧ-кабелів змінюється через зміну їхньої довжини. Калібрування референсної лінії `S₂₁(H_ref)` необхідно проводити повторно при кожній фіксованій температурі `T`.

### 6. Типові джерела похибок вимірювань та методи їх нейтралізації

При проведенні високоточних спектроскопічних вимірювань FMR виникають кілька категорій систематичних похибок:

1. **Неоднорідність статичного магнітного поля `H₀`:**
   Градієнт поля по об'єму зразка викликає штучне розширення лінії `ΔH` та спотворення форми піку. Для нейтралізації похибки вимагається однорідність поля `ΔH₀ / H₀ < 10⁻⁵` у робочому об'ємі резонатора чи CPW.
2. **Ефект скінченної товщини (неоднорідні спінові хвилі / моди Прінса):**
   У товстих плівках (`t > 100 нм`) поруч із головним піком Кіттеля збуджуються стоячі спінові хвилі за товщиною (PSSW), які ускладнюють інтерпретацію спектра. Для дослідження чистого FMR використовують плівки товщиною `t < 50 нм`.
3. **НВЧ-перегрів зразка (поглинання великої потужності):**
   Високий рівень потужності `P_RF > 10 мВт` викликає локальний нагрів зразка, що зменшує намагніченість насичення `M_s(T)` та зсуває резонансне поле `H_r`. У вимірюваннях рекомендується підтримувати рівень потужності `P_RF < 1 мВт`.
4. **Неправильне розмагнічувальне факторне нормування:**
   Використання формул для нескінченної плівки до квадратних micro-pathed елементів з малим відношенням сторін призводить до похибки обчислення `M_s` до 15–20%. Для мікроструктур слід застосовувати чисельні розрахунки демагнетизуючих факторів Ахароні.
