# 🧮 Рівняння дифузії-рекомбінації: математичний вивід профілю носіїв

Ця вставка містить строгий математичний вивід диференціального рівняння переносу неосновних носіїв у стаціонарному режимі. Ми виведемо просторовий профіль розмиття надлишкової концентрації `Δn(x)`, покажемо походження дифузійної довжини `L = √(D · τ)` як власного значення диференціального оператора, виведемо співвідношення Ейнштейна з умов термодинамічної рівноваги та розрахуємо точний дифузійний струм і накопичений об'ємний заряд для різних граничних умов.

### 1. Перехід від тривимірного рівняння неперервності до одновимірного

У загальному тривимірному випадку локальний баланс надлишкових неосновних носіїв (наприклад, дірок у напівпровіднику n-типу `Δp(x, y, z, t)`) описується векторним рівнянням неперервності:

```
∂(Δp) / ∂t = - (1 / q) · (∇ · J_p) - U_p + G_p
```

де:
- `q` — елементарний заряд;
- `J_p` — вектор густини струму дірок;
- `∇ · J_p = (∂J_px/∂x) + (∂J_py/∂y) + (∂J_pz/∂z)` — дивергенція векторного поля струму;
- `U_p` — швидкість об'ємної рекомбінації носіїв;
- `G_p` — швидкість об'ємної генерації носіїв зовнішнім впливом (наприклад, світлом).

Якщо напівпровідникова структура є плоскопаралельною (як у площинних діодах, транзисторах чи сонячних батареях), площа планарного контакту значно перевищує товщину приладу. У цьому випадку градієнтами уздовж осей `y` та `z` можна знехтувати (`∂/∂y = 0`, `∂/∂z = 0`), а дивергенція спрощується до одновимірної похідної `∂J_px / ∂x`.

За низького рівня інжекції, коли надлишкова концентрація неосновних носіїв набагато менша за концентрацію основних носіїв (`Δp << n₀`), швидкість рекомбінації описується лінійним законом з постійним часом життя `τ_p`:

```
U_p = Δp / τ_p
```

Якщо у нейтральній області напівпровідника електричне поле відсутнє або нехтувно мале (`E ≈ 0`), основним механізмом переміщення дірок є **дифузія**. За першим законом Фіка густина дифузійного струму дорівнює:

```
J_p(x) = - q · D_p · (d(Δp) / dx)
```

знак «мінус» підкреслює, що дифузійний потік спрямований від ділянок з високою концентрацією до ділянок з низькою концентрацією.

### 2. Співвідношення Ейнштейна з умов термодинамічної рівноваги

Перед тим як виводити рівняння дифузії, доведемо фундаментальний зв'язок між коефіцієнтом дифузії `D` та рухливістю `μ`. 

У стані термодинамічної рівноваги за відсутності зовнішнього джерела живлення повний дірковий струм у напівпровіднику повинен бути строго нульовим у кожній точці простору (`J_p = 0`). Повний струм складається з дрейфової та дифузійної компонент:

```
J_p = q · μ_p · p(x) · E(x) - q · D_p · (dp / dx) = 0
```

У стаціонарному потенціальному полі `E(x) = - dφ/dx` розподіл концентрації носіїв підкоряється класичній статистиці Больцмана:

```
p(x) = p₀ · exp( - q · φ(x) / (k_B · T) )
```

Взьмемо похідну від концентрації `p(x)` по координаті `x`:

```
dp / dx = p₀ · exp( - q · φ(x) / (k_B · T) ) · [ - (q / (k_B · T)) · (dφ / dx) ]    [похідна складеної функції]
        = p(x) · [ (q / (k_B · T)) · E(x) ]                                        [підставили p(x) та E = -dφ/dx]
```

Підставимо отриману похідну `dp/dx` у вираз для повного струму `J_p = 0`:

```
q · μ_p · p(x) · E(x) - q · D_p · [ p(x) · (q / (k_B · T)) · E(x) ] = 0             [рівновага струмів]
q · p(x) · E(x) · [ μ_p - D_p · (q / (k_B · T)) ] = 0                              [винесли спільний множник]
```

Оскільки концентрація `p(x)` та поле `E(x)` не є тотожними нуля, вираз у дужках мусить дорівнювати нулю:

```
μ_p = D_p · (q / (k_B · T))  =>  D_p / μ_p = k_B · T / q = V_T
```

Це і є **співвідношення Ейнштейна**, яке доводить, що коефіцієнт дифузії та рухливість мають єдину мікроскопічну природу — тепловий хаотичний рух носіїв та розсіяння на ґратці.

### 3. Вивід стаціонарного рівняння дифузії

Підставимо закон Фіка для струму у стаціонарне рівняння неперервності (`∂(Δp)/∂t = 0`) за відсутності об'ємної генерації (`G_p = 0` при `x > 0`):

```
0 = - (1 / q) · d/dx [ - q · D_p · (d(Δp) / dx) ] - (Δp / τ_p)
```

Вважаючи коефіцієнт дифузії `D_p` постійним уздовж зразка, виносимо його за знак похідної:

```
D_p · (d²(Δp) / dx²) - (Δp / τ_p) = 0             [підставили похідну від J_p]
d²(Δp) / dx² - (1 / (D_p · τ_p)) · Δp = 0        [поділили на D_p]
```

Уводимо позначення для фундаментального просторового масштабу `L_p ≡ √(D_p · τ_p)`:

```
d²(Δp) / dx² - (1 / L_p²) · Δp = 0
```

Це лінійне однорідне диференціальне рівняння другого порядку зі сталими коефіцієнтами.

### 4. Аналітичний розв'язок для напівнескінченного кристала

Характеристичне рівняння для даної диференціальної операції має вигляд:

```
k² - (1 / L_p²) = 0             [характеристичне рівняння]
k = ± (1 / L_p)                 [корені характеристичного рівняння]
```

Отже, загальний розв'язок виражається сумою двох експонент:

```
Δp(x) = C₁ · exp(-x / L_p) + C₂ · exp(x / L_p)
```

Для визначення довільних сталих `C₁` та `C₂` застосуємо граничні умови для напівнескінченного зразка (`0 ≤ x < ∞`):

1. **Гранична умова на нескінченності (`x → ∞`):**
   Концентрація надлишкових носіїв не може безмежно зростати у товщі матеріалу:
   ```
   lim_{x → ∞} Δp(x) = 0  =>  C₂ = 0
   ```
   оскільки `exp(x / L_p) → ∞`, стала `C₂` мусить бути строго нульовою.

2. **Гранична умова на поверхні інжекції (`x = 0`):**
   Концентрація на межі задана зовнішнім джерелом (наприклад, прямим зміщенням p-n переходу):
   ```
   Δp(0) = Δp₀  =>  C₁ = Δp₀
   ```

Таким чином, отримуємо частинний розв'язок — **експоненціальний розподіл надлишкових носіїв**:

```
Δp(x) = Δp₀ · exp(-x / L_p)
```

На відстані `x = L_p` надлишкова концентрація зменшується у `e ≈ 2.718` раза:
```
Δp(L_p) = Δp₀ / e ≈ 0.368 · Δp₀
```

### 5. Розрахунок повного накопиченого заряду

Інжектовані неосновні носії створюють у напівпровіднику об'ємний надлишковий заряд. Знайдемо повний заряд дірок `Q_p` на одиницю площі поперечного перерізу шляхом інтегрування концентрації по всій глибині зразка:

```
Q_p = q · ∫₀^∞ Δp(x) dx                        [означення повного накопиченого заряду]
    = q · Δp₀ · ∫₀^∞ exp(-x / L_p) dx          [підставили експоненціальний профіль Δp(x)]
    = q · Δp₀ · [ - L_p · exp(-x / L_p) ]₀^∞   [взяли первісну від експоненти]
    = q · Δp₀ · (0 - (- L_p))                  [підставили границі інтегрування]
    = q · Δp₀ · L_p                            [обчислили кінцеве значення]
```

Отже, повний накопичений заряд дорівнює добутку поверхневого заряду `q · Δp₀` на дифузійну довжину `L_p`.

### 6. Густина інжекційного дифузійного струму

Знайдемо густину струму дірок, який необхідно подавати на межу `x = 0` для підтримки стаціонарного профілю концентрації. Диференціюємо профіль `Δp(x)`:

```
J_p(0) = - q · D_p · (d(Δp) / dx)|_{x=0}                  [закон Фіка на межі x = 0]
       = - q · D_p · [ - (Δp₀ / L_p) · exp(-0 / L_p) ]     [взяли похідну від Δp(x)]
       = q · (D_p / L_p) · Δp₀                             [спростили знаки та exp(0) = 1]
```

Ураховуючи, що `L_p = √(D_p · τ_p)`, вираз для густини струму можна переписати через час життя:

```
J_p(0) = q · (D_p / √(D_p · τ_p)) · Δp₀       [підставили L_p = √(D_p · τ_p)]
       = q · √(D_p / τ_p) · Δp₀               [скоротили D_p / √D_p = √D_p]
       = (q · Δp₀ · L_p) / τ_p                [помножили і поділили на √D_p]
       = Q_p / τ_p                            [урахували Q_p = q · Δp₀ · L_p]
```

Ця формула має прозорий фізичний зміст: **струм інжекції, що входить у напівпровідник, точно дорівнює заряду, що рекомбінує в об'ємі за одиницю часу `τ_p`**.

### 7. Випадок скінченної товщини зразка (тонка база W << L)

Якщо напівпровідникова пластина має скінченну товщину `W` (наприклад, база біполярного транзистора), гранична умова на правому краї `x = W` змінюється. Якщо правий контакт є ідеальним стоком для носіїв (`Δp(W) = 0`, як на зворотно зміщеному колекторному переході):

Застосуємо граничні умови `Δp(0) = Δp₀` та `Δp(W) = 0` до загального розв'язку:

```
C₁ + C₂ = Δp₀                                             [гранична умова при x = 0]
C₁ · exp(-W / L_p) + C₂ · exp(W / L_p) = 0                [гранична умова при x = W]
```

Розв'язуючи цю систему алгебраїчних рівнянь відносно `C₁` та `C₂`, отримуємо профіль через гіперболічний синус:

```
Δp(x) = Δp₀ · [ sinh((W - x) / L_p) / sinh(W / L_p) ]
```

Для тонкої бази, де `W << L_p`, ми можемо розкласти гіперболічний синус у ряд Тейлора (`sinh(z) = z + z³/6 + ... ≈ z` при `z << 1`):

```
Δp(x) ≈ Δp₀ · [ ((W - x) / L_p) / (W / L_p) ]             [лінійна апроксимація для W << L]
      = Δp₀ · (1 - x / W)
```

У цьому граничному випадку профіль концентрації стає **лінійним**, а рекомбінація в об'ємі бази майже повністю зникає. 

Обчислимо базовий транспортний фактор `α_T`, який описує частку інжектованого струму, що досягає колектора при `x = W`:

```
α_T = J_p(W) / J_p(0)
    = [ - q · D_p · (d(Δp)/dx)|_{x=W} ] / [ - q · D_p · (d(Δp)/dx)|_{x=0} ]
    = 1 / cosh(W / L_p)                                   [диференціювання гіперболічного синуса]
```

Розкладаючи гіперболічний косинус у ряд Тейлора (`cosh(z) ≈ 1 + z²/2`), отримуємо фундаментальну формулу втрат у базі біполярного транзистора:

```
α_T ≈ 1 - (W² / (2 · L_p²))
```

Саме цей результат пояснює, чому для досягнення `α_T ≈ 0.99` товщина бази `W` повинна бути принаймні у 10 разів меншою за дифузійну довжину `L_p`.

### 8. Оптична генерація світлом G(x) = G₀ · exp(-α · x)

Розглянемо випадок, коли у товщі напівпровідника діє об'ємна фотогенерація світлом з коефіцієнтом поглинання `α`. Неоднорідне стаціонарне рівняння дифузії має вигляд:

```
D_p · (d²(Δp) / dx²) - (Δp / τ_p) + G₀ · exp(-α · x) = 0
d²(Δp) / dx² - (1 / L_p²) · Δp = - (G₀ / D_p) · exp(-α · x)
```

Частинний розв'язок неоднорідного рівняння шукають у вигляді `Δp_p(x) = A · exp(-α · x)`. Підставляючи `Δp_p(x)` у диференціальне рівняння:

```
A · α² · exp(-α · x) - (A / L_p²) · exp(-α · x) = - (G₀ / D_p) · exp(-α · x)
A · (α² - 1 / L_p²) = - G₀ / D_p
A = (G₀ / D_p) / (1 / L_p² - α²) = (G₀ · τ_p) / (1 - α² · L_p²)
```

Отже, повний розв'язок для напівнескінченного кристала з пасивованою поверхнею та фотогенерацією описується сумою власної та вимушеної експонент:

```
Δp(x) = C₁ · exp(-x / L_p) + [ (G₀ · τ_p) / (1 - α² · L_p²) ] · exp(-α · x)
```

Ця формула лежить в основі розрахунку спектральної чутливості та квантового виходу сонячних батарей і фотодіодів.
