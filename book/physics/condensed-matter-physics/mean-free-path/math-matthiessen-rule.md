# 🧮 Виведення правила Маттіссена та транспортного часу релаксації

Ця математична вставка містить строге розгортання квантової та статистичної теорії транспорту носіїв у кристалах. У ній наведено виведення рівняння транспорту Больцмана в наближенні часу релаксації, математично обґрунтовано різницю між квантовим часом життя стану та транспортним часом релаксації через кутовий інтегральний фактор `(1 - cos θ)`, доведено адитивність частот розсіювання Маттіссена на основі Золотого правила Фермі та розглянуто математичні умови порушення цього правила.

---

### 1. Рівняння транспорту Больцмана та стаціонарний стан

Динаміка ансамблю носіїв заряду описується функцією розподілу `f(r, k, t)`, яка визначає ймовірність знаходження електрона у фазовому об'ємі `d³r d³k / (2π)³` коло точки `(r, k)`.

Відповідно до теореми Ліувілля про збереження фазового об'єму для нестискуваної рідини, повна похідна функції розподілу за часом з урахуванням зіткнень задовольняє кінетичне рівняння Больцмана:

```
df/dt = ∂f/∂t + (dr/dt) · ∇_r f + (dk/dt) · ∇_k f = (∂f/∂t)_coll
```

У стаціонарному за часом (`∂f/∂t = 0`) та просторово однорідному середовищі (`∇_r f = 0`) під дією зовнішнього постійного електричного поля `E` маємо:

```
(dk/dt) = - e · E / ħ
- (e · E / ħ) · ∇_k f = (∂f/∂t)_coll
```

Для слабких електричних полів функція розподілу лише незначно відхиляється від рівноважної функції Фермі — Дірака `f_0(E(k))`:

```
f(k) = f_0(E(k)) + f_1(k),   де |f_1(k)| ≪ f_0(E(k))
```

де рівноважна функція має вигляд:

```
f_0(E) = 1 / (exp((E - E_F) / (k_B · T)) + 1)
```

У **наближенні часу релаксації** (*relaxation time approximation*) припускається, що інтеграл зіткнень прагне відновити рівноважний розподіл `f_0` зі швидкістю, пропорційною величині відхилення `f_1`:

```
(∂f/∂t)_coll = - (f(k) - f_0(k)) / τ(k) = - f_1(k) / τ(k)
```

Градієнт рівноважної функції за імпульсом обчислюється через ланцюгове правило диференціювання:

```
∇_k f_0 = (∂f_0 / ∂E) · ∇_k E = (∂f_0 / ∂E) · ħ · v(k)
```

Підставляючи цей вираз у ліву частину рівняння Больцмана і нехтуючи малими членами другого порядку `∇_k f_1`, отримуємо лінеаризоване рівняння:

```
- (e · E / ħ) · (∂f_0 / ∂E) · ħ · v(k) = - f_1(k) / τ(k)
f_1(k) = e · τ(k) · (v(k) · E) · (∂f_0 / ∂E)
```

Ця поправка `f_1(k)` є асиметричною відносно напрямку електричного поля `E` і описує зсув сфери Фермі в імпульсному просторі, що створює макроскопічний дрейфовий струм.

### 2. Квантовий інтеграл зіткнень та виведення транспортного часу `τ_tr`

Точний квантовомеханічний інтеграл зіткнень описує баланс прибутку та убутку частинок у стан `k` за рахунок переходу з/у всі інші квантові стани `k'`:

```
(∂f/∂t)_coll = ∑_k' [ W(k', k) · f(k') · (1 - f(k)) - W(k, k') · f(k) · (1 - f(k')) ]
```

де `W(k, k')` — ймовірність переходу зі стану `k` у стан `k'` за одиницю часу, а множники `(1 - f)` враховують принцип заборони Паулі для кінцевих станів.

Для пружного розсіювання (`E(k) = E(k')`) квантовий принцип детальної рівноваги стверджує симетрію ймовірностей: `W(k, k') = W(k', k)`. Нелінійні члени `f(k')·f(k)` взаємно скорочуються, і інтеграл спрощується до лінійної форми:

```
(∂f/∂t)_coll = ∑_k' W(k, k') · [ f_1(k') - f_1(k) ]
```

Підставимо у цей вираз розраховану вище поправку `f_1(k) = e · τ_tr · (v(k) · E) · (∂f_0 / ∂E)`:

```
(∂f/∂t)_coll = e · (∂f_0 / ∂E) · τ_tr · ∑_k' W(k, k') · [ (v(k') · E) - (v(k) · E) ]
```

Для параболічної ізотропної зони швидкість електрона напрямлена вздовж хвильового вектора: `v(k) = ħ·k / m*`. Позначимо кут між початковим імпульсом `k` та розсіяним імпульсом `k'` як `θ`.

При інтегруванні по азимутальному куту `φ` перпендикулярна складова вектора `v(k')` обертається в нуль, а паралельна проекція дорівнює:

```
v(k') · E = |v(k)| · |E| · cos θ
(v(k') · E) - (v(k) · E) = - (v(k) · E) · (1 - cos θ)
```

Підставляючи цю проекцію в інтеграл зіткнень, маємо:

```
(∂f/∂t)_coll = - e · (∂f_0 / ∂E) · (v(k) · E) · τ_tr · ∑_k' W(k, k') · (1 - cos θ)
```

Порівнюючи це з феноменологічним виразом `(∂f/∂t)_coll = - f_1(k) / τ_tr`, негайно отримуємо математичне визначення **транспортного часу релаксації `τ_tr`**:

```
1 / τ_tr = ∑_k' W(k, k') · (1 - cos θ)
```

Переходячи від дискретної суми до інтегрування по кутах у тривимірному просторі:

```
1 / τ_tr = ∫₀^π W(θ) · (1 - cos θ) · 2π · sin θ dθ
```

З іншого боку, **повний квантовий час життя стану `τ_0`** (або час релаксації квантової фази), який визначає розширення квантових рівнів та вимірюється в експериментах із кутовою фотоемісійною спектроскопією (ARPES) чи квантових осциляціях де Гааза — ван Альфена, дорівнює повній сумі ймовірностей без кутового фактора:

```
1 / τ_0 = ∑_k' W(k, k') = ∫₀^π W(θ) · 2π · sin θ dθ
```

Звідси випливає фундаментальне математичне співвідношення:

```
1 / τ_tr = (1 / τ_0) · ⟨1 - cos θ⟩
```

#### Анатомія фактора `(1 - cos θ)`
1. **Ізотропне розсіювання** (`W(θ) = const`, наприклад, на короткосяжних точкових дефектах чи ізотропних акустичних фононах):
```
⟨cos θ⟩ = ∫₀^π cos θ · sin θ dθ = 0   ⟹   1 / τ_tr = 1 / τ_0
```
У цьому випадку кожен акт розсіювання повністю знищує пам'ять про початковий дрейфовий імпульс.

2. **Малокутове розсіювання** (`W(θ)` має гострий пік при `θ → 0`, наприклад, на кулонівських потенціалах з великим радіусом екранування чи м'яких фононах за низьких температур):
```
cos θ ≈ 1 - θ² / 2   ⟹   (1 - cos θ) ≈ θ² / 2 ≪ 1
1 / τ_tr = (1 / τ_0) · ⟨θ² / 2⟩ ≪ 1 / τ_0
```
Малокутові зсуви часто збивають квантову фазу хвилі (малий `τ_0`), але майже не гальмують дрейфовий струм, забезпечуючи тривалий транспортний час `τ_tr ≫ τ_0`.

### 3. Строге виведення правила Маттіссена із Золотого правила Фермі

Правило Маттіссена визначає сумативність частот розсіювання від різних незалежних джерел.

Згідно з квантовомеханічною теорією збурень (Золоте правило Фермі), ймовірність переходу носія зі стану `k` у стан `k'` під дією оператора збурення `V` дорівнює:

```
W(k, k') = (2π / ħ) · |⟨k'| V |k⟩|² · δ(E(k') - E(k))
```

Нехай у кристалі діють два різні джерела розсіювання, які описуються операторами збурення `V_ph` (фонони) та `V_imp` (домішки). Загальний оператор збурення дорівнює:

```
V_total = V_ph + V_imp
```

Квадрат матричного елемента сумарного збурення розкривається як:

```
|⟨k'| V_total |k⟩|² = |⟨k'| V_ph |k⟩ + ⟨k'| V_imp |k⟩|²
                    = |⟨k'| V_ph |k⟩|² + |⟨k'| V_imp |k⟩|² 
                      + 2 · Re [ ⟨k'| V_ph |k⟩* · ⟨k'| V_imp |k⟩ ]
```

Для статично некорельованих джерел розсіювання (позиції іонізованих домішок у ґратці є випадковими і не залежать від миттєвих теплових зсувів атомів ґратки) усреднення по просторових конфігураціях перетворює перехресний інтерференційний член у нуль:

```
⟨ ⟨k'| V_ph |k⟩* · ⟨k'| V_imp |k⟩ ⟩_ens = 0
```

Отже, сумарна ймовірність переходу строго розпадається на суму ймовірностей:

```
W_total(k, k') = W_ph(k, k') + W_imp(k, k')
```

Підставляючи цей вираз у математичний інтеграл для транспортного часу релаксації, отримуємо:

```
1 / τ_tr,total = ∑_k' [ W_ph(k, k') + W_imp(k, k') ] · (1 - cos θ)
               = ∑_k' W_ph(k, k') · (1 - cos θ) + ∑_k' W_imp(k, k') · (1 - cos θ)
```

Звідси випливає класичне **правило додавання частот розсіювання Маттіссена**:

```
1 / τ_total = 1 / τ_ph + 1 / τ_imp
```

Помноживши обидві частини на `m* / (n · e²)`, отримуємо адитивність питомих опорів:

```
m* / (n · e² · τ_total) = m* / (n · e² · τ_ph) + m* / (n · e² · τ_imp)
ρ_total = ρ_ph + ρ_imp
```

### 4. Фізичні та математичні причини порушення правила Маттіссена

На практиці правило Маттіссена часто порушується, тобто `ρ_total > ρ_ph + ρ_imp` або `ρ_total < ρ_ph + ρ_imp`. Математичний аналіз виділяє чотири основні механізми таких відхилень:

#### 1. Анізотропія розсіювання по поверхні Фермі (Ефект Мотта — Блейкмора)
Рівняння Больцмана є функціональним рівнянням. Якщо фононне розсіювання є сильно анізотропним (наприклад, відбувається лише у певних ділянках сфери Фермі — hot spots), а домішкове розсіювання є ізотропним, то поправка до функції розподілу `f_1(k)` має різну кутову симетрію для кожного механізму окремо.

Загальний опір описується варіаційним принципом Зейтца — Колера:
```
ρ_total ≤ ρ_ph + ρ_imp
```
Сумарний опір завжди є меншим або дорівнює простій сумі, оскільки наявність ізотропного домішкового розсіювання згладжує анізотропію фононного розподілу.

#### 2. Двохзонна провідність (Модель Мотта для перехідних d-металів)
У перехідних металах (Pt, Pd, Ni) провідність забезпечується легкими s-електронами, які можуть розсіюватися як у s-зону, так і у важку d-зону з високою щільністю станів. 

Якщо два канали провідності діють паралельно, то додаються провідності `σ = σ_1 + σ_2`, а не опори:

```
ρ_total = 1 / (σ_1 + σ_2) = (ρ_1 · ρ_2) / (ρ_1 + ρ_2) ≠ ρ_1 + ρ_2
```

Це викликає значні відхилення від правила Маттіссена.

#### 3. Електрон-фонон-домішкова інтерференція (Ефект Каганова — Жернова)
У брудних металах наявність важких домішкових атомів змінює локальний фононний спектр кристала, викликаючи появу локалізованих фононних мод. Це створює інтерференційні члени в матричному елементі `⟨V_ph · V_imp⟩ ≠ 0`, що приводить до виникнення додаткового температурно-залежного внеску в опір `Δρ(T, c_imp) ∝ c_imp · T²`.

#### 4. Зміна екранування та рівня Фермі у напівпровідниках
У напівпровідниках додавання домішок `c_imp` змінює концентрацію вільних носіїв `n`, що змінює радіус екранування Томаса — Фермі `r_TF` та рівень Фермі `E_F`. Як наслідок, фононна частота розсіювання `1 / τ_ph` сама стає функцією концентрації домішок, що порушує незалежність процесів.
