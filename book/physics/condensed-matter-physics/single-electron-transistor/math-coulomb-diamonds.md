# 🧮 Електростатика квантового острівця та математична геометрія ромбів Кулона

Ця вставка містить суворе математичне виведення електростатичної вільної енергії квантового острівця, розрахунок термодинамічних умов кулонівського блокування тунелювання та точні алгебраїчні рівняння меж стабільності ромбів Кулона в площині напруг затвора й витоку-стоку.

## 1. Електростатичний потенціал та вільна енергія острівця

Розглянемо систему одноелектронного транзистора, що складається з провідного острівця, з'єднаного з витоком (S) та стоком (D) через два тунельні переходи з ємностями `C₁` та `C₂`, а також з керувальним затвором (G) через ємність `C_g`.

```
        Source (V_S)   Drain (V_D)    Gate (V_g)
             │              │              │
             ├───[ C₁ ]─────┼─────[ C₂ ]───┤
             │              │              │
                            ◯  Острівець (потенціал φ, заряд Q)
                            │
                       ─────┴───── C_g
                            │
                         Gate (V_g)
```

Нехай заряд на острівці дорівнює `Q = -n·e`, де `n` — ціле число надлишкових електронів на острівці, а `e = 1.602·10⁻¹⁹` Кл — елементарний заряд.

За законом збереження заряду, індукований заряд на острівці від усіх зовнішніх електродів дорівнює сумі зарядів на відповідних ємностях:

```
Q = C₁·(φ - V_S) + C₂·(φ - V_D) + C_g·(φ - V_g)
```

Розкриємо дужки у показнику заряду та згрупуємо члени відносно потенціалу острівця `φ`:

```
Q = φ·(C₁ + C₂ + C_g) - (C₁·V_S + C₂·V_D + C_g·V_g)
```

Визначимо повну ємність острівця `C_Σ` як суму всіх з'єднаних ємностей:

```
C_Σ = C₁ + C₂ + C_g
```

Виразимо потенціал острівця `φ`:

```
φ·C_Σ = Q + C₁·V_S + C₂·V_D + C_g·V_g
φ = (Q + C₁·V_S + C₂·V_D + C_g·V_g) / C_Σ
```

Для симетричної схеми живлення витоку та стоку покладемо: `V_S = V_ds / 2` та `V_D = -V_ds / 2`. Тоді вираз для потенціалу `φ` набуває вигляду:

```
φ = (-n·e + C_g·V_g + (C₁ - C₂)·V_ds / 2) / C_Σ
```

Повна електростатична вільна енергія Гіббса `F(n, V_g, V_ds)` обчислюється як різниця власної енергії заряджених ємностей та роботи, виконаної зовнішніми джерелами напруги при перенесенні заряду:

```
F(n, V_g, V_ds) = E_electrostatic - W_sources
```

Обчислимо власну електростатичну енергію трьох ємностей:

```
E_electrostatic = (C₁·(φ - V_S)² + C₂·(φ - V_D)² + C_g·(φ - V_g)²) / 2
```

Підставивши вираз для `φ` та обчисливши роботу зовнішніх джерел `W_sources`, отримаємо квадратичний вираз для вільної енергії стану з `n` електронами:

```
F(n) = ((-n·e + C_g·V_g + (C₁ - C₂)·V_ds / 2)² / (2·C_Σ)) - E_const
```

Позначимо кулонівську заряджальну енергію одного електрона як `E_C`:

```
E_C = e² / (2·C_Σ)      [кулонівська енергетична щілина]
```

та введемо безрозмірне число індукованого заряду затвора `n_g`:

```
n_g = (C_g·V_g + (C₁ - C₂)·V_ds / 2) / e      [індукований заряд затвора]
```

Зарядова частина вільної енергії острівця спрощується до точного квадратичного вигляду:

```
F(n) = E_C · (n - n_g)²      [зарядова вільна енергія Гіббса]
```

## 2. Умови тунельних переходів та енергетичний баланс

Перехід електрона крізь перший або другий тунельний перехід змінює кількість електронів на острівці `n -> n ± 1`. Зміна вільної енергії системи `ΔF` при тунелюванні електрона визначає ймовірність та напрямок тунельного процесу.

За першим законом термодинаміки та золотим правилом Фермі, тунельний перехід відбувається самочинно за нульової температури лише тоді, коли зміна вільної енергії є від'ємною: `ΔF < 0`.

Розглянемо зміну енергії при збільшенні кількості електронів від `n` до `n + 1` за відсутності напруги витік-стік (`V_ds = 0`):

```
ΔF = F(n + 1) - F(n)
= E_C · (n + 1 - n_g)² - E_C · (n - n_g)²      [підстановка вільної енергії]
= E_C · ((n + 1 - n_g) - (n - n_g)) · ((n + 1 - n_g) + (n - n_g))  [різниця квадратів]
= E_C · 1 · (2·n + 1 - 2·n_g)                  [алгебраїчне спрощення]
= 2·E_C · (n + 1/2 - n_g)                      [винесення двійки]
```

Аналізуючи вираз `ΔF`:

1. **Якщо `n_g` не є півцілим числом (`n_g ≠ N + 1/2`):** Значення `ΔF ≠ 0`, і існує енергетичний бар'єр `ΔF > 0` для зміни кількості електронів. Перехід заборонений — це стан **кулонівського блокування**.
2. **Якщо `n_g` є півцілим числом (`n_g = N + 1/2`):** Енергії двох зарядових станів `F(N)` та `F(N + 1)` стають тотожно рівними:

```
F(N + 1) - F(N) = 0      [умова виродження енергетичних станів]
```

У цій точці електростатична енергія додавання електрона дорівнює нулю. Електрони можуть безперешкодно тунелювати на острівець і з нього, викликаючи пік квантової провідності.

Звідси випливає умова напруги затвора для спостереження періодичних піків провідності:

```
C_g · V_g = (N + 1/2) · e
V_g^(N) = (N + 1/2) · e / C_g      [положень піків осциляцій Кулона]
```

Відстань між сусідніми піками провідності (період кулонівських осциляцій) строго дорівнює:

```
ΔV_g = V_g^(N+1) - V_g^(N)
= e / C_g      [період осциляцій затвора]
```

## 3. Математичні межі ромбів Кулона (Coulomb Diamonds)

При прикладанні скінченної напруги витік-стік `V_ds ≠ 0` енергетичні рівні витоку та стоку зсуваються на величину `e·V_ds`. Електрон може тунелювати крізь Бар'єр 1 (з витоку на острівець) або крізь Бар'єр 2 (з острівця на стік).

Розглянемо чотири можливі елементарні тунельні процеси:

1. `Γ₁⁺(n)`: Електрон тунелює з Витоку на Острівець (`n -> n + 1`).
2. `Γ₁⁻(n)`: Електрон тунелює з Острівця на Витік (`n -> n - 1`).
3. `Γ₂⁺(n)`: Електрон тунелює зі Стоку на Острівець (`n -> n + 1`).
4. `Γ₂⁻(n)`: Електрон тунелює з Острівця на Стік (`n -> n - 1`).

Обчислимо зміну вільної енергії для кожного з двох основних напрямків струму:

```
ΔF₁⁺ = E_C · (1 + 2·(n - n_g)) - e·V_ds · (C₂ + C_g/2) / C_Σ
ΔF₂⁻ = E_C · (1 - 2·(n - n_g)) - e·V_ds · (C₁ + C_g/2) / C_Σ
```

Умови блокування струму полягають у тому, що жоден із процесів тунелювання не може відбутися самочинно: `ΔF₁⁺ > 0` та `ΔF₂⁻ > 0`. Рівняння меж, при яких блокування знімається (`ΔF = 0`), задають прямі лінії на площині напруг `(V_g, V_ds)`.

Знайдемо рівняння першої межі ромба (`ΔF₁⁺ = 0`):

```
E_C · (1 + 2·n - 2·C_g·V_g / e) = e·V_ds · (C₂ + C_g/2) / C_Σ
```

Виразивши `V_ds` як функцію `V_g`:

```
V_ds = (C_g / (C₂ + C_g/2)) · (V_g^(N) - V_g)      [лінія межі 1]
```

Наклон першої межі ромба Кулона на площині `(V_g, V_ds)` дорівнює:

```
dV_ds / dV_g = - C_g / (C₂ + C_g)      [наклон лівої верхньої межі]
```

Аналогічно знайдемо рівняння другої межі ромба (`ΔF₂⁻ = 0`):

```
dV_ds / dV_g = C_g / (C₁ + C_g)        [наклон правої верхньої межі]
```

Перетин чотирьох таких ліній утворює замкнені чотирикутники — **ромби Кулона**. Всередині кожного ромба кількість електронів `n` на острівці фіксована, а струм `I_ds = 0`.

Геометричні характеристики ромба Кулона дозволяють безпосередньо виміряти ємності транзистора:

1. **Максимальна висота ромба по осі `V_ds` (амплітуда кулонівської щілини):**

```
V_ds^(max) = e / C_Σ      [вершина ромба Кулона]
```

2. **Ширина ромба по осі `V_g` (період осциляцій):**

```
ΔV_g = e / C_g
```

3. **Співвідношення нахилів бокових граней ромба:**

```
k_left = - C_g / (C₂ + C_g)
k_right = C_g / (C₁ + C_g)
```

Звідси ємності переходів обчислюються за виміряною геометрією ромба:

```
C_g = e / ΔV_g
C_Σ = e / V_ds^(max)
C₁ = C_g / k_right - C_g
C₂ = - C_g / k_left - C_g
```

## 4. Квантові флуктуації, ко-тунелювання та межа Гейзенберга

Класична ортодоксальна теорія припускає, що тунельні події відбуваються строго послідовно в часі. Проте при врахуванні вищих порядків теорії збурень квантової механіки виникає ефект **квантового ко-тунелювання** (*co-tunneling*).

Під підко-тунелюванням розуміють процес одночасного (когерентного) тунелювання двох електронів крізь два бар'єри через віртуальний стан острівця. При цьому один електрон тунелює з витоку на острівець, а інший з острівця на стік за інтервал часу `Δt`, обмежений принципом невизначеності Гейзенберга:

```
Δt ≈ ℏ / E_C
```

Швидкість ко-тунелювання у зоні кулонівського блокування при нульовій температурі обчислюється за формулою другого порядку теорії збурень:

```
Γ_cotunneling ∝ (R_q / R_T1) · (R_q / R_T2) · (e·V_ds)³ / E_C²
```

Звідси випливає фундаментальна умова придушення ко-тунелювання:

```
R_T1, R_T2 >> R_q = h / e²
≈ 25.8 кОм
```

Якщо опір тунельних переходів є достатньо високим (`R_T >> 25.8` кОм), ймовірність ко-тунелювання падає пропорційно квадрату відношення `(R_q / R_T)²`, і витоки струму всередині ромбів Кулона стають знехтувно малими.
