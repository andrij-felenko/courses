# 🔌 Порівняльний аналіз DC-SET та RF-SET архітектур

Ця вставка надає порівняльний аналіз двох класів одноелектронних транзисторних систем — класичного одноелектронного транзистора на постійному струмі (DC-SET) та високочастотного одноелектронного транзистора (RF-SET), розкриваючи фізичні механізми узгодження імпедансу, обмеження смуги пропускання та системні інженерні компроміси при проведенні надчутливої електрометрії.

## 1. Фізична проблема смуги пропускання DC-SET

Класичний одноелектронний транзистор на постійному струмі (DC-SET) підключається до вимірювальних приладів за допомогою паралельної схеми живильних коаксіальних кабелів. Для збереження квантового режиму блокування тунельний опір кожної з двох меж пристрою `R_T` за фундаментальними квантовими вимогами повинен перевищувати квант опору `R_q ≈ 25.8` кОм. У реальних вимірювальних структурах типовий тунельний опір становить `R_T ≈ 100` кОм — 1 МОм.

Водночас паразитична ємність підвідних кріогенних коаксіальних кабелів `C_cable`, які з'єднують вимірювальний прилад при кімнатній температурі (300 К) із пристроєм у розчинному кріостаті на рівні 10 мілікельвінів (довжина лінії 1.5–2 метри), становить близько 100–300 пікофарад (`10⁻¹⁰` Ф).

```
        V_ds ───[ R_T ≈ 100 кОм ]───┬───> Підсилювач струму
                                    │
                                  ═════ C_cable ≈ 200 пФ
                                    │
                                   GND
```

Ця комбінація утворює паразитичний низькочастотний RC-фільтр із часовою сталою `τ = R_T · C_cable`. Верхня гранична частота зрізу цього фільтра визначається співвідношенням:

```
f_cutoff = 1 / (2·π · R_T · C_cable)
```

Підставивши типові значення експериментальних установок (`R_T = 100` кОм, `C_cable = 200` пФ):

```
f_cutoff = 1 / (2 · 3.14159 · 100000 · 200·10⁻¹²)
≈ 795.7 Гц
```

Унаслідок такої паразитичної RC-фільтрації смуга пропускання DC-SET виявляється жорстко обмеженою діапазоном від 100 Гц до кількох кілогерців. Будь-яка спроба виміряти швидкі зарядові флуктуації, простежити за динамікою перескоку поодиноких носіїв або зчитати квантовий стан спінового чи зарядового кубіта за наносекундні інтервали часу виявляється фізично неможливою.

## 2. Принцип роботи та схемотехніка RF-SET

Радіочастотний одноелектронний транзистор (RF-SET), запропонований Робертом Шоелкопфом у 1998 році, докорінно вирішує проблему RC-обмеження шляхом включення тунельного транзистора у високочастотний контур узгодження імпедансу (*impedance matching LC tank circuit*).

```
 ВЧ Генератор (f_RF ≈ 1 ГГц)
        │
    [Спрямований відгалужувач / Напрямний відгалужувач] ───> ВЧ Підсилювач (LNA)
        │
        ├───[ Ємність зв'язку C_c ]───┬───[ Індуктивність L ]───┐
                                      │                         │
                                    ==== C_p (Паразитична)     [ SET (Динамічний опір R_SET) ]
                                      │                         │
                                     GND                       GND
```

У цій схемі тунельний транзистор виконує роль змінного навантажувального опору `R_SET = dV_ds / dI_ds`, підключеного паралельно або послідовно до індуктивності `L` та паразитичної ємності `C_p`.

Така конфігурація утворює високочастотний паралельний або послідовний резонатор із власною резонансною частотою `f_r`:

```
f_r = 1 / (2·π · √(L · (C_p + C_c)))      [резонансна частота LC-контуру]
```

Добротність резонансного контуру `Q` визначається співвідношенням реактивного та активного опорів:

```
Q = R_SET / √(L / C_total)
```

При виконанні умови резонансу схема перетворює високий дифенціційний опір SET (`R_SET ≈ 100` кОм) у помірний еквівалентний імпеданс `Z_in` на вході коаксіальної лінії:

```
Z_in = L / (C_total · R_SET)
```

Шляхом підбору індуктивності `L ≈ 50–100` нГн та ємності зв'язку `C_c ≈ 0.1–0.5` пФ, вхідний імпеданс `Z_in` на резонансній частоті роблять тотожно рівним хвильовому опору коаксіального кабелю `Z_0 = 50` Ом.

Коефіцієнт відбиття радіочастотної хвилі `Γ_RF` від контуру визначається стандартним співвідношенням ліній передачі:

```
Γ_RF = (Z_in - Z_0) / (Z_in + Z_0)
```

Зміна електродичного заряду на затворі `ΔQ` викликає зміну потенціалу острівця, що миттєво змінює динамічний опір транзистора `R_SET`. Це призводить до модуляції вхідного імпедансу `Z_in` та відповідної зміни амплітуди й фази відбитої ВЧ хвилі `Γ_RF`.

Зчитування здійснюється шляхом реєстрації відбитої радіочастотної хвилі на несучих частотах від 100 МГц до 1.5 ГГц. Оскільки смуга пропускання резонатора визначається його добротністю:

```
BW = f_r / Q
```

смуга пропускання RF-SET зростає з 1 кілогерца до 10–100 мегагерців. Це дозволяє здійснювати часову роздільну здатність зчитування заряду за інтервали часу від 10 до 50 наносекунд.

## 3. Порівняльний аналіз характеристик DC-SET та RF-SET

У таблиці наведено вичерпне порівняння параметрів обох архітектурних рішень.

```
+--------------------------------------------------------------------------------------------------+
| Таблиця 1. Системне порівняння параметрів DC-SET та RF-SET                                       |
+--------------------------------+--------------------------------+--------------------------------+
| Параметр / Характеристика      | Архітектура DC-SET             | Архітектура RF-SET             |
+--------------------------------+--------------------------------+--------------------------------+
| Смуга пропускання (Bandwidth)  | 100 Гц — 10 кГц                | 10 МГц — 100 МГц               |
| Часова роздільна здатність     | 100 мкс — 1 мс                 | 10–50 нс                       |
| Зарядова чутливість δQ         | 10⁻⁴ e / √Гц                   | 10⁻⁶ – 10⁻⁵ e / √Гц            |
| Основний тип вимірювання       | Прямий тунельний струм I_ds    | Коефіцієнт відбиття ВЧ хвилі Γ |
| Робоча частота несучої         | Постійний струм (f = 0)        | 100 МГц — 1.5 ГГц              |
| ВЧ-компоненти кріостата        | Не потрібні                    | LNA, циркулятори, атенюатори   |
| Складність калібрування        | Низька (пряме вимірювання ВАХ) | Висока (калібрування ВЧ-тракту)|
| Теплове розсіювання на острівці| P = I_ds · V_ds (< 1 пВт)      | P_RF ≈ -90 дБм (~1 пВт)        |
| Основна галузь застосування    | Метрологія, ВАХ-спектроскопія  | Зчитування кубітів, реальний час|
+--------------------------------+--------------------------------+--------------------------------+
```

### Фізичний порівняльний аналіз:

1. **Швидкодія та часова роздільна здатність:** RF-SET перевищує класичний DC-SET за смугою пропускання у 10 000 разів. Це дає змогу спостерігати одноелектронні перескоки в реальному часі (*single-shot charge readout*).
2. **Зарядова чутливість:** Завдяки винесенню вимірювального сигналу на високу частоту (сотні мегагерців), RF-SET повністю позбавлений впливу низькочастотного флікер-шуму (`1/f` шуму) вимірювальних підсилювачів, досягаючи граничної чутливості `δQ ≈ 10⁻⁶ e / √Гц`.
3. **Складність установки:** DC-SET вимагає лише прецизійного джерела напруги та підсилювача малого струму (пікоамперметра). RF-SET вимагає побудови складного кріогенного ВЧ-тракту з гетеродинним детектуванням, малошумними підсилювачами на основі HEMT та фазочутливими демодуляторами.

## 4. Специфічні інженерні пастки та підводні камені

При проектуванні та експлуатації систем електрометрії на основі SET слід враховувати такі типові проблеми обох класів пристроїв:

1. **Дрейф робочої точки через низькочастотний шум заряду (1/f Charge Noise):**
Усі SET критично чутливі до перескоків поодиноких зарядів у діелектричній підкладці та оксидних шарах (так звані дворевневі системи, *Two-Level Systems, TLS*). Перескок заряду поблизу острівця викликає випадковий зсув порогової напруги затвора `ΔV_g = e / C_g`, переміщуючи транзистор із максимуму провідності в зону блокування. У RF-SET для компенсації дрейфу застосовують системи активного зворотного зв'язку за затвором (*active feedback tracking*).

2. **Поширокосмугове розмивання ВЧ потужністю (RF Power Broadening):**
У RF-SET амплітуда вимірювального ВЧ сигналу `V_RF` на острівці не повинна перевищувати термічний потенціал та кулонівську щілину: `e·V_RF << min(k_B T, E_C)`. Якщо потужність ВЧ генератора занадто велика, напруга `V_RF` розмиває осциляції провідності Кулона, знижуючи чутливість електрометра.

3. **Необхідність кріогенного циркулятора та малошумного підсилювача (HEMT):**
Для захисту RF-SET від шумового випромінювання кімнатного підсилювача у ВЧ тракт на ступені 10–20 мК обов'язково вбудовують кріогенний феритовий циркулятор або ізолятор зі згасанням зворотної хвилі понад 20 дБ. Зчитуваний ВЧ сигнал підсилюється малошумним транзисторним підсилювачем на основі HEMT (High Electron Mobility Transistor), розміщеним на ступені 4 К.
