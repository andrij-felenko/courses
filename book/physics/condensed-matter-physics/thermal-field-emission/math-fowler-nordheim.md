# 🧮 Математичне виведення рівняння Фаулера — Нордгейма

Ця математична вставка містить суворе виведення рівняння Фаулера — Нордгейма для густини автоелектронного емісійного струму. Розрахунок базується на поєднанні трьох фундаментальних концепцій: статистичного розподілу електронного газу за енергіями Фермі — Дірака, квантово-механічного квазікласичного наближення Вентцеля — Крамерса — Бріллюена (ВКБ) для обчислення прозорості бар'єру та врахування сил дзеркального відображення через еліптичні інтеграли Нордгейма.

## 1. Потік електронів у металі та функція постачання

Розглянемо метал при температурі `T`, що займає півпростір `x < 0`. Вільні електрони провідності описуються тривимірним розподілом Фермі — Дірака у просторі імпульсів `(p_x, p_y, p_z)`. Нас цікавить потік електронів, які рухаються з нормальними до поверхні компонентами імпульсу `p_x > 0` у напрямку вакууму (`x > 0`).

Позначимо нормальну кінетичну енергію електрона всередині металу як `E_x = p_x² / (2·m)`. Кількість електронів, які щосекунди падають на одиницю площі поверхні розділу метал-вакуум з нормальними енергіями в інтервалі від `E_x` до `E_x + dE_x`, описується **функцією постачання** (Supply Function) `N(E_x) dE_x`.

Для обчислення `N(E_x)` необхідно перейти до циліндричних координат у просторі імпульсів та проінтегрувати розподіл Фермі по тангенціальних компонентах `p_y` та `p_z`:

```
N(E_x) dE_x = (2 / h³) · (p_x / m) dp_x · ∫∫ [ -∞ to +∞ ] (1 / (exp((E_x + E_y + E_z - E_F) / (k_B · T)) + 1)) dp_y dp_z
```

Враховуючи, що `dE_x = (p_x / m) dp_x`, та вводячи тангенціальну кінетичну енергію `E_┴ = (p_y² + p_z²) / (2·m)`, маємо `dp_y dp_z = 2·π·m dE_┴`.

Інтеграл по тангенціальній енергії береться аналітично:

```
∫ [ 0 to ∞ ] (1 / (exp((E_x + E_┴ - E_F) / (k_B · T)) + 1)) dE_┴ 
= k_B · T · ln( 1 + exp( (E_F - E_x) / (k_B · T) ) )
```

Множачи на передінтегральний коефіцієнт `(4·π·m / h³)`, отримуємо вираз для функції постачання при довільній температурі `T`:

```
N(E_x) = (4·π·m·k_B·T / h³) · ln( 1 + exp( (E_F - E_x) / (k_B · T) ) )
```

Фізичний зміст функції постачання: вона визначає, скільки електронів заданої нормальної енергії `E_x` щосекунди ударяються об внутрішній поверхневий бар'єр металу.

### Граничний випадок абсолютного нуля (T = 0 K)

При температурі абсолютного нуля (`T → 0 K`) термічне збудження електронів відсутнє. Проаналізуємо поведінку аргументу логарифма:

1. Для електронів із енергіями нижче рівня Фермі (`E_x ≤ E_F`):
   Показник експоненти `(E_F - E_x) / (k_B · T)` прямує до `+∞`. Для великих додатних `u` виконується логарифмічна апроксимація `ln(1 + exp(u)) ≈ u`.
   Звідси отримуємо: `k_B · T · ln(1 + exp((E_F - E_x)/(k_B·T))) ≈ E_F - E_x`.

2. Для електронів із енергіями вище рівня Фермі (`E_x > E_F`):
   Показник експоненти прямує до `-∞`, тому `exp(u) → 0`, а `ln(1 + 0) = 0`.

Таким чином, при `T = 0 K` функція постачання набуває строго лінійного вигляду:

```
N(E_x) = (4·π·m / h³) · (E_F - E_x)      [для E_x ≤ E_F]
N(E_x) = 0                                 [для E_x > E_F]
```

Це означає, що при холодній автоелектронній емісії потік носіїв формується виключно тими електронами, які знаходяться під сферою Фермі.

## 2. Коефіцієнт прозорості трикутного бар'єру у наближенні ВКБ

Коли до поверхні металу прикладено сильне зовнішнє електричне поле `E`, потенціальна енергія електрона у вакуумі (`x > 0`) знижується за лінійним законом:

```
V(x) = E_F + Φ - e · E · x
```

де `Φ` — робота виходу металу, `e` — модуль заряду електрона. Утворюється трикутний потенціальний бар'єр.

Застосування квазікласичного наближення Вентцеля — Крамерса — Бріллюена (ВКБ) є правомірним, коли довжина хвилі де Бройля електрона змінюється повільно на масштабі потенціального бар'єру.

Ймовірність `D(E_x)` тунельного проходження електрона з нормальною енергією `E_x` крізь бар'єр `V(x)` описується інтегралом ВКБ:

```
D(E_x) = exp( -2 · ∫ [ 0 to x_0 ] k(x) dx )
```

де `k(x) = √(2·m / ℏ² · (V(x) - E_x))` — волнове число електрона під бар'єром, а `x_0` — класична точка повороту, у якій кінетична енергія під бар'єром обертається в нуль: `V(x_0) = E_x`.

Обчислимо точну позицію класичної точки повороту `x_0`:

```
E_F + Φ - e · E · x_0 = E_x
x_0 = (E_F + Φ - E_x) / (e · E)
```

Тепер обчислимо квазікласичний інтеграл затухання `I`:

```
I = ∫ [ 0 to x_0 ] √(2·m / ℏ² · (E_F + Φ - E_x - e·E·x)) dx
```

Виносимо сталі множники і виконуємо заміну змінної `u = E_F + Φ - E_x - e·E·x`, звідси `du = -e·E dx`:

```
I = (√(2·m) / (ℏ · e · E)) · ∫ [ 0 to E_F+Φ-E_x ] √u du
  = (√(2·m) / (ℏ · e · E)) · (2/3) · (E_F + Φ - E_x)^(3/2)
```

Підставляючи цей інтеграл у показниковий вираз для `D(E_x)` та враховуючи співвідношення `2 · I`, отримуємо коефіцієнт прозорості ідеального трикутного бар'єру:

```
D(E_x) = exp( - (4 · √(2·m) / (3 · e · E · ℏ)) · (E_F + Φ - E_x)^(3/2) )
```

Замінивши зведену сталу Планка `ℏ = h / (2·π)`, переписуємо вираз у стандартних фундаментальних константах:

```
D(E_x) = exp( - (8·π · √(2·m) / (3 · h · e · E)) · (E_F + Φ - E_x)^(3/2) )
```

## 3. Розклад поблизу рівня Фермі

Потенціальний бар'єр є найтоншим для електронів із найвищою можливою нормальної енергією `E_x ≈ E_F`. Для електронів із нижчими енергіями товщина бар'єру зростає, і ймовірність тунелювання експоненціально спадає. Тому левова частка емісійного струму формується вузьким енергетичним інтервалом шириною в частки електрон-вольта безпосередньо під рівнем Фермі.

Позначимо відхилення енергії від рівня Фермі як `ε = E_F - E_x ≥ 0`. Розкладемо величину `(Φ + ε)^(3/2)` у ряд Тейлора за степенями `ε / Φ`:

```
(Φ + ε)^(3/2) = Φ^(3/2) · (1 + ε / Φ)^(3/2)
              ≈ Φ^(3/2) · (1 + (3/2) · (ε / Φ))
              = Φ^(3/2) + (3/2) · √Φ · (E_F - E_x)
```

Підставимо цей розклад у показник експоненти коефіцієнта прозорості `D(E_x)`:

```
D(E_x) = D(E_F) · exp( - (E_F - E_x) / d_0 )
```

де `D(E_F)` — ймовірність тунелювання електрона безпосередньо з рівня Фермі:

```
D(E_F) = exp( - (8·π · √(2·m) · Φ^(3/2)) / (3 · h · e · E) )
```

а характерний енергетичний масштаб згасання `d_0` виражається як:

```
d_0 = (e · E · ℏ) / (2 · √(2·m·Φ)) = (e · E · h) / (4·π · √(2·m·Φ))
```

Фізичний зміст параметра `d_0`: це енергетичний інтервал глибини під рівнем Фермі, у межах якого прозорість потенціального бар'єру зменшується в `e ≈ 2.718` разів. Для вольфраму (`Φ = 4.5 eV`) при полі `E = 3 × 10⁹ V/m` параметр `d_0` становить всього `0.093 eV`, що підтверджує cựскову вузькість емісійного енергетичного спектра.

## 4. Інтегрування загальної густини струму

Повна густина автоелектронного струму `J` визначається інтегралом від добутку заряду електрона `e`, функції постачання `N(E_x)` та коефіцієнта тунелювання `D(E_x)` по всіх можливих нормальних енергіях при `T = 0 K`:

```
J = e · ∫ [ 0 to E_F ] N(E_x) · D(E_x) dE_x
```

Підставляємо розкладені вирази для `N(E_x)` та `D(E_x)`:

```
J = e · (4·π·m / h³) · D(E_F) · ∫ [ 0 to E_F ] (E_F - E_x) · exp( - (E_F - E_x) / d_0 ) dE_x
```

Виконаємо заміну змінної інтегрування `u = (E_F - E_x) / d_0`. Оскільки `d_0 << E_F` (наприклад, `0.09 eV << 5.8 eV`), верхню межу інтегрування можна з високою точністю поширити до нескінченності:

```
∫ [ 0 to ∞ ] u · exp(-u) du = 1
```

Отже, інтеграл по енергіях дає просто `d_0²`:

```
J = e · (4·π·m / h³) · D(E_F) · d_0²
```

Підставимо математичний вираз для `d_0²`:

```
d_0² = (e² · E² · h²) / (16 · π² · 2·m · Φ) = (e² · E² · h²) / (32 · π² · m · Φ)
```

Перемножимо константи:

```
J = e · (4·π·m / h³) · (e² · E² · h² / (32 · π² · m · Φ)) · D(E_F)
  = (e³ · E² / (8 · π · h · Φ)) · D(E_F)
```

Підставляючи вираз для `D(E_F)`, отримуємо підсумкове рівняння Фаулера — Нордгейма для трикутного бар'єру:

```
J_FN = (e³ · E² / (8·π·h·Φ)) · exp( - (8·π · √(2·m) · Φ^(3/2)) / (3 · h · e · E) )
```

## 5. Врахування сил дзеркального відображення (еліптичні функції Нордгейма)

У реальних металах потенціальний бар'єр не є строго трикутним. Кулонівська сила дзеркального відображення `F_img = -e² / (16·π·ε₀·x²)` скругляє вершину бар'єру та зменшує його ефективну товщину.

Повний потенціал приймає вигляд:

```
V(x) = E_F + Φ - e · E · x - e² / (16·π·ε₀·x)
```

Точне обчислення інтеграла ВКБ для такого потенціалу зводиться до повних еліптичних інтегралів першого `K(k)` та другого `E(k)` роду. Результат виражають через безрозмірний параметр Шотткі `y`:

```
y = √(e³ · E / (4·π·ε₀)) / Φ = ΔΦ / Φ
```

Параметр `y` вимірює відношення зниження бар'єру за рахунок ефекту Шотткі `ΔΦ` до початкової роботи виходу `Φ`. При `y = 0` (без поправки на відображення) `v(0) = 1` та `t(0) = 1`. При `y = 1` бар'єр повністю знищується полем.

Точне рішення для поправки Нордгейма `v(y)` виражається через еліптичні функції:

```
v(y) = (1/√2) · √(1 + √(1 - y²)) · [ E(k) - (1 - √(1 - y²)) · K(k) ]
```

де модуль еліптичного інтеграла `k = √((2 · √(1 - y²)) / (1 + √(1 - y²)))`.

Уточнена формула Фаулера — Нордгейма з урахуванням сил відображення приймає вигляд:

```
J_FN = (e³ · E² / (8·π·h·Φ · t²(y))) · exp( - (8·π · √(2·m) · Φ^(3/2) · v(y)) / (3 · h · e · E) )
```

Для практичних інженерних обчислень використовують апроксимаційні формули Нордгейма:

```
v(y) ≈ 1 - y² + (y² / 3) · ln(y)
t(y) ≈ 1 + 0.11 · y²
```

Виражаючи фундаментальні константи у числових одиницях SI та електрон-вольтах:

```
A_FN = e³ / (8·π·h) ≈ 1.5414 × 10⁻⁶ A · eV / V²
B_FN = 8·π · √(2·m) / (3 · h · e) ≈ 6.8308 × 10⁹ V / (m · eV^(3/2))
```

Рівняння набуває остаточної практичної форми:

```
J_FN = (1.5414 × 10⁻⁶ · E² / (Φ · t²(y))) · exp( - 6.8308 × 10⁹ · Φ^(3/2) · v(y) / E )
```

де `J` вимірюється в `A/m²`, `E` — у `V/m`, а `Φ` — у електрон-вольтах (`eV`).
