# 🧮 Математична теорія ґірації в анізотропних кристалах та рівні Ландау

У перпендикулярному магнітному полі класична частинка з масою `m` та зарядом `q` здійснює коловий рух із частотою `ω_c = q · B / m`. Однак у кристалічній ґратці періодичний потенціал кристала модифікує дисперсійне співвідношення носіїв заряду `E(k)`. Рух квантовомеханічного квазічастинкового пакету описується тензором оберненої ефективної маси, що вимагає математичного узагальнення концепції циклотронної частоти як у класичному, так і в квантовому режимах.

---

### Класичний рух носія у кристалі з анізотропним законом дисперсії

Рівняння руху квазіімпульсу `ℏ · k` носія заряду в магнітному полі `B` визначається формулою Лоренца:

```
ℏ · (dk / dt) = q · (v × B)
```

де групова швидкість квазічастинки `v` зв'язана з градієнтом енергії у k-просторі:

```
v = (1 / ℏ) · ∇_k E(k)
```

Зі скалярного добутку `(dk / dt) · ∇_k E = 0` випливає, що під час руху в магнітному полі енергія частинки `E` зберігається. Крім того, зі скалярного добутку `(dk / dt) · B = 0` слідує, що проекція квазіімпульсу на напрямок магнітного поля `k_z = const` також залишається незмінною (припускаємо, що поле `B` спрямоване вздовж осі `z`).

Таким чином, траєкторія частинки у k-просторі є лінією перетину поверхні постійної енергії `E(k) = const` з площиною `k_z = const`.

Щоб обчислити період обертання `T_c`, виразимо елемент довжини дуги `dk_⊥` траєкторії у k-просторі через модуль групової швидкості в перпендикулярній площині `v_⊥`:

```
|dk_⊥| = (q / ℏ) · |v_⊥ × B| = (q · B / ℏ) · v_⊥
```

Час руху вздовж дуги `dt` становить:

```
dt = ℏ · |dk_⊥| / (q · B · v_⊥)
```

Інтегруючи за повним замкненим контуром траєкторії у k-просторі, отримуємо період циклотронного обертання `T_c`:

```
T_c = (ℏ / (q · B)) · ∮ |dk_⊥| / v_⊥
```

Зв'яжемо цей інтеграл з площею `S(E, k_z)`, яку охоплює замкнена траєкторія у k-просторі. Розглянемо дві близькі ізоенергетичні поверхні `E` та `E + dE`. Перпендикулярна відстань між контурами у k-просторі дорівнює `dk_N = dE / (ℏ · v_⊥)`. Площа кільця між контурами становить:

```
dS = ∮ dk_N · |dk_⊥| = (dE / ℏ) · ∮ |dk_⊥| / v_⊥
```

Звідси похідна площі перетину за енергією дорівнює:

```
∂S / ∂E = (1 / ℏ) · ∮ |dk_⊥| / v_⊥
```

Підставляючи отриманий вираз у формулу для періоду `T_c`, маємо:

```
T_c = (ℏ² / (q · B)) · (∂S / ∂E)
```

Визначаючи циклотронну частоту як `ω_c = 2π / T_c`, а циклотронну ефективну масу як `m_c* = q · B / ω_c`, отримуємо фундаментальну формулу Ліфшиця — Онсагера для циклотронної маси:

```
m_c* = (ℏ² / 2π) · (∂S / ∂E)
```

Ця формула є абсолютно загальною: вона справедлива для будь-якої складної форми поверхні Фермі чи зонного мінімуму, включаючи непараболічні та некубічні кристалічні ґратки.

### Циклотронна маса для еліпсоїдальної зони провідності

У багатьох напівпровідниках (германій, кремній, арсенід галію) енергетичні мінімуми зони провідності описуються анізотропним квадратним законом дисперсії. У головних осях еліпсоїда (де вісь `3` є віссю симетрії):

```
E(k) = (ℏ² / 2) · ( (k₁² + k₂²) / m_t*  +  k₃² / m_l* )
```

де `m_t*` — поперечна ефективна маса, а `m_l*` — поздовжня (поздовжньо-осьова) ефективна маса.

Якщо постійне магнітне поле `B` спрямоване під кутом `θ` до осі симетрії еліпсоїда (осі `3`), перетин еліпсоїда площиною, перпендикулярною до `B`, являє собою еліпс. Обчислення площі цього еліпса `S(E, k_z)` та інтегрування за формулою Ліфшиця надає наступну залежність циклотронної маси від кута `θ`:

```
1 / (m_c*)^2 = (cos²θ / (m_t*)^2)  +  (sin²θ / (m_t* · m_l*))
```

Звідси одержуємо явний вираз для анізотропної циклотронної маси `m_c*(θ)`:

```
m_c*(θ) = m_t* · √ ( m_l* / (m_l* · cos²θ + m_t* · sin²θ) )
```

Аналіз граничних випадків:
1. Якщо магнітне поле спрямоване вздовж осі симетрії еліпсоїда (`θ = 0°`), електрон здійснює обертання у площині з поперечною масою: `m_c*(0°) = m_t*`.
2. Якщо магнітне поле перпендикулярне до осі симетрії (`θ = 90°`), електрон охоплює овал, до якого входять як поздовжня, так і поперечна маси: `m_c*(90°) = √(m_l* · m_t*)`.

У загальному випадку, коли магнітне поле задається напрямними косинусами `α = (α₁, α₂, α₃)` відносно головних осей еліпсоїда, формула для тензора циклотронної маси узагальнюється до вигляду:

```
m_c*(α) = √ ( m_1* m_2* m_3* / ( α₁² m_1* + α₂² m_2* + α₃² m_3* ) )
```

Оскільки в кремнії є 6 еквівалентних долин вздовж осей `<100>`, а в германії — 4 долини вздовж осей `<111>`, довільна орієнтація магнітного поля відносно монокристала створює різні кути `θ_i` для різних долин. Це призводить до розщеплення єдиного циклотронного піку на кілька окремих ліній резонансного поглинання.

### Квантовомеханічна теорія: рівні Ландау та оптичні переходи

У сильному магнітному полі класичний неперервний спектр кінетичної енергії частинки у перпендикулярній площині квантується. Розглянемо рівняння Шредінгера для вільного електрона у магнітному полі `B = (0, 0, B)` з використанням калібрування Ландау для векторного потенціалу `A = (0, B·x, 0)`.

Гамільтоніан частинки має вигляд:

```
H = (1 / 2m*) · [ p_x² + (p_y - q·B·x)² + p_z² ]
```

Оскільки оператори `p_y = -iℏ (∂/∂y)` та `p_z = -iℏ (∂/∂z)` комутують з гамільтоніаном `H`, хвильову функцію шукаємо у вигляді:

```
Ψ(x, y, z) = ψ(x) · exp(i · k_y · y) · exp(i · k_z · z)
```

Підставляючи цю формулу у рівняння Шредінгера `H Ψ = E Ψ`, отримуємо одновимірне рівняння для `ψ(x)`:

```
[ - (ℏ² / 2m*) · (d² / dx²) + (m* · ω_c² / 2) · (x - x₀)² ] ψ(x) = E' · ψ(x)
```

де `x₀ = - (ℏ · k_y) / (q · B)` — центр зміщеного квантового осцилятора, `ω_c = q · B / m*`, а поздовжня кінетична енергія виділена у вигляді:

```
E' = E - (ℏ² · k_z²) / (2m*)
```

Це рівняння є точним рівнянням квантового гармонічного осцилятора з частотою `ω_c`. Власні енергетичні значення (рівні Ландау) з урахуванням зееманівського розщеплення спіну дорівнюють:

```
E_(n, s)(k_z) = (n + 1/2) · ℏ · ω_c  +  s · g* · μ_B · B  +  (ℏ² · k_z²) / (2m*),     n = 0, 1, 2...
```

де `s = ± 1/2` — спіновий квантовий номер, `g*` — ефективний g-фактор електрона в напівпровіднику, а `μ_B = e ℏ / (2 m₀)` — магнетон Бора.

#### Операторне представлення та матричні елементи

Для обчислення ймовірностей оптичних переходів між рівнями Ландау зручно ввести оператори знищення `a` та народження `a⁺`:

```
a  = √( m* ω_c / (2 ℏ) ) · ( (x - x₀) + i · p_x / (m* ω_c) )
a⁺ = √( m* ω_c / (2 ℏ) ) · ( (x - x₀) - i · p_x / (m* ω_c) )
```

Ці оператори задовольняють стандартне комутаційне співвідношення `[a, a⁺] = 1`. За допомогою них оператор координати `x` виражається як:

```
x = x₀ + √( ℏ / (2 m* ω_c) ) · ( a + a⁺ )
```

При прикладанні змінного високочастотного електричного поля `E_RF(t) = E₀ · cos(ω t)` перпендикулярно до магнітного поля `B` (наприклад, вздовж осі `x`), оператор збурення має вигляд:

```
V(t) = - q · E₀ · x · cos(ω t)
```

Ймовірність оптичного переходу між рівнем Ландау `|n⟩` та рівнем `|n'⟩` пропорційна квадрату модуля матричного елемента координати `x`:

```
|⟨n'| x |n⟩|² = ( ℏ / (2 m* ω_c) ) · [ n · δ_(n', n-1)  +  (n + 1) · δ_(n', n+1) ]
```

Звідси негайно випливає правило відбору для оптичних дипольних переходів:

```
Δn = n' - n = ± 1
```

Енергія кванту поглинання при такому переході дорівнює:

```
ΔE = E_(n+1) - E_n = ℏ · ω_c
```

Прирівнюючи енергію кванту зовнішнього НВЧ-випромінювання `ℏ · ω` до відстані між рівнями Ландау `ℏ · ω_c`, отримуємо умову циклотронного резонансу: `ω = ω_c`. Таким чином, квантовий розрахунок тотожно збігається з класичною частотою ґірації, підтверджуючи фундаментальний принцип відповідності Бора.

### Квантові осциляції та непараболічність зон

У напівпровідниках із малим значенням забороненої зони `E_g` (наприклад, антимонід індію InSb з `E_g ≈ 0.23` еВ), закон дисперсії `E(k)` відхиляється від квадратичного закону Кейна. Ефективна маса електрона зростає з підвищенням енергії:

```
m*(E) = m₀* · ( 1 + 2 E / E_g )
```

Унаслідок цього відстань між сусідніми рівнями Ландау зменшується зі зростанням квантового номера `n`:

```
E_{n+1} - E_n ≈ ℏ · ω_c0 · [ 1 - (2n + 2) · (ℏ ω_c0 / E_g) ]
```

Це викликає розщеплення циклотронної лінії на серію еквідистантних квантових піків (квантовий циклотронний резонанс гарячих електронів), де кожен пік відповідає переходу `n → n+1` із різними початковими станами `n`.
