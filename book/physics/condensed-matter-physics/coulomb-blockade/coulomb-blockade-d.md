При зменшенні геометричних розмірів провідного острова до нанометрових масштабів (менше `100 нм`) сумарна електростатична ємність острова `C_Σ` падає до атоофарадних значень (`10⁻¹⁸–10⁻¹⁵ Ф`), а робота перенесення одного поодинокого електрона `e ≈ 1.602 × 10⁻¹⁹ Кл` на острівець — **енергія заряджання** `E_c = e² / (2 · C_Σ)` — зростає до межаулевих величин (`0.1–100 меВ`). Якщо енергія заряджання `E_c` значно перевищує енергію теплових флуктуацій `k_B · T`, а опір тунельних бар'єрів `R_T` перевищує квант опору `R_Q = h / (2·e²) ≈ 12.9 кОм` (або `R_Q = h / e² ≈ 25.8 кОм` для одноканального тунелювання), перенесення електричного заряду крізь острівець при малих напругах зміщення припиняється повністю. Це явище зупинки тунельного струму внаслідок міжелектронного кулонівського відштовхування називається **кулонівською блокадою**.

### 1. Фундаментальні фізичні умови виникнення кулонівської блокади

Перенесення заряду через макроскопічний тунельний контакт є неперервним процесом, де квантові флуктуації заряду на конденсаторі `ΔQ` визначаються співвідношенням невизначеностей Гейзенберга `ΔE · Δt ≥ ℏ`. Для спостереження дискретної одноелектронної блокади необхідне одночасне виконання двох фундаментальних критеріїв: **енергетичного** та **квантово-декогерентного**.

Перший критерій — **енергетична умова пригнічення теплових флуктуацій**:

```
E_c = e² / (2 · C_Σ) >> k_B · T
```

де `k_B ≈ 1.38 × 10⁻²³ Дж/К` — стала Больцмана, `T` — абсолютна температура. Якщо теплова енергія `k_B · T` є порівнянною або більшою за `E_c`, електронами розмивається термодинамічний розподіл Фермі — Дірака в електродах, надаючи носіям достатньо енергії для спонтанного подолання зарядового бар'єру. Для острова з ємністю `C_Σ = 1 фФ` (`10⁻¹⁵ Ф`) енергія заряджання становить `E_c ≈ 0.08 меВ`, що вимагає охолодження пристрою нижче `T < 1 К`. При зменшенні острова до `1 нм` (наприклад, поодинока молекула або золотий нанокластер з ємністю `C_Σ = 1 аФ`) енергія `E_c` зростає до `80 меВ`, що дозволяє спостерігати кулонівську блокаду за кімнатної температури (`T = 300 К`).

Другий критерій — **умова локалізації заряду (квантовий опір)**:

```
R_T >> R_Q = h / (2 · e²) ≈ 12.9 кОм
```

Для того щоб заряд електрона перебував на острові триваліший час, ніж квантовий час флуктуації `Δt ≈ ℏ / E_c`, тунельний опір бар'єра `R_T` має бути набагато більшим за квант опору `R_Q`. Опір тунельного контакту описується експоненціальною залежністю від товщини тунельного диелектрика `d` та висоти потенціального бар'єру `U_0`:

```
R_T ∝ exp( 2 · d · √(2 · m* · U_0) / ℏ )
```

Час релаксації заряду на конденсаторі становить `τ_RC = R_T · C_Σ`. Підставляючи `τ_RC` у співвідношення Гейзенберга `E_c · τ_RC >> ℏ`, отримуємо:

```
(e² / (2 · C_Σ)) · (R_T · C_Σ) >> ℏ  ⇒  R_T >> 2 · ℏ / e² = h / (π · e²) ≈ 8.2 кОм
```

Якщо тунельний бар'єр є занадто прозорим (`R_T < R_Q`), квантове тунелювання електронів відбувається настільки швидко, що хвильова функція електрона делокалізується між островами та електродами, дискретне число електронів `n` втрачає свій сенс, а кулонівська блокада руйнується квантовими флуктуаціями заряду.

Третій важливий фактор — **вплив електромагнітного оточення (Environment Theory)**. Для ізольованого поодинокого тунельного контакту кулонівська блокада пригнічується квантовими флуктуаціями заряду через паразитну ємність підвідних дротів. Щоб спостерігати блокаду на поодинокому переході, зовнішній вимірювальний імпеданс `Z_ext(ω)` на високих частотах повинен перевищувати квант опору `Z_ext >> R_Q` безпосередньо поблизу контакту (на відстані, меншій за довжину хвилі електромагнітного випромінювання). У транзисторних структурах (SET) роль високоомного захисного середовища виконує другий тунельний перехід, послідовно з'єднаний із першим. При цьому власні квантові флуктуації електромагнітного поля у зовнішньому колі модифікують ймовірність тунелювання через функцію $P(E)$, яка описує обмін енергією між тунелюючим електроном та модами довкілля.

![Енергетична діаграма кулонівської блокади](/book/physics/condensed-matter-physics/coulomb-blockade/img/coulomb-blockade-energy-diagram.svg)
*Рис. 1. Енергетична діаграма тунельного острова. Ліворуч: режим кулонівської блокади (eV_ds < E_c), де рівень Фермі острова перебуває у забороненій енергетичній щілині 2E_c. Праворуч: провідний режим (eV_ds > E_c), коли прикладана напруга зміщення зміщує рівні і відкриває одно-електронний тунельний транспорт.*

### 2. Електростатика квантового острова та енергетичні параболи

Розглянемо острівець із `n` надлишковими електронами. Електростатичний потенціал острова `V_island` визначається сумою власного заряду `-n · e` та зарядів, індукованих зовнішніми електродами через ємності переходів `C_s`, `C_d`, `C_g` та паразитні ємності підкладки `C_stray`.

Сумарна ємність острова дорівнює:

```
C_Σ = C_s + C_d + C_g + C_stray
```

Загальна вільна енергія електростатичного поля системи `E(n)` за наявності зовнішнього затворного потенціалу `V_g` описується квадратним виразом:

```
E(n, n_g) = E_c · (n - n_g)²
```

де `n_g` — безрозмірний індукований заряд затвора, виражений у одиницях елементарного заряду:

```
n_g = (C_g · V_g + Q_offset) / e
```

Тут `C_g` — ємність затворного конденсатора, а `Q_offset` — за залишковий потенціал підкладки, спричинений дефектами, пастками заряду та імплантованими іонами.

![Схема SET та параболи зарядової енергії](/book/physics/condensed-matter-physics/coulomb-blockade/img/set-circuit-and-parabolas.svg)
*Рис. 2. Еквівалентна електрична схема одно-електронного транзистора (ліворуч) та родина парабол електростатичної енергії E(n) як функцій затворного заряду n_g (праворуч). Перетин парабол n та n+1 у точках n_g = n + 0.5 знімає кулонівську блокаду.*

Енергетичні параболи `E(n)` описують дискретний спектр системних станів. При цілих значеннях індукованого заряду `n_g = 0, 1, 2...` мінімум енергії відповідає строго визначеній кількості електронів `n = n_g`. Щоб змінити число електронів від `n` до `n + 1`, необхідно затратити енергію:

```
ΔE = E(n+1) - E(n) = E_c · [ (n + 1 - n_g)² - (n - n_g)² ] = 2 · E_c · (n + 0.5 - n_g)
```

При `n_g = n` робота додавання дорівнює `ΔE = E_c`. Для малого сток-витокового зміщення `e · V_ds < E_c` жоден електрон не може перейти з витоку на острівець або з острова на сток, оскільки цей процес вимагає позитивного припливу енергії (`ΔE > 0`), забороненого за нульової температури. Система залишається у блокованому стані із `I = 0`.

Ситуація кардинально змінюється в точках енергетичного виродження `n_g = n + 0.5` (наприклад, `n_g = 0.5, 1.5, 2.5...`). У цих точках значення енергії для `n` та `n + 1` електронів є суворо однаковими:

```
E(n, n_g = n + 0.5) = E(n+1, n_g = n + 0.5)
```

Енергетичний бар'єр заряджання зникає повністю (`ΔE = 0`). Електрон може вільно тунелювати на острівець і одразу ж тунелювати далі на сток без виконання роботи проти електростатичного поля. При зміні напруги затвора `V_g` провідність пристрою описує послідовність періодичних **кулонівських осциляцій**.

У багатозатворних структурах (Multi-Gate SET) сумарний індукований заряд складається з векторного внеску всіх затворів `n_g = ∑_k (C_g,k · V_g,k) / e`. Це дозволяє використовувати квантові точки як логічні елементи із багатьма входами.

Строгий математичний вивід парціальних швидкостей переходів за Золотим правилом Фермі, рівнянь стаціонарного рівняння балансу та профілю осциляцій наведено у вставці [math-orthodox-tunneling.md](book:physics/condensed-matter-physics/coulomb-blockade/math-orthodox-tunneling.md).

### 3. Одноелектронний транзистор (SET) та кулонівські осциляційні піки

Одно-електронний транзистор (Single-Electron Transistor, SET) є трьохелектродним нанопристроєм, який складається з провідного острова, під'єднаного через два тунельні переходи із ємностями `C_s`, `C_d` та опорами `R_s`, `R_d` до витоку й стоку, а також ємнісно зв'язаного з затвором `V_g`.

За малих напруг зміщення сток-витік `V_ds << E_c / e` диференціальна провідність `G = dI / dV_ds` як функція напруги затвора `V_g` демонструє гострі піки, розділені широкими зонами нульової провідності. Період осциляцій по напрузі затвора `ΔV_g` визначається геометричною ємністю затвора `C_g`:

```
ΔV_g = e / C_g
```

Кожен пік відповідає додаванню рівно одного електрона на острівець. Цей ефект дозволяє підраховувати електрони по одному з абсолютною точністю.

За скінченної температури `T > 0` амплітуда і форма осциляційного піка описуються аналітичним виразом:

```
G(V_g) = ( 1 / (2 · (R_s + R_d)) ) · cosh⁻² [ (C_g · (V_g - V_peak)) / (2 · k_B · T / e) ]
```

З цієї формули випливають важливі властивості кулонівського піка:
- **Центр піка (`V_peak`):** Відповідає напрузі затвора `V_g = (n + 0.5) · e / C_g`.
- **Напівширина піка (FWHM):** Допомагає прямо вимірювати температуру електронного газу `ΔV_g,FWHM ≈ 3.52 · (k_B · T / e) · (C_Σ / C_g)`.
- **Амплітуда піка:** При підйомі температури амплітуда спадає як `1 / T`, а при `k_B · T ≈ E_c` піки повністю перекриваються, повертаючи пристрій до омічного режиму із постійною провідністю `G_0 = 1 / (R_s + R_d)`.

Важливою характеристикою SET є **коефіцієнт підсилення по напрузі** `A_V`:

```
A_V = dV_ds / dV_g = C_g / C_d
```

Для того щоб одноелектронний транзистор міг використовуватись у складних логічних схемах як підсилювач (де вихідний сигнал керує наступним каскадом), ємність затвора повинна перевищувати стокову ємність `C_g > C_d`, що вимагає високоточного асиметричного проектирования наноструктури.

### 4. Кулонівські сходи в асиметричних бар'єрах (Coulomb Staircase)

Якщо тунельні переходи SET суттєво відрізняються за опором (наприклад, `R_s >> R_d`), вольт-амперна характеристика `I(V_ds)` демонструє унікальну ступенчату структуру — **кулонівські сходи** (Coulomb Staircase).

Фізичний механізм виникнення сходів полягає у драматичній різниці швидкостей тунелювання. Оскільки `R_s >> R_d`, швидкість тунелювання через витоковий бар'єр `Γ_s` є набагато меншою за швидкість тунелювання через стоковий бар'єр `Γ_d`. Коли електрон нарешті проникає через високоомний бар'єр `R_s` на острівець, він майже миттєво (`~10⁻¹² с`) залишає острівець через низькоомний бар'єр `R_d`.

У результаті острівець більшість часу перебуває у стані з числом надлишкових електронів `n = 0`. При зростанні напруги зміщення `V_ds` послідовно відкриваються нові енергетичні канали для тунелювання `n → n+1`.

Параметри кулонівських сходів описуються точними формулами:
- **Порогові напруги відкриття сходів:** `V_threshold(N) = (2·N + 1) · e / (2 · C_Σ)`.
- **Ширина ступеня по напрузі:** `ΔV_ds = e / C_Σ`.
- **Стрибок струму на сходинці:** `ΔI = e / (R_s · C_Σ)`.

Кулонівські сходи також спостерігаються у самоорганізованих масивах металевих наночастинок та гранульованих плівках, де виникає випадковий розподіл тунельних опорів між суміжними гранулами.

Чисельне моделювання вольт-амперних характеристик SET, розрахунок кулонівських сходів та двовимірних карт провідності мовами Python і C++ наведено у практичній вставці [proj-set-simulation.md](book:physics/condensed-matter-physics/coulomb-blockade/proj-set-simulation.md).

### 5. Діаграма стабільності: геометрична математика кулонівських ромбів

При одночасній зміні напруги затвора `V_g` та напруги зміщення сток-витік `V_ds` диференціальна провідність `G(V_g, V_ds)` формує двовимірну карту стабільності заряду — **кулонівські ромби** (Coulomb Diamonds).

![Діаграма стабільності (кулонівські ромби)](/book/physics/condensed-matter-physics/coulomb-blockade/img/coulomb-diamonds.svg)
*Рис. 3. Двовимірна діаграма стабільності заряду (кулонівські ромби) в координатах (V_g, V_ds). Всередині ромбів струм строго блокований (I = 0), а число електронів n є фіксованим. Нахили граней k_1 та k_2 задаються співвідношенням парціальних ємностей C_g, C_s, C_d.*

Кожен ромб являє собою область у координатному просторі `(V_g, V_ds)`, у якій число електронів `n` на острові є строго фіксованим цілим числом, а тунельний струм дорівнює нулю (`I = 0`).

Геометричні межі кулонівського ромба визначаються чотирма лінійними рівняннями відкриття першого тунельного каналу:

1. **Верхня права межа (тунелювання S → I):**
   ```
   V_ds = ( 2·E_c / e ) · ( C_Σ / (C_d + C_g/2) ) · ( n + 0.5 - n_g )
   ```
   Схил цієї межі дорівнює: `k_1 = dV_ds / dV_g = C_g / (C_d + C_g)`.

2. **Верхня ліва межа (тунелювання I → D):**
   ```
   V_ds = - ( 2·E_c / e ) · ( C_Σ / (C_s + C_g/2) ) · ( n + 0.5 - n_g )
   ```
   Схил другої межі дорівнює: `k_2 = dV_ds / dV_g = - C_g / C_s`.

Геометрія ромба безпосередньо пов'язана з фундаментальними параметрами наноструктури:
- **Ширина ромба уздовж осі затвора (`V_ds = 0`):** `ΔV_g = e / C_g`.
- **Максимальна висота ромба по осі зміщення (`n_g = n`):** `ΔV_ds = e / C_Σ = 2 · E_c / e`.

Вимірювання кутів нахилу граней `k_1` та `k_2` на експериментальній карті дозволяє з високою точністю вичислити всі внутрішні ємності пристрою (`C_g`, `C_s`, `C_d`) без проведення руйнівного розтину зразка.

Для **подвійних квантових точок** (Double Quantum Dot, DQD), розташованих послідовно, двовимірна діаграма стабільності в координатах затворів двох точок `(V_g1, V_g2)` утворює регулярну стільникову структуру (Honeycomb Pattern). Точки потрійного перетину (Triple Points) на межах стільників відповідають станам квантового виродження трьох зарядних станів `(n_1, n_2)`, `(n_1 + 1, n_2)` та `(n_1, n_2 + 1)`, через які здійснюється когерентний двосерійний транспорт носіїв.

### 6. Квантово-розмірне квантування та надпровідні острови

Коли розміри провідного острова зменшуються до кінетичної довжини хвилі електрона (`L < 20 нм`), окрім макроскопічної кулонівської енергії заряджання `E_c`, виникає **квантово-розмірне квантування** одночастинкових енергетичних рівнів.

Відстань між сусідніми квантованими рівнями у квантовій точці описується формулою:

```
Δε = (π² · ℏ²) / (2 · m* · L²)
```

де `m*` — ефективна маса електрона у провідності.

Повна енергія додавання другого електрона на один і той самий рівень включає як кулонівське відштовхування, так і орбітальний зсув:
- Додавання 2-го електрона на той самий рівень зі протилежним спіном: `E_add = E_c`.
- Додавання 3-го електрона на наступний орбітальний рівень: `E_add = E_c + Δε`.

Це призводить до чергування великих і малих кулонівських ромбів на діаграмах стабільності квантових точок у напівпровідникових гетероструктурах `GaAs/AlGaAs` та кремнієвих нанодротах.

Для **надпровідних островів** (наприклад, алюмінієвий острівець при `T < 1.2 К`) носіями заряду є куперівські пари із зарядом `2·e`. Енергетичний спектр острова залежить від співвідношення між зарядною енергією `E_c` та надпровідною енергетичною щілиною `Δ_super`.

Виникає характерний **паритетний ефект (Even-Odd Effect)**:
- Коли число електронів є парним (`N = 2m`), усі електрони спарені в куперівські пари.
- Коли число електронів є непарним (`N = 2m + 1`), один електрон залишається неспареним квазічастинковим збудженням.

Додавання неспареного електрона вимагає виконання додаткової роботи з розриву куперівської пари `Δ_super`. Якщо `Δ_super > E_c`, непарні розв'язки стають енергетично невигідними при будь-яких значеннях затвора, і період кулонівських осциляцій подвоюється:

```
ΔV_g,super = 2 · e / C_g
```

У надпровідних пристроях **куперівських пар** (Cooper Pair Box) тунелювання куперівських пар задається Джозефсонівською енергією `E_J`. Регулювання співвідношення `E_J / E_c` лежить в основі роботи трансмонних кубітів (Transmon Qubits), що використовуються у сучасних квантових процесорах Google Sycamore та IBM Eagle.

### 7. Квантові процеси вищих порядків: со-тунелювання та ефект Кондо

У класичній ортодоксальній теорії всередині кулонівського ромба при `T = 0` струм строго дорівнює нулю. Однак вищі порядки квантово-механічної теорії збурень дозволяють ефекти **когерентного со-тунелювання** (co-tunneling), у яких два електрони тунелюють одночасно через віртуальні проміжні стани острова.

Розрізняють два типи со-тунелювання:

1. **Непружне со-тунелювання:** Електрон із витоку тунелює на острівець, а інший електрон з острова одночасно тунелює на сток, залишаючи острівець у збудженому електрон-дірковому стані. Струм непружного со-тунелювання залежить від напруги як `I_co ∝ V_ds³` при `T → 0` або `I_co ∝ V_ds · T²` при скінченній температурі.
2. **Пружне со-тунелювання:** Один і той самий електрон тунелює крізь обидва бар'єри без залишення енергії збудження на острові. Струм є лінійним по напрузі `I_co ∝ V_ds / E_c²`.

Со-тунелювання створює паразитно витоковий фоновий струм усередині кулонівських ромбів, що задає фундаментальну нижню межу витоку заряду в осередках одноелектронної пам'яті.

Іншим фундаментальним багаточастинковим явищем є **ефект Кондо в квантових точках**. 

Якщо острівець містить непарне число електронів (`n = 2·m + 1`), останній електрон має неспарений спін `S = 1/2`. Нижче температури Кондо `T < T_K` антиферомагнітна обмінна взаємодія між спіном острова та електронами провідності в електродах формує зв'язаний багаточастинковий синглетний стан.

Температура Кондо `T_K` описується експоненціальним виразом:

```
T_K = ( √(Γ · E_c) / 2 ) · exp[ - (π · E_c) / (8 · Γ) ]
```

де `Γ` — квантове уширення рівня острова через тунельний зв'язок з електродами.

На рівні Фермі виникає резонансний пік густини станів (резонанс Абрикосова — Сула), який повністю знімає кулонівську блокаду при `V_ds → 0` всередині непарних ромбів. Провідність пристрою зростає до теоретичного унітарного ліміту:

```
G_Kondo = 2 · e² / h ≈ 77.48 мкСім
```

### 8. Кулонівська блокада у низьковимірних наноматеріалах (0D, 1D, 2D)

Прояв кулонівської блокади суттєво залежить от розмірності електронної системи та матеріалознавчого виконання тунельного острова:

- **Одновимірні нанотрубки (1D Carbon Nanotubes):** У вуглецевих нанотрубках із двома електронними долинами `K` та `K'` кулонівські ромби формують чотирикратне виродження за спіном та долиною. Група із 4 ромбів відображає послідовне заповнення однієї орбіталі 4 електронами, після чого виникає стрибок додаткової орбітальної енергії `Δε`.
- **Двовимірний графін (2D Graphene Quantum Dots):** Оскільки у безщілинному графіні електрони підпорядковуються рівнянню Дірака і викликають ефект Клейнівського тунелювання (безбар'єрне проходження через високі потенційні сходинки), створення тунельних контактах вимагає спеціального геометричного звуження (нанострічки, Graphene Nanoribbons). Завдяки відсутності спін-орбітального розщеплення кулонівські піки у графінових точках володіють високою фазовою когерентністю.
- **Одномолекулярні транзистори (Single-Molecule Transistors):** При ізоляції поодинокої молекули (наприклад, фулерена `C₆₀` або металоорганічного комплексу) між золотими електродами з ємністю `C_Σ ≈ 0.1 аФ`, енергія заряджання сягає `E_c ≈ 0.5 еВ`. Тунелювання електрона супроводжується збудженням внутрішньомолекулярних квантованих вібрацій (фононів). Це викликає появу додаткових супутникових ліній провідності на діаграмі стабільності — **Франк-Кондонівську блокаду** (Franck-Condon Blockade).

### 9. Експериментальна техніка, кріогенне устаткування та зарядовий шум

Вимірювання кулонівської блокади вимагає унікального кріогенного інструментарію, здатного підтримувати температури електронного газу на рівні `10–50 мК` і пригнічувати зовнішні електромагнітні перешкоди.

Вимірювальний комплекс розбудовується на базі **кріостатів розчинення ³He/⁴He** (Dilution Refrigerators). Проте температура механічної камери розчинення (`10 мК`) автоматично не означає таку саму температуру носіїв заряду в наноструктурі: гарячі електрони легко прогріваються високочастотним випромінюванням кімнатної температури, що наводиться через металеві кабелі.

Для захисту наноструктур від чорнотільного шуму довкілля застосовується трирівнева система фільтрації:
1. **Холодні атенюатори (Coaxial Attenuators):** Встановлюються на кожному ступені охолодження кріостату (`4.2 K`, `1 K`, `100 mK`, `10 mK`) для послаблення теплових шумів верхніх ступенів.
2. **Мідно-порошкові фільтри (Copper Powder Filters):** Високочастотні зрізові фільтри, що складаються з мідного нанопорошку в епоксидній матриці, які ефективно поглинають гігагерцові перешкоди (`> 1 ГГц`).
3. **П'єзоелектричні `RC`-фільтри:** Зрізають низькочастотні наводки мережі живлення (`50 Гц`).

Другим ключовим експериментальним бар'єром є **низькочастотний зарядовий шум типа `1/f`**. 

Усі напівпровідникові та металеві острівці контактують із підкладкою (`SiO₂`, `Al₂O₃`) або захисним оксидом. У цих диелектриках присутні двопозиційні центри захоплення електронів (Two-Level Systems, TLS). Випадковий стрибок заряду поблизу острова викликає зсув затворного потенціалу `ΔQ_offset ≈ ±0.1 e`, що призводить до часового дрейфу кулонівських піків та зсуву ромбів стабільності.

Для боротьби з зарядовим дрейфом застосовуються спеціальні схеми активного зворотного зв'язку (Active Charge Stabilization), де високочастотне зчитування RF-SET реєструє зміщення піка і миттєво коригує постійну напругу затвора `V_g`.

### 10. Одноелектронна логіка, пам'ять та межа Ландауера

Здатність одно-електронного транзистора переключатися між провідним та блокованим станами при перенесенні одного електрона відкрила напрямок **одноелектронної логіки (Single-Electron Logic, SEL)** та **одноелектронної пам'яті (Single-Electron Memory, SEM)**.

У комірках одноелектронної пам'яті носієм інформації (`0` або `1`) служить наявність або відсутність поодинокого електрона на металевому плаваючому затворі (Floating Gate). Тунелювання на плаваючий затвор здійснюється через високоомний тунельний бар'єр при короткочасному подаванні керуючого імпульсу.

Фундаментальною перевагою одноелектронних пристроїв є екстремально мала дисипація енергії. Теплова енергія, що розсіюється при перенесенні одного електрона через потенціальний бар'єр `V_ds`, дорівнює:

```
E_diss = e · V_ds ≈ E_c
```

Для атоофарадних ємностей `E_diss ≈ 10⁻²⁰ Дж`, що на 5 порядків менше за енергію переключення сучасних кремнієвих CMOS-транзисторів (`10⁻¹⁵ Дж`) і наближається до термодинамічної межі Ландауера `E_min = k_B · T · ln(2) ≈ 3 × 10⁻²¹ Дж` при `300 К`.

Проте практичне впровадження масової одноелектронної логіки зіткнулося з двома інженерними обмеженнями:
- **Чутки дрейфу заряду:** Будь-який випадковий заряд підкладки `Q_offset` може незворотно інвертувати логічний стан комірки.
- **Низька навантажувальна здатність:** Мала струмова потужність SET (`I ≈ 1–100 нА`) не дозволяє швидко перезаряджати паразитні ємності міжз'єднань на макроскопічних кристалах.

### 11. Одноелектронні насоси та турнікети (Single-Electron Pumps & Turnstiles)

Для застосування кулонівської блокади в фундаментальній метрології розроблено пристрої періодичного транспорту носіїв — **одноелектронні насоси** (Pumps) та **турнікети** (Turnstiles).

Різниця між ними полягає в динаміці керування:
- **Одноелектронний турнікет (Single-Electron Turnstile):** Складається з двох тунельних переходів та одного затвора, на який подається змінна напруга `V_g(t) = V_0 + V_ac · sin(2·π·f·t)` за наявності постійної напруги зміщення `V_ds`. У першому півперіоді потенціал острова знижується, дозволяючи одному електрону тунелювати з витоку на острівець. У втором півперіоді потенціал зростає, виштовхуючи електрон з острова на сток.
- **Одноелектронний насос (Single-Electron Pump):** Складається з ланцюжка з трьох чи більше тунельних переходів із двома або більше затворами, на які подаються зміщені за фазою напруги `V_g1(t)` та `V_g2(t)` (зсув фаз `π/2`). Це дозволяє транспортувати електрон через острівці навіть при суворо нульовій зовнішній напрузі зміщення `V_ds = 0`.

В обох випадках середній струм через пристрій строго квантується за частотою сигналів затвора:

```
I = f · e
```

Сучасні одноелектронні насоси на основі кремнієвих квантових точок забезпечують метрологічну точність квантування струму з відносною похибкою, меншою за `10⁻⁷` (0.1 ppm) при струмах `I ≈ 100 пА`. Це фундаментальне явище сформувало основу первинного квантового еталону сили струму, який увійшов у реформовану систему одиниць SI (2019 рік), остаточно зв'язавши електричні вимірювання із зафіксованими значеннями константи Планка `h` та зарядові константи електрона `e`.

### 12. Порівняльний фізичний та технологічний аналіз типів SET

Залежно від фізичної природи матеріалів islands та тунельних контактах, одноелектронні транзистори розрізняються за ключовими фізичними параметрами та технологічною реалізацією.

Порівняльна характеристика типів пристроїв:

1. **Металевий SET (Al / Al₂O₃ / Al):**
   - **Острівець:** Металевий алюмінієвий острів (`L ≈ 50–100 нм`).
   - **Переходи:** Оксид алюмінію `Al₂O₃`, отриманий термоокисленням у вакуумі (техніка тіньового напилення Долана).
   - **Особливості:** Неперервна густина станів, низька ємність затвора, відсутність квантово-розмірного квантування `Δε ≈ 0`. Працює за кріогенних температур (`T < 1 K`).
2. **Напівпровідниковий SET (Si-FinFET / GaAs-2DEG):**
   - **Острівець:** Двовимірний електронний газ (2DEG) або кремнієва квантова точка (`L ≈ 10–30 нм`).
   - **Переходи:** Збіднені електродні зони під збіркою бічних металевих затворів.
   - **Особливості:** Яскраво виражене квантово-розмірне квантування `Δε ≈ E_c`, можливість електричного регулювання тунельних опорів `R_s`, `R_d` за допомогою змінної потенціальної висоти бар'єра.
3. **Молекулярний SET (Single-Molecule C₆₀ / Oligo-Phenylene):**
   - **Острівець:** Поодинока органічна молекула (`L ≈ 1 нм`).
   - **Переходи:** Механічно керовані розривні контакти (Mechanically Controllable Break Junctions, MCBJ).
   - **Особливості:** Екстремально висока зарядова енергія `E_c > 100 меВ`, спостереження кулонівської блокади за кімнатної температури (`300 K`), сильний зв'язок із молекулярними вібраціями (фононами).
4. **Надпровідний SET / CPB (Cooper Pair Box):**
   - **Острівець:** Надпровідний алюмінієвий острівець за температур `T < 1.2 K`.
   - **Переходи:** Джозефсонівські тунельні переходи (`Al/Al₂O₃/Al`).
   - **Особливості:** Когерентний транспорт куперівських пар, паритетний ефект, регулювання співвідношення `E_J / E_c`, фундаментальна база трансмонних кубітів.

### 13. Перспективи розвитку одноелектронної наноелектроніки

Сучасна фізика конденсованого стану демонструє стрімкий перехід від дослідження поодиноких одноелектронних транзисторів до інтеграції масштабних матрицій квантових точок у промислові напівпровідникові процесори.

Головними векторами розвитку технології є:
- **Кремнієві спінові кубіти на базі CMOS:** Використання стандартного 300-мм промислового літографічного процесу (FD-SOI та FinFET) дозволяє формувати квантові точки розміром `10 нм` із надійним кулонівським обмеженням. Керована кулонівська блокада ізолює неспарені електронні спіни, створюючи кубіти з тривалістю фазової когерентності `T_2 > 1 мс`.
- **Кріогенні схеми керування (Cryo-CMOS):** Для керування тисячами затворів у кубітна матрицях створюються інтегровані кріогенні мікросхеми, що працюють при `4 К` поруч із кріостатом розчинення. Це усуває проблему теплового припливу через тисячі коаксіальних дротів.
- **Однофотонні квантові сенсори та НВЧ-спектроскопія:** Інтеграція RF-SET у надпровідні мікрохвильові резонатори відкриває можливість вимірювання окремих терагерцових та НВЧ фотонів із роздільною здатністю, обмеженою лише квантовим шумом Гейзенберга. Завдяки високій чутливості до затворного заряду, радіочастотний транзистор діє як ультрашвидкий електрометр із часовою роздільною здатністю наносекундного діапазону. Це дозволяє в реальному часі проводити дисперсійне безрозірне зчитування станів квантових бітів.

### 14. Практичні застосування кулонівської блокади у квантовій інженерії

Кулонівська блокада виросла з фундаментального фізичного ефекту у потужний інструмент нанотехнологій, метрології та квантових обчислень.

Основоположні напрямки застосування включають:

- **Високочутлива електрометрія (SET Electrometer):** Завдяки високій затворній крутизні `g_m = dI / dV_g` поблизу кулонівського піка, SET є найчутливішим відомим електрометром. Він здатний реєструвати зарядові флуктуації на рівні `δq ≈ 10⁻⁶ · e / √Гц`.
- **Радіочастотний транзистор (RF-SET):** Для подолання обмеження паразитних ємностей вимірювальних дротів (`RC`-фільтр низьких частот із зрізом біля `1 кГц`), SET інтегрується в резонансний `LC`-контур узгодження імпедансу із частотою `f_0 ≈ 1–3 ГГц`. Зміна затворного заряду модулює дифпровідність транзистора, що змінює коефіцієнт відбиття високочастотного сигналу `Γ_RF`. Це розширює вимірювальну смугу частот понад `100 МГц`, дозволяючи проводити однознімкове дисперсійне бездисипативне зчитування спінових та зарядових кубітів у реальному часі без розсіювання тепла Джоуля на острові.
- **Первинна термометрія (Coulomb Blockade Thermometer, CBT):** Масив паралельно-послідовних металевих тунельних переходів демонструє напівширину диференціального опору `ΔV_1/2`, яка залежить виключно від фундаментальних констант та абсолютної температури `ΔV_1/2 = 5.439 · N_junctions · k_B · T / e`. CBT використовується як первинний кріогенний термометр у діапазоні `10 мК – 30 К`.
- **Квантові обчислення (Transmon & Quantum Dots):** Керована кулонівська блокада в напівпровідникових квантових точках (`Si/SiGe`, `GaAs`) дозволяє ізолювати поодинокі електрони для створення спінових кубітів Клосса — Лосса. У надпровідникових квантових схемах енергія заряджання `E_c` задає ангармонічність енергетичних рівнів трансмонів, гарантуючи селективне мікрохвильове керування станами `|0⟩` та `|1⟩`.

Отже, кулонівська блокада являє собою міст між класичною електростатикою Максвелла та квантовою теорією багаточастинкових систем.
