# 🧮 Ортодоксальна теорія одноелектронного тунелювання та математичний вивід кулонівських сходів

Ортодоксальна теорія одноелектронного тунелювання, сформульована Дмитром Аверіним та Костянтином Ліхарєвим у 1985 році, описує квантово-механічний та електростатичний транспорт носіїв заряду через ультрамалі тунельні переходи та квантові острови. У цій вставці наведено строгий математичний вивід електростатичного потенціалу острова, парціальних швидкостей тунелювання за Золотим правилом Фермі, розв'язок стаціонарного рівняння балансу (Master Equation), аналітичний розрахунок кулонівських сходів, геометрію меж кулонівських ромбів, математику надпровідного пристрою куперівських пар, квантово-розмірне квантування, резонанс Кондо та метрологічні вирази чутливості RF-SET.

---

### 1. Повна електростатична енергія та потенціал острова

Розглянемо одноелектронний транзистор (Single-Electron Transistor, SET), що складається з провідного острова, під'єднаного через два тунельні переходи з ємностями `C_s` (витік) та `C_d` (сток) до зовнішніх електродів із потенціалами `V_s` та `V_d`, а також через ємнісний затвор `C_g` до джерела затворного потенціалу `V_g`.

Загальна електростатична ємність острова дорівнює сумі всіх парціальних ємностей (з урахуванням можливих паразитних ємностей підкладки `C_stray`):

```
C_Σ = C_s + C_d + C_g + C_stray
```

Якщо на острові перебуває `n` надлишкових електронів, його сумарний вільний заряд становить `Q = -n · e`, де `e ≈ 1.602 × 10⁻¹⁹ Кл` — елементарний заряд. Потенціал острова `V_island` визначається сумісною дією заряду острова та індукованих зарядів від зовнішніх електродів:

```
V_island(n, V_s, V_d, V_g)
= ( -n·e + C_s·V_s + C_d·V_d + C_g·V_g ) / C_Σ
```

Загальна електростатична енергія системи `E(n)` складається з власної енергії заряджання конденсаторів та роботи, виконаної зовнішніми джерелами напруги при зміні заряду:

```
E(n, V_s, V_d, V_g)
= ( (-n·e + C_s·V_s + C_d·V_d + C_g·V_g)² ) / (2 · C_Σ) - W_ext
```

Виразивши енергію через прикладену напругу сток-витік `V_ds = V_s - V_d` (при симетричному подаванні `V_s = V_ds / 2`, `V_d = -V_ds / 2`) та безрозмірний індукований заряд затвора `n_g = C_g · V_g / e`, електростатичну енергію можна подати у виточеній параболічній формі:

```
E(n, n_g, V_ds)
= E_c · (n - n_g)² - e · V_ds · [ (C_s + C_g/2) / C_Σ · n + C_d / C_Σ · n_g ]
```

де `E_c` — характеристична **енергія заряджання** одного електрона:

```
E_c = e² / (2 · C_Σ)
```

Енергія заряджання `E_c` задає фундаментальний енергетичний масштаб кулонівської блокади: це робота, яку необхідно виконати проти кулонівського поля острова для додавання одного додаткового електрона `n → n+1` за відсутності зовнішньої напруги затвора (`n_g = 0`).

### 2. Зміна енергії при тунельному переході та умови блокування

Тунельний процес є фізично дозволеним за низьких температур лише у випадку, якщо в результаті переходу електрона загальна вільна енергія системи **зменшується** (`ΔE < 0`). 

Розглянемо чотири елементарні тунельні процеси:

1. **Тунелювання з витоку S на острівець I (`n → n+1`):**
   Зміна вільної енергії системи описується виразом:
   ```
   ΔE_s⁺(n)
   = E(n+1) - E(n) + e · V_s
   = E_c · [ 1 + 2·(n - n_g) ] - e · V_ds · (C_d + C_g/2) / C_Σ
   ```

2. **Тунелювання з острова I на витік S (`n → n-1`):**
   ```
   ΔE_s⁻(n)
   = E(n-1) - E(n) - e · V_s
   = E_c · [ 1 - 2·(n - n_g) ] + e · V_ds · (C_d + C_g/2) / C_Σ
   ```

3. **Тунелювання зі стоку D на острівець I (`n → n+1`):**
   ```
   ΔE_d⁺(n)
   = E(n+1) - E(n) + e · V_d
   = E_c · [ 1 + 2·(n - n_g) ] + e · V_ds · (C_s + C_g/2) / C_Σ
   ```

4. **Тунелювання з острова I на сток D (`n → n-1`):**
   ```
   ΔE_d⁻(n)
   = E(n-1) - E(n) - e · V_d
   = E_c · [ 1 - 2·(n - n_g) ] - e · V_ds · (C_s + C_g/2) / C_Σ
   ```

При нульовій напрузі зміщення (`V_ds = 0`) та нульовій температурі (`T = 0`) умова блокування тунелювання означає, що додавання одного електрона (`n → n+1`) вимагає додатної енергії `ΔE_s⁺(n) > 0`, а видалення електрона (`n → n-1`) також вимагає додатної енергії `ΔE_s⁻(n) > 0`.

Це дає нерівність кулонівської блокади при цілому `n_g = n`:

```
-E_c < ΔE < +E_c  ⇒  Струм I = 0
```

### 3. Швидкості тунельних переходів за Золотим правилом Фермі

У квантовій електродинаміці швидкість пружного тунелювання електрона крізь бар'єр розраховується згідно з Золотим правилом Фермі шляхом інтегрування за всіма початковими заповненими станами в одному електроді та кінцевими вільними станами в іншому.

Нехай `R_T` — опір тунельного переходу у класичному омічному режимі за високих напруг. Парціальна швидкість тунелювання `Γ(ΔE)` для зміщення енергії `ΔE` описується інтегралом Фермі-Дірака:

```
Γ(ΔE)
= (1 / (e² · R_T)) · ∫ [ f(E) · (1 - f(E + ΔE)) ] dE
```

де `f(E) = 1 / [ 1 + exp(E / (k_B · T)) ]` — функція розподілу Фермі — Дірака.

Виконуючи аналітичне інтегрування, отримуємо точну формулу ортодоксальної теорії для швидкості тунелювання при довільній температурі `T`:

```
Γ(ΔE) = (1 / (e² · R_T)) · [ -ΔE / (1 - exp(ΔE / (k_B · T))) ]
```

Розглянемо два важливі граничні випадки цієї фундаментальної формули:

1. **Границя абсолютного нуля (`T → 0 K`):**
   Згладжуючий термічний вираз `1 / (1 - exp(x))` перетворюється на сходинкову функцію Гевісайда `θ(-ΔE)`:
   ```
   Якщо ΔE < 0 (енергетично вигодно):    Γ(ΔE) = |ΔE| / (e² · R_T)
   Якщо ΔE > 0 (кулонівська блокада):   Γ(ΔE) = 0
   ```
   Це означає, що за абсолютного нуля тунелювання строго заборонене, якщо вільна енергія системи після переходу є більшою за початкову.

2. **Високотемпературна омічна границя (`k_B · T >> |ΔE|`):**
   Розкладаючи експоненту в ряд Тейлора `exp(x) ≈ 1 + x`, отримуємо:
   ```
   Γ(ΔE) ≈ k_B · T / (e² · R_T)
   ```
   При прикладаній напрузі `V` енергетичний зсув `ΔE = -e · V`, і сумарна швидкість тунельного потоку перетворюється на омічний струм:
   ```
   I = e · [ Γ(-e·V) - Γ(+e·V) ] = V / R_T
   ```
   Таким чином, ортодоксальна теорія природно відтворює класичний закон Ома при високих температурах чи великих напругах зміщення.

### 4. Рівняння балансу стаціонарного стану (Master Equation)

Оскільки острівець є дискретною квантовою системою, його стан описується ймовірністю `P(n)` виявити на острові строго `n` надлишкових електронів у даний момент часу.

Часова еволюція векторного розподілу ймовірностей `P(n)` описується кинетичним рівнянням балансу (Master Equation):

```
d P(n) / d t
= P(n+1) · [ Γ_s⁻(n+1) + Γ_d⁻(n+1) ]
+ P(n-1) · [ Γ_s⁺(n-1) + Γ_d⁺(n-1) ]
- P(n)   · [ Γ_s⁺(n) + Γ_s⁻(n) + Γ_d⁺(n) + Γ_d⁻(n) ]
```

У стаціонарному режимі (`d P(n) / dt = 0`) отримуємо систему лінійних алгебраїчних рівнянь. Сумарна матриця переходів `W` є тридіагональною:

```
W_(n, n-1) = Γ_s⁺(n-1) + Γ_d⁺(n-1)
W_(n, n+1) = Γ_s⁻(n+1) + Γ_d⁻(n+1)
W_(n, n)   = - [ Γ_s⁺(n) + Γ_s⁻(n) + Γ_d⁺(n) + Γ_d⁻(n) ]
```

Разом із умовою нормування ймовірностей `∑_n P(n) = 1`, матрична система `W · P = 0` вироджується в один розв'язок через детальний баланс між сусідніми станами:

```
P(n+1) / P(n)
= [ Γ_s⁺(n) + Γ_d⁺(n) ] / [ Γ_s⁻(n+1) + Γ_d⁻(n+1) ]
```

Після розрахунку стаціонарного розподілу ймовірностей `P(n)`, підсумковий тунельний струм `I`, що протікає через транзистор від витоку до стоку, розраховується як баланс тунельних подій через будь-який із двох бар'єрів (наприклад, через витік `S`):

```
I = e · ∑_(n = -∞)⁺∞ P(n) · [ Γ_s⁺(n) - Γ_s⁻(n) ]
```

Оскільки у стаціонарному стані накопичення заряду на острові не відбувається, струм через витоковий бар'єр `I_s` суворо дорівнює струму через стоковий бар'єр `I_d`.

### 5. Геометрія та аналітичні рівняння меж кулонівських ромбів

Кулонівські ромби (Coulomb Diamonds) на діаграмі стабільності в координатах `(V_g, V_ds)` являють собою замкнені чотирикутники, всередині яких тунельний струм строго дорівнює нулю (`I = 0`).

Межі ромба для фіксованого числа електронів `n` визначаються чотирма рівняннями відкриття першого тунельного каналу:

1. **Тунелювання S → I (`ΔE_s⁺(n) = 0`):**
   ```
   V_ds = ( 2·E_c / e ) · ( C_Σ / (C_d + C_g/2) ) · ( n + 0.5 - n_g )
   ```
   Схил цієї прямої на площині `(V_g, V_ds)` становить:
   ```
   k_1 = dV_ds / dV_g = C_g / (C_Σ - C_s) = C_g / (C_d + C_g)
   ```

2. **Тунелювання I → D (`ΔE_d⁻(n) = 0`):**
   ```
   V_ds = - ( 2·E_c / e ) · ( C_Σ / (C_s + C_g/2) ) · ( n + 0.5 - n_g )
   ```
   Схил другої прямої становить:
   ```
   k_2 = dV_ds / dV_g = - C_g / C_s
   ```

Перетин чотирьох ліній утворює ромб із наступними геометричними параметрами:
- **Ширина ромба по затвору при `V_ds = 0`:** `ΔV_g = e / C_g`.
- **Максимальна висота ромба по `V_ds` (при `n_g = n`):** `ΔV_ds = e / C_Σ`.

Вимірювання нахилів меж кулонівського ромба `k_1` та `k_2` на експериментальній карті провідності дозволяє високоточно визначити всі парціальні ємності структури: `C_g`, `C_s` та `C_d`.

### 6. Математичний вивід ступенів кулонівських сходів (Coulomb Staircase)

Кулонівські сходи являють собою послідовність ступінчастих плато на вольт-амперній характеристиці `I(V_ds)`, що виникають у тунельних структурах із сильною асиметрією опорів бар'єрів (`R_s >> R_d` або `R_d >> R_s`).

Розглянемо асиметричний SET, у якому опір першого бар'єру є набагато більшим за опір другого (`R_s >> R_d`), а ємності є рівними (`C_s = C_d = C`).

Оскільки `R_d` є дуже малим, електрон, що тунелював з витоку на острівець крізь високоомний бар'єр `R_s`, майже миттєво залишає острівець через низькоомний бар'єр `R_d` (`Γ_d >> Γ_s`). Це означає, що заселеність острова обмежена двома основними станами заряду `n = 0` та `n = 1`.

При підвищенні сток-витік напруги `V_ds` енергетичний зсув `ΔE_s⁺(n)` послідовно долає енергетичні пороги для відкриття нового тунельного каналу.

Поріг відкриття `N`-ї кулонівської сходинки за нульової температури визначається умовою `ΔE_s⁺(N) = 0`:

```
V_threshold(N) = (2·N + 1) · e / (2 · C_Σ)
```

Ширина кожної кулонівської сходинки по напрузі є постійною величиною:

```
ΔV_ds = e / C_Σ
```

Висота ступеня струму (значення струму на `N`-му плато) визначається повільно-протікаючим бар'єром `R_s`:

```
I_N = N · e / (R_s · C_Σ) = N · (E_c / e) / R_s
```

Стрибок струму при переході від `N`-ї до `(N+1)`-ї сходинки становить:

```
ΔI = e / (R_s · C_Σ)
```

Цей результат підтверджує, що кулонівські сходи є прямою макроскопічною маніфестацією послідовного відкриття нових одноелектронних транспортних каналів при збільшенні напруги зміщення.

### 7. Температурне розширення та аналітичний профіль піків кулонівських осциляцій

За малих напруг зміщення `V_ds << k_B · T / e` диференціальна провідність `G = dI / dV_ds` при зміні затворної напруги `V_g` описується кулонівськими осциляціями.

Поблизу точки виродження енергії `n_g = n + 0.5`, де енергії двох зарядних станів `E(n)` та `E(n+1)` збігаються, ортодоксальна теорія дає аналітичну формулу для профілю провідності:

```
G(V_g)
= G_max / cosh²[ C_g · (V_g - V_peak) / (2 · k_B · T / e) ]
```

де `G_max = 1 / (2 · (R_s + R_d))` — максимальна амплітуда провідності в піку при `T → 0`, а `V_peak = (n + 0.5) · e / C_g` — положення центра `n`-го піка.

З цієї формули випливають два фундаментальні висновки щодо температурного розширення:

1. **Напівширина піка на піввисоті (FWHM):**
   ```
   ΔV_g,FWHM ≈ 3.52 · (k_B · T / e) · (C_Σ / C_g)
   ```
   Ширина осциляційного піка пропорційна абсолютній температурі `T`. Підвищення температури розмиває термодинамічний розподіл електронів на електродах, роблячи піки ширшими.

2. **Температурне згасання амплітуди:**
   При `k_B · T ≈ E_c` термодинамічне розширення носіїв перекриває кулонівську енергетичну щілину `E_c`, суміжні піки зливаються між собою, і кулонівські осциляції повністю зникають, відновлюючи постійну класичну провідність `G_0 = 1 / (R_s + R_d)`.

### 8. Кулонівська блокада в надпровідних островах (Cooper Pair Box)

Коли острівець та електроди переходять у надпровідний стан (наприклад, алюміній при `T < 1.2 K`), носіями заряду стають не поодинокі електрони, а куперівські пари із зарядом `2·e` та енергетичною щілиною надпровідника `Δ_super`.

Гамільтоніан комірки куперівських пар (Cooper Pair Box) описується гамільтоніаном Гамофа — Джозефсона:

```
H = 4 · E_c · (n - n_g)² - E_J · cos(ϕ)
```

де `n` — оператор числа тунельованих куперівських пар, `n_g = C_g · V_g / (2·e)` — індукований затворний заряд у одиницях пар, `ϕ` — різниця фаз надпровідного порядку, а `E_J` — енергія Джозефсона переходу:

```
E_J = (h · Δ_super) / (8 · e² · R_T)
```

Залежно від співвідношення між зарядною енергією `E_c` та енергією Джозефсона `E_J` виникають два фундаментальні квантові режими:

1. **Зарядовий режим (`E_c >> E_J`):**
   Енергетичні рівні острова строго залежать від заряду `n`. Системні стани являють собою суперпозицію зарядних станів `|n⟩` та `|n+1⟩`. Це режим роботи класичного зарядового кубіта (Charge Qubit).

2. **Трансмонний режим (`E_J >> E_c ≈ 20...50`):**
   Джозефсонівське тунелювання згладжує зарядові параболи, вироджуючи дисперсію зарядового шуму `dE / dn_g → exp(-√(8·E_J/E_c))`. Це повністю захищає кубіт від низькочастотного флікер-шуму затвора при збереженні незначної ангармонічності енергетичних рівнів, що застосовується у квантових процесорах Google Sycamore та IBM Eagle.

### 9. Квантово-розмірне квантування у квантовій точці

У напівпровідниковій квантовій точці геометричні розміри `L` є порівнянними з дебройлівською довжиною хвилі електрона (`L ≈ 10–50 нм`), що призводить до дискретизації одночастинкового спектра енергій з інтервалом квантування `Δε`:

```
Δε = (π² · ℏ²) / (2 · m* · L²)
```

де `m*` — ефективна маса електрона в провідності (наприклад, `m* ≈ 0.067 · m_e` для `GaAs`).

Повна енергія додавання другого електрона на один і той самий квантово-розмірний рівень вимагає поєднання електростатичної енергії заряджання `E_c` та відстані між квантованими станами `Δε`:

```
E_add(1 → 2) = E_c
E_add(2 → 3) = E_c + Δε
```

Це математично пояснює чергування високих та низьких ромбів стабільності на діаграмах напівпровідникових квантових точок у режимі електронного квантування.

### 10. Ефект Кондо в квантових точках при кулонівській блокаді

Якщо на острові перебуває непарна кількість електронів (`n = 2·m + 1`), останній електрон має неспарений спін `S = 1/2`. 

За низьких температур `T < T_K` (де `T_K` — температура Кондо), внаслідок квантово-механічної антиферомагнітної обмінної взаємодії між неспареним спіном острова та електронами провідності в електродах виникає екранування спіну острова (резонанс Кондо).

Температура Кондо `T_K` описується виразом:

```
T_K = ( √(Γ · E_c) / 2 ) · exp[ - (π · E_c) / (8 · Γ) ]
```

де `Γ = ℏ · (Γ_s + Γ_d)` — уширення енергетичного рівня острова через зв'язок із електродами.

У результаті формування багаточастинкового синглетного стану на рівні Фермі створюється гострий резонансний пік густини станів. Це знімає кулонівську блокаду всередині непарного ромба при `V_ds → 0`, підвищуючи провідність до теоретичного унітарного ліміту:

```
G_Kondo(T → 0) = 2 · e² / h ≈ 77.48 мкСім
```

### 11. Метрологічна чутливість та математика RF-SET

Одно-електронний транзистор слугує найчутливішим відомим електрометром для вимірювання затворного заряду. Затворна крутизна струму `g_m` поблизу піка осциляцій (`n_g = n + 0.25`) дорівнює:

```
g_m = dI / dV_g ≈ (e · C_g / C_Σ) · (1 / (4 · (R_s + R_d) · k_B · T / e))
```

Шотівський шум струму `S_I = 2 · e · I` визначає граничну спектральну густину еквівалентного зарядового шуму `S_q`:

```
S_q = S_I / (dI / dQ_g)² ≈ (2 · e · I) / (g_m / C_g)²
```

Мінімальний вимірюваний заряд за нульової температури у смузі `1 Гц` сягає граничного значення `δq_min ≈ 10⁻⁶ · e / √Гц`.

У радіочастотному одноелектронному транзисторі (RF-SET) пристрій інтегрується в резонансний LC-контур узгодження імпедансу (`L_match`, `C_match`) із резонансною частотою `f_0 = 1 / (2·π·√(L·C)) ≈ 1–3 ГГц`.

Коефіцієнт відбиття високочастотного сигналу `Γ_RF` визначається динамічним опором транзистора `R_SET(V_g) = 1 / G(V_g)`:

```
Γ_RF = ( Z_SET - Z_0 ) / ( Z_SET + Z_0 )
```

Зміна затворного заряду `dQ_g` модулює дифпровідність `G(V_g)`, що змінює коефіцієнт відбиття `Γ_RF`. Це розширює смугу пропускання електрометра від кріогенного ліміту паразитних ємностей дротів (близько 1 кГц) до гігагерцових частот (`> 100 МГц`), що дозволяє реєструвати тунелювання поодиноких електронів у реальному часі без втрати роздільної здатності.

Окрім вимірювання амплітуди відбитого сигналу, радіочастотна схема дозволяє реєструвати зміну фази високої частоти `Δϕ_RF = arctan(Im(Γ_RF) / Re(Γ_RF))`, що забезпечує дисперсійне бездисипативне зчитування зарядових станів квантових точок та надпровідних кубітів без розсіювання Джоулевого тепла на острові.

### 12. Квантове со-тунелювання другої теорії збурень (Co-tunneling)

У класичній ортодоксальній теорії всередині кулонівського ромба при `T → 0` струм строго дорівнює нулю. Проте вищі порядки квантово-механічної теорії збурень передбачають ефект **со-тунелювання** (co-tunneling) — одночасний когерентний процес тунелювання двох електронів через віртуальні проміжні стани острова.

Розрізняють два типи со-тунелювання:

1. **Непружне со-тунелювання (Inelastic Co-tunneling):**
   Електрон з витоку тунелює на острівець, а інший електрон з острова одночасно тунелює на сток, залишаючи на острові електрон-діркову збуджену пару. Швидкість непружного со-тунелювання масштабується як:
   ```
   Γ_inelastic ∝ (1 / (R_s · R_d)) · ( (e·V_ds)² + (2·π·k_B·T)² ) / E_c²
   ```
   Це створює параболічний фоновий виток струму всередині кулонівського ромба при `V_ds > 0`.

2. **Пружне со-тунелювання (Elastic Co-tunneling):**
   Один і той самий електрон тунелює крізь обидва бар'єри через віртуальний стан острова без залишення енергії збудження. Його швидкість є лінійною за напругою:
   ```
   Γ_elastic ∝ (1 / (R_s · R_d)) · ( e · V_ds / E_c² )
   ```

Со-тунелювання задає фундаментальну нижню межу для витоку струму у пристроях одноелектронної пам'яті та квантових реєстрах.
