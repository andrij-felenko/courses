# 🧮 Термодинаміка Онсагера та рівняння спінового і магнонного транспорту

Математичний апарат незворотної термодинаміки та феноменологічних рівнянь транспорту є фундаментальною основою спінової калоритроніка (від лат. *calor* — тепло та англ. *electronics* — електроніка). Ця вставка містить мікроскопічне та феноменологічне виведення термодинамічної матриці Онсагера для зв'язаних потоків заряду, спіну та тепла, математичне доведення теореми взаємності Кельвіна — Онсагера для спінового коефіцієнта Пельтьє, а також повну систему диференціальних рівнянь магнонно-флуїдної дифузії в неоднорідних температурних полях.

## Термодинамічні сили, ентропійні потоки та матрична форма Онсагера

У термодинамічно відкритому твердотільному середовищі з просторовими градієнтами електронного електрохімічного потенціалу, спінового накопичення та температури швидкість локального продукування ентропії в одиниці об'єму `σ_S` описується сумою добутків сопряжених термодинамічних потоків `J_k` на відповідні термодинамічні сили `X_k`:

```
σ_S = J_c · X_c + J_s · X_s + Q · X_q
```

де `J_c` — густина електричного зарядного струму (А/м²), `J_s` — густина спінового струму (Дж/м² або А/м²), а `Q` — густина теплового потоку (Вт/м²).

Термодинамічні сили `X_k` виражаються через просторові градієнти інтенсивних величин стану — електронного електрохімічного потенціалу `μ_c`, спінового електрохімічного потенціалу `μ_s = μ_↑ - μ_↓` та температури `T`:

```
X_c = - ∇(μ_c / e)                  [сила зарядного електрохімічного градієнта]
X_s = - ∇(μ_s / 2e)                 [сила спінового хімічного потенціалу]
X_q = ∇(1 / T) = - (1 / T^2) ∇T     [сила температурного градієнта]
```

У наближенні лінійної незворотної термодинаміки (при малих відхиленнях від локальної термодинамічної рівноваги) кожен термодинамічний потік `J_i` описується лінійною комбінацією всіх діючих сил `X_j`:

```
J_c = L_cc X_c + L_cs X_s + L_cq X_q   [рівняння для густини зарядного струму]
J_s = L_sc X_c + L_ss X_s + L_sq X_q   [рівняння для густини спінового струму]
Q   = L_qc X_c + L_qs X_s + L_qq X_q   [рівняння для густини теплового потоку]
```

де `L_ij` — феноменологічні кінетичні коефіцієнти Онсагера. Згідно з принципом мікроскопічної оборотності Ларса Онсагера, коефіцієнти симетричної матриці транспорту задовольняють співвідношення:

```
L_ij(M) = ε_i ε_j L_ji(-M)
```

де `M` — вектор макроскопічної намагніченості середовища, а `ε_i = ±1` — сигнатура парності відповідної змінної відносно інверсії часу (t → -t). Заряд та тепловий вміст є парними змінними (`ε = +1`), тоді як електронний спін та намагніченість є непарними (`ε = -1`). Внаслідок цього для крос-коефіцієнтів виконуються співвідношення взаємності:

```
L_cs(M) = - L_sc(-M)      [непарність спін-зарядного зв'язку відносно намагніченості]
L_cq(M) = L_qc(M)         [парність тепло-зарядного зв'язку за Кельвіном]
L_sq(M) = - L_qs(-M)      [непарність спін-теплового зв'язку Онсагера]
```

## Виведення спінового коефіцієнта Зеєбека з двофлуїдної моделі Мотта

Розглянемо провідний феромагнітний метал (наприклад, кобальт або нікель), у якому електронний транспорт описується двофлуїдною моделлю Невілла Мотта. Носії заряду розділяються на дві незалежні підгрупи: електрони зі спіном, орієнтованим паралельно намагніченості (`↑`), та електрони зі спіном проти намагніченості (`↓`).

Густина електричного струму `J_c` та густина спінового струму `J_s` виражаються через парціальні струми двох спінових каналів `J_↑` та `J_↓`:

```
J_c = J_↑ + J_↓                       [сумарний зарядний струм]
J_s = (ħ / 2e) (J_↑ - J_↓)            [чистий спіновий струм]
```

Записуємо феноменологічний закон Ома — Зеєбека для кожного спінового каналу окремо, враховуючи парціальні електропровідності `σ_↑`, `σ_↓` та парціальні коефіцієнти Зеєбека `S_↑`, `S_↓`:

```
J_↑ = - σ_↑ ∇(μ_↑ / e) - σ_↑ S_↑ ∇T   [струм електронів спінового каналу вгору]
J_↓ = - σ_↓ ∇(μ_↓ / e) - σ_↓ S_↓ ∇T   [струм електронів спінового каналу вниз]
```

Згідно з рівнянням Больцмана в наближенні часу релаксації `τ_σ(E)`, парціальні коефіцієнти `σ_σ` та `S_σ` (де `σ = ↑, ↓`) визначаються інтегралами по енергії біля рівня Фермі `E_F`:

```
σ_σ = e^2 ∫ D_σ(E) v_σ^2(E) τ_σ(E) (- d f_0 / dE) dE   [парціальна провідність]
S_σ = - (π^2 k_B^2 T / 3 e) [ d ln σ_σ(E) / dE ]|_{E_F}  [парціальний коефіцієнт Зеєбека]
```

де `D_σ(E)` — густина електронних станів, `v_σ(E)` — фермієвська швидкість, а `f_0(E)` — рівноважна функція розподілу Фермі — Дірака. Через обмінне розщеплення `d`-зони у феромагнетику `D_↑(E_F) ≠ D_↓(E_F)`, що робить парціальні коефіцієнти неоднаковими: `σ_↑ ≠ σ_↓` та `S_↑ ≠ S_↓`.

Підставляємо парціальні струми у вираз для сумарного зарядного струму `J_c`:

```
J_c = - σ_↑ ∇(μ_↑ / e) - σ_↓ ∇(μ_↓ / e) - (σ_↑ S_↑ + σ_↓ S_↓) ∇T
```

Виразимо парціальні хімічні потенціали через середній електрохімічний потенціал `μ_c = (μ_↑ + μ_↓)/2` та спінове накопичення `μ_s = μ_↑ - μ_↓`:

```
μ_↑ = μ_c + μ_s / 2                   [розклад потенціалу для спіну вгору]
μ_↓ = μ_c - μ_s / 2                   [розклад потенціалу для спіну вниз]
```

Підставляємо ці вирази у формулу зарядного струму `J_c`:

```
J_c = - (σ_↑ + σ_↓) ∇(μ_c / e) - (σ_↑ - σ_↓) ∇(μ_s / 2e) - (σ_↑ S_↑ + σ_↓ S_↓) ∇T
= - σ ∇V - P_σ σ ∇(μ_s / 2e) - σ S ∇T
```

де визначено макроскопічну електропровідність `σ`, поляризацію провідності `P_σ` та середній коефіцієнт Зеєбека `S`:

```
σ = σ_↑ + σ_↓                         [загальна електропровідність]
P_σ = (σ_↑ - σ_↓) / σ                 [ступінь спінової поляризації]
S = (σ_↑ S_↑ + σ_↓ S_↓) / σ           [макроскопічна термоЕРС]
```

Тепер виконаємо підставлення для густини спінового струму `J_s`:

```
J_s = (ħ / 2e) (J_↑ - J_↓)
= - (ħ / 2e) [ (σ_↑ - σ_↓) ∇(μ_c / e) + (σ_↑ + σ_↓) ∇(μ_s / 2e) + (σ_↑ S_↑ - σ_↓ S_↓) ∇T ]
= - (ħ / 2e) P_σ σ ∇V - (ħ / 2e) σ ∇(μ_s / 2e) - (ħ / 2e) σ S_S ∇T
```

де визначається дифференційний спіновий коефіцієнт Зеєбека `S_S`:

```
S_S = (σ_↑ S_↑ - σ_↓ S_↓) / σ
```

Виразимо `S_S` через ступінь поляризації провідності `P_σ` та різницю парціальних термоЕРС `ΔS = S_↑ - S_↓`:

```
S_S = P_σ S + (1 - P_σ^2) (S_↑ - S_↓) / 2
```

Це рівняння показує, що генерування чисто спінового струму під дією градієнта температури `∇T` виникає навіть у тому випадку, коли середній зарядний струм відсутній (`J_c = 0`).

## Доведення теореми Кельвіна — Онсагера для спінового ефекту Пельтьє

Спіновий ефект Пельтьє полягає у виникненні локального теплового потоку `Q_s`, який генерується при проходженні спінового струму `J_s` через межу матеріалів або неоднорідність. Виведемо математичне співвідношення між спіновим коефіцієнтом Пельтьє `Π_S` та спіновим коефіцієнтом Зеєбека `S_S`.

Повний тепловий потік `Q` у спіновому середовищі виражається через термодинамічні сили:

```
Q = Π J_c + Π_S (2e / ħ) J_s - κ_0 ∇T
```

де `Π` — класичний коефіцієнт Пельтьє, `Π_S` — спіновий коефіцієнт Пельтьє, а `κ_0` — решіткова теплопровідність за відсутності струмів.

Запишемо матрицю транспорту Онсагера у формі, що зв'язує сопряжені змінні. З фундаментального співвідношення взаємності Онсагера для термогенераційних крос-коефіцієнтів випливає:

```
L_qs = T L_sq                         [співвідношення Онсагера для спін-теплового зв'язку]
```

Здійснюємо тотожні перетворення, виражаючи коефіцієнти матриці через феноменологічні параметри `S_S` та `Π_S`:

```
L_sq = - (ħ / 2e) T σ S_S             [зв'язок спінового коефіцієнта з елементом Онсагера]
L_qs = - (ħ / 2e) σ Π_S               [зв'язок теплового коефіцієнта Пельтьє з елементом Онсагера]
```

Рівняємо праві частини виразів за теоремою Онсагера `L_qs = T L_sq`:

```
- (ħ / 2e) σ Π_S = - (ħ / 2e) T σ S_S
Π_S = T · S_S                          [теорема взаємності Кельвіна — Онсагера]
```

Отримане співвідношення `Π_S = T · S_S` є строго доведеним наслідком мікроскопічної оборотності часового ходу. Воно демонструє, що вимірювання прямого спінового ефекту Зеєбека повністю визначає термодинамічний коефіцієнт спінового нагрівання або охолодження Пельтьє без залучення додаткових підгонкових параметрів.

## Диференціальні рівняння магнонної дифузії у феромагнітних ізоляторах

У феромагнітних ізоляторах (наприклад, залізо-ітрієвому гранаті YIG, `Y_3 Fe_5 O_12`) електрична провідність носіїв заряду дорівнює нулю (`σ = 0`), тому транспорт кутового моменту здійснюється виключно колективними збудженнями спінової ґратки — магнонами.

Розглянемо неізотермічний магнонний газ з ефективою магнонною температурою `T_m(z)` та магнонним хімічним потенціалом `μ_m(z)`. Рівняння неперервності для густини магнонного струму `J_m` має вигляд:

```
∇ · J_m = - (n_m - n_0) / τ_mp
```

де `n_m` — нерівноважна густина магнонів, `n_0` — рівноважна густина магнонів за температури ґратки `T_p`, а `τ_mp` — характерний час магнон-фононної релаксації чисельності магнонів за рахунок тримагнонних та чотирьохмагнонних процесів розсіювання.

Густина магнонного струму `J_m` виражається через градієнти магнонного хімічного потенціалу `∇μ_m` та магнонної температури `∇T_m`:

```
J_m = - (σ_m / 2e) ∇μ_m - L_m ∇T_m
```

де `σ_m` — магнонна спінова провідність, а `L_m` — магнонний термоелектричний коефіцієнт.

Для малих відхилень від рівноваги зміна густини магнонів зв'язана з хімічним потенціалом через магнонну сприйнятливість `χ_m`:

```
n_m - n_0 = χ_m μ_m
```

Підставляємо феноменологічний вираз для `J_m` у рівняння неперервності:

```
∇ · [ - (σ_m / 2e) ∇μ_m - L_m ∇T_m ] = - χ_m μ_m / τ_mp
```

Розкриваємо дивергенцію для просторово однорідного магнонного середовища з постійними коефіцієнтами:

```
(σ_m / 2e) ∇^2 μ_m + L_m ∇^2 T_m = χ_m μ_m / τ_mp
∇^2 μ_m - (2e χ_m / σ_m τ_mp) μ_m = - (2e L_m / σ_m) ∇^2 T_m
```

Вводимо магнонну довжину дифузії `λ_m` та магнонний коефіцієнт Зеєбека `S_m`:

```
λ_m = sqrt( σ_m τ_mp / (2e χ_m) )     [характерна магнонна довжина релаксації]
S_m = 2e L_m / σ_m                    [магнонна термоЕРС]
```

Отримуємо підсумкове стаціонарне незведене диференціальне рівняння магнонної дифузії:

```
∇^2 μ_m - μ_m / λ_m^2 = - S_m ∇^2 T_m
```

Це диференціальне рівняння другого порядку показує, що просторове джерело магнонного хімічного потенціалу `μ_m` пропорційне нелінійності (другій похідній) температурного профілю `∇^2 T_m`. Якщо температурний профіль є строго лінійним усередині об'єму (`∇^2 T_m = 0`), генерація спінового накопичення відбувається виключно на межах розділу за рахунок стрибка теплового потоку та різниці магнон-фононних температур `T_m - T_p`.

## Граничні умови та термодинаміка гетеропереходу феромагнетик / важкий метал

На межі розділу між феромагнітним ізолятором та немагнітним важким металом з сильним спін-орбітальним зв'язком (`z = L`) проходження спінового струму задається ефективною спіновою провідністю змішування `g_↑↓`.

Спіновий струм інжекції `J_s^{interface}` на межі `z = L` виражається граничним співвідношенням:

```
J_s^{interface} = (g_↑↓ / 2π) [ μ_m(L) - μ_s^{NM}(L) ] + (g_↑↓ / 2π) S_m^{interface} (T_m - T_e)
```

де `μ_s^{NM}(L)` — спінове накопичення в металі безпосередньо біля контакту, `T_e` — температура електронів у металі, а `S_m^{interface}` — коефіцієнт поверхневого термоспінового перенесення.

У шарі важкого металу спіновий струм зазнає швидкого згасання через спін-орбітальне розсіювання з довжиною релаксації `λ_NM`. Профіль спінового накопичення у металі `μ_s^{NM}(z)` задовольняє дифузійне рівняння Валета — Ферта:

```
d^2 μ_s^{NM} / dz^2 = μ_s^{NM} / λ_NM^2
```

Інжектований спіновий струм `J_s^{interface}` перетворюється на поперечний зарядний струм `J_c^{ISHE}` за рахунок оберненого ефекту Холла (ISHE):

```
J_c^{ISHE} = θ_SH (2e / ħ) (J_s × σ_spin)
```

де `θ_SH` — спіновий кут Холла металу, а `σ_spin` — одиничний вектор орієнтації поляризації спінів. Інтегрування цього струму по товщині та довжині металевої смужки дає вимірювану макроскопічну напругу `V_ISHE`, що є прямим проявом термодинамічно інжектованого спінового струму.
