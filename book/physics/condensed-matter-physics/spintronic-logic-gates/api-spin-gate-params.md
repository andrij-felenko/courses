# 📋 Параметри та фізичний інтерфейс спінових логічних вентилів

Ця довідкова вставка містить розширений паспорт кількісних специфікацій, енергетичних та часових характеристик, а також фізичні інтерфейсні контракти узгодження спінтронних логічних вентилів (STT/SOT мажоритарних елементів, транзисторів Датта — Даса та магнонних інтерферометрів) із гібридними КМОН-схемами керування та зчитування.

### Детальний опис паспортних параметрів та фізичний аналіз

#### Енергія перемикання вентиля (E_sw)
Енергія перемикання визначає кількість теплоти та роботи, що розсіюється елементом під час виконання одиночної логічної операції переперемикання стану. Вона складається з двох основних компонентів: Джоулевого дисипативного нагрівання `E_Joule = I² · R · τ_sw` та ємнісного перезарядження `E_cap = C · V²`. 

У вентилях на основі перенесення спінового моменту (STT-MTJ) струм запису протікає безпосередньо через високий тунельний опір діелектрика MgO (`R_MTJ ≈ 1–10 кОм`), що обумовлює відносно високу дисипацію від 100 до 500 фДж. 

У елементах на основі спін-орбітального моменту (SOT-MTJ) струм запису протікає через високопровідну металеву смужку з важкого металу (`R_SOT ≈ 100–300 Ом`), розташовану під тунельним переходом. Це зменшує енергію перемикання до 5–25 фДж. 

У магнонних інтерферометрах перенесення електричного заряду у каналі обчислень повністю відсутнє, а фазова модуляція здійснюється накопиченням заряду на обкладках затвора VCMA, що знижує енергію перемикання до аттоджоулевого діапазону (`0.1–1.0` фДж).

#### Час затримки перемикання (τ_sw)
Час затримки визначає максимальну тактову частоту логічного елемента. У феромагнітних пристроях час перемикання намагніченості визначається тривалістю Ларморівської прецесії вектора `M` у ефективному полі та описується рівнянням Ландау — Ліфшиця — Гільберта. Для феромагнетиків на основі CoFeB цей час становить від 0.2 до 5 нс (частоти 0.2–5 ГГц). 

Використання антиферомагнітних матеріалів (наприклад, NiO, Mn₂Au) дозволяє підвищити прецесійну частоту до терагерцового діапазону (частоти 0.1–1 ТГц), зменшуючи затримку перемикання до пікосекундного рівня (`τ_sw < 10` пс).

#### Критична густина струму (J_c) та межа електроміграції
Критична густина струму `J_c` є ключовим параметром, який визначає порогове значення спіново-поляризованого струму, необхідного для перевертання магнітного моменту вільного шару проти сили магнітної анізотропії. 

Для STT-структур критична густина струму становить `J_c ≈ 10⁶ – 10⁷` А/см². Оскільки поріг електроміграції металевих провідників становить близько `10⁷` А/см², вентилі STT працюють поблизу фізичної межі деградації матеріалу. Перехід до SOT-структур знижує критичну густину струму в металевому треку до `10⁵ – 10⁶` А/см², усуваючи загрозу електроміграційного руйнування.

#### Довжина спінової релаксації (L_s)
Довжина спінової релаксації визначає максимальну відстань, на яку спіновий струм або спінова хвиля може поширюватися у каналі без втрати спінової поляризації. У немагнітних металах (мідь Cu, алюміній Al) при кімнатній температурі `L_s` становить від 300 до 500 нм. 

У напівпровідникових каналах InAs через сильну спін-орбітальну релаксацію Дьяконова — Переля довжина `L_s` не перевищує 200 нм. У той же час у плівках залізо-ітрієвого гранату (YIG) завдяки відсутності електронного розсіяння магнонні хвилі поширюються на відстані понад 10–50 мікрометрів, що робить YIG ідеальним середовищем для хвильових інтерферометрів.

## 2. Специфікація логічних станів та кодування сигналів

Для забезпечення сумісності з цифровою напівпровідниковою логікою спінові величини кодуються у фізичні стани провідності, магнітного моменту, напруги або фази хвиль.

| Фізична платформа | Логічний біт `0` | Логічний біт `1` | Стан високого імпедансу (High-Z) |
| :--- | :--- | :--- | :--- |
| **Спіновий вентиль / MTJ (STT/SOT)** | Антипаралельна намагніченість (M_S ↑↓ M_D), опір HRS | Паралельна намагніченість (M_S ↑↑ M_D), опір LRS | Розкрито транзистор вибірки (High-R) |
| **Магнонний інтерферометр (хвильовий)** | Фаза магнонної хвилі φ = π, амплітуда A → 0 | Фаза магнонної хвилі φ = 0 (або 2π), амплітуда A = A_max | Відсутність збудження магнонів (A = 0) |
| **Спіновий FET Датта — Даса** | Прецесія спіна Δθ = π, струм I ≈ I_min | Прецесія спіна Δθ = 2π, струм I = I_max | V_g < V_th (канал знеструмлений) |
| **Мажоритарна комірка (NML)** | Вектор намагніченості спрямовано ліворуч / вниз (← / ↓) | Вектор намагніченості спрямовано праворуч / вгору (→ / ↑) | Суперпарамагнітна фаза / відсутність орієнтації |

### Деталізація фізичних станів кодування

#### Тунельний магнітоопір (TMR) та інтервали станів
Параметри провідності тунельного магнітного переходу кодуються через ефект тунельного магнітоопору (TMR). Відносна зміна опору визначається співвідношенням:

```
TMR = (R_HRS - R_LRS) / R_LRS × 100%
```

Для монокристалічних тунельних бар'єрів Fe/MgO/Fe чи CoFeB/MgO/CoFeB значення TMR при кімнатній температурі становить від 150% до 250%. 

У логічних схемах опір `R_LRS` (паралельний стан намагніченостей) інтерпретується як логічна `1` (високий струм проходження), а опір `R_HRS` (антипаралельний стан) — як логічний `0` (низький струм). Стан високого імпедансу (High-Z) формується розмиканням КМОН-транзистора вибірки, підключеного послідовно з тунельним переходом.

#### Деградація TMR при зсуві напруги
При підвищенні напруги зчитування `V_read` понад 0.5 В значення TMR монотонно спадає через тунелювання електронів за участю магнонних збуджень та станів на межі розділу MgO. Тож робоча напруга зчитування спінових вентилів обмежується діапазоном `0.1–0.3` В для збереження контрастності логічних станів.

#### Фазове кодування хвиль у магноніці
У магнонних елементах логічний стан кодується не наявністю заряду, а фазою коливань спінових моментів у хвилеводі. Фаза `φ = 0` (збігається з початковою фазою генератора) приймається за логічну `1`, а протифаза `φ = π` — за логічний `0`. 

Оскільки хвильові фази додаються за законом суперпозиції, додавання хвиль зі станами `1` та `0` створює деструктивну інтерференцію та нульову результуючу амплітуду, що автоматично формує логічний результат `0` у магнонній логіці XOR.

## 3. Електричні та фізичні інтерфейси узгодження з КМОН-периферією

Оскільки спінові вентилі оперують мілівольтними напругами та мікроамперними струмами, їх інтеграція у кремнієві інтегральні схеми вимагає спеціалізованих блоків перетворення сигналів:

### 1. Вхідні інжекторні блоки (Charge-to-Spin Converters)

- **SOT Інжекторний контакт:** Шар важкого металу (Pt, Ta, W) товщиною `3–5 нм`, розташований під вільним шаром MTJ. Електричний струм заряду `I_charge`, що протікає в площині металу, генерує поперечний спіновий струм завдяки спіновому ефекту Холла:
  ```
  I_spin = θ_SH · (ℏ / (2 · e)) · I_charge
  ```
  де `θ_SH` — кут спіна Холла (для β-W `θ_SH ≈ 0.3–0.4`, для Ta `θ_SH ≈ -0.15`).
- **Мікросмужкова магнонна антена:** Золота або мідна смужка шириною `50–100 нм`, сформована над магнонним хвилеводом YIG. Високочастотний КМОН-імпульс струму частотою `f = 5–20 ГГц` створює змінне магнітне поле Ерстеда `H_Oersted`, яке порушує спини у плівці та генерує магнонний пакет.

### 2. Вихідні зчитувальні блоки (Spin-to-Charge Converters)

- **Диференційний підсилювач зчитування MTJ (Sense Amplifier):** Схема на основі чотирьох КМОН-транзисторів порівнює струм, що протікає крізь логічний MTJ, зі струмом опорної комірки `R_ref = (R_LRS + R_HRS) / 2`. Різниця струмів підсилюється до стандартних логічних рівнів КМОН (0 В та 1.2 В).
- **Обернений спіновий ефект Холла (ISHE):** Магнонна хвиля, що підходить до виходу хвилеводу, інжектує спіновий струм у контакт із важкого металу. Завдяки ефекту ISHE у металі виникає поперечна різниця потенціалів:
  ```
  E_ISHE ∝ θ_SH · (J_spin × σ_spin)
  ```
  отримана напруга `V_ISHE ≈ 0.1–1.0 мВ` підсилюється малошумним КМОН-компаратором.

## 4. Обмеження каскадування, Fan-Out та відновлення сигналу

Ключові інженерні параметри каскадування спінтронних вентилів подано у таблиці:

| Характеристика | Значення | Фізична причина та інженерне рішення |
| :--- | :--- | :--- |
| **Максимальний Fan-Out (N_fanout)** | 1 – 2 | Ослаблення спінової поляризації в металевих і напівпровідникових каналах; вимагає проміжних підсилювачів. |
| **Згасання магнонного сигналу** | 2 – 5 дБ/мкм | Магнітні втрати та параметр затухання Гільберта `α_YIG ≈ 10⁻⁴`; потребує SOT-підкачки. |
| **Тактова частота (f_clk)** | 1 – 10 ГГц | Визначається релаксаційною частотою феромагнітного резонансу (FMR). |
| **Щільність упакування** | > 10¹⁰ елементів/см² | Вентилі SOT-MTJ та NML мають площу комірки `≈ 4 F²`, де `F` — технологічний нормал. |
| **Термічна стабільність (K_u V / k_B T)**| > 60 | Вимога збереження магнітного стану протягом 10 років проти суперпарамагнітного перевороту. |

### Фізичний аналіз обмеження розгалуження (Fan-Out)

У класичній КМОН-логіці один вихідний транзистор може керувати входами 10–20 наступних вентилів (Fan-Out `N > 10`), оскільки затвор КМОН споживає лише незначний струм витоку у статичному режимі.

У спінтроніці спіновий струм або магнонна хвиля ділиться між вихідними гілками. При розгалуженні на `N` каналів амплітуда хвилі у кожному каналі зменшується у `√N` разів, а інтенсивність — у `N` разів. Крім того, спінова релаксація та затухання Гільберта додатково послаблюють сигнал.

Для забезпечення надійного каскадування багатокаскадних спінових процесорів використовуються наступні методи:

1. **SOT-підкачка магнонів (Spin-Orbit Torque Amplification):** Введення проміжних важких металів під магнонний хвилевід. Подача постійного струму через важкий метал створює спіновий момент, що компенсує природне затухання Гільберта у YIG і підтримує постійну амплітуду хвилі при розгалуженні.
2. **Гібридне КМОН-каскадування:** Кожна група з 3–5 спінових вентилів завершується КМОН-підсилювачем зчитування, який відновлює електричний сигнал до повної амплітуди напруги живильної мережі і подає його на наступний блок спінтронних вентилів.

### Критерій термічної стабільності наномагнітів
Зменшення фізичного об'єму наномагніта `V` загрожує втратою збереженої інформації через суперпарамагнітний переворот під дією флуктуацій кімнатної температури. Розрахунок часу збереження стану `τ_retention` здійснюється за формулою Неєля — Брауна:

```
τ_retention = τ₀ · exp( (K_u · V) / (k_B · T) )
```

де `τ₀ ≈ 10⁻⁹` с — спроба прецесійного перевороту, `K_u` — константа магнітної анізотропії. Для забезпечення 10-річного терміну зберігання даних у промислових спінтронних логічних вентилях вимагається виконання співвідношення `(K_u · V) / (k_B · T) ≥ 60`.
