# 🧮 Математичний апарат: розклад Зоммерфельда та температурний зсув хімічного потенціалу

Розрахунок макроскопічних термодинамічних, електричних та магнітних характеристик електронного газу в твердих тілах вимагає підсумовування або інтегрування відповідних квантовомеханічних величин по всій сукупності доступних квантових станів. Роль вагового коефіцієнта при цьому відіграє функція розподілу Фермі — Дірака. Через наявність експоненціального додатка у знаменнику функції розподілу такі інтеграли не виражаються в елементарних функціях і вимагають застосування спеціальних функцій — інтегралів Фермі — Дірака та асимптотичного розкладу Зоммерфельда.

Загальна концентрація електронів `n` у дозволеній енергетичній зоні з об'ємною густиною станів `g(E)` обчислюється за допомогою інтеграла:

```
n = ∫₀^∞ g(E) · f(E) dE
```

де `f(E) = 1 / (exp((E - μ) / (k_B · T)) + 1)` — функція розподілу Фермі — Дірака, а `μ` — хімічний потенціал носіїв.

---

## 1. Густина квантових станів у просторі квазіімпульсів

Щоб обчислити інтеграл концентрації, необхідно спочатку вивести математичний вираз для густини квантових станів `g(E)` залежно від розмірності системи.

У трьохвимірному кристаліці об'ємом `V = L_x · L_y · L_z` з періодичними граничними умовами Борна — фон Кармана дозволені значення волнового вектора `k` утворюють регулярну ґратку в `k`-просторі з об'ємом комірки `ΔV_k = (2π / L_x) · (2π / L_y) · (2π / L_z) = (2π)³ / V`.

Оскільки у кожному просторовому квантовому стані за принципом Паулі може перебувати два електрони з протилежними проекціями спіну (`s = 1/2`), кількість квантових станів у сферичному шарі радіуса `k` та товщини `dk` дорівнює:

```
dN_k = 2 · (4 · π · k² dk) / ((2 · π)³ / V) = (V / π²) · k² dk
```

Для параболічного закону дисперсії вільних електронів або квазічастинок з ефективною масою `m*` зв'язок між кінетичною енергією `E` та волновим вектором `k` має вигляд:

```
E = (ℏ² · k²) / (2 · m*)
```

Виражаючи `k` та `dk` через енергію `E`:

```
k = ((2 · m* · E) / ℏ²)¹ᐟ²
dk = (1 / 2) · ((2 · m*) / ℏ²)¹ᐟ² · E⁻¹ᐟ² dE
```

Підставляючи ці вирази у диференціал `dN_k` і ділячи на об'єм `V`, отримуємо тривимірну об'ємну густину станів `g(E) = (1/V) · (dN_k / dE)`:

```
g(E) = (1 / (2 · π²)) · ((2 · m*) / ℏ²)³ᐟ² · √E
```

Для порівняння, у двовимірному електронному газі (2DEG) густина станів не залежить від енергії і є константою `g_2D(E) = m* / (π · ℏ²)`, а у одновимірному провіднику (1D) спадає за законом `g_1D(E) ∝ 1 / √E`.

## 2. Енергія Фермі та термодинамічні характеристики при T = 0 K

При абсолютному нулю температур (`T = 0 K`) функція Фермі — Дірака перетворюється на ступеневу функцію Хевісайда: `f(E) = 1` при `E ≤ E_F0` та `f(E) = 0` при `E > E_F0`. Інтеграл концентрації електронів обрізається строго на граничній енергії Фермі `E_F0`:

```
n = ∫₀^{E_F0} g(E) dE
  = (1 / (2 · π²)) · ((2 · m*) / ℏ²)³ᐟ² · ∫₀^{E_F0} E¹ᐟ² dE          [підстановка g(E) для 3D зон]
  = (1 / (2 · π²)) · ((2 · m*) / ℏ²)³ᐟ² · (2 / 3) · E_F0³ᐟ²           [інтегрування степеня E¹ᐟ²]
  = (1 / (3 · π²)) · ((2 · m* · E_F0) / ℏ²)³ᐟ²                        [спрощення коефіцієнтів]
```

Виражаючи енергію Фермі `E_F0` через концентрацію електронів `n`, отримуємо фундаментальне співвідношення для виродженого електронного газу при `T = 0 K`:

```
E_F0 = (ℏ² / (2 · m*)) · (3 · π² · n)²ᐟ³
```

Аналогічно обчислюються модуль волнового вектора Фермі `k_F`, імпульс Фермі `p_F` та швидкість Фермі `v_F`:

```
k_F = (3 · π² · n)¹ᐟ³
p_F = ℏ · (3 · π² · n)¹ᐟ³
v_F = (ℏ / m*) · (3 · π² · n)¹ᐟ³
```

### Повна внутрішня енергія та тиск електронного газу при T = 0 K

Повна кінетична енергія `U_0` електронного газу в об'ємі `V` при `T = 0 K` дорівнює:

```
U_0 = V · ∫₀^{E_F0} E · g(E) dE
    = V · (1 / (2 · π²)) · ((2 · m*) / ℏ²)³ᐟ² · ∫₀^{E_F0} E³ᐟ² dE    [підстановка g(E) у вираз енергії]
    = V · (1 / (2 · π²)) · ((2 · m*) / ℏ²)³ᐟ² · (2 / 5) · E_F0⁵ᐟ²     [інтегрування степеня E³ᐟ²]
    = (3 / 5) · N · E_F0                                              [вираження через загальне число N = n·V]
```

Таким чином, середня енергія, яка припадає на один електрон у моралі Фермі при `T = 0 K`, становить три п'ятих від максимальної енергії Фермі:

```
⟨E⟩ = U_0 / N = (3 / 5) · E_F0
```

Цей нульовий рух створює квантовий **тиск виродження електронного газу `P_0`**, який запобігає гравітаційному колапсу білих карликів у астрофізиці:

```
P_0 = - (dU_0 / dV)_N = (2 / 3) · (U_0 / V) = (2 / 5) · n · E_F0
```

## 3. Спеціальні інтеграли Фермі — Дірака та больцманівська межа

Для скінченної температури `T > 0` зручно перейти до безрозмірних змінних: безрозмірної енергії `x = E / (k_B · T)` та безрозмірного хімічного потенціалу `η = μ / (k_B · T)`. 

Безрозмірний **інтеграл Фермі — Дірака порядку `j`** визначається як:

```
F_j(η) = (1 / Γ(j + 1)) · ∫₀^∞ (x^j / (exp(x - η) + 1)) dx
```

де `Γ(z)` — гамма-функція Ейлера, яка для напівцілих аргументів має значення `Γ(3/2) = √π / 2` та `Γ(5/2) = (3 · √π) / 4`.

За допомогою інтеграла `F₁ᐟ₂(η)` точний вираз для концентрації електронів у параболічній зоні провідності записується у вигляді:

```
n = N_c · F₁ᐟ₂((E_F - E_c) / (k_B · T))
```

де `N_c` — ефективна густина станів у зоні провідності:

```
N_c = 2 · ((2 · π · m_e* · k_B · T) / h²)³ᐟ²
```

### Невироджений граничний випадок (статистика Максвелла — Больцмана)

Якщо рівень Фермі розташований у забороненій зоні на відстані більше `2–3 · k_B · T` нижче від дна зони провідності (`E_c - E_F >> k_B · T`), безрозмірний параметр `η = (E_F - E_c)/(k_B · T) << -2`.

У цьому випадку для всіх позитивних енергій `x ≥ 0` виконується нерівність `exp(x - η) >> 1`, і додаванням одиниці в знаменнику можна знехтувати:

```
1 / (exp(x - η) + 1) ≈ exp(η - x) = exp(η) · exp(-x)
```

Підставляючи це апроксимацію в інтеграл `F_j(η)`:

```
F_j(η) ≈ exp(η) · (1 / Γ(j + 1)) · ∫₀^∞ x^j · exp(-x) dx = exp(η)
```

оскільки за визначенням гамма-функції `∫₀^∞ x^j · exp(-x) dx = Γ(j + 1)`.

Отже, для невиродженого напівпровідника концентрація вільних електронів `n` та вільних дірок `p` описується класичними експоненціальними законами Больцмана:

```
n = N_c · exp(-(E_c - E_F) / (k_B · T))
p = N_v · exp(-(E_F - E_v) / (k_B · T))
```

Перемножуючи ці два вирази, отримуємо **закон діючих мас** для напівпровідника у стані термодинамічної рівноваги, згідно з яким добуток концентрацій носіїв не залежить від положення рівня Фермі (і відповідно від допування):

```
n · p = N_c · N_v · exp(-(E_c - E_v) / (k_B · T)) = N_c · N_v · exp(-E_g / (k_B · T)) = n_i²
```

де `n_i` — власна концентрація носіїв заряду.

## 4. Сильновироджений ліміт: математична техніка розкладу Зоммерфельда

У металах та сильнолегованих напівпровідниках рівень Фермі перебуває глибоко всередині дозволеної зони (`μ >> k_B · T` або `η >> 1`). Для обчислення інтегралів вигляду:

```
I = ∫₀^∞ H(E) · f(E) dE
```

де `H(E)` — довільна гладка функція енергії (наприклад, `H(E) = g(E)` або `H(E) = E · g(E)`), застосовують асимптотичний розклад Зоммерфельда по малому параметру `(k_B · T / μ) << 1`.

### Математичний вивід розкладу Зоммерфельда

Введемо первообразну функцію `K(E) = ∫₀^E H(ε) dε`, для якої `K(0) = 0` та `dK/dE = H(E)`. Проінтегруємо початковий інтеграл `I` частинами:

```
I = ∫₀^∞ H(E) · f(E) dE
  = [K(E) · f(E)]₀^∞ - ∫₀^∞ K(E) · (df / dE) dE                      [інтегрування частинами: u=f, dv=H dE]
  = ∫₀^∞ K(E) · (-df / dE) dE                                        [позаінтегральний член дорівнює нулю]
```

Оскільки похідна `(-df/dE) = (1 / (k_B · T)) · exp((E - μ)/(k_B · T)) / (exp((E - μ)/(k_B · T)) + 1)²` є симетричною гострою функцією з максимумом у точці `E = μ` і товщиною `~ k_B · T`, розкладемо гладку функцію `K(E)` у ряд Тейлора поблизу точки `E = μ`:

```
K(E) = K(μ) + K'(μ) · (E - μ) + (1 / 2) · K''(μ) · (E - μ)² + (1 / 6) · K'''(μ) · (E - μ)³ + ...
```

Оскільки `K'(μ) = H(μ)`, `K''(μ) = H'(μ)` та `K'''(μ) = H''(μ)`, підставимо цей розклад в інтеграл:

```
I = K(μ) · ∫₀^∞ (-df/dE) dE + H(μ) · ∫₀^∞ (E - μ) · (-df/dE) dE + (1/2) · H'(μ) · ∫₀^∞ (E - μ)² · (-df/dE) dE + ...
```

Зробимо заміну змінної `z = (E - μ) / (k_B · T)`. Оскільки `μ >> k_B · T`, нижню межу інтегрування `z = -μ / (k_B · T)` можна без втрати точності замінити на `-∞`.

1. Перший інтеграл: `∫₋∞^∞ (-df/dz) dz = f(-∞) - f(+∞) = 1 - 0 = 1`.
2. Другий інтеграл: `∫₋∞^∞ z · (exp(z) / (exp(z) + 1)²) dz = 0` (через непарність підінтегральної функції).
3. Третій інтеграл: `∫₋∞^∞ z² · (exp(z) / (exp(z) + 1)²) dz = π² / 3`.

Підставляючи значення цих визначених інтегралів, отримуємо **класичну формулу розкладу Зоммерфельда**:

```
∫₀^∞ H(E) · f(E) dE = ∫₀^μ H(E) dE + (π² / 6) · (k_B · T)² · H'(μ) + (7 · π⁴ / 360) · (k_B · T)⁴ · H'''(μ) + O((k_B · T)⁶)
```

## 5. Застосування розкладу Зоммерфельда до фізичних величин

### 1. Температурний зсув хімічного потенціалу μ(T)

Застосуємо розклад Зоммерфельда до рівняння збереження кількості частинок `n = ∫₀^∞ g(E) · f(E) dE`, поклавши `H(E) = g(E)`:

```
n = ∫₀^μ g(E) dE + (π² / 6) · (k_B · T)² · g'(μ)
```

З іншого боку, за визначенням енергії Фермі при `T = 0 K`: `n = ∫₀^{E_F0} g(E) dE`. Прирівнюючи обидва вирази:

```
∫₀^{E_F0} g(E) dE = ∫₀^μ g(E) dE + (π² / 6) · (k_B · T)² · g'(μ)
```

Переносячи перший інтеграл у праву частину і враховуючи, що `μ` мало відрізняється від `E_F0`:

```
∫₀^μ g(E) dE - ∫₀^{E_F0} g(E) dE = ∫_{E_F0}^μ g(E) dE ≈ (μ - E_F0) · g(E_F0)
```

Звідси випливає фундаментальна формула для температурної залежності хімічного потенціалу:

```
μ(T) - E_F0 = - (π² / 6) · (k_B · T)² · (g'(E_F0) / g(E_F0))
```

Для параболічної 3D зони, де `g(E) = C · √E`, логарифмічна похідна дорівнює:

```
g'(E_F0) / g(E_F0) = (1 / 2) · (1 / E_F0)
```

Підставляючи це значення, отримуємо остаточну температурну залежність хімічного потенціалу для металу або виродженого напівпровідника:

```
μ(T) = E_F0 · [1 - (π² / 12) · (k_B · T / E_F0)²]
```

### 2. Електронна теплоємність виродженого електронного газу

Покладемо `H(E) = E · g(E)` для обчислення повної внутрішньої енергії електронного газу `U(T)`:

```
U(T) = ∫₀^∞ E · g(E) · f(E) dE
     = ∫₀^μ E · g(E) dE + (π² / 6) · (k_B · T)² · [d(E · g(E)) / dE]_{E=μ}
     = U_0 + (π² / 6) · (k_B · T)² · g(E_F0)
```

Диференціюючи внутрішню енергію `U(T)` по температурі `T`, отримуємо електронну теплоємність:

```
C_V,el = (dU / dT) = (π² / 3) · k_B² · T · g(E_F0)
```

Підставляючи вираз для густини станів `g(E_F0) = (3 / 2) · (N / E_F0)`, отримуємо знамениту формулу Зоммерфельда для електронної теплоємності:

```
C_V,el = (π² / 2) · N · k_B · (T / T_F)
```

де `T_F = E_F0 / k_B` — температура Фермі. Ця формула математично підтверджує строгу лінійну залежність електронної теплоємності від температури та пояснює її малість при звичайних температурах.
