# 🧮 Математичний апарат функції Фермі — Дірака та концентрації носіїв

Ця математична вставка містить фундаментальний і систематичний вивід аналітичних співвідношень для термодинамічного хімічного потенціалу `μ(T)`, тривимірної, двовимірної та одновимірної густини квантових станів `g(E)`, концентрацій носіїв заряду в напівпровідниках у невиродженому й виродженому лімітах, точних інтегралів Фермі — Дірака, кінетичного рівняння Болцмана, потенціалу інверсії в МОП-структурах та фізики пинування рівня Фермі.

## 1. Термодинамічний вивід розподілу Фермі — Дірака у великому канонічному ансамблі

Розглянемо квантовомеханічну систему однорідних частинок із напівцілим спіном (ферміонів), що перебувають у термодинамічній рівновазі з термостатом при температурі `T` та резервуаром частинок із хімічним потенціалом `μ`. 

Згідно з принципом заборони Паулі, кожен окремий квантовий стан `i` з енергією `E_i` може бути або повністю вільним (число заповнення `n_i = 0`), або зайнятим строго одним електроном (`n_i = 1`). Взаємодією між частинками у складі ідеального газу ферміонів нехтують.

У великому канонічному ансамблі Гіббса ймовірність того, що квантовий стан з енергією `E` містить `n` частинок, визначається мікроканонічним розподілом:

```
P(n) = (1 / Z_G) · exp(-n · (E - μ) / (k_B·T))
```

де `Z_G` — велика статистична сума для одного квантового стану, обчислена шляхом підсумовування за всіма дозволеними числами заповнення `n ∈ {0, 1}`:

```
Z_G = ∑_{n=0}^{1} exp(-n · (E - μ) / (k_B·T))
= exp(0) + exp(-(E - μ) / (k_B·T))
= 1 + exp(-(E - μ) / (k_B·T))     [підсумовування двох фізично можливих станів]
```

Середнє статистичне значення числа заповнення `f(E) = <n>` визначає ймовірність того, що стан з енергією `E` зайнятий електроном:

```
f(E) = ∑_{n=0}^{1} n · P(n)     [усереднення за двома можливими станами n = 0 та n = 1]
= (0 · 1 + 1 · exp(-(E - μ) / (k_B·T))) / (1 + exp(-(E - μ) / (k_B·T)))     [підстановка P(0) та P(1)]
= exp(-(E - μ) / (k_B·T)) / (1 + exp(-(E - μ) / (k_B·T)))     [спрощення чисельника]
```

Поділивши чисельник і знаменник отриманого дробу на експоненціальний фактор `exp(-(E - μ) / (k_B·T))`, отримуємо канонічну форму функції розподілу Фермі — Дірака:

```
f(E) = 1 / (exp((E - μ) / (k_B·T)) + 1)
```

Розглянемо граничні випадки цієї фундаментальної функції:

1. **Границя абсолютного нуля (`T → 0 K`)**:
   Позначивши `μ(0) = E_F` (енергія Фермі):
   - Якщо `E < E_F`, показник експоненти прямує до мінус нескінченності `(E - E_F) / (+0) = -∞`. Тоді `exp(-∞) = 0`, і `f(E) = 1 / (0 + 1) = 1`.
   - Якщо `E > E_F`, показник експоненти прямує до плюс нескінченності `(E - E_F) / (+0) = +∞`. Тоді `exp(+∞) = ∞`, і `f(E) = 1 / (∞ + 1) = 0`.
   Таким чином, при `T = 0 K` функція розподілу являє собою сувору прямокутну сходинку Хевісайда.

2. **Точка симетрії (`E = μ` при `T > 0 K`)**:
   Для будь-якої скінченної температури `T > 0 K`, коли енергія стану точно дорівнює хімічному потенціалу `E = μ`:
   ```
   f(μ) = 1 / (exp(0) + 1) = 1 / (1 + 1) = 1 / 2
   ```
   Це означає, що рівень Фермі `E_F` (хімічний потенціал `μ`) завжди є енергетичною точкою, де ймовірність заповнення квантового стану становить строго 50%.

3. **Імовірність незаповнення (розподіл дірок)**:
   Імовірність того, що квантовий стан із енергією `E` є вільним від електрона (тобто зайнятий діркою), дорівнює:
   ```
   f_h(E) = 1 - f(E)     [ймовірність протилежної події для дірок]
   = 1 - 1 / (exp((E - μ) / (k_B·T)) + 1)     [підстановка виразу для f(E)]
   = exp((E - μ) / (k_B·T)) / (exp((E - μ) / (k_B·T)) + 1)     [зведення до спільного знаменника]
   = 1 / (exp((μ - E) / (k_B·T)) + 1)     [ділення чисельника і знаменника на exp((E - μ) / (k_B·T))]
   ```
   Отримана формула показує повну дзеркальну симетрію розподілу дірок відносно рівня Фермі `μ`.

## 2. Вивід густини квантових станів g(E) у 3D та 2D системах

Для знаходження кількості електронів в енергетичному інтервалі `[E, E + dE]` необхідно знайти **густину квантових станів `g(E)`** — кількість доступних квантових станів на одиницю об'єму матеріалу в одиничному інтервалі енергій.

### Тривимірний об'ємний кристал (3D bulk)

Розглянемо тривимірну потенціальну яму з розмірами `L_x, L_y, L_z` та об'ємом `V = L_x · L_y · L_z`. Згідно з періодичними межовими умовами Борна — Кармана, дозволені значення волнового вектора `k` у `k`-просторі утворюють тривимірну ґратку з елементарною коміркою об'ємом `(2·π / L_x) · (2·π / L_y) · (2·π / L_z) = (2·π)³ / V`.

Кількість дозволених квантових станів всередині сфери радіуса `k` у квазіімпульсному просторі з урахуванням двох можливих орієнтацій спіну електрона (`g_s = 2`) дорівнює:

```
N(k) = 2 · ( (4/3) · π · k³ / ((2·π)³ / V) )
= (V / (3 · π²)) · k³
```

Поділивши на об'єм `V`, отримуємо концентрацію станів у `k`-просторі:

```
n_k(k) = N(k) / V = (1 / (3 · π²)) · k³
```

Для параболічної зони провідності з ізотропною ефективною масою `m_n^*` зв'язок між хвильовим вектором `k` та енергією електрона `E` має вигляд:

```
E - E_c = (ℏ² · k²) / (2 · m_n^*)
```

Виразивши модуль хвильового вектора `k` через енергію:

```
k = ( (2 · m_n^* · (E - E_c)) / ℏ² )^(1/2)
```

Підставляємо значення `k` у вираз для `n_k(E)`:

```
n_k(E) = (1 / (3 · π²)) · ( (2 · m_n^* · (E - E_c)) / ℏ² )^(3/2)
```

Диференціюючи `n_k(E)` по енергії `E`, отримуємо об'ємну густину станів `g_c(E) = dn_k / dE`:

```
g_c(E) = (d / dE) [ (1 / (3 · π²)) · ( (2 · m_n^*) / ℏ² )^(3/2) · (E - E_c)^(3/2) ]
= (1 / (2 · π²)) · ( (2 · m_n^*) / ℏ² )^(3/2) · (E - E_c)^(1/2)     (при E ≥ E_c)
```

Аналогічно для стелі валентної зони `E_v` з ефективною масою дірок `m_p^*`:

```
g_v(E) = (1 / (2 · π²)) · ( (2 · m_p*) / ℏ² )^(3/2) · (E_v - E)^(1/2)     (при E ≤ E_v)
```

Вивід демонструє, що в тривимірному кристалі густина станів зростає за параболічним законом як квадратний корінь від енергії `g(E) ∝ √(ΔE)`.

### Двовимірна квантова яма (2D system)

У двовимірних системах (наприклад, у квантових ямах чи 2D-матеріалах на кшталт графену або MoS₂), де рух електрона обмежений уздовж одного напрямку, площа елементарного стану у 2D `k`-просторі дорівнює `(2·π)² / A`, де `A` — площа системи.

Кількість станів всередині круга радіуса `k` становить:

```
N_2D(k) = 2 · ( (π · k²) / ((2·π)² / A) ) = (A / (2 · π)) · k²
```

Звідси двовимірна концентрація станів у `k`-просторі: `n_2D(k) = k² / (2·π)`.

Підставляючи квадратичний закон дисперсії `k² = (2 · m_n^* · (E - E_c)) / ℏ²` та диференціюючи по енергії, отримуємо двовимірну густину станів:

```
g_2D(E) = (d / dE) [ (m_n^* · (E - E_c)) / (π · ℏ²) ]
= (m_n^*) / (π · ℏ²) = const     (при E ≥ E_c)
```

Отриманий результат є фундаментальним: у двовимірному електронному газі густина станів є абсолютно сталою величиною, яка не залежить від енергії, утворюючи характерний ступенчастий спектр.

## 3. Точний вивід концентрацій носіїв у невиродженому напівпровіднику

Концентрація вільних електронів у зоні провідності `n` визначається об'ємним інтегралом:

```
n = ∫_{E_c}^{∞} g_c(E) · f(E) dE
```

Напівпровідник називається **невиродженим**, якщо рівень Фермі `μ` розташований глибоко всередині забороненої зони на відстані щонайменше `2·k_B·T` від дна зони провідності `E_c` (тобто `E_c - μ >> k_B·T`). 

При цій умові для всіх енергій `E ≥ E_c` виконується нерівність `(E - μ) / (k_B·T) >> 1`. Тоді одиницею у знаменнику функції Фермі — Дірака можна знехтувати, і квантовий розподіл переходить у класичне наближення Максвелла — Больцмана:

```
f(E) = 1 / (exp((E - μ)/(k_B·T)) + 1) ≈ exp(-(E - μ) / (k_B·T))
```

Підставивши вираз для `g_c(E)` та наближення Больцмана в інтеграл концентрації:

```
n = ∫_{E_c}^{∞} [ (1 / (2·π²)) · ((2·m_n^*)/ℏ²)^(3/2) · (E - E_c)^(1/2) ] · exp(-(E - μ)/(k_B·T)) dE
```

Винесемо множники, що не залежать від змінної інтегрування `E`:

```
n = (1 / (2·π²)) · ((2·m_n^*)/ℏ²)^(3/2) · exp((μ - E_c)/(k_B·T)) · ∫_{E_c}^{∞} (E - E_c)^(1/2) · exp(-(E - E_c)/(k_B·T)) dE
```

Здійснимо заміну змінної `x = (E - E_c) / (k_B·T)`, звідки `E - E_c = x · k_B·T` та `dE = k_B·T · dx`:

```
∫_{E_c}^{∞} (E - E_c)^(1/2) · exp(-(E - E_c)/(k_B·T)) dE
= (k_B·T)^(3/2) · ∫_0^∞ x^(1/2) · exp(-x) dx
```

Значення табличного Ейлерового інтеграла (Гамма-функція `Γ(3/2)`):

```
∫_0^∞ x^(1/2) · exp(-x) dx = Γ(3/2) = (√π) / 2
```

Підставляючи значення інтеграла назад у вираз для `n`:

```
n = (1 / (2·π²)) · ((2·m_n^*)/ℏ²)^(3/2) · (k_B·T)^(3/2) · ((√π) / 2) · exp(-(E_c - μ)/(k_B·T))
= 2 · ( (2·π·m_n^*·k_B·T) / h² )^(3/2) · exp(-(E_c - μ)/(k_B·T))
```

Остаточно записуємо:

```
n = N_c · exp(-(E_c - μ) / (k_B·T))
```

де `N_c` — **ефективна густина станів у зоні провідності**:

```
N_c = 2 · ( (2·π·m_n^*·k_B·T) / h² )^(3/2)
```

Проводячи аналогічне інтегрування для імовірності заповнення валентних станів дірками `1 - f(E)`:

```
p = ∫_{-∞}^{E_v} g_v(E) · (1 - f(E)) dE = N_v · exp(-(μ - E_v) / (k_B·T))
```

де `N_v` — **ефективна густина станів у валентній зоні**:

```
N_v = 2 · ( (2·π·m_p^*·k_B·T) / h² )^(3/2)
```

При кімнатній температурі `T = 300 K` для кремнію (`Si`): `N_c ≈ 2.86 × 10¹⁹ см⁻³`, `N_v ≈ 3.10 × 10¹⁹ см⁻³`.

## 4. Закон діючих мас та асиметрія власного рівня Фермі

Перемноживши вирази для концентрацій вільних електронів `n` та дірок `p`:

```
n · p = [ N_c · exp(-(E_c - μ)/(k_B·T)) ] · [ N_v · exp(-(μ - E_v)/(k_B·T)) ]
= N_c · N_v · exp(-(E_c - E_v)/(k_B·T))
= N_c · N_v · exp(-E_g / (k_B·T)) = n_i²
```

Отримане співвідношення називається **законом діючих мас**. Воно показує, що для термодинамічно рівноважного невиродженого напівпровідника добуток концентрацій вільних електронів та дірок за даної температури є абсолютно сталою величиною `n_i²`, яка не залежить від положення хімічного потенціалу `μ` та ступеня легування донорами чи акцепторами.

Власна концентрація носіїв `n_i` становить:

```
n_i = √(N_c · N_v) · exp(-E_g / (2·k_B·T))
```

У власному (ідеально чистому) напівпровіднику електронейтральність вимагає `n = p = n_i`. Прирівнявши вирази для `n` та `p`:

```
N_c · exp(-(E_c - E_i)/(k_B·T)) = N_v · exp(-(E_i - E_v)/(k_B·T))
```

Поділивши обидві частини на `N_c` та взявши натуральний логарифм:

```
-(E_c - E_i) / (k_B·T) = ln(N_v / N_c) - (E_i - E_v) / (k_B·T)
```

Перенесши терми з `E_i` в ліву частину:

```
(2 · E_i - E_c - E_v) / (k_B·T) = ln(N_v / N_c)
```

Виразивши власний рівень Фермі `E_i`:

```
E_i = (E_c + E_v) / 2 + (1/2)·k_B·T · ln(N_v / N_c)
```

Підставивши вирази для `N_v` та `N_c`:

```
ln(N_v / N_c) = ln[ (m_p^* / m_n^*)^(3/2) ] = (3/2) · ln(m_p^* / m_n^*)
```

Остаточно отримуємо співвідношення для температурного зсуву власного рівня Фермі:

```
E_i = (E_c + E_v) / 2 + (3/4)·k_B·T · ln(m_p^* / m_n^*)
```

Фізичний аналіз отриманої формули:
- При `T = 0 K` другий доданок обнуляється, і власний рівень Фермі `E_i` лежить строго посередині забороненої зони.
- Якщо ефективна маса дірок перевищує ефективну масу електронів `m_p^* > m_n^*` (що виконується для кремнію `Si`, де `m_p^* ≈ 0.59·m_0`, `m_n^* ≈ 0.32·m_0`), то `ln(m_p^* / m_n^*) > 0`. З підвищенням температури власний рівень Фермі `E_i` злегка піднімається вгору до зони провідності. Це пояснюється тим, що важчим діркам відповідає більша густина станів у валентній зоні `N_v > N_c`, тому для збереження рівності `n = p` рівень Фермі повинно зсунутися ближче до зони з меншою густиною станів.

## 5. Загальний випадок: Інтеграли Фермі — Дірака F_{1/2}(η) для вироджених систем

У сильно легованих напівпровідниках (коли концентрація домішок перевищує `10¹⁸ – 10¹⁹ см⁻³`) рівень хімічного потенціалу `μ` наближається до краю зони провідності `E_c` або входить усередину дозволеної зони. У цьому разі наближення Больцмана втрачає чинність, і розрахунок концентрації електронів має проводитися без спрощень за точною формулою:

```
n = N_c · F_{1/2}(η_c)
```

де `η_c = (μ - E_c) / (k_B·T)` — безрозмірний приведений хімічний потенціал, а `F_{1/2}(η)` — **знаменитий інтеграл Фермі — Дірака порядку 1/2**:

```
F_{1/2}(η) = (2 / √π) · ∫_0^∞ ( x^(1/2) / (exp(x - η) + 1) ) dx
```

Розглянемо дві граничні асимптотики інтеграла `F_{1/2}(η)`:

1. **Слабке невиродження (`η << -2`)**:
   Знаменник підінтегрального виразу `exp(x - η) + 1 ≈ exp(x - η)`. Тоді:
   ```
   F_{1/2}(η) ≈ (2 / √π) · exp(η) · ∫_0^∞ x^(1/2) · exp(-x) dx = exp(η)
   ```
   Формула точно збігається з класичним розрахунком Больцмана: `n = N_c · exp(η_c)`.

2. **Сильне квантове виродження (`η >> +4`)**:
   При великих додатних значеннях `η` функція Фермі — Дірака є близькою до сходинки. Аналітичне інтегрування дає Зоммерфельдівську асимптотику:
   ```
   F_{1/2}(η) ≈ (4 / (3·√π)) · η^(3/2) · [ 1 + (π² / (8·η²)) + ... ]
   ```
   Підставивши головний член асимптотики `(4 / (3·√π)) · η^(3/2)` у вираз для концентрації `n`:
   ```
   n = 2 · ( (2·π·m_n^*·k_B·T) / h² )^(3/2) · (4 / (3·√π)) · ( (μ - E_c) / (k_B·T) )^(3/2)
   = (1 / (3·π²)) · ( (2·m_n^*·(μ - E_c)) / ℏ² )^(3/2)
   ```
   Отриманий вираз повністю збігається з формулою квантового виродженого газу Зоммерфельда для металів при `T = 0 K`, де енергія Фермі відраховується від дна зони провідності `E_F = μ - E_c`.

Для точного зворотного розрахунку хімічного потенціалу `η_c` через відому концентрацію електронів `n` у проміжній області виродження використовується високоточна наближена формула Джойса — Діксона:

```
η_c = ln(r) + A_1 · r + A_2 · r² + A_3 · r³ + A_4 · r⁴
```

де `r = n / N_c`, а коефіцієнти становлять `A_1 = 1 / √8 ≈ 0.35355`, `A_2 = -4.95009 × 10⁻²`, `A_3 = 1.48385 × 10⁻³`, `A_4 = -4.42563 × 10⁻⁵`. Ця формула забезпечує похибку менше `0.1%` для всіх практичних розрахунків напівпровідникових пристроїв.

## 6. Квазірівні Фермі та узагальнене співвідношення Ейнштейна

При порушенні термодинамічної рівноваги (наприклад, під дією фотооптичної генерації або ін'єкції носіїв крізь p-n перехід) єдиний рівень Фермі `E_F` розщеплюється на два окремі **квазірівні Фермі**: `E_Fn` для електронів у зоні провідності та `E_Fp` для дірок у валентній зоні:

```
n = N_c · exp(-(E_c - E_Fn) / (k_B·T))
p = N_v · exp(-(E_Fp - E_v) / (k_B·T))
```

Різниця квазірівнів Фермі визначає відхилення системи від рівноваги: `n · p = n_i² · exp((E_Fn - E_Fp) / (k_B·T))`.

У нерівноважній системі повна густина електронного струму `J_n` складається з дрейфової та дифузійної складових:

```
J_n = n · e · μ_n · E + e · D_n · (dn / dx)
```

де `μ_n` — рухливість електронів, а `D_n` — коефіцієнт дифузії. 

У загальному випадку довільного виродження зв'язок між рухливістю та коефіцієнтом дифузії визначається **узагальненим співвідношенням Ейнштейна**:

```
D_n / μ_n = (k_B·T / e) · [ F_{1/2}(η_c) / F_{-1/2}(η_c) ]
```

У невиродженому ліміті `F_{1/2} / F_{-1/2} → 1`, що дає класичне співвідношення Ейнштейна `D_n = μ_n · (k_B·T / e) ≈ 0.0259 · μ_n` при 300 K. У сильно виродженому ліміті `D_n / μ_n → (2/3) · (E_F / e)`, що показує, що дифузія вироджених електронів визначається не тепловою енергією `k_B·T`, а високою кінетичною енергією Фермі `E_F`.

## 7. Одновимірна квантова нитка (1D) та особливості Ван Хова

У квантовій нитці (1D nanowire) рух електрона вільний лише вздовж однієї осі `x`, а вздовж `y` та `z` квантований потенціалом із розмірами `L_y, L_z`.

Дозволені значення волнового вектора `k_x` мають інтервал `2·π / L_x`. Кількість станів в інтервалі `k_x` становить `N_1D(k) = 2 · (2·k_x / (2·π / L_x)) = (2·L_x / π) · k_x`.

Діленням на довжину `L_x` знаходимо погонну концентрацію станів у `k`-просторі: `n_1D(k) = (2 / π) · k_x`.

Виразивши `k_x = √(2·m_n^*·(E - E_{c, n_y, n_z})) / ℏ` та продиференціювавши по енергії, отримуємо одновимірну густину станів для кожної підзони:

```
g_1D(E) = (1 / π) · ( (2 · m_n*) / ℏ² )^(1/2) · (E - E_{c, n_y, n_z})^(-1/2)
```

Отриманий розв'язок демонструє особливості Ван Хова: на відміну від 3D- та 2D-систем, в одновимірній квантовій нитці густина станів прямує до нескінченності `g_1D(E) ∝ 1 / √(ΔE)` безпосередньо біля дна кожної квантованої підзони `E_{c, n_y, n_z}`. Цей вибуховий ріст густини станів на межі підзони забезпечує високе підсилення в напівпровідникових квантових ниткових лазерах.

## 8. Поверхневий потенціал інверсії в МОП-структурах

У структурі Метал — Діелектрик — Напівпровідник (МОП / MIS) під дією зовнішньої напруги затвора `V_g` енергетичні зони на поверхні напівпровідника викривляються на величину електростатичного потенціалу `ψ(x)`.

Краї зон визначаються просторовим профілем:

```
E_c(x) = E_c0 - e · ψ(x)
E_v(x) = E_v0 - e · ψ(x)
```

де `E_c0, E_v0` — енергії зон у глибині об'єму напівпровідника.

Поверхнева концентрація вільних електронів `n_s` при поверхневому потенціалі `ψ_s = ψ(0)` становить:

```
n_s = n_0 · exp((e · ψ_s) / (k_B·T))
```

Область **сильної інверсії** (утворення n-каналу на поверхні p-напівпровідника з акцепторною концентрацією `N_a`) виникає тоді, коли поверхневий потенціал сягає критичного значення порогу інверсії:

```
ψ_s = 2 · ψ_B = 2 · (k_B·T / e) · ln(N_a / n_i)
```

При виконанні цієї умови поверхнева концентрація електронів `n_s` досягає об'ємної концентрації акцепторів `N_a`, а рівень Фермі на поверхні зміщується до зони провідності на таку ж відстань, на якій він знаходився біля валентної зони в глибині кристала. 

Максимальна ширина збідненої області `W_max` під інверсійним каналом визначається аналітичним співвідношенням Пуассона:

```
W_max = √( (4 · ε_s · k_B·T · ln(N_a / n_i)) / (e² · N_a) )
```

Ця формула використовується в інженерії транзисторів для обчислення порогової напруги `V_th` мікропроцесорних комірок.

## 9. Поверхневі стани та математичний аналіз пинування рівня Фермі (Fermi Level Pinning)

На реальній фізичній поверхні напівпровідника обрив періодичної кристалічної ґратки створює нескомпенсовані ковалентні зв'язки (dangling bonds), що викликають появу високої густини поверхневих квантових станів `D_ss` (вимірюється в `см⁻²·еВ⁻¹`), розподілених всередині забороненої зони.

Харчова заряджена модель Бардіна описує рівень нейтральності поверхні `E_CNL` (Charge Neutrality Level):
- Якщо рівень Фермі на поверхні `E_Fs` лежить нижче `E_CNL`, поверхневі стани віддають електрони й заряджаються позитивно.
- Якщо `E_Fs` лежить вище `E_CNL`, поверхня захоплює надлишкові електрони й заряджаються негативно.

Сумарний поверхневий заряд `Q_ss` визначається інтегралом:

```
Q_ss = -e · D_ss · (E_Fs - E_CNL)
```

При контакті металу з напівпровідником наявність проміжного діелектричного шару товщиною `δ` дає вираз для висоти потенціального бар'єра Шотткі `Φ_B`:

```
Φ_B = S · (Φ_m - χ) + (1 - S) · (E_c - E_CNL)
```

де `S` — безрозмірний фактор пинування рівня Фермі Бардіна:

```
S = (d Φ_B / d Φ_m) = 1 / [ 1 + (e² · D_ss · δ) / ε_i ]
```

Розглянемо два граничні фізичні випадки:
1. **Ідеальна межа без поверхневих станів (`D_ss → 0`)**: `S = 1`. Висота бар'єра суворо підпорядковується межі Шотткі — Мотта: `Φ_B = Φ_m - χ`.
2. **Висока густина поверхневих станів (`D_ss > 10¹³ см⁻²·еВ⁻¹`)**: `S → 0`. Висота бар'єра повністю фіксується (пинується) на рівні нейтральності поверхні: `Φ_B = E_c - E_CNL` незалежно від роботи виходу металу `Φ_m` (межа Бардіна). 

У режимі термопольової емісії (Thermionic-Field Emission, TFE), який реалізується при помірному легуванні `10¹⁷ < N_d < 10¹⁹ см⁻³`, струм протікає шляхом тунелювання теплово збуджених електронів крізь вершину звуженого бар'єра. Загальна густина струму описується узагальненою формулою Падованні — Страттона: `J_{TFE} = J_s · exp(V / E_0)`, де параметричний фактор `E_0 = E_00 · coth(E_00 / (k_B·T))` поєднує thermal emission та quantum tunneling regimes.

Саме феномен пинування рівня Фермі та перехід від чистої термоелектронної емісії до тунелювання визначає електричні властивості реальних контактів метал–кремній та метал–арсенід галію.
