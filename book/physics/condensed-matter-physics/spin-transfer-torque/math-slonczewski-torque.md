# 🧮 Вивід рівняння Ландау — Ліфшиця — Ґільберта з термомом Слончевського

Математична вставка містить строгий дедуктивний вивід рівняння Ландау — Ліфшиця — Ґільберта з додатковим термомом Слончевського (LLGS), розрахунок функціональної залежності ефективності передачі спінового моменту від кута між намагніченостями, сферичне представлення, аналіз розсіювання енергії, вивід квантової проводимості змішування спінів, теорію автоколивань, квантові граничні умови, аналіз теплових шумів, мікромагнітні розширення та чисельний алгоритм RK4.

---

### 1. Рівняння руху намагніченості у феноменології Ґільберта

Динаміка вектора намагніченості `M = M_s · m` (де `M_s` — намагніченість насичення, а `m` — безрозмірний одиничний вектор, `|m| = 1`) описується рівнянням Ландау — Ліфшиця з дисипативним членом Ґільберта. У відсутності електричного струму вектор `m` здійснює прецесію навколо напрямку ефективного магнітного поля `H_eff`:

```
dm/dt = -γ₀ · (m × H_eff) + α · (m × dm/dt)
```

де значення величин і параметрів зафіксовано так:
- `γ₀ = μ₀ · γ` — гіромагнітне відношення, помножене на магнітну сталу (`γ₀ ≈ 2.211 × 10⁵ м/(А·с)`);
- `H_eff = - (1 / (μ₀ M_s)) · ∇_m F` — ефективне поле, що включає зовнішнє поле, анізотропію, розмагнічування та обмін;
- `α` — безрозмірний коефіцієнт загасання Ґільберта (`α ≪ 1`, зазвичай `0.005 — 0.03`).

Ефективне поле визначається варіаційною похідною від вільної енергії системи `F`.

Для явного розв'язання відносно похідної за часом `dm/dt` виконаємо векторний множник рівняння на `m` зліва та застосуємо тотожність подвійного векторного добутку `m × (m × A) = (m · A) m - (m · m) A`.

Оскільки вектор намагніченості збереже довжину `|m| = 1`, виконується усім відома тотожність `m · m = 1`, звідки похідна за часом перпендикулярна до вектора `m · (dm/dt) = 0`.

Крок 1: Векторний добуток `m` на вихідне рівняння Ґільберта зліва:

```
m × (dm/dt) = - γ₀ · m × (m × H_eff) + α · m × (m × dm/dt)
```

Крок 2: Спрощення подвійного векторного добутку `m × (m × dm/dt)`:

```
m × (m × dm/dt) = (m · dm/dt) m - (m · m) (dm/dt) = 0 - 1 · (dm/dt) = - dm/dt
```

Крок 3: Підстановка виразу для `m × (dm/dt)` назад у початкове рівняння:

```
dm/dt = - γ₀ · (m × H_eff) + α · [ - γ₀ · m × (m × H_eff) - α · (dm/dt) ]
```

Крок 4: Групування доданків з `dm/dt` у лівій частині:

```
(1 + α²) · dm/dt = - γ₀ · (m × H_eff) - α γ₀ · [m × (m × H_eff)]
```

Крок 5: Остаточне ділення на `(1 + α²)` дає явну форму рівняння Ґільберта:

```
dm/dt = - (γ₀ / (1 + α²)) · (m × H_eff) - (α γ₀ / (1 + α²)) · [m × (m × H_eff)]    [явна форма Ґільберта]
```

Перший доданок описує консервативну ларморову прецесію, а другий — релаксацію намагніченості вздовж градієнта енергії до напрямку `H_eff`.

### 2. Квантово-механічний тензор спінового струму та дивергенція потоку

При проходженні електричного струму крізь феромагнітний шар електронам притаманний тензор спінового струму `J_s`. У напівкласичному наближенні густина спінового струму `J_s`, що рухається вздовж осі `z` (перпендикулярно до площини шарів), пов'язана з густиною електричного струму `J_e` та безрозмірним вектором спінової поляризації `p` (`|p| = 1` — напрямок намагніченості фіксованого шару):

```
J_s = (ħ / (2 e)) · P · J_e · p
```

де:
- `ħ` — зведена стала Планка (`1.05457 × 10⁻³⁴ Дж·с`);
- `e` — елементарний заряд (`1.60218 × 10⁻¹⁹ Кл`);
- `P` — коефіцієнт спінової поляризації струму (`0 < P ≤ 1`).

Коли спин-поляризований потік входить у тонкий вільний шар товщиною `d`, його поперечна компонента відносно локального вектора `m` поглинається на межі поділу завдяки s-d обмінній взаємодії на довжині спінової прецесії `λ_J = π / (k_F^↑ - k_F^↓) ≈ 1 нм`.

Об'ємна густина спинового обертального моменту `T_STT`, що діє на локалізований магнітний момент `M_s`, дорівнює мінус дивергенції спінового струму уздовж товщини `d`:

```
T_STT = - (1 / d) · (J_s^out - J_s^in)_perp
```

Підставляючи вираз для спінового струму та враховуючи, що поглинається лише поперечна компонента `p_perp = m × (p × m) = - m × (m × p)`, отримуємо об'ємний момент:

```
T_STT = (ħ P J_e / (2 e M_s d)) · g(θ) · [m × (m × p)]
```

де `g(θ)` — безрозмірна функція ефективності Слончевського, що залежить від кута `θ` між векторами `m` та `p`.

### 3. Повний вивід функції ефективності Слончевського g(θ) з матриці квантового тунелювання

Слончевський вивів функцію `g(θ, P)` з розв'язку стаціонарного рівняння Шредінгера для електронних хвиль на інтерфейсі феромагнетик/ізолятор/феромагнетик з урахуванням граничних умов для спінового накопичення та неперервності хвильових функцій електронів зі спіном «вгору» та «вниз».

Розглянемо квантово-механічну задачу проходження спінора з хвильовим вектором `k` крізь потенціальний бар'єр. Хвильова функція інжектованого електрона у фіксованому шарі записується як спінор:

```
Ψ_in(z) = A_↑ · exp(i k_↑ z) · |↑_p> + A_↓ · exp(i k_↓ z) · |↓_p>
```

У вільному шарі спінор розкладається за власними станами локальної намагніченості `m`, поверненої на кут `θ` у площині спинового простору:

```
|↑_p> = cos(θ/2) · |↑_m> + sin(θ/2) · |↓_m>
|↓_p> = - sin(θ/2) · |↑_m> + cos(θ/2) · |↓_m>
```

Обчислюючи матричні елементи тензора передачі кутового моменту на межі поділу `z = 0` через амплітуди відбиття `R_↑, R_↓` та проходження `T_↑, T_↓`, Слончевський отримав точний вираз для функції ефективності `g(θ, P)` у симетричному тунельному переході:

```
g(θ, P) = [ -4 + (1 + P)⁴ · (3 + cos θ) / (4 P^(3/2)) ]⁻¹
```

У наближенні малої різниці потенціалів та однакових феромагнітних обкладок формула спрощується до класичного компактного вигляду:

```
g(θ, P) = P / (1 + P² · cos θ)
```

Графічний аналіз функції `g(θ, P)` показує:
1. При паралельній орієнтації (`θ = 0`, `cos θ = 1`):

```
g(0) = P / (1 + P²)
```

2. При антипаралельній орієнтації (`θ = π`, `cos θ = -1`):

```
g(π) = P / (1 - P²)
```

Оскільки `1 - P² < 1 + P²`, завжди виконується нерівність:

```
g(π) > g(0)
```

Це пояснює фундаментальну асиметрію перемикання: струм, необхідний для перемикання зі стану AP у P, завжди менший за струм, необхідний для перемикання з P у AP.

### 4. Квантова проводимість змішування спінів (Spin Mixing Conductance)

Сучасне узагальнення теорії Слончевського у рамках формалізму балістичного транспорту Ландауера — Брюттікера виражає момент Слончевського через комплексну проводимість змішування спінів (Spin Mixing Conductance `G_↑↓`):

```
G_↑↓ = G_r + i G_i
```

де:
- `G_r = (e² / h) · ∑_mn [ δ_mn - R_mn^↑ (R_mn^↓)* ]` — дійсна частина спінової проводимості змішування;
- `G_i = (e² / h) · Im [ ∑_mn R_mn^↑ (R_mn^↓)* ]` — уявна частина спінової проводимості змішування.

через проводимість змішування адіабатичний момент Слончевського `a_J` та неадіабатичний польовий момент `b_J` виражаються фундаментальним чином:

```
a_J = (ħ / (2 e M_s d)) · (G_r / G_e) · J_e
b_J = (ħ / (2 e M_s d)) · (G_i / G_e) · J_e
```

де `G_e` — повна електрична проводимість тунельного переходу.

Для інтерфейсів `CoFeB / MgO` дійсна частина `G_r` суттєво перевищує уявну частину `G_i` (`G_r ≫ G_i`), що пояснює, чому поздовжній момент Слончевського `a_J` домінує над позаплощинним польовим моментом `b_J`.

### 5. Об'ємний момент Чжан — Лі (Zhang-Li Torque) у неоднорідних магнітних структурах

У неоднорідних магнітних структурах (наприклад, у доменних межах або спіральних спінових структурах) вектор намагніченості `m(r)` плавно змінюється в просторі. Чжан і Лі (Zhang and Li, 2004) вивели рівняння для об'ємного спінового моменту, що діє на доменну стінку:

```
T_ZL = - (u · ∇) m + β · m × [ (u · ∇) m ]
```

де:
- `u = (b_J J_e / M_s) e_j` — ефективна швидкість спін-поляризованих електронів;
- `β = ħ / (2 e M_s d · τ_sf)` — безрозмірний коефіцієнт неадіабатичності розсіювання спіна (`β ≈ 0.01 — 0.05`).

Перший доданок `-(u · ∇)m` описує адіабатичне захоплення спінів електронів локальною намагніченістю, а другий доданок `β m × [(u · ∇)m]` описує неадіабатичне розсіювання зі зміною спіна.

Об'ємний момент Чжан — Лі змушує доменну межу зсуватися вздовж провідника у напрямку руху електронів зі швидкістю `v_DW = (β / α) u`.

### 6. Рівняння ЛЛҐС у сферичній системі координат

Для аналітичного дослідження траєкторій перемикання вектор намагніченості `m` зручно представити у сферичних координатах через полярний кут `θ` (відхилення від осі Z) та азимутальний кут `φ` (прецесія у площині XY):

```
m = (sin θ cos φ, sin θ sin φ, cos θ)
```

Підставляючи параметризацію у явне рівняння ЛЛҐС з вектором поляризації `p = (0, 0, 1)`, отримуємо зв'язану систему двох скалярних диференціальних рівнянь:

```
dθ / dt = (γ₀' / sin θ) · ( ∂F / ∂φ ) - α γ₀' · ( ∂F / ∂θ ) + γ₀' a_J · sin θ
sin θ · (dφ / dt) = - γ₀' · ( ∂F / ∂θ ) - (α γ₀' / sin θ) · ( ∂F / ∂φ ) + γ₀' b_J · sin θ
```

де `F(θ, φ)` — безрозмірна вільна енергія осередка.

Фізична інтерпретація сферичних рівнянь:
1. Похідна полярного кута `dθ / dt` відповідає за зміну кута відхилення намагніченості від легкої осі. Доданок `γ₀' a_J sin θ` показує, що момент Слончевського прямо пропорційний `sin θ`. При `θ = 0` або `θ = π` момент Слончевського дорівнює нулю, що вимагає наявності початкових теплових відхилень для запуску прецесії.
2. Похідна азимутального кута `dφ / dt` визначає частоту прецесії. Польовий момент `b_J` безпосередньо зміщує частоту прецесії, діючи аналогічно до додаткового поздовжнього магнітного поля.

### 7. Баланс енергії та швидкість дисипації dE/dt

Повна магнітна енергія одиниці об'єму шару дорівнює `E(m) = - μ₀ M_s (m · H_eff)`. Знайдемо швидкість зміни енергії з часом `dE / dt`:

```
dE / dt = ∇_m E · (dm / dt) = - μ₀ M_s H_eff · (dm / dt)
```

Підставляючи явну форму рівняння ЛЛҐС та враховуючи перпендикулярність вектору прецесії `(m × H_eff) · H_eff = 0`, отримуємо загальне рівняння балансу енергії:

```
dE / dt = - (α μ₀ M_s γ₀' ) · |m × H_eff|² + (μ₀ M_s γ₀' a_J) · H_eff · [m × (m × p)]
```

Аналіз доданків рівняння енергетичного балансу:
1. **Перший член `- α μ₀ M_s γ₀' |m × H_eff|² ≤ 0`** завжди від'ємний і описує неперервне розсіювання енергії у кристалічну ґратку за рахунок дисипації Ґільберта.
2. **Другий член `+ μ₀ M_s γ₀' a_J H_eff · [m × (m × p)]`** відповідає за зовнішню роботу, що виконується спин-поляризованим струмом.

Умова стаціонарної незагасаючої прецесії (режим СВЧ-генератора STNO) вимагає строгої рівності нулю середньої швидкості зміни енергії за період прецесії:

```
< dE / dt >_T = 0
```

Коли потужність накачування від моменту Слончевського перевищує потужність дисипації Ґільберта (`dE/dt > 0`), енергія системи зростає, траєкторія розгортається, і намагніченість долає потенціальний бар'єр `E_b`, здійснюючи повний переворот.

### 8. Повний вивід критичної густини струму J_c0 та аналіз біфуркації Гопфа

Розглянемо детальний математичний вивід критичного струму через аналіз стійкості матриці Якобі для гетероструктури з перпендикулярною анізотропією (pMTJ).

#### Аналіз матриці Якобі (Jacobian Stability Analysis)
У pMTJ легка вісь анізотропії та вектор поляризації `p` спрямовані вздовж осі `z` (`p = (0, 0, 1)`). Ефективне поле дорівнює:

```
H_eff = H_k^eff · m_z · z_hat
```

Для малих відхилень від верхнього полюса `m_z ≈ 1 - (1/2)(m_x² + m_y²)`, вектор відхилень у площині дорівнює `u = (m_x, m_y)^T`. Лінеаризована система диференціальних рівнянь `du/dt = A · u` має матрицю Якобі `A`:

```
A = |  - (α γ₀ H_k^eff - γ₀ a_J)      - γ₀ H_k^eff            |
    |  + γ₀ H_k^eff                   - (α γ₀ H_k^eff - γ₀ a_J) |
```

Власні значення `λ` матриці `A` знаходяться з характеристичного рівняння `det(A - λ I) = 0`:

```
λ₁‚₂ = - (α γ₀ H_k^eff - γ₀ a_J) ± i γ₀ H_k^eff
```

Дійсна частина власних значень визначає стійкість рівноважного стану:
- При `a_J < α H_k^eff`: `Re(λ) < 0` — стійкий фокус (намагніченість повертається до полюса).
- При `a_J = α H_k^eff`: `Re(λ) = 0` — **біфуркація Гопфа** (виникнення незагасаючих автоколивань на граничному циклі, режим STNO).
- При `a_J > α H_k^eff`: `Re(λ) > 0` — нестійкий фокус (амплітуда відхилення зростає експоненційно, викликаючи перемикання).

#### Формула критичного струму для pMTJ
З умови біфуркації `a_J = α H_k^eff` підстановкою виразу для `a_J = (ħ P J_e / (2 e μ₀ M_s d)) · g(0)`, виводиться критична густина струму при `T = 0 K`:

```
J_c0^pMTJ = (2 e μ₀ M_s d / (ħ P g(0))) · α · H_k^eff       [критичний струм pMTJ]
```

Виражаючи ефективне поле через енергетичний бар'єр термічної стабільності `E_b = K_u^eff · V = (1/2) μ₀ M_s H_k^eff · (A · d)` (де `A` — площа комірки, `V = A · d` — об'єм):

```
J_c0^pMTJ = (4 e α E_b) / (ħ P g(0) A)
```

Цей вираз показує, що для перпендикулярних комірок `J_c0` прямо пропорційний коефіцієнту загасання `α` та висоті енергетичного бар'єра `E_b`.

#### Випадок 2: Комірка з плоскою анізотропією (In-Plane)
Для шарів з плоскою анізотропією (легка вісь вздовж `x`, форма у вигляді еліпса) лінеаризація дає додатковий член розмагнічування площини `4π M_s` (або `M_s` у СІ):

```
J_c0^In-Plane = (2 e μ₀ M_s d / (ħ P g(0))) · α · (H_k + M_s / 2)    [критичний струм In-Plane]
```

Оскільки `M_s / 2 ≫ H_k`, критичний струм для плоских комірок істотно більший, ніж для перпендикулярних:

```
J_c0^In-Plane ≫ J_c0^pMTJ
```

Саме тому сучасна промисловість STT-MRAM повністю перейшла на структури з перпендикулярною анізотропією (pMTJ).

### 9. Рівняння Фоккера — Планка та термічна активація

При скінченній температурі `T > 0 K` теплові коливання описуються стохастичним рівнянням Ландау — Ліфшиця — Ланжевена:

```
dm/dt = f(m, J_e) - γ₀ (m × H_th)
```

де `H_th` — білий гауссів шум з нулевим середнім та кореляційною функцією:

```
< H_th_i(t) H_th_j(t') > = (2 α k_B T / (γ₀ M_s V)) · δ_ij · δ(t - t')
```

Густина ймовірності розподілу орієнтації намагніченості `W(m, t)` описується рівнянням Фоккера — Планка на сфері:

```
dW/dt = - ∇ · (J_W)
```

де `J_W` — потік ймовірності, що враховує як адвективне знесення під дією Слончевського, так і теплову дифузію Ейнштейна з коефіцієнтом `D_th = α k_B T / (μ₀ M_s V (1 + α²))`.

Аналітичний розв'язок рівняння Фоккера — Планка для середнього часу першого виходу (Mean First Passage Time, MFPT) дає закон Суна для залежності критичного струму від тривалості імпульсу `t_p` у теплово-активованому режимі (`t_p > 10 нс`):

```
J_c(t_p) = J_c0 · [ 1 - (k_B T / E_b) · ln(t_p / τ_0) ]
```

де `τ_0 ≈ 1 нс` — час прецесійної спроби виходу з потенціальної ями.

---

### 10. Фізичні межі та розширені режими автоколивань (STNO)

При струмах, що перевищують порог біфуркації Гопфа (`J_e > J_c0`), але недостатніх для перемикання у стаціонарний стан (наприклад, у наноконтактних геометріях з неоднорідним протіканням струму), вектор намагніченості виходить на стійкий граничний цикл. У цьому режимі пристрій генерує високочастотні електричні коливання на частотах від 1 до 40 ГГц за рахунок тунельного магнітоопору.

Частота автоколивань спін-торк наноосцилятора (Spin-Torque Nano-Oscillator, STNO) визначається рівнянням:

```
f(J_e) = f_FMR · sqrt( 1 - (J_e / J_c0)² ) + N_p · I_e
```

де `N_p` — коефіцієнт нелінійного зсуву частоти, зумовлений залежністю розмагнічувального поля від амплітуди відхилення кута `θ`.

### 11. Стохастичне інтегрування за Стратоновичим та Іто

У стохастичному численні при наявності мультиплікативного шуму (коли шум залежить від вектора `m`) виникає розбіжність між інтегралами Іто та Стратоновича. Для збереження умови `|m| = 1` при чисельному моделюванні рівняння ЛЛҐС необхідно застосовувати саме формулювання Стратоновича.

Аналітичний вигляд випадкового поля Ланжевена у чисельній схемі Рунге — Кутти з кроком `Δt`:

```
H_th = sqrt( (2 α k_B T) / (γ₀ M_s V Δt) ) · N(0, 1)
```

де `N(0, 1)` — тривимірний вектор незалежних стандартних нормальних випадкових величин із нульовим математичним сподіванням та одиничною дисперсією.

---

### 12. Математичний базис чисельного інтегрування RK4

Оскільки явне рівняння ЛЛҐС є жорсткою системною диференціальних рівнянь (Stiff Differential Equations) через наявність двох сильно рознесених часових масштабів (прецесія `~ 0.1 нс` та дисипація `~ 10 нс`), використання простих схем Ейлера вимагає нереально малих кроків інтегрування (`Δt < 10⁻¹⁶ с`).

Для забезпечення чисельної стійкості застосовують алгоритм Рунге — Кутти 4-го порядку (RK4) з нормуванням вектора на кожному кроці:

```
k_1 = f( m_n, t_n )
k_2 = f( m_n + 0.5 Δt k_1, t_n + 0.5 Δt )
k_3 = f( m_n + 0.5 Δt k_2, t_n + 0.5 Δt )
k_4 = f( m_n + Δt k_3, t_n + Δt )

m_{n+1}^unnorm = m_n + (Δt / 6) · (k_1 + 2 k_2 + 2 k_3 + k_4)
m_{n+1} = m_{n+1}^unnorm / |m_{n+1}^unnorm|
```

Операція повторного нормування `m_{n+1} = m / |m|` гарантує збереження закону збереження модуля намагніченості `|m| = 1` з машиною точністю `10⁻¹⁶`, запобігаючи нефізичному накопиченню чисельної похибки амплітуди вектора.

### 13. Мікромагнітне розширення та чисельні пакети (MuMax3 / OOMMF)

У разі, коли діаметр магнітного тунельного переходу перевищує 30–40 нанометрів, припущення макроспіна (одноелементного вектора намагніченості `m`) перестає виконуватися через виникнення неколінеарних спінових текстур, таких як вихрові стани (vortex) або крайові доменні зародки. 

Для моделювання таких багаточастинкових систем простір розділяють на сітку мікромагнітних осередків (типовий розмір `2 × 2 × 1 нм`), у кожному з яких розв'язується локальне рівняння ЛЛҐС з урахуванням обмінної взаємодії між сусідніми осередками через дискретний лапласіан `∇² m`. Стандартним промисловим та науковим інструментом для таких розрахунків є пакети графічного прискорення **MuMax3** та **OOMMF**.

---

### 14. Фізичні обмеження напівкласичного наближення

Класичне рівняння ЛЛҐС спирається на припущення про постійність модуля вектора намагніченості `|m| = 1` та нехтування термічним випромінюванням магнонів високих енергій. Це наближення порушується при температурах, близьких до температури Кюрі `T_C` сплаву `CoFeB` (близько 800 K), або при проходженні суперкоротких фемтосекундних лазерних чи електричних імпульсів.

Для опису ультрашвидкої спінової динаміки використовують поздовжньо-поперечне рівняння Ландау — Ліфшиця — Блоха (LLB), де модуль намагніченості `|m|` перестає бути константою і змінюється під дією термодинамічних сил.

### 15. Порівняльний підсумок математичних формул STT

| Фізична величина | Символ | Математичний вираз | Одиниці |
| :--- | :--- | :--- | :--- |
| Інпланарний момент | `T_STT` | `- γ₀ a_J [m × (m × p)]` | 1/с |
| Польовий момент | `T_FL` | `- γ₀ b_J (m × p)` | 1/с |
| Критичний струм (pMTJ) | `J_c0^pMTJ` | `(2 e μ₀ M_s d / (ħ P g(0))) · α · H_k^eff` | А/м² |
| Критичний струм (In-Plane) | `J_c0^In-Plane` | `(2 e μ₀ M_s d / (ħ P g(0))) · α · (H_k + M_s / 2)` | А/м² |
| Закон Суна | `J_c(t_p)` | `J_c0 · [1 - (k_B T / E_b) ln(t_p / τ_0)]` | А/м² |

Математична форма рівняння ЛЛҐС забезпечує повний аналітичний та чисельний базис для проектування спінтронних обчислювальних пристроїв.
