# 🧮 Виведення коефіцієнта екранування магнітного поля

Коефіцієнт екранування `S` є квантифікативним показником, який визначає здатність пасивної або надпровідної оболонки послаблювати зовнішнє магнітне поле у своєму внутрішньому захищеному об'ємі. У строгому математичному формулюванні задача магнітостатичного екранування зводиться до розв'язання рівняння Лапласа для скалярного магнітного потенціалу із відповідними граничними умовами неперервності векторних полів на поверхнях розділу середовищ.

```
Визначення коефіцієнта екранування S:
S = B_ext / B_int
S_dB = 20 · log₁₀(S)
```

---

### 1. Математичні рівняння магнітостатики та граничні умови

Розглянемо простір, у якому відсутні вільні електричні струми плинності (`j = 0`). За цих умов стаціонарні рівняння Максвелла для напруженості магнітного поля `H` та індукції `B` виглядають так:

```
∇ × H = 0
∇ · B = 0
```

Перше рівняння `∇ × H = 0` є необхідною і достатньою умовою існування однозначного скалярного магнітного потенціалу `V_m`, зв'язаного з вектором напруженості співвідношенням:

```
H = -∇ V_m
```

Фізичний зміст скалярного потенціалу полягає у тому, що робота переміщення одиничного магнітного заряду вздовж будь-якого замкненого контуру за відсутності макроскопічних струмів дорівнює нулю `∮ H · dl = 0`. Якщо у досліджуваному просторі є струми плинності (`j ≠ 0`), скалярний потенціал стає багатозначним, і замість нього використовують векторний магнітний потенціал `A`, визначений як `B = ∇ × A`. Проте у задачах пасивного екранування у захищуваній порожнині струми відсутні, що робить використання скалярного потенціалу `V_m` математично виправданим і зручним.

Друге рівняння `∇ · B = 0` виражає фундаментальний закон електродинаміки про відсутність у природі магнітних зарядів (монополів). Оскільки для лінійного ізотропного середовища зв'язок між індукцією та напруженістю визначається відносною магнітною проникністю `B = μ₀ · μ_r · H`, підстановка скалярного потенціалу у закон неперервності магнітного потоку дає:

```
∇ · (μ₀ · μ_r · (-∇ V_m)) = 0
```

Для однорідної області, де відносна проникність `μ_r` є константою, цей вираз перетворюється на фундаментальне **рівняння Лапласа** для скалярного магнітного потенціалу:

```
∇² V_m = 0
```

На межі розподілу двох середовищ 1 та 2 (наприклад, внутрішнього повітря з `μ₁ = 1` та матеріалу оболонки екрана з `μ₂ = μ_r ≫ 1`) повинні виконуватися дві граничні умови електродинаміки, які випливають з інтегральних форм рівнянь Максвелла:

1. **Неперервність тангенціальної компоненти напруженості поля `H_t`:**
   Інтегрування рівняння `∇ × H = 0` вздовж вузького прямокутного контуру, що перетинає межу середовищ, вимагає відсутності стрибка тангенціальної компоненти. Тангенціальна компонента градієнта потенціалу не повинна мати стрибків, що гарантує відсутність поверхневих магнітних струмів:
   ```
   H_t1 = H_t2  ⇒  ∂V_m1 / ∂t = ∂V_m2 / ∂t
   ```

2. **Неперервність нормальної компоненти магнітної індукції `B_n`:**
   Інтегрування рівняння `∇ · B = 0` по об'єму нескінченно малого циліндра (гауссової таблетки), розташованого на межі середовищ, показує, що магнітний потік крізь межу є неперервним. Це вимагає компенсації стрибка напруженості відносною проникністю:
   ```
   B_n1 = B_n2  ⇒  μ₁ · (∂V_m1 / ∂n) = μ₂ · (∂V_m2 / ∂n)
   ```

### 2. Строге виведення для сферичної оболонки

Розглянемо замкнену порожнисту сферичну оболонку з внутрішнім радіусом `R_in` та зовнішнім радіусом `R_out`, виготовлену з матеріалу з відносною проникністю `μ_r`. Оболонка поміщена в однорідне зовнішнє магнітне поле `B₀ = μ₀ · H₀`, спрямоване уздовж осі `z`.

Запровадимо сферичну систему координат `(r, θ, φ)` із початком у центрі сфери. З огляду на осьову симетрію задачі відносно напрямку зовнішнього поля, скалярний потенціал `V_m` не залежить від азимутального кута `φ`.

Загальний розв'язок рівняння Лапласа `∇² V_m = 0` у сферичних координатах шукається у вигляді розкладу за ортогональною системою поліномів Лежандра `P_n(cos θ)`:

```
V_m(r, θ) = ∑ [ A_n · rⁿ + B_n · r⁻⁽ⁿ⁺¹⁾ ] · P_n(cos θ)
```

Поліноми Лежандра є розв'язками диференціального рівняння `(1 - x²) P_n''(x) - 2x P_n'(x) + n(n+1) P_n(x) = 0` для `x = cos θ`. Перші три поліноми мають вигляд `P₀(x) = 1`, `P₁(x) = x = cos θ`, `P₂(x) = (1/2)(3x² - 1)`.

Оскільки зовнішнє однорідне поле визначається виразом `V_m_ext = -H₀ · z = -H₀ · r · cos θ = -H₀ · r · P₁(cos θ)`, у граничних умовах на нескінченності виступає лише перша гармоніка `n = 1` (дипольний режим). Ортогональність поліномів Лежандра `∫ P_n(x) P_m(x) dx = 0` при `n ≠ m` гарантує, що вищі гармоніки `n > 1` (квадрупольні, октупольні) дорівнюють нулю у всіх трьох областях.

Тому розв'язок у кожній із трьох областей спрощується до вигляду `V_m(r, θ) = R(r) · cos θ`.

Розділимо простір на три характерні області:
- **Область 1 (`r < R_in`):** Внутрішня екранована порожнина (повітря, `μ_r = 1`). Потенціал мусить бути скінченним у центрі сфери `r = 0`, тому сингулярний член `r⁻²` відсутній:
  ```
  V_m1(r, θ) = -A · r · cos θ
  ```
- **Область 2 (`R_in < r < R_out`):** Стінка екрана (матеріал з проникністю `μ_r`):
  ```
  V_m2(r, θ) = -(C · r + D / r²) · cos θ
  ```
- **Область 3 (`r > R_out`):** Зовнішній простір (повітря, `μ_r = 1`). При `r → ∞` поле повинно прямувати до однорідного незбуреного поля `V_m3 → -H₀ · r · cos θ`:
  ```
  V_m3(r, θ) = -(H₀ · r - E / r²) · cos θ
  ```

Для знаходження коефіцієнтів `A`, `C`, `D`, `E` застосуємо граничні умови неперервності потенціалу та нормальної індукції на межах `r = R_in` та `r = R_out`.

#### Крок 1: Умови на внутрішній межі `r = R_in`

З неперервності потенціалу (тангенціального поля):
```
A · R_in = C · R_in + D / R_in²  [поділимо обидві частини на R_in]
= A = C + D / R_in³               (Рівняння 1)
```

З неперервності нормальної індукції (`μ₁ = 1`, `μ₂ = μ_r`):
```
1 · A = μ_r · (C - 2D / R_in³)   [диференціювання по r та помноження на μ]
= A = μ_r · C - 2 · μ_r · D / R_in³ (Рівняння 2)
```

Прирівняємо праві частини Рівнянь 1 та 2:
```
C + D / R_in³ = μ_r · C - 2 · μ_r · D / R_in³
= (2 · μ_r + 1) · D / R_in³ = (μ_r - 1) · C    [перенесення членів з D ліворуч, з C праворуч]
= D = [(μ_r - 1) / (2 · μ_r + 1)] · R_in³ · C   [вираження D через C]
```

Виразимо коефіцієнт `A` повністю через `C`:
```
A = C + [(μ_r - 1) / (2 · μ_r + 1)] · C
= A = [(3 · μ_r) / (2 · μ_r + 1)] · C           [зведення до спільного знаменника]
```

#### Крок 2: Умови на зовнішній межі `r = R_out`

З неперервності потенціалу при `r = R_out`:
```
C · R_out + D / R_out² = H₀ · R_out - E / R_out²  (Рівняння 3)
```

З неперервності нормальної індукції при `r = R_out`:
```
μ_r · (C - 2D / R_out³) = H₀ + 2E / R_out³         (Рівняння 4)
```

Щоб виключити невідомий коефіцієнт `E`, помножимо Рівняння 3 на 2 і додамо його до Рівняння 4:
```
2 · (C · R_out + D / R_out²) + μ_r · (C · R_out - 2D / R_out²) = 3 · H₀ · R_out  [додавання рівнянь]
= (μ_r + 2) · C - 2 · (μ_r - 1) · (D / R_out³) = 3 · H₀                         [поділ на R_out]
```

Підставимо у отримане співвідношення раніше виражене значення `D`:
```
(μ_r + 2) · C - 2 · (μ_r - 1) · [(μ_r - 1) / (2 · μ_r + 1)] · (R_in / R_out)³ · C = 3 · H₀  [підстановка D(C)]
```

Винесемо коефіцієнт `C` за дужки:
```
C · [ (μ_r + 2) - 2 · (μ_r - 1)² / (2 · μ_r + 1) · (R_in / R_out)³ ] = 3 · H₀               [факторизація C]
```

Підставляючи вираз для `C` у формулу для внутрішнього поля `H_int = A = [(3 · μ_r) / (2 · μ_r + 1)] · C`, отримуємо аналітичне значення індукції всередині сфери:
```
H_int = (9 · μ_r · H₀) / [ (2 · μ_r + 1)(μ_r + 2) - 2 · (μ_r - 1)² · (R_in / R_out)³ ]
```

Оскільки коефіцієнт екранування за визначенням є `S = H₀ / H_int`, після алгебраїчних перетворень отримуємо **точну формулу для сферичного екрана**:

```
S_sphere = 1 + (2 / 9) · [ ((μ_r - 1)²) / μ_r ] · [ 1 - (R_in / R_out)³ ]
```

#### Тонкостінне геометричне наближення для сфери

У більшості практичних інженерних застосувань відносна магнітна проникність є високою (`μ_r ≫ 1`), а товщина стінки `d = R_out - R_in` є набагато меншою за радіус сфери (`d ≪ R_in`).

Спростимо геометричний член формули за допомогою розкладу в степеневий ряд:

```
1 - (R_in / R_out)³ 
= 1 - (1 - d / R_out)³      [підстановка R_in = R_out - d]
≈ 1 - (1 - 3d / R_out)     [лінійне наближення бінома (1 - x)³ ≈ 1 - 3x при x ≪ 1]
= 3d / R_in                [радіальне наближення R_out ≈ R_in]
```

Підставляючи це тонкостінне спрощення у формулу екранування при `μ_r ≫ 1`, отримуємо:

```
S_sphere ≈ 1 + (2 / 9) · μ_r · (3d / R_in)
= (2 / 3) · μ_r · (d / R_in)     [нехтування одиницею при μ_r ≫ 1 та скорочення (2/9)·3 = 2/3]
```

### 3. Формули екранування для нескінченного циліндра

Для циліндричної оболонки радіуса `R_in` із товщиною стінки `d`, розташованої у перпендикулярному зовнішньому магнітному полі, розклад скалярного потенціалу у двовимірній циліндричній системі координат `(r, φ)` виконується за трігонометричним базисом `cos(nφ)`:

```
V_m(r, φ) = ∑ [ A_n · rⁿ + B_n · r⁻ⁿ ] · cos(nφ)
```

Аналогічне зшивання граничних умов неперервності потенціалу `V_m` та нормальної індукції `μ_r · (∂V_m / ∂r)` на двох циліндричних поверхнях `r = R_in` та `r = R_out` дає **точну формулу циліндричного екранування**:

```
S_cyl = 1 + (1 / 4) · [ ((μ_r - 1)²) / μ_r ] · [ 1 - (R_in / R_out)² ]
```

Для тонкостінного циліндра при `μ_r ≫ 1` та `d ≪ R_in` формула набуває вигляду:

```
S_cyl ≈ (1 / 2) · μ_r · (d / R_in)
```

Порівняння сферичного та циліндричного коефіцієнтів показує, що сферичний екран забезпечує на 33% вище екранування при однаковій товщині стінки `d` та радіусі `R` (`2/3` проти `1/2`). Це пояснюється тим, що сфера концентрує магнітний потік у трьох вимірах, тоді як циліндр — лише у двох.

#### Поздовжнє екранування циліндра та розмагнічувальні фактори

Якщо магнітне поле спрямоване вздовж осі циліндра довжиною `L`, екранування є значно менш ефективним через виникнення розмагнічувальних полів на відкритих торцах циліндра:

```
S_long ≈ 1 + 4 · N_z · μ_r · (d / R_in)
```
де `N_z` — фактор розмагнічування циліндра вздовж поздовжньої осі `z`.

Для довільного тривісного еліпсоїда з напівосями `a`, `b`, `c` фактори розмагнічування за трьома декартовими осями пов'язані фундаментальною теоремою суми:

```
N_x + N_y + N_z = 1
```

У випадку сфери через ідеальну симетрію `N_x = N_y = N_z = 1/3`. 

Для витягнутого еліпсоїда обертання або циліндра співвідношенням довжини до радіуса `m = L / R ≫ 1` фактор розмагнічування вздовж довгої осі `z` обчислюється аналітично:

```
N_z ≈ (1 / m²) · [ ln(2m) - 1 ]
```

Для довгого циліндра (`L / R = 10`) фактор `N_z` становить близько 0.015, що знижує коефіцієнт поздовжнього екранування у десятки разів порівняно з поперечним полем. Для усунення цього дефекту торці циліндричних екранів обов'язково закривають конусоподібними або пласкими кришками з мю-металу.

### 4. Інтегральні рівняння методом поверхневих потенціалів

При розрахунку екранів довільної тривимірної форми диференціальне рівняння Лапласа `∇² V_m = 0` зручно перетворити на поверхневе інтегральне рівняння Фредгольма другого роду. 

Замість обчислення потенціалу в усьому 3D-просторі, вводиться ефективна густина поверхневих магнітних зарядів `σ_m(r')` на поверхні екрана `S`:

```
V_m(r) = V_ext(r) + (1 / 4π) ∬_S [ σ_m(r') / |r - r'| ] dS'
```

Гранична умова неперервності нормальної індукції при `μ_r ≫ 1` дає інтегральне рівняння для невідомої густини зарядів `σ_m(r)`:

```
σ_m(r) = 2 · [ (μ_r - 1) / (μ_r + 1) ] · [ n(r) · H_ext(r) + (1 / 4π) ∬_S σ_m(r') · ( n(r) · (r - r') / |r - r'|³ ) dS' ]
```

Оскільки при `μ_r ≫ 1` коефіцієнт `(μ_r - 1)/(μ_r + 1) ≈ 1 - 2/μ_r` прямує до одиниці, розподіл поверхневих зарядів повністю визначається геометрією оболонки `S`. Це дозволяє швидко вираховувати екранування складних оболонок методом граничних елементів.

### 4. Багатошарове екранування та формули Кюпфмюллера

Розглянемо систему із двох концентричних циліндричних оболонок із радіусами `R₁` та `R₂` (`R₁ < R₂`), розділених немагнітним проміжком (повітря, алюміній).

Німецький електротехнік Карл Кюпфмюллер (*Karl Küpfmüller*) вивів співвідношення для підсумкового коефіцієнта екранування двошарової структури:

```
S_tot = S₁ · S₂ · [ 1 - (R₁ / R₂)² ] + S₁ + S₂
```
де `S₁` та `S₂` — коефіцієнти екранування першого та другого шару, розраховані як окремі оболонки.

Фізична причина розв'язки потенціалів полягає у тому, що повітряний зазор між шарами `g = R₂ - R₁` дозволяє зовнішньому екрану `S₂` виступати первинним бар'єром, який скидає основний магнітний потік. Внутрішній шар `S₁` омивається вже суттєво послабленим полем `B_mid = B_ext / S₂` і працює у чистому лінійному режимі високої проникності.

За наявності помірного радіального зазору між оболонками (`R₂ > 1.3 · R₁`) членом `S₁ + S₂` можна знехтувати, і формула набуває мультиплікативної форми:

```
S_tot ≈ S₁ · S₂ · [ 1 - (R₁ / R₂)² ]
```

#### Матричний метод каскадування для `N` шарів (Transfer Matrix Method)

Для довільної кількості `N` концентричних шарів розрахунок зручно проводити за допомогою передавальних матриць 2×2. Напруженість та індукція полів на внутрішній та зовнішній поверхні кожного шару пов'язані матричним рівнянням:

```
[ H(r_out) ] = [ M₁₁  M₁₂ ] · [ H(r_in) ]
[ B(r_out) ]   [ M₂₁  M₂₂ ]   [ B(r_in) ]
```

Для тонкостінного шару з проникністю `μ_r[i]` та радіусом `R[i]` передавальна матриця має вигляд:

```
M_i = [ 1                            R_i / (2 μ₀ μ_r[i] d[i]) ]
      [ 2 μ₀ μ_r[i] d[i] / R_i       1                        ]
```

Для повітряного зазору між шарами `i` та `i+1` передавальна матриця визначається зміною геометрії:

```
M_gap = [ (1/2)(1 + R_i²/R_{i+1}²)    (R_{i+1}² - R_i²) / (4 μ₀ R_{i+1}) ]
        [ 0                            (1/2)(1 + R_i²/R_{i+1}²)          ]
```

Загальна передавальна матриця всього багатошарового екрана дорівнює добутку матриць окремих шарів та повітряних зазорів:

```
M_total = M_N · M_gap_(N-1) · ... · M_gap_1 · M_1
```

Підсумковий коефіцієнт екранування визначається елементом матриці `S_tot = M_total[0][0]`. Цей метод дозволяє миттєво обчислювати каскади з будь-якого числа шарів (до 10–12 шарів у прецизійних МЕГ-кімнатах).

#### Доведення математичної переваги багатошаровості

Припустимо, що у розпорядженні інженера є об'єм мю-металу, з якого можна виготовити або один шар товщиною `2d`, або два окремі шари товщиною `d`, розділені радіальним зазором таким, що `(R₁ / R₂)² = 0.5`.

1. **Екранування суцільного шару товщиною `2d`:**
   ```
   S_single ≈ (1 / 2) · μ_r · (2d / R₁) = μ_r · (d / R₁)
   ```

2. **Екранування двох шарів товщиною `d` кожен:**
   ```
   S₁ ≈ (1 / 2) · μ_r · (d / R₁)
   S₂ ≈ (1 / 2) · μ_r · (d / R₂)
   S_tot ≈ S₁ · S₂ · (1 - 0.5) = (1 / 8) · μ_r² · (d / R₁)²
   ```

Знайдемо відношення ефективності двох конструкцій за однаковісінької витрати мю-металу:

```
S_tot / S_single = [ (1 / 8) · μ_r² · (d / R₁)² ] / [ μ_r · (d / R₁) ]
= (1 / 8) · μ_r · (d / R₁)
```

Оскільки відносна проникність відпаленого мю-металу сягає `μ_r = 200 000`, а типичний геометричний член `d / R₁` становить близько `0.01`, маємо:

```
S_tot / S_single ≈ (1 / 8) · 200 000 · 0.01 = 250
```

Це математичне доведення показує, що розділення матеріалу на дві ізольовані концентричні оболонки підвищує ефективність захисту у 250 разів порівняно із суцільним шаром подвійної товщини за абсолютно однакової маси використаного сплаву.

### 5. Граничний перехід до ідеального діамагнетика (Надпровідника)

Цікавим математичним аспектом формул Кюпфмюллера та сферичного екранування є поведінка виразів при зміні відносної проникності `μ_r` від нуля до нескінченності.

```
Спектр коефіцієнта екранування S залежно від відносної проникності μ_r:

μ_r = 0 (Надпровідник, ефект Мейснера)  ⇒ S → ∞    [Повне виштовхування]
μ_r = 1 (Вакуум, повітря)               ⇒ S = 1    [Ніякого екранування]
μ_r ≫ 1 (Мю-метал, пермаллой)          ⇒ S ≈ (2/3) μ_r (d/R)  [Переспрямування]
```

Якщо виконати граничний перехід `μ_r → 0` у точній формулі сферичного екранування:

```
lim_{μ_r → 0} S_sphere = lim_{μ_r → 0} [ 1 + (2/9) · ((μ_r - 1)² / μ_r) · (1 - (R_in/R_out)³) ]
= ∞
```

Математично цей результат показує, що для середовища з нульовою відносною проникністю `μ_r = 0` (надпровідник у Мейснер-стані) коефіцієнт екранування прямує до нескінченності незалежно від товщини стінки `d`. Граничні умови електродинаміки при `μ_r = 0` вимагають строго `B_n = 0` на поверхні, що фізично реалізується утворенням поверхневих надпровідних струмів Лондона.

### 6. Математична модель вихрового екранування на високих частотах

Для змінних полів амплітуда поля на поверхні провідника з електропровідністю `σ` згасає за рівнянням Гельмгольца:

```
∇² B = k² · B
```
де `k = (1 + i) / δ` — комплексне хвильове число, `δ = √(2 / (ω μ₀ μ_r σ))` — глибина скін-шару.

Для плоского листа товщиною `d` розв'язок рівняння Гельмгольца дає точний коефіцієнт екранування вихровими струмами:

```
S_AC = | cosh(k · d) + (1/2) · (Z_wall / Z_air + Z_air / Z_wall) · sinh(k · d) |
```
де `Z_wall = √((i ω μ) / σ)` — хвильовий імпеданс матеріалу екрана, `Z_air = √(μ₀ / ε₀) ≈ 377 Ом` — імпеданс вільного простору.

При `d ≫ δ` формула спрощується до експоненційного закону:

```
S_AC ≈ (1 / 4) · (Z_air / Z_wall) · exp(d / δ)
```

Математичний аналіз виразу показує, що при зростанні частоти `ω` глибина скін-шару `δ` зменшується пропорційно `1 / √ω`, унаслідок чого показник експоненти `d / δ` зростає як `√ω`. Це забезпечує потужне експоненційне зростання екранування на високих частотах для високоелектропровідних металів (міді та алюмінію).

#### Енергетичні втрати на вихрові струми у шихтованих структурах

Об'ємна густина потужності втрат на вихрові струми у металевому листі товщиною `d` під дією змінного магнітного поля `B(t) = B₀ sin(ωt)` описується співвідношенням:

```
P_eddy = (1 / 6) · σ · d² · ω² · B₀²  [Вт/м³]
```

Для зменшення цих втрат у силових трансформаторах і магнітних екранах низької частоти суцільний метал замінюють шихтованими пакетами з ізольованих пластин товщиною 0.2–0.5 мм. Оскільки втрати зменшуються пропорційно квадрату товщини `d²`, шихтування пластин дозволяє уникнути паразитичного нагріву екранувальних оболонок при збереженні високого значення `μ_r`.

Ключовим критерієм переходу від магнітостатичного режиму до режиму вихрових струмів є безрозмірне співвідношення товщини стінки до глибини скін-шару `d / δ`. Коли `d / δ < 0.5`, вихрові струми майже не спотворюють магнітостатичний розподіл полей, і коефіцієнт екранування вираховується за класичними потенціальними формулами Лапласа. Коли ж `d / δ > 3`, домінуючим стає експоненційне виштовхування електромагнітної хвилі поверхневими струмами Фуко.

Отримані математичні формули є фундаментальною підвалиною для числового моделювання складних багатошарових оболонок, розрахунку передавальних матриць та проектування прецизійних магнітних екранів вимірювальних систем.

Таким чином, математичний апарат розрахунку коефіцієнтів екранування охоплює як стаціонарні магнітостатичні задачі (потенціали Лапласа, концентричні оболонки та формули Кюпфмюллера), так і динамічні високочастотні процеси з урахуванням комплексних імпедансів та вихрових струмів у провідних матеріалах.
