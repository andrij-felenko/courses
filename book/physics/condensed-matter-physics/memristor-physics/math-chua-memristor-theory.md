# 🧮 Математична теорія мемристивних систем Леона Чуа: фундаментальні рівняння стан-вихід

Ця вставка надає строгий математичний апарат теорії мемристорів та мемристивних систем, сформульований Леоном Чуа та Сун-Мо Кангом (1976). Вона деталізує виведення фундаментальних рівнянь стану, аналіз енергетичної пасивності, малогнальний спектральний аналіз імпедансу та доведення трьох математичних теорем («відбитків пальців»), за якими будь-який двополюсник однозначно ідентифікується як мемристивний.

## Фундаментальні класи двополюсних мемристорів

Математичний опис ідеального мемристора базується на припущенні, що існує функціональна залежність між часовим інтегралом напруги (магнітним потоком `φ`) та часовим інтегралом струму (електричним зарядом `q`):

```
g(φ, q) = 0
```

Залежно від того, яку з двох змінних обрано незалежним аргументом, розрізняють два класи елементів:

### 1. Керувальний зарядом мемристор (Charge-Controlled Memristor)

Якщо магнітний потік `φ` є однозначною функцією від заряду `q`, тобто `φ = φ(q)`, то дифференціювання за часом дає:

```
v(t) = dφ(t) / dt
= (dφ / dq) · (dq / dt)     [ланцюгове правило: dφ/dt = (dφ/dq)·(dq/dt)]
= M(q(t)) · i(t)           [означення мемристора M(q) та струму i = dq/dt]
```

де скалярна функція `M(q)` називається **мемристором** або мемристивним опором (memristance, вимірюється в Омах, `Ом`):

```
M(q) = dφ(q) / dq
```

### 2. Керувальний потоком мемристор (Flux-Controlled Memristor)

Якщо заряд `q` є однозначною функцією від потоку `φ`, тобто `q = q(φ)`, то дифференціювання дає:

```
i(t) = dq(t) / dt
= (dq / dφ) · (dφ / dt)     [ланцюгове правило: dq/dt = (dq/dφ)·(dφ/dt)]
= W(φ(t)) · v(t)           [означення мемдуктенсу W(φ) та напруги v = dφ/dt]
```

де функція `W(φ)` називається **мемдуктенсом** або мемристивною провідністю (memductance, вимірюється в Сименсах, `См`):

```
W(φ) = dq(φ) / dφ
```

Мемристор та мемдуктенс пов'язані взаємно оберненим співвідношенням у кожній точці: `W(φ(q)) = 1 / M(q)`.

## Термодинаміка та умова пасивності

Енергія `E(t)`, що надходить у мемристор від початку часу `t = -∞` до моменту `t`, обчислюється як інтеграл мгновенної потужності:

```
E(t) = ∫[-∞..t] v(τ) · i(τ) dτ
= ∫[-∞..t] M(q(τ)) · i²(τ) dτ
= ∫[q(-∞)..q(t)] M(q) dq
```

Двополюсник є **пасивним** (не містить внутрішніх джерел енергії і лише дисипує енергію у вигляді тепла), якщо накопичена енергія є невід'ємною для будь-якої траєкторії:

```
E(t) ≥ 0  для всіх t
```

Звідси випливає **умова пасивності мемристора**:
Мемристор є пасивним елементом тоді й лише тоді, коли його інфінітезимальний опір є додатним для всіх значень заряду:

```
M(q) ≥ 0  для всіх q ∈ ℝ
```

У цьому випадку мемристор дисипує потужність `P(t) = M(q(t)) · i²(t) ≥ 0` точно так само, як і звичайний омічний резистор, проте величина цієї дисипації визначається всією попередньою історією проходження заряду.

## Узагальнені мемристивні системи (Chua & Kang, 1976)

Більшість реальних фізичних пристроїв (зокрема наноплівки `TiO₂`, `HfO₂`, фазові матеріали) не описуються простою залежністю `φ(q)`. Перерозподіл носіїв чи зміна фазового стану вимагає введення **внутрішніх змінних стану**.

Узагальнена **n-мірна мемристивна система**, керувальна струмом, задається системою диференціальних та алгебраїчних рівнянь:

```
d x / dt = f(x, i, t)          [Рівняння внутрішнього стану]
v(t) = R(x, i, t) · i(t)       [Рівняння відгуку / виходу]
```

де:
- `x = (x₁, x₂, ..., xₙ)` — вектор внутрішніх змінних стану (наприклад, товщина збагаченого шару `w`, температура локального філаменту `T`, радіус провідного каналу `r`);
- `f: ℝⁿ × ℝ × ℝ → ℝⁿ` — нелінійна вектор-функція кінетики стану;
- `R: ℝⁿ × ℝ × ℝ → ℝ` — оборотна нелінійна функція опору (мемристор).

Для системи, керувальної напругою, рівняння задаються аналогічно:

```
d x / dt = f(x, v, t)
i(t) = G(x, v, t) · v(t)
```

де `G(x, v, t)` — оборотний мемдуктенс.

## Три фундаментальні теореми («Відбитки пальців» мемристора)

Леон Чуа довів, що будь-яка фізична система, яка описується узагальненими рівняннями мемристивної системи, обов'язково демонструє три чіткі математичні властивості.

### Теорема 1: Стиснута петля гістерезису (Pinched Hysteresis Loop)

**Теорема**: Якщо до мемристивної системи прикласти періодичний гармонічний сигнал напруги з нульовим середнім значенням `v(t) = V₀ · sin(ω·t)`, то вольт-амперна характеристика у площині `(v, i)` утворює замкнену петлю гістерезису, яка **примусово проходить через початок координат (0, 0)**.

**Доведення**:
1. Розглянемо момент часу `t₀`, коли напруга звертається в нуль: `v(t₀) = 0`.
2. Рівняння виходу системи дорівнює `i(t₀) = G(x(t₀), 0, t₀) · v(t₀)`.
3. Оскільки функція `G(x, 0, t₀)` є скінченною для фізичної системи, множення на `v(t₀) = 0` дає:
   ```
   i(t₀) = G(x(t₀), 0, t₀) · 0 = 0
   ```
4. Отже, при `v = 0` струм завжди дорівнює `i = 0`, незалежно від значення вектора стану `x(t₀)`.
5. Це означає, що траєкторія ВАХ обов'язково перетинає точку `(0, 0)` без будь-якого зсуву за напругою чи струмом (відсутність самовільної ЕРС або внутрішньої ємності).

### Теорема 2: Виродження петлі при високих частотах (Frequency Degeneracy)

**Теорема**: При прямуванні частоти збудження до нескінченності (`ω → ∞`) площа петлі гістерезису прямує до нуля, а характеристика системи вироджується у ВАХ **однозначного лінійного резистора**.

**Доведення**:
1. Зміна вектора стану за один період `T = 2π / ω` дорівнює:
   ```
   Δx = ∫[0..T] f(x(τ), v(τ), τ) dτ
   ```
2. Коли `ω → ∞`, період `T → 0`. Оскільки швидкість зміни стану `f(x, v, t)` обмежена фізичними законами дрейфу іонів, вектор стану `x(t)` не встигає помітно змінитися за малий період `T` і фіксується на своєму середньому значенні `x_eq`.
3. Запроваджуючи суттєво постійний стан `x(t) ≈ x_eq`, рівняння виходу перетворюється на:
   ```
   i(t) = G(x_eq, v(t), t) · v(t) ≈ G_eq · v(t)
   ```
4. Графік `i(v)` стає прямою лінією, що проходить через `(0,0)` з нахилом `G_eq`. Площа петлі гістерезису `Area(ω) ∝ 1/ω` згасає до нуля.

### Теорема 3: Збереження стану при відсутності сигналу (Non-Volatility)

**Теорема**: Якщо зовнішній сигнал дорівнює нулю (`v(t) = 0` або `i(t) = 0`), швидкість зміни внутрішнього стану звертається в нуль `d x / dt = 0`, і система зберігає поточний опір нескінченно довго.

**Доведення**:
Для фізично енергонезалежної мемристивної системи функція кінетики задовольняє умову `f(x, 0, t) = 0`. 

Тоді при `v = 0`:
```
d x / dt = f(x, 0, t) = 0  ⇒  x(t) = const = x_hold
```

Опір пристрою `R_hold = R(x_hold, 0, t)` залишається абсолютно стабільним, що забезпечує функцію неенергозалежної пам'яті (Non-Volatile Memory).

## Малосигнальний еквівалентний імпеданс та псевдоіндуктивність

Для аналізу динамічної стійкості та частотного відгуку мемристора біля робочої точки `(V₀, I₀, x₀)` розкладемо рівняння стану та виходу в тригонометричний ряд Тейлора за малими відхиленнями `δv(t)`, `δi(t)` та `δx(t)`.

Лінеаризовані рівняння узагальненої 1D мемристивної системи мають вигляд:

```
d δx / dt = a · δx + b · δv
δi = c · δx + g₀ · δv
```

де часткові похідні обчислюються у стаціонарній точці `(x₀, V₀)`:
- `a = ∂f / ∂x |_(x₀, V₀)` — коефіцієнт релаксації стану (зазвичай `a < 0` для стійких систем);
- `b = ∂f / ∂v |_(x₀, V₀)` — ефективна чутливість дрейфу до напруги;
- `c = V₀ · (∂G / ∂x) |_(x₀, V₀)` — зсувний струмовий коефіцієнт;
- `g₀ = G(x₀, V₀)` — статична провідність у робочій точці.

Застосовуючи перетворення Лапласа (`d/dt → s`), отримуємо операторну провідність стану `Y(s) = δI(s) / δV(s)`:

```
δX(s) = [b / (s - a)] · δV(s)
δI(s) = [c · b / (s - a) + g₀] · δV(s)
```

Малосигнальна адмітансна функція мемристора `Y(s)` дорівнює:

```
Y(s) = g₀ + [b · c / (s - a)]
```

Переходячи до малосигнального імпедансу `Z(s) = 1 / Y(s)`, ми бачимо, що еквівалентна електрична схема мемристора при малих гармонічних коливаннях складається з паралельного з'єднання:
1. Омічного резистора `R₀ = 1 / g₀`.
2. Послідовного контуру з додаткового опору `R_x = -a / (b · c)` та еквівалентної індуктивності `L_eq = 1 / (b · c)`.

Цей результат пояснює важливо фізичне явище: на низьких частотах дрейф вакансій створює фазову затримку струму відносно напруги, викликаючи **псевдоіндуктивний відгук** без наявності справжнього магнітного поля, що дозволяє синтезувати активні індуктивності на основі чисто пасивних наномемристорів.
