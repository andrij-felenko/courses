# 🧮 Математичне виведення рівнянь метода трансферної лінії (TLM)

Метод трансферної лінії (*Transfer Line Method*, TLM) спирається на розрахунок одномірного розподілу електричного потенціалу та струму під плоским прямокутним металевим контактом. Оскільки напівпровідниковий шар під контактом має власний омічний опір, а межа розділу між металом і напівпровідником володіє питомим опором контакту, ця система моделюється у вигляді розподіленої електродинамічної лінії передачі з неперервними витоками струму.

Нижче наведено строге математичне виведення диференціальних рівнянь розподілу потенціалу `V(x)`, густини струму `J(x)`, та вираження повного опору контакту `R_c` через характерні фізичні параметри матеріалу.

## 1. Постановка задачі та диференціальне рівняння планарного контакту

Розглянемо прямокутну контактну площадку шириною `W` та довжиною `L`, сформовану на поверхні легованої напівпровідникової мези товщиною `t`. Металевий електрод має високу провідність, тому його електричний потенціал вважаємо сталим по всій площі й приймаємо за нульовий рівень відліку (`V_m = 0`).

Потенціал у легованому напівпровідниковому шарі безпосередньо під контактом є функцією координати `x`, тобто `V(x)`. Координату `x = 0` виберемо на передньому краю контакту (куди входить струм із зазору), а `x = L` — на протилежному задньому краю.

Розглянемо елементарний шар напівпровідника довжиною `dx` між точками `x` та `x + dx`. Струм `I(x)`, що протікає вздовж напівпровідника паралельно поверхні, спричиняє спад потенціалу згідно із законом Ома:

```
dV/dx = - I(x) · (R_sk / W)             [зміна потенціалу вздовж напівпровідника]
```
де `R_sk` — шаровий опір легованого напівпровідникового шару безпосередньо під контактом (`Ом/кв`).

За рахунок різниці потенціалів між напівпровідником `V(x)` та металом `V_m = 0` частина струму відгалужується і перетікає вертикально через омічний бар'єр у метал. Зміна струму `dI` на відрізку `dx` дорівнює:

```
dI/dx = - V(x) · (W / rho_c)            [витік струму в метал крізь опір rho_c]
```
де `rho_c` — питомий опір контакту (`Ом·см²`).

Продиференціювавши перше рівняння за координатою `x` та підставивши у нього вираз для `dI/dx` з другого рівняння, отримуємо фундаментальне диференціальне рівняння другого порядку:

```
d²V/dx² = - (R_sk / W) · (dI/dx)                 [диференціювання рівняння dV/dx за змінною x]
        = - (R_sk / W) · (- V(x) · W / rho_c)    [підстановка виразу dI/dx з другого рівняння]
        = V(x) · (R_sk / rho_c)                  [скорочення ширини W та зведення мінусів]
```

Введемо характерний фізичний параметр системи — **довжину перенесення струму** `L_T` (*transfer length*):

```
L_T = √(rho_c / R_sk)                    [довжина згасання струму під контактом]
```

Завдяки цьому введенню диференціальне рівняння набуває класичного вигляду однорідного рівняння лінії передачі зі згасанням:

```
d²V/dx² - V(x) / L_T² = 0                [основне рівняння струморозподілу TLM]
```

## 2. Загальний розв'язок та крайові умови

Загальний інтеграл цього лінійного диференціального рівняння другого порядку зі сталими коефіцієнтами виражається через комбінацію гіперболічних функцій:

```
V(x) = A · cosh((L - x) / L_T) + B · sinh((L - x) / L_T)
```
де `A` та `B` — константи інтегрування, що визначаються фізичними крайовими умовами на межах контактної площадки.

Сформулюємо дві фундаментальні крайові умови:
1. **На задньому краю контакту (`x = L`):** Металева площадка закінчується, тому далі струм у напівпровідникові протікати не може. Звідси струм вздовж напівпровідника дорівнює нулю: `I(L) = 0`, що еквівалентно умові `dV/dx|_(x=L) = 0`.
2. **На передньому краю контакту (`x = 0`):** У контакт входить увесь повний струм `I_0`, що протікає через вимірювальне коло.

Застосуємо першу крайову умову `dV/dx|_(x=L) = 0`. Для цього знайдемо першу похідну розв'язку:

```
dV/dx = - (A / L_T) · sinh((L - x) / L_T) - (B / L_T) · cosh((L - x) / L_T)

При x = L:
sinh(0) = 0,  cosh(0) = 1
dV/dx|_(x=L) = - (B / L_T) = 0  ⇒  B = 0
```

Таким чином, константа `B` строго дорівнює нулю, і вираз для потенціалу спрощується:

```
V(x) = A · cosh((L - x) / L_T)
```

Тепер застосуємо другу крайову умову при `x = 0`, де струм `I(0) = I_0`:

```
I(0) = - (W / R_sk) · dV/dx|_(x=0)               [закон Ома для струму на вході х = 0]
     = - (W / R_sk) · (- A / L_T · sinh(L / L_T))  [підстановка похідної dV/dx при х = 0]
     = A · (W / (R_sk · L_T)) · sinh(L / L_T) = I_0 [зведення подвійного мінуса]
```

Виражаємо константу `A`:

```
A = I_0 · (R_sk · L_T / W) / sinh(L / L_T)
```

Підставляючи отримане значення константи `A` у вираз для `V(x)`, маємо точний розподіл потенціалу вздовж контакту:

```
V(x) = I_0 · (R_sk · L_T / W) · [ cosh((L - x) / L_T) / sinh(L / L_T) ]
```

Діленням потенціалу `V(x)` на питомий опір `rho_c` отримуємо вираз для густини вертикального струму `J(x)`, який протікає через омічний бар'єр у метал у кожній точці `x`:

```
J(x) = V(x) / rho_c
     = [ I_0 / (W · L_T) ] · [ cosh((L - x) / L_T) / sinh(L / L_T) ]
```

## 3. Точне виведення опору контакту `R_c`

Повний експериментально вимірюваний опір контакту `R_c` визначається як відношення потенціалу на передньому краю контакту `V(0)` до повного струму `I_0`:

```
R_c = V(0) / I_0
    = [ I_0 · (R_sk · L_T / W) · cosh(L / L_T) / sinh(L / L_T) ] / I_0
    = (R_sk · L_T / W) · coth(L / L_T)
```

Оскільки за визначенням `L_T = √(rho_c / R_sk)`, то добуток `R_sk · L_T` можна переписати як:

```
R_sk · L_T = R_sk · √(rho_c / R_sk) = √(rho_c · R_sk)
```

Тоді остаточна точна формула для опору контакту `R_c` набирає вигляду:

```
R_c = ( √(rho_c · R_sk) / W ) · coth(L / L_T)
```

## 4. Фізичний аналіз граничних випадків та ефект скупчення струму

Аналіз формули опору контакту виявляє два кардинально різних фізичних режими роботи залежно від безрозмірного співвідношення `L / L_T`:

### 1. Довгий контакт (`L ≥ 2 · L_T`)
Для значень аргументу `z = L / L_T ≥ 2` значення гіперболічного котангенса швидко прямує до одиниці (`coth(z) ≈ 1.033` при `z = 2`, і `coth(z) → 1.000` при `z > 3`). 

Тоді формула для опору контакту спрощується до:

```
R_c ≈ √(rho_c · R_sk) / W = rho_c / (W · L_T)     [для L ≥ 2·L_T]
```

Цей результат виявляє фундаментальний ефект **скупчення струму** (*current crowding*): практично весь струм перетікає з напівпровідника в метал на вузькій передній смужці довжиною близько `L_T`. Задня частина контакту (при `x > 2·L_T`) виявляється струмово неактивною. Збільшення географічної довжини контакту `L` понад `2·L_T` більше взагалі не зменшує його опір `R_c`.

### 2. Короткий контакт (`L << L_T`)
Якщо контакт є географічно коротким (`L << L_T`), аргумент `z = L / L_T << 1`. Розкладаючи гіперболічний котангенс у ряд Тейлора:

```
coth(z) ≈ 1/z + z/3
```

Підставляючи це розкладання у формулу опору контакту:

```
R_c ≈ ( √(rho_c · R_sk) / W ) · ( L_T / L )       [підстановка наближення coth(z) ≈ 1/z]
    = ( √(rho_c · R_sk) / W ) · ( √(rho_c / R_sk) / L ) [підстановка L_T = √(rho_c / R_sk)]
    = rho_c / (W · L)                             [скорочення R_sk у чисельнику й знаменнику]
```

У режимі короткого контакту струм рівномірно розподіляється по всій геометричній площі контакту `S = W · L`, і контакт поводиться як звичайний плоский омічний резистор із площею `S`.

## 5. Залежність загального опору `R_T(d)` від відстані між контактами

У стандартному аналізі TLM вимірюється загальний опір `R_T` між двома подібними контактами, розташованими на відстані `d` один від одного. Загальний опір є сумою опору двох контактів та опору напівпровідникового зазору між ними:

```
R_T(d) = 2 · R_c + R_gap
       = 2 · R_c + (R_sh / W) · d
```

Для довгих контактів (`L ≥ 2·L_T`) підставимо вираз `R_c ≈ (R_sh · L_T) / W` (припускаючи `R_sk ≈ R_sh`):

```
R_T(d) = 2 · (R_sh · L_T / W) + (R_sh / W) · d     [підстановка R_c для довгого контакту]
       = (R_sh / W) · (d + 2 · L_T)                [винесення спільного множника (R_sh / W)]
```

Це рівняння прямої лінії `R_T = A · d + B` дає просту геометричну інтерпретацію експериментального графіка:
- **Нахил прямої:** `A = dR_T / dd = R_sh / W`, звідки шаровий опір напівпровідника `R_sh = A · W`.
- **Точка перетину з віссю ординат (`d = 0`):** `B = R_T(0) = 2 · R_c`, звідки опір одного контакту `R_c = B / 2`.
- **Точка перетину з віссю абсцис (`R_T = 0`):** `d_intercept = - 2 · L_T`, звідки довжина перенесення `L_T = |d_intercept| / 2`.

З урахуванням вилучених з регресії параметрів питомий опір контакту `rho_c` обчислюється як:

```
rho_c = R_c · W · L_T = (R_T(0) / 2) · W · L_T      [Ом·см²]
```

Ці математичні співвідношення лежать в основі всіх автоматизованих систем вимірювання та контролю якості омічних контактів у напівпровідниковій індустрії.
