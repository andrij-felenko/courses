# 🧮 Математична теорія детального балансу та межа Шокли — Квайссера

Математичний розрахунок граничного коефіцієнта корисної дії (ККД) напівпровідникового сонячного елемента спирається на принцип детального балансу, сформульований Вільямом Шокли та Гансом-Йоахімом Квайссером у 1961 році. Цей розрахунок встановлює сувору термодинамічну межу перетворення сонячного випромінювання на електричну енергію для одноперехідного фотоелемента, незалежно від майбутніх інженерних удосконалень матеріалу чи технології виготовлення приладу.

## 1. Спектральний потік фотонів та модель чорного тіла

Сонце розглядають як абсолютне чорне тіло з температурою `T_s = 5778 K`, яке випромінює у безмежний простір, а сонячний елемент — як плоский поглинач із температурою навколишнього середовища `T_c = 300 K`.

Згідно із законом випромінювання Планка, спектральна густина потоку фотонів з енергією `E = h·ν`, які падають на одиницю площі сонячного елемента за одиницю часу в тілесному куті `Ω_s`, визначається виразом:

```
F(E, T_s) = (2·π / (c²·h³)) · (E² / (exp(E / (k_B·T_s)) − 1))
```

де `h` — стала Планка (`6.626 × 10⁻³⁴ Дж·с`), `c` — швидкість світла в вакуумі (`2.998 × 10⁸ м/с`), `k_B` — стала Больцмана (`1.381 × 10⁻²³ Дж/К`), `E` — енергія фотона у джоулях або електронвольтах (`1 еВ = 1.602 × 10⁻¹⁹ Дж`).

В одноперехідному фотоелементі із шириною забороненої зони `E_g` кожен фотон з енергією `E ≥ E_g` здатний згенерувати рівно одну електронно-діркову пару. Фотони з енергією `E < E_g` не поглинаються і переходять у тепловий опір або проходять наскрізь.

Загальна кількість згенерованих фотоносіїв на одиницю площі за секунду (густина фотоструму генерації `J_ph`) у наближенні повного поглинання квантів вище порогу дорівнює:

```
J_ph = q · S_sun(E_g)
```

де `q` — елементарний заряд (`1.602 × 10⁻¹⁹ Кл`), а `S_sun(E_g)` — інтегральний потік фотонів Сонця вище ширини зони:

```
S_sun(E_g)
= ∫_{E_g}^{∞} F(E, T_s) dE                     [інтегрування спектра від E_g до нескінченності]
= ∫_{E_g}^{∞} (2·π / (c²·h³)) · (E² / (exp(E / (k_B·T_s)) − 1)) dE
```

Для полегшення аналітичного обчислення довгохвильової частини спектра при `E >> k_B·T_s` зазвичай використовують наближення Віна `exp(E / (k_B·T_s)) − 1 ≈ exp(E / (k_B·T_s))`, що дозволяє звести інтеграл до виразу за допомогою неповної гамма-функції:

```
S_sun(E_g)
≈ (2·π · k_B · T_s / (c²·h³)) · exp(−E_g / (k_B·T_s)) · (E_g² + 2·E_g·k_B·T_s + 2·(k_B·T_s)²)
```

## 2. Теплове випромінювання та радіаційна рекомбінація

Принцип детального балансу вимагає, щоб у стані термодинамічної рівноваги (без освітлення та при нульовій напрузі `V = 0`) швидкість генерації носіїв тепловим випромінюванням оточення дорівнювала швидкості зворотної радіаційної рекомбінації.

За наявності зовнішнього освітлення та прикладеної напруги `V` концентрація нерівноважних носіїв у напівпровіднику зростає. Розщеплення квазірівнів Фермі для електронів `E_Fn` та дірок `E_Fp` сягає величини:

```
ΔE_F = E_Fn − E_Fp = q · V
```

Збільшення концентрації носіїв зарядів пропорційне чиннику Больцмана `exp(q·V / (k_B·T_c))`. Це призводить до підсилення зворотної випромінювальної (радіаційної) рекомбінації електронів та дірок у тілесний кут `2·π` півсфери:

```
J_rad(V) = q · R_0 · exp(q·V / (k_B·T_c))
```

де `R_0` — рівноважна швидкість випромінювальної рекомбінації сонячного елемента при температурі `T_c = 300 K` у суцільній темряві:

```
R_0
= ∫_{E_g}^{∞} (2·π / (c²·h³)) · (E² / (exp(E / (k_B·T_c)) − 1)) dE
```

Зауважимо, що оскільки температура Сонця `T_s (5778 K)` значно перевищує температуру елемента `T_c (300 K)`, коефіцієнт `R_0` на багато порядків менший за сонячний потік `S_sun(E_g)`.

Для порівняння параметрів кремнію (`E_g = 1.12 еВ`):
- Сонячний потік фотонів над порогом: `S_sun(1.12 еВ) ≈ 2.7 × 10²¹ м⁻²·с⁻¹` (що відповідає гранічному струму короткого замикання `J_sc ≈ 43.5 мА/см²`).
- Рівноважний випромінювальний потік у темряві: `R_0(1.12 еВ) ≈ 1.8 × 10⁻¹⁰ А/м² = 1.8 × 10⁻¹⁴ А/см²`.

Саме це величезне співвідношення `S_sun / R_0 ≈ 10¹²` забезпечує виникнення високої напруги холостого ходу в напівпровідниковому переходу.

## 3. Математичний баланс струмів та знаходження максимальної потужності

Результуюча вольт-амперна характеристика ідеального освітленого фотоелемента, що обмежений лише фундаментальною радіаційною рекомбінацією, описується балансом струмів:

```
J(V)
= J_ph − J_rad(V)
= q · S_sun(E_g) − q · R_0 · exp(q·V / (k_B·T_c))     [Рівняння детального балансу Шокли — Квайссера]
```

Електрична потужність `P(V)`, яку сонячний елемент передає у зовнішнє електричне навантаження з одиниці своєї площі, є добутком струму на напругу:

```
P(V)
= J(V) · V
= q · [S_sun(E_g) − R_0 · exp(q·V / (k_B·T_c))] · V
```

Для визначення точки максимальної потужності (Maximum Power Point, MPP) обчислюємо першу похідну потужності по напрузі та прирівнюємо її до нуля:

```
dP / dV = 0
⇒ J(V_mp) + V_mp · (dJ / dV)|_{V_mp} = 0
```

Підставляючи вираз для `J(V)` та обчислюючи похідну `dJ/dV = − (q²·R_0 / (k_B·T_c)) · exp(q·V / (k_B·T_c))`, отримуємо трансцендентне рівняння для напруги максимальної потужності `V_mp`:

```
q · S_sun(E_g) − q · R_0 · exp(q·V_mp / (k_B·T_c)) − q · V_mp · (q·R_0 / (k_B·T_c)) · exp(q·V_mp / (k_B·T_c)) = 0
```

Для спрощення математичного запису введемо безрозмірну напругу `v = q·V / (k_B·T_c)` та позначимо безрозмірну напругу холостого ходу `v_oc = q·V_oc / (k_B·T_c)`.

Оскільки при холостому ході `J(V_oc) = 0`, з рівняння детального балансу випливає:

```
exp(v_oc) = S_sun(E_g) / R_0
⇒ v_oc = ln(S_sun(E_g) / R_0)
```

Тоді трансцендентне рівняння для точки максимальної потужності `v_mp` перетворюється на компактну форму:

```
(1 + v_mp) · exp(v_mp) = exp(v_oc)
```

Розв'язок цього рівняння може бути виражений через спеціальну функцію Ламберта `W(x)`:

```
v_mp = W(exp(v_oc + 1)) − 1
```

Або через точне аналітичне наближення Мартина Ґріна з похибкою менше ніж `0.05\%`:

```
v_mp ≈ v_oc − ln(v_oc + 1) + ln(1 + ln(v_oc + 1) / (v_oc + 1))
```

Струм у точці максимальної потужності `J_mp` обчислюється через оптимальну напругу `v_mp`:

```
J_mp = q · S_sun(E_g) · [v_mp / (1 + v_mp)]
```

## 4. Коефіцієнт заповнення FF та вирази для ККД

Коефіцієнт заповнення вольт-амперної характеристики `FF` (Fill Factor) визначається як відношення максимальної вихідної потужності `P_max = J_mp · V_mp` до прямокутника теоретичного максимуму `P_th = J_sc · V_oc`:

```
FF
= (J_mp · V_mp) / (J_sc · V_oc)
= (v_mp² / ((1 + v_mp) · v_oc)) · (1 − exp(−v_mp))      [Точна формула детального балансу для FF]
```

Граничний коефіцієнт корисної дії `η_max` є відношенням вихідної електричної потужності до повної густини падаючого сонячного випромінювання `P_in`:

```
η_max = P_max / P_in = (J_sc · V_oc · FF) / P_in
```

Для стандарту сонячного спектра AM1.5G інтегральна густина падаючої потужності становить `P_in ≈ 1000 Вт/м²` (`100 мВт/см²`).

## 5. Гранична ефективність залежно від забороненої зони E_g

Чисельне інтегрування рівнянь детального балансу для стандарту сонячного спектра AM1.5G дає такий розподіл граничного ККД залежно від ширини забороненої зони напівпровідника `E_g`:

## 7. Гранична ефективність при фокусуванні світла та каскадні структури

Термодинамічна межа Шокли — Квайссера може бути суттєво підвищена за допомогою двох фізичних методів:

1. **Концентрація сонячного випромінювання (`C > 1`)**:
   Якщо сонячне світло сфокусувати лінзами чи дзеркалами у `C` разів (до максимуму `C_max = 46200` сонячних дисків), густина фотоструму `J_ph` зростає в `C` разів. При цьому напруга холостого ходу збільшується на величину:

```
ΔV_oc = (k_B·T_c / q) · ln(C)
```

   При максимальній теоретичній концентрації сонячного світла (`C = 46200`) граничний ККД одноперехідного фотоелемента зростає з `33.7\%` до `40.7\%`.

2. **Багатоперехідні (каскадні або тандемні) фотоелементи**:
   Якщо розмістити послідовно один за одним `N` напівпровідникових переходів із ширинами заборонених зон `E_g1 > E_g2 > … > E_gN`, кожен перехід буде поглинати свій вузький спектральний діапазон. Це різко знижує втрати на термалізацію та пропущення фотонів.

Для нескінченної кількості переходів (`N → ∞`) при звичайному освітленні (`C = 1`) термодинамічна межа ККД досягає `68.8\%`, а при максимальній концентрації світла (`C = 46200`) — становить `86.8\%`, наближаючись до межі Карно `1 − T_c / T_s = 94.8\%`.
