# 🧮 Математичне виведення рівнянь Лондонів та квантування магнітного потоку

Цей матеріал містить строге математичне виведення феноменологічних рівнянь братів Лондонів, термодинамічний аналіз дворідинної моделі, виведення нелокального рівняння Піппарда, розрахунок проникнення поля в тонкі плівки, виведення межі депарування струму та доведення квантування флюксоїда на основі градієнта фази макроскопічної хвильової функції.

## 1. Перше рівняння Лондонів: Динаміка носіїв без розсіювання

Розглянемо електронний газ у надпровідному стані. Припускається, що частина електронів провідності з об'ємною густиною `n_s` об'єднується у надпровідний конденсат і рухається крізь кристалічну ґратку без жодного треку чи розсіювання на теплових фононах і дефектах.

Другий закон Ньютона для надпровідного електрона масою `m` і зарядом `e` у локальному електричному полі `E` має вигляд:

```
m · (d v_s / d t) = e · E
[другий закон Ньютона для носія без розсіювання]
```

Густина надпровідного струму `j_s` визначається як добуток заряду, густини та середньої швидкості носіїв:

```
j_s = n_s · e · v_s
[визначення густини надструму]
```

Диференціюючи вираз для `j_s` по часу та підставляючи прискорення `d v_s / d t`, отримуємо перше рівняння Лондонів:

```
d j_s / d t = (n_s · e² / m) · E
[перше рівняння Лондонів: зв'язок прискорення струму з полем E]
```

Ввівши фундаментальний параметр з розмірністю довжини `λ_L` (лондонівська глибина проникнення):

```
λ_L = √( m / (μ_0 · n_s · e²) )
[лондонівська глибина проникнення]
```

перше рівняння Лондонів записується у компактній формі:

```
μ_0 · λ_L² · (d j_s / d t) = E
[перше рівняння Лондонів через λ_L]
```

Фізичний зміст першого рівняння: на відміну від звичайного провідника (де закон Ома `j = σ · E` вимагає наявності поля `E` для підтримки постійного струму `j`), у надпровіднику електричне поле `E` потрібне лише для *прискорення* чи змінення струму. Постійний надструм (`d j_s / d t = 0`) тече при строго нульовому полі `E = 0`.

## 2. Друге рівняння Лондонів: Екранування магнітного поля

Для виведення зв'язку надструму з магнітним полем застосуємо операцію ротора (`∇ ×`) до обох частин першого рівняння Лондонів:

```
∇ × (d j_s / d t) = (n_s · e² / m) · (∇ × E)
[ротор від першого рівняння Лондонів]
```

Використаємо закон електромагнітної індукції Фарадея `∇ × E = - ∂ B / ∂ t`:

```
∇ × (d j_s / d t) = - (n_s · e² / m) · (∂ B / ∂ t)
[підстановка закону Фарадея]
```

Виносячи оператор часткової похідної по часу за дужки:

```
∂ / ∂ t [ ∇ × j_s + (n_s · e² / m) · B ] = 0
[часова похідна комбінації дорівнює нулю]
```

Інтегрування по часу дає:

```
∇ × j_s + (n_s · e² / m) · B = C(r)
[інтегрування по часу; C(r) — константа інтегрування]
```

Для гіпотетичного ідеального провідника константа `C(r)` визначалася б початковим магнітним полем до охолодження. Однак експеримент Мейснера — Оксенфельда довів, що в об'ємі надпровідника магнітне поле завжди дорівнює нулю (`B = 0` та `j_s = 0`), незалежно від початкових умов. Тому постулат Лондонів полягає у виборі `C(r) ≡ 0`.

Це дає друге рівняння Лондонів:

```
∇ × j_s = - (n_s · e² / m) · B
[друге рівняння Лондонів: ротор струму відновлює поле B]
```

Або у термінах `λ_L`:

```
μ_0 · λ_L² · (∇ × j_s) = - B
[друге рівняння Лондонів через λ_L]
```

## 3. Енергетика екрануючого надструму та вільна енергія Лондонів

З фундаментальних рівнянь Лондонів випливає, що повна вільна енергія надпровідника `F_L` складається з двох суттєвих внесків: магнітної енергії поля та кінетичної енергії екрануючого надструму:

```
F_L = ∬_V [ B² / (2 · μ_0) + (μ_0 · λ_L² / 2) · j_s² ] dV
[функціонал вільної енергії Лондонів]
```

Використовуючи закон Ампера `j_s = (1 / μ_0) · (∇ × B)` та інтегруючи за частинами у просторі, можна довести, що мінімізація цього функціонала відносно варіацій магнітного поля `δ B` строго приводить до гельмогольцівського рівняння екранування `∇² B = B / λ_L²`.

Повна енергія, яка запасається на одиницю площі поверхні надпровідника у скіни товщиною `λ_L`, становить:

```
U_surf = (λ_L / (2 · μ_0)) · B_ext²
[поверхнева густина енергії екранування]
```

Цей результат показує, що екранування поля вимагає затрати кінетичної енергії надструму, яка прямо пропорційна глибині проникнення `λ_L`.

## 4. Дворідинна модель Гортера — Казимира та температурна залежність `λ_L(T)`

У 1934 році Корнеліс Гортер та Хендрік Казимир запропонували дворідинну модель, згідно з якою при температурах `0 < T < T_c` загальна густина електронів провідності `n` розпадається на дві компоненти:

```
n = n_s(T) + n_n(T)
[баланс нормальної та надпровідної компонент]
```

де `n_s(T)` — густина надпровідної рідини (надструм без опору), а `n_n(T)` — густина нормальної рідини (звичайна провідність із розсіюванням).

З феноменологічного мінімуму вільної енергії Гортер і Казимир вивели закон зміни надпровідної фракції:

```
n_s(T) = n_0 · [ 1 - (T / T_c)⁴ ]
[температурна залежність густини надпровідних електронів]
```

Підставляючи `n_s(T)` у формулу лондонівської глибини проникнення `λ_L`, отримуємо універсальну температурну залежність глибини екранування:

```
λ_L(T) = λ_L(0) / √( 1 - (T / T_c)⁴ )
[температурна залежність лондонівської глибини проникнення]
```

Графічний та фізичний аналіз цього виразу показує:
- При `T → 0 K` значення `λ_L(T)` прямує до свого мінімального значення `λ_L(0)`.
- При наближенні до критичної температури (`T → T_c`) густина надпровідних носіїв прямує до нуля (`n_s → 0`), що спричиняє кореневу розбіжність лондонівської глибини проникнення `λ_L(T) → ∞`. Це означає, що при `T = T_c` екрануючі поверхневі струми більше не здатні виштовхувати поле, і магнітне поле повністю пронизує зразок.

## 5. Виведення диференціального рівняння проникнення поля

Поєднаємо друге рівняння Лондонів із рівнянням Максвелла для ротора магнітного поля (у квазістаціонарному наближенні без струму зсуву):

```
∇ × B = μ_0 · j_s
[закон Ампера — Максвелла]
```

Застосуємо оператор ротора до обох частин закону Ампера:

```
∇ × (∇ × B) = μ_0 · (∇ × j_s)
[ротор від обох частин закону Ампера]
```

Використовуючи векторну тотожність для подвійного ротора `∇ × (∇ × B) = ∇(∇ · B) - ∇² B` та закон відсутності магнітних монополів `∇ · B = 0`:

```
- ∇² B = μ_0 · (∇ × j_s)
[векторна тотожність при ∇ · B = 0]
```

Підставляючи вираз для `∇ × j_s` з другого рівняння Лондонів:

```
- ∇² B = - μ_0 · (n_s · e² / m) · B
[підстановка другого рівняння Лондонів]
```

Отримуємо фундаментальне гельмогольцівське рівняння екранування Лондонів:

```
∇² B = B / λ_L²
[диференціальне рівняння лондонівського екранування]
```

Аналогічне рівняння виконується і для густини надструму:

```
∇² j_s = j_s / λ_L²
[диференціальне рівняння згасання поверхневого струму]
```

## 6. Одновимірні розв'язки: Напівпростір та тонкі плівки

### А. Масивний надпровідник (напівпростір `x ≥ 0`)
Розглянемо плоску межу надпровідника, який займає півпростір `x ≥ 0`. Зовнішнє однорідне магнітне поле `B_ext` спрямоване вздовж осі `z` паралельно поверхні: `B(0) = (0, 0, B_ext)`.

Рівняння екранування в одновимірному випадку набуває вигляду:

```
d² B_z / d x² = B_z / λ_L²
[одновимірне диференціальне рівняння]
```

Загальний розв'язок цього рівняння є лінійною комбінацією двох експонент:

```
B_z(x) = C_1 · exp(-x / λ_L) + C_2 · exp(x / λ_L)
[загальний розв'язок]
```

З фізичної умови скінченності поля у глибині надпровідника (`B_z(x → ∞) = 0`) випливає, що `C_2 = 0`. З граничної умови на поверхні (`B_z(0) = B_ext`) маємо `C_1 = B_ext`.

Отже, розподіл магнітного поля вглиб надпровідника має вигляд:

```
B_z(x) = B_ext · exp(-x / λ_L)
[експоненційне згасання поля B(x)]
```

Густину поверхневого екрануючого струму знайдемо із закону Ампера `j_s = (1 / μ_0) · (∇ × B)`:

```
j_y(x) = - (1 / μ_0) · (d B_z / d x) = (B_ext / (μ_0 · λ_L)) · exp(-x / λ_L)
[розподіл густини екрануючого надструму]
```

### Б. Тонка надпровідна пластина (товщиною `d`)
Розглянемо пластину товщиною `d`, розташовану симетрично між `-d/2 ≤ x ≤ d/2`, в об'ємі якої магнітне поле подається з обох боків: `B(±d/2) = B_ext`.

Розв'язок рівняння `d² B_z / d x² = B_z / λ_L²` з симетричними граничними умовами має вигляд:

```
B_z(x) = B_ext · [ cosh(x / λ_L) / cosh(d / (2·λ_L)) ]
[розподіл магнітного поля у тонкій пластині]
```

У граничному випадку дуже тонкої плівки (`d << λ_L`), розкладаючи гіперболічний косинус в ряд Тейлора (`cosh(u) ≈ 1 + u² / 2`), отримуємо:

```
B_z(0) ≈ B_ext · [ 1 - d² / (8 · λ_L²) ]
[неповне екранування поля в тонкій плівці]
```

Магнітне поле практично повністю пронизує тонку плівку, а екрануючий струм зростає лінійно від нуля в центрі до країв. У 2D плівках товщиною `d` ефективна довжина проникнення поля за межі плівки визначається **довжиною Перла** `Λ = 2 · λ_L² / d >> λ_L`.

## 7. Нелокальна електродинаміка Піппарда

Лондонівська теорія є **локальною**: густина струму у точці `r` визначається значенням вектора-потенціалу `A(r)` у тій самій точці: `j_s(r) = - (1 / (μ_0 · λ_L²)) · A(r)`.

У 1953 році Брайан Піппард з'ясував, що для чистих надпровідників I роду локальна співвідношення дає збій. Причина полягає в тому, що куперівська пара має скінченний розмір — довжину кореляції `ξ_0 ≈ 100–1000 нм`, яка суттєво перевищує лондонівську глибину `λ_L ≈ 30–50 нм`. Оскільки розмір носія перевищує ширину області, в якій змінюється магнітне поле, відгук струму стає **нелокальним**.

Піппард запропонував за аналогією з нелокальною теорією металів Чемберса інтегральне співвідношення:

```
j_s(r) = - (3 / (4π · ξ_0 · μ_0 · λ_L²)) · ∬ [ R · (R · A(r')) / R⁴ ] · exp(-R / ξ) dV'
[нелокальне інтегральне рівняння Піппарда; R = r - r']
```

де ефективна довжина кореляції `ξ` враховує розсіювання на домішках з довжиною вільного пробігу електронів `l`:

```
1 / ξ = 1 / ξ_0 + 1 / (α · l)
[зв'язок довжини кореляції з довжиною вільного пробігу]
```

У границі брудного надпровідника (`l << ξ_0`) нелокальне рівняння Піппарда знову зводиться до локального лондонівського формалізму, але з ефективною глибиною проникнення:

```
λ_eff = λ_L · √( ξ_0 / l )
[збільшення глибини проникнення у брудних надпровідниках]
```

Це пояснює, чому легування металу домішками суттєво збільшує ефективну глибину проникнення магнітного поля `λ`.

## 8. Граничний критичний струм Дворака — Депарування (Pair-breaking Limit)

Максимальна густина струму, яку може транспортувати надпровідник без руйнування надпровідного стану кінетичною енергією носіїв, називається струмом депарування `j_dep`.

Коли кінетична енергія впорядкованого руху куперівської пари дорівнює енергії зв'язку (енергетичній щілині `Δ`), швидкість струму досягає критичного значення `v_c = Δ / p_F`.

З рівнянь Гінзбурга — Ландау маємо розрахунок критичної густини струму депарування:

```
j_dep = (2 / 3^1.5) · (H_c / (μ_0 · λ_L)) = (q* · n_s / m*) · (ℏ / (√3 · ξ))
[теоретична межа струму депарування]
```

При досягненні `j = j_dep` надпровідний конденсат стає кінетично нестійким, і куперівські пари розпадаються на поодинокі електронні збудження.

## 9. Квантування магнітного потоку (флюксоїда) та кінетична індуктивність

За теорією Гінзбурга — Ландау та БКШ, надпровідний конденсат описується макроскопічною хвильовою функцією:

```
Ψ(r) = |Ψ(r)| · exp(i · φ(r))
[макроскопічна хвильова функція конденсату]
```

де `|Ψ(r)|² = n_s / 2` — густина куперівських пар, а `φ(r)` — їхня спільна макроскопічна фаза.

Оператор швидкості надпровідної пари із зарядом `q* = 2e` та масою `m* = 2m` у присутності вектора-потенціалу `A` має вигляд:

```
v_s = (1 / m*) · (ℏ · ∇φ - q* · A)
[швидкість надпровідної пари у магнітному полі]
```

Густина надструму куперівських пар дорівнює:

```
j_s = q* · |Ψ|² · v_s = (n_s · e / m) · (ℏ · ∇φ - 2e · A)
[густина надструму через градієнт фази та вектор-потенціал]
```

Виразимо градієнт фази `∇φ`:

```
∇φ = (2e / ℏ) · A + (m / (n_s · e · ℏ)) · j_s
[градієнт фази хвильової функції]
```

Проінтегруємо цей вираз по замкненому контуру `C`, який проходить всередині надпровідного кільця:

```
∮_C ∇φ · dl = (2e / ℏ) · ∮_C A · dl + (m / (n_s · e · ℏ)) · ∮_C j_s · dl
[циркуляція градієнта фази по контуру]
```

Оскільки хвильова функція `Ψ(r)` є однозначною в кожній точці простору, при обході по замкненому контуру фаза `φ` може змінитися лише на ціле число повних обертів `2π`:

```
∮_C ∇φ · dl = 2π · n,    n ∈ Z
[умова однозначності хвильової функції]
```

Величина у дужках визначає **флюксоїд** `Φ'`:

```
Φ' = ∮_C A · dl + (μ_0 · λ_L²) · ∮_C j_s · dl = n · (h / (2e))
[визначення квантованого флюксоїда]
```

Другий доданок у виразі для флюксоїда описує внесок кінетичної енергії струму і пов'язаний з **кінетичною індуктивністю** `L_k`.

Якщо контур `C` проходить у глибині товстого надпровідного кільця на відстані `r >> λ_L`, то густина струму `j_s` на ньому прямує до нуля (`j_s = 0`). Тоді другий інтеграл зникає.

За теоремою Стокса, циркуляція векторного потенціалу `A` по контуру `C` дорівнює геометричному магнітному потоку `Φ`, що пронизує поверхню `S`, обмежену цим контуром:

```
∮_C A · dl = ∬_S (∇ × A) · dS = ∬_S B · dS = Φ
[теорема Стокса для векторного потенціалу]
```

Звідси отримуємо фундаментальний закон квантування магнітного потоку:

```
Φ = n · (h / (2e)) = n · Φ_0
[дискретні значення магнітного потоку]
```

де `Φ_0` — елементарний квант магнітного потоку:

```
Φ_0 = h / (2e) ≈ 2.067833848 × 10⁻¹⁵ Вб (або Тл·м²)
[значення кванта магнітного потоку]
```

Наявність двійки `2e` у знаменнику кванта потоку `Φ_0` є безпосереднім математичним і експериментальним доказом того, що носіями заряду в надпровіднику є зв'язані пари двох електронів (куперівські пари), а не поодинокі електрони.
