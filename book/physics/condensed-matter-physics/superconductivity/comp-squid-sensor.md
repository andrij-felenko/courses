# 🔌 Надопровідні прилади: Квантовий інтерферометр (SQUID)

Надопровідний квантовий інтерферометр (SQUID, Superconducting Quantum Interference Device) становить узагальнений клас зверхчутливих вимірювальних приладів. Фізична реалізація SQUID поєднує будову надпровідного контуру, квантовомеханічний принцип роботи, схеми зчитування, підсилювальний тракт, аналіз джерел шумів та клас-специфічні особливості застосування.

## 1. Загальний опис та принципи роботи класу

Надопровідний квантовий інтерферометр є найчутливішим відомим датчиком магнітного потоку. Його робота ґрунтується на поєднанні двох макроскопичних квантових явищ: квантування магнітного потоку у надпровідному кільці та квантової інтерференції фаз куперівських пар у джозефсонівських переходах.

Розрізняють два основні фізичні підкласи приладів цього класу:
- **DC SQUID (постійного струму):** складається з надпровідного кільця індуктивністю `L`, розірваного двома паралельними джозефсонівськими переходами (структура S-I-S або мікромістки). Прилад живиться постійним струмом смещения `I_b`.
- **RF SQUID (высокочастотний):** містить надпровідне кільце з одним джозефсонівським переходом, яке індуктивно зв'язане з високочастотним LC-контуром накачки (на частотах 20–100 МГц або ГГц).

### Математична модель макроскопічної інтерференції (DC SQUID)

Нехай через надпровідне кільце індуктивністю `L` проходить зовнішній магнітний потік `Φ`. Повний надструм, що протікає через два паралельні джозефсонівські переходи з однаковими критичними струмами `I_c0`, дорівнює:

```
I = I_c0 · sin(φ_1) + I_c0 · sin(φ_2)
[сума надструмів двох паралельних переходів]
```

де `φ_1` та `φ_2` — різниці фаз хвильової функції на першому та другому переходах відповідно.

З умови однозначності макроскопічної хвильової функції при обході замкненого контуру випливає зв'язок між фазами та магнітним потоком:

```
φ_2 - φ_1 = 2π · (Φ / Φ_0)
[зв'язок різниці фаз із магнітним потоком]
```

Максимальний сумнівний критичний струм `I_c(Φ)`, який може протікати крізь прилад без виникнення падіння напруги, визначається інтерференційною формулою:

```
I_c(Φ) = 2 · I_c0 · |cos(π · Φ / Φ_0)|
[модуляція критичного струму магнітним потоком]
```

Критичний струм є строго періодичною функцією магнітного потоку `Φ` з періодом, що дорівнює одному кванту потоку `Φ_0 = h / (2e) ≈ 2.0678 × 10⁻¹⁵ Вб`.

## 2. Схеми підключення та режим зчитування сигналів

Для перетворення модуляції критичного струму `I_c(Φ)` у вимірювану електричну напругу SQUID задається постійний струм зміщення `I_b`, який перевищує максимальний критичний струм (`I_b > 2 · I_c0`).

У цьому резистивному режимі на приладі виникає падіння напруги `V`, яке періодично залежить від зовнішнього магнітного потоку:

```
V(Φ) = V_0 + ΔV · cos(2π · Φ / Φ_0)
[вихідна напруга DC SQUID у резистивному режимі]
```

Амплітуда модуляції напруги `ΔV` визначається формулою `ΔV ≈ (R_sh / L) · Φ_0` і зазвичай становить від одиниць до десятків мікровольт (`10–50 мкВ`), де `R_sh` — опір нормального шунта джозефсонівського переходу.

```
              +------------------------------------------+
              |           Джерело струму I_b             |
              +--------------------+---------------------+
                                   |
                         +---------+---------+
                         |                   |
                     [Перехід 1]         [Перехід 2]
                     (Джозефсон)         (Джозефсон)
                         |                   |
                         |  <-- Потік Φ -->  |
                         +---------+---------+
                                   |
                                   v
                         Вихідний сигнал V(Φ)
```

### Схема негативного зворотного зв'язку (Flux-Locked Loop, FLL)

Оскільки синусоїдальна залежність `V(Φ)` є нелінійною і має вузький динамічний діапазон (менше півкванта потоку `Φ_0 / 2`), у реальних вимірювальних системах SQUID працює у режимі слідкування (нуль-індикатор) за допомогою негативного зворотного зв'язку за потоком (FLL):

1. На прилад подається високочастотне модуляційне поле з частотою 100–500 кГц та амплітудою `~ Φ_0 / 4`.
2. Сигнал напруги підсилюється малошумним підсилювачем і демонтується синхронним детектором.
3. Вихідний сигнал детектора через резистор зворотного зв'язку подається на інтегратор і далі на компенсаційну котушку, розташовану поруч із кільцем SQUID.
4. Струм зворотного зв'язку створює компенсаційне магнітне поле `B_fb = - B_ext`, яке утримує робочу точку приладу на найкритішому схилі характеристичної кривої (`∂V / ∂Φ = max`).
5. Напруга на виході інтегратора стає строго лінійною функцією зовнішнього магнітного поля з динамічним діапазоном до `10⁶–10⁸ Φ_0`.

### Узгодження імпедансів та підсилювальний тракт

Динамічний опір SQUID у резистивному режимі є дуже малим (`R_d = ∂V / ∂I ≈ 5–20 Ом`). Безпосереднє підключення кімнатного підсилювача напівпровідникового типу призводить до того, що шуми підсилювача (зазвичай `1–2 нВ / √Гц`) повністю маскують корисний сигнал `ΔV`.

Для узгодження низького імпедансу SQUID із малошумним підсилювачем застосовують:
- **Кріогенні резонансні LC-трансформери:** кріогенний трансформатор із коефіцієнтом трансформації `N = 10–30` та підвищенням напруги в `N` разів.
- **Двокаскадні SQUID-підсилювачі (SQUID Series Array):** послідовна решітка із 50–100 надпровідних квантових інтерферометрів, яка збільшує вихідну напругу модуляції до мілівольтних значень (`ΔV_arr ≈ 1–5 мВ`).

## 3. Трансформери магнітного потоку та градієнтометри

Геометричні розміри кільця SQUID роблять навмисно малими (площа `S_sq ≈ 10⁻⁴–10⁻² мм²`), щоб зменшити власну індуктивність `L` і мінімізувати тепловий шум `k_B T / L`. Однако така мала площа призводить до дуже низької чутливості приладу безпосередньо до однорідного магнітного поля.

Для вирішення цієї суперечності застосовують **надпровідні трансформери магнітного потоку**:
- **Приймальна котушка (Pick-up coil):** макроскопічна надпровідна котушка площею `S_p ≈ 1–10 см²`.
- **Вхідна котушка (Input coil):** багатовиткова котушка індуктивністю `L_in`, індуктивно зв'язана з кільцем SQUID.

При зміні зовнішнього поля у замкненому надпровідному контурі трансформера наводиться незагасаючий струм `I_p = Φ_ext / (L_p + L_in)`, який передає потік у кільце SQUID без додання активного шуму.

```
      Приймальна котушка S_p                 Вхідна котушка L_in     Кільце SQUID
      +------------------+                    +---------------+       +-------+
      |                  |                    |               |       |       |
      |   Фоновий потік  |====================|  (Індуктивний)|======>| SQUID |
      |      B_ext       |                    |    зв'язок)   |       |       |
      +------------------+                    +---------------+       +-------+
```

Ефективна чутливість магнітометра за полем визначається формулою:

```
S_B^1/2 = S_Φ^1/2 / [ S_p · L_in / (L_p + L_in) ]
[спектральна чутливість за магнітним полем]
```

Для вимірювання слабких біомагнітних сигналів (наприклад, сигналів мозку `10–100 фТл`) на тлі сильних магнітних завад Землі та промислової мережі (`50 мкТл`) приймальні котушки виконують у формі **осьових або планарних градієнтометрів**:
- **Градієнтометр першого порядку:** складається з двох однакових котушок, намотаних у протилежних напрямках. Він не реагує на однорідне поле (`∂B / ∂z = 0`), а вимірює лише його першу просторову похідну.
- **Градієнтометр другого порядку:** містить три котушки зі співвідношенням витків `1 : -2 : 1`, що компенсує як однорідне поле, так і його лінійний градієнт.

## 4. Аналіз шумів та практичні обмеження

Спектральна густина шуму потоку `S_Φ(f)` приладу SQUID визначається двома основними складовими:

1. **Тепловий шум (білий шум):** виникає через флуктуації напруги в шунтуючих резисторах `R_sh` джозефсонівських переходів. Мінімальний рівень білого шуму оцінюється співвідношенням:

```
S_Φ^1/2 ≈ √( 16 · k_B · T · L² / R_sh )
[спектральна густина білого шуму потоку]
```

Для ніобієвих SQUID при `T = 4.2 K` це дає рекордну чутливість `S_Φ^1/2 ≈ 10⁻⁶ Φ_0 / √Гц`, що відповідає роздільній здатності за магнітним полем `1–5 фТл / √Гц`.

2. **Фліккер-шум `1/f`:** домінує на низьких частотах (`f < 1–10 Гц`). Він виникає через два незалежні джерела:
   - Флуктуації критичного струму `I_c` у тунельному бар'єрі.
   - Термофлуктуаційне стрибання захоплених вихорів Абрикосова (Vortex Hopping) у товщині надпровідних плівок.

> 🔧 **Навіщо це у розробці.**
> SQUID є єдиним приладом, здатним реєструвати надзвичайно слабкі магнітні поля людського мозку (магнітоенцефалографія, `10–100 фТл`), серця (магнітокардіографія, `1–10 пТл`), а також застосовується як квантовий підсилювач для читання надпровідних кубітів та у геофізичній розвідці корисних копалин.

### Класові пастки та інженерні обмеження

При проектуванні та експлуатації SQUID-систем слід враховувати наступні критичні фактори:

1. **Вразливість до зовнішніх електромагнітних завад (EMI):** Прилад є надчутливим до будь-яких високочастотних наводок. Для ізоляції від радіочастотного шуму SQUID розміщують у багатошарових екранах із пермалою (Mu-Metal) та надпровідних свинцевих чи ніобієвих екранах.
2. **Захоплення паразитного магнітного потоку:** При переході крізь `T_c` у зовнішньому полі вихори Абрикосова можуть захоплюватися у товщині надпровідних плівок, створюючи низькочастотний фліккер-шум. Для запобігання цього застосовують процедуру термічного розмагнічування та перфорацію плівок гетерними пастками вихорів.
3. **Параметри шунтування:** Для усунення гістерезису на ВАХ джозефсонівські переходи шунтують резисторами з номіналом `R_sh = 1–5 Ом`. Параметр макроскопічного гістерезису Маккамбера — Стюарта `β_c = (2π / Φ_0) · I_c · R_sh² · C_j` вибирають близьким до одиниці (`β_c ≤ 1`).
