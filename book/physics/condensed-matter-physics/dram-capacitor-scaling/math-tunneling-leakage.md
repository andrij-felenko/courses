# 🧮 Математичне виведення еквівалентної товщини оксиду та струмів тунельного витоку

Для кількісного фізичного аналізу, теоретичного розрахунку та чисельного моделювання електрофізичних характеристик нанорозмірних конденсаторів DRAM застосовується математичний апарат електростатики неоднорідних діелектричних середовищ та квантової механіки потенціальних бар'єрів.

Нижче наведено послідовне виведення рівнянь електроємності, еквівалентної товщини оксиду (*EOT*), поправки на екранування в металевих електродах Томаса — Фермі, а також математичних моделей трьох основних механізмів тунельного витоку заряду.

---

### 1. Розрахунок ємності та еквівалентної товщини оксиду (EOT)

Електроємність плоского конденсатора з геометричною площею пластин `A`, фізичною товщиною діелектричного шару `d_phys` та відносною діелектричною проникністю `k` задається класичним співвідношенням електростатики:

```
C = (ε₀ · k · A) / d_phys
```

де `ε₀ ≈ 8.854188 · 10⁻¹² Ф/м` — електрична стала у вакуумі.

Для зручного порівняння різноманітних High-k діелектричних матеріалів із еталонним діоксидом кремнію (`SiO₂`, діелектрична проникність якого становить `k_SiO₂ = 3.9`) у мікроелектроніці введено фундаментальний параметр — **еквівалентна товщина оксиду** (*Equivalent Oxide Thickness*, `EOT`). Вона визначає товщину такого уявного шару `SiO₂`, який забезпечує точно таку ж електроємність на одиницю площі, що й реальний High-k діелектрик товщиною `d_phys`:

```
C / A = (ε₀ · k_SiO₂) / EOT = (ε₀ · k_high_k) / d_phys
```

Прирівнюючи ліві та праві частини виразу і скорочуючи електричну сталу `ε₀`, отримуємо остаточне рівняння для обчислення EOT:

```
EOT = d_phys · (k_SiO₂ / k_high_k) = d_phys · (3.9 / k_high_k)      [визначення EOT]
```

#### Багатошарові гетероструктури та ZAZ-наноламінати

У разі двошарової або багатошарової діелектричної структури (наприклад, ZAZ-наноламінату `ZrO₂ / Al₂O₃ / ZrO₂`) загальна ємність являє собою послідовне з'єднання окремих шарів:

```
1 / C_total = 1 / C_1 + 1 / C_2 + ... + 1 / C_n
```

Підставляючи вираз для кожної ємності `C_i = (ε₀ · k_i · A) / d_i`, отримуємо загальну формулу для сумарної значення EOT багатошарової системи:

```
EOT_total = ∑ [ d_i · (k_SiO₂ / k_i) ]
```

Для тришарової структури ZAZ (`ZrO₂` товщиною `d_ZrO2`, `Al₂O₃` товщиною `d_Al2O3`) підсумкове значення обчислюється як:

```
EOT_ZAZ = 2 · d_ZrO2 · (3.9 / k_ZrO2) + d_Al2O3 · (3.9 / k_Al2O3)      [сумування шарів ZAZ]
```

#### Перехід до циліндричної геометрії 3D-стовпчика

У сучасних конденсаторах DRAM верхній і нижній електроди формують циліндричну співвісну структуру. Для співвісного циліндричного конденсатора з внутрішнім радіусом `R_in`, зовнішнім радіусом `R_out = R_in + d_phys` та висотою `h` точний розв'язок рівняння Лапласа `∇² Φ = 0` у циліндричних координатах дає формулу ємності:

```
C_cyl = (2 · π · ε₀ · k_high_k · h) / ln(R_out / R_in) = (2 · π · ε₀ · k_high_k · h) / ln(1 + d_phys / R_in)
```

За умови, коли товщина діелектрика є значно меншою за радіус стовпчика (`d_phys << R_in`), ми можемо скористатися розкладом логарифма в ряд Тейлора `ln(1 + x) ≈ x - x²/2 + ...`:

```
ln(1 + d_phys / R_in) ≈ d_phys / R_in
```

Підставляючи це наближення назад у формулу циліндричної ємності, отримуємо:

```
C_cyl ≈ (2 · π · R_in · h · ε₀ · k_high_k) / d_phys = (ε₀ · k_high_k · A_side) / d_phys
```

це свідчить про те, що для ультратонких High-k шарів плоске наближення є високоточним інженерним допуском.

### 2. Екранування Томаса — Фермі в металевих електродах та ефекти межі розділу

У реальній MIM-структурі (*Metal-Insulator-Metal*) електроди не є ідеальними провідниками з нескінченною концентрацією носіїв. При прикладанні напруги електричне поле проникає всередину металевого електрода (наприклад, `TiN` або `Ru`) на скінченну глибину **довжини екранування Томаса — Фермі** `λ_TF`:

```
λ_TF = √[ (2 · ε_metal · E_F) / (3 · q² · n₀) ]
```

де `E_F` — енергія Фермі металу, `n₀` — об'ємна концентрація вільних електронів у металі. Для нітриду титану `TiN` значення `λ_TF ≈ 0.05–0.1 нм`.

Проникання поля створює біля обох металевих електродів два поверхневі збіднені шари з ємністю `C_int = (ε₀ · k_metal · A) / λ_TF`. В результаті ефективна товщина конденсатора `t_eff` зростає:

```
1 / C_total = 1 / C_high_k + 2 / C_int
t_eff = EOT + 2 · λ_TF · (k_SiO₂ / k_metal)      [поправка на екранування металу]
```

Ця поправка показує, чому вибір матеріалу металевого електрода з високою густиною станів на рівні Фермі є таким же важливим, як і вибір самого High-k діелектрика.

### 3. Математичні моделі квантових струмів тунельного витоку

При зменшенні фізичної товщини діелектрика `d_phys < 4 нм` основними каналами розряду конденсатора стають квантово-механічне тунелювання та термопольова іонізація.

#### А. Пряме квантове тунелювання (Direct Tunneling, DT)

Виникає при відносно низьких напругах (`V_DD < 1.0 В`), коли електрон тунелює крізь всю прямокутну або трапецієподібну товщину потенціального бар'єра заввишки `Φ_B` (висота бар'єра Шотткі `ΔE_c`).

У квазікласичному наближенні ВЕНК (Вентцеля — Крамерса — Бріллюена) коефіцієнт прозорості бар'єра `D(E)` для електрона з енергією `E` обчислюється через інтеграл хвильового вектора:

```
D(E) = exp( - 2 · ∫ [ √(2 · m* · (V(x) - E)) / ℏ ] dx )
```

Для прямокутного бар'єра товщиною `d_phys` та постійною висотою `V(x) = q · Φ_B` вираз спрощується до:

```
D_DT ≈ exp( - (4 · π · d_phys / h_planck) · √(2 · m* · q · Φ_B) )
```

Інтегрування потоку електронів за всіма можливими енергіями дає підсумкову густину струму прямого тунелювання `J_DT`:

```
J_DT = (q² · V / (h_planck² · d_phys)) · √(2 · m* · q · Φ_B) · exp( - (4 · π · d_phys / h_planck) · √(2 · m* · q · Φ_B) )
```

де `m*` — ефективна маса електрона в діелектрику (для `ZrO₂` значення `m* ≈ 0.25–0.3 · m_0`), `h_planck ≈ 6.626070 · 10⁻³⁴ Дж·с` — стала Планка.

З аналізу формули видно, що густина струму `J_DT` залежить **експоненціально стрімко** від товщини діелектрика `d_phys` та квадратного кореня з висоти бар'єра `√Φ_B`. Зменшення товщини всього на `0.5 нм` збільшує струм тунельного витоку майже на 2 порядки.

#### Б. Тунелювання Фаулера — Нордгейма (Fowler–Nordheim Tunneling, FN)

Виникає при високих електричних полях (`E = V / d_phys > 3–5 МВ/см`), коли сильний нахил зони провідності перетворює прямокутний бар'єр на трикутний. Електрон тунелює не крізь усьому товщину `d_phys`, а лише крізь частину трикутного профілю завдовжки `x_tunnel = Φ_B / E`.

Рівняння густини струму Фаулера — Нордгейма має вигляд:

```
J_FN = A_FN · E² · exp( - B_FN / E )      [рівняння Фаулера — Нордгейма]
```

де електрофізичні коефіцієнти `A_FN` та `B_FN` визначаються параметрами матеріалу:

```
A_FN = q³ / (8 · π · h_planck · q · Φ_B)      [перша стала FN]
B_FN = (8 · π · √(2 · m*) · (q · Φ_B)^(3/2)) / (3 · q · h_planck)      [друга стала FN]
```

Побудова експериментальних характеристик витоку в спеціальних координатних вісях `ln(J / E²)` як функції від `1 / E` (так званий **графік Фаулера — Нордгейма**) утворює пряму лінію. Кутовий нахил цієї прямої дорівнює коефіцієнту `- B_FN`, що слугує точним методом експериментального визначення ефективної маси `m*` та висоти бар'єра Шотткі `Φ_B` на межі розділу метал-діелектрик.

#### В. Об'ємно-обмежена емісія Пула — Френкеля (Poole–Frenkel Emission, PF)

У polycrystalline або аморфних High-k оксидах (`ZrO₂`, `TiO₂`, `Ta₂O₅`) основними носіями струму витоку є електрони, захоплені дефектами кристалічної ґратки (кисневими вакансіями або міжвузольними атомами).

Потенціал сферично симетричної кулонівської пастки для електрона має вигляд `V(r) = - q / (4 · π · ε₀ · k_opt · r)`. При накладанні зовнішнього електричного поля `E` кулонівська потенціальна яма викривляється, і її висота з одного боку знижується на величину `ΔΦ_PF`:

```
V_total(r) = - (q / (4 · π · ε₀ · k_opt · r)) - E · r
```

Знаходячи екстремум цієї функції `d V_total / dr = 0`, отримуємо точку максимуму `r_max = √( q / (4 · π · ε₀ · k_opt · E) )`. Підстановка `r_max` назад у потенціал дає величину зниження потенціального бар'єра Пула — Френкеля:

```
ΔΦ_PF = β_PF · √E = √( (q³ · E) / (π · ε₀ · k_opt) )      [зниження бар'єра Пула — Френкеля]
```

де `k_opt = n²` — оптична діелектрична проникність (квадрат показника заломлення світла в діелектрику, для `ZrO₂` значення `n ≈ 2.1–2.2`, отже `k_opt ≈ 4.5–4.8`).

Густина струму термопольової іонізації пасток Пула — Френкеля задається фундаментальним рівнянням:

```
J_PF = C_PF · E · exp( - (q · Φ_T - q · √( (q · E) / (π · ε₀ · k_opt) )) / (k_B · T) )
```

де `Φ_T` — енергетична глибина залягання дефекту щодо дна зони провідності `E_c` (у вольтах), `k_B ≈ 1.380649 · 10⁻²³ Дж/К` — стала Больцмана, `T` — абсолютна температура в кельвінах, `C_PF` — константа провідності середовища.

На відміну від квантового тунелювання, струм Пула — Френкеля **сильно залежить від температури**: зростання температури від `25 °C` (298 К) до `85 °C` (358 К) підвищує експоненційний множник і збільшує виток пам'яті в десятки разів.

### 4. Фундаментальне емпіричне закономірне співвідношення `k` та `E_g`

У фізиці конденсованого стану існує фундаментальне емпіричне співвідношення між відносною діелектричною проникністю матеріалу `k` та шириною його забороненої зони `E_g` (*bandgap*):

```
E_g ≈ 20 · (3.9 / k)^(2/3)   [електронвольт]
```

Графічний та математичний аналіз цього рівняння демонструє зворотну пропорційність:

```
k ↑  ==>  E_g ↓  ==>  Φ_B (ΔE_c) ↓  ==>  J_PF, J_DT ↑↑
```

Практичний висновок цього співвідношення полягає у наступному: спроба використати матеріал із надвисоким `k` (наприклад, `TiO₂` з `k ≈ 80`) приводить до звуження забороненої зони до `E_g ≈ 3.2 еВ` та зниження бар'єра Шотткі до `ΔE_c ≈ 0.8 еВ`. Це викликає катастрофічне експоненціальне зростання струмів витоку Пула — Френкеля та Шотткі, унеможливлюючи утримання заряду в конденсаторі. Саме ця математична закономерність змусила інженерів перейти до створення складних гетероструктурних наноламінатів ZAZ (`ZrO₂ / Al₂O₃ / ZrO₂`).
