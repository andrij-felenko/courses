# 🧮 Математична теорія методу Ван дер Пау та 4-зондових поправок

У цій математичній вставці виведено фундаментальне рівняння Ван дер Пау для зразків довільної форми на основі конформних відображень, а також розраховано геометричні поправочні коефіцієнти для 4-зондових вимірювань у обмежених об'ємах.

Вона призначена для поглибленого фізико-математичного розуміння квазіпотенціальних полів у тонкоплівкових та об'ємних провідних середовищах.

## 1. Потенціал точкового джерела струму та колонеарні 4-зондові формули

Розглянемо ізотропне однорідне середовище з питомим опором `ρ`. При інжекції стаціонарного струму `I` через точковий контакт на поверхні напівбезмежного 3D-тіла струм радіально розтікається по півсферичних поверхнях радіуса `r`. Густина струму `j(r)` на відстані `r` дорівнює:

```
j(r) = I / (2 · π · r²)
```

За законом Ома у диференціальній формі, напруженість електричного поля `E(r)` дорівнює:

```
E(r) = ρ · j(r) = (I · ρ) / (2 · π · r²)
```

Оскільки електричне поле є потенціальним (`E = -dV/dr`), інтегрування по радіальній координаті від `r` до нескінченності дає вираз для електричного потенціалу точкового джерела на поверхні 3D-півпростору:

```
V(r) = ∫_r^∞ E(r') dr' = (I · ρ) / (2 · π · r)      [для 3D напівбезмежного середовища]
```

Для колонеарної чотиризондової головки з однаковим кроком між зондами `s` струм `I` вводиться через зонд 1 і виводиться через зонд 4. Потенціали у точках розташування внутрішніх зондів 2 та 3 визначаються прямою суперпозицією полів від двох точкових джерел протилежного знака (+I у точці 1 та -I у точці 4):

```
V₂ = (I · ρ / (2 · π)) · (1/s - 1/(2s)) = (I · ρ) / (4 · π · s)
V₃ = (I · ρ / (2 · π)) · (1/(2s) - 1/s) = -(I · ρ) / (4 · π · s)
```

Різниця потенціалів `ΔV = V₂ - V₃` між внутрішніми вимірювальними зондами дорівнює:

```
ΔV = V₂ - V₃ = (I · ρ) / (2 · π · s)
ρ = 2 · π · s · (ΔV / I)
```

Якщо ж зразок являє собою тонку плівку товщиною `d ≪ s`, товщинне обмеження блокує вертикальний рух струму. Струм розтікається не по півсферах, а по циліндричних поверхнях площею `2 · π · r · d`. Густина струму на відстані `r` дорівнює:

```
j(r) = I / (2 · π · r · d)
```

Інтегрування напруженості поля `E(r) = ρ · j(r) = -dV/dr` дає логарифмічний розподіл потенціалу у 2D-середовищі:

```
V(r) = -(I · ρ / (2 · π · d)) · ln(r) + C
```

Розрахунок потенціалів у точках 2 та 3 від струмових зондів 1 та 4:

```
V₂ = -(I · ρ / (2 · π · d)) · [ln(s) - ln(2s)] = (I · ρ / (2 · π · d)) · ln(2)
V₃ = -(I · ρ / (2 · π · d)) · [ln(2s) - ln(s)] = -(I · ρ / (2 · π · d)) · ln(2)
```

Відповідно, різниця потенціалів `ΔV = V₂ - V₃` дорівнює:

```
ΔV = (I · ρ / (π · d)) · ln(2)     [для тонкої плівки d ≪ s]
```

Виражаючи поверхневий опір `R_s = ρ / d`, отримуємо фундаментальне співвідношення для нескінченної тонкої плівки:

```
R_s = (π / ln 2) · (ΔV / I) ≈ 4.53236014 · (ΔV / I)
```

## 2. Математичне виведення теореми Ван дер Пау

Розглянемо просто зв'язану тонку плівку довільної двовимірної форми сталої товщини `d` з чотирма точковими контактами A, B, C, D на периметрі. За теоремою Рімана про конформні відображення, будь-яку просто зв'язану область у 2D-площині `z = x + i·y` можна конформно відобразити на верхню півплощину `w = u + i·v` за допомогою аналітичної функції `w = f(z)`.

При конформному відображенні:
1. Двовимірний поверхневий опір `R_s` зберігається в усіх точках (є інваріантом конформних перетворень двовимірного потенціального поля).
2. Образи точкових контактів A, B, C, D на дійсій осі `u` позначаються відповідно як координати `u_A < u_B < u_C < u_D`.

Розподіл потенціалу у верхній півплощині `w` від інжекції струму `I` у точках `u_A` та `u_B` задовольняє функціоналу Гріна. Завдяки інваріантності комплексної координатної сітки, ангармонічне співвідношення (двійкове відношення чотирьох точок) на дійсій осі визначається через криволінійні опори `R_A` та `R_B`:

```
(u_A - u_B) · (u_C - u_D) / ((u_A - u_C) · (u_B - u_D)) = exp(-π · d / ρ · R_A) = exp(-π · R_A / R_s)
```

Аналогічно для другої конфігурації вимірювання `R_B`:

```
(u_B - u_C) · (u_A - u_D) / ((u_A - u_C) · (u_B - u_D)) = exp(-π · R_B / R_s)
```

Додаючи два дрібно-лінійних вирази у лівих частинах, легко переконатися, що їхня сума тотожно дорівнює одиниці для будь-яких дійсних координат `u_A < u_B < u_C < u_D`:

```
(u_A - u_B)·(u_C - u_D) + (u_B - u_C)·(u_A - u_D)
= u_A·u_C - u_A·u_D - u_B·u_C + u_B·u_D + u_B·u_A - u_B·u_D - u_C·u_A + u_C·u_D      [розкриття дужок у лівій частині]
= u_A·u_C - u_A·u_D - u_B·u_C + u_C·u_D                                              [взаємне скорочення u_B·u_D та u_A·u_B]
= (u_A - u_C) · (u_B - u_D)                                                          [групування добутків різниць]
```

Ділення суми на знаменник `(u_A - u_C) · (u_B - u_D)` дає тотожну одиницю, звідки випливає універсальне **теоретичне рівняння Ван дер Пау**:

```
exp(-π · R_A / R_s) + exp(-π · R_B / R_s) = 1
```

### Чисельні методи розв meння для асиметричних геометрій
Якщо зразок має несиметричну форму або контакти розташовані нерівномірно, виміряні опори відрізняються (`R_A ≠ R_B`). Тоді рівняння Ван дер Пау розв'язується через поправочний множник асиметрії `f(R_A / R_B)`:

```
R_s = (π / ln 2) · ((R_A + R_B) / 2) · f
```

Де множник `f` задовольняє строгому співвідношенню:

```
cosh( (ln 2 / f) · ( (R_A/R_B - 1) / (R_A/R_B + 1) ) ) = (1/2) · exp(ln 2 / f)
```

Для аналітичної оцінки при незначній асиметрії (`R_A / R_B ≈ 1`) застосовують розклад Тейлора:

```
f ≈ 1 - (ln 2 / 2) · [ (R_A - R_B) / (R_A + R_B) ]² - ( (ln 2)² / 6 - (ln 2)³ / 24 ) · [ (R_A - R_B) / (R_A + R_B) ]⁴
```

Якщо відношення `R_A / R_B = 1.5`, значення `f ≈ 0.965`; якщо `R_A / R_B = 2.0`, значення `f ≈ 0.903`.

## 3. Геометричні поправочні коефіцієнти для 4-зондових вимірювань

На практиці зразки тонких плівок мають обмежені розміри (ширину `W` та довжину `L`), а також скінченну товщину `d`. Реальний поверхневий опір розраховується з урахуванням тривимірних і крайових поправок:

```
R_s = (V / I) · C_thick · C_boundary · C_size
```

### 1. Поправка на товщину плівки `C_thick`
Якщо товщина плівки `d` становить помітну частку відстані між зондами `s` (`d > 0.5 s`), струм починає тривимірно відхилятися у глибину. Використовуючи метод дзеркальних відображень від ізолюючої нижньої межі підкладки, поправка на товщину має вигляд:

```
C_thick = (π · d / s) / [ ln( sinh(d/s) / sinh(d/(2s)) ) ]
```

Для тонких плівок (`d / s → 0`) границя `C_thick → π / ln(2) ≈ 4.5324`.

### 2. Поправка на край ізолюючого зразка `C_boundary`
Якщо колонеарний 4-зондовий датчик розташований на відстані `x` від ізолюючого краю плівки (паралельно межі), струм не може розтікатися за межу. Метод дзеркальних відображень дає додатковий дзеркальний струмовий центр, що зміщує потенціал:

```
C_boundary = (π / ln 2) / [ 1 + (1 / ln 2) · ln( ( (2x/s)² + 1 ) / ( (2x/s)² + 4 ) ) ]
```

При наближенні зондів безпосередньо до ізолюючого краю (`x / s → 0`), опір подвоюється (`C_boundary → 2 · (π / ln 2)`), оскільки півпростір розтікання струму скорочується вдвічі.

### 3. Поправка на скінченні розміри контактів у методі Ван дер Пау
Для методу Ван дер Пау реальні контакти завжди мають скінченний розмір `d_c`. Внесок скінченного розміру контактів призводить до систематичного заниження виміряного опору. Оснащена поправка першого порядку для круглого зразка радіуса `D/2` з чотирма однаковими контактами розміром `d_c` на периметрі виражається формулою:

```
ΔR_s / R_s ≈ - (d_c / D)² / (4 · ln 2)
```

Для досягнення похибки менше `0.1%` розмір контактів не повинен перевищувати `d_c < 0.05 · D`.

## 4. Математична теорія ефекту Холла у геометрії Ван дер Пау

При накладанні зовнішнього магнітного поля з індукцією `B`, спрямованого перпендикулярно площині плівки (вздовж осі `z`), тензор поверхневої провідності набуває недіагональних компонент:

```
σ = [ σ_xx   σ_xy ]
    [ -σ_xy  σ_xx ]
```

де `σ_xy = σ_xx · μ_H · B` (тут `μ_H` — холлівська рухливість носіїв).

Підстановка недіагонального тензора провідності у рівняння Пуассона для комплексного потенціалу показує, що магнітне поле створює додатковий діагональний потенціальний зсув між протилежними контактами. При зміні напрямку магнітного поля на протилежне (`+B → -B`) омічні компоненти напруги не змінюють знак, тоді як холлівська напруга змінює знак на протилежний.

Виміряна напруга Холла `V_H` визначається як напіврізниця напруг при протилежних напрямках магнітного поля:

```
V_H = [ V_BD(+B) - V_BD(-B) ] / 2
```

Поверхневий коефіцієнт Холла `R_Hs` обчислюється як:

```
R_Hs = V_H / (I_AC · B)
```

Об'ємний коефіцієнт Холла `R_H = R_Hs · d` дозволяє безпосередньо обчислити концентрацію вільних носіїв заряду `n = 1 / (q · R_H)` та їхню холлівську рухливість `μ_H = R_H / ρ = R_Hs / R_s`.
