# 🧮 Термодинаміка точкових дефектів та пружна енергія дислокацій

Математична фізика дефектів спирається на два фундаментальні апарати: варіювання вільної енергії для термодинамічно рівноважних 0D-дефектів та лінійну теорію пружності суцільних середовищ для 1D, 2D та 3D-дефектів. Нижче наведено розгорнуті математичні виводи для рівноважної концентрації вакансій та пар Френкеля, термодинаміки іонних дефектів Шотткі, пружного поля напружень та енергії ґвинтових і крайових дислокацій, рівняння Ріда-Шоклі для енергії меж зерен, а також сили взаємодії Піча-Келера та механічного критичного напруження джерела Франка-Роада.

## 1. Рівноважна концентрація вакансій у моноатомному кристалі

Розглянемо кристалічну ґратку, яка містить `N` атомних вузлів. Нехай за температури `T` унаслідок теплового руху виникло `n` поодиноких вакансій (дефекти Шотткі), причому `n ≪ N`.

Утворення кожної вакансії вимагає витрати енергії `E_v` (енергія утворення вакансії), яка витрачається на розрив атомних зв'язків та релаксацію оточуючої ґратки. Повна зміна внутрішньої енергії кристала становить:

```
ΔU = n · E_v
```

Одночасно утворення вакансій змінює ентропію системи `ΔS`. Ентропія складається з двох компонентів: вібраційної ентропії `ΔS_vib` (зміна частот коливань сусідніх з вакансією атомів) та конфігураційної ентропії `S_conf`, яка описує кількість можливих способів розміщення `n` однаковісіньких вакансій по `N + n` вузлах кристала.

Число мікростанів `W` (перестановок) визначається комбінаторною формулою:

```
W = (N + n)! / [ n! · N! ]
```

За формулою Больцмана конфігураційна ентропія дорівнює:

```
S_conf = k_B · ln(W)
       = k_B · [ ln((N + n)!) - ln(n!) - ln(N!) ]      [формула Больцмана для ентропії]
```

Для великих чисел `N` та `n` застосуємо формулу Стірлінга `ln(x!) ≈ x · ln(x) - x`:

```
ln((N + n)!) ≈ (N + n) · ln(N + n) - (N + n)
ln(n!)       ≈ n · ln(n) - n
ln(N!)       ≈ N · ln(N) - N
```

Підставляючи наближення Стірлінга у вираз для ентропії, отримуємо:

```
S_conf
= k_B · [ (N + n)·ln(N + n) - (N + n) - n·ln(n) + n - N·ln(N) + N ]
= k_B · [ (N + n)·ln(N + n) - n·ln(n) - N·ln(N) ]      [скорочення лінійних членів]
```

Зміна вільної енергії Гіббса кристала `ΔF = ΔU - T·ΔS` має вигляд:

```
ΔF(n) = n · E_v - n · T · ΔS_vib - k_B · T · [ (N + n)·ln(N + n) - n·ln(n) - N·ln(N) ]
```

У стані термодинамічної рівноваги за постійних температури й об'єму вільна енергія мінімальна. Продиференціюємо `ΔF(n)` по `n` і прирівняємо похідну до нуля:

```
d(ΔF)/dn
= E_v - T · ΔS_vib - k_B · T · [ ln(N + n) + (N + n)/(N + n) - ln(n) - n/n ]
= E_v - T · ΔS_vib - k_B · T · [ ln(N + n) - ln(n) ]      [скорочення +1 та -1]
= E_v - T · ΔS_vib - k_B · T · ln( (N + n) / n )
= 0                                                        [умова мінімуму вільної енергії]
```

Виражаємо логарифм відношення вузлів до вакансій:

```
ln( (N + n) / n ) = (E_v - T · ΔS_vib) / (k_B · T)
```

Потенціюємо обидві частини рівняння:

```
(N + n) / n = exp( (E_v - T · ΔS_vib) / (k_B · T) )
```

Оскільки при реальних температурах кількість вакансій набагато менша за кількість вузлів (`n ≪ N`), то `(N + n) / n ≈ N / n`. Звідси отримуємо остаточну формулу рівноважної відносної концентрації вакансій `c_v`:

```
c_v = n / N
    = exp( ΔS_vib / k_B ) · exp( -E_v / (k_B · T) )
    = A_v · exp( -E_v / (k_B · T) )                        [де A_v ≈ 1..10 — предекспоненційний множник]
```

Температурна залежність самодифузії атомів за вакансійним механізмом визначається сумою енергії утворення `E_v` та енергії міграції `E_m` вакансії:

```
D = D_0 · exp( -(E_v + E_m) / (k_B · T) )                 [коефіцієнт вакансійної самодифузії]
```

## 2. Рівноважна концентрація пар Френкеля

У разі утворення пар Френкеля атом залишає вузол ґратки і переходить у міжвузол. Нехай `N` — кількість вузлів ґратки, а `N_i` — кількість можливих міжвузлових позицій у кристалі. Позначимо через `n_f` кількість утворених пар Френкеля.

Кількість способів розмістити `n_f` вакансій по `N` вузлах та `n_f` міжвузлових атомів по `N_i` міжвузлях дорівнює добутку відповідних комбінаторних множників:

```
W_f = [ N! / ( (N - n_f)! · n_f! ) ] · [ N_i! / ( (N_i - n_f)! · n_f! ) ]
```

Логарифмуючи `W_f` і застосовуючи наближення Стірлінга `ln(x!) ≈ x·ln(x) - x` за умови `n_f ≪ N` та `n_f ≪ N_i`, маємо для конфігураційної ентропії:

```
S_f = k_B · [ N·ln(N/(N - n_f)) + n_f·ln((N - n_f)/n_f) + N_i·ln(N_i/(N_i - n_f)) + n_f·ln((N_i - n_f)/n_f) ]
```

Мінімізація вільної енергії `ΔF_f = n_f · E_f - T · S_f = 0` по `n_f` дає:

```
d(ΔF_f)/dn_f = E_f - k_B · T · ln( (N - n_f)·(N_i - n_f) / n_f² ) = 0
```

Враховуючи `n_f ≪ N` та `n_f ≪ N_i`, спрощуємо підлогарифмічний вираз `(N · N_i) / n_f²`:

```
ln( (N · N_i) / n_f² ) = E_f / (k_B · T)
```

Звідси знаходимо рівноважну кількість пар Френкеля `n_f`:

```
n_f = √(N · N_i) · exp( -E_f / (2 · k_B · T) )             [концентрація пар Френкеля]
```

Знаменник `2 · k_B · T` в експоненті виникає тому, що один акт теплової активації з енергією `E_f` утворює одразу два дефекти — вакансію та міжвузловий атом.

## 3. Пружне поле та енергія ґвинтової дислокації

Розглянемо ґвинтову дислокацію в ізотропному суцільному середовищі з модулем зсуву `G`. Нехай лінія дислокації збігається з віссю `Z`, а вектор Бюргерса напрямлений уздовж осьового вектора `b = (0, 0, b)`.

Завдяки осьовій симетрії ґвинтової дислокації єдиною відмінною від нуля компонентою зміщення є осьове зміщення `u_z`, яке лінійно зростає від `0` до `b` при повному обході навколо лінії дефекту на кут `2π`:

```
u_z(θ) = b · θ / (2π) = (b / 2π) · arctan(y / x)
```

Обчислюємо компоненти деформації зсуву в циліндричних координатах `(r, θ, z)`:

```
γ_θz = (1 / r) · ∂u_z/∂θ
     = (1 / r) · (b / 2π)
     = b / (2π · r)                                        [компонента деформації зсуву]
```

За законом Гука для ізотропного тіла відповідне зсувне напруження дорівнює:

```
τ_θz = G · γ_θz
     = G · b / (2π · r)                                    [зсувне напруження ґвинтової дислокації]
```

Усі інші компоненти напружень (`σ_rr`, `σ_θθ`, `σ_zz`, `τ_rθ`, `τ_rz`) дорівнюють нулю.

Густина пружної енергії деформації `w(r)` в об'ємі кристала становить:

```
w(r) = (1 / 2) · τ_θz · γ_θz
     = (1 / 2) · G · [ b / (2π · r) ]²
     = G · b² / (8π² · r²)                                 [густина пружної енергії]
```

Повна пружна енергія дислокації на одиницю її довжини `E_screw` обчислюється інтегруванням густини енергії по циліндричному шару від радіуса ядра дислокації `r_0 ≈ b` до зовнішнього радіуса кристала `R`:

```
E_screw
= ∫[r_0..R] w(r) · 2π · r · dr
= ∫[r_0..R] [ G · b² / (8π² · r²) ] · 2π · r · dr
= (G · b² / 4π) · ∫[r_0..R] (1 / r) · dr
= (G · b² / 4π) · [ ln(r) ]_[r_0..R]
= (G · b² / 4π) · ln(R / r_0)                              [пружна енергія ґвинтової дислокації]
```

Додаючи енергію ядра дислокації `E_core ≈ G · b² / 10`, повна енергія лінійного дефекту набуває вигляду:

```
E_total_screw = (G · b² / 4π) · [ ln(R / r_0) + 1 ]
```

## 4. Пружна енергія крайової дислокації

Для крайової дислокації з вектором Бюргерса `b = (b, 0, 0)` та лінією дислокації вздовж оси `Z` полем напружень є двовимірний стан деформації. Крім зсувних напружень виникають нормальні напруження стиску над площиною ковзання та розтягу під нею:

```
σ_xx = -D_e · y · (3x² + y²) / (x² + y²)²
σ_yy =  D_e · y · (x² - y²) / (x² + y²)²
σ_zz =  ν · (σ_xx + σ_yy) = -2 · ν · D_e · y / (x² + y²)
τ_xy =  D_e · x · (x² - y²) / (x² + y²)²
```

де параметр `D_e` визначається через модуль зсуву `G` та коефіцієнт Пуассона `ν`:

```
D_e = G · b / [ 2π · (1 - ν) ]
```

Інтегрування густини пружної енергії крайової дислокації по всьому об'єму дає вираз:

```
E_edge = [ G · b² / (4π · (1 - ν)) ] · ln(R / r_0)          [погонова енергія крайової дислокації]
```

Оскільки для більшості металів `ν ≈ 0.3`, то `1 / (1 - ν) ≈ 1.43`. Отже, погонова енергія крайової дислокації приблизно на 40% більша за енергію ґвинтової дислокації з таким самим вектором Бюргерса.

## 5. Сила взаємодії Піча-Келера та дислокаційні стінки

На лінійну дислокацію з вектором Бюргерса `b` та одиничним вектором напрямку лінії `t`, яка перебуває у зовнішньому полі напружень `σ`, діє механічна сила Піча-Келера `F_PK` на одиницю довжини:

```
F_PK = (σ · b) × t                                         [векторна сила Піча-Келера]
```

Для двох паралельних крайових дислокацій з однаковими векторами Бюргерса `b`, розташованих на відстані `x` вздовж оси ковзання та на відстані `y` між паралельними площинами ковзання, сила ковзання `F_x` на одиницю довжини дорівнює:

```
F_x = [ G · b² / (2π · (1 - ν)) ] · [ x · (x² - y²) / (x² + y²)² ]
```

З аналізу функції `F_x(x, y)` випливають важливі фізичні наслідки:

1. Якщо дислокації лежать в одній площині ковзання (`y = 0`), сила дорівнює `F_x = G·b² / (2π·(1-ν)·x) > 0` — дислокації одного знака завжди відштовхуються.
2. Якщо дислокації лежать у паралельних площинах (`y ≠ 0`), стійке положення рівноваги (`F_x = 0`) досягається при `x = 0`, тобто коли дислокації шикуються одна над одною у вертикальну стінку. Цей ефект утворення вертикальних дислокаційних стінок є математичною основою формування малокутових меж зерен при полігонізації та відпалі металів.

## 6. Енергія малокутової межі нахилу (Рівняння Ріда-Шоклі)

Малокутова межа нахилу складається зі стінки крайових дислокацій, розташованих на однаковій відстані `D = b / θ`, де `θ` — кут разорієнтації сусідніх зерен у радіанах.

Підсумовуючи поля напружень окремих дислокацій у стінці, В. Рід та В. Шоклі вивели математичне співвідношення для поверхневої енергії межі `γ_gb` як функції кута `θ`:

```
γ_gb(θ) = γ_0 · θ · [ A - ln(θ) ]                          [рівняння Ріда-Шоклі]
```

де параметри `γ_0` та `A` визначаються пружними константами кристала та енергією ядра дислокації:

```
γ_0 = G · b / [ 4π · (1 - ν) ]
A = 1 + ln(b / (2π · r_0))
```

Функція Ріда-Шоклі проходить через максимум при куті `θ_max = exp(A - 1) ≈ 15°..20°`. При вищих кутах (`θ > 15°`) ядра дислокацій перекриваються, дискретний дислокаційний опис втрачає силу, і межа стає великокутовою з постійною поверхневою енергією `γ_gb ≈ 0.5..0.8 Дж/м²`.

## 7. Критичне напруження джерела Франка-Роада

Розглянемо сегмент дислокації довжиною `L`, закріплений на двох кінцях (наприклад, у вузлах сітки). Під дією зовнішнього зсувного напруження `τ` на сегмент діє сила Піча-Келера `F = τ · b` на одиницю довжини.

Унаслідок натягу дислокаційної лінії `T_line ≈ (1/2) · G · b²` сегмент вигинається в дугу радіуса `R_c`. Умова механічної рівноваги дуги має вигляд:

```
τ · b = T_line / R_c
```

Мінімальний радіус кривини `R_c_min = L / 2` досягається тоді, коли сегмент вигинається у напівколо. При подальшому збільшенні напруження дуга втрачає стійкість і починає самочинно розширюватися, утворюючи замкнену дислокаційну петлю.

Критичне напруження спрацьовування джерела Франка-Роада `τ_crit` дорівнює:

```
τ_crit = T_line / (b · R_c_min)
       = [ (1/2) · G · b² ] / [ b · (L / 2) ]
       = G · b / L                                         [критичне напруження джерела Франка-Роада]
```

Формула `τ_crit = G · b / L` пояснює, чому дрібнокристалічні матеріали з малими розмірами зерен (і відповідно з короткими довжинами дислокаційних сегментів `L`) мають значно вищу межу плинності (закон Голла-Петча `σ_y = σ_0 + k_y / √d`).

## 8. Енергетична вигідність дислокаційних реакцій (Правило Франка)

Під час пластичної деформації та взаємодії дислокацій у кристалі відбуваються дислокаційні реакції, за яких дві дислокації з векторами Бюргерса `b_1` та `b_2` зливаються в одну дислокацію з вектором `b_3 = b_1 + b_2`, або одна дислокація розщеплюється на дві.

Оскільки пружна енергія дислокації пропорційна квадрату модуля її вектора Бюргерса (`E ∝ b²`), Ч. Франк запропонував простий енергетичний критерій вигідності дислокаційної реакції. Реакція злиття або розщеплення відбувається самочинно з виділенням енергії тоді і тільки тоді, коли сума квадратів векторів Бюргерса вихідних дислокацій більша за квадрат вектора Бюргерса утвореної дислокації:

```
b_1² + b_2² > b_3²                                         [критерій енергетичної вигідності Франка]
```

Якщо `b_1² + b_2² < b_3²`, утворення нової дислокації енергетично невигідне і вимагає зовнішньої роботи. Якщо `b_1² + b_2² = b_3²`, дислокації не взаємодіють пружно.

Прикладом енергетично вигідного розщеплення є розпад повної дислокації у ГЦК-кристалі з вектором `b = (a/2)·[1, 1, 0]` на дві часткові дислокації Шкідлі з векторами `b_1 = (a/6)·[2, 1, -1]` та `b_2 = (a/6)·[1, 2, 1]`:

```
b² = (a/2)² · (1² + 1² + 0²) = a² / 2 = 0.500 · a²
b_1² = (a/6)² · (2² + 1² + (-1)²) = 6·a² / 36 = a² / 6 ≈ 0.167 · a²
b_2² = (a/6)² · (1² + 2² + 1²) = 6·a² / 36 = a² / 6 ≈ 0.167 · a²
b_1² + b_2² = a² / 3 ≈ 0.333 · a² < 0.500 · a²              [реакція розщеплення енергетично вигідна]
```

## 9. Ширина розщеплення дислокації та енергія дефекту упаковки

Коли повна дислокація розщеплюється на дві часткові дислокації Шкідлі `b_1` та `b_2`, між ними виникає смужка дефекту упаковки з поверхневою енергією `γ_sf` (Дж/м²). 

Дві одноіменні часткові дислокації відштовхуються з пружною силою `F_elastic(d)`, яка обернено пропорційна відстані `d` між ними. З іншого боку, натяг дефекту упаковки притягує їх з постійною силою `F_surface = γ_sf`.

Умова рівноваги сил дає рівноважну ширину розщеплення `d_eq`:

```
F_elastic(d_eq) = γ_sf
[ G · (b_1 · b_2) ] / [ 2π · d_eq ] = γ_sf
```

Звідси отримуємо вираз для рівноважної ширини дефекту упаковки `d_eq`:

```
d_eq = [ G · (b_1 · b_2) ] / [ 2π · γ_sf ]                 [рівноважна ширина розщеплення]
```

Для металів з високою енергією дефекту упаковки (алюміній, `γ_sf ≈ 160 мДж/м²`) ширина розщеплення становить лише пару атомних радіусів (`d_eq ≈ 1..2 нм`), тому дислокації легко перескакують між площинами ковзання (поперечне ковзання). Для металів з низькою енергією дефекту упаковки (латунь, аустенітні сталі, `γ_sf ≈ 15..20 мДж/м²`) ширина розщеплення сягає `d_eq ≈ 10..20 нм`, що унеможливлює поперечне ковзання й визначає високу схильність до деформаційного двійникування.

## 10. Енергія взаємодії домішкового атома з дислокацією (Атмосфера Коттрелла)

Замісний або міжвузловий атом домішки, розмір якого відрізняється від розміру атомів матриці на величину `ΔV = V_impurity - V_matrix`, створює навколо себе сферичне поле об'ємної деформації.

Крайова дислокація створює гідростатичне напруження `p = -(1/3) · (σ_xx + σ_yy + σ_zz)`. Взаємодія поля об'ємної деформації домішки з гідростатичним тиском дислокації дає енергію взаємодії Коттрелла `E_int(r, θ)` у полярних координатах `(r, θ)` біля ядра дислокації:

```
E_int(r, θ) = p · ΔV
            = [ A_cottrell · sin(θ) ] / r                  [енергія взаємодії Коттрелла]
```

де константа взаємодії `A_cottrell` дорівнює:

```
A_cottrell = (1 / 3) · [ (1 + ν) / (1 - ν) ] · G · b · ΔV
```

Оскільки `E_int < 0` у зоні розтягу крайової дислокації (`sin(θ) < 0` під площиною ковзання для великорозмірного атома `ΔV > 0`), атоми домішок самочинно дифундують у цю область, утворюючи атмосферу Коттрелла з локальною концентрацією `c(r, θ)`:

```
c(r, θ) = c_0 · exp( -E_int(r, θ) / (k_B · T) )             [концентрація атмосфери Коттрелла]
```

Сила виривання дислокації з атмосфери Коттрелла визначає величину верхньої межі плинності та явище деформаційного старіння металів.

## 11. Напруження Паєрлса-Набарро (Градієнтний опір кристалічної ґратки)

Під час руху дислокації крізь кристалічну ґратку атоми в її ядрі виходять зі своїх мінімумів потенціальної енергії. Періодичний потенціальний рельєф ґратки створює природний опір ковзанню дислокації — напруження Паєрлса-Набарро `τ_PN`.

Р. Паєрлс та Ф. Набарро вивели математичний вираз для `τ_PN`, моделюючи атомну структуру ядра дислокації через синусоїдальні сили взаємодії між атомами верхньої та нижньої напівплощин:

```
τ_PN = [ 2 · G / (1 - ν) ] · exp( -2π · w_core / b )       [напруження Паєрлса-Набарро]
```

де `w_core = d_interplane / (1 - ν)` — ширина ядра дислокації, а `d_interplane` — міжплощинна відстань.

Звідси випливають три фундаментальні математичні висновки:

1. Ковзання дислокацій завжди відбувається по найщільніше пакованих атомних площинах із найбільшою міжплощинною відстанню `d_interplane`, оскільки експоненціальний множник `exp(-2π · d_interplane / b)` робить опір ґратки для цих площин мінімальним.
2. У кристалах із ковалентним зв'язком (кремній, алмаз) ядро дислокації вузьке (`w_core ≈ b`), тому `τ_PN` надзвичайно велике (досягає `10⁻² · G`), що зумовлює їхню крихкість за низьких температур.
3. У металах із ГЦК-ґраткою (мідь, алюміній) ядро широке (`w_core ≈ 3..4 b`), тому `τ_PN` мізерно мале (`10⁻⁵ · G`), що забезпечує високу пластичність навіть при температурах близько абсолютного нуля.

## 12. Енергетика та критичний радіус зародження вакансійних петель

Під час радіаційного опромінення або швидкого гартування з високих температур у кристалі виникає високе надпересичення вакансій `c_v > c_eq`. Складання вакансій у двовимірні диски з подальшим схлопуванням атомних площин утворює кругові крайові дислокаційні петлі радіуса `R_loop`.

Зміна вільної енергії при утворенні кругової дислокаційної петлі `ΔF_loop(R_loop)` складається з пружної енергії контуру петлі та виграшу енергії від анігіляції надлишкових вакансій:

```
ΔF_loop(R_loop)
= 2π · R_loop · E_edge - π · R_loop² · (b / Ω) · k_B · T · ln( c_v / c_eq )
```

де `Ω ≈ b³` — атомний об'єм.

Диференціюючи `ΔF_loop` по `R_loop` і дорівнюючи похідну нулю, знаходимо критичний радіус `R_crit`, понад який вакансійна петля самочинно зростає:

```
d(ΔF_loop)/dR_loop
= 2π · E_edge - 2π · R_crit · (b / Ω) · k_B · T · ln( c_v / c_eq ) = 0
```

Звідси отримуємо критичний радіус зародження дислокаційної петлі:

```
R_crit = [ E_edge · Ω ] / [ b · k_B · T · ln( c_v / c_eq ) ]  [критичний радіус зародження петлі]
```

Ця формула пояснює явище радіаційного розпухання та вакансійного пороутворення в конструкційних матеріалах ядерних реакторів: при високих надпересиченнях `c_v ≫ c_eq` критичний радіус `R_crit` стає сумірним із декількома міжатомними відстанями, що спричиняє масове зародження вакансійних петель та пор.

## 13. Термодинамічна рівновага дефектів Шотткі в іонних кристалах

В іонних сполуках виду `MX` (наприклад, `NaCl`) утворення вакансій у катіонній та аніонній підґратках підпорядковується вимозі збереження електронейтральності об'єму кристала.

Пара дефектів Шотткі складається з однієї катіонної вакансії `V_M'` та однієї аніонної вакансії `V_X<sup>•</sup>`. Кількість комбінаторних способів розташувати `n_s` катіонних вакансій по `N` вузлах катіонної підґратки та `n_s` аніонних вакансій по `N` вузлах аніонної підґратки дорівнює:

```
W_schottky = [ N! / ((N - n_s)! · n_s!) ]²
```

Виражаючи конфігураційну ентропію за формулою Больцмана `S = k_B · ln(W_schottky)` та застосовуючи наближення Стірлінга, отримуємо:

```
S_schottky = 2 · k_B · [ N · ln(N / (N - n_s)) + n_s · ln((N - n_s) / n_s) ]
```

Мінімізація вільної енергії `ΔF_schottky = n_s · E_s - T · S_schottky` дає рівноважну концентрацію пар дефектів Шотткі `c_s = n_s / N`:

```
d(ΔF_schottky)/dn_s = E_s - 2 · k_B · T · ln( (N - n_s) / n_s ) = 0
```

При `n_s ≪ N` отримуємо класичний вираз для відносної концентрації дефектів Шотткі:

```
c_s = n_s / N = exp( -E_s / (2 · k_B · T) )                 [концентрація дефектів Шотткі]
```

Знаменник `2 · k_B · T` показує, що для утворення нейтральної сукупності дефектів Шотткі вимагається парне виникнення катіонної та аніонної вакансій. Для сполук стехіометрії `MX_2` (наприклад, `CaF_2`) на кожну вакансію катіона `V_Ca''` виникає дві вакансії аніона `V_F<sup>•</sup>`, що змінює показник експоненти на `3 · k_B · T`.
