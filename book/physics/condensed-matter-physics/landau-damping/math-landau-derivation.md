# 🧮 Математичне виведення декременту загасання Ландау з контуру Ландау

Ця вставка містить строгий і деталізований математичний розрахунок дисперсійного співвідношення для поздовжніх електростатичних коливань у плазмі, а також аналітичне виведення декременту загасання Ландау за допомогою методу перетворення Лапласа та аналітичного продовження уздовж контуру Ландау. Вона розкриває покроковий математичний апарат кінетичної теорії беззіткновальної плазми та пояснює математичні основи обходу полюса в інтегралах за швидкостями.

---

### 1. Виведення 1D-рівняння Власова з теореми Ліувілля та умови беззіткновальності

Опис багаточастинкової системи заряджених частинок у плазмі починається з N-частинкової функції розподілу у фазовому просторі. Згідно з теоремою Ліувілля, для точної функції розподілу об'ємна густина в узгодженому фазовому просторі зберігається вздовж траєкторій руху частинок.

У високотемпературній плазмі кількість частинок у дебаївській сфері є надзвичайно великою (`N_D = n_0 · λ_D³ >> 1`). Це означає, що сили флуктуаційних парних зіткнень на малій відстані (парні кулонівські зіткнення) є нехтовно малими порівняно з усередненими макроскопічними колективними полями, які створюються всіма частинками плазми разом. За цієї умови інтеграл зіткнень Больцмана дорівнює нулю `(∂f/∂t)_{coll} ≈ 0`, і одночастинкова функція розподілу электронів `f(r, v, t)` підпорядковується беззіткновальному кінетичному рівнянню Власова.

Розглянемо найпростішу одновимірну модель плазми (1D1V), де просторова координата позначена як `x`, а швидкість частинок — як `v`. Рух електронів масою `m` і зарядом `-e` відбувається в електростатичному полі `E(x, t)`, створеному самоузгодженим просторовим розподілом заряду. Позитивні іони вважаємо нерухомим однорідним нейтралізуючим фоном із постійною густиною `n_0`.

Загальне одновимірне рівняння Власова має вигляд:

```
∂f/∂t + v · ∂f/∂x - (e/m) · E · ∂f/∂v = 0
```

Електричне поле `E(x, t)` визначається через просторову похідну електричного потенціалу `E = - ∂Φ/∂x` та описується 1D-рівнянням Пуассона:

```
∂E/∂x = (e / ε_0) · (n_0 - ∫ f(x, v, t) dv)
```

Для аналізу малих хвильових збурень припустимо, що функція розподілу `f(x, v, t)` лише трохи відхиляється від рівноважного просторово однорідного стану `f_0(v)`:

```
f(x, v, t) = f_0(v) + f_1(x, v, t),    де |f_1| << f_0
```

де `f_0(v)` — рівноважний розподіл Максвелла, для якого просторова похідна дорівнює нулю `∂f_0/∂x = 0`, а внутрішнє електричне поле дорівнює нулю `E_0 = 0`.

Підставимо розклад `f = f_0 + f_1` у рівняння Власова і знехтуємо нелінійним членом другого порядку малості `(e/m) · E_1 · (∂f_1/∂v)`, оскільки добуток двох малих величин `E_1` та `f_1` є нехтовно малим у лінійному наближенні:

```
∂f_1/∂t + v · ∂f_1/∂x - (e/m) · E_1 · (df_0/dv) = 0
```

Рівняння Пуассона для малого збурення електричного поля `E_1(x, t)` береться з урахуванням того, що рівноважний шар іонів повністю нейтралізує рівноважний заряд електронів `n_0 = ∫ f_0 dv`:

```
∂E_1/∂x = - (e / ε_0) · ∫ f_1(x, v, t) dv
```

### 2. Застосування математичного апарату Фур'є — Лапласа

Оскільки лінеаризована система рівнянь є однорідною за просторовою координатою `x`, застосуємо просторове перетворення Фур'є. Окрему просторову гармоніку з хвильовим вектором `k` представимо у вигляді:

```
f_1(x, v, t) = f_k(v, t) · exp(i · k · x)
E_1(x, t) = E_k(t) · exp(i · k · x)
```

Підставивши ці вирази в лінеаризоване рівняння Власова та скоротивши спільний множник `exp(i · k · x)`, отримуємо диференціальне рівняння першого порядку за часом для амплітуди Фур'є-моди `f_k(v, t)`:

```
∂f_k/∂t + i · k · v · f_k - (e/m) · E_k · (df_0/dv) = 0
```

Фізична задача про збудження й поширення хвилі у плазмі є задачею з початковими умовами Коші. Припустимо, що в початковий момент часу `t = 0` у плазмі створено початкове збурення функції розподілу `f_k(v, t=0) = g_k(v)`.

Для розв'язання початкової задачі застосуємо одностороннє перетворення Лапласа за часовою змінною `t`:

```
f_k(v, p) = ∫_0^∞ f_k(v, t) · exp(-p · t) dt
E_k(p) = ∫_0^∞ E_k(t) · exp(-p · t) dt
```

де `p` — комплексний параметр перетворення Лапласа (`Re(p) > 0`).

Використовуючи математичну властивість перетворення Лапласа від часової похідної `L{∂f_k/∂t} = p · f_k(v, p) - g_k(v)`, перетворюємо диференціальне рівняння на алгебраїчне:

```
p · f_k(v, p) - g_k(v) + i · k · v · f_k(v, p) = (e/m) · E_k(p) · (df_0/dv)
```

Звідси виражаємо Лаплас-образ збурення функції розподілу `f_k(v, p)` через Лаплас-образ електричного поля `E_k(p)` та початковий функціональний профіль `g_k(v)`:

```
f_k(v, p) = [g_k(v) + (e/m) · E_k(p) · (df_0/dv)] / (p + i · k · v)
```

Математична перевага методу Лапласа полягає в тому, що він принципово враховує часову асиметрію задачі `t ≥ 0`. Диференціальний оператор Власова не є самоспряженим у просторі `L²`, тому звичайний розклад Фур'є за часом призводить до формальних сингулярностей. Перетворення Лапласа переносить розв'язок у комплексну напівплощину `Re(p) > 0`, де всі інтеграли є абсолютно збіжними.

### 3. Діелектрична функція плазми ε(k, p) та контур Ландау

Тепер підставимо отримане значення `f_k(v, p)` у перетворене за Фур'є рівняння Пуассона `i · k · E_k(p) = - (e / ε_0) · ∫ f_k(v, p) dv`:

```
i · k · E_k(p) = - (e / ε_0) · ∫_{-∞}^{+∞} [g_k(v) + (e/m) · E_k(p) · (df_0/dv)] / (p + i · k · v) dv
```

Розділимо підінтегральний вираз на дві частини — початкове збурення та самоузгоджене поле:

```
i · k · E_k(p) + (e² / (m · ε_0)) · E_k(p) · ∫_{-∞}^{+∞} (df_0/dv) / (p + i · k · v) dv = - (e / ε_0) · ∫_{-∞}^{+∞} g_k(v) / (p + i · k · v) dv
```

Винесемо `E_k(p)` за дужки та поділимо обидві частини на `i · k`:

```
E_k(p) · [1 - (e² / (m · ε_0 · i · k)) · ∫_{-∞}^{+∞} (df_0/dv) / (p + i · k · v) dv] = - (e / (i · k · ε_0)) · ∫_{-∞}^{+∞} g_k(v) / (p + i · k · v) dv
```

Вираз у квадратних дужках визначає комплексну діелектричну проникність плазми `ε(k, p)`:

```
ε(k, p)
= 1 - (e² / (m · ε_0 · i · k)) · ∫_{-∞}^{+∞} (df_0/dv) / (p + i · k · v) dv  [підстановка f_k(v, p) у Пуассон]
= 1 + (e² / (m · ε_0 · k²)) · ∫_{-∞}^{+∞} (df_0/dv) / (v - i · p / k) dv     [винесення множника (i·k) зі знаменника]
```

Здійснимо заміну комплексної змінної `p = -i · ω`, де `ω = ω_r + i · γ` — комплексна частота коливань. Тоді вираз для діелектричної проникності набуває вигляду:

```
ε(k, ω) = 1 + (ω_p² / (n_0 · k²)) · ∫_C (df_0/dv) / (v - ω/k) dv
```

де `ω_p = √(n_0 · e² / (m · ε_0))` — плазмова частота електронів.

Підінтегральна функція має полюс у точці `v = u = ω / k`. Зворотне перетворення Лапласа для електричного поля `E_k(t)` визначається інтегралом Бромвіча:

```
E_k(t) = (1 / (2πi)) · ∫_{c - i∞}^{c + i∞} E_k(p) · exp(p · t) dp
```

Для аналітичного продовження функції `ε(k, p)` у ліву напівплощину комплексної змінної `p` (що відповідає загасаючим хвилям із `γ = Im(ω) < 0`) контур інтегрування за швидкістю `v` необхідно деформувати. Лев Ландау сформулював суворі правила обходу полюса `u = ω/k`:

1. **Верхня напівплощина (`Im(ω) > 0`):** Полюс `u` розташований вище дійсної осі `v`. Інтегрування проводиться строго вздовж дійсної осі від `-∞` до `+∞`.
2. **Дійсна вісь (`Im(ω) = 0`):** Полюс `u` лежить на дійсній осі. Інтеграл обчислюється за теоремою Сохоцького — Племеля, де полюс огинається по нескінченно малому півколу знизу:

```
1 / (v - u ∓ i·0) = P.V. (1 / (v - u)) ± i · π · δ(v - u)
```

3. **Нижня напівплощина (`Im(ω) < 0`):** При аналітичному продовженні полюс `u` опускається нижче дійсної осі. Щоб функція `ε(k, ω)` залишалася аналітичною, контур інтегрування `C` деформується вниз у комплексній площині `v`, втягуючи полюс і проходячи строго під ним:

```
∫_C = P.V. ∫_{-∞}^{+∞} (df_0/dv) / (v - u) dv + i · π · (df_0/dv)|_{v = u}
```

Математична обґрунтованість деформації контуру спирається на теорему Коші про інтегрування аналітичних функцій. Якщо підінтегральний вираз `df_0/dv` є цілою аналітичною функцією у комплексній площині `v` (як це має місце для експоненціального максвеллівського розподілу `exp(-v²/2v_th²)`), контур можна неперервно деформувати в нижню напівплощину без виникнення розрізів чи додаткових сингулярностей.

Строге обґрунтування Ландау-контуру можна отримати також шляхом введення нескінченно малого модельного зіткновального члена Крука `(∂f/∂t)_{coll} = - ν (f - f_0)` у рівняння Власова. Зіткновальне диференціальне рівняння набуває вигляду:

```
(p + ν + i k v) f_k(v, p) = g_k(v) + (e/m) E_k(p) (df_0/dv)
```

Діелектрична функція зіткновальної плазми набуває вигляду `ε_ν(k, p) = 1 + (e²/(m ε_0 k²)) ∫ (df_0/dv) / (v - i(p+ν)/k) dv`. Оскільки релаксаційний параметр зіткнень дорівнює `ν > 0`, полюс `v = i(p+ν)/k` завжди лежить у верхній напівплощині для дійсної частоти. У граничному переході беззіткновальної плазми `ν → 0+` полюс наближається до дійсної осі зверху. Це фундаментально доводить, що для деформації контуру полюс обов'язково має огинатися знизу.

### 4. Розрахунок декременту загасання γ для максвеллівського розподілу

Обчислимо значення діелектричної проникності `ε(k, ω)` для рівноважного максвеллівського розподілу електронів:

```
f_0(v) = n_0 / (√(2π) · v_th) · exp(- v² / (2 · v_th²))
```

де `v_th = √(k_B · T_e / m)` — теплова швидкість електронів.

Похідна функції розподілу за швидкістю дорівнює:

```
df_0/dv = - (v / v_th²) · f_0(v)
```

Розкладемо діелектричну функцію на дійсну та уявну частини `ε(k, ω) = ε_r(k, ω) + i · ε_i(k, ω)` для слабкого загасання (`|γ| << ω_r`), що відповідає довгим хвилям `k · λ_D << 1` і фазовим швидкостям, які значно перевищують теплову `u = ω_r/k >> v_th`.

#### 1. Дійсна частина ε_r(k, ω_r)

Розкладемо знаменник `1 / (v - u) = - (1/u) · (1 + v/u + v²/u² + v³/u³ + ...)` у головному значенні інтеграла для `u >> v_th`:

```
ε_r(k, ω_r)
= 1 - (ω_p² / (n_0 · k² · u²)) · ∫_{-∞}^{+∞} (1 + 3 v² / u²) · f_0(v) dv  [розклад у ряд Тейлора за v/u]
= 1 - (ω_p² / ω_r²) · (1 + 3 · k² · v_th² / ω_r²)                           [інтегрування моментів максвеллівського розподілу]
```

Прирівнюючи дійсну частину до нуля `ε_r(k, ω_r) = 0`, отримуємо **дисперсійне співвідношення Бома — Гросса** для реальної частоти коливань:

```
ω_r² = ω_p² · (1 + 3 · k² · λ_D²)
ω_r ≈ ω_p · (1 + (3/2) · k² · λ_D²)
```

де `λ_D = v_th / ω_p = √(ε_0 · k_B · T_e / (n_0 · e²))` — дебаївський радіус екранування плазми.

#### 2. Уявна частина ε_i(k, ω_r)

Уявна частина діелектричної проникності виникає виключно з лишку підінтегрального виразу в точці полюса Ландау `v = u = ω_r / k`:

```
ε_i(k, ω_r)
= π · (ω_p² / (n_0 · k²)) · (df_0/dv)|_{v = ω_r/k}                 [теорема про лишки у полюсі v = ω_r/k]
= - π · (ω_p² / (n_0 · k²)) · (ω_r / (k · v_th²)) · f_0(ω_r/k)     [підстановка df_0/dv = -(v/v_th²)·f_0]
= - √(π/2) · (ω_p² · ω_r / (k³ · v_th³)) · exp(- ω_r² / (2 k² v_th²)) [підстановка максвеллівського розподілу f_0]
```

#### 3. Формула для декременту загасання γ

Розкладемо комплексне рівняння `ε(k, ω_r + i · γ) = 0` у ряд Тейлора в околиці дійсної частоти `ω_r`:

```
ε(k, ω_r + i · γ) ≈ ε_r(k, ω_r) + i · γ · (∂ε_r/∂ω)|_{ω = ω_r} + i · ε_i(k, ω_r) = 0
```

Оскільки `ε_r(k, ω_r) = 0`, виражаємо уявну частину частоти `γ = Im(ω)`:

```
γ = - ε_i(k, ω_r) / (∂ε_r/∂ω)|_{ω = ω_r}
```

Обчислимо похідну дійсної частини діелектричної проникності за частотою `ω`:

```
∂ε_r/∂ω ≈ ∂/∂ω [1 - ω_p² / ω²] = 2 · ω_p² / ω_r³ ≈ 2 / ω_p
```

Підставивши вирази для `ε_i(k, ω_r)` та `∂ε_r/∂ω`, а також підставивши значення `ω_r / (k · v_th) ≈ (1 / (k · λ_D)) · (1 + (3/2) k² λ_D²)`, отримуємо остаточну **формулу декременту загасання Ландау**:

```
γ = - √(π/8) · ω_p · (1 / (k · λ_D)³) · exp(- 1 / (2 · k² · λ_D²) - 3/2)
```

### 5. Аналіз плазмової функції дисперсії Z(ζ) та іонно-акустичних хвиль

Для довільних значень співвідношення `v_ph / v_th` (без обмеження `k · λ_D << 1`) діелектрична проникність плазми строго виражається через **плазмове дисперсійне інтегральне співвідношення Фрідмана — Конте** (Plasma Dispersion Function, `Z(ζ)`):

```
Z(ζ) = (1 / √π) · ∫_C exp(-t²) / (t - ζ) dt
```

де `ζ = ω / (√2 · k · v_th)` — безрозмірна комплексна фазова швидкість.

Функція `Z(ζ)` задовольняє точній диференціальній рівності `Z'(ζ) = -2 (1 + ζ Z(ζ))`. Через функцію `Z(ζ)` точна діелектрична проникність плазми записується як:

```
ε(k, ω) = 1 + (1 / (k² · λ_D²)) · [1 + ζ · Z(ζ)]
```

Аналіз асимптотичних розкладів функції `Z(ζ)` дає два принципово різних фізичних режими загасання електростатичних хвиль:

1. **Довгохвильовий режим (`|ζ| >> 1`, що відповідає `k · λ_D << 1`):**
   Асимптотика функції `Z(ζ) ≈ - 1/ζ - 1/(2 ζ³) + i √π σ exp(-ζ²)` дає слабке загасання Ландау `|γ| << ω_p`. Фазова швидкість хвилі значно більша за теплову швидкість електронів `v_ph >> v_th`. Хвиля здатна поширюватися на значні відстані, здійснюючи сотні й тисячі осциляцій.

2. **Короткохвильовий режим (`|ζ| ~ 1`, що відповідає `k · λ_D ≳ 0.5`):**
   Асимптотичний розклад перестає працювати. Чисельний розв'язок точного рівняння `1 + (1 / (k² λ_D²)) [1 + ζ Z(ζ)] = 0` показує, що при `k · λ_D ≈ 0.5` уявна частина частоти досягає величини `|γ| ≈ 0.15 · ω_p`, а при `k · λ_D = 1.0` уявна частина перевищує дісну `|γ| ≳ ω_r`. Це означає катастрофічно швидку передачу всієї енергії хвилі тепловим електронам за час, менший за один період коливань.

Розглянемо двокомпонентну плазму (електрони й іони), у якій можуть поширюватися низькочастотні **іонно-акустичні хвилі** (*ion-acoustic waves*). Дисперсійне співвідношення включає як електронну, так і іонну діелектричні проникності:

```
ε(k, ω) = 1 + (1 / (k² · λ_De²)) · [1 + ζ_e Z(ζ_e)] + (1 / (k² · λ_Di²)) · [1 + ζ_i Z(ζ_i)] = 0
```

Для невизотермічної плазми із гарячими електронами й холодними іонами (`T_e >> T_i`) фазова швидкість іонного звуку дорівнює `c_s = √(k_B T_e / m_i)`. У цьому випадку фазова швидкість задовольняє умові `v_thi << c_s << v_the`.

Декремент **іонного загасання Ландау** для іонно-акустичних хвиль виражається сумою електронного та іонного внесків:

```
γ_sound = - √(π/8) · ω_sound · [ √(m_e / m_i) + (T_e / T_i)^(3/2) · exp(- T_e / (2 T_i)) ]
```

З цієї формули випливає вирішальний фізичний висновок: якщо температура іонів наближається до температури електронів (`T_i ≈ T_e`), другий експоненціальний член в іонному загасанні стає порядку одиниці `exp(-1/2) ~ 0.6`. Іонне загасання Ландау стає сильним (`|γ_sound| ~ ω_sound`), і іонно-акустичні хвилі повністю згасають. Проживання іонного звуку у плазмі можливе лише у сильно неізотермічних умовах `T_e >> T_i`.

### 6. Критерій Пенроуза кінетичної стійкості плазми

Загальна умова кінетичної стійкості або нестійкості беззіткновальної плазми для довільної (не обов'язково максвеллівської) однорідної функції розподілу `f_0(v)` описується **критерієм Пенроуза** (*Penrose instability criterion*).

Необхідною і достатньою умовою існування зростаючих мод (`γ > 0`, тобто від'ємного загасання Ландау) є наявність локального мінімуму (локальної ями) у функції `f_0(v)` в точці `v = v_0`, для якого виконується інтегральна нерівність:

```
P_penrose = ∫_{-∞}^{+∞} [ f_0(v) - f_0(v_0) ] / (v - v_0)² dv > 0
```

Якщо для всіх локальних екстремумів `v_0` інтеграл є від'ємним `P_penrose < 0`, плазма є суворо стійкою до всіх електростатичних збурень, і будь-яка збуджена електростатична хвиля підпорядковується загасанню Ландау. Якщо ж функція розподілу має два відокремлених піки з достатньо глибоким проміжним мінімумом (наприклад, суміш плазми та інтенсивного електронного пучка), інтеграл Пенроуза стає додатним, виникає нестійкість і хвиля самовільно розганяється за рахунок вільній енергії пучка.

### 7. Тривимірний тензор діелектричної проникності та релятивістське загасання

У повній 3D3V геометрії для довільних електромагнітних хвиль у магнітоактивній плазмі (де існує зовнішнє магнітне поле `B_0`) діелектрична проникність узагальнюється до тензора `ε_ij(k, ω)`. Рівняння хвильового поля має вигляд `[ (k² δ_ij - k_i k_j) - (ω²/c²) ε_ij(k, ω) ] E_j = 0`.

При наявності зовнішнього магнітного поля частинки рухаються по спіральних траєкторіях із циклотронною частотою `Ω_c = e B_0 / m`. Умова резонансу Ландау узагальнюється до **циклотронного та циклотронно-резонансного загасання Ландау**:

```
ω - k_parallel · v_parallel - n · Ω_c = 0,    де n = 0, ±1, ±2, ...
```

Для релятивістських електронів, енергія яких дорівнює `E_rel = c √(p² + m² c²)`, заміна швидкості на імпульс `p = m γ_rel v` вимагає врахування релятивістського фактора `γ_rel = √(1 + p²/(m² c²))`. У релятивістській кінетиці полюс Ландау в просторі імпульсів визначається релятивістською умовою черінковського резонансу `ω - k · v = 0`, що перетворюється на `ω - k · p / (m γ_rel) = 0`. 

Оскільки швидкість частинки обмежена швидкістю світла `v < c`, релятивістське загасання Ландау для хвиль із фазовою швидкістю `v_ph = ω/k > c` дорівнює нулю. Релятивістське загасання існує виключно для сповільнених електромагнітних хвиль (`v_ph < c`), де резонансні релятивістські електрони здатні підхоплювати потенціальний рельєф хвилі.

### 8. Квантове загасання Ландау у виродженому електронному газі твердих тіл

У твердих тілах (металах та вироджених напівпровідниках) електрони провідності описуються не класичною статистикою Максвелла — Больцмана, а квантовою статистикою Фермі — Дірака з енергією Фермі `E_F = (1/2) m v_F²`.

Квантова діелектрична функція виродженого електронного газу в наближенні хаотичних фаз (RPA) описується **формулою Ліндхарда** (*Lindhard dielectric function*):

```
ε_RPA(q, ω) = 1 + (e² / (ε_0 q²)) · ∑_k [ f_FD(E_k) - f_FD(E_{k+q}) ] / [ ℏ ω + E_k - E_{k+q} + i 0+ ]
```

Уявна частина функції Ліндхарда відповідає **квантовому загасанню Ландау**. У квантовій теорії поглинання плазмона (плазмової хвилі з енергією `ℏ ω` та імпульсом `ℏ q`) відбувається не через неперервний серфінг класичної частинки, а через одночастинковий квантовий перехід електрона зі стану під поверхнею Фермі `|k>` у вільний стан над поверхнею Фермі `|k + q>`.

Область існування одночастинкових електрон-діркових збуджень у просторі `(q, ω)` називається **континуумом Стонера** (*Stoner continuum*). Якщо плазмонний спектр `ω_pl(q)` перетинає межу континууму Стонера (що відбувається при достатньо великих переданих імпульсах `q > q_crit ≈ ω_p / v_F`), плазмон розпадається на електрон-діркову пару за час порядку `10⁻¹⁵` секунд. Це становить твердотільний квантовий аналог катастрофічного загасання Ландау. У двовимірних матеріалах (таких як ґрафен, дихалькогеніди перехідних металів MoS2/WSe2 або квантові ями на основі GaAs/AlGaAs) плазмони мають конусоподібну або квадратну дисперсію `ω ∝ √q`, і їхнє квантове загасання Ландау істотно залежить від Fermi-рівня допування матеріалу, просторової локалізації носіїв та міжзонних квантових переходів електронів провідності.
