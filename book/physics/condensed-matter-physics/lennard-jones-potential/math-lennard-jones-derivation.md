# 🧮 Математичний аналіз та термодинамічні виведення потенціалу Леннард-Джонса

Аналітичне дослідження парного потенціалу Леннард-Джонса 12-6 дозволяє побудувати математичний міст між мікроскопічними параметрами міжатомної взаємодії та макроскопічними фізико-хімічними властивостями конденсованої речовини і неідеальних газів. Математичний апарат дає змогу не лише розрахувати характерні геометричні та енергетичні репери потенційної ями, але й вивести коефіцієнт теплового розширення, пружні модулі кристалічної ґратки, ізотермічну стисливість та рівняння стану флюїду.

У цьому математичному аналізі послідовно виведено критичні точки потенціалу, функції міжатомної сили та її максимум, асимптотичні границі, квантово-механічні апроксимації, ангармонічний розклад у ряд Тейлора, пружні модулі ГЦК-кристала та другий віріальний коефіцієнт.

## 1. Повний аналітичний апарат парного потенціалу

Парний потенціал Леннард-Джонса описується нелінійною функцією відстані `r` між центрами двох сферично симетричних нейтральних атомів:

```
V(r) = 4 · ε · [ (σ / r)¹² - (σ / r)⁶ ]
```

у цьому виразі `r` є просторовою змінною відстані, `ε > 0` — параметр енергетичного масштабу (глибина потенційної ями), а `σ > 0` — лінійний масштаб (діаметр нульової взаємодії). 

Для спрощення математичних перетворень та диференціальних операцій введемо безрозмірну змінну `x = σ / r`. Завдяки цій заміні функція потенціалу набуває компактного поліноміального вигляду за змінною `x`:

```
V(x) = 4 · ε · (x¹² - x⁶)
```

### Нуль потенціалу (перетин осі відстаней)

Знайдемо геометричну точку `r_0`, в якій потенціальна енергія взаємодії частинок дорівнює нулю `V(r_0) = 0`. Прирівнюючи вираз для потенціалу до нуля, отримуємо алгебраїчне рівняння:

```
4 · ε · (x¹² - x⁶) = 0
x⁶ · (x⁶ - 1) = 0      [винесено спільний множник x⁶]
x⁶ - 1 = 0             [поділено на x⁶ ≠ 0 при скінченній відстані r]
x⁶ = 1                 [перенесено одиницю у праву частину]
x = 1                  [взято дійсний корінь шостого степеня з 1]
(σ / r_0) = 1          [підставлено визначення безрозмірної змінної x = σ / r]
r_0 = σ                [помножено обидві частини рівняння на r_0]
```

Отриманий результат показує фундаментальний фізичний зміст параметра `σ`: це відстань найближчого підходу двох атомів із нульовою початковою кінетичною енергією. При `r < σ` потенціальна енергія стає додатною `V(r) > 0`, що означає переважання сил відштовхування.

### Диференціальний аналіз та знаходження мінімуму потенційної ями

Для знаходження екстремумів потенціальної енергії обчислимо першу похідну функції `V(x)` по безрозмірній змінній `x`:

```
dV / dx = d/dx [ 4 · ε · (x¹² - x⁶) ]
        = 4 · ε · (12 · x¹¹ - 6 · x⁵)           [взято похідні степенів x¹² та x⁶]
        = 24 · ε · x⁵ · (2 · x⁶ - 1)             [винесено спільний множник 6·x⁵]
```

Перейдемо від похідної по `x` до похідної по просторовій координаті `r`. За законом диференціювання складеної функції `dV/dr = (dV/dx) · (dx/dr)`, враховуючи, що `dx/dr = d/dr (σ/r) = -σ/r² = -x/r`:

```
dV / dr = (24 · ε · x⁵ · (2 · x⁶ - 1)) · (-x / r) [за застосуванням ланцюгового правила]
        = - (24 · ε / r) · x⁶ · (2 · x⁶ - 1)      [перемножено x⁵ на -x/r]
        = - (24 · ε / σ) · x⁷ · (2 · x⁶ - 1)      [підставлено співвідношення 1/r = x/σ]
```

Прирівняємо першу похідну `dV/dr` до нуля для пошуку стаціонарної точки механічної рівноваги `r_min`:

```
dV / dr = 0
- (24 · ε / σ) · x⁷ · (2 · x⁶ - 1) = 0  [записано умову стаціонарності]
2 · x⁶ - 1 = 0                           [поділено на ненульовий множник -24·ε·x⁷/σ]
x⁶ = 1 / 2                               [перенесено 1 та поділено на 2]
x = (1 / 2)¹/⁶ = 2⁻¹/⁶                   [взято корінь шостого степеня]
σ / r_min = 2⁻¹/⁶                         [підставлено визначення x = σ / r_min]
r_min = 2¹/⁶ · σ ≈ 1.122462 · σ          [виражено r_min шляхом множення на 2¹/⁶]
```

Знайдена координата `r_min = 2¹/⁶ σ` визначає рівноважну відстань між двома ізольованими атомами при нульовій температурі. Обчислимо значення потенціальної енергії у цій точці:

```
V(r_min) = 4 · ε · [ (x⁶)² - x⁶ ]        [подано x¹² у вигляді квадрата (x⁶)²]
         = 4 · ε · [ (1/2)² - (1/2) ]     [підставлено знайдене значення x⁶ = 1/2]
         = 4 · ε · [ (1/4) - (1/2) ]     [піднесено дріб 1/2 до квадрата]
         = 4 · ε · ( -1/4 )               [обчислено різницю у дужках]
         = - ε                            [скорочено множник 4 на знаменник 4]
```

Таким чином, мінімальне значення потенціальної енергії становить `-ε`. Параметр `ε` має зміст енергії дисоціації (енергії розриву) міжатомного зв'язку двохатомного комплексу.

### Запис потенціалу через координату мінімуму `r_min`

У фізиці суцільних середовищ та молекулярній спектроскопії потенціал часто записують через рівноважну відстань `r_min`. Підставляючи `σ = 2⁻¹/⁶ · r_min` у вихідний вираз:

```
V(r) = 4 · ε · [ ((2⁻¹/⁶ · r_min) / r)¹² - ((2⁻¹/⁶ · r_min) / r)⁶ ]
     = 4 · ε · [ 2⁻² · (r_min / r)¹² - 2⁻¹ · (r_min / r)⁶ ] [обчислено степені 2⁻¹²⁺⁶ та 2⁻⁶]
     = 4 · ε · [ (1/4) · (r_min / r)¹² - (1/2) · (r_min / r)⁶ ] [розкрито від'ємні степені]
     = ε · [ (r_min / r)¹² - 2 · (r_min / r)⁶ ]             [внесено множник 4 у дужки]
```

Ця форма явно показує баланс між відштовхуванням `(r_min/r)¹²` та подвоєним притяганням `-2(r_min/r)⁶`, що забезпечує мінімум `-ε` при `r = r_min`.

## 2. Виведення функції міжатомної сили та точки перегину

Класична сила міжатомної взаємодії `F(r)` визначається як від'ємний градієнт потенціальної енергії `F(r) = - dV / dr`.

Використовуючи раніше знайдену похідну `dV/dr`:

```
F(r) = - [ - (24 · ε / σ) · (σ / r)⁷ · (2 · (σ / r)⁶ - 1) ] [підставлено вираз dV/dr]
     = (24 · ε / σ) · (σ / r)⁷ · [ 2 · (σ / r)⁶ - 1 ]        [змінено знак на протилежний]
     = (24 · ε / σ) · [ 2 · (σ / r)¹³ - (σ / r)⁷ ]           [внесено множник (σ/r)⁷ у дужки]
```

Аналіз функції сили відображає три фундаментальні фізичні режими:
1. `r < r_min`: `(σ/r)⁶ > 1/2`, тому `F(r) > 0` — **сила відштовхування**, яка перешкоджає зближенню атомів.
2. `r = r_min`: `(σ/r)⁶ = 1/2`, тому `F(r_min) = 0` — **стан механічної рівноваги**.
3. `r > r_min`: `(σ/r)⁶ < 1/2`, тому `F(r) < 0` — **сила притягання**, яка повертає атоми до рівноважного стану.

### Пошук точки перегину та точного максимуму сили притягання

Точка перегину потенціальної кривої `r_inf` відповідає екстремуму сили `dF / dr = 0`, що математично еквівалентно другій похідній потенціалу `d²V / dr² = 0`.

Продиференціюємо силу `F(r)` по відстані `r`:

```
dF / dr = d/dr [ (24 · ε / σ) · (2 · σ¹³ · r⁻¹³ - σ⁷ · r⁻⁷) ] [записано силу у степеневому вигляді]
        = (24 · ε / σ) · [ 2 · σ¹³ · (-13 · r⁻¹⁴) - σ⁷ · (-7 · r⁻⁸) ] [взято похідні r⁻¹³ та r⁻⁷]
        = (24 · ε / σ) · [ -26 · σ¹³ · r⁻¹⁴ + 7 · σ⁷ · r⁻⁸ ]   [перемножено коефіцієнти]
        = (24 · ε / (σ · r⁸)) · [ -26 · (σ / r)⁶ + 7 ]         [винесено r⁻⁸ та σ⁷ за дужки]
```

Прирівняємо похідну сили до нуля `dF / dr = 0` для знаходження координати `r_inf`:

```
-26 · (σ / r_inf)⁶ + 7 = 0        [прирівняно дужку до нуля при r = r_inf]
26 · (σ / r_inf)⁶ = 7              [перенесено 7 у праву частину]
(σ / r_inf)⁶ = 7 / 26              [поділено обидві частини на 26]
(σ / r_inf) = (7 / 26)¹/⁶          [взято корінь шостого степеня]
r_inf = (26 / 7)¹/⁶ · σ ≈ 1.24445 · σ [взято обернену величину та помножено на σ]
```

Для знаходження точної максимальної сили притягання `F(r_inf)` підставимо `(σ / r_inf)⁶ = 7 / 26` та `(σ / r_inf)⁷ = (7 / 26)⁷/⁶` у формулу сили `F(r)`:

```
F(r_inf) = (24 · ε / σ) · (7 / 26)⁷/⁶ · [ 2 · (7 / 26) - 1 ] [підставлено значення (σ/r_inf)⁶]
         = (24 · ε / σ) · (7 / 26)⁷/⁶ · [ (14 / 26) - (26 / 26) ] [зведено до спільного знаменника]
         = (24 · ε / σ) · (7 / 26)⁷/⁶ · ( -12 / 26 )          [обчислено різницю у дужках]
         = - ( (24 · 12) / 26 ) · (7 / 26)⁷/⁶ · (ε / σ)      [перегруповано чисельні множники]
         = - (288 / 26) · (7 / 26)⁷/⁶ · (ε / σ)              [перемножено 24 на 12]
         = - (144 / 13) · (7 / 26)⁷/⁶ · (ε / σ)              [скорочено дріб 288/26 на 2]
         ≈ - 2.39637 · (ε / σ)                               [чисельний розрахунок значення]
```

Точний алгебраїчний розрахунок дає значення максимальної сили притягання:

```
F(r_inf) = - (288 / 26) · (7 / 26)⁷/⁶ · (ε / σ) ≈ - 2.396 · (ε / σ)
```

Модуль цієї сили `|F_max| ≈ 2.396 ε/σ` визначає теоретичну межу міцності парного міжатомного зв'язку на механічний розрив (Tensile Strength). Якщо прикладена зовнішня розтягувальна сила перевищує `|F_max|`, атоми незворотно дисоціюють.

## 3. Квантово-механічні апроксимації та альтернативні потенціали

Модель Леннард-Джонса є математично оптимальним компромісом між фізичною точністю та обчислювальною швидкістю. Проте корисним є зіставлення її з альтернативними парними потенціалами, що застосовуються у фізиці конденсованого стану.

### Квантово-механічне походження сили Лондона та відштовхування Паулі

Доданок притягання `-4ε(σ/r)⁶` прямо випливає з другого порядку квантово-механічної теорії збурень для флуктуацій електромагнітного поля. Якщо уявити два неполярні атоми як взаємодіючі квантові гармонічні осцилятори із характеристичною частотою `ω_e` та поляризовуваністю `α`, енергія нульових коливань поляризованого вакууму знижується на величину:

```
E_disp(r) = - (3 / 4) · ℏ · ω_e · (α² / r⁶)
```

Порівнюючи це із членом Леннард-Джонса `-4ε σ⁶ / r⁶`, отримуємо фундаментальний зв'язок мікроскопічного енергетичного параметра `ε σ⁶` із квантовими характеристиками електронних оболонок: `ε σ⁶ = (3/16) ℏ ω_e α²`.

Що стосується відштовхування Паулі, квантовий розрахунок ортогоналізації хвильових функцій двох перекритих атомів (інтеграл перекриття `S(r) = ⟨Ψ_A | Ψ_B⟩`) приводить до кінетичної енергії електронного газу, яка пропорційна квадратній похідній хвильових функцій: `E_kin ∝ (ℏ²/2m) ∫ |∇Ψ|² d³r`. Точний аналітичний розрахунок дає експоненційну залежність `V_rep(r) = A exp(-B r)`.

### Порівняння з потенціалами Морзе, Букінгема та Мі

Для кращого розуміння меж застосовності моделі 12-6 зіставимо її з іншими класичними потенціалами:

1. **Потенціал Мі (Mie potential)**: Узагальнена степенна модель `V_Mie(r) = (C_n / (n - m)) · (n/m)^(m/(n-m)) · ε · [ (σ/r)ⁿ - (σ/r)ᵐ ]`. При `n = 12, m = 6` потенціал Мі тотожно перетворюється на потенціал Леннард-Джонса. Для жорсткіших речовин (наприклад, деяких металів) іноді вибирають `n = 14` або `n = 18`.
2. **Потенціал Букінгема (Buckingham potential)**: Замінює степенне відштовхування на квантову експоненту: `V_Buck(r) = A exp(-B r) - (C / r⁶)`. Потенціал Букінгема точніше описує кристали при надвисоких тисках (`P > 10 ГПа`), але має математичну аномалію (яму "колапсу") при `r → 0`, що вимагає штучного відтинання у чисельних алгоритмах.
3. **Потенціал Морзе (Morse potential)**: Описує ковалентні двохатомні молекули через експоненційну функцію `V_Morse(r) = D_e [ (1 - exp(-a(r - r_e)))² - 1 ]`. На відміну від Леннард-Джонса, потенціал Морзе має три незалежні параметри (`D_e, r_e, a`), що дозволяє незалежно підбирати гармонічну жорсткість та енергію зв'язку.

## 4. Крайові випадки та асимптотична поведінка

Аналіз граничних режимів дозволяє перевірити фізичну коректність моделі при малих та великих відстанях.

### Асимптотика близького підходу (`r → 0⁺`)

При надмалих відстанях між ядрами `r « σ` (тобто `x = σ / r » 1`):

```
lim_{r → 0⁺} V(r) = lim_{r → 0⁺} 4ε [ (σ/r)¹² - (σ/r)⁶ ] = + ∞
lim_{r → 0⁺} F(r) = lim_{r → 0⁺} (24ε/σ) [ 2(σ/r)¹³ - (σ/r)⁷ ] = + ∞
```

У цій області доданок відштовхування `(σ/r)¹²` асимптотично переважає доданок притягання `(σ/r)⁶`. Сила відштовхування зростає як `1/r¹³`, утворюючи крутий потенціальний бар'єр ("потенціальну стінку Паулі"). Це повністю запобігає колапсу речовини та самовільному проникненню атомних ядер одне в одне.

### Асимптотика великих відстаней (`r → ∞`)

При великих відстанях між атомами `r » σ` (тобто `x = σ / r « 1`):

```
V(r) = 4ε [ (σ/r)¹² - (σ/r)⁶ ] ≈ - 4ε · (σ / r)⁶      [нехтуємо членом (σ/r)¹² вищого порядку]
F(r) = (24ε/σ) [ 2(σ/r)¹³ - (σ/r)⁷ ] ≈ - (24ε/σ) · (σ / r)⁷ [нехтуємо відштовхуванням]
```

Потенціал прямує до нуля знизу `V(r) → -0`, а сила притягання згасає за степенним законом `F(r) ∝ -1/r⁷`. Це точно відповідає квантово-механічній теорії дисперсійних сил Лондона для флуктуаційно індукованих дипольних моментів.

### Межі степенного відштовхування при високих тисках (`P → ∞`)

При всебічних тисках понад `10 ГПа` степенна залежність `1/r¹²` описує відштовхування дещо жорсткішим, ніж реальна квантово-механічна експонента Борна — Маєра `V_rep(r) ∝ exp(-B·r)`. Однак у термодинамічному діапазоні тисків до `5 ГПа` модель 12-6 забезпечує високу точність, зберігаючи обчислювальну перевагу тотожності `r¹² = (r⁶)²`.

## 5. Ангармонічний розклад у ряд Тейлора поблизу мінімуму

У разі малих відхилень `u = r - r_min` від стану рівноваги розкладемо потенціал `V(r)` у ряд Тейлора:

```
V(u) = V(r_min) + V'(r_min) · u + (1/2!) · V''(r_min) · u² + (1/3!) · V'''(r_min) · u³ + (1/4!) · V''''(r_min) · u⁴ + ...
```

Враховуючи `V(r_min) = -ε` та `V'(r_min) = 0`, розклад набуває вигляду:

```
V(u) = - ε + (1/2) · k_eff · u² - (1/6) · g_anharm · u³ + (1/24) · h_quad · u⁴ + ...
```

де `k_eff = V''(r_min)` — коефіцієнт гармонічної жорсткості, `g_anharm = -V'''(r_min)` — параметр кубічної ангармонічності, а `h_quad = V''''(r_min)` — четвертий тейлорівський коефіцієнт.

### Розрахунок коефіцієнта жорсткості `k_eff`

Обчислимо другу похідну `V''(r) = - dF / dr` у точці мінімуму `r = r_min` (де `(σ / r_min)⁶ = 1/2` та `r_min = 2¹/⁶ σ`):

```
V''(r) = (24 · ε / (σ · r⁸)) · [ 26 · (σ / r)⁶ - 7 ] [виражено другу похідну потенціалу]
k_eff = V''(r_min)
      = (24 · ε / (σ · (2¹/⁶ · σ)⁸)) · [ 26 · (1/2) - 7 ] [підставлено координати мінімуму]
      = (24 · ε / (σ² · 2⁴/³)) · [ 13 - 7 ]                [обчислено 2⁸/⁶ = 2⁴/³ та 26/2]
      = (24 · ε / (σ² · 2⁴/³)) · 6                         [обчислено різницю у дужках]
      = (144 / 2⁴/³) · (ε / σ²)                            [перемножено 24 на 6]
      = (72 / 2¹/³) · (ε / σ²)                             [скорочено чисельник та знаменник на 2]
      ≈ 57.1464 · (ε / σ²)                                 [чисельний розрахунок значення]
```

Ефективна гармонічна жорсткість міжатомного зв'язку становить:

```
k_eff = (72 / 2¹/³) · (ε / σ²) ≈ 57.1464 · (ε / σ²)
```

Власна частота малих коливань двохатомного димера з масою атома `m` (зведена маса `μ = m / 2`) дорівнює:

```
ω_0 = √( k_eff / μ ) = √( (144 / 2¹/³) · (ε / (m · σ²)) ) ≈ 10.693 · √( ε / (m · σ²) )
```

### Розрахунок кубічної ангармонічності `g_anharm`

Диференціюємо другу похідну `V''(r)` по відстані `r` для отримання третьої похідної:

```
V'''(r) = d/dr [ 24 · ε · (26 · σ¹³ · r⁻¹⁵ - 7 · σ⁷ · r⁻⁹) ] [записано V''(r) у степеневому вигляді]
        = 24 · ε · [ 26 · σ¹³ · (-15 · r⁻¹⁶) - 7 · σ⁷ · (-9 · r⁻¹⁰) ] [взято похідні r⁻¹⁵ та r⁻⁹]
        = 24 · ε · [ -390 · σ¹³ · r⁻¹⁶ + 63 · σ⁷ · r⁻¹⁰ ]  [перемножено коефіцієнти]
        = (24 · ε / (σ³ · (r/σ)¹⁰)) · [ -390 · (σ/r)⁶ + 63 ] [винесено σ³ та (σ/r)¹⁰]
```

Підставляємо значення мінімуму `r = r_min` (де `(σ / r_min)⁶ = 1/2` та `(r_min / σ)¹⁰ = 2⁵/³`):

```
V'''(r_min) = (24 · ε / (σ³ · 2⁵/³)) · [ -390 · (1/2) + 63 ] [підставлено значення у мінімумі]
            = (24 · ε / (σ³ · 2⁵/³)) · [ -195 + 63 ]          [обчислено -390 / 2]
            = (24 · ε / (σ³ · 2⁵/³)) · ( -132 )               [обчислено різницю -195 + 63]
            = - (3168 / 2⁵/³) · (ε / σ³)                      [перемножено 24 на -132]
            = - (1584 / 2²/³) · (ε / σ³)                      [скорочено чисельник та знаменник на 2]
            = - 378 · √2 · (ε / σ³)                           [переведено у точний ірраціональний вираз]
            ≈ - 534.573 · (ε / σ³)                            [чисельний розрахунок значення]
```

Параметр кубічної ангармонічності `g_anharm = - V'''(r_min)` дорівнює:

```
g_anharm = 378 · √2 · (ε / σ³) ≈ 534.573 · (ε / σ³)
```

### Розрахунок четвертого коефіцієнта `h_quad`

Взявши четверту похідну `V''''(r) = d/dr [ V'''(r) ]`:

```
V''''(r) = 24 · ε · [ -390 · σ¹³ · (-16 · r⁻¹⁷) + 63 · σ⁷ · (-10 · r⁻¹¹) ] [диференційовано r⁻¹⁶ та r⁻¹⁰]
         = 24 · ε · [ 6240 · σ¹³ · r⁻¹⁷ - 630 · σ⁷ · r⁻¹¹ ]    [перемножено чисельники]
         = (24 · ε / (σ⁴ · (r/σ)¹¹)) · [ 6240 · (σ/r)⁶ - 630 ] [винесено σ⁴ та (σ/r)¹¹]
```

Підставляючи координати мінімуму `r = r_min` (де `(σ / r_min)⁶ = 1/2` та `(r_min / σ)¹¹ = 2¹¹/⁶`):

```
V''''(r_min) = (24 · ε / (σ⁴ · 2¹¹/⁶)) · [ 6240 · (1/2) - 630 ] [підставлено координати мінімуму]
             = (24 · ε / (σ⁴ · 2¹¹/⁶)) · [ 3120 - 630 ]         [обчислено 6240 / 2]
             = (24 · ε / (σ⁴ · 2¹¹/⁶)) · ( 2490 )               [обчислено різницю у дужках]
             = (59760 / 2¹¹/⁶) · (ε / σ⁴)                       [перемножено 24 на 2490]
             = (14940 / 2⁵/⁶) · (ε / σ⁴)                        [скорочено дріб на 4]
             ≈ 8413.78 · (ε / σ⁴)                               [чисельний розрахунок значення]
```

### Фізичний механізм теплового розширення

У статистичній механіці середній зсув атомів `⟨u⟩` визначається канонічним усередненням Больцмана:

```
⟨u⟩ = ( ∫ -∞^+∞ u · exp(-V(u)/(k_B T)) du ) / ( ∫ -∞^+∞ exp(-V(u)/(k_B T)) du )
```

Розкладаючи експоненту з ангармонічним членом `u³` у ряд Тейлора та обчислюючи гауссові інтеграли:

```
⟨u⟩ ≈ (3 / 2) · (g_anharm / k_eff²) · k_B · T
```

Підставляючи точні значення `g_anharm` та `k_eff`:

```
⟨u⟩ ≈ (3 / 2) · ( 534.573 · (ε/σ³) / (57.1464 · (ε/σ²))² ) · k_B · T
    ≈ (3 / 2) · ( 534.573 / 3265.71 ) · (σ / ε) · k_B · T
    ≈ 0.2455 · (σ / ε) · k_B · T
```

Коефіцієнт лінійного теплового розширення `α_T = (1 / r_min) · (d⟨u⟩ / dT)` дорівнює:

```
α_T = (1 / (2¹/⁶ σ)) · 0.2455 · (σ / ε) · k_B = (0.2455 / 1.12246) · (k_B / ε) ≈ 0.2187 · (k_B / ε)
```

Отже, асиметрія потенційної ями (ненульова третя похідна `g_anharm > 0`) є прямою математичною причиною теплового розширення тіл при нагріванні.

## 6. Геометрія кристалічних ґраток та решіткові суми Джонса — Інгама

При низьких температурах інертні гази (аргон, криптон, ксенон) утворюють гранецентровану кубічну ґратку (ГЦК / FCC). Для розрахунку макроскопічних властивостей кристала необхідно обчислити сумарну потенціальну енергію взаємодії одного атома з усіма іншими вузлами кристалічної ґратки.

Повна потенціальна енергія кристала у розрахунку на один атом задається виразом:

```
u_coul(a) = (1 / 2) · ∑_{j ≠ 0} V(r_0j) = 2 · ε · [ A₁₂ · (σ / a)¹² - A₆ · (σ / a)⁶ ]
```

де `a` — період кристалічної ґратки, а `A₁₂` та `A₆` — решіткові суми Джонса — Інгама (Jones-Ingham lattice sums), що визначаються геометрією ґратки: `A_m = ∑_{j ≠ 0} p_j⁻ᵐ` (де `p_j = r_0j / a` — безрозмірна відстань до `j`-го вузла).

### Порівняльний аналіз решіткових сум для різних кристалічних структур

Геометричний розрахунок решіткових сум для базових типів кристалічних ґраток дає наступні чисельні значення:

1. **Проста кубічна ґратка (Simple Cubic, SC)**:
   - Кількість найближчих сусідів: `z = 6`
   - Сума притягання: `A₆(SC) ≈ 8.40193`
   - Сума відштовхування: `A₁₂(SC) ≈ 6.20215`
   - Мінімум енергії зв'язку на атом: `u_min(SC) ≈ - 5.688 ε`
2. **Об'ємноцентрована кубічна ґратка (Body-Centered Cubic, BCC)**:
   - Кількість найближчих сусідів: `z = 8`
   - Сума притягання: `A₆(BCC) ≈ 12.2533`
   - Сума відштовхування: `A₁₂(BCC) ≈ 9.11418`
   - Мінімум енергії зв'язку на атом: `u_min(BCC) ≈ - 8.237 ε`
3. **Гранецентрована кубічна ґратка (Face-Centered Cubic, FCC)**:
   - Кількість найближчих сусідів: `z = 12`
   - Сума притягання: `A₆(FCC) ≈ 14.45392`
   - Сума відштовхування: `A₁₂(FCC) ≈ 12.13188`
   - Мінімум енергії зв'язку на атом: `u_min(FCC) ≈ - 8.6102 ε`
4. **Гексагональна щільноупакована ґратка (Hexagonal Close-Packed, HCP)**:
   - Кількість найближчих сусідів: `z = 12`
   - Сума притягання: `A₆(HCP) ≈ 14.45489`
   - Сума відштовхування: `A₁₂(HCP) ≈ 12.13229`
   - Мінімум енергії зв'язку на атом: `u_min(HCP) ≈ - 8.6111 ε`

Математичне порівняння значень `u_min` пояснює, чому інертні гази кристалізуються у щільноупаковані структури ГЦК та ГЩУ: максимальне координаційне число (`z = 12`) забезпечує найглибший енергетичний мінімум кристала (`-8.61 ε` проти `-5.69 ε` у простій кубічній). Урахування квантових нульових коливань кристалічної ґратки (фактор Дебая — Валлера) додатково стабілізує саме ГЦК-фазу для аргону, криптону та ксенону.

## 7. Виведення механічних властивостей: модуль об'ємного стиснення K, модуль Юнга E та стисливість κ_T

Для ГЦК-кристала елементарний кубічний осередок об'ємом `V_cell = a³` містить `Z = 4` атоми, тому об'єм речовини у розрахунку на один атом становить `v = a³ / 4`.

### Рівноважний параметр ґратки `a_eq` та енергія когезії

Мінімізуємо енергію за періодом ґратки `du_coul / da = 0`:

```
du_coul / da = 2 · ε · [ -12 · A₁₂ · σ¹² · a⁻¹³ + 6 · A₆ · σ⁶ · a⁻⁷ ] = 0 [умова рівноваги]
-12 · A₁₂ · (σ / a)⁶ + 6 · A₆ = 0   [поділено на множник 2·ε·σ⁶·a⁻⁷]
(σ / a_eq)⁶ = (6 · A₆) / (12 · A₁₂) = A₆ / (2 · A₁₂) [перенесено члени та скорочено дріб]
a_eq = ( (2 · A₁₂) / A₆ )¹/⁶ · σ     [взято обернену величину та корінь 6-го степеня]
```

Підставляючи чисельні суми `A₁₂ = 12.13188` та `A₆ = 14.45392`:

```
a_eq = ( (2 · 12.13188) / 14.45392 )¹/⁶ · σ = ( 24.26376 / 14.45392 )¹/⁶ · σ ≈ 1.0901 · σ
```

Обчислимо енергію когезії у точці рівноваги `u_coul(a_eq)`:

```
u_coul(a_eq) = 2 · ε · [ A₁₂ · (A₆ / (2·A₁₂))² - A₆ · (A₆ / (2·A₁₂)) ] [підставлено (σ/a_eq)⁶]
             = 2 · ε · [ (A₆² / (4·A₁₂)) - (A₆² / (2·A₁₂)) ]             [піднесено дріб до квадрата]
             = 2 · ε · ( - A₆² / (4 · A₁₂) )                              [обчислено різницю у дужках]
             = - ( A₆² / (2 · A₁₂) ) · ε                                 [скорочено 2 на 4]
             = - ( (14.45392)² / (2 · 12.13188) ) · ε                    [підставлено решіткові суми]
             = - ( 208.916 / 24.26376 ) · ε ≈ - 8.6102 · ε               [чисельний розрахунок значення]
```

Енергія зв'язку атома у кристалі (`-8.61 ε`) перевищує глибину парної ями (`-1.0 ε`), оскільки кожен атом взаємодіє з `12` сусідіми першої координаційної сфери та дальшими сферами.

### Виведення об'ємного модуля пружності `K`

Об'ємний модуль пружності визначається як `K = V · (d²U / dV²) = v_0 · (d²u / dv²)|_{v_0}`.

Враховуючи `v = a³ / 4`, похідна координати по об'єму дорівнює `da / dv = 1 / (3 · a² / 4) = 4 / (3 · a²)`.
Використовуючи правило диференціювання складеної функції:

```
d²u / dv² = d/dv [ (da/dv) · (du/da) ] = (d²a / dv²) · (du/da) + (da/dv)² · (d²u / da²)
```

Оскільки в точці рівноваги `v = v_0` перша похідна `du/da = 0`, перший доданок перетворюється на нуль:

```
(d²u / dv²)|_{v_0} = (da/dv)² · (d²u / da²)|_{a_eq} = ( 16 / (9 · a_eq⁴) ) · (d²u / da²)|_{a_eq}
```

Підставляючи це у формулу об'ємного модуля `K = v_0 · (d²u / dv²)` при `v_0 = a_eq³ / 4`:

```
K = (a_eq³ / 4) · ( 16 / (9 · a_eq⁴) ) · (d²u / da²)|_{a_eq} [підставлено v_0 та (da/dv)²]
  = ( 4 / (9 · a_eq) ) · (d²u / da²)|_{a_eq}                  [скорочено a_eq³ та 16/4]
```

Обчислимо другу похідну `d²u / da²` при `a = a_eq`:

```
d²u / da² = d/da [ 2ε · (-12 · A₁₂ · σ¹² · a⁻¹³ + 6 · A₆ · σ⁶ · a⁻⁷) ] [диференційовано першу похідну]
          = 2ε · [ 156 · A₁₂ · σ¹² · a⁻¹⁴ - 42 · A₆ · σ⁶ · a⁻⁸ ]       [взято похідні a⁻¹³ та a⁻⁷]
          = (12ε / a²) · [ 26 · A₁₂ · (σ/a)¹² - 7 · A₆ · (σ/a)⁶ ]      [винесено 6/a² за дужки]
```

Підставляємо `(σ / a_eq)⁶ = A₆ / (2 A₁₂)` та `(σ / a_eq)¹² = A₆² / (4 A₁₂²)`:

```
(d²u / da²)|_{a_eq} = (12ε / a_eq²) · [ 26 · A₁₂ · (A₆² / (4 A₁₂²)) - 7 · A₆ · (A₆ / (2 A₁₂)) ]
                    = (12ε / a_eq²) · [ (13 A₆² / (2 A₁₂)) - (7 A₆² / (2 A₁₂)) ] [скорочено A₁₂ та 26/4]
                    = (12ε / a_eq²) · [ (6 A₆²) / (2 A₁₂) ]                    [обчислено різницу у дужках]
                    = ( (36 · A₆²) / A₁₂ ) · (ε / a_eq²)                       [перемножено 12 на 3]
```

Тепер підставимо значення другої похідної у вираз модуля `K`:

```
K = ( 4 / (9 · a_eq) ) · ( (36 · A₆²) / A₁₂ ) · (ε / a_eq²) [підставлено другу похідну]
  = ( (16 · A₆²) / A₁₂ ) · (ε / a_eq³)                       [скорочено 36 на 9 та помножено 4 на 4]
```

Враховуючи `a_eq³ = ( (2 A₁₂) / A₆ )¹/² · σ³`:

```
K = ( (16 · A₆²) / A₁₂ ) · ( 1 / ( (2 A₁₂) / A₆ )¹/² ) · (ε / σ³) [підставлено a_eq³]
  = ( (16 · A₆⁵/²) / (√2 · A₁₂³/²) ) · (ε / σ³)                    [спрощено степені A₆ та A₁₂]
  = 8 · √2 · ( A₆⁵/² / A₁₂³/² ) · (ε / σ³)                         [раціоналізовано дріб 16/√2 = 8√2]
```

Підставляючи значення решіткових сум `A₆ = 14.45392` та `A₁₂ = 12.13188`:

```
A₆⁵/² = (14.45392)²·⁵ ≈ 787.584
A₁₂³/² = (12.13188)¹·⁵ ≈ 42.2571
K = 8 · 1.41421356 · ( 787.584 / 42.2571 ) · (ε / σ³)
  = 11.3137 · 18.6379 · (ε / σ³) ≈ 210.865 · (ε / σ³)
```

Об'ємний модуль пружності ГЦК-кристала Леннард-Джонса становить:

```
K ≈ 210.87 · (ε / σ³)
```

### Строгий тензорний розрахунок пружних констант `C_11, C_12, C_44`

Узагальнений закон Гука для кубічного кристала описується трьома незалежними тензорними модулями пружності `C_11`, `C_12` та `C_44`. Для парного центрального потенціалу Леннард-Джонса аналітичний розрахунок другої похідної по компонентах тензора деформації дає:

```
C_11 ≈ 335.63 · (ε / σ³)
C_12 ≈ 148.48 · (ε / σ³)
C_44 ≈ 148.48 · (ε / σ³)
```

Зверніть увагу: рівність `C_12 = C_44` є відомим співвідношенням Коші, яке строго виконується для будь-якої кристалічної ґратки з центральними парними силами взаємодії при `T = 0 К`.

Зв'язок між тензорними модулями та об'ємним модулем `K` підтверджує раніше отримане значення:

```
K = (C_11 + 2 · C_12) / 3 = (335.63 + 2 · 148.48) / 3 ≈ 210.86 · (ε / σ³)
```

### Ізотермічна стисливість `κ_T` та модуль Юнга `E`

Ізотермічна стисливість є оберненою величиною до об'ємного модуля пружності:

```
κ_T = 1 / K = ( 1 / 210.865 ) · (σ³ / ε) ≈ 0.004742 · (σ³ / ε)
```

Модуль Юнга `E` для кубічного кристала з коефіцієнтом Пуассона `ν = C_12 / (C_11 + C_12) ≈ 0.307` обчислюється через пружні константи:

```
E = (C_11 - C_12) · (C_11 + 2·C_12) / (C_11 + C_12) ≈ 242.15 · (ε / σ³)
```

У наближенні лише першої координаційної сфери `E ≈ 0.75 K ≈ 158.15 ε/σ³`.

## 8. Віріальне виведення рівняння стану та інтеграл Маєра

У статистичній термодинаміці рівняння стану реального газу подають віріальним розкладом Маєра:

```
P / (k_B T) = ρ + B₂(T) · ρ² + B₃(T) · ρ³ + ...
```

де `ρ = N / V` — числова густина, а `B₂(T)` — другий віріальний коефіцієнт, що визначається інтегралом Маєра:

```
B₂(T) = - (1 / 2) · ∫₀^∞ [ exp(- V(r) / (k_B T)) - 1 ] · 4πr² dr
```

### Точний розклад `B_2(T)` через Гамма-функції

Вводячи безрозмірну обернену температуру `β* = ε / (k_B T)`, після перетворення інтеграла через послідовні Гамма-функції `Γ(z)` отримуємо точний ряд:

```
B₂(T) = (2/3) · π · σ³ · (4 · β*)¹/⁴ · ∑_{k=0}^∞ ( 1 / (4 · k!) ) · Γ( (2k - 1) / 4 ) · (4 · β*)^{k/2}
```

### Фізичний зміст третього віріального коефіцієнта `B_3(T)`

Третій віріальний коефіцієнт `B_3(T)` враховує потрійні зіткнення частинок у помірно щільних газах. Він описується двовимірним інтегралом Маєра за конфігураціями трьох атомів `1, 2, 3`:

```
B_3(T) = - (1 / 3) · ∬ f_12 · f_23 · f_31 d³r_2 d³r_3
```

де `f_ij = exp(-V(r_ij)/(k_B T)) - 1` — майєрівська f-функція зв'язку. Додатне значення `B_3(T)` при помірних температурах відображає додатковий внутрішній тиск за рахунок потрійних відштовхувальних конфігурацій частинок у щільному середовищі.

### Температура Бойля `T_B` та критичні параметри флюїду

Температура Бойля `T_B` відповідає умові ідеальності другого віріального коефіцієнта `B₂(T_B) = 0`. Знаходження нуля цієї функції дає безрозмірну температуру Бойля:

```
T_B* = (k_B · T_B) / ε ≈ 3.418
```

При `T > T_B` маємо `B₂(T) > 0` (переважає короткодіюче відштовхування Паулі), а при `T < T_B` маємо `B₂(T) < 0` (переважає дальнодіюче притягання Лондона).

Збігання термодинамічних похідних другого та третього віріальних коефіцієнтів дозволяє аналітично знайти безрозмірні критичні параметри фазового переходу рідина — газ для Леннард-Джонсового флюїду: безрозмірна критична температура становить `T_c* = k_B T_c / ε ≈ 1.312`, критична числова густина `ρ_c* = ρ_c σ³ ≈ 0.316`, а критичний тиск `P_c* = P_c σ³ / ε ≈ 0.128`. Ці параметри слугують еталоном для перевірки молекулярно-динамічних симуляцій реальних газів.

### Зв'язок із константами Ван-дер-Ваальса

При високих температурах (`k_B T » ε`) розклад першого порядку дає:

```
B₂(T) ≈ (2/3) · π · σ³ · [ 1 - (4 · ε / (k_B T)) ]
```

Зіставляючи із віріальним записом рівняння Ван-дер-Ваальса `B₂(T) = b - (a / (R T))`, отримуємо мікроскопічний вираз для констант `a` та `b`:

```
b = (2/3) · π · N_A · σ³
a = (8/3) · π · N_A² · ε · σ³ = 4 · b · N_A · ε
```

Ці співвідношення дають змогу розраховувати атомні параметри `ε` та `σ` з виміряних критичних температур і тисків речовини.
