# 📋 Параметрична довідка політипів SiC та ZnS

Ця параметрична довідка містить систематизовані кристалографічні, електрофізичні, теплофізичні, оптичні та механічні константи найважливіших политипних модифікацій карбіду кремнію (4H-SiC, 6H-SiC, 3C-SiC, 15R-SiC, 2H-SiC, 8H-SiC, 21R-SiC), сульфіду цинку (ZnS) та дисульфіду молібдену (MoS₂). Вона призначена для використання під час розрахунку напівпровідникових приладів силової електроніки, моделювання зонної структури, TCAD-симуляції транспорту носіїв заряду та інтерпретації рентгеноструктурних і оптичних даних.

## 1. Контракт інтерфейсу та умови застосування параметрів

Для коректного використання поданих величин у фізичних розрахунках та числовому моделюванні напівпровідникових структур встановлюються такі базові інваріанти та вимірювальні умови:
- **Температурний режим:** Усі табличні значення констант (якщо не вказано інше) наведено для кімнатної температури `T = 300 K` (`27 °C`) при атмосферному тиску `101.3 кПа`.
- **Низькопольовий та високопольовий транспорт:** Значення рухливостей електронів та дірок `μ` відповідають границі низького електричного поля (`E < 10³ В/см`), де дрейфова швидкість носіїв прямо пропорційна полю `v_d = μ · E`. Значення критичного пробійного поля `E_br` та швидкості насичення `v_sat` наведено для високопольового режиму (`E > 10⁵ В/см`).
- **Рівень легування:** Значення рухливості та пробійного поля розраховані для власного напівпровідника або слаболегованих епітаксійних шарів з концентрацією активних домішок `N_D - N_A ≤ 10¹⁶ см⁻³`. При зростанні концентрації носіїв рухливість зменшується внаслідок розсіювання на іонізованих домішках за детализованими моделями, наведеними в §7.
- **Орієнтація кристаллографічних осей:** Індекс `|| c` (паралельно) відповідає транспорту уздовж головної кристаллографічної осі `c` (напрямок `[0001]` у гексагональній та `[111]` у кубічній системі). Індекс `⊥ c` (перпендикулярно) відповідає транспорту у базисній площині `(0001)` (напрямки `[11-20]` та `[1-100]`).

### Кристалофізичний розбір геометрії ґратки
- **Нормоване відношення осей `(c/a) / N`:** У кубічному политипі 3C елементарна комірка описується трансляційним вектором осей `a_cubic = 4.3596 Å`. У гексагональній системі координат цей кубічний кристал можна представити еквівалентною гексагональною коміркою з параметром `a = a_cubic / √2 = 3.0827 Å` та `c = a_cubic · √3 = 7.5511 Å` (для 3 шарів), що дає нормоване значення `(c/a)/3 = √(8/3) = 1.632993`. У гексагональних політипах 2H, 4H, 6H збільшення частки гексагональних шарів `α_h` призводить до стиснення ґратки уздовж осі `c` та незначного розширення в базисній площині `(0001)`. Для 2H-SiC нормоване відношення становить `1.6409`, що на `0.5%` перевищує ідеальне кубічне значення.
- **Деформація ковалентних тетраедрів:** Ковалентний зв'язок між атомами Si та C у кубічному політипі 3C має строго однакову довжину `1.89 Å` для всіх чотирьох напрямків тетраедра. У гексагональних політипах (4H, 6H) тетраедри злегка витягнуті уздовж осі `c`. Аксиальний зв'язок `d_ax` уздовж осі `c` коротший або довший за три екваторіальні зв'язки `d_eq` у базисній площині на `0.1–0.3%`. Ця мікроскопічна геодеформація викликає внутрішній електростатичний дипольний момент на кожному подвійному шарі Si-C.
- **Просторові групи та п'єзоелектричний ефект:** Кубічний политип 3C має високосиметричну просторову групу `F-43m` (№ 216), позбавлену центросиметричності, але анізотропія тензорів другого рангу (зокрема діелектричної проникності та електропровідності) у ньому повністю відсутня. Гексагональні політипи 2H, 4H, 6H, 8H належать до полярної просторової групи `P6_3mc` (№ 186). У цих кристалах наявність нееквівалентних гексагональних шарів створює незкомпенсований вектор спонтанної електричної поляризації `P_sp` вздовж осі `c`. Це викликає внутрішні п'єзоелектричні поля та впливає на розщеплення енергетичних рівнів домішок.

## 3. Енергетичний спектр зонної структури та параметри Аберніті

Енергетичний спектр електронних станів политипів карбіду кремнію визначається локальним оточенням атомів у найближчих та наступних координаційних сферах. Перехід від кубічного укладання (0% гексагональності) до гексагонального (100% гексагональності) не лише змінює абсолютну ширину забороненої зони `E_g`, але й перебудовує топологію зони провідності та знімає виродження вершини валентної зони.

### Функціональна модель Аберніті для политипів SiC
У фізиці напівпровідникових политипів модель Аберніті (Abernathy parameterization) встановлює кількісний зв'язок між ступенем гексагональності `α_h` та фундаментальними параметрами зонної структури. Аберніті запропонував феноменологічні співвідношення, що описують нелінійне зростання ширини забороненої зони `E_g(α_h)` та внутрішнього кристалічного розщеплення валентної зони `Δ_cr(α_h)` через вклад локальних гексагональних блоків:

```
E_g(α_h) = E_g(3C) + ΔE_max · [1 - exp(-A_1 · α_h)]
Δ_cr(α_h) = Δ_cr(2H) · (α_h / 100%)^A_2
```

де `E_g(3C) = 2.36 еВ` — базова ширина забороненої зони кубічного политипу, `ΔE_max = 0.97 еВ` — максимальний приріст ширини зони при переході до 2H-SiC, `A_1 = 1.85` — емпіричний параметр нелінійності Аберніті, `Δ_cr(2H) = 340 меВ` — кристалічне розщеплення 2H-SiC, а `A_2 = 1.12` — параметр зростання анізотропії кристалічного поля за Аберніті.

### Фізичні механізми трансформації зонного спектра
- **Згортання зон Бріллюена (Zone Folding):** Збільшення періоду елементарної комірки вздовж осі `c` у `N` разів зменшує розмір зони Бріллюена у напрямку `Γ-A` в `N` разів. Внаслідок цього дисперсійні криві електронного спектра кубічної ґратки «згортаються» у зменшену зону Бріллюена. Це призводить до виникнення мінімумів зони провідності в різних точках оберненого простору: в X-точці для 3C-SiC, у M-точці для 4H-SiC та уздовж лінії M-L для 6H-SiC.
- **Розщеплення валентної зони кристалічним полем `Δ_cr`:** У кубічному політипі 3C-SiC вершина валентної зони в точці `Γ` є трикратно виродженою (без урахування спіну) і розщеплюється лише спін-орбітальною взаємодією на `Δ_so = 10.3 меВ`. У гексагональних політипах внутрішнє анізотропне кристалічне поле знімає виродження між `p_z`-орбіталями та `(p_x, p_y)`-орбіталями атомів Вуглецю та Кремнію. У 4H-SiC кристалічне розщеплення сягає `330 меВ`, що у 12 разів перевищує теплову енергію `k_B · T` при кімнатній температурі. Це витісняє дірки на найвищу підзону легких дірок та суттєво зменшує їх ефективну масу у базисній площині.
- **Фізична інтерпретація зсуву Аберніті `ΔE_Ab`:** Аберніті обґрунтував, що зміна забороненої зони диктується не лише лінійною пропорційністю кількості гексагональних шарів, а й взаємодією хвильових функцій електронів з потенціальними бар'єрами сусідніх `h`-шарів. У кристалічній ґратці 4H-SiC зсув Аберніті складає `0.90 еВ`, розширюючи зону з `2.36 еВ` (3C) до `3.26 еВ` (4H). Для 15R-SiC зсув становить `0.62 еВ`, що узгоджується зі ступенем гексагональності `40%`.

### Фізичний розбір анізотропії транспорту та пробійного поля
- **Парадокс рухливості 6H-SiC проти 4H-SiC:** У політипі 6H-SiC паралельна рухливість електронів `μ_n,par = 100 см²/В·с` є в 4.5 раза нижчою за перпендикулярну `μ_n,perp = 450 см²/В·с`. Причиною цього є утворення глибоких потенціальних бар'єрів на межах між кубічними та гексагональними блоками `h k k | h k k`, що викликає додаткове Бреґґівське відбивання електронних хвиль уздовж осі `c` та збільшує поздовжню ефективну масу до `m_n,par* = 1.42 m_0`. У 4H-SiC симетричне регулярне чергування `h k h k` усуває потенціальні ями, забезпечуючи `μ_n,par = 1150 см²/В·с` та анізотропію `1.21`. Саме це робить 4H-SiC єдиним оптимальним политипом для вертикальних силових транзисторів з дрейфовим струмом вздовж осі `c`.
- **Залежність пробійного поля від ширини забороненої зони:** Критичне поле електричного пробою `E_br` зростає з шириною забороненої зони за квадратичним законом `E_br ∝ E_g^2`. Перехід від кремнію (`E_g = 1.12 еВ`, `E_br = 0.3 МВ/см`) до 4H-SiC (`E_g = 3.26 еВ`, `E_br = 3.0 МВ/см`) підвищує електричну міцність у 10 разів. Це дозволяє зменшити товщину дрейфового шару силового приладу в 10 разів та знизити питомий опір у відкритому стані `R_DS(on)` у сотні разів.
- **Розсіювання на акустичних та оптичних фононах:** При високих температурах дрейфова рухливість обмежується непружним розсіюванням на полярних оптичних фононах (LO-фонони з енергією `120 меВ`). Завдяки високій частоті LO-фононів у SiC електрон залишається в режимі низького розсіювання при напруженостях полів до `10⁴ В/см`, що забезпечує збереження високої швидкості дрейфу при високій питомій потужності.

## 5. Моделі імпуритивного легування та енергії іонізації домішок (h та k позиції)

У політипах SiC атоми домішок можуть заміщувати Кремній або Вуглець у нееквівалентних кристалографічних позиціях: гексагональних `h` або кубічних `k`. Оскільки локальний електростатичний потенціал та відстані до сусідніх шарів у них відрізняються, енергії іонізації тих самих домішкових атомів у позиціях `h` та `k` є суттєво різними.

У таблиці наведено енергії іонізації основних донорів (Азот N, Фосфор P) та акцепторів (Алюміній Al, Бор B) для різних кристалографічних вузлів.

### Фізичні наслідки нееквівалентності вузлів ґратки
- **Неповна іонізація азотних донорів при 300 K:** У 4H-SiC азот створює неглибокий рівень `N(h)` з енергією `60 меВ` та більш глибокий рівень `N(k)` з енергією `125 меВ`. За кімнатної температури теплова енергія `k_B · T = 25.9 меВ` повністю іонізує донори у гексагональних вузлах, тоді як донори у кубічних вузлах іонізовані лише частково (~40%). Це вимагає урахування статистичного розподілу Фермі-Дірака при розрахунку концентрації вільних електронів:

```
n = N_D(h) / [1 + 2 · exp((E_F - E_D(h)) / k_B T)] + N_D(k) / [1 + 2 · exp((E_F - E_D(k)) / k_B T)]
```

- **Висока енергія акцепторів Алюмінію:** Алюміній створює акцепторні рівні з енергією `191–215 меВ` у 4H-SiC. При кімнатній температурі іонізується менше 5% введеної домішки Алюмінію. Для досягнення високої p-провідності в силових приладах вимагається висока концентрація легування (`> 10¹⁹ см⁻³`) або температура відпалу понад `1600 °C`.
- **Вплив D-центрів Бору:** При легуванні бором, окрім неглибокого акцепторного рівня `300 меВ`, утворюється глибокий комплексний центр (D-центр) з енергією залегання `650 меВ`. Цей центр діє як ефективний центр безвипромінювальної рекомбінації носіїв, що сильно скорочує час життя невашонних носіїв у p-i-n діодах.

Висока модуль Юнга (`~470 ГПа`) забезпечує стійкість підкладок SiC до термоударів та механічного деформування при механічній обробці зливків.

## 7. Параметри для TCAD-моделювання та температурні залежності

Для комп'ютерного моделювання напівпровідникових приладів у пакетах TCAD (Synopsys Sentaurus, Silvaco Atlas) використовуються аналітичні температурні та польові залежності матеріальних параметрів 4H-SiC та 6H-SiC.

### 1. Модель температурної зміни ширини забороненої зони (Варшні)
Звуження забороненої зони зі зростанням температури внаслідок теплового розширення ґратки та електрон-фононної взаємодії описується формулою Варшні:

```
E_g(T) = E_g(0) - (α_V · T²) / (T + β_V)
```

Параметри моделі Варшні для политипів SiC:
- **4H-SiC:** `E_g(0) = 3.285 еВ`, `α_V = 6.5 · 10⁻⁴ еВ/K`, `β_V = 1300 K`.
- **6H-SiC:** `E_g(0) = 3.053 еВ`, `α_V = 6.0 · 10⁻⁴ еВ/K`, `β_V = 1200 K`.
- **3C-SiC:** `E_g(0) = 2.390 еВ`, `α_V = 5.8 · 10⁻⁴ еВ/K`, `β_V = 1100 K`.

### 2. Залежність рухливості від легування та температури (Модель Масетті)
Зменшення рухливості електронів `μ_n` при кімнатній температурі залежно від сумарної концентрації домішок `N_total = N_D + N_A` описується формулою Масетті:

```
μ_n(N_total) = μ_min + (μ_max - μ_min) / [1 + (N_total / N_ref)^γ_m]
```

Калібровані параметри моделі Масетті для 4H-SiC (⊥ c):
- `μ_max = 950 см²/В·с` (рухливість у чистому кристалі);
- `μ_min = 40 см²/В·с` (гранична рухливість при сильному легуванні);
- `N_ref = 2.0 · 10¹⁷ см⁻³` (характерна концентрація переходу);
- `γ_m = 0.76` (показник розмиття переходу).

Температурна деградація рухливості при `T > 300 K` враховується степеневим співвідношенням:

```
μ_n(T) = μ_n(300 K) · (T / 300)^(-γ_T)
```
де для 4H-SiC показник степеня становить `γ_T = 2.15` (для транспорту || c) та `γ_T = 2.25` (для ⊥ c).

### 3. Модель ударної іонізації та лавинного пробою (Чиновет)
Коефіцієнти ударної іонізації електронів `α_n` та дірок `α_p` визначають умови лавинного пробою p-n переходів і описуються рівнянням Чиновета:

```
α_n(E) = a_n · exp(-b_n / E)
α_p(E) = a_p · exp(-b_p / E)
```

Калібровані константи Чиновета для 4H-SiC при `T = 300 K`:
- **Електрони:** `a_n = 1.76 · 10⁶ см⁻¹`, `b_n = 1.75 · 10⁷ В/см`.
- **Дірки:** `a_p = 3.41 · 10⁶ см⁻¹`, `b_p = 1.16 · 10⁷ В/см`.

Оскільки `b_p < b_n`, дірки в 4H-SiC мають вищий коефіціент ударної іонізації, ніж електрони (`α_p > α_n`). Це означає, що лавинний пробій силових діодів Шотткі та MOSFET на основі 4H-SiC ініціюється переважно дірковою компонентою струму.

### 4. Модель високопольового насичення дрейфової швидкості (Когі-Томас)
При високих напруженостях електричного поля `E > 10⁴ В/см` дрейфова швидкість носіїв `v_d(E)` відхиляється від лінійного закону `μ · E` внаслідок інтенсивного випромінювання оптичних фононів і прямує до асимптотичної швидкості насичення `v_sat`. TCAD-симулятори моделюють цей ефект формулою Когі-Томаса (Caughey-Thomas model):

```
v_d(E) = (μ · E) / [1 + (μ · E / v_sat)^β_ct]^(1 / β_ct)
```

Калібровані параметри Когі-Томаса для електронів у 4H-SiC (⊥ c):
- `v_sat = 2.0 · 10⁷ см/с` — швидкість насичення при 300 K;
- `β_ct = 1.2` — показник крутизни насичення;
- `E_c = v_sat / μ = 2.1 · 10⁴ В/см` — критична напруженість поля початку насичення.
