# 🧮 Квантово-розмірне обмеження та виведення рівняння Бруса

Ця вставка містить детальний квантовомеханічний вивід енергетичного спектра носіїв заряду у сферичній напівпровідниковій наночастинці, математичне розв'язання рівняння Шредінгера у сферичних координатах, урахування скінченності потенціального бар'єра, теорію збурень для Кулонівської взаємодії та екранування, а також аналіз непараболічності зон та чисельні приклади для п'яти фундаментальних напівпровідникових матеріалів.

---

## 1. Рівняння Шредінгера у сферично-симетричному потенціалі

Розглянемо електрон або дірку з ефективною масою `m*` у сферичному нанокристалі радіуса `R`. Для ідеалізованого випадку потенціального бар'єра нескінченної висоти геометрична межа частинки задається умовою:

```
V(r) = 0,   якщо r ≤ R
V(r) = ∞,   якщо r > R
```

У стаціонарному рівнянні Шредінгера у сферичній системі координат `(r, θ, φ)` оператор Лапласа `∇²` розкладається на радіальну та кутову частини:

```
[- (ℏ² / 2m*) · (1/r² · ∂/∂r (r² · ∂/∂r) + (1 / r² · sin θ) · ∂/∂θ (sin θ · ∂/∂θ) + 1 / (r² · sin² θ) · ∂²/∂φ²) + V(r)] Ψ = E · Ψ
```

Завдяки сферичній симетрії потенціального поля `V(r) = V(|r|)` повний момент імпульсу частинки збережеться, а хвильова функція шукається у вигляді відокремлених змінних:

```
Ψ_{n,l,m}(r, θ, φ) = R_{n,l}(r) · Y_{l,m}(θ, φ)
```

де `Y_{l,m}(θ, φ)` — нормовані сферичні гармоніки (власні функції операторів `L²` та `L_z`), `l = 0, 1, 2, ...` — орбітальне квантове число, `m = -l, ..., +l` — магнітне квантове число, `n = 1, 2, 3, ...` — головне радіальне квантове число.

Підстановка хвильової функції дає таке радіальне диференціальне рівняння другого порядку для функції `R_{n,l}(r)` усередині кулі (`r ≤ R`):

```
d²R/dr² + (2/r) · dR/dr + [k² - l(l+1)/r²] R = 0
```

де хвильовий вектор `k` пов'язаний із шуканою кінетичною енергією частинки `E`:

```
k = √(2 · m* · E) / ℏ
```

Шляхом заміни змінних `x = k·r` радіальне рівняння зводиться до стандартного рівняння Бесселя для півцілого індексу `l + 1/2`. Загальний розв'язок є лінійною комбінацією сферичних функцій Бесселя першого роду `j_l(x)` та другого роду (функцій Ноймана) `y_l(x)`:

```
R_{n,l}(r) = A_{n,l} · j_l(k_{n,l} · r) + B_{n,l} · y_l(k_{n,l} · r)
```

Оскільки сферична функція Ноймана `y_l(k·r)` прямує до мінус нескінченності в центрі кулі при `r → 0` (наприклад, `y_0(x) = -cos(x)/x`), умова фізичної скінченності хвильової функції у центрі вимагає суворого покладення `B_{n,l} = 0`. Отже, радіальний розв'язок задається виключно функцією Бесселя:

```
R_{n,l}(r) = A_{n,l} · j_l(k_{n,l} · r)
```

Гранична умова нескінченно високого бар'єра вимагає повного обнулення хвильової функції на зовнішній поверхні кулі (`r = R`):

```
j_l(k_{n,l} · R) = 0
```

Отже, дозволені дискретні значення хвильового числа `k_{n,l}` визначені коренями сферичних функцій Бесселя:

```
k_{n,l} = χ_{n,l} / R
```

де `χ_{n,l}` позначає `n`-й додатний корінь сферичної функції Бесселя `j_l(x)`.

## 2. Енергетична спектроскопія та оболонкова структура «штучного атома»

Знайшовши `k_{n,l}`, отримуємо точний квантований спектр кінетичної енергії частинки у кулі:

```
E_{n,l} = (ℏ² · χ_{n,l}²) / (2 · m* · R²)
```

Розглянемо найнижчі за енергією квантові стани:

### Основний стан S-оболонки (l = 0, n = 1)
Сферична функція Бесселя нульового порядку виражається через елементарну синусоїду:

```
j_0(x) = sin(x) / x
```

Рівняння `j_0(χ) = 0` зводиться до `sin(χ) = 0`. Перший додатний корінь:

```
χ_{1,0} = π ≈ 3.14159265
```

Енергія основного `1S`-стану частинки дорівнює:

```
E_{1,0} = (ℏ² · π²) / (2 · m* · R²)
```

Нормована хвильова функція основного стану має сферично-симетричний вигляд:

```
Ψ_{1,0,0}(r) = (1 / √(2 · π · R)) · (sin(π · r / R) / r)
```

### Перший збуджений стан P-оболонки (l = 1, n = 1)
Сферична функція Бесселя першого порядку:

```
j_1(x) = sin(x) / x² - cos(x) / x
```

Рівняння `j_1(χ) = 0` еквівалентне трансцендентному рівнянню `tan(χ) = χ`. Перший додатний корінь:

```
χ_{1,1} ≈ 4.49340945
```

Енергія `1P`-стану перевищує енергію `1S`-стану в `(4.4934 / π)² ≈ 2.04` раза:

```
E_{1,1} = (4.4934² / π²) · E_{1,0} ≈ 2.044 · E_{1,0}
```

### Другий збуджений стан D-оболонки (l = 2, n = 1)
Для `l = 2` функція Бесселя `j_2(x) = (3/x³ - 1/x) · sin(x) - (3/x²) · cos(x)`. Перший корінь:

```
χ_{1,2} ≈ 5.76345920
```

Енергія `1D`-стану: `E_{1,2} ≈ 3.37 · E_{1,0}`.

Сводна таблиця параметрів квантованих оболонок наведена нижче:

```
Стан    l   Орбіталь    χ_{n,l}   E / E_{1S}   Просторове виродження   Повне виродження (+спін)
-----------------------------------------------------------------------------------------
1S      0   S-оболонка  3.1416    1.000        1 (m=0)                 2
1P      1   P-оболонка  4.4934    2.044        3 (m=-1,0,+1)           6
1D      2   D-оболонка  5.7635    3.371        5 (m=-2..+2)            10
2S      0   S-оболонка  6.2832    4.000        1 (m=0)                 2
1F      3   F-оболонка  6.9879    4.943        7 (m=-3..+3)            14
```

## 3. Кінетичний доданок розмірного обмеження (ΔE_conf)

Під час оптичного поглинання фотон народжує пара електрон-дірка. У наближенні ефективної маси вважаємо, що електрон перебуває в зоні провідності з масою `m_e*`, а дірка — у валентній зоні з масою `m_h*`.

Енергія квантового обмеження обох частинок у найнижчому оптичному переході `1S_e - 1S_h` обчислюється шляхом додавання кінетичних енергій обох частинок:

```
ΔE_conf
= E_{1,0}^e + E_{1,0}^h                                       [сума енергій квантування електрона й дірки]
= (ℏ² · π²) / (2 · m_e* · R²) + (ℏ² · π²) / (2 · m_h* · R²)    [підстановка виразу енергії 1S-стану]
= (ℏ² · π²) / (2 · R²) · (1/m_e* + 1/m_h*)                     [винесення спільних множників]
= (ℏ² · π²) / (2 · μ* · R²)                                    [визначення зведеної маси μ*]
```

де `μ*` — зведена ефективна маса екситона:

```
μ* = (m_e* · m_h*) / (m_e* + m_h*)
```

Кінетичний доданок `ΔE_conf ∝ +1/R²` завжди додатний і зростає квадратично зі зменшенням радіуса, що розсуває рівні й створює синій зсув оптичного поглинання.

## 4. Скінченність потенціального бар'єра та проникання хвильових функцій

У реальних нанокристалах потенціальний бар'єр `V_0` на межі напівпровідник-матриця є скінченним (типово від 1.5 до 4.0 еВ). За межами кулі (`r > R`) хвильова функція не дорівнює нулю, а експоненційно загасає:

```
R_{out}(r) = C · k_K(κ · r) = C · (exp(-κ · r) / r)
```

де `κ = √(2 · m_{out}* · (V_0 - E)) / ℏ` — коефіцієнт загасання у матриці.

Зшивання хвильової функції та її першої похідної на межі `r = R` дає трансцендентне рівняння для допустимих значень `k`:

```
1 - k · R · cot(k · R) = (m_in* / m_out*) · (1 + κ · R)
```

Математичний наслідок скінченності бар'єра полягає у тому, що частина електронної густини тунелює за межі нанокристала у навколишню матрицю. Це підвищує ефективний радіус ями й дещо зменшує кінетичний доданок `ΔE_conf` на 10–25% порівняно з моделлю нескінченного бар'єра.

## 5. Кулонівська взаємодія та поляризаційний доданок

Оскільки електрон і дірка затиснуті у нанометровому об'ємі, їхнє електростатичне притягання є дуже сильним. Розрахунок оператора Кулонівського потенціалу проводиться за першим порядком теорії збурень:

```
V_{Coulomb}(r_e, r_h) = - e² / (4 · π · ε₀ · ε_r · |r_e - r_h|)
```

Матричний елемент на хвильових функціях основного `1S`-стану:

```
ΔE_Coulomb = - ∬ |Ψ_{1S}(r_e)|² · [e² / (4π ε₀ ε_r |r_e - r_h|)] · |Ψ_{1S}(r_h)|² d³r_e d³r_h
```

Розкладаючи зворотну відстань `1/|r_e - r_h|` за поліномами Лежандра `P_l(cos γ)` у сферичних гармоніках та інтегруючи по об'єму кулі радіуса `R`, отримуємо точний аналітичний вираз:

```
ΔE_Coulomb = - 1.786 · e² / (4 · π · ε₀ · ε_r · R)
```

Кулонівське притягання зменшує енергію переходу (червоний зсув) і масштабується як `-1/R`.

Крім того, Луїс Брус урахував поляризаційну взаємодію носіїв із наведеними поверхневими зарядами на межі з диелектричним розчинником чи матрицею (`ε_out`). Поляризаційна енергія самодії додає постійну поправку:

```
ΔE_pol ≈ - 0.248 · E_Ry*
```

де `E_Ry* = (μ* · e⁴) / (2 · (4π ε₀ ε_r)² · ℏ²)` — ефективна рідбергівська енергія екситона.

## 6. Підсумкове рівняння Бруса

Остаточне **рівняння Бруса** для ефективної ширини забороненої зони квантової точки `E_g(R)` має вигляд:

```
E_g(R) = E_{g,0} + (ℏ² · π²) / (2 · R²) · (1/m_e* + 1/m_h*) - 1.786 · e² / (4 · π · ε₀ · ε_r · R) - 0.248 · E_Ry*
```

### Параметри матеріалів (при 300 K):
1. **Селенід кадмію (CdSe):** `E_{g,0} = 1.74 eV`, `m_e* = 0.13 m_0`, `m_h* = 0.45 m_0`, `ε_r = 9.3`, `μ* = 0.101 m_0`.
