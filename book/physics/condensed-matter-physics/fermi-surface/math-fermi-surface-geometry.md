# 🧮 Геометрія поверхні Фермі та обчислення циклотронної маси

Ця вставка містить детальні математичні виведення геометрії поверхні Фермі у моделі сильного зв'язку, геометричне доведення умови ортогональності контакта з межами зон Бріллюена, квазікласичне виведення умови квантування Онсагера для площі екстремального перерізу `A(E, k_z)` у магнітному полі, аналітичний вивід циклотронної ефективної маси `m_c*`, аналіз сприйнятливості Ліндгарда, математичну класифікацію топологічних переходів Ліфшиця, квантове виведення фази Беррі та рівняння аномального скін-ефекту Піппарда.

---

## 1. Поверхня Фермі у моделі сильного зв'язку на двовимірній квадратній ґратці

Розглянемо двовимірну квадратну ґратку з періодом `a`. У наближенні сильного зв'язку (tight-binding model), враховуючи лише перескоки електронів між найближчими сусідніми атомами з інтегралом перескоку `t > 0`, закон дисперсії електронної зони має вигляд:

```
E(k_x, k_y) = E_0 - 2 · t · (cos(k_x · a) + cos(k_y · a))
```

де `E_0` — енергія ізольованого атомного рівня, а `k_x, k_y ∈ [-π/a, π/a]` належать першій зоні Бріллюена. Для спрощення покладемо точку відліку енергії `E_0 = 0`.

Рівняння поверхні (лінії) Фермі задається невиявним виразом `E(k_x, k_y) = E_F`. Проаналізуємо топологію контуру Фермі залежно від ступеня заповнення зони (значення енергії Фермі `E_F`):

### 1. Дно зони (E_F ≈ -4t) — Параболічне наближення
При низькій концентрації електронів хвильові вектори є малими (`k_x · a, k_y · a << 1`). Розкладаючи косинуси у ряд Тейлора `cos(x) ≈ 1 - x²/2 + x⁴/24`, отримуємо:

```
E(k_x, k_y) ≈ -4 · t + t · a² · (k_x² + k_y²) - (t · a⁴ / 12) · (k_x⁴ + k_y⁴)
```

Ввівши ефективну масу на дні зони `m* = ℏ² / (2 · t · a²)`, у квадратичному наближенні вираз набуває стандартного параболічного вигляду ізотропного електронного газу:

```
E(k_x, k_y) = -4 · t + (ℏ² / (2 · m*)) · (k_x² + k_y²)
```

Ізоенергетичні лінії `E(k_x, k_y) = E_F` у цьому ліміті є **колами** з радіусом `k_F = √(2 · m* · (E_F + 4t)) / ℏ`. Поверхня Фермі є сферично-симетричною (кола у 2D).

Тензор оберненої ефективної маси визначається другими похідними від закону дисперсії:

```
(m*-¹) = (1 / ℏ²) · ║ ∂²E / ∂k_i ∂k_j ║
```

На дні зони діагональні компоненти дорівнюють `m_xx* = m_yy* = ℏ² / (2 t a²)`.

### 2. Половинне заповнення (E_F = 0) — Точка переходів та нестинг
Коли енергія Фермі дорівнює точно нулю (`E_F = 0`), рівняння лінії Фермі набуває вигляду:

```
cos(k_x · a) + cos(k_y · a) = 0
```

Використовуючи тригонометричну тотожність `cos(α) + cos(β) = 2 · cos((α+β)/2) · cos((α-β)/2)`, маємо умови:

```
k_y · a = ± π ± k_x · a
```

Ці чотири прямі лінії утворюють повернутий на 45° квадрат (ромб), кути якого торкаються точок `(±π/a, 0)` та `(0, ±π/a)` на межах зони Бріллюена.

Цей контур володіє унікальною топологічною властивістю — **ідеальним нестингом** (англ. *nesting*). Будь-яка ділянка лінії Фермі суміщається з протилежною ділянкою шляхом зсуву на єдиний хвильовий вектор **вектора нестингу**:

```
Q = (± π/a, ± π/a)
```

Наявність нестингу призводить до дивергенції статичної сприйнятивності Ліндгарда `χ(Q) → ∞` та провокує нестабільність електронного газу з утворенням хвилі зарядової густини (CDW) або хвилі спінової густини (SDW).

### 3. Верхня частина зони (E_F > 0) — Діркові орбіти
При подальшому заповненні зони (`E_F > 0`) ізоенергетичні контури розриваються у квадратні порожнини з центром у кутах зони Бріллюена `(±π/a, ±π/a)`. Заповненими є стани **поза** цими контурами, а всередині знаходяться незаповнені стани. Електрони поблизу цих меж поводяться як носії з негативною ефективною масою — **дірки**.

## 2. Перпендикулярність нормалі поверхні Фермі до межі зони Бріллюена

Доведемо фундаментальну геометричну теорему: **поверхня Фермі завжди перетинає межу зони Бріллюена під прямим кутом (90°)** у кристалах із симетрією інверсії часового руху та просторовою інверсією.

Групова швидкість електрона задається градієнтом енергії у `k`-просторі:

```
v_k = (1 / ℏ) · ∇_k E(k)
```

Нормаль до межі зони Бріллюена задається вектором оберненої ґратки `G`. Межа зони визначена плоскою Брегга:

```
k · G = (1 / 2) · G²
```

З симетрії кристала відносно інверсії часу випливає `E(k) = E(-k)`. Додатково, операція трансляції на вектор оберненої ґратки дає періодичність `E(k + G) = E(k)`.

Розглянемо точку `k_B`, що лежить безпосередньо на межі зони Бріллюена. Відбиття цієї точки від площини Брегга дає точку `k_B' = k_B - G`. Зі міркувань симетрії кристала:

```
E(k_B + Δk_normal) = E(k_B - Δk_normal)
```

Беручи похідну по нормальній координаті на самій межі (`Δk_normal = 0`):

```
(∂E / ∂k_normal)_{k = k_B} = - (∂E / ∂k_normal)_{k = k_B}
2 · (∂E / ∂k_normal)_{k = k_B} = 0   ⇒   ∇_k E(k) · n̂_boundary = 0
```

Оскільки вектор нормалі до поверхні Фермі є паралельним до градієнта `∇_k E(k)`, а компонент градієнта уздовж нормалі до межі дорівнює нулю, вектор нормалі поверхні Фермі лежить **у площині межі**. Це означає, що поверхня Фермі перетинає межу зони Бріллюена під кутом 90°.

## 3. Математичний вивід умови квантування Онсагера та циклотронної маси

Розглянемо рух електрона у квазіімпульсному `k`-просторі під дією однорідного магнітного поля `B = (0, 0, B)`, спрямованого уздовж осі `z`.

Рівняння руху Лоренца у `k`-просторі має вигляд:

```
ℏ · (dk / dt) = -e · (v_k × B)
```

Оскільки сила Лоренца є перпендикулярною до швидкості `v_k = (1/ℏ) · ∇_k E`, енергія електрона `E(k)` та поздовжня складова квазіімпульсу `k_z` зберігаються:

```
E(k) = const = E_F,    k_z = const
```

Траєкторія електрона у `k`-просторі є перетином поверхні Фермі площиною `k_z = const`.

### 1. Квантування площі за Бором — Зоммерфельдом
Згідно з квантовою механікою, квазікласичний рух вздовж замкненого контуру в фазовому просторі підпорядковується правилу квантування Бора — Зоммерфельда:

```
∮ p · dq = (n + γ) · 2 · π · ℏ
```

Для частинки в магнітному полі з векторним потенціалом `A` канонічний імпульс дорівнює `P = ℏ · k - e · A`. Проінтегрувавши вздовж орбіти у реальному просторі та скориставшись зв'язком `dr = -(ℏ / (e · B²)) · (B × dk)`, фазовий інтеграл зводиться до інтеграла по площі `A(E, k_z)` у `k`-просторі:

```
∮ P · dr = ℏ · (e · B / ℏ²) · A(E, k_z) = e · B · A(E, k_z)
```

Отримуємо рівняння квантування площі Онсагера:

```
A(E_n, k_z) = (2 · π · e · B / ℏ) · (n + γ)
```

де `n ∈ N` — ціле квантове число (номер рівня Ландау), а `γ ∈ [0, 1/2]` — фазовий зсув. Для параболічного електронного газу `γ = 1/2`, а для діраківських ферміонів у графіті чи топологічних ізоляторах `γ = 0` завдяки топологічній фазі Беррі `Φ_B = π`.

Різниця площ між сусідніми рівнями Ландау є постійною величиною:

```
ΔA = A(E_{n+1}) - A(E_n) = 2 · π · e · B / ℏ
```

Магнітна сприйнятливість та опір отримують виражені осцилюючі вклади кожного разу, коли рівень Ландау перетинає поверхню Фермі. Екстремальне значення площі `A_ext` задає період осциляцій по оберненому полю `Δ(1/B)`:

```
Δ(1/B) = 2 · π · e / (ℏ · A_ext)   ⇒   F = (ℏ / (2 · π · e)) · A_ext
```

### 2. Точне виведення циклотронної ефективної маси
Період обертання електрона по циклотронній орбіті у `k`-просторі дорівнює часу проходження вздовж замкненої кривої `C`:

```
T_c = ∮_C dt = ∮_C (dk_perpendicular / (dk_perpendicular / dt))
```

З рівняння руху Лоренца маємо абсолютне значення швидкості зміни `k`:

```
ℏ · (dk_perpendicular / dt) = e · |v_perpendicular| · B   ⇒   dt = (ℏ² / (e · B)) · (dk_perpendicular / |∇_k E|)
```

Отже, циклотронний період дорівнює:

```
T_c = (ℏ² / (e · B)) · ∮_C (dk_perpendicular / |∇_k E|)
```

Розглянемо дві близькі ізоенергетичні орбіти з енергіями `E` та `E + dE` у площині `k_z = const`. Елемент площі між цими контурами дорівнює `dA = ∮_C dk_normal · dk_perpendicular`.

Оскільки різниця енергій `dE = |∇_k E| · dk_normal`, маємо `dk_normal = dE / |∇_k E|`.

Підставляючи це у вираз для зміни площі `dA`:

```
dA = dE · ∮_C (dk_perpendicular / |∇_k E|)   ⇒   (∂A / ∂E)_{k_z} = ∮_C (dk_perpendicular / |∇_k E|)
```

Порівнюючи цей результат із виразом для циклотронного періоду `T_c`:

```
T_c = (ℏ² / (e · B)) · (∂A / ∂E)
```

За визначенням, циклотронна частота `ω_c = 2π / T_c = e · B / m_c*`. Підставляючи `T_c`, отримуємо остаточну математичну формулу **циклотронної ефективної маси**:

```
m_c* = (ℏ² / (2 · π)) · (∂A / ∂E)_{E = E_F}
```

Для анізотропного еліпсоїдного закону дисперсії `E(k) = (ℏ² k_x² / 2m_x) + (ℏ² k_y² / 2m_y) + (ℏ² k_z² / 2m_z)` площа перерізу магнітним полем уздовж осі `z` дорівнює `A(E, k_z) = (2π / ℏ²) · √(m_x m_y) · (E - (ℏ² k_z² / 2m_z))`. Взявши похідну `∂A / ∂E`, отримуємо точний аналітичний вираз циклотронної маси:

```
m_c* = √(m_x · m_y)
```

Маса дорівнює середньому геометричному ефективних мас у площині, перпендикулярній до магнітного поля.

## 4. Сприйнятливість Ліндгарда та нестинг поверхонь Фермі

Поведінка електронного газу при прикладній зовнішній збуджуючій силі з хвильовим вектором `q` описується статичною сприйнятливістю Ліндгарда (поляризаційною функцією Пайєрлса):

```
χ_0(q) = ∫ (d³k / (4 · π³)) · ( (f(E_k) - f(E_{k+q})) / (E_{k+q} - E_k) )
```

Розмірність геометрії поверхні Фермі визначає математичний характер аномалій сприйнятивності Ліндгарда:

1. **Тривимірний випадок (3D куля):**
   Аналітичне інтегрування виразу Ліндгарда для 3D сфери Фермі дає формулу:

```
χ_0(q) = g(E_F) · [ 1/2 + ( (1 - x²) / (4 x) ) · ln │ (1 + x) / (1 - x) │ ]
```

де `x = q / (2 k_F)`. При `q = 2 k_F` (`x = 1`) похідна `(dχ_0 / dq)` прямує до логарифмічної нескінченності. Це породжує осцилююче розсіяння фононів — **аномалію Кона (Kohn anomaly)** у фононному спектрі кристала та немісцеві осциляції електронної густини РККІ (Руддермана — Киттеля — Касуї — Йосіди).

2. **Двовимірний випадок (2D циліндр):**
   Сприйнятливість `χ_0(q)` є постійною для `q < 2 k_F` і зазнає розриву зламу при `q = 2 k_F`.

3. **Одновимірний випадок (1D площини / нестинг):**
   Оскільки дві плоскі ділянки поверхні Фермі при `k = +k_F` та `k = -k_F` повністю суміщаються зсувом на вектор `Q = 2 k_F`, знаменник у формулі Ліндгарда обертається в нуль для великої кількості станів. Сприйнятливість логарифмічно дивергує при `T → 0 K`:

```
χ_0(2 · k_F) ∝ ln( E_F / (k_B · T) )  →  ∞
```

Ця математична дивергенція є причиною пайєрлсівського переходу електрон-фононної системи у стан хвилі зарядової (CDW) або спінової (SDW) густини з відкриттям енергетичної щілини `Δ_{CDW}`.

## 5. Сингулярності Ван Хова та топологічне число Ейлера при переходах Ліфшиця

При зміні енергії Фермі `E_F` через критичне значення `E_c` (точку переходу Ліфшиця) змінюється топологічний рід поверхні Фермі. У цій точці градієнт енергії обертається в нуль `∇_k E(k_c) = 0` — утворюється **критична точка Ван Хова** (низьковалентний сідловий або екстремальний центр).

Розкладемо енергію поблизу сідлової точки у 3D:

```
E(k) = E_c + (ℏ² / 2) · ( (k_x² / m_x) + (k_y² / m_y) - (k_z² / m_z) )
```

Вклад у густину станів `g(E) = (1 / (4 · π³)) · ∫ (dS / |∇_k E|)` при наближенні до критичної точки має характерний математичний вигляд сингулярності:

```
У двовимірному випадку (2D):   δg(E) ∝ - ln │ E - E_c │
У тривимірному випадку (3D):   δg(E) ∝ √│ E - E_c │ · Θ(E - E_c)
```

де `Θ(x)` — ступенчата функція Хевісайда. 

З математичного погляду диференціальної геометрії, перехід Ліфшиця супроводжується стрибком **характеристики Ейлера — Пуанкаре** `χ_E` поверхні Фермі:

```
χ_E = (1 / (2 · π)) · ∬ K_g · dS = 2 · (1 - g_genus)
```

де `K_g` — гауссова кривина поверхні, а `g_genus` — топологічний рід (кількість ручок). При розриві шиї рід `g_genus` зменшується на одиницю, а характеристика Ейлера зростає на 2. Цей стрибок прямо позначається на скачку коефіцієнта термоЕДС Зеєбека `S` та нелінійній стисливості ґратки.

## 6. Фаза Беррі та топологічні інваріанти у вейлівських та діраківських матеріалах

У топологічних квантових матеріалах (таких як вейлівські та діраківські напівметали чи графінові моношари) квантовомеханічна хвильова функція Блоха `|u_n(k)⟩` володіє геометричною фазою Беррі при обході замкненого контуру в квазіімпульсному просторі.

Векторний потенціал Беррі (связність Беррі) задається виразом:

```
A_B(k) = i · ⟨ u_n(k) │ ∇_k │ u_n(k) ⟩
```

Кривина Беррі `Ω(k) = ∇_k × A_B(k)` виступає квантовим аналогом магнітного поля у квазіімпульсному просторі. Вона модифікує напівкласичне рівняння руху групової швидкості носіїв:

```
v_k = (1 / ℏ) · ∇_k E(k) - (e / ℏ) · (E_ext × Ω(k))
```

Другий доданок описує аномальну швидкість розсіювання (anomalous velocity), яка спричиняє аномальний ефект Голла та квантовий аномальний ефект Голла без зовнішнього магнітного поля.

Для діраківського конуса в графіті кривина Беррі локалізована у вершині конуса у формі дельта-функції з інваріантною фазою Беррі `Φ_B = ∮ A_B · dk = π`. У формулі Онсагера квантування Ландау фазовий зсув `γ` стає строго рівним `0` замість `1/2`. Це є прямим експериментальним маркером діраківських ферміонів у вимірюваннях квантових осциляцій Шубникова — де Гааза.

## 7. Аномальний скін-ефект та геометрія кривини за Піппардом

У радіочастотній електродинаміці металів поверхневий імпеданс `Z_s = R_s + i · X_s` при аномальному скін-ефекті (`l >> δ`) визначається інтегралом по лінії ефективних електронів на поверхні Фермі:

```
R_s = ( (3 · π · ω² · μ_0² / ℏ) · ∮_{v_z = 0} (dk_z / |K_g(k_z)|) )¹ᐟ³
```

де `K_g` — гауссова кривина поверхні Фермі у точках, де групова швидкість електронів паралельна поверхні зразка (`v_z = 0`).

Вимірювання поверхневого опору `R_s` для різних кристаллографічних зрізів монокристала дозволяє з високою точністю реконструювати тривимірний рельєф кривини поверхні Фермі, що й дозволило Брайану Піппарду у 1957 році відтворити перетяжки міді.
