# 🧮 Математичне моделювання синаптичної пластичності STDP та провідності кросбарів

Математичний апарат опису штучних синапсів охоплює три фундаментальні рівні фізичного аналізу: мікроскопічне моделювання дрейфу іонних дефектів під дією локального електричного поля та температури (модель Мотта — Ґерні), феноменологічні рівняння часово-залежної пластичності (Spike-Timing-Dependent Plasticity, STDP), та розрахунок розподілу струмів і потенціалів у матрицях аналогового множення (Crossbar Compute-in-Memory) з урахуванням паразитичних опорів провідників (IR-Drop).

## 1. Мікроскопічна фізика дрейфу дефектів: Модель Мотта — Ґерні

Зміна провідності штучного синапсу на основі оксидів перехідних металів (OxRAM) описується переміщенням позитивно заряджених кисневих вакансій `V_O²⁺` у діелектичній матриці. У відсутності зовнішнього електричного поля киснева вакансія перебуває у потенціальній ямі кристалічної ґратки, відокремленій від сусідніх рівноважних станів енергетичним бар'єром активації `E_A` (типово 0.8–1.5 еВ для `HfO₂`).

Частота спонтанних термодинамічних стрибків вакансії через бар'єр визначається розпределенням Больцмана:

```
ν_0_hop = ν_0 · exp(−E_A / (k_B · T))      [Частота спонтанних стрибків без поля]
```

де `ν_0 ≈ 10¹³` Гц — спроба частоти фононних коливань ґратки, `k_B` — стала Больцмана, а `T` — локальна температура в Кельвінах.

При прикладенні зовнішнього електричного поля `E = V / D` (де `V` — напруга на електродах, `D` — товщина оксиду) потенціальний профіль деформується. Потенціальний бар'єр знижується на величину `q · a · E / 2` у напрямку поля та підвищується на ту саму величину у протилежному напрямку (де `a ≈ 0.25` нм — середня відстань між сусідніми позиціями вакансій у ґратці, `q` — заряд дефекту).

Швидкість дрейфу вакансій `v_drift` описується законом Мотта — Ґерні:

```
v_drift = 2 · a · ν_0 · exp(−E_A / (k_B · T)) · sinh(q · a · E / (2 · k_B · T))
```

При високих електричних полях (`E > 10⁶` В/см), коли `q · a · E >> 2 · k_B · T`, гіперболічний синус `sinh(x) ≈ exp(x) / 2`, і швидкість дрейфу стає експоненційно залежною від напруги:

```
v_drift ≈ a · ν_0 · exp(−(E_A − q · a · E / 2) / (k_B · T))      [Експоненційний дрейф у сильному полі]
```

Ця рівняння пояснює нелінійне мемристивне переключення: при малих зчитувальних напругах (`V < 0.2` В) електричне поле не здатне підняти швидкість дрейфу, і опір залишається сталим. При напругах запису (`V > 1.0` В) швидкість міграції дефектів зростає на 6–8 порядків, дозволяючи змінити провідність пристрою за наносекундні проміжки часу.

### Термодинаміка Джоулевого нагріву та температурний саморозгін

При проходженні струму `I` крізь провідну нитку радіуса `r_fil` виділяється потужність Джоулевого нагріву `P = I² · R`. Локальна температура `T` у гарячій точці (*hotspot*) нитки описується стаціонарним рівнянням теплопровідності Фурьє:

```
T = T_0 + R_th · I · V
```

де `T_0 = 300` K — температура навколишнього середовища, а `R_th` — ефективний тепловий опір оточуючої оксидної матриці:

```
R_th = 1 / (4 · π · κ_ox · r_fil)      [Тепловий опір оточення нитки]
```

де `κ_ox ≈ 1.5` Вт/(м·К) — коефіцієнт теплопровідності аморфного `HfO₂`. Підвищення температури в нитці до `T ≈ 600–800` K під час імпульсу RESET прискорює термічну рекомбінацію вакансій з іонами кисню у мільйони разів, що математично пояснює асиметрію між повільною потенціацією та швидким розривом нитки.

## 2. Математична формалізація пластичності STDP

Часово-залежна пластичність STDP визначає зміну вагового коефіцієнта (провідності `G`) залежно від точної часової різниці `Δt = t_post − t_pre` між моментом приходу імпульсу від пресинаптичного нейрона `t_pre` та моментом генерації спайка постсинаптичним нейроном `t_post`.

Класична двокомпонентна експоненційна модель STDP описується наступними рівняннями:

```
Δw(Δt) = A₊ · exp(−Δt / τ₊)     [при Δt > 0: Пре-потім-Пост імпульс (LTP)]
Δw(Δt) = −A₋ · exp(Δt / τ₋)      [при Δt < 0: Пост-потім-Пре імпульс (LTD)]
```

де феноменологічні параметри мають чіткий фізичний зміст:
* `A₊ > 0` — амплітуда потенціації, визначена максимальним числом вакансій, що додаються до нитки за один імпульс;
* `A₋ > 0` — амплітуда депресії, визначена швидкістю рекомбінації дефектів;
* `τ₊` — часове вікно потенціації (визначається тривалістю хвоста електричного потенціалу дії);
* `τ₋` — часове вікно депресії.

### Модель накладання хвильових форм (Waveform Overlapping Model)

У штучних синапсах біологічне вікно STDP моделюється шляхом подачі спеціально сформованих пре- та постсинаптичних напруг `V_pre(t)` та `V_post(t)`. Загальна напруга на мемристорі дорівнює різниці потенціалів:

```
V_memristor(t) = V_pre(t) − V_post(t)
```

Реальна зміна провідності `ΔG` обчислюється шляхом інтегрування швидкості дрейфу `v_drift` по всьому проміжку часу накладання імпульсів `[0, t_pulse]`:

```
ΔG(Δt) = ∫_0^t_pulse C_material · exp(q · a · |V_pre(t) − V_post(t − Δt)| / (2 · D · k_B · T)) dt
```

Якщо `|V_memristor(t)|` перевищує порогову напругу переключення `V_th`, провідність змінює своє значення. Якщо затримка `Δt` занадто велика, пікові значення напруг не накладаються, напруга на пристрої залишається нижчою `V_th`, і зміна провідності дорівнює нулю (`ΔG = 0`).

```
           Генерація STDP вікна через накладання хвильових форм:

  Напруга V
     ▲
  V_th│                     ┌───┐  Піковий суммарний імпульс > V_th
      │                    /     \ ───► Переключення провідності ΔG > 0
  ────────────────────────/───────\─────────────────────────────
      │      V_pre(t)    /         \    V_post(t - Δt)
   0 ─┼─────────────────/───────────\──────────────────────────► Час t
      │  ┌──────────┐  /             \  ┌──────────┐
 −V_th│  │          │ /               \ │          │
      └──┴──────────┴─┴────────────────┴┴──────────┴────────────
```

### Моделі м'яких та жорстких меж провідності (Soft-bound vs Hard-bound)

Оскільки провідність реального пристрою є фізично обмеженою у діапазоні `[G_min, G_max]`, математичне оновлення ваги залежить від поточного стану провідності `G`:

1. **Модель жорстких меж (Hard-bound model):**
   ```
   G_new = G_old + ΔG
   G_new = G_max,  якщо G_old + ΔG > G_max
   G_new = G_min,  якщо G_old + ΔG < G_min
   ```
   У цій моделі кроки оновлення однакові на всьому діапазоні, але при досягненні меж відбувається різке насичення.

2. **Модель м'яких меж (Soft-bound model):**
   ```
   ΔG_LTP = A₊ · [(G_max − G_old) / (G_max − G_min)]^γ_LTP · exp(−Δt / τ₊)
   ΔG_LTD = −A₋ · [(G_old − G_min) / (G_max − G_min)]^γ_LTD · exp(Δt / τ₋)
   ```
   де `γ_LTP` та `γ_LTD` — коефіцієнти нелінійності матеріалу. При наближенні провідності до `G_max` величина приросту `ΔG_LTP` асимптотично прямує до нуля.

Для оцінки динаміки провідності від кількості поданих однакових імпульсів `N` використовується аналітичний інтеграл диференціального рівняння м'яких меж:

```
G_LTP(N) = G_min + (G_max − G_min) · [1 − exp(−ν_LTP · N)]
G_LTD(N) = G_max − (G_max − G_min) · [1 − exp(−ν_LTD · (N_max − N))]
```

де `ν_LTP` та `ν_LTD` — безрозмірні коефіцієнти швидкості насичення.

## 3. Математика аналогового множення у Кросбар-матриці (MVM)

Аналогове множення матриці ваг `W` розміром `M × N` на вектор вхідних напруг `V` розміром `M × 1` реалізується у тривимірній сітці перетинів шин Word Lines (WL) та Bit Lines (BL).

Нехай `V_i` — напруга, прикладена до `i`-го рядка (`i = 1, 2, ..., M`), а `G_ij` — штучна синаптична провідність елемента, розташованого на перетині `i`-го рядка та `j`-го стовпчика (`j = 1, 2, ..., N`).

Згідно із **Законом Ома**, локальний струм `I_ij`, який протікає крізь мемристор у вузлі `(i, j)`, дорівнює:

```
I_ij = V_i · G_ij
```

Згідно з **Першим правилом Кірхгофа** (законом збереження заряду), загальний струм `I_j`, який витікає з `j`-го стовпчика в суматор або аналого-цифровий перетворювач (АЦП), є сумою струмів усіх вузлів даного стовпчика:

```
I_j = ∑_(i=1)^M I_ij
I_j = ∑_(i=1)^M (V_i · G_ij)      [Стум j-го стовпчика: аналоговий добуток Vector-Matrix Multiplication]
```

У матричній формі для всього вектора вихідних струмів `I = [I₁, I₂, ..., I_N]^T` та вектора вхідних напруг `V = [V₁, V₂, ..., V_M]^T`:

```
I = G^T · V
```

Таким чином, математична операція `O(M · N)` складності виконується за **один фізичний такт** (часова складність `O(1)`), оскільки струми підсумовуються безпосередньо у фізичному середовищі провідників зі швидкістю поширення електромагнітної хвилі.

## 4. Фізичні паразитичні ефекти: Падіння напруги IR-Drop

У реальних напівпровідникових матрицях металеві шини рядків та стовпчиків мають скінченний опір `R_line` на один сегмент між сусідніми вузлами. Це викликає паразитичне падіння напруги (IR-Drop), через що потенціал у віддалених вузлах матриці стає меншим за прикладену напругу `V_i`.

Для вузла `(i, j)` нехай `v_i,j` — реальний потенціал на шині рядка, а `u_i,j` — потенціал на шині стовпчика. Система різницевих рівнянь Кірхгофа для вузла `(i, j)` має вигляд:

```
(v_i,j−1 − v_i,j) / R_line + (v_i,j+1 − v_i,j) / R_line = (v_i,j − u_i,j) · G_ij
(u_i−1,j − u_i,j) / R_line + (u_i+1,j − u_i,j) / R_line = (u_i,j − v_i,j) · G_ij
```

Граничні умови для системи з `M` рядків та `N` стовпчиків:

```
v_i,0 = V_i_in       [Вхідна напруга на початку рядка]
v_i,N = v_i,N−1      [Вільний кінець рядка: струм відсутній]
u_0,j = u_1,j        [Вільний кінець стовпчика]
u_M+1,j = 0          [Вихід стовпчика підключено до віртуальної землі АЦП]
```

### Аналітична модель згасання потенціалу у великих матрицях

У континуальному наближенні для матриці з рівномірною середньою провідністю штучних синапсів `G_avg` система різницевих рівнянь перетворюється на диференціальне рівняння другого порядку:

```
d²v(x) / dx² = R_line · G_avg · v(x)
```

Розв'язок цього рівняння для потенціалу вздовж рядка описується затухаючою гіперболічною функцією:

```
v(x) = V_in · [cosh((L − x) / λ_eff) / cosh(L / λ_eff)]
λ_eff = 1 / √(R_line · G_avg)
```

де `L` — фізична довжина шини, а `λ_eff` — характеристична довжина згасання напруги.

```
       Розподіл потенціалу v(x) вздовж шини кросбару через ефект IR-Drop:

   Потенціал v(x) / V_in
       ▲
   1.0 │█
   0.8 │ ▀▀──╮  Ідеальна шина (R_line = 0)
   0.6 │      ▀▀──╮
   0.4 │           ▀▀──╮  Реальна шина (Експоненційне згасання IR-Drop)
   0.2 │                ▀▀──────────────┐
     0 └┴───────────────────────────────┴──────────────────────────► Довжина x (Вузли)
       0               λ_eff            L
```

Якщо розмір матриці перевищує довжину `λ_eff`, потенціал у кінці рядка спадає настільки сильно, що струми відддалених синапсів не роблять внеску в загальну суму. Це спотворює математичну операцію множення матриці. Для запобігання цьому ефекту в архітектурі аналогових NPU великі матриці фрагментують на малі локальні блоки розміром `128 × 128` або `256 × 256` осередків, об'єднані цифровими суматорами.
