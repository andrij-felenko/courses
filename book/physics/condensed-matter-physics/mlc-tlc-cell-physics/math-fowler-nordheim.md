# 🧮 Математична модель тунелювання Фаулера-Нордгейма та електростатика затвора

Для квантовомеханічного опису ін'єкції носіїв у комірках флеш-пам'яті розглянемо гетероперехід між напівпровідниковою кремнієвою підкладкою `Si` та тунельним діелектриком з оксиду кремнію `SiO₂`. Електронам зони провідності кремнію для потрапляння в зону провідності оксиду необхідно подолати потенціальний бар'єр висотою `Φ_b ≈ 3.15 еВ`, який визначається різницею спорідненості до електрона цих двох матеріалів. У термодинамічній рівновазі за відсутності зовнішнього поля оксидний шар товщиною `d_ox ≈ 7-9 нм` є надійним ізолятором з прямокутною формою енергетичного бар'єра.

Коли до керуючого затвора прикладається висока позитивна напруга програмування `V_pgm ≈ 15-20 В`, у тунельному оксиді створюється велетенська напруженість електричного поля `E_ox = V_ox / d_ox > 8·10⁶ В/см` (або `8-10 МВ/см`). Під дією цього поля енергетичні зони діелектрика сильно нахиляються з крутизною `dE / dx = -q · E_ox`. Прямокутний потенціальний бар'єр деформується і набуває трикутної форми, верхня межа якої спадає за лінійним законом.

```
Кремній (Si)           Тунельний оксид (SiO₂)          Плаваючий затвор (FG)
x < 0                   0 ≤ x ≤ x_b                      x > d_ox
                        
E_c ────┐               U(x) = E_c - q·E_ox·x
        │               ╲
        │                ╲ (Трикутний бар'єр)
        │                 ╲
        └──────────────────┐───────────────────────────── E_c(FG)
                           x_b = Φ_b / (q·E_ox)
```

Електрон зони провідності кремнію з кінетичною енергією `E_x` наближається до потенціального бар'єра на межі `x = 0`. При трикутній деформації ефективна просторова товщина бар'єра, яку електрон повинен подолати на своїй енергетичній висоті, перестає дорівнювати повній геометричній товщині оксиду `d_ox` і зменшується до величини класичної точки повороту `x_b = Φ_b / (q · E_ox)`. Якщо напруженість поля `E_ox` досягає значень `10⁷ В/см`, товщина трикутного підбар'єрного шляху `x_b` зменшується до `3-4 нм`, що порівняно з довжиною дебройлівської хвилі електрона в напівпровіднику. У результаті хвильова функція електрона не встигає повністю згаснути всередині оксиду, і електрон дістає можливість квантовомеханічного тунелювання безпосередньо у зону провідності плаваючого затвора або шару пасток.

### Квантовомеханічне виведення коефіцієнта прозорості за методом ВКБ

Хвильова функція електрона `Ψ(x)` усередині одновимірного потенціального бар'єра `U(x)` описується стаціонарним рівнянням Шредінгера. Оскільки потенціал `U(x)` плавно змінюється у просторі під дією однорідного електричного поля, для розв'язку рівняння скористаємося квазікласичним наближенням Вентцеля-Крамерса-Бріллюена (ВКБ).

У рамках методу ВКБ хвильова функція електрона в класично забороненій області `0 ≤ x ≤ x_b`, де потенціальна енергія бар'єра перевищує повну енергію частинки `U(x) > E_x`, шукається у вигляді згасаючої експоненти. Зтухання амплітуди хвилі визначається локальним значенням хвильового вектора згасання `κ(x)`.

Коефіціент прозорості бар'єра `T(E_x)`, який характеризує ймовірність проходження електрона з енергією `E_x` крізь підбар'єрну область, визначається логарифмічним інтегралом згасання між межею ін'єкції `x = 0` та класичною точкою повороту `x_b`:

```
T(E_x) = exp( - 2 · ∫₀^{x_b} κ(x) dx )
```

де хвильовий вектор згасання хвильової функції у підбар'єрній області дорівнює:

```
κ(x) = √( ( 2 · m* / ħ² ) · ( U(x) - E_x ) )
```

У цьому виразі `m*` означає ефективну тунельну масу електрона в забороненій зоні оксиду кремнію, яка враховує взаємодію носія з періодичним потенціалом діелектричної ґратки (`m* ≈ 0.42 · m₀`, де `m₀` — маса вільного електрона у вакуумі), а `ħ = h / (2·π)` є зведеною сталою Планка.

Підставимо у вираз хвильового вектора лінійний трикутний профіль потенціальної енергії `U(x) = Φ_b - q · E_ox · x` припускаючи, що електрони падають на бар'єр з дна зони провідності кремнієвої підкладки, де їхня поперечна кінетична енергія є малою порівняно з висотою бар'єра (`E_x ≈ 0`):

```
κ(x) = √( ( 2 · m* / ħ² ) · ( Φ_b - q · E_ox · x ) )
```

Для обчислення визначеного інтеграла у показнику експоненти виконаємо алгебраїчну заміну змінної `u = Φ_b - q · E_ox · x`, при якій диференціал дорівнює `du = -q · E_ox · dx`, а межі інтегрування змінюються від `u(0) = Φ_b` до `u(x_b) = 0`:

```
∫₀^{x_b} √( Φ_b - q · E_ox · x ) dx
= [ ( - 2 / (3 · q · E_ox) ) · ( Φ_b - q · E_ox · x )^(3/2) ]₀^{Φ_b / (q·E_ox)}
= ( 2 / (3 · q · E_ox) ) · Φ_b^(3/2)
```

Підставляючи знайдений розв'язок інтеграла у квазікласичну формулу ВКБ, отримуємо квантовомеханічний вираз для коефіцієнта прозорості трикутного бар'єра Фаулера-Нордгейма:

```
T(E_x) = exp( - ( 4 · √(2 · m*) · Φ_b^(3/2) ) / ( 3 · q · ħ · E_ox ) )
```

### Густина струму тунелювання Фаулера-Нордгейма та числові параметри

Повний струм тунелювання через одиницю площі тунельного оксиду обчислюється шляхом інтегрування потоку падаючих електронів по всьому спектру енергетичних станів у напівпровідниковій підкладці. Густина струму `J_FN` дорівнює добутку елементарного заряду `q`, групи группової швидкості носіїв `v_x`, густини доступних станів `n(E_x)`, імовірності їх заповнення Фермі-Дірака та коефіцієнта квантової прозорості `T(E_x)`:

```
J_FN = q · ∫₀^∞ v_x · n(E_x) · T(E_x) dE_x
```

В умовах сильної поверхневої інверсії кремнію, коли до керуючого затвора прикладено високий позитивний потенціал програмування, біля поверхні напівпровідника формується вироджений електронний газ. Електрони зони провідності зосереджені у вузькому енергетичному інтервалі поблизу рівня Фермі. Інтегрування цього розкладу дає класичне фундаментальне рівняння Фаулера-Нордгейма:

```
J_FN = A_FN · E_ox² · exp( - B_FN / E_ox )
```

де феноменологічні коефіцієнти `A_FN` та `B_FN` виражаються через фундаментальні фізичні константи та фізичні характеристики межі розділу `Si/SiO₂`:

```
A_FN = q³ / ( 8 · π · h · Φ_b )
```

```
B_FN = ( 8 · π · √(2 · m*) · Φ_b^(3/2) ) / ( 3 · q · h )
```

Для проведення практичних фізичних та інженерних розрахунків підставимо відомі значення матеріальних констант для системи кремній — оксид кремнію:
- Елементарний заряд електрона: `q = 1.602 · 10⁻¹⁹ Кл`
- Енергетична висота бар'єра на межі `Si/SiO₂`: `Φ_b = 3.15 еВ = 5.046 · 10⁻¹⁹ Дж`
- Ефективна тунельна маса електрона в оксиді: `m* = 0.42 · m₀ = 3.826 · 10⁻³¹ кг`
- Постійна Планка: `h = 6.626 · 10⁻³⁴ Дж·с`

Проведемо розрахунок першої пред'експоненційної константи `A_FN`:

```
A_FN = ( (1.602 · 10⁻¹⁹)³ ) / ( 8 · π · (6.626 · 10⁻³⁴) · (5.046 · 10⁻¹⁹) )   [підстановка констант q, h, Φ_b у вираз A_FN]
     = 4.111 · 10⁻⁵⁷ / 8.406 · 10⁻⁵¹                                          [обчислення чисельника і знаменника]
     = 4.88 · 10⁻⁶ А / В²                                                     [остаточний розрахунок пред'експоненційного множника]
```

Проведемо розрахунок другої експоненційної полевої константи `B_FN`:

```
B_FN = ( 8 · π · √( 2 · (3.826 · 10⁻³¹ ) · (5.046 · 10⁻¹⁹)³ ) ) / ( 3 · (1.602 · 10⁻¹⁹) · (6.626 · 10⁻³⁴) )   [підстановка m*, Φ_b, q, h у вираз B_FN]
     = ( 25.132 · √( 3.826 · 10⁻³¹ · 1.284 · 10⁻⁵⁵ ) ) / ( 3.185 · 10⁻⁵² )                                    [піднесення висоти бар'єра до степеня 3/2]
     = ( 25.132 · 7.009 · 10⁻⁴⁴ ) / ( 3.185 · 10⁻⁵² )                                                        [обчислення квадратного кореня добутку мас та енергій]
     = 2.56 · 10⁸ В / см                                                                                      [підсумкове значення критичної напруженості поля]
```

Математичний аналіз отриманого рівняння демонструє виключну чутливість густини тунельного струму `J_FN` до найменших змін напруженості електричного поля `E_ox`:
- У режимі збереження та зчитування даних при помірному полі `E_ox = 3 МВ/см`: експоненційний множник дорівнює `exp(-2.56·10⁸ / 3·10⁶) = exp(-85.3) ≈ 3 · 10⁻³⁷`. Густина струму є абсолютно нехтовною `J_FN ≈ 10⁻²⁰ А/см²`. Це означає, що за 10 років зберігання при кімнатній температурі комірка втрачає менше ніж одну тисячну частку відсотка збережених електронів.
- У режимі програмування при високому полі `E_ox = 10 МВ/см`: експоненційний множник зростає до `exp(-2.56·10⁸ / 10⁷) = exp(-25.6) ≈ 7.6 · 10⁻¹²`. Густина струму досягає велетенського значення `J_FN ≈ 2.5 · 10⁻² А/см²`.

Таким чином, збільшення напруженості електричного поля всього в 3.3 рази викликає зростання тунельного струму ін'єкції на 18 порядків! Саме ця колосальна фізична нелінійність ефекту Фаулера-Нордгейма робить можливим поєднання довготривалого збереження даних із можливістю швидкого перезапису за мікросекунди.

### Порівняльний аналіз тунелювання Фаулера-Нордгейма та прямого тунелювання

При розробці напівпровідникових комірок пам'яті принципово важливо розрізняти тунелювання Фаулера-Нордгейма від прямого квантового тунелювання (Direct Tunnelling).

```
Тунелювання Фаулера-Нордгейма (E_ox > 8 МВ/см)       Пряме тунелювання (Direct Tunnelling)
Оксид d_ox ≈ 7-9 нм, Трикутний бар'єр                Оксид d_ox < 3 нм, Трапецієподібний бар'єр

E_c ───┐  U(x)                                       E_c ───┐  U(x)
       │  ╲                                                 │  ┌───────┐
       │   ╲ (Електрон тунелює                              │  │       │ (Електрон пробиває
       │    ╲  у зону провідності SiO₂)                     │  │       │  весь оксид наскрізь)
       └─────┐────────────────                              └──┼───────┼───────────
             x_b < d_ox                                        0       d_ox
```

Пряме тунелювання виникає тоді, коли геометрична товщина тунельного оксиду `d_ox` зменшується до величини менше 3 нанометрів. За таких умов навіть при малій напруженні поля класична точка повороту `x_b` виходить за межі оксиду (`x_b > d_ox`). Електрон тунелює крізь увесь оксидний шар трапецієподібної форми і потрапляє безпосередньо в анод. Густина струму прямого тунелювання описується формулою Симпсона і залежить від товщини діелектрика за жорстким експоненційним законом `J_direct ∝ exp(-A · d_ox)`. Оскільки прямому тунелюванню не потрібна висока напруженість поля, тонкий оксид `d_ox < 3 нм` постійно протікає навіть при нульовій напрузі затвора, що унеможливлює довготривале збереження заряду.

Натомість у комірках флеш-пам'яті використовується товщий тунельний оксид (`d_ox = 7-9 нм` у 2D FG та `3-4 нм` у 3D CTF), який повністю блокує пряме тунелювання в режимі спокою. Ін'єкція виникає тільки тоді, коли прикладена висока напруга штучно нахиляє зони оксиду і створює вузький трикутний підбар'єрний прохід `x_b < d_ox` за механізмом Фаулера-Нордгейма.

Крім того, тунелювання Фаулера-Нордгейма володіє високою температурною стабільністю. На відміну від термоелектронної емісії Річардсона або провідності по пастках за механізмом Френкеля-Пула, коефіцієнт прозорості `T(E_x)` у наближенні ВКБ не містить абсолютного значення температури `T`. Невелика температурна залежність `J_FN` виникає лише через температурну деформацію ширини забороненої зони кремнію `E_g(T)` та помірне розмиття розподілу Фермі. Це гарантує надійність та відтворюваність алгоритмів програмування накопичувачів у широкому індустріальному діапазоні температур від `-40 °C` до `+125 °C`.

### Фізична модель деградації оксиду та накопичення пасток при ін'єкції FN

Багаторазове проходження високоенергетичних тунелюючих електронів крізь кристалічну ґратку тунельного оксиду `SiO₂` у режимах програмування та стирання не минає безслідно для структури діелектрика. Сильне електричне поле `E_ox > 10 МВ/см` розганяє електрони в зоні провідності оксиду, надаючи їм кінетичну енергію, достатню для розриву ослаблених кремній-водневих (`Si-H`) та кремній-кремнієвих (`Si-Si`) зв'язків.

Цей процес описується фізичною моделлю генерації дефектів (Anode Hole Injection та Defect Generation model). Під дією тунельного струму `J_FN` в об'ємі тунельного оксиду генеруються два основних типи дефектів:
1. **Об'ємні оксидні пастки (Bulk Oxide Traps `N_ot`)** — обірвані зв'язки атома кремнію (`E'`-центри), які здатні локалізувати електрони у товщі діелектрика.
2. **Поверхневі стани (Interface Traps `N_it`)** — електронні пастки безпосередньо на металургійній межі `Si/SiO₂`, які порушують гладкість інверсійного каналу та знижують рухливість носіїв.

Накопичення об'ємних пасток `N_ot` залежить від інтегрального пропущеного заряду `Q_inj = ∫ J_FN dt` за степеневим законом:

```
N_ot(Q_inj) = K_trap · ( Q_inj )^β
```

де `K_trap` — постійна генерації дефектів матеріалу, а показник степеня `β ≈ 0.5` вказує на дифузійний характер накопичення водневих дефектів.

Накопичені негативно заряджені пастки `N_ot` створюють власне електростатичне поле, яке додається до зовнішнього поля і поступово змінює ефективні константи Фаулера-Нордгейма:

```
A_FN_eff = A_FN · ( 1 - ΔA(N_ot) )
```

```
B_FN_eff = B_FN + ΔB(N_ot)
```

Внаслідок накопичення пасток початкова програмуюча напруга `V_pgm` перестає забезпечувати розраховану густину тунельного струму `J_FN`. Швидкість програмування комірки знижується, а пороговий розкид `V_th` у серії імпульсів ISPP розширюється, що призводить до фізичної деградації комірки після вичерпання ресурсу P/E циклів.

### Фізична модель стирання комірки (Erase Dynamics)

Процес електричного стирання комірки флеш-пам'яті (Erase mode) є фізично дзеркальним до процесу програмування. Для вилучення накопиченого негативного заряду з плаваючого затвора або шару пасток до об'ємної p-канальної кремнієвої підкладки (P-well) прикладається висока позитивна напруга стирання `V_erase ≈ 20 В`, тоді як керуючі затвори `CG` обраного блоку заземлюються (`V_CG = 0 В`).

У цьому випадку напрямок електричного поля в тунельному оксиді змінюється на протилежний. Напруженість поля виштовхує електрони з затвора назад у кремнієву підкладку за допомогою тунелювання Фаулера-Нордгейма. Одночасно з цим сильне поле викликає зворотне тунелювання дірок із валентної зони підкладки у затвор, що прискорює нейтралізацію накопиченого негативного заряду.

Рівняння густини струму стирання `J_erase` має аналогічну структуру Фаулера-Нордгейма, проте бар'єрні параметри регулюються потенціалом підкладки:

```
J_erase = A_FN_erase · E_ox_erase² · exp( - B_FN_erase / E_ox_erase )
```

Оскільки стирання здійснюється одночасно для мільйонів комірок усього блоку, фізичний розкид товщини оксиду та початкового заряду викликає явище перестирання (Over-erase). Якщо з комірки вилучити занадто багато електронів, на плаваючому затворі виникає лишковий позитивний заряд, який перетворює N-канальний транзистор на збіднений (деплеційний) з від'ємною пороговою напругою `V_th < 0`. Для запобігання цьому контролер проводить спеціальну фазу м'якого відновлювального програмування (Soft Program).

Фізичний зсув порогової напруги при стиранні `ΔV_th_erase` прямо пропорційний вилученому заряду `ΔQ_erase` та обернено пропорційний ємності `C_IPD`:

```
ΔV_th_erase = ΔQ_erase / C_IPD
```

### Електростатична модель ємнісного дільника комірки

Комірка флеш-пам'яті з плаваючим затвором є багатоелектродною фізичною системою із взаємним ємнісним зв'язком. Провідний плаваючий затвор `FG` оточений чотирма основними діелектричними ємностями:
1. `C_IPD` — ємність межпетльового діелектрика (Inter-Poly Dielectric, високоякісна тришарова структура ONO або High-k) між керуючим затвором `CG` та плаваючим затвором `FG`.
2. `C_tox` — ємність тонкого тунельного оксиду між плаваючим затвором та кремнієвим каналом підкладки `Sub`.
3. `C_D` — паразитна ємність просторового перекриття між плаваючим затвором та високолегованим стоком `Drain`.
4. `C_S` — паразитна ємність перекриття між плаваючим затвором та витоком `Source`.

Загальна еквівалентна ємність плаваючого затвора `C_tot` дорівнює алгебраїчній сумі всіх елементарних ємностей зв'язку:

```
C_tot = C_IPD + C_tox + C_D + C_S
```

Згідно з законом збереження електричного заряду, потенціал ізольованого плаваючого затвора `V_FG` визначається розносом потенціалів на всіх зовнішніх електродах та величою накопиченого на ньому негативного заряду `Q_fg`:

```
V_FG = ( C_IPD / C_tot ) · V_CG + ( C_D / C_tot ) · V_D + ( C_S / C_tot ) · V_S + ( Q_fg / C_tot )
```

Фундаментальною характеристикою комірки є коефіцієнт ємнісного зв'язку керуючого затвора (Control Gate Coupling Ratio `α_CG`). Він визначає, яка частка прикладеного зовнішнього потенціалу `V_CG` передається безпосередньо на плаваючий затвор:

```
α_CG = C_IPD / C_tot
```

Для забезпечення низьких програмуючих напруг розробники прагнуть максимізувати коефіцієнт `α_CG` до значень `0.6 - 0.7`. Це досягається збільшенням фізичної площі поверхні межпетльового діелектрика `C_IPD` (наприклад, за рахунок U-подібного обгортання плаваючого затвора) або використанням матеріалів із високою діелектричною проникністю (`Al₂O₃`, `HfO₂`).

### Зсув порогової напруги та розрахунок кількості інжектованих електронів

Транзистор комірки пам'яті переходить у провідний стан та формує інверсійний n-канал тоді, коли потенціал плаваючого затвора досягає власної порогової напруги кремнієвого каналу `V_th0` (яка визначається легуванням підкладки):

```
V_FG = V_th0
```

Підставимо умову відкриття каналу у формулу потенціалу плаваючого затвора при заземлених витоку та стоці (`V_S = V_D = 0`):

```
V_th0 = α_CG · V_th + ( Q_fg / C_tot )
```

Виразимо зовнішню порогову напругу комірки `V_th`, яка вимірюється на керуючому затворі `CG`:

```
V_th = ( V_th0 / α_CG ) - ( Q_fg / ( α_CG · C_tot ) )
```

Оскільки `α_CG = C_IPD / C_tot`, отримуємо фундаментальне співвідношення між інжектованим зарядом `Q_fg` та зсувом порогової напруги `ΔV_th`:

```
ΔV_th = V_th - V_th_erased = - Q_fg / C_IPD
```

Оскільки інжектовані електрони несуть негативний знак заряду (`Q_fg < 0`), накопичення електронів на плаваючому затворі викликає **позитивний зсув порогової напруги** `ΔV_th > 0`.

Проведемо числовий розрахунок кількості електронів `N_e`, необхідних для зсуву порогової напруги на `ΔV_th = 1.0 В` у сучасній комірці з ємністю межпетльового діелектрика `C_IPD ≈ 1.6 · 10⁻¹⁷ Ф` (16 аттофарад):

```
Q_fg = - ΔV_th · C_IPD = - 1.0 В · (1.6 · 10⁻¹⁷ Ф) = - 1.6 · 10⁻¹⁷ Кл
```

Кількість електронів `N_e` дорівнює:

```
N_e = |Q_fg| / q = (1.6 · 10⁻¹⁷ Кл) / (1.602 · 10⁻¹⁹ Кл) ≈ 100 електронів!
```

Цей розрахунок демонструє дивовижну фізичну чутливість: у сучасних високощільних комірках TLC та QLC зсув між сусідніми логічними станами на `0.3 В` відповідає зміні заряду всього на **30 електронів**! Втрата або випадкове захоплення всього кількох десятків електронів внаслідок деградації оксиду призводить до помилки зчитування біта.

### Диференціальне рівняння кінетики заряджання комірки

Під час дії імпульсу програмування тривалістю `t_pulse` напруженість поля в тунельному оксиді `E_ox(t)` динамічно зменшується в міру накопичення негативного заряду `Q_fg(t)` на затворі:

```
E_ox(t) = ( V_FG(t) - V_channel ) / d_ox
        = ( α_CG · V_pgm + ( Q_fg(t) / C_tot ) ) / d_ox
```

Зміна накопиченого заряду в часі описується нелінійним диференціальним рівнянням першого порядку:

```
dQ_fg / dt = - A_gate · J_FN( E_ox(t) )
           = - A_gate · A_FN · E_ox(t)² · exp( - B_FN / E_ox(t) )
```

де `A_gate` — активна площа тунельного вікна комірки.

Оскільки густина струму `J_FN` спадає за експоненційним законом при зменшенні напруженості поля `E_ox(t)`, процес заряджання комірки володіє ефектом фізичного самообмеження (self-limiting kinetics). Початкові мікросекунди імпульсу при високому полі забезпечують стрімке інжектування електронів та швидке зростання `V_th`. Однак у міру накопичення заряду потенціал `V_FG` падає, поле `E_ox` послаблюється, і струм `J_FN` спадає на кілька порядків, виводячи порогову напругу на насичення. Фізичний ефект самообмеження дає змогу контролювати порогові рівні у багатобітних комірках із прецизійною точністю за допомогою алгоритму ISPP.
