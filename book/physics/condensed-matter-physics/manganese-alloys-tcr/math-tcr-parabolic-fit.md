# 🧮 Математичне моделювання параболічної залежності опору та термо-ЕРС

Температурний коефіцієнт опору (ТКО) прецизійних сплавів типу манганіну не є строго константою, а змінюється з температурою, описуючи параболічну криву. Математичне моделювання цієї залежності дає змогу виразити параметри параболи, розрахувати точку локального екстремуму, визначити паразитного термо-ЕРС потенціал при вимірюваннях та виконати МНК-апроксимацію експериментальних даних.

## 1. Параболічна апроксимація температурної залежності R(T)

У діапазоні робочих температур від `-40 °C` до `+100 °C` відносний електричний опір манганіну описується квадратичним поліномом другого порядку відносно референтної температури `T_0 = 20 °C`:

```
R(T) = R_0 · [1 + α · (T - T_0) + β · (T - T_0)²]
```

- `R_0` — значення електричного опору при базовій референтній температурі `T_0 = 20 °C` (в `Ом` або `мОм`).
- `α` — лінійний температурний коефіцієнт опору при `20 °C` (вимірюється в `1/K` або в мільйонних частках `ppm/K`).
- `β` — квадратичний коефіцієнт кривини параболи (вимірюється в `1/K²` або `ppm/K²`).

Температурний коефіцієнт опору як диференціальна величина визначається першою похідною від питомого опору по температурі:

```
TCR(T) = (1 / R_0) · (dR / dT)
       = (1 / R_0) · (d / dT) [R_0 · (1 + α·(T - T_0) + β·(T - T_0)²)]
       = α + 2 · β · (T - T_0)       [диференціювання квадратичної форми]
```

Для виготовленого та належним чином термообробленого манганінового дроту лінійний коефіцієнт `α` лежить у межах від `-5 · 10⁻⁶ K⁻¹` до `+15 · 10⁻⁶ K⁻¹` (`-5 ... +15 ppm/K`), а квадратичний коефіцієнт `β` завжди є негативним і становить близько `-0.35 · 10⁻⁶ K⁻²` до `-0.50 · 10⁻⁶ K⁻²` (`-0.35 ... -0.50 ppm/K²`).

Фізичний зміст від'ємного значення квадратичного коефіцієнта `β < 0` полягає у тому, що при відхиленні температури від кімнатної в будь-який бік (як при нагріванні, так і при охолодженні) швидкість зростання квантового розмиття Фермі-поверхні та s-d розсіяння переважає лінійне фононне розсіяння, зменшуючи підсумковий опір.

## 2. Розрахунок вершини параболи T_max та умов оптимальної стабільності

Оскільки квадратичний коефіцієнт є негативним (`β < 0`), залежність `R(T)` має абсолютний максимум (вершину параболи), при якому диференціальний ТКО перетворюється на нуль. Температура максимуму `T_max` знаходиться з умови рівності нулю першої похідної:

```
TCR(T_max) = α + 2 · β · (T_max - T_0) = 0
```

Виражаємо `T_max`:

```
2 · β · (T_max - T_0) = -α
T_max - T_0 = -α / (2 · β)
T_max = T_0 - α / (2 · β)           [розв'язок відносно T_max]
```

**Аналітичний приклад розрахунку**:
Нехай для конкретної партії термообробленого манганінового дроту в лабораторній камері виміряно коефіцієнти `α = +8.0 ppm/K = +8.0 · 10⁻⁶ K⁻¹` та `β = -0.40 ppm/K² = -0.40 · 10⁻⁶ K⁻²`.

Обчислимо температуру максимуму опору `T_max`:

```
T_max = 20.0 - (+8.0 · 10⁻⁶) / (2 · (-0.40 · 10⁻⁶))
      = 20.0 - (-10.0)
      = 30.0 °C                     [температура максимального опору]
```

У точці `T_max = 30.0 °C` температурна залежність опору стає локально нульовою (`TCR = 0`). 

Обчислимо зміну опору `ΔR / R_0` при відхиленні температури на `±5 °C` від точки максимуму (в інтервалі від `25 °C` до `35 °C`):

```
ΔT_vertex = T - T_max = 5.0 K           [відхилення від вершини параболи, де лінійний доданок α·ΔT дорівнює нулю]
ΔR / R_0 = β · (ΔT_vertex)²             [квадратичний внесок квадратичного коефіцієнта β]
         = (-0.40 · 10⁻⁶ K⁻²) · (5.0 K)²
         = -10.0 · 10⁻⁶ = -10 ppm = -0.001 %
```

Цей розрахунок показує, що в околі вершини параболи `T_max ± 5 °C` зміна опору не перевищує тисячної частки відсотка, що забезпечує найвищу точність метрологічних вимірювань.

Для досягнення мінімальної температурної чутливості у лабораторному приладі технологічну термообробку манганіну підбирають так, щоб змістити `T_max` точно на робочу температуру термостатованого корпусу (наприклад, `23.0 °C`).

## 3. Кубічні поправки вищого порядку при широких температурних інтервалах

При розширенні досліджуваного температурного діапазону понад `100 °C` (наприклад, від `-100 °C` до `+200 °C`) квадратичного полінома стає недостатньо через наростання асиметрії кривої `R(T)`. У цьому випадку використовують кубічне рівняння розкладу Тейлора:

```
R(T) = R_0 · [1 + α · (T - T_0) + β · (T - T_0)² + γ · (T - T_0)³]
```

де `γ` — кубічний коефіцієнт асиметрії параболи (порядок `10⁻⁹ K⁻³` або `ppm/K³`).

Диференціальний ТКО з урахуванням кубічної поправки набуває вигляду:

```
TCR(T) = α + 2 · β · (T - T_0) + 3 · γ · (T - T_0)²
```

Кубічний внесок описує зміщення точки максимуму `T_max` при розігріві провідника високими струмами навантаження.

## 4. Математична модель виведення термоелектрорушійної сили (ефект Зеєбека)

При з'єднанні манганіну або константану з мідними провідниками виникає термоелектричне коло. Згідно з квантово-статистичною теорією Мотта — Ейзенмана, диференціальний коефіцієнт Зеєбека `S` металевого провідника визначається логарифмічною похідною провідності по енергії на рівні Фермі `E_F`:

```
S = (π² / 3) · (k_B² · T / e) · [d ln σ(E) / dE]  (при E = E_F)
```

де `k_B` — константа Больцмана, `e` — заряд електрона, `σ(E)` — енергетична залежність електропровідності.

Для нерівномірно нагрітого провідника із градієнтом температур між двома контактами `T_1` та `T_2` результуюча напруга термо-ЕРС `V_emf` визначається інтегралом від диференціальної різниці коефіцієнтів Зеєбека міді `S_Cu` та сплаву `S_alloy`:

```
V_emf = ∫ [S_Cu(T) - S_alloy(T)] dT  (інтегрування від T_2 до T_1)
```

Для відносно невеликих температурних перепадів `ΔT = T_1 - T_2` напруга термо-ЕРС лінеаризується через диференціальний коефіцієнт Зеєбека `S_Cu-alloy`:

```
V_emf = S_Cu-alloy · ΔT              [лінійна апроксимація термо-ЕРС]
```

Відносна похибка вимірювання напруги на шунті `δ_emf` дорівнює відношенню паразитної термо-ЕРС `V_emf` до корисного спаду напруги `V_shunt = I · R`:

```
δ_emf = V_emf / V_shunt
      = (S_Cu-alloy · ΔT) / (I · R)  [відносна похибка DC-вимірювання]
```

**Порівняльний чисельний розрахунок похибки для константану та манганіну**:
Розглянемо вимірювальний шунт з номінальним падінням напруги `V_shunt = 100 мВ` при робочому струмі `100 А`. Нехай внаслідок асиметричного охолодження між потенційними контактами виник градієнт температур `ΔT = 10 K`.

1. **Для константану** (`S_Cu-CuNi44 = -43 мкВ/К`):
   ```
   V_emf = (-43 · 10⁻⁶ В/К) · 10 К = -430 · 10⁻⁶ В = -0.43 мВ
   δ_emf = -0.43 мВ / 100 мВ = -0.0043 = -0.43 %
   ```
   Паразитна термо-ЕРС створює неприпустиму похибку `-0.43%`, що у 430 разів перевищує допустимий клас точності метрологічного шунта (`0.001%`).

2. **Для манганіну** (`S_Cu-CuMn12Ni2 = +1.5 мкВ/К`):
   ```
   V_emf = (+1.5 · 10⁻⁶ В/К) · 10 К = +15 · 10⁻⁶ В = +0.015 мВ
   δ_emf = +0.015 мВ / 100 мВ = +0.00015 = +0.015 %
   ```
   Використання манганіну зменшує систематичну термоелектричну похибку вимірювання у `28.6 разів`, зводячи її до безпечного рівня.

## 5. Метод найменших квадратів для обчислення α та β з експериментальних даних

При лабораторній калібровці партії прецизійних резисторів вимірюють опір `R_i` при `N` різних температурах `T_i`. Для визначення коефіцієнтів `R_0`, `α` та `β` мінімізують суму квадратів відхилень `S_res`:

```
S_res = ∑ [R_i - R_0 · (1 + α · ΔT_i + β · ΔT_i²)]²  (сумування i від 1 до N)
```

де `ΔT_i = T_i - 20.0 °C`.

Ввівши позначення заміни `c_0 = R_0`, `c_1 = R_0 · α`, `c_2 = R_0 · β`, отримуємо лінійну систему рівнянь розшуку невизначених коефіцієнтів (систему нормальних рівнянь 3x3):

```
┌                     ┐   ┌     ┐     ┌        ┐
│ N    ∑ΔT    ∑ΔT²    │   │ c_0 │     │  ∑R_i  │
│ ∑ΔT  ∑ΔT²   ∑ΔT³    │ · │ c_1 │  =  │ ∑ΔT·R_i│
│ ∑ΔT² ∑ΔT³   ∑ΔT⁴    │   │ c_2 │     │∑ΔT²·R_i│
└                     ┘   └     ┘     └        ┘
```

Розв'язок цієї матричної системи методом Крамера або Гаусса дає точні значення оцінок `c_0`, `c_1`, `c_2`, з яких обчислюють фізичні параметри ТКО:

```
R_0 = c_0
α = c_1 / c_0
β = c_2 / c_0
```

Математичні рівняння нормальної системи 3x3 забезпечують однозначне знаходження global екстремуму функції неузгодженості, якщо вимірювальні точки охоплюють діапазон не менше `40 °C` із кроком `5–10 °C`.

## 6. Оцінка невизначеності обчислення коефіцієнтів ТКО

Точність визначення розрахованих коефіцієнтів `α` та `β` залежить від точності вимірювання температури `u(T)` та опору `u(R)`. Відповідно до міжнародного керівництва з вираження невизначеності вимірювань (GUM), стандартна розширена невизначеність `u(α)` обчислюється через часткові похідні:

```
u²(α) = (∂α / ∂R)² · u²(R) + (∂α / ∂T)² · u²(T)
```

При використанні платинового термометра опору (Pt100/Pt1000) із похибкою `u(T) = 0.01 °C` та 8.5-розрядного нанівольтметра із похибкою `u(R) = 0.1 ppm` відносна невизначеність визначення ТКО `α` не перевищує `0.05 ppm/K`, що відповідає вимогам первинних державне метрологічних центрів.
