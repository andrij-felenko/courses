# 🧮 Математична модель ін'єкції та рівняння неперервності

Аналіз транспорту носіїв заряду в напівпровідникових приладах спирається на диференціальні рівняння неперервності. Вони виражають фундаментальний закон збереження електричного заряду у визначеному об'ємі напівпровідника з урахуванням тривимірного дрейфово-дифузійного струму, швидкості генерації та швидкості рекомбінації носіїв. Для неосновних носіїв (наприклад, дірок у n-області) диференціальне рівняння неперервності пов'язує часову зміну концентрації `p(x,t)` із градієнтом густини струму `J_p(x,t)`, генерацією `G_p` та рекомбінацією `R_p`.

Ця вставка містить строгий математичний вивід рівняння неперервності, розгляд граничних умов Закон переходу Шоклі, аналіз дифузійних профілів для довгих та коротких баз, а також вивід рівняння амбіполярного транспорту для високого рівня ін'єкції.

---

### 1. Детальний вивід рівняння неперервності у 1D випадку

Розглянемо елементарний шар напівпровідника товщиною `dx` та площею поперечного перерізу `A`, розташований уздовж осі `x`. Кількість дірок у цьому об'ємі змінюється за рахунок двох фундаментальних чинників: просторового припливу або відпливу струму через бічні межі `x` та `x + dx`, а також внутрішніх процесів генерації та рекомбінації носіїв.

Баланс кількості частинок у наведеному об'ємі за елементарний проміжок часу `dt` записується виразом:

```
[Зміна кількості частинок] 
= [Вхідний потік] - [Вихідний потік] + [Генерація] - [Рекомбінація]

dp · A · dx
= ( J_p(x)/q - J_p(x+dx)/q ) · A · dt + ( G_p - R_p ) · A · dx · dt
```

Розкладаючи густину струму `J_p(x+dx)` у ряд Тейлора першого порядку за координатою `x`:

```
J_p(x+dx) ≈ J_p(x) + ( dJ_p / dx ) · dx
```

Підставляючи цей розклад у рівняння балансу та скорочуючи обидві частини на об'єм елементарного шару `A · dx` та крок часу `dt`, отримуємо фундаментальне одновимірне рівняння неперервності для дірок:

```
dp / dt = - (1/q) · ( dJ_p / dx ) + G_p - R_p
```

Аналогічно, для електронів, враховуючи від'ємний знак їхнього електричного заряду `-q`:

```
dn / dt = (1/q) · ( dJ_n / dx ) + G_n - R_n
```

Густина струму дірок `J_p` у загальному випадку є сумою дрейфового струму під дією електричного поля `E` та дифузійного струму, викликаного градієнтом концентрації дірок `dp/dx`:

```
J_p = q · μ_p · p · E - q · D_p · ( dp / dx )
```

Вважаючи рухливість `μ_p` та коефіцієнт дифузії `D_p` однорідними вздовж напівпровідника, підставимо вираз для густини струму `J_p` у рівняння неперервності:

```
dJ_p / dx = q · μ_p · d(p · E) / dx - q · D_p · ( d²p / dx² )
```

Підставляючи цю похідну у рівняння неперервності, маємо загальне рівняння транспорту меншинних дірок:

```
dp / dt = D_p · ( d²p / dx² ) - μ_p · ( d(p · E) / dx ) + G_p - R_p
```

Це рівняння є диференціальним рівнянням у приватних похідних другого порядку параболічного типу (типу адвекції-дифузії-реакції).

### 2. Режим низького рівня ін'єкції (Low-Level Injection)

У режимі низького рівня ін'єкції надлишкова концентрація впорсканих неосновних носіїв `Δp(x,t) = p(x,t) - p_n0` є набагато меншою за рівноважну концентрацію основних носіїв у кристалі `n_n0`:

```
Δp << n_n0
```

Ця умова дозволяє зробити три важливі математичні й фізичні спрощення:

1. **Сталість провідності основних носіїв**: Зміна концентрації основних електронів є нехтувально малою порівняно з їхньою початковою кількістю: `n_n ≈ n_n0 = const`.
2. **Відсутність внутрішнього дрейфового поля**: Квазінейтральна область n-типу залишається практично повністю нейтральною без залучення помітних додаткових носіїв. Електричне поле в об'ємі є крихітним (`E ≈ 0`), тому дрейфовим доданком `μ_p · d(p·E)/dx` можна повністю знехтувати порівняно з дифузійним.
3. **Лінійність рекомбінації**: Чиста швидкість рекомбінації `U_p = R_p - G_p` строго лінійно залежить від надлишкової концентрації меншинних носіїв:

```
U_p = R_p - G_p = Δp / τ_p
```

де `τ_p` — сталий час життя меншинних носіїв.

З урахуванням цих спрощень рівняння неперервності для надлишкової концентрації дірок `Δp` у стаціонарному режимі (`d(Δp)/dt = 0`) за відсутності зовнішнього оптичного підсвічування набуває вигляду:

```
D_p · ( d²(Δp) / dx² ) - ( Δp / τ_p ) = 0
```

Поділивши обидві частини рівняння на коефіцієнт дифузії `D_p` та ввівши характеристичну просторову шкалу — **дифузійну довжину `L_p = √(D_p · τ_p)`**, отримуємо класичне диференціальне рівняння дифузії:

```
d²(Δp) / dx² - ( Δp / L_p² ) = 0
```

Характеристичне рівняння для даної диференціальної системи має вигляд `r² - (1 / L_p²) = 0`, корені якого `r = ± 1 / L_p`. Отже, загальний розв'язок записується у вигляді суми двох експоненціальних функцій:

```
Δp(x) = C_1 · exp( -x / L_p ) + C_2 · exp( x / L_p )
```

де константи `C_1` та `C_2` визначаються конкретними геометричними та фізичними граничними умовами напівпровідникового зразка.

### 3. Граничні умови та Закон переходу Шоклі

Для знаходження констант інтегрування розглянемо граничні умови на межах квазінейтральної n-області.

#### Межова умова на кордоні зі збідненою зоною (`x = 0`)

На лівій межі квазінейтральної n-області (`x = 0`), що межує зі збідненою зоною `p-n` переходу, прикладена пряма напруга `V` знижує потенціальний бар'єр. Згідно із Законом переходу Шоклі, квазірівні Фермі для електронів `E_Fn` та дірок `E_Fp` усередині тонкого збідненого шару залишаються практично горизонтальними, що дає расщеплення `E_Fn - E_Fp = q · V`.

Тоді повна концентрація дірок на межі `p_n(0)` визначається як:

```
p_n(0) = p_n0 · exp( q · V / (k · T) )
```

Звідси надлишкова концентрація `Δp(0)` на межі `x = 0` становить:

```
Δp(0) = p_n(0) - p_n0 = p_n0 · ( exp( q · V / (k · T) ) - 1 )
```

#### Межові умови на зовнішній границі кристала

Форма розподілу носіїв залежить від співвідношення між товщиною квазінейтральної n-області `W_n` та дифузійною довжиною `L_p`.

**Сценарій А: Довгий напівпровідник (`W_n >> L_p`)**

Для довгої бази на великій відстані від переходу (`x → ∞`) усі інжектовані дірки повністю рекомбінують з основними електронами, тому надлишкова концентрація прямує до нуля: `Δp(∞) = 0`.

З цієї умови випливає, що константа `C_2 = 0`. Константи `C_1 = Δp(0)`. Отже, розв'язок для довгого напівпровідника має чистий експоненційний вигляд:

```
Δp(x) = Δp(0) · exp( -x / L_p ) = p_n0 · ( exp( q·V / (k·T) ) - 1 ) · exp( -x / L_p )
```

Густина дифузійного струму дірок `J_p(x)` обчислюється шляхом диференціювання розподілу `Δp(x)`:

```
J_p(x) = - q · D_p · ( d(Δp) / dx ) = ( q · D_p · Δp(0) / L_p ) · exp( -x / L_p )
```

На межі збідненої області (`x = 0`) густина струму впорсканих дірок дорівнює:

```
J_p(0) = ( q · D_p · p_n0 / L_p ) · ( exp( q · V / (k · T) ) - 1 )
```

**Сценарій Б: Короткий напівпровідник з омічним контактом (`W_n << L_p`)**

Якщо товщина n-області `W_n` набагато менша за дифузійну довжину `L_p`, а на відстані `x = W_n` розташований ідеальний омічний контакт з нескінченною швидкістю поверхневої рекомбінації (`S → ∞`), то на цьому контакті надлишкова концентрація миттєво обнуляється: `Δp(W_n) = 0`.

Розкладаючи експоненціальні функції в ряд Тейлора для `x / L_p << 1`, отримуємо **лінійний профіль розподілу носіїв**:

```
Δp(x) ≈ Δp(0) · ( 1 - x / W_n )
```

У цьому разі градієнт концентрації `d(Δp)/dx = - Δp(0) / W_n` є сталим уздовж усієї бази, а густина дифузійного струму дірок дорівнює:

```
J_p = q · D_p · Δp(0) / W_n = ( q · D_p · p_n0 / W_n ) · ( exp( q · V / (k · T) ) - 1 )
```

Порівняння цих двох сценаріїв показує, що у короткій базі дифузійний струм зростає в `L_p / W_n` разів, оскільки рекомбінація в об'ємі не встигає згасити потік частинок.

### 4. Вивід Вольт-Амперної характеристики ідеального діода Шоклі

Повний струм `J`, що протікає через `p-n` перехід, дорівнює сумі дифузійних струмів інжектованих дірок `J_p(0)` та інжектованих електронів `J_n(0)` на відповідних межах збідненої зони:

```
J = J_p(0) + J_n(0)
```

Підставляючи вирази для інжектованого струму дірок у n-область та інжектованого струму електронів у p-область для випадку довгих областей:

```
J_p(0) = ( q · D_p · p_n0 / L_p ) · ( exp( q·V / (k·T) ) - 1 )
J_n(0) = ( q · D_n · n_p0 / L_n ) · ( exp( q·V / (k·T) ) - 1 )
```

Отримуємо класичне **рівняння ідеального діода Шоклі**:

```
J = J_s · ( exp( q · V / (k · T) ) - 1 )
```

де густина теплового струму насичення `J_s` становить:

```
J_s = q · ( ( D_p · p_n0 / L_p ) + ( D_n · n_p0 / L_n ) )
```

Виразивши рівноважні концентрації меншинних носіїв через власну концентрацію напівпровідника `n_i` та концентрації легуючих донорних `N_D` й акцепторних `N_A` домішок (`p_n0 = n_i² / N_D` та `n_p0 = n_i² / N_A`), отримуємо остаточну формулу струму насичення:

```
J_s = q · n_i² · ( ( D_p / ( L_p · N_D ) ) + ( D_n / ( L_n · N_A ) ) )
```

Ця формула показує, що струм насичення `J_s` експоненційно залежить від температури через квадрат власної концентрації `n_i² ∝ exp(-E_g / (k·T))` та обернено пропорційний рівням легування напівпровідникових областей.

### 5. Високий рівень ін'єкції та Амбіполярне рівняння транспорту

Коли прямий струм стає дуже великим, надлишкова концентрація меншинних носіїв порівнюється з концентрацією основних носіїв або перевищує її (`Δp ≥ n_n0`). Квазінейтральність вимагає, щоб для компенсації позитивного заряду впорсканих дірок у квазінейтральну n-область прибула така ж кількість додаткових електронів: `Δn ≈ Δp`.

За цих умов повні концентрації носіїв становлять:

```
n(x,t) = n_n0 + Δp(x,t)
p(x,t) = p_n0 + Δp(x,t) ≈ Δp(x,t)
```

Оскільки електрони мають вищу рухливість, ніж дірки (`μ_n > μ_p`), вони намагаються дифундувати швидше. Це створює мікроскопічне просторове розділення заряду й породжує внутрішнє **амбіполярне електричне поле `E_amb`**.

Для виводу рівняння транспорту виразимо повний струм `J = J_n + J_p`:

```
J = q · ( μ_n · n + μ_p · p ) · E + q · D_n · ( dn / dx ) - q · D_p · ( dp / dx )
```

Враховуючи, що `dn/dx ≈ dp/dx = d(Δp)/dx`, виразимо електричне поле `E`:

```
E = ( J / ( q · ( μ_n·n + μ_p·p ) ) ) - ( ( D_n - D_p ) · ( d(Δp)/dx ) / ( μ_n·n + μ_p·p ) )
```

Підставляючи це значення поля `E` у рівняння неперервності для дірок і виконуючи алгебраїчні перетворення, отримуємо **Амбіполярне рівняння транспорту**:

```
d(Δp) / dt = D_amb · ( d²(Δp) / dx² ) - μ_amb · E_ext · ( d(Δp) / dx ) - ( Δp / τ_high )
```

де **амбіполярний коефіцієнт дифузії `D_amb`** визначається як:

```
D_amb = ( ( n + p ) · D_n · D_p ) / ( n · D_n + p · D_p )
```

а **амбіполярна рухливість `μ_amb`** становить:

```
μ_amb = ( ( n - p ) · μ_n · μ_p ) / ( n · μ_n + p · μ_p )
```

Розглянемо два граничні випадки для `D_amb` та `μ_amb`:

1. **Низький рівень ін'єкції в n-тип (`n >> p`)**:
   `D_amb → D_p`, `μ_amb → μ_p`. Рівняння зводиться до звичайного дифузійного транспорту меншинних дірок.
2. **Дуже високий рівень ін'єкції (`n ≈ p ≈ Δp`)**:
   `D_amb → ( 2 · D_n · D_p ) / ( D_n + D_p )`, а амбіполярна рухливість `μ_amb → 0`.

Зникнення амбіполярної рухливості (`μ_amb → 0`) при дуже високій ін'єкції означає, що плазмовий сгусток електрон-діркової пари перестає дрейфувати під дією зовнішнього електричного поля як єдине ціле і рухається **виключно за рахунок амбіполярної дифузії**. Це явище є визначальним для розрахунку динаміки перемикання силових приладів (IGBT, тиристорів та PIN-діодів).
