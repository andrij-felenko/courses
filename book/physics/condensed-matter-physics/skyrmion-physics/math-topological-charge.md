# 🧮 Топологічний інваріант та математична модель магнітного скирміона

Ця математична вставка містить строге виведення топологічного заряду магнітного скирміона, стереографічну проєкцію, параметризацію спінової текстури у полярній системі координат, доведення стабілізації за теоремою Дерріка та аналіз функціонала мікромагнітної вільної енергії.

## 1. Топологічний інваріант та стереографічна проєкція

Магнітний скирміон у двовимірному матеріалі описують безперервним векторним полем одиничної намагніченості `m(r) = (m_x(r), m_y(r), m_z(r))`, де фіксована норма `|m(r)| = 1` для кожної точки простору `r = (x, y)`. Завдяки крайовій умові далеко від центра скирміона, де намагніченість вирівнюється однорідно вздовж фонового магнітного поля (`m(r → ∞) = (0, 0, 1)`), нескінченну двовимірну площину `R²` можна топологічно компактифікувати до двовимірної сфери `S²`.

Геометрично цю компактифікацію здійснюють за допомогою стереографічної проєкції. Точка площини з полярними координатами `(r, φ)` відображається на одиничну сферу через комплексне число `z = (r / r_0) exp(i φ)`. Комплексна функція `w(z)`, що описує орієнтацію вектора намагніченості, пов'язана з компонентами поля `m` співвідношеннями:

```
w = (m_x + i m_y) / (1 + m_z)
m_x = (2 Re(w)) / (1 + |w|²)
m_y = (2 Im(w)) / (1 + |w|²)
m_z = (1 - |w|²) / (1 + |w|²)
```

Векторне поле `m(r)` здійснює відображення просторової сфери `S²` на цільову сферу порядку магнітного параметра `S²`. Класифікацію таких відображень задає друга гомотопічна група `π₂(S²) = Z`. Ступінь відображення — це ціле число, яке називають топологічним зарядом або топологічним інваріантом `Q`:

```
Q = (1 / 4π) ∬ m · ( (∂m / ∂x) × (∂m / ∂y) ) dx dy
```

Підінтегральний вираз виражає скалярний добуток вектора `m` з векторним добутком його просторових похідних. Цю величину називають топологічною щільністю `q(r)`:

```
q(r) = (1 / 4π) m · ( (∂m / ∂x) × (∂m / ∂y) )
```

Фізичний зміст величини `Q` полягає в тому, скільки разів вектор намагніченості `m` повністю ортає цільову одиничну сферу `S²`, коли точка `r` обходить усю площину `R²`. Оскільки інтеграл виражає телесний кут, заметенний вектором `m`, поділений на повний телесний кут сфери `4π`, значення `Q` завжди є цілим числом (`Q = 0, ±1, ±2...`).

Для гладких плавної деформації вектора `m(r)` значення `Q` залишається суворо незмінним. Щоб змінити `Q` (наприклад, знищити скирміон і перетворити його на однорідний феромагнітний стан з `Q = 0`), необхідно подолати високий енергетичний бар'єр, створивши точкову сингулярність безперервності спінового поля — сингулярну точку Блоха.

Також можна ввести топологічний струм `j_μ` у тривимірному просторі-часі `(x, y, t)`:

```
j_μ = (1 / 8π) ε_μνρ m · ( ∂_ν m × ∂_ρ m )
```

де `ε_μνρ` — повністю асиметричний тензор Леві-Чивіти. Закон збереження топологічного струму `∂_μ j_μ = 0` випливає безпосередньо з тотожності Бянкі для топологічного заряду, що гарантує збереження кількості скирміонів під час їхнього неперервного руху та взаємодії.

## 2. Сферична параметризація та полярні координати

Для аналізу аксіально-симетричних скирміонів зручно перейти до двовимірної полярної системи координат `(r, φ)`, де `x = r cos φ`, `y = r sin φ`. Вектор намагніченості `m(r, φ)` параметризують у сферичній системі координат кутом відхилення від вертикалі `Θ(r)` та азимутальним кутом спіна `Φ(φ)`:

```
m_x(r, φ) = sin Θ(r) · cos Φ(φ)
m_y(r, φ) = sin Θ(r) · sin Φ(φ)
m_z(r, φ) = cos Θ(r)
```

Залежність азимутального кута спінів `Φ` від просторового кута `φ` задають лінійним співвідношенням:

```
Φ(φ) = q · φ + γ
```

Тут визначено два фундаментальні параметри структури:
- `q` (вортичність / winding number) — ціле число, яке показує, скільки обертів робить вектор спіна при повному обході навколо центра скирміона по колу (`φ` від `0` до `2π`). Для звичайного скирміона `q = 1`, для антискирміона `q = -1`.
- `γ` (кут киральності / гелічність) — визначає орієнтацію спінів у площині:
  - `γ = ± π/2`: Блохівський скирміон (тангенційне обертання спінів, спіни перпендикулярні до радіус-вектора `r`);
  - `γ = 0` або `π`: Неєлівський скирміон (радіальне обертання, їжакоподібна структура).

Підставимо цю параметризацію в загальне визначення топологічного заряду `Q`:

```
∂m / ∂r = (dΘ/dr) · (cos Θ cos Φ, cos Θ sin Φ, -sin Θ)
∂m / ∂φ = q · sin Θ · (-sin Φ, cos Φ, 0)
```

Обчислимо векторний добуток частинних похідних:

```
(∂m / ∂r) × (∂m / ∂φ) = q · sin Θ (dΘ/dr) · (sin Θ cos Φ, sin Θ sin Φ, cos Θ)
                     = q · sin Θ (dΘ/dr) · m
```

Скалярний добуток з вектором `m` додає нормалізацію `m · m = 1`:

```
m · ( (∂m / ∂r) × (∂m / ∂φ) ) = q · sin Θ · (dΘ/dr)
```

Тепер обчислимо двовимірний інтеграл поверхні у полярній сітці з елементом площі `dx dy = r dr dφ`:

```
Q = (1 / 4π) ∫₀^∞ dr ∫₀^(2π) dφ [ q · sin Θ (dΘ/dr) ]
  = (q / 4π) · (∫₀^(2π) dφ) · (∫₀^∞ sin Θ (dΘ/dr) dr)
  = (q / 4π) · 2π · [ -cos Θ(r) ]₀^∞
  = (q / 2) · [ cos Θ(0) - cos Θ(∞) ]
```

Крайові умови для скирміона з ядром, спрямованим униз (`Θ(0) = π`, `cos Θ(0) = -1`), та периферією, спрямованою вгору (`Θ(∞) = 0`, `cos Θ(∞) = +1`):

```
Q = (q / 2) · [ -1 - 1 ] = -q
```

Отже, для скирміона з вортичністю `q = 1` топологічний заряд `Q = -1` (або `+1` при інверсії крайових умов), що підтверджує його квантований характер.

## 3. Теорема Дерріка та роль DMI у стабілізації розміру

У чистій феромагнітній моделі Гейзенберга без DMI та анізотропії існує фундаментальна теорема Дерріка (Derrick's theorem), яка стверджує, що двавимірні локалізовані солітони є масштабно нестійкими.

Розглянемо масштабування координат `r → λ r`. Обмінна енергія Гейзенберга `E_ex = A ∬ (∇m)² dx dy` при такій трансформації змінює коефіцієнт як `λ⁰ = 1`, тобто є масштабно інваріантною. Це означає, що енергія скирміона за умови наявності лише обміну Гейзенберга не залежить від його радіуса `R_sk`. Додавання зеєманівської енергії поля або магнітної анізотропії (які масштабуються як `λ²`) приводить до того, що стискання скирміона до нуля (`R_sk → 0`) монотонно знижує загальну енергію системи. Без DMI ізольований скирміон неминуче колапсує.

Взаємодія Дзялошинського — Моріа (DMI) містить перші просторові похідні `m` і при масштабуванні `r → λ r` змінюється пропорційно `λ¹`. Оскільки внесок DMI в енергію є від'ємним для правильно вибраної киральності, функціонал повної енергії набуває чіткого локального мінімуму при скінченному радіусі `R_sk > 0`. Саме конкуруючий внесок DMI зупиняє колапс і стабілізує скирміон як стійку квазічастинку.

## 4. Мікромагнітний функціонал вільної енергії

Термодинамічну стійкість та характерний радіус скирміона `R_sk` визначають мінімізацією функціонала континуальної мікромагнітної енергії `E[m]`:

```
E[m] = ∬ ( w_ex + w_DMI + w_ani + w_Z ) dx dy
```

Розглянемо внесок кожної фізичної взаємодії окремо:

### 4.1. Симетричний обмін Гейзенберга (Exchange Energy)

Обмінна енергія прагне зробити векторне поле однорідним:

```
w_ex = A · [ (∇m_x)² + (∇m_y)² + (∇m_z)² ]
```

Тут `A` (в `J/m`) — константа обмінної жорсткості. У полярних координатах для симетричної профілю:

```
w_ex = A · [ (dΘ/dr)² + (q² / r²) sin² Θ ]
```

### 4.2. Взаємодія Дзялошинського — Моріа (DMI)

Асиметричний обмін виникає через спін-орбітальний зв'язок у кристалах без центра інверсії або на межах розподілу важкий метал / феромагнетик:

- Об'ємний DMI (bulk DMI, характерний для кристалів `MnSi` чи `FeGe`):

```
w_DMI_bulk = D · m · (∇ × m)
```

- Інтерфейсний DMI (interfacial DMI, характерний для тонкоплівкових структур `Pt/Co/MgO`):

```
w_DMI_int = D · [ m_z (∇ · m) - (m · ∇) m_z ]
```

Тут `D` (в `J/m²`) — константа DMI. Інтерфейсна DMI зануляє енергію саме для Неєлівських скирміонів з `γ = 0` або `π`, тоді як об'ємна DMI віддає перевагу Блохівським скирміонам з `γ = ± π/2`. У полярній параметризації для Неєлівського скирміона:

```
w_DMI_int = D · [ (dΘ/dr) + (1/r) sin Θ cos Θ ]
```

### 4.3. Перпендикулярна магнітна анізотропія (PMA)

У тонких плівках легка вісь магнітної анізотропії спрямована перпендикулярно до площини (вздовж осі `z`):

```
w_ani = K_u · (1 - m_z²) = K_u · sin² Θ
```

Тут `K_u` (в `J/m³`) — константа перпендикулярної анізотропії.

### 4.4. Зеєманівська енергія (Зовнішнє магнітне поле)

Зовнішнє магнітне поле `H`, спрямоване уздовж осі `z`:

```
w_Z = -M_s · H · (m_z - 1) = M_s · H · (1 - cos Θ)
```

Тут `M_s` (в `A/m`) — намагніченість насичення.

## 5. Рівняння Ейлера — Лагранжа та асимптотичний профіль

Різниця варіації функціонала `δE / δΘ = 0` дає нелінійне звичайне диференціальне рівняння другого порядку для радіального профілю `Θ(r)`:

```
A · [ (d²Θ/dr²) + (1/r)(dΘ/dr) - (q²/r²) sin Θ cos Θ ] 
+ D · (q / r) sin² Θ - K_eff sin Θ cos Θ - M_s H sin Θ = 0
```

де `K_eff = K_u - (1/2) μ₀ M_s²` — ефективна магнітна анізотропія.

Для розв'язання цього рівняння застосовують два граничні асимптотичні режими:

1. **Поблизу центра скирміона (`r → 0`):**
   Кут відхилення близький до `π`: `Θ(r) ≈ π - c · r`. Лінеаризація дає лінійне зростання відхилення від вертикалі.

2. **На великих відстанях від центра (`r → ∞`):**
   Кут `Θ(r)` є малим (`sin Θ ≈ Θ`, `cos Θ ≈ 1`). Диференціальне рівняння переходь у модифіковане рівняння Бесселя:

```
(d²Θ/dr²) + (1/r)(dΘ/dr) - ( (1/r²) + (1 / L_sk²) ) Θ = 0
```

де `L_sk = √( A / (K_eff + M_s H) )` — характеристична анізотропна довжина згасання скирміона.

Асимптотичний розв'язок на великих відстанях має вигляд модифікованої функції Бесселя другого роду `K₁(r / L_sk)`, яка при `r >> L_sk` експоненціально спадає:

```
Θ(r) ∝ (1 / √r) · exp( - r / L_sk )
```

Це експоненціальне згасання підтверджує, що скирміон є строго локалізованою у просторі квазічастинкою з чітко визначеним ефективним радіусом `R_sk`.

## 6. Критерій спонтанного формування скирміонної фази

Аналіз енергетичного балансу дозволяє обчислити критичне значення DMI `D_c`, при якому однорідний феромагнітний стан стає нестійким щодо утворення скирміонів:

```
D_c = (4 / π) · √(A · K_eff)
```

- Якщо `|D| < D_c`, скирміони можуть існувати лише як метастабільні ізольовані збудження у зовнішньому магнітному полі `H`.
- Якщо `|D| ≥ D_c`, енергія скирміонного стану стає від'ємною порівняно з феромагнітним фоном, і у матеріалі спонтанно утворюється періодична ґратка скирміонів навіть за відсутності зовнішнього поля.
