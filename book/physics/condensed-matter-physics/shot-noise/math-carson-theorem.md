# 🧮 Теорема Карсона та спектральна густина дробового струму

Математичний вивід формули Шотткі для спектральної густини потужності дробового шуму спирається на теорію пуассонівських випадкових процесів, теореми Кемпбелла та теорему Карсона (Carson's theorem). Цей строгий аналіз дає змогу встановити безпосередній аналітичний зв'язок між часовою формою одиночного імпульсу струму, який наводиться рухом окремої зарядженої частинки, випадковим розподілом моментів емісії та підсумковим спектром флуктуацій у зовнішньому колі.

Розглянемо макроскопічний електричний струм `I(t)`, що протікає через провідник або вакуумний проміжок. Струм утворюється внаслідок проходження дискретних носіїв заряду `q`. Якщо частинка з номером `k` проходить через спостережуваний переріз або долає потенціальний бар'єр у випадковий момент часу `t_k`, вона наводить у зовнішньому колі елементарний імпульс струму `i_1(t - t_k)`. Загальний струм у довільний момент часу `t` виражається як суперпозиція імпульсів від усіх частинок:

```
I(t) = ∑ i_1(t - t_k)
```

де підсумовування виконується за всіма подіями `k`, які відбулися за час роботи системи.

Припустимо, що моменти надходження частинок `t_k` утворюють стаціонарний пуассонівський процес із середньою інтенсивністю `n̄` (середня кількість електронів за одиницю часу). Це означає виконання трьох фундаментальних умов:
1. **Незалежність:** ймовірність появи частинки в інтервалі часу `[t, t + Δt]` не залежить від того, скільки частинок вилетіло раніше.
2. **Ордність:** ймовірність одночасної появи двох або більше частинок в нескінченно малому інтервалі `Δt` є величиною вищого порядку малості `o(Δt)`.
3. **Стаціонарність:** середня частота подій `n̄` є постійною величиною у часі.

Для аналізу статистичних моментів такого струму застосуємо теореми Кемпбелла. Перша теорема Кемпбелла визначає математичне сподівання (середнє значення) струму `⟨I⟩`. Для цього усереднимо вираз суперпозиції за часовим ансамблем:

```
⟨I⟩ = n̄ · ∫ i_1(t) dt     [від -∞ до +∞]
```

Оскільки інтеграл від часового профілю імпульсу струму одиночної частинки за весь час її проходження `i_1(t)` за означенням дорівнює переносу її повного заряду `q`:

```
∫ i_1(t) dt = q
```

підстановка дає стандартну макроскопічну формулу для постійного струму:

```
⟨I⟩ = n̄ · q
```

Друга теорема Кемпбелла визначає дисперсію флуктуацій струму `Var(I) = ⟨(I(t) - ⟨I⟩)²⟩`. Оскільки події емісії є незалежними, дисперсія суми дорівнює сумі дисперсій окремих імпульсів:

```
Var(I) = n̄ · ∫ (i_1(t))² dt
```

Для аналізу розподілу потужності флуктуацій за частотами визначимо автокореляційну функцію флуктуацій струму `R_I(τ)`, де `ΔI(t) = I(t) - ⟨I⟩`:

```
R_I(τ) = ⟨ΔI(t) · ΔI(t + τ)⟩
```

Підставивши вираз для `ΔI(t)` через суму елементарних імпульсів і врахувавши, що для незалежних подій `k ≠ m` перехресні середні дорівнюють нулю `⟨i_1(t - t_k) · i_1(t + τ - t_m)⟩ = 0`, маємо:

```
R_I(τ) = n̄ · ∫ i_1(t) · i_1(t + τ) dt
```

За теоремою Вінера — Хінчина, спектральна густина потужності флуктуацій струму `S_I(ω)` пов'язана з автокореляційною функцією `R_I(τ)` двостороннім перетворенням Фур'є:

```
S_I(ω) = 2 · ∫ R_I(τ) · exp(-j · ω · τ) dτ     [від -∞ до +∞]
```

Множник `2` у цій формулі відповідає прийнятій у фізиці та радіотехніці односторонній спектральній густині (визначеній лише для додатних частот `f ≥ 0`).

Підставимо вираз для автокореляційної функції через інтеграл імпульсів у перетворення Фур'є:

```
S_I(ω) = 2 · n̄ · ∫ [∫ i_1(t) · i_1(t + τ) dt] · exp(-j · ω · τ) dτ
```

Змінивши порядок інтегрування та зробивши заміну змінної `u = t + τ` (звідси `τ = u - t`, `dτ = du`), маємо:

```
S_I(ω) = 2 · n̄ · ∫ i_1(t) · exp(j · ω · t) dt · ∫ i_1(u) · exp(-j · ω · u) du
```

Перший інтеграл є комплексно-спряженим до другого інтеграла. Другий інтеграл є прямо відповідним фур'є-образом одиночного імпульсу струму `F(ω)`:

```
F(ω) = ∫ i_1(t) · exp(-j · ω · t) dt
```

Отже, добуток комплексних інтегралів дорівнює квадрату модуля `|F(ω)|²`. Це прямо доводить **теорему Карсона (Carson's theorem)**:

```
S_I(ω) = 2 · n̄ · |F(ω)|²
```

Розглянемо два найважливіших фізичних застосування теореми Карсона.

### 1. Низькочастотна границя та класична формула Шотткі

Якщо робоча частота `ω` є значно меншою за обернений час прольоту частинки `1 / τ_tr`, тривалістю одиночного імпульсу можна знехтувати. У часовій області імпульс струму моделюється дельта-функцією Дірака:

```
i_1(t) = q · δ(t)
```

Обчислимо фур'є-образ дельта-імпульсу:

```
F(ω) = ∫ q · δ(t) · exp(-j · ω · t) dt
     = q · exp(0)     [підстановка t = 0 за властивістю дельта-функції]
     = q              [оскільки exp(0) = 1]
```

Модуль фур'є-образу є постійною величиною `|F(ω)| = q` на всіх частотах. Підставивши цей результат у теорему Карсона, отримуємо **класичну формулу Шотткі**:

```
S_I(ω) = 2 · n̄ · q²
       = 2 · q · (n̄ · q)     [оскільки n̄ · q = ⟨I⟩]
       = 2 · q · ⟨I⟩
```

Отже, точковий пуассонівський процес викликає абсолютно плаский шумовий спектр, потужність якого прямо пропорційна величині заряду частинки `q` та середному струму `⟨I⟩`.

### 2. Скінченний час прольоту та високочастотний зріз

Розглянемо випадок, коли електрон з зарядом `q` пролітає між двома паралельними плоскими електродами за скінченний час `τ_tr` з постійною швидкістю. Згідно з теоремою Шокли — Рамо, струм, наведений на електродах під час руху частинки, має прямокутний профіль:

```
i_1(t) = q / τ_tr     при 0 ≤ t ≤ τ_tr
i_1(t) = 0            при решті t
```

Обчислимо фур'є-образ прямокутного імпульсу:

```
F(ω) = ∫ (q / τ_tr) · exp(-j · ω · t) dt     [від 0 до τ_tr]
     = (q / (j · ω · τ_tr)) · [1 - exp(-j · ω · τ_tr)]
```

Квадрат модуля цього виразу дорівнює:

```
|F(ω)|² = q² · [sin(ω · τ_tr / 2) / (ω · τ_tr / 2)]²
```

Позначивши безрозмірний фактор частотного зрізу через `χ(ω) = [sin(ω · τ_tr / 2) / (ω · τ_tr / 2)]²`, підставимо його в теорему Карсона:

```
S_I(ω) = 2 · q · ⟨I⟩ · χ(ω)
```

При `ω · τ_tr ≪ 1` значення `χ(ω) → 1`, і спектр залишається білим. При `ω ≈ 2 π / τ_tr` значення `χ(ω)` спадає за законом `1 / ω²`, утворюючи високочастотний зріз шуму через усереднення імпульсів за час прольоту.

### 3. Квантовий перенос та формалізм Ландауера — Бюттікера

У квантових мезоскопічних провідниках (квантові точкові контакти, нанодротини) перенос описується набором квантових каналів із коефіцієнтами прозорості `T_n ∈ [0, 1]`. За формулою Ландауера — Бюттікера, з урахуванням статистики Фермі — Дирака, загальна спектральна густина флуктуацій струму при довільній температурі `T` і напрузі `V` становить:

```
S_I = 4 · k_B · T · G + 2 · (e³ · V / h) · coth(e · V / (2 · k_B · T)) · ∑ T_n · (1 - T_n)
```

де `G = (2 e² / h) · ∑ T_n` — повна квантова провідність пристрою.

З цієї видатної формули випливають дві важливі фізичні границі:
- **Рівноважна межа (`e V ≪ k_B T`):** дробовий член зникає, і формула переходіть у чисто тепловий шум Найквіста: `S_I = 4 k_B T G`.
- **Нерівноважна межа (`e V ≫ k_B T`):** при `T → 0` маємо чисто нерівноважний квантовий дробовий шум:

```
S_I = 2 · e · I · F
```

де фактор Фано `F` повністю визначається коефіцієнтами прозорості каналів:

```
F = [∑ T_n · (1 - T_n)] / [∑ T_n]
```

Якщо канал є повністю прозорим (`T_n = 1`, балістичний режим), то `T_n · (1 - T_n) = 0`, і фактор Фано дорівнює нулю `F = 0`. Кулонівське та фермієвське відштовхування електронів у повністю прозорому квантовому каналі повністю пригнічує дробовий шум, роблячи потік носіїв ідеально впорядкованим.
