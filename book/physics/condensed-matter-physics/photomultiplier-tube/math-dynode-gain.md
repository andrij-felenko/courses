# 🧮 Математична модель підсилення та флуктуацій ФЕУ

Математичний аналіз фотоелектронного помножувача дозволяє кількісно розрахувати каскадне підсилення струму, оцінити чутливість коефіцієнта помноження до нестабільності напруги живлення та обчислити флуктуаційні шуми, що виникають через статистичний характер вторинної електронної емісії.

### 1. Фізика вторинної емісії та залежність від напруги

Коефіцієнт вторинної емісії `δ` показує середню кількість вторинних електронів, які вибиває один первинний електрон при ударі об поверхню дінода. Емпірично та з зонної теорії емісії залежність `δ` від міжелектродної прискорювальної напруги `V_d` описується степеневим законом:

```
δ(V_d) = A · V_d^α
```

тут:
- `V_d` — прискорювальна напруга між двома суміжними дінодами (зазвичай 100–250 В);
- `A` — константа матеріалу поверхні дінода (залежить від роботи виходу, гладкості та електронної спорідненісті);
- `α` — показник степеня, який для більшості сурм'яно-цезієвих та берилієвих дінодів лежить у межах `0.7 ≤ α ≤ 0.8`.

Фізично цей закон пояснюється тим, що з підвищенням прискорювальної напруги `V_d` зростає кінетична енергія первинного електрона `E_k = e · V_d`. Вона іонізує більшу кількість атомів кристалічної ґратки дінода, породжуючи більшу кількість вторинних електронів. Однак при занадто високих напругах (`V_d > 500 В`) первинний електрон проникає занадто глибоко в товщу емітера, і вибитим електронам стає важче дифундувати до поверхні без втрати енергії, що призводить до насичення та подальшого падіння `δ`.

Екстремум коефіцієнта вторинної емісії `δ_max` для стандартних матеріалів досягається при енергіях первинних електронів 400–600 еВ. У практичних ФЕУ робоча точка обирається на висхідній ділянці кривої (`V_d = 100..200 В`), де залежність є строго монотонною і передбачуваною.

### 2. Загальний коефіцієнт підсилення каскаду

Якщо дінодна система містить `N` однакових ступенів підсилення з однаковим міжелектродним розподілом напруги `V_d = V_total / (N + 1)`, то загальний коефіцієнт підсилення струму `M` визначається як добуток коефіцієнтів емісії всіх каскадів:

```
M = ∏[i=1..N] δ_i = δ^N
```

Підставивши вираз для `δ(V_d)`, отримуємо повну залежність підсилення від повної напруги живлення `V_total`:

```
M = (A · (V_total / (N + 1))^α)^N
M = C · V_total^(α·N)
```

де `C = (A / (N + 1)^α)^N` — стала величина для даної трубки та дільника.

Позначивши `k = α·N`, маємо компактну формулу:

```
M(V_total) = C · V_total^k
```

Для типового ФЕУ з `N = 10` дінодами та `α = 0.75` показник степеня становить `k = 0.75 · 10 = 7.5`.

#### Чутливість підсилення до нестабільності напруги

Знайдемо відносну зміну підсилення `dM / M` через логарифмічне диференціювання:

```
ln(M) = ln(C) + k · ln(V_total)

dM / M = k · (dV_total / V_total)
```

При `k = 8` зміна напруги живлення всього на **1%** викликає зміну коефіцієнта підсилення анодного струму на **8%**:

```
dM / M = 8 · 1% = 8%
```

Цей висновок визначає критичну вимогу до джерел живлення ФЕУ: високовольтний блок повинен мати пульсації та нестабільність напруги нижче 0.05–0.1%. Зсув напруги живлення всього на 10 вольт при розрахункових 1500 В здатен змінити амплітуду вихідних імпульсів спектрометра на 5–10%, що повністю зіпсує калібрування енергетичних піків.

### 3. Статистика каскадного помноження та фактор надлишкового шуму

Виліт вторинних електронів є випадковим пуассонівським процесом. Якщо на перший дінод припадає один первинний електрон, кількість вибитих вторинних електронів є випадковою величиною з середнім `δ` та дисперсією `σ_δ²`.

Для пуассонівського розподілу емісії дисперсія дорівнює середньому значенню:

```
σ_δ² = δ
```

Каскадування `N` випадкових процесів призводить до додаткового розширення амплітудного розподілу анодних імпульсів. Фактор надлишкового шуму (Excess Noise Factor, `F`), який описує погіршення відношення сигнал/шум після підсилювального тракту, визначається формулою Шокі-Берджесса:

```
F = 1 + (σ_δ² / δ²) · ∑[j=1..N] (1 / δ^(j-1))

F = 1 + (1 / δ) · (1 + 1/δ + 1/δ² + ... + 1/δ^(N-1))
```

Обчисливши суму геометричної прогресії при `N → ∞`, отримуємо граничне значення:

```
F ≈ 1 + 1 / (δ - 1) = δ / (δ - 1)
```

При типовому коефіцієнті вторинної емісії першого дінода `δ = 4`:

```
F ≈ 4 / (4 - 1) = 4 / 3 ≈ 1.33
```

Це означає, що каскадне дінодне підсилення збільшує дисперсію шуму всього на 33% порівняно з ідеальним безшумним підсилювачем.

#### Розподіл Пойя для першого дінода
У реальних ФЕУ вибірка вторинних електронів на першому діноді флуктує сильніше, ніж описує розподіл Пуассона. Для врахування мікроскопічної неоднорідності гладкості та роботи виходу поверхні емітера застосовують розподіл Пойя (негативний біноміальний):

```
P(n) = ((μ · (1 + b))^n / n!) · (1 + b · n)^(-n - 1/b)
```

де `b` — параметр неоднорідності емітера (`0.1 ≤ b ≤ 0.5`). Відносна дисперсія емісії при цьому зростає: `σ_δ² / δ² = 1/δ + b`, що трохи підвищує фактор надлишкового шуму `F`.

Щоб мінімізувати фактор `F`, першому діноду `D1` надають підвищену напругу `V_{K-D1} = 2..3 · V_d`. Завдяки цьому коефіцієнт вторинної емісії першого каскаду зростає до `δ1 = 8..12`, а фактор надлишкового шуму знижується до `F ≈ 1 + 1/8 = 1.12`, що суттєво покращує роздільну здатність однофотонних сигналів.

### 4. Відношення сигнал/шум (SNR) та амплітудна роздільна здатність

При реєстрації світлового потоку з середньою кількістю падаючих фотонів `N_ph` та квантовою ефективністю фотокатода `η` середня кількість фотоелектронів становить `N_pe = η · N_ph`.

Відношення сигнал/шум `SNR` на аноді ФЕУ в інтегрувальному режимі становить:

```
SNR = N_pe / √(F · N_pe)
SNR = √(η · N_ph / F)
```

Завдяки високому коефіцієнту підсилення `M ≈ 10⁶` власні електронні шуми анодного навантаження стають знехтовно малими порівняно з квантовим дробовим шумом самих фотоелектронів.

#### Енергетична роздільна здатність сцинтиляційного детектора
При з'єднанні ФЕУ зі сцинтилятором енергетична роздільна здатність `R = ΔE / E` (ширина піку на піввисоті, FWHM) описується виразом:

```
R = 2.355 · √( (σ_scint / N_photon)² + F / (η · N_photon) )
```

де `σ_scint` — власний статистичний флуктуаційний шум сцинтиляційного кристала. Зі зменшенням фактора `F` (підвищенням підсилення першого дінода `δ1`) амплітудна роздільна здатність спектрометра покращується.

#### Однофотонний спектр (Single Photoelectron Spectrum)
При освітленні ФЕУ слабкими спалахами, де `N_pe ≤ 1`, амплітудний спектр анодних імпульсів демонструє чіткий **однофотонний пік** (Single Photoelectron Peak, SPE). Відношення ширини цього піку `σ_SPE` до його середньої амплітуди `Q_SPE` безпосередньо вимірює коефіцієнт вторинної емісії першого дінода:

```
(σ_SPE / Q_SPE)² = 1 / δ1
```

Чітке відділення SPE-піку від темнового шуму є головним критерієм придатності ФЕУ для квантового відліку поодиноких фотонів.
