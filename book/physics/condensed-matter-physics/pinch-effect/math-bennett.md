# 🧮 Математична модель рівноваги Беннетта та МГД-нестійкостей

Ця вставка містить строгий математичний вивід стану магнітогідродинамічної (МГД) рівноваги циліндричного плазмового шнура, що утримується власним магнітним полем струму (**рівновага Беннетта**), аналіз варіаційного принципу вільної енергії, неізотермічні ефекти, релятивістську теорію Беннетта та лінійний аналіз дисперсійних співвідношень для МГД-нестійкостей.

---

### 1. Рівняння МГД-рівноваги у циліндричних координатах

Розглядаємо стаціонарний, нескінченно довгий плазмовий циліндр з аксіальною симетрією. Усі фізичні величини залежать лише від радіальної координати `r` у циліндричній системі координат `(r, φ, z)`.

Згідно з магнітогідродинамікою, умовою механічної рівноваги є рівність градієнта газокінетичного тиску `p(r)` та об'ємної густини сили Лоренца `j × B`:

```
∇p = j × B
```

Оскільки електричний струм тече вздовж осі `z` (`j = (0, 0, j_z(r))`), а власний магнітний вектор спрямований по азимуту `φ` (`B = (0, B_φ(r), 0)`), векторний добуток дає лише радіальну складову сили:

```
dp / dr = - j_z(r) · B_φ(r)               [радіальне рівняння рівноваги]
```

Для зв'язку магнітного поля `B_φ(r)` із густиною струму `j_z(r)` використовуємо рівняння Максвелла-Ампера у циліндричній системі координат:

```
(1 / r) · d(r · B_φ) / dr = μ₀ · j_z(r)    [закон Ампера для циркуляції]
```

Виражаємо густину струму `j_z(r)` з рівняння Максвелла та підставляємо у рівняння рівноваги тиску:

```
dp / dr = - (B_φ / μ₀) · (1 / r) · d(r · B_φ) / dr
```

Множимо обидві частини на `r²`:

```
r² · (dp / dr) = - (1 / μ₀) · (r · B_φ) · d(r · B_φ) / dr
```

### 2. Точне інтегрування та вивід співвідношення Беннетта

Проінтегруємо отримане рівняння вздовж усього радіуса плазмового циліндра від `r = 0` до `r = ∞`.

**А. Інтегрування лівої частини (за частинами):**

```
∫₀^∞ r² · (dp / dr) · dr
= [ r² · p(r) ]₀^∞ - 2 · ∫₀^∞ r · p(r) · dr   [інтегрування за частинами]
```

Оскільки плазма локалізована в просторі, тиск на нескінченності прямує до нуля швидше ніж `1/r²`, а при `r = 0` вираження `r² · p(0) = 0`. Отже, граничний член зникає:

```
∫₀^∞ r² · (dp / dr) · dr = - 2 · ∫₀^∞ r · p(r) · dr
```

**Б. Інтегрування правої частини:**

```
- (1 / μ₀) · ∫₀^∞ (r · B_φ) · d(r · B_φ)
= - (1 / (2 · μ₀)) · [ (r · B_φ(r))² ]₀^∞
```

За циркуляційним законом Ампера, на великих відстанях від шнура (`r → ∞`) усе магнітне поле визначається повним струмом `I`:

```
lim_{r→∞} (r · B_φ(r)) = (μ₀ · I) / (2 · π)
```

При `r = 0` поле `B_φ(0) = 0`, тому член на нижній границі дорівнює нулю. Підставляючи значення на нескінченності:

```
- (1 / (2 · μ₀)) · ( (μ₀ · I) / (2 · π) )² = - (μ₀ · I²) / (8 · π²)
```

**В. Зведення лівої та правої частин:**

Прирівнюємо обоє інтегралів:

```
- 2 · ∫₀^∞ r · p(r) · dr = - (μ₀ · I²) / (8 · π²)
```

Скорочуємо знаки мінус і множимо обидві частини на `2 · π`:

```
4 · π · ∫₀^∞ r · p(r) · dr = (μ₀ · I²) / (4 · π)
```

Зауважимо, що повне число частинок `N` (сума електронів та іонів) на одиницю довжини шнура пов'язане з концентрацією `n(r)` співвідношенням:

```
N = ∫₀^∞ 2 · π · r · n(r) · dr
```

Згідно з ідеально-газовим рівнянням стану, тиск дорівнює `p(r) = n(r) · k_B · (T_e + T_i)`, де `T_e` та `T_i` — температури електронної та іонної компонент. Вважаючи температуру ізотермічною по перерізу:

```
∫₀^∞ 2 · π · r · p(r) · dr = N · k_B · (T_e + T_i)
```

Підставляючи це значення у прирівняння, отримуємо остаточне **співвідношення Беннетта**:

```
2 · N · k_B · (T_e + T_i) = (μ₀ · I²) / (4 · π)
```

або у традиційній формі:

```
μ₀ · I² = 8 · π · N · k_B · (T_e + T_i)        [рівновага Беннетта]
```

Це співвідношення показує, що для утримання плазми з заданою лінійною густиною частинок `N` та температурою `T` потрібен струм, квадрат якого прямо пропорційний тепловій енергії частинок.

### 3. Самоузгоджені профілі Беннетта та варіаційний принцип

В. Беннетт знайшов точний аналітичний розв'язок сукупності рівнянь рівноваги та розподілу Максвелла-Больцмана для електронно-іонного газу.

Якщо вважати дрейфову швидкість електронів `v_d` постійною по перерізу шнура, самоузгоджені профілі концентрації `n(r)`, густини струму `j_z(r)` та азимутального магнітного поля `B_φ(r)` мають вигляд:

```
n(r) = n₀ / ( 1 + (r / a)² )²                  [профіль концентрації]

j_z(r) = j₀ / ( 1 + (r / a)² )²                [профіль густини струму]

B_φ(r) = ( (μ₀ · I) / (2 · π) ) · ( r / (r² + a²) )  [профіль магнітного поля]
```

де `a` — характерний **радіус Беннетта**, який визначається балансом між дифузією частинок та магнітним стисканням:

```
a² = ( 8 · (D_e + D_i) · ε₀ ) / ( μ₀ · σ · v_d² )
```

З профілю `B_φ(r)` видно, що всередині шнура при `r ≪ a` магнітне поле зростає лінійно (`B_φ ∝ r`), досягає максимуму при `r = a`, а на зовнішніх межах при `r ≫ a` спадає за класичним законом Ампера (`B_φ ∝ 1/r`).

З погляду термодинаміки, стан Беннетта відповідає мінімуму вільної енергії `F = U - T · S` плазмового циліндра при збереженні повного струму `I` та числа частинок `N`.

Варіація загальної енергії системи `W_tot`, яка складається з магнітної енергії `W_mag = ∫ (B_φ² / (2 μ₀)) dV` та теплової енергії плазми `W_th = ∫ (p / (γ - 1)) dV`:

```
δW_tot = δ ( ∫ ( B_φ² / (2 · μ₀) + p / (γ - 1) ) dV ) = 0
```

вимагає виконання суворої рівності Беннетта у кожному просторовому перерізі.

### 4. Неізотермічний пінч та теплопровідний баланс

У реальних експериментах електронна `T_e` та іонна `T_i` температури не є константами по перерізу шнура. За рахунок джоульова нагріву `j_z² / σ` тепло виділяється переважно в центрі, де густина струму максимальна, після чого передається на периферію за рахунок поперечної електронної теплопровідності `κ_⊥`.

Стаціонарне рівняння теплового балансу для електронного газу має вигляд:

```
(1 / r) · (d / dr) ( r · κ_⊥ · (dT_e / dr) ) + j_z² / σ = Q_ei
```

де `Q_ei = (3 m_e / m_i) · n · ν_ei · k_B · (T_e - T_i)` — швидкість обміну енергією між електронами та іонами при парних зіткненнях з частотою `ν_ei`.

У сильному азимутальному магнітному полі поперечна теплопровідність класично пригнічується в `(1 + (ω_ce · τ_ee)²) ` разів, де `ω_ce = e B_φ / m_e` — циклотронна частота електронів, `τ_ee` — час між електрон-електронними зіткненнями. Це призводить до формування гострого температурного піку на осі `r = 0`, де `T_e(0) ≫ T_e(a)`.

При врахуванні неізотермічності радіальний профіль тиску набуває більш крутого спаду ніж класичний беннеттівський квадрат ступеня:

```
p(r) = p₀ · exp( - ∫₀^r ( (μ₀ · j_z(r') · ∫₀^r' j_z(r'') r'' dr'') / (r' · k_B · (T_e(r') + T_i(r'))) ) dr' )
```

### 5. Релятивістський пінч Беннетта та фокусування пучків

Коли пінч-ефект реалізується в релятивістських електронних пучках зі швидкістю електронів `v_z ≈ c`, кулонівське відштовхування електронів у пучку перестає бути знехтовно малим.

Для пучка електронів густиною `n_e` із фактором Лоренца `γ_rel = (1 - v_z² / c²)^(-1/2)` діють дві конкуруючі сили:

1. **Електростатичне кулонівське відштовхування:**
```
F_E = e · E_r = ( e² · N_e ) / ( 2 · π · ε₀ · r )
```

2. **Магнітне амперівське притягання:**
```
F_M = e · v_z · B_φ = ( e² · N_e · v_z² ) / ( 2 · π · ε₀ · c² · r )
```

Сумарна радіальна сила, що діє на електрон на межі пучка:

```
F_net = F_E - F_M = ( e² · N_e ) / ( 2 · π · ε₀ · r ) · ( 1 - v_z² / c² ) = ( e² · N_e ) / ( 2 · π · ε₀ · r · γ_rel² )
```

Звідси випливає важливий фізичний висновок: для чисто електронного релятивістського пучка у вакуумі магнітне притягання не може повністю компенсувати кулонівське відштовхування (`F_net > 0`), але зменшує його в `γ_rel²` разів.

Самостискання пучка (релятивістський пінч) стає можливим лише тоді, коли у пучку присутній нейтралізуючий фон іонів з коефіцієнтом компенсації заряду `f_i = N_i / N_e`. Умова релятивістського самофокусування Беннетта дає порогове значення компенсації:

```
f_i > 1 / γ_rel²                               [умова релятивістського пінчу]
```

Для високоенергетичних пучків (`γ_rel ≫ 1`) вистачає часткової компенсації заряду іонами фонового газу (`f_i ≪ 1`), щоб пучок самостійно стиснувся у тонку голку.

### 6. Інкременти МГД-нестійкостей та варіаційний енергетичний принцип Бернштейна

Для дослідження стійкості рівноважного стану Беннетта застосовується енергетичний принцип Бернштейна-Фрімана-Крус-Кулсруда. Прирост потенціальної енергії `δW_MHD` при малих збуреннях плазмового зсуву `ξ(r, φ, z)` записується у вигляді квадратичної форми:

```
δW_MHD = (1 / (2 μ₀)) · ∫ [ (Q_⊥)² + (Q_∥ - μ₀ (ξ · ∇p) / B)² + γ_gas μ₀ p (∇ · ξ)² - 2 μ₀ (ξ · ∇p) (ξ · κ) ] dV
```

де `Q = ∇ × (ξ × B)` — збурене магнітне поле, `κ = (b · ∇) b` — вектор кривини силових ліній магнітного поля (`b = B / B`).

Якщо `δW_MHD < 0` для бодай одного виду збурення `ξ`, система є гідромагнітно нестійкою.

Зсув плазмової поверхні `δr` подається у вигляді суми просторових гармонік:

```
δr(r, φ, z, t) = δr₀(r) · exp( γ · t + i · m · φ + i · k · z )
```

де `m` — азимутальне число моди (симетрія), `k = 2π/λ` — аксіальне хвильове число, `γ` — інкримент зростання нестійкості.

#### А. Перетяжкова нестійкість (мода m = 0):
Збурення змінює радіус циліндра `r = a + δr`. У місці звуження (`δr < 0`) магнітне поле зростає до `B_φ + δB_φ`, де:

```
δB_φ = - B_φ₀ · (δr / a)
```

Магнітний тиск `P_mag = B_φ² / (2 μ₀)` отримує приріст:

```
δP_mag = - (B_φ₀² / μ₀) · (δr / a)
```

Оскільки `δr < 0`, приріст магнітного тиску є додатним (`δP_mag > 0`), що підсилює стискання. Дисперсійне співвідношення у наближенні коротких хвиль (`k · a ≫ 1`) дає інкремент зростання:

```
γ_{m=0} ≈ k · v_A = k · ( B_φ₀ / √(μ₀ · ρ) )   [інкремент перетяжки]
```

де `v_A` — альфвенівська швидкість у плазмі, `ρ` — масова густина плазми. Час розвитку нестійкості `τ = 1/γ` дорівнює часові прольоту альфвенівської хвилі поперек шнура (`τ ≈ a / v_A`), що становить частки мікросекунди.

#### Б. Змійоподібна нестійкість (мода m = 1):
Для дугоподібного вигину шнура радіуса кривини `R_c` різниця магнітного тиску між увігнутим і опуклим боками створює виштовхувальну силу:

```
F_kink = ( μ₀ · I² / (4 · π · R_c) ) · ln( L / a )
```

Інкремент зростання змійоподібної моди дорівнює:

```
γ_{m=1} ≈ ( B_φ₀ / √(μ₀ · ρ) ) · k · √( ln(1 / (k · a)) )
```

#### В. Стабілізація аксіальним полем B_z та критерій Крускала-Шафранова:
При наявності внутрішнього поздовжнього магнітного поля `B_z` деформація шнура згинає та стискає силові лінії цього поля, що створює відновлювальну силу зсуву. Умова стійкості щодо змійоподібної нестійкості для тороїдального або замороженого шнура довжиною `L = 2πR` записується у вигляді **критерію Крускала-Шафранова**:

```
q(a) = ( a · B_z ) / ( R · B_φ(a) ) > 1         [критерій Крускала-Шафранова]
```

де `q(a)` — коефіцієнт запасу стійкості (safety factor). Якщо `q(a) < 1`, крок гвинтової лінії магнітного поля збігається з довжиною системи, викликаючи резонансне зростання моди `m = 1` та руйнування пінчу.
