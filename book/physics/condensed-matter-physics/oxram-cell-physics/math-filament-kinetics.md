# 🧮 Математична кінетика росту та деструкції кисневого філамента

Функціонування оксидної резистивної пам'яті (OxRAM) базується на динамічній перебудові нанорозмірного провідного філамента (CF — *conductive filament*), утвореного кисневими вакансіями `V_O` у функціональному діелектрику. Кількісний опис процесів формоутворення, перемикання у низькорезистивний стан (SET) та розриву філамента (RESET) вимагає сумісного розв'язання рівнянь іонного переносу, джоулевого нагріву та квантово-механічного тунелювання носіїв заряду.

Ця вставка розкриває математичний апарат, що описує кінетику руху вакансій, термодинаміку джоулевого нагріву та полеву залежність опору наноізолюючого зазору.

## 1. Рівняння іонного мигтіння Мотта — Ґерні

Перенос іонів кисню `O²⁻` та вакансій `V_O` у кристалічній або аморфній оксидній матриці (HfO₂, Ta₂O₅) відбувається шляхом термоактивованого стрибання крізь потенціальні бар'єри періоду ґратки.

У відсутності зовнішнього електричного поля потенціальний рельєф є симетричним із висотою бар'єра `E_a` (енергія активації міграції, яка становить близько 0.7–1.0 еВ для HfO₂). Частота термічних спроб подолання бар'єра дорівнює фононній частоті ґратки `ν₀ ≈ 10¹³` Гц. При прикладанні електричного поля `E` потенціальний бар'єр знижується у напрямку поля на величину `ΔE = q · α · E / 2`, де `a` — відстань між сусідніми потенціальними ямами (постійна ґратки `a ≈ 0.3` нм), `q = 2e` — ефективний заряд вакансії кисню `V_O⁺⁺`, `α` — коефіціент асиметрії бар'єра (`α ≈ 0.5`).

Ймовірність стрибка вгору та вниз по полю описується виразами:

```
P_forward = ν₀ · exp(-(E_a - q · a · E / 2) / (k_B · T))
P_backward = ν₀ · exp(-(E_a + q · a · E / 2) / (k_B · T))
```

Чиста швидкість йонного дрейфу `v` визначається різницею цих ймовірностей, помноженою на довжину стрибка `a`:

```
v = a · (P_forward - P_backward)
= a · ν₀ · exp(-E_a / (k_B · T)) · [ exp(q · a · E / (2 · k_B · T)) - exp(-q · a · E / (2 · k_B · T)) ]    [винесено спільний множник]
= 2 · a · ν₀ · exp(-E_a / (k_B · T)) · sinh(q · a · E / (2 · k_B · T))                                [означення гіперболічного синуса]
```

Це є фундаментальне **рівняння Мотта — Ґерні** для йонного дрейфу у сильних електричних полях (`E > 10⁶` В/см).

Для слабких полів (`q · a · E << 2 · k_B · T`) гіперболічний синус наближається до свого аргументу `sinh(x) ≈ x`, що дає лінійний закон Ома для йонного струму:

```
v ≈ (q · a² · ν₀ / (k_B · T)) · exp(-E_a / (k_B · T)) · E
v = μ_v · E
```

де `μ_v` — дрейфова рухливість кисневих вакансій. У сильних полях (`E > 1` МВ/см) швидкість дрейфу зростає експоненційно: `v ∝ exp(q · a · E / (2 · k_B · T))`.

Фізичний зміст рівняння Мотта — Ґерні полягає у тому, що при кімнатній температурі (`T = 300` К) та слабкому полі дрейфова рухливість вакансій є знехтовно малою (`μ_v < 10⁻¹⁵` см²/В·с), завдяки чому філамент залишається стабільним роками. Однак при прикладанні робочої напруги `V ≈ 1` В поле локалізується на нанометровому зазорі `x_gap ≈ 1` нм, досягаючи величини `E ≈ 10` МВ/см. Це знижує потенціальний бар'єр міграції на `ΔE ≈ 0.3` еВ і прискорює рух вакансій на 8–10 порядків, забезпечуючи перемикання стану за кілька наносекунд.

## 2. Динаміка величини тунельного зазору x_gap при SET та RESET

Спрощена одновимірна модель філамента розглядає провідний канал довжиною `L_CF`, який відділений від верхнього електрода нанорозмірним оксидним зазором товщиною `x_gap`.

Загальна товщина функціонального оксиду дорівнює `D = L_CF + x_gap`.

Зміна товщини зазору `dx_gap / dt` під час операцій перемикання описується балансом двох протилежних процесів: дрейфу вакансій під дією поля (зменшення зазору при SET) та термічної рекомбінації/окиснення (збільшення зазору при RESET).

```
dx_gap / dt = -v_SET + v_RESET
```

### А. Швидкість закриття зазору під час SET:

Під час прикладання позитивної напруги `V_SET` на верхній електрод електричне поле напрямлене від верхнього до нижнього електрода. Позитивно заряджені кисневі вакансії `V_O⁺⁺` дрейфують до верхнього електрода, зменшуючи величину зазору `x_gap`:

```
v_SET = v₀ · exp(-E_a / (k_B · T)) · sinh(q · a · V / (2 · x_gap · k_B · T))
```

оскільки падіння напруги `V` при високому опорі зазору локалізується переважно на самому зазорі, створюючи надвисоке поле `E_gap = V / x_gap`.

### Б. Швидкість відновлення оксидного зазору під час RESET:

Під час операції RESET падіння напруги зворотної полярності генерує високий струм крізь філамент, розігріваючи звуження до температури `T_max`. При підвищених температурах енергія активації рекомбінації вакансій з іонами кисню `E_rec` долається за рахунок термічних флуктуацій:

```
v_RESET = v_rec,0 · exp(-E_rec / (k_B · T_max)) · sinh(q · a · E_gap / (2 · k_B · T_max))
```

Ланцюг обчислення повного динамічного рівняння зазору:

```
dx_gap / dt
= -v₀ · exp(-E_a / (k_B · T)) · sinh(q · a · V / (2 · x_gap · k_B · T)) + v_rec,0 · exp(-E_rec / (k_B · T_max))
```

Ці рівняння показують високу нелінійність: при напрузі нижче порогового значення `V_th` швидкість зміни `dx_gap / dt` дорівнює практично нулю, що гарантує збереження стану протягом 10 років (ретеншн). При `V > V_th` швидкість зростає на 6–8 порядків, забезпечуючи перемикання за наносекунди.

## 3. Співвідношення Кольрауша для пікової температури джоулевого нагріву

Оскільки діаметр провідного філамента `r_CF` становить всього від 2 до 10 нанометрів, густина струму у звуженні досягає величезних величин `J = I / (π · r_CF²) ≈ 10⁸` А/см². Це генерує потужне локалізоване джоулеве тепловиділення.

Для визначення максимальної температури `T_max` у найвужчому місці філамента використовується розв'язок рівняння теплопровідності Фурьє з урахуванням закону Відемана — Франца.

Рівняння балансу тепла та електричного струму у стаціонарному режимі:

```
∇ · (κ · ∇T) + J · E = 0
```

де `κ` — теплопровідність, `σ` — питома електропровідність матеріалу філамента.

Згідно із **законом Відемана — Франца**, відношення теплопровідності до електропровідності для металевих і сильнолегованих провідників є пропорційним температурі:

```
κ / σ = L_W · T
```

де `L_W = (π² / 3) · (k_B / e)² ≈ 2.44 · 10⁻⁸` Вт·Ом/К² — число Відемана — Франца.

Інтегрування рівняння теплопровідності вздовж лінії струму від контактного електрода з температурою `T_0 = 300` К до центра гарячої точки `T_max`:

```
∫ κ dT = ∫ σ · V dV
∫ (L_W · σ · T) dT = σ · ∫ V dV                              [підстановка закону Відемана — Франца]
L_W · ∫ T dT = ∫ V dV                                        [скорочення електропровідності σ]
L_W · (T_max² - T_0²) / 2 = V² / 8                           [інтегрування по T від T_0 до T_max та по V від 0 до V/2]
T_max² - T_0² = V² / (4 · L_W)                               [множення обох частин на 2 / L_W]
T_max = √( T_0² + V² / (4 · L_W) )                           [добування квадратного кореня]
```

Це є класичне **співвідношення Кольрауша**.

### Числовий приклад розрахунку пікової температури:

Розрахуємо локальну температуру у філаменті при напрузі RESET `V_reset = 0.8` В та кімнатній температурі електродів `T_0 = 300` К:

```
V² / (4 · L_W)
= (0.8)² / (4 · 2.44 · 10⁻⁸)                [підстановка напруги та числа Відемана — Франца]
= 0.64 / (9.76 · 10⁻⁸)                      [обчислення знаменника]
= 6.557 · 10⁵ K²                            [значення термічного доданка]

T_max
= √( (300)² + 6.557 · 10⁵ )                 [додавання квадратів температур]
= √( 90000 + 655700 )                       [обчислення підкореневого виразу]
= √( 745700 )                               [підсумкова сума в K²]
≈ 863.5 K                                   [значення T_max у Кельвінах]
```

Таким чином, при напрузі всього 0.8 В локальна температура у звуженні філамента досягає `T_max ≈ 863` K (`~ 590` °C). Цей локальний нагрів експоненційно прискорює термічну рекомбінацію кисневих вакансій `v_rec ∝ exp(-E_rec / (k_B · T_max))`, що дозволяє розірвати філамент за час менше 5 наносекунд.

## 4. Струм переносу у високорезистивному стані (HRS): модель тунелювання

У високорезистивному стані (HRS) провідний філамент є розірваним, і струм визначається носіями, що долають оксидний зазор `x_gap`. Залежно від товщини зазору та напруги перенос кодується двома основними механізмами: прямим квантовим тунелюванням та термоелектронною емісією Пуля — Френкеля.

### А. Пряме тунелювання крізь прямокутний бар'єр (Simmons model):

Для тонких зазорів (`x_gap < 1.5` нм) густина струму тунелювання `J_DT` описується рівнянням Симмонса:

```
J_DT = (q² · V / (h² · x_gap)) · exp( -(4 · π · x_gap · √(2 · m* · Φ_B)) / h )
```

де `m*` — ефективна маса електрона в діелектрику (`m* ≈ 0.4 · m_e` для HfO₂), `Φ_B` — висота потенціального бар'єра на межі металевий філамент / оксид (`Φ_B ≈ 1.2` еВ), `h` — стала Планка.

У низьковольтному режимі (`V << Φ_B / q`) опір зазору залежить експоненційно від його товщини:

```
R_HRS ∝ exp(A · x_gap)
```

де `A = (4 · π / h) · √(2 · m* · Φ_B) ≈ 10.25` нм⁻¹. Зміна товщини зазору всього на 0.2 нм (один атомарний шар кисню) змінює опір осередку майже на порядок величини, що вимагає високої точності контролю імпульсу RESET.

### Б. Емісія Пуля — Френкеля (Poole-Frenkel Emission):

Для більш товстих зазорів (`x_gap > 2` нм) або при підвищених температурах тунелювання поступається місцем термопольовому звільненню електронів із пасток у забороненій зоні діелектрика.

Електричне поле знижує висоту кулонівської ями пастки на величину `ΔΦ_PF = √(q³ · E / (π · ε_r · ε₀))`:

```
J_PF = C · E · exp( -(q · Φ_t - q · √(q · E / (π · ε_r · ε₀))) / (k_B · T) )
```

де `Φ_t` — глибина енергетичної пастки, `ε_r` — оптична діелектрична проникність оксиду (`ε_r ≈ 4` для HfO₂).

Логарифмічна залежність струму Пуля — Френкеля `ln(I / V)` від `√V` являє собою пряму лінію, що слугує експериментальним підтвердженням наявності оксидного зазору у стані HRS.

## 5. Модель квантового точкового контакту (QPC) для стану LRS

У низькорезистивному стані (LRS), коли зазор `x_gap = 0`, а радіус найвужчої частини філамента `r_CF` порівнюваний із ферміївською довжиною хвилі електрона `λ_F ≈ 0.5` нм, класичний закон Ома поступається місцем балістичному транспорту.

Провідність філамента квантується згідно з формулою Ландауера:

```
G_LRS = I / V = (2 · e² / h) · ∑ T_i
```

де `2 · e² / h ≈ (12.9 кОм)⁻¹` — квант провідності `G₀`, `T_i` — коефіцієнт проходження `i`-го електронного модового каналу.

Якщо філамент містить лише декілька провідних атомних ланцюжків кисневих вакансій, провідність комірки становить `G ≈ N · G₀`, де `N` — кількість провідних каналів. Це пояснює дискретні кроки провідності, які спостерігаються при надточних імпульсах SET.
