# 📜 Відкриття обмінного зміщення: від загадки наночастинок Co/CoO до основи спінтроніки

Цей історичний нарис розв'язує задачу відновлення хронології та фізичної логіки відкриття обмінного зміщення Філіпом Мейклджоном та Чарльзом Біном у 1956 році. Задача дослідження виникла через парадокс у розробці дрібнодисперсних постійних магнітів: поверхневе окислення наночастинок кобальту вважалося псуванням матеріалу, проте вимірювання після охолодження в магнітному полі показали неможливий для тодішньої теорії асиметричний зсув петлі гістерезису. Без опрацювання цього відкриття класична фізика магнетизму вважала будь-яку магнітну анізотропію симетричною, через що не вдавалося пояснити односпрямоване закріплення спінів на інтерфейсі та створити стабільні елементи спінтроніки.

---

### 1. Дослідницький контекст 1950-х років та пошук нових магнітних матеріалів

У середині XX століття фундаментальні та прикладні дослідження у фізиці магнетизму зазнавали бурхливого розвитку. Післявоєнна індустріалізація, розвиток обчислювальної техніки та радіоелектроніки вимагали створення нових матеріалів із новими магнітними характеристиками. Дослідницький центр компанії General Electric у Скенектаді (штат Нью-Йорк, США) був одним із провідних світових осередків, де розроблялися нові ферити, високочастотні сердечники та матеріали для постійних магнітів.

Зокрема, значна увага наукової спільноти приділялася так званим дрібнодисперсним постійним магнітам (*Fine Particle Magnets*). Згідно з теоретичними працями французького фізика Луї Нееля та американського теоретика Чарльза Біна, якщо зменшити розмір феромагнітного кристала нижче критичного радіуса однодоменного стану (порядку 10–50 нм), у ньому зникають доменні стінки. Перемагнічування такої однодоменної частинки може відбуватися виключно шляхом однорідного обертання вектора намагніченості проти сил магнітно-кристалічної або формової анізотропії. Це обіцяло гігантські значення коерцитивної сили `H_c`, необхідні для створення надпотужних постійних магнітів нового покоління.

```
+---------------------------------------------------+
|               Наночастинка Co/CoO                 |
|                                                   |
|             /-------------------\                 |
|            /   Оболонка CoO      \                |
|           /   (Антиферомагнетик)  \               |
|          |     /-------------\     |              |
|          |    /  Ядро Co      \    |              |
|          |   | (Феромагнетик)  |   |              |
|          |    \               /    |              |
|          |     \-------------/     |              |
|           \                       /               |
|            \---------------------/                |
+---------------------------------------------------+
```

Молодий експериментатор Філіп Мейклджон (*W. Philip Meiklejohn*) та його досвідченіший колега Чарльз Бін (*Charles P. Bean*) вивчали магнітні властивості дрібнодисперсного кобальтового порошку. Частинки кобальту (`Co`) середнім діаметром близько 20 нм отримували методом електролітичного осадження в ртутну ванну з подальшим відпалом. Prote у процесі вилучення з розчину та контакту з повітрям поверховий шар частинок неминуче окислювався, утворюючи тонку захисну оболонку оксиду кобальту `CoO` товщиною 1–3 нм.

На той момент фізичні властивості чистого металевого кобальту були чудово відомі: це класичний феромагнетик із високою температурою Кюрі (`T_C = 1388 K`). Натомість оксид кобальту `CoO` виявляв антиферомагнітні властивості з температурою Нееля `T_N = 291 K` (поблизу кімнатної температури). Мейклджон і Бін спочатку розглядали наявність оксидної оболонки як прикрий побічний ефект фабрікації, який лише зменшував корисну макроскопічну намагніченість порошку.

### 2. Експериментальний парадокс: асиметричний зсув петлі гістерезису

У 1956 році Мейклджон і Бін провели серію вимірювань витоку магнітного потоку порошку `Co/CoO` за допомогою торсіонного магнітометра при різних температурах.

Коли зразок вимірювали при кімнатній температурі (понад `T_N = 291 K`), оксидна оболонка `CoO` перебувала у парамагнітному стані. Отримана петля гістерезису була абсолютно стандартною для феромагнетика: строго симетричною відносно початку координат `(H = 0, M = 0)` з помірною коерцитивною силою `H_c ≈ 600 Е`.

Проте наступний крок експерименту призвів до результату, який спочатку здавався помилкою приладу або наслідком залишкової намагніченості полюсів електромагніту:
1. Зразок `Co/CoO` нагрівали трохи вище кімнатної температури (вище `T_N`, але далеко нижче `T_C`).
2. До зразка прикладали потужне зовнішнє магнітне поле `H_FC = 10 кЕ`.
3. Утримуючи поле ввімкненим, зразок охолоджували до температури рідкого азоту (`T = 77 K`, що значно нижче `T_N`).

Коли після цього термомагнітного оброблення (*Field Cooling*, FC) Мейклджон і Бін зняли петлю гістерезису у змінному магнітному полі при `77 K`, вони побачили дивовижну картини. Петля гістерезису не просто розширилася — вона **повністю зсунулася вліво** вздовж осі зовнішнього магнітного поля на величину `H_EB ≈ -600 Е` у напрямку, протилежному до поля охолодження!

```
                    M (Намагніченість)
                            ^
                            |       Зсунута петля (77 K, FC)
                            |       +------------+
                            |       |            |
                            |       |            |
  <-------------------------+-------+------------+----------> H
   -H_c1       H_EB         0       |   H_c2
                            |       +------------+
                            |
```

Це означало фундаментальне порушення очікуваної симетрії:
- Щоб перемагнітити зразок у напрямку, протилежному до поля охолодження `H_FC`, потрібно було прикласти величезне поле `|H_c1| = 2000 Е`.
- Проте при зворотному ході поля зразок повертався у початковий стан вже при значно меншому полі `H_c2 = 800 Е`.
- Петля була зсунута так, ніби всередині матеріалу неперервно діяло приховане "внутрішнє" магнітне поле, яке прагнуло втримати намагніченість кобальту в напрямку оригінального поля охолодження `H_FC`.

Окрім горизонтального зсуву, коерцитивна сила зразка `H_c = (H_c2 - H_c1) / 2` зросла у кілька разів порівняно з чистими частинками кобальту.

### 3. Концепція односпрямованої анізотропії (Unidirectional Anisotropy)

Усі відомі на той час види магнітної анізотропії — магнітно-кристалічна, формова, анізотропія напружень — володіли **одноосьовою симетрією** (*uniaxial anisotropy*). Енергетичний потенціал описувався парними степенями тригонометричних функцій:

```
E_uniaxial = K_u · sin²(θ)
```

Цей вираз є інваріантним відносно заміни `θ → θ + π`. Тобто осі легкого намагнічування мали два рівноправні й енергетично еквівалентні напрямки: "вперед" (`θ = 0`) і "назад" (`θ = π`). Саме ця симетрія гарантувала строго симетричну форму класичної петлі гістерезису відносно вісі `H = 0`.

Щоб пояснити експеримент `Co/CoO`, Мейклджон і Бін запропонували сміливу гіпотезу: на межі розділу феромагнітного ядра `Co` та антиферомагнітної оболонки `CoO` виникає принципово новий тип взаємодії — **односпрямована анізотропія** (*unidirectional anisotropy*). Енергія цієї анізотропії залежить від першого степеня косинуса кута:

```
E_unidirectional = - K_eb · cos(θ)
```

Цей потенціал має строго один енергетичний мінімум при `θ = 0`. Напрямок `θ = π` відповідає максимуму енергії. Симетрія відносно розвороту на 180° виявилася повністю зламаною.

Мейклджон і Бін опублікували свої перші результати у стислій замітці в журналі *Physical Review* у 1956 році («*New Magnetic Anisotropy*»), а у 1957 році випустили фундаментальну статтю в *Journal of Applied Physics*. Вони пояснили фізичний механізм так: при охолодженні через температуру Нееля `T_N` у зовнішньому полі `H_FC` спіни феромагнетика орієнтуються вздовж поля. Перший шар атомних спінів антиферомагнетика на інтерфейсі під дією потужного обмінного інтегралу `J_inter` також шикується паралельно до спінів феромагнетика. При подальшому охолодженні жорстка кристалографічна анізотропія антиферомагнетика "заморожує" цю орієнтацію. Коли зовнішнє поле знімають або розвертають, закріплені спіни антиферомагнетика діють на феромагнетик як ефективне поле утримування.

### 4. Дискусії у науковій спільноті та пошуки теоретичного пояснення

Перші публікації Мейклджона та Біна викликали хвилю скепсису серед теоретиків. Видатні фізики-магнетологи того часу, зокрема Луї Неель та Джон Ван Влек, ставили під сумнів можливість існування чистих незакомплексованих спінових площин на межі розділу кристалів.

Основні лінії наукових дискусій 1960–1970-х років:
1. **Проблема компенсації спінів:** За розрахунками Нееля, більшість кристалографічних граней антиферомагнетиків (таких як `NiO` чи `CoO`) є скомпенсованими, тобто містять рівну кількість спінів протилежних напрямків. За таких умов сумарний обмінний момент на інтерфейсі повинен дорівнювати нулю, і поле `H_EB` виникати не повинно.
2. **Розбіжність за величиною полів:** Проста модель Мейклджона — Біна передбачала теоретичні поля зміщення `H_EB` порядку `10⁴ Е` для одноатомного інтерфейсу. Prote реальні вимірювання показували значення у десятки разів менші (`100–300 Е`).

Ці парадокси були розв'язані лише у 1980-х роках завдяки працям Алана Малоземова (*A. P. Malozemoff*), який запропонував **модель випадкових полів** (*Random-Field Model*), та Мередіта Нейрта (*H. Suhl, M. Kouvel*), які довели, що саме атомарна шорсткість, кристалографічні сходинки та випадковий розподіл незакомплексованих спінів створюють помірне, але надзвичайно стабільне поле зміщення.

### 5. Від порошків до плівок: Технологічна революція у спінтроніці

Упродовж перших двох десятиліть після відкриття ефект обмінного зміщення розглядався більшістю фізиків як наукова екзотика, притаманна лише окисненим порошкам та неоднорідним сплавам. Практичне застосування порошкових матеріалів `Co/CoO` було обмеженим через складність контролю розміру частинок та ступеня окислення.

Прорив відбувся наприкінці 1970-х та у 1980-х роках із розвитком вакуумних технологій магнетронного та електронно-променевого осадження тонких плівок. Науковці навчилися напилювати ідеально планарні двошарові та багатошарові плівки `FM/AFM` з контролем товщини на рівні моноатомних шарів.

Хронологія подальшого розквіту ефекту:
- **1988 рік:** Альбер Ферт (*Albert Fert*) та Петер Ґрюнберґ (*Peter Grünberg*) відкривають ефект гігантського магнітоопору (GMR) у багатошарових структурах `Fe/Cr` (Нобелівська премія з фізики 2007 року).
- **1991 рік:** Група дослідників IBM під керівництвом Бернарда Дієні (*Bernard Dieny*) та Стюарта Паркіна (*Stuart Parkin*) розробляє **спіновий клапан** (*Spin Valve*). Для роботи спінового клапана потрібно було створити два феромагнітні шари, один з яких (Вільний шар) вільно повертався у слабких магнітних полях, а другий (Закріплений шар) залишався непорушно фіксованим у полях до 1–2 кЕ.

Саме ефект обмінного зміщення, відкритий Мейклджоном і Біном за 35 років до того, ідеально вирішив задачу фіксації закріпленого шару. Шар антиферомагнетика (наприклад, сплаву `IrMn` або `PtMn`), нанесений у контакті з феромагнітним опорним шаром `CoFe`, надійно "прив'язував" його намагніченість за рахунок односпрямованої анізотропії.

Сьогодні обмінне зміщення є невід'ємною частиною мільярдів спінтронічних пристроїв:
- Зчитувальних головок жорстких дисків HDD (забезпечили стрибок щільності запису у тисячі разів).
- Магніторезистивної оперативної пам'яті (MRAM, STT-MRAM, SOT-MRAM).
- Високочутливих автомобільних та медичних датчиків магнітного поля та струму.

Просте експериментальне спостереження аномального зсуву петлі у скляній ампулі з азотом у 1956 році перетворилося на один із наріжних каменів новітньої мікроелектроніки.
