# 🧮 Математика зонних розривів та інтегральне співвідношення Крьомера

Математичний апарат опису напівпровідникового гетеропереходу є основою сучасної зонної інженерії. На відміну від гомопереходу, де потенціальний рельєф формується виключно розподілом легуючих домішок та просторового заряду, у гетероструктурах профілі зони провідності `E_c(z)` та валентної зони `E_v(z)` визначаються спільною дією трьох фундаментальних механізмів:
1. Квантово-механічною різницею фундаментальних параметрів матеріалів (ширини забороненої зони та електронної спорідненості);
2. Ефективними квазіелектричними полями Крьомера, викликаними градієнтом хімічного складу;
3. Електростатичним вигином зон, описуваним розв'язком рівняння Пуассона з урахуванням інтегрального співвідношення Крьомера для вольт-фарадної метрології.

У цій вставці наведено строгий математичний вивід усіх трьох компонентів, викладений у послідовній causally-linked формі.

---

### 1. Модель спорідненості до електрона (Правило Андерсона)

Розгляньмо два ізольовані монокристалічні напівпровідники 1 та 2 до утворення контакту. Для кожного з них за нульовий рівень енергії відліку приймається **вакуумний рівень** `E_vac` — потенціальна енергія електрона, який вилучено з кристала та розміщено у вакуумі безпосередньо біля його поверхні без надання йому кінетичної енергії.

Фундаментальними параметрами напівпровідникового матеріалу є:
- `E_g` — ширина забороненої зони;
- `χ` — електронна спорідненість (*electron affinity*), що дорівнює енергетичній відстані від дна зони провідності `E_c` до вакуумного рівня `E_vac`:

```
χ = E_vac - E_c                      [означення електронної спорідненості]
```

#### Гіпотеза неперервності вакуумного рівня
Модель Андерсона (1962) спирається на фізичне припущення про те, що за відсутності локальних дипольних шарів атомарного масштабу на межі розділу, вакуумний рівень `E_vac(z)` є неперервною функцією координати при переході через межу розділу `z = z_i`.

Застосуємо цю умову для обчислення розриву зони провідності `ΔE_c`. Записавши вираз для дна зони провідності з обох боків гетеромежі:

```
E_c1 = E_vac - χ₁                     [дно зони провідності напівпровідника 1]
E_c2 = E_vac - χ₂                     [дно зони провідності напівпровідника 2]
```

Віднімаючи друге рівняння від першого, отримуємо точне значення стрибка зонного краю зони провідності `ΔE_c`:

```
ΔE_c
= E_c1 - E_c2                        [означення розриву зони провідності]
= (E_vac - χ₁) - (E_vac - χ₂)         [підстановка виразів через E_vac]
= χ₂ - χ₁                             [скорочення вакуумного рівня E_vac]
```

Отже, розрив зони провідності в ідеальній моделі Андерсона дорівнює математичній різниці електронних спорідненостей двох контактуючих матеріалів.

#### Баланс зонних розривів
Повна різниця ширин забороненої зони двох напівпровідників визначається як `ΔE_g = E_g2 - E_g1`. Загальна висота енергетичного перепаду складається із суми розриву зони провідності `ΔE_c` та розриву валентної зони `ΔE_v`:

```
ΔE_g = ΔE_c + ΔE_v                    [закон збереження повної енергетичної щілини]
```

Виражаючи розрив валентної зони `ΔE_v` через вихідні параметри:

```
ΔE_v
= ΔE_g - ΔE_c                         [вираження розриву валентної зони]
= (E_g2 - E_g1) - (χ₂ - χ₁)           [підстановка формули Андерсона]
```

#### Кількісний приклад для гетеропари `GaAs / Al_x Ga_{1-x} As`
Розгляньмо практичну гетероструктуру `GaAs / Al_{0.3}Ga_{0.7}As` при 300 К:
- `GaAs` (вузькозонний, матеріал 1): `E_g1 = 1.424 еВ`, `χ₁ = 4.070 еВ`;
- `Al_{0.3}Ga_{0.7}As` (широкозонний, матеріал 2): `E_g2 = 1.798 еВ`, `χ₂ = 3.740 еВ`.

Обчислимо зонні розриви крок за кроком:

```
ΔE_g = 1.798 - 1.424 = 0.374 еВ       [різниця ширин забороненої зони]
ΔE_c = 4.070 - 3.740 = 0.330 еВ       [стрибок зони провідності]
ΔE_v = 0.374 - 0.330 = 0.044 еВ       [стрибок валентної зони]
```

Відносні частки зонних розривів становлять:

```
ΔE_c / ΔE_g = 0.330 / 0.374 ≈ 0.88    [88% розриву припадає на зону провідності]
ΔE_v / ΔE_g = 0.044 / 0.374 ≈ 0.12    [12% розриву припадає на валентну зону]
```

### 2. Математичне виведення квазіелектричних полів Крьомера

У напівпровідниковій гетероструктурі зі змінним хімічним складом (градному напівпровіднику) молярна частка складових `x(z)` плавно змінюється вздовж осі `z`. Це означає, що фундаментальні величини `χ(z)` та `E_g(z)` стають явними неперервними функціями координати `z`.

#### Потенціальна енергія носіїв заряду
Позначимо через `ϕ(z)` електростатичний потенціал внутрішнього поля, породженого просторовим зарядом іонів та вільних носіїв. Повна потенціальна енергія електрона у зоні провідності `E_c(z)` зв'язана з електростатичним та хімічним потенціалами:

```
E_c(z) = -q · ϕ(z) - χ(z)             [потенціальна енергія електрона у простір]
```

Відповідно, потенціальна енергія верху валентної зони `E_v(z)` відраховується вниз від зони провідності на величину ширини забороненої зони `E_g(z)`:

```
E_v(z)
= E_c(z) - E_g(z)                      [зв'язок зон через ширину забороненої зони]
= -q · ϕ(z) - χ(z) - E_g(z)            [підстановка виразу для E_c(z)]
= -q · ϕ(z) - (χ(z) + E_g(z))          [групування хімічних доданків]
```

#### Обчислення сил, що діють на носії
За законами класичної та квантової механіки, ефективна сила `F`, що діє на частинку в потенціальному полі, дорівнює градієнту потенціальної енергії з протилежним знаком:

```
F_e(z) = -dE_c / dz                    [ефективна сила, що діє на електрон]
F_h(z) = +dE_v / dz                    [ефективна сила, що діє на дірку]
```

Обчислимо похідну потенціальної енергії електрона за координатою `z`:

```
F_e(z)
= -d/dz [ -q · ϕ(z) - χ(z) ]           [підстановка потенціальної енергії E_c]
= q · (dϕ / dz) + (dχ / dz)            [розкриття дужок і диференціювання]
= -q · F_es(z) + (dχ / dz)             [введення електростатичного поля F_es = -dϕ/dz]
```

Перший додаток `-q · F_es(z)` є стандартною кулонівською силою електростатичного поля. Другий додаток є чистою внутрішньою силою хімічного походження.

Визначимо **квазіелектричне поле Крьомера для електронів** `F_e^{quasi}`:

```
F_e^{quasi}(z) = (1/q) · (dχ / dz)     [напруженість квазіполя електронів]
```

Тепер обчислимо ефективну силу, що діє на дірку у валентній зоні:

```
F_h(z)
= +d/dz [ -q · ϕ(z) - (χ(z) + E_g(z)) ] [підстановка потенціальної енергії E_v]
= -q · (dϕ / dz) - d/dz [ χ(z) + E_g(z) ] [диференціювання за координатою z]
= +q · F_es(z) - d(χ + E_g) / dz        [введення кулонівської сили +q·F_es]
```

Визначимо **квазіелектричне поле Крьомера для дірок** `F_h^{quasi}`:

```
F_h^{quasi}(z) = -(1/q) · d/dz [ χ(z) + E_g(z) ] [напруженість квазіполя дірок]
```

#### Математичне порівняння з кулонівським полем
У звичайній електродинаміці для будь-якої точки простору діє рівність `F_e / (-q) = F_h / (+q) = F_es`. Електростатичне поле за визначенням не здатне прискорювати електрон і дірку в один і той самий бік.

У гетероструктурі Крьомера повні сили дорівнюють:

```
F_e(z) = q · [ -F_es(z) + F_e^{quasi}(z) ] [повна сила на електрон]
F_h(z) = q · [ +F_es(z) + F_h^{quasi}(z) ] [повна сила на дірку]
```

Оскільки квазіполя `F_e^{quasi}` та `F_h^{quasi}` залежать від незалежних градієнтів `dχ/dz` та `dE_g/dz`, систему можна сконструювати так, щоб `F_e(z) > 0` (електрони прискорюються праворуч), тоді як `F_h(z) = 0` або `F_h(z) > 0` (дірки також рухаються праворуч або залишаються нерухомими). Це математично доводить розв'язання сил у гетероструктурах.

### 3. Строге математичне виведення інтегрального співвідношення Крьомера для C-V вимірювань

Для прямого вимірювання розриву зони провідності `ΔE_c` на реальних гетеропереходах Герберт Крьомер (1980) розробив точний інтегральний метод, що ґрунтується на подвійному інтегруванні рівняння Пуассона через збіднену область гетеропереходу.

#### Вихідне диференціальне рівняння
Розгляньмо одновимірне рівняння Пуассона для гетеропереходу між напівпровідником 1 (`z < z_i`) та напівпровідником 2 (`z > z_i`), розташованого між межами `z = 0` та `z = W`:

```
d/dz [ ε(z) · (dϕ / dz) ] = -q · [ N_d(z) - n(z) ]  [1D рівняння Пуассона]
```

де `ε(z)` відчуває стрибок у точці металургійної межі `z = z_i`:

```
ε(z) = ε₁  при  z < z_i
ε(z) = ε₂  при  z > z_i
```

#### Крок 1: Перше інтегрування рівняння Пуассона
Проінтегруймо рівняння Пуассона від `0` до `z`:

```
ε(z) · (dϕ / dz) = -q · ∫₀^z [ N_d(z') - n(z') ] dz' [потік електричної індукції D(z)]
```

за припущення, що поза збідненою областю (`z = 0` та `z = W`) електричне поле дорівнює нулю: `dϕ/dz|_{z=0} = dϕ/dz|_{z=W} = 0`.

#### Крок 2: Друге інтегрування за частинами
Повторно проінтегруймо вираз для потенціалу `ϕ(z)` від `0` до `W`, застосовуючи формулу інтегрування за частинами:

```
∫₀^W [ dϕ / dz ] dz = ϕ(W) - ϕ(0) = V_bi       [повний вбудований потенціал]
```

Розбиваючи інтеграл на дві області до і після металургійної межі `z_i` та підставляючи вираз для електричного поля через густину заряду `ρ(z) = q · (N_d(z) - n(z))`:

```
V_bi = (q / ε̄) · ∫₀^W (z - z_i) · [ N_d(z) - n(z) ] dz + V_D1 + V_D2 - (ΔE_c / q)
```

де:
- `ε̄ = (ε₁ + ε₂) / 2` — ефективна діелектрична проникність межі;
- `V_D1 = (k_B·T / q) · ln(N_c1 / n₀1)` — різниця між рівнем Фермі та дном зони провідності в об'ємі матеріалу 1;
- `V_D2 = (k_B·T / q) · ln(N_c2 / n₀2)` — різниця потенціалів в об'ємі матеріалу 2.

#### Крок 3: Остаточна формула Крьомера
Виражаючи шуканий розрив зони провідності `ΔE_c` із вищевказаного рівняння:

```
ΔE_c = q · (V_bi - V_D1 - V_D2) + (q² / ε̄) · ∫₀^W (z - z_i) · [ N_d(z) - n(z) ] dz
```

#### Фізичний зміст складових формули Крьомера:
1. Перший доданок `q · (V_bi - V_D1 - V_D2)` представляє макроскопічний вигин потенціалу, визначений із нахилу характеристик `1/C²(V)` при вольт-фарадному профільуванні.
2. Другий доданок `(q² / ε̄) · ∫₀^W (z - z_i) · [ N_d(z) - n(z) ] dz` обчислює дипольний момент перерозподілу вільних носіїв відносно металургійної межі `z_i`.

Це співвідношення є математично точним: воно не залежить від невідомого профілю легування `N_d(z)` чи форми потенціальної ями, що робить його головним інструментом експериментальної фізики гетероструктур.

### 4. Вплив поверхневих станів та деформацій ґратки

У реальних гетеропереходах формула Андерсона вимагає модифікації з урахуванням двох додаткових фізичних чинників:

#### Атомарний міжфазний диполь (`ΔE_dip`)
Перерозподіл електронних хмар між нерівноцінними атомами обабіч межі створює подвійний шар заряду атомарного товщини (`~0.1...0.3 нм`), що додає стрибок потенціалу `ΔE_dip`:

```
ΔE_c = (χ₂ - χ₁) + ΔE_dip              [урахування атомарного диполя]
```

#### Деформаційний зсув зон (Теорія потенціалу деформації)
Якщо сталі кристалічної ґратки матеріалів відрізняються (`a_1 ≠ a_2`), епітаксійний шар зазнає двовісного стискання або розтягування з деформацією `e_xx = (a_sub - a_layer) / a_layer`.

Зсув краю зони провідності під дією механічного напруження обчислюється через потенціал деформації `a_c`:

```
ΔE_c^{strain} = a_c · (e_xx + e_yy + e_zz) [деформаційний зсув дна зони провідності]
```

де `e_zz = -2 · (C₁₂ / C₁₁) · e_xx` описує поперечну деформацію кристала за законом Пуассона. Урахування деформаційного зсуву є критично важливим при проектуванні псевдоморфних транзисторів pHEMT та лазерів на квантових точках.
