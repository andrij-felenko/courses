# 🧮 Виведення умов Лауе, сфери Евальда та структурного фактора

Ця математична вставка містить суворе тривимірне векторне виведення умов Лауе, їхню геометрію у просторі оберненої ґратки через побудову сфери Евальда, аналітичне доведення математичної еквівалентності умови Бреґґа та розрахунок геометричного структурного фактора `S(h,k,l)` для кубічних ґраток. Читач відкрив цей розділ для математичного обґрунтування інтерференційних явищ: щоб перейти від спрощеного наочного відображення від площин до точного тривимірного векторного опису розсіювання на електронній густині кристала та аналітично вивести правила систематичних погасань (зникання) дифракційних піків для різних типів симетрії комірки Браве.

---

## 1. Векторне розсіювання хвилі та умови Лауе

Розглянемо еластичне розсіювання плоскої монохроматичної хвилі з хвильовим вектором `k₀` (`|k₀| = 2π / λ`) на кристалічній ґратці Браве, заданій вектором трансляції:

```
R_n = n₁·a₁ + n₂·a₂ + n₃·a₃
```

де `a₁, a₂, a₃` — примітивні вектори прямої ґратки, а `n₁, n₂, n₃` — цілі числа.

Розсіяна хвиля в напрямку `k` (`|k| = |k₀| = 2π / λ`, оскільки розсіювання пружне) має вектор розсіювання:

```
q = k - k₀
```

Фазовий зсув `Δφ` між хвилею, розсіяною атомом у початку координат `0`, та хвилею, розсіяною атомом у вузлі `R_n`, визначається скалярним добутком:

```
Δφ = q · R_n = (k - k₀) · R_n
```

Амплітуда сумарної хвилі від усіх `N` вузлів кристала дорівнює сумі фазових множників:

```
A(q) = ∑ exp(-i · q · R_n)
     = ∑ exp(-i · (k - k₀) · (n₁·a₁ + n₂·a₂ + n₃·a₃))
```

Для того щоб амплітуда `A(q)` мала гострий конструктивний максимум (порядок `N`), фазовий зсув для кожного з трьох примітивних векторів трансляції мусить бути кратним `2π`. Це дає три скалярні **рівняння Лауе**:

```
a₁ · (k - k₀) = 2π · m₁
a₂ · (k - k₀) = 2π · m₂      [де m₁, m₂, m₃ — цілі числа]
a₃ · (k - k₀) = 2π · m₃
```

## 2. Еквівалентність умов Лауе та закону Бреґґа

Вектори оберненої ґратки `b₁, b₂, b₃` за визначенням задовольняють співвідношення ортогональності:

```
a_i · b_j = 2π · δ_ij
```

Будь-який вектор оберненої ґратки `G` з цілочисельними індексами Міллера `(h, k, l)` записується як:

```
G = h·b₁ + k·b₂ + l·b₃
```

Порівнюючи рівняння Лауе із визначенням `G`, бачимо, що три умови Лауе виконуються тоді й тільки тоді, коли вектор розсіювання `q = k - k₀` точно дорівнює вектору оберненої ґратки `G`:

```
k - k₀ = G               [фундаментальна умова Лауе у векторній формі]
```

Доведемо, що векторне рівняння `k - k₀ = G` математично повністю еквівалентне скалярній умові Бреґґа `2d sin θ = n λ`.

### Доведення крок за кроком:

```
|k| = |k₀| = 2π / λ

k = k₀ + G
k² = (k₀ + G)² = k₀² + 2·k₀·G + G²   [піднесення до скалярного квадрата]

k² = k₀²                             [умова пружного розсіювання |k| = |k₀|]
2·k₀·G + G² = 0                      [скасування k² та k₀²]

-2 · |k₀| · |G| · cos(90° + θ) + G² = 0  [кути між k₀ та G: θ — кут ковзання]
2 · |k₀| · |G| · sin θ = G²
2 · (2π / λ) · |G| · sin θ = |G|²     [підстановка |k₀| = 2π / λ]
2 · (2π / λ) · sin θ = |G|           [скорочення на |G|]
```

З теорії оберненої ґратки міжплощинна відстань `d_{hkl}` пов'язана з довжиною вектора оберненої ґратки `G_{hkl}` формулою:

```
d_{hkl} = 2π / |G_{hkl}|
```

Підставляючи `|G| = 2π / d` у попереднє співвідношення, отримуємо:

```
2 · (2π / λ) · sin θ = 2π / d
2 · d · sin θ = λ                   [для найпростішого вектора G (n = 1)]
```

Якщо вектор `G` має спільний множник `n` (тобто `G = n · G₀`), де `G₀` — найкоротший вектор оберненої ґратки, перпендикулярний до даних площин, міжплощинна відстань `d₀ = 2π / |G₀|`, що дає загальний закон Бреґґа:

```
2 · d₀ · sin θ = n · λ               [порядок дифракційного відображення n]
```

## 3. Геометрія сфери Евальда

Векторна умова `k - k₀ = G` має наочну геометричну інтерпретацію, запропоновану Паулем Евальдом.

Побудова сфери Евальда виконується у просторі оберненої ґратки:
1. Вибирається початок оберненої ґратки `O (0,0,0)`.
2. Від початку `O` відкладається вектор падіння `k₀` у напрямку, звідки приходить пучок. Початок вектора `k₀` дає точку `C` (центр сфери Евальда).
3. Навколо точки `C` описується сфера радіуса `R = |k₀| = 2π / λ`. Оскільки `|C - O| = 2π / λ`, сфера обов'язково проходить через початок координат `O`.
4. Будь-яка точка `G` оберненої ґратки, яка виявляється **точно на поверхні сфери**, задовольняє умову `|C - G| = 2π / λ` і відповідає напрямку розсіяного пучка `k = C -> G`.

Отже, дифракційний рефлекс із індексами `(h, k, l)` виникає тоді й тільки тоді, коли відповідний вузол оберненої ґратки `G_{hkl}` перетинає поверхню сфери Евальда.

## 4. Геометричний структурний фактор та систематичні згасання

Кожна елементарна комірка кристала містить `M` атомів у позиціях `r_j = x_j·a₁ + y_j·a₂ + z_j·a₃` (де `x_j, y_j, z_j` — дробові координати у одиницях ребер комірки).

Амплітуда когерентного розсіювання хвилі від однієї елементарної комірки задається **структурним фактором** `F(h,k,l)`:

```
F(h,k,l) = ∑_{j=1}^{M} f_j(q) · exp(-i · G_{hkl} · r_j)
```

де `f_j(q)` — атомний фактор розсіювання `j`-го атома, який описує розсіювання на його електронній хмарі:

```
f_j(q) = ∫ ρ_j(r) · exp(-i · q · r) d³r
```

Якщо всі атоми в комірці однакові (`f_j = f`), структурний фактор можна подати у вигляді:

```
F(h,k,l) = f · S(h,k,l)
```

де `S(h,k,l)` — **геометричний структурний фактор**, що залежить виключно від геометрії розташування атомів у базисі:

```
S(h,k,l) = ∑_{j=1}^{M} exp(-2π i · (h·x_j + k·y_j + l·z_j))
```

Інтенсивність дифракційного піка прямо пропорційна квадрату модуля структурного фактора:

```
I(h,k,l) ∝ |F(h,k,l)|² ∝ |S(h,k,l)|²
```

Якщо для певних індексів `(h,k,l)` сума `S(h,k,l) = 0`, інтенсивність розсіяного променя дорівнює нулю. Це явище називається **систематичним згасанням (погасанням)** рефлексів.

## 5. Обчислення S(h,k,l) для кубічних ґраток

### А. Проста кубічна ґратка (SC)
Базис містить 1 атом у координатах `(0, 0, 0)`:

```
S(h,k,l) = exp(0) = 1
|S(h,k,l)|² = 1
```
**Висновок**: Усі рефлекси `(100), (110), (111), (200), (210)...` є дозволеними. Згасання відсутні.

---

### Б. Об'ємноцентрована кубічна ґратка (BCC)
Базис елементарної комірки містить 2 однакові атоми: `(0, 0, 0)` та `(1/2, 1/2, 1/2)`.

```
S(h,k,l) = exp(0) + exp(-2π i · (h/2 + k/2 + l/2))   [сумування за атомами базису (0,0,0) та (1/2,1/2,1/2)]
         = 1 + exp(-π i · (h + k + l))               [скорочення 2 у чисельнику й знаменнику]
         = 1 + (-1)^(h + k + l)                      [формула Ейлера exp(-i π N) = (-1)^N]
```

Аналіз значень `S(h,k,l)`:
- Якщо `(h + k + l)` є **парним числом**: `exp(-π i · парне) = 1 ⇒ S = 1 + 1 = 2`, отже `|S|² = 4`.
- Якщо `(h + k + l)` є **непарним числом**: `exp(-π i · непарне) = -1 ⇒ S = 1 - 1 = 0`, отже `|S|² = 0`.

**Правило згасання для BCC**:
- Дозволені рефлекси: `(110), (200), (211), (220), (310), (222)...` (сума індексів парна).
- Погасають (відсутні): `(100), (111), (210), (300), (320)...` (сума індексів непарна).

---

### В. Гранецентрована кубічна ґратка (FCC)
Базис містить 4 однакові атоми: `(0, 0, 0)`, `(1/2, 1/2, 0)`, `(1/2, 0, 1/2)`, `(0, 1/2, 1/2)`.

```
S(h,k,l) = 1 + exp(-π i · (h + k)) + exp(-π i · (h + l)) + exp(-π i · (k + l))   [сумування за чотирма атомами базису FCC]
         = 1 + (-1)^(h + k) + (-1)^(h + l) + (-1)^(k + l)                       [формула Ейлера exp(-i π N) = (-1)^N]
```

Аналіз значень `S(h,k,l)`:
1. Якщо індекси `h, k, l` є **однієї парності** (усі три парні або усі три непарні):
   Суми `(h + k)`, `(h + l)`, `(k + l)` є парними числами.
   `S = 1 + 1 + 1 + 1 = 4 ⇒ |S|² = 16`.
2. Якщо індекси `h, k, l` мають **змішану парність** (наприклад, два непарних і одне парне):
   Дві із сум будуть непарними, а одна парною.
   `S = 1 + 1 - 1 - 1 = 0 ⇒ |S|² = 0`.

**Правило згасання для FCC**:
- Дозволені рефлекси: `(111), (200), (220), (311), (222), (400)...` (індекси незмішаної парності).
- Погасають (відсутні): `(100), (110), (210), (211), (300)...` (індекси змішаної парності).

---

### Г. Кристалічна ґратка алмазу (Diamond)
Ґратка алмазу (та кремнію `Si`, германію `Ge`) складається з двох вкладених FCC ґраток, зсунутих одна відносно одної на вектор `(1/4, 1/4, 1/4)`.
Базис містить 8 однакові атоми: 4 атоми FCC + 4 атоми зі зсувом `(1/4, 1/4, 1/4)`.

Структурний фактор розпадається на добуток:

```
S_{diamond}(h,k,l) = S_{FCC}(h,k,l) · (1 + exp(-i (π/2) · (h + k + l)))
```

Аналіз значень:
1. Якщо `h, k, l` змішаної парності: `S_{FCC} = 0 ⇒ S = 0`.
2. Якщо `h, k, l` непарні: `|1 + exp(-i (π/2) · непарне)|² = |1 ∓ i|² = 2 ⇒ |S|² = 32`.
3. Якщо `h, k, l` парні:
   - Якщо `h + k + l = 4n` (кратне 4, наприклад, `(220), (400)`): `exp(-i π · 2n) = 1 ⇒ S_{diamond} = 8 ⇒ |S|² = 64`.
   - Якщо `h + k + l = 4n + 2` (наприклад, `(200), (222), (420)`): `exp(-i π · (2n+1)) = -1 ⇒ S_{diamond} = 0`.

Отже, у структурі кремнію та алмазу рефлекс `(200)` додатково згасає, що є прямим доказом тетраедричного зв'язку між атомами.
