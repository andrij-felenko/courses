# 🔌 Будова вертикального каналу Macaroni та ONO-стека

Ця вставка містить узагальнений опис фізичної структури, радіальних шарів та геометрії вертикального циліндричного каналу (*Macaroni Channel*) та діелектричного стека ONO/SONOS у 3D NAND пам'яті. Розглянуто електростатичні переваги кругового затвора GAA (*Gate-All-Around*), фізику атомно-шарового осадження (ALD) та механічні напруження в матеріалах.

## 1. Пошарова концентрична структура

Вертикальний осередок 3D NAND являє собою порожнистий циліндр, що пронизує стек горизонтальних керувальних затворів. У радіальному напрямку — від зовнішнього металевого затвора до внутрішньої осі отвору — розташовані шість послідовних шарів:

```
[Зовнішній затвор Word Line (W / TiN)]
  └── 1. Blocking Dielectric (Al₂O₃ / SiO₂)  [6–10 нм]
        └── 2. Charge Trap Layer (Si₃N₄)     [4–6 нм]
              └── 3. Tunnel Oxide (SiO₂)     [1.5–2.0 нм]
                    └── 4. Poly-Si Channel    [6–10 нм]
                          └── 5. Oxide Core  [SiO₂ ядро]
```

### Геометричні та фізичні ролі шарів

1. **Керувальний затвор (Control Gate / Word Line):** Металевий шар з вольфраму (`W`) із тонким адгезійним підшаром нітриду титану (`TiN`). Подає напруги програмування (`V_pgm ≈ 18–24` В) та читання (`V_read ≈ 6–8` В). Металізація вольфрамом замінила первинний полікремній, що знизило питомий опір слівних ліній у десятки разів та зменшило затримку поширення сигналу RC.
2. **Блокуючий діелектрик (Blocking Layer):** Двошарова структура Al₂O₃ / SiO₂. Матеріал з високою діелектричною проникністю (High-k, `ε_r ≈ 9–10` для Al₂O₃) запобігає витоку інжектованих електронів із нітриду у керувальний затвор при програмуванні. Використання Al₂O₃ створює високий електронний бар'єр (3.1 еВ) і одночасно забезпечує високу ємність затвора без збільшення фізичної товщини шару.
3. **Шар пастки заряду (Charge Trap Layer):** Аморфний нітрид кремнію (Si₃N₄). Містить високу концентрацію некомпенсованих кремнієвих зв'язків (K⁰-центрів), які утворюють глибокі потенціальні пастки (`Φ_B ≈ 1.0–1.1` еВ) для накопичення електронів. Заряд зберігається в ізольованих просторових точках, що унеможливлює витік усього осередку при локальних пошкодженнях.
4. **Тунельний оксид (Tunnel Oxide):** Ультратонка плівка діоксиду кремнію (SiO₂). Слугує потенціальним бар'єром висотою 3.15 еВ. Забезпечує тунелювання електронів Фаулера — Нордгейма під дією сильного поля при записі та ізолює заряд у режимі утримання.
5. **Вертикальний канал (Poly-Si Channel):** Тонка плівка ненаплівленого або слабко легованого полікристалічного кремнію товщиною 6–10 нм. У ній утворюється інверсійний шар для проходження індукованого струму зчитування.
6. **Центральне діелектричне ядро (Macaroni Core):** Порожнина в центрі каналу, заповнена діоксидом кремнію (SiO₂).

## 2. Фізика ефекту Macaroni (Порожнистий vs Суцільний стержень)

У перших експериментальних зразках 3D NAND вертикальний канал заповнювали полікремнієм повністю, утворюючи суцільний кремнієвий циліндр. Проте це викликало серйозні проблеми з контролем порогової напруги `V_th`.

При товстому суцільному стержні (`d ≈ 60–80` нм) потенціал кругового затвора не міг повністю збіднити центральну область каналу. Виникав ефект об'ємного витоку (*parasitic body effect*), що призводив до високого струму в закритому стані та поганого підпорогового нахилу (`S > 120` мВ/дек).

Заміна суцільного стержня на тонкостінну трубку (*Macaroni*) товщиною `t_poly ≈ 6–8` нм повністю вирішила проблему:
- **Повне збіднення (Fully Depleted):** Тонка плівка полікремнію повністю контролюється електростатичним полем затвора з усіх боків.
- **Ідеальний підпороговий нахил:** Значення `S` наблизилося до теоретичної межі для MOSFET (`S ≈ 65–70` мВ/дек).
- **Пригнічення DIBL:** Зниження бар'єра, індуковане стоком (*Drain-Induced Barrier Lowering*), знизилося до нехтуваних величин.

### Радіальний розподіл електричного поля у циліндрі

Електричне поле `E(r)` у концентричних діелектричних шарах циліндричного каналу залежить від радіуса `r` за законом Гаусса для циліндричної симетрії:

```
E(r) = V_gate / (r · ln(r_out / r_in) · (ε_r(r) / ε_ref))
```

Оскільки електричне поле пропорційне `1/r`, найвищі значення напруженості поля виникають на внутрішній межі тунельного оксиду SiO₂ (при найменшому радіусі `r`), що полегшує тунелювання електронів при нижчих напругах програмування `V_pgm`.

## 3. Фізико-хімічні етапи атомно-шарового осадження (ALD)

Створення однакових тонких плівок на внутрішніх стінках глибоких отворів з аспектним співвідношенням 80:1 неможливе звичайним хімічним осадженням із газової фази (CVD). Використовується процес атомно-шарового осадження (ALD — *Atomic Layer Deposition*), який базується на самообмежувальних поверхневих реакціях.

Процес формування ONO-стека складається з п'яти послідовних газових циклів:
1. **Осадження Al₂O₃ (High-k Blocking):** Послідовні імпульси триметилалюмінію `Al(CH₃)₃` (TMA) та пари води `H₂O`. Молекули TMA реагують із гідроксильними групами поверхні до повного насичення одного моношару.
2. **Осадження SiO₂ (Blocking Buffer):** Нанесення buffer-шару діоксиду кремнію з реактивів дихлорсилану `SiH₂Cl₂` та озону `O₃`.
3. **Осадження Si₃N₄ (Charge Trap):** Хімічна реакція дихлорсилану з аміаком `NH₃` при температурі 650–700 °C, унаслідок чого утворюється аморфний нітрид кремнію з високою щільністю K⁰-центрів.
4. **Формування Ultra-Thin SiO₂ (Tunnel Oxide):** Високоякісне термохімічне осадження тунельного оксиду з подальшим високотемпературним відпалом у середовищі азоту для мінімізації початкових дефектів.
5. **Осадження Poly-Si каналу:** Піроліз моносилану `SiH₄` при 550 °C з утворенням аморфного кремнію, який піддається твердофазній рекристалізації для збільшення розміру монокристалічних зерен.

## 4. Механічні напруження та пасивація дефектів

Поєднання матеріалів із різними коефіцієнтами термічного розширення (полікремній, вольфрам, Al₂O₃, SiO₂, Si₃N₄) викликає високі термомеханічні напруження у вертикальному каналі.

При охолодженні від температури осадження (650 °C) до кімнатної різниця розширення між вольфрамовим затвором та оксидним ядром створює стискаючі напруження до 1–2 ГПа. Це може викликати викривлення цілісної кремнієвої пластини (*wafer warpage*) та розшарування плівок.

Для зменшення дефектності полікремнієвого каналу застосовують відпал у формувальному газі (*Forming Gas Anneal*) у середовищі водню `H₂` при тиску до 20 атм. Атоми водню дифундують у полікремній та пасивують ненасичені зв'язки на межах зерен, знижуючи щільність пасток у каналі з `10¹⁸` см⁻³ до `10¹⁵` см⁻³, що підвищує рухливість електронів.

Практичні аспекти застосування вертикальних каналів у сучасних накопичувачах розглядаються у статті [3D NAND: фізика вертикального стека](book:physics/condensed-matter-physics/3d-nand-architecture).
