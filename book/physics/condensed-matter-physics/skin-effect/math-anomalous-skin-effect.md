# 🧮 Математична теорія аномального скін-ефекту та поверхневого імпедансу

Цей математичний розділ містить послідовний вивід рівняння дифузії електромагнітного поля у провідному середовищі з рівнянь Максвелла, розрахунок комплексного поверхневого імпедансу `Z_s`, а також детальний математичний апарат нелокальної кінетичної теорії Піппарда — Реутера — Сондхаймера для аномального скін-ефекту при кріогенних температурах.

---

### 1. Класичний скін-ефект: хвильове рівняння та розв'язок у півпросторі

Розглянемо плоску межу провідного півпростору `x ≥ 0`. Матеріал має питому провідність `σ`, абсолютну магнітну проникність `μ = μ₀ · μ_r` та діелектричну проникність `ε`. На поверхню металу (`x = 0`) з вакууму падає плоска електромагнітна хвиля з частотою `ω`, у якій вектор електричного поля спрямований вздовж осі `y` (`E = E_y(x, t) · ŷ`), а вектор магнітного поля — вздовж осі `z` (`H = H_z(x, t) · ẑ`).

Виходимо з системи рівнянь Максвелла у квазістаціонарному наближенні. Враховуючи високу провідність металів на радіочастотах та у діапазоні СВЧ, діелектричний струм зсуву `∂D / ∂t` є нехтовно малим порівняно зі струмом провідності `j`, оскільки безрозмірне відношення становить `σ / (ω · ε) ≫ 1`:

```
∇ × E = - μ · (∂H / ∂t)                              [закон електромагнітної індукції Фарадея]
∇ × H = j = σ · E                                    [закон Ампера та локальний закон Ома]
```

Враховуючи обрану одновимірну геометрію (`∂ / ∂y = 0`, `∂ / ∂z = 0`), роторні рівняння спрощуються до системи двох скалярних диференціальних рівнянь першого порядку:

```
∂E_y / ∂x = μ · (∂H_z / ∂t)                          [просторова похідна електричного поля з закону Фарадея]
∂H_z / ∂x = σ · E_y                                  [просторова похідна магнітного поля з закону Ампера]
```

Диференціюючи перше рівняння за координатою `x` та підставляючи вираз з другого рівняння, отримуємо одновимірне диференціальне рівняння дифузії для електричного поля у металевому середовищі:

```
∂²E_y / ∂x² = ∂/∂x (μ · ∂H_z / ∂t)                   [диференціювання першого рівняння за координатою x]
∂²E_y / ∂x² = μ · ∂/∂t (∂H_z / ∂x)                   [перестановка порядку диференціювання за x та t]
∂²E_y / ∂x² = μ · σ · (∂E_y / ∂t)                    [підстановка закону Ампера ∂H_z / ∂x = σ · E_y]
```

Шукаємо гармонічний розв'язок у комплексному вигляді `E_y(x, t) = Re [ E(x) · e^(i·ω·t) ]`. Заміна часової похідної `∂ / ∂t → i · ω` зводить рівняння дифузії до одновимірного рівняння Гельмгольца:

```
d²E / dx² = i · ω · μ · σ · E                        [підстановка часової гармонічної залежності]
d²E / dx² - k² · E = 0                               [підстановка комплексного хвильового вектора k]
```

де `k` — комплексний хвильовий вектор у провідному середовищі, визначений з характеристичного рівняння:

```
k² = i · ω · μ · σ                                   [характеристичне рівняння хвильового вектора]
```

Представимо уявну одиницю у показниковій формі Ейлера `i = e^(i·π/2)`. Квадратний корінь з `i` дорівнює:

```
√i = (e^(i·π/2))^(1/2) = e^(i·π/4)                   [формула піднесення до степеня комплексної экспоненти]
e^(i·π/4) = cos(π/4) + i · sin(π/4)                  [формула Ейлера для тригонометричної форми]
cos(π/4) + i · sin(π/4) = (1 + i) / √2               [обчислення значень табличних тригонометричних функцій]
```

Підставляючи `√i` у вираз для комплексного хвильового вектора `k`, отримуємо:

```
k = √(i · ω · μ · σ)                                 [вилучення квадратного кореня з характеристичного рівняння]
k = (1 + i) · √( (ω · μ · σ) / 2 )                   [підстановка розкладу √i = (1 + i) / √2]
k = (1 + i) / δ                                      [уведення масштабу класичної глибини скін-шару δ]
```

де параметр **класичної глибини скін-шару** `δ` виражається фундаментальною формулою:

```
δ = √( 2 / (ω · μ · σ) )                             [визначення класичної глибини проникнення поля]
```

Загальний розв'язок рівняння Гельмгольца, що задовольняє фізичній граничній умові затухання поля у глибині металу `E(x → ∞) = 0`, має вигляд:

```
E_y(x) = E_0 · e^(- k · x)                           [розв'язок диференціального рівняння другого порядку]
E_y(x) = E_0 · e^(- x / δ) · e^(- i · x / δ)         [розділення дійсної та уявної частин показника]
```

Переходячи до дійсних фізичних величин шляхом множення на `e^(i·ω·t)` та виділення дійсної частини:

```
E_y(x, t) = E_0 · e^(- x / δ) · cos(ωt - x / δ)       [дійсний профіль електричного поля в скін-шарі]
```

Для знаходження відповідного профілю магнітного поля `H_z(x, t)` інтегруємо скалярне рівняння Ампера `∂H_z / ∂x = σ · E_y`:

```
H_z(x) = - (σ / k) · E_0 · e^(- k · x)                [інтегрування за координатою x з граничною умовами]
H_z(x) = - (σ · δ / (1 + i)) · E_0 · e^(- k · x)      [підстановка виразу k = (1 + i) / δ]
H_z(x) = (σ · δ / 2) · (1 - i) · E_0 · e^(- k · x)    [множення чисельника і знаменника на спряжене (1 - i)]
```

Звідси дійсний просторово-часовий профіль магнітного поля дорівнює:

```
H_z(x, t) = H_0 · e^(- x / δ) · cos(ωt - x / δ - π/4) [дійсний профіль магнітного поля зі зсувом фази 45°]
```

де амплітуда поверхневого магнітного поля зв'язана з електричним амплітудним значенням співвідношенням `H_0 = E_0 · σ · δ / √2`.

### 2. Поверхневий імпеданс провідника (Z_s) та енергетичний баланс Пойнтінга

Поверхневий імпеданс `Z_s` визначається як відношення тангенціальної компоненти напруженості електричного поля на поверхні провідника `E_y(0)` до повного поверхневого струму `I_s`, який згідно з теоремою про циркуляцію векторного поля дорівнює тангенціальній компоненті магнітного поля `H_z(0)` на межі `x = 0`:

```
Z_s = E_y(0) / H_z(0)                                [визначення поверхневого імпедансу провідника]
```

Підставляючи комплексні амплітуди `E_y(0) = E_0` та `H_z(0) = (σ / k) · E_0`:

```
Z_s = k / σ                                          [підстановка амплітудного відношення поля до струму]
Z_s = (1 + i) / (σ · δ)                              [підстановка виразу комплексного вектора k = (1 + i) / δ]
```

Розділяючи поверхневий імпеданс на активну (резистивну) та реактивну (індуктивну) частини `Z_s = R_s + i · X_s`:

```
R_s = Re [ Z_s ] = 1 / (σ · δ) = √( (ω · μ) / (2 · σ) ) [активний поверхневий опір classical skin layer]
X_s = Im [ Z_s ] = 1 / (σ · δ) = √( (ω · μ) / (2 · σ) ) [реактивний індуктивний поверхневий опір]
```

Строга рівність `R_s = X_s` означає, що у класичному скін-шарі активний та індуктивний поверхневі опори рівні між собою, а фазовий кут між електричним та магнітним полем становить `φ = π/4` (45°).

Перевіримо енергетичну узгодженість моделі за допомогою вектора Пойнтінга `S = E × H`. Середня за періодом потужність електромагнітного випромінювання, що входить у метал через одиничну площу поверхні `x = 0`, дорівнює:

```
P_in = (1 / 2) · Re [ E_y(0) · H_z*(0) ]             [середній потік вектора Пойнтінга через поверхню]
P_in = (1 / 2) · Re [ Z_s · |H_z(0)|² ]              [підстановка зв'язку E(0) = Z_s · H(0)]
P_in = (1 / 2) · R_s · |H_z(0)|²                     [виділення дійсної частини через поверхневий опір R_s]
```

З іншого боку, обчислимо сумарну потужність джоулевих втрат `P_joule` в усьому об'ємі провідника на одиницю площі шляхом інтегрування густини виділення тепла `j² / σ`:

```
P_joule = (1 / 2) · ∫₀^∞ σ · |E_y(x)|² dx             [об'ємний інтеграл теплових втрат Джоуля — Ленца]
P_joule = (1 / 2) · σ · |E_0|² · ∫₀^∞ e^(- 2x / δ) dx  [підстановка модуля електричного поля |E(x)|]
P_joule = (1 / 2) · σ · |E_0|² · [ - (δ / 2) · e^(- 2x / δ) ]₀^∞ [обчислення первісної визначеного інтеграла]
P_joule = (1 / 4) · σ · δ · |E_0|²                   [результат інтегрування експоненційного згасання]
```

Виразивши `|E_0|` через `|H_z(0)|` за допомогою співвідношення `|E_0| = (√2 / (σ · δ)) · |H_z(0)|`:

```
P_joule = (1 / 4) · σ · δ · [ 2 / (σ² · δ²) ] · |H_z(0)|² [підстановка амплітуди E_0 через магнітне поле H_0]
P_joule = (1 / 2) · (1 / (σ · δ)) · |H_z(0)|²        [скорочення співмножників у чисельнику та знаменнику]
P_joule = (1 / 2) · R_s · |H_z(0)|²                  [доведення строгої тотожності P_joule = P_in]
```

Це математично доводить точне виконання закону збереження енергії: потік вектора Пойнтінга через поверхню дорівнює об'ємній дисипації джоулевого тепла.

### 3. Кінетичне рівняння Больцмана та феноменологія Піппарда

Класична теорія спирається на локальний закон Ома `j(r) = σ · E(r)`. Проте при кріогенних температурах у чистих металах середня довжина вільного пробігу електронів `l = v_F · τ` (де `v_F` — швидкість Фермі, `τ` — час релаксації) стає набагато більшою за глибину проникнення поля `δ` (`l ≫ δ`).

Температурна залежність довжини вільного пробігу `l(T)` описується правилом Маттіссена, у якому враховується розсіювання на домішках та фононах:

```
1 / l(T) = 1 / l_imp + A · T³ + B · T⁵              [правило Маттіссена для довжини вільного пробігу]
```

При зниженні температури до `T = 4.2 K` фононний член `A · T³ + B · T⁵` прямує до нуля, і довжина вільного пробігу виходить на статичний дефектом ліміт `l_imp ≈ 10–100 мкм`. Оскільки на частотах СВЧ (`f ≈ 1–10 ГГц`) класична товщина скін-шару `δ_cl ≈ 0.1 мкм`, виникає умова аномального скін-ефекту:

```
l ≫ δ_cl                                             [критерій гранично аномального скін-ефекту]
```

У цьому випадку електрон під час вільного пробігу багаторазово перетинає скін-шар. Густина струму `j(x)` у точці `x` визначається електричним полем не лише в точці `x`, а у всій області радіусом `l` навколо неї.

Розподіл електронів описується кінетичним рівнянням Больцмана для функції розподілу `f(x, v, t)` у наближенні часу релаксації:

```
∂f / ∂t + v_x · (∂f / ∂x) + (e · E_y / m*) · (∂f / ∂v_y) = - (f - f_0) / τ [кінетичне рівняння Больцмана]
```

де `f_0(v)` — рівноважна функція розподілу Фермі — Дирака, `e` — заряд електрона, `m*` — ефективна маса носія.

Шукаємо відхилення функції розподілу від рівноважного стану у вигляді `f(x, v, t) = f_0(v) + g(x, v) · e^(i·ω·t)`. Нехтуючи квадратичними за полем термами `E_y · (∂g / ∂v_y)`, отримаємо лінеаризоване рівняння:

```
i · ω · g + v_x · (∂g / ∂x) + (e · E_y / m*) · (∂f_0 / ∂v_y) = - g / τ [лінеаризація поблизу поверхні Фермі]
v_x · (∂g / ∂x) + (1 + i · ω · τ) / τ · g = - (e · E_y / m*) · (∂f_0 / ∂v_y) [групування членів для релаксації]
```

Уведемо комплексний час релаксації `τ* = τ / (1 + i · ω · τ)`. У низькочастотній області (`ω · τ ≪ 1`) комплексний час релаксації зводиться до `τ* ≈ τ`. Тоді рівняння набуває вигляду:

```
∂g / ∂x + g / (v_x · τ*) = - (e · E_y(x) / (m* · v_x)) · (∂f_0 / ∂v_y) [диференціальне рівняння першого порядку]
```

Інтегруючи це рівняння методом характеристик вздовж траєкторій електронів, що рухаються під кутом до поверхні, отримуємо відхилення функції розподілу `g(x, v)` для електронів, що летять углиб металу (`v_x > 0`):

```
g(x, v) = - (e / (m* · v_x)) · (∂f_0 / ∂v_y) · ∫₀^x E_y(x') · e^(- (x - x') / (v_x · τ*)) dx' [інтегрування характеристик]
```

Для електронів, що рухаються до поверхні (`v_x < 0`), інтегрування здійснюється від нескінченності:

```
g(x, v) = (e / (m* · |v_x|)) · (∂f_0 / ∂v_y) · ∫_x^∞ E_y(x') · e^(- (x' - x) / (|v_x| · τ*)) dx' [траєкторії з глибини]
```

Гранична умова на межі `x = 0` виражається через феноменологічний параметр дзеркальності Фукса `p` (`0 ≤ p ≤ 1`):

```
g(0, v_x > 0) = p · g(0, v_x < 0)                      [умова граничного відбиття електронів Фукса]
```

Густина поверхневого струму `j_y(x)` обчислюється як інтеграл за всім об'ємом імпульсного простору носіїв:

```
j_y(x) = e · ∫ v_y · g(x, v) d³v                     [інтегрування функції розподілу по швидкостях]
```

Згідно з нелокальною феноменологічною теорією Чемберса — Піппарда (1952), тривимірне узагальнення зв'язку струму та поля має вигляд:

```
j(r) = (3 · σ₀ / (4 · π · l)) · ∫ [ R · (R · E(r')) / R⁴ ] · e^(- R / l) d³r' [тривимірний інтеграл Чемберса]
```

де `R = r - r'` — вектор відстані між точками спостереження та джерела.

Для плоского скін-шару (`x ≥ 0`) після інтегрування по азимутальному куту отримаємо одновимірне інтегро-диференціальне рівняння для поля `E_y(x)`:

```
d²E_y(x) / dx² = i · (2 / δ_cl²) · ∫₀^∞ K(|x - x'| / l) · E_y(x') dx' [одновимірне нелокальне рівняння]
```

де ядро Чемберса `K(u)` виражається через інтегральні экспоненти:

```
K(u) = ∫₁^∞ (1 / s - 1 / s³) · e^(- u · s) ds         [аналітичне ядро зсуву в нелокальному інтегралі]
```

З фізичної точки зору, як показав Браян Піппард, у тонкий скін-шар товщиною `δ` роблять внесок лише ті електрони, кут руху яких до поверхні не перевищує `θ ≈ δ / l`. Ефективна концентрація носіїв, що беруть участь у провідності, зменшується у відношення `n_eff ≈ n · (δ / l)`.

### 4. Розв'язок у гранично аномальному режимі методом перетворення Фур'є

Розглянемо випадок чисто дзеркального відбиття електронів від поверхні металу (`p = 1`). У цьому випадку поле `E_y(x)` можна симетрично продовжити на від'ємну піввісь `x < 0` як парну функцію `E_y(-x) = E_y(x)`.

Застосуємо просторове перетворення Фур'є:

```
E(q) = ∫_{-∞}^∞ E_y(x) · e^(- i · q · x) dx          [пряме просторове перетворення Фур'є поля]
E_y(x) = (1 / (2 · π)) · ∫_{-∞}^∞ E(q) · e^(i · q · x) dq [обернене перетворення Фур'є]
```

Диференціюванню `d²E_y / dx²` у фур'є-просторі відповідає множення на `- q²` з урахуванням скачка першої похідної на межі `x = 0`:

```
F [ d²E_y / dx² ] = - q² · E(q) + 2 · E_y'(0+)       [перетворення Фур'є другої похідної з крайовим стрибком]
```

Тоді одновимірне рівняння Максвелла у фур'є-просторі набуває вигляд алгебраїчного рівняння:

```
(q² + i · ω · μ · σ(q)) · E(q) = 2 · E_y'(0+)         [алгебраїчне рівняння для фур'є-компонент поля]
```

де `σ(q)` — нелокальна динамічна провідність у фур'є-просторі:

```
σ(q) = σ₀ · (3 / (2 · (q · l)³)) · [ (1 + (q · l)²) · arctg(q · l) - q · l ] [нелокальна провідність у q-просторі]
```

Дослідимо асимптотичну поведінку `σ(q)` у двох граничних режимах:

1. **Локальний режим (`q · l ≪ 1`):**
```
arctg(q · l) ≈ q · l - (q · l)³ / 3 + (q · l)⁵ / 5   [розклад арктангенса у ряд Тейлора при малих аргументах]
σ(q) = σ₀ · (3 / (2 · (q · l)³)) · [ q · l + (q · l)³ - (q · l)³ / 3 - (q · l)⁵ / 3 + (q · l)⁵ / 5 - q · l ] [підстановка]
σ(q) = σ₀ · (1 - (1/5) · (q · l)² + ...) → σ₀       [граничний перехід до статичної провідності Друде]
```

2. **Гранично аномальний режим (`q · l ≫ 1`):**
```
arctg(q · l) ≈ π / 2 - 1 / (q · l)                   [асимптотичний розклад арктангенса на нескінченності]
σ(q) ≈ σ₀ · (3 / (2 · (q · l)³)) · [ (q · l)² · (π / 2) ] [виділення домінуючого члена другого порядку]
σ(q) ≈ σ₀ · (3 · π / (4 · q · l))                    [асимптотична нелокальна провідність для великих q]
```

### 5. Обчислення аномального поверхневого імпедансу

Знаючи `E(q)`, знайдемо електричне поле на поверхні `x = 0` за допомогою оберненого перетворення Фур'є:

```
E_y(0) = (1 / (2 · π)) · ∫_{-∞}^∞ E(q) dq             [значення поля на поверхні через фур'є-інтеграл]
E_y(0) = (E_y'(0+) / π) · ∫_{-∞}^∞ dq / (q² + i · ω · μ · σ(q)) [підстановка виразу для E(q)]
```

Зважаючи на перше рівняння Максвелла `∂E_y / ∂x = μ · (∂H_z / ∂t) = i · ω · μ · H_z`, поверхневе значення похідної зв'язане з магнітним полем: `E_y'(0+) = i · ω · μ · H_z(0)`.

Підставивши це значення, знайдемо точну формулу поверхневого імпедансу `Z_s = E_y(0) / H_z(0)`:

```
Z_s = (i · ω · μ / π) · ∫_{-∞}^∞ dq / (q² + i · ω · μ · σ(q)) [загальний інтегральний вираз імпедансу]
```

У гранично аномальному режимі підставимо асимптотику провідності `σ(q) = (3 · π · σ₀) / (4 · q · l)`:

```
Z_s = (i · ω · μ / π) · ∫_{-∞}^∞ dq / [ q² + i · (3 · π · ω · μ · σ₀ / (4 · l)) / q ] [підстановка асимптотики σ(q)]
Z_s = (i · ω · μ / π) · ∫_{-∞}^∞ q dq / [ q³ + i · (3 · π · ω · μ · σ₀ / (4 · l)) ] [зведення до спільного знаменника]
```

Уведемо масштабний параметр `β`:

```
β = [ (3 · π · ω · μ · σ₀) / (4 · l) ]^(1/3)         [уведення масштабного коефіцінта для заміни змінних]
```

Тоді заміна змінної `u = q / β` зводить інтеграл до безрозмірної контурної константи:

```
Z_s = (i · ω · μ / (π · β)) · ∫_{-∞}^∞ u du / (u³ + i) [безрозмірний контурний інтеграл]
```

Для обчислення безрозмірного інтеграла розглянемо полюси підінтегральної функції `u³ + i = 0`. Полюси знаходяться у точках `u_k = e^(i · (π/2 + 2πk)/3)`:

```
u₁ = e^(i · π / 6) = √3 / 2 + i / 2                   [перший полюс у верхній півплощині]
u₂ = e^(i · 5π / 6) = - √3 / 2 + i / 2                 [другий полюс у верхній півплощині]
u₃ = e^(i · 3π / 2) = - i                             [третій полюс у нижній півплощині]
```

Замикаючи контур у верхній півплощині комплексної змінної `u`, обчислюємо суму лишків у полюсах `u₁` та `u₂`:

```
Res [ u / (u³ + i), u₁ ] = u₁ / (3 · u₁²) = 1 / (3 · u₁) = (1 / 3) · e^(- i · π / 6) [лишок у першому полюсі]
Res [ u / (u³ + i), u₂ ] = u₂ / (3 · u₂²) = 1 / (3 · u₂) = (1 / 3) · e^(- i · 5π / 6) [лишок у другому полюсі]
```

Сума лишків дорівнює:

```
Σ Res = (1 / 3) · [ e^(- i · π / 6) + e^(- i · 5π / 6) ] [додавання лишків обох полюсах]
Σ Res = (1 / 3) · [ (√3/2 - i/2) + (- √3/2 - i/2) ]    [підстановка тригонометричних компонент]
Σ Res = (1 / 3) · [ - i ] = - i / 3                   [результат додавання лишків у верхній півплощині]
```

Згідно з основною теоремою про лишки:

```
∫_{-∞}^∞ u du / (u³ + i) = 2 · π · i · ( - i / 3 ) = 2 · π / 3 [значення контурного інтеграла через лишки]
```

Помноживши на чисельний коефіцієнт `(i · ω · μ / (π · β))`:

```
Z_s = (i · ω · μ / (π · β)) · (2 · π / 3)             [підстановка значення контурного інтеграла]
Z_s = (2 / 3) · (ω · μ / β) · i                      [скорочення числа π у чисельнику та знаменнику]
Z_s = (2 / 3) · (ω · μ / β) · e^(i · π / 2)          [представлення уявної одиниці i у формі e^(i·π/2)]
```

Враховуючи кутовий розклад при дифузному відбитті (`p = 0`), строгий аналітичний розв'язок Реутера та Сондхаймера дає додатковий геометричний коефіцієнт `9/8`, що приводить підсумковий фазовий вираз для дзеркального та дифузного граничних режимів до виразів:

```
Z_s(p=1) = (√3 / 2) · [ (4/3) · (ω² · μ² · l / (π · σ₀)) ]^(1/3) · e^(i · π / 3) [імпеданс при дзеркальному відбитті]
Z_s(p=0) = (9/8) · Z_s(p=1)                          [поправка Реутера — Сондхаймера для дифузного розсіювання]
```

Виділяємо активну `R_s` та реактивну `X_s` частини поверхневого імпедансу:

```
R_s = Re [ Z_s ] = (1 / 2) · (√3 / 2) · [ (4/3) · (ω² · μ² · l / (π · σ₀)) ]^(1/3) [активний опір (cos(π/3)=1/2)]
X_s = Im [ Z_s ] = (√3 / 2) · (√3 / 2) · [ (4/3) · (ω² · μ² · l / (π · σ₀)) ]^(1/3) [реактивний опір (sin(π/3)=√3/2)]
```

Звідси випливає фундаментальне співвідношення для аномального скін-ефекту:

```
X_s = √3 · R_s                                       [фазовий зв'язок реактивного та активного опорів]
```

Фазовий кут між електричним та магнітним полем становить **60°** (`π/3`), на відміну від **45°** (`π/4`) у класичному режимі!

### 6. Скорочення довжини вільного пробігу та порівняльний аналіз

Виразимо статичну провідність `σ₀` за моделлю Друде через параметри електронів на поверхні Фермі:

```
σ₀ = (n · e² · l) / (m* · v_F)                       [модель Друде для статичної провідності металу]
```

Підставимо `σ₀` у вираз для `R_s`:

```
l / σ₀ = l / [ (n · e² · l) / (m* · v_F) ]           [підстановка формули Друде у відношення l / σ_0]
l / σ₀ = (m* · v_F) / (n · e²)                       [скорочення довжини вільного пробігу l у чисельнику й знаменнику]
```

Довжина вільного пробігу `l` повністю скоротилася з рівнянь! Підставляючи це у підсумкову формулу:

```
R_s = (√3 / 4) · [ (4 · ω² · μ² · m* · v_F) / (3 · π · n · e²) ]^(1/3) [підсумкова формула аномального R_s]
R_s ∝ ω^(2/3)                                        [залежність аномального поверхневого опору від частоти]
```

У випадку анізотропних металів або несферичної поверхні Фермі відношення `v_F / n` узагальнюється через кривину поверхні Фермі `K(φ)` у напрямку електричного поля:

```
R_s = C · [ ω² · μ² / ℏ · ∫ |K(φ)|^(-1/2) dφ ]^(1/3) [узагальнений вираз для нелінійної поверхні Фермі]
```

Для експериментальних вимірювань надчистих металів при кріогенних температурах важливим показником є відношення залишкового опору `RRR = σ(4.2K) / σ(300K)`. При `RRR > 1000` класична теорія дає хибний опір `R_s → 0`, тоді як реальний імпеданс виходить на плато аномального режиму.

Нижче наведено порівняльну таблицю ключових математичних характеристик двох режимів:

| Характеристика | Класичний скін-ефект (`l ≪ δ`) | Аномальний скін-ефект (`l ≫ δ`) |
| :--- | :--- | :--- |
| **Співвідношення довжин** | `l ≪ δ_cl` | `l ≫ δ_anom` |
| **Закон Ома** | Локальний: `j(x) = σ · E(x)` | Нелокальний: `j(x) = ∫ K(x, x') E(x') dx'` |
| **Залежність R_s від частоти** | `R_s ∝ ω^(1/2)` | `R_s ∝ ω^(2/3)` |
| **Залежність від температури** | Сильна (`R_s ∝ 1 / √σ(T)`) | Незалежний від `T` та `l` |
| **Співвідношення X_s / R_s** | `X_s = R_s` (фаза 45°) | `X_s = √3 · R_s` (фаза 60°) |
| **Ефективна товщина шару** | `δ_cl = √(2 / (ω · μ · σ))` | `δ_anom ≈ (δ_cl² · l)^(1/3) ∝ ω^(-1/3)` |

Ця математична незалежність `R_s` від температури та її залежність виключно від геометрії поверхні Фермі (`v_F / n`) зробила вимірювання поверхневого імпедансу у режимі аномального скін-ефекту прямим способом визначення імпульсу Фермі `p_F` та фундаментальним інструментом фізики конденсованого стану.
