# ⚙️ Моделювання розмагнічування та робочої точки SmCo

Алгоритм чисельного розрахунку робочої точки (`B_d, H_d`) самарій-кобальтового магніту у замкненому або відкритому магнітопроводі з урахуванням розмагнічувального фактора `N_d` та температурної деградації характеристик `B_r(T)` і `H_cj(T)` до температури 500 °C.

---

### 1. Постановка задачі та фізична модель магнітного ланцюга

У будь-якому практичному застосуванні (електродвигуні, магнітній муфті, датчику або магнітному сепараторі) постійний магніт перебуває під дією власного розмагнічувального поля та полів реакції зовнішніх елементів. Внаслідок цього робочий стан магніту описується точкою (`B_d, H_d`), яка належить II квадранту петлі магнітного гістерезису.

Робоча точка визначається сумісним розв'язком двох рівнянь:
1. **Рівняння матеріалу:** Кривої розмагнічування `B(H, T)` самарій-кобальтового сплаву при робочій температурі `T`.
2. **Рівняння ланцюга (лінії навантаження):** Закону збереження магнітного потоку та теореми про циркуляцію вектора напруженості магнітного поля (закону Ампера).

```
                 II Квадрант кривої розмагнічування
  B (Тл) ^
   B_r  +-------------+------> Лінія розмагнічування B(H, T)
        |             |
   B_d  |.........*...(Робоча точка B_d, H_d)
        |        /|
        |       / |
        |      /  |
        |     /   |
  ------+----+----+---------------------> H (кА/м)
      -H_ci  H_d  0
              \
               \---> Лінія навантаження (Load Line): B = - μ₀ · P_c · H
```

#### Розмагнічувальний фактор N_d та коефіцієнт навантаження P_c
Для ізольованого магніту у формі тіла обертання (еліпсоїда, циліндра або бруса) власне розмагнічувальне поле `H_m` всередині магніту пропорційне намагніченості `M` зі зворотким знаком:

```
H_m = - N_d · M
```

де `N_d` — геометрічний розмагнічувальний фактор вздовж осі намагнічування ($0 < N_d < 1$). Сума розмагнічувальних факторів уздовж трьох ортогональних осей для будь-якого тіла завжди дорівнює одиниці:

```
N_x + N_y + N_z = 1
```

Для сфери `N_x = N_y = N_z = 1/3`. Для тонокого диска, намагніченого перпендикулярно площині, `N_z ≈ 1`. Для довгого тонкого циліндра з відношенням довжини до діаметра `L/D > 5`, намагніченого вздовж осі, `N_z ≈ 0.04`.

Для циліндричних магнітів радіуса `R` та довжини `L` розмагнічувальний фактор `N_d` вздовж осі обчислюється за наближеною формулою Чена та Пардо:

```
N_d = 1 / [ 1 + 2 · (L / (2·R)) ] = 1 / [ 1 + (L / R) ]
```

Зв'язок між індукцією `B` та напруженістю поля `H` у магніті:

```
B = μ₀ · (H + M)  =>  M = (B / μ₀) - H
```

Підставляючи вираз для `M` у рівняння розмагнічувального поля `H = - N_d · M`:

```
H = - N_d · [ (B / μ₀) - H ]

H · (1 - N_d) = - N_d · (B / μ₀)

B = - μ₀ · [ (1 - N_d) / N_d ] · H
```

Величина `P_c = (1 - N_d) / N_d` називається **коефіцієнтом навантаження** (*Permeance Coefficient*, $P_c$). Отже, кутовий нахил лінії навантаження на діаграмі $(B, H)$ визначається виключно геометричним коефіцієнтом $P_c$:

```
B = - μ₀ · P_c · H
```

Для замкненого магнітопроводу з магнітопроводом із м'якого заліза довжиною `L_fe`, перерізом `A_fe` та повітряним зазором товщиною `g` і перерізом `A_g`, коефіцієнт навантаження виражається через відношення геометрії:

```
P_c = (A_m / A_g) · (g / h_m) · f_leak
```

де `h_m` — товщина магніту в напрямку намагнічування, `A_m` — площа магніту, а `f_leak ≈ 0.8–0.95` — коефіцієнт розсіювання магнітного потоку.

#### Лінійне наближення кривої розмагнічування SmCo
Оскільки самарій-кобальтові магніти (`SmCo₅` та `Sm₂Co₁₇`) володіють велетенським полем анізотропії та високою коерцитивністю `H_ci`, їхня крива розмагнічування у II квадранті є строго лінійною до полів `H ≈ - H_ci`. Лінія розмагнічування (і лінія повернення) описується рівнянням:

```
B(H, T) = B_r(T) + μ₀ · μ_rec · H
```

де:
- `B_r(T) = B_r(20 °C) · [1 + α · (T - 20) / 100]` — залишкова індукція при температурі `T`;
- `μ_rec` — відносна магнітна проникність повернення (*recoil permeability*, `1.03–1.05` для `Sm₂Co₁₇` та `1.05–1.08` для `SmCo₅`).

Прирівнюючи вирази для індукції з лінії розмагнічування та з лінії навантаження:

```
B_r(T) + μ₀ · μ_rec · H_d = - μ₀ · P_c · H_d

B_r(T) = - μ₀ · (P_c + μ_rec) · H_d

H_d = - B_r(T) / [ μ₀ · (P_c + μ_rec) ]
```

Підставляючи знайдений `H_d` у рівняння лінії навантаження:

```
B_d = μ₀ · P_c · B_r(T) / [ μ₀ · (P_c + μ_rec) ] = B_r(T) · [ P_c / (P_c + μ_rec) ]
```

Якщо модуль розмагнічувального поля $|H_d|$ перевищує критичну коерцитивну силу `H_cj(T)` при цій температурі, відбувається незворотний злам петлі намагнічування, й магніт втрачає частину індукції навіть після повернення до кімнатної температури.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <stdbool.h>

#define MU_0 1.2566370614359173e-6 /* Гн/м */

typedef struct {
    double br_20c;    /* B_r при 20 °C, Тл */
    double hcj_20c;   /* H_cj при 20 °C, А/м */
    double alpha_br;  /* Темп. коеф. B_r, %/°C */
    double beta_hcj;  /* Темп. коеф. H_cj, %/°C */
    double mu_rec;    /* Проникність повернення (1.03-1.05) */
    double tc;        /* Температура Кюрі, °C */
} SmCoProperties;

typedef struct {
    double B_d;         /* Робоча індукція, Тл */
    double H_d;         /* Робоче поле, А/м */
    double pc;          /* Коефіцієнт навантаження P_c = -B/(mu0*H) */
    bool is_demagged;   /* Прапорець незворотного розмагнічування */
} OperatingPoint;

/* Конструктори типових марок */
static const SmCoProperties SMCO_1_5 = {
    .br_20c = 0.98,
    .hcj_20c = 1591500.0, /* ~20 кЕ */
    .alpha_br = -0.045,
    .beta_hcj = -0.25,
    .mu_rec = 1.05,
    .tc = 727.0
};

static const SmCoProperties SMCO_2_17 = {
    .br_20c = 1.12,
    .hcj_20c = 1989400.0, /* ~25 кЕ */
    .alpha_br = -0.032,
    .beta_hcj = -0.18,
    .mu_rec = 1.03,
    .tc = 820.0
};

/* Розрахунок робочої точки за даної температури та розмагнічувального фактора Nd */
bool calculate_operating_point(const SmCoProperties *prop, double temp_c, 
                               double Nd, OperatingPoint *out_op) {
    if (!prop || !out_op || Nd <= 0.0 || Nd >= 1.0) {
        return false;
    }

    if (temp_c >= prop->tc) {
        out_op->B_d = 0.0;
        out_op->H_d = 0.0;
        out_op->pc = 0.0;
        out_op->is_demagged = true;
        return true;
    }

    /* Температурний перерахунок параметрів */
    double dT = temp_c - 20.0;
    double br_t = prop->br_20c * (1.0 + (prop->alpha_br / 100.0) * dT);
    double hcj_t = prop->hcj_20c * (1.0 + (prop->beta_hcj / 100.0) * dT);

    if (br_t < 0.0) br_t = 0.0;
    if (hcj_t < 0.0) hcj_t = 0.0;

    /* Похил лінії навантаження: B = - mu0 * Pc * H, де Pc = (1 - Nd) / Nd */
    double Pc = (1.0 - Nd) / Nd;
    out_op->pc = Pc;

    /* Рівняння перетину: B_r(T) + mu0*mu_rec*H = - mu0*Pc*H */
    /* H_d = - B_r(T) / (mu0 * (Pc + mu_rec)) */
    double denom = MU_0 * (Pc + prop->mu_rec);
    out_op->H_d = - br_t / denom;
    out_op->B_d = - MU_0 * Pc * out_op->H_d;

    /* Перевірка чи розмагнічувальне поле не перевищує критичне H_cj(T) */
    out_op->is_demagged = (fabs(out_op->H_d) >= hcj_t);

    return true;
}

int main(void) {
    printf("=== Симуляція робочої точки SmCo2:17 при нагріванні ===\n");
    printf("Т (°C) | B_d (Тл) | -H_d (кА/м) | P_c   | Стан\n");
    printf("---------------------------------------------------\n");

    double Nd = 0.2; /* Типовий циліндр L/D ≈ 1 */
    double temps[] = { 20.0, 150.0, 300.0, 450.0, 550.0 };
    size_t n_temps = sizeof(temps) / sizeof(temps[0]);

    for (size_t i = 0; i < n_temps; ++i) {
        OperatingPoint op;
        if (calculate_operating_point(&SMCO_2_17, temps[i], Nd, &op)) {
            printf("%6.1f | %8.4f | %11.1f | %5.2f | %s\n",
                   temps[i], op.B_d, -op.H_d / 1000.0, op.pc,
                   op.is_demagged ? "РОЗМАГНІЧЕНО" : "ОК (Лінійний)");
        }
    }

    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <expected>
#include <string_view>
#include <iomanip>

namespace smco {

constexpr double MU_0 = 1.2566370614359173e-6; // Гн/м

enum class DemagError {
    InvalidGeometry,
    AboveCurieTemperature
};

struct MagnetGrade {
    std::string_view name;
    double br_20c;    // Тл
    double hcj_20c;   // А/м
    double alpha_br;  // %/°C
    double beta_hcj;  // %/°C
    double mu_rec;
    double tc;        // °C
};

struct OperatingState {
    double B_d;       // Тл
    double H_d;       // А/м
    double load_line_slope; // P_c
    bool is_irreversible;
};

class DemagSimulator {
public:
    explicit DemagSimulator(MagnetGrade grade) : grade_(grade) {}

    [[nodiscard]] std::expected<OperatingState, DemagError>
    calculate_state(double temp_c, double demag_factor_nd) const {
        if (demag_factor_nd <= 0.0 || demag_factor_nd >= 1.0) {
            return std::unexpected(DemagError::InvalidGeometry);
        }
        if (temp_c >= grade_.tc) {
            return std::unexpected(DemagError::AboveCurieTemperature);
        }

        const double dT = temp_c - 20.0;
        const double br_t = std::max(0.0, grade_.br_20c * (1.0 + (grade_.alpha_br / 100.0) * dT));
        const double hcj_t = std::max(0.0, grade_.hcj_20c * (1.0 + (grade_.beta_hcj / 100.0) * dT));

        const double Pc = (1.0 - demag_factor_nd) / demag_factor_nd;
        const double H_d = - br_t / (MU_0 * (Pc + grade_.mu_rec));
        const double B_d = - MU_0 * Pc * H_d;

        const bool demagged = (std::abs(H_d) >= hcj_t);

        return OperatingState{
            .B_d = B_d,
            .H_d = H_d,
            .load_line_slope = Pc,
            .is_irreversible = demagged
        };
    }

private:
    MagnetGrade grade_;
};

} // namespace smco

int main() {
    using namespace smco;

    constexpr MagnetGrade Sm2Co17_HT{
        .name = "Sm2Co17 High-Temp Grade",
        .br_20c = 1.12,
        .hcj_20c = 1989400.0,
        .alpha_br = -0.032,
        .beta_hcj = -0.18,
        .mu_rec = 1.03,
        .tc = 820.0
    };

    DemagSimulator sim(Sm2Co17_HT);
    const double Nd = 0.25;

    std::cout << "=== Обчислення C++23 для " << Sm2Co17_HT.name << " (Nd = " << Nd << ") ===\n";
    std::cout << std::fixed << std::setprecision(3);

    const std::vector<double> test_temperatures = { 20.0, 200.0, 350.0, 500.0, 850.0 };

    for (double T : test_temperatures) {
        auto result = sim.calculate_state(T, Nd);
        std::cout << "Т = " << std::setw(5) << T << " °C: ";
        if (result) {
            std::cout << "B_d = " << result->B_d << " Тл, H_d = " 
                      << std::setw(8) << result->H_d / 1000.0 << " кА/м | "
                      << (result->is_irreversible ? "УВАГА: Незворотні втрати!" : "Норма");
        } else {
            if (result.error() == DemagError::AboveCurieTemperature) {
                std::cout << "ПОМИЛКА: Температура перевищує точку Кюрі!";
            } else {
                std::cout << "ПОМИЛКА: Некоректна геометрія (Nd)!";
            }
        }
        std::cout << '\n';
    }

    return 0;
}
```

### 3. Архітектурні особливості та інженерний аналіз результатів

1. **Типізація помилок через `std::expected` (C++23):** Замість повернення небезпечних некоректних значень або викидання важких винятків (*exceptions*), модуль C++ використовує сучасний стандартний тип `std::expected`. Це гарантує перевірку викликів на етапі компіляції й унеможливлює використання невалідного стану магніту при проходженні точки Кюрі.
2. **Просторовий розподіл `N_d` у скінченно-елементних моделях (FEA):** У реальних прямокутних блоках поле `N_d` є нелінійним і зосередженим на гострих кутах та кутах виходу магнітного потоку. При аналізі високонавантажених електродвигунів розрахована середня робоча точка `B_d` виступає першим наближенням для ініціалізації сітки 3D FEA (Finite Element Analysis) в ANSYS Maxwell або COMSOL Multiphysics.
3. **Динамічні зовнішні розмагнічувальні поля (Stator Reaction):** У вентильних двигунах зі зворотними струмами поля реакції статора додаються до власного розмагнічувального поля магніту:

```
H_total = H_d - H_stator_reaction
```

Якщо `|H_total| > H_cj(T)`, магніт зазнає місцевого розмагнічування на кутах полюсів ротора. Самарій-кобальтові магніти `Sm₂Co₁₇` завдяки високій коерцитивності `H_cj > 25 кЕ` та лінійній кривій розмагнічування дозволяють проектувати двигуни з високою щільністю струму без ризику незворотного розмагнічування полюсів.
4. **Порівняння C та C++ реалізацій:** Реалізація мовою C призначена для вбудованих контролерів сервоприводів та лічильників з обмеженою пам'яттю (STM32, ESP32), де відсутні динамічне виділення пам'яті та стандартна бібліотека C++. Реалізація мовою C++23 забезпечує сувору інкапсуляцію та нульові накладні витрати (*zero-cost abstractions*) для САПР і високоефективних інженерних симуляцій.
5. **Динаміка лінії повернення (Recoil Line Trajectories):** При циклічних змінах температури від 20 °C до 300 °C робоча точка переміщується вздовж лінії повернення з нахилом `μ_rec ≈ 1.03`. Оскільки крива розмагнічування `Sm₂Co₁₇` залишається лінійною у всьому робочому діапазоні, зсув є 100% оборотним. Після повернення системного блоку до початкової температури 20 °C залишкова індукція повністю відновлюється до значення `1.12 Тл` без виникнення гістерезисних втрат чи потреби у повторному намагнічувальному імпульсі.
6. **Компенсація температурного дрейфу в чутливих вимірювальних приладах:** У датчиках Холла та датчиках кута повороту аерокосмічного виконання зсув індукції `α = -0.032% / °C` може компенсуватися алгоритмічно на рівні мікроконтролера за допомогою вбудованого термодатчика або шляхом застосування термокомпенсаційних шунтів зі сплавів нікелю та заліза (пермаллоїв із низькою точкою Кюрі), які відгалужують надлишковий магнітний потік при охолодженні.
