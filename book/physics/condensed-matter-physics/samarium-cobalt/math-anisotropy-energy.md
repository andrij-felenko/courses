# 🧮 Кристалографічна анізотропія та квантовий механізм 4f-3d обміну

Математичний апарат кристалографічної анізотропії рідкісноземельних міжметалідів пояснює, як колосальне поле анізотропії (`H_A > 250 кЕ`) виникає з взаємодії кулонівського поля кристалічної ґратки з асиметричною 4f-електронною хмарою іона самарію `Sm³⁺` та як ця анізотропія передається 3d-електронам кобальту.

---

### 1. Феноменологічний опис енергії анізотропії у гексагональній ґратці

У гексагональному кристалі (структурні типи `CaCu₅` для `SmCo₅` та `Th₂Zn₁₇` / `Th₂Ni₁₇` для `Sm₂Co₁₇`) густина енергії магнітної кристалографічної анізотропії `E_A` розкладається в ряд за ступенями направляючих косинусів або синусів полярного кута `θ` між вектором намагніченості `M` та гексагональною віссю `c` (`[0001]`), а також азимутального кута `φ` у базисній площині `(ab)`:

```
E_A(θ, φ) = K₁·sin²(θ) + K₂·sin⁴(θ) + K₃·sin⁶(θ) + K₄·sin⁶(θ)·cos(6φ)
```

де:
- `θ` — полярний кут вектора намагніченості відносно осі `c`;
- `φ` — азимутальний кут у базисній площині `(ab)`;
- `K₁, K₂, K₃, K₄` — феноменологічні константи анізотропії з розмірністю густини енергії (Дж/м³ або ерг/см³).

Для `SmCo₅` за кімнатної температури константа першого порядку становить `K₁ ≈ 1.7 · 10⁷ Дж/м³`, тоді як константа другого порядку `K₂ ≈ 0.1 · 10⁷ Дж/м³`. Оскільки `K₁ ≫ K₂ > 0`, азимутальною анізотропією `K₄` та вищими членами розкладу у першому наближенні можна знехтувати:

```
E_A(θ) ≈ K₁·sin²(θ) + K₂·sin⁴(θ)
```

Оскільки `K₁ > 0`, мінімум енергії `E_A` досягається при `θ = 0` або `θ = π`, що відповідає орієнтації намагніченості строго уздовж кристалографічної осі `c`. Ця вісь називається **віссю легкого намагнічування** (*easy axis*). Якби константа `K₁` мала від'ємний знак (`K₁ < 0`), мінімум енергії відповідав би `θ = π/2`, і легкий напрямок лежав би у базисній площині (*easy plane*), що унеможливило б створення висококоерцитивного постійного магніту.

#### Метод Саксміта — Томпсона для експериментального визначення K₁ та K₂
Для експериментального розділення констант `K₁` та `K₂` використовують метод Саксміта — Томпсона (*Sucksmith-Thompson method*), який спирається на вимірювання кривої намагнічування вздовж «важкого» напрямку (у базисній площині, при `θ = π/2`).

Рівняння рівноваги вектора намагніченості у зовнішньому полі `H`, прикладеному під кутом `π/2` до осі `c`:

```
d/dθ [ E_A(θ) - μ₀ · M_s · H · sin(θ) ] = 0

2·K₁·sin(θ)·cos(θ) + 4·K₂·sin³(θ)·cos(θ) - μ₀·M_s·H·cos(θ) = 0
```

Скорочуючи на `cos(θ) ≠ 0` (до моменту повного насичення) та позначаючи відносну намагніченість уздовж поля як `m = sin(θ) = M_⊥ / M_s`:

```
2·K₁·m + 4·K₂·m³ = μ₀·M_s·H
```

Ділячи обидві частини на `m`:

```
μ₀ · M_s · H / m = 2·K₁ + 4·K₂·m²
```

Побудова графічної залежності величини `(H / M_⊥)` від квадрата намагніченості `M_⊥²` дає пряму лінію, відрізок якої на осі ординат дає значення `2 K₁ / (μ₀ M_s²)`, а кутовий нахил дозволяє обчислити `4 K₂ / (μ₀ M_s⁴)`.

#### Розрахунок ефективного поля анізотропії H_A
Поле анізотропії `H_A` за визначенням є еквівалентним внутрішнім магнітним полем, яке утримує вектор намагніченості уздовж легкої осі `c`. Його величина дорівнює зовнвшньому полю, необхідному для повного розвертання намагніченості у важкий напрямок (`m = sin(θ) = 1`):

```
H_A = (2·K₁ + 4·K₂) / (μ₀ · M_s)
```

При нехтуванні `K₂` отримуємо фундаментальне співвідношення:

```
H_A = 2·K₁ / (μ₀ · M_s)
```

Для `SmCo₅` із виміряними параметрами `K₁ = 1.7 · 10⁷ Дж/м³` та намагніченістю насичення `M_s ≈ 7.7 · 10⁵ А/м` (`μ₀·M_s ≈ 0.97 Тл`):

```
H_A = 2 · (1.7 · 10⁷) / (4·π · 10⁻⁷ · 7.7 · 10⁵)
    = 3.4 · 10⁷ / 0.9676
    ≈ 3.51 · 10⁷ А/м  (≈ 440 кЕ / 44 Тл)
```

Навіть із урахуванням температурних відхилень та вищих порядків анізотропії реальне поле анізотропії `SmCo₅` за кімнатної температури сягає `H_A ≈ 250–300 кЕ` (`20–24 МА/м`), що є абсолютним рекордом серед усіх практичних постійних магнітів.

### 2. Квантовомеханічна природа 4f-анізотропії: кристал-філд та Стівенс-фактори

У чому полягає мікроскопічна квантова причина такої велетенської анізотропії? Відповідь дає теорія внутрішньокристалічного електричного поля (*crystal field theory*).

В іоні самарію `Sm³⁺` незаповнена 4f-оболонка містить 5 електронів (`4f⁵`). Згідно з правилами Гунда для основного мультиплету `Sm³⁺`:
- Сумарний орбітальний момент: `L = 5`;
- Сумарний спіновий момент: `S = 5/2`;
- Згідно зі спин-орбітальною взаємодією `H_so = λ · L · S` для менш ніж напівзаповненої оболонки (`λ > 0`), повний момент квантується як `J = |L - S| = 5/2`.

Гамільтоніан одноатомної кристалографічної анізотропії 4f-іона у кристалічному полі описується через метод еквівалентних операторів Стівенса `O_k^m(J)`:

```
H_CF = ∑_{k,m} B_k^m · O_k^m(J) = B₂⁰·O₂⁰ + B₄⁰·O₄⁰ + B₆⁰·O₆⁰ + B₆⁶·O₆⁶
```

де оператор квадрупольного моменту другого порядку має вигляд:

```
O₂⁰ = 3·J_z² - J·(J+1)
```

Параметри кристалічного поля `B_k^m` виражаються через розклад електростатичного потенціалу ґратки `A_k^m` та коефіцієнти Стівенса `α_J, β_J, γ_J`:

```
B₂⁰ = α_J · <r₄f²> · A₂⁰
```

де:
- `α_J` — фактор Стівенса другого порядку, який характеризує асферичність (еліпсоїдальність) розподілу заряду 4f-електронної хмари іона;
- `<r₄f²>` — квантовомеханічне середнє квадрата радіуса 4f-орбіталі;
- `A₂⁰` — градієнт кристалічного електричного поля на вузлі рідкісноземельного елемента, створюваний оточуючими атомами ґратки.

Знак та величина фактора Стівенса `α_J` визначаються електронною конфігурацією конкретного лантаноїда:
- Для іона самарію `Sm³⁺` фактор Стівенса має **позитивний знак** (`α_J = +0.0413 > 0`). Це означає, що 4f-електронна хмара `Sm³⁺` має форму витягнутого сфероїда (*prolate electron cloud*).
- Для іонів неодиму `Nd³⁺` (`α_J = -0.0064`), диспрозію `Dy³⁺` (`α_J = -0.0063`) та тербію `Tb³⁺` (`α_J = -0.0101`) фактори Стівенса мають **від'ємний знак** (їхня електронна хмара є сплюснутим диском, *oblate electron cloud*).

Для гексагональної кристалічної ґратки `SmCo₅` градієнт електричного поля на вузлі самарію є від'ємним (`A₂⁰ < 0`). Отже, для `Sm³⁺`:

```
B₂⁰ = α_J · <r₄f²> · A₂⁰  <  0   (оскільки α_J > 0, а A₂⁰ < 0)
```

Від'ємне значення `B₂⁰` означає, що мінімум енергії гамільтоніана `H_CF` досягається при максимальному значенні полярної проєкції `J_z = ± J = ± 5/2`. Це жорстко зафіксовує магнітний момент іона самарію вздовж осі `z` (кристалографічної осі `c`), утворюючи потужну одновісну анізотропію.

Якби ми спробували замінити самарій на неодим `Nd³⁺` у тій самій гексагональній ґратці `CaCu₅`, то через від'ємний знак `α_J < 0` отримали б `B₂⁰ > 0`. Це призвело б до легкого напрямку у базисній площині (`J_z = 0`), і сполука `NdCo₅` не була б магнітотвердою при кімнатній температурі. В цьому полягає фундаментальна краса фізики рідкісноземельних магнітів: симетрія електронної хмари конкретного іона мусить ідеально відповідати симетрії електростатичного поля кристала.

### 3. Гамільтоніан 4f-3d обмінної взаємодії та температурний закон Каллена — Каллена

Сам по собі 4f-підмагнітний шар не міг би утримати впорядкування за високих температур, оскільки непрямий обмін між рідкісноземельними іонами Рудермана — Киттеля — Касуї — Йосіди (RKKY) через електрони провідності є слабким (`T_c(Sm) < 30 K`). 

Висока температура Кюрі забезпечується сильним прямим 3d-3d обміном між атомами кобальту (`J_Co-Co > 0`, `T_c > 700 °C`).

Зв'язок між двома підсистемами описується **гамільтоніаном міжпідґраткового 4f-3d обміну**:

```
H_ex = - 2 · J_3d-4f · (g_J - 1) · (J_Sm · S_Co)
```

де:
- `J_3d-4f` — ефективний обмінний інтеграл між 3d-електронами кобальту та 4f-електронами самарію;
- `g_J` — фактор Ланде для `Sm³⁺` (`g_J = 2/7`).

Оскільки для легких рідкісноземельних елементів (`J = L - S`) величина `(g_J - 1) = -5/7 < 0` є від'ємною, спіновий та повний моменти спрямовані протилежно. В результаті ефективна обмінна взаємодія між магнітними моментами самарію та кобальту є строго **феромагнітною** (паралельною). Обмінне поле кобальту (`H_ex ≈ 300 Тл`) «прив'язує» спіни кобальту до анізотропної осі самарію.

#### Температурна залежність константи анізотропії K₁(T)
Згідно з квантово-статистичною теорією Каллена — Каллена (*Callen-Callen power law*), температурне падіння константи анізотропії `K₁(T)` під дією теплових спінових флуктуацій для одноатомної анізотропії другого порядку описується степенем відносної намагніченості підґратки:

```
K₁(T) = K₁(0) · [ M_Sm(T) / M_Sm(0) ]³
```

Оскільки обмінне поле кобальту утримує підґратку самарію у високопаралельному стані до температур 300–400 °C, спад `K₁(T)` у самарій-кобальтових магнітах відбувається значно повільніше, ніж у феритах чи неодимових сплавах.

### 4. Розрахунок теоретичної межі максимального енергетичного добутку (BH)_max

Максимальний енергетичний добуток `(BH)_max` є головним критерієм якості постійного магніту. Він характеризує максимальну густину магнітостатичної енергії, яку одиниця об'єму магніту може передати у зовнішнє середовище (робочий зазор):

```
(BH)_max = - (B · H)_max   в II квадранті петлі гістерезису
```

Проведемо математичний вивід теоретичної межі `(BH)_max` для ідеального прямокутного магніту.

У II квадранті залежність магнітної індукції `B` від внутрішнього поля `H` (яке є від'ємним, `H < 0`) виражається через намагніченість `J(H)`:

```
B(H) = μ₀·H + J(H)
```

Для ідеального магнітотвердого матеріалу із прямокутною петлею намагніченості намагніченість залишається сталою та дорівнює залишковій індукції `J(H) = B_r = const` у всьому діапазоні полів до коерцитивної сили `H > - H_ci`. Тоді:

```
B(H) = μ₀·H + B_r
```

Записавши вираз для енергетичної функції `f(H) = B · H`:

```
f(H) = (μ₀·H + B_r) · H = μ₀·H² + B_r·H
```

Знаходимо екстремум (максимум) цієї функції шляхом взяття першої похідної за полем `H`:

```
df/dH = d/dH [ μ₀·H² + B_r·H ] = 2·μ₀·H + B_r = 0

H_opt = - B_r / (2·μ₀)
```

Підставляючи оптимальне поле `H_opt` назад у вираз для індукції `B`:

```
B_opt = μ₀ · [ - B_r / (2·μ₀) ] + B_r = - B_r/2 + B_r = B_r / 2
```

Таким чином, у точці максимальної енергетичної віддачі робоча індукція дорівнює половині залишкової індукції (`B_d = B_r / 2`), а робоче поле дорівнює половині коерцитивного поля за індукцією (`H_d = - B_r / (2 μ₀)`).

Підставляючи `B_opt` та `H_opt` у вираз для `(BH)_max`:

```
(BH)_max = - (B_opt · H_opt) = - (B_r / 2) · [ - B_r / (2·μ₀) ] = B_r² / (4·μ₀)
```

Розрахуємо теоретичні межі `(BH)_max` для обох фах самарій-кобальтових магнітів.

#### 1. Для SmCo₅ (Фаза 1:5)
При залишковій індукції `B_r ≈ 1.05 Тл`:

```
(BH)_max,th = (1.05)² / (4 · 4·π · 10⁻⁷)
            = 1.1025 / (5.0265 · 10⁻⁶)
            ≈ 219 320 Дж/м³  (≈ 27.5 МГОе)
```

#### 2. Для Sm₂Co₁₇ (Фаза 2:17)
При залишковій індукції `B_r ≈ 1.18 Тл`:

```
(BH)_max,th = (1.18)² / (4 · 4·π · 10⁻⁷)
            = 1.3924 / (5.0265 · 10⁻⁶)
            ≈ 277 000 Дж/м³  (≈ 34.8 МГОе)
```

Промислові високоякісні спечені магніти `Sm₂Co₁₇` досягають реальних значень `(BH)_max ≈ 30–32 МГОе` (`240–255 кДж/м³`), що становить понад 90% теоретичної квантової межі, підтверджуючи виняткову досконалість осередкової наноструктури та високий рівень магнітного вирівнювання кристалітів.
