# 🧮 Математичне виведення бета-функції КХД та залежності константи зв'язку

Ця вставка містить строге аналітичне виведення бета-функції квантової хромодинаміки (КХД) у першому та другому петельних наближеннях теорії збурень у схемі розміркісної регуляризації та мінімальних віднімань (MS-bar), повний розрахунок вагових внесків ферміонних петель кварків, ґлуонних автовзаємодій та духів Фаддєєва — Попова, а також точне інтегрування рівняння ренормалізаційної групи для ефективної константи зв'язку `α_s(Q²)`.

---

### 1. Калібрувальний Лагранжіан та правила Фейнмана квантової хромодинаміки

Квантова хромодинаміка є квантовою теорією поля, побудованою на неабелевій локальній калібрувальній групі колірної симетрії `SU(3)_c`. Колірні за заряди діють на трикомпонентні комплексні кваркові спінори `q = (q_R, q_G, q_B)^T`, а взаємодія переношується 8 векторними калібрувальними полями ґлуонів `A^a_\mu` (`a = 1, ..., 8`).

Класичний Лагранжіан КХД у коваріантному лоренцівському калібруванні з параметром зафіксованого калібрування `ξ` має вигляд:

```
L_QCD = - (1 / 4) · G^a_{\mu\nu} · G^{a,\mu\nu} + ∑_{f=1}^{n_f} q̄_f · ( i · γ^\mu · D_\mu - m_f ) · q_f - (1 / (2·ξ)) · (∂_\mu A^{a,\mu})² + c̄^a · ( - ∂^\mu · D_{\mu}^{ab} ) · c^b
```

Компоненти даного Лагранжіана мають наступну фізичну структуру:
1. **Тензор калібрувального поля `G^a_{\mu\nu}`:**
   Описує кінетичну енергію та самодію векторних ґлуонів:
   ```
   G^a_{\mu\nu} = ∂_\mu A^a_\nu - ∂_\nu A^a_\mu + g_0 · f^{abc} · A^b_\mu · A^c_\nu
   ```
   де `f^{abc}` — цілком антисиметричні структурні константи алгебри Лі `su(3)`, які задовольняють комбінаторному співвідношенню `[T^a, T^b] = i · f^{abc} · T^c`. Генератори `T^a = λ^a / 2` відповідають матрицям Ґелл-Манна. Існування нелінійного доданку `g_0 · f^{abc} · A^b_\mu · A^c_\nu` породжує трибозонні `A³` та чотирибозонні `A⁴` вершини взаємодії ґлуонів між собою.
2. **Коваріантна похідна `D_\mu`:**
   Забезпечує коваріантність квантових полів відносно локальних перетворень `SU(3)_c`:
   ```
   D_\mu = ∂_\mu - i · g_0 · A^a_\mu · T^a
   ```
3. **Духові поля Фаддєєва — Попова `c^a`:**
   Оскільки квантування неабелевих калібрувальних полів у континуальному інтегралі за конфігураціями вимагає зафіксувати калібрувальний режим (для усунення нефізичних поздовжніх і часових ступенів вільності ґлуонів), у теорію вводяться фіктивні скалярні духові поля `c^a` з антикомутативною статистикою Фермі — Дірака. Коваріантна похідна духового поля у приєднаному представленні дорівнює:
   ```
   D_{\mu}^{ab} = δ^{ab} · ∂_\mu - g_0 · f^{abc} · A^c_\mu
   ```

### 2. Схема ренормалізації та тотожності Славнова — Тейлора

У процесі квантовопольових обчислень діаграми Фейнмана з вакуумними петлями містять ультрафіолетові (УФ) розбіжності при великих віртуальних імпульсах `k → ∞`. Для їх усунення застосовується метод розміркісної регуляризації Патера — Вейтмана у просторі-часі розмірності `d = 4 - 2·ε`.

У розмірності `d = 4 - 2·ε` безрозмірна константа зв'язку замінюється на величину `g_0 · μ^ε`, де `μ` — довільний масовий масштаб ренормалізації (‘т Хоофта). Зв'язок між незарегульованими («голими») та ренормалізованими фізичними полями задається за допомогою безрозмірних констант ренормалізації `Z`:

```
A_{0,\mu}^a = √Z_3 · A_\mu^a                    [ренормалізація калібрувального ґлуонного поля]
q_0 = √Z_2 · q                                  [ренормалізація ферміонного кваркового поля]
c_0^a = √Z_{3c} · c^a                           [ренормалізація духового поля Фаддєєва-Попова]
g_0 = μ^ε · g · Z_g                             [ренормалізація калібрувального заряду]
```

Калібрувальна симетрія неабелевої теорії інваріантна відносно BRST-перетворень (Беккі — Руе — Стора — Тютіна). Це накладає суворі тотожності Славнова — Тейлора між константами ренормалізації полів та вершин:

```
Z_g = Z_{1,3g} / ( Z_3 )^(3/2)                  [через триґлуонну вершину]
Z_g = Z_{1,qqg} / ( Z_2 · √Z_3 )                [через кварк-ґлуонну вершину]
Z_g = Z_{1,ccg} / ( Z_{3c} · √Z_3 )               [через дух-ґлуонну вершину]
```

Ці співвідношення гарантують, що незалежно від того, яку саме вершину обрано для розрахунку ренормалізації заряду, підсумкова бета-функція теорії є універсальною та унікальною.

### 3. Повний однопетельний розрахунок поляризаційного оператора ґлуона Z₃

Розглянемо поправки першого порядку теорії збурень до власної енергії (поляризаційного оператора) ґлуона `Π^{ab}_{\mu\nu}(q)`. Завдяки лоренцівській інваріантності та калібрувальній симетрії тензор поляризації має строго поперечну структуру:

```
Π^{ab}_{\mu\nu}(q) = δ^{ab} · ( q² · g_{\mu\nu} - q_\mu · q_\nu ) · Π(q²)
```

Значення `Z_3` пов'язане з виділенням вилітної полюсної частини `1/ε` поляризаційного оператора: `Z_3 = 1 + Π_{1/ε}`.

Обчислимо внески трьох типів квантових петель у фейнманівській калібровці (`ξ = 1`):

#### А. Кваркова ферміонна петля (колірне екранування)
Діаграма з віртуальною кварковою петлею `q q̄` для `n_f` активних ароматів дає квантовий інтеграл:

```
i · Π^{ab,(q)}_{\mu\nu}(q) = - n_f · ∫ (d^d k / (2·π)^d) · Sp[ (-i·g₀·γ_\mu·T^a) · (i·k̸ / k²) · (-i·g₀·γ_\nu·T^b) · (i·(k̸ - q̸) / (k - q)²) ]
```

Обчислюючи шпур `Sp[T^a T^b] = T_F · δ^{ab}` (де `T_F = 1/2`) та алгебру гамма-матриць `Sp[γ_\mu γ_\alpha γ_\nu γ_\beta] = 4 · (g_{\mu\alpha} g_{\nu\beta} - g_{\mu\nu} g_{\alpha\beta} + g_{\mu\beta} g_{\nu\alpha})`, отримуємо:

```
Π_q(q²) = - (g² / (16 · π²)) · (4 / 3) · T_F · n_f · (1 / ε) + O(1)
```

Підставляючи `T_F = 1/2` для колірної групи `SU(3)_c`:

```
ΔZ_3^{(q)} = - (g² / (16 · π²)) · (2 / 3) · n_f · (1 / ε)
```

Цей внесок є від'ємним, що відповідає **екрануванню** колірного заряду віртуальними кварковими парами.

---

#### Б. Ґлуонна самодіяльна петля (колірне антиекранування)
Діаграма з віртуальною ґлуонною петлею за рахунок трибозонної вершини взаємодії включає антисиметричні структурні константи `f^{acd} f^{bcd} = C_A · δ^{ab}` (де `C_A = 3` для `SU(3)`). 

Інтегрування за віртуальним імпульсом `k` у розмірності `d = 4 - 2·ε` дає внесок:

```
Π_g(q²) = + (g² / (16 · π²)) · (19 / 6) · C_A · (1 / ε) + O(1)
```

Цей внесок є додатним і описує **антиекранування** заряду за рахунок парамагнітного вакуумного відгуку самодіючих калібрувальних бозонів.

---

#### В. Петля духів Фаддєєва — Попова
Оскільки скалярні духи `c^a` мають ферміонну статистику (кожна духова петля входить зі знаком мінус за правилами Фейнмана), внесок дух-антидух петлі виражається як:

```
Π_c(q²) = - (g² / (16 · π²)) · (1 / 6) · C_A · (1 / ε) + O(1)
```

---

#### Г. Підсумкова константа ренормалізації ґлуонного поля Z₃
Додаючи калібрувальний внесок ґлуонів та духовий внесок:

```
Π_{gauge}(q²) = Π_g(q²) + Π_c(q²)
= (g² / (16 · π²)) · C_A · [ (19 / 6) - (1 / 6) ] · (1 / ε)
= + (g² / (16 · π²)) · (5 / 3) · C_A · (1 / ε)
```

Підсумовуючи внески полів по сукупності:

```
Z_3 = 1 + (g² / (16 · π²)) · [ (5 / 3) · C_A - (4 / 3) · T_F · n_f ] · (1 / ε)
```

Для колірної групи `SU(3)_c` (`C_A = 3`, `T_F = 1/2`):

```
Z_3 = 1 + (g² / (16 · π²)) · [ 5 - (2 / 3) · n_f ] · (1 / ε)
```

### 4. Розрахунок Z_{1,qqg}, Z₂ та виведення бета-функції

Для отримання ренормалізації калібрувального заряду `Z_g` скористаємося тотожністю Славнова — Тейлора через кварк-ґлуонну вершину:

```
Z_g = Z_{1,qqg} / ( Z_2 · √Z_3 )
```

1. **Ренормалізація хвильової функції кварка `Z_2`:**
   Розрахунок власної енергії кварка від випромінювання віртуального ґлуона дає:
   ```
   Z_2 = 1 - (g² / (16 · π²)) · C_F · (1 / ε)
   ```
   де `C_F = (N² - 1) / (2·N) = 4/3` — фундаментальний оператор Казимира для `SU(3)`.

2. **Ренормалізація кварк-ґлуонної вершини `Z_{1,qqg}`:**
   Вершинні однопетельні діаграми включають абелеву поправку (фотонний тип) та неабелеву поправку з триґлуонним вузлом:
   ```
   Z_{1,qqg} = 1 - (g² / (16 · π²)) · [ C_F + C_A ] · (1 / ε)
   ```

3. **Точний розрахунок `Z_g`:**
   Підставляємо значення `Z_3`, `Z_2` та `Z_{1,qqg}` у формулу `Z_g`:

```
Z_g = Z_{1,qqg} · (Z_2)⁻¹ · (Z_3)⁻¹/²
= [ 1 - (g² / (16·π²))·(C_F + C_A)·(1/ε) ] · [ 1 + (g² / (16·π²))·C_F·(1/ε) ] · [ 1 - (1/2)·(g² / (16·π²))·((5/3)C_A - (4/3)T_F n_f)·(1/ε) ]
```

Абелеві члени `C_F` повністю скорочуються (що демонструє узгодженість із тотожністю Ворда у QED), залишаючи лише неабелеві внески:

```
Z_g = 1 - (g² / (16 · π²)) · [ C_A + (5 / 6) · C_A - (2 / 3) · T_F · n_f ] · (1 / ε)
= 1 - (g² / (16 · π²)) · [ (11 / 6) · C_A - (2 / 3) · T_F · n_f ] · (1 / ε)
```

Для колірної групи `SU(3)_c` (`C_A = 3`, `T_F = 1/2`):

```
Z_g = 1 - (g² / (16 · π²)) · [ (11 / 2) - (1 / 3) · n_f ] · (1 / ε)
```

### 5. Бета-функція КХД та її вищі петельні поправки

Оскільки «гола» константа зв'язку `g_0 = μ^ε · g · Z_g` не залежить від вибору масштабу `μ`:

```
d g_0 / d ln(μ) = 0
```

Диференціюємо за `ln(μ)` і виражаємо бета-функцію `β(g) = dg / d ln(μ)`:

```
β(g) = - ε · g - g · ( d ln Z_g / d ln μ )
```

Обчислюючи похідну `d ln Z_g / d ln μ` у фізичній межі `ε → 0` (`d = 4`), отримуємо:

```
β(g) = - (β₀ / (16 · π²)) · g³
```

де перший коефіцієнт бета-функції КХД становить:

```
β₀ = (11 / 3) · C_A - (4 / 3) · T_F · n_f = 11 - (2 / 3) · n_f
```

Переходячи до константи тонкої структури КХД `α_s = g² / (4·π)`:

```
d α_s / d ln(Q²) = β(α_s) = - (β₀ / (4 · π)) · α_s² - (β₁ / (16 · π²)) · α_s³ - (β₂ / (64 · π³)) · α_s⁴ - ...
```

Коефіцієнти вищих порядків бета-функції КХД у схемах MS-bar дорівнюють:
- **Двопетельний коефіцієнт `β₁`:**
  ```
  β₁ = (34 / 3) · C_A² - (20 / 3) · C_A · T_F · n_f - 4 · C_F · T_F · n_f
  = 102 - (38 / 3) · n_f
  ```
- **Трипетельний коефіцієнт `β₂`:**
  ```
  β₂ = 2857 / 2 - (5033 / 18) · n_f + (325 / 54) · n_f²
  ```

### 6. Точне інтегрування та аналітична формула еволюції α_s(Q²)

Для однопетельного рівняння `d α_s / d ln(Q²) = - (β₀ / (4·π)) · α_s²` розділимо змінні та проінтегруємо від опорного масштабу `μ²` до довільного кінематичного переданого імпульсу `Q²`:

```
∫_{α_s(μ²)}^{α_s(Q²)} ( 1 / α² ) dα = - (β₀ / (4 · π)) · ∫_{μ²}^{Q²} d ln(k²)
⇒ [ - 1 / α_s ]_{α_s(μ²)}^{α_s(Q²)} = - (β₀ / (4 · π)) · ln( Q² / μ² )
⇒ ( 1 / α_s(Q²) ) - ( 1 / α_s(μ²) ) = (β₀ / (4 · π)) · ln( Q² / μ² )
```

Виражаємо `α_s(Q²)`:

```
α_s(Q²) = α_s(μ²) / [ 1 + (β₀ / (4 · π)) · α_s(μ²) · ln( Q² / μ² ) ]
```

Вводимо вільний від інваріантності ренормалізаційного масштабу `μ` фізичний параметр **`Λ_QCD`** (*Dimensional Transmutation*):

```
Λ_QCD² = μ² · exp( - (4 · π) / ( β₀ · α_s(μ²) ) )
```

Тоді підсумкова аналітична формула для константи зв'язку КХД при довільному імпульсі `Q²` набуває виключно прозорого вигляду:

```
α_s(Q²) = (4 · π) / [ β₀ · ln( Q² / Λ_QCD² ) ]
```

У двопетельному наближенні розклад за логарифмічним масштабом `t = ln(Q² / Λ_QCD²)` приймає вигляд:

```
α_s^{(2-loop)}(Q²) = (4 · π) / ( β₀ · t ) · [ 1 - (β₁ / β₀²) · ( ln(t) / t ) ]
```

Ці строго виведені математичні формули є теоретичним доказом того, що при збільшенні імпульсу `Q² → ∞` константа зв'язку КХД `α_s(Q²)` логарифмічно зникає (**асимптотична свобода**), а при наближенні до масштабу `Q² → Λ_QCD²` константа прямує до нескінченності (**конфайнмент**).
