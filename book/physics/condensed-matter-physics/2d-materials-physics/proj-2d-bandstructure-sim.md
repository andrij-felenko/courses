# ⚙️ Чисельний розрахунок зонної структури 2D матеріалів

Цей практичний модуль присвячено розробці чисельного алгоритму розрахунку зонної структури двовимірних кристалів методом сильного зв'язку (Tight-Binding Model) у наближенні лінійної комбінації атомних орбіталей (LCAO — Linear Combination of Atomic Orbitals). Модуль містить повний теоретичний опис дискретизації оберненого простору, математичну формулізацію матричного Гамільтона для графена та дихалькогенідів перехідних металів (TMD), а також готові реалізації мовами Python і C++ із детальним аналізом чисельних крайових випадків, похибок дискретизації та порівнянням із методом функціонала густини (DFT).

## 1. Фізична модель сильного зв'язку та дискретизація зони Бріллюена

Метод сильного зв'язку опирається на припущення, що валентні електрони в двовимірному кристалі значною мірою локалізовані поблизу своїх атомних ядер, а їхній перенос по решітці відбувається шляхом квантовомеханічного тунелювання (перескоку) між найближчими або наступними за ними сусідами.

Для моношару графена елементарна комірка містить два атоми вуглецю, що належать до нееквівалентних підґраток `A` та `B`. Валентна провідність визначається `2pz`-орбіталями, які утворюють де локалізовану систему `π`- та `π*`-зон. Хвильова функція Блоха (від імені швейцарського фізика Фелікса Блоха) розкладається за атомними базисними функціями:

```
Ψ_k(r) = C_A(k) · Φ_A(k, r) + C_B(k) · Φ_B(k, r)
```

де `Φ_A` та `Φ_B` — блохівські суми атомних `2pz`-орбіталей на підґратках `A` та `B` відповідно.

Матричний Гамільтоніан системи у k-просторі має розмірність `2 × 2`:

```
H(k) = [[  H_AA(k),  H_AB(k) ]
        [ H_BA(k),  H_BB(k) ]]
```

У найпростішому наближенні найближчих сусідів діагональні елементи визначають відносний енергетичний рівень атомів `H_AA = H_BB = ε_0` (який можна прийняти за точку відліку `ε_0 = 0`). Позадіагональний елемент `H_AB(k)` описує тунельний перескок між підґратками `A` та `B`:

```
H_AB(k) = -t · [ e^{i · k · δ₁} + e^{i · k · δ₂} + e^{i · k · δ₃} ]
```

де `t ≈ 2.7 еВ` — інтеграл перескоку найближчих сусідів, а `δ₁`, `δ₂`, `δ₃` — вектори, що з'єднують центральний атом підґратки `A` із трьома найближчими атомами підґратки `B`.

У декартових координатах вектори найближчих сусідів мають вигляд:

```
δ₁ = (0,  a_{C-C})
δ₂ = (a_{C-C} · √3 / 2,  -a_{C-C} / 2)
δ₃ = (-a_{C-C} · √3 / 2, -a_{C-C} / 2)
```

де `a_{C-C} ≈ 0.142 нм` — відстань між атомами вуглецю.

Підставляючи координати `δ_m` у вираз для `H_AB(k)`, отримуємо комплекснозначну функцію перескоку `f(k)`:

```
f(k) = -t · [ e^{i·k_y·a_{C-C}} + 2 · e^{-i·k_y·a_{C-C}/2} · cos(k_x·a_{C-C}·√3 / 2) ]
```

Власні значення енергії `E(k)` отримуються з розв'язку секулярного рівняння `det(H(k) - E·I) = 0`:

```
E(k) = ± |f(k)| = ± √ [ Re(f(k))² + Im(f(k))² ]
```

Для аналізу електронного спектра обчислення здійснюють уздовж замкненого контуру у двовимірній зоні Бріллюена, що з'єднує високосиметричні точки:
1. **Точка `Γ` (Гамма, `k = (0, 0)`):** Центр зони Бріллюена, де перекриття хвильових функцій є максимальним.
2. **Точка `K` (Точка Дірака, `k = (2·π / (3·a_{C-C}·√3), 2·π / (3·a_{C-C}))`):** Вершина гексагональної зони Бріллюена, де `f(k) = 0`, і валентна зона доторкається до зони провідності.
3. **Точка `M` (`k = (0, 2·π / (3·a_{C-C}))`):** Середина межі зони Бріллюена між двома сусідніми точками `K`.

```
        [ Точка Γ (0, 0) ]
              ↓  (Сегмент 1: Γ → K, розгортання конуса Дірака)
        [ Точка K (Dirac Point) ]
              ↓  (Сегмент 2: K → M, край забороненої зони)
        [ Точка M (Edge of BZ) ]
              ↓  (Сегмент 3: M → Γ, закриття контуру)
        [ Точка Γ (0, 0) ]
```

```py
import math

class GrapheneBandSimulator:
    """
    Клас для обчислення зонної структури графена методом сильного зв'язку (Tight-Binding).
    """
    def __init__(self, bond_length=0.142, hopping_integral=2.7):
        self.a_cc = bond_length  # Відстань між атомами C-C у нанометрах
        self.t = hopping_integral # Інтеграл перескоку найближчих сусідів у еВ

    def get_high_symmetry_points(self):
        """
        Повертає координати високосиметричних точок Gamma, K, M у k-просторі (1/нм).
        """
        pi = math.pi
        a_cc = self.a_cc

        gamma = (0.0, 0.0)
        k_point = (2.0 * pi / (3.0 * a_cc * math.sqrt(3.0)), 2.0 * pi / (3.0 * a_cc))
        m_point = (0.0, 2.0 * pi / (3.0 * a_cc))

        return gamma, k_point, m_point

    def interpolate_path(self, p1, p2, num_steps):
        """
        Лінійна інтерполяція між двома точками у k-просторі.
        """
        points = []
        for i in range(num_steps):
            alpha = i / float(num_steps)
            kx = p1[0] + alpha * (p2[0] - p1[0])
            ky = p1[1] + alpha * (p2[1] - p1[1])
            points.append((kx, ky))
        return points

    def compute_energy_at_k(self, kx, ky):
        """
        Обчислення комплексного структурного фактора f(k) та власних значень енергії.
        """
        a_cc = self.a_cc
        t = self.t

        # Фазові аргументи експонент
        arg1 = ky * a_cc
        arg2 = -ky * a_cc / 2.0
        arg3 = kx * a_cc * math.sqrt(3.0) / 2.0

        # Дійсна та уявна частини функції перескоку f(k)
        re_f = -t * (math.cos(arg1) + 2.0 * math.cos(arg2) * math.cos(arg3))
        im_f = -t * (math.sin(arg1) + 2.0 * math.sin(arg2) * math.cos(arg3))

        mod_f = math.sqrt(re_f * re_f + im_f * im_f)

        e_valence = -mod_f    # Зона pi (валентна)
        e_conduction = +mod_f # Зона pi* (провідність)

        return e_valence, e_conduction

    def run_simulation(self, steps_per_segment=100):
        """
        Запуск повного розрахунку уздовж контуру Gamma -> K -> M -> Gamma.
        """
        gamma, k_pt, m_pt = self.get_high_symmetry_points()

        path_gk = self.interpolate_path(gamma, k_pt, steps_per_segment)
        path_km = self.interpolate_path(k_pt, m_pt, steps_per_segment)
        path_mg = self.interpolate_path(m_pt, gamma, steps_per_segment)

        full_k_path = path_gk + path_km + path_mg
        band_data = []

        for kx, ky in full_k_path:
            e_v, e_c = self.compute_energy_at_k(kx, ky)
            band_data.append({'kx': kx, 'ky': ky, 'e_val': e_v, 'e_con': e_c})

        return band_data

if __name__ == "__main__":
    sim = GrapheneBandSimulator(bond_length=0.142, hopping_integral=2.7)
    results = sim.run_simulation(steps_per_segment=50)

    print(f"Розрахунок завершено. Отримано {len(results)} точок зонного спектра.")
    print("Аналіз характерних точок:")
    print(f"  1. Точка Gamma (k=0): E_val = {results[0]['e_val']:.4f} eV, E_con = {results[0]['e_con']:.4f} eV")
    print(f"  2. Точка K (Dirac):   E_val = {results[50]['e_val']:.4f} eV, E_con = {results[50]['e_con']:.4f} eV")
    print(f"  3. Точка M:           E_val = {results[100]['e_val']:.4f} eV, E_con = {results[100]['e_con']:.4f} eV")
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <complex>
#include <iomanip>
#include <utility>

struct BandState {
    double kx;
    double ky;
    double energy_valence;
    double energy_conduction;
};

class GrapheneTightBindingCalculator {
private:
    double a_cc; // Довжина ковалентного зв'язку C-C (нм)
    double t;    // Інтеграл перескоку найближчих сусідів (еВ)

public:
    explicit GrapheneTightBindingCalculator(double bond_len = 0.142, double hopping = 2.7)
        : a_cc(bond_len), t(hopping) {}

    std::pair<double, double> compute_band_energies(double kx, double ky) const {
        using namespace std::complex_literals;

        std::complex<double> phase1(0.0, ky * a_cc);
        std::complex<double> phase2(0.0, -ky * a_cc / 2.0);
        double cos_factor = std::cos(kx * a_cc * std::sqrt(3.0) / 2.0);

        // Комплексна функція перескоку f(k)
        std::complex<double> f_k = -t * (std::exp(phase1) + 2.0 * std::exp(phase2) * cos_factor);
        double energy_magnitude = std::abs(f_k);

        return {-energy_magnitude, +energy_magnitude};
    }

    std::vector<BandState> calculate_brillouin_path(std::size_t steps_per_segment) const {
        const double pi = std::acos(-1.0);

        const std::pair<double, double> gamma{0.0, 0.0};
        const std::pair<double, double> k_point{2.0 * pi / (3.0 * a_cc * std::sqrt(3.0)), 2.0 * pi / (3.0 * a_cc)};
        const std::pair<double, double> m_point{0.0, 2.0 * pi / (3.0 * a_cc)};

        std::vector<BandState> path_data;
        path_data.reserve(steps_per_segment * 3);

        auto append_segment = [this, steps_per_segment, &path_data](auto p_start, auto p_end) {
            for (std::size_t i = 0; i < steps_per_segment; ++i) {
                double alpha = static_cast<double>(i) / static_cast<double>(steps_per_segment);
                double kx = p_start.first + alpha * (p_end.first - p_start.first);
                double ky = p_start.second + alpha * (p_end.second - p_start.second);

                auto [e_v, e_c] = this->compute_band_energies(kx, ky);
                path_data.push_back({kx, ky, e_v, e_c});
            }
        };

        append_segment(gamma, k_point);
        append_segment(k_point, m_point);
        append_segment(m_point, gamma);

        return path_data;
    }
};

int main() {
    GrapheneTightBindingCalculator calculator(0.142, 2.7);
    const std::size_t resolution = 100;
    auto band_structure = calculator.calculate_brillouin_path(resolution);

    std::cout << std::fixed << std::setprecision(5);
    std::cout << "=========================================================\n";
    std::cout << "  РЕЗУЛЬТАТИ ОБЧИСЛЕННЯ ЗОННОЇ СТРУКТУРИ ГРАФЕНА (C++17) \n";
    std::cout << "=========================================================\n";
    std::cout << "Загальна кількість точок розрахунку: " << band_structure.size() << "\n\n";

    std::cout << "1. Точка Gamma (k = 0):\n";
    std::cout << "   E_val = " << band_structure[0].energy_valence 
              << " eV, E_con = " << band_structure[0].energy_conduction << " eV\n\n";

    std::cout << "2. Точка K (Конус Дірака):\n";
    std::cout << "   E_val = " << band_structure[resolution].energy_valence 
              << " eV, E_con = " << band_structure[resolution].energy_conduction << " eV\n\n";

    std::cout << "3. Точка M:\n";
    std::cout << "   E_val = " << band_structure[2 * resolution].energy_valence 
              << " eV, E_con = " << band_structure[2 * resolution].energy_conduction << " eV\n";

    return 0;
}
```

## 3. Глибокий аналіз результатів та чисельні крайові випадки

Аналіз обчислених енергетичних зон дає змогу зробити фундаментальні фізичні висновки щодо електронних властивостей матеріалу:

### 1. Максимальне розщеплення в точці `Γ`
У центрі зони Бріллюена (`k = 0`) усі три експоненціальні фазові множники перетворюються на одиницю `e^{i·k·δ_m} = 1`. Внаслідок цього функція перескоку набуває максимального значення `f(0) = -3·t`. 

Енергія валентної зони становить `E_π(0) = -3·t ≈ -8.1 еВ`, а зони провідності `E_{π*}(0) = +3·t ≈ +8.1 еВ`. Повна ширина `π`-зонного спектра графена дорівнює `W = 6·t ≈ 16.2 еВ`. Це свідчить про надзвичайно сильну де локалізацію `2pz`-електронів уздовж площини моношару.

### 2. Точка торкання (Конус Дірака) у точці `K`
У точці `K` фазові зсуви між трьома векторами `δ₁, δ₂, δ₃` утворюють кути `120°` (`2·π / 3`). Сума трьох одиничних векторів на комплексній площині строго дорівнює нулю:

```
f(K) = -t · [ 1 + e^{i · 2·π / 3} + e^{-i · 2·π / 3} ] = 0
```

Це означає, що енергетичний розрив між зонами перетворюється на нуль `E_{π*}(K) - E_π(K) = 0`. Система описується як безмасовий напівметал.

### 3. Точка сідла в точці `M`
У точці `M` значення функції перескоку становить `|f(M)| = t ≈ 2.7 еВ`. У цій точці похідні енергії по імпульсу задовольняють умову `∂²E / ∂k_x² > 0`, але `∂²E / ∂k_y² < 0`. Це створює сідлову точку на двовимірній поверхні `E(k_x, k_y)`.

В електронній густині станів `g(E)` сідлова точка `M` викликає появу сингулярності Ван Хова (на честь бельгійського фізика Леона Ван Хова) — логарифмічного піка густини станів при `E = ± t ≈ ± 2.7 еВ`.

## 4. Пастки дискретизації та методи їх подолання

При розробці чисельних симуляторів 2D матеріалів виникає серія типових алгоритмічних пасток:

1. **Фальшива заборонена зона через похибку дискретизації сітки:**
   Оскільки швидкість Фермі у точці Дірака дуже висока (`v_F ≈ 10⁶ м/с`), навіть незначне відхилення обчисленої координати `k` від точного положення точки `K` на величину `Δk ≈ 0.001 1/нм` призводить до фальшивого розщеплення зон на величину:
   ```
   ΔE = 2 · ℏ · v_F · Δk ≈ 2 · 0.658 eV·nm · 0.001 nm⁻¹ ≈ 1.3 meV
   ```
   Щоб уникнути появи штучної забороненої зони, координати високосиметричних точок `K` повинні обчислюватися з використанням точності `double` (64 біти) або `long double`.

2. **Врахування перескоків другого порядку `t'` (Second-Nearest Neighbor Hopping):**
   При врахуванні тунелювання між однаковими підґратками `A → A` та `B → B` з інтегралом перескоку `t' ≈ 0.1·t ≈ 0.27 еВ` порушується симетрія між валентною зоною та зоною провідності:
   ```
   E(k) = ± |f(k)| - t' · |f(k)|² / t
   ```
   Це зміщує точку Дірака по енергії та робить валентну зону асиметричною відносно зони провідності, що критично враховувати при високих рівнях легування.

## 5. Узагальнення на триорбітальну модель дихалькогенідів (TMD)

Для обчислення зонного спектра прямозонних напівпровідникових моношарів TMD (наприклад, `MoS₂` або `WSe₂`) двоорбітальної моделі графена недостатньо. Зонну структуру моношару `MoS₂` поблизу точок `K` та `K'` описують у рамках триорбітальної моделі сильного зв'язку, яка включає три валентні `d`-орбіталі атома молібдену: `d_{z²}`, `d_{xy}` та `d_{x²-y²}`.

Матричний Гамільтоніан TMD у базисі `( d_{z²}, d_{xy}, d_{x²-y²} )` має розмірність `3 × 3`:

```
H_TMD(k) = [[ H_11(k),  H_12(k),  H_13(k) ]
            [ H_12*(k), H_22(k),  H_23(k) ]
            [ H_13*(k), H_23*(k), H_33(k) ]]
```

Диагональний елемент `H_11(k)` визначає дно зони провідності, яке формується переважно `d_{z²}`-орбіталями атома металу, а елементи `H_22` та `H_33` описують розщеплену валентну зону.

У поєднанні зі спін-орбітальним взаємодією `H_SOC = λ_SOC · L · S` Гамільтоніан подвоює розмірність до `6 × 6`, відтворюючи спінове розщеплення валентної зони `ΔE_SOC ≈ 150 меВ` у точці `K`.

Порівняння обчислених зонних структур із першопринципними розрахунками методу функціонала густини (DFT — Density Functional Theory у наближенні GGA-PBE) показує, що модель сильного зв'язку з точністю до `2–5%` відтворює ефективні маси носіїв `m_e* ≈ 0.45 · m_0` та `m_h* ≈ 0.54 · m_0` для моношару `MoS₂`.
