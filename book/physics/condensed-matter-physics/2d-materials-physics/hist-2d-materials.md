# 📜 Історія відкриття двовимірних кристалів та парадокс Мерміна — Вагнера

Протягом майже сімдесяти років фізик-теоретики вважали створення вільних двовимірних кристалів товщиною в один атом принципово неможливим з точки зору фундаментальної термодинаміки. Теоретична заборона Ландау, Паєрлса, Мерміна та Вагнера тривалий час стримувала експерименти у фізиці конденсованого стану, аж поки мікромеханічне розщеплення 2004 року не довело можливість існування метастабільних 2D решіток завдяки мікроскопічним деформаціям згину.

## 1. Теоретична заборона: від Ландау та Паєрлса до теореми Мерміна — Вагнера

Витоки теоретичного сумніву щодо існування 2D кристалів сягають 1930-х років. У 1935 році видатний фізик Лев Ландау у праці про фазові переходи другого роду довів, що термодинамічні флуктуації в двовимірній решітці знищують далекий трансляційний порядок. Незалежно від нього Рудольф Паєрлс (від німецького *Peierls*) показав, що теплові коливання атомів у двовимірному ланцюжку або площині роблять крісталічні решітки нестабільними при будь-якій температурі `T > 0`.

Фізичний механізм цієї нестабільності полягає у специфічній поведінці довгохвильових акустичних фононів у просторі пониженої розмірності. Розглянемо флуктуацію зміщення атома `u(r)` від його рівноважного положення у двовимірній решітці. У гармонічному наближенні середня квадратична амплітуда зміщень `⟨u²⟩` обчислюється шляхом інтегрування за всіма дозволеними фононними хвильовими векторами `k` у зоні Бріллюена:

```
⟨u²⟩ = (k_B · T / (2 · π · C)) · ∫_{k_min}^{k_max} (1 / k) · dk
```

де `C` — двовимірний модуль пружності зсуву, `k_max = 2·π / a` визначається сталою ґратки `a`, а `k_min = 2·π / L` визначається макроскопічним розміром кристала `L`.

Виконуючи інтегрування, отримуємо логарифмічну залежність середня квадратичного зміщення атомів від розміру кристала `L`:

```
⟨u²⟩ = (k_B · T / (2 · π · C)) · ln( L / a )
```

У граничному переході до термодинамічної межі для макроскопічного зразка `L → ∞` логарифм необмежено зростає `ln(L / a) → ∞`. Це означає, що при будь-якій температурі `T > 0` амплітуда теплових коливань атомів `⟨u²⟩` перевищує міжатомну відстань `a`. Згідно з критерієм плавлення Ліндемана (від імені німецького фізика Фредеріка Ліндемана), коли зміщення `√⟨u²⟩` досягає `10–15%` від сталої ґратки, кристал неминуче плавиться. Таким чином, теорема передбачала, що вільна двовимірна решітка повинна миттєво розпадатися або згортатися у краплі.

У 1966 році Нейтан Мермін та Герберт Вагнер (N. D. Mermin, H. Wagner) надали цьому виводу суворого математичного статусу у формі теореми про відсутність спонтанного порушення неперервної симетрії у системі з короткосяжною взаємодією при розмірності `d ≤ 2`. Теорема Мерміна — Вагнера стверджувала, що у двовимірних системах не можуть існувати ні далекий кристалічний порядок, ні спонтанний феромагнетизм при `T > 0`, оскільки безмасові Ґолдстоунівські збудження (від імені американського фізика Джеффрі Голдстоуна) руйнують впорядкований стан.

Пізніше Вадим Березинський, Майкл Костерліц та Девід Таулесс (Berezinskii-Kosterlitz-Thouless, BKT-перехід) уточнили, що у 2D можливий особливий «квазідалекий порядок» (Квазі-довгосяжний порядок), де кореляційна функція спадає не експоненціально, а за степеневим законом, проте ідеальний двовимірний кристал усе одно вважався гіпотетичною абстракцією.

```
[Теоретична модель Ландау — Паєрлса (1935)]
       ↓  (Логарифмічна розбіжність фононних флуктуацій ⟨u²⟩ ∝ ln(L/a))
[Теорема Мерміна — Вагнера (1966)]
       ↓  (Заборона далекого трансляційного порядку у 2D при T > 0)
[Загальне переконання фізиків (1966–2004)]
       ↓  («2D кристали принципово нестабільні та не існують»)
[Експеримент Гейма та Новосьолова (2004)]
       ↓  (Відкриття стабільного моношару графена)
[Фізика позаплощинних деформацій згину (2007)]
       ↓  (Стабілізація решітки ZA-фононами та мікрохвилями)
```

## 2. Від епитаксії до клейкої стрічки: експериментальний прорив 2004 року

Упродовж другої половини XX століття вчені неодноразово намагалися синтезувати тонкі атомарні шари методом гетероепітаксії (молекулярно-променевої епітаксії MBE або хімічного осадження з газової фази CVD) на тривимірних металевих чи напівпровідникових підкладках. Проте ці плівки завжди залишалися міцно зв'язаними з об'ємною підкладкою ковалентними чи іонними зв'язками і втрачали прибудинкові двовимірні властивості через напруження ґратки (Lattice Strain).

Революційний прорив відбувся у 2004 році в Лабораторії високих магнітних полів Манчестерського університету. Андрій Гейм та Костянтин Новосьолово у рамках так званих «експериментів п'ятничного вечора» (Friday night experiments) досліджували електричні властивості тонких вуглецевих плівок.

Замість складного коштовного обладнання вони застосували метод мікромеханічного розщеплення (micromechanical cleavage), відомий як «метод клейкої стрічки» (Scotch tape method):
1. Високоорієнтований піролітичний графіт (HOPG) закріплювався на полімерній клейкій стрічці.
2. Багаторазове притискання та розклеювання стрічки розділяло шар графіту на все тонші лусочки, розриваючи слабкі міжшарові вандерваальсові зв'язки.
3. Отримані атомарно тонкі пластинки притискалися до кремнієвої підкладки `Si` з окисленим шаром діоксиду кремнію `SiO₂` товщиною строго `300 нм`.

Вибір товщини оксиду `300 нм` виявився вирішальним. Моношаровий графен товщиною всього `0.335 нм` абсолютно прозорий для світла (поглинає лише `2.3%` падаючого випромінювання). Проте за рахунок ефекту оптичної інтерференції у тришаровій системі «вакуум — графен — SiO₂ — Si» моношар створював слабкий фіолетово-синій оптичний контраст (близько `1.5%`), що дало змогу легко знаходити моношарові лусочки під звичайним оптичним мікроскопом.

```
[Початковий кристал графіту]
       ↓  (Мікромеханічне розщеплення клейкою стрічкою)
[Багатошарові лусочки на стрічці]
       ↓  (Перенос на підкладку SiO₂ / Si)
[Моношаровий графен d = 0.335 нм]
```

## 3. Розв'язання парадоксу: як 2D кристал виживає у 3D просторі

Відкриття стабільного моношару графена при кімнатній температурі поставило перед теоретичною фізикою фундаментальне питання: чому експериментальний 2D кристал не розпадається під дією теореми Мерміна — Вагнера?

У 2007 році експерименти з просвічувальної електронної мікроскопії (TEM), проведені Жанісом Мейєром (Jannik Meyer) та Андрієм Геймом на підвішених моношарах графена, дало змогу розкрити фізичний механізм стабілізації.

З'ясувалося, що двовимірний кристал існує у тривимірному фізичному просторі. Це надає йому додатковий ступінь вільності — позаплощинні деформації згину (out-of-plane flexural phonons, або `ZA`-моди):

1. **Мікрохвилі (Ripples):** Вільний моношар графена самовільно утворює тривимірну атомарну хвилястість (риплі) з амплітудою близько `h ≈ 1 нм` та просторовим періодом `λ_r ≈ 10–25 нм`.
2. **Немодульований зв'язок деформацій:** Позаплощинні деформації згину `h(r)` нелінійно зв'язані з поздовжніми деформаціями розтягу `u(r)`. Інваріантний закон зв'язку тензора деформацій має вигляд:
   ```
   u_ij = (1 / 2) · [ (∂ u_i / ∂ x_j) + (∂ u_j / ∂ x_i) + (∂ h / ∂ x_i) · (∂ h / ∂ x_j) ]
   ```
3. **Ангармонічне самозміцнення:** Нелінійний член `(∂h/∂x_i)·(∂h/∂x_j)` призводить до того, що на великих просторових масштабах ефективний модуль зсуву та пружності зростає. Ангармонізм фононів затискає довгохвильові флуктуації `k → 0`, пригнічуючи логарифмічне зростання `⟨u²⟩` та стабілізуючи двовимірну решітку при `T > 0`.

Таким образом, графен виживає завдяки тому, що на мікроскопічному рівні він є не строго пласким, а хвилястим у третьому вимірі.

## 4. Еволюція родини 2D матеріалів та Нобелівське визнання

Після успіху з графеном метод мікромеханічного та хімічного розщеплення було поширено на інші шаруваті кристали:

- **Гексагональний нітрид бору (h-BN, 2005):** Ізолюючий 2D кристал із забороненою зоною `5.9 еВ`, який став основою для підкладок та диелектричних затворів.
- **Дихалькогеніди перехідних металів (TMD, 2010):** Група Андраша Кіша (Andras Kis) у Федеральній політехнічній школі Лозанни (EPFL) виділила моношар `MoS₂` та створила на його основі перший високоефективний 2D транзистор із відношенням струмів `I_ON / I_OFF > 10⁸`.
- **2D магніти та надпровідники (2017):** Відкриття двовимірного феромагнетизму у моношарах `CrI₃` та `Fe₃GeTe₂` продемонструвало, що анізотропія кристалічного поля дає змогу обійти теорему Мерміна — Вагнера і для спінових систем.

У 2010 році Андрію Гейму та Костянтину Новосьолову було присуджено Нобелівську премію з фізики «за новаторські експерименти з двовимірним матеріалом графеном». Це відкриття започаткувало нову еру у фізиці конденсованого стану речовини, перетворивши двовимірні матеріали на головний майданчик для дослідження квантових фазових переходів, релятивістських електронних явищ та атомарної наноелектроніки.
