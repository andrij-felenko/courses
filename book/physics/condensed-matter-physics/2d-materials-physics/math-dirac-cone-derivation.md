# 🧮 Математичний вивід конуса Дірака та фази Беррі у графені

Цей математичний додаток розгортає строгий алгебраїчний вивід безмасового релятивістського електронного спектра у двовимірній гексагональній ґратці графена. Розрахунок пояснює, як з двопідґраткового наближення сильного зв'язку (tight-binding model) виникають конуси Дірака, псевдоспінова симетрія, тунелювання Клейна, рівні Ландау та топологічна фаза Беррі, рівна `π`.

## 1. Геометрія ґратки та базисні вектори оберненого простору

Двовимірна ґратка графена складається з двох еквівалентних трикутних підґраток `A` та `B`, які зміщені одна відносно одної на вектор найближчих сусідів.

Примітивні вектори трансляції `a₁` та `a₂` у декартових координатах описуються виразами:

```
a₁ = (a / 2) · (√3, 3)
a₂ = (a / 2) · (-√3, 3)
```

де `a_{C-C} ≈ 0.142 нм` — відстань між найближчими атомами вуглецю, а `a = |a₁| = |a₂| = a_{C-C} · √3 ≈ 0.246 нм` — стала двовимірної ґратки.

Кожен атом підґратки `A` зв'язаний із трьома найближчими атомами підґратки `B` векторами `δ₁`, `δ₂`, `δ₃`:

```
δ₁ = (0, a_{C-C})
δ₂ = (a_{C-C} · √3 / 2, -a_{C-C} / 2)
δ₃ = (-a_{C-C} · √3 / 2, -a_{C-C} / 2)
```

Примітивні вектори оберненої ґратки `b₁` та `b₂`, що задовольняють умову `a_i · b_j = 2·π·δ_ij`, дорівнюють:

```
b₁ = ((2·π) / (a·√3),  (2·π) / (3·a))
b₂ = (-(2·π) / (a·√3), (2·π) / (3·a))
```

Шість вершин першої гексагональної зони Бріллюена розпадаються на дві нееквівалентні групи — точки `K` та `K'`, які не зв'язані вектором оберненої ґратки:

```
K  = ( (2·π) / (3·a_{C-C}·√3),  (2·π) / (3·a_{C-C}) )
K' = (-(2·π) / (3·a_{C-C}·√3),  (2·π) / (3·a_{C-C}) )
```

## 2. Гамільтоніан сильного зв'язку у виставі другого квантування

Розглянемо `π`-електрони, локалізовані на `2pz`-орбіталях атомів вуглецю. У наближенні найближчих сусідів оператор Гамільтона має вигляд:

```
H = -t · ∑ [ a_r^† · b_{r + δ} + b_{r + δ}^† · a_r ]
```

де `t ≈ 2.7 еВ` — інтеграл перескоку між найближчими орбіталями `A` та `B`, `a_r^†` (`a_r`) — оператор народження (знищення) електрона на вузлі `r` підґратки `A`, а `b_{r+δ}` — оператор на вузлі підґратки `B`.

Виконуючи перетворення Фур'є (на честь Жана-Батіста Фур'є) для операторів у k-простір:

```
a_r = (1 / √N) · ∑ e^{i · k · R_r} · a_k
b_r = (1 / √N) · ∑ e^{i · k · R_r} · b_k
```

Гамільтоніан зводиться до двокомпонентного блохівського базису `Ψ_k = (a_k, b_k)^T`:

```
H(k) = [[   0,   f(k) ]
        [ f*(k),   0  ]]
```

де комплекснозначна функція перескоку `f(k)` описується сумою трьох експоненціальних фазових множників:

```
f(k) = -t · [ e^{i · k · δ₁} + e^{i · k · δ₂} + e^{i · k · δ₃} ]
```

Раскриваючи скалярні добутки `k · δ_m`:

```
f(k) = -t · [ e^{i·k_y·a_{C-C}} + 2 · e^{-i·k_y·a_{C-C}/2} · cos( k_x · a_{C-C} · √3 / 2 ) ]
```

Характеристичне рівняння `det(H(k) - E·I) = 0` визначає власний енергетичний спектр:

```
E(k) = ± |f(k)| = ± √ [ Re(f(k))² + Im(f(k))² ]
```

де знак «+» відповідає розпушувальній `π*`-зоні провідності, а знак «−» — зв'язуючій `π`-валентній зоні.

## 3. Лінеаризація поблизу точки K: вивід Гамільтоніана Дірака — Вейля

Дослідимо поведінку спектра поблизу точки `K`. Покладемо хвильовий вектор `k = K + q`, де `q = (q_x, q_y)` — мале відхилення квазіімпульсу (`|q| « |K|`).

Розкладемо скалярні добутки `(K + q) · δ_m` у ряд Тейлора (на честь Брука Тейлора) до першого порядку по `q`:

1. Для першого вектора `δ₁ = (0, a_{C-C})`:
   ```
   (K + q) · δ₁ = K_y · a_{C-C} + q_y · a_{C-C} = (2·π / 3) + q_y · a_{C-C}
   ```
2. Для другого та третього векторів `δ₂, δ₃`:
   ```
   (K + q) · δ₂ = -(π / 3) + (q_x · √3 / 2 - q_y / 2) · a_{C-C}
   (K + q) · δ₃ = -(π / 3) + (-q_x · √3 / 2 - q_y / 2) · a_{C-C}
   ```

Підставляючи розклади експонент `e^{i·(θ₀ + Δθ)} ≈ e^{i·θ₀} · (1 + i·Δθ)` у вираз для `f(K + q)`:

```
f(K + q) ≈ -t · [ e^{i·2·π/3} · (1 + i·q_y·a_{C-C}) 
                + e^{-i·π/3} · (1 + i·a_{C-C}·(q_x·√3/2 - q_y/2)) 
                + e^{-i·π/3} · (1 + i·a_{C-C}·(-q_x·√3/2 - q_y/2)) ]
```

Використовуючи тотожність `1 + e^{i·2·π/3} + e^{-i·2·π/3} = 0` та групуючи доданки при `q_x` та `q_y`, отримуємо:

```
f(K + q) = (3 · t · a_{C-C} / 2) · (q_x - i·q_y) = ℏ · v_F · (q_x - i·q_y)
```

де швидкість Фермі `v_F` виражається через параметри ґратки:

```
v_F = (3 · t · a_{C-C}) / (2 · ℏ) ≈ 10⁶ м/с
```

Підставляючи розкладену функцію `f(K + q)` у матрицю Гамільтона `H(k)`, отримуємо двовимірний Гамільтоніан Дірака — Вейля для безмасових релятивістських ферміонів:

```
H_K(q) = ℏ · v_F · [[      0,      q_x - i·q_y ]
                    [ q_x + i·q_y,      0      ]]
= ℏ · v_F · ( σ_x · q_x + σ_y · q_y )
```

де `σ_x` та `σ_y` — матриці Паулі (на честь Вольфганга Паулі), що діють у квантовому просторі псевдоспіну двох підґраток `A` і `B`:

```
σ_x = [[0, 1], [1, 0]],       σ_y = [[0, -i], [i, 0]]
```

Модуль енергії дає строго лінійний конус Дірака:

```
E(q) = ± ℏ · v_F · |q| = ± ℏ · v_F · √(q_x² + q_y²)
```

Ефективна маса `m*`, визначена через кривину зони `1 / m* = (1 / ℏ²) · (∂²E / ∂q²)`, перетворюється на нуль `m* = 0`.

## 4. Псевдоспінові власні стани, спіральність та тунелювання Клейна

Власні вектори `|Ψ_±(q)⟩` Гамільтоніана `H_K(q)` являють собою двокомпонентні спінори у підґратковому просторі `(A, B)^T`:

```
|Ψ_±(q)⟩ = (1 / √2) · [[ 1 ], [ ± e^{i·θ_q} ]]
```

де `θ_q = arctan(q_y / q_x)` — полярний кут хвильового вектора `q` у 2D площині.

Оператор спіральності (Helicity) описується проекцією псевдоспіну на напрямок руху:

```
h = (1 / 2) · ( σ · q ) / |q|
```

Власні значення оператора спіральності дорівнюють `h = +1/2` для зони провідності (псевдоспін паралельний квазіімпульсу) та `h = -1/2` для валентної зони (псевдоспін антипаралельний квазіімпульсу).

Збереження спіральності призводить до ефекту тунелювання Клейна (на честь шведського фізика Оскара Клейна). Розглянемо проходження електрона через прямокутний потенціальний бар'єр висотою `V_0` та шириною `L`.

Хвильові функції у трьох областях мають вигляд:

```
[Область I (x < 0, E > 0)]:     |Ψ_I⟩  = (1 / √2) · [ [1], [e^{i·ϕ}] ] · e^{i·k_x·x + i·k_y·y} + r · (1 / √2) · [ [1], [-e^{-i·ϕ}] ] · e^{-i·k_x·x + i·k_y·y}
[Область II (0 < x < L, V_0 > E)]: |Ψ_II⟩ = A · [ [1], [-e^{i·θ}] ] · e^{i·q_x·x + i·k_y·y} + B · [ [1], [e^{-i·θ}] ] · e^{-i·q_x·x + i·k_y·y}
[Область III (x > L, E > 0)]:   |Ψ_III⟩ = t_tr · (1 / √2) · [ [1], [e^{i·ϕ}] ] · e^{i·k_x·x + i·k_y·y}
```

При нормальному падінні електрона (`ϕ = 0`, `k_y = 0`) кути рефракції також перетворюються на нуль (`θ = 0`). Зшивання двох компонентів спінора `Ψ_A` та `Ψ_B` на межах `x = 0` та `x = L` дає системний розв'язок:

```
r = 0,       |t_tr|² = 1.0
```

Це означає, що при нормальному падінні коефіцієнт прозорості бар'єра дорівнює строго `T_{Klein} = 1.0` при будь-якій висоті `V_0` та товщині `L`. Електрон не може відбитися назад, оскільки відбиття вимагало б зміни напрямку квазіімпульсу `q_x → -q_x` без зміни орієнтації псевдоспіну, що заборонено симетрією спіральності.

## 5. Топологічна фаза Беррі та аномальний квантовий ефект Холла

Розглянемо адіабатичний обхід точки Дірака `q = 0` по замкненому колу `C` радіуса `q_0` у k-просторі. При повній зміні кута `θ_q` від `0` до `2·π` власна хвильова функція `|Ψ_+(q)⟩` отримує додатковий топологічний фазовий набіг — фазу Беррі `γ_N` (на честь британського фізика Майкла Беррі).

Векторний потенціал Беррі (Berry Connection) `A(q)` обчислюється як:

```
A(q) = i · ⟨Ψ_+(q)| ∇_q |Ψ_+(q)⟩
```

Обчислюючи градієнт `∇_q` у полярних координатах `(q, θ_q)`:

```
∇_q = e_q · (∂ / ∂q) + e_θ · (1 / q) · (∂ / ∂θ_q)
```

Отримуємо:

```
A(q) = i · (1 / 2) · [ 1,  e^{-i·θ_q} ] · ( e_θ / q ) · [[ 0 ], [ i · e^{i·θ_q} ]]
= - (1 / (2·q)) · e_θ
```

Інтегруючи потенціал `A(q)` вздовж замкненого контуру `C`:

```
γ_N = ∮_C A(q) · dq = ∫₀^{2·π} ( - 1 / (2·q) ) · q · dθ_q = - π  ≡  π  (mod 2·π)
```

Топологічна фаза Беррі `γ_N = π` обумовлює аномальний квантовий ефект Холла у графені (на честь американського фізика Едвіна Холла). 

При накладанні квантуючого магнітного поля `B` перпендикулярно до моношару конус Дірака розпадається на дискретні рівні Ландау (на честь Лева Ландау):

```
E_N = sgn(N) · v_F · √( 2 · e · ℏ · B · |N| )      [N = 0, ±1, ±2, ...]
```

Наявність центрального рівня Ландау з `N = 0` при `E = 0` (який належить одночасно електронам і діркам) та фаза Беррі `π` призводять до напівцілого квантування холлівської провідності `σ_xy`:

```
σ_xy = ± 4 · (e² / h) · ( N + 1/2 )      [N ∈ ℕ_0]
```

де фактор 4 враховує двократне спінове та двократне долинне (`K, K'`) виродження. Напівціле зсунення `+1/2` є безпосереднім експериментальним доказом існування релятивістських ферміонів Дірака та фази Беррі `π` у двовимірному графені.

## 6. Врахування перескоків другого порядку t' та порушення електронно-діркової симетрії

У точніших розрахунках враховують тунельний перескок електронів між атомами однієї і тієї ж підґратки (`A → A` або `B → B`) на відстань `a = a_{C-C} · √3`. Інтеграл перескоку другого порядку становить `t' ≈ 0.1 · t ≈ 0.25–0.30 еВ`.

Гамільтоніан сильного зв'язку набуває модифікованого вигляду:

```
H(k) = [[  g(k),   f(k) ]
        [ f*(k),  g(k)  ]]
```

де діагональна функція `g(k)` описує перескоки другого порядку:

```
g(k) = -t' · ∑ e^{i · k · a_m}      [по m = 1..6]
= -2 · t' · [ cos(k_x·a_C-C·√3) + 2 · cos(k_x·a_C-C·√3 / 2) · cos(3·k_y·a_C-C / 2) ]
```

Власні значення енергії набувають асиметричного вигляду:

```
E_±(k) = g(k) ± |f(k)|
```

Врахування `t'` не відкриває заборонену зону у точці `K` (`|f(K)| = 0`), але зміщує енергетичне положення точок Дірака на величину `E(K) = +3·t'`, порушуючи ідеальну симетрію між валентною зоною та зоною провідності.
