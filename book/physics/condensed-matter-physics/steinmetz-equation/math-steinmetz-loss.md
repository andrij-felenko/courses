# 🧮 Математичний вивід та поділ втрат у магнітному сердечнику

Ця вставка містить виводи фундаментальних математичних співвідношень для втрат у магнітом'яких матеріалах. Розглянуто аналітичний вивід вихрових втрат із рівнянь Максвелла, статистичну модель поділу втрат Джорджо Бертотті, урахування поверхневого ефекту (Skin Effect) в магнітопроводах, а також повний математичний вивід модифікованого коефіцієнта матеріалу `k_i` для покращеного рівняння Штейнмеця (iSE).

---

## 1. Повний вивід класичних вихрових втрат у тонких пластинах з рівнянь Максвелла

Розглянемо нескінченний плоский шар (пластину) магнітом'якого провідного матеріалу товщиною `d` уздовж осі `x` (де межі пластини знаходяться у точках `x = -d/2` та `x = +d/2`), шириною `w` вздовж осі `y` та довжиною `L` вздовж осі `z`. Припустимо, що товщина пластини значно менша за її інші розміри (`d « w, L`), що дозволяє знехтувати крайовими ефектами і вважати задачу одновимірною.

Магнітне поле `B(t)` спрямоване вздовж осі `z` і рівномірно змінюється в часі.

```
       z (Напрямок магнітного поля B_z)
       ^
       |     +-----------------------+
       |    /                       /|
       |   /                       / |  w (ширина)
       |  +-----------------------+  |
       |  |  . (x=0)              |  |
       |  | <--  d (товщина) -->  |  +
       +--|-----------------------|-----> x (напрямок товщини)
         /                         /
        /                         /  L (довжина)
       +-------------------------+
```

Для аналізу вихрових струмів запишемо другий закон Максвелла (закон електромагнітної індукції Фарадея в диференціальній формі):

```
∇ × E = - ∂B / ∂t
```

У векторній формі для виобраної геометрії, де магнітна індукція має лише компонент `B_z(x, t)`, а індуковане вихрове електричне поле має лише компонент `E_y(x, t)` (ортогонально до поля та координати товщини):

```
∂E_y / ∂x = - ∂B_z / ∂t
```

Оскільки геометрична структура є симетричною відносно центральної площини пластини `x = 0`, електричне поле в центрі дорівнює нулю через компенсацію протилежно спрямованих вихрових контурів: `E_y(0, t) = 0`.

Проінтегруємо диференціальне рівняння по координаті `x` від `0` до довільної точки `x`:

```
∫₀ˣ (∂E_y / ∂x') dx' = - ∫₀ˣ (∂B_z / ∂t) dx'
```

Припускаючи на даному етапі, що магнітне поле повністю і рівномірно проникає в товщу пластини (відсутній поверхневий ефект), похідна `∂B_z / ∂t` є константою по координаті `x`. Отже, інтегрування дає точний лінійний розподіл напруженості вихрового електричного поля по товщині пластини:

```
E_y(x, t) = - x · (dB_z / dt)
```

Цей результат показує, що напруженість вихрового електричного поля дорівнює нулю в центрі пластини і лінійно зростає до максимального значення `E_max = (d/2) · |dB/dt|` на зовнішніх поверхнях.

Згідно із законом Ома в диференціальній формі, густина вихрового струму `j_y(x, t)` у кожній точці дорівнює:

```
j_y(x, t) = E_y(x, t) / ρ = - (x / ρ) · (dB_z / dt)
```

де `ρ` — питомий електричний опір матеріалу (Ом·м).

Миттєва питома потужність джоулевих втрат на одиницю об'єму у шарі товщиною `dx` обчислюється як:

```
p_e(x, t) = j_y(x, t) · E_y(x, t) = (E_y(x, t))² / ρ = (x² / ρ) · (dB_z / dt)²
```

Щоб обчислити середню по всьому об'єму пластини питому потужність вихрових втрат `P_e(t)`, проінтегруємо `p_e(x, t)` по координаті `x` від одного краю пластини `-d/2` до іншого `+d/2` та поділимо на товщину `d`:

```
P_e(t) = (1 / d) · ∫₋d/2⁺d/2 (x² / ρ) · (dB_z / dt)² dx
       = (1 / (d · ρ)) · (dB_z / dt)² · [ x³ / 3 ]₋d/2⁺d/2
       = (1 / (d · ρ)) · (dB_z / dt)² · [ (d³/24) - (-d³/24) ]
       = (1 / (d · ρ)) · (dB_z / dt)² · (d³ / 12)
       = (d² / (12 · ρ)) · (dB_z / dt)²
```

Ця формула є фундаментальною: вона визначає миттєву питому потужність вихрових втрат для **довільної** часової форми магнітного поля `B(t)`.

### Випадок гармонічного (синусоїдального) поля
Для синусоїдальної індукції `B_z(t) = B_m · sin(2π f t)` знайдемо часову похідну:

```
dB_z / dt = 2π · f · B_m · cos(2π f t)
```

Піднесемо похідну до квадрата:

```
(dB_z / dt)² = 4 · π² · f² · B_m² · cos²(2π f t)
```

Усереднивши значення по періоду `T = 1/f` (враховуючи, що середнє значення квадрата косинуса `<cos²(θ)> = 1/2`):

```
<(dB_z / dt)²> = 2 · π² · f² · B_m²
```

Підставляючи середній квадрат похідної у вираз для `P_e(t)`, отримуємо класичну формулу вихрових втрат у пластинах для синусоїди:

```
P_e = (d² / (12 · ρ)) · (2 · π² · f² · B_m²)
    = (π² · d² / (6 · ρ)) · f² · B_m²   [Вт/м³]
```

Якщо необхідно виразити питомі втрати на одиницю маси (у Вт/кг), вираз ділять на густину речовини `γ` (кг/м³):

```
P_e_mass = (π² · d² / (6 · ρ · γ)) · f² · B_m²   [Вт/кг]
```

## 2. Поверхневий ефект (Skin Effect) у провідних магнітопроводах

Вищенаведений вивід базувався на припущенні, що вихрові струми не витісняють магнітне поле з товщі пластини і індукція `B_z` однакова по всьому перерізу. Це припущення справджується лише тоді, коли товщина пластини `d` значно менша за глибину проникнення електромагнітного поля (скіновський шар `δ`):

```
d « 2 · δ
```

Глибина скіновського шару у магнітопроводі визначається формулою:

```
δ = √( ρ / (π · f · μ_0 · μ_r) )
```

де `μ_0 = 4π · 10⁻⁷ Гн/м` — магнітна стала, а `μ_r` — відносна магнітна проникність сталі.

### Аналіз високочастотного обмеження
Якщо частота `f` зростає або товщина пластини `d` є великою (`d > 2δ`), вихрові струми за законом Ленца створюють власне протилежне магнітне поле, яке розмагнічує внутрішні шари пластини. Магнітний потік концентрується лише у вузьких приповерхневих шарах товщиною `δ`.

У цьому випадку формула вихрових втрат змінює свою частотну залежність:
- При low frequency (`d « δ`): втрати пропорційні квадрату частоти `P_e ∝ f²`.
- При high frequency (`d » δ`): через витіснення поля ефективна товщина провідного шару зменшується як `1/√f`, і залежність втрат від частоти стає кореневою `P_e ∝ f^1.5` або `P_e ∝ √f`.

Саме тому для високочастотних трансформаторів замість товстої сталі застосовують тонкі стрічки з аморфних сплавів (товщиною 15–25 мкм) або ферити з високим питомим опором, у яких скіновський шар `δ` перевищує розміри зерен навіть на частотах у кілька мегагерц.

## 3. Статистична теорія поділу втрат Бертотті

Італійський фізик Джорджо Бертотті розробив статистичну теорію перемагнічування, яка пояснює природу надлишкових втрат `P_exc`.

Згідно з теорією Бертотті, об'єм магнітопроводу містить певну кількість `N_0` активних центрів перемагнічування (доменних стінок). Під дією зовнішнього поля кількість динамічно активних стінок `N` зростає пропорційно швидкості зміни поля.

Загальне рівняння балансу потужності виражається сумою трьох доданків:

```
P_v = P_h + P_e + P_exc
```

де кожна компонента виражається через мікроскопічні параметри матеріалу:

1. **Гістерезисна компонента:**
   ```
   P_h = k_h · f · B_m^β
   ```
   де `k_h` визначається коефіцієнтом коерцитивності та щільністю потенційних ям (дефектів).

2. **Класична вихрова компонента:**
   ```
   P_e = k_e · f² · B_m²
   ```
   де `k_e = π² · d² / (6 · ρ · γ)`.

3. **Надлишкова компонента:**
   ```
   P_exc = √(8 · σ · G · S · V_0) · f^1.5 · B_m^1.5
   ```
   де `σ = 1/ρ` — провідність, `G = 0.1356` — безрозмірна внутрішня геометрична константа доменної структури, `S` — площа перерізу магнітопроводу, а `V_0` — статистичний параметр, що характеризує неоднорідність внутрішніх полів зачіпляння доменних стінок.

Цей математичний вивід пояснює фізичне походження дробового показника `1.5` для частоти та індукції в надлишковій компоненті втрат.

## 4. Аналітичний вивід матеріального коефіцієнта k_i для iSE

Згадаємо розширене покращене рівняння Штейнмеця (iSE) для обчислення втрат при несплавних сигналах:

```
P_v = (1 / T) · ∫₀ᵀ k_i · |dB(t) / dt|^α · |ΔB|^(β - α) dt
```

де `ΔB = 2 B_m` — розмах індукції за цикл, а `k_i` — коефіцієнт, який гарантує точний збіг результатів iSE та OSE на ідеальній синусоїді.

Здійснимо кроковий математичний вивід коефіцієнта `k_i`:

1. Візьмемо синусоїдальний сигнал `B(t) = B_m · sin(2π f t)`. Його часова похідна дорівнює `dB/dt = 2π f B_m cos(2π f t)`.

2. Підставимо `dB/dt` у формулу iSE:
   ```
   P_v = (1 / T) · ∫₀ᵀ k_i · |2π f B_m cos(2π f t)|^α · (2 B_m)^(β - α) dt
   ```

3. Винесемо константи за знак інтеграла:
   ```
   P_v = k_i · (2π f)^α · B_m^α · 2^(β - α) · B_m^(β - α) · [ (1 / T) · ∫₀ᵀ |cos(2π f t)|^α dt ]
   ```

4. Заміна змінної `θ = 2π f t` перетворює часовий інтеграл на кутовий по одному періоду від `0` до `2π`:
   ```
   (1 / T) · ∫₀ᵀ |cos(2π f t)|^α dt = (1 / 2π) · ∫₀²ᵖⁱ |cos θ|^α dθ
   ```

5. Зважаючи на симетрію функції `|cos θ|^α` у чотирьох квадрантах:
   ```
   ∫₀²ᵖⁱ |cos θ|^α dθ = 4 · ∫₀ᵖⁱ/² (cos θ)^α dθ
   ```

6. Табличний інтеграл для тригонометричних ступенів виражається через Бета-функцію Ейлера `B(x, y)`:
   ```
   ∫₀ᵖⁱ/² (cos θ)^α dθ = (1 / 2) · B( (α + 1) / 2,  1 / 2 )
   ```
   де Бета-функція пов'язана з Гамма-функцією співвідношенням `B(x, y) = Γ(x) · Γ(y) / Γ(x + y)`.

7. Отже, значення повного інтеграла по періоду дорівнює:
   ```
   ∫₀²ᵖⁱ |cos θ|^α dθ = 4 · (1 / 2) · B( (α + 1) / 2, 1 / 2 ) = 2 · B( (α + 1) / 2, 1 / 2 )
   ```

8. Підставляємо обчислений інтеграл у вираз для `P_v`:
   ```
   P_v = k_i · (2π)^α · f^α · 2^(β - α) · B_m^β · [ (1 / 2π) · 2 · B( (α + 1) / 2, 1 / 2 ) ]
       = k_i · f^α · B_m^β · [ (2π)^(α - 1) · 2^(β - α + 1) · B( (α + 1) / 2, 1 / 2 ) ]
   ```

9. Прирівнюємо отриманий вираз до класичного рівняння Штейнмеця `P_v = k · f^α · B_m^β`:
   ```
   k = k_i · (2π)^(α - 1) · 2^(β - α + 1) · B( (α + 1) / 2, 1 / 2 )
   ```

10. Виражаємо шуканий модифікований коефіцієнт `k_i`:
    ```
    k_i = k / [ (2π)^(α - 1) · 2^(β - α + 1) · B( (α + 1) / 2, 1 / 2 ) ]
    ```

Цей результат доводить, що коефіцієнт `k_i` в iSE є універсальною матеріальною константою, що аналітично обчислюється з базових параметрів `(k, α, β)` без проведення додаткових експериментів.
