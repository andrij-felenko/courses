# 🧮 Квазіімпульс, ефективна маса та динаміка валентної дірки

Цей матеріал містить строгий квантовомеханічний вивід динамічних характеристик незаповненого електронного стану (дірки) у валентній зоні напівпровідника. Вставка обґрунтовує еквівалентність між колективною динамікою ансамблю `N - 1` електронів та рухом окремої квазічастинки з додатним зарядом `+e`, додатною ефективною масою `m_h*` та хвильовим вектором `k_h = -k_e`.

## 1. Сумування квазіімпульсів та електричний струм зони

Розглянемо повністю заповнену енергетичну зону, яка містить `N` квантових станів. Кожен квантовий стан описується хвильовим вектором `k_i` та спіновим числом `s_i`. Оскільки зона Бріллюена є симетричною відносно інверсії координат `k → -k`, сума хвильових векторів по всіх заповнених станах повної зони строго дорівнює нулю:

```
K_full = ∑_{i=1}^{N} k_i = 0      [симетрія зони Бріллюена відносно інверсії]
```

Нехай один електрон видалено зі стану з хвильовим вектором `k_e` та енергією `E_e(k_e)`. Сумарний хвильовий вектор `K_total` решти `N - 1` електронів визначається відніманням вектора видаленого електрона від суми по всій зоні:

```
K_total = ∑_{i ≠ e} k_i
= ∑_{всі i} k_i - k_e              [додано та віднято стан k_e]
= K_full - k_e                     [використано K_full = 0]
= -k_e                             [сумарний квазіімпульс решти електронів]
```

Оскільки квазічастинка «дірка» репрезентує колективний рух решти електронів, її квазіімпульс `p_h` та хвильовий вектор `k_h` визначаються з умови збереження сумарного імпульсу системи:

```
k_h = K_total = -k_e               [хвильовий вектор дірки є протилежним до k_e]
```

Аналогічно обчислюється сумарний електричний струм, створюваний рештою `N - 1` електронів зони:

```
J_total = ∑_{i ≠ e} (-e) · v_i
= ∑_{всі i} (-e) · v_i - (-e) · v_e(k_e)    [додано та віднято струм видаленого електрона]
= J_full + e · v_e(k_e)                    [струм повністю заповненої зони J_full = 0]
= +e · v_e(k_e)                             [ефективний додатний струм]
```

Звідси випливає, що колективний струм решти електронів повністю еквівалентний струму однієї квазічастинки із зарядом `q_h = +e`, яка рухається зі швидкістю `v_h`:

```
J_total = q_h · v_h = +e · v_e(k_e)        [де q_h = +e та v_h = v_e]
```

## 2. Оператор інверсії часу та групова швидкість

У квантовій механіці оператор інверсії часу `T` є антиунітарним оператором, який діє на хвильову функцію за правилом `T ψ(r, t) = ψ*(r, -t)`. Для нерелятивістського Гамільтоніана кристала `H`, що не містить зовнішнього магнітного поля чи магнітного впорядкування, діє комутаційне співвідношення `[H, T] = 0`.

Якщо блохівська хвильова функція `ψ_{k,s}(r) = u_{k,s}(r) · exp(i k · r)` є власною функцією Гамільтоніана з енергією `E(k, s)`, то функція `T ψ_{k,s}(r) = u_{k,s}*(r) · exp(-i k · r)` є власною функцією з хвильовим вектором `-k` та тим самим значенням енергії. Це дає фундаментальну теорему Крамерса про парність дисперсійного співвідношення:

```
E_e(k, s) = E_e(-k, -s)                    [парність енергії відносно інверсії часу]
```

У центросиметричних кристалах (де є симетрія просторової інверсії `P`) енергетичні рівні є подвійно виродженими за спіном для кожного значення хвильового вектора: `E_e(k, ↑) = E_e(k, ↓)`.

Групова швидкість електронного хвильового пакета визначається як квантовомеханічна середня швидкість носія, тобто градієнт енергетичної функції `E(k)` у `k`-просторі:

```
v_e(k_e) = (1 / ħ) · ∇_k E_e(k_e)          [визначення групової швидкості електрона]
```

Власні значення енергії дірки `E_h(k_h)` відраховуються від вершини валентної зони `E_v` вниз у глибину зони:

```
E_h(k_h) = E_v - E_e(k_e)                  [відлік енергії дірки вниз від вершини зони]
```

Обчислимо групову швидкість дірки `v_h(k_h)` через градієнт її закону дисперсії:

```
v_h(k_h) = (1 / ħ) · ∇_{k_h} E_h(k_h)
= (1 / ħ) · ∇_{-k_e} (E_v - E_e(k_e))       [заміна k_h = -k_e та E_h = E_v - E_e]
= (1 / ħ) · (-1) · (-1) · ∇_{k_e} E_e(k_e)  [два мінуси при диференціюванні скорочуються]
= (1 / ħ) · ∇_{k_e} E_e(k_e)                [результат диференціювання]
= v_e(k_e)                                 [швидкість дірки дорівнює швидкості електрона]
```

Отже, напрямок групової швидкості дірки `v_h` строго збігається з напрямком групової швидкості відсутнього електрона `v_e`.

## 3. Трьохмірний тензор ефективної маси та гофрованість

Ефективна маса описує відгук носія на зовнішнє поле й у загальному трьохмірному випадку визначається тензором другої похідної закону дисперсії:

```
(1 / m_e*)_{ij} = (1 / ħ²) · (∂² E_e(k) / (∂ k_i ∂ k_j))    [тензор оберненої ефективної маси]
```

Розкладемо енергію електрона `E_e(k)` у ряд Тейлора поблизу максимуму валентної зони `k_v = 0`:

```
E_e(k) = E_v + (1/2) · ∑_{i,j} (∂² E_e / (∂ k_i ∂ k_j)) · k_i · k_j    [лінійні члени дорівнюють нулю у максимумі]
```

Оскільки у точці максимуму гладка функція має локальний екстремум, матриця других похідних (гесіан) є від'ємно визначеною. За визначенням від'ємної матриці, всі її власні значення є від'ємними числами:

```
∂² E_e(k) / ∂ k_i² < 0                     [умова максимуму на вершині валентної зони]
```

Це означає, що ефективна маса електрона на вершині валентної зони є строго від'ємною величиною вздовж усіх кристалографічних напрямків: `m_e* < 0`.

Обчислимо тензор ефективної маси дірки `m_h*` за допомогою її закону дисперсії `E_h(k_h) = E_v - E_e(k_e)` та підстановки `k_h = -k_e`:

```
(1 / m_h*)_{ij} = (1 / ħ²) · (∂² E_h(k_h) / (∂ k_{h,i} ∂ k_{h,j}))
= (1 / ħ²) · (∂² (E_v - E_e(k_e)) / (∂ (-k_{e,i}) ∂ (-k_{e,j})))    [заміна змінних]
= - (1 / ħ²) · (∂² E_e(k_e) / (∂ k_{e,i} ∂ k_{e,j}))                [мінус виноситься з чисельника]
= - (1 / m_e*)_{ij}                                                 [зв'язок між масами]
```

Оскільки для відсутнього електрона `m_e* < 0`, ефективна маса дірки `m_h*` стає строго додатною величиною вздовж усіх напрямків:

```
m_h* = -m_e* > 0                           [ефективна маса дірки завжди додатна]
```

У кубічних напівпровідниках зі структурою алмазу (Si, Ge) та сфалериту (GaAs) валентна зона утворюється з p-атомних орбіталей з орбітальним моментом `L = 1` та спіном `S = 1/2`. Ураховуючи спін-орбітальну взаємодію, закон дисперсії важких та легких дірок описується теорією Латтінджера-Кона (k·p метод):

```
E_h(k) = (ħ² / (2 m_0)) · [ A · k² ± √( B² · k⁴ + C² · (k_x² k_y² + k_y² k_z² + k_z² k_x²) ) ]
```

де `A`, `B`, `C` — безрозмірні параметри Латтінджера, а знаки `±` відповідають легким (знак `-`) та важким (знак `+`) діркам. Наявність додатка з параметром `C` показує, що поверхні постійної енергії дірок є не ідеальними сферами, а гофрованими еліпсоїдами.

## 4. Рівняння руху дірки у зовнішніх полях

Розглянемо дію зовнішнього електричного поля `E_ext` та магнітного поля `B` на незаповнений стан валентної зони. Згідно з теоремою Блоха, під дією сили Лоренца хвильовий вектор кожного електрона змінюється за рівнянням:

```
ħ · (d k_i / dt) = -e · (E_ext + v_i × B)  [рівняння руху Блоха для електрона]
```

Продиференціюємо сумарний хвильовий вектор решти електронів `K_total = -k_e` за часом:

```
ħ · (d K_total / dt) = -ħ · (d k_e / dt)
= - [ -e · (E_ext + v_e × B) ]             [підставили рівняння руху видаленого електрона]
= +e · (E_ext + v_e × B)                    [мінуси скоротилися]
```

Використовуючи тотожності `k_h = K_total`, `q_h = +e` та `v_h = v_e`, отримуємо фундаментальне рівняння Ньютона-Лоренца для квазіімпульсу дірки:

```
ħ · (d k_h / dt) = +e · (E_ext + v_h × B)   [динамічне рівняння руху дірки]
```

З урахуванням визначення додатної ефективної маси `m_h* > 0`, прискорення дірки `a_h = d v_h / dt` набуває стандарного класичного вигляду:

```
m_h* · a_h = +e · (E_ext + v_h × B)        [другий закон Ньютона для дірки]
```

Ця формула остаточно доводить, що квантовомеханічна вакансія у валентній зоні поводиться у зовнішніх полях як класична матеріальна точка з додатним зарядом `+e` та додатною масою `m_h*`.

## 5. Кінетичне рівняння Больцмана та провідність дірок

Макроскопічний опис транспорту дірок у напівпровіднику регулюється кінетичним рівнянням Больцмана для функції розподілу дірок `f_h(r, k, t)`. У наближенні часу релаксації `τ_p(E)` рівняння має вигляд:

```
∂f_h / ∂t + v_h · ∇_r f_h + (e / ħ) · (E_ext + v_h × B) · ∇_k f_h = - (f_h - f_0) / τ_p
```

де `f_0(E) = 1 / (1 + exp((E - E_F) / (k_B T)))` — рівноважна функція розподілу Фермі-Дірака.

У слабкому електричному полі `E_x` збурена функція розподілу виражається через першу поправку: `f_h = f_0 + e · τ_p · v_{h,x} · E_x · (-∂f_0 / ∂E)`.

Густина дрейфового струму дірок обчислюється шляхом інтегрування швидкості по всьому `k`-простору:

```
j_p = (e / (4 π³)) · ∫ v_h(k) · f_h(k) d³k
= (e² / (4 π³)) · E_x · ∫ v_{h,x}² · τ_p(E) · (-∂f_0 / ∂E) d³k    [підстановка f_h]
= p · e · μ_p · E_x                                                [визначення дрейфової провідності]
```

де концентрація дірок `p` та їхня середня дрейфова рухливість `μ_p` визначаються як:

```
p = (1 / (4 π³)) · ∫ f_0(E) d³k = N_v · exp(-(E_F - E_v) / (k_B T))

μ_p = e · <τ_p> / m_h*                                              [формула Друде для рухливості дірок]
```

Значення `<τ_p>` являє собою усереднений по енергії час релаксації імпульсу дірок при розсіюванні на акустичних фононах та іонізованих домішках.

## 6. Двозонна модель електропровідності та коефіцієнта Холла

У напівпровідниках зі змішаною провідністю струм створюється одночасно електронами зони провідності (концентрація `n`, рухливість `μ_n`) та дірками валентної зони (концентрація `p`, рухливість `μ_p`).

Густина дрейфового струму у слабкому електричному полі `E_x` дорівнює сумі електронного та діркового потоків:

```
j_x = j_n + j_p
= (-e) · n · v_{n,x} + (+e) · p · v_{p,x}   [заряди носіїв та швидкості]
= (-e) · n · (-μ_n · E_x) + e · p · (μ_p · E_x)    [v_{n,x} = -μ_n E_x, v_{p,x} = +μ_p E_x]
= e · (n · μ_n + p · μ_p) · E_x             [сумарна питома провідність]
```

Звідси повна питома електропровідність дорівнює: `σ = e · (n · μ_n + p · μ_p)`.

При прикладенні перпендикулярного магнітного поля `B_z` сумарне поперечне електричне поле Холла `E_y` визначається з умови відсутності поперечного струму `j_y = 0`:

```
j_y = σ_xy · E_x + σ_xx · E_y = 0           [умова рівноваги Холла]
```

Розв'язання рівнянь Boltzmann для кінетичного тензора провідності у слабкому магнітному полі з урахуванням холл-фактора носіїв `r_H = <τ²> / <τ>²` дає вираз для загального коефіцієнта Холла `R_H`:

```
R_H = E_y / (j_x · B_z)
= (r_H / e) · (p · μ_p² - n · μ_n²) / (p · μ_p + n · μ_n)²    [двозонна формула Холла]
```

З аналізу двозонної формули випливають важливі граничні випадки:

1. **Чистий p-напівпровідник (`p >> n`):**
   ```
   R_H = + r_H / (p · e) > 0               [коефіцієнт Холла строго додатний]
   ```

2. **Чистий n-напівпровідник (`n >> p`):**
   ```
   R_H = - r_H / (n · e) < 0               [коефіцієнт Холла строго від'ємний]
   ```

3. **Точка компенсації знака Холла (`R_H = 0`):**
   Коефіцієнт Холла звертається в нуль при співвідношенні концентрацій `p / n = (μ_n / μ_p)²`. Оскільки для більшості напівпровідників `μ_n > μ_p`, точка компенсації знака досягається при превалюванні концентрації дірок над електронами (`p > n`).

## 7. Квантова модель акцептора та перехід Мотта

Для повного математичного опису дірок у легованому p-напівпровіднику проаналізуємо квантовий стан дірки, зв'язаної з від'ємним іоном акцептора при низьких температурах. Гамільтоніан зв'язаної дірки у наближенні ефективної маси описується водневоподібним рівнянням Шредінгера:

```
[ - (ħ² / (2 m_h*)) · ∇² - (e² / (4 π ε ε_0 r)) ] ψ_h(r) = - ΔE_A · ψ_h(r)
```

Власні значення енергії іонізації `ΔE_A` та ефективний радіус Бора `r_B*` визначаються квантовомеханічним розв'язком:

```
ΔE_A = (m_h* · e⁴) / (32 π² ε² ε_0² ħ²) = E_H · (m_h* / m_0) / ε²

r_B* = (4 π ε ε_0 ħ²) / (m_h* · e²) = r_B · ε · (m_0 / m_h*)
```

При зростанні концентрації акцепторних домішок `N_A` середня відстань між домішковими іонами `d_A ≈ N_A^(-1/3)` зменшується. Коли потенціальні ями сусідніх акцепторів починають перекриватися, виникає квантовомеханічне тунелювання дірок між сусідніми іонами.

Критерій Мотта описує критичну концентрацію `N_c`, при якій відбувається метал-діелектричний перехід (зливання акцепторного рівня з валентною зоною):

```
N_c^(1/3) · r_B* ≈ 0.25                    [критерій переходу Мотта]
```

Для кремнію, легованого бором (`r_B* ≈ 1.5 nm`), критична концентрація становить `N_c ≈ 4.6 · 10^18 cm^-3`. При `N_A > N_c` напівпровідник переходить у вироджений стан, і дірки стають вільними носіями заряду за будь-яких придатних температур, аж до абсолютного нуля `T = 0 K`.

## 8. Статистична термодинаміка діркового газу та інтеграли Фермі

Для квантовомеханічного розрахунку концентрації дірок `p` у параболічній валентній зоні необхідно проінтегрувати добуток щільності квантових станів `g_v(E)` на ймовірність їхнього незаповнення електроном `1 - f_e(E)`:

```
g_v(E) = (1 / (2 π²)) · (2 m_h* / ħ²)^(3/2) · √(E_v - E)    [щільність станів валентної зони]

1 - f_e(E) = 1 / (1 + exp((E_F - E) / (k_B T)))              [ймовірність існування дірки]
```

Підставивши ці вирази в інтеграл по енергії від `-∞` до вершини зони `E_v`, отримуємо строгу формулу для концентрації дірок у вигляді інтеграла Фермі-Дірака півцілого індексу:

```
p = N_v · F_{1/2}(η_v)                     [де η_v = (E_v - E_F) / (k_B T)]
```

де `N_v = 2 (2 π m_h* k_B T / h²)^(3/2)` — ефективна щільність станів у валентній зоні, а інтеграл Фермі-Дірака визначається як:

```
F_{1/2}(η_v) = (2 / √π) · ∫_{0}^{∞} (√x / (1 + exp(x - η_v))) dx
```

Розглянемо два важливі граничні випадки для діркового газу:

1. **Невироджений газ дірок (`η_v << -2`, рівень Фермі у забороненій зоні):**
   Інтеграл Фермі асимптотично переходить в експоненту Максвелла-Больцмана: `F_{1/2}(η_v) ≈ exp(η_v)`.
   Концентрація дірок набуває класичного вигляду:

   ```
   p ≈ N_v · exp(-(E_F - E_v) / (k_B T))    [закон дійних мас для невироджених дірок]
   ```

2. **Сильно вироджений газ дірок (`η_v >> 2`, рівень Фермі у глибині валентної зони):**
   Використовуючи розклад Зоммерфельда при низьких температурах `T → 0 K`, маємо `F_{1/2}(η_v) ≈ (4 / (3 √π)) · η_v^(3/2)`.
   Концентрація дірок стає залежною лише від квазірівня Фермі `E_F` і не залежить від температури:

   ```
   p ≈ (1 / (3 π²)) · [ (2 m_h* (E_v - E_F)) / ħ² ]^(3/2)    [концентрація виродженого діркового газу]
   ```

Це пояснює, чому у сильнолегованих p-напівпровідниках провідність дірок залишається високою навіть при температурах рідкого гелію `4.2 K`.

## 9. Циклотронне квантування дірок у магнітному полі

При прикладенні сильного зовнішнього магнітного поля `B_z` орбітальний рух дірок у площині `XY`, перпендикулярній до поля, квантується. Неперервний трьохмірний закон дисперсії розпадається на дискретні еквідистантні рівні Ландау.

Гамільтоніан дірки у калібруванні Ландау `A = (-B_z · y, 0, 0)` набуває вигляду одновимірного гармонічного осцилятора для руху вздовж `Y`:

```
[ (1 / (2 m_h*)) · (p_x - e B_z y)² + (p_y² / (2 m_h*)) + (p_z² / (2 m_h*)) ] ψ = E · ψ
```

Власні значення енергії квантованих рівнів Ландау для дірки дорівнюють:

```
E_{n,k_z,s} = E_v - ħ ω_c · (n + 1/2) - (ħ² k_z² / (2 m_h*)) ± (1/2) g_h* μ_B B_z
```

де `n = 0, 1, 2, ...` — номер рівня Ландау, `ω_c = e B_z / m_h*` — циклотронна частота дірки, `g_h*` — ефективний g-фактор дірки у валентній зоні, а `μ_B = e ħ / (2 m_0)` — магнетон Бора.

Знак мінус перед `ħ ω_c` відображає відлік енергії дірки від вершини валентної зони вниз. Оскільки валентна зона складається із важких та легких дірок, у магнітному полі виникають дві серії рівнів Ландау з різними циклотронними частотами `ω_c,hh = e B_z / m_hh*` та `ω_c,lh = e B_z / m_lh*`.

Вимірювання частот резонансного НВЧ-поглинання між сусідніми рівнями Ландау `Δn = 1` при `ω = ω_c` забезпечує прямий метод точного експериментального визначення тензора ефективних мас дірок.

## 10. Математична теорія оптичного поглинання за участю дірок

Під час міжзонових оптичних переходів світловий фотон із частотою `ν` поглинається кристалом, переводячи електрон із валентної зони у зону провідності. З точки зору теорії квазічастинок виникає електронно-діркова пара.

Імовірність переходів за секунду в одиниці об'єму розраховується за золотим правилом Фермі:

```
W_{v→c} = (2 π / ħ) · |M_{vc}|² · δ(E_c(k) - E_v(k) - hν)
```

де `M_{vc} = (e A_0 / (2 m_0)) · <c, k| e_polar · p |v, k>` — матричний елемент оператора імпульсу між блохівськими станами зони провідності `c` та валентної зони `v`.

Для прямозонного напівпровідника з параболічними зонами різниця енергій електронно-діркової пари дорівнює:

```
E_c(k) - E_v(k) = E_g + (ħ² k² / (2 m_e*)) + (ħ² k² / (2 m_h*))
= E_g + (ħ² k² / (2 μ*))                     [де 1/μ* = 1/m_e* + 1/m_h* — зведена маса]
```

Підставивши зведену ефективну масу `μ* = (m_e* · m_h*) / (m_e* + m_h*)` в інтеграл по `k`-простору, отримуємо математичну формулу для коефіцієнта міжзонового оптичного поглинання `α(hν)`:

```
α(hν) = A_opt · (2 μ* / ħ²)^(3/2) · √(hν - E_g)    [для прямозонових оптичних переходів при hν >= E_g]
```

Цей результат показує, що спектр міжзонового поглинання прямо визначається зведеною масою електронно-діркової пари `μ*`. Оскільки для більшості напівпровідників `m_h* > m_e*`, зведена маса `μ*` близька до легшої маси електрона провідності `m_e*`, проте внесок дірки у щільність станів є вирішальним для розрахунку форми оптичного краю поглинання.

## 11. Квантовий аналіз розсіювання дірок та температурні залежності

Інтенсивність розсіювання дірок визначається ймовірністю квантових переходів між станами валентної зони під дією збурень `V_scat(r)`. У напівпровідниках дірки зазнають двох основних типів розсіювання:

1. **Розсіювання на акустичних фононах (деформаційний потенціал):**
   Коли кристал деформується фононом, зміщення атомів викликає модуляцію енергії вершини валентної зони `δ E_v = E_1v · div(u)`. Матричний елемент розсіювання прямо пропорційний деформаційному потенціалу валентної зони `E_1v`.
   Обрахований час релаксації імпульсу залежить від енергії дірки як `τ_ac(E) ∝ E^(-1/2) · T^(-1)`. Усереднення цієї залежності по функції розподілу Максвелла-Больцмана дає температурну залежність дрейфової рухливості дірок:

   ```
   μ_p,ac ∝ (m_h*)^(-5/2) · T^(-3/2)        [температурний закон розсіювання на фононах]
   ```

2. **Розсіювання на іонізованих акцепторних іонах:**
   Кулонівський потенціал нерухомого іона `B^-` екранується вільною електронно-дірковою плазмою за радіусом Дебая `r_D = √(ε ε_0 k_B T / (e² p))`. Згідно з класичною формулою Брукса-Херінга, переріз розсіювання дірки зменшується зі зростанням її енергії.
   Час релаксації імпульсу залежить від енергії як `τ_imp(E) ∝ E^(3/2) / N_A`. При низьких температурах розсіювання на домішках стає домінуючим, обумовлюючи зростання рухливості з температурою:

   ```
   μ_p,imp ∝ (m_h*)^(-1/2) · N_A^(-1) · T^(3/2)    [температурний закон розсіювання на іонах]
   ```

Комбінація двох механізмів розсіювання за правилом Маттіссена `1/μ_p = 1/μ_p,ac + 1/μ_p,imp` утворює куполоподібну графічну залежність `μ_p(T)` з максимумом при температурах близько `50–100 K`.

## 12. Математичний формалізм рекомбінації Шоклі-Ріда-Холла (SRH)

У практичних напівпровідникових приладах зникнення нерівноважних дірок відбувається переважно за участю глибоких глибоколежачих дефектів та пасток у забороненій зоні з енергією `E_t`. Цей процес описується теорією Шоклі-Ріда-Холла (SRH).

Швидкість захоплення дірки з валентної зони на негативно заряджену або нейтральну пастку пропорційна концентрації дірок `p` та концентрації заповнених пасток `N_t (1 - f_t)`:

```
r_p = C_p · p · N_t · (1 - f_t)            [де C_p — коефіцієнт захоплення дірки]
```

Зворотом є швидкість емісії дірки з пастки у валентну зону: `e_p = e_p_coeff · N_t · f_t`. З умови термодинамічної рівноваги обчислюється коефіцієнт емісії `e_p_coeff = C_p · p_1`, де `p_1 = N_v · exp(-(E_t - E_v) / (k_B T))` — приведена концентрація дірок, коли рівень Фермі збігається з рівнем пастки `E_F = E_t`.

У стаціонарному нерівноважному стані стаціонарна швидкість рекомбінації електронно-діркових пар `U_SRH` дорівнює:

```
U_SRH = (n · p - n_i²) / [ τ_p0 · (n + n_1) + τ_n0 · (p + p_1) ]
```

де `τ_p0 = 1 / (N_t C_p)` — мінімальний час життя дірок у напівпровіднику n-типу при високому рівнянні інжекції.

Ця формула має фундаментальне значення: у напівпровіднику n-типу (`n >> p`) час життя неосновних носіїв (дірок) вирівнюється до `τ_p0`. Вимірявши час життя нерівноважних дірок, можна безпосередньо визначити концентрацію рекомбінаційних дефектів `N_t` та переріз захоплення дірки `σ_p = C_p / v_th`.
