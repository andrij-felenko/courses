# ⚙️ Симуляція температурної компенсації та поліноміальний фітинг ТКО

При розробці високоточних вимірювальних систем струму, промислових контролерів керування тяговими батареями електромобілів (BMS) та еталонів опору інженерам необхідно моделювати тепловий розгін шунта під навантаженням та обчислювати фактичний температурний коефіцієнт опору (ТКО) за виміряними експериментальними точками.

Безпосереднє вимірювання струму силою у кілька сотень ампер за допомогою невикаліброваного шунта призводить до виникнення системних похибок. Коли крізь прецизійний провідник протікає великий струм, виділення джоулевого тепла викликає нелінійне підвищення температури активного елемента. Це нагрівання змінює опір шунта, створюючи зворотний зв'язок між електричним струмом, тепловиділенням та коефіцієнтом передачі вимірювального каналу.

Чисельне моделювання дозволяє оцінити тепловий опір охолодження, розрахувати диференціальний зсув опору та здійснити програмну компенсацію виміряного спаду напруги у реальному часі на основі апроксимації параболічної залежності манганіну або тригонометричного/поліноміального плато сплаву Карма.

## 1. Математичний апарат МНК-апроксимації параболічної характеристики ТКО

Для прецизійних сплавів (таких як манганін, ізабеллін та зеранін) залежність електричного опору від температури у діапазоні від `-40 °C` до `+100 °C` описується параболічним поліномом другого порядку:

```
R(T) = R_0 · [1 + α_0 · (T - T_ref) + β · (T - T_ref)²]
```

де `T_ref = 20 °C` — стандартизована референтна температура.

При розробці прецизійного вимірювального приладу на етапі фабричного калібрування резистор або шунт вміщують у термокамеру та знімають серію з `N` дискретних вимірювань `(T_i, R_i)` при різних температурах довкілля. Завдання фітингу полягає у визначенні триплета оптимальних параметрів `(R_0, α_0, β)`, які мінімізують середньоквадратичне відхилення експериментальних точок від теоретичної параболи.

Для обчислення коефіцієнтів застосовують метод найменших квадратів (МНК). Здійснюється заміна змінних `x_i = T_i - T_ref` та `y_i = R_i`. Теоретичне рівняння набирає вигляду лінійної комбінації трьох параметрів `a_0`, `a_1` та `a_2`:

```
y(x) = a_0 + a_1 · x + a_2 · x²
```

де шукані фізичні параметри пов'язані з коефіцієнтами розкладу співвідношеннями:

```
a_0 = R_0
a_1 = R_0 · α_0
a_2 = R_0 · β
```

Мінімізація функціонала квадратичної помилки `S(a_0, a_1, a_2) = ∑ (y_i - a_0 - a_1 · x_i - a_2 · x_i²)²` попрямовує до системи трьох нормальних лінійних алгебраїчних рівнянь відносно шуканого вектора `a`:

```
S_0 · a_0 + S_1 · a_1 + S_2 · a_2 = Y_0
S_1 · a_0 + S_2 · a_1 + S_3 · a_2 = Y_1
S_2 · a_0 + S_3 · a_1 + S_4 · a_2 = Y_2
```

Коефіцієнти матриці нормальних рівнянь являють собою суми степенів центрованої температури `x_i`:

```
S_k = ∑ (x_i)^k   (для k = 0, 1, 2, 3, 4)
```

А вектор правих частин `Y` утворюється сумами добутків виміряного опору на степені температури:

```
Y_k = ∑ (y_i) · (x_i)^k   (для k = 0, 1, 2)
```

Розв'язання цієї системи здійснюється точним методом Крамера або методом LU-розкладу. Визначник головної матриці системи `Det` обчислюється як:

```
Det = S_0 · (S_2 · S_4 - S_3²) - S_1 · (S_1 · S_4 - S_2 · S_3) + S_2 · (S_1 · S_3 - S_2²)
```

Якщо визначник ненульовий (`Det ≠ 0`), значення коефіцієнтів знаходять через відповідні додаткові визначники `Det_a0`, `Det_a1` та `Det_a2`. Після обчислення коефіцієнтів розкладу відновлюють фундаментальні характеристики прецизійного сплаву:
- Базовий опір при референтній температурі: `R_0 = a_0`;
- Лінійний температурний коефіцієнт: `α_0 = a_1 / a_0`;
- Квадратичний температурний коефіцієнт: `β = a_2 / a_0`;
- Температура вершини параболи (точки екстремуму `dR / dT = 0`): `T_peak = T_ref - α_0 / (2 · β)`.

Знання точки `T_peak` має критичне значення для метрологічної оцінки. Якщо вершина параболи лежить у межах робочого діапазону приладу (наприклад, `T_peak = 22.5 °C`), то ТКО у найважливішій зоні кімнатних температур є мінімальним і змінює знак, що забезпечує найвищу точність вимірювання.

## 2. Фізична модель динаміки теплового розгону та самонагріву шунта

У силових вимірювальних колах струмовий шунт перебуває у постійній взаємодії з навколишнім середовищем. Проходження постійного або змінного струму `I(t)` викликає джоулеве тепловидилення з миттєвою потужністю `P_joule(t) = I(t)² · R(T)`.

Динаміка зміни температури активного манганінового елемента шунта `T_shunt(t)` описується диференціальним рівнянням першого порядку теплового балансу Fourier:

```
C_th · (dT_shunt / dt) = P_joule(t) - (T_shunt - T_ambient) / R_th
```

де:
- `C_th` — повна теплоємність металевої пластини шунта та прилеглих струмових блоків, Дж/К;
- `R_th` — еквівалентний тепловий опір відведення тепла у довкілля за рахунок конвекції та випромінювання, К/Вт;
- `T_ambient` — температура навколишнього повітря або охолоджувача, °C.

У стаціонарному усталеному режимі (`dT_shunt / dt = 0`) температура шунта досягає рівноважного значення `T_eq`, яке задовольняє нелінійне алгебраїчне рівняння:

```
T_eq = T_ambient + R_th · I² · R(T_eq)
```

Оскільки опір `R(T_eq)` сам залежить від температури, точний розрахунок стаціонарного стану вимагає ітераційного розв'язання. У симуляторі застосовується метод простої ітерації або метод Ньютона — Рафсона. Ітераційний процес починається з початкового наближення `T^(0) = T_ambient`. На кожному `k`-му кроці обчислюється поточне значення опору `R^(k) = calculate_resistance(T^(k))`, після чого розраховується нове наближення температури:

```
T^(k+1) = T_ambient + R_th · I² · R^(k)
```

Для стабільних матеріалів із малим ТКО ітераційний процес збігається всього за 3–5 кроків із високою точністю (`|T^(k+1) - T^(k)| < 10⁻⁶ °C`).

Однак, якщо матеріал має великий позитивний ТКО (наприклад, мідь), при перевищенні критичного струму виникає ефект **теплового розгону** (thermal runaway): зростання температури збільшує опір, що підвищує виділення потужності та викликає подальше необмежене нагрівання до розплавлення або спрацьовування теплового захисту.

Для манганінових шунтів від'ємний квадратичний ТКО `β < 0` діє як природний обмежувач: при високих температурах опір починає зменшуватися, що стабілізує тепловий режим приладу.

## 3. Програмна реалізація симулятора та фітера ТКО

Нижче наведено повну реалізацію симулятора теплового режиму та алгоритму МНК-фітингу коефіцієнтів ТКО двома мовами — ідіоматичною C та сучасним C++ (з використанням концепції RAII, обгортки безпеки `std::span` та `std::optional`).

Програма моделює проходження вимірювального струму `50 А` через прецизійний манганіновий шунт номіналом `1 мОм`, обчислює усталену температуру самонагріву, розраховує зсув опору у `ppm` та виконує зворотне відновлення коефіцієнтів ТКО за синтезованими калібрувальними точками.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

typedef struct {
    double r20;       /* Опір при 20 °C, Ом */
    double alpha20;   /* Лінійний ТКО, 1/К */
    double beta;      /* Квадратичний ТКО, 1/К² */
    double r_th;      /* Тепловий опір охолодження, К/Вт */
    double t_ambient; /* Температура довкілля, °C */
} AlloyParams;

typedef struct {
    double r_fitted_0;
    double alpha_fitted;
    double beta_fitted;
    double t_peak;
} FitResult;

/* Обчислення опору сплаву при температурі T */
double calculate_resistance(const AlloyParams* alloy, double temp_c) {
    double dt = temp_c - 20.0;
    return alloy->r20 * (1.0 + alloy->alpha20 * dt + alloy->beta * dt * dt);
}

/* Симуляція самонагріву шунта струмом I (ітераційне знаходження теплової рівноваги) */
double simulate_self_heating(const AlloyParams* alloy, double current_a) {
    double temp = alloy->t_ambient;
    for (int iter = 0; iter < 10; ++iter) {
        double r_current = calculate_resistance(alloy, temp);
        double power_w = current_a * current_a * r_current;
        double new_temp = alloy->t_ambient + power_w * alloy->r_th;
        if (fabs(new_temp - temp) < 1e-6) {
            break;
        }
        temp = new_temp;
    }
    return temp;
}

/* МНК-фітинг параболічної залежності за виміряними точками (T_i, R_i) */
bool fit_tcr_parabola(const double* temp_array, const double* r_array, int count, FitResult* result) {
    if (count < 3 || !temp_array || !r_array || !result) {
        return false;
    }

    double s0 = count, s1 = 0, s2 = 0, s3 = 0, s4 = 0;
    double y0 = 0, y1 = 0, y2 = 0;

    for (int i = 0; i < count; ++i) {
        double x = temp_array[i] - 20.0;
        double x2 = x * x;
        double y = r_array[i];

        s1 += x;
        s2 += x2;
        s3 += x2 * x;
        s4 += x2 * x2;

        y0 += y;
        y1 += y * x;
        y2 += y * x2;
    }

    /* Розв'язання системи 3x3 методом Крамера */
    double det = s0 * (s2 * s4 - s3 * s3) - s1 * (s1 * s4 - s2 * s3) + s2 * (s1 * s3 - s2 * s2);
    if (fabs(det) < 1e-15) {
        return false;
    }

    double det_a0 = y0 * (s2 * s4 - s3 * s3) - s1 * (y1 * s4 - s3 * y2) + s2 * (y1 * s3 - s2 * y2);
    double det_a1 = s0 * (y1 * s4 - s3 * y2) - y0 * (s1 * s4 - s2 * s3) + s2 * (s1 * y2 - y1 * s2);
    double det_a2 = s0 * (s2 * y2 - y1 * s3) - s1 * (s1 * y2 - y1 * s2) + y0 * (s1 * s3 - s2 * s2);

    double a0 = det_a0 / det;
    double a1 = det_a1 / det;
    double a2 = det_a2 / det;

    result->r_fitted_0 = a0;
    result->alpha_fitted = a1 / a0;
    result->beta_fitted = a2 / a0;
    result->t_peak = 20.0 - (result->alpha_fitted / (2.0 * result->beta_fitted));

    return true;
}

int main(void) {
    /* Параметри манганінового шунта 1 мОм */
    AlloyParams manganin = {
        .r20 = 0.001,         /* 1 мОм */
        .alpha20 = 2e-6,      /* +2 ppm/K */
        .beta = -4e-7,        /* -0.4 ppm/K² */
        .r_th = 15.0,         /* 15 K/Вт */
        .t_ambient = 25.0
    };

    printf("=== Симуляція манганінового шунта ===\n");
    double current = 50.0; /* 50 А */
    double t_eq = simulate_self_heating(&manganin, current);
    double r_eq = calculate_resistance(&manganin, t_eq);
    double dr_ppm = (r_eq - manganin.r20) / manganin.r20 * 1e6;

    printf("Струм: %.1f А -> Т_рівн: %.2f °C, R: %.7f Ом (Зсув: %.2f ppm)\n\n",
           current, t_eq, r_eq, dr_ppm);

    /* Фітинг ТКО за калібрувальними точками */
    double test_temps[] = {0.0, 15.0, 25.0, 40.0, 60.0};
    double test_res[5];
    for (int i = 0; i < 5; ++i) {
        test_res[i] = calculate_resistance(&manganin, test_temps[i]);
    }

    FitResult fit;
    if (fit_tcr_parabola(test_temps, test_res, 5, &fit)) {
        printf("=== Результати МНК-фітингу ===\n");
        printf("R20: %.6f Ом\n", fit.r_fitted_0);
        printf("Alpha20: %.3f ppm/K\n", fit.alpha_fitted * 1e6);
        printf("Beta: %.4f ppm/K²\n", fit.beta_fitted * 1e6);
        printf("Вершина параболи (T_peak): %.2f °C\n", fit.t_peak);
    }

    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <span>
#include <optional>
#include <iomanip>

struct AlloyProperties {
    double r20{0.001};       // Опір при 20 °C, Ом
    double alpha20{2e-6};    // Лінійний ТКО, 1/К
    double beta{-4e-7};      // Квадратичний ТКО, 1/К²
    double r_th{15.0};       // Тепловий опір, К/Вт
    double t_ambient{25.0};  // Температура довкілля, °C

    [[nodiscard]] double calculate_resistance(double temp_c) const noexcept {
        const double dt = temp_c - 20.0;
        return r20 * (1.0 + alpha20 * dt + beta * dt * dt);
    }

    [[nodiscard]] double simulate_equilibrium_temp(double current_a) const noexcept {
        double temp = t_ambient;
        for (int iter = 0; iter < 10; ++iter) {
            const double r_curr = calculate_resistance(temp);
            const double power_w = current_a * current_a * r_curr;
            const double new_temp = t_ambient + power_w * r_th;
            if (std::abs(new_temp - temp) < 1e-6) {
                break;
            }
            temp = new_temp;
        }
        return temp;
    }
};

struct PolynomialFitResult {
    double r20{0.0};
    double alpha20{0.0};
    double beta{0.0};
    double t_peak{0.0};
};

class TcrAnalyzer {
public:
    [[nodiscard]] static std::optional<PolynomialFitResult> fit_parabola(
        std::span<const double> temps,
        std::span<const double> resistances) noexcept 
    {
        if (temps.size() != resistances.size() || temps.size() < 3) {
            return std::nullopt;
        }

        double s0 = static_cast<double>(temps.size()), s1 = 0, s2 = 0, s3 = 0, s4 = 0;
        double y0 = 0, y1 = 0, y2 = 0;

        for (size_t i = 0; i < temps.size(); ++i) {
            const double x = temps[i] - 20.0;
            const double x2 = x * x;
            const double y = resistances[i];

            s1 += x;
            s2 += x2;
            s3 += x2 * x;
            s4 += x2 * x2;

            y0 += y;
            y1 += y * x;
            y2 += y * x2;
        }

        const double det = s0 * (s2 * s4 - s3 * s3) - s1 * (s1 * s4 - s2 * s3) + s2 * (s1 * s3 - s2 * s2);
        if (std::abs(det) < 1e-15) {
            return std::nullopt;
        }

        const double det_a0 = y0 * (s2 * s4 - s3 * s3) - s1 * (y1 * s4 - s3 * y2) + s2 * (y1 * s3 - s2 * y2);
        const double det_a1 = s0 * (y1 * s4 - s3 * y2) - y0 * (s1 * s4 - s2 * s3) + s2 * (s1 * y2 - y1 * s2);
        const double det_a2 = s0 * (s2 * y2 - y1 * s3) - s1 * (s1 * y2 - y1 * s2) + y0 * (s1 * s3 - s2 * s2);

        const double a0 = det_a0 / det;
        const double a1 = det_a1 / det;
        const double a2 = det_a2 / det;

        PolynomialFitResult res;
        res.r20 = a0;
        res.alpha20 = a1 / a0;
        res.beta = a2 / a0;
        res.t_peak = 20.0 - (res.alpha20 / (2.0 * res.beta));

        return res;
    }
};

int main() {
    const AlloyProperties manganin{.r20 = 0.001, .alpha20 = 2e-6, .beta = -4e-7, .r_th = 15.0, .t_ambient = 25.0};

    std::cout << "=== Симуляція манганінового шунта (C++) ===\n";
    const double current = 50.0;
    const double t_eq = manganin.simulate_equilibrium_temp(current);
    const double r_eq = manganin.calculate_resistance(t_eq);
    const double dr_ppm = (r_eq - manganin.r20) / manganin.r20 * 1e6;

    std::cout << std::fixed << std::setprecision(7);
    std::cout << "Струм: " << current << " А -> Т_рівн: " << t_eq << " °C, R: " << r_eq 
              << " Ом (Зсув: " << dr_ppm << " ppm)\n\n";

    const std::vector<double> test_temps{0.0, 15.0, 25.0, 40.0, 60.0};
    std::vector<double> test_res;
    test_res.reserve(test_temps.size());

    for (double t : test_temps) {
        test_res.push_back(manganin.calculate_resistance(t));
    }

    if (auto fit = TcrAnalyzer::fit_parabola(test_temps, test_res)) {
        std::cout << "=== Результати МНК-фітингу (C++) ===\n";
        std::cout << "R20: " << fit->r20 << " Ом\n";
        std::cout << "Alpha20: " << fit->alpha20 * 1e6 << " ppm/K\n";
        std::cout << "Beta: " << fit->beta * 1e6 << " ppm/K²\n";
        std::cout << "Вершина параболи (T_peak): " << fit->t_peak << " °C\n";
    }

    return 0;
}
```

## 4. Фізичний та інженерний аналіз результатів моделювання

Детальний розбір обчислених даних розкриває фундаментальні переваги прецизійних сплавів:

1. **Термічний режим шунта**: При проходженні силового струму `50 А` через шунт опором `1 мОм` виділяється теплова потужність `P = I² · R = 2500 · 0.001 = 2.5 Вт`. З урахуванням теплового опору природного охолодження `R_th = 15 К/Вт` температура активного елемента зростає на `ΔT = P · R_th = 37.5 °C`, досягаючи стаціонарного рівня `62.5 °C` при температурі довкілля `25 °C`.
2. **Порівняння з чистими металами**: Якби цей шунт виготовили з чистої міді (`α_Cu = +3900 ppm/K`), нагрівання на `37.5 °C` викликало б відносний зсув опору `ΔR/R = +14.6%` (`146 250 ppm`). Вимірювальний прилад показав би струм `57.3 А` замість реальних `50.0 А`, що створює недопустиму похибку вимірювання.
3. **Ефективність манганіну**: Для манганінового шунта з параболічним профілем (`α_20 = +2 ppm/K`, `β = -0.4 ppm/K²`) при нагріванні від `25 °C` до `62.5 °C` відносна зміна опору становить всього **`-0.72 ppm`** (`-0.000072%`).
4. **Алгоритм цифрової компенсації**: У цифрових вимірювальних системах 24-бітний аналого-цифровий перетворювач (АЦП) зчитує спад напруги `V_sense` та додатковий термодатчик температури шунта `T_sensor`. Вбудований мікроконтролер обчислює скориговане значення опору `R(T_sensor)` за фітованими МНК-коефіцієнтами `(R_0, α_0, β)` та відновлює істинне значення струму:

```
I_exact = V_sense / R(T_sensor)
```

Така поєднана фізико-програмна компенсація дозволяє досягати метрологічної точності вимірювання струму краще за `0.001%` (`10 ppm`) у всьому діапазоні робочих температур промислового обладнання.
