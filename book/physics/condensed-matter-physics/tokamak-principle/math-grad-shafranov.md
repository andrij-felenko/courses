# 🧮 Математичне виведення рівноваги Града — Шафранова та коефіцієнта запасу q

Аналітичний опис гідромагнітної рівноваги плазмового шнура в токамаку вимагає сумісного розв'язання рівнянь Максвелла та статичного рівняння руху суцільного провідного середовища. Оскільки токамак володіє осьовою симетрією відносно тороїдального кута `φ`, тривимірна задача рівнянь магнітогідродинаміки зводиться до двовимірного нелінійного рівняння в частинних похідних відносно функції полоїдального магнітного потоку `ψ(R, z)`. Ця вставка містить суворе математичне виведення рівняння Града — Шафранова, точний розрахунок зсуву Шафранова, аналітичний розв'язок Соловйова, віріальну теорему Шафранова, виведення струмів Пфірша — Шлютера, розрахунок профілю коефіцієнта запасу стійкості `q(r)` та математичний доказ компенсації градієнтного дрейфу заряджених частинок завдяки закручуванню магнітних ліній.

## 1. Магнітні поверхні та векторний потенціал в осьовій симетрії

Розглянемо циліндричну систему координат `(R, φ, z)`, де `R` — відстань від головної осі симетрії токамака, `φ` — тороїдальний кут, `z` — вертикальна вісь. Осьова симетрія означає, що для будь-якої фізичної величини `X` частинна похідна за тороїдальним кутом дорівнює нулю:

```
∂X / ∂φ = 0
```

Умова відсутності магнітних монополів `∇·B = 0` в осьовій симетрії дозволяє виразити полоїдальне магнітне поле `B_pol = (B_R, 0, B_z)` через скалярну функцію магнітного потоку `ψ(R, z)`. Зв'язок із тороїдальною компонентою векторного потенціалу `A` задається співвідношенням `ψ = R · A_φ`. Тоді компоненти векторного магнітного поля виражаються частинними похідними за координатами `R` та `z`:

```
B_R = - (1 / R) · (∂ψ / ∂z)          [з умови ∇·B = 0 для R-компоненти]
B_z =   (1 / R) · (∂ψ / ∂R)          [з умови ∇·B = 0 для z-компоненти]
B_φ =   F(ψ) / R                     [де F(ψ) = R·B_φ — тороїдальна функція потоку]
```

Перевіримо дивергенцію поля `B` у циліндричних координатах:

```
∇·B
= (1/R)·∂(R·B_R)/∂R + ∂B_z/∂z                    [дивергенція в циліндричних координатах при ∂/∂φ = 0]
= (1/R)·∂(-∂ψ/∂z)/∂R + ∂((1/R)·∂ψ/∂R)/∂z        [підстановка компонент полів B_R та B_z через поток ψ]
= - (1/R)·(∂²ψ / ∂R∂z) + (1/R)·(∂²ψ / ∂z∂R)      [розкриття похідних та диференціювання добутку]
= 0                                              [рівність мішаних похідних Клеро — Шварца]
```

Поверхні рівня `ψ(R, z) = const` називаються **вкладеними магнітними поверхнями**. Оскільки силові лінії магнітного поля в кожній точці дотичні до поверхні `ψ = const`, скалярний добуток градієнта потоку на магнітне поле `(B · ∇ψ)` тотожно дорівнює нулю:

```
B · ∇ψ
= B_R · (∂ψ/∂R) + B_z · (∂ψ/∂z)                       [визначення скалярного добутку в циліндричних координатах]
= (- (1/R)·∂ψ/∂z) · (∂ψ/∂R) + ((1/R)·∂ψ/∂R) · (∂ψ/∂z)  [підстановка виразів B_R = -(1/R)·∂ψ/∂z та B_z = (1/R)·∂ψ/∂R]
= 0                                                    [взаємне скорочення доданків]
```

Геометричний зміст цього результату полягає в тому, що кожна силова лінія магнітного поля повністю лежить на своїй магнітній поверхні `ψ = const` і ніколи її не перетинає. Магнітний потік `ψ(R, z)` представляє собою повний полоїдальний магнітний потік, що проходить крізь диск радіуса `R` на висоті `z`.

## 2. Густина струму та МГД-рівновага

Рівновага плазмового шнура в квазістаціонарному стані описується балансом газокінетичного тиску плазми `p` та амперівської сили `j × B`:

```
∇p = j × B                            [рівняння МГД-рівноваги]
```

З цього рівняння негайно випливають дві важливі математичні властивості топології токамака:
1. `B · ∇p = 0` — тиск плазми сталий уздовж силових ліній магнітного поля. Тобто ізобари `p = const` тотожно збігаються з магнітними поверхнями: `p = p(ψ)`.
2. `j · ∇p = 0` — лінії електричного струму також повністю лежать на магнітних поверхнях `ψ = const`.

Густина струму `j` знаходиться із закону Ампера `∇ × B = μ₀ · j`:

```
j = (1 / μ₀) · ∇ × B
```

Обчислимо компоненти ротора поля `B` в циліндричних координатах з урахуванням осьової симетрії `∂/∂φ = 0`:

```
j_R = - (1 / μ₀·R) · (∂F / ∂z)       [де F = R·B_φ]
j_z =   (1 / μ₀·R) · (∂F / ∂R)
j_φ =   (1 / μ₀) · [ ∂/∂R ((1/R)·∂ψ/∂R) + (1/R)·(∂²ψ/∂z²) ]
```

Введемо еліптичний диференціальний оператор Града — Шафранова `Δ*`:

```
Δ* ψ ≡ R · ∂/∂R ((1/R) · ∂ψ/∂R) + ∂²ψ/∂z²
= ∂²ψ/∂R² - (1/R) · (∂ψ/∂R) + ∂²ψ/∂z²
```

Тоді тороїдальна компонента струму спрощується до вигляду: `j_φ = (1 / μ₀·R) · Δ* ψ`.

## 3. Виведення рівняння Града — Шафранова

Підставимо вирази для `B` та `j` у радіальну `R`-компоненту рівняння МГД-рівноваги `∇p = j × B`.

Оскільки `p = p(ψ)`, градієнт тиску дорівнює `∇p = p'(ψ) · ∇ψ`, звідки його `R`-компонента становить:

```
(∇p)_R = p'(ψ) · (∂ψ / ∂R)
```

З іншого боку, обчислимо `R`-компоненту векторного добутку `(j × B)_R = j_φ · B_z - j_z · B_φ`:

```
(j × B)_R
= [ (1 / μ₀·R) · Δ* ψ ] · [ (1 / R) · ∂ψ/∂R ] - [ (1 / μ₀·R) · ∂F/∂R ] · [ F / R ]   [компоненти j_φ·B_z - j_z·B_φ]
= (1 / μ₀·R²) · (Δ* ψ) · (∂ψ/∂R) - (1 / μ₀·R²) · F · (∂F/∂R)                         [винесення 1/(μ₀·R²) за дужки]
```

Прирівнюємо обоє виразів:

```
p'(ψ) · (∂ψ/∂R) = (1 / μ₀·R²) · (Δ* ψ) · (∂ψ/∂R) - (1 / μ₀·R²) · F · F'(ψ) · (∂ψ/∂R)
```

Оскільки це співвідношення має виконуватися в кожній точці плазмового об'єму, ми можемо скоротити спільний множник `∂ψ / ∂R` (за умови `∂ψ / ∂R ≠ 0`).

Після множення обох частин на `μ₀ · R²` отримуємо класичне **рівняння Града — Шафранова**:

```
Δ* ψ = - μ₀ · R² · p'(ψ) - F(ψ) · F'(ψ)
```

де:
- `Δ* ψ = ∂²ψ/∂R² - (1/R)·(∂ψ/∂R) + ∂²ψ/∂z²` — диференціальний оператор на двовимірній сітці `(R, z)`;
- `p(ψ)` — функція профілю тиску плазми;
- `F(ψ) = R · B_φ` — функція тороїдального магнітного потоку;
- `p'(ψ) = dp/dψ` та `F'(ψ) = dF/dψ` — джерельні функції, що задаються профілем нагріву та зовнішніми струмами.

Рівняння Града — Шафранова є нелінійним еліптичним рівнянням у частинних похідних з вільною межею. Воно складає математичну основу всіх сучасних чисельних кодів розрахунку рівноваги плазми у токамаках (наприклад, EFIT, HELENA, CHEASE).

Фізичний зміст лівої частини рівняння Града — Шафранова `Δ* ψ` відповідає тороїдальній густині струму `μ₀·R·j_φ`. Права частина показує, що тороїдальний струм складається з двох різних внесків:
1. `- μ₀ · R² · p'(ψ)` — струм діамагнітного та градієнтного походження, викликаний наявністю газокінетичного тиску плазми. Цей внесок зростає з збільшенням великого радіуса `R`.
2. `- F(ψ) · F'(ψ)` — струм, пов'язаний із силовим закручуванням тороїдального магнітного поля (парамагнітний чи діамагнітний струм).

## 4. Аналітичні розв'язки Соловйова та віріальна теорема Шафранова

У найпростішому лінійному випадку, коли джерельні функції вибираються константами `p'(ψ) = C₁ = const` та `F(ψ)·F'(ψ) = C₂ = const`, рівняння Града — Шафранова стає лінійним:

```
Δ* ψ = - μ₀ · R² · C₁ - C₂
```

Цей випадок має точний аналітичний розв'язок, виведений Л. Соловйовим у 1968 році. Для плазмового витка з витягнутістю (elongation) `κ` та трикутністю (triangularity) `δ` розв'язок Соловйова описується поліномом відносно `(R, z)`:

```
ψ(R, z) = (ψ₀ / R₀² · b²) · [ R² · z² + (κ² / 4) · (R² - R₀²)² ]
```

де `ψ₀` — значення магнітного потоку на осі, `R₀` — великий радіус магнітної осі, `b` — вертикальний піврозмір плазмового перерізу.

З розв'язку Соловйова можна математично вивести **зсув Шафранова** `ΔR` — відхилення геометричного центру внутрішніх магнітних поверхонь відносно зовнішніх. У наближенні великого аспектного відношення `ε = a / R₀ ≪ 1` зсув Шафранова на радіусі `r` описується інтегральною формулою:

```
ΔR(r) = ∫₀ʳ (r' / R₀) · [ β_p(r') + l_i(r') / 2 ] dr'
```

де `β_p` — полоїдальний параметр бета (відношення тиску плазми до тиску полоїдального поля), а `l_i` — питома внутрішня індуктивність плазмового шнура. Ця формула чітко показує, що з нагрівом плазми та зростанням тиску `β_p` магнітна вісь зміщується до зовнішньої стінки тора.

Для утримання тороїдального витка в радіальній рівновазі необхідне зовнішнє вертикальне магнітне поле `B_z_ext`. **Віріальна теорема Шафранова** встановлює точне аналітичне значення для утримувального поля:

```
B_z_ext = (μ₀ · I_p / 4π · R₀) · [ ln(8·R₀ / a) + β_p + (l_i - 3) / 2 ]
```

Цей результат підтверджує, що для утримання гарячої плазми з високим тиском `β_p` потрібне посилення зовнішнього вертикального поля.

Також витягнутість плазмового перерізу `κ = b / a` створює вертикальну нестійкість (vertical displacement event, VDE). Для математичної стабілізації VDE в коефіцієнті спаду вертикального магнітного поля `n_index` має виконуватись умова:

```
n_index = - (R / B_z) · (∂B_z / ∂R) < 0
```

що вимагає застосування активної електронної системи підтримання положення плазми за допомогою додаткових котушок зворотного зв'язку.

## 5. Струми Пфірша — Шлютера та умова несжимаємості струму

З умови збереження заряду в квазістаціонарному стані `∇·j = 0` випливає, що паралельна компонента густини струму `j_|| = (j · B) / B` не може бути довільною.

Розділимо густину струму на перпендикулярну (діамагнітну) та паралельну компоненти:

```
j_⊥ = (B × ∇p) / B²
```

Підставляючи `j_⊥` у закон збереження струму `∇·j = ∇·j_|| + ∇·j_⊥ = 0`, отримуємо диференціальне рівняння для поздовжніх струмів:

```
B · ∇(j_|| / B) = - ∇ · j_⊥ = - ∇ · [ (B × ∇p) / B² ]
```

У тороїдальній геометрії токамака із тороїдальним полем `B_φ ≈ B₀ · (1 - (r/R₀)·cos θ)` інтегрування цього рівняння вздовж силової лінії дає знамениту формулу для **струмів Пфірша — Шлютера** `j_||^PS`:

```
j_||^PS = - (2 / B_θ) · (dp / dr) · cos θ
```

де `θ` — полоїдальний кут (`θ = 0` відповідає зовнішньому обводу тора, `θ = π` — внутрішньому).

Фізичний зміст струмів Пфірша — Шлютера полягає у замиканні вертикальних переносів заряду, викликаних градієнтним та кривинним дрейфами. Вони течуть уздовж гвинтових силових ліній від верхньої напівсфери до нижньої, компенсуючи розділення зарядів та усуваючи катастрофічний електричний дрейф плазми.

## 6. Критерій Мерсьє для локалізованих желобкових мод

Математична стійкість МГД-рівноваги відносно локалізованих перестановних (жолобкових) мод описується **критерієм Мерсьє** (Mercier criterion). У циліндричному наближенні без тороїдальності критерій Мерсьє переходить у класичний **критерій Суйдома** (Suydam criterion):

```
(r / 8·μ₀) · (dp / dr) · (s / q)² + 1/4 > 0
```

де `s = (r/q)·(dq/dr)` — магнітний шир.

Оскільки у термоядерній плазмі градієнт тиску від'ємний `dp/dr < 0`, перший доданок є від'ємним. Це означає, що для забезпечення стійкості плазми необхідний достатньо високий позитивний магнітний шир `s > 0`, який «перекриває» дестабілізуючу дію градієнта тиску. У тороїдальній геометрії сприятлива кривизна на внутрішньому боці тора створює «магнітну яму», що додатково підвищує стійкість.

## 7. Виведення коефіцієнта запасу q(r) та кута обертання

Топологія магнітного поля визначається кутом обертального перетворення `ι(r)` — кутом, на який повертається силова лінія за один повний обхід уздовж тора `Δφ = 2π`.

Коефіцієнт запасу стійкості (safety factor) `q(r)` визначається як відношення кількості тороїдальних обходів `N_tor` до одного полоїдального обходу `N_pol`:

```
q(r) = 2π / ι(r) = (1 / 2π) · ∮ dφ
```

Уздовж силової лінії магнітного поля виконується рівняння траєкторії `dR / B_R = R·dφ / B_φ = dz / B_z`. Отже, елемент тороїдального кута дорівнює:

```
dφ = (B_φ / R) · (ds / B_pol)
```

де `ds = √(dR² + dz²)` — елемент довжини дуги уздовж магнітної поверхні у полоїдальному перерізі, а `B_pol = √(B_R² + B_z²)` — полоїдальне магнітне поле.

Підставляючи вираз для `dφ`, отримуємо точну математичну формулу для `q`:

```
q(ψ) = (F(ψ) / 2π) · ∮ [ 1 / (R² · B_pol) ] ds
```

Для малого тороїдального співвідношення `ε = r / R ≪ 1` та кругових магнітних поверхонь радіуса `r` це рівняння спрощується до стандартної інженерної формули:

```
q(r) ≈ (r · B_φ) / (R₀ · B_θ(r))
```

де `R₀` — великий радіус токамака, `r` — малий радіус розглянутої магнітної поверхні, `B_θ(r)` — полоїдальне магнітне поле на радіусі `r`.

### Закон Ампера для полоїдального поля:

```
B_θ(r) = (μ₀ · I_p(r)) / (2π · r)
```

Підставляючи `B_θ(r)` у вираз для `q(r)`:

```
q(r) = (2π · r² · B_φ) / (μ₀ · R₀ · I_p(r))
```

Це рівняння показує, що для збільшення запасу стійкості `q` необхідно або підвищувати тороїдальне магнітне поле `B_φ`, або зменшувати струм плазми `I_p`, що створює безпосередній компроміс між стійкістю плазми й ефективністю її омічного нагріву.

Похідна коефіцієнта запасу за радіусом називається **магнітним широм** (magnetic shear) `s`:

```
s(r) = (r / q) · (dq / dr)
```

Позитивний магнітний шир `s > 0` стабілізує МГД-моди, тоді як зворотний магнітний шир `s < 0` у центрі камери дозволяє формувати внутрішні бар'єри переносу (ITB).

## 8. Математичний інваріант магнітної гелічності

Під час магнітного перезамикання у тингових модах важливу роль відіграє топологічний інваріант — **магнітна гелічність** (magnetic helicity) `K`, яка вимірює ступінь зачеплення та закручування силових ліній у магнітному об'ємі `V`:

```
K = ∫_V (A · B) dV
```

Згідно з теоремою Вольтєра (Taylor relaxation), в умовах малої дисипації (високої провідності) плазма прагне перейти до стану з мінімальною магнітною енергією `W_B = ∫ (B² / 2μ₀) dV` при збереженні повної магнітної гелічності `K = const`.

Варіаційна задача мінімізації `δ(W_B - λ·K) = 0` приводить до рівняння бессилового магнітного поля (force-free field):

```
∇ × B = μ₀ · λ · B
```

де `λ` — константа лагранжевого множника. Це рівняння описує бессилові струми в токамаку, які течуть строго уздовж силових ліній `j || B`, не створюючи додаткового градієнта тиску `j × B = 0`.

## 9. Доказ нейтралізації градієнтного дрейфу

У неоднорідному магнітному полі тора `B(R) ≈ B₀ · (R₀ / R)` заряджена частинка з масою `m`, зарядом `q_e` та швидкостями `v_||` (уздовж поля) та `v_⊥` (поперек поля) зазнає градієнтного та кривинного дрейфів.

Сумарна швидкість вертикального дрейфу напрямлена вздовж осі `z`:

```
v_d = v_∇B + v_c = [ (m · (v_⊥² + 2·v_||²)) / (2 · q_e · B₀ · R₀) ] · ẑ
```

У простому торі `(B_θ = 0)` ця швидкість є постійною за знаком. Іони дрейфують вгору `(+z)`, електрони — вниз `(-z)`. Накопичений заряд створює вертикальне електричне поле `E_z`, яке викликає радіальний дрейф усієї плазми на зовнішню стінку зі швидкістю `v_r = E_z / B_φ`.

У токамаку завдяки наявності полоїдального поля `B_θ` силові лінії описують гвинтову траєкторію. Частинка рухається уздовж силової лінії з тороїдальною кутовою швидкістю `ω_φ = v_|| / R₀`. 

Зміна вертикальної координати частинки `z(t)` під час руху уздовж закрученої силової лінії описується рівнянням:

```
z(t) = r · sin(θ(t)) = r · sin( (v_|| / q·R₀) · t )
```

Знайдемо повне радіальне зміщення частинки `Δr(t)` під дією комбінації дрейфу `v_d` та обертання:

```
dr/dt
= v_d · sin(θ(t))                         [радіальна проекція вертикального дрейфу]
= v_d · sin( (v_|| / q·R₀) · t )          [підстановка кута полоїдального обертання θ(t)]
```

Інтегруємо від `t = 0` до `t`:

```
Δr(t)
= ∫₀ᵗ v_d · sin( (v_|| / q·R₀) · τ ) dτ                       [визначення радіального зсуву як інтеграла швидкості]
= [ (v_d · q · R₀) / v_|| ] · [ 1 - cos( (v_|| / q·R₀) · t ) ]  [первісна гармонічної функції]
```

### Висновок з формули зміщення:
1. Максимальне радіальне відхилення частинки від магнітної поверхні є скінченним і обмеженим величиною:
   ```
   Δr_max = (2 · v_d · q · R₀) / v_|| ≈ q · ρ_L
   ```
   де `ρ_L = m·v / q_e·B` — ларморівський радіус частинки.
2. Усереднений за один полоїдальний обіг радіальний зсув дорівнює нулю: `<Δr> = 0`.

Таким чином, обертальне перетворення магнітних ліній у токамаку трансформує необмежений катастрофічний дрейф у дрібні замкнені осциляції навколо вкладених магнітних поверхонь, що забезпечує стабільне магнітне утримання плазми.
