# 🧮 Тензорний формалізм п'єзоопору та кубічна симетрія кристалів

У цій математичній вставці виведено тензорні рівняння п'єзорезистивного ефекту, виконано матричне скорочення Фойгта, доведено спрощення тензора п'єзоопору для кубічних кристалів (клас симетрії `m3m`), розраховано поздовжні й поперечні коефіцієнти чутливості для головних кристалографічних орієнтацій кремнієвих пластин та побудовано математичну модель температурної та концентраційної редукції коефіцієнтів п'єзоопору.

---

### Рівняння зв'язку тензора питомого опору та тензора напружень

У загальному анізотропному середовищі електричне поле `E_i` та густина струму `j_k` пов'язані тензором питомого електричного опору `ρ_ik`:

```
E_i = ρ_ik · j_k
```

Під дією зовнішніх механічних напружень, що описуються тензором другого рангу `σ_kl`, компоненти тензора питомого опору змінюються. У наближенні малих деформацій відносна зміна компонента питомого опору `Δρ_ij / ρ₀` є лінійною функцією компонентів тензора напружень `σ_kl`:

```
(Δρ_ij / ρ₀) = π_ijkl · σ_kl
```

де `π_ijkl` — тензор п'єзорезистивних коефіцієнтів четвертого рангу, який у загальному тривимірному просторі містить `3⁴ = 81` компонент, `ρ₀` — ізотропний питомий опір недеформованого кристала.

Замість тензора напружень `σ_kl` зв'язок можна також виразити через тензор деформацій `ε_kl` за допомогою тензора деформаційного потенціалу `m_ijkl`:

```
(Δρ_ij / ρ₀) = m_ijkl · ε_kl
```

Тензори `π_ijkl` та `m_ijkl` пов'язані між собою через тензор модулів пружності `C_klmn` (закон Гука `σ_kl = C_klmn · ε_mn`):

```
m_ijmn = π_ijkl · C_klmn
```

#### Властивості симетрії та зменшення кількості компонентів

Тензор напружень `σ_kl` є симетричним відносно перестановки індексів унаслідок умови моментної рівноваги суцільного середовища:

```
σ_kl = σ_lk
```

Тензор питомого опору `ρ_ij` також є симетричним згідно з принципом онсагерівської симетрії кінетичних коефіцієнтів за відсутності зовнішнього магнітного поля:

```
Δρ_ij = Δρ_ji
```

Оскільки лівий та правий боки тензорного рівняння є симетричними відносно перестановки першої та другої пари індексів, тензор `π_ijkl` володіє внутрішньою симетрією:

```
π_ijkl = π_jikl = π_ijlk
```

Завдяки цим двом симетріям кількість незалежних компонентів тензора `π_ijkl` зменшується з 81 до 36.

### Матрична нотація Фойгта

Для спрощення запису тензорних рівнянь застосовують стандартне скорочення індексів Фойгта, де кожна пара симетричних тензорних індексів `(i, j)` замінюється одним матричним індексом `α` від 1 до 6 за такою схемою:

```
(1, 1) → 1    (Вздовж осі X [100])
(2, 2) → 2    (Вздовж осі Y [010])
(3, 3) → 3    (Вздовж осі Z [001])
(2, 3) або (3, 2) → 4    (Зсув у площині YZ)
(1, 3) або (3, 1) → 5    (Зсув у площині XZ)
(1, 2) або (2, 1) → 6    (Зсув у площині XY)
```

За допомогою нотації Фойгта тензор напружень `σ_kl` та відносна зміна опору `Δρ_ij / ρ₀` записуються як шестивимірні вектори-стовпці:

```
[σ] = [ σ₁₁,  σ₂₂,  σ₃₃,  σ₂₃,  σ₁₃,  σ₁₂ ]ᵀ = [ σ₁, σ₂, σ₃, σ₄, σ₅, σ₆ ]ᵀ

[Δρ/ρ₀] = [ Δρ₁/ρ₀, Δρ₂/ρ₀, Δρ₃/ρ₀, Δρ₄/ρ₀, Δρ₅/ρ₀, Δρ₆/ρ₀ ]ᵀ
```

Тензор четвертого рангу `π_ijkl` перетворюється на квадратну матрицю розміром `6 × 6`, а тензорне рівняння набуває компактного матричного вигляду:

```
Δρ_α / ρ₀ = ∑_(β=1..6) π_αβ · σ_β
```

Розгорнута система рівнянь має вигляд:

```
[ Δρ₁/ρ₀ ]   [ π₁₁  π₁₂  π₁₃  π₁₄  π₁₅  π₁₆ ]   [ σ₁ ]
[ Δρ₂/ρ₀ ]   [ π₂₁  π₂₂  π₂₃  π₂₄  π₂₅  π₂₆ ]   [ σ₂ ]
[ Δρ₃/ρ₀ ]   [ π₃₁  π₃₂  π₃₃  π₃₄  π₃₅  π₃₆ ]   [ σ₃ ]
[ Δρ₄/ρ₀ ] = [ π₄₁  π₄₂  π₄₃  π₄₄  π₄₅  π₄₆ ] · [ σ₄ ]
[ Δρ₅/ρ₀ ]   [ π₅₁  π₅₂  π₅₃  π₅₄  π₅₅  π₅₆ ]   [ σ₅ ]
[ Δρ₆/ρ₀ ]   [ π₆₁  π₆₂  π₆₃  π₆₄  π₆₅  π₆₆ ]   [ σ₆ ]
```

### Точечна симетрія кубічних кристалів (Клас m3m)

Кристали кремнію (Si) та германію (Ge) належать до точкової групи симетрії `m3m` (точкова група `O_h`, кубічна ґратка типу алмазу). Точкова симетрія кубічного кристала накладає жорсткі обмеження на елементи матриці `π_αβ`:

1. **Інваріантність відносно дзеркального відображення:** Перетворення `x → -x`, `y → -y`, `z → -z` вимагають, щоб усі елементи матриці, які зв'язують нормальні напруження зі зсувними деформаціями (та навпаки), дорівнювали нулю:
   ```
   π_αβ = 0  для  α ∈ {1,2,3}, β ∈ {4,5,6}  або  α ∈ {4,5,6}, β ∈ {1,2,3}
   ```
2. **Інваріантність відносно повороту навколо осей третього порядку `<111>`:** Поворот на 120° навколо головної діагоналі куба циклічно переставляє координатні осі `X → Y → Z → X`. Це вимагає рівності діагональних елементів та взаємних елементів зв'язку:
   ```
   π₁₁ = π₂₂ = π₃₃
   π₁₂ = π₂₁ = π₁₃ = π₃₁ = π₂₃ = π₃₂
   π₄₄ = π₅₅ = π₆₆
   ```

У результаті з 36 компонентів матриці п'єзоопору незалежними та ненульовими залишаються лише три коефіцієнти: `π₁₁`, `π₁₂` та `π₄₄`.

Матриця п'єзоопору кубічного кристала у кристалографічній системі координат `[100]`, `[010]`, `[001]` набуває підсумкового вигляду:

```
          [  π₁₁   π₁₂   π₁₂    0     0     0  ]
          [  π₁₂   π₁₁   π₁₂    0     0     0  ]
          [  π₁₂   π₁₂   π₁₁    0     0     0  ]
[π_αβ] =  [   0     0     0    π₄₄    0     0  ]
          [   0     0     0     0    π₄₄    0  ]
          [   0     0     0     0     0    π₄₄ ]
```

Фізичний зміст трьох незалежних коефіцієнтів:
- `π₁₁`: Поздовжній п'єзорезистивний коефіцієнт при прикладанні напруження та вимірюванні струму вздовж головної кристалографічної осі `[100]`.
- `π₁₂`: Поперечний п'єзорезистивний коефіцієнт при прикладанні напруження вздовж осі `[010]`, а вимірюванні опору вздовж осі `[100]`.
- `π₄₄`: Сдвіговий (зсувний) п'єзорезистивний коефіцієнт при прикладанні зсувного напруження `σ₁₂` у площині `(100)`.

### Перетворення компонентів при повороті системи координат

У реальних MEMS-датчиках п'єзорезистори формуються на поверхні напівпровідникових пластин (наприклад, на пластині `(100)` або `(111)`), а струм протікає під довільним кутом до головних кубічних осей.

Нехай вектор напрямку електричного струму задано напрямними косинусами `l₁ = (l₁, m₁, n₁)`, а вектор одноосьового механічного напруження `σ` — напрямними косинусами `l₂ = (l₂, m₂, n₂)` відносно кубічних осей `[100]`, `[010]`, `[001]`.

Загальний вираз для відносної зміни питомого опору має вигляд:

```
Δρ / ρ₀ = π_L · σ_L  +  π_T · σ_T
```

де `π_L` — поздовжній п'єзорезистивний коефіцієнт (струм та напруження сонапрямлені: `l₁ = l₂`), `π_T` — поперечний п'єзорезистивний коефіцієнт (струм та напруження ортогональні: `l₁ ⊥ l₂`).

#### Виведення формули для поздовжнього коефіцієнта π_L

Застосовуючи тензорне правило перетворення координат для вектора з напрямними косинусами `(l, m, n)`, отримуємо загальну формулу поздовжнього коефіцієнта `π_L`:

```
π_L = π₁₁ - 2 · (π₁₁ - π₁₂ - π₄₄) · (l² m² + m² n² + l² n²)
```

Коефіцієнт `Ω = π₁₁ - π₁₂ - π₄₄` називається **коефіцієнтом анізотропії п'єзоопору**. Якщо `Ω = 0`, кристал є повністю ізотропним за п'єзорезистивними властивостями.

#### Виведення формули для поперечного коефіцієнта π_T

Для поперечної конфігурації, коли вектор струму має косинуси `(l₁, m₁, n₁)`, а вектор напруження — `(l₂, m₂, n₂)` за умови `l₁ l₂ + m₁ m₂ + n₁ n₂ = 0`, поперечний коефіцієнт описується виразом:

```
π_T = π₁₂ + (π₁₁ - π₁₂ - π₄₄) · (l₁² l₂² + m₁² m₂² + n₁² n₂²)
```

### Розрахунок коефіцієнтів для головних кристалографічних орієнтацій

Проаналізуємо практичні значення коефіцієнтів `π_L` та `π_T` для трьох ключових напрямків кремнієвих пластин.

#### 1. Орієнтація вздовж осі [100] (Пластина (100))

Напрямні косинуси вектора струму та напруження: `l = 1, m = 0, n = 0`.
Обчислимо комбінацію косинусів:

```
l² m² + m² n² + l² n²
= 1² · 0²  +  0² · 0²  +  1² · 0²    [підстановка напрямних косинусів l=1, m=0, n=0]
= 0                                   [перемноження та сумування добутків]
```

Отримуємо:

```
π_L[100] = π₁₁
π_T[100] = π₁₂
```

Для n-тип кремнію `π₁₁ ≈ -102.2 × 10⁻¹¹ Pa⁻¹`, тому орієнтація `[100]` є оптимальною для створення n-тип п'єзодатчиків.

#### 2. Орієнтація вздовж осі [110] (Стандартна пластина (100) MEMS)

Напрямні косинуси для осі `[110]`: `l = 1/√2, m = 1/√2, n = 0`.
Обчислимо комбінацію косинусів:

```
l² m² + m² n² + l² n²
= (1/2) · (1/2)  +  (1/2) · 0  +  (1/2) · 0    [підстановка косинусів l=1/√2, m=1/√2, n=0]
= 1/4                                          [перемноження дробових компонентів]
= 0.25                                         [переведення у десятковий дріб]
```

Підставляємо значення у формулу поздовжнього коефіцієнта `π_L`:

```
π_L[110]
= π₁₁ - 2 · (π₁₁ - π₁₂ - π₄₄) · (1/4)      [підстановка комбінації косинусів 1/4]
= π₁₁ - (1/2) · π₁₁ + (1/2) · π₁₂ + (1/2) · π₄₄ [розкривання дужок із множником 2/4 = 1/2]
= (1/2) · (π₁₁ + π₁₂ + π₄₄)                [зведення подібних доданків π₁₁ - ½ π₁₁ = ½ π₁₁]
```

Аналогічно обчислюємо поперечний коефіцієнт `π_T[110]` для струму вздовж `[110]` та напруження вздовж `[1̄10]`:

```
π_T[110] = (1/2) · (π₁₁ + π₁₂ - π₄₄)
```

Для p-тип кремнію значення коефіцієнта `π₄₄ ≈ +138.1 × 10⁻¹¹ Pa⁻¹` значно перевищує значення `π₁₁` (`+6.6`) та `π₁₂` (`-1.1`).
Тому отримуємо:

```
π_L[110] ≈ (1/2) · π₄₄ ≈ +71.8 × 10⁻¹¹ Pa⁻¹
π_T[110] ≈ -(1/2) · π₄₄ ≈ -68.7 × 10⁻¹¹ Pa⁻¹
```

Поздовжній та поперечний коефіцієнти мають майже однаковий модуль, але протилежні знаки. Саме ця властивість дозволяє будувати високочутливі мостові схеми Вітстона на пластинах `(100)` із p-резисторами.

#### 3. Орієнтація вздовж осі [111] (Максимум чутливості p-Si)

Напрямні косинуси для осі `[111]`: `l = 1/√3, m = 1/√3, n = 1/√3`.
Обчислимо комбінацію косинусів:

```
l² m² + m² n² + l² n²
= (1/3) · (1/3) + (1/3) · (1/3) + (1/3) · (1/3)    [підстановка косинусів l=m=n=1/√3]
= 1/9 + 1/9 + 1/9                                  [перемноження квадратів напрямних косинусів]
= 3/9 = 1/3                                        [сумування трьох однакових дробив та скорочення]
```

Підставляємо значення у формулу `π_L`:

```
π_L[111]
= π₁₁ - 2 · (π₁₁ - π₁₂ - π₄₄) · (1/3)              [підстановка кутової суми 1/3]
= π₁₁ - (2/3) · π₁₁ + (2/3) · π₁₂ + (2/3) · π₄₄     [розкривання дужок із множником 2/3]
= (1/3) · (π₁₁ + 2 π₁₂ + 2 π₄₄)                    [зведення подібних доданків π₁₁ - ⅔ π₁₁ = ⅓ π₁₁]
```

Для p-тип кремнію підстановка числових значень дає абсолютний рекорд п'єзорезистивної чутливості:

```
π_L[111] ≈ (2/3) · π₄₄ ≈ +93.5 × 10⁻¹¹ Pa⁻¹
```

### Математична модель температурного та легувального факторів P(N, T)

Експериментально виміряний коефіцієнт п'єзоопору `π(N, T)` при довільній температурі `T` та концентрації домішок `N` зв'язаний із фундаментальним значенням слаболегованого кристала при `300 K` (`π₀`) через феноменологічний **п'єзорезистивний фактор Kanda — Piezoresistive Factor `P(N, T)`**:

```
π(N, T) = π₀ · P(N, T)
```

Для n-тип кремнію п'єзорезистивний фактор обчислюється через відношення інтегралів Фермі — Дірака `F_k(η)`, де `η = (E_F - E_c) / (k_B T)` — зведела енергія Фермі:

```
P(N, T) = (300 / T) · [ F_(-1/2)(η) / F_(1/2)(η) ]
```

Аналітичне наближення формули Кандера для діапазону температур `200 K ≤ T ≤ 450 K` та концентрацій легування `10¹5 cm⁻³ ≤ N ≤ 10²0 cm⁻³` виражається емпіричним виразом:

```
P(N, T) = 1 / [ 1 + (N / N_ref)^α · (300 / T)^β ]
```

де для p-кремнію опорні параметри становлять:
- `N_ref = 1.4 × 10¹⁹ cm⁻³` (критична концентрація виродження);
- `α = 0.72` (показник концентраційного насичення);
- `β = 0.85` (показник температурної деградації).

З цієї моделі випливає важливий практичний висновок: при високих рівнях легування (`N > 10¹⁹ cm⁻³`) п'єзорезистивний коефіцієнт зменшується в 3–5 разів, однак при цьому температурна стабільність датчика (зниження температурного коефіцієнта чутливості TCGF) суттєво покращується.

### Крок-за-кроком приклад обчислення вихідної напруги датчика

**Постановка задачі:**
Розрахувати відносну зміну опору `ΔR / R₀` та вихідну напругу `V_out` мостової схеми Вітстона з p-тип п'єзорезисторами, розміщеними на кремнієвій пластині `(100)` вздовж осей `[110]`.

Вхідні дані:
- Живлення моста: `V_in = 5.0` Вольт
- Одноосьове деформаційне напруження: `σ_L = 100` МПа (`100 × 10⁶` Па)
- П'єзорезистивні коефіцієнти p-кремнію: `π₁₁ = +6.6 × 10⁻¹¹ Pa⁻¹`, `π₁₂ = -1.1 × 10⁻¹¹ Pa⁻¹`, `π₄₄ = +138.1 × 10⁻¹¹ Pa⁻¹`.
- Робоча температура: `T = 300 K`, помірне легування (`P(N, T) = 1.0`).

#### Крок 1: Обчислення поздовжнього коефіцієнта π_L[110]

```
π_L
= (1/2) · (π₁₁ + π₁₂ + π₄₄)
= (1/2) · ( 6.6 × 10⁻¹¹  -  1.1 × 10⁻¹¹  +  138.1 × 10⁻¹¹ )      [підстановка компонентів]
= (1/2) · ( 143.6 × 10⁻¹¹ )                                      [сумування в дужках]
= +71.8 × 10⁻¹¹ Pa⁻¹                                             [ділення на 2]
```

#### Крок 2: Обчислення відносного приросту опору ΔR / R₀

```
ΔR / R₀
= π_L · σ_L
= (71.8 × 10⁻¹¹ Pa⁻¹) · (100 × 10⁶ Pa)     [підстановка напруження 100 МПа]
= 71.8 × 10⁻³                              [скорочення степенів 10⁻¹¹ · 10⁶ = 10⁻⁵]
= 0.0718                                   [переведення у десятковий дріб]
= +7.18%                                   [у відсотках]
```

#### Крок 3: Обчислення вихідної напруги моста V_out

Для повного моста Вітстона з плечима `R₁ = R₃ = R₀ (1 + ΔR/R₀)` та `R₂ = R₄ = R₀ (1 - ΔR/R₀)` диференціальна напруга виражається формулою:

```
V_out
= V_in · (ΔR / R₀)
= 5.0 V · 0.0718                            [підстановка живлення та відносного опору]
= 0.359 V                                   [множення]
= 359 мВ                                    [переведення у мілівольти]
```

Таким чином, помірне механічне напруження 100 МПа створює потужний вихідний сигнал 359 мілівольт, який не вимагає високопрецизійного підсилення перед подачею на аналого-цифровий перетворювач (АЦП).
