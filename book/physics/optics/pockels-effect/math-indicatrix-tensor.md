# 🧮 Математична теорія оптичної індикатриси та електрооптичного тензора

Математичний апарат тензорного опису оптичної індикатриси (еліпсоїда покажчиків заломлення), аналітичне виведення повороту головних осей кристала під дією зовнішнього електричного поля та розрахунок напівхвильової напруги `V_π` для поздовжньої та поперечної геометрій.

---

### 1. Канонічне рівняння оптичної індикатриси

У прозорому анізотропному діелектрику зв'язок між вектором електричної індукції `D` та вектором напруженості електричного поля `E` задається тензором оптичної діелектричної проникності `ε`:

```
D_i = ε_0 · ∑_j ε_ij · E_j
```

В оптично дисипативно незамкненій та неактивній оптичній системі тензор `ε_ij` є симетричним (`ε_ij = ε_ji`), тому існує така система ортогональних координаторних осей `(x_1, x_2, x_3)` — головних осей кристала — у якій цей тензор стає діагональним із головними значеннями `ε_11 = n_1²`, `ε_22 = n_2²`, `ε_33 = n_3²`.

Оптична індикатриса (еліпсоїд покажчиків заломлення) визначається як геометрична поверхня постійної густини електромагнітної енергії `w = 1 / (2·ε_0) · D · E = 1`:

```
x_1² / n_1² + x_2² / n_2² + x_3² / n_3² = 1   [канонічне рівняння індикатриси]
```

У загальному вигляді (у довільній системі координат, яка не збігається з головними осями) рівняння трьохвісного еліпсоїда описується тензором оптичної непроникності `η = ε⁻¹ = (1 / n²)`:

```
η_11·x_1² + η_22·x_2² + η_33·x_3² + 2·η_23·x_2·x_3 + 2·η_13·x_1·x_3 + 2·η_12·x_1·x_2 = 1
```

У головних осях незбуреного кристала всі перехресні коефіцієнти `η_ij` (де `i ≠ j`) дорівнюють нулю, а діагональні коефіцієнти становлять `η_11 = 1 / n_1²`, `η_22 = 1 / n_2²`, `η_33 = 1 / n_3²`.

### 2. Тензор Поккельса та нотація Фогта

При прикладанні зовнішнього низькочастотного або постійного електричного поля `E = (E_1, E_2, E_3)` компоненти тензора оптичної непроникності `η_ij` змінюються за лінійним законом:

```
Δη_ij = ∑_k r_ijk · E_k
```

де `r_ijk` — тензор лінійного електрооптичного ефекту (тензор Поккельса) 3-го рангу, що містить `3 × 3 × 3 = 27` компонент. Оскільки тензор оптичної непроникності є симетричним (`Δη_ij = Δη_ji`), тензор Поккельса є симетричним по перших двох індексах: `r_ijk = r_jik`.

Це дозволяє спростити індексацію за нотацією Фогта (Voigt notation), зменшуючи пару симетричних індексів `(ij)` до одного індексу `m` від 1 до 6:

```
(11) → 1,   (22) → 2,   (33) → 3
(23) → 4,   (13) → 5,   (12) → 6
```

Тензор Поккельса перетворюється на матрицю `r_mk` розміром `6 × 3` (6 рядків, 3 стовпчики):

```
┌ Δη_1 ┐   ┌ r_11  r_12  r_13 ┐
│ Δη_2 │   │ r_21  r_22  r_23 │
│ Δη_3 │ = │ r_31  r_32  r_33 │ · ┌ E_1 ┐
│ Δη_4 │   │ r_41  r_42  r_43 │   │ E_2 │
│ Δη_5 │   │ r_51  r_52  r_53 │   └ E_3 ┘
└ Δη_6 ┘   └ r_61  r_62  r_63 ┘
```

Для конкретного кристалографічного класу більшість компонентів `r_mk` дорівнюють нулю або пов'язані між собою симетрією.

### 3. Математичний аналіз деформації індикатриси кристала KDP (клас 4̄2m)

Розглянемо кристал дигідрофосфату калію (`KH₂PO₄` або KDP). Кристал є одноосним та належить до тетрагональної точкової групи симетрії `4̄2m`. У незбуреному стані його покажчики заломлення дорівнюють `n_1 = n_2 = n_o` (звичайний промінь) та `n_3 = n_e` (надзвичайний промінь).

Завдяки симетрії `4̄2m` матриця Поккельса має лише три ненульові компоненти: `r_41 = r_52` та `r_63`. Усі інші коефіцієнти строго дорівнюють нулю:

```
┌ Δη_1 ┐   ┌  0     0     0   ┐
│ Δη_2 │   │  0     0     0   │
│ Δη_3 │ = │  0     0     0   │ · ┌ E_x ┐
│ Δη_4 │   │ r_41   0     0   │   │ E_y │
│ Δη_5 │   │  0    r_41   0   │   └ E_z ┘
└ Δη_6 ┘   └  0     0    r_63 ┘
```

Прикладемо електричне поле строго вздовж оптичної осі `z` кристала: `E = (0, 0, E_z)`.

Множення матриці на вектор поля дає єдиний ненульовий прирост `Δη_6 = r_63 · E_z`. Рівняння оптичної індикатриси набуває вигляду:

```
x² / n_o² + y² / n_o² + z² / n_e² + 2·r_63·E_z·x·y = 1
```

Наявність перехресного доданку `2·r_63·E_z·x·y` означає, що переріз еліпсоїда площиною `xy` перестав бути колом і повернувся відносно початкових осей `x, y`.

#### 3.1. Діагоналізація та повертання головних осей

Щоб привести рівняння до канонічного вигляду у площині `xy`, виконаємо поворот системи координат у площині `xy` на кут `θ = 45°` навколо осі `z`. Формули перетворення координат мають вигляд:

```
x = x'·cos(45°) - y'·sin(45°) = (x' - y') / √2
y = x'·sin(45°) + y'·cos(45°) = (x' + y') / √2
```

Підставимо вирази для `x` та `y` у рівняння індикатриси і виконаємо алгебраїчні перетворення:

```
x² + y² = ((x' - y')² + (x' + y')²) / 2 = x'² + y'²
2·x·y = 2 · ((x' - y')·(x' + y')) / 2 = x'² - y'²
```

Підставимо ці тотожності у рівняння індикатриси:

```
(x'² + y'²) / n_o² + z² / n_e² + r_63·E_z·(x'² - y'²) = 1
```

Згрупуємо доданки при `x'²` та `y'²`:

```
x'² · (1 / n_o² + r_63·E_z) + y'² · (1 / n_o² - r_63·E_z) + z² / n_e² = 1
```

Це рівняння є канонічним рівнянням тривісного еліпсоїда у нових головних осях `x', y', z`. Нові головні покажчики заломлення `n_x'` та `n_y'` дорівнюють:

```
1 / n_x'² = 1 / n_o² + r_63·E_z
1 / n_y'² = 1 / n_o² - r_63·E_z
```

Оскільки електрооптична деформація `r_63·E_z` є надзвичайно малою величиною порівняно з `1 / n_o²` (порядок `10⁻⁵` проти `0.4`), скористаємося першим членом диференціального розкладу в ряд Тейлора для функції `f(η) = η^(-1/2)`:

```
d(1 / n²) = -2 / n³ · dn
⇒ Δη = -1 / 2 · n³ · Δη_i
```

Отримуємо значення нових покажчиків заломлення:

```
n_x' ≈ n_o - 1 / 2 · n_o³ · r_63 · E_z
n_y' ≈ n_o + 1 / 2 · n_o³ · r_63 · E_z
```

#### 3.2. Індуковане двозаломлення та фазовий набіг

Індукована різниця покажчиків заломлення між двома ортогонально поляризованими хвильними компонентами, що поширюються вздовж осі `z`:

```
Δn = n_y' - n_x' = n_o³ · r_63 · E_z
```

При проходженні кристала завдовжки `L` фазові набіги компонентів `x'` та `y'` становлять:

```
φ_x' = (2π / λ) · n_x' · L
φ_y' = (2π / λ) · n_y' · L
```

Загальна фазова різниця (різниця фазових набігів / фазове запізнення `Γ`):

```
Γ = φ_y' - φ_x' = (2π / λ) · (n_y' - n_x') · L = (2π / λ) · n_o³ · r_63 · E_z · L
```

### 4. Виведення напівхвильової напруги V_π

Напівхвильова напруга `V_π` (half-wave voltage) — це значення напруги, прикладеної до комірки Поккельса, яке створює фазову різницю `Γ = π` радіан (що відповідає запізненню на півдовжини хвилі `λ / 2`).

#### 4.1. Поздовжня геометрія (Longitudinal)

У поздовжній геометрії електричне поле `E_z` спрямоване вздовж напрямку поширення світлового променя `z`. Електрична напруга `V` прикладається між вхідною та вихідною гранями кристала завдовжки `L`:

```
E_z = V / L
```

Підставимо `E_z` у формулу для фазової різниці `Γ`:

```
Γ = (2π / λ) · n_o³ · r_63 · (V / L) · L = (2π / λ) · n_o³ · r_63 · V
```

Довжина кристала `L` у чисельнику та знаменнику скорочується!

Прирівняємо `Γ = π` для знаходження `V_π`:

```
π = (2π / λ) · n_o³ · r_63 · V_π
⇒ 1 = (2 / λ) · n_o³ · r_63 · V_π
⇒ V_π = λ / (2 · n_o³ · r_63)        [формула поздовжньої напівхвильової напруги]
```

**Фундаментальний висновок:** у поздовжній комірці Поккельса напівхвильова напруга `V_π` принципово **не залежить від геометричних розмірів кристала** (ні від довжини `L`, ні від поперечного перерізу). Вона визначається виключно довжиною хвилі світла `λ` та матеріальними константами кристала (`n_o` та `r_63`).

##### Докладний чисельний розрахунок для кристала DKDP:
Розглянемо кристал дейтерованого KDP (`KD₂PO₄`, ступінь дейтерування 98%). Для випромінювання Nd:YAG лазера з довжиною хвилі `λ = 1064 нм`:
- Звичайний покажчик заломлення: `n_o = 1.50`
- Електрооптичний коефіцієнт: `r_63 = 26.4·10⁻¹² м/В`

Виконаємо покрокове підставлення у формулу:

```
V_π = 1064·10⁻⁹ / (2 · (1.50)³ · 26.4·10⁻¹²)
V_π = 1064·10⁻⁹ / (2 · 3.375 · 26.4·10⁻¹²)
V_π = 1064·10⁻⁹ / (1.782·10⁻¹⁰) = 5970 В ≈ 5.97 кВ
```

Для порівняння, для незаміщеного кристала KDP (`r_63 = 10.5 пм/В`) аналогічний розрахунок дає `V_π ≈ 7.5 кВ`. Заміна водню на дейтерій зменшує напівхвильову напругу на 20%.

#### 4.2. Поперечна геометрія (Transverse)

У поперечній геометрії електричне поле прикладається перпендикулярно до напрямку поширення світла. Наприклад, у кристалі ніобату літію (`LiNbO₃`, тригональна група `3m`) світло поширюється вздовж осі `x`, а електричне поле `E_z` прикладається вздовж оптичної осі `z` між бічними електродами, відстанню `d`.

Тензорна компонента `r_33` дає зміну покажчика заломлення для світла, поляризованого вздовж осі `z`:

```
Δn_z = -1 / 2 · n_e³ · r_33 · E_z
```

Напруженість поля виражається через напругу на електродах `V` та товщину кристала `d`: `E_z = V / d`.

Фазовий набіг на довжині кристала `L`:

```
Γ = (2π / λ) · (1 / 2 · n_e³ · r_33 · (V / d)) · L = (π / λ) · n_e³ · r_33 · V · (L / d)
```

Прирівняємо `Γ = π` для розрахунку `V_π`:

```
π = (π / λ) · n_e³ · r_33 · V_π · (L / d)
⇒ V_π = (λ / (n_e³ · r_33)) · (d / L)    [формула поперечної напівхвильової напруги]
```

Завдяки геометричному фактору `(d / L)` (відношенню товщини кристала до його довжини) напівхвильова напруга може бути зменшена в десятки разів.

##### Докладний чисельний розрахунок для кристала LiNbO3:
Розглянемо інтегрально-оптичний хвилевід на підкладці `LiNbO₃` для телекомунікаційної довжини хвилі `λ = 1550 нм`:
- Надзвичайний покажчик заломлення: `n_e = 2.14`
- Електрооптичний коефіцієнт: `r_33 = 30.8·10⁻¹² м/В`
- Довжина електродного плеча: `L = 40 мм = 0.04 м`
- Зазор між копланарними електродами: `d = 10 мкм = 10⁻⁵ м`

Розрахуємо значення `V_π`:

```
V_π = (1550·10⁻⁹ / ((2.14)³ · 30.8·10⁻¹²)) · (10·10⁻⁶ / 40·10⁻³)
V_π = (1550·10⁻⁹ / (9.80 · 30.8·10⁻¹²)) · (2.5·10⁻⁴)
V_π = 5.13·10³ В · 2.5·10⁻⁴ = 1.28 В
```

Керуюча напівхвильова напруга знижується з кіловольт до всього **1.28 Volt**, що дозволяє керувати модулятором безпосередньо від високошвидкісних транзисторних мікросхем CMOS чи SiGe з частотою модуляції понад 100 ГГц.
