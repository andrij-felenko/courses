# 🧮 Математичний апарат дифракції: від інтеграла Гюйгенса — Френеля до хвильового рівняння

Ця вставка містить вивід фундаментальних рівнянь хвильової дифракції світла. У ній детально подано математичний перехід від тривимірного скалярного хвильового рівняння та другої теореми Ґріна до інтеграла Френеля — Кірхгофа, обґрунтовано граничні умови Кірхгофа та умови випромінювання Зоммерфельда, розкрито параксіальне квадратичне наближення Френеля (близьке поле) та лінійне наближення Фраунгофера (далеке поле як перетворення Фур'є), а також наведено точне інтегрування для 1D-щілини та круглого отвору з виводом функції Бесселя та плями Ейрі.

---

### 1. Скалярне хвильове рівняння та теорема Ґріна

У однорідному прозорому діелектричному середовищі без вільних зарядів і струмів кожна компонента електромагнітного поля задовольняє тривимірне скалярне хвильове рівняння:

```
∇² U(r, t) - (1 / v²) · (∂²U / ∂t²) = 0     [Хвильове рівняння]
```

де `v = c / n` — фазова швидкість світла у середовищі з показником заломлення `n`.

Для монохроматичного випромінювання з коловою частотою `ω` шукаємо розв'язок у вигляді часового гармонічного коливання:
```
U(r, t) = Re[ E(r) · exp(-i · ω · t) ]
```

Підставляючи цю форму у хвильове рівняння та скорочуючи часовий множник `exp(-i·ω·t)`, отримуємо **однорідне рівняння Гельмгольца**:

```
∇² E(r) + k² · E(r) = 0     [Рівняння Гельмгольца]
```

де `k = ω / v = 2π · n / λ` — хвильове число у середовищі.

#### Застосування другої теореми Ґріна

Нехай `V` — об'єм, обмежений замкненою поверхнею `S`. Нехай `E(r)` — шукане поле, а `G(r)` — фундаментальний розв'язок (функція Ґріна) для точкового джерела, розташованого у точці спостереження `P`:

```
G(r) = exp(i · k · r) / r     [Сферична хвиля Ґріна]
```

де `r` — відстань від змінної точки інтегрування до точки `P`.

Друга теорема Ґріна стверджує, що для двох тричі неперервно диференційовних скалярних функцій `E` та `G`:

```
∭_V (E · ∇²G - G · ∇²E) dV = ∬_S ( E · (∂G / ∂n) - G · (∂E / ∂n) ) dS
```

де `∂ / ∂n` позначує похідну вздовж внутрішньої нормалі `n` до поверхні `S`.

Оскільки у всьому об'ємі `V` (за винятком самої точки `P`) функції `E` та `G` задовольняють рівняння Гельмгольца (`∇²E = -k² E` та `∇²G = -k² G`), ліва частина інтеграла дорівнює нулю:

```
E · ∇²G - G · ∇²E = E · (-k² G) - G · (-k² E) = 0
```

Оточивши точку `P` маленькою сферою радіуса `ε` і спрямувавши `ε → 0`, отримуємо фундаментальну **інтегральну формулу Гюйгенса — Кірхгофа**:

```
E(P) = (1 / 4π) · ∬_S [ E · (∂ / ∂n)(exp(i·k·r) / r) - (exp(i·k·r) / r) · (∂E / ∂n) ] dS
```

### 2. Граничні умови Кірхгофа та похилий множник

Нехай плоский непрозорий екран із вирізаним отвором `A` розділяє простір на дві півсфери. Обчислимо поле у правій півсфері. Замкнена поверхня інтегрування `S` складається з трьох частин:
1. Площі самого отвору `A`;
2. Непрозорої задньої поверхні екрана `B`;
3. Нескінченно віддаленої напівсфери `S_inf`.

Густав Кірхгоф сформулював такі фізичні граничні умови:
- На відкритому отворі `A`: поле `E` та його нормальна похідна `∂E/∂n` точно збігаються з полем первинної незатененної хвилі `E_in`.
- На непрозорому екрані `B`: поле та його похідна дорівнюють нулю (`E = 0`, `∂E/∂n = 0`).
- На нескінченній півсфері `S_inf`: інтеграл перетворюється на нуль завдяки **умові випромінювання Зоммерфельда** (*Sommerfeld radiation condition*), яка гарантує, що хвилі лише відходять від джерела на нескінченність, а не повертаються з нескінченності.

#### Вивід похилого множника Кірхгофа

Якщо на отвір `A` падає сферична хвиля від точкового джерела `S`, розташованого на відстані `r₀` від отвору `E_in = E₀ · exp(i · k · r₀) / r₀`, обчислимо нормальні похідні:

```
(∂ / ∂n)( exp(i·k·r₀) / r₀ ) ≈ i · k · cos(n, r₀) · ( exp(i·k·r₀) / r₀ )
(∂ / ∂n)( exp(i·k·r) / r )   ≈ i · k · cos(n, r)  · ( exp(i·k·r) / r )
```

де підставили `k · r ≫ 1` (відстані значно більші за довжину хвилі).

Підставляючи ці похідні в інтеграл Гюйгенса — Кірхгофа, отримуємо підсумкову **інтегральну формулу Френеля — Кірхгофа**:

```
E(P) = - (i / 2λ) · E₀ · ∬_A ( exp(i · k · (r₀ + r)) / (r₀ · r) ) · K(θ) dS
```

де `K(θ)` — **похилий множник Кірхгофа** (*obliquity factor*):

```
K(θ) = ( cos θ₀ + cos θ ) / 2     [Похилий множник Кірхгофа]
```

Тут `θ₀` — кут між нормаллю до екрана `n` та напрямком падіння променя від джерела `S`, а `θ` — кут між нормаллю та дифрагованим променем до точки спостереження `P`.

*Фізичний аналіз похилого множника:*
- Для променя, що поширюється строго прямо вперед (`θ₀ = 0`, `θ = 0`), `K(0) = (1 + 1) / 2 = 1` (максимальне випромінювання).
- Для променя, що відхиляється на кут `90°` (`θ = π/2`), `K(π/2) = (1 + 0) / 2 = 0.5`.
- Для зворотної хвилі (`θ = π`), `K(π) = (1 - 1) / 2 = 0`. Це математично пояснює, чому вторинні хвилі Гюйгенса **не поширюються у зворотному напрямку**.

### 3. Наближення Френеля (параксіальне близьке поле)

Розглянемо падіння монохроматичної плоскої хвилі амплітуди `E₀` вздовж осі `Z` на плоский отвір у площині `(x', y')`. Точка спостереження знаходиться у площині `(x, y)` на відстані `z`.

Точна відстань `r` між точкою апертури `(x', y', 0)` та точкою екрана `(x, y, z)` дорівнює:

```
r = √( z² + (x - x')² + (y - y')² )
```

Винесемо `z` за знак кореня і застосуємо степеневий розклад Тейлора `√(1 + α) = 1 + α/2 - α²/8 + ...`:

```
r = z · [ 1 + ((x - x')² + (y - y')²) / (2z²) - ((x - x')² + (y - y')²)² / (8z⁴) + ... ]
r = z + ((x - x')² + (y - y')²) / (2z) - ((x - x')² + (y - y')²)² / (8z³) + ...
```

Для знаменника у виразі амплітуди підставимо `r ≈ z`. 

Для фазового множника `exp(i · k · r)` збережемо квадратичний член і знехтуємо членами четвертого порядку. Це допустимо, якщо максимальна фазова похибка від відкинутого члена менша за `π`:

```
k · ((x - x')² + (y - y')²)² / (8z³) ≪ π     [Умова параксіальності Френеля]
```

Отримуємо **інтеграл дифракції Френеля**:

```
E(x, y, z) = (exp(i·k·z) / (i·λ·z)) · ∬_A E(x', y') · exp( (i·k / (2z)) · ((x - x')² + (y - y')²) ) dx' dy'
```

Розкриваючи квадрат `(x - x')² = x² - 2x x' + x'²`, винесемо множник `exp(i·k·(x²+y²)/(2z))` за знак інтеграла:

```
E(x, y, z) = C(z) · ∬_A [ E(x', y') · exp(i·k·(x'²+y'²)/(2z)) ] · exp( -i · (k/z) · (x x' + y y') ) dx' dy'
```

де `C(z) = (exp(i·k·z) / (i·λ·z)) · exp(i·k·(x² + y²) / (2z))`.

Ввівши **число Френеля** `N_F = a² / (λ · z)`, режим дифракції Френеля відповідає умовам `N_F ≳ 1`.

### 4. Наближення Фраунгофера (далеке поле як перетворення Фур'є)

Якщо відстань `z` від апертури до екрана стає настільки великою, що навіть квадратичний фазовий член у площині апертури стає значно меншим за `π`:

```
k · (x'² + y'²) / (2z) ≪ π     ⇒   z ≫ a² / λ     [Умова далекого поля Фраунгофера, N_F ≪ 1]
```

тоді квадратичний фазовий множник `exp(i · k · (x'² + y'²) / (2z)) ≈ 1`.

Підставляючи це спрощення в інтеграл Френеля, отримуємо **інтеграл дифракції Фраунгофера**:

```
E(u, v) = C(z) · ∬_A E(x', y') · exp( -i · (u · x' + v · y') ) dx' dy'
```

де просторові частоти `u` та `v` зв'язані з координатами екрана та кутами дифракції `θ_x`, `θ_y`:

```
u = k · x / z = (2π / λ) · sin θ_x
v = k · y / z = (2π / λ) · sin θ_y
```

Вираз `∬_A E(x', y') · exp(-i · (u x' + v y')) dx' dy'` є точним двовимірним **просторовим перетворенням Фур'є** `F{E(x', y')}` від амплітудної маски апертури!

### 5. Точне інтегрування для 1D-щілини

Розглянемо прямокутну щілину шириною `a` (від `-a/2` до `+a/2`), освічену пласкою хвилею амплітуди `E₀`.

Обчислимо інтеграл Фраунгофера вздовж осі `X`:

```
E(u) = C₀ · ∫_{-a/2}^{+a/2} exp(-i · u · x') dx'
```

Виконуємо точне інтегрування показникової функції:

```
∫_{-a/2}^{+a/2} exp(-i · u · x') dx'
= [ exp(-i · u · x') / (-i · u) ]_{-a/2}^{+a/2}
= ( exp(i · u · a / 2) - exp(-i · u · a / 2) ) / (i · u)
= 2 · sin(u · a / 2) / u
= a · [ sin(u · a / 2) / (u · a / 2) ]
```

Ввівши фазовий параметр `β = u · a / 2 = (π · a · sin θ) / λ`, отримуємо комплексне поле:

```
E(θ) = E₀ · a · ( sin β / β )
```

Підносячи амплітуду до квадрата `I(θ) = |E(θ)|²`, маємо підсумкову **формулу інтенсивності на щілині**:

```
I(θ) = I₀ · ( sin β / β )²     [Розподіл інтенсивності 1D-щілини]
```

*Аналітичний розбір функцій:*
- Точна границя при `β → 0`: `lim_{β→0} (sin β / β) = 1`, звідси `I(0) = I₀`.
- Точні нулі (мінімуми інтенсивності `I = 0`): `sin β = 0` при `β = m · π` (`m = ±1, ±2, ...`):

```
(π · a · sin θ) / λ = m · π   ⇒   a · sin θ = m · λ     [Умова мінімумів]
```

### 6. Дифракція на круглому отворі: Функції Бесселя та Формула Ейрі

Для круглого отвору радіуса `R = D / 2` перейдемо до полярних координат в апертурі `(ρ', φ')` та на екрані `(w, ψ)`:
```
x' = ρ' · cos φ',   y' = ρ' · sin φ',   dx' dy' = ρ' dρ' dφ'
x = w · cos ψ,      y = w · sin ψ
```

Скалярний добуток в експоненті дорівнює `u x' + v y' = k · ρ' · (w / z) · cos(φ' - ψ)`.

Інтеграл Фраунгофера набуває вигляду:

```
E(w) = C₀ · ∫₀ʳ ρ' dρ' ∫₀²ᵖ exp( -i · k · ρ' · (w / z) · cos(φ' - ψ) ) dφ'
```

Внутрішній інтеграл за кутом `φ'` описує канонічне інтегральне представлення **функції Бесселя першого роду нульового порядку** `J₀`:

```
J₀(x) = (1 / 2π) · ∫₀²ᵖ exp(-i · x · cos φ) dφ
```

Тоді інтеграл за радіусом береться за допомогою рекурентного співвідношення для функцій Бесселя `∫ x · J₀(x) dx = x · J₁(x)`:

```
∫₀ʳ ρ' · J₀( k · ρ' · sin θ ) dρ' = R² · [ J₁(k · R · sin θ) / (k · R · sin θ) ]
```

Ввівши безрозмірний параметр `q = k · R · sin θ = (π · D · sin θ) / λ`, отримуємо розподіл амплітуди:

```
E(q) = E₀ · (π · R²) · [ 2 · J₁(q) / q ]
```

Підносячи до квадрата, отримуємо фундаментальну **формулу Ейрі** (*Airy pattern*):

```
I(θ) = I₀ · [ 2 · J₁(q) / q ]²     [Розподіл інтенсивності Ейрі]
```

Перший нуль функції Бесселя `J₁(q) = 0` розташований при значеннях аргументу `q₁ ≈ 3.8317`.

Звідси знаходимо кутовий радіус першого темного кільця плями Ейрі:

```
(π · D · sin θ₁) / λ = 3.8317   ⇒   sin θ₁ = (3.8317 / π) · (λ / D) ≈ 1.22 · (λ / D)
```

Це співвідношення `θ₁ = 1.22 · λ / D` є точним математичним підґрунтям **критерію роздільної здатності Релея** в оптиці.
