# 🧮 Виведення рівнянь Френеля з граничних умов Максвелла

Ця вставка містить детальний і суворий математичний вивід коефіцієнтів відбиття та заломлення Френеля безпосередньо з фундаментальної системи рівнянь Максвелла класичної електродинаміки. Ми розглянемо векторну структуру електромагнітних хвиль, встановимо умови узгодження фаз на межі, доведемо амплітудні формули для s- та p-поляризацій, розберемо енергетичні співвідношення на основі вектора Пойнтінга та виведемо формули Стокса.

### 1. Електромагнітна хвиля та векторний базис

Розглянемо плоску монокристалічну електромагнітну хвилю частоти `ω`, яка поширюється в однорідному, ізотропному, незарядженому середовищі. З рівнянь Максвелла випливає, що така хвиля описується векторами напруженості електричного поля `E` та магнітного поля `H`:

```
E(r, t) = E₀ · exp(i · (k · r - ω · t))
H(r, t) = H₀ · exp(i · (k · r - ω · t))
```

де `k` — хвильовий вектор, модуль якого дорівнює `|k| = k₀ · n = (ω / c) · n`, а `n` — показник заломлення середовища. У плоскій хвилі вектори `E`, `H` та `k` утворюють праву трійку взаємно перпендикулярних векторів. Модулі амплітуд полів пов'язані співвідношенням:

```
H₀ = (n / Z₀) · E₀
```

де `Z₀ = √(μ₀ / ε₀) ≈ 377 Ом` — фундаментальний хвильовий імпеданс вакууму. Для прозорих неферромагнітних діелектриків відносна магнітна проникність `μ = 1`, тому діелектрична проникність зв'язана з показником заломлення як `ε = n²`.

### 2. Геометрія межі та фазове узгодження

Нехай плоскопаралельна межа розділу між середовищем 1 (`n₁`) та середовищем 2 (`n₂`) збігається з площиною `z = 0`. Площина падіння хвилі збігається з площиною `x-z`, а нормаль до межі спрямована вздовж осі `z`.

Падаюча хвиля має хвильовий вектор `k₁ = (k₀ · n₁ · sin θ₁, 0, k₀ · n₁ · cos θ₁)`.
Відбита хвиля має хвильовий вектор `kᵣ = (k₀ · n₁ · sin θ₁, 0, -k₀ · n₁ · cos θ₁)`.
Заломлена хвиля має хвильовий вектор `k₂ = (k₀ · n₂ · sin θ₂, 0, k₀ · n₂ · cos θ₂)`.

Границя `z = 0` мусить виконувати умови неперервності полів у будь-який момент часу `t` та в будь-якій точці `x`. Це вимагає строгої рівності фазових множників уздовж поверхні розділу:

```
k₁ₓ = kᵣₓ = k₂ₓ
```

Підставляючи проєкції хвильових векторів на вісь `x`:

```
k₀ · n₁ · sin θ₁ = k₀ · n₁ · sin θᵣ = k₀ · n₂ · sin θ₂
```

З цієї рівності негайно випливають два фундаментальні закони геометричної оптики:
1. **Закон відбиття**: кут відбиття дорівнює куту падіння (`θᵣ = θ₁`).
2. **Закон заломлення Снелла**: `n₁ · sin θ₁ = n₂ · sin θ₂`.

### 3. Граничні умови Максвелла

Для довільної поверхні розділу двох середовищ без вільних поверхневих зарядів і струмів інтегральні рівняння Максвелла вимагають безумовної неперервності тангенціальних (паралельних до поверхні `z = 0`) компонент електричного й магнітного полів:

```
E₁ₓ(x, y, 0) = E₂ₓ(x, y, 0)
E₁ᵧ(x, y, 0) = E₂ᵧ(x, y, 0)
H₁ₓ(x, y, 0) = H₂ₓ(x, y, 0)
H₁ᵧ(x, y, 0) = H₂ᵧ(x, y, 0)
```

Оскільки вектор електричного поля падаючої хвилі можна розкласти на дві незалежні ортогональні поляризації — s-поляризацію (`E` паралельний осі `y`) та p-поляризацію (`E` лежить у площині `x-z`), вивід проводиться окремо для кожного випадку.

### 4. Докладне виведення для s-поляризації (TE-хвиля)

При s-поляризації (Transverse Electric) вектор електричного поля повністю спрямований уздовж осі `y`:

```
Eᵢ = (0, E₀ᵢ, 0)
Eᵣ = (0, E₀ᵣ, 0)
Eₜ = (0, E₀ₜ, 0)
```

Вектори магнітного поля `H = (k × E) / (ω · μ₀)` мають як `x`-, так і `z`-компоненти:

```
Hᵢ = (n₁ / Z₀) · E₀ᵢ · (-cos θ₁, 0, sin θ₁)
Hᵣ = (n₁ / Z₀) · E₀ᵣ · (cos θ₁, 0, sin θ₁)
Hₜ = (n₂ / Z₀) · E₀ₜ · (-cos θ₂, 0, sin θ₂)
```

Застосуємо граничну умову неперервності `Eᵧ` на поверхні `z = 0`:

```
E₀ᵢ + E₀ᵣ = E₀ₜ                   [1: Неперервність E_y]
```

Застосуємо граничну умову неперервності тангенціальної компоненти магнітного поля `Hₓ` на поверхні `z = 0`:

```
- (n₁ / Z₀) · E₀ᵢ · cos θ₁ + (n₁ / Z₀) · E₀ᵣ · cos θ₁ = - (n₂ / Z₀) · E₀ₜ · cos θ₂
```

Домноживши обидві частини на `-Z₀`, маємо:

```
n₁ · cos θ₁ · (E₀ᵢ - E₀ᵣ) = n₂ · cos θ₂ · E₀ₜ     [2: Неперервність H_x]
```

Отримано систему двох лінійних алгебраїчних рівнянь відносно шуканих амплітуд `E₀ᵣ` та `E₀ₜ`. Для знаходження амплітудного коефіцієнта відбиття `r⛛ = E₀ᵣ / E₀ᵢ` підставимо `E₀ₜ = E₀ᵢ + E₀ᵣ` із рівняння [1] у рівняння [2]:

```
n₁ · cos θ₁ · (E₀ᵢ - E₀ᵣ) = n₂ · cos θ₂ · (E₀ᵢ + E₀ᵣ)
```

Раскриємо дужки та перегрупуємо доданки з `E₀ᵢ` ліворуч, а з `E₀ᵣ` праворуч:

```
E₀ᵢ · (n₁ · cos θ₁ - n₂ · cos θ₂) = E₀ᵣ · (n₁ · cos θ₁ + n₂ · cos θ₂)
```

Розділивши на `E₀ᵢ · (n₁ · cos θ₁ + n₂ · cos θ₂)`, отримуємо першу амплітудну формулу Френеля для s-поляризації:

```
r⛛ = E₀ᵣ / E₀ᵢ = (n₁ · cos θ₁ - n₂ · cos θ₂) / (n₁ · cos θ₁ + n₂ · cos θ₂)   [Формула r_s]
```

Тепер знайдемо амплітудний коефіцієнт заломлення `t⛛ = E₀ₜ / E₀ᵢ`. Виразимо `E₀ᵣ = E₀ₜ - E₀ᵢ` з рівняння [1] і підставимо у рівняння [2]:

```
n₁ · cos θ₁ · (E₀ᵢ - (E₀ₜ - E₀ᵢ)) = n₂ · cos θ₂ · E₀ₜ
n₁ · cos θ₁ · (2·E₀ᵢ - E₀ₜ) = n₂ · cos θ₂ · E₀ₜ
2 · n₁ · cos θ₁ · E₀ᵢ = E₀ₜ · (n₁ · cos θ₁ + n₂ · cos θ₂)
```

Звідси отримуємо формулу амплітудного заломлення s-хвилі:

```
t⛛ = E₀ₜ / E₀ᵢ = (2 · n₁ · cos θ₁) / (n₁ · cos θ₁ + n₂ · cos θ₂)             [Формула t_s]
```

Звернемо увагу на важливе алгебраїчне співвідношення між коефіцієнтами:

```
1 + r⛛ = 1 + (n₁·cos θ₁ - n₂·cos θ₂) / (n₁·cos θ₁ + n₂·cos θ₂)
       = (n₁·cos θ₁ + n₂·cos θ₂ + n₁·cos θ₁ - n₂·cos θ₂) / (n₁·cos θ₁ + n₂·cos θ₂)  [зведення до спільного знаменника]
       = (2·n₁·cos θ₁) / (n₁·cos θ₁ + n₂·cos θ₂)                                   [скорочення n₂·cos θ₂]
       = t⛛                                                                         [за означенням t_s]
```

Отже, тотожність `1 + r⛛ = t⛛` виконується для s-поляризації безумовно при будь-яких кутах і показниках заломлення.

### 5. Докладне виведення для p-поляризації (TM-хвиля)

При p-поляризації (Transverse Magnetic) вектор магнітного поля повністю спрямований уздовж осі `y`:

```
Hᵢ = (0, H₀ᵢ, 0)
Hᵣ = (0, H₀ᵣ, 0)
Hₜ = (0, H₀ₜ, 0)
```

Вектори електричного поля `E` лежать у площині `x-z`:

```
Eᵢ = E₀ᵢ · (cos θ₁, 0, -sin θ₁)
Eᵣ = E₀ᵣ · (-cos θ₁, 0, -sin θ₁)
Eₜ = E₀ₜ · (cos θ₂, 0, -sin θ₂)
```

Застосуємо граничну умову неперервності тангенціальної компоненти електричного поля `Eₓ` при `z = 0`:

```
E₀ᵢ · cos θ₁ - E₀ᵣ · cos θ₁ = E₀ₜ · cos θ₂
cos θ₁ · (E₀ᵢ - E₀ᵣ) = cos θ₂ · E₀ₜ              [3: Неперервність E_x]
```

Застосуємо граничну умову неперервності магнітного поля `Hᵧ` при `z = 0`:

```
H₀ᵢ + H₀ᵣ = H₀ₜ
```

Виразивши магнітні поля через електричні `H = (n / Z₀) · E` та скоротивши на `1 / Z₀`:

```
n₁ · (E₀ᵢ + E₀ᵣ) = n₂ · E₀ₜ                       [4: Неперервність H_y]
```

Розв'яжемо систему рівнянь [3] і [4]. Підставимо `E₀ₜ = (n₁ / n₂) · (E₀ᵢ + E₀ᵣ)` із рівняння [4] у рівняння [3]:

```
cos θ₁ · (E₀ᵢ - E₀ᵣ) = cos θ₂ · (n₁ / n₂) · (E₀ᵢ + E₀ᵣ)
n₂ · cos θ₁ · (E₀ᵢ - E₀ᵣ) = n₁ · cos θ₂ · (E₀ᵢ + E₀ᵣ)
```

Раскриємо дужки та перегрупуємо доданки:

```
E₀ᵢ · (n₂ · cos θ₁ - n₁ · cos θ₂) = E₀ᵣ · (n₂ · cos θ₁ + n₁ · cos θ₂)
```

Звідси маємо амплітудний коефіцієнт відбиття p-поляризації `rₚ = E₀ᵣ / E₀ᵢ`:

```
rₚ = (n₂ · cos θ₁ - n₁ · cos θ₂) / (n₂ · cos θ₁ + n₁ · cos θ₂)   [Формула r_p]
```

Для знаходження коефіцієнта заломлення `tₚ = E₀ₜ / E₀ᵢ` виразимо `E₀ᵣ = (n₂ / n₁) · E₀ₜ - E₀ᵢ` із рівняння [4] і підставимо у рівняння [3]:

```
cos θ₁ · (E₀ᵢ - ((n₂ / n₁) · E₀ₜ - E₀ᵢ)) = cos θ₂ · E₀ₜ
cos θ₁ · (2·E₀ᵢ - (n₂ / n₁) · E₀ₜ) = cos θ₂ · E₀ₜ
2 · n₁ · cos θ₁ · E₀ᵢ = E₀ₜ · (n₁ · cos θ₂ + n₂ · cos θ₁)
```

Отже, амплітудний коефіцієнт заломлення p-хвилі дорівнює:

```
tₚ = (2 · n₁ · cos θ₁) / (n₂ · cos θ₁ + n₁ · cos θ₂)             [Формула t_p]
```

Для p-поляризації алгебраїчне співвідношення між коефіцієнтами має вигляд: `1 + rₚ = (n₂ / n₁) · (cos θ₂ / cos θ₁) · tₚ`.

### 6. Енергетичні коефіцієнти та вектор Пойнтінга

Митьовий потік енергії електромагнітного поля визначається вектором Пойнтінга `S = E × H`. Середній за періодом модуль вектора Пойнтінга для плоскої хвилі в середовищі з показником `n` становить:

```
⟨S⟩ = (1/2) · n · (1 / Z₀) · |E₀|²
```

Оскільки межа розділу знаходиться в площині `z = 0`, фізичний інтерес становить не повний потік енергії вздовж променя, а його **нормальна компонента** `S_z = ⟨S⟩ · cos θ`, яка перетинає одиницю площі поверхні розділу за одиницю часу:

```
Iᵢ,᲻ = (1/2) · (n₁ / Z₀) · |E₀ᵢ|² · cos θ₁   [Нормальний потік падаючої хвилі]
Iᵣ,᲻ = (1/2) · (n₁ / Z₀) · |E₀ᵣ|² · cos θ₁   [Нормальний потік відбитої хвилі]
Iₜ,᲻ = (1/2) · (n₂ / Z₀) · |E₀ₜ|² · cos θ₂   [Нормальний потік заломленої хвилі]
```

Енергетичний коефіцієнт відбиття `R` визначається як відношення нормального відбитого потоку до падаючого:

```
R = Iᵣ,᲻ / Iᵢ,᲻ = (|E₀ᵣ|² · cos θ₁) / (|E₀ᵢ|² · cos θ₁) = |E₀ᵣ / E₀ᵢ|² = |r|²
```

Отже, для обох поляризацій енергетична відбивність дорівнює просто квадрату модуля відповідного амплітудного коефіцієнта:

```
R⛛ = |r⛛|²
Rₚ = |rₚ|²
```

Енергетичний коефіцієнт пропущення `T` визначається як відношення нормального заломленого потоку до падаючого:

```
T = Iₜ,᲻ / Iᵢ,᲻ = (n₂ · cos θ₂ · |E₀ₜ|²) / (n₁ · cos θ₁ · |E₀ᵢ|²)
  = (n₂ · cos θ₂ / n₁ · cos θ₁) · |t|²
```

### 7. Доведення закону збереження енергії R + T = 1

Доведемо тотожне виконання закону збереження енергії `R⛛ + T⛛ = 1` для s-поляризації при довільних значеннях кутів `θ₁`, `θ₂` та показників `n₁`, `n₂`.

Обчислимо суму `R⛛ + T⛛`:

```
R⛛ = (n₁·cos θ₁ - n₂·cos θ₂)² / (n₁·cos θ₁ + n₂·cos θ₂)²
T⛛ = (n₂·cos θ₂ / n₁·cos θ₁) · [4 · n₁² · cos² θ₁ / (n₁·cos θ₁ + n₂·cos θ₂)²]
    = (4 · n₁ · n₂ · cos θ₁ · cos θ₂) / (n₁·cos θ₁ + n₂·cos θ₂)²
```

Зведемо обидва доданки до спільного знаменника `D = (n₁·cos θ₁ + n₂·cos θ₂)²`:

```
R⛛ + T⛛ = [ (n₁·cos θ₁ - n₂·cos θ₂)² + 4 · n₁ · n₂ · cos θ₁ · cos θ₂ ] / D          [зведення до спільного знаменника]
```

Раскриємо квадрат у чисельнику:

```
Чисельник = (n₁·cos θ₁ - n₂·cos θ₂)² + 4 · n₁ · n₂ · cos θ₁ · cos θ₂                  [раскриття квадрата різниці]
          = (n₁·cos θ₁)² - 2·n₁·n₂·cos θ₁·cos θ₂ + (n₂·cos θ₂)² + 4·n₁·n₂·cos θ₁·cos θ₂ [зведення подібних доданків]
          = (n₁·cos θ₁)² + 2·n₁·n₂·cos θ₁·cos θ₂ + (n₂·cos θ₂)²                      [згортання в квадрат суми]
          = (n₁·cos θ₁ + n₂·cos θ₂)²                                                  [квадрат суми: A² + 2AB + B² = (A+B)²]
          = D                                                                         [знаменник початкового дробу]
```

Оскільки чисельник строго дорівнює знаменнику `D`, маємо:

```
R⛛ + T⛛ = D / D = 1
```

Аналогічне алгебраїчне перетворення для p-поляризації дає точно такий самий результат: `Rₚ + Tₚ = 1`. Математична узгодженість рівнянь Френеля із фундаментальним законом збереження енергії доведена повністю.

### 8. Співвідношення взаємності Стокса

У 1849 році Джордж Габрієль Стокс застосував принцип обратності світлових променів (обратність часу в рівняннях Максвелла) до процедури відбиття й заломлення.

Якщо відбиту хвилю амплітуди `r · E₀` та заломлену хвилю амплітуди `t · E₀` розвернути в часі назад, вони мусять у результаті інтерференції дати вихідну падаючу хвилю амплітуди `E₀` та нульову хвилю в інших напрямках.

Нехай `r` та `t` — коефіцієнти при переході з середовища 1 у середовище 2, а `r'` та `t'` — коефіцієнти при зворотному переході з середовища 2 у середовище 1.

Стокс показав, що з принципів симетрії та обратності випливають **формули Стокса**:

```
r' = - r                          [1: Зміна знака при зворотному відбитті]
t · t' = 1 - r²                   [2: Зв'язок амплітудних коефіцієнтів]
```

Рівняння `r' = -r` показує, що якщо при відбитті від оптично густішого середовища виникає зсув фази на 180° (`r < 0`), то при відбитті зсередини цього середовища від межі з рідшим середовищем зсув фази відсутній (`r' > 0`). Це співвідношення відіграє ключову роль у теорії багатопроменевої інтерференції та інтерферометрів Фабрі-Перо.
