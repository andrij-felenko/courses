# ⚙️ Обчислення коефіцієнтів Френеля для довільних середовищ

Ця вставка містить практичну реалізацію алгоритму обчислення амплітудних (`r⛛`, `rₚ`, `t⛛`, `tₚ`) та енергетичних (`R⛛`, `Rₚ`, `T⛛`, `Tₚ`) коефіцієнтів Френеля. Програма підтримує розрахунок як для звичайних прозорих діелектриків (із дійсними показниками заломлення), так і для поглинальних середовищ та металів (із комплексними показниками заломлення `ñ = n + i·k`), а також автоматично враховує явище повного внутрішнього відбиття без створення окремих умовних розгалужень у коді.

### 1. Фізична та математична модель калькулятора

Для побудови універсального калькулятора оптики необхідно поширити класичний закон Снелла та формули Френеля на область комплексних чисел. Якщо перше середовище має комплексний показник заломлення `ñ₁ = n₁ + i·k₁`, а друге — `ñ₂ = n₂ + i·k₂`, то закон Снелла визначає комплексний синус кута заломлення:

```
sin θ₂ = (ñ₁ / ñ₂) · sin θ₁
```

Головне обчислювальне завдання полягає у правильному знаходженні значення косинуса кута заломлення `cos θ₂`. У комплексній аналітичній оптиці використовують фундаментальну тригонометричну тотожність:

```
cos θ₂ = √(1 - sin² θ₂)
```

Оскільки квадратний корінь із комплексного числа має дві гілки рішень, алгоритм вимагає вибору такої гілки, у якої дійсна частина `Re(cos θ₂) ≥ 0`, що відповідає поширенню заломленої хвилі вперед у друге середовище, або уявна частина `Im(cos θ₂) ≥ 0` для згасаючої (еванесцентної) хвилі при повному внутрішньому відбитті.

Після обчислення `cos θ₂` комплексні амплітудні коефіцієнти відбиття та заломлення розраховуються за загальними формулами:

```
r⛛ = (ñ₁·cos θ₁ - ñ₂·cos θ₂) / (ñ₁·cos θ₁ + n₂·cos θ₂)
t⛛ = (2·ñ₁·cos θ₁) / (ñ₁·cos θ₁ + n₂·cos θ₂)

rₚ = (ñ₂·cos θ₁ - ñ₁·cos θ₂) / (ñ₂·cos θ₁ + n₁·cos θ₂)
tₚ = (2·ñ₁·cos θ₁) / (ñ₂·cos θ₁ + n₁·cos θ₂)
```

Енергетичний коефіцієнт відбиття (відбивність `R`) обчислюється як квадрат модуля відповідного комплексного амплітудного коефіцієнта:

```
R⛛ = |r⛛|² = Re(r⛛)² + Im(r⛛)²
Rₚ = |rₚ|² = Re(rₚ)² + Im(rₚ)²
```

Енергетичний коефіцієнт пропущення (пропускання `T`) враховує дійсний перенос енергії вектора Пойнтінга через межу. Множник геометрії та імпедансу `(ñ₂ · cos θ₂ / ñ₁ · cos θ₁)` у загальному випадку є комплексним числом. Фізичний перенос енергії визначається лише його дійсною частиною:

```
T⛛ = Re[ (ñ₂ · cos θ₂) / (ñ₁ · cos θ₁) ] · |t⛛|²
Tₚ = Re[ (ñ₂ · cos θ₂) / (ñ₁ · cos θ₁) ] · |tₚ|²
```

При повному внутрішньому відбитті у прозорому середовищі `cos θ₂` є чисто уявним числом, тому `Re(n₂ · cos θ₂) = 0`. Формула автоматично дає `T⛛ = 0` та `Tₚ = 0`, що повністю відповідає фізичній дійсності: еванесцентна хвиля у другому середовищі не переносить енергії вглиб вздовж нормалі.

#include <stdio.h>
#include <math.h>
#include <complex.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

typedef struct {
    double complex r_s;  /* Комплексний амплітудний коефіцієнт відбиття s */
    double complex r_p;  /* Комплексний амплітудний коефіцієнт відбиття p */
    double complex t_s;  /* Комплексний амплітудний коефіцієнт заломлення s */
    double complex t_p;  /* Комплексний амплітудний коефіцієнт заломлення p */
    double R_s;          /* Енергетична відбивність s-поляризації */
    double R_p;          /* Енергетична відбивність p-поляризації */
    double T_s;          /* Енергетичне пропускання s-поляризації */
    double T_p;          /* Енергетичне пропускання p-поляризації */
    double R_avg;        /* Середня відбивність неполяризованого світла */
    double phase_s_deg;  /* Зсув фази s-хвилі при відбитті (в градусах) */
    double phase_p_deg;  /* Зсув фази p-хвилі при відбитті (в градусах) */
} fresnel_result_t;

fresnel_result_t calc_fresnel(double complex n1, double complex n2, double theta1_deg) {
    fresnel_result_t res;
    double theta1_rad = theta1_deg * M_PI / 180.0;
    
    double complex cos_t1 = cos(theta1_rad);
    double complex sin_t1 = sin(theta1_rad);

    /* Комплексний закон Снелла */
    double complex sin_t2 = (n1 / n2) * sin_t1;
    double complex cos_t2 = csqrt(1.0 - sin_t2 * sin_t2);

    /* Захист від вибору не тієї гілки квадратного кореня */
    if (creal(cos_t2) < 0.0) {
        cos_t2 = -cos_t2;
    }

    /* Амплітудні коефіцієнти Френеля */
    res.r_s = (n1 * cos_t1 - n2 * cos_t2) / (n1 * cos_t1 + n2 * cos_t2);
    res.t_s = (2.0 * n1 * cos_t1) / (n1 * cos_t1 + n2 * cos_t2);

    res.r_p = (n2 * cos_t1 - n1 * cos_t2) / (n2 * cos_t1 + n1 * cos_t2);
    res.t_p = (2.0 * n1 * cos_t1) / (n2 * cos_t1 + n1 * cos_t2);

    /* Енергетична відбивність R = |r|^2 */
    res.R_s = cabs(res.r_s) * cabs(res.r_s);
    res.R_p = cabs(res.r_p) * cabs(res.r_p);
    res.R_avg = 0.5 * (res.R_s + res.R_p);

    /* Зсуви фаз при відбитті */
    res.phase_s_deg = carg(res.r_s) * 180.0 / M_PI;
    res.phase_p_deg = carg(res.r_p) * 180.0 / M_PI;

    /* Дійсний потік енергії для пропускання T */
    double complex factor = (n2 * cos_t2) / (n1 * cos_t1);
    double real_factor = creal(factor);
    if (real_factor < 0.0) real_factor = 0.0;

    res.T_s = real_factor * (cabs(res.t_s) * cabs(res.t_s));
    res.T_p = real_factor * (cabs(res.t_p) * cabs(res.t_p));

    return res;
}

int main(void) {
    /* Приклад 1: Повітря (n=1.0) -> Скло (n=1.5) під кутом 45 градусів */
    double complex n_air = 1.0 + 0.0 * I;
    double complex n_glass = 1.5 + 0.0 * I;
    fresnel_result_t res_glass = calc_fresnel(n_air, n_glass, 45.0);

    printf("=== Межа Повітря -> Скло (theta1 = 45 deg) ===\n");
    printf("R_s: %.4f (%.2f%%)\n", res_glass.R_s, res_glass.R_s * 100.0);
    printf("R_p: %.4f (%.2f%%)\n", res_glass.R_p, res_glass.R_p * 100.0);
    printf("R_avg: %.4f (%.2f%%)\n", res_glass.R_avg, res_glass.R_avg * 100.0);
    printf("T_s: %.4f, T_p: %.4f\n", res_glass.T_s, res_glass.T_p);

    /* Приклад 2: Золото при довжині хвилі 633 нм (n = 0.18 + 3.43i) */
    double complex n_gold = 0.18 + 3.43 * I;
    fresnel_result_t res_gold = calc_fresnel(n_air, n_gold, 0.0);

    printf("\n=== Межа Повітря -> Золото при нормальному падінні (0 deg) ===\n");
    printf("R_s = R_p: %.4f (%.2f%%)\n", res_gold.R_s, res_gold.R_s * 100.0);

    return 0;
}

struct FresnelResult {

    std::complex<double> t_s;

    double R_s;
    double R_p;

    double T_p;
    double R_avg;

    double phase_p_deg;
};

[[nodiscard]] FresnelResult calculate_fresnel(std::complex<double> n1, 
                                              std::complex<double> n2, 
                                              double theta1_deg) noexcept {
    const double theta1_rad = theta1_deg * std::numbers::pi / 180.0;
    const std::complex<double> cos_t1{std::cos(theta1_rad), 0.0};
    const std::complex<double> sin_t1{std::sin(theta1_rad), 0.0};

    const std::complex<double> sin_t2 = (n1 / n2) * sin_t1;
    std::complex<double> cos_t2 = std::sqrt(1.0 - sin_t2 * sin_t2);

    if (cos_t2.real() < 0.0) {
        cos_t2 = -cos_t2;
    }

    const auto r_s = (n1 * cos_t1 - n2 * cos_t2) / (n1 * cos_t1 + n2 * cos_t2);
    const auto t_s = (2.0 * n1 * cos_t1) / (n1 * cos_t1 + n2 * cos_t2);

    const auto r_p = (n2 * cos_t1 - n1 * cos_t2) / (n2 * cos_t1 + n1 * cos_t2);
    const auto t_p = (2.0 * n1 * cos_t1) / (n2 * cos_t1 + n1 * cos_t2);

    const double R_s = std::norm(r_s);
    const double R_p = std::norm(r_p);
    const double R_avg = 0.5 * (R_s + R_p);

    const double phase_s_deg = std::arg(r_s) * 180.0 / std::numbers::pi;
    const double phase_p_deg = std::arg(r_p) * 180.0 / std::numbers::pi;

    const std::complex<double> factor = (n2 * cos_t2) / (n1 * cos_t1);
    double real_factor = factor.real();
    if (real_factor < 0.0) real_factor = 0.0;

    const double T_s = real_factor * std::norm(t_s);
    const double T_p = real_factor * std::norm(t_p);

    return {r_s, r_p, t_s, t_p, R_s, R_p, T_s, T_p, R_avg, phase_s_deg, phase_p_deg};
}

import cmath
import math

def calculate_fresnel(n1: complex, n2: complex, theta1_deg: float) -> dict:
    theta1_rad = math.radians(theta1_deg)
    cos_t1 = cmath.cos(theta1_rad)
    sin_t1 = cmath.sin(theta1_rad)

    sin_t2 = (n1 / n2) * sin_t1
    cos_t2 = cmath.sqrt(1.0 - sin_t2 ** 2)

    if cos_t2.real < 0.0:
        cos_t2 = -cos_t2

    r_s = (n1 * cos_t1 - n2 * cos_t2) / (n1 * cos_t1 + n2 * cos_t2)
    t_s = (2.0 * n1 * cos_t1) / (n1 * cos_t1 + n2 * cos_t2)

    r_p = (n2 * cos_t1 - n1 * cos_t2) / (n2 * cos_t1 + n1 * cos_t2)
    t_p = (2.0 * n1 * cos_t1) / (n2 * cos_t1 + n1 * cos_t2)

    R_s = abs(r_s) ** 2
    R_p = abs(r_p) ** 2
    R_avg = 0.5 * (R_s + R_p)

    phase_s_deg = math.degrees(cmath.phase(r_s))
    phase_p_deg = math.degrees(cmath.phase(r_p))

    factor = (n2 * cos_t2) / (n1 * cos_t1)
    real_factor = max(0.0, factor.real)

    T_s = real_factor * (abs(t_s) ** 2)
    T_p = real_factor * (abs(t_p) ** 2)

    return {
        "r_s": r_s, "r_p": r_p, "t_s": t_s, "t_p": t_p,
        "R_s": R_s, "R_p": R_p, "T_s": T_s, "T_p": T_p,
        "R_avg": R_avg,
        "phase_s_deg": phase_s_deg, "phase_p_deg": phase_p_deg
    }

### 3. Покроковий розбір алгоритму та обчислювальних пасток

Під час інженерної реалізації обчислень за рівняннями Френеля виникає декілька типових обчислювальних пасток, розбір яких критично важливий для забезпечення чисельної стійкості програми.

#### Крок 1. Переведення кутів та комплексний закон Снелла

Вхідний кут падіння `theta1_deg` переводиться в радіани: `theta1_rad = theta1_deg * π / 180`. Обчислюються комплексні синус `sin_t1` та косинус `cos_t1`. Комплексна математична бібліотека підтримує передачу дійсних кутів у формі комплексного числа із нульовою уявною частиною `std::complex<double>(cos(theta1_rad), 0.0)`.

Синус кута заломлення обчислюється як `sin_t2 = (n1 / n2) * sin_t1`. Якщо `n1` або `n2` містять уявну частину (поглинання чи метал), то `sin_t2` стає повністю комплексним числом.

#### Крок 2. Колекція пастки гілки квадратного кореня `cos θ₂`

Стандартні математичні функції `csqrt` у мові C та `std::sqrt` у C++ повертають значення квадратного кореня у правій півплощині комплексного числа, де дійсна частина `Re(√z) ≥ 0`.

Проте для деяких комплексних комбінацій діелектричної проникності числовий розріз гілки коріння у стандартній бібліотеці може видати результат із негативною дійсною частиною `Re(cos θ₂) < 0`. Фізично це означало б, що заломлена хвиля біжить з другого середовища у перше (інверсія напрямку поширення енергії).

Для усунення цієї помилки у код додано примусову перевірку: `if (cos_t2.real() < 0.0) cos_t2 = -cos_t2;`. Ця умова гарантує, що вектор фазової швидкості заломленої хвилі завжди спрямований углиб другого середовища.

#### Крок 3. Скользяще падіння (`θ₁ → 90°`) та запобігання діленню на нуль

При кутах падіння, що наближаються до 90° (промінь заковзає вздовж межі), `cos θ₁` наближається до нуля. У формулах для `t⛛` та `tₚ` це призводить до чисельника, близького до нуля. Проте при розрахунку фактора енергетичного потоку `(n₂ · cos θ₂ / n₁ · cos θ₁)` виникає ділення на малу величину `cos θ₁`.

Якщо значення `cos θ₁` падає нижче машинного епсилон (`< 1e-15`), у чисельних розрахунках виникає невизначеність вигляду `0 / 0`. Для запобігання цій помилці в інженерних бібліотеках додається граничне переривання: при `θ₁ ≥ 89.9999°` алгоритм чисельно покладає `R⛛ = 1.0`, `Rₚ = 1.0`, `T⛛ = 0.0`, `Tₚ = 0.0` без виконання ділення на косинус.

#### Крок 4. Розрахунок фазового зсуву та аргументу комплексного числа

Дійсна та уявна частини комплексних коефіцієнтів `r⛛` та `rₚ` містять інформацію про зміну фази світлової хвилі при відбитті. Для отримання фазового кута в градусах використовується функція аргументу комплексного числа: `phase_s_deg = carg(r_s) * 180.0 / M_PI;`.

У мові C++ використовується `std::arg(r_s)`, а у Python — `cmath.phase(r_s)`.

Для s-поляризації при падінні з повітря на скло під кутом 0° значення `r⛛ = -0.2`. Функція аргументу повертає `π` радіан (180°), що строго відповідає інверсії фази на межі з оптично густішим середовищем. При повному внутрішньому відбитті модуль `|r| = 1.0`, а значення `carg(r)` неперервно змінюється від 0° до 180° залежно від кута падіння.

### 4. Практичні приклади застосування та перевірка матеріалів

Розглянемо три конкретні фізичні задачі, для розв'язання яких застосовується розроблений калькулятор.

#### Задача 1. Оптичне скло K8/BK7 (прозорий діелектрик)

Для оптичного крона K8 на довжині хвилі 589 нм показник заломлення дорівнює `n₂ = 1.5168`. При падінні світла з повітря (`n₁ = 1.0`) під кутом 45° розрахунок дає:

```
R⛛ = 0.0920 (9.20%)
Rₚ = 0.0084 (0.84%)
R_avg = 0.0502 (5.02%)
```

Сумарні втрати неполяризованого світла на відбиття становлять 5.02%. Звернувши увагу на `Rₚ = 0.84%`, бачимо, що кут 45° знаходиться вже неподалік від кута Брюстера (`θ_B = arctg(1.5168) ≈ 56.6°`), де `Rₚ` стає нулем.

#### Задача 2. Сонячні елементи із монокристалічного кремнію (Si)

Кремній у видимому діапазоні світла (на довжині хвилі 633 нм) має високий комплексний показник заломлення `ñ = 3.88 + 0.02i`. Обчислимо відбивність чистої кремнієвої пластини при нормальному падінні (`θ₁ = 0°`):

```
R = |(1.0 - (3.88 + 0.02i)) / (1.0 + (3.88 + 0.02i))|²
  = |-2.88 - 0.02i|² / |4.88 + 0.02i|²
  = (2.88² + 0.02²) / (4.88² + 0.02²)
  = 8.2948 / 23.8144 ≈ 0.3483 (34.83%)
```

Без застосування протиблискового покриття чистий кремнієвий елемент втрачає понад 34.8% усієї падаючої сонячної енергії лише за рахунок відбиття Френеля.

Щоб мінімізувати ці втрати, на кремній наносять одношарове покриття з нітриду кремнію `Si₃N₄` з оптимальним показником заломлення `n_film = √(n_air · n_Si) = √(1.0 · 3.88) ≈ 1.97`. Розрахунок за калькулятором показує, що двошарова система знижує підсумкову відбивність на робочій довжині хвилі з 34.8% до менш ніж 1.2%.

#### Задача 3. Срібне дзеркало для лазерного резонатора

Срібло володіє найвищою відбивністю серед усіх металів у видимому й інфрачервоному діапазонах. При довжині хвилі 633 нм показник заломлення срібла `ñ = 0.14 + 4.15i`. Обчислимо відбивність при прямому падінні:

```
R = |(1.0 - (0.14 + 4.15i)) / (1.0 + (0.14 + 4.15i))|²
  = |0.86 - 4.15i|² / |1.14 + 4.15i|²
  = (0.86² + 4.15²) / (1.14² + 4.15²)
  = (0.7396 + 17.2225) / (1.2996 + 17.2225)
  = 17.9621 / 18.5221 ≈ 0.9698 (96.98%)
```

Срібне дзеркало повертає 96.98% світла, а решта 3.02% енергії поглинається у тонкому поверхневому шарі металу завтовшки всього кілька нанометрів (скіновий шар) і перетворюється на тепло.

За допомогою розробленого алгоритму можна будувати графіки спектральної відбивності для будь-яких багатошарових оптичних систем, дзеркал та напівпровідникових гетероструктур.
