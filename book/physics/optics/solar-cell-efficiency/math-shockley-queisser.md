# 🧮 Математичний вивід границі Шокли-Квіссера та термодинамічного ККД

Ця математична вставка містить детальний термодинамічний вивід границі Шокли-Квіссера (*Shockley-Queisser limit*) для одноперехідного сонячного елемента на основі детального балансу випромінювання між Сонцем, навколишнім середовищем та напівпровідниковим фотодетектором.

### Спектральний потік фотонів та модель абсолютно чорного тіла

Сонце моделюється як абсолютно чорне тіло з температурою `T_sun = 5778 K`, яке випромінює у тілесний кут `Ω_sun ≈ 6.85·10⁻⁵ стер`. Сонячний елемент перебуває при температурі навколишнього середовища `T_cell = 300 K` й обмінюється випромінюванням із навколишнім середовищем у тілесному куті `Ω_cell = π` (півсфера).

За законом випромінювання Планка, спектральна густина потоку фотонів з енергією `E = h·ν` на одиницю площі за секунду у спектральному інтервалі `dE` становить:

```
F(E, T, Ω) = (Ω / (4·π³·ħ³·c²)) · (E² / (exp(E / (k_B·T)) - 1))
```

де:
- `ħ = h / (2·π)` — зведена стала Планка (`1.05457·10⁻³⁴ Дж·с`),
- `c` — швидкість світла у вакуумі (`2.99792·10⁸ м/с`),
- `k_B` — стала Больцмана (`1.38064·10⁻²³ Дж/К`),
- `E` — енергія фотона у джоулях або електронвольтах.

Загальний потік фотонів з енергією, що перевищує ширину забороненої зони напівпровідника `E_g`, які падають на одиницю площі сонячного елемента за секунду від Сонця, дорівнює:

```
N_ph(E_g) = ∫_{E_g}^{∞} F(E, T_sun, Ω_sun) dE
          = (Ω_sun / (4·π³·ħ³·c²)) · ∫_{E_g}^{∞} (E² / (exp(E / (k_B·T_sun)) - 1)) dE
```

За умови ідеального поглинання, кожен падаючий фотон з енергією `E ≥ E_g` генерує рівно одну пару електрон-дірка (`EQE = 1` для `E ≥ E_g`). Фотони з енергією `E < E_g` не поглинаються взагалі (`EQE = 0`).

Густина струму короткого замикання `J_sc` визначається добутком елементарного заряду `e` на потік генерації фотоносіїв:

```
J_sc = e · N_ph(E_g)
```

### Випромінювальна рекомбінація та квазірівні Фермі

Згідно із принципом детального балансу Ван Русбрука-Шокли (*van Roosbroeck-Shockley relation*), у стані термодинамічної рівноваги сонячний елемент самостійно випромінює кванти світла у навколишнє середовище внаслідок випромінювальної рекомбінації носіїв. Коли до p-n переходу прикладена зовнішня напруга `V`, квазірівні Фермі електронів `E_Fn` та дірок `E_Fp` розщеплюються на величину `ΔE = E_Fn - E_Fp = e·V`.

Це розщеплення збільшує хімічний потенціал фотонного газу всередині кристала на величину `μ = e·V`. Внаслідок цього ймовірність випромінювальної рекомбінації описується розподілом Бозе-Айнштайна із хімічним потенціалом `μ`:

```
N_rec(E_g, V) = (Ω_cell / (4·π³·ħ³·c²)) · ∫_{E_g}^{∞} (E² / (exp((E - e·V) / (k_B·T_cell)) - 1)) dE
```

Густина зворотного випромінювального струму рекомбінації `J_rec(V)` описується рівнянням:

```
J_rec(V) = e · N_rec(E_g, V)
```

При кімнатній температурі `T_cell = 300 K` енергія `E_g ≥ 1.0 еВ` значно перевищує `k_B·T_cell ≈ 0.0259 еВ`. Застосовуючи наближення Больцмана `exp((E - e·V) / (k_B·T_cell)) ≫ 1`, інтеграл спрощується:

```
J_rec(V) = J_0 · exp(e·V / (k_B·T_cell))
```

де `J_0` — густина теплового струму насичення випромінювальної рекомбінації у темряві:

```
J_0 = e · (Ω_cell / (4·π³·ħ³·c²)) · ∫_{E_g}^{∞} E² · exp(-E / (k_B·T_cell)) dE
```

Виконуючи аналітичне інтегрування по частинах для `∫ E² · exp(-a·E) dE`:

```
∫_{E_g}^{∞} E² · exp(-a·E) dE
= (E_g² / a + 2·E_g / a² + 2 / a³) · exp(-a·E_g)      [де a = 1 / (k_B·T_cell)]
```

Підставляючи параметр `a = 1 / (k_B·T_cell)`, отримуємо точний вираз для струму насичення:

```
J_0 = e · (Ω_cell / (4·π³·ħ³·c²)) · (k_B·T_cell) · (E_g² + 2·k_B·T_cell·E_g + 2·(k_B·T_cell)²) · exp(-E_g / (k_B·T_cell))
```

### Вольт-амперне рівняння та напруга холостого ходу

Підсумкова вольт-амперна характеристика ідеального одноперехідного фотоелемента є різницею фотоструму та струму випромінювальної рекомбінації:

```
J(V) = J_sc - J_0 · (exp(e·V / (k_B·T_cell)) - 1)
```

Напруга холостого ходу `V_oc` досягається при результуючому струмі `J(V_oc) = 0`:

```
J_sc = J_0 · (exp(e·V_oc / (k_B·T_cell)) - 1)
⇒ exp(e·V_oc / (k_B·T_cell)) = J_sc / J_0 + 1
⇒ V_oc = (k_B·T_cell / e) · ln(J_sc / J_0 + 1)
```

Оскільки `J_sc ≫ J_0` (зазвичай `J_sc ≈ 40 мА/см²`, а `J_0 ≈ 10⁻¹³ А/см²`), одиницею під логарифмом можна знехтувати:

```
V_oc ≈ (k_B·T_cell / e) · ln(J_sc / J_0)
```

### Оптимізація потужності та фактор заповнення (FF)

Електрична потужність на одиницю площі елемента становить `P(V) = V · J(V)`:

```
P(V) = V · [ J_sc - J_0 · (exp(e·V / (k_B·T_cell)) - 1) ]
```

Для знаходження точки максимальної потужності `V_mp` беремо похідну `dP / dV = 0`:

```
dP / dV = J_sc - J_0 · (exp(e·V / (k_B·T_cell)) - 1) - V · J_0 · (e / (k_B·T_cell)) · exp(e·V / (k_B·T_cell)) = 0
```

Ввівши безрозмірну напругу `v = e·V / (k_B·T_cell)` та `v_oc = e·V_oc / (k_B·T_cell)`, умова максимуму набуває трансцендентного вигляду:

```
exp(v_mp) · (1 + v_mp) = exp(v_oc)
⇒ v_mp + ln(1 + v_mp) = v_oc
```

Наближений розв'язок для оптимальної напруги `V_mp` та струму `J_mp`:

```
V_mp ≈ V_oc - (k_B·T_cell / e) · ln(1 + e·V_oc / (k_B·T_cell))

J_mp ≈ J_sc · [ 1 - 1 / (e·V_oc / (k_B·T_cell)) ]
```

Фактор заповнення (*Fill Factor*, `FF`) визначається як відношення максимальної прямокутної площі `V_mp · J_mp` до добутку `V_oc · J_sc`:

```
FF = (V_mp · J_mp) / (V_oc · J_sc)
   ≈ (v_oc - ln(v_oc + 0.72)) / (v_oc + 1)
```

Для якісного кремнієвого елемента при `V_oc ≈ 0.72 В` та `T = 300 K` безрозмірна напруга `v_oc = 0.72 / 0.0259 ≈ 27.8`, що дає теоретичну межу `FF ≈ 0.85` (85%).

### Границя Шокли-Квіссера під концентрованим світлом

Якщо сонячне світло концентрується оптичними лінзами або дзеркалами з коефіцієнтом концентрації `X` (де `X` варіюється від 1 до максимального значення `X_max = 1 / sin²(θ_sun) ≈ 46200`), потік падаючих фотонів збільшується в `X` разів:

```
J_sc(X) = X · J_sc(1)
```

При цьому напруга холостого ходу `V_oc` зростає логарифмічно:

```
V_oc(X) = V_oc(1) + (k_B·T_cell / e) · ln(X)
```

Під максимальним фізично можливим сонячним концентратором (`X = 46200`) фундаментальна границя Шокли-Квіссера для одноперехідного сонячного елемента зростає від **33.7% до 40.8%**.

### Порівняння з термодинамічною межею Ландсберга та безипромінювальними втратами

Граничний ККД Шокли-Квіссера (33.7%) є квантово-механічним обмеженням для конкретної одноперехідної напівпровідникової структури. Якщо ж розглядати сонячний випромінювач та приймач як ідеальну термодинамічну теплову машину Карно, максимальний термодинамічний ККД перетворення теплового випромінювання Сонця (`T_sun = 5778 K`) у роботу при температурі холодильника (`T_cell = 300 K`) описується межею Ландсберга (*Landsberg limit*):

```
η_Landsberg = 1 - (4/3) · (T_cell / T_sun) + (1/3) · (T_cell / T_sun)⁴ ≈ 93.3%
```

Різниця між межею Ландсберга (93.3%) та межею Шокли-Квіссера (33.7%) описує незворотні ентропійні втрати, пов'язані з неселективним квантовим поглинанням в одноперехідному матеріалі.

Крім випромінювальної рекомбінації, у реальних кремнієвих кристалах виникає безипромінювальна Оже-рекомбінація (*Auger recombination*), де енергія рекомбінації передається третьому носієві заряду. Швидкість Оже-рекомбінації пропорційна кубу концентрації носіїв `R_Auger = C_n·n²·p + C_p·n·p²`. Врахування Оже-рекомбінації знижує практичну межу для кристалічного кремнію з 32.9% до **29.4%**.

### Розрахунок граничного ККД η_SQ

Підсумковий коефіцієнт корисної дії `η` визначається відношенням максимальної вихідної електричної потужності `P_max` до повної вхідної оптичної потужності сонячного випромінювання `P_in`:

```
P_max = V_mp · J_mp = V_oc · J_sc · FF

η = P_max / P_in = (V_oc · J_sc · FF) / P_in
```

Для стандартного сонячного спектра AM1.5G загальна вхідна потужність становить `P_in = 1000 Вт/м²`.

Проаналізуємо залежність складників `η(E_g)` від ширини забороненої зони `E_g`:

1. **При малій `E_g` (наприклад, `E_g = 0.5 еВ`):** поглинається більша частина спектра, тому струм `J_sc` великий, але напруга `V_oc` та `E_g` дуже малі. Крім того, фотони з високою енергією `E ≫ E_g` втрачають більшість енергії на тепло через термалізацію `(E - E_g)`. Підсумок: `η` мала (~15%).
2. **При великій `E_g` (наприклад, `E_g = 2.2 еВ`):** напруга `V_oc` висока, а втрати на термалізацію малі. Проте більшість сонячних фотонів мають енергію `E < E_g` і проходять крізь кристал без поглинання, тому струм `J_sc` падає до мінімуму. Підсумок: `η` мала (~14%).
3. **Оптимум при `E_g ≈ 1.34 еВ`:** баланс між максимальним струмом та високою напругою дає піковий ККД **33.7%** під спектром AM1.5G. Для монокристалічного кремнію (`E_g = 1.12 еВ`) фундаментальна термодинамічна границя Шокли-Квіссера становить **32.9%**.
