# 🧮 Виведення перерізу релеєвського розсіяння з рівнянь Максвелла

Ця вставка містить послідовний математичний вивід ефективного перерізу релеєвського розсіяння, його залежності від кута спостереження, довжини хвилі та оптичних характеристик середовища. Розрахунок спирається на теорію класичної електродинаміки осцилювального диполя, хвильове випромінювання у далекій зоні та інтегрування вектора Пойнтінга по тілесному куту.

### 1. Поляризованість малого діелектричного включення

Розглянемо малу однорідну ізотропну діелектричну частинку сферичної форми з радіусом `a` та об'ємом `V = (4/3)·π·a³`. Частинка знаходиться в прозорому однорідному середовищі з відносною діелектричною проникністю `ε_m`. Матеріал самої частинки має діелектричну проникність `ε_p` або відповідний комплексний показник заломлення `n = √(ε_p / ε_m)`.

Фундаментальна передумова теорії релеєвського розсіяння полягає в тому, що геометричні розміри частинки є значно меншими за довжину світлової хвилі у навколишньому середовищі:

```
a ≪ λ  (або безрозмірний параметр розміру x = 2·π·a / λ ≪ 1)
```

За виконання цієї умови електричне поле електромагнітної хвилі `E(t) = E₀ · e⁻ⁱᵐᵗ` можна вважати просторово однорідним у межах усього об'єму частинки в кожен фіксований момент часу. Це дозволяє розраховувати локальне внутрішнє та зовнішнє електричні поля у квазістаціонарному наближенні електростатики.

Згідно з класичним розв'язком рівняння Лапласа для діелектричної кулі, вміщеної в однорідне зовнішнє електричне поле `E₀`, однорідна поляризованість середовища кулі утворює наведений дипольний момент `p`. Цей дипольний момент пропорційний напруженості зовнішнього поля:

```
p = α · E₀
```

де `α` — точкова **електрична дипольна поляризованість** частинки. Застосовуючи граничні умови неперервності потенціалу та нормальної складової індукції на поверхні сфери, отримуємо класичне співвідношення Клаузіуса — Моссотті (або формулу Лоренца — Лоренца):

```
α = 4·π·ε₀·a³ · (n² - 1) / (n² + 2)   [поляризованість малого шарa]
```

Якщо виразити радіус частинки `a` через її геометричний об'єм `V = (4/3)·π·a³`, поляризованість набуває зручного компактного вигляду:

```
α = 3·ε₀·V · (n² - 1) / (n² + 2)
```

Отже, наведений дипольний момент прямо пропорційний об'єму частинки `V` та оптичному контрасту між діелектриком частинки та оточуючим середовищем `(n² - 1) / (n² + 2)`.

### 2. Динаміка осцилювального диполя та випромінювання хвилі

Зовнішнє світлове поле змінюється за гармонічним законом із кутовою частотою `ω = 2·π·c / λ`. Під дією цього поля наведений дипольний момент частинки здійснює вимушені гармонічні коливання з тією ж частотою:

```
p(t) = p₀ · e⁻ⁱᵐᵗ = α · E₀ · e⁻ⁱᵐᵗ
```

Згідно з рівняннями Максвелла, будь-який часово змінний дипольний момент випромінює у навколишній простір вторинну електромагнітну хвилю. Друга похідна дипольного моменту по часу виражає прискорення зв'язаних зарядів у діелектрику:

```
d²p / dt² = - ω² · p(t)
```

У хвильовій зоні випромінювання (на відстані від частинки `r ≫ λ`) напруженість електричного поля випроміненої хвилі `E_rad` визначається стандартним розв'язком для осцилювального герцівського диполя:

```
E_rad(r, θ) = (ω² · p₀ · sin θ) / (4·π·ε₀·c²·r)
```

де:
- `c` — швидкість поширення світла у середовищі;
- `k = ω / c = 2·π / λ` — хвильове число електромагнітного випромінювання;
- `r` — відстань від частинки-розсіювача до точки спостереження;
- `θ` — кут між вектором коливань дипольного моменту `p` (орієнтацією електричного поля падаючої хвилі) та напрямком на спостерігача.

Замінивши частоту `ω` через хвильове число `k = ω / c` та підставивши вираз для амплітуди дипольного моменту `p₀ = α · E₀`, отримуємо точне значення поля випромінювання:

```
E_rad(r, θ)
= (k² · p₀ · sin θ) / (4·π·ε₀·r)              [1: поле диполя через хвильове число]
= (k² · α · E₀ · sin θ) / (4·π·ε₀·r)          [2: підстановка p₀ = α · E₀]
```

Ця формула показує, що амплітуда розсіяного поля падає обернено пропорційно відстані `1 / r` (що забезпечує збереження енергії у сферичній хвилі) та зростає пропорційно квадрату хвильового числа `k² ∝ 1 / λ²`.

### 3. Вектор Пойнтінга та інтенсивність розсіяного світла

Усереднена за періодом світлових коливань густина потоку енергії (інтенсивність випромінювання) обчислюється як модуль усередненого вектора Пойнтінга:

```
I_scattered(r, θ) = (1/2) · c · ε₀ · |E_rad|²
```

Підставивши раніше отриманий вираз для напруженості електричного поля `E_rad`:

```
I_scattered(r, θ)
= (1/2) · c · ε₀ · [ (k² · α · E₀ · sin θ) / (4·π·ε₀·r) ]²
= (c · ε₀ · E₀² / 2) · [ (k⁴ · α²) / (16·π²·ε₀²·r²) ] · sin² θ
```

Зважаючи на те, що інтенсивність падаючої плоскої світлової хвилі дорівнює `I₀ = (1/2) · c · ε₀ · E₀²`, отримуємо фундаментальне співвідношення для інтенсивності розсіяння лінійно поляризованої хвилі:

```
I_scattered(r, θ) = I₀ · [ (k⁴ · α²) / (16·π²·ε₀²·r²) ] · sin² θ
```

Звернувши увагу на множник `sin² θ`, можна помітити важливу фізичну особливість: вздовж лінії коливань диполя (`θ = 0` або `θ = 180°`) інтенсивність розсіяного світла дорівнює нулю. Осцилювальний диполь не випромінює уздовж осі власних коливань.

### 4. Розсіяння неполяризованого (природного) світла

Природне сонячне світло є неполяризованим. Це означає, що вектор напруженості електричного поля `E₀` хаотично та з високою частотою змінює свій напрямок у площині, перпендикулярній до напрямку поширення падаючого променя.

Для розрахунку розсіяння неполяризованого світла розкладемо падаючу хвилю на дві незалежні взаємно перпендикулярні поляризаційні компоненти однакової інтенсивності `I₀ / 2`:
- `I_parallel`: вектор `E` коливається в площині розсіяння (визначеній падаючим та розсіяним променями);
- `I_perpendicular`: вектор `E` коливається перпендикулярно до площини розсіяння.

Для перпендикулярної компоненти кут між вектором `E` та напрямком розсіяння завжди дорівнює `90°`, тому `sin² θ_perp = 1`. Для паралельної компоненти кут коливань залежить від кута розсіяння `θ` (кута між напрямком первинного променя та напрямком на спостерігача) як `sin² θ_par = cos² θ`.

Усереднення кутового множника по двох компонентах дає класичну нормовану фазову функцію розсіяння (індикаторну функцію):

```
⟨sin² θ⟩ = (1 + cos² θ) / 2
```

Тоді підсумкова інтенсивність розсіяння неполяризованого світла під кутом `θ` на відстані `r` дорівнює:

```
I_scattered(r, θ) = I₀ · [ (k⁴ · α²) / (32·π²·ε₀²·r²) ] · (1 + cos² θ)
```

Аналіз цієї формули розкриває фундаментальні властивості релеєвського розсіяння:
1. **Симетрія вперед-назад**: значення множника `1 + cos² θ` однакові для `θ = 0°` (прямо вперед) та `θ = 180°` (строго назад), де вони дорівнюють `2`. Для кута `θ = 90°` множник дорівнює `1`. Таким чином, інтенсивність розсіяння вперед і назад вдвічі більша за інтенсивність розсіяння у бічному напрямку.
2. **Залежність від довжини хвилі**: оскільки `k = 2·π / λ`, то `k⁴ = 16·π⁴ / λ⁴`. Інтенсивність розсіяного світла обернено пропорційна четвертому степеню довжини хвилі `1 / λ⁴`.

### 5. Диференціальний та повний ефективний переріз розсіяння

У фізичній оптиці та атомній фізиці взаємодію випромінювання з частинкою кількісно характеризують за допомогою **ефективного перерізу розсіяння** `σ`.

**Диференціальний переріз розсіяння** `dσ / dΩ` виражає частку енергії падаючого потоку, яка розсіюється в одиничний тілесний кут `dΩ`:

```
dσ / dΩ = (I_scattered(r, θ) · r²) / I₀
```

Підставляючи отриману інтенсивність для неполяризованого світла, маємо:

```
dσ / dΩ = [ (k⁴ · α²) / (32·π²·ε₀²) ] · (1 + cos² θ)
```

Щоб знайти **повний ефективний переріз розсіяння** `σ_R`, проінтегруємо диференціальний переріз по всій сфері тілесного кута `dΩ = sin θ · dθ · dφ`:

```
σ_R = ∫₀²ᵖʰⁱ dφ ∫₀ᵖʰⁱ (dσ / dΩ) · sin θ dθ
= [ (k⁴ · α²) / (32·π²·ε₀²) ] · ∫₀²ᵖʰⁱ dφ · ∫₀ᵖʰⁱ (1 + cos² θ) · sin θ dθ
```

Інтеграли по азимутальному куту `φ` та полярному куту `θ` обчислюються вільним чином:

```
∫₀²ᵖʰⁱ dφ = 2·π
∫₀ᵖʰⁱ (1 + cos² θ) · sin θ dθ = [ -cos θ - (cos³ θ / 3) ]₀ᵖʰⁱ = (1 + 1/3) - (-1 - 1/3) = 8/3
```

Перемножуємо коефіцієнти:

```
σ_R
= [ (k⁴ · α²) / (32·π²·ε₀²) ] · (2·π) · (8/3)
= (8·π / 3) · k⁴ · (α / 4·π·ε₀)²              [Формула перерізу через поляризованість]
```

### 6. Явний канонічний вираз через радіус та показник заломлення

Підставимо у вираз для `σ_R` точне значення поляризованості малого діелектричного шару `α = 4·π·ε₀·a³ · (n² - 1) / (n² + 2)`:

```
σ_R
= (8·π / 3) · k⁴ · [ a³ · (n² - 1) / (n² + 2) ]²
= (8·π / 3) · (2·π / λ)⁴ · a⁶ · [ (n² - 1) / (n² + 2) ]²
= (128·π⁵ · a⁶ / 3·λ⁴) · [ (n² - 1) / (n² + 2) ]²
```

Виразивши радіус частинки `a` через її геометричний об'єм `V = (4/3)·π·a³` (звідки `a³ = 3·V / 4·π` і відповідно `a⁶ = 9·V² / 16·π²`), отримуємо підсумковий канонічний вираз ефективного перерізу релеєвського розсіяння:

```
σ_R = (24 · π³ · V² / λ⁴) · [ (n² - 1) / (n² + 2) ]²
```

Ця формула є математичним ядром теорії релеєвського розсіяння. Вона строго демонструє:
- Пропорційність квадрату об'єму частинки `V² ∝ a⁶`: при збільшенні радіуса частинки у 2 рази ефективний переріз розсіяння зростає у `2⁶ = 64` рази.
- Зворотно пропорційну залежність від четвертого степеня довжини хвилі `λ⁻⁴`: синє світло розсіюється у 9.4 раза сильніше за червоне.
- Залежність від квадратного оптичного контрасту `[(n² - 1) / (n² + 2)]²`: чим більша різниця між показниками заломлення частинки та середовища, тим інтенсивнішим є розсіяння.

### 7. Врахування анізотропії молекул та коефіцієнт Кабанна

Виведені вище формули передбачають, що частинка-розсіювач є ідеально сферичною та оптично ізотропною. Проте реальні двоатомні та багатоатомні молекули газів (наприклад, `N₂`, `O₂`, `CO₂`) мають витягнуту гантелеподібну геометричну форму і мають анізотропний тензор поляризованості.

Для врахування анізотропії у макроскопічних розрахунках атмосфери використовують **коефіцієнт деполяризації Кабанна** `F_K`:

```
F_K = (6 + 3·ρ_n) / (6 - 7·ρ_n)
```

де `ρ_n` — коефіцієнт деполяризації світла, розсіяного під кутом `90°` при падінні неполяризованого променя. Для атмосферного повітря `ρ_n ≈ 0.0279`, що дає `F_K ≈ 1.054`.

Тоді повний переріз розсіяння на реальній анізотропній молекулі повітря обчислюється з урахуванням фактора Кабанна:

```
σ_real = σ_R · F_K
```

Ця поправка є обов'язковою при точних розрахунках оптичної товщини атмосфери та моделюванні супутникових каналів зв'язку.
