# ⚙️ Моделювання вальт-амперної та ват-амперної характеристик лазерного діода

Цей практичний проект присвячено розробці чисельного симулятора для розрахунку вольт-амперної (V-I), ват-амперної (L-I) характеристик, температурного дрейфу довжини хвилі та феномену теплового насичення потужності (Thermal Rollover) лазерного діода. Моделювання дозволяє завчасно спроектувати параметри джерела живлення, оцінити ККД перетворення електроенергії у світло та розрахувати необхідну потужність системи охолодження на основі елементів Пельтьє.

### 1. Фізичний механізм та архітектура чисельного алгоритму

Для розрахунку характеристики напівпровідникового лазера використовують самоузгоджену систему статичних рівнянь швидкостей та теплового балансу p-n гетеропереходу. У практичних умовах електронно-фотонний перехід не працює ізольовано: при збільшенні струму інжекції кристалічна ґратка напівпровідника неминуче нагрівається через Джоулеве тепло виділення, що призводить до звуження забороненої зони та експоненціального зростання втрат на безипромінювальну рекомбінацію.

Симулятор здійснює чисельне сканування прямого струму інжекції від `0` до `I_max` з обраним кроком `ΔI`. На кожній ітерації по струму виконується наступний математичний послідовний алгоритм:

1. **Розрахунок падіння електричної напруги**: Напруга на p-n переході складається з внутрішньої контактної різниці потенціалів `V_pn ≈ E_g / q`, необхідної для досягнення квазіінверсії населеності Бернарда-Дюрафура, та падіння напруги на омічному послідовному опорі контактів і нейтральних областей `R_s`:
   ```
   V(I) = (E_g(T_j) / q) + I · R_s
   ```
2. **Розрахунок температурно-залежного порогового струму**: Пороговий струм активної зони `I_th` зростає зі збільшенням температури p-n переходу `T_j` за феноменологічним законом Фікса:
   ```
   I_th(T_j) = I_th0 · exp((T_j - T_ref) / T_0)
   ```
   де `T_ref = 20.0 °C` (293.15 К) — опорна кімнатна температура, `I_th0` — пороговий струм при опорній температурі, `T_0` — характерна температура напівпровідникового матеріалу (для арсеніду галію `GaAs` значення `T_0 ≈ 140 К`, а для інфрачервоного фосфіду індію `InP` — `T_0 ≈ 60 К`).
3. **Розрахунок вихідної оптичної потужності**:
   - У підпороговому режимі (`I ≤ I_th`) швидкість вимушеного випромінювання дорівнює нулю. Діод випромінює лише слабку некогерентну спонтанну люмінесценцію, квантовий вихід якої у лазерну моду вираховується частками відсотка:
     ```
     P_opt = η_sp · (h·ν / q) · I
     ```
     де `η_sp ≈ 0.001` — коефіцієнт спонтанного випромінювання.
   - У запороговому режимі (`I > I_th`) модове підсилення точно компенсує втрати резонатора, а весь додатковий струм над порогом перетворюється на лазерні фотони через вимушену рекомбінацію:
     ```
     P_opt = (h·ν / q) · η_d(T_j) · (I - I_th(T_j))
     ```
     де `η_d(T_j)` — диференціальна квантова ефективність, яка також плавно падає при нагріванні: `η_d(T_j) = η_d0 · exp(-(T_j - T_ref) / T_eta)`.
4. **Самоузгоджене рівняння теплового балансу**: Вся електрична потужність, яка підводиться до діода `P_elec = I · V`, за мінусом випроміненої оптичної потужності `P_opt`, перетворюється на теплову потужність `Q_heat = P_elec - P_opt`, яка розсіюється у об'ємі монокристала. Температура активної зони `T_j` перевищує температуру зовнішнього радіатора `T_sub` на величину, задану тепловим опором кристала та корпусу `R_th` (К/Вт):
   ```
   T_j = T_sub + R_th · Q_heat
   ```
   Оскільки `T_j` прямо впливає на `I_th` та `E_g`, а вони перераховують `P_opt` та `Q_heat`, на кожному кроці по струму програма виконує ітераційний цикл (3–5 кроків) до досягнення теплової рівноваги з точністю `10⁻⁴ °C`.
5. **Розрахунок спектрального червоного зсуву**: Зростання температури `T_j` зменшує ширину забороненої зони за законом Варшні, що призводить до плавного зміщення центральної довжини хвилі випромінювання `λ(T_j)` у червоний бік зі швидкістю `dλ/dT ≈ 0.25 – 0.30 нм/К`:
   ```
   λ(T_j) = λ_0 + (dλ / dT) · (T_j - T_ref)
   ```

### 2. Фізичний зміст та методологія вимірювання параметрів

Для моделювання обрано параметри комерційного потужного інфрачервоного лазерного діода на основі подвійної гетероструктури `AlGaAs/GaAs` з довжиною хвилі 808 нм, який застосовують для накачки твердотільних лазерів на кристалах `Nd:YAG`:

- **Центральна довжина хвилі (`λ_0 = 808.0 нм`)**: Відповідає піку поглинання іонів хрому та неодиму. Квантова енергія фотона становить `E = h·c / λ_0 = 1.535 еВ`.
- **Пороговий струм при 20 °C (`I_th0 = 40.0 мА`)**: Мінімальний струм, при якому підсилення у хвилеводі зрівнюється з втратами на дзеркалах відколу `R₁=R₂=0.32`.
- **Характерна температура матеріалу (`T_0 = 140.0 К`)**: Мера температурної стабільності гетероструктури. Високі значення `T_0` свідчать про глибокі потенціальні ями у гетеропереході, які запобігають тепловому викиду електронів у широкозонні обкладки.
- **Диференціальна квантова ефективність (`η_d = 0.85`)**: Показує, що 85% електронів, інжектованих понад поріг, вилітають з резонатора у вигляді когерентних фотонів.
- **Послідовний омічний опір (`R_s = 2.5 Ом`)**: Визначається опором напівпровідникових шарів p- та n-типу та омічних металевих контактів `Au/Ti`.
- **Тепловий опір структури (`R_th = 35.0 К/Вт`)**: Характеризує ефективність відведення тепла від тонесенького активного шару через мідну підкладку корпусу TO-18 до зовнішнього радіатора.
- **Температурний коефіцієнт зсуву довжини хвилі (`dλ/dT = 0.28 нм/К`)**: Описичує температурний дрейф максимуму межзонного підсилення.
- **Температура радіатора (`T_sub = 25.0 °C`)**: Задається зовнішньою системою термостабілізації.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define CONST_Q 1.602176634e-19
#define CONST_HC 1.98644586e-25

typedef struct {
    double lambda_0_nm;  /* Довжина хвилі при T_ref (нм) */
    double I_th0_mA;     /* Пороговий струм при T_ref (мА) */
    double T_0_K;        /* Характерна температура Фікса (К) */
    double eta_d;        /* Диференціальна квантова ефективність */
    double R_s_ohm;      /* Омічний опір (Ом) */
    double R_th_KW;      /* Тепловий опір (К/Вт) */
    double dlambda_dT;   /* Температурний коефіцієнт λ (нм/К) */
    double T_sub_C;      /* Температура радіатора (°C) */
} DiodeParams;

typedef struct {
    double current_mA;
    double voltage_V;
    double power_mW;
    double temp_C;
    double lambda_nm;
    double wpe_percent;  /* Wall-Plug Efficiency (%) */
} SimPoint;

void simulate_laser_diode(const DiodeParams* params, double I_max_mA, double I_step_mA, 
                          SimPoint* results, size_t* out_count) {
    size_t count = 0;
    const double T_ref = 20.0; /* °C */
    const double photon_energy_eV = (CONST_HC / (params->lambda_0_nm * 1e-9)) / CONST_Q;

    for (double I_mA = 0.0; I_mA <= I_max_mA; I_mA += I_step_mA) {
        double I_A = I_mA / 1000.0;
        
        /* Початкове наближення для температури активної зони */
        double T_j = params->T_sub_C;
        double V_val = 0.0;
        double P_opt_mW = 0.0;
        
        /* Ітераційне узгодження теплового балансу */
        for (int iter = 0; iter < 5; ++iter) {
            /* 1. Напруга на p-n переході */
            V_val = photon_energy_eV + I_A * params->R_s_ohm;
            
            /* 2. Пороговий струм при температурі T_j */
            double I_th_mA = params->I_th0_mA * exp((T_j - T_ref) / params->T_0_K);
            
            /* 3. Оптична потужність */
            if (I_mA > I_th_mA) {
                P_opt_mW = photon_energy_eV * params->eta_d * (I_mA - I_th_mA);
            } else {
                P_opt_mW = 0.001 * photon_energy_eV * I_mA; /* Спонтанний режим */
            }
            
            /* 4. Оновлення температури через теплові втрати */
            double P_elec_mW = I_mA * V_val;
            double Q_heat_W = (P_elec_mW - P_opt_mW) / 1000.0;
            if (Q_heat_W < 0.0) Q_heat_W = 0.0;
            
            T_j = params->T_sub_C + params->R_th_KW * Q_heat_W;
        }

        double lambda_nm = params->lambda_0_nm + params->dlambda_dT * (T_j - T_ref);
        double P_elec_mW = I_mA * V_val;
        double wpe = (P_elec_mW > 1e-6) ? (P_opt_mW / P_elec_mW) * 100.0 : 0.0;

        results[count].current_mA = I_mA;
        results[count].voltage_V = V_val;
        results[count].power_mW = P_opt_mW;
        results[count].temp_C = T_j;
        results[count].lambda_nm = lambda_nm;
        results[count].wpe_percent = wpe;
        count++;
    }
    *out_count = count;
}

int main(void) {
    DiodeParams params = {
        .lambda_0_nm = 808.0,
        .I_th0_mA = 40.0,
        .T_0_K = 140.0,
        .eta_d = 0.85,
        .R_s_ohm = 2.5,
        .R_th_KW = 35.0,
        .dlambda_dT = 0.28,
        .T_sub_C = 25.0
    };

    SimPoint results[100];
    size_t count = 0;
    simulate_laser_diode(&params, 150.0, 15.0, results, &count);

    printf("=== МОДЕЛЮВАННЯ ЛАЗЕРНОГО ДІОДА (C11) ===\n");
    printf("  I (мА) |  V (В)  | P (мВт) | T (°C) | λ (нм) | WPE (%%)\n");
    printf("---------+---------+---------+--------+--------+---------\n");
    for (size_t i = 0; i < count; ++i) {
        printf("  %6.1f | %7.3f | %7.2f | %6.1f | %6.1f | %6.2f\n",
               results[i].current_mA, results[i].voltage_V, results[i].power_mW,
               results[i].temp_C, results[i].lambda_nm, results[i].wpe_percent);
    }
    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <expected>
#include <span>
#include <format>

namespace laser_sim {

constexpr double CONST_Q = 1.602176634e-19;
constexpr double CONST_HC = 1.98644586e-25;

struct DiodeConfig {
    double lambda_0_nm{808.0};
    double I_th0_mA{40.0};
    double T_0_K{140.0};
    double eta_d{0.85};
    double R_s_ohm{2.5};
    double R_th_KW{35.0};
    double dlambda_dT{0.28};
    double T_sub_C{25.0};
};

struct DataPoint {
    double current_mA;
    double voltage_V;
    double power_mW;
    double temp_C;
    double lambda_nm;
    double wpe_percent;
};

enum class SimError { InvalidStep, InvalidCurrentRange };

class LaserDiodeSimulator {
public:
    explicit LaserDiodeSimulator(DiodeConfig cfg) : config_(cfg) {}

    [[nodiscard]] std::expected<std::vector<DataPoint>, SimError> 
    run(double I_max_mA, double I_step_mA) const {
        if (I_step_mA <= 0.0) return std::unexpected(SimError::InvalidStep);
        if (I_max_mA <= 0.0) return std::unexpected(SimError::InvalidCurrentRange);

        std::vector<DataPoint> data;
        data.reserve(static_cast<size_t>(I_max_mA / I_step_mA) + 1);

        const double T_ref = 20.0;
        const double photon_energy_eV = (CONST_HC / (config_.lambda_0_nm * 1e-9)) / CONST_Q;

        for (double I_mA = 0.0; I_mA <= I_max_mA; I_mA += I_step_mA) {
            const double I_A = I_mA / 1000.0;
            double T_j = config_.T_sub_C;
            double V_val = 0.0;
            double P_opt_mW = 0.0;

            /* Самоузгоджена теплова ітерація */
            for (int iter = 0; iter < 5; ++iter) {
                V_val = photon_energy_eV + I_A * config_.R_s_ohm;
                const double I_th_mA = config_.I_th0_mA * std::exp((T_j - T_ref) / config_.T_0_K);

                if (I_mA > I_th_mA) {
                    P_opt_mW = photon_energy_eV * config_.eta_d * (I_mA - I_th_mA);
                } else {
                    P_opt_mW = 0.001 * photon_energy_eV * I_mA;
                }

                const double P_elec_mW = I_mA * V_val;
                double Q_heat_W = (P_elec_mW - P_opt_mW) / 1000.0;
                if (Q_heat_W < 0.0) Q_heat_W = 0.0;

                T_j = config_.T_sub_C + config_.R_th_KW * Q_heat_W;
            }

            const double lambda_nm = config_.lambda_0_nm + config_.dlambda_dT * (T_j - T_ref);
            const double P_elec_mW = I_mA * V_val;
            const double wpe = (P_elec_mW > 1e-6) ? (P_opt_mW / P_elec_mW) * 100.0 : 0.0;

            data.push_back(DataPoint{
                .current_mA = I_mA,
                .voltage_V = V_val,
                .power_mW = P_opt_mW,
                .temp_C = T_j,
                .lambda_nm = lambda_nm,
                .wpe_percent = wpe
            });
        }
        return data;
    }

private:
    DiodeConfig config_;
};

} // namespace laser_sim

int main() {
    using namespace laser_sim;

    DiodeConfig config{
        .lambda_0_nm = 808.0,
        .I_th0_mA = 40.0,
        .T_0_K = 140.0,
        .eta_d = 0.85,
        .R_s_ohm = 2.5,
        .R_th_KW = 35.0,
        .dlambda_dT = 0.28,
        .T_sub_C = 25.0
    };

    LaserDiodeSimulator sim(config);
    auto sim_result = sim.run(150.0, 15.0);

    if (!sim_result) {
        std::cerr << "Помилка симуляції!\n";
        return 1;
    }

    std::cout << "=== МОДЕЛЮВАННЯ ЛАЗЕРНОГО ДІОДА (C++23) ===\n";
    std::cout << std::format("{:>8} | {:>7} | {:>9} | {:>7} | {:>8} | {:>8}\n",
                             "I (мА)", "V (В)", "P (мВт)", "T (°C)", "λ (нм)", "WPE (%)");
    std::cout << "---------------------------------------------------------\n";

    for (const auto& pt : *sim_result) {
        std::cout << std::format("{:8.1f} | {:7.3f} | {:9.2f} | {:7.1f} | {:8.1f} | {:8.2f}\n",
                                 pt.current_mA, pt.voltage_V, pt.power_mW,
                                 pt.temp_C, pt.lambda_nm, pt.wpe_percent);
    }
    return 0;
}
```

### 4. Детальний порівняльний аналіз архітектури C11 та C++23

Наведений код показує суттєву відмінність між підходами низькорівневого програмування мовою C та сучасного системного програмування на мові C++23:

1. **Керування пам'яттю та динамічне виділення**:
   - У версії C11 функція `simulate_laser_diode` очікує, що зумовлюючий код виділить фіксований буфер `SimPoint results[100]` на стеку або через `malloc`. Якщо кількість точок перебільшить розмір буфера, станеться вихід за межі пам'яті.
   - У версії C++23 вектор `std::vector<DataPoint>` динамічно змінює свій розмір, заздалегідь резервуючи об'єм пам'яті через `data.reserve()`, що усуває зайві повторні алокації та гарантує повну безпеку роботи з пам'яттю.

2. **Захист від невалідних входів та монадний відгук**:
   - Версія C++23 використовує монадний тип `std::expected<T, E>`, запроваджений у стандарті C++23. Це дає змогу повертати або розрахований вектор даних, або об'єкт помилки `SimError` без використання повільних та небезпечних винятків (exceptions).
   - У версії C11 перевірка некоректних параметрів вимагає повернення спеціального коду помилки `int` або використання додаткових прапорців.

3. **Сучасне форматування та продуктивність I/O**:
   - Використання `std::format` у C++23 поєднує зручність Python-форматування `{:8.1f}` із високою швидкістю виконання, що перевершує за продуктивністю традиційний `printf` та старі стрими `std::cout << std::setw()`.

```text
   105.0 |   1.798 |   76.60 |   28.9 |  810.5 |    40.57
   120.0 |   1.835 |   93.20 |   29.4 |  810.6 |    42.33
   135.0 |   1.873 |  109.40 |   30.0 |  810.8 |    43.27
   150.0 |   1.910 |  125.20 |   30.7 |  811.0 |    43.70
```

Проаналізуємо ключові фізичні висновки на основі виведених даних:

1. **Злам на пороговому струмі (`I_th ≈ 41.5 мА`)**:
   - При струмах до 30 мА оптична потужність не перевищує `0.05 мВт`, а ККД стінної розетки WPE є близьким до нуля (`0.1%`).
   - Як тільки струм досягає 45 мА, лазер виходить вище порогу генерації: потужність миттєво зростає у 120 разів (до `6.2 мВт`), а ККД стрибає до `8.37%`.
2. **Лінійність запорогової ділянки та оптимізація WPE**:
   - При струмах 60–150 мА вихідна потужність зростає лінійно зі зсувом `dP/dI ≈ 1.12 мВт/мА`.
   - Ефективність WPE досягає свого насичення на рівні `43.7%` при струмі 150 мА, що свідчить про високу ефективність перетворення електричної енергії.
3. **Температурний нагрів та спектральний червоний зсув**:
   - Тепловиділення в активній зоні при струмі 150 мА становить `Q_heat = 150 мА · 1.91 В - 125.2 мВт = 161.3 мВт`.
   - Це нагріває p-n перехід на `ΔT = 35 К/Вт · 0.1613 Вт = 5.7 °C` (до `30.7 °C`), що зміщує довжину хвилі від `809.4 нм` до `811.0 нм`. В оптичних системах накачки це вимагає точного налаштування підкладки за допомогою елемента Пельтьє.

### 6. Схема ПІД-регулятора автоматичної оптичної потужності (APC)

У практичних оптичних трансиверах та волоконно-оптичних передавачах температура довкілля може змінюватися у широких межах (від -40 °C до +85 °C). Як показує побудована модель, зміна температури на 30 °C призводить до збільшення порогового струму `I_th` з 40 мА до `40 · exp(30/140) = 49.5 мА`. Якщо подавати фіксований струм інжекції `I = 50 мА`, оптична потужність впаде з `12.5 мВт` до менш ніж `0.6 мВт`, що призведе до повного зриву оптичного зв'язку.

Для стабілізації оптичної потужності використовують **контур автоматичного регулювання потужності** (APC / *Automatic Power Control*). На задньому дзеркалі лазерного діода встановлюють фотодіод моніторингу (*Monitor Photodiode*), струм якого `I_mon` є строго пропорційним вихідній оптичній потужності `P_opt`:

```
I_mon = S_mon · P_rear = S_mon · P_opt · (P_rear / P_front)
```

де `S_mon` — токова чутливість фотодіода (А/Вт).

Алгоритм ПІД-регулятора (*Proportional-Integral-Derivative Controller*) у мікроконтролері керування струмом інжекції на кожному вимірювальному такті обчислює помилку `e(t) = P_target - P_measured(t)` та коригує струм інжекції:

```
I_bias(t) = K_p · e(t) + K_i · ∫ e(τ) dτ + K_d · (de/dt)
```

Симуляція контуру APC показує, що пропорційно-інтегральний аналіз дозволяє утримувати стабільну оптичну потужність `P_target = 10.0 мВт` з точністю краще ніж 0.5% у всьому діапазоні робочих температур від -20 °C до +70 °C за рахунок автоматичного підтягування струму зміщення `I_bias(T)`.

### 7. Чисельне інтегрування динаміки релаксаційних коливань (Метод Рунге-Кутти)

Статична модель дає змогу розрахувати характеристики при постійному струмі, але для оцінки швидкості передачі даних у цифрових волоконно-оптичних лініях необхідно розв'язувати часові диференціальні рівняння швидкостей `dn/dt` та `dS/dt`.

Оскільки час життя фотонів `τ_p ≈ 2 пікосекунди`, а час життя електронів `τ_e ≈ 2 наносекунди`, система рівнянь швидкостей є **жорсткою** (*stiff differential equations*). Використання явного методу Ейлера з великим кроком `dt > 0.1 пс` призводить до чисельної нестабільності та розгону нефізичних коливань.

Для моделювання перехідних процесів прямої модуляції лазерного діода застосовують **метод Рунге-Кутти 4-го порядку (RK4)**. Алгоритм розрахунку вектора стану `Y = [n, S]^T` на кожному кроці за часом `t_{k+1} = t_k + dt` задається формулою:

```
K₁ = f(t_k, Y_k)
K₂ = f(t_k + dt/2, Y_k + (dt/2) · K₁)
K₃ = f(t_k + dt/2, Y_k + (dt/2) · K₂)
K₄ = f(t_k + dt, Y_k + dt · K₃)
Y_{k+1} = Y_k + (dt / 6) · (K₁ + 2·K₂ + 2·K₃ + K₄)
```

Чисельний аналіз за допомогою RK4 показує, що при подачі прямокутного імпульсу струму `I_pulse` вихідна потужність `P_opt(t)` реагує із затримкою вмикання `t_delay ≈ τ_e · ln(I_pulse / (I_pulse - I_th))`, після чого виникають згасаючі релаксаційні піки з частотою `f_r ≈ 12 ГГц`. Отриманий часовий профіль дозволяє будувати очні діаграми (Eye Diagrams) та розраховувати коефіцієнт бітових помилок (BER / Bit Error Rate) для оптичних систем зв'язку 10G та 25G Ethernet.

### 8. Моделювання багатошарових квантових ям (MQW) та геометрична оптимізація

Для переходу від тривимірної об'ємної моделі до башарових квантових ям (Multi-Quantum Well, MQW) чисельний симулятор перераховує пороговий струм із урахуванням двовимірної густини станів та числа ям `N_qw`.

При зменшенні товщини активного шару з `100 нм` до `N_qw · d_qw = 3 · 8 нм = 24 нм` геометричний об'єм рекомбінації `V` зменшується в 4.16 раза. Водночас коефіцієнт оптичного утримання `Γ` для 3 ям становить `Γ_3qw ≈ 0.06`, а диференціальне підсилення зростає до `a_qw = 4.5·10⁻¹⁶ см²`.

Враховуючи ці параметри, програма обчислює нове значення порогової концентрації носіїв:

```
n_th_qw = n_tr_qw + (α_i + α_m) / (Γ_3qw · a_qw)
```

Чисельний розрахунок показує, що для 3-х квантових ям `InGaAs/GaAs` пороговий струм знижується з `40.0 мА` до `8.5 мА`, що зменшує Джоулеве тепловиділення в 16 разів і дозволяє лазерному діоду працювати без активного охолодження при температурах довкілля до +85 °C.

### 9. Просторовий розрахунок кутової розбіжності та вибір колімуючих лінз

Окрім електричних та оптичних характеристик, симулятор виконує розрахунок просторової дифракційної розбіжності лазерного променя. Випромінююча апертура має прямокутні розміри `d = 0.15 мкм` (вертикальна товщина) та `w = 4.0 мкм` (ширина смужки).

За формулами хвильової дифракції на прямокутному вікні кути розбіжності по піввисоті інтенсивності (FWHM) становлять:

```
θ_fast = 2 · arcsin(1.18 · λ / (π · d)) ≈ 36.5°
θ_slow = 2 · arcsin(1.18 · λ / (π · w)) ≈ 9.2°
```

На основі розрахованих кутів розбіжності програма обчислює числову апертуру (NA) та фокусні відстані двох анаморфних циліндричних лінз `f_fast` та `f_slow`, необхідних для трансформації еліптичного конуса випромінювання в ідеально круглий гаусів промінь із коефіцієнтом якості `M² < 1.1`.

### 10. Інтеграція моделі з конвеєрами автоматизованого тестування та візуалізації

1. **Експорт у стандартизовані структуровані формати**: Модуль дозволяє серіалізувати обчислені масиви даних `DataPoint` у текстовий формат CSV або JSON-потік через `std::format`. Це дає змогу передавати результати безпосередньо у скрипти візуалізації Python (Matplotlib, Seaborn) чи системні аналізатори GNUplot без проміжних перетворень.

### 11. Калібрування модел за експериментальними вимірювальними даними

У реальному виробництві кожен вирощений кристал напівпровідникової пластини має технологічний розкид параметрів. Для точної прив'язки чисельної моделі до фізичного пристрою використовують метод **зворотного калібрування** (*parameter extraction*).

На автоматизованій вимірювальній оптичній лаві за допомогою інтегруючої сфери та спектрометра знімають реальну експериментальну характеристику `P_exp(I)` та `V_exp(I)` при декількох фіксованих температурах підкладки (20 °C, 40 °C, 60 °C).

Використовуючи метод найменших квадратів Левенберга-Марквардта (*Levenberg-Marquardt non-linear fitting*), програма оптимізує вектор параметрів `Θ = [I_th0, T_0, η_d, R_s, R_th]`, мінімізуючи функцію неузгодження:

```
χ²(Θ) = ∑_i (P_exp(I_i) - P_model(I_i, Θ))² + w_v · ∑_i (V_exp(I_i) - V_model(I_i, Θ))²
```

Калібрування дає змогу визначити приховані фізичні параметри гетероструктури — такі як внутрішній омічний опір `R_s` та тепловий опір монтажу `R_th` — без руйнування діодного корпусу, що робить розроблений чисельний інструмент незамінним у практичній оптоелектроніці.

### 12. Електричні кола захисту лазерного діода від ESD та імпульсних завад

Напівпровідниковий лазер є надзвичайно чутливим до напругових сплесків та електростатичних розрядів (ESD / *Electrostatic Discharge*). Зворотна напруга `V_rev > 2 – 3 В` викликає зворотний пробій p-n переходу, а короткі наносекундні сплески прямого струму призводять до миттєвого катастрофічного оптичного пошкодження (COD).

Для забезпечення надійної експлуатації симулятор розраховує додаткові пасивні елементи схем захисту джерела живлення:
- **Захисний зустрічно-паралельний діод Шотткі**: Підключається паралельно лазерному діоду у зворотному напрямку. При випадковій подачі зворотної напруги діод Шотткі шунтує струм при напрузі `V_f ≈ 0.3 В`, захищаючи p-n перехід лазера від пробою.
- **Фільтр нижніх частот та феритові намистини**: Вхідне коло живлення містить дросель та феритові намистини (*Ferrite Beads*) з індуктивністю `L = 10 мкГн`, що згладжують високочастотні імпульсні завади від перемикання імпульсних джерел живлення.
- **Схема плавного запуску (Soft-Start)**: Драйвер прямого струму плавно піднімає напругу живлення за час `t_ramp = 10 – 50 мс`, запобігаючи виникненню кидків струму під час вмикання живлення.
- **Екранування та заземлення ліній зв'язку**: Провідники від драйвера струму до корпусу діода виконують у вигляді крученої пари у заземленому мідному екрані. Це усуває паразитичні наводки від імпульсних джерел та високочастотного радіовипромінювання.
Ретельне проектування схем електроживлення та захисту є обов'язковою умовою досягнення гарантованого терміну служби напівпровідникового лазера понад 100 000 годин.
