# 🧮 Математичне виведення оптичної маси повітря та геометрії інсоляції

Цей математичний вивід розкриває геометрію оптичного шляху сонячних променів у плоскій та сферичній атмосфері, а також формалізм інтегрування закону Бугера — Ламберта — Бера для спектрального згасання.

### Плоскопаралельна модель атмосфери

Розглянемо геометрію поширення світла у спрощеній моделі, де атмосфера Землі представлена у вигляді однорідного плоского шару товщиною `h_atm`. Сонце перебуває під зенітним кутом `θ_z` (кут між напрямком на сонячний диск та вертикальною нормаллю до поверхні Землі в точці спостереження).

Коли Сонце перебуває в зениті (`θ_z = 0°`), сонячний промінь долає найкоротший прямий шлях через атмосферу, який дорівнює вертикальній товщині газового шару `h_atm`. Цей стандартний шлях приймається за фундаментальну одиницю оптичної маси повітря:

```
AM = 1.0     [при θ_z = 0°]
```

Якщо Сонце відхиляється від зеніту на кут `θ_z`, геометрична довжина похилого оптичного шляху `S` у прямокутному трикутнику, утвореному вертикаллю спостерігача, променем Сонця та горизонтальною поверхнею, виражається як:

```
S = h_atm / cos(θ_z)
= h_atm · sec(θ_z)
```

Маса повітря `AM` за означенням дорівнює відношенню геометричної довжини похилого шляху `S` до вертикальної товщини атмосфери `h_atm`:

```
AM = S / h_atm
= (h_atm · sec(θ_z)) / h_atm    [підстановка виразу для S]
= sec(θ_z)                      [скорочення h_atm]
= 1 / cos(θ_z)                  [за означенням тригонометричного секанса]
```

Ця плоскопаралельна формула `AM = 1 / cos(θ_z)` забезпечує високу обчислювальну точність для малих і помірних зенітних кутів (`θ_z < 60°`). Наприклад, при `θ_z = 60°` маса повітря дорівнює `AM = 1 / cos(60°) = 2.0`, що означає подвоєний шлях світла порівняно із зенітом.

### Точна геометрія сферичної атмосфери та формула Кастена — Янга

При помітних зенітних кутах (`θ_z > 70°`) плоскопаралельна модель дає суттєву похибку, а при наближенні Сонця до горизонту (`θ_z = 90°`) вираз `1 / cos(90°)` прямує до нескінченності, що суперечить фізичній дійсності. У реальних умовах поверхня Землі має сферичну кривизну, а оптична товщина шару обмежується кривизною планетного диска.

Враховуючи радіус Землі `R_E ≈ 6371 км` та ефективну висоту однорідної атмосфери `h_atm ≈ 8.5...9.0 км` (визначену через інтегрування барометричної формули розподілу тиску `P(z) = P₀·exp(-z/h_atm)`), геометричний трикутник з вершинами в центрі Землі `O`, точці спостереження `P` та точці входу променя в атмосферу `A` не є прямокутним.

Застосовуючи теорему косинусів для трикутника `OPA` зі сторонами `OA = R_E + h_atm`, `OP = R_E` та `PA = S`, має місце співвідношення:

```
(R_E + h_atm)² = R_E² + S² - 2·R_E·S·cos(180° - θ_z)
(R_E + h_atm)² = R_E² + S² + 2·R_E·S·cos(θ_z)            [тригонометрична тотожність]
```

Розкриваючи дужки в лівій частині та зводячи подібні доданки:

```
R_E² + 2·R_E·h_atm + h_atm² = R_E² + S² + 2·R_E·S·cos(θ_z)
S² + 2·R_E·S·cos(θ_z) - (2·R_E·h_atm + h_atm²) = 0      [квадратне рівняння відносно S]
```

Розв'язуючи квадратне рівняння відносно довжини шляху `S` та обираючи додатний корінь:

```
S = -R_E·cos(θ_z) + √(R_E²·cos²(θ_z) + 2·R_E·h_atm + h_atm²)
```

Поділивши обидві частини на `h_atm`, отримуємо вираз для геометричної маси повітря сферичної атмосфери:

```
AM = S / h_atm
= √((R_E / h_atm)² · cos²(θ_z) + 2·(R_E / h_atm) + 1) - (R_E / h_atm) · cos(θ_z)
```

Для відношення `R_E / h_atm ≈ 6371 / 9.0 ≈ 708` на горизонті (`θ_z = 90°`, `cos(90°) = 0`) чиста геометрична формула дає скінченне значення `AM = √(2 · 708 + 1) ≈ 37.6`.

У реальній атмосфері світловий промінь додатково зазнає заломлення (оптичної рефракції) у шарах повітря зі зростаючою густиною біля поверхні. Для урахування рефракції та реального профілю температури у практичних розрахунках застосовують емпіричну апроксимаційну формулу Кастена — Янга (*Kasten-Young model*, 1989), яка забезпечує високу точність по всій небесній напівсфері аж до самого горизонту:

```
AM = 1 / (cos(θ_z) + 0.50572 · (96.07995 - θ_z)^(-1.6364))
```

При `θ_z = 90°` ця формула дає значення маси повітря `AM ≈ 37.9` біля поверхні моря, що повністю відповідає фотометричним вимірюванням на сході та заході Сонця.

### Інтегрування Бугера — Ламберта — Бера для спектрального згасання

Випромінювання Сонця, потрапляючи в атмосферу, зазнає згасання за рахунок розсіяння та поглинання. Диференціальне зменшення спектральної потокової густини `dI(λ)` на нескінченно малому відрізку шляху `ds` пропорційне поточній інтенсивності `I(λ)` та загальному коефіцієнту екстинкції `k(λ)`:

```
dI(λ) = -k(λ) · I(λ) · ds
dI(λ) / I(λ) = -k(λ) · ds                                 [розділення змінних]
```

Інтегруючи це рівняння вздовж усього шляху променя від верхньої межі атмосфери (`s = 0`, `I = I₀`) до поверхні Землі (`s = S`, `I = I_dir`), маємо:

```
∫ (1 / I(λ)) dI(λ) = -∫ k(λ) ds
ln(I_dir(λ)) - ln(I₀(λ)) = -τ(λ) · AM                      [де τ(λ) = ∫ k(λ) dh_atm]
I_dir(λ) = I₀(λ) · exp(-τ(λ) · AM)                        [потенціювання]
```

Загальна оптична товщина атмосфери `τ(λ)` складається із суми чотирьох незалежних фізичних механізмів:

```
τ(λ) = τ_Rayleigh(λ) + τ_Mie(λ) + τ_O3(λ) + τ_H2O(λ)
```

1. **Молекулярне Релеєвське розсіяння** (на молекулах N₂ та O₂):
   Оптична товщина Релея описується класичною формулою з сильною спектральною залежністю:

   ```
   τ_Rayleigh(λ) = 0.008735 · λ^(-4.08) · (P / P₀)
   ```

   Тут `P / P₀` — відношення місцевого барометричного тиску до стандартного (1013.25 гПа). Оскільки оптична товщина обернено пропорційна четвертому степеню довжини хвилі `λ^(-4.08)`, синє світло (`400 нм`) розсіюється майже у 9 разів інтенсивніше за червоне (`700 нм`).

2. **Аерозольне Мі-розсіяння** (на частинках пилу, вологи та смогу):
   Описується емпіричним рівнянням Онгстрема:

   ```
   τ_Mie(λ) = β_aero · λ^(-α)
   ```

   Тут `β_aero` — коефіцієнт мутності атмосфери Онгстрема (варіює від 0.02 для кришталево чистого гірського повітря до 0.5 для засмогованого мегаполіса), а `α` — показник розміру аерозольних часток (зазвичай `0.8 ... 1.5`).

3. **Спектральне поглинання газами** (озон O₃ у смугах Хартлі-Шаппюї, водяна пара H₂O та вуглекислий газ CO₂ в ІЧ-діапазоні):
   Розраховується за вузькосмуговими коефіцієнтами поглинання з використанням молекулярних баз даних (наприклад, HITRAN).

### Трансформація кутів інсоляції для похилої поверхні

Для розрахунку прямого випромінювання, яке вловлюється похилою сонячною панеллю, необхідно визначити кут падіння `θ` між напрямком сонячного променя та векторною нормаллю до площини панелі.

Положення Сонця в горизонтальній системі координат визначається двома кутами:
- Зенітним кутом `θ_z` (або висотою Сонця над горизонтом `α_s = 90° - θ_z`);
- Сонячним азимутом `γ_s` (кут від напрямку на південь по часовій стрілці).

Положення площини сонячної панелі задається:
- Кутом нахилу `β` відносно горизонтальної землі (`β = 0°` — горизонтальна, `β = 90°` — вертикальна);
- Азимутом панелі `γ` (напрямок нормалі панелі по горизонту відносно півдня).

У тривимірній декартовій системі координат (де вісь X спрямована на південь, Y — на схід, Z — у зеніт), одиничний вектор напрямку на Сонце `ŝ` та одиничний вектор нормалі до панелі `n̂` записуються як:

```
ŝ = (sin(θ_z)·cos(γ_s),  sin(θ_z)·sin(γ_s),  cos(θ_z))
n̂ = (sin(β)·cos(γ),      sin(β)·sin(γ),      cos(β))
```

Косинус кута падіння променя `cos(θ)` визначається як скалярний добуток цих двох одиничних векторів:

```
cos(θ) = ŝ · n̂                                          [скалярний добуток векторів]
= sin(θ_z)·cos(γ_s)·sin(β)·cos(γ) + sin(θ_z)·sin(γ_s)·sin(β)·sin(γ) + cos(θ_z)·cos(β)
= cos(θ_z)·cos(β) + sin(θ_z)·sin(β)·[cos(γ_s)·cos(γ) + sin(γ_s)·sin(γ)]  [групування]
= cos(θ_z)·cos(β) + sin(θ_z)·sin(β)·cos(γ_s - γ)        [косинус різниці кутів]
```

Отримане рівняння `cos(θ) = cos(θ_z)·cos(β) + sin(θ_z)·sin(β)·cos(γ_s - γ)` є фундаментальною тригонометричною формулою сонячної інженерії. Якщо розраховане значення `cos(θ) ≤ 0`, це означає, що Сонце перебуває за площиною модульу, і пряме випромінювання на лицьову поверхню не падає (`G_{b,T} = 0`).
