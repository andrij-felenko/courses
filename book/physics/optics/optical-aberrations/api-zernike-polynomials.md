# 📋 Довідник поліномів Церніке та критеріїв якості зображення

Поліноми Церніке (*Zernike polynomials*) утворюють математично ортогональну систему функцій на круговому зіничному отворі одиничного радіуса. Вони слугують де-факто міжнародним стандартом (стандарти ISO 24157 та ANSI Z80.28) для кількісного опису викривлень світлового хвильового фронту в сучасній прикладної оптиці, астрономічній адаптивній оптиці, офтальмології та хвильовій інтерферометрії. Завдяки властивості ортогональності будь-яке довільне спотворення хвильового фронту реальної оптичної системи можна однозначно розкласти в ряд за поліномами Церніке, де кожен коефіцієнт описує внесок конкретного фізичного типу аберації.

### 1. Теоретичні засади та математичне визначення поліномів Z_n^m(ρ, φ)

Система поліномів Церніке розроблена нідерландським фізиком і лауреатом Нобелівської премії Фріцом Церніке у 1934 році для аналізу дифракційного контрасту в мікроскопії та оцінки інтерферограм. 

Поліноми задаються у полярній системі координат `(ρ, φ)`, де `0 ≤ ρ ≤ 1` — нормований радіальний координатный радіус на вхідній або вихідній зіниці оптичної системи, а `0 ≤ φ < 2π` — азимутальний кут.

Кожен поліном Церніке характеризується двома цілочисельними індексами:
- `n` — радіальний порядок або степінь полінома (`n ≥ 0`), що визначає найвищий степінь радіальної координати `ρ`;
- `m` — азимутальний порядок або кутова частота (`|m| ≤ n`), причому різниця `n - |m|` обов'язково має бути парним числом.

Загальна формула ортонормованого полінома Церніке має вигляд:

```
Z_n^m(ρ, φ) = N_n^m · R_n^m(ρ) · M(m · φ)     [Поліном Церніке]
```

Кутова частина `M(m · φ)` визначає азимутальну симетрію спотворення:

```
M(m · φ) = cos(m · φ)   при m ≥ 0
M(m · φ) = sin(|m| · φ) при m < 0
```

Радіальна функція `R_n^m(ρ)` являє собою ортогональний поліном від радіуса `ρ`, який обчислюється через скінченну суму:

```
R_n^m(ρ) = ∑_{k=0}^{(n-|m|)/2} [ (-1)^k · (n - k)! ] / [ k! · ((n + |m|)/2 - k)! · ((n - |m|)/2 - k)! ] · ρ^(n - 2k)
```

Нормувальний коефіцієнт `N_n^m` вибрано таким чином, щоб дисперсія (середній квадрат) кожного окремого полінома по площі одиничного круга дорівнювала одиниці (`RMS = 1`):

```
N_n^m = √( 2 · (n + 1) / (1 + δ_m0) )
```

де `δ_m0` — символ Кронекера (`δ_m0 = 1` при `m = 0`, та `δ_m0 = 0` при `m ≠ 0`).

Фундаментальною властивістю поліномів Церніке є їхня ортогональність на круговому дискі:

```
∫₀¹ ∫₀²ⁿ Z_n^m(ρ, φ) · Z_p^q(ρ, φ) · ρ dρ dφ = π · δ_np · δ_mq
```

Це означає, що при аналізі оптичної системи зміна або корекція одного коефіцієнта Церніке (наприклад, фокусування `Z₄`) не змінює значення і не впливає на виміряні коефіцієнти інших аберацій (наприклад, коми `Z₇` чи сферичної аберації `Z₁₁`).

### 2. Індексація за Ноллом та ANSI Z80.28

У практичному оптичному програмуванні та інтерферометрії подвійний індекс `(n, m)` незручно використовувати для матричних обчислень. Тому розроблено алгоритми зведення подвійної індексації до єдиного наскрізного індексу `j`.

Найбільш поширеними є дві системи індексації:
1. **Схема Нолла (*Noll ordering*):** Призначена для атмосферної адаптивної оптики та обчислення турбулентності. У ній поліноми з нижчим радіальним порядком `n` отримують менші індекси, а при однаковому `n` коефіцієнти з парними кутовими функціями (`cos`) передують непарним (`sin`).
2. **Стандарт ANSI Z80.28 / ISO 24157:** Використовується в офтальмології, лазерній корекції зору та вимірювачах аберацій ока (аберометрах Шака-Гартмана). Індекс обчислюється строго за формулою:

```
j_ANSI = (n · (n + 2) + m) / 2     [Формула індексу ANSI]
```

| Індекс Нолла `j` | ANSI `j_ANSI` | Порядок `(n, m)` | Радіальна функція `R_n^m(ρ)` | Поліном `Z_j(ρ, φ)` | Фізична інтерпретація аберації |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **1** | 0 | (0, 0) | `1` | `1` | **Поршень (*Piston*):** Рівномірний фазовий зсув усього хвильового фронту. Не впливає на якість зображення. |
| **2** | 2 | (1, 1) | `ρ` | `2 · ρ · cos φ` | **Нахил по X (*Tilt X*):** Поперечне зміщення точкового зображення вздовж осі X без розмиття. |

### 3. Метрики якості хвильового фронту та інтегральні коефіцієнти

Будь-яка реальна аберація оптичного приладу вимірюється інтерферометром (наприклад, інтерферометром Тваймана-Гріна) або датчиком хвильового фронту Шака-Гартмана. Результатом вимірювання є двовимірна карта відхилень хвильового фронту `W(ρ, φ)`.

Розклад карти у скінченну суму за поліномами Церніке має вигляд:

```
W(ρ, φ) = ∑_{j=1}^{N} c_j · Z_j(ρ, φ)     [Розклад хвильового фронту]
```

де `c_j` — вагові коефіцієнти Церніке, які вимірюються в мікронах (`мкм`) або довжинах хвиль (`λ`).

#### А. Середньоквадратична помилка хвильового фронту (W_RMS)
Завдяки ортонормованості поліномів Церніке, середньоквадратичне відхилення хвильового фронту від ідеальної сфери `W_RMS` обчислюється за винятково простою алгебраїчною формулою (теорема Парсеваля для поліномів Церніке):

```
W_RMS = √( ∑_{j=4}^{N} (c_j)² )     [Формула W_RMS]
```

У цій сумі коефіцієнти поршня `c₁` та нахилів `c₂, c₃` свідомо відкидаються, оскільки поршень описує лише загальну фазу, а нахили — лінійне зміщення картини без втрати чіткості.

#### Б. Повний розмах хвильової аберації Peak-to-Valley (W_PV)
Метрика `W_PV` показує максимальну різницю між найвищим піком та найглибшою западиною хвильового фронту на зіниці:

```
W_PV = max(W(ρ, φ)) - min(W(ρ, φ))     [Абераційний розмах Peak-to-Valley]
```

Хоча `W_PV` є дуже популярним і простим критерієм, він є чутливим до поодиноких локальних дефектів скла або шуму вимірювання. Тому в сучасному оптичному дизайні основним критерієм оцінки чіткості є саме метрика `W_RMS`.

#### В. Число Штреля (Strehl Ratio) та наближення Марешаля
**Число Штреля** `S` (`0 ≤ S ≤ 1.0`) є головним кількісним показником якості оптичного зображення. Воно визначається як відношення пикової інтенсивності світла в центрі реальної дифракційної плями Ері до пікової інтенсивності ідеальної оптичної системи, що обмежена лише дифракцією:

```
S = I_real(0, 0) / I_ideal(0, 0)     [Число Штреля]
```

Для оптичних систем з малими абераціями (`W_RMS ≤ λ / 14`) французький оптик Андре Марешаль запропонував точне експоненційне наближення (**наближення Марешаля**):

```
S ≈ exp( - (2π · W_RMS / λ)² ) ≈ 1 - (2π · W_RMS / λ)²     [Наближення Марешаля]
```

Якщо `W_RMS = λ / 14` (що відповідає приблизно `0.071 λ`), число Штреля за формулою Марешаля дорівнює:

```
S ≈ exp( - (2π / 14)² ) = exp( - 0.201 ) ≈ 0.818     [Значення межі Марешаля]
```

Це значення `S ≥ 0.80` є фундаментальним порогом в оптиці: якщо число Штреля перевищує `0.80`, оптична система вважається **дифракційно-обмеженою** (*diffraction-limited*), а її залишені аберації є практично непомітними для спостерігача.

### 4. Стандартизовані критерії якості optical-систем

У науковому приладобудуванні, космічній галузі та виготовленні напівпровідників застосовуються строго градаційні вимоги до залишкових аберацій хвильового фронту:

| Критерій та рівень якості | Допуск за розмахом `W_PV` | Допуск за дисперсією `W_RMS` | Число Штреля `S` | Область практичного застосування |
| :--- | :--- | :--- | :--- | :--- |
| **Критерій Релея** (*Rayleigh 1/4 wave*) | `W_PV ≤ λ / 4` (0.25 λ) | `W_RMS ≤ λ / 13.5` | `S ≥ 0.80` | Аматорські телескопи, шкільні мікроскопи, біноклі. |
| **Дифракційна межа Марешаля** (*Diffraction limited*) | `W_PV ≤ λ / 5` (0.20 λ) | `W_RMS ≤ λ / 14` (0.071 λ) | `S ≥ 0.80` | Професійні фотооб'єктиви, лабораторні мікроскопи. |
| **Високопрецизійна оптика** (*Precision optics*) | `W_PV ≤ λ / 10` (0.10 λ) | `W_RMS ≤ λ / 30` (0.033 λ) | `S ≥ 0.955` | Астрономічні обсерваторії, лазерні спектрометри. |
| **Суперпрецизійна оптика** (*Sub-wavelength optics*) | `W_PV ≤ λ / 20` (0.05 λ) | `W_RMS ≤ λ / 60` (0.017 λ) | `S ≥ 0.989` | Космічний телескоп Джеймс Вебб (JWST), космічний телескоп Габбл. |
| **Екстремальна оптика** (*Extreme optics*) | `W_PV ≤ λ / 50` (0.02 λ) | `W_RMS ≤ λ / 150` (0.0067 λ) | `S ≥ 0.998` | Проекційні об'єктиви EUV-літографії (ASML), інтерферометри LIGO. |

### 5. Інтерпретація карт хвильового фронту та адаптивна оптика

Виміряний ряд коефіцієнтів Церніке дозволяє не лише діагностувати дефекти виготовлення лінз і дзеркал, але й в режимі реального часу компенсувати спотворення атмосфери у великих наземних телескопах (наприклад, *Very Large Telescope*, VLT чи *Keck Observatory*).

У системах **адаптивної оптики** (*Adaptive Optics*) датчик Шака-Гартмана вимірює нахили світлової хвилі від астрономічної опорної зорі та обчислює коефіцієнти Церніке `c₄ ... c₂₀`. Потім електронний контролер подає керуючі напруги на п'єзоелектричні приводи деформівного дзеркала (*deformable mirror*). Дзеркало вигинається у форму, що є дзеркальним відображенням поліномів Церніке хвильового фронту, компенсуючи атмосферну турбулентність та піднімаючи число Штреля з `0.05` до `0.85-0.92`.

В офтальмології аналіз поліномів Церніке `Z₄` (дефокус), `Z₅, Z₆` (астигматизм) та `Z₇, Z₈` (кома рогівки) дозволяє розраховувати індивідуальний профіль абляції ексимерного лазера при проведенні процедур персоніфікованої лазерної корекції зору (Custom LASIK/Wavefront LASIK). Це дозволяє виправляти не лише звичайну короткозорість, але й аберації вищих порядків, забезпечуючи так званий «суперзір» (`20/10` або `200%`).
