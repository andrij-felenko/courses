# 🧮 Математична модель лоренцівського осцилятора та класичне виведення дисперсії

Фундаментальне математичне та фізичне пояснення оптичної дисперсії світла у прозорих діелектриках спирається на класичну електронну теорію Хендріка Лоренца (*Hendrik Lorentz*). Згідно з цією теорією, речовина розглядається не як суцільна суцільна середовищна маса, а як дискретний ансамбль позитивно заряджених важких атомних ядер та зв'язаних із ними негативно заряджених електронних оболонок. Коли крізь таке середовище поширюється електромагнітна хвиля, її змінне електричне поле змушує зв'язані електрони здійснювати вимушені коливання, перетворюючи кожний атом на мікроскопічний випромінювальний диполь.

Нижче наведено повне математичне виведення рівняння руху електрона, комплексної діелектричної проникності, показника заломлення, формул Зельмейєра та Коші, а також співвідношення для групової швидкості.

### 1. Диференціальне рівняння руху зв'язаного електрона

Розглянемо оптичний електрон масою `m` і зарядом `-e`, зв'язаний з атомом квазіпружною повертальною силою з власною частотою `ω₀`. При поширенні світлової хвилі на електрон діють три сили:
1. Повертальна пружна сила електронної оболонки: `F_elast = -m · ω₀² · x`
2. Сила опору та дисипації енергії (дисипація на випромінювання та атомарні зіткнення): `F_damp = -m · γ · (dx / dt)`
3. Зовнішня збуджувальна сила з боку електричного поля хвилі `E(t) = E₀ · e^(-i·ω·t)`: `F_ext = -e · E(t)`

За другим законом Ньютона рівняння руху електрона має вигляд:

```
m · (d²x / dt²) + m · γ · (dx / dt) + m · ω₀² · x = -e · E₀ · e^(-i·ω·t)
```

Поділивши обидві частини на масу `m`, отримуємо канонічне рівняння вимушених згасаючих коливань:

```
d²x / dt² + γ · (dx / dt) + ω₀² · x = -(e / m) · E(t)
```

Шукаємо стаціонарний розв'язок у формі гармонічних коливань із частотою зовнішнього поля `x(t) = x₀ · e^(-i·ω·t)`. Обчислюємо першу та другу похідні за часом:

```
dx / dt  = -i · ω · x₀ · e^(-i·ω·t)
d²x / dt² = -ω² · x₀ · e^(-i·ω·t)
```

Підставляємо похідні назад у диференціальне рівняння:

```
(-ω² - i · γ · ω + ω₀²) · x₀ · e^(-i·ω·t) = -(e / m) · E₀ · e^(-i·ω·t)
```

Скорочуємо часовий множник `e^(-i·ω·t)` та виражаємо амплітуду зсуву електрона `x₀`:

```
x₀ = -(e / m) / (ω₀² - ω² - i · γ · ω) · E₀
```

### 2. Макроскопічна поляризація та комплексна діелектрична проникність

Зсув електрона відносно ядра на відстань `x(t)` створює індукований елементарний дипольний момент атома `p(t) = -e · x(t)`. Якщо в одиниці об'єму середовища міститься `N` однакових осциляторів, макроскопічний вектор поляризації середовища `P(t)` дорівнює:

```
P(t) = N · p(t)
= N · (-e) · x(t)
= [ (N · e² / m) / (ω₀² - ω² - i · γ · ω) ] · E(t)     [макроскопічна поляризація]
```

Електрична сприйнятливість середовища `χ_e(ω)` визначається зі співвідношення `P = ε₀ · χ_e · E`:

```
χ_e(ω) = (N · e² / (ε₀ · m)) / (ω₀² - ω² - i · γ · ω)
```

Для зручності вводять поняття **плазмової частоти** електронного газу `ω_p`:

```
ω_p² = N · e² / (ε₀ · m)
```

Тоді комплексна діелектрична проникність середовища `ε̃(ω) = 1 + χ_e(ω)` набуває вигляду:

```
ε̃(ω) = 1 + ω_p² / (ω₀² - ω² - i · γ · ω)
```

Якщо в речовині наявні кілька груп електронів з різними власними частотами `ω_j`, силами осциляторів `f_j` (які задовільняють правило сум Томаса-Райхе-Куна `∑ f_j = 1`) та коефіцієнтами затухання `γ_j`, загальна діелектрична проникність є сумою внесків усіх типів осциляторів:

```
ε̃(ω) = 1 + (e² / (ε₀ · m)) · ∑ [ (N_j · f_j) / (ω_j² - ω² - i · γ_j · ω) ]
```

### 3. Поправка Лоренца на локальне поле (формула Лоренца-Лоренца)

У щільних діелектриках (скло, рідини, кристали) на кожен окремий атом діє не лише макроскопічне поле світлової хвилі `E`, але й додаткове мікроскопічне поле диполів сусідніх атомів. За розрахунком Лоренца, дійсне локальне електричне поле `E_loc`, що діє на електрон, становить:

```
E_loc = E + P / (3 · ε₀)
```

Підставляючи це локальне поле в рівняння поляризації, отримуємо співвідношення Лоренца-Лоренца (або Клаузіуса-Мосотті для статичних полів):

```
(n² - 1) / (n² + 2) = (N · e²) / (9 · ε₀ · m) · ∑ [ f_j / (ω_j² - ω² - i · γ_j · ω) ]
```

Це співвідношення описує залежність показника заломлення не лише від частоти хвилі, але й від густини речовини `N` та її температурного розширення.

### 4. Комплексний показник заломлення та розділення на дійсну й уявну частини

Комплексний показник заломлення `ñ(ω)` пов'язаний із комплексною діелектричною проникністю співвідношенням `ñ(ω) = √ε̃(ω)`. Розділивши `ñ` на дійсну та уявну частини:

```
ñ(ω) = n(ω) + i · κ(ω)
```

де:
- `n(ω)` — дійсний показник заломлення, що визначає фазову швидкість світла `v_p = c / n`.
- `κ(ω)` — показник екстинкції (поглинання), що описує затухання амплітуди хвилі за законом Бугера: `I(z) = I₀ · e^(-α·z)`, де `α = 2 · ω · κ / c`.

Здійснюючи розклад `ñ² = ε̃`:

```
(n + i · κ)² = n² - κ² + 2 · i · n · κ = ε' + i · ε''
```

Отримуємо систему двох рівнянь для дійсної `ε'` та уявної `ε''` частин:

```
n² - κ² = 1 + ω_p² · (ω₀² - ω²) / [ (ω₀² - ω²)² + γ² · ω² ]   [дійсна частина]
2 · n · κ = ω_p² · (γ · ω) / [ (ω₀² - ω²)² + γ² · ω² ]        [уявна частина]
```

При наближенні частоти хвилі до резонансу `ω ➔ ω₀` уявна частина `ε''` досягає максимуму, створюючи смугу поглинання, а дійсна частина `ε'` різко спадає, що призводить до аномальної дисперсії `dn / dω < 0` (`dn / dλ > 0`).

### 5. Виведення формул Зельмейєра та Коші для прозорих середовищ

У ділянках прозорості речовини частота світла `ω` лежить далеко від резонансних частот `ω_j`, а загасання `γ_j` є нехтовно малим (`γ_j ≈ 0`). У цьому випадку показник поглинання `κ ≈ 0`, а дійсний показник заломлення спрощується:

```
n²(ω) = 1 + ∑ [ (N_j · e² / (ε₀ · m)) / (ω_j² - ω²) ]
```

Перейдемо від колових частот `ω` до довжин хвиль у вакуумі `λ = 2 · π · c / ω`. Позначивши `λ_j = 2 · π · c / ω_j` як резонансні довжини хвиль поглинання:

```
ω_j² - ω² = (2 · π · c)² · (1 / λ_j² - 1 / λ²)
= (2 · π · c)² · (λ² - λ_j²) / (λ_j² · λ²)
```

Підставляючи це значення у формулу для `n²`, отримуємо класичне **рівняння Зельмейєра**:

```
n²(λ) = 1 + ∑ [ (A_j · λ²) / (λ² - B_j) ]
```

де `B_j = λ_j²` — квадрати резонансних довжин хвиль, а `A_j` — безрозмірні коефіцієнти, пропорційні густині та силі осциляторів відповідного типу.

Якщо довжина хвилі світла `λ` значно більша за резонансні УФ-довжини хвиль `λ_j` (`λ >> λ_j`), дріб у формулі Зельмейєра можна розкласти в геометричну прогресію за степенями `(λ_j / λ)²`:

```
λ² / (λ² - λ_j²) = 1 / (1 - (λ_j / λ)²)
= 1 + (λ_j / λ)² + (λ_j / λ)⁴ + ...
```

Підставляючи цей розклад у вираз для `n(λ) = √(1 + χ)` та добуваючи квадратний корінь за формулою Тейлора, отримуємо **формулу Коші**:

```
n(λ) = A + B / λ² + C / λ⁴
```

де:
- `A` — оптична стала середовища на безмежній довжині хвилі (`λ ➔ ∞`).
- `B` — коефіцієнт нормальної дисперсії, що визначає швидкість зміни показника заломлення у видимому діапазоні.

### 6. Виведення формули групової швидкості

Світловий імпульс або квазімонохроматична хвиля є суперпозицією спектральних компонент із частотами в інтервалі `[ω - Δω, ω + Δω]`. Огінаюча такого імпульсу поширюється зі **груповою швидкістю** `v_g`, яка виводиться з умови збереження фази обвідної:

```
v_g = dω / dk
```

Хвильове число `k` виражається через фазову швидкість `v_p = c / n(ω)`:

```
k(ω) = ω / v_p = ω · n(ω) / c
```

Обчислюємо повну похідну `dk / dω`:

```
dk / dω = d/dω [ (ω · n(ω)) / c ]
= (1 / c) · [ n(ω) + ω · (dn / dω) ]
```

Отже, групова швидкість дорівнює:

```
v_g = c / [ n(ω) + ω · (dn / dω) ]
```

Перейдемо від частоти `ω` до довжини хвилі `λ`. Використовуємо співвідношення `ω = 2 · π · c / λ`, звідки:

```
dω / dλ = -2 · π · c / λ²
```

Тоді похідна `dn / dω` перетворюється на:

```
dn / dω = (dn / dλ) · (dλ / dω)
= (dn / dλ) · [ -λ² / (2 · π · c) ]
```

Підставляємо цей результат у вираз для групової швидкості:

```
ω · (dn / dω) = (2 · π · c / λ) · (dn / dλ) · [ -λ² / (2 · π · c) ]
= -λ · (dn / dλ)
```

Отримуємо остаточну точну формулу для групової швидкості через довжину хвилі та дисперсію `dn / dλ`:

```
v_g = c / [ n(λ) - λ · (dn / dλ) ]
```

Вводиться також **груповий показник заломлення** `n_g`:

```
n_g = c / v_g = n(λ) - λ · (dn / dλ)
```

У зоні нормальної дисперсії `dn / dλ < 0`, тому `n_g > n(λ)`, а групова швидкість світлового імпульсу `v_g` завжди менша за фазову швидкість монохроматичної хвилі `v_p`.
