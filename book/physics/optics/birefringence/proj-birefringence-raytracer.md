# ⚙️ Чисельне моделювання двозаломлення: простеження звичайного та незвичайного променів в одновісному кристалі

Ця вставка містить практичну розрахункову модель, чисельний алгоритм та вихідний код мовами C та C++ для простеження траєкторій світлових променів в анізотропних одновісних кристалах. Модуль призначений для розрахунку ефективного показника заломлення незвичайного променя `nₑ(θ)`, кута зносу Пойнтінга `η`, фазового запізнення та просторового зсуву пучка `Δ` при довільній орієнтації оптичної осі кристала.

## 1. Постановка завдання та фізико-чисельна модель

При розробці оптичних симуляторів (наприклад, професійних аналогів Zemax, Code V, Synopsys CODE V або спеціалізованих модулів моделювання лазерних резонаторів) стандартний алгоритм простеження променів, побудований на класичному скалярному законі Снелла, є недійсним. В анізотропному середовищі необхідно розраховувати траєкторії двох незалежних хвиль із різними фізичними та геометро-динамічними властивостями:

1. **Ззвичайний промінь (Ordinary ray / o-ray):** Напрямок хвильового вектора `k_o` (хвильової нормалі) та напрямок вектора Пойнтінга `S_o` (променя) строго збігаються. Фазовий показник заломлення `n_o` залишається постійною величиною для будь-якого напрямку поширення в кристалі.
2. **Незвичайний промінь (Extraordinary ray / e-ray):** Напрямок поширення фазового фронту `k_e` взагалі не збігається з напрямком перенесення світлової енергії `S_e`. Ефективний фазовий показник заломлення `n_e(θ)` залежить від кута `θ` між хвильовим вектором та оптичною віссю кристала.

### Математичний алгоритм обчислення

Розглянемо плоский монохроматичний промінь із довжиною хвилі `λ`, який поширюється під кутом `θ` до оптичної осі одновісного кристала товщиною `d` із головними показниками заломлення `n_o` та `n_e`:

1. **Обчислення ефективного фазового показника заломлення `n_e(θ)`:**
   ```
   n_e(θ) = (n_o · n_e) / √(n_e² · cos²(θ) + n_o² · sin²(θ))
   ```
2. **Обчислення кута зносу Пойнтінга `η(θ)`:**
   ```
   η(θ) = arctan[ ((n_o² - n_e²) · tan(θ)) / (n_o² + n_e² · tan²(θ)) ]
   ```
3. **Просторовий зсув пучка `Δ` на виході з плоскопаралельної пластини товщиною `d`:**
   ```
   Δ = d · tan(|η|)
   ```
4. **Фазове запізнення `Δφ` між звичайною та незвичайною хвилями:**
   ```
   Δφ = (2π / λ) · d · |n_e(θ) - n_o|
   ```

## 2. Перетворення координат та граничні умови на межі анізотропного середовища

У тривимірному обчислювальному простеженні променів (3D Ray Tracing) орієнтація оптичної осі кристала задається одиничним вектором `a = (a_x, a_y, a_z)` у глобальній лабораторній системі координат `(X, Y, Z)`. Падаючий промінь визначається напрямним вектором `u = (u_x, u_y, u_z)`.

Скалярний добуток векторів дозволяє обчислити косинус кута між напрямком поширення хвилі та оптичною віссю кристала:

```
cos(θ) = u · a = u_x · a_x + u_y · a_y + u_z · a_z
```

Синус кута обчислюється через модуль векторного добутку:

```
sin(θ) = |u × a| = √(1 - (u · a)²)
```

### Закони заломлення на межі анізотропного середовища
При падінні променя з ізотропного середовища з показником `n_in` під кутом `θ_inc` на плоску грань анізотропного кристала з нормаллю `N` діє фундаментальна гранична умова Максвелла: **тангенціальна компонента хвильового вектора повинна бути безперервною вздовж поверхні розділу**:

```
k_tangential = (2π / λ) · n_in · sin(θ_inc) = const
```

Для звичайного променя кут заломлення `θ_ref,o` обчислюється за скалярним законом Снелла:

```
sin(θ_ref,o) = (n_in / n_o) · sin(θ_inc)
```

Для незвичайного променя показник заломлення `n_e(θ_ref,e)` сам залежить від невідомого кута заломлення `θ_ref,e`. Це дає трансцендентне рівняння:

```
n_e(θ_ref,e) · sin(θ_ref,e) = n_in · sin(θ_inc)
```

У наведеному нижче обчислювальному модулі реалізовано аналітичний розв'язок для плоскопаралельного проходження та чисельну процедуру розрахунку просторового зсуву та фазового запізнення.

## 3. Обчислення вектора Пойнтінга та кута зносу у тривимірному просторі

У тривимірному просторі напрямок вектора Пойнтінга `S_e` незвичайного променя обчислюється через напрямок хвильового вектора `k_e` та орієнтацію оптичної осі `a`:

```
S_e = n_e²(θ) · k_e + (n_o² - n_e²) · (k_e · a) · a
```

Після нормування вектор `S_e / |S_e|` визначає фактичну геометричну траєкторію незвичайного світлового пучка всередині кристала.

### Повне внутрішнє відбиття та крайові випадки

При досягненні межі кристала з повітрям або іншим середовищем можливе явище повного внутрішнього відбиття. Для незвичайного променя критичний кут відбиття залежить від кута до оптичної осі:

```
sin(θ_crit,e) = n_out / n_e(θ)
```

Оскільки `n_e(θ)` змінюється при зміні напрямку, критичний кут не є константою, що необхідно перевіряти на кожному кроці трасування в лазерних призмах.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

/* Структура паспортних параметрів одновісного кристала */
typedef struct {
    double n_o;        /* Звичайний показник заломлення */
    double n_e;        /* Головний незвичайний показник заломлення */
    const char* name;  /* Текстова назва кристалічного матеріалу */
} UniaxialCrystal;

/* Результати аналізу двозаломлення для конкретного променя */
typedef struct {
    double theta_deg;   /* Кут між хвильовим вектором та оптичною віссю (градуси) */
    double n_e_theta;   /* Ефективний показник заломлення e-променя */
    double walkoff_deg; /* Кут зносу Пойнтінга (градуси) */
    double shift_um;    /* Просторовий зсув e-променя (мікрометри) */
    double ret_rad;     /* Набіг різниці фаз (радіани) */
    double ret_deg;     /* Набіг різниці фаз (градуси) */
} BirefringenceResult;

/* Обчислення параметрів двозаломлення */
BirefringenceResult calculate_birefringence(const UniaxialCrystal* crystal,
                                           double theta_deg,
                                           double thickness_mm,
                                           double wavelength_nm) {
    BirefringenceResult res;
    res.theta_deg = theta_deg;

    /* Перехід до радіан */
    double theta = theta_deg * M_PI / 180.0;
    double cos_t = cos(theta);
    double sin_t = sin(theta);
    double tan_t = tan(theta);

    /* 1. Ефективний показник заломлення n_e(theta) */
    double no2 = crystal->n_o * crystal->n_o;
    double ne2 = crystal->n_e * crystal->n_e;
    double denom = sqrt(ne2 * cos_t * cos_t + no2 * sin_t * sin_t);
    res.n_e_theta = (crystal->n_o * crystal->n_e) / denom;

    /* 2. Кут зносу Пойнтінга eta */
    double eta = 0.0;
    if (fabs(cos_t) > 1e-12 && fabs(sin_t) > 1e-12) {
        eta = atan(((no2 - ne2) * tan_t) / (no2 + ne2 * tan_t * tan_t));
    }
    res.walkoff_deg = eta * 180.0 / M_PI;

    /* 3. Просторовий зсув променя (у мікрометрах) */
    double d_um = thickness_mm * 1000.0;
    res.shift_um = d_um * tan(fabs(eta));

    /* 4. Фазове запізнення */
    double delta_n = fabs(res.n_e_theta - crystal->n_o);
    double lambda_mm = wavelength_nm * 1e-6;
    res.ret_rad = (2.0 * M_PI / lambda_mm) * thickness_mm * delta_n;
    res.ret_deg = fmod(res.ret_rad * 180.0 / M_PI, 360.0);

    return res;
}

/* Друк таблиці аналізу */
void print_birefringence_table(const UniaxialCrystal* crystal,
                               double thickness_mm,
                               double wavelength_nm) {
    printf("=========================================================================\n");
    printf(" МАТЕРІАЛ: %s\n", crystal->name);
    printf(" Параметри: n_o = %.4f, n_e = %.4f, Δn_max = %+.4f\n",
           crystal->n_o, crystal->n_e, crystal->n_e - crystal->n_o);
    printf(" Умови: Товщина = %.1f мм, Довжина хвилі = %.1f нм\n", thickness_mm, wavelength_nm);
    printf("=========================================================================\n");
    printf(" Кут θ (°) |  n_e(θ)   | Знос η (°) | Зсув Δ (мкм) | Фаза (рад) | Фаза (°) \n");
    printf("-----------+-----------+------------+--------------+------------+----------\n");

    for (int deg = 0; deg <= 90; deg += 10) {
        BirefringenceResult r = calculate_birefringence(crystal, (double)deg, thickness_mm, wavelength_nm);
        printf("    %2d     |  %.6f |   %6.3f   |   %8.2f   | %10.2f |  %6.1f \n",
               deg, r.n_e_theta, r.walkoff_deg, r.shift_um, r.ret_rad, r.ret_deg);
    }
    printf("-------------------------------------------------------------------------\n\n");
}

int main(void) {
    /* Кальцит (одновісний негативний) */
    UniaxialCrystal calcite = {1.6580, 1.4864, "Кальцит (CaCO3) - Негативний"};
    /* Кварц (одновісний позитивний) */
    UniaxialCrystal quartz = {1.5426, 1.5517, "Кварц (SiO2) - Позитивний"};

    double thickness = 10.0;   /* 10 мм */
    double wavelength = 632.8;  /* Гелій-неоновий лазер */

    print_birefringence_table(&calcite, thickness, wavelength);
    print_birefringence_table(&quartz, thickness, wavelength);

    return 0;
}
```

```cpp
#include <iostream>
#include <cmath>
#include <iomanip>
#include <string_view>
#include <vector>
#include <numbers>

// Паспортні дані анізотропного одновісного кристала
struct UniaxialCrystal {
    double n_o{1.0};            // Звичайний показник заломлення
    double n_e{1.0};            // Незвичайний показник заломлення
    std::string_view name{};    // Назва кристала

    [[nodiscard]] constexpr double max_birefringence() const noexcept {
        return n_e - n_o;
    }
};

// Результат чисельного простеження променя
struct BirefringenceResult {
    double theta_deg;   // Кут між хвильовим вектором і оптичною віссю (°)
    double n_e_theta;   // Фазовий показник заломлення n_e(θ)
    double walkoff_deg; // Кут зносу Пойнтінга η (°)
    double shift_um;    // Просторовий зсув променя (мкм)
    double ret_rad;     // Фазове запізнення (рад)
    double ret_deg;     // Фазове запізнення у градусах (модуль 360°)
};

class BirefringenceRaytracer {
public:
    // Обчислення оптичних параметрів для заданого кута падіння
    [[nodiscard]] static BirefringenceResult trace_ray(const UniaxialCrystal& crystal,
                                                       double theta_deg,
                                                       double thickness_mm,
                                                       double wavelength_nm) noexcept {
        constexpr double deg2rad = std::numbers::pi / 180.0;
        const double theta = theta_deg * deg2rad;
        const double cos_t = std::cos(theta);
        const double sin_t = std::sin(theta);
        const double tan_t = std::tan(theta);

        // 1. Ефективний показник заломлення n_e(θ)
        const double no2 = crystal.n_o * crystal.n_o;
        const double ne2 = crystal.n_e * crystal.n_e;
        const double denom = std::sqrt(ne2 * cos_t * cos_t + no2 * sin_t * sin_t);
        const double n_e_th = (crystal.n_o * crystal.n_e) / denom;

        // 2. Кут зносу η
        double eta = 0.0;
        if (std::abs(cos_t) > 1e-12 && std::abs(sin_t) > 1e-12) {
            eta = std::atan(((no2 - ne2) * tan_t) / (no2 + ne2 * tan_t * tan_t));
        }

        // 3. Зсув Δ (мкм)
        const double shift = (thickness_mm * 1000.0) * std::tan(std::abs(eta));

        // 4. Різниця фаз Δφ
        const double delta_n = std::abs(n_e_th - crystal.n_o);
        const double phase_ret = (2.0 * std::numbers::pi / (wavelength_nm * 1e-6)) *
                                 (thickness_mm * 1e-3) * delta_n;

        return BirefringenceResult{
            .theta_deg = theta_deg,
            .n_e_theta = n_e_th,
            .walkoff_deg = eta / deg2rad,
            .shift_um = shift,
            .ret_rad = phase_ret,
            .ret_deg = std::fmod(phase_ret / deg2rad, 360.0)
        };
    }

    // Звітність за діапазоном кутів
    static void print_report(const UniaxialCrystal& crystal,
                             double thickness_mm,
                             double wavelength_nm) {
        std::cout << "=========================================================================\n";
        std::cout << " МАТЕРІАЛ: " << crystal.name << "\n";
        std::cout << " Оптичний тип: " << (crystal.max_birefringence() > 0 ? "Позитивний (+)" : "Негативний (-)") << "\n";
        std::cout << " n_o = " << crystal.n_o << ", n_e = " << crystal.n_e
                  << ", Δn = " << crystal.max_birefringence() << "\n";
        std::cout << " Товщина = " << thickness_mm << " мм, Довжина хвилі = " << wavelength_nm << " нм\n";
        std::cout << "=========================================================================\n";
        std::cout << " Кут θ (°) |  n_e(θ)   | Знос η (°) | Зсув Δ (мкм) | Фаза (рад) | Фаза (°) \n";
        std::cout << "-----------+-----------+------------+--------------+------------+----------\n";

        std::cout << std::fixed << std::setprecision(4);
        for (int deg = 0; deg <= 90; deg += 10) {
            const auto res = trace_ray(crystal, static_cast<double>(deg), thickness_mm, wavelength_nm);
            std::cout << "    " << std::setw(2) << deg << "     |  "
                      << res.n_e_theta << " |   "
                      << std::setw(6) << res.walkoff_deg << "   |   "
                      << std::setw(8) << res.shift_um << "   | "
                      << std::setw(10) << res.ret_rad << " |  "
                      << std::setw(6) << std::setprecision(1) << res.ret_deg << "\n"
                      << std::setprecision(4);
        }
        std::cout << "-------------------------------------------------------------------------\n\n";
    }
};

int main() {
    constexpr UniaxialCrystal calcite{
        .n_o = 1.6580,
        .n_e = 1.4864,
        .name = "Кальцит (Iceland Spar)"
    };

    constexpr UniaxialCrystal quartz{
        .n_o = 1.5426,
        .n_e = 1.5517,
        .name = "Кварц (Crystalline Quartz)"
    };

    constexpr double thickness_mm = 10.0;
    constexpr double wavelength_nm = 632.8;

    BirefringenceRaytracer::print_report(calcite, thickness_mm, wavelength_nm);
    BirefringenceRaytracer::print_report(quartz, thickness_mm, wavelength_nm);

    return 0;
}
```

## 5. Фізичний аналіз обчислювальних результатів

Аналіз проведених чисельних експериментів виявляє фундаментальні відмінності між негативними та позитивними одновісними кристалами:

1. **Кальцит (`CaCO₃`, негативний кристал, `n_e < n_o`):**
   - Максимальний кут зносу `η ≈ -6.24°` досягається при куті `θ ≈ 48°`.
   - Знак кута зносу від'ємний, що означає відхилення вектора Пойнтінга `S` від оптичної осі `z` у бік еліпсоїдальної хвильової поверхні.
   - На товщині `10 мм` просторовий зсув `Δ` перевищує `1.09 мм` (`1093.5 мкм`), що робить кальцит ідеальним матеріалом для поляризаційних призм розщеплення променя (Wollaston, Rochon, Glan-Thompson).

2. **Кварц (`SiO₂`, позитивний кристал, `n_e > n_o`):**
   - Анізотропія кварцю на порядок менша (`Δn = +0.0091` проти `Δn = -0.1716` у кальциту).
   - Максимальний кут зносу становить лише `η ≈ +0.17°`, а просторовий зсув променя на товщині `10 мм` не перевищує `29.4 мкм`.
   - Невелике значення двозаломлення робить кварц ідеальним матеріалом для прецизійних фазових платівок (`λ/4` та `λ/2`), оскільки контрольовану товщину пластини набагато легше виготовити технологічно з високою точністю.

## 6. Інженерні особливості обчислень у промислових пакетах

При інтеграції цих обчислювальних моделей у комерційні САПР (Zemax OpticStudio, Code V):
- Використовують матриці перетворення 3x3 для зв'язку між системою координат поверхні та головними осями кристала.
- Обчислюють амплітуди Френеля на межі анізотропного середовища шляхом розв'язання граничної системи рівнянь 4x4 для векторів `E` та `H`.
- Враховують термооптичні коефіцієнти `dn_o / dT` та `dn_e / dT` для моделювання лазерних систем високої потужності.
