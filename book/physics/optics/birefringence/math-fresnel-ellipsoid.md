# 🧮 Математичний апарат оптичної анізотропії: тензор діелектричної проникності, еліпсоїд оптичної індикатриси та рівняння хвильових нормалей Френеля

Ця вставка містить строгий математичний вивід хвильових поверхонь та фазових швидкостей світла в кристалічних середовищах на основі систем рівнянь Максвелла. Вона пояснює, як з тензорного характеру діелектричної проникності речовини виникає еліпсоїд оптичної індикатриси, виводиться рівняння Френеля для хвильових нормалей та розраховуються фазові швидкості й кути зносу променів.

## 1. Матеріальні співвідношення та тензор діелектричної проникності

У макроскопічній електродинаміці суцільних середовищ відгук діелектрика на зовнішнє електромагнітне поле описується матеріальним співвідношенням між вектором електричного зміщення (індукції) `D` та вектором напруженості електричного поля `E`. В анізотропній кристалічній ґратці зміщення електронних хвиль під дією електричного поля залежить від напрямку прикладеного поля, тому коефіцієнт пропорційності між `D` та `E` має тензорний характер:

```
D_i = ε_0 · ∑_j (ε_ij · E_j)
```

де `ε_0 ≈ 8.854 · 10⁻¹² Ф/м` — електрична стала, а `ε_ij` — тензор відносної діелектричної проникності середовища (симетричний тензор другого рангу, у якому `ε_ij = ε_ji` на основі мікроскопічної оборотності та законів термодинаміки).

Оскільки тензор `ε_ij` є дійсним та симетричним, його завжди можна звести до діагонального вигляду шляхом переходу до спеціальної ортогональної системи координат `(x, y, z)`, яка називається **головними оптичними осями кристала**. У цій декартовій системі координат зв'язок між векторами індукції та напруженості розпадається на три незалежні скалярні рівняння:

```
D_x = ε_0 · ε_x · E_x
D_y = ε_0 · ε_y · E_y
D_z = ε_0 · ε_z · E_z
```

або у зручній матричній формі:

```
[ D_x ]             [ ε_x   0    0  ]   [ E_x ]
[ D_y ] =  ε_0  ·   [  0   ε_y   0  ] · [ E_y ]
[ D_z ]             [  0    0   ε_z ]   [ E_z ]
```

Величина `ε_x`, `ε_y`, `ε_z` називаються головними діелектричними проникностями кристала. Відповідні їм **головні показники заломлення** визначаються як квадратні корені з головних діелектричних проникностей:

```
n_x = √ε_x,   n_y = √ε_y,   n_z = √ε_z
```

Залежно від кількості різних значення серед трійки `(n_x, n_y, n_z)` кристалографічні середовища класифікують на три класи:
1. **Оптично ізотропні кристали:** `ε_x = ε_y = ε_z = ε` (`n_x = n_y = n_z = n`). Усі напрямки оптично еквівалентні (кристали кубічної симетрії).
2. **Одновісні кристали:** `ε_x = ε_y = ε_o ≠ ε_z = ε_e` (`n_x = n_y = n_o`, `n_z = n_e`). Кристали тригональної, тетрагональної та гексагональної симетрій. Вісь `z` називається оптичною віссю кристала.
3. **Двовісні кристали:** `ε_x ≠ ε_y ≠ ε_z` (`n_x ≠ n_y ≠ n_z`). Кристали ромбічної, моноклінної та триклінної симетрій.

## 2. Густина електричної енергії та еліпсоїд оптичної індикатриси

Об'ємна густина електричної енергії `w_e` в анізотропному діелектрику виражається через скалярний добуток векторів напруженості `E` та індукції `D`:

```
w_e = (1 / 2) · (E · D)
= (1 / 2) · (E_x · D_x + E_y · D_y + E_z · D_z)
```

Виразивши компоненти напруженості електричного поля через компоненти індукції `E_i = D_i / (ε_0 · ε_i) = D_i / (ε_0 · n_i²)`, отримуємо вираз для густини енергії тільки через компоненти вектора індукції `D`:

```
w_e = (1 / (2 · ε_0)) · (D_x² / n_x² + D_y² / n_y² + D_z² / n_z²)
```

Ввівши нормовані просторові координати `x = D_x / √(2 · ε_0 · w_e)`, `y = D_y / √(2 · ε_0 · w_e)`, `z = D_z / √(2 · ε_0 · w_e)`, рівняння поверхні постійної густини енергії зводиться до канонічного рівняння тривісного еліпсоїда:

```
x² / n_x² + y² / n_y² + z² / n_z² = 1
```

Цей геометричний об'єкт називається **оптичною індикатрисою** або **еліпсоїдом показників заломлення** (еліпсоїд Френеля).

### Алгоритм геометричного побудови показників заломлення
Оптична індикатриса дозволяє наочно знаходити дозволені напрямки коливань та фазові показники заломлення для будь-якої плоскій електромагнітної хвилі, що поширюється у довільному напрямку, заданому одиничним вектором хвильової нормалі `s = (s_x, s_y, s_z)`:

1. Через центр еліпсоїда індикатриси проводить площину, строго перпендикулярну до напрямку хвильової нормалі `s`: `s_x · x + s_y · y + s_z · z = 0`.
2. Перетин цієї площини з еліпсоїдом утворює плоский **еліпс перерізу**.
3. Довжини двох піввісей цього еліпса дорівнюють фазовим показникам заломлення `n₁` та `n₂` двох монохроматичних хвиль, які можуть поширюватися у даному напрямку без зміни своєї поляризації.
4. Напрямки великої та малої піввісей цього еліпса вказують строго дозволені напрямки коливань вектора електричного зміщення `D₁` та `D₂`.

Для одновісного кристала (`n_x = n_y = n_o`, `n_z = n_e`) рівняння індикатриси спрощується до еліпсоїда обертання навколо оптичної осі `z`:

```
x² / n_o² + y² / n_o² + z² / n_e² = 1
```

Будь-який перетин цього еліпсоїда площиною, перпендикулярною до осі `z`, дає коло радіуса `n_o`. Це означає, що для хвилі, яка поширюється вздовж оптичної осі `z`, показник заломлення залишається однаковим для будь-якого напрямку поляризації.

## 3. Суворий вивід рівняння хвильових нормалей Френеля з рівнянь Максвелла

Розглянемо плоску плоскому монохроматичну електромагнітну хвилю, яка поширюється в діелектрику без вільних зарядів та струмів. Часова залежність векторів поля задається гармонічним чинником `exp(-i · ω · t)`, а просторова — чинником `exp(i · k · r)`, де `k = (ω / v) · s` — хвильовий вектор, `v` — фазова швидкість хвилі, `s` — одиничний вектор хвильової нормалі (`|s| = 1`).

У цьому випадку оператор дифференціювання `∇` замінюється на домноження на `i · k`, і система рівнянь Максвелла набуває алгебраїчної форми:

```
k × E = ω · B = ω · μ_0 · H       [закон електромагнітної індукції Фарадея]
k × H = -ω · D                   [закон Ампера — Максвелла]
```

Виразивши вектор магнітної напруженості `H` з першого рівняння `H = (1 / (ω · μ_0)) · (k × E)` і підставивши його у друге рівняння, маємо:

```
D = - (1 / (ω² · μ_0)) · k × (k × E)
```

Застосовуючи векторну тотожність для подвійного векторного добутку `a × (b × c) = b · (a · c) - c · (a · b)`:

```
k × (k × E) = k · (k · E) - E · (k²) = k² · [ s · (s · E) - E ]
```

Враховуючи, що фазова швидкість хвилі дорівнює `v = ω / |k|`, а швидкість світла у вакуумі `c = 1 / √(ε_0 · μ_0)`, отримуємо векторне співвідношення між індукцією `D` та напруженістю `E`:

```
D = (k² / (ω² · μ_0)) · [ E - s · (s · E) ]
  = ε_0 · (c² / v²) · [ E - s · (s · E) ]
```

Розглянемо проекції цього векторного рівняння на головні оптичні осі `(x, y, z)`. З одного боку, матеріальне співвідношення дає `D_i = ε_0 · n_i² · E_i = ε_0 · (c² / v_i²) · E_i`, де `v_i = c / n_i` — головні фазові швидкості. Підставляючи це значення у компоненти індукції:

```
ε_0 · (c² / v_x²) · E_x = ε_0 · (c² / v²) · [ E_x - s_x · (s · E) ]
```

Скорочуючи на `ε_0 · c²` та переносячи доданки з `E_x` в один бік:

```
E_x · (1 / v_x² - 1 / v²) = - (1 / v²) · s_x · (s · E)
```

Звівши до спільного знаменника та виразивши компоненту `E_x`:

```
E_x · ((v² - v_x²) / (v² · v_x²)) = - (1 / v²) · s_x · (s · E)

E_x = (s · E) · (v_x² · s_x) / (v² - v_x²)
```

Аналогічно отримуємо компоненти `E_y` та `E_z`:

```
E_y = (s · E) · (v_y² · s_y) / (v² - v_y²)
E_z = (s · E) · (v_z² · s_z) / (v² - v_z²)
```

Тепер обчислимо скалярний добуток `(s · E) = s_x · E_x + s_y · E_y + s_z · E_z`, підставивши знайдені вирази для компонент:

```
(s · E) = (s · E) · [ (v_x² · s_x²) / (v² - v_x²) + (v_y² · s_y²) / (v² - v_y²) + (v_z² · s_z²) / (v² - v_z²) ]
```

Припустивши, що `(s · E) ≠ 0` (що справджується для будь-якого напрямку, який не збігається з точним напрямком зсуву), скорочуємо ліву і праву частини на `(s · E)`:

```
(v_x² · s_x²) / (v² - v_x²) + (v_y² · s_y²) / (v² - v_y²) + (v_z² · s_z²) / (v² - v_z²) = 1
```

Щоб звести це рівняння до класичного симетричного вигляду Френеля, скористаємося геометричною тотожністю `s_x² + s_y² + s_z² = 1`. Перенесемо одиницю у ліву частину та перегрупуємо кожен доданок:

```
[ (v_x² · s_x²) / (v² - v_x²) - s_x² ] + [ (v_y² · s_y²) / (v² - v_y²) - s_y² ] + [ (v_z² · s_z²) / (v² - v_z²) - s_z² ] = 0
```

Спрощуючи кожен дужковий доданок `(v_i² · s_i²) / (v² - v_i²) - s_i² = s_i² · (v_i² - (v² - v_i²)) / (v² - v_i²) = - (v² - v_i² + v_i² ...)`:

```
s_i² · [ (v_i² - v² + v_i²) / (v² - v_i²) ] = (s_i² · v² / (v² - v_i²))
```

Зміна знака дає остаточне **рівняння хвильових нормалей Френеля**:

```
s_x² / (v² - v_x²) + s_y² / (v² - v_y²) + s_z² / (v² - v_z²) = 0
```

Або у еквівалентній формі через показники заломлення (`n = c / v` та `n_i = c / v_i`):

```
s_x² / (n⁻² - n_x⁻²) + s_y² / (n⁻² - n_y⁻²) + s_z² / (n⁻² - n_z⁻²) = 0
```

Це рівняння є квадратним відносно квадрата фазової швидкості `v²` (або `n²`). Для будь-якого заданого напрямку хвильової нормалі `s = (s_x, s_y, s_z)` воно має рівно два дійсні додатні корені `v₁²` та `v₂²`, які визначають фазові швидкості двох дозволених оптичних хвиль.

## 4. Точний розв'язок для одновісних кристалів

В одновісному кристалі оптичні властивості симетричні відносно осі `z`. Приймемо `n_x = n_y = n_o` (`v_x = v_y = v_o = c / n_o`), а `n_z = n_e` (`v_z = v_e = c / n_e`).

Позначимо кут між хвильовим вектором `s` та оптичною віссю `z` через `θ`. У цьому випадку `s_z = cos(θ)`, а `s_x² + s_y² = sin²(θ)`.

Підставивши ці значення у рівняння Френеля:

```
(s_x² + s_y²) / (v² - v_o²) + s_z² / (v² - v_e²) = 0

sin²(θ) / (v² - v_o²) + cos²(θ) / (v² - v_e²) = 0
```

Звівши дроби до спільного знаменника:

```
sin²(θ) · (v² - v_e²) + cos²(θ) · (v² - v_o²) = 0
```

Розкриваючи дужки та групуючи відносно `v²`:

```
v² · (sin²(θ) + cos²(θ)) = v_e² · sin²(θ) + v_o² · cos²(θ)

v² = v_o² · cos²(θ) + v_e² · sin²(θ)
```

Таким чином, квадратне рівняння розпадається на два рішення:

### Перший корінь: звичайна хвиля (o-wave)
```
v_1² = v_o²  ⇒  v_1 = v_o = c / n_o
```
Фазова швидкість звичайної хвилі взагалі не залежить від кута `θ`. Хвильова поверхня фазових швидкостей являє собою **сферу** радіуса `v_o`.

### Другий корінь: незвичайна хвиля (e-wave)
```
v_2²(θ) = v_o² · cos²(θ) + v_e² · sin²(θ)
```
Виразивши фазову швидкість через показник заломлення `n_e(θ) = c / v_2(θ)`:

```
1 / n_e²(θ) = cos²(θ) / n_o² + sin²(θ) / n_e²
```

Звівши до спільного знаменника та добувши квадратний корінь, отримуємо точну залежність показника заломлення незвичайного променя від кута `θ` до оптичної осі:

```
n_e(θ) = (n_o · n_e) / √(n_e² · cos²(θ) + n_o² · sin²(θ))
```

Хвильова поверхня фазових швидкостей незвичайного променя являє собою **еліпсоїд обертання**.

## 5. Кут зносу (Walk-off angle) між вектором Пойнтінга S та хвильовим вектором k

В анізотропному середовищі вектор електричного поля `E` у незвичайній хвилі відхиляється від вектора індукції `D` на кут `η`. Оскільки вектор Пойнтінга `S = E × H` визначає напрямок переносу енергії (променя), а хвильовий вектор `k` перпендикулярний до `D`, промінь відхиляється від хвильової нормалі на той самий кут `η`.

Тангенс кута зносу `η` між хвильовою нормаллю `k` та вектором Пойнтінга `S` обчислюється шляхом дифференціювання фазової швидкості за кутом `θ`:

```
tan(η) = - (1 / v) · (∂v / ∂θ)
```

Підставляючи вираз `v²(θ) = v_o² · cos²(θ) + v_e² · sin²(θ)` та переходячи до показників заломлення:

```
tan(η) = ((n_o² - n_e²) · tan(θ)) / (n_o² + n_e² · tan²(θ))
```

### Аналіз граничних випадків:
- При `θ = 0°` (поширення вздовж оптичної осі): `tan(η) = 0 ⇒ η = 0°`. Промінь і хвильовий вектор збігаються.
- При `θ = 90°` (поширення перпендикулярно оптичній осі): `tan(η) = 0 ⇒ η = 0°`. Промінь і хвильовий вектор збігаються, але різниця показників заломлення `|n_e - n_o|` максимальна.
- При `θ ≈ 45°`: кут зносу досягає свого екстремального значення. Для ісландського шпату (`n_o = 1.658`, `n_e = 1.486`) максимальний кут зносу становить `η_max ≈ 6.24°`.
