# 🧮 Математика планарних хвилеводів: дисперсійні рівняння TE та TM мод

Строгий аналіз поширення оптичного випромінювання у планарних (плоських) хвилеводах базується на аналітичному розв'язанні системи диференціальних рівнянь Максвелла для неоднорідного діелектричного середовища. У цій вставці наведено повний математичний вивід дисперсійних рівнянь для симетричних та асиметричних хвилеводів, розраховано просторові профілі полів, узагальнено умови відсічки мод, а також виведено коефіцієнт просторової локалізації потужності.

---

### 1. Виведення рівняння Гельмгольца з рівнянь Максвелла

Розглянемо тришарову діелектричну структуру, шари якої паралельні площині `yz` і нескінченні вздовж осі `y`. Напрямок поширення світлової хвилі збігається з віссю `z`, а поперечна координата `x` спрямована нормально до поверхонь розподілу шарів.

Профіль показника заломлення задається шматочково-сталою функцією `n(x)`:
* **Серцевина** (шар 1): `|x| ≤ d/2`, показник заломлення `n₁`.
* **Покриття** / Верхня оболонка (шар 2): `x > d/2`, показник заломлення `n₂`.
* **Підкладка** / Нижня оболонка (шар 3): `x < −d/2`, показник заломлення `n₃`.

Для існування утриманих (зв'язаних) хвильоводних мод вимагається виконання фундаментальної умови: `n₁ > n₂ ≥ n₃`. Якщо `n₂ = n₃`, хвилевід називається **симетричним**; якщо `n₂ ≠ n₃` — **асиметричним**.

Виходимо з рівнянь Максвелла для монохроматичного електромагнітного поля з часовою залежністю `exp(i · ω · t)` у немагнітному середовищі (`μ = μ₀`):

```
rot E = −i · ω · μ₀ · H
rot H = i · ω · ε₀ · n²(x) · E
```

Оскільки структура однорідна вздовж осі `y`, усі похідні `∂ / ∂y = 0`. Поширення хвилі вздовж осі `z` описується фазовим множником `exp(−i · β · z)`, де `β` — поздовжня стала поширення. Оператор просторового диференціювання за віссю `z` зводиться до множення на `−i · β`.

Розкриваючи ротори у декартових координатах, отримуємо систему з шести зв'язаних скалярних рівнянь:

```
i · β · E_y = −i · ω · μ₀ · H_x                     (1a)
∂E_y / ∂x = −i · ω · μ₀ · H_z                        (1b)
−i · β · E_x − ∂E_z / ∂x = −i · ω · μ₀ · H_y          (1c)

i · β · H_y = i · ω · ε₀ · n²(x) · E_x              (2a)
∂H_y / ∂x = i · ω · ε₀ · n²(x) · E_z                 (2b)
−i · β · H_x − ∂H_z / ∂x = i · ω · ε₀ · n²(x) · E_y   (2c)
```

Аналіз цієї системи показує, що вона розпадається на дві абсолютно незалежні групи векторних мод, які володіють різною поляризацією поля:

1. **TE-моди (Transverse Electric)**:
   Компоненти поля: `E_y ≠ 0`, `H_x ≠ 0`, `H_z ≠ 0`, причому `E_x = E_z = H_y = 0`. Електричний вектор орієнтований суворо поперечно до напрямку поширення.
   
   Підставляючи (1a) та (1b) у (2c), отримуємо скалярне **хвильове рівняння Гельмгольца** для `E_y(x)`:
   
   ```
   d²E_y(x) / dx² + (k₀² · n²(x) − β²) · E_y(x) = 0
   ```
   
   де `k₀ = ω / c = 2π / λ₀` — вакуумне хвильове число.

2. **TM-моди (Transverse Magnetic)**:
   Компоненти поля: `H_y ≠ 0`, `E_x ≠ 0`, `E_z ≠ 0`, причому `H_x = H_z = E_y = 0`. Магнітний вектор орієнтований суворо поперечно.
   
   Підставляючи (2a) та (2b) у (1c), отримуємо хвильове рівняння для `H_y(x)`:
   
   ```
   n²(x) · d/dx ( (1 / n²(x)) · dH_y(x) / dx ) + (k₀² · n²(x) − β²) · H_y(x) = 0
   ```

Для існування локалізованих мод, енергія яких не випромінюється в оболонку, поздовжня стала поширення `β` повинна перебувати у жорстко обмеженому діапазоні:

```
k₀ · n₂ ≤ β ≤ k₀ · n₁
```

Величина `n_eff = β / k₀` називається **ефективним показником заломлення** моди.

### 2. Загальні розв'язки у шарах хвилеводу

Розглянемо хвильове рівняння для TE-поля `E_y(x)` окремо у кожній із трьох областей планарної структури.

Введемо дійсні поперечні параметри поширення:
* У серцевині (`|x| ≤ d/2`): `h = √(k₀² · n₁² − β²)`
* У верхній оболонці (`x > d/2`): `q = √(β² − k₀² · n₂²)`
* У нижній підкладці (`x < −d/2`): `p = √(β² − k₀² · n₃²)`

Загальні розв'язки диференціальних рівнянь Гельмгольца виглядають так:

1. **Верхня оболонка (`x > d/2`)**:
   Поле має експоненційно згасати при `x → +∞`, щоб відсутнє було випромінювання енергії на нескінченність:
   ```
   E_y(x) = C_clad · exp(−q · (x − d/2))
   ```

2. **Серцевина (`−d/2 ≤ x ≤ d/2`)**:
   Поле володіє осцилюючим (хвильовим) характером:
   ```
   E_y(x) = A · cos(h · x) + B · sin(h · x)
   ```

3. **Нижня підкладка (`x < −d/2`)**:
   Поле має експоненційно згасати при `x → −∞`:
   ```
   E_y(x) = C_sub · exp(p · (x + d/2))
   ```

Для поздовжньої компоненти магнітного поля `H_z(x)` використовуємо співвідношення (1b): `H_z = (i / (ω · μ₀)) · (dE_y / dx)`. Отже, похідна `dE_y / dx` безпосередньо визначає тангенціальне магнітне поле.

Граничні умови електродинаміки вимагають суворої неперервності тангенціальних компонентів полів `E_y` та `H_z` (і відповідно похідної `dE_y / dx`) на обох межах розділу: `x = d/2` та `x = −d/2`.

### 3. Дисперсійні рівняння для симетричного хвилеводу

У симетричному хвилеводі (`n₂ = n₃`, звідси `p = q`) геометрична структура є парною відносно центральної осі `x = 0`. Усі розв'язки розділяються на дві незалежні сімейства мод: парні та непарні.

#### 1. Парні TE-моди (TE₀, TE₂, TE₄, ...)

Для парних мод `B = 0`, тому поле у серцевині описується косинусом: `E_y(x) = A · cos(h · x)`.

Застосовуємо граничні умови на верхній межі `x = d/2`:
* Неперервність `E_y`: `A · cos(h · d / 2) = C_clad`
* Неперервність `dE_y / dx`: `−A · h · sin(h · d / 2) = −C_clad · q`

Ділячи друге рівняння на перше, усуваємо невідомі амплітудні коефіцієнти `A` та `C_clad` і отримуємо **трансцендентне дисперсійне рівняння для парних TE-мод**:

```
tan(h · d / 2) = q / h
```

#### 2. Непарні TE-моди (TE₁, TE₃, TE₅, ...)

Для непарних мод `A = 0`, тому поле у серцевині описується синусом: `E_y(x) = B · sin(h · x)`.

Застосування аналогічних граничних умов на межі `x = d/2` дає:
* Неперервність `E_y`: `B · sin(h · d / 2) = C_clad`
* Неперервність `dE_y / dx`: `B · h · cos(h · d / 2) = −C_clad · q`

Ділення рівнянь дає **дисперсійне рівняння для непарних TE-мод**:

```
−cot(h · d / 2) = q / h
```

### 4. Нормовані параметри V, b та геометричний розв'язок

Для аналізу хвилеводів зручно перейти до безрозмірних універсальних змінних:

1. **Нормоване хвильове число у серцевині**: `u = h · d / 2`
2. **Нормоване хвильове число в оболонці**: `w = q · d / 2`
3. **Нормована частота хвилеводу (V-число)**:
   ```
   V = √(u² + w²) = k₀ · d · √(n₁² − n₂²) = (2π / λ₀) · d · NA
   ```
   де `NA = √(n₁² − n₂²)` — числова апертура хвилеводу.

Трансцендентні рівняння набувають компактної безрозмірної форми:
* Для парних мод: `u · tan(u) = w`
* Для непарних мод: `−u · cot(u) = w`

Геометрично розв'язки відповідають точкам перетину графіків функцій `u · tan(u)` або `−u · cot(u)` з колом радіуса `V / 2` на площині координат `(u, w)`. Оскільки коло має скінченний радіус `V / 2`, кількість точок перетину (а отже, і кількість дозволених хвильоводних мод) завжди обмежена й збільшується зі зростанням `V`.

#### Нормований показник заломлення (b)

Спеціальний параметр `b` визначає ступінь фазової локалізації хвилі у серцевині:

```
b = (n_eff² − n₂²) / (n₁² − n₂²) = w² / (V / 2)²
```

Зміна `b` лежить у межах `0 ≤ b ≤ 1`:
* `b = 0`: Мода перебуває на межі відсічки (`n_eff = n₂`), поле повністю витікає в оболонку.
* `b = 1`: Мода ідеально локалізована у серцевині (`n_eff → n₁`), зникаючі хвости в оболонці прямують до нуля.

### 5. Асиметричні хвилеводи та узагальнене дисперсійне рівняння

У реальних інтегральних фотонних схемах підкладка (`n₃`) та верхній покривний шар (`n₂`) зазвичай виготовлені з різних матеріалів (наприклад, кремнієва серцевина $n_1 = 3.45$ на оксидній підкладці $n_3 = 1.45$ з повітряним покриттям $n_2 = 1.0$).

Введемо **параметр асиметрії структури** `a`:
* Для TE-мод: `a_TE = (n₃² − n₂²) / (n₁² − n₃²)`
* Для TM-мод: `a_TM = (n₁ / n₂)⁴ · a_TE`

Узагальнене дисперсійне рівняння для асиметричного планарного хвилеводу описується єдиним співвідношенням для мод порядку `m = 0, 1, 2, ...`:

```
V · √(1 − b) = m · π + arctan( √(b / (1 − b)) ) + arctan( √((b + a) / (1 − b)) )
```

#### Межа відсічки в асиметричному хвилеводі

На відміну від симетричного хвилеводу, де фундаментальна мода `TE₀` не має відсічки (`V_cutoff = 0`), в асиметричному хвилеводі навіть фундаментальна мода вимагає мінімальної товщини серцевини для утримання світла.

Покладаючи `b = 0`, отримуємо **критичне V-число відсічки** для фундаментальної моди:

```
V_cutoff(TE₀) = arctan(√a_TE)
```

Якщо `V < V_cutoff`, світло не може поширюватися у планарному хвилеводі взагалі й повністю випромінюється у підкладку.

### 6. Частка оптичної потужності у серцевині (Коефіцієнт локалізації)

Важливим практичним параметром є **коефіцієнт локалізації потужності** `Γ` (*Confinement Factor*), який визначається як відношення оптичної потужності, що протікає всередині серцевини, до повної потужності хвилі по всьому перетину:

```
Γ = ( ∫[від −d/2 до +d/2] |E_y(x)|² dx ) / ( ∫[від −∞ до +∞] |E_y(x)|² dx )
```

Для парної TE-моди симетричного хвилеводу аналітичне інтегрування дає виражену залежність через нормовані параметри:

```
Γ = (1 + (sin(2u) / (2u))) / (1 + (sin(2u) / (2u)) + (2 / w) · cos²(u))
```

В наближенні сильної локалізації (`V ≫ 1`) коефіцієнт локалізації можна оцінити за спрощеною формулою:

```
Γ ≈ b ≈ 1 − (2 / V)
```

Для одномодового кремнієвого хвилеводу SOI (перетин `450 × 220 нм`) коефіцієнт локалізації фундаментальної моди `TE₀` становить `Γ ≈ 0.82–0.88`, що означає, що понад `80%` оптичної енергії рухається всередині кремнію, а близько `15%` поширюється у вигляді зникаючої хвилі в оксидній підкладці та верхньому покритті.
