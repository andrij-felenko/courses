# 🧮 Виведення розподілу Ейрі та аналіз багатопроменевої інтерференції

Цей математичний додаток містить строге електродинамічне виведення функції Ейрі для інтенсивності пропущеного та відбитого світла в ресонаторі Фабрі — Перо. Викладений матеріал розгортає алгебру сум нескінченної геометричної прогресії комплексних амплітуд, враховує граничні умови Френеля, фазові стрибки при відбитті, поглинання в дзеркалах, матричний метод передачі (TMM), а також аналітичну апроксимацію профілю інтерференційних піків лоренцівською кривою.

---

### 1. Електродинамічні граничні умови та фазові зсуви при відбитті

Розглянемо плоску електромагнітну хвилю з комплексною амплітудою електричного поля `E₀`, яка поширюється у середовищі з показником заломлення `n₀` та падає під кутом `θ` на плоскопаралельний шар товщиною `d` із показником заломлення `n`. Поверхні шару обмежені напівпрозорими дзеркальними покриттями.

Згідно з рівняннями Максвелла, на границі розподілу двох оптичних середовищ дотичні компоненти векторів напруженості електричного `E` та магнітного `H` полів повинні залишатися неперервними. При падінні хвилі з середовища з меншим показником заломлення `n₀` на середовище з більшим показником заломлення `n` (абсолютно оптично густішим), амплітудний коефіцієнт відбития `r` є від'ємним числом. Це означає виникнення додаткового фазового стрибка на `π` радіан (втрата півхвилі `λ / 2`). Якщо ж відбиття відбувається від межі з оптично менш густим середовищем, фазовий стрибок дорівнює нулю.

Для диелектричних дзеркал амплітудні коефіцієнти відбиття `r₁, r₂` та пропускання `t₁, t₂` для падаючої та зворотної хвиль пов'язані співвідношеннями Стокса, які випливають із принципу оборотності світлових променів та закону збереження енергії:

```
r' = -r
t · t' = 1 - r² = 1 - R
```

де `r`, `t` — коефіцієнти при переході світла зовні всередину порожнини, а `r'`, `t'` — при переході зсередини назовні.

При кожному подвійному проходженні світла туди й назад між дзеркалами ресонатора хвиля долає геометричний шлях `2 · d / cos θ'` всередині середовища (де `θ'` — кут заломлення, що визначається законом Снелла `n₀ · sin θ = n · sin θ'`).

Оптична різниця ходу `Δs` між двома послідовними пропущеними променями обчислюється з урахуванням зсуву хвильового фронту на поверхні:

```
Δs = 2 · n · d · cos θ'
```

Відповідно, оптичний фазовий набіг `δ` дорівнює:

```
δ = (2 · π / λ) · Δs + φ_r1 + φ_r2 = (4 · π · n · d · cos θ') / λ + φ_r1 + φ_r2
```

де `φ_r1` та `φ_r2` — додаткові фазові зсуви, що виникають безпосередньо у внутрішніх структурованих відбивальних шарах дзеркал (для простих диелектриків `φ_r1 = φ_r2 = 0` або `π`).

### 2. Сумування комплексних амплітуд світлових хвиль

Повна комплексна амплітуда пропущеного електричного поля `E_T` утворюється когерентним суперпозиційним додаванням нескінченної серії парціальних хвиль, які зазнали `0, 1, 2, 3...` подвійних відбитків усередині ресонатора перш ніж вийти крізь друге дзеркало:

```
E_T = E₀ · t₁ · t₂ · e^(i · α) · [ 1 + (r₁ · r₂) · e^(i · δ) + (r₁ · r₂)² · e^(i · 2δ) + (r₁ · r₂)^3 · e^(i · 3δ) + ... ]
```

де `α` — базовий фазовий набіг першого проходу.

Вираз у квадратних дужках являє собою нескінченну спадну геометричну прогресію з першим членом `a = 1` та знаменником `q = r₁ · r₂ · e^(i · δ)`. Оскільки для будь-яких реальних напівпрозорих дзеркал модуль амплітудного відбиття `|r₁ · r₂| < 1`, ряд є строго збіжним, а його сума обчислюється за формулою:

```
S = 1 / (1 - q) = 1 / (1 - r₁ · r₂ · e^(i · δ))
```

Отже, комплексна амплітуда пропущеного поля виражається компактною функцією:

```
E_T = (E₀ · t₁ · t₂ · e^(i · α)) / (1 - r₁ · r₂ · e^(i · δ))
```

### 3. Алгебраїчне виведення функції Ейрі для інтенсивності

Інтенсивність оптичного випромінювання `I` обчислюється як квадрат модуля комплексної амплітуди: `I_T = |E_T|² = E_T · E_T*`, де `E_T*` — комплексно-спряжена величина.

Позначимо добуток амплітудних коефіцієнтів відбиття через `r_eff = r₁ · r₂`. Знайдемо квадрат модуля знаменника виразу для `E_T`:

```
|1 - r_eff · e^(i · δ)|²
= (1 - r_eff · cos δ - i · r_eff · sin δ) · (1 - r_eff · cos δ + i · r_eff · sin δ)   [формула Ейлера: e^(i·δ) = cos δ + i·sin δ]
= (1 - r_eff · cos δ)² + (r_eff · sin δ)²                                             [модуль комплексного числа: (a - i·b)(a + i·b) = a² + b²]
= 1 - 2 · r_eff · cos δ + r_eff² · cos² δ + r_eff² · sin² δ                            [піднесення до квадрата: (1 - x)² = 1 - 2x + x²]
= 1 - 2 · r_eff · cos δ + r_eff²                                                       [основна тригонометрична тотожність: cos² δ + sin² δ = 1]
```

Застосуємо тригонометричну тотожність пониження степеня для косинуса `cos δ = 1 - 2 · sin²(δ / 2)`:

```
1 - 2 · r_eff · cos δ + r_eff²
= 1 - 2 · r_eff · (1 - 2 · sin²(δ / 2)) + r_eff²        [формула подвійного кута: cos δ = 1 - 2·sin²(δ / 2)]
= 1 - 2 · r_eff + 4 · r_eff · sin²(δ / 2) + r_eff²       [розкриття дужок: -2·r_eff · (-2·sin²(δ / 2)) = 4·r_eff·sin²(δ / 2)]
= (1 - r_eff)² + 4 · r_eff · sin²(δ / 2)                [згруповано повний квадрат: 1 - 2·r_eff + r_eff² = (1 - r_eff)²]
```

Винесемо множник `(1 - r_eff)²` за дужки:

```
|1 - r_eff · e^(i · δ)|² = (1 - r_eff)² · [ 1 + (4 · r_eff / (1 - r_eff)²) · sin²(δ / 2) ]
```

Підставляючи цей вираз у формулу інтенсивності `I_T = |E_T|²`, маємо:

```
I_T = I₀ · (t₁ · t₂)² / [ (1 - r_eff)² · (1 + F_coeff · sin²(δ / 2)) ]
```

де введено **коефіцієнт різкості Ейрі** `F_coeff`:

```
F_coeff = (4 · r_eff) / (1 - r_eff)²
```

Для асиметричного ресонатора з різними дзеркалами (`R₁ = r₁²`, `R₂ = r₂²`, `T₁ = t₁²`, `T₂ = t₂²`) відносне пропускання дорівнює:

```
I_T / I₀ = (T₁ · T₂) / [ (1 - √(R₁ · R₂))² · (1 + F_coeff · sin²(δ / 2)) ]
```

Якщо дзеркала є ідентичними (`R₁ = R₂ = R`, `T₁ = T₂ = T`), вираз спрощується до:

```
I_T / I₀ = (T / (1 - R))² · [ 1 / (1 + F_coeff · sin²(δ / 2)) ]
```

#### Вплив внутрішнього поглинання у дзеркалах

Якщо напівпрозорі покриття мають внутрішній коефіцієнт поглинання та розсіювання `A`, то згідно з законом збереження енергії `T + R + A = 1`.

Тоді множник максимального пропускання у піку `I_max` стає меншим за одиницю:

```
I_max / I₀ = (T / (1 - R))² = ((1 - R - A) / (1 - R))² = (1 - A / (1 - R))²
```

Ця формула показує катастрофічний вплив поглинання: якщо дзеркало має `R = 0.99`, а поглинання становить лише `A = 0.005` (`0.5%`), то максимальне пропускання у резонансі падає до `I_max / I₀ = (1 - 0.005 / 0.01)² = (0.5)² = 0.25` (`25%`). Це пояснює, чому для високодобротних еталонів використовують лише диелектричні багатошарові покриття з `A < 0.0001`.

За відсутності поглинання (`A = 0`, `T = 1 - R`) ми отримуємо класичну **функцію Ейрі**:

```
I_T(δ) = I₀ / [ 1 + F_coeff · sin²(δ / 2) ]
```

### 4. Аналіз відбитої інтенсивності та баланс енергії

Для прозорого ресонатора без поглинання енергія не зникає, тому в кожній точці сума пропущеного та відбитого світла дорівнює вхідній інтенсивності: `I_T(δ) + I_R(δ) = I₀`.

Звідси спектр відбитого світла `I_R(δ)` описується рівнянням:

```
I_R(δ) = I₀ - I_T(δ)
       = I₀ · [ 1 - 1 / (1 + F_coeff · sin²(δ / 2)) ]
       = I₀ · [ (F_coeff · sin²(δ / 2)) / (1 + F_coeff · sin²(δ / 2)) ]
```

Аналіз відбитого спектра показує:
- При резонансі (`δ = 2 · m · π`) `sin(δ / 2) = 0`, тому відбиття дорівнює нулю (`I_R = 0`). Ресонатор є повністю прозорим.
- При антирезонансі (`δ = (2m + 1) · π`) `sin(δ / 2) = 1`, тому відбита інтенсивність досягає максимуму `I_R_max = I₀ · F_coeff / (1 + F_coeff) = I₀ · 4R / (1 + R)²`. При `R = 0.95` відбиття становить `99.93%`.

### 5. Точний розрахунок спектральних параметрів: FWHM, Finesse та контраст

Знайдемо фазову ширину піку `δFWHM` на рівні половинної інтенсивності `I_T = I_max / 2`:

```
1 / (1 + F_coeff · sin²(δFWHM / 4)) = 1 / 2
⇒ F_coeff · sin²(δFWHM / 4) = 1
⇒ sin(δFWHM / 4) = 1 / √F_coeff
```

Для високодобротних ресонаторів з `R > 0.8` значення `F_coeff ≫ 1`, тому кут `δFWHM / 4` є дуже малим, що дозволяє використати наближення `sin(x) ≈ x`:

```
δFWHM / 4 ≈ 1 / √F_coeff
⇒ δFWHM ≈ 4 / √F_coeff = 4 · (1 - R) / (2 · √R) = 2 · (1 - R) / √R
```

Відношення фазової відстані між максимумами `Δδ_FSR = 2 · π` до напівширини `δFWHM` дає точний вираз для **різкості (Finesse) `F`**:

```
F = Δδ_FSR / δFWHM
  = (2 · π) / [ 2 · (1 - R) / √R ]
  = (π · √R) / (1 - R)
```

Таблиця співвідношень параметрів розрахунку Ейрі:

| Коефіцієнт відбиття `R` | Коефіцієнт різкості `F_coeff` | Ширина піку `δFWHM` (рад) | Різкість (Finesse) `F` | Контраст `I_max / I_min` |
| :--- | :--- | :--- | :--- | :--- |
| **0.50** | 16.0 | 1.000 | 6.28 | 17.0 |
| **0.80** | 80.0 | 0.447 | 14.05 | 81.0 |
| **0.90** | 360.0 | 0.211 | 29.80 | 361.0 |
| **0.95** | 1520.0 | 0.103 | 61.24 | 1521.0 |
| **0.99** | 39600.0 | 0.020 | 312.58 | 39601.0 |

#### Виведення контрасту (екстинції)

Контрастність картини `C` виражається відношенням максимальної інтенсивності до мінімальної:

```
C = I_max / I_min
  = 1 + F_coeff                              [визначення відношення піку до мінімуму]
  = 1 + (4 · R) / (1 - R)²                   [підстановка коефіцієнта Ейрі: F_coeff = 4·R / (1 - R)²]
  = ((1 - R)² + 4 · R) / (1 - R)²            [зведення до спільного знаменника]
  = (1 + R)² / (1 - R)²                      [спрощення чисельника: (1 - R)² + 4·R = (1 + R)²]
```

### 6. Лоренцівське наближення контуру піку поблизу резонансу

Поблизу резонансного максимуму, коли фазовий зсув `δ = 2 · m · π + Δδ` (де `Δδ ≪ 1`), виконаємо розклад функції `sin(δ / 2)` у ряд Тейлора:

```
sin(δ / 2) = sin(m · π + Δδ / 2) = ± sin(Δδ / 2) ≈ ± Δδ / 2
```

Підставляючи цей розклад у розподіл Ейрі, маємо:

```
I_T(Δδ) ≈ I₀ / [ 1 + F_coeff · (Δδ / 2)² ]
        = I₀ / [ 1 + (4 · R / (1 - R)²) · (Δδ² / 4) ]
        = I₀ / [ 1 + (R / (1 - R)²) · Δδ² ]
```

Враховуючи, що `δFWHM = 2 · (1 - R) / √R`, перепишемо знаменник:

```
I_T(Δδ) ≈ I₀ / [ 1 + (2 · Δδ / δFWHM)² ]
```

Це рівняння являє собою класичний **профіль Лоренца** (*Lorentzian profile*), який описує фізичні резонансні системи із затуханням (такі як гармонічний осцилятор або атомний перехід). Лоренцівська апроксимація є надзвичайно точною поблизу верхівки піку (`I_T > 0.5 · I_max`) і широко використовується при спектральному аналізі лазерних мод.

### 7. Врахування хроматичної дисперсії субстрату

Якщо внутрішній проміжок ресонатора заповнений оптичним середовищем з дисперсією `n(λ)` (залежністю показника заломлення від довжини хвилі), область вільної дисперсії за довжиною хвилі `FSR_λ` отримує дисперсійну поправку.

Диференціюючи умову резонансу `2 · n(λ) · d = m · λ` по довжині хвилі `λ`, отримуємо:

```
2 · d · [ (dn / dλ) · λ + n ] = m · dλ = (2 · n · d / λ) · dλ
```

Звідси модифікована область вільної дисперсії з урахуванням **групового показника заломлення** `n_g = n - λ · (dn / dλ)` становить:

```
FSR_λ = λ² / (2 · n_g · d)
```

Враховувати груповий показник заломлення `n_g` критично необхідно при проектуванні монолітних кварцевих та напівпровідникових еталонів у спектральних областях із високою дисперсією (наприклад, поблизу краю фундаментального поглинання).
