# 🧮 Математичний апарат хроматичності та розрахунок колірного охоплення

Математичний опис кольору спирається на лінійну алгебру тривимірних векторних просторів, теореми проективної геометрії та математичний аналіз опуклих многокутників на двовимірній площині хроматичностей. Нижче наведено послідовне виведення фундаментальних формул перетворення спектрального випромінювання у значення `XYZ`, нормування до координат `(x, y)`, барицентричного змішування джерел за законами Ґрассмана, переходу до рівноконтрастних просторів та розрахунку об'єму й площі колірного охоплення.

## 1. Інтегрування спектра у тристимульні значення CIE XYZ

Фізичною основою колориметричного розрахунку є спектральна густина потужності джерела світла `S(λ)` (вимірювана у Вт/(м²·нм)). Згідно зі стандартом CIE 1931, зорове відчуття людини описується трьома спектральними функціями додавання кольору `x̄(λ)`, `ȳ(λ)` та `z̄(λ)`, які репрезентують ефективну чутливість трьох типів колбочок сітківки через лінійний базис.

Тристимульні значення `X`, `Y` та `Z` обчислюються шляхом інтегрування добутку спектра `S(λ)` на відповідні функції чутливості по всьому видимому діапазону довжин хвиль від `λ[min] = 380 нм` до `λ[max] = 780 нм`:

```
X = k · ∫ S(λ) · x̄(λ) dλ    [380 нм .. 780 нм]
Y = k · ∫ S(λ) · ȳ(λ) dλ    [380 нм .. 780 нм]
Z = k · ∫ S(λ) · z̄(λ) dλ    [380 нм .. 780 нм]
```

Коефіцієнт `k` визначає системну норму:
- Для **випромінювальних джерел** (дисплеї, світлодіоди, світильники) `k` приймають рівним максимальній світловій віддачі монохроматичного випромінювання `K[m] = 683.002 лм/Вт`. У цьому випадку координата `Y` виражає абсолютну фотометричну яскравість у канделах на квадратний метр (кд/м²).
- Для **відбивальних поверхонь** із коефіцієнтом спектрального відбиття `R(λ) ∈ [0, 1]` під освітленням джерела `I(λ)`, коефіцієнт `k` нормують так, щоб ідеально біла поверхня (`R(λ) = 1`) давала значення `Y = 100`:

```
k = 100 / ( ∫ I(λ) · ȳ(λ) dλ )
```

У практичних цифровізованих обчисленнях безперервний інтеграл замінюють дискретною рімановою сумою з кроком `Δλ` (зазвичай 1 нм або 5 нм):

```
X = k · ∑ S[i] · x̄[i] · Δλ
Y = k · ∑ S[i] · ȳ[i] · Δλ
Z = k · ∑ S[i] · z̄[i] · Δλ
```

Механізм інтегрування демонструє, що безліч різних фізичних спектрів `S(λ)` можуть після множення на функції чутливості давати абсолютно однакові трійки чисел `(X, Y, Z)`. Це явище називається **метамеризмом**: оптично різні фізичні хвилі викликають ідентичне зорове відчуття в ока людини.

## 2. Нормування та проекція на хроматичну площину (x, y)

Тристимульні значення `(X, Y, Z)` утворюють тривимірний вектор у додатному октанті `ℝ³`. Щоб відокремити кольоровий тон і насиченість від інтенсивності випромінювання (яскравості), виконують центральне проектування вектора на площину `X + Y + Z = 1`.

Хроматичні координати `x`, `y` та `z` визначаються як відносні частки кожної з трьох складових у загальній сумі:

```
x = X / (X + Y + Z)
y = Y / (X + Y + Z)
z = Z / (X + Y + Z)
```

За визначенням сума трьох хроматичних координат зародиться до тотожної одиниці:

```
x + y + z = 1
```

Звідси випливає, що `z = 1 - x - y`. Третя координата `z` є лінійно залежною, тож для повного опису якісної складової кольору достатньо подати його точкою `(x, y)` на двовимірній площині хроматичностей CIE 1931.

Якщо відомі хроматичні координати `(x, y)` та фотометрична яскравість `Y`, вихідний 3D-вектор `(X, Y, Z)` відновлюється за точними формулами:

```
X = (x / y) · Y
Z = ((1 - x - y) / y) · Y
```

Ці рівності справедливі при `y > 0`. Випадок `y = 0` відповідає нульовій яскравості (абсолютна темрява), де поняття хроматичності втрачає фізичний зміст, оскільки вектор скорочується в нуль.

## 3. Математичний доказ законів аддитивного змішування Ґрассмана

Нехай маємо два незалежні джерела світла з тристимульними векторами `C₁ = (X₁, Y₁, Z₁)` та `C₂ = (X₂, Y₂, Z₂)`. Згідно з лінійністю сприйняття, сумарне відчуття виражається вектором:

```
C[sum] = C₁ + C₂ = (X₁ + X₂,  Y₁ + Y₂,  Z₁ + Z₂)
```

Визначимо полні модулі тристимулів для кожного джерела:
- `m₁ = X₁ + Y₁ + Z₁ = Y₁ / y₁`
- `m₂ = X₂ + Y₂ + Z₂ = Y₂ / y₂`

Хроматичні координати сумарного світлового потоку `(x[sum], y[sum])` обчислюються за правилом нормування:

```
x[sum] = (X₁ + X₂) / (m₁ + m₂)
       = (m₁·x₁ + m₂·x₂) / (m₁ + m₂)

y[sum] = (Y₁ + Y₂) / (m₁ + m₂)
       = (m₁·y₁ + m₂·y₂) / (m₁ + m₂)
```

З алгебраїчного погляду точка суміші `(x[sum], y[sum])` являє собою строго **барицентричну комбінацію** точок `(x₁, y₁)` та `(x₂, y₂)` із точковими масовими вагами `m₁` та `m₂`.

Звідси математично доводяться три фундаментальні наслідки:
1. **Геометрична прямолінійність**: Хроматичність суміші двох світлових джерел завжди лежить строго на відрізку, що з'єднує вихідні точки `P₁` та `P₂` на площині `(x, y)`.
2. **Правило важеля**: Точка суміші ділить відрізок `P₁P₂` у зворотному відношенні вагових мас `m₁` та `m₂`. Чим більша яскравість та модуль першого джерела, тим ближче підсумок до точки `P₁`.
3. **Опуклість колірного охоплення**: Будь-який набір із `N` первинних джерел формує колірне охоплення у вигляді опуклої оболонки (Convex Hull) своїх вершин на площині. Для трьох джерел `R`, `G`, `B` це трикутник, а точки всередині відповідають невід'ємним барицентричним ваговим коефіцієнтам.

## 4. Обчислення площі трикутника колірного охоплення

Колірне охоплення триколірної дисплейної системи визначається як площа трикутника `RGB` у координатах `(x, y)`.

Нехай опорні вершини первинних кольорів мають координати:
- Червоний: `R(x[R], y[R])`
- Зелений: `G(x[G], y[G])`
- Синій: `B(x[B], y[B])`

Площа трикутника `A[gamut]` обчислюється через псевдоскалярний добуток векторів ребер або визначник матриці 3×3:

```
               | x[R]  y[R]  1 |
A[gamut] = 0.5·| x[G]  y[G]  1 |
               | x[B]  y[B]  1 |

         = 0.5 · | x[R]·(y[G] - y[B]) + x[G]·(y[B] - y[R]) + x[B]·(y[R] - y[G]) |
```

Для прикладу розрахуємо площу охоплення стандарту **sRGB**:
- `R = (0.64, 0.33)`
- `G = (0.30, 0.60)`
- `B = (0.15, 0.06)`

Обчислення по кроках:

```
Term1 = 0.64 · (0.60 - 0.06) = 0.64 · 0.54 = 0.3456
Term2 = 0.30 · (0.06 - 0.33) = 0.30 · (-0.27) = -0.0810
Term3 = 0.15 · (0.33 - 0.60) = 0.15 · (-0.27) = -0.0405

Sum = 0.3456 - 0.0810 - 0.0405 = 0.2241
A[sRGB] = 0.5 · 0.2241 = 0.11205
```

Загальна площа всієї видимої хроматичної області всередині спектрального локусу CIE 1931 становить приблизно `A[CIE1931] ≈ 0.3352`.

Відносне колірне охоплення системи sRGB у відсотках від усього людського зору:

```
Coverage[sRGB] = (A[sRGB] / A[CIE1931]) · 100%
               = (0.11205 / 0.3352) · 100% ≈ 33.4%
```

## 5. Матричне перетворення між координатними системами RGB та XYZ

Щоб перетворити лінійні індикатори напруги чи цифрових рівнів `(R, G, B)` (від нормованого діапазону `[0, 1]`) у тристимульні значення `(X, Y, Z)`, застосовують матрицю зв'язку `M` розміром 3×3:

```
[ X ]   [ X[r]  X[g]  X[b] ]   [ R ]
[ Y ] = [ Y[r]  Y[g]  Y[b] ] · [ G ]
[ Z ]   [ Z[r]  Z[g]  Z[b] ]   [ B ]
```

Стовпчики матриці `M` є тристимулами первинних кольорів при їхній максимальній інтенсивності. Елементи матриці визначаються з координат вершин `(x[R], y[R])`, `(x[G], y[G])`, `(x[B], y[B])` та хроматичності опорного білого кольору `(x[W], y[W])` з яскравістю `Y[W] = 1`:

```
X[i] = (x[i] / y[i]) · C[i]
Y[i] = C[i]
Z[i] = ((1 - x[i] - y[i]) / y[i]) · C[i]    (де i ∈ {r, g, b})
```

Вектор коефіцієнтів масштабу `(C[r], C[g], C[b])ᵀ` знаходять із системи рівнянь для білого кольору:

```
[ X[W] ]   [ x[R]/y[R]  x[G]/y[G]  x[B]/y[B] ]   [ C[r] ]
[ Y[W] ] = [     1          1          1     ] · [ C[g] ]
[ Z[W] ]   [ z[R]/y[R]  z[G]/y[G]  z[B]/y[B] ]   [ C[b] ]
```

Для стандарту **sRGB** із опорним білим D65 `(x=0.3127, y=0.3290, Y=1.0)`ведена пряма матриця `M` дорівнює:

```
[ X ]   [ 0.412456  0.357576  0.180437 ]   [ R[linear] ]
[ Y ] = [ 0.212672  0.715152  0.072175 ] · [ G[linear] ]
[ Z ]   [ 0.019334  0.119192  0.950304 ]   [ B[linear] ]
```

Зворотом матриці `M⁻¹` обчислюють координати `(R, G, B)` з абсолютних тристимулів `(X, Y, Z)`:

```
[ R[linear] ]   [  3.240454 -1.537138 -0.498531 ]   [ X ]
[ G[linear] ] = [ -0.969266  1.876011  0.041556 ] · [ Y ]
[ B[linear] ]   [  0.055643 -0.204026  1.057225 ]   [ Z ]
```

Якщо для заданої точки `(X, Y, Z)` хоча б один із розрахованих компонентів `R[linear]`, `G[linear]` або `B[linear]` виявляється від'ємним або перевищує 1.0, це слугує математичним доказом того, що дана хроматичність лежить **поза колірним охопленням** цієї системи.

## 6. Перехід до рівноконтрастного простору CIE 1976 L*a*b* та розрахунок колірного об'єму

Для адекватної оцінки колірного охоплення з урахуванням динамічного діапазону яскравості (High Dynamic Range, HDR), площини 2D недостатньо. Використовують обчислення **колірного об'єму** (Color Volume) у тривимірному рівноконтрастному просторі CIE 1976 L*a*b*.

Формули перетворення з `(X, Y, Z)` у `(L*, a*, b*)` відносно білої точки `(X[n], Y[n], Z[n])`:

```
L* = 116 · f(Y / Y[n]) - 16
a* = 500 · ( f(X / X[n]) - f(Y / Y[n]) )
b* = 200 · ( f(Y / Y[n]) - f(Z / Z[n]) )
```

де нелінійна функція `f(t)` визначається як:

```
If t > (6/29)³ ≈ 0.008856:
    f(t) = t ^ (1/3)
Else:
    f(t) = (841 / 108) · t + (4 / 29)
```

Об'єм колірного охоплення `V[gamut]` обчислюється шляхом тривимірного інтегрування або тріангуляції (тетраедризації) 3D-поліедра в просторі `L*a*b*`:

```
V[gamut] = ∭ dL* da* db*    [одиниці L*a*b*³]
```

Обчислення колірного об'єму показує, що при максимальній і мінімальній яскравості (`L* → 100` та `L* → 0`) досяжна площа хроматичностей звужується до однієї точки (білої або чорної відповідно). Максимальне хроматичне охоплення досягається у середньому діапазоні яскравостей (`L* ≈ 40..60`).
