# ⚙️ Симуляція спектра відбиття та інтерференційного забарвлення тонкої плівки

Фізично точна симуляція кольору тонких плівок є важливою задачею для сучасного комп'ютерного рендерингу (PBR), оптичного проектування, біосенсорики, мікроелектроніки та розробки антивідбивальних покриттів. Для того щоб розрахувати реальний колір мильної плівки або просвітленого об'єктива під сонячним світлом, необхідно обчислити коефіцієнт відбиття `R(λ)` для кожної довжини хвилі у видимому спектрі (`380–780` нм), зінтегрувати результат із спектральною чутливістю людського ока (функціями відповідності кольору CIE 1931) та конвертувати результат у простір sRGB.

### 1. Фізична та колориметрична модель симулятора

Моделювання інтерференційного забарвлення тонкої плівки складається з кількох послідовних етапів: розрахунку спектрального відбиття, чисельного інтегрування у тристимульних координатах та нормалізації колірного гамуту.

#### Фізичний етап: розрахунок спектра R(λ)
Для кожного монохроматичного компонента з довжиною хвилі `λ₀` у вакуумі (із кроком `Δλ = 5` нм від `380` до `780` нм) обчислюються кути поширення хвилі в кожному середовищі за законом Снелла:

```
n₁ · sin θ₁ = n₂ · sin θ₂ = n₃ · sin θ₃
```

Далі обчислюються амплітудні коефіцієнти відбиття Френеля на двох межах розділу (для s-поляризації):

```
r₁₂ = (n₁ · cos θ₁ - n₂ · cos θ₂) / (n₁ · cos θ₁ + n₂ · cos θ₂)
r₂₃ = (n₂ · cos θ₂ - n₃ · cos θ₃) / (n₂ · cos θ₂ + n₃ · cos θ₃)
```

Набіг фази за один подвійний прохід усередині плівки товщиною `d`:

```
β(λ₀) = (4 · π · n₂ · d · cos θ₂) / λ₀
```

Енергетичний коефіцієнт відбиття від плівки розраховується за формулою Ері, яка враховує нескінченний ряд багатократних внутрішніх відбитків:

```
R(λ₀) = (r₁₂² + r₂₃² + 2 · r₁₂ · r₂₃ · cos β) / (1 + r₁₂² · r₂₃² + 2 · r₁₂ · r₂₃ · cos β)
```

#### Чисельне інтегрування та колориметричні криві CIE 1931
Людське око містить три типи колбочок, спектральна чутливість яких описується кривими чутливості стандартного спостерігача CIE 1931 `x̄(λ), ȳ(λ), z̄(λ)`. Для переведення розрахованого спектра відбиття `R(λ)` у сприйманий колір обчислюються тристимульні координати `X, Y, Z` шляхом чисельного інтегрування за методом трапецій з кроком `Δλ`:

```
X = ∑ R(λ) · S(λ) · x̄(λ) · Δλ
Y = ∑ R(λ) · S(λ) · ȳ(λ) · Δλ
Z = ∑ R(λ) · S(λ) · z̄(λ) · Δλ
```

де `S(λ)` — спектральний розподіл енергії джерела освітлення (наприклад, стандартного денного світла D65). Отримані значення `X, Y, Z` нормалізуються відносно абсолютно білого відбивача, для якого `Y = 1.0`.

#### Матрична конверсія XYZ у sRGB та обробка позагамутових кольорів
Перехід від координат `XYZ` до лінійних компонент кольору `r_lin, g_lin, b_lin` у колірному просторі sRGB здійснюється за допомогою стандартної матриці конверсії ITU-R BT.709:

```
| r_lin |   |  3.2406  -1.5372  -0.4986 |   | X |
| g_lin | = | -0.9689   1.8758   0.0415 | · | Y |
| b_lin |   |  0.0557  -0.2040   1.0570 |   | Z |
```

Оскільки інтерференційні спектри є високоселективними та вузькосмуговими, отримані значення `r_lin, g_lin, b_lin` можуть виходити за межі стандартного колірного охоплення sRGB (отримувати від'ємні значення). У професійних обчислювальних системах для таких кольорів застосовується тональне відображення (tone mapping) або стискання гамуту (gamut clamping), яке відсікає значення до відрізка `[0.0, 1.0]`.

Фінальним кроком є застосування нелінійної гамма-корекції sRGB (`γ = 2.2`):

```
Для кожної компоненти c ∈ {r, g, b}:
Якщо c_lin ≤ 0.0031308:
    c_sRGB = 12.92 · c_lin
Інакше:
    c_sRGB = 1.055 · (c_lin ^ (1 / 2.4)) - 0.055

Фінальне байтове значення: C_byte = round(255 · c_sRGB)
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>
#include <iomanip>
#include <string>
#include <array>

// Структура для зберігання спектральних кольорових координат
struct ColorRGB {
    uint8_t r;
    uint8_t g;
    uint8_t b;

    std::string to_hex() const {
        char buf[8];
        std::snprintf(buf, sizeof(buf), "#%02X%02X%02X", r, g, b);
        return std::string(buf);
    }
};

// Аналітична апроксимація кривих чутливості ока CIE 1931 (Гаусові апроксимації)
struct CIE1931 {
    static double x_bar(double lambda_nm) {
        double t1 = (lambda_nm - 442.0) / ((lambda_nm < 442.0) ? 16.0 : 22.0);
        double t2 = (lambda_nm - 599.0) / ((lambda_nm < 599.0) ? 38.0 : 32.0);
        double t3 = (lambda_nm - 501.0) / ((lambda_nm < 501.0) ? 24.0 : 22.0);
        return 0.362 * std::exp(-0.5 * t1 * t1) + 1.056 * std::exp(-0.5 * t2 * t2) - 0.065 * std::exp(-0.5 * t3 * t3);
    }

    static double y_bar(double lambda_nm) {
        double t1 = (lambda_nm - 568.8) / ((lambda_nm < 568.8) ? 46.9 : 44.5);
        double t2 = (lambda_nm - 530.9) / ((lambda_nm < 530.9) ? 16.3 : 37.1);
        return 0.821 * std::exp(-0.5 * t1 * t1) + 0.286 * std::exp(-0.5 * t2 * t2);
    }

    static double z_bar(double lambda_nm) {
        double t1 = (lambda_nm - 437.0) / ((lambda_nm < 437.0) ? 11.8 : 19.8);
        double t2 = (lambda_nm - 459.0) / ((lambda_nm < 459.0) ? 26.0 : 26.0);
        return 1.217 * std::exp(-0.5 * t1 * t1) + 0.681 * std::exp(-0.5 * t2 * t2);
    }
};

class ThinFilmSimulator {
private:
    double n1; // середовище над плівкою (наприклад, повітря 1.00)
    double n2; // плівка (наприклад, мильний розчин 1.33)
    double n3; // середовище під плівкою (наприклад, скло 1.52 або повітря 1.00)

public:
    ThinFilmSimulator(double n1_val, double n2_val, double n3_val)
        : n1(n1_val), n2(n2_val), n3(n3_val) {}

    // Обчислення коефіцієнта відбиття R(lambda) за формулою Ері
    double calculate_reflectance(double lambda_nm, double d_nm, double theta1_rad = 0.0) const {
        double sin_theta2 = (n1 / n2) * std::sin(theta1_rad);
        if (std::abs(sin_theta2) > 1.0) return 1.0; // Повне внутрішнє відбиття
        double theta2_rad = std::asin(sin_theta2);

        double sin_theta3 = (n2 / n3) * std::sin(theta2_rad);
        double theta3_rad = (std::abs(sin_theta3) <= 1.0) ? std::asin(sin_theta3) : 0.0;

        // Амплітудні коефіцієнти відбиття Френеля для s-поляризації
        double r12 = (n1 * std::cos(theta1_rad) - n2 * std::cos(theta2_rad)) /
                     (n1 * std::cos(theta1_rad) + n2 * std::cos(theta2_rad));
        double r23 = (n2 * std::cos(theta2_rad) - n3 * std::cos(theta3_rad)) /
                     (n2 * std::cos(theta2_rad) + n3 * std::cos(theta3_rad));

        // Набіг фази за один подвійний прохід плівки
        constexpr double PI = 3.14159265358979323846;
        double beta = (4.0 * PI * n2 * d_nm * std::cos(theta2_rad)) / lambda_nm;

        // Формула Ері для коефіцієнта відбиття R
        double num = r12 * r12 + r23 * r23 + 2.0 * r12 * r23 * std::cos(beta);
        double den = 1.0 + r12 * r12 * r23 * r23 + 2.0 * r12 * r23 * std::cos(beta);

        return std::clamp(num / den, 0.0, 1.0);
    }

    // Симуляція інтерференційного кольору плівки товщиною d_nm у sRGB
    ColorRGB simulate_color(double d_nm, double theta1_rad = 0.0) const {
        double X = 0.0, Y = 0.0, Z = 0.0;
        double norm_y = 0.0;

        constexpr double LAMBDA_START = 380.0;
        constexpr double LAMBDA_END = 780.0;
        constexpr double STEP = 5.0;

        for (double lambda = LAMBDA_START; lambda <= LAMBDA_END; lambda += STEP) {
            double R_val = calculate_reflectance(lambda, d_nm, theta1_rad);
            double x_b = CIE1931::x_bar(lambda);
            double y_b = CIE1931::y_bar(lambda);
            double z_b = CIE1931::z_bar(lambda);

            X += R_val * x_b * STEP;
            Y += R_val * y_b * STEP;
            Z += R_val * z_b * STEP;
            norm_y += y_b * STEP;
        }

        // Нормалізація
        if (norm_y > 0.0) {
            X /= norm_y;
            Y /= norm_y;
            Z /= norm_y;
        }

        // Конверсія CIE XYZ у лінійне RGB (матриця D65 / sRGB)
        double r_lin =  3.2406 * X - 1.5372 * Y - 0.4986 * Z;
        double g_lin = -0.9689 * X + 1.8758 * Y + 0.0415 * Z;
        double b_lin =  0.0557 * X - 0.2040 * Y + 1.0570 * Z;

        // Гамма-корекція sRGB (γ = 2.2)
        auto gamma_correct = [](double val) -> uint8_t {
            val = std::clamp(val, 0.0, 1.0);
            double corrected = (val <= 0.0031308) ? (12.92 * val) : (1.055 * std::pow(val, 1.0 / 2.4) - 0.055);
            return static_cast<uint8_t>(std::round(corrected * 255.0));
        };

        return ColorRGB{gamma_correct(r_lin), gamma_correct(g_lin), gamma_correct(b_lin)};
    }
};

int main() {
    // Симуляція мильної бульбашки у повітрі (n1=1.0, n2=1.33, n3=1.0)
    ThinFilmSimulator soap_bubble(1.00, 1.33, 1.00);

    std::cout << "--- Симуляція кольору мильної плівки у повітрі ---\n";
    std::cout << std::left << std::setw(15) << "Товщина d (нм)" << std::setw(15) << "HEX Колір" << "Коментар\n";
    std::cout << "---------------------------------------------------------\n";

    std::vector<double> thicknesses = {10.0, 100.0, 250.0, 380.0, 500.0, 650.0, 1000.0};
    for (double d : thicknesses) {
        ColorRGB col = soap_bubble.simulate_color(d);
        std::string desc = (d < 30.0) ? "Надватонка плівка (чорна)" :
                           (d < 150.0) ? "Світло-жовта / білувата" :
                           (d < 300.0) ? "Яскраво-пурпурова / фіолетова" : "Зелена / переливчаста";
        std::cout << std::left << std::setw(15) << d << std::setw(15) << col.to_hex() << desc << "\n";
    }

    return 0;
}
```

```py
import math

class ThinFilmSimulator:
    def __init__(self, n1=1.00, n2=1.33, n3=1.00):
        self.n1 = n1
        self.n2 = n2
        self.n3 = n3

    @staticmethod
    def _cie_x_bar(l):
        t1 = (l - 442.0) / (16.0 if l < 442.0 else 22.0)
        t2 = (l - 599.0) / (38.0 if l < 599.0 else 32.0)
        t3 = (l - 501.0) / (24.0 if l < 501.0 else 22.0)
        return 0.362 * math.exp(-0.5 * t1**2) + 1.056 * math.exp(-0.5 * t2**2) - 0.065 * math.exp(-0.5 * t3**2)

    @staticmethod
    def _cie_y_bar(l):
        t1 = (l - 568.8) / (46.9 if l < 568.8 else 44.5)
        t2 = (l - 530.9) / (16.3 if l < 530.9 else 37.1)
        return 0.821 * math.exp(-0.5 * t1**2) + 0.286 * math.exp(-0.5 * t2**2)

    @staticmethod
    def _cie_z_bar(l):
        t1 = (l - 437.0) / (11.8 if l < 437.0 else 19.8)
        t2 = (l - 459.0) / (26.0 if l < 459.0 else 26.0)
        return 1.217 * math.exp(-0.5 * t1**2) + 0.681 * math.exp(-0.5 * t2**2)

    def calculate_reflectance(self, lambda_nm, d_nm, theta1_rad=0.0):
        sin_t2 = (self.n1 / self.n2) * math.sin(theta1_rad)
        if abs(sin_t2) > 1.0:
            return 1.0
        theta2_rad = math.asin(sin_t2)

        sin_t3 = (self.n2 / self.n3) * math.sin(theta2_rad)
        theta3_rad = math.asin(sin_t3) if abs(sin_t3) <= 1.0 else 0.0

        r12 = (self.n1 * math.cos(theta1_rad) - self.n2 * math.cos(theta2_rad)) / \
              (self.n1 * math.cos(theta1_rad) + self.n2 * math.cos(theta2_rad))
        r23 = (self.n2 * math.cos(theta2_rad) - self.n3 * math.cos(theta3_rad)) / \
              (self.n2 * math.cos(theta2_rad) + self.n3 * math.cos(theta3_rad))

        beta = (4.0 * math.pi * self.n2 * d_nm * math.cos(theta2_rad)) / lambda_nm

        num = r12**2 + r23**2 + 2.0 * r12 * r23 * math.cos(beta)
        den = 1.0 + r12**2 * r23**2 + 2.0 * r12 * r23 * math.cos(beta)
        return max(0.0, min(1.0, num / den))

    def simulate_hex_color(self, d_nm, theta1_rad=0.0):
        X, Y, Z, norm_y = 0.0, 0.0, 0.0, 0.0
        step = 5.0
        for l in [380.0 + i * step for i in range(int((780.0 - 380.0) / step) + 1)]:
            r_val = self.calculate_reflectance(l, d_nm, theta1_rad)
            xb, yb, zb = self._cie_x_bar(l), self._cie_y_bar(l), self._cie_z_bar(l)
            X += r_val * xb * step
            Y += r_val * yb * step
            Z += r_val * zb * step
            norm_y += yb * step

        if norm_y > 0.0:
            X, Y, Z = X / norm_y, Y / norm_y, Z / norm_y

        r_lin =  3.2406 * X - 1.5372 * Y - 0.4986 * Z
        g_lin = -0.9689 * X + 1.8758 * Y + 0.0415 * Z
        b_lin =  0.0557 * X - 0.2040 * Y + 1.0570 * Z

        def gamma(val):
            val = max(0.0, min(1.0, val))
            c = 12.92 * val if val <= 0.0031308 else (1.055 * (val ** (1.0 / 2.4)) - 0.055)
            return int(round(c * 255.0))

        return f"#{gamma(r_lin):02X}{gamma(g_lin):02X}{gamma(b_lin):02X}"

if __name__ == "__main__":
    sim = ThinFilmSimulator(1.00, 1.33, 1.00)
    for d in [10.0, 100.0, 250.0, 380.0, 500.0, 650.0, 1000.0]:
        print(f"Товщина {d:6.1f} нм -> {sim.simulate_hex_color(d)}")
```

### 3. Структура алгоритму та складові оптимізації

Програмна симуляція тонкоплівкового забарвлення розбита на три ключові алгоритмічні модулі:

#### Модуль 1: Обчислення оптичного коефіцієнта Ері
Для кожного кроку за довжиною хвилі `λ` обчислюються хвильовий вектор `k₀ = 2π / λ` та комплексна амплітуда відбиття. При використанні недиспесійного матеріалу (постійні значення `n₁, n₂, n₃`) коефіцієнти `r₁₂` та `r₂₃` обчислюються лише один раз перед початком циклу, що значно прискорює симуляцію у графічних рушіях реального часу (PBR shaders).

#### Модуль 2: Спектральний інтегратор CIE 1931
Використання аналітичних Гаусових апроксимацій для кривих чутливості `x̄(λ), ȳ(λ), z̄(λ)` дозволяє обходитися без завантаження зовнішніх колориметричних таблиць даних. Для досягнення високої точності колориметричного інтегрування достатньо обрати крок `Δλ = 5` нм, що дає всього `81` ітерацію на кожне обчислення кольору.

#### Модуль 3: Гамма-коректований колірний перетворювач
Перетворення `XYZ → sRGB` з урахуванням гамма-функції гарантує точне відображення симульованого кольору на цифрових дисплеях. Для від'ємних лінійних RGB-значень (які виникають через надзвичайно високу насиченість інтерференційного спектра) застосовується процедура `std::clamp`, яка м'яко зрізає позагамутові кольори до найближчої границі колірного куба sRGB.

### 4. Аналіз фізичних результатів та крайові випадки

Аналіз результатів обчислювального експерименту підтверджує ключові фізичні закони тонкоплівкової оптики:

1. **Гранична зона надватонких плівок (`d < 30` нм)**: Колір відбиття прямує до чисто чорного (`#000000` або темно-сірого), оскільки амплітуди двох відбитих хвиль майже однакові за модулем, але протилежні за фазою через фазовий стрибок `π` на першій межі. Вся світлова енергія без перешкод проходить крізь плівку.
2. **Перший порядок інтерференційного забарвлення (`d = 100–350` нм)**: Завдяки вибірковому деструктивному гасінню вузького спектрального діапазону (наприклад, зеленій складовій `λ ≈ 530` нм при `d ≈ 250` нм), відбите світло набуває надзвичайно насичених та чистих пурпурово-фіолетових та золотисто-жовтих відтінків.
3. **Високі порядки інтерференції (`d > 2500` нм)**: Зі збільшенням товщини плівки кількість інтерференційних максимумів у видимому діапазоні `380–780` нм стає надзвичайно великою (понад 10–15 максимумів). Густо розташовані спектральні піки згладжуються під час інтегрування функціями чутливості ока, і підсумковий колір знову прямує до ахроматичного білого або світло-сірого.
4. **Залежність від кута спостереження `θ₁`**: При збільшенні кута падіння `θ₁` значення `cos θ₂` у формулі фази зменшується. Математично це еквівалентно ефективному зменшенню товщини плівки `d_eff = d · cos θ₂`. Саме тому при нахилі мильної бульбашки або олійної плями їхнє забарвлення плавно зсувається в бік коротших довжин хвиль (фіолетово-синя частина спектра).
