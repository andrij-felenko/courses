# 🧮 Виведення згасаючої хвилі та фазового зсуву при повному внутрішньому відбитті

Хвильова теорія світла показує, що при повному внутрішньому відбитті електромагнітне поле не зупиняється на геометричній межі середовищ, а проникає в оптично менш щільне середовище у вигляді згасаючої (еванесцентної) хвилі. Цей розрахунок надає вичерпне математичне виведення комплексної форми хвильового вектора, формули глибини проникнення `d[p]`, доказ відсутності нормального потоку енергії в середньому за часом, розрахунок комплексних фазових зсувів Френеля для обох поляризацій, геометрію ромба Френеля та просторовий зсув Гуса-Хенхен.

---

### 1. Комплексний хвильовий вектор та експоненційне загасання

Нехай плоска монохроматична електромагнітна хвиля падає з першого прозорого середовища з показником заломлення `n₁` на плоску межу розділу `z = 0` з другим середовищем, що має менший показник заломлення `n₂ < n₁`. Площина падіння збігається з площиною `xz`, а поверхня розділу належить площині `xy`.

Граничні умови для електромагнітного поля вимагають безперервності тангенціальних компонент векторів напруженості електричного `E[x], E[y]` та магнітного `H[x], H[y]` полів у кожній точці межі `z = 0` в будь-який момент часу `t`. Це можливе лише за умови, що фазові чинники падаючої, відбитої та заломленої хвиль збігаються уздовж всієї поверхні розділу:

```
k[1x] = k[2x] = k[rx]
```

Позначимо кут падіння через `θ₁`. Вектор хвильового числа падаючої хвилі у першому середовищі має компоненти:

```
k[1x] = k₁ · sin θ₁ = k₀ · n₁ · sin θ₁
k[1z] = k₁ · cos θ₁ = k₀ · n₁ · cos θ₁
```

Тут `k₀ = ω / c = 2π / λ₀` — хвильове число у вакуумі, `λ₀` — довжина хвилі у порожнечі, `ω` — кругова частота світла.

У другому середовищі повний модуль хвильового вектора визначається оптичною щільністю другого середовища: `k₂ = k₀ · n₂`. Дисперсійне співвідношення для плоскої хвилі у другому середовищі зв'язує тангенціальну та нормальну компоненти хвильового вектора:

```
k[2x]² + k[2z]² = k₂² = (k₀ · n₂)²
```

Враховуючи рівність тангенціальних компонент `k[2x] = k[1x] = k₀ · n₁ · sin θ₁`, виразимо квадрат нормальної компоненти `k[2z]²`:

```
k[2z]² = k₂² - k[2x]²
k[2z]² = (k₀ · n₂)² - (k₀ · n₁ · sin θ₁)²
k[2z]² = k₀² · (n₂² - n₁² · sin² θ₁)
```

Розглянемо випадок, коли кут падіння перевищує критичний поріг `θ₁ > θc = arcsin(n₂ / n₁)`. Оскільки `sin θ₁ > n₂ / n₁`, вираз у дужках стає строго від'ємним: `n₂² - n₁² · sin² θ₁ < 0`.

Отже, нормальна компонента хвильового вектора `k[2z]` не має дійсного значення й стає чисто уявною величиною:

```
k[2z] = ± i · α
α = k₀ · √(n₁² · sin² θ₁ - n₂²) = (2π / λ₀) · √(n₁² · sin² θ₁ - n₂²)
```

Підставимо отриманий комплексний хвильовий вектор `k₂ = (k₀ · n₁ · sin θ₁, 0, i · α)` у загальний вираз для комплексної напруженості електричного поля заломленої хвилі у другому середовищі `E₂(x, z, t) = E₀ · exp(i(k[2x] · x + k[2z] · z - ωt))`:

```
E₂(x, z, t) = E₀ · exp(i(k₀ · n₁ · sin θ₁ · x + (i · α) · z - ωt))
E₂(x, z, t) = E₀ · exp(i² · α · z) · exp(i(k₀ · n₁ · sin θ₁ · x - ωt))
E₂(x, z, t) = E₀ · exp(-α · z) · exp(i(k₀ · n₁ · sin θ₁ · x - ωt))
```

При виборі знака для `k[2z]` знак плюс перед `i · α` відкидається з фізичних міркувань: вираз `exp(+α · z)` означав би необмежене зростання амплітуди поля при віддаленні від межі `z → +∞`, що суперечить закону збереження енергії.

Отримане рішення описує **еванесцентну (згасаючу) хвилю**:
1. Уздовж поверхні розділу (вісь `x`) хвиля поширюється як звичайна біжуча хвиля з гармонічним фазовим чинником та фазовою швидкістю `v[ph] = ω / k[2x] = c / (n₁ · sin θ₁)`. Оскільки `sin θ₁ < 1`, фазова швидкість огинаючої вздовж поверхні є меншою за швидкість світла у першому середовищі.
2. Перпендикулярно до поверхні розділу (вісь `z`) амплітуда хвилі згасає за суто експоненційним законом `exp(-α · z)` без фазового зміщення вздовж осі `z`.

### 2. Глибина проникнення еванесцентного поля

Глибиною проникнення `d[p]` називають відстань вздовж осі `z`, на якій амплітуда електричного поля зменшується в `e` разів (приблизно в 2.71828 разів) порівняно зі значенням безпосередньо на межі `z = 0`.

За означенням, `α · d[p] = 1`, звідки маємо:

```
d[p] = 1 / α
d[p] = λ₀ / (2π · √(n₁² · sin² θ₁ - n₂²))
```

Проаналізуємо граничні випадки цієї формули:

1. **Наближення до критичного кута (`θ₁ → θc + 0°`):**
   Вираз під коренем прямує до нуля: `n₁² · sin² θc - n₂² = 0`. Отже, `α → 0`, а глибина проникнення прямує до нескінченності `d[p] → ∞`. На порозі критичного кута згасаюча хвиля трансформується у звичайну плоску хвилю, що ковзає вздовж межі `z = 0` у другому середовищі й займає весь півпростір.

2. **Границя ковзного падіння (`θ₁ → 90°`):**
   Синус кута падіння прямує до одиниці `sin θ₁ → 1`. Знаменник досягає свого фізичного максимуму, а глибина проникнення знижується до мінімального значення:
   ```
   d[p,min] = λ₀ / (2π · √(n₁² - n₂²))
   ```

3. **Числовий розрахунок для межі скло–повітря:**
   Для оптичного крон-скла (`n₁ = 1.50`) та повітря (`n₂ = 1.00`) на довжині хвилі червоного лазера `λ₀ = 632.8 нм` при куті падіння `θ₁ = 45°` (`sin 45° = 1 / √2 ≈ 0.7071`):

```
n₁² · sin² θ₁ = 1.50² · (0.7071)² = 2.25 · 0.5 = 1.125
√(n₁² · sin² θ₁ - n₂²) = √(1.125 - 1.000) = √0.125 ≈ 0.35355

d[p] = 632.8 нм / (2π · 0.35355)
d[p] = 632.8 нм / (6.28318 · 0.35355)
d[p] = 632.8 нм / 2.22144 ≈ 284.8 нм
```

Отже, глибина проникнення світлового поля у повітря становить близько 285 нанометрів — менше половини довжини світлової хвилі.

### 3. Доказ відсутності нормального потоку енергії

Потік електромагнітної енергії визначається вектором Пойнтінга `S = E × H`. Для з'ясування того, чи витікає енергія у друге середовище, обчислимо перпендикулярну компоненту вектора Пойнтінга `S[z] = E[x] · H[y] - E[y] · H[x]`, усереднену за часом протягом періоду коливань:

```
⟨S[z]⟩ = (1/2) · Re(E₂ × H₂*)_z
```

Розглянемо випадок s-поляризації (перпендикулярної, TE-хвилі), де вектор електричного поля напрямлений строго вздовж осі `y`: `E₂ = (0, E[2y], 0)`.

Вираз для електричного поля у другому середовищі:

```
E[2y](x, z, t) = E₀ · exp(-α · z) · exp(i(k[2x] · x - ωt))
```

З першого диференціального рівняння Максвелла `rot E = - μ₀ · (∂H / ∂t)` виразимо тангенціальну компоненту магнітного поля `H[2x]`:

```
(rot E)_x = ∂E[2z]/∂y - ∂E[2y]/∂z = - ∂E[2y]/∂z
- ∂E[2y]/∂z = - μ₀ · (∂H[2x] / ∂t) = i · ω · μ₀ · H[2x]
```

Обчислимо похідну `∂E[2y] / ∂z`:

```
∂E[2y] / ∂z = - α · E₀ · exp(-α · z) · exp(i(k[2x] · x - ωt)) = - α · E[2y]
```

Підставимо похідну у рівняння для `H[2x]`:

```
H[2x] = (1 / (i · ω · μ₀)) · (α · E[2y]) = - i · (α / (ω · μ₀)) · E[2y]
```

Отриманий вираз показує, що тангенціальна компонента магнітного поля `H[2x]` має фазове зміщення на `90°` (чинник `-i`) відносно електричного поля `E[2y]`.

Обчислимо нормальний потік енергії `⟨S[z]⟩`:

```
⟨S[z]⟩ = (1/2) · Re(E[2y] · (-H[2x]*))
⟨S[z]⟩ = (1/2) · Re(E[2y] · (i · (α / (ω · μ₀)) · E[2y]*))
⟨S[z]⟩ = (1/2) · (α / (ω · μ₀)) · |E₂|² · Re(i)
```

Оскільки дійсна частина чисто уявної одиниці `Re(i) = 0`, отримуємо строго:

```
⟨S[z]⟩ = 0
```

Усереднений за часом потік енергії крізь межу `z = 0` дорівнює **точно нулю**. Світлова хвиля не переносить енергію углиб другого середовища. 

Проте поздовжня компонента вектора Пойнтінга `⟨S[x]⟩` є відмінною від нуля:

```
⟨S[x]⟩ = (1/2) · Re(-E[2y] · H[2z]*) = (1/2) · (k[2x] / (ω · μ₀)) · E₀² · exp(-2α · z) > 0
```

Це означає, що енергія електромагнітного поля переношується строго вздовж межі розділу усередині приповерхневого шару товщиною `d[p]`, здійснюючи локальну циркуляцію без безповоротного витікання.

### 4. Фазові зсуви Френеля та ромб Френеля

При `θ₁ > θc` коефіцієнти відбиття Френеля для s-поляризації `r[s]` та p-поляризацій `r[p]` визначаються через комплексний кут заломлення `n₂ · cos θ₂ = i · √(n₁² · sin² θ₁ - n₂²)`:

```
r[s] = (n₁ · cos θ₁ - i · √(n₁² · sin² θ₁ - n₂²)) / (n₁ · cos θ₁ + i · √(n₁² · sin² θ₁ - n₂²))
r[p] = (n₂² · cos θ₁ - i · n₁ · √(n₁² · sin² θ₁ - n₂²)) / (n₂² · cos θ₁ + i · n₁ · √(n₁² · sin² θ₁ - n₂²))
```

Обидва вирази мають структуру комплексного числа `(u - i·v) / (u + i·v)`. Модуль такого числа дорівнює одиниці:

```
|r[s]|² = (u² + v²) / (u² + v²) = 1
|r[p]|² = (u'² + v'²) / (u'² + v'²) = 1
```

Енергетичний коефіцієнт відбиття `R = |r|² = 1.0000` (точно 100%). Тим не менш, чисельник і знаменник надають коефіцієнтам відбиття комплексні фазові кути `r[s] = exp(i · δ[s])` та `r[p] = exp(i · δ[p])`:

```
tg(δ[s] / 2) = - √(n₁² · sin² θ₁ - n₂²) / (n₁ · cos θ₁)
tg(δ[p] / 2) = - n₁ · √(n₁² · sin² θ₁ - n₂²) / (n₂² · cos θ₁)
```

Зсув фаз між p- та s-поляризованими компонентами `Δδ = δ[p] - δ[s]` описується формулою:

```
tg(Δδ / 2) = (cos θ₁ · √(n₁² · sin² θ₁ - n₂²)) / (n₁ · sin² θ₁)
```

У **ромбі Френеля** світло зазнає двох послідовних повних внутрішніх відбиттів під таким кутом `θ₁`, щоб при кожному відбитті різниця фаз становила `Δδ = 45°` (`π/4`). Після двох відбиттів сумарний фазовий зсув досягає `90°` (`π/2`), що перетворює лінійно поляризоване світло з кутом поляризації `45°` на циркулярно поляризоване світло без використання хроматичних хвильових пластин.

### 5. Просторовий зсув Гуса-Хенхен

Оскільки фазовий зсув `δ` залежить від кута падіння `θ₁`, падаючий світловий пучок обмеженої ширини (який є суперпозицією плоских хвиль з різними хвильовими векторами `k[x]`) зазнає просторового зсуву при відбитті.

Згідно з теорією стаціонарної фази Артманна, центр відбитого пучка зміщується вздовж межі розділу на макроскопічну відстань `Δx`:

```
Δx = - dδ / d(k[x])
```

Для s-поляризації формула Артманна дає:

```
Δx[s] = (λ₀ / π) · (sin θ₁ / √(n₁² · sin² θ₁ - n₂²)) · (1 / √(n₁² - 1))
```

Фізично зсув Гуса-Хенхен означає, що падаючий промінь не відбивається дзеркально з точки падіння на межі, а входить у друге середовище, пробігає відстань `Δx` вздовж поверхні усередині еванесцентного шару й лише потім вертається назад у перше середовище.
