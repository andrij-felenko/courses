# ⚙️ Векторний алгоритм 3D-заломлення променя для трасування променів (Ray Tracing)

Ця прикладна вставка містить алгоритм, математичний розбір та високопродуктивну реалізацію векторного закону Снелла у тривимірному просторі для оптичних симуляторів та рушіїв комп'ютерної графіки.

## Математичний механізм 3D-векторного розкладання

У комп'ютерній графіці, системи оптичного проектування (CAD) та фізично коректному рендерингу (Path Tracing) оперування кутами `θ₁` та `θ₂` через тригонометричні функції `asin` або `acos` є обчислювально повільним та неефективним. Алгоритми трасування променів (Ray Tracing) обчислюють напрямок заломленого променя `T` безпосередньо через нормований вектор падіння `I` та вектор нормалі до поверхні `N`.

Нехай:
- `I` — нормований вектор напрямку падаючого променя (`|I| = 1`), спрямований від джерела у точку падіння на поверхні.
- `N` — нормований вектор нормалі до поверхні (`|N| = 1`), спрямований зовні об'єкта.
- `η = n₁ / n₂` — відношення показників заломлення середовища, з якого світло виходить (`n₁`), до середовища, у яке світло входить (`n₂`).

Заломлений вектор `T` виражається сумою двох ортогональних складових — тангенціальної `T_parallel` (паралельної до площини межі) та нормальної `T_perpendicular`:

```
T = T_parallel + T_perpendicular

T_parallel = η · (I + cos(θ₁) · N)
T_perpendicular = -√(1 - η² · (1 - cos²(θ₁))) · N
```

Ввівши косинус кута падіння `cos(θ₁) = -(I · N)` та проміжну дискримінантну величину `k = 1 - η² · (1 - (I · N)²)`, яка математично відповідає `cos²(θ₂)` заломленого кута, отримуємо підсумкову векторну формулу закону Снелла:

```
якщо k < 0:
    подія = Повне Внутрішнє Відбиття (заломлений промінь відсутній)
інакше:
    T = η · I + (η · (-(I · N)) - √k) · N
```

## Алгоритм двостороннього заломлення на межі об'єкта

При трасуванні променів крізь замкнені прозорі об'єкти (наприклад, скляну кулю, лінзу або краплю води) промінь світла послідовно перетинає дві поверхні:
1. **Первинний вхід (повітря → скло):** Промінь входить із середовища з меншим показником `n₁ = 1.0` у середовище з більшим `n₂ = 1.5`. Вектор падіння `I` та нормаль `N` спрямовані назустріч один одному (`I · N < 0`), а відношення показників дорівнює `η = n₁ / n₂ = 1.0 / 1.5 = 0.6667`.
2. **Вторинний вихід (скло → повітря):** Промінь виходить ізсередини об'єкта у повітря. У цьому випадку промінь рушить у напрямку нормалі `N` (`I · N > 0`). Щоб алгоритм правильно порахував заломлення, орієнтацію нормалі слід інвертувати `N_oriented = -N`, кут падіння брати як `cos(θ₁) = I · N`, а відношення показників змінити на обернене `η = n₂ / n₁ = 1.5 / 1.0 = 1.5`.

Саме на другому кроці (при виході зі щільного середовища) виникає можливість Повного Внутрішнього Відбиття, коли підкореневий вираз `k` стає від'ємним. У такому разі промінь не залишає об'єкт, а відбивається від внутрішньої стінки.

## Реалізація векторного заломлення мовами C та C++

Нижче наведено ідіоматичні реалізації алгоритму векторного заломлення для пар середовищ. Мова C застосовує явну передачу вказівників та код повернення прапорця, тоді як C++ використовує семантику `std::optional` та метод обробки відсутності значення без створення зайвих об'єктів у пам'яті.

```c
#include <math.h>
#include <stdbool.h>

typedef struct {
    double x;
    double y;
    double z;
} Vector3;

static inline double vec3_dot(Vector3 a, Vector3 b) {
    return a.x * b.x + a.y * b.y + a.z * b.z;
}

static inline Vector3 vec3_add(Vector3 a, Vector3 b) {
    return (Vector3){a.x + b.x, a.y + b.y, a.z + b.z};
}

static inline Vector3 vec3_scale(Vector3 v, double s) {
    return (Vector3){v.x * s, v.y * s, v.z * s};
}

/*
 * Обчислює напрямок заломленого променя за законом Снелла у 3D.
 * I — нормований вектор падаючого променя (спрямований в точку падіння).
 * N — нормований вектор нормалі поверхні.
 * eta — відношення n1 / n2.
 * out_refracted — вказівник на вектор заломлення T (якщо є).
 * Повертає true якщо заломлення відбулося, або false при повному внутрішньому відбитті.
 */
bool ray_refract(Vector3 I, Vector3 N, double eta, Vector3* out_refracted) {
    double cos_i = -vec3_dot(I, N);
    Vector3 oriented_N = N;

    /* Перевіряємо, з якого боку межі входить промінь */
    if (cos_i < 0.0) {
        cos_i = -cos_i;
        oriented_N = vec3_scale(N, -1.0);
    }

    double k = 1.0 - eta * eta * (1.0 - cos_i * cos_i);
    if (k < 0.0) {
        /* Повне внутрішнє відбиття */
        return false;
    }

    double cos_t = sqrt(k);
    Vector3 term1 = vec3_scale(I, eta);
    Vector3 term2 = vec3_scale(oriented_N, eta * cos_i - cos_t);
    *out_refracted = vec3_add(term1, term2);

    return true;
}
```
```cpp
#include <cmath>
#include <optional>

struct Vector3 {
    double x{0.0};
    double y{0.0};
    double z{0.0};

    [[nodiscard]] constexpr double dot(const Vector3& rhs) const noexcept {
        return x * rhs.x + y * rhs.y + z * rhs.z;
    }

    [[nodiscard]] constexpr Vector3 operator+(const Vector3& rhs) const noexcept {
        return {x + rhs.x, y + rhs.y, z + rhs.z};
    }

    [[nodiscard]] constexpr Vector3 operator*(double scalar) const noexcept {
        return {x * scalar, y * scalar, z * scalar};
    }

    [[nodiscard]] constexpr Vector3 operator-() const noexcept {
        return {-x, -y, -z};
    }
};

/*
 * Обчислює вектор заломленого променя за допомогою векторного закону Снелла.
 * Повертає std::optional<Vector3>, що містить нормований вектор T або std::nullopt при ПВВ.
 */
[[nodiscard]] std::optional<Vector3> refract(const Vector3& I,
                                            const Vector3& N,
                                            double eta) noexcept {
    double cos_i = -I.dot(N);
    Vector3 oriented_N = N;

    if (cos_i < 0.0) {
        cos_i = -cos_i;
        oriented_N = -N;
    }

    const double k = 1.0 - eta * eta * (1.0 - cos_i * cos_i);
    if (k < 0.0) {
        // Повне внутрішнє відбиття (Total Internal Reflection)
        return std::nullopt;
    }

    const double cos_t = std::sqrt(k);
    return I * eta + oriented_N * (eta * cos_i - cos_t);
}
```

## Спектральне заломлення та обчислення хроматичної дисперсії

Для візуалізації дисперсійного розщеплення світла у призмах та алмазах (дисперсійні каустики) алгоритм трасування випромінює окремі промені для трьох спектральних каналів — червоного (`λ_R = 700 нм`), зеленого (`λ_G = 546 нм`) та синього (`λ_B = 435 нм`).

Для кожного спектрального каналу значення `η` обчислюється індивідуально за законом Снелла:

```
η_R = n₁ / n₂_R
η_G = n₁ / n₂_G
η_B = n₁ / n₂_B
```

Оскільки `n₂_B > n₂_G > n₂_R`, вектор заломлення синього каналу `T_B` відхиляється ближче до нормалі, ніж вектор червоного каналу `T_R`. Розщеплення векторів `T_R`, `T_G`, `T_B` створює у 3D-сцені кольорову веселкову облямівку на межах прозорих об'єктів.

## Розрахунок енергетичного розподілу за наближенням Шліка (Fresnel Blend)

У фізично коректному рендерингу (PBR) самої лише геометричної директиви закону Снелла недостатньо — промінь на межі прозорого середовища розщеплюється на дві частини: відбиту та заломлену. Для обчислення частки енергії `R(θ₁)`, яка відбивається від поверхні під кутом падіння `θ₁`, застосовують наближення Шліка (Schlick's approximation) для рівнянь Френеля:

```
R(θ₁) = R₀ + (1 - R₀) · (1 - cos(θ₁))⁵
```

де `R₀` — коефіцієнт відбиття при нормальному падінні (`θ₁ = 0°`), який прямо розраховується з показників заломлення за законом Снелла:

```
R₀ = ((n₁ - n₂) / (n₁ + n₂))²
```

Частка енергії, що проходить у заломлений промінь за законом Снелла, дорівнює `T_energy = 1 - R(θ₁)`. Якщо алгоритм трасування виявляє Повне Внутрішнє Відбиття (`k < 0`), то `R(θ₁) = 1.0`, і уся енергія передається дзеркально відбитому променю.

## Чисельна стабільність та граничні випадки обчислень

При практичній реалізації векторного заломлення у графічних рушіях та симуляторах оптичних систем розробники стикаються з трьома критичними крайовими проблемами:

### 1. Захист від втрати точності та значення `NaN` при `k ≈ 0`

Коли кут падіння променя дорівнює граничному критичному куту `θ₁ = θ_c`, математичне значення `k` дорівнює точно нулю (`k = 0`). Проте через неминучі похибки заокруглення чисел із плаваючою комою стандартів IEEE 754 (`float` або `double`) обчислення виразу `1.0 - eta * eta * (1.0 - cos_i * cos_i)` може дати невелике від'ємне число на кшталт `-1e-16`.

Якщо передати таке від'ємне значення у функцію обчислення квадратного кореня `std::sqrt(-1e-16)`, процесор поверне значення `NaN` (Not a Number). Поширення значення `NaN` в алгоритмах трасування променів призводить до появи чорних або білих «артефактних пикселів» (fireflies) на підсумковому зображенні. Для захисту від цієї похибки вираз `k` слід обрізати за допомогою функції максимуму:

```cpp
const double k = std::max(0.0, 1.0 - eta * eta * (1.0 - cos_i * cos_i));
```

### 2. Самоперетин променів (Ray Self-Intersection / Shadow Acne)

Після обчислення заломленого вектора `T` нова базова точка випромінювання променя виражається як `P_new = P + T * ε`. Якщо не додати невеликий зсув `ε` (зазвичай `ε ≈ 1e-4`), через похибки координат точка `P` виявиться трохи «позаду» або «попереду» геометричної поверхні, і наступний крок трасування негайно зареєструє помилкове перетинання з тією ж самою поверхнею.

### 3. Оптимізація під векторні SIMD-інструкції (AVX2 / NEON) та GPU-шейдери

Сучасні графічні процесори та компілятори трасування променів (NVIDIA OptiX, DirectX Raytracing, Vulkan DXR) обробляють тисячі променів паралельно. Синтаксис мов HLSL та GLSL містить вбудовану інструкцію `refract(I, N, eta)`. На апаратному рівні GPU виконають векторне заломлення за допомогою SIMD-інструкцій (Single Instruction, Multiple Data) без відгалужень `if/else`, обчислюючи маску Повного Внутрішнього Відбиття через беззнакові порівняння.
