# 🧮 Геометрія та математичний апарат сфери Пуанкаре

Математична концепція сфери Пуанкаре дає можливість наочно відобразити довільний стан поляризації світла у вигляді точки на тривимірній одиничній сфері, а дію оптичних елементів — у вигляді її просторових повертань. Цей геометричний апарат пов'язує параметри поляризаційного еліпса, компоненти вектора Стокса, геометрію групи розширень `SO(3)` та квантовомеханічні симетрії групи `SU(2)` і двокомпонентних спінорів.

### 1. Зв'язок параметрів еліпса та векторів Стокса

Електричне поле монохроматичної плоскої світлової хвилі, що рухається вздовж осі `z`, задається ортогональними компонентами у площині `xy`:

```
E_x(t) = E_0x · cos(ω·t - k·z + φ_x)
E_y(t) = E_0y · cos(ω·t - k·z + φ_y)
```

Поляризаційний еліпс характеризується двома основними геометричними кутами:
1. **Азимутальний кут `ψ`** (`0 ≤ ψ < π`): кут між вектором великої осі еліпса та горизонтальною віссю `x`.
2. **Кут еліптичності `χ`** (`-π/4 ≤ χ ≤ π/4`): виражає відношення малої осі еліпса `b` до великої осі `a` через `tg χ = ± b / a`. Знак кута `χ` визначає напрям обертання (додатний для правої поляризації, від'ємний для лівої).

Чотири нормовані параметри Стокса `s_i = S_i / S_0` для повністю поляризованого світла виражаються через кути `ψ` та `χ` за допомогою сферичних координат:

```
s_1 = S_1 / S_0 = cos(2·χ) · cos(2·ψ)   [1: відносна H/V поляризація]
s_2 = S_2 / S_0 = cos(2·χ) · sin(2·ψ)   [2: відносна +45°/-45° поляризація]
s_3 = S_3 / S_0 = sin(2·χ)              [3: відносна колова поляризація]
```

#### 1.1. Математичний вивід сферичних координат Стокса

Виведемо ці співвідношення з базових виразів для параметрів Стокса:

```
S_0 = E_0x² + E_0y²
S_1 = E_0x² - E_0y²
S_2 = 2 · E_0x · E_0y · cos Δφ
S_3 = 2 · E_0x · E_0y · sin Δφ
```

Виразимо амплітуди `E_0x` та `E_0y` через результуючу амплітуду `E_0 = √(S_0)` та вспоміжний кут `α` (`0 ≤ α ≤ π/2`), де `E_0x = E_0 · cos α` і `E_0y = E_0 · sin α`:

```
S_1 / S_0 = (E_0² · cos² α - E_0² · sin² α) / E_0² = cos² α - sin² α = cos(2·α)
S_2 / S_0 = (2 · E_0² · cos α · sin α · cos Δφ) / E_0² = sin(2·α) · cos Δφ
S_3 / S_0 = (2 · E_0² · cos α · sin α · sin Δφ) / E_0² = sin(2·α) · sin Δφ
```

Використовуючи тригонометричні тотожності зв'язку між кутами `(α, Δφ)` та еліптичними кутами `(ψ, χ)`:

```
cos(2·α) = cos(2·χ) · cos(2·ψ)
sin(2·α) · cos Δφ = cos(2·χ) · sin(2·ψ)
sin(2·α) · sin Δφ = sin(2·χ)
```

Для повністю поляризованого світла строго виконується умова нормування одиничної сфери:

```
s_1² + s_2² + s_3²
= cos²(2·χ)·cos²(2·ψ) + cos²(2·χ)·sin²(2·ψ) + sin²(2·χ)   [підстановка сферичних координат]
= cos²(2·χ) · (cos²(2·ψ) + sin²(2·ψ)) + sin²(2·χ)          [факторизація за спільно розкладеним cos²(2·χ)]
= cos²(2·χ) · 1 + sin²(2·χ)                                 [тригонометрична тотожність: cos²(2·ψ) + sin²(2·ψ) = 1]
= 1                                                         [основна тригонометрична тотожність: cos²(2·χ) + sin²(2·χ) = 1]
```

Точка з декартовими координатами `(s_1, s_2, s_3)` лежить на поверхні радіальної сфери одиничного радіуса `R = 1` у просторі Стокса. Зверніть увагу, що геометричні кути еліпса `ψ` та `χ` подвоюються (`2·ψ` та `2·χ`). Це пов'язано з тим, що зміна орієнтації поляризатора на 180° повертає стан у вихідну позицію, тоді як на сфері Пуанкаре це відповідає повному оберту на 360°.

### 2. Топологія поверхонь сфери Пуанкаре

Геометрія сфери Пуанкаре розподіляє поляризаційні стани за суворими топологічними зонами:

1. **Екваторіальне коло (`s_3 = 0`, тобто `χ = 0`)**: містить усі можливі лінійно поляризовані стани.
   - Точка `(1, 0, 0)` (`ψ = 0°`): горизонтальна поляризація (H).
   - Точка `(-1, 0, 0)` (`ψ = 90°`): вертикальна поляризація (V).
   - Точка `(0, 1, 0)` (`ψ = 45°`): лінійна поляризація під кутом +45°.
   - Точка `(0, -1, 0)` (`ψ = 135°`): лінійна поляризація під кутом -45°.

2. **Полюси сфери (`s_1 = 0, s_2 = 0`, тобто `χ = ±π/4`)**:
   - Північний полюс `(0, 0, +1)` (`χ = +π/4`): права колова поляризація (RCP).
   - Південний полюс `(0, 0, -1)` (`χ = -π/4`): ліва колова поляризація (LCP).

3. **Північна та Південна півсфери**:
   - Північна півсфера (`s_3 > 0`): еліптичні поляризації правого обертання.
   - Південна півсфера (`s_3 < 0`): еліптичні поляризації лівого обертання.

4. **Внутрішній об'єм кулі (`r = √(s_1² + s_2² + s_3²) < 1`)**:
   - Будь-яка внутрішня точка описує **частково поляризоване світло** зі ступенем поляризації `P = r`.
   - Точний центр кулі `(0, 0, 0)` з радіусом `r = 0` виражає **повністю неполяризоване (хаотичне) світло** (`P = 0`).

### 3. Алгебра повертань на сфері: фазові платівки та оператор `SO(3)`

Дія будь-якого оптичного елемента без поглинання (ідеальної фазової платівки чи повороту поляризатора) відповідає **жорсткому повороту сфери Пуанкаре** як твердого тіла навколо певної осі на кут `δ`.

Для фазової платки із запізненням `δ` та швидкою віссю під кутом `θ` до горизонталі вектор осі обертання `n⃗` на екваторі сфери напрямлений під кутом `2·θ`:

```
n⃗ = (cos 2θ,  sin 2θ,  0)ᵀ
```

Трансформація вектора Стокса `s⃗ = (s_1, s_2, s_3)ᵀ` описується трьохвимірною матрицею обертання `R_n(δ) ∈ SO(3)` згідно з формулою Ейлера-Родріга:

```
s⃗_out = s⃗ · cos δ + (n⃗ × s⃗) · sin δ + n⃗ · (n⃗ · s⃗) · (1 - cos δ)
```

Розглянемо фундаментальні приклади перетворення станів на сфері:

#### 3.1. Чвертьхвильова платівка (QWP, `δ = π/2`), швидка вісь під 0°
Вектор осі обертання спрямований уздовж осі `s_1` (`n⃗ = (1, 0, 0)`). Платівка повертає сферу навколо осі `s_1` на кут `90°`.
- Стан падаючого світла під кутом `+45°` має координати `s_in = (0, 1, 0)`.
- Після обертання на 90° навколо осі `s_1` вектор переходить у точку `s_out = (0, 0, 1)` — тобто у Північний полюс (крайня права колова поляризація RCP).

#### 3.2. Півхвильова платівка (HWP, `δ = π`), швидка вісь під кутом `θ`
Вектор осі напрямлений під кутом `2·θ` в екваторіальній площині, а кут обертання дорівнює `180°`.
- Півхвильова платівка віддзеркалює будь-який вектор Стокса відносно осі `2·θ`.
- Якщо падаюче світло є лінійно поляризованим під кутом `α`, вихідне світло залишається лінійно поляризованим, але повертається на кут `2·θ - α`.

### 4. Ізоморфізм `SU(2)` і двокомпонентні спінори

Існує глибока математична аналогія між тривимірним простором Стокса та двоквантовою спінорною механікою (спін-1/2 у квантовій фізиці). Вектор Джонса `J = (E_x, E_y)ᵀ` є чисто геометричним **спінором**.

Кожній точці на сфері Пуанкаре відповідає проективна Ермітова матриця щільності розміром `2×2`:

```
ρ = J · J† = 1/2 · (S_0 · I + S_1 · σ_x + S_2 · σ_y + S_3 · σ_z)
```

де `I` — одинична матриця 2×2, а `σ_x, σ_y, σ_z` — матриці Паулі:

```
σ_x = [ 1   0 ]      σ_y = [ 0  -i ]      σ_z = [ 0   1 ]
      [ 0  -1 ]            [ i   0 ]            [ 1   0 ]
```

Трансформація вектора Джонса `J_out = U · J_in` за допомогою унітарної матриці `U ∈ SU(2)` виражається на сфері Пуанкаре як поворот `R ∈ SO(3)` за допомогою двозначного гомоморфізму між групами Лі `SU(2)` та `SO(3)`:

```
R_ij = 1/2 · Tr(σ_i · U · σ_j · U†)     [перехід від 2×2 complex до 3×3 real]
```

Цей математичний зв'язок показує, що фазова платівка в оптиці діє на вектор Джонса точно так само, як магнітне поле діє на спін електрона у квантовій механіці, а сфера Пуанкаре є точним аналогом **сфери Блоха** (*Bloch sphere*) у квантових обчисленнях.

### 5. Геометрична фаза Панчаратнама-Беррі

Коли стан поляризації світла описує замкнену траєкторію `C` на поверхні сфери Пуанкаре (наприклад, при проходженні крізь послідовність трьох повернутих поляризаторів чи фазових платівок), світлова хвиля набуває додаткового фазового насуву — **геометричної фази Панчаратнама-Беррі** (*Pancharatnam-Berry phase*, `γ_G`).

Величина геометричної фази строго дорівнює половині тілесного кута `Ω`, що охоплюється замкненим контуром `C` на сфері Пуанкаре:

```
γ_G = - 1/2 · Ω                         [Геометрична фаза Панчаратнама]
```

Цей ефект не залежить від довжини оптичного шляху чи показника заломлення середовища, а визначається виключно геометрією замкненої траєкторії на сфері Пуанкаре. Принцип геометричної фази Панчаратнама-Беррі застосовується у сучасній плоскій фотоніці та метаповерхнях для керування хвильовим фронтом світла без використання громіздких лінз.
