# 🧮 Математична модель осцилятора Лоренца та виведення рівняння Селмейєра

Мікроскопічний механізм формування показника заломлення та його залежності від частоти падаючої хвилі (дисперсії) описується класичною моделлю електронного осцилятора Лоренца. Модель розглядає валентний електрон масою `m` і зарядом `-e`, зв'язаний з важким ядром атома квазіпружною повертальною силою з власною резонансною частотою `ω₀`. Рух електрона гальмується силою тертя (загасання) з коефіцієнтом `γ`, яка описує радіаційне згасання або передачу енергії при зіткненнях атомів.

Під дією зовнішнього монохроматичного електричного поля електромагнітної хвилі `E(t) = E₀ · e^(-i·ω·t)` рівняння руху електрона має вигляд класичного диференціального рівняння вимушених коливань:

```
m · (d²x/dt² + γ · dx/dt + ω₀² · x) = -e · E₀ · e^(-i·ω·t)
```

Шукаємо стаціонарний розв'язок у формі вимушених коливань `x(t) = x₀ · e^(-i·ω·t)`. Виконаємо диференціювання функції `x(t)` по часу:

```
d x / dt = -i · ω · x₀ · e^(-i·ω·t)                     [перша похідна по часу]
d² x / dt² = -ω² · x₀ · e^(-i·ω·t)                     [друга похідна по часу]
```

Підставивши знайдені похідні в початкове диференціальне рівняння руху:

```
m · (-ω² - i · γ · ω + ω₀²) · x₀ · e^(-i·ω·t) = -e · E₀ · e^(-i·ω·t)
```

Скоротивши спільний часовий множник `e^(-i·ω·t)` в обох частинах рівняння, отримуємо вираз для комплексної амплітуди зміщення електрона `x₀`:

```
x₀ = -e · E₀ / (m · (ω₀² - ω² - i · γ · ω))            [розв'язок для амплітуди зміщення]
```

Зміщення електрона відносно позитивного ядра створює індукований мікроскопічний електричний дипольний момент атома `p(t) = -e · x(t)`:

```
p₀ = e² · E₀ / (m · (ω₀² - ω² - i · γ · ω))             [комплексна поляризовність]
```

Атомну поляризовність `α(ω)` визначають як коефіцієнт пропорційності між індукованим дипольним моментом `p₀` та локальним електричним полем `E₀`: `p₀ = α(ω) · E₀`.

```
α(ω) = (e² / m) / (ω₀² - ω² - i · γ · ω)              [атомна поляризовність]
```

Фізичний зміст отриманої атомної поляризовності полягає у висвітленні фазового зсуву між збуджувальним полем хвилі та відкликом електрона. При низьких частотах (`ω ≪ ω₀`) електрон коливається у фазі з полем, а поляризовність є дійсною й додатною. При частоті, що наближається до резонансу (`ω ≈ ω₀`), зсув фази сягає `90°`, а амплітуда зміщення електрона різко зростає і обмежується виключно коефіцієнтом загасання `γ`. На високочастотній межі (`ω ≫ ω₀`) електрон через власну інерцію не встигає реагувати на швидкі зміни поля, і його зміщення прямує до нуля у протифазі з полем.

## Від мікроскопічного поля до макроскопічного показника заломлення

Якщо в одиниці об'єму середовища міститься `N` однакових атомів, макроскопічний вектор поляризованості середовища `P` дорівнює вектору суми всіх індукованих дипольних моментів: `P = N · p`. З іншого боку, у макроскопічній електродинаміці поляризованість пов'язана з векторним електричним полем `E` та діелектричною сприйнятливістю `χₑ` співвідношенням `P = ε₀ · χₑ · E`.

У розреджених середовищах (газах) діюче локальне поле на електрон збігається із середнім макроскопічним полем `E`. Тоді комплексна діелектрична сприйнятливість `χₑ(ω)` набуває вигляду:

```
χₑ(ω) = (N · e² / (m · ε₀)) / (ω₀² - ω² - i · γ · ω)    [діелектрична сприйнятливість]
```

Комплексна відносна діелектрична проникність середовища `ε̃(ω) = 1 + χₑ(ω)` пов'язана з комплексним показником заломлення `ñ(ω) = n(ω) + i · k(ω)` фундаментальним співвідношенням Максвелла `ñ² = ε̃`:

```
ñ²(ω) = 1 + (N · e² / (m · ε₀)) / (ω₀² - ω² - i · γ · ω)  [комплексне дисперсійне співвідношення]
```

У щільних діелектриках (скло, кристали, рідини) електричне поле сусідніх поляризованих атомів створює додатковий внесок у діюче локальне поле, яке описується полем Лоренца `E_local = E + P / (3 · ε₀)`. Урахування поля Лоренца приводить до співвідношення Клаузіуса-Моссотті (Lorentz-Lorenz equation):

```
(ñ² - 1) / (ñ² + 2) = N · α(ω) / (3 · ε₀)              [формула Лоренца-Лоренца]
```

Ця формула зв'язує макроскопічний оптичний показник заломлення із мікроскопічною густиною речовини `ρ`. Питома рефракція `R = (n² - 1) / ((n² + 2) · ρ)` залишається інваріантною величиною при фазових переходах, що дозволяє обчислювати показники заломлення сумішей та розчинів за ваговими частками компонентів.

## Прозорі середовища та виведення рівняння Селмейєра

У ділянках оптичного спектра, які віддалені від власного резонансного поглинання середовища, загасанням можна знехтувати (`γ → 0`). У цьому випадку уявна частина показника заломлення прямує до нуля (`k = 0`), а середовище є прозорим. Дійсний показник заломлення `n(ω)` описується рівнянням:

```
n²(ω) = 1 + (N · e² / (m · ε₀)) / (ω₀² - ω²)            [модель прозорого середовища]
```

Реальні оптичні матеріали (наприклад, оптичні скла типу BK7 або F2) містять декілька типів зв'язаних електронів та іонів, що утворюють цілий спектр резонансних частот `ω_j` з відповідними силами осциляторів `f_j` (де відповідно до квантово-механічного правила сум Томаса-Райхе-Куна `∑ f_j = 1`). Внесок усіх типів осциляторів підсумовується:

```
n²(ω) = 1 + (e² / (m · ε₀)) · ∑ [ N_j · f_j / (ω_j² - ω²) ]
```

Для практичного використання у фізиці та оптичному інженерному проектуванні зручно перейти від циклічної частоти `ω` до довжини хвилі у вакуумі `λ = 2π · c / ω` та відповідних резонансних довжин хвиль `λ_j = 2π · c / ω_j`.

Перетворимо різницю квадратів частот у знаменнику дробу:

```
ω_j² - ω² = (2π · c)² / λ_j² - (2π · c)² / λ²
          = (2π · c)² · (1 / λ_j² - 1 / λ²)             [винесення спільного множника]
          = (2π · c)² · (λ² - λ_j²) / (λ² · λ_j²)       [зведення до спільного знаменника]
```

Підставимо отриманий вираз для знаменника у суму за осциляторами:

```
N_j · f_j / (ω_j² - ω²) = N_j · f_j · λ² · λ_j² / ((2π · c)² · (λ² - λ_j²))
```

Ввівши нові безрозмірні позначення коефіцієнтів `B_j = (N_j · f_j · e² · λ_j²) / (4π² · c² · m · ε₀)` та квадрати резонансних довжин хвиль `C_j = λ_j²`, отримуємо канонічне **рівняння Селмейєра (Sellmeier equation)**:

```
n²(λ) = 1 + ∑ [ B_j · λ² / (λ² - C_j) ]                 [загальне рівняння Селмейєра]
```

Для більшості оптичних стекол використовують тричленову формулу Селмейєра, де два члени описують резонанси у коротохвильовій ультрафіолетовій області (електронні переходи з довжинами хвиль `λ₁ ≈ 0.05 ... 0.1` мкм та `λ₂ ≈ 0.1 ... 0.2` мкм), а третій член описує коливання атомної кристалічної ґратки в довгохвильовій інфрачервоній області (`λ₃ ≈ 8 ... 12` мкм):

```
n²(λ) = 1 + (B₁ · λ²) / (λ² - C₁) + (B₂ · λ²) / (λ² - C₂) + (B₃ · λ²) / (λ² - C₃)
```

## Граничний перехід до формули Коші

У прозорій видимій області довжина хвилі падаючого світла `λ` значно більша за УФ-резонансні довжини хвиль `λ_j` (`λ ≫ √C_j`). Це дозволяє розкласти дробовий множник у рівнянні Селмейєра в біноміальний степенний ряд за малим параметром `(C_j / λ²)`:

```
λ² / (λ² - C_j) = 1 / (1 - C_j / λ²)
                = 1 + C_j / λ² + C_j² / λ⁴ + C_j³ / λ⁶ + ...   [розкладання в ряд Тейлора]
```

Підставивши цей степенний ряд у вираз для `n²(λ)` та обмежившись першими трьома членами:

```
n²(λ) ≈ (1 + ∑ B_j) + (∑ B_j · C_j) / λ² + (∑ B_j · C_j²) / λ⁴
```

Враховуючи, що для відхилення показника заломлення від одиниці виконано `n - 1 ≪ 1`, можна скористатися наближенням `n = √(n²) ≈ 1 + 0.5 · (n² - 1)`. У результаті отримуємо класичну емпіричну **формулу Коші (Cauchy formula)**:

```
n(λ) = A + B / λ² + C / λ⁴                              [формула Коші]
```

де феноменологічні коефіцієнти Коші `A`, `B`, `C` пов'язані з мікроскопічними параметрами середовища як:

```
A = 1 + 0.5 · ∑ B_j
B = 0.5 · ∑ (B_j · C_j)
C = 0.5 · ∑ (B_j · C_j²)
```

Формула Коші є дуже зручним практичним наближенням для вузьких спектральних інтервалів у видимому світлі, проте вона принципово не здатна описувати ІЧ-дисперсію та аномальну дисперсію поблизу ліній поглинання, де необхідно використовувати повне рівняння Селмейєра.

## Дисперсійні співвідношення Крамерса-Кроніга

Фундаментальний зв'язок між дійсною частиною показника заломлення `n(ω)` (що описує заломлення та фазову швидкість) та уявною частиною `k(ω)` (що описує поглинання) встановлюють **співвідношення Крамерса-Кроніга (Kramers-Kronig relations)**.

Ці співвідношення є прямою математичною наслідком принципу причинності в електродинаміці (відклик середовища на електричне поле не може передувати самому полю):

```
n(ω) - 1 = (2 / π) · P ∫₀^∞ [ (ω' · k(ω')) / (ω'² - ω²) ] dω'  [Крамерс-Кроніг для дійсної частини]

k(ω) = - (2 · ω / π) · P ∫₀^∞ [ (n(ω') - 1) / (ω'² - ω²) ] dω'  [Крамерс-Кроніг для уявної частини]
```

де символ `P ∫` означає інтеграл у сенсі головного значення за Коші (Cauchy principal value).

Зі співвідношень Крамерса-Кроніга випливає глибокий фізичний висновок: дійсний показник заломлення `n(ω)` на будь-якій вибраній частоті `ω` однозначно визначається інтегральним поглинанням середовища `k(ω')` по всьому спектральному діапазону частот від `0` до `∞`. Будь-яке середовище, яке володіє смугами поглинання, неминуче володіє дисперсією показника заломлення у сусідніх спектральних областях. Це дозволяє експериментально визначати дійсний показник заломлення широкої області спектра на основі виміряних спектрів поглинання без безпосереднього проведення заломлювальних вимірювань.
