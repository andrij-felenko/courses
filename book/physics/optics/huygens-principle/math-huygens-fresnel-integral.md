# 🧮 Математичний апарат принципу Гюйгенса — Френеля та інтеграл Кірхгофа

Математичне формулювання принципу Гюйгенса — Френеля перетворює наочну геометричну ідею про огинаючу вторинних хвиль у строгий обчислювальний апарат скалярної теорії дифракції. Без суворого фазового інтегрування неможливо розрахувати амплітудний розподіл світла у зонах дифракції Френеля та Фраунгофера, обчислити роздільну здатність оптичних приладів чи спроектувати дифракційні оптичні елементи. Цей розрахунок виводить коефіцієнт спрямованості вторинних джерел, пояснює походження фазового зсуву `-π/2` та доводить математичну відсутність зворотної хвилі з перших принципів диференціального рівняння Гельмгольца.

## 1. Постулат Френеля та комплексні амплітуди вторинних джерел

Розглянемо монохроматичне хвильове поле з частотою `ω` та хвильовим числом `k = 2·π / λ`, яке поширюється в однорідному середовищі. Нехай `S` — довільна замкнена або відкрита поверхня, яка збігається з первинним хвильовим фронтом у момент часу `t`. Фізичний сенс методу полягає у заміни реального джерела випромінювання еквівалентним розподілом вторинних точкових випромінювачів, розташованих безпосередньо на проміжній поверхні `S`.

Згідно з принципом Гюйгенса — Френеля, кожен елемент поверхні `dS` у точці `Q` розглядається як когерентне джерело вторинної сферичної хвилі. Диференціал комплексної напруженості електричного поля `d E(P)` у точці спостереження `P`, розташованій на відстані `r` від точкового елемента `dS`, визначається виразом:

```
d E(P)
= C · E(Q) · (e^(i·k·r) / r) · K(θ) · dS        [диференціал вторинного збудження]
```

Тут `E(Q)` — комплексне поле на первинному фронті у точці `Q`, `e^(i·k·r) / r` — факторіальний опис сферичної хвилі, що згасає з відстанню як `1/r`, `K(θ)` — фактор спрямованості (фактор нахилу), який залежить від кута `θ` між зовнішньою нормаллю `n` до поверхні `S` та вектором напрямку `r` на точку `P`, а `C` — постійний комплексний коефіцієнт нормування.

Повне поле у точці `P` обчислюється шляхом сумування (інтегрування) збуджень від усіх вторинних джерел поверхні `S`. Векторна сума у комплексній площині враховує як відносні амплітуди вторинних хвильок, так і їхні фазові зсуви за рахунок різниці шляхів проходження:

```
E(P)
= C · ∫_S E(Q) · (e^(i·k·r) / r) · K(θ) dS       [інтеграл Гюйгенса — Френеля]
```

Для визначення точного фізичного змісту коефіцієнта `C` та фактора `K(θ)` застосуємо методологію зонального аналізу Френеля до розрахунку нескінченної плоскої хвилі.

## 2. Зони Френеля, нормувальний фазовий зсув та зонна пластинка

Нехай на плоский непрозорий екран з отвором падає перпендикулярно плоска хвиля з амплітудою `E_0`. Точка спостереження `P` розташована на нормалі до екрана на відстані `L`. Розіб'ємо первинну площину на концентричні кільцеві зони (зони Френеля) відносно точки `P`. Межі `m`-ї зони визначаються відстанями `r_m` до точки `P` так, щоб кожна наступна зона була віддалена від точки спостереження додатково на півдовжини хвилі `λ/2`:

```
r_m
= L + m · (λ / 2)                               [умова меж зон Френеля]
```

Обчислимо геометричну площу `m`-ї кільцевої зони `Δ S_m`. У практичних оптичних задачах відстань до екрана значно перевищує довжину хвилі (`L ≫ λ`), тому вища степінь `λ²` є нехтовно малою величиною другого порядку дрібності:

```
Δ S_m
= π · r_m² - π · r_{m-1}²
= π · [ (L + m·λ/2)² - (L + (m-1)·λ/2)² ]       [розкриття квадратів]
= π · L · λ + π · (2·m - 1) · λ² / 4
≈ π · L · λ                                     [хвильове наближення L ≫ λ]
```

Оскільки середня відстань від двох сусідніх зон до точки `P` відрізняється на `λ/2`, фази збуджень від сусідніх зон протилежні (різниця фаз дорівнює `π` радіан). Сумарне поле у точці `P` можна подати у вигляді знакозмінного ряду амплітуд:

```
E(P)
= E_1 - E_2 + E_3 - E_4 + ... ± E_m             [знакозмінний ряд зон Френеля]
```

Оскільки амплітуда `E_m` повільно і монотонно зменшується із зростанням номера зони `m` через незначне збільшення відстані `r_m` та зменшення множника `K(θ)`, кожен член ряду можна наближено подати як середнє арифметичне двох сусідніх членів `E_m ≈ (E_{m-1} + E_{m+1}) / 2`. Згрупуємо члени ряду наступним чином:

```
E(P)
= E_1 / 2 + (E_1 / 2 - E_2 + E_3 / 2) + (E_3 / 2 - E_4 + E_5 / 2) + ...
= E_1 / 2                                       [сума монотонного ряду]
```

Фізичний висновок із цієї векторної суми є фундаментальним: підсумкова амплітуда хвильового поля у точці `P` від усього нескінченного відкритого хвильового фронту дорівнює половині амплітуди, яку створює одна лише перша центральна зона Френеля `E_1 / 2`.

Зручним прикладом практичного застосування зон Френеля є **зонова пластинка Френеля**. Якщо перекрити непрозорим екраном усі парні (або всі непарні) зони Френеля, то підсумкове поле у точці `P` перетвориться на суму однознакових членів `E(P) = E_1 + E_3 + E_5 + ... + E_{2m-1}`. Інтенсивність світла у точці `P` при цьому зростає в десятки разів, а сама зонна пластинка діє як фокусувальна лінза з головною фокусною відстанню `f = R_1² / λ`.

Обчислимо внесок першої зони Френеля безпосередньо через інтеграл хвильових елементів. Радіус першої зони дорівнює `R_1 = √(L·λ)`. Інтегруючи по елементах кільця `dS = 2·π·ρ dρ` від `ρ = 0` до `ρ = R_1`, де відстань підкоряється наближенню `r ≈ L + ρ² / (2·L)`:

```
E_1
= C · E_0 · ∫_0^(R_1) (e^(i·k·(L + ρ²/(2·L))) / L) · 2·π·ρ dρ
= C · E_0 · (e^(i·k·L) / L) · [ (2·π·L / (i·k)) · (e^(i·k·λ/2) - 1) ] [інтегрування по ρ]
= C · E_0 · (e^(i·k·L) / L) · [ (L · λ / i) · (-2) ]                   [враховано e^(i·π) = -1]
= C · E_0 · e^(i·k·L) · (2 · λ / (-i))                                 [скорочено L]
= C · E_0 · e^(i·k·L) · (i · 2 · λ)                                    [ураховано 1/(-i) = i]
```

Щоб нескінченний плоский фронт відтворював вихідне поле `E(P) = E_0 · e^(i·k·L)`, сума `E_1 / 2` має тотожно дорівнювати первинному незбуреному полю:

```
E(P)
= E_1 / 2
= C · E_0 · e^(i·k·L) · i · λ
= E_0 · e^(i·k·L)                                [умова відновлення незбуреного поля]
```

Звідси негайно отримуємо строге значення нормувального амплітудно-фазового коефіцієнта `C`:

```
C
= 1 / (i · λ)
= (1 / λ) · e^(-i · π / 2)                       [амплітудно-фазовий коефіцієнт джерела]
```

Цей результат розкриває два критично важливі фізичні факти щодо точкових вторинних джерел:
1. Множник `1/λ` забезпечує правильну розмірність: елемент `dS / (λ · r)` стає безрозмірним коефіцієнтом геометрії.
2. Уявна одиниця `-i = e^(-i · π / 2)` у знаменнику показує, що кожне вторинне точкове джерело Гюйгенса випромінює хвилю із **зсувом фази на `-π/2`** (випередження фази на 90 градусів) відносно первинного падаючого фронту. Цей фазовий зсув компенсаторно врівноважує набіг фази, що виникає при інтегруванні по елементах поверхні.

## 3. Виведення інтеграла Кірхгофа з рівняння Гельмгольца

Строге математичне обґрунтування принципу Гюйгенса — Френеля було отримане німецьким физиком Ґуставом Кірхгофом у 1882 році. Кірхгоф показав, що цей принцип є не просто зручним геометричним постулатом, а точним результатом розв'язку диференціального рівняння хвилі.

Розглянемо скалярне хвильове рівняння для монохроматичної компоненти полів у часовому поданні `E(r, t) = E(r) · e^(-i·ω·t)`. Просторовий розподіл `E(r)` задовольняє однорідне скалярне рівняння Гельмгольца:

```
∇² E + k² E = 0                                 [рівняння Гельмгольца]
```

Застосуємо другу векторну теорему Гріна для скалярної функції поля `E(r)` та фундаментального розв'язку точкового джерела (функції Ґріна для вільного простору) `G(r) = e^(i·k·r) / r` у замкненому об'ємі `V`, обмеженому поверхнею `S`:

```
∫_V (E · ∇² G - G · ∇² E) dV
= ∮_S [ E · (∂G / ∂n) - G · (∂E / ∂n) ] dS       [друга формула Гріна]
```

Оскільки функція Ґріна `G(r)` має математичну сингулярність у точці спостереження `P` (`r = 0`), виключимо точку `P` з об'єму маленькою допоміжною сферою `S_ε` радіуса `ε`. Крім того, для довільної відкритої діафрагми замкнемо поверхню `S` нескінченно віддаленою півсферою `S_∞`. На цій півсфері виконується **умова випромінювання Зоммерфельда**:

```
lim_{r→∞} r · [ (∂E / ∂r) - i · k · E ] = 0    [умова випромінювання Зоммерфельда]
```

Фізичний зміст умови Зоммерфельда полягає у вимозі того, що на нескінченності полем може бути лише хвиля, яка рухається від джерел назовні, а джерела на нескінченності відсутні. Це гарантує, що поверхневий інтеграл по нескінченній півсфері `S_∞` дорівнює нулю.

У решті замкненого об'єму між поверхнею `S` та малою сферою `S_ε` обидві функції задовольняють рівняння Гельмгольца `∇² E = -k² E` та `∇² G = -k² G`. Сума об'ємних інтегралів перетворюється на тотожний нуль:

```
0
= ∮_S [ E · (∂G / ∂n) - G · (∂E / ∂n) ] dS + ∮_{S_ε} [ E · (∂G / ∂n) - G · (∂E / ∂n) ] dS [поверхневі інтеграли]
```

Обчислимо граничний перехід при `ε → 0` на поверхні малої сфери `S_ε`. Для зовнішньої нормалі `n`, яка спрямована всередину малого об'єму (`∂/∂n = -∂/∂r`):

```
lim_{ε→0} ∮_{S_ε} [ E · (- ∂/∂r (e^(i·k·r)/r)) - (e^(i·k·r)/r) · (- ∂E/∂r) ] dS
= lim_{ε→0} ∮_{S_ε} E(P) · (1 / r²) dS           [головний член диференціювання 1/r²]
= lim_{ε→0} E(P) · (1 / ε²) · (4 · π · ε²)
= 4 · π · E(P)                                  [граничне значення поля у точці P]
```

Підставляючи це значення назад у вираз формули Гріна, отримуємо **інтегральну формулу Кірхгофа**:

```
E(P)
= (1 / (4·π)) · ∮_S [ E · (∂/∂n (e^(i·k·r) / r)) - (e^(i·k·r) / r) · (∂E / ∂n) ] dS  [теорема Кірхгофа]
```

Для оптичних хвиль відстань до екрана значно більша за довжину хвилі (`r ≫ λ`), що відповідає виразу `k = 2·π/λ ≫ 1/r`. Обчислимо нормальну похідну функції Ґріна:

```
∂/∂n (e^(i·k·r) / r)
= (∂/∂r (e^(i·k·r) / r)) · cos(n, r)             [диференціювання за напрямком]
= [ i·k · (e^(i·k·r) / r) - (e^(i·k·r) / r²) ] · cos(n, r)
≈ i·k · (e^(i·k·r) / r) · cos(n, r)               [хвильове наближення r ≫ λ]
```

Якщо на поверхню `S` падає первинна хвиля `E(Q) = E_0 · e^(i·k_in·r)`, її нормальна похідна виражається через кут падіння:

```
∂E / ∂n
= i · k · E(Q) · cos(n, k_in)                   [нормальна похідна падаючого поля]
```

Підставляючи ці нормальні похідні в інтеграл Кірхгофа та виносячи спільний множник `i·k / (4·π)`:

```
E(P)
= (1 / (4·π)) · ∮_S [ E(Q) · i·k · (e^(i·k·r)/r) · cos(n, r) - (e^(i·k·r)/r) · i·k · E(Q) · cos(n, k_in) ] dS
= (i · k / (4·π)) · ∮_S E(Q) · (e^(i·k·r) / r) · [ cos(n, r) - cos(n, k_in) ] dS
= (1 / (i · λ)) · ∮_S E(Q) · (e^(i·k·r) / r) · [ (cos(n, r) - cos(n, k_in)) / 2 ] dS [перехід до λ = 2π/k]
```

Отримане рівняння тотожно збігається з хвильовим формулюванням Гюйгенса — Френеля при `C = 1 / (i·λ)`, де фактор спрямованості `K(θ)` тепер виражається точним геометричним співвідношенням:

```
K(θ)
= (cos(n, r) - cos(n, k_in)) / 2                 [фактор спрямованості Кірхгофа]
```

Для випадку, коли первинна хвиля падає перпендикулярно до площини діафрагми, вектор хвильового числа `k_in` спрямований всередину області (`cos(n, k_in) = -1`), і множник Кірхгофа набирає простого вигляду:

```
K(θ)
= (cos θ - (-1)) / 2
= (1 + cos θ) / 2                                [фактор спрямованості для нормального падіння]
```

## 4. Математичне розв'язання парадоксу зворотної хвилі

Отриманий Кірхгофом вираз для `K(θ)` дає аналітичне розв'язання фундаментальної проблеми зворотної хвилі, яка залишалася нездоланною для оригінального геометричного принципу Гюйгенса. Проаналізуємо значення `K(θ)` для трьох ключових напрямків:

1. **Прямий напрямок (`θ = 0`):**
   Кут між нормаллю та напрямком поширення дорівнює нулю (`cos 0 = 1`). Множник `K(0) = (1 + 1) / 2 = 1`. Вторинні сферичні хвилі випромінюються з максимальною амплітудою вздовж нормалі у напрямку поширення.
2. **Перпендикулярний бічний напрямок (`θ = π/2`):**
   Кут дорівнює 90 градусів (`cos(π/2) = 0`). Множник `K(π/2) = (1 + 0) / 2 = 0.5`. Амплітуда вторинного випромінювання зменшується у два рази.
3. **Зворотний напрямок (`θ = π`):**
   Кут дорівнює 180 градусів (`cos π = -1`). Множник `K(π) = (1 - 1) / 2 = 0`. Амплітуда вторинного випромінювання у зворотному напрямку дорівнює **строгому нулю**.

Отже, математична структура рівняння Гельмгольца та граничних умов Гріна повністю виключає появу зворотної хвилі: вторинні джерела фізично не здатні випромінювати хвилю назад до джерела.

## 5. Наближення Френеля та Фраунгофера

Для обчислення реальних дифракційних картин у прикладній оптиці інтеграл Кірхгофа спрощують у залежності від відстані між отвором `S` та екраном спостереження. Розкладемо відстань `r` між точкою отвору `(x', y', 0)` та точкою екрана `(x, y, z)` у ряд Тейлора:

```
r
= √[ z² + (x - x')² + (y - y')² ]
= z · √[ 1 + ((x - x')² + (y - y')²) / z² ]
≈ z + ((x - x')² + (y - y')²) / (2·z)             [параболічне наближення]
= z + (x² + y²) / (2·z) + (x'² + y'²) / (2·z) - (x·x' + y·y') / z [розгортка квадрата різниці]
```

Залежно від того, які члени розкладу необхідно враховувати у фазовому множнику `e^(i·k·r)`, розділяють дві фізичні області дифракції.

### Наближення дифракції Френеля (ближня зона)
Коли відстань `z` порівнянна з розміром апертури `a`, але виконується умова `z³ ≫ (k/8) · ((x-x')² + (y-y')²)²`, квадратними членами `(x'² + y'²) / (2·z)` у показнику експоненти не можна нехтувати:

```
E(x, y, z)
≈ (e^(i·k·z) / (i·λ·z)) · e^(i·k·(x²+y²)/(2·z)) · ∬_S E(x', y') · e^(i·k·(x'²+y'²)/(2·z)) · e^(-i·k·(x·x' + y·y')/z) dx' dy' [інтеграл дифракції Френеля]
```

При дифракції на прямокутній щілині або прямолінійному краї непрозорого екрана у цьому наближенні виникають спеціальні математичні функції — **інтеграли Френеля** `C(u)` та `S(u)`:

```
C(u) = ∫_0^u cos(π · t² / 2) dt
S(u) = ∫_0^u sin(π · t² / 2) dt                  [визначення інтегралів Френеля]
```

Геометричним поданням суми цих інтегралів у комплексній площині є **спіраль Корню** (або клотоїда). Кожна точка спіралі відповідає конкретному положенню края екрана або діафрагми, а довжина вектору, що з'єднує дві точки на спіралі Корню, задає підсумковий модуль амплітуди та фазу електричного поля у даній точці спостереження.

Розподіл інтенсивності біля прямолінійного края непрозорого екрана демонструє характерний хвильовий ефект: замість різкого переходу від 100% світла до повної тіні, на межі геометричної тіні інтенсивність становить рівно 25% від незбуреного значення (`I / I_0 = 0.25`), а у світлій зоні виникають осцилюючі дифракційні смуги, амплітуда яких повільно згасає при віддаленні від края.

### Наближення дифракції Фраунгофера (далека зона)
Коли точка спостереження знаходиться у далекій зоні (або у фокальній площині збиральної лінзи), виконується умова **дифракції Фраунгофера**:

```
z
≫ k · (x'² + y'²) / 2
= π · a² / λ                                     [критерій далекої зони Фраунгофера]
```

У цьому випадку квадратичним фазовим множником `e^(i·k·(x'²+y'²)/(2·z))` усередині інтеграла можна знехтувати (`e^(i·φ) ≈ 1`), і вираз спрощується до двовимірного **перетворення Фур'є** від амплітудної функції отвору `E(x', y')`:

```
E(x, y, z)
≈ C_0 · ∬_S E(x', y') · e^(-i · (u · x' + v · y')) dx' dy' [інтеграл дифракції Фраунгофера]
```

де `u = k · x / z` та `v = k · y / z` — просторові частоти у площині спостереження.

Цей результат встановлює фундаментальний зв'язок між хвильовою оптикою та Фур'є-аналізом: розподіл амплітуди світлового поля у далекій зоні дифракції дорівнює двовимірному просторовому спектру Фур'є для оптичного об'єкта або діафрагми.

## 6. Точний аналітичний розрахунок дифракції на круговому отворі та диск Ейрі

Застосуємо інтеграл Фраунгофера до кругового отвору радіуса `R = D/2`. Перейдемо у полярні координати як у площині отвору `(ρ, φ)`, так і у площині екрана `(w, ψ)`:

```
x' = ρ · cos φ,   y' = ρ · sin φ
x  = w · cos ψ,   y  = w · sin ψ                 [полярна заміна координат]
```

Скалярний добуток у показнику експоненти набирає вигляду:

```
u · x' + v · y'
= (k · w / z) · ρ · (cos φ · cos ψ + sin φ · sin ψ)
= (k · w · ρ / z) · cos(φ - ψ)                   [тригонометричне згортання]
```

Елемент площі дорівнює `dx' dy' = ρ dρ dφ`. Підставляючи ці вирази у двовимірний інтеграл Фраунгофера для рівномірно освітленого круглого отвору з амплітудою `E(x', y') = E_0`:

```
E(w)
= C_0 · E_0 · ∫_0^R ρ dρ ∫_0^(2·π) e^(-i · (k·w·ρ/z) · cos(φ - ψ)) dφ [полярний інтеграл]
```

Внутрішній кутовий інтеграл є відомим інтегральним поданням **функції Бесселя першого роду нульового порядку** `J_0(x)`:

```
∫_0^(2·π) e^(-i · q · cos(φ - ψ)) dφ
= 2 · π · J_0(q)                                 [інтегральне подання Бесселя J_0]
```

де `q = k · w · ρ / z`. Підставляючи цей кутовий інтеграл у радіальний вираз:

```
E(w)
= 2 · π · C_0 · E_0 · ∫_0^R J_0(k · w · ρ / z) · ρ dρ [радіальний інтеграл з J_0]
```

Скористаємося відомою рекурентною тотожністю для математичних функцій Бесселя `∫ x · J_0(x) dx = x · J_1(x)`:

```
E(w)
= 2 · π · C_0 · E_0 · R² · [ J_1(k · w · R / z) / (k · w · R / z) ] [інтегрування Бесселя]
```

Позначаючи безрозмірний параметр `γ = k · w · R / z = π · D · w / (λ · z)`, розподіл інтенсивності світла `I(w) = |E(w)|²` набуває виразу для дифракційної картини **диска Ейрі**:

```
I(w)
= I_0 · [ 2 · J_1(γ) / γ ]²                      [розподіл інтенсивності Ейрі]
```

Перший нуль математичної функції Бесселя `J_1(γ) = 0` спостерігається при значенні аргументу `γ_1 ≈ 3.8317`. Звідси обчислимо кутовий та лінійний радіус центрального світлого диска Ейрі:

```
γ_1
= π · D · w_1 / (λ · z)
= 3.8317                                        [перший нуль J_1]

w_1
= 3.8317 · λ · z / (π · D)
≈ 1.22 · λ · z / D                               [лінійний радіус диска Ейрі]

sin θ_1
≈ w_1 / z
= 1.22 · λ / D                                   [критерій роздільної здатності Релея]
```

Цей строгий математичний результат із інтеграла Гюйгенса — Кірхгофа визначає фундаментальну дифракційну межу роздільної здатності будь-якої оптичної системи (телескопів, мікроскопів, об'єктивів камер): два точкові об'єкти вважаються розділеними, якщо центр диска Ейрі одного збігається з першим мінімумом інтенсивності іншого.

## 7. Дискретне сумування та керування променем у фазованих решітках

Важливим практичним розширенням принципу Гюйгенса у сучасній радіофізиці та мікрохвильовій оптиці є сумування вторинних джерел на дискретній лінійній решітці з `N` елементів. Нехай `N` ізотропних вторинних випромінювачів розміщені уздовж осі `x` з однаковим кроком `d`. Кожен `n`-й випромінювач має керований фазовий зсув `φ_n = n · Δ φ`.

Сумарна комплексна амплітуда у далекій зоні під кутом `θ` до нормалі решітки виражається дискретною сумою Гюйгенса:

```
E(θ)
= E_0 · ∑_{n=0}^{N-1} e^(i · n · (k · d · sin θ + Δ φ)) [дискретна сума Гюйгенса]
```

Це геометрична прогресія із знаменником `q = e^(i · (k · d · sin θ + Δ φ))`. Згортаючи суму геометричної прогресії:

```
E(θ)
= E_0 · [ (1 - e^(i · N · ψ)) / (1 - e^(i · ψ)) ] [сума геометричної прогресії]
```

де `ψ = k · d · sin θ + Δ φ`. Модуль сумарного поля виражається інтерференційною функцією:

```
|E(θ)|
= E_0 · | sin(N · ψ / 2) / sin(ψ / 2) |        [функція спрямованості решітки]
```

Головний максимум інтенсивності досягається при `ψ = 0`, тобто коли `k · d · sin θ + Δ φ = 0`. Кутовий напрямок головного променя керується лінійним фазовим зсувом `Δ φ`:

```
sin θ_main
= - Δ φ / (k · d)
= - (λ / (2·π·d)) · Δ φ                         [формула сканування фазованої решітки]
```

Цей результат є прямою технічною реалізацією принципу Гюйгенса: електронна зміна фаз `Δ φ` між вторинними джерелами повертає результуючу огинаючу (хвильовий фронт) без будь-якого механічного обертання самої антени чи оптичної решітки. У сучасній фотоніці та метаповерхнях цей принцип лежить в основі розробки пласких оптичних елементів та ультратонких керованих оптичних лінз.
