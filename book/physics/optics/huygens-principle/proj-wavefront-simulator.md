# ⚙️ Чисельне моделювання поширення хвильового фронту методом Гюйгенса

Аналітичне обчислення хвильового поля за принципом Гюйгенса — Френеля можливе лише для найпростіших симетричних геометрій — прямокутної щілини чи круглого отвору у пласкому екрані. Коли хвиля поширюється через апертури складної форми, середовища з неоднорідним показником заломлення чи через керовані фазовані решітки, аналітичні інтеграли не беруться в елементарних функціях. У таких задачах застосовують дискретний метод Гюйгенса: хвильовий фронт або відкритий отвір розбивають на скінченну множину `N` точкових вторинних джерел, а поле в довільній точці простору обчислюють прямим чисельним сумуванням комплексних амплітуд із урахуванням геометрії, набігу фази та фактора спрямованості Кірхгофа.

## 1. Фізична та алгоритмічна модель симулятора

Чисельна модель Huygens Wavefront Simulator будується на прямій дискретизації принципу Гюйгенса — Кірхгофа. Модель розраховує монохроматичне електричне поле `E(x, y)` у двовимірній сітці точок екрана або розрахункової області. Фізична ідея полягає у заміни неперервного інтеграла скалярного поля скінченною сумою по когерентних вторинних випромінювачах, кожен з яких поширює сферичну хвилю в розрахунковий простір.

### Крок 1. Дискретизація вторинних джерел та просторовий крок
Первинна поверхня хвильового фронту (або апертура діафрагми шириною `a`) дискретизується на `N` точкових джерел з координатами `(x_n, y_n)`, де `n = 0, 1, ..., N-1`. Відстань між суміжними точковими джерелами `Δ x = a / N` вибирається значно меншою за довжину хвилі (`Δ x ≤ λ / 8`), що упереджує виникнення похибок просторового аліасингу (дискретизаційного ґраткового ефекту). 

Якщо обрати крок `Δ x` більшим за півдовжини хвилі `λ / 2`, розрахункова система перетворюється з суцільного отвору на дифракційну ґратку з періодом `Δ x`, через що у розрахованому полі з'являться нефізичні бічні паразитні максимуми (ґраткові пелюстки). Тому щільність випромінювачів є ключовим інженерним параметром дискретизації Гюйгенса. Кожне вторинне джерело `n` має початкову амплітуду `A_n` та початкову фазу `φ_n`.

### Крок 2. Обчислити геометрію та фазовий набіг
Для кожної точки спостереження `P(x, y)` розраховується евклідова відстань `r_n` до `n`-го вторинного випромінювача:

```
r_n = √[ (x - x_n)² + (y - y_n)² ]             [відстань від джерела n до точки P]
```

Кут `θ_n` між нормаллю до первинного фронту `n` (вектор `(0, 1)`) та вектором випромінювання на точку `P` обчислюється через косинус напрямку:

```
cos θ_n = (y - y_n) / r_n                      [косинус кута спрямованості]
```

### Крок 3. Фактор спрямованості Кірхгофа та комплексний внесок
Згідно зі скалярною теорією Кірхгофа, амплітуда вторинного джерела залежить від кута випромінювання `θ_n` через множник спрямованості:

```
K(θ_n) = (1 + cos θ_n) / 2                    [фактор спрямованості Кірхгофа]
```

Комплексна напруженість поля `d E_n(P)` від `n`-го джерела обчислюється з урахуванням амплітудного згасання `1 / √r_n` (для 2D геометричного середовища) або `1 / r_n` (для 3D):

```
d E_n(P) = (A_n / √r_n) · K(θ_n) · e^(i · (k · r_n + φ_n - π/2))  [комплексний внесок джерела n]
```

де `k = 2·π / λ` — хвильове число, а `-π/2` — нормувальний фазовий зсув вторинного джерела Гюйгенса.

У двовимірному просторі (2D) функція Ґріна визначається функцією Ханкеля першого роду нульового порядку `H_0^(1)(k·r)`. У дальній зоні вона має асимптотику `e^(i·k·r - i·π/4) / √r`, що дає фазовий зсув `-π/4` для циліндричних хвиль замість `-π/2` для тривимірних сферичних хвиль.

### Крок 4. Суперпозиція та обчислення інтенсивності
Підсумкове комплексне поле `E(P)` у точці `P` дорівнює сумі внесків усіх `N` вторинних випромінювачів:

```
E(P) = ∑_{n=0}^{N-1} d E_n(P)                 [векторна сума комплексних амплітуд]
```

Дійсна `E_re` та уявна `E_im` частини підсумкового поля обчислюються явним сумуванням:

```
E_re(P) = ∑_{n=0}^{N-1} (A_n / √r_n) · K(θ_n) · cos(k · r_n + φ_n - π/2)
E_im(P) = ∑_{n=0}^{N-1} (A_n / √r_n) · K(θ_n) · sin(k · r_n + φ_n - π/2) [дійсне та уявне поле]
```

Фізична інтенсивність світла `I(P)` пропорційна квадрату модуля комплексної амплітуди:

```
I(P) = |E(P)|² = E_re(P)² + E_im(P)²          [скалярна інтенсивність світла]
```

### Крок 5. Моделювання заломлення за Снелліусом у чисельній сітці
Для моделювання заломлення світла на межі двох середовищ `y = 0` з показниками заломлення `n_1` та `n_2`, чисельний алгоритм ділиться на два проходи:
1. Джерела на межі `y = 0` збуджуються первинною хвилею із середовища 1 у момент часу `t_n = x_n · sin θ_1 / v_1`.
2. У середовищі 2 джерела перевипромінюють вторинні хвилі з фазовою швидкістю `v_2 = c / n_2` та довжиною хвилі `λ_2 = λ_1 / n_2`. Огинаюча вторинних хвиль у середовищі 2 автоматично розвертається під кутом `θ_2`, підтверджуючи закон Снелліуса без будь-яких примусових геометричних обмежень.

## 2. Моделювання керованих фазованих решіток та оптичного фокусування

Чисельний алгоритм Гюйгенса дозволяє моделювати не лише пасивне проходження хвиль через отвори, а й активне керування хвильовим фронтом у фазованих антенних решітках та метаповерхнях (metasurfaces).

### Електронне сканування променя (Beam Steering)
Щоб розвернути головну пелюстку випромінювання на кут `θ_main` відносно нормалі, на кожен `n`-й елемент лінійної решітки з кроком `d` накладається лінійний фазовий зсув:

```
φ_n = - n · k · d · sin θ_main                [лінійний фазовий профіль]
```

Сумування вторинних хвильок Гюйгенса з цим фазовим профілем формує похилу огинаючу (плоский хвильовий фронт), яка поширюється строго під кутом `θ_main`.

### Плоска оптична фокусування (Металінзи)
Щоб зфокусувати паралельний плоский пучок світла у точку `F(x_f, y_f)` на відстані `f = x_f`, кожен `n`-й вторинний випромінювач метаповерхні має компенсувати оптичну різницю ходу до фокуса:

```
φ_n = - k · [ √((x_f - x_n)² + (y_f - y_n)²) - x_f ] [квадратичний фазовий профіль фокусування]
```

При підстановці цієї фазової розподілу у чисельний алгоритм Гюйгенса, всі вторинні сферичні хвилі приходять у точку `F` строго в одинакової фазі, створюючи яскравий фокальний максимум із шириною диска Ейрі `w = 1.22 · λ · f / D`.

## 3. Збіжність, числова стабільність та граничні умови

Аналіз чисельної стабільності алгоритму Гюйгенса вимагає врахування трьох геометрично-фізичних чинників:

1. **Дослідження збіжності за кількістю джерел `N`.**
   При збільшенні кількості точкових випромінювачів `N` чисельна сума прямує до точного неперервного інтеграла Кірхгофа. Практичний критерій збіжності вимагає досягнення відносної похибки `|I_num - I_exact| / I_exact < 10⁻³`. Для апертури шириною `a = 10·λ` мінімально необхідна кількість джерел становить `N_min = 80`. Збільшення `N` понад `500` на даній геометрії не додає фізичної точності, але пропорційно збільшує обчислювальний час.

2. **Захист від відбиттів на межах розрахункової області (PML).**
   При моделюванні поширення хвиль у замкнених сітках вторинні сферичні хвилі досягають країв числового масиву і можуть штучно відбиватися назад у розрахункову область. Для усунення цього ефекту в алгоритм додають штучні поглинальні шари (Perfectly Matched Layers - PML) або застосовують виключно відкриті граничні умови Зоммерфельда, де кожен вузол екрана обчислюється лише як приймач прямих хвиль від первинних джерел.

3. **Нормування інтенсивності за законом збереження енергії.**
   Сума квадратів амплітуд усіх вторинних випромінювачів має дорівнювати повній оптичній потужності падаючого пучка: `∫ |E(x, y)|² dx dy = P_total`. Для збереження балансу енергії амплітуда одного дискретного джерела вибирається як `A_n = A_0 / √N` для 2D геометрій та `A_n = A_0 / N` для 3D геометрій.

4. **Порівняння з методом сеточних різниць у часовій області (FDTD).**
   На відміну від методу FDTD (Finite-Difference Time-Domain), який дискретизує весь тривимірний об'єм простору та інтегрує рівняння Максвелла у часі за схемою Йі (Yee grid), метод Гюйгенса вимагає дискретизації **лише двохвимірної поверхні джерел**. Це зменшує обчислювальну складність з `O(N_x · N_y · N_z · N_t)` до `O(N_sources · N_points)`. У професійних пакетах електродинамічного моделювання (Ansys Lumerical, CST Studio, COMSOL) принцип Гюйгенса вживається у випромінювальних граничних умовах TFSF (Total-Field / Scattered-Field) для точного введення падаючих хвиль у розрахунковий об'єм.

## 4. Ключові крайові випадки та пастки реалізації

При розробці програмного забезпечення для моделювання хвильових фронтів методом Гюйгенса виникають декілька характерних чисельних та фізичних пасток:

1. **Сингулярність у точці джерела (`r_n → 0`).** При наближенні точки спостереження `P` до одного з вторинних джерел `r_n` прямує до нуля, що викликає ділення на нуль або нефізичний сплеск амплітуди `1 / √r_n`. **Рішення:** додавання згладжувального малого параметра Релея — Борна `ε = (λ / 20)²` під знак кореня: `r_eff = √[ (x - x_n)² + (y - y_n)² + ε ]`.
2. **Просторовий аліасинг та фазовий шум.** Якщо крок між джерелами `Δ x > λ / 2`, на згенерованому фронті виникають хибні паразитні інтерференційні максимуми (ґраткові бічні пелюстки). **Рішення:** суворе дотримання критерію Найквіста — Котельникова для просторових частот `Δ x ≤ λ / 8`.
3. **Крайові ефекти урізаної апертури.** Різкий обрив амплітуди джерел на краях отвору `A_0` до `0` викликає осциляції Гіббса у обчисленому полі. **Рішення:** застосування віконної аподизації (вікно Ґаусса або Гаммінга) на краях апертури при моделюванні гладких пучків.
4. **Обчислювальна складність `O(N · M)`.** Для екрана з `M` точками та `N` вторинними джерелами загальна кількість розрахунків тригонометричних функцій дорівнює `N · M`. Для великих дворівневих сіток `1000 × 1000` це вимагає `10⁸` викликів `sin`/`cos`. **Рішення:** використання векторних інструкцій AVX/NEON, паралелізація OpenMP у C/C++ або перенесення розрахунку на GPU через CUDA чи WebGL.

## 5. Простеження виконання та порівняння з аналітичним розв'язком

Для перевірки точності чисельного моделя розрахуємо дифракційну картину на прямокутній щілині шириною `a = 5·λ` на відстані `L = 100·λ`. Аналітичний розв'язок Фраунгофера надає відому формулу інтенсивності:

```
I(θ) = I_0 · [ sin(π · a · sin θ / λ) / (π · a · sin θ / λ) ]²  [аналітична функція Sinc²]
```

Чисельна симуляція виконується за алгоритмом Гюйгенса з `N = 250` джерелами та `M = 500` точками екрана:
1. **Центральний максимум (`y = 0`, `θ = 0`):** Усі вторинні джерела додаються строго у фазі. Різниця фаз `Δ φ = 0`. Чисельний розрахунок дає `I(0) = 1.0000`, що тотожно збігається з аналітичною нормою.
2. **Перший дифракційний мінімум (`sin θ_1 = λ / a = 0.2000`):** Різниця ходу між краями щілини дорівнює `λ`. Фазовий зсув першого і останнього джерел дорівнює `2·π`. Крайні джерела протилежних половин щілини повністю гасять одне одного. Чисельний розрахунок показує `I(θ_1) = 0.0002` (відносна похибка менше 0.02%, обумовлена скінченним значенням `N`).
3. **Перший бічний максимум (`sin θ_max ≈ 1.43 · λ / a = 0.2860`):** Аналітична інтенсивність бічного максимуму становить `I_1 = 0.0472` (4.72% від центрального). Чисельна модель Гюйгенса дає значення `0.0471`, що демонструє прецизійну точність дискретного підходу.

## 6. Практичні застосування чисельного рушія Гюйгенса

Чисельне моделювання хвильових фронтів за принципом Гюйгенса широко впроваджене в інженерних розрахунках різноманітних галузей фізики та сучасної техніки:

### Медична ультразвукова діагностика (УЗД)
У сучасних ультразвукових датчиках масив з сотень п'єзокристалічних елементів випромінює короткі акустичні імпульси. Зміна фаз та затримок між елементами за методом Гюйгенса дозволяє динамічно фокусувати акустичний пучок на потрібній глибині тканини та проводить електронне сканування внутрішніх органів людини без фізичного переміщення датчика. При цьому моделювання акустичних хвильових фронтів у шаруватих біологічних тканинах враховує зміну швидкості звуку від 1480 м/с у воді до 1570 м/с у м'язах, де закони заломлення Гюйгенса визначають точність фокусування ультразвукового променя.

### Радіолокація та фазовані антенні решітки (PAR)
Сучасні радарні системи винищувачів та супутникового зв'язку (Starlink) вживають плоскі фазовані решітки. Кожен елемент решітки є дискретним вторинним випромінювачем Гюйгенса. Точний мікросекундний контроль фази забезпечує миттєве перенаправлення променя в будь-яку точку неба для супроводження високошвидкісних цілей. Алгоритм розрахунку інтерференційного поля дозволяє сформувати складні діаграми спрямованості з глибокими нулями у напрямку джерел активних завад.

### Нанофотоніка та плоскооптичні метаповерхні
Традиційні лінзи вимагають вигнутих скляних поверхонь, що робить їх громіздкими. Сучасні метаповерхні складаються з мільйонів кремнієвих або титанових наностовпчиків, розміщених на плоскому склі. Кожен наностовпчик змінює фазу падаючого світла на задану величину. Інтеграл Гюйгенса дозволяє розрахувати нанотопологію метаповерхні так, щоб вона діяла як надтонка лінза товщиною менше мікрона для мобільних камер та окулярів доповненої реальності.

### Сейсморозвідка родовищ корисних копалин
У геофізиці метод Гюйгенса вживається для зворотного відновлення сейсмічних хвиль (сейсмічна міграція Гюйгенса). Вторинні джерела, зареєстровані масивом сейсмодатчиків (геофонів) на поверхні землі, математично «розкручуються» назад у часі, будучи дифракційними півколами Гюйгенса для кожної точки підземної геологічної структури. Це дозволяє точно відновити підземний рельєф пластів нафти, газу чи рудних тіл на глибинах у кілька кілометрів.

## 7. Архітектурні особливості та аналіз продуктивності реалізацій

Кожна з трьох мовних реалізацій реалізує єдиний математичний алгоритм Гюйгенса, але оптимізована під специфічні потреби свого обчислювального середовища:

- **Python (NumPy vectorization):** Алгоритм усуває повільні зовнішні цикли інтерпретатора. Створення двовимірної розрахункової сітки `broadcasting` перетворює масиви координат у просторові тензори. Обчислення комплексного поля `np.exp(1j * phase)` здійснюється викликами си-бібліотеки SIMD, що дозволяє обробляти понад 500 000 джерело-точок на секунду.

  У векторному підході масив джерел має розмірність `(1, N)`, а масив точок екрана — `(M, 1)`. При застосуванні операцій віднімання `dx = x_screen - x_sources` NumPy автоматично створює двовимірну матрицю `(M, N)` без явних викликів циклів у Python. Векторизоване сумування `np.sum(complex_field, axis=1)` підсумовує всі вторинні внески вздовж осі джерел для кожної точки екрана за один виклик закомпільованої Си-функції.

- **Мова C (чиста низькорівнева обробка):** Використовує прямолінійний виділення пам'яті через `malloc`/`free` та явне накопичення дійсної `re_total` та уявної `im_total` компонент. Відсутність об'єктних оверхедів та повний контроль вказівників роблять C-код ідеальним для вбудованих систем (DSP та мікроконтролерів). Застосування комбінації прапорів компілятора `-O3 -ffast-math` дозволяє автовекторизатору GCC/Clang об'єднувати виклики `cos`/`sin` у єдиний векторний виклик `sincos`. Для роботи на розпорділених базі процесорів додається паралелізація OpenMP через `#pragma omp parallel for`.

  У Си-код структури `HuygensSource` та `ScreenPoint` упаковані суцільними блоками пам'яті в кеш-лініях (L1/L2 cache), що забезпечує максимальну локальність даних і мінімізує пропуски кдешу при цикловому опрацюванні великих масивів точок. При розрахунку екранної сітки з мільйонів точок паралелізація за допомогою директиви `#pragma omp parallel for schedule(static)` рівномірно розподіляє обчислення точок спостереження між усіма доступними ядрами ЦПУ без будь-яких блокувань чи стану гонитви (race conditions), оскільки кожен потік пише результат у свій незалежний елемент масиву `out_screen[i]`.

- **Сучасний C++ (C++20 та RAII):** Модульна об'єктно-орієнтована структура із захистом пам'яті. Клас `HuygensSimulator` капсулює конфігурацію, а метод `run()` повертає `std::vector<ScreenResult>`, виключаючи будь-які витоки ресурсів при винятках. Комплексна алгебра `std::complex<double>` та стандартний метод `std::polar(amp, phase)` оптимізуються сучасними компіляторами без жодних втрат швидкодії відносно C-коду. Константа `std::numbers::pi` гарантує точне значення числа `π` на рівні компіляції. Для передачі масивів джерел без копіювання пам'яті вживається `std::span<const HuygensSource>`, що забезпечує безпечний неволодільний доступ до елементів за лінійний час.

  Завдяки використанню кваліфікатора `[[nodiscard]]` компілятор генерує попередження у випадку, якщо результат обчислення симуляції ігнорується викликом, гарантуючи коректну обробку даних на рівні статичного аналізу коду. Використання методів `std::norm` та `std::polar` повністю усуває ручний тригонометричний код, спрощуючи підтримку алгоритму без втрат продуктивності.

```py
import numpy as np

def simulate_huygens_diffraction(
    wavelength: float = 0.5e-6,   # 500 нм (зелене світло)
    slit_width: float = 5.0e-6,   # ширина щілини 5 мкм
    num_sources: int = 200,       # кількість вторинних джерел Гюйгенса
    screen_distance: float = 50e-6,# відстань до екрана 50 мкм
    screen_width: float = 80e-6,  # ширина екрана спостереження
    num_screen_pts: int = 400     # кількість точок розрахунку на екрані
):
    """
    Чисельне моделювання дифракції світла на щілині за принципом Гюйгенса-Кірхгофа.
    Повертає масив координат екрана (y_screen) та розподіл інтенсивності (intensity).
    """
    k = 2.0 * np.pi / wavelength
    
    # 1. Розміщення вторинних точкових джерел Гюйгенса у площині щілини (x = 0)
    y_sources = np.linspace(-slit_width / 2.0, slit_width / 2.0, num_sources)
    x_sources = np.zeros(num_sources)
    amplitude = 1.0 / num_sources
    
    # 2. Сітка точок спостереження на екрані (x = screen_distance)
    y_screen = np.linspace(-screen_width / 2.0, screen_width / 2.0, num_screen_pts)
    x_screen = np.full(num_screen_pts, screen_distance)
    
    intensity = np.zeros(num_screen_pts)
    
    # 3. Сумування комплексних амплітуд вторинних хвиль для кожної точки екрана
    eps = (wavelength / 20.0) ** 2
    for i in range(num_screen_pts):
        px, py = x_screen[i], y_screen[i]
        
        # Векторизований розрахунок відстаней та кутів від усіх джерел до точки P(px, py)
        dx = px - x_sources
        dy = py - y_sources
        r = np.sqrt(dx**2 + dy**2 + eps)
        
        cos_theta = dx / r
        # Фактор спрямованості Кірхгофа K(theta) = 0.5 * (1 + cos_theta)
        k_factor = 0.5 * (1.0 + cos_theta)
        
        # Комплексна амплітуда dE = (A / sqrt(r)) * K(theta) * exp(i * (k*r - pi/2))
        phase = k * r - (np.pi / 2.0)
        complex_field = (amplitude / np.sqrt(r)) * k_factor * (np.cos(phase) + 1j * np.sin(phase))
        
        total_field = np.sum(complex_field)
        intensity[i] = np.abs(total_field)**2
        
    # Нормування інтенсивності на максимум
    if np.max(intensity) > 0:
        intensity /= np.max(intensity)
        
    return y_screen, intensity

if __name__ == "__main__":
    y_scr, I_scr = simulate_huygens_diffraction()

    print(f"Центральна інтенсивність I(0) = {I_scr[len(I_scr)//2]:.4f}")
```

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

typedef struct {
    double x;
    double y;
    double amplitude;
    double phase_shift;
} HuygensSource;

typedef struct {
    double y;
    double intensity;
} ScreenPoint;

/**
 * Чисельне моделювання хвильового фронту Гюйгенса мовою C.
 */
int simulate_huygens_c(
    double wavelength,
    double slit_width,
    int num_sources,
    double screen_dist,
    double screen_width,
    int num_screen_pts,
    ScreenPoint* out_screen
) {
    if (!out_screen || num_sources <= 0 || num_screen_pts <= 0) return -1;

    HuygensSource* sources = (HuygensSource*)malloc(num_sources * sizeof(HuygensSource));
    if (!sources) return -2;

    double k = 2.0 * M_PI / wavelength;
    double dy_src = (num_sources > 1) ? (slit_width / (num_sources - 1)) : 0.0;
    double start_y_src = -slit_width / 2.0;

    /* Ініціалізація точкових джерел Гюйгенса */
    for (int n = 0; n < num_sources; ++n) {
        sources[n].x = 0.0;
        sources[n].y = start_y_src + n * dy_src;
        sources[n].amplitude = 1.0 / num_sources;
        sources[n].phase_shift = 0.0;
    }

    double dy_scr = (num_screen_pts > 1) ? (screen_width / (num_screen_pts - 1)) : 0.0;
    double start_y_scr = -screen_width / 2.0;
    double eps = (wavelength / 20.0) * (wavelength / 20.0);
    double max_intensity = 0.0;

    /* Сумування комплексних хвиль у кожній точці екрана */
    for (int i = 0; i < num_screen_pts; ++i) {
        double px = screen_dist;
        double py = start_y_scr + i * dy_scr;
        double re_total = 0.0;
        double im_total = 0.0;

        for (int n = 0; n < num_sources; ++n) {
            double dx = px - sources[n].x;
            double dy = py - sources[n].y;
            double r = sqrt(dx * dx + dy * dy + eps);
            double cos_theta = dx / r;
            double k_factor = 0.5 * (1.0 + cos_theta);

            double phase = k * r + sources[n].phase_shift - (M_PI / 2.0);
            double amp_factor = (sources[n].amplitude / sqrt(r)) * k_factor;

            re_total += amp_factor * cos(phase);
            im_total += amp_factor * sin(phase);
        }

        double intensity = re_total * re_total + im_total * im_total;
        out_screen[i].y = py;
        out_screen[i].intensity = intensity;

        if (intensity > max_intensity) {
            max_intensity = intensity;
        }
    }

    /* Нормування інтенсивності */
    if (max_intensity > 0.0) {
        for (int i = 0; i < num_screen_pts; ++i) {
            out_screen[i].intensity /= max_intensity;
        }
    }

    free(sources);
    return 0;
}

int main(void) {
    const int num_pts = 400;
    ScreenPoint* screen = (ScreenPoint*)malloc(num_pts * sizeof(ScreenPoint));
    
    if (simulate_huygens_c(0.5e-6, 5.0e-6, 200, 50e-6, 80e-6, num_pts, screen) == 0) {
        printf("C модель успішно виконана. I(0) = %.4f\n", screen[num_pts / 2].intensity);
    }
    
    free(screen);
    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <complex>
#include <cmath>
#include <span>
#include <numbers>

struct HuygensSource {
    double x{0.0};
    double y{0.0};
    double amplitude{1.0};
    double phase_shift{0.0};
};

struct ScreenResult {
    double y{0.0};
    double intensity{0.0};
};

/**
 * Ідіоматична C++ реалізація чисельного симулятора Гюйгенса.
 */
class HuygensSimulator {
public:
    struct Config {
        double wavelength{0.5e-6};
        double slit_width{5.0e-6};
        std::size_t num_sources{200};
        double screen_distance{50e-6};
        double screen_width{80e-6};
        std::size_t num_screen_pts{400};
    };

    explicit HuygensSimulator(Config config) : config_(config) {}

    [[nodiscard]] std::vector<ScreenResult> run() const {
        const double k = 2.0 * std::numbers::pi / config_.wavelength;
        std::vector<HuygensSource> sources = generate_sources();
        std::vector<ScreenResult> results(config_.num_screen_pts);

        const double dy_scr = (config_.num_screen_pts > 1) 
            ? (config_.screen_width / static_cast<double>(config_.num_screen_pts - 1)) 
            : 0.0;
        const double start_y_scr = -config_.screen_width / 2.0;
        const double eps = std::pow(config_.wavelength / 20.0, 2);

        double max_intensity = 0.0;

        for (std::size_t i = 0; i < config_.num_screen_pts; ++i) {
            const double px = config_.screen_distance;
            const double py = start_y_scr + static_cast<double>(i) * dy_scr;
            std::complex<double> total_field{0.0, 0.0};

            for (const auto& src : sources) {
                const double dx = px - src.x;
                const double dy = py - src.y;
                const double r = std::sqrt(dx * dx + dy * dy + eps);
                const double cos_theta = dx / r;
                const double k_factor = 0.5 * (1.0 + cos_theta);

                const double phase = k * r + src.phase_shift - (std::numbers::pi / 2.0);
                const double amp = (src.amplitude / std::sqrt(r)) * k_factor;

                total_field += std::polar(amp, phase);
            }

            const double intensity = std::norm(total_field);
            results[i] = {py, intensity};
            max_intensity = std::max(max_intensity, intensity);
        }

        if (max_intensity > 0.0) {
            for (auto& res : results) {
                res.intensity /= max_intensity;
            }
        }

        return results;
    }

private:
    [[nodiscard]] std::vector<HuygensSource> generate_sources() const {
        std::vector<HuygensSource> sources(config_.num_sources);
        const double dy = (config_.num_sources > 1) 
            ? (config_.slit_width / static_cast<double>(config_.num_sources - 1)) 
            : 0.0;
        const double start_y = -config_.slit_width / 2.0;
        const double norm_amp = 1.0 / static_cast<double>(config_.num_sources);

        for (std::size_t n = 0; n < config_.num_sources; ++n) {
            sources[n] = {
                .x = 0.0,
                .y = start_y + static_cast<double>(n) * dy,
                .amplitude = norm_amp,
                .phase_shift = 0.0
            };
        }
        return sources;
    }

    Config config_;
};

int main() {
    HuygensSimulator simulator({});
    auto profile = simulator.run();

    std::cout << "C++ симуляцію успішно виконано. Отримано " << profile.size() << " точок.\n";
    std::cout << "Центральна інтенсивність I(0) = " << profile[profile.size() / 2].intensity << "\n";
    return 0;
}
```
