# 🧮 Математичний вивід розподілу інтенсивності та фазових відносин

Ця математична вставка містить суворий аналітичний вивід формул двощілинної інтерференції, векторний аналіз електромагнітних полів, комбінований розподіл інтенсивності з урахуванням Фраунгоферової дифракції на кінцевій ширині щілин, спектральне розкладання некогерентного світла та розрахунок коефіцієнта контрастності (видності) смуг через функцію просторової й часової когерентності.

---

### 1. Геометрія поля та параксіальне розкладання різниці ходу

Розглянемо дві вузькі паралельні щілини `S₁` та `S₂`, розташовані у непрозорій плоскій ширмі при `x = 0` симетрично відносно оптичної осі `Ox`. Відстань між центрами щілин дорівнює `d`. У тривимірній декартовій системі координат їхні центри мають координати:

```
S₁: (x = 0, y = +d/2, z = 0)
S₂: (x = 0, y = -d/2, z = 0)
```

Спостережний екран розташований паралельно ширмі на відстані `x = L` (`L ≫ d`). Дослідимо довільну точку `P` на екрані з координатами `(L, y, z)`.

Точні евклідові відстані від центрів щілин `S₁` та `S₂` до точки `P`:

```
r₁ = √( L² + (y - d/2)² + z² )
r₂ = √( L² + (y + d/2)² + z² )
```

Оскільки у реальних експериментальних установках відстань до екрана `L` (порядку `1–3 м`) значно перевищує як відстань між щілинами `d` (порядку `0.1–0.5 мм`), так і поперечні зміщення `y, z` на екрані (порядку `1–5 см`), застосуємо параксіальне наближення Тейлора першого порядку для `√(1 + ε) ≈ 1 + ε/2` при `ε ≪ 1`:

```
r₁ = L · √( 1 + ((y - d/2)² + z²) / L² )
   = L · ( 1 + ((y - d/2)² + z²) / (2 L²) ) + O(1/L³)
   = L + z² / (2 L) + (y - d/2)² / (2 L)        [1: відстань r₁]
```

```
r₂ = L · √( 1 + ((y + d/2)² + z²) / L² )
   = L · ( 1 + ((y + d/2)² + z²) / (2 L²) ) + O(1/L³)
   = L + z² / (2 L) + (y + d/2)² / (2 L)        [2: відстань r₂]
```

Обчислимо оптичну різницю ходу `Δs = r₂ - r₁`:

```
Δs = r₂ - r₁
   = [ L + z²/(2L) + (y + d/2)²/(2L) ] - [ L + z²/(2L) + (y - d/2)²/(2 L) ]
   = 1 / (2 L) · [ (y + d/2)² - (y - d/2)² ]
   = 1 / (2 L) · [ (y² + y·d + d²/4) - (y² - y·d + d²/4) ]
   = 1 / (2 L) · [ 2 y · d ]
   = (y · d) / L                                 [3: точна параксіальна різниця ходу Δs]
```

Зверніть увагу: координата `z` повністю скоротилася. Це означає, що у параксіальному наближенні інтерференційні смуги на пласкому екрані являють собою прямі паралельні лінії, орієнтовані вздовж осі `Oz`.

Враховуючи кут спостереження `θ` у площині `Oxy` (де `sin θ ≈ tg θ = y / L` для малих кутів), різницю ходу можна виразити через тригонометричну функцію кута падіння:

```
Δs = d · sin θ
```

### 2. Векторний аналіз Максвелла та інтерференція поляризованих хвиль

У класичній електродинаміці Максвелла світлова хвиля описується векторними полями напруженості електричного поля `E` та магнітної індукції `B`. Для монохроматичної плоскої хвилі електричне поле визначається вектором:

```
E(r, t) = E₀ · cos(ωt - k·r + δ₀)
```

де `E₀` — вектор амплітуди, `ω` — колова частота, `k = (2π/λ) · n` — хвильовий вектор, `δ₀` — початкова фаза.

У точці спостереження `P` на екрані електричне поле є результатом векторної суперпозиції двох хвиль від щілин `S₁` та `S₂`:

```
E_res(t) = E₁(t) + E₂(t)
```

Векторний характер полів відіграє вирішальну роль, яку вперше систематично дослідили Огюстен-Жан Френель та Франсуа Араго у 1819 році (закони Френеля — Араго). 

Розглянемо кут `θ_pol` між векторами електричних полів `E₁` та `E₂`:

```
E₁ = E₀₁ · u₁ · cos(ωt - k·r₁)
E₂ = E₀₂ · u₂ · cos(ωt - k·r₂)
```

де `u₁` та `u₂` — одиничні вектори поляризації.

Часово усереднений вектор Пойнтінга (інтенсивність світла) `I = ⟨|E_res|²⟩` розгортається у скалярний добуток:

```
I = ⟨ |E₁ + E₂|² ⟩
  = ⟨ E₁² ⟩ + ⟨ E₂² ⟩ + 2 · ⟨ E₁ · E₂ ⟩
  = I₁ + I₂ + 2 · √(I₁ · I₂) · (u₁ · u₂) · cos(Δφ)   [4: векторна інтерференція]
```

де `Δφ = k · Δs = (2π · d · y) / (λ · L)` — різниця фаз, а скалярний добуток одиничних векторів поляризації дорівнює `u₁ · u₂ = cos(θ_pol)`.

З цієї формули випливають два фундаментальні граничні випадки:

1. **Паралельні поляризації (`u₁ ∥ u₂`, `θ_pol = 0`, `cos θ_pol = 1`)**:
   Хвилі поляризовані у тій самій площині (наприклад, обидві мають s-поляризацію). Скалярний добуток максимальний, виникає повна скалярна інтерференція з максимальною контрастністю:

```
I(y) = I₁ + I₂ + 2 · √(I₁ · I₂) · cos( (2π · d · y) / (λ · L) )
```

При однаковій амплітуді `I₁ = I₂ = I₀`:

```
I(y) = 2 I₀ · ( 1 + cos Δφ ) = 4 I₀ · cos²(Δφ / 2)
```

2. **Ортогональні поляризації (`u₁ ⟂ u₂`, `θ_pol = 90°`, `cos θ_pol = 0`)**:
   Якщо хвиля від щілини `S₁` поляризована вертикально, а від `S₂` — горизонтально, скалярний добуток `u₁ · u₂` строго дорівнює нулю. Інтерференційний доданок зникає повністю при будь-яких фазових співвідношеннях:

```
I(y) = I₁ + I₂ = 2 I₀ = const
```

Це перший закон Френеля — Араго: **дві хвилі, поляризовані у взаємно перпендикулярних площинах, не інтерферують між собою**. Цей принцип лежить в основі сучасних квантових експериментів із «стереженням шляху» (*which-way detectors*), де поляризаційне маркування щілин нищить інтерференційну картину.

### 3. Інтегрування Фраунгофера для скінченної ширини щілини та N-щілинових ґраток

Розглянемо прямокутну щілину шириною `a` та висотою `h`, орієнтовану вздовж осі `Oz`. За принципом Гюйгенса — Френеля амплітуда хвильового поля `dE` від елементарної смужки шириною `dy'` з координатою `y'` дорівнює:

```
dE(y') = C · dy' · e^(i(ωt - k·r(y')))
```

У наближенні Фраунгофера (віддалена зона, `L ≫ a²/λ`) фаза хвилі від точки `y'` відносно центру щілини змінюється лінійно:

```
k · r(y') ≈ k · r₀ - k · y' · sin θ
```

Інтегруємо амплітуду по всій ширині щілини від `y' = -a/2` до `y' = +a/2`:

```
E_single(θ) = E_c · e^(i(ωt - k r₀)) · ∫_{-a/2}^{+a/2} e^(i · k · y' · sin θ) dy'
```

Обчислимо визначений інтеграл:

```
∫_{-a/2}^{+a/2} e^(i · k · y' · sin θ) dy'
= [ e^(i · k · y' · sin θ) / (i · k · sin θ) ]_{-a/2}^{+a/2}
= ( e^(i · k · (a/2) · sin θ) - e^(-i · k · (a/2) · sin θ) ) / (i · k · sin θ)
= ( 2 i · sin( (k · a · sin θ) / 2 ) ) / ( i · k · sin θ )
= a · [ sin( (π · a · sin θ) / λ ) / ( (π · a · sin θ) / λ ) ]
= a · sinc(β)                                    [5: дифракційний фактор]
```

де введено дифракційний фазовий аргумент `β`:

```
β = (π · a · sin θ) / λ ≈ (π · a · y) / (λ · L)
```

Для системи з `N` однакових паралельних щілин шириною `a`, розташованих із періодом `d`, загальна амплітуда дорівнює сумі `N` членів геометричної прогресії зі знаменником `q = e^(i 2 α)`, де `α = (π · d · sin θ) / λ`:

```
E_total(θ) = E_single(θ) · ∑_{m=0}^{N-1} e^(i · 2 m α)
           = E_single(θ) · [ (1 - e^(i · 2 N α)) / (1 - e^(i · 2 α)) ]
```

Модуль квадрата цієї суми дає загальний розподіл інтенсивності для `N` щілин:

```
I_N(θ) = I₀ · [ sin(N · α) / sin(α) ]² · sinc²(β)   [6: загальна формула N щілин]
```

Підставимо у цю узагальнену формулу `N = 2` для нашого двощілинного випадку:

```
[ sin(2 α) / sin(α) ]² = [ (2 sin α · cos α) / sin α ]² = 4 cos²(α)
```

Отримуємо класичне рівняння двощілинної дифракції-інтерференції:

```
I(θ) = 4 I₀ · cos²( (π · d · sin θ) / λ ) · sinc²( (π · a · sin θ) / λ )  [7: підсумкова двощілинна інтенсивність]
```

Аналіз формули [7]:
- **Інтерференційні максимуми**: виникають при `α = m π`, тобто `d · sin θ = m λ` (`m ∈ ℤ`).
- **Дифракційні мінімуми**: виникають при `β = n π`, тобто `a · sin θ = n λ` (`n ∈ ℤ, n ≠ 0`).
- **Умова зниклих максимумів**: якщо `d / a = m / n` (де `m, n` — цілі числа), то `m`-ний інтерференційний максимум збігається з `n`-ним дифракційним нулем. Внаслідок цього множник `sinc²(n π) = 0` повністю обнуляє інтенсивність, і `m`-на світла смуга зникає з екрана.

### 4. Часова когерентність та спектральне розкладання квазімонохроматичного світла

Жодне реальне фізичне джерело світла не є строго монохроматичним. Випромінювання завжди має скінченну спектральну ширину `Δλ` довкола центральної довжини хвилі `λ₀` (або ширину частоти `Δω` довкола `ω₀`).

Розглянемо квазімонохроматичне джерело з гаусовим спектральним розподілом густини випромінювання `S(ω)`:

```
S(ω) = (I₀ / (√(2π) Δω)) · exp( - (ω - ω₀)² / (2 Δω²) )
```

Відповідно до теореми Вінера — Хінчина, функція часової автокореляції полів `Γ(τ) = ⟨E(t) E*(t + τ)⟩` є фур'є-перетворенням спектральної густини `S(ω)`:

```
Γ(τ) = ∫_{-∞}^{+∞} S(ω) · e^(i ω τ) dω
     = I₀ · exp( - (Δω · τ)² / 2 ) · e^(i ω₀ τ)     [8: автокореляційна функція]
```

Часовий зсув між хвилями від двох щілин дорівнює `τ = Δs / c = (d · y) / (c · L)`. 

Підставляючи автокореляційну функцію у вираз для інтенсивності, отримуємо розподіл освітленості для некогерентного спектрального пучка:

```
I(y) = 2 I₀ · [ 1 + Re( γ(τ) ) ]
     = 2 I₀ · [ 1 + exp( - (Δω · Δs / c)² / 2 ) · cos( (2π · d · y) / (λ₀ · L) ) ]  [9: спектральна інтерференція]
```

З формули [9] видно, що амплітуда інтерференційних осциляцій згасає за гаусовим законом по мірі віддалення від центрального максимуму (`y = 0`). 

Визначаємо **час когерентності** `τ_c` та **довжину часової когерентності** `l_c`:

```
τ_c = 1 / Δω ≈ λ₀² / (2π c Δλ)
l_c = c · τ_c ≈ λ₀² / Δλ                          [10: довжина часової когерентності]
```

Якщо оптична різниця ходу перевищує довжину когерентності (`Δs > l_c`), експоненційний множник `exp( - (Δs / l_c)² )` прямує до нуля. Контрастність смуг зникає, і на екрані залишається рівномірне фонове освітлення `I = 2 I₀`.

Для білого світла (видимий спектр `λ` від 400 нм до 700 нм, `Δλ ≈ 300 нм`, `λ₀ ≈ 550 нм`) довжина когерентності становить лише:

```
l_c ≈ (550 нм)² / 300 нм ≈ 1000 нм = 1.0 мкм
```

Це означає, що при освітленні білим світлом виразні кольорові смуги можна спостерігати лише у безпосередній близькості від центрального максимуму (`|m| ≤ 2..3`), де різниця ходу не перевищує 1–2 мікрони.

### 5. Видність смуг Майкельсона та теорема Ван Циттерта — Церніке

Для квантифікації якості інтерференційної картини Альберт Майкельсон ввів безрозмірний параметр **контрастності (видності) смуг** (*fringe visibility*, `V`):

```
V = (I_max - I_min) / (I_max + I_min)             [11: видність Майкельсона]
```

Для частково когерентного світла з комплексним ступенем просторової когерентності `γ₁₂ = |γ₁₂| · e^(i ϕ₁₂)` розподіл інтенсивності записується у вигляді:

```
I(y) = I₁ + I₂ + 2 · √(I₁ · I₂) · |γ₁₂| · cos( Δφ + ϕ₁₂ )
```

Обчислимо максимальне та мінімальне значення інтенсивності (при `I₁ = I₂ = I₀`):

```
I_max = 2 I₀ · ( 1 + |γ₁₂| )
I_min = 2 I₀ · ( 1 - |γ₁₂| )
```

Підставляючи ці значення у формулу [11], отримуємо фундаментальний висновок:

```
V = [ 2 I₀ (1 + |γ₁₂|) - 2 I₀ (1 - |γ₁₂|) ] / [ 2 I₀ (1 + |γ₁₂|) + 2 I₀ (1 - |γ₁₂|) ]
  = ( 4 I₀ |γ₁₂| ) / ( 4 I₀ )
  = |γ₁₂|                                         [12: точний зв'язок видності та когерентності]
```

Видимість інтерференційних смуг чисельно дорівнює модулю комплексного ступеня просторової когерентності полів у точках розташування щілин.

Ступінь просторової когерентності від розширеного некогерентного джерела шириною `b`, розташованого на відстані `L_s` від двощілинного екрана, обчислюється за **теоремою Ван Циттерта — Церніке**. Згідно з цією теоремою, комплексний ступінь когерентності `γ₁₂` є фур'є-перетворенням нормованого розподілу інтенсивності на поверхні джерела:

```
γ₁₂ = ∫_{-b/2}^{+b/2} I_src(y_s) · e^(i · (2π / λ L_s) · y_s · d) dy_s / ∫ I_src(y_s) dy_s
```

Для однорідного прямокутного джерела шириною `b` цей інтеграл дає стандартну функцію `sinc`:

```
γ₁₂ = sinc( (π · b · d) / (λ · L_s) )            [13: теорема Ван Циттерта — Церніке]
```

Перший нуль когерентності (`V = 0`) виникає при:

```
(π · b · d) / (λ · L_s) = π  ===>  b · d / L_s = λ
```

Ця умова виражає межу просторової когерентності: щоб інтерференційні смуги мали високу контрастність (`V > 0.85`), кутовий розмір джерела `θ_src = b / L_s` повинен задовольняти критерій:

```
θ_src < λ / (2 d)                                 [14: критерій просторової когерентності]
```

Ця формула служить математичною основою зоряної інтерферометрії Майкельсона: вимірюючи відстань між дзеркалами `d`, при якій інтерференційні смуги від зорі повністю зникають (`V = 0`), астрономи точнюсінько обчислюють кутовий діаметр віддалених зір `θ_star = 1.22 λ / d`.
