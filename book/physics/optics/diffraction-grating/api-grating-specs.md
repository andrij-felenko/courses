# 📋 Специфікація та Паспортні параметри оптичних дифракційних ґраток

Довідник паспортних характеристик, класифікаційних параметрів, оптичних інтерфейсів та інженерних вимог до монтажу комерційних дифракційних ґраток для лазерної оптики, спектрометрів, монохроматорів та систем волоконно-оптичного зв'язку.

### 1. Повна матриця класифікації та порівняльних характеристик

В оптичному приладобудуванні вибір типу дифракційної ґратки визначається спектральним діапазоном, необхідною світлосилою, рівнем розсіяного світла та лучевою стійкістю. Нижче наведено зведені параметри основних категорій ґраток.

| :--- | :--- | :--- | :--- | :--- | :--- |

### 2. Детальний опис паспортних параметрів оптичного елемента

При замовленні або розрахунку оптичної системи для кожної дифракційної ґратки визначається строго нормований набір геометричних, оптичних та фізико-механічних характеристик.

#### 2.1. Геометричні та структурні параметри

1. **Густина штрихів (`n` або `groove density`):** Кількість паралельних канавок на один міліметр робочої поверхні.
   - Одиниці вимірювання: `lines/mm` або `grooves/mm`.
   - Зв'язок із періодом ґратки: `d = 10⁶ / n` (де `d` у нанометрах, `n` у `lines/mm`).
   - Стандартні ряди значень: `150`, `300`, `600`, `900`, `1200`, `1800`, `2400`, `3600`, `4800 lines/mm`.
2. **Габаритні та світлові розміри (`W × H × T`):**
   - `W` (ширина уздовж перпендикуляра до штрихів): Визначає світлову апертуру та межу роздільної здатності `R = m · N = m · n · W`.
   - `H` (висота уздовж довжини штрихів): Визначає світлосилу та висоту вхідного пучка.
   - `T` (товщина підкладки): Забезпечує механічну жорсткість. Співвідношення товщини до діагоналі зазвичай становить не менше `1:6` для запобігання температурним деформаціям.
   - Стандартні розміри підкладок: `25 × 25 × 6 мм`, `50 × 50 × 10 мм`, `102 × 102 × 16 мм`.
3. **Матеріал підкладки (Substrate Material):**
   - **Оптичне скло BK7 / N-BK7:** Використовується для відбивних ґраток видимого та ближнього інфрачервоного діапазонів при стандартних температурних умовах.
   - **Плавленый кварц (Fused Silica):** Забезпечує високу термостабільність (КТР `0.5 × 10⁻⁶ K⁻¹`) та прозорість в ультрафіолеті (від `190 нм`).
   - **Сіталл / Zerodur:** Склокераміка з нульовим коефіцієнтом температурного розширення (`< 0.02 × 10⁻⁶ K⁻¹`). Застосовується в прецизійних астрономічних спектрометрах.
   - **Металеві підкладки (мідь, берилій, алюміній):** Для силових лазерних систем із примусовим водяним охолодженням.

#### 2.2. Енергетичні та поляризаційні характеристики

1. **Довжина хвилі Блейза (`λ_b` — Blaze Wavelength):**
   - Довжина хвилі, для якої відносна дифракційна ефективність у робочому порядку (`m = +1` або `m = +2`) досягає максимуму.
   - Вказується для конкретної геометрії освітлення (за замовчуванням для автоколімаційної схеми Літтроу `θₘ = θᵢ = θ_b`).
   - Зв'язок із кутом Блейза: `λ_b = 2 · d · sin θ_b`.
2. **Кут Блейза (`θ_b` — Blaze Angle):**
   - Кут між площиною робочої грані канавки та площиною підкладки ґратки.
   - Стандартні кути блейзування:
     - `5.7°` — відповідає `λ_b ≈ 300 нм` для `600 lines/mm`;
     - `8.6°` — відповідає `λ_b ≈ 500 нм` для `600 lines/mm`;
     - `17.5°` — відповідає `λ_b ≈ 1000 нм` для `600 lines/mm`;
     - `26.7°` — відповідає `λ_b ≈ 500 нм` для `1800 lines/mm`;
     - `63.5°` — стандартний кут для ґраток Ешелле (*blaze angle factor tg θ_b = 2*).
3. **Оптичне покриття (Optical Coating):**
   - **Алюміній (Al):** Стандартне покриття для діапазону `200 нм – 5 мкм`.
   - **Алюміній із захисним шаром фториду магнію (Al + MgF₂):** Запобігає окисленню алюмінію на повітрі та зберігає високий ККД у глибокому УФ (`120–200 нм`).
   - **Золото (Au):** Оптимальне покриття для ІЧ-діапазону (`800 нм – 25 мкм`). Має ККД відбиття понад `98%` та не піддається корозії.
   - **Багатошарові діелектричні покриття (Multilayer Dielectric, MLD):** Використовуються у фазових відбивних ґратках для досягнення пробійної стійкості понад `5 J/cm²` та ККД понад `97%` у вузькій лазерній смузі.
4. **Аномалії Вуда (Wood's Anomalies):**
   - Різкі провали або піки на кривій дифракційної ефективності як функції довжини хвилі для p-поляризованого світла (`TM`).
   - **Аномалії Рейлея (Rayleigh Anomalies):** Виникають при довжинах хвиль, коли один із вищих порядків дифракції поширюється ковзаючи уздовж поверхні ґратки (`θ = ±90°`), викликаючи перерозподіл енергії між іншими порядками.
   - **Резонансні аномалії (Resonance Anomalies):** Пов'язані зі збудженням поверхневих плазмонів у металевому покритті ґратки p-поляризованою хвилею.

### 3. Оптичні схеми установки та розрахункові співвідношення

У практичній оптиці застосовуються чотири класичні інженерні конфігурації монтування дифракційних ґраток.

#### 3.1. Схема Літтроу (Littrow Configuration)

У схемах Літтроу падаючий та дифрагований промені поширюються автоколімаційно уздовж майже однакового оптичного шляху (`θₘ ≈ θᵢ = θ_L`).

- **Рівняння ґратки у схеми Літтроу:**

```
2 · d · sin θ_L = m · λ     [Автоколімаційне рівняння Літтроу]
```

- **Сфера застосування:** Перенастроювані лазерні резонатори (наприклад, лазери на барвниках або CO₂-лазери), де ґратка слугує вибірковим дзеркалом резонатора. Поворот ґратки виділяє вузьку лінію генерації.

#### 3.2. Схема Черні — Тернера (Czerny-Turner Mount)

Найпопулярніша схема для аналітичних спектрометрів та монохроматорів. Включає два вигнутих сферичних дзеркала та плоску відбивну ґратку.

- **Геометричні параметри:**
  - `F₁` — фокусна відстань коліматорного дзеркала М₁;
  - `F₂` — фокусна відстань фокусувального дзеркала М₂;
  - `2·K` — кут між напрямками від дзеркал М₁ та М₂ до центру ґратки (кут відхилення / *inclusion angle*).
- **Кути падіння та дифракції при повороті ґратки на кут `φ`:**

```
θᵢ = φ + K
θₘ = φ - K
```

- **Рівняння ґратки для кута повороту `φ`:**

```
2 · d · cos K · sin φ = m · λ     [Сканування у схемі Черні — Тернера]
```

- **Переваги:** Поворот ґратки довкола центральної осі забезпечує лінійне сканування спектра по довжинах хвиль при нерухомих вхідній та вихідній щілинах.

#### 3.3. Схема Літтмана — Меткалфа (Littman-Metcalf Cavity)

Застосовується у зовнішніх резонаторах напівпровідникових лазерів (ECDL) для отримання вузькосмугового випромінювання з можливістю безперервної перебудови частоти без стрибків мод.

- **Склад:** Напівпровідниковий лазерний чіп, прохідна або відбивна ґратка під ковзаючим кутом падіння (`θᵢ ≈ 85°`) та глухе повертаєме дзеркало.
- **Властивості:** Світло проходить крізь ґратку двічі за один обхід резонатора, що подвоює спектральне розділення `R = 2 · m · N` і звужує лінію генерації лазера до кількох кілогерц.

#### 3.4. Окружність Роуланда для увігнутих ґраток (Rowland Circle Mount)

Для роботи в області вакуумного ультрафіолету (ВУФ, `10–200 нм`) та м'якого рентгенівського випромінювання застосовують увігнуті сферичні ґратки з радіусом кривини `R`.

- **Геометрія кола Роуланда:** Ууявне коло діаметром `D = R`, яке торкається центру увігнутої ґратки.
- **Умова фокусування:** Якщо вхідна щілина розташована в будь-якій точці на колі Роуланда, то дифракційні фокуси всіх порядків та всіх довжин хвиль `λ` також лежать строго на цій самій окружності Роуланда.
- **Переваги:** Відсутність додаткових дзеркал та лінз мінімізує світлові втрати у спектральних областях, де всі оптичні матеріали мають високе поглинання.

### 4. Інженерні вимоги до юстування, юстирування та експлуатації

Дифракційна ґратка є високоточним оптичним елементом з мікроскопічною структурою поверхні, що вимагає дотримання суворих правил монтажу та обслуговування.

#### 4.1. Допустимі відхилення монтажу (Alignment Tolerances)

1. **Кут кутової роз'юстировки штрихів (Tilt / Yaw error):** Кутовий поворот штрихів ґратки відносно вхідної щілини викликає нахил спектральних ліній на матриці детектора. Відхилення не повинно перевищувати `30 кутових секунд` (`30"`) для високої спектральної роздільності.
2. **Центрування світлової плями (Aperture Centering):** Світловий пучок має покривати центральну частину ґратки симетрично. Зріз пучка краєм підкладки викликає дифракційні аберації та зрізання роздільної здатності `R`.
3. **Площинність хвильового фронту підкладки (Flatness / Wavefront Error):**
   - Для вимірювальних спектрометрів: не гірше `λ/4` при `λ = 632.8 нм`.
   - Для інтерферометрів та лазерних компресорів: не гірше `λ/10`.

#### 4.2. Правила поводження та очищення (Handling and Cleaning Protocol)

- ⚠️ **Категорична заборона протирання:** Поверхню нарізної або голографічної ґратки **заборонено протирати** серветками, ватними паличками або будь-якими матеріалами. Мікроскопічні штрихи мають товщину в частки мікрона й безповоротно руйнуються при найменшому механічному контакті.
- **Видалення пилу:** Дозволяється очищення лише безконтактним продуванням сухим знежиреним стисненим азотом або повітрям під тиском не більше `1.5 бар`.
- **Видалення жирових забруднень:** Для нелакованих відбивних ґраток допускається промивання зануренням у надчистий спектральний ізопропіловий спирт або ацетон із наступною сушкою в парах розчинника.
- **Зберігання:** Ґратки повинні зберігатися в герметичних контейнерах у середовищі з відносною вологістю `< 40%` при температурі `20°C ± 5°C` для запобігання окисленню алюмінієвого дзеркального шару.
