# 🧮 Математичний вивід рівняння поляризаційного еліпса та фазового зсуву

Математичний опис поляризованого світла спирається на суворе розкладання вектора напруженості електричного поля `E` на дві взаємно перпендикулярні компоненти в площині, нормальній до напрямку поширення хвилі. Коли дві такі ортогональні гармонічні хвилі поширюються у просторі з однаковою частотою, сумарний вектор електричного поля описує складну криву — поляризаційний еліпс. 

Ця вставка містить покроковий детальний алгебраїчний вивід канонічного рівняння поляризаційного еліпса, аналіз усіх його граничних і часткових станів (лінійна, кругова, еліптична поляризація), а також математичний розрахунок фазової затримки та товщини двозаломлюючих кристалічних пластинок (`λ/4` та `λ/2`).

### 1. Параметрична система вихідних коливань

Розглянемо плоску монохроматичну електромагнітну хвилю, що поширюється вздовж осі `z` у прозорому однорідному середовищі. Згідно з рівняннями Максвелла, вектор напруженості електричного поля `E(z, t)` не має поздовжньої компоненти (`E_z = 0`) і лежить повністю у поперечній площині `xy`.

Будь-який такий вектор можна розкласти на дві ортогональні складові — `Eₓ` уздовж осі `x` та `Eᵣ` уздовж осі `y`:

```
Eₓ(z, t) = E₀ₓ · cos(ω·t - k·z + φₓ)
Eᵣ(z, t) = E₀ᵣ · cos(ω·t - k·z + φᵣ)
```

У цих рівняннях використано такі фізичні величини:
- `E₀ₓ` та `E₀ᵣ` — дійсні додатні амплітуди коливань електричного поля уздовж осей `x` та `y` відповідно, вимірювані у вольтах на метр (В/м);
- `ω` — кругова (колова) частота світлової хвилі, яка пов'язана з циклічною частотою `ν` та довжиною хвилі `λ` співвідношенням `ω = 2·π·ν = 2·π·c / λ`;
- `k = 2·π / λ` — модуль хвильового вектора (хвильове число);
- `φₓ` та `φᵣ` — початкові фази коливань двох ортогональних компонент у момент часу `t = 0` та в точці `z = 0`.

Фізичні властивості поляризованої хвилі залежать не від абсолютних значень фаз `φₓ` та `φᵣ`, а від їхньої відносної різниці, яку позначають `Δφ`:

```
Δφ = φᵣ - φₓ
```

Величина `Δφ` показує, на скільки радіан коливання електричного поля уздовж осі `y` відстають або випереджають коливання уздовж осі `x`.

Щоб спростити подальші тригонометричні перетворення, введемо узагальнену часово-просторову фазу `τ = ω·t - k·z + φₓ`. Тоді вирази для миттєвих компонент напруженості електричного поля набувають зручного параметричного вигляду, де параметром виступає фаза `τ`:

```
Eₓ / E₀ₓ = cos τ
Eᵣ / E₀ᵣ = cos(τ + Δφ)
```

Ця система з двох параметричних рівнянь повністю визначає рух кінчика вектора `E` у площині `xy` з перебігом часу.

### 2. Алгебраїчне виключення часу та вивід рівняння еліпса

Для того щоб знайти геометричне рівняння траєкторії кінця вектора електричного поля у площині `xy`, необхідно алгебраїчно виключити з системи часову фазу `τ`. Це дозволить отримати пряму залежність між `Eᵣ` та `Eₓ`, яка описує геометричну форму хвильового профілю в будь-якому фіксованому перерізі `z`.

Застосуємо відому тригонометричну формулу для косинуса суми двох кутів до другого рівняння системи:

```
Eᵣ / E₀ᵣ = cos τ · cos Δφ - sin τ · sin Δφ
```

Оскільки з першого параметричного рівняння ми маємо точний вираз для косинуса фази `cos τ = Eₓ / E₀ₓ`, підставимо його у розгорнуте рівняння:

```
Eᵣ / E₀ᵣ = (Eₓ / E₀ₓ) · cos Δφ - sin τ · sin Δφ
```

Тепер ізолюємо доданок, що містить синус фази `sin τ`, перенісши член з косинусом різниці фаз у ліву частину рівняння:

```
(Eᵣ / E₀ᵣ) - (Eₓ / E₀ₓ) · cos Δφ = - sin τ · sin Δφ
```

Щоб позбутися синуса фази `sin τ`, піднесемо ліву та праву частини отриманого рівняння до квадрата:

```
[(Eᵣ / E₀ᵣ) - (Eₓ / E₀ₓ) · cos Δφ]² = sin² τ · sin² Δφ
```

Розкриємо квадрат двочлена у лівій частині за стандартним алгебраїчним правилом:

```
(Eᵣ / E₀ᵣ)² - 2 · (Eₓ · Eᵣ / (E₀ₓ · E₀ᵣ)) · cos Δφ + (Eₓ / E₀ₓ)² · cos² Δφ = sin² τ · sin² Δφ
```

Тепер виразимо квадрат синуса `sin² τ` у правій частині через квадрат косинуса `cos² τ` за допомогою основної тригонометричної тотожності `sin² τ = 1 - cos² τ = 1 - (Eₓ / E₀ₓ)²`:

```
sin² τ · sin² Δφ 
= [1 - (Eₓ / E₀ₓ)²] · sin² Δφ
= sin² Δφ - (Eₓ / E₀ₓ)² · sin² Δφ      [розкриття дужок]
```

Підставимо цей вираз назад у праву частину квадратичного рівняння:

```
(Eᵣ / E₀ᵣ)² - 2 · (Eₓ · Eᵣ / (E₀ₓ · E₀ᵣ)) · cos Δφ + (Eₓ / E₀ₓ)² · cos² Δφ
= sin² Δφ - (Eₓ / E₀ₓ)² · sin² Δφ
```

Перенесемо доданок `-(Eₓ / E₀ₓ)² · sin² Δφ` з правої частини у ліву, згрупувавши його з членом `(Eₓ / E₀ₓ)² · cos² Δφ`:

```
(Eₓ / E₀ₓ)² · (cos² Δφ + sin² Δφ) + (Eᵣ / E₀ᵣ)² - 2 · (Eₓ · Eᵣ / (E₀ₓ · E₀ᵣ)) · cos Δφ = sin² Δφ
```

Оскільки сума квадратів косинуса й синуса одного кута дорівнює одиниці (`cos² Δφ + sin² Δφ = 1`), ми отримуємо остаточне канонічне **рівняння поляризаційного еліпса**:

```
(Eₓ / E₀ₓ)² + (Eᵣ / E₀ᵣ)² - 2 · (Eₓ · Eᵣ / (E₀ₓ · E₀ᵣ)) · cos Δφ = sin² Δφ
```

Це рівняння являє собою загальну квадратичну форму двох змінних `Eₓ` та `Eᵣ`. У геометричному відношенні воно описує еліпс у двовимірній декартовій системі координат `(Eₓ, Eᵣ)`. Цей еліпс завжди вписаний у прямокутник зі сторонами `2·E₀ₓ` та `2·E₀ᵣ`, центрований у початку координат.

### 3. Детальний математичний аналіз окремих станів поляризації

Отримане канонічне рівняння є універсальним: воно описує абсолютно всі можливі поляризаційні стани монохроматичного світла. Конкретна форма траєкторії кінця вектора `E` та її орієнтація залежать від співвідношення амплітуд `E₀ₓ`, `E₀ᵣ` і фазової різниці `Δφ`.

#### 3.1. Лінійна (плоска) поляризація

Лінійна поляризація виникає тоді, коли ортогональні коливання відбуваються синфазно або у протифазі, тобто коли різниця фаз дорівнює нулю або кратній `π` радіан.

1. **Випадок синфазних коливань (`Δφ = 0`, `cos Δφ = 1`, `sin Δφ = 0`):**
   Підставляючи значення косинуса й синуса в канонічне рівняння, отримуємо:
   ```
   (Eₓ / E₀ₓ)² + (Eᵣ / E₀ᵣ)² - 2 · (Eₓ · Eᵣ / (E₀ₓ · E₀ᵣ)) = 0
   ```
   Згортаємо ліву частину як квадрат різниці:
   ```
   [(Eₓ / E₀ₓ) - (Eᵣ / E₀ᵣ)]² = 0
   (Eₓ / E₀ₓ) - (Eᵣ / E₀ᵣ) = 0
   Eᵣ = (E₀ᵣ / E₀ₓ) · Eₓ                        [рівняння прямої лінії]
   ```
   Це рівняння прямої лінії, що проходить крізь початок координат у першому та третьому квадрантах. Кут нахилу `θ` цієї прямої до осі `x` визначається співвідношенням амплітуд: `tg θ = E₀ᵣ / E₀ₓ`.

2. **Випадок противофазних коливань (`Δφ = π`, `cos Δφ = -1`, `sin Δφ = 0`):**
   ```
   (Eₓ / E₀ₓ)² + (Eᵣ / E₀ᵣ)² + 2 · (Eₓ · Eᵣ / (E₀ₓ · E₀ᵣ)) = 0
   [(Eₓ / E₀ₓ) + (Eᵣ / E₀ᵣ)]² = 0
   Eᵣ = -(E₀ᵣ / E₀ₓ) · Eₓ                       [пряма у 2-му та 4-му квадрантах]
   ```
   Вектор `E` здійснює лінійні коливання вздовж прямої з від'ємним нахилом.

У обох випадках еліпс вироджується в відрізок прямої лінії. Світло є повністю лінійно поляризованим.

#### 3.2. Кругова (циркулярна) поляризація

Кругова поляризація являє собою частковий випадок, коли кінчик вектора електричного поля описує у просторі правильне коло. Для цього необхідне одночасне виконання двох суворих умов:
1. Амплітуди обох ортогональних компонент повинні бути строго однаковими: `E₀ₓ = E₀ᵣ = E₀`.
2. Зсув фаз між компонентами повинен дорівнювати чверті періоду: `Δφ = ±π/2` (або ±90°).

Підставимо `E₀ₓ = E₀ᵣ = E₀`, `cos(±π/2) = 0` та `sin²(±π/2) = 1` у канонічне рівняння еліпса:

```
(Eₓ / E₀)² + (Eᵣ / E₀)² - 2 · (Eₓ · Eᵣ / E₀²) · 0 = 1
(Eₓ / E₀)² + (Eᵣ / E₀)² = 1
Eₓ² + Eᵣ² = E₀²                                [канонічне рівняння кола]
```

Отримане рівняння описує коло радіуса `E₀`.

Знак різниці фаз визначає напрямок обертання вектора напруженості електричного поля:
- **Правий напрямок обертання (`Δφ = +π/2`):** якщо спостерігач дивиться назустріч світловому променю, вектор `E` повертається за годинниковою стрілкою. У фізичній оптиці таке світло називають правополяризованим за кругом.
- **Лівий напрямок обертання (`Δφ = -π/2`):** вектор `E` повертається проти годинникової стрілки (лівополяризоване світло).

#### 3.3. Геометричні параметри загального поляризаційного еліпса

У найзагальнішому випадку, коли `E₀ₓ ≠ E₀ᵣ`, а фазовий зсув `Δφ` не дорівнює `0`, `π` чи `±π/2`, головні осі поляризаційного еліпса не збігаються з координатами `x` та `y`, а повернуті на деякий кут `ψ`.

Кут орієнтації головної осі еліпса `ψ` (кут між великою піввіссю еліпса та віссю `x`) обчислюється за формулою:

```
tg(2·ψ) = (2 · E₀ₓ · E₀ᵣ / (E₀ₓ² - E₀ᵣ²)) · cos Δφ
```

Співвідношення довжини малої піввісі `b` до великої піввісі `a` описується за допомогою **кута еліптичності** `χ` (`tg χ = ±b / a`), який пов'язаний з амплітудами й фазою виразом:

```
sin(2·χ) = (2 · E₀ₓ · E₀ᵣ / (E₀ₓ² + E₀ᵣ²)) · sin Δφ
```

Кут еліптичності приймає значення від `-45°` (ліва кругова поляризація) до `+45°` (права кругова поляризація). При `χ = 0` еліпс перетворюється на лінію (лінійна поляризація).

### 4. Розрахунок фазової затримки у двозаломлюючих пластинках

При проходженні світла крізь анізотропний двозаломлюючий кристал (наприклад, кварц або кальцит) товщиною `d`, звичайний (`o`) та незвичайний (`e`) промені поширюються з різними фазовими швидкостями:

```
vₒ = c / nₒ
vₑ = c / nₑ
```

де `nₒ` та `nₑ` — показники заломлення середовища для звичайного та незвичайного променів відповідно, а `c` — швидкість світла у вакуумі.

Відповідні хвильові числа у кристалі дорівнюють:

```
kₒ = (2 · π / λ₀) · nₒ
kₑ = (2 · π / λ₀) · nₑ
```

де `λ₀` — довжина хвилі світла у вакуумі.

Провівши світло крізь кристалічну пластинку товщиною `d`, кожна з хвиль накопичує свій власни набіг фази:

```
Фₒ = kₒ · d = (2 · π / λ₀) · nₒ · d
Фₑ = kₑ · d = (2 · π / λ₀) · nₑ · d
```

Результуюча різниця фаз `Δφ`, яка виникає між двома взаємно перпендикулярними поляризаційними компонентами на виході з пластинки, визначається формулою:

```
Δφ = |Фₑ - Фₒ| = (2 · π / λ₀) · |nₑ - nₒ| · d
```

Величина `Δn = |nₑ - nₒ|` називається **абсолютним показником двозаломлення** матеріалу.

#### 4.1. Чвертьхвильова пластинка (Quarter-Wave Plate, `λ/4`)

Чвертьхвильова пластинка призначена для внесення фазового зсуву `Δφ = π/2` (90°) між ортогональними компонентами.

Умова для товщини пластинки `d` має вигляд:

```
(2 · π / λ₀) · |nₑ - nₒ| · d = π / 2 + 2 · π · m   [де m = 0, 1, 2...]
```

Мінімальна товщина пластинки нулевого порядку (`m = 0`) становить:

```
d = λ₀ / (4 · |nₑ - nₒ|)
```

**Практичне значення:** Якщо на чвертьхвильову пластинку падає лінійно поляризоване світло, вектор `E` якого утворює кут 45° до оптичних осей кристала (`E₀ₓ = E₀ᵣ`), пластинка перетворює його на **кругово поляризоване світло**. Якщо ж на таку пластинку спрямувати кругово поляризоване світло, на виході ми отримаємо лінійно поляризоване світло.

#### 4.2. Напівхвильова пластинка (Half-Wave Plate, `λ/2`)

Напівхвильова пластинка вносить фазовий зсув `Δφ = π` (180°).

Мінімальна необхідна товщина `d` обчислюється за формулою:

```
d = λ₀ / (2 · |nₑ - nₒ|)
```

**Практичне значення:** Фазовий зсув на `π` означає зміну знаку однієї з компонент поля на протилежний (`Eᵣ → -Eᵣ`). У результаті вектор напруженості `E` дзеркально відображається відносно оптичної осі пластинки. Якщо вхідний вектор утворював кут `θ` з оптичною віссю, на виході плоскополяризований вектор виявиться повернутим на кут **`2·θ`**. Напівхвильова пластинка є найпростішим і найефективнішим інструментом для точного повороту площини поляризації лазерного випромінювання.
