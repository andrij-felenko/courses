# 🧮 Математичний апарат закону Ламберта та інтегрування по півсфері

Ця вставка містить повний математичний вивід строгих співвідношень між енергетичними та фотометричними величинами ламбертового випромінювача. Вона показує, як із диференціального формулювання закону косинуса Ламберта отримати інтегральний потік у півпростір, вивести коефіцієнт `π` між світимістю й яскравістю, обчислити освітленість від джерел різної геометрії, розрахувати кутові коефіцієнти випромінювання (конфігураційні фактори), а також довести збереження інваріанта яскравості (етанду) уздовж оптичного променя.

---

### 1. Диференціальна форма закону Ламберта та векторний опис

Розглянемо плоский елемент дифузної поверхні площею `dA`. Світловий або енергетичний потік `d²Φ`, який випромінюється (або відбивається) цим елементом у елементарний тілесний кут `dΩ` під кутом `θ` до нормалі `n̂`, задається фундаментальним співвідношенням:

```
d²Φ = L(θ) · dA · cos θ · dΩ
```

У цій формулі використовуються такі величини:
- `dA` — фізична площа випромінювального або відбивального елемента (м²);
- `θ` — зенітний кут між одиничним вектором нормалі до поверхні `n̂` та одиничним вектором напрямку випромінювання `ω̂` (радіани або градуси);
- `dA_proj = dA · cos θ = dA · (n̂ · ω̂)` — проєкована (видима) площа елемента з напрямку `ω̂`;
- `dΩ` — елементарний тілесний кут довкола напрямку `ω̂` (стерадіани, ср);
- `L(θ)` — яскравість (або енергетична яскравість) у напрямку `θ` (Вт/(м²·ср) або кд/м²).

Означення **ідеальної ламбертової поверхні** полягає в тому, що її яскравість є абсолютно однаковою в усіх напрямках верхньої півсфери:

```
L(θ, φ) = L₀ = const
```

Сила світла (або енергетична сила світла) `I(θ)` за означенням є відношенням потоку до елементарного тілесного кута:

```
I(θ) = d²Φ / dΩ
     = (L₀ · dA · cos θ · dΩ) / dΩ   [підставили вираз для d²Φ]
     = (L₀ · dA) · cos θ             [скоротили dΩ]
     = I₀ · cos θ                    [ввели позначення I₀ = L₀ · dA]
```

Отже, сила світла дифузного елемента досягає свого абсолютного максимуму `I₀ = L₀ · dA` вздовж нормалі (`θ = 0°`) і спадає до нуля при наближенні до ковзних кутів (`θ → 90°`).

Векторний запис дифференциального потоку через скалярний добуток нормалі `n̂` та напрямку `ω̂` має вигляд:

```
d²Φ = L₀ · dA · max(0, n̂ · ω̂) · dΩ
```

Оператор `max(0, n̂ · ω̂)` строго відтинає зворотну півсферу (`n̂ · ω̂ < 0`), запевняючи, що елемент поверхні випромінює світло тільки у свій зовнішній півпростір.

### 2. Інтегрування потоку по півсфері: виведення співвідношення M = π · L

Знайдемо повний світловий або енергетичний потік `dΦ`, який елементарна площа `dA` випромінює в увесь верхній напівпростір (півсферу `S²⁺`).

У сферичній системі координат з елементом зенітного кута `θ ∈ [0, π/2]` та азимутального кута `φ ∈ [0, 2π]` елемент тілесного кута `dΩ` розкладається як:

```
dΩ = sin θ · dθ · dφ
```

Щоб обчислити світимість (або енергетичну світимість) `M = dΦ / dA`, проінтегруємо диференціальний потік по всій півсфері:

```
M = (1 / dA) · ∬ d²Φ
  = (1 / dA) · ∫₀²ᵖʰⁱ dφ ∫₀ᵖʰⁱ/² L₀ · dA · cos θ · sin θ dθ
  = L₀ · ∫₀²ᵖʰⁱ dφ · ∫₀ᵖʰⁱ/² cos θ · sin θ dθ        [винесли константи L₀ та dA]
  = L₀ · (2π) · ∫₀ᵖʰⁱ/² cos θ · sin θ dθ             [інтеграл по dφ дає 2π]
```

Для обчислення внутрішнього тригонометричного інтеграла скористаємося тотожністю `cos θ · sin θ = (1/2) · sin(2θ)` або заміною змінних `u = sin θ`, `du = cos θ dθ`:

```
∫₀ᵖʰⁱ/² cos θ · sin θ dθ 
= ∫₀¹ u du                     [межі: u(0)=0, u(π/2)=1]
= [u² / 2]₀¹
= 1/2
```

Підставляємо значення інтеграла назад у вираз для світимості:

```
M = L₀ · (2π) · (1/2)
  = π · L₀
```

Це всесвітньо відомий **закон Ламберта для світимості**:

```
M = π · L
```

Звідси випливає фізичне розуміння коефіцієнта `π`:
Повний тілесний кут півсфери становить `2π` стерадіан. Якби сила світла була однаковою у всіх напрямках (`I(θ) = I₀`), інтегральний потік дорівнював би `2π · I₀`. Проте через геометрію закону косинуса кутові напрями поблизу горизонту (`θ → 90°`) зважуються множником `cos θ → 0`. Ефективний тілесний кут ламбертового випромінювача становить рівно **`π` стерадіан**.

### 3. Освітленість від скінченного ламбертового диска та сфери

#### А. Освітленість від паралельного ламбертового диска

Розглянемо практичну задача: обчислити освітленість `E` у центрі площадки `dA₂`, розташованої на відстані `H` паралельно до плоского ламбертового диска радіуса `R` з постійною яскравістю `L₀`.

Елемент площі диска в полярних координатах `(r, φ)` на диску дорівнює `dA₁ = r · dr · dφ`. Відстань від елемента `dA₁` до точки спостереження дорівнює `ρ = √(r² + H²)`. Кут падіння та випромінювання задовольняє умову `cos θ = H / ρ = H / √(r² + H²)`.

Елементарна освітленість `dE` задається диференціальним законом:

```
dE = (L₀ · dA₁ · cos² θ) / ρ²
   = (L₀ · r · dr · dφ · H²) / (r² + H²)²
```

Інтегруємо по всій площі диска від `r = 0` до `r = R` та від `φ = 0` до `φ = 2π`:

```
E = L₀ · H² · ∫₀²ᵖʰⁱ dφ · ∫₀ᴿ (r / (r² + H²)²) dr
  = L₀ · H² · (2π) · [ -1 / (2 · (r² + H²)) ]₀ᴿ
  = π · L₀ · H² · ( (1 / H²) - (1 / (R² + H²)) )
  = π · L₀ · ( 1 - (H² / (R² + H²)) )
  = π · L₀ · ( R² / (R² + H²) )
  = π · L₀ · sin² α
```

Тут `α` — півкут конуса, під яким диск видно з точки спостереження (`sin α = R / √(R² + H²)`).

Розглянемо граничні випадки цієї формули:

1. **Нескінченна ламбертова площина (`R → ∞`, `α → 90°`):**
   ```
   E = π · L₀ · sin²(90°) = π · L₀ = M
   ```
   Освітленість біля нескінченної ламбертової площини не залежить від відстані `H` і точно дорівнює її світимості `M`.

2. **Віддалений малий диск (`R << H`, точкове джерело площею `A = π · R²`):**
   ```
   E ≈ π · L₀ · (R² / H²) = (L₀ · A) / H² = I₀ / H²
   ```
   Отримуємо класичний закон обернених квадратів Кеплера.

#### Б. Випромінювання суцільної ламбертової сфери

Розглянемо сферичне дифузне джерело (наприклад, розпечену кулю або зірку) радіуса `R_s` з однаковою яскравістю `L₀` по всій поверхні.

Знайдемо силу світла `I_total` всієї кулі у довільному напрямку. Проєкція всієї кулі на площину, перпендикулярну до напрямку спостереження, є кругом радіуса `R_s` площею `A_proj = π · R_s²`.

Оскільки яскравість ламбертової поверхні `L₀` є постійною для кожної точки видимої півсфери, сила світла кулі становить:

```
I_total = L₀ · A_proj = π · R_s² · L₀
```

Повний світловий потік `Φ_total`, випромінюваний кулею в усіх напрямках (у тілесний кут `4π` стерадіан), розраховується шляхом інтегрування постійної сили світла `I_total` по всій сфері напрямків:

```
Φ_total = 4π · I_total = 4π · (π · R_s² · L₀) = 4π² · R_s² · L₀
```

З іншого боку, площа всієї поверхні кулі дорівнює `A_sphere = 4π · R_s²`. Тоді світимість поверхні кулі:

```
M = Φ_total / A_sphere = (4π² · R_s² · L₀) / (4π · R_s²) = π · L₀
```

Ми знову отримали точне співвідношення `M = π · L`, що підтверджує узгодженість фотометричного апарату для кульових об'єктів.

#### В. Освітленість від прямокутного ламбертового випромінювача

Для прямокутної ламбертової площадки розмірами `2a × 2b`, розташованої на відстані `H` паралельно до площини спостереження, інтегрування в декартових координатах дає формулу для освітленості в точці на осьові лінії:

```
X = a / H,  Y = b / H
E = (2 · L₀ / π) · [ (X / √(1 + X²)) · arctan(Y / √(1 + X²)) + (Y / √(1 + Y²)) · arctan(X / √(1 + Y²)) ]
```

Ця формула використовується у професійному світлотехнічному розрахунку растрових і світлодіодних світильників під час проектування освітлення робочих місць.

### 4. Конфігураційні фактори та геометричні аналогії Нуссельта

У теорії радіаційного теплообміну для розрахунку перенесення випромінювання між двома ламбертовими поверхнями `A₁` та `A₂` вводиться безрозмірний **кутовий коефіцієнт випромінювання (конфігураційний фактор)** `F₁₂`. Він показує, яка частка повного випромінювального потоку поверхні `A₁` перехоплюється поверхнею `A₂`:

```
F₁₂ = (1 / A₁) · ∬_A₁ ∬_A₂ (cos θ₁ · cos θ₂ / (π · r²)) dA₁ dA₂
```

Для кутових коефіцієнтів виконується фундаментальне **теорема взаємності (Reciprocity Relation)**:

```
A₁ · F₁₂ = A₂ · F₂₁
```

Ця теорія має наочну геометричну інтерпретацію, відому як **метод аналогії Нуссельта (Nusselt Analog)**:
1. З центру орієнтованого елемента поверхні `dA₁` будується одинична півсфера.
2. Контур поверхні `A₂` проектується з центру на цю півсферу.
3. Отримана на півсфері сферична область проектується прямовисно вниз на площину основи площадки `dA₁`.
4. Площа отриманої плоскої проєкції, поділена на `π`, точно дорівнює конфігураційному фактору `F₁₂`.

Метод Нуссельта дозволяє замінювати складні тривимірні інтеграли обчисленням площ плоских проєкцій, що широко застосовується у геометрії комп'ютерної графіки (алгоритми Radiosity).

### 5. Інваріант яскравості уздовж пучка променів та збереження етанду

У геометричній оптиці важливим наслідком закону Ламберта є теорема про збереження яскравості (та збереження оптичного етанду).

Розглянемо пучок променів перерізом `dA₁`, який поширюється в прозорому середовищі з показником заломлення `n₁` під тілесним кутом `dΩ₁`, і входить у середовище з показником `n₂` (переріз `dA₂`, кут `dΩ₂`).

Зі збереження світлового потоку `d²Φ₁ = d²Φ₂` у відсутність поглинання та закону заломлення Снелла `n₁ · sin θ₁ = n₂ · sin θ₂` випливає диференціальне співвідношення для елементів геометричного етанду:

```
n₁² · dA₁ · cos θ₁ · dΩ₁ = n₂² · dA₂ · cos θ₂ · dΩ₂
```

Підставляючи вираз для потоку `d²Φ = L · dA · cos θ · dΩ`, маємо:

```
L₁ / n₁² = L₂ / n₂²
```

Це рівняння називається **інваріантом яскравості**. 

Для оптичної системи, що працює в одному середовищі (наприклад, у повітрі `n₁ = n₂ = 1`), яскравість уздовж будь-якого пучка променів у відсутність поглинання й розсіювання є **строго постійною**:

```
L_image = L_source · τ
```

де `τ` — коефіцієнт пропускання оптичної системи (`τ ≤ 1`).

> ⚠️ **Фундаментальне обмеження оптики:** Жодна оптична система (лінза, телескоп, мікроскоп, дзеркало чи лупа) не може збільшити яскравість поверхні джерела (`L_image ≤ L_source`). Вона здатна лише змінити кутовий розмір зображення та тілесний кут, зберігши яскравість `L` незмінною або зменшивши її за рахунок поглинання чи відбиття. Спроби побудувати оптичну систему, яка б фокусувала світло ламбертового джерела для створення яскравості, вищої за яскравість самого джерела, еквівалентні створенню вічного двигуна другого роду.

### 6. Мікрофасетні математичні моделі (Орен — Наяр та Гапке)

Для реальних шорстких дифузних поверхонь класичний закон Ламберта дає похибку при великих кутах падіння. У 1994 році Майкл Орен та Шрікумар Наяр розробили фізично обґрунтовану модель, у якій поверхня подається як сукупність мікроскопічних ламбертових фасет із гаусовим розподілом нахилів.

Якщо стандартне відхилення кута нахилу мікрограней дорівнює `σ` (радіани), то BRDF моделі Орена — Наяра набирає вигляду:

```
f_r = (ρ / π) · ( A + B · max(0, cos(φ_i - φ_o)) · sin α · tan β )
```

де коефіцієнти `A` та `B` обчислюються через дисперсію шорсткості `σ²`:

```
A = 1.0 - 0.5 · (σ² / (σ² + 0.33))
B = 0.45 · (σ² / (σ² + 0.09))
```

Кут `α = max(θ_i, θ_o)`, а кут `β = min(θ_i, θ_o)`.

При `σ = 0` (абсолютно гладка мікроповерхня) коефіцієнти дають `A = 1`, `B = 0`, і модель Орена — Наяра тотожно зводиться до класичного закону Ламберта `f_r = ρ / π`. Для шорстких поверхонь (`σ > 0`) модель точніше описує зворотне розсіювання світла, яке спостерігається на реальних об'єктах у природі та астрофізиці.

### 7. Позаосьова освітленість від круглого ламбертового джерела

У практичних задачах проектування оптичних систем виникає потреба обчислити освітленість у точці, яка зміщена на відстань `x` від центральної осі круглого ламбертового випромінювача радіуса `R`, розташованого на відстані `H` паралельно площині.

За формулою Фута — Джонса (Foote & Jones relation), позаосьова освітленість `E(x, H)` описується аналітичним виразом:

```
γ = (x / H),  r = (R / H)
E(x, H) = (π · L₀ / 2) · [ 1 - (1 + γ² - r²) / √((1 + γ² + r²)² - 4 · r² · γ²) ]
```

Аналіз цього виразу показує спад освітленості на краях поля зору. При `x = 0` (`γ = 0`) формула точно зводиться до раніше отриманого виразу `E = π · L₀ · (r² / (1 + r²)) = π · L₀ · sin² α`. При малих радіусах джерела (`r << 1`) вираз зводиться до закону косинуса четвертого ступеня (закон `cos⁴ θ` у фотографії та оптиці об'єктивів):

```
E(θ) = E₀ · cos⁴ θ
```

Тут один косинус походить від проєкції площадки джерела, другий — від проєкції приймача, а два інші косинуси (`cos² θ = H² / ρ²`) з'являються через збільшення відстані від джерела до приймача. Це пояснює віньєтування (потемніння країв) на фотографіях, зроблених ширококутними об'єктивами.

### 8. Математичне доведення інваріантності етанду

Оптичний етанд (*etendue* або геометричний фактор `G`) описує просторово-кутовий об'єм пучка світлових променів:

```
G = n² · ∬_A ∬_Ω cos θ dA dΩ
```

Розглянемо проходження пучка крізь заломлюючу поверхню з радіусом кривини `R_c`, що розділяє середовища з показниками заломлення `n₁` та `n₂`. Згідно з дифференциальною формою закону Снелла:

```
n₁ · sin θ₁ = n₂ · sin θ₂
```

Диференціюючи це рівняння за кутом, отримуємо:

```
n₁ · cos θ₁ dθ₁ = n₂ · cos θ₂ dθ₂
```

Множачи цей вираз на азимутальну частину `dφ` та елемент площі `dA`, знаходимо:

```
n₁² · cos θ₁ dA₁ dΩ₁ = n₂² · cos θ₂ dA₂ dΩ₂
```

Інтегруючи по всій оптичній системі, знаходимо:

```
G₁ = G₂ = const
```

Геометричний етанд є абсолютним інваріантом будь-якої оптичної системи у відсутність втрат. Оскільки світловий потік пов'язаний з етандом співвідношенням `dΦ = L · dG`, збереження потоку `dΦ₁ = dΦ₂` вимагає збереження узагальненої яскравості `L / n² = const`. Це строго доводить неможливість збільшення яскравості зображення за допомогою будь-якої комбінації лінз чи дзеркал.

### 9. Нормування емпіричних BRDF моделей (Фонґ та Блінн-Фонґ)

У комп'ютерній графіці поряд із дифузним ламбертовим розсіюванням `f_r,diff = ρ_d / π` застосовують емпіричні дзеркальні моделі. Для збереження закону енергії сумарна BRDF повинна бути нормованою.

Для дзеркального піку Фонґа з показником блиску `n_s` модель має вигляд:

```
f_r,spec = k_s · (n_s + 2) / (2π) · max(0, R̂ · V̂)ⁿˢ
```

де `R̂` — вектор дзеркально відбитого променя, `V̂` — вектор на спостерігача. Нормувальний коефіцієнт `(n_s + 2) / (2π)` виводиться шляхом інтегрування купола `cosⁿˢ θ` по півсфері:

```
∫₀²ᵖʰⁱ dφ ∫₀ᵖʰⁱ/² cosⁿˢ θ · sin θ dθ = 2π · [ -cosⁿˢ⁺¹ θ / (n_s + 1) ]₀ᵖʰⁱ/² = 2π / (n_s + 1)
```

### 10. Променевий теплообмін між сірими ламбертовими поверхнями

Закон Ламберта є фундаментальною основою теплотехнічного розрахунку променевого теплообміну між сірими тілами у вакуумі чи прозорому середовищі.

Згідно з законом Стефана — Больцмана, власна енергетична світимість абсолютно чорного тіла з температурою `T` дорівнює `M = σ_SB · T⁴`, де `σ_SB ≈ 5.670374 · 10⁻⁸ Вт/(м²·К⁴)` — постійна Стефана — Больцмана. Для сірого тіла з коефіцієнтом чорноти `ε ∈ [0, 1]` власна світимість становить `M_self = ε · σ_SB · T⁴`.

Згідно з законом Кірхгофа, кутовий розподіл власного теплового випромінювання сірого тіла є строго ламбертовим:

```
L_self(θ) = (ε · σ_SB · T⁴) / π
```

Розглянемо дві паралельні нескінченні ламбертові пластини з температурами `T₁` та `T₂` і коефіцієнтами чорноти `ε₁` та `ε₂`. Враховуючи нескінченну серію багаторазових дифузних відбиттів між пластинами, результуюча густина результуючого теплового потоку `q₁₂` (Вт/м²) обчислюється як сума геометричної прогресії:

```
q₁₂ = (σ_SB · (T₁⁴ - T₂⁴)) / ( (1 / ε₁) + (1 / ε₂) - 1 )
```

У цій формулі косинусні кутові інтеграли вже згорнуті в коефіціент `π`, який точно скорочується з `π` у знаменнику яскравості `L = M / π`. Цей математичний результат лежить в основі проектування екранно-вакуумної теплоізоляції (ЕВтІ) космічних апаратів, де десятки шарів алюмінізованого майлару з малим `ε` зменшують втрати тепла в тисячі разів.

### 11. Багатократне розсіювання та H-функції Чандрасекара

Для опису багатократного розсіювання світла у глибоких напівнескінченних шарах пилу чи планетних атмосферах класичного закону Ламберта стає недостатньо. 

Субраманьян Чандрасекар вивів точне математичне рішення рівняння переносу випромінювання за допомогою нелінійного інтегрального рівняння для H-функції:

```
H(μ) = 1 + (w / 2) · μ · H(μ) · ∫₀¹ (H(μ') / (μ + μ')) dμ'
```

де `μ = cos θ`, а `w` — альбедо однократного розсіювання. Відбита яскравість середовища описується добутком H-функцій від кута падіння `μ_i` та кута виходу `μ_o`:

```
L_out(μ_i, μ_o) = (w / 4) · (μ_i / (μ_i + μ_o)) · H(μ_i) · H(μ_o) · E₀
```

При консервативному розсіюванні (`w = 1`, відсутність поглинання) H-функція наближає кутовий розподіл до ламбертового з незначним потемнінням до краю диска, що точно узгоджується з фотометричними вимірюваннями щільних хмарних покривів Венери та Юпітера.
