# 🧮 Математика спектрального інтегрування та фотонного потоку

У цій вставці наведено математичний апарат для роботи зі спектральним розподілом випромінювання AM1.5G: розрахунок інтегральної густоти потужності, перетворення спектральної інтенсивності на фотонний потік, обчислення теоретичного струму короткого замикання напівпровідникових фотоелементів та геометрію маси атмосфери.

---

### 1. Визначення спектральної густоти потужності та чисельне інтегрування

Електромагнітне випромінювання Сонця є безперервним спектральним потоком. Щоб математично описати розподіл енергії по довжинах хвиль, вводять спектральну диференціальну величину — **спектральну густину потужності випромінювання** `E_λ(λ)`.

Фізичний сенс цієї величини полягає у тому, що вона описує густину потоку енергії `dE` [Вт/м²], яка припадає на нескінченно малий інтервал довжин хвиль `dλ` [нм]:

```
E_λ(λ) = dE / dλ      [спектральна диференціальна густина потужності]
```

Одиницею вимірювання `E_λ(λ)` у системі SI є `Вт/(м²·м)`, проте в оптиці та фотовольтаїці загальноприйнято використовувати практичну одиницю `Вт/(м²·нм)`. Щоб перейти від практичних одиниць до системних, спектральне значення помножують на `10⁹`.

Загальна інтегральна густина потужності випромінювання `E_total` [Вт/м²] у визначеному діапазоні довжин хвиль від `λ_min` до `λ_max` обчислюється як визначений інтеграл спектральної функції:

```
E_total = ∫[λ_min..λ_max] E_λ(λ) dλ     [інтегрування спектральної функції потужності]
```

Оскільки експериментальні та нормативні дані стандарту ASTM G173-03 задано не у вигляді неперервної аналітичної функції, а як дискретний масив `N = 2002` точок `(λ_i, E_i)` з нерівномірним кроком сітки `Δλ_i = λ_(i+1) - λ_i` (крок становить 0.5 нм в УФ-області, 1 нм у видимому діапазоні, 5 нм у ближньому ІЧ та до 10–20 нм у далекій інфрачервоній області), чисельне значення інтеграла обчислюють методом трапецій:

```
E_total
= ∑[i=1..N-1] 0.5 · (E_λ(λ_i) + E_λ(λ_(i+1))) · (λ_(i+1) - λ_i)      [квадратура трапецій]
```

Для стандарту AM1.5G у межах спектрального вікна від `λ_min = 280 нм` до `λ_max = 4000 нм` чисельне інтегрування дає:

```
E_total(AM1.5G)
= ∫[280..4000] E_λ^(AM1.5G)(λ) dλ
≈ 1000.4 Вт/м²
```

Ця величина є фундаментальною сталою наземної геліоенергетики та називається «одним стандартним сонцем».

### 2. Перетворення спектра потужності на спектральний фотонний потік

Під час аналізу взаємодії світла з напівпровідниками енергетичний підхід (вимірювання у ватах) є недостатнім. Квантова фізика показує, що внутрішній фотоелектричний ефект є підрахунком поштучних подій: один поглинутий фотон з енергією `hν ≥ E_g` збуджує один електрон із валентної зони до зони провідності. Тому виникає потреба перерахувати спектральну потужність у **спектральну густину фотонного потоку** `Φ_λ(λ)`.

Кожен квант світла (фотон) із довжиною хвилі `λ` несе дискретну порцію енергії `E_photon`:

```
E_photon(λ) = h · f = h · c / λ     [формула Планка — Ейнштейна]
```

де `h ≈ 6.62607015×10⁻³⁴ Дж·с` — фундаментальна стала Планка, `c ≈ 2.99792458×10⁸ м/с` — швидкість світла у вакуумі.

Спектральна густина фотонного потоку `Φ_λ(λ)` [фотонів/(м²·с·нм)] визначає число фотонів з довжиною хвилі `λ`, які щосекунди падають на квадратний метр поверхні в інтервалі `dλ`:

```
Φ_λ(λ)
= E_λ(λ) / E_photon(λ)          [ділення густоти потужності на енергію одного фотона]
= E_λ(λ) · λ / (h · c)          [підстановка квантової енергії E_photon = h·c / λ]
```

Для спрощення інженерних розрахунків добуток `h · c` виражають у зручних комбінованих одиницях `еВ·нм`:

```
h · c
= (6.62607015×10⁻³⁴ Дж·с) · (2.99792458×10⁸ м/с) / (1.602176634×10⁻¹⁹ Дж/еВ)     [переведення джоулів в електронвольти]
≈ 1239.841984 еВ·нм
```

Завдяки цьому співвідношенню енергія фотона у ВeV розраховується за простою формулою:

```
E_photon [еВ] = 1239.84 / λ [нм]
```

А спектральна густина фотонного потоку у практичних одиницях [фотонів/(м²·с·нм)] набирає вигляду:

```
Φ_λ(λ) [фотонів/(м²·с·нм)]
= E_λ(λ) [Вт/(м²·нм)] · λ [нм] / (1.986445×10⁻²⁵ Дж·м)     [чисельний розрахунок фотонного потоку]
```

Загальний інтегральний фотонний потік `Φ_total` [фотонів/(м²·с)], який щосекунди потрапляє на один квадратний метр біля поверхні Землі в умовах AM1.5G, дорівнює:

```
Φ_total
= ∫[280..4000] Φ_λ(λ) dλ
≈ 4.312×10²¹ фотонів/(м²·с)
```

Це означає, що на один квадратний сантиметр сонячної панелі щосекунди випадає понад 4.3 секстильйона світлових квантів.

### 3. Математика фотогенерованого струму короткого замикання J_sc

Кожен поглинутий у напівпровіднику фотон, енергія якого перевищує ширину забороненої зони (`hν ≥ E_g`), генерує одну електронно-діркову пару. Крайня (найдовша) хвиля, здатна викликати фотоефект, називається **червоною межею фотоефекту** або **краєм поглинання** `λ_cut`:

```
λ_cut = h · c / E_g = 1239.84 / E_g [нм]      [порогова довжина хвилі фотоефекту]
```

Реальний фотоприймач чи сонячний елемент має спектрально-залежну **зовнішню квантову ефективність** `EQE(λ)` (*External Quantum Efficiency*). Вона визначається як відношення кількості зібраних на електродах електронів до кількості падаючих фотонів із довжиною хвилі `λ`:

```
EQE(λ) = N_electrons_collected(λ) / N_photons_incident(λ)
```

Густина фотоструму короткого замикання `J_sc` [А/м²] розраховується шляхом інтегрування добутку фотонного потоку на квантову ефективність і елементарний заряд `q`:

```
J_sc = q · ∫[0..λ_cut] Φ_λ(λ) · EQE(λ) dλ      [інтеграл генерації носіїв заряду]
```

де `q ≈ 1.602176634×10⁻¹十九 Кл` — елементарний електричний заряд.

Щоб оцінити фізичну стелю напівпровідникового матеріалу, розглядають **ідеальний фотоелемент**, у якого відсутні оптичні відбиття від поверхні та рекомбінація носіїв (`EQE(λ) = 1` для всіх `λ ≤ λ_cut` та `EQE(λ) = 0` для `λ > λ_cut`). У цьому випадку гранична густина струму `J_sc^(max)` дорівнює:

```
J_sc^(max) = q · ∫[280..λ_cut] Φ_λ(λ) dλ       [граничний фотострум при ідеальній EQE]
```

#### Покроковий розрахунок граничного струму для кремнію (Si):

Ширина забороненої зони кремнію при 300 K становить `E_g = 1.12 еВ`.

1. Розрахунок краю поглинання:
```
λ_cut(Si) = 1239.84 / 1.12 ≈ 1107 нм
```

2. Інтегрування поглинаного фотонного потоку в діапазоні від 280 до 1107 нм:
```
Φ_absorbed(Si)
= ∫[280..1107] Φ_λ(λ) dλ
≈ 2.730×10²¹ фотонів/(м²·с)
```

3. Розрахунок густини струму короткого замикання:
```
J_sc^(max)(Si)
= (1.602176634×10⁻¹⁹ Кл) · (2.730×10²¹ м⁻²·с⁻¹)      [множення елементарного заряду на поглинаний фотонний потік]
= 437.39 А/м²
= 43.74 мА/см²
```

#### Покроковий розрахунок граничного струму для арсеніду галію (GaAs):

Ширина забороненої зони арсеніду галію становить `E_g = 1.42 еВ`.

1. Розрахунок краю поглинання:
```
λ_cut(GaAs) = 1239.84 / 1.42 ≈ 873 нм
```

2. Інтегрування фотонного потоку в діапазоні від 280 до 873 нм:
```
Φ_absorbed(GaAs)
= ∫[280..873] Φ_λ(λ) dλ
≈ 2.000×10²¹ фотонів/(м²·с)
```

3. Розрахунок граничного струму:
```
J_sc^(max)(GaAs)
= (1.602176634×10⁻¹⁹ Кл) · (2.000×10²¹ м⁻²·с⁻¹)      [розрахунок граничного струму GaAs]
= 320.43 А/м²
= 32.04 мА/см²
```

Отримані значення `43.74 мА/см²` для Si та `32.04 мА/см²` для GaAs є фундаментальними метрологічними межами, вище яких струм одного p-n переходу під спектром AM1.5G піднятися не може.

### 4. Геометрія оптичної маси атмосфери та формула Кастена — Янга

У спрощеній моделі атмосфери, яку розглядають як плоский шар постійної густини й товщини `H`, геометричний шлях променя `L` зв'язаний із зенітним кутом Сонця `θ_z` співвідношенням:

```
AM = L / H = 1 / cos(θ_z) = sec(θ_z)     [проста плоскопаралельна модель]
```

Для стандартизованого кута `θ_z = 48.19°`:

```
cos(48.19°) = 0.66666 ≈ 2/3
AM = 1 / (2/3) = 1.5000
```

Проте реальна Земля є кулею з радіусом `R_E ≈ 6371 км`, а атмосфера має експоненціальний профіль густини з ефективною висотою однорідної атмосфери `H_atm ≈ 8.43 км`. При великих кутах зеніту (`θ_z > 60°`) проста формула косеканса дає суттєву похибку, а при `θ_z = 90°` прямує до нескінченності, хоча реальний оптичний шлях на горизонті дорівнює приблизно `AM ≈ 38`.

Для точного опису маси атмосфери у всьому діапазоні кутів зеніту (включаючи рефракцію світла у сферичних шарах повітря) німецький метеоролог Фріц Кастен та його колега Річард Янг у 1989 році вивели апроксимаційну формулу **Кастена — Янга** (*Kasten-Young formula*):

```
AM = 1 / [cos(θ_z) + 0.50572 · (96.07995° - θ_z)^(-1.6364)]      [формула Кастена — Янга з атмосферною рефракцією]
```

Здійснимо порівняльний розрахунок оптичної маси за двома моделями для різних кутів зеніту Сонця:

```
1. Випадок θ_z = 48.19° (Стандарт AM1.5):
   Плоскопаралельна модель: AM_plane = 1 / cos(48.19°) = 1.5000
   Формула Кастена — Янга: 
     Δθ = 96.07995° - 48.19° = 47.88995°
     (47.88995)^(-1.6364) ≈ 0.001763
     AM_KY = 1 / [0.66666 + 0.50572 · 0.001763] = 1.4981      [обчислення AM за Кастеном — Янгом]
   Абсолютна різниця: 0.0019 (відносна похибка спрощеної моделі < 0.13%)

2. Випадок θ_z = 70.0°:
   AM_plane = 1 / cos(70°) = 2.9238
   AM_KY = 2.9044
   Відносна похибка спрощеної моделі: ~ 0.67%

3. Випадок θ_z = 85.0° (Сонце біля горизонту):
   AM_plane = 1 / cos(85°) = 11.4737
   AM_KY = 10.3952
   Відносна похибка спрощеної моделі: ~ 10.4%
```

Отже, для стандартизованого зенітного кута `θ_z = 48.19°` спрощене співвідношення `AM = 1 / cos(θ_z) = 1.5` демонструє високу математичну точність, відхиляючись від точного геодезичного розрахунку менше ніж на дві тисячні частки.

### 5. Математична розкладка межі Шоклі — Квайссера під AM1.5G

Щоб обчислити граничний ККД одноперехідного сонячного елемента під спектром AM1.5G, падаючу потужність випромінювання `P_in = ∫ E_λ(λ) dλ = 1000 Вт/м²` розкладають на чотири фундаментальні доданки:

```
P_in = P_el + P_therm + P_transp + P_rad      [баланс потужності Шоклі — Квайссера]
```

де:
- `P_el = V_mp · J_mp` — максимальна корисна електрична потужність;
- `P_therm = q · ∫[0..λ_cut] Φ_λ(λ) · (E_photon(λ) - E_g) dλ` — потужність втрат на термалізацію надпорогових фотонів;
- `P_transp = ∫[λ_cut..∞] E_λ(λ) dλ` — потужність втрат від підпорогової прозорості;
- `P_rad` — потужність неминучої термодинамічної радіаційної рекомбінації носіїв (випромінювання фотоелемента як чорного тіла з температурою 300 K).

Застосування спектра AM1.5G замість абсолютно чорного тіла з температурою 6000 K зміщує оптимальну ширину забороненої зони від `1.40 еВ` до `1.34 еВ` через наявність атмосферних провалів поглинання водяної пари та кисню, піднімаючи теоретичний ККД до **33.7%**.
