# 🧮 Математичний вивід спектральної чутливості та квантового виходу

Ця вставка містить суворий математичний вивід зв'язку між квантовою ефективністю фотодетектора, енергією квантів світла, коефіцієнтом поглинання напівпровідника, інтерференційним просвітленням поверхні та диференціальними рівняннями переносу носіїв заряду.

### 1. Від оптичної потужності до фотоструму

Нехай на фоточутливу площадку детектора падає монохроматичне світло з довжиною хвилі `λ` та оптичною потужністю `P_in` (у ватах, Дж/с). Енергія одного фотона `E_γ` визначається формулою Планка:

```
E_γ = h · ν = (h · c) / λ
```

де:
- `h = 6.6261 × 10⁻³⁴ Дж·с` — стала Планка,
- `c = 2.9979 × 10⁸ м/с` — швидкість світла у вакуумі,
- `ν` — частота світла,
- `λ` — довжина хвилі у вакуумі.

Кількість фотонів `N_γ`, що падають на детектор за 1 секунду (потік фотонів):

```
N_γ = P_in / E_γ
    = (P_in · λ) / (h · c)
```

Якщо зовнішня квантова ефективність детектора дорівнює `η` (тобто `η_ext`), то кількість знайдених і зібраних електричних носіїв `N_e` за секунду становить:

```
N_e = η · N_γ
    = (η · P_in · λ) / (h · c)
```

Кожен зібраний носій несе елементарний заряд `e = 1.6022 × 10⁻¹⁹ Кл`. Вихідний фотострум `I_ph` (в амперах):

```
I_ph = N_e · e
     = (e · η · P_in · λ) / (h · c)
```

### 2. Формула спектральної чутливості R_λ

Спектральна чутливість `R_λ` (*responsivity*) визначається як відношення згенерованого фотоструму `I_ph` до вхідної оптичної потужності `P_in`:

```
R_λ = I_ph / P_in
```

Підставивши вираз для `I_ph`, отримуємо фундаментальне співвідношення:

```
R_λ = (e · η · λ) / (h · c)
```

Підставимо числові значення фундаментальних фізичних констант:

```
(h · c) / e = (6.6261 × 10⁻³⁴ · 2.9979 × 10⁸) / (1.6022 × 10⁻¹⁹)
            ≈ 1.2398 × 10⁻⁶ В·м
            ≈ 1.240 В·мкм
```

Якщо довжину хвилі `λ` виразити в мікрометрах (мкм), отримаємо зручну інженерну формулу для розрахунку чутливості у А/Вт:

```
R_λ ≈ (η · λ_мкм) / 1.240    [у А/Вт]
```

З цієї формули видно ключовий факт: навіть якщо квантова ефективність `η` стабільна й не залежить від довжини хвилі у певному діапазоні, спектральна чутливість `R_λ` **зростає лінійно** зі збільшенням довжини хвилі `λ`. Причина полягає в тому, що фотони більшої довжини хвилі мають меншу енергію `E_γ = hc/λ`, тому 1 Ват потужності на довжині хвилі 800 нм містить удвічі більше фотонів, ніж 1 Ват на довжині хвилі 400 нм.

### 3. Оптичне відбиття та антивідбивальне покриття

При падінні світла перпендикулярно на межу між середовищем з показником заломлення `n₀` (повітря, `n₀ = 1.0`) та напівпровідником з показником `n_s` (для кремнію `n_s ≈ 3.8`), коефіцієнт відбиття за Френелем дорівнює:

```
R₀ = ((n_s − n₀) / (n_s + n₀))²
```

Для незахищеної поверхні кремнію це дає `R₀ ≈ ((3.8 − 1) / (3.8 + 1))² ≈ 0.34` (тобто 34% оптичних втрат).

Для зменшення відбиття на поверхню наносять тонку плівку диелектрика (наприклад, нітриду кремнію Si₃N₄ або оксиду титану TiO₂) з показником заломлення `n_arc` та товщиною `d_arc`. Ідеальний показник заломлення плівки дорівнює геометричному середньому:

```
n_arc = √(n₀ · n_s)
```

Для кремнію в повітрі `n_arc = √(1.0 · 3.8) ≈ 1.95`.

Товщина плівки вибирається так, щоб хвилі, відбиті від верхньої та нижньої меж плівки, перебували у протифазі для розрахункової довжини хвилі `λ₀`:

```
d_arc = λ₀ / (4 · n_arc)
```

За цих умов спектральний коефіцієнт відбиття з урахуванням інтерференції описується формулою:

```
R(λ) = (r₁² + r₂² + 2·r₁·r₂·cos 2δ) / (1 + r₁²·r₂² + 2·r₁·r₂·cos 2δ)
```

де `r₁ = (n_arc − n₀)/(n_arc + n₀)`, `r₂ = (n_s − n_arc)/(n_s + n_arc)`, а фазове набігання `δ = (2·π·n_arc·d_arc) / λ`. На розрахунковій довжині хвилі `λ = λ₀` маємо `2δ = π`, отже `cos 2δ = −1`, і відбиття `R(λ₀)` падає майже до нуля.

### 4. Диференціальні рівняння переносу носіїв і розрахунок IQE

Розглянемо одновимірну структуру напівпровідникового p-n фотодіода. Нехай світло падає на поверхню `x = 0`. Інтенсивність випромінювання на глибині `x` описується законом Бугера — Ламберта — Бера:

```
I(x) = I₀ · (1 − R) · e⁻ᵃˣ
```

Швидкість генерації пар електрон-дірка `G(x)` на глибині `x`:

```
G(x) = −dI/dx = α · I₀ · (1 − R) · e⁻ᵃˣ
```

Структура фотодіода складається з трьох областей:
1. Нейтральна p-область від `x = 0` до `x = x_j` (глибина залягання p-n переходу).
2. Область збіднення (виснажений шар) від `x = x_j` до `x = x_j + W`.
3. Нейтральна n-база від `x = x_j + W` до `x = H` (задня поверхня кристала).

#### А. Збір носіїв із нейтральної p-області
Стаціонарне диференціальне рівняння дифузії некорисних електронів у p-області має вигляд:

```
D_n · (d² Δn / dx²) − (Δn / τ_n) + G(x) = 0
```

де `D_n` — коефіцієнт дифузії електронів, `τ_n` — їхній час життя, а `L_n = √(D_n · τ_n)` — дифузійна довжина.

Граничні умови враховують поверхневу рекомбінацію на `x = 0` зі швидкістю `S_p` та повне висмоктування носіїв полем p-n переходу на `x = x_j` (`Δn(x_j) = 0`):

```
D_n · (d Δn / dx)|ₓ₌₀ = S_p · Δn(0)
```

Загальний розв'язок неоднорідного диференціального рівняння складається із суми загального розв'язку однорідного рівняння та часткового розв'язку:

```
Δn(x) = A · cosh(x / L_n) + B · sinh(x / L_n) − [ (α · I₀ · (1 − R) · τ_n) / (α² · L_n² − 1) ] · e⁻ᵃˣ
```

Константи `A` та `B` знаходяться з граничних умов на поверхні `x = 0` та на межі виснаженої зони `x = x_j`. Точний дифузійний струм електронів на межі p-n переходу `J_n = e · D_n · (d Δn / dx)|ₓ₌ₓⱼ` визначає внесок p-шару у квантову ефективність:

```
η_p = [ (α · L_n) / (α² · L_n² − 1) ] · [ ( (S_n + α·L_n) − e⁻ᵃ ˣʲ · (S_n · cosh(x_j/L_n) + sinh(x_j/L_n)) ) / ( S_n · sinh(x_j/L_n) + cosh(x_j/L_n) ) − α · L_n · e⁻ᵃ ˣʲ ]
```

де `S_n = (S_p · L_n) / D_n` — безрозмірна швидкість поверхневої рекомбінації.

У наближенні тонкого p-шару (`x_j ≪ L_n`) та низької поверхневої рекомбінації цей вираз спрощується до інженерної форми:

```
η_p ≈ [ (α · L_n) / (α² · L_n² − 1) ] · [ α · L_n − e⁻ᵃ ˣʲ ]
```

#### Б. Збір носіїв з області збіднення W
В області збіднення існує сильне внутрішнє електричне поле `E ~ 10⁴–10⁵ В/см`. Час дрейфу носіїв скрізь шар `W` становить `t_drift = W / v_sat ≈ 10⁻¹¹ с`, що на три порядки менше за час життя носіїв `τ ≈ 10⁻⁸ с`.

Тому рекомбінація в i-шарі відсутня, і кожен фотон, поглинутий у зоні збіднення, дає внесок у фотострум із 100% імовірністю:

```
η_dep = e⁻ᵃ ˣʲ · (1 − e⁻ᵃ ᵂ)
```

#### В. Збір носіїв з нейтральної n-бази
Аналогічний розв'язок дифузійного рівняння для дірок у n-базі з товщиною `H − (x_j + W) ≫ L_p` дає внесок:

```
η_n = [ (α · L_p) / (α² · L_p² − 1) ] · e⁻ᵃ ⁽ˣʲ ⁺ ᵂ⁾
```

#### Г. Загальна внутрішня квантова ефективність IQE
Сума трьох компонент визначає повну внутрішню квантову ефективність детектора:

```
IQE(λ) = η_p(λ) + η_dep(λ) + η_n(λ)
```

Якщо шар p-типу дуже тонкий (`x_j → 0`), а дифузійна довжина в базі велика (`L_p ≫ 1/α`), формула спрощується до класичного виразу:

```
IQE(λ) ≈ 1 − [ e⁻ᵃ ᵂ / (1 + α · L_p) ]
```

### 5. Довжина хвилі відсічки λ_c

Міжзонне поглинання можливе лише тоді, коли енергія фотона `E_γ` більша або дорівнює ширині забороненої зони напівпровідника `E_g`:

```
E_γ = (h · c) / λ ≥ E_g
```

Найбільша довжина хвилі, за якої фотон ще здатен створити пару електрон-дірка, називається **довжиною хвилі відсічки** (`λ_c`):

```
λ_c = (h · c) / E_g ≈ 1.240 / E_g(еВ)    [у мкм]
```

Для кремнію (`E_g = 1.12 еВ` при 300 K):

```
λ_c(Si) = 1.240 / 1.12 ≈ 1.107 мкм = 1107 нм
```

Для арсеніду галію-індію In₀.₅₃Ga₀.₄₇As (`E_g = 0.75 еВ`):

```
λ_c(InGaAs) = 1.240 / 0.75 ≈ 1.653 мкм = 1653 нм
```

На довжинах хвиль `λ > λ_c` коефіцієнт поглинання `α(λ)` паде до нуля, напівпровідник стає повністю прозорим, і квантова ефективність `η` опускається до нуля.

### Розрахункові приклади

#### Приклад 1. Кремнієвий PIN-фотодіод (850 нм)
Обчислимо фотострум кремнієвого PIN-фотодіода під дією лазерного випромінювання потужністю `P_in = 2.5 мВт` на довжині хвилі `λ = 850 нм` (0.85 мкм). Припустимо, що завдяки антивідбивальному покриттю та сильному полю у виснаженій зоні зовнішня квантова ефективність дорівнює `η = 82%` (0.82).

1. Обчислимо спектральну чутливість `R_λ`:

```
R_λ = (η · λ_мкм) / 1.240
    = (0.82 · 0.85) / 1.240      [підстановка η = 0.82 та λ = 0.85 мкм]
    = 0.697 / 1.240              [обчислення добутку у чисельнику]
    ≈ 0.562 А/Вт                 [ділення: результат спектральної чутливості]
```

2. Знайдемо вихідний фотострум `I_ph`:

```
I_ph = R_λ · P_in
     = 0.562 А/Вт · 2.5 × 10⁻³ Вт    [підстановка значень чутливості та потужності]
     = 1.405 × 10⁻³ А                 [обчислення добутку]
     = 1.405 мА                       [переведення в міліампери]
```

#### Приклад 2. InGaAs фотодіод оптичного зв'язку (1550 нм)
Обчислимо чутливість телекомунікаційного фотодіода на основі InGaAs для довжини хвилі `λ = 1550 нм` (1.55 мкм). Для високоякісного фотодіода з антивідбивальним покриттям `EQE = 92%` (0.92).

1. Обчислимо спектральну чутливість `R_λ`:

```
R_λ = (η · λ_мкм) / 1.240
    = (0.92 · 1.55) / 1.240      [підстановка η = 0.92 та λ = 1.55 мкм]
    = 1.426 / 1.240              [обчислення добутку]
    ≈ 1.150 А/Вт                 [результат чутливості для телеком-діапазону]
```

Оскільки 1550 нм фотон має меншу енергію, ніж 850 нм фотон, чутливість InGaAs фотодіода перевищує 1.0 А/Вт, незважаючи на те, що кожні 100 фотонів створюють лише 92 електрони.

#### Приклад 3. Обчислення оптичного відбиття з просвітлювальним шаром
Розрахуємо товщину плівки Si₃N₄ (`n_arc = 2.0`) на поверхні кремнію (`n_s = 3.8`) для мінімізації відбиття на довжині хвилі `λ₀ = 633 нм` (He-Ne лазер).

1. Обчислимо необхідну товщину плівки `d_arc`:

```
d_arc = λ₀ / (4 · n_arc)
      = 633 нм / (4 · 2.0)      [підстановка розрахункової довжини хвилі та показника]
      = 633 / 8.0               [обчислення частки]
      = 79.1 нм                 [оптимальна товщина просвітлювального шару]
```

На довжині хвилі 633 нм інтерференція променів дає мінімум відбиття `R < 1%`, що піднімає зовнішню квантову ефективність `EQE` майже до значення `IQE`.
