# 🧮 Математична теорія та спектральний розклад Оселедця

Математичний апарат теорії показників Ляпунова спирається на лінеаризацію нелінійного фазового потоку в дотичному просторі та аналіз границь мультиплікативних операторів еволюції. Тут подано строге виведення мультиплікативної теореми Оселедця, розкладу QR у дотичному просторі, інваріантності спектра відносно координатних перетворень, а також математичне виведення фрактальної розмірності Каплана–Йорке та КС-ентропії Песіна.

## Лінеаризація фазового потоку та варіаційне рівняння

Розглянемо нелінійну автономну динамічну систему, яка задається системою звичайних диференціальних рівнянь у n-вимірному фазовому просторі ℝⁿ:

```
dx / dt = f(x)
```

де `x(t) ∈ ℝⁿ` — вектор стану системи в момент часу `t`, а `f: ℝⁿ → ℝⁿ` — неперервно диференційовне векторне поле класу C¹.

Нехай `x(t)` — опорна (базова) траєкторія у фазовому просторі з початковою умовою `x(0) = x₀`. Розглянемо збурену траєкторію `x̃(t) = x(t) + δx(t)`, де `δx(t) ∈ ℝⁿ` — нескінченно малий вектор збурення. Розкладаючи векторне поле `f(x + δx)` у ряд Тейлора в околиці опорної точки `x(t)` і обмежуючись членами першого порядку малості, отримуємо лінеаризоване варіаційне рівняння:

```
d(δx) / dt = J(x(t)) · δx(t)
```

Матриця `J(x) ∈ ℝⁿˣⁿ` є матрицею Якобі (якобіаном) векторного поля `f(x)`, елементи якої визначені як часткові похідні:

```
J_ij(x) = ∂f_i(x) / ∂x_j
```

Оскільки якобіан `J(x(t))` залежить від часу через опорну траєкторію `x(t)`, розв'язок варіаційного рівняння виражається через фундаментальну матрицю розв'язків (або оператор еволюції в дотичному просторі) `Y(t) ∈ ℝⁿˣⁿ`:

```
δx(t) = Y(t) · δx(0)
```

Фундаментальна матриця `Y(t)` задовольняє матричне диференціальне рівняння з початковою умовою, заданою одиничною матрицею `I`:

```
dY(t) / dt = J(x(t)) · Y(t),     Y(0) = I
```

## Старший показник Ляпунова

Старший (максимальний) показник Ляпунова `λ_max` характеризує середню швидкість експоненціальної розбіжності двох нескінченно близьких траєкторій вздовж напрямку найбільшого нестійкого розтягнення. Він визначається як границя:

```
λ_max = lim_{t → ∞} (1 / t) · ln( ||δx(t)|| / ||δx(0)|| )
      = lim_{t → ∞} (1 / t) · ln( ||Y(t) · δx(0)|| / ||δx(0)|| )
```

де `||·||` позначено стандартну евклідову норму у фазовому просторі ℝⁿ.

Якщо `λ_max > 0`, мала початкова помилка `||δx(0)||` зростає за експоненціальним законом `||δx(t)|| ≈ ||δx(0)|| · exp(λ_max · t)`. Це означає наявність чутливості до початкових умов та детермінованого хаосу.

## Мультиплікативна ергодична теорема Оселедця

Для опису повної деформації фазового елемента необхідно розглянути еволюцію не одного вектора `δx`, а повного n-вимірного інфінітезимального об'єму. Нехай `μ` — ергодична ймовірнісна міра, інваріантна відносно фазового потоку.

Мультиплікативна ергодична теорема Оселедця (1968) стверджує: для майже всіх початкових умов `x₀` за мірою `μ` існує границя симетричної додатно визначеної матриці:

```
Λ_x = lim_{t → ∞} [ Y(t)^T · Y(t) ]^{1 / (2t)}
```

Оскільки матриця `Λ_x` є самоспряженою, вона має `n` дійсних додатних власних значень `μ₁ ≥ μ₂ ≥ ... ≥ μ♁ > 0`.

Показники Ляпунова `λ_i` визначаються як натуральні логарифми власних значень матриці Оселедця `Λ_x`:

```
λ_i = ln(μ_i) = lim_{t → ∞} (1 / (2t)) · ln( eigenvalue_i [ Y(t)^T · Y(t) ] )
```

Упорядкований набір з n чисел `λ₁ ≥ λ₂ ≥ ... ≥ λ♁` називається покроковим спектром показників Ляпунова.

Теорема Оселедця гарантує існування ієрархії підпросторів дотичного простору `T_x ℝⁿ`:

```
{0} = V₀ ⊂ V₁ ⊂ V₂ ⊂ ... ⊂ V_p = T_x ℝⁿ
```

таких, що для будь-якого вектора `v ∈ V_k \ V_{k-1}` швидкість зростання норми прямо прямує до відповідного показника Ляпунова:

```
lim_{t → ∞} (1 / t) · ln( ||Y(t) · v|| ) = λ_k
```

## Інваріантність спектра відносно диффеоморфізмів

Важливою математичною властивістю показників Ляпунова є їхня інваріантність відносно нелінійних гладких замін координат у фазовому просторі.

Нехай `y = g(x)` — взаємно однозначне диференційовне перетворення координат (диффеоморфізм), де `g: ℝⁿ → ℝⁿ`. Матриця Якобі цього перетворення позначується як `D_g(x) = ∂g / ∂x`. Оскільки `g` — диффеоморфізм, матриці `D_g(x)` та `D_g⁻¹(y)` є обмеженими і неособливими у фазовій області.

Вектор збурення в нових координатах `δy(t)` пов'язаний зі збуренням у старих координатах `δx(t)` співвідношенням:

```
δy(t) = D_g(x(t)) · δx(t)
```

Виразимо норму збурення `||δy(t)||` через `δx(t)`:

```
||δy(t)|| = ||D_g(x(t)) · Y(t) · δx(0)||
```

Використовуючи властивості норми матриць, отримуємо двосторонню оцінку:

```
||D_g(x(t))⁻¹||⁻¹ · ||Y(t) · δx(0)|| ≤ ||δy(t)|| ≤ ||D_g(x(t))|| · ||Y(t) · δx(0)||
```

Візьмемо логарифм і поділимо на `t` при `t → ∞`:

```
(1/t) ln(||D_g⁻¹||⁻¹) + (1/t) ln(||Y(t) δx(0)||) ≤ (1/t) ln(||δy(t)||) ≤ (1/t) ln(||D_g||) + (1/t) ln(||Y(t) δx(0)||)
```

Оскільки за припущенням фазовий атрактор є обмеженою множиною, а `g` — диффеоморфізмом, супремум норм `||D_g(x)||` та `||D_g(x)⁻¹||` є скінченним числом `C > 0`. Отже:

```
lim_{t → ∞} (1 / t) · ln(C) = 0
```

Звідси випливає рівність границь:

```
lim_{t → ∞} (1 / t) · ln(||δy(t)||) = lim_{t → ∞} (1 / t) · ln(||δx(t)||) = λ_i
```

Це доводить, що спектр показників Ляпунова є фундаментальним інваріантом динамічної системи і не залежить від вибору системи координат.

## QR-факторизація дотичного простору

Для практичного чисельного розрахунку спектра Ляпунова фундаментальну матрицю розв'язків `Y(t)` розкладають за допомогою QR-факторизації через рівні часові інтервали `Δt`.

Нехай `t_k = k · Δt`. Запишемо еволюцію фундаментальної матриці від моменту `t_k` до `t_{k+1}`:

```
Y(t_{k+1}) = Φ(t_{k+1}, t_k) · Y(t_k)
```

де `Φ(t_{k+1}, t_k)` — локальний оператор еволюції, отриманий інтегруванням варіаційного рівняння `dY/dt = J(x(t)) Y` на інтервалі `[t_k, t_{k+1}]`.

Застосуємо QR-розклад до фундаментальної матриці на кожному кроці:

```
Y(t_k) = Q_k · R_k
```

де `Q_k ∈ ℝⁿˣⁿ` — ортогональна матриця (`Q_k^T · Q_k = I`), вектори-стовпці якої утворюють ортонормований базис дотичного простору, а `R_k ∈ ℝⁿˣⁿ` — верхня трикутна матриця з додатними діагональними елементами `(R_k)_{ii} > 0`.

На наступному часовому кроці `t_{k+1}` спочатку інтегруємо ортонормований базис `Q_k`:

```
Z_{k+1} = Φ(t_{k+1}, t_k) · Q_k
```

Потім здійснюємо QR-розклад матриці `Z_{k+1}`:

```
Z_{k+1} = Q_{k+1} · R̂_{k+1}
```

Підставляючи це у вираз для `Y(t_{k+1})`, отримуємо:

```
Y(t_{k+1}) = Z_{k+1} · R_k = Q_{k+1} · R̂_{k+1} · R_k
```

Таким чином, за `K` кроків часового інтегрування матриця `R(t_K)` дорівнює добутку верхніх трикутних матриць `R̂_k`. Оскільки діагональний елемент добутку верхніх трикутних матриць дорівнює добутку діагональних елементів, коефіцієнт розтягнення вздовж i-го ортогонального напрямку за час `T = K · Δt` дорівнює:

```
(R(t_K))_{ii} = ∏_{k=1}^K (R̂_k)_{ii}
```

Взявши логарифм та поділивши на загальний час `T = K · Δt`, отримуємо точну формулу для обчислення i-го показника Ляпунова:

```
λ_i = lim_{K → ∞} (1 / (K · Δt)) · ∑_{k=1}^K ln( (R̂_k)_{ii} )
```

Ця формула лежить в основі алгоритмів Бенеттіна та Вольфа, оскільки діагональні елементи `(R̂_k)_{ii}` обчислюються безпосередньо через норми векторів під час ортогоналізації Грама-Шмідта.

## Фрактальна розмірність Каплана–Йорке та ентропія Песіна

Спектр показників Ляпунова зв'язує геометрію атрактора з його інформаційними властивостями.

### Розмірність Каплана–Йорке (Ляпунова)

Джеймс Каплан та Джеймс Йорке (James Kaplan, James Yorke, 1979) висунули гіпотезу, що фрактальна розмірність дивного атрактора `D_L` може бути виражена безпосередньо через його спектр Ляпунова.

Упорядкуємо показники Ляпунова за спаданням: `λ₁ ≥ λ₂ ≥ ... ≥ λ♁`. Знайдено таке найбільше ціле число `k`, що сума перших `k` показників є невід'ємною:

```
∑_{i=1}^k λ_i ≥ 0     і     ∑_{i=1}^{k+1} λ_i < 0
```

Тоді розмірність Ляпунова (або розмірність Каплана–Йорке) `D_L` визначається формулою:

```
D_L = k + ( ∑_{i=1}^k λ_i ) / |λ_{k+1}|
```

Геометричний зміст формули: дробова частина `(∑_{i=1}^k λ_i) / |λ_{k+1}|` показує, яка саме частка (k+1)-го стискального виміру потрібна для точної компенсації розтягнення фазового об'єму у перших `k` вимірах.

### Теорема (Рівність) Песіна та КС-ентропія

Швидкість втрати інформації про стан динамічної системи описується метричною ентропією Колмогорова–Синая (KS-ентропією) `h_KS`. Яків Песін (1977) довів, що для C²-диффеоморфізмів з інваріантною абсолютно неперервною мірою KS-ентропія дорівнює сумі всіх додатних показників Ляпунова:

```
h_KS = ∑_{λ_i > 0} λ_i
```

Песінівська ентропія `h_KS` вимірюється в натах (або бітах при використанні логарифма за основою 2) за одиницю часу і характеризує швидкість, з якою спостерігач втрачає здатність прогнозувати майбутній стан системи при наявності скінченної точності вимірювань.
