# 📋 Інтерфейс та довідник елементарних потенціальних елементів

Цей довідник містить аналітичний інтерфейс, формули поля швидкостей, потенціалу, функції течії та просторові сингулярності шести базових елементів потенціальної гідродинаміки.

## Загальний аналітичний специфікатор потенціального елемента

У потенціальній гідродинаміці кожен елементарний розв'язок рівняння Лапласа виступає самостійним математичним об'єктом із чітко визначеним аналітичним контрактом. Завдяки лінійності рівняння Лапласа будь-який складний двовимірний або тривимірний плин є лінійною комбінацією цих фундаментальних елементів.

Кожен потенціальний елемент реалізує єдиний обчислювальний контракт:
- **Параметри положення:** `(x_0, y_0)` — координати геометричного центру або точкової сингулярності.
- **Вхідні величини:** просторові координати точки спостереження `(x, y)` або полярні координати `(r, θ)`.
- **Вихідні величини:** потенціал швидкості `ϕ`, функція течії `ψ`, компоненти швидкості `(u_x, u_y)` або `(u_r, u_θ)`, комплексний потенціал `W(z)` та комплексна швидкість `dW/dz`.

Низькорівневий аналітичний контракт шести основних елементів зведено у порівняльну таблицю:

| Потенціальний елемент | Вхідні параметри | Фізичний зміст | Особливості / Сингулярності |
| :--- | :--- | :--- | :--- |
| **1. Однорідний потік** | `U_∞` (швидкість), `α` (кут) | Паралельний потік на нескінченності | Всюди гладкий, немає сингулярностей |
| **2. Точкове джерело / сток** | `Q` (витрата, `Q > 0` джерело, `Q < 0` сток) | Радіальне випромінювання / поглинання | Точкова сингулярність `r = 0` (`v -> ∞`) |
| **3. Точковий вихор** | `Γ` (циркуляція, `Γ > 0` проти годинника) | Циркуляційне обертання навколо точки | Точкова сингулярність `r = 0` (`v -> ∞`) |
| **4. Диполь (дуплет)** | `μ` (момент), `α_d` (орієнтація) | Граничне поєднання джерела та стоку | Сингулярність 2-го порядку у `r = 0` |
| **5. Напівтіло Ранкіна** | `U_∞`, `Q` | Потік навколо тупого носа напівнескінченного тіла | Точка гальмування `x_s = -Q / (2πU_∞)` |
| **6. Джерельна / вихрова панель** | `q_j` або `γ_j`, вузли `(x_1, y_1), (x_2, y_2)` | Неперервний шар сингулярностей вздовж відрізка | Перепад нормальної/тангенціальної швидкості |

## 1. Однорідний (рівномірний) потік

Однорідний потік описує поступальний плин зі сталою за величиною та напрямком швидкістю `U_∞`, спрямованою під кутом `α` до осі `x`. Він є основою для моделювання набігаючого потоку в аеродинамічних трубах та у вільному політі літальних апаратів.

### Аналітичний контракт та специфікація параметрів:
- **Швидкість потоку на нескінченності (`U_∞`):** вимірюється в м/с, `U_∞ > 0`.
- **Кут атаки (`α`):** кут нахилу потоку до осі `x`, вимірюється у радіанах або градусах, `α ∈ [-π, π]`.
- **Область визначення:** увесь фізичний простір `ℝ²` без жодних сингулярностей чи крайових обмежень.

### Формули у декартових координатах:
```
u_x = U_∞ · cos α
u_y = U_∞ · sin α

ϕ(x, y) = U_∞ · (x · cos α + y · sin α)
ψ(x, y) = U_∞ · (y · cos α - x · sin α)
```

### Комплексний потенціал та комплексна швидкість:
```
W(z) = U_∞ · e^(-i · α) · z
dW / dz = U_∞ · e^(-i · α)
```

Лінії течії `ψ = const` являють собою сімейство паралельних прямих ліній, нахилених під кутом `α` до осі `x`. Ізопотенціальні лінії `ϕ = const` утворюють ортогональне сімейство паралельних прямих, перпендикулярних до вектора швидкості.

## 2. Точкове джерело та сток

Точкове джерело генерує радіально-симетричний плин, випромінюючи об'ємну витрату `Q` в усіх напрямках рівномірно від полярного центру `(x_0, y_0)`. Для джерела `Q > 0` (випромінювання), для стоку `Q < 0` (поглинання).

### Аналітичний контракт та специфікація параметрів:
- **Координати сингулярності `(x_0, y_0)`:** полярний центр розташування елемента.
- **Інтенсивність (потужність) `Q`:** об'ємна витрата рідини на одиницю глибини, вимірюється в м²/с.
- **Область визначення:** `ℝ² \ {(x_0, y_0)}`. У точці `r = 0` існує логарифмічна сингулярність.

### Формули у полярних координатах відносно центру `(x_0, y_0)`:
Нехай `r = √((x - x_0)² + (y - y_0)²)` — відстань від точки спостереження до джерела, а `θ = arctan2(y - y_0, x - x_0)` — полярний кут.

```
u_r = Q / (2π · r)
u_θ = 0

ϕ(r, θ) = (Q / (2π)) · ln r
ψ(r, θ) = (Q / (2π)) · θ
```

### Формули у декартових координатах:
```
u_x = (Q / (2π)) · (x - x_0) / ((x - x_0)² + (y - y_0)²)
u_y = (Q / (2π)) · (y - y_0) / ((x - x_0)² + (y - y_0)²)
```

### Комплексний потенціал:
```
W(z) = (Q / (2π)) · ln(z - z_0)
dW / dz = Q / (2π · (z - z_0))
```

Лінії течії `ψ = const` являють собою пучок радіальних променів, що виходять із точки `(x_0, y_0)`. Ізопотенціальні лінії `ϕ = const` є концентричними колами з центром у джерелі.

## 3. Точковий (потенціальний) вихор

Точковий вихор створює чисто циркуляційне обертальне поле швидкостей навколо точки `(x_0, y_0)` з постійною циркуляцією `Γ`. Він є базовим елементом для створення аеродинамічної підйомної сили на крилах.

### Аналітичний контракт та специфікація параметрів:
- **Координати вихрового ядра `(x_0, y_0)`:** положення точкового вихру.
- **Циркуляція `Γ`:** інтенсивність вихру, вимірюється в м²/с. Для `Γ > 0` обертання відбувається проти годинникової стрілки.
- **Область визначення:** `ℝ² \ {(x_0, y_0)}`. У точці `r = 0` існує сингулярність нескінченної тангенціальної швидкості.

### Формули у полярних координатах:
```
u_r = 0
u_θ = Γ / (2π · r)

ϕ(r, θ) =  (Γ / (2π)) · θ
ψ(r, θ) = -(Γ / (2π)) · ln r
```

### Формули у декартових координатах:
```
u_x = -(Γ / (2π)) · (y - y_0) / ((x - x_0)² + (y - y_0)²)
u_y =  (Γ / (2π)) · (x - x_0) / ((x - x_0)² + (y - y_0)²)
```

### Комплексний потенціал:
```
W(z) = -i · (Γ / (2π)) · ln(z - z_0)
dW / dz = -i · Γ / (2π · (z - z_0))
```

Для запобігання чисельного вибуху швидкості біля ядра в алгоритмах обчислювальної гідродинаміки зазвичай вводять радіус зрізання `r_core` (модель Ранкіна або Ватсона-Лемба), всередині якого тангенціальна швидкість прямує до нуля за лінійним законом.

## 4. Диполь (дуплет)

Диполь утворюється граничним зближенням джерела та стоку з моментом `μ = (Q · Δx) / π`. Він використовується для моделювання непроникаючих твердих тіл (циліндрів, еліпсів, сфер) у набігаючому потоці.

### Аналітичний контракт та специфікація параметрів:
- **Координати диполя `(x_0, y_0)`:** центр розташування елемента.
- **Момент диполя `μ`:** вимірюється в м³/с.
- **Орієнтація диполя `α_d`:** кут напрямку вісі диполя. Для `α_d = 0` вісь диполя спрямована уздовж осі `x`.

### Формули у полярних координатах:
```
u_r = -(μ · cos θ) / r²
u_θ = -(μ · sin θ) / r²

ϕ(r, θ) =  (μ · cos θ) / r
ψ(r, θ) = -(μ · sin θ) / r
```

### Формули у декартових координатах:
```
u_x = -μ · ((x - x_0)² - (y - y_0)²) / ((x - x_0)² + (y - y_0)²)²
u_y = -2μ · (x - x_0) · (y - y_0)   / ((x - x_0)² + (y - y_0)²)²
```

### Комплексний потенціал:
```
W(z) = μ / (z - z_0)
dW / dz = -μ / (z - z_0)²
```

Лінії течії диполя `ψ = const` являють собою сімейство дотичних кіл, які проходять через початок координат і мають центри на осі `y`.

## 5. Напівтіло Ранкіна (суперпозиція однорідного потоку та джерела)

Поєднання однорідного потоку `U_∞` вздовж осі `x` та точкового джерела `Q` у початку координат утворює обтікання напівнескінченного тупого тіла Ранкіна.

### Специфікація комбінованого елемента:
- **Вхідні параметри:** `U_∞` (набігаючий потік), `Q` (інтенсивність джерела в початку координат).
- **Область застосування:** розрахунок носових частин трубок Піто, дирижаблів та підводних човнів.

### Формули потенціалу та функції течії:
```
ϕ(r, θ) = U_∞ · r · cos θ + (Q / (2π)) · ln r
ψ(r, θ) = U_∞ · r · sin θ + (Q / (2π)) · θ
```

### Політичні параметри напівтіла:
- **Переднє гальмування (Stagnation point):** `(x_s, y_s) = (-Q / (2π · U_∞), 0)`.
- **Роздільна лінія течії (Роздільний контур тіла):** `ψ = Q / 2`.
- **Напівтовщина тіла на нескінченності (`x -> +∞`):** `y_max = Q / (2 · U_∞)`.

## 6. Джерельна та вихрова панель (граничний елемент)

Розглянемо панель завдовжки `L`, що проганяється від вузла `A(x_1, y_1)` до `B(x_2, y_2)` під кутом `θ_p` з постійною інтенсивністю джерел `q` на одиницю довжини. Панелі слугують елементарними цеглинами чисельних методів розрахунку крил.

### Аналітичний контракт панельного елемента:
- **Геометрія панелі:** початковий вузол `(x_1, y_1)`, кінцевий вузол `(x_2, y_2)`, довжина `L = √((x_2 - x_1)² + (y_2 - y_1)²)`.
- **Інтенсивність:** питома інтенсивність джерел `q` (м/с) або вихрості `γ` (м/с).

### Локальна система координат панелі `(s, n)`:
Введемо локальну координату `s ∈ [0, L]` вздовж панелі та нормаль `n`. Для будь-якої точки спостереження `P(x, y)` визначимо радіус-вектори `r_1`, `r_2` до кінців панелі та кути `β_1`, `β_2`:

```
ϕ_panel(P) = (q / (2π)) · ∫[0->L] ln √( (s - s_p)² + n_p² ) ds
ψ_panel(P) = (q / (2π)) · ∫[0->L] arctan2(n_p, s_p - s) ds
```

### Розриви швидкості при переході крізь панель:
- **Джерельна панель:** нормальна швидкість зазнає розриву `u_n^+ - u_n^- = q`, тангенціальна швидкість є неперервною.
- **Вихрова панель:** тангенціальна швидкість зазнає розриву `u_t^+ - u_t^- = γ`, нормальна швидкість є неперервною.

## Таблиця правила суперпозиції елементів

Принцип суперпозиції дозволяє будувати довільні течії шляхом сумування потенціалів окремих елементів. Нижче наведено зведену таблицю комбінацій та їхніх фізичних наслідків:

| Цільовий гідродинамічний плин | Необхідна комбінація елементів | Отримані геометричні та фізичні наслідки |
| :--- | :--- | :--- |
| **Гладкий циліндр без циркуляції** | Рівномірний потік `U_∞` + Диполь `μ = U_∞ · R²` | Повний розв'язок з опіром `D = 0` та підйомом `L = 0` |
| **Обертальний циліндр (Ефект Магнуса)** | Рівномірний потік `U_∞` + Диполь `μ` + Вихор `Γ` | Виникнення підйомної сили `L' = ρ · U_∞ · Γ` |
| **Аеродинамічний профіль Жуковського** | Однорідний потік + Перетворення `z = ζ + a²/ζ` + Умова Кутти | Підйомна сила `Γ = 4πUR sin(α+β)` при скінченній швидкості |
| **Овоїд Ранкіна (замкнене тіло)** | Рівномірний потік `U_∞` + Джерело `+Q` у `(-a,0)` + Сток `-Q` у `(+a,0)` | Симетричне замкнене тіло овальної форми у потоці |
| **Довільний 2D профіль** | Система `N` джерельних та вихрових панелей `q_j, γ` | Чисельний розподіл тиску `C_p` та підйомної сили |

## Практична інструкція використання елементів у CFD розв'язувачах

Під час побудови чисельних кодів потенціальної теорії рекомендується дотримуватися таких практичних правил:

1. **Єдині орт-вектори нормалей та дотичних:** для кожної панелі `j` орт-дотична обчислюється як `t_j = (cos θ_j, sin θ_j)`, а зовнішня нормаль як `n_j = (-sin θ_j, cos θ_j)`.
2. **Перевірка знака циркуляції:** за загальноприйнятою математичною угодою додатна циркуляція `Γ > 0` обертає потік проти годинникової стрілки. За аеродинамічною угодою для створення підйомної сили на крилі при додатному куті атаки циркуляція спрямовується за годинниковою стрілкою.
3. **Чисельне регулювання сингулярностей:** при наближенні точки спостереження до точкового вихру чи джерела на відстань `r < ε` (де `ε ~ 10⁻⁶ · L`), прямий розрахунок швидкості замінюється на граничне значення або регуляризовану модель вихрової плями (модель Ватсона).
