# ⚙️ Від сирого відліку гіроскопа до кутової швидкості й кута

[Вібраційний гіроскоп](book:physics/coriolis-effect/comp-mems-gyro.md) віддає на шину не «градуси за секунду», а **сире 16-бітне число** на кожну вісь — знакове ціле, пропорційне кутовій швидкості. Між цим числом і корисним значенням стоять три речі: масштаб, зсув нуля і шум. Розберімо їх у коді, доведемо потік до накопиченого кута — і побачимо, чому цей кут неминуче спливає. Мова тут — C: це читання регістрів на мікроконтролері, домен, де інша мова була б удаванням.

## Сире зчитування й масштаб

Масштаб (чутливість, LSB на °/с) береться з даташита обраного давача й залежить від вибраного діапазону — того, що задають у [регістрі конфігурації](book:physics/coriolis-effect/api-mems-gyro.md):

```c
#include <stdint.h>

// --- залежить від конкретної мікросхеми: реалізуй під свою шину (I²C/SPI) ---
// має повернути знакове 16-бітне значення осі: raw = (hi << 8) | lo
extern int16_t gyro_read_raw(int axis);
extern uint32_t millis(void);            // системний час, мс

#define AXIS_Z   2
#define G_SENS   16.4f   // LSB на (°/с) — приклад для діапазону ±2000 °/с

float gyro_rate_dps(float bias) {
    int16_t raw = gyro_read_raw(AXIS_Z);
    return (raw - bias) / G_SENS;        // (LSB − LSB) / (LSB/(°/с)) = °/с
}
```

## Зсув нуля: калібровка тільки в спокої

Навіть нерухомий давач видає не строго нуль, а маленьке ненульове число (zero-rate output, ZRO) — і воно різне для кожного екземпляра. Найпростіша калібровка: усереднити багато відліків, поки прилад **гарантовано нерухомий**:

```c
float gyro_calibrate_zero(int n) {
    long acc = 0;
    for (int i = 0; i < n; i++) acc += gyro_read_raw(AXIS_Z);
    return (float)acc / n;               // середнє сире значення = зсув нуля
}
```

Одразу пастка: якщо давач ворухнувся під час калібровки, «нуль» увібрає справжнє обертання, і давач потім брехатиме на цю величину. Калібрувати — тільки в спокої.

## Згладжування й інтегрування

Далі сирий потік треба **згладити** й **проінтегрувати**. Згладжування — фільтр нижніх частот; найдешевший — експоненційне усереднення (одне множення на відлік). Інтегрування дає кут:

```c
static float rate_f = 0.0f;   // згладжена кутова швидкість, °/с
static float angle  = 0.0f;   // накопичений кут, °
static uint32_t t_prev = 0;
static float bias_z = 0.0f;

void gyro_init(void) {
    bias_z = gyro_calibrate_zero(512);   // у спокої!
    t_prev = millis();
}

void gyro_update(void) {
    float rate = gyro_rate_dps(bias_z);

    // ФНЧ 1-го порядку: менше alpha — сильніше згладжування, але більша затримка
    const float alpha = 0.15f;
    rate_f += alpha * (rate - rate_f);

    // інтегрування: кут += швидкість × крок часу
    uint32_t now = millis();
    float dt = (now - t_prev) * 1e-3f;   // мс → с
    t_prev = now;
    angle += rate_f * dt;                // ° += (°/с)·с
}
```

Тут ховається найважливіша правда про гіроскопи. Кут `angle` **спливає**. Зсув нуля ніколи не віднімається ідеально, а до того ж повільно дрейфує; ще й випадковий шум інтегрується у блукання. Тому голий інтеграл гіроскопа вірний лише на коротких часах, а далі кут відпливає від істини. Лікують це не кращим фільтром, а **злиттям** з абсолютним орієнтиром: акселерометр дає нахил, магнітометр — курс, і ними раз за разом підправляють дрейф гіроскопа [комплементарним фільтром](book:algorithms/complementary-filter) чи фільтром Калмана. Гіроскоп добрий на коротку дистанцію (швидкий, тихий, не боїться прискорень), абсолютні давачі — на довгу; разом вони покривають слабкості одне одного.

## Скільки коштує дрейф: порахуймо

Абстрактне «спливає» варто відчути в числах.

**Задача.** Зсув нуля дрейфує на 20 °/год, кутовий випадковий блукач (ARW) — 0.3 °/√год. Яку похибку в куті дасть кожен через 1 с і через 100 с вільного інтегрування?

```
дрейф зсуву (систематичний, росте лінійно з часом):
   20 °/год = 20 / 3600 ≈ 0.0056 °/с
   за 1 с   → 0.0056 · 1   ≈ 0.006 °
   за 100 с → 0.0056 · 100 ≈ 0.56 °

ARW (випадкове блукання, росте як √час):
   за 1 с   → 0.3 · √(1/3600)   = 0.3 · 0.0167 ≈ 0.005 °
   за 100 с → 0.3 · √(100/3600) = 0.3 · 0.167  ≈ 0.05 °
```

**Висновок.** У першу секунду обидві похибки одного порядку — тут головний ворог випадковий шум. Але систематичний дрейф росте лінійно, а шумовий — лише як корінь, тож уже за десяток секунд зсув переганяє шум і далі домінує безроздільно: на ста секундах він у десяток разів більший. Ось чому «скільки секунд можна вірити голому гіроскопу» визначає не шум, а **стабільність зсуву** — і чому без злиття з іншими давачами інерціальна навігація неможлива.
