# 📋 Специфікація та програмований контракт метрологічного стандарту напруги на сходинках Шапіро

Первинні державні та міжнародні еталони одиниці електричної напруги (Вольта) спираються на квантовані сходинки Шапіро в масивах надпровідних джозефсонівських переходів. Даний довідник містить технічну специфікацію, фундаментальні фізичні константи, описи архітектури метрологічних чипів JVS, PJVS та ACJVS, аналіз джерел невизначеності вимірювань, а також строго типізований програмний контракт для автоматизованого керування вимірювальними комплексами мовами C та C++.

### 1. Метрологічне підґрунтя та фундаментальні константи

До реформи Міжнародної системи одиниць SI 2019 року еталон напруги спирався на константу Джозефсона `K_J-90 = 483597.9 ГГц/В`, ухвалену за домовленістю. Після 20 травня 2019 року значення сталої Планка `h` та заряд електрона `e` зафіксовано як точні числові константи. Це зробило відношення `K_J = 2e / h` точним абсолютним числом без будь-якої вимірювальної похибки чи невизначеності.

Точні значення базових фізичних констант:

```
h = 6.62607015 e-34 J·s          [стала Планка, точно]
e = 1.602176634 e-19 C           [заряд електрона, точно]
K_J = 2e / h = 483597.8484... GHz/V  [константа Джозефсона, точно]
```

Одиничний квант напруги на один перехід при частоті НВЧ випромінювання `f_rf` обчислюється як:

```
V_quantum = f_rf / K_J = (h · f_rf) / (2e)
```

Для стандартної метрологічної частоти НВЧ поля `f_rf = 70 ГГц` одиничний квант становить приблизно `144.697 мікровольта` (`144.697 μV`). Для частоти `10 ГГц` квант дорівнює `20.678 мікровольта` (`20.678 μV`).

### 2. Порівняльний аналіз архітектур джозефсонівських чипів

Залежно від фізичної структури тунельних контактів та методу струмового зсуву, у метрологічній практиці застосовують три покоління джозефсонівських стандартизованих чипів.

#### Класичний масив (Conventional JVS)
Класичний стандарт напруги спирається на масиви переходів типу надпровідник-ізолятор-надпровідник (SIS) з високим опором у нормальному стані та малим згасанням. Переходи працюють у гістерезисному режимі й формально не потребують додаткового струму зсуву для перебування на сходинці (ефект нульового струмового зсуву Кауца, англ. *zero-bias steps*). Під дією НВЧ поля близько 70 ГГц перехід вискакує на однакову за величиною сходинку. Головне обмеження класичних JVS — чутливість до зовнішніх імпульсних завад: шум може перекинути частину переходів на інший номер сходинки, через що вимірювання доводиться зупиняти та повторювати знову.

#### Програмований масив (Programmable PJVS)
Програмований еталон напруги використовує негістерезисні переходи типу надпровідник-нормальний метал-надпровідник (SNS) або надпровідник-ізолятор-нормальний метал-надпровідник (SNIS). Переходи об'єднано у сегменти, кількість контактив у яких зважена за бінарним законом (`1, 2, 4, 8, 16, 32, ..., 2^k`). Кожен сегмент забезпечений окремими струмовими вводами. Подаючи постійний струм зсуву певного знака, кожен сегмент можна переводити у стан `n = +1`, `n = 0` або `n = -1`. Це дозволяє синтезувати будь-яку точну напругу від `-10 В` до `+10 В` із кроком в один квант за кілька мікросекунд.

#### Змінно-струмовий імпульсний еталон (ACJVS / Pulse-Driven JVS)
У сучасних системах ACJVS масив контактив обпромінюється не неперервною синусоїдою, а послідовністю високоефективних НВЧ імпульсів, згенерованих оптичними детекторами під дією дельта-сигма модульованого лазерного променя. Це дозволяє створювати еталонні змінні напруги (синусоїдальної чи довільної форми) для калібрування прецизійних вольтметрів змінного струму.

| Специфікаційний параметр | Класичний JVS | Програмований PJVS | Динамічний ACJVS |
| :--- | :--- | :--- | :--- |
| **Матеріал тунельного бар'єра** | Оксид алюмінію AlOx (SIS) | Сплав Nb-Si або MoSi (SNS) | Силіцид молібдену MoSi (SNS) |
| **Кількість контактив у чипі** | 15 000 – 20 000 | 81 920 – 300 000 | 100 000 – 500 000 |
| **Робоча температура** | 4.2 K (рідкий гелій) | 4.2 K (гелій або закритий кріокулер) | 4.2 K (закритий кріокулер) |
| **Максимальна напруга** | 10.0 V | 10.0 V / 20.0 V | 1.0 V (амплітудне) |
| **Частота НВЧ випромінювання** | 70 – 75 GHz | 18 – 20 GHz або 70 GHz | 10 – 20 GHz |
| **Ширина струмової сходинки** | 20 – 50 μA | 1.0 – 4.0 mA | 1.0 – 2.0 mA |
| **Швидкість перемикання** | Ручне або > 10 с | < 10 мікросекунд | Неперервна форма |

### 3. Математичний контракт квантування та розрахунок напруги

Квантована напруга `V_out`, що генерується програмованим масивом PJVS, обчислюється як сума внесків усіх `M` бінарних сегментів. Для кожного сегмента `k` призначено кількість переходів `N_k` та керуючий стан `b_k ∈ {-1, 0, +1}`:

```
V_out = (f_rf / K_J) · Σ [k=0..M-1] ( b_k · N_k · n_k )
```

де `n_k` — номер сходинки Шапіро (зазвичай `n_k = 1` для основної сходинки).

Для захисту від термо-ЕРС у з'єднувальних провідниках метрологічні вимірювання завжди виконують за двополярною схемою (метод перемикання полярності, англ. *polarity reversal method*). Обчислюється середня величина напруги між позитивним `V(+)` та негативним `V(-)` станами:

```
V_calibrated = ( V(+) - V(-) ) / 2
V_offset_thermal = ( V(+) + V(-) ) / 2
```

Це дозволяє повністю компенсувати паразитна дрейфуючу термо-ЕРС вимірювального кола (яка може досягати кількох сотень нановольт) без утрати точності квантового стандарту.

### 5. Кріогенні вимоги та тракт узгодження НВЧ потужності

Для забезпечення надійного фазового захоплення на всіх тисячах переходів масиву необхідна висока однорідність розподілу НВЧ потужності вздовж чипа.

#### Кріогенне обладнання
1. **Кріостат рідинного гелію.** Занурення зонда з чипом у рідкий гелій при температурі `T = 4.2 K` (або `T = 3.8 K` під зниженим тиском).
2. **Затворені кріокулери безрідкого типу (Dry Cryocoolers).** Використання двоступеневих трубок пульсаційного охолодження (Pulse Tube Cryocoolers) для підтримання температури 4 K без витрат рідкого гелію.
3. **Екранування.** Тришаровий мю-металевий (µ-metal) макроскопічний екран для придушення геомагнітного поля Землі та зовнішніх низькочастотних завад до рівня менше `1 нТл`.

#### Хвилеводна передача НВЧ хвилі
НВЧ сигнал від атомно-синхронізованого синтезатора подається у кріостат через тонкостінні хвилеводи з визильберу чи нержавіючої сталі зі срібним покриттям для зменшення теплоприпливу. На чипі НВЧ потужність ділиться між паралельними копланарними мікросмужковими лініями, у які послідовно вбудовано джозефсонівські переходи.

### 6. Аналіз бюджета невизначеності та джерела похибок

Під час метрологічної атестації вимірювальних систем калібрування проводиться аналіз стандартної невизначеності за методикою GUM (англ. *Guide to the Expression of Uncertainty in Measurement*).

Основними джерелами похибок у квантовому стандарту є:
1. **Невизначеність опорного частотного генератора (Type A/B).** Синхронізація НВЧ синтезатора з підключеним гелієвим мазером або цезієвим атомним стандартом частоти дає відносну невизначеність не гірше `1 e-12`.
2. **Паразитна термо-ЕРС (Type B).** Виникає на температурному градієнті у кріостаті від 4.2 K до 293 K у вимірювальних провідниках із високочистої міді. Усувається двополярним перемиканням струмів зсуву.
3. **Витоки струмів у ізоляції кріогенного джгута (Type B).** Опір ізоляції між вимірювальними колами та землею повинен перевищувати `10¹2 Ом`, щоб не спотворювати вимірюваний струм.
4. **Скінченний нахил сходинки Шапіро `dV/dI` (Type B).** У якісно виготовлених надпровідних мікросхемах опір на плато сходинки дорівнює нулю з точністю до `10⁻¹³ Ом`. Будь-яка поява нахилу свідчить про наявність локальних руйнувань надпровідності або недостатню потужність НВЧ поля.

Нижче наведено таблицю бюджета невизначеності для калібрування напруги 10 Вольт:

| Джерело невизначеності | Метод оцінки | Стандартна невизначеність | Відносна невизначеність `u_r` |
| :--- | :--- | :--- | :--- |
| **Частота НВЧ гетеродина (Атомний стандарт)** | Type A | 0.05 нВ | `5.0 e-12` |
| **Залишкова компенсація термо-ЕРС** | Type B | 0.80 нВ | `8.0 e-11` |
| **Струм витоку в кабелях кріостата** | Type B | 0.20 нВ | `2.0 e-11` |
| **Шум підсилювача та нуль-детектора** | Type A | 0.35 нВ | `3.5 e-11` |
| **Нерівномірність НВЧ потужності вздовж чипа** | Type B | 0.10 нВ | `1.0 e-11` |
| **Підсумкова розширена невизначеність (`k=2`)** | **Combined** | **1.80 нВ** | **`1.8 e-10`** |

Завдяки квантовому захопленню фази, сумарна розширена невизначеність 10-вольтового еталона не перевищує 1.8 нановольта (`1.8 nV`), що робить сходинки Шапіро незамінним стандартом вищої точності в сучасній фізиці.
