# 🧮 Математична теорія відображення Пуанкаре: секущі поверхні, лінеаризація та множники Флоке

Ця вставка містить строге математичне обґрунтування концепції відображення Пуанкаре, виведення рівнянь лінеаризації потоку, зв'язок із теорією Флоке для періодичних розв'язків, фрактальну вимірність, інваріантні міри, метод Мельникова та аналітичні критерії стійкості й біфуркацій.

---

### Формальні означення фазового потоку та секущої поверхні

Нехай динамічна система задана у вимірі `N` на гладкому орієнтованому багатовидовому просторі `M ⊆ Rⁿ` за допомогою автономного векторного поля `f: M → Rⁿ` класу `Cʳ` (де `r ≥ 1`):

```
d(x)/dt = f(x)
```

Завдяки теоремі Коші-Пікара про існування та єдиність розв'язку диференціального рівняння, векторне поле `f` генерує однопараметричну групу гладких перетворень фазового простору — фазовий потік `φᵗ: M → M`, який задовольняє фундаментальним груповим властивостям:

```
φ⁰(x) = x                         [тотожне перетворення]
φᵗ⁺ˢ(x) = φᵗ( φˢ(x) )            [групова властивість аддитивності за часом]
d(φᵗ(x))/dt ∣ₜ₌₀ = f(x)           [векторне поле як швидкості потоку]
```

Нехай `Σ ⊂ M` є гладким підмноговидом корозмірності 1 (тобто розмірності `dim(Σ) = N - 1`), що задається незамкненим нульовим рівнем деякої скалярної гладкої функції `g: M → R`:

```
Σ = { x ∈ M ∣ g(x) = 0 }
```

Гладість функції `g` означає, що її градієнт `∇g(x) = (∂g/∂x₁, ..., ∂g/∂xₙ)` є ненульовим вектором у кожній точці `x ∈ Σ`.

#### Умова трансверсальності

Поверхня `Σ` називається трансверсальною секущою поверхнею Пуанкаре для потоку `φᵗ`, якщо векторне поле `f(x)` у кожній точці `x ∈ Σ` утворює ненульовий кут із дотичним простором `TₓΣ`. 

Математично це виражається умовою ненульового скалярного добутку між градієнтом `∇g(x)` (який орієнтований уздовж нормалі до `Σ`) та вектором швидкості `f(x)`:

```
∇g(x) · f(x) ≠ 0   для всіх x ∈ Σ
```

Для однозначності визначення напрямку перетину ми розглядаємо трансверсальну секущу поверхню з одностороннім напрямком проходження `Σ⁺`:

```
Σ⁺ = { x ∈ M ∣ g(x) = 0,  ∇g(x) · f(x) > 0 }
```

### Оператор першого повернення та час Пуанкаре

Нехай точка `x` належить секущій поверхні `Σ⁺`. Розглянемо множину додатних моментів часу `t > 0`, у які фазова траєкторія `φᵗ(x)` знову пробиває поверхню `Σ⁺`:

```
T(x) = { t > 0 ∣ φᵗ(x) ∈ Σ⁺ }
```

Якщо множина `T(x)` не порожня, ми визначаємо функцію часу першого повернення `τ: Σ⁺ → R⁺` як точну нижню межу додатних моментів перетину:

```
τ(x) = inf { t > 0 ∣ φᵗ(x) ∈ Σ⁺ }
```

Величина `τ(x)` показує найменший додатний час, необхідний траєкторії, яка стартувала з точки `x ∈ Σ⁺`, щоб здійснити повне повернення на поверхню `Σ⁺`.

Відображення Пуанкаре (або оператор першого повернення) `P: Σ⁺ → Σ⁺` визначається як дійсний стан системи у момент часу першого повернення:

```
P(x) = φᵀ⁽ˣ⁾(x)
```

#### Доведення дифреоморфності відображення Пуанкаре

Щоб довести, що відображення Пуанкаре `P` є гладким дифреоморфізмом у деякій області `U ⊂ Σ⁺`, застосуємо теорему про неявну функцію до скалярного рівняння перетину:

```
F(x, t) = g( φᵗ(x) ) = 0
```

Припустимо, що при `t = τ(x₀)` система повертається у точку `P(x₀) ∈ Σ⁺`. Обчислимо часткову похідну функції `F(x, t)` за часовою змінною `t`:

```
∂F(x, t)/∂t = ∇g( φᵗ(x) ) · d(φᵗ(x))/dt
            = ∇g( φᵗ(x) ) · f( φᵗ(x) )
```

У момент повернення `t = τ(x₀)` маємо `φᵀ⁽ˣ⁰⁾(x₀) = P(x₀) ∈ Σ⁺`. Враховуючи умову трансверсальності, отримуємо:

```
∂F(x₀, τ(x₀))/∂t = ∇g( P(x₀) ) · f( P(x₀) ) > 0
```

Оскільки часткова похідна за часом є ненульовою, згідно з теоремою про неявну функцію в околі точки `x₀` існує єдина гладка функція часу повернення `τ(x)` класу `Cʳ`, яка задовольняє тотожність `g( φᵀ⁽ˣ⁾(x) ) ≡ 0`.

Отже, оскільки фазовий потік `φᵗ(x)` та функція часу `τ(x)` є гладкими функціями, композиційне відображення `P(x) = φᵀ⁽ˣ⁾(x)` є гладким дифреоморфізмом, що зберігає топологічну вимірність та гладкість фазового многовиду.

### Лінеаризація відображення Пуанкаре та рівняння у варіаціях

Розглянемо періодичну орбіту (граничний цикл) `γ` з періодом `T`, яка перетинає поверхню `Σ⁺` у нерухомій точці `x*`:

```
P(x*) = x*,   де τ(x*) = T
```

Щоб дослідити стійкість цієї нерухомої точки, розкладемо відображення Пуанкаре в ряд Тейлора в околі точки `x*`:

```
P(x* + δx) = P(x*) + DP(x*) · δx + O(∥δx∥²)
           = x* + DP(x*) · δx + O(∥δx∥²)
```

де `DP(x*)` — це `(N-1) × (N-1)` матриця Якобі відображення Пуанкаре на секущій поверхні `Σ⁺`.

#### Рівняння у варіаціях та матриця Монодромії

Еволюція малого відхилення `Y(t) = ∂φᵗ(x)/∂x` уздовж періодичної орбіти описується матричним лінійним диференціальним рівнянням у варіаціях з періодичними коефіцієнтами:

```
dY/dt = A(t) · Y(t),   де A(t) = Df( φᵗ(x*) )
Y(0) = I
```

де `Df(x)` — це `N × N` матриця Якобі векторного поля `f(x)`, а `I` — одинична матриця розміру `N × N`.

Значення фундаментальної матриці розв'язків у кінці періоду `t = T` називається матрицею монодромії `M`:

```
M = Y(T) = exp( ∫₀ᵀ A(t) dt )   [у разі комутативних матриць]
```

Власні значення матриці монодромії `M` називаються множниками Флоке (Floquet Multipliers) системи `ρ₁, ρ₂, ..., ρₙ`.

#### Зв'язок між множниками Флоке та матрицею Якобі DP(x*)

Оскільки початкова система є автономною, один із множників Флоке завжди строго дорівнює одиниці:

```
ρₙ = 1
```

Цей одиничний множник відповідає відхиленню вздовж напрямку самого фазового вектора швидкості `f(x*)` (зсув по фазі уздовж орбіти).

Решта `N - 1` множників Флоке `ρ₁, ρ₂, ..., ρₙ₋₁` строго збігаються з власними значеннями `μ₁, μ₂, ..., μₙ₋₁` лінеаризованої матриці відображення Пуанкаре `DP(x*)`:

```
Spec( DP(x*) ) = { ρ₁, ρ₂, ..., ρₙ₋₁ }
```

#### Математичні критерії стійкості нерухомої точки

Стійкість нерухомої точки `x*` відображення Пуанкаре (а отже, і стійкість відповідного граничного циклу `γ`) повністю визначається модулями її `N - 1` множників Флоке `μᵢ`:

```
1. Асимптотична стійкість:  ∣μᵢ∣ < 1  для всіх i = 1, ..., N - 1
   [усі фазові відхилення на секущій поверхні експоненційно згасають: ∥Pⁿ(δx)∥ → 0]

2. Нестійкість (сідло або джерело):  існує k таке, що ∣μⲕ∣ > 1
   [принаймні один напрямок відхилення експоненційно зростає при ітеруванні]

3. Критичний біфуркаційний стан:  max ∣μᵢ∣ = 1
   [система перебуває на межі втрати стійкості]
```

### Метод Мельникова: аналітичний критерій гомоклінічного розщеплення

Для аналітичного доведення виникнення хаосу в околі гомоклінічних петель секущої поверхні застосовується теорія збурень у формі методу Мельникова (Melnikov Method). Цей підхід дозволяє явно обчислити відстань між розщепленими многовидами без чисельного інтегрування.

Розглянемо малі збурення плоскої гамільтонової системи під дією періодичної сили:

```
dx/dt = ∂H₀/∂y + ε · g₁(x, y, t)
dy/dt = -∂H₀/∂x + ε · g₂(x, y, t)
```

де `ε << 1` — малий параметр збурення, а `(x₀(t), y₀(t))` — незбурена гомоклінічна петля сепаратриси, яка виходить із сідлової точки `(x*, y*)` та повертається в неї при `t → ±∞`.

#### Функція Мельникова (Melnikov Function)

При додаванні періодичного збурення `ε > 0` стійкий `Wˢ` та нестійкий `Wᵘ` інваріантні многовиди сідлової точки розщеплюються у фазовому просторі. Відстань між ними `d(t₀)` у перерізі Пуанкаре обчислюється у першому порядку теорії збурень за допомогою скалярної функції Мельникова `M(t₀)`:

```
d(t₀) = ε · M(t₀) / ∥f₀(x₀(0))∥ + O(ε²)
```

де інтеграл Мельникова визначається виразом:

```
M(t₀) = ∫₋∞⁺∞ f₀(x₀(t), y₀(t)) ∧ g(x₀(t), y₀(t), t + t₀) dt
```

знак `∧` означає кососкалярний косинусний добуток `u ∧ v = u₁·v₂ - u₂·v₁`.

#### Теорема Мельникова про хаос

Якщо функція Мельникова `M(t₀)` має прості нулі (тобто існує момент `t₀*` такий, що `M(t₀*) = 0` та `dM/dt₀ ∣ₜ₀* ≠ 0`), це є строгим математичним доказом того, що стійкий `Wˢ` та нестійкий `Wᵘ` многовиди трансверсально перетинаються у перерізі Пуанкаре.

Згідно з теоремою Смейла, це трансверсальне перетинне розщеплення спричиняє виникнення гомоклінічної сітки та підкови Смейла, що математично гарантує наявність детермінованого хаосу у системі.

### Симплектична геометрія гамільтонових відображень Пуанкаре

Для гамільтонових автономних систем із `n` ступенями вільностей (розмірність фазового простору `N = 2n`) канонічні координати мають вигляд `x = (q₁, ..., qₙ, p₁, ..., pₙ)`. Динаміка визначається функцією Гамільтона `H(q, p)` через канонічні рівняння Гамільтона:

```
dqᵢ/dt = ∂H/∂pᵢ,   dpᵢ/dt = -∂H/∂qᵢ
```

Сукупність канонічних рівнянь записується у компактній матричній формі через канонічну симплектичну структуру `J`:

```
dx/dt = J · ∇H(x),   де J = [  0   Iₙ ]
                             [ -Iₙ  0  ]
```

де `Iₙ` — одинична матриця розмірності `n × n`.

#### Збереження симплектичної форми та інтеграла Пуанкаре-Картана

Нехай `Σ_E = { x ∈ M ∣ H(x) = E, g(x) = 0 }` — секуща поверхня фіксованої енергії `E` розмірності `2n - 2`.

Відображення Пуанкаре `P: Σ_E → Σ_E` зберігає канонічну симплектичну форму `ω = ∑ᵢ=₁ⁿ⁻¹ dqᵢ ∧ dpᵢ`. Це означає, що матриця Якобі відображення `DP(x)` у кожній точці є симплектичною матрицею:

```
(DP(x))ᵀ · J · (DP(x)) = J
```

З симплектичної умови випливають важливі математичні наслідки для властивостей гамільтонова відображення Пуанкаре:
1. **Збереження фазового об'єму (Теорема Ліувілля):** Визначник матриці Якобі відображення строго дорівнює одиниці `det(DP(x)) = 1`.
2. **Симетрія множників Флоке:** Якщо `μ` є власним значенням `DP(x*)`, то `1/μ`, `μ̄` та `1/μ̄` також є власними значеннями. Власні значення завжди виникають інваріантними четверками на комплексній площині `{μ, 1/μ, μ̄, 1/μ̄}` чи парами на дійсній осі `{μ, 1/μ}`.

Це математично пояснює відсутність атракторів у консервативних системах: нерухома точка відображення Пуанкаре не може бути асимптотично стійким фокусом (`∣μ∣ < 1`), оскільки разом із кожним стискаючим напрямком обов'язково існує спряжений розтягуючий напрямок (`1/∣μ∣ > 1`).

### Інваріантні міри та оператор Фробеніуса-Перрона

При тривалому хаотичному ітеруванні відображення Пуанкаре `x[k+1] = P(x[k])` дискретні точки заповнюють атрактор відповідно до деякого просторового розподілу густини ймовірності.

#### Поняття інваріантної міри

Міра Бореля `μ_inv` на секущій поверхні `Σ` називається інваріантною відносно відображення Пуанкаре `P`, якщо для будь-якої вимірної множини `B ⊂ Σ` виконується умова:

```
μ_inv( P⁻¹(B) ) = μ_inv( B )
```

де `P⁻¹(B)` — повний прообраз множини `B`.

Якщо міра `μ_inv` є абсолютно неперервною відносно стандартної міри Лебега, вона може бути виражена через гладку густину ймовірності `ρ(x)`:

```
dμ_inv(x) = ρ(x) dx
```

#### Оператор Фробеніуса-Перрона (Frobenius-Perron Operator)

Еволюція густини ймовірності `ρ[k](x)` при одному кроці відображення Пуанкаре описується лінійним оператором Фробеніуса-Перрона `P_FP`:

```
ρ[k+1](x) = P_FP [ ρ[k] ] (x) = ∑_{y ∈ P⁻¹(x)} ρ[k](y) / ∣ det( DP(y) ) ∣
```

Стаціонарна густина ймовірності хаотичного атрактора `ρ*(x)` є власною функцією оператора Фробеніуса-Перрона, що відповідає власному значенню 1:

```
P_FP [ ρ* ] = ρ*
```

#### Ергодична теорема Біргофа для відображень Пуанкаре

Якщо інваріантна міра `μ_inv` є ергодичною, згідно з теоремою Біргофа для будь-якої інтегровної фізичної величини `A(x)` часове середнє вздовж дискретної траєкторії майже для всіх початкових точок `x₀` дорівнює просторовому середньому за інваріантною мірою:

```
lim_{n → ∞} (1/n) · ∑_{k=0}^{n-1} A( Pᵏ(x₀) ) = ∫_Σ A(x) dμ_inv(x)
```

Цей результат є математичним містком між чисельним модулюванням послідовних перетинів Пуанкаре та статистичним обчисленням термодинамічних середніх характеристик системи.

### Показники Ляпунова та фрактальна розмірність відображення

Для дискретного відображення Пуанкаре `x[k+1] = P(x[k])` швидкість експоненційного розходження початково близьких траєкторій вимірюється спектром дискретних показників Ляпунова `λ₁ ≥ λ₂ ≥ ... ≥ λₙ₋₁`.

#### Дискретні показники Ляпунова

Нехай `v` — початковий вектор відхилення у дотичному просторі `TₓΣ`. Показник Ляпунова `λ(v)` визначається границею:

```
λ(v) = lim_{n → ∞} (1/n) · ln( ∥ DPⁿ(x₀) · v ∥ )
```

де `DPⁿ(x₀) = DP(xₙ₋₁) · DP(xₙ₋₂) · ... · DP(x₀)` — матриця Якобі `n`-ї ітерації відображення Пуанкаре, що обчислюється за правилом ланцюгового дифференцирування.

Існує прямий зв'язок між показниками Ляпунова безперервного потоку `λᵢ^flow` та показниками Ляпунова відображення Пуанкаре `λᵢ^map`:

```
λᵢ^map = λᵢ^flow · T_avg   для всіх i = 1, ..., N - 1
```

де `T_avg` — середній час першого повернення Пуанкаре.

#### Фрактальна розмірність за Капланом-Йорком (Kaplan-Yorke Dimension)

Якщо відображення Пуанкаре генерує хаотичний атрактор із впорядкованим спектром показників Ляпунова `λ₁ > 0 > λ₂`, його фрактальна розмірність `D_KY` (розмірність Ляпунова) обчислюється за формулою Каплана-Йорка:

```
D_KY = k + ( ∑ᵢ₌₁ᵏ λᵢ ) / ∣λ[k+1]∣
```

де `k` — найбільше ціле число, для якого сума перших `k` показників є невід'ємною: `∑ᵢ₌₁ᵏ λᵢ ≥ 0`.

Для двовимірного відображення Пуанкаре з показниками `λ₁ > 0` та `λ₂ < 0` (при цьому `λ₁ + λ₂ < 0` через дисипативне стиснення площі) формула Каплана-Йорка спрощується до:

```
D_KY = 1 + λ₁ / ∣λ₂∣
```

Оскільки `0 < λ₁ < ∣λ₂∣`, розмірність перерізу `D_KY` є дробовим числом на інтервалі `(1, 2)`. Додаючи одиницю за рахунок неперервного часового руху потоку, отримуємо повну розмірність хаотичного атрактора у безперервному просторі: `D_attractor = D_KY + 1 ∈ (2, 3)`.

### Класифікація кодомен-1 біфуркацій у перерізі Пуанкаре

Зміна керуючого параметра `λ` динамічної системи викликає дрейф множників Флоке `μᵢ(λ)` на комплексній площині. Момент, коли один чи кілька множників перетинають одиничне коло `∣μ∣ = 1`, відповідає втраті стійкості.

```
                  УВАГА: СХЕМА ПЕРЕТИНУ ОДИНИЧНОГО КОЛА МНОЖНИКАМИ ФЛОКЕ
                  
                         Im(μ)
                           ▲
                           │    .---.  Neimark-Sacker (μ = e±ⁱⱯ)
                           │  .'  *  '.
                           │ /         \
       Flip (μ = -1)  ◄────┼─*────+────*─►  Saddle-Node (μ = +1)
      [Подвоєння періоду]  │ \         /    [Касання / зрив]
                           │  '.  *  .'
                           │    '---'
                           └───────────► Re(μ)
```

#### 1. Біфуркація подвоєння періоду (Flip / Period-Doubling Bifurcation)

Відбувається при проходженні множника Флоке через точку `μ = -1`:

```
DP(x*) · v = -1 · v
```

Для аналізу цієї біфуркації побудуємо скалярне скалювання відображення Пуанкаре в околі нерухомої точки `x* = 0` за допомогою методу центрального многовиду:

```
xₖ₊₁ = P(xₖ, λ) = -xₖ - c·xₖ³ - a·λ·xₖ + O(xₖ⁴)
```

Застосовуючи другу ітерацію відображення `P²(x) = P( P(x) )`, отримуємо:

```
P²(xₖ) = -(-xₖ - c·xₖ³ - a·λ·xₖ) - c·(-xₖ)³ - a·λ·(-xₖ) + ...
       = xₖ + 2·a·λ·xₖ + 2·c·xₖ³ + O(xₖ⁴)
```

При значенні параметра `λ > 0` розв'язок `x* = 0` втрачає стійкість, і виникають дві нові нерухомі точки 2-го порядку:

```
x₁*,₂ = ± √( -a·λ / c )
```

Ці дві точки переставляються відображенням `P(x₁*) = x₂*` та `P(x₂*) = x₁*`, що відповідає появі стійкого граничного циклу подвійного періоду `2T`.

#### 2. Сідло-вузлова біфуркація (Saddle-Node / Tangent Bifurcation)

Відбувається при проходженні множника Флоке через точку `μ = +1`:

```
DP(x*) · v = +1 · v
```

Нормальна форма відображення Пуанкаре у цьому випадку має вигляд:

```
xₖ₊₁ = P(xₖ, λ) = λ + xₖ - b·xₖ² + O(xₖ³)
```

Рівняння для нерухомих точок `P(x*) = x*` дає:

```
λ - b·(x*)² = 0   ⇒   x₁*,₂ = ± √( λ / b )
```

При `λ < 0` нерухомих точок не існує. При `λ = 0` виникає одна кратна нерухома точка, яка при `λ > 0` розщеплюється на дві: одну стійку `x₁* = +√(λ/b)` та одну нестійку сідлову `x₂* = -√(λ/b)`.

#### 3. Біфуркація Неймарка-Сакера (Neimark-Sacker Bifurcation)

Відбувається при перетині одиничного кола парою комплексно-спряжених множників:

```
μ₁,₂ = (1 + α·λ) · exp( ± i·θ₀ ),   де 0 < θ₀ < π
```

У двовимірних полярних координатах `(r, ϕ)` на секущій поверхні нормальна форма відображення записується у вигляді:

```
rₖ₊₁ = (1 + α·λ)·rₖ - d·rₖ³ + O(rₖ⁵)
ϕₖ₊₁ = ϕₖ + θ₀ + b·rₖ² + O(rₖ⁴)
```

При `λ > 0` нерухома точка `r* = 0` втрачає стійкість, і народжується стійке інваріантне коло радіуса `r* = √( α·λ / d )`. У неперервному просторі це відповідає переходу від граничного циклу до двовимірного тора `T²` (народження квазіперіодичних коливань).

### Обчислювальний приклад 1: аналітичний розрахунок для планарної системи

Розглянемо двовимірну нелінійну систему у полярних координатах `(r, θ)`:

```
dr/dt = r · (1 - r²)
dθ/dt = 1
```

Побудуємо відображення Пуанкаре для цієї системи.

#### Крок 1: Вибір секущої поверхні
Виберемо як секущу поверхню промінь `Σ = { (r, θ) ∣ θ = 0 }`.

Умова трансверсальності перевіряється скалярним добутком із нормаллю:

```
∇g · f = (0, 1) · (r·(1 - r²), 1)ᵀ = 1 > 0   [умова виконується тотожно]
```

#### Крок 2: Точний розв'язок рівнянь
Друге рівняння `dθ/dt = 1` інтегрується безпосередньо: `θ(t) = t`. 

Отже, час першого повернення на промінь `θ = 2π` є постійним для всіх точок і дорівнює:

```
τ(r₀) = 2π
```

Перше диференціальне рівняння `dr/dt = r · (1 - r²)` розв'язується шляхом розділення змінних:

```
dr / (r · (1 - r²)) = dt

[Розклад на прості дроби]
( 1/r + r/(1 - r²) ) dr = dt

[Інтегрування від r₀ до r(t)]
ln(r / r₀) - (1/2) · ln( ∣1 - r²∣ / ∣1 - r₀²∣ ) = t
```

Підносячи до квадрата й розв'язуючи відносно `r²(t)`, отримуємо точну траєкторію радіуса:

```
r²(t) = r₀² / ( r₀² + (1 - r₀²) · exp(-2t) )
```

#### Крок 3: Побудова відображення Пуанкаре
Підставляючи час повернення `t = τ = 2π`, отримуємо явний вигляд відображення Пуанкаре `P: r₀ ↦ r₁`:

```
P(r₀) = r₀ / √( r₀² + (1 - r₀²) · exp(-4π) )
```

#### Крок 4: Знаходження нерухомих точок та аналіз стійкості
Нерухома точка шукається з умови `P(r*) = r*`:

```
r* = r* / √( (r*)² + (1 - (r*)²) · exp(-4π) )

(r*)² + (1 - (r*)²) · exp(-4π) = 1  ⇒  (1 - (r*)²) · (exp(-4π) - 1) = 0
```

Оскільки `exp(-4π) ≠ 1`, єдиним додатним розв'язком є:

```
r* = 1
```

Це відповідає граничному циклу одиничного радіуса.

Обчислимо похідну відображення Пуанкаре `P'(r)` у нерухомій точці `r* = 1`:

```
P'(r*) = d/dr₀ [ r₀ · ( r₀² + (1 - r₀²) · exp(-4π) )⁻¹ᐟ² ] ∣ᵣ₀₌₁
       = exp(-4π)
```

Оскільки `0 < P'(1) = exp(-4π) ≈ 2.87 × 10⁻⁶ < 1`, множник Флоке за модулем строго менший за одиницю. 

Це строго доводить, що граничний цикл `r* = 1` є сильно асимптотично стійким.

### Обчислювальний приклад 2: Стробоскопічне відображення слабонелінійного осцилятора

Розглянемо вимушений гармонічний осцилятор із малою кубічною нелінійністю та малим згасанням:

```
d²x/dt² + ω₀²·x = ε · ( -γ·(dx/dt) - β·x³ + f₀·cos(ω·t) )
```

де `ε << 1` — малий параметр збурення.

Застосовуючи метод усереднення Боголюбова-Митропольського для амплітуди `a(t)` та фази `ϕ(t)` відносно резонансної частоти `ω ≈ ω₀`:

```
x(t) = a(t) · cos(ω·t + ϕ(t))
dx/dt = -a(t)·ω · sin(ω·t + ϕ(t))
```

Шляхом інтегрування усереднених рівнянь на проміжку одного періоду зовнішньої сили `T = 2π / ω` виводиться стробоскопічне відображення Пуанкаре для амплітуди `a[k]` та фази `ϕ[k]`:

```
a[k+1] = a[k] + ε·T · ( -(γ/2)·a[k] + (f₀/(2ω))·sin(ϕ[k]) ) + O(ε²)
ϕ[k+1] = ϕ[k] + ε·T · ( (ω₀ - ω) - (3β/(8ω))·a[k]² + (f₀/(2ω·a[k]))·cos(ϕ[k]) ) + O(ε²)
```

Нерухомі точки цього стробоскопічного відображення `(a*, ϕ*)` відповідають стаціонарним амплітудам нелінійного резонансу. Матриця Якобі цього 2D відображення дозволяє аналітично довести нестійкість середньої гілки амплітудно-частотної характеристики та обчислити точки гістерезисного зриву.
