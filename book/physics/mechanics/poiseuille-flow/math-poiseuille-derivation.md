# 🧮 Виведення течії Пуазейля: два шляхи до профілю — і що ховається за витратою

Параболу швидкості можна дістати хитрим трюком — вирізати подумки в трубі циліндричне осердя й зважити сили на ньому. Трюк працює, але він просить нас **угадати** правильне тіло: чому саме співвісний циліндр, а не якась інша форма? Для круглої труби відповідь очевидна, проте здогад лишається здогадом. Тож заслужімо закон Пуазейля двічі. Спершу зробімо той самий баланс сил чесно, до останнього знака. Потім виведімо все наново — прямо з рівнянь руху в'язкої рідини, де вгадувати не треба нічого, форма профілю **випадає** з математики сама. І побачимо, що це той самий один рядок, лише вдягнений у два різні костюми: інтегральний і диференціальний.

А коли профіль і витрата будуть у руках, підемо далі — у шар, яким інженер користується щодня: коефіцієнт тертя, що зводить усю формулу до однієї безрозмірної сталої; потужність накачування, яка вся до краплі йде в тепло; вхідна ділянка, де параболи ще немає; і що робити, коли труба не кругла.

## Що саме ми замикаємо припущеннями

Перш ніж рахувати, випишімо чесно всі умови — бо кожна з них потім десь зайде у виведення на видимому кроці, і, знаючи де, ми завжди бачитимемо, коли формула має право збрехати.

```
стала течія            ∂/∂t = 0        (кран давно відкрутили)
нестислива рідина      ρ = const        (рідина, не швидкий газ)
ньютонівська           μ = const        (в'язкість не залежить від зсуву)
повністю розвинена     ∂u/∂z = 0        (профіль однаковий уздовж труби)
осесиметрична          ∂/∂θ = 0         (нічого не залежить від кута)
ламінарна              без вихорів      (шари не перемішуються)
горизонтальна          тяжіння в тиск   (або вбираємо ρgz у p)
```

Геометрія проста: труба радіуса *R*, довжини *L*; вісь позначмо *z* (уздовж течії), відстань від осі — *r*. Тиск падає вздовж потоку, тож похідна тиску вздовж осі від'ємна; зручно ввести додатний перепад Δ*p* = *p*(0) − *p*(*L*) > 0, і тоді

```
dp/dz = −Δp / L      (сталий градієнт — це ми ще доведемо)
```

## Шлях перший: баланс сил, зроблений до останнього знака

Вирізьмо співвісне осердя радіуса *r* і довжини *L*. Течія стала — осердя не прискорюється, тож сума всіх поздовжніх сил на ньому нульова. Спереду й ззаду на торці (площею π*r*²) тисне рідина; різниця цих тисків штовхає осердя вперед із силою Δ*p*·π*r*². Утримує його єдина зустрічна сила — [в'язке тертя об навколишню рідину](book:physics/viscosity): зовні осердя тече повільніша рідина, вона чіпляється за нього й гальмує. Ця сила діє на бічну поверхню 2π*r*·*L* через дотичне напруження, і рівновага дає

```
Δp · π r²  =  τ · 2π r L        │ скоротити на π r
τ(r) = (Δp / 2L) · r
```

Напруження росте від нуля на осі до максимуму коло стінки — строго лінійно. Тепер підставмо, що таке в'язке напруження за [законом Ньютона: воно дорівнює в'язкості на швидкість зміни швидкості поперек потоку](book:math/derivative), τ = μ·d*u*/d*r*. Тонкість зі знаком: швидкість спадає від центра до стінки, тож d*u*/d*r* < 0, і напруження, що **гальмує** осердя, за величиною дорівнює −μ·d*u*/d*r*. Прирівнявши до знайденого τ(*r*):

```
−μ · du/dr = (Δp / 2L) · r
du/dr = −(Δp / 2μL) · r
```

Лишилося «розкрутити» похідну назад у саму швидкість — проінтегрувати:

```
u(r) = −(Δp / 4μL) · r² + C
```

Сталу *C* прибиває [умова прилипання](book:physics/viscosity): на стінці рідина стоїть, *u*(*R*) = 0. Звідси *C* = Δ*p*·*R*²/(4μ*L*), і профіль набуває остаточного вигляду

```
u(r) = (Δp / 4μL) · (R² − r²)       (парабола)
u_max = u(0) = Δp · R² / (4μL)
```

Виведення бездоганне — але зверни увагу, де в ньому сидить здогад: ми **обрали** циліндричне осердя. Для круглої труби це природно, для квадратної вже ні. Ось чому варто мати другий шлях, вільний від будь-якого вибору форми.

## Шлях другий: прямо з Нав'є–Стокса, без жодного здогаду

Рівняння Нав'є–Стокса — це той самий другий закон Ньютона «маса × прискорення = сума сил», записаний для крихітної частинки в'язкої рідини: ліворуч інерція, праворуч градієнт тиску плюс в'язкі сили. Назвали рівняння за Клодом-Луї Нав'є, який 1822 року вписав у рух рідини член тертя, і Джорджем Ґабріелем Стоксом, що надав йому строгого вигляду (усталений історичний факт). У циліндричних координатах поздовжня (уздовж *z*) складова для нестисливої рідини має вигляд

```
ρ(∂u/∂t + (v·∇)u) = −∂p/∂z + μ[ (1/r)·∂/∂r(r·∂u/∂r) + (1/r²)·∂²u/∂θ² + ∂²u/∂z² ]
```

Тепер по черзі вимикаймо доданки нашими умовами — і дивімося, як складна рівність тане:

- **осесиметрична** (∂/∂θ = 0) — зникає середній член у дужці;
- **повністю розвинена** (∂*u*/∂*z* = 0) — зникає останній член у дужці; а з рівняння нерозривності для нестисливої рідини випливає, що коли є лише поздовжня швидкість і вона не міняється вздовж *z*, то радіальної складової просто немає;
- **стала** (∂*u*/∂*t* = 0) — зникає перший доданок ліворуч;
- **конвективне прискорення** (v·∇)*u* теж нуль: рухатися частинці «в іншу швидкість» нема куди, бо вздовж *z* профіль не міняється.

Ліворуч не лишається нічого — інерція занулилася. Уся рівність згортається до

```
μ · (1/r) · d/dr(r · du/dr) = dp/dz
```

І тут — найкрасивіший крок усього виведення. Ліворуч стоїть функція **тільки від r**, праворуч — похідна тиску, яка (з рівнянь для радіального й кутового напрямків виходить ∂*p*/∂*r* = 0, ∂*p*/∂*θ* = 0, тобто тиск сталий по перерізу) залежить **тільки від z**. Функція від *r* тотожно дорівнює функції від *z* лише в одному разі — коли обидві є **однією й тією самою сталою**. Ось і доведено те, що ми раніше просто прийняли: градієнт тиску вздовж труби сталий, тиск падає **лінійно**. Позначмо цю сталу −Δ*p*/*L*:

```
(1/r) · d/dr(r · du/dr) = −Δp / (μL)
```

Далі — чиста математика, два інтегрування. Помножмо на *r* й проінтегруймо раз:

```
r · du/dr = −(Δp / 2μL) · r² + C₁
du/dr = −(Δp / 2μL) · r + C₁ / r
```

Сталу *C₁* прибиває умова на осі. Член *C₁*/*r* вибухнув би в нескінченність при *r* → 0, а швидкість у центрі труби скінченна й гладенька — отже, *C₁* = 0. Придивись, що це фізично: *r*·d*u*/d*r* — це з точністю до μ саме дотичне напруження, помножене на *r*, тобто повна сила тертя на циліндрі. Вимога *C₁* = 0 означає «на осі немає ниткової сили» — рівно те, що в першому шляху дав баланс сил на найтоншому осерді. **Два шляхи — одне рівняння:** перший записав його в інтегральній формі (сила = сила), другий — у диференціальній (Нав'є–Стокс), а стала інтегрування *C₁* виявилася містком між ними. Друге інтегрування з умовою прилипання *u*(*R*) = 0 повертає ту саму параболу:

```
u(r) = (Δp / 4μL) · (R² − r²)
```

![Дві панелі поряд: ліворуч зсувне напруження τ(r) — «галочка», що росте лінійно від нуля на осі до τ_w на обох стінках; праворуч швидкість u(r) — парабола з максимумом у центрі й нулем на стінках; між ними стрілка з підписом τ = −μ·du/dr, інтегруємо з умовою u(R)=0.](/book/physics/mechanics/poiseuille-flow/img/shear-to-velocity.svg)
*Уся справа — одне інтегрування. Напруження лінійне по r (де швидкість найкрутіше спадає — коло стінки — там воно найбільше; на осі, де профіль плаский, воно нуль). Проінтегрувавши нахил швидкості −τ/μ, дістаємо параболу.*

## Витрата: складаємо всі кільця

Профіль відомий — порахуймо, скільки рідини несе труба. Розріжмо переріз на тонкі кільця: кільце на радіусі *r* має площу 2π*r*·d*r* і біжить зі швидкістю *u*(*r*). Об'ємна витрата *Q* — це [сума-інтеграл внесків усіх кілець](book:math/integral) від осі до стінки:

```
Q = ∫₀ᴿ u(r) · 2πr dr = (2π Δp / 4μL) · ∫₀ᴿ (R² − r²) · r dr
```

Інтеграл усередині береться в один рядок: ∫₀ᴿ (*R*²*r* − *r*³) d*r* = *R*²·*R*²/2 − *R*⁴/4 = *R*⁴/4. Підставмо:

```
Q = (2π Δp / 4μL) · R⁴/4 = π R⁴ Δp / (8 μ L)        (закон Пуазейля)
```

Середню швидкість дістанемо, поділивши витрату на площу перерізу:

```
v̄ = Q / (π R²) = Δp R² / (8μL) = ½ · u_max
```

Рівно половина максимуму. Це чиста властивість параболи: усереднення *R*² − *r*² по круглому перерізу дає половину пікового значення. Тримаймо цей результат — «½» — в голові: скоро побачимо, що для некруглої труби він **інший**, і сама зміна цього числа розкаже нам про форму.

## Коефіцієнт тертя Дарсі: чому саме 64/Re

Інженер рідко тягає всі μ, *L*, *R* окремо — він згортає втрати тиску в одну безрозмірну сталу через формулу Дарсі–Вайсбаха (за Анрі Дарсі й Юліусом Вайсбахом), яка описує тертя в **будь-якій** трубі, ламінарній чи турбулентній:

```
Δp = f · (L / D) · (½ ρ v̄²)
```

де *D* = 2*R* — діаметр, *f* — коефіцієнт тертя, а ½ρv̄² — [динамічний напір потоку](book:physics/dynamic-pressure). Для ламінарної течії *f* нам уже фактично відомий — треба лише переписати закон Пуазейля в цих позначеннях. Виразимо Δ*p* через середню швидкість: із *Q* = *v̄*·π*R*² маємо

```
Δp = 8μL Q / (πR⁴) = 8μL v̄ / R² = 32 μ L v̄ / D²
```

Прирівняймо це до формули Дарсі й виділимо *f*:

```
f · (L/D) · (½ρv̄²) = 32 μ L v̄ / D²
f = 64 μ / (ρ v̄ D) = 64 / Re ,   де   Re = ρ v̄ D / μ
```

Ось воно — уся заплутана залежність від радіуса, в'язкості й швидкості сховалася в одне [число Рейнольдса — безрозмірну міру, що зважує інерцію потоку проти в'язкості](book:physics/reynolds-number), а коефіцієнт тертя ламінарної труби виявився просто **64/Re**. Це ламінарна пряма діаграми Муді; вона тримається, доки течія шарувата — приблизно до Re ≈ 2300, де починається перехід до турбулентності й крива тертя зривається вгору з-під простої гіперболи.

> 🔧 **Навіщо це.** Одна пастка коштує інженерам годин: є **дві** різні «*f*». Наша, Дарсі, дає *f* = 64/Re. Але хімік-технолог часто вживає коефіцієнт Феннінга, у якого рівно вчетверо менше: *f*_F = 16/Re. Обидва правильні — просто по-різному означені. Переплутати їх — це помилитися в перепаді тиску в чотири рази. Тому, побачивши «*f* = 16/Re» чи «*f* = 64/Re», спершу з'ясуй, чий це коефіцієнт, а вже потім став у формулу.

![Логарифмічний графік коефіцієнта тертя f проти числа Рейнольдса Re: пряма лінія f = 64/Re круто спадає в ламінарній області до Re≈2300, далі смуга переходу, потім турбулентні криві — гладка (Блазіус) і майже горизонтальні лінії шорстких труб.](/book/physics/mechanics/poiseuille-flow/img/friction-factor.svg)
*Закон Пуазейля — це ламінарна пряма f = 64/Re в лівій частині діаграми Муді. За Re ≈ 2300 шари зриваються у вихори, і тертя більше не слухається простої формули.*

**Приклад: замкнути коло на капілярі.** Хай вода (ρ = 1000 кг/м³, μ = 1.0·10⁻³ Па·с) біжить трубкою *D* = 1 мм із середньою швидкістю *v̄* = 0.31 м/с на довжині *L* = 0.1 м. Порахуймо тертя через Дарсі й перевірмо, чи збіжиться з прямим Пуазейлем.

```
Re = ρ v̄ D / μ = 1000 · 0.31 · 0.001 / 0.001 = 310      (глибоко ламінарно)
f  = 64 / Re = 64 / 310 = 0.206
Δp = f · (L/D) · ½ρv̄² = 0.206 · (0.1/0.001) · (0.5 · 1000 · 0.31²)
   = 0.206 · 100 · 48.05 = 990 Па
пряма перевірка:  Δp = 32 μ L v̄ / D² = 32 · 10⁻³ · 0.1 · 0.31 / (10⁻³)² = 992 Па  ✓
```

Два незалежні рахунки дають те саме — і це не диво, а тавтологія: *f* = 64/Re **є** законом Пуазейля, лише переодягнений у безрозмірну мову діаграми Муді.

## Уся робота накачування йде в тепло

Скільки потужності треба, щоб гнати рідину? Насос піднімає тиск на Δ*p* і проштовхує об'єм *Q* за секунду; добуток і є потужність накачування:

```
P = Q · Δp = π R⁴ Δp² / (8μL)
```

Куди ця енергія дівається? Течія стала, швидкість уздовж труби не міняється, висота теж — отже, ні кінетична, ні потенціальна енергія не ростуть. Уся робота накачування до останнього джоуля переходить у **тепло** через в'язке тертя шарів. Перевірмо це прямим підрахунком розсіяння. Локальна потужність тертя на одиницю об'єму дорівнює μ·(d*u*/d*r*)²; підставивши d*u*/d*r* = −Δ*p*·*r*/(2μ*L*) й проінтегрувавши по всій трубі:

```
розсіяння = ∫ μ(du/dr)² dV = ∫₀ᴿ μ · [Δp r/(2μL)]² · (2πr L) dr
          = (π Δp² / 2μL) · ∫₀ᴿ r³ dr = (π Δp² / 2μL) · R⁴/4
          = π R⁴ Δp² / (8μL)  =  Q · Δp   ✓
```

Тепловий рахунок точно збігся з механічним *Q*·Δ*p*. Це не випадковість, а закон збереження енергії, застосований до труби: скільки роботи вкинув насос, стільки тепла й виділилося в рідині.

> 🔧 **Навіщо це.** Ця рівність — чому мікрофлюїдні чипи гріються, а гідравлічна олива в вузьких каналах тепліє під навантаженням. Проштовхуєш *Q* крізь опір, що дає Δ*p*, — і викидаєш *Q*·Δ*p* ватів тепла просто в рідину. Для тієї крапельниці (*Q* ≈ 2.45·10⁻⁷ м³/с, Δ*p* ≈ 1000 Па) це мізерні *P* = 0.25 мВт; але в потужному гідроприводі з великими *Q* і Δ*p* ті самі ватти вже доводиться відводити радіатором, інакше олива перегріється.

## Вхідна довжина: де параболи ще немає

Уся наша побудова спиралася на «повністю розвинену» течію — профіль, що вже не міняється вздовж труби. Але рідина не народжується параболою. На вході в трубу вона зазвичай іде майже **пласким** фронтом; парабола виростає поступово. Коло стінок прилипання гальмує рідину, і від кожної стінки всередину росте загальмований **межовий шар**; ці шари товщають уздовж потоку, доки не зустрінуться на осі. Аж там профіль стає остаточною параболою й далі вже не міняється. Довжину цього розгону називають **вхідною** (гідродинамічною) ділянкою; для ламінарної труби вона добре описується оцінкою

```
L_e ≈ 0.06 · Re · D        (ламінарна; точніше 0.0575·Re·D)
L_e ≈ 10 · D               (груба оцінка для турбулентної)
```

![Труба збоку: рідина входить пласким профілем, від стінок ростуть заштриховані межові шари, поки не зімкнуться на осі; далі профіль — стала парабола. Внизу розмірна лінія позначає вхідну довжину L_e ≈ 0.06·Re·D, за нею напис «розвинена течія — закон Пуазейля».](/book/physics/mechanics/poiseuille-flow/img/entrance-length.svg)
*На вході параболи ще немає: межові шари від стінок ростуть, доки не зімкнуться. Лише за вхідною довжиною L_e профіль стає тим, що описує закон Пуазейля.*

Це не дрібниця для експерименту. Реальний перепад тиску на короткій трубці **більший** за пуазейлевий: у вхідній зоні рідину ще й розганяють у параболу (частина тиску йде в кінетичну енергію), а тертя там сильніше, ніж на розвиненій ділянці. Ця добавка зветься поправкою Гагенбаха. Саме тому Пуазейль у своїх вимірах брав **довгі тонкі** капіляри, де вхідна зона мізерна проти всієї довжини, — і тільки завдяки цьому вилущив чистий закон *Q* ∝ *R*⁴.

Тут доречно згадати, хто ж пояснив закон теоретично, бо історія повчальна. Дослід випередив теорію майже на два десятиліття: емпіричний закон знали з 1839–1841 років, а перше строге виведення з рівнянь руху дав Джордж Стокс близько 1845-го — але **не опублікував**, бо сумнівався в самій умові прилипання (тоді ще не було певності, що рідина коло стінки справді завмирає). Незалежні виведення оприлюднили Ґустав Відеман (1856), Франц Нейман і Едуард Гагенбах (близько 1858–1860); саме Гагенбах увів назву «закон Пуазейля» й ту поправку на вхід (усталений історичний факт). Мораль: навіть бездоганний висновок можна відкласти в шухляду через одне непевне граничне припущення — а вся наша парабола тримається саме на ньому.

## Коли переріз не круглий: гідравлічний діаметр

Труби бувають не лише круглі — прямокутні канали, щілини, кільцеві зазори. Щоб не виводити все наново для кожної форми, вводять **гідравлічний діаметр** — спосіб приписати некруглому перерізу «еквівалентний» розмір:

```
D_h = 4A / P        (A — площа перерізу, P — змочений периметр)
```

Для кола *D*_h = 4·π*R*²/(2π*R*) = 2*R* = *D* — означення підібране так, щоб на колі збігтися зі звичайним діаметром. Ідея приваблива: підстав *D*_h замість *D* у Re й у формулу Дарсі — і користуйся *f* = 64/Re для будь-якої форми. Пастка в тому, що **стала 64 змінюється разом із формою**. Чесна відповідь — *f* = *C*/Re, де *C* залежить від перерізу, і лише для кола *C* = 64.

Найясніше це видно на **пласкій щілині** — течії між двома паралельними пластинами із зазором 2*h* (широчінь велика, краями нехтуємо). Тут Нав'є–Стокс іще простіший, бо все залежить від однієї поперечної координати *y*:

```
μ · d²u/dy² = dp/dz = −Δp/L
u(y) = (Δp / 2μL) · (h² − y²)        знову парабола, u(±h)=0
```

Витрата на одиницю широчіні й середня швидкість дають цього разу **інше** відношення до максимуму:

```
v̄ = Δp h² / (3μL),   u_max = Δp h² / (2μL)   ⇒   v̄ = (2/3) · u_max
```

Не «½», як у круглій трубі, а «⅔» — і ця зміна числа не випадкова: вона прямо кодує форму перерізу. А порахувавши для щілини гідравлічний діаметр (*D*_h = 2·зазор) і коефіцієнт тертя, дістаємо

```
f = 96 / Re        (пласка щілина)
```

Ось наочна ціна форми: та сама фізика, той самий гідравлічний діаметр — а стала вже не 64, а 96. Для **прямокутних** каналів *C* лежить між цими краями й береться з числового розв'язку рівняння течії (табличні дані Шаха–Лондона):

```
квадрат            C ≈ 56.9
прямокутник 2:1    C ≈ 62.2
прямокутник 8:1    C ≈ 82.3
пласка щілина (∞)  C = 96
```

![П'ять перерізів у ряд — коло, квадрат, прямокутник 2:1, паралельні пластини, кільце — і під кожним його гідравлічний діаметр D_h = 4A/P та стала C у формулі f = C/Re: 64, ≈56.9, ≈62.2, 96 і 64→96 для кільця.](/book/physics/mechanics/poiseuille-flow/img/cross-sections.svg)
*Гідравлічний діаметр вирівнює масштаб, але не форму: стала C у f = C/Re повзе від 56.9 (квадрат) до 96 (щілина). Наївно взяти 64 для квадрата — завищити перепад тиску майже на 12%.*

Останній важливий випадок — **кільцевий зазор** між двома співвісними циліндрами (зовнішній радіус *R*, внутрішній *r_i*): так тече рідина в теплообміннику «труба в трубі» чи в затрубному просторі свердловини. Розв'язавши те саме рівняння з прилипанням на **обох** стінках, дістаємо точну витрату

```
Q = (π Δp / 8μL) · [ R⁴ − r_i⁴ − (R² − r_i²)² / ln(R / r_i) ]
```

Формула гарна тим, що містить обидва знайомі краї як границі. Коли внутрішній циліндр стягується в нитку (*r_i* → 0), останні два члени тануть, і лишається чистий π*R*⁴Δ*p*/(8μ*L*) — звичайна труба. А коли зазор тонкий (*r_i* → *R*), кільце локально випрямляється в пласку щілину, і його *C* прямує до 96. Між цими краями стала кільця пробігає весь діапазон від ~64 до 96 — тобто одна й та сама рідина під тим самим натиском тектиме помітно по-різному лише через те, якої форми щілину ти їй дав.

## Що дало це виведення

Ми здобули закон Пуазейля двічі й переконалися, що це один рядок у двох костюмах. Баланс сил на осерді (інтегральна форма) і рівняння Нав'є–Стокса (диференціальна форма) ведуть до тієї самої параболи *u* = (Δ*p*/4μ*L*)(*R*² − *r*²), а стала інтегрування, яку в другому шляху прибиває вимога скінченності на осі, виявляється тим самим «немає ниткової сили», що й у першому. Склавши всі кільця, дістали *Q* = π*R*⁴Δ*p*/(8μ*L*) і середню швидкість у половину максимуму.

А далі відкрився шар, заради якого варто було виводити строго. Уся формула згортається в одну безрозмірну сталу — *f* = 64/Re, ламінарну пряму діаграми Муді. Потужність накачування *Q*·Δ*p* точно дорівнює в'язкому розсіянню — уся до краплі йде в тепло. Парабола — це лише **розвинений** стан, якому передує вхідна ділянка *L_e* ≈ 0.06·Re·*D*, де профіль ще росте (і де ховається поправка Гагенбаха, і ціла історія про те, як Стокс відклав виведення через сумнів у прилипанні). А коли труба некругла, гідравлічний діаметр вирівнює масштаб, та не форму: стала *C* повзе від 56.9 для квадрата до 96 для щілини, і навіть знайоме «½» для середньої швидкості обертається на «⅔». За кожним із цих чисел стоїть та сама рівновага тиску й тертя — просто перерахована для нової межі.
