# 📋 Параметри та інтерфейс моделей турбулентності RANS: k-epsilon та k-omega SST

Ця вставка є структурованим довідником з контракту, фізичних рівнянь, модельних констант, формул вхідних граничних умов, пристінних функцій та налаштувань обчислювального інтерфейсу для двох найпоширеніших у промисловості моделей турбулентності RANS (Reynolds-Averaged Navier-Stokes): стандартної двоінтегральної моделі **Standard k-epsilon** та заснованої на зсувному напруженні моделі **Menter k-omega SST** (Shear Stress Transport).

## 1. Специфікація моделей та фізичний зміст рівнянь переносу

Усі моделі турбулентної в'язкості спираються на гіпотезу Буссінеска, яка пов'язує анізотропний тензор турбулентних напружень Рейнольдса `-ρ·⟨u'_i u'_j⟩` із тензором швидкостей деформації середнього потоку через скалярну вихрову динамічну в'язкість `μ_t`:

```
-ρ · ⟨u'_i u'_j⟩ = μ_t · (∂U_i/∂x_j + ∂U_j/∂x_i) - (2/3) · ρ · k · δ_ij
```

Фізичний зміст цього припущення полягає в тому, що турбулентні вихори розглядаються аналогічно до хаотичного руху молекул газу: вихори переносять імпульс із зон з високою швидкістю у зони з низькою швидкістю, створюючи ефективне додаткове тертя `μ_t`. Проте на відміну від молекулярної в meханіці, де в'язкість є фізичною властивістю самої речовини, вихрова в'язкість `μ_t` є динамічною функцією стану потоку й розраховується з двох скалярних параметрів турбулентності.

### Докладна специфікація моделі Standard k-epsilon (k-ε)

Модель `k-ε` є історично першою і найрозповсюдженішою двоінтегральною моделлю. Вона розв'язує два окремих диференціальних рівняння переносу у приватних похідних: одне для турбулентної кінетичної енергії `k`, а друге — для швидкості її дисипації `ε`.

Вихрова динамічна в'язкість обчислюється з макроскопічних міркувань розмірності:

```
μ_t = ρ · C_μ · (k² / ε)
```

Запишемо повні диференціальні рівняння переносу у консервативній формі:

```
∂(ρk)/∂t + ∂(ρU_j k)/∂x_j = ∂/∂x_j [ (μ + μ_t / σ_k) · ∂k/∂x_j ] + P_k - ρ·ε
∂(ρε)/∂t + ∂(ρU_j ε)/∂x_j = ∂/∂x_j [ (μ + μ_t / σ_ε) · ∂ε/∂x_j ] + C_1ε · (ε/k) · P_k - C_2ε · ρ · (ε²/k)
```

Кожен доданок у цих рівняннях відповідає за конкретний фізичний механізм балансу турбулентності:
1. **Часова похідна `∂(ρk)/∂t`:** накопичення чи виснаження турбулентної енергії у розрахунковому осередку з часом (нестаціонарність).
2. **Конвективний член `∂(ρU_j k)/∂x_j`:** переношення турбулентної енергії середньою швидкістю потоку `U_j` з сусідніх областей.
3. **Дифузійний член `∂/∂x_j [ (μ + μ_t / σ_k) · ∂k/∂x_j ]`:** турбулентне та молекулярне градієнтне розсіювання енергії за рахунок пульсацій тиску й хаотичного руху вихорів.
4. **Член генерації `P_k`:** викачування кінетичної енергії від середнього потоку в турбулентні вихори під дією зсувних напружень:
   ```
   P_k = μ_t · (∂U_i/∂x_j + ∂U_j/∂x_i) · (∂U_i/∂x_j)
   ```
5. **Член стоку (дисипація) `-ρ·ε`:** безпосереднє перетворення турбулентної кінетичної енергії у внутрішню теплову енергію під дією молекулярної в'язкості на найменших вихорах.

У рівнянні для `ε` перший правосторонній член описує вихрове розтягування та підсилення дисипації під дією зсуву потоку з коефіцієнтом `C_1ε`, а другий член описує природне згасання дисипативної структури з коефіцієнтом `C_2ε`.

Головний крайовий недолік стандартної моделі `k-ε` — вона припускає ізотропність турбулентності й не враховує вплив градієнтів тиску поблизу стінок. У зонах гальмування потоку (лобова точка стагнації обтіканого кузова чи крила) модель `k-ε` створює нереалістично високі значення `P_k`, що призводить до штучного вибуху турбулентної в'язкості та викривлення поля тиску.

### Докладна специфікація моделі Menter k-omega SST (k-ω SST)

Модель Menter SST позбавлена недоліків `k-ε`. Вона використовує питому швидкість дисипації `ω = ε / (C_μ · k)` (яку можна тлумачити як характерну частоту обертання вихорів, од. вимірювання 1/с). 

Поблизу твердих стінок модель SST працює в режимі `k-ω` Вілкокса, що дозволяє виконувати інтегрування крізь в'язкий підшар аж до самої поверхні без використання штучних згасаючих функцій. У вільному ж потоці (далеко від стінок) модель математично трансформується у модель `k-ε`, що усуває головну слабость чистої `k-ω` — високу чутливість до довільно заданих вхідних значень `ω` на межі розрахункової області.

Перемикання між двома режимами здійснюється за допомогою зважувальної функції блендингу `F_1`, яка приймає значення `F_1 = 1` у пристінній зоні й плавно знижується до `F_1 = 0` у вільному потоці:

```
F_1 = tanh( arg_1⁴ )
arg_1 = min( max( √k / (β* · ω · y), 500 ν / (y² · ω) ), 4 ρ · k / (CD_kω · σ_ω2 · y²) )
```

Де `y` — фізична відстань від поточного осередку сітки до найближчої твердої стінки, а `CD_kω` — член перехресної дифузії.

Для запобігання надмірному накопиченню турбулентної в'язкості при несприятливих (позитивних) градієнтах тиску (що часто стається перед відривом пограничного шару) модель SST обмежує турбулентну кінематичну в'язкість `ν_t = μ_t / ρ`:

```
ν_t = a_1 · k / max(a_1 · ω, S · F_2)
```

Де `S = √(2 S_ij S_ij)` — модуль тензора швидкостей деформацій середнього потоку, `a_1 = 0.31`, а `F_2` — друга функція блендингу, що вимикає обмеження у вільних зсувних шарах:

```
F_2 = tanh( arg_2² )
arg_2 = max( 2 √k / (β* · ω · y), 500 ν / (y² · ω) )
```

Завдяки цьому обмеженню модель `k-ω SST` є найкращим інструментом для точного передбачення точки зриву потоку з гладких поверхонь крил та кузовів автомобілів.

## 3. Формули розрахунку вхідних граничних умов

Задання некоректних початкових та вхідних значень турбулентних величин на межі входу у розрахункову область (`Inlet`) є найпоширенішою причиною розбіжності чисельних розрахунків та помилок у розрахунку опору.

На входу зазвичай задають два макроскопічні інженерні параметри:
1. **Інтенсивність турбулентності `I`:** відношення середньоквадратичного значення пульсацій швидкості до середньої основи швидкості потоку `V_in`:
   ```
   I = √( (1/3) · (⟨u'^2⟩ + ⟨v'^2⟩ + ⟨w'^2⟩) ) / V_in  =  √(2/3 k) / V_in
   ```
   Типові значення `I`:
   - `0.1% .. 1%` — високоякісні аеродинамічні труби зі сітками гасіння;
   - `1% .. 5%` — вільна атмосфера, незашумлені канали;
   - `5% .. 15%` — внутрішній потік у двигунах, слід за пропелером або турбіною.

2. **Характерний масштаб турбулентності `L`:** розмір найбільших вихорів у вхідному перерізі. Для внутрішніх течій у трубах чи каналах із гідравлічним діаметром `D` приймають `L = 0.07 · D`. Для вільних аеродинамічних течій обтікання тіл розміру `H` приймають `L = 0.1 · H`.

Виходячи з `I` та `L`, формули розрахунку вхідних полів мають такий вигляд:

```
Вхідне k:     k = 1.5 · (V_in · I)²

Вхідне ε:     ε = C_μ^(3/4) · (k^(3/2) / L)   ≈  0.1643 · (k^(3/2) / L)

Вхідне ω:     ω = k^(1/2) / (C_μ^(1/4) · L)   ≈  k^(1/2) / (0.5477 · L)

Вхідне ν_t:   ν_t = C_μ · k² / ε  =  k / ω
```

### Докладний приклад розрахунку вхідних умов

Розрахуємо вхідні параметри для повітряного потоку зі швидкістю `V_in = 20 м/с` у круглому повітропроводі діаметром `D = 0.1 м` при помірній інтенсивності турбулентності `I = 5%` (`I = 0.05`):

```
Масштаб вихорів L = 0.07 · 0.1 м = 0.007 м

Пульсація швидкості u' = V_in · I = 20 · 0.05 = 1.0 м/с

Кінетична енергія k = 1.5 · (1.0)² = 1.5 м²/с²

Дисипація ε = 0.1643 · (1.5^(1.5)) / 0.007
            = 0.1643 · 1.8371 / 0.007
            = 0.3018 / 0.007  ≈  43.12 м²/с³

Питома дисипація ω = (1.5^(0.5)) / (0.5477 · 0.007)
                   = 1.2247 / 0.003834  ≈  319.4 с⁻¹

Турбулентна кінематична в'язкість ν_t = 1.5 / 319.4  ≈  4.70 × 10⁻³ м²/с
```

Зверніть увагу: отримана вихрова в'язкість `ν_t ≈ 4.70 × 10⁻³ м²/с` у **300 разів перевищує** молекулярну в'язкість повітря (`ν ≈ 1.5 × 10⁻⁵ м²/с`). Це яскраво демонструє, наскільки турбулентне тертя переважає молекулярне у реальних каналах.

## 4. Граничні умови на твердих стінках та пристінні функції

Вибір граничних умов на стінці залежить від безрозмірної відстані першого вузла розрахункової сітки від поверхні: `y⁺ = (u_τ · y) / ν`, де `u_τ = √(τ_w / ρ)` — динамічна швидкість.

Існує дві принципово різні концепції сіткового розбиття біля стінки:

1. **Режим Low-Re (Low Reynolds Number approach, `y⁺ < 1`):**
   Призначений для точного розрахунку тертя й теплообміну. Перший пристінний шар сітки будується настільки тонким (`y⁺ < 1`), що розрахункові вузли потрапляють безпосередньо у в'язкий підшар. 
   - На стінці задаються фізичні граничні умови: `k = 0`, `ν_t = 0`.
   - Для `ω` задається спеціальне асимптотичне граничне значення біля самої поверхні: `ω_wall = 10 · (6 ν / (β_1 · y²))`.

2. **Режим High-Re (High Reynolds Number approach з пристінними функціями, `y⁺ > 30 .. 300`):**
   Економить обчислювальні ресурси. Перший вузол сітки свідомо розміщують у логарифмічному шарі (`y⁺ > 30`), а в'язкий підшар не розраховується чисельно, а моделюється аналітично через Закон Стіни Прандтля.
   - На стінці застосовують математичні **пристінні функції** (wall functions):
     - `nutkWallFunction` обчислює вихрову в'язкість `ν_t` з логарифмічного співвідношення `u⁺ = (1/κ) ln(y⁺) + B`.
     - `epsilonWallFunction` задає значення дисипації у першому осередку виходячи з умови локальної рівноваги між генерацією та дисипацією: `ε = C_μ^(3/4) · k^(3/2) / (κ · y)`.

### Сводна таблиця стандартних граничних умов OpenFOAM

| Змінна | Режим High-Re (`y⁺ > 30`) | Режим Low-Re (`y⁺ < 1`) |
| :--- | :--- | :--- |
| `k` | `kLowReWallFunction` або `zeroGradient` | `fixedValue; value uniform 0;` |
| `ε` | `epsilonWallFunction` | `zeroGradient` або `fixedValue` |
| `ω` | `omegaWallFunction` | `omegaWallFunction` (із авто-перемиканням) |
| `nut` (`ν_t`) | `nutkWallFunction` або `nutWallFunction` | `fixedValue; value uniform 0;` |

Для моделі `k-ω SST` у пакеті OpenFOAM гранична умова `omegaWallFunction` є автоматично адаптивною (continuous wall function): вона самостійно перемикається між формулою в'язкого підшару та логарифмічною формулою у буферній зоні (`5 < y⁺ < 30`), що захищає розрахунок від втрати точності на неідеальних сітках.

## 5. Конфігураційний формат словників OpenFOAM

Нижче наведено повну робочу специфікацію конфігураційних словників OpenFOAM для моделювання турбулентності за моделлю `k-omega SST`.

### Словник `constant/turbulenceProperties`

Цей файл вказує солверу режим розрахунку (RAS — Reynolds-Averaged Simulation) та вмикає конкретну модель турбулентності.

```text
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    location    "constant";
    object      turbulenceProperties;
}

simulationType RAS;

RAS
{
    RASModel        kOmegaSST;
    turbulence      on;
    printCoeffs     on;
}
```

### Словник `system/fvSchemes` (Схеми чисельної дискретизації)

Файл `fvSchemes` визначає математичні оператори дискретизації диференціальних рівнянь на неструктурованій сітці методом скінченних об'ємів (FVM).

Для конвективних членів перенесення турбулентних величин `div(phi,k)` та `div(phi,omega)` вкрай важливо використовувати **обмежені схеми другого порядку** (наприклад, `limitedLinear 1.0` або `bounded Gauss linearUpwind`). Використання чистої центрально-різницевої схеми (`linear`) призведе до виникнення нефізичних осциляцій та появи від'ємних значень `k` або `ω`, що негайно викличе аварійне зупинення розрахунку.

```text
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    location    "system";
    object      fvSchemes;
}

ddtSchemes
{
    default         bounded Implicit;
}

gradSchemes
{
    default         Gauss linear;
    grad(U)         cellMDLimited Gauss linear 1.0;
}

divSchemes
{
    default         none;
    div(phi,U)      bounded Gauss linearUpwind grad(U);
    div(phi,k)      bounded Gauss limitedLinear 1.0;
    div(phi,omega)  bounded Gauss limitedLinear 1.0;
    div(phi,epsilon) bounded Gauss limitedLinear 1.0;
    div((nuEff*dev2(T(grad(U))))) Gauss linear;
}

laplacianSchemes
{
    default         Gauss linear corrected;
}

interpolationSchemes
{
    default         linear;
}

snGradSchemes
{
    default         corrected;
}
```

### Словник `system/fvSolution` (Солвери лінійних систем та параметри збіжності)

Файл `fvSolution` контролює роботу ітераційних лінійних солверів (GAMG, SmoothSolver), коефіцієнти нижньої релаксації (relaxationFactors) та критерії зупинки розрахунку (residualControl) при розв'язанні алгебраїчних систем `A · x = b`.

```text
FoamFile
{
    version     2.0;
    format      ascii;
    class       dictionary;
    location    "system";
    object      fvSolution;
}

solvers
{
    p
    {
        solver          GAMG;
        tolerance       1e-06;
```
