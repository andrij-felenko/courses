# 🧮 Виведення каскаду та закону "п'яти третіх" Колмогорова

У цій вставці наведено повний математичний вивід основних співвідношень теорії турбулентності Колмогорова (K41 та K62). Використовуючи методи аналізу розмірностей, теорію кореляційних та структурних функцій, а також точне рівняння Кармана — Ховарта для ізотропного вихрового поля, ми строго одержимо мікроскопічні масштаби дисипації, спектральний закон «п'яти третіх» та єдиний точний результат теорії турбулентності — закон «чотирьох п meтих» Колмогорова.

## 1. Аналіз розмірностей та масштаби Колмогорова

У повністю розвинутому турбулентному потоці за дуже великих чисел Рейнольдса (`Re >> 1`) кінетична енергія вводиться у потік на великих масштабах `L` зі швидкістю `ε` (одиниця вимірювання — квадрат швидкості за секунду, тобто Па·м³ / (кг·с) = м²/с³). Ця енергія передається без втрат крізь інерційний інтервал і дисипує на найдрібніших вихорах розміру `η` за рахунок кінематичної в'язкості `ν` (одиниця вимірювання — м²/с).

За першою гіпотезою Колмогорова, характеристики вихорів дисипативного інтервалу залежать **виключно** від двох фізичних величин: швидкості дисипації `ε` та кінематичної в'язкості `ν`. Знайдімо унікальні комбінації цих параметрів, що мають розмірність довжини (`η`), часу (`τ_η`) та швидкості (`v_η`).

Запишемо розмірності вихідних величин:

```
[ε] = м² / с³     (питома швидкість дисипації енергії)
[ν] = м² / с      (кінематична в'язкість)
```

Шукаємо масштаб довжини у формі `η = νᵃ · εᵇ`:

```
[η] = [ν]ᵃ · [ε]ᵇ
м   = (м²/с)ᵃ · (м²/с³)ᵇ  =  м^(2a + 2b) / с^(a + 3b)
```

Складаємо систему лінійних алгебраїчних рівнянь для показників степенів за секундами та метрами:

```
рівняння за секундами:  a + 3b = 0      ⇒  a = -3b
рівняння за метрами:    2a + 2b = 1
```

Підставляємо `a = -3b` у рівняння за метрами:

```
2·(-3b) + 2b = 1
-6b + 2b = 1
-4b = 1                 ⇒  b = -1/4
a = -3·(-1/4)           ⇒  a = 3/4
```

Отримуємо **масштаб довжини Колмогорова**:

```
η = (ν³ / ε)^(1/4)      [масштаб дисипації Колмогорова]
```

Аналогічно виводимо масштаб часу `τ_η` та масштаб швидкості `v_η`:

```
[τ_η] = (м²/с)ᵃ · (м²/с³)ᵇ  =  с¹
2a + 2b = 0             ⇒  a = -b
a + 3b = 1              ⇒  -b + 3b = 1  ⇒  b = 1/2,  a = -1/2

τ_η = (ν / ε)^(1/2)    [масштаб часу Колмогорова]
```

Для швидкості `v_η`:

```
v_η = η / τ_η = (ν³ / ε)^(1/4) / (ν / ε)^(1/2) = (ν · ε)^(1/4)
v_η = (ν · ε)^(1/4)    [масштаб швидкості Колмогорова]
```

Обчислимо число Рейнольдса, побудоване за мікроскопічними масштабами Колмогорова:

```
Re_η = v_η · η / ν
     = (ν · ε)^(1/4) · (ν³ / ε)^(1/4) / ν
     = (ν⁴)^(1/4) / ν
     = ν / ν  =  1     [число Рейнольдса на масштабі Колмогорова дорівнює одиниці]
```

Рівність `Re_η = 1` є глибоким фізичним результатом: вона показує, що на масштабі `η` сили інерції точно зрівноважуються силами в'язкості. На менших масштабах в'язке тертя повністю пригнічує будь-які хвильові коливання, і потік стає гладким.

Співвідношення між найбільшим масштабом течії `L` та дисипативним масштабом `η` виражається через глобальне число Рейнольдса `Re_L = V · L / ν`:

```
ε  ≈  V³ / L            [оцінка швидкості каскаду з великомасштабного руху]

η / L  =  (ν³ / (V³/L))^(1/4) / L
       =  (ν³ L / V³)^(1/4) / L
       =  (ν / (V·L))^(3/4)
       =  Re_L^(-3/4)

η / L  =  Re_L^(-3/4)   [відношення масштабів Колмогорова до розміру системи]
```

Оскільки число тривимірних комірок сітки для чисельного розв'язання дорівнює `(L / η)³`, мінімальна кількість вузлів сітки для повного розрахунку всіх вихорів (DNS) зростає як:

```
N_узлів  ~  (L / η)³  =  (Re_L^(3/4))³  =  Re_L^(9/4)
```

Для реального пасажирського літака (`Re ~ 10⁸`) це дає `N ~ (10⁸)^(2.25) = 10¹⁸` вузлів, що пояснює неможливість прямого розрахунку реальних технічних об'єктів без застосування моделей турбулентності.

## 2. Спектральний закон «п'яти третіх» Колмогорова — Обухова

Спектральна густина кінетичної енергії `E(k)` визначається так, щоб інтеграл по всіх хвильових числах `k` дорівнював повній питомій кінетичній енергії турбулентних пульсацій `k_e`:

```
k_e = ∫₀^∞ E(k) dk     [питома кінетична енергія, м²/с²]
```

Оскільки хвильове число `k` має розмірність `1/м`, розмірність спектральної густини `E(k)` дорівнює:

```
[E(k)] = [k_e] / [k] = (м²/с²) / (1/м) = м³ / с²
```

В інерційному інтервалі масштабів (`1/L << k << 1/η`) спектр залежить лише від швидкості переносу енергії `ε` та самого хвильового числа `k`. Шукаємо залежність у вигляді `E(k) = C · εᵃ · kᵇ`:

```
[E(k)] = [ε]ᵃ · [k]ᵇ
м³ / с² = (м²/с³)ᵃ · (1/м)ᵇ = м^(2a - b) / с^(3a)
```

Прирівнюємо показники степенів при базових одиницях (секундах та метрах):

```
рівняння за секундами:  3a = 2         ⇒  a = 2/3
рівняння за метрами:    2a - b = 3
```

Підставляємо `a = 2/3` у друге рівняння:

```
2·(2/3) - b = 3
4/3 - b = 3
b = 4/3 - 9/3           ⇒  b = -5/3
```

Отже, отримуємо знамениту формулу Колмогорова — Обухова:

```
E(k) = C · ε^(2/3) · k^(-5/3)   [спектральний закон «п'яти третіх»]
```

Тут `C ≈ 1.5` — безрозмірна універсальна константа Колмогорова, визначена з численних фізичних та чисельних експериментів.

## 3. Математичний зв'язок між спектром енергії та кореляційними функціями

Для статистичного опису турбулентності у просторовому середовищі використовують двоточковий тензор кореляції пульсацій швидкості `B_ij(r) = ⟨u'_i(x) · u'_j(x + r)⟩`.

Для статистично однорідної та ізотропної турбулентності двоточковий кореляційний тензор повністю виражається через одну скалярну **поздовжню кореляційну функцію** `B_LL(r) = ⟨u'_L(x) · u'_L(x + r)⟩`, де `u'_L` — компонента пульсації швидкості, паралельна вектору `r`.

За теоремою Вінера — Хінчина для вихрових полів, спектральна щільність кінетичної енергії `E(k)` є прямо пов'язаною з поздовжньою кореляційною функцією `B_LL(r)` через 3D-перетворення Фур'є:

```
E(k) = (1 / π) · ∫₀^∞ k · r · sin(k · r) · B_LL(r) dr
```

І навпаки, кореляційна функція відновлюється зі спектра через зворотне перетворення:

```
B_LL(r) = 2 · ∫₀^∞ E(k) · ( sin(k·r)/(k·r)³ - cos(k·r)/(k·r)² ) dk
```

Цей математичний зв'язок показує, що спектр `E(k)` у хвильовому просторі та структурні функції у фізичному просторі є двома еквівалентними способами опису тієї самої вихрової структури.

## 4. Рівняння Кармана — Ховарта та точний закон «чотирьох п'ятих»

Для дослідження турбулентності у фізичному просторі використовують **подовжню структурну функцію** `p`-го порядку, яка визначається як математичне сподівання різниці паралельних компонент швидкості між двома точками, віддаленими на відстань `r`:

```
S_p(r) = ⟨ (u'_L(x + r) - u'_L(x))^p ⟩
```

З рівнянь Нав'є — Стокса безпосередньо виводиться точне диференціальне **рівняння Кармана — Ховарта (1938)**, яке описує часову еволюцію другої структурної функції `S_2(r, t)` через третю структурну функцію `S_3(r, t)`:

```
∂S_2/∂t + (1/6r⁴) · ∂(r⁴ S_3)/∂r = 2 ν · (1/r⁴) · ∂(r⁴ ∂S_2/∂r)/∂r - (4/3) ε
```

Це рівняння є точним математичним наслідком закон збереження імпульсу. 

Для стаціонарної турбулентності (`∂S_2/∂t = 0`) при дуже великих числах Рейнольдса (`Re → ∞`), коли в'язкий доданок `2 ν · ...` прямує до нуля в інерційному інтервалі (`η << r << L`), рівняння Кармана — Ховарта спрощується до вигляду:

```
(1/r⁴) · ∂(r⁴ S_3)/∂r = - (4) · ε
```

Помножимо обидві частини рівняння на `r⁴`:

```
∂(r⁴ S_3)/∂r = - 4 · ε · r⁴
```

Інтегруємо це рівняння по `r` від `0` до `r`:

```
r⁴ · S_3(r) = ∫₀^r (- 4 · ε · r'⁴) dr'  =  - (4/5) · ε · r⁵
```

Поділимо обидві частини на `r⁴` й отримаємо знаменитий **точний закон «чотирьох п'ятих» Колмогорова (1941)**:

```
S_3(r) = - (4/5) · ε · r   [точний закон «чотирьох п'ятих» Колмогорова]
```

Це **єдиний точний аналітичний результат** у всій теорії турбулентності, доведений без емпіричних констант і без припущень про замикання. Знак мінус показує від'ємну асиметрію (скошеність) розподілу пульсацій швидкості, що є математичним виразом незворотної передачі енергії від великих вихорів до дрібних через вихрове розтягування.

## 5. Переривчастість (інтермітність) та поправки K62 і Ше — Левека

У первинній теорії K41 висувалося припущення, що питома швидкість дисипації `ε` є строго постійною величиною. Проте експерименти з гарячою дротовою анемометрією 1950–1960-х років виявили невеликі систематичні відхилення від теорії K41 для структурних функцій високих порядків (`p ≥ 4`). 

Причиною стала **переривчастість (інтермітність)**: дисипація енергії `ε` не розподілена рівномірно у просторі, а концентрується у вузьких вихрових нитках та тонких зсувних шарах, що утворюють рідкісну мультифрактальну мережу.

1962 року Колмогоров та Обухов уточнять теорію (модель **K62**), ввівши логарифмічно-нормальний розподіл флуктуацій локальної дисипації `ε_r`, усередненої по об'єму радіуса `r`. Уточнений закон для показника масштабування `S_p(r) ~ r^(ζ_p)` має вигляд:

```
ζ_p = p/3 - μ · p · (p - 3) / 18
```

Де `μ ≈ 0.25` — безрозмірна константа інтермітності. 

Для `p = 3` поправка перетворюється на нуль (`ζ_3 = 1`), що зберігає точний закон «чотирьох п'ятих», тоді як для `p = 2` дає крихітну поправку `ζ_2 ≈ 0.70` замість `0.67` (2/3). 

Пізніші мультифрактальні моделі, зокрема **ієрархічна модель Ше — Левека (She-Leveque, 1994)**, спираються на припущення про те, що найсильніші дисипативні структури у тривимірному просторі є одновимірними вихровими нитками (дронтами). Розрахункова формула Ше — Левека має вигляд:

```
ζ_p = p/9 + 2 · ( 1 - (2/3)^(p/3) )
```

Ця формула не містить жодної вільної емпіричної константи й ідеально узгоджується з сучасними суперкомп'ютерними розрахунками DNS та експериментами на ядерних прискорювачах до `p = 10`.
