# 📋 Довідник в'язкопружних моделей та параметрів

Цей довідник містить комплексні математичні та фізичні характеристики в'язкопружних матеріалів, зведені матриці конститутивних рівнянь, числові параметри для широкого спектра полімерів, біологічних тканин і високотемпературних сплавів, детальний опис п'яти основних експериментальних методів випробувань, а також специфікацію вхідних даних для комерційних солеверів скінченноелементного аналізу (FEA).

## 1. Порівняльна матриця реологічних моделей

Феноменологічні моделі в'язкопружності будуються шляхом поєднання двох базових механічних примітивів: ідеально пружної пружини Гука (характеризується модулем Юнга `E` або модулем зсуву `G`) та ідеально в'язкого поршня-демпфера Ньютона (характеризується коефіцієнтом динамічної в'язкості `η`). Вибір конкретної реологічної топології визначає, які фізичні ефекти здатна відтворити математична модель.

У наведеній нижче порівняльній матриці зібрано конститутивні рівняння, аналітичні функції часового відгуку (модуль релаксації `E(t)` та податливість повзучості `J(t)`), а також динамічні спектральні характеристики (модуль накопичення `E'(ω)`, модуль втрат `E''(ω)` та тангенс кута механічних втрат `tan δ`).

| Модель | Схема з'єднання | Конститутивне рівняння | Модуль релаксації `E(t)` | Податливість повзучості `J(t)` | Модуль накопичення `E'(ω)` | Модуль втрат `E''(ω)` | Тангенс втрат `tan(δ)` |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Гук (Hooke)** | Одиночна пружина | `σ = E · ε` | `E` (сталий) | `1 / E` (стала) | `E` | `0` | `0` (чиста пружність) |
| **Ньютон (Newton)** | Одиночний демпфер | `σ = η · (dε/dt)` | Не визначений (`η·δ(t)`) | `t / η` | `0` | `ω · η` | `∞` (чиста в'язкість) |
| **Максвелл (Maxwell)** | Пружина й демпфер послідовно | `(dε/dt) = (1/E)(dσ/dt) + σ/η` | `E · exp(-t / τ_R)` | `1/E + t/η` | `E · (ω² τ_R²) / (1 + ω² τ_R²)` | `E · (ω τ_R) / (1 + ω² τ_R²)` | `1 / (ω · τ_R)` |
| **Кельвін-Фойгт (Kelvin-Voigt)** | Пружина й демпфер паралельно | `σ = E·ε + η·(dε/dt)` | `E + η·δ(t)` | `(1/E)·[1 - exp(-t / τ_D)]` | `E` | `ω · η` | `(ω · η) / E = ω · τ_D` |
| **Зенер (SLS / SLS-Zener)** | Пружина паралельно з віткою Максвелла | `σ + τ_σ(dσ/dt) = E_R[ε + τ_ε(dε/dt)]` | `E_R + (E_U - E_R)·exp(-t / τ_σ)` | `J_U + (J_R - J_U)[1 - exp(-t / τ_ε)]` | `E_R + (E_U - E_R) (ω² τ_σ²) / (1 + ω² τ_σ²)` | `(E_U - E_R) (ω τ_σ) / (1 + ω² τ_σ²)` | `(E_U - E_R) ω τ_σ / [E_R + E_U ω² τ_σ²]` |
| **Ряд Проні (Prony Series)** | `G_∞` паралельно з `N` вітками Максвелла | `σ = G_∞ ε + ∑ h_i` | `G_∞ + ∑ G_i · exp(-t / τ_i)` | Обчислюється чисельно / матрично | `G_∞ + ∑ G_i (ω² τ_i²) / (1 + ω² τ_i²)` | `∑ G_i (ω τ_i) / (1 + ω² τ_i²)` | `G''(ω) / G'(ω)` |

### Детальний фізичний розбір характеристик моделей

1. **Модель Гука:** Забезпечує миттєву й повністю зворотну деформацію. Кут фазового зсуву `δ = 0`, модуль втрат `E'' = 0`. Вся механічна робота зберігається потенціально. Застосовується для кристалічних металів при низьких температурах та крихких керамік.
2. **Модель Ньютона:** Описує суто в'язке тертя рідини. Напруження випереджає деформацію на `δ = π/2` (90°). Модуль накопичення `E' = 0`. Робота повністю перетворюється на тепло. Застосовується для низькомолекулярних рідин і газів.
3. **Модель Максвелла:** Найпростіша модель в'язкопружної рідини. Вона якісно описує експоненціальну релаксацію напружень із часом `τ_R = η / E`. На високих частотах (`ω ≫ 1/τ_R`) модель поводиться пружно (`E' → E`), а на низьких частотах (`ω ≪ 1/τ_R`) — як ньютонівська рідина. Недолік — необмежена лінійна повзучість при сталому напруженні.
4. **Модель Кельвіна-Фойгта:** Найпростіша модель в'язкопружного твердого тіла з затриманою пружністю. Вона чудово описує експоненціальне наростання деформації повзучості до обмеженої асимптоти з часом затримки `τ_D = η / E`. Недоліки — відсутність миттєвого пружного стрибка та передбачення нескінченно великого напруження при східчастій деформації.
5. **Стандартне лінійне тіло Знера (SLS):** Мінімальна фізично повноцінна модель в'язкопружного твердого тіла. Об'єднує миттєву пружну деформацію (завдяки нерелаксованому модулю `E_U`), обмежену повзучість (завдяки рівноважному модулю `E_R`) та скінченну релаксацію напружень. Вона має два різні часові параметри: час релаксації при сталому зміщенні `τ_σ` та час затримки при сталому навантаженні `τ_ε`.
6. **Узагальнена модель Максвелла (Ряд Проні):** Найпотужніший феноменологічний апарат, що використовується в інженерній практиці. Вона складається з рівноважної пружини `G_∞` та масиву з `N` паралельних віток Максвелла, кожна з яких має власний модуль `G_i` та час релаксації `τ_i`. Сума вагових модулів описує миттєву жорсткість `G_0 = G_∞ + ∑ G_i`. Ряд Проні дає змогу апроксимувати реальні полімерні спектри в діапазоні від мілісекунд до років.

### Фізичний розбір реологічних властивостей за класами

1. **Аморфні термопласти (ПММА, Полістирол, Полікарбонат):** При кімнатній температурі (`T < T_g`) перебувають у склоподібному стані. Їхній миттєвий модуль Юнга високий (`E_0 ~ 3 ГПа`), а релаксаційні процеси дуже повільні. При нагріванні вище температури склування (`T_g ≈ +105 °C` для ПММА) модуль падає на три порядки величини, переходячи у високоеластичне плато. Температурна залежність часу релаксації точно підпорядковується рівнянню WLF з константами `C₁ ≈ 17.4`, `C₂ ≈ 51.6 К`.
2. **Частково кристалічні полімери (ПЕНП, ПЕВЕД, Найлон-66):** Складаються з аморфних ділянок та кристалічних ламелей. Оскільки робоча температура більшості з них вища за температуру склування аморфної фази (`T_g = -120 °C` для поліетилену), вони демонструють постійну повзучість навіть при кімнатній температурі. Їхня температура зсуву описується рівнянням Арреніуса з енергією активації `E_a ~ 30 ... 60 кДж/моль`.
3. **Еластомери та каучуки (Нітрильний NBR, Силіконовий PDMS, Натуральний каучук):** Редкозшиті вулканізовані сітки. Їхня температура склування глибоко від'ємна (`T_g = -40 ... -125 °C`), тому при кімнатній температурі вони перебувають у високоеластичному стані. Миттєвий модуль `G_0` визначається розтягом міжвузлових сегментів, а рівноважний модуль `G_∞` — ентропійною пружністю зшитої сітки.
4. **Біологічні тканини (Суглобовий хрящ, стінки аорти, зв'язки):** Вони є двофазними гідратованими композитами. Понад 75% їхнього об'єму становить міжклітинна рідина, затиснута всередині негативно зарядженого протеогліканового гелю та колагенової сітки. Релаксація напружень у суглобовому хрящі обумовлена фільтраційним витіканням рідини крізь нанорозмірні пори. Це забезпечує унікальну амортизацію: при миттєвому ударі під час стрибка хрящ поводиться як тверде тіло (`E_0 ~ 10 МПа`), а при сталій вазі повільно осідає до рівноважного стану (`E_∞ ~ 0.6 МПа`).
5. **Метали та припої при високих температурах (SAC305, Inconel 718):** При гомологічних температурах `T / T_melt > 0.4` у металах активуються дифузійні процеси. У безсвинцевих припоях SAC305 (Sn-3.0Ag-0.5Cu) при `125 °C` (`T / T_melt ≈ 0.8`) час релаксації становить лише 12 секунд. Це спричиняє швидку релаксацію напружень у кулькових виводах (BGA) мікросхем при термоциклюванні, що призводить до втомного тріщиноутворення. У жароміцних нікелевих суперсплавах (Inconel 718) при `650 °C` час релаксації вимірюється годинами, що визначає термін служби лопаток газових турбін.

## 3. Методів експериментальної реолометрії

Огляд п'яти стандартних експериментальних методик вимірювання в'язкопружних властивостей.

### 3.1. Динамічний механічний аналіз (DMA / ДМА)
- **Принцип:** Прикладання малоамплітудної гармонічної деформації `ε(t) = ε₀ sin(ωt)` або напруження `σ(t) = σ₀ sin(ωt)` у режимі вигину, розтягу чи зсуву.
- **Вимірювані величини:** Модуль накопичення `G'(ω)`, модуль втрат `G''(ω)`, тангенс механічних втрат `tan(δ)`.
- **Сфера застосування:** Визначення температури склування `T_g`, побудова температурно-частотних спектрів, розрахунок коефіцієнтів WLF.
- **Стандарти:** ASTM E1640, ISO 6721.

### 3.2. Випробування на повзучість (Creep Test)
- **Принцип:** Миттєве прикладання та утримання сталого напруження `σ = σ₀` із вимірюванням зростання деформації `ε(t)` протягом тривалого часу (від годин до років).
- **Вимірювані величини:** Податливість повзучості `J(t) = ε(t) / σ₀`, межа тривалої міцності, швидкість усталеної повзучості `dε/dt`.
- **Сфера застосування:** Прогнозування довговічності пластикових труб, будівельних елементів, лопаток турбін та затяжки болтів.
- **Стандарти:** ASTM D2990, ISO 899.

### 3.3. Випробування на релаксацію напружень (Stress Relaxation Test)
- **Принцип:** Миттєве прикладання сталого зміщення / деформації `ε = ε₀` із вимірюванням спадання спадаючого зусилля `σ(t)`.
- **Вимірювані величини:** Модуль релаксації `E(t) = σ(t) / ε₀`, час релаксації `τ`.
- **Сфера застосування:** Розрахунок втрати зусилля в силіконових ущільнювальних кільцях, прокладках ГБЦ, роз'ємних з'єднаннях.
- **Стандарти:** ASTM E328, ISO 3384.

### 3.4. Ротаційна зсувна реометрія (Torsional Shear Rheometry)
- **Принцип:** Зсув рідкого або високопластичного матеріалу між конусом і плашкою або паралельними дисками.
- **Вимірювані величини:** Динамічна в'язкість `η*(ω)`, перша та друга різниці нормальних напружень `N₁`, `N₂`.
- **Сфера застосування:** Розплави полімерів, фарби, гелі, нафтові мастила, екструзійні пасти.
- **Стандарти:** ASTM D4440, ISO 3219.

### 3.5. Наноіндентування та повзучість індентора (Nanoindentation Creep)
- **Принцип:** Вдавлювання гострого індентора (Берковича або сферичного) в поверхню тонкої плівки або мікроструктури із заданою силою `F₀`.
- **Вимірювані величини:** В'язкопружний модуль контактного зсуву, глибина повзучості `h(t)`.
- **Сфера застосування:** Тонкі плівки покриттів, біологічні клітини, живі тканини, мікроелектронні з'єднання.
- **Стандарти:** ISO 14577.

## 4. Специфікація параметрів ряду Проні для FEA (Abaqus / ANSYS)

У пакетах скінченноелементного аналізу (FEA) в'язкопружність ізотропного матеріалу задається через безрозмірні коефіцієнти ряду Проні для модуля зсуву `g_i = G_i / G_0` та об'ємного модуля `k_i = K_i / K_0`:

```
g(t) = 1 - ∑_{i=1}^N g_i · [1 - exp(-t / τ_i^g)]
k(t) = 1 - ∑_{i=1}^N k_i · [1 - exp(-t / τ_i^k)]
```

де `G_0` та `K_0` — миттєві модулі при `t = 0`. Умова фізичної коректності вимагає:

```
∑_{i=1}^N g_i < 1.0   та   ∑_{i=1}^N k_i < 1.0
```

### Приклад файлу вхідних даних для солевера Abaqus (*VISCOELASTIC)

```text
*MATERIAL, NAME=PMMA_VISCOELASTIC
*ELASTIC
 3.2E9, 0.35
*VISCOELASTIC, TIME=PRONY
 0.15625, 0.15625, 0.10
 0.09375, 0.09375, 1.00
 0.04688, 0.04688, 10.00
*TRS, DEFINITION=WLF
 105.0, 17.44, 51.60
```

У наведеному блоці:
- Блок `*ELASTIC` задає мгновенний модуль Юнга `E₀ = 3.2 ГПа` та коефіцієнт Пуассона `ν = 0.35`;
- Блок `*VISCOELASTIC` містить три строки параметрів `g_i, k_i, τ_i`;
- Блок `*TRS, DEFINITION=WLF` задає температурно-часову суперпозицію WLF з опорною температурою склування `T_g = 105 °C` та константами `C₁ = 17.44`, `C₂ = 51.60 К`.
