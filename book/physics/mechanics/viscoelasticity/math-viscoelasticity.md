# 🧮 Математичний апарат в'язкопружності

Математичний опис в'язкопружності будується на поєднанні двох протилежних конститутивних законів механіки суцільних середовищ: лінійної пружності Гука та лінійної в'язкості Ньютона. Головне математичне завдання полягає у формулюванні диференціальних та інтегральних рівнянь, що пов'язують напруження `σ`, деформацію `ε` та їхні похідні за часом `dσ/dt`, `dε/dt`.

## 1. Фундаментальні елементи та одиниці вимірювання

Суто пружний елемент (ідеалізована пружина) описує миттєве зворотно накопичення механічної енергії. Напруження `σ(t)` (вимірюване в паскалях, Па = Н/м²) прямо пропорційне безрозмірній деформації `ε(t)`:

```
σ(t) = E · ε(t)
```

де `E` — модуль Юнга (Па). Потенціальна енергія, збережена в одиниці об'єму пружини, дорівнює `U = (1/2) E ε²`.

Суто в'язкий елемент (ідеалізований демпфер або поршень у в'язкій рідині) описує незворотну дисипацію механічної роботи в тепло через внутрішнє тертя. Напруження пропорційне швидкості деформації `dε/dt` (вимірюваній у с⁻¹):

```
σ(t) = η · (dε(t) / dt)
```

де `η` — коефіцієнт динамічної в'язкості (Па·с). Дисипована потужність в одиниці об'єму становить `P = η (dε/dt)²`.

## 2. Модель Максвелла (послідовне з'єднання)

У моделі Максвелла пружина та демпфер з'єднані в єдиний послідовний ланцюг. Оскільки елементи з'єднані послідовно, силовий потік через кожен із них є однаковий, тож напруження в обох елементах збігається з загальним напруженням `σ`:

```
σ_e(t) = σ_v(t) = σ(t)
```

Загальна деформація `ε` складається із суми пружної деформації пружини `ε_e` та в'язкої деформації поршня `ε_v`:

```
ε = ε_e + ε_v
```

Взявши похідну за часом від обох частин, отримуємо рівняння для швидкостей деформації:

```
dε/dt = dε_e/dt + dε_v/dt
```

З закону Гука маємо `ε_e = σ / E`, тому `dε_e/dt = (1/E) · (dσ/dt)`. З закону Ньютона швидкість в'язкого зсуву `dε_v/dt = σ / η`.

Підставляючи ці вирази у сумарну швидкість, виводимо конститутивне диференціальне рівняння моделі Максвелла:

```
dε/dt = (1/E) · (dσ/dt) + σ / η
```

### Аналітичний розв'язок для релаксації напружень

Розглянемо випробування на релаксацію. У момент часу `t = 0` зразок миттєво деформують до значення `ε₀` і утримують цю деформацію строго сталою протягом усього експерименту (`ε(t) = ε₀` при `t ≥ 0`).

Оскільки деформація зафіксована, швидкість її зміни дорівнює нулю (`dε/dt = 0`). Рівняння Максвелла спрощується до звичайного диференціального рівняння першого порядку з відокремлюваними змінними:

```
(1/E) · (dσ/dt) + σ / η = 0
```

Перенесемо доданок із напруженням у праву частину і розділимо змінні:

```
(1 / σ) dσ = - (E / η) dt
```

Введемо характеристичний параметр моделі — **час релаксації Максвелла** `τ_R = η / E` (вимірюється в секундах). Рівняння набуває вигляду:

```
(1 / σ) dσ = - (1 / τ_R) dt
```

Інтегруємо обидві частини від початкового моменту `t = 0` (де напруження дорівнює миттєвому пружному відгуку пружини `σ(0) = σ₀ = E · ε₀`) до довільного моменту `t`:

```
∫_{σ₀}^{σ(t)} (1 / σ) dσ = - ∫₀^t (1 / τ_R) dt
ln(σ(t) / σ₀) = - t / τ_R
σ(t) = σ₀ · exp(- t / τ_R)
```

Поділивши напруження `σ(t)` на величину сталої деформації `ε₀`, дістаємо часову функцію **модуля релаксації** `E(t)`:

```
E(t) = E · exp(- t / τ_R)
```

Цей результат показує, що в моделі Максвелла напруження експоненціально прямує до нуля при `t → ∞`. За час `t = τ_R` напруження спадає в `e ≈ 2.718` рази (на 63.2%).

### Аналітичний розв'язок для повзучості

Розглянемо випробування на повзучість. У момент `t = 0` до матеріалу прикладають стале напруження `σ(t) = σ₀` (`σ = const`).

Оскільки напруження не змінюється в часі, його похідна дорівнює нулю (`dσ/dt = 0`). Рівняння Максвелла набуває вигляду:

```
dε/dt = σ₀ / η
```

Інтегруємо це рівняння за часом від `t = 0` до `t`:

```
ε(t) = ε(0) + (σ₀ / η) · t
```

Початкова деформація `ε(0)` визначається миттєвим розтягом пружини `ε(0) = σ₀ / E`. Остаточно отримуємо:

```
ε(t) = σ₀ / E + (σ₀ / η) · t
```

Визначаємо **податливість повзучості** `J(t) = ε(t) / σ₀`:

```
J(t) = 1 / E + t / η
```

Цей результат висвітлює обмеженість моделі Максвелла для опису твердих тіл: деформація повзучості зростає нескінченно й лінійно за часом, тобто матеріал тече як рідина.

## 3. Модель Кельвіна-Фойгта (паралельне з'єднання)

У моделі Кельвіна-Фойгта пружина й демпфер з'єднані паралельно. Через паралельне сполучення деформація обох елементів є тотожною і дорівнює загальній деформації матеріалу:

```
ε_e(t) = ε_v(t) = ε(t)
```

Загальне напруження `σ` дорівнює сумі сил, які виникають у пружині та демпфері:

```
σ(t) = σ_e(t) + σ_v(t)
σ(t) = E · ε(t) + η · (dε(t) / dt)
```

### Аналітичний розв'язок для повзучості

При сталій навантаженій силі `σ(t) = σ₀` конститутивне рівняння стає неоднорідним лінійним диференціальним рівнянням першого порядку відносно деформації `ε(t)`:

```
η · (dε/dt) + E · ε = σ₀
(dε/dt) + (E / η) · ε = σ₀ / η
```

Уведемо **час затримки (ретардації) Кельвіна-Фойгта** `τ_D = η / E`. Рівняння набуває виляду:

```
(dε/dt) + (1 / τ_D) · ε = σ₀ / η
```

Для розв'язання використовуємо метод інтегрувального множника `exp(t / τ_D)`:

```
d/dt [ε(t) · exp(t / τ_D)] = (σ₀ / η) · exp(t / τ_D)
```

Інтегруємо обидві частини від `t = 0` до `t` з початковою умовою `ε(0) = 0` (демпфер у перший момент унеможливлює миттєву деформацію):

```
ε(t) · exp(t / τ_D) = (σ₀ / η) · τ_D · [exp(t / τ_D) - 1]
```

Оскільки `(σ₀ / η) · τ_D = (σ₀ / η) · (η / E) = σ₀ / E`, дістаємо:

```
ε(t) = (σ₀ / E) · [1 - exp(- t / τ_D)]
```

Податливість повзучості `J(t)` дорівнює:

```
J(t) = (1 / E) · [1 - exp(- t / τ_D)]
```

При `t → ∞` деформація прагне до асимптотичної межі `ε_∞ = σ₀ / E`. Модель Кельвіна-Фойгта чудово описує обмежену повзучість твердого тіла, проте зовсім не містить миттєвого пружного стрибка.

## 4. Стандартне лінійне тіло (Модель Зенера)

Модель Зенера (Standard Linear Solid, SLS) є найпростішою системою, що позбавлена недоліків моделей Максвелла та Кельвіна-Фойгта. Вона складається з пружини `E₀` (тривалий рівноважний модуль), підключеної паралельно до послідовної вітки Максвелла з елементами `E₁` та `η₁`.

Конститутивне диференціальне рівняння моделі Зенера має симетричний вигляд:

```
σ + τ_σ · (dσ/dt) = E_R · [ε + τ_ε · (dε/dt)]
```

де введені такі величини:
- `E_R = E₀` — тривалий рівноважний модуль при `t → ∞`;
- `E_U = E₀ + E₁` — мгновенний модуль при `t = 0`;
- `τ_σ = η₁ / E₁` — час релаксації напружень при зафіксованій деформації;
- `τ_ε = η₁ · (E₀ + E₁) / (E₀ · E₁) = τ_σ · (E_U / E_R)` — час затримки деформації при сталому напруженні.

Модуль релаксації Зенера `E(t)` при східчастій деформації `ε₀`:

```
E(t) = E_R + (E_U - E_R) · exp(- t / τ_σ)
```

Податливість повзучості Зенера `J(t)` при східчастому напруженні `σ₀`:

```
J(t) = J_U + (J_R - J_U) · [1 - exp(- t / τ_ε)]
```

де `J_U = 1 / E_U` — миттєва податливість, а `J_R = 1 / E_R` — рівноважна тривала податливість.

## 5. Гармонічний осциляційний режим та комплексний модуль

У динамічному механічному аналізі (DMA) на зразок діють гармонічною деформацією із круговою частотою `ω`:

```
ε(t) = ε₀ · sin(ωt)
```

У сталеному режимі напруження зміщене за фазою на кут `δ`:

```
σ(t) = σ₀ · sin(ωt + δ)
```

Розкладаємо синус суми:

```
σ(t) = σ₀ · [sin(ωt)·cos(δ) + cos(ωt)·sin(δ)]
σ(t) = ε₀ · [E'(ω) · sin(ωt) + E''(ω) · cos(ωt)]
```

Вводимо складові модулі:
- **Модуль накопичення (Storage Modulus):** `E'(ω) = (σ₀ / ε₀) · cos(δ)`
- **Модуль втрат (Loss Modulus):** `E''(ω) = (σ₀ / ε₀) · sin(δ)`

У комплексній формі `ε(t) = ε₀ · exp(i·ωt)` та `σ(t) = σ₀ · exp(i·(ωt + δ))`:

```
E*(ω) = σ(t) / ε(t) = (σ₀ / ε₀) · exp(i·δ) = E'(ω) + i · E''(ω)
```

Тангенс кута механічних втрат:

```
tan(δ) = E''(ω) / E'(ω)
```

### Комплексний модуль для моделі Зенера

Підставивши гармонічні функції у диференціальне рівняння Зенера, отримуємо:

```
σ* · [1 + i · ω · τ_σ] = ε₀ · E_R · [1 + i · ω · τ_ε]

E*(ω) = E_R · [1 + i · ω · τ_ε] / [1 + i · ω · τ_σ]
```

Домножуємо на комплексне спряжене `(1 - i · ω · τ_σ)` і розділяємо дійсну та уявну частини:

```
E'(ω) = E_R + (E_U - E_R) · (ω² · τ_σ²) / (1 + ω² · τ_σ²)

E''(ω) = (E_U - E_R) · (ω · τ_σ) / (1 + ω² · τ_σ²)
```

## 6. Інтеграл суперпозиції Больцмана

Для довільної безперервної історії деформацій `ε(t)` загальне напруження описується спадковим інтегралом Больцмана:

```
σ(t) = ∫_{-∞}^t E(t - τ) · (dε(τ) / dτ) · dτ
```

Якщо в момент `t = 0` виник скачок деформації `Δε₀`, інтеграл набирає вигляду:

```
σ(t) = Δε₀ · E(t) + ∫₀^t E(t - τ) · (dε(τ) / dτ) · dτ
```

Дзеркально, якщо задано історію напружень `σ(t)`, деформацію обчислюють через податливість `J(t)`:

```
ε(t) = Δσ₀ · J(t) + ∫₀^t J(t - τ) · (dσ(τ) / dτ) · dτ
```

## 7. Рівняння Вільямса-Ландела-Феррі (WLF)

При зміні температури `T` всі часи релаксації `τ_i` масштабуються на коефіцієнт зсуву `a_T(T)`:

```
τ_i(T) = a_T(T) · τ_i(T₀)
```

де `T₀` — опорна температура (температура склування `T_g`).

Для аморфних полімерів у діапазоні від `T_g` до `T_g + 100 °C` коефіцієнт зсуву обчислюють за рівнянням WLF:

```
log₁₀ a_T = - C₁ · (T - T₀) / [C₂ + (T - T₀)]
```

Для багатьох аморфних полімерів при `T₀ = T_g` емпіричні константи приймають значення `C₁ ≈ 17.44` та `C₂ ≈ 51.6 К`.
