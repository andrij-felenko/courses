# 🧮 Математичний апарат осцилятора Дуффінга: теорія збурень, метод гармонічного балансу та інтеграл Мельникова

Математичний аналіз нелінійного осцилятора Дуффінга вимагає поєднання аналітичних методів теорії збурень, гармонічного балансу та якісної теорії диференціальних рівнянь для знаходження спектра частот, побудови амплітудно-частотних характеристик та розрахунку точної межі виникнення хаосу.

Цей документ містить повний математичний вивід та аналітичний апарат усіх ключових властивостей системи.

---

### 1. Автономний осцилятор Дуффінга: інтеграл енергії та метод Ліндштедта-Пуанкаре

Розглянемо вільний нелінійний осцилятор Дуффінга без згасання (`δ = 0`) та без зовнішнього періодичного збудження (`γ = 0`). Формально це динамічна система з одним ступенем вільності, описувана диференціальним рівнянням другого порядку:

```
d²x/dt² + α·x + β·x³ = 0
```

#### Інтеграл енергії та нелінійний потенціал

Оскільки система є автономною та консервативною, для неї існує точний перший інтеграл руху — повна механічна енергія. Щоб вивести його, помножимо обидві частини диференціального рівняння на миттєву швидкість `v = dx/dt`:

```
v·(d²x/dt²) + α·x·v + β·x³·v = 0
```

Зауваживши, що `v·(d²x/dt²) = (1/2)·d(v²)/dt`, `x·(dx/dt) = (1/2)·d(x²)/dt`, а `x³·(dx/dt) = (1/4)·d(x⁴)/dt`, згортаємо ліву частину в повну похідну за часом:

```
d/dt [ (1/2)·v² + (1/2)·α·x² + (1/4)·β·x⁴ ] = 0
```

Інтегруючи це співвідношення за часом, отримуємо закон збереження повної механічної енергії:

```
E = (1/2)·v² + V(x) = const
V(x) = (1/2)·α·x² + (1/4)·β·x⁴
```

де `V(x)` є нелінійною потенціальною функцією. 

Розглянемо амплітуду коливань `A`, тобто максимальне відхилення координати, у якому миттєва швидкість звертається в нуль (`v(A) = 0`). Підставляючи `x = A` та `v = 0` у вираз для повної енергії, отримуємо значення константи енергії через амплітуду:

```
E = (1/2)·α·A² + (1/4)·β·A⁴
```

Виразивши миттєву швидкість `v = dx/dt` із закону збереження енергії, отримуємо перше диференціальне рівняння з відокремлюваними змінними:

```
v = dx/dt = ± √[ 2·(E - V(x)) ]
  = ± √[ α·(A² - x²) + (1/2)·β·(A⁴ - x⁴) ]
```

Точний період коливань `T` визначається як час, необхідний для здійснення одного повного циклу. За симетрією потенціалу `V(-x) = V(x)`, час руху від `x = 0` до `x = A` становить чверть повного періоду `T/4`:

```
T = 4 · ∫₀ᴬ dx / √[ α·(A² - x²) + (1/2)·β·(A⁴ - x⁴) ]
```

Для малого параметра нелінійності цей неелементарний інтеграл зводиться до повного еліптичного інтеграла першого роду `K(k)`.

#### Метод Ліндштедта-Пуанкаре для слабкої нелінійності

Звичайний класичний розклад розв'язку в ряд за малим параметром `β = ε·β'` видами `x(t) = x₀(t) + ε·x₁(t) + ...` зазнає математичного тупика. Через наявність резонансних членів на першому ж кроці виникають секулярні члени видами `t·sin(ω₀t)`, які безмежно зростають при `t → ∞` і руйнують фізичний зміст періодичного руху.

Метод Ліндштедта-Пуанкаре усуває секулярні члени шляхом введення безрозмірного масштабу часу `τ = ω·t` та одночасного розкладу невідомої частоти коливань `ω` в степеневий ряд за малим параметром `ε`:

```
x(τ) = x₀(τ) + ε·x₁(τ) + ε²·x₂(τ) + ...
ω = ω₀ + ε·ω₁ + ε²·ω₂ + ...
```

де `ω₀ = √α` — власна лінійна частота малих коливань. Заміна змінної часу перетворює оператор другої похідної:

```
d²/dt² = ω² · d²/dτ²
```

Підставляючи ці розклади у вихідне рівняння осцилятора Дуффінга `ω²·(d²x/dτ²) + α·x + ε·β'·x³ = 0`, збираємо члени при однаковісіньких степенях малого параметра `ε`.

##### Рівняння нульового порядку ε⁰:
```
ω₀² · (d²x₀/dτ²) + α·x₀ = 0
```
Оскільки `ω₀² = α`, це звичайне рівняння лінійного гармонічного осцилятора. За початкових умов `x₀(0) = A` та `(dx₀/dτ)(0) = 0` його розв'язок має вигляд:
```
x₀(τ) = A · cos(τ)
```

##### Рівняння першого порядку ε¹:
```
ω₀² · (d²x₁/dτ²) + α·x₁ = - 2·ω₀·ω₁ · (d²x₀/dτ²) - β'·x₀³
```

Підставляємо знайдений розв'язок нульового порядку `x₀(τ) = A·cos(τ)` та його другу похідну `d²x₀/dτ² = -A·cos(τ)`. Для кубічного члена застосовуємо тригонометричну тотожність потрійного аргументу `cos³(τ) = (3/4)·cos(τ) + (1/4)·cos(3τ)`:

```
ω₀² · (d²x₁/dτ²) + α·x₁ 
= 2·ω₀·ω₁·A · cos(τ) - β'·A³ · [ (3/4)·cos(τ) + (1/4)·cos(3τ) ]
= [ 2·ω₀·ω₁·A - (3/4)·β'·A³ ] · cos(τ) - (1/4)·β'·A³ · cos(3τ)
```

Права частина містить гармоніку `cos(τ)`, яка збігається з власною частотою лівої частини. Саме вона генерує небажані секулярні члени. Вимагаючи, щоб коефіцієнт при `cos(τ)` дорівнював суворо нулю (умова відсутності секулярності), отримуємо першу поправку до частоти `ω₁`:

```
2·ω₀·ω₁·A - (3/4)·β'·A³ = 0
ω₁ = (3·β'·A²) / (8·ω₀)
```

Повертаючись від малого параметра `ε·β'` до початкового коефіцієнта нелінійності `β`, отримуємо точний аналітичний вираз для частоти нелінійних коливань осцилятора Дуффінга в першому наближенні:

```
ω(A) = ω₀ + (3·β·A²) / (8·ω₀) + O(β²)
     = √α + (3·β·A²) / (8·√α) + O(β²)
```

Цей фундаментальний результат показує, що залежність частоти від амплітуди має квадратний характер: для жорсткої пружини (`β > 0`) частота зростає з амплітудою, а для м'якої (`β < 0`) — зменшується.

### 2. Вимушені коливання та метод гармонічного балансу

Розглянемо вимушений затухаючий осцилятор Дуффінга під дією зовнішнього гармонічного збудження:

```
ẍ + δ·ẋ + α·x + β·x³ = γ·cos(ω·t)
```

#### Вивід амплітудно-частотного рівняння

Шукаємо стаціонарний періодичний розв'язок на частоті збудження `ω` у вигляді першої гармоніки із невідомим зсувом фази `φ`:

```
x(t) = A · cos(ω·t - φ)
```

Обчислимо першу та другу похідні за часом, а також кубічну нелінійність:

```
ẋ(t) = - A·ω · sin(ω·t - φ)
ẍ(t) = - A·ω² · cos(ω·t - φ)
x³(t) = A³ · [ (3/4)·cos(ω·t - φ) + (1/4)·cos(3·(ω·t - φ)) ]
```

У першому наближенні методу гармонічного балансу ми нехтуємо вищою гармонікою `cos(3·(ω·t - φ))`, оскільки її амплітуда мала, а частота знаходиться далеко від резонансу. Підставляємо вирази у вихідне диференціальне рівняння:

```
- A·ω²·cos(ψ) - δ·A·ω·sin(ψ) + α·A·cos(ψ) + (3/4)·β·A³·cos(ψ) = γ·cos(ψ + φ)
```

де позначено `ψ = ω·t - φ`. Розкриваємо праву частину за формулою косинуса суми: `γ·cos(ψ + φ) = γ·cos(ψ)·cos(φ) - γ·sin(ψ)·sin(φ)`. Прирівнюючи коефіцієнти при квадратурних складових `cos(ψ)` та `sin(ψ)` окремо, отримуємо систему двох алгебраїчних рівнянь:

```
[ (α + (3/4)·β·A² - ω²) · A ] = γ · cos(φ)      [синфазна складова]
[ δ·ω · A ] = γ · sin(φ)                         [квадратурна складова]
```

Підносячи обидва рівняння до квадрата та складаючи їх разом (`cos²(φ) + sin²(φ) = 1`), вилучаємо зсув фази `φ`:

```
[ (α + (3/4)·β·A² - ω²) · A ]² + [ δ·ω · A ]² = γ²
```

Це рівняння є нелінійним алгебраїчним зв'язком між амплітудою коливань `A` та частотою зовнішнього збудження `ω`.

#### Скелетна крива та аналіз двостабільності

За відсутності дисипації (`δ = 0`) амплітуда коливань розганяється до нескінченності, коли перший вираз у квадратних дужках звертається в нуль. Це задає так звану **скелетну криву** (або хребтовий графік):

```
α + (3/4)·β·A² - ω² = 0
ω_skel(A) = √[ α + (3/4)·β·A² ]
```

Скелетна крива є «хребтом», навколо якого вигинається резонансний пік. Оскільки для жорсткої пружини `β > 0`, скелетна крива відхиляється праворуч у бік вищих частот. Це призводить до появи діапазону частот `[ω₁, ω₂]`, у якому рівняння для `A²` має три дійсних корені.

### 3. Двоямний потенціал: гомоклінічна сепаратриса та точний розв'язок

У випадку двоямного потенціалу параметр лінійної жорсткості від'ємний `α = -|α| < 0`, а кубічний позитивний `β > 0`.

```
V(x) = - (1/2)·|α|·x² + (1/4)·β·x⁴
```

Особливі точки знаходяться з умови нуля відновлювальної сили `dV/dx = 0`:

```
- |α|·x + β·x³ = 0   =>   x₁ = 0,  x₂,,₃ = ± √[ |α| / β ]
```

Точка `x = 0` є нестійким сідлом, а точки `x = ±√(|α|/β)` — стійкими центрами потенціальних ям.

Повна енергія на рівні сідла дорівнює `E = V(0) = 0`. Рівняння траєкторії, що з'єднує сідло саме з собою (гомоклінічна сепаратриса), виводиться з рівняння енергії:

```
(1/2)·v² - (1/2)·|α|·x² + (1/4)·β·x⁴ = 0
v² = |α|·x² - (1/2)·β·x⁴
```

Відокремлюючи змінні `dx/dt = ± x · √[ |α| - (1/2)·β·x² ]` та інтегруючи за допомогою гіперболічної підстановки, отримуємо точні аналітичні вирази для гомоклінічної координати та швидкості:

```
x₀(t) = √[ (2·|α|) / β ] · sech(√|α| · t)
v₀(t) = - √[ (2·|α|²) / β ] · sech(√|α| · t) · tanh(√|α| · t)
```

Ці розв'язки описують безкінечно тривалу сепаратрисну петлю у фазовому просторі.

### 4. Метод Мельникова: математичний критерій виникнення хаосу

При додаванні малого згасання `ε·δ` та малої зовнішньої сили `ε·γ·cos(ω·t)` гомоклінічна петля розпадається. Інваріантні стійкий `Wˢ` та нестійкий `Wᵘ` многовиди сідла розходяться.

Функція Мельникова `M(t₀)` задає зі знаком ортогональну відстань між многовидами `Wˢ` та `Wᵘ` у фазовому просторі:

```
M(t₀) = ∫₋∞⁺∞ v₀(t) · [ - δ·v₀(t) + γ·cos(ω·(t + t₀)) ] dt
```

Розбиваємо інтеграл на дві складові `M(t₀) = - I_дисипації + I_збудження(t₀)`:

##### 1. Дисипативна складова:
```
I_дисипації = δ · ∫₋∞⁺∞ v₀²(t) dt = (4·δ·|α|^(3/2)) / (3·β)
```

##### 2. Складова зовнішнього збудження:
За допомогою теореми про лишки в комплексній площині обчислюємо інтеграл від секанса та тангенса:
```
I_збудження(t₀) = γ · π·ω · √[ 2 / β ] · sech[ (π·ω) / (2·√|α|) ] · sin(ω·t₀)
```

#### Критична амплітуда хаосу

Умова виникнення трансверсального перетину многовидів `Wˢ` та `Wᵘ` (що за теоремою Смейла-Беркгофа означає появу хаотичного атрактора) полягає в тому, що амплітуда гармонічної частини `I_збудження` повинна перевищувати згасання `I_дисипації`. Це задає точну критичну формулу для межі хаосу:

```
γ_crit = [ (4 · δ · |α|^(3/2)) / (3 · π · ω · √(2·β)) ] · cosh[ (π · ω) / (2 · √|α|) ]
```

При `γ > γ_crit` у системі Дуффінга невідворотно виникають міжямні хаотичні коливання.
