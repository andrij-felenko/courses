# 🧮 Математична теорія ренормалізаційного оператора Фейгенбаума

Математичне пояснення універсальності каскаду подвоєння періоду спирається на концепцію оператора ренормалізації в нескінченновимірному функціональному просторі. Ця вставка містить строгий аналітичний розрахунок непорушної точки оператора Фейгенбаума — Цвітановича, обчислення універсальних констант `α` та `δ`, аналіз спектра лінеаризованого оператора, а також розгляд строгого доведення Оскара Ланфорда за допомогою інтервальної арифметики.

## 1. Функціональний простір та оператор ренормалізації

Розглянемо Банахів простір `ℋ` парних аналітичних функцій `f: I → I` на симетричному інтервалі `I = [-1, 1]`, які задовольняють наступним геометричним та аналітичним умовам:
1. **Нормування максимуму:** `f(0) = 1` (значення у вершині екстремуму зафіксоване на одиниці).
2. **Квадратична вершина:** `f'(0) = 0` та `f''(0) < 0` (гладкий параболічний максимум у точці `x = 0`).
3. **Парність (симетрія):** `f(-x) = f(x)` для всіх `x ∈ I`.
4. **Унімодальність:** Функція є строго монотонно спадною на напівінтервалі `(0, 1]`.

Оператор ренормалізації Твіса — Фейгенбаума — Каданова `T: ℋ → ℋ` діє на довільну функцію `f(x) ∈ ℋ` за допомогою двокрокової нелінійної процедури:
* **Перший крок (подвійна ітерація):** Формування другої ітерації відображення `f⁽²⁾(x) = f(f(x))`. Якщо початкова функція має один максимум, то її друга ітерація `f⁽²⁾(x)` поблизу нуля має два локальних максимуми і один мінімум, утворюючи рельєф з чотирма екстремумами.
* **Другий крок (масштабування):** Стиснення координати `x` та дзеркальне інвертування амплітуди на універсальний масштабний коефіцієнт `α`:

```
T f(x) = -α · f( f( x / (-α) ) )
```

Умова збереження нормування `T f(0) = 1` дає перше фундаментальне алгебраїчне співвідношення для константи `α`:

```
T f(0) = -α · f( f(0) )
= -α · f(1) = 1
```

Звідси отримуємо строгий аналітичний зв'язок між константою `α` та значенням функції на межі інтервалу `x = 1`:

```
α = -1 / f(1)
```

Оскільки для унімодальних відображень `f(1) < 0`, константа `α` є додатною величиною `α ≈ 2.5029...`, а масштабний фактор стиснення координат дорівнює `-α ≈ -2.5029...` (знак «мінус» забезпечує дзеркальну інверсію орієнтації орбіт відносно вершини).

## 2. Виведення функціонального рівняння Фейгенбаума — Цвітановича

Шукаємо універсальне граничне відображення `g(x) ∈ ℋ`, яке є непорушною точкою оператора ренормалізації: `T g(x) = g(x)`. Це приводить до функціонального **рівняння Фейгенбаума — Цвітановича**:

```
g(x) = -α · g( g( x / (-α) ) )
```

з початковими умовами `g(0) = 1`, `g'(0) = 0`.

Оскільки `g(x)` є парною аналітичною функцією, розкладемо її у статевий ряд Тейлора за парними степенями `x²`:

```
g(x) = 1 + c_2 · x² + c_4 · x⁴ + c_6 · x⁶ + c_8 · x⁸ + ...
```

Для знаходження коефіцієнтів `c_2, c_4, c_6, ...` та масштабної константи `α` застосуємо метод послідовних поліноміальних наближень.

### 2.1. Перше наближення (квадратичний поліном)

Обріжемо ряд Тейлора на другому члені: `g(x) ≈ 1 + c_2 · x²`.
Обчислимо послідовно внутрішній вираз `g(x / (-α))` та зовнішню композицію `g(g(x / (-α)))`:

```
g( x / (-α) ) = 1 + c_2 · (x / (-α))²
= 1 + (c_2 / α²) · x²

g( g( x / (-α) ) ) = 1 + c_2 · [ 1 + (c_2 / α²) · x² ]²
= 1 + c_2 · [ 1 + (2·c_2 / α²) · x² + (c_2² / α⁴) · x⁴ ]
= (1 + c_2) + (2·c_2² / α²) · x² + (c_2³ / α⁴) · x⁴
```

Підставимо отриману композицію у рівняння непорушної точки `g(x) = -α · g(g(x / (-α)))`:

```
1 + c_2 · x² = -α · (1 + c_2) - (2·α·c_2² / α²) · x² - (α·c_2³ / α⁴) · x⁴
= -α · (1 + c_2) - (2·c_2² / α) · x² + O(x⁴)
```

Прирівнюючи коефіцієнти при однакових степенях `x⁰` та `x²`, отримуємо систему нелінійних алгебраїчних рівнянь:

```
[x⁰]:  1 = -α · (1 + c_2)
[x²]:  c_2 = -2 · c_2² / α
```

З другого рівняння (оскільки `c_2 ≠ 0`) виражаємо коефіцієнт `c_2`:

```
c_2 = -α / 2
```

Підставляємо `c_2 = -α / 2` у перше рівняння для `x⁰`:

```
1 = -α · (1 - α / 2)
1 = -α + α² / 2
α² - 2·α - 2 = 0
```

Розв'язуємо отримане квадратне рівняння відносно `α`:

```
D = (-2)² - 4 · 1 · (-2) = 4 + 8 = 12
α = (2 + √12) / 2 = 1 + √3 ≈ 2.73205
```

Отже, вже у найпростішому квадратичному наближенні аналітичний розрахунок дає значення `α ≈ 2.732`, що лише на `9.1%` відрізняється від точного значення `α = 2.5029078...`!
Коефіцієнт Тейлора у першому наближенні дорівнює:

```
c_2 = -(1 + √3) / 2 ≈ -1.3660
```

### 2.2. Друге та вищі наближення

Для підвищення точності врахуємо член `c_4 · x⁴`: `g(x) = 1 + c_2 · x² + c_4 · x⁴`.
Підставляючи цей поліном у функціональне рівняння та розкладаючи композицію до `x⁴`, отримуємо систему трьох нелінійних рівнянь відносно `α`, `c_2` та `c_4`:

```
1 = -α · (1 + c_2 + c_4)
c_2 = -2 · c_2² / α - 4 · c_2 · c_4 / α
c_4 = -2 · c_2 · c_4 / α³ - (c_2³ + 4 · c_2² · c_4) / α³
```

Чисельний розв'язок цієї системи за допомогою методу Ньютона — Рафсона дає значення з високою точністю:

```
α ≈ 2.5095  (похибка менше 0.26%)
c_2 ≈ -1.5222
c_4 ≈ 0.2671
```

При збільшенні порядку Тейлорівського полінома до `x¹²` система алгебраїчних рівнянь дає абсолютну збіжність до точних значень коефіцієнтів універсальної функції Фейгенбаума — Цвітановича:

```
α = 2.502907875095892...
c_2 = -1.527632997037102...
c_4 = 0.104814494261773...
c_6 = -0.026705670525199...
c_8 = 0.002684940213180...
```

## 3. Спектиальний аналіз лінеаризованого оператора та виведення константи δ

Щоб пояснити, чому параметрична швидкість збіжності каскаду подвоєнь дорівнює `δ ≈ 4.6692...`, розглянемо лінеаризацію оператора ренормалізації `T` ув околі непорушної функції `g(x)`.

Нехай `f(x) = g(x) + h(x)` — малозбурена функція у Банаховому просторі `ℋ`, де `h(x)` являє собою нескінченно мале відхилення. Застосуємо оператор `T`:

```
T(g + h)(x) = -α · (g + h)( (g + h)( x / (-α) ) )
```

Розкладемо праворуч у лінійний Тейлорівський ряд по функціональному збуренню `h(x)`:

```
T(g + h)(x) ≈ -α · g( g(-x/α) ) - α · h( g(-x/α) ) - α · g'( g(-x/α) ) · h(-x/α)
```

Оскільки `g(x)` задовольняє рівнянню непорушної точки (`-α · g(g(-x/α)) = g(x)`), лінійний прирост збурення `h_{n+1} = T(g + h_n) - g` описується лінійним оператором Фреше `L = dT|_g`:

```
L [h](x) = -α · h( g(-x/α) ) - α · g'( g(-x/α) ) · h(-x/α)
```

Задача на власні значення та власні функції для лінеаризованого оператора Фреше `L` має вигляд:

```
L [h](x) = λ · h(x)
```

### 3.1. Спектральна структура оператора L

Спектральний аналіз оператора `L` у просторі парних аналітичних функцій показує, що точковий спектр оператора складається з:
1. **Єдиного нестійкого власного значення `λ_1 = δ > 1`:**

```
δ = 4.669201609102990...
```

2. **Нескінченного спектра стійких власних значень `|λ_i| < 1`:**
   * `λ_2 = 1 / (-α) ≈ -0.3995` (відповідає координатному зсуву та зміні масштабної шкали).
   * `λ_3 ≈ 0.101`
   * `λ_4 ≈ -0.028`
   * і далі `|λ_k| → 0` зі зростанням `k`.

### 3.2. Геометрична інтерпретація гіперболічної сідлової точки

Наявність єдиного нестійкого власного значення `δ > 1` означає, що у нескінченновимірному функціональному просторі непорушна точка `g(x)` є **сідловою точкою гіперболічного типу з корозмірністю 1** (англ. *codimension-1 saddle point*).

У просторі `ℋ` виникає наступна топологічна структура:
* **Стійке многовиддя `W^s(g)` (гіперповерхня корозмірності 1):** Множина усіх функцій, які під дією нескінченної кількості ітерацій оператора ренормалізації `T^n` притягуються до `g(x)`. Це і є **клас універсальності** відображень з квадратичним максимумом.
* **Нестійке одновимірне многовиддя `W^u(g)`:** Одновимірна крива, вздовж якої динаміка оператора `T` віддаляється від `g(x)` з показником зростання `δ^n`.

Коли ми змінюємо фізичний параметр системи `r` поблизу точки накопичення `r_∞`, однопараметрична крива `f_r(x)` перетинає стійке многовиддя `W^s(g)` у точці `r = r_∞` під деяким ненульовим кутом.

Відстань у просторі параметрів від `r_k` до критичної межі `r_∞` зменшується за законами геометричної прогресії з кроком `δ`:

```
r_∞ - r_k ≈ C · δ⁻ᵏ
```

Звідси безпосередньо випливає визначення першої константи Фейгенбаума як границі відношення сусідніх параметричних інтервалів:

```
δ = lim_{k → ∞} (r_k - r_{k-1}) / (r_{k+1} - r_k) = 4.669201609102990...
```

## 4. Доведення Ланфорда за допомогою інтервальної арифметики

Протягом кількох років після публікацій Фейгенбаума існування непорушної точки `g(x)` та властивості спектра оператора `L` залишалися аналітичною гіпотезою. Перше строге математичне доведення теореми Фейгенбаума надав американський математик Оскар Ланфорд III (англ. *Oscar Lanford III*) у 1982 році.

Доведення Ланфорда спирається на застосування **теореми Банаха про нерухому точку** в поєднанні з строгими строго підтвердженими комп'ютерними обчисленнями (англ. *computer-assisted proof*):
1. **Інтервальна арифметика:** Комп'ютерна програма обчислює межі Тейлорівських коефіцієнтів не у вигляді стандартних чисел з плаваючою комою, а у вигляді строгих чисельних інтервалів `[a_min, a_max]`, які гарантовано містять точні математичні значення з урахуванням усіх похибок округлення IEEE 754.
2. **Конструктивна область:** Ланфорд побудував кулю `B` у Банаховому просторі парних аналітичних функцій з центром у поліномі 10-го степеня.
3. **Сжимаючий оператор:** Було строго доведено, що оператор ренормалізації `T` відображає кулю `B` у її строгу внутрішню частину `T(B) ⊂ B`, а оператор Фреше `dT` є стискаючим відображенням на цій кулі.

Згідно з теоремою Банаха, це гарантує існування єдиної непорушної аналітичної функції `g(x) ∈ B` та існування єдиного нестійкого власного значення `δ = 4.6692...`.

## 5. Залежність констант від порядку екстремуму (класи універсальності)

Універсальні константи `δ = 4.6692...` та `α = -2.5029...` розраховані для відображень з **квадратичним максимумом** (`z = 2`, `f(x) ≈ 1 - c · |x|²`).

Якщо нелінійне відображення має максимум іншого степеня гладкості `z > 1` (`f(x) ≈ 1 - c · |x|^z`), функціональне рівняння Фейгенбаума — Цвітановича зберігає свій вигляд, але значення універсальних констант змінюються:

| Порядок екстремуму `z` | Тип гладкості вершини | Константа `δ` | Константа `α` |
| :--- | :--- | :--- | :--- |
| `z = 1.1` | Дробовий степінь | `1.6441` | `-1.3102` |
| `z = 2.0` | **Параболічний (квадратичний)** | **`4.6692`** | **`-2.5029`** |
| `z = 4.0` | Четвертого степеня (`x⁴`) | `7.2846` | `-1.6903` |
| `z = 6.0` | Шостого степеня (`x⁶`) | `9.2962` | `-1.4677` |
| `z → ∞` | Прямокутний максимум | `→ ∞` | `→ -1.0000` |

Таким образом, порядок екстремуму `z` строго визначає **клас універсальності** динамічної системи: усі фізичні системи, що мають гладкий квадратичний максимум (`z = 2`), підпорядковуються канонічним константам Фейгенбаума `δ ≈ 4.6692` та `α ≈ -2.5029`.
