# 🧮 Символічна динаміка, гіперболічність та топологічна спряженість підкови Смейла

Ця математична вставка містить строгі формальні докази топологічної спряженості між інваріантною множиною відображення підкови Смейла та зсувом Бернуллі на просторі двійкових послідовностей, а також математичне обгрунтування її гіперболічної структури та фрактальної вимірності.

## Математичне означення відображення підкови

Розглянемо замкнений одиничний квадрат `S = [0, 1] × [0, 1] ⊂ R²` у двовимірному евклідовому просторі з декартовими координатами `(x, y)`. На цьому квадраті задаються дві неперетинні горизонтальні смуги `H₀` та `H₁`, які визначаються інтервалами координат:

```
H₀ = [0, 1] × [0, α]           [нижня горизонтальна смуга висотою α]
H₁ = [0, 1] × [1 - α, 1]       [верхня горизонтальна смуга висотою α]
```

де параметр стиску задовольняє сувору нерівність `0 < α < 1/2`. Вільна смуга `[0, 1] × (α, 1 - α)`, розташована між `H₀` та `H₁`, під дією перетворення потрапляє в область купола підкови поза початковим квадратом `S`.

Відображення підкови `f: H₀ ∪ H₁ → R²` визначається як кусково-афінне перетворення, яке діє окремо на кожній смузі:

```
Для (x, y) ∈ H₀:
f(x, y) = (α · x, β · y)      [стискання по X в 1/α разів, розтягнення по Y у β разів]

Для (x, y) ∈ H₁:
f(x, y) = (1 - α · x, β · (1 - y))      [стискання, розтягнення та поворот на 180 градусів]
```

де параметр вертикального розтягування задовольняє нерівність `β > 2`.

Образами смуг `H₀` та `H₁` при перетворенні `f` є дві вертикальні смуги `V₀` та `V₁`, які повністю перетинають квадрат `S` від нижньої до верхньої межі:

```
V₀ = f(H₀) = [0, α] × [0, β · α] ∩ S = [0, α] × [0, 1]
V₁ = f(H₁) = [1 - α, 1] × [0, 1]
```

Зворотне відображення `f⁻¹: V₀ ∪ V₁ → H₀ ∪ H₁` задається аналітичними формулами:

```
Для (x, y) ∈ V₀:
f⁻¹(x, y) = ((1 / α) · x, (1 / β) · y)

Для (x, y) ∈ V₁:
f⁻¹(x, y) = ((1 / α) · (1 - x), 1 - (1 / β) · y)
```

## Побудова інваріантної множини та послідовностей Кантора

Інваріантна множина `Λ` визначається як множина точок, орбіти яких не залишають квадрат `S` для всіх моментах часу `n ∈ Z`:

```
Λ = ⋂_{n = -∞}^{+∞} fⁿ(S)
```

Щоб строго дослідити геометричну будову інваріантної множини `Λ`, розділимо фазовий аналіз на пряму динаміку в майбутнє та зворотну динаміку в минуле.

Визначимо множину `Λ₊` точок, які залишаються у квадраті при всіх додатних ітераціях `n ≥ 0`:

```
Λ₊ = ⋂_{n=0}^{∞} f⁻ⁿ(S) = S ∩ f⁻¹(S) ∩ f⁻²(S) ∩ ...
```

Та множину `Λ₋` точок, які залишаються у квадраті при всіх від'ємних ітераціях `n ≥ 1`:

```
Λ₋ = ⋂_{n=1}^{∞} fⁿ(S) = f(S) ∩ f²(S) ∩ f³(S) ∩ ...
```

Повний інваріантний набір точок дорівнює перетину цих двох множин: `Λ = Λ₊ ∩ Λ₋`.

### Лема 1 (Строга структура множини Λ₊)

Множина `Λ₊` є прямим добутком неперервного відрізка `[0, 1]` уздовж осі `X` на одновимірну канторову множину `K_y` уздовж осі `Y`.

**Доказ:**

Розглянемо перший зворотний образ `S ∩ f⁻¹(S) = H₀ ∪ H₁`. Це дві замкнені горизонтальні смуги висотою `α`.

Другий зворотний образ `S ∩ f⁻¹(S) ∩ f⁻²(S) = H₀₀ ∪ H₀₁ ∪ H₁₀ ∪ H₁₁` складається з `2² = 4` горизонтальних смуг висотою `α · β⁻¹`.

За принципом математичної індукції, після `n` кроків область `⋂_{k=0}^{n} f⁻ᵏ(S)` складається з `2ⁿ` замкнених горизонтальних смуг висотою `h_n`:

```
h_n = α · β⁻ⁿ⁺¹      [висота кожної з 2ⁿ смуг на кроці n]
```

Оскільки `β > 2`, при прямуванні `n → ∞` висота смуг експоненційно прямує до нуля: `h_n → 0`. Перетин нескінченної послідовності вкладених замкнених смуг за теоремою Кантора про вкладені відрізки утворює континуум горизонтальних відрізків, ординати яких утворюють досконалу ніде не щільну канторову множину `K_y`.

### Лема 2 (Строга структура множини Λ₋)

Множина `Λ₋` є прямим добутком одновимірної канторової множини `K_x` уздовж осі `X` на неперервний відрізок `[0, 1]` уздовж осі `Y`.

**Доказ:**

Розглянемо перший прямий образ `f(S) ∩ S = V₀ ∪ V₁`. Це дві замкнені вертикальні смуги шириною `α`.

Після `n` прямих ітерацій область `⋂_{k=1}^{n} fᵏ(S)` складається з `2ⁿ` вертикальних смуг шириною `w_n`:

```
w_n = αⁿ      [ширина кожної з 2ⁿ вертикальних смуг]
```

Оскільки `0 < α < 1/2`, при прямуванні `n → ∞` ширина смуг експоненційно прямує до нуля: `w_n → 0`. Перетин утворює множину вертикальних відрізків, абсциси яких утворюють канторову множину `K_x`.

Отже, інваріантна множина `Λ` є прямим добутком двох канторових множин у двовимірному фазовому просторі:

```
Λ = K_x × K_y      [добуток двох замкнених досконалих ніде не щільних множин]
```

Оскільки кожна з канторових множин `K_x` та `K_y` має нульову міру Лебега на відрізку `[0, 1]`, загальна двовимірна міра Лебега (площа) інваріантної множини `Λ` на площині дорівнює нулю: `mes_2(Λ) = 0`.

## Простір послідовностей та кодувальне відображення

Нехай `Σ₂ = {0, 1}^Z` — простір усіх двосторонньо нескінченних послідовностей двозначного двійкового алфавіту:

```
s = (..., s_{-2}, s_{-1}, s_0, s_1, s_2, ...)
```

Введемо на просторі `Σ₂` евклідоподібну метрику `d(s, t)` для двох послідовностей `s` та `t`:

```
d(s, t) = ∑_{k = -∞}^{+∞} |s_k - t_k| / 2^{|k|}
```

Ця метрика перетворює `Σ₂` на компактний повний метричний простір. Базисом топології у `Σ₂` є циліндричні множини `C_{a_{-m} ... a_n}`, які складаються з послідовностей, що мають фіксовані символи від позиції `-m` до `n`.

Визначимо кодувальне відображення `h: Λ → Σ₂` за правилом:

```
(h(p))_k = 0,  якщо fᵏ(p) ∈ H₀
(h(p))_k = 1,  якщо fᵏ(p) ∈ H₁
```

для кожного цілого значення `k ∈ Z`.

## Теорема Смейла про топологічну спряженість

Відображення `h: Λ → Σ₂` є гомеоморфізмом (бієктивним, неперервним у обидва боки відображенням), і виконується тотожність топологічної спряженості:

```
h ∘ f = σ ∘ h
```

де `σ: Σ₂ → Σ₂` — оператор зсуву Бернуллі, `(σ(s))_k = s_{k+1}`.

**Доказ теореми:**

Розб'ємо доказ на три послідовні математичні кроки: бієктивність, неперервність та комутативність.

### Крок 1: Взаємно однозначна відповідність (бієктивність)

Нехай задано довільну нескінченну двосторонню послідовність символів `s = (..., s_{-1}, s_0, s_1, ...) ∈ Σ₂`.

Для кожного натурального `n ≥ 0` визначимо замкнений прямокутник `R_n(s)` як перетин смуг:

```
R_n(s) = ⋂_{k = -n}^{n} f⁻ᵏ(H_{s_k})
```

Обчислимо геометричні розміри прямокутника `R_n(s)` у фазовій площині:

```
Ширина:   w(R_n(s)) = αⁿ⁺¹      [ширина вертикальної смуги порядку n]
Висота:   h(R_n(s)) = α · β⁻ⁿ   [висота горизонтальної смуги порядку n]
```

Оскільки `R_n(s)` є послідовністю вкладених непорожніх замкнених прямокутників, розміри яких прямують до нуля:

```
lim_{n → ∞} w(R_n(s)) = 0
lim_{n → ∞} h(R_n(s)) = 0
```

за теоремою про вкладені компакти перетин `⋂_{n=0}^{∞} R_n(s)` складається з **єдиної точної точки** `p ∈ Λ`. Це доводить, що відображення `h` є сюр'єктивним та ін'єктивним, тобто бієктивним.

### Крок 2: Неперервність `h` та `h⁻¹`

Припустимо, що дві точки `p, q ∈ Λ` знаходяться дуже близько одна до одної у фазовому просторі, так що вони належать одному прямокутнику `R_N`. Тоді їхні символьні коди повністю збігаються для всіх позицій від `-N` до `+N`:

```
s_k(p) = s_k(q)    для всіх |k| ≤ N
```

Обчислимо відстань між їхніми кодами у символічному просторі `Σ₂`:

```
d(h(p), h(q)) = ∑_{|k| > N} |s_k(p) - s_k(q)| / 2^{|k|} ≤ ∑_{|k| > N} 1 / 2^{|k|} = 1 / 2ᴺ⁻¹
```

При прямуванні `N → ∞` відстань у кодовому просторі прямує до нуля `d(h(p), h(q)) → 0`. Це гарантує неперервність `h`. Аналогічно доводиться неперервність зворотного відображення `h⁻¹`.

### Крок 3: Співвідношення топологічної спряженості

За означенням кодувального відображення для `k`-го елемента послідовності маємо:

```
(h(f(p)))_k = 0  ⇔  fᵏ(f(p)) ∈ H₀  ⇔  fᵏ⁺¹(p) ∈ H₀  ⇔  (h(p))_{k+1} = 0
```

Отже, для всіх позицій `k ∈ Z`:

```
(h(f(p)))_k = (h(p))_{k+1} = (σ(h(p)))_k
```

Що й доводить тотожність `h(f(p)) = σ(h(p))` для всіх точок `p ∈ Λ`. Теорему доведено повністю.

## Аналіз гіперболічної структури

Формальне означення гіперболічності за Дмитро Аносовим та Стівеном Смейлом вимагає розкладу дотичного бандла.

Для відображення `f: Λ → Λ` інваріантна множина `Λ` називається **гіперболічною**, якщо для кожної точки `x ∈ Λ` дотичний простір `T_x R²` розкладається у пряму суму двох інваріантних лінійних підпросторів:

```
T_x R² = E^s(x) ⊕ E^u(x)
```

таких, що виконуються три фундаментальні умови:

1. **Інваріантність підпросторів під дією диференціала:**
   ```
   Df(x) E^s(x) = E^s(f(x))
   Df(x) E^u(x) = E^u(f(x))
   ```
2. **Рівномірне стискання уздовж стійкого підпростору `E^s`:**
   ```
   ||Dfⁿ(v)|| ≤ C · λⁿ · ||v||      для всіх v ∈ E^s(x), n ≥ 0
   ```
   де константа `C > 0` та параметр стискання `0 < λ < 1`.
3. **Рівномірне розтягнення уздовж нестійкого підпростору `E^u`:**
   ```
   ||Df⁻ⁿ(w)|| ≤ C · λⁿ · ||w||     для всіх w ∈ E^u(x), n ≥ 0
   ```

Для підкови Смейла підпростір `E^s(x)` у кожній точці `x ∈ Λ` є паралельним горизонтальній осі `X` (з одиничним направляючим вектором `e_x = (1, 0)`), а підпростір `E^u(x)` — паралельним вертикальній осі `Y` (з одиничним направляючим вектором `e_y = (0, 1)`).

Обчислимо норму матриці Якобі після `n` ітерацій для довільного вектора `v = (v_x, 0) ∈ E^s`:

```
Dfⁿ(v) = (αⁿ · v_x, 0)
||Dfⁿ(v)|| = αⁿ · ||v||
```

Оскільки `0 < α < 1/2`, маємо `C = 1`, а `λ = α < 1/2 < 1`.

Для довільного вектора `w = (0, w_y) ∈ E^u` під дією зворотного відображення:

```
Df⁻ⁿ(w) = (0, β⁻ⁿ · w_y)
||Df⁻ⁿ(w)|| = β⁻ⁿ · ||w||
```

Оскільки `β > 2`, маємо `λ' = 1/β < 1/2 < 1`.

Отже, підкова Смейла повністю задовольняє суворі критерії гіперболічної інваріантної множини.

## Теорема Бірмана — Вільямса та шаблони орбіт

Математичний аналіз топологічної структури замкнених періодичних орбіт у тривимірному фазовому просторі описується теоремою Джоан Бірман та Роберта Вільямса (Joan Birman and Robert Williams).

Нехай `f_t` — трьохвимірний фазовий потік, який у перетині Пуанкаре генерує підкову Смейла. Завдяки наявності гіперболічної структури можна здійснити топологічне стискання стійкого многовиду `E^s`, фактор-простір якого утворює двовимірний розгалужений многовид — **вузловий шаблон (knot template)** `K_{horseshoe}`.

Шаблон `K_{horseshoe}` складається з двох смуг, які з'єднуються у зоні склеювання:
- Ліва смуга `0` є прямою (орієнтованою).
- Права смуга `1` має один повний скрут на 180 градусів (неорієнтована).

Для кожної періодичної послідовності `s = (s_0, s_1, ..., s_{N-1})` довжини `N` топологічний тип вузла `K(s)` визначається за правилом в'язання на шаблоні:

```
K(s) = Trace_{template}(s_0 ⊗ s_1 ⊗ ... ⊗ s_{N-1})    [топологічний інваріант вузла]
```

Цей математичний інструмент дав змогу довести, що підкова Смейла містить нескінченно багато типів топліцевих вузлів, які роблять хаотичний рух топологічно затиснутим у просторі.

## Математичний доказ леми про тіні (Shadowing Lemma)

Наведем строгий доказ леми про тіні для гіперболічної підкови Смейла.

Нехай `(z_n)_{n ∈ Z}` є `ε`-псевдоорбітою відображення `f`, тобто для всіх `n ∈ Z`:

```
||f(z_n) - z_{n+1}|| < ε
```

Шукаємо точну орбіту `y_n = fⁿ(y_0)`, таку що `||y_n - z_n|| < δ` для всіх `n ∈ Z`.

Оскільки `T_{z_n} R² = E^s ⊕ E^u`, розкладемо вектор відхилення `w_n = y_n - z_n` на горизонтальну та вертикальну компоненти: `w_n = (u_n, v_n)`.

Запишемо лінеаризовані рівняння для відхилень з урахуванням обчислювальної похибки `(ξ_n, η_n)` на кожному кроці:

```
u_{n+1} = α · u_n + ξ_n      [стискальна координата X]
v_{n+1} = β · v_n + η_n      [розтягувальна координата Y]
```

Розв'язуємо ці різницеві рівняння методом оператора Гріна у зворотному напрямку для нестійкої координати та у прямому для стійкої:

```
u_n = ∑_{k = -∞}^{n-1} αⁿ⁻ᵏ⁻¹ · ξ_k      [сума для стійкої компоненти, |α| < 1/2]
v_n = - ∑_{k = n}^{∞} βⁿ⁻ᵏ⁻¹ · η_k       [сума для нестійкої компоненти, β > 2]
```

Обчислимо максимальну норму відхилень:

```
|u_n| ≤ ε · ∑_{m=0}^{∞} αᵐ = ε / (1 - α) < 2 · ε
|v_n| ≤ ε · ∑_{m=1}^{∞} β⁻ᵐ = ε / (β - 1) < ε
```

Покладаючи `δ = 2 · ε / (1 - max(α, 1/β))`, отримуємо, що при будь-якому `ε < δ · (1 - max(α, 1/β)) / 2` існує єдина справжня точна орбіта `y_n`, яка тінить чисельну псевдоорбіту `z_n` із точністю `δ`. Лему про тіні доведено.

## Формалізм інтеграла Мельникова та замикання расщепления

Розглянемо двовимірну гамільтонову систему із гамільтоніаном `H_0(x, y)`, яка має сідлову нерухому точку `p_0 = (0, 0)` та сепаратрисну петлю `(x_0(t), y_0(t))`, що описує гомоклінічну орбіту `W^s(p_0) = W^u(p_0)`.

Піддамо систему малому періодичному збуренню `ε · g(x, y, t)`:

```
dx / dt = ∂H_0 / ∂y + ε · g_1(x, y, t)
dy / dt = - ∂H_0 / ∂x + ε · g_2(x, y, t)
```

Збурені стійкий `W^s_ε` та нестійкий `W^u_ε` многовиди розщеплюються. Відстань `d(t_0)` між ними уздовж нормалі `n(t)` до незбуреної сепаратриси в точці `(x_0(t_0), y_0(t_0))` обчислиться за формулою першого порядку теорії збурень:

```
d(t_0) = ε · M(t_0) / ||∇H_0(x_0(t_0))|| + O(ε²)
```

де `M(t_0)` — інтеграл Мельникова:

```
M(t_0) = ∫_{-∞}^{+∞} [ ∂H_0 / ∂x · g_2(x_0(t), y_0(t), t + t_0) - ∂H_0 / ∂y · g_1(x_0(t), y_0(t), t + t_0) ] dt
```

Якщо функція Мельникова `M(t_0)` має простий нуль у точці `t_0^*`:

```
M(t_0^*) = 0    та    dM / dt_0 (t_0^*) ≠ 0
```

то за теоремою про неявну функцію збурені многовиди `W^s_ε` та `W^u_ε` перетинаються під ненульовим кутом в точці `q(t_0^*)`. Це гарантує наявність трансверсальної гомоклінічної точки та підкови Смейла.

## Марковські партиції та підзсуви скінченного типу

Для формалізації зв'язку між підковою Смейла та марковськими ланцюгами будується **Марковське розбиття** фазового простору.

Множина `S` розбивається на скінченну кількість прямокутників `R = {R_1, R_2, ..., R_k}`, межі яких є відрізками стійких та нестійких многовидів.

Матриця суміжності `A_{ij}` розміру `k × k` визначається перетином образів:

```
A_{ij} = 1,  якщо f(int R_i) ∩ int R_j ≠ ∅
A_{ij} = 0,  якщо f(int R_i) ∩ int R_j = ∅
```

Динаміка підкови Смейла еквівалентна підзсуву скінченного типу (Subshift of Finite Type, SFT) на просторі допустимих послідовностей `Σ_A`:

```
Σ_A = { (s_n)_{n ∈ Z} : A_{s_n, s_{n+1}} = 1  для всіх n ∈ Z }
```

Для стандартної двогілкової підкови Смейла матриця `A` складається з усіх одиниць:

```
A = [ 1  1 ]
    [ 1  1 ]
```

що повертає нас до повного незсунутого двійкового зсуву Бернуллі `Σ₂`.

## Фрактальні вимірності Реньї та спектр вимірностей

Для комплексної фрактальної характеристики інваріантної множини `Λ` використовують спектр обобщених фрактальних вимірностей Реньї `D_q`.

Нехай `p_i(ε)` — ймовірнісна міра потрапляння точки в `i`-й осередок сітки розміром `ε`. Вимірність Реньї порядку `q` визначається границею:

```
D_q = (1 / (q - 1)) · lim_{ε → 0} (ln ∑_i p_i(ε)ⁿ / ln ε)
```

Для підкови Смейла з однаковою ймовірністю відвідування двох смуг `p_0 = p_1 = 1/2` усі вимірності Реньї збігаються між собою:

```
D_0 = D_1 = D_2 = D_q = (ln 2 / ln(1 / α)) + (ln 2 / ln β)
```

де `D_0` — ємнісна вимірність (box-counting dimension), `D_1` — інформаційна вимірність (information dimension), а `D_2` — кореляційна вимірність (correlation dimension). Це збігання є математичним наслідком суворої однорідності гіперболічної множини Смейла.

## Статистичні закони для хаотичних послідовностей

Топологічна спряженість із зсувом Бернуллі дає змогу застосувати до класичної детермінованої системи фундаментальні закони теорії ймовірностей.

Для майже всіх початкових точок `p ∈ Λ` за ймовірнісною мірою Бернуллі виконується **Закон великих чисел**:

```
lim_{N → ∞} (1 / N) · ∑_{k=0}^{N-1} s_k(p) = 1 / 2      [середня частота появу символу 1 дорівнює 1/2]
```

Більше того, флуктуації кількості символів `1` відносно середнього значення `N/2` підпорядковуються **Центральній граничній теоремі**:

```
lim_{N → ∞} P( a ≤ (∑_{k=0}^{N-1} s_k - N / 2) / (√N / 2) ≤ b ) = (1 / √(2·π)) · ∫_{a}^{b} e^{-t²/2} dt
```

Це доводить, що детермінована динаміка підкови Смейла на мікроскопічному рівні генерує гауссівські статистичні флуктуації, ідентичні незалежним кидкам монети (Bernoulli trials).

## Квантування фазового простору та матрична операторна формалізація

У квантово-механічному описі системи із класичною підковою Смейла фазовий простір дискретизується на квантові комірки площею `2·π·ℏ`. Замість класичного відображення `f` розглядається унітарний оператор еволюції `U_{quantum}` на гіперпросторі функцій.

Зв'язок між класичним зсувом `σ` на `Σ₂` та квантовим квазіспектром описується спектральним радіусом оператора Перерона — Фробеніуса `L`:

```
(L φ)(s) = ∑_{t : σ(t) = s} φ(t) / |det Df(t)|
```

Власні значення оператора Перерона — Фробеніуса дають точні резонанси Полікотта — Руеля (Pollicott-Ruelle resonances), які визначають швидкість згасання часових кореляційних функцій у нелінійних фізичних системах:

```
C(t) = ⟨ A(x(t)) · B(x(0)) ⟩ ~ e^{-γ · t}      [експоненційне згасання кореляцій із швидкістю γ]
```

Таким чином, математичний формалізм підкови Смейла виводить статистичну незворотність безпосередньо з детермінованої гіперболічної геометрії.

## Структурна стійкість та теорема про збурення Аносова — Смейла

Завершуючи формальний математичний огляд, розкрито ключову теорему про структурну стійкість. Якщо відображення `f` належить класу гладких дифеоморфізмів `Diff¹(M)` і має гіперболічну інваріантну множину `Λ`, то для будь-якого малості `ε > 0` існує така `C¹`-окіл `U(f)`, що для кожного дифеоморфізму `g ∈ U(f)` знайдеться інваріантна множина `Λ_g` та неперервний гомеоморфізм `h_g: Λ → Λ_g`, для якого:

```
h_g ∘ f = g ∘ h_g      [топологічна спряженість збуреної динаміки зі початковою]
```

Це доводить, що хаотична динаміка підкови Смейла є абсолютно стійким явищем, яке неруйнівно зберігається при будь-яких малих нелінійних деформаціях системи.

## Точне обчислення координат фрактала

Обчислимо горизонтальні координати Канторової множини `K_x`. Точка `x ∈ K_x` має двійкове розкладення, яке визначається послідовністю символів `(s_0, s_1, s_2, ...)` при прямих ітераціях.

За аналітичними формулами відображення:

```
x = ∑_{k=0}^{∞} s_k · αᵏ · (1 - α)^{1 - s_k}    [абсциса точки інваріантної множини]
```

Аналогічно, ордината `y ∈ K_y` точки підкови визначається послідовністю символів `(s_{-1}, s_{-2}, s_{-3}, ...)` при зворотних ітераціях:

```
y = ∑_{k=1}^{∞} s_{-k} · β⁻ᵏ                     [ордината точки інваріантної множини]
```

Для кожної двоїсто нескінченної послідовності `s = (..., s_{-2}, s_{-1}, s_0, s_1, s_2, ...)` пара `(x(s), y(s))` дає явний точний алгебраїчний розв'язок координат відповідної точки фрактальної множини `Λ`.

## Теорема про зліченність періодичних точок та оператор Перерона — Фробеніуса

Для знаходження кількості періодичних точок періоду `N` розглянемо оператор Перерона — Фробеніуса (Transfer operator) `T` на просторі функцій над символічною множиною `Σ₂`.

Матриця переходу Марковського ланцюга для підкови Смейла дорівнює:

```
M_trans = [ 1   1 ]
          [ 1   1 ]
```

Кількість періодичних точок `N_{per}(N)` періоду `N` обчислюється через след `N`-ї ступені матриці переходу:

```
N_{per}(N) = Tr(M_transᴺ) = 1ᴺ + 1ᴺ = 2ᴺ      [кількість періодичних точок періоду N]
```

Це доводить, що кількість періодичних орбіт зростає як точна показникові функція від періоду `N`. Топологічна ентропія `h_{top}(f)` обчислюється як логарифм наибольшого власного значення `λ_{max} = 2` матриці переходу:

```
h_{top}(f) = ln λ_{max} = ln 2 ≈ 0.69315
```

Отже, представлені формальні докази та аналітичні моделі повністю підтверджують сувору математичну та фізичну цілісність конструкції підкови Смейла.
