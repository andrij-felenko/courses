# 📋 Довідник режимів числа Кнудсена та граничних умов

Цей довідник містить таблиці фізичних параметрів газів, граничні умови ковзання та зведені формули режимів числа Кнудсена для розрахунку вакуумних систем і мікрофлюїдних пристроїв.

## 1. Фізична інтерпретація та кінетичні параметри газів

Вибір фізичних параметрів газу є першим кроком при розрахунку будь-якого газодинамічного процесу у мікромасштабах або у вакуумі. Ефективний газокінетичний діаметр молекули `d` визначає переріз зіткнення `σ = π·d²`. Через цей діаметр серединний вільний пробіг `λ` прямо пов'язаний із термодинамічними параметрами стану — абсолюдною температурою `T` та абсолютним тиском `P`.

У кінетичній теорії газів молекули моделюються як пружні сфери. Проте реальні молекули мають міжатомні сили притягання та відштовхування, описувані потенціалом Леннард-Джонса або модельними розсіювальними геометріями VSS (*Variable Soft Sphere*). При підвищенні температури ефективний діаметр молекули `d(T)` злегка зменшується, оскільки частинки зіштовхуються з більшою кінетичною енергією й глибше проникають у потенціальний бар'єр одна одної. За формулою Сазерленда динамічна в'язкість газу `μ(T)` та серединний вільний пробіг `λ(T)` зростають із температурою:

```
μ(T)  =  μ₀ · (T / T₀)^(3/2) · (T₀ + S) / (T + S)

S        [постійна Сазерленда для даного газу, К]
μ₀       [динамічна в'язкість за опорної температури T₀]
```

Значення у наведеній нижче таблиці розраховано для стандартних умов: температура `T = 298.15 К` (`25 °C`), атмосферний тиск `P = 101 325 Па` (`760 мм рт. ст.`). Для обчислення пробігу за довільних тисків і температур використовується пропорційність `λ ∝ T / P`.

Легкі гази, такі як водень та гелій, мають значно менший діаметр молекул та високу середню теплову швидкість. Завдяки цьому їхній серединний вільний пробіг `λ` при тій самій температурі й тиску втричі перевищує пробіг азоту чи повітря. Завдяки високому `λ` легкі гази набагато раніше проявляють ефекти ковзання та розрідження. При виборі газової суміші у вакуумній техніці важливо враховувати, що наявність навіть невеликої домішки гелію істотно підвищує загальний серединний вільний пробіг суміші, полегшуючи перехід системи у вільномолекулярний режим течії.

Унаслідок цього один і той самий вакуумний трубопровід діаметром 10 см під час відкачування послідовно проходить усі чотири фізичні режими газової динаміки.

## 2. Зведена класифікація режимів числа Кнудсена

Число Кнудсена визначається як безрозмірне відношення серединного вільного пробігу `λ` до характерного геометричного розміру системи `L`: `Kn = λ / L`.

У закритих каналах та трубах за характерний розмір `L` береться гідравлічний діаметр або висота мікроканалу. При обтіканні перешкод або літальних апаратів за `L` беруть характерну хорду крила або радіус затуплення головної частини апарата.

| Режим течії | Діапазон `Kn` | Основні математичні рівняння | Граничні умови на стінці | Переносний механізм | Приклади з техніки |
| :--- | :---: | :--- | :--- | :--- | :--- |
| **Суцільний** *(Continuum)* | `Kn < 0.01` | Рівняння Нав'є-Стокса | `v_slip = 0`, `T_jump = 0` (Прилипання) | Об'ємна в'язкість і теплопровідність газу | Макроскопічна аеродинаміка, водогін, вентиляція |
| **З ковзанням** *(Slip Flow)* | `0.01 ≤ Kn < 0.1` | Рівняння Нав'є-Стокса з поправками | Перший порядок Максвелла (`v_slip ≠ 0`, `T_jump ≠ 0`) | В'язкість в об'ємі + пристінковий зсув | МЕМС-сенсори, капіляри, мікропомпа |
| **Перехідний** *(Transition Flow)* | `0.1 ≤ Kn < 10` | Рівняння Больцмана / Метод DSMC | Кінетичний шар Кнудсена займає весь канал | Суміш в'язкісного переносу й ефузії | Головка HDD (10 нм), середній вакуум |
| **Вільномолекулярний** *(Free-Molecular)* | `Kn ≥ 10` | Рівняння Власова (беззіткнувальне) | Дифузне/дзеркальне відбивання Кнудсена | Прямолінійний балістичний перенос | Високий вакуум, супутники (150+ км) |

У режимі з ковзанням класичні рівняння Нав'є-Стокса залишаються справедливими в усій товщі газу, крім вузького пристінкового шару Кнудсена. Для правильного розрахунку течії достатньо замінити звичайну умову прилипання на феноменологічну граничну умову Максвелла.

### Поправки ковзання другого порядку

Коли число Кнудсена наближається до верхньої межі режиму ковзання (`Kn ~ 0.05–0.1`), граничні умови першого порядку Максвелла накопичують похибку. У таких випадках застосовують **граничні умови другого порядку за числом Кнудсена** (моделі Карнахана-Дайслера та Хаджиконстантіну):

```
v_slip  =  C₁ · λ · ( ∂v / ∂n )|_wall + C₂ · λ² · ( ∂²v / ∂n² )|_wall

C₁      [коефіцієнт ковзання першого порядку, C₁ ≈ (2 - σ_v)/σ_v]
C₂      [коефіцієнт ковзання другого порядку, C₂ ≈ -(5/12) або -0.5]
```

Використання поправки другого порядку дозволяє розширити застосування розв'язків Нав'є-Стокса до `Kn ≈ 0.25`, відсуваючи потребу в трудомногих чисельних розрахунках Больцмана чи DSMC. Це дає інженерам зручний аналітичний інструмент для швидкого проектування мікрофлюїдних чипів та МЕМС-акселерометрів.

## 3. Математичний контракт граничних умов ковзання

При взаємодії молекул газу зі стінкою дотична швидкість газу безпосередньо біля поверхні `v_gas|_wall` не дорівнює швидкості самої стінки `v_wall`. Виникає швидкість ковзання `v_slip`. Аналогічно виникає різниця температур між газом біля стінки та самою поверхнею — стрибок температури `T_jump`.

### Перший порядок Максвелла та Смолуховського

```
v_slip  =  v_gas|_wall - v_wall  =  ( (2 - σ_v) / σ_v ) · λ · ( ∂v / ∂n )|_wall

T_jump  =  T_gas|_wall - T_wall  =  ( (2 - σ_T) / σ_T ) · ( (2·γ) / (γ + 1) ) · (λ / Pr) · ( ∂T / ∂n )|_wall
```

У цих рівняннях використано такі величини:
- `σ_v` — коефіцієнт аккомодації дотичного імпульсу (Tangential Momentum Accommodation Coefficient, TMAC). Він показує частку молекул, які втрачають свій дотичний імпульс і відбиваються від стінки хаотично (дифузно).
- `σ_T` — коефіцієнт термічної аккомодації (Thermal Accommodation Coefficient). Він описує ступінь енергетичного обміну між молекулами та стінкою.
- `∂ / ∂n` — похідна за нормаллю, спрямованою всередину газу.
- `Pr` — число Прандтля (`Pr ≈ 0.71` для повітря при нормальних умовах).

### Емпіричні значення коефіцієнтів аккомодації `σ_v` та `σ_T`

Коефіцієнти аккомодації залежать від хімічного складу поверхонь, їхньої мікрошорсткості та наявності адсорбованих моношарів вологи чи мастила.

| Пара газ — поверхня | Стан поверхні | Коефіцієнт `σ_v` | Коефіцієнт `σ_T` | Фізичні особливості розсіювання |
| :--- | :--- | :---: | :---: | :--- |
| **Повітря — Полірована сталь** | Промислова чиста | 0.87 – 0.93 | 0.85 – 0.90 | Майже повне дифузне розсіювання через адсорбовані моношари |
| **Повітря — Кремній (Si)** | Монокристалічна гладка | 0.85 – 0.90 | 0.80 – 0.85 | Поширений контакт у МЕМС-пристроях та мікроканалах |
| **Гелій — Скло** | Очищене у вакуумі | 0.89 – 0.95 | 0.35 – 0.45 | Низька термічна аккомодація через велику різницю мас |
| **Азот — Алюміній** | Оксидована | 0.92 – 0.98 | 0.88 – 0.94 | Висока аккомодація на оксидній плівці `Al₂O₃` |
| **Водень — Платина** | Термічно знегазована | 0.25 – 0.35 | 0.30 – 0.40 | Значна частка дзеркального відбивання легких молекул |
| **Ідеальна шорстка поверхня** | Повне дифузне розсіювання | **1.00** | **1.00** | Модель Максвелла для шорстких поверхонь |

Для ультрачистих атомарно-гладких поверхонь у надвисокому вакуумі коефіцієнт аккомодації легких газів (водню чи гелію) може падати до `0.2–0.3`. Це означає, що понад 70% молекул відбиваються дзеркально, і пристінкове ковзання зростає у кілька разів. Знання точного значення `σ_v` є критичним для точного проектування мікропомп та вакуумних датчиків.

## 4. Співвідношення режимів тиску у вакуумній техніці

Вакуумна інженерія класифікує ступені розрідження газу за робочими тисками та відповідними числами Кнудсена. Таблицю нижче розраховано для характерного діаметра вакуумного патрубка `L = 0.10 м` (`10 см`).

| Ступінь вакууму | Тиск `P` (Па) | Тиск `P` (мм рт. ст. / Торр) | Вільний пробіг `λ` | Число Кнудсена `Kn` (`L=10 см`) | Режим течії | Типові вакуумні насоси |
| :--- | :---: | :---: | :---: | :---: | :--- | :--- |
| **Низький вакуум** | `10⁵ … 100` | `760 … 0.75` | `< 67 мкм` | `< 0.0007` | **Суцільний** | Пластинчасто-роторні, мембранні |
| **Середній вакуум** | `100 … 0.1` | `0.75 … 10⁻³` | `67 мкм … 6.7 см` | `0.0007 … 0.67` | **З ковзанням / Перехідний** | Насоси Рутса, спиральні насоси |
| **Високий вакуум** | `0.1 … 10⁻⁵` | `10⁻³ … 10⁻⁷` | `6.7 см … 670 м` | `0.67 … 6700` | **Перехідний / Вільномолекулярний** | Турбомолекулярні, дифузійні |
| **Надвисокий (UHV)** | `< 10⁻⁵` | `< 10⁻⁷` | `> 670 м` | `> 6700` | **Вільномолекулярний** | Магніторозрядні, кріогенні |

У низькому вакуумі газ тече як суцільна в'язка рідина. У високому та надвисокому вакуумі молекули рухаються балістично: вони практично не зазнають зіткнень між собою у вакуумному об'ємі. Відповідно змінюється й принцип роботи насосів: від витіснення об'єму (пластинчасті насоси) до передачі молекулярного імпульсу високоефективними лопатками турбомолекулярних насосів чи захоплення молекул замороженими кріоповерхнями.

### Формули провідності трубопроводів у різних режимах

Провідність вакуумного патрубка `U` визначається як відношення масового потоку газу до різниці тисків: `U = Q / ΔP` (вимірюється в м³/с або л/с).

1. **В'язкісний суцільний режим (`Kn < 0.01`, закон Пуазейля):**
   ```
   U_visc  =  (π · D⁴ / (128 · μ · L)) · P_avg
   ```
   Провідність прямо пропорційна четвертому степеню діаметра `D⁴` та середньому тиску `P_avg`.

2. **Вільномолекулярний режим (`Kn > 10`, формула Кнудсена):**
   ```
   U_mol  =  (1/6) · √( (2·π·R_gas·T) / M ) · (D³ / L)
   ```
   Провідність пропорційна третьому степеню діаметра `D³` і **зовсім не залежить від тиску**.

3. **Перехідний режим (формула Кнудсена-Кнудсена):**
   ```
   U_trans  =  U_visc + a · U_mol

   a  =  (1 + 2.53·(D / (2·λ))) / (1 + 3.14·(D / (2·λ)))
   ```
   Ця комбінована формула забезпечує гладкий перехід між в'язкісним та вільномолекулярним режимами під час розрахунку систем вакуумної відкачки.
