# 🧮 Математична кінематика твердого тіла: матриці обертання, кути Ейлера та кватерніони

Математичний опис руху абсолютно твердого тіла вимагає суворого апарату лінійної алгебри, диференціальної геометрії та теорії груп Лі. На відміну від однієї матеріальної точки, стан якої повністю задається трьома декартовими координатами `r = (x, y, z)`, стан абсолютно твердого тіла вимагає опису як положення деякого вибраного полюса (зазвичай центру мас), так і орієнтації тіла у тривимірному евклідовому просторі `ℝ³`.

У цій вставці наведено математичне виведення кінематичних співвідношень обертового руху: від спеціальної ортогональної групи Лі `SO(3)` до зкісносиметричного тензора кутової швидкості, формули обертання Родріга, кінематичних рівнянь Пуассона, кутів Ейлера та алгебри одиничних кватерніонів.

### 1. Група обертань SO(3) та геометрія ізометрії

Умова абсолютної жорсткості означає, що відстань між будь-якою парою точок тіла `Pᵢ` та `Pⱼ` є строго незмінною в часі:

```
|rᵢ(t) - rⱼ(t)| = |rᵢ(0) - rⱼ(0)| = const     [умова жорсткості]
```

Звідси випливає, що довільне перетворення координат точки тіла із власної (зв'язаної) системи відліку `x'y'z'` у нерухому лабораторну систему відліку `xyz` є ізометрією збереження орієнтації. Воно подається у вигляді афінного перетворення:

```
r(t) = r_CM(t) + R(t) · r'     [перетворення координат Ейлера-Шаля]
```

де `r_CM(t)` — радіус-вектор центру мас у лабораторній системі, `r'` — сталий радіус-вектор точки у власній системі тіла, а `R(t)` — ортогональна матриця розміром 3×3.

Множина всіх можливих матриць обертання утворює спеціальну ортогональну групу Лі `SO(3)` (англ. *Special Orthogonal Group* in 3 dimensions), яка визначається двома умовами:

```
Rᵀ · R = I               [умова ортогональності: зберігає довжини векторів]
det(R) = +1              [умова власного обертання: зберігає орієнтацію базису]
```

Оскільки ортогональна матриця 3×3 має 9 елементів і підпорядкована 6 незалежним скалярним рівнянням ортогональності `Rᵀ R = I` (3 рівняння одиничної довжини стовпчиків + 3 рівняння ортогональності між стовпчиками), розмірність многовиду `SO(3)` дорівнює `9 - 6 = 3`. Отже, для повного опису орієнтації твердого тіла у просторі потрібно рівно 3 незалежні параметри.

### 2. Зкісносиметричний тензор кутової швидкості та алгебра Лі so(3)

Продиференціюємо рівняння руху точки тіла `r(t) = r_CM(t) + R(t) · r'` за часом `t`, враховуючи, що у власній системі координат вектор `r'` є константою (`dr'/dt = 0`):

```
v(t) = (d r / dt)
= (d r_CM / dt) + (d R / dt) · r'                    [похідна за часом]
= v_CM(t) + Ṙ(t) · r'                                [позначення Ṙ = dR/dt]
= v_CM(t) + Ṙ(t) · Rᵀ(t) · (R(t) · r')                [підстановка r - r_CM = R·r']
= v_CM(t) + Ω(t) · (r(t) - r_CM(t))                  [введення тензора Ω = Ṙ·Rᵀ]
```

Величина `Ω(t) = Ṙ(t) · Rᵀ(t)` називається **тензором (матрицею) кутової швидкості** у лабораторній системі відліку. Доведемо, що матриця `Ω` є строго зкісносиметричною (`Ωᵀ = -Ω`):

```
R(t) · Rᵀ(t) = I                                     [тотожність ортогональності]
d/dt (R · Rᵀ) = 0                                    [похідна від константи]
Ṙ · Rᵀ + R · Ṙᵀ = 0                                  [правило Лейбніца]
Ω + Ωᵀ = 0                                           [оскільки R·Ṙᵀ = (Ṙ·Rᵀ)ᵀ = Ωᵀ]
Ωᵀ = -Ω                                              [доведено: Ω — зкісносиметрична]
```

Множина всіх зкісносиметричних матриць 3×3 утворює алгебру Лі `so(3)`, яка є дотичним простором до групи Лі `SO(3)` у точці одиничного елемента `I`.

Будь-яка зкісносиметрична матриця 3×3 повністю визначається лише трьома незалежними компонентами `(ω_x, ω_y, ω_z)` і має вигляд:

```
    [   0   -ω_z   ω_y ]
Ω = [  ω_z    0   -ω_x ] = [ω]×                      [оператор векторного добутку]
    [ -ω_y   ω_x    0  ]
```

Дія матриці `Ω` на довільний вектор `a` тотожно дорівнює векторному добутку трьохвимірного вектора кутової швидкості `ω = (ω_x, ω_y, ω_z)` на вектор `a`:

```
Ω · a = [ω]× · a = ω × a                             [еквівалентність матричного та векторного добутку]
```

Таким чином, повне поле швидкостей точок абсолютно твердого тіла набуває класичної форми розподілу Ейлера: `v_P = v_O + ω × r_PO`.

#### Кінематичні рівняння Пуассона

Якщо ми розглянемо напрямні косинуси трьох ортів власного базису тіла `(e'₁, e'₂, e'₃)` відносно лабораторної системи, вони утворюють стовпчики матриці обертання `R = [e'₁ | e'₂ | e'₃]`. Диференціальні рівняння для ортів мають вигляд:

```
d e'₁ / dt = ω × e'₁
d e'₂ / dt = ω × e'₂                                 [кінематичні рівняння Пуассона]
d e'₃ / dt = ω × e'₃
```

У матричній формі рівняння Пуассона записуються як `Ṙ = [ω]× · R` (у лабораторній системі) або `Ṙ = R · [ω_body]×` (у власній системі тіла).

### 3. Експоненціальне відображення та формула обертання Родріга

Зв'язок між алгеброю Лі `so(3)` (кутовими швидкостями) та групою Лі `SO(3)` (матрицями обертання) здійснюється через матричне експоненціальне відображення:

```
R(u, α) = exp(α · [u]×) = ∑ (αⁿ / n!) · [u]×ⁿ          [матрична експонента]
```

де `u = (u_x, u_y, u_z)` — одиничний вектор осі обертання (`||u|| = 1`), а `α` — кут повороту навколо цієї осі у радіанах.

Враховуючи алгебраїчні властивості зкісносиметричного оператора `[u]×³ = -[u]×` та `[u]×⁴ = -[u]×²`, нескінченний степеневий ряд Тейлора згортається у точну замкнену аналітичну формулу — **формулу обертання Родріга** (Олен Родріг, 1840 рік):

```
R(u, α) = I + sin(α) · [u]× + (1 - cos(α)) · [u]×²   [формула обертання Родріга]
```

Явний вигляд матриці обертання Родріга через компоненти вектора осі `u = (u_x, u_y, u_z)` та кут `α`:

```
    [ c + u_x² (1-c)       u_x u_y (1-c) - u_z s   u_x u_z (1-c) + u_y s ]
R = [ u_y u_x (1-c) + u_z s   c + u_y² (1-c)       u_y u_z (1-c) - u_x s ]   [c = cos α, s = sin α]
    [ u_z u_x (1-c) - u_y s   u_z u_y (1-c) + u_x s   c + u_z² (1-c)       ]
```

Формула Родріга дає змогу миттєво обчислити поворот вектора навколо довільної осі у просторі без побудови комбінацій кутів Ейлера.

### 4. Кути Ейлера (Z-X-Z послідовність) та їхні кінематичні рівняння

Для явного параметричного опису орієнтації Ейлер запропонував подавати підсумкову матрицю обертання `R` у вигляді добутку трьох елементарних матриць повороту навколо осей координат:

1. Поворот навколо вертикальної осі `z` на кут прецесії `φ ∈ [0, 2π)`:
   Матриця `R_z(φ)`.
2. Поворот навколо нової осі `x'` (лінії вузлів `N`) на кут нутації `θ ∈ [0, π]`:
   Матриця `R_x(θ)`.
3. Поворот навколо власної осі симетрії тіла `z''` на кут власного обертання `ψ ∈ [0, 2π)`:
   Матриця `R_z(ψ)`.

Підсумкова матриця переходу від власної системи тіла до лабораторної має вигляд:

```
R(φ, θ, ψ) = R_z(φ) · R_x(θ) · R_z(ψ)
```

Перемноживши ці елементарні матриці повороту, отримуємо явне вираження елементів ортогональної матриці:

```
    [ cφ cψ - sφ cθ sψ   -cφ sψ - sφ cθ cψ    sφ sθ ]
R = [ sφ cψ + cφ cθ sψ   -sφ sψ + cφ cθ cψ   -cφ sθ ]    [c = cos, s = sin]
    [      sθ sψ                sθ cψ           cθ  ]
```

Кінематичні рівняння Ейлера зв'язують проекції вектора кутової швидкості `(ω₁, ω₂, ω₃)` на осі тіла з похідними кутів Ейлера `(dφ/dt, dθ/dt, dψ/dt)`:

```
ω₁ = (dφ/dt) · sin(θ) · sin(ψ) + (dθ/dt) · cos(ψ)
ω₂ = (dφ/dt) · sin(θ) · cos(ψ) - (dθ/dt) · sin(ψ)    [кінематичні рівняння Ейлера]
ω₃ = (dφ/dt) · cos(θ) + (dψ/dt)
```

Розв'язуючи цю систему відносно похідних кутів Ейлера, отримуємо:

```
dφ/dt = (ω₁ · sin(ψ) + ω₂ · cos(ψ)) / sin(θ)
dθ/dt =  ω₁ · cos(ψ) - ω₂ · sin(ψ)                   [обернені рівняння Ейлера]
dψ/dt =  ω₃ - (ω₁ · sin(ψ) + ω₂ · cos(ψ)) · ctg(θ)
```

**Проблема заклинювання кардана (Gimbal Lock):** При `θ = 0` або `θ = π` осі прецесії `φ` та власного обертання `ψ` стають колінеарними (паралельними). У цьому стані знаменник `sin(θ) = 0`, і розв'язати похідні кутів стає неможливо. Втрачається один ступінь вільності орієнтації. Це створює катастрофічні обчислювальні збої при чисельному моделюванні польоту літаків, ракет та космічних апаратів.

### 5. Кватерніони та гладка кінематика обертання

Щоб повністю уникнути сингулярностей заклинювання кардана, у сучасній обчислювальній механіці, робототехніці та 3D-графіці використовують **одиничні кватерніони** (кватерніони Гамільтона).

Кватерніон `q` — це чотиривимірне число, що складається з дійсної скалярної частини `w` та тривимірного векторного значення `v = (x, y, z)`:

```
q = w + x·i + y·j + z·k = (w, v)                      [гіперкомплексне число Гамільтона]
```

з основоположними правилами множення уявних одиниць: `i² = j² = k² = i·j·k = -1`.

Згідно з теоремою Ейлера про обертання, довільну орієнтацію можна подати як один чистий поворот на кут `α` навколо одиничного вектора осі `u = (u_x, u_y, u_z)`. Відповідний одиничний кватерніон орієнтації формується як:

```
q = (cos(α/2),  u_x · sin(α/2),  u_y · sin(α/2),  u_z · sin(α/2))     [кватерніон повороту]
```

з умовою нормування: `||q||² = w² + x² + y² + z² = 1`.

Поворот тривимірного вектора `r` за допомогою кватерніона `q` здійснюється через сопряжене кватерніонне множення:

```
r_rotated = q ⊗ (0, r) ⊗ q*                          [кватерніонний поворот вектора]
```

де `q* = (w, -v)` — сопряжений кватерніон, а `⊗` позначує кватерніонний добуток Гамільтона:

```
q₁ ⊗ q₂ = (w₁ w₂ - v₁ · v₂,  w₁ v₂ + w₂ v₁ + v₁ × v₂)  [формула добутку кватерніонів]
```

#### Диференціальне рівняння кінематики кватерніона

Зміна кватерніона орієнтації `q(t)` у часі під дією кутової швидкості `ω(t) = (ω_x, ω_y, ω_z)`, заданої у лабораторній системі координат, описується лінійним диференціальним рівнянням першого порядку:

```
dq/dt = ½ · ω_quat ⊗ q                               [кінематичне рівняння кватерніона]
```

де `ω_quat = (0, ω_x, ω_y, ω_z)` — кватерніон кутової швидкості із нульовою скалярною частиною.

У матричній формі це рівняння записується як:

```
[ dw/dt ]       [  0   -ω_x  -ω_y  -ω_z ]   [ w ]
[ dx/dt ] = ½ · [  ω_x   0    ω_z  -ω_y ] · [ x ]    [матрична система для інтегрування]
[ dy/dt ]       [  ω_y -ω_z    0    ω_x ] · [ y ]
[ dz/dt ]       [  ω_z  ω_y  -ω_x    0  ]   [ z ]
```

#### Сферична лінійна інтерполяція (SLERP)

Для створення гладких траєкторій обертання між двома орієнтаціями `q₁` та `q₂` (наприклад, у анімації чи робототехніці) використовують інтерполяцію SLERP (англ. *Spherical Linear Interpolation*):

```
Slerp(q₁, q₂, t) = [sin((1-t)Ω) / sin(Ω)] · q₁ + [sin(t Ω) / sin(Ω)] · q₂
```

де `cos(Ω) = q₁ · q₂` — скалярний добуток кватерніонів як 4D-векторів, а `t ∈ [0, 1]` — параметр інтерполяції. Перевагою SLERP є суворо постійна кутова швидкість руху вздовж геодезичної дуги на сферичному многовиді.

Переваги кватерніонного формалізму у порівнянні з кутами Ейлера:

1. **Відсутність сингулярностей:** Рівняння кватерніона гладкі для будь-яких орієнтацій у просторі (немає ділення на нуль чи сингулярних осей).
2. **Обчислювальна ефективність:** Кватерніонний добуток вимагає лише 16 множень і 12 додавань (проти 27 множень при множенні матриць 3×3).
3. **Стабільність ортогональності:** Нормування кватерніона вимагає лише ділення чотирьох компонент на скалярну довжину `q = q / ||q||`, що значно дешевше за процедуру ортогоналізації Ґрама-Шмідта для матриць обертання `R`.
