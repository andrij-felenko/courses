# 🧮 Математичний вивід функції Прандтля — Майєра

Ця математична вставка містить суворий аналітичний вивід диференціального рівняння течії Прандтля — Майєра, його інтегрування в замкнену алгебраїчну функцію `ν(M)`, розрахунок граничного кута розширення `ν_max` та систем фундаментальних співвідношень для обчислення термодинамічних параметрів газу впродовж веєра характеристик.

## 1. Кінематика нескінченно малого повороту надзвукового потоку

Розглянемо двовимірний стаціонарний потенціальний потік ідеального стисливого газу, що рухається зі швидкістю `v > a` (число Маха `M > 1`). Нехай потік проходить через нескінченно слабку хвилю розрядження (хвилю Маха), що виходить із вершини опуклого кута під кутом Маха `μ` до напрямку набігаючого потоку.

Кут Маха `μ` пов'язаний із місцевим числом Маха `M` прямокутним трикутником швидкостей. Гіпотенузою трикутника є вектор швидкості газу `v`, а катетом — місцева швидкість звуку `a`:

```
sin(μ) = 1 / M
cos(μ) = √(M² - 1) / M
tan(μ) = 1 / √(M² - 1)
```

При проходженні хвилі Маха вектор швидкості газу `v` змінює свій напрямок на нескінченно малий кут `dθ` (повертаючи у бік стінки) і збільшує свою модульну величину на `dv`. Розкладемо приріст швидкості `dv` на компоненти, паралельну та нормальну до лінії Маха:

- Дотична до лінії Маха компонента швидкості залишається безнеперервною через відсутність поздовжніх сил тиску уздовж лінії фронту: `v_t = const`.
- Нормальна компонента `v_n = v · sin(μ)` зазнає прискорення на `dv_n` під дією перепаду статичного тиску `dp` поперек хвилі.

З геометрії прямокутного трикутника векторів швидкостей до і після хвилі випливає співвідношення для кута повороту `dθ`:

```
dθ = dv_n / v           [визначення кута повороту через нормальну компоненту]
   = (dv / v) · cot(μ)  [з прямокутного трикутника векторів швидкостей]
   = (dv / v) / tan(μ)  [тотожність cot(μ) = 1 / tan(μ)]
```

Підставляючи вираз для `tan(μ) = 1 / √(M² - 1)`, отримуємо фундаментальну кінематичну залежність:

```
dθ = √(M² - 1) · (dv / v)
```

Ця формула виражає фундаментальний фізичний факт: кут повороту вектора швидкості `dθ` прямо пропорційний відносному приросту швидкості `dv / v` та геометричному множнику стисливості `√(M² - 1)`.

## 2. Связочна термодинамічна залежність між mod швидкості та числом Маха

Щоб виразити відносний приріст швидкості `dv / v` через число Маха `M` та його приріст `dM`, скористаємося законом збереження енергії для ізоентропійного потоку ідеального газу.

Квадрат модуля швидкості виражається через число Маха та абсолютну статичну температуру `T`:

```
v² = M² · a² = M² · γ · R · T
```

Повна температура (температура гальмування) `T₀` залишається суворо сталою уздовж лінії течії при адіабатичному русі:

```
T₀ = T · (1 + ½(γ - 1)·M²) = const
```

Звідси статична температура виражається через `T₀` та `M`:

```
T = T₀ / (1 + ½(γ - 1)·M²)
```

Підставимо `T` у формулу для квадрата швидкості `v²`:

```
v² = γ · R · T₀ · [ M² / (1 + ½(γ - 1)·M²) ]
```

Продиференціюємо логарифм обох частин цього рівняння. Логарифмування дає:

```
2 · ln(v) = ln(γ · R · T₀) + 2 · ln(M) - ln(1 + ½(γ - 1)·M²)
```

Беручи повний диференціал від обох частин рівняння (враховуючи, що `γ`, `R` та `T₀` є константами):

```
2 · (dv / v) = 2 · (dM / M) - [ (γ - 1)·M · dM / (1 + ½(γ - 1)·M²) ]  [диференціювання логарифма]
             = 2 · dM / [ M · (1 + ½(γ - 1)·M²) ]                     [зведення до спільного знаменника]
```

Скоротивши двійку в обох частинах, отримуємо точне диференціальне співвідношення для відносного приросту швидкості:

```
dv / v = dM / [ M · (1 + ½(γ - 1)·M²) ]
```

## 3. Диференціальне рівняння функції Прандтля — Майєра

Підставимо вираз для `dv / v` у кінематичне рівняння для кута повороту `dθ`:

```
dθ = [ √(M² - 1) / ( M · (1 + ½(γ - 1)·M²) ) ] · dM
```

Цією формулою визначається нескінченно малий кут повороту потоку `dθ = dν`, який супроводжує зростання числа Маха на `dM`. Для обчислення повного кута повороту від звукового стану (`M = 1`, де прийнято `ν(1) = 0`) до довільного числа Маха `M` необхідно обчислити визначений інтеграл:

```
ν(M) = ∫₁ᴹ [ √(m² - 1) / ( m · (1 + ½(γ - 1)·m²) ) ] dm
```

## 4. Аналітичне інтегрування та вивід формули ν(M)

Щоб обчислити цей інтеграл у замкненому вигляді, застосуємо алгебраїчну заміну змінної:

```
u = √(m² - 1)  ⇒  m² = u² + 1  ⇒  m · dm = u · du
```

Виразимо диференціал `dm / m`:

```
dm / m = (m · dm) / m² = (u · du) / (u² + 1)
```

Підставимо `u` та `dm / m` в підінтегральний вираз:

```
I(u) = ∫ [ u² / ( (u² + 1) · (1 + ½(γ - 1)·(u² + 1)) ) ] du
```

Введемо позначення постійного коефіцієнта `λ²`:

```
λ² = (γ - 1) / (γ + 1)
```

Тоді знаменник другого множника спрощується:

```
1 + ½(γ - 1)·(u² + 1) = ½(γ + 1) · (1 + λ²·u²)
```

Отже, інтеграл набуває вигляду:

```
I(u) = (2 / (γ + 1)) · ∫ [ u² / ( (u² + 1) · (1 + λ²·u²) ) ] du
```

Розкладемо підінтегральний дріб на суму найпростіших дробей за методом невизначених коефіцієнтів:

```
u² / [ (u² + 1) · (1 + λ²·u²) ] = [ 1 / (1 - λ²) ] · [ (1 / (1 + λ²·u²)) - (1 / (u² + 1)) ]
```

Оскільки `1 / (1 - λ²) = 1 / (1 - (γ-1)/(γ+1)) = (γ + 1) / 2`, коефіцієнт `(2 / (γ + 1))` повністю скорочується! Інтеграл розпадається на два стандартні табличні інтеграли:

```
I(u) = (2 / (γ + 1)) · ∫ [ u² / ( (u² + 1) · (1 + λ²·u²) ) ] du  [підстановка алгебраїчного тотожності]
     = ∫ [ 1 / (1 + λ²·u²) ] du - ∫ [ 1 / (1 + u²) ] du          [розклад на суму найпростіших дробей]
     = (1 / λ) · arctan(λ · u) - arctan(u)                       [інтегрування табличних арктангенсів]
```

Повертаючись до початкових змінних `u = √(M² - 1)` та `λ = √((γ - 1) / (γ + 1))`, отримуємо точний аналітичний вираз для **функції Прандтля — Майєра** `ν(M)`:

```
ν(M) = √((γ + 1) / (γ - 1)) · arctan( √((γ - 1) / (γ + 1) · (M² - 1)) ) - arctan( √(M² - 1) )
```

У цій формулі кут `ν(M)` отримується в **радіанах**. Для переведення в градуси результат множиться на `180 / π`.

## 5. Раціональна апроксимація оберненої функції ν⁻¹(ν)

У комп'ютерних програмах та симуляторах реального часу часто виникає потреба обчислювати обернену функцію `M = ν⁻¹(ν)` без виконання ітераційних циклів Ньютона — Рафсона. Для цього використовують раціональні наближення Голла (англ. *Hall's rational approximation*).

Для двоатомного газу (`γ = 1.40`, де `ν_max ≈ 130.454°` або `2.2769` рад) формула Голла задається виразом:

```
y = (ν / ν_max)^(2/3)
```

За цією проміжною змінною `y` число Маха обчислюється раціональним дробом:

```
M_approx = ( 1.0 + A₁·y + A₂·y² + A₃·y³ ) / ( 1.0 + B₁·y + B₂·y² )
```

де коефіцієнти для `γ = 1.40` мають значення:
- `A₁ = 1.3604`
- `A₂ = 0.0962`
- `A₃ = -0.0031`
- `B₁ = -0.5614`
- `B₂ = -0.0815`

Ця формула дає відносну похибку менше ніж `0.05%` в усьому діапазоні від `M = 1.0` до `M = 10.0`, що робить її ідеальним інструментом для швидкого формування початкового наближення.

## 6. Граничні властивості та максимальний кут повороту

Аналіз виведеного виразу для `ν(M)` показує дві критичні точки:

1. **Звуковий потік (`M = 1`):**
   ```
   u = √(1² - 1) = 0
   arctan(0) = 0
   ν(1) = 0 rad = 0°
   ```
   Це підтверджує, що функція нормована так, що для звукового потоку кут повороту дорівнює нулю.

2. **Нескінченне число Маха (`M → ∞`):**
   При `M → ∞` аргументи обох арктангенсів прямують до нескінченності, а самі арктангенси — до `π / 2`:
   ```
   lim_{M→∞} arctan(...) = π / 2
   ```
   Граничне максимальне значення функції Прандтля — Майєра `ν_max` становить:

   ```
   ν_max = (π / 2) · [ √((γ + 1) / (γ - 1)) - 1 ]
   ```

   Для стандартного двоатомного газу (повітря при помірних температурах, `γ = 1.40`):

   ```
   √((γ + 1) / (γ - 1)) = √(2.4 / 0.4) = √6 ≈ 2.44948974
   ν_max = (π / 2) · (2.44948974 - 1)
         = 1.57079632 · 1.44948974
         ≈ 2.2769 rad ≈ 130.454°
   ```

   **Фізичний зміст `ν_max`:** Це абсолютна математична межа кута, на який надзвуковий потік газу з `M₁ = 1` може розвернутися у вакуум (`p₂ → 0`, `T₂ → 0 K`, `M₂ → ∞`).

## 7. Покроковий приклад чисельного розрахунку

Для закріплення математичної теорії розглянемо контрольний приклад розрахунку газодинамічного стану.

**Початкові дані:**
- Робочий газ: повітря (`γ = 1.40`)
- Початкове число Маха: `M₁ = 2.00`
- Початковий статичний тиск: `p₁ = 100 кПа`
- Початкова статична температура: `T₁ = 300 K`
- Геометричний кут повороту опуклої стінки: `Δθ = 15.0°` (`0.2618 rad`)

**Покроковий розрахунок:**

1.Обчислюємо початковий кут Маха:
  `μ₁ = arcsin(1 / 2.0) = 30.0°`

2.Обчислюємо початкове значення функції Прандтля — Майєра:
  `ν₁ = ν(2.00) = 26.380°` (`0.4604 rad`)

3.Обчислюємо цільове значення функції за веєром розширення:
  `ν₂ = ν₁ + Δθ = 26.380° + 15.000° = 41.380°` (`0.7222 rad`)

4.Знаходимо вихідне число Маха `M₂` інвертуванням `ν(M₂) = 41.380°`:
  За допомогою методу Ньютона отримуємо `M₂ = 2.5972`

5.Обчислюємо новий кут Маха на виході з веєра:
  `μ₂ = arcsin(1 / 2.5972) = 22.641°`

6.Обчислюємо газодинамічний термодинамічний температурний коефіцієнт:
  `τ₁ = 1 + 0.2 · (2.00)² = 1.8000`
  `τ₂ = 1 + 0.2 · (2.5972)² = 2.3491`
  `T₂ / T₁ = τ₁ / τ₂ = 1.8000 / 2.3491 = 0.7662`
  `T₂ = 300 K · 0.7662 = 229.87 K` (`-43.28 °C`)

7.Обчислюємо перепад статичного тиску:
  `p₂ / p₁ = (0.7662)^(1.4 / 0.4) = (0.7662)^3.5 = 0.3957`
  `p₂ = 100 кПа · 0.3957 = 39.57 кПа`

8.Обчислюємо перепад статичної густини:
  `ρ₂ / ρ₁ = (0.7662)^(1 / 0.4) = (0.7662)^2.5 = 0.5164`

Таким чином, у результаті повороту на `15°` число Маха зросло з `2.00` до `2.60`, статичний тиск впав на `60.4%`, а температура впала на `70.1 K`.
