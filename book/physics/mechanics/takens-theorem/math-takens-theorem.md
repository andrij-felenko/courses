# 🧮 Математичне доведення та диференціальна топологія теореми Такенса

Математичне обґрунтування реконструкції фазового простору за часовими затримками спирається на апарат гладкої диференціальної топології, теореми про вкладення Уїтні, теорію трансверсальності Тома та властивості загального положення у просторах функцій. У цій вставці наведено строге математичне формулювання теореми Флоріса Такенса (1981), її узагальнення для фрактальних хаотичних атракторів (теорема Зауера-Йорка-Касдаглі 1991 року), теорію струменів, аналітичний розрахунок реконструкції для 2D осцилятора, а також детальний аналіз двох головних топологічних перешкод — втрати гладкості (імерсії) та виникнення самоперетинів (ін'єктивності).

---

### 1. Формальна постановка задачі та математичні об'єкти

Розглянемо гладкий скінченновимірний компактний многовид `M` вимірності `d` класу гладкості `C^k` (де `k ≥ 2`).

Нехай на многовиді `M` задано гладке векторне поле `f ∈ χ^k(M)`, яке генерує однопараметричну групу дифеоморфізмів — фазовий потік `φ_t: M → M`, такий що для будь-якої точки `x ∈ M`:

```
d(φ_t(x)) / dt = f(φ_t(x)),   φ_0(x) = x
```

Нехай `y: M → R` є гладкою функцією спостереження (скалярним вимірювальним оператором), що належить простору `C^k(M, R)`. Топологія на просторі функцій `C^k(M, R)` визначається нормою Уїтні, яка враховує рівномірне наближення не лише самих функцій, але й усіх їхніх частинних похідних до порядку `k` включно:

```
|| y ||_{C^k} = max_{x ∈ M} ( |y(x)| + || Dy(x) || + ... + || D^k y(x) || )
```

Фізично функція спостереження `y(x)` моделює дію вимірювального приладу (датчика), який перетворює стан системи `x ∈ M` у єдине скалярне число `s(t) = y(x(t))`. Завдяки нелінійній динаміці фазового потоку `φ_t`, інформація про всі інші приховані координати фазового простору розгортається у часі і закарбовується у послідовних похідних та затримованих значеннях цього єдиного сигналу. Кожен новий відлік затримки `s(t - k·τ)` додає до реконструкції одну незалежну ортогональну проекцію фазового траєкторії.

Зафіксуємо часову затримку `τ > 0` та ціле число `m ∈ N` (вимірність вкладення). Означимо **мапу часових затримок Такенса** `Ф_{(m, τ, f, y)}: M → R^m` наступним векторним співвідношенням:

```
Ф(x) = ( y(x),  y(φ_{-τ}(x)),  y(φ_{-2τ}(x)),  ...,  y(φ_{-(m-1)τ}(x)) )
```

У практичних застосуваннях використовується зворотний напрямок за часу `φ_{-τ}`, що відповідає збиранню минулих значень сигналу `s(t), s(t-τ), ..., s(t-(m-1)τ)` для поточного стану `x(t)`.

Головна мета полягає у доведенні того, що відображення `Ф` є **вкладенням (гладким дифеоморфізмом на свій образ)**.

### 2. Дифеоморфізм, імерсія та теорема Уїтні

Нагадаємо топологічні критерії того, коли мапа `Ф: M → R^m` є вкладенням многовиду `M` у евклідів простір `R^m`:

1. **Ін'єктивність (відсутність самоперетинів)**: Для будь-яких двох різних точок `x₁ ≠ x₂` з многовиду `M` їхні образи у просторі затримок не збігаються:
   ```
   Ф(x₁) ≠ Ф(x₂)
   ```
2. **Імерсія (відсутність виродження похідної)**: У кожній точці `x ∈ M` касаційне відображення (матриця Якобі) `DФ_x: T_x M → T_{Ф(x)} R^m` має максимальний ранг, що дорівнює вимірності многовиду `d`:
   ```
   rank( DФ_x ) = d   для всіх x ∈ M
   ```
3. **Гомеоморфізм на образ**: Оскільки `M` є компактним многовидом, будь-яка неперервна ін'єктивна імерсія `Ф` автоматично є дифеоморфізмом на свій образ `Ф(M) ⊂ R^m`.

Фундаментальною основою для побудови векторних вкладень є **Теорема Уїтні про вкладення** (Hassler Whitney, 1936):

> **Теорема Уїтні**: Будь-який гладкий компактний `d`-вимірний многовид `M` можна гладко вкласти у евклідів простір `R^(2d+1)`.

Геометричний зміст коефіцієнта `2d + 1` полягає у наступному: множина всіх можливих впорядкованих пар точок `(x₁, x₂)` у декартовому добутку `M × M` утворює многовид вимірності `2d`. Щоб уникнути перетину траєкторій при проекціюванні у просторі загального положення, вимірність цільового простору `m` повинна бути строго більшою за вимірність простору конфліктних пар:

```
m ≥ 2d + 1
```

Геніальність Флоріса Такенса полягала у тому, що замість `2d + 1` різних незалежних функцій Уїтні використовуються `2d + 1` часові затримки однієї-єдиної вимірюваної функції `y(x)`.

### 3. Теорія струменів та трансверсальність Тома

Для доведення існування вкладень у просторі функцій використовується апарат **простору струменів (Jet Bundles)** та **Теорема Тома про трансверсальність**.

Нехай `J^k(M, R)` позначує простір `k`-струменів гладких функцій на `M`. Точка у `J^k(M, R)` визначається точкою `x ∈ M`, значенням функції `y(x)` та всіма її частинними похідними до порядку `k` включно.

Потік `φ_t` генерує відображення оцінки `ev: M × C^k(M, R) → J^k(M, R)`.

Дві підмноговиди `A` та `B` у гладкому многовиді `N` називаються **трансверсальними** (позначається `A ⋔ B`), якщо у кожній точці їх перетину `p ∈ A ∩ B` сума їхніх касаційних просторів покриває весь касаційний простір носія:

```
T_p A + T_p B = T_p N
```

> **Параметрична теорема Тома про трансверсальність**: Якщо відображення оцінки є трансверсальним до підмноговиду `W ⊂ J^k(M, R)`, то множина функцій `y ∈ C^k(M, R)`, для яких розріз `j^k y ⋔ W`, є залишковою множиною (відкритою та усюди щільною у топології Уїтні `C^k`).

Згідно з теоремою про категорії Бера, залишкова множина є повсюдно щільною і представляє властивості «загального положення» (generic properties). Це означає, що відхилення від властивості вкладення можуть виникати лише на множинах нульової міри.

### 4. Строге формулювання Теореми Такенса (1981)

Позначимо через `G` відкриту усюди щільну множину у просторі пар `χ^2(M) × C^2(M, R)`.

> **Теорема Такенса (1981)**: Припустимо, що `m ≥ 2d + 1`. Тоді для типової пари `(f, y) ∈ G` (векторного поля `f` та функції спостереження `y`) та для довільної часової затримки `τ > 0` мапа затримок:
> ```
> Ф: M → R^m,   Ф(x) = ( y(x),  y(φ_{-τ}(x)),  ...,  y(φ_{-(m-1)τ}(x)) )
> ```
> є вкладенням (дифеоморфізмом класу `C^1`) многовиду `M` у `R^m`. При цьому затримка `τ` не повинна збігатися з періодами замкнених орбіт `T` у сенсі `T = q·τ` для раціональних `q`.

### 5. Детальна схема доведення: подолання двох топологічних перешкод

Доведення теореми розбивається на аналіз двох незалежних умов: умови імерсії (локальна відсутність складок) та умови ін'єктивності (глобальна відсутність самоперетинів).

#### 5.1. Подолання перешкоди 1: Доведення умови імерсії (ранг якобіана)

Обчислимо матрицю Якобі `DФ_x` розміром `m × d` у довільній точці `x ∈ M`:

```
DФ_x = [
  Dy(x),
  Dy(φ_{-τ}(x))   · D(φ_{-τ})_x,
  Dy(φ_{-2τ}(x))  · D(φ_{-2τ})_x,
  ...,
  Dy(φ_{-(m-1)τ}(x)) · D(φ_{-(m-1)τ})_x
]ᵀ
```

Ранг матриці `DФ_x` дорівнює `d` тоді й лише тоді, коли градієнти функцій затримок `∇(y ∘ φ_{-kτ})(x)` для `k = 0, 1, ..., m-1` породжують увесь кокасаційний простір `T_x^* M`.

Розглянемо локальні випадки:

1. **Нерухомі точки (стаціонарні стани)**: Нехай `f(x₀) = 0`. Тоді `φ_{-kτ}(x₀) = x₀` для всіх `k`.
   Якобіан у точці рівноваги приймає вигляд:
   ```
   DФ_{x₀} = [ Dy(x₀),  Dy(x₀)·J,  Dy(x₀)·J²,  ...,  Dy(x₀)·J^{m-1} ]ᵀ
   ```
   де `J = Df(x₀)` — матриця Якобі векторного поля у точці рівноваги.
   У теорії керування ця матриця називається **матрицею спостережуваності Калмана**. Згідно з теоремою Калмана про спостережуваність, ранг цієї матриці дорівнює `d` тоді й лише тоді, коли пара `(J, Dy(x₀))` є повністю спостережуваною (усі власні вектори `J` мають ненульову проекцію на градієнт `Dy(x₀)`).
   У просторі функцій множина функцій `y`, для яких ранг матриці Калмана є меншим за `d`, утворює алгебраїчний многовид додатної ковимірності, а отже, її доповнення є відкритою щільною множиною.

2. **Регулярні (нестаціонарні) точки**: Нехай `f(x) ≠ 0`.
   Завдяки теоремі про спрямлення векторного поля (локальні координати Флоке), потік локально виглядає як паралельне зсунення `dx₁/dt = 1, dx_i/dt = 0`.
   Використовуючи теорему Тома про трансверсальність для струменів порядку `k`, можна довести, що для типової функції `y` диференціали `Dy(φ_{-kτ}(x))` вздовж траєкторії розвертаються нелінійним потоком так, що `m ≥ 2d + 1` градієнтів стають лінійно незалежними у `T_x^* M`.

#### 5.2. Подолання перешкоди 2: Доведення умови ін'єктивності (усунення самоперетинів)

Для доведення глобальної ін'єктивності розглянемо простір пар точок зі зсувом `N = (M × M) \ Δ`, де `Δ = {(x, x) | x ∈ M}` — діагональ простору `M × M`. Вимірність многовиду пар `N` дорівнює `2d`.

Означимо відображення розниці `G: N → R^m`:

```
G(x₁, x₂) = Ф(x₁) - Ф(x₂)
```

Точка `(x₁, x₂) ∈ N` є хибним самоперетином тоді й лише тоді, коли `G(x₁, x₂) = 0`.

Наша мета — довести, що для типової пари `(f, y)` рівняння `G(x₁, x₂) = 0` не має жодного розв'язку на `N`.

Розглянемо компоненти мапи `G`:

```
G_k(x₁, x₂) = y( φ_{-kτ}(x₁) ) - y( φ_{-kτ}(x₂) ),   k = 0, 1, ..., m-1
```

Використовуючи параметричну теорему про трансверсальність до нульового підпростору у `R^m`, розглянемо ковимірність нульової множини `G⁻¹(0)`:
- кожна умова `G_k(x₁, x₂) = 0` накладає один незалежний геометричний зв'язок у просторі `N`;
- оскільки компоненти `G_k` для типового потоку є функціонально незалежними, ковимірність множини спільних нулів `G⁻¹(0)` у просторі `N` дорівнює вимірності цільового простору `m`;
- вимірність множини самоперетинів `S` дорівнює:
  ```
  dim(S) = dim(N) - m = 2d - m
  ```

Якщо вибрати вимірність вкладення `m ≥ 2d + 1`, отримаємо:

```
dim(S) ≤ 2d - (2d + 1) = -1
```

Вимірність `-1` у топології означає, що множина самоперетинів `S` є **порожньою множиною**. Отже, у просторі `R^m` для `m ≥ 2d + 1` не існує жодної пари різних точок `x₁ ≠ x₂`, які б перетиналися при відображенні `Ф`.

### 6. Узагальнення для фрактальних атракторів: Теорема Зауера-Йорка-Касдаглі (1991)

Класична теорема Такенса вимагає знання гладкої вимірності всього многовиду `d`. На практиці хаотичні траєкторії стискаються на дивні атрактори `A ⊂ M`, які займають лише мізерну частину фазового простору і мають дробову фрактальну вимірність.

У 1991 році Тім Зауер, Джеймс Йорк та Мартін Касдаглі довели узагальнену теорему для компактних інваріантних множин (Теорема Ембедології).

Нехай `A ⊂ R^N` — компактна інваріантна множина з **капаситетною (box-counting) вимірністю `d_A`**:

```
d_A = lim_{ε → 0} [ ln N(ε) / ln(1/ε) ]
```

де `N(ε)` — мінімальна кількість кубів розміру `ε`, необхідних для покриття множини `A`.

> **Теорема Зауера-Йорка-Касдаглі (Embedology, 1991)**: Нехай `A` — компактна інваріантна множина з капаситетною вимірністю `d_A`. Якщо вимірність вкладення задовольняє нерівність:
> ```
> m > 2 · d_A
> ```
> то для майже кожної затримки `τ > 0` та для типової функції спостереження `y`:
> 1. мапа затримок `Ф` є ін'єктивною на `A`;
> 2. мапа `Ф` є імерсією на кожному гладкому підмноговиді, що міститься в `A`;
> 3. мапа `Ф` точно зберігає локальну Hausdorff-вимірність та всі раціональні фрактальні вимірності `d_q` (зокрема кореляційну вимірність `d₂`).

Цей результат є надзвичайно важливим для фізики: якщо дивний атрактор Лоренца має фрактальну вимірність `d_A ≈ 2.06`, то за теоремою Такенса для гладкого 3D простору потрібна була б вимірність `m = 2·3 + 1 = 7`. Проте за теоремою Зауера-Йорка достатньо вибрати ціле `m > 2 · 2.06 = 4.12`, тобто `m = 5`.

### 7. Аналітичний розрахунок вкладення для 2D гармонічного осцилятора

Щоб проілюструвати роботу мапи Такенса на конкретному механічному прикладі, розглянемо лінійний двовимірний гармонічний осцилятор із власною частотою `ω`:

```
dx₁/dt = x₂
dx₂/dt = -ω² · x₁
```

Справжній фазовий простір є двовимірним `(d = 2)` з координатами `(x₁, x₂) ∈ R²`, де `x₁` — зміщення, `x₂` — швидкість.

Фазовий потік системи у момент часу `t` задається матрицею повороту:

```
x₁(t) = x₁(0)·cos(ω·t) + (x₂(0)/ω)·sin(ω·t)
x₂(t) = -x₁(0)·ω·sin(ω·t) + x₂(0)·cos(ω·t)
```

Припустимо, що в експерименті ми вимірюємо лише зміщення `y(x) = x₁`. Побудуємо мапу Такенса вимірності `m = 3` з затримкою `τ`:

```
Ф(x₁, x₂) = ( y₀,  y₁,  y₂ )
```

де:
```
y₀ = y(x₁, x₂) = x₁
y₁ = y(φ_{-τ}(x₁, x₂)) = x₁·cos(ω·τ) - (x₂/ω)·sin(ω·τ)
y₂ = y(φ_{-2τ}(x₁, x₂)) = x₁·cos(2ω·τ) - (x₂/ω)·sin(2ω·τ)
```

Знайдемо матрицю Якобі `DФ` розміром `3 × 2`:

```
DФ = [
  [ 1,                           0                       ],
  [ cos(ω·τ),                   -(1/ω)·sin(ω·τ)          ],
  [ cos(2ω·τ),                  -(1/ω)·sin(2ω·τ)         ]
]
```

Розглянемо детермінант перших двох рядків цієї матриці:

```
det( DФ_{1,2} ) = 1 · [ -(1/ω)·sin(ω·τ) ] - 0 · cos(ω·τ) = -(1/ω)·sin(ω·τ)
```

Ранг матриці Якобі дорівнює `2` (максимальний ранг `d = 2`) тоді й лише тоді, коли:

```
det( DФ_{1,2} ) ≠ 0   ⇒   sin(ω·τ) ≠ 0   ⇒   ω·τ ≠ k·π  (k ∈ Z)
```

Це означає, що затримка `τ` не повинна бути кратною напівперіоду коливань `T/2 = π/ω`. За цієї умови мапа Такенса є імерсією!

Тепер явно виразимо приховану змінну швидкості `x₂` за першими двома координатами затримки `(y₀, y₁)`:

```
y₁ = y₀ · cos(ω·τ) - (x₂/ω) · sin(ω·τ)
⇒  x₂ = ω · [ y₀ · cos(ω·τ) - y₁ ] / sin(ω·τ)
```

Ми отримали точну аналітичну формулу, яка відновлює приховану фізичну швидкість `x₂` виключно за двома виміряними значеннями зміщення `y₀ = s(t)` та `y₁ = s(t-τ)`. Це пряма конструктивна демонстрація теореми Такенса у механіці.

### 8. Нетипові та вироджені випадки: де теорема ламається

У практичних обчисленнях важливо знати межі застосовності теореми Такенса. Існують три класи нетипових випадків, коли умова вкладення порушується:

1. **Симетрія функції спостереження**:
   Якщо векторне поле та атрактор володіють симетрією (наприклад, непарна симетрія атрактора Лоренца `(x, y, z) → (-x, -y, z)`), а функція спостереження підпорядковується непарній симетрії `y(-x) = -y(x)`, то мапа затримок відображає симетричні точки `x` та `-x` у протилежні вектори `Ф(-x) = -Ф(x)`. Якщо при цьому вимірювати парну змінну `z(t)` (яка однакова для обох віток атрактора), відображення склеює дві вітки атрактора в одну, створюючи дволисний самоперетин (двозначне накриття) і руйнуючи ін'єктивність.

2. **Резонанс затримки та періодичних орбіт**:
   Якщо у системі існує замкнена періодична орбіта з періодом `T`, і затримка вибрана так, що `τ = (p/q) · T` для цілих `p, q`, то затримкові координати утворюють замкнений зв'язок. Наприклад, при `τ = T` мапа дає `y(t) = y(t-τ) = y(t-2τ) = ...`, вироджуючи весь `m`-вимірний вектор у 1D діагональ `(s(t), s(t), ..., s(t))`.

3. **Втрата спостережуваності Калмана**:
   Якщо фізична система розпадається на декілька заповнених підсистем, які не взаємодіють між собою (відсутність нелінійного зв'язку у векторному полі), вимірювання змінної однієї підсистеми принципово не містить інформації про динаміку другої. Ранг якобіана `DФ` падає до вимірності лише першої підсистеми.

### 9. Спектральні та динамічні інваріанти, що зберігаються при дифеоморфізмі

Оскільки мапа Такенса `Ф: A → Ф(A) ⊂ R^m` є дифеоморфізмом, вона є співвідношенням еквівалентності у категорії гладких динамічних систем. Це гарантує точне збереження наступних нелінійних інваріантів:

1. **Кореляційний інтеграл та вимірність Грассбергера-Прокаччі `d₂`**:
   Означимо кореляційний інтеграл у просторі `R^m`:
   ```
   C(r) = lim_{N → ∞} [ 2 / (N·(N-1)) ] · ∑_{i < j} Θ( r - || Y_i - Y_j || )
   ```
   де `Θ(z)` — функція Хевісайда (`Θ(z) = 1` при `z ≥ 0` та `0` при `z < 0`).
   Оскільки дифеоморфізм локально розтягує відстані не більше ніж у `||DФ||` та `||DФ⁻¹||` разів, у границі `r → 0` степенний закон `C(r) ∝ r^{d₂}` має абсолютно однаковий показник `d₂` як у вихідному фазовому просторі `M`, так і у відновленому просторі затримок `R^m`.

2. **Динамічні показники Ляпунова**:
   Усі додатні показники Ляпунова `λ_i > 0` відновленого атрактора строго збігаються з додатними показниками вихідної фізичної системи;
   Сума додатних показників Ляпунова (ентропія Песіна `h_{KS} = ∑ λ_i^+`) залишається інваріантною відносно вибору функції спостереження `y(t)`.

Таким чином, математична теорема Такенса гарантує, що відновлений у просторі затримок атрактор є не просто візуальною імітацією, а абсолютно точним динамічним еквівалентом реальної нелінійної фізичної системи.
