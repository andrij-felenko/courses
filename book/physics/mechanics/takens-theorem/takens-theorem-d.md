### 1. Проблема спостережуваності та обмеженість вимірювань у фізичних системах

Еволюція довільної неперервної нелінійної динамічної системи у фізиці описується автономною системою диференціальних рівнянь першого порядку:

```
dX / dt = F( X(t) )
```

де `X(t) = ( x₁(t), x₂(t), ..., x_d(t) )` — вектор стану, що належить `d`-вимірному гладкому багатовиду `M` (фазовому простору системи), а `F: M → TM` — векторне поле, що визначає локальні швидкості зміни кожної компоненти.

У реальних фізичних умовах вектори стану `X(t)` знаходяться всередині замкненого об'єму або недоступні для прямого вимірювання через відсутність відповідних вимірювальних приладів. Наприклад, у конвективній комірці Бенара-Релеї повний стан рідини описується нескінченновимірним полем швидкостей `v(r, t)` та температурним полем `T(r, t)`. Проте експериментатор зазвичай спроможний встановити лише один точковий терморезистор або датчик швидкості в одній конкретній точці простору.

Аналогічна ситуація виникає в аерокосмічній техніці при вимірюванні згинальних коливань крила літака за допомогою одного тензодатчика, у кардіології при реєстрації одного відведення електрокардіограми, а також при діагностиці зносу зупчастих передач у важкому машинобудуванні за допомогою акселерометра, встановленого на зовнішньому корпусі редуктора.

У результаті вимірювальний прилад здійснює скалярну проекцію фазового стану системи:

```
s(t) = y( X(t) )
```

де `y: M → R` — гладка скалярна функція спостереження (Measurement Function).

Функція спостереження `y(X)` описує передавальну характеристику датчика. Вона може бути лінійною проекцією (наприклад, вимірюванням першої координати `y(X) = x₁`) або складною нелінійною комбінацією декількох фізичних величин (наприклад, поєднанням температури та тиску через нелінійну криву чутливості сенсора).

Протягом тривалого часу головною перешкодою для аналізу складних сигналів була проекційна неповнота скалярного сигналу `s(t)`. Здавалося, що втрата `d - 1` ортогональних координат безповоротно знищує топологічну структуру фазової траєкторії. Перші спроби відновити фазовий простір спиралися на обчислення послідовних часових похідних сигналу:

```
Y_deriv(t) = ( s(t),  ds/dt,  d²s/dt²,  ...,  d^{m-1}s / dt^{m-1} )
```

З теоретичної точки зору для аналітичних функцій похідні дійсно утворюють повноцінну систему координат. Проте в реальному фізичному експерименті цей підхід виявляється повністю непридатним через чутливість операції чисельного диференціювання до вимірювальних шумів. Якщо виміряний сигнал містить адитивний вимірювальний шум `η(t)` з амплітудою `σ` та частотою `ω`, обчислення `k`-ої похідної призводить до посилення амплітуди шуму пропорційно `σ · ω^k`. Вже друга та третя похідні зашумленого сигналу перетворюються на хаотичне коливання шуму приладу, повністю маскуючи корисну фізичну динаміку.

У 1980 році вчені з так званої «Кабали хаосу Санта-Крус» (Chaos Cabal) — Пакард, Кратчфілд, Фармер та Шоу — запропонували принципово інший підхід: замість чисельних похідних використовувати часові затримки сигналу. Детальний хронологічний опис розвитку нелінійного аналізу та внесок наукових груп описано в [історичному екскурс про відновлення атракторів за часовими рядами](book:physics/mechanics/takens-theorem/hist-takens-theorem.md).

### 2. Механізм часових затримок та векторний простір реконструкції

Фізична сутність методу затримок спирається на той факт, що нелінійна система є динамічно зв'язаною. Значення скалярної величини `s(t)` у минулі моменти часу `t - τ`, `t - 2τ`, ..., `t - (m-1)τ` несуть у собі накопичену інформацію про попередній фазовий стан системи, а отже, пов'язані з поточним станом через дію нелінійного фазового потоку `Φ^t`.

З виміряного одномірного часового ряду `s(t)` формується штучний `m`-вимірний вектор затримок `Y(t)`:

```
Y(t) = ( s(t),  s(t - τ),  s(t - 2τ),  ...,  s(t - (m - 1)τ) )
```

де `τ > 0` — часова затримка (Delay Time), а `m ∈ N` — вимірність вкладення (Embedding Dimension).

![Концепція затримкового вкладення Такенса](/book/physics/mechanics/takens-theorem/img/takens-embedding-concept.svg)
*Рис. 1: Концепція реконструкції багатовимірного фазового простору з одномірного часового ряду за допомогою векторів часових затримок.*

Для дискретизованого скалярного сигналу `s_k = s(k · Δt)`, де `k = 1, 2, ..., N`, вектор затримок будується як послідовність точок у евклідовому просторі `R^m`:

```
Y_k = ( s_k,  s_{k - p},  s_{k - 2p},  ...,  s_{k - (m-1)p} )
```

де `p = τ / Δt` — цілочисельний зсув у відліках (Delay Steps).

Сукупність усіх побудованих векторів `Y_k` формує траєкторну матрицю затримок розміром `(N - (m-1)p) × m`. Кожен рядок цієї матриці задає координати однієї точки у відновленому штучному фазовому просторі `R^m`. Головне питання, яке постає перед математичною физикою: за яких фундаментальних умов штучний атрактор, утворений траєкторією векторів `Y_k` у `R^m`, буде топологічно тотожним справжньому атрактору, що існує у недоступному фазовому просторі `M`?

#### 2.1. Фізична інтуїція: чому затримки замінюють невідомі координати
Розглянемо найпростіший випадок лінійного гармонічного осцилятора `d²x/dt² + ω² x = 0`. Його фазовий простір є двовимірним `(x, v)`, де `v = dx/dt`. Розв'язок має вигляд `x(t) = A cos(ω t + φ)`.
Якщо ми вимірюємо лише `s(t) = x(t)`, то зсунутий за часом сигнал буде дорівнювати:

```
s(t - τ) = A cos(ω t + φ - ω τ) = A cos(ω t + φ) cos(ω τ) + A sin(ω t + φ) sin(ω τ)
```

Якщо вибрати затримку `τ = π / (2 ω)` (тобто чверть періоду коливань `T / 4`), отримуємо:

```
s(t - τ) = A sin(ω t + φ) = - (1 / ω) (dx / dt)
```

Таким чином, затриманий за часом сигнал `s(t - τ)` стає прямо пропорційним швидкості `v(t)` з протилежним знаком! Фазова траєкторія у координатах `(s(t), s(t-τ))` утворює коло або еліпс, повністю ідентичний класичному фазовому портрету `(x, v)`. 

У нелінійних хаотичних системах залежність між змінами координат є складнішою, проте принцип залишається аналогічним: координати затримки виступають як нелінійні інтегральні трансформації минулих станів, розгортаючи приховані ступені вільності у багатовимірний фазовий простір.

### 3. Геометрія вкладень: від теореми Уітні до фундаментальної нерівності Такенса

Відповідь на це запитання дає диференціальна топологія. Два багатовиди називаються топологічно еквівалентними, якщо між ними існує **дифеоморфізм** — взаємно однозначне гладке відображення, обернене до якого також є гладким. 

Якщо відображення з вихідного фазового простору `M` у відновлений простір затримок `R^m` є дифеоморфізмом, воно діє як ідеальна нелінійна деформація без розривів та склеювань. Таке відображення строго зберігає всі ключові геометричні та нелінійні інваріанти: фрактальну вимірність атрактора, спектр показників Ляпунова, ентропію Шеннона-Колмогорова та топологічну вузлуватість замкнених траєкторій.

#### 3.1. Теорема Уітні про гладкі вкладення
У 1936 році американський математик Хасслер Уітні (Hassler Whitney) довів фундаментальну теорему диференціальної топології: будь-який гладкий `d`-вимірний многовид `M` можна гладко вкласти у евклідів простір `R^{2d + 1}`.

Нерівність `2d + 1` має чітке геометричне пояснення. Розглянемо виникнення самоперетинів при проектуванні багатовимірного об'єкта. Якщо `d`-вимірний многовид проектується у простір вимірності `m`, умова перетину двох `d`-вимірних поверхневих сегментів у `R^m` описується системою `m` незалежних рівнянь відносно `2d` локальних координат (по `d` координат на кожному сегменті).

Якщо `m < 2d`, кількість невідомих перевищує кількість рівнянь (`2d > m`), і система має стійкі розв'язки. Це означає, що при проектуванні неминуче виникають хибні самоперетини траєкторій (точки перетину, які насправді знаходяться далеко одна від одної у вихідному просторі). Наявність самоперетинів руйнує детермінізм: в одній точці перетину вектор швидкості системи стає неоднозначним.

Якщо ж `m ≥ 2d + 1`, кількість рівнянь перевищує кількість невідомих (`m > 2d`), і система не має розв'язків для майже всіх проекцій. Перетини траєкторій зникають, а відображення стає ін'єктивним.

#### 3.2. Теорема Такенса (1981)
У 1981 році голландський математик Флоріс Такенс (Floris Takens) довів, що для побудови гладкого вкладення не потрібно знати `2d + 1` окремих координат. Достатньо виміряти лише одну скалярну величину `s(t)` і сформувати вектор часових затримок.

**Строге формулювання теореми Такенса**:
Нехай `M` — компактний гладкий многовид вимірності `d`. Нехай `Φ^t: M → M` — гладкий динамічний потік, а `y: M → R` — гладка скалярна функція спостереження. Тоді відображення затримки `Φ_{y, τ}: M → R^m`, визначене як:

```
Φ_{y, τ}(x) = ( y(x),  y(Φ^{-τ}(x)),  y(Φ^{-2τ}(x)),  ...,  y(Φ^{-(m-1)τ}(x)) )
```

є **вкладенням** (тобто дифеоморфізмом многовиду `M` на його образ `Φ_{y, τ}(M) ⊂ R^m`) для типових (generic) пар `(Φ, y)`, якщо вимірність вкладення задовольняє умову:

```
m ≥ 2d + 1
```

Термін «типові» (generic) у математичному сенсі означає, що пари `(Φ, y)`, для яких відображення `Φ_{y, τ}` не є вкладенням, утворюють множину першої категорії за Бером (всюди нещільну множину у просторі гладких функцій зі слабкою топологією Уітні). Це означає, що у реальному фізичному світі при довільному виборі гладкого датчика та відсутності спеціальних симетрій відображення Такенса є вкладенням майже завжди.

![Проекція та дифеоморфізм атрактора](/book/physics/mechanics/takens-theorem/img/diffeomorphism-projection.svg)
*Рис. 2: Виникнення штучних самоперетинів проекції атрактора при m < 2d_A та відновлення гладкого дифеоморфного вкладення без перетинів при m ≥ 2d_A + 1.*

#### 3.3. Узагальнення Зауера-Йорка-Касдаглі (Embedology)
У 1991 році Тім Зауер (Tim Sauer), Джеймс Йорк (James Yorke) та Мартін Касдаглі (Martin Casdagli) у своїй фундаментальній праці «Embedology» розширили теорему Такенса на випадок фрактальних атракторів.

У більшості хаотичних дисипативних систем атрактор займає лише малу частину фазового простору `M` і має фрактальну вимірність `d_A < d` (наприклад, ємкісну вимірність Хаусдорфа або вимірність Каплана-Йорке). Зауер та колеги довели, що нерівність Такенса можна послабити: замість цілочисельної вимірності фазового простору `d` достатньо вимагати, щоб вимірність вкладення задовольняла фрактальну нерівність:

```
m > 2 d_A
```

де `d_A` — фрактальна вимірність хаотичного атрактора.

Строгі математичні доведення леми про занурення (immersion), ін'єктивність та теорію трансверсальності Тома наведено у [строгому математичному доведенні теореми Такенса та диференціальній топології вкладень](book:physics/mechanics/takens-theorem/math-takens-theorem.md).

### 4. Вибір практичних параметрів: часова затримка `τ` та вимірність `m`

Математична теорема Такенса сформульована для ідеального випадку: нескінченно довгого сигналу, відсутності вимірювальних шумів та нескінченної чисельної точності. У цьому ідеалі значення затримки `τ` може бути довільним додатним числом. Проте при обробці реальних фізичних сигналів вибір параметрів `τ` та `m` стає критично важливим для мінімізації впливу шуму та обмеженості вибірки.

![Оптимізація параметрів затримки та вимірності](/book/physics/mechanics/takens-theorem/img/tau-m-selection.svg)
*Рис. 3: Графіки оцінки оптимальних параметрів: перший місцевий мінімум взаємної інформації I(τ) для вибору затримки та монотонне падіння відсотка хибних сусідів FNN(m) для вибору вимірності.*

#### 4.1. Визначення оптимальної часової затримки `τ`
Вибір затримки `τ` підпорядковується компромісу між двома крайнощами:

- **Надмірно мала затримка (`τ → 0`)**: Значення `s(t)` та `s(t-τ)` є майже тотожними. Усі координати вектора затримок `Y(t)` мають близькі значення, і відновлений атрактор стискається вздовж головної діагоналі простору `R^m`. Утворюється вироджена проекція з високою чутливістю до дрібних шумів.
- **Надмірно велика затримка (`τ >> τ_c`)**: Через наявність хаотичної розбіжності траєкторій зв'язок між `s(t)` та `s(t-(m-1)τ)` повністю втрачається. Вектори затримок стають статистично незалежними випадковими величинами, і геометрична структура атрактора розпадається у безструктурне хмару точок.

Для пошуку оптимальної затримки застосовують два методи:

1. **Перший нуль автокореляційної функції**: Вибирають `τ`, при якому автокореляція `C(τ) = <s(t) s(t+τ)>` вперше стає рівною нулю. Цей підхід вимірює лише лінійну незалежність координат і є недостатнім для сильно нелінійних систем.
2. **Перший місцевий мінімум середньої взаємної інформації (Mutual Information)**: Метод Фрейзера-Свінні (Fraser & Swinney, 1986). Взаємна інформація `I(τ)` вимірює кількість інформації про стан `s(t+τ)`, яку надає вимірювання `s(t)` з урахуванням усіх нелінійних зв'язків:

```
I(τ) = ∑ P(s(t), s(t+τ)) · log₂ [ P(s(t), s(t+τ)) / ( P(s(t)) · P(s(t+τ)) ) ]
```

Перший мінімум функції `I(τ)` гарантує оптимальну статистичну незалежність координат затримки без руйнування топологічної неперервності траєкторії.

#### 4.2. Визначення вимірності вкладення `m` (Алгоритм FNN)
Для оцінки мінімально необхідної вимірності `m` використовують алгоритм хибних найближчих сусідів (False Nearest Neighbors, FNN), розроблений Кеннелом, Брауном та Абарбанелем у 1992 році.

Ідея алгоритму спирається на перевірку найближчих сусідів. Для кожного вектора `Y_i^{(m)}` у просторі `R^m` знаходять його найближчого сусіда `Y_j^{(m)}`. Потім обчислюють зміну відстані між ними при переході до вимірності `m + 1` (додаванні координати `s_{i + m p}`):

```
R_1 = | s_{i + m p} - s_{j + m p} | / || Y_i^{(m)} - Y_j^{(m)} || > R_{tol}
```

Якщо відношення `R_1` перевищує поріг `R_{tol}` (зазвичай `10 ≤ R_{tol} ≤ 20`), сусід є хибним — він знаходився поруч лише через недостатню вимірність проекції. Також застосовують другий критерій `R_2` для виключення розріджених областей атрактора, де відстань між точками порівнянна з розміром самого атрактора `R_{attr} = σ_s`:

```
R_2 = || Y_i^{(m+1)} - Y_j^{(m+1)} || / R_{attr} > 2.0
```

Частка хибних сусідів `FNN(m)` розраховується для `m = 1, 2, 3, ...`. Найменше `m`, при якому `FNN(m)` падає нижче 1%, вибирається як мінімальна вимірність вкладення Такенса.

Алгоритмічну реалізацію, оцінку складності та приклади коду мовами C, C++ та Python наведено у [практичній реалізації алгоритмів реконструкції фазового простору](book:physics/mechanics/proj-attractor-reconstruction.md) та у [довіднику інтерфейсу бібліотеки реконструкції атрактора](book:physics/mechanics/takens-theorem/api-delay-embedding.md).

### 5. Покроковий чисельний аналіз реконструкції атрактора Лоренца

Для наочного розуміння дії теореми Такенса розглянемо класичну нелінійну систему Лоренца (1963), яка описує теплову конвекцію у шарі рідини:

```
dx/dt = σ (y - x)
dy/dt = x (ρ - z) - y
dz/dt = x y - β z
```

з класичними параметрами хаосу: `σ = 10.0`, `ρ = 28.0`, `β = 8/3`.

Фазовий простір цієї системи є тривимірним `M = R³` (`d = 3`). Фрактальна вимірність атрактора Лоренца становить `d_A ≈ 2.06`.

#### 5.1. Реконструкція заодним скалярним сигналом `x(t)`
Припустимо, що змінні `y(t)` та `z(t)` є повністю прихованими, а вимірюється лише одномірна координата `s(t) = x(t)`.

1. **Розрахунок взаємної інформації**: Для згенерованого ряду `x(t)` функція взаємної інформації `I(τ)` демонструє перший місцевий мінімум при `τ = 0.17` секунди (`p = 17` відліків при `Δt = 0.01` с).
2. **Оцінка хибних сусідів FNN**:
   - При `m = 1`: `FNN = 98.4%` (проекція 3D атрактора на 1D вісь створює повне накладання траєкторій);
   - При `m = 2`: `FNN = 64.1%` (плоска проекція `(x(t), x(t-τ))` містить численні самоперетини у формі «метелика»);
   - При `m = 3`: `FNN = 0.8%` (крива FNN стрибкоподібно спадає нижче 1%).
3. **Результат вкладення**: Згідно з теоремою Зауера, оскільки `d_A ≈ 2.06`, умова `m > 2 d_A = 4.12` у строгому математичному сенсі вимагає `m = 5`. Проте для системи Лоренца практичний алгоритм FNN показує, що вже при `m = 3` самоперетини зникають, оскільки топологічна вимірність многовиду дорівнює 3.

Побудований у `R³` вектор `Y(t) = ( x(t), x(t-τ), x(t-2τ) )` відтворює знамениту двопетельну структуру «двох крил метелика» Лоренца. Відновлений атрактор є повністю дифеоморфним вихідному атрактору `(x(t), y(t), z(t))`: він не має штучних перетинів траєкторій, а його товщина та петельні згини строго відповідають топології вихідної системи.

### 6. Детальний порівняльний аналіз реконструкції системи Реслера та осцилятора Дуффінга

Для глибшого розуміння універсальності теореми Такенса порівняємо реконструкцію двох інших еталонних нелінійних систем механіки та фізики: атрактора Реслера та вимушеного осцилятора Дуффінга.

#### 6.1. Атрактор Реслера (Rössler Attractor)
Система Реслера описується трьома нелінійними рівняннями з єдиним квадратичним членом:

```
dx/dt = -y - z
dy/dt = x + a y
dz/dt = b + z (x - c)
```

з параметрами `a = 0.2`, `b = 0.2`, `c = 5.7`.

Фрактальна вимірність атрактора Реслера `d_A ≈ 2.01`. Головною особливістю цієї системи є чітко виражене стрічкове скручування (ленточний атрактор): траєкторія обертається у площині `(x, y)`, а при досягненні критичного радіуса викидається вгору вздовж осі `z` та знову повертається на основний дипольний виток.

При вимірюванні лише скалярного сигналу `x(t)` перший мінімум взаємної інформації дає затримку `τ ≈ T_orbit / 4`, де `T_orbit ≈ 6.0` секунд — період обертання фазової точки навколо центру. Векторне вкладення у `R³` повністю відновлює топологічну структуру стрічки Реслера, включаючи геометрію складки (fold bifurcation) у перетині Пуанкаре.

#### 6.2. Вимушений неавтономний осцилятор Дуффінга
Розглянемо двоямовий осцилятор Дуффінга з зовнішнім періодичним збудженням, який описує нелінійні коливання пружної балки у магнітному полі:

```
d²x / dt² + δ (dx / dt) - x + x³ = γ cos(ω t)
```

Переходячи до системи рівнянь першого порядку, отримуємо 3D фазовий простір `(x, v, θ)`:

```
dx/dt = v
dv/dt = x - x³ - δ v + γ cos(θ)
dθ/dt = ω
```

Оскільки система є неавтономною, координата фази вимушуючої сили `θ(t) = ω t` робить фазовий простір періодичним по часу. Фрактальна вимірність хаотичного атрактора Дуффінга становить `d_A ≈ 2.45`.

При виконанні фазової реконструкції за одномірним вібраційним зміщенням `x(t)` взаємна інформація дає мінімум біля `τ = T_drive / 4 = π / (2 ω)`. Проте на відміну від системи Реслера, для осцилятора Дуффінга дріб хибних сусідів `FNN(m)` падає нижче 1% лише при `m_{opt} = 4` або `m_{opt} = 5`. Це повністю підтверджує дробову нерівність Зауера `m > 2 · 2.45 = 4.90`: складчаста фрактальна структура перетину Пуанкаре осцилятора Дуффінга вимагає вимірності `R⁵` для повного усунення геометричних перетинів.

### 7. Фільтрація шуму та проекція за головними компонентами (SVD/PCA) у затримковому просторі

У 1986 році Брумхед та Кінг (Broomhead & King) запропонували комбінувати метод затримок Такенса із сингулярним розкладом матриць (SVD) та аналізом головних компонент (PCA).

Якщо вхідний сигнал містить адитивний вимірювальний шум `η(t)`, пряме застосування методів затримок у великій вимірності `M >> m` створює зашумлений фазовий простір. Для його компенсації формується траєкторна матриця затримок великої вимірності `M` (наприклад, `M = 20` або `M = 50`):

```
Y_{full} = ( N_{eff} × M )
```

Коваріаційна матриця траєкторій обчислюється як:

```
C_Y = ( 1 / N_{eff} ) Y_{full}^T Y_{full}
```

Сингулярний розклад матриці `Y_{full} = U Σ V^T` розкладає фазовий простір на впорядковані за енергією ортогональні координати (главні компоненти). Спектр сингулярних чисел `σ₁ ≥ σ₂ ≥ ... ≥ σ_M` складається з двох частин:
- Сигнальна частина: перші `m` великих сингулярних чисел `σ₁, ..., σ_m`, які відповідають справжній хаотичній динаміці атрактора;
- Шумова підлога (Noise Floor): малі сингулярні числа `σ_{m+1}, ..., σ_M`, які утворюють плоске плато зі значенням `σ_{noise} ≈ σ_n √M`.

Проектування траєкторії на перші `m` власних векторів `V_m` виконує оптимальну лінійну фільтрацію вимірювального шуму у фазовому просторі, забезпечуючи високу точність обчислення кореляційного інтегралу та показників Ляпунова.

### 8. Реконструкція фазового простору при нерівномірній та адаптивній дискретизації

У сучасних сенсорних мережах та біомедичних системах часові інтервали між вимірюваннями нерідко є неконстантними (`Δt_k ≠ const`). Наприклад, при аналізі варіабельності серцевого ритму часовий ряд описує послідовність RR-інтервалів `t_k` між скороченнями міокарда.

Застосування стандартного методу затримок з фіксованим зсувом за відліками `p` до нерівномірно дискретизованих рядів спричиняє штучні фазові спотворення. Для адаптації теореми Такенса використовуються два підходи:

1. **Інтерполяція кубічними сплайнами**: Часовий ряд `s(t_k)` інтерполюється гладким кубічним сплайном або SINC-фільтром з подальшою передискретизацією на постійний крок `Δt_{rect}`.
2. **Неперервне затримкове вкладення (Continuous-Time Embedding)**: Вектор затримок обчислюється шляхом пошуку значення `s(t - τ)` через безпосередню неперервну часову затримку `τ` у секундах, а не у відліках index:

```
Y(t) = ( s(t),  s(t - τ),  s(t - 2τ) )
```

Це дозволяє застосовувати теорему Такенса до подійно-орієнтованих сенсорних даних (Event-Triggered Sensors) без втрати геометричної інвар'янтності атрактора.

### 9. Інваріанти хаотичної динаміки, що зберігаються дифеоморфізмом

Головна цінність теореми Такенса полягає у тому, що дифеоморфне вкладення `Φ_{y, τ}` повністю зберігає ключові динамічні та геометричні інваріанти нелінійної системи. Це означає, що розраховані у штучному просторі `R^m` характеристики збігаються з істинними характеристиками системи `M`.

#### 9.1. Збереження кореляційної вимірності `d₂`
За методом Грассбергера-Прокаччі (Grassberger & Procaccia, 1983) кореляційний інтеграл `C(r)` обчислюється як частка пар точок у `R^m`, відстань між якими є меншою за `r`:

```
C(r) = ( 2 / (N (N - 1)) ) ∑ ∑ Θ( r - || Y_i - Y_j || )
```

У масштабній області `r → 0` кореляційний інтеграл підпорядковується степенному закону:

```
C(r) ∝ r^{d₂}   ⇒   d₂ = lim_{r → 0} [ d ln C(r) / d ln r ]
```

Оскільки відображення Такенса є гладким вкладенням, градієнти відстаней трансформуються з обмеженими Якобіанами, що гарантує абсолютну незмінність степенного показника `d₂`.

#### 9.2. Збереження спектра показників Ляпунова
Показники Ляпунова `λ₁ ≥ λ₂ ≥ ... ≥ λ_d` вимірюють середню швидкість експоненційної розбіжності початково близьких траєкторій вздовж головних осей фазового еліпсоїда:

```
δX(t) ∝ δX(0) · exp( λ_i · t )
```

Оскільки мапа Такенса дифеоморфно переносить вектори дотичного простору `T_x M` у дотичний простір `T_{Y} R^m`, додатні показники Ляпунова `λ_i > 0` (які відповідають за генерацію хаосу та втрату інформації) повністю зберігаються при реконструкції. Збереження старшого показника Ляпунова `λ₁` є основою прогнозування горизонту детермінованого хаосу `t_{pred} ≈ 1 / λ₁`.

#### 9.3. Збереження Kolmogorov-Sinai ентропії `K₂`
Ентропія Колмогорова-Синая вимірює швидкість генерації інформації в нелінійній системі. Через нерівність Песіна ентропія `K` пов'язана з сумою додатних показників Ляпунова:

```
K = ∑_{λ_i > 0} λ_i
```

Вона вимірюється через оцінку запізнення кореляційного інтегралу для послідовних вимірностей вкладення `m`. Збереження дифеоморфізму Такенса гарантує точність оцінки ентропії `K₂` за одномірним часовим рядом.

### 10. Крайові випадки, шумова підлога та інженерні обмеження

Незважаючи на потужний математичний апарат, практична застосовність теореми Такенса має фізичні та алгоритмічні межі.

#### 10.1. Багатовимірний хаос та просторово-часова турбулентність
Для систем із великою кількістю ступенів вільного простору (турбулентні потоки рідин, розподілені ланцюги осциляторів, плазмові нестійкості) фрактальна вимірність атрактора може сягати значень `d_A > 20`. 
Згідно з теоремою Зауера, це вимагає вимірності вкладення `m > 40`. Проте обчислювальна складність пошуку найближчих сусідів та розрахунку кореляційного інтегралу зростає експоненційно як `O(N^m)`, а необхідна довжина часового ряду для заповнення `m`-вимірного простору масштабується як `N ≈ 10^{d_A}`. У таких випадках одномірна реконструкція Такенса стає чисельно нереалізовною, що вимагає переходу до просторово-розподілених вимірювань (багатоточкових датчиків).

#### 10.2. Вплив вимірювального шуму та виникнення шумовій підлоги (Noise Floor)
У реальних експериментах скалярний сигнал містить адитивний шум `s(t) = s_{true}(t) + η(t)` з дисперсією `σ_n^2`.
Оскільки білий шум `η(t)` має нескінченну вимірність, на малих масштабах відстаней `r < σ_n` структура атрактора розмивається. На логарифмічному графіку `ln C(r)` від `ln r` виникає злам: при `r > σ_n` нахил кривої відповідає справжній фрактальній вимірності `d₂`, а при `r < σ_n` нахил різко зростає до значення вимірності вкладення `m`.
Для усунення цього дефекту застосовують попереднє шумопониження методом сингулярного розкладу (SVD) або проєкцій за головними компонентами (PCA) у затримковому просторі великої вимірності.

#### 10.3. Вироджені спостереження та неавтономні системи
Теорема Такенса гарантує вкладення лише для «типових» функцій спостереження `y(X)`. Якщо обрана скалярна зміна є парною симетричною функцією відносно центру атрактора (наприклад, `y(t) = x₁(t)^2` для симетричної системи), мапа затримок втрачає ін'єктивність: точки з протилежними знаками `x₁` та `-x₁` відображаються у той самий вектор затримок. Це утворює непереборні самоперетини у `R^m`, які не зникають при збільшенні `m`.

### 11. Підсумковий синтез та значення теореми для сучасної науки

Теорема Такенса перетворила нелінійну динаміку з абстрактного розділу теоретичної фізики на потужний прикладний інструмент інженерного аналізу. Вона довів, що скалярний часовий ряд — це не просто випадкова осцилограма, а повноцінна геометрична проекція фазової траєкторії нелінійної системи.

#### 11.1. Прогнозування нелінійних часових рядів
Побудова гладкого дифеоморфізму Такенса робить можливим детерміноване передбачення майбутніх станів хаотичної системи за допомогою методу локальних найближчих сусідів (Sugihara & May, 1990).
Для поточного вектора затримок `Y(t)` у просторі `R^m` шукаються `K` найближчих історичних сусідів `Y_k`. Кожен із цих сусідів зміщується вперед за часом на інтервал прогнозу `T_{pred}`, а підсумкове передбачення обчислюється як виважене середнє їхніх майбутніх траєкторій. Завдяки гладкості мапи Такенса близькі точки у відновленому фазовому просторі еволюціонують по близьких фазових траєкторіях, що дозволяє отримувати високоточні прогнози на інтервалах `T_{pred} < 1 / λ₁`. Порівняння похибки прогнозування для різної довжини інтервалу `T_{pred}` є надійним тестом для розрізнення детермінованого нелінійного хаосу від випадкового кольорового шуму: для хаосу похибка експоненційно зростає з часом, тоді як для шуму вона залишається сталою високою величиною. Цей фундаментальний метод локального прогнозування підтверджує, що інформація про майбутній стан нелінійного осцилятора повністю кодується в топології вкладеного атрактора.

Сьогодні фазова реконструкція Такенса лежить в основі:
- **Медичної діагностики**: аналіз варіабельності серцевого ритму (ЕКГ) та енцефалограм (ЕЕГ) для виявлення епілептичних нападів та аритмій за довгостроковою фрактальною вимірністю;
- **Неруйнівного контролю та роторної механіки**: моніторинг вібрацій акселерометрів для виявлення мікротріщин у підшипниках та турбінах до їх катастрофічного руйнування;
- **Попередження автоколивань у токарній та фрезерній обробці (Chatter Monitoring)**: фазова реконструкція вібрації різця дозволяє ідентифікувати зародження регенеративного хаотичного автоколивання до пошкодження оброблюваної деталі;
- **Машинного навчання та штучного інтелекту**: концепція резервуарних обчислень (Reservoir Computing) та нейронних диференціальних рівнянь (Neural ODEs) спирається на затримкові вкладення для побудови цифрових двійників нелінійних процесів, оскільки рекурентний резервуар діє як фізичне вкладення Такенса для лінійного зчитування.
