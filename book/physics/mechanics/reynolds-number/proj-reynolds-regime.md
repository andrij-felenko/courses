# ⚙️ Калькулятор режиму й втрат тиску в трубі

Ти проєктуєш геть буденну річ: трубу, якою треба прогнати рідину. Насос водогону, контур охолодження процесора, змійовик бойлера, паливну магістраль. І найперше, що питає фізика — ще до всякого заліза, — **скільки тиску з'їсть тертя об стінки на цьому шматку труби?** Бо саме цю втрату муситиме перекрити насос; помилишся втричі — і він або не докачає, або роками гризтиме зайві кіловати.

Відповідь упирається в число Рейнольдса Re = ρ·v·D/μ — але не напряму. Шлях від нього до втрати тиску має розвилку: ламінарна течія й турбулентна рахують тертя за **різними формулами**, а поміж ними лежить смуга, де чесна відповідь — «точно не скажу». Напишімо калькулятор, що проходить весь цей шлях від початку до кінця: бере чотири властивості потоку, рахує Re, вибирає гілку, підбирає коефіцієнт тертя й видає втрату тиску в паскалях. І, головне, не бреше на чотирьох підступних місцях, де наївний код тихо помиляється в рази.

## Що на вході, що на виході

На вході — чотири числа про сам потік, усі в СІ:

```
ρ  — густина рідини, кг/м³          (вода ≈ 1000, повітря ≈ 1.2, олива ≈ 900)
v  — середня швидкість, м/с
D  — ВНУТРІШНІЙ діаметр труби, м
μ  — динамічна в'язкість, Па·с      (вода ≈ 1×10⁻³, олива ≈ 0.1)
```

плюс два параметри самої труби:

```
L  — довжина ділянки, м
ε  — абсолютна шорсткість стінки, м   (пластик ≈ 1.5×10⁻⁶, сталь ≈ 4.5×10⁻⁵)
```

На виході — чотири речі, кожна практична:

```
Re     — число Рейнольдса (безрозмірне)
режим  — ламінарний / перехідний / турбулентний
f      — коефіцієнт тертя Дарсі (безрозмірний)
Δp     — втрата тиску на ділянці L, Па   (а з неї напір h = Δp/(ρ·g), м)
```

Напір h — це та сама втрата, виражена «висотою стовпа рідини»: зручно, бо насоси часто паспортизують саме в метрах, а не в паскалях.

## Ідея: три ланки й одна розвилка

Весь калькулятор — це три ланки, зчеплені послідовно, з розгалуженням посередині.

**Ланка 1 — Re.** Ділимо, і все: Re = ρ·v·D/μ. Тут єдина тонкість, але критична: за характерний розмір труби беруть **діаметр**, не радіус. Пороги, за якими судять режим, історично зміряні саме на діаметрі — тож візьмеш радіус, і Re вийде вдвічі меншим, а вирок про режим — хибним.

**Ланка 2 — режим.** Порівнюємо Re з двома порогами круглої труби:

```
Re < 2300       — ламінарний   (гладкі шари)
2300 … 4000     — перехідний   (нестійкий, миготить)
Re > 4000       — турбулентний (вихори)
```

**Ланка 3 — коефіцієнт тертя f, і ось де розвилка.** Коефіцієнт тертя Дарсі f — це безрозмірний множник, що каже, наскільки жадібно труба з'їдає тиск. І він рахується **по-різному** для двох режимів, бо фізика тертя в них інша:

- ламінарний: f = 64/Re — точна формула, без жодної підгонки;
- турбулентний: f = формула Гааланда, якій потрібна ще й відносна шорсткість ε/D.

Чому дві різні формули, а не одна плавна крива — розберемо трохи нижче; поки досить знати, що код мусить **розгалузитися** за режимом, бо однією формулою обидва світи не накрити.

**Ланка 4 — втрата тиску.** Маючи f, решта — одна формула Дарсі–Вайсбаха:

```
Δp = f · (L/D) · (ρ·v²/2)
```

Її легко прочитати зліва направо: тертя f, помножене на те, скільки діаметрів завдовжки труба (L/D — що довша й вужча, то більше стінки на шляху), помножене на ρ·v²/2 — [динамічний тиск](book:physics/dynamic-pressure) потоку, тобто «напір руху», який труба й гальмує. Коротша й ширша труба, повільніший чи легший потік — менша втрата. Кожен множник на своєму місці. (Ім'я рівняння несе двох людей: сучасну форму дав саксонець Юліус Вайсбах 1845 року, а до тертя в трубах довів її француз Анрі Дарсі близько 1857-го; спільною назвою «Дарсі–Вайсбах» їх поєднав Гантер Раус аж 1942 року — типова доля формул, зшитих із кількох внесків.)

![Схема калькулятора: від входу через Re й розвилку режиму до втрат тиску](/book/physics/mechanics/reynolds-number/img/calc-flow.svg)
*Один прохід згори вниз: чотири властивості потоку → Re → розвилка за порогами труби → свій коефіцієнт тертя на кожній гілці → Δp за Дарсі–Вайсбахом. Перехідна гілка не має чесної формули, тож несе флаг.*

## Робочий калькулятор

Задача суто інженерна й не прив'язана до заліза, тож пишемо мовами, якими такі розрахунки й живуть, — Python (числа й скрипт інженера) та TypeScript (той самий калькулятор у вебі чи в конфігураторі приладу). Логіка ідентична; різниця лише в тому, як кожна мова любить згортати результат у структуру.

:::tabs
```python
import math
from dataclasses import dataclass

# Пороги переходу — саме для КРУГЛОЇ ТРУБИ (характерний розмір = діаметр).
RE_LAMINAR_MAX   = 2300.0
RE_TURBULENT_MIN = 4000.0

@dataclass
class Result:
    Re: float
    regime: str          # 'ламінарний' | 'перехідний' | 'турбулентний'
    f: float             # коефіцієнт тертя Дарсі
    dp: float            # втрата тиску, Па
    head: float          # втрата напору, м
    note: str = ''       # застереження, якщо є

def reynolds(rho, v, D, mu):
    return rho * v * D / mu               # Re = ρ·v·D/μ; D — ДІАМЕТР, не радіус

def classify(Re):
    if Re < RE_LAMINAR_MAX:   return 'ламінарний'
    if Re < RE_TURBULENT_MIN: return 'перехідний'
    return 'турбулентний'

def friction_factor(Re, eps, D):
    if Re < RE_LAMINAR_MAX:
        return 64.0 / Re                  # ламінар: точно, з Пуазейля; ε байдужа
    # турбулент — явна формула Гааланда (наближення неявного Коулбрука):
    # 1/√f = −1.8·log₁₀[ (ε/D / 3.7)^1.11 + 6.9/Re ]
    inv_sqrt_f = -1.8 * math.log10((eps / D / 3.7) ** 1.11 + 6.9 / Re)
    return 1.0 / inv_sqrt_f ** 2

def pipe_loss(rho, v, D, mu, L, eps=1.5e-6, g=9.81):
    Re = reynolds(rho, v, D, mu)
    regime = classify(Re)
    f = friction_factor(Re, eps, D)
    dp = f * (L / D) * (rho * v ** 2 / 2)     # Дарсі–Вайсбах; ρv²/2 — динамічний тиск
    note = '' if regime != 'перехідний' else 'перехідна смуга: f — груба оцінка'
    return Result(Re, regime, f, dp, dp / (rho * g), note)

if __name__ == '__main__':
    r = pipe_loss(rho=1000, v=1.0, D=0.015, mu=1e-3, L=10.0, eps=1.5e-6)
    print(f'Re     = {r.Re:.0f}  ({r.regime})')
    print(f'f      = {r.f:.4f}')
    print(f'Δp     = {r.dp/1000:.2f} кПа  на 10 м труби')
    print(f'напір  = {r.head:.2f} м')
    if r.note:
        print('⚠ ', r.note)
```

```typescript
// Пороги переходу — саме для КРУГЛОЇ ТРУБИ (характерний розмір = діаметр).
const RE_LAMINAR_MAX = 2300;
const RE_TURBULENT_MIN = 4000;

type Regime = 'ламінарний' | 'перехідний' | 'турбулентний';

interface Result {
  Re: number;
  regime: Regime;
  f: number;        // коефіцієнт тертя Дарсі
  dp: number;       // втрата тиску, Па
  head: number;     // втрата напору, м
  note?: string;    // застереження, якщо є
}

const reynolds = (rho: number, v: number, D: number, mu: number): number =>
  (rho * v * D) / mu;                 // Re = ρ·v·D/μ; D — ДІАМЕТР, не радіус

function classify(Re: number): Regime {
  if (Re < RE_LAMINAR_MAX) return 'ламінарний';
  if (Re < RE_TURBULENT_MIN) return 'перехідний';
  return 'турбулентний';
}

function frictionFactor(Re: number, eps: number, D: number): number {
  if (Re < RE_LAMINAR_MAX) return 64 / Re;          // ламінар: точно, ε байдужа
  // турбулент — явна формула Гааланда:
  // 1/√f = −1.8·log₁₀[ (ε/D / 3.7)^1.11 + 6.9/Re ]
  const invSqrtF = -1.8 * Math.log10((eps / D / 3.7) ** 1.11 + 6.9 / Re);
  return 1 / invSqrtF ** 2;
}

function pipeLoss(
  rho: number, v: number, D: number, mu: number, L: number,
  eps = 1.5e-6, g = 9.81,
): Result {
  const Re = reynolds(rho, v, D, mu);
  const regime = classify(Re);
  const f = frictionFactor(Re, eps, D);
  const dp = f * (L / D) * (rho * v ** 2 / 2);      // Дарсі–Вайсбах
  return {
    Re, regime, f, dp, head: dp / (rho * g),
    note: regime === 'перехідний' ? 'перехідна смуга: f — груба оцінка' : undefined,
  };
}

const r = pipeLoss(1000, 1.0, 0.015, 1e-3, 10.0);
console.log(`Re    = ${r.Re.toFixed(0)}  (${r.regime})`);
console.log(`f     = ${r.f.toFixed(4)}`);
console.log(`Δp    = ${(r.dp / 1000).toFixed(2)} кПа  на 10 м труби`);
console.log(`напір = ${r.head.toFixed(2)} м`);
```

```

f      = 0.0278
Δp     = 9.28 кПа  на 10 м труби
напір  = 0.95 м
```

Тобто десять метрів звичайної труби з'їдають майже метр напору — цілком відчутно для насоса. А тепер та сама функція на густій оливі (ρ=900, v=0.5 м/с, D=20 мм, μ=0.1 Па·с): Re виходить лише **90** — ламінарний світ, — коефіцієнт тертя аж f = 64/90 ≈ 0.71, у двадцять п'ять разів більший, і на п'яти метрах губиться 20 кПа. Швидкість мала, а тертя люте: у в'язкому режимі труба опирається геть інакше, ніж у турбулентному, — і саме тому одна формула на обидва не годиться.

## Чому дві формули, а не одна

Ламінарна гілка — точна, і це рідкісний у гідравліці випадок, коли формула взагалі точна. Коли течія шарувата, рівняння руху рідини розв'язуються до кінця олівцем: швидкість у трубі лягає акуратною параболою — це [течія Пуазейля](book:physics/poiseuille-flow), — а з неї тертя виходить рівно f = 64/Re. Жодного експерименту, жодної підгонки, чиста математика. Прикметно, що шорсткість стінки ε сюди не входить зовсім: у ламінарному потоці біля стінки й так лежить нерухомий шар рідини, він «заливає» будь-які нерівності, і потоку байдуже, гладка труба чи шкарубка.

Турбулентна гілка — інша порода. Турбулентність досі не розв'язана з перших засад: вихори всіх розмірів годують один одного так заплутано, що вивести тертя чистою теорією ніхто не вміє. Лишається зміряти й підігнати криву під дані. Саме це зробив британський інженер Сиріл Коулбрук 1939 року: його рівняння (часто «Коулбрук–Вайт» — за спільними з К. Вайтом дослідами 1937-го) описує тертя турбулентної труби через Re й шорсткість ε/D. Вада в тому, що воно **неявне** — f сидить по обидва боки, всередині логарифма й зовні:

```
1/√f = −2·log₁₀( ε/(3.7·D) + 2.51/(Re·√f) )
```

Алгеброю f звідси не витягнеш; доводиться крутити ітерацію. Для калькулятора, який хочеться писати в один рядок, це морока — і 1983 року норвежець С. Е. Гааланд запропонував **явне** наближення, зумисне скроєне під ручний рахунок:

```
1/√f = −1.8·log₁₀[ (ε/D / 3.7)^1.11 + 6.9/Re ]
```

Тут f стоїть лише зліва: підставив Re й ε/D, узяв логарифм, звів у квадрат — готово, без ітерацій. Ціна за зручність крихітна: на воді з крана Гааланд дає f = 0.0278, а точний Коулбрук — 0.0280, розбіжність пів відсотка; у найгіршому разі по всьому діапазону труб — близько двох відсотків. Для інженерної оцінки втрат це шум, тож у калькулятор беремо саме Гааланда.

Тепер видно, ЧОМУ код мусить розгалужуватися, а не тягти одну формулу на все. Ламінарна пряма 64/Re і турбулентні криві Гааланда — це два різні закони, і вони навіть не стикаються: між Re = 2300 і 4000 зяє розрив. Це не огріх графіка, а сама фізика: у перехідній смузі течія стрибає між станами, тертя нестійке, і жодна з двох формул там не має сили.

![Коефіцієнт тертя проти Re: ламінарна пряма, розрив переходу, турбулентні криві двох шорсткостей](/book/physics/mechanics/reynolds-number/img/friction-curve.svg)
*Дві різні формули на одній осі. Зліва спадає ламінарна пряма f = 64/Re (шорсткість не впливає). Справа — турбулентні криві Гааланда: гладка труба й шорстка ε/D = 0.01, що на великих Re виходить на поличку (тертя перестає падати, бо його вже правлять самі виступи стінки). Помаранчева смуга 2300…4000 — перехід, де чесної кривої немає. Точка — вода з крана.*

Якщо ж потрібне саме еталонне значення Коулбрука (скажімо, щоб звірити Гааланда), його дає кілька витків простої ітерації — підставляй попереднє f у праву частину, доки не устоїться:

```python
def colebrook(Re, eps, D, iters=30):
    f = 0.02                                        # будь-яке розумне зерно
    for _ in range(iters):
        rhs = -2.0 * math.log10(eps / (3.7 * D) + 2.51 / (Re * math.sqrt(f)))
        f = 1.0 / rhs ** 2
    return f
```

Ітерація збігається блискавично — формула стискає похибку щокроку, тож за десяток витків f устоюється до всіх значущих цифр. Але для калькулятора однорядковий Гааланд простіший і практично такий самий; Коулбрук лишається еталоном, до якого його звіряють.

## Складність і пастки

За обчисленнями калькулятор — ніщо: одне ділення на Re, одне порівняння на режим, один логарифм на тертя, одне множення на Δp. Складність O(1), рахується швидше, ніж читається ця фраза; навіть ітеративний Коулбрук — це десяток арифметичних витків. Уся складність тут не в машині, а в тому, щоб **не збрехати**. І місць, де брехня заповзає тихо, рівно чотири.

**Пастка перша — діаметр проти радіуса.** Характерний розмір труби — діаметр D. Пороги 2300 і 4000 зміряні на діаметрі, формули тертя теж чекають діаметр. Візьмеш радіус — Re вийде вдвічі меншим. Іноді це лише псує f; іноді — перекидає сам вирок про режим. Пусти воду швидкістю 0.4 м/с трубою D = 10 мм: правильно Re = ρ·v·D/μ = 4000, тобто щойно турбулентний. А порахуй «від радіуса» r = 5 мм — дістанеш Re = 2000, і калькулятор упевнено скаже «ламінарний», вибере не ту гілку тертя й промахнеться по втратах. Одна буква — D чи r — і відповідь з іншого світу.

**Пастка друга — одиниці.** Формула Re безрозмірна лише тоді, коли всі чотири величини в узгоджених одиницях, найпростіше — в СІ. Дві класичні міни. Перша: діаметр у міліметрах замість метрів — і Re, і Δp злітають у тисячі разів. Друга, підступніша: динамічну в'язкість часто дають у **сантипуазах** (сП), а не в Па·с. Вода — це 1 сП, тобто 1×10⁻³ Па·с. Забудеш перерахувати й підставиш «1» у Па·с — Re з тих самих 15000 упаде до 15, і калькулятор оголосить кран ламінарним. Тисячократна помилка з однієї недоглянутої одиниці.

**Пастка третя — μ проти ν.** В'язкість буває двох ґатунків, і їх легко сплутати: динамічна μ (Па·с) і кінематична ν = μ/ρ (м²/с). Число Рейнольдса можна писати обома, але не змішуючи:

```
Re = ρ·v·D / μ        =        v·D / ν
```

Для води μ = 1×10⁻³ Па·с, а ν = 1×10⁻⁶ м²/с — вони відрізняються рівно на густину, тобто в тисячу разів. Візьмеш ν там, де формула чекає μ (або поділиш і на ρ, і на ν заразом), — знову тисячократний промах. Правило просте: обрав ліву форму — ділиш на μ і множиш на ρ; обрав праву — ділиш на ν і про ρ забуваєш. Що це за два ґатунки й чому вони різняться саме на густину — [в'язкість](book:physics/viscosity).

**Пастка четверта — перехідна смуга не має формули.** Спокуса — «домалювати» щось між 2300 і 4000, щоб крива вийшла суцільна. Але там фізично немає визначеного тертя: та сама труба за тих самих чисел може текти то ламінарно, то зриватися у вихори, залежно від дрібних збурень на вході. Чесний калькулятор не вдає, ніби знає точне f у цій смузі, — він рахує консервативну (турбулентну) оцінку й **позначає її флагом**, щоб інженер знав: тут закладай запас, а не довіряй цифрі до третього знака.

І ще одна, п'ята, радше пересторога, ніж пастка: коефіцієнт тертя буває **двох означень**. Наш f — Дарсі, з ламінарним законом f = 64/Re. Але в хімічній та частині американської літератури ходить **фаннінгів** коефіцієнт, учетверо менший: f_Fanning = f_Darcy/4, з ламінарним 16/Re. Обидва правильні, але живуть у різних формулах втрат. Візьмеш фаннінгове число у формулу Дарсі–Вайсбаха — недорахуєш тиск рівно вчетверо. Тож перше, що варто спитати про будь-яку взяту з таблиці формулу тертя: це Дарсі чи Фаннінг?

Оцим калькулятор і цінний. Сама арифметика тривіальна; вартість у тому, що він проходить розвилку режиму правильно й не дає одиницям чи означенням тихо зіпсувати відповідь у рази. Порахувати Re вміє кожен; не промахнутися по дорозі від Re до втрат тиску — оце вже інженерія.
