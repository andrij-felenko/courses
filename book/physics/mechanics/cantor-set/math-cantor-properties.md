# 🧮 Математична теорія, міра Лебега та Хаусдорфова вимірність множини Кантора

Ця математична вставка містить строгі доведення топологічних властивостей, розрахунок нульової міри Лебега, вивід потужності континууму, математичний розрахунок фрактальної вимірності Хаусдорфа та аналіз спектра Реньї для класичної, узагальненої та жирної множин Кантора.

## 1. Топологічна формалізація та компактність

Триадна множина Кантора `C` конструюється як граничний перетин послідовності вкладених покриттів `Eₖ` на одиничному відрізку `[0, 1]`.

Позначимо `E₀ = [0, 1]`. Для кожного `k ≥ 0` множина `Eₖ₊₁` утворюється з `Eₖ` вилученням відкритої середньої третини з кожного з `2ᵏ` замкнених інтервалів, з яких складається `Eₖ`:

```
Eₖ = ⋃_{j=1}^{2ᵏ} [a_{k,j}, b_{k,j}]
```

де довжина кожного інтервалу дорівнює `b_{k,j} - a_{k,j} = 3⁻ᵏ`.

Гранична множина `C` задається як:

```
C = ⋂_{k=0}^{∞} Eₖ
```

### Доведення компактності

1. Кожен відрізок `[a_{k,j}, b_{k,j}]` є замкненою та обмеженою множиною у `ℝ`.
2. Множина `Eₖ` як скінченне об'єднання замкнених відрізків є замкненою у `[0, 1]`.
3. Замкнений перетин довільної сім'ї замкнених множин є замкненою множиною. Отже, `C` є замкненою підмножиною `[0, 1]`.
4. Згідно з теоремою Гейне–Бореля, замкнена й обмежена підмножина `ℝ` є компактною. Отже, множина Кантора `C` є компактним топологічним простором.

### Доведення досконалості (Perfect set)

Множина називається досконалою, якщо вона замкнена і кожна її точка є граничною точкою.

Розглянемо довільну точку `x ∈ C` та її довільний окіл `U(x, ε)` радіуса `ε > 0`. Оскільки `x ∈ Eₖ` для всіх `k`, точка `x` належить одному з інтервалів `I_{k,j}` довжиною `3⁻ᵏ`. Виберемо таке `k`, що `3⁻ᵏ < ε`. Кінці інтервалу `I_{k,j}` (позначимо їх `p` та `q`) належать множині Кантора `C` за побудовою. Оскільки довжина інтервалу менша за `ε`, принаймні один із кінців `p` або `q` лежить усередині околу `U(x, ε)` і не збігається з `x`. Отже, `x` є граничною точкою `C`.

### Категорія Бера та топологічна товщина

Згідно з теоремою Бера про категорії, кожний повний метричний простір є простором другої категорії. Оскільки `C` є компактним повним метричним простором, вона є простором другої категорії у собі. Однак як підмножина дійсної прямої `ℝ`, множина Кантора є ніде не щільною, а отже, має першу категорію у `ℝ`.

## 2. Обчислення міри Лебега

Міра Лебега вихідного відрізка дорівнює `μ(E₀) = 1`. Обчислимо міру вилучених відкритих інтервалів.

На кроці `k = 1` вилучається 1 інтервал довжиною `1/3`.
На кроці `k = 2` вилучається 2 інтервали довжиною `1/9`.
На кроці `k` вилучається `2ᵏ⁻¹` інтервалів довжиною `3⁻ᵏ`.

Сумарна міра вилученої множини `U = [0, 1] \ C`:

```
μ(U) = ∑_{k=1}^{∞} 2ᵏ⁻¹ · 3⁻ᵏ         [сума довжин вилучених інтервалів]
     = (1/3) · ∑_{k=0}^{∞} (2/3)ᵏ      [винесення спільного множника 1/3]
     = (1/3) / (1 - 2/3)               [формула суми геометричної прогресії a / (1 - q)]
     = (1/3) / (1/3)                   [спрощення знаменника: 1 - 2/3 = 1/3]
     = 1                               [ділення: 1/3 на 1/3]
```

Застосуємо формулу суми нескінченно спадної геометричної прогресії зі першим членом `a = 1/3` та знаменником `q = 2/3`:

```
μ(C) = μ(E₀) - μ(U)                    [адитивність міри Лебега]
     = 1 - 1                           [підстановка значень: μ(E₀) = 1, μ(U) = 1]
     = 0                               [підсумок: міра множини Кантора дорівнює 0]
```

Міра Лебега триадної множини Кантора строго дорівнює нулю.

## 3. Точна бієкція та незліченність (Потужність Континууму)

Кожне число `x ∈ [0, 1]` подається у потрійній системі числення рядоми:

```
x = ∑_{i=1}^{∞} a[i] · 3⁻ⁱ,  a[i] ∈ {0, 1, 2}
```

Вилучення відкритих середніх третин на кожному кроці `k` відповідає вилученню чисел, у яких на `k`-му місці потрійного розкладу обов'язково стоїть цифра `1`. Таким чином:

```
C = { x ∈ [0, 1] | x = ∑_{i=1}^{∞} a[i] · 3⁻ⁱ,  де a[i] ∈ {0, 2} для всіх i ∈ ℕ }
```

Побудуємо відображення `h: C → [0, 1]`, що діє за правилом:

```
h( ∑_{i=1}^{∞} a[i] · 3⁻ⁱ ) = ∑_{i=1}^{∞} (a[i] / 2) · 2⁻ⁱ
```

### Властивості відображення `h`

1. Значення `b[i] = a[i] / 2` приймають значення у множині `{0, 1}`.
2. Ряд `∑_{i=1}^{∞} b[i] · 2⁻ⁱ` є канонічним двійковим розкладом дійсного числа з відрізка `[0, 1]`.
3. Для кожного числа `y ∈ [0, 1]` існує принаймні один двійковий розклад `y = 0.b₁b₂b₃...₂`. Задаючи `a[i] = 2 · b[i]`, ми отримуємо точку `x ∈ C`, таку що `h(x) = y`.

Отже, відображення `h` є сюр'єктивним відображенням `C` на `[0, 1]`. Звідси випливає нерівність для потужностей множин:

```
|C| ≥ |[0, 1]| = 2^{ℵ₀}
```

Оскільки `C ⊂ [0, 1]`, за теоремою Кантора–Bernstein–Шредера потужність множини Кантора дорівнює потужності континууму:

```
|C| = 2^{ℵ₀}
```

## 4. Вивід вимірності Хаусдорфа та спектра Реньї

Нехай `F ⊂ ℝⁿ` — компактна множина. `s`-вимірна зовнішня міра Хаусдорфа `Hˢ(F)` визначається як:

```
Hˢ(F) = lim_{δ → 0} [ inf { ∑_{i} (diam U_i)ˢ } ]
```

де інфімум береться за всіма не більш ніж зліченними покриттями `{U_i}` множини `F` діаметрами `diam U_i ≤ δ`.

Вимірність Хаусдорфа `dim_H(F)` є точки переходу, у якій міра змінюється від нескінченності до нуля:

```
dim_H(F) = inf { s ≥ 0 | Hˢ(F) = 0 } = sup { s ≥ 0 | Hˢ(F) = ∞ }
```

Для триадної множини Кантора `C` на кроці `k` ми маємо покриття з `Nₖ = 2ᵏ` інтервалів однакової довжини `δₖ = 3⁻ᵏ`.

Оцінимо `s`-вимірну суму покриття `S_k(s)`:

```
S_k(s) = ∑_{j=1}^{2ᵏ} (3⁻ᵏ)ˢ            [сума по 2ᵏ однаковим покриваючим інтервалам]
       = 2ᵏ · 3⁻ᵏˢ                      [множення кількості елементів на довжину у степені s]
       = (2 · 3⁻ˢ)ᵏ                     [об'єднання степенів з однаковим показником k]
```

Розглянемо поведінку цієї суми при `k → ∞`:

1. Якщо `2 · 3⁻ˢ < 1`, тобто `s > ln(2) / ln(3)`, то `lim_{k → ∞} S_k(s) = 0`. Отже, `Hˢ(C) = 0`.
2. Якщо `2 · 3⁻ˢ > 1`, тобто `s < ln(2) / ln(3)`, то `lim_{k → ∞} S_k(s) = ∞`. Отже, `Hˢ(C) = ∞`.
3. Якщо `2 · 3⁻ˢ = 1`, тобто `s = ln(2) / ln(3)`, то `S_k(s) = 1` для всіх `k`.

Точне значення вимірності Хаусдорфа триадної множини Кантора дорівнює:

```
dim_H(C) = ln(2) / ln(3) ≈ 0.6309297535714574
```

### Теорема про самоподібні множини Хатчінсона

За теоремою Хатчінсона, якщо стискаючі відображення `F₁` та `F₂` мають коефіцієнти `r₁` та `r₂` і задовольняють умову відкритої множини (Open Set Condition), інваріанта множина `C = F₁(C) ∪ F₂(C)` має вимірність Хаусдорфа `d`, яка строго задається єдиним коренем рівняння:

```
r₁ᵈ + r₂ᵈ = 1
```

Для класичної однорідної множини Кантора `r₁ = r₂ = 1/3`:

```
(1/3)ᵈ + (1/3)ᵈ = 2 · (1/3)ᵈ = 1  ⇒  3ᵈ = 2  ⇒  d = ln 2 / ln 3
```

Якщо ж ліва копія стискається у 4 рази (`r₁ = 1/4`), а права у 2 рази (`r₂ = 1/2`), вимірність визначається розв'язком рівняння:

```
(1/4)ᵈ + (1/2)ᵈ = 1
```

Позначивши `z = (1/2)ᵈ`, отримуємо квадратне рівняння `z² + z - 1 = 0`. Його додатний корінь `z = (√5 - 1) / 2` задає вимірність `d = ln((√5 - 1) / 2) / ln(1/2) ≈ 0.694242`.

### Мультифрактальний спектр Реньї

Узагальнена вимірність Реньї `D_q` описує статистичний розподіл імовірності відвідування осередків фазового простору:

```
D_q = (1 / (1 - q)) · lim_{ε → 0} [ ln ∑_{i} p_i^q / ln(1 / ε) ]
```

де `p_i` — імовірність потрапляння траєкторії у `i`-й осередок розміром `ε`. Для однорідної триадної множини Кантора рівномірний розподіл `p_i = 1 / 2ᵏ` дає однакове значення для всіх порядків:

```
D_q = ln 2 / ln 3  для всіх q ∈ ℝ
```

Це свідчить про те, що класична множина Кантора є монофракталом.

## 5. Математична конструкція жирної множини Кантора (Smith-Volterra-Cantor)

Жирна множина Кантора `K_{SVC}` будується вилученням середніх інтервалів, довжина яких зменшується швидше з кожним кроком `k`.

Нехай `E₀ = [0, 1]`. На кроці `k = 1` вилучимо з центру інтервал довжиною `r₁ = 1/4`.
На кроці `k = 2` з двох залишків вилучимо центральні інтервали довжиною `r₂ = 1/16`.
На кроці `k` з `2ᵏ⁻¹` залишків вилучаємо інтервали довжиною `r_k = 2⁻²ᵏ`.

Обчислимо сумарну довжину вилучених інтервалів:

```
μ(U_{SVC}) = ∑_{k=1}^{∞} 2ᵏ⁻¹ · 2⁻²ᵏ            [сума довжин усіх вилучених інтервалів]
           = ∑_{k=1}^{∞} 2ᵏ⁻¹ / 2²ᵏ              [перетворення показника від'ємного степеня]
           = ∑_{k=1}^{∞} 2ᵏ⁻¹ / 4ᵏ              [піднесення основи 2² = 4 до степеня k]
           = (1/4) · ∑_{k=0}^{∞} (2/4)ᵏ         [винесення першого члена 1/4 за дужки]
           = (1/4) / (1 - 1/2)                  [сума геометричної прогресії зі q = 1/2]
           = 1/2                                [обчислення значення: (1/4) / (1/2) = 1/2]
```

Загальна міра Лебега граничної жирної множини Кантора дорівнює:

```
μ(K_{SVC}) = 1 - 1/2 = 1/2 > 0
```

При цьому множина `K_{SVC}` залишається ніде не щільною, не містить жодного відкритого інтервалу і має топологічну вимірність `d_T = 0`, однак її вимірність Хаусдорфа дорівнює `dim_H(K_{SVC}) = 1`.

### Доведення ніде не щільності (Nowhere dense)

Множина `C` є замкненою у `ℝ`, тобто `cl(C) = C`. Для того щоб довести, що `C` є ніде не щільною, необхідно показати, що її нутрощ є порожньою: `int(C) = ∅`.

Припустимо протилежне: нехай існує відкритий інтервал `(α, β) ⊂ C` довжиною `L = β - α > 0`.

Оскільки `C = ⋂_{k=0}^{∞} Eₖ`, це означає, що `(α, β) ⊂ Eₖ` для всіх `k ≥ 0`.

Однак на кожному кроці `k` множина `Eₖ` складається з інтервалів довжиною `3⁻ᵏ`. Виберемо `k` таким великим, що `3⁻ᵏ < L`. Тоді жоден інтервал складової `Eₖ` не може повністю містити відкритий інтервал `(α, β)` довжиною `L`. Отримане суперечність доводить, що `int(C) = ∅`.

Отже, множина Кантора є ніде не щільною підмножиною дійсної прямої `ℝ`.

### Доведення рівняння Реньї та інтеграла Грассбергера–Прокаччі

Для хаотичних атракторів у фазовому просторі кореляційна вимірність `D₂` обчислюється через кореляційний інтеграл Грассбергера–Прокаччі `C(r)`:

```
C(r) = lim_{N → ∞} [ (2 / (N · (N - 1))) · ∑_{i < j} Θ(r - ||x_i - x_j||) ]
```

де `Θ` — функція Хевісайда, а `||x_i - x_j||` — відстань між точками фазової траєкторії.

Для триадної множини Кантора відстані між точками приймають дискретні значення `3⁻ᵏ`. Кількість пар точок на відстані, меншій за `r = 3⁻ᵏ`, масштабується як `C(r) ∼ r^{D₂}`. Підставляючи значення кількості точок `N(r) = 2ᵏ`, отримуємо:

```
C(3⁻ᵏ) = (2ᵏ / 2ᵏ)² / 2 = 2⁻ᵏ
```

Логарифмуючи співвідношення при `k → ∞`:

```
D₂ = lim_{r → 0} [ ln C(r) / ln r ]
   = lim_{k → ∞} [ ln(2⁻ᵏ) / ln(3⁻ᵏ) ]
   = (-k · ln 2) / (-k · ln 3)
   = ln 2 / ln 3 ≈ 0.63092975
```

Отже, кореляційна вимірність триадної множини Кантора строго збігається з її вимірністю Хаусдорфа та ємкісною вимірністю Box-Counting.

## 6. Строгі властивості та похідна функції Кантора

Розглянемо неперервну монотонну функцію Кантора `F: [0, 1] → [0, 1]`.

### Аналітичне визначення

Нехай `x ∈ [0, 1]` подано у потрійній системі числення `x = ∑_{i=1}^{∞} a[i] · 3⁻ⁱ`.

1. Якщо розклад не містить одиниць (`a[i] ∈ {0, 2}` для всіх `i`), значення функції дорівнює `F(x) = ∑_{i=1}^{∞} (a[i] / 2) · 2⁻ⁱ`.
2. Якщо у потрійному розкладі існує перша цифра `a[N] = 1`, значення функції покладається рівним `F(x) = ∑_{i=1}^{N-1} (a[i] / 2) · 2⁻ⁱ + 2⁻ᴺ`.

### Рівномірна збіжність послідовності наближень

Функцію Кантора можна побудувати як границя послідовності неперервних функцій `F_k(x)`:

- `F₀(x) = x` для всіх `x ∈ [0, 1]`.
- На кроці `k+1` функція `F_{k+1}(x)` визначається рекурсивно:
  - `F_{k+1}(x) = 0.5 · F_k(3x)` при `0 ≤ x ≤ 1/3`.
  - `F_{k+1}(x) = 0.5` при `1/3 < x < 2/3`.
  - `F_{k+1}(x) = 0.5 + 0.5 · F_k(3x - 2)` при `2/3 ≤ x ≤ 1`.

Оцінка відхилення функцій:

```
max_{x ∈ [0,1]} |F_{k+1}(x) - F_k(x)| ≤ 2⁻ᵏ⁻¹
```

За критерієм Вейєрштрасса, послідовність неперервних функцій `F_k` збігається рівномірно на `[0, 1]`. Оскільки рівномірна границя неперервних функцій є неперервною функцією, гранична функція Кантора `F(x) = lim_{k → ∞} F_k(x)` є строго неперервною на всьому відрізку `[0, 1]`.

### Доведення дорівнювання похідної нулю майже скрізь

Доповнення множини Кантора `U = [0, 1] \ C` складається з зліченного об'єднання відкритих вилучених інтервалів `I_{k, j}`.

На кожному вилученому інтервалі `I_{k, j}` функція Кантора `F(x)` за побудовою приймає постійне значення `m / 2ᵏ`.

Оскільки функція є постійною на відкритому інтервалі, її локальна похідна в кожній точці `x ∈ I_{k, j}` дорівнює:

```
F'(x) = 0  для всіх x ∈ U
```

Оскільки сумарна міра Лебега вилучених інтервалів дорівнює `μ(U) = 1`, висновок є строгим: похідна функції Кантора дорівнює нулю `F'(x) = 0` **майже скрізь** на відрізку `[0, 1]` у сенсі міри Лебега. Оскільки `F(0) = 0` та `F(1) = 1`, дана функція слугує нетривіальним контрприкладом до формули Ньютона–Лейбніца для не абсолютно неперервних функцій.

Повна варіація функції Кантора на відрізку `[0, 1]` дорівнює `V_0^1(F) = F(1) - F(0) = 1`. Оскільки її сингулярна складова є відмінною від нуля, вона є канонічним прикладом неперервної сингулярної функції у розкладі Лебега.

## 7. Топологічний гомеоморфізм із простором послідовностей

Розглянемо простір нескінченних послідовностей нулів та одиниць `Σ₂ = {0, 1}^ℕ` з тихоновською топологією прямого добутку дискретних просторів `{0, 1}`.

Метрика на `Σ₂` задається для будь-яких двох послідовностей `s = (s_1, s_2, ...)` та `t = (t_1, t_2, ...)` у вигляді:

```
d_Σ(s, t) = ∑_{i=1}^{∞} |s_i - t_i| / 2ⁱ
```

Побудуємо відображення `Ψ: Σ₂ → C`:

```
Ψ(s) = ∑_{i=1}^{∞} (2 · s_i) / 3ⁱ
```

### Властивості гомеоморфізму

1. Відображення `Ψ` є бієктивним за побудовою потрійного розкладу без одиниць.
2. Відображення `Ψ` є неперервним, оскільки для будь-якого `ε > 0` можна вибрати таке `N`, що `3⁻ᴺ < ε`, і для всіх `s, t` із однаковими першими `N` символами відстань `|Ψ(s) - Ψ(t)| < ε`.
3. Оскільки `Σ₂` є компактним топологічним простором, а `C` — хаусдорфовим простором, неперервна бієкція `Ψ` є гомеоморфізмом.

Таким чином, триадна множина Кантора топологічно еквівалентна канторовому дисконтинууму `Σ₂`.

## 8. Мультифрактальний аналіз та перетворення Лежандра

Для неоднорідних Канторових множин, де ймовірності потрапляння у ліву та праву гілки є нерівними (`p₁ ≠ p₂`), узагальнена вимірність Реньї `D_q` залежить від порядку `q`:

```
τ(q) = (q - 1) · D_q
```

Масовий показник `τ(q)` задовольняє рівняння Хатчінсона–Захле:

```
p₁^q · r₁^{-τ(q)} + p₂^q · r₂^{-τ(q)} = 1
```

Мультифрактальний спектр вимірностей `f(α)` обчислюється через перетворення Лежандра масового показника `τ(q)`:

```
α(q) = dτ(q) / dq
f(α) = q · α(q) - τ(q)
```

Максимум функції `f(α)` досягається при `q = 0` і дорівнює вимірності Хаусдорфа `f(α(0)) = dim_H(C)`. Для однорідного випадку `p₁ = p₂ = 1/2` спектр згортається в одну точку `(α₀, f(α₀)) = (ln 2 / ln 3, ln 2 / ln 3)`.

## 9. Нульвимірність та топологічні зв'язності

Топологічна вимірність Лебега (small inductive dimension `ind(C)`) визначається через межі відкритих околів.

### Доведення `ind(C) = 0`

Множина `C` має базу топології, що складається з відкритих-замкнених (clopen) множин. Розглянемо пару відрізків `[a, b] ⊂ Eₖ`. Оскільки кінці вилучених відкритих інтервалів не належать вилученій середній частині, для будь-якої точки `x ∈ C` можна знайти довільно малий відкритий окіл у `ℝ`, межа якого взагалі не перетинає множину Кантора `C`.

Оскільки межа кожної базісної відкритої множини у топології `C` є порожньою множиною `∅`, а топологічна вимірність порожньої множини дорівнює `ind(∅) = -1`, за індуктивним означенням Урисона–Менгера вимірність множини Кантора дорівнює:

```
ind(C) = 0
```

Це доводить, що множина Кантора є абсолютно незв'язаною: її тільки зв'язаними підмножинами є одноточкові множини `{x}`. Жодні дві точки `x ≠ y ∈ C` не можуть бути з'єднані неперервною дугою, яка лежить усередині `C`.

Таким чином, комбінація незліченності (`|C| = 2^{ℵ₀}`), нульової міри Лебега (`μ(C) = 0`), топологічної нульвимірності (`ind(C) = 0`) та дробової вимірності Хаусдорфа (`dim_H(C) = ln 2 / ln 3`) робить множину Кантора унікальним канонічним об'єктом математичного аналізу та нелінійної геометрії.

## 10. Оператор Хатчінсона у метричному просторі компактів

Розглянемо простір усіх непорожніх компактних підмножин `𝒦(ℝ)` з метрикою Хаусдорфа `d_H`:

```
d_H(A, B) = max { sup_{a ∈ A} inf_{b ∈ B} |a - b|,  sup_{b ∈ B} inf_{a ∈ A} |a - b| }
```

Метричний простір `(𝒦(ℝ), d_H)` є повним.

Визначимо оператор Хатчінсона `F: 𝒦(ℝ) → 𝒦(ℝ)` для двох стискаючих відображень `f₁(x) = x / 3` та `f₂(x) = 2/3 + x / 3`:

```
F(K) = f₁(K) ∪ f₂(K)
```

### Доведення стискання оператора

Для довільних компактів `A, B ∈ 𝒦(ℝ)` маємо:

```
d_H(F(A), F(B)) = d_H(f₁(A) ∪ f₂(A),  f₁(B) ∪ f₂(B))
                ≤ max { d_H(f₁(A), f₁(B)),  d_H(f₂(A), f₂(B)) }
                = (1/3) · d_H(A, B)
```

Оскільки коефіцієнт стискання `k = 1/3 < 1`, за теоремою Банаха про нерухому точку оператор Хатчінсона `F` має єдину нерухому точку у `𝒦(ℝ)`, до якої збігається будь-яка початкова множина `K₀` при послідовних ітераціях:

```
C = lim_{m → ∞} Fᵐ(K₀)
```

Це доводить глобальну атракторну стійкість геометричної побудови множини Кантора.

## 11. Спектральні властивості оператора Лапласа на Канторових фракталах

У математичній фізиці оператор Лапласа `Δ` на фрактальних множинах розглядається як границя скінченно-елементних різницевих операторів на сітках покриття `Eₖ`.

Спектральна вимірність `d_s` описує асимптотичний розподіл власних значень `λ_N` оператора Лапласа:

```
N(λ) = #{ λ_i ≤ λ } ∼ λ^{d_s / 2}  при λ → ∞
```

Для триадної множини Кантора спектральна вимірність обчислюється через вимірність Хаусдорфа `d_H = ln 2 / ln 3` та коефіцієнт блукання `d_w`:

```
d_s = 2 · d_H / d_w
```

Оскільки аномальна дифузія на множині Кантора характеризується коефіцієнтом блукання `d_w = 1 + d_H`, отримуємо точний спектральний показник:

```
d_s = 2 · (ln 2 / ln 3) / (1 + ln 2 / ln 3) = (2 · ln 2) / (ln 6) ≈ 0.7737
```

Спектральна вимірність `d_s` визначає термодинамічну теплоємність фрактальних граток при низьких температурах та щільність електронних станів у фрактальних провідниках, показуючи, що квантові та теплові збудження на Канторових структурованих матеріалах поширюються строго за субохоплюючими дробовими законами.

Таким чином, розроблений математичний апарат підтверджує, що триадна множина Кантора є не лише класичним об'єктом теорії множин, а й універсальною геометричною мовою фізики нелінійних середовищ, термодинаміки фрактальних ґраток, квантового хаосу та теорії хаотичного розсіювання, забезпечуючи точну відповідність між абстрактною геометрією та експериментальною вимірюваністю. Отримані аналітичні співвідношення закладають математичне підґрунтя для числового моделювання складних фізичних систем та обчислення фрактальних характеристик у прикладних алгоритмах нелінійної механіки суцільних середовищ і теоретичної фізики детермінованого хаосу.
