# 🧮 Математичне виведення центрального розширення алгебри Вітта

Математичний апарат центральних розширень алгебр Лі є однією з найгарніших галузей сучасної абстрактної алгебри та алгебраїчної топології. У даній вставці наведено строге математичне виведення єдиного (з точністю до алгебраїчного ізоморфізму) одновимірного центрального розширення алгебри Вітта, яке приводить до появи знаменитої алгебри Вірасоро.

Розглянемо алгебру Вітта `Witt` — нескінченновимірну алгебру Лі диференціальних операторів (векторних полів) на одиничному колі `S¹`. У комплексному базисі Фур'є генератори алгебри Вітта визначаються як перші похідні вздовж комплексної координати `z`:

```
Lₙ = -zⁿ⁺¹ · (∂ / ∂z),    n ∈ ℤ
```

Класична скоба Лі (коммутатор векторних полів) задовольняє алгебраїчні співвідношення:

```
[Lₙ, Lₘ] = Lₙ Lₘ - Lₘ Lₙ                                         [визначення комутатора векторних полів]
         = (-zⁿ⁺¹ ∂/∂z)(-zᵐ⁺¹ ∂/∂z) - (-zᵐ⁺¹ ∂/∂z)(-zⁿ⁺¹ ∂/∂z)    [підстановка Lₙ = -zⁿ⁺¹ ∂/∂z]
         = (m + 1) zⁿ⁺ᵐ⁺¹ ∂/∂z - (n + 1) zⁿ⁺ᵐ⁺¹ ∂/∂z              [диференціювання за правилом Лейбніца]
         = (n - m) Lₙ₊ₘ                                           [зведення подібних членів та заміна Lₙ₊ₘ = -zⁿ⁺ᵐ⁺¹ ∂/∂z]
```

Метою подальшого викладу є побудова центрального розширення `Vir = Witt ⊕ ℂ · C` та доведення того, що простір 2-когомологій алгебри Вітта є одновимірним: `H²(Witt, ℂ) ≅ ℂ`.

---

### 1. Формалізм 2-когомологій та 2-коциклів

Загальна задача про центральне розширення алгебри Лі `g` за допомогою центрального елемента `C` полягає у побудові нової алгебри Лі `g~ = g ⊕ ℂ · C`, у якій елемент `C` комутує з усіма елементами алгебри: `[X, C]~ = 0` для будь-якого `X ∈ g~`. 

Комутатор двох елементів вихідної алгебри у розширеній алгебрі набуває додаткового скалярного доданку:

```
[X, Y]~ = [X, Y] + θ(X, Y) · C
```

де `θ: g × g → ℂ` є двомісною білінійною функцією (числовим коциклом).

Щоб новоутворена алгебра `g~` задовольняла аксіомам алгебри Лі, функція `θ(X, Y)` повинна підкорятися двом обов'язковим геометричним і алгебраїчним вимогам:

1. **Антисиметричність**: З кососиметричності комутатора `[X, Y]~ = -[Y, X]~` негайно випливає, що коцикл має бути антисиметричним:
```
θ(X, Y) = -θ(Y, X)
```

2. **Тотожність Якобі**: Для будь-якої трійки елементів `X, Y, Z ∈ g~` повинна виконуватися тотожність Якобі:
```
[X, [Y, Z]~]~ + [Y, [Z, X]~]~ + [Z, [X, Y]~]~ = 0
```

Підставляючи вираз для комутатора із розширенням у тотожність Якобі й відокремлюючи коефіцієнти при центральному генераторі `C`, отримуємо фундаментальне **рівняння 2-коциклу**:

```
θ([X, Y], Z) + θ([Y, Z], X) + θ([Z, X], Y) = 0
```

Застосуємо це фундаментальне рівняння до генераторів алгебри Вітта `X = Lₖ`, `Y = Lₘ`, `Z = Lₙ`. Позначивши `g(n, m) ≡ θ(Lₙ, Lₘ)`, запишемо комутатор у розширеній алгебрі Вірасоро:

```
[Lₙ, Lₘ]~ = (n - m) Lₙ₊ₘ + g(n, m) · C
```

Тоді рівняння 2-коциклу для алгебри Вітта приймає канонічний вигляд:

```
(m - n)·g(k, m+n) + (n - k)·g(m, n+k) + (k - m)·g(n, k+m) = 0    [Рівняння 1: Рівняння 2-коциклу]
```

### 2. Редукція за допомогою калібрувального зсуву (2-комеж)

У теорії когомологій алгебр Лі не кожен розв'язок рівняння 2-коциклу дає фізично або математично новий результат. Припустимо, що ми виконаємо лінійну заміну базисних генераторів, додавши до кожного з них зсув, пропорційний центральному елементу `C`:

```
Lₙ' = Lₙ + a(n) · C
```

де `a(n)` — довільна послідовність комплексних чисел. 

Обчислимо комутатор нових генераторів `Lₙ'` та `Lₘ'`:

```
[Lₙ', Lₘ']~ = [Lₙ + a(n) C,  Lₘ + a(m) C]~
            = [Lₙ, Lₘ]~
            = (n - m) Lₙ₊ₘ + g(n, m) · C
            = (n - m) (Lₙ₊ₘ' - a(n+m) C) + g(n, m) · C
            = (n - m) Lₙ₊ₘ' + [ g(n, m) - (n - m) a(n+m) ] · C
```

Звідси видно, що новий коцикл `g'(n, m)` пов'язаний із початковим співвідношенням:

```
g'(n, m) = g(n, m) - (n - m) a(n+m)
```

Коцикли, які можна подати у вигляді `(n - m) a(n+m)` для деякої функції `a(n)`, називаються **2-комежами** (2-coboundaries). Вони утворюють тривіальні розширення, які легко усуваються ізоморфною заміною базису. Множина нетривіальних розширень алгебри Лі класифікується факторалгеброю 2-коциклів за 2-комежами — **другою групою когомологій** `H²(Witt, ℂ) = Z²(Witt, ℂ) / B²(Witt, ℂ)`.

Використаємо цю калібрувальну свободу для спрощення функції `g(n, m)`. Покладемо у загальному [Рівнянні 1] модове число `k = 0`:

```
(m - n)·g(0, m+n) + n·g(m, n) - m·g(n, m) = 0
```

Враховуючи антисиметричність `g(n, m) = -g(m, n)`, об'єднаємо останні два доданки:

```
(m - n)·g(0, m+n) + (n + m)·g(m, n) = 0    [Рівняння 2]
```

Якщо сума модових чисел не дорівнює нулю (`m + n ≠ 0`), ми завжди можемо вибрати калібрувальний зсув генераторів `a(k)` у вигляді:

```
a(k) = -g(0, k) / k,    для всіх k ≠ 0
```

Завдяки такому вибору зсуву новий коцикл задовольняє умові `g(0, k) = 0` для всіх `k ≠ 0`. Підставляючи `g(0, m+n) = 0` у [Рівняння 2], отримуємо:

```
(n + m)·g(m, n) = 0    для всіх m + n ≠ 0
```

Отже, коцикл `g(m, n)` обов'язково перетворюється на нуль для всіх пар чисел, сума яких не дорівнює нулю (`m + n ≠ 0`). Це означає, що коцикл є діагональним і може бути записаний через єдину функцію одного цілого аргументу `d(n)`:

```
g(n, m) = d(n) · δₙ₊ₘ,₀
```

З антисиметричності `g(n, -n) = -g(-n, n)` негайно випливає, що функція `d(n)` є непарною:

```
d(-n) = -d(n),    зокрема d(0) = 0
```

### 3. Розв'язання різницевого рівняння для d(n)

Тепер підставимо діагональну форму коциклу `g(n, m) = d(n) · δₙ₊ₘ,₀` у загальне [Рівняння 1] для випадку, коли сума трьох індексів дорівнює нулю: `k + m + n = 0` (поклавши `k = -(m+n)`):

```
(m - n)·d(m+n) + (2n + m)·d(m) - (2m + n)·d(n) = 0    [Рівняння 3]
```

Оскільки це рівняння має виконуватися для довільних цілих чисел `m` та `n`, зафіксуємо одне з них, поклавши `n = 1`:

```
(m - 1)·d(m+1) - (m + 2)·d(m) + (2m + 1)·d(1) = 0    [Рівняння 4]
```

Ми отримали лінійне однорідне рекурентне (різницеве) рівняння третього порядку відносно невідомої функції `d(m)`. Для розв'язання цього рівняння шукатимемо його базисні розв'язки у вигляді степенів `d(m) = mᵖ`.

1. **Аналіз лінійного розв'язку `d(m) = m`**:
```
(m - 1)(m + 1) - (m + 2)m + (2m + 1)(1)
= (m² - 1) - (m² + 2m) + (2m + 1)     [підстановка d(k) = k та розкриття дужок]
= 0                                   [скорочення подібних доданків m² - m² та 2m - 2m - 1 + 1]
```
Лінійний член `d(m) = m` тотожно задовольняє рівняння коциклу. Однак перевіримо, чи не є він тривіальною комежею. Обчислимо комежу `(n - m) a(n+m)` для `a(k) = const = c₀`:
```
(n - m) a(n+m) = c₀ · (n - m)
```
Для діагонального випадку `m = -n` маємо `2n · c₀`. Звідси видно, що лінійний розв'язок `d(n) = A · n` є чистою комежею і повністю усувається коваріантним зсувом генератора `L₀' = L₀ + (A/2) C`.

2. **Аналіз кубічного розв'язку `d(m) = m³`**:
```
(m - 1)(m + 1)³ - (m + 2)m³ + (2m + 1)(1³)
= (m - 1)(m³ + 3m² + 3m + 1) - m⁴ - 2m³ + 2m + 1    [піднесення до кубу (m+1)³ = m³ + 3m² + 3m + 1]
= (m⁴ + 2m³ - 2m - 1) - m⁴ - 2m³ + 2m + 1           [перемноження кубічного многочлена на (m - 1)]
= 0                                                 [тотожне скорочення всіх доданків m⁴, m³, m та вільних членів]
```
Кубічна функція `d(m) = m³` також тотожно задовольняє рівняння 2-коциклу. Проте, на відміну від лінійного члена, кубічна залежність `m³` **не може бути виражена через жодну комежу** `(n - m) a(n+m)`!

Отже, єдиним нетривіальним розв'язком рівняння 2-коциклу (з точністю до додавання тривіальної комежі) є кубічний многочлен:

```
d(n) = B · (n³ - n)
```

де `B` — довільна комплексна константа. У фізичній літературі з конформної теорії поля та теорії струн прийнято виражати константу `B` через параметр **центрального заряду** `c`, покладаючи `B = c / 12`:

```
g(n, m) = (c / 12) · (n³ - n) · δₙ₊ₘ,₀
```

### 4. Фізична та алгебраїчна інтерпретація результату

Таким чином, ми довели, що простір нетривіальних 2-коциклів алгебри Вітта є одновимірним (`H²(Witt, ℂ) ≅ ℂ`), а канонічний коммутатор алгебри Вірасоро приймає вигляд:

```
[Lₙ, Lₘ] = (n - m) Lₙ₊ₘ + (c / 12) · (n³ - n) · δₙ₊ₘ,₀ · I
```

Цей математичний результат має глибокі фізичні наслідки:

1. **Єдиність центрального розширення**: Не існує інших нетривіальних центральних розширень алгебри Вітта. Будь-яка квантова теорія поля у двох вимірах, що володіє конформною симетрією, може характеризуватися виключно єдиним числом `c`.
2. **Інваріантність підалгебри sl(2, ℂ)**: Розглянемо трійку генераторів `{L₋₁, L₀, L₁}`. Для них кубічний член `(n³ - n)` тотожно перетворюється на нуль:
   - `d(-1) = (-1)³ - (-1) = 0`
   - `d(0) = 0³ - 0 = 0`
   - `d(1) = 1³ - 1 = 0`

Це означає, що підалгебра `sl(2, ℂ)` глобальних конформних перетворень сфери Рімана залишається строго точної і не відчуває квантового центрального розширення.
