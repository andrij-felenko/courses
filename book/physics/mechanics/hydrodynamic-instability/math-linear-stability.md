# 🧮 Лінійний аналіз нестійкості та рівняння Орра — Зоммерфельда

Ця вставка містить детальний і послідовний математичний вивід рівнянь лінійної стійкості ламінарних зсувних потоків нестисливої рідини. Без цих виведень неможливо зрозуміти, як із вихідних нелінійних рівнянь Нав'є — Стокса виринає спектральна задача на власні значення, чому в'язкість виступає двоїстим чинником нестійкості, як доводиться фундаментальна теорема Релея про точку перегину та в чому полягає суть теореми Сквайрса.

## 1. Постановка задачі та лінеаризація рівнянь руху

Розглянемо двовимірний потік в'язкої нестисливої рідини в плоскому каналі. Рух рідини описується системою рівнянь Нав'є — Стокса та рівнянням неперервності. Вони виражають відповідно другий закон Ньютона для елементарного об'єму рідини та закон збереження маси:

```
∂u/∂t + u·(∂u/∂x) + v·(∂u/∂y)  =  -1/ρ · (∂p/∂x) + ν·(∂²u/∂x² + ∂²u/∂y²)     [подовжній імпульс]
∂v/∂t + u·(∂v/∂x) + v·(∂v/∂y)  =  -1/ρ · (∂p/∂y) + ν·(∂²v/∂x² + ∂²v/∂y²)     [поперечний імпульс]
∂u/∂x + ∂v/∂y  =  0                                                          [неперервність]
```

Представимо повне поле швидкості й тиску як суму стаціонарного основного потоку (стаціонарного ламінарного стану) та малих збурень:

```
u(x, y, t)  =  U(y) + u'(x, y, t)     [подовжня швидкість: основний профіль U(y) + мале збурення u']
v(x, y, t)  =  v'(x, y, t)            [поперечна швидкість: основна дорівнює нулю, лише збурення v']
p(x, y, t)  =  P(x) + p'(x, y, t)     [тиск: основний градієнт P(x) + мале збурення p']
```

Припускаємо, що збурення є безкінечно малими порівняно з основною швидкістю: `|u'| << |U|`, `|v'| << |U|`. Це припущення дозволяє нам виконати процедуру лінеаризації. Підставимо розкладені поля швидкостей у вихідні рівняння руху й знехтуємо квадратичними за збуренням членами `u'·(∂u'/∂x)` та `v'·(∂u'/∂y)` як величинами другого порядку малості:

```
∂u'/∂t + U·(∂u'/∂x) + v'·U'  =  -1/ρ · (∂p'/∂x) + ν·(∂²u'/∂x² + ∂²u'/∂y²)   [лінеаризоване x-рівняння]
∂v'/∂t + U·(∂v'/∂x)          =  -1/ρ · (∂p'/∂y) + ν·(∂²v'/∂x² + ∂²v'/∂y²)   [лінеаризоване y-рівняння]
∂u'/∂x + ∂v'/∂y              =  0                                           [неперервність збурень]
```

тут позначено `U' = dU/dy` — зсув швидкості основного потоку. Фізичний зміст третього доданка в першому рівнянні `v'·U'` полягає у конвективному переносі імпульсу основного потоку поперечним збуренням швидкості `v'`.

## 2. Функція струменю та виключення тиску

Щоб позбутися тиску `p'` та зменшити кількість невідомих змінних, введемо **функцію струменю збурення** `ψ'(x, y, t)`, яка скалярно визначає компоненти швидкості й автоматично задовольняє рівняння неперервності:

```
u' =  ∂ψ'/∂y     [компонента подовжньої швидкості збурення]
v' = -∂ψ'/∂x     [компонента поперечної швидкості збурення]
```

Перевірмо рівняння неперервності підстановкою функцій струменю:

```
∂u'/∂x + ∂v'/∂y
= ∂/∂x(∂ψ'/∂y) + ∂/∂y(-∂ψ'/∂x)   [підстановка узагальнених швидкостей]
= ∂²ψ'/(∂x·∂y) - ∂²ψ'/(∂y·∂x)    [рівність мішаних похідних за теоремою Шварца]
= 0                              [умова неперервності виконується тотожно]
```

Тепер виключимо градієнт тиску `p'`. Для цього продиференціюємо лінеаризоване `x`-рівняння за координатою `y`, а лінеаризоване `y`-рівняння за координатою `x`, після чого віднімемо друге рівняння від першого:

```
∂/∂t (∇²ψ') + U · ∂/∂x (∇²ψ') - U'' · (∂ψ'/∂x)  =  ν · ∇⁴ψ'   [рівняння переносу вихровості]
```

де позначено оператори Лапласа та бігармонічний для функцій двох змінних:

```
∇² = ∂²/∂x² + ∂²/∂y²            [оператор Лапласа]
∇⁴ = (∇²)² = ∂⁴/∂x⁴ + 2·∂⁴/(∂x²·∂y²) + ∂⁴/∂y⁴   [бігармонічний оператор]
```

Отримане рівняння виражає закон переносу та дифузії вихровості збурення `ζ' = -∇²ψ'` у зсувному потоці.

## 3. Модальний аналіз та виведення рівняння Орра — Зоммерфельда

Оскільки коефіцієнти отриманого рівняння залежать лише від просторової координати `y` і не залежать від `x` та часу `t`, ми можемо шукати розв'язок у вигляді **нормальних мод** (плоских монохроматичних хвиль, що поширюються уздовж каналу):

```
ψ'(x, y, t)  =  ϕ(y) · exp( i·(α·x - ω·t) )   [нормальна мода збурення]
```

тут застосовуються такі фундаментальні позначення:
- `α` — хвильове число збурення вздовж вісі `x` (дійсне додатне число, пов'язане з довжиною хвилі як `α = 2·π / λ`);
- `ω = ω_r + i·ω_i` — комплексна частота коливань;
- `c = ω / α = c_r + i·c_i` — комплексна фазова швидкість хвилі;
- `ϕ(y)` — комплексна амплітудна функція збурення по перерізу каналу.

Фізична інтерпретація комплексної фазової швидкості `c = c_r + i·c_i`:
1. Дійсна частина `c_r` визначає швидкість переміщення фазового фронту хвилі збурення вздовж потоку.
2. Уявна частина `c_i` (або `ω_i = α·c_i`) визначає часовий інкремент зростання амплітуди:
   - Якщо `c_i > 0` (або `ω_i > 0`), амплітуда збурення зростає експоненційно за законом `exp(α·c_i·t)` — потік є **лінійно нестійким**.
   - Якщо `c_i < 0`, амплітуда експоненційно загасає — потік **стійкий**.
   - Якщо `c_i = 0`, потік перебуває в стані **нейтральної стійкості**.

Обчислимо просторові та часові похідні від функції струменю збурення `ψ'`:

```
∂ψ'/∂x  =  i·α · ϕ(y) · exp( i·(α·x - ω·t) )                     [перша похідна за x]
∂²ψ'/∂x² = -α² · ϕ(y) · exp( i·(α·x - ω·t) )                      [друга похідна за x]
∂ψ'/∂t  = -i·ω · ϕ(y) · exp( i·(α·x - ω·t) )                     [похідна за часом]
∇²ψ'    = (ϕ'' - α²·ϕ) · exp( i·(α·x - ω·t) )                     [Лапласіан збурення]
∇⁴ψ'    = (ϕ'''' - 2·α²·ϕ'' + α⁴·ϕ) · exp( i·(α·x - ω·t) )       [бігармоніан збурення]
```

Підставимо обчислені похідні у рівняння переносу вихровості й скоротимо спільний для всіх доданків експоненціальний множник `exp(i·(α·x - ω·t))`:

```
-i·ω·(ϕ'' - α²·ϕ) + i·α·U·(ϕ'' - α²·ϕ) - i·α·U''·ϕ  =  ν · (ϕ'''' - 2·α²·ϕ'' + α⁴·ϕ)   [підстановка мод]
```

Поділимо обидві частини рівняння на `i·α` та підставимо комплексну фазову швидкість `c = ω / α`:

```
(U - c) · (ϕ'' - α²·ϕ) - U''·ϕ  =  ν / (i·α) · (ϕ'''' - 2·α²·ϕ'' + α⁴·ϕ)   [проміжний крок]
```

Перейдемо до безрозмірних змінних. Приймемо напівширину каналу `h` за характерну довжину, а максимальну швидкість на осі `U_max` за характерну швидкість. Безрозмірне число Рейнольдса визначається як `Re = U_max · h / ν`. Перепишемо праву частину через `Re` (ураховуючи алгебраїчне співвідношення `1/i = -i`):

```
[ (U - c) · (ϕ'' - α²·ϕ) - U''·ϕ ]  =  -i / (α·Re) · (ϕ'''' - 2·α²·ϕ'' + α⁴·ϕ)   [РІВНЯННЯ ОРРА — ЗОММЕРФЕЛЬДА]
```

Це і є класичне **рівняння Орра — Зоммерфельда** — лінійне звичайне диференціальне рівняння четвертого порядку зі змінними коефіцієнтами щодо амплітудної функції `ϕ(y)`.

Граничні умови на твердих нерухомих стінках каналу `y = -1` та `y = 1` вимагають виконання умов прилипання рідини (і подовжня `u'`, і поперечна `v'` компоненти швидкості збурення перетворюються на нуль):

```
ϕ(1)  = 0,   ϕ'(1)  = 0     [умови прилипання на верхній стінці y = 1]
ϕ(-1) = 0,   ϕ'(-1) = 0     [умови прилипання на нижній стінці y = -1]
```

Рівняння Орра — Зоммерфельда разом із граничними умовами утворює **спектральну задачу на власні значення**: для заданого профілю швидкості `U(y)`, числа Рейнольдса `Re` та хвильового числа `α` потрібно знайти спектр власних значень `c` та відповідних власних функцій `ϕ(y)`.

## 4. Нев'язкий ліміт та теорема Релея про точку перегину

У граничному випадку нескінченно великих чисел Рейнольдса (`Re → ∞`) або для ідеальної нев'язкої рідини (`ν = 0`) в'язка права частина рівняння Орра — Зоммерфельда перетворюється на нуль. У результаті отримуємо **рівняння Релея**:

```
(U - c) · (ϕ'' - α²·ϕ) - U''·ϕ  =  0   [РІВНЯННЯ РЕЛЕЯ ДЛЯ НЕВ'ЯЗКОГО ПОТОКУ]
```

Це рівняння другого порядку. Для нього граничні умови вимагають лише непротікання рідини крізь стінки: `ϕ(1) = 0` та `ϕ(-1) = 0`.

Доведемо фундаментальну **теорему Релея про точку перегину**.

**Теорема Релея:** *Необхідною умовою лінійної нестійкості нев'язкого паралельного потоку є наявність точки перегину в профілі швидкості `U(y)` всередині інтервалу `y ∈ (-1, 1)`.*

**Доведення:**
Припустимо супротивне: нехай потік є нестійким, тобто існує принаймні одне власне значення з додатною уявною частиною `c_i > 0`.

Поділимо рівняння Релея на вираз `(U - c)`. Це ділення є математично коректним на всьому інтервалі, оскільки за припущення `c_i > 0` знаменник `U(y) - c` ніде не перетворюється на нуль у дійсній області:

```
ϕ'' - α²·ϕ - [ U'' / (U - c) ] · ϕ  =  0   [розв'язане відносно похідних]
```

Домножимо отримане рівняння на комплексно-спряжену функцію `ϕ*(y)` та інтегруємо по всій висоті каналу від `y = -1` до `y = 1`:

```
∫₋₁¹ ϕ*·ϕ'' dy - α²·∫₋₁¹ |ϕ|² dy - ∫₋₁¹ [ U'' / (U - c) ] · |ϕ|² dy  =  0   [інтегрування]
```

Проінтегруємо перший доданок частинами, застосовуючи граничні умови непротікання `ϕ(±1) = 0`:

```
∫₋₁¹ ϕ*·ϕ'' dy  =  [ϕ*·ϕ']₋₁¹ - ∫₋₁¹ |ϕ'|² dy  =  -∫₋₁¹ |ϕ'|² dy   [інтегрування частинами]
```

Підставимо цей результат у вихідне інтегральне співвідношення:

```
-∫₋₁¹ ( |ϕ'|² + α²·|ϕ|² ) dy - ∫₋₁¹ [ U'' / (U - c) ] · |ϕ|² dy  =  0   [інтегральна рівність]
```

Перепишемо дріб `1 / (U - c)`, виділивши його дійсну та уявну частини шляхом домноження на комплексно-спряжений знаменник:

```
1 / (U - c)  =  1 / ( (U - c_r) - i·c_i )
             =  ( (U - c_r) + i·c_i ) / ( (U - c_r)² + c_i² )   [алгебраїчне перетворення]
```

Розділимо інтегральне співвідношення на дійсну та уявну частини. Розглянемо **уявну частину**:

```
c_i · ∫₋₁¹ [ U''(y) / ( (U - c_r)² + c_i² ) ] · |ϕ|² dy  =  0   [УЯВНА ЧАСТИНА ІНТЕГРАЛА]
```

Проаналізуємо отриманий вираз. Ми виходили з припущення, що потік нестійкий, тобто `c_i > 0`. Отже, для того щоб добуток дорівнював нулю, сам інтеграл мусить дорівнювати нулю.

Проте множник `|ϕ|² / ( (U - c_r)² + c_i² )` під інтегралом є строго додатним для всіх `y ∈ (-1, 1)`. Отже, інтеграл від добутку цього додатного множника на `U''(y)` може дорівнювати нулю **лише тоді, коли друга похідна швидкості `U''(y)` змінює свій знак на інтервалі `y ∈ (-1, 1)`**.

Зміна знаку другої похідної `U''(y)` означає існування принаймні однієї точки `y_s`, у якій виконано умову:

```
U''(y_s) = 0   [ТЕОРЕМА РЕЛЕЯ ДОВЕДЕНА]
```

Це доводить, що за відсутності точки перегину нев'язкий потік є строго стійким.

## 5. Точний аналітичний розв'язок для зсувного шару та дисперсійне співвідношення

Щоб побачити, як теоретичні формули працюють на практиці, виведемо точне дисперсійне співвідношення для тангенціального розриву швидкості (ідеалізований зсувний шар Кельвіна — Гельмгольца).

Нехай у нескінченному об'ємі нев'язкої рідини з однаковою густиною `ρ` верхній шар (`y > 0`) рухається зі швидкістю `U_1`, а нижній шар (`y < 0`) — зі швидкістю `U_2`. Усередині кожного з двох шарів профіль швидкості постійний (`U'' = 0`), тому рівняння Релея спрощується до вигляду:

```
ϕ'' - α²·ϕ = 0   [рівняння для постійного профілю]
```

Розв'язки для верхньої та нижньої напівплощин із урахуванням згасання збурень на нескінченності (`y → ±∞`):

```
ϕ₁(y) = A · exp(-α·y),  y > 0   [розв'язок у верхньому шарі]
ϕ₂(y) = B · exp(+α·y),  y < 0   [розв'язок у нижньому шарі]
```

На межі поділу `y = 0` вимагаємо виконання двох умов стикування:
1. Кінематична умова: зсув межі `η(x, t)` є єдиним для обох рідин, що дає зв'язок амплітуд `A / (U_1 - c) = B / (U_2 - c)`.
2. Динамічна умова: безперервність тиску `p'` на викривленій межі поділу.

Підстановка амплітуд `ϕ_1` та `ϕ_2` у динамічну умову дає поліноміальне рівняння щодо фазової швидкості `c`:

```
(U_1 - c)² + (U_2 - c)² = 0   [характеристичне рівняння]
```

Розв'яжемо це квадратне рівняння відносно `c`:

```
c² - (U_1 + U_2)·c + (U_1² + U_2²)/2 = 0   [зведене квадратне рівняння]
c = (U_1 + U_2)/2 ± i · |U_1 - U_2|/2       [ДИСПЕРСІЙНЕ СВІВВІДНОШЕННЯ КЕЛЬВІНА — ГЕЛЬМГОЛЬЦА]
```

Оскільки уявна частина є принципово відмінною від нуля (`c_i = |U_1 - U_2| / 2 > 0`), **будь-який тангенціальний розрив швидкості в нев'язкій рідині є нестійким для всіх хвильових чисел `α`**. Інкремент зростання амплітуди `γ = α · c_i = α · |U_1 - U_2| / 2` зростає лінійно з ростом хвильового числа `α` (коротші хвилі зростають швидше).

## 6. Виведення дисперсійного співвідношення Релея — Тейлора з урахуванням поверхневого натягу

Аналогічний аналіз виконаємо для межі поділу двох непорушних рідин з різними густинами `ρ_1` (верхня рідина) та `ρ_2` (нижня рідина) в полі сили тяжіння `g`, спрямованому вниз.

Динамічна умова на межі поділу `y = 0` враховує стрибок тиску Лапласа за рахунок поверхневого натягу `σ`:

```
p_1' - p_2' = -σ · (∂²η / ∂x²)   [стрибок тиску Лапласа на викривленій межі]
```

Виражаючи збурення тиску `p'` через функції струменю з лінеаризованих рівнянь руху й підставляючи модальний вигляд `η = η_0 · exp(i·α·x + γ·t)`, отримуємо характеристичне рівняння для інкременту зростання `γ = -i·ω`:

```
γ² = g · α · ( (ρ_1 - ρ_2) / (ρ_1 + ρ_2) )  -  ( σ · α³ ) / ( ρ_1 + ρ_2 )   [ДІСПЕРСІЙНЕ СВІВВІДНОШЕННЯ РЕЛЕЯ — ТЕЙЛОРА]
```

Проаналізуємо отримане співвідношення:
1. Якщо **важка рідина лежить зверху** (`ρ_1 > ρ_2`), безрозмірне число Атвуда `A = (ρ_1 - ρ_2) / (ρ_1 + ρ_2) > 0`. Перший доданок є додатним і прагне дестабілізувати межу.
2. Поверхневий натяг (другий доданок `-σ·α³`) діє як демпфер, що пригнічує короткі хвилі (великі `α`).
3. **Критичне хвильове число** `α_c`, вище якого потік стабілізується (`γ² ≤ 0`):

```
α_c = √[ g · (ρ_1 - ρ_2) / σ ]   [критичне хвильове число Релея — Тейлора]
```

Хвилі з `α < α_c` (довжини хвиль `λ > 2·π / α_c`) є нестійкими. Максимум інкременту зростання досягається за хвильового числа `α_max = α_c / √3`, яке визначає початковий розмір шпильок важкої рідини, що занурюються в легку.

## 7. Рівняння конвективної стійкості Релея — Бенара

Для опису конвективної нестійкості Релея — Бенара рівняння руху доповнюються рівнянням переносу тепла в наближенні Буссінеска (де зміна густини під дією температури враховується лише у масовій силі плавучості `f_buoyancy = ρ_0 · g · β · T'`, де `β` — коефіцієнт об'ємного термічного розширення).

Лінеаризовані рівняння для збурень вертикальної швидкості `v'` та температури `T'` в горизонтальному шарі товщиною `d`:

```
∂/∂t (∇²v')  =  g · β · ∇_h² T' + ν · ∇⁴v'   [імпульс у наближенні Буссінеска]
∂T'/∂t - v' · (ΔT / d)  =  κ · ∇²T'          [перенос тепла]
```

тут `κ` — коефіцієнт температуропровідності рідини, `ΔT = T_bottom - T_top` — перепад температур між підігрітою нижньою та холодною верхньою стінками.

Підставивши нормальні моди `v' = v_0(y) · exp(i·(α_x·x + α_z·z) + γ·t)`, об'єднуємо два рівняння у єдину диференціальну систему шостого порядку. На межі нейтральної стійкості (`γ = 0`) виринає безрозмірний параметр — **число Релея**:

```
Ra = g · β · ΔT · d³ / (ν · κ)   [ЧИСЛО РЕЛЕЯ]
```

Математичний розв'язок спектральної задачі для двох плоских твердих стінок із умовами прилипання та заданими температурами дає мінімальне критичне значення числа Релея:

```
Ra_c ≈ 1707.76,   α_c ≈ 3.117   [КРИТИЧНІ ПАРАМЕТРИ РЕЛЕЯ — БЕНАРА]
```

Якщо `Ra < Ra_c`, тепло переноситься виключно теплопровідністю, а будь-які рухи рідини згасають. Якщо `Ra > Ra_c`, стаціонарний стан теплопровідності втрачає стійкість і зароджуються регулярні осередки конвективного руху.

## 8. Баланс енергії збурень і напруження Рейнольдса

Аналіз механізму передачі енергії від основного потоку до збурень виконується шляхом інтегрування лінеаризованого рівняння кінетичної енергії збурень по об'єму каналу.

Помножимо `x`-рівняння на `u'`, `y`-рівняння на `v'`, додамо їх та інтегруємо по перерізу каналу. Отримуємо **рівняння енергетичного балансу збурень**:

```
dE/dt  =  ∫₋₁¹ ( -u'v' · U' ) dy  -  ν · ∫₋₁¹ ( (∂u'/∂y - ∂v'/∂x)² + … ) dy   [РІВНЯННЯ ЕНЕРГІЇ ЗБУРЕНЬ]
```

тут:
- `E(t) = 1/2 · ∫ (u'² + v'²) dy` — середня кінетична енергія збурень на одиницю площі;
- `P_turb = ∫ ( -u'v' · U' ) dy` — швидкість генерації енергії збурень за рахунок роботи **напружень Рейнольдса** `τ_R = -ρ·u'v'` на зсуві основного потоку `U'`;
- `D_visc = ν · ∫ ( ... ) dy` — швидкість в'язкої дисипації кінетичної енергії в тепло (завжди додатна величина).

З цього балансу випливає фізична суть гідродинамічної нестійкості: **збурення зростають лише тоді, коли генерація енергії напруженнями Рейнольдса перевищує в'язку дисипацію (`P_turb > D_visc`)**. Для цього кореляція між подовжньою та поперечною компонентами швидкостей `u'` і `v'` має бути від'ємною у зонах з додатним зсувом `U' > 0`.

## 9. Доповнення Фйортофта та теорема Сквайрса

У 1950 році норвезький метеоролог Рагнар Фйортофт розширив теорему Релея. Домноживши дійсну частину інтегрального співвідношення на `(U - c_r)`, він довів, що наявність точки перегину є лише першим кроком. Для нестійкості необхідно також виконання умови:

```
U''(y) · ( U(y) - U(y_s) )  <  0   [КРИТЕРІЙ ФЙОРТОФТА]
```

принаймні в якійсь частині потоку. Фізично це означає, що абсолютна величина вихровості основного потоку `|U'(y)|` повинна мати локальний максимум у точці перегину `y_s`, а не локальний мінімум.

Ще одним фундаментальним результатом теорії лінійної стійкості є **теорема Сквайрса** (Squires' theorem, 1933). Вона стверджує: *для кожного тривимірного нестійкого збурення з хвильовими числами `(α, β)` за числа Рейнольдса `Re` існує еквівалентне двовимірне збурення з хвильовим числом `α_2D = √(α² + β²)`, яке є нестійким за нижчого числа Рейнольдса `Re_2D = Re · (α / α_2D) < Re`.*

З теореми Сквайрса випливає критичний практичний висновок: **мінімальне (найнебезпечніше) критичне число Рейнольдса завжди відповідає двовимірним збуренням**. Саме тому аналіз двовимірних мод є достатнім для знаходження межі лінійної стійкості.

## 10. Немодальне алгебраїчне зростання (Transient Growth)

У класичному аналізі Орра — Зоммерфельда припускається, що поведінка потоку повністю визначається окремими власними модами `exp(-i·ω·t)`. Однак лінійний оператор Орра — Зоммерфельда `L` не є самоспряженим (`L ≠ L*`), через що його власні функції **неортогональні** між собою у звичайному енергетичному скалярному добутку.

Неортогональність власних функцій призводить до ефекту **транзієнтного (немодального) зростання**. Навіть якщо абсолютно всі власні значення є стабільними (`c_i < 0` для кожної моди), сума декількох неортогональних мод у початковий момент часу `t = 0` може утворювати конфігурацію із взаємним гасінням. З часом, через відмінності у фазових швидкостях `c_r`, деструктивна інтерференція змінюється на конструктивну.

Оцінка максимального підсилення кінетичної енергії збурення `E(t)` показує можливість тимчасового **алгебраїчного зростання**:

```
G(t)  =  max [ E(t) / E(0) ]  ~  (Re)²   [максимальне коефіцієнтне підсилення енергії]
```

Для плоскої течії Куетта чи Поазейля таке тимчасове зростання енергії збурень може сягати факторів `10³ … 10⁵` за чисел Рейнольдса `Re ~ 1000`. Збурення зростає до амплітуди, за якої вмикаються нелінійні члени рівнянь Нав'є — Стокса, розриваючи ламінарний стан ще до того, як лінійна мода встигне згаснути. Це явище пояснює так званий **обхідний перехід** (bypass transition) до турбулентності в течіях без точок перегину.

| Фізична модель | Диференціальне рівняння | Кількість точок перегину | Характер стійкості |
| :--- | :--- | :--- | :--- |
| **Нев'язкий потік без точки перегину** | Рівняння Релея | `U''(y) ≠ 0` ніде | Абсолютно стійкий (`c_i = 0`) |
| **Нев'язкий потік з точкою перегину** | Рівняння Релея | `U''(y_s) = 0` | Можливо нестійкий (`c_i > 0`) |
| **В'язкий потік (Орр — Зоммерфельд)** | Рівняння Орра — Зоммерфельда | Залежить від `Re` та профілю | Нестійкий за `Re > Re_c` (для Поазейля `Re_c = 5772`) |
| **Немодальна нестійкість** | Лінеаризовані рівняння Н-С | Будь-який профіль | Алгебраїчне зростання `G(t) ~ Re²` |
