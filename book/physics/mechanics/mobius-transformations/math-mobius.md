# 🧮 Алгебра та геометрія дробово-лінійних перетворень

Ця математична вставка містить строгі алгебраїчні виведення елементарного розкладу перетворень Мьобіуса, доведення збереження узагальнених кіл, конформності, інваріантності подвійного відношення, канонічні нормальні форми та класифікацію нерухомих точок за слідом матриці.

## 1. Елементарний алгебраїчний розклад

Нехай задано дробово-лінійне перетворення на розширеній комплексній площині `ℂ̂`:

```
w = f(z) = (a·z + b) / (c·z + d)
```

де `a, b, c, d ∈ ℂ` та визначник `Δ = a·d - b·c ≠ 0`.

Розглянемо випадок `c ≠ 0`. Виділимо цілу частину дробу шляхом ділення чисельника на знаменник:

```
w = (a·z + b) / (c·z + d)
  = (a/c · (c·z + d) + b - a·d/c) / (c·z + d)    [виділення множника a/c у чисельнику]
  = a/c + (b - a·d/c) / (c·z + d)                [розбиття дробу на два доданки]
  = a/c + (b·c - a·d) / (c · (c·z + d))          [зведення до спільного знаменника в чисельнику]
  = a/c - (a·d - b·c) / (c² · (z + d/c))         [винесення мінуса та c² за дужки]
```

Позначивши `Δ = a·d - b·c` та `α = -(a·d - b·c)/c²`, отримуємо ланцюжок із чотирьох послідовних елементарних відображень:

```
z₁ = z + d/c                   [Крок 1: паралельне перенесення (Translation)]
z₂ = 1 / z₁                    [Крок 2: комплексне обернення (Inversion)]
z₃ = α · z₂                    [Крок 3: розтяг та поворот (Dilation & Rotation)]
w  = z₃ + a/c                  [Крок 4: підсумкове перенесення (Translation)]
```

Геометричний зміст кожного з чотирьох кроків:
- **Крок 1 (Зсув):** Переносить початок координат у точку `-d/c`. Це простий евклідовий зсув площини, який зберігає відстані, кути та орієнтацію.
- **Крок 2 (Інверсія):** Головний нелінійний крок. Точка `z₁ = r·e^(i·θ)` перетворюється на `z₂ = (1/r)·e^(-i·θ)`. Модуль точки інвертується відносно одиничного кола `r ↦ 1/r`, а аргумент змінює знак `θ ↦ -θ`. Це відображення міняє місцями внутрішню та зовнішню області одиничного кола. Точка `0` прямує в `∞`, а `∞` прямує в `0`.
- **Крок 3 (Масштаб і поворот):** Множення на комплексне число `α = |α|·e^(i·Arg α)`. Модуль `|α|` виконує рівномірне гомотетичне розтягнення чи стиснення відносно нуля, а аргумент `Arg α` повертає всю площину на відповідний кут.
- **Крок 4 (Фінальний зсув):** Переносить отриману конфігурацію в підсумкове положення, зсуваючи на вектор `a/c`.

Якщо `c = 0`, умова `Δ ≠ 0` вимагає `a ≠ 0` та `d ≠ 0`. Тоді перетворення спрощується до прямого афінного відображення `w = (a/d)·z + (b/d)`, яке є комбінацією лише зсуву, повороту та масштабування.

## 2. Збереження узагальнених кіл та кола Аполлонія

Узагальненим колом на комплексній площині зветься фігура, яка є або звичайним колом, або прямою лінією (колом нескінченного радіуса, що проходить через `∞`).

Рівняння довільного узагальненого кола у комплексних координатах `z` та `z̄` має вигляд:

```
A·z·z̄ + B̄·z + B·z̄ + C = 0
```

де `A, C ∈ ℝ` — дійсні коефіцієнти, а `B ∈ ℂ` — комплексне число. 

Умова того, що рівняння описує дійсне коло або пряму, вимагає додатного радіуса:

```
|B|² - A·C > 0
```

- Якщо `A ≠ 0`, ділимо на `A` та виділяємо повний модуль: `|z + B/A|² = (|B|² - A·C)/A²`, що є колом з центром `-B/A` та радіусом `R = √(|B|² - A·C) / |A|`.
- Якщо `A = 0`, рівняння набуває вигляду `B̄·z + B·z̄ + C = 0`, що є загальним рівнянням прямої лінії у комплексній формі.

Доведемо, що кожна з чотирьох елементарних операцій розкладу зберігає вигляд цього рівняння.

### Паралельне перенесення `w = z + z₀`
Підставляючи `z = w - z₀` у рівняння кола:

```
A·(w - z₀)·(w̄ - z̄₀) + B̄·(w - z₀) + B·(w̄ - z̄₀) + C = 0
```

Раскриваємо дужки:

```
A·w·w̄ + (B̄ - A·z̄₀)·w + (B - A·z₀)·w̄ + (A·|z₀|² - B̄·z₀ - B·z̄₀ + C) = 0
```

Позначивши `B' = B - A·z₀` та `C' = A·|z₀|² - 2·Re(B̄·z₀) + C ∈ ℝ`, отримуємо таке саме рівняння узагальненого кола `A·w·w̄ + B̄'·w + B'·w̄ + C' = 0`. Коефіцієнт `A` при `w·w̄` не змінився.

### Комплексна інверсія `w = 1/z`
Підставляємо `z = 1/w` та `z̄ = 1/w̄` у рівняння кола:

```
A · (1/w) · (1/w̄) + B̄ · (1/w) + B · (1/w̄) + C = 0
```

Множимо все рівняння на `w·w̄ = |w|²`:

```
A + B̄·w̄ + B·w + C·w·w̄ = 0
```

Впорядковуємо доданки:

```
C·w·w̄ + B·w + B̄·w̄ + A = 0
```

Отримане рівняння має точно таку саму алгебраїчну структуру, але коефіцієнти `A` та `C` помінялися місцями:

- Якщо початкова фігура була звичайним колом, що не проходило через `0` (`A ≠ 0`, `C ≠ 0`), результатом є нове звичайне коло з коефіцієнтом `C` при `w·w̄`.
- Якщо початкова фігура була колом, що проходило через початок координат `0` (`A ≠ 0`, `C = 0`), нове рівняння має `C' = 0` при `w·w̄`, тобто перетворюється на пряму лінію (`B·w + B̄·w̄ + A = 0`).
- Якщо початкова фігура була прямою, що не проходила через `0` (`A = 0`, `C ≠ 0`), результат стає колом, що проходить через `0` (`C' = A = 0`).
- Якщо початкова фігура була прямою через `0` (`A = 0`, `C = 0`), результат лишається прямою через `0`.

Отже, інверсія завжди переводить узагальнені кола в узагальнені кола. Оскільки всі кроки елементарного розкладу перетворюють узагальнені кола в узагальнені кола, то й будь-яке комбіноване перетворення Мьобіуса володіє цією інваріантною властивістю.

### Кола Аполлонія
Важливим геометричним наслідком збереження кіл є кола Аполлонія. Геометричне місце точок `z`, відношення відстаней від яких до двох фіксованих точок `z₁` та `z₂` є сталою величиною `k > 0` (`k ≠ 1`):

```
|z - z₁| / |z - z₂| = k
```

є звичайним колом. Відображення Мьобіуса `w = (z - z₁)/(z - z₂)` переводить це сімейство кіл Аполлонія в концентричні кола `|w| = k` з центром у початку координат, а медіатрису відрізка `[z₁, z₂]` (`k = 1`) — в одиничне коло `|w| = 1`.

## 3. Конформність та матричний Якобіан

Відображення `w = f(z)` називається конформним у точці `z₀`, якщо воно зберігає кути між будь-якими двома гладкими кривими, що перетинаються в цій точці, як за величиною, так і за напрямком обходу (орієнтацією).

Знайдемо комплексне диференційне перетворення `f'(z)`:

```
f'(z) = d/dz [ (a·z + b) / (c·z + d) ]
      = (a·(c·z + d) - c·(a·z + b)) / (c·z + d)²    [за правилом похідної частки]
      = (a·d - b·c) / (c·z + d)²                    [раскриття дужок у чисельнику]
```

Оскільки за умовою невиродженості `a·d - b·c ≠ 0`, то `f'(z) ≠ 0` для всіх `z ≠ -d/c`.

Матриця Якобі (Якобіан) двовимірного дійсного відображення `(u(x,y), v(x,y))` для аналітичної функції `f(z) = u + i·v` через умови Коші-Рімана (`u_x = v_y`, `u_y = -v_x`) має вигляд:

```
J = [ u_x   u_y ] = [  u_x   -v_x ]
    [ v_x   v_y ]   [  v_x    u_x ]
```

Визначник Якобіана дорівнює:

```
det(J) = u_x² + v_x² = |f'(z)|² > 0
```

Оскільки Якобіан є матрицею розтягу-повороту `|f'(z)| · R(θ)` (де `R(θ)` — матриця повороту на кут `θ = Arg f'(z)`), це доводить, що перетворення Мьобіуса є строго конформним у кожній точці розширеної комплексної площини, крім особливості `z = -d/c`, яка конформно відображається в `∞` на сфері Рімана.

## 4. Подвійне відношення та його інваріантність

Під подвійним (ангармонійним) відношенням чотирьох впорядкованих комплексних точок `z₁, z₂, z₃, z₄ ∈ ℂ̂` розуміють число:

```
(z₁, z₂; z₃, z₄) = ((z₁ - z₃) · (z₂ - z₄)) / ((z₁ - z₄) · (z₂ - z₃))
```

Доведемо теорему про інваріантність: для будь-якого перетворення Мьобіуса `w = f(z)` виконується тотожність:

```
(f(z₁), f(z₂); f(z₃), f(z₄)) = (z₁, z₂; z₃, z₄)
```

Знайдемо різницю двох образів `w_i - w_j`:

```
w_i - w_j = (a·z_i + b)/(c·z_i + d) - (a·z_j + b)/(c·z_j + d)
          = ((a·z_i + b)·(c·z_j + d) - (a·z_j + b)·(c·z_i + d)) / ((c·z_i + d)·(c·z_j + d))    [зведення двох дробів до спільного знаменника]
          = (a·d·(z_i - z_j) - b·c·(z_i - z_j)) / ((c·z_i + d)·(c·z_j + d))                    [розкриття дужок у чисельнику та винесення (z_i - z_j)]
          = (a·d - b·c) · (z_i - z_j) / ((c·z_i + d)·(c·z_j + d))                            [групування за визначником Δ = a·d - b·c]
```

Позначивши `Δ = a·d - b·c` та `K_i = c·z_i + d`, отримуємо:

```
w_i - w_j = Δ · (z_i - z_j) / (K_i · K_j)
```

Підставимо цю різницю в підпункти подвійного відношення чотирьох точок `w₁, w₂, w₃, w₄`:

```
(w₁ - w₃) = Δ · (z₁ - z₃) / (K₁ · K₃)
(w₂ - w₄) = Δ · (z₂ - z₄) / (K₂ · K₄)
(w₁ - w₄) = Δ · (z₁ - z₄) / (K₁ · K₄)
(w₂ - w₃) = Δ · (z₂ - z₃) / (K₂ · K₃)
```

Складаємо підсумковий дріб:

```
(w₁, w₂; w₃, w₄) 
= [ (Δ·(z₁ - z₃)/(K₁·K₃)) · (Δ·(z₂ - z₄)/(K₂·K₄)) ] / [ (Δ·(z₁ - z₄)/(K₁·K₄)) · (Δ·(z₂ - z₃)/(K₂·K₃)) ]    [підстановка виразів різниць]
= [ Δ² · (z₁ - z₃)·(z₂ - z₄) / (K₁·K₂·K₃·K₄) ] / [ Δ² · (z₁ - z₄)·(z₂ - z₃) / (K₁·K₂·K₃·K₄) ]               [перемноження чисельників і знаменників]
= ((z₁ - z₃) · (z₂ - z₄)) / ((z₁ - z₄) · (z₂ - z₃))                                                         [скорочення спільних множників Δ² та K₁·K₂·K₃·K₄]
= (z₁, z₂; z₃, z₄)                                                                                          [визначення подвійного відношення]
```

Знаменники `K₁ · K₂ · K₃ · K₄` та множники `Δ²` у чисельнику й знаменнику скорочуються повністю. Інваріантність доведено.

## 5. Нормальні канонічні форми та нерухомі точки

Нерухомою точкою перетворення `w = f(z)` є точка `z`, яка відображається сама в себе: `f(z) = z`.

```
(a·z + b) / (c·z + d) = z
```

Припускаючи `c ≠ 0`, помножимо на знаменник `c·z + d`:

```
a·z + b = c·z² + d·z
c·z² + (d - a)·z - b = 0
```

Це квадратне рівняння відносно `z`. Його дискримінант виражається через след нормованої матриці (`a·d - b·c = 1`):

```
D = (a + d)² - 4 = Tr(M)² - 4
```

### Канонічні нормальні форми

Залежно від кількості нерухомих точок довільне перетворення Мьобіуса зводиться спряженням `g o f o g⁻¹` до однієї з двох канонічних нормальних форм:

1. **Дві нерухомі точки (`z₁ ≠ z₂`):**
   Шляхом переведення `z₁ ↦ 0` та `z₂ ↦ ∞` нормальна форма має вигляд:

   ```
   (w - z₁) / (w - z₂) = λ · (z - z₁) / (z - z₂)
   ```

   де `λ = k·e^(i·θ)` — комплексний multiplier (множник).
   - Якщо `|λ| = 1` (`k = 1`), перетворення є **еліптичним** (чистий поворот на кут `θ`).
   - Якщо `Im(λ) = 0` (`θ = 0`), перетворення є **гіперболічним** (чистий розтяг із коефіцієнтом `k`).
   - Якщо `|λ| ≠ 1` та `Im(λ) ≠ 0`, перетворення є **локсодромним** (спіральний рух).

2. **Одна нерухома точка (`z₁ = z₂ = z₀`):**
   Шляхом переведення `z₀ ↦ ∞` нормальна форма має вигляд:

   ```
   1 / (w - z₀) = 1 / (z - z₀) + h
   ```

   де `h ≠ 0` — комплексний крок зсуву. Це **параболічне** перетворення.
