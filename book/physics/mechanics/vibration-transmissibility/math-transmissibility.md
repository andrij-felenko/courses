# 🧮 Звідки береться коефіцієнт передавання: фазорне виведення

Тема стверджує дивну річ: дві протилежні задачі — погасити силу від машини й уберегти прилад від тряски основи — дають той самий коефіцієнт передавання T(r, ζ). Тут ми це доводимо просто з рівняння руху, а заразом видобуваємо все, чого з готової формули не видно на око: точне місце й висоту резонансного піка (він не рівно на r = 1), дві частоти, де T = 1 за будь-якого загасання, недемпфовану границю й фазу — на скільки вихідне коливання відстає від вхідного.

Знаряддя одне, і варто спинитися, ЧОМУ саме воно.

## Знаряддя: фазор замість похідних

Уся розмова — про усталений режим: щось гойдає систему на сталій частоті ω досить довго, перехідні поштовхи згасли, і кожна величина в системі коливається на тій самій ω. Різняться вони лише двома речами — розмахом і зсувом по фазі. А два числа зручно скласти в одне комплексне.

Ідея [фазора](book:math/phasors) (англ. *phasor* — «фаза + вектор») така: замість дійсного косинуса беремо комплексний оберт і наприкінці повертаємось до дійсної частини. Підстава — [формула Ойлера](book:math/euler-formula): e^{jωt} = cos ωt + j·sin ωt, тож cos ωt = Re(e^{jωt}). Кожну величину a(t) пишемо як

```
a(t) = Re( A · e^{jωt} )
```

де A — комплексна амплітуда (фазор): її модуль |A| — це розмах, а аргумент arg A — фаза. (Уявну одиницю в механіці коливань традиційно позначають j, щоб не плутати з індексами; j² = −1.)

Навіщо це все? Похідна по часу перетворюється на просте множення:

```
d/dt  e^{jωt} = jω · e^{jωt}       →   похідна  ≡  ×jω
d²/dt² e^{jωt} = (jω)² · e^{jωt} = −ω² · e^{jωt}   →   друга похідна  ≡  ×(−ω²)
```

Диференціальне рівняння з косинусом-рушієм стає **лінійною алгеброю над комплексними числами**. А відношення двох фазорів одразу віддає дві речі: модуль — це відношення розмахів, аргумент — це зсув фаз. Саме так виглядає коефіцієнт передавання: відношення фазора «виходу» до фазора «входу». Тому фазор — природна мова цієї задачі, а не просто зручний трюк.

> 🔧 **Навіщо це.** Одне комплексне число несе і «у скільки разів», і «на скільки пізніше». Модуль дасть криву передавання, на якій стоїть уся тема; аргумент — фазу, якої на тій кривій не видно. Обидва впадуть з однієї алгебри.

## Випадок 1: сило-передавання

Маса m на пружині k з гасником коливань c спирається на нерухому основу. По масі б'є коливна сила F(t) = F₀·cos ωt (незбалансований барабан, ротор із дисбалансом). Питання: яка сила дійде до основи?

Рівняння руху маси — те саме, що в [загасному осциляторі](book:physics/damped-oscillator) з рушійною силою праворуч (звідти ж означення власної частоти ωₙ² = k/m і коефіцієнта загасання ζ = c/(2√(km))):

```
m·ẍ + c·ẋ + k·x = F₀·cos ωt
```

Переходимо у фазори: x(t) = Re(X·e^{jωt}), силу пишемо як Re(F₀·e^{jωt}) з дійсним F₀. Кожну похідну міняємо на множення:

```
(−m·ω² + j·ω·c + k) · X = F₀

        F₀
X = ───────────────────
     k − m·ω² + j·ω·c
```

Тепер головне: сила в основу йде **крізь пружину й гасник разом** (вони з'єднані паралельно між масою та основою). Пружина тисне k·x, гасник — c·ẋ, разом:

```
F_осн = k·x + c·ẋ     →  у фазорах:   F_осн = (k + j·ω·c) · X
```

Підставляємо X і ділимо на вхід F₀ — маса скорочується, лишається чиста передавальна функція:

```
F_осн       k + j·ω·c
───── = ───────────────────  ≡  H(jω)
 F₀      k − m·ω² + j·ω·c
```

Коефіцієнт передавання — це її модуль:

```
T = |F_осн| / |F₀| = |k + j·ω·c| / |k − m·ω² + j·ω·c|
```

Чисельник (k + jωc) — це «як пара пружина+гасник пропускає крізь себе силу», знаменник — «як уся одноступенева система відгукується». Запам'ятаймо це H(jω): зараз воно вигулькне вдруге з зовсім іншого боку.

## Випадок 2: рухо-передавання

Тепер джерело зовні. Основа сама їздить y(t) = Y₀·cos ωt (дрижить підлога, стіл, рама), а ми стежимо за рухом маси x(t). Пружина й гасник відчувають **різницю** рухів — наскільки маса відстала від основи:

```
m·ẍ = k·(y − x) + c·(ẏ − ẋ)
```

Переносимо все з x ліворуч, а джерело — праворуч:

```
m·ẍ + c·ẋ + k·x = k·y + c·ẏ
```

У фазори (x = Re(X·e^{jωt}), y = Re(Y·e^{jωt})):

```
(k − m·ω² + j·ω·c) · X = (k + j·ω·c) · Y

 X       k + j·ω·c
─── = ───────────────────  =  H(jω)
 Y      k − m·ω² + j·ω·c
```

Те самісіньке H(jω). Літера в літеру — і чисельник, і знаменник. А отже, збігаються не лише модулі (коефіцієнт передавання), а й **фази**: рух маси відстає від руху основи рівно так само, як передана сила відстає від прикладеної.

Чому це не випадковість? Обидва рази ми беремо відношення *через одну й ту саму пару* «пружина + гасник». Чисельник (k + jωc) — це властивість самого підвісу (два шляхи, якими зусилля перетинає його: пружний ∝ зміщенню й в'язкий ∝ швидкості). Знаменник — відгук усієї системи. Підвіс не має пам'яті про те, з якого боку його навантажили: чи маса штовхає основу, чи основа штовхає масу — «пропускна» дія та сама. Тому досить розв'язати одне завдання — друге вже безплатно в кишені.

## Нормування: до безрозмірних r і ζ

H(jω) громіздке через розмірні k, m, c. Виженемо їх. Поділимо чисельник і знаменник на k і згадаємо два означення:

```
ωₙ² = k / m        →   m·ω²/k = ω²/ωₙ² = r²      (r = ω/ωₙ — відношення частот)

c = 2ζ·√(k·m) = 2ζ·m·ωₙ    →    ω·c/k = ω·2ζ·m·ωₙ / (m·ωₙ²) = 2ζ·(ω/ωₙ) = 2ζr
```

Обидва «важкі» доданки збіглися до однієї величини — 2ζr. Передавальна функція стає безрозмірною:

```
          1 + j·2ζr
H = ─────────────────────
     (1 − r²) + j·2ζr
```

а модуль комплексного дробу — це відношення модулів чисельника й знаменника, і кожен береться за правилом |a + jb| = √(a² + b²):

```
         |1 + j·2ζr|            √(1 + (2ζr)²)
T = |H| = ────────────────── = ──────────────────────
         |(1 − r²) + j·2ζr|    √((1 − r²)² + (2ζr)²)

      = √[ (1 + (2ζr)²) / ((1 − r²)² + (2ζr)²) ]
```

Ось вона. Уся поведінка тепер сидить у двох числах: r (де ми на частотній осі) і ζ (скільки тертя). Далі — просто читаємо цю формулу з різних боків.

![Фазор чисельника N = 1 + j·2ζr та знаменника D = (1−r²) + j·2ζr у комплексній площині: коефіцієнт передавання — це відношення їхніх довжин, а фаза виходу — різниця їхніх кутів.](/book/physics/mechanics/vibration-transmissibility/img/phasor-construction.svg)

*Обидва фазори мають однакову уявну частину 2ζr (спільний член із гасника), тож їхні вершини на одній висоті. T = |N|/|D| — у скільки разів один довший за другий; φ = α − β — на який кут вихід відстав. Тут r = 1.5 (зона ізоляції): |N| < |D|, тож T < 1.*

## Дві частоти, де T = 1

Прирівняймо T до одиниці й подивімось, де підвіс не робить ні гірше, ні краще. Підносимо до квадрата й дивимось на чисельник і знаменник:

```
1 + (2ζr)²  =  (1 − r²)² + (2ζr)²
```

Член із загасанням (2ζr)² стоїть по обидва боки — **скорочується цілком**. Лишається чиста алгебра без ζ:

```
1 = (1 − r²)²      →    1 − r² = ±1
```

Два корені:

```
1 − r² = +1   →   r² = 0   →   r = 0
1 − r² = −1   →   r² = 2   →   r = √2 ≈ 1.414
```

Оскільки ζ випало ще на початку, ці рівності тримаються **за будь-якого загасання**. Тобто хоч яку гуму візьми, усі криві T(r) неодмінно проходять через дві спільні точки: r = 0 і r = √2.

Перший корінь очевидний фізично: r = 0 — це нескінченно повільне «трясіння», по суті статика; система рухається як одне ціле, розмах виходу дорівнює розмаху входу, T = 1. Другий, r = √2, — це той самий поріг ізоляції: ліворуч від нього підвіс підсилює (T > 1), праворуч — нарешті приглушує (T < 1). Красиво, що точка перетину не залежить від тертя зовсім.

**Перевірка r = √2 числом (візьмімо для конкретики ζ = 0.3):**
```
2ζr = 2·0.3·1.414 = 0.849       (2ζr)² = 0.720
1 − r² = 1 − 2 = −1             (1 − r²)² = 1
T = √[(1 + 0.720) / (1 + 0.720)] = √1 = 1      ✓
```
Чисельник дорівнює знаменнику незалежно від того, яке там 2ζr, — тому T = 1 за будь-якого ζ.

## Точний пік: не на r = 1

Резонансний пік «десь коло r = 1» — але де саме й наскільки високий? Знайдімо максимум T(r) при сталому ζ. Зручніше максимізувати T², а щоб не тягати дроби — замінити r² = u і (2ζ)² = A = 4ζ²:

```
        1 + A·u
T² = ─────────────────
      (1 − u)² + A·u
```

Максимум — там, де похідна dT²/du = 0. Беремо похідну дробу (чисельник похідної = N'·D − N·D') і після зведення подібних лишається напрочуд просте квадратне рівняння:

```
A·u² + 2u − 2 = 0     →    u = ( −1 + √(1 + 2A) ) / A
```

Повертаємось до r² = u і A = 4ζ²:

```
         ┌──────────────────┐
         │  √(1 + 8ζ²) − 1  │
r_пік = √│ ──────────────── │
         │       4ζ²        │
         └──────────────────┘
```

Це **менше** за одиницю. Для слабкого загасання розкладемо корінь: √(1 + 8ζ²) ≈ 1 + 4ζ², тож під коренем (4ζ²)/(4ζ²) = 1 з поправкою, і r_пік ≈ √(1 − 2ζ²) ≈ 1 − ζ². Пік сидить трохи нижче резонансу й сповзає лівіше, що більше тертя. При ζ = 0 він рівно на r = 1; при ζ = 1 уже аж на r ≈ 0.707.

Тепер висота. Підставмо u_пік назад. Позначмо s = √(1 + 8ζ²). Тоді A·u_пік = s − 1, і чисельник 1 + A·u = s. Знаменник після спрощення (там усе гарно скорочується через s² = 1 + 8ζ²) стає (s − 1)·s·(s + 3)/(s + 1)². Відношення дає компактний точний результат:

```
              s + 1
T_пік = ─────────────────── ,      s = √(1 + 8ζ²)
         √[ (s − 1)(s + 3) ]
```

Для слабкого загасання s ≈ 1 + 4ζ², і вираз стягується до T_пік ≈ 1/(2ζ) — тієї самої [добротності](book:physics/mechanical-resonance), що описує гостроту резонансу. Але «1/(2ζ)» — наближення; точна висота трохи вища.

**Пік для ζ = 0.05 (слабке тертя):**
```
s = √(1 + 8·0.0025) = √1.02 = 1.00995
r_пік = √[(1.00995 − 1)/(4·0.0025)] = √(0.00995/0.01) = √0.995 = 0.9975
T_пік = (s + 1)/√[(s − 1)(s + 3)]
      = 2.00995 / √(0.00995 · 4.00995) = 2.00995 / 0.19975 = 10.06
```
Отже пік не на r = 1, а на r ≈ 0.9975, і його висота 10.06, а не «рівно 10 = 1/(2·0.05)». Різниця дрібна при слабкому тремтінні, але при відчутному загасанні і зсув піка вліво, і поправка до висоти стають помітними.

## Без загасання: гола границя T = 1/|1 − r²|

Кинемо ζ = 0 у формулу — миттю видно кістяк без «м'якшого» тертя:

```
T = √[ 1 / (1 − r²)² ] = 1 / |1 − r²|
```

Тут усе оголене. При r → 1 знаменник іде в нуль, T → ∞ — чистий резонанс без стелі (саме тому будь-яке реальне загасання рятівне: воно й робить пік скінченним). Нижче резонансу (r < 1) вираз 1/(1 − r²) більший за одиницю — підсилення. Вище (r > 1) стає 1/(r² − 1); при r = √2 це рівно 1/(2 − 1) = 1 — той самий поріг, тепер уже без жодного ζ. Далеко за порогом T ≈ 1/r² — двадцять децибел на декаду спаду. Ця гола крива — скелет, на який загасання лише «навішує м'ясо»: збиває нескінченний пік до скінченного й ледь зсуває його з r = 1.

## Фаза виходу: коли передане тягне назад

Модуль ми вичавили; лишився аргумент H — те, чого на кривій передавання не видно, а він теж вилазить безплатно. Фаза виходу відносно входу — це різниця аргументів чисельника й знаменника:

```
φ(r) = arg(1 + j·2ζr) − arg((1 − r²) + j·2ζr)
     = arctan(2ζr) − arctan₂(2ζr, 1 − r²)
```

де arctan₂ — двоаргументний арктангенс (він правильно розрізняє чверті: при r < 1 дійсна частина знаменника додатна, при r > 1 — від'ємна, і кут «перевалює» за 90°). Значення φ виходять від'ємні: **вихід відстає** від входу. Пройдімо орієнтири.

**Повільно, r ≪ 1.** Обидва кути дрібні, φ ≈ 0 — вихід іде за входом майже нога в ногу, у фазі.

**На резонансі, r = 1.** Знаменник стає чисто уявним ((1 − r²) = 0), його кут рівно 90°, тож φ = arctan(2ζ) − 90° ≈ −90°. Вихід відстає приблизно на чверть періоду — класична ознака проходу через резонанс.

**Границя без загасання.** При ζ = 0 фаза стрибком: φ = 0 нижче r = 1 (у фазі) і −180° вище (у протифазі). Загасання розмазує цей стрибок у плавний спуск.

**Високо, r ≫ 1.** Тут ховається тонкість. Гасник додає в чисельник свій доданок j·2ζr, тобто **нуль** передавальної функції. Через нього фаза на високих частотах іде не до −180°, а вертається до −90°. Тому для слабкого загасання φ спершу провалюється майже до −180° одразу за резонансом, а тоді поволі підіймається назад до −90° — крива немонотонна.

Цікаво, що навіть там, де T = 1 (при r = √2, обидва фазори однакові завдовжки), вихід усе одно зсунутий: φ = 2·arctan(2ζ√2) − 180°. Для ζ = 0.2 це близько −121°. Рівність розмахів не означає «нічого не сталося» — фаза вже перевернулась.

![Фаза виходу φ залежно від відношення частот для кількох значень загасання: від нуля на малих r, крізь ≈ −90° на резонансі, до −90° на високих частотах; для слабкого загасання крива провалюється майже до −180° одразу за резонансом і повертається назад.](/book/physics/mechanics/vibration-transmissibility/img/transmissibility-phase.svg)

*Сірою пунктирною лінією — недемпфований крок 0 → −180° на r = 1. Тертя згладжує його; нуль від гасника тягне фазу на високих частотах назад до −90°, а не до −180°. Усі криві стартують з нуля (вхід і вихід у фазі) на повільному трясінні.*

## Де це працює в темі

Усе виведення стягується до одного об'єкта — комплексної передавальної функції

```
          k + j·ω·c              1 + j·2ζr
H(jω) = ─────────────────  =  ─────────────────
         k − m·ω² + j·ω·c       (1 − r²) + j·2ζr
```

і з неї читається геть уся тема. Її модуль |H| — це та сама крива коефіцієнта передавання, на якій усе тримається. Те, що H однакове для сили й для руху, — і є причина, чому один розрахунок покриває обидві дзеркальні задачі. Корінь r = √2 у рівнянні |H| = 1 задає поріг ізоляції. Точне u_пік = (√(1+8ζ²) − 1)/(4ζ²) каже, на якій частоті насправді найгірше й наскільки (а не «рівно на власній»). Гола границя 1/|1 − r²| показує скелет без тертя. А аргумент arg H — фаза — доказує, коли передана сила тягне джерело назад, а коли підштовхує. Жодного нового рівняння більше не треба: кожне практичне правило теми — це |H| або arg H, зчитане на робочому r.
