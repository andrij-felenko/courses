# ⚙️ Калькулятор squeeze-film демпфування

Три речі тягнуть відповідь у різні боки, і жодну не можна відкинути. Куб зазору `1/h³` роздмухує демпфування так круто, що промах у зазорі на пів-мікрометра зсуває втрати в рази. На тих самих малих зазорах газ перестає бути гладеньким суцільним середовищем і **прослизає** біля стінок — реальне демпфування виходить помітно слабше, ніж пророкує суцільна формула. А на високій частоті замкнений газ стискається й із демпфера обертається на пружину. Тримати всі три ефекти водночас на олівці важко, а помилка спливає вже на готовому кремнієвому чипі, коли переробляти дорого.

Тож зведімо фізику прошарку в невеликий інструмент. На вхід — геометрія (прямокутник `L×W`, зазор `h₀`), газ ([в'язкість](book:physics/viscosity) `μ`, [довжина вільного пробігу](book:physics/mean-free-path) `λ`), навколишній тиск `p₀` й частота `f`. На виході — нестисливий коефіцієнт демпфування `c`, число стиснення `σ`, частота зрізу, поділ на демпфер і газову пружину, ефективна в'язкість із поправкою на розрідження та стеля [добротності](book:physics/q-factor), яку прошарок накидає резонаторові заданої маси. Це помічник конструктора: його ганяють **перед** тим, як щось витравлювати, тому й писатимемо його заради ясності — на Python з numpy, розкладаючи все на масиви, а не заради мікросекунд.

## Що він рахує — і чому це майже одна сума

За всім цим стоїть одна картина. Тиск під пластиною, що коливається, розкладається на «squeeze-моди» — стоячі синуси `sin(mπx/L)·sin(nπy/W)` з непарними `m`, `n`. Кожна мода витікає вбік із власною швидкістю: чим дрібніша мода (більші `m`, `n`), тим коротший шлях до вузла й тим швидше вона встигає розсмоктатися. При гармонічному русі на частоті `ω` кожна мода поводиться як простий фільтр-високочастотник із кутовою частотою

```
ω_mn = (π²·p₀·h₀²)/(12·μ_eff) · (m²/L² + n²/W²)
```

Нижче своєї кутової (`ω ≪ ω_mn`) газ моди встигає втекти — вона **демпфує**. Вище (`ω ≫ ω_mn`) газ замкнено — вона **пружинить**. Увесь прошарок — це сума таких мод, і звідси прямо виходять обидва коефіцієнти:

```
c(ω) = (64·p₀·L·W)/(π⁴·h₀) · Σ  1/(mn)² · ω_mn/(ω_mn² + ω²)     демпфер, Н·с/м
k(ω) = (64·p₀·L·W)/(π⁴·h₀) · Σ  1/(mn)² · ω² /(ω_mn² + ω²)     пружина, Н/м
                                m,n непарні
```

Нестисливе демпфування — це просто границя `ω → 0`, і вона згортається у компактну форму на кшталт Стефанової:

```
c₀ = β(W/L) · μ_eff · L · W³ / h₀³
```

де `β` — **множник форми** з тієї самої суми мод: `β = 0.42` для квадрата, `β → 1` для довгої смуги. Узяти `β` не для того співвідношення сторін — це тиха похибка в ≈2.4 раза, тому в коді ми не вбиваємо число, а рахуємо `β` із суми для будь-якого `L:W`.

Далі — поправка на розрідження. Коли зазор наближається до `λ`, газ прослизає вздовж стінок і переносить імпульс гірше, тож його **ефективна в'язкість падає**. Її беруть за емпіричним припасуванням, яке дали Veijola та колеги (1995) для squeeze-плівки в кремнієвому акселерометрі:

```
Kn = λ / h₀
μ_eff = μ / (1 + 9.638·Kn^1.159)
```

Головне — це **ділення**, а не множення: більший `Kn` (вужчий зазор) → менша `μ_eff` → слабше демпфування. І `μ_eff`, а не сиру `μ`, треба підставити **скрізь**, де фігурує в'язкість: у `c₀`, у `σ` і в `ω_mn`. Інакше поправка ляже лише наполовину.

Нарешті число стиснення, зріз і стеля добротності:

```
σ   = 12·μ_eff·ω·a² / (p₀·h₀²),   a = min(L, W)   — коротша сторона задає час втечі
f_c = ω₁₁ / 2π                                     — кутова першої моди
Q   = M·ω₀ / c,     ζ = c / (2·M·ω₀)               — стеля Q від прошарку
```

## Код

Одна структурка на вхід і чотири короткі функції. Уся математика — векторна: сітка непарних мод і одна векторна сума `numpy`, без гарячих циклів.

```python
import numpy as np
from dataclasses import dataclass

@dataclass
class Film:
    L:  float                # довша сторона пластини, м
    W:  float                # коротша сторона, м
    h0: float                # зазор, м
    mu:  float = 1.8e-5      # в'язкість газу, Па·с        (повітря ≈ 1.8·10⁻⁵)
    lam: float = 68e-9       # довжина вільного пробігу, м (повітря ≈ 68 нм)
    p0:  float = 101_325.0   # навколишній тиск, Па

def _odd(N=40):
    o = np.arange(1, 2*N, 2)                 # 1, 3, 5, …
    return np.meshgrid(o, o, indexing="ij")

def eff_viscosity(f):
    """μ_eff за Veijola: прослизання біля стінок зменшує ефективну в'язкість."""
    Kn = f.lam / f.h0
    return f.mu / (1.0 + 9.638 * Kn**1.159), Kn

def damping_incompressible(f, N=40):
    """Нестисливий коеф.  c₀ = β·μ_eff·L·W³/h₀³  через суму squeeze-мод."""
    mu, _ = eff_viscosity(f)
    m, n  = _odd(N)
    S  = np.sum(1.0 / ((m*n)**2 * (m**2/f.L**2 + n**2/f.W**2)))
    c0 = 768.0 * mu * f.L * f.W * S / (np.pi**6 * f.h0**3)
    beta = c0 * f.h0**3 / (mu * f.L * f.W**3)      # 0.42 квадрат, →1 смуга
    return c0, beta

def split(f, freq, N=40):
    """Стисливий поділ:  c(ω) — демпфер,  k(ω) — газова пружина."""
    w    = 2*np.pi*freq
    mu, _ = eff_viscosity(f)
    m, n = _odd(N)
    w_mn = (np.pi**2 * f.p0 * f.h0**2 / (12*mu)) * (m**2/f.L**2 + n**2/f.W**2)
    pref = 64.0 * f.p0 * f.L * f.W / (np.pi**4 * f.h0)
    inv  = 1.0 / (m*n)**2
    c = pref * np.sum(inv * w_mn / (w_mn**2 + w**2))    # Н·с/м
    k = pref * np.sum(inv * w**2  / (w_mn**2 + w**2))    # Н/м
    f_c   = w_mn.min() / (2*np.pi)         # зріз — кутова першої моди ω₁₁
    a     = min(f.L, f.W)                  # коротша сторона задає час втечі
    sigma = 12*mu*w*a**2 / (f.p0 * f.h0**2)
    return c, k, f_c, sigma

def q_ceiling(f, mass, f0, N=40):
    """Стеля Q, яку прошарок накидає резонаторові маси mass із частотою f0."""
    c, k, f_c, sigma = split(f, f0, N)
    w0 = 2*np.pi*f0
    return mass*w0/c, c/(2*mass*w0), c     # Q, ζ, c(ω₀)
```

Запуск на зразковій пластині — квадрат `200×200 мкм` за `2 мкм` над підкладкою, у звичайному повітрі, з робочою частотою `10 кГц`:

```python
plate = Film(L=200e-6, W=200e-6, h0=2e-6)
c0, beta          = damping_incompressible(plate)
c, k, f_c, sigma  = split(plate, 10e3)
mass              = 200e-6 * 200e-6 * 2e-6 * 2330   # кремній, товщина 2 мкм → 0.19 мкг
Q, zeta, _        = q_ceiling(plate, mass, 10e3)

print(f"μ_eff/μ = {eff_viscosity(plate)[0]/plate.mu:.3f}   (Kn = {plate.lam/plate.h0:.3f})")
print(f"β       = {beta:.3f}")
print(f"c₀      = {c0:.3e} Н·с/м    c(10кГц) = {c:.3e}   k = {k:.2f} Н/м")
print(f"σ       = {sigma:.2f}    f_c = {f_c/1e3:.0f} кГц")
print(f"Q_film  = {Q:.4f}   (ζ = {zeta:.1f})")
```

## Що показує зразкова пластина

```
μ_eff/μ = 0.839   (Kn = 0.034)
β       = 0.422
c₀      = 1.274e-03 Н·с/м    c(10кГц) = 1.270e-03   k = 4.35 Н/м
σ       = 1.12    f_c = 176 кГц
Q_film  = 0.0092   (ζ = 54.2)
```

Прочитаймо ці числа — кожне щось радить конструкторові.

**Розрідження вже кусає навіть за 2 мкм.** `Kn = 0.034` — начебто мало, але `μ_eff/μ = 0.839`: прошарок утратив 16 % ефективної в'язкості, ще й не думаючи заходити в молекулярний режим. Якби ми взяли суцільну формулу з сирою `μ` і хрестоматійним `β = 0.42`, вийшло б `1.51·10⁻³` замість `1.27·10⁻³` — завищення в 1.19 раза на голому місці.

**На 10 кГц це ще демпфер.** `σ = 1.12` далеко від переходу, а `f_c = 176 кГц` — аж де-небудь угорі. Робоча частота вкладається в `f/f_c ≈ 0.06`, тобто газ устигає витікати, і `c(10кГц)` майже збігається з нестисливим `c₀` (`c/c₀ = 0.997`). Для квадрата перехід «демпфер → пружина» лежить біля `σ ≈ 2π² ≈ 20` (перша мода бере `1/L² + 1/W²`), а для довгої смуги — біля `σ ≈ π² ≈ 10` (працює лише один вимір). Ось звідки та обережна приказка «`σ` порядку `π²`, точне число залежить від форми»: калькулятор робить її точною.

**Газова пружина мала, але не нульова.** `k = 4.35 Н/м` — дрібниця проти повністю замкненого газу (`p₀·A/h₀ ≈ 2000 Н/м`), бо на малому `σ` майже все витікає. Та якщо власна механічна жорсткість цієї пластинки лише `M·ω₀² ≈ 0.74 Н/м`, то навіть така крихітна `k` — це вшестеро більше, і вона помітно **зсуває власну частоту** резонатора. Тому `k(ω)` варто дивитися разом із `c(ω)`, а не після.

**А тепер найважче число.** `Q_film = 0.009`, `ζ = 54`. Прошарок повітря настільки давить цю пластину, що вона взагалі **не задзвенить** — коефіцієнт загасання вп'ятдесятеро більший за критичний, це не резонатор, а грудка глини. Калькулятор каже це **до** виготовлення: у повітрі на `2 мкм` від підкладки такий резонатор мертвий, і єдиний вихід — прибрати газ.

> 🔧 **Навіщо це.** Саме цей рядок пояснює, чому точні MEMS-резонатори — генератори такту, гіроскопи, фільтри — живуть у вакуумній упаковці. Не примха й не боротьба з окисненням: у повітрі squeeze-film опускає стелю `Q` нижче одиниці, і жодне налаштування геометрії цього не витягне. Порахувати `Q_film` — перший крок, який каже, потрібен вакуум чи ні, ще на папері.

## Розгортка зазору: урвище й де його згинає розрідження

Найкорисніше, що вміє інструмент, — прогнати зазор і показати, як `1/h³` бореться з розрідженням:

```python
for h_um in (10, 3, 1, 0.3, 0.1):
    f = Film(L=200e-6, W=200e-6, h0=h_um*1e-6)
    c0, _  = damping_incompressible(f)                    # з поправкою на μ_eff
    c_cont = 0.42 * f.mu * f.L * f.W**3 / f.h0**3         # «суцільна» 1/h³
    print(f"h = {h_um:>4} мкм   Kn = {f.lam/f.h0:5.3f}   "
          f"c₀ = {c0:.2e}   суцільна = {c_cont:.2e}   ×{c_cont/c0:.2f}")
```

```
h =   10 мкм   Kn = 0.007   c₀ = 1.18e-05   суцільна = 1.21e-05   ×1.03
h =    3 мкм   Kn = 0.023   c₀ = 4.02e-04   суцільна = 4.48e-04   ×1.12
h =    1 мкм   Kn = 0.068   c₀ = 8.51e-03   суцільна = 1.21e-02   ×1.42
h =  0.3 мкм   Kn = 0.227   c₀ = 1.65e-01   суцільна = 4.48e-01   ×2.71
h =  0.1 мкм   Kn = 0.680   c₀ = 1.70e+00   суцільна = 1.21e+01   ×7.13
```

Обидва стовпці летять угору як `1/h³` — від `10` до `0.1 мкм` демпфування зростає в `10⁶` разів, дослівно урвище. Але суцільна колонка й колонка з поправкою **розходяться**, і що вужчий зазор, то дужче. За `2 мкм` різниця — скромні 19 %, за `1 мкм` — уже півтора раза, а за `0.1 мкм` суцільна формула бреше в **сім разів**: вона й далі вірить у гладкий газ, тоді як насправді молекули майже вільно ковзають повз стінки. Пряма `1/h³` в логарифмі — а реальна крива на малих зазорах помітно від неї відгинається вниз.

## Складність і пастки

**Складність.** Рахувати нема чого боятися. Вага `1/(mn)²` гасить високі моди так швидко, що кількох десятків непарних доданків із головою — насправді збіжність настає вже на `N ≈ 8`. Кожен виклик — це одне векторне підсумовування `numpy` по сітці `N×N`, тобто мікросекунди; повна розгортка зазору на сотні точок відпрацьовує за мить. Ми свідомо лишили прозору суму мод замість підігнаного замкненого виразу: інструмент проєктний, і бачити, звідки взялося число, важливіше, ніж заощадити такти.

Небезпека не в обчисленні, а в тому, **що** підставити. Ось де промахуються найчастіше.

- **Забути розрідження на малих зазорах.** Найпоширеніша й найдорожча помилка. Суцільна `1/h³` завищує втрати вже на 19 % за `2 мкм` і всемеро за `0.1 мкм`. Правило: перше, що рахуємо, — це `Kn = λ/h₀`; щойно `Kn` перевалює за `~0.01`, беремо `μ_eff`, а не `μ`.

- **Суцільна модель у молекулярному режимі.** Поправка Veijola — це **місток** через зону прослизання й початок перехідного режиму, а не істина на всі випадки. Коли `Kn` дотягується до `~1` (зазор порівнявся з `λ`), газ стає майже вільномолекулярним, і саме рівняння Рейнольдса — навіть із прослизанням — перестає описувати те, що діється. Тут потрібна вже вільномолекулярна модель (з кінетики, а не з в'язкої течії). Тому розумний калькулятор на такому `Kn` не екстраполює мовчки, а голосно попереджає:

```python
def regime_warning(f):
    Kn = f.lam / f.h0
    if Kn > 1.0:
        return f"Kn={Kn:.2f}: молекулярний режим — суцільна модель НЕ діє"
    if Kn > 0.1:
        return f"Kn={Kn:.2f}: перехідний режим — μ_eff обов'язкова, точність груба"
    return f"Kn={Kn:.3f}: течія суцільна зі слабким прослизанням — модель надійна"
```

- **`β` не для того співвідношення сторін.** Хрестоматійне `β = 0.42` — це квадрат. Застосуйте його до довгої смуги (де правильне `β → 1`) — і занизите демпфування в ≈2.4 раза; навпаки, візьміть смугове `β = 1` для квадрата — і рівно настільки ж завищите. Тому в коді `β` не константа, а результат суми мод, який сам підлаштовується під будь-який `L:W`.

- **`μ` замість `μ_eff` у `σ` та `f_c`.** Розрідження зсуває не лише демпфування — воно рухає всю карту: число стиснення, частоту зрізу, межу «демпфер / пружина». Виправляйте в'язкість **один раз**, у `eff_viscosity`, і протягуйте `μ_eff` крізь усі формули, а не тільки в `c₀`.

- **Звітувати `c₀`, коли `σ ≫ 1`.** На високій частоті, малому зазорі чи низькому тиску прошарок стає переважно пружиною. Нестисливий `c₀` там завищує демпфування й геть проминає жорсткість `k`, що зсуває резонанс. Дивіться частотнозалежні `c(ω)` і `k(ω)`, а не саме `c₀`.

І межа чесності: ця модель — про суцільну непробиту пластину. Перфорація вкорочує шлях втечі й обриває демпфування; крайові ефекти на вузьких пластинах трохи його додають. Обидві поправки — окрема розмова; калькулятор дає базову лінію, від якої їх відлічують.
