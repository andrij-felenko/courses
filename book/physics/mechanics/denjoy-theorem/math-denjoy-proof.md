# 🧮 Математичне виведення теореми Данжуа та конструкція контрприкладу

Ця вставка містить строге математичне виведення леми Данжуа про спотворення похідних (Denjoy Distortion Lemma), доведення відсутності блукаючих інтервалів для відображень із похідною обмеженої варіації, а також детальну точну конструкцію контрприкладу Денжуа у класі `C¹(S¹)`.

## 1. Арифметика ланцюгових дробів та наближення чисел обертання

Нехай `f: S¹ → S¹` — збережувальний орієнтацію диффеоморфізм кола з ірраціональним числом обертання `ρ(f) = α ∉ ℚ`.

Розкладемо ірраціональне число `α ∈ (0, 1)` у нескінченний ланцюговий дріб:

```
α = 1 / (a_1 + 1 / (a_2 + 1 / (a_3 + ...))) = [0; a_1, a_2, a_3, ...]
```

де `a_k ∈ ℕ` — неповні частки (partial quotients) розкладу.

Послідовність найкращих раціональних наближень `p_n / q_n` обчислюється за рекурентними формулами для чисельників та знаменників:

```
p_{-1} = 1,   p_0 = 0,   p_{n+1} = a_{n+1} p_n + p_{n-1}
q_{-1} = 0,   q_0 = 1,   q_{n+1} = a_{n+1} q_n + q_{n-1}
```

Знаменники `q_n` володіють фундаментальними алгебраїчними та геометричними властивостями, які визначають поведінку орбіт на колі:

1. **Некратне зростання знаменників**:

```
q_{n+1} ≥ q_n + q_{n-1} ≥ 2 q_{n-1}      [зокрема q_n ≥ 2^{(n-1)/2}]
```

2. **Точність наближення (нерівність Діріхле)**:

```
1 / (q_n (q_{n+1} + q_n)) < | α - p_n / q_n | < 1 / (q_n q_{n+1})
```

3. **Геометрична топологія орбіт (Тривідстаннева теорема)**:
   Для будь-якої початкової точки `x ∈ S¹` множина точок `{x, f(x), f²(x), ..., f^{q_n - 1}(x)}` ділить коло `S¹` на `q_n` неперетинних підінтервалів. Сусідні точки цієї орбіти знаходяться на відстанях, які приймають лише два (або максимум три) можливих значення: `|q_n α - p_n|` та `|q_{n-1} α - p_{n-1}|`.

Зокрема, важливим є той факт, що жодна точка орбіти `f^k(x)` при `1 ≤ k < q_n` не може потрапити у відкритий інтервал між точкою `x` та її `q_n`-м образом `f^{q_n}(x)`. Це геометричне розбиття гарантує, що підінтервали, утворені траєкторією, не накладаються один на одного занадто часто.

## 2. Доведення леми Данжуа про спотворення похідних

Нехай логарифм похідної `log f'` має обмежену варіацію `Var(log f') = V < ∞` на колі `S¹`.

Розглянемо `q_n`-у ітерацію відображення `f^{q_n}(x)`. За ланцюговим правилом диференціювання складного відображення, похідна дорівнює:

```
(f^{q_n}')(x) = ∏_{k=0}^{q_n-1} f'(f^k(x))
```

Логарифмуючи обидві частини, переходимо від добутку похідних до суми їхніх логарифмів уздовж орбіти:

```
log (f^{q_n}')(x) = ∑_{k=0}^{q_n-1} log f'(f^k(x))
```

Візьмемо дві довільні точки `x, y ∈ S¹`. Знайдемо різницю логарифмів їхніх похідних під дією `q_n`-ї ітерації відображення:

```
log (f^{q_n}')(x) - log (f^{q_n}')(y)
= ∑_{k=0}^{q_n-1} ( log f'(f^k(x)) - log f'(f^k(y)) )      [групування доданків суми]
```

Оскільки точки `{f^k(x)}_{k=0}^{q_n-1}` та `{f^k(y)}_{k=0}^{q_n-1}` утворюють послідовність пар точок, що обмежують підінтервали `J_k` з кінцями `f^k(x)` та `f^k(y)`, сума різниць значень функції `log f'` на цих підінтервалах оцінюється зверху повною варіацією функції:

```
| ∑_{k=0}^{q_n-1} ( log f'(f^k(x)) - log f'(f^k(y)) ) |
≤ ∑_{k=0}^{q_n-1} | log f'(f^k(x)) - log f'(f^k(y)) |
≤ ∑_{k=0}^{q_n-1} Var(log f'; J_k)
```

Оскільки для знаменника ланцюгового дробу `q_n` підінтервали `J_k` покривають коло `S¹` щонайбільше двічі (кожна точка кола належить максимум двом інтервалам `J_k`), сума варіацій по всіх підінтервалах обмежується подвійною повною варіацією функції на всьому колі:

```
∑_{k=0}^{q_n-1} Var(log f'; J_k) ≤ 2 · Var(log f') = 2 V
```

Детальніший геометричний аналіз розташування точок дозволяє покращити константу з `2V` до `V`. Таким чином отримуємо точну аналітичну оцінку:

```
| log (f^{q_n}')(x) - log (f^{q_n}')(y) | ≤ V      [Лема Данжуа про спотворення]
```

Потенціюючи отриману нерівність, маємо подвійну нерівність:

```
exp(-V) ≤ (f^{q_n}')(x) / (f^{q_n}')(y) ≤ exp(V)
```

Ця нерівність є **універсальною нерівністю спотворення Данжуа**: відношення похідних `q_n`-ї ітерації в будь-яких двох точках кола є обмеженим сталими `exp(V)` та `exp(-V)`, незалежно від номера ітерації `q_n`.

## 3. Доведення відсутності блукаючих інтервалів

Тепер доведемо, що для `C²`-диффеоморфізму (або будь-якого диффеоморфізму з `Var(log f') < ∞`) блукаючі інтервали повністю відсутні.

Припустимо від зворотного, що на колі `S¹` існує відкритий блукаючий інтервал `I_0 = (a, b)` додатної довжини `|I_0| = b - a > 0`.

Розглянемо послідовність його образів під дією ітерацій `f`:

```
I_k = f^k(I_0),   k ∈ ℤ
```

За означенням блукаючого інтервалу, всі образи є попарно диз'юнктними:

```
I_k ∩ I_m = ∅   при   k ≠ m
```

Оскільки всі інтервали `I_k` лежать всередині кола `S¹` одиничної довжини `|S¹| = 1`, сума їхніх довжин повинна бути строго обмеженою:

```
∑_{k=0}^{∞} |I_k| ≤ |S¹| = 1 < ∞
```

За необхідною ознакою збіжності числового ряду, довжини образів обов'язково прямують до нуля:

```
lim_{k → ∞} |I_k| = 0      [необхідна умова збіжності ряду довжин]
```

З іншого боку, застосуємо теорему Лагранжа про середнє значення до функції `f^{q_n}` на інтервалі `I_0`. Існує точка `y_n ∈ I_0`, така що довжина `q_n`-го образу дорівнює:

```
|I_{q_n}| = |f^{q_n}(I_0)| = (f^{q_n}')(y_n) · |I_0|
```

Тепер застосуємо теорему про середнє значення для похідної на всьому колі. Оскільки загальна довжина кола дорівнює `1`, маємо:

```
∫_0¹ (f^{q_n}')(x) dx = f^{q_n}(1) - f^{q_n}(0) = 1
```

За теоремою про середнє значення для інтеграла, на колі обов'язково знайдеться принаймні одна точка `x_n ∈ S¹`, у якій значення похідної дорівнює точно одиниці:

```
(f^{q_n}')(x_n) = 1
```

Застосуємо нерівність Данжуа про спотворення до пари точок `y_n ∈ I_0` та `x_n ∈ S¹`:

```
(f^{q_n}')(y_n) / (f^{q_n}')(x_n) ≥ exp(-V)
```

Підставляючи `(f^{q_n}')(x_n) = 1`, отримуємо нижню оцінку для похідної у точці `y_n`:

```
(f^{q_n}')(y_n) ≥ exp(-V)
```

Підставимо цю нижню оцінку у вираз для довжини інтервалу `|I_{q_n}|`:

```
|I_{q_n}| = (f^{q_n}')(y_n) · |I_0| ≥ exp(-V) · |I_0|
```

Оскільки `V = Var(log f') < ∞` та `|I_0| > 0`, величина `C_{min} = exp(-V) · |I_0|` є **строго додатною сталою**, яка не залежить від `n`!

Таким чином, для підпослідовності знаменників `q_n` ми отримали:

```
|I_{q_n}| ≥ C_{min} > 0   для всіх   n ∈ ℕ
```

Це виражає пряму суперечність із раніше доведеним фактом `lim_{k → ∞} |I_k| = 0`. Границя довжин образів мусить дорівнювати нулю, але нерівність Данжуа забороняє їм опускатися нижче `C_{min} > 0`.

Отже, припущення про існування блукаючого інтервалу `I_0` додатної довжини `|I_0| > 0` є хибним. На колі `S¹` не існує жодного блукаючого інтервалу, а отже будь-яка орбіта є всюди щільною на `S¹`, і відображення `f` є топологічно спряженим до жорсткого повороту `R_α`. Теорему доведено.

## 4. Явна конструкція контрприкладу Денжуа у класі $C^1(S^1)$

Щоб зрозуміти, чому умова `Var(log f') < ∞` є непереборною межею, наведемо точну покрокову конструкцію контрприкладу Денжуа у класі `C¹(S¹)`.

**Крок 1. Базовий поворот.**
Візьмемо чистий поворот `R_α(x) = x + α (mod 1)` з ірраціональним числом `α ∈ (0, 1)`. Фіксуємо початкову точку `x_0 = 0` і розглянемо її орбіту `x_n = R_αⁿ(0) = n α (mod 1)` для всіх `n ∈ ℤ`.

**Крок 2. Задання довжин інтервалів.**
Оберем послідовність додатних чисел `{l_n}_{n ∈ ℤ}`, які задовольняють дві вимоги:
1. Сума послідовності є скінченною:

```
L = ∑_{n = -∞}^{∞} l_n < ∞      [наприклад, l_n = 1 / (|n| + 2)²]
```

2. Відношення сусідніх членів прямує до одиниці при `n → ±∞`, але їхня різниця зростає:

```
lim_{|n| → ∞} (l_{n+1} / l_n) = 1,   але   ∑_{n = -∞}^{∞} | 1 - l_{n+1} / l_n | = ∞
```

**Крок 3. "Роздування" точок орбіти у блукаючі інтервали.**
Замінимо кожну точку `x_n` орбіти повороту на відкритий інтервал `I_n` довжиною `l_n`. Сукупна довжина нових інтервалів дорівнює `L`.

Розширимо коло `S¹` до нового кола `S¹_{new}` довжиною `1 + L`. Для цього визначимо монотонну фукцію розширення `h_0: [0, 1] → [0, 1 + L]`:

```
h_0(x) = x + ∑_{x_n < x} l_n
```

Множина `K = h_0(S¹) \ (⋃_{n ∈ ℤ} I_n)` є замкненою, доскональною, ніде не щільною канторівською множиною на розширеному колі `S¹_{new}`.

**Крок 4. Побудова відображення `f`.**
На кожному інтервалі `I_n = (a_n, b_n)` довжиною `l_n` задамо відображення `f`, яке гладко переводить `I_n` в `I_{n+1} = (a_{n+1}, b_{n+1})` довжиною `l_{n+1}`.

Щоб відображення `f` було класу `C¹`, його похідна `f'(x)` на кінцях інтервалу `a_n` та `b_n` повинна дорівнювати `1` і неперервно узгоджуватися з похідною на канторівській множині `K`, де `f'(x) = 1` для всіх `x ∈ K`.

На інтервалі `I_n = [a_n, b_n]` задамо похідну `f'(x)` за допомогою гладкої купольної функції:

```
f'(x) = 1 + (l_{n+1} / l_n - 1) · φ( (x - a_n) / l_n )
```

де `φ: [0, 1] → [0, 1]` — гладка функція, така що `φ(0) = φ(1) = 0` та `∫_0¹ φ(t) dt = 1`.

Інтегруючи похідну, отримуємо `f(b_n) - f(a_n) = l_n + (l_{n+1} - l_n) = l_{n+1}`, що тотожно гарантує переведення інтервалу `I_n` у сусідній інтервал `I_{n+1}`!

**Крок 5. Перевірка гладкості та варіації.**
Оскільки `lim_{|n| → ∞} (l_{n+1} / l_n) = 1`, маємо:

```
lim_{x → K} f'(x) = 1
```

Отже, похідна `f'(x)` є **суцільно неперервною** на всьому колі `S¹_{new}`, що означає `f ∈ C¹(S¹)`.

Проте обчислимо варіацію логарифма похідної `log f'`:

```
Var(log f') ≥ ∑_{n = -∞}^{∞} | log f'(x_n^{max}) - log f'(a_n) |
≈ ∑_{n = -∞}^{∞} | (l_{n+1} / l_n - 1) | = ∞
```

Через те, що сума відносних відхилень довжин `∑ |l_{n+1} / l_n - 1| = ∞`, варіація логарифма похідної є **нескінченною** (`Var(log f') = ∞`).

Контрприклад побудовано. Ми явно показуємо, як виникає блукаючий інтервал `I_0`, чому відображення є класу `C¹`, і який саме аналітичний механізм (нескінченна варіація `log f'`) дає йому змогу оминути нерівність Данжуа.
