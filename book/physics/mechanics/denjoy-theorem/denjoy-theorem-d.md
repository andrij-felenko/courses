Спроба описати регулярне обертання зв'язаних нелінійних осциляторів, таких як два фазово-синхронізовані генератори, джозефсонівські переходи під дією зовнішнього випромінювання або електрони у квантовому кільці під дією змінного поля, за допомогою неперервного деформування кола неминуче приводить до відображень кола `f: S¹ → S¹`. Якщо відношення власних частот двох систем є ірраціональним числом `α`, виникає фундаментальна динамічна дилема: чи будуть траєкторії системи рівномірно й щільно заповнювати все коло (як при ідеальному жорсткому повороті), чи фазовий простір розпадеться на блукаючі ділянки з фрактальним атрактором. Теорема Данжуа (Arnaud Denjoy, 1932) дає чітку та вичерпну відповідь: якщо відображення є достатньо гладким, зародження блукаючих інтервалів та фрактальних атракторів є фізично та математично неможливим, а динаміка є топологічно еквівалентною чистому повороту.

## Геометрія кругових відображень та число обертання Пуанкаре

Розглянемо орієнтоване коло `S¹ = ℝ / ℤ`, яке зручно моделювати півінтервалом `[0, 1)` з тотожним склеюванням кінцевих точок `0` та `1`. Будь-яка неперервна функція `f: S¹ → S¹`, яка зберігає орієнтацію та є взаємно однозначною, називається гомеоморфізмом кола. Для математичного та фізичного аналізу динаміки такої системи зазвичай переходять від замкненого кола до його універсальної накриваючої прямої `ℝ` за допомогою операції підйому (lift).

Підйомом гомеоморфізму `f: S¹ → S¹` називається така неперервна функція `F: ℝ → ℝ`, яка задовольняє природну умову проекції на коло:

```
F(x) (mod 1) = f(x (mod 1))      [умова комутації проекції]
```

Оскільки відображення `f` зберігає орієнтацію та є взаємно однозначним, його підйом `F` є строго зростаючою монотонною функцією на прямій `ℝ` і задовольняє фундаментальне тотожне співвідношення періодичності:

```
F(x + 1) = F(x) + 1              [збереження одиничного періоду накриття]
```

Зауважимо, що підйом `F` визначений з точністю до додавання цілого числа. Якщо обрати один конкретний підйом `F`, то для будь-якої початкової точки `x ∈ ℝ` послідовні ітерації `Fⁿ(x) = (F ∘ F ∘ ... ∘ F)(x)` описують повний рух точки вздовж розгорнутої прямої.

У 1885 році Анрі Пуанкаре у своїй класичній праці про диференціальні рівняння на торі довів, що середня швидкість зміщення точки при нескінченній кількості ітерацій завжди існує, є скінченною і не залежить від вибору початкової точки `x`:

```
ρ(F) = lim_{n → ∞} (Fⁿ(x) - x) / n
```

Значення цього ліміту, вираховане за модулем `1`, називається числом обертання Пуанкаре (Poincaré rotation number) і позначається `ρ(f) ∈ [0, 1)`:

```
ρ(f) = ρ(F) (mod 1)
```

Доведення існування числа обертання базується на топологічній властивості монотонності підйому `F`. Якщо для двох точок виконано `x < y`, то за строгим зростанням `F` маємо `Fⁿ(x) < Fⁿ(y)` для всіх `n ∈ ℕ`. Крім того, з умови `F(x + 1) = F(x) + 1` випливає, що для будь-яких цілих чисел `k, m ∈ ℤ` нерівність `Fⁿ(x) - x < k` рівносильна нерівності `F^{m·n}(x) - x < m·k`. Це дозволяє встановити рівномірне обмеження на коливання величини `Fⁿ(x) - x` для всіх `x ∈ ℝ`:

```
| (Fⁿ(x) - x) - (Fⁿ(y) - y) | < 1      [рівномірна оцінка для довільних x, y]
```

Ділення цієї нерівності на `n` при `n → ∞` негайно доводить, що границя є абсолютно однаковою для всіх початкових точок `x`. Цей важливий факт означає, що середня кутова швидкість обертання фазової точки є глобальною характеристикою всієї динамічної системи, а не властивістю окремої траєкторії.

Число обертання Пуанкаре `ρ(f)` відіграє роль фундаментального топологічного інваріанта системи. Воно визначає середня кількість обертів, яку здійснює фазова точка навколо кола за один крок дискретного часу. За залежністю від арифметичної природи числа `ρ(f)` усі кругові відображення поділяються на два принципово відмінних класи:

1. **Раціональне число обертання `ρ(f) = p / q ∈ ℚ` (де `p` та `q` — взаємно прості цілі числа)**:
   У цьому випадку відображення `f` обов'язково має принаймні одну періодичну орбіту періоду `q`, тобто існує точка `x_0 ∈ S¹`, для якої `f^{q}(x_0) = x_0`. Будь-яка інша орбіта `fⁿ(x)` при `n → ∞` асимптотично наближається до однієї з таких періодичних орбіт. У фізиці це відповідає явищу фазового захоплення (phase locking), або резонансу, коли власні коливання системи повністю синхронізуються із зовнішньою періодичною силою.

2. **Ірраціональне число обертання `ρ(f) = α ∉ ℚ`**:
   У цьому випадку періодичні орбіти повністю відсутні. Жодна точка не повертається в початковий стан за скінченну кількість кроків (`fⁿ(x) ≠ x` для всіх `n ∈ ℕ` та всіх `x ∈ S¹`). Траєкторії неперервно блукають по колу, утворюючи квазіперіодичний режим коливань.

Найпростішим і найчистішим представником ірраціонального обертання є жорсткий або чистий поворот (rigid rotation) на ірраціональний кут `α`:

```
R_α(θ) = θ + α (mod 1)
```

Для жорсткого повороту з ірраціональним `α` кожна орбіта `{R_αⁿ(θ)}_{n ∈ ℤ}` є всюди щільною на колі `S¹` (теорема Якобі-Кронекера). Крім того, звичайна міра Лебега `λ` на колі є єдиною інваріантною ймовірнісною мірою для `R_α`, що означає строгу ергодичність системи: часові середні вздовж будь-якої траєкторії збігаються з просторовими середніми по всьому колу.

Природно виникає фундаментальне питання класичної динаміки: якщо довільний неперервний гомеоморфізм `f: S¹ → S¹` має ірраціональне число обертання `ρ(f) = α`, чи буде його якісна динаміка повністю еквівалентною ідеальному жорсткому повороту `R_α`? Іншими словами, чи існує неперервна заміна координат `h: S¹ → S¹` (гомеоморфізм), яка спряжує відображення `f` з чистим поворотом `R_α`?

Таке співвідношення називається топологічною спряженістю (topological conjugacy) і описується функціональним рівнянням спряження:

```
h(f(x)) = R_α(h(x))      [комутаційна діаграма: h ∘ f = R_α ∘ h]
```

Якщо такий гомеоморфізм `h` існує, то відображення `f` успадковує всі топологічні та динамічні властивості жорсткого повороту: усі його орбіти є всюди щільними на колі `S¹`, у системі відсутні атрактори та блукаючі ділянки, а неперервна міра `μ = h* λ` є єдиною інваріантною мірою.

Анрі Пуанкаре припустив, що будь-який безнеперервний гомеоморфізм із ірраціональним числом обертання є топологічно спряженим до повороту. Проте виявилося, що для загального класу лише неперервних або один раз диференційовних відображень це припущення є хибним.

Детальніше про історію формування концепції числа обертання та дослідження Пуанкаре можна прочитати в [історичному нарисі](book:physics/denjoy-theorem/hist-denjoy.md).

## Контрприклад Данжуа: $C^1$-гладкість та блукаючі інтервали

У 1932 році Арно Денжуа спростував гіпотезу Пуанкаре у загальному вигляді, побудувавши знаменитий контрприклад: строго зростаючий диффеоморфізм кола `f ∈ C¹(S¹)` з ірраціональним числом обертання `ρ(f) = α`, який **не є** топологічно спряженим до жорсткого повороту `R_α`.

Замість того, щоб мати орбіти, щільні по всьому колу `S¹`, цей диффеоморфізм розбиває фазовий простір кола на два інваріантні класи підмножин:

```
S¹ = K ∪ (⋃_{n ∈ ℤ} I_n)
```

де `I_0 = (a, b) ⊂ S¹` — відкритий інтервал деякої додатної довжини `|I_0| = b - a > 0`, а `I_n = fⁿ(I_0)` — його послідовні прямі та обернені образи при ітераціях відображення `f`. Побудований Денжуа диффеоморфізм гарантує виконання двох критичних властивостей для цієї родини інтервалів:

1. **Попарна диз'юнктність (відсутність перекриття образів)**:

```
I_n ∩ I_m = ∅            [для всіх цілих n ≠ m]
```

2. **Збіжність суми довжин усього сімейства**:

```
∑_{n = -∞}^{∞} |I_n| ≤ 1 < ∞      [сума довжин усіх образів не перевищує довжину кола]
```

Відкритий інтервал `I_0`, усі послідовні образи якого при ітераціях `fⁿ(I_0)` є попарно диз'юнктними, називається **блукаючим інтервалом** (wandering interval).

Множина `K = S¹ \ (⋃_{n ∈ ℤ} I_n)`, яка залишається після видалення з кола всіх блукаючих інтервалів `I_n`, володіє унікальними топологічними властивостями:
- Вона є замкненою, доскональною (не містить ізольованих точок) та ніде не щільною в `S¹`.
- Множина `K` є фрактальною множиною типу множини Кантора з нульовою або додатною мірою Лебега.

Динамічна поведінка точок під дією відображення `f` у наявності блукаючого інтервалу повністю руйнує класичну картину квазіперіодичного руху:
- Орбіта будь-якої точки `x ∈ K` є щільною всередині самої множини `K`, але **не є щільною** на всьому колі `S¹`, оскільки вона повністю оминає всі відкриті інтервали `I_n`.
- Будь-який відкритий блукаючий інтервал `I_0` при `n → ±∞` асимптотично стискається, а його точки прямують до межі канторівської множини `K`.

Таким чином, канторівська множина `K` виконує роль виродженого фрактального атрактора системи, а блукаючі інтервали `I_n` утворюють басейн притягання. Оскільки для жорсткого повороту `R_α` будь-яка орбіта є щільною на всьому колі `S¹`, наявність блукаючого інтервалу створює топологічний перешкоду: не існує жодного безнеперервного гомеоморфізму `h`, який міг би спрягти відображення `f` з чистим поворотом `R_α`.

У чому ж полягає аналітична причина виникнення такого дивного ефекту у класі `C¹`? Денжуа детально дослідив побудоване ним відображення і виявив, що хоч похідна `f'(x)` є неперервною функцією на всьому колі (`f ∈ C¹`), її логарифм `log f'(x)` має **безмежну варіацію** (infinite total variation):

```
Var(log f') = sup ∑_{i=1}^{m} | log f'(x_i) - log f'(x_{i-1}) | = ∞
```

Тобто похідна `f'(x)` здійснює нескінченну кількість коливань зі зростаючою амплітудою або надто повільним згасанням при наближенні до кінців блукаючих інтервалів. Саме відсутність обмеженої варіації дозволяє інтервалам `I_n` стискатися з нерівномірною швидкістю, забезпечуючи збіжність ряду їхніх довжин.

Якщо ж на похідну відображення накласти вимогу обмеженої варіації, картина змінюється кардинально.

## Формулювання та сутність теореми Данжуа

Теорема Данжуа встановлює точну аналітичну межу гладкості, за якої зародження блукаючих інтервалів є математично неможливим, а топологічна спряженість до жорсткого повороту є повністю guaranteed.

> **Теорема Данжуа (1932):**
> Нехай `f: S¹ → S¹` — диффеоморфізм кола, який зберігає орієнтацію, з ірраціональним числом обертання `ρ(f) = α ∉ ℚ`. Якщо логарифм його похідної `log f'` має обмежену варіацію на колі `S¹`:
>
> ```
> Var(log f') = V < ∞
> ```
>
> то відображення `f` є топологічно спряженим до жорсткого повороту `R_α(θ) = θ + α (mod 1)`. Тобто існує гомеоморфізм `h: S¹ → S¹`, такий що `h ∘ f = R_α ∘ h`.

Оскільки для будь-якої функції `f` із класу `C²(S¹)` похідна `f''(x)` є неперервною та обмеженою, логарифм похідної `log f'(x)` має неперервну похідну `f''(x) / f'(x)`, а отже його варіація обчислюється звичайним інтегралом і є строго скінченною:

```
Var(log f') = ∫_0¹ | (log f'(x))' | dx = ∫_0¹ | f''(x) / f'(x) | dx < ∞
```

Те ж саме справджується для ширшого класу відображень `C¹⁺ᵃ(S¹)` (похідна задовольняє умову Гьольдера з показником `α > 0`). Звідси негайно випливають два фундаментальні наслідки теореми Данжуа для фізики та механіки:

1. **Достатність `C²`-гладкості**: Будь-який `C²`-диффеоморфізм кола з ірраціональним числом обертання є топологічно спряженим до чистого повороту.
2. **Абсолютна відсутність блукаючих інтервалів**: Для `C²`-диффеоморфізмів з ірраціональним числом обертання на колі `S¹` не існує жодного блукаючого інтервалу. Усі орбіти без винятку є всюди щільними на `S¹`.

Крім того, оскільки спряження `h` переносить інваріантну міру Лебега `λ` з жорсткого повороту на відображення `f`, міра `μ = h* λ` є єдиною інваріантною ймовірнісною мірою для `f`. Це означає, що будь-який `C²`-диффеоморфізм з ірраціональним числом обертання є **строго ергодичним**.

Строге математичне виведення відсутності блукаючих інтервалів та детальні формули наведено в [математичному виведенні](book:physics/denjoy-theorem/math-denjoy-proof.md).

## Аналітичний механізм: Лема Данжуа про спотворення

Фундаментальним інструментом доведення теореми Данжуа є точна оцінка того, як похідна складного відображення `fⁿ(x)` контролюється варіацією `Var(log f')`. За ланцюговим правилом диференціювання, похідна `n`-ї ітерації відображення дорівнює добутку похідних уздовж траєкторії:

```
(fⁿ)'(x) = ∏_{k=0}^{n-1} f'(f^k(x))
```

Логарифмуючи цей добуток, ми переходимо від добутку до арифметичної суми значень функції `log f'` у точках орбіти:

```
log (fⁿ)'(x) = ∑_{k=0}^{n-1} log f'(f^k(x))
```

Для аналізу цієї суми використовуються арифметичні властивості ірраціонального числа обертання `α`. Будь-яке ірраціональне число `α` розкладається у нескінченний ланцюговий дріб (continued fraction):

```
α = a_0 + 1 / (a_1 + 1 / (a_2 + ...))
```

Послідовні підхідні дроби `p_n / q_n` дають найкращі раціональні наближення до `α`. Знаменники `q_n` задовольняють рекурентне співвідношення `q_{n+1} = a_{n+1} q_n + q_{n-1}` і ростуть як мінімум як послідовність Фібоначчі.

Головна геометрична властивість знаменників `q_n` полягає у тому, що точки орбіти `{x, f(x), f²(x), ..., f^{q_n - 1}(x)}` розміщуються на колі в такому порядку, що вони розбивають коло `S¹` на `q_n` підінтервалів, причому жодна точка не потрапляє всередину сусідніх інтервалів (теорема про три відстані).

Якщо ми розглянемо дві довільні точки `x, y ∈ S¹` і порівняємо похідні `q_n`-ї ітерації в цих точках, то логарифм їхнього відношення дорівнює:

```
log (f^{q_n}')(x) - log (f^{q_n}')(y) = ∑_{k=0}^{q_n-1} ( log f'(f^k(x)) - log f'(f^k(y)) )
```

Оскільки інтервали між точками `f^k(x)` та `f^k(y)` при `k = 0, 1, ..., q_n - 1` покривають коло `S¹` щонайбільше двічі, модуль суми різниць значень `log f'` не може перевищувати повну варіацію цієї функції по всьому колу:

```
| log (f^{q_n}')(x) - log (f^{q_n}')(y) | ≤ Var(log f') = V      [Лема Данжуа про спотворення]
```

Переходячи від логарифмів до експоненти, ми отримуємо знамениту **Нерівність Данжуа про спотворення** (Denjoy Distortion Inequality):

```
exp(-V) ≤ (f^{q_n}')(x) / (f^{q_n}')(y) ≤ exp(V)
```

Ця нерівність має фундаментальне значення: вона стверджує, що для знаменників `q_n` похідна `q_n`-ї ітерації `(f^{q_n}')(x)` в будь-якій точці кола є пропорційною похідній у будь-якій іншій точці `y` з універсальним коефіцієнтом спотворення `exp(V)`, який **не залежить від номера ітерації `q_n`**!

Тепер ми можемо простежити остаточний аналітичний доказ відсутності блукаючого інтервалу `I_0`. Припустимо від зворотного, що блукаючий інтервал `I_0` існує і має додатну довжину `|I_0| > 0`. Розглянемо його образи `I_k = f^k(I_0)`.

За теоремою Лагранжа про середнє значення, для кожного `q_n` усередині інтервалу `I_0` існує принаймні одна точка `y_n ∈ I_0`, така що довжина `q_n`-го образу дорівнює:

```
|I_{q_n}| = |f^{q_n}(I_0)| = (f^{q_n}')(y_n) · |I_0|
```

З іншого боку, за теоремою про середнє значення для всієї довжини кола `1 = ∫_0¹ (f^{q_n}')(x) dx`, на колі обов'язково існує точка `x_n ∈ S¹`, у якій похідна дорівнює точно одиниці: `(f^{q_n}')(x_n) = 1`.

Застосовуючи нерівність Данжуа для пари точок `y_n` та `x_n`, отримуємо нижню оцінку для похідної у точці `y_n`:

```
(f^{q_n}')(y_n) ≥ exp(-V) · (f^{q_n}')(x_n) = exp(-V) · 1 = exp(-V)
```

Підставляючи цю оцінку у вираз для довжини образу `|I_{q_n}|`, маємо:

```
|I_{q_n}| = (f^{q_n}')(y_n) · |I_0| ≥ exp(-V) · |I_0|
```

Отриманий результат є вражаючим: довжина `q_n`-го образу блукаючого інтервалу **не може падати до нуля**! Для всіх знаменників ланцюгового дробу `q_n` довжина `|I_{q_n}|` залишається строго більшою за додатне число `exp(-V) · |I_0|`.

Проте всі образи `I_k` є попарно диз'юнктними інтервалами, що лежать всередині кола одиничної довжини. Отже, нескінченний ряд з їхніх довжин мусить бути збіжним:

```
∑_{k=0}^{∞} |I_k| ≤ 1 < ∞
```

Згідно з необхідною ознакою збіжності числового ряду, границя його загального члена мусить дорівнювати нулю:

```
lim_{k → ∞} |I_k| = 0
```

Отримано явну і нездоланну суперечність: границя послідовності довжин `|I_{q_n}|` має дорівнювати нулю, але нерівність Данжуа забороняє їй опускатися нижче додатного числа `exp(-V) · |I_0|`. Єдиний логічний вихід із цієї суперечності — початкове припущення про існування блукаючого інтервалу додатної довжини було хибним. Отже, `|I_0| = 0`, і блукаючих інтервалів для `C²`-відображень не існує!

У контрприкладі Данжуа (`f ∈ C¹`) варіація `V = ∞`, тому нижня межа `exp(-V) = 0`, і суперечності не виникає: образи блукаючого інтервалу можуть стискатися до нуля як завгодно швидко, забезпечуючи збіжність ряду довжин.

## Ергодичні властивості та унікальність інваріантної міри

Найважливішим наслідком теореми Данжуа для статистичної механіки та теорії динамічних систем є **строга ергодичність** гладких кругових відображень з ірраціональним числом обертання.

Для будь-якої динамічної системи інваріантна міра `μ` описує довгостроковий розподіл ймовірності перебування фазової точки в різних областях фазового простору. Міра `μ` називається інваріантною відносно відображення `f`, якщо для будь-якої вимірної множини `A ⊂ S¹` виконано:

```
μ(f⁻¹(A)) = μ(A)                [умова інваріантності міри]
```

Оскільки теорема Данжуа гарантує існування топологічного спряження `h: S¹ → S¹`, таке що `h ∘ f = R_α ∘ h`, ми можемо перенести єдину інваріантну міру Лебега `λ` з жорсткого повороту на відображення `f` за допомогою операції переносу міри (pushforward measure):

```
μ = h* λ,   тобто   μ(A) = λ(h(A))
```

Оскільки `h` є топологічним гомеоморфізмом (взаємно однозначним та неперервним у формі `h` та `h⁻¹`), побудована міра `μ` володіє фундаментальними фізичними властивостями:

1. **Неатомність та суцільна неперервність**: Міра не містить точкових мас (тобто `μ({x}) = 0` для будь-якої окремої точки `x ∈ S¹`).
2. **Строга додатність на відкритих множинах**: Для будь-якого відкритого інтервалу `I ⊂ S¹` додатної довжини його міра є строго додатною: `μ(I) > 0`.
3. **Єдиність інваріантної міри**: На колі `S¹` не існує жодної іншої інваріантної ймовірнісної міри для відображення `f`.

З єдиності інваріантної міри (строгої ергодичності) за Ергодичною теоремою Біркгофа випливає, що для будь-якої неперервної фізичної спостережуваної величини `φ ∈ C(S¹)` часове середнє вздовж орбіти **будь-якої** початкової точки `x_0 ∈ S¹` збігається до однакового просторового середнього за мірою `μ`:

```
lim_{N → ∞} (1 / N) ∑_{k=0}^{N-1} φ(f^k(x_0)) = ∫_{S¹} φ(x) dμ(x)
```

Це означає, що у гладких систем із ірраціональним числом обертання відсутня чутливість до початкових умов у статистичному сенсі: незалежно від того, з якої точки `x_0` починається рух, часові характеристики системи в границі прямують до єдиного стаціонарного розподілу.

## Фізичні застосування: Від нелінійних осциляторів до хаосу

У нелінійній механіці та фізиці коливань теорема Данжуа відіграє роль фундаментального гаранта регулярності: вона гарантує, що гладкі фізичні системи без дисипативного руйнування монотонності не можуть демонструвати спонтанного утворення фрактальних атракторів у квазіперіодичному режимі.

Класичною модельною системою є синус-кругове відображення Арнольда (Arnold circle map), яке виникає при описі збуреного нелінійного осцилятора:

```
θₙ₊₁ = f(θₙ) = θₙ + Ω - (K / 2π) · sin(2π θₙ) (mod 1)
```

де `Ω` — несбурене частотне відношення (bare winding number), а `K ≥ 0` — параметр зв'язку або амплітуда зовнішнього збурення.

Динаміка цієї системи залежить від величини параметра `K`:

1. **Субкритичний режим (`0 ≤ K < 1`)**:
   Похідна відображення дорівнює `f'(θ) = 1 - K cos(2π θ)`. Оскільки `K < 1`, похідна є строго додатною для всіх `θ`: `f'(θ) ≥ 1 - K > 0`. Відображення `f` є строго зростаючим `C^∞`-диффеоморфізмом кола. Його похідна неперервна й обмежена, тому `Var(log f') < ∞`. За теоремою Данжуа, для будь-якого ірраціонального числа обертання `ρ(f) = α` динаміка є строго спряженою до жорсткого повороту. Траєкторії квазіперіодичного руху повністю покривають фазовий простір, а фрактальні атрактори повністю відсутні.

2. **Критична межа (`K = 1`)**:
   У точці `θ = 0` похідна перетворюється на нуль: `f'(0) = 1 - 1 = 0`. Відображення перестає бути диффеоморфізмом, утворюючи кубічну критичну точку. У цей момент умова теореми Данжуа про гладкість оберненого відображення порушується (`log f'` стає необмеженим у точці нуля). Фазовий простір зазнає топологічної перебудови: виникає фрактальна драбина диявола (Devil's staircase), а об'єм язиків Арнольда в просторі параметрів заповнює повну міру.

3. **Надкритичний режим (`K > 1`)**:
   Відображення втрачає строгу монотонність (з'являється складка), виникає локальне стискання та розтягнення фазового об'єму і відбувається перехід до детермінованого хаосу через руйнування інваріантних торій.

Аналогічні явища спостерігаються в описі джозефсонівських переходів у надпровідності. Рівняння надпровідного переходу під дією змінного струму виражається рівнянням Resistively Shunted Junction (RSJ):

```
(ħ / 2eR) · dϕ/dt + I_c sin(ϕ) = I_0 + I_1 cos(ω t)
```

Перехід від цього диференціального рівняння до відображення Poincaré на перетині періоду `2π / ω` дає відображення кола, гладкість якого задовольняє умови теореми Данжуа при помірних струмах `I_1`. Це пояснює високу стабільність і відсутність хаотичних шумів у ступенях нальт-амперних характеристик (сходинки Шапіро).

Крім того, поняття нерівності спотворення Данжуа відіграє вирішальну роль у квантовій фізиці конденсованого стану, зокрема в моделі Обрі-Андре (Aubry-André model) для одноточкового транспорту електронів у квазіперіодичних кристалічних полях. Спотворення похідних регулює локалізацію та делокалізацію електронних хвильових функцій при переході між металевою та діелектричною фазами.

Також теорема Данжуа використовується у радіотехніці при розрахунку систем фазового автопідстроювання частоти (ФАПЧ / PLL). Вона гарантує, що при квазіперіодичній розбудові частоти у фазовому детекторі не виникає непередбачуваного фрактального тремтіння фази (phase jitter).

## Чисельна діагностика блукаючих інтервалів у експериментах

На практиці під час чисельного симулювання або обробки експериментальних часових рядів нелінійних осциляторів постає завдання чисельної діагностики стану системи. Як відрізнити регулярну гладку квазіперіодичність за Данжуа від фрактального канторівського атрактора?

1. **Аналіз спектра спотворення похідних**:
   Обчислюється послідовність логарифмів спотворення `L(q_k) = log(max (f^{q_k}') / min (f^{q_k}'))` для знаменників `q_k` ланцюгового дробу. Якщо `L(q_k)` виходить на стаціонарне плато при `q_k → ∞`, система є гладкою `C²` і перебуває у режимі Данжуа. Якщо `L(q_k)` росте пропорційно `log q_k` або лінійно по `q_k`, у системі виник блукаючий інтервал або точка втрати гладкості.

2. **Обчислення фрактальної розмірності інваріантного сету**:
   Для гладких відображень за теоремою Данжуа носій інваріантної міри `K = S¹` має топологічну та хаусдорфову розмірність `dim_H(K) = 1`. У разі виникнення блукаючих інтервалів (контрприклад Данжуа) хаусдорфова розмірність канторівського атрактора падає строго нижче одиниці: `0 < dim_H(K) < 1`.

3. **Перевірка відсутності інтервальних дірок на рекурентних діаграмах**:
   Побудова графіків повернення (recurrence plots) для орбіти точок дозволяє візуально виявити наявність блукаючих смуг. Відсутність порожніх смуг гарантує всюди щільність орбіти.

Крім того, при чисельному аналізі фізичних систем слід враховувати вплив чисельного шуму. Малий чисельний шум з амплітудою `σ` може згладжувати фрактальну структуру блукаючих інтервалів, імітуючи гладку інваріантну міру. Для розрізнення цих ефектів застосовують масштабувальний аналіз залежності спотворення від амплітуди шуму `L(q_k, σ)`.

У високоточних системах обчислювальної механіки аналіз спотворення похідних Данжуа дає змогу будувати карти стабільності фазових торій для канонічних змінних "дія-кут", підтверджуючи відсутність квантового хаосу в низькоенергетичних фазових станах.

> 🔧 **Навіщо це у розробці та фізичному моделюванні.**
> При чисельному розрахунку нелінійних коливальних систем (мережі генераторів, лазери з оптичним зв'язком, фазові системи автоматичного підстроювання частоти ФАПЧ) виявлення фрактальних атракторів чи блукаючих інтервалів у субкритичному режимі `K < 1` свідчить про наявність обчислювальних дефектів чисельної схеми (наприклад, накопичення помилок дискретизації або втрату монотонності через недостатню точність крок інтегрування). Теорема Данжуа стверджує, що фізично коректна модель із гладким потенціалом не може мати блукаючих інтервалів доти, доки відображення залишається строго монотонним `C²`-диффеоморфізмом.

Алгоритми обчислення числа обертання, перевірки нерівності Данжуа та моделювання контрприкладу на мовах Python, C та C++ детально розібрано в [чисельному проекті](book:physics/denjoy-theorem/proj-circle-map-denjoy.md). Специфікацію виробничої C/C++ бібліотеки для аналізу кругових відображень наведено в [довіднику інтерфейсу](book:physics/denjoy-theorem/api-denjoy-map.md).

## Гладкість спряження: Теореми Германа та Йоккоза

Теорема Данжуа гарантує існування **неперервного** спряження `h` (тобто топологічного гомеоморфізму). Проте для застосувань у теоретичній фізиці та небесній механіці вкрайважливо знати, чи є ця заміна координат гладкою (`h ∈ C^∞` або `h ∈ Cᵏ`). Гладке спряження означає, що за допомогою гладкої заміни змінних `θ = h(x)` складне нелінійне диференціальне рівняння можна перетворити на просте лінійне рівняння зі сталими коефіцієнтами.

Виявилося, що гладкість спряження `h` залежить не лише від гладкості самого відображення `f`, але й від того, наскільки добре ірраціональне число обертання `α` наближається раціональними дробами (проблема малих дільників).

У 1979 році Майкл Герман (Michael Herman) здобув революційний результат, довівши теорему про гладку спряженість:

> **Теорема Германа (1979):**
> Якщо `f ∈ C^∞(S¹)` є диффеоморфізмом кола з ірраціональним числом обертання `α`, яке задовольняє діофантову умову (Diophantine condition):
>
> ```
> | α - p / q | > C / q²⁺ᵉ      [для всіх p ∈ ℤ, q ∈ ℕ та деяких сталих C > 0, ε > 0]
> ```
>
> то спряжуючий гомеоморфізм `h` також є нескінченно гладким диффеоморфізмом класу `C^∞`.

Згодом Жан-Крістоф Йоккоз (Jean-Christophe Yoccoz) у 1984 році поширив результат Германа на ширший клас ірраціональних чисел, які задовольняють так звану умову Брюно (Brjuno condition) на ріст знаменників `q_n` ланцюгового дробу:

```
∑_{n=0}^{∞} (log q_{n+1}) / q_n < ∞      [умова Брюно]
```

Йоккоз довів, що умова Брюно є не лише достатньою, але й строго необхідною для існування `C^∞`-спряженості для всіх `C^∞`-диффеоморфізмів. За цей фундаментальний внесок у теорію динамічних систем Йоккоз у 1994 році був нагороджений найвищою математичною нагородою — Філдсівською медаллю.

Результати Германа та Йоккоза показують, що теорема Данжуа є першою і найважливішою сходинкою в ієрархії гладкості динамічних систем:
- **`C¹` без обмеженої варіації**: Можливі блукаючі інтервали та фрактальні канторівські атрактори (контрприклад Данжуа).
- **`C²` або `C¹⁺ᵃ`**: Відсутність блукаючих інтервалів, існування топологічного спряження `h ∈ C⁰` (Теорема Данжуа).
- **`C^∞` з діофантовим чи брюнівським `α`**: Існування нескінченно гладкого спряження `h ∈ C^∞` (Теореми Германа та Йоккоза).

Ця ієрархія слугує одновимірним аналогом теорії КАМ (Колмогорова-Арнольда-Мозера) у багатовимірній гамільтоновій механіці, яка пояснює вікову стійкість сонячної системи та інваріантних магнітних поверхонь у термоядерних реакторах (токамаках). Таким чином, теорема Данжуа не лише розв'язала тривалу геометричну загадку Анрі Пуанкаре, а й створила фундаментальний міст між чистою топологією, функціональним аналізом та сучасними фізичними теоріями складних нелінійних коливань.
