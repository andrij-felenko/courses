# 🧮 Від двох рухів до всіх формул: парабола, час, висота, дальність і правило 45°

Уся картина польоту тримається на одному спостереженні: тіло робить одразу два незалежні рухи — рівномірно котиться вбік і вільно падає вниз. Це красиво, але картинка сама по собі ще не скаже, за скільки секунд м'яч упаде й на скільки метрів. Щоб дістати числа, картину треба перекласти на алгебру. І тут чекає приємна несподіванка: усе — форма дуги, час у повітрі, висота, дальність, магічні 45° і чому 30° б'є на ту саму відстань, що й 60°, — виросте буквально з **двох рядків** рівнянь. Не запам'ятаємо формули, а виростимо їх на очах, одну з одної.

## Два рядки, з яких усе випливає

Поставмо початок координат туди, звідки кидаємо, вісь x — уперед по землі, вісь y — угору. Тіло вилітає зі швидкістю v₀ під кутом α до горизонту. Перше, що треба зробити, — [розкласти цю швидкість](book:math/vector-components) на дві осі, бо далі кожна ось житиме окремо:

```
vₓ = v₀ · cos α     (уперед)
v_y = v₀ · sin α     (угору)
```

Тепер два незалежні рухи. **Уперед** на тіло не діє жодна сила — рука позаду, торкання немає, — тож за інерцією швидкість vₓ лишається сталою, і пройдена вбік відстань росте рівно з часом. **Угору** діє тяжіння зі сталим прискоренням g: тіло стартує вгору зі швидкістю v_y, але це те саме, що підкинути його й дати [вільно падати](book:physics/free-fall) — підйом за інерцією мінус провал ½g·t². Записуємо, де опиниться тіло через час t:

```
x(t) = v₀·cos α · t
y(t) = v₀·sin α · t − ½·g·t²
```

Оці два рядки — повний опис польоту. Час t тут — прихований ляльковод: він тягне тіло і вбік (лінійно), і вгору-вниз (квадратично), а ми бачимо лише слід, який лишає ця пара. Зверніть увагу, чого в рядках немає: **маси**. Ані vₓ, ані v_y, ані g про масу не знають — тому важкий камінь і легкий, кинуті однаково, малюють ту саму дугу. Далі — самі лише наслідки цих двох рядків.

## Викидаємо час — і проступає чиста форма

Час у двох рівняннях спільний. Якщо його вилучити, лишиться прямий зв'язок «висота від віддалі» — сама **форма** дуги, без згадки про те, коли тіло де було. З першого рядка час виражається миттєво:

```
t = x / (v₀·cos α)
```

Підставмо це замість t у другий рядок і акуратно спростимо два доданки по черзі:

```
y = v₀·sin α · [ x / (v₀·cos α) ] − ½·g · [ x / (v₀·cos α) ]²
```

Перший доданок: v₀ угорі й унизу скорочується, а sin α / cos α — це за означенням [тангенс](book:math/tangent-cotangent) кута:

```
v₀·sin α · x / (v₀·cos α) = x · (sin α / cos α) = x · tan α
```

Другий доданок: квадрат розкриває x² і кладе v₀²·cos²α у знаменник:

```
½·g · x² / (v₀²·cos²α) = ( g / (2·v₀²·cos²α) ) · x²
```

Складаємо, і ось рівняння траєкторії — висота як функція самої лише віддалі:

```
y = x·tan α − ( g / (2·v₀²·cos²α) ) · x²
```

Прочитаймо його. Перший доданок, x·tan α, — це пряма з нахилом tan α: рівно та лінія, вздовж якої тіло полетіло б, якби тяжіння вимкнули (нахил tan α — це і є напрям кидка). Від цієї прямої віднімається другий доданок — квадратичний провал, що росте як x². Пряма мінус квадрат, який усе дужче тягне донизу, — ось що згинає політ у дугу.

## Чому це парабола — і що ховає її вершина

Виведене рівняння має вигляд

```
y = A·x − B·x² ,     де A = tan α ,   B = g / (2·v₀²·cos²α)
```

При заданому кидку (фіксовані v₀, α, g) обидва коефіцієнти A і B — просто числа, обидва додатні. Крива, у якій y лінійно залежить від x і **мінус** квадратично від x², у математиці зветься **параболою** (гр. *parabolḗ* — прикладання), віткою донизу, бо коефіцієнт при x² від'ємний. Але замість того щоб просто назвати її, вичавимо з цього запису все, що він приховує, — доповнимо до повного квадрата:

```
y = −B·( x² − (A/B)·x )
  = −B·[ ( x − A/(2B) )² − A²/(4B²) ]
  = A²/(4B) − B·( x − A/(2B) )²
```

Останній рядок — парабола в найпрозорішому вигляді: від сталої A²/(4B) віднімається невід'ємний квадрат, що обертається на нуль рівно при x = A/(2B). Звідси одразу читаються дві ключові точки.

**Корені** (де y = 0, тобто де тіло на землі). Розкладемо вихідну форму: y = x·(A − B·x) = 0 дає два корені:

```
x = 0        — точка кидка
x = A/B      — точка падіння
```

Другий корінь — це і є **дальність**. Підставмо A і B:

```
R = A/B = tan α · 2·v₀²·cos²α / g = 2·v₀²·sin α·cos α / g
```

**Вершина** параболи — при x = A/(2B), тобто рівно посередині між коренями 0 і A/B. Це загальна властивість будь-якої параболи (вершина стоїть точно між коренями), і саме вона доводить **симетрію дуги** одним рядком: найвища точка польоту припадає рівно на середину дальності, на x = R/2. Висота цієї вершини — та сама стала A²/(4B):

```
H = A²/(4B) = tan²α · 2·v₀²·cos²α / (4g) = v₀²·sin²α / (2g)
```

Отже, саме́ доповнення до квадрата вже безкоштовно віддало нам і дальність (корені), і симетрію (вершина посередині), і висоту підйому (висота вершини) — усе з тих самих двох рядків.

![Траєкторія як парабола вниз y = A·x − B·x² з коренями в точці кидка (x=0) і точці падіння (x=R) та вершиною рівно посередині, при x=R/2, заввишки H](/book/physics/mechanics/projectile-motion/img/trajectory-parabola.svg)
*Траєкторія — многочлен другого степеня за x. Її корені — точка кидка (x = 0) і точка падіння (x = R); вершина стоїть рівно між ними, при x = R/2, на висоті H. Вершина посередині коренів і є доказ симетрії дуги: підйом дзеркальний до спуску.*

Тепер здобудемо ті самі три величини — час, висоту, дальність — ще й напряму, з руху по кожній осі, щоб побачити їхній фізичний зміст, а не лише алгебраїчний.

## Час польоту: усе вирішує вертикаль

Скільки тіло протримається в повітрі — питання **тільки до вертикалі**; убік воно котитиметься рівно стільки, скільки падатиме. Вертикальна швидкість щосекунди меншає на g:

```
v_y(t) = v₀·sin α − g·t
```

У найвищій точці тіло на мить перестає підійматися — вертикальна швидкість там нуль. Прирівнявши, дістаємо час підйому:

```
0 = v₀·sin α − g·t_підйом   →   t_підйом = v₀·sin α / g
```

А спуск — дзеркало підйому: вільне падіння з вершини триває рівно стільки ж, скільки тривав підйом. Тому повний час удвічі більший:

```
T = 2·v₀·sin α / g
```

Той самий результат випливе, якщо просто спитати рівняння y(t), коли тіло знову на землі (y = 0):

```
v₀·sin α · t − ½·g·t² = 0
t·( v₀·sin α − ½·g·t ) = 0   →   t = 0  (старт)   або   t = 2·v₀·sin α / g  (падіння)
```

Два корені за часом — це ті самі два корені за віддаллю з попереднього розділу, побачені з іншого боку: старт і падіння. Горизонтальна швидкість у цей рахунок не втрутилася ані разу — час у повітрі задає сама лише вертикальна складова.

## Висота підйому: три дороги до однієї формули

Висоту вершини ми вже дістали з параболи (H = v₀²·sin²α / 2g). Перевірмо її двома незалежними шляхами — збіг трьох машинерій і є найтвердіша порука, що формула правильна.

**Через час підйому.** Підставмо t_підйом = v₀·sin α / g у y(t):

```
H = v₀·sin α · (v₀·sin α / g) − ½·g·(v₀·sin α / g)²
  = (v₀·sin α)²/g − ½·(v₀·sin α)²/g = (v₀·sin α)² / (2g)
```

**Через енергію.** У вершині вертикальна швидкість зникла — уся кінетична енергія вертикального руху перейшла в потенціальну:

```
½·m·(v₀·sin α)² = m·g·H   →   H = (v₀·sin α)² / (2g)
```

Маса скорочується — знову жодного її сліду. Три дороги (парабола, кінематика, енергія) сходяться в одне:

```
H = (v₀·sin α)² / (2g)
```

Зверніть увагу на **квадрат** синуса: висота росте не з кутом, а з квадратом його синуса, тому вона надзвичайно чутлива до крутизни кидка. Подвойте вертикальну складову — і злетите вчетверо вище; саме тому крутий, «навісний» кидок закидає тіло так високо.

## Дальність: чому в ній подвоєний кут

Дальність — це проста річ: горизонтальна швидкість, помножена на час у повітрі. Обидва множники вже маємо:

```
R = vₓ · T = v₀·cos α · (2·v₀·sin α / g) = 2·v₀²·sin α·cos α / g
```

Тут спрацьовує [тригонометрична тотожність](book:math/trig-identities) подвоєного кута — 2·sin α·cos α — це рівно sin подвоєного кута:

```
2·sin α·cos α = sin 2α       →       R = v₀²·sin 2α / g
```

Звідки взявся подвоєний кут, видно з самої будови дальності. R — це **добуток двох суперників**, і обидва залежать від того самого кута: cos α каже, як швидко тіло посувається вперед, а sin α (через час T) — як довго воно висить у повітрі. Перемножити «швидкість уперед» на «час у повітрі» — це перемножити cos α на sin α, а подвоєний їхній добуток згортається в один-єдиний sin 2α. Уся залежність дальності від кута сховалася в цьому подвоєному синусі.

## Найдалі — рівно під 45°

У формулі R = v₀²·sin 2α / g при заданому кидку закріплене все, крім кута. Тож дальність тягне за собою єдиний множник — sin 2α. Синус найбільший (дорівнює одиниці), коли його аргумент дорівнює 90°:

```
sin 2α = max = 1   ⇔   2α = 90°   ⇔   α = 45°
R_макс = v₀² / g
```

Ось і вся відповідь на давнє гарматне питання: у порожнечі найдальший постріл — рівно під сорок п'ять градусів. Але чому саме посередині? Бо це — **перемир'я двох суперників**. Піднімаючи кут, ти виграєш час у повітрі (sin α росте), але програєш у швидкості вперед (cos α меншає); опускаючи — навпаки. Дальність — їхній добуток, і він досягає піку там, де виграш одного точно врівноважує програш другого, — на самій середині діапазону, під 45°.

Той самий висновок дає й формальний [пошук екстремуму](book:math/extrema): дальність максимальна там, де її похідна за кутом обертається на нуль.

```
dR/dα ∝ d(sin 2α)/dα = 2·cos 2α = 0   →   cos 2α = 0   →   2α = 90°   →   α = 45°
```

А що це саме максимум, а не мінімум, підтверджує друга похідна: −4·sin 2α при α = 45° дорівнює −4 < 0 — вітка справді дивиться вниз, це вершина.

![Три криві від кута α: cos α (швидкість уперед) спадає, sin α (час у повітрі) росте, а їхній подвоєний добуток sin 2α (дальність) сягає піку на 45°, де cos α і sin α зрівнюються](/book/physics/mechanics/projectile-motion/img/range-factors.svg)
*Дальність ∝ sin 2α = 2·sin α·cos α — добуток двох суперників. cos α (швидкість уперед) падає з кутом, sin α (час у повітрі) росте; їхній подвоєний добуток піднімається до одиниці рівно там, де вони зрівнюються, — під 45°. Праворуч і ліворуч від 45° один множник обвалюється швидше, ніж росте другий, і дальність меншає.*

## Чому 30° і 60° падають в одну точку

Із того самого sin 2α випливає гарна симетрія. Синус не розрізняє кута й того, що доповнює його до 90°, бо синус кута дорівнює синусу його доповнення до 180°:

```
sin 2α = sin (180° − 2α) = sin ( 2·(90° − α) )
```

Праворуч стоїть дальність для кута (90° − α). Отже, **кут α і кут (90° − α) дають однакову дальність**: 30° і 60°, 15° і 75°, і будь-яка інша пара, що сумується в прямий кут.

Є й прозоріший спосіб це побачити, без тотожностей. Запишімо дальність через самі складові:

```
R = 2 · (v₀·cos α) · (v₀·sin α) / g = 2 · vₓ · v_y / g
```

Заміна α на (90° − α) міняє cos α на sin α і навпаки — тобто просто **міняє місцями vₓ і v_y**. А добуток vₓ·v_y від перестановки множників не змінюється. Тому й дальність не змінюється: два кидки різні, а їхня дальність тотожна, бо вона тримається на добутку, а не на кожній складовій окремо.

**Приклад (30° проти 60°).** М'яч кидають зі швидкістю v₀ = 20 м/с; порівняймо два кидки (g = 9.81 м/с²).

```
                 30°                          60°
vₓ = 20·cos α    20·0.866 = 17.32 м/с         20·0.500 = 10.00 м/с
v_y = 20·sin α   20·0.500 = 10.00 м/с         20·0.866 = 17.32 м/с

T = 2·v_y/g      2·10.00/9.81 = 2.04 с        2·17.32/9.81 = 3.53 с
H = v_y²/(2g)    100/19.62   = 5.10 м         300/19.62   = 15.29 м
R = 2·vₓ·v_y/g   2·173.2/9.81 = 35.31 м       2·173.2/9.81 = 35.31 м
```

Дальність збіглася до сантиметра, а от політ — зовсім різний: під 30° м'яч мчить полого, недовго й низько; під 60° — злітає втричі вище й висить майже вдвічі довше. Механізм видно в самому рядку: vₓ і v_y між двома кидками помінялися значеннями (17.32 ↔ 10.00), а їхній добуток лишився той самий — 173.2, — тому й R однакова. Це та сама перестановка cos ↔ sin, тепер у числах.

## Коли кидаємо з висоти

Уся симетрія доти трималася на тому, що тіло падає на той самий рівень, з якого злетіло: підйом дзеркалив спуск. Піднімімо точку кидка на висоту h над місцем падіння — скелю, дах, руку над землею — і дзеркало розіб'ється. Вертикальна координата, відлічена від землі, тепер стартує з h:

```
y(t) = h + v₀·sin α · t − ½·g·t²
```

Падіння — коли y = 0. Це квадратне рівняння за часом:

```
½·g·t² − v₀·sin α · t − h = 0
```

Із двох його коренів фізичний — додатний (від'ємний був би «до кидка»):

```
t* = [ v₀·sin α + √( (v₀·sin α)² + 2·g·h ) ] / g
```

Підкореневий доданок 2gh — це весь внесок висоти: він додає до часу польоту зайвий шматок понад симетричний випадок, і тіло встигає пролетіти вбік далі. Дальність — знову горизонтальна швидкість на цей час:

```
R = v₀·cos α · t*
```

А що з найкращим кутом? Він **сповзає нижче 45°**. Логіка проста: висота дарує додатковий час падіння задарма, незалежно від того, як ми кинули, — тож вигідніше витратити більше швидкості на рух уперед (cos α), а не на набір власної висоти (sin α), яку скеля й так забезпечить. Точний оптимум (його можна дістати, прирівнявши dR/dα до нуля) виходить напрочуд компактним:

```
α_опт = arctan( v₀ / √( v₀² + 2·g·h ) )
R_макс = (v₀/g) · √( v₀² + 2·g·h )
```

Перевіримо на краях. При h = 0 корінь дорівнює v₀, arctan(1) = 45°, а R_макс = v₀²/g — рівно рівнинний випадок. При дуже великій висоті (h → ∞) кут прямує до нуля: з високої вежі найдалі кидати майже горизонтально, бо часу впасти й так удосталь.

**Приклад (кидок зі скелі).** v₀ = 20 м/с, висота h = 25 м, g = 9.81 м/с².

```
√(v₀² + 2gh) = √(400 + 2·9.81·25) = √890.5 = 29.84 м/с

α_опт = arctan(20 / 29.84) = arctan(0.670) = 33.8°
R_макс = (20/9.81)·29.84 = 60.84 м
```

Перевіримо прямим рахунком під цим кутом: v_y = 20·sin 33.8° = 11.13 м/с, vₓ = 20·cos 33.8° = 16.61 м/с.

```
t* = [11.13 + √(11.13² + 2·9.81·25)] / 9.81 = [11.13 + 24.79] / 9.81 = 3.66 с
R  = 16.61 · 3.66 = 60.8 м
```

Зі скелі найдалі летить кинуте не під 45°, а десь під 34°, і залітає на 60.8 м — проти 40.8 м (це v₀²/g), на які той самий м'яч сягнув би з рівнини під 45°. Двадцять метрів висоти купують двадцять метрів дальності й опускають найкращий кут на одинадцять градусів.

## Що звідки взялося

Усе виросло з двох рядків — x(t) = v₀·cos α·t і y(t) = v₀·sin α·t − ½g·t². Вилучивши з них час, ми дістали чисту форму польоту — параболу y = A·x − B·x², — а сама́ її алгебра безкоштовно віддала три числа: корені 0 і R (дальність R = v₀²·sin 2α/g), вершину рівно посередині коренів, при x = R/2 (це й є симетрія дуги), заввишки H = (v₀·sin α)²/2g. Час у повітрі T = 2·v₀·sin α/g задала сама вертикаль — горизонтальний рух до нього байдужий. Дальність виявилася добутком «швидкості вперед» на «час у повітрі», cos α на sin α, і цей подвоєний добуток згорнувся в один sin 2α — звідси єдиний пік під 45° (перемир'я двох суперників) і рівність доповняльних кутів (перестановка cos ↔ sin лишає добуток недоторканим). Підніміть кидок на висоту — і дзеркало розіб'ється: оптимум сповзе нижче 45°, а дальність підросте на підкореневий внесок 2gh. Жодну з цих формул не довелося запам'ятовувати чи звідкись брати — усі вони весь час сиділи всередині тих двох рядків, а алгебра лише зробила їх видимими.
