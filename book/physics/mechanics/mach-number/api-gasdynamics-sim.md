# 📋 Інтерфейс газодинамічних розрахунків атмосфери та чисел Маха

Цей документ є повним довідковим документом та технічною специфікацією програмного інтерфейсу (API), структур даних, фізичних констант та lookup-таблиць газодинамічних функцій. Інтерфейс призначений для реалізації обчислювальних ядер у польотних контролерах, аеродинамічних симуляторах, бортових обчислювачах повітряних сигналів (Air Data Computer) та програмних комплексах чисельного моделювання газодинаміки (CFD).

Запропонована специфікація забезпечує суворе дотримання фізичних законів стисливого потоку ідеального газу, описує математичні межі застосовності алгоритмів, гарантує сумісність на рівні двоплинного ABI (Application Binary Interface) для мов C та C++, а також визначає уніфіковані коди статусу та поведінку пристроїв вимірювання за різних режимів польоту.

---

## 1. Фундаментальні фізичні константи та термодинамічні властивості газів

Модуль газодинаміки підтримує розрахунки як для сухого земного повітря в рамках Міжнародної стандартної атмосфери (ISA), так і для інших технічних газів чи їх сумішей (наприклад, у соплах ракетних двигунів чи газових турбінах). Для кожного середовища специфікація визначає три базові термодинамічні константи: показник адіабати `γ`, молярну масу `M_mol` та питому газову сталу `R`.

Питома газова стала `R` пов'язана з універсальною газовою сталою `R_u = 8314.462618 Дж/(кмоль·К)` співвідношенням:

```
R = R_u / M_mol
```

Швидкість звуку за нормальних термодинамічних умов (`T₀ = 293.15 K`, `p₀ = 101325 Pa`) обчислюється за формулою Лапласа `a₀ = √(γ · R · T₀)`.

| Назва газу | Хімічна формула | Молярна маса `M_mol` (кг/кмоль) | Показник адіабати `γ` | Питома газова стала `R` (Дж/(кг·К)) | Швидкість звуку `a₀` при 20 °C (м/с) | Призначення / Галузь застосування |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| Сухе повітря (ISA) | — | 28.9647 | 1.400 | 287.058 | 343.21 | Стандартна авіаційна атмосфера ICAO |
| Азот | N₂ | 28.0134 | 1.400 | 296.800 | 349.10 | Основна компонента атмосфери, чистий двоатомний газ |
| Кисень | O₂ | 31.9988 | 1.396 | 259.840 | 325.85 | Окиснювач аеродинамічних і трубних установок |
| Гелій | He | 4.0026 | 1.667 | 2077.100 | 1007.40 | Інертний одноатомний газ, висока швидкість звуку |
| Вуглекислий газ | CO₂ | 44.0095 | 1.289 | 188.920 | 267.15 | Продукти згоряння, атмосфера Марса і Венери |
| Водень | H₂ | 2.0158 | 1.405 | 4124.200 | 1304.80 | Легкий газ, водневі ракетні двигуни |
| Метан | CH₄ | 16.0425 | 1.304 | 518.280 | 445.30 | Перспективне ракетне паливо (LCH4) |

Усі обчислювальні процедури API використовують показник адіабати як змінний параметр, що дозволяє виконувати розрахунки для довільних газових сумішей без зміни структури викликів.

## 2. Модель Міжнародної стандартної атмосфери ISA (ICAO Doc 7488)

Для забезпечення єдності вимірювань висоти та швидкості в авіації API імплементує офіційну модель Міжнародної стандартної атмосфери (International Standard Atmosphere, ISA). Модель розраховує геопотенціальну висоту `h`, статичну температуру `T`, статичний тиск `p`, густину `ρ` та швидкість звуку `a` від рівня моря до висоти `80 000 м`.

У тропосфері та стратосфері температура змінюється з вертикальним градієнтом `L = dT/dh`. Для ізотермічних шарів (`L = 0`) тиск обчислюється за барометричною формулою, а для політропних шарів (`L ≠ 0`) — за степеневим законом.

```
Для L ≠ 0:  T(h) = T_base + L · (h - h_base)
            p(h) = p_base · ( T(h) / T_base )^( -g₀ / (L · R) )

Для L = 0:  T(h) = T_base
            p(h) = p_base · exp( -g₀ · (h - h_base) / (R · T_base) )
```

де `g₀ = 9.80665 м/с²` — стандартне прискорення вільного падіння на рівні моря.

| Назва шару | Діапазон геопотенціальних висот `h` (м) | Вертикальний градієнт `L` (К/км) | Статична температура на нижній межі `T` (K) | Статичний тиск на нижній межі `p` (Па) | Густина повітря `ρ` (кг/м³) | Локальна швидкість звуку `a` (м/с) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| Тропосфера | `0 ≤ h < 11000` | `-6.5` | 288.15 | 101325.0 | 1.22500 | 340.29 |
| Тропопауза | `11000 ≤ h < 20000` | `0.0` | 216.65 | 22632.1 | 0.36391 | 295.07 |
| Стратосфера-1 | `20000 ≤ h < 32000` | `+1.0` | 216.65 | 5474.89 | 0.08803 | 295.07 |
| Стратосфера-2 | `32000 ≤ h < 47000` | `+2.8` | 228.65 | 868.02 | 0.01322 | 303.13 |
| Стратопауза | `47000 ≤ h < 51000` | `0.0` | 270.65 | 110.91 | 0.00143 | 329.80 |
| Мезосфера-1 | `51000 ≤ h < 71000` | `-2.8` | 270.65 | 66.94 | 0.00086 | 329.80 |
| Мезосфера-2 | `71000 ≤ h < 80000` | `-2.0` | 214.65 | 3.96 | 0.00006 | 293.71 |

Модуль ISA вихідними даними дає чисті статичні параметри середовища, які надалі слугують аргументами для розрахунку числа Маха та характеристик гальмування потоку.

## 3. Структури даних API та C/C++ ABI специфікація

Двоплинний інтерфейс викликів розроблено з урахуванням суворих вимог крос-платформеного ABI. Усі структури мають 64-бітне вирівнювання полів, не містять системно-залежних вказівників чи віртуальних таблиць, що дозволяє передавати їх між модулями C та C++.

### 3.1. Структура стану атмосфери (`isa_atmosphere_state_t`)

Ця структура описує незбурений термодинамічний стан атмосферного повітря на заданій геопотенціальній висоті.

:::tabs
```c
typedef struct {
    double altitude_m;          /* Геопотенціальна висота над рівнем моря [м] */
    double temperature_k;       /* Абсолютна статична температура газу T [К] */
    double pressure_pa;         /* Статичний барометричний тиск p [Па] */
    double density_kg_m3;       /* Густина повітря ρ [кг/м³] */
    double speed_of_sound_m_s;  /* Локальна швидкість звуку a [м/с] */
} isa_atmosphere_state_t;
```
```cpp
namespace gas_dynamics {

struct isa_atmosphere_state {
    double altitude_m{};          // Геопотенціальна висота над рівнем моря [м]
    double temperature_k{};       // Абсолютна статична температура газу T [К]
    double pressure_pa{};         // Статичний барометричний тиск p [Па]
    double density_kg_m3{};       // Густина повітря ρ [кг/м³]
    double speed_of_sound_m_s{};  // Локальна швидкість звуку a [м/с]
};

} // namespace gas_dynamics
```
:::

**Вимоги до полів:**
- `altitude_m`: значення повинно перебувати в межах від `-500.0` до `80000.0` метрів.
- `temperature_k`: завжди строго додатне значення (`> 0.0 K`).
- `pressure_pa`: статичний тиск газу (`> 0.0 Па`).
- `speed_of_sound_m_s`: обчислюється точно як `sqrt(1.4 * 287.058 * temperature_k)`.

### 3.2. Структура стану стисливого потоку (`compressible_flow_state_t`)

Описує кінематичні та термодинамічні характеристики потоку газу навколо рухомого об'єкта або всередині аеродинамічного каналу.

:::tabs
```c
typedef struct {
    double true_airspeed_m_s;      /* Істинна повітряна швидкість v [м/с] */
    double mach_number;            /* Безрозмірне число Маха M = v / a */
    double total_temperature_k;     /* Повна температура гальмування T₀ [К] */
    double total_pressure_pa;       /* Повний тиск гальмування p₀ [Па] */
    double dynamic_pressure_pa;     /* Динамічний тиск (швидкісний напір) q [Па] */
    double prandtl_glauert_factor;    /* Поправка стисливості 1/√(1-M²) (для M < 1) */
    uint32_t flow_regime_flags;    /* Бітові прапорці режиму течії */
    uint32_t reserved;             /* Резервне поле для вирівнювання структури */
} compressible_flow_state_t;
```
```cpp
namespace gas_dynamics {

struct compressible_flow_state {
    double true_airspeed_m_s{};      // Істинна повітряна швидкість v [м/с]
    double mach_number{};            // Безрозмірне число Маха M = v / a
    double total_temperature_k{};     // Повна температура гальмування T₀ [К]
    double total_pressure_pa{};       // Повний тиск гальмування p₀ [Па]
    double dynamic_pressure_pa{};     // Динамічний тиск (швидкісний напір) q [Па]
    double prandtl_glauert_factor{};    // Поправка стисливості 1/√(1-M²) (для M < 1)
    std::uint32_t flow_regime_flags{};// Бітові прапорці режиму течії
    std::uint32_t reserved{};         // Резервне поле для вирівнювання структури
};

} // namespace gas_dynamics
```
:::

**Особливості обчислення полів:**
- `dynamic_pressure_pa`: визначається як `0.5 * density * v^2`.
- `prandtl_glauert_factor`: обчислюється для дозвукових чисел Маха (`M < 0.95`). Для `M ≥ 0.95` встановлюється в `0.0` для запобігання діленню на нуль та числової сингулярності.
- `flow_regime_flags`: бітова маска, що описує поточний аеродинамічний режим (див. розділ 5).

### 3.3. Структура скачка ущільнення (`shock_wave_params_t`)

Використовується для опису стрибкоподібного змінення параметрів газу при переході через пряму або косу ударну хвилю.

:::tabs
```c
typedef struct {
    double upstream_mach;       /* Число Маха перед скачком M₁ (мусить бути > 1.0) */
    double downstream_mach;     /* Число Маха після скачка M₂ (завжди < 1.0) */
    double pressure_ratio;      /* Відношення статичних тисків p₂ / p₁ */
    double temperature_ratio;   /* Відношення статичних температур T₂ / T₁ */
    double density_ratio;       /* Відношення густин ρ₂ / ρ₁ */
    double total_pressure_loss; /* Коефіцієнт збереження повного тиску p₀₂ / p₀₁ */
} shock_wave_params_t;
```
```cpp
namespace gas_dynamics {

struct shock_wave_params {
    double upstream_mach{};       // Число Маха перед скачком M₁ (> 1.0)
    double downstream_mach{};     // Число Маха після скачка M₂ (< 1.0)
    double pressure_ratio{};      // Відношення статичних тисків p₂ / p₁
    double temperature_ratio{};   // Відношення статичних температур T₂ / T₁
    double density_ratio{};       // Відношення густин ρ₂ / ρ₁
    double total_pressure_loss{}; // Коефіцієнт збереження повного тиску p₀₂ / p₀₁
};

} // namespace gas_dynamics
```

## 4. Детальна специфікація функцій обчислювального ядра

Усі функції API розроблені як потокобезпечні (thread-safe), не використовують глобального стану чи статичних буферів, і повертають цілочисельний код статусу виконання.

### 4.1. `isa_atmosphere_get_state`

Розраховує стандартні термодинамічні параметри атмосфери для вказаної геопотенціальної висоти.

:::tabs
```c
int isa_atmosphere_get_state(
    double altitude_m,
    isa_atmosphere_state_t *out_state
);
```
```cpp
namespace gas_dynamics {

[[nodiscard]] std::int32_t get_isa_state(
    double altitude_m,
    isa_atmosphere_state& out_state
) noexcept;

} // namespace gas_dynamics
```
:::

**Опис роботи:**
Функція визначає атмосферний шар, якому відповідає `altitude_m`, обчислює статичну температуру `T` з урахуванням температурного градієнта `L`, після чого знаходить тиск `p` за адіабатичною або барометричною формулою. На завершення розраховується густина `ρ = p / (R · T)` та локальна швидкість звуку `a = √(γ · R · T)`.

**Параметри:**
- `altitude_m` [in]: геопотенціальна висота над рівнем моря в метрах (`-500.0 ≤ altitude_m ≤ 80000.0`).
- `out_state` [out]: вказівник на вихідну структуру `isa_atmosphere_state_t`.

**Коди повернення:**
- `0` (`GAS_DYNAMICS_OK`) — розрахунок виконано успішно.
- `-1` (`GAS_DYNAMICS_ERR_NULL_POINTER`) — `out_state` дорівнює `NULL`.
- `-101` (`GAS_DYNAMICS_ERR_ALTITUDE_OUT_OF_RANGE`) — висота перевищує допустимі межі специфікації.

### 4.2. `mach_calculate_from_state`

Виконує повний розрахунок параметрів стисливого потоку за відомою швидкістю руху та станом атмосфери.

:::tabs
```c
int mach_calculate_from_state(
    double true_airspeed_m_s,
    const isa_atmosphere_state_t *atm_state,
    compressible_flow_state_t *out_flow
);
```
```cpp
namespace gas_dynamics {

[[nodiscard]] std::int32_t calculate_flow_from_state(
    double true_airspeed_m_s,
    const isa_atmosphere_state& atm_state,
    compressible_flow_state& out_flow
) noexcept;

} // namespace gas_dynamics
```
:::

**Опис роботи:**
Функція обчислює число Маха `M = true_airspeed_m_s / atm_state->speed_of_sound_m_s`, визначає поточний режим течії, розраховує температуру гальмування `T₀ = T · (1 + 0.2 · M²)`, повний тиск гальмування `p₀ = p · (1 + 0.2 · M²)^3.5`, швидкісний напір `q = ½ ρ v²` та коефіцієнт Прандтля-Ґлауерта.

**Параметри:**
- `true_airspeed_m_s` [in]: істинна повітряна швидкість апарата у м/с (`≥ 0.0`).
- `atm_state` [in]: вказівник на валідну структуру стану атмосфери.
- `out_flow` [out]: вказівник на структуру результатів розрахунку.

**Коди повернення:**
- `0` (`GAS_DYNAMICS_OK`) — успіх.
- `-1` (`GAS_DYNAMICS_ERR_NULL_POINTER`) — один із вказівників дорівнює `NULL`.
- `-102` (`GAS_DYNAMICS_ERR_NEGATIVE_VELOCITY`) — від'ємна швидкість `true_airspeed_m_s < 0`.

### 4.3. `mach_calculate_from_pitot_static`

Визначення числа Маха за різницею тисків, виміряних комбінованим датчиком Пито-Статика (махометром).

:::tabs
```c
int mach_calculate_from_pitot_static(
    double pitot_total_pressure_pa,
    double static_pressure_pa,
    double *out_mach_number
);
```
```cpp
namespace gas_dynamics {

[[nodiscard]] std::int32_t calculate_mach_from_pitot(
    double pitot_total_pressure_pa,
    double static_pressure_pa,
    double& out_mach_number
) noexcept;

} // namespace gas_dynamics
```
:::

**Опис роботи:**
Функція аналізує співвідношення повного тиску до статичного `r = p₀ / p`.
- Якщо `r ≤ 1.89293` (дозвуковий режим, `M ≤ 1.0`), застосовується формула Сен-Венана—Ванцеля:
  ```
  M = √[ 5 · ( (p₀ / p)^(2/7) - 1 ) ]
  ```
- Якщо `r > 1.89293` (надзвуковий режим, `M > 1.0`), перед приймачем Пито виникає прямий скачок ущільнення. Число Маха визначається розв'язанням трансцендентного рівняння Пито-Релея методом Ньютона-Рафсона:
  ```
  p₀ / p = ( (7 · M² - 1) / 6 ) · ( 6 / (5 · M²) )^2.5
  ```

**Параметри:**
- `pitot_total_pressure_pa` [in]: виміряний повний тиск `p₀` [Па].
- `static_pressure_pa` [in]: виміряний статичний тиск `p` [Па].
- `out_mach_number` [out]: розраховане значення числа Маха.

**Коди повернення:**
- `0` (`GAS_DYNAMICS_OK`) — розрахунок успішний.
- `-1` (`GAS_DYNAMICS_ERR_NULL_POINTER`) — `out_mach_number` дорівнює `NULL`.
- `-103` (`GAS_DYNAMICS_ERR_PRESSURE_RATIO_INVALID`) — некоректне співвідношення `p₀ < p` або від'ємний тиск.

### 4.4. `shock_wave_normal_calculate`

Розрахунок газодинамічних параметрів прямого скачка ущільнення за співвідношеннями Ренкіна-Гюгоньо.

:::tabs
```c
int shock_wave_normal_calculate(
    double upstream_mach,
    double gamma,
    shock_wave_params_t *out_shock
);
```
```cpp
namespace gas_dynamics {

[[nodiscard]] std::int32_t calculate_normal_shock(
    double upstream_mach,
    double gamma,
    shock_wave_params& out_shock
) noexcept;

} // namespace gas_dynamics
```
:::

**Опис роботи:**
Функція обчислює число Маха за прямим скачком `M₂ = √[ ((γ-1)M₁² + 2) / (2γ M₁² - (γ-1)) ]`, скачок статичного тиску `p₂/p₁`, скачок температури `T₂/T₁`, скачок густини `ρ₂/ρ₁` та відносний коефіцієнт втрати повного тиску `p₀₂/p₀₁`.

**Параметри:**
- `upstream_mach` [in]: число Маха перед скачком `M₁` (мусить бути `> 1.0`).
- `gamma` [in]: показник адіабати газу (за замовчуванням `1.4`).
- `out_shock` [out]: вказівник на структуру результату.

**Коди повернення:**
- `0` (`GAS_DYNAMICS_OK`) — успіх.
- `-1` (`GAS_DYNAMICS_ERR_NULL_POINTER`) — `out_shock` дорівнює `NULL`.
- `-104` (`GAS_DYNAMICS_ERR_SUBSONIC_SHOCK`) — спроба розрахувати скачок ущільнення для дозвукового потоку (`M₁ ≤ 1.0`).

## 5. Коди помилок та бітові прапорці режимів

### 5.1. Реєстр кодів повернення API

| Константа статусу | Значення | Категорія | Опис причини помилки або стану |
| :--- | :---: | :---: | :--- |
| `GAS_DYNAMICS_OK` | `0` | Успіх | Операцію виконано без помилок |
| `GAS_DYNAMICS_ERR_NULL_POINTER` | `-1` | Аргументи | Передано вказівник на `NULL` пам'ять |
| `GAS_DYNAMICS_ERR_ALTITUDE_OUT_OF_RANGE` | `-101` | Вхідні дані | Висота за межами діапазону ISA (`-500..80000 м`) |
| `GAS_DYNAMICS_ERR_NEGATIVE_VELOCITY` | `-102` | Вхідні дані | Фізично неможлива від'ємна швидкість `v < 0` |
| `GAS_DYNAMICS_ERR_PRESSURE_RATIO_INVALID` | `-103` | Датчики | Повний тиск менший за статичний (`p₀ < p`) |
| `GAS_DYNAMICS_ERR_SUBSONIC_SHOCK` | `-104` | Фізика | Прямий скачок вимагає надзвуку (`M₁ > 1.0`) |
| `GAS_DYNAMICS_ERR_SINGULARITY_MACH_ONE` | `-105` | Математика | Обічнення поправки Прандтля при `M = 1.0` |

### 5.2. Специфікація бітових прапорців режимів (`flow_regime_flags`)

:::tabs
```c
#define FLOW_REGIME_SUBSONIC_INCOMPRESSIBLE  (1U << 0) /* M < 0.3: нестислий потік */
#define FLOW_REGIME_SUBSONIC_COMPRESSIBLE    (1U << 1) /* 0.3 <= M < 0.8: стислий дозвук */
#define FLOW_REGIME_TRANSONIC                (1U << 2) /* 0.8 <= M <= 1.2: трансзвуковий потік */
#define FLOW_REGIME_SUPERSONIC               (1U << 3) /* 1.2 < M <= 5.0: надзвуковий потік */
#define FLOW_REGIME_HYPERSONIC               (1U << 4) /* M > 5.0: гіперзвуковий потік */
#define FLOW_REGIME_SHOCK_WAVE_PRESENT       (1U << 5) /* У потоці присутні скачки ущільнення */
#define FLOW_REGIME_THERMAL_EFFECTS_CRITICAL (1U << 6) /* Критичний кінетичний нагрів (T₀ > 500 K) */
```
```cpp
namespace gas_dynamics {

enum class regime_flags : std::uint32_t {
    subsonic_incompressible  = (1U << 0), // M < 0.3
    subsonic_compressible    = (1U << 1), // 0.3 <= M < 0.8
    transonic                = (1U << 2), // 0.8 <= M <= 1.2
    supersonic               = (1U << 3), // 1.2 < M <= 5.0
    hypersonic               = (1U << 4), // M > 5.0
    shock_wave_present       = (1U << 5), // Скачки ущільнення
    thermal_effects_critical = (1U << 6)  // Нагрів T0 > 500 K
};

} // namespace gas_dynamics
```
