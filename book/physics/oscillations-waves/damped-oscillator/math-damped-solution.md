# 🧮 Виведення розв'язку загасного осцилятора: одна підстановка, три долі

Рівняння m·ẍ + c·ẋ + k·x = 0 виглядає скромно, а ховає в собі три зовсім різні поведінки — дзвінке гойдання, найшвидше повернення без перельоту й мляве повзання назад до спокою. Найдивовижніше, що всі троє випливають не з трьох різних фізик, а з однієї-єдиної алгебраїчної розвилки. Тут ми пройдемо весь шлях чесно, від диференціального рівняння до готових формул: підставимо пробну функцію, перетворимо рівняння на звичайне квадратне й побачимо, як знак одного підкореневого виразу розводить осцилятор на три долі. А насамкінець навчимося прямо із запису коливання вимірювати загасання лінійкою — і глянемо на всі три режими згори, як на криві у фазовій площині.

## Спершу причешемо рівняння

Три коефіцієнти m, c, k — забагато, щоб тримати їх в голові водночас; насправді долю осцилятора вирішують не вони поодинці, а кілька їхніх поєднань. Тож поділімо все рівняння на масу m:

```
ẍ + (c/m)·ẋ + (k/m)·x = 0
```

і дамо двом дробам імена, які самі просяться. Відношення k/m — це квадрат [власної частоти](book:physics/harmonic-oscillator) незгасного осцилятора: ω₀² = k/m, бо саме √(k/m) — частота, з якою маса на пружині гойдалася б без жодних утрат. Половину коефіцієнта при ẋ назвемо **темпом загасання** γ = c/(2m); чому саме половину — стане видно за хвилину, коли двійка красиво скоротиться. Тоді c/m = 2γ, і рівняння набуває чистого канонічного вигляду:

```
ẍ + 2γ·ẋ + ω₀²·x = 0
```

Ще зручніше міряти загасання не саме по собі, а відносно «жвавості» осцилятора — порівняти γ з ω₀. Це безрозмірне відношення і є **міра загасання** ζ:

```
ζ = γ/ω₀ = c/(2m) · 1/√(k/m) = c/(2·√(m·k))
```

Звідси темп загасання пишеться просто γ = ζ·ω₀, і в рівнянні лишається всього два числа — ω₀ (як швидко воно взагалі коливається) і ζ (наскільки те коливання згасає):

```
ẍ + 2ζω₀·ẋ + ω₀²·x = 0
```

Уся подальша історія — про одне число ζ. Але щоб його роль проступила, треба спершу рівняння розв'язати.

## Пробна функція: чому неодмінно показник

Яку функцію часу шукати? Здоровий глузд підказує вимогу, від якої нікуди не дітися. Рівняння вимагає, щоб сума самої функції, її першої похідної та другої в кожну мить давала нуль. А це можливо лише тоді, коли всі три — і x, і ẋ, і ẍ — **однакові за формою**, відрізняючись хіба сталим множником: інакше вони не скоротяться в кожен момент часу, а лише в окремі. Функція, чия похідна — це вона сама, помножена на сталу, одна-єдина: [показникова](book:math/exponential-ode) e^(λt). Її перша похідна — λ·e^(λt), друга — λ²·e^(λt); усі три — той самий e^(λt) з різними коефіцієнтами. Тому пробуємо (нім. *Ansatz* — заготовка, робоче припущення):

```
x(t) = e^(λt)
```

де λ — поки невідоме число (можливо, комплексне — і саме тут ховається вся сіль). Підставмо його разом із похідними в канонічне рівняння:

```
λ²·e^(λt) + 2ζω₀·λ·e^(λt) + ω₀²·e^(λt) = 0
```

Множник e^(λt) спільний у всіх трьох доданках, і він **ніколи не дорівнює нулю** — показникова функція не обертається на нуль за жодного скінченного t. Тож поділити на нього можна безбоязно, і від цілого диференціального рівняння лишається коротке алгебраїчне:

```
λ² + 2ζω₀·λ + ω₀² = 0
```

Ось де магія. Ми проміняли похідні на степені: **диференціальне рівняння перетворилося на квадратне**. Його називають **характеристичним рівнянням** осцилятора — бо його корені й задають характер руху. У вихідних буквах, до нормування, воно читається так само прозоро: m·λ² + c·λ + k = 0.

## Дискримінант — розвилка на три світи

Квадратне рівняння розв'язується формулою, яку кожен знає зі школи:

```
λ = ( −2ζω₀ ± √( (2ζω₀)² − 4ω₀² ) ) / 2 = −ζω₀ ± ω₀·√(ζ² − 1)
```

Згадавши, що γ = ζω₀, запишімо це найкомпактніше:

```
λ = −γ ± ω₀·√(ζ² − 1)
```

Тепер придивімося, від чого залежить усе. Дійсна частина −γ у всіх випадках однакова й завжди від'ємна — це спільна «стеля згасання». А от підкореневий вираз **ζ² − 1** поводиться по-різному, і саме його знак вирішує долю. Це і є дискримінант (лат. *discrimināre* — розрізняти) характеристичного рівняння; у первісних буквах він дорівнює c² − 4mk і має той самий знак, що й ζ² − 1. Можливі рівно три випадки, і кожен дає осцилятору свій світ:

```
ζ < 1   →  ζ²−1 < 0   →  корінь із від'ємного  →  два КОМПЛЕКСНІ корені  →  гойдання
ζ = 1   →  ζ²−1 = 0   →  корінь нульовий       →  один ПОДВІЙНИЙ корінь  →  межа
ζ > 1   →  ζ²−1 > 0   →  корінь із додатного   →  два ДІЙСНІ корені      →  повзання
```

Це головна думка всього виведення: три режими загасного осцилятора — не три окремі теорії, а три відповіді однієї квадратної формули на питання «яка тепер під коренем величина». Пройдімо кожен світ окремо.

## ζ < 1: комплексні корені, що обертаються на синусоїду

При слабкому загасанні ζ² − 1 від'ємне, і корінь із нього — уявний. Витягнімо звідти уявну одиницю i:

```
√(ζ² − 1) = √( −(1 − ζ²) ) = i·√(1 − ζ²)
```

і дамо ім'я тому, що лишилося під коренем, — **частоті загасного гойдання** ω_d = ω₀·√(1 − ζ²). Тоді два корені виходять комплексно-спряженою парою:

```
λ = −γ ± i·ω_d
```

Загальний розв'язок лінійного рівняння — сума двох показникових з цими коренями:

```
x(t) = C₁·e^((−γ+iω_d)t) + C₂·e^((−γ−iω_d)t) = e^(−γt)·( C₁·e^(iω_d t) + C₂·e^(−iω_d t) )
```

Спільний множник e^(−γt) — це вже знайоме згасання, що йде від дійсної частини −γ кореня. А що робить решта, з уявними показниками? Тут вступає [формула Ейлера](book:math/euler-formula), яка перекладає показник з уявним аргументом на мову синуса й косинуса: e^(iθ) = cos θ + i·sin θ. Комплексна експонента — це насправді обертання; її дійсна й уявна частини гойдаються косинусом і синусом. Ось де народжується коливання: **уявна частина кореня ±iω_d — це і є частота гойдання, а дійсна −γ — темп його згасання**.

Лишається одна вимога здорового глузду: положення маси x(t) — річ фізична, а отже дійсна, без жодного i. Комбінація двох комплексних доданків буде дійсною лише тоді, коли коефіцієнти [комплексно-спряжені](book:math/complex-numbers): C₂ = C₁*. За цієї умови уявні частини гасять одна одну, а дійсні складаються, і після згортання за Ейлером усе зводиться до двох дійсних сталих a і b:

```
x(t) = e^(−γt)·( a·cos(ω_d t) + b·sin(ω_d t) )
```

Косинус і синус тієї самої частоти завжди можна злити в один зсунутий косинус із амплітудою A = √(a² + b²) і фазою φ (де tan φ = b/a). Виходить рівно та крива, яку тема обіцяла:

```
x(t) = A·e^(−γt)·cos(ω_d t − φ)
```

Тепер вона не постульована, а виведена. Множник e^(−γt) — спадна ковдра з дійсної частини кореня; cos(ω_d t − φ) — гойдання з його уявної частини. І одразу випадає той факт, що загасне гойдання **повільніше** за незгасне: ω_d = ω₀·√(1 − ζ²) завжди менша за ω₀, бо √(1 − ζ²) < 1. Причина не в якійсь новій фізиці, а прямо в геометрії кореня.

Ця геометрія варта окремого погляду. Обчислімо, як далеко корінь −γ + iω_d від початку комплексної площини:

```
|λ|² = γ² + ω_d² = (ζω₀)² + ω₀²(1 − ζ²) = ω₀²·(ζ² + 1 − ζ²) = ω₀²
```

Отже |λ| = ω₀ — незалежно від ζ! Обидва комплексні корені завжди сидять на **колі радіуса ω₀**. А міра загасання ζ — це просто косинус кута φ, під яким корінь відхилений від від'ємної дійсної осі: cos φ = γ/ω₀ = ζ. Звідси видно все одразу. Коли загасання зникає (ζ → 0), кут φ → 90°, корінь виходить на уявну вісь у точку iω₀ — чисте незгасне гойдання. Коли загасання росте, корінь сповзає колом униз, його уявна частина (тобто справжня частота ω_d) меншає, аж поки при ζ → 1 корінь не з'їде на дійсну вісь у точку −ω₀, де гойдання зникає зовсім.

![Корені характеристичного рівняння на комплексній площині](/book/physics/oscillations-waves/damped-oscillator/img/roots.svg)
*Обидва корені комплексної пари лежать на колі радіуса ω₀; міра загасання — косинус кута φ від від'ємної дійсної осі. Зі зростанням ζ корені сповзають колом до точки −ω₀, зливаються там у подвійний (ζ = 1), а далі розходяться вздовж дійсної осі у два дійсні (ζ > 1). Усі корені — ліворуч від уявної осі, тому будь-який рух згасає.*

Дві сталі A і φ (чи то a і b) визначаються з початкових умов — де маса й куди рухалася в мить t = 0. Якщо задано x(0) = x₀ і v(0) = v₀, то підстановка t = 0 дає a = x₀, а похідна в нулі — b = (v₀ + γx₀)/ω_d. Для найпоказовішого випадку — масу відхилили на x₀ і **відпустили зі спокою** (v₀ = 0) — виходить:

```
x(t) = x₀·e^(−γt)·( cos(ω_d t) + (ζ/√(1−ζ²))·sin(ω_d t) )
     = ( x₀/√(1−ζ²) )·e^(−γt)·cos(ω_d t − φ),   tan φ = ζ/√(1−ζ²)
```

Маленька фаза φ у косинусі — це не примха: відпущена зі спокою маса стартує з горизонтальною дотичною (швидкість нуль), і саме зсув фази забезпечує цю рівну вершину на самому початку.

## ζ = 1: подвійний корінь і зникла половина розв'язку

Рівно на межі, при ζ = 1, дискримінант обертається на нуль, і обидва корені зливаються в один:

```
λ = −γ = −ω₀   (двічі)
```

Тут криється тонкість, повз яку легко проскочити. Характеристичне рівняння дало **лише один** показник, e^(−ω₀t). Але рівняння другого порядку мусить мати **два** незалежні розв'язки — інакше двома сталими не задовольнити дві початкові умови (і положення, і швидкість). Куди ж подівся другий розв'язок?

Найкраще побачити це як **злиття**. Візьмімо недозагашений розв'язок і обережно спрямуймо ζ до одиниці, тобто ω_d до нуля. Синусна гілка містила множник sin(ω_d t), а її стала b росла як 1/ω_d — і в добутку виникає невизначеність 0/0, яку варто розкрити чесно:

```
lim(ω_d → 0)  sin(ω_d t) / ω_d  =  t
```

(бо для малого аргументу sin(ω_d t) ≈ ω_d·t). Синусна половина розв'язку не зникає — вона **вироджується в лінійний множник t**. Ось звідки береться другий, схований розв'язок: t·e^(−ω₀t). Отже загальний розв'язок на критичній межі:

```
x(t) = (A + B·t)·e^(−ω₀t)
```

Той самий результат дає й формальний прийом: якщо продиференціювати пробну функцію e^(λt) за параметром λ, вийде t·e^(λt), і в точці подвійного кореня обидві функції — e^(λt) і t·e^(λt) — задовольняють рівняння. Хоч так, хоч так, друга незалежна ланка — та сама.

Множник (A + B·t) спершу може навіть трохи піднести криву (лінійна частина росте), але показник e^(−ω₀t) зрештою придушує будь-який многочлен, і маса плавно осідає в нуль. При відпусканні зі спокою (v₀ = 0) сталі виходять A = x₀, B = ω₀x₀, тобто x(t) = x₀·(1 + ω₀t)·e^(−ω₀t) — крива, що доходить до рівноваги якнайшвидше й **жодного разу її не перетинає**. Чому саме це найшвидше — стане зрозуміло з наступного світу.

## ζ > 1: два дійсні корені й чому це найповільніше

При сильному загасанні ζ² − 1 додатне, корінь із нього дійсний, і пара коренів — два різні **дійсні** числа:

```
λ₁,₂ = −γ ± ω₀·√(ζ² − 1) = −ω₀·( ζ ∓ √(ζ² − 1) )
```

Обидва від'ємні (бо ζ > √(ζ² − 1) завжди), тож розв'язок — сума двох чисто спадних показникових, без жодного синуса:

```
x(t) = C₁·e^(λ₁ t) + C₂·e^(λ₂ t)
```

Гойдання нема й близько: немає уявних частин — немає обертання. Маса просто повзе до рівноваги. Але ось несподіванка, яку варто вивести, а не проковтнути: перезагашений осцилятор повертається **повільніше** за критичний, хоч гальмування й сильніше.

Секрет — у тому, що на великих часах виживає лише **повільніший** з двох показників, той, чий корінь ближчий до нуля:

```
λ_повільний = −ω₀·( ζ − √(ζ² − 1) )
```

Його час згасання τ = 1/|λ_повільний| = 1 / ( ω₀·( ζ − √(ζ² − 1) ) ) і задає, скільки насправді триває повернення. Погляньмо, як поводиться множник g(ζ) = ζ − √(ζ² − 1). При ζ = 1 він дорівнює 1. А для великих ζ розкладемо корінь: √(ζ² − 1) ≈ ζ − 1/(2ζ), тож

```
g(ζ) = ζ − √(ζ² − 1) ≈ 1/(2ζ) → 0   при ζ → ∞
```

Отже що більше ζ, то менший g, то **більший** час τ — повернення розтягується. Мінімум τ (найшвидше згасання) припадає рівно на ζ = 1, де g = 1 і τ = 1/ω₀. Це і є суворе пояснення «золотої середини»: піднімеш загасання понад критичне — і один із коренів сповзає до нуля, тобто один із режимів руху стає майже незгасним, тягнучи весь спад за собою. На комплексній площині це видно наочно: за критичною точкою корені розбігаються вздовж дійсної осі, і той, що прямує до початку координат, робить рух дедалі млявішим.

## Логарифмічний декремент: виміряти ζ лінійкою по піках

Виведене має негайну практичну користь. Уявімо, що ми записали вільний «дзвін» недозагашеного осцилятора й хочемо дізнатися його ζ, не знаючи наперед ані маси, ані жорсткості, ані c. Виявляється, досить виміряти висоту двох сусідніх вершин.

Сусідні піки того самого знаку віддалені рівно на один період T_d = 2π/ω_d. (Тонкість: через нахил спадної обвідної вершини сидять не точно там, де cos = 1, — але умова піку ẋ = 0 дає той самий фазовий зсув щоразу, тож проміжок між сусідніми піками **точно** дорівнює T_d.) Візьмімо відношення двох вершин, у моменти tₙ і tₙ + T_d. Косинус в обох однаковий (минув цілий період), тож лишається саме відношення обвідних:

```
xₙ / xₙ₊₁ = e^(−γ tₙ) / e^(−γ (tₙ + T_d)) = e^(γ T_d)
```

Це відношення однакове для **будь-якої** пари сусідніх вершин — розмах падає в стале число разів щоцикла (геометрична прогресія). Його логарифм і назвали **логарифмічним декрементом** δ (лат. *decrementum* — спад, зменшення):

```
δ = ln(xₙ / xₙ₊₁) = γ·T_d = γ · (2π/ω_d) = 2π · (ζω₀)/(ω₀√(1−ζ²)) = 2π·ζ / √(1 − ζ²)
```

Ось і обіцяна формула. Вона працює в обидва боки: виміряли дві вершини — дістали δ, а з нього одразу ζ, розв'язавши рівняння відносно ζ:

```
ζ = δ / √(4π² + δ²)
```

При слабкому загасанні (δ ≪ 1) корінь ≈ 2π, і все спрощується до чудово простого ζ ≈ δ/(2π). А щоб не мучитися з двома зашумленими вершинами, беруть N-ту вершину замість першої: ln(x₀/x_N) = N·δ, тобто нахил прямої «логарифм висоти піку проти номера циклу» — це прямо δ. Один графік, одна лінійка — і загасання виміряне.

## Спад енергії та добротність

Тепер погляньмо на те саме з боку енергії — і виведемо число, що міряє «дзвінкість». Повна енергія осцилятора — сума кінетичної й пружної:

```
E = ½·m·v² + ½·k·x²
```

Обидва доданки квадратичні за амплітудою, а амплітуда спадає як e^(−γt). Тому усереднена за цикл енергія спадає **удвічі стрімкіше**:

```
⟨E⟩ = ½·k·A(t)² = ½·k·A₀²·e^(−2γt)  ∝  e^(−2γt)
```

Це не збіг: продиференціювавши, дістаємо dE/dt = −2γ·E — за одиницю часу зникає стала **частка** енергії, 2γ. Втрачена на тертя енергія — це рівно та, що покидає коливання; час загасання енергії τ_E = 1/(2γ) удвічі коротший за час загасання амплітуди 1/γ.

Скільки ж циклів осцилятор продзвенить? Природна міра — скільки енергії він зберігає проти того, скільки губить за один оберт. Саме так означають **добротність** Q:

```
Q = 2π · (запасена енергія) / (втрата за цикл)
```

Втрата за один період — це ΔE = E·(1 − e^(−2γ T_d)) ≈ 2γ·T_d·E для слабкого загасання. Підставмо:

```
Q = 2π·E / ΔE = 2π / (2γ T_d) = π / (γ · 2π/ω_d) = ω_d / (2γ)
```

При слабкому загасанні ω_d ≈ ω₀, і формула згортається до знаменитого:

```
Q = ω₀ / (2γ) = ω₀ / (2ζω₀) = 1 / (2ζ)
```

Ось звідки Q = 1/(2ζ). Що менша міра загасання, то вища добротність, то довше дзвенить осцилятор. Ці числа не самотні: порівнявши з декрементом, бачимо δ = 2πζ = π/Q при слабкому загасанні — тож Q = π/δ, ще один спосіб добути добротність із запису. А ще прикидка «скільки циклів до затухання»: амплітуда падає в e ≈ 2.72 раза за час 1/γ, тобто за 1/(γ T_d) = ω_d/(2πγ) ≈ Q/π повних гойдань. Дешевий дзвіночок із Q ≈ 3 продзвенить менш ніж один цикл, кварц із Q ≈ 10⁴ — тисячі.

## Фазовий портрет: три режими одним поглядом

Насамкінець — геометрична вершина всього. Замість креслити x проти часу, викладемо стан осцилятора інакше. У кожну мить осцилятор повністю описується двома числами: де маса (x) і як швидко вона рухається (v = ẋ). Тож нанесімо на горизонтальну вісь x, на вертикальну — v, і весь стан системи стане **однією точкою** на цій площині. Час іде — точка повзе, малюючи криву. Таку площину звуть фазовою, а криву — фазовою траєкторією.

Що на ній видно? Енергія ½·m·v² + ½·k·x² = const — це еліпс (а якщо міряти вертикаль у зручних одиницях v/ω₀, то й рівне коло). Тому:

- **Незгасний осцилятор (ζ = 0)** іде замкненим колом вічно: енергія стала, точка кружляє й ніколи не спиняється.
- **Недозагашений (ζ < 1)** втрачає трохи енергії щовитком, тож коло стягується у **спіраль**: точка обертається навколо початку координат, але щоразу ближче, аж поки не спіраллю впаде в центр. Кожен оберт стискає радіус у те саме e^(−γ T_d) — та сама геометрична прогресія, що й у вершинах дзвону.
- **Критичний і перезагашений (ζ ≥ 1)** взагалі не обертаються навколо центру: точка заходить у нуль **прямо**, не встигнувши обкрутити початок жодного разу.

Початок координат — це рівновага, і загасання перетворює його з нейтрального центру (замкнені орбіти) на **стягувальний атрактор**: хоч звідки відпусти осцилятор, траєкторія зрештою спадає в нуль. Три режими зводяться до одного геометричного питання — встигає точка обкрутити центр чи ні: оберт навколо нуля — це гойдання, стягування в нуль — це загасання, а їхнє поєднання чи роз'єднання і є вся різниця між дзвоном і повзанням.

![Фазовий портрет трьох режимів у площині x–v](/book/physics/oscillations-waves/damped-oscillator/img/phase.svg)
*Три осцилятори, відпущені з тієї самої точки (x₀, 0). Недозагашений в'ється спіраллю до рівноваги, обкручуючи її раз за разом. Критичний і перезагашений заходять у центр прямо, не обкрутивши його. Пунктирне коло — незгасний рух зі сталою енергією, від якого загасання й «відкушує» щовитком.*

Ось чому одна квадратна формула тримає всю тему: корінь із додатного числа дає дійсні λ і пряме падіння в центр, корінь із від'ємного — комплексні λ, обертання й спіраль, а нуль під коренем — точну межу між ними. Три долі осцилятора — це три відповіді дискримінанта, побачені то як криві часу, то як корені на колі, то як траєкторії у фазовій площині; і всі три погляди — про одне й те саме число ζ.
