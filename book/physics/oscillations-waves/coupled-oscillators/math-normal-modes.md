# 🧮 Математичний апарат нормальних мод та діагоналізація масивів зв'язаних осциляторів

Ця математична вставка містить повний аналітичний вивід малого коливального руху `N`-вимірних зв'язаних механічних та електричних систем, формалізм Лагранжа, метод вікового рівняння, математичні доведення дійсності власних частот і ортогональності модальних векторів, а також процедуру одночасної діагоналізації матриць мас і жорсткості для переходу до незалежних нормальних координат.

## 1. Лагранжів формалізм малих коливань систем із N ступенями вільності

Розглянемо довільну консервативну механічну або електричну систему з `N` ступенями вільності, стан якої у будь-який момент часу повністю визначається вектором узагальнених координат `x = (x₁, x₂, ..., x_N)ᵀ`. Припустимо, що система перебуває у стані стійкої рівноваги, який ми без втрати загальності оберемо за початок відліку узагальнених координат: `x = (0, 0, ..., 0)ᵀ`.

Оскільки ми розглядаємо малі коливання поблизу стану рівноваги, ми можемо розкласти потенціальну енергію системи `V(x)` у багатовимірний ряд Тейлора в околі точки `x = 0`:

```
V(x) = V(0) + ∑ (∂V / ∂x_i)₀ · x_i + (1/2) · ∑ (∂²V / (∂x_i ∂x_j))₀ · x_i · x_j + ...
```

Покладемо рівень відліку потенціальної енергії рівним нулю у точці рівноваги: `V(0) = 0`. Оскільки точка `x = 0` за припущенням є точкою локального мінімуму потенціальної енергії (умовою стійкої рівноваги), всі перші частинні похідні потенціалу в цій точці точно дорівнюють нулю: `(∂V / ∂x_i)₀ = 0`.

Обмежившись у розкладі найнижчими ненульовими квадратичними членами (наближення малих коливань), отримуємо симетричну квадратичну форму потенціальної енергії:

```
V(x) = (1/2) · ∑ K_ij · x_i · x_j = (1/2) · xᵀ · K · x
```

де коефіцієнти `K_ij = (∂²V / (∂x_i ∂x_j))₀` є елементами квадратної симетричної **матриці жорсткості** `K` розміру `N × N` (`K_ij = K_ji`, тобто `K = Kᵀ`). Умова стійкості рівноваги гарантує, що квадратична форма `V(x)` є строго додатно визначеною: для будь-якого ненульового зміщення `x ≠ 0` потенціальна енергія `V(x) > 0`, а отже, матриця `K` є додатно визначеною (`K > 0`).

Кінетична енергія системи `T` при малих узагальнених швидкостях `ẋ = (ẋ₁, ẋ₂, ..., ẋ_N)ᵀ` у загальному випадку виражається як квадратична форма від швидкостей зі сталими коефіцієнтами, обчисленими у точці рівноваги:

```
T(ẋ) = (1/2) · ∑ M_ij · ẋ_i · ẋ_j = (1/2) · ẋᵀ · M · ẋ
```

де коефіцієнти `M_ij` утворюють квадратну симетричну **матрицю мас** (або матрицю інерції) `M` розміру `N × N` (`M_ij = M_ji`, тобто `M = Mᵀ`). Оскільки кінетична енергія будь-якого руху матерії є додатною величиною (`T > 0` при `ẋ ≠ 0`), матриця мас `M` також є строго додатно визначеною.

Складемо функцію Лагранжа системи `L = T − V`:

```
L(x, ẋ) = (1/2) · ẋᵀ · M · ẋ − (1/2) · xᵀ · K · x
```

Запишемо диференціальні рівняння руху у формі рівнянь Ейлера — Лагранжа для кожної узагальненої координати `i = 1, 2, ..., N`:

```
d/dt (∂L / ∂ẋ_i) − (∂L / ∂x_i) = 0
```

Обчислимо частинні похідні функції Лагранжа:
- Частинна похідна кінетичної енергії по швидкості дає узагальнений імпульс: `∂L / ∂ẋ_i = ∑ M_ij · ẋ_j`. Повна похідна по часу від цього виразу дає `d/dt (∂L / ∂ẋ_i) = ∑ M_ij · ẍ_j`.
- Частинна похідна потенціальної енергії по координаті дає узагальнену силу зі знаком мінус: `∂L / ∂x_i = −∑ K_ij · x_j`.

Підставивши ці похідні у рівняння Ейлера — Лагранжа, дістаємо систему `N` зв'язаних лінійних диференціальних рівнянь другого порядку:

```
∑ M_ij · ẍ_j + ∑ K_ij · x_j = 0
```

У компактній матричній формі ця система приймає класичний вигляд:

```
M · ẍ + K · x = 0
```

де `ẍ = d²x / dt²` — вектор узагальнених прискорень.

## 2. Вікове рівняння та аналітичне доведення дійсності власних частот

Шукатимемо частинний розв'язок матричного рівняння руху у вигляді синусоїдального гармонічного коливання, в якому всі `N` узагальнених координат коливаються з однаковою шуканою частотою `ω` та однаковою початковою фазою `φ`:

```
x(t) = v · cos(ω · t + φ)
```

де `v = (v₁, v₂, ..., v_N)ᵀ` — постійний вектор амплітуд (вектор модальної форми).

Друга похідна по часу від цього розв'язку дорівнює: `ẍ(t) = −ω² · v · cos(ω · t + φ)`. Підставимо вектор зсувів та вектор прискорень у матричне рівняння руху `M · ẍ + K · x = 0`:

```
−ω² · M · v · cos(ω · t + φ) + K · v · cos(ω · t + φ) = 0
```

Скоротивши на скалярний часовий множник `cos(ω · t + φ) ≠ 0`, дістаємо алгебраїчну **узагальнену проблему власних значень**:

```
(K − ω² · M) · v = 0
```

Ця однорідна система `N` лінійних алгебраїчних рівнянь відносно елементів вектора `v` має ненульовий розв'язок `v ≠ 0` тоді і тільки тоді, коли матриця системи `(K − ω² · M)` є виродженою, тобто її детермінант дорівнює нулю. Це дає характеристичне **вікове рівняння**:

```
det(K − ω² · M) = 0
```

Розкриття цього детермінанта відносно змінної `λ = ω²` дає алгебраїчний поліном ступеня `N`. Доведемо дві фундаментальні теореми про корені цього рівняння:

### Теорема 1: Усі корені `λ = ω²` є строго дійсними числами
Припустимо протилежне: нехай існує комплексний корінь `λ = ω² = α + i·β` з відповідним комплексним власним вектором `v = u + i·w`.

Запишемо рівняння власних значень: `K · v = λ · M · v`. Домножимо це рівняння зліва на сопряженно-транспонований вектор `v*ᵀ`:

```
v*ᵀ · K · v = λ · (v*ᵀ · M · v)
```

Оскільки матриці `M` та `K` є дійсними й симетричними, скалярні квадратичні форми `A = v*ᵀ · K · v` та `B = v*ᵀ · M · v` є строго дійсними й додатними числами (`A > 0`, `B > 0`). 

Отже, `λ = A / B` є відношенням двох дійсних додатних чисел. Це означає, що `λ = ω²` є **суворо дійсним і додатним числом** (`λ > 0`, `β = 0`).

### Теорема 2: Власні частоти `ω_r = √(λ_r)` є дійсними
Оскільки `λ_r = ω_r² > 0`, усі `N` власних частот `ω_r = √(λ_r)` (`r = 1, 2, ..., N`) є дійсними додатними числами. Це гарантує, що малі коливання консервативної системи поблизу стійкої рівноваги завжди залишаються обмеженими й не призводять до експоненційного зростання амплітуди.

## 3. Ортогональність модальних векторів

Власні вектори `v_r` та `v_s`, які відповідають двом різним власним частотам `ω_r ≠ ω_s`, володіють властивістю **ортогональності відносно матриць мас та жорсткості**.

Запишемо рівняння власних значень для двох різних мод `r` та `s`:

```
K · v_r = ω_r² · M · v_r
K · v_s = ω_s² · M · v_s
```

Домножимо перше рівняння зліва на транспонований вектор `v_sᵀ`, а друге рівняння — на `v_rᵀ`:

```
v_sᵀ · K · v_r = ω_r² · (v_sᵀ · M · v_r)
v_rᵀ · K · v_s = ω_s² · (v_rᵀ · M · v_s)
```

З огляду на симетрію матриць `M = Mᵀ` та `K = Kᵀ`, транспонування скалярів дає: `v_rᵀ · K · v_s = v_sᵀ · K · v_r` та `v_rᵀ · M · v_s = v_sᵀ · M · v_r`. Віднімемо друге рівняння від першого:

```
(ω_r² − ω_s²) · (v_sᵀ · M · v_r) = 0
```

Оскільки за припущенням частоти є різними (`ω_r² ≠ ω_s²`), скалярний добуток обов'язково дорівнює нулю. Це доводить **умови ортогональності мод**:

```
v_sᵀ · M · v_r = 0      [при r ≠ s]
v_sᵀ · K · v_r = 0      [при r ≠ s]
```

Онормуємо кожен модальний вектор `v_r` так, щоб `v_rᵀ · M · v_r = 1` (масова нормування). Тоді умови ортогональності й нормування записуються єдиною формулою через символ Кронекера `δ_rs`:

```
v_sᵀ · M · v_r = δ_rs
v_sᵀ · K · v_r = ω_r² · δ_rs
```

## 4. Одночасна діагоналізація та перехід до нормальних координат

Складемо з `N` ортонормованих векторів-стовпців `v_1, v_2, ..., v_N` квадратну **модальну матрицю** `T` розміру `N × N`:

```
T = [ v_1 | v_2 | ... | v_N ]
```

Співвідношення ортогональності у матричному вигляді приймають вигляд одночасної діагоналізації двох квадратичних форм:

```
Tᵀ · M · T = I           [одинична матриця розміру N x N]
Tᵀ · K · T = Ω²          [діагональна матриця квадратів частот: diag(ω₁², ω₂², ..., ω_N²)]
```

Виконаємо лінійне перетворення координат від початкових фізичних координат `x` до **нормальних координат** `η = (η₁, η₂, ..., η_N)ᵀ`:

```
x(t) = T · η(t) = ∑ v_r · η_r(t)
```

Підставимо заміну `x = T · η` у функцію Лагранжа системи `L = (1/2) · ẋᵀ · M · ẋ − (1/2) · xᵀ · K · x`:

```
L = (1/2) · η̈ᵀ · (Tᵀ · M · T) · η̈ − (1/2) · ηᵀ · (Tᵀ · K · T) · η
```

Застосовуючи умови діагоналізації `Tᵀ · M · T = I` та `Tᵀ · K · T = Ω²`, функція Лагранжа розпадається на суму `N` незалежних доданків:

```
L = (1/2) · ∑ (η̇_r² − ω_r² · η_r²)
```

Рівняння Ейлера — Лагранжа для кожної нормальної координати `η_r` приймають вигляд повністю розчеплених рівнянь незалежних гармонічних осциляторів:

```
η̈_r + ω_r² · η_r = 0      [для r = 1, 2, ..., N]
```

Загальний розв'язок для кожної нормальної координати:

```
η_r(t) = C_r · cos(ω_r · t + φ_r)
```

Повертаючись до початкових фізичних координат `x(t) = T · η(t)`, отримуємо точний аналітичний розв'язок для руху кожної частини системи:

```
x(t) = ∑ C_r · v_r · cos(ω_r · t + φ_r)
```

де амплітуди `C_r` та фази `φ_r` знаходять із початкових умов через скалярний добуток `η(0) = Tᵀ · M · x(0)`.

## 5. Детальний покроковий приклад розрахунку системи з 3 мас

Розглянемо три однакові маси `m₁ = m₂ = m₃ = m`, з'єднані послідовно пружинами жорсткістю `k` між собою та нерухомими стінами (симетрична 3-масова система).

```
Матриця мас: M = m · I_3

Матриця жорсткості:
    [  2k  -k   0 ]
K = [ -k   2k  -k ]
    [  0  -k   2k ]
```

Знайдемо власні частоти з вікового рівняння `det(K − ω² M) = 0`. Покладемо безрозмірну змінну `λ = m · ω² / k`:

```
det [ 2-λ   -1     0  ]
    [ -1   2-λ    -1  ] = 0
    [  0    -1   2-λ  ]
```

Розкриваємо детермінант по першому рядку:

```
(2 - λ) · ((2 - λ)² - 1) - (-1) · (-1 · (2 - λ))
= (2 - λ) · ((2 - λ)² - 1 - 1)
= (2 - λ) · ((2 - λ)² - 2) = 0      [розкладено на множники]
```

Прирівнюючи кожен множник до нуля, отримуємо три корені для `λ`:

```
λ₁ = 2 - √2    ⇒    ω₁ = √((2 - √2) · k / m) ≈ 0.765 · √(k/m)   [синфазна мода]
λ₂ = 2         ⇒    ω₂ = √(2 · k / m)        ≈ 1.414 · √(k/m)   [протифазна мода]
λ₃ = 2 + √2    ⇒    ω₃ = √((2 + √2) · k / m) ≈ 1.848 · √(k/m)   [високочастотна мода]
```

Підставивши значення `λ_r` у систему алгебраїчних рівнянь `(K − λ_r · (k/m) · M) · v_r = 0`, знаходимо відповідні власні вектори (модальні форми):

```
Мода 1 (найнижча частота ω₁ = 0.765 √(k/m)):
v_1 = (1,  √2,  1)ᵀ        [усі 3 маси рухаються в один бік; центральна маса має в √2 разів більший розмах]

Мода 2 (середня частота ω₂ = 1.414 √(k/m)):
v_2 = (1,   0, -1)ᵀ        [центральна маса нерухома у вузлі; крайні маси коливаються у точній протифазі]

Мода 3 (найвища частота ω₃ = 1.848 √(k/m)):
v_3 = (1, -√2,  1)ᵀ        [суміжні маси рухаються у протилежні боки з максимальним стисненням пружин]
```

Цей приклад ілюструє загальну теорему Rayleigh: **що більше вузлів (точок нульового зсуву) має модальна форма, то вища її власна частота `ω_r`**. Почергове зростання кількості вузлів від 0 до `N-1` визначає впорядкування частотного спектра будь-якої зв'язаної системи.
