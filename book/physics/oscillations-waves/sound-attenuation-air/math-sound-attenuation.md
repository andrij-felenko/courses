# 🧮 Фізико-математична модель загасання звуку в повітрі

Математичне описування загасання акустичних хвиль в атмосферному повітрі базується на об'єднанні механіки суцільних дисипативних середовищ із двостановою квантово-термодинамічною теорією молекулярної релаксації. Сумарний коефіцієнт поглинання звуку в реальній атмосфері складається з двох фундаментальних компонентів: класичного термов'язкого поглинання Стокса–Кірхгофа та молекулярного релаксаційного поглинання, викликаного збудженням коливальних ступенів вільності двоатомних молекул кисню та азоту. Точний розрахунок коефіцієнта поглинання регламентовано стандартом ISO 9613-1.

```
Повний коефіцієнт поглинання α = α_cl + α_vib,O + α_vib,N
  ├── α_cl: термов'язке поглинання Стокса–Кірхгофа (∝ f²)
  ├── α_vib,O: релаксаційний внесок молекул кисню O₂ (пік на f_r,O)
  └── α_vib,N: релаксаційний внесок молекул азоту N₂ (пік на f_r,N)
```

## 1. Класичне дисипативне хвильове рівняння та межа Стокса–Кірхгофа

У недисипативному ідеальному газі поширення плоскої акустичної хвилі описується класичним одновимірним хвильовим рівнянням для малого звукового тиску `p(x, t)`:

```
∂²p / ∂t² − c₀² · ∂²p / ∂x² = 0
```

де `c₀ = √(γ · R · T / M)` — адіабатична швидкість звуку в ідеальному газі, `γ = C_p / C_v` — показник адіабати, `R` — універсальна газова стала, `T` — абсолютна температура в Кельвінах, `M` — молярна маса газу.

Однак у реальному атмосферному повітрі необхідно враховувати два класичні незворотні транспортні процеси: внутрішнє тертя між рухомими шарами газу (в'язкість) та незворотний теплообмін між стисненими й розрядженими ділянками (теплопровідність). Враховуючи зсувну в'язкість `η`, об'ємну в'язкість `η_v` та теплопровідність `κ`, рівняння руху Нав'є–Стокса для стисливого газу разом із рівнянням неперервності та рівнянням теплопровідності перетворюються на дисипативне хвильове рівняння третього порядку:

```
∂²p / ∂t² − c₀² · ∂²p / ∂x² − b · ∂³p / ∂x²∂t = 0
```

Тут параметр ефективної дисипації середовища `b` визначається комбінацією механічних та теплових коефіцієнтів перенесення газу:

```
b = (1 / ρ₀) · [ (4/3)·η + η_v + κ·(γ − 1) / C_p ]
```

де `ρ₀` — рівноважна густина повітря при даній температурі й тиску, `C_p` — питома теплоємність газу при сталому тиску.

Шукаючи розв'язок дисипативного хвильового рівняння у вигляді плоскої монохроматичної хвилі з циклічною частотою `ω = 2·π·f`:

```
p(x, t) = P₀ · e^(i·(k·x − ω·t))
```

де `k` — комплексне хвильове число, що має вигляд `k = (ω / c) + i·α_cl`. У наближенні слабкого поглинання на довжину хвилі (умова `α_cl « ω / c₀`, яка виконується для чутних частот у повітрі з величезним запасом) ми отримуємо квадратне дисперсійне рівняння для хвильового числа `k`. Розділяючи дійсну та уявну частини розв'язку, отримуємо формулу Стокса–Кірхгофа для класичного коефіцієнта поглинання `α_cl` (вираженого в Неперах на метр):

```
α_cl = (ω² / (2 · ρ₀ · c₀³)) · [ (4/3)·η + η_v + κ·(γ − 1) / C_p ]
```

Оскільки циклічна частота `ω = 2·π·f`, класичне поглинання строго пропорційне квадрату частоти звуку `f²`:

```
α_cl = A_cl · f²
```

Для сухого повітря при температурі `T = 293.15 K` (20 °C) та стандартному тиску `p₀ = 101.325 kPa` значення класичного коефіцієнта становить `A_cl ≈ 1.60 × 10⁻¹₀ дБ/(м·Гц²)`. Це означає, що для частоти 1 кГц класичне поглинання становить лише `0.00016 дБ/км`, проте для ультразвукової частоти 100 кГц воно зростає до `1.6 дБ/м` (`1600 дБ/км`).

Тепловий та в'язкий градієнти також створюють так звані в'язкі та теплові примежові шари біля твердих поверхонь і підстильної поверхні землі. Товщина в'язкого примежового шару `δ_v` та теплового примежового шару `δ_t` виражаються через кінематичну в'язкість `ν = η / ρ₀` та температуропровідність `χ = κ / (ρ₀ · C_p)`:

```
δ_v = √(2 · ν / ω)
δ_t = √(2 · χ / ω)
```

На частоті 1 кГц у повітрі товщина цих примежових шарів становить близько `0.07 мм`. При поширенні звуку вздовж шорсткої поверхні землі дисипація енергії в цих шарах значно перевищує об'ємні класичні втрати.

## 2. Модель двостанової термодинамічної релаксації Айнштайна–Кнеснера

Класична теорія Стокса–Кірхгофа припускає, що поступальні, обертальні та коливальні ступені вільності молекул перебувають у миттєвій термодинамічній рівновазі. Проте для двоатомних молекул азоту (`N₂`) та кисню (`O₂`) обмін енергією між поступальним рухом всієї молекули та внутрішніми між атомними коливаннями вимагає скінченного часу.

Уявімо двостанову модель молекули, яка може перебувати або в основному коливальному стані з енергією `E₀`, або у першому збудженому коливальному стані з енергією `E₁ = E₀ + h·ν`. Рівноважна населеність першого збудженого стану `n₁` визначається класичним розподілом Больцмана:

```
n₁ / n₀ = exp(− ΔE / (k_B · T))
```

При проходженні звукової хвилі температура поступального руху газу `T(t)` коливається за гармонічним законом навколо рівноважного значення. Рівняння релаксації для внутрішньої коливальної енергії одиниці маси газу `E_vib(t)` має вигляд фундаментального кінетичного рівняння першого порядку:

```
d E_vib / dt = − (E_vib(t) − E_eq(T(t))) / τ
```

де `E_eq(T(t))` — миттєве рівноважне значення коливальної енергії при даній поступальній температурі `T(t)`, а `τ` — характерний **час релаксації** даної коливальної моди.

Згідно з квантово-механічною теорією Ландау–Теллера, ймовірність `P_10` деактивації коливального кванта при зіткненні молекул обернено пропорційна експоненті кубічного кореня з температури:

```
P_10 ∝ exp(− C_LT · T^(−1/3))
```

Цей результат пояснює наявність терму `(T_*)⁻¹ᐟ³` у стандартних формулах ISO 9613-1 для розрахунку частоти релаксації азоту.

Підставляючи гармонічну зміну температури `T(t) = T₀ + ΔT · e^(−i·ω·t)` у кінетичне рівняння релаксації, отримуємо, що коливальна енергія змінюється за законом:

```
ΔE_vib(t) = (C_vib · ΔT) / (1 − i · ω · τ)
```

де `C_vib = dE_eq / dT` — рівноважна питома теплоємність коливальних ступенів вільності.

Унаслідок цього ефективна повна теплоємність газу при сталому об'ємі `C_v(ω)` стає комплексною величиною, що залежить від циклічної частоти звукової хвилі `ω`:

```
C_v(ω) = C_v,∞ + C_vib / (1 − i · ω · τ)
```

де `C_v,∞` — «нескінченночастотна» теплоємність газу, яка враховує лише миттєві ступені вільності (поступальні та обертальні).

Комплексний характер теплоємності призводить до того, що адіабатичний модуль стисливості газу `K(ω)` також стає комплексним:

```
K(ω) = K₀ + ΔK · (i · ω · τ) / (1 − i · ω · τ)
```

Уявна частина комплексного модуля стисливості описує фазовий зсув між акустичним тиском і густиною газу. Підстановка комплексного модуля стисливості у хвильове рівняння дає формулу для релаксаційного коефіцієнта поглинання `α_relax`:

```
α_relax = (Δc / c₀) · (ω² · τ) / (1 + ω² · τ²)
```

Переходячи від циклічної частоти `ω` до лінійної частоти `f` (де `ω = 2·π·f`) та ввівши **частоту релаксації** `f_r = 1 / (2·π·τ)`, релаксаційну формулу подають у стандартному лоренцівському вигляді:

```
α_relax = A_relax · (f_r · f²) / (f_r² + f²)
```

Лоренцівський фактор `(f_r · f²) / (f_r² + f²)` володіє фундаментальними асимптотичними властивостями:
- На низьких частотах (`f « f_r`): знаменник наближається до `f_r²`, отже поглинання зростає квадратично: `α_relax ≈ (A_relax / f_r) · f²`.
- На високих частотах (`f » f_r`): чисельник і знаменник скорочуються по `f²`, отже поглинання виходить на постійне плато: `α_relax ≈ A_relax · f_r = const`.
- Безрозмірне поглинання на одну довжину хвилі `μ = α · λ` досягає свого абсолютного максимуму саме при збігу частоти звуку з частотою релаксації: `f = f_r`.

Математичне співвідношення між коефіцієнтом поглинання у Неперах на метр `α_Np` та у Децибелах на метр `α_dB` виводиться строго з логарифмічного визначення рівня звукового тиску. Оскільки амплітуда спадає як `P(x) = P₀ * exp(-α_Np * x)`, логарифм відношення тисків за основою 10 становить:

```
L_p = 20 * log10(P(x) / P₀) = 20 * log10(exp(-α_Np * x)) = - 20 * α_Np * x * log10(e)
```

Оскільки `20 * log10(e) = 20 / ln(10) ≈ 8.685889638`, коефіцієнт переведення дорівнює точній математичній константі `8.686`.

Зсув фази між тиском і густиною неминуче супроводжується **дисперсією швидкості звуку** (зміною фазової швидкості залежно від частоти `c(ω)`), що пов'язано з інтегральним співвідношенням Крамерса–Кроніга:

```
c(ω) = c₀ + Δc · (ω² · τ²) / (1 + ω² · τ²)
```

Для чутних частот у повітрі відносна зміна швидкості `Δc / c₀` не перевищує `0.1%`, однак при високих акустичних вимірюваннях ця дисперсія створює додатковий зсув фази.

## 3. Математичний апарат стандарту ISO 9613-1

Стандарт ISO 9613-1 об'єднує класичний термов'язкий внесок Стокса–Кірхгофа та двостаново-релаксаційні внески кисню `O₂` та азоту `N₂` у єдину математичну модель.

### 3.1. Базові вхідні змінні та нормування

Вхідні параметри навколишнього середовища:
- `t` — температура повітря у градусах Цельсія (°C). Абсолютна температура в Кельвінах: `T = t + 273.15`.
- `p_kPa` — атмосферний тиск у кілопаскалях (кПа).
- `h_r` — відносна вологість повітря у відсотках (`0 < h_r ≤ 100`).
- `f` — акустична частота у Гертцах (Гц).

Нормувальні довідкові константи:
- `T_pr = 293.15 K` (стандартна температура 20 °C).
- `T_01 = 273.16 K` (потрійна точка води).
- `p_pr = 101.325 kPa` (стандартний атмосферний тиск 1 атм).

Безрозмірні відносні параметри:
```
p_* = p_kPa / p_pr
T_* = T / T_pr
```

### 3.2. Розрахунок молярної концентрації вологи h

1. Безрозмірний насичений тиск водяної пари `p_sat / p_pr` обчислюється за апроксимаційним рівнянням Великої Британії/NPL:

```
log₁₀(p_sat / p_pr) = −6.8346 · (T_01 / T)¹˙²⁶¹ + 4.6151
```

2. Молярна концентрація водяної пари `h` (у відсотках %):

```
h = h_r · (p_sat / p_pr) / p_*
```

### 3.3. Частоти релаксації кисню f_r,O та азоту f_r,N

Частота релаксації кисню `f_r,O` (у Гц):

```
f_r,O = p_* · [ 24 + 4.04 × 10⁴ · h · (0.02 + h) / (0.391 + h) ]
```

Частота релаксації азоту `f_r,N` (у Гц):

```
f_r,N = p_* · (T_*)⁻⁰˙⁵ · [ 9 + 280 · h · exp(−4.17 · ((T_*)⁻¹ᐟ³ − 1)) ]
```

### 3.4. Підсумкове рівняння для коефіцієнта загасання α (дБ/м)

Підсумкова формула ISO 9613-1 обчислює коефіцієнт загасання `α` у децибелах на метр (дБ/м):

```
α = 8.686 · f² · [ α_cl_term + α_O_term + α_N_term ]
```

де трьохкомпонентні складові у дужках розраховуються за формулами:

```
α_cl_term = 1.84 × 10⁻¹¹ · (p_*)⁻¹ · (T_*)⁰˙⁵
α_O_term  = (T_*)⁻²˙⁵ · 0.1068 · exp(−3352 / T) · [ f_r,O / (f_r,O² + f²) ]
α_N_term  = (T_*)⁻²˙⁵ · 0.01275 · exp(−2239.1 / T) · [ f_r,N / (f_r,N² + f²) ]
```

Множник `8.686` відповідає точному переведенню між Неперами та Децибелами (`20 / ln(10)`).

Для переведення у децибели на кілометр (дБ/км) підсумкове значення множиться на `1000`: `α_dB_km = α · 1000`.

## 4. Покроковий числовий приклад розрахунку

Здійснімо повний математичний розрахунок загасання для конкретних практичних умов:
- Частота звукової хвилі `f = 4000 Hz` (4 кГц).
- Температура повітря `t = 20 °C` (`T = 293.15 K`, отже `T_* = 1.000`).
- Атмосферний тиск `p_kPa = 101.325 kPa` (отже `p_* = 1.000`).
- Відносна вологість `h_r = 50 %`.

### Крок 1: Обчислення тиску насиченої пари та концентрації вологи h

Розраховуємо відношення температур та десятковий логарифм:

```
T_01 / T = 273.16 / 293.15 = 0.93181                                [ділення потрійної точки води на T]
(0.93181)¹˙²⁶¹ = 0.91456                                           [піднесення до степеня 1.261]
log₁₀(p_sat / p_pr) = −6.8346 · 0.91456 + 4.6151 = −1.6347          [підстановка за формулою NPL]
p_sat / p_pr = 10⁻¹˙⁶³⁴⁷ ≈ 0.02319                                 [знаходження потенційного тиску пари]
h = 50 · 0.02319 / 1.000 = 1.1595 %                                 [молярна концентрація вологи h]
```

### Крок 2: Обчислення частот релаксації f_r,O та f_r,N

Для кисню `f_r,O`:

```
f_r,O = 1.000 · [ 24 + 4.04 × 10⁴ · 1.1595 · (0.02 + 1.1595) / (0.391 + 1.1595) ]  [формула релаксації O₂]
      = 24 + 40400 · 1.1595 · 1.1795 / 1.5505                                     [підстановка h = 1.1595]
      = 24 + 40400 · 0.8820                                                       [обчислення раціонального дробу]
      = 24 + 35633 = 35657 Hz ≈ 35.66 kHz                                         [підсумкова частота f_r,O]
```

Для азоту `f_r,N`:

```
f_r,N = 1.000 · (1.000)⁻⁰˙⁵ · [ 9 + 280 · 1.1595 · exp(−4.17 · ((1.000)⁻¹ᐟ³ − 1)) ] [формула релаксації N₂]
      = 9 + 280 · 1.1595 · exp(0)                                                 [враховуючи T_* = 1]
      = 9 + 324.66 = 333.66 Hz ≈ 333.7 Hz                                         [підсумкова частота f_r,N]
```

### Крок 3: Обчислення трьох складових поглинання

1. Класичний термов'язкий внесок `α_cl_term`:

```
α_cl_term = 1.84 × 10⁻¹¹ · 1.000 · 1.000 = 1.84 × 10⁻¹¹              [класична термов'язка складова]
```

2. Внесок релаксації кисню `α_O_term`:

```
exp(−3352 / 293.15) = exp(−11.4344) ≈ 1.0817 × 10⁻⁵                [експоненціальний температурний фактор O₂]
f_r,O / (f_r,O² + f²) = 35657 / (35657² + 4000²) ≈ 2.7696 × 10⁻⁵    [лоренцівський частотний фактор O₂]
α_O_term = 1.000 · 0.1068 · (1.0817 × 10⁻⁵) · (2.7696 × 10⁻⁵)       [добуток факторів для кисню]
         = 3.199 × 10⁻¹¹                                           [підсумковий внесок кисню]
```

3. Внесок релаксації азоту `α_N_term`:

```
exp(−2239.1 / 293.15) = exp(−7.6381) ≈ 4.8175 × 10⁻⁴                [експоненціальний температурний фактор N₂]
f_r,N / (f_r,N² + f²) = 333.66 / (333.66² + 4000²) ≈ 2.0710 × 10⁻⁵  [лоренцівський частотний фактор N₂]
α_N_term = 1.000 · 0.01275 · (4.8175 × 10⁻⁴) · (2.0710 × 10⁻⁵)     [добуток факторів для азоту]
         = 1.272 × 10⁻¹⁰                                           [підсумковий внесок азоту]
```

### Крок 4: Підсумковий розрахунок α

Сумуємо всі три складові у дужках:

```
Sum = α_cl_term + α_O_term + α_N_term                              [сума трьох складових у дужках]
    = 0.184 × 10⁻¹⁰ + 0.320 × 10⁻¹⁰ + 1.272 × 10⁻¹⁰                [зведення до спільного порядку 10⁻¹⁰]
    = 1.776 × 10⁻¹⁰                                                [підсумкова сума]
```

Множимо на `8.686 · f²`:

```
f² = 4000² = 1.6 × 10⁷                                             [квадрат частоти 4 кГц]
α = 8.686 · (1.6 × 10⁷) · (1.776 × 10⁻¹⁰)                           [множення на децибельний коефіцієнт]
  = 1.38976 × 10⁸ · 1.776 × 10⁻¹⁰                                   [проміжний добуток]
  = 0.02468 дБ/м                                                   [коефіцієнт загасання у дБ/м]
```

Переводимо у децибели на кілометр:

```
α_dB_km = 0.02468 · 1000 = 24.68 дБ/км                              [коефіцієнт загасання у дБ/км]
```

**Фізичний висновок:** На частоті 4 кГц при нормальних умовах (20 °C, 50 % вологості) звук втрачає **24.68 дБ на кожний кілометр** шляху виключно через поглинання атмосферою, незалежно від геометричного розходження хвиль. При цьому релаксація азоту дає ~71.6% втрат, релаксація кисню ~18.0%, а класичні термов'язкі втрати Стокса-Кірхгофа — ~10.4%.
