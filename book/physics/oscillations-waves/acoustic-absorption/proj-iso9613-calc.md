# ⚙️ Реалізація розрахунку атмосферного поглинання звуку за стандартом ISO 9613-1

Ця проектна вставка містить практичну алгоритмічну реалізацію розрахунку коефіцієнта поглинання звуку у повітрі відповідно до міжнародного стандарту **ISO 9613-1** (ANSI S1.26). Наведено деталізований аналіз алгоритму, покрокову розшифровку математичних етапів та ідіоматичний вихідний код мовами C та C++.

## 1. Покроковий алгоритмічний аналіз ISO 9613-1

Алгоритм стандарту ISO 9613-1 розраховує коефіцієнт згасання звукової хвилі `α` у децибелах на кілометр (дБ/км) на основі чотирьох фізичних параметрів атмосферного середовища: частоти акустичного сигналу `f`, температури повітря `T_degC`, відносної вологості `RH` та барометричного тиску `p_a`.

Обчислювальний процес розбито на п'ять послідовних розрахункових етапів, кожен з яких відображає конкретну фізичну величину стан середовища.

### Крок 1. Переведення одиниць та термодинамічна нормалізація

На першому етапі вхідна температура повітря переводиться з градусів Цельсія у абсолютні Кельвіни: `T = T_degC + 273.15`. Після цього вираховується безрозмірне відношення температур `Tr = T / T₀`, де `T₀ = 293.15 К` (20 °C) — базова відлікова температура стандарту ISO 9613-1. Аналогічним чином барометричний тиск середовища нормалізується відносно стандартного атмосферного тиску на рівні моря `101.325 кПа`: `pr = p_a / 101.325`. Ця нормалізація дозволяє безпосередньо масштабувати обчислення при використанні даних у гірській місцевості або на різних висотах польоту.

### Крок 2. Розрахунок тиску насиченої водяної пари

Тиск насиченої пари вологи над чистою гладкою поверхнею води `p_sat` обчислюється за емпіричною формулою Екслера (Wexler formula), яка рекомендована стандартом ISO 9613-1 для діапазону температур від `-20 °C` до `+50 °C`. Ця формула є фундаментальною для термодинаміки вологого повітря, оскільки вона визначає максимальну кількість водяної пари, яку газова суміш здатна утримувати у стані фазової рівноваги при даній температурі:

```
p_sat_pr = 10^( -6.8346 · (T₀₁ / T)^1.261 + 4.6151 )      [формула насиченого тиску вологи]
```

де `T₀₁ = 273.16 К` — температура потрійної точки води у шкалі Кельвіна.

### Крок 3. Перерахунок відносної вологості у молярну концентрацію

Оскільки молекулярний обмін енергією під час зіткнень залежить від кількості молекул `H₂O`, а не від відносної вологості, алгоритм здійснює перерахунок відносної вологості `RH` (%) у молярний відсоток водяної пари `h` (%):

```
h = RH · (p_sat_pr / pr)      [молярна концентрація водяної пари]
```

Для абсолютно сухого повітря у коді встановлюється нижнє підлогове значення `h = 1e-6` %, що запобігає виникненню ділення на нуль чи математичної невизначеності при обчисленні частот релаксації.

### Крок 4. Розрахунок частот релаксації кисню та азоту

Частота релаксації кисню `f_r,O2` (Гц) обчислюється з урахуванням парних зіткнень з молекулами водяної пари, які виступають каталізатором обміну енергією:

```
f_r,O2 = pr · [ 24 + 4.04×10⁴ · h · (0.02 + h) / (0.391 + h) ]   [частота релаксації кисню]
```

Частота релаксації азоту `f_r,N2` (Гц) обчислюється з урахуванням температурної залежності ефективного перерізу молекулярних зіткнень:

```
f_r,N2 = pr · Tr^(-0.5) · [ 9 + 280 · h · exp( -4.170 · (Tr^(-1/3) - 1) ) ]  [частота релаксації азоту]
```

### Крок 5. Обчислення підсумкового коефіцієнта поглинання

Сумарне поглинання (у децибелах на кілометр) обчислюється як сума трьох фізичних внесків: класичного внеску Стокса — Кірхгофа, релаксації кисню та релаксації азоту:

```
α = f² · [ 1.84×10⁻¹¹ · (pr)⁻¹ · (Tr)¹/² + (Tr)⁻⁵/² · ( A_O2 · f_rO2 / (f_rO2² + f²) + A_N2 · f_rN2 / (f_rN2² + f²) ) ]
```

де `A_O2 = 0.01275 · exp(-2239.1 / T)` та `A_N2 = 0.10680 · exp(-3352.0 / T)` — амплітудні коефіцієнти коливальних мод відповідно для кисню та азоту.

## 2. Програмна реалізація мовами C та C++

Нижче наведено повну реалізацію алгоритму мовами C та C++. Код мовою C призначений для систем із жорсткими обмеженнями на обсяг пам'яті (мікроконтролери ARM Cortex-M, DSP-процесори), тоді як код мовою C++20 використовує сучасні концепції безнаплічних зрізів пам'яті `std::span`, строгової типобезпеки та обробки помилок за допомогою `std::expected`.

```c
/* iso9613_calc.c — Реалізація стандарту ISO 9613-1 мовою C */
#include <stdio.h>
#include <math.h>

typedef struct {
    double temp_c;      /* Температура повітря у °C (-20..+50) */
    double rh_percent;  /* Відносна вологість у % (0..100) */
    double pressure_kpa;/* Атмосферний тиск у кПа (наприклад, 101.325) */
} iso9613_env_t;

/* Обчислення коефіцієнта поглинання у дБ/км для заданої частоти f (Гц) */
double iso9613_attenuation_db_per_km(double f_hz, const iso9613_env_t *env) {
    if (f_hz <= 0.0 || env == NULL) {
        return 0.0;
    }

    double T_k = env->temp_c + 273.15;
    double T0 = 293.15;      /* 20 °C у Кельвінах */
    double T01 = 273.16;     /* Потрійна точка води */
    
    double pr = env->pressure_kpa / 101.325; /* Відносний тиск */
    double Tr = T_k / T0;                    /* Відносна температура */

    /* Тиск насиченої пари вологи (ISO 9613-1 рівняння B.1) */
    double exponent = -6.8346 * pow(T01 / T_k, 1.261) + 4.6151;
    double p_sat_pr = pow(10.0, exponent);

    /* Молярна концентрація водяної пари h (%) */
    double h = env->rh_percent * (p_sat_pr / pr);
    if (h < 1e-6) {
        h = 1e-6; /* Захист від нуля для сухого повітря */
    }

    /* Частота релаксації кисню f_r,O2 (Гц) */
    double fr_O2 = pr * (24.0 + 4.04e4 * h * (0.02 + h) / (0.391 + h));

    /* Частота релаксації азоту f_r,N2 (Гц) */
    double fr_N2 = pr * pow(Tr, -0.5) * 
                   (9.0 + 280.0 * h * exp(-4.170 * (pow(Tr, -1.0 / 3.0) - 1.0)));

    /* Класичний внесок та в'язкісна теплопровідність */
    double alpha_class = 1.84e-11 * (1.0 / pr) * sqrt(Tr);

    /* Коливальні амплітуди молекул кисню та азоту */
    double A_O2 = 0.01275 * exp(-2239.1 / T_k);
    double A_N2 = 0.10680 * exp(-3352.0 / T_k);

    /* Релаксаційні внески */
    double alpha_O2 = pow(Tr, -2.5) * (A_O2 * fr_O2 / (fr_O2 * fr_O2 + f_hz * f_hz));
    double alpha_N2 = pow(Tr, -2.5) * (A_N2 * fr_N2 / (fr_N2 * fr_N2 + f_hz * f_hz));

    /* Загальний коефіцієнт поглинання у дБ/км */
    double alpha_db_km = 8.686 * f_hz * f_hz * (alpha_class + alpha_O2 + alpha_N2);

    return alpha_db_km;
}

int main(void) {
    iso9613_env_t env = { .temp_c = 20.0, .rh_percent = 50.0, .pressure_kpa = 101.325 };
    double freqs[] = { 125.0, 500.0, 1000.0, 4000.0, 8000.0, 40000.0 };
    size_t count = sizeof(freqs) / sizeof(freqs[0]);

    printf("Частота (Гц) | Поглинання (дБ/км) | Поглинання (дБ/м)\n");
    printf("--------------------------------------------------\n");
    for (size_t i = 0; i < count; ++i) {
        double db_km = iso9613_attenuation_db_per_km(freqs[i], &env);
        printf("%11.1f | %17.3f | %16.5f\n", freqs[i], db_km, db_km / 1000.0);
    }
    return 0;
}
```

```cpp
// iso9613_calc.cpp — Реалізація стандарту ISO 9613-1 мовою C++20
#include <iostream>
#include <cmath>
#include <vector>
#include <span>
#include <iomanip>
#include <expected>
#include <string_view>

namespace acoustics {

struct Environment {
    double temp_c{20.0};       // Температура повітря у °C
    double rh_percent{50.0};   // Відносна вологість у %
    double pressure_kpa{101.325}; // Тиск у кПа
};

enum class CalculationError {
    InvalidFrequency,
    InvalidHumidity,
    InvalidPressure
};

class AtmosphereAbsorption {
public:
    static std::expected<double, CalculationError> 
    calculate_db_per_km(double freq_hz, const Environment& env) noexcept {
        if (freq_hz <= 0.0) {
            return std::unexpected(CalculationError::InvalidFrequency);
        }
        if (env.rh_percent < 0.0 || env.rh_percent > 100.0) {
            return std::unexpected(CalculationError::InvalidHumidity);
        }
        if (env.pressure_kpa <= 0.0) {
            return std::unexpected(CalculationError::InvalidPressure);
        }

        const double T_k = env.temp_c + 273.15;
        constexpr double T0 = 293.15;
        constexpr double T01 = 273.16;

        const double pr = env.pressure_kpa / 101.325;
        const double Tr = T_k / T0;

        // Паровий тиск над водою за ISO 9613-1
        const double exponent = -6.8346 * std::pow(T01 / T_k, 1.261) + 4.6151;
        const double p_sat_pr = std::pow(10.0, exponent);

        // Молярна концентрація водяної пари h
        double h = env.rh_percent * (p_sat_pr / pr);
        if (h < 1e-6) h = 1e-6;

        // Частоти релаксації O2 та N2
        const double fr_O2 = pr * (24.0 + 4.04e4 * h * (0.02 + h) / (0.391 + h));
        const double fr_N2 = pr * std::pow(Tr, -0.5) * 
                             (9.0 + 280.0 * h * std::exp(-4.170 * (std::pow(Tr, -1.0 / 3.0) - 1.0)));

        // Компоненти згасання
        const double alpha_class = 1.84e-11 * (1.0 / pr) * std::sqrt(Tr);
        const double A_O2 = 0.01275 * std::exp(-2239.1 / T_k);
        const double A_N2 = 0.10680 * std::exp(-3352.0 / T_k);

        const double f2 = freq_hz * freq_hz;
        const double alpha_O2 = std::pow(Tr, -2.5) * (A_O2 * fr_O2 / (fr_O2 * fr_O2 + f2));
        const double alpha_N2 = std::pow(Tr, -2.5) * (A_N2 * fr_N2 / (fr_N2 * fr_N2 + f2));

        return 8.686 * f2 * (alpha_class + alpha_O2 + alpha_N2);
    }

    static void compute_spectrum(std::span<const double> frequencies, 
                                 const Environment& env, 
                                 std::span<double> output_db_km) {
        const size_t n = std::min(frequencies.size(), output_db_km.size());
        for (size_t i = 0; i < n; ++i) {
            auto res = calculate_db_per_km(frequencies[i], env);
            output_db_km[i] = res.value_or(0.0);
        }
    }
};

} // namespace acoustics

int main() {
    using namespace acoustics;

    Environment env{.temp_c = 20.0, .rh_percent = 50.0, .pressure_kpa = 101.325};
    const std::vector<double> freqs = {125.0, 500.0, 1000.0, 4000.0, 8000.0, 40000.0};
    std::vector<double> results(freqs.size());

    AtmosphereAbsorption::compute_spectrum(freqs, env, results);

    std::cout << std::fixed << std::setprecision(3);
    std::cout << "Частота (Гц) | Поглинання (дБ/км) | Поглинання (дБ/м)\n";
    std::cout << "--------------------------------------------------\n";
    for (size_t i = 0; i < freqs.size(); ++i) {
        std::cout << std::setw(11) << freqs[i] << " | "
                  << std::setw(17) << results[i] << " | "
                  << std::setw(16) << std::setprecision(5) << (results[i] / 1000.0) << "\n";
        std::cout << std::setprecision(3);
    }

    return 0;
}
```

## 3. Практичні аспекти інтеграції та архітектурні рішення

Під час впровадження стандарту ISO 9613-1 у реальні інженерні пакети (такі як геоінформаційні системи SoundPLAN, CadnaA або реалогемні двигуни розрахунку акустики приміщень) важливо враховувати кілька архітектурних нюансів.

Першим із них є поділ обчислень на атмосферно-інваріантну та частотно-залежну частини. Оскільки метеорологічні умови середовища (температура `T`, відносна вологість `RH` та барометричний тиск `p_a`) у більшості розрахункових сценаріїв є сталими для всього просторового об'єму чи кадру моделювання, тригонометричні та трансцендентні обчислення (`pow`, `exp`, `log10`) рекомендується виконувати **один раз на початку кадру** і зберігати у проміжній структурі стану. Для кожного з тисяч обчислювальних звукових променів чи акустичних джерел залишається виконати лише базове оцінювання двох дробово-раціональних функцій релаксаційного згасання, що прискорює загальну роботу обчислювального ядра у 15–20 разів.

Другим важливим аспектом є сумісність із векторами частотних смуг. Замість обчислення поглинання для кожної точкової частоти окремо, стандарти акустичного проектування вимагають обчислення у третьоктавних або октавних смугах (із центральними частотами від 31.5 Гц до 16 кГц). Використання безнаплічних зрізів пам'яті `std::span` у версії C++20 дозволяє передавати масиви спектральних даних без будь-якого виділення динамічної пам'яті чи копіювання векторів.

Третім аспектом є надійність роботи при субнульових температурах та екстремально низькій вологості. Алгоритм містить нижнє затискання молярної вологості `h = 1e-6`, що унеможливлює виникнення від'ємних чи нульових значень частот релаксації та захищає від виникнення математичної помилки ділення на нуль при роботі з абсолютно сухим повітрям.
