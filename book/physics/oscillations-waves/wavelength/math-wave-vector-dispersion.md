# 🧮 Хвильове число, хвильовий вектор та дисперсійне співвідношення

Математичний апарат хвильової фізики систематизує зв'язок між часовою періодичністю коливань (періодом `T` та кутовою частотою `ω`) і просторовою періодичністю (довжиною хвилі `λ` та хвильовим числом `k`). У цьому матеріалі детально виведено рівняння плоскої гармонічної хвилі, математичні властивості хвильового вектора, фазову та групову швидкості, а також розглянуто дисперсійні співвідношення для ключових фізичних середовищ.

### 1. Математичне виведення просторової хвильової функції та хвильового числа k

Розглянемо одновимірну гармонічну хвилю, яка поширюється вздовж додатної осі `x` зі сталою фазовою швидкістю `v`. Якщо у точці `x = 0` джерело здійснює гармонічні коливання за законом `u(0, t) = A · sin(ω·t + φ₀)`, то в довільній точці `x` коливання запізнюються на час `Δt = x / v`, який потрібен хвилі для подолання відстані `x`:

```
u(x, t) = A · sin(ω · (t - x/v) + φ₀)
```

Розкриємо дужки у фазовому аргументі синусоїди:

```
u(x, t) = A · sin(ω·t - (ω/v)·x + φ₀)
```

Коефіцієнт при координаті `x` називається **хвильовим числом** або **просторовою кутовою частотою** і позначається літерою `k`:

```
k = ω / v
```

Виразимо кутову частоту через період `ω = 2π / T`, а фазову швидкість — через довжину хвилі та період `v = λ / T`:

```
k = (2π / T) / (λ / T) = 2π / λ        [рад/м]
```

Звідси видно глибоку математичну симетрію між часовими та просторовими характеристиками хвилі:
- **Часова кутова частота** `ω = 2π / T` показує, на скільки радіанів змінюється фаза хвилі в одній точці простору за одиницю часу (1 секунду).
- **Просторова кутова частота (хвильове число)** `k = 2π / λ` показує, на скільки радіанів змінюється фаза хвилі в один момент часу при переміщенні вздовж простору на одиницю довжини (1 метр).

Завдяки цьому хвильова функція набуває симетричного просторово-часового вигляду:

```
u(x, t) = A · sin(k·x - ω·t + φ₀)
```

Знак мінус перед `ω·t` (або перед `k·x`) вказує на напрямок поширення хвилі в бік додатних значень осі `x`. Якщо хвиля поширюється в протилежний бік (вліво), знак змінюється на плюс: `u(x, t) = A · sin(k·x + ω·t + φ₀)`.

### 2. Строгий доказ просторової періодичності

Формально доведемо, що величина `λ = 2π / k` дійсно є просторовим періодом хвильової функції. Функція `u(x, t)` називається просторово періодичною з періодом `λ`, якщо для будь-яких `x` та `t` виконується тотожність `u(x + λ, t) = u(x, t)`.

Підставимо значення `x + λ` у хвильову функцію:

```
u(x + λ, t) = A · sin(k·(x + λ) - ω·t + φ₀)
            = A · sin(k·x + k·λ - ω·t + φ₀)
            = A · sin(k·x + (2π/λ)·λ - ω·t + φ₀)      [підставили k = 2π/λ]
            = A · sin(k·x + 2π - ω·t + φ₀)            [використовуємо періодичність синуса: sin(α + 2π) = sin(α)]
            = A · sin(k·x - ω·t + φ₀)
            = u(x, t)
```

Отже, просторовий період `λ` є найменшим додатним зсувом вздовж осі `x`, який повністю зберігає фазу та значення хвильової функції.

### 3. Хвильовий вектор k у тривимірному просторі

У тривимірному неоднорідному або багатовимірному просторі напрямок поширення хвильового фронту не обов'язково збігається з декартовими осями координат. Для опису напрямку та просторової частоти використовується **хвильовий вектор** `k`.

Вектор `k` спрямований перпендикулярно до ізофазної поверхні (хвильового фронту) у бік поширення фази, а його модуль дорівнює:

```
|k| = √(k_x² + k_y² + k_z²) = 2π / λ
```

Компоненти хвильового вектора `k_x`, `k_y`, `k_z` пов'язані з напрямними косинусами `cos(α)`, `cos(β)`, `cos(γ)` кутів між напрямком поширення хвилі та координатними осями:

```
k_x = (2π / λ) · cos(α)
k_y = (2π / λ) · cos(β)
k_z = (2π / λ) · cos(γ)
```

Тоді рівняння тривимірної плоскої гармонічної хвилі виражається через скалярний добуток хвильового вектора `k` на радіус-вектор точки `r = (x, y, z)`:

```
u(r, t) = A · sin(k · r - ω·t + φ₀) = A · sin(k_x·x + k_y·y + k_z·z - ω·t + φ₀)
```

У комплексній формі, яка є стандартом у теоретичній фізиці та радіотехніці, плоска хвиля записується як експонента з уявним показником:

```
u(r, t) = Re { A · exp( i·(k · r - ω·t + φ₀) ) }
```

Використання комплексної форми спрощує математичні операції диференціювання та інтегрування, оскільки просторовий градієнт перетворюється на множення на `i·k`, а часова похідна — на множення на `-i·ω`:

```
∇ u = i · k · u          [просторовий градієнт]
∂u / ∂t = -i · ω · u      [часова похідна]
```

### 4. Фазова швидкість та виведення хвильового рівняння

**Фазова швидкість** `vₚ` — це швидкість, з якою переміщується точка постійної фази у просторі. Позначимо повну фазу хвилі як `Φ(x, t) = k·x - ω·t + φ₀`. Вимога постійності фази означає:

```
Φ(x, t) = const
d/dt (k·x - ω·t + φ₀) = 0
k · (dx/dt) - ω = 0
dx/dt = ω / k
```

Отже, фазова швидкість за визначенням дорівнює:

```
vₚ = dx/dt = ω / k = f · λ
```

Знайдемо другі часткові похідні хвильової функції `u(x, t) = A · sin(k·x - ω·t)` за координатою та часом:

```
∂²u / ∂x² = -k² · A · sin(k·x - ω·t) = -k² · u
∂²u / ∂t² = -ω² · A · sin(k·x - ω·t) = -ω² · u
```

Поділимо часову похідну на просторову:

```
(∂²u / ∂t²) / (∂²u / ∂x²) = (-ω² · u) / (-k² · u) = ω² / k² = vₚ²
```

Переносячи члени, отримуємо класичне однорідне **хвильове рівняння Д'Аламбера**:

```
∂²u / ∂x² - (1 / vₚ²) · (∂²u / ∂t²) = 0
```

Це рівняння показує, що будь-який процес, описаний функцією вигляду `u(x, t) = f(x - vₚ·t)`, є хвилею, що поширюється зі швидкістю `vₚ`, а зв'язок між просторовими й часовими змінами строго визначається фазовою швидкістю.

### 5. Дисперсійне співвідношення та групова швидкість

Фундаментальне рівняння, яке пов'язує часову частоту `ω` з хвильовим числом `k`, називається **дисперсійним співвідношенням**:

```
ω = ω(k)
```

Функціональна форма `ω(k)` визначається фізичними властивостями середовища. Якщо `ω` строго пропорційне `k` (`ω = c · k`), фазова швидкість `vₚ = ω / k = c` є сталою величиною, яка не залежить від довжини хвилі. Таке середовище називається **недисперсійним**. Прикладом є світло у вакуумі чи акустичні хвилі малої амплітуди в ідеальному газі.

Якщо ж `ω(k)` є нелінійною функцією, середовище називається **дисперсійним**. У дисперсійному середовищі хвилі різної довжини `λ` поширюються з різними фазовими швидкостями `vₚ(λ)`.

Коли сигнал являє собою групу хвиль (хвильовий пакет або імпульс), що складається з вузького спектра частот коло центральної частоти `ω₀`, огинаюча цього пакета (яка переносить енергію та інформацію) переміщується з **груповою швидкістю** `v_g`:

```
v_g = dω / dk
```

### 6. Строге виведення формули Релея

Знайдемо математичний зв'язок між груповою швидкістю `v_g` та фазовою швидкістю `vₚ(k)`. За визначенням фазової швидкості `ω = k · vₚ(k)`. Диференціюємо цей добуток по `k`:

```
v_g = dω / dk = d/dk (k · vₚ) = vₚ + k · (dvₚ / dk)            [за правилом похідної добутку]
```

Перейдемо від хвильового числа `k` до довжини хвилі `λ`. Використаємо співвідношення `k = 2π / λ` і знайдемо похідну `dk / dλ`:

```
dk / dλ = d/dλ (2π / λ) = - 2π / λ²
```

За правилом диференціювання складеної функції:

```
dvₚ / dk = (dvₚ / dλ) / (dk / dλ) = (dvₚ / dλ) / (- 2π / λ²) = - (λ² / 2π) · (dvₚ / dλ)
```

Підставимо отриманий вираз та `k = 2π / λ` у формулу для `v_g`:

```
v_g = vₚ + (2π / λ) · [ - (λ² / 2π) · (dvₚ / dλ) ]
    = vₚ - λ · (dvₚ / dλ)
```

Ця формула називається **формулою Релея**. Вона дозволяє класифікувати дисперсійні явища у фізиці:
1. **Відсутність дисперсії (`dvₚ / dλ = 0`):** `v_g = vₚ`. Усі частотні складові імпульсу біжать з однаковою швидкістю, форма пакета не спотворюється.
2. **Нормальна дисперсія (`dvₚ / dλ > 0`):** Довші хвилі поширюються швидше за короткі (`dvₚ/dλ > 0`), тому `v_g < vₚ`. Окремі гребені всередині пакета зароджуються на хвості імпульсу, пробігають уперед і зникають на чолі пакета.
3. **Аномальна дисперсія (`dvₚ / dλ < 0`):** Короткі хвилі поширюються швидше за довші, тому `v_g > vₚ`.

### 7. Приклади розрахунку дисперсійних співвідношень у фізиці

#### А. Гравітаційно-капілярні хвилі на поверхні води

Для хвиль на поверхні рідини скінченної глибини `H` з урахуванням сили тяжіння `g` та поверхневого натягу `σ` точне дисперсійне співвідношення має вигляд:

```
ω² = (g·k + (σ/ρ)·k³) · th(k·H)
```

де `ρ` — густина рідини, `th` — гіперболічний тангенс.

Розглянемо випадок **глибокої води** (`H >> λ`, тоді `th(k·H) ≈ 1`) без урахування капілярних сил (`σ ≈ 0`):

```
ω² = g · k
ω(k) = √(g · k)
```

Знайдемо фазову швидкість:

```
vₚ = ω / k = √(g · k) / k = √(g / k) = √(g · λ / (2π) )
```

Обчислимо групову швидкість `v_g`:

```
v_g = dω / dk = d/dk (g · k)^(1/2) = (1/2) · g^(1/2) · k^(-1/2) = (1/2) · √(g / k) = (1/2) · vₚ
```

На глибокій воді довжина хвилі прямо визначає швидкість: морські хвилі з довжиною `λ = 100 м` біжать зі швидкістю `vₚ ≈ 12.5 м/с` (45 км/год), а групова швидкість енергії становить рівно половину фазової (`6.25 м/с`).

Для **мілководдя** (`H << λ`, тоді `th(k·H) ≈ k·H`):

```
ω² ≈ g · k · (k · H) = g · H · k²
ω ≈ √(g · H) · k
```

На мілкій воді дисперсія зникає: `vₚ = v_g = √(g · H)`. Усі хвилі (включаючи цунамі з довжиною хвилі у сотні кілометрів) поширюються з однаковою швидкістю, яка залежить лише від глибини океану `H`.

#### Б. Електромагнітні хвилі в плазмі та волноводах

Для поширення високочастотної електромагнітної хвилі в електроній плазмі (або у металевому прямокутному хвилеводі) дисперсійне рівняння виражається через плазмову частоту `ωₚ`:

```
ω² = ωₚ² + c² · k²
```

Визначимо фазову швидкість `vₚ`:

```
vₚ = ω / k = √(ωₚ² + c²·k²) / k = c · √(1 + ωₚ² / (c²·k²) ) > c
```

Знайдемо групову швидкість `v_g`, продиференціювавши дисперсійне рівняння за `k`:

```
d/dk (ω²) = d/dk (ωₚ² + c²·k²)
2·ω · (dω/dk) = 2·c²·k
dω/dk = c² · (k / ω) = c² / (ω / k) = c² / vₚ
```

Отримуємо фундаментальне співвідношення для хвилеводів та плазми:

```
vₚ · v_g = c²
```

Оскільки фазова швидкість фазового фронту перевищує швидкість світла у вакуумі (`vₚ > c`), групова швидкість переносу енергії сигналу обов'язково є меншою за швидкість світла: `v_g = c² / vₚ < c`. Це фундаментальне правило забезпечує дотримання принципу причинності спеціальної теорії відносності.

#### В. Квантові хвилі де Бройля для масивних частинок

У квантовій механіці будь-яка частинка з масою `m` та імпульсом `p` проявляє хвильові властивості з довжиною хвилі де Бройля `λ = h / p` та хвильовим числом `k = p / ℏ` (де `ℏ = h / (2π)` — зведена стала Планка).

Енергія вільної нерелятивістської частинки дорівнює `E = p² / (2m)`. Оскільки у квантовій фізиці `E = ℏ·ω`, підставимо `p = ℏ·k`:

```
ℏ · ω = (ℏ · k)² / (2m)
ω(k) = ℏ · k² / (2m)
```

Знайдемо фазову швидкість хвилі де Бройля:

```
vₚ = ω / k = (ℏ · k) / (2m) = p / (2m) = (m · v_particle) / (2m) = (1/2) · v_particle
```

Знайдемо групову швидкість квантового хвильового пакета:

```
v_g = dω / dk = d/dk ( ℏ · k² / (2m) ) = (2 · ℏ · k) / (2m) = (ℏ · k) / m = p / m = v_particle
```

Розрахунок показує ідеальну узгодженість фізичних картин: групова швидкість квантового хвильового пакета `v_g` точно дорівнює класичній механічній швидкості руху частинки `v_particle`, тоді як фазова швидкість окремих гармонічних складників становить рівно половину цієї швидкості.
