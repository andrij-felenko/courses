# 🧮 Математика далекого поля: інтеграл Релея та функції спрямованості

У цій математичній вставці виведено детальні математичні вирази для акустичного поля у далекій та ближній зонах та проаналізовано нормовані характеристики спрямованості для восьми основних геометрій випромінювачів: одновимірного неперервного відрізка, прямокутної апертури, суцільного кругового поршня, сферичного угнутого поршня (фокусуючого перетворювача), кільцевого поршня, Гауссового профілю амплітуди, дискретного фазованого лінійного масиву, двовимірної прямокутної решітки, а також розкрито математику ближнього поля Френеля, віконної аподизації (Хеммінґа та Ганна), рекурентних співвідношень Бесселя і сформульовано теорему про множення діаграм спрямованості та обчислення випроміненої акустичної потужності. Усі виведення виконано за допомогою класичного інтеграла Релея, властивостей спеціальних функцій Бесселя та підсумовування комплексних експонент.

### 1. Постановка задачі та інтеграл Релея

Розглянемо плоский випромінювач (апертуру) площею `S`, розташований у площині `z = 0` і вмонтований у жорсткий нескінченний плоский екран (baffle). Кожна точка поверхні `(x', y', 0)` коливається за гармонічним законом уздовж осі `z` з комплексною амплітудою коливальної швидкості `v₀(x', y')`.

Середовище, у яке випромінюється хвиля, є однорідним, безмежним і описується густиною `ρ₀` та швидкістю звуку `c`. Хвильове число акустичної хвилі визначається класичним співвідношенням `k = ω / c = 2π / λ`.

Згідно з принципом Гюйгенса-Френеля у формі інтеграла Релея першого роду, акустичний тиск `p(r, θ, φ)` у довільній точці простору `P(r, θ, φ)` дорівнює сумі випромінювання від усіх елементарних майданчиків `dS' = dx' dy'`:

```
p(r, θ, φ) = (i ρ₀ c k / (2π)) · ∬_S v₀(x', y') · (e^(i k r') / r') dx' dy'
```

де `r'` — відстань від елементарного випромінювача `(x', y', 0)` до точки спостереження `P(x, y, z)`.

У сферичній системі координат точка спостереження має декартові координати `x = r sin(θ) cos(φ)`, `y = r sin(θ) sin(φ)`, `z = r cos(θ)`. Точна відстань `r'` між точкою джерела та точкою спостереження виражається тотожністю:

```
r' = √[(x − x')² + (y − y')² + z²]
   = √[r² − 2 r sin(θ) (x' cos(φ) + y' sin(φ)) + x'² + y'²]
```

#### Межа Френеля та Фраунгофера

Розкладемо геометричний вираз для `r'` у степеневий ряд у околі великих відстаней `r`:

```
r' = r · √[1 − (2 sin(θ) (x' cos(φ) + y' sin(φ)) / r) + ((x'² + y'²) / r²)]
   ≈ r − sin(θ) (x' cos(φ) + y' sin(φ)) + (x'² + y'² − (x' cos(φ) + y' sin(φ))²) / (2 r) + ...
```

Для експоненціального фазового множника `e^(i k r')` максимальна фазова похибка від квадратного члена на краях апертури радіуса `a = D/2` не повинна перевищувати `π / 8` (або 22.5 градуса). Це дає строго математичну умову для межі далекої зони (зони Фраунгофера):

```
k · (D / 2)² / (2 r) ≤ π / 8   ⇒   (2π / λ) · (D² / 8 r) ≤ π / 8   ⇒   r ≥ D² / λ
```

Для практичних інженерних обчислень межею ближньої зони (зони Френеля) часто вважають відстань `R_F = D² / (4 λ)`. У цій вставці всі виведення характеристики спрямованості виконуються для далекої зони (`r ≫ D² / λ`), де квадратними членами можна знехтувати.

У знаменнику амплітудного множника наближено покладаємо `r' ≈ r`. У фазовому експоненціальному множнику зберігаємо лінійні члени розкладу за координатами:

```
r' ≈ r − sin(θ) · (x' cos(φ) + y' sin(φ))
```

Підставляючи це наближення в інтеграл Релея, отримуємо фундаментальну формулу для поля далекої зони:

```
p(r, θ, φ) = (i ρ₀ c k / (2π r)) · e^(i k r) · ∬_S v₀(x', y') · e^(−i k sin(θ) (x' cos(φ) + y' sin(φ))) dx' dy'
```

Отже, кутовий розподіл акустичного тиску у далекій зоні з точністю до постійного фазового та амплітудного множника є двовимірним **перетворенням Фур'є** від розподілу коливальної швидкості `v₀(x', y')` по поверхні випромінювача.

### 2. Одновимірний неперервний нитковий випромінювач

Розглянемо найпростіший неперервний випромінювач — вузьку нитку довжиною `L`, розташовану вздовж осі `x` у межах `x' ∈ [−L/2, L/2]`.

Амплітуда коливальної швидкості вздовж нитки є постійною `v₀(x') = v₀`. Інтеграл далекої зони в площині `xz` (`φ = 0`) набуває вигляду:

```
p(r, θ) = (i ρ₀ c k v₀ / (2π r)) · e^(i k r) · ∫_{−L/2}^{L/2} e^(−i k x' sin(θ)) dx'
```

Обчислимо одновимірний інтеграл:

```
∫_{−L/2}^{L/2} e^(−i k x' sin(θ)) dx' = [ e^(−i k x' sin(θ)) / (−i k sin(θ)) ]_{−L/2}^{L/2}
                                      = 2 · sin(k (L/2) sin(θ)) / (k sin(θ))
                                      = L · sin((π L / λ) sin(θ)) / ((π L / λ) sin(θ))
```

Позначивши `u_L = (π L / λ) sin(θ)`, нормована функція спрямованості неперервного лінійного джерела дорівнює:

```
R_line(θ) = | sin(u_L) / u_L |
```

Цей вираз описує базовий розподіл амплітуди для будь-якої одновимірної апертури й показує, що перші нулі спрямованості настають при `sin(θ₀) = ± λ / L`.

### 3. Прямокутна апертура: вивід прямокутної характеристики

Розглянемо прямокутну апертуру шириною `W` (уздовж осі `x`) та висотою `H` (уздовж осі `y`). Припустимо, що амплітуда швидкості коливань по всій поверхні є синфазною та сталою: `v₀(x', y') = v₀ = const`.

Інтегрування проводиться в межах `x' ∈ [−W/2, W/2]` та `y' ∈ [−H/2, H/2]`. Подвійний інтеграл розпадається на добуток двох незалежних одновимірних інтегралів:

```
∬_S e^(−i k sin(θ) (x' cos(φ) + y' sin(φ))) dx' dy'
= ∫_{−W/2}^{W/2} e^(−i k sin(θ) cos(φ) x') dx' · ∫_{−H/2}^{H/2} e^(−i k sin(θ) sin(φ) y') dy'
```

Обчислимо перший інтеграл за зміною `x'`:

```
∫_{−W/2}^{W/2} e^(−i k sin(θ) cos(φ) x') dx'
= [ e^(−i k sin(θ) cos(φ) x') / (−i k sin(θ) cos(φ)) ]_{−W/2}^{W/2}
= (e^(i k (W/2) sin(θ) cos(φ)) − e^(−i k (W/2) sin(θ) cos(φ))) / (i k sin(θ) cos(φ))
= 2 · sin(k (W/2) sin(θ) cos(φ)) / (k sin(θ) cos(φ))
= W · sin(u) / u
```

де позначено просторову частотну змінну:

```
u = (k W / 2) · sin(θ) cos(φ) = (π W / λ) · sin(θ) cos(φ)
```

Аналогічно обчислюється другий інтеграл за зміною `y'`:

```
∫_{−H/2}^{H/2} e^(−i k sin(θ) sin(φ) y') dy' = H · sin(w) / w
```

де позначено:

```
w = (k H / 2) · sin(θ) sin(φ) = (π H / λ) · sin(θ) sin(φ)
```

Нормована амплітудна характеристика спрямованості `R(θ, φ) = |p(r, θ, φ)| / |p(r, 0, 0)|` для прямокутної апертури дорівнює:

```
R(θ, φ) = | (sin(u) / u) · (sin(w) / w) |
```

Для головного перерізу в площині `xz` (де `φ = 0`, отже `w = 0`, `sin(w)/w = 1`) функція спрямованості спрощується до класичного кардинального синуса (функції `sinc`):

```
R(θ) = | sin(u) / u |      де  u = (π W / λ) · sin(θ)
```

#### Нулі напрямності прямокутника

Нулі характеристики спрямованості виникають тоді, коли чисельник перетворюється на нуль, а знаменник є відмінним від нуля:

```
sin(u) = 0   ⇒   u = m · π   (де m = ±1, ±2, ±3, ...)
(π W / λ) · sin(θ_m) = m · π
sin(θ_m) = m · λ / W
```

Кут першого нуля спрямованості `θ₀` (при `m = 1`) за умови `W > λ` дорівнює:

```
sin(θ₀) = λ / W   ⇒   θ₀ = arcsin(λ / W) ≈ λ / W  (для малих кутів)
```

Ширина головної пелюстки між нулями за кутом дорівнює `Δθ_null = 2 θ₀ ≈ 2 λ / W`.

#### Ширина головної пелюстки за рівнем −3 dB

Рівень потужності −3 dB відповідає зменшенню амплітуди акустичного тиску у `√2` разів, тобто `R(θ) = 1 / √2 ≈ 0.7071`.

Знаходимо розв'язок рівняння:

```
sin(u) / u = 1 / √2   ⇒   u ≈ 1.39155
(π W / λ) · sin(θ_{-3dB}) = 1.39155
sin(θ_{-3dB}) = 1.39155 / π · (λ / W) ≈ 0.4429 · (λ / W)
```

Повна ширина головної пелюстки за рівнем −3 dB (між половинними точками) становить:

```
2 θ_{-3dB} ≈ 2 · 0.4429 · (λ / W) ≈ 0.8858 · (λ / W)
```

#### Рівень першої бічної пелюстки прямокутника

Максимуми бічних пелюсток знаходяться з умови екстремуму похідної `d/du (sin(u)/u) = 0`, що зводиться до трансцендентного рівняння:

```
tan(u) = u
```

Перший додатний корінь цього рівняння дорівнює `u₁ ≈ 4.49341`.

Обчислюємо амплітуду першої бічної пелюстки:

```
R(u₁) = | sin(4.49341) / 4.49341 | = | −0.9761 / 4.49341 | ≈ 0.21723
```

У логарифмічному масштабі (децибелах) рівень першої бічної пелюстки (Side Lobe Level, SLL) відносно головного максимуму становить:

```
SLL_dB = 20 · log₁₀(0.21723) ≈ −13.26 dB
```

Це фундаментальна межа прямокутної апертури з рівномірним розподілом амплітуди: перша бічна пелюстка містить понад 21% амплітуди головного променя.

### 4. Круговий поршень: вивід через функції Бесселя

Розглянемо круговий поршень радіуса `a` (діаметром `D = 2a`), що випромінює в жорсткий екран. Амплітуда швидкості є стала: `v₀(r') = v₀`.

Перейдемо до полярних координат на поверхні випромінювача: `x' = r' cos(φ')`, `y' = r' sin(φ')`, де `r' ∈ [0, a]`, `φ' ∈ [0, 2π]`.

Скалярний добуток у фазовому множнику інтеграла Релея набирає вигляду:

```
x' cos(φ) + y' sin(φ) = r' (cos(φ') cos(φ) + sin(φ') sin(φ)) = r' cos(φ' − φ)
```

Інтеграл по поверхні поршня переписується як:

```
I(θ) = ∫₀ᵃ r' dr' ∫₀²ᵖⁱ e^(−i k r' sin(θ) cos(φ' − φ)) dφ'
```

Скористаємося інтегральним представленням функції Бесселя першого роду нулевого порядку `J₀(z)`:

```
J₀(z) = (1 / (2π)) · ∫₀²ᵖⁱ e^(−i z cos(ψ)) dψ
```

Застосовуючи цю тотожність до внутрішнього інтеграла по `φ'`, отримуємо:

```
∫₀²ᵖⁱ e^(−i k r' sin(θ) cos(φ' − φ)) dφ' = 2π · J₀(k r' sin(θ))
```

Тоді поверхневий інтеграл спрощується до одновимірного інтеграла за радіусом:

```
I(θ) = 2π · ∫₀ᵃ r' J₀(k r' sin(θ)) dr'
```

Для обчислення цього інтеграла використаємо відоме диференціальне співвідношення для функцій Бесселя: `d/dx [x J₁(x)] = x J₀(x)`, або у неозначеному інтегралі:

```
∫ x J₀(x) dx = x J₁(x)
```

Введемо заміну змінної `t = k r' sin(θ)`, `dt = k sin(θ) dr'`. Межі інтегрування змінюються від `t = 0` до `t = k a sin(θ) = v`:

```
I(θ) = 2π · (1 / (k sin(θ))²) · ∫₀ᵛ t J₀(t) dt
     = 2π · (1 / (k sin(θ))²) · [ t J₁(t) ]₀ᵛ
     = 2π · (1 / (k sin(θ))²) · v J₁(v)
     = 2π a² · (J₁(v) / v)
```

де позначено безрозмірну кутову змінну:

```
v = k a sin(θ) = (π D / λ) · sin(θ)
```

Оскільки площа поршня `S = π a²`, значення інтеграла на осі (`θ = 0`, `v → 0`, `lim_{v→0} J₁(v)/v = 1/2`) дорівнює `I(0) = π a²`.

Звідси нормована характеристика спрямованості кругового поршня `R(θ) = |I(θ) / I(0)|` має вигляд:

```
R(θ) = | 2 J₁(v) / v |      де  v = (π D / λ) · sin(θ)
```

Ця функція в акустиці та оптиці отримала назву **функції спрямованості поршня** або сомбреро-функції (jinc function).

#### Рекурентні співвідношення та степенний розклад Бесселя

Для точного чисельного обчислення функції спрямованості у коді застосовуються рекурентні тотожності між функціями Бесселя суміжних порядків:

```
J_{n−1}(x) + J_{n+1}(x) = (2 n / x) · J_n(x)
d/dx [ J_n(x) ] = 0.5 · [ J_{n−1}(x) − J_{n+1}(x) ]
```

Для малих аргументів `v ≪ 1` функція Бесселя `J₁(v)` розкладається в степенний ряд Тейлора:

```
J₁(v) = (v / 2) − (v³ / 16) + (v⁵ / 384) − (v⁷ / 18432) + ...
```

Підставляючи це у функцію спрямованості поршня, отримуємо наближену формулу для практичних обчислень при малих кутах:

```
2 J₁(v) / v ≈ 1 − (v² / 8) + (v⁴ / 192) − (v⁶ / 9216)
```

Для великих аргументів `v ≫ 1` (далекі бічні пелюстки) використовується асимптотичний розклад Бесселя:

```
J₁(v) ≈ √(2 / (π v)) · cos(v − 3π / 4)
```

Звідси амплітуда бічних пелюсток поршня на великих кутах спадає зі швидкістю `v^(−3/2)` (тобто пропорційно `1 / (sin(θ))^(3/2)`), що є значно швидшим спаданням, ніж у прямокутника (`1 / sin(θ)`).

#### Нулі напрямності кругового поршня

Нулі характеристики спрямованості визначаються коренями функції Бесселя першого порядку `J₁(v) = 0` (при `v > 0`).

Перші корені функції `J₁(v)` дорівнюють:

```
v₁ ≈ 3.83171
v₂ ≈ 7.01559
v₃ ≈ 10.17347
```

Прирівнюючи `v = (π D / λ) sin(θ₀) = v₁`, отримуємо кут першого нуля:

```
sin(θ₀) = 3.83171 / π · (λ / D) ≈ 1.21967 · (λ / D)
```

Це і є знаменитий **диск Ейрі** (Airy disk) та акустичний критерій Релея. Для кругової апертури перший нуль розташований далі, ніж для прямокутної (`1.22 λ/D` проти `1.00 λ/D`), оскільки ефективна ширина поршня на його краях зменшується.

#### Ширина головної пелюстки за рівнем −3 dB

Знаходимо корінь рівняння `2 J₁(v) / v = 1 / √2 ≈ 0.7071`:

```
v_{-3dB} ≈ 1.61634
(π D / λ) · sin(θ_{-3dB}) = 1.61634
sin(θ_{-3dB}) = 1.61634 / π · (λ / W) ≈ 0.5145 · (λ / D)
```

Повна ширина головної пелюстки за рівнем −3 dB становить:

```
2 θ_{-3dB} ≈ 2 · 0.5145 · (λ / D) ≈ 1.029 · (λ / D)
```

#### Рівень першої бічної пелюстки кругового поршня

Максимуми бічних пелюсток знаходяться з умови `d/dv (2 J₁(v) / v) = 0`, що зводиться до рівняння `J₂(v) = 0`.

Перший додатний корінь функції Бесселя другого порядку `J₂` дорівнює `v_side ≈ 5.13562`.

Обчислюємо значення характеристики спрямованості в цьому максимумі:

```
R(v_side) = | 2 · J₁(5.13562) / 5.13562 | = | 2 · (−0.33967) / 5.13562 | ≈ 0.13228
```

У логарифмічному масштабі рівень першої бічної пелюстки дорівнює:

```
SLL_dB = 20 · log₁₀(0.13228) ≈ −17.57 dB
```

Порівняння показує важливий інженерний факт: круговий поршень має значно нижчий рівень бічних пелюсток (`−17.57 dB`), ніж прямокутна апертура (`−13.26 dB`). Причина полягає у природному плавному спаданні площі кругового поршня від центра до країв при інтегруванні вздовж прямолінійних смуг.

### 5. Сферичний угнутий поршень (Фокусуючий перетворювач)

Якщо поверхня кругового поршня радіуса `a` вигнута за сферою радіуса кривини `F` (фокусна відстань), амплітуда коливальної швидкості отримує фазовий зсув `e^(i k r'² / (2 F))`.

Акустичний тиск у фокальній площині (`z = F`) визначається співвідношенням:

```
p(r_p, θ) = (i ρ₀ c k a² v₀ / (2 F)) · e^(i k F) · [ 2 J₁(k a r_p / F) / (k a r_p / F) ]
```

де `r_p` — радіальна відстань від фокальної осі.

Ширина плями фокуса за рівнем −3 dB дорівнює:

```
d_focus = 1.029 · λ · F / D
```

Ця формула показує, що геометричне фокусування дозволяє стиснути акустичну енергію у вузьку перетяжку, розмір якої обмежений лише дифракційною межею Релея-Ейрі.

---

### 6. Кільцевий поршень (Annular Aperture)

Розглянемо випромінювач у формі тонкого кільця або кільцевої пластини з внутрішнім радіусом `a₁` та зовнішнім радіусом `a₂`.

Обчислюючи інтеграл Релея в межах `r' ∈ [a₁, a₂]`, отримуємо результуючу ненормовану функцію випромінювання:

```
I_ring(θ) = 2π · ∫_{a₁}^{a₂} r' J₀(k r' sin(θ)) dr'
          = 2π · [ (a₂ / (k sin(θ))) J₁(k a₂ sin(θ)) − (a₁ / (k sin(θ))) J₁(k a₁ sin(θ)) ]
```

Позначивши `v₂ = k a₂ sin(θ)` та `v₁ = k a₁ sin(θ)`, нормована характеристика спрямованості кільця дорівнює:

```
R_ring(θ) = | (a₂² · (2 J₁(v₂) / v₂) − a₁² · (2 J₁(v₁) / v₁)) / (a₂² − a₁²) |
```

Для граничного випадку нескінченно тонкого кільця (`a₁ → a₂ = a`) інтеграл прямо дає функцію Бесселя нулевого порядку:

```
R_thin_ring(θ) = | J₀(k a sin(θ)) |
```

Оскільки перша бічна пелюстка функції `J₀(v)` має амплітуду `|J₀(3.8317)| ≈ 0.4027` (`−7.9 dB`), тонке кільце має дуже високі бічні пелюстки. Проте головна пелюстка тонкого кільця є вужчою, ніж у суцільного поршня того ж діаметра: перший нуль настає при `v = 2.4048` (тобто `sin(θ₀) ≈ 0.766 λ / D`).

---

### 7. Гауссовий випромінювач (Апертура з Гауссовим профілем)

Якщо амплітуда коливальної швидкості на нескінченній площині спадає за законом Гаусса `v₀(r') = v₀ · e^(−r'² / b²)`, де `b` — ефективний радіус плями, то інтегрування перетворення Фур'є виконується в аналітичному вигляді без виникнення бічних пелюсток:

```
I_gauss(θ) = v₀ · ∫₀^∞ 2π r' e^(−r'² / b²) J₀(k r' sin(θ)) dr' = π b² v₀ · e^(−(k b sin(θ))² / 4)
```

Нормована характеристика спрямованості Гауссового випромінювача дорівнює чистому Гауссовому дзвону:

```
R_gauss(θ) = e^(−(π b / λ)² · sin²(θ))
```

Головний фізичний та математичний результат для Гауссової апертури полягає в тому, що **бічні пелюстки повністю відсутні** (`SLL = −∞ dB`). За це доводиться платити відсутністю чітких нулів і плавнішим розширенням головної пелюстки.

---

### 8. Дискретний фазований лінійний масив та теорема про множення діаграм

Розглянемо масив із `N` однаково орієнтованих випромінювачів, розташованих уздовж осі `x` з постійним кроком `d`. Кожен `n`-й елемент (`n = 0, 1, ..., N−1`) має власну характеристику спрямованості `R_elem(θ)` та комплексну амплітуду `A_n = a_n · e^(i φ_n)`.

Сумарне акустичне поле у далекій зоні під кутом `θ` описується **теоремою про множення характеристик спрямованості**:

```
R_total(θ) = R_elem(θ) · AF(θ)
```

де `AF(θ)` — решітковий множник (Array Factor).

Для однакових амплітуд (`a_n = 1`) та лінійного фазового зсуву `φ_n = −n · Δφ` з метою електронного відхилення променя на кут `θ_s`:

```
Δφ = k d sin(θ_s)
```

Вираз для решіткового множника (Array Factor) набуває вигляду суми геометричної прогресії:

```
AF(θ) = ∑_{n=0}^{N−1} e^(i n (k d sin(θ) − Δφ))
```

Ввівши узагальнену фазову змінну `ψ = k d sin(θ) − Δφ = k d (sin(θ) − sin(θ_s))`, згортаємо суму геометричної прогресії:

```
AF(θ) = (1 − e^(i N ψ)) / (1 − e^(i ψ))
      = e^(i (N−1) ψ / 2) · [ sin(N ψ / 2) / sin(ψ / 2) ]
```

Нормована характеристика спрямованості фазованої решітки дорівнює модулю відношення:

```
AF_norm(θ) = | sin(N ψ / 2) / (N · sin(ψ / 2)) |
```

де `ψ = k d (sin(θ) − sin(θ_s))`.

#### Поява ґратчастих часток (Grating Lobes)

Знаменник виразу перетворюється на нуль, а отже `AF_norm(θ) = 1` (побічний головний максимум), коли `ψ / 2 = m π`, тобто:

```
k d (sin(θ_m) − sin(θ_s)) = 2 m π
(2π / λ) · d (sin(θ_m) − sin(θ_s)) = 2 m π
sin(θ_m) = sin(θ_s) + m · (λ / d)    (де m = ±1, ±2, ...)
```

Щоб додаткові максимуми (ґратчасті частки / Grating Lobes) не потрапляли у фізичний простір кутів `|sin(θ_m)| ≤ 1`, крок решітки `d` мусить задовольняти строгому обмеженню:

```
d ≤ λ / (1 + |sin(θ_s_max)|)
```

Для сканування у повному півпросторі `θ_s ∈ [−90°, +90°]` умова відсутності ґратчастих часток стає класичною:

```
d ≤ λ / 2
```

Це є просторовим аналогом теореми Котельникова-Шеннона-Найквіста про дискретизацію сигналів у часовій області.

---

### 9. Двовимірна прямокутна фазована решітка

Для двовимірного масиву з `N_x × N_y` елементів, розміщених на плоскій сітці з кроками `d_x` та `d_y`, сумарний решітковий множник є добутком двох одновимірних множників:

```
AF_2D(θ, φ) = AF_x(θ, φ) · AF_y(θ, φ)
```

де фазові змінні для сканування у напрямку `(θ_s, φ_s)` дорівнюють:

```
ψ_x = k d_x (sin(θ) cos(φ) − sin(θ_s) cos(φ_s))
ψ_y = k d_y (sin(θ) sin(φ) − sin(θ_s) sin(φ_s))
```

Нормована характеристика спрямованості 2D-решітки набуває компактного вигляду:

```
R_2D(θ, φ) = | (sin(N_x ψ_x / 2) / (N_x sin(ψ_x / 2))) · (sin(N_y ψ_y / 2) / (N_y sin(ψ_y / 2))) |
```

Ця формула лежить в основі математичного забезпечення медичних 3D УЗД-сканерів та радіолокаційних станцій з активними фазованими решітками (АФАР).

### 10. Математика віконної аподизації (Хеммінґа та Ганна)

При дискретній вибірці амплітуд елементів `a_n` застосовуються вагові вікна для ефективного пригнічення бічних пелюсток:

1. **Вікно Ганна (Raised Cosine / Hann):**
   ```
   a_n = 0.5 − 0.5 · cos(2π n / (N − 1))
   ```
   Зменшує рівень першої бічної пелюстки до `−31.5 dB`.

2. **Вікно Хеммінґа (Hamming):**
   ```
   a_n = 0.54 − 0.46 · cos(2π n / (N − 1))
   ```
   Забезпечує мінімізацію першої бічної пелюстки до рівню `−42.7 dB`.

Аналітичне перетворення Фур'є вікна Хеммінґа згортається як сума трьох зсунутих функцій `sinc`:

```
AF_hamming(ψ) = 0.54 · AF_norm(ψ) + 0.23 · AF_norm(ψ − 2π/N) + 0.23 · AF_norm(ψ + 2π/N)
```

Завдяки протифазній інтерференції зсунутих бічних пелюсток бічні піки майже повністю компенсуються, ціною розширення головного променя у `1.37` раза.

### 11. Обчислення акустичної потужності та коефіцієнт спрямованості (DI)

Повна випромінена акустична потужність `P_ac` визначається інтегруванням векторного потоку інтенсивності `I(θ, φ) = |p(r, θ, φ)|² / (2 ρ₀ c)` по замкненій сферичній поверхні радіуса `r`:

```
P_ac = ∬_{4π} I(r, θ, φ) r² dΩ = (r² / (2 ρ₀ c)) · ∬_{4π} |p(r, θ, φ)|² sin(θ) dθ dφ
```

Для порівняння спрямованого випромінювача з еквівалентним ненапрямленим джерелом тої ж потужності вводиться коефіцієнт спрямованості `D_dir`:

```
D_dir = 4π / ∬_{4π} R²(θ, φ) sin(θ) dθ dφ
```

Для кругового поршня у жорсткому екрані при `k a ≫ 1` точний аналітичний інтеграл дає:

```
D_dir = (k a)² / (1 − J₁(2 k a) / (k a)) ≈ (k a)² = (π D / λ)²
```

Виражений у децибелах індекс спрямованості (Directivity Index, DI) дорівнює:

```
DI = 10 · log₁₀(D_dir) = 10 · log₁₀((π D / λ)²) = 20 · log₁₀(π D / λ)
```

Ці математичні співвідношення є фундаментальною основою точного розрахунку та проектування акустичних, гідроакустичних, медичних та радіолокаційних систем далекої дії. Завдяки їм інженери розраховують енергетичний баланс лінка та роздільну здатність антенних систем.
