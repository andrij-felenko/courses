# 📖 Специфікація параметрів спрямованості перетворювачів (API Reference)

Ця довідкова вставка містить формалізовані інженерні специфікації, стандартні терміни, математичні означення, граничні фізичні співвідношення та методики метрологічної атестації паспортних характеристик спрямованості акустичних, гідроакустичних, медичних та промислових ультразвукових перетворювачів відповідно до міжнародних стандартів (ISO/IEC 60604, IEEE Std 176, NEMA UD-2).

---

### 1. Перелік паспортних параметрів спрямованості

У специфікаціях акустичних антен, сонарів та датчиків ультразвукової дефектоскопії діаграма спрямованості (Beam Pattern / Radiation Pattern) описується комплексом стандартних метрик, які визначають енергетичний баланс акустичної лінії зв'язку, кутову та просторову роздільну здатність системи.

#### 1.1. Ширина головного променя за рівнем −3 dB (Half-Power Beamwidth, HPBW)

* **Позначення у паспортах:** `θ_{-3dB}`, `BW_{-3dB}`, `HPBW`.
* **Означення:** Кутова ширина головної пелюстки між двома симетричними напрямками відносно акустичної осі, у яких інтенсивність випромінювання падає у 2 рази відносно максимуму на осі. У масштабі акустичного тиску це відповідає зменшенню амплітуди у `√2 ≈ 1.4142` разів або на `-3.01 dB`.
* **Фізичний зміст:** Параметр визначає мінімальну кутову відстань між двома точковими об'єктами однаковою відбивною здатністю, при якій їхні ехо-сигнали ще розрізняються в режимі випромінювання.
* **Формули розрахунку для неохопленої (uniform) апертури:**
  - Прямокутна апертура шириною `W`:
    ```
    θ_{-3dB} = 2 · arcsin(0.4429 · λ / W) ≈ 0.8858 · (λ / W)  [рад]
             ≈ 50.76° · (λ / W)
    ```
  - Круговий поршень діаметром `D`:
    ```
    θ_{-3dB} = 2 · arcsin(0.5145 · λ / D) ≈ 1.0290 · (λ / D)  [рад]
             ≈ 58.96° · (λ / D)
    ```
* **Одиниці вимірювання:** кутові градуси (`°`) або радіани (`rad`).

#### 1.2. Ширина головного променя за рівнем −6 dB (Quarter-Power Beamwidth)

* **Позначення у паспортах:** `θ_{-6dB}`, `BW_{-6dB}`.
* **Означення:** Кутова ширина головного променя між точками, у яких амплітуда акустичного тиску падає в 2 рази (на `-6.02 dB`), а інтенсивність випромінювання — у 4 рази.
* **Галузеве застосування:** Широко використовується у специфікаціях медичних УЗД-сканерів та промислової дефектоскопії. Оскільки медичний сканер працює в суміщеному режимі випромінювання та прийому (Tx/Rx), результуюча двопрохідна характеристика спрямованості є квадратом однопрохідної `R_{double}(θ) = R²(θ)`. Відповідно, рівень `-3 dB` у двопрохідному режимі точно відповідає рівню `-6 dB` у однопрохідному паспорті перетворювача.
* **Формули розрахунку:**
  - Прямокутна апертура: `θ_{-6dB} = 2 · arcsin(0.6033 · λ / W) ≈ 1.2066 · (λ / W)` rad.
  - Круговий поршень: `θ_{-6dB} = 2 · arcsin(0.7028 · λ / D) ≈ 1.4056 · (λ / D)` rad.

#### 1.3. Кут першого нуля (First Null Beamwidth, FNBW)

* **Позначення у паспортах:** `θ_{null}`, `FNBW`.
* **Означення:** Повний кутовий інтервал між першими симетричними нулями характеристики спрямованості, які обмежують головний промінь з обох боків.
* **Формули розрахунку:**
  - Прямокутна апертура шириною `W`:
    ```
    Δθ_{null} = 2 · arcsin(λ / W) ≈ 2.000 · (λ / W)  [рад]
    ```
  - Круговий поршень діаметром `D` (Межа Ейрі):
    ```
    Δθ_{null} = 2 · arcsin(1.2197 · λ / D) ≈ 2.4394 · (λ / D)  [рад]
    ```

#### 1.4. Рівень бічних пелюсток (Side Lobe Level, SLL)

* **Позначення у паспортах:** `SLL`, `SLR` (Side Lobe Ratio), `PSLL` (Peak Side Lobe Level).
* **Означення:** Відношення амплітуди найвищого максимуму бічного випромінювання (зазвичай першої бічної пелюстки, що примикає до головного променя) до амплітуди головного максимуму на акустичній осі.
* **Формула обчислення у децибелах:**
  ```
  SLL_dB = 20 · log₁₀( |p_{side_max}| / |p_{main_max}| )
  ```
* **Нормативні фізичні межі (без аподизації):**
  - Неперервний прямокутний випромінювач: `SLL = −13.26 dB` (амплітудне відношення `0.2172`).
  - Неперервний круговий поршень: `SLL = −17.57 dB` (амплітудне відношення `0.1323`).
  - Тонке кільце (Annular): `SLL = −7.90 dB` (амплітудне відношення `0.4027`).

#### 1.5. Коефіцієнт спрямованості (Directivity Factor, Q) та Індекс спрямованості (Directivity Index, DI)

* **Позначення у паспортах:** `Q` (Directivity Factor) та `DI` (Directivity Index).
* **Означення:** `Q` — безрозмірне відношення інтенсивності акустичного тиску, створюваної випромінювачем на осі головного променя у далекій зоні, до інтенсивності еквівалентного ненапрямленого (ізотропного) випромінювача тієї ж сумарної акустичної потужності `P_{ac}` на такій же відстані `r`.
* **Математичні вирази:**
  ```
  Q = 4π / ∬_{4π} R²(θ, φ) sin(θ) dθ dφ
  DI = 10 · log₁₀(Q)  [dB]
  ```
* **Асимптотичні інженерні співвідношення при `D ≫ λ`:**
  - Прямокутна апертура площею `A = W · H`:
    ```
    Q ≈ 4π · A / λ² = 4π · W · H / λ²
    DI ≈ 10 · log₁₀(4π · W · H / λ²)  [dB]
    ```
  - Круговий поршень діаметром `D`:
    ```
    Q ≈ (π · D / λ)²
    DI ≈ 20 · log₁₀(π · D / λ)  [dB]
    ```

#### 1.6. Відношення випромінювання вперед/назад (Front-to-Back Ratio, F/B)

* **Позначення у паспортах:** `F/B`, `FTB`.
* **Означення:** Відношення акустичного тиску, випроміненого у напрямку головної осі (`θ = 0°`), до тиску, випроміненого у прямо протилежному напрямку (`θ = 180°`).
* **Формула:**
  ```
  (F/B)_dB = 20 · log₁₀( |p(0°)| / |p(180°)| )
  ```
* **Фізичні норми:** Для перетворювачів у жорсткому екрані (baffle) `F/B = +∞` (тильне випромінювання відсутнє). Для неекранованого п'єзодиска `F/B = 0 dB` (дипольна спрямованість).

### 3. Специфікація аподизаційних вікон (Apodization Windows Reference)

Для пригнічення бічних пелюсток у фазованих решітках застосовуються амплітудні вікна. У технічній документації на перетворювач вказується коефіцієнт розширення головного променя та досягнутий рівень пригнічення SLL.

#### 3.1. Прямокутне вікно (Uniform Window)
* **Формула вагових коефіцієнтів:** `w_n = 1.0` (`n = 0, 1, ..., N-1`).
* **Піковий рівень бічних пелюсток (SLL):** `−13.26 dB`.
* **Коефіцієнт розширення головної пелюстки (Beam Expansion Factor):** `1.00` (стандарт).
* **Спадання бічних пелюсток:** `6 dB/октава` (пропорційно `1 / u`).

#### 3.2. Вікно Ганна (Hann / Raised Cosine)
* **Формула вагових коефіцієнтів:** `w_n = 0.5 − 0.5 · cos(2π n / (N − 1))`.
* **Піковий рівень бічних пелюсток (SLL):** `−31.47 dB`.
* **Коефіцієнт розширення головної пелюстки:** `1.34`.
* **Спадання бічних пелюсток:** `18 dB/октава` (пропорційно `1 / u³`).

#### 3.3. Вікно Хеммінґа (Hamming)
* **Формула вагових коефіцієнтів:** `w_n = 0.54 − 0.46 · cos(2π n / (N − 1))`.
* **Піковий рівень бічних пелюсток (SLL):** `−42.69 dB`.
* **Коефіцієнт розширення головної пелюстки:** `1.37`.
* **Застосування:** Основне стандартне вікно у медичних УЗД-сканерах та сонарах високої роздільної здатності.

#### 3.4. Вікно Блекмана (Blackman)
* **Формула вагових коефіцієнтів:**
  ```
  w_n = 0.42 − 0.50 · cos(2π n / (N − 1)) + 0.08 · cos(4π n / (N − 1))
  ```
* **Піковий рівень бічних пелюсток (SLL):** `−58.11 dB`.
* **Коефіцієнт розширення головної пелюстки:** `1.68`.
* **Спадання бічних пелюсток:** `18 dB/октава`.

#### 3.5. Вікно Дольфа-Чебишева (Dolph-Chebyshev)
* **Властивості:** Забезпечує мінімально можливу ширину головного променя при строго фіксованому рівні всіх бічних пелюсток `SLL_{target}` (наприклад, рівно `-40 dB` для кожної пелюстки).

### 4. Вплив узгоджувальних шарів (Matching Layers) на спрямованість

Для забезпечення максимальної передачі акустичної енергії від п'єзокераміки (хвильовий опір `Z_{pzt} ≈ 30 MRayl`) у воду чи біологічну тканину (`Z_{med} ≈ 1.5 MRayl`) застосовують чвертьхвильові акустичні узгоджувальні шари (Quarter-Wave Matching Layers) з імпедансом `Z_{match} = √(Z_{pzt} · Z_{med}) ≈ 6.7 MRayl`.

Вплив узгоджувальних шарів на спрямованість описується такими паспортними факторами:

1. **Розширення частотної смуги (Bandwidth Enhancement):**
   Широкосмугові перетворювачі з 2-ма узгоджувальними шарами мають відносну смугу `Δf / f₀ ≈ 80%`. Оскільки ширина променя залежить від частоти `θ_{-3dB} ∝ c / (f D)`, у широкосмуговому імпульсі діаграма спрямованості усереднюється по спектру, усуваючи глибокі нулі випромінювання.
2. **Паразитні радіальні моди (Cross-Talk & Lateral Waves):**
   Неякісне розв'язування елементів масиву у поперечному напрямку створює бічні поверхневі хвилі, які підвищують рівень бічних пелюсток SLL на `3 - 6 dB` відносно теоретичної границі.

### 5. Електроакустичний ККД та Ефективна Апертура

У технічних специфікаціях антен також зазначаються енергетичні параметри:

* **Електроакустичний ККД (Electroacoustic Efficiency, η):**
  Відношення випроміненої акустичної потужності `P_{ac}` до підведеної електричної потужності `P_{el}`:
  ```
  η = P_{ac} / P_{el}
  ```
  Для п'єзокерамічних перетворювачів PZT-5H типове значення `η ≈ 60% - 80%`.

* **Ефективна апертурна площа (Effective Aperture Area, A_{eff}):**
  Площа ідеальної прямокутної чи кругової апертури з рівномірним розподілом швидкості, яка створює такий же коефіцієнт спрямованості `Q`:
  ```
  A_{eff} = Q · λ² / (4π)
  ```
  Для прямокутника без аподизації `A_{eff} = W · H`, при аподизації Хеммінґа `A_{eff} ≈ 0.74 · W · H`.

### 6. Паспортні типи перетворювачів та приклади реальних специфікацій

Нижче наведено практичні витяги з технічних паспортів реальних гідроакустичних, медичних та промислових ультразвукових перетворювачів.

#### 6.1. Гідроакустичний ехолотний перетворювач 200 кГц (Circular PZT Disk)
* **Призначення:** Судновий промірний ехолот для мілководдя.
* **Робоча частота:** `f₀ = 200 kHz` (`λ = 7.5 mm` у морській воді при `c = 1500 m/s`).
* **Діаметр активного елемента:** `D = 75 mm` (`D / λ = 10`).
* **Ширина променя (−3 dB):** `θ_{-3dB} = 5.9°`.
* **Ширина променя (−6 dB):** `θ_{-6dB} = 8.1°`.
* **Кут першого нуля:** `θ_{null} = 7.0°` (на один бік).
* **Рівень бічних пелюсток (SLL):** `−17.5 dB`.
* **Індекс спрямованості (DI):** `29.9 dB`.
* **Ефективна акустична площа:** `A_{eff} = 44.2 cm²`.

#### 6.2. Медичний ультразвуковий лінійний датчик 7.5 МГц (Linear Array)
* **Призначення:** Поверхневе УЗД (судини, щитоподібна залоза).
* **Робоча частота:** `f₀ = 7.5 MHz` (`λ = 0.205 mm` у м'яких тканинах при `c = 1540 m/s`).
* **Кількість елементів масиву:** `N = 128`.
* **Крок елементів (Pitch):** `d = 0.1025 mm` (`λ / 2`).
* **Ширина елемента (Width):** `e = 0.085 mm`.
* **Повна довжина апертури:** `W = N · d = 13.12 mm` (`W / λ = 64`).
* **Ширина променя у фокусі (двопрохідна −3 dB / однопрохідна −6 dB):** `θ_{-6dB} = 1.08°`.
* **Рівень бічних пелюсток при аподизації Хеммінґа:** `SLL = −42.0 dB`.
* **Умова відсутності ґратчастих часток (Grating Lobes):** Виконана для кутів сканування `θ_s ∈ [−60°, +60°]`.

#### 6.3. Промисловий УЗД дефектоскопічний нахилений датчик 5 МГц (Angled Beam Probe)
* **Призначення:** Ультразвуковий контроль зварних швів сталевих трубопроводів.
* **Робоча частота:** `f₀ = 5.0 MHz` (`λ = 0.64 mm` для поперечної хвилі у сталі `c_t = 3200 m/s`).
* **Кут вводу променя у сталь:** `α_{ref} = 45°` або `60°` (зазм. призма з оргскла).
* **Розмір п'єзопластини:** `10 × 10 mm`.
* **Ширина променя за рівнем −6 dB:** `θ_{-6dB} = 4.2°`.
* **Рівень бічних пелюсток:** `SLL = −13.2 dB`.

#### 6.4. Гідроакустична антена низькочастотного сонара 12 кГц (Cylindrical Array)
* **Призначення:** Глибоководний навігаційний сонар далекої дії.
* **Робоча частота:** `f₀ = 12 kHz` (`λ = 0.125 m` у воді).
* **Діаметр циліндричної решітки:** `D_c = 1.25 m` (`D_c / λ = 10`).
* **Кількість вертикальних стовпчиків:** `N = 36`.
* **Ширина променя в горизонті (360° круговий огляд):** `θ_{-3dB} = 8.5°`.
* **Індекс спрямованості у горизонті:** `DI = 22.1 dB`.

### 7. Умова запобігання просторовому аліасингу (Grating Lobe Bound)

У специфікаціях фазованих решіток обов'язково вказується критичний крок елементів `d_{max}`, який гарантує відсутність побічних головних максимумів (ґратчастих часток):

```
d ≤ λ / (1 + |sin(θ_s_max)|)
```

Для різних максимально допустимих кутів сканування `θ_s_max` критичний крок дорівнює:
- Сканування `θ_s_max = ±30°`: `d_{max} = λ / 1.5 ≈ 0.667 λ`.
- Сканування `θ_s_max = ±45°`: `d_{max} = λ / 1.707 ≈ 0.586 λ`.
- Сканування `θ_s_max = ±90°` (повний півпростір): `d_{max} = λ / 2.0 = 0.500 λ`.

Якщо крок `d > d_{max}`, у паспорті перетворювача зазначається кутове положення ґратчастої частки `θ_{gl}`:

```
sin(θ_{gl}) = sin(θ_s) ± (λ / d)
```

### 8. Підсилення решітки (Array Gain) та покращення сигналу до шуму (SNR)

У специфікаціях сонарів та фазованих антен розрізняють Індекс спрямованості `DI` та Підсилення решітки (Array Gain, AG):

* **Індекс спрямованості (`DI`):** Описує концентрацію випроміненої енергії в просторі проти ізотропного джерела.
* **Підсилення решітки (`AG`):** Описує реальне покращення співвідношення сигнал/шум (SNR) на виході фазованого суматора проти одного елемента в умовах просторово ізотропного акустичного шуму океану:
  ```
  AG = 10 · log₁₀( (S/N)_{out} / (S/N)_{elem} )
  ```
  Для масиву з `N` однакових некорельованих за шумом елементів при амплітудному додаванні:
  ```
  AG = 10 · log₁₀(N)  [dB]
  ```
  Приклад: 64-елементний масив забезпечує підсилення `AG = 10 log₁₀(64) = 18.06 dB` за рахунок когерентного додавання сигналу та некогерентного додавання шумів.

### 9. Глосарій міжнародних термінів (ISO / IEEE Acoustic Glossary)

У міжнародній технічній документації використовується сувора терминологічна база:

- **Acoustic Pressure Amplitude (`p₀`):** Амплітуда змінного акустичного тиску у паскалях (`Па`).
- **Beam Axis / Acoustic Axis:** Напрямок у просторі, уздовж якого випромінена інтенсивність є максимальною.
- **Far-Field Boundary (`R_F`):** Відстань `r = D² / λ`, починаючи з якої фазова похибка від квадратних членів апертури не перевищує `π / 8`.
- **Near-Field Distance / Fresnel Distance (`N_F`):** Відстань останнього максимуму тиску на осі `N_F = D² / (4 λ)`.
- **Radiation Impedance (`Z_{rad}`):** Комплексний опір середовища випромінюванню поверхні перетворювача `Z_{rad} = R_{rad} + i X_{rad}`.
- **Transducer Sensitivity Index (`M_v`):** Відношення напруги на клемах приймача до виміряного акустичного тиску на осі у `В/Па` або `дБ відносно 1 В/мкПа`.
- **Equivalent Noise Pressure (NEP):** Рівень акустичного тиску шуму перетворювача, зведений до його входу.

### 10. Формат метрологічного сертифіката калібрування (ISO 17025 Compliant Template)

Відповідно до вимог стандарту **ISO 17025**, протокол калібрування характеристики спрямованості акустичного перетворювача повинен містити такі обов'язкові розділи та дані:

1. **Загальні відомості про об'єкт випробувань:**
   - Модель та серійний номер перетворювача (Serial Number).
   - Тип п'єзоелектричного матеріалу (PZT-4, PZT-8, PZT-5H, PVDF, PMN-PT монокристали).
   - Резонансна частота `f_r` та антирезонансна частота `f_a` [кГц].
   - Механічна добротність `Q_m` та коефіцієнт електромеханічного зв'язку `k_{33}`.
2. **Паспортні кутові параметри при `20.0 °C`:**
   - Горизонтальна ширина променя за рівнем `-3 dB` та `-6 dB` [градуси].
   - Вертикальна ширина променя (Elevation Beamwidth) [градуси].
   - Максимальний рівень першої бічної пелюстки `SLL` [дБ].
   - Заміряний індекс спрямованості `DI_{meas}` [дБ].
3. **Умови проведення вимірювань:**
   - Відстань від випромінювача до гідрофона `r_{meas}` [метри].
   - Модель та діаметр активної поверхні контрольного гідрофона [мм].
   - Температура та солоність води в гідроакустичному басейні.
   - Похибка вимірювання тиску `± U_{exp}` [дБ] при довірчій ймовірності `P = 95%`.

### 11. Стандарти та методики метрологічних вимірювань (Measurement Protocols)

Відповідно до міжнародних стандартів **IEC 60604** (Акустика — Вимірювання характеристик спрямованості), **IEEE Std 176** (Стандарт на п'єзоелектрику) та **NEMA UD-2** (Вимірювання акустичного поля УЗД-сканерів), атестація перетворювачів виконується у вимірювальному басейні з дотриманням таких умов:

1. **Умова далекої зони (Far-Field Criterion):**
   Вимірювальний гідрофон розташовується від поверхні перетворювача на відстані `r`, що задовольняє суворій умові Фраунгофера:
   ```
   r ≥ D² / λ
   ```
2. **Імпульсно-часова фільтрація (Gated Impulse Measurement):**
   Вимірювання здійснюються імпульсним сигналом з часовою віконною фільтрацією приймача, що усуває вплив відбитих хвиль від стінок акустичного басейну.
3. **Поправка на просторове усереднення гідрофона (Hydrophone Spatial Averaging):**
   Якщо діаметр приймальної апертури гідрофона `d_h` є порівняним із шириною пелюстки, виміряна амплітуда коригується на величину `sin(k d_h sin(θ)/2) / (k d_h sin(θ)/2)`.
4. **Кутова точність поворотного пристрою:**
   Автоматизований позиціонер повинен забезпечувати дискретність повороту з похибкою не більше `0.02°`.
5. **Температурна стабільність:**
   Вимірювання виконуються при дистильованій або знеповітряній воді за температури `20.0 °C ± 0.5 °C` (`c = 1482.3 m/s`).

Цей API-довідник є вичерпною нормативною основою для розрахунку, розробки, метрологічної перевірки, сертифікаційного контролю та складання технічних паспортів на акустичні перетворювачі будь-якої складності. Використання зазначених міжнародних стандартів гарантує повну сумісність пристроїв та точність вимірювань у морських, медичних та промислових застосуваннях.
