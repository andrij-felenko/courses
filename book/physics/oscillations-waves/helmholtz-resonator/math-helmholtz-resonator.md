# 🧮 Математична теорія резонатора Гельмгольца: від хвильового рівняння до зосередженого імпедансу

Ця вставка містить строгий математичний вивід власної частоти, приєднаної маси та комплексного акустичного імпедансу резонатора Гельмгольца — як з концепції зосереджених параметрів Лагранжа, так і з тривимірного акустичного хвильового рівняння з урахуванням випромінювальних і термовизкозних втрат.

### 1. Вивід власної частоти через механіку Лагранжа

Розглянемо акустичний резонатор Гельмгольца з об'ємом каверни `V`, шийкою площею поперечного перерізу `S` та довжиною `L`. Повітря у шийці розглядається як суцільний несжимаємий поршень масою `m`, який здійснює малі поздовжні зміщення `ξ(t)` коло положення рівноваги.

Густина повітря в стані рівноваги дорівнює `ρ`, рівноважний тиск — `p₀`, а швидкість звуку — `c`.

Для математичного формулювання системи обчислимо кінетичну енергію `T` повітряного стовпа в шийці. Маса повітря в шийці дорівнює добутку густини на ефективну довжину шийки `m = ρ · S · L_eff`. Кінетична енергія руху поршня зі швидкістю `v = dξ / dt` становить:

```
Кінетична енергія повітряного поршня в шийці:
T = (1/2) · m · (dξ / dt)²

де маса поршня:
m = ρ · S · L_eff
```

При зміщенні повітряного поршня всередину каверни на відстань `ξ` зміна об'єму повітря всередині судини становить:

```
ΔV = −S · ξ
```

Вважаючи стиск повітря в каверні адіабатичним (оскільки частоти звуку лежать у діапазоні від десятків до тисяч герц, а теплопровідність газу не встигає зрівняти температури), зв'язок між відносною зміною об'єму та надлишковим акустичним тиском `Δp` визначається модулем об'ємної пружності газу `K = γ · p₀ = ρ · c²`:

```
Δp = −K · (ΔV / V)                        [закон Гука для об'ємного стиску]
= −(ρ · c²) · (−S · ξ / V)                [модуль пружності K = ρ·c² та ΔV = −S·ξ]
= (ρ · c² · S / V) · ξ                    [спрощення знаків мінус]
```

Надлишковий тиск `Δp` створює повертальний сила `F`, що діє на поршень площею `S`:

```
F = −Δp · S                               [визначення сили через тиск і площу]
= −(ρ · c² · S² / V) · ξ                  [підстановка виразу для Δp]
```

Звідси потенціальна енергія `U` стиснутого повітря в каверні обчислюється як робота проти виштовхувальної сили тиску при зміщенні поршня від `0` до `ξ`:

```
U = ∫ (ρ · c² · S² / V) · ξ dξ
= (1/2) · (ρ · c² · S² / V) · ξ²          [інтегрування лінійної сили за зміщенням]
```

Позначивши еквівалентну механічну жорсткість повітряної подушки через `k = ρ · c² · S² / V`, ми бачимо повну ізоморфність потенціальної енергії стиснутого газу потенціальній енергії деформованої механічної пружини `U = (1/2) · k · ξ²`.

Складемо функцію Лагранжа `L_lag = T − U` для даного осцилятора з однією ступеню вільності:

```
L_lag = (1/2) · (ρ · S · L_eff) · (dξ / dt)² − (1/2) · (ρ · c² · S² / V) · ξ²
```

Застосуємо рівняння Ейлера — Лагранжа:

```
(d / dt) (∂L_lag / ∂(dξ/dt)) − (∂L_lag / ∂ξ) = 0
⇒ (ρ · S · L_eff) · (d²ξ / dt²) + (ρ · c² · S² / V) · ξ = 0          [диференціальне рівняння]
⇒ d²ξ / dt² + (c² · S / (V · L_eff)) · ξ = 0                       [скорочено на ρ · S · L_eff]
```

Отримане диференціальне рівняння описує незагасаючі гармонічні коливання з власною коловою частотою `ω₀`:

```
ω₀² = c² · S / (V · L_eff)
⇒ ω₀ = c · √(S / (V · L_eff))
```

Власна резонансна частота резонатора Гельмгольца `f_H = ω₀ / (2π)` виражається фундаментальною формулою:

```
f_H = (c / 2π) · √(S / (V · L_eff))
```

### 2. Тривимірне хвильове рівняння та умова зосереджених параметрів

Перевіримо межі застосовності зосередженої аналогії Лагранжа, виходячи з тривимірного скалярного хвильового рівняння для надлишкового акустичного тиску `p(x, y, z, t)` у середовищі:

```
∇²p − (1 / c²) · (∂²p / ∂t²) = 0
```

У часовому гармонічному режимі `p(r, t) = p̂(r) · exp(j · ω · t)` хвильове рівняння переходить у скалярне рівняння Гельмгольца:

```
∇²p̂ + k² · p̂ = 0
```

де `k = ω / c = 2π / λ` — акустичне хвильове число, а `λ` — довжина звукової хвилі у газі.

Розглянемо каверну об'ємом `V` з характерним просторовим розміром `D ≈ V^(1/3)`. Розкладемо тиск `p̂` всередині судини в ряд за малим параметром `k · D = 2π · D / λ`:

```
p̂(r) = p̂₀ + (k · D) · p̂₁ + (k · D)² · p̂₂ + ...
```

Якщо довжина хвилі `λ` значно перевищує геометричні розміри резонатора:

```
λ ≫ V^(1/3)   та   λ ≫ L
⇒ k · D ≪ 1
```

то нульове наближення тиску `p̂₀` всередині каверни залишається **просторово однорідним** (`∇p̂₀ = 0`). Це означає, що тиск у кожній точці каверни змінюється синхронно в часі, а хвильова фазова затримка всередині об'єму відсутня.

Саме нерівність `λ ≫ V^(1/3)` є строгим математичним критерієм **зосередженої акустичної системи** (*lumped element parameter system*). Як тільки частота зростає до рівня, де `λ ≈ 2 · V^(1/3)`, у каверні виникають власні об'ємні стоячі хвилі (тривимірні моди каверни), і зосереджене рівняння Гельмгольца втрачає силу.

### 3. Функція Гріна та строгий вивід кінцевої поправки Релея

Фізична довжина шийки `L` не враховує того факту, що повітря при виході з отвору не зупиняється миттєво. На обох зрізах шийки створюється сферичне акустичне поле швидкостей, яке захоплює сусідні шари газу.

Розглянемо зовнішній торець циліндричної труби радіусом `r`, що виходить у відкритий півпростір з нескінченним плоским фланцем. Згідно з методом функцій Гріна для акустичного напівпростору `z > 0`, функція Гріна з нульовою похідною за нормаллю на екрані має вигляд:

```
G(r, r') = (exp(−j · k · |r − r'|) / (2π · |r − r'|))
```

Акустичний потенціал швидкості `Φ(r)` у напівпросторі задається інтегралом Релея по площі відкритого отвору `S_0` при гармонічній коливальній швидкості поршня `v₀`:

```
Φ(r') = (v₀ / 2π) · ∬ (exp(−j · k · |r' − r''|) / |r' − r''|) dS''
```

У долгохвильовому наближенні (`k · r ≪ 1`) експоненціальний множник `exp(−j·k·R)` можна розкласти в ряд Тейлора: `exp(−j·k·R) ≈ 1 − j·k·R`. Перший (дійсний) доданок визначає приєднану реактивну масу, а другий (уявний) доданок — активний опір акустичного випромінювання.

Проінтегрувавши потенціал `Φ` по всій площі кругового отвору радіусом `r`, знайдемо середній акустичний тиск на поверхні поршня `p_avg`:

```
p_avg = j · ρ · ω · Φ_avg
= (8 · ρ · ω · v₀ · r / (3π)) + j · (ρ · ω² · v₀ · r² / (2c))
```

Множення тиску `p_avg` на площу отвору `S = π · r²` дає повну силу реакції середовища `F_rad`:

```
F_rad = (8 / 3) · ρ · r³ · ω · v₀ + j · (ρ · π · r⁴ · ω² / (2c)) · v₀
```

Уявна частина цієї сили відповідає інерційному опору приєднаної маси `m_rad = (8 / 3) · ρ · r³`. Поділивши цю масу на добуток `ρ · S`, отримуємо додаткову акустичну довжину `ΔL_flanged`:

```
ΔL_flanged = m_rad / (ρ · S)                        [визначення кінцевої поправки через приєднану масу]
= ((8 / 3) · ρ · r³) / (ρ · π · r²)                 [підстановка виразу для m_rad та площі S]
= (8 / (3π)) · r ≈ 0.848826 · r                      [скорочення густини ρ та радіуса r]
```

Для нефланцевого відкритого торця шийки, де повітря розтікається у повне тривимірне тілесне кутове охоплення `4π` стерадіан, строге розв'язання інтегрального рівняння за методом Вінера — Гопфа, виконане у ХХ столітті, дає:

```
ΔL_unflanged ≈ 0.613300 · r
```

Отже, повна ефективна акустична довжина шийки `L_eff` складається із трьох доданків:

```
L_eff = L + ΔL_in + ΔL_out
```

### 4. Комплексний акустичний імпеданс та три механізми втрат

Введемо поняття **комплексного акустичного імпедансу перерізу** `Z_A(ω)`, який дорівнює відношенню вхідного акустичного тиску `p_in` до вхідного об'ємного потоку `U_A = v · S`:

```
Z_A(ω) = p_in / U_A
= R_A + j · X_A(ω)
```

де `X_A(ω)` — акустичний реактанс, що складається з інерційного та пружного внесків:

```
X_A(ω) = ω · M_A − (1 / (ω · C_A))

де акустична маса (інертність):
M_A = ρ · L_eff / S

та акустична гнучкість (ємність):
C_A = V / (ρ · c²)
```

Умова резонансу відповідає рівності нулю реактансу `X_A(ω₀) = 0`:

```
ω₀ · M_A = 1 / (ω₀ · C_A)                        [умова нульового реактансу X_A = 0]
⇒ ω₀² = 1 / (M_A · C_A)                          [множення на ω₀ та ділення на M_A]
= 1 / ((ρ · L_eff / S) · (V / (ρ · c²)))         [підстановка виразів M_A та C_A]
= c² · S / (V · L_eff)                           [скорочення густини ρ]
```

Повний активний опір втрат `R_A` складається із суми трьох незалежних фізичних процесів розсіювання енергії:

```
R_A = R_rad + R_visc + R_therm
```

#### A. Акустичне випромінювання у зовнішнє середовище (`R_rad`)
Коли повітря у шийці коливається, воно працює як поршневий акустичний випромінювач, посилаючи у навколишній простір сферичну хвилю. Випромінена потужність не повертається у резонатор. Для вільної шийки опір випромінювання дорівнює:

```
R_rad = ρ · ω² / (4π · c)           [для вільного сферичного випромінювання]
R_rad = ρ · ω² / (2π · c)           [для випромінювання у півпростір з фланцем]
```

#### Б. В'язкі втрати у пристінковому межовому шарі (`R_visc`)
У вузькій шийці внаслідок в'язкості газу `μ` на стінках утворюється динамічний зсувний межовий шар товщиною `δ_v`:

```
δ_v = √(2 · μ / (ρ · ω))
```

В'язке тертя шарів газу, які ковзають один відносно одного з великим градієнтом швидкості, дисипує механічну енергію в тепло. Опір в'язкого тертя в циліндричній шийці радіусом `r` дорівнює:

```
R_visc = (√(2 · ρ · μ · ω) / (π · r³)) · L_eff
```

#### В. Теплові втрати на стінках каверни (`R_therm`)
При адіабатичному стиску температура газу в центрі каверни коливається. Проте теплопровідність стінок резонатора утримує їхню температуру постійною. Виникає температурний межовий шар товщиною `δ_th = √(2κ / (ρ c_p ω))` (де `κ` — теплопровідність газу), в якому відбуваються незворотні термодинамічні втрати теплоти.

#### Добротність резонатора (`Q`)
Добротність резонатора Гельмгольца `Q` виражає відношення накопиченої реактивної енергії до енергії, що втрачається за один період коливань:

```
Q = ω₀ · M_A / R_A                               [визначення добротності через опір втрат]
= (1 / R_A) · √(M_A / C_A)                       [підстановка резонансної частоти ω₀ = 1/√(M_A C_A)]
= (1 / R_A) · √((ρ · L_eff / S) / (V / (ρ · c²))) [підстановка виразів для M_A та C_A]
= (ρ · c / R_A) · √(L_eff / (S · V))              [винесення сталих ρ·c з-під кореня]
```

Для незаглушеного металевого резонатора в повітрі при кімнатній температурі значення `Q` зазвичай лежить у діапазоні від `10` до `100`. Шляхом впровадження у шийку пористого матеріалу (тканини або сітки) опір `R_A` навмисно збільшують, знижуючи `Q` до `1..2` для створення широкосмугових акустичних поглиначів.

### 5. Теорема Пойнтінга та дисипація акустичної енергії

Сформулюємо баланс енергії в резонаторі Гельмгольца на основі акустичної теореми Пойнтінга. Об'ємна густина акустичної енергії `e(r, t)` у суцільному газовому середовищі дорівнює сумі густини кінетичної енергії руху частинок та потенціальної енергії стиску газу:

```
e(r, t) = (1/2) · ρ · |v(r, t)|² + (1/2) · (|p(r, t)|² / (ρ · c²))
```

Вектор акустичної густини потоку енергії (вектор Пойнтінга — Умова) `I(r, t)` визначається добутком надлишкового тиску на вектор швидкості частинок:

```
I(r, t) = p(r, t) · v(r, t)
```

Проінтегрувавши вектор Пойнтінга `I` по замкненій поверхні каверни, ми отримуємо потужність втрат енергії `W_diss`. У напівперіоді стиску акустична енергія втікає у каверну у вигляді кінетичного потоку повітряного поршня в шийці, а потім зберігається як потенціальна енергія стиснутого газу в об'ємі `V`.

Часова константа згасання вільної енергії осцилятора `τ` зв'язана з добротністю `Q` та власною коловою частотою `ω₀`:

```
τ = 2 · Q / ω₀
```

Це означає, що за час `t = τ` амплітуда коливань швидкості в шийці зменшується в `e ≈ 2.718` рази, а накопичена акустична енергія падає у `e² ≈ 7.39` рази.

### 6. Узагальнення для шийок із змінним поперечним перерізом

У багатьох практичних застосуваннях шийка резонатора Гельмгольца не є суворо циліндричною, а має змінний за довжиною переріз `S(x)` (наприклад, конічні розтруби або рупорні фазоінвертори).

Для обчислення акустичної маси такої неоднорідної шийки інтегрують інфінітезимальні акустичні маси елементарних шарів газу завтовшки `dx`:

```
M_A = ∫₀^L (ρ / S(x)) dx
```

Для конічної шийки із радіусом, що змінюється за лінійним законом від `r₁` до `r₂` вздовж довжини `L`, інтегрування дає точний вираз акустичної маси:

```
M_A = (ρ · L) / (π · r₁ · r₂)
```

Застосування конічних або закруглених шийок знижує в'язкий опір та запобігає турбулентному відриву потоку газу, забезпечуючи високу добротність та лінійність роботи резонатора при високих рівнях звукового тиску.

### 7. Вплив механічної пружності стінок каверни

У реальних конструкціях стінки каверни мають скінченну механічну жорсткість `K_wall` (наприклад, пластикові судини, тонкостінний метал або біологічні тканини гортані). При підвищенні тиску всередині каверни на `Δp` стінки деформуються, викликаючи додатковий прирост об'єму `ΔV_wall = Δp / K_wall`.

Це додає до акустичної гнучності газу `C_A = V / (ρ · c²)` додаткову паралельну акустичну ємність деформації стінок `C_wall`:

```
C_eff = C_A + C_wall
```

де `C_wall = 1 / K_wall`. Внаслідок цього ефективна жорсткість повітряно-структурної системи зменшується, що призводить до зниження резонансної частоти резонатора Гельмгольца:

```
f_H_elastic = (c / 2π) · √(S / (V · L_eff · (1 + C_wall / C_A)))
```

Цей ефект має принципове значення при розрахунку акустики гнучких судин у біоакустиці, голосових зв'язок та гумових компенсаторів шуму в гідравлічних і пневматичних магістралях.

### 8. Нелінійні квадратичні втрати Бернуллі при великих амплітудах

При значних амплітудах звукового тиску (`SPL > 130` дБ) швидкість руху газу в шийці досягає десятків метрів на секунду. На гострих зрізах шийки виникає перепад тиску Бернуллі, пов'язаний з незворотною втратою динамічного напору газу при утворенні струменя:

```
Δp_Bernoulli = (1/2) · ρ · |v| · v / C_d²
```

де `C_d ≈ 0.6...0.8` — коефіцієнт витрати отвору.

Впровадження квадратичного доданка Бернуллі у диференціальне рівняння коливань перетворює гармонічний осцилятор на нелінійну систему. При цьому виникає нелінійне зсунення частоти, а також генерація непарних вищих гармонік `3f_H, 5f_H`. Ефективний опір втрат стає функцією об'ємної швидкості `U_A`, викличучи явище амплітудного самообмеження акустичних коливань.

### 9. Передавальна функція системи у частотній області (спектральний оператор)

Застосуємо пряме перетворення Фур'є `P(ω) = ∫ p(t) exp(−j ω t) dt` до диференціального рівняння вимушених коливань тиску в каверні `p_cavity(t)` під дією зовнішнього акустичного тиску `p_ext(t)`:

```
M_A · (d²U_A / dt²) + R_A · (dU_A / dt) + (1 / C_A) · U_A = (d p_ext / dt)
```

Комплексна передавальна функція акустичного тиску `H(ω) = P_cavity(ω) / P_ext(ω)` дорівнює:

```
H(ω) = 1 / (1 − (ω / ω₀)² + j · (ω / (ω₀ · Q)))
```

Модуль передавальної функції `|H(ω)|` виражає коефіцієнт підсилення тиску всередині каверни:
* На низьких частотах (`ω ≪ ω₀`) підсилення дорівнює одиниці (`|H| = 1`), тиск у каверні строго дорівнює зовнішньому тиску.
* На резонансій частоті (`ω = ω₀`) модуль передавальної функції сягає свого максимального пикового значення `|H(ω₀)| = Q`. Саме це підсилення акустичного тиску у `Q` разів дозволило Герману фон Гельмгольцу виявляти слабкі обертони людського голосу та музичних інструментів.
* На високих частотах (`ω ≫ ω₀`) підсилення спадає за законом `|H(ω)| ∝ (ω₀ / ω)²` зі швидкістю `12` дБ на октаву.

Застосування зсуву фази `Arg(H(ω))` показує, що на резонансій частоті тиск у каверні відстає від зовнішнього звукового тиску строго на `90°` (`π/2` радіан). На високих частотах фазовий зсув прямує до `180°` (`π` радіан), що відповідає протифазним коливанням.

### 10. Акустична теорема Крамерса — Кроніга та причинність

Оскільки акустична система є лінійною та причинною, дійсне та уявне значення комплексного імпедансу `Z_A(ω) = R_A(ω) + j · X_A(ω)` зв'язані між собою дисперсійними інтегральними співвідношеннями Крамерса — Кроніга:

```
X_A(ω) = −(2 · ω / π) · P.V. ∫₀^∞ (R_A(ω') / (ω'² − ω²)) dω'
```

де `P.V.` позначує головне значення інтеграла за Коші. Це співвідношення показує фундаментальний фізичний факт: наявність активної дисипації енергії `R_A(ω)` неминуче породжує дисперсію та фазову затримку реактансу `X_A(ω)`.

### 11. Ненезалежність від геометрії каверни у довгохвильовій межі

Цікавим математичним питанням є те, чи залежить резонансна частота `f_H` від геометричної форми каверни (сфера, куб, прямокутний паралелепіпед чи довільна складна судина).

Застосуємо варіаційне розкладання потенціалу тиску `p(x, y, z)` всередині каверни `V` за власними функціями тривимірного оператора Лапласа `ψ_n(x, y, z)` з нейманівськими крайовими умовами `∂ψ_n / ∂n = 0` на жорстких стінках:

```
∇²ψ_n + k_n² · ψ_n = 0
```

Власні хвильові числа тривимірних мод каверни дорівнюють `k_{l,m,n} = π · √((l/L_x)² + (m/L_y)² + (n/L_z)²)`.

Найнижча власна мода `k₀ = 0` відповідає поршневому (монопольному) стиску газу, де `ψ₀ = const`. Наступні вищі тривимірні моди каверни мають хвильові числа `k₁ ≥ π / D_max`.

Оскільки у довгохвильовій межі акустичне хвильове число `k_H = ω₀ / c` задовольняє умову `k_H ≪ k₁`, внесок усіх вищих просторових мод `ψ_n (n ≥ 1)` є зневажливо малим і придушується множником `(k_H / k_n)² ≪ 1`.

Отже, фундаментальна частота резонатора Гельмгольца `f_H` **не залежить від конкретної геометричної форми каверни** (чи це куля, циліндр або куб), а визначається строго її повною об'ємною мірою `V`. Форма каверни впливає лише на частоти вищих партикулярних резонансів каверни, які лежать у кілогерцовій області.

### 12. Порівняльний аналіз хвильових та зосереджених акустичних систем

Для глибшого математичного розуміння порівняємо резонатор Гельмгольца з розподіленими акустичними резонаторами — відкритою органною трубою та чвертьхвильовим закритим хвилеводом.

| Характеристика | Резонатор Гельмгольца | Відкрита труба (`λ/2`) | Чвертьхвильова труба (`λ/4`) |
| :--- | :--- | :--- | :--- |
| **Фізичний тип** | Система із зосередженими параметрами | Хвильова розподілена система | Хвильова розподілена система |
| **Співвідношення габаритів** | `λ ≫ V^(1/3)` та `λ ≫ L` | `λ = 2 · L` | `λ = 4 · L` |
| **Основна резонансна частота** | `f_H = (c / 2π) · √(S / (V L_eff))` | `f₁ = c / (2 L)` | `f₁ = c / (4 L)` |
| **Спектр вищих гармонік** | Відсутній у квазістатичній зоні | Повний спектр: `f_n = n · f₁` | Лише непарні: `f_n = (2n-1) f₁` |
| **Розподіл тиску всередині** | Просторово однорідний `∇p = 0` | Синусоїдальний `p(x) = p₀ cos(kx)` | Синусоїдальний `p(x) = p₀ sin(kx)` |

Цей порівняльний аналіз показує головне теоретичне досягнення моделі Гельмгольца: вона дозволяє отримувати як завгодно низькі резонансні частоти `f_H` при мінімальних геометричних габаритах за рахунок зменшення перерізу шийки `S` або збільшення об'єму `V`, тоді як хвильові резонатори жорстко прив'язані до довжини хвилі співвідношенням `L = λ / 2` або `L = λ / 4`.
