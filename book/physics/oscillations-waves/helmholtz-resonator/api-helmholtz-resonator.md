# 📋 Інженерний довідник та інтерфейс параметрів резонатора Гельмгольца

Цей довідник містить повний систематизований перелік фізичних, геометричних та акустичних параметрів резонатора Гельмгольца, підсумкову таблицю розрахункових співвідношень, термодинамічні залежності від умов навколишнього середовища, аналіз границь застосовності моделі та специфікований заголовочний контракт API (С/C++) для інтеграції моделі резонатора в акустичні САПР і DSP-процесори аудіообробки.

### 1. Детальний фізичний розбір акустичних параметрів

У фундаментальній та прикладній акустиці функціонування резонатора Гельмгольца описується через п'ять пов'язаних наборів параметрів. Нижче наведено детальний огляд фізичного змісту та механічної аналогії кожної групи параметрів.

#### А. Геометрична підсистема резонатора
* **Об'єм внутрішньої каверни `V` (м³):** Задає замкнений об'єм стискуваного газу. У концепції зосереджених параметрів об'єм каверни визначає пружну повертальну силу (акустичну гнучкість). Чим більший об'єм каверни `V`, тим м'якшою є повітряна подушка, і тим нижчою виявляється власна частота коливань.
* **Фізична довжина шийки `L` (м):** Визначає довжину геометрії каналу, в якому зосереджено основну масу повітряного поршня.
* **Внутрішній радіус шийки `r` (м) та площа перерізу `S = π · r²` (м²):** Площа перерізу шийки визначає площу контактної поверхні, через яку тиск у каверні передає механічний імпульс повітряному поршню.
* **Ефективна акустична довжина шийки `L_eff` (м):** Фізична довжина шийки `L`, збільшена на суму внутрішньої та зовнішньої кінцевих поправок Релея `ΔL_in` і `ΔL_out`. Вона враховує приєднану масу повітря, яке бере участь у коливальному русі біля відкритих зрізів шийки.

#### Б. Термодинамічні параметри газового середовища
* **Рівноважна густина газу `ρ` (кг/м³):** Задає масу одиниці об'єму середовища. Визначає акустичну масу шийки `M_A` та характеристичний імпеданс середовища `z₀ = ρ · c`.
* **Акустична швидкість звуку `c` (м/с):** Швидкість поширення поздовжніх малих акустичних збурень у газі. Визначається як `c = √(γ · p₀ / ρ)`.
* **Рівноважний атмосферний тиск `p₀` (Па):** Базовий статичний тиск середовища, який визначає модуль об'ємної пружності газу `K = γ · p₀`.
* **Показник адіабати газу `γ = c_p / c_v`:** Безрозмірне співвідношення питомих теплоємностей газу при постійному тиску та постійному об'ємі (`γ ≈ 1.40` для повітря).
* **Динамічна в'язкість газу `μ` (Па·с):** Визначає опір в'язкого тертя у динамічному межовому шарі на внутрішніх стінках шийки.

#### В. Зосереджені акустичні еквіваленти
* **Акустична маса (інертність шийки) `M_A = (ρ · L_eff) / S` (кг/м⁴):** Міра інерційного опору повітряного стовпа в шийці при прискоренні об'ємного потоку газу. Вона є прямою акустичною аналогією електричної індуктивності `L`.
* **Акустична гнучкість (ємність каверни) `C_A = V / (ρ · c²)` (м⁵/Н):** Міра пружної здатності повітряного об'єму накопичувати потенціальну енергію при адіабатичному стиску. Є прямою акустичною аналогією електричної ємності `C`.
* **Повний акустичний опір втрат `R_A` (Па·с/м³):** Сума активних опорів втрат на акустичне випромінювання `R_rad`, в'язке тертя `R_visc` та теплопровідність `R_therm`. Є аналогом електричного активного опору `R`.
* **Комплексний акустичний імпеданс `Z_A(ω) = R_A + j · X_A` (Па·с/м³):** Комплексна величина, яка визначає відношення надлишкового акустичного тиску `p_in` до об'ємного потоку `U_A` у перерізі шийки.

### 2. Фізичні обмеження та критерії валідності математичної моделі

Класична формула Гельмгольца `f_H = (c / 2π) · √(S / (V · L_eff))` спирається на наближення зосереджених параметрів. Для забезпечення високої точності розрахунків у реальних інженерних системах слід суворо контролювати дотримання чотирьох фундаментальних критеріїв валідності.

```
                  ┌──────────────────────────────────────────┐
                  │    КРИТЕРІЇ ВАЛІДНОСТІ МОДЕЛІ            │
                  └──────────────────────────────────────────┘
                                       │
         ┌─────────────────────────────┼─────────────────────────────┐
         ▼                             ▼                             ▼
┌─────────────────┐           ┌─────────────────┐           ┌─────────────────┐
│ 1. Довгохвильове│           │ 2. Вузькість    │           │ 3. Адіабатичний │
│    наближення   │           │    шийки        │           │    стиск        │
│ λ ≫ V^(1/3)     │           │ L_eff ≪ λ / 2π  │           │ f ≫ f_thermal   │
└─────────────────┘           └─────────────────┘           └─────────────────┘
```

#### А. Критерій долгохвильової зосередженості (просторова однорідність)
Акустичний тиск всередині каверни можна вважати однорідним тільки у тому випадку, коли найбільший фізичний розмір каверни `D_max` не перевищує десятої частини довжини хвилі на резонансій частоті `λ_H = c / f_H`:

```
D_max ≤ 0.10 · λ_H   ⇒   k_H · D_max ≤ 0.63
```

Якщо цей критерій порушується (наприклад, при `D_max > 0.20 · λ_H`), усередині каверни виникають власні хвильові моди (стоячі хвилі каверни), а похибка розрахунку резонансної частоти за зосередженою формулою перевищує `5%`.

Наприклад, якщо ми розраховуємо каверну об'ємом `100` літрів з розміром стінки `D = 0.5` метра, довжина звукової хвилі на частоті `100` Гц становить `λ = 3.43` метра. Оскільки `D / λ = 0.5 / 3.43 ≈ 0.146`, це значення перевищує поріг `0.10`. У такій великій каверні тиск на задній стінці буде відрізнятися від тиску коло шийки, і класична модель Гельмгольца дасть помилку у визначенні частоти.

#### Б. Критерій коротности шийки
Фізична довжина шийки `L` повинна бути значно меншою за довжину акустичної хвилі, щоб повітря у ній рухалося як єдиний несжимаємий поршень:

```
L_eff ≤ 0.08 · λ_H
```

При збільшенні довжини шийки до `L_eff ≈ 0.25 · λ_H` шийка починає поводитися як самостійний чвертьхвильовий органний резонатор. У системі з'являється нескінченна серія вищих гармонік `f_n = n · (c / 4 L_eff)`, а класична модель Гельмгольца втрачає застосовність.

#### В. Критерій адіабатичного стиску газу
Стиск повітря у каверні описується адіабатичним модулем пружності `K = γ · p₀` лише тоді, коли частота коливань `f` значно перевищує граничну частоту теплової релаксації `f_th`:

```
f_th = κ / (π · ρ · c_p · D²)
```

де `κ` — теплопровідність газу, `c_p` — питома ізобарна теплоємність. Для повітря в каверні розміром `D = 0.1` м частота `f_th` становить частки мілігерца (`10⁻⁴` Гц). Оскільки всі реальні акустичні частоти перевищують `10` Гц, процес у центрі каверни є строго адіабатичним. Однак коло стінок існує тонкий тепловий межовий шар `δ_th = √(2κ / (ρ c_p ω))`, який створює додатковий опір теплових втрат `R_therm`.

#### Г. Межа лінійності (рівень звукового тиску)
Класичні лінійні рівняння акустики дійсні за умови, що амплітуда коливальної швидкості газу в шийці `v₀` не перевищує критичного значення вихроутворення:

```
M_v = v₀ / c ≤ 0.05       (відповідає рівням звукового тиску SPL ≤ 130 дБ)
Re_a = (ρ · v₀ · r) / μ ≤ 500
```

При рівнях тиску `SPL > 130` дБ у шийці виникають розриви потоку, турбулентні вихори та генерація вищих гармонік. Опір резонатора перестає бути постійним і лінійно зростає з ростом амплітуди тиску.

### 3. Термодинамічні залежності від умов навколишнього середовища

Резонансна частота `f_H` та опір втрат `R_A` резонатора Гельмгольца не є абсолютно фіксованими константами — вони суттєво змінюються при коливаннях температури, атмосферного тиску, вологості та складу газу.

#### А. Вплив температури повітря
Швидкість звуку `c` та густина повітря `ρ` сильно залежать від температури `T` (в °C):

```
c(T) = 331.3 · √(1 + T / 273.15)  ≈  331.3 + 0.606 · T   (м/с)
ρ(T) = 1.293 · (273.15 / (273.15 + T))                  (кг/м³)
```

Оскільки резонансна частота прямо пропорційна швидкості звуку `f_H ∝ c`, зміна температури на кожні `5 °C` викликає зміщення резонансної частоти приблизно на `0.9%`:

```
f_H(T) = f_H(0 °C) · √(1 + T / 273.15)
```

При підвищенні температури з `0 °C` до `30 °C` резонансна частота акустичного резонатора зростає на `5.3%` (наприклад, з `100.0` Гц до `105.3` Гц). Це вимагає обов'язкової термокомпенсації при проектуванні точних акустичних фільтрів та музичних інструментів.

#### Б. Вплив атмосферного тиску та висоти над рівнем моря
При зміні статичного тиску `p₀` (наприклад, при підйомі в гори або політі літака) густина повітря `ρ` зменшується пропорційно тиску `ρ = (p₀ · M_g) / (R_g · T)`. Оскільки швидкість звуку `c = √(γ p₀ / ρ)` залежить лише від відношення тиску до густини, швидкість звуку при постійній температурі залишається **незмінною**!
Проте зміна густини `ρ` впливає на акустичну масу `M_A` та характеристичний імпеданс `z₀ = ρ · c`. Внаслідок цього на великій висоті резонансна частота `f_H` залишається постійною, але добротність `Q` зміщується через зменшення в'язкого тертя та випромінювання.

#### В. Вплив молярної маси та типу газу
При заповненні резонатора іншим газом швидкість звуку `c` обчислюється через молярну масу `M_g` та показник адіабати `γ`:

```
c = √(γ · R_g · (T + 273.15) / M_g)
```

де `R_g = 8.31446` Дж/(моль·К) — універсальна газова стала.

| Назва газу | Формула | Молярна маса `M_g` (г/моль) | Показник адіабати `γ` | Швидкість звуку `c` (20 °C, м/с) | Відносне зміщення `f_H` |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Повітря | N₂ + O₂ | `28.97` | `1.40` | `343.2` | `1.000` (база) |
| Гелій | He | `4.00` | `1.67` | `1007.0` | `2.934` (зростання у ~3 рази) |
| Вуглекислий газ| CO₂ | `44.01` | `1.30` | `267.0` | `0.778` (зниження на 22%) |
| Елегаз (SF₆) | SF₆ | `146.06` | `1.09` | `152.0` | `0.443` (зниження на 56%) |
| Метан | CH₄ | `16.04` | `1.31` | `446.0` | `1.299` (зростання на 30%) |

#### Г. Вплив відносної вологості повітря
При підвищенні відносної вологості повітря водяна пара (з молярною масою `18.01` г/моль) витісняє важчий сухий газ (`28.97` г/моль). Це незначно знижує середня густину повітря `ρ` і підвищує швидкість звуку `c` приблизно на `0.35%` при `100%` вологості й температурі `20 °C`. Водночас молекули водяної пари істотно прискорюють процеси коливальної релаксації азоту та кисню, підвищуючи об'ємне затухання звуку на високих частотах.

### 4. Співвідношення акустичних та механічних одиниць СІ

Для полегшення розрахунків у суміжних інженерних дисциплінах нижче наведено аналогії та зв'язки між коефіцієнтами в різних фізичних системах одиниць.

В акустичній системі основними змінними є акустичний тиск `p` (Па) та об'ємний потік `U_A` (м³/с). Перехід до механічної системи «маса-сила» (де основними змінними є сила `F` у Ньютонах та швидкість `v` у м/с) здійснюється множенням або діленням на квадрат площі шийки `S²`:

* **Механічна маса поршня:** `m = S² · M_A = ρ · S · L_eff` (кг).
* **Механічна жорсткість повітряної подушки:** `k = S² / C_A = (ρ · c² · S²) / V` (Н/м).
* **Механічний опір втрат:** `R_m = S² · R_A` (Н·с/м).

Ці формули зв'язку дозволяють безпосередньо впроваджувати розраховані значення акустичного резонатора Гельмгольца у універсальні системи скінченноелементного та динамічного моделювання механічних систем (таких як ANSYS, COMSOL Multiphysics, MATLAB Simscape).

### 5. Інженерний синтез геометрії та регулювання добротності

При інженерному проектуванні резонатора часто виникає зворотна задача: розрахувати оптимальні геометричні розміри каверни `V` та шийки `L, r` для забезпечення заданої частоти `f_target` та заданої добротності `Q_target`.

Алгоритм зворотного інженерного синтезу складається з чотирьох кроків:
1. **Вибір об'єму каверни `V`:** Виходячи з доступних габаритних обмежень конструкції.
2. **Обчислити необхідне відношення `S / L_eff`:** З виразу `S / L_eff = (2π · f_target / c)² · V`.
3. **Вибір радіуса шийки `r`:** З урахуванням нелінійного обмеження по швидкості потоку та очікуваного рівня звукового тиску.
4. **Введення пористого звукопоглинача:** Якщо природна добротність резонатора `Q_natural ≈ 40` є занадто високою (вузька смуга поглинання), всередину шийки або каверни впроваджують шар пористого матеріалу (тканину, сітку або мінеральну вату) з питомим продувальним опором `σ`. Це підвищує опір втрат `R_A` до розрахункового рівня, знижуючи добротність до необхідного широкого значення `Q ≈ 2…4`.

### 6. Стандартизовані акустичні випробування (ISO 354, ISO 11654, ASTM C423)

Для лабораторної сертифікації акустичних панелей на основі резонаторів Гельмгольца вимірювання проводять у спеціальних ревербераційних камерах згідно з міжнародними стандартами **ISO 354** та **ASTM C423**.

Вимірювання базується на обчисленні ревербераційного часу `T₆₀` (часу згасання звукової енергії на `60` дБ після вимкнення джерела) порожньої камери `T₆₀,empty` та камери зі зразком акустичних панелей `T₆₀,sample`. Коефіцієнт поглинання за Себіном `α_S` розраховується за формулою Себіна:

```
α_S = (55.3 · V_chamber / (c · S_sample)) · (1 / T₆₀,sample − 1 / T₆₀,empty)
```

Згідно зі стандартом **ISO 11654**, виміряні спектри `α_S(f)` у третьоктавних смугах частот від `125` Гц до `4000` Гц порівнюють зі стандартною нормативною кривою для обчислення зваженого коефіцієнта звукопоглинання `α_w` та присвоєння класифікаційного класу звукопоглинання (від класу A до класу E).

### 7. Випробування глушників на аероакустичних стендах із продувкою

Для випробування реактивних глушників вихлопних систем двигунів та авіаційних систем кондиціонування застосовують випробувальні стенди з супутнім потоком повітря (*flow duct rigs*).

Супутній потік повітря зі швидкістю `v_flow` (число Маха `M = v_flow / c`) змінює акустичний імпеданс отвору резонатора:
* Потік здуває приєднану масу повітря, зменшуючи зовнішню кінцеву поправку Релея: `ΔL_out(M) = ΔL_out(0) / (1 + (1.5 · M)²)`. Це зсуває резонансну частоту `f_H` убік вищих частот.
* Потік створює додатковий опір продувки `R_flow = ρ · v_flow / (S · C_flow)`, що знижує добротність глушника.

Головним показником ефективності глушника на стенді є **внесені втрати** (*Insertion Loss*, `IL`), які визначаються як різниця рівнів звукового тиску у децибелах на виході каналу до та після встановлення резонатора Гельмгольца:

```
IL(f) = 20 · log10(|p_without(f)| / |p_with(f)|)   (дБ)
```

При проектуванні авіаційних двигунів турбореактивних літаків (наприклад, Boeing 787 або Airbus A350) стінки повітрозабірників облицьовують так званими звукопоглинальними сендвіч-панелями (*acoustic liners*). Ці панелі являють собою стільникову структуру (*honeycomb core*), накриту перфорованим металевим або композитним листом. Кожен отвір перфорації є шийкою резонатора Гельмгольца, забезпечуючи високоефективне глушіння шуму лопаток двигуна.

### 9. Інженерний контроль граничних режимів та діагностика відмов

При довготривалій експлуатації резонаторів Гельмгольца в реальних промислових та побутових умовах виникають граничні режими, які потребують спеціальних інженерних заходів.

#### А. Забруднення та конденсація у шийці
У вихлопних системах автомобілів або промислових вентиляційних каналах на внутрішніх стінках шийки відкладаються сажа, пил та конденсат вологи. Зменшення ефективного радіуса шийки на `10%` викликає зміщення резонансної частоти вниз на `5%` (`f_H ∝ r`), а в'язкий опір зростає на `33%` (`R_visc ∝ 1/r³`), що призводить до повного розладу акустичного фільтра та падіння добротності. Інженерне рішення полягає у виборі шийок із радіусом `r > 8` мм та застосуванні водовідштовхувальних покриттів.

#### Б. Термоакустичний саморозігрів газу в шийці
При високих рівнях звуку (`SPL > 140` дБ) в'язке тертя у шийці дисипує акустичну потужність до декількох ват. Локальний розігрів газу у шийці підвищує температуру на десятки градусів, змінюючи швидкість звуку `c` та в'язкість `μ`. Це спричиняє термоакустичний дрейф частоти резонансу під час роботи системи на повній потужності.

#### В. Акустичний зв'язок у масивах резонаторів (мультирезонатори)
При створенні звукопоглинальних конструкцій із масивом близьковстановлених отворів (наприклад, перфоровані гіпсокартонні панелі) відстань між шийками `d` часто стає меншою за `4 · r`. У цьому разі зовнішні сферичні поля приєднаних мас суміжних отворів перекриваються. Це викликає взаємне збільшення ефективної довжини шийок `L_eff`, що знижує резонансну частоту масиву на `10–20%` проти розрахунку поодинокого отвору.
