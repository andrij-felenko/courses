# 🧮 Математичне виведення добротності: п'ять еквівалентних означень

Ця математична вставка містить строгі алгебраїчні виведення співвідношень для добротності Q: від фундаментального енергетичного означення через диференціальне рівняння осцилятора до смуги резонансу, нахилу фази та зв'язку з коефіцієнтом загасання.

## 1. Фундаментальне енергетичне означення та спад амплітуди

На фундаментальному термодинамічному рівні добротність `Q` визначається як відношення запасеної в системі енергії `W` до дисипованої (втраченої) енергії `ΔW_цикл` за один період коливань `T = 2π / ω₀`:

```
Q = 2π · ( W / ΔW_цикл )
```

Коефіцієнт `2π` з'являється тому, що повний період коливань відповідає фазовому куту у `2π` радіан. Якщо розглянути розсіювання енергії як безперервний процес, можна виразити швидкість зміни енергії по фазовому куту `φ = ω₀ t`. Зміна енергії за один радіан дорівнює:

```
dW / dφ = − W / Q
```

Якщо ж виразити втрату енергії за малий проміжок часу `dt = dφ / ω₀`, ми дістанемо класичне диференціальне рівняння першого порядку для енергії системи:

```
dW / dt = − (ω₀ / Q) · W
```

Це диференціальне рівняння зі розділюваними змінними розв'язується шляхом інтегрування обидвох частин:

```
∫ (1 / W) dW = − ∫ (ω₀ / Q) dt   ⇒   ln(W) = − (ω₀ / Q) · t + C
```

Враховуючи початкову умову `W(0) = W₀`, отримуємо експоненційний спад енергії з часом:

```
W(t) = W₀ · e^( − (ω₀ / Q) · t )
```

Оскільки механічна або електрична енергія коливальної системи пропорційна квадрату амплітуди (`W ~ A²`), закон спадання амплітуди коливань `A(t)` містить у удвічі менший показник експоненти:

```
A(t) = A₀ · e^( − (ω₀ / (2Q)) · t ) = A₀ · e^( − (π · f₀ / Q) · t )
```

Звідси легко виводиться **логарифмічний декремент загасання** `δ` — натуральний логарифм відношення двох послідовних амплітуд через один період `T`:

```
δ = ln( A(t) / A(t + T) )
  = ln( e^( (π·f₀·T / Q) ) )       [законом спаду A(t) = A₀ e^(−π·f₀·t / Q)]
  = (π · f₀ / Q) · T             [тотожність ln(e^x) = x]
  = (π · f₀ / Q) · (1 / f₀)      [значення періоду T = 1 / f₀]
  = π / Q                        [скорочення частоти f₀]
```

Таким чином, добротність прямо пов'язана з декрементом загасання пропорційністю `Q = π / δ`. За один період коливань амплітуда зменшується в `e^(π / Q)` разів, а за `Q` періодів енергія системи падає в `e^(2π) ≈ 535` разів.

## 2. Виведення Q з диференціального рівняння вільного осцилятора

Розглянемо диференціальне рівняння вільного загасного осцилятора з масою `m`, жорсткістю `k` та коефіцієнтом в'язкого тертя `c`:

```
m·ẍ + c·ẋ + k·x = 0
```

Поділимо рівняння на масу `m` та введемо власну частоту `ω₀ = √(k/m)` і темп загасання `γ = c / (2m)`:

```
ẍ + 2γ·ẋ + ω₀²·x = 0
```

Застосуємо методом Ейлера пробну функцію `x(t) = e^(λt)`. Підстановка дає характеристичне рівняння:

```
λ² + 2γ·λ + ω₀² = 0
```

Його корені дорівнюють:

```
λ₁,₂ = −γ ± √(γ² − ω₀²) = −γ ± i · √(ω₀² − γ²)
```

У слабкодемпфованому режимі (`γ < ω₀`) уявна частина є квазірезонансною частотою коливань `ω_d = √(ω₀² − γ²)`. Дійсна частина `−γ` відповідає за експоненційне спадання амплітуди `e^(−γ t)`.

Порівнюючи показник експоненційного спаду амплітуди `A(t) = A₀ · e^(−γ t)` із виведеною раніше формулою `A(t) = A₀ · e^(−ω₀ t / (2Q))`, отримуємо прямий зв'язок темпу загасання та добротності:

```
γ = ω₀ / (2Q)   ⇒   Q = ω₀ / (2γ)
```

Підставивши фізичні параметри осцилятора `γ = c / (2m)` та `ω₀ = √(k/m)`, дістаємо вирази для механічної добротності:

```
Q = m·ω₀ / c = √(m·k) / c
```

Виразимо добротність через безрозмірний **коефіцієнт загасання** (демпфування) `ζ = γ / ω₀ = c / (2√(m·k))`:

```
Q = 1 / (2ζ)
```

Це співвідношення є містком між теорією автоматичного керування (де оперують коефіцієнтом `ζ`) та радіотехнікою й акустикою (де оперують добротністю `Q`).

## 3. Вимушені коливання, висота піка та смуга пропускання

Розглянемо осцилятор під дією зовнішньої періодичної сили `F(t) = F₀ · cos(ω t)`:

```
ẍ + 2γ·ẋ + ω₀²·x = (F₀ / m) · cos(ω t)
```

У сталогому режимі амплітуда вимушених коливань `A(ω)` залежить від частоти збудження `ω`:

```
A(ω) = (F₀ / m) / √( (ω₀² − ω²)² + 4γ²·ω² )
```

На нульовій частоті (`ω = 0`) маємо статичне відхилення під дією сили: `A_stat = F₀ / (m·ω₀²) = F₀ / k`. На точній резонансній частоті (`ω = ω₀`) амплітуда сягає свого максимуму:

```
A_max = (F₀ / m) / (2γ·ω₀) = (F₀ / (m·ω₀²)) · (ω₀ / (2γ)) = A_stat · Q
```

Отже, **добротність Q показує, у скільки разів амплітуда на резонансі перевищує статичне відхилення**.

Знайдемо смугу пропускання за рівнем половинної потужності (або `1/√2 ≈ 0.707` від максимуму амплітуди). Для цього прирівняємо квадрат амплітуди до половини максимального значення:

```
A(ω)² = 1/2 · A_max²
```

При слабкому загасанні (`Q >> 1`) поблизу резонансу можна припустити `ω₀² − ω² = (ω₀ − ω)(ω₀ + ω) ≈ 2ω₀ · Δω`. Звідси граничні частоти `ω₁` та `ω₂` задовольняють умову:

```
(2ω₀ · Δω)² = 4γ²·ω₀²   ⇒   Δω = 2γ = ω₀ / Q
```

Переходячи до циклових частот у герцах (`f = ω / 2π`), дістаємо класичну формулу смуги пропускання `Δf`:

```
Δf = f₂ − f₁ = f₀ / Q   ⇒   Q = f₀ / Δf
```

## 4. Фазово-частотна характеристика та крутизна переходу

Зсув фази `φ(ω)` між зовнішньою силою та відгуком осцилятора описується формулою:

```
tan φ(ω) = − (2γ·ω) / (ω₀² − ω²) = − ( (ω / Q) ) / ( 1 − (ω / ω₀)² )
```

На резонансній частоті `ω = ω₀` фаза дорівнює `φ = −π/2` (−90°). Похідна фази по частоті (крутизна фазової характеристики) на резонансі обчислюється як:

```
dφ / dω |_(ω = ω₀) = 2Q / ω₀ = Q / (π · f₀)
```

Висока добротність `Q` означає надзвичайно крутий переворот фази на резонансі. Саме ця висока крутизна `dφ/dω` робить кварцові та оптичні резонатори стійкими до зовнішніх фазових шумів у генераторах частоти.

## 5. Власна добротність проти навантаженої (Q₀, Q_ext та Q_L)

У реальних фізичних приладах резонатор не ізольований, а під'єднаний до зовнішнього кола або вимірювального тракту. Повна дисипація потужності `P_total` складається з внутрішніх втрат `P_internal` та втрат у зовнішньому навантаженні `P_external`:

```
P_total = P_internal + P_external
```

Поділивши це рівняння на `ω₀ · W`, дістаємо правило паралельного додавання втрат для добротностей:

```
1 / Q_L = 1 / Q₀ + 1 / Q_ext
```

де розрізняють:
1. **Власну (ненавантажену) добротність** `Q₀ = ω₀ · W / P_internal` — втрати лише всередині самого резонатора.
2. **Зовнішню добротність** `Q_ext = ω₀ · W / P_external` — енергія, що випромінюється у зовнішнє навантаження.
3. **Навантажену добротність** `Q_L` — сукупна добротність резонатора в колі.

Коли зв'язок зі зовнішнім трактом є критичним (критичне узгодження імпедансів, `Q₀ = Q_ext`), навантажена добротність стає точно вдвічі меншою за власну: `Q_L = Q₀ / 2`.

## 6. Обчислення добротності в оптичних резонаторах Фабри — Перо

В оптиці та лазерній фізиці коливальною системою є стояча світлова хвиля між двома діелектричними дзеркалами з коефіцієнтами відбивання `R₁` та `R₂` на відстані `L`.

Повна енергія фотонного поля в порожнині довжиною `L` розсіюється за рахунок часткового проходження крізь дзеркала на кожному проході. Коефіцієнт пропускання за один прохід дорівнює `1 − R`, де `R = √(R₁ · R₂)`.

Час одного проходу фотона між дзеркалами становить `t_pass = L / c` (де `c` — швидкість світла), а період оптичної хвилі `T = λ / c`. Кількість відбивань за один період світлової хвилі дорівнює `T / (2 t_pass) = λ / (2L)`.

Добротність оптичного резонатора виражається через резкість (*finesse*) `F`:

```
F = (π · √R) / (1 − R)
```

Співвідношення між добротністю `Q` та різкістю `F` дорівнює:

```
Q = (2π L / λ) · ( √R / (1 − R) ) = m · F
```

де `m = 2L / λ` — порядковий номер повздовжньої моди резонатора (кількість півхвиль, що вміщаються на довжині `L`). Для реальних оптичних порожнин `m ≈ 10⁵ … 10⁶`, що при `R = 0.9999` дає гігантську добротність `Q ≈ 10⁸ … 10¹¹`.
