# 📋 Інженерні параметри та специфікація експоненційного рупора

Цей довідниковий документ визначає інженерну специфікацію, параметричний контракт, таблиці фізичних співвідношень, акустичні матричні моделі та граничні конструктивні обмеження для розрахунку й сполучення експоненційного акустичного рупора з електромеханічними випромінювачами (компресійними драйверами).

### 1. Специфікація параметрів акустичного рупора

В акустичній інженерії та розрахунку звукових систем експоненційний рупор описується стандартизованим набором геометро-акустичних параметрів:

| Назва параметра | Символ | Одиниця вимірювання (СІ) | Фізичний зміст та допуск |
| :--- | :--- | :--- | :--- |
| **Площа горла** | `S₀` | м² (або см²) | Площа початкового перерізу рупора в місці стикування з драйвером. Допуск ±0.5%. |
| **Площа гирла** | `S_L` | м² (або см²) | Площа кінцевого відкритого перерізу рупора на межі з вільним простором. |
| **Показник розширення** | `m` | м⁻¹ | Постійна експоненціального зростання площі: `S(x) = S₀ · e^(m·x)`. |
| **Довжина рупора** | `L` | м (або см) | Відстань вздовж центральної осі від горла до гирла. |
| **Критична частота зрізу** | `f_c` | Гц | Нижній поріг частоти, вище якого починається активне випромінювання енергії: `f_c = m·c / (4·π)`. |
| **Нижня робоча частота** | `f_min` | Гц | Рекомендована мінімальна частота сигналу: `f_min ≥ 1.4 · f_c` до `2.0 · f_c`. |
| **Діаметр горла** | `d₀` | м (або дюйми) | Еквівалентний круговий діаметр горла: `d₀ = 2 · √(S₀ / π)`. |
| **Діаметр гирла** | `d_L` | м (або см) | Еквівалентний круговий діаметр гирла: `d_L = 2 · √(S_L / π)`. |
| **Характеристичний імпеданс** | `Z₀` | Па·с/м³ | Асимптотичний хвильовий опір горла: `Z₀ = ρ₀ · c / S₀`. |
| **Коефіцієнт стиску** | `CR` | безрозмірний | Відношення площі дифузора драйвера `S_d` до площі горла `S₀`: `CR = S_d / S₀`. |

### 2. Детальний опис геометро-акустичних параметрів та їхнього фізичного впливу

Кожен із наведених параметрів відіграє критичну роль у формуванні амплітудно-частотної характеристики, коефіцієнта корисної дії та спрямованості акустичної системи:

* **Площа горла (`S₀`):** визначає рівень акустичного навантаження на мембрану драйвера. Чим менша площа горла порівняно з площею мембрани, тим вищий акустичний опір і ККД системи, але тим більші нелінійні спотворення повітря у предрупорній камері. При зменшенні `S₀` тиск у горлі зростає, змушуючи легку мембрану віддавати максимальну механічну потужність.
* **Показник розширення (`m`):** визначає крутизну розширення каналу. Велике значення `m` робить рупор коротким, але зсуває частоту зрізу `f_c` у бік високих частот. Мале значення `m` дозволяє відтворювати глибокі баси, але вимагає значної довжини `L`.
* **Площа гирла (`S_L`):** відповідає за узгодження внутрішнього середовища рупора з відкритим вільним простором. Якщо площа гирла занадто мала, звукова хвиля зазнає сильного відбиття від країв рупора, утворюючи стоячі хвилі й глибокі пульсації на імпедансній кривій.
* **Довжина рупора (`L`):** визначається співвідношенням площ гирла й горла та показником розширення `m`. Збільшення довжини при фіксованих `S₀` та `S_L` вимагає зменшення `m`, що знижує частоту зрізу `f_c`.
* **Характеристичний імпеданс горла (`Z₀ = ρ₀·c / S₀`):** є граничною асимптотичною величиною активного акустичного опору, до якої прямує вхідний опір рупора на високих частотах (`f ≫ f_c`).
* **Нижня робоча частота (`f_min`):** обирається вищою за частоту зрізу `f_c` у 1.4–2.0 рази для того, щоб уникнути роботи на крутому схилі імпедансної характеристики, де присутні високі фазові спотворення та сплески реактивної акустичної маси.

### 3. Фундаментальні розрахункові формули та співвідношення

Низка математичних формул визначає взаємозв'язок між інженерними параметрами експоненційного рупора при швидкості звуку `c = 343 м/с` та густині повітря `ρ₀ = 1.204 кг/м³` (при температурі 20°C):

```
1. Площа перерізу на відстані x від горла:
   S(x) = S₀ · e^(m · x)

2. Еквівалентний діаметр перерізу на відстані x:
   d(x) = d₀ · e^(m · x / 2)

3. Показник розширення через частоту зрізу:
   m = (4 · π · f_c) / c ≈ 0.03663 · f_c  [для c = 343 м/с]

4. Критична частота зрізу через показник m:
   f_c = (m · c) / (4 · π) ≈ 27.298 · m  [для c = 343 м/с]

5. Розрахункова довжина L через площі перерізів:
   L = (1 / m) · ln(S_L / S₀) = (2 / m) · ln(d_L / d₀)

6. Мінімальна площа гирла для усунення хвильового відбиття (S_L_min):
   d_L_min ≥ c / (π · f_c) ≈ 109.18 / f_c  [в метрах]
   S_L_min ≥ c² / (4 · π · f_c²) ≈ 9363 / f_c²  [в м²]

7. Нормований активний вхідний опір R_in(f):
   R_in(f) = (ρ₀ · c / S₀) · √(1 - (f_c / f)²)  [при f ≥ f_c]

8. Нормована реактивна акустична маса X_in(f):
   X_in(f) = (ρ₀ · c / S₀) · (f_c / f)  [при f ≥ f_c]
```

### 4. Акустична матриця передачі (чотириполюсник)

Для розрахунку складних багаторамних або скінченних рупорних систем кожен сегмент експоненційного рупора довжиною `L` розглядається як акустичний чотириполюсник, що описується матрицею передачі `[A, B; C, D]`.

Зв'язок між акустичним тиском і об'ємною швидкістю на вході (горло: `p₁, U₁`) та на виході (гирло: `p₂, U₂`) задається системою рівнянь:

```
p₁ = A · p₂ + B · U₂
U₁ = C · p₂ + D · U₂
```

Елементи матриці передачі для експоненціального сегмента на частотах `f > f_c` розраховуються за формулами:

```
A = e^(m·L / 2) · [ cos(β·L) + (m / (2·β)) · sin(β·L) ]
B = j · (ρ₀·c / S_L) · (k / β) · e^(m·L / 2) · sin(β·L)
C = j · (S₀ / (ρ₀·c)) · (k / β) · e^(−m·L / 2) · sin(β·L)
D = e^(−m·L / 2) · [ cos(β·L) − (m / (2·β)) · sin(β·L) ]
```

де `k = 2·π·f / c` — хвильове число у вільному повітрі, а `β = √(k² − m²/4)` — хвильовий вектор у рупорі.

Вхідний акустичний імпеданс горла `Z_in = p₁ / U₁` при довільному навантаженні гирла імпедансом `Z_L = p₂ / U₂` визначається виразом:

```
Z_in = (A · Z_L + B) / (C · Z_L + D)
```

Матричний підхід дозволяє легко розраховувати каскадні з'єднання рупорних сегментів із різними коефіцієнтами розширення та враховувати вплив складних акустичних фільтрів.

### 5. Специфікація стикування з компресійним акустичним драйвером

Горло експоненційного рупора призначене для механічного та акустичного з'єднання з вихідним фланцем компресійного випромінювача (*compression driver*). Параметри стику мають строго відповідати промисловим стандартам:

#### Стандарти діаметрів вихідного горла драйверів
* **1 дюйм (25.4 мм):** стандарт для високочастотних рупорів (частота розділу кросовера `f_cross ≥ 1.2–2.0 кГц`). Площа `S₀ ≈ 5.07 см²`. Кріплення — зазвичай різбове (1 3/8"-18 TPI) або фланец на 2/3 болти.
* **1.4 дюйма (35.6 мм):** середньо-високочастотний стандарт (`f_cross ≥ 800–1200 Гц`). Площа `S₀ ≈ 9.94 см²`. Кріплення — стандартний 4-болтовий фланець.
* **2 дюйми (50.8 мм):** потужний середньочастотний та широкосмуговий стандарт (`f_cross ≥ 400–800 Гц`). Площа `S₀ ≈ 20.27 см²`. Кріплення — 4-болтовий фланець із діаметром кола міжцентрових відстаней 101.6 мм.

#### Коефіцієнт стиску (Compression Ratio)
Відношення площі випромінюючої мембрани драйвера `S_d` до площі горла рупора `S₀`:

```
CR = S_d / S₀
```

* **Рекомендований діапазон `CR`:** від `4:1` до `10:1`.
* **Призначення:** збільшує акустичний опір горла, змушуючи легку титанову або майларову мембрану працювати проти високого тиску повітря. Це підвищує електромеханічний ККД перетворення енергії до `20–40%` (на відміну від `1–2%` у звичайних конусних динаміках).
* **Граничні обмеження:** при `CR > 10:1` виникає нелінійний неадіабатичний стиск повітря у предрупорній камері, що призводить до високих гармонійних спотворень (поява другої гармоніки `HD₂` через нелінійність рівняння стану газу при високих акустичних тисках).

#### Максимальний акустичний тиск у горлі (`p_throat_max`)
Максимальний надлишковий тиск у горлі рупора не повинен перевищувати порогу нелінійності повітря:

```
p_throat_max ≤ 0.1 · p_atm ≈ 10 000 Па  (відповідає рівню акустичного тиску SPL ≈ 174 дБ)
```

При перевищенні цього рівня швидкість частинок стає порівнянною зі швидкістю звуку, утворюються ударні хвилі (*shock waves*), і звук відчутно спотворюється.

### 6. Характеристики спрямованості та фактори прямого випромінювання

Експоненційний рупор не лише трансформує імпеданс, а й концентрує акустичну енергію в обмеженому просторовому тілесному куті `Ω`:

| Параметр спрямованості | Позначення | Формула / Визначення | Інженерний зміст |
| :--- | :--- | :--- | :--- |
| **Фактор спрямованості** | `Q` | `Q = 4·π / Ω` | Відношення інтенсивності звуку на осі рупора до інтенсивності ненаправленого точкового джерела тієї ж потужності. |
| **Індекс спрямованості** | `DI` | `DI = 10 · lg(Q)` дБ | Логарифмічна міра концентрації звукової енергії вздовж головної осі. |
| **Кут розкриття (Coverage Angle)** | `θ_6dB` | Градуси (°) | Кут між напрямками, на яких інтенсивність звуку спадає на 6 дБ (вдвічі за тиском) від осьового значення. |

Для чистого експоненційного рупора кут розкриття звужується зі зростанням частоти за законом:

```
sin(θ / 2) ≈ c / (f · d_L)
```

Це явище називається **гострінням променя** (*beamwidth narrowing*). На високочастотному краю діапазону експоненційний рупор формує вузький гострий промінь уздовж осі.

### 7. Детальний приклад розрахунку та вибору параметрів

Розглянемо практичний інженерний приклад розрахунку експоненційного рупора для високоякісного концертного середньочастотного модуля.

#### Вхідні технічні вимоги:
* Нижня робоча частота акустичного модуля: `f_lower = 500` Гц.
* Використовуваний компресійний драйвер: 1.4-дюймовий вихід (`d₀ = 0.0356` м).
* Швидкість звуку: `c = 343` м/с.

#### Покроковий розрахунок:

1. **Розрахунок частоти зрізу `f_c`:**
Обираємо частоту зрізу з коефіцієнтом запасу 1.5 від нижньої робочої частоти:
`f_c = f_lower / 1.5 = 500 / 1.5 ≈ 333.3` Гц.

2. **Обчислення показника розширення `m`:**
`m = (4 · π · 333.33) / 343 ≈ 12.212` м⁻¹.

3. **Обчислення площі горла `S₀`:**
`S₀ = π · (0.0356)² / 4 ≈ 0.000995` м² (`9.95` см²).

4. **Визначення мінімального діаметра та площі гирла `S_L`:**
Щоб уникнути відбиття звукових хвиль від виходу, діаметр гирла повинен бути:
`d_L_min = 343 / (π · 333.33) ≈ 0.327` м (`32.7` см).
Мінімальна площа гирла:
`S_L_min = π · (0.327)² / 4 ≈ 0.0840` м² (`840` см²).

5. **Обчислення довжини рупора `L`:**
`L = (1 / 12.212) · ln(0.0840 / 0.000995) = (1 / 12.212) · ln(84.42) ≈ 0.363` м (`36.3` см).

6. **Контрольна перевірка імпедансу на робочих частотах:**
На частоті `f = 500` Гц:
`R_norm(500) = √(1 - (333.33 / 500)²) = √(1 - 0.444) ≈ 0.745`.
На частоті `f = 1000` Гц:
`R_norm(1000) = √(1 - (333.33 / 1000)²) = √(1 - 0.111) ≈ 0.943`.

Результати підтверджують, що розрахований рупор забезпечує понад `74.5%` від максимальної ефективності випромінювання вже на нижній межі 500 Гц та виходить на `94.3%` ефективності на частоті 1 кГц.
