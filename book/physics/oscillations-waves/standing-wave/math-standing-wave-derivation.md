# 🧮 Математична вставка: тригонометричний вивід стоячої хвилі та розподіл енергії

Математичний аналіз стоячої хвилі дає змогу точно пояснити два фундаментальних фактів: чому вузли й пучності залишаються нерухомими в просторі та чому стояча хвиля, на відміну від біжучої, не здійснює нетто-переносу енергії вздовж середовища.

---

### 1. Додавання двох протилежних біжучих хвиль з однаковою амплітудою

Розглянемо дві гармонічні біжучі хвилі з однаковою амплітудою `A`, коловою частотою `ω` та хвильовим числом `k = 2·π / λ`. Перша хвиля поширюється в додатному напрямку осі `x`, друга — у від'ємному:

```
y₁(x, t) = A·sin(k·x − ω·t)
y₂(x, t) = A·sin(k·x + ω·t)
```

За принципом суперпозиції підсумкове відхилення середовища `y(x, t)` дорівнює алгебраїчній сумі окремих відхилень:

```
y(x, t) = y₁ + y₂
        = A·sin(k·x − ω·t) + A·sin(k·x + ω·t)
```

Застосуємо тригонометричну тотожність для суми синусів `sin α + sin β = 2·sin((α + β)/2)·cos((α − β)/2)`:

```
α = k·x + ω·t
β = k·x − ω·t

(α + β) / 2 = (2·k·x) / 2 = k·x
(α − β) / 2 = (2·ω·t) / 2 = ω·t
```

Підставивши ці вирази у формулу суми, отримуємо рівняння стоячої хвилі:

```
y(x, t) = 2·A·sin(k·x)·cos(ω·t)   [рівняння ідеальної стоячої хвилі]
```

Отримане рівняння розпадається на два незалежних множники:
1. **Просторовий множник `2·A·sin(k·x)`** — визначає **профіль амплітуди**, який залежить виключно від координати `x` і залишається нерухомим із перебігом часу.
2. **Часовий множник `cos(ω·t)`** — описує синфазні гармонічні коливання всіх точок середовища з частотою `ω`.

### 2. Точне знаходження вузлів та пучностей

З рівняння стоячої хвилі безпосередньо випливають координати точок спокою та точок максимального розгону.

#### Вузли (точки абсолютної нерухомості)
Вузли відповідають координатам `x_n`, у яких просторовий множник перетворюється на нуль для будь-якого моменту часу:

```
sin(k·x_n) = 0
k·x_n = n·π   [де n = 0, 1, 2, 3, ...]
```

Згадавши, що хвильове число `k = 2·π / λ`, виразимо координати вузлів через довжину хвилі:

```
(2·π / λ)·x_n = n·π
x_n = n·(λ / 2)   [координати вузлів]
```

Вузли розміщені в точках `x = 0, λ/2, λ, 3λ/2, 2λ, ...`. Відстань між двома сусідніми вузлами дорівнює півхвилі:

```
Δx_вузлів = x_[n+1] − x_n = λ / 2
```

#### Пучності (точки максимальної амплітуди)
Пучності відповідають координатам `x_a`, у яких модуль просторового множника сягає максимуму `|sin(k·x)| = 1`:

```
sin(k·x_a) = ±1
k·x_a = (2·n + 1)·(π / 2)   [де n = 0, 1, 2, 3, ...]
```

Виразимо координати пучностей через довжину хвилі:

```
(2·π / λ)·x_a = (2·n + 1)·(π / 2)
x_a = (2·n + 1)·(λ / 4)   [координати пучностей]
```

Пучності розміщені в точках `x = λ/4, 3λ/4, 5λ/4, 7λ/4, ...`. Амплітуда коливань у пучностях дорівнює подвійній амплітуді вихідних хвиль `2·A`.

Відстань між сусіднім вузлом і пучністю дорівнює чверті хвилі:

```
Δx_(вузол–пучність) = |x_a − x_n| = λ / 4
```

### 3. Узагальнений вивід для довільних початкових фаз

Якщо дві хвилі мають довільні початкові фази `φ₁` та `φ₂`:

```
y₁(x, t) = A·sin(k·x − ω·t + φ₁)
y₂(x, t) = A·sin(k·x + ω·t + φ₂)
```

Сума хвиль знову згортається за формулою тригонометрії:

```
y(x, t) = 2·A · sin( k·x + (φ₁ + φ₂)/2 ) · cos( ω·t + (φ₂ − φ₁)/2 )
```

Цей вивід доводить, що **зсув початкових фаз лише зміщує вузли й пучності в просторі та змінює початковий відлік часу**, але не порушує стоячого характеру візерунка:
- Просторове зміщення вузлів становить `Δx = −(φ₁ + φ₂) / (2·k)`.
- Відстань між сусідніми вузлами `λ / 2` та відношення амплітуд залишаються суворо незмінними.

### 4. Енергетика стоячої хвилі: кінетична та потенціальна енергія

Розглянемо затиснуту струну з лінійною густиною `μ` та силою натягу `T₀`. Знайдемо густини кінетичної та потенціальної енергії стоячої хвилі.

Густина кінетичної енергії елемента струни пропорційна квадрату його поперечної швидкості `v_y = ∂y / ∂t`:

```
∂y / ∂t = ∂ [ 2·A·sin(k·x)·cos(ω·t) ] / ∂t
        = −2·A·ω·sin(k·x)·sin(ω·t)

w_кін(x, t) = (1/2)·μ·(∂y / ∂t)²
            = 2·μ·A²·ω²·sin²(k·x)·sin²(ω·t)
```

Густина потенціальної енергії пружної деформації струни пропорційна квадрату кута нахилу струни `∂y / ∂x`:

```
∂y / ∂x = ∂ [ 2·A·sin(k·x)·cos(ω·t) ] / ∂x
        = 2·A·k·cos(k·x)·cos(ω·t)

w_пот(x, t) = (1/2)·T₀·(∂y / ∂x)²
            = 2·T₀·A²·k²·cos²(k·x)·cos²(ω·t)
```

Враховуючи, що фазова швидкість хвилі в струні `v = √(T₀ / μ) = ω / k`, маємо `T₀·k² = μ·ω²`. Тоді густина потенціальної енергії набуває вигляду:

```
w_пот(x, t) = 2·μ·A²·ω²·cos²(k·x)·cos²(ω·t)
```

#### Обчислення повної енергії між двома вузлами
Зінтегруємо кінетичну та потенціальну енергію вздовж однієї півхвилі (від `x = 0` до `x = λ/2`):

```
E_кін(t) = ∫₀^(λ/2) w_кін(x, t) dx
         = 2·μ·A²·ω²·sin²(ω·t) · ∫₀^(λ/2) sin²(k·x) dx
```

Оскільки інтеграл `∫₀^(λ/2) sin²(k·x) dx = λ / 4`, отримуємо:

```
E_кін(t) = (1/2)·μ·A²·ω²·λ · sin²(ω·t)
```

Аналогічно для потенціальної енергії, оскільки `∫₀^(λ/2) cos²(k·x) dx = λ / 4`:

```
E_пот(t) = (1/2)·μ·A²·ω²·λ · cos²(ω·t)
```

Повна механічна енергія сегмента струни між двома вузлами є сумою кінетичної та потенціальної енергій:

```
E_повна = E_кін(t) + E_пот(t)
        = (1/2)·μ·A²·ω²·λ · [ sin²(ω·t) + cos²(ω·t) ]
        = (1/2)·μ·A²·ω²·λ = const
```

**Висновок:** Повна енергія стоячої хвилі між вузлами є сталою в часі. Двічі за період коливання вся енергія повністю переходить з потенціальної (коли струна максимально вигнута `cos²(ω·t) = 1`, а швидкість усіх точок `∂y/∂t = 0`) у кінетичну (коли струна повністю плоска `sin²(ω·t) = 1`, а поперечна швидкість сягає максимуму).

### 5. Доведення відсутності переносу енергії (потік Пойнтінга)

Миттєва потужність `P(x, t)`, що передається через переріз струни в точці `x`, дорівнює добутку сили натягу на поперечну швидкість:

```
P(x, t) = −T₀ · (∂y / ∂x) · (∂y / ∂t)
```

Підставимо знайдені частинні похідні стоячої хвилі:

```
P(x, t) = −T₀ · [ 2·A·k·cos(k·x)·cos(ω·t) ] · [ −2·A·ω·sin(k·x)·sin(ω·t) ]
        = 4·T₀·A²·k·ω · [ cos(k·x)·sin(k·x) ] · [ cos(ω·t)·sin(ω·t) ]
```

Використавши формулу подвійного кута `sin(2·θ) = 2·sin θ · cos θ`:

```
P(x, t) = T₀·A²·k·ω · sin(2·k·x) · sin(2·ω·t)   [миттєвий потік енергії]
```

Знайдемо середнє значення потоку потужності за період коливання `T = 2·π / ω`:

```
<P(x)> = (1 / T) · ∫₀^T P(x, t) dt
       = T₀·A²·k·ω · sin(2·k·x) · (1 / T) · ∫₀^T sin(2·ω·t) dt
```

Оскільки інтеграл від синуса за повний період дорівнює нулю `∫₀^T sin(2·ω·t) dt = 0`, отримуємо:

```
<P(x)> = 0   [середній потік енергії дорівнює нулю в кожній точці]
```

Це є суворе математичне доведення того, що **ідеальна стояча хвиля не здійснює нетто-переносу енергії**. Енергія лише локально перекачується туди-назад між вузлами сусідніх пучностей з подвоєною частотою `2·ω`.

### 6. Частково стояча хвиля та комплексний коефіцієнт відбиття

Якщо відбиття хвилі від межі не є повним, коефіцієнт відбиття є комплексним числом `Γ = |Γ|·e^(j·θ)`, де `|Γ| ≤ 1` — модуль відбиття, а `θ` — фазовий зсув при відбиванні.

Падаюча та відбита хвилі в комплексній формі:

```
U_пад(x) = A₁ · e^(−j·k·x)
U_відб(x) = A₁ · |Γ| · e^(j·k·x + j·θ)
```

Сумарна хвиля дорівнює:

```
U(x) = A₁ · e^(−j·k·x) · [ 1 + |Γ| · e^(2·j·k·x + j·θ) ]
```

Модуль сумарного відхилення `|U(x)|` змінюється впродовж координати `x` залежно від фази:

```
|U(x)| = A₁ · √[ 1 + |Γ|² + 2·|Γ|·cos(2·k·x + θ) ]
```

Аналіз отриманого виразу показує:
1. **Максимум амплітуди (пучність):** досягається при `cos(2·k·x + θ) = +1`:
   ```
   V_max = A₁ · (1 + |Γ|)
   ```
2. **Мінімум амплітуди (вузол):** досягається при `cos(2·k·x + θ) = −1`:
   ```
   V_min = A₁ · (1 − |Γ|)
   ```

Звідси коефіцієнт стоячої хвилі (КСХ / SWR) дорівнює:

```
SWR = V_max / V_min = (1 + |Γ|) / (1 − |Γ|)   [формула КСХ / SWR]
```

Виразимо модуль коефіцієнта відбиття через КСХ:

```
|Γ| = (SWR − 1) / (SWR + 1)
```

Граничні випадки:
- **Ідеальне узгодження (`|Γ| = 0`):** `SWR = 1`. Стояча хвиля відсутня, амплітуда скрізь однакова, вся енергія передається в навантаження.
- **Повне відбиття (`|Γ| = 1`):** `SWR = ∞`. Виникає чиста стояча хвиля з нулями у вузлах (`A_min = 0`), перенос енергії повністю припиняється.

### 7. Спектральний розклад стоячих хвиль методом Фур'є

Будь-який початковий вигин струни `y(x, 0) = f(x)` із закріпленими кінцями `y(0, t) = y(L, t) = 0` можна розкласти в ряд Фур'є за синусами:

```
f(x) = ∑_(n=1)^∞ b_n · sin(n·π·x / L)
```

де амплітудні коефіцієнти `b_n` визначаються за формулою інтегрування Фур'є:

```
b_n = (2 / L) · ∫₀^L f(x) · sin(n·π·x / L) dx
```

Загальне часове рішення для довільної форми струни є сумою (суперпозицією) незалежних стоячих мод:

```
y(x, t) = ∑_(n=1)^∞ b_n · sin(n·π·x / L) · cos(ω_n · t)
```

де `ω_n = n · π · v / L` — частота `n`-ї моди. Цей вивід доводить, що **будь-яке складне коливання затиснутої струни є простою сумою незалежних стоячих гармонік**, кожна з яких дзвенить на своїй власній частоті `ω_n`.
