# ⚙️ Чисельне моделювання вимушених коливань та розрахунок АЧХ на C та C++

У цій вставці описано розробку програмного алгоритму чисельного моделювання вимушених коливань загасного осцилятора під дією зовнішньої періодичної сили. Ми розглянемо теорію симплектичних інтеграторів, реалізуємо метод Верле у швидкостях (*Velocity Verlet*), виконаємо частотне сканування (покрокову зміну частоти збудження ω) та побудуємо амплітудно-частотну характеристику (АЧХ) системи для автоматичного чисельного визначення резонансного піку й добротності Q.

### 1. Теоретичні основи чисельного інтегрування коливальних систем

Диференціальне рівняння вимушених коливань має вигляд:

```
m·ẍ + c·ẋ + k·x = F₀ · cos(ω·t)
```

Для обчислення стану системи на комп'ютері рівняння зводять до системи двох диференціальних рівнянь першого порядку відносно зміщення x(t) та швидкості v(t):

```
dx/dt = v(t)
dv/dt = a(t) = (F₀ · cos(ω·t) − c·v(t) − k·x(t)) / m
```

Перша думка, яка спадає на думку початківцю — застосувати простий явний метод Ейлера:
- `x[n+1] = x[n] + v[n] · dt`
- `v[n+1] = v[n] + a[n] · dt`

Проте для коливальних систем метод Ейлера категорично **непридатний**. Метод Ейлера є несимплектичним інтегратором першого порядку точності O(dt). На кожному кроці він вносить штучну додатну похибку у фазовий об'єм системи, через що виникає числове «саморозкачування» (енергія системи зростає як e^(const · dt · t) навіть при відсутності зовнішньої сили). Для загасного осцилятора це призводить до викривлення резонансного піку, а для ідеального осцилятора — до вибухоподібного зростання амплітуди до нескінченності.

Для чисельного моделювання коливань застосовують класи симплектичних інтеграторів. Найкращим балансом між обчислювальною складністю, швидкістю та точністю є **метод Верле у швидкостях** (*Velocity Verlet*).

#### Вивід схеми Верле у швидкостях

Розкладемо координату x(t + dt) та x(t − dt) у ряд Тейлора поблизу точки t:

```
x(t + dt) = x(t) + v(t)·dt + (1/2)·a(t)·dt² + (1/6)·b(t)·dt³ + O(dt⁴)
x(t − dt) = x(t) − v(t)·dt + (1/2)·a(t)·dt² − (1/6)·b(t)·dt³ + O(dt⁴)
```

Додавши ці два рівняння, дістаємо класичну позиційну схему Верле:

```
x(t + dt) = 2·x(t) − x(t − dt) + a(t)·dt² + O(dt⁴)
```

Зверніть увагу: члена третього порядку (1/6)·b(t)·dt³ повністю взаємно скоротилися! Це забезпечує точність схеми за координатою O(dt²). 

Щоб позбутися потреби зберігати попередню позицію x(t − dt) і мати явний доступ до швидкості v(t) на кожному кроці (що необхідно для обчислення кінетичної енергії та сили в'язкого тертя −c·v), схему переписують у формі **Верле у швидкостях**:

1. Оновлення координати на основі поточної швидкості та прискорення:
   ```
   x(t + dt) = x(t) + v(t)·dt + (1/2)·a(t)·dt²
   ```
2. Обчислення нового прискорення a(t + dt) з використанням нової координати x(t + dt):
   ```
   a(t + dt) = ( F₀·cos(ω·(t + dt)) − c·v(t) − k·x(t + dt) ) / m
   ```
3. Оновлення швидкості на основі напівсуми старого та нового прискорення:
   ```
   v(t + dt) = v(t) + (1/2)·(a(t) + a(t + dt))·dt
   ```

Цей метод точно зберігає фазовий об'єм, не має числового дрейфу енергії при малих dt і забезпечує високу стабільність амплітуди при моделюванні тривалих перехідних процесів.

Метод Верле у швидкостях є неявним щодо швидкості, але для в'язкого тертя −c·v система алгебраїчних рівнянь розв'язується в явному вигляді, що дозволяє виконувати розрахунок одного кроку всього за 4 арифметичні операції.

### 2. Архітектура та алгоритм частотного сканера АЧХ

Для чисельної побудови амплітудно-частотної характеристики (АЧХ) застосовують двостадійну схему моделювання для кожної дискретної частоти збудження:

```
                  ┌─────────────────────────────────────────────────────────┐
                  │                 Початок симуляції                       │
                  └────────────────────────────┬────────────────────────────┘
                                               │
                                               ▼
                  ┌─────────────────────────────────────────────────────────┐
                  │ Phase 1: Перехідний процес (t < t_settle)               │
                  │ Пропускаємо згасання власних коливань e⁻ᵞᵗ             │
                  └────────────────────────────┬────────────────────────────┘
                                               │
                                               ▼
                  ┌─────────────────────────────────────────────────────────┐
                  │ Phase 2: Вимірювання сталого режиму (t_settle..t_end)  │
                  │ Шукаємо max(|x(t)|) протягом кількох повних періодів    │
                  └────────────────────────────┬────────────────────────────┘
                                               │
                                               ▼
                  ┌─────────────────────────────────────────────────────────┐
                  │ Запис точки АЧХ (ω, A(ω)) та перехід до ω + dω         │
                  └────────────────────────────┬────────────────────────────┘
```

#### Розрахунок параметрів часу симуляції

1. **Час встановлення сталого режиму (`t_settle`)**. Перехідний процес визначається темпом загасання γ = c / (2m). Амплітуда власних коливань зменшується за законом e⁻ᵞᵗ. Щоб вільні коливання згасли щонайменше у 400 разів (до рівня менше 0.25% від початкового), час пропускання має становити:
   ```
   t_settle ≥ 6 / γ = (12 · m) / c
   ```
2. **Час вимірювання сталевої амплітуди (`t_measure`)**. Щоб гарантовано захопити пікове значення синусоїди, вимірювання слід проводити протягом щонайменше 10–20 повних періодів коливань T = 2·π / ω₀:
   ```
   t_measure ≥ 20 · (2·π / ω₀)
   ```

Використання адаптивного розрахунку часових інтервалів дозволяє суттєво прискорити обчислення: для низькодобротних систем `t_settle` зменшується автоматично, тоді як для високодобротних систем алгоритм виділяє достатній часовий ресурс для повного згасання перехідних бить.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <stdbool.h>

/* Конфігураційна структура параметрів осцилятора */
typedef struct {
    double m;       /* маса системи (кг) */
    double k;       /* жорсткість пружини (Н/м) */
    double c;       /* коефіцієнт в'язкого тертя (Н·с/м) */
    double f0;      /* амплітуда зовнішньої збуджувальної сили (Н) */
} OscillatorParams;

/* Структура для збереження однієї точки АЧХ */
typedef struct {
    double omega;   /* колова частота (рад/с) */
    double amp;     /* амплітуда сталого режиму (м) */
} AFCPoint;

/* Обчислення миттєвого прискорення в момент часу t */
static inline double compute_accel(const OscillatorParams *p, double x, double v, double f_ext) {
    return (f_ext - p->c * v - p->k * x) / p->m;
}

/**
 * @brief Провести симуляцію вимушених коливань на фіксованій частоті omega
 * @return Значення амплітуди сталого режиму (м)
 */
static double simulate_frequency(const OscillatorParams *p, 
                                 double omega, 
                                 double dt, 
                                 double t_settle, 
                                 double t_measure) 
{
    double x = 0.0;
    double v = 0.0;
    double t = 0.0;

    /* Початкове прискорення при t = 0 */
    double a = compute_accel(p, x, v, p->f0);

    /* 1. Фаза пропуску перехідного процесу (згасання власних коливань) */
    while (t < t_settle) {
        double f_next = p->f0 * cos(omega * (t + dt));
        
        /* Крок Верле у швидкостях */
        x += v * dt + 0.5 * a * dt * dt;
        double a_next = (f_next - p->c * v - p->k * x) / p->m;
        v += 0.5 * (a + a_next) * dt;
        
        a = a_next;
        t += dt;
    }

    /* 2. Фаза вимірювання максимуму амплітуди сталого режиму */
    double max_x = 0.0;
    double t_end = t_settle + t_measure;

    while (t < t_end) {
        double f_next = p->f0 * cos(omega * (t + dt));

        x += v * dt + 0.5 * a * dt * dt;
        double a_next = (f_next - p->c * v - p->k * x) / p->m;
        v += 0.5 * (a + a_next) * dt;

        a = a_next;
        t += dt;

        double abs_x = fabs(x);
        if (abs_x > max_x) {
            max_x = abs_x;
        }
    }

    return max_x;
}

int main(void) {
    OscillatorParams p = {
        .m = 1.0,     /* 1 кг */
        .k = 100.0,   /* w0 = sqrt(100/1) = 10 рад/с */
        .c = 1.0,     /* gamma = 1/(2*1) = 0.5, Q = 10 / 1 = 10 */
        .f0 = 10.0    /* A_stat = 10 / 100 = 0.1 м */
    };

    double w0_theory = sqrt(p.k / p.m);
    double gamma = p.c / (2.0 * p.m);
    double w_res_theory = sqrt(w0_theory * w0_theory - 2.0 * gamma * gamma);
    double q_theory = w0_theory / (2.0 * gamma);

    printf("=== ТЕОРЕТИЧНІ ЗНАЧЕННЯ ===\n");
    printf("Власна частота w0  : %.4f рад/с\n", w0_theory);
    printf("Резонансна частота : %.4f рад/с\n", w_res_theory);
    printf("Добротність Q      : %.2f\n\n", q_theory);

    /* Параметри сканування АЧХ */
    double w_min = 5.0;
    double w_max = 15.0;
    int num_steps = 100;
    double dw = (w_max - w_min) / num_steps;

    double dt = 0.001;        /* крок інтегрування 1 мс */
    double t_settle = 15.0;   /* 15 секунд на згасання власних коливань */
    double t_measure = 10.0;  /* 10 секунд на вимірювання */

    double best_omega = 0.0;
    double max_amplitude = 0.0;

    printf("=== ЧИСЕЛЬНЕ СКАНУВАННЯ АЧХ ===\n");
    printf("%-12s | %-16s | %-16s\n", "w (рад/с)", "Амплітуда (м)", "Відносна A/A_stat");
    printf("--------------------------------------------------\n");

    for (int i = 0; i <= num_steps; ++i) {
        double w = w_min + i * dw;
        double amp = simulate_frequency(&p, w, dt, t_settle, t_measure);
        double a_stat = p.f0 / p.k;
        
        if (amp > max_amplitude) {
            max_amplitude = amp;
            best_omega = w;
        }

        if (i % 10 == 0) {
            printf("%-12.2f | %-16.6f | %-16.2f\n", w, amp, amp / a_stat);
        }
    }

    printf("\n=== РЕЗУЛЬТАТИ СИМУЛЯЦІЇ ===\n");
    printf("Знайдена резонансна частота : %.4f рад/с (похибка: %.2f%%)\n", 
           best_omega, fabs(best_omega - w_res_theory) / w_res_theory * 100.0);
    printf("Максимальна амплітуда      : %.6f м\n", max_amplitude);
    printf("Чисельне підсилення A/A_stat: %.2f (Теорія Q ≈ %.2f)\n", 
           max_amplitude / (p.f0 / p.k), q_theory);

    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <iomanip>
#include <algorithm>
#include <span>

// Фізичні параметри осцилятора
struct OscillatorParams {
    double m{1.0};     // маса (кг)
    double k{100.0};   // жорсткість (Н/м)
    double c{1.0};     // демпфування (Н·с/м)
    double f0{10.0};   // амплітуда сили (Н)

    [[nodiscard]] constexpr double natural_frequency() const noexcept {
        return std::sqrt(k / m);
    }

    [[nodiscard]] constexpr double damping_rate() const noexcept {
        return c / (2.0 * m);
    }

    [[nodiscard]] constexpr double resonance_frequency() const noexcept {
        const double w0 = natural_frequency();
        const double g = damping_rate();
        const double val = w0 * w0 - 2.0 * g * g;
        return (val > 0.0) ? std::sqrt(val) : 0.0;
    }

    [[nodiscard]] constexpr double quality_factor() const noexcept {
        return natural_frequency() / (2.0 * damping_rate());
    }
};

// Точка профілю АЧХ
struct AFCPoint {
    double omega{0.0};
    double amplitude{0.0};
};

class DrivenOscillatorSimulator {
public:
    explicit DrivenOscillatorSimulator(OscillatorParams params)
        : params_(params) {}

    // Симуляція вимушених коливань на фіксованій частоті за методом Velocity Verlet
    [[nodiscard]] double simulate_frequency(double omega, double dt, double t_settle, double t_measure) const {
        double x = 0.0;
        double v = 0.0;
        double t = 0.0;

        auto compute_acc = [this](double x_pos, double v_vel, double f_ext) {
            return (f_ext - params_.c * v_vel - params_.k * x_pos) / params_.m;
        };

        double a = compute_acc(x, v, params_.f0);

        // Фаза 1: пропуск перехідного процесу
        while (t < t_settle) {
            const double f_next = params_.f0 * std::cos(omega * (t + dt));
            
            x += v * dt + 0.5 * a * dt * dt;
            const double a_next = compute_acc(x, v, f_next);
            v += 0.5 * (a + a_next) * dt;

            a = a_next;
            t += dt;
        }

        // Фаза 2: вимірювання максимуму амплітуди
        double max_amp = 0.0;
        const double t_end = t_settle + t_measure;

        while (t < t_end) {
            const double f_next = params_.f0 * std::cos(omega * (t + dt));

            x += v * dt + 0.5 * a * dt * dt;
            const double a_next = compute_acc(x, v, f_next);
            v += 0.5 * (a + a_next) * dt;

            a = a_next;
            t += dt;

            max_amp = std::max(max_amp, std::abs(x));
        }

        return max_amp;
    }

    // Сканування діапазону частот та повернення векторного профілю АЧХ
    [[nodiscard]] std::vector<AFCPoint> scan_afc(double w_min, double w_max, int steps, double dt) const {
        std::vector<AFCPoint> result;
        result.reserve(static_cast<size_t>(steps + 1));

        const double dw = (w_max - w_min) / steps;
        const double t_settle = 6.0 / params_.damping_rate(); // ~6 сталих часу 1/gamma
        const double t_measure = 10.0 * (2.0 * M_PI / params_.natural_frequency());

        for (int i = 0; i <= steps; ++i) {
            const double w = w_min + i * dw;
            const double amp = simulate_frequency(w, dt, t_settle, t_measure);
            result.push_back({w, amp});
        }

        return result;
    }

private:
    OscillatorParams params_;
};

int main() {
    const OscillatorParams params{.m = 1.0, .k = 100.0, .c = 1.0, .f0 = 10.0};
    const DrivenOscillatorSimulator sim(params);

    std::cout << std::fixed << std::setprecision(4);
    std::cout << "=== ТЕОРЕТИЧНІ ПАРАМЕТРИ ===\n";
    std::cout << "Власна частота w0  : " << params.natural_frequency() << " рад/с\n";
    std::cout << "Резонансна частота : " << params.resonance_frequency() << " рад/с\n";
    std::cout << "Добротність Q      : " << params.quality_factor() << "\n\n";

    const auto afc = sim.scan_afc(5.0, 15.0, 100, 0.001);

    // Знаходимо резонансний пік через std::max_element
    const auto peak_it = std::max_element(
        afc.begin(), afc.end(),
        [](const AFCPoint& a, const AFCPoint& b) { return a.amplitude < b.amplitude; }
    );

    std::cout << "=== РЕЗУЛЬТАТИ СИМУЛЯЦІЇ ===\n";
    std::cout << "Знайдена резонансна частота : " << peak_it->omega << " рад/с\n";
    std::cout << "Максимальна амплітуда      : " << peak_it->amplitude << " м\n";
    
    const double a_stat = params.f0 / params.k;
    std::cout << "Коефіцієнт підсилення A/A_stat: " << (peak_it->amplitude / a_stat) << "\n";

    return 0;
}
```

### 4. Покроковий розбір коду C та C++

Розглянемо ключові відмінності двох архітектурних реалізацій:

1. **Інкапсуляція стану**: У версії C++ фізичні параметри осцилятора та методи обчислення об'єднано у клас `DrivenOscillatorSimulator`. Методи позначено атрибутом `[[nodiscard]]`, що запобігає випадковому ігноруванню поверненого результату обчислень.
2. **Динамічне виділення пам'яті**: Резервування вектора `result.reserve(...)` у C++ запобігає зайвим повторним виділенням пам'яті в купі під час збереження точок АЧХ.
3. **Пошук максимуму АЧХ**: У версії C++ пошук резонансного піку виконується через стандартний алгоритм `std::max_element` із лямбда-компаратором, що виключає написання явних ручних циклів.

### 5. Пастки чисельного моделювання резонансу

Під час розробки симулятора резонансу початківці найчастіше припускаються трьох типових помилок:

1. **Помилка 1: Недостатній час пропускання перехідного процесу (`t_settle`)**. 
   Якщо вимірювати максимум амплітуди одразу з моменту включення сили (t = 0), у системі присутня згасна власна складова на частоті ω_d. Відбувається взаємодія (інтерференція) між власною та збуджувальною частотою, що призводить до [биттів](topic:physics/beats). На графіку АЧХ з'являються несправжні паразитні піки, а чисельна амплітуда може виявитися завищеною на 30–50%. Для запобігання цьому `t_settle` має становити не менше (5…6) / γ.

2. **Помилка 2: Занадто великий крок за часом (`dt`)**. 
   Крок чисельного інтегрування dt пов'язаний із частотою системною умовою стійкості Куранта-Фрідріхса-Леві. Для інтегратора Верле крок має задовольняти обмеження:
   ```
   dt ≤ 0.1 / ω_max
   ```
   Якщо вибрати `dt` занадто великим (наприклад, `dt = 0.05` при `ω = 10 рад/с`), на один період коливань припадатиме лише 12 дискретних точок. Чисельна схема згладжуватиме піки синусоїди, і обчислена амплітуда виявиться суттєво заниженою.

3. **Помилка 3: Неадекватна дискретизація частоти (`dw`) для високодобротних систем**. 
   При високій добротності Q = 1000 ширина резонансного піку на рівні половинної потужності становить Δω = ω₀ / Q = 10 / 1000 = 0.01 рад/с. Якщо крок частотного сканування задати рівним `dw = 0.1 рад/с`, сканер просто «проскочить» повз резонансний пік шириною 0.01 рад/с, і зареєстрована амплітуда на АЧХ виявиться в десятки разів меншою за реальну. Для високодобротних осциляторів крок сканування має підбиратися адаптивно за умовою:
   ```
   dw ≤ Δω / 10 = ω₀ / (10 · Q)
   ```
