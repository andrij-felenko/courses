# 🧮 Математична геометрія фігур Ліссажу: від тригонометрії до поліномів Чебишова

Ця математична вставка містить суворий аналітичний вивід параметричних і неявних рівнянь фігур Ліссажу, аналіз їхньої топології, півосей еліпса, площі замкненого контуру, миттєвої швидкості руху, повертальних точок та зв'язок із поліномами Чебишова.

Фігури Ліссажу виникають як результат параметричного додавання двох гармонічних коливань у взаємно перпендикулярних напрямках. Узагальнена система параметричних рівнянь у часовій області описується виразами:

```
x(t) = A · sin(a·t + δ)
y(t) = B · sin(b·t)
```

де `A` та `B` — амплітуди коливань уздовж осей X та Y, `a` та `b` — кутові частоти коливань у радіанах за секунду, а `δ` — початкова різниця фаз між коливаннями.

---

### 1. Виведення неявного рівняння траєкторії для співвідношення частот 1:1

Розглянемо випадок однакових частот, коли кутові частоти обох коливань суворо збігаються (`a = b = ω`). Система параметричних рівнянь набуває вигляду:

```
x(t) / A = sin(ω·t + δ)
y(t) / B = sin(ω·t)
```

Для того щоб отримати неявне рівняння траєкторії на площині `(x, y)`, необхідно повністю вилучити часову змінну `t`. Застосуємо фундаментальну формулу тригонометрії для синуса суми двох кутів до першого рівняння системи:

```
x / A = sin(ω·t)·cos(δ) + cos(ω·t)·sin(δ)
```

З другого рівняння системи ми безпосередньо маємо `sin(ω·t) = y / B`. Для заміни косинуса скористаємося основною тригонометричною тотожністю `sin²(ω·t) + cos²(ω·t) = 1`, звідки виразимо косинус через синус `cos(ω·t) = √(1 − (y/B)²)`:

```
x / A = (y / B)·cos(δ) + √(1 − (y/B)²) · sin(δ)
```

Тепер виконаємо алгебраїчні перетворення для позбавлення від знака квадратного кореня. Спочатку ізолюємо доданок із коренем у правій частині рівняння:

```
x / A − (y / B)·cos(δ) = √(1 − (y/B)²) · sin(δ)
```

Піднесемо обидві частини рівняння до квадрата:

```
(x/A)² − 2·(x/A)·(y/B)·cos(δ) + (y/B)²·cos²(δ) = (1 − (y/B)²) · sin²(δ)
```

Розкриємо дужки у правій частині виразу:

```
(x/A)² − 2·(x/A)·(y/B)·cos(δ) + (y/B)²·cos²(δ) = sin²(δ) − (y/B)²·sin²(δ)
```

Перенесемо від'ємний доданок `(y/B)²·sin²(δ)` із правої частини в ліву та винесемо спільний множник `(y/B)²` за дужки:

```
(x/A)² − 2·(x/A)·(y/B)·cos(δ) + (y/B)²·[cos²(δ) + sin²(δ)] = sin²(δ)
```

Зважаючи на те, що сума квадратів косинуса й синуса дорівнює одиниці `cos²(δ) + sin²(δ) = 1`, отримуємо остаточне канонічне неявне рівняння другого порядку (квадратичну форму):

```
(x/A)² − 2·(x/A)·(y/B)·cos(δ) + (y/B)² = sin²(δ)      [загальне рівняння еліпса]
```

Це алгебраїчне рівняння описує повернутий еліпс із центром у початку координат `(0, 0)`. Його геометрична форма повністю визначається трьома параметрами: амплітудами `A`, `B` та різницею фаз `δ`.

#### Детальний розбір крайових випадків фазового зсуву δ:

1. **Синфазність (δ = 0) та протифазність (δ = π):**
   При `δ = 0` маємо `sin(0) = 0` та `cos(0) = 1`. Рівняння перетворюється на повний квадрат:

   ```
   (x/A)² − 2·(x/A)·(y/B) + (y/B)² = 0
   = [ (x/A) − (y/B) ]² = 0
   ⇒ y = (B / A) · x                                 [пряма лінія у I та III квадрантах]
   ```

   Фізично це означає, що коливання відбуваються абсолютно синхронно: коли точка зсувається праворуч по осі X, вона одночасно зсувається вгору по осі Y. Траєкторія стискається у похилий відрізок прямої лінії.

   При `δ = π` (протифаза) маємо `cos(π) = −1`, що дає пряму `y = −(B / A) · x` у II та IV квадрантах. Точка рухається праворуч-вниз і ліворуч-вгору.

2. **Квадратурний зсув (δ = π/2 або δ = 3π/2):**
   При `δ = π/2` (зсув на чверть періоду, 90 градусів) маємо `cos(π/2) = 0` та `sin(π/2) = 1`. Перехресний член зникає:

   ```
   (x/A)² + (y/B)² = 1                               [стоячий канонічний еліпс]
   ```

   Головні осі еліпса розташовані строго вздовж координатних осей X та Y. Якщо амплітуди коливань по обох осях однакові (`A = B = R`), то рівняння спрощується до рівняння кола `x² + y² = R²`.

### 2. Геометричні параметри еліпса: кут повороту та довжини півосей

Загальне неявне рівняння еліпса можна подати у компактній матричній формі `Vᵀ · M · V = sin²(δ)`, де вектор координат `V = [x, y]ᵀ`, а симетрична матриця квадратичної форми `M` має вигляд:

```
M = [ 1/A²           −cos(δ)/(A·B) ]
    [ −cos(δ)/(A·B)   1/B²         ]
```

#### Математичний розрахунок кута повороту головних осей θ:
Щоб привести квадратичну форму до діагонального вигляду без перехресного члена, виконаємо поворот системи координат на кут `θ`. Для цього складемо матрицю повороту `R(θ)` та знайдемо кут, при якому позадіагональні елементи перетворюються на нуль. Кут нахилу головної осі еліпса відносно горизонтальної осі X розраховується за формулою:

```
tan(2θ) = (2 · A · B · cos(δ)) / (A² − B²)
```

Фізичний зміст та аналіз формули повороту:
- Для випадку рівних амплітуд (`A = B`) знаменник перетворюється на нуль, оскільки `A² − B² = 0`. Це означає, що `tan(2θ) → ∞`, звідки `2θ = π/2` і `θ = 45°` (або `135°`). Таким чином, при однакових амплітудах головна вісь еліпса Ліссажу завжди нахилена строго під кутом 45 градусів до осей незалежно від значення різниці фаз `δ`.
- При квадратурному зсуві `δ = π/2` чисельник перетворюється на нуль, адже `cos(π/2) = 0`. Це дає `tan(2θ) = 0 ⇒ θ = 0°`, тобто осі еліпса збігаються з координатними осями.

#### Точний розрахунок великої та малої півосей (a_e, b_e):
Довжини півосей еліпса обчислюються через власні значення матриці квадратичної форми. Характеристичне рівняння `det(M − λI) = 0` визначає власні числа `λ₁` та `λ₂`. Оскільки довжини півосей прямо пропорційні `1 / √λ`, точні вирази для квадрата великої піввісі `a_e` та малої піввісі `b_e` мають вигляд:

```
a_e² = (A² + B² + √[(A² − B²)² + 4·A²·B²·cos²(δ)]) / 2
b_e² = (A² + B² − √[(A² − B²)² + 4·A²·B²·cos²(δ)]) / 2
```

При `δ = π/2` косинус дорівнює нулю `cos(δ) = 0`, що спрощує вирази до `a_e = max(A, B)` та `b_e = min(A, B)`.

### 3. Площа еліпса Ліссажу та застосування теореми Гріна

Площу `S`, яку охоплює замкнена траєкторія еліпса Ліссажу для співвідношення частот 1:1, розрахуємо за допомогою криволінійного інтеграла другого роду вздовж замкненого контуру (наслідок із формули Гріна для обчислення площі плоских фігур):

```
S = (1/2) · ∮ [ x · dy − y · dx ]
```

Підставимо параметричні рівняння `x(t) = A·sin(ωt + δ)` та `y(t) = B·sin(ωt)` за один повний період коливання `t ∈ [0, 2π/ω]`. Знайдемо диференціали осей за часовим аргументом:

```
dx = A · ω · cos(ωt + δ) · dt
dy = B · ω · cos(ωt) · dt
```

Підставимо `dx` та `dy` у підінтегральний вираз і розкриємо дужки:

```
x · dy − y · dx 
= A·sin(ωt + δ) · B·ω·cos(ωt) − B·sin(ωt) · A·ω·cos(ωt + δ)
= A·B·ω · [ sin(ωt + δ)·cos(ωt) − cos(ωt + δ)·sin(ωt) ]
```

Використаємо тригонометричну тотожність для синуса різниці двох кутів `sin(α − β) = sin α cos β − cos α sin β`, де покладемо `α = ωt + δ` та `β = ωt`:

```
x · dy − y · dx = A · B · ω · sin(δ) · dt
```

Отримана величина є абсолютно сталою в часі й не залежить від змінного кута `ωt`. Тепер виконаємо інтегрування цієї сталої величини по повному періоду `t ∈ [0, 2π/ω]`:

```
S = (1/2) · ∫₀^(2π/ω) [ A·B·ω · sin(δ) ] dt
= (1/2) · A·B·ω · sin(δ) · (2π / ω)
= π · A · B · sin(δ)                              [площа еліпса Ліссажу]
```

Фізичний висновок: Площа замкненого еліпса Ліссажу є прямо пропорційною синусу різниці фаз `sin(δ)`:
- При синфазних коливаннях (`δ = 0`) площа дорівнює нулю `S = 0`, оскільки еліпс вироджується в лінійний відрізок без внутрішньої площі.
- При квадратурному зсуві (`δ = π/2`) площа набуває свого максимального можливого значення `S_max = π · A · B`.

### 4. Динаміка руху: вектор миттєвої швидкості та прискорення

Розглянемо кінематику руху точки вздовж траєкторії Ліссажу. Компоненти вектора миттєвої швидкості `v = [v_x, v_y]ᵀ` є першими похідними параметричних координат за часом:

```
v_x(t) = dx/dt = A · a · cos(a·t + δ)
v_y(t) = dy/dt = B · b · cos(b·t)
```

Повний модуль вектора швидкості `|v(t)|` обчислюється за теоремою Піфагора для двох ортогональних компонент:

```
|v(t)| = √[ (A · a · cos(a·t + δ))² + (B · b · cos(b·t))² ]
```

Аналіз кінематичних точок траєкторії:
- У крайніх повертальних точках (вершинах прямокутника обмеження), де `x = ±A` або `y = ±B`, відповідна компонента швидкості перетворюється на нуль (`cos = 0`). Точка на мить зупиняється по відповідній осі й змінює напрямок руху на протилежний.
- При проходженні центру координат `(0, 0)` при `δ = π/2` обидві компоненти швидкості досягають свого максимуму: `v_x = A·a` та `v_y = B·b`, а підсумковий модуль швидкості є максимальним `|v_max| = √[ (A·a)² + (B·b)² ]`.

Другі похідні за часом дають компоненти вектора прискорення `w = [w_x, w_y]ᵀ`:

```
w_x(t) = d²x/dt² = −A · a² · sin(a·t + δ) = −a² · x(t)
w_y(t) = d²y/dt² = −B · b² · sin(b·t) = −b² · y(t)
```

Це пряме аналітичне підтвердження того, що прискорення точки в будь-який момент часу спрямоване до початку координат і прямо пропорційне величині зсуву (класична властивість двовимірного гармонічного осцилятора).

### 5. Напрямок обертання та векторна кутова швидкість

Напрямок обходу еліпса (за годинниковою стрілкою чи проти неї) визначається знаком полярної кутової швидкості `dφ/dt`.

Полярний кут точки визначається як `φ = arctan(y / x)`. Взявши похідну за часом від цього виразу, отримуємо полярну кутову швидкість:

```
dφ/dt = (x · dy/dt − y · dx/dt) / (x² + y²)
```

Підставивши виведений раніше вираз для чисельника `x·dy − y·dx = A·B·ω·sin(δ)·dt`, отримуємо остаточне співвідношення:

```
dφ/dt = (A · B · ω · sin(δ)) / (x(t)² + y(t)²)
```

Оскільки знаменник `x² + y²` завжди є додатним числом для будь-якої точки, крім початку координат, знак кутової швидкості `dφ/dt` повністю й однозначно визначається знаком `sin(δ)`:
- Якщо `sin(δ) > 0` (тобто фазовий зсув лежить у межах `0 < δ < π`), то `dφ/dt > 0` — точка рухається уздовж еліпса **проти годинникової стрілки**.
- Якщо `sin(δ) < 0` (тобто фазовий зсув лежить у межах `π < δ < 2π`), то `dφ/dt < 0` — точка рухається **за годинниковою стрілкою**.

### 6. Виведення фази δ за точки перетину координатних осей

На практиці різницю фаз `δ` вимірюють за координатами точок перетину еліпса з осями X та Y.

#### 1. Перетин із віссю Y (при x = 0):
Покладемо `x(t) = A · sin(ωt + δ) = 0`, звідки маємо `ωt + δ = kπ` або `ωt = kπ − δ`.
Підставимо це значення часового аргументу у вираз для `y(t)`:

```
y = B · sin(kπ − δ) = ± B · sin(δ)
```

Позначимо висоту точки перетину з віссю Y як `Y₀ = |y(x=0)|`. Отримуємо вирази:

```
Y₀ = B · |sin(δ)|
⇒ |sin(δ)| = Y₀ / B
```

#### 2. Перетин із віссю X (при y = 0):
Покладемо `y(t) = B · sin(ωt) = 0`, звідки `ωt = kπ`.
Підставимо часовий аргумент у вираз для `x(t)`:

```
x = A · sin(kπ + δ) = ± A · sin(δ)
```

Позначимо ширину точки перетину з віссю X як `X₀ = |x(y=0)|`. Тоді:

```
X₀ = A · |sin(δ)|
⇒ |sin(δ)| = X₀ / A
```

Зваживши на те, що максимальна амплітуда по осі Y дорівнює `Y_max = B`, отримуємо стандартні вимірювальні формули:

```
δ = arcsin( Y₀ / Y_max )  або  δ = arcsin( X₀ / X_max )
```

Правило квадранта: Функція `arcsin` повертає кут у діапазоні від `0` до `90` градусів. Для визначення точного квадранта фази аналізують нахил головної осі еліпса:
- Якщо головна вісь лежить у I та III квадрантах (еліпс нахилений праворуч), фаза належить інтервалам `[0, π/2]` або `[3π/2, 2π]`.
- Якщо головна вісь лежить у II та IV квадрантах (еліпс нахилений ліворуч), фаза належить інтервалам `[π/2, π]` або `[π, 3π/2]`.

### 7. Співвідношення частот 1:2 та 2:3: тригонометричний вивід

#### Аналіз співвідношення 1:2 (квадратурна фаза δ = π/2):
Розглянемо коливання з частотами `a = ω` та `b = 2ω` при різниці фаз `δ = π/2`:

```
x(t) = A · sin(ω·t + π/2) = A · cos(ω·t)
y(t) = B · sin(2ω·t) = 2·B · sin(ω·t)·cos(ω·t)
```

Виразимо `cos(ω·t) = x / A` та `sin(ω·t) = √(1 − (x/A)²)` і підставимо у вираз для `y`:

```
y = 2·B · (x / A) · √(1 − (x/A)²)
```

Піднесення обох частин до квадрата дає неявне алгебраїчне рівняння самоперетинної кривої:

```
(y / B)² = 4 · (x / A)² · (1 − (x/A)²)              [неявне рівняння «вісімки»]
```

Ця крива відома у геометрії як алгебраїчна крива четвертого порядку (вісімка або лемніската).

#### Співвідношення частот 2:3 (симетричний вузол):
Для кратних частот `a = 2ω` та `b = 3ω` при початковій фазі `δ = 0` параметричні рівняння мають вигляд:

```
x(t) = A · sin(2ω·t) = 2·A · sin(ωt)·cos(ωt)
y(t) = B · sin(3ω·t) = B · [ 3·sin(ωt) − 4·sin³(ωt) ]
```

Вилучення часу в цьому випадку дає алгебраїчне рівняння шостого порядку. Крива має три лопаті по горизонталі та дві по вертикалі, перетинаючи саму себе в двох симетричних вузлових точках на площині.

### 8. Замкненість траєкторії, нерозмірні частоти та ергодичність

При дослідженні параметричних виразів Ліссажу ключове математичне питання полягає в тому, чи є траєкторія руху строго замкненою кривою на площині, чи вона заповнює простір без кінця.

1. **Раціональне співвідношення частот (a / b = p / q, де p, q ∈ ℤ):**
   Якщо відношення частот є раціональним числом, траєкторія є замкненою періодичною лінією. Загальний період руху `T_загальний` обчислюється як найменше спільне кратне періодів обох коливань:

   ```
   T_загальний = 2π · q / a = 2π · p / b
   ```

   За один повний період `T_загальний` електронний промінь чи маятник робить `p` повних циклів по осі X та `q` повних циклів по осі Y, повертаючись строго у вихідну точку з тією самою швидкістю.

2. **Ірраціональне співвідношення частот (a / b ∉ ℚ) та теорема Кронекера:**
   Якщо співвідношення частот є ірраціональним числом (наприклад, `a/b = √2`), то крива є **незамкненою та ергодичною**. Відповідно до відомої математичної теореми Кронекера-Вейля про рівномірний розподіл фазових траєкторій на двовимірному торі `T²`, крива ніколи не повертається у вихідну точку й за нескінченний час `t → ∞` утворює всюди щільну сітку, що повністю заповнює прямокутник `[−A, A] × [−B, B]`.

### 9. Зв'язок із поліномами Чебишова

Якщо різниця фаз дорівнює `δ = 0` (або `π/2` залежно від вибору синуса чи косинуса), траєкторія стає виродженою незамкненою дугою, по якій точка рухається туди й назад.

Виразимо `y` як функцію від `x` для `a = ω` та `b = n·ω`:

```
x / A = sin(ωt) ⇒ cos(n·ωt) = T_n(sin(ωt))
```

Для співвідношення частот `1 : n` вирази `y(x)` повністю збігаються з **поліномами Чебишова першого роду** `T_n(x)`:

```
T₁(x) = x
T₂(x) = 2x² − 1
T₃(x) = 4x³ − 3x
T₄(x) = 8x⁴ − 8x² + 1
```

Рівняння фігури Ліссажу для `1 : n` при виродженій фазі записується як:

```
y = B · T_n(x / A)
```

Отже, будь-яка фігура Ліссажу з цілочисельним співвідношенням частот `1 : n` при виродженій фазі являє собою ортогональну проекцію циліндричної кривої та збігається з графіком відповідного полінома Чебишова `n`-го порядку на проміжку `x ∈ [−A, A]`.

### 10. Топологічний підрахунок дотичних та петель

Для швидкого визначення невідомого співвідношення частот `a / b` за зображенням непорушної фігури Ліссажу використовують топологічне правило дотичних точок.

Опишемо навколо фігури уявний прямокутник `[−A, A] × [−B, B]`:
- Порахуємо кількість точок `N_y`, у яких траєкторія торкається верхньої горизонтальної межі прямокутника.
- Порахуємо кількість точок `N_x`, у яких траєкторія торкається бічної вертикальної межі прямокутника.

Співвідношення частот дорівнює зворотному відношенню кількості дотичних:

```
a / b = N_y / N_x
```

Кутові точки, де траєкторія повертає назад по власній дузі, враховуються як `1/2` дотику. Цей топологічний метод є надзвичайно надійним у вимірювальній практиці й абсолютно не залежить від амплітуди сигналів чи масштабної сітки осцилографа.

### 11. Повний чисельний розрахунковий приклад

**Задача:** Сигнал каналу X має амплітуду `A = 5 В` та частоту `100 Гц`. Сигнал каналу Y має амплітуду `B = 3 В` та частоту `100 Гц`. На екрані осцилографа зафіксовано перетин осі Y у точці `Y₀ = 1.5 В`. Обчислити різницю фаз `δ`, кут повороту осей `θ`, площу еліпса `S` та півосі `a_e`, `b_e`.

```
1. Розрахунок різниці фаз δ:
   sin(δ) = Y₀ / Y_max = 1.5 В / 3.0 В = 0.5
   δ = arcsin(0.5) = 30° (π/6 rad)

2. Кут нахилу головної осі еліпса θ:
   tan(2θ) = (2 · A · B · cos(δ)) / (A² − B²)
   tan(2θ) = (2 · 5 · 3 · cos(30°)) / (5² − 3²)
   tan(2θ) = (30 · 0.866) / (25 − 9) = 25.98 / 16 ≈ 1.62375
   2θ = arctan(1.62375) ≈ 58.37°
   θ ≈ 29.18°

3. Обчислення площі еліпса S:
   S = π · A · B · sin(δ)
   S = π · 5 · 3 · sin(30°) = 15 · π · 0.5 ≈ 23.56 В²

4. Обчислення великої піввісі a_e:
   a_e² = (25 + 9 + √[(25 − 9)² + 4 · 25 · 9 · (0.866)²]) / 2
   a_e² = (34 + √[256 + 900 · 0.75]) / 2
   a_e² = (34 + √[256 + 675]) / 2 = (34 + √931) / 2
   a_e² ≈ (34 + 30.51) / 2 = 32.255
   a_e ≈ √32.255 ≈ 5.68 В

5. Обчислення малої піввісі b_e:
   b_e² = (34 − 30.51) / 2 = 3.49 / 2 = 1.745
   b_e ≈ √1.745 ≈ 1.32 В
```

Чисельний розрахунок показує, що завдяки нахилу на 29.18° велика піввісь еліпса `a_e ≈ 5.68 В` перевищує окремі амплітуди обох каналів `A = 5 В` та `B = 3 В`, тоді як мала піввісь `b_e ≈ 1.32 В` задає його товщину. Траєкторія руху є повністю визначеною та геометрично замкненою.
