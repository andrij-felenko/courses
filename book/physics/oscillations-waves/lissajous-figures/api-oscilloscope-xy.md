# 📋 Протокол вимірювань та налаштування X-Y режиму осцилографа

Ця довідково-інтерфейсна вставка описує стандартний операційний протокол (SOP), порядок підключення вимірювальних щупів, процедуру калібрування каналів та таблиці параметрів для вимірювання різниці фаз і співвідношення частот у режимі X-Y двоканальних осцилографів.

Режим X-Y є спеціальним функціональним режимом роботи осцилографа, у якому розгортка по осі X формується не внутрішнім генератором пилоподібної напруги (розгорткою часу), а вхідним сигналом, поданим на перший канал (CH1 / X). Сигнал другого каналу (CH2 / Y) відхиляє електронний промінь по вертикалі.

---

### 1. Специфікація режимів входу та налаштування каналів

План налаштування органів керування аналогового або цифрового осцилографа (DSO) перед початком вимірювань у режимі X-Y наведено у структурованій таблиці нижче. 

Кожен параметр входу осцилографа має строге фізичне обґрунтування:

| Параметр | Значення / Налаштування | Призначення та фізичний зміст |
| :--- | :--- | :--- |
| **Режим розгортки (Display Mode)** | `X-Y` (або `Vector / Dual`) | Відключає генератор часу; CH1 керує відхиленням X, CH2 — відхиленням Y. |
| **Вхідний зв'язок (Channel Coupling)** | `DC` (постійний струм) | Зберігає постійну складову напруги та запобігає фазовим спотвореннях на низьких частотах. |
| **Зв'язок AC (для особливих випадків)** | `AC` (змінний струм) | Застосовують для відсікання постійного зсуву, але лише при `f > 100 Гц` (щоб уникнути фазового зсуву `RC`-ланцюга). |
| **Вхідний імпеданс (Input Impedance)** | `1 MΩ / 15-20 pF` | Стандартне вхідне навантаження для підключення пасивних щупів-дільників `10:1`. |
| **Дільник щупа (Probe Attenuation)** | `10X` (або `1X`) | Зменшує вхідну ємність щупа до `~10 pF` та розширює смугу пропускання. |
| **Смуга пропускання (BW Limit)** | `OFF` (або `20 MHz`) | `OFF` — для високочастотних вимірів; `20 MHz` — для придушення високочастотних завад і шумів. |
| **Калібрування фази каналів (Channel Skew)** | `0.0 ns` | Компенсує різницю довжин вимірювальних кабелів та міжканальну затримку осцилографа. |

#### Детальний аналіз фізичного впливу вхідних кіл осцилографа:
1. **Небезпека режиму AC-coupling при фазових вимірюваннях:**
   При включенні режиму `AC` послідовно із входом осцилографа вмикається роздільний конденсатор `C_ac`, який разом із вхідним опором `R_in = 1 МОм` утворює дифенціювальний `RC`-фільтр високих частот. Частота зрізу цього фільтра становить `f_c = 1 / (2π · R_in · C_ac) ≈ 2...10 Гц`. Однак фазовий зсув `Δφ = arctan(f_c / f)` поширюється значно вище частоти зрізу. На частоті `50 Гц` додатковий фазовий зсув від `AC`-зв'язку може досягати `2°...5°`, що повністю спотворює вимірювання фази. Тому для вимірювання фази завжди використовують режим `DC`.

2. **Компенсація пасивних щупів 10X:**
   Перед проведенням вимірювань обидва щупи мають бути строго скомпенсовані за допомогою вбудованого калібратора меандру `1 кГц / 3 В`. Некомпенсований щуп утворює частотно-залежний дільник напруги, який вносить неузгоджені фазові затримки між каналами CH1 та CH2 на частотах понад `10 кГц`.

### 2. Покроковий стандартний протокол вимірювання різниці фаз δ

Визначення різниці фаз між двома гармонічними сигналами одинакової частоти `f_x = f_y` здійснюється за методом геометричних параметрів еліпса Ліссажу.

```
+-------------------------------------------------------------------------+
|                ПОКРОКОВИЙ ПРОТОКОЛ ВИМІРЮВАННЯ ФАЗИ                    |
+-------------------------------------------------------------------------+
| Крок 1. Калібрування нульового зміщення (Zero Offset Calibration)      |
|   1.1. Переключити обидва канали CH1 та CH2 у режим зв'язку 'GND'.      |
|   1.2. Ручками 'Position X' та 'Position Y' звести світлову точку       |
|        строго в центр координатної сітки екрана (0, 0).                |
|                                                                         |
| Крок 2. Подача сигналів та збалансування амплітуд                       |
|   2.1. Переключити CH1 та CH2 у режим 'DC'.                             |
|   2.2. Ручками 'Volts/Div' налаштувати масштаби так, щоб еліпс займав   |
|        приблизно 80% висоти та ширини екрана (наприклад, 6-8 поділок).   |
|                                                                         |
| Крок 3. Вимірювання геометричних розмірів еліпса                        |
|   3.1. Виміряти повну висоту еліпса по вертикальній осі: 2 · Y_max      |
|        (від найнижчої точки еліпса до найвищої).                        |
|   3.2. Виміряти відстань між точками перетину еліпса з віссю Y: 2 · Y₀   |
|        (відстань між точками, де еліпс перетинає центральну лінію X=0). |
|                                                                         |
| Крок 4. Розрахунок різниці фаз δ                                       |
|   4.1. Обчислити відношення: sin(δ) = (2 · Y₀) / (2 · Y_max) = Y₀ / Y_max |
|   4.2. Знайди кут: δ = arcsin( Y₀ / Y_max )                            |
+-------------------------------------------------------------------------+
```

### 3. Таблиця ідентифікації квадранта фазового зсуву

Математична функція `arcsin` повертає значення кута лише у діапазоні `[0°, 90°]`. Для точного визначення повного значення фазового зсуву `δ ∈ [0°, 360°]` використовують геометричні ознаки орієнтації та напрямку обертання траєкторії, наведені у таблиці:

| Нахил головної осі еліпса | Напрямок обертання променя | Перетин Y₀ при X=0 | Квадрант фази | Підсумкова формула для фази δ |
| :--- | :--- | :--- | :--- | :--- |
| **I та III квадранти** (Пряма лінія) | Немає (Відрізок) | `Y₀ = 0` | `0°` (Синфазність) | `δ = 0°` |
| **I та III квадранти** (Праворуч) | Проти годинникової стрілки | `0 < Y₀ < Y_max` | I квадрант (`0° < δ < 90°`) | `δ = arcsin(Y₀ / Y_max)` |
| **Вертикально / Горизонтально** | Проти годинникової стрілки | `Y₀ = Y_max` | `90°` (Квадратура) | `δ = 90°` (π/2 rad) |
| **II та IV квадранти** (Ліворуч) | Проти годинникової стрілки | `0 < Y₀ < Y_max` | II квадрант (`90° < δ < 180°`) | `δ = 180° − arcsin(Y₀ / Y_max)` |
| **II та IV квадранти** (Пряма лінія) | Немає (Відрізок) | `Y₀ = 0` | `180°` (Протифаза) | `δ = 180°` (π rad) |
| **II та IV квадранти** (Ліворуч) | За годинниковою стрілкою | `0 < Y₀ < Y_max` | III квадрант (`180° < δ < 270°`)| `δ = 180° + arcsin(Y₀ / Y_max)` |
| **Вертикально / Горизонтально** | За годинниковою стрілкою | `Y₀ = Y_max` | `270°` (Квадратура) | `δ = 270°` (3π/2 rad) |
| **I та III квадранти** (Праворуч) | За годинниковою стрілкою | `0 < Y₀ < Y_max` | IV квадрант (`270° < δ < 360°`)| `δ = 360° − arcsin(Y₀ / Y_max)` |

### 4. Визначення знака фази через метод зміщення (Frequency Shift Test)

Якщо осцилограф не має функції відображення напрямку обертання електронного променя (наприклад, у стаціонарному растровому режимі цифрового DSO), знак квадранта фази визначають за допомогою випробувального зміщення частоти:

1. Невеликим поворотом ручки генератора збільште частоту сигналу каналу X (`f_x`) на крихітну величину `Δf ≈ 1 Гц`.
2. Уважно спостерігайте за напрямком обертання світлового еліпса на екрані:
   - Якщо еліпс почне обертатися **проти годинникової стрілки**, початковий фазовий зсув каналу X відносно Y був додатним (`0 < δ < 180°`).
   - Якщо еліпс почне обертатися **за годинниковою стрілкою**, початковий фазовий зсув був від'ємним (`180° < δ < 360°`).

### 5. Протокол вимірювання зсуву фази між струмом та напругою в силовій електроніці

У силовій електротехніці та розрахунках коефіцієнта потужності `cos φ` вимірювання різниці фаз між напругою `v(t)` та струмом `i(t)` у колі є критично важливим для оцінки реактивної потужності.

#### Налаштування вимірювальної схеми:
1. **Канал X (CH1):** Підключається через диференційний високовольтний щуп паралельно до навантаження для зняття сигналу напруги `v(t)`.
2. **Канал Y (CH2):** Підключається через токознімальний резистор (шунт) або струмові кліщі (Current Probe) послідовно із навантаженням для зняття сигналу струму `i(t)`.
3. **Калібрування затримки струмового щупа:** Струмові кліщі з активною компенсацією мають власну внутрішню затримку сигналу `t_delay ≈ 15...45 нс`. Перед початком вимірювань обов'язково подають синусоїдальний тестовий сигнал на активний резистор та за допомогою регулятора `Deskew` досягають перетворення еліпса на пряму похилу лінію (`δ = 0°`).

Обчислений кут `φ = arcsin(Y₀ / Y_max)` дозволяє відразу визначити коефіцієнт потужності кола `cos φ` та активну потужність `P = V_rms · I_rms · cos φ`.

### 6. Протокол підрахунку співвідношення частот f_x : f_y

Для визначення невідомої частоти сигналу `f_x` при відомій еталонній частоті `f_y` виконують підрахунок кількості дотичних точок траєкторії до меж прямокутника обмеження.

```
+-------------------------------------------------------------------------+
|          ПРОТОКОЛ ВИЗНАЧЕННЯ СПІВВІДНОШЕННЯ ЧАСТОТ LISSAJOUS            |
+-------------------------------------------------------------------------+
| 1. Зупинити або стабілізувати обертання фігури ручкою частоти джерела. |
| 2. Уявно описати прямокутник навколо фігури Ліссажу на екрані.          |
| 3. Порахувати кількість точок N_horiz, у яких крива торкається        |
|    верхньої або нижньої горизонтальної рамки.                           |
| 4. Порахувати кількість точок N_vert, у яких крива торкається           |
|    лівої або правої вертикальної рамки.                                 |
| 5. Розрахувати невідому частоту за формулою:                            |
|                                                                         |
|       f_x = f_y · ( N_horiz / N_vert )                                  |
|                                                                         |
| Примітка: Якщо вершина фігури проходить через кут прямокутника, ця      |
| кутова точка зараховується як 0.5 дотику.                               |
+-------------------------------------------------------------------------+
```

#### Довідкова таблиця типових конфігурацій фігур Ліссажу:

| Співвідношення частот `f_x : f_y` | Кількість верт. точок `N_vert` | Кількість гор. точок `N_horiz` | Форма фігури при `δ = 90°` | Форма фігури при `δ = 0°` |
| :---: | :---: | :---: | :--- | :--- |
| **1 : 1** | 1 | 1 | Коло / Стоячий еліпс | Похила пряма лінія |
| **1 : 2** | 2 | 1 | «Вісімка» (Лемніската) | Парабола / Дуга Чебишова T₂ |
| **1 : 3** | 3 | 1 | Потрійна петля | Крива Чебишова T₃ |
| **2 : 3** | 3 | 2 | 3 вертикальні / 2 горизонтальні петлі | Кобзарний вузол |
| **3 : 4** | 4 | 3 | 4 вертикальні / 3 горизонтальні петлі | Мереживний вузол |

### 7. Особливості роботи цифрових осцилографів (DSO) у режимі X-Y

Сучасні цифрові осцилографи запам'ятовування (DSO / MSO) мають власні апаратні та програмні особливості при роботі в режимі X-Y:

1. **Обмеження глибини пам'яті (Record Length):**
   У режимі X-Y більшість цифрових осцилографів автоматично зменшують глибину буфера кадру до `10 kpts...100 kpts` для забезпечення високої частоти оновлення екрана (WFM/s). Це запобігає затримкам відображення при обробці великих масивів точок.

2. **Режими інтерполяції (Linear vs Sin(x)/x Interpolation):**
   Для запобігання появі кутастих зламів траєкторії рекомендується включати інтерполяцію `Sin(x)/x`. Вона відновлює непреривну форму синусоїди між апаратними відліками АЦП. Линійне з'єднання точок при низькій частоті дискретизації утворює многокутники замість плавних еліпсів.

3. **Аппаратно-програмна затримка каналів (Channel Skew Compensation):**
   У меню цифрового осцилографа `Channel -> Deskew` виправляючу часову затримку можна встановити вручну з точністю до `10 пікосекунд`. Це дозволяє скомпенсувати різницю довжин кабелів або різницю затримок у вимірювальних трансформаторах струму та напруги.

4. **Використання третього каналу модуляції (Z-Axis Modulation):**
   Багато лабораторних осцилографів мають задній роз'єм входу `Z-Axis Input`. Подача на цей вхід імпульсів напруги вимикає або підсилює яскравість електронного променя у визначені моменти часу. Це дозволяє наносити часові мітки (пунктир) прямо на траєкторію Ліссажу для точного визначення частоти обертання.

### 8. Вимірювання фазового розбалансу I/Q у квадратурних RF-демодуляторах

У радіочастотних системах зв'язку (LTE, Wi-Fi, 5G) квадратурні модулятори формують два аналогові сигнали: синфазний `I(t)` (In-Phase) та квадратурний `Q(t)` (Quadrature). В ідеальному випадку кут між ними становить точно `90°`, а амплітуди `A_I = A_Q`.

#### Протокол діагностики I/Q розбалансу на векторному осцилографі:
1. Подати сигнал `I(t)` на канал X (CH1), а сигнал `Q(t)` на канал Y (CH2).
2. На екрані осцилографа утвориться констеляційна фігура Ліссажу:
   - **Ідеальний квадратурний сигнал:** утворює ідеальне коло з центром у точці `(0, 0)`.
   - **Амплітудний розбаланс (`A_I ≠ A_Q`):** коло сплющується у вертикальний або горизонтальний еліпс із горизонтальними осями.
   - **Фазовий розбаланс (`Δφ ≠ 90°`):** коло перетворюється на похилий еліпс, головна вісь якого повернена на кут `θ = 0.5 · arctan(2 · A_I · A_Q · cos(Δφ) / (A_I² − A_Q²))`.

Цей протокол дає змогу інженеру за кілька секунд візуально виявити та скомпенсувати фазові нелінійності гетеродина квадратурного змішувача.

### 9. Режим характеристичного промальовувача (Curve Tracer Mode)

Режим X-Y осцилографа є основою для побудови **характеристичних графопобудовників** (Curve Tracer) для дослідження вольт-амперних характеристик (ВАХ) напівпровідникових приладів (діодів, стабілітронів, транзисторів).

#### Схема вимірювання ВАХ діода:
- На схему подається змінна напруга `V_ac(t)` від синусоїдального трансформатора 50 Гц.
- **Канал X (CH1):** вимірює падіння напруги безпосередньо на діоді `V_d(t)`.
- **Канал Y (CH2):** вимірює напругу на послідовному токовимірювальному резисторі `R_sense`, яка пропорційна струму діода `I_d(t) = V_R / R_sense`.

На екрані осцилографа утворюється пряма графічна крива вольт-амперної характеристики: нульовий струм при зворотній напрузі, експоненціальне зростання при досягненні прямого порогу `V_th ≈ 0.7 В` для кремнієвого діода та зворотний пробій для стабілітрона.

### 10. Визначення резонансних частот п'єзокерамічних ультразвукових випромінювачів

При дослідженні п'єзоелектричних датчиків та ультразвукових випромінювачів важливо точно визначати резонансну частоту `f_r` (де імпеданс є чисто активним) та антирезонансну частоту `f_a`.

#### Протокол резонансних вимірювань:
1. Подати на п'єзоелемент сигнал від генератора частоти `f_gen` через послідовний вимірювальний резистор `R = 100 Ом`.
2. Канал X підключити до виходу генератора, а Канал Y — до точки з'єднання резистора і п'єзоелемента.
3. Повільно плавно змінювати частоту генератора `f_gen`:
   - На більшості частот п'єзоелемент має ємнісний характер, утворюючи похилий еліпс Ліссажу.
   - При досягненні резонансної частоти `f_r` фазовий зсув `δ` стає рівним `0°`, і еліпс схлопується у вузьку похилу пряму лінію.

### 11. Використання вектороскопа у професійному аудіозапису (Goniometer Protocol)

У звукорежисурі та майстерингу двоканальний режим X-Y осцилографа застосовується у вигляді вимірювального приладу — **гоніометра** (стереовектороскопа).

#### Порядок інтерпретації стереокартини на гоніометрі:
- **Повна моно-сумісність (Синфазні лівий і правий канали `L = R`):** траєкторія згортається у тонку вертикальну пряму лінію під кутом `45°`.
- **Протифазні канали (`L = −R`):** траєкторія перетворюється на тонку горизонтальну пряму під кутом `135°` (сигнал скасується при підсумовуванні в моно).
- **Ідеальне стерео (Об'ємна панорама):** утворюється симетрична кругова або овальна хмара з фазовим коефіцієнтом кореляції `r ∈ [+0.5, +0.8]`.

### 12. Автоматизовані вимірювання через інтерфейс SCPI (IEEE 488.2)

Для автоматизації лабораторних вимірювань фази та частоти за допомогою програмного забезпечення (Python / LabVIEW / MATLAB) осцилографи керуються за допомогою команд протоколу SCPI через USB-TMC або Ethernet (LXI).

#### Типовий послідовний скрипт налаштування осцилографа (SCPI Command Set):

```
:CHANnel1:COUPling DC            # Включення DC-зв'язку каналу 1 (X)
:CHANnel2:COUPling DC            # Включення DC-зв'язку каналу 2 (Y)
:CHANnel1:PROBe 10               # Налаштування дільника 10X для каналу 1
:CHANnel2:PROBe 10               # Налаштування дільника 10X для каналу 2
:TIMebase:MODe XY                # Переключення осцилографа у режим X-Y
:MEASure:PHASes CH1, CH2         # Апаратне вимірювання різниці фаз між CH1 та CH2
:WAVeform:SOURce CH1             # Вибір каналу 1 для зчитування масиву відліків АЦП
:WAVeform:DATA?                  # Запит сирого масиву точок траєкторії
```

#### Математична обробка отриманого масиву в Python (SciPy):
Після отримання сирих цифрових масивів напруг `x_data` та `y_data` обчислення точностей параметрів еліпса здійснюється методом найменших квадратів (Least Squares Ellipse Fitting):

```python
import numpy as np
from scipy.optimize import least_squares

def fit_ellipse(x, y):
    # Апроксимація загального рівняння другого порядку Ax² + Bxy + Cy² + Dx + Ey + 1 = 0
    D = np.array([x**2, x*y, y**2, x, y]).T
    d2 = np.ones_like(x)
    res = np.linalg.lstsq(D, d2, rcond=None)[0]
    return res
```

Це дозволяє цифровому алгоритму визначати фазовий зсув із точністю до `0.01°`, що недосяжно при зоровому спостереженні за аналоговою сіткою осцилографа.

### 13. Вимірювання фазового шуму та нестабільності гетеродина (Phase Noise SOP)

У високостабільних генераторах опорної частоти (рубідієвих або кварцових генераторах OCXO) режим X-Y використовується для швидкого виявлення фазового шуму та дрейфу частоти.

#### Покроковий SOP вимірювання короткочасної нестабільності:
1. Подати сигнал від еталонного опорного генератора 10 МГц на канал X.
2. Подати сигнал від досліджуваного генератора 10 МГц на канал Y.
3. Якщо розсув частот між генераторами становить `Δf = 0.001 Гц`, світловий еліпс буде здійснювати один повний оберт за 1000 секунд. Спостереження за швидкістю та плавністю обертання дозволяє визначати короткочасну фазову нестабільність (девіацію Аллена) без застосування дорогих спектроаналізаторів.

### 14. Лазерна інтерферометрія та оптичні вимірювання фази

У прецизійних оптичних лабораторіях (лазерна інтерферометрія Майкельсона чи Гейгера) фігури Ліссажу утворюються при змішуванні двох фотодіодних сигналів від фотодетектора.

Один сигнал пропорційний `sin(2π · Δd / λ)`, другий — `cos(2π · Δd / λ)`. Подача цих сигналів у режим X-Y перетворює мікроскопічний зсув дзеркала `Δd` на кутове обертання фазового вектора на екрані, де один повний оберт еліпса відповідає зсуву дзеркала на половину довжини хвилі світла `λ / 2 ≈ 316.4 нм` для гелій-неонового лазера.

### 15. Протокол безпеки та захисту входів осцилографа при високовольтних вимірюваннях

При роботі в режимі X-Y із високовольтними ланцюгами (наприклад, в електроприводах або імпульсних джерелах живлення) недотримання правил заземлення може призвести до короткого замикання або виходу осцилографа з ладу:

1. **Заборона зняття заземлення осцилографа ("Floating Scope Hazard"):**
   Ніколи не відключайте дріт заземлення вилки осцилографа від мережі. Використовуйте тільки гальванічно ізольовані диференційні щупи (High-Voltage Differential Probes).
2. **Перевірка максимально припустимої напруги каналу (CAT Rating):**
   Переконайтеся, що напруга між землею щупа та корпусом не перевищує категорію захисту осцилографа (наприклад, CAT II 300 V).

### 16. Практичний інженерний діагностичний календар та типові несправності

При вимірюваннях у режимі X-Y на реальних радіотехнічних схемах спотворення форми еліпса Ліссажу дозволяє миттєво діагностувати характер несправності:

1. **Еліпс зі зрізаними вершинами (Clipping / Saturation):**
   Вказує на підсилювальне перевантаження одного з каналів або насичення сердечника вимірювального трансформатора. Сигнал виходить за межі лінійного діапазону.

2. **«Розмита» або потовщена лінія еліпса (Noise Floor / Hum):**
   Вказує на наявність високочастотного шуму або наводок мережі `50 Гц`. Необхідно включити обмеження смуги `20 MHz BW Limit` або перевірити заземлення щупів.

3. **Спіралеподібне обертання або «дихання» розміру:**
   Вказує на наявність амплітудної або частотної модуляції у вхідному сигналі (амплітудна нестабільність джерела).

### 17. Розрахунок бюджету похибки вимірювань (Error Budget)

Точність вимірювання фазового зсуву `δ` на аналогових та цифрових осцилографах обмежена апаратною похибкою. Головні компоненти похибки наведено нижче:

1. **Похибка зчитування координат з сітки (Grid Reading Error):**
   При ручному вимірюванні по сітці абсолютна похибка відліку становить близько `ΔY ≈ ±0.1` поділки. Відносна похибка обчислення фази `Δδ` прямує до мінімуму при `δ ≈ 0°` та стрімко зростає при `δ → 90°` через нелінійність функції `arcsin`:

   ```
   Δδ = (1 / cos(δ)) · √[ (ΔY₀ / Y_max)² + (Y₀ · ΔY_max / Y_max²)² ]
   ```

   При `δ = 85°` похибка вимірювання фази може досягати `±10°`. Для підвищення точності при `δ → 90°` рекомендується переходити на вимірювання перетинів по осі X (`X₀ / X_max`).

2. **Міжканальний розсинхронізм (Inter-channel Skew):**
   Різниця довжин внутрішніх трактів підсилювачів каналів CH1 та CH2 вносить додатковий фазовий зсув `δ_skew = 2π · f · Δt_skew`. Для осцилографів із `Δt_skew = 100 ps` на частоті `10 МГц` додаткова похибка фази становить:

   ```
   δ_skew = 2π · 10⁷ Гц · 10⁻¹⁰ с = 0.002π rad ≈ 0.36°
   ```

3. **Вхідна ємність та кабельне навантаження:**
   Використання неузгоджених коаксіальних кабелів без дільників `10X` створює фазовий зсув на вхідній ємності осцилографа `C_in ≈ 20 pF`, що на високочастотних сигналах вимагає обов'язкового попереднього калібрування каналів за допомогою фазового катушки або вимірювального містка.
