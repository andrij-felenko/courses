# 🧮 Математика лінійності: оператори, функції Гріна та спектральний розклад

Математичним фундаментом принципу суперпозиції є теорія **лінійних операторів** у векторних та функціональних просторах. Незалежно від того, чи йдеться про механічну систему з пружинами, електричне коло із конденсаторами, поширення світла чи квантовомеханічну хвильову функцію, формальна математична структура залишається незмінною. Якщо фізичний процес описується лінійним операторним рівнянням, принципово будь-яку складну дію можна розкласти на суму простих складників.

У цій математичній вставці розглядається математичний апарат лінійності: алгебра просторів Гільберта, операторні тотожності, метод розв'язання неоднорідних рівнянь через імпульсну функцію Гріна, спектральна теорема Штурма — Ліувілля та матричний формалізм простору станів.

---

### 1. Визначення лінійного простору та лінійного оператора

Нехай `V` та `W` — два векторні простори над полем дійсних `ℝ` або комплексних `ℂ` чисел. Відображення (або оператор) `L: V → W` називається **лінійним**, якщо для будь-яких елементів `x₁, x₂ ∈ V` та довільних скалярів `c₁, c₂` виконується фундаментальна операторна тотожність:

```
L(c₁ · x₁ + c₂ · x₂) = c₁ · L(x₁) + c₂ · L(x₂)
```

Ця єдина тотожність поєднує в собі дві фундаментальні алгебраїчні властивості:

1. **Адитивність:** `L(x₁ + x₂) = L(x₁) + L(x₂)` — відгук на суму збурень дорівнює сумі окремих відгуків. Принцип адитивності гарантує відсутність нелінійного «склеювання» чи спотворення сигналів при їхньому сумісному проходженні крізь систему.
2. **Однорідність (масштабна інваріантність):** `L(c · x) = c · L(x)` — зміна масштабу вхідного збурення в `c` разів призводить до точно такого ж масштабування вихідного відгуку.

Якщо оператор `L` задовольняє цю умову, будь-яке лінійне рівняння вигляду:

```
L(u) = f
```

де `u` — невідомий стан системи (вектор чи функція), а `f` — зовнішнє збурення (вхідний сигнал, джерело заряду, сила), підпорядковується принципу суперпозиції.

#### Скалярний добуток та Гільбертів простір

Для фізичних застосувань функціональний простір `V` забезпечують додатковою структурою — **скалярним добутком** `⟨f | g⟩`. У просторі дійснозначних або комплекснозначних функцій, інтегровних із квадратом `L²(a, b)`, скалярний добуток двох функцій визначається як інтеграл їхнього перекриття:

```
⟨f | g⟩ = ∫ [ f*(x) · g(x) ] dx
```

де `f*(x)` позначує комплексне спряження.

Наявність скалярного добутку дозволяє ввести поняття **норми** (довжини функції) `||f|| = √(⟨f | f⟩)` та **ортогональності**: дві функції `f` та `g` називаються ортогональними, якщо їхній скалярний добуток дорівнює нулю `⟨f | g⟩ = 0`. Ортогональність є математичним еквівалентом незалежності двох фізичних станів. Повний нормамований простір зі скалярним добутком називається **Гільбертовим простором**.

Оператор `L†` називається **спряженим** (або гермітово-спряженим) до оператора `L`, якщо для будь-яких функцій `f` та `g` виконується тотожність:

```
⟨L(f) | g⟩ = ⟨f | L†(g)⟩
```

Якщо оператор збігається зі своїм спряженим `L = L†`, він називається **самоспряженим** (або гермітовим). У квантовій механіці самоспряженість операторів є фундаментальною вимогою, оскільки лише самоспряжені оператори гарантують суто дійсні власні значення `λₖ ∈ ℝ`, які відповідають вимірюваним фізичним величинам (енергії, імпульсу, координаті).

За теоремою Рісса про представлення лінійних функціоналів, будь-який неперервний лінійний функціонал `F(f)` у Гільбертовому просторі виражається у вигляді скалярного добутку `F(f) = ⟨g | f⟩` для деякого єдиного елемента `g`. Саме ця теорема забезпечує математичну строгість застосування дельта-функції Дірака `δ(x - x')` як узагальненої функції (дистрибуції).

За альтернативою Фредгольма, для лінійного операторного рівняння `L(u) = f` існує дві взаємовиключні можливості:
1. Однорідне рівняння `L(u) = 0` має лише тривіальний розв'язок `u = 0`. Тоді неоднорідне рівняння `L(u) = f` має єдиний розв'язок для будь-якої правої частини `f`.
2. Однорідне рівняння `L(u) = 0` має нетривіальні розв'язки (підпростір ядер `Ker(L)` розмірності `k > 0`). Тоді неоднорідне рівняння `L(u) = f` має розв'язок тоді і тільки тоді, коли права частина `f` є ортогональною до всіх розв'язків спряженого однорідного рівняння `L†(v) = 0`.

Ця теорема грає вирішальну роль при аналізі систем із резонансом: якщо частота зовнішньої сили збігається з власною частотою однорідного рівняння, звичайна суперпозиція обривається виникненням необмежено зростаючих резонансних коливань.

### 2. Однорідні й неоднорідні рівняння: структура розв'язку

Розглянемо лінійне диференціальне рівняння `n`-го порядку з коефіцієнтами `aₖ(t)`, що залежать від часу або координат:

```
L(u) = aₙ(t)·(dⁿu/dtⁿ) + aₙ₋₁(t)·(dⁿ⁻¹u/dtⁿ⁻¹) + ... + a₁(t)·(du/dt) + a₀(t)·u = f(t)
```

Математична структура розв'язку такого рівняння будується у два обов'язкових кроки.

#### Крок 1. Ядро оператора та однорідне рівняння

Спочатку розглянемо однорідне рівняння, коли зовнішня сила відсутня (`f(t) = 0`):

```
L(u) = 0
```

Множина всіх розв'язків однорідного рівняння утворює ядро оператора `Ker(L)` — лінійний підпростір простору функцій. Для диференціального рівняння `n`-го порядку цей підпростір має скінченну розмірність `n`. Це означає, що існує фундаментальна система розв'язків із `n` лінійно незалежних функцій `{u₁(t), u₂(t), ..., uₙ(t)}`.

Лінійна незалежність визначається за допомогою визначника Вронського (вронськіана):

```
W(u₁, u₂, ..., u♞) = det [ dᵏ⁻¹uᵢ / dtᵏ⁻¹ ] ≠ 0
```

За принципом суперпозиції, будь-яка лінійна комбінація фундаментальних функцій також є розв'язком однорідного рівняння:

```
u_hom(t) = c₁·u₁(t) + c₂·u₂(t) + ... + cₙ·uₙ(t)    [де cᵢ — довільні сталі]
```

Перевірка адитивності для фундаментальної системи здійснюється безпосередньо:

```
L(u_hom)
= L(c₁·u₁ + c₂·u₂ + ... + cₙ·uₙ)
= c₁·L(u₁) + c₂·L(u₂) + ... + cₙ·L(uₙ)     [лінійність оператора L]
= c₁·0 + c₂·0 + ... + cₙ·0                  [бо uᵢ — розв'язки однорідного]
= 0
```

#### Крок 2. Загальний розв'язок неоднорідного рівняння

Якщо на систему діє зовнішня сила `f(t) ≠ 0`, загальний розв'язок неоднорідного рівняння `L(u) = f` складається із суми загального розв'язку однорідного рівняння `u_hom` та будь-якого часткового розв'язку неоднорідного рівняння `u_part`:

```
u(t) = u_hom(t) + u_part(t)
```

Перевірка підстановкою в оператор:

```
L(u) 
= L(u_hom + u_part)      [підстановка u = u_hom + u_part]
= L(u_hom) + L(u_part)   [лінійність оператора L]
= 0 + f(t)               [бо L(u_hom) = 0 та L(u_part) = f(t)]
= f(t)                   [додавання нульового вектора]
```

Фізичний зміст цієї суми глибокий: `u_hom(t)` описує **власні коливання** системи (вільний рух за рахунок початкової енергії чи початкових умов), а `u_part(t)` описує **вимушені коливання**, нав'язані зовнішнім джерелом `f(t)`. Суперпозиція дозволяє розв'язувати ці дві частини абсолютно незалежно.

### 3. Метод функцій Гріна: неперервна суперпозиція імпульсів

Що робити, коли права частина `f(t)` є довільною, складною функцією часу чи простору? Традиційний вибір часткового розв'язку підбором стає неможливим. На допомогу приходить метод функцій Гріна — найвищий прояв суперпозиції у формі неперервного інтегрування.

Представимо довільну дію `f(t)` як нескінченну суму (інтеграл) точкових імпульсів — дельта-функцій Дірака `δ(t - t')`:

```
f(t) = ∫ f(t') · δ(t - t') dt'
```

Дельта-функція Дірака має властивості: `δ(t - t') = 0` при `t ≠ t'`, а інтеграл `∫ δ(t - t') dt' = 1`. Вона описує ідеальний миттєвий імпульс одиничної площі. Кожен елементарний імпульс `f(t') dt'` діє у мить `t'` із «вагою» `f(t')`.

Нехай `G(t, t')` є відгуком системи у мить `t` на одиничний імпульс, прикладений у мить `t'`. Ця функція називається **функцією Гріна** (або імпульсною перехідною характеристикою) і задовольняє операторне рівняння:

```
L[ G(t, t') ] = δ(t - t')
```

Для причинних (causal) часових систем функція Гріна задовольняє умову причинності: `G(t, t') = 0` при `t < t'` (система не може відповідати на збурення до того, як воно відбулося). Така функція Гріна називається **запізнілою (retarded) функцією Гріна**.

Завдяки лінійності оператора `L`, шуканий частковий розв'язок `u_part(t)` для довільного `f(t)` будується як неперервна лінійна комбінація (суперпозиція) відгуків на окремі дельта-імпульси:

```
u_part(t) = ∫ G(t, t') · f(t') dt'
```

Доведемо цей результат безпосередньою дією оператора `L`:

```
L[ u_part(t) ]
= L[ ∫ G(t, t') · f(t') dt' ]
= ∫ L[ G(t, t') ] · f(t') dt'    [внесення лінійного оператора під інтеграл]
= ∫ δ(t - t') · f(t') dt'       [бо L[G] = δ(t - t')]
= f(t)                           [за фільтруючою властивістю δ-функції]
```

Це математичне виведення доводить: функція Гріна `G(t, t')` повністю характеризує лінійну систему. Знаючи відгук на один імпульс, ми через суперпозицію (інтеграл згортки) знаємо відгук системи на **будь-який** вхідний сигнал.

#### Крайові умови та типи функцій Гріна

У просторових задачах (електростатика, гравітація, теплопровідність, хвилі у резонаторах) функція Гріна підпорядковується крайовим умовам на межі області `∂Ω`:

1. **Умова Діріхле:** `G(r, r') = 0` при `r ∈ ∂Ω` — потенціал на межі дорівнює нулю (наприклад, заземлена провідна поверхня).
2. **Умова Неймана:** `∂G / ∂n = 0` при `r ∈ ∂Ω` — нормальна похідна дорівнює нулю (ізольована межа без потоку).
3. **Умова випромінювання Зоммерфельда:** хвилі на нескінченності мають бігти від джерела, а не з нескінченності до нього.

Завдяки граничним умовам функція Гріна враховує не лише пряму дію джерела, а й усе відбивання від меж області через суперпозицію уявних джерел (метод дзеркальних зображень).

Наприклад, для тривимірного оператора Пуассона `∇² V = -ρ / ε₀` у безмежному просторі функція Гріна задається фундаментальним кулонівським відгуком `G(r, r') = 1 / (4 · π · ε₀ · |r - r'|)`. А для одновимірного хвильового рівняння `(∂²u/∂t²) - c² · (∂²u/∂x²) = f(x, t)` запізніла функція Гріна описується прямокутним імпульсом просуву:

```
G(x, t; x', t') = (1 / (2·c)) · θ( c·(t - t') - |x - x'| )
```

де `θ(ξ)` — сходинкова функція Хевісайда. Ця формула математично виражає відомий висновок д'Аламбера: збурення, створене у мить `t'` у точці `x'`, розходиться у обидва боки зі швидкістю `c`, утворюючи «трикутник впливу» в просторі-часі. За принципом суперпозиції, стан хвилі у будь-якій точці є сумою всіх збурень із їхніх минулих трикутників впливу.

### 4. Спектральна теорія та розклад за власними функціями

Інший фундаментальний спосіб застосування суперпозиції полягає в зміні базису у функціональному просторі. Для багатьох лінійних самоспряжених операторів (наприклад, оператора Лапласа `∇²` чи оператора Шредінгера) існує набір **власних функцій** `ϕₖ` та **власних значень** `λₖ`, які задовольняють рівняння:

```
L(ϕₖ) = λₖ · ϕₖ
```

Дія оператора `L` на власну функцію `ϕₖ` не змінює її форми, а лише масштабує її на число `λₖ`.

#### Теорема Штурма — Ліувілля та повнота базису

За теоремою Штурма — Ліувілля, для будь-якого самоспряженого диференціального оператора `L = L†`:

1. Усі власні значення `λₖ` є суто дійсними числами.
2. Власні функції `ϕₖ`, що відповідають різним власним значенням, є ортогональними: `⟨ϕᵢ | ϕⱼ⟩ = 0` при `i ≠ j`.
3. Система власних функцій `{ϕₖ}` утворює **повний ортонормований базис** у Гільбертовому просторі `L²`.

Повнота базису означає, що довільну функцію стану `u(x)` можна подати як нескінченний ряд (суперпозицію) власних функцій:

```
u(x) = ∑ cₖ · ϕₖ(x)
```

де коефіцієнти розкладу обчислюються через скалярний добуток:

```
cₖ = ⟨ϕₖ | u⟩ = ∫ [ ϕₖ*(x) · u(x) ] dx
```

Рівність Парсеваля гарантує збереження норми (повної енергії) при переході до спектрального базису:

```
∫ |u(x)|² dx = ∑ |cₖ|²
```

Завдяки суперпозиції, дія оператора `L` на складну функцію `u(x)` перетворюється на просте множення коефіцієнтів розкладу на власні числа:

```
L(u) 
= L( ∑ cₖ · ϕₖ )
= ∑ cₖ · L(ϕₖ)       [за лінійністю оператора L]
= ∑ cₖ · λₖ · ϕₖ      [бо L(ϕₖ) = λₖ·ϕₖ]
```

Саме ця властивість робить перетворення Фур'є та перетворення Лапласа такими потужними інструментами: вони діагоналізують лінійний оператор, перетворюючи складні диференціальні рівняння на прості алгебраїчні рівняння відносно спектральних амплітуд `cₖ`.

Зв'язок між методом функцій Гріна та розкладом за власними функціями є фундаментальним. Функцію Гріна можна подати у вигляді спектрального сумування за власними модами оператора:

```
G(x, x') = ∑ [ (ϕₖ(x) · ϕₖ*(x')) / (λₖ - λ) ]
```

Ця формула показує, що функція Гріна є не що інше, як нескінченна сума резонансних відгуків кожної власної моди системи. При збігу частоти зовнішнього збурення `λ` із одним із власних чисел `λₖ` відповідний знаменник прямує до нуля, амплітуда прямує до нескінченності, і виникає фізичний **резонанс**.

### 5. Матрична форма у просторі станів (State-Space)

У сучасній теорії керування, обробці сигналів та багатовимірній механіці лінійну систему з `N` ступенями вільності задають системою диференціальних рівнянь першого порядку у просторі станів:

```
(d/dt) x(t) = A · x(t) + B · u(t)
y(t) = C · x(t) + D · u(t)
```

де `x(t)` — `N`-вимірний вектор стану (позиції та швидкості), `u(t)` — `M`-вимірний вектор вхідних сигналів, `y(t)` — `K`-вимірний вектор вихідних спостережень, `A` — матриця системи розміром `N × N`, `B` — матриця входів `N × M`, `C` — матриця виходу `K × N`, `D` — матриця прямого зв'язку `K × M`.

Загальний розв'язок цієї лінійної системи для початкового стану `x(0) = x₀` та вхідного сигналу `u(t)` описується формулою Коші (матричним аналогом імпульсної суперпозиції):

```
x(t) = exp(A · t) · x₀ + ∫ [ exp(A · (t - τ)) · B · u(τ) ] dτ
```

де `exp(A · t)` — матрична експонента, що обчислюється через матричний ряд Тейлора:

```
exp(A · t) = I + A·t + (A·t)² / 2! + (A·t)³ / 3! + ... = ∑ [ (A · t)ᵏ / k! ]
```

Перший доданок `exp(A · t) · x₀` — це суперпозиція відгуків системи на початкові умови при відсутньому вході (вільний рух). Другий доданок — це неперервна суперпозиція відгуків на зовнішній вхід `u(τ)` від моменту `τ = 0` до `τ = t` (вимушений рух).

Якщо матрицю системи `A` можна діагоналізувати за допомогою матриці власних векторів `V`:

```
A = V · Λ · V⁻¹
```

де `Λ = diag(λ₁, λ₂, ..., λ♞)` — діагональна матриця власних чисел, то матрична експонента спрощується до обчислення звичайних скалярних експонент для кожної моди:

```
exp(A · t) = V · diag( e^(λ₁·t), e^(λ₂·t), ..., e^(λ♞·t) ) · V⁻¹
```

Це доводить, що навіть у матричній формі простору станів динаміка будь-якої високовимірної лінійної системи розкладається на незважані суперпозиції незалежних експоненційних модальних відгуків.

#### Неперервний спектр та перетворення Фур'є

Коли область визначення сигналу або стану розширюється на всю дійсну вісь `(-∞, +∞)`, дискретний ряд Фур'є переходить у **неперервне перетворення Фур'є**. Замість дискретного набору власні значення утворюють неперервний спектр.

Довільний сигнал `f(t)` подається у вигляді неперервної суперпозиції нескінченної кількості гармонічних експонент `e^(i·ω·t)`:

```
f(t) = (1 / (2·π)) · ∫ [ F(ω) · e^(i·ω·t) ] dω
```

де спектральна густина `F(ω)` є прямим перетворенням Фур'є:

```
F(ω) = ∫ [ f(t) · e^(-i·ω·t) ] dt
```

Ця формула являє собою найвищий прояв спектральної суперпозиції в аналізі: будь-який неперіодичний процес скінченної енергії розкладається у континуум синусоїдальних хвиль. Згортка двох функцій `(f * g)(t) = ∫ f(τ)·g(t - τ) dτ` у спектральному просторі за теоремою про згортку перетворюється на просте поелементне множення їхніх спектральних густин:

```
F{ (f * g)(t) } = F(ω) · G(ω)
```

Це пояснює, чому у спектральній області аналіз будь-яких лінійних часовоінваріантних систем (LTI-систем) стає алгебраїчним: відгук системи `Y(ω)` дорівнює добутку спектра входу `X(ω)` на передавальну функцію `H(ω)`.

У дискретному часі спектральний розклад задається матрицею дискретного перетворення Фур'є (DFT) розміром `N × N` із елементами `Wₙₖ = exp(-i · 2π · n · k / N)`. Матриця DFT є унітарною матрицею, яка здійснює точну ортогональну зміну базису у `N`-вимірному просторі дискретних сигналів. Кожен вектор дискретного сигналу `x[n]` виражається як унікальна суперпозиція `N` дискретних гармонійних ортів, а швидкодія обчислень забезпечується алгоритмом швидкого перетворення Фур meра Кулі — Тьюкі.

| Галузь математики | Формулювання суперпозиції | Фізичний зміст |
| :--- | :--- | :--- |
| **Лінійна алгебра** | `L(c₁x₁ + c₂x₂) = c₁L(x₁) + c₂L(x₂)` | Адитивність векторів сил, полів та струмів. |
| **Гільбертові простори** | `⟨f | g⟩ = ∫ f*(x)g(x)dx, ||f||² = ∑ |cₖ|²` | Збереження повної енергії та ортогональність станів. |
| **Диференціальні рівняння**| `u(t) = u_hom(t) + u_part(t)` | Розділення власних і вимушених коливань. |
| **Метод функцій Гріна** | `u(t) = ∫ G(t, t') f(t') dt'` | Згортка вхідного сигналу з імпульсним відгуком. |
| **Спектральний аналіз** | `L( ∑ cₖ ϕₖ ) = ∑ cₖ λₖ ϕₖ` | Розклад сигналу у ряд Фур'є / по модах. |
| **Простір станів** | `x(t) = eᴬᵗ x₀ + ∫ eᴬ⁽ᵗ⁻ᵀ⁾ B u(τ) dτ` | Повний стан як сума вільного й вимушеного руху. |
