# 🧮 Математика тиску насичення та психрометрії

Ця вставка містить строгі математичні виведення та числові наближення термодинамічних величин вологого повітря. Вона розгортає виведення рівняння Клаузіуса-Клапейрона для тисків фазової рівноваги, порівнює напівемпіричні формули Августа-Рош-Магнуса, Тетенса та Ардена Бака, розкриває диференціальний енергетичний баланс психрометра й виводить аналітичні рівняння розрахунку точки роси.

## 1. Строге термодинамічне виведення рівняння Клаузіуса-Клапейрона

Розглянемо двофазну гетерогенну систему, яка складається з рідкої води та її насиченої пари у стані фазової рівноваги за абсолютної температури `T` та рівноважного тиску `e_s`.

Умові термодинамічної рівноваги фаз відповідає рівність їхніх молярних ізобарно-ізотермічних потенціалів (хімічних потенціалів `μ`):

```
μ_l(T, e_s) = μ_g(T, e_s)
```

При нескінченно малому квазістатичному зсуві стану рівноваги уздовж фазової кривої на `dT` та `de_s` приріст хімічного потенціалу рідкої фази (`l`) мусить дорівнювати приросту хімічного потенціалу газоподібної фази (`g`):

```
dμ_l = dμ_g
```

З фундаментального співвідношення термодинаміки виразимо диференціал хімічного потенціалу через молярний об'єм `v` та молярну ентропію `s`:

```
dμ = -s · dT + v · de_s
```

Підставляючи вираз для рідкої та газоподібної фаз у умову рівноваги приростів:

```
-s_l · dT + v_l · de_s = -s_g · dT + v_g · de_s
```

Перегруповуємо члени рівняння, збираючи диференціали тиску з одного боку, а диференціали температури — з іншого:

```
(v_g - v_l) · de_s = (s_g - s_l) · dT
```

Зміна молярної ентропії `Δs = s_g - s_l` під час ізотермічного фазового переходу першого роду (випаровування) виражається через молярну або питому приховану теплоту випаровування `L_v`:

```
s_g - s_l = L_v / T
```

Підставляючи це співвідношення у диференціальне рівняння, отримуємо точне **рівняння Клаузіуса-Клапейрона**:

```
de_s / dT = L_v / (T · (v_g - v_l))
```

### Фізичні спрощення для газової фази
Оскільки за кімнатних температур питомий об'єм водяної пари `v_g` на три порядки перевищує питомий об'єм рідкої води `v_l` (`v_g ≈ 1000 · v_l`), величиною `v_l` у знаменнику можна знехтувати з похибкою менше 0.1%:

```
v_g - v_l ≈ v_g
```

Далі, розглядаючи водяну пару як ідеальний газ за помірних тисків, виразимо її питомий об'єм через рівняння стану ідеального газу:

```
v_g = R_v · T / e_s
```

де `R_v = R / M_w = 8.31446 / 0.018015 = 461.5` Дж/(кг·К) — питома газова стала водяної пари.

Підставляємо значення `v_g` у спрощене рівняння Клаузіуса-Клапейрона:

```
de_s / dT = L_v / (T · (R_v · T / e_s))
de_s / dT = (L_v · e_s) / (R_v · T²)
```

Розділимо змінні й підготуємо рівняння до інтегрування:

```
(1 / e_s) · de_s = (L_v / R_v) · T⁻² · dT
```

Інтегруємо ліву частину від опорного тиску `e_0 = e_s(T_0) = 6.112` гПа при `T_0 = 273.15` К (0 °C) до поточного тиску `e_s`, вважаючи питому теплоту випаровування `L_v` приблизно сталою:

```
∫ (1 / e_s) de_s = ∫ (L_v / R_v) · T⁻² dT
ln(e_s / e_0) = (L_v / R_v) · (1 / T_0 - 1 / T)
e_s(T) = e_0 · exp( (L_v / R_v) · (1 / T_0 - 1 / T) )
```

Оскільки відношення `L_v / R_v = 2.44 × 10⁶ / 461.5 ≈ 5418` К, ця математична форма демонструє стрімке експоненційне зростання тиску насиченої пари з підвищенням температури.

## 2. Емпіричні та напівемпіричні наближення

Оскільки питома теплота випаровування `L_v(T)` насправді слабко зменшується з підвищенням температури (`L_v(T) ≈ 2.501 × 10⁶ - 2370 · T` Дж/кг), теоретична інтегральна формула потребує температурної корекції для забезпечення високої точності у широкому діапазоні.

### 1. Формула Августа-Рош-Магнуса
Використовується як основний інженерний стандарт для розрахунків у діапазоні від `-40 °C` до `+50 °C`:

```
e_s(T) = a · exp( (b · T) / (c + T) )
```

де температура `T` задана у градусах Celsius (°C), а коефіцієнти становлять:
- Для водної поверхні (`T ≥ 0` °C): `a = 6.112` гПа, `b = 17.67`, `c = 243.5` °C.
- Для поверхні льоду (`T < 0` °C): `a = 6.112` гПа, `b_ice = 22.587`, `c_ice = 273.86` °C.

### 2. Рівняння Тетенса (1930)
Використовує аналогичний математичний вигляд з десятковим логарифмом:

```
e_s(T) = 6.1078 · 10^( (7.5 · T) / (237.3 + T) )
```

### 3. Високоточне рівняння Ардена Бака (Arden Buck, 1981)
Забезпечує найвищу точність у метеорології (абсолютна похибка < 0.05% у діапазоні від -40 °C до +50 °C):

```
e_s(T) = 6.1121 · exp( (18.729 - T / 227.3) · T / (257.87 + T) )
```

Для врахування підвищення тиску насичення у присутності сухого повітря під атмосферним тиском `p` (так званий фактор підвищення *enhancement factor* `f_p`), фактичний тиск насичення вологого повітря становить `e_s,air(T, p) = f_p · e_s(T)`, де `f_p ≈ 1.0016 + 3.15 × 10⁻⁶ · p - 0.074 / p`.

### Числовий приклад розрахунку тиску насичення
Обчислимо тиск насиченої пари `e_s` при `T = 25.0` °C за формулою Магнуса:

```
(b · T) / (c + T)
= (17.67 · 25.0) / (243.5 + 25.0)      [підстановка параметрів]
= 441.75 / 268.5
= 1.64525                             [показник степеня]

e_s(25°C)
= 6.112 · exp(1.64525)
= 6.112 · 5.18228
= 31.67 гПа                           [підсумковий тиск насичення]
```

## 3. Диференціальний енергетичний баланс психрометра

Психрометричний метод вимірювання базується на стаціонарному тепловому балансі резервуара вологого термометра, оточеного зволоженим бавовняним ґнотом, який обдувається потоком повітря.

### 1. Конвективний приплив тепла від повітря
Повітря з температурою `T_dry` віддає тепло охолодженому вологому ґноту з температурою `T_wet` за рахунок конвективного теплообміну у межевому шарі:

```
q_conv = h_c · (T_dry - T_wet)
```

де `h_c` — коефіцієнт конвективної тепловіддачі.

### 2. Відтік тепла за рахунок випаровування води
Масовий потік випаровування вологи `j_evap` з поверхні ґнота визначається різницею густини пари біля поверхні ґнота `ρ_s(T_wet)` та у навколишньому набігаючому потоці повітря `ρ_v`:

```
j_evap = h_m · (ρ_s(T_wet) - ρ_v)
```

де `h_m` — коефіцієнт масовідачі.

Переходячи від густини пари до парціального тиску через рівняння стану ідеального газу `e = ρ_v · R_v · T`:

```
j_evap = (h_m / (R_v · T)) · (e_s(T_wet) - e)
```

Потік випаровування відбирає приховану теплоту `q_evap = L_v · j_evap`. Прирівнюючи конвективний приплив тепла до його відтоку за рахунок випаровування (`q_conv = q_evap`):

```
h_c · (T_dry - T_wet) = L_v · (h_m / (R_v · T)) · (e_s(T_wet) - e)
```

### Співвідношення Льюїса та психрометрична константа
Зі співвідношення Льюїса (*Lewis relation*) для турбулентного переносу у вологому повітрі чисельно випливає, що число Льюїса `Le = h_c / (h_m · ρ_air · c_p) ≈ 1`, де `c_p` — питома теплоємність вологого повітря при постійному тиску, а `ρ_air` — густина повітря.

Підставляючи це співвідношення, отримуємо класичне психрометричне рівняння Августа-Камінського:

```
e = e_s(T_wet) - A · p · (T_dry - T_wet)
```

де `A = c_p / (0.622 · L_v) ≈ 0.000662` К⁻¹ — психрометрична константа для аспіраційного психрометра Ассмана (при швидкості обдування повітрям ≥ 2.5 м/с), а `p` — загальний атмосферний тиск.

## 4. Аналітичне обернення та розрахунок точки роси T_d

Температура точки роси `T_d` визначається як умова, за якої тиск насичення `e_s(T_d)` дорівнює фактичному парціальному тиску водяної пари `e` у даній повітряній масі:

```
e_s(T_d) = e
```

Використовуючи формулу Магнуса, запишемо це співвідношення:

```
a · exp( (b · T_d) / (c + T_d) ) = e
exp( (b · T_d) / (c + T_d) ) = e / a
(b · T_d) / (c + T_d) = ln(e / a)
```

Позначимо безрозмірний логарифмічний фактор як `γ(T, RH)`:

```
γ(T, RH) = ln(e / a) = ln( (RH / 100) · (e_s(T) / a) )
γ(T, RH) = ln(RH / 100) + (b · T) / (c + T)
```

Розв'яжемо дробово-лінійне рівняння відносно `T_d`:

```
b · T_d = γ · (c + T_d)
b · T_d = γ · c + γ · T_d
T_d · (b - γ) = c · γ
T_d = (c · γ(T, RH)) / (b - γ(T, RH))
```

### Покроковий числовий приклад розрахунку точки роси
Нехай температура повітря `T = 25.0` °C, а відносна вологість `RH = 50.0%`.
Раніше ми знайшли `e_s(25°C) = 31.67` гПа.

1. Фактичний парціальний тиск водяної пари `e`:
```
e = (RH / 100) · e_s(25°C)
= 0.50 · 31.67
= 15.835 гПа                          [фактичний парціальний тиск]
```

2. Обчислимо параметр `γ(T, RH)`:
```
γ = ln(RH / 100) + (b · T) / (c + T)
= ln(0.50) + (17.67 · 25.0) / (243.5 + 25.0)
= -0.69315 + 1.64525
= 0.95210                             [значення параметру gamma]
```

3. Обчислимо точку роси `T_d`:
```
T_d = (c · γ) / (b - γ)
= (243.5 · 0.95210) / (17.67 - 0.95210)
= 231.836 / 16.7179
= 13.87 °C                            [температура точки роси]
```

Підсумковий висновок: якщо повітря з температурою 25.0 °C та відносною вологістю 50% охолодити до 13.9 °C без зміни масового вмісту вологи, воно досягне стану 100% насичення, й почнеться утворення крапель роси.
