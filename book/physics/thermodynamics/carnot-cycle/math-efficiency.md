# 🧮 Математичний вивід ККД циклу Карно та нерівності Клаузіуса

У цій математичній вставці подано строге алгебраїчне та інтегральне виведення формули граничного ККД циклу Карно для ідеального газу, доведення його незалежності від робочого тіла через ентропійний баланс та математичне обґрунтування нерівності Клаузіуса.

## 1. Алгебраїчний вивід ККД для ідеального газу

Розглянемо коликвий процес із `n` молями ідеального газу, який складається з чотирьох послідовних зворотних тактів на `P-V` площині:

1. **Такт 1 → 2 (Ізотермічне розширення при T_H):**
   Газ знаходиться в контакті з нагрівачем температури `T_H`. Його об'єм збільшується від `V_1` до `V_2`. Оскільки внутрішня енергія ідеального газу залежить лише від температури (`dU = 0`), з Першого закону термодинаміки підведена теплота `Q_H` повністю перетворюється на роботу розширення:

```
Q_H = ∫ [від V_1 до V_2] P dV
    = ∫ [від V_1 до V_2] (n · R · T_H / V) dV   [рівняння стану: P = nRT/V]
    = n · R · T_H · ln(V_2 / V_1)              [інтегрування первісної 1/V]
```

2. **Такт 2 → 3 (Адіабатичне розширення від T_H до T_C):**
   Газ теплоізольовано (`dQ = 0`), він розширюється від `V_2` до `V_3`, охолоджуючись від `T_H` до `T_C`. Рівняння адіабати Пуассона у змінних `(T, V)` має вигляд:

```
T_H · V_2^(γ - 1) = T_C · V_3^(γ - 1)          [рівняння адіабати: T·V^(γ-1) = const]
```

3. **Такт 3 → 4 (Ізотермічне стискання при T_C):**
   Газ перебуває в контакті з холодильником температури `T_C`. Зовнішні сили стискають газ від `V_3` до `V_4`. Газ віддає холодильнику теплоту `|Q_C|`:

```
|Q_C| = - ∫ [від V_3 до V_4] P dV
      = - n · R · T_C · ln(V_4 / V_3)          [інтегрування первісної 1/V]
      = n · R · T_C · ln(V_3 / V_4)            [властивість логарифма: -ln(a/b) = ln(b/a)]
```

4. **Такт 4 → 1 (Адіабатичне стискання від T_C до T_H):**
   Газ теплоізольовано (`dQ = 0`), він стискається від `V_4` до `V_1`, нагріваючись від `T_C` назад до `T_H`. Рівняння адіабати:

```
T_C · V_4^(γ - 1) = T_H · V_1^(γ - 1)          [рівняння адіабати: T·V^(γ-1) = const]
```

### Зв'язок між співвідношеннями об'ємів

Поділимо рівняння адіабати (2 → 3) на рівняння адіабати (4 → 1):

```
(T_H · V_2^(γ - 1)) / (T_H · V_1^(γ - 1)) = (T_C · V_3^(γ - 1)) / (T_C · V_4^(γ - 1))  [почленне ділення двох рівнянь]
(V_2 / V_1)^(γ - 1) = (V_3 / V_4)^(γ - 1)                                                [скорочено температурні коефіцієнти T_H та T_C]
V_2 / V_1 = V_3 / V_4                                                                   [піднесення до степеня 1/(γ-1)]
```

Співвідношення ізотермічного розширення та стискання виявилися абсолютно однаковими!

### Розрахунок термічного ККД

Підставимо отриманий геометричний результат у вирази для теплот `Q_H` та `|Q_C|`:

```
|Q_C| / Q_H = (n · R · T_C · ln(V_3 / V_4)) / (n · R · T_H · ln(V_2 / V_1))  [підставлено вирази теплот |Q_C| та Q_H]
            = T_C / T_H                                                      [скорочено n, R та однакові логарифми ln(V_3/V_4) = ln(V_2/V_1)]
```

За визначенням, термічний ККД `η` дорівнює відношенню корисної роботи `W = Q_H - |Q_C|` до витраченого тепла `Q_H`:

```
η = W / Q_H
  = (Q_H - |Q_C|) / Q_H                        [заміна роботи різницею теплот W = Q_H - |Q_C|]
  = 1 - |Q_C| / Q_H                            [почленне ділення чисельника на Q_H]
  = 1 - T_C / T_H                              [підставлено відношення |Q_C|/Q_H = T_C/T_H]
```

Ця формула доводить, що ККД циклу Карно залежить **виключно від абсолютних температур** нагрівача `T_H` та холодильника `T_C`.

## 2. Загальний вивід через ентропію (незалежність від типу робочого тіла)

Ентропія `S` задається диференціальним співвідношенням `dS = dQ_rev / T` для будь-якого зворотного термодинамічного процесу. Оскільки ентропія є однозначною функцією стану системи, її контурний інтеграл по замкненому коловому процесу тотожно дорівнює нулю:

```
∮ dS = 0
```

Розрахуємо зміну ентропії робочого тіла довільної фізичної природи (газу, рідини, намагніченого кристала чи фотонного газу) у чотирьох тактах циклу Карно:

1. **Ізотерма 1 → 2 (T_H = const):**
   Зміна ентропії при отриманні тепла від нагрівача:
   `ΔS_12 = S_2 - S_1 = ∫ [1 до 2] dQ / T_H = Q_H / T_H`
   Звідси підведена теплота виражається як:
   `Q_H = T_H · (S_2 - S_1)`

2. **Адіабата 2 → 3 (dQ = 0):**
   Оскільки процес оборотний і теплообмін відсутній, зміна ентропії дорівнює нулю:
   `ΔS_23 = 0`  =>  `S_3 = S_2`

3. **Ізотерма 3 → 4 (T_C = const):**
   Зміна ентропії при віддачі тепла холодильнику:
   `ΔS_34 = S_4 - S_3 = ∫ [3 до 4] dQ / T_C = - |Q_C| / T_C`
   Звідси скинута теплота виражається через ентропію як:
   `|Q_C| = T_C · (S_3 - S_4) = T_C · (S_2 - S_1)`

4. **Адіабата 4 → 1 (dQ = 0):**
   `ΔS_41 = 0`  =>  `S_4 = S_1`

Підставимо отримані універсальні вирази для `Q_H` та `|Q_C|` у визначення ККД:

```
η = (Q_H - |Q_C|) / Q_H
  = (T_H · (S_2 - S_1) - T_C · (S_2 - S_1)) / (T_H · (S_2 - S_1))   [підставлено вирази Q_H та |Q_C| через ентропію]
  = (T_H - T_C) · (S_2 - S_1) / (T_H · (S_2 - S_1))                 [винесено спільний множник (S_2 - S_1)]
  = (T_H - T_C) / T_H                                               [скорочено на різницю ентропій (S_2 - S_1)]
  = 1 - T_C / T_H                                                   [почленне ділення чисельника на T_H]
```

Цей вивід є принципово важливим: він показує, що формула `η = 1 - T_C / T_H` не спирається на закони ідеального газу і є **універсальним фундаментальним законом фізики**, справедливим для будь-якого фізичного носія енергії.

## 3. Узагальнення через співвідношення Максвелла для довільних PVT-систем

Щоб математично переконатися у справедливості рівності `(V_2 / V_1) = (V_3 / V_4)` для будь-якої реальної речовини із довільним рівнянням стану `P = P(T, V)`, використаємо перше співвідношення Максвелла, яке випливає з рівності других мішаних похідних від вільної енергії Гельмгольца `F`:

```
(∂S / ∂V)_T = (∂P / ∂T)_V
```

Інтегруючи цей вираз вздовж ізотерми від `V_a` до `V_b`, отримуємо зміну ентропії:

```
ΔS = ∫ [від V_a до V_b] (∂P / ∂T)_V dV
```

Для адіабатичних процесів (2 → 3) та (4 → 1) ентопія системи залишається сталою: `S_2 = S_3` та `S_1 = S_4`. Отже, зміна ентропії на верхній ізотермі `(S_2 - S_1)` строго дорівнює зміні ентропії на нижній ізотермі `(S_3 - S_4)`. 

Звідси випливає, що незалежно від складності залежності тиску від температури й об'єму (будь то рівняння Ван-дер-Ваальса для реального газу або вирази для кристалічної ґратки), інтеграли зміни ентропії на обох ізотермах тотожно збігаються. Це гарантує строге виконання формули Карно для довільного робочого тіла.

## 4. Доведення теореми Карно методом від супротивного

**Перша теорема Карно:** Жодна теплова машина, що працює між двома даними термостатами з температурами `T_H` та `T_C`, не може мати ККД більший, ніж оборотна машина Карно.

### Доведення:
Припустимо супротивне: існує гіпотетичний незворотний двигун `X` із ККД `η_X > η_Carnot`.

Нехай двигун `X` забирає від нагрівача `T_H` теплоту `Q_H_X`, виконує корисну роботу `W' = η_X · Q_H_X` і скидає в холодильник `Q_C_X = (1 - η_X) · Q_H_X`.

З'єднаємо двигун `X` з оборотною машиною Карно `R`, яка працює у зворотному режимі (як тепловий насос). Машину `R` відкалібруємо так, щоб вона споживала точно таку саму роботу `W'`, яку виробляє двигун `X`.

Оскільки `η_X > η_R`, для вироблення роботи `W'` двигуну `X` потрібно менше тепла від нагрівача, ніж поверне в нагрівач зворотна машина `R`:

```
W' = η_X · Q_H_X = η_R · Q_H_R
оскільки η_X > η_R  =>  Q_H_R > Q_H_X
```

Сумарний ефект комбінованої установки `(X + R)` за один цикл:
- Зовнішня робота не подається і не виводиться: `W_net = W' - W' = 0`.
- Нагрівач отримує чистий приплив тепла: `ΔQ_H = Q_H_R - Q_H_X > 0`.
- Холодильник віддає чистий потік тепла: `ΔQ_C = Q_C_R - Q_C_X = ΔQ_H > 0`.

В результаті отримано пристрій, єдиним наслідком роботи якого є самочинне передавання теплоти `ΔQ_H` від холодного тіла `T_C` до гарячого тіла `T_H` без виконання зовнішньої роботи. Це прямо суперечить Другому закону термодинаміки у формулюванні Клаузіуса.

Отже, початкове припущення `η_X > η_Carnot` виявилося хибним, що й доводить Першу теорему Карно.

## 5. Вивід нерівності Клаузіуса для довільних циклічних процесів

Для оборотної машини Карно сума приведених теплот за один цикл строго дорівнює нулю:

```
Q_H / T_H + Q_C / T_C = Q_H / T_H - |Q_C| / T_C = 0
```

Для незворотного циклу, оскільки `η_unrev < η_rev`, маємо:

```
1 - |Q_C_unrev| / Q_H < 1 - T_C / T_H                          [теорема Карно для незворотного циклу]
|Q_C_unrev| / Q_H > T_C / T_H                                  [перенесення одиниць]
|Q_C_unrev| / T_C > Q_H / T_H                                  [перегрупування температур і теплот]
Q_H / T_H + Q_C_unrev / T_C < 0                                [враховано, що Q_C_unrev = -|Q_C_unrev|]
```

Узагальнимо цей результат на довільний складний коловий процес, зображений замкненою кривою будь-якої форми на `P-V` чи `T-S` діаграмі.

Розіб’ємо замкнений контур процесу сіткою з нескінченно великої кількості адіабат та ізотерм. Утворена сітка являє собою сукупність нескінченно малих елементарних циклів Карно. Для кожного `i`-го елементарного циклу виконується співвідношення:

```
δQ_H_i / T_H_i + δQ_C_i / T_C_i ≤ 0
```

Пропідсумувавши всі елементарні цикли та перейшовши до границі при прямуванні розмірів циклів до нуля, сума перетворюється на криволінійний інтеграл по замкненому контуру. Це дає загальну **нерівність Клаузіуса**:

```
∮ (dQ / T) ≤ 0
```

Де знак рівності `∮ (dQ / T) = 0` справджується строго для оборотних процесів (що дозволяє ввести ентропію як функцію стану `dS = dQ_rev / T`), а знак строгої нерівності `∮ (dQ / T) < 0` стосується будь-яких реальних незворотних термодинамічних циклів.
