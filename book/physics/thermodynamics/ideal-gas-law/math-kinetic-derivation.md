# 🧮 Молекулярно-кінетичне виведення рівняння стану ідеального газу

У цій математичній вставці подано суворе статистичне виведення макроскопічного рівняння стану ідеального газу Клапейрона — Менделєєва з мікроскопічної моделі хаотичного руху частинок. Покроковий розрахунок показує, як усереднення мікроскопічних імпульсів пружних зіткнень частинок зі стінкою посудини дає класичний тиск та абсолютну температуру, а також виводить розподіл Максвелла за швидкостями, барометричну формулу та геометрію критичної точки реального газу Ван-дер-Ваальса.

## 1. Постулати мікроскопічної моделі

Для побудови математичної моделі розглядається система із `N` однакових частинок масою `m` кожна, що знаходяться у прямокутному паралелепіпеді з довжинами ребер `L_x`, `L_y`, `L_z` та загальним об'ємом `V = L_x · L_y · L_z`.

Модель базується на чотирьох фундаментальних спрощеннях ідеального газу:
1. Власний геометричний об'єм молекул вважається знехтовно малим порівняно з повним об'ємом посудини `V`. Це означає, що частинки розглядаються як матеріальні точки, а весь об'єм `V` є повністю доступним для їхнього вільного хаотичного переміщення.
2. Молекули взаємодіють між собою та зі стінками посудини виключно шляхом абсолютних пружних зіткнень. Будь-які сили дальнодіючого міжмолекулярного притягання чи відштовхування на відстані вважаються рівними нулю.
3. Рух кожної частинки між двома послідовними зіткненнями є строго прямолінійним і рівномірним, підпорядковуючись законам класичної механіки Ньютона.
4. Розподіл швидкостей молекул у просторі є абсолютно ізотропним: внаслідок мільярдів хаотичних зіткнень у просторі немає жодного переважного напрямку руху.

## 2. Обчислення переданого імпульсу та сили на стінку

Розглянемо одну частинку `i`, що рухається зі швидкістю `v_i = (v_{x,i}, v_{y,i}, v_{z,i})`. Частинка здійснює пружне зіткнення зі стінкою площею `A = L_y · L_z`, перпендикулярною до осі `x`.

При абсолютно пружному відбитку молекули від гладкої стінки паралельні компоненти швидкості `v_y` та `v_z` залишаються незмінними, а нормальна компонента `v_x` дзеркально змінює свій знак на протилежний. Внаслідок цього вектор швидкості частинки після відбитку змінюється від `v_{x,i}` до `-v_{x,i}`.

Зміна імпульсу частинки при одному зіткненні становить:

```
v_{x,i}' = −v_{x,i}                                        [умова пружного відбитку]
```

```
Δp_{частинки} = m · v_{x,i}' − m · v_{x,i}                 [означення зміни імпульсу]
= −m · v_{x,i} − m · v_{x,i}                              [підстановка v_{x,i}']
= −2 · m · v_{x,i}                                        [підсумовування компонент]
```

За третім законом Ньютона імпульс `Δp_{стінки}`, переданий стінці посудини під час цього пружного удару, дорівнює зміні імпульсу частинки з протилежним знаком:

```
Δp_{стінки} = −Δp_{частинки} = 2 · m · v_{x,i}            [третій закон Ньютона]
```

Щоб обчислити середню силу ударів однієї частинки за тривалий проміжок часу, визначимо частоту її зіткнень із цією конкретною стінкою. Для цього частинка повинна пролетіти вздовж осі `x` до протилежної стінки і повернутися назад, подолавши відстань `2 · L_x`. Чим вища швидкість `v_{x,i}`, тим частіше частинка повертається до стінки.

Час `Δt` між двома послідовними зіткненнями цієї ж частинки з тією самою стінкою дорівнює:

```
Δt = (2 · L_x) / v_{x,i}                                   [час прольоту в посудині]
```

Середня сила `F_i`, з якою одна частинка діє на стінку за тривалий проміжок часу, дорівнює відношенню переданого імпульсу до часу між ударами:

```
F_i = Δp_{стінки} / Δt                                    [другий закон Ньютона у формі Ейлера]
= (2 · m · v_{x,i}) / ((2 · L_x) / v_{x,i})               [підстановка значення Δp та Δt]
= (m · v_{x,i}²) / L_x                                    [скорочення двійки та спрощення]
```

## 3. Усереднення по ансамблю та розрахунок тиску

Загальна сила `F_{total}`, що діє на стінку площею `A = L_y · L_z` від усіх `N` частинок, є сумою сил окремих молекул. Оскільки в макроскопічній системі число частинок `N` сягає мільярдів, суму квадратів швидкостей окремих молекул можна виразити через їхнє статистичне середнє значення `<v_x²>`.

```
F_{total} = ∑_{i=1}^{N} F_i                               [сумування сил усіх частинок]
= ∑_{i=1}^{N} ((m · v_{x,i}²) / L_x)                     [підстановка виразу сили F_i]
= (m / L_x) · ∑_{i=1}^{N} v_{x,i}²                        [винесення сталих за знак суми]
= (m / L_x) · N · <v_x²>                                  [введення середнього квадрата швидкості <v_x²>]
```

Тиск `P` за означенням є відношенням нормальної сили `F_{total}` до площі стінки `A = L_y · L_z`. Поєднуючи геометричні розміри посудини `L_x · L_y · L_z` у повний об'єм `V`, виразимо тиск через об'ємну концентрацію молекул `n = N / V`:

```
P = F_{total} / A                                         [означення тиску]
= ((m · N / L_x) · <v_x²>) / (L_y · L_z)                  [підстановка сили F_{total} та площі A]
= (N · m · <v_x²>) / (L_x · L_y · L_z)                    [об'єднання довжин у повний об'єм]
= (N · m / V) · <v_x²>                                    [підстановка V = L_x · L_y · L_z]
= n · m · <v_x²>                                          [введення концентрації n = N / V]
```

Внаслідок ізотропності хаотичного теплового руху середня кінетична енергія по трьох координатних осях розподілена рівномірно. Квадрат модуля швидкості дорівнює сумі квадратів його проєкцій:

```
<v²> = <v_x²> + <v_y²> + <v_z²>                            [теорема Піфагора для вектора швидкості]
= 3 · <v_x²>                                              [умова ізотропності: <v_x²> = <v_y²> = <v_z²>]
⇒ <v_x²> = (1 / 3) · <v²>                                 [вираження x-компоненти через повний квадрат]
```

Підставляючи середній квадрат швидкості у вираз для тиску, отримуємо **основне рівняння молекулярно-кінетичної теорії (МКТ)**:

```
P = (1 / 3) · n · m · <v²>                                [основне рівняння МКТ]
= (2 / 3) · n · ((m · <v²>) / 2)                          [виділення поступальної кінетичної енергії]
= (2 / 3) · n · <E_k>                                     [позначення <E_k> = (m · <v²>) / 2]
```

Це рівняння показує, що макроскопічний тиск газу прямо пропорційний концентрації молекул `n` та їхній середній кінетичній енергії поступального руху `<E_k>`.

## 4. Виведення розподілу Максвелла та характерних швидкостей

У рівноважному стані незалежність ортогональних компонент швидкості `v_x`, `v_y`, `v_z` означає, що спільна щільність ймовірності `f(v_x, v_y, v_z)` розкладається в добуток одновимірних функцій `f(v_x) · f(v_y) · f(v_z)`. Оскільки у просторі немає виділеного напрямку, ця функція залежить лише від модуля швидкості `v² = v_x² + v_y² + v_z²`:

```
f(v_x) · f(v_y) · f(v_z) = g(v_x² + v_y² + v_z²)
```

Єдиним нетривіальним розв'язком цього функціонального рівняння є експоненціальна функція Гаусса:

```
f(v_x) = √(m / (2 · π · k_B · T)) · exp(−(m · v_x²) / (2 · k_B · T))
```

Переходячи до сферичної системи координат у просторі швидкостей, де елемент об'єму дорівнює `4 · π · v² · dv`, отримуємо розподіл Максвелла для модуля швидкості:

```
f(v) = 4 · π · (m / (2 · π · k_B · T))^(3/2) · v² · exp(−(m · v²) / (2 · k_B · T))
```

Для знаходження найімовірнішої швидкості `v_p` береться похідна від `f(v)` по `v` і прирівнюється до нуля:

```
df / dv = 0                                                [пошук екстремуму функції розподілу]
⇒ 2 · v − v · ((m · v²) / (k_B · T)) = 0                   [диференціювання v² · exp(-b·v²)]
⇒ v_p = √(2 · k_B · T / m)                                 [знаходження найімовірнішої швидкості]
```

Середня арифметична швидкість `<v>` розраховується як інтеграл першого моменту:

```
<v> = ∫₀^∞ v · f(v) dv                                     [означення математичного сподівання]
= 4 · π · (m / (2 · π · k_B · T))^(3/2) · ∫₀^∞ v³ · exp(−m·v² / (2·k_B·T)) dv
= √(8 · k_B · T / (π · m))                                 [обчислення гауссового інтегралу]
```

Середній квадрат швидкості `<v²>` розраховується через другий момент функції розподілу:

```
<v²> = ∫₀^∞ v² · f(v) dv                                   [обчислення другого моменту швидкості]
= (3 · k_B · T) / m                                        [результат інтегрування МКТ]
⇒ v_rms = √<v²> = √(3 · k_B · T / m)                       [середня квадратна швидкість]
```

## 5. Перехід до температури та універсального рівняння стану

У статистичній фізиці середня кінетична енергія поступального руху однієї молекули прямо пропорційна абсолютній температурі `T` (теорема про рівнорозподіл енергії по ступенях вільності):

```
<E_k> = (m · <v²>) / 2 = (3 / 2) · k_B · T                 [теорема про рівнорозподіл енергії]
```

де `k_B = 1.380649 · 10⁻²³ Дж / К` — стала Больцмана.

Підставляємо вираз для `<E_k>` в основне рівняння МКТ:

```
P = (2 / 3) · n · ((3 / 2) · k_B · T)                      [підстановка середної енергії в рівняння МКТ]
= n · k_B · T                                             [скорочення дробу 2/3 та 3/2]
```

Оскільки концентрація `n = N / V`, множимо обидві частини на об'єм `V`:

```
P · V = N · k_B · T                                        [мікроскопічна форма рівняння стану]
```

Виразимо повне число молекул `N` через кількість речовини `ν` (в молях) та число Авогадро `N_A`:

```
N = ν · N_A = (m_{газу} / M) · N_A                         [зв'язок числа частинок із молярною масою]
```

Підставляючи `N` у вираз для `P · V`:

```
P · V = (m_{газу} / M) · (N_A · k_B) · T                   [підстановка числового ансамблю N]
```

Добуток двох фундаментальних сталих `N_A · k_B` утворює **універсальну газову сталу R**:

```
R = N_A · k_B                                              [означення універсальної газової сталої R]
= (6.02214076 · 10²³ моль⁻¹) · (1.380649 · 10⁻²³ Дж / К)   [підстановка числових значень N_A та k_B]
= 8.314462618 Дж / (моль · К)                              [результат обчислення R]
```

Отже, отримуємо класичне **рівняння стану Клапейрона — Менделєєва**:

```
P · V = (m_{газу} / M) · R · T                             [остаточна форма Клапейрона — Менделєєва]
```

## 6. Барометрична формула з розподілу Больцмана

У потенціальному полі тяжіння Землі з потенціальною енергією `U(z) = m · g · z` повна енергія частинки дорівнює `E = m·v²/2 + m·g·z`. Канонічний розподіл Ґіббса задає ймовірність знаходження частинки в елементі фазового простору:

```
dP(r, v) ∝ exp(−(m · v² / 2 + m · g · z) / (k_B · T)) d3r d3v
```

Інтегруючи по всіх швидкостях `v`, отримуємо просторову концентрацію частинок `n(z)` на висоті `z`:

```
n(z) = n₀ · exp(−(m · g · z) / (k_B · T))                  [розподіл Больцмана по висоті]
```

Оскільки тиск ідеального газу прямо пропорційний концентрації `P = n · k_B · T`, отримуємо барометричну формулу для ізотермічної атмосфери:

```
P(z) = P₀ · exp(−(m · g · z) / (k_B · T))                 [барометрична формула через масу молекули]
= P₀ · exp(−(M · g · z) / (R · T))                        [барометрична формула через молярну масу]
```

## 7. Критична точка рівняння Ван-дер-Ваальса

Для реальних газів рівняння Ван-дер-Ваальса на молярний об'єм `V_m` має вигляд:

```
P = (R · T) / (V_m − b) − a / V_m²                        [рівняння Ван-дер-Ваальса]
```

У критичній точці `(P_c, V_c, T_c)` ізотерма має точку згину з горизонтальною дотичною, що задається умовами першої та другої похідних:

```
(∂P / ∂V_m)_T = 0 ⇒ −(R · T_c) / (V_c − b)² + (2 · a) / V_c³ = 0     [перша похідна]
```

```
(∂²P / ∂V_m²)_T = 0 ⇒ (2 · R · T_c) / (V_c − b)³ − (6 · a) / V_c⁴ = 0  [друга похідна]
```

Поділивши друге рівняння на перше, знаходимо критичний молярний об'єм `V_c`:

```
2 / (V_c − b) = 3 / V_c ⇒ V_c = 3 · b                      [критичний молярний об'єм]
```

Підставляючи `V_c = 3·b` у першу похідну, знаходимо критичну температуру `T_c`:

```
T_c = (8 · a) / (27 · R · b)                              [критична температура]
```

Підставляючи `V_c` та `T_c` у вихідне рівняння стану, отримуємо критичний тиск `P_c`:

```
P_c = a / (27 · b²)                                       [критичний тиск]
```

Критичний коефіцієнт стискуваності реального газу Ван-дер-Ваальса є універсальним числом:

```
Z_c = (P_c · V_c) / (R · T_c)
= (a / (27 · b²) · 3 · b) / (R · (8 · a) / (27 · R · b))
= 3 / 8 = 0.375                                           [універсальний критичний коефіцієнт Z_c]
```

Цей розрахунок доводить, що статистична механіка не лише обґрунтовує закон ідеального газу, але й точно визначає межі його розпаду та фазового переходу реальної речовини.
