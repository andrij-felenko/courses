# 📋 Термодинамічні параметри циклів та ентропійні баланси

Цей довідковий інтерфейсний документ містить структурований зведення математичних співвідношень, формул ККД, змін ентропії та виразів для холодильних коефіцієнтів ідеальних термодинамічних циклів.

---

### 1. Зведена таблиця основних термодинамічних циклів

Нижче наведено параметри ідеальних прямих та зворотних циклів, де `T_1` — температура нагрівача, `T_2` — температура охолоджувача, `r = V_max / V_min` — ступінь стиснення, `γ = C_p / C_v` — показник адіабати.

| Назва циклу | Процеси в циклі | Формула ККД (η) або COP (ε) | Зміна ентропії за один процес |
| :--- | :--- | :--- | :--- |
| **Цикл Карно** | 2 Ізотерми, 2 Адіабати | `η = 1 - T_2 / T_1` | `ΔS_12 = R · ln(V_2 / V_1)` (ізотерма)<br>`ΔS_23 = 0` (адіабата) |
| **Холодильний Карно** | 2 Ізотерми, 2 Адіабати (зворотний) | `ε_холод = T_2 / (T_1 - T_2)`<br>`ε_насос = T_1 / (T_1 - T_2)` | `ΔS_абсорбція = Q_2 / T_2`<br>`ΔS_скид = -Q_1 / T_1` |
| **Цикл Отто** (бензиновий двигун) | 2 Ізохори, 2 Адіабати | `η = 1 - 1 / (r^(γ - 1))` | `ΔS_ізохора = C_v · ln(T_high / T_low)` |
| **Цикл Дизеля** (дизельний двигун) | 1 Ізобара, 1 Ізохора, 2 Адіабати | `η = 1 - (1 / r^(γ - 1)) · [(ρ^γ - 1) / (γ · (ρ - 1))]` | `ΔS_ізобара = C_p · ln(T_high / T_low)` |
| **Цикл Брайтона** (газова турбіна) | 2 Ізобари, 2 Адіабати | `η = 1 - 1 / (π^((γ - 1) / γ))` | `ΔS_ізобара = C_p · ln(T_2 / T_1)` |
| **Цикл Стірлінга** | 2 Ізотерми, 2 Ізохори | `η = 1 - T_2 / T_1` (із регенератором) | `ΔS_ізотерма = R · ln(V_2 / V_1)` |
| **Цикл Ренкіна** (парова турбіна) | 2 Ізобари, 2 Адіабати (фазовий перехід) | `η = (h_1 - h_2 - (h_4 - h_3)) / (h_1 - h_4)` | `ΔS_випаровування = r_фазове / T_насичення` |

*Примітка:* `ρ = V_3 / V_2` — ступінь ізобарного розширення в циклі Дизеля; `π = P_max / P_min` — ступінь підвищення тиску в циклі Брайтона; `h_i` — питома ентальпія робочого тіла в точках циклу Ренкіна.

### 2. Докладний аналіз термодинамічних режимів теплових машин

#### 1. Прямий цикл Карно (Ідеальний тепловий двигун)
Прямий цикл Карно слугує теоретичним еталоном для будь-якого теплового двигуна. Робоче тіло послідовно проходить два ізотермічних та два адіабатичних процеси. Під час ізотермічного розширення при високій температурі `T_1` система поглинає теплоту `Q_1`, а під час ізотермічного стиснення при низькій температурі `T_2` віддає теплоту `Q_2`. 
- **Корисна робота**: `W = Q_1 - Q_2 = (T_1 - T_2) · ΔS`.
- **Термічний ККД**: `η_Карно = (T_1 - T_2) / T_1 = 1 - T_2 / T_1`.
- **Особливості**: Максимально можливий ККД серед усіх машин у заданому діапазоні температур.

#### 2. Зворотний цикл Карно (Холодильна машина та тепловий насос)
Зворотний цикл Карно виконується у протилежному напрямку за рахунок витрати зовнішньої механічної роботи `W_in`. Робоче тіло забирає теплоту `Q_2` від холодного джерела `T_2` і передає теплоту `Q_1` гарячому джерелу `T_1`.
- **Холодильний коефіцієнт (COP refrigeration)**: Показує кількість відкачаного тепла з охолоджуваної камери на одиницю витраченої роботи:
  ```
  ε_холод = Q_2 / W_in = T_2 / (T_1 - T_2)
  ```
- **Опалювальний коефіцієнт (COP heat pump)**: Показує кількість тепла, переданого опалювальному приміщенню на одиницю витраченої роботи:
  ```
  ε_насос = Q_1 / W_in = T_1 / (T_1 - T_2) = ε_холод + 1
  ```

#### 3. Цикл Отто (Двигуни з іскровим запалюванням)
Моделює роботу класичного бензинового внутрішнього згоряння. Складається з адіабатичного стиснення `(1 → 2)`, ізохорного підведення тепла `(2 → 3)` (миттєве згоряння суміші), адіабатичного розширення `(3 → 4)` та ізохорного відведення тепла `(4 → 1)`.
- **Формула ККД**: `η_Отто = 1 - 1 / (r^(γ - 1))`, де `r = V_1 / V_2` — ступінь стиснення.
- **Фізичне обмеження**: Збільшення `r` підвищує ККД, проте обмежене детонацією палива (самозайманням суміші при стисненні).

#### 4. Цикл Дизеля (Двигуни зі стискальним запалюванням)
У циклі Дизеля паливо вприскується в циліндр наприкінці адіабатичного стиснення і згорає повільніше, що моделюється ізобарним процесом `(2 → 3)`.
- **Формула ККД**: `η_Дизель = 1 - (1 / r^(γ - 1)) · [(ρ^γ - 1) / (γ · (ρ - 1))]`.
- **Особливості**: Дозволяє досягати більших ступенів стиснення `r ≈ 15..22` без детонації, забезпечуючи вищий реальний ККД порівняно з двигунами Отто.

#### 5. Цикл Брайтона (Газотурбінні установки та авіаційні двигуни)
Описує роботу газотурбінних двигунів безперервної дії. Компресор адіабатично стискає повітря `(1 → 2)`, у камері згоряння ізобарно підводиться тепло `(2 → 3)`, у турбіні відбувається адіабатичне розширення `(3 → 4)`, а в атмосферу ізобарно скидається тепло `(4 → 1)`.
- **Формула ККД**: `η_Брайтон = 1 - 1 / (π^((γ - 1) / γ))`, де `π = P_2 / P_1` — ступінь підвищення тиску.

#### 6. Цикл Ренкіна (Паротурбінні електростанції)
Використовує фазовий перехід рідкої води в пара та її подальшу конденсацію. Вода стискається насосом `(1 → 2)`, у котлі ізобарно випаровується та перегрівається `(2 → 3)`, у паровий турбіні адіабатично розширюється `(3 → 4)`, у конденсаторі ізобарно конденсується в рідину `(4 → 1)`.
- **Формула ККД**: `η_Ренкін = (h_3 - h_4 - (h_2 - h_1)) / (h_3 - h_2)`, де `h` — ентальпія стану.
- **Перевага**: Витрата роботи на привід рідинного насоса `(h_2 - h_1)` є мізерно малою порівняно з роботою турбіни `(h_3 - h_4)`.

### 3. Докладний аналіз параметрів процесів та ентропійні співвідношення

#### Елементарні зміни ентропії для базових процесів (1 моль ідеального газу)

1. **Ізохорний процес (`V = const`)**:
   При постійному об'ємі робоче тіло не виконує механічної роботи (`dW = 0`). Все підведене тепло витрачається на зміну внутрішньої енергії:
   ```
   dS = C_v · (dT / T)
   ΔS = C_v · ln(T_2 / T_1)
   ```

2. **Ізобарний процес (`P = const`)**:
   При постійному тиску підведення тепла супроводжується виконанням роботи розширення `P · dV`:
   ```
   dS = C_p · (dT / T)
   ΔS = C_p · ln(T_2 / T_1)
   ```

3. **Ізотермічний процес (`T = const`)**:
   При постійній температурі внутрішня енергія ідеального газу не змінюється (`dU = 0`). Все підведене тепло повністю перетворюється на роботу розширення:
   ```
   dS = (P / T) · dV = R · (dV / V)
   ΔS = R · ln(V_2 / V_1) = -R · ln(P_2 / P_1)
   ```

4. **Адіабатичний оборотний процес (`δQ = 0`)**:
   Оскільки теплообмін із навколишнім середовищем відсутній, а процес оборотний, ентропія залишається суворо постійною (ізоентропійний процес):
   ```
   dS = 0
   ΔS = 0
   ```

5. **Вільне незворотне розширення газу у вакуум (`Q = 0`, `W = 0`, `ΔU = 0`, `T = const`)**:
   Хоча теплота відсутня, процес є суворо необоротним через відсутність протитиску. Зміна ентропії газу дорівнює зміні ентропії еквівалентного оборотного ізотермічного процесу:
   ```
   ΔS_газ = R · ln(V_2 / V_1) > 0
   ΔS_оточення = 0
   ΔS_всесвіт = R · ln(V_2 / V_1) > 0
   ```

### 4. Ентропійний баланс незворотного теплообміну

При з'єднанні двох тіл із масами `m_1`, `m_2`, питомими теплоємностями `c_1`, `c_2` та початковими температурами `T_1 > T_2` в адіабатично ізольованій системі відбувається незворотний теплообмін до досягнення кінцевої рівноважної температури `T_фінальна`:

```
T_фінальна = (m_1 · c_1 · T_1 + m_2 · c_2 · T_2) / (m_1 · c_1 + m_2 · c_2)
```

Зміна ентропії гарячого тіла (віддає тепло):
```
ΔS_1 = m_1 · c_1 · ln(T_фінальна / T_1) < 0
```

Зміна ентропії холодного тіла (отримує тепло):
```
ΔS_2 = m_2 · c_2 · ln(T_фінальна / T_2) > 0
```

Сумарна зміна ентропії всієї ізольованої системи є строго додатною:

```
ΔS_сумарна = ΔS_1 + ΔS_2 = m_1 · c_1 · ln(T_фінальна / T_1) + m_2 · c_2 · ln(T_фінальна / T_2) > 0
```

Це математично підтверджує закон зростання ентропії при самій лише передачі тепла між тілами із скінченною різницею температур.

### 5. Ексергія та знецінення енергії (Закон Гуї-Стодоли)

**Ексергія (`E_x`)** — це максимальна теоретично можлива робота, яку може виконати система при переході з поточного стану в стан повного термодинамічного рівноваги з навколишнім середовищем (з параметрами `T_0`, `P_0`).

Втрата ексергії (знецінення енергії, робота, втрачена внаслідок незворотності `W_втрачена`) прямо пропорційна генерації ентропії в системі:

```
W_втрачена = T_0 · ΔS_ген
```

де `T_0` — температура навколишнього середовища (в Кельвінах), `ΔS_ген` — сумарна ентропія, згенерована внаслідок незворотних процесів (тертя, джоулів нагрев, теплообмін при скінченній різниці температур).

#### Питома ексергія потоку в термодинамічних розрахунках

Для потоку речовини у відкритих системах (наприклад, у парових турбінах чи компресорах) питома ексергія потоку `e_x` (на 1 кг маси) обчислюється як:

```
e_x = (h - h_0) - T_0 · (s - s_0) + (v² / 2) + g · z
```

де `h` — питома ентальпія, `s` — питома ентропія, `v` — швидкість потоку, `z` — висота підйому, `h_0` та `s_0` — ентальпія та ентропія речовини у стані рівноваги з навколишнім середовищем при `T_0`, `P_0`.

### 6. Термодинамічні потенціали та ентропійні співвідношення

Співвідношення між ентропією `S` та фундаментальними термодинамічними потенціалами:

```
dU = T · dS - P · dV            [Внутрішня енергія U(S, V)]
dH = T · dS + V · dP            [Ентальпія H(S, P)]
dF = -S · dT - P · dV           [Вільна енергія Гельмгольца F(T, V)]
dG = -S · dT + V · dP           [Енергія Гіббса G(T, P)]
```

Вирази ентропії через часткові похідні потенціалів:

```
S = - (∂F / ∂T)_V = - (∂G / ∂T)_P
```

#### Співвідношення Максвелла для ентропії

З рівності мішаних похідних термодинамічних потенціалів випливають фундаментальні співвідношення Максвелла, які дозволяють визначати зміну ентропії через експериментально вимірювані макроскопічні параметри (`P`, `V`, `T`):

```
(∂S / ∂V)_T = (∂P / ∂T)_V       [з потенціалу Гельмгольца F]
(∂S / ∂P)_T = - (∂V / ∂T)_P      [з потенціалу Гіббса G]
```

Ці рівності активно використовуються при розрахунку термодинамічних таблиць реальних газів та холодоагентів.
