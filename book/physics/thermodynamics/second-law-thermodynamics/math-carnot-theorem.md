# 🧮 Теорема Карно та доведення нерівності Клаузіуса

Ця математична вставка містить суворе виведення теореми Карно для ККД оборотного циклу, аналіз диференціальних форм Пфаффа, розрахунок термодинамічної стійкості та математичний доказ нерівності Клаузіуса для довільних замкнених термодинамічних процесів.

---

### 1. Теорема Карно про максимальний ККД

**Теорема:** Жодна теплова машина, що працює між двома тепловими резервуарами з температурами `T₁` та `T₂` (`T₁ > T₂`), не може мати ККД більший, ніж оборотна машина Карно, що працює між тими самими резервуарами.

Доведення здійснюється методом від супротивного.

Нехай існує необоротна теплова машина `E_необ` із ККД `η_необ`, який перевищує ККД оборотної машини Карно `η_карно`:

```
η_необ > η_карно
```

Машина `E_необ` бере від гарячого резервуара `T₁` теплоту `Q₁`, виконує роботу `W_необ` і віддає холодному резервуару `T₂` теплоту `Q₂ = Q₁ - W_необ`. Її ККД дорівнює:

```
η_необ = W_необ / Q₁
```

Запустимо оборотну машину Карно `E_карно` у зворотному напрямку (як тепловий насос). Масштабуємо її так, щоб вона виконувала ту саму роботу `W_необ`, споживаючи її від машини `E_необ`. Оскільки машина оборотна, вона забере від холодного резервуара теплоту `Q₂'` і передасть гарячому резервуару теплоту `Q₁'`:

```
η_карно = W_необ / Q₁'
```

Оскільки за припущенням `η_необ > η_карно`, маємо:

```
W_необ / Q₁ > W_необ / Q₁'       [підстановка виразів для ККД у припущену нерівність]
Q₁' > Q₁                         [ділення на W_необ та обернення дробу]
```

Розглянемо об'єднану систему із двох машин:
- Гарячий резервуар отримує від теплового насоса `Q₁'` і віддає двигуну `Q₁`. Чиста зміна тепла гарячого резервуара: `ΔQ₁ = Q₁' - Q₁ > 0`.
- Зовнішня робота не виконується, оскільки вся робота `W_необ` двигуна витрачається на привід насоса.
- Відповідно до першого закону, чиста теплота, забрана від холодного резервуара, дорівнює `ΔQ₂ = Q₁' - Q₁`.

Отже, єдиним результатом роботи об'єднаної системи є самовільна передача тепла `ΔQ₁` від холодного резервуара `T₂` до гарячого `T₁` без витрати зовнішньої роботи. Це прямо суперечить формулюванню Клаузіуса. Отже, припущення хибне:

```
η_необ ≤ η_карно
```

### 2. Співвідношення температур та ККД ідеального газу в циклі Карно

Для одного моля ідеального газу розрахуємо теплоти на чотирьох ділянках циклу Карно:
1. **Ізотермічне розширення (1 → 2) при `T₁`**:
   ```
   Q₁ = R · T₁ · ln(V₂ / V₁)
   ```
2. **Адіабатичне розширення (2 → 3) від `T₁` до `T₂`**:
   ```
   (T₁ / T₂) = (V₃ / V₂)^(γ - 1)
   ```
3. **Ізотермічне стиснення (3 → 4) при `T₂`**:
   ```
   Q₂ = R · T₂ · ln(V₃ / V₄)       [модуль відданого тепла]
   ```
4. **Адіабатичне стиснення (4 → 1) від `T₂` до `T₁`**:
   ```
   (T₁ / T₂) = (V₄ / V₁)^(γ - 1)
   ```

З порівняння адіабатичних співвідношень випливає пропорція об'ємів:

```
(V₃ / V₂)^(γ - 1) = (V₄ / V₁)^(γ - 1)       [рівність температурних відношень обох адіабат]
V₃ / V₄ = V₂ / V₁                           [піднесення до степеня 1/(γ-1) та перегрупування]
```

Підставляючи це у вирази для теплот:

```
Q₁ = R · T₁ · ln(V₂ / V₁)                   [ізотермічне розширення]
Q₂ = R · T₂ · ln(V₂ / V₁)                   [ізотермічне стиснення з однаковим відношенням об'ємів]
Q₁ / Q₂ = T₁ / T₂                           [ділення Q₁ на Q₂ з підстановкою логарифмів]
```

Звідси ККД оборотної машини Карно становить:

```
η_карно = (Q₁ - Q₂) / Q₁                     [означення термічного ККД через теплоти]
        = 1 - Q₂ / Q₁                        [розкриття дужок у чисельнику]
        = 1 - T_2 / T_1                      [підстановка пропорції температур Q₂/Q₁ = T₂/T₁]
```

### 3. Математичне виведення нерівності Клаузіуса

Для оборотного циклу з виразу `Q₁ / T₁ = Q₂ / T₂` (враховуючи термодинамічний знак тепла: `δQ₁ > 0`, `δQ₂ < 0`):

```
Q₁ / T₁ + Q₂ / T₂ = 0
```

Узагальнюючи на довільну кількість `N` резервуарів:

```
∑[i=1..N] (Q[i] / T[i]) ≤ 0
```

Переходячи до границі неперервного замкненого циклу при підведенні елементарних порцій тепла `δQ` від резервуарів із температурою `T`:

```
∮ δQ / T ≤ 0
```

#### Доказ для необоротного циклу

Для довільного необоротного циклу згідно з теоремою Карно:

```
η_необ = 1 - Q₂ / Q₁ < 1 - T₂ / T₁
Q₂ / Q₁ > T₂ / T₁                            [віднімання одиниці та зміна знаку нерівності]
Q₁ / T₁ - Q₂ / T₂ < 0                        [перенесення членів в один бік нерівності]
```

З урахуванням знаків `δQ₁ = +Q₁` та `δQ₂ = -Q₂`:

```
δQ₁ / T₁ + δQ₂ / T₂ < 0
```

Для складного необоротного циклу це дає сувору нерівність Клаузіуса:

```
∮ δQ / T < 0       [для необоротного циклу]
∮ δQ / T = 0       [для оборотного циклу]
```

### 4. Введення ентропії як точного диференціала та інтегрувальний множник

З погляду математичного аналізу, елементарна теплота `δQ` у формі Пфаффа є **неточним диференціалом** (*inexact differential*):

```
δQ = dU + P · dV
```

Значення інтеграла `∫ δQ` залежить від траєкторії процесу на `P-V` площині, а замкнений інтеграл `∮ δQ = W_циклу ≠ 0`.

Однак відповідно до теореми Каратеодорі та нерівності Клаузіуса, існує універсальний **інтегрувальний множник** (*integrating factor*), який перетворює неточний диференціал `δQ_rev` на точний диференціал. Цим множником є обернена абсолютна температура `1 / T`:

```
dS = δQ_rev / T = (1 / T) · dU + (P / T) · dV
```

Для перевірки умови точного диференціала `dS` виразимо `dU` через змінні `T` та `V`:

```
dU = C_v · dT + [(∂U / ∂V)_T] · dV
```

Підставляючи це у вираз для `dS`:

```
dS = (C_v / T) · dT + (1 / T) · [ (∂U / ∂V)_T + P ] · dV
```

Знайдемо мішані часткові похідні коефіцієнтів при `dT` та `dV`. За теоремою Шварца для точного диференціала вони мають бути рівними:

```
∂/∂V (C_v / T)_T = ∂/∂T [ (1 / T) · ( (∂U / ∂V)_T + P ) ]_V
```

Розкриваючи похідні, отримуємо фундаментальне термодинамічне рівняння стану:

```
(∂U / ∂V)_T = T · (∂P / ∂T)_V - P
```

Для ідеального газу `P = R · T / V`, тому `(∂P / ∂T)_V = R / V`. Підставляючи це значення:

```
(∂U / ∂V)_T = T · (R / V) - P = P - P = 0
```

Це математично доводить, що внутрішня енергія ідеального газу залежить лише від температури `U = U(T)`, а вираз `dS = δQ_rev / T` дійсно є точним диференціалом ентропії!

### 5. Обчислення зміни ентропії у політропних процесах

Політропним називається квазістатичний процес, що відбувається при сталій теплоємності `C_c` і описується рівнянням `P · V^n = const`, де `n` — показник політропи.

Елементарна теплота в політропному процесі:

```
δQ = C_c · dT
```

Зміна ентропії при переході зі стану 1 (температура `T_1`, об'єм `V_1`) у стан 2 (`T_2`, `V_2`):

```
ΔS = ∫[T_1..T_2] (C_c · dT / T) = C_c · ln(T_2 / T_1)
```

Виражаючи теплоємність політропного процесу через показник політропи `n`:

```
C_c = C_v · (n - γ) / (n - 1)
```

Отримуємо загальну формулу зміни ентропії для одного моля ідеального газу у політропному процесі:

```
ΔS = C_v · [(n - γ) / (n - 1)] · ln(T_2 / T_1)
```

Часткові випадки:
- **Ізобарний процес (`n = 0`, `C_c = C_p`)**: `ΔS = C_p · ln(T_2 / T_1) = C_p · ln(V_2 / V_1)`.
- **Ізохорний процес (`n = ∞`, `C_c = C_v`)**: `ΔS = C_v · ln(T_2 / T_1) = C_v · ln(P_2 / P_1)`.
- **Ізотермічний процес (`n = 1`, `C_c = ∞`)**: `ΔS = R · ln(V_2 / V_1)`.
- **Адіабатичний процес (`n = γ`, `C_c = 0`)**: `ΔS = 0`.

### 6. Умови термодинамічної стійкості та опуклість ентропії

Зі збільшення ентропії в ізольованій системі `ΔS ≥ 0` випливають суворі математичні критерії **макроскопічної термодинамічної стійкості** однорідного середовища. 

Щоб рівноважний стан із максимальною ентропією був стійким відносно малих локальних флуктуацій температури та густини, друга варіація ентропії має бути від'ємно визначеною квадратичною формою (`d²S < 0`):

```
d²S = - (1 / T) · [ (C_v / T) · (dT)² + (-∂P / ∂V)_T · (dV)² ] < 0
```

Це приводить до двох обов'язкових математичних умов стійкості речовини:

1. **Термічна стійкість**: Ізохорна теплоємність повинна бути строго додатною:
   ```
   C_v > 0
   ```
   Якщо б `C_v < 0`, підведення тепла охолоджувало б тіло, що призводило б до нескінченного самовільного розігріву гарячих ділянок за рахунок холодних.

2. **Механічна стійкість**: Ізотермічний модуль стиснення повинен бути строго додатним:
   ```
   -(∂P / ∂V)_T > 0
   ```
   Це означає, що при збільшенні об'єму тиск речовини зобов'язаний падати. Якби `(∂P / ∂V)_T > 0`, довільне випадкове розширення локального об'єму приводило б до зростання тиску і вибухоподібного розриву середовища.

### 7. Теорема Гуї-Стодоли про втрачену роботу

Для необоротного процесу різниця між ентропією кінцевого та початкового станів перевищує підведений тепловий інтеграл:

```
∫[1..2, I] (δQ / T) + ∫[2..1, R] (δQ_rev / T) < 0            [нерівність Клаузіуса для замкненого шляху I + R]
∫[1..2, I] (δQ / T) - (S₂ - S₁) < 0                          [заміна зворотного інтеграла R на різницю ентропій]
S₂ - S₁ > ∫[1..2, I] (δQ / T)                                [перенесення різниці ентропій в іншу частину нерівності]
```

Генерована внаслідок незворотності ентропія `ΔS_ген` дорівнює:

```
ΔS_ген = (S_2 - S_1) - ∫[1..2] (δQ / T_довкілля) > 0
```

Відповідно до **теореми Гуї-Стодоли**, втрачена корисна робота `W_втрачена` (знецінення енергії) прямо пропорційна генерації ентропії в системі та навколишньому середовищі:

```
W_втрачена = T_0 · ΔS_ген
```

де `T_0` — температура навколишнього середовища. Це рівняння є фундаментальною основою сучасного розрахунку втрат ексергії в будь-які інженерних пристроях.
