# 🧮 Виведення розподілу Бозе — Ейнштейна та математика критичної температури

Ця вставка містить строге математичне виведення функцій розподілу Бозе — Ейнштейна у великому канонічному ансамблі, детальний розрахунок квантово-статистичного термодинамічного потенціалу, точне обчислення інтегралів за дзета-функцією Рімана `ζ(3/2)` для визначення критичної температури фазового переходу, а також аналіз впливу геометричної розмірності та потенціалу пастки.

## 1. Комбінаторне виведення середнього числа заповнення

Розглянемо квантову систему, що складається з квантових станів (комірок), згрупованих у підрівні з близькими енергіями `ε_i`. Нехай `g_i` — кратність дегенерації (кількість квантових станів) `i`-го енергетичного рівня, а `N_i` — кількість нерозрізнювальних бозонів, що знаходяться на цьому рівні.

Завдання полягає у підрахунку кількості способів `W_i`, якими можна розмістити `N_i` однаковим частинкам по `g_i` різних станах без жодних обмежень на кількість частинок у кожному стані.

Ця математична задача еквівалентна класичній задачі про перегородки: якщо викласти `N_i` частинок (позначимо їх як кружечки `•`) і `g_i - 1` перегородок (позначимо їх як риски `|`) в один ряд, то кожен варіант розстановки відповідає унікальному розподілу частинок по `g_i` комірках. Загальна кількість елементів у ряду дорівнює `N_i + g_i - 1`. Кількість способів вибрати місця для `N_i` частинок серед цієї суми елементів дорівнює перестановкам із повтореннями:

```
W_i = C(N_i + g_i - 1, N_i)
    = (N_i + g_i - 1)! / [ N_i! · (g_i - 1)! ]
```

Повна статистична вага системи `W` дорівнює добутку комбінаторних факторів для всіх енергетичних рівнів:

```
W = ∏_i [ (N_i + g_i - 1)! / (N_i! · (g_i - 1)!) ]
```

Для знаходження найімовірнішого (рівноважного) розподілу максимізуємо логарифм статистичної ваги `ln W` за умов збереження загальної кількості частинок `N` та загальної енергії `E`:

```
∑_i N_i = N         [умова збереження кількості частинок]
∑_i N_i · ε_i = E   [умова збереження повної енергії]
```

Застосовуючи формулу Стірлінга `ln(x!) ≈ x · ln(x) - x` для великих чисел `N_i >> 1` та `g_i >> 1`, маємо:

```
ln W ≈ ∑_i [ (N_i + g_i) · ln(N_i + g_i) - N_i · ln(N_i) - g_i · ln(g_i) ]
```

За методом невизначених множників Лагранжа складаємо функціонал `Φ`:

```
Φ = ln W - α · ∑_i N_i - β · ∑_i N_i · ε_i
```

Диференціюємо `Φ` за змінною `N_i` та прирівнюємо похідну до нуля:

```
∂Φ / ∂N_i = ln(N_i + g_i) + 1 - ln(N_i) - 1 - α - β · ε_i = 0
```

Спрощуємо вираз:

```
ln( (N_i + g_i) / N_i ) = α + β · ε_i
1 + g_i / N_i = exp(α + β · ε_i)
g_i / N_i = exp(α + β · ε_i) - 1
```

Позначивши `n_i = N_i / g_i` як середнє число заповнення одного квантового стану, й ідентифікувавши з термодинаміки множники Лагранжа `β = 1 / (k_B · T)` та `α = -μ / (k_B · T)`, отримуємо функцію розподілу Бозе — Ейнштейна:

```
n(ε) = 1 / [ exp((ε - μ) / (k_B · T)) - 1 ]
```

де `μ` — хімічний потенціал газу, `k_B` — стала Больцмана, `T` — абсолютна температура.

## 2. Виведення у великому канонічному ансамблі

Альтернативний і більш строгий метод виведення спирається на велику канонічну суму за станами. У великому канонічному ансамблі система може обмінюватися з термостатом як енергією, так і частинками.

Для ідеального газу без міжатомної взаємодії середня статсума розпадається на добуток великих статистичних сум окремих квантових станів `k`:

```
Ξ = ∏_k Ξ_k
```

де `Ξ_k` — велика статсума `k`-го одночастинкового стану з енергією `ε_k`. Для бозонів кількість частинок `n_k` у даному стані може набувати будь-яких цілих значень від `0` до `∞`:

```
Ξ_k = ∑_{n_k = 0}^∞ exp[ -n_k · (ε_k - μ) / (k_B · T) ]
```

Позначивши `z = exp[ -(ε_k - μ) / (k_B · T) ]`, бачимо нескінченно спадну геометричну прогресію. Сума підсумовується лише за умови `z < 1`, тобто `ε_k - μ > 0`:

```
Ξ_k = 1 / (1 - z)
    = 1 / [ 1 - exp(-(ε_k - μ) / (k_B · T)) ]
```

Великий термодинамічний потенціал `Ω` дорівнює:

```
Ω = -k_B · T · ln Ξ
  = k_B · T · ∑_k ln [ 1 - exp(-(ε_k - μ) / (k_B · T)) ]
```

Середнє число заповнення `n_k` знаходиться як часткова похідна термодинамічного потенціалу за хімічним потенціалом `μ` зі знаком мінус:

```
n_k = - ∂Ω / ∂μ
    = 1 / [ exp((ε_k - μ) / (k_B · T)) - 1 ]
```

Знайдений вираз повністю збігається з комбінаторним виведенням. Фізична умова збіжності суми `z < 1` накладає фундаментальне обмеження на хімічний потенціал бозе-газу:

```
μ < ε_0
```

Якщо відлічувати енергію від найнижчого стану `ε_0 = 0`, хімічний потенціал бозе-газу завжди мусить бути від'ємним або дорівнювати нулю: `μ ≤ 0`.

## 3. Перехід до неперервного спектра та густина станів

У тривимірному кубічному об'ємі `V = L³` з нульовими граничними умовами енергетичні рівні частинки масою `m` квантуються:

```
ε(p) = p² / (2 · m)
```

Кількість квантових станів у фазовому об'ємі `d³r · d³p` дорівнює `g_s · d³r · d³p / (2π · ħ)³`, де `g_s = 2S + 1` — спіновий фактор дегенерації (для безспінових частинок `g_s = 1`). Інтегруючи за координатою по об'єму `V`, отримуємо густину станів за інтервалом енергій `dε`:

```
g(ε) = (V · m^(3/2) · g_s / (2^(1/2) · π² · ħ³)) · ε^(1/2)
```

Загальна кількість частинок у газі `N` дорівнює сумі частинок у всіх станах. У неперервному наближенні замінюємо суму інтегралом:

```
N = ∫_0^∞ g(ε) · n(ε) dε
```

Підставляючи вирази для `g(ε)` та `n(ε)`:

```
N = [ V · m^(3/2) · g_s / (2^(1/2) · π² · ħ³) ] · ∫_0^∞ [ ε^(1/2) dε / (exp((ε - μ) / (k_B · T)) - 1) ]
```

Введемо безрозмірну змінну інтегрування `x = ε / (k_B · T)` та безрозмірну фугітивність `z = exp(μ / (k_B · T)) ≤ 1`:

```
N = V · (m · k_B · T / (2π · ħ²))^(3/2) · g_s · g_{3/2}(z)
```

де `g_ν(z)` — особлива спеціальна функція (полілогарифм або функція Бозе — Ейнштейна):

```
g_ν(z) = (1 / Γ(ν)) · ∫_0^∞ [ x^(ν-1) dx / (z⁻¹ · e^x - 1) ]
       = ∑_{k=1}^∞ (z^k / k^ν)
```

## 4. Обчислення критичної температури бозе-конденсації

Функція `g_{3/2}(z)` є монотонно зростаючою відносно `z` на інтервалі `0 < z ≤ 1`. Вона досягає свого абсолютного максимуму при `z = 1` (що відповідає граничному значенню хімічного потенціалу `μ = 0`):

```
g_{3/2}(1) = ∑_{k=1}^∞ (1 / k^(3/2))
           = ζ(3/2)
```

де `ζ(s)` — дзета-функція Рімана. Чисельне значення дзета-функції:

```
ζ(3/2) ≈ 2.61237537...
```

Отже, максимальна кількість частинок `N_{th}^{max}`, яку можуть вмістити всі збуджені (теплові) стани при даній температурі `T` і об'ємі `V`, обмежена верхньою межею:

```
N_{th}^{max}(T) = V · (m · k_B · T / (2π · ħ²))^(3/2) · g_s · ζ(3/2)
```

Якщо зафіксувати густину частинок `n = N / V` і знижувати температуру `T`, ми неминуче досягнемо точки, де `N_{th}^{max}(T)` стане меншим за загальну кількість частинок `N`.

Критична температура `T_c` визначається з умови `N_{th}^{max}(T_c) = N`:

```
N = V · (m · k_B · T_c / (2π · ħ²))^(3/2) · g_s · ζ(3/2)
```

Виражаючи `T_c` з цього рівняння, отримуємо точну математичну формулу критичної температури бозе-конденсації:

```
T_c = [ 2π · ħ² / (m · k_B) ] · [ N / (V · g_s · ζ(3/2)) ]^(2/3)
```

Враховуючи теплову довжину хвилі де Бройля `λ_{dB} = (2π · ħ² / (m · k_B · T))^(1/2)`, критерій бозе-конденсації можна переписати у витонченій просторовій формі:

```
n · λ_{dB}³ = ζ(3/2) / g_s ≈ 2.612
```

Це означає, що конденсація настає тоді, коли середня відстань між частинками `r ~ n⁻¹ᐟ³` стає сумірною з дебройлівською довжиною хвилі частинок, і хвильові пакети окремих атомів починають перекриватися у просторі.

## 5. Розділення фаз та частка конденсату

При температурах нижчих за критичну `T < T_c`, хімічний потенціал строго фіксується на рівні `μ = 0`. Кількість частинок у збуджених станах `N_{th}` визначається температурою `T`:

```
N_{th}(T) = V · (m · k_B · T / (2π · ħ²))^(3/2) · g_s · ζ(3/2)
          = N · (T / T_c)^(3/2)
```

Усі інші `N_0` частинок змушені осісти у найнижчому квантовому стані з енергією `E_0 = 0`:

```
N_0(T) = N - N_{th}(T)
       = N · [ 1 - (T / T_c)^(3/2) ]
```

Таким чином, частка бозе-конденсату `N_0 / N` прямує до `1` при `T → 0` за законом трьох других:

```
N_0 / N = 1 - (T / T_c)^(3/2)   [для T ≤ T_c]
```

Цей вираз описує точний функціональний профіль фазового переходу другого роду в ідеальному бозе-газі.

## 6. Виведення термодинамічних функцій та скачка похідної теплоємності

Знайдемо термодинамічний потенціал `Ω` для бозе-газу при `T ≤ T_c` (`μ = 0`). Інтегруючи за енергією з густиною станів `g(ε) ∝ ε¹ᐟ²`:

```
Ω = k_B · T · ∫_0^∞ g(ε) · ln [ 1 - exp(-ε / (k_B · T)) ] dε
```

Інтегруючи частинами, отримуємо зв'язок між великим потенціалом `Ω` та внутрішньою енергією `U`:

```
Ω = - (2/3) · U(T)
```

Внутрішня енергія `U(T)` задається інтегралом:

```
U(T) = ∫_0^∞ ε · g(ε) · n(ε) dε
     = [ V · m^(3/2) · g_s / (2^(1/2) · π² · ħ³) ] · (k_B · T)^(5/2) · ∫_0^∞ [ x^(3/2) dx / (e^x - 1) ]
```

Оскільки табличний інтеграл `∫_0^∞ x^(3/2) dx / (e^x - 1) = Γ(5/2) · ζ(5/2) = (3/4) · π^(1/2) · ζ(5/2)`, отримуємо вираз для внутрішньої енергії:

```
U(T) = (3/2) · N · k_B · T · (T / T_c)^(3/2) · [ ζ(5/2) / ζ(3/2) ]   [при T ≤ T_c]
```

Оскільки `P · V = -Ω = (2/3) U`, тиск бозе-газу нижче `T_c` описується формулою:

```
P(T) = (k_B · T / λ_{dB}³) · ζ(5/2)
```

Звідси випливає фундаментальний термодинамічний факт: тиск ідеального бозе-газу нижче `T_c` повністю незалежний від об'єму `V` і є суто функцією температури.

Диференціюючи `U(T)` за температурою, отримуємо молярну теплоємність `C_V`:

```
C_V(T) = (∂U / ∂T)_V
       = (15/4) · N · k_B · [ ζ(5/2) / ζ(3/2) ] · (T / T_c)^(3/2)   [при T ≤ T_c]
```

У критичній точці `T = T_c` значення теплоємності зліва дорівнює:

```
C_V(T_c⁻) = (15/4) · N · k_B · (1.34149 / 2.61238) ≈ 1.925 · N · k_B
```

При `T > T_c` хімічний потенціал `μ < 0` залежить від температури. Диференціюючи вираз для `U(T, μ)` вище `T_c`, отримуємо теплоємність справа:

```
C_V(T_c⁺) = (15/4) · N · k_B · [ ζ(5/2) / ζ(3/2) ] - (9/4) · N · k_B · [ ζ(3/2) / ζ(1/2) ]
```

Оскільки `ζ(1/2) = -1.46035`, другий доданок зменшує теплоємність справа, причому сама функція `C_V(T)` є неперервною в точці `T_c`, але її перша похідна за температурою `dC_V / dT` зазнає скінченного від'ємного скачка:

```
Δ (dC_V / dT)|_{T_c} = (dC_V / dT)|_{T_c⁺} - (dC_V / dT)|_{T_c⁻} ≈ - 3.66 · N · k_B / T_c
```

Це строго доводить, що бозе-конденсація в ідеальному газі є фазовим переходом другого роду за класифікацією Еренфеста.

## 7. Бозе-конденсація у гармонічній пастці та довільній розмірності

Розглянемо виведення параметрів конденсації у `d`-вимірній системі з поліноміальним спектром енергії `ε(p) = a · p^s` та обмежувальним потенціалом.

Густина станів у `d`-вимірному просторі з енергетичним спектром з показником `s` задається силовим законом `g(ε) = C · ε^(α - 1)`, де `α = d / s`.

Для анізотропної `d`-вимірної гармонічної пастки `V(r) = ∑_{i=1}^d (m/2) ω_i² x_i²` спектр одночастинкових станів квантується рівномірно: `ε_n = ∑_{i=1}^d n_i ħ ω_i`.

Густина станів у `d`-вимірній пастці має вигляд:

```
g(ε) = (ε^(d-1) / ((d-1)! · (ħ ω̄)^d))
```

де `ω̄ = (∏_{i=1}^d ω_i)^(1/d)` — середнє геометричне частот пастки.

Кількість теплових частинок у `d`-вимірній пастці описується інтегралом:

```
N_{th}(T) = ∫_0^∞ g(ε) · n(ε) dε
          = ( (k_B · T / (ħ ω̄))^d / (d-1)! ) · ∫_0^∞ [ x^(d-1) dx / (e^x - 1) ]
          = ( k_B · T / (ħ ω̄) )^d · ζ(d)
```

Отже, критична температура бозе-конденсації у тривимірній гармонічній пастці (`d = 3`) дорівнює:

```
T_c^{trap} = (ħ ω̄ / k_B) · [ N / ζ(3) ]^(1/3) ≈ 0.94 · (ħ ω̄ / k_B) · N^(1/3)
```

де `ζ(3) ≈ 1.202056`.

Частка бозе-конденсату у гармонічній пастці змінюється за кубічним законом:

```
N_0 / N = 1 - (T / T_c^{trap})³   [для T ≤ T_c^{trap}]
```

Це показує, що геометричне обмеження пастки прискорює накопичення частинок у конденсаті у порівнянні з тривимірним однорідним газом (де закон є `(T/T_c)³ᐟ²`).

З аналізу збіжності інтеграла `N_{th} = ∫_0^∞ g(ε) n(ε) dε` при `μ = 0` випливає загальний математичний критерій можливості бозе-конденсації при `T > 0`:

```
Інтеграл збігається  ⇒  α = d/s > 1  (для вільного газу s=2, отже потрібна розмірність d > 2)
```

Для однорідного газу (`s = 2`) інтеграл збігається лише при `d ≥ 3`. У двовимірному однорідному газі (`d = 2, s = 2`) інтеграл розбігається логарифмічно при `μ → 0`, що робить бозе-конденсацію неможливою при будь-якій `T > 0` (у згоді з теоремою Мерміна — Вагнера). Проте гармонічна пастка додає потенціал `V(r) ∝ r²`, змінюючи параметр на `α = d = 2 > 1`, завдяки чому в двовимірній пастці бозе-конденсація стає математично й фізично можливою.
