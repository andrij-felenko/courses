# 🧮 Математичний вивід критичних параметрів та ізотерм Максвелла

Ця математична вставка містить розширений алгебраїчний та термодинамічний вивід критичних параметрів стану (критичного об'єму, тисків та температури), зведеного рівняння Ван дер Ваальса, рівнянь спінодалі, рівняння кривої інверсії Джоуля-Томсона, віріального розкладу та математичного формулювання правила рівних площ Максвелла.

---

## 1. Повний диференціальний вивід критичних параметрів V_c, P_c, T_c

Рівняння Ван дер Ваальса для одного моля реального газу записане у формі залежності тиску `P` від молярного об'єму `V_m` та температури `T`:

```
P(V_m, T) = (R · T) / (V_m - b) - a / V_m²
```

Критичний стан термодинамічної системи на `P-V` діаграмі визначається як точка перегину з горизонтальною дотичною на критичній ізотермі `T = T_c`. Фізично це означає, що у критичній точці стискальність системи стає безкінечно великою, а флуктуації густини зростають до макроскопічних масштабів (явище критичної оппалесценції). Математично цей стан відповідає одночасному справдженню двох умов для першої та другої частинних похідних тиску за молярним об'ємом:

```
(∂P / ∂V_m)_T = 0                                           [Умова 1: горизонтальна дотична]
(∂²P / ∂V_m²)_T = 0                                          [Умова 2: точка перегину]
```

Знайдемо першу частинну похідну тиску `P` за об'ємом `V_m` за сталої температури `T`:

```
(∂P / ∂V_m)_T = ∂/∂V_m [ (R · T) / (V_m - b) - a · V_m⁻² ]
= - (R · T) / (V_m - b)² + 2 · a / V_m³                      [диференціювання за V_m]
```

Прирівняємо першу похідну до нуля за критичних умов (`T = T_c`, `V_m = V_c`):

```
(R · T_c) / (V_c - b)² = (2 · a) / V_c³                       [1: вираз для першої похідної]
```

Знайдемо другу частинну похідну тиску `P` за об'ємом `V_m`:

```
(∂²P / ∂V_m²)_T = ∂/∂V_m [ - (R · T) / (V_m - b)² + 2 · a · V_m⁻³ ]
= (2 · R · T) / (V_m - b)³ - 6 · a / V_m⁴                     [повторне диференціювання]
```

Прирівняємо другу похідну до нуля за критичних умов:

```
(2 · R · T_c) / (V_c - b)³ = (6 · a) / V_c⁴                   [2: вираз для другої похідної]
```

Поділимо рівняння `[2]` на рівняння `[1]`, щоб виключити температурний множник `R · T_c`:

```
[ (2 · R · T_c) / (V_c - b)³ ] / [ (R · T_c) / (V_c - b)² ] = [ (6 · a) / V_c⁴ ] / [ (2 · a) / V_c³ ]
2 / (V_c - b) = 3 / V_c                                      [скорочення R·T_c, (V_c-b)² та a/V_c³]
2 · V_c = 3 · (V_c - b)                                      [перемноження пропорції]
2 · V_c = 3 · V_c - 3 · b                                    [розкриття дужок]
V_c = 3 · b                                                  [3: критичний молярний об'єм]
```

Підставимо знайдений критичний об'єм `V_c = 3b` у рівняння першої похідної `[1]`:

```
(R · T_c) / (3 · b - b)² = (2 · a) / (3 · b)³                [підстановка V_c = 3b]
(R · T_c) / (2 · b)² = (2 · a) / (27 · b³)                   [піднесення до степенів]
(R · T_c) / (4 · b²) = (2 · a) / (27 · b³)                   [розкриття квадрата]
R · T_c = (8 · a) / (27 · b)                                 [множення обох частин на 4·b²]
T_c = (8 · a) / (27 · R · b)                                 [4: критична температура]
```

Тепер обчислимо критичний тиск `P_c`, підставивши `V_c = 3b` та `T_c` у вихідне рівняння Ван дер Ваальса:

```
P_c = (R · T_c) / (V_c - b) - a / V_c²
P_c = [ R · (8 · a / (27 · R · b)) ] / (3 · b - b) - a / (3 · b)²   [підстановка T_c та V_c]
P_c = (8 · a / (27 · b)) / (2 · b) - a / (9 · b²)            [спрощення дробу]
P_c = (4 · a) / (27 · b²) - a / (9 · b²)                     [ділення на 2b]
P_c = (4 · a) / (27 · b²) - (3 · a) / (27 · b²)             [зведення до спільного знаменника]
P_c = a / (27 · b²)                                          [5: критичний тиск]
```

## 2. Кубічний розклад та метод зливаних коренів Кардано

Альтернативний алгебраїчний метод виводу спирається на розклад кубічного полінома. Помножимо рівняння Ван дер Ваальса на `V_m²` і згрупуємо за степенями `V_m`:

```
P · V_m³ - (P · b + R · T) · V_m² + a · V_m - a · b = 0
```

Поділимо на тиск `P`:

```
V_m³ - (b + R · T / P) · V_m² + (a / P) · V_m - (a · b / P) = 0   [6]
```

У критичній точці `(P_c, T_c)` всі три корені рівняння `[6]` зливаються в один трикратний корінь `V_c`: `(V_m - V_c)³ = 0`. Раскриваємо за формулою куба різниці двох чисел:

```
V_m³ - 3 · V_c · V_m² + 3 · V_c² · V_m - V_c³ = 0              [7]
```

Прирівнюємо коефіцієнти при однакових степенях `V_m` у рівняннях `[6]` та `[7]`:

```
1) 3 · V_c = b + R · T_c / P_c                                [8: коефіцієнт при V_m²]
2) 3 · V_c² = a / P_c                                         [9: коефіцієнт при V_m]
3) V_c³ = a · b / P_c                                         [10: вільний член]
```

Ділення рівняння `[10]` на `[9]` негайно дає:

```
V_c³ / (3 · V_c²) = (a · b / P_c) / (a / P_c)
V_c / 3 = b
V_c = 3 · b
```

Звідки шляхом послідовної підстановки повністю підтверджуються вирази для `P_c = a / (27b²)` та `T_c = 8a / (27Rb)`.

## 3. Обчислення критичного фактора стискальності Z_c

Фактор стискальності (коефіцієнт стискальності) вимірює відносне відхилення реального газу від ідеального стану:

```
Z = (P · V_m) / (R · T)
```

Обчислимо критичний фактор стискальності `Z_c` за знайденими вище виразами для `P_c`, `V_c` та `T_c`:

```
Z_c = (P_c · V_c) / (R · T_c)
= (a / (27 · b²)) · (3 · b) / (R · (8 · a / (27 · R · b)))      [підстановка виразів для P_c, V_c та T_c]
= (3 · a · b / (27 · b²)) / (8 · a / (27 · b))                   [перемноження чисельника та скорочення R]
= (a / (9 · b)) / (8 · a / (27 · b))                             [спрощення чисельника: 3/27 = 1/9]
= (a / (9 · b)) · (27 · b / (8 · a))                             [множення на обернений дріб]
= (27 · a · b) / (72 · a · b)                                    [перемноження чисельників і знаменників]
= 3 / 8                                                          [скорочення a·b та 27/72 = 3/8]
= 0.375                                                          [переведення у десятковий дріб]
```

Отже, теорія Ван дер Ваальса передбачає універсальне значення `Z_c = 3/8 = 0.375` незалежно від індивідуальних параметрів речовини `a` і `b`.

## 4. Алгебраїчний вивід зведеного рівняння стану

Введемо безрозмірні зведені змінні:

```
π = P / P_c       ⇒   P = π · P_c = π · (a / (27 · b²))
φ = V_m / V_c     ⇒   V_m = φ · V_c = φ · (3 · b)
τ = T / T_c       ⇒   T = τ · T_c = τ · (8 · a / (27 · R · b))
```

Підставимо вирази `P`, `V_m`, `T` у вихідне рівняння Ван дер Ваальса `(P + a / V_m²) · (V_m - b) = R · T`:

```
(π · P_c + a / (φ² · V_c²)) · (φ · V_c - b) = R · τ · T_c      [підстановка зведених змінних]
(π · (a / (27 · b²)) + a / (9 · φ² · b²)) · (3 · φ · b - b) = R · τ · ((8 · a) / (27 · R · b))   [розгортання P_c, V_c, T_c]
```

Винесемо спільні множники `a / (27 · b²)` з першої дужки та `b` з другої дужки:

```
(a / (27 · b²)) · (π + 3 / φ²) · b · (3 · φ - 1) = (8 · a / (27 · b)) · τ   [винесення множників]
```

Поділимо обидві частини рівняння на множник `a / (27 · b)`:

```
(π + 3 / φ²) · (3 · φ - 1) = 8 · τ                              [зведене рівняння стану]
```

Рівняння містить виключно числові коефіцієнти (3, 1, 8), що доводить **закон відповідних станів**.

## 5. Вивід рівняння спінодалі та межі абсолютної стійкості

Спінодаль являє собою параболічну межу на `P-V` або `T-V` діаграмі, яка відокремлює метастабільні фази від абсолютно нестійкої області спінодального розпаду. Умова спінодалі полягає у дорівнюванні нулю першої похідної тиску за об'ємом:

```
(∂P / ∂V_m)_T = - (R · T) / (V_m - b)² + 2 · a / V_m³ = 0
```

Виразимо температуру спінодалі `T_spin` як функцію молярного об'єму `V_m`:

```
(R · T_spin) / (V_m - b)² = 2 · a / V_m³
T_spin(V_m) = (2 · a / R) · (V_m - b)² / V_m³                    [11: температура спінодалі]
```

Підставимо `T_spin(V_m)` у рівняння Ван дер Ваальса для обчислення тиску спінодалі `P_spin`:

```
P_spin(V_m) = (R · [ (2 · a / R) · (V_m - b)² / V_m³ ]) / (V_m - b) - a / V_m²
P_spin(V_m) = (2 · a · (V_m - b)) / V_m³ - a / V_m²             [скорочення R та (V_m - b)]
P_spin(V_m) = (2 · a · V_m - 2 · a · b - a · V_m) / V_m³        [зведення до спільного знаменника]
P_spin(V_m) = a · (V_m - 2 · b) / V_m³                           [12: тиск спінодалі]
```

Аналіз рівняння спінодалі `[12]` показує важливі геометричні властивості:
- При `V_m = 2b` тиск спінодалі перетворюється на нуль (`P_spin = 0`).
- При `V_m = 3b = V_c` тиск спінодалі досягає максимуму і дорівнює критичному тиску `P_spin(3b) = a · b / (27 b³) = a / (27 b²) = P_c`.
- Спінодаль торкається бінодалі (вершини купола фазового співіснування) строго у критичній точці `(V_c, P_c)`.

## 6. Термодинамічний вивід кривої інверсії ефекту Джоуля-Томсона

Ефект Джоуля-Томсона полягає у зміні температури газу під час його адіабатичного протікання через пористу перегородку (дроселювання за сталої ентальпії `H = const`). Диференціальний коефіцієнт Джоуля-Томсона `μ_JT` виражається через термодинамічні похідні:

```
μ_JT = (∂T / ∂P)_H = (1 / C_p) · [ T · (∂V_m / ∂T)_P - V_m ]
```

Умова інверсії знаку ефекту (`μ_JT = 0`) вимагає справдження рівності:

```
T · (∂V_m / ∂T)_P - V_m = 0   ⇒   (∂V_m / ∂T)_P = V_m / T         [13]
```

Використавши циклічне співвідношення для частинних похідних `(∂V_m/∂T)_P = - (∂P/∂T)_V / (∂P/∂V_m)_T`, перепишемо умову інверсії через похідні тиску:

```
- T · (∂P / ∂T)_V / (∂P / ∂V_m)_T = V_m
(∂P / ∂V_m)_T = - (T / V_m) · (∂P / ∂T)_V                        [14]
```

Обчислимо похідну `(∂P/∂T)_V` з рівняння Ван дер Ваальса:

```
(∂P / ∂T)_V = R / (V_m - b)
```

Підставимо `(∂P/∂T)_V` та `(∂P/∂V_m)_T = - (R · T) / (V_m - b)² + 2 · a / V_m³` у рівняння `[14]`:

```
- (R · T) / (V_m - b)² + 2 · a / V_m³ = - (T / V_m) · (R / (V_m - b))
- (R · T) / (V_m - b)² + (R · T) / (V_m · (V_m - b)) = - 2 · a / V_m³
(R · T) / (V_m - b) · [ 1 / V_m - 1 / (V_m - b) ] = - 2 · a / V_m³
(R · T) / (V_m - b) · [ - b / (V_m · (V_m - b)) ] = - 2 · a / V_m³
(R · T · b) / (V_m · (V_m - b)²) = 2 · a / V_m³
T_inv(V_m) = (2 · a / (R · b)) · (V_m - b)² / V_m²               [15: температура інверсії]
```

Знайдемо максимальну температуру інверсії `T_inv,max`, яка досягається у межі дуже розрідженого газу (`V_m >> b`):

```
T_inv,max = lim_{V_m -> ∞} T_inv(V_m) = (2 · a) / (R · b)        [16]
```

Порівнюючи максимальну температуру інверсії з критичною температурою `T_c = 8a / (27Rb)`:

```
T_inv,max / T_c = (2 · a / (R · b)) / ((8 · a) / (27 · R · b)) = 27 / 4 = 6.75
```

Цей висновок означає, що для будь-якого газу Ван дер Ваальса ефект охолодження під час дроселювання можливий лише за температур, нижчих за `6.75 · T_c`.

## 7. Віріальний розклад та вивід другого віріального коефіцієнта

Віріальний розклад Камерлінга-Оннеса виражає фактор стискальності `Z` як ряд за молярною густиною `1 / V_m`:

```
Z = 1 + B_2(T) / V_m + B_3(T) / V_m² + B_4(T) / V_m³ + ...
```

Виведемо віріальні коефіцієнти з рівняння Ван дер Ваальса. Виразимо `Z`:

```
Z = (P · V_m) / (R · T) = V_m / (V_m - b) - a / (R · T · V_m)
```

Перепишемо перший член у вигляді `(1 - b / V_m)⁻¹` і розкладемо в ряд Тейлора за малим параметром `(b / V_m < 1)`:

```
(1 - b / V_m)⁻¹ = 1 + (b / V_m) + (b / V_m)² + (b / V_m)³ + ...   [розклад у ряд Тейлора]
```

Підставимо цей розклад у вираз для `Z`:

```
Z = [ 1 + (b / V_m) + (b² / V_m²) + (b³ / V_m³) + ... ] - a / (R · T · V_m)
Z = 1 + [ b - a / (R · T) ] / V_m + b² / V_m² + b³ / V_m³ + ...   [групування за степенями 1/V_m]
```

Зіставляючи коефіцієнти при одинакових степенях `1 / V_m`:

```
Другий віріальний коефіцієнт:    B_2(T) = b - a / (R · T)       [17]
Третій віріальний коефіцієнт:    B_3(T) = b²                    [18]
Четвертий віріальний коефіцієнт: B_4(T) = b³                    [19]
```

Температура Бойля `T_B` визначається як температура, за якої другий віріальний коефіцієнт перетворюється на нуль (`B_2(T_B) = 0`):

```
b - a / (R · T_B) = 0
b = a / (R · T_B)
T_B = a / (R · b)                                            [20: температура Бойля]
```

Порівнюючи температуру Бойля `T_B` з критичною температурою `T_c = 8a / (27Rb)`:

```
T_B / T_c = (a / (R · b)) / ((8 · a) / (27 · R · b)) = 27 / 8 = 3.375
```

Отже, температура Бойля газу Ван дер Ваальса у `3.375` рази перевищує його критичну температуру.

## 8. Термодинамічний вивід інтеграла Максвелла для рівноваги фаз

Умовою фазової рівноваги насиченої рідини `V_l` та насиченої пари `V_g` за підкритичної температури `T < T_c` є рівність тисків та хімічних потенціалів:

```
P_l = P_g = P_sat
μ_l(P_sat, T) = μ_g(P_sat, T)
```

Зміна хімічного потенціалу уздовж ізотерми описується диференціалом `dμ = V_m · dP`. Інтегруємо від рідкої фази до газоподібної:

```
μ_g - μ_l = ∫_{P_sat}^{P_sat} V_m dP = 0                      [21]
```

Застосуємо формулу інтегрування частинами для `∫ V_m dP`:

```
∫_{P_sat}^{P_sat} V_m dP = [ P · V_m ]_{V_l}^{V_g} - ∫_{V_l}^{V_g} P_{VdW}(V_m) dV_m = 0
P_sat · V_g - P_sat · V_l - ∫_{V_l}^{V_g} P_{VdW}(V_m) dV_m = 0
P_sat · (V_g - V_l) = ∫_{V_l}^{V_g} P_{VdW}(V_m) dV_m         [22]
```

Перенесемо ліву частину під знак інтеграла:

```
∫_{V_l}^{V_g} [ P_{VdW}(V_m) - P_sat ] dV_m = 0               [23: Конструкція Максвелла]
```

Геометрично рівняння `[23]` означає, що площа `S₁` верхнього сегмента ізотерми над ізобарою `P_sat` дорівнює площі `S₂` нижнього сегмента під ізобарою.

Підставимо у рівняння `[22]` функцію тиску Ван дер Ваальса `P_{VdW}(V_m) = (R · T) / (V_m - b) - a / V_m²`:

```
P_sat · (V_g - V_l) = ∫_{V_l}^{V_g} [ (R · T) / (V_m - b) - a / V_m² ] dV_m
P_sat · (V_g - V_l) = [ R · T · ln(V_m - b) + a / V_m ]_{V_l}^{V_g}    [обчислення первісної]
P_sat · (V_g - V_l) = R · T · ln( (V_g - b) / (V_l - b) ) + a · (1 / V_g - 1 / V_l)   [24]
```

Трансцендентне рівняння `[24]` разом із кубічним рівнянням стану дозволяє обчислити точний тиск насиченої пари `P_sat(T)` та молярні об'єми співіснуючих фаз `V_l` і `V_g` за будь-якої підкритичної температури `T`.
