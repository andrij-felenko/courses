# 🧮 Математичне виведення розподілу Максвелла — Больцмана

У цій математичній вставці наведено двома незалежними шляхами строго алгебраїчний вивід розподілу молекул ідеального газу за швидкостями та енергіями, а також виконано точне обчислення інтегральних моментів розподілу для знаходження характеристичних швидкостей `v_p`, `v_сер` та `v_кв`, аналіз характеристичної функції, інтеграла накопиченої ймовірності, коефіцієнтів асиметрії та асимптотичних властивостей кривої.

---

### 1. Метод 1: Функціональний підхід Максвелла (1860)

Розглянемо однорідний ідеальний газ із масою молекули `m` за абсолютної температури `T`. Припустимо, що проєкції швидкості частинки за тривимірними декартовими осями `v_x`, `v_y`, `v_z` є випадковими величинами зі щільністю розподілу ймовірностей `f(v_x, v_y, v_z)`.

#### Постулати Максвелла:
1. **Ізотропність простору**: функція розподілу залежить лише від модуля вектора швидкості `v = √(v_x² + v_y² + v_z²)`, тобто є сферично симетричною:
   ```
   f(v_x, v_y, v_z) = Ψ(v_x² + v_y² + v_z²)
   ```
2. **Статистична незалежність**: розподіл проєкції за однією віссю не залежить від значення проєкцій за іншими осями:
   ```
   f(v_x, v_y, v_z) = f₁(v_x) · f₁(v_y) · f₁(v_z)
   ```

Фізичним підґрунтям гіпотези про незалежність є те, що хаотичні зіткнення молекул розсіюють імпульси за трьома осями без жодної колінеарної преференції.

#### Розв'язання функціонального рівняння:
Прирівнюючи два вирази для щільності ймовірності, отримуємо базове функціональне рівняння:

```
f₁(v_x) · f₁(v_y) · f₁(v_z) = Ψ(v_x² + v_y² + v_z²)
```

Щоб звести добуток функцій до суми, логарифмуємо ліву та праву частини рівняння:

```
ln(f₁(v_x)) + ln(f₁(v_y)) + ln(f₁(v_z)) = ln(Ψ(v_x² + v_y² + v_z²))
```

Тепер продиференціюємо цю рівність за змінною `v_x`. Позначаючи радіус-вектор у просторі швидкостей як `r² = v_x² + v_y² + v_z²`, застосовуємо ланцюгове правило диференціювання складного виразу:

```
d/dv_x [ln(f₁(v_x))] 
= f₁'(v_x) / f₁(v_x)                             [похідна лівої частини]

d/dv_x [ln(Ψ(r²))] 
= (1 / Ψ(r²)) · dΨ/dr² · (∂r² / ∂v_x)
= (1 / Ψ(r²)) · dΨ/dr² · (2 · v_x)                 [ланцюгове правило, ∂r²/∂v_x = 2 v_x]
```

Прирівнюючи ліву та праву похідні та ділячи обидві частини на `2 · v_x`, отримуємо відокремлення змінних:

```
f₁'(v_x) / (2 · v_x · f₁(v_x)) = (1 / Ψ(r²)) · dΨ/dr²
```

Зверніть увагу на структуру цього рівняння: ліва частина містить виключно змінну `v_x`, тоді як права частина залежить від загальної суми квадратів `r² = v_x² + v_y² + v_z²`. Зміна значення `v_y` чи `v_z` змінює праву частину, але не впливає на ліву. Така тотожність можлива лише за умови, що обидві частини дорівнюють одній і тій самій від'ємній сталій величині `-λ`:

```
f₁'(v_x) / (v_x · f₁(v_x)) = -2 · λ               [константа розділення змінних]

d[ln(f₁(v_x))] / dv_x = -2 · λ · v_x               [диференціальне рівняння першого порядку]
```

Значення `λ` має бути строго додатним (`λ > 0`), оскільки при від'ємному значення функція розподілу зростала б до нескінченності при великих швидкостях, що суперечить умові нормування та фізичному змісту.

Проінтегруємо отримане диференціальне рівняння за змінною `v_x`:

```
ln(f₁(v_x)) = -λ · v_x² + C₀                      [невизначений інтеграл]

f₁(v_x) = A · exp(-λ · v_x²)                      [потенціювання, A = exp(C₀)]
```

#### Доведення унікальності функціонального розв'язку:
Чи існує інший математичний розв'язок рівняння `f₁(x) · f₁(y) · f₁(z) = Ψ(x² + y² + z²)`?
Нехай `g(x) = ln(f₁(√x))`. Тоді вихідне рівняння набуває вигляду:
```
g(x) + g(y) + g(z) = G(x + y + z)
```
Покладаючи `y = 0` та `z = 0`, маємо `g(x) + 2·g(0) = G(x)`. Підставляючи `G(x)` назад у рівняння:
```
g(x) + g(y) + g(z) = g(x + y + z) + 2·g(0)
```
Позначаючи `h(x) = g(x) - g(0)`, одержуємо класичне **функціональне рівняння Коші**:
```
h(x) + h(y) = h(x + y)
```
Єдиним неперервним розв'язком рівняння Коші є лінійна функція `h(x) = -λ · x`. Отже, `ln(f₁(v_x)) = -λ · v_x² + C₀`, що математично доводить єдиність гауссової форми розподілу.

#### Нормування одновимірного розподілу:
Сумарна ймовірність знаходження проєкції швидкості у всьому діапазоні від `-∞` до `+∞` мусить дорівнювати одиниці. Це задає умову нормування:

```
∫₋∞⁺∞ f₁(v_x) dv_x = 1

A · ∫₋∞⁺∞ exp(-λ · v_x²) dv_x = 1
```

Обчислення цього пуассонового (гауссового) інтеграла здійснюється за допомогою зведення до подвійного інтеграла у полярних координатах:
- Позначимо `I = ∫₋∞⁺∞ exp(-λ · x²) dx`.
- Тоді `I² = ∫₋∞⁺∞ ∫₋∞⁺∞ exp(-λ · (x² + y²)) dx dy`.
- Переходячи до полярних координат `(r, θ)`, маємо `dx dy = r dr dθ`:
  `I² = ∫₀²π dθ ∫₀∞ r exp(-λ · r²) dr = 2·π · (1 / (2·λ)) = π / λ`.
- Звідси `I = √(π / λ)`.

Підставляючи значення інтеграла у умову нормування, знаходимо амплітудний множник `A`:

```
A · √(π / λ) = 1

A = √(λ / π)                                      [коефіцієнт нормування A]
```

#### Визначення константи λ з середня кінетичної енергії:
Обчислимо математичне сподівання квадрата проєкції швидкості `⟨v_x²⟩`:

```
⟨v_x²⟩ 
= ∫₋∞⁺∞ v_x² · f₁(v_x) dv_x
= A · ∫₋∞⁺∞ v_x² · exp(-λ · v_x²) dv_x
= √(λ / π) · (1 / (2 · λ)) · √(π / λ)             [інтегрування частинами для гауссового моменту]
= 1 / (2 · λ)
```

Згідно з термодинамічною теоремою про рівнорозподіл енергії, на кожен поступальний ступінь вільності припадає середня кінетична енергія `(1/2) · k_B · T`:

```
(1/2) · m · ⟨v_x²⟩ = (1/2) · k_B · T

⟨v_x²⟩ = (k_B · T) / m

1 / (2 · λ) = (k_B · T) / m

λ = m / (2 · k_B · T)                            [значення константи λ]
```

Таким чином, для одновимірної щільності розподілу проєкції швидкості отримуємо остаточну формулу Ґаусса:

```
f₁(v_x) = √(m / (2 · π · k_B · T)) · exp(-m · v_x² / (2 · k_B · T))
```

Для довільного довільно орієнтованого одиничного вектора `n⃗ = (n_x, n_y, n_z)` проєкція швидкості `v_n = v⃗ · n⃗` так само є гауссовою випадковою величиною з нульовим середнім та дисперсією `⟨v_n²⟩ = k_B · T / m`. Це математично ілюструє повну інваріантність розподілу щодо повертань системи координат.

#### Характеристична функція одномірного розподілу
У теорії ймовірностей характеристична функція випадкової величини `v_x` визначається як фур'є-перетворення її щільності ймовірності:
```
Φ(t) = ⟨exp(i · t · v_x)⟩ = ∫₋∞⁺∞ exp(i · t · v_x) · f₁(v_x) dv_x
```
Підставляючи гауссів вираз для `f₁(v_x)` та доповнюючи показник до повного квадрата:
```
Φ(t) = exp(-k_B · T · t² / (2 · m))
```
Характеристична функція дозволяє легко обчислювати всі парні моменти вищих порядків шляхом диференціювання по `t`: `⟨v_x²ⁿ⟩ = (-1)ⁿ · d²ⁿΦ/dt² |ₜ₌₀`.

### 2. Перехід до тривимірного розподілу за модулем швидкості

Тривимірна щільність ймовірності знаходження вектора швидкості у кубічному елементі об'єму `dv_x dv_y dv_z` дорівнює добутку трьох одновимірних розподілів:

```
f(v_x, v_y, v_z) dv_x dv_y dv_z
= f₁(v_x) · f₁(v_y) · f₁(v_z) dv_x dv_y dv_z                                     [незалежність ортогональних компонент]
= (m / (2 · π · k_B · T))^(3/2) · exp(-m · (v_x² + v_y² + v_z²) / (2 · k_B · T)) dv_x dv_y dv_z [підстановка виразів для f₁(v_i)]
```

Щоб знайти розподіл за модулем швидкості `v`, перейдемо від декартових координат у просторі швидкостей до сферичних `(v, θ, φ)`:
- `v_x = v · sin(θ) · cos(φ)`
- `v_y = v · sin(θ) · sin(φ)`
- `v_z = v · cos(θ)`
- Елемент об'єму в сферичних координатах обчислюється через визначник матриці Якобі:
  `J = ∂(v_x, v_y, v_z) / ∂(v, θ, φ) = v² · sin(θ)`.
  Звідси `d³v = v² · sin(θ) dv dθ dφ`.
- Оскільки інтегранд не залежить від кутів `θ` та `φ` (через сферичну симетрію ізотропного газу), проінтегруємо за всім тілесним кутом: `∫₀²π dφ ∫₀π sin(θ) dθ = 4 · π`.

Отже, елемент об'єму сферичного шару радіуса `v` та товщини `dv` дорівнює `4 · π · v² dv`.

Множачи тривимірну щільність на площу сферичного шару `4 · π · v²`, одержуємо **функцію розподілу Максвелла за модулем швидкості**:

```
f(v) = 4 · π · (m / (2 · π · k_B · T))^(3/2) · v² · exp(-m · v² / (2 · k_B · T))
```

### 3. Метод 2: Обґрунтування через канонічний ансамбль Гіббса

У статистичній механіці канонічний ансамбль Гіббса визначає ймовірність знаходження системи у мікростані з енергією `E`:

```
dP = (1 / Z) · exp(-E / (k_B · T)) dΓ
```

Де `dΓ = d³r d³p / h³` — фазовий об'єм елементарного стану, а `Z` — статистична сума ансамблю.

Для одноатомного ідеального газу без зовнішнього поля потенціальна енергія дорівнює нулю, а енергія системи є чисто кінетичною: `E = p² / (2·m) = m·v² / 2`. Інтегрування за просторовими координатами `d³r` дає об'єм судини `V`, який скорочується при нормуванні.

Переходячи від імпульсу до швидкостей `p = m · v` (`d³p = m³ · d³v`), імовірність потрапляння вектора швидкості у сферичний шар `d³v = 4·π·v² dv` набуває вигляду:

```
dP(v) = C · exp(-m · v² / (2 · k_B · T)) · 4 · π · v² dv
```

Умова нормування `∫₀∞ dP(v) = 1` вимагає обчислення пуассонового інтеграла другого порядку:

```
∫₀∞ v² · exp(-a · v²) dv = (1 / 4) · √(π / a³)   [де a = m / (2 · k_B · T)]
```

Підставляючи значення `a`:

```
(1/4) · √(π / (m / (2 · k_B · T))³) = (1/4) · (2 · π · k_B · T / m)^(3/2) / √π
```

Звідси нормалізаційна константа `C` строго дорівнює `(m / (2 · π · k_B · T))^(3/2)`, що повністю підтверджує результат Максвелла.

### 4. Виведення характеристичних швидкостей та вищих моментів

Розподіл Максвелла є асиметричним, тому його центр, максимум та середній квадрат характеризуються трьома різними швидкостями.

Для зручності обчислення моментів розподілу введемо безрозмірну швидкість `u = v / v_p = v / √(2 · k_B · T / m)`. У цих безрозмірних змінних функція розподілу набуває універсальної форми:

```
f(u) du = (4 / √π) · u² · exp(-u²) du
```

Загальна формула для `n`-го моменту безрозмірної швидкості `⟨uⁿ⟩`:

```
⟨uⁿ⟩ = (4 / √π) · ∫₀∞ u^{n+2} · exp(-u²) du = (2 / √π) · Γ((n + 3) / 2)
```

Де `Γ(x)` — гамма-функція Ейлера, яка задовольняє співвідношення `Γ(x + 1) = x · Γ(x)` та `Γ(1/2) = √π`.

#### 1. Найімовірніша швидкість v_p (екстремум f(v))
Швидкість `v_p` відповідає екстремуму функції `f(v)`. Знайдемо першу похідну та прирівняємо її до нуля:

```
d/dv [v² · exp(-a · v²)] = 0                      [де a = m / (2 · k_B · T)]

2 · v · exp(-a · v²) + v² · (-2 · a · v) · exp(-a · v²) = 0

2 · v · exp(-a · v²) · (1 - a · v²) = 0
```

Для `v ≠ 0` та `v ≠ ∞` вираз у дужках дорівнює нулю:

```
1 - a · v_p² = 0

v_p² = 1 / a = (2 · k_B · T) / m

v_p = √(2 · k_B · T / m)                           [найімовірніша швидкість]
```

#### 2. Середня арифметична швидкість v_сер (перший момент ⟨v⟩)
Обчислимо математичне сподівання модуля швидкості:

```
v_сер = ∫₀∞ v · f(v) dv 
= 4 · π · (a / π)^(3/2) · ∫₀∞ v³ · exp(-a · v²) dv
```

Використовуємо табличний інтеграл `∫₀∞ x³ · exp(-a · x²) dx = 1 / (2 · a²)`:

```
∫₀∞ v³ · exp(-a · v²) dv = 1 / (2 · (m / (2 · k_B · T))²) = 2 · (k_B · T / m)²
```

Підставляємо у вираз для `v_сер`:

```
v_сер = 4 · π · (m / (2 · π · k_B · T))^(3/2) · 2 · (k_B · T / m)²
= 4 · (2 / π)^(1/2) · (k_B · T / m)^(1/2)
= √(8 · k_B · T / (π · m))                        [середня арифметична швидкість]
```

#### 3. Середня квадратична швидкість v_кв (другий момент ⟨v²⟩)
Обчислимо математичне сподівання квадрата швидкості:

```
⟨v²⟩ = ∫₀∞ v² · f(v) dv
= 4 · π · (a / π)^(3/2) · ∫₀∞ v⁴ · exp(-a · v²) dv
```

Використовуємо табличний інтеграл `∫₀∞ x⁴ · exp(-a · x²) dx = (3 / 8) · √(π / a⁵)`:

```
⟨v²⟩ = 4 · π · (a / π)^(3/2) · (3 / 8) · √(π / a⁵) [підстановка значення інтеграла за v⁴]
= (3 / 2) · (1 / a)                                [скорочення степенів a та числових множників]
= (3 / 2) · (2 · k_B · T / m)                     [підстановка a = m / (2 k_B T)]
= (3 · k_B · T) / m                                [скорочення двійки]
```

Беручи квадратний корінь, одержуємо середня квадратичну швидкість:

```
v_кв = √(⟨v²⟩) = √(3 · k_B · T / m)                 [середня квадратична швидкість]
```

#### 4. Обчислення кубічного моменту ⟨v³⟩
Кубічний момент швидкості використовується при розрахунках переносу кінетичної енергії молекулярними пучками через отвір (потік енергії ефузії):

```
⟨v³⟩ = ∫₀∞ v³ · f(v) dv 
= (4 / √π) · v_p³ · ∫₀∞ u⁵ · exp(-u²) du           [перехід до безрозмірної u = v / v_p]
= (4 / √π) · v_p³ · (1 / 2) · Γ(3)                 [інтеграл Ейлера, Γ(3) = 2! = 2]
= (4 / √π) · v_p³
= (8 / √π) · (k_B · T / m)^(3/2)                   [значення кубічного моменту]
```

#### 5. Четвертий момент ⟨v⁴⟩ та дисперсія кінетичної енергії
Четвертий момент швидкості дозволяє знайти дисперсію флуктуацій кінетичної енергії частинок `Var(E_k) = ⟨E_k²⟩ - ⟨E_k⟩²`:

```
⟨v⁴⟩ = (4 / √π) · v_p⁴ · ∫₀∞ u⁶ · exp(-u²) du = (15 / 4) · v_p⁴ = (15 / 4) · (2 · k_B · T / m)²
```

Звідси середня квадратична енергія `⟨E_k²⟩ = (1/4) · m² · ⟨v⁴⟩ = (15/4) · (k_B · T)²`.
Оскільки середня енергія `⟨E_k⟩ = (3/2) · k_B · T`, дисперсія флуктуацій енергії дорівнює:
```
Var(E_k) = (15/4) · (k_B · T)² - (9/4) · (k_B · T)² = (6/4) · (k_B · T)² = (3/2) · (k_B · T)²
```
Відносна флуктуація енергії однієї молекули становить `√(Var(E_k)) / ⟨E_k⟩ = √(2/3) ≈ 81.6%`, що ілюструє гігантську амплітуду мікроскопічного хаосу.

#### 6. Коефіцієнт скошеності (асиметрії) розподілу
Асиметрія кривої Максвелла характеризується коефіцієнтом скошеності (*skewness*):
```
γ₁ = ⟨(v - v_сер)³⟩ / (Var(v))^(3/2) = 2 · √2 · (4 - π) / (3 · π - 8)^(3/2) ≈ 0.4857
```
Додатний коефіцієнт скошеності `γ₁ > 0` математично підтверджує наявність довгого правого хвоста високих швидкостей.

### 5. Інтеграл накопиченої ймовірності та функція помилок (erf)

Ймовірність того, що швидкість молекули не перевищує певного граничного значення `v_max`, задається накопиченою функцією розподілу `F(v_max) = ∫₀^{v_max} f(v) dv`.

У безрозмірних змінних `u_max = v_max / v_p`:

```
F(u_max) = (4 / √π) · ∫₀^{u_max} u² · exp(-u²) du
```

Інтегруючи частинами (`udv = u · exp(-u²) du`):

```
F(u_max) = erf(u_max) - (2 / √π) · u_max · exp(-u_max²)
```

Де `erf(x) = (2 / √π) · ∫₀ˣ exp(-t²) dt` — класична функція помилок Гаусса.

Ряд Маклорена для функції помилок `erf(x)` дозволяє проводити чисельні розрахунки для малых значень `x`:
```
erf(x) = (2 / √π) · (x - x³/3 + x⁵/10 - x⁷/42 + ...)
```

Цей вираз дозволяє точно розраховувати частку молекул у будь-якому інтервалі швидкостей за допомогою стандартних математичних бібліотек.

Для асимптотичних випадків:
- При малих швидкостях (`u ≪ 1`): `F(u) ≈ (4 / (3 · √π)) · u³`.
- При великих швидкостях (`u ≫ 1`): `1 - F(u) ≈ (2 / √π) · u · exp(-u²)`.

### 6. Трансформація у розподіл за кінетичною енергією

Здійснимо заміну змінної від модуля швидкості `v` до кінетичної енергії `E = (1/2) · m · v²`.

Зв'язок змінних та їхніх диференціалів:

```
v = √(2 · E / m)

dv = (1 / √(2 · m · E)) dE
```

Закон збереження ймовірності вимагає рівності елементарних ймовірностей: `f_E(E) dE = f(v) dv`.

Підставляємо `v` та `dv` у формулу Максвелла:

```
f_E(E) dE 
= 4 · π · (m / (2 · π · k_B · T))^(3/2) · (2 · E / m) · exp(-E / (k_B · T)) · (1 / √(2 · m · E)) dE

f_E(E) = (2 / √π) · (1 / (k_B · T))^(3/2) · √E · exp(-E / (k_B · T))
```

#### Ключовий висновок:
Розподіл за кінетичною енергією `f_E(E)` **абсолютно не залежить від маси молекули `m`**. За даної температури `T` гази з різною молекулярною масою (наприклад, важкий ксенон та легкий гелій) мають тотожний розподіл кінетичної енергії частинок.
