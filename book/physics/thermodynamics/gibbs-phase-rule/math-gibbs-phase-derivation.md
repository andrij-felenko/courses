# 🧮 Термодинамічне виведення рівняння Гіббса-Дюгема та правила фаз

Рівняння Гіббса-Дюгема та правило фаз Гіббса базуються на фундаментальних термодинамічних властивостях вільної енергії Гіббса як однорідної функції першого ступеня від екстенсивних змінних системи. Нижче наведено математичне виведення термодинамічної рівноваги у багатокомпонентних багатофазних системах, умов термодинамічної стійкості фаз, геометричного методу дотичних, розрахунку бінодалей і спінодалей, фугітивності, активностей, ідеального й надлишкового змішування, осмотичного тиску та механізму виведення похідних співвідношень.

## 1. Співвідношення Ейлера та рівняння Гіббса-Дюгема

Розглянемо гомогенну фазу, яка містить `K` незалежних хімічних компонентів. Термодинамічний потенціал Гіббса `G` цієї фази є функцією температури `T`, тиску `P` та кількостей речовини компонентів `N[1], N[2], ..., N[K]`:

```
G = G(T, P, N[1], N[2], ..., N[K])
```

Оскільки енергія Гіббса є екстенсивною величиною, при збільшенні кількості всіх компонентів у `λ` разів за постійних температури `T` та тиску `P` значення `G` зростає рівно у `λ` разів:

```
G(T, P, λ·N[1], λ·N[2], ..., λ·N[K])
= λ · G(T, P, N[1], N[2], ..., N[K])     [однорідність першого ступеня за N[i]]
```

Диференціюючи цю рівність за параметром `λ` та покладаючи `λ = 1` за теоремою Ейлера про однорідні функції, отримуємо важливе інтегральне співвідношення для енергії Гіббса:

```
G = ∑ μ[i] · N[i]                       [інтегральна форма Гіббса, і від 1 до K]
```

де `μ[i] = (∂G / ∂N[i])[T, P, N[j≠i]]` визначається як хімічний потенціал `i`-го компонента у даній фазі.

Знайдемо повний диференціал виразу для `G`, розглядаючи і хімічні потенціали, і кількості речовини як змінні:

```
dG = ∑ μ[i]·dN[i] + ∑ N[i]·dμ[i]         [диференціювання добутку, і від 1 до K]
```

З іншого боку, з першого та другого законів термодинаміки випливає фундаментальне термодинамічне рівняння для диференціала вільної енергії Гіббса обраної фази:

```
dG = -S·dT + V·dP + ∑ μ[i]·dN[i]          [основне рівняння термодинаміки]
```

Прирівнюючи ці два незалежні вирази для диференціала `dG`, отримуємо рівняння Гіббса-Дюгема для гомогенної фази:

```
-S·dT + V·dP + ∑ μ[i]·dN[i]
= ∑ μ[i]·dN[i] + ∑ N[i]·dμ[i]             [прирівнювання двох виразів dG]

S·dT - V·dP + ∑ N[i]·dμ[i] = 0            [рівняння Гіббса-Дюгема для фази]
```

Розділивши це рівняння на повне число молей у фазі `N = ∑ N[i]`, запишемо його через інтенсивні мольні величини: мольну ентропію `s = S/N`, мольний об'єм `v = V/N` та мольні частки компонентів `x[i] = N[i]/N`:

```
s·dT - v·dP + ∑ x[i]·dμ[i] = 0            [мольна форма рівняння Гіббса-Дюгема]
```

Це рівняння показує, що інтенсивні параметри однієї фази (`T`, `P`, `μ[1], ..., μ[K]`) не є повністю незалежними: між їхніми змінами існує один суворий математичний зв'язок.

## 2. Підрахунок змінних та рівнянь для гетерогенної системи

Розглянемо гетерогенну систему, яка складається з `K` незалежних хімічних компонентів та `P` співіснуючих фаз. Для визначення стану такої системи потрібно підрахувати кількість незалежних змінних та кількість рівнянь термодинамічної рівноваги.

### Крок А: Підрахунок загальної кількості інтенсивних змінних

У кожній фазі `j` (де `j = 1, ..., P`) стан системи описується такими інтенсивними параметрами:
1. Загальна для всіх співіснуючих фаз температура `T` (1 змінна);
2. Загальний для всіх співіснуючих фаз тиск `P` (1 змінна);
3. Склад кожної фази `j`, який виражається `K` мольними частками `x[i]^(j)` (де `i = 1, ..., K`).

Оскільки сума мольних часток у кожній окремій фазі обов'язково дорівнює одиниці:

```
∑ x[i]^(j) = 1                           [умова нормування складу у фазі j]
```

кількість незалежних мольних часток у кожній окремій фазі дорівнює `(K - 1)`.

Отже, для `P` співіснуючих фаз загальне число незалежних інтенсивних змінних `N[var]` становить:

```
N[var] = 2 + P·(K - 1)                   [число інтенсивних змінних системи]
```

### Крок Б: Підрахунок термодинамічних рівнянь рівноваги

Умова термодинамічної рівноваги між `P` фазами вимагає рівності хімічних потенціалів кожного компонента `i` в усіх фазах системи:

```
μ[i]^(1) = μ[i]^(2) = ... = μ[i]^(P)     [умова хімічної рівноваги для i-го компонента]
```

Для одного конкретного компонента `i` ланцюжок з `P` рівних величин містить `(P - 1)` незалежних рівнянь зв'язку.

Оскільки в системі присутні `K` незалежних компонентів, загальне число незалежних рівнянь термодинамічної рівноваги `N[eq]` дорівнює:

```
N[eq] = K·(P - 1)                        [число незалежних рівнянь рівноваги]
```

### Крок В: Виведення числа ступенів вільності (правило Гіббса)

Число ступенів вільності (або варіантність системи `F`) виражається різницею між числом незалежних інтенсивних змінних та числом незалежних рівнянь рівноваги:

```
F = N[var] - N[eq]                       [означення варіантності системи]

F = [2 + P·(K - 1)] - K·(P - 1)          [підстановка N[var] та N[eq]]

F = 2 + P·K - P - K·P + K                [розкриття дужок]

F = K - P + 2                            [класичне правило фаз Гіббса]
```

Оскільки число ступенів вільності не може бути від'ємним (`F ≥ 0`), максимальне число співіснуючих фаз у рівноважній системі обмежене кількістю компонентів:

```
P[max] = K + 2                           [максимальне число співіснуючих фаз]
```

Для однокомпонентної системи (`K = 1`) максимальне число фаз дорівнює `P[max] = 3` (потрійна точка, де `F = 0`).

## 3. Функції змішування для ідеальних та надлишкових розчинів

Для аналізу фазових перетворень у багатокомпонентних розчинах обчислюють зміну термодинамічних потенціалів при змішуванні чистих компонентів.

Мольна ентропія змішування для ідеальної системи утворюється виключно внаслідок конфігураційної хаотизації молекул:

```
Δs[mix]^(id) = -R · ∑ x[i] · ln(x[i])   [ідеальна мольна ентропія змішування, і від 1 до K]
```

Оскільки мольна ентальпія змішування ідеального розчину дорівнює нулю (`Δh[mix]^(id) = 0`), мольна енергія Гіббса змішування ідеального розчину становить:

```
Δg[mix]^(id) = R·T · ∑ x[i] · ln(x[i])  [вільна енергія Гіббса ідеального змішування]
```

Для реальних розчинів виникає надлишкова вільна енергія Гіббса `g^(ex)`, яка виражає енергетичну нерівноцінність міжмолекулярних взаємодій `A-A`, `B-B` та `A-B`:

```
Δg[mix] = R·T · ∑ x[i] · ln(x[i]) + g^(ex) [повна мольна енергія змішування]
```

Хімічний потенціал кожного компонента реального розчину пов'язаний з надлишковою енергією через коефіцієнт активності `γ[i]`:

```
R·T · ln(γ[i]) = (∂(N · g^(ex)) / ∂N[i])[T, P, N[j≠i]] [коефіцієнт активності компонента]
```

## 4. Вираження хімічних потенціалів через фугітивність та активність

Для реальних реагуючих та багатофазних систем умови рівноваги хімічних потенціалів виражають через фугітивність `f[i]` (у газовій фазі) та термодинамічну активність `a[i]` (у конденсованих фазах).

Хімічний потенціал `i`-го компонента у реальному газі виражається через коефіцієнт фугітивності `ϕ[i]`:

```
μ[i]^(V) = μ[i]°(T) + R·T · ln(f[i])     [хімічний потенціал реального газу]

f[i] = ϕ[i] · y[i] · P                  [фугітивність компонента у суміші]
```

Для реального рідкого розчину хімічний потенціал визначається через коефіцієнт активності `γ[i]`:

```
μ[i]^(L) = μ[i]°(T, P) + R·T · ln(a[i])  [хімічний потенціал рідкої фази]

a[i] = γ[i] · x[i]                      [активність компонента у розчині]
```

Рівність хімічних потенціалів між рідкою та газовою фазами `μ[i]^(L) = μ[i]^(V)` перетвориться на суворе математичне рівняння фазової рівноваги рідина-пара (iso-fugacity condition):

```
γ[i] · x[i] · P[i]^(sat) · ϕ[i]^(sat) = ϕ[i]^(V) · y[i] · P [рівняння рідина-пара]
```

де `P[i]^(sat)` — тиск насиченої пари чистого компонента `i` при температурі `T`.

## 5. Мембранна рівновага та осмотичний тиск

Якщо дві рідкі фази розділені напівпроникною мембраною, яка пропускає лише розчинник (компонент 1) і є непроникною для розчиненої речовини (компонент 2), тиски у двох фазах у стані рівноваги виявляються неоднаковими: `P^(α) ≠ P^(β)`.

Умова рівноваги для розчинника через мембрану вимагає рівності хімічних потенціалів:

```
μ[1]^(α)(T, P^(α), x[1]^(α)) = μ[1]^(β)(T, P^(β), x[1]^(β)) [мембранна рівновага]
```

Нехай фаза `α` — чистий розчинник (`x[1]^(α) = 1`, тиск `P`), а фаза `β` — розчин з мольною часткою розчинника `x[1]` під тиском `P + Π`, де `Π` — осмотичний тиск.

Розкладаючи хімічний потенціал розчинника за тиском від `P` до `P + Π`:

```
μ[1]°(T, P + Π) + R·T · ln(x[1]) = μ[1]°(T, P) [рівність хімічних потенціалів]

μ[1]°(T, P + Π) - μ[1]°(T, P) = -R·T · ln(x[1]) [різниця потенціалів чистого розчинника]
```

Оскільки `(∂μ[1]° / ∂P) = v[1]` (мольний об'єм розчинника):

```
v[1] · Π = -R·T · ln(x[1])               [суворе точне рівняння осмотичного тиску]
```

Для розведеного розчину (`ln(x[1]) = ln(1 - x[2]) ≈ -x[2]`), отримуємо класичне рівняння Вант-Гоффа для осмотичного тиску:

```
Π = R·T · (x[2] / v[1]) = C[2] · R · T   [закон Вант-Гоффа для осмотичного тиску]
```

де `C[2] = x[2] / v[1]` — молярна концентрація розчиненої речовини. Наявність напівпроникної мембрани знімає умову механічної рівноваги тисків, додаючи один механічний ступінь вільності у вигляді осмотичного перепаду тиску `Π`.

## 6. Геометричний метод спільної дотичної до поверхонь вільної енергії

Мінімізація енергії Гіббса для двокомпонентної системи має просту та наочну геометричну інтерпретацію. Мольна енергія Гіббса фази `g(x)` є функцією мольної частки другого компонента `x`.

Для двох співіснуючих у рівновазі фаз `α` та `β` хімічні потенціали компонентів виражаються через мольну енергію Гіббса та її першу похідну:

```
μ[1] = g - x · (dg / dx)                 [хімічний потенціал першого компонента]

μ[2] = g + (1 - x) · (dg / dx)           [хімічний потенціал другого компонента]
```

Умови рівноваги `μ[1]^(α) = μ[1]^(β)` та `μ[2]^(α) = μ[2]^(β)` приводять до двох геометричних рівнянь:

```
(dg^(α) / dx)|x_α = (dg^(β) / dx)|x_β     [рівність нахилів дотичних]

g^(α)(x_α) - x_α · (dg^(α)/dx)|x_α
= g^(β)(x_β) - x_β · (dg^(β)/dx)|x_β     [рівність відрізків на осі ординат]
```

Це означає, що склади співіснуючих фаз `x[α]` та `x[β]` визначаються точками дотику спільної дотичної прямої до двох кривих мольної енергії Гіббса `g^(α)(x)` та `g^(β)(x)`. Тільки розчини зі складами між `x[α]` та `x[β]` розшаровуються на дві фази, оскільки сумарна вільна енергія суміші на спільній дотичній є нижчою, ніж вільна енергія будь-якої однорідної фази.

## 7. Модель регулярного розчину: розрахунок бінодалі та спінодалі

Розглянемо симетричний двокомпонентний регулярний розчин, у якому надлишкова вільна енергія Гіббса виражається через енергетичний параметр взаємодії компонентів `Ω`:

```
g(x) = (1 - x)·g[1]° + x·g[2]° + R·T·[x·ln(x) + (1 - x)·ln(1 - x)] + Ω·x·(1 - x)
```

де перший доданок описує ідеальне змішування, а доданок `Ω·x·(1 - x)` виражає відхилення від ідеальності.

### Крок А: Розрахунок бінодалі (лінії фазового розшарування)

Точки бінодалі визначають межу термодинамічної рівноваги між двома розшарованими рідкими розчинами. Внаслідок симетрії системи склади співіснуючих фаз `x[1]` та `x[2]` задовольняють умову `x[2] = 1 - x[1]`.

Рівність хімічних потенціалів компонента у двох фазах приводить до рівняння бінодалі:

```
R·T · ln(x / (1 - x)) + Ω · (1 - 2·x) = 0 [рівняння бінодалі для регулярного розчину]
```

Критична температура розшарування (верхня критична температура розчинності `T[c]`) досягається в точці `x = 0.5`:

```
T[c] = Ω / (2 · R)                       [критична температура розшарування]
```

При температурах `T < T[c]` виникає область фазового розшарування з двома співіснуючими рідкими розчинами.

### Крок Б: Розрахунок спінодалі (межі абсолютної нестійкості)

Спінодаль визначає межу термодинамічної стійкості однорідного розчину відносно нескінченно малих флуктуацій складу. Рівняння спінодалі виражається рівністю нулю другої похідної мольної енергії Гіббса:

```
(∂²g / ∂x²) = R·T / (x·(1 - x)) - 2·Ω = 0 [умова спінодалі]

T[spin](x) = (2·Ω / R) · x · (1 - x)     [температура спінодалі від складу]
```

У критичній точці `x = 0.5` температура спінодалі збігається з критичною температурою бінодалі `T[spin](0.5) = T[c] = Ω / (2R)`. Область між бінодаллю та спінодаллю є метастабільною (розпад вимагає подолання енергетичного бар'єра зародкоутворення), а область усередині спінодалі є абсолютно нестійкою (перебігає самочинний спінодальний розпад).

## 8. Виведення законів Коновалова для бінарних рідко-парових систем

Закони Коновалова описують зв'язок між зміною складу фаз та тиском насиченої пари або температурою кипіння бінарного розчину.

Запишемо рівняння Гіббса-Дюгема для рідкої фази `L` та газової фази `V` при постійній температурі (`dT = 0`):

```
v^(L)·dP = x[1]^(L)·dμ[1] + x[2]^(L)·dμ[2] [рівняння Гіббса-Дюгема для рідини]

v^(V)·dP = x[1]^(V)·dμ[1] + x[2]^(V)·dμ[2] [рівняння Гіббса-Дюгема для пари]
```

Виразивши `dμ[1]` через `dμ[2]` з першого рівняння та підставивши у друге, отримуємо співвідношення між зміною тиску `dP` та хімічного потенціалу:

```
(v^(V) - v^(L)) · dP
= (x[2]^(V) - x[2]^(L)) · (dμ[2] - dμ[1])  [основне співвідношення випаровування]
```

Оскільки `(dμ[2] - dμ[1]) / dx[2]^(L) > 0` внаслідок умов термодинамічної стійкості рідкої фази, отримуємо перший закон Коновалова:

```
dP / dx[2]^(L) > 0  <=>  x[2]^(V) > x[2]^(L) [перший закон Коновалова]
```

Пара збагачується тим компонентом, додавання якого до рідкої фази збільшує загальний тиск насиченої пари (або знижує температуру кипіння розчину).

Якщо тиск пара досягає екстремуму (`dP / dx[2]^(L) = 0`), з вищезазначеного рівняння безпосередньо випливає другий закон Коновалова:

```
x[2]^(V) = x[2]^(L)                      [другий закон Коновалова, точка азеотропу]
```

У точках екстремуму тиску пари (азеотропних сумішах) склад пари тотожно збігається зі складом рідини, а система поводиться подібно до однокомпонентної речовини з одною ступенем вільності при фіксованому тиску (`F = 1`).

## 9. Виведення рівняння Клапейрона-Клаузіуса з умов рівноваги

Розглянемо двофазну систему з одного компонента (`K = 1`, `P = 2`, наприклад, рідина та пара). Число ступенів вільності дорівнює `F = 1 - 2 + 2 = 1` (система моноваріантна). Це означає, що тиск насиченої пари є однозначною функцією температури `P = P(T)`.

Для двох співіснуючих фаз `α` та `β` умова рівноваги має вигляд:

```
μ^(α)(T, P) = μ^(β)(T, P)                 [рівність хімічних потенціалів]
```

При зміні температури на `dT` тиск змінюється на `dP` вздовж лінії рівноваги так, щоб хімічні потенціали фаз залишалися рівними:

```
dμ^(α) = dμ^(β)                          [умова збереження рівноваги]
```

Використовуючи рівняння Гіббса-Дюгема для одного моля чистої речовини у кожній фазі (`dμ = -s·dT + v·dP`):

```
-s^(α)·dT + v^(α)·dP = -s^(β)·dT + v^(β)·dP  [підстановка dμ для обох фаз]

(v^(β) - v^(α)) · dP = (s^(β) - s^(α)) · dT  [перегрупування доданків]

dP / dT = Δs / Δv                        [похідна тиску за температурою]
```

Оскільки фазовий перехід супроводжується мольною теплотою переходу `L = T · Δs`:

```
dP / dT = L / (T · (v^(β) - v^(α)))     [рівняння Клапейрона-Клаузіуса]
```

Це рівняння математично описує нахил моноваріантних ліній `F = 1` на фазовій діаграмі `P-T`.

## 10. Математичне виведення правила важеля для двофазних областей

У двокомпонентній двофазній системі (`K = 2`, `P = 2`, наприклад, рідкий розчин `L` та тверда фаза `α`) при фіксованій температурі та тиску склад кожної з фаз є строго визначеним (`x[L]` та `x[α]`). Загальний склад системи `x[0]` описується масовим балансом.

Нехай `n[L]` та `n[α]` — мольні частки рідкої та твердої фаз у системі (`n[L] + n[α] = 1`). Збереження кількості речовини компонента додає рівняння:

```
x[0] = n[L]·x[L] + n[α]·x[α]             [баланс кількості речовини]

x[0] = n[L]·x[L] + (1 - n[L])·x[α]        [заміна n[α] = 1 - n[L]]

x[0] - x[α] = n[L] · (x[L] - x[α])       [перегрупування доданків]

n[L] = (x[0] - x[α]) / (x[L] - x[α])     [відносна частка рідкої фази]
```

Аналогічно для твердої фази `α`:

```
n[α] = (x[L] - x[0]) / (x[L] - x[α])     [відносна частка твердої фази]
```

Співвідношення кількостей співіснуючих фаз визначається правилом важеля:

```
n[L] / n[α] = (x[0] - x[α]) / (x[L] - x[0]) [правило важеля]
```

Відношення мольних часток фаз дорівнює оберненому відношенню довжин відрізків на ноді (ізотермічному відрізку між складами співіснуючих фаз).

## 11. Врахування хімічних реакцій та матричного рангу

Якщо у системі між `N[spec]` хімічними речовинами перебігають хімічні реакції, хімічні потенціали пов'язані співвідношеннями хімічної рівноваги.

Нехай `A` — матриця стехіометричних коефіцієнтів розміром `R[tot] × N[spec]`, де кожний рядок відповідає хімічній реакції. Кількість термодинамічно незалежних хімічних реакцій `R` дорівнює рангу цієї матриці:

```
R = rank(A)                              [число незалежних хімічних реакцій]
```

Якщо на систему додатково накладено `q` лінійно незалежних початкових концентраційних обмежень (наприклад, рівність молярностей продуктів при дисоціації `NH4Cl(s) ⇌ NH3(g) + HCl(g)`), число незалежних компонентів `K` обчислюється як:

```
K = N[spec] - R - q                      [число незалежних компонентів Гіббса]
```

Тоді узагальнена варіантність реагуючої системи становить:

```
F = (N[spec] - R - q) - P + 2            [узагальнена варіантність системи]
```

## 12. Теорема Дюгема для закритих багатокомпонентних систем

Видатний французький фізик П'єр Дюгем сформулював важливе доповнення до правила фаз Гіббса для закритих систем. Теорема Дюгема стверджує:

Для закритої гетерогенної системи відомого початкового складу (із заданими масами або мольними кількостями `N[1]^(0), ..., N[K]^(0)` усіх компонентів), перебування у стані рівноваги повністю визначається заданням рівно двох незалежних інтенсивних або екстенсивних змінних (наприклад, `T` та `P`, або `T` та `V`, або `H` та `P`), незалежно від кількості співіснуючих фаз `P`.

Це пояснюється тим, що при заданих початкових масах компонентів додатково виникають `(K - 1)·P` рівнянь матеріального балансу між масами фаз та їхніми складами, що точно компенсує втрату інтенсивних ступенів вільності при збільшенні числа фаз `P`.

## 13. Термодинамічна стійкість фаз та гесіан вільної енергії

Термодинамічна стійкість гомогенної фази відносно малих флуктуацій складу вимагає додатної визначеності квадратичної форми другої варіації вільної енергії Гіббса `δ²G > 0`. Це еквівалентно умові, що матриця Гессе (гесіан) `H` других похідних від `G` за мольними частками компонентів є додатновизначеною:

```
H[i, j] = (∂²G / ∂N[i] ∂N[j])[T, P] > 0   [умова термодинамічної стійкості]
```

Для двокомпонентної системи умова стійкості фази зводиться до нерівності:

```
(∂²G / ∂x²)[T, P] > 0                   [критерій стійкості двокомпонентної фази]
```

У точках, де друга похідна дорівнює нулю `(∂²G / ∂x²)[T, P] = 0`, фаза втрачає стійкість відносно безбар'єрного розпаду. Геометричне місце таких точок визначає лінію спінодалі, за якою відбувається спінодальний розпад однорідного розчину на дві співіснуючі фази.

## 14. Конденсовані системи та зовнішні фізичні поля

Для ізобарних процесів або конденсованих систем (тверді тіла та рідини при атмосферному тиску), де вплив тиску на фазові рівноваги знехтовно малий (`dP ≈ 0`), параметр тиску `P` вилучається з числа інтенсивних змінних. Число ступенів вільності зменшується на одиницю:

```
F[cond] = K - P + 1                      [приведене правило фаз для конденсованих систем]
```

Якщо система перебуває у зовнішніх фізичних полях (електричному, магнітному, гравітаційному), кожне додаткове незалежне поле додає один інтенсивний параметр (наприклад, напруженість електричного поля `E` або магнітного поля `H`), що збільшує число ступенів вільності:

```
F[ext] = K - P + 2 + m                   [правило фаз у m зовнішніх полях]
```

Ці виведення підтверджують математичну строгість термодинамічного формалізму Гіббса та свідчать про його універсальність для фізико-хімічного аналізу гетерогенних систем.
