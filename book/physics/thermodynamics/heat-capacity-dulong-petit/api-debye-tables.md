# 📋 Довідкові параметри кристалів та температурні межі застосовності

Зведені таблиці експериментальних фізичних параметрів містять характеристичні температури Дебая `Θ_D`, температури Ейнштейна `Θ_E`, коефіцієнти електронної теплоємності Зоммерфельда `γ`, швидкість поширення акустичних хвиль, а також температурні критерії застосовності класичного закону Дюлонга — Пті в інженерній практиці для простих речовин, металів, напівпровідників та сполук.

## 1. Довідкові температури Дебая та Ейнштейна для простих елементів

Характеристична температура Дебая `Θ_D` визначає верхню межу фононного спектра кристала. Вона є фундаментальним параметром речовини, який залежить від маси атомів, жорсткості міжатомних зв'язків та густини кристалічної ґратки. Матеріали з сильними ковалентними зв'язками та малими атомними масами (наприклад, алмаз або берилій) мають високі значення `Θ_D`, тоді як важкі метали з м'якими зв'язками (свинець, золото) мають низькі значення `Θ_D`.

Температура Ейнштейна `Θ_E` відповідає серединній частоті оптичних коливань або ефективній частоті локалізованих модальних осциляторів. У наближенні зв'язку між моделями температура Ейнштейна зазвичай дорівнює приблизно `0.75 Θ_D`.

### Детальний фізичний аналіз довідкових параметрів елементів:

1. **Аномалія алмазу та легких ковалентних кристалів**:
   Температура Дебая алмазу (`2230 K`) значно перевищує кімнатну температуру (`300 K`). Це означає, що при `300 K` безрозмірний параметр `T / Θ_D ≈ 0.13`, що відповідає глибокому квантовому регіону виморожування мод. Саме тому теплоємність алмазу при кімнатній температурі становить лише `6.12 Дж/(моль·К)`, що становить менше чверті від класичної границі Дюлонга — Пті (`3R ≈ 24.94 Дж/(моль·К)`).
   
2. **Важкі метали з м'якою ґраткою (Pb, Au, Ag)**:
   Для свинцю `Θ_D = 105 K`. За кімнатної температури `T / Θ_D ≈ 2.86 ≫ 1`, тому закон Дюлонга — Пті виконується для свинцю з високою точністю вже за `300 K` (`26.44 Дж/(моль·К)` з урахуванням незначного електронного та ангармонічного внеску).

3. **Залежність від швидкості звуку у середовищі**:
   Оскільки частота Дебая безпосередньо пропорційна середній швидкості звуку у кристалі `ω_D ~ v`, матеріали з високою швидкістю звуку (алмаз `12000 м/с`, берилій `12890 м/с`) мають високу межу спектра і потребують високих температур для виходу на класичне насичення.

## 2. Електронний внесок у теплоємність металів (Коефіцієнти Зоммерфельда)

У металевих провідниках поруч із фононними коливаннями кристалічної ґратки існує газ вільних електронів провідності. Відповідно до квантової теорії металів Зоммерфельда, лише ті електрони, які знаходяться в межах теплового розмиття поверхні Фермі (`k_B T` біля `E_F`), можуть брати участь у тепловому русі. Це приводить до строго лінійного за температурою внеску в молярну теплоємність:

```
C_el = γ · T
```

де `γ` — коефіцієнт електронної теплоємності Зоммерфельда, який прямо пропорційний ефективній масі електронного стану та щільності електронних станів на рівні Фермі `g(E_F)`:

```
γ = (1/3) π² k_B² g(E_F)
```

Загальна молярна теплоємність металу в кріогенному діапазоні температур являє собою суму електронного та фононного доданків:

```
C_v = C_el + C_ph = γ · T + A · T³
```

де `A = (12 π⁴ / 5) R / Θ_D³` — коефіцієнт закону кубу Дебая.

Нижче наведено експериментальні значення коефіцієнтів Зоммерфельда `γ` та фононних коефіцієнтів `A` для основних металів:

| Метал | Символ | Коефіцієнт Зоммерфельда γ (мДж/(моль·К²)) | Фононний коефіцієнт A (мДж/(моль·К⁴)) | Температура кросовера T_crossover (K) | Електронна частка при 1 K (%) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| Мідь | Cu | 0.695 | 0.0476 | 3.82 | 93.6% |
| Срібло | Ag | 0.646 | 0.1700 | 1.95 | 79.2% |
| Золото | Au | 0.729 | 0.4570 | 1.26 | 61.5% |
| Алюміній | Al | 1.350 | 0.0246 | 7.41 | 98.2% |
| Залізо | Fe | 4.980 | 0.0197 | 15.89 | 99.6% |
| Натрій | Na | 1.380 | 0.4900 | 1.68 | 73.8% |
| Свинець | Pb | 2.980 | 3.0300 | 0.99 | 49.6% |
| Нікель | Ni | 7.020 | 0.0174 | 20.08 | 99.8% |
| Платина | Pt | 6.800 | 0.0630 | 10.39 | 99.1% |

### Поняття та фізичний зміст температури кросовера `T_crossover`:

Температура кросовера `T_crossover` визначає точну межу, при якій лінійний електронний внесок дорівнює кубічному фононному внеску:

```
γ · T_crossover = A · T_crossover³   ⇒   T_crossover = √(γ / A)
```

При температурах `T < T_crossover` (для більшості провідників це діапазон `1...15 K`) електронна теплоємність превалює над теплоємністю кристалічної ґратки. Якщо побудувати експериментальний графік залежності `C_v / T` від `T²`, отримаємо пряму лінію з нахилом `A` та відрізком `γ` на осі ординат, що є стандартним методом експериментального розділення електронного та фононного внесків.

## 3. Критерії та межі застосовності закону Дюлонга — Пті в інженерії

У теплофізичному проектуванні та інженерних розрахунках закон Дюлонга — Пті застосовується для швидкої оцінки теплоємності конструкційних матеріалів при помірних та підвищених температурах без складних чисельних обчислень.

### Критерії похибки класичного закону Дюлонга — Пті:

1. **Верхня температурна межа (Відхилення від `3R` при високих температурах)**:
   При високих температурах (`T > Θ_D`) молярна теплоємність реальних матеріалів починає **перевищувати** класичне значення `3R`. Це зумовлено трьома основними фізичними ефектами:
   - **Ангармонізм коливань**: при зростанні амплітуди коливань атомів міжатомний потенціал відхиляється від симетричної параболи, створюючи додатковий додатний внесок у теплоємність.
   - **Термічні вакансії**: теплова генерація точкових дефектів (дефектів Шотткі та Френкеля) вимагає витрат енергії на розрив міжатомних зв'язків.
   - **Різниця між `C_p` та `C_v`**: вимірювання зазвичай проводять при постійному тиску (`C_p`). Зв'язок задається формулою Термодинаміки `C_p - C_v = α² V T / B_T` (де `α` — коефіцієнт об'ємного розширення, `B_T` — модуль ізотермічного стиску). При високих температурах ця різниця досягає `10...20%`.

2. **Нижня температурна межа**:
   Закон Дюлонга — Пті можна застосовувати з інженерною похибкою не більше `5%`, якщо виконується умова:

```
T ≥ 1.2 · Θ_D
```

   Для інженерної похибки не більше `1%` потрібна умова:

```
T ≥ 2.0 · Θ_D
```

Нижче наведено зведену таблицю температурних меж застосовності закону Дюлонга — Пті для практичних конструкційних матеріалів:

| :--- | :---: | :---: | :---: | :--- |
| Свинець (Pb) | 105 | 126 K (-147 °C) | 210 K (-63 °C) | Відмінно (похибка < 1%) |
| Мідь (Cu) | 343 | 412 K (+139 °C) | 686 K (+413 °C) | Задовільно (похибка ~6%) |
| Залізо (Fe) | 470 | 564 K (+291 °C) | 940 K (+667 °C) | Обмежено (похибка ~15%) |
| Алюміній (Al) | 428 | 514 K (+241 °C) | 856 K (+583 °C) | Обмежено (похибка ~12%) |
| Кремній (Si) | 645 | 774 K (+501 °C) | 1290 K (+1017 °C) | Непридатний (похибка ~20%) |

## 4. Довідкові параметри неорганічних сполук та складних кристалів

Для складних багатоатомних кристалів із `p` атомами у хімічній формулі або елементарній комірці класична гранична теплоємність за правило Неймана — Коппа узагальнює закон Дюлонга — Пті:

```
C_v = 3 · p · R
```

У фононній теорії такі сполуки мають `3` акустичні гілки (описуються моделлю Дебая) та `3p - 3` оптичні гілки (описуються моделлю Ейнштейна).

### Інженерні висновки для складних сполук:
Для матеріалів з високою жорсткістю та тугоплавкістю (наприклад, корунд `Al2O3`, оксид магнію `MgO` або карбід кремнію `SiC`) температура Дебая перевищує `900...1200 K`. Для цих матеріалів кімнатна теплоємність становить менше `60%` від граничного значення `3pR`. Нехтування квантовим виморожуванням фононів у таких матеріалах приводить до істотних помилок при проектуванні теплових бар'єрів, ізоляторів та силової електронної кераміки.
