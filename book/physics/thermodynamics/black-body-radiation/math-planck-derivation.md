# 🧮 Математичне виведення закону Планка та граничних інтегралів

Строге математичне виведення густини стоячих хвиль у замкненій порожнині, середньої енергії квантового гармонічного осцилятора, а також аналітичне обчислення граничних виразів, константи Стефана-Больцмана через дзета-функцію Рімана та трансцендентного рівняння для закону зсуву Віна.

---

## 1. Геометричний підрахунок густини мод у тривимірному об'ємі

Для знаходження спектрального розподілу електромагнітного випромінювання у замкненому об'ємі спочатку потрібно обчислити кількість можливих типів коливань (стоячих хвиль або мод) у заданому інтервалі частот.

Розглянемо замкнену порожнину у формі прямокутного паралелепіпеда з розмірами `L_x`, `L_y`, `L_z` та дзеркальними провідними стінками. Електромагнітні хвилі у такій порожнині утворюють стоячі хвилі, на межах яких напруженість електричного поля дорівнює нулю. Це означає, що на кожному з ребер порожнини повинно вкладатися ціле число півхвиль. Компоненти хвильового вектора `k = (k_x, k_y, k_z)` підпорядковуються граничним умовам:

```
k_x = n_x · π / L_x
k_y = n_y · π / L_y
k_z = n_z · π / L_z
```

де `n_x, n_y, n_z = 1, 2, 3, ...` — додатні цілі числа, що задають вузли стоячої хвилі.

У фазовому просторі хвильових векторів `k` кожному допустимому квантовому стану відповідає комірка з елементарним об'ємом:

```
ΔV_k = (π / L_x) · (π / L_y) · (π / L_z) = π³ / V
```

де `V = L_x · L_y · L_z` — фізичний об'єм порожнини.

Оскільки числа `n_x, n_y, n_z` є строго додатними, розглядати слід лише один октант (восьму частину) сферичного шару радіуса `k = |k|` та товщини `dk`. Кількість можливих станів `dN_k` у сферичному шарі від `k` до `k + dk` з урахуванням двох незалежних поперечних поляризацій світла (множник `2`) виражається як:

```
dN_k = 2 · (1 / 8) · (4 · π · k² dk / (π³ / V))
```

Поділивши кількість станів `dN_k` на об'єм порожнини `V`, отримуємо концентрацію мод у просторі хвильових векторів:

```
dn_k = dN_k / V = (k² / π²) dk
```

Для переходу до звичайної частоти `ν` скористаємося зв'язком між хвильовим числом та частотою світла у вакуумі: `k = 2 · π · ν / c` та `dk = (2 · π / c) dν`. Підставляючи ці вирази у формулу для `dn_k`:

```
g(ν) dν = ( (2·π·ν/c)² / π² ) · (2·π dν / c)
        = (8 · π · ν² / c³) dν
```

**Функція `g(ν) = 8 · π · ν² / c³` визначає спектральну густину мод (кількість електромагнітних коливань на одиницю об'єму в одиничному інтервалі частот).**

Спектральна густина мод залежить виключно від квадрата частоти `ν²` та швидкості світла `c` і не залежить від форми порожнини.

## 2. Квантово-статистичний розрахунок середньої енергії осцилятора

У класичній статистичній механіці енергія осцилятора `E` вважається безперервною величиною, яка може набувати будь-яких невід'ємних значень. Середня енергія осцилятора за канонічним розподілом Больцмана обчислюється через інтеграли:

```
<E_class> = ∫₀^∞ E · exp(-E / (k_B · T)) dE / ∫₀^∞ exp(-E / (k_B · T)) dE
          = k_B · T
```

Множення класичної середньої енергії `<E_class> = k_B · T` на густину мод `g(ν)` дає класичний закон Релея-Джинса `u(ν, T) = (8 · π · ν² / c³) · k_B · T`, який розходиться при `ν → ∞` (ультрафіолетова катастрофа).

Згідно з квантовою гіпотезою Планка, енергія атомарного осцилятора частоти `ν` не може бути довільною, а є дискретизованою: `E_n = n · h · ν`, де `n = 0, 1, 2, ...` — ціле число квантів.

Обчислимо середнє значення енергії квантового осцилятора за канонічним розподілом Больцмана:

```
<E> = ∑_{n=0}^∞ E_n · exp(-E_n / (k_B · T)) / ∑_{n=0}^∞ exp(-E_n / (k_B · T))
```

Введемо безрозмірний параметр `x = h · ν / (k_B · T)`. Тоді вираз для середньої енергії спрощується до вигляду:

```
<E> = h · ν · ( ∑_{n=0}^∞ n · exp(-n · x) / ∑_{n=0}^∞ exp(-n · x) )
```

Обчислимо окремо знаменник `Z` (статистичну суму осцилятора). Вона являє собою нескінченно спадну геометричну прогресію зі знаменником `q = exp(-x) < 1`:

```
Z = ∑_{n=0}^∞ exp(-n · x) = 1 / (1 - exp(-x))
```

Чисельник можна подати як мінус похідну від статистичної суми `Z` за зміною параметра `x`:

```
∑_{n=0}^∞ n · exp(-n · x) = - dZ / dx
                          = d/dx [ (1 - exp(-x))⁻¹ ]
                          = exp(-x) / (1 - exp(-x))²
```

Поділивши чисельник на знаменник `Z`, отримуємо exact середнє значення:

```
<E> = h · ν · ( exp(-x) / (1 - exp(-x)) )
    = h · ν / (exp(x) - 1)                 [ділення чисельника та знаменника на exp(-x)]
    = h · ν / (exp(h · ν / (k_B · T)) - 1)  [підстановка x = h·ν / (k_B·T)]
```

**Головний фізичний наслідок:** при низьких частотах (`h·ν ≪ k_B·T`) розклад експоненти дає `<E> ≈ k_B·T` (класичний результат). Проте при високих частотах (`h·ν ≫ k_B·T`) величина `exp(h·ν / k_B·T)` зростає надзвичайно стрімко, і середня енергія експоненційно згасає до нуля. Це відсікає високочастотний внесок і повністю усуває ультрафіолетову катастрофу.

## 3. Математичне формування формул закону Планка

Множачи спектральну густину мод `g(ν)` на середню квантову енергію однієї моди `<E>`, отримуємо **закон Планка для спектральної об'ємної густини енергії випромінювання**:

```
u(ν, T) = g(ν) · <E>
        = (8 · π · h · ν³ / c³) · 1 / (exp(h · ν / (k_B · T)) - 1)
```

Для багатьох практичних застосувань потрібен розподіл енергії не за частотою `ν`, а за довжиною хвилі `λ`. Оскільки енергія у відповідних спектральних інтервалах має бути однаковою, виконується умова `u(λ, T) |dλ| = u(ν, T) |dν|`.

Зважаючи на те, що `ν = c / λ` та `|dν / dλ| = c / λ²`:

```
u(λ, T) = u(ν, T) · |dν / dλ|              [зв'язок спектральних густин]
        = (8 · π · h · (c/λ)³ / c³) · (1 / (exp(h · c / (λ · k_B · T)) - 1)) · (c / λ²)  [підстановка ν = c/λ та |dν/dλ| = c/λ²]
        = (8 · π · h · c / λ⁵) · 1 / (exp(h · c / (λ · k_B · T)) - 1)  [спрощення степенів λ та c]
```

Спектральна випромінювальна здатність поверхні чорного тіла `R(λ, T)` пов'язана з об'ємною густиною енергії співвідношенням `R(λ, T) = (c / 4) · u(λ, T)`:

```
R(λ, T) = (2 · π · h · c² / λ⁵) · 1 / (exp(h · c / (λ · k_B · T)) - 1)
```

## 4. Аналітичне інтегрування спектра та вивід закону Стефана-Больцмана

Повна (інтегральна) випромінювальна здатність чорного тіла `R(T)` дорівнює визначеному інтегралу від спектральної функції `R(λ, T)` по всьому інтервалу довжин хвиль від `0` до `∞`:

```
R(T) = ∫₀^∞ R(λ, T) dλ
     = ∫₀^∞ (2 · π · h · c² / λ⁵) · (1 / (exp(h · c / (λ · k_B · T)) - 1)) dλ
```

Для обчислення цього інтеграла виконаємо заміну змінної:

```
x = h · c / (λ · k_B · T)
```

Звідси виражаємо довжину хвилі та її диференціал:

```
λ = h · c / (k_B · T · x)
dλ = - (h · c / (k_B · T · x²)) dx
```

При зміні `λ` від `0` до `∞` безрозмірна змінна `x` змінюється від `∞` до `0`. Підставляючи ці вирази в інтеграл та виносячи сталі множники за знак інтеграла:

```
R(T) = ∫₀^∞ (2 · π · h · c²) · ( (k_B · T · x / (h · c))⁵ ) · (1 / (exp(x) - 1)) · (h · c / (k_B · T · x²)) dx
     = (2 · π · k_B⁴ · T⁴ / (h³ · c²)) · ∫₀^∞ (x³ / (exp(x) - 1)) dx
```

Позначимо визначений інтеграл через `I = ∫₀^∞ (x³ / (exp(x) - 1)) dx`. Для його строгого обчислення розкладемо підінтегральний дріб у нескінченний ряд за показниковою функцією:

```
1 / (exp(x) - 1) = exp(-x) / (1 - exp(-x))
                 = ∑_{n=1}^∞ exp(-n · x)
```

Завдяки рівномірній збіжності ряду міняємо місцями інтегрування та підсумовування:

```
I = ∑_{n=1}^∞ ∫₀^∞ x³ · exp(-n · x) dx
```

Здійснюючи заміну `u = n · x` (`dx = du / n`), кожен доданок перетворюється на:

```
∫₀^∞ x³ · exp(-n · x) dx = (1 / n⁴) · ∫₀^∞ u³ · exp(-u) du
```

Визначений інтеграл `∫₀^∞ u³ · exp(-u) du` дорівнює значенням ейлерової гамма-функції `Γ(4) = 3! = 6`. 
Сума ряду `∑_{n=1}^∞ (1 / n⁴)` являє собою значення дзета-функції Рімана `ζ(4) = π⁴ / 90`.

Таким чином:

```
I = 6 · ζ(4)           [значення гамма-функції Γ(4) = 6]
  = 6 · (π⁴ / 90)      [значення дзета-функції Рімана ζ(4) = π⁴ / 90]
  = π⁴ / 15            [скорочення 6 / 90 = 1 / 15]
```

Підставляючи значення інтеграла `I = π⁴ / 15` у формулу для `R(T)`:

```
R(T) = (2 · π · k_B⁴ · T⁴ / (h³ · c²)) · (π⁴ / 15)  [підстановка значення інтеграла I = π⁴ / 15]
     = (2 · π⁵ · k_B⁴ / (15 · c² · h³)) · T⁴         [перемноження констант]
     = σ · T⁴                                        [означення константи Стефана-Больцмана σ]
```

де константа Стефана-Больцмана `σ` виражається комбінацією фундаментальних фізичних сталих:

```
σ = 2 · π⁵ · k_B⁴ / (15 · c² · h³) ≈ 5.6703744 × 10⁻⁸ Вт / (м² · К⁴)
```

## 5. Знаходження максимуму спектра та закон зсуву Віна

Для обчислення довжини хвилі `λ_max`, на якій спектральна випромінювальна здатність досягає свого абсолютного максимуму, знайдемо точку екстремуму функції `R(λ, T)` шляхом диференціювання за `λ` та прирівняння похідної до нуля.

Враховуючи заміни `x = h · c / (λ · k_B · T)`, спектральну функцію `R(λ, T)` можна записати у вигляді:

```
R(λ, T) = C · T⁵ · (x⁵ / (exp(x) - 1))
```

Оскільки `x ∝ 1 / λ`, умовою максимуму `dR / dλ = 0` є прирівняння до нуля похідної за `x`:

```
d/dx [ x⁵ / (exp(x) - 1) ] = 0
```

Застосовуючи правило диференціювання частки:

```
(5 · x⁴ · (exp(x) - 1) - x⁵ · exp(x)) / (exp(x) - 1)² = 0
```

Оскільки `x ≠ 0`, скорочуємо чисельник на `x⁴ · (exp(x) - 1)`:

```
5 · (exp(x) - 1) - x · exp(x) = 0
```

Поділивши обидві частини рівняння на `exp(x)`, отримуємо **трансцендентне рівняння закону Віна**:

```
5 · (1 - exp(-x)) = x
```

Це рівняння не розв'язується в аналітичних елементарних функціях. Застосуємо метод Ньютона-Рафсона для знаходження точного чисельного значення кореня. Записуємо функцію `f(x) = 5 · (1 - exp(-x)) - x` та її похідну `f'(x) = 5 · exp(-x) - 1`.

Ітераційна формула Ньютона:

```
x_{n+1} = x_n - f(x_n) / f'(x_n)
```

Вибираючи початкове наближення `x₀ = 5.0`, обчислюємо послідовні ітерації:
- `x₀ = 5.00000000`
- `x₁ = 4.96515574`
- `x₂ = 4.96511424`
- `x₃ = 4.9651142317`

Корінь збігається з високою точністю до значення `x_max ≈ 4.9651142317`.

Повертаючись до початкових фізичних змінних `x_max = h · c / (λ_max · k_B · T)`:

```
λ_max · T = h · c / (k_B · x_max) = b
```

Обчислимо числове значення сталої зсуву Віна `b`:

```
b = (6.62607015 × 10⁻³⁴ · 2.99792458 × 10⁸) / (1.380649 × 10⁻²³ · 4.9651142317)
  ≈ 2.897771955 × 10⁻³ м · К
```

Це аналітично підтверджує закон зсуву Віна та пов'язує його сталу з константами Планка, Больцмана та швидкістю світла.
