# 📋 Довідник фундаментальних констант та формул спектрометрії

Довідкові таблиці фундаментальних фізичних констант CODATA 2018, точні математичні формули перерахунку між частотними та довжинними розподілами, а також параметри яскравості, фотонного потоку й спектрометричних співвідношень теплового випромінювання.

---

## 1. Фундаментальні фізичні сталі (CODATA 2018)

Усі теоретичні та інженерні розрахунки випромінювання абсолютно чорного тіла спираються на фундаментальні фізичні сталі. З 20 травня 2019 року в результаті історичної реформи Міжнародної системи одиниць (СІ) значення сталої Планка `h`, елементарного заряду `e`, сталої Больцмана `k_B` та швидкості світла у вакуумі `c` були фіксовані точними чисельними значеннями без жодної експериментальної похибки. Це означає, що похідні радіаційні константи, такі як перша і друга радіаційні сталі `c₁` та `c₂`, а також константа Стефана-Больцмана `σ` та стала зсуву Віна `b`, тепер також обчислюються зі точністю математичних визначень.

У наведеній нижче таблиці подано офіційні значення констант згідно з релізом CODATA 2018:

| Фізична величина | Символ | Значення в одиницях СІ | Одиниці вимірювання |
| :--- | :---: | :---: | :---: |
| **Стала Планка** | `h` | `6.626 070 15 × 10⁻³⁴` | Дж · с (або Н · м · с) |
| **Зведена стала Планка** | `ħ = h / (2·π)` | `1.054 571 817 × 10⁻³⁴` | Дж · с |
| **Швидкість світла у вакуумі** | `c` | `299 792 458` | м / с (точно) |
| **Стала Больцмана** | `k_B` | `1.380 649 × 10⁻²³` | Дж / К |
| **Стала Стефана-Больцмана** | `σ` | `5.670 374 419 × 10⁻⁸` | Вт / (м² · К⁴) |
| **Перша радіаційна стала** | `c₁ = 2·π·h·c²` | `3.741 771 852 × 10⁻¹⁶` | Вт · м² |
| **Перша спектральна середня стала** | `c₁L = 2·h·c²` | `1.191 042 972 × 10⁻¹⁶` | Вт · м² / стер |
| **Друга радіаційна стала** | `c₂ = h·c / k_B` | `1.438 776 877 × 10⁻²` | м · К |
| **Стала зсуву Віна (для λ)** | `b` | `2.897 771 955 × 10⁻³` | м · К |
| **Стала зсуву Віна (для ν)** | `b'` | `5.878 925 757 × 10¹⁰` | Гц / К |

Фізичний зміст першої радіаційної константи `c₁` полягає у визначенні амплітудного масштабу випромінювальної здатності поверхні чорного тіла, тоді як друга радіаційна стала `c₂` визначає спектральний масштаб та температурний розподіл у показнику експоненти Планка.

## 2. Спектральні форми закону Планка

Залежно від фізичної задачі, конструкції оптичних елементів та типів вимірювальних приладів спектральний розподіл випромінювання чорного тіла описується у термінах довжини хвилі `λ`, циклічної частоти `ν` або кутової частоти `ω`.

### 2.1 Спектральна об'ємна густина енергії `u` (Дж / м³)
Об'ємна густина визначає кількість електромагнітної енергії випромінювання у кожному кубічному метрі порожнини на одиничний спектральний інтервал:

```
u(λ, T) = (8 · π · h · c / λ⁵) · 1 / (exp(h · c / (λ · k_B · T)) - 1)
```

```
u(ν, T) = (8 · π · h · ν³ / c³) · 1 / (exp(h · ν / (k_B · T)) - 1)
```

```
u(ω, T) = (ħ · ω³ / (π² · c³)) · 1 / (exp(ħ · ω / (k_B · T)) - 1)
```

Ці формули є фундаментальними для термодинаміки випромінювання у порожнині та опису фотонного газу.

### 2.2 Спектральна випромінювальна здатність `R` (потік з одиниці площі, Вт / м³)
Спектральна випромінювальна здатність (або випромінювальне існування) описує потік енергії, що випромінюється з одиниці площі поверхні чорного тіла в напівпростір `2·π` стерадіан:

```
R(λ, T) = (c / 4) · u(λ, T) = (c₁ / λ⁵) · 1 / (exp(c₂ / (λ · T)) - 1)
```

```
R(ν, T) = (c / 4) · u(ν, T) = (2 · π · h · ν³ / c²) · 1 / (exp(h · ν / (k_B · T)) - 1)
```

Ця величина використовується в інженерних розрахунках теплообміну випромінюванням між поверхнями.

### 2.3 Спектральна яскравість `B` (на одиницю тілесного кута, Вт / (м² · стер · м))
Спектральна яскравість визначає потік енергії, що випромінюється з одиниці проекції площі поверхні в одиничний тілесний кут `1` стерадіан. Оскільки випромінювання чорного тіла є повністю ізотропним (дифузним) і підпорядковується закону Ламберта, зв'язок між випромінювальною здатністю `R` та яскравістю `B` виражається множником `π`:

```
B(λ, T) = R(λ, T) / π = (c₁L / λ⁵) · 1 / (exp(c₂ / (λ · T)) - 1)
```

```
B(ν, T) = R(ν, T) / π = (2 · h · ν³ / c²) · 1 / (exp(h · ν / (k_B · T)) - 1)
```

Спектральна яскравість є основною величиною в оптичному приладобудуванні, оскільки саме вона зберігається вздовж оптичного променя при проходженні крізь лінзи та дзеркала за відсутності поглинання.

## 3. Правила перетворення спектральних величин

При переході від спектрального опису за частотою `ν` до опису за довжиною хвилі `λ` необхідно враховувати нелінійний зв'язок між цими змінними `ν = c / λ`. Через диференціальне співвідношення `|dν| = (c / λ²) dλ` спектральні густини перераховуються за формулами:

```
R_λ(λ, T) = R_ν(c / λ, T) · (c / λ²)
```

```
R_ν(ν, T) = R_λ(c / ν, T) · (c / ν²)
```

### Фізична пастка: незбіжність максимумів
Оскільки диференціальний множник `c / λ²` залежить від довжини хвилі, максимум спектральної функції `R_λ(λ, T)` **не відповідає** максимуму функції `R_ν(ν, T)`:

```
λ_max · T = 2.897 772 × 10⁻³ м · К             [розв'язок рівняння 5*(1-exp(-x)) = x, де x ≈ 4.965]
```

```
ν_max / T = 5.878 926 × 10¹⁰ Гц / К             [розв'язок рівняння 3*(1-exp(-x)) = x, де x ≈ 2.821]
```

При перерахунку довжини хвилі максимуму `λ_max` у частоту виходить значення `c / λ_max ≈ 1.76 · ν_max`, яке виявляється суттєво більшим за максимум частотного спектра `ν_max`. Цю відмінність необхідно враховувати при налаштуванні спектрометрів та оптичних фільтрів, щоб не допустити помилок при інтерпретації результатів вимірювань.

## 4. Радіометричні та фометричні величини

У практичній оптиці та світлотехніці слід чітко розрізняти радіометричні величини (що вимірюють абсолютну енергію в ватах) та фотометричні величини (що враховують спектральну чутливість людського ока).

Людське око чутливе лише до вузького спектрального діапазону від 380 до 780 нм із максимумом чутливості на довжині хвилі 555 нм у денному (фотопічному) зорі. Спектральна світлова ефективність описується стандартною функцією `V(λ)`, затвердженою Міжнародною комісією з освітлення (CIE).

Світловий потік `Ф_v` (у люменах, лм) для чорного тіла обчислюється як інтеграл від спектральної потужності, зваженої з кривою чутливості ока:

```
Ф_v = K_m · ∫₃₈₀⁷⁸⁰ R(λ, T) · V(λ) dλ
```

де `K_m = 683` лм/Вт — максимальна світлова віддача монохроматичного випромінювання на довжині хвилі 555 нм.

Для абсолютно чорного тіла світлова віддача зростає з температурою, досягає максимуму біля `T ≈ 6600 K` (близько 95 лм/Вт) і далі повільно спадає внаслідок зсуву спектра в ультрафіолетову область.

## 5. Фотонні характеристики випромінювання чорного тіла

У квантовій оптиці, астрофотометрії та при роботі з напівпровідниковими фотоприймачами (CCD/CMOS матриці, фотодіоди), які реагують на кількість поглинутих фотонів, а не на їхню сумарну енергію, застосовують фотонні величини.

### 5.1 Спектральна густина фотонного потоку `Q_p(λ, T)`
Діленням енергетичного потоку `R(λ, T)` на енергію одного фотона `E_ph = h·c / λ` отримуємо кількість фотонів, випромінюваних з одиниці площі за секунду в одиничному інтервалі довжин хвиль:

```
Q_p(λ, T) = R(λ, T) / (h · c / λ)
          = (2 · π · c / λ⁴) · 1 / (exp(h · c / (λ · k_B · T)) - 1)
```

### 5.2 Повний фотонний потік `Q_total(T)`
Повний фотонний потік, випромінюваний з одиниці площі чорного тіла в напівпростір за секунду, отримують інтегруванням `Q_p(λ, T)` по всьому спектру від `0` до `∞`:

```
Q_total(T) = ∫₀^∞ Q_p(λ, T) dλ
           = (4 · π · ζ(3) · k_B³ / (h³ · c²)) · T³
           ≈ 1.5205 × 10¹⁵ · T³  фотонів / (с · м²)
```

де `ζ(3) ≈ 1.202 056 903` — константа Апері (значення дзета-функції Рімана від 3). На відміну від енергетичного потоку Стефана-Больцмана, який зростає як `T⁴`, **повний фотонний потік пропорційний кубу температури `T³`**.

### 5.3 Середня енергія фотона
Діленням повного енергетичного потоку `R_total = σ · T⁴` на повний фотонний потік `Q_total` отримуємо середню енергію одного фотона у спектрі чорного тіла:

```
<E_photon> = R_total(T) / Q_total(T)
           = (π⁴ / (30 · ζ(3))) · k_B · T
           ≈ 2.701178 · k_B · T
```

Ця формула показує, що середня енергія фотона теплового випромінювання прямо пропорційна абсолютній температурі.

## 6. Класифікація температур у пірометрії та термографії

При вимірюванні температури реальних тіл за їхнім тепловим випромінюванням застосовують умовні температурні шкали:

1. **Яскравісна температура (`T_b`):** Температура абсолютно чорного тіла, за якої його спектральна яскравість на фіксованій довжині хвилі `λ` дорівнює спектральній яскравості досліджуваного об'єкта. Для реальних тіл із коефіцієнтом чорноти `ε(λ) < 1` яскравісна температура завжди менша за дійсну термодинамічну температуру (`T_b < T`).
2. **Колірна температура (`T_c`):** Температура абсолютно чорного тіла, за якої відношення його спектральних яркостей на двох вибраних довжинах хвиль `λ₁` та `λ₂` строго дорівнює відношенню яркостей досліджуваного об'єкта. Вона активно використовується в світлотехніці для характеристики колірного відтінку ламп (наприклад, теплий білий 2700 К або денний 6500 К).
3. **Радіаційна (радіометрична) температура (`T_r`):** Температура абсолютно чорного тіла, за якої його повна інтегральна випромінювальна здатність по всьому спектру дорівнює інтегральній випромінювальній здатності досліджуваного об'єкта. Зв'язок із дійсною температурою: `T_r = T · (ε_total)^(1/4)`.

## 7. Метрологічні еталони чорного тіла

Для калібрування тепловізорів, інфрачервоних радіометрів та пірометрів у метрологічних лабораторіях (таких як NIST у США або PTB у Німеччині) використовуються спеціальні еталонні випромінювачі у вигляді порожнин з високостабілізованою температурою.

Коефіцієнт чорноти метрологічної порожнини `ε_eff` обчислюється за формулою Губеля:

```
ε_eff = ε_wall / (ε_wall + (1 - ε_wall) · (A_hole / A_cavity))
```

де `ε_wall` — коефіцієнт чорноти покриття внутрішніх стінок, `A_hole` — площа вихідного отвору, а `A_cavity` — повна площа внутрішньої поверхні порожнини. Для якісних метрологічних печей відношення площ вибирається на рівні `A_hole / A_cavity < 0.005`, що забезпечує ефективний коефіцієнт чорноти `ε_eff > 0.999`.
