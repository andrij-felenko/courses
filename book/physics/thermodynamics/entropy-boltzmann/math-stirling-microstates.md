# 🧮 Математичне виведення формули Больцмана та розподілу Максвелла-Больцмана

Ця вставка містить строге математичне виведення двох фундаментальних співвідношень статистичної фізики: логарифмічного зв'язку між ентропією та числом мікростанів `S = k_B · ln W` з вимог аддитивності та незалежності, а також виведення класичного розподілу Максвелла-Больцмана за допомогою асимптотики Стірлінга та методу невизначених множників Лагранжа.

---

## 1. Функціональне виведення формули `S = k_B · ln W`

Розглянемо дві фізичні системи `A` та `B`, які є термодинамічно незалежними. Це означає, що енергія взаємодії між ними є нехтовно малою порівняно з їхніми внутрішніми енергіями, а стан частинок першої системи жодним чином не обмежує доступні конфігурації частинок другої системи.

Нехай система `A` може перебувати у будь-якому з `W_A` доступних мікростанів, а система `B` — у будь-якому з `W_B` доступних мікростанів. Під мікростаном у класичній механіці розуміють точну точку у фазовому просторі координати та імпульсів частинок, а у квантовій механіці — конкретний власний стан гамільтоніана системи.

Оскільки системи незалежні, кожному з `W_A` мікростанів першої системи відповідає будь-який із `W_B` мікростанів другої системи. Отже, загальне число доступних мікростанів комбінованої системи `A + B` дорівнює добутку чисел мікростанів окремих частин:

```
W_AB = W_A · W_B
```

З іншого боку, з класичної феноменологічної термодинаміки відомо, що ентропія є аддитивною величиною станційного типу. При з'єднанні двох незалежних систем загальна ентропія `S_AB` дорівнює сумі ентропій складників:

```
S_AB = S_A + S_B
```

Шукаємо неперервну функціональну залежність ентропії від числа мікростанів `S = S(W)`. Підставляючи співвідношення для `W_AB` та ентропій, отримуємо фундаментальне функціональне рівняння:

```
S(W_A · W_B) = S(W_A) + S(W_B)
```

Щоб розв'язати це рівняння у загальному вигляді, продиференціюємо його за змінними `W_A` та `W_B`.

Крок 1. Диференціювання за змінною `W_A`:

```
dS(W_A · W_B) / dW_A
= S'(W_A · W_B) · W_B      [за правилом диференціювання складеної функції]
= S'(W_A)                  [бо частина S(W_B) не залежить від W_A]
```

Крок 2. Диференціювання за змінною `W_B`:

```
dS(W_A · W_B) / dW_B
= S'(W_A · W_B) · W_A      [за правилом диференціювання складеної функції]
= S'(W_B)                  [бо частина S(W_A) не залежить від W_B]
```

Крок 3. Помножимо перше рівняння на `W_A`, а друге — на `W_B`:

```
S'(W_A · W_B) · (W_A · W_B)
= S'(W_A) · W_A            [з першого рівняння]
= S'(W_B) · W_B            [з другого рівняння]
```

Зауважимо, що вираз `S'(W_A) · W_A` залежить лише від стану системи `A`, тоді як `S'(W_B) · W_B` залежить лише від стану системи `B`. Рівність цих виразів для довільних незалежних систем означає, що дане добуток є універсальною сталою величиною, яка не залежить від конкретної природи речовини чи її об'єму. Позначимо цю сталу через `C`:

```
S'(W) · W = C
```

Отримуємо звичайне диференціальне рівняння першого порядку для функції `S(W)`:

```
S'(W) = C / W
```

Проінтегруємо це рівняння за змінною `W`:

```
S(W)
= ∫ (C / W) dW
= C · ln W + C_0            [де C_0 — стала інтегрування]
```

Згідно з третім началом термодинаміки (теоремою Нернста-Планка), при наближенні температури до абсолютного нуля (`T → 0 K`) система переходить у єдиний основний квантовий стан з `W = 1`. Вимагаючи, щоб ентропія в цьому стані дорівнювала нулю `S(1) = 0`, знаходимо сталу інтегрування `C_0`:

```
S(1) = C · ln(1) + C_0 = 0   ⇒   C_0 = 0
```

Універсальну сталу `C` позначають літерою `k_B` і називають сталістю Больцмана. Вона пов'язує макроскопічні одиниці вимірювання енергії та температури (джоулі на кельвін) із безрозмірним числом доступних мікростанів:

```
S = k_B · ln W
```

## 2. Асимптотика Стірлінга та її уточнення

При аналізі статистичних ансамблів макроскопічних масштабах (`N ~ 10²³`) виникає потреба обчислювати логарифм факторіала `ln N!`. Пряме визначення факторіала як добутку послідовних натуральних чисел призводить до незручних виразів.

За логарифмічною властивістю добутку:

```
ln N!
= ln(1 · 2 · 3 · ... · N)   [визначення факторіала як добутку]
= ∑_{k=1}^{N} ln k          [за властивістю логарифма добутку]
```

Оскільки при великих `N` приріст функції `ln k` між сусідніми цілими точками є нескінченно малим порівняно з величиною `N`, дискретну суму можна замінити визначеним інтегралом:

```
∑_{k=1}^{N} ln k
≈ ∫_{1}^{N} ln x dx         [наближення суми Рімана інтегралом]
```

Обчислимо інтеграл методом інтегрування частинами (`u = ln x`, `dv = dx`, `du = dx / x`, `v = x`):

```
∫_{1}^{N} ln x dx
= [x · ln x - x]_{1}^{N}    [формула Ньютона-Лейбніца]
= (N · ln N - N) - (1 · ln 1 - 1)
= N · ln N - N + 1
```

Для макроскопічних систем `N >> 1`, тому одиницею порівняно з `N · ln N` можна безхмарно знехтувати. Отримуємо класичну формулу Стірлінга:

```
ln N! ≈ N · ln N - N
```

### Уточнення Стірлінга вищого порядку

Для біологічних макромолекул або нанокластерів із числом частинок `N ~ 10²...10⁴` може знадобитися уточнена асимптотична формула Стірлінга, яка враховує наступний член розкладу Ейлера-Маклорена:

```
N! ≈ √(2πN) · (N / e)^N
```

Логарифмуючи цей вираз, отримуємо уточнену формулу:

```
ln N! = N · ln N - N + (1 / 2) · ln(2πN) + O(1 / N)
```

Відносна похибка спрощеної формули `ln N! ≈ N · ln N - N` дорівнює `(1 / 2 ln(2πN)) / (N ln N)`. При `N = 10²³` ця відносна похибка становить нечувально малу величину порядку `10⁻²²`, що підтверджує абсолютну точність формули Больцмана у термодинамічній межі.

## 3. Мультиноміальний розподіл та логарифмування `W`

Розглянемо замкнену систему з `N` однакових частинок, які можуть перебувати на `m` різних дискретних енергетичних рівнях `E_1, E_2, ..., E_m`. Позначимо через `N_i` кількість частинок на `i`-му енергетичному рівні.

Конкретний набор чисел `{N_1, N_2, ..., N_m}` визначає макроскопічний стан системи. Кількість способів, якими можна розподілити `N` розрізнюваних частинок по рівнях так, щоб на `i`-му рівні опинилося точно `N_i` частинок, задається комбінаторним мультиноміальним коефіцієнтом:

```
W = N! / (N_1! · N_2! · ... · N_m!) = N! / ∏_{i=1}^{m} N_i!
```

Вважаючи частинки класичними та розрізнюваними, ми можемо переставити їх між рівнями `N!` способами, але внутрішні перестановки `N_i!` частинок всередині того самого рівня `i` не змінюють фізичного стану і тому діляться у знаменнику.

Прологарифмуємо термодинамічну вагу `W`:

```
ln W
= ln N! - ∑_{i=1}^{m} ln N_i!
```

Застосуємо формулу Стірлінга `ln K! ≈ K · ln K - K` до чисельника `ln N!` та кожного знаменника `ln N_i!`:

```
ln W
≈ (N · ln N - N) - ∑_{i=1}^{m} (N_i · ln N_i - N_i)
= N · ln N - N - ∑_{i=1}^{m} N_i · ln N_i + ∑_{i=1}^{m} N_i
```

Оскільки сума заселеностей по всіх рівнях дорівнює загальному числу частинок у системі `∑ N_i = N`, додатки `- N` та `+ ∑ N_i` точно скорочуються. Отримуємо остаточний вираз для логарифма термодинамічної ваги:

```
ln W = N · ln N - ∑_{i=1}^{m} N_i · ln N_i
```

## 4. Метод невизначених множників Лагранжа та розподіл Максвелла-Больцмана

Найбільш ймовірний макроскопічний стан системи у стані термодинамічної рівноваги відповідає максимуму ентропії `S = k_B · ln W`, а отже — максимуму величини `ln W`.

Шукаємо екстремум функції `ln W({N_i})` за наявності двох фундаментальних фізичних законів збереження (умовних зв'язків):

1. Збереження повної кількості частинок у замкненій системі: `∑_{i=1}^{m} N_i = N`
2. Збереження повної внутрішньої енергії системи: `∑_{i=1}^{m} N_i · E_i = E`

Складемо функцію Лагранжа `Φ({N_i}, α, β)` з невизначеними множниками `α` та `β`:

```
Φ({N_i}, α, β)
= ln W + α · (N - ∑_{i=1}^{m} N_i) + β · (E - ∑_{i=1}^{m} N_i · E_i)                  [функція Лагранжа з умовними обмеженнями]
= N · ln N - ∑_{i=1}^{m} N_i · ln N_i + α · N - α · ∑_{i=1}^{m} N_i + β · E - β · ∑_{i=1}^{m} N_i · E_i [підстановка виразу для ln W]
```

Для знаходження умовного екстремуму прирівняємо до нуля частинні похідні функції Лагранжа за кожною змінною заселеності `N_k`:

```
∂Φ / ∂N_k
= - ∂(N_k · ln N_k) / ∂N_k - α - β · E_k             [диференціювання за змінною N_k]
= - (1 · ln N_k + N_k · (1 / N_k)) - α - β · E_k     [диференціювання добутку N_k · ln N_k]
= - ln N_k - 1 - α - β · E_k                         [спрощення: N_k · (1 / N_k) = 1]
= 0                                                  [умова умовного екстремуму: похідна дорівнює нулю]
```

Виразимо `ln N_k` з цього рівняння:

```
ln N_k = - (1 + α) - β · E_k
```

Потенціюючи обидві частини рівняння, отримуємо рівноважну заселеність `k`-го рівню:

```
N_k = exp(-(1 + α)) · exp(-β · E_k)
```

Позначивши нормувальну сталу `A = exp(-(1 + α))`, отримуємо знаменитий канонічний розподіл Максвелла-Больцмана:

```
N_k = A · exp(-β · E_k)
```

Нормувальна стала `A` визначається з умови збереження повної кількості частинок `∑ N_k = N`:

```
A = N / (∑_{i=1}^{m} exp(-β · E_i)) = N / Z
```

де `Z = ∑ exp(-β · E_i)` називається статистичною сумою (Zustandssumme) канонічного ансамблю.

### Визначення фізичного змісту множника `β`

Для з'ясування зв'язку множника `β` з макроскопічною температурою розглянемо диференціал ентропії `dS` при безнескінченно малій зміні енергії системи `dE`:

```
dS = k_B · d(ln W)
= k_B · ∑_{k=1}^{m} (∂(ln W) / ∂N_k) · dN_k    [диференціал функції багатьох змінних]
= k_B · ∑_{k=1}^{m} (- ln N_k - 1) · dN_k      [підстановка частинної похідної ∂(ln W)/∂N_k]
```

Підставимо отримане вище значення `ln N_k = - (1 + α) - β · E_k`:

```
dS
= k_B · ∑_{k=1}^{m} ((1 + α) + β · E_k - 1) · dN_k   [підстановка виразу для ln N_k]
= k_B · (α · ∑_{k=1}^{m} dN_k + β · ∑_{k=1}^{m} E_k · dN_k) [розкриття дужок та групування суми]
= k_B · β · dE                                       [враховуючи ∑ dN_k = 0 та ∑ E_k dN_k = dE]
```

Оскільки загальна кількість частинок фіксована, сума варіацій `∑ dN_k = dN = 0`. Сума `∑ E_k · dN_k` дорівнює повній зміні внутрішньої енергії `dE`. Звідси:

```
dS = k_B · β · dE
```

З класичного термодинамічного виразу для абсолютної температури `1 / T = (∂S / ∂E)_V` випливає:

```
1 / T = k_B · β   ⇒   β = 1 / (k_B · T)
```

Таким чином, параметр `β` є фундаментальною характеристикою теплової рівноваги — зворотною тепловою енергією `1 / (k_B · T)`.

> 🔧 **Навіщо це.** Представлений математичний апарат розрахунку комбінаторної ваги `W` є універсальною основою всієї статистичної фізики. При переході до квантової статистики Фермі-Дірака (для електронів у металах) або Бозе-Ейнштейна (для фотонів) змінюється виключно вираз для мультиноміального коефіцієнта `W`, оскільки квантові частинки є принципово нерозрізнюваними. Процедура варіювання за методом Лагранжа залишається абсолютно тотожною.
