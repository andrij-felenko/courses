# 🧮 Математичний аналіз рівняння нестаціонарної теплопровідності та імпульсних методів

У цій математичній вставці наведено строгий та послідовний розбір рівняння нестаціонарної теплопровідності. Розглянуто векторне виведення дифрівняння із фундаментального закону збереження енергії, точний розв'язок методом перетворення Фур'є для миттєвого джерела тепла (функція Ґріна), вивід теорії Паркера для імпульсного методу лазерного спалаху (Laser Flash Analysis) та амплітудно-фазовий розв'язок для гармонічних температурних хвиль Онгстрема.

---

### 1. Строгий вивід диференціального рівняння теплопровідності з перших принципів

Розглянемо довільну замкнену область `V` всередині суцільного ізотропного середовища. Область обмежена неперервною просторовою поверхнею `S` з ортом зовнішньої нормалі `n`. Загальна кількість внутрішньої теплової енергії, що міститься в даному об'ємі в момент часу `t`, визначається об'ємним інтегралом від скалярної густини енергії `u(x,y,z,t)` [Дж/м³].

Закон збереження енергії стверджує: швидкість зміни внутрішньої теплової енергії всередині об'єму `V` дорівнює результуючому векторному тепловому потоку, що протікає крізь поверхню `S` всередину області, плюс потужність усіх внутрішніх джерел тепла `s(x,y,z,t)` [Вт/м³]:

```
d/dt ∫_V u dV = - ∮_S q · n dS + ∫_V s dV
```

Знак «мінус» перед поверхневим інтегралом відображає той факт, що вектор зовнішності `n` спрямований назовні, тож вхідний у середовище потік енергії відповідає `q · n < 0`.

Застосуємо класичну теорему Остроградського-Гаусса (теорему про дивергенцію) для перетворення поверхневого інтеграла другого роду в об'ємний інтеграл від дивергенції вектора густини теплового потоку `q`:

```
∮_S q · n dS = ∫_V ( ∇ · q ) dV
```

Підставляючи це значення в рівняння енергетичного балансу та переносячи всі доданки під один спільний об'ємний інтеграл:

```
∫_V ( ∂u/∂t + ∇ · q - s ) dV = 0
```

Оскільки це співвідношення має виконуватися для абсолютно довільного вибору об'єму `V`, підінтегральна функція повинна бути тотожно рівною нулю в кожній просторовій точці середовища. Це дає диференціальне рівняння збереження енергії у локальній формі:

```
∂u/∂t + ∇ · q = s      [диференціальне рівняння балансу енергії]
```

Для термодинамічно стабільних середовищ за відсутності фазових переходів при постійному тиску зміна внутрішньої енергії прямо пропорційна зміні температури `T` через масову питому теплоємність `c_p` та густину речовини `ρ`:

```
∂u/∂t = ρ · c_p · (∂T/∂t)
```

Підставляємо фундаментальний феноменологічний закон Фурьє, який стверджує, що вектор густини теплового потоку `q` пропорційний градієнту температури `∇T` з коефіцієнтом теплопровідності `λ`:

```
q = -λ · ∇T
```

Обчислюємо скалярну дивергенцію векторного поля `q` у припущенні, що коефіцієнт теплопровідності `λ` є просторово однорідним:

```
∇ · q = ∇ · ( -λ · ∇T )
= -λ · ∇²T      [вважаючи λ = const]
```

де `∇² = ∂²/∂x² + ∂²/∂y² + ∂²/∂z²` — просторовий оператор Лапласа.

Підставляємо вирази для `∂u/∂t` та `∇ · q` у диференціальне рівняння балансу енергії за відсутності внутрішніх джерел тепла (`s = 0`):

```
ρ · c_p · (∂T/∂t) - λ · ∇²T = 0
```

Переносимо доданок з оператором Лапласа в праву частину і ділимо обидві частини рівняння на об'ємну теплоємність матеріалу `C_v = ρ · c_p`:

```
∂T/∂t = ( λ / (ρ · c_p) ) · ∇²T
```

Впроваджуючи фундаментальне позначення температуропровідності `a = λ / (ρ · c_p)` з вимірністю `м²/с`, отримуємо остаточне рівняння дифузії тепла:

```
∂T/∂t = a · ∇²T
```

### 2. Точний розв'язок для миттєвого точкового джерела тепла (Функція Ґріна)

Розглянемо одновимірну задачі переносу тепла в нескінченній просторовій області `-∞ < x < +∞`. У початковий момент часу `t = 0` у площині `x = 0` виділяється миттєвий тепловий імпульс енергії `Q_area` на одиницю площі [Дж/м²]. Початковий розподіл температури описується математичною дельта-функцією Дірака `δ(x)`:

```
T(x, 0) - T_0 = ( Q_area / (ρ · c_p) ) · δ(x)
```

Для розв'язання цієї задачі Коші застосуємо інтегральне перетворення Фур'є за просторовою координатою `x`:

```
T̃(k, t) = ∫_{-∞}^{+∞} T(x, t) · exp(-i · k · x) dx
```

Диференціюючи трансформовану функцію за часом та інтегруючи за частинами просторову другу похідну `∂²T/∂x²`, ми зводимо вихідне рівняння у приватних похідних до звичайного диференціального рівняння першого порядку для спектральної амплітуди `T̃(k, t)`:

```
d T̃ / dt = - a · k² · T̃(k, t)
```

Розв'язок цього ЗДУ з початковою умовою `T̃(k, 0) = Q_area / (ρ · c_p)` має вигляд згасаючої експоненти:

```
T̃(k, t) = ( Q_area / (ρ · c_p) ) · exp( - a · k² · t )
```

Для повернення у фізичний просторовий простір виконуємо обернене інтегральне перетворення Фур'є:

```
T(x, t) - T_0
= (1 / (2·π)) · ∫_{-∞}^{+∞} T̃(k, t) · exp(i · k · x) dk                [обернене перетворення Фур'є]
= ( Q_area / ( 2 · π · ρ · c_p ) ) · ∫_{-∞}^{+∞} exp( - a · k² · t + i · k · x ) dk  [підстановка T̃(k,t)]
```

Щоб обчислити цей інтеграл, доповнимо квадратний тричлен у показнику експоненти до повного квадрата за змінною хвильового числа `k`:

```
- a · k² · t + i · k · x = - a · t · ( k - i · x / (2 · a · t) )² - x² / (4 · a · t)
```

Виносячи постійний множник `exp(-x² / (4·a·t))` за знак інтеграла та застосовуючи класичний табличний інтеграл Гаусса `∫_{-∞}^{+∞} exp(-A · u²) du = √(π / A)` де `A = a · t`:

```
T(x, t) - T_0 = ( Q_area / ( 2 · √(π · a · t) · ρ · c_p ) ) · exp( - x² / (4 · a · t) )
```

Отриманий розв'язок виявляє фундаментальний нормальний (гауссів) розподіл температурного поля у просторі. Просторова дисперсія температурного дзвона зростає прямо пропорційно часу: `σ²(t) = 2 · a · t`. Максимальне значення температури в центрі імпульсу `x = 0` падає обернено пропорційно `√t`, а ефективний просторовий радіус прогрева зростає як `x_diff = √(2 · a · t)`.

### 3. Математична теорія методу лазерного спалаху Паркера (LFA)

Розглянемо тонкий плоский зразок товщиною `L` у формі диска, що займає просторову область `0 ≤ x ≤ L`. Зразок знаходиться у вакуумній комірці і його поверхні ідеально теплоізольовані (адіабатичні граничні умови Неймана):

```
∂T/∂x (x = 0, t) = 0
∂T/∂x (x = L, t) = 0
```

У момент часу `t = 0` на передню грань `x = 0` діє короткий світловий лазерний спалах, що створює миттєве поверхневе джерело тепла з енергією `Q_area`. Початковий розподіл температури по товщині зразка описується співвідношенням:

```
T(x, 0) - T_0 = ( Q_area / (ρ · c_p) ) · δ(x)
```

Розв me розв'язуємо одновимірне рівняння теплопровідності `∂T/∂t = a · (∂²T/∂x²)` методом відокремлення змінних (методом Фур'є). Шукаємо розв'язок у вигляді розкладу в ортогональний ряд за власними функціями задачі Штурма-Ліувілля:

```
T(x, t) - T_0 = X_0(x) + ∑_{n=1}^∞ X_n(x) · T_n(t)
```

Власні просторові функції з адіабатичними граничними умовами являють собою косинуси:

```
X_n(x) = cos( n · π · x / L ),      n = 0, 1, 2, 3, ...
```

Часові множники `T_n(t)` задовольняють диференціальному рівнянню `d T_n / dt = - a · (n² · π² / L²) · T_n`, загальний розв'язок якого є експоненційним:

```
T_n(t) = C_n · exp( - n² · π² · a · t / L² )
```

Коефіцієнти розкладу `C_n` знаходяться з початкової умови шляхом обчислення інтегралів проєкції дельта-функції на ортогональний базис косинусів на відрізку `[0, L]`:

```
C_0 = (1 / L) · ∫_0^L ( Q_area / (ρ · c_p) ) · δ(x) dx = Q_area / ( ρ · c_p · L ) = T_max
C_n = (2 / L) · ∫_0^L ( Q_area / (ρ · c_p) ) · δ(x) · cos( n · π · x / L ) dx = 2 · T_max
```

де `T_max = Q_area / (ρ · c_p · L)` — асимптотичне максимальне підвищення температури зразка після повного вирівнювання тепла по всьому об'єму.

Таким чином, повний аналітичний розв'язок для температурного поля всередині зразка записується у вигляді нескінченного гармонічного ряду:

```
T(x, t) - T_0 = T_max · [ 1 + 2 · ∑_{n=1}^∞ exp( - n² · π² · a · t / L² ) · cos( n · π · x / L ) ]
```

Обчислимо відносну нормовану температуру на тильній грані зразка `x = L`, оскільки саме її фіксує інфрачервоний детектор вимірювального приладу LFA. Оскільки `cos(n · π) = (-1)^n`:

```
V(t) = ( T(L, t) - T_0 ) / T_max
= 1 + 2 · ∑_{n=1}^∞ (-1)^n · exp( - n² · π² · a · t / L² )
```

Для аналізу введемо безрозмірний час `ω_1 = π² · a · t / L²`. Запишемо перші доданок ряду для нормованої температури тильної поверхні `V(t)`:

```
V(t) = 1 - 2 · exp(-ω_1) + 2 · exp(-4·ω_1) - 2 · exp(-9·ω_1) + 2 · exp(-16·ω_1) - ...
```

Знайдемо момент часу півпідйому `t_{1/2}`, коли температура тильної грані досягає рівно половини від максимального підйому, тобто `V(t_{1/2}) = 0.5`:

```
0.5 = 1 - 2 · exp(-ω_1) + 2 · exp(-4·ω_1) - 2 · exp(-9·ω_1) + ...
```

Переносимо сталі доданки у ліву частину і отримуємо трансцендентне рівняння відносно невідомого безрозмірного часу `ω_1`:

```
2 · exp(-ω_1) - 2 · exp(-4·ω_1) + 2 · exp(-9·ω_1) - ... = 0.5
```

Виконуючи високоточне чисельне розв'язання цього трансцендентного рівняння методом Ньютона-Рафсона з точністю до шостого знака:

```
ω_1 = π² · a · t_{1/2} / L² ≈ 1.36979
```

Виражаємо шукану температуропровідність матеріалу `a` через товщину зразка `L` та виміряний час півпідйому `t_{1/2}`:

```
a = 1.36979 · L² / ( π² · t_{1/2} )
= ( 1.36979 / 3.14159² ) · ( L² / t_{1/2} )    [підстановка π ≈ 3.14159]
= 0.138785 · ( L² / t_{1/2} )                 [обчислення 1.36979 / 3.14159²]
≈ 0.1388 · L² / t_{1/2}                      [округлення до 4 значущих цифр]
```

Отримане співвідношення являє собою фундаментальну **формулу Паркера (1961)**, яка служить метрологічною основою для більшості сучасних імпульсних приладів вимірювання температуропровідності.

### 4. Гармонічний розв'язок для температурних хвиль Онгстрема

Розглянемо напівнескінченний вимірювальний стрижень `x ≥ 0`. На передньому торці `x = 0` створюється гармонічне температурне нагрівання з частотою `ω = 2π / P`:

```
T(0, t) = T_0 + A_0 · cos(ω · t)
```

Шукаємо усталений гармонічний розв'язок одновимірного рівняння теплопровідності `∂T/∂t = a · (∂²T/∂x²)` у комплексній формі `T̃(x, t) = θ(x) · exp(i · ω · t)`:

```
i · ω · θ(x) = a · ( d²θ / dx² )
```

Переносимо доданки в один бік і отримуємо лінійне однорідне ЗДУ другого порядку з постійними коефіцієнтами:

```
d²θ / dx² - ( i · ω / a ) · θ(x) = 0
```

Характеристичне рівняння `k² - (i·ω/a) = 0` має комплексні корені. Згадуючи алгебраїчну тотожність `√i = (1 + i) / √2`, корінь `k_c = √[ i · ω / a ]` дорівнює:

```
k_c = (1 + i) · √( ω / (2 · a) ) = (1 + i) / δ
```

де `δ = √( 2 · a / ω )` — глибина проникнення температурної хвилі в матеріал.

Загальний розв'язок диференціального рівняння, що задовольняє умові фізичної обмеженості температури на нескінченності (`θ(x) → 0` при `x → ∞`), записується у вигляді:

```
θ(x) = A_0 · exp( - k_c · x ) = A_0 · exp( - x / δ ) · exp( - i · x / δ )
```

Помножимо просторову функцію на часовий множник `exp(i · ω · t)` та виділимо дійсну частину комплексної функції:

```
T(x, t) - T_0
= Re [ A_0 · exp( - x / δ ) · exp( i · ( ω · t - x / δ ) ) ]  [комбінація амплітуди й фази]
= A_0 · exp( - x / δ ) · cos( ω · t - x / δ )                [виділення дійсної частини]
```

Проаналізуємо температурний сигнал у двох точках спостереження `x_1` та `x_2` на відстані `Δx = x_2 - x_1`:
1. Амплітуди температурних коливань дорівнюють `A_1 = A_0 · exp(-x_1 / δ)` та `A_2 = A_0 · exp(-x_2 / δ)`. Звідси логарифмічне відношення амплітуд становить: `ln(A_1 / A_2) = (x_2 - x_1) / δ = Δx / δ`.
2. Фазовий зсув температурної хвилі між точками `x_1` та `x_2` становить: `Δφ = (x_2 - x_1) / δ = Δx / δ`.

Перемножуючи логарифмічне відношення амплітуд на фазовий зсув:

```
ln(A_1 / A_2) · Δφ
= ( Δx / δ )²                   [перемноження ln(A₁/A₂) та Δφ]
= (Δx)² / ( 2 · a / ω )         [підстановка δ² = 2·a/ω]
= (Δx)² · ω / ( 2 · a )         [перенесення ω у чисельник]
```

Виражаємо температуропровідність матеріалу `a`:

```
a = (Δx)² · ω / ( 2 · ln(A_1 / A₂) · Δφ )
```

Цей результат строгим математичним шляхом підтверджує розрахункову формулу Онгстрема, яка дозволяє обчислювати температуропровідність за відношенням амплітуд та фазовим зсувом двох термопар.
