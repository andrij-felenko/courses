# 📋 Довідник величин температуропровідності та безрозмірних чисел

У цьому довіднику зібрано фундаментальні фізичні характеристики температуропровідності `a`, теплопровідності `λ`, густини `ρ` та питомої теплоємності `c_p` для понад 50 чистих речовин, металевих сплавів, керамік, полімерних композитів, рідин та газів при температурі `T = 298.15 K` (25 °C) та стандартному атмосферному тиску `101.325 кПа`. Також наведено аналітичні залежності температуропровідності від температури `a(T)`, довідник еталонних стандартних матеріалів NIST та критеріальні рівняння безрозмірних чисел тепломасопереносу.

---

### 1. Фізичний зміст та класифікація матеріалів за температуропровідністю

Температуропровідність `a = λ / (ρ · c_p)` є головною кінетичною характеристикою речовини у нестаціонарних теплових процесах. На відміну від коефіцієнта теплопровідності `λ` [Вт/(м·К)], який показує потужність стаціонарного теплового потоку через прогрітий шар матеріалу, температуропровідність `a` [м²/с] вимірює швидкість зміщення температурного фронту та швидкість вирівнювання температурних неоднорідностей у часі.

Значення температуропровідності природних та штучних матеріалів охоплюють понад вісім порядків — від рекордно високих `10⁻³ м²/с` у монокристалічному алмазі та графені до `10⁻⁹ м²/с` у високоефективних вакуумно-пористих панелях. За мікроскопічним механізмом переносу тепла всі матеріали поділяються на п'ять фундаментальних класів:
1. **Нановуглецеві матеріали та надпровідні кристали** (`a > 500 мм²/с`): Домінують кванти коливань кристалічної ґратки (фонони) з надзвичайно великою довжиною вільного пробігу (`l_ph > 100 нм`) та високою швидкістю звуку (`v_s > 10000 м/с`).
2. **Чисті метали та високоефективні провідники** (`a ≈ 30 – 200 мм²/с`): Перенос тепла здійснюється газом вільних електронів із ферміївськими швидкостями `v_F ≈ 10⁶ м/с`.
3. **Конструкційні сплави та технічна кераміка** (`a ≈ 2 – 30 мм²/с`): Процеси розсіювання електронів та фононів на межах зерен, легуючих домішках та дефектах решітки суттєво знижують довжину вільного пробігу носіїв тепла.
4. **Рідини, полімери, аморфні речовини та біоматеріали** (`a ≈ 0.07 – 1.5 мм²/с`): Через відсутність дальньої кристалічної впорядкованості довжина пробігу збуджень обмежується міжатомними відстанями (`l ≈ 0.2 – 0.5 нм`).
5. **Гази за нормальних умов** (`a ≈ 10 – 180 мм²/с`): Перенос тепла відбувається шляхом пружних парних зіткнень хаотично рухомих молекул. Через малу об'ємну густину `ρ` об'ємна теплоємність газів `C_v = ρ · c_p` є на три порядки нижчою за тверді тіла, що забезпечує відносно високі значення температуропровідності при малій теплопровідності.

### 4. Аналітичний опис температурних залежностей `a(T)`

Залежність температуропровідності від температури `a(T)` у широкому діапазоні від `20 K` до `1500 K` описується трьома основними температурними режимами:

#### 4.1 Кріогенні температури (`T < Θ_D / 10`)
При низьких температурах теплоємність діелектриків падає за законом Дебая `C_v ∝ T³`. Довжина вільного пробігу фононів обмежена лише розмірами кристала чи зерен `l_ph ≈ L_grain = const`. З огляду на кінетичну формулу `a_ph = (1/3) · v_s · l_ph`, у кріогенному режимі температуропровідність кристалів прямує до високих значень і визначається виключно геометричними розмірами зразка.

#### 4.2 Середні та високі температури (`T > Θ_D`)
При високих температурах об'ємна теплоємність виходить на насичення за законом Дюлонга-Пті `C_v ≈ 3 · N · k_B = const`. Довжина вільного пробігу фононів визначається процесами фонон-фононного розсіювання Перейро-Умкляппа і падає як `l_ph ∝ 1 / T`. У результаті температуропровідність діелектричних монокристалів спадає за гіперболічним законом:

```
a(T) = a_298 · ( 298.15 / T )^m
```

де показник степеня `m` становить:
- `m = 1.0 ... 1.2` — для чистих монокристалів (Si, Ge, Diamond, SiC);
- `m = 0.5 ... 0.8` — для полікристалічних керамік (Al₂O₃, ZrO₂);
- `m ≈ 0` — для аморфного кварцового скла та високопористих матеріалів, де довжина пробігу фононів досягла атомного ліміту і не залежить від температури.

#### 4.3 Гази при різній температурі та тиску
Для газів середня швидкість молекул зростає як `v_avg ∝ √T`, а довжина вільного пробігу при постійному тиску зростає як `l ∝ T / P`. З урахуванням слабкої залежності в'язкості від температури `μ ∝ T^0.7`, температуропровідність газів зростає з температурою та спадає з тиском:

```
a_gas(T, P) = a_0 · ( T / T_0 )^1.75 · ( P_0 / P )
```

| Безрозмірне число | Символ та формула | Фізичний зміст | Типові значення та граничні режими |
| :--- | :--- | :--- | :--- |
| **Число Фурьє** | `Fo = a · t / L²` | Безрозмірний час нестаціонарного переносу тепла. Характеризує глибину прогрева тіла за час `t`. | `Fo < 0.1` — приповерхневий нагрів;<br>`Fo ≈ 0.5` — регулярний режим;<br>`Fo > 1.0` — стаціонарний стан. |
| **Число Прандтля** | `Pr = ν / a = μ · c_p / λ` | Співвідношення між дифузією імпульсу (в'язкістю) та дифузією тепла (температуропровідністю). | `Pr ≈ 0.01` (рідкі метали);<br>`Pr ≈ 0.7` (гази);<br>`Pr ≈ 7.0` (вода);<br>`Pr > 100` (масла). |
| **Число Льюїса** | `Le = a / D` | Відношення температуропровідності до коефіцієнта масової дифузії речовини. | `Le > 1` — тепловий фронт випереджає масовий;<br>`Le ≈ 1` — солідарний перенос у газах. |
| **Число Пекле** | `Pe = U · L / a = Re · Pr` | Відношення конвективного переносу тепла потоком до молекулярного переносу теплопровідністю. | `Pe << 1` — теплопровідність домінує;<br>`Pe >> 1` — конвекція домінує. |
| **Число Біот** | `Bi = h · L / λ` | Відношення внутрішнього теплового опору тіла `L/λ` до зовнішнього конвективного опору `1/h`. | `Bi < 0.1` — рівномірна температура в тілі;<br>`Bi > 0.1` — значний градієнт всередині. |
| **Число Релея** | `Ra = Gr · Pr = g · β · ΔT · L³ / (ν · a)` | Критерій виникнення природної термогравітаційної конвекції в рідині чи газі. | `Ra < 1708` — конвекція відсутня (чистий теплопровід);<br>`Ra > 1708` — виникає конвекція. |
| **Число Кнудсена фононів** | `Kn_ph = l_ph / L` | Відношення довжини вільного пробігу фононів до геометрії наноструктури. | `Kn_ph < 0.1` — дифузійний перенос тепла;<br>`Kn_ph > 1.0` — балістичний перенос тепла. |

Ці таблиці, метрологічні стандарти NIST та аналітичні вирази утворюють повну розрахункову базу для інженерного моделювання нестаціонарних теплових процесів у фізиці матеріалів, мікроелектроніці, теплоенергетиці та геофізиці.
