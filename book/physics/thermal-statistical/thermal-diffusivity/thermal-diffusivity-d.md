# Температуропровідність (a)

<preknowlist>
- [Теплопровідність матеріалів](book:physics/thermal-statistical/thermal-conductivity) — швидкість перенесення теплової енергії у речовині при заданому градієнті температури.
- [Питома теплоємність](book:physics/thermal-statistical/heat-capacity) — кількість теплоти, необхідна для підвищення температури одиниці маси речовини на один кельвін.
- [Тепловий опір](book:physics/thermal-statistical/thermal-resistance) — протидія матеріалу або конструктивного елемента стаціонарному тепловому потоку.
- [Дифузія та закони Фіка](book:physics/thermal-statistical/fick-laws) — макроскопічний перенос речовини внаслідок хаотичного теплового руху під дією градієнта концентрації.
</preknowlist>

Якщо покласти на розпечену електричну плиту тонку мідну пластину завтовшки пару міліметрів, її верхня поверхня розігріється майже миттєво. Якщо ж замінити мідь на таку ж за товщиною пластину зі сталі чи кераміки, для прогріву верхнього шару знадобляться секунди, а у випадку вологого шару ґрунту чи бетону — хвилини. На перший погляд здається, що все вирішує звичайна теплопровідність `λ`. Проте срібло має коефіцієнт теплопровідності `λ ≈ 429 Вт/(м·К)`, а монокристалічний алмаз — `λ ≈ 2200 Вт/(м·К)`. При цьому швидкість вирівнювання температури в алмазі перевершує срібну деталь у шість разів.

Річ у тім, що коефіцієнт теплопровідності `λ` показує лише здатність матеріалу пропускати стаціонарний тепловий потік через уже прогрітий об'єм. Але коли температура змінюється у часі — під час увімкнення силового транзистора, удару лазерного спалаху чи сезонної зміни погоди — виникає фундаментальне змагання між двома фізичними процесами: швидкістю переносу енергії між сусідніми мікроатомами та швидкістю її поглинання внутрішньою теплоємністю самого матеріалу. Кількісною мірою швидкості вирівнювання температури та поширення температурних хвиль у речовині є **температуропровідність** `a` (у зарубіжній науковій літературі позначається як `α` або `D_T`).

### Від статичного потоку до часової динаміки: що таке температуропровідність

Щоб з'ясувати фізичний зміст температуропровідності, розглянемо невеликий елементарний об'єм речовини `dV = dx · dy · dz` із густиною `ρ` та питомою масовою теплоємністю `c_p` при постійному тиску. Продукт цих двох величин утворює **об'ємну теплоємність** матеріалу:

```
C_v = ρ · c_p
```

Одиницею вимірювання об'ємної теплоємності в системі SI є `Дж/(м³·К)`. Вона показує, скільки джоулів теплової енергії потрібно запакувати в один кубічний метр речовини, щоб підвищити її температуру на один кельвін. Об'ємна теплоємність працює як «теплова інерція» матеріалу: що більша величина `C_v`, то більше енергії поглинає кожна мікроскопічна комірка речовини, запобігаючи швидкому зростанню локальної температури. Наприклад, вода має величезну об'ємну теплоємність `C_v = 1000 кг/м³ · 4184 Дж/(кг·К) ≈ 4.18 × 10⁶ Дж/(м³·К)`, тоді як для повітря за нормальних умов `C_v = 1.2 кг/м³ · 1005 Дж/(кг·К) ≈ 1.2 × 10³ Дж/(м³·К)` — майже у 3500 разів менше!

![Фізичний зміст температуропровідності: порівняння двох матеріалів](/book/physics/thermal-statistical/thermal-diffusivity/img/diffusivity-concept.svg)
*Порівняння двох режимів переносу тепла: у матеріалах із низькою температуропровідністю a (вода, важкі сплави) тепловий потік інтенсивно витрачається на внутрішнє нагрівання об'єму (велике ρ·c_p), через що температурний фронт просувається повільно; у матеріалах із високою температуропровідністю a (алмаз, мідь) теплова інерція мала відносно λ, тому зміна температури поширюється миттєво.*

Нехай крізь цей елементарний об'єм уздовж осі `x` протікає нестаціонарний тепловий потік. Згідно із законом Фурьє, густина теплового потоку в точці `x` становить `q(x) = -λ · (∂T/∂x)`. За час `dt` у ліву грань об'єму входить енергія `dE_in = q(x) · dy · dz · dt`. З правої грані на відстані `x + dx` виходить енергія `dE_out = q(x + dx) · dy · dz · dt`. Різниця між цими потоками залишається всередині об'єму і витрачається на зміну його температури `dT`:

```
dE_in - dE_out = - (∂q/∂x) · dx · dy · dz · dt
```

Розкладаючи густину потоку `q(x + dx)` у ряд Тейлора і підставляючи закон Фурьє `q = -λ · (∂T/∂x)` (вважаючи коефіцієнт `λ` постійним у межах малого перепаду температур), отримуємо:

```
- (∂q/∂x) = ∂/∂x ( λ · ∂T/∂x ) = λ · (∂²T/∂x²)
```

З іншого боку, теплова енергія, необхідна для нагрівання елементарного об'єму `dV` на `dT` за час `dt`, дорівнює:

```
dE_stored = ρ · c_p · dV · (∂T/∂t) · dt = ρ · c_p · dx · dy · dz · (∂T/∂t) · dt
```

Прирівнюючи збережену всередині об'єму енергію до різниці вхідного та вихідного теплових потоків, скорочуємо об'єм `dx · dy · dz` і проміжок часу `dt`:

```
ρ · c_p · (∂T/∂t) = λ · (∂²T/∂x²)
```

Поділивши обидві частини рівняння на об'ємну теплоємність `ρ · c_p`, ми приходимо до фундаментального визначення температуропровідності `a`:

```
∂T/∂t = ( λ / (ρ · c_p) ) · (∂²T/∂x²)
= a · (∂²T/∂x²)      [одновимірне рівняння теплопровідності]
```

Звідси формулюється фундаментальне означення: **температуропровідність `a` — це фізична величина, що дорівнює відношенню коефіцієнта теплопровідності матеріалу `λ` до його об'ємної теплоємності `ρ · c_p`**:

```
a = λ / (ρ · c_p)
```

Термін «температуропровідність» походить від німецького *Temperaturleitfähigkeit* (що дослівно означає «здатність проводити температуру»), а міжнародна назва *thermal diffusivity* підкреслює кінетичну аналогію між переносом тепла та молекулярною дифузією (від латинського *diffundere* — розтікатися, поширюватися).

Знайдемо розмірність температуропровідності `a` у Міжнародній системі одиниць (SI):

```
[a] = [λ] / ( [ρ] · [c_p] )
= [ Вт / (м·К) ] / [ (кг/м³) · (Дж/(кг·К)) ]
= [ Дж / (с·м·К) ] / [ Дж / (м³·К) ]
= м² / с
```

Розмірність `м²/с` виявляє дивовижну фізичну єдність усіх процесів переносу в природі. Точно таку ж розмірність `м²/с` мають:
- **Кінематична в'язкість** `ν = μ / ρ` (коефіцієнт дифузії імпульсу в гідродинаміці);
- **Коефіцієнт масової дифузії** `D` (коефіцієнт дифузії речовини у законах Фіка);
- **Магнітна гідродинамічна дифузія** `η_m = 1 / (μ₀ · σ)` (швидкість дифузії магнітного поля у провідному середовищі).

Кожна з цих величин описує швидкість «розмивання» у просторі відповідної фізичної субстанції: температуропровідність `a` описує дифузію теплової енергії (температури), кінематична в'язкість `ν` — дифузію механічного імпульсу (швидкості), а коефіцієнт дифузії `D` — дифузію маси (концентрації частинок).

| Фізична величина | Символ | Формула | Фізичний зміст | Одиниця SI |
| :--- | :--- | :--- | :--- | :--- |
| **Теплопровідність** | `λ` (або `k`) | `q = -λ · ∇T` | Здатність проводити стаціонарний тепловий потік | Вт / (м·К) |
| **Об'ємна теплоємність** | `C_v` | `C_v = ρ · c_p` | Теплова інерція одиниці об'єму | Дж / (м³·К) |
| **Температуропровідність** | `a` (або `α`) | `a = λ / (ρ · c_p)` | Швидкість часового вирівнювання температури | м² / с |

### Рівняння нестаціонарної теплопровідності та температурні хвилі

У тривимірному випадку для ізотропного середовища рівняння нестаціонарної теплопровідності записується через оператор Лапласа `∇²`:

```
∂T/∂t = a · ∇²T = a · ( ∂²T/∂x² + ∂²T/∂y² + ∂²T/∂z² )
```

Оператор Лапласа `∇²T` має чіткий геометричний і фізичний зміст: він вимірює локальну опуклість або кривину температурного поля. Якщо температура у точці `x` нижча за середню температуру її найближчих сусідів, друга похідна `∂²T/∂x² > 0`, і похідна за часом `∂T/∂t > 0` — точка починає нагріватися. Навпаки, якщо температура у точці вища за довколишній рівень, `∂²T/∂x² < 0`, і точка охолоджується. Коефіцієнт `a` виступає константою пропорційності між цією просторовою кривиною і швидкістю часової зміни температури.

Для розв'язання рівняння теплопровідності необхідно задати початкові умови `T(x,y,z, t=0)` та крайові граничні умови на поверхні тіла:
- **Граничні умови першого роду (Діріхле)**: Задається безпосередньо температура поверхні як функція часу `T_wall = f(t)`.
- **Граничні умови другого роду (Неймана)**: Задається густина теплового потоку на поверхні `q_wall = -λ · (∂T/∂n) = f(t)` (наприклад, при нагріванні лазерним променем чи електронагрівачем).
- **Граничні умови третього роду (Робіна)**: Задається конвективний теплообмін із навколишнім середовищем `q_wall = h · (T_wall - T_fluid)`.

Якщо у нескінченному однорідному просторі в момент часу `t = 0` виділяється миттєвий точковий тепловий імпульс енергії `Q` в точці `x = 0`, розв'язок рівняння теплопровідності надається **функцією Ґріна** (функцією джерела):

```
T(x, t) = T_0 + ( Q / ( 2 · √(π · a · t) ) ) · exp( - x² / (4 · a · t) )
```

Цей розв'язок являє собою гауссів дзвін, дисперсія якого зростає прямо пропорційно часом: `σ²(t) = 2 · a · t`. Тобто характерний просторовий розмір розмивання температурного імпульсу зростає як квадратний корінь із добутку температуропровідності на час: `x_diff ∝ √(a · t)`.

![Температурні хвилі Онгстрема у стрижні](/book/physics/thermal-statistical/thermal-diffusivity/img/angstrom-waves.svg)
*Принцип методу Онгстрема (1861): періодичне нагрівання та охолодження торця металевого стрижня генерує затухаючу температурну хвилю. За зсувом фази Δφ та відношенням амплітуд A₁/A₂ між двома термопарами точно обчислюється температуропровідність a.*

Особливо наочно роль температуропровідності проявляється при поширенні періодичних температурних коливань (температурних хвиль). Нехай поверхня напівнескінченного твердого тіла `x ≥ 0` піддається синусоїдальному нагріванню з частотою `ω = 2π / P` (де `P` — період коливань):

```
T(0, t) = T_avg + A_0 · cos(ω · t)
```

Розв'язок рівняння теплопровідності `∂T/∂t = a · (∂²T/∂x²)` для такого граничного умови має вигляд загасаючої гармонічної хвилі:

```
T(x, t) = T_avg + A_0 · exp(-x / δ) · cos(ω · t - x / δ)
```

де параметр `δ` називається **глибиною проникнення температурної хвилі** (або характерною довжиною затухання):

```
δ = √( 2 · a / ω ) = √( a · P / π )
```

Аналіз цього розв'язку дозволяє зробити три фундаментальні висновки про фізику нестаціонарного переносу тепла:
1. **Експоненційне загасання амплітуди**: Амплітуда температурних коливань `A(x) = A_0 · exp(-x / δ)` згасає в `e ≈ 2.718` раза на кожній відстані `δ`. На глибині `x = 3·δ` амплітуда становить менше 5% від початкової на поверхні.
2. **Фазовий зсув (запізнення)**: Температурна хвиля поширюється зі скінченною фазовою швидкістю `v_w = ω · δ = √( 2 · a · ω )`. На глибині `x` графік температури запізнюється за часом на величину `Δt = x / v_w = x / √(2·a·ω)`. На глибині `x = π · δ` зсув фази досягає `π` (180°), тобто максимум температури вглибині тіла настає рівно тоді, коли на поверхні спостерігається мінімум!
3. **Залежність від частоти**: Що вища частота коливань `ω` (коротший період `P`), то менша глибина проникнення `δ`. Високочастотні теплові імпульси згасають у тонкому приповерхневому шарі, тоді як повільні низькочастотні коливання проникають глибоко в товщу матеріалу.

Детальний математичний вивід імпульсних розв'язків рівняння теплопровідності, інтеграла помилок `erfc(x / (2·√(a·t)))` та аналітичних моделей для методу лазерного спалаху наведено у 🧮 [Математичному аналізі рівняння нестаціонарної теплопровідності та імпульсних методів](book:physics/thermal-statistical/thermal-diffusivity/math-heat-equation-waves.md). Історію відкриття температурних хвиль та створення перших імпульсних калориметрів висвітлено у 📜 [Від періодичних хвиль Онгстрема до лазерного спалаху Паркера](book:physics/thermal-statistical/thermal-diffusivity/hist-angstrom-parker.md).

### Мікроскопічна природа температуропровідності у різних фазах матерії

Значення температуропровідності `a` для різних речовин охоплюють понад шість порядків: від `10⁻³ м²/с` у монокристалічному алмазі та графені до `10⁻⁷ м²/с` у воді та полімерах, і далі до `10⁻⁹ м²/с` у високоефективних теплоізоляційних аерогелях. Така колосальна відмінність визначається мікроскопічною природою носіїв тепла та довжиною їхнього вільного пробігу.

#### 1. Ідеальні гази: парадокс солідарного переносу

У рамках молекулярно-кінетичної теорії ідеального газу теплопровідність описується формулою Больцмана: `λ = (1/3) · ρ · v_avg · l · c_v`, де `v_avg = √(8·k_B·T / (π·m))` — середня арифметична швидкість молекул, `l = 1 / (√2 · π · d² · n)` — середня довжина вільного пробігу, а `c_v` — питома теплоємність при постійному об'ємі.

Підставляючи це значення `λ` у формулу температуропровідності `a = λ / (ρ · c_p)` та враховуючи показник адіабати `γ = c_p / c_v`:

```
a = (1/3) · (v_avg · l / γ)
```

Звідси випливає важливий фундаментальний факт: **у газах температуропровідність `a`, кінематична в'язкість `ν` та коефіцієнт масової дифузії `D` з точністю до безрозмірного множника порядка одиниці дорівнюють добутку середньої швидкості молекул на довжину вільного пробігу**:

```
a ≈ ν ≈ D ≈ v_avg · l
```

Оскільки довжина вільного пробігу молекул газу обернено пропорційна тиску `l ∝ 1 / P`, а середня швидкість зростає як `v_avg ∝ √T`, температуропровідність газу різко збільшується при розрідженні (падінні тиску) та нагріванні: `a ∝ T^(3/2) / P`. Наприклад, для повітря за нормальних умов `a ≈ 2.2 × 10⁻⁵ м²/с`. У легких газах (гелій, водень) через малу атомну масу швидкість молекул `v_avg` у кілька разів вища, тому гелій має `a ≈ 1.7 × 10⁻⁴ м²/с` — майже у 8 разів більше, ніж повітря!

#### 2. Діелектричні кристали: фононний газ та розмірний ефект

У твердих діелектриках та напівпровідниках єдиними носіями тепла є кванти решіткових коливань — **фонони**. За аналогією з газом, температуропровідність фононного газу записується через об'ємну теплоємність решітки `C_v = ρ · c_p`, середню швидкість звуку в кристалі `v_s` (близько `3000 – 11000 м/с`) та середню довжину вільного пробігу фононів `l_ph`:

```
a_ph = (1/3) · v_s · l_ph
```

У високодосконалих кристалах із жорсткими ковалентними зв'язками (алмаз, нітрид алюмінію AlN, карбід кремнію 4H-SiC) швидкість звуку `v_s` надзвичайно висока, а при кімнатній температурі довжина пробігу фононів `l_ph` досягає сотень нанометрів. Це забезпечує рекордну температуропровідність:
- **Монокристалічний алмаз**: `a ≈ 1.1 × 10⁻³ м²/с` (1100 мм²/с);
- **Карбід кремнію (SiC)**: `a ≈ 1.2 × 10⁻⁴ м²/с` (120 мм²/с);
- **Монокристалічний кремній (Si)**: `a ≈ 9.0 × 10⁻⁵ м²/с` (90 мм²/с).

З підвищенням температури `T > Θ_D` (де `Θ_D` — температура Дебая) інтенсивність трифононних процесів розсіювання Перейро-Умкляппа зростає пропорційно температурі, через що довжина пробігу падає як `l_ph ∝ 1 / T`. Відповідно, температуропровідність кристалів спадає за законом `a(T) ∝ 1 / T`.

У наноструктурах та тонких плівках товщиною `L`, порівнянною з довжиною пробігу фононів `l_ph` (число Кнудсена для фононів `Kn_ph = l_ph / L ≥ 1`), виникає **балістичний перенос тепла**. Фонони розсіюються не між собою, а на межах плівки, через що ефективна температуропровідність `a_eff` падає пропорційно товщині плівки `L`.

Крім того, у двовимірних матеріалах (графен, моношари MoS₂) спостерігається гігантська анізотропія: поздовжня температуропровідність графену у площині шару становить `a_in-plane ≈ 1.5 × 10⁻³ м²/с`, тоді як поперечна температуропровідність між шарами графіту через слабкий ван-дер-ваальсів зв'язок є нижчою майже у 400 разів!

#### 3. Метали: електронне море

У металах основними носіями тепла є вільні електрони провідності. Температуропровідність електронного газу визначається швидкістю Фермі `v_F ≈ 10⁶ м/с` та довжиною вільного пробігу електронів `l_e`:

```
a_e = (1/3) · v_F · l_e · ( C_v,e / C_v,total )
```

Хоча швидкість електронів `v_F` на два порядки перевищує швидкість звуку у кристалі, електронна об'ємна теплоємність при кімнатній температурі становить лише пару відсотків від повної теплоємності решітки. У результаті чисті метали мають високу, але не рекордну температуропровідність:
- **Мідь (Cu)**: `a ≈ 1.17 × 10⁻⁴ м²/с` (117 мм²/с);
- **Срібло (Ag)**: `a ≈ 1.70 × 10⁻⁴ м²/с` (170 мм²/с);
- **Алюміній (Al)**: `a ≈ 9.7 × 10⁻⁵ м²/с` (97 мм²/с);
- **Залізо (Fe)**: `a ≈ 2.3 × 10⁻⁵ м²/с` (23 мм²/с).

Впровадження легуючих домішок у метал створює додаткові центри розсіювання для електронів, що різко зменшує `l_e`. Саме тому нержавіюча сталь марки 316L має температуропровідність `a ≈ 3.8 × 10⁻⁶ м²/с` — майже у 30 разів нижчу за чисту мідь!

#### 4. Рідини, полімери та аморфні речовини

В аморфних тілах (скло, пластики) та рідинах відсутня дальня кристалічна впорядкованість. Довжина вільного пробігу фононів або структурних збуджень стискається до міжатомних відстаней `l ≈ 0.2 – 0.5 нм`. У результаті температуропровідність таких речовин знаходиться на низькому рівні:
- **Вода при 20 °C**: `a ≈ 1.43 × 10⁻⁷ м²/с` (0.143 мм²/с);
- **Моторне масло**: `a ≈ 7.5 × 10⁻⁸ м²/с` (0.075 мм²/с);
- **Поліетилен високої густини (HDPE)**: `a ≈ 1.8 × 10⁻⁷ м²/с`;
- **Кварцове скло (SiO₂)**: `a ≈ 8.5 × 10⁻⁷ м²/с`.

### Безрозмірні числа переносу: Фурьє, Прандтль, Льюїс, Пекле, Біот

При описі конвективного та нестаціонарного переносу тепла температуропровідність входить до складу кількох фундаментальних безрозмірних чисел подібності, які визначають фізичний режим перебігу процесів у теплогідродинаміці.

![Безрозмірні числа переносу та пристінкові шари](/book/physics/thermal-statistical/thermal-diffusivity/img/transport-numbers-boundary.svg)
*Структура пристінкових шарів залежно від числа Прандтля Pr = ν / a: у рідких металах (Pr << 1) температура дифундує швидше за імпульс, тому тепловий пристінковий шар δ_T значно товщий за гідродинамічний δ_v; у газах (Pr ≈ 1) товщини шарів однакові; у в'язких маслах (Pr >> 1) гідродинамічний шар охоплює значно більший об'єм.*

#### 1. Число Фурьє (Fo) та число Біот (Bi)

**Число Фурьє** є критерієм подібності нестаціонарних теплових процесів. Воно дорівнює відношенню поточного часу процесу `t` до характерного часу теплової релаксації системи `t_rel = L² / a`:

```
Fo = a · t / L²
```

де `L` — характерний геометричний розмір тіла (наприклад, товщина пластини чи радіус циліндра).
- При `Fo << 0.1` тепловий імпульс ще не встиг проникнути в товщу тіла; середина об'єму «не знає» про зміну температури на поверхні.
- При `Fo ≈ 0.5 – 1.0` температурне поле по всій товщині тіла стає суттєво нестаціонарним і описується першою гармонікою розкладу в ряд (регулярний тепловий режим).
- При `Fo >> 1` температура у всіх точках тіла повністю вирівнюється, і система доходить до стаціонарного стану.

Взаємодія числа Фурьє з **числом Біот** `Bi = h · L / λ` (відношення зовнішнього конвективного опору до внутрішнього теплового опору) визначає аналітичний вигляд розв'язку:
- Якщо `Bi < 0.1` (модель зосередженої теплоємності), внутрішній перепад температур всередині тіла малий, і швидкість охолодження описується простою експонентою `T(t) - T_env = (T_init - T_env) · exp( - Bi · Fo )`.
- Якщо `Bi > 0.1`, температурне поле є суттєво неоднорідним у просторі, і розрахунок вимагає повного використання температуропровідності `a` в рівнянні теплопровідності.

#### 2. Число Прандтля (Pr) — співвідношення теплової та гідродинамічної дифузії

**Число Прандтля** дорівнює відношенню кінематичної в'язкості (коефіцієнта дифузії імпульсу) до температуропровідності (коефіцієнта дифузії тепла):

```
Pr = ν / a = ( μ / ρ ) / ( λ / (ρ · c_p) ) = μ · c_p / λ
```

Фізичний зміст числа Прандтля полягає у порівнянні товщини гідродинамічного пристінкового шару `δ_v` та температурного пристінкового шару `δ_T` при омиванні тіла потоком рідини чи газу:

```
δ_v / δ_T ≈ √Pr
```

За значенням числа Прандтля всі середовища поділяються на три великі класи:
- **Рідкі метали (натрій, ртуть, сплав Ga-In-Sn)**: `Pr ≈ 0.005 – 0.03 << 1`. Температуропровідність колосально перевершує в'язкість (`a >> ν`). Тепловий пристінковий шар набагато товщий за гідродинамічний (`δ_T >> δ_v`), тому тепло дифундує глибоко в потік ще до того, як сформується шар гальмування швидкості.
- **Гази (повітря, азот, водяна пара)**: `Pr ≈ 0.7 – 1.0 ≈ 1`. Дифузія імпульсу та тепла відбуваються з однаковою швидкістю за рахунок солідарних молекулярних зіткнень. Товщини пристінкових шарів майже збігаються (`δ_v ≈ δ_T`).
- **В'язкі рідини (вода, трансформаторне та моторне масло, гліцерин)**: `Pr ≈ 7 (вода)` і `Pr ≈ 100 – 10000 (масла) >> 1`. В'язкісні сили розповсюджуються набагато швидше за теплові (`ν >> a`). Гідродинамічний пристінковий шар набагато товщий за температурний (`δ_v >> δ_T`).

#### 3. Число Льюїса (Le) та число Пекле (Pe)

- **Число Льюїса** дорівнює відношенню температуропровідності до коефіцієнта масової дифузії: `Le = a / D`. У процесах сушіння, горіння та хімічного синтезу воно показує, що поширюється швидше — тепловий фронт чи фронт концентрації реагентів.
- **Число Пекле** дорівнює відношенню конвективного переносу тепла потоком зі швидкістю `U` до молекулярного переносу теплопровідністю: `Pe = U · L / a = Re · Pr`.

Повний зведення фізичних значень температуропровідності для понад 50 матеріалів та розрахункові формули безрозмірних чисел наведено у 📋 [Довіднику величин температуропровідності та безрозмірних чисел](book:physics/thermal-statistical/thermal-diffusivity/api-thermal-diffusivity-db.md).

### Експериментальні методи визначення температуропровідності

Оскільки виміряти статичний тепловий потік `q` з високою точністю у лабораторних умовах надзвичайно важко через неминучі втрати тепла через випромінювання та конвекцію, пряме вимірювання коефіцієнта теплопровідності `λ` часто дає великі похибки. Натомість вимірювання **часових інтервалів** `t` та **геометричних відстаней** `L` виконується з метрологічною точністю аж до наносекунд та мікрометрів. Тому у сучасній фізиці матеріалів спочатку вимірюють температуропровідність `a`, після чого обчислюють теплопровідність за формулою `λ = a · ρ · c_p`.

![Метод світлового спалаху Паркера (Laser Flash Analysis)](/book/physics/thermal-statistical/thermal-diffusivity/img/laser-flash-method.svg)
*Принцип вимірювання температуропровідності методом Laser Flash Analysis (LFA): короткий лазерний спалах нагріває передню грань зразка товщиною L, а ІЧ-детектор реєструє криву підйому температури T(L,t) на тильній грані. За часом напівпідйому t₁/₂ за формулою Паркера розраховується значення a.*

Основними експериментальними методами є:

#### 1. Метод лазерного спалаху (Laser Flash Analysis, LFA)

Запропонований у 1961 році Вільямом Паркером зі співробітниками, цей метод став світовим стандартом (ASTM E1461, ISO 22007-4).
- Плоский дископодібний зразок завтовшки `L ≈ 1 – 3 мм` розміщується у термостатованій вимірювальній комірці.
- Передня поверхня зразка нагрівається коротким світловим імпульсом лазера або імпульсної ксенонової лампи тривалістю `0.1 – 1 мс`.
- Високошвидкісний інфрачервоний детектор (InSb або MCT), зфокусований на тильну грань зразка, фіксує часову залежність зростання її температури `T(L, t)`.

Усередині ідеально ізольованого зразка без втрат тепла аналітична залежність температури тильної грані має вигляд:

```
T(L, t) = T_max · [ 1 + 2 · ∑_{n=1}^∞ (-1)^n · exp( - n² · π² · a · t / L² ) ]
```

Половина від максимального підйому температури `T(L, t_{1/2}) = 0.5 · T_max` досягається у момент часу `t_{1/2}`, який пов'язаний із температуропровідністю простим співвідношенням Паркера:

```
a = 0.1388 · L² / t_{1/2}
```

Для тонкого диска міді товщиною `L = 2 мм` час напівпідйому становить лише `t_{1/2} ≈ 4.7 мс`, а для кераміки — близько `50 – 100 мс`. Сучасні прилади LFA дозволяють вимірювати температуропровідність у діапазоні від `-150 °C` до `+2800 °C`.

#### 2. Метод періодичних температурних хвиль (Метод Онгстрема)

Запропонований у 1861 році шведським фізиком Андерсом Онгстремом. На один кінець довгого стрижня подаються періодичні імпульси тепла й холоду з частотою `ω`. Дві термопари, розташовані на відстані `Δx = x₂ - x₁`, фіксують осциляції температури. Вимірюючи відношення амплітуд `A₁ / A₂` та фазовий зсув `Δφ`, температуропровідність обчислюють безпосередньо:

```
a = (Δx)² · ω / ( 2 · ln(A₁ / A₂) · Δφ )
```

Головна перевага методу Онгстрема полягає у тому, що зовнішні втрати тепла крізь бічну поверхню стрижня однаково зменшують амплітуду обох термопар і повністю компенсуються у формулі при одночасному вимірюванні амплітуди та фази!

#### 3. Неразрушаючий контроль: активна локін-термографія

На принципі температуропровідних хвиль базується метод **активної термографії (Lock-in Thermography)** для неруйнівного контролю авіаційних композитів та зварних швів. Поверхня деталі піддається модульованому світловому нагріванню. Якщо під поверхнею на глибині `d` є дефект (розшарування, раковина або тріщина), температурна хвиля відбивається від межі розділу. Інфрачервона камера фіксує амплітуду та фазу температурних коливань на поверхні. За фазовим зсувом `Δφ = d / δ = d / √(a/π·f)` обчислюють точну глибину залягання дефекту `d`.

Чисельну алгоритмічну реалізацію явних та неявних схем Кранка-Ніколсон для моделювання методів LFA та Онгстрема з повним кодом на мовах C, C++ та Python наведено у ⚙️ [Чисельному моделюванні температурного імпульсу та методі Flash Analysis](book:physics/thermal-statistical/thermal-diffusivity/proj-laser-flash-solver.md).

### Інженерні та природничі застосування: від мікроелектроніки до геофізики

Розуміння та точний розрахунок температуропровідності відіграють вирішальну роль у багатьох сферах сучасних технологій та фізики Землі.

#### 1. Динамічний тепловий режим мікропроцесорів та силової напівпровідникової електроніки

Сучасні кремнієві процесори споживають питому потужність понад `100 Вт/см²`. Під час виконання важких обчислювальних інструкцій (наприклад, векторних блоків AVX-512 чи матричних помножувачів штучного інтелекту) локальні ділянки кристала («гарячі плями», *hotspots*) виділяють тепло у вигляді коротких сплесків тривалістю від кількох мікросекунд до мілісекунд.

![Сезонні температурні коливання у ґрунті](/book/physics/thermal-statistical/thermal-diffusivity/img/soil-temperature-depth.svg)
*Згасання та фазовий зсув сезонних температурних хвиль у ґрунті (a ≈ 10⁻⁶ м²/с): на поверхні амплітуда коливань між літом і зимою сягає 30 °C, тоді як на глибині згасання δ ≈ 3.17 м вона зменшується в e разів, а на глибині 10 метрів температура залишається сталою протягом усього року.*

Характерний час розповсюдження тепла від кристала кремнію (`a_Si ≈ 9.0 × 10⁻⁵ м²/с`) товщиною `L = 100 мкм` до мідного теплорозподілювача (*IHS*, `a_Cu ≈ 1.17 × 10⁻⁴ м²/с`) визначається формулою:

```
t_relax ≈ L² / a_Si = (10⁻⁴ м)² / (9.0 × 10⁻⁵ м²/с) ≈ 1.1 × 10⁻⁴ с = 110 мкс
```

Якщо тривалість теплового імпульсу менша за `100 мкс`, тепло не встигає вийти за межі кристала. Весь імпульс енергії поглинається безпосередньо об'ємною теплоємністю кремнію у локальній зоні, що може викликати локальний перегрів до `150 °C` та спрацьовування систем термотротлінгу ще до того, як масивний зовнішній радіатор встигне бодай трохи нагрітися! Для боротьби з цим ефектом у найновіших напівпровідникових приладах використовують підкладки з алмазу (`a ≈ 1.1 × 10⁻³ м²/с`), які відводять локальні імпульси тепла у 10 разів швидше за кремній.

#### 2. Аддитивне виробництво та лазерне 3D-друкування металів

У процесах лазерного виплавлення металевого порошку (SLM / DMLS) промінь потужного лазера локально розплавляє мікроскопічну ванну розплаву у порошку титанового сплаву (Ti-6Al-4V) або жароміцного інконелю (Inconel 718). Швидкість охолодження та кристалізації матеріалу визначається виключно температуропровідністю `a`:

```
dT/dt ≈ a · ∇²T
```

При температуропровідності `a ≈ 3 × 10⁻⁶ м²/с` швидкість охолодження становить від `10⁵` до `10⁶ °C/с`. Така стрімка гартування фіксує метастабільні дрібнокристалічні або мартенситні фази в металі, що забезпечує надзвичайно високу механічну міцність надрукованих деталей авіаційних двигунів.

#### 3. Стійкість матеріалів до теплового шоку

Коли крихкий керамічний деталь (наприклад, лопатка газової турбіни чи захисна плитка космічного корабля) піддається раптовому охолодженню чи нагріванню, у ній виникає різкий градієнт температур `∇T`. Приповерхневий шар намагається швидко стиснутися або розширитися, тоді як внутрішня товща тіла зберігає початковий об'єм. Це породжує колосальні термопружні напруження:

```
σ_thermal ≈ E · α_exp · ΔT / (1 - ν_p)
```

де `E` — модуль Юнга, `α_exp` — коефіцієнт лінійного теплового розширення, а `ν_p` — коефіцієнт Пуассона.

Стійкість матеріалу до руйнування при тепловому шоці описується **параметром стійкості до теплового удару Кінгері** `R'_T`:

```
R'_T = σ_fracture · a · (1 - ν_p) / ( E · α_exp )
```

Що вища температуропровідність матеріалу `a`, то швидше вирівнюється температура по товщині деталі, то меншими є тимчасові градієнти `∇T` і то нижчим є ризик утворення катастрофічних тріщин.

#### 4. Геофізика: добові та сезонні хвилі у ґрунті

Ґрунт і гірські породи є типовими тепловими ізоляторами з низькою температуропровідністю `a_soil ≈ 1.0 × 10⁻⁶ м²/с` (1.0 мм²/с). Зміна пір року створює на поверхні Землі зсув температур із періодом `P = 1 рік = 3.1536 × 10⁷ с` (частота `ω = 1.99 × 10⁻⁷ рад/с`).

Обчислимо глибину проникнення річної температурної хвилі в ґрунт:

```
δ_year = √( a_soil · P / π )
= √( (1.0 × 10⁻⁶ м²/с) · (3.1536 × 10⁷ с) / 3.14159 )
≈ 3.17 метрів
```

На глибині `x = 3.17 м` амплітуда річних температурних коливань зменшується в `e ≈ 2.72` раза. На глибині `x = π · δ_year ≈ 10 метрів` коливання повністю гаснуть (менше 4% від амплітуди на поверхні), а зсув фази становить рівно 180° (пів року). Це означає, що на глибині кількох метрів найвищий рівень температури спостерігається взимку (в грудні-січні), а найнижчий — у розпал літа (в липні)!

Цей природний ефект фундаментально використовується в інженерній геології та енергетиці:
- **Льохи та підвали**: завдяки фазовому зсуву та затуханню хвилі температура в глибокому льоху цілий рік тримається на рівні сталої середньорічної температури даної місцевості (близько `+8 – +10 °C`).
- **Геотермальні теплові насоси**: ґрунтові зонди, занурені на глибину понад 10 метрів, відбирають стабільне тепло взимку та використовуються для ефективного кондиціонування будівель улітку.
- **Глибина промерзання ґрунту**: для добових коливань (`P = 24 години = 86400 с`) глибина проникнення становить лише `δ_day ≈ √( 10⁻⁶ · 86400 / π ) ≈ 0.165 м` (16.5 см). Саме тому навіть під час лютих нічних морозів заморозки не проникають глибоко у ґрунт під сніговим покривом.

Таким чином, температуропровідність `a = λ / (ρ · c_p)` виступає універсальним містком між мікроскопічним світом квантових носіїв тепла та макроскопічною динамікою теплових процесів у техніці й природі.
