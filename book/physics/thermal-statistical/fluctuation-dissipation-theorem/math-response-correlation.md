# 🧮 Вивід теореми флуктуації-дисипації через теорію лінійного відгуку

Ця вставка містить детальне математичне виведення теореми флуктуації-дисипації на основі квантової теорії лінійного відгуку Рього Кубо. Мета виведення полягає у тому, щоб показати математично строго й без додаткових спрощувальних наближень, як квантовий комутатор операторів, який визначає причинну реакцію системи на зовнішній удар, пов'язаний з їхнім квантовим антикомутатором або автокореляційною функцією, яка описує спонтанні термодинамічні флуктуації.

---

### 1. Постановка задачі та гамільтоніан збурення

Розглянемо квантовомеханічну систему з незбуреним гамільтоніаном, що перебуває у стані стійкої термодинамічної рівноваги при абсолютній температурі. Стан такої системи описується рівноважною матрицею щільності Канонічного ансамблю Гіббса.

Матриця щільності дає змогу врахувати як квантовомеханічну ймовірнісну природу стану, так і статистичне розпроділення систем у мікроканонічному чи канонічному ансамблі. Зважена сума за всіма власними станами гамільтоніана забезпечує рівномірне підсумовування енергетичних рівнів з больцманівськими ваговими множниками.

```
ρ₀ = exp(-β · H₀) / Z
```

Тут параметр означає обернену температуру (де стала Больцмана задає зв'язок між теплом та енергією), а статистична сума виступає в ролі нормувального множника, який гарантує, що повна ймовірність знаходження системи в усіх можливих станах дорівнює одиниці.

Припустимо тепер, що в далекій минувшині на систему почало повільно чи швидко діяти слабке зовнішнє поле або сила. Збурення взаємодіє з системою через скалярний фізичний оператор, що описує відповідну динамічну змінну.

```
H(t) = H₀ - A · f(t)
```

Наша мета полягає у тому, щоб розрахувати математичне сподівання іншого або того самого фізичного оператора у довільний момент часу та виявити загальну функцію відгуку цієї системи на зовнішній вплив.

---

### 2. Рівняння фон Неймана та теорія збурень першого порядку

Динамічна еволюція часової матриці щільності підпорядковується квантовому рівнянню фон Неймана, яке є квантовим аналогом класичного рівняння Ліувілля для фазового простору.

```
i · ħ · (dρ / dt) = [H(t), ρ(t)]
```

Для виділення чистого збурення зручно перейти до представлення взаємодії, у якому часова залежність самих операторів повністю визначається власним незбуреним гамільтоніаном системи. У цьому представленні матриця щільності залишається незмінною у часі за відсутності зовнішніх сил, а будь-яка її зміна спричиняється виключно зовнішньою дією.

```
A(t) = exp(i · H₀ · t / ħ) · A · exp(-i · H₀ · t / ħ)
ρ_I(t) = exp(i · H₀ · t / ħ) · ρ(t) · exp(-i · H₀ · t / ħ)
```

Рівняння руху для матриці щільності у представленні взаємодії набуває простішого та прозорішого вигляду, де праворуч стоїть лише комутатор збурення з рівноважним станом.

```
i · ħ · (dρ_I / dt) = - [A(t), ρ₀] · f(t)
```

Інтегруючи це диференціальне рівняння від початкового незбуреного стану в нескінченному минулому до поточного моменту часу у першому лінійному порядку теорії збурень за зовнішньою силою, отримуємо явний вираз для зсуву матриці щільності.

```
ρ_I(t) = ρ₀ + (i / ħ) · ∫_{-∞}^{t} [A(t'), ρ₀] · f(t') dt'
```

Тепер обчислимо квантове середнє значення оператора у момент часу за допомогою операції взяття математичного сліду від добутку матриці щільності на відповідний оператор.

```
⟨B(t)⟩ = Tr[ρ(t) · B] = Tr[ρ_I(t) · B(t)]
       = ⟨B⟩₀ + (i / ħ) · ∫_{-∞}^{t} Tr([A(t'), ρ₀] · B(t)) · f(t') dt'
```

Використовуючи фундаментальну алгебраїчну властивість циклічної перестановки операторів під знаком математичного сліду, перепишемо цей вираз у стандартній інтегральній формі лінійного відгуку.

```
⟨B(t)⟩ - ⟨B⟩₀ = ∫_{-∞}^{t} χ_{BA}(t - t') · f(t') dt'
```

Тут виникає причинна функція відгуку, яка також називається ретардованою сприйнятливістю Кубо.

```
χ_{BA}(t) = (i / ħ) · θ(t) · ⟨[B(t), A(0)]⟩₀
```

Хевісайдова східчаста функція строго гарантує виконання фундаментального принципу причинності: фізичний відгук системи ніколи не може випереджати за часом зовнішнє збудження, яке його викликало.

### 3. Фурьє-образ та розділення на дійсну й уявну частини

Для глибокого розуміння спектрального складу відгуку системи доцільно перейти від часового представлення до частотної області за допомогою інтегрального перетворення Фур'є.

```
χ_{BA}(ω) = ∫₀^{∞} χ_{BA}(t) · e^{i · ω · t} dt
```

Оскільки часова функція відгуку є дійснозначною для реальних фізичних спостережуваних величин, її спектральна сприйнятливість у частотній області є комплексною функцією, яка розпадається на дійсну та уявну складові.

Розглянемо уявною частину сприйнятливості. Використовуючи енергетичні співвідношення для гармонічно змінюваного поля, можна строго довести, що саме уявна частина визначає середню поглинуту потужність енергії від зовнішнього поля, тобто репрезентує необоротну дисипацію. За допомогою симетризованого перетворення Фур'є уявна частина виражається через середнє значення комутатора операторів.

```
χ''(ω) = (1 / (2 · ħ)) · ∫_{-∞}^{∞} ⟨[B(t), A(0)]⟩₀ · e^{i · ω · t} dt
```

Позначимо через спектральну густину часової кореляційної функції.

```
S_BA(ω) = ∫_{-∞}^{∞} ⟨B(t) A(0)⟩₀ · e^{i · ω · t} dt
```

Розкриваючи квантовий комутатор як різницю двох операторних добутків, отримуємо явний вираз у вигляді різниці двох спектральних густин, узятих при протилежних знаках частоти.

```
∫_{-∞}^{∞} ⟨[B(t), A(0)]⟩₀ · e^{i · ω · t} dt = S_BA(ω) - S_AB(-ω)
```

### 4. Співвідношення Кубо—Мартіна—Швінгера (умова KMS)

Щоб пов'язати спектр комутатора з температурою термостата, використаємо фундаментальну властивість квантовомеханічного усереднення для канонічного ансамблю Гіббса.

Розглянемо часову кореляційну функцію двох операторів у стані рівноваги.

```
⟨B(t) A(0)⟩₀ = (1 / Z) · Tr[exp(-β · H₀) · B(t) · A(0)]
```

Використовуючи явний вираз для оператора Гейзенберга та циклічну перестановку операторів під знаком математичного сліду, внесемо експоненціальний оператор під знак іншого оператора.

```
Tr[exp(-β · H₀) · B(t) · A(0)]
= Tr[B(t) · exp(-β · H₀) · A(0)]
= Tr[exp(-β · H₀) · exp(β · H₀) · B(t) · exp(-β · H₀) · A(0)]
= Tr[exp(-β · H₀) · A(0) · B(t + i · ħ · β)]
```

Отже, ми довели важливу тотожність у комплексному площині часу, яка показує, що зсув часового аргументу на уявну величину відповідає дії оператора канонічного розподілу.

```
⟨B(t) A(0)⟩₀ = ⟨A(0) B(t + i · ħ · β)⟩₀
```

Переходячи до спектральних густин у частотній області шляхом перетворення Фур'є, цей комплексний зсув часу перетворюється на звичайний експоненціальний множник Больцмана.

```
S_AB(-ω) = e^{-ħ · ω · β} · S_BA(ω)    [Співвідношення KMS]
```

Це співвідношення називається умовою Кубо—Мартіна—Швінгера. Воно слугує строгою математичною ознакою стану термодинамічної рівноваги у квантовій статистичній фізиці та квантовій теорії поля.

### 5. Підстановка умови KMS у вираз для дисипації

Тепер підставимо доведене співвідношення у вираз для уявної частини сприйнятливості для випадку автокореляції однієї фізичної величини.

```
χ''(ω) = (1 / (2 · ħ)) · (S_AA(ω) - S_AA(-ω))
       = (1 / (2 · ħ)) · (1 - e^{-ħ · ω · β}) · S_AA(ω)    [підставили умову KMS S_AA(-ω) = e^{-ħ·ω·β} · S_AA(ω)]
```

Висловимо спектральну густину рівноважних флуктуацій через дисипативну сприйнятливість.

```
S_AA(ω) = 2 · ħ · χ''(ω) / (1 - e^{-ħ · ω · β})
```

Перетворимо множник з експонентою до класичної та квантової форми за допомогою гіперболічного котангенса.

```
1 / (1 - e^{-x})
= e^{x/2} / (e^{x/2} - e^{-x/2})                    [помножили чисельник і знаменник на e^{x/2}]
= (1/2) · (1 + coth(x / 2))                        [за означенням coth(y) = (e^y + e^-y)/(e^y - e^-y)]
```

Тоді симетризована спектральна густина флуктуацій набуває остаточного квантового вигляду, сформульованого Калленом і Велтоном.

```
S_A_sym(ω) = ħ · coth(ħ · ω / (2 · k_B · T)) · χ''(ω)    [Квантова ФДТ Каллена-Велтона]
```

### 6. Класичний граничний перехід та аналіз асимптотик

Розглянемо класичну межу високих температур або низьких частот, коли квант енергії збудження є значно меншим за характерну теплову енергію навколишнього середовища.

Ввівши безрозмірний параметр, скористаємося стандартним розкладом Тейлора для гіперболічного котангенса в околі нуля.

```
coth(x) = 1/x + x/3 - x³/45 + ...
coth(ħ · ω / (2 · k_B · T)) ≈ 2 · k_B · T / (ħ · ω)    [розклад Тейлора при x ≪ 1]
```

Підставляємо цей асимптотичний розклад у квантову формулу.

```
S_A(ω) = ħ · [2 · k_B · T / (ħ · ω)] · χ''(ω)
       = (2 · k_B · T / ω) · χ''(ω)    [Класична теорема флуктуації-дисипації]
```

Ми повністю відтворили класичне співвідношення теореми флуктуації-дисипації.

Розглянемо також протилежну квантову межу низьких температур або високих частот. При температурах, що прямують до абсолютного нуля, параметр прямує до нескінченності, а гіперболічний котангенс прямує до одиниці. Це означає, що спектральна густина шуму більше не залежить від температури і визначається виключно квантовими нульовими коливаннями вакууму з мінімальною енергією.

### 7. Підсумок і фізична інтерпретація виведення

Крок за кроком ми довели фундаментальний ланцюг причинно-наслідкових зв'язків:

1. Причинний відгук описується середньою величиною квантового комутатора операторів, який репрезентує чутливість квантового стану до зовнішнього удару.
2. Спонтанний шум описується середньою величиною квантового антикомутатора або автокореляційної функції.
3. Термодинамічна рівновага (через співвідношення KMS) жорстко пов'язує спектр комутатора (дисипацію) зі спектром антикомутатора (флуктуації) за допомогою температурного множника Больцмана.
4. Головний висновок: Для обчислення рівноважного спектра теплового шуму фізичної системи за будь-якої температури не потрібно розраховувати складні стохастичні траєкторії — достатньо обчислити уявну частину її детермінованої сприйнятливості.
