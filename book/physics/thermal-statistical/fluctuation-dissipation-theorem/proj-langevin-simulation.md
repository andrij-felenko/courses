# ⚙️ Моделювання Ланжевенівського осцилятора та чисельна перевірка ФДТ

Чисельне моделювання стохастичної динаміки Ланжевена для згасаючого гармонічного осцилятора, зануреного у тепловий термостат з температурою T, дозволяє згенерувати часові траєкторії, обчислити автокореляційну функцію швидкості та спектральну густину потужності шуму й експериментально перевірити виконання теореми флуктуації-дисипації на комп'ютері.

---

### Фізична модель та дискретизація стохастичних рівнянь

Рівняння руху гармонічного осцилятора масою, коефіцієнтом в'язкого тертя та власною частотою під дією теплових поштовхів середовища описується стохастичним диференціальним рівнянням Ланжевена.

```
m · (d²x / dt²) = - m · ω₀² · x - γ · (dx / dt) + ξ(t)
```

Тут стохастична сила є гауссівським білим шумом і задовольняє термодинамічну умову теореми флуктуації-дисипації, яка пов'язує інтенсивність випадкових поштовхів з коефіцієнтом в'язкого гальмування та температурою середовища.

```
⟨ξ(t)⟩ = 0,    ⟨ξ(t) ξ(t')⟩ = 2 · γ · k_B · T · δ(t - t')
```

Оскільки флуктуаційна сила виражається через похідну від дельта-корельованого вінерівського процесу, її інтеграл за малий часовий крок дає випадковий приріст. Зі стандартних математичних властивостей вінерівського процесу випливає, що приріст має нульове математичне сподівання та дисперсію, яка є строго пропорційною величині кроку часу.

```
⟨ΔW_n⟩ = 0,    ⟨(ΔW_n)²⟩ = Δt
```

Звідси випливає фундаментальне правило для числового моделювання: середньоквадратична амплітуда стохастичного шумового імпульсу за крок часу масштабується як квадратний корінь з величини кроку часу.

Дискретизація рівняння руху за скінченно-різницевою схемою першого порядку Ейлера—Маруями для фазових координат (координати та швидкості) на рівномірній сітці часу набуває вигляду послідовного оновлення стану системи.

```
Δx[n] = v[n] · Δt
Δv[n] = (- ω₀² · x[n] - (γ / m) · v[n]) · Δt + (1 / m) · √(2 · γ · k_B · T · Δt) · R_n
```

Тут послідовність символізує незалежні стандартизовані нормальні випадкові величини з нульовим середнім та одиничною дисперсією.

### Особливості чисельних інтеграторів та генерація випадкових чисел

У чисельному аналізі стохастичних систем схема Ейлера—Маруями є найпростішою базовою схемою. Проте для тривалого моделювання молекулярної динаміки часто застосовують більш просунуті алгоритми, такі як стохастичний інтегратор Верле у формі Брюгера—Брукса—Карплуса (BBK) або розщеплені схеми типу BAOAB, розроблені Бенедетто Леймкюлером та Чарльзом Меттьюзом. Схема BAOAB забезпечує точне збереження точного канонічного розподілу Гіббса за координатами навіть при відносно великих кроках часової сітки.

Для генерації нормальних випадкових чисел у мові C застосовано двовимірне перетворення Бокса—Мюллера. Цей алгоритм бере два незалежні рівномірно розподілені псевдовипадкові числа у проміжку від нуля до одиниці та за допомогою логарифмічних й тригонометричних функцій перетворює їх на дві незалежні стандартні нормальні величини.

У реалізації на мові C++20 використано сучасні стандартизовані інструменти генерації випадкових чисел з бібліотеки. В якості базового генератора застосовано 64-бітну версію вихру Мерсенна, яка володіє велетенським періодом повторюваності та відмінними статистичними властивостями багановимірного розподілу. Застосування нормального розподілу гарантує високу точність формування гауссівського білого шуму.

```c
/* langevin_fdt.c — Моделювання осцилятора Ланжевена мовою C (C99) */

#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

/* Генератор нормально розподілених випадкових чисел (перетворення Бокса—Мюллера) */
static double generate_gaussian(void) {
    double u1 = (double)rand() / (double)RAND_MAX;
    double u2 = (double)rand() / (double)RAND_MAX;
    if (u1 < 1e-12) u1 = 1e-12; /* Запобігання log(0) */
    return sqrt(-2.0 * log(u1)) * cos(2.0 * M_PI * u2);
}

typedef struct {
    double m;       /* Маса частинки (кг) */
    double gamma;   /* Коефіцієнт тертя (кг/с) */
    double w0;      /* Власна колово частота (рад/с) */
    double T;       /* Температура (К) */
    double kB;      /* Стала Больцмана (Дж/К) */
    double dt;      /* Крок за часом (с) */
} LangevinParams;

void simulate_langevin(const LangevinParams *p, size_t num_steps, double *out_v) {
    double x = 0.0;
    double v = 0.0;
    
    /* Амплітуда стохастичного імпульсу за теоремою ФДТ */
    double noise_amp = sqrt(2.0 * p->gamma * p->kB * p->T * p->dt) / p->m;
    double gamma_over_m = p->gamma / p->m;
    double w0_sq = p->w0 * p->w0;

    for (size_t i = 0; i < num_steps; ++i) {
        double R_n = generate_gaussian();
        double dv = (-w0_sq * x - gamma_over_m * v) * p->dt + noise_amp * R_n;
        double dx = v * p->dt;

        x += dx;
        v += dv;
        out_v[i] = v;
    }
}

/* Обчислення автокореляційної функції Cv(tau) */
void compute_autocorrelation(const double *v, size_t N, size_t max_lag, double *out_Cv) {
    for (size_t lag = 0; lag < max_lag; ++lag) {
        double sum = 0.0;
        size_t count = N - lag;
        for (size_t i = 0; i < count; ++i) {
            sum += v[i] * v[i + lag];
        }
        out_Cv[lag] = sum / (double)count;
    }
}

int main(void) {
    LangevinParams p = {
        .m = 1e-12,         /* 1 пікограм */
        .gamma = 1e-8,      /* В'язкість середовища */
        .w0 = 1000.0,       /* Резонанс 1000 рад/с */
        .T = 300.0,         /* Кімнатна температура 300 К */
        .kB = 1.380649e-23,
        .dt = 1e-6          /* 1 мікросекунда */
    };

    size_t num_steps = 100000;
    size_t max_lags = 200;

    double *v_arr = (double*)malloc(num_steps * sizeof(double));
    double *Cv_arr = (double*)malloc(max_lags * sizeof(double));

    if (!v_arr || !Cv_arr) {
        fprintf(stderr, "Помилка виділення пам'яті\n");
        free(v_arr);
        free(Cv_arr);
        return 1;
    }

    simulate_langevin(&p, num_steps, v_arr);
    compute_autocorrelation(v_arr, num_steps, max_lags, Cv_arr);

    /* Перевірка теореми про рівномірний розподіл енергії: <v^2> = kB * T / m */
    double theoretical_v2 = p.kB * p.T / p.m;
    printf("Обчислено <v^2> (t=0): %.6e м²/с²\n", Cv_arr[0]);
    printf("Теоретичне kB*T/m:    %.6e м²/с²\n", theoretical_v2);
    printf("Відносна похибка:      %.2f%%\n", fabs(Cv_arr[0] - theoretical_v2) / theoretical_v2 * 100.0);

    free(v_arr);
    free(Cv_arr);
    return 0;
}
```

```cpp
// langevin_fdt.cpp — Ідіоматична реалізація на C++20 (RAII, <random>, std::vector, std::span)

#include <iostream>
#include <vector>
#include <cmath>
#include <random>
#include <span>
#include <numeric>
#include <iomanip>

struct LangevinConfig {
    double m{1e-12};         // Маса (кг)
    double gamma{1e-8};      // Тертя (кг/с)
    double w0{1000.0};       // Частота (рад/с)
    double T{300.0};         // Температура (К)
    static constexpr double kB{1.380649e-23};
    double dt{1e-6};         // Крок (с)
};

class LangevinSimulator {
public:
    explicit LangevinSimulator(LangevinConfig config)
        : cfg_(config),
          rng_(std::random_device{}()),
          dist_(0.0, 1.0) {}

    [[nodiscard]] std::vector<double> run(std::size_t num_steps) {
        std::vector<double> velocities;
        velocities.reserve(num_steps);

        double x = 0.0;
        double v = 0.0;

        const double noise_amp = std::sqrt(2.0 * cfg_.gamma * LangevinConfig::kB * cfg_.T * cfg_.dt) / cfg_.m;
        const double gamma_over_m = cfg_.gamma / cfg_.m;
        const double w0_sq = cfg_.w0 * cfg_.w0;

        for (std::size_t i = 0; i < num_steps; ++i) {
            const double R_n = dist_(rng_);
            const double dv = (-w0_sq * x - gamma_over_m * v) * cfg_.dt + noise_amp * R_n;
            const double dx = v * cfg_.dt;

            x += dx;
            v += dv;
            velocities.push_back(v);
        }

        return velocities;
    }

    [[nodiscard]] static std::vector<double> compute_autocorrelation(std::span<const double> v, std::size_t max_lags) {
        std::vector<double> Cv(max_lags, 0.0);
        const std::size_t N = v.size();

        for (std::size_t lag = 0; lag < max_lags; ++lag) {
            double sum = 0.0;
            const std::size_t count = N - lag;
            for (std::size_t i = 0; i < count; ++i) {
                sum += v[i] * v[i + lag];
            }
            Cv[lag] = sum / static_cast<double>(count);
        }

        return Cv;
    }

private:
    LangevinConfig cfg_;
    std::mt19937_64 rng_;
    std::normal_distribution<double> dist_;
};

int main() {
    LangevinConfig cfg{};
    LangevinSimulator sim{cfg};

    const std::size_t num_steps = 100000;
    const std::size_t max_lags = 200;

    const auto v = sim.run(num_steps);
    const auto Cv = LangevinSimulator::compute_autocorrelation(v, max_lags);

    const double theoretical_v2 = LangevinConfig::kB * cfg.T / cfg.m;
    const double error_percent = std::abs(Cv[0] - theoretical_v2) / theoretical_v2 * 100.0;

    std::cout << std::scientific << std::setprecision(6);
    std::cout << "Обчислено <v^2> (t=0): " << Cv[0] << " м²/с²\n";
    std::cout << "Теоретичне kB*T/m:    " << theoretical_v2 << " м²/с²\n";
    std::cout << std::fixed << std::setprecision(2);
    std::cout << "Відносна похибка:      " << error_percent << "%\n";

    return 0;
}
```

### Практичний аналіз похибок, вибір часу та пастки при розробці

Під час практичної розробки та проведення чисельних експериментів зі стохастичними диференціальними рівняннями програмісти часто зіштовхуються з низкою підступних помилок та чисельних артефактів, які спотворюють перевірку теореми флуктуації-дисипації.

Перша та найголовніша пастка полягає у неправильному масштабуванні стохастичної сили за часовим кроком. Якщо розробник за звичкою помножить амплітуду випадкового поштовху на крок часу замість кореня з кроку часу, то при зменшенні кроку сітки чисельний шум почне спадати до нуля значно швидше за тертя. У результаті обчислена кінетична енергія системи прямуватиме до нуля, а ефективна чисельна температура штучно знизиться.

Друга пастка стосується стадії термостабілізації системи. У початковий момент часу програма задає координату та швидкість рівними нулю. Цей стан є строго детермінованим і не належить до рівноважного ансамблю Гіббса. Якщо почати накопичувати статистику автокореляційної функції одразу з першого кроку, результати будуть спотворені перехідним процесом. Необхідно обов'язково виконати так званий прогон релаксації протягом часу, що перевищує характерний час в'язкого згасання, і лише після цього вмикати збір статистичних даних.

Третя пастка пов'язана з вибором кроку інтегрування. Для забезпечення високої стійкості чисельної схеми крок часу повинен бути суттєво меншим за найменший характерний часовий масштаб системи. Для осцилятора існує два таких масштаби: період власних коливань та час релаксації швидкості. Порушення умови стійкості призводить до чисельної вибухової нестійкості, коли амплітуда швидкості експоненціально зростає до нескінченності за кілька кроків.

Четверта пастка виникає при спектральному аналізі швидкостей. Обчислення спектральної густини потужності за допомогою прямого Швидкого Перетворення Фур'є (FFT) без усереднення за сегментами дає дуже зашумлений спектр із відносною похибкою порядку ста відсотків у кожній точці частоти. Для отримання гладкого спектра слід застосовувати метод Велча з розбиттям довгої траєкторії на сегменти, що перекриваються, застосуванням згладжувальних вікон (наприклад, вікна Ханна чи Хеммінга) та наступним усередненням періодограм.

Отриманий таким чином спектр дозволяє строго підтвердити теоретичну формулу Ланжевена для спектральної густини швидкості та отримати точний збіг із передбаченням теореми флуктуації-дисипації.
