# 📋 Інтерфейс аналізу спектральної сприйнятливості та шумової густини

Цей довідник описує детальний програмний та математичний інтерфейс системи обробки спектральних функцій флуктуацій та дисипації. Модуль призначений для розрахунку комплексної сприйнятливості, спектральної густини потужності (PSD) теплового шуму, а також для розв'язання оберненої експериментальної задачі — калібрування фізичних параметрів системи (температури, коефіцієнта тертя, жорсткості) за експериментально виміряним спектром шуму.

Програмний інтерфейс розроблено у вигляді модульної бібліотеки з подвійним API: низькорівневим C-інтерфейсом для інтеграції у вбудовані системи та високорівневим ідіоматичним C++20 інтерфейсом для наукових розрахунків та високопродуктивної обробки сигналів.

---

### 1. Архітектурні принципи та структури даних фізичного середовища

Архітектура програмного інтерфейсу побудована на принципі безстанних (stateless) та потокобезпечних обчислювальних сервісів. Усі обчислювальні функції є строго детермінованими, не використовують глобального стану та можуть безпечно викликатися з багатьох паралельних потоків обробки даних без використання блокувань чи мутексів.

Усі фізичні величини у представленому інтерфейсі подаються виключно в міжнародній системі одиниць СІ (SI). Обчислювальний модуль оперує параметрами фізичної системи, об'єднаними у відповідні структури даних `fdt_system_params_t` у мові C та `SystemParameters` у мові C++.

Структура параметрів описує механічні та термодинамічні властивості одиничного осцилятора. Кожне поле має строго визначений фізичний зміст та допустимий діапазон значень.

| Поле структури | Тип даних | Одиниці вимірювання | Допустимий діапазон | Опис фізичного параметра |
| :--- | :--- | :--- | :--- | :--- |
| `temperature` | `double` | Кельвіни (К) | `T > 0` | Абсолютна температура термостата |
| `mass` | `double` | Кілограми (кг) | `m > 0` | Ефективна маса осцилятора |
| `friction` | `double` | кг/с | `γ > 0` | Коефіцієнт в'язкого гальмування |
| `stiffness` | `double` | Н/м | `k > 0` | Жорсткість пружини / відновлювальна сила |
| `use_quantum` | `bool` | прапорець | `true / false` | Ввімкнення квантових нульових коливань |

Фундаментальні фізичні константи системи задаються у модулі як сталі величини високої точності згідно зі стандартами CODATA:

```
k_B  = 1.380649 × 10⁻²³ Дж/К   — стала Больцмана (точно за визначенням SI)
ħ    = 1.054571817 × 10⁻³⁴ Дж·с — зведена стала Планка
```

Використання цих стандартних структур даних забезпечує єдиний сквозний формат передачі фізичних параметрів між усіма обчислювальними функціями бібліотеки, запобігаючи помилкам плутанини одиниць вимірювання.

### 2. Математичні контракти сприйнятливості та спектральної густини

Узагальнена сприйнятливість визначається як коефіцієнт пропорційності між Фур'є-образом збуджувальної зовнішньої сили та виміряним відгуком системи у частотній області:

```
A(ω) = χ(ω) · F(ω)
```

Для класичного механічного осцилятора сприйнятливість зміщення має вигляд комплексної передавальної функції другого порядку. Вона виражає динамічний баланс між інерційною силою маси, в'язким гальмуванням тертя та відновлювальною силою жорсткості.

```
χ_x(ω) = 1 / (k - m · ω² - i · γ · ω)
```

Дійсна (пружна) та уявна (дисипативна) частини сприйнятливості розділяються алгебраїчно шляхом множення чисельника й знаменника на сопряжене комплексне число. Дійсна частина описує фазово-синхронний відгук, який зберігає енергію коливань, тоді як уявна частина описує квадратурний відгук, відповідальний за необоротну дисипацію.

```
χ'_x(ω) = (k - m · ω²) / ((k - m · ω²)² + γ² · ω²)
χ''_x(ω) = (γ · ω) / ((k - m · ω²)² + γ² · ω²)
```

За теоремою флуктуації-дисипації спектральна густина флуктуацій координат пов'язана з уявною частиною сприйнятливості через температурні множники Больцмана та Планка.

У класичному режимі високих температур або низьких частот спектральна густина дорівнює добутку теплової енергії на уявною частину сприйнятливості, ділену на частоту. Цей вираз задає теоретичний профіль Лоренцівської форми для спектра шуму.

```
S_x(ω) = (2 · k_B · T / ω) · χ''_x(ω) = (2 · k_B · T · γ) / ((k - m · ω²)² + γ² · ω²)
```

У квантовому режимі низьких температур або високих частот класична теплова енергія замінюється на квантовий фактор з гіперболічним котангенсом, який враховує нульові коливання вакууму та планківський розподіл бозонів.

```
S_x(ω) = ħ · coth(ħ · ω / (2 · k_B · T)) · χ''_x(ω)
```

В експериментальній спектроскопії та цифровій обробці сигналів фізичні спектральні аналізатори вимірюють потужність лише на додатних частотах. Для зручності експериментаторів бібліотека надає функцію розрахунку одностороннього спектра, який дорівнює подвоєному значенню двостороннього спектра.

```
G_x(f) = 2 · S_x(2πf) = (4 · k_B · T · γ) / ((k - 4π² m f²)² + 4π² γ² f²)
```

Для багатьох ступенів вільності узагальнена сприйнятливість стає матрицею сприйнятливостей, а спектральна густина шуму перетворюється на матрицю спектральних густин флуктуацій. Модуль підтримує матричні операції для розрахунку перехресних шумових кореляцій між різними координатами.

```cpp
// fdt_analysis.hpp — C++20 Обгортка та аналітичні сервіси

#ifndef FDT_ANALYSIS_HPP
#define FDT_ANALYSIS_HPP

#include <complex>
#include <vector>
#include <span>
#include <optional>

namespace physics::fdt {

struct SystemParameters {
    double temperature{300.0}; // К
    double mass{1e-12};        // кг
    double friction{1e-8};     // кг/с
    double stiffness{1e-3};    // Н/м
    bool use_quantum{false};

    static constexpr double kB = 1.380649e-23;
    static constexpr double hbar = 1.054571817e-34;
};

class FdtAnalyzer {
public:
    explicit FdtAnalyzer(SystemParameters params) : params_(params) {}

    [[nodiscard]] std::complex<double> susceptibility(double omega) const noexcept {
        const double denom_r = params_.stiffness - params_.mass * omega * omega;
        const double denom_i = -params_.friction * omega;
        const std::complex<double> denom{denom_r, denom_i};
        return 1.0 / denom;
    }

    [[nodiscard]] double noise_psd(double omega) const noexcept {
        const auto chi = susceptibility(omega);
        const double chi_pp = chi.imag();

        if (params_.use_quantum && omega > 0.0) {
            const double x = (SystemParameters::hbar * omega) / (2.0 * SystemParameters::kB * params_.temperature);
            return SystemParameters::hbar * (1.0 / std::tanh(x)) * chi_pp;
        }

        return (2.0 * SystemParameters::kB * params_.temperature / omega) * chi_pp;
    }

    [[nodiscard]] double single_sided_psd(double freq_hz) const noexcept {
        const double omega = 2.0 * M_PI * std::abs(freq_hz);
        return 2.0 * noise_psd(omega);
    }

    [[nodiscard]] std::vector<double> generate_psd_spectrum(std::span<const double> freqs_hz) const {
        std::vector<double> spectrum;
        spectrum.reserve(freqs_hz.size());
        for (double f : freqs_hz) {
            spectrum.push_back(single_sided_psd(f));
        }
        return spectrum;
    }

private:
    SystemParameters params_;
};

} // namespace physics::fdt

#endif // FDT_ANALYSIS_HPP
```

### 4. Алгоритм нелінійного аппроксимування та калібрування датчиків

Функція калібрування розв'язує важливу практичну задачу експериментальної фізики: відновлення невідомих механічних параметрів осцилятора (жорсткості та тертя) за експериментально виміряним масивом спектральної густини потужності зміщень.

Підгонка здійснюється шляхом мінімізації цільової функції взваженої суми квадратів відхилень виміряного спектра від теоретичної кривої Лоренцівського профілю, що випливає з ФДТ:

```
S(k, γ) = ∑_{i=1}^{N} w_i · [G_measured(f_i) - G_theoretical(f_i; k, γ)]²
```

Для оптимізації застосовується ітераційний алгоритм Левенберга—Маркварда, який поєднує метод градієнтного спуску у віддалених точках із методом Ньютона—Рафсона поблизу локального мінімуму. Вагові коефіцієнти зазвичай обираються обернено пропорційними квадрату виміряного спектра, що забезпечує однакову відносну вагу вимірювань як на низьких частотах, так і на резонансному піку.

Під час виконання оптимізаційного процесу обчислюються часткові похідні Якобіана цільової функції за шуканими параметрами жорсткості та тертя. Матриця Якобіана дозволяє не лише знайти оптимальну точку мінімуму, а й розрахувати коваріаційну матрицю похибок відновлення параметрів, що надає експериментатору точну статистичну оцінку невизначеності вимірювань.

Відновлені значення жорсткості та тертя дозволяють точно відкалібрувати атомно-силові мікроскопи та оптичні пінцети без застосування прямого механічного контакту з еталонними об'єктами.

### 5. Обробка виняткових ситуацій та граничні випадки

Для забезпечення високої надійності програмного забезпечення наукових приладів обчислювальний модуль містить вбудовану обробку всіх граничних випадків та нефізичних входів:

По-перше, при частоті, що прямує до нуля, пряма підстановка у вираз класичної ФДТ створює математичну невизначеність ділення нуля на нуль. Обчислювальні функції бібліотеки містять явний аналітичний граничний перехід: при значеннях частоти, менших за порогове значення, функція повертає точну скінченну математичну границю спектральної густини, запобігаючи виникненню нечислових значень.

По-друге, усі функції обчислення здійснюють вхідну перевірку структур параметрів. При передачі від'ємних чи нульових значень температури, маси чи тертя функції негайно повертають нульове значення або від'ємний код помилки, запобігаючи нефізичним розрахункам.

По-третє, якщо експериментально виміряний шум суттєво перевищує межу, встановлену теоремою флуктуації-дисипації для даної температури середовища, модуль розраховує ефективну температура системи. Це дає змогу виявляти нерівноважні стани у біологічних об'єктах та живих клітинах.
