### Фізичний коментар та аналіз тенденцій Таблиці 1:

1. **Залежність температури Дебая `Θ_D` від маси та жорсткості:**
   Характеристична температура Дебая `Θ_D ∝ v ∝ √(K / M)` безпосередньо відображає міжмикроскопічну жорсткість хімічного зв'язку `K` та атомну масу `M`. Алмаз володіє найвищою температурою Дебая (`Θ_D = 2230 К`) завдяки легкій масі атома вуглецю та ковалентним зв'язкам. Унаслідок цього алмаз при кімнатній температурі перебуває у глибокій квантовій області заморожування (`T / Θ_D ≈ 0.13`), що дає малу молярну теплоємність `6.115 Дж/(моль·К)`. Навпаки, важкий свинець (`M = 207.2 г/моль`) має м'яку ґратку та низьку температуру Дебая (`Θ_D = 105 К`), тому вже при 100 К свинець повністю досягає класичної межі Дюлонга — Пті.

2. **Залежність електронного коефіцієнта Зоммерфельда `γ` від структури електронних зон:**
   Коефіцієнт Зоммерфельда `γ ∝ g(E_F)` пропорційний електронній густині станів на рівні Фермі. Перехідні d-метали (залізо `γ = 4.98`, нікель `γ = 7.02`, платина `γ = 6.67 мДж/(моль·К²)`) мають високі значення `γ` через те, що рівень Фермі перетинає вузьку d-зону з високою густиною станів. Благородні та лужні метали (мідь `γ = 0.695`, натрій `γ = 1.38`) мають майже вільний s-електронний газ з малою густиною станів, що дає малий електронний внесок.

3. **Багатоатомні лінійні та нелінійні молекули (CO₂, H₂O, CH₄):** Лінійні молекули (CO₂) мають `3N - 5 = 4` коливальні моди (дві деформаційні згинальні з малою енергією `T_vib = 960 К` частково розморожені вже при 300 К, через що `C_V,m ≈ 3.47 R > 2.5 R`). Об'ємна нелінійна молекула води H₂O має 3 обертальні ступені вільності навколо трьох головних осей інерції (`C_V,m ≈ 3.04 R`).

## 4. Температурні поліноми Шомейта (NIST Shomate Equations)

Для високоточного теплового розрахунку хімічних реакцій та парогазових турбін у діапазоні температур від 298 К до 6000 К використовується рівняння Шомейта, що описує молярну теплоємність `C_p^0` (у Дж / (моль · К)) як функцію від безрозмірної нормованої температури `t = T / 1000`:

```
C_p^0(t) = A + B · t + C · t² + D · t³ + E / t²
```

У таблиці наведено стандартні коефіцієнти `A, B, C, D, E` для вибраних речовин у діапазоні температур 298–1200 К.

| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Азот | N₂(g) | 298 – 6000 | 26.09200 | 8.218801 | -1.976141 | 0.159274 | 0.044413 |
| Кисень | O₂(g) | 298 – 1200 | 29.65900 | 6.137261 | -1.186521 | 0.095780 | -0.219663 |
| Двоокис вуглецю | CO₂(g) | 298 – 1200 | 24.99735 | 55.18696 | -33.69137 | 7.948387 | -0.136638 |
| Водяна пара | H₂O(g) | 298 – 1200 | 30.09200 | 6.832514 | 6.793043 | -2.534480 | 0.082139 |
| Метан | CH₄(g) | 298 – 1300 | -0.703029 | 108.4773 | -42.52157 | 5.862788 | 0.678565 |
| Оксид азоту | NO(g) | 298 – 1200 | 23.83491 | 12.56479 | -6.002658 | 1.096732 | 0.054366 |
| Рідка вода | H₂O(l) | 298 – 500 | -203.6060 | 1523.290 | -3196.413 | 2474.455 | 3.855326 |

### Математичні властивості розкладу Шомейта:
Поліноми Шомейта апроксимують плавну криву розморожування коливальних мод Ейнштейна за допомогою 5-параметричної розкладки Тейлора та Лорана. Доданок `E / t²` описує асимптотичний спад при низьких температурах, а кубічні терми `B t + C t² + D t³` апроксимують безперервний ріст коливальної теплоємності при високотемпературному розширенні.

## 5. Таблиця коефіцієнтів перерахунку одиниць вимірювання теплоємності

Питома та молярна теплоємність вимірюються у різних системах одиниць (SI, CGS, британська імперська система). Для швидкого конвертування використовуйте наведені нижче точні співвідношення.


## 7. Приклади прагматичних розрахунків теплових систем

Для демонстрації практичного застосування наведених у довіднику табличних даних розглянемо чотири типові інженерно-фізичні розрахункові задачі.

### Задача 1. Охолодження кремнієвого мікропроцесора
Розглянемо кремнієвий кристальний процесор масою `m = 2.5 г`, який виділяє теплову потужність `P = 65 Вт`. Знайдемо час `t`, за який температура процесора зросте від `T_1 = 25 °C` до критичної межі `T_2 = 85 °C` у разі відмови системи охолодження (пасивний тепловий розгін).

1. З Таблиці 1 знаходимо питому теплоємність кремнію: `c_p = 705 Дж / (кг · К)`.
2. Обчислимо повну теплоємність (теплову масу) кристала:
   ```
   C_chip = m · c_p = 0.0025 кг · 705 Дж/(кг·К) = 1.7625 Дж/К
   ```
3. Виражаємо зміну температури: `ΔT = 85 - 25 = 60 К`.
4. Поглинена теплова енергія: `Q = C_chip · ΔT = 1.7625 · 60 = 105.75 Дж`.
5. Час нагріву без охолодження:
   ```
   t = Q / P = 105.75 Дж / 65 Вт ≈ 1.63 секунди
   ```
*Висновок:* Без системи охолодження висока питома потужність призводить до критичного перегріву напівпровідника менш ніж за 2 секунди.

### Задача 2. Витрата палива газової турбіни на водяній парі
Обчислимо кількість теплоти `Q`, необхідну для нагрівання 1 моля водяної пари `H₂O(g)` від `T_1 = 300 К` до `T_2 = 1000 К` при сталому тиску з використанням поліномів Шомейта.

1. З Таблиці 4 виписуємо коефіцієнти Шомейта для водяної пари: `A = 30.09200`, `B = 6.832514`, `C = 6.793043`, `D = -2.534480`, `E = 0.082139`.
2. Враховуємо нормовані межі інтегрування: `t_1 = 0.3`, `t_2 = 1.0`.
3. Виконуємо аналітичне інтегрування `ΔH = 1000 · ∫_{t_1}^{t_2} C_p^0(t) dt`:
   ```
   ∫ C_p^0(t) dt = [ A · t + ½ B · t² + ⅓ C · t³ + ¼ D · t⁴ - E / t ]_{0.3}^{1.0}
   ```
4. Підстановка меж `t_2 = 1.0` та `t_1 = 0.3` дає значення інтеграла `ΔH ≈ 25.86 кДж/моль`, що дозволяє проектувати камери згоряння з точністю до 0.1%.

### Задача 3. Тепловий акумулятор сонячної електростанції
Обчислимо масу `m` рідкого сольового теплоносія (суміш 60% NaNO₃ + 40% KNO₃, `c_p = 1500 Дж/(кг·К)`), необхідну для накопичення `E = 100 МВт·год` теплової енергії при нагріванні від `T_1 = 290 °C` до `T_2 = 560 °C`.

1. Переводимо енергію в Джоулі: `100 МВт·год = 100 × 10⁶ × 3600 = 3.6 × 10¹¹ Дж`.
2. Температурний напір: `ΔT = 560 - 290 = 270 К`.
3. Необхідна маса теплоносія:
   ```
   m = E / ( c_p · ΔT ) = 3.6×10¹¹ / ( 1500 · 270 ) ≈ 888 888 кг (889 тонн)
   ```
*Висновок:* Для акумулювання 100 МВт·год теплоти у сонячній електростанції вежового типу потрібен резервуар об'ємом близько 490 м³ розплавленої солі.

### Задача 4. Кріогенне випаровування гелію в надпровідному томографі (МРТ)
Обчислимо швидкість випаровування рідкого гелію-4 (в літрах за годину), якщо теплове припливання до кріостата надпровідного магніту становить `P = 0.5 Вт`.

1. З Таблиці 6 та фізичних довідників знаходимо приховану теплоту випаровування рідкого гелію при `T = 4.22 К`: `L_vap = 20.7 кДж/кг`, а густина рідкого гелію `ρ = 125 кг/м³` (125 г/л).
2. Масова швидкість випаровування:
   ```
   dm/dt = P / L_vap = 0.5 Вт / 20700 Дж/кг ≈ 2.415×10⁻⁵ кг/с
   ```
3. Годинна масова витрата: `Δm = 2.415 × 10⁻⁵ × 3600 ≈ 0.0869 кг/год`.
4. Об'ємна витрата рідкого гелію:
   ```
   dV/dt = Δm / ρ = 0.0869 кг/год / 0.125 кг/л ≈ 0.695 літра/годину
   ```
*Висновок:* Теплоприплив всього у 0.5 Вт спричиняє випаровування близько 16.7 літрів дорогого рідкого гелію за добу, що обґрунтовує використання додаткових замкнених кріоохолоджувачів (кріокулерів Гіффорда — Макмагона) для конденсації парів гелію.

## 8. Інженерні розрахунки теплового опору та постійної часу

У тепловому дизайні електронних пристроїв теплоємність системи `C_th = m · c_p` (у Дж/К) разом із тепловим опором `R_th` (у К/Вт) визначає динаміку теплоперехідних процесів та часову сталу thermal time constant `τ`:

```
τ = R_th · C_th
```

Під час імпульсного навантаження на напівпровідниковий прилад (наприклад, короткочасного сплеску струму в силовому транзисторі MOSFET або IGBT тривалістю `t_pulse << τ`) теплова енергія не встигає віддатися через радіатор у довкілля. Увесь тепловий сплеск поглинається внутрішньою тепловою масою кристала кремнію:

```
ΔT_peak = Q_pulse / C_th = ( P_pulse · t_pulse ) / ( m · c_p )
```

Це співвідношення показує, що для захисту напівпровідникових ключів від імпульсного теплового пробою вирішальне значення має максимальне збільшення питомої теплоємності та маси теплового розсіювача безпосередньо під кристалом.

Окрім того, критерій стійкості матеріалів до теплового удару (Thermal Shock Resistance Parameter) `R_s` визначається як:

```
R_s = ( σ_f · λ ) / ( E · α · c_p )
```

де `σ_f` — границя міцності на розрив, `λ` — теплопровідність, `E` — модуль Юнга, `α` — коефіцієнт лінійного теплового розширення, а `c_p` — питома теплоємність. Матеріали з високою теплоємністю та теплопровідністю легко переносять різкі термоциклічні стрибки температури без утворення внутрішніх мікротріщин.

## 9. Матеріали зі зміною фази (PCM) для накопичення теплової енергії

Матеріали зі зміною фази (Phase Change Materials - PCM) є перспективними речовинами для терморегулювання електроніки та пасивного клімат-контролю будівель. Вони використовуються для поглинання або виділення великих обсягів теплоти при фіксованій температурі плавлення.

| Матеріал PCM | Температура плавлення (°C) | Прихована теплота плавлення L (кДж/кг) | Питома теплоємність c_p (кДж/(кг·К)) | Об'ємне накопичення (МДж/м³) |
| :--- | :--- | :--- | :--- | :--- |
| Парафін n-Eicosane (C₂₀H₄₂) | 36.1 | 247 | 2.21 | 192 |
| Парафін n-Octadecane (C₁₈H₃₈) | 28.2 | 244 | 2.15 | 188 |
| Гідрат солі CaCl₂·6H₂O | 29.8 | 190 | 1.42 | 275 |
| Еутектична суміш солей | 117.0 | 185 | 1.55 | 290 |
| Еритритол (цукровий спирт) | 117.7 | 340 | 1.38 | 490 |

Використання парафінових PCM-композитів у системах охолодження мобільних акумуляторів Li-ion дозволяє утримувати температуру батарейного блоку нижче 45 °C під час швидкої зарядки високим струмом. Завдяки високій прихованій теплоті плавлення `L ≈ 200 - 250 кДж/кг` такі матеріали здатні акумулювати у 100 разів більше теплоти під час фазового переходу, ніж звичайний нагрів тієї ж маси металу на один градус.

Наведені у даному довіднику числові значення теплоємностей, фазових температур та поліноміальних коефіцієнтів дозволяють проводити високоточні термодинамічні розрахунки в аерокосмічній галузі, кріогенній фізиці, енергетиці та промисловому матеріалознавстві.
