# 🧮 Статистична теорія та квантове виведення моделей Ейнштейна й Дебая

Ця математична вставка містить строгий статистико-механічний вивід термодинамічних функцій, статистичних сум та теплоємностей речовини у квантових моделях Ейнштейна, Дебая та Зоммерфельда на основі канонічного ансамблю Гіббса та квантової статистики.

## 1. Канонічний ансамбль Гіббса та статистична сума квантового осцилятора

Статистична механіка описує макроскопічні термодинамічні властивості системи через усереднення за мікроскопічними станами. Для системи з фіксованою кількістю частинок `N`, об'ємом `V` та температурою `T` імовірність `P_n` перебування системи у квантовому стані `n` з енергією `E_n` задається канонічним розподілом Гіббса:

```
P_n = ( 1 / Z ) · exp( - E_n / (k_B T) )
```

де `Z` — канонічна статистична сума, яка виконує роль нормувального множника за всіма можливими мікростанами системи у фазовому просторі:

```
Z = ∑ₙ exp( - E_n / (k_B T) )
```

Усі макроскопічні термодинамічні потенціали виражаються безпосередньо через статистичну суму. Зокрема, вільна енергія Гельмгольца `F` дорівнює `F = - k_B T · ln Z`, середня внутрішня енергія системи обчислюється як `U = - (∂ ln Z / ∂ β)` (де `β = 1 / (k_B T)` — зворотна температура), а молярна теплоємність при сталому об'ємі визначається як друга похідна вільної енергії за температурою:

```
C_V = (∂ U / ∂ T)_V = - T · (∂² F / ∂ T²)_V = k_B β² · (∂² ln Z / ∂ β²)
```

Розглянемо одномірний квантовий гармонічний осцилятор із власною частотою `ω`. Згідно з квантовою механікою, його енергетичний спектр є дискретним і задається рівнянням Шредінгера для гармонічного потенціалу:

```
E_n = (n + ½) · ℏ ω,     n = 0, 1, 2, ...
```

де `ℏ = h / (2π)` — зведена стала Планка, а `n` — цілочисельне квантове число осцилятора.

Знайдемо одночастинкову статистичну суму `z` цього квантового осцилятора шляхом підсумовування больцманівських факторів за всіма дискретними енергетичними рівнями:

```
z = ∑ₙ₌₀ºº exp( - E_n / (k_B T) )
  = ∑ₙ₌₀ºº exp( - (n + ½) · ℏ ω / (k_B T) )
  = exp( - ℏ ω / (2 k_B T) ) · ∑ₙ₌₀ºº [ exp( - ℏ ω / (k_B T) ) ]ⁿ
```

Позначимо безрозмірний температурний параметр `x = ℏ ω / (k_B T)`. Сума у виразі являє собою нескінченно спадну геометричну прогресію зі першим членом `a = 1` та знаменником `q = exp(-x) < 1`. Застосовуючи формулу суми геометричної прогресії `S = a / (1 - q)`, отримуємо точний вираз для одночастинкової статистичної суми:

```
z(x) = exp( - x / 2 ) / ( 1 - exp(-x) )
     = 1 / ( 2 · sinh(x / 2) )
```

Середня термодинамічна енергія осцилятора `⟨E⟩` обчислюється як логарифмічна похідна статистичної суми за зворотною температурою `β = 1 / (k_B T)`:

```
⟨E⟩ = - (∂ ln z / ∂ β)
    = - (∂ / ∂ β) [ - ½ β ℏ ω - ln( 1 - exp(- β ℏ ω) ) ]
    = ½ ℏ ω + ( ℏ ω · exp(- β ℏ ω) ) / ( 1 - exp(- β ℏ ω) )
    = ½ ℏ ω + ℏ ω / ( exp( ℏ ω / (k_B T) ) - 1 )
```

У цьому математичному виразі перший доданок `½ ℏ ω` являє собою енергію нульових коливань (квантово-механічний рух осцилятора при абсолютному нулю `T = 0`), а другий доданок описує теплове збудження. Середня кількість квантів (фононів) з енергією `ℏ ω` надається статистикою Бозе — Ейнштейна з нульовим хімічним потенціалом:

```
⟨n⟩ = 1 / ( exp( ℏ ω / (k_B T) ) - 1 )
```

## 2. Зв'язок теплоємності з флуктуаціями внутрішньої енергії

Фундаментальне значення статистичної механіки полягає у встановленні зв'язку між макроскопічним коефіцієнтом поглинання тепла `C_V` та мікроскопічними флуктуаціями енергії системи. Продиференціюємо середнє значення внутрішньої енергії `⟨E⟩ = (1 / Z) · ∑ E_n exp(-β E_n)` за зворотною температурою `β`:

```
(∂ ⟨E⟩ / ∂ β) = (∂ / ∂ β) [ (1 / Z) · ∑ₙ E_n exp(-β E_n) ]
               = - (1 / Z²) · (∂ Z / ∂ β) · ∑ₙ E_n exp(-β E_n) + (1 / Z) · ∑ₙ (- E_n²) exp(-β E_n)
```

Оскільки `(1 / Z) · (∂ Z / ∂ β) = - ⟨E⟩`, перший доданок перетворюється на `+ ⟨E⟩²`, а другий доданок дає `- ⟨E²⟩`. Звідси похідна дорівнює мінусу дисперсії енергії:

```
(∂ ⟨E⟩ / ∂ β) = ⟨E⟩² - ⟨E²⟩ = - ⟨(E - ⟨E⟩)²⟩ = - ⟨(ΔE)²⟩
```

З іншого боку, за правилом диференціювання складеної функції за температурою `T` (де `dβ / dT = - 1 / (k_B T²)`):

```
C_V = (∂ ⟨E⟩ / ∂ T)_V = (∂ ⟨E⟩ / ∂ β) · (dβ / dT) = - ⟨(ΔE)²⟩ · ( - 1 / (k_B T²) )
```

Отримуємо строге флуктуаційно-термодинамічне співвідношення Гіббса:

```
C_V = ⟨(ΔE)²⟩ / (k_B T²)
```

Це співвідношення показує, що ізохорна теплоємність `C_V` є прямо пропорційною середньоквадратичній флуктуації внутрішньої енергії `⟨(ΔE)²⟩` у канонічному ансамблі. Оскільки дисперсія енергії завжди є додатною величиною (`⟨(ΔE)²⟩ ≥ 0`), звідси математично слідує фундаментальна термодинамічна нерівність стійкості: теплоємність будь-якої фізичної системи у стані рівноваги є строго додатною (`C_V > 0`).

## 3. Модель Ейнштейна: тривимірна ґратка незалежних осциляторів

У моделі Ейнштейна (1907 рік) макроскопічний кристалик з `N` атомів описується як система з `3N` невзаємодіючих квантових осциляторів, які здійснюють коливання з однаковою характеристичною частотою `ω_E`.

Повна середня внутрішня енергія кристала `U` дорівнює сумі середніх енергій усіх `3N` незалежних осциляторів:

```
U(T) = 3 N · ⟨E⟩
     = 3 N · ½ ℏ ω_E + 3 N ℏ ω_E / ( exp( ℏ ω_E / (k_B T) ) - 1 )
```

Введемо характеристичну **температуру Ейнштейна** `T_E = ℏ ω_E / k_B`. Для одного моля речовини (`N = N_A`, де `N_A` — число Авогадро) вираз для молярної внутрішньої енергії набуває вигляду:

```
U_m(T) = U_0 + 3 R T_E / ( exp( T_E / T ) - 1 )
```

де `R = N_A k_B` — універсальна газова стала, а `U_0 = 1.5 R T_E` — потенціальна енергія нульових коливань кристалічної ґратки.

Ізохорна молярна теплоємність `C_V^E` обчислюється шляхом диференціювання внутрішньої енергії за температурою:

```
C_V^E = (∂ U_m / ∂ T)_V
      = (d / dT) [ 3 R T_E / ( exp( T_E / T ) - 1 ) ]
      = 3 R T_E · [ - 1 / ( exp( T_E / T ) - 1 )² ] · exp( T_E / T ) · ( - T_E / T² )
      = 3 R · ( T_E / T )² · exp( T_E / T ) / ( exp( T_E / T ) - 1 )²
```

Дослідимо граничні математичні асимптотики формули Ейнштейна:

1. **Високотемпературна межа (`T >> T_E` або `x = T_E / T << 1`):**
   Розкладемо показникову функцію у ряд Тейлора поблизу нуля: `exp(x) ≈ 1 + x + ½ x² + ...`. Тоді знаменник перетворюється на `exp(x) - 1 ≈ x + ½ x² ≈ x`, а чисельник `exp(x) ≈ 1`.
   ```
   C_V^E ≈ 3 R · x² · 1 / x² = 3 R
   ```
   Таким чином, у високотемпературній границі модель Ейнштейна строго відтворює класичний закон Дюлонга — Пті. Якщо врахувати наступний член розкладу Тейлора, отримуємо першу поправку на квантову дискретність: `C_V^E ≈ 3 R · [ 1 - (1/12) · (T_E / T)² ]`.

2. **Низькотемпературна межа (`T << T_E` або `x = T_E / T >> 1`):**
   Оскільки `exp(x) >> 1`, то в знаменнику можна знехтувати одиницею: `exp(x) - 1 ≈ exp(x)`. Тоді знаменник дає `exp(2x)`:
   ```
   C_V^E ≈ 3 R · ( T_E / T )² · exp( T_E / T ) / exp( 2 T_E / T )
         = 3 R · ( T_E / T )² · exp( - T_E / T )
   ```
   У межі `T -> 0` експоненційний множник `exp(-T_E / T)` прямує до нуля незрівнянно швидше за будь-який степеневий множник `(T_E / T)²`. Це експоненційне виморожування теплоємності виникає через існування енергетичної щілини `ℏ ω_E` між основним та першим збудженим станом осцилятора.

## 4. Модель Дебая: густина фононних станів у суцільному середовищі

Експериментальні дослідження показали, що при низьких температурах реальна теплоємність диелектричних кристалів спадає як `T³`, а не експоненційно. Петер Дебай зрозумів, що атоми в кристалі зв'язані між собою пружинними силами, тому вони коливаються не ізольовано, а утворюють колективні зв'язані хвилі деформації (фонони).

Розглянемо кристал об'ємом `V` як суцільне тривимірне пружне середовище. У ньому можуть поширюватися звукові хвилі з фазовою швидкістю `v`. Хвильовий вектор `k` задовольняє лінійне дисперсійне співвідношення `ω = v · k`.

Для кубічного зразка об'ємом `V = L³` граничні умови періодичності Борна — фон Кармана квантують компоненти хвильового вектора:

```
k_x = (2π / L) · n_x,   k_y = (2π / L) · n_y,   k_z = (2π / L) · n_z
```

де `n_x, n_y, n_z` — цілі числа. У k-просторі один дозволений стан займає об'єм `(2π / L)³ = 8 π³ / V`.

Кількість дозволених хвильових станів усередині сфери радіуса `k` дорівнює:

```
N(k) = 3 · [ (4/3) π k³ / (8 π³ / V) ] = 3 · V · k³ / ( 6 π² ) = V k³ / ( 2 π² )
```

Множник 3 враховує три можливі поляризації звукових хвиль: одну поздовжню (з ідеалізованою швидкістю `v_L`) та дві поперечні (зі швидкістю `v_T`). Середня швидкість звуку `v` у середовищі задається співвідношенням `3 / v³ = 1 / v_L³ + 2 / v_T³`.

Виразивши хвильовий вектор через частоту `k = ω / v`, отримуємо кількість станів із частотами, меншими за `ω`:

```
N(ω) = V · ω³ / ( 2 π² v³ )
```

Густина станів `g(ω) = dN / dω` визначається як кількість спектральних мод у вузькому інтервалі частот `[ω, ω + dω]`:

```
g(ω) = (d / dω) [ V · ω³ / ( 2 π² v³ ) ] = ( 3 V · ω² ) / ( 2 π² v³ )
```

Оскільки кристал складається з `N` атомів, загальна кількість незалежних механічних ступенів вільності дорівнює `3N`. Дебай зв'язав суцільну модель із дискретною атомарною ґраткою, обрізавши фононний спектр на граничній частоті зрізання — **частоті Дебая** `ω_D`, з умови нормування:

```
∫₀^ω_D g(ω) dω = 3 N
```

Підставивши вираз для густини станів `g(ω)` в інтеграл нормування, виконуємо обчислення:

```
∫₀^ω_D [ ( 3 V · ω² ) / ( 2 π² v³ ) ] dω = ( 3 V ) / ( 2 π² v³ ) · [ ω_D³ / 3 ] = ( V · ω_D³ ) / ( 2 π² v³ ) = 3 N
```

Звідси виводиться точна формула для граничної частоти Дебая:

```
ω_D = v · ( 6 π² N / V )^(1/3)
```

Характеристична **температура Дебая** `Θ_D` визначається як енергетичний еквівалент частоти зрізання:

```
Θ_D = ℏ ω_D / k_B = ( ℏ v / k_B ) · ( 6 π² N / V )^(1/3)
```

Завдяки температурі Дебая густину станів `g(ω)` можна переписати у параболічній формі:

```
g(ω) = 9 N · ω² / ω_D³
```

## 5. Виведення закону куба температури Дебая

Повна середня внутрішня енергія ґратки в моделі Дебая обчислюється інтегруванням середньої енергії осциляторів за всіма частотами від 0 до `ω_D`:

```
U(T) = U_0 + ∫₀^ω_D [ ℏ ω / ( exp( ℏ ω / (k_B T) ) - 1 ) ] · g(ω) dω
     = U_0 + ∫₀^ω_D [ ℏ ω / ( exp( ℏ ω / (k_B T) ) - 1 ) ] · [ 9 N ω² / ω_D³ ] dω
     = U_0 + ( 9 N ℏ / ω_D³ ) · ∫₀^ω_D [ ω³ / ( exp( ℏ ω / (k_B T) ) - 1 ) ] dω
```

Введемо безрозмірну змінну інтегрування `x = ℏ ω / (k_B T)`. Тоді `ω = x · (k_B T / ℏ)` та `dω = (k_B T / ℏ) dx`. Верхня межа інтегрування перетворюється на безрозмірний параметр `x_D = ℏ ω_D / (k_B T) = Θ_D / T`:

```
U(T) = U_0 + ( 9 N ℏ / ω_D³ ) · ( k_B T / ℏ )⁴ · ∫₀^(Θ_D/T) [ x³ / ( exp(x) - 1 ) ] dx
     = U_0 + 9 N k_B T · ( T / Θ_D )³ · ∫₀^(Θ_D/T) [ x³ / ( exp(x) - 1 ) ] dx
```

Продиференціюємо внутрішню енергію за температурою `T`, щоб знайти ізохорну теплоємність `C_V^D`:

```
C_V^D = (∂ U / ∂ T)_V
      = 9 N k_B · ( T / Θ_D )³ · ∫₀^(Θ_D/T) [ x⁴ · exp(x) / ( exp(x) - 1 )² ] dx
```

Розглянемо низькотемпературну межу (`T << Θ_D` або `x_D = Θ_D / T -> ∞`). У цьому випадку верхня межа інтеграла прямує до нескінченності:

```
J_∞ = ∫₀ºº [ x⁴ · exp(x) / ( exp(x) - 1 )² ] dx
```

Обчислимо цей інтеграл методом інтегрування частинами:

```
∫₀ºº [ x⁴ · exp(x) / ( exp(x) - 1 )² ] dx = 4 · ∫₀ºº [ x³ / ( exp(x) - 1 ) ] dx
```

Для обчислення інтеграла розкладемо підінтегральну функцію `1 / (exp(x) - 1)` у ряд за степенями `exp(-x)`:

```
1 / ( exp(x) - 1 ) = exp(-x) / ( 1 - exp(-x) ) = ∑ₙ₌₁ºº exp( - n x )
```

Підставляючи цей ряд в інтеграл та міняючи місцями знаки інтегрування й сумування:

```
∫₀ºº [ x³ / ( exp(x) - 1 ) ] dx = ∑ₙ₌₁ºº ∫₀ºº x³ · exp( - n x ) dx
```

Здійснюючи заміну змінної `u = n x`, маємо `dx = du / n`:

```
∫₀ºº x³ · exp( - n x ) dx = ( 1 / n⁴ ) · ∫₀ºº u³ · exp(-u) du = ( 1 / n⁴ ) · Γ(4) = 6 / n⁴
```

Отже, сума перетворюється на дзета-функцію Рімана `ζ(4)`:

```
∫₀ºº [ x³ / ( exp(x) - 1 ) ] dx = 6 · ∑ₙ₌₁ºº ( 1 / n⁴ ) = 6 · ζ(4) = 6 · ( π⁴ / 90 ) = π⁴ / 15
```

Підставляючи це точне значення назад у вираз для `J_∞`:

```
J_∞ = 4 · ( π⁴ / 15 ) = ( 4 π⁴ ) / 15
```

Тепер підставимо значення інтеграла `J_∞` у підсумкову формулу теплоємності:

```
C_V^D = 9 N k_B · ( T / Θ_D )³ · [ ( 4 π⁴ ) / 15 ]
      = ( 12 π⁴ / 5 ) · N k_B · ( T / Θ_D )³
```

Для одного моля речовини (`N = N_A`, `N_A k_B = R`):

```
C_V,m^D = ( 12 π⁴ / 5 ) · R · ( T / Θ_D )³ ≈ 233.8 · R · ( T / Θ_D )³
```

Це і є строгий вивід **закону куба температури Дебая**.

Тепер розглянемо високотемпературну межу моделі Дебая (`T >> Θ_D` або `x_D = Θ_D / T << 1`). Оскільки верхня межа інтегрування `x_D` є малою величиною, ми можемо розкласти підінтегральну функцію `x³ / (exp(x) - 1)` у ряд Тейлора: `exp(x) - 1 ≈ x + ½ x² + (1/6) x³`. Тоді `x³ / (exp(x) - 1) ≈ x² · (1 - ½ x + (1/12) x²)`.

Інтегрування цього ряду від 0 до `x_D` дає:

```
∫₀^x_D [ x³ / (exp(x) - 1) ] dx ≈ ⅓ x_D³ - ⅛ x_D⁴ + (1/60) x_D⁵
```

Підставляючи цей розклад у вираз для внутрішньої енергії `U(T)`:

```
U(T) ≈ 9 N k_B T · ( T / Θ_D )³ · [ ⅓ (Θ_D / T)³ - ⅛ (Θ_D / T)⁴ + (1/60) (Θ_D / T)⁵ ]
     = 3 N k_B T - (9/8) N k_B Θ_D + (3/20) N k_B Θ_D² / T
```

Диференціюючи за температурою, отримуємо вираз для молярної теплоємності при високих температурах:

```
C_V,m^D = (∂ U_m / ∂ T)_V ≈ 3 R · [ 1 - (1/20) · ( Θ_D / T )² + ... ]
```

Цей результат показує, що при `T -> ∞` модель Дебая прагне до класичної межі Дюлонга — Пті `3R`, а перша квантова поправка зменшує теплоємність пропорційно `(Θ_D / T)²`.

## 6. Електронна теплоємність Зоммерфельда в металах

У металах крім фононів кристалічної ґратки присутні вільні електромагнітні носії — електронний газ. Класична теорія Друде — Лоренца припускала, що електрони підпорядковуються статистиці Максвелла — Больцмана і мають 3 поступальні ступені вільності, що давало молярну електронну теплоємність `C_e = 1.5 R`. Проте експериментально така велетенська електронна теплоємність не спостерігалася за кімнатної температури.

Арнольд Зоммерфельд розв'язав цю суперечність, застосувавши квантову статистику Фермі — Декілька для електронів із спіном `½`. Згідно з принципом заборони Паулі, у кожному квантовому стані може перебувати не більше одного електрона. При `T = 0` електрони заповнюють усі енергетичні рівні від 0 до енергії Фермі `E_F = k_B T_F`, де температура Фермі `T_F` для металів має порядок `10⁴ - 10⁵ К`.

Розподіл Фермі — Декілька задає ймовірність заповнення стану з енергією `E`:

```
f(E) = 1 / ( exp( (E - μ) / (k_B T) ) + 1 )
```

де `μ` — хімічний потенціал (при `T = 0` `μ = E_F`).

При підвищенні температури від 0 до `T` (де `T << T_F`) теплове збудження розмиває розподіл Фермі лише у вузькому енергетичному прошарку товщиною порядку `k_B T` поблизу поверхні Фермі. Частка електронів, які здатні поглинати теплове збудження, становить приблизно `T / T_F`.

Повна внутрішня енергія електронного газу `U_e(T)` обчислюється як:

```
U_e(T) = ∫₀ºº E · g_e(E) · f(E) dE
```

де `g_e(E)` — електронна густина станів на одиницю енергії. Здійснюючи розклад Зоммерфельда для інтегралів із функцією Фермі при `k_B T << E_F`:

```
U_e(T) ≈ U_e(0) + ( π² / 6 ) · g_e(E_F) · ( k_B T )²
```

Диференціюючи внутрішню енергію за температурою, отримуємо **лінійну електронну теплоємність Зоммерфельда**:

```
C_e = (∂ U_e / ∂ T)_V = ( π² / 3 ) · k_B² · g_e(E_F) · T = γ · T
```

де `γ` — коефіцієнт Зоммерфельда:

```
γ = ( π² / 3 ) · k_B² · g_e(E_F)
```

Для параболічної зони вільних електронів густина станів на рівні Фермі дорівнює `g_e(E_F) = (3 N_e) / (2 E_F)`. Тоді молярний коефіцієнт `γ` набуває вигляду:

```
γ_m = ( π² / 2 ) · R · ( 1 / T_F )
```

Оскільки `T_F ~ 50000 К`, коефіцієнт `γ_m` є дуже малим (порядку `1 - 10 мДж / (моль · К²)`). За кімнатної температури електронний внесок `γ T` становить менше 1% від фононного внеску `3R`, що повністю пояснює парадокс Друде.

## 7. Низьковимірні системи: теплоємність графіту, графену та вуглецевих трубок

У низьковимірних наноструктурах (двовимірний графен, одновимірні вуглецеві нанотрубки та полімерні ланцюжки) геометрія фазового простору суттєво змінює вигляд фононної густини станів `g(ω)`, що призводить до інших степеневих законів теплоємності при низьких температурах.

1. **Двовимірні системи (2D, графен, моношари):**
   У двовимірному k-просторі площа сфери замінюється колом радіуса `k`. Кількість хвильових станів дорівнює `N_2D(k) = S · π k² / (4 π²) = S k² / (4 π)`, де `S` — площа шару.
   Густина фононних станів стає лінійною за частотою: `g_2D(ω) = dN / dω = (S · ω) / (2 π v²)`.
   Інтегрування внутрішньої енергії в 2D дає вираз `U_2D(T) ∝ T³ · ∫ x² / (exp(x) - 1) dx`, що після диференціювання за температурою приводить до **квадратичного закону теплоємності**:
   ```
   C_V,2D(T) ∝ T²
   ```
   Саме через цю двовимірність фононів у моношарі графену або міжшаровому графіті при низьких температурах спостерігається чітка квадратична залежність теплоємності від температури `C_V ∝ T²`, на відміну від кубічного закону `T³` для об'ємного тривимірного кристала.

2. **Одновимірні системи (1D, нанотрубки, полімерні молекули):**
   У одновимірному k-просторі довжина відрізка `2k` займає кількість станів `N_1D(k) = L · (2k) / (2π) = (L · k) / π`, де `L` — довжина ланцюжка.
   Густина фононних станів у 1D є константою, незалежною від частоти: `g_1D(ω) = L / (π v)`.
   Інтегрування внутрішньої енергії приводить до **лінійного закону теплоємності**:
   ```
   C_V,1D(T) ∝ T
   ```
   Таким чином, вимірювання показника степеня `d` у низькотемпературному законі `C_V ∝ T^d` дає прямий експериментальний метод визначення ефективної розмірності `d` фононного переносу в наноструктурах.

## 8. Теоретичний аналіз аномалій теплоємності при фазових переходах

При фазових переходах другого роду (наприклад, переході металу в надпровідний стан або феромагнетика у парамагнітний стан в точці Кюрі) симетрія системи змінюється безперервно, без виділення прихованої теплоти (`L = 0`).

Згідно з феноменологічною теорією Ландау фазових переходів другого роду, вільну енергію системи `F` у околі точки переходу `T_c` розкладають за параметром порядку `η`:

```
F(T, η) = F_0(T) + ½ a · (T - T_c) · η² + ¼ b · η⁴
```

де `a > 0` та `b > 0` — феноменологічні коефіцієнти розкладу.

Мінімізація вільної енергії за параметром порядку (`∂F / ∂η = 0`) дає два розв'язки:
1. При `T > T_c` рівноважний параметр порядку дорівнює нулю (`η = 0`), система перебуває в симетричній фазі, а вільна енергія дорівнює `F = F_0(T)`.
2. При `T < T_c` виникає спонтанна впорядкованість `η² = (a / b) · (T_c - T)`.

Підставляючи цей рівноважний параметр порядку назад у вираз для вільної енергії при `T < T_c`:

```
F(T) = F_0(T) - ( a² / (4 b) ) · (T_c - T)²
```

Диференціюючи вільну енергію двічі за температурою, знаходимо теплоємність `C = - T · (∂² F / ∂ T²)` у двох фазах:
- Для `T > T_c`: `C = C_0(T)`.
- Для `T < T_c`: `C = C_0(T) + ( a² T_c / (2 b) )`.

Отже, теорія середнього поля Ландау передбачає скінченний скачок теплоємності `ΔC_p` у точці фазового переходу `T_c`:

```
ΔC_p = C(T_c^-) - C(T_c^+) = ( a² T_c ) / ( 2 b )
```

У теорії надпровідності Бардіна — Купера — Шріффера (БКШ) цей стрибок теплоємності у точці надпровідного переходу має точне співвідношення `ΔC / C_n = 1.43`, що слугує фундаментальним доказом утворення Куперівських пар електронів.

## 9. Математична узгодженість та граничний синтез моделей

Підсумовуючи математичний аналіз, відзначимо, що всі розглянуті моделі утворюють ієрархію послідовних наближень. Класична теорія рівнорозподілу є вихідною точкою, де середня енергія кожного квадратичного ступеня вільності вважається сталою і дорівнює `½ k_B T`. Квантова модель Ейнштейна усуває безкінечне зростання теплоємності за рахунок урахування дискретності енергетичного спектра окремого осцилятора з фіксованою частотою `ω_E`.

У свою чергу, модель Дебая узагальнює підхід Ейнштейна на випадок суцільного спектра акустичних фононів у пружному середовищі, враховуючи квадратичний розклад густини станів `g(ω) ∝ ω²`. При високих температурах (`T >> Θ_D`) як модель Ейнштейна, так і модель Дебая строго асимптотично переходять у класичну межу Дюлонга — Пті `3R`. Нарешті, модель Зоммерфельда додає лінійний електронний внесок `γ T`, що дозволяє повністю описати термодинаміку металів у всьому діапазоні температур від абсолютного нуля до плавлення.
