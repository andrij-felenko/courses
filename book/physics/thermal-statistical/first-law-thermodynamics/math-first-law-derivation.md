# 🧮 Математичний апарат першого закону: диференціальні форми, неточні диференціали та рівняння Майєра

Перший закон термодинаміки з математичного погляду є диференціальним рівнянням балансу енергії, яке поєднує два фундаментально різних типи математичних об'єктів: повні диференціали функцій стану та неточні диференціали процесових величин. У цьому розділі наведено строгий математичний аналіз дифформалізму Пфаффа, доказ точковості внутрішньої енергії, виведення термодинамічного рівняння стану, фундаментальне виведення рівняння Майєра `C_p - C_v = R` та адіабатного рівняння Пуассона `P·V^γ = const`.

---

### 1. Функції стану та процесів: точні й неточні диференціали

Розглянемо просту закриту термодинамічну систему, стан якої повністю визначається двома незалежними макроскопічними змінними, наприклад об'ємом `V` та температурою `T`.

#### Повний диференціал внутрішньої енергії
Внутрішня енергія `U = U(T, V)` є **функцією стану** (*state function*). Це означає, що її приростом при переході зі стану 1 у стан 2 є однозначна величина, яка визначається лише координатами початкової та кінцевої точок у просторі станів і не залежить від траєкторії процесу:

```
ΔU = ∫[від 1 до 2] dU = U(T₂, V₂) - U(T₁, V₁)
```

Математично це виражається тим, що диференціал `dU` є **точним диференціалом** (*exact differential*). Його розклад за частинними похідними за незалежними змінними `T` та `V` має вигляд:

```
dU = (∂U / ∂T)_V · dT + (∂U / ∂V)_T · dV
```

Згідно з теоремою Шварца про рівність мішаних частинних похідних, для будь-якої двічі диференційовної функцій стану `U(T, V)` виконується умова симетрії:

```
∂ / ∂V [ (∂U / ∂T)_V ] = ∂ / ∂T [ (∂U / ∂V)_T ]
```

Для будь-якого замкненого колового термодинамічного контуру (де система повертається у початковий стан `(T₁, V₁)`) інтеграл від точного диференціала дорівнює нулю:

```
∮ dU = 0
```

#### Диференціальні форми Пфаффа та неточні диференціали тепла й роботи
На відміну від внутрішньої енергії, теплота `δQ` та робота `δW` є **процесовими величинами** (*path functions*). Для них не існує функцій `Q(T, V)` чи `W(T, V)`, значення яких визначалося б лише поточним станом. 

Математичним символом `δ` (або `đ`) позначають **неточний диференціал** (*inexact differential*). Робота елементарного розширення середовища проти зовнішнього тиску `P` виражається диференціальною формою Пфаффа 1-го ступеня:

```
δW = P · dV + 0 · dT
```

Перевіримо умову точного диференціала для формального запису `δW = A(T,V)·dV + B(T,V)·dT`, де коефіцієнти `A = P`, `B = 0`:

```
(∂A / ∂T)_V = (∂P / ∂T)_V
(∂B / ∂V)_T = 0
```

Оскільки при нагріванні газу при сталому об'ємі тиск зростає `(∂P / ∂T)_V ≠ 0`, умова симетрії Шварца ламається:

```
(∂P / ∂T)_V ≠ 0    [умова точного диференціала не виконується]
```

Отже, інтеграл роботи по замкненому контуру не дорівнює нулю:

```
∮ δW = ∮ P · dV = W_циклу ≠ 0
```

За Першим законом термодинаміки `δQ = dU + δW`. Оскільки `δQ` є сумою точного диференціала `dU` та неточного `δW`, диференціал теплоти `δQ` **також є неточним диференціалом**. Його розклад через частинні похідні має вигляд:

```
δQ = (∂U / ∂T)_V · dT + [ (∂U / ∂V)_T + P ] · dV
```

Перевірка умови точного диференціала для `δQ = M(T,V)·dT + N(T,V)·dV`:

```
(∂M / ∂V)_T = ∂ / ∂V [ (∂U / ∂T)_V ]
(∂N / ∂T)_V = ∂ / ∂T [ (∂U / ∂V)_T ] + (∂P / ∂T)_V
```

Оскільки `(∂P / ∂T)_V ≠ 0`, вирази `(∂M / ∂V)_T` та `(∂N / ∂T)_V` є нерівними між собою. Це математично доводить, що теплота залежить від шляху процесу, а циклічний інтеграл тепла точно дорівнює циклічній роботі:

```
∮ δQ = ∮ δW = W_циклу
```

#### Математична теорія інтегрувального множника
З математичного аналізу диференціальних форм Пфаффа від двох змінних випливає фундаментальна теорема: для будь-якої лінійної диференціальної форми `ω = M(x,y)dx + N(x,y)dy` завжди існує **інтегрувальний множник** `μ(x,y)`, такий що добуток `μ · ω` стає точним диференціалом деякої нової функції `S(x,y)`.

У термодинаміці цим інтегрувальним множником для неточного диференціала тепла `δQ` виступає обернена absolute температура `1 / T`:

```
dS = δQ / T = (1 / T) · dU + (P / T) · dV
```

Отримана функція `S` є функцією стану — **ентропією**, що становить математичний міст між Першим та Другим законами термодинаміки.

### 2. Строге виведення термодинамічного рівняння стану та закону Джоуля

Застосуємо апарат частинних похідних для визначення залежності внутрішньої енергії від об'єму для довільного термодинамічного середовища.

Використовуючи співвідношення Максвелла, яке випливає з точного диференціала вільної енергії Гельмгольца `F = U - T·S`:

```
dF = -S · dT - P · dV   ⇒   (∂S / ∂V)_T = (∂P / ∂T)_V
```

Підставимо це співвідношення у вираз для Першого закону `dU = T·dS - P·dV`. Поділивши на `dV` при `T = const`:

```
(∂U / ∂V)_T = T · (∂S / ∂V)_T - P
```

Замінивши `(∂S / ∂V)_T` на `(∂P / ∂T)_V`, отримуємо **термодинамічне рівняння стану**:

```
(∂U / ∂V)_T = T · (∂P / ∂T)_V - P
```

Ця фундаментальна формула дозволяє обчислити залежність `(∂U / ∂V)_T` для будь-якої речовини, знаючи лише її макроскопічне рівняння стану `P = P(T, V)`.

#### Перевірка для ідеального газу
Рівняння стану ідеального газу для 1 моля: `P = R · T / V`.

Обчислимо частинну похідну тиску за температурою при `V = const`:

```
(∂P / ∂T)_V = ∂ / ∂T (R · T / V) = R / V
```

Підставимо у термодинамічне рівняння стану:

```
(∂U / ∂V)_T = T · (R / V) - P = P - P = 0
```

Отже, математично доведено: для ідеального газу частинна похідна `(∂U / ∂V)_T = 0`. Це є строгим математичним доказом **закону Джоуля**: внутрішня енергія ідеального газу не залежить від об'єму, а є функцією виключно температури `U = U(T)`.

### 3. Строге виведення рівняння Майєра

Рівняння Майєра пов'язує молярну теплоємність газу при сталому тиску `C_p` та молярну теплоємність при сталому об'ємі `C_v`.

#### Крок 1. Визначення ізохорної теплоємності C_v
За означенням, молярна теплоємність при сталому об'ємі є відношенням підведеного тепла до приросту температури при `V = const`:

```
C_v = (δQ / dT)_V
```

При `V = const` робота розширення `δW = P·dV = 0`. З Першого закону термодинаміки випливає:

```
δQ = dU = (∂U / ∂T)_V · dT
```

Поділивши на `dT`, отримуємо фундаментальний зв'язок:

```
C_v = (∂U / ∂T)_V
```

#### Крок 2. Визначення ізобарної теплоємності C_p
При сталому тиску `P = const` надане тепло витрачається як на зміну внутрішньої енергії, так і на роботу розширення:

```
δQ = dU + P · dV
```

Підставимо розклад повного диференціала `dU = (∂U / ∂T)_V · dT + (∂U / ∂V)_T · dV`:

```
δQ = [ (∂U / ∂T)_V · dT + (∂U / ∂V)_T · dV ] + P · dV
```

Групуємо доданки при `dV`:

```
δQ = (∂U / ∂T)_V · dT + [ (∂U / ∂V)_T + P ] · dV
```

Поділимо обидві частини на `dT` за умови сталого тиску `P`:

```
C_p = (δQ / dT)_P = (∂U / ∂T)_V + [ (∂U / ∂V)_T + P ] · (∂V / ∂T)_P
```

Підставивши `C_v = (∂U / ∂T)_V`, отримуємо загальну термодинамічну формулу для різниці теплоємностей будь-якого термодинамічного середовища:

```
C_p - C_v = [ (∂U / ∂V)_T + P ] · (∂V / ∂T)_P
```

#### Крок 3. Спрощення для ідеального газу
Для ідеального газу за законом Джоуля `(∂U / ∂V)_T = 0`. 

Формула різниці теплоємностей спрощується до:

```
C_p - C_v = P · (∂V / ∂T)_P
```

#### Крок 4. Застосування рівняння стану Клапейрона — Менделєєва
Записавши рівняння стану для 1 моля ідеального газу `V = R·T / P`, продиференціюємо об'єм по температурі при `P = const`:

```
(∂V / ∂T)_P = ∂ / ∂T (R · T / P) = R / P
```

Підставляємо знайдений похідний коефіцієнт у вираз для `C_p - C_v`:

```
C_p - C_v = P · (R / P) = R
```

Отже, **рівняння Майєра** доведено:

```
C_p - C_v = R
```

Різниця молярних теплоємностей ідеального газу є універсальною константою `R ≈ 8.314 Дж/(моль·К)` і дорівнює роботі, яку виконує 1 моль газу при розширенні під час ізобарного нагрівання на 1 Кельвін.

### 4. Виведення рівняння адіабатного процесу (Рівняння Пуассона)

Адіабатним називається процес, який відбувається без теплообміну із зовнішнім середовищем:

```
δQ = 0
```

#### Крок 1. Диференціальний баланс енергії
З Першого закону термодинаміки для 1 моля ідеального газу:

```
dU + δW = 0
C_v · dT + P · dV = 0     [Рівняння 1]
```

#### Крок 2. Зв'язок через рівняння стану
Диференціюємо рівняння стану 1 моля ідеального газу `P·V = R·T`:

```
P · dV + V · dP = R · dT
dT = (P · dV + V · dP) / R     [Рівняння 2]
```

#### Крок 3. Виключення температури dT
Підставимо `dT` з Рівняння 2 у Рівняння 1:

```
C_v · [ (P · dV + V · dP) / R ] + P · dV = 0
```

Помножимо все рівняння на `R` та скористаємося рівнянням Майєра `R = C_p - C_v`:

```
C_v · (P · dV + V · dP) + (C_p - C_v) · P · dV = 0
C_v · P · dV + C_v · V · dP + C_p · P · dV - C_v · P · dV = 0
```

Доданки `C_v · P · dV` скорочуються, залишаючи:

```
C_v · V · dP + C_p · P · dV = 0
```

#### Крок 4. Інтегрування та адіабатний показник
Поділимо рівняння на `C_v · P · V`:

```
(dP / P) + (C_p / C_v) · (dV / V) = 0
```

Введемо безрозмірний **показник адіабати** (коефіцієнт Пуассона):

```
γ = C_p / C_v
```

Рівняння набуває вигляду:

```
(dP / P) + γ · (dV / V) = 0
```

Проінтегруємо обидві частини:

```
∫ (dP / P) + γ · ∫ (dV / V) = const'
ln(P) + γ · ln(V) = const'
ln(P · V^γ) = const'
```

Потенціюючи, отримуємо першу формацію **рівняння Пуассона**:

```
P · V^γ = const
```

#### Еквівалентні співвідношення Пуассона у змінних (T, V) та (T, P)
Користуючись рівнянням `P = R·T / V`, підставляємо `P` у `P · V^γ = const`:

```
(R · T / V) · V^γ = const
T · V^(γ - 1) = const
```

Аналогічно, виключаючи об'єм `V = R·T / P`:

```
T^γ · P^(1 - γ) = const   (або   T / P^((γ - 1) / γ) = const)
```

Таким чином, для адіабатного розширення тиск падає швидше, ніж при ізотермічному, оскільки газ витрачає власну внутрішню енергію `U` на виконання роботи `W`, що призводить до неминучого охолодження середовища.
