# 🧮 Виведення наближення Буссінеска та безрозмірних параметрів конвекції

Цей математичний аналіз виводить фундаментальні рівняння руху флюїду в умовах природної конвекції на основі наближення Буссінеска. Ми покажемо, як із загальних рівнянь Нав'є — Стокса та переносу тепла шляхом безрозмірності виникають ключові фізичні критерії подібності — числа Грасгофа, Прандтля та Релея, а також виведемо автомодельне рішення Польгаузена — Остраха для примежового шару.

## 1. Термодинамічна лінеаризація рівняння стану

У суцільних середовищах густина флюїду `ρ` залежить від температури `T` та тиску `p`. Для крапельних рідин та газів при невеликих швидкостях течії впливом стисливості від зміни тиску можна знехтувати порівняно з температурним розширенням.

Розкладемо густину у ряд Тейлора поблизу опорної температури `T₀` при сталому тиску `p₀`:

```
ρ(T, p) = ρ(T₀, p₀) + (∂ρ/∂T)_p · (T - T₀) + (∂ρ/∂p)_T · (p - p₀) + ...
```

Ігноруючи акустичні хвилі та стисливість від динамічного тиску (`M << 0.3`), ізотермічною стисливістю зневажаємо. Визначимо ізобарний коефіцієнт об'ємного теплового розширення `β`:

```
β = - (1 / ρ₀) · (∂ρ/∂T)_p
```

де `ρ₀ = ρ(T₀)`. Підставляючи означення `β` у розклад Тейлора, отримуємо лінеаризоване рівняння стану флюїду:

```
ρ(T) = ρ₀ · [1 - β · (T - T₀)]
```

Для ідеального газу з рівнянням стану `p = ρ · R · T` коефіцієнт об'ємного розширення виражається тотожно як:

```
β = - (1 / ρ) · (∂/∂T)(p / (R · T)) = 1 / T
```

де температура `T` виражена у Кельвінах.

**Сутність наближення Жозефа Буссінеска (1870):**
1. Зміною густини `Δρ = ρ - ρ₀` зневажають у всіх членах рівнянь збереження маси та імпульсу, де вона множиться на прискорення (член інерції), вважаючи `ρ ≈ ρ₀ = const`.
2. Зміна густини враховується **виключно** у члені масових сил гравітації `ρ · g`, оскільки саме різниця вагових сил створює виштовхувальну силу плавучості.

## 2. Виведення рівняння руху та сили плавучості

Розглянемо рівняння руху Нав'є — Стокса у векторній формі для в'язкої рідини під дією поля сили тяжіння `g`:

```
ρ · (∂u/∂t + (u · ∇)u) = -∇p + μ · ∇²u + ρ · g
```

Розділимо повний тиск `p` на гідростатичний тиск `p₀`, який знаходиться у механічній рівновазі з нерухомим флюїдом при опорній температурі `T₀`, та динамічний надлишковий тиск `p'`:

```
∇p₀ = ρ₀ · g
p = p₀ + p'
```

Підставимо розклад тиску `p` та лінеаризовану густину `ρ(T)` у праворуч рівняння Нав'є — Стокса:

```
-∇p + ρ(T) · g
= -(∇p₀ + ∇p') + ρ₀ · [1 - β · (T - T₀)] · g
= -∇p₀ - ∇p' + ρ₀ · g - ρ₀ · β · (T - T₀) · g
= -∇p' - ρ₀ · β · (T - T₀) · g        [оскільки -∇p₀ + ρ₀·g = 0]
```

Застосовуючи перше припущення Буссінеска до лівої частини (`ρ ≈ ρ₀`), поділимо обидві частини рівняння на сталу опорну густину `ρ₀` та введемо кінематичну в'язкість `ν = μ / ρ₀`:

```
∂u/∂t + (u · ∇)u = - (1 / ρ₀) · ∇p' + ν · ∇²u - β · (T - T₀) · g
```

Член `f_b = - β · (T - T₀) · g` являє собою питому силу плавучості (архімедів подразник), спрямовану проти вектора гравітації для нагрітих елементів (`T > T₀`).

## 3. Повна система рівнянь природної конвекції

До рівняння руху додаємо рівняння нерозривності для нестисливого флюїду та рівняння переносу теплової енергії:

```
∇ · u = 0                                                          [нерозривність]
∂u/∂t + (u · ∇)u = - (1 / ρ₀) · ∇p' + ν · ∇²u - β · (T - T₀) · g   [імпульс]
∂T/∂t + (u · ∇)T = α · ∇²T                                         [енергія]
```

де `α = k / (ρ₀ · c_p)` — температуропровідність флюїду, `k` — теплопровідність, `c_p` — питома ізобарна теплоємність.

## 4. Зведення до безрозмірного вигляду та виділення комплексу Грасгофа й Релея

Для зведення рівнянь до безрозмірного вигляду введемо характерні масштаби системи:
- Масштаб довжини: `L` (наприклад, висота пластини або товщина шару);
- Безрозмірна координата: `x* = x / L`, оператор `∇* = L · ∇`;
- Масштаб температури: `ΔT = T_wall - T_ambient`;
- Безрозмірна температура: `θ = (T - T_ambient) / ΔT`;
- Масштаб швидкості дифузії тепла: `U₀ = α / L`;
- Безрозмірна швидкість: `u* = u / U₀ = u · L / α`;
- Безрозмірний час: `t* = t · α / L²`;
- Безрозмірний надлишковий тиск: `p* = p' · L² / (ρ₀ · α²)`.

Підставимо безрозмірні змінні у рівняння переносу імпульсу:

```
(α² / L³) · [ ∂u*/∂t* + (u* · ∇*)u* ]
= - (α² / L³) · ∇*p* + (ν · α / L³) · ∇*²u* - g · β · ΔT · θ
```

Помножимо все рівняння на `L³ / α²`:

```
∂u*/∂t* + (u* · ∇*)u*
= -∇*p* + (ν / α) · ∇*²u* - [ (g · β · ΔT · L³) / α² ] · θ · n_g
```

де `n_g = g / |g|` — одиничний вектор напрямку гравітації.

Згадаємо, що число Прандтля `Pr` за означенням дорівнює співвідношенню дифузій імпульсу та тепла:

```
Pr = ν / α
```

Перепишемо коефіцієнт при температурному члені, помноживши й поділивши його на `ν²`:

```
(g · β · ΔT · L³) / α²
= [ (g · β · ΔT · L³) / ν² ] · (ν / α)²
= Gr · Pr²
```

де введено **число Грасгофа** (`Gr`):

```
Gr = (g · β · ΔT · L³) / ν²
```

Отже, безрозмірне рівняння руху Буссінеска набуває остаточного вигляду:

```
∂u*/∂t* + (u* · ∇*)u* = -∇*p* + Pr · ∇*²u* + Gr · Pr² · θ · n_g
```

Добуток числа Грасгофа на число Прандтля утворює **число Релея** (`Ra`):

```
Ra = Gr · Pr = (g · β · ΔT · L³) / (ν · α)
```

Отже, множник при плавучості можна виразити як `Gr · Pr² = Ra · Pr`.

## 5. Двовимірна форма у змінних завихреність — функція току (`ω - ψ`)

Для двовимірних течій у площині `(x, y)` зручно усунути тиск `p'`, застосувавши оператор ротора до рівняння руху. Введемо завихреність `ω` та функцію току `psi`:

```
u = ∂psi/∂y,   v = -∂psi/∂x
ω = ∂v/∂x - ∂u/∂y = -∇²psi
```

Рівняння переносу завихреності та температури у безрозмірній формі:

```
∂ω*/∂t* + u*·(∂ω*/∂x*) + v*·(∂ω*/∂y*) = Pr · ∇*²ω* + Ra · Pr · (∂θ/∂x*)
∂θ/∂t* + u*·(∂θ/∂x*) + v*·(∂θ/∂y*) = ∇*²θ
∇*²psi* = -ω*
```

Член `Ra · Pr · (∂θ/∂x*)` являє собою генерацію завихреності за рахунок горизонтального градієнта температури.

## 6. Лінійний аналіз стійкості конвекції Рейле — Бенара

Розглянемо горизонтальний шар рідини товщиною `d`, нагрітий знизу (`T(0) = T_bot`, `T(d) = T_top`).

У базовому стан нерухомості (`u₀ = 0`) температура змінюється за лінійним законом:

```
T_base(z) = T_bot - (ΔT / d) · z
```

Накладемо малі збурення: `u = u'`, `T = T_base + T'`. Лінеаризовані рівняння збурень для вертикальної компоненти швидкості `w'` та температури `T'`:

```
(∂/∂t - ν·∇²) ∇²w' = g · β · ∇_H² T'
(∂/∂t - α·∇²) T' = (ΔT / d) · w'
```

де `∇_H² = ∂²/∂x² + ∂²/∂y²` — двовимірний лапласіан у горизонтальній площині.

Шукаємо рішення у вигляді нормальних мод:

```
w'(x, y, z, t) = W(z) · exp(i·k_x·x + i·k_y·y + λ·t)
T'(x, y, z, t) = Θ(z) · exp(i·k_x·x + i·k_y·y + λ·t)
```

де `k² = k_x² + k_y²` — квадрат горизонтального хвильового числа. На межі стійкості (нейтральна стійкість, `λ = 0`) виключаємо `Θ(z)` та зводимо систему до єдиного диференціального рівняння 6-го порядку для `W(z)` у безрозмірних координатах `z* = z / d`:

```
(D² - a²)³ W = - Ra · a² · W
```

де `D = d/dz*`, `a = k · d` — безрозмірне хвильове число.

### Граничні умови та знаходження `Ra_c`:

1. **Для двох вільних меж (без тертя):** `W = 0`, `D²W = 0`, `D⁴W = 0` при `z* = 0` та `z* = 1`.
Точне рішення шукається у вигляді `W(z*) = sin(π·z*)`. Підставляючи у рівняння:

```
(π² + a²)³ = Ra · a²
Ra(a) = (π² + a²)³ / a²
```

Мінімум функції `Ra(a)` визначається з умови `dRa/da = 0`:

```
d/da [ (π² + a²)³ / a² ] = 0
==> a_c² = π² / 2  ==> a_c = π / √2 ≈ 2.22
Ra_c = (π² + π²/2)³ / (π²/2) = (3/2 π²)³ / (1/2 π²) = (27 / 4) · π⁴ ≈ 657.5
```

2. **Для двох твердих меж (умова прилипання):** `W = 0`, `DW = 0` при `z* = 0` та `z* = 1`.
Чисельне розв'язання граничної задачі методом пристрілки дає:

```
a_c ≈ 3.117
Ra_c ≈ 1707.76
```

Якщо `Ra > 1707.76`, шар втрачає стійкість і в ньому розвивається конвекція.

## 7. Автомодельне рішення Остраха для ламінарного примежового шару

Для вертикальної гарячої пластини висотою `H` у нескінченному об'ємі рідини рівняння ламінарного примежового шару мають вигляд:

```
∂u/∂x + ∂v/∂y = 0
u · (∂u/∂x) + v · (∂u/∂y) = ν · (∂²u/∂y²) + g · β · (T - T_∞)
u · (∂T/∂x) + v · (∂T/∂y) = α · (∂²T/∂y²)
```

Запровадимо автомодельну змінну Саймона Остраха (1953) `η`:

```
Gr_x = (g · β · (T_w - T_∞) · x³) / ν²
η = (y / x) · (Gr_x / 4)^(1/4)
```

Функція току `psi` та безрозмірна температура `θ`:

```
psi(x, y) = 2 · √2 · ν · Gr_x^(1/4) · f(η)
θ(η) = (T(x, y) - T_∞) / (T_w - T_∞)
```

Компоненти швидкості виражаються як:

```
u = ∂psi/∂y = (2 · ν / x) · Gr_x^(1/2) · f'(η)
v = -∂psi/∂x = (ν / x) · (Gr_x / 4)^(1/4) · [ η · f'(η) - 3 · f(η) ]
```

Підставляючи розклади у вихідні рівняння примежового шару, отримуємо систему двох зв'язаних звичайних диференціальних рівнянь (ЗДРУ):

```
f''' + 3 · f · f'' - 2 · (f')² + θ = 0
θ'' + 3 · Pr · f · θ' = 0
```

з граничними умовами:

```
f(0) = 0,   f'(0) = 0,   θ(0) = 1       [на стінці η = 0]
f'(∞) -> 0,  θ(∞) -> 0                  [у довкіллі η -> ∞]
```

Чисельне інтегрування цієї системи методом Рунге — Кутти 4-го порядку для повітря (`Pr = 0.72`) дає `θ'(0) ≈ -0.5046`.

Звідси місцеве число Нуссельта на висоті `x`:

```
Nu_x = (h_x · x) / k = -θ'(0) · (Gr_x / 4)^(1/4) = 0.357 · Gr_x^(1/4) = 0.478 · Ra_x^(1/4)
```

Середнє число Нуссельта по всій висоті пластини `H`:

```
Nu_H = (1 / H) · ∫ [0..H] Nu_x dx = (4 / 3) · Nu_x(H) ≈ 0.637 · Ra_H^(1/4)
```

Це автомодельне виведення теоретично обґрунтовує експериментальний показник ступеня `1/4` у залежностях тепловіддачі для ламінарної природної конвекції.
