# 🧮 Математика психометричного рівняння та точка роси

Ця математична вставка містить повне диференціальне виведення термодинамічного балансу тепло- та масообміну вологого термометра, математичну формуляцію тиску насиченої водяної пари (рівняння Клапейрона-Клаузіуса та Магнуса-Тетенса), а також аналітичний вивід точного співвідношення для обчислення температури точки роси, точки інею та ентальпії вологого повітря.

---

### 1. Рівняння Клапейрона-Клаузіуса та тиск насиченої пари

Фазовий перехід рідкої води у стан насиченої пари перебуває під суворим термодинамічним контролем рівняння Клапейрона-Клаузіуса, яке виражає зв'язок між зміною тиску насичення `P_s` та абсолютною температурою `T`:

```
dP_s / dT = L_v / (T · (v_g - v_l))      [рівняння Клапейрона-Клаузіуса]
```

Де `L_v` — питома прихована теплота випаровування води, `v_g` — питомий об'єм газової фази (водяної пари), `v_l` — питомий об'єм рідкої води.

Оскільки питомий об'єм газу `v_g` за помірних атмосферних температур на три порядки перевищує питомий об'єм рідини `v_l` (`v_g ≫ v_l`), об'ємом рідкої фази можна знехтувати (`v_g - v_l ≈ v_g`). Вважаючи водяну пару ідеальним газом із молярною масою `M_w = 18.0152 г/моль`, виразимо питомий об'єм за рівнянням стану:

```
v_g = (R · T) / (M_w · P_s)              [рівняння стану для одиниці маси]
```

Підставивши вираз для `v_g` у диференціальне рівняння Клапейрона-Клаузіуса, отримуємо:

```
dP_s / dT
= L_v / (T · (R · T / (M_w · P_s)))     [підстановка v_g]
= (L_v · M_w · P_s) / (R · T²)            [спрощення дробу]
```

Розділивши змінні `P_s` та `T`, маємо:

```
dP_s / P_s
= (L_v · M_w / R) · (dT / T²)             [розділені змінні]
```

Інтегруючи це рівняння за припущення про сталість прихованої теплоти випаровування `L_v`, отримуємо базову формулу Клаузіуса: `P_s(T) = P_0 · exp((L_v · M_w / R) · (1/T_0 - 1/T))`.

Проте прихована теплота випаровування залежить від температури за законом Кірхгофа: `dL_v / dT = c_pv - c_pl`, де `c_pv` — питома теплоємність водяної пари, `c_pl` — питома теплоємність рідкої води. Враховуючи цю залежність при інтегруванні, для широкого інженерного інтервалу від -40°C до +50°C отримуємо напівемпіричне рівняння Магнуса-Тетенса:

```
P_s(T) = a · exp((b · T) / (c + T))       [формула Магнуса]
```

Де `T` — температура у градусах Цельсія (°C), `P_s` — тиск у паскалях (Па), а коефіцієнти становлять:
- **Над рідкою водою (T ≥ 0°C):** `a = 611.21 Па`, `b = 17.502`, `c = 240.97 °C`.
- **Над льодом (T < 0°C):** `a = 611.15 Па`, `b = 22.452`, `c = 272.55 °C`.

Парціальний тиск водяної пари `P_v` при відомій відносній вологості `Ф` (у відсотках від 0 до 100%) виражається відношенням:

```
P_v = (Ф / 100) · P_s(T)                  [знаходження парціального тиску]
```

### 2. Термодинамічний баланс психрометра та аналогія Чилтона-Колборна

У стаціонарному стані вологий термометр психрометра досягає рівноважної температури `T_w`, при якій конвективний приплив тепла від оточуючого повітря з температурою `T` повністю компенсується витратою енергії на випаровування води з ґнота.

Розглянемо тепловий потік `Q_conv`, що надходить до вологого резервуара площею `A`:

```
Q_conv = h_c · A · (T - T_w)             [закон конвективного теплообміну Ньютона-Ріхмана]
```

Де `h_c` — коефіцієнт конвективної тепловіддачі (Вт/(м²·К)).

Одночасно масовий потік випаруваної води `m_evap` визначається законом масообміну Дальтона:

```
m_evap = k_m · A · (ρ_s(T_w) - ρ_v)       [закон масопереносу]
```

Де `k_m` — коефіцієнт масовіддачі (м/с), `ρ_s(T_w)` — густина насиченої пари при температурі вологого термометра `T_w`, `ρ_v` — фактична густина пари у набігаючому потоці.

Застосувавши рівняння стану ідеального газу для густини пари `ρ_v = (P_v · M_w) / (R · (T + 273.15))`, виразимо поглинуту приховану теплоту випаровування `Q_evap`:

```
Q_evap
= m_evap · L_v                            [прихована теплота випаровування]
= k_m · A · (M_w / (R · T)) · (P_s(T_w) - P_v) · L_v   [підстановка густини]
```

У стаціонарній термодинамічній рівновазі `Q_conv = Q_evap`:

```
h_c · A · (T - T_w)
= k_m · A · (M_w / (R · T)) · L_v · (P_s(T_w) - P_v)   [рівність теплових потоків]
```

Скоротивши площу `A` та виразивши парціальний тиск `P_v`, отримуємо:

```
P_v
= P_s(T_w) - (h_c / (k_m · L_v · (M_w / (R · T)))) · (T - T_w)   [вираження P_v]
= P_s(T_w) - A_psych · P · (T - T_w)                             [канонічне психрометричне рівняння]
```

За аналогією Чилтона-Колборна для перенесення імпульсу, тепла й маси в прикордонному шарі відношення коефіцієнтів тепловіддачі та масовіддачі виражається через безрозмірне число Люїса `Le = h_c / (c_p · k_m · ρ)`:

```
A_psych = (c_p · M_d) / (M_w · L_v · Le)                          [теоретичне виведення психрометричної константи]
```

Для бінарної суміші «повітря — водяна пара» число Люїса близьке до одиниці (`Le ≈ 1`), що дає для аспіраційного психрометра Ассмана при швидкості потоку `v ≥ 2.5 м/с` значення:

```
A_psych ≈ 6.66 × 10⁻⁴ K⁻¹               [значення для води при атмосферному тиску]
```

Якщо вологий термометр покритий льодом (при `T_w < 0°C`), прихована теплота випаровування замінюється прихованою теплотою сублімації `L_s = L_v + L_f = 2834 кДж/кг`, і константа стає дорівнювати:

```
A_ice ≈ 5.94 × 10⁻⁴ K⁻¹                 [значення для льоду]
```

### 3. Аналітичне виведення температури точки роси

Точка роси `T_d` виражає температуру, до якої треба ізобарично охолодити повітря, щоб фактичний парціальний тиск водяної пари `P_v` став тиском насичення: `P_s(T_d) = P_v`.

Скориставшись формулою Магнуса для `P_s(T_d)` та `P_s(T)`:

```
P_s(T_d) = a · exp((b · T_d) / (c + T_d))                        [тиск насичення при T_d]
P_v = (Ф / 100) · a · exp((b · T) / (c + T))                      [фактичний парціальний тиск]
```

Прирівнюємо `P_s(T_d) = P_v`:

```
a · exp((b · T_d) / (c + T_d))
= (Ф / 100) · a · exp((b · T) / (c + T))                          [прирівняння тисків]
```

Скорочуємо множник `a` та логарифмуємо обидві частини рівняння:

```
ln(exp((b · T_d) / (c + T_d)))
= ln(Ф / 100) + ln(exp((b · T) / (c + T)))                        [логарифмування]

(b · T_d) / (c + T_d)
= (b · T) / (c + T) + ln(Ф / 100)                                 [спрощення логарифма]
```

Введемо проміжну безрозмірну функцію `γ(T, Ф)`:

```
γ(T, Ф) = (b · T) / (c + T) + ln(Ф / 100)                          [визначення параметра γ]
```

Тепер рівняння набуває алгебраїчного вигляду:

```
(b · T_d) / (c + T_d) = γ(T, Ф)                                    [рівняння відносно T_d]
```

Розв'язуємо відносно `T_d`:

```
b · T_d = γ(T, Ф) · (c + T_d)                                       [розкриття знаменника]
b · T_d = c · γ(T, Ф) + T_d · γ(T, Ф)                              [розкриття дужок]
T_d · (b - γ(T, Ф)) = c · γ(T, Ф)                                  [перенесення доданків з T_d ліворуч]
T_d = (c · γ(T, Ф)) / (b - γ(T, Ф))                                [остаточна формула точки роси]
```

Ця формула дає високу точність обчислення точки роси (похибка не перевищує `±0.1°C` в діапазоні температур від 0°C до 50°C та відносної вологості від 1% до 100%).

### 4. Точка інею (Frost Point) при від'ємних температурах

При температурах нижче 0°C насичена пара може перебувати у двох фазових станах: над переохолодженою рідкою водою або над твердим льодом.

Визначення температури точки інею `T_f` здійснюється за тим самим принципом, але з використанням коефіцієнтів сублімації льоду:

```
γ_ice(T, Ф) = (22.452 · T) / (272.55 + T) + ln(Ф / 100)             [параметр γ для льоду]
T_f = (272.55 · γ_ice(T, Ф)) / (22.452 - γ_ice(T, Ф))               [температура точки інею, °C]
```

Оскільки `P_s,ice(T) < P_s,water(T)`, значення точки інею при від'ємних температурах завжди лежить вище точки роси. Різниця `T_f - T_d` досягає `0.5°C` при -10°C та зростає до `1.2°C` при -20°C.

### 5. Влаговміст, абсолютна вологість та ентальпія вологого повітря

Вологе повітря розглядається як бінарна суміш сухого повітря масою `m_d` та водяної пари масою `m_v`.

#### Влаговміст `w` (масова частка пари на кг сухого повітря)
За законом Дальтона співвідношення мас дорівнює співвідношенню молярних мас та парціальних тисків:

```
w = m_v / m_d
= (M_w · P_v) / (M_d · (P - P_v))                                  [співвідношення молярних мас]
= 0.62198 · (P_v / (P - P_v))                                      [де M_w/M_d = 18.0152/28.9644 ≈ 0.622]
```

Якщо `w` виражають у грамах пари на кілограм сухого повітря (г/кг):

```
w = 621.98 · (P_v / (P - P_v))                                     [значення у г/кг]
```

#### Абсолютна вологість `ρ_v` (густина пари в об'ємі)
Визначається масою водяної пари в одному кубічному метрі вологого повітря:

```
ρ_v = m_v / V
= (P_v · M_w) / (R · (T + 273.15))                                 [у кг/м³]
= 2.1667 · (P_v / (T + 273.15))                                    [де P_v у Па, ρ_v у г/м³]
```

#### Питома ентальпія вологого повітря `h`
Аддитивна сума ентальпій сухого повітря та водяної пари з урахуванням фазового переходу, віднесена до 1 кг сухого повітря (кДж/кг):

```
h = c_pd · T + w · (L_v0 + c_pv · T)                               [формула ентальпії]
```

Де:
- `c_pd = 1.006 кДж/(кг·К)` — питома теплоємність сухого повітря за постійного тиску;
- `c_pv = 1.86 кДж/(кг·К)` — питома теплоємність водяної пари;
- `L_v0 = 2501 кДж/кг` — питома прихована теплота випаровування води при 0°C;
- `w` — влаговміст у кг/кг сухого повітря.

Спрощена інженерна формула для ентальпії:

```
h = 1.006 · T + w · (2501 + 1.86 · T)                               [інженерний вираз ентальпії в кДж/кг]
```

Ці математичні співвідношення є фундаментальною основою для програмних алгоритмів обробки даних у сучасних цифрових мікроконтролерних контролерах вологості.
