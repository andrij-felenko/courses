# 🧮 Математичний вивід границь питомої потужності та енергії накопичувачів

Ця вставка містить строгий математичний вивід граничних кривих на діаграмі Рагоне для різних фізичних механізмів накопичення та перетворення енергії. Вивід базується на фундаментальних рівняннях електродинаміки, хімічної термодинаміки, дифузії Фіка та еквівалентних схемах імпедансу.

### 1. Модель внутрішнього опору та екстремум корисної потужності

Розглянемо фізичне або хімічне джерело струму з масою `m`, номінальною електрорушійною силою (ЕРС) `E_0` та еквівалентним внутрішнім омічним опором `R_in`. При підключенні зовнішнього навантаження з опором `R_L` у колі протікає струм `I`. Згідно із законом Ома для повного кола, струм виражається співвідношенням:

```
I = E_0 / (R_in + R_L)             [закон Ома для повного кола]
```

Вихідна напруга на зовнішніх клемах накопичувача `V_L` менша за термодинамічну ЕРС `E_0` через внутрішнє падіння напруги на опорі `R_in`:

```
V_L = E_0 - I · R_in               [падіння напруги під навантаженням]
```

Корисна електрична потужність `P_L`, яка виділяється у зовнішньому навантаженні, дорівнює добутку струму на вихідну напругу на клемах:

```
P_L = I · V_L
= I · (E_0 - I · R_in)             [підстановка виразу клемової напруги]
= E_0 · I - R_in · I²              [квадратична залежність потужності від струму]
```

Отриманий вираз є параболічною функцією від струму розряду `I`. Щоб знайти струм `I_max_p`, за якого вихідна потужність досягає теоретичного максимуму, знайдемо першу похідну від корисній потужності за струмом і прирівняємо її до нуля:

```
dP_L / dI = E_0 - 2 · R_in · I = 0 [умова досягнення екстремуму]
I_max_p = E_0 / (2 · R_in)         [оптимальний струм максимальної потужності]
```

Підставляючи оптимальний струм `I_max_p` назад у формулу вихідної потужності, отримуємо фундаментальну межу питомої потужності (умова узгодження опорів `R_L = R_in`):

```
P_max = E_0 · (E_0 / (2 · R_in)) - R_in · (E_0 / (2 · R_in))²
= E_0² / (2 · R_in) - E_0² / (4 · R_in)
= E_0² / (4 · R_in)                [теоретична межа корисної потужності]
```

Шляхом нормування вихідної потужності на повну масу накопичувача `m` отримуємо вираз для максимальної гравіметричної питомої потужності `P_sp,max`:

```
P_sp,max = E_0² / (4 · R_in · m)   [теоретична границя питомої потужності, Вт/кг]
```

Важливо підкреслити фізичний зміст цього режиму: за максимальної питомої потужності `P_sp,max` електричний ККД розряджання падає точно до 50%. Рівно половина енергії, що генерується хімічною реакцією або електричним полем, незворотно перетворюється на джоулеве тепло `Q_heat = I² · R_in` усередині самого джерела. Робота в такому режимі протягом тривалого часу призводить до критичного перегріву осередку.

### 2. Залежність питомої енергії від питомої потужності (параболічне огинання)

При розряджанні накопичувача нескінченно малим струмом (`I → 0`) внутрішнє падіння напруги прямує до нуля (`I · R_in → 0`), а напруга на клемах лишається рівною ЕРС `E_0`. У цьому квазістаціонарному термодинамічному режимі накопичувач віддає максимальну питому енергію `E_sp,0`:

```
E_sp,0 = (E_0 · Q_0) / m           [максимальна термодинамічна питома енергія]
```

де `Q_0` — повна електрична ємність накопичувача у кулонах (або ампер-годинах).

При розряджанні скінченним струмом `I` тривалість розряду `t_d` виражається через повний заряд як `t_d = Q_0 / I`. Загальна корисна енергія `E_L`, віддана у навантаження за цей час, становить:

```
E_L = V_L · I · t_d
= (E_0 - I · R_in) · Q_0           [зв'язок відданої енергії зі струмом]
= E_0 · Q_0 - R_in · Q_0 · I       [втрати енергії на внутрішньому опорі]
```

Поділивши обидві частини рівняння на масу `m`, отримуємо залежність питомої енергії від розрядного струму `I`:

```
E_sp(I) = E_sp,0 - (R_in · Q_0 / m) · I [лінійний спад енергії зі зростанням струму]
```

Виразимо струм розряду `I` через миттєву питому потужність `P_sp = (E_0 · I - R_in · I²) / m`. Для помірних струмів (`R_in · I << E_0`) падіння напруги мале порівняно з ЕРС, тому струм наближено дорівнює `I ≈ (P_sp · m) / E_0`. Підставляючи цей вираз у рівняння питомої енергії, отримуємо перше лінійне наближення спаду енергії зі зростанням потужності:

```
E_sp(P_sp) = E_sp,0 - (R_in · Q_0 · m / E_0²) · P_sp
= E_sp,0 · [1 - (R_in · Q_0 / E_0²) · P_sp]
```

Враховуючи зв'язок із граничною потужністю `P_sp,max = E_0² / (4 · R_in · m)` та підставляючи точне розв'язання квадратичного рівняння відносно струму `I = [E_0 - √(E_0² - 4 · R_in · P_sp · m)] / (2 · R_in)`, отримуємо точне параболічне рівняння верхньої огинаючої кривої Рагоне:

```
E_sp(P_sp) = E_sp,0 · [1 - (1 - √(1 - P_sp / P_sp,max))] [параболічна огинаюча Рагоне]
```

Для малих і середніх потужностей (`P_sp << P_sp,max`) це рівняння спрощується до параболічного спаду:

```
E_sp(P_sp) ≈ E_sp,0 · [1 - (P_sp / (2 · P_sp,max))]
```

Цє рівняння пояснює, чому на діаграмі Рагоне верхня межа будь-якого електрохімічного джерела неминуче відхиляється праворуч і загинається донизу при наближенні до максимальної потужності.

### 3. Модель RC-релаксації для електростатичних та суперконденсаторів

Для електростатичного або двошарового суперконденсатора (EDLC) з ємністю `C` та послідовним омічним опором `R_in` розрядний процес описується диференціальним рівнянням релаксації RC-контуру. При замиканні на зовнішній опір `R_L` напруга на ємнісному елементі `V_C(t)` падає за експоненційним законом:

```
V_C(t) = V_0 · exp(-t / τ)         [експоненційний закон розряду]
```

де `τ = (R_in + R_L) · C` — часова константа RC-кола. Миттєвий струм у колі становить:

```
I(t) = [V_0 / (R_in + R_L)] · exp(-t / τ)
```

Миттєва корисна потужність, яка виділяється у зовнішньому навантаженні `R_L`, дорівнює:

```
P_L(t) = I²(t) · R_L
= [V_0² · R_L / (R_in + R_L)²] · exp(-2t / τ)
```

Інтегруючи миттєву потужність від `t = 0` до `t → ∞`, знайдемо повну енергію `E_L`, передану у навантаження:

```
E_L = ∫₀^∞ P_L(t) dt
= [V_0² · R_L / (R_in + R_L)²] · ∫₀^∞ exp(-2t / τ) dt
= [V_0² · R_L / (R_in + R_L)²] · [τ / 2]
= (1/2) · C · V_0² · [R_L / (R_in + R_L)] [розподіл ентальпії між опорами]
```

Поділивши вираз енергії на масу `m`, отримуємо питому енергію суперконденсатора:

```
E_sp = (1/2) · C · V_0² · η_el / m [питома енергія EDLC з урахуванням ККД]
```

де `η_el = R_L / (R_in + R_L)` — електричний ККД розряду.

Середня питома потужність за час розряду `t_d = τ` становить:

```
P_sp,avg = E_sp / τ = [(1/2) · C · V_0² · η_el] / [(R_in + R_L) · C · m]
= (1/2) · V_0² · R_L / [(R_in + R_L)² · m]
```

Оскільки омічний опір суперконденсаторів `R_in` становить частки міліома, їхній час розряду `τ` вимірюється секундами, а питома потужність `P_sp` на 2–3 порядки перевищує показники хімічних акумуляторів.

### 4. Дифузійні обмеження Фіка та кінетика Батлера-Фольмера

В акумуляторних батареях при високих потужностях головним чинником спаду ємності стає не лише омічний опір `R_in`, а й дифузійне обмеження швидкості масопереносу іонів у порах електроліту та кристалічній ґратці електродів (імпеданс Варбурга).

Згідно з першим законом Фіка, дифузійний потік іонів `J` прямо пропорційний градієнту їхньої концентрації `∂C / ∂x`:

```
J = -D · (∂C / ∂x)                 [перший закон дифузії Фіка]
```

де `D` — коефіцієнт дифузії іонів у твердій фазі або рідкому електроліті (м²/с).

При пропусканні великого розрядного струму `I` густина струму на межі розділу фаз `j = I / A_surf` вимагає високого дифузійного припливу іонів. Якщо швидкість екстракції іонів перевищує дифузійний приплив, поверхнева концентрація іонів `C_surf` стрімко падає до нуля. Це явище викликає **концентраційну поляризацію** `η_conc`:

```
η_conc = (R · T / (n · F)) · ln(C_bulk / C_surf) [концентраційне перенапруження]
```

де `R` — універсальна газова стала, `T` — абсолютна температура, `n` — валентність іона, `F` — стала Фарадея, `C_bulk` — об'ємна концентрація іонів у глибині електроліту.

Коли поверхнева концентрація `C_surf` наближається до нуля, концентраційне перенапруження `η_conc` прямує до нескінченності, а клемова напруга падає до порогу відсічки `V_cutoff`. Час `t_sand`, за який поверхнева концентрація виснажується до нуля під дією постійного струму `j`, описується **рівнянням Зенда**:

```
t_sand = π · D · (n · F · C_bulk)² / (2 · j)² [рівняння Зенда для граничного струму]
```

Рівняння Зенда пояснює фізичне походження **закону Пейкерта** `t_d = C_p / I^k`: при квадратичній залежності часу виснаження від густини струму (`t_sand ∝ 1 / j²`) реальна віддана ємність стрімко падає зі зростанням потужності розряду.

Виражаючи віддану питому енергію з урахуванням закону Пейкерта, отримуємо градуйоване ступенне рівняння спаду кривої Рагоне для електрохімічних батарей у зоні високих потужностей:

```
E_sp(P_sp) = E_sp,0 · (P_nom / P_sp)^((k - 1) / k) [ступенний спад за законами дифузії]
```

Для сучасних літій-іонних батарей показник Пейкерта становить `k ≈ 1.03–1.08`, що забезпечує помірний спад енергії. Для застарілих свинцево-кислотних батарей `k ≈ 1.25–1.35`, що призводить до стрімкого обвалу кривої Рагоне при підвищенні питомої потужності понад 100 Вт/кг.
