# 🧮 Математичне виведення теореми рівнорозподілу та теореми віріалу

У цій статті наведено строге математичне виведення узагальненої форми теореми рівнорозподілу енергії у канонічному ансамблі Гіббса. Окрім класичного випадку гармонічних та квадратичних термів, детально розглянуто математичні особливості для системи з неквадратичними потенціалами, релятивістських частинок, а також математичне виведення зв'язку теореми рівнорозподілу з класичною теоремою віріалу Клаузіуса.

---

### 1. Поняття канонічного ансамблю Гіббса та фазового простору

Розглянемо макроскопічну фізичну систему, яка складається з `N` частинок у стані теплової рівноваги з навколишнім термостатом при фіксованій температурі `T`. У класичній механіці стан такої системи повністю задається точкою у `2N`-вимірному фазовому просторі. Траєкторія системи визначається набор канонічних змінних `x = (q₁, ..., q_N, p₁, ..., p_N)`, де `q_i` — узагальнені просторові координати, а `p_i` — відповідні їм узагальнені канонічні імпульси.

Повна механічна енергія системи визначається функцією Гамільтона `H(q, p)`. Згідно з фундаментальним постулатом класичної статистичної фізики Гіббса, ймовірність `w(x) dx` того, що система перебуватиме у нескінченно малому фазовому об'ємі `dx = dq₁...dq_N dp₁...dp_N` навколо точки `x`, описується больцманівським розподілом.

У цій математичній моделі графік щільності ймовірності пропорційний експоненціальному фактору `exp(−β H(x))`, де параметр `β = 1 / (k_B T)` виступає як обернена температура. Знаменник `Z`, який називається статистичною сумою канонічного ансамблю Гіббса, забезпечує абсолютне нормування повної ймовірності до одиниці у всьому доступному фазовому об'ємі.

#### Сформулюємо узагальнену теорему рівнорозподілу:
Для будь-яких двох фазових змінних `x_i` та `x_j` (які можуть бути як координатами, так і імпульсами) середня величина математичного добутку змінного значення `x_i` на частинну похідну функції Гамільтона за змінною `x_j` виражається точним співвідношенням:

```
⟨x_i · (∂H / ∂x_j)⟩ = δ_ij · k_B · T
```

де символ Кронекера `δ_ij` дорівнює одиниці, якщо index `i` збігається з index `j`, та дорівнює нулю у всіх інших випадках, коли змінні є статистично незалежними.

### 2. Детальний математичний доказ методом інтегрування частинами

Щоб отримати це фундаментальне співвідношення, запишемо точний математичний вираз для канонічного середнього значення шуканої величини у фазовому просторі. За означенням канонічного ансамблю Гіббса, середня величина обчислюється як інтеграл від добутку фізичної величини на щільність ймовірності по всьому фазовому простору.

Здійснимо ключове математичне перетворення: розглянемо частинну похідну від больцманівського експоненціального множника за канонічною змінною `x_j`. Використовуючи правило диференціювання складної функції, виявимо, що частинна похідна функції Гамільтона під інтегралом може бути точно замінена на похідну від експоненціального множника з від'ємним коефіцієнтом `−1 / β`.

Після цієї заміни підставимо отриманий вираз у багаторазовий фазовий інтеграл і виділимо однократне інтегрування за змінною `x_j`. До цього інтеграла застосуємо класичний метод **інтегрування частинами**.

У результаті застосування інтегрування частинами вираз розпадається на два окремих математичних доданки:
1. Позаінтегральний підстановочний терм, розрахований на нескінченних межах фазового простору.
2. Новий фазовий інтеграл, що містить частинну похідну `∂x_i / ∂x_j`.

Проаналізуємо поведінку позаінтегрального додатка на межах інтегрування:
- Якщо змінна `x_j` являє собою імпульс `p_j`, межі інтегрування простягаються від мінус нескінченності до плюс нескінченності. Оскільки функція Гамільтона будь-якої реальної фізичної системи зростає при нескінченному збільшенні імпульсу частинок, больцманівський фактор спадає до нуля значно швидше за будь-яку степіневу функцію. Отже, підстановочний терм на нескінченності строго дорівнює нулю.
- Якщо змінна `x_j` являє собою координату `q_j` у замкненому об'ємі, то при наближенні координати частинки до твердих стінок посудини потенціальна енергія взаємодії зростає до нескінченності, що також перетворює больцманівську експоненту та весь позаінтегральний терм у нуль.

Отже, позаінтегральний терм повністю зникає у всіх фізично можливих випадках.

У другому інтегралі частинна похідна канонічних координат `∂x_i / ∂x_j` за означенням незалежності фазових осей строго дорівнює символу Кронекера `δ_ij`. Виносячи цей постійний символ за знак інтеграла, ми отримуємо інтеграл, який після ділення на статистичну суму `Z` тотожно дорівнює одиниці внаслідок нормування ймовірностей.

У результаті обчислень залишається лише коефіцієнт `1 / β`, який за означенням температури дорівнює `k_B T`. Це повністю доводить узагальнену теорему рівнорозподілу.

### 3. Фізичний аналіз окремих випадків гамільтоніана

#### 3.1. Квадратичні терми (Класичний гармонічний рівнорозподіл)
Розглянемо випадок, коли функція Гамільтона містить квадратичний додаток за змінною `x_i` вигляду `H_i(x_i) = A x_i²`, де `A` — довільний додатний коефіцієнт (наприклад, `1 / (2m)` для кінетичної енергії або `k / 2` для потенціальної енергії пружини).

Обчислимо частинну похідну гамільтоніана за цією змінною: `∂H / ∂x_i = 2 A x_i`. Підставляючи цей вираз у доведене загальне співвідношення для випадку `i = j`, отримуємо:

```
⟨x_i · (2 A x_i)⟩ = 2 · ⟨A x_i²⟩ = k_B T
```

Ділячи обидві частини математичного рівняння на два, маємо класичне формулювання теореми рівнорозподілу: середня енергія кожного квадратичного ступеня вільності строго дорівнює **½ k_B T**.

#### 3.2. Степіневі неквадратичні потенціальні ями
Розглянемо фізичну систему, у якій потенціальна енергія частинки описується степенем `n` від модуля координати: `U(q) = A |q|^n`.
Обчислюючи частинну похідну потенціалу за координатою та множачи її на значення координати `q`, маємо співвідношення `q (∂U / ∂q) = n U(q)`.

Застосовуючи узагальнену теорему рівнорозподілу, отримуємо дивовижний висновок: середня потенціальна енергія для неквадратичного потенціалу дорівнює:

```
⟨U(q)⟩ = (1 / n) · k_B T
```

Цей математичний результат показує, що лише для гармонічного потенціалу (`n = 2`) середня потенціальна енергія дорівнює `½ k_B T`. Для більш м'яких потенціальних ям (наприклад, `n = 4`) середня енергія менша і дорівнює `¼ k_B T`, а для прямокутної ями з нескінченно жорсткими стінками (`n → ∞`) середня потенціальна енергія прямує до нуля.

#### 3.3. Релятивістський рух частинок
У випадку ультрарелятивістських частинок (наприклад, високотемпературного електронно-позитронного газу чи фотонів), енергія яких лінійно залежить від модуля імпульсу `H = c |p|`, частинна похідна гамільтоніана за імпульсом дає складову швидкості. Сумування трьох компонент руху дає точну рівність: середня енергія на кожну просторову координату релятивістського руху дорівнює **k_B T** замість класичного значення ½ k_B T.

### 4. Зв'язок із класичною теоремою віріалу Клаузіуса

Застосуємо доведену узагальнену теорему рівнорозподілу до просторових координат частинок системи та частинних похідних потенціальної енергії взаємодії.

Сумуючи отримані співвідношення за всіма просторовими координатами всіх частинок системи та порівнюючи їх із середньою кінетичною енергією поступального руху, ми виводимо знамениту **теорему віріалу Клаузіуса**: подвоєна середня кінетична енергія системи дорівнює середньому значення скалярного добутку радіус-векторів частинок на сили, що діють на них.

Цей математичний зв'язок є фундаментальною основою для розрахунку рівняння стану реальних газів Ван-дер-Ваальса, обчислення поверхневого натягу рідин та моніторингу механічного тиску у симуляціях молекулярної динаміки.
