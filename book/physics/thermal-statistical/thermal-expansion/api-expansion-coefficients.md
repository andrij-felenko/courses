# 📋 Довідник коефіцієнтів теплового розширення та розрахункових формул

Цей довідник містить систематизовані числові дані коефіцієнтів теплового розширення для основних конструкційних матеріалів, інженерні формули для розрахунку 1D, 2D та 3D деформацій, співвідношення для біметалевих елементів, а також розрахунок теплових напружень і термостійкості тендітних матеріалів.

### 2. Фізичні особливості розширення різних класів матеріалів

#### Метали та металеві сплави
У металах розширення обумовлене тепловими коливаннями іонів кристалічної ґратки. Оскільки металевий зв'язок є ненапрямленим і нелокалізованим (електронний газ), атоми здатні до значних ангармонічних відхилень. Метали з гранецентрованою кубічною ґраткою (ГЦК: алюміній, мідь, срібло) володіють вищими значеннями КТР, ніж метали з об'ємноцентрованою (ОЦК: залізо, вольфрам, молібден), оскільки щільноупакована ГЦК-ґратка володіє меншою жорсткістю на зсув.

#### Кераміка, скло та тугоплавкі сполуки
Ковалентні та іонні кристали (карбід кремнію `SiC`, оксид алюмінію `Al₂O₃`, кварц) характеризуються дуже глибокими та вузькими потенціальними ямами з високим значенням жорсткості зв'язку `c`. Це обумовлює надзвичайно малі значення КТР (`α < 8 × 10⁻⁶ K⁻¹`) та високу температуру плавлення. Кварцеве скло завдяки пухкій тривимірній сітці зв'язків `Si-O-Si` має КТР всього `0.5 × 10⁻⁶ K⁻¹`.

#### Полімери та температурний перехід склування
Полімерні матеріали складаються з міцних ковалентних ланцюгів вуглецю, які з'єднані між собою слабкими ван-дер-ваальсовими силами. При нагріванні слабкі міжланцюгові зв'язки розриваються першими, що обумовлює гігантські значення КТР (`α > 100 × 10⁻⁶ K⁻¹`). При досягненні температури склування `T_g` полімер переходить із твердого склоподібного стану у високоеластичний. При цьому коефіцієнт теплового розширення стрибкоподібно зростає у 3–5 разів. Наприклад, для епоксидної смоли КТР нижче `T_g` дорівнює `50 × 10⁻⁶ K⁻¹`, а вище `T_g` сягає `180 × 10⁻⁶ K⁻¹`.

### 3. Температурні поліноміальні апроксимації КТР

У широких температурних інтервалах (від кріогенних 4 К до високотемпературних 1000 °C) лінійне наближення `α = const` стає недопустимо грубим. Для точних інженерних обчислень використовують багаточленні розклади КТР за температурою `T` (у кельвінах):

```
α(T) = a₀ + a₁ · T + a₂ · T² + a₃ · T⁻²
```

Подовження тіла від температури `T₁` до `T₂` обчислюється визначеним інтегралом:

```
ΔL = L₀ · ∫_{T₁}^{T₂} α(T) dT = L₀ · [ a₀(T₂ - T₁) + ½ a₁(T₂² - T₁²) + ⅓ a₂(T₂³ - T₁³) - a₃(1/T₂ - 1/T₁) ]
```

#### Поліноміальні коефіцієнти для ключових матеріалів (діапазон 293...800 K)

1. **Алюміній 6061-T6:**
   - `a₀ = 1.94 × 10⁻⁵ K⁻¹`
   - `a₁ = 1.25 × 10⁻⁸ K⁻²`
   - `a₂ = -4.10 × 10⁻¹² K⁻³`

2. **Нержавіюча сталь AISI 304:**
   - `a₀ = 1.41 × 10⁻⁵ K⁻¹`
   - `a₁ = 1.02 × 10⁻⁸ K⁻²`
   - `a₂ = -2.30 × 10⁻¹² K⁻³`

3. **Кремній монокристалічний Si:**
   - `a₀ = -2.14 × 10⁻⁶ K⁻¹`
   - `a₁ = 2.18 × 10⁻⁸ K⁻²`
   - `a₂ = -1.62 × 10⁻¹¹ K⁻³`

### 4. Фундаментальні розрахункові формули

#### 4.1. Лінійне розширення (1D)
Для однорідного ізотропного стрижня початкової довжини `L₀` при температурі `T₀`:

```
ΔL = α · L₀ · ΔT
L(T) = L₀ · (1 + α · ΔT)
```

де `ΔT = T - T₀`.

#### 4.2. Поверхневе та об'ємне розширення (2D та 3D)
Для ізотропного тіла з однаковим коефіцієнтом `α` за всіма напрямками:

```
Поверхневий коефіцієнт: β = 2 · α
A(T) = A₀ · (1 + β · ΔT) = A₀ · (1 + 2α · ΔT)

Об'ємний коефіцієнт: γ = 3 · α
V(T) = V₀ · (1 + γ · ΔT) = V₀ · (1 + 3α · ΔT)
```

**Анізотропний кристал (некубічний):**
Якщо розширення описано тензором `α_ij` з головними значеннями `α_xx`, `α_yy`, `α_zz`:

```
γ = α_xx + α_yy + α_zz
```

#### 4.3. Зміна густини речовини
Оскільки маса тіла `m = ρ · V` зберігається:

```
ρ(T) = ρ₀ / (1 + γ · ΔT) ≈ ρ₀ · (1 - γ · ΔT)
```

#### 4.4. Зміна внутрішнього об'єму порожнин та судин
**Правило розширення порожнин:** Замкнена порожнина чи отвір у суцільному тілі розширюється при нагріванні **абсолютно так само, як розширювався б суцільний шматок того самого матеріалу**, що заповнює цей отвір.

```
V_порожнини(T) = V_порожнини,0 · (1 + γ_матеріалу · ΔT)
```

#### 4.5. Біметалеві елементи (Повна формула Тимошенка)
Радіус кривини `R` (чи кривина `κ = 1/R`) вигнутої біметалевої пластини, складеної з двох шарів товщинами `t₁` та `t₂`, модулями Юнга `E₁`, `E₂` та коефіцієнтами `α₁`, `α₂`:

```
        6 · (α₁ - α₂) · ΔT · (t₁ + t₂) · (1 + m)²
1/R = -------------------------------------------------------------
      (t₁ + t²)² · [ 3(1 + m)² + (1 + m·n) · (m² + 1/(m·n)) ]
```

де `m = t₁ / t₂`, `n = E₁ / E₂`.

Якщо товщини однакові (`t₁ = t₂ = t/2`) та модулі Юнга близькі (`E₁ ≈ E₂`):

```
       3 · (α₁ - α₂) · ΔT
1/R = --------------------
              2 · t
```

#### 4.6. Механічні теплові напруження при обмеженні розширення
Якщо стрижень площею перерізу `A`, затиснутий між двома абсолютно жорсткими непорушними стінками, нагріти на `ΔT`, виникає стискальне теплове напруження `σ`:

```
σ = - E · α · ΔT
```

Сила тиску стрижня на стінки дорівнює:

```
F = |σ| · A = E · A · α · ΔT
```

Якщо стінки володіють власною пружною жорсткістю `k_st`:

```
        E · A · α · ΔT
σ = - -------------------
       1 + (E · A / (k_st · L₀))
```

#### 4.7. Параметр термостійкості тендітних матеріалів (Критерії Гассельмана)
Максимальний перепад температур `ΔT_max`, який може витримати тендітна кераміка чи скло при швидкому охолодженні (термоудар) без утворення тріщин:

```
             σ_f · (1 - ν)
ΔT_max = ---------------------
                 E · α
```

де `σ_f` — границя міцності на розрив, `ν` — коефіцієнт Пуассона.

Критерій теплового удару `R'` з урахуванням теплопровідності `k` (для помірних швидкостей охолодження з числом Біоте `Bi = h L / k`):

```
       k · σ_f · (1 - ν)
R' = --------------------
            E · α
```

Критерій стійкості до поширення тріщин при багаторазовому термоциклюванні `R''''`:

```
          E · γ_fracture
R'''' = ------------------
         σ_f² · (1 - ν)
```

де `γ_fracture` — питома поверхнева енергія руйнування матеріалу.

Що вищі значення `R'` та `R''''`, то стійкіший матеріал до раптових температурних стрибків та втоминного термоциклічного розтріскування.

### 5. Інженерний аналіз температурного розсогласування у мікроелектроніці

У сучасних електронних модулях з BGA-монтажем (Ball Grid Array) кремнієвий кристал чи корпус із малими КТР піддається циклічному нагріванню.

Зсувна деформація `γ_shear` крайнього олов'яного кулькового виводу BGA на відстані `D_dist` від центра нейтралі (DNP) обчислюється як:

```
γ_shear = (Δα · ΔT · D_dist) / h_ball
```

де:
- `Δα = α_board - α_chip` — різниця коефіцієнтів розширення друкованої плати та chip-корпуса;
- `h_ball` — висота олов'яної кульки;
- `D_dist` — відстань від геометричного центра мікросхеми до крайнього виводу.

Згідно з емпіричним законом втоми Коффіна — Менсона, кількість циклів `N_f` до зародження тріщини у BGA-контакті дорівнює:

```
N_f = C · (γ_shear)^(-1.9) · (f_freq)^0.33 · exp(E_act / (k_B · T_max))
```

Для збільшення надійності BGA-вузлів простір під мікросхемою заповнюють епоксидним компаундом (*underfill*) із добавками кварцевого мікропорошку, що зменшує ефекти зсувних напружень та розподіляє навантаження по всій площі компонента.

### 6. Інженерний чек-лист узгодження теплового розширення

1. **Термомеханічне узгодження у мікроелектроніці (PCB / IC Packaging):**
   - Кремнієвий кристал (`α = 2.6 × 10⁻⁶ K⁻¹`) заборонено паяти безпосередньо на плату FR-4 (`α = 15 × 10⁻⁶ K⁻¹`) без компенсатора. Використовують проміжні керамічні підкладки з `AlN` (`α = 4.5 × 10⁻⁶ K⁻¹`) чи інварні тепловідводи, щоб уникнути зрізу кулькових виводів BGA від термоциклування.
2. **Компенсація трубопроводів:**
   - Гарячі паропроводи та нафтопроводи завдовжки понад 20 метрів вимагають встановлення U-подібних компенсаційних петель або сильфонних металевих компенсаторів, які компенсують подовження `ΔL ≈ 1.2 мм/м` на кожні 100 °C нагріву.
3. **Оптико-механічні оправи телескопів та лазерів:**
   - Для збереження фокусної відстані дзеркала з **Zerodur** (`α ≈ 0`) оправа кріпиться через штанги з **Інвару** або вуглепластику CFRP, розраховані так, щоб розширення оправи не зміщувало оптичну вісь.
4. **Кріогенні деталі та кріостати:**
   - При охолодженні від 300 К до 4.2 К (рідкий гелій) нержавіюча сталь стискається на `0.3%`, а алюміній — на `0.42%`. Різниця у стисканні складових частин може викликати розгерметизацію вакуумних ущільнень із мідними чи індієвими прокладками.
