# 🧮 Строге виведення хімічного потенціалу у великому канонічному ансамблі та квантових статистиках

Ця вставка містить суворе математичне виведення хімічного потенціалу `μ` із перших принципів статистичної механіки Гіббса. Оскільки для відкритих систем кількість частинок `N` є змінною величиною, фундаментальною математичною основою для опису хімічного потенціалу є великий канонічний ансамбль (*grand canonical ensemble*), його статистична сума `Ξ` та великий термодинамічний потенціал `Ω(T, V, μ)`.

---

### 1. Перетворення Лежандра та виникнення потенціалу Омега

У мікроканонічному ансамблі фундаментальним потенціалом є ентропія `S(U, V, N)`. Переходячи до ансамблів із фіксованою температурою `T` та хімічним потенціалом `μ`, ми здійснюємо послідовні перетворення Лежандра для виключення екстенсивних змінних `S` та `N`.

Запишемо перший та другий закони термодинаміки для внутрішньої енергії `U(S, V, N)` у диференціальній формі:

```
dU = T·dS - P·dV + μ·dN
```

Здійснюючи перетворення Лежандра по змінних `S → T` та `N → μ`, отримуємо великий термодинамічний потенціал `Ω`:

```
Ω = U - T·S - μ·N = F - μ·N
```

Знайдемо повний диференціал потенціалу `Ω`:

```
dΩ
= dF - d(μ·N)
= (-S·dT - P·dV + μ·dN) - (μ·dN + N·dμ)      [використано dF = -S·dT - P·dV + μ·dN]
= -S·dT - P·dV - N·dμ                      [скорочено члени μ·dN]
```

З цього диференціального співвідношення випливають фундаментальні часткові похідні великого потенціалу:

```
S = -(∂Ω / ∂T)_(V, μ)
P = -(∂Ω / ∂V)_(T, μ)
N = -(∂Ω / ∂μ)_(T, V)
```

Оскільки `Ω` є екстенсивною величиною відносно об'єму `V` при сталих інтенсивних параметрах `T` та `μ`, потенціал `Ω` є строго лінійним по об'єму. Використовуючи теорему Ейлера для однорідних функцій першого степеня, маємо:

```
Ω(T, V, μ) = -P(T, μ) · V
```

Це співвідношення встановлює прямий зв'язок між тиском середовища `P` та великою статистичною сумою ансамблю.

---

### 2. Великий канонічний розподіл Гіббса та статистична сума

Розглянемо систему об'ємом `V`, яка перебуває у тепловому та дифузійному контакті з термостатом при температурі `T` (де `β = 1 / (k_B · T)`) та резервуаром частинок із хімічним потенціалом `μ`. Ймовірність того, що система містить точно `N` частинок і перебуває у мікростані `i` з енергією `E_{N, i}`, виражається великим канонічним розподілом Гіббса:

```
w_{N, i} = (1 / Ξ) · exp(-β·(E_{N, i} - μ·N))
```

Нормувальний множник `Ξ` є великою статистичною сумою системи:

```
Ξ(T, V, μ)
= ∑_{N=0}^∞ ∑_i exp(-β·(E_{N, i} - μ·N))
= ∑_{N=0}^∞ exp(β·μ·N) · Z_N(T, V)          [де Z_N — канонічна статсума системи з N частинок]
```

Великий термодинамічний потенціал `Ω` пов'язаний зі статистичною сумою `Ξ` співвідношенням:

```
Ω(T, V, μ) = -k_B · T · ln Ξ
```

Звідси середнє число частинок у системі `N` виражається безпосередньо через логарифм великої статсуми:

```
N = k_B · T · (∂ ln Ξ / ∂μ)_(T, V)
```

Ввівши безрозмірну макроскопічну величину **фугативність** (*fugacity*) `z = exp(β·μ) = exp(μ / (k_B·T))`, отримуємо:

```
Ξ(T, V, z) = ∑_{N=0}^∞ zⁿ · Z_N(T, V)
N = z · (∂ ln Ξ / ∂z)_(T, V)
```

### 3. Точне виведення для класичного ідеального газу

Для класичного ідеального газу з `N` нетотожних непідгоняльних частинок масою `m` канонічна статистична сума дорівнює:

```
Z_N(T, V) = (1 / N!) · (V / λ_dB³)ⁿ
```

де `λ_dB = h / √(2·π·m·k_B·T)` — теплова довжина хвилі де Бройля. Підставимо `Z_N` у велику статистичну суму `Ξ`:

```
Ξ(T, V, μ)
= ∑_{N=0}^∞ exp(β·μ·N) · (1 / N!) · (V / λ_dB³)ⁿ
= ∑_{N=0}^∞ (1 / N!) · [ (V / λ_dB³) · exp(β·μ) ]ⁿ
= exp [ (V / λ_dB³) · exp(β·μ) ]           [розклад експоненти у ряд Тейлора]
```

Обчислимо великий потенціал `Ω`:

```
Ω(T, V, μ) = -k_B · T · (V / λ_dB³) · exp(β·μ) = -P·V
```

Обчислимо середнє число частинок `N`:

```
N
= -(∂Ω / ∂μ)_(T, V)
= - (∂ / ∂μ) [ -k_B · T · (V / λ_dB³) · exp(μ / (k_B·T)) ]
= (V / λ_dB³) · exp(μ / (k_B·T))
```

Виразимо хімічний потенціал `μ` через концентрацію частинок `n = N / V`:

```
n = (1 / λ_dB³) · exp(μ / (k_B·T))           [ділення N на об'єм V]
exp(μ / (k_B·T)) = n · λ_dB³                  [ізоляція експоненти]
μ(T, n) = k_B · T · ln(n · λ_dB³)             [логарифмування обох частин]
```

Для класичного газу середня відстань між частинками `n⁻¹/³` значно більша за теплову довжину хвилі `λ_dB` (`n · λ_dB³ << 1`), тому аргумент логарифма є набагато меншим за одиницю, а хімічний потенціал класичного газу є **від'ємною величиною** (`μ < 0`).

### 4. Фермі-газ та точний виразок Зоммерфельда

У квантовій статистиці Фермі — Дірака середня кількість ферміонів (частинок із напівцілим спіном, наприклад електронів) на квантовому стані з енергією `ε` описується розподілом:

```
f(ε) = 1 / (exp((ε - μ) / (k_B · T)) + 1)
```

Повне число частинок `N` визначається інтегруванням по густині станів `g(ε)`:

```
N = ∫₀^∞ g(ε) · f(ε) dε
```

Для тривимірного електронного газу з об'ємом `V` та спіновим виродженням `g_s = 2` густина станів дорівнює `g(ε) = C · √ε`, де `C = (V / (2·π²)) · (2·m / ℏ²)³⁺²`.

При абсолютному нулю `T = 0 K` функція розподілу є сходинковою: `f(ε) = 1` при `ε ≤ E_F` та `f(ε) = 0` при `ε > E_F`. Отже, при `T = 0 K` хімічний потенціал дорівнює енергії Фермі:

```
μ(T = 0) = E_F = (ℏ² / (2·m)) · (3·π² · n)²⁺³
```

#### Математична техніка інтегрування Зоммерфельда

Для обчислення інтегралів вида `I = ∫₀^∞ H(ε) · f(ε) dε` при низьких температурах `k_B · T << μ` Арнольд Зоммерфельд розробив спеціальний асимптотичний розклад. Проінтегруємо частинами:

```
I = ∫₀^μ H(ε) dε + ∫₀^∞ [ ∫_μ^ε H(x) dx ] · (-∂f / ∂ε) dε
```

Оскільки похідна `-∂f / ∂ε` є симетричною пікоподібною функцією з центром у точці `ε = μ` та шириною порядку `k_B · T`, розкладаємо внутрішній інтеграл у ряд Тейлора по степенях `(ε - μ)`:

```
-∂f / ∂ε = (1 / (k_B·T)) · exp((ε-μ)/(k_B·T)) / [ exp((ε-μ)/(k_B·T)) + 1 ]²
```

Використовуючи значення табличних безрозмірних інтегралів `∫_{-∞}^∞ (x² / (eˣ + 1)²) dx = π² / 3` та `∫_{-∞}^∞ (x⁴ / (eˣ + 1)²) dx = 7·π⁴ / 15`, отримуємо точний розклад Зоммерфельда четвертого порядку:

```
I = ∫₀^μ H(ε) dε + (π² / 6) · (k_B · T)² · H'(μ) + (7·π⁴ / 360) · (k_B · T)⁴ · H'''(μ) + O((k_B·T)⁶)
```

Застосуємо розклад Зоммерфельда до інтеграла числа частинок `N = ∫₀^∞ C · √ε · f(ε) dε` (де `H(ε) = C · √ε`, `H'(ε) = C / (2·√ε)`, `H'''(ε) = (3/8) · C · ε⁻⁵⁺²`):

```
N = (2/3) · C · μ³⁺² + (π² / 12) · C · (k_B · T)² · μ⁻¹⁺² - (7·π⁴ / 960) · C · (k_B · T)⁴ · μ⁻⁵⁺²
```

Поділивши обидві частини на `N = (2/3) · C · E_F³⁺²`:

```
1 = (μ / E_F)³⁺² · [ 1 + (π² / 8) · (k_B · T / μ)² - (7·π⁴ / 640) · (k_B · T / μ)⁴ ]
```

Розкладаючи зворотну залежність по малому параметру `η = k_B · T / E_F`, отримуємо строгий розклад хімічного потенціалу фермі-газу:

```
μ(T) = E_F · [ 1 - (π² / 12) · (k_B · T / E_F)² - (π⁴ / 80) · (k_B · T / E_F)⁴ + O((k_B·T/E_F)⁶) ]
```

Фізичний зміст цього спадання полягає у симетрії розмиття поверхні Фермі: оскільки густина станів `g(ε) ∝ √ε` зростає з енергією, для збереження незмінної загальної кількості частинок `N` хімічний потенціал змушений трохи зміщуватися вниз у бік менших енергій при підвищенні температури.

### 5. Бозе-газ та полілогарифмічні функції

Для бозонів (частинок із цілим спіном, наприклад атомів гелію-4) функція розподілу Бозе — Ейнштейна має вигляд:

```
n(ε) = 1 / (exp((ε - μ) / (k_B · T)) - 1)
```

Оскільки середня кількість частинок `n(ε)` на будь-якому енергетичному рівні не може бути від'ємною, для найнижчого енергетичного стану (основний стан `ε = 0`) має виконуватися умова:

```
exp((0 - μ) / (k_B · T)) - 1 > 0
exp(-μ / (k_B · T)) > 1
-μ / (k_B · T) > 0  ⇒  μ ≤ 0
```

Хімічний потенціал бозе-газу **ніколи не може бути додатним**. Фугативність `z = exp(μ / (k_B · T))` обмежена інтервалом `0 < z ≤ 1`.

#### Розподіл частинок через полілогарифми

Обчислимо повну концентрацію незакондесованих частинок у збуджених станах `n_{ex}` через інтеграл з густиною станів `g(ε) = C · √ε`:

```
n_{ex} = (1 / V) · ∫₀^∞ [ C · √ε / (z⁻¹ · exp(ε / (k_B·T)) - 1) ] dε
```

Ввівши безрозмірну змінну `x = ε / (k_B · T)` та розкладаючи підінтегральний вираз у геометричну прогресію по степенях `z · e⁻ˣ`:

```
n_{ex} = (1 / λ_dB³) · Li₃⁺₂(z)
```

де `Li_s(z) = ∑_{k=1}^∞ (z^k / k^s)` — спеціальна математична функція **полілогарифм** порядку `s`.

При зниженні температури хімічний потенціал росте, наближаючись до нуля з боку від'ємних значень (`μ → 0⁻` або `z → 1⁻`). Значення полілогарифма при `z = 1` дорівнює дзета-функції Рімана: `Li₃⁺₂(1) = ζ(3/2) ≈ 2.612375`.

Гранична температура `T_c`, при якій `μ` вперше сягає нуля, називається критичною температурою Бозе-Ейнштейнівської конденсації (БКЕ):

```
n = (2.612375 / λ_dB(T_c)³)
T_c = (h² / (2·π·m·k_B)) · (n / 2.612375)²⁺³
```

При `T ≤ T_c` хімічний потенціал тотожно дорівнює нулю (`μ = 0`), а відносна частка атомів, що накопичується у макроскопічному конденсаті Бозе — Ейнштейна на найнижчому квантовому рівні `ε = 0`, дорівнює:

```
N_0 / N = 1 - (T / T_c)³⁺²
```

Цей математичний результат доводить, що при `T ≤ T_c` надлишкові атоми випадають у конденсат без будь-яких затрат вільної енергії Гіббса, оскільки для конденсату `μ = 0`.
