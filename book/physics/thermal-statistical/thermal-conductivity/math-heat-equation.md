# 🧮 Виведення рівняння теплопровідності та крайові умови

Ця вставка містить строге математичне виведення диференціального рівняння теплопровідності (рівняння Фурьє) у 1D, 2D та 3D форматах на основі закону збереження енергії, розгляд криволінійних систем координат (циліндричної та сферичної), аналіз фізичного змісту температуропровідності `α`, розв'язок методом відокремлення змінних (метод Фур'є), функцію Ґріна для точкового джерела тепла, розгляд трьох типів граничних умов та покрокові приклади розрахунку.

---

### 1. Фізична модель: збереження енергії у контрольному об'ємі

Розглянемо нескінченно малий паралелепіпед у твердому тілі із ребрами `dx`, `dy`, `dz`. Його об'єм дорівнює `dV = dx · dy · dz`, густина матеріалу — `ρ`, а питома ізобарна теплоємність — `c_p`. Маса матеріалу у контрольному об'ємі дорівнює `dm = ρ · dV`.

Зміна внутрішньої теплової енергії цього елемента за проміжок часу `dt` зумовлена двома факторами:
1. Різницею між тепловими потоками, що входять у граничні грані об'єму та виходять із них шляхом теплопровідності.
2. Внутрішнім виділенням тепла у самому об'ємі (наприклад, через [джоулів нагрів](book:physics/joule-heating), хімічну реакцію чи радіоактивний розпад) із об'ємною потужністю `q_gen` [Вт/м³].

```
Зміна теплової енергії об'єму dV за час dt:
dQ_st = dm · c_p · (∂T/∂t) · dt
= ρ · c_p · (∂T/∂t) · dx · dy · dz · dt
```

---

### 2. Покрокове виведення у вимірі 1D

Розглянемо випадок одновимірного переносу тепла вздовж осі `x`. 

Крізь ліву грань площею `dA = dy · dz` у точці `x` за час `dt` входить тепловий потік:

```
Q_in = q_x(x) · dy · dz · dt
```

Крізь праву грань у точці `x + dx` виходить тепловий потік `Q_out = q_x(x + dx) · dy · dz · dt`. Розкладемо `q_x(x + dx)` у ряд Тейлора по `dx`, утримуючи перші два члени:

```
q_x(x + dx) = q_x(x) + (∂q_x/∂x) · dx
```

Різниця між вхідним і вихідним потоками становить:

```
Q_in - Q_out = q_x(x)·dy·dz·dt - [q_x(x) + (∂q_x/∂x)·dx]·dy·dz·dt
= - (∂q_x/∂x) · dx · dy · dz · dt
```

Додамо внутрішнє джерело тепла `Q_gen = q_gen · dx · dy · dz · dt`. За законом збереження енергії зміна накопиченої енергії дорівнює балансу припливу й виділення:

```
ρ·c_p · (∂T/∂t) · dx·dy·dz·dt = - (∂q_x/∂x) · dx·dy·dz·dt + q_gen · dx·dy·dz·dt
```

Скорочуємо обидві частини на об'єм `dx·dy·dz` та інтервал часу `dt`:

```
ρ · c_p · (∂T/∂t) = - (∂q_x/∂x) + q_gen      [диференціальний баланс енергії]
```

Підставимо закон Фурьє `q_x = -λ · (∂T/∂x)` у баланс енергії:

```
ρ · c_p · (∂T/∂t)
= - ∂/∂x [ -λ · (∂T/∂x) ] + q_gen            [підстановка закону Фурьє]
= ∂/∂x [ λ · (∂T/∂x) ] + q_gen               [спрощення знака мінус]
```

Якщо матеріал однорідний і ізотропний, а коефіцієнт теплопровідності `λ` сталий по всьому об'єму (`λ = const`), виносимо `λ` за знак похідної:

```
ρ · c_p · (∂T/∂t) = λ · (∂²T/∂x²) + q_gen
```

Поділивши обидві частини на добуток `ρ · c_p`, отримуємо класичне **одновимірне рівняння теплопровідності**:

```
∂T/∂t = α · (∂²T/∂x²) + q_gen / (ρ · c_p)
```

де `α` — коефіцієнт температуропровідності матеріалу:

```
α = λ / (ρ · c_p)                             [м²/с]
```

### 3. Тривимірне рівняння у декартових та криволінійних координатах

У тривимірному просторі густина теплового потоку є вектором `q = -λ · ∇T = -λ · (i·∂T/∂x + j·∂T/∂y + k·∂T/∂z)`. Баланс енергії у векторній формі записується через дивергенцію потоку:

```
ρ · c_p · (∂T/∂t) = - ∇ · q + q_gen
```

Підставляючи векторний закон Фурьє, маємо:

```
ρ · c_p · (∂T/∂t) = ∇ · (λ · ∇T) + q_gen
```

Для сталого `λ` дивергенція градієнта дає оператор Лапласа `∇²T = ΔT = ∂²T/∂x² + ∂²T/∂y² + ∂²T/∂z²`:

```
∂T/∂t = α · ∇²T + q_gen / (ρ · c_p)
```

#### 3.1. Циліндрична система координат (r, φ, z)

У багатьох інженерних задачах (трубопроводи, кругові провідники, циліндричні вилки) зручніше використовувати циліндричні координати. Оператор Лапласа набуває вигляду:

```
∇²T = (1/r) · ∂/∂r [ r · (∂T/∂r) ] + (1/r²) · (∂²T/∂φ²) + (∂²T/∂z²)
```

Якщо температурне поле володіє осьовою симетрією (`∂T/∂φ = 0`) та є однорідним вздовж довжини (`∂T/∂z = 0`), рівняння теплопровідності для довгого циліндра спрощується до:

```
∂T/∂t = α · [ (1/r) · ∂/∂r ( r · ∂T/∂r ) ] + q_gen / (ρ · c_p)
```

#### 3.2. Сферична система координат (r, θ, φ)

Для сферичних тіл (геофізичні задачі, сферичні резервуари, краплі) оператор Лапласа у радіальній симетрії (`T = T(r, t)`) має вигляд:

```
∇²T = (1/r²) · ∂/∂r [ r² · (∂T/∂r) ] = ∂²T/∂r² + (2/r) · (∂T/∂r)
```

Рівняння теплопровідності для центрально-симетричної сфери:

```
∂T/∂t = α · [ ∂²T/∂r² + (2/r) · (∂T/∂r) ] + q_gen / (ρ · c_p)
```

### 4. Фізичний зміст температуропровідності α

Коефіцієнт температуропровідності `α = λ / (ρ · c_p)` вимірюється у м²/с (або мм²/с) і характеризує **інерційність температурного поля**. 

- Чисельник `λ` показує здатність матеріалу **проводити** теплову енергію.
- Знаменник `C_v = ρ · c_p` (об'ємна теплоємність) показує здатність матеріалу **акумулювати (затримувати)** тепло у даній точці.

Матеріали з високим `α` (наприклад, мідь `α ≈ 117 мм²/с` чи алюміній `α ≈ 97 мм²/с`) миттєво реагують на зовнішній нагрів: тепловий фронт швидко поширюється углиб, і температура по всьому тілу вирівнюється. Матеріали з низьким `α` (наприклад, вода `α ≈ 0.14 мм²/с` або базальтова вата `α ≈ 0.8 мм²/с`) поглинають тепло поверхневим шаром, а всередині довго залишаються холодними.

Характерний час `τ` прогрівання шару завтовшки `L` оцінюється за числом Фур'є `Fo = α · τ / L² ≈ 1`, звідки:

```
τ ≈ L² / α
```

### 5. Крайові (граничні) умови для рівняння теплопровідності

Щоб знайти єдиний розв'язок диференціального рівняння теплопровідності, необхідно задати початковий розподіл температури `T(x, y, z, t=0)` та граничні умови на поверхнях тіла:

1. **Гранична умова I роду (умова Діріхле):**
   На поверхні тіла задано розподіл температури у кожен момент часу:
   `T(x_bound, t) = T_surf(t)`
   *Приклад:* деталь занурена у киплячу воду із постійною температурою 100 °C.

2. **Гранична умова II роду (умова Неймана):**
   На поверхні тіла задано значення густини теплового потоку:
   `-λ · (∂T/∂n)|_bound = q_surf(t)`
   *Приклад:* поверхню піддано стабільному опроміненню лазером або забійному електричному нагрівачу з відомою потужністю. 
   *Частиний випадок (ідеальна теплоізоляція):* `q_surf = 0 ⇒ (∂T/∂n)|_bound = 0`.

3. **Гранична умова III роду (умова Робіна):**
   Описує конвективний теплообмін поверхні із навколишнім середовищем за законом Ньютона-Ріхмана (де `h` — коефіцієнт тепловіддачі у Вт/(м²·К), а `T_amb` — температура середовища):
   `-λ · (∂T/∂n)|_bound = h · [T(x_bound, t) - T_amb]`
   *Приклад:* охолодження ребристого радіатора в потоці повітря від вентилятора.

### 6. Точний аналітичний розв'язок методом відокремлення змінних (Метод Фур'є)

Розглянемо класичну задачу про охолодження однорідного стрижня завдовжки `L`, початкова температура якого дорівнювала `T_init`. У момент часу `t = 0` обидва кінці стрижня `x = 0` та `x = L` миттєво охолоджуються до 0 °C і утримуються при цій температурі (`T(0, t) = T(L, t) = 0`).

Шукаємо розв'язок рівняння `∂T/∂t = α · (∂²T/∂x²)` у вигляді добутку двох функцій — часової `T_time(t)` та просторової `X_space(x)`:

```
T(x, t) = T_time(t) · X_space(x)
```

Підставляючи цей добуток у рівняння теплопровідності та розділяючи змінні, маємо:

```
(1 / (α · T_time)) · (dT_time/dt) = (1 / X_space) · (d²X_space/dx²) = - k²
```

де `-k²` — від'ємна константа відокремлення (від'ємна, оскільки температура має затухати у часі).

Отримуємо два звичайних диференціальних рівняння:

1. **Часове рівняння:** `dT_time/dt + α · k² · T_time = 0`
   Його розв'язок: `T_time(t) = C · exp(-α · k² · t)`
2. **Просторове рівняння:** `d²X_space/dx² + k² · X_space = 0`
   Його загальний розв'язок: `X_space(x) = A · cos(k·x) + B · sin(k·x)`

Застосовуємо граничні умови:
- `T(0, t) = 0 ⇒ A = 0`
- `T(L, t) = 0 ⇒ B · sin(k·L) = 0`

Оскільки `B ≠ 0`, маємо спектр власних чисел: `k_n = n · π / L`, де `n = 1, 2, 3, ...`.

За принципом суперпозиції підсумковий розв'язок записується у вигляді нескінченного тригонометричного ряду Фур'є:

```
T(x, t) = ∑_{n=1}^{∞} B_n · sin(n · π · x / L) · exp( - α · (n · π / L)² · t )
```

Коефіцієнти `B_n` визначаються з початкової умови `T(x, 0) = T_init` через інтеграли Фур'є:

```
B_n = (2 / L) · ∫_0^L T_init · sin(n · π · x / L) dx
= (2 · T_init / (n · π)) · [ 1 - cos(n · π) ]
```

Для непарних `n = 1, 3, 5, ...` коефіцієнт `B_n = 4 · T_init / (n · π)`, а для парних `n` дорівнює 0.

Таким чином, підсумковий розв'язок має вигляд:

```
T(x, t) = (4 · T_init / π) · ∑_{m=0}^{∞} [ 1 / (2m + 1) ] · sin( (2m+1)·π·x / L ) · exp( - α · ((2m+1)·π/L)² · t )
```

Видно, що вищі гармоніки (`n = 3, 5, ...`) затухають експоненціально набагато швидше за першу гармоніку `n = 1` завдяки множнику `n²` у показнику експоненти. Тому при великих значеннях часу `t > L² / (π² · α)` профіль температури описується першою синусоїдою!

### 7. Функція Ґріна та імпульсне теплове джерело (Гауссів ядро теплопровідності)

Для нескінченного середовища `(-∞ < x < +∞)`, якщо у початковий момент часу `t = 0` у точці `x = 0` виділяється миттєвий імпульс теплової енергії `Q_pulse` [Дж/м²], точний розв'язок диференціального рівняння описується **фундаментальним розв'язком (функцією Ґріна рівняння теплопровідності)**:

```
T(x, t) = [ Q_pulse / (ρ · c_p · √(4 · π · α · t)) ] · exp( - x² / (4 · α · t) )
```

Це рівняння описує **гауссову теплову хвилю**, яка з перебігом часу `t` розпливається у просторі:
- Максимальна температура у точці виділення `x = 0` спадає обернено пропорційно квадратному кореню з часу: `T_max(t) = T(0, t) ∝ 1 / √t`.
- Напівширина теплової плями (просторове розмивання) зростає за законом `σ_x = √(2 · α · t)`.

### 8. Покрокові приклади розрахунку

#### Приклад 8.1: Стаціонарний профіль температури з джерелом тепла

**Задача:** Прямокутний мідний провідник (ширина `2L`, `L = 5 мм`) проводить високий електричний струм, який створює рівномірне об'ємне джоулеве тепловидилення `q_gen = 2 × 10⁶ Вт/м³`. Обидві бічні поверхні `x = -L` та `x = +L` охолоджуються протоком рідини й утримуються при температурі `T_surf = 40 °C`. Визначити максимальну температуру в центрі провідника `x = 0`. Теплопровідність міді `λ = 400 Вт/(м·К)`.

**Розв'язання:**

Крок 1: Записуємо 1D стаціонарне рівняння Пуассона (`∂T/∂t = 0`):

```
d²T/dx² + q_gen / λ = 0
```

Крок 2: Інтегруємо перший раз по `x`:

```
dT/dx = - (q_gen / λ) · x + C₁
```

Крок 3: Інтегруємо другий раз по `x`:

```
T(x) = - (q_gen / (2·λ)) · x² + C₁·x + C₂
```

Крок 4: Знаходимо константи `C₁` та `C₂` з симетрії та граничних умов.
За умовою симетрії профіль температури має бути симетричним відносно центра `x = 0`, тобто потік у центрі дорівнює нулю:

```
(dT/dx)|_{x=0} = 0 ⇒ C₁ = 0
```

Використовуємо граничну умову на краях `T(L) = T_surf`:

```
T(L) = - (q_gen / (2·λ)) · L² + C₂ = T_surf
C₂ = T_surf + (q_gen · L²) / (2·λ)
```

Підставляємо `C₁` та `C₂` у загальний розв'язок:

```
T(x) = T_surf + [ (q_gen · L²) / (2·λ) ] · [ 1 - (x / L)² ]
```

Профіль температури виявився **параболічним**! 

Крок 5: Обчислюємо максимальну температуру в центрі `x = 0`:

```
T_max = T(0) = T_surf + (q_gen · L²) / (2·λ)
```

Підставляємо числові значення (`L = 0.005 м`, `q_gen = 2 × 10⁶ Вт/м³`, `λ = 400 Вт/(м·К)`, `T_surf = 40 °C`):

```
T_max = 40 + [ (2 × 10⁶) · (0.005)² ] / (2 × 400)
= 40 + [ (2 × 10⁶) · (2.5 × 10⁻⁵) ] / 800
= 40 + 50 / 800
= 40 + 0.0625 °C = 40.0625 °C
```

Завдяки високій теплопровідності міді (`λ = 400 Вт/(м·К)`) перепад температури між центром і поверхнею провідника завтовшки 10 мм становить лише 0.0625 °C. Якщо ж замінити мідь на нержавіючу сталь (`λ = 15 Вт/(м·К)`), цей самий перепад склав би `50 / 30 = 1.67 °C`, а для пластмасової матриці (`λ = 0.2 Вт/(м·К)`) перепад досяг би `50 / 0.4 = 125 °C`, що призвело б до розплавлення центра деталі.

#### Приклад 8.2: Сферична теплопровідність навколо точкового нагрівача

**Задача:** У центрі суцільної кулі радіуса `R_out = 0.1 м` розміщено точкове джерело тепла потужністю `P = 50 Вт`. Зовнішня поверхня кулі утримується при 20 °C. Матеріал має `λ = 2.5 Вт/(м·К)`. Визначити стаціонарний розподіл температури `T(r)`.

**Розв'язання:**
У стаціонарному сферично-симетричному випадку повний тепловий потік крізь сферичну поверхню радіуса `r` дорівнює `P = const`:

```
P = -λ · (4 · π · r²) · (dT/dr)
```

Розділяємо змінні та інтегруємо від `r` до `R_out`:

```
dT = - [ P / (4 · π · λ) ] · (dr / r²)
T(r) - T(R_out) = [ P / (4 · π · λ) ] · [ (1 / r) - (1 / R_out) ]
```

Підставляючи граничну умову `T(R_out) = 20 °C`:

```
T(r) = 20 + [ P / (4 · π · λ) ] · [ (1 / r) - (1 / R_out) ]
```

Для `r = 0.01 м` (1 см від центра):

```
T(0.01) = 20 + [ 50 / (4 · 3.14159 · 2.5) ] · [ 100 - 10 ]
= 20 + [ 50 / 31.4159 ] · 90
= 20 + 1.5915 · 90 = 20 + 143.2 = 163.2 °C
```

Температура зростає за гіперболічним законом `1/r` при наближенні до центрального джерела тепла.
