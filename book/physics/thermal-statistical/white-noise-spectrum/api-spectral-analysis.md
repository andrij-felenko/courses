# 📋 Довідник інтерфейсів та параметрів спектрального аналізу

Цей довідник містить технічні специфікації, структуру даних, параметри віконних функцій, коефіцієнти еквівалентної шумової смуги (ENBW), довірчі інтервали та формули перетворення одиниць для спектрального аналізу вимірювальних систем і моделювання білого шуму.

---

### 1. Одиниці вимірювання шумових величин та спектральних характеристик

При проведенні аналізу, вимірюваннях і розрахунках у радіотехніці, акустиці, вимірювальній техніці та цифровій обробці сигналів використовують кілька альтернативних систем одиниць для опису випадкових шумових процесів. 

Головна фізична та розрахункова відмінність полягає між **квадратичними одиницями спектральної щільності потужності (Power Spectral Density, PSD)**, які вимірюють середня шумова потужність на одиницю частотної смуги (`В²/Гц` або `А²/Гц`), та **амплітудними одиницями спектральної густини (Amplitude Spectral Density, ASD)**, які виражаються у вольтах або амперах на корінь із герца (`В/√Гц` або `А/√Гц`).

У специфікаціях напівпровідникових компонентів (операційних підсилювачів, малошумних транзисторів, малошумних регуляторів напруги LDO) виробники майже завжди вказують спектральну густину напруги шуму `e_n` у `нВ/√Гц`. Для переходу до шумової потужності чи обчислення середньоквадратичного значення напруги в заданій смузі частот `B_n` амплітудну густину підносять до квадрата і множать на смугу.

У таблиці наведено стандартні фізичні й інженерні одиниці вимірювання спектральних характеристик шумів, їхні математичні позначення, формули взаємного перетворення та фізичний зміст.

| Величина | Позначення | Одиниці вимірювання | Формула зв'язку | Фізичний зміст та застосування |
| :--- | :--- | :--- | :--- | :--- |
| **Одностороння PSD (напруга)** | `G_U(f)` | `В²/Гц` | `G_U = e_n²` | Середня шумова потужність напруги на `1 Гц` смуги. Використовується в теоретичній фізиці. |
| **Спектральна густина напруги (ASD)** | `e_n(f)` | `В/√Гц`, `нВ/√Гц` | `e_n = √(G_U)` | Амплітудна густина флуктуацій напруги. Стандарт у специфікаціях операційних підсилювачів. |
| **Одностороння PSD (струм)** | `G_I(f)` | `А²/Гц` | `G_I = i_n²` | Середня шумова потужність струму на `1 Гц` смуги. Розрахунок дробового шуму Шотткі. |
| **Спектральна густина струму (ASD)** | `i_n(f)` | `А/√Гц`, `пА/√Гц` | `i_n = √(G_I)` | Амплітудна густина вхідного шумового струму транзисторів та підсилювачів. |
| **Логарифмічна PSD потужності** | `S_dBm(f)` | `дБм/Гц` | `10·lg( G_P / 1 мВт )` | Шумова потужність на опорі `50 Ом` відносно `1 мВт`. Стандарт аналізаторів спектра ВЧ. |
| **Логарифмічна ASD напруги** | `S_dBV(f)` | `дБВ/√Гц` | `20·lg( e_n / 1 В/√Гц )` | Амплітудна густина шумової напруги відносно `1 В/√Гц`. Застосовується в аудіометрії. |
| **Повна шумова напруга (RMS)** | `U_rms` | `В`, `мкВ` | `U_rms = e_n · √(B_n)` | Інтегральне середньоквадратичне значення шумової напруги в еквівалентній смузі `B_n`. |

### 2. Специфікація віконних функцій та еквівалентної шумової смуги (ENBW)

При проведенні цифрового спектрального аналізу методом БПФ часовий сигнал ділять на скінченні сегменти тривалістю `L` відліків. Пряме зрізання сигналу відповідає застосуванню прямокутного вікна, яке викликає сильний ефект розтікання спектра (spectral leakage) через повільне згасання бокових пелюсток функції `sin(x)/x`.

Щоб зменшити розтікання спектра, сегмент сигналу множать на згладжувальне вікно `w[n]`. Проте застосування вікна змінює амплітуду і розширює центральну пелюстку БПФ. Для точного нормування спектральної щільності вводиться поняття **еквівалентної шумової смуги вікна (ENBW)**.

ENBW виражає ширину ідеального прямокутного фільтра, який пропускає таку саму потужність білого шуму, як і дана віконна функція. Вона вимірюється в одиницях частотних комірок БПФ `Δf = f_s / L` і обчислюється за формулою:

```
ENBW = L · [ ∑_{n=0}^{L-1} w²[n] ] / [ ∑_{n=0}^{L-1} w[n] ]²   [в одиницях частотних комірок Δf = f_s / L]
```

У таблиці подано вичерпні параметри основних віконних функцій, які застосовуються при вимірюванні шумів:

| Віконна функція | Математична формула `w[n]` (`n = 0..L-1`) | ENBW (комірок) | Згасання 1-ї пелюстки | Крутизна спаду пелюсток | Нормувальний коефіцієнт потужності `S_w` |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Прямокутне (Rectangular)** | `w[n] = 1.0` | `1.000` | `-13.3 дБ` | `-6 дБ/октава` | `1.000` |
| **Хенна (Hann)** | `0.5 · [1 - cos(2πn / (L-1))]` | `1.500` | `-31.5 дБ` | `-18 дБ/октава` | `0.375` |
| **Хеммінга (Hamming)** | `0.54 - 0.46 · cos(2πn / (L-1))` | `1.363` | `-42.7 дБ` | `-6 дБ/октава` | `0.397` |
| **Блекмана (Blackman)** | `0.42 - 0.5·cos(2πn/L) + 0.08·cos(4πn/L)` | `1.727` | `-58.1 дБ` | `-18 дБ/октава` | `0.305` |
| **Flat Top (Плоска вершина)** | `0.215 - 0.42·cos + 0.28·cos - 0.08·cos` | `3.770` | `-93.6 дБ` | `-6 дБ/октава` | `0.147` |

#### Практичні правила вибору вікна:
1. **Вікно Хенна (Hann):** Є вибором за замовчуванням для спектрального аналізу білого та забарвленого шуму. Воно забезпечує відмінний компроміс між помірним розширенням смуги (`ENBW = 1.50`) та високим пригніченням бокових пелюсток (`-31.5 дБ`).
2. **Вікно Блекмана (Blackman):** Застосовується, коли в сигналі поруч із широким шумовим спектром присутні потужні тональні завади, які необхідно пригнітити більше ніж на `50 дБ`.
3. **Вікно Flat Top:** Використовується виключно для точного вимірювання амплітуди дискретних гармонійних піків. Для аналізу суцільного білого шуму воно небажане через надмірно широку шумову смугу (`ENBW = 3.77`).

### 3. Специфікація програмного інтерфейсу (C/C++ API)

Нижче подано повну специфікацію інтерфейсного заголовочного файла `spectral_analysis_api.h` для інтеграції модулів аналізу шуму в інженерне програмне забезпечення, а також ідіоматичну C++ обгортку.

:::tabs
```c
/* Header: spectral_analysis_api.h */
#ifndef SPECTRAL_ANALYSIS_API_H
#define SPECTRAL_ANALYSIS_API_H

#ifdef __cplusplus
extern "C" {
#endif

/* Перераховуваний тип переліку віконних функцій */
typedef enum {
    WINDOW_RECTANGULAR = 0, /* Прямокутне вікно (без віконної обробки) */
    WINDOW_HANN        = 1, /* Вікно Хенна (рекомендоване для шумів) */
    WINDOW_HAMMING     = 2, /* Вікно Хеммінга */
    WINDOW_BLACKMAN    = 3, /* Вікно Блекмана з високим пригніченням */
    WINDOW_FLAT_TOP    = 4  /* Вікно з плоскою вершиною для калібрування */
} WindowType;

/* Коди помилок API */
typedef enum {
    PSD_SUCCESS           =  0, /* Успішне виконання операції */
    PSD_ERR_NULL_POINTER  = -1, /* Передано нульовий вказівник */
    PSD_ERR_INVALID_SIZE  = -2, /* Некоректний розмір БПФ (не є ступенем 2) */
    PSD_ERR_INVALID_RATE  = -3, /* Частота дискретизації <= 0 */
    PSD_ERR_NO_MEMORY     = -4  /* Помилка виділення динамічної пам'яті */
} PsdErrorCode;

/* Структура конфігурації аналізатора спектра Велча */
typedef struct {
    double     sample_rate_hz;  /* Частота дискретизації f_s (Гц), f_s > 0 */
    int        fft_size;        /* Розмір БПФ N_fft (2^K: 512, 1024, 2048...) */
    int        overlap_samples; /* Перекриття сегментів в відліках (N_fft / 2) */
    WindowType window_type;     /* Обраний тип згладжувального вікна */
} PsdConfig;

/* Структура конфігурації генератора гауссового білого шуму */
typedef struct {
    double       target_g0;     /* Цільова одностороння PSD G_0 (В²/Гц) */
    double       sample_rate_hz;/* Частота дискретизації f_s (Гц) */
    unsigned int seed;          /* Початкове зерно генератора випадкових чисел */
} NoiseGenConfig;

/* Структура з результатами спектрального аналізу */
typedef struct {
    double *freq_bins;         /* Масив частотних точок f_k від 0 до f_s/2 (Гц) */
    double *psd_density;       /* Масив значень PSD G_x(f) (В²/Гц) */
    int     num_bins;          /* Кількість частотних комірок (N_fft/2 + 1) */
    double  enbw_hz;           /* Еквівалентна шумова смуга однієї комірки (Гц) */
    int     segments_averaged; /* Кількість усереднених періодограм K */
} PsdResult;

/* Публічні функції програмного інтерфейсу */

/**
 * @brief Ініціалізація та перевірка коректності конфігурації аналізатора.
 * @param cfg Вказівник на структуру конфігурації PsdConfig.
 * @return PSD_SUCCESS у разі успіху або відповідний код помилки.
 */
int psd_analyzer_init(PsdConfig *cfg);

/**
 * @brief Обчислення спектральної щільності потужності методом Велча.
 * @param signal_in Вхідний масив відліків сигналу.
 * @param signal_len Загальна кількість відліків у масиві.
 * @param cfg Вказівник на налаштування аналізатора.
 * @param res_out Вказівник на структуру результату (пам'ять виділяється всередині).
 * @return PSD_SUCCESS або код помилки.
 */
int psd_compute_welch(const double *signal_in, int signal_len, 
                      const PsdConfig *cfg, PsdResult *res_out);

/**
 * @brief Звільнення динамічної пам'яті, виділеної під результат аналізу.
 * @param res_out Вказівник на структуру результату PsdResult.
 */
void psd_result_free(PsdResult *res_out);

#ifdef __cplusplus
}
#endif

#endif /* SPECTRAL_ANALYSIS_API_H */
```

```cpp
// C++ Idiomatic Wrapper Header: spectral_analysis_api.hpp
#ifndef SPECTRAL_ANALYSIS_API_HPP
#define SPECTRAL_ANALYSIS_API_HPP

#include <span>
#include <vector>
#include <system_error>
#include "spectral_analysis_api.h"

namespace spectral {

enum class Window : int {
    Rectangular = WINDOW_RECTANGULAR,
    Hann        = WINDOW_HANN,
    Hamming     = WINDOW_HAMMING,
    Blackman    = WINDOW_BLACKMAN,
    FlatTop     = WINDOW_FLAT_TOP
};

struct SpectralResult {
    std::vector<double> frequencies;
    std::vector<double> psd;
    double enbw_hz;
    int segments_averaged;
};

class Analyzer {
public:
    Analyzer(double sample_rate_hz, int fft_size, Window win = Window::Hann) {
        cfg_.sample_rate_hz = sample_rate_hz;
        cfg_.fft_size = fft_size;
        cfg_.overlap_samples = fft_size / 2;
        cfg_.window_type = static_cast<WindowType>(win);
        
        if (int err = psd_analyzer_init(&cfg_); err != PSD_SUCCESS) {
            throw std::system_error(err, std::generic_category(), "PSD Init Failed");
        }
    }

    SpectralResult process(std::span<const double> signal) const {
        PsdResult c_res{};
        int status = psd_compute_welch(signal.data(), static_cast<int>(signal.size()), &cfg_, &c_res);
        if (status != PSD_SUCCESS) {
            throw std::system_error(status, std::generic_category(), "PSD Compute Failed");
        }

        SpectralResult cpp_res;
        cpp_res.frequencies.assign(c_res.freq_bins, c_res.freq_bins + c_res.num_bins);
        cpp_res.psd.assign(c_res.psd_density, c_res.psd_density + c_res.num_bins);
        cpp_res.enbw_hz = c_res.enbw_hz;
        cpp_res.segments_averaged = c_res.segments_averaged;

        psd_result_free(&c_res);
        return cpp_res;
    }

private:
    PsdConfig cfg_{};
};

} // namespace spectral

#endif // SPECTRAL_ANALYSIS_API_HPP
```

### 4. Статистична похибка та довірчі інтервали оцінки Велча

Оцінка спектральної щільності `Ĝ(f)`, отримана методом Велча шляхом усереднення `K` незалежних перекритих сегментів, є випадковою величиною, яка підпорядковується розподілу хі-квадрат `χ²` з `2 · K` ступенями вільності.

#### Відносна середньоквадратична похибка
Відносна середньоквадратична похибка (Normalized RMS Error) оцінки виражається простішою формулою:

```
ε_rms = σ[ Ĝ(f) ] / E[ Ĝ(f) ] = 1 / √( K )
```

У таблиці наведено залежність статистичної похибки та розмаху 95% довірчого інтервалу від кількості усереднених сегментів `K`:

| Кількість усереднених сегментів `K` | Відносна RMS похибка `ε_rms` | Верхня/нижня межа 95% довірчого інтервалу (в дБ) |
| :--- | :--- | :--- |
| `1` (одинарна періодограма) | `100.0 %` | від `-5.21 дБ` до `+13.52 дБ` |
| `4` | `50.0 %` | від `-3.12 дБ` до `+5.64 дБ` |
| `16` | `25.0 %` | від `-1.74 дБ` до `+2.31 дБ` |
| `64` | `12.5 %` | від `-0.92 дБ` до `+1.12 дБ` |
| `256` | `6.25 %` | від `-0.44 дБ` до `+0.48 дБ` |

#### Формула обчислення точних довірчих меж
Істинне значення спектральної щільності `G(f)` з ймовірністю `95%` перебуває у межах:

```
[ (2 · K · Ĝ(f)) / χ²_{0.025, 2K} ] ≤ G(f) ≤ [ (2 · K · Ĝ(f)) / χ²_{0.975, 2K} ]
```

де `χ²_{α, 2K}` — відповідні квантилі розподілу хі-квадрат із `2K` ступенями вільності.

### 5. Метрики шуму та динамічного діапазону аналого-цифрових перетворювачів (АЦП)

При використанні АЦП для оцифрування аналогового шуму власні шуми АЦП (шум квантування, тепловий шум та джитєр тактового генератора) накладаються на вхідний білий шум. Для специфікації вимірювальних АЦП застосовують наступні стандартні параметри:

1. **Шум квантування (Quantization Noise):**
   Ідеальний N-розрядний АЦП створює шум квантування з рівномірним розподілом помилки в інтервалі `[-Δ/2, +Δ/2]`, де `Δ = V_ref / 2^N` — крок квантування. Дисперсія шуму квантування дорівнює:
   ```
   σ_квант² = Δ² / 12
   ```
   Уся потужність шуму квантування розмазується у смузі Найквіста `0..f_s/2`, створюючи білу шумову підлогу зі спектральною щільністю `G_квант = Δ² / (6 · f_s)`.

2. **Теоретичне відношення сигнал/шум (SNR) ідеального АЦП:**
   При подачі синусоїди повної шкали максимально досяжне відношення сигнал/шум дорівнює:
   ```
   SNR_max = 6.02 · N + 1.76   [дБ]
   ```

3. **Ефективна кількість розрядів (ENOB):**
   Реальний АЦП має додаткові шуми та нелінійності. Якщо виміряти параметр SINAD (Signal-to-Noise and Distortion), то ефективна кількість розрядів обчислюється як:
   ```
   ENOB = ( SINAD - 1.76 ) / 6.02
   ```

4. **Передискретизація (Oversampling) та шумова вигода:**
   Збільшення частоти дискретизації у `OSR` разів (OverSampling Ratio) розмазує той самий шум квантування по `OSR` разів ширшій смузі. Якщо потім застосувати цифровий ФНЧ і зменшити частоту дискретизації назад, спектральна щільність шуму падає у `OSR` разів. Це дає виграш по відношенню сигнал/шум:
   ```
   ΔSNR = 10 · lg( OSR )   [дБ]
   ```
   Кожна чотирикратна передискретизація (`OSR = 4`) додає `1` ефективний біт роздільності (`+6 дБ` до SNR).

### 6. Специфікація вимірювання фазового шуму та варіації Аллана

Для оцінки високостабільних генераторів частоти (кварцових генераторів OCXO, рубіндієвих та цезієвих стандартів частоти, синтетзаторів PLL) застосовують специфічні характеристики шумових флуктуацій фази:

1. **Спектральна щільність фазового шуму `L(f)`:**
   Вимірюється у `дБн/Гц` (децибели відносно потужності несучої в смузі `1 Гц`) на заданій частоті зсуву `f` від несучої:
   ```
   L(f) = 10 · lg[ S_phi(f) / 2 ]   [дБн/Гц]
   ```
   де `S_phi(f)` — одностороння спектральна щільність флуктуацій фази у `рад²/Гц`. Білий фазовий шум описується горизонтальною прямою `L(f) = const`.

2. **Двовибіркова варіація Аллана `σ_y²(τ)`:**
   Для часових інтервалів усереднення `τ` варіація Аллана пов'язана зі спектральною щільністю флуктуацій частоти `S_y(f)` інтегральним співвідношенням:
   ```
   σ_y²(τ) = 2 · ∫_{0}^{∞} S_y(f) · [ sin⁴(π · f · τ) / (π · f · τ)² ] df
   ```
   Для білого шуму частоти варіація Аллана спадає як `σ_y(τ) ∝ 1 / √τ`, що дозволяє оцінювати граничну точність атомних годинників та супутникових систем навігації (GPS/GLONASS/Galileo).

### 7. Промислові вимірювальні стандарти спектрального аналізу

При проведення випробувань на електромагнітну сумісність (EMC/EMI) та вимірюванні шумів радіоелектронного обладнання керуються міжнародними вимірювальними стандартами:

* **IEEE 181-2011:** Стандарт на термінологію та методи вимірювання часових та частотних характеристик пульсуючих сигналів і шумів.
* **IEEE 1057:** Стандарт на випробування та методи апаратної цифрової оцінки параметрів аналого-цифрових перетворювачів.
* **MIL-STD-461G:** Військовий стандарт США, що встановлює максимальні дозволені рівні спектральної щільності кондуктивних та випромінювальних шумових завад у діапазоні від 10 Гц до 40 ГГц.

Застосування міжнародних вимірювальних стандартів забезпечує метрологічну єдність та відтворюваність результатів вимірювань спектральної щільності шумів у незалежних тестових лабораторіях по всьому світу.

---

### 8. Специфікація оптоелектронних вимірювань оптичного шуму (EDFA та ASE)

У волоконно-оптичних системах зв'язку волоконні оптичні підсилювачі на ербієвому склі (EDFA) створюють шуми спонтанного випромінювання (Amplified Spontaneous Emission, ASE), які є оптичним гауссовим білим шумом у широкій оптичній смузі порядку кількох терагерц.

Шумовий фактор оптичного підсилювача `F_opt` описується відношенням спектральних щільностей фотоструму до та після підсилення і визначається фундаментальним квантовим лімітом: `F_opt ≥ 2` (`3 дБ`). Жоден оптичний підсилювач світла не може мати коефіцієнт шуму нижчий за `3 дБ` через фундаментальний квантовий білий шум спонтанних переходів атома.

### 9. Специфікації мікроконтролерних бібліотек обробки шумів (CMSIS-DSP та IPP)

У промислових вбудованих системах розробники не пишуть БПФ вручну, а використовують оптимізовані апаратні бібліотеки від виробників мікросхем:

1. **ARM CMSIS-DSP:**
   Містить високооптимізовані функції `arm_rfft_fast_f32()` для мікроконтролерів Cortex-M4F/M7/M55. Для обчислення БПФ на 1024 точок у форматі float32 витрачається всього близько `12000` тактів процесора.

2. **Intel Integrated Performance Primitives (IPP):**
   Використовує інструкції AVX-512 для обчислення векторних БПФ над масивами з мільйонів відліків на серверних процесорах Xeon, забезпечуючи швидкість у десятки гігафлопс.

### 10. Методика калібрування спектральних вимірювань (ENR та Y-фактор)

При вимірюванні абсолютних рівнів спектральної щільності радіочастотних шумів застосовують метод **Y-фактора** з використанням калабірованого джерела генератора білого шуму з відомим коефіцієнтом надлишкового шуму (Excess Noise Ratio, ENR):

```
ENR (дБ) = 10 · lg[ (T_hot - T_cold) / T₀ ]
```

Джерело почергово вмикають (гарячий стан `T_hot`) та вимикають (холодний стан `T_cold = T₀`). Відношення виміряних вихідних потужностей визначає `Y = P_hot / P_cold`, з якого розраховують коефіцієнт шуму вимірювального тракту `F`:

```
F = [ 10^(ENR / 10) ] / ( Y - 1 )
```

Ця методика усуває власні шуми вимірювального приладу і дозволяє вимірювати спектральну щільність білого шуму з високою точністю до `0.1 дБ`.

### 11. Параметри шумових характеристик каскадних систем (Формула Фрііса)

При розробці багатокаскадних радіоприймальних систем, вимірювальних трактів та підсилювальних ланцюгів кожен каскад додає свій власний шумові внесок до вхідного білого шуму. Для кількісної оцінки погіршення відношення сигнал/шум (SNR) використовують **коефіцієнт шуму (Noise Factor)** `F` та **індекс шуму (Noise Figure)** `NF`:

```
F = ( SNR_in ) / ( SNR_out ) ≥ 1
NF = 10 · lg( F )   [вимірюється в дБ]
```

Якщо систему утворено послідовним з'єднанням `M` каскадів з коефіцієнтами підсилення потужності `G₁, G₂, ..., G_M` та коефіцієнтами шуму `F₁, F₂, ..., F_M`, то загальний коефіцієнт шуму системи `F_total` визначається **формулою Фрііса** (Harald Friis, 1944 рік):

```
F_total = F₁ + (F₂ - 1) / G₁ + (F₃ - 1) / (G₁ · G₂) + ... + (F_M - 1) / (G₁ · G₂ · ... · G_{M-1})
```

#### Головні інженерні висновки з формули Фрііса:
1. **Перший каскад вирішує все:** Коефіцієнт шуму першого підсилювального каскаду `F₁` повністю додається до загального шуму системи, тоді як внески наступних каскадів діляться на коефіцієнт підсилення попередніх ступенів `G₁ · G₂...`. 
2. **Вимоги до малошумного малосигнального підсилювача (LNA):** Перший підсилювач тракту повинен мати якомога менший власний коефіцієнт шуму `F₁` та достатньо високий коефіцієнт підсилення `G₁ >> 1`, щоб пригнітити шумові внески всіх подальших елементів (змішувачів, АЦП, фільтрів).

Еквівалентна шумова температура системи `T_e` пов'язана з коефіцієнтом шуму `F` через стандартну температуру `T₀ = 290 К`:

```
T_e = T₀ · (F - 1)
```

### 12. Практичний довідник перетворення між одиницями вимірювання

При проведеному аналізі та розрахунках шумів виникає потреба переводити значення між вольтовими одиницями, логарифмічними дБм та абсолютними значеннями потужності.

1. **Перетворення спектральної густини напруги `e_n` (`нВ/√Гц`) у спектральну щільність `G_U` (`В²/Гц`):**

```
G_U (В²/Гц) = [ e_n (нВ/√Гц) × 10⁻⁹ ]²
```
*Приклад:* Якщо підсилювач має власну шумову напругу `e_n = 5 нВ/√Гц`, його спектральна щільність потужності напруги становить `G_U = (5 × 10⁻⁹)² = 2.5 × 10⁻¹⁷ В²/Гц`.

2. **Перетворення спектральної щільності напруги `G_U` (`В²/Гц`) у логарифмічну потужність `S_dBm` (`дБм/Гц`) на опорі `R = 50 Ом`:**

```
S_dBm/Гц = 10 · lg[ (G_U / R) / 1 мВт ] 
= 10 · lg[ G_U / 0.05 ]
= 10 · lg(G_U) + 13.01 дБm
```
*Приклад:* Для теплового шуму опору `50 Ом` при кімнатній температурі (`300 К`) одностороння спектральна щільність дорівнює `G_U = 4 · k_B · T · R ≈ 8.28 × 10⁻²⁰ В²/Гц`.
Обчислимо логарифмічну щільність:
`S_dBm/Гц = 10 · lg(8.28 × 10⁻²⁰) + 13.01 = -190.82 + 13.01 = -173.81 дБм/Гц ≈ -174 дБм/Гц`.

3. **Фундаментальна теплова шумова підлога:**
Число **`-174 дБм/Гц`** є фундаментальним фізичним орієнтиром для будь-якого розробника радіоприймальних систем, ВЧ-підсилювачів та датчиків. Воно визначає мінімально можливу шумову потужність білого шуму у смузі `1 Гц` при кімнатній температурі. Жоден радіоприймач чи підсилювач на опорі `50 Ом` не може мати власний шум, нижчий за `-174 дБм/Гц`.

### 13. Специфікація шумових параметрів датчиків (MEMS та фотодіоди)

В сучасних мікроелектромеханічних системах (MEMS-акселерометрах, гіроскопах) та оптичних фотодетекторах параметри шуму в специфікаціях вказуються в спеціальних вимірювальних одиницях фізичної величини на корінь із герца:

#### MEMS Акселерометри
Шумова підлога акселерометра вказується у спектральній густині прискорення `a_n` у одиницях `мкg/√Гц` або `(м/с²)/√Гц`.
*Середньоквадратичний шум прискорення у смузі `B`:*
```
a_rms = a_n · √( B )
```
*Приклад:* Для акселерометра з `a_n = 100 мкg/√Гц` у смузі `B = 100 Гц` маємо `a_rms = 100 · √100 = 1000 мкg = 1 mg`.

#### MEMS Гіроскопи
Шумова підлога кутової швидкості вказується в одиницях `°/с/√Гц` або `°/год/√Гц` (Rate Noise Density).
Кутовий випадковий блукач (Angle Random Walk, ARW) описує накопичення похибки інтегрування кута за часом:
```
ARW ( °/√год ) = (1 / 60) · Noise_Density ( °/с/√Гц )
```

#### Фотодіоди та трансімпедансні підсилювачі (TIA)
У фотодетекторах еквівалентна потужність шуму (Noise Equivalent Power, NEP) визначає мінімальну оптичну потужність сигналу у ватах, яка дає відношення сигнал/шум, що дорівнює одиниці у смузі `1 Гц`:
```
NEP = i_n / R_λ   [вимірюється у Вт/√Гц]
```
де `i_n` — спектральна густина шумового струму в `А/√Гц`, а `R_λ` — спектральна чутливість фотодіода у `А/Вт`.

### 14. Рекомендації з проєктування низькошумних друкованих плат (PCB Design)

При розробці високоелементних плати вимірювальних приладів дотримання правил розведення плати є вирішальним для збереження низького рівня шуму:
1. **Розділення аналогової та цифрової землі:** Цифрові земляні провідники несуть високочастотні імпульсні струми від перемикання логічних брам, які можуть наводити білий та рожевий шум на аналогові кола. З'єднання аналогової (AGND) та цифрової (DGND) земель проводиться строго в одній точці — безпосередньо під АЦП («зіркова земля»).
2. **Розв'язувальні конденсатори:** Для пригнічення високочастотного білого шуму у шинах живлення паралельно підключають керамічні конденсатори ємністю `0.1 мкФ` (з малою власною індуктивністю) та танталові або електролітичні ємності `10 мкФ` біля кожного виводу живлення МС.
3. **Екранування чутливих вузлів:** Вхідні високомодомні кола трансімпедансних підсилювачів або датчиків оточують захисним кільцем (Guard Ring), під'єднаним до того самого потенціалу, для усунення струмів витоку по поверхні текстоліту.
