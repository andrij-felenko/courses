# 🧮 Молекулярно-кінетичний вивід рівняння стану ідеального газу

Ця математична вставка містить строгий крок-за-кроком вивід рівняння стану ідеального газу виходячи з законів класичної механіки Ньютона для пружних зіткнень частинок зі стінками посудини, виведення через інтегрування по сферичному тілесному куту та статистичне обґрунтування через теорему про рівнорозподіл енергії за ступенями вільності.

### 1. Фізична модель, фазовий простір та ергодична гіпотеза

Термодинамічний стан ідеального газу визначається ансамблем із колосального числа частинок `N` (порядку `10²³`), заперених у судині об'ємом `V`. Модель ідеального газу базується на трьох точних математичних припущеннях:
1. Власний об'єм частинок дорівнює нулю (матеріальні точки).
2. Потенціальна енергія міжмолекулярної взаємодії на відстані дорівнює нулю (`E_pot = 0`).
3. Усі зіткнення частинок між собою та зі стінками посудини є абсолютно пружними.

Для математичного опису ансамблю застосовують концепцію 6-вимірного фазового простору частинки `(x, y, z, p_x, p_y, p_z)`, де стан кожної молекули задається координатами та компонентами імпульсу. Згідно з ергодичною гіпотезою Больцмана, усреднення за часом для однієї частинки на довгій траєкторії є тотожним усредненню за статистичним ансамблем у даній точці фазового простору.

Розглянемо закриту посудину у формі прямокутного паралелепіпеда з довжинами ребер `L_x`, `L_y`, `L_z`, усередині якої знаходиться `N` однаковими частинок масою `m₀` кожна. Повний геометричний об'єм посудини становить:

```
V = L_x · L_y · L_z
```

Частинки хаотично рухаються зі швидкостями `v⃗_i = (v_ix, v_iy, v_iz)`. Розглянемо одну частинку `i`, яка рухається до правої вертикальної стінки площею `A_x = L_y · L_z`, перпендикулярної до осі `x`.

При абсолютно пружному відбиванні від нерухомої стінки нормальна складова швидкості `v_ix` змінює знак на протилежний, тоді як тангенціальні складові `v_iy` та `v_iz` залишаються незмінними:

```
v⃗_i  = ( v_ix,  v_iy,  v_iz)      [стан до удару]
v⃗_i' = (-v_ix,  v_iy,  v_iz)      [стан після пружного відбивання]
```

Зміна проекції імпульсу частинки на вісь `x` за один удар дорівнює різниці між кінцевим та початковим імпульсом:

```
Δp_ix = m₀ · (-v_ix) - m₀ · v_ix = -2 · m₀ · v_ix      [зміна імпульсу: кінцевий мінус початковий]
```

За третім законом Ньютона стінка отримує від частинки імпульс, рівний за модулем і протилежний за напрямком:

```
Δp_стінки = +2 · m₀ · v_ix      [3-й закон Ньютона: імпульс передано стінці]
```

### 2. Частота ударів, елементарний потік та середня сила

Після відбивання частинка летить до протилежної стінки, відбивається від неї і знову повертається до правої стінки. Відстань між двома послідовними ударами об праву стінку вздовж осі `x` дорівнює `2 · L_x`. Інтервал часу `Δt_i` між двома послідовними ударами цієї частинки об праву стінку дорівнює:

```
Δt_i = 2 · L_x / v_ix      [час прольоту туди й назад зі швидкістю v_ix]
```

Усереднена за часом сила `F_ix`, з якою ця одна частинка тисне на праву стінку, за другим законом Ньютона дорівнює відношенню переданого імпульсу до інтервалу часу:

```
F_ix = Δp_стінки / Δt_i                        [2-й закон Ньютона у формі імпульсу]
     = (2 · m₀ · v_ix) / (2 · L_x / v_ix)      [підстановка виразів для Δp_стінки та Δt_i]
     = m₀ · v_ix² / L_x                        [скорочення двійки та множення на v_ix]
```

Загальна середня сила `F_x`, що діє на стінку з боку всіх `N` частинок газу, дорівнює сумі сил від кожної частинки:

```
F_x = ∑ (i=1..N) F_ix                           [сумування сил по всьому ансамблю]
    = (m₀ / L_x) · ∑ (i=1..N) v_ix²             [винесення спільного множника m₀ / L_x]
```

Введемо середній квадрат проекції швидкості `⟨v_x²⟩` по всьому ансамблю `N` частинок:

```
⟨v_x²⟩ = (1 / N) · ∑ (i=1..N) v_ix²             [визначення математичного усереднення по ансамблю]
```

Тоді загальну силу можна переписати через середнє значення:

```
F_x = (N · m₀ / L_x) · ⟨v_x²⟩                   [підстановка середнього квадрата проекції]
```

### 3. Строгий вивід через потоки частинок у сферичних координатах

Для довільної форми посудини вивід можна зробити ще строгішим через потік частинок. Розглянемо елементарну площадку стінки `dA`. Нехай концентрація частинок, що мають швидкості у діапазоні від `v⃗` до `v⃗ + d(v⃗)`, дорівнює `dn(v⃗)`.

Усі частинки з цією швидкістю, які вдаряться об площадку `dA` за час `dt`, знаходяться усередині похилого циліндра з основою `dA` та твірною `v⃗ · dt`. Об'єм цього циліндра дорівнює:

```
dV_цил = dA · v · cos(θ) · dt
```

де `θ` — кут між вектором швидкості `v⃗` та внутрішньою нормаллю до стінки. Число ударів таких частинок за час `dt` дорівнює:

```
dN_ударів = dn(v⃗) · dA · v · cos(θ) · dt
```

Кожна така частинка передає стінці нормальний імпульс `2 · m₀ · v · cos(θ)`. Тоді елементарний імпульс `d(dp)`, переданий площадці `dA` за час `dt`, становить:

```
d(dp) = 2 · m₀ · v² · cos²(θ) · dn(v⃗) · dA · dt
```

Поділивши на `dA · dt`, отримуємо внесок у макроскопічний тиск:

```
dP = 2 · m₀ · v² · cos²(θ) · dn(v⃗)
```

Ураховуючи ізотропію напрямків, частка молекул із напрямком у тілесному куті `dΩ = sin(θ) dθ dϕ` дорівнює `dΩ / (4·π)`. Інтегруючи за кутом `ϕ` від `0` до `2·π` та за полярним кутом `θ` від `0` до `π/2` (тільки молекули, що летять до стінки):

```
∫ (ϕ=0..2π) dϕ ∫ (θ=0..π/2) cos²(θ) · sin(θ) dθ = 2·π · [ -cos³(θ) / 3 ] (від 0 до π/2)
                                                = 2·π · (1 / 3) = (2 / 3) · π
```

Ураховуючи нормувальний множник `1 / (4·π)` від повного тілесного кута та множник `2` від відбивання:

```
2 · [ (2/3) · π / (4·π) ] = 2 · (1 / 6) = 1 / 3
```

Ми отримуємо той самий фундаментальний множник `1 / 3`, незалежно від геометричної форми судини!

### 4. Ізотропія та основне рівняння МКТ для тиску

Унаслідок абсолютної хаотичності теплового руху жоден напрямок у просторі не є виділеним (властивість ізотропії). Це означає, що середні квадрати проекцій швидкостей за всіма трьома осями координат абсолютно однакові:

```
⟨v_x²⟩ = ⟨v_y²⟩ = ⟨v_z²⟩                      [рівність трьох осях за умовою ізотропії]
```

Оскільки повний квадрат швидкості частинки за теоремою Піфагора дорівнює `v² = v_x² + v_y² + v_z²`, для середніх квадратів маємо:

```
⟨v²⟩ = ⟨v_x²⟩ + ⟨v_y²⟩ + ⟨v_z²⟩
     = 3 · ⟨v_x²⟩                              [підстановка рівності осей]
```

Звідси середня квадратна проекція на будь-яку одну вісь складає рівно третину від середнього квадрата повної швидкості:

```
⟨v_x²⟩ = (1 / 3) · ⟨v²⟩                        [розв'язання відносно ⟨v_x²⟩]
```

Тиск `P` за визначенням є відношенням нормальної сили `F_x` до площі стінки `A_x = L_y · L_z`:

```
P = F_x / (L_y · L_z)                           [визначення тиску як сили на одиницю площі]
  = [ (N · m₀ / L_x) · (1 / 3) · ⟨v²⟩ ] / (L_y · L_z)  [підстановка F_x з урахуванням ізотропії]
  = (1 / 3) · (N / (L_x · L_y · L_z)) · m₀ · ⟨v²⟩     [групування знаменника у повний об'єм]
  = (1 / 3) · (N / V) · m₀ · ⟨v²⟩               [підстановка V = L_x · L_y · L_z]
```

Позначивши числову концентрацію частинок через `n_V = N / V`, отримуємо основне рівняння молекулярно-кінетичної теорії газів:

```
P = (1 / 3) · n_V · m₀ · ⟨v²⟩                   [підстановка концентрації n_V]
```

Виразимо тиск через середню кінетичну енергію поступального руху однієї молекули `⟨E_kin⟩ = (1 / 2) · m₀ · ⟨v²⟩`:

```
P = (2 / 3) · n_V · [ (1 / 2) · m₀ · ⟨v²⟩ ]     [виділення множника 1/2 у дужках]
  = (2 / 3) · n_V · ⟨E_kin⟩                     [підстановка кінетичної енергії ⟨E_kin⟩]
```

Макроскопічний тиск газу прямо пропорційний концентрації частинок та їхній середній кінетичній енергії.

### 5. Теорема про рівнорозподіл енергії за ступенями вільності

У класичній статистичній фізиці класичний канонічний ансамбль Гіббса підкоряється теоремі про рівнорозподіл енергії: на кожен квадратний член у виразі для квадратичної форми енергії частинки припадає середня теплова енергія, що дорівнює `(1 / 2) · k_B · T`.

Для одноатомного ідеального газу кожна молекула має 3 поступальні ступені вільності (рух уздовж осей x, y, z). Повна кінетична енергія є сумою квадратів:

```
E_kin = (1 / 2) · m₀ · v_x² + (1 / 2) · m₀ · v_y² + (1 / 2) · m₀ · v_z²
```

Усереднення за канонічним розподілом Максвелла — Больцмана дає:

```
⟨(1 / 2) · m₀ · v_x²⟩ = (1 / 2) · k_B · T
⟨(1 / 2) · m₀ · v_y²⟩ = (1 / 2) · k_B · T
⟨(1 / 2) · m₀ · v_z²⟩ = (1 / 2) · k_B · T
```

Сумуючи три поступальні ступені вільності, отримуємо середню повну поступальну кінетичну енергію молекули:

```
⟨E_kin⟩ = (3 / 2) · k_B · T
```

Слід підкреслити: навіть якщо молекула є багатоатомною (наприклад, двохатомний азот `N₂` має 3 поступальні та 2 обертальні ступені вільності, разом 5), у створення тиску при ударах об стінку роблять внесок **тільки поступальні ступені вільності**. Обертання та коливання молекули не змінюють нормального імпульсу при гладкому відбиванні центру мас. Тому вираз `P = (2 / 3) · n_V · ⟨E_kin_поступальна⟩` залишається строго точним для абсолютно будь-яких газів — одноатомних, двохатомних чи багатоатомних!

### 6. Завершення виводу рівняння Клапейрона — Менделєєва

Підставивши вираз `⟨E_kin⟩ = (3 / 2) · k_B · T` в основне рівняння МКТ:

```
P = (2 / 3) · (N / V) · [ (3 / 2) · k_B · T ]   [підстановка n_V = N/V та ⟨E_kin⟩]
  = (N / V) · k_B · T                          [скорочення 2/3 та 3/2]
```

Домноживши обидві частини на об'єм `V`, отримуємо мікроскопічну форму рівняння стану ідеального газу:

```
P · V = N · k_B · T                            [перенесення об'єму V у ліву частину]
```

Перейдемо до молярного опису. Позначивши число молей через `n = N / N_A` (де `N_A` — стала Авогадро), маємо `N = n · N_A`. Підставляємо в рівняння:

```
P · V = (n · N_A) · k_B · T                    [підстановка N = n · N_A]
      = n · (N_A · k_B) · T                    [перегрупування констант N_A та k_B]
```

Визначаючи універсальну газову сталу як `R = N_A · k_B`, отримуємо класичну молярну форму рівняння Клапейрона — Менделєєва:

```
P · V = n · R · T                              [підстановка універсальної сталої R = N_A · k_B]
```

### 7. Флуктуації тиску та термодинамічна границя

Виведений тиск `P` є математичним сподіванням (усередненою величиною). Оскільки число частинок скінченне, макроскопічний тиск зазнає дрібних часових флуктуацій.

Згідно зі статистичною фізикою, відносна флуктуація тиску `σ_P / P` у термодинамічній системі з `N` частинок є обернено пропорційною квадратному кореню з числа частинок:

```
σ_P / P = 1 / √N
```

Для макроскопічного об'єму газу, де `N ≈ 10²³` молекул:

```
σ_P / P = 1 / √(10²³) ≈ 3.16 × 10⁻¹²
```

Відносна величина флуктуацій складає порядку трильйонних часток відсотка. Саме тому в термодинамічній границі (`N → ∞`, `V → ∞`, `n_V = const`) флуктуації стають геть непомітними, а макроскопічний тиск `P` сприймається як абсолютно гладка, строго детермінована величина.
