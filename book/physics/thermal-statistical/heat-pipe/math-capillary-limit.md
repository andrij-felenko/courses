# 🧮 Термодинаміка та гідродинаміка капілярного обмеження теплових трубок

Ця вставка містить строгий математичний вивід гідродинамічних балансів тиску, втрат напору в рідкій та паровій фазах за рівняннями Нав'є-Стокса та законом Дарсі, аналіз стисливості пари, а також формулювання граничної теплової потужності `Q_max` за капілярним, звуковим та кипійним лімітами.

### 1. Геометрія контуру та сумарний баланс тисків

Розглянемо теплову трубку загальною довжиною `L`, яка складається з трьох послідовних функціональних ділянок:
- Зона випаровувача довжиною `L_evap`, у якій відбувається підведення теплового потоку `Q` та випаровування рідини.
- Адіабатична транспортна зона довжиною `L_adiab`, у якій пара та рідина рухаються без теплообміну з довкіллям.
- Зона конденсатора довжиною `L_cond`, у якій відбувається відведення тепла й конденсація пари.

Для гідродинамічного розрахунку зручно ввести **ефективну довжину переносу маси** `L_eff`, яка враховує розподілене підведення та відведення маси вздовж випаровувача та конденсатора:

```
L_eff = 0.5 · L_evap + L_adiab + 0.5 · L_cond
```

Теплова потужність `Q` (у ватах), відведена у випаровувачі, зв'язана з масовою витратою носія `m_dot` (у кг/с) та питомою прихованою теплотою пароутворення `h_fg` (у Дж/кг) фундаментальним співвідношенням фазового переходу:

```
Q = m_dot · h_fg     =>     m_dot = Q / h_fg
```

Щоб двофазний цикл працював безперервно й випаровувач не висихав, максимальний лапласівський тиск `ΔP_cap,max`, створюваний менісками рідини у порах фітиля, мусить перевищувати суму всіх гідродинамічних та гідростатичних втрат тиску в замкненому контурі:

```
ΔP_cap,max ≥ ΔP_l + ΔP_v + ΔP_g    [головна умова неперервності замкненого циклу]
```

Максимальний капілярний тиск визначається рівнянням Лапласа-Янга для сферичного меніска у циліндричній порі ефективного радіуса `r_eff`:

```
ΔP_cap,max = (2 · γ · cos θ) / r_eff
```

Де `γ` — поверхневий натяг рідини (Н/м), `θ` — краевий кут змочування матеріалу фітиля рідиною. Для якісно очищеної металевої поверхні та смачувальних рідин (вода на міді, аміак на алюмінії) має місце повне змочування, тобто `θ ≈ 0` і `cos θ ≈ 1`.

### 2. Гідродинаміка течії рідини у пористому фітилі (Закон Дарсі)

Рух сконденсованої рідини з конденсатора назад до випаровувача відбувається у пористому середовищі фітиля. Оскільки розміри пор `r_eff` є дуже малими (від 5 до 100 мкм), швидкість течії рідини є низокою, а число Рейнольдса для рідкої фази не перевищує одиниці (`Re_l = (ρ_l · u_l · r_eff) / μ_l << 1`).

Це означає, що інерційними членами у рівнянні Нав'є-Стокса можна повністю знехтувати, і течія описується **законом Дарсі** для в'язкої фільтрації у пористому середовищі:

```
dp_l / dx = - (μ_l · u_l) / K
```

Тут:
- `dp_l / dx` — локальний градієнт тиску у рідкій фазі вздовж поздовжньої осі `x`,
- `μ_l` — динамічна в'язкість рідкої фази (Па·с),
- `u_l` — середня швидкість фільтрації рідини (м/с),
- `K` — питома проникність пористого фітиля (вимірюється у м²).

Зв'яжемо швидкість фільтрації `u_l` із передаваною тепловою потужністю `Q`. Масова витрата рідини через повну площу поперечного перерізу фітиля `A_w` становить:

```
m_dot = ρ_l · A_w · u_l     =>     u_l = Q / (ρ_l · A_w · h_fg)
```

Підставляючи вираз для швидкості `u_l` у закон Дарсі, отримуємо диференціальне рівняння для градієнта тиску рідини:

```
dp_l / dx = - (μ_l · Q) / (ρ_l · K · A_w · h_fg)
```

Інтегруючи це рівняння вздовж поздовжньої координати від зони конденсації до зони випаровувача з урахуванням розподілу витрати на краях, одержуємо підсумкову формулу втрат тиску у рідкій фазі:

```
ΔP_l = (μ_l · Q · L_eff) / (ρ_l · K · A_w · h_fg)    [гідродинамічний опір рідкої фази]
```

З отриманої формули випливає важливий фізичний висновок: втрати тиску в рідині зростають прямо пропорційно потужності `Q` та довжині `L_eff` і обернено пропорційно проникності `K`, площі перерізу фітиля `A_w` та густині рідини `ρ_l`.

### 3. Гідродинаміка течії пари у центральному каналі (Рівняння Нав'є-Стокса)

Парове ядро являє собою відкритий центральний канал кругового або прямокутного перерізу площею `A_v` та гідравлічним радіусом `r_v`. На відміну від рідини, пара має значно нижчу густину `ρ_v` та високу швидкість течії `u_v`.

Для опису течії пари застосовують одновимірні рівняння Нав'є-Стокса для стисливого в'язкого газу. За помірних теплових потоків, коли швидкість пари значно менша за швидкість звуку (число Маха `Mach = u_v / a < 0.2`), паровий потік можна вважати нестисливим і ламінарним.

Локальний градієнт тиску пари визначається тертям об шорстку поверхню фітиля та зміною імпульсу за рахунок вдування пари у випаровувачі:

```
dp_v / dx = - (f_v · ρ_v · u_v²) / (4 · r_v)
```

Де `f_v` — коефіцієнт тертя Фаннінга. Для ламінарного потоку у круглому каналі `f_v = 16 / Re_v`, де число Рейнольдса пари дорівнює:

```
Re_v = (2 · r_v · ρ_v · u_v) / μ_v = (2 · r_v · Q) / (A_v · μ_v · h_fg)
```

Підставляючи `f_v` та швидкість пари `u_v = Q / (ρ_v · A_v · h_fg)` та інтегруючи вздовж ефективної довжини `L_eff`, отримуємо втрати тиску у паровій фазі:

```
ΔP_v = (C_f · μ_v · Q · L_eff) / (2 · ρ_v · A_v · r_v² · h_fg)
```

Для круглого перерізу парового ядра константа `C_f = 16`. У більшості правильно спроектованих трубок радіус парового ядра `r_v` роблять значно більшим за радіус пор `r_eff`, тому втрати тиску у парі становлять не більше 2–8% від втрат у рідкій фазі (`ΔP_v << ΔP_l`). Проте при сплющуванні трубок у вузькі пластини `r_v` різко зменшується, і `ΔP_v` стає домінуючим чинником.

### 4. Гравітаційний протитиск

Якщо теплова трубка працює у похилому положенні під кутом `φ` до горизонту (випаровувач розміщено вище за конденсатор, тобто підйом рідини відбувається проти вектора прискорення вільного падіння `g`), стовп рідини створює гідростатистичний протитиск:

```
ΔP_g = ρ_l · g · L · sin φ
```

Тут `L` — повна довжина трубки від нижньої до верхньої точки. Якщо випаровувач розміщено внизу (`φ < 0`), гравітація допомагає капілярному помпу, і значок перед `ΔP_g` змінюється на протилежний.

### 5. Вивід максимальної теплової потужності та числа Мерита

Підставляємо вирази для `ΔP_l`, `ΔP_v` та `ΔP_g` у підсумкове рівняння капілярного балансу. Зважаючи на те, що `ΔP_v << ΔP_l`, отримуємо:

```
(2 · γ · cos θ) / r_eff  ≥  [ (μ_l · Q · L_eff) / (ρ_l · K · A_w · h_fg) ] + ρ_l · g · L · sin φ
```

Виражаємо граничну теплову потужність `Q_max,cap` з цієї нерівності:

```
Q_max,cap = [ (2 · γ · cos θ / r_eff) - ρ_l · g · L · sin φ ] · [ (ρ_l · γ · h_fg) / μ_l ] · [ (K · A_w) / (L_eff · r_eff) ]
```

Аналізуючи отриману формулу, виділимо співвідношення, яке залежить виключно від фізичних властивостей робочої рідини. Це співвідношення називають **числом Мерита** (*Merit number*, або *Liquid Transport Factor* `N_M`):

```
N_M = (ρ_l · γ · h_fg) / μ_l        [число Мерита, Вт/м²]
```

Фізичний зміст числа Мерита полягає у тому, що воно вимірює здатність рідини переносити теплову енергію під дією поверхневого натягу за мінімального в'язкісного опору. Чим вище значення `N_M`, тим більшу теплову потужність здатна транспортувати дана рідина крізь один і той самий фітиль.

### 6. Математична модель звукового ліміту (Sonic limit)

За низьких робрчих температур та тисків густина пари `ρ_v` є вкрай малою. Щоб перенести задану масову витрату `m_dot`, пара змушена розганятися до дуже високих швидкостей.

Максимально можлива швидкість течії газу в каналі постійного перерізу без сопла Лаваля обмежена місцевою швидкістю звуку `a = sqrt(γ_g · R_gas · T_sat)` (де `γ_g` — показник адіабати пари, `R_gas` — газова сталість). Гіперзвуковий режим заблокований ефектом замикання потоку (Choking flow).

Гранична теплова потужність за звуковим лімітом виражається формулою:

```
Q_max,sonic = A_v · ρ_v · h_fg · sqrt( (γ_g · R_gas · T_sat) / (2 · (γ_g + 1)) )
```

Якщо необхідна потужність перевищує `Q_max,sonic`, тиск у конденсаторі падає, але маса пари не може розігнатися швидше за швидкість звуку, і температура випаровувача починає неконтрольовано зростати.

### 7. Математичний аналіз кипійного ліміту (Boiling limit)

Кипійний ліміт настає тоді, коли густина теплового потоку в зоні випаровувача є настільки високою, що перепад температур на товщі фітиля перевищує критичну величину перегріву, необхідну для зародження парових бульбашок.

Згідно з рівнянням Клапейрона-Клаузіуса, критичний перепад температур `ΔT_crit`, який викликає зародження парової бульбашки радіуса `r_b` на стінці випаровувача, дорівнює:

```
ΔT_crit = (2 · γ · T_sat) / (ρ_v · h_fg · r_b)
```

З іншого боку, радіальний тепловий потік `Q` через циліндричний шар фітиля товщиною `t_wick = r_inner - r_vapor` створює перепад температур за законом теплопровідності Фурьє:

```
ΔT = [ Q · ln(r_inner / r_vapor) ] / (2 · π · L_evap · λ_eff,wick)
```

Прирівнюючи `ΔT` до критичного значення `ΔT_crit`, отримуємо граничну потужність за кипійним лімітом:

```
Q_max,boil = (4 · π · L_evap · λ_eff,wick · γ · T_sat) / [ ρ_v · h_fg · r_b · ln(r_inner / r_vapor) ]
```

Ефективна теплопровідність просоченого фітиля `λ_eff,wick` визначається за формулою Максвелла для двокомпонентних пористих систем:

```
λ_eff,wick = λ_m · [ (λ_m + λ_l) - (1 - ε)·(λ_m - λ_l) ] / [ (λ_m + λ_l) + (1 - ε)·(λ_m - λ_l) ]
```

Де `λ_m` — теплопровідність металу (мідь: 400 Вт/(м·К)), `λ_l` — теплопровідність рідини (вода: 0.68 Вт/(м·К)), `ε` — порозність фітиля.

Отриманий математичний апарат дає змогу повністю розраховувати та оптимізувати геометричні й термодинамічні параметри теплових трубок на етапі інженерного проектування.
