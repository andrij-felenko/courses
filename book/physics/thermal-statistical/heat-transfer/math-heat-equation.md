# 🧮 Виведення рівняння теплопровідності

Рівняння теплопровідності (дифузії тепла) є фундаментальним диференціальним рівнянням у частинних похідних параболічного типу, що описує просторово-часовий розподіл температури в суцільному середовищі. Воно виводиться шляхом поєднання фундаментального фізичного закону збереження енергії з емпіричним феноменологічним законом Фур'є для векторного теплового потоку. Нижче наведено детальний крок-за-кроком вивід одновимірного та тривимірного рівнянь, аналіз у різних системах координат, виведення аналітичного розв'язку методом відокремлення змінних та фізичний зміст коефіцієнта температуропровідності.

### 1. Елементарний контрольний об'єм та закон збереження енергії

Розглянемо нескінченно малий прямокутний паралелепіпед усередині нерухомого суцільного тіла. Сторони паралелепіпеда паралельні декартовим осям координат `x`, `y`, `z` і мають довжини `dx`, `dy`, `dz`. Об'єм цього елементарного елемента становить `dV = dx · dy · dz`.

![Елементарний контрольний об'єм dx dy dz з потоками тепла q_in та q_out](/book/physics/thermal-statistical/heat-transfer/img/fourier-law.svg)
*Баланс енергії в елементарному об'ємі: тепловий потік входить через ліву грань і виходить через праву. Різниця витрачається на накопичення внутрішньої енергії.*

За час `dt` усередині цього контрольного об'єму відбувається зміна внутрішньої теплової енергії. Відповідно до першого початку термодинаміки (закону збереження енергії), баланс потужності для нерухомого середовища за відсутності макроскопічної роботи виражається принципом:

```
Швидкість накопичення внутрішньої енергії в об'ємі
= (Чистий результуючий приплив тепла через поверхні) + (Потужність внутрішніх джерел тепла)
```

Введіть фізичні параметри середовища:
- `ρ` [кг/м³] — локальна густина речовини;
- `c_p` [Дж/(кг·К)] — питома масова теплоємність за постійного тиску;
- `q_gen(x,y,z,t)` [Вт/м³] — об'ємна потужність внутрішніх джерел тепла (наприклад, джоулевий нагрів електричним струмом, радіоактивний розпад або ендотермічна/екзотермічна хімічна реакція);
- `q_x(x,y,z,t)` [Вт/м²] — проекція вектора густини теплового потоку на вісь `x`.

Зміна внутрішньої енергії елементарного об'єму `dV` при зміні його температури на `dT` виражається через об'ємну теплоємність:

```
dU = ρ · c_p · (∂T / ∂t) · dt · dV
dU = ρ · c_p · (∂T / ∂t) · dt · dx · dy · dz
```

Відповідно, швидкість зміни внутрішньої енергії в одиницю часу становить:

```
dQ_acc / dt = ρ · c_p · (∂T / ∂t) · dx · dy · dz
```

### 2. Аналіз потоків тепла через межі (одновимірний випадок)

Розглянемо спочатку одновимірний потік тепла вздовж осі `x`. Площа граней паралелепіпеда, перпендикулярних до осі `x`, дорівнює `dA_x = dy · dz`.

Теплова потужність, що входить у контрольний об'єм через ліву грань у точці `x`, становить:

```
Q_in = q_x(x) · dy · dz
```

Теплова потужність, що виходить із контрольного об'єму через протилежну праву грань у точці `x + dx`, розкладається у ряд Тейлора з утриманням членів першого порядку малості:

```
q_x(x + dx) = q_x(x) + (∂q_x / ∂x) · dx
Q_out = [ q_x(x) + (∂q_x / ∂x) · dx ] · dy · dz
```

Чиста результуюча теплова потужність `Q_net`, яка затримується в об'ємі через нерівність вхідного та вихідного потоків, дорівнює різниці `Q_in - Q_out`:

```
Q_net = Q_in - Q_out
Q_net = q_x(x)·dy·dz - [ q_x(x) + (∂q_x / ∂x)·dx ]·dy·dz    [розкриття дужок]
Q_net = - (∂q_x / ∂x) · dx · dy · dz                      [приведення подібних доданків]
```

Знак мінус виникає природно: якщо потік тепла зростає за координатою (`∂q_x / ∂x > 0`), то з об'єму виходить більше тепла, ніж входить, і внутрішня енергія елемента зменшується.

Додамо потужність, що виділяється внутрішніми джерелами тепла `Q_gen`:

```
Q_gen = q_gen · dx · dy · dz
```

Запишемо повне рівняння теплового балансу для елементарного об'єму:

```
dQ_acc / dt = Q_net + Q_gen
ρ·c_p·(∂T/∂t)·dx·dy·dz = - (∂q_x / ∂x)·dx·dy·dz + q_gen·dx·dy·dz
ρ·c_p·(∂T / ∂t) = - (∂q_x / ∂x) + q_gen                   [скорочення на об'єм dV = dx·dy·dz]
```

### 3. Підстановка закону Фур'є та утворення диффузійного члена

Закон Фур'є пов'язує густину теплового потоку `q_x` з місцевим градієнтом температури через коефіцієнт теплопровідності матеріалу `k` [Вт/(м·К)]:

```
q_x = - k · (∂T / ∂x)
```

Підставимо цей вираз у праву частину отриманого диференціального рівняння балансу:

```
ρ·c_p·(∂T / ∂t) = - ∂/∂x [ - k · (∂T / ∂x) ] + q_gen
ρ·c_p·(∂T / ∂t) = ∂/∂x [ k · (∂T / ∂x) ] + q_gen           [мінус на мінус дає плюс]
```

Якщо матеріальне середовище є однорідним і коефіцієнт теплопровідності `k` не залежить від просторової координати `x`, його можна винести за знак похідної:

```
ρ·c_p·(∂T / ∂t) = k · (∂²T / ∂x²) + q_gen
∂T / ∂t = (k / (ρ·c_p)) · (∂²T / ∂x²) + q_gen / (ρ·c_p)   [ділення обох частин на ρ·c_p]
```

Введемо фундаментальну фізичну характеристику середовища — **коефіцієнт температуропровідності** (термічну дифузійність) `α` [м²/с]:

```
α = k / (ρ · c_p)
```

З урахуванням `α` одновимірне диференціальне рівняння теплопровідності набуває вигляду:

```
∂T / ∂t = α · (∂²T / ∂x²) + q_gen / (ρ · c_p)
```

У разі відсутності внутрішніх джерел тепла (`q_gen = 0`) отримуємо однорідне одновимірне рівняння дифузії тепла:

```
∂T / ∂t = α · (∂²T / ∂x²)
```

### 4. Узагальнення на тривимірний випадок (3D) у різних системах координат

У тривимірному просторі потік тепла описується вектором густини теплового потоку `q = (q_x, q_y, q_z)`. За законами векторного аналізу, чистий відплив тепла з одиниці об'єму дорівнює дивергенції вектора потоку `∇ · q`.

Загальне рівняння збереження енергії у векторній формі записується так:

```
ρ · c_p · (∂T / ∂t) = - ∇ · q + q_gen
```

Підставивши тривимірний закон Фур'є `q = - k · ∇T` (де `∇T` — вектор градієнта температури), отримуємо:

```
ρ · c_p · (∂T / ∂t) = ∇ · (k · ∇T) + q_gen
```

Для ізотропного та однорідного середовища (`k = const`) оператор `∇ · ∇` перетворюється на оператор Лапласа `∇²` (або `Δ`):

```
∂T / ∂t = α · ∇²T + q_gen / (ρ · c_p)
```

Форма оператора Лапласа `∇²T` залежить від геометрії системи координат:

#### Декартові координати (x, y, z):
```
∇²T = (∂²T / ∂x²) + (∂²T / ∂y²) + (∂²T / ∂z²)
```

#### Циліндричні координати (r, θ, z) — для труб, кабелів та циліндричних деталей:
```
∇²T = (1/r) · ∂/∂r [ r · (∂T / ∂r) ] + (1/r²) · (∂²T / ∂θ²) + (∂²T / ∂z²)
```

#### Сферичні координати (r, θ, φ) — для кульових резервуарів та геотермальних сфер:
```
∇²T = (1/r²) · ∂/∂r [ r² · (∂T / ∂r) ] + (1 / (r² sin θ)) · ∂/∂θ [ sin θ · (∂T / ∂θ) ] + (1 / (r² sin² θ)) · (∂²T / ∂φ²)
```

### 5. Аналітичний розв'язок методом відокремлення змінних (метод Фур'є)

Розглянемо класичну задачу про остигання однорідного тонкого стрижня довжиною `L` без внутрішніх джерел тепла (`q_gen = 0`). Межі стрижня утримуються при нульовій температурі, а початковий розподіл температури задано функцією `f(x)`:

```
∂T / ∂t = α · (∂²T / ∂x²)
T(0, t) = 0,    T(L, t) = 0          [граничні умови Діріхле]
T(x, 0) = f(x)                       [початкова умова]
```

Шукаємо розв'язок у вигляді добутку двох функцій — часової `T_t(t)` та просторової `X(x)`:

```
T(x, t) = X(x) · T_t(t)
```

Підставимо цей добуток у рівняння теплопровідності:

```
X(x) · (dT_t / dt) = α · (d²X / dx²) · T_t(t)
(1 / (α · T_t)) · (dT_t / dt) = (1 / X) · (d²X / dx²)    [розділення змінних]
```

Ліва частина залежить лише від `t`, а права — лише від `x`. Вони можуть бути рівними для всіх `x` та `t` лише у випадку, якщо обидві дорівнюють одній від'ємній константі `- λ²`:

```
(1 / X) · (d²X / dx²) = - λ²    ⇒    d²X / dx² + λ² · X = 0
(1 / (α · T_t)) · (dT_t / dt) = - λ²    ⇒    dT_t / dt + α · λ² · T_t = 0
```

Розв'язок просторового рівняння зі збереженням граничних умов `X(0) = 0` та `X(L) = 0` приводить до задачі Штурма–Ліувілля:

```
X(x) = C · sin(λ · x)
sin(λ · L) = 0    ⇒    λ_n = (n · π) / L,    n = 1, 2, 3...
```

Розв'язок часового рівняння для кожного власного значення `λ_n` дає експоненціальний зпад:

```
T_t,n(t) = exp( - α · λ_n² · t ) = exp( - α · (n·π/L)² · t )
```

За принципом суперпозиції, загальний розв'язок є нескінченною сумою гармонік:

```
T(x, t) = ∑ [ b_n · sin((n·π·x) / L) · exp( - α · (n·π/L)² · t ) ]
```

Коефіцієнти `b_n` знаходяться з початкової умови `T(x,0) = f(x)` через інтеграл Фур'є:

```
b_n = (2 / L) · ∫ [ f(x) · sin((n·π·x) / L) ] dx
```

Вираз `exp( - α · (n·π/L)² · t )` показує, що вищі гармоніки (великі `n`, тобто дрібномасштабні просторові збурення температури) згасають у часі **експоненціально швидше**, ніж низькі. Теплопровідність працює як природний фільтр високих просторових частот, згладжуючи будь-які гострі температурні піки.

### 6. Класифікація граничних умов

Щоб виділити єдиний фізичний розв'язок диференціального рівняння для конкретного тіла об'ємом `V` з поверхнею `S`, необхідно задати початкові та граничні умови.

#### 1. Гранична умова першого роду (Діріхле)
На межі задається точна температура як функція часу та координат:

```
T(x_S, y_S, z_S, t) = T_surface(t)
```
*Застосування:* поверхня щільно притиснута до масивного мідного термостата з великою теплоємністю або перебуває у стані фазового переходу (кипіння води при 100 °C, танення льоду при 0 °C).

#### 2. Гранична умова другого роду (Неймана)
На межі задається густина теплового потоку `q_surface`:

```
- k · (∂T / ∂n)_S = q_surface(t)
```
де `n` — зовнішня нормаль до поверхні `S`.
*Застосування:* рівномірний нагрів поверхні випромінюванням лазера чи електронагрівачем. Частковий випадок `q_surface = 0` означає **ідеальну теплоізоляцію** (`∂T/∂n = 0`).

#### 3. Гранична умова третього роду (Робіна / Конвективна)
На межі задається конвективний теплообмін з навколишнім середовищем температурою `T_ambient` і коефіцієнтом віддачі `h`:

```
- k · (∂T / ∂n)_S = h · ( T(x_S,t) - T_ambient )
```
*Застосування:* поверхня радіαтора охолоджується рухомим потоком повітря чи рідини.

#### 4. Гранична умова четвертого роду (Спряжений теплообмін)
Задається умова ідеального теплового контакту на межі розподілу двох різних твердих тіл A та B:

```
T_A(x_S, t) = T_B(x_S, t)                           [рівність температур]
- k_A · (∂T_A / ∂n)_S = - k_B · (∂T_B / ∂n)_S        [рівність теплових потоків]
```
Якщо контакт неідеальний через шорсткість, додається контактний тепловий опір `R_contact`:

```
- k_A · (∂T_A / ∂n)_S = ( T_A(x_S,t) - T_B(x_S,t) ) / R_contact
```
