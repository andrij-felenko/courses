# 🧮 Термодинамічний вивід та математичний апарат правила фаз

Ця математична вставка містить строгий аналітичний вивід правила фаз Гіббса на основі термодинамічних потенціалів, аналіз лінійної незалежності рівнянь рівноваги через матрицю Якобі, виведення рівняння Гіббса — Дюгема, а також розв'язані покрокові приклади для складних реакційноздатних, електрохімічних та багатокомпонентних систем.

### Теоретичний фундамент: термодинамічні потенціали та перетворення Лежандра

Для фундаментального опису термодинамічного стану фази `α` виходять з першого та другого начал термодинаміки для закритої системи. Повний дифференциал внутрішньої енергії `U^α` як функції екстенсивних змінних — ентропії `S^α`, об'єму `V^α` та чисел молей компонентів `N_1^α, N_2^α, ..., N_C^α` — виражається співвідношенням:

```
dU^α = T^α · dS^α - P^α · dV^α + ∑_{i=1}^C μ_i^α · dN_i^α
```

де `T^α = (∂U^α / ∂S^α)_{V, N}` — абсолютна температура, `P^α = -(∂U^α / ∂V^α)_{S, N}` — тиск, а `μ_i^α = (∂U^α / ∂N_i^α)_{S, V, N_{j≠i}}` — хімічний потенціал `i`-го компонента у фазі `α`.

Оскільки більшість фізико-хімічних та технологічних процесів відбуваються за умов вимірюваних зовні температури `T` та тиску `P`, зручно перейти від внутрішньої енергії `U` до ізобарно-ізотермічного потенціалу (енергії Гіббса) `G` за допомогою послідовного перетворення Лежандра:

```
G^α = U^α - T^α · S^α + P^α · V^α
```

Беручи повний дифференциал енергії Гіббса `dG^α` та підставляючи значення `dU^α`, отримуємо:

```
dG^α = dU^α - T^α · dS^α - S^α · dT^α + P^α · dV^α + V^α · dP^α
```

```
dG^α = (T^α · dS^α - P^α · dV^α + ∑ μ_i^α · dN_i^α) - T^α · dS^α - S^α · dT^α + P^α · dV^α + V^α · dP^α
     = -S^α · dT^α + V^α · dP^α + ∑_{i=1}^C μ_i^α · dN_i^α
```

Таким чином, для хімічного потенціалу випливає рівноцінне визначення через енергію Гіббса:

```
μ_i^α = ( ∂G^α / ∂N_i^α )_{T, P, N_{j ≠ i}^α}
```

### Теорема Ейлера та виведення рівняння Гіббса — Дюгема

Енергія Гіббса є **екстенсивною величиною**: при збільшенні кількості всіх компонентів фази в `k` разів при незмінних `T` та `P` значення енергії Гіббса `G^α` зростає рівно в `k` разів. Математично це означає, що `G^α(T, P, k·N_1^α, ..., k·N_C^α) = k · G^α(T, P, N_1^α, ..., N_C^α)`, тобто `G^α` є однорідною функцією першого степеня від мольних кількостей `N_i^α`.

За математичною теоремою Ейлера про однорідні функції, будь-яка однорідна функція першого степеня дорівнює сумі добутків своїх часткових похідних на відповідні незалежні змінні:

```
G^α = ∑_{i=1}^C ( ∂G^α / ∂N_i^α )_{T, P, N_{j≠i}} · N_i^α
    = ∑_{i=1}^C μ_i^α · N_i^α
```

Знайдемо повний дифференциал цього виразу за формулою дифференціювання добутку:

```
dG^α = ∑_{i=1}^C μ_i^α · dN_i^α + ∑_{i=1}^C N_i^α · dμ_i^α
```

Зіставимо два отримані вирази для `dG^α`:
1. `dG^α = -S^α · dT^α + V^α · dP^α + ∑ μ_i^α · dN_i^α`
2. `dG^α = ∑ μ_i^α · dN_i^α + ∑ N_i^α · dμ_i^α`

Віднімаючи перший вираз від другого, отримуємо фундаментальне **рівняння Гіббса — Дюгема** для фази `α`:

```
S^α · dT^α - V^α · dP^α + ∑_{i=1}^C N_i^α · dμ_i^α = 0
```

Поділивши це рівняння на загальну кількість молей у фазі `N^α = ∑ N_i^α`, виразимо його через мольну ентропію `S_m^α = S^α / N^α`, мольний об'єм `V_m^α = V^α / N^α` та мольні частки компонентів `x_i^α = N_i^α / N^α`:

```
S_m^α · dT^α - V_m^α · dP^α + ∑_{i=1}^C x_i^α · dμ_i^α = 0
```

Рівняння Гіббса — Дюгема показує, що інтенсивні змінні всередині однієї фази (`T`, `P`, `μ_1`, ..., `μ_C`) не є повністю незалежними: зміна температури чи тиску неминуче спричиняє узгоджену зміну хімічних потенціалів компонентів.

### Термодинамічний вивід правила фаз через систему рівнянь Гіббса — Дюгема

Розглянемо гетерогенну систему, що складається з `C` незалежних компонентів та `P` рівноважних фаз.

У стані термічної, механічної та фазової хімічної рівноваги:
1. `dT¹ = dT² = ... = dT^P = dT` (термічна рівновага);
2. `dP¹ = dP² = ... = dP^P = dP` (механічна рівновага);
3. `dμ_i¹ = dμ_i² = ... = dμ_i^P = dμ_i` (для кожного з `C` компонентів).

Записуємо рівняння Гіббса — Дюгема для кожної з `P` фаз:

```
S_m¹ · dT - V_m¹ · dP + x_1¹ · dμ_1 + x_2¹ · dμ_2 + ... + x_C¹ · dμ_C = 0
S_m² · dT - V_m² · dP + x_1² · dμ_1 + x_2² · dμ_2 + ... + x_C² · dμ_C = 0
...
S_m^P · dT - V_m^P · dP + x_1^P · dμ_1 + x_2^P · dμ_2 + ... + x_C^P · dμ_C = 0
```

У цій системі диференціальних рівнянь маємо наступний набір інтенсивних диференціальних змінних:
- `dT` (1 змінна);
- `dP` (1 змінна);
- `dμ_1, dμ_2, ..., dμ_C` (`C` змінних).

Загальна кількість диференціальних інтенсивних змінних становить `(C + 2)`.

Система містить рівно **`P`** диференціальних рівнянь (по одному рівнянню на кожну фазу).

Кількість ступеней вільності `F` — це кількість змінних диференціалів, які можна задавати повністю довільно й незалежно, не порушуючи сумісності системи рівнянь:

```
F = (Загальна кількість інтенсивних диференціалів) - (Кількість незалежних рівнянь)
  = (C + 2) - P
  = C - P + 2
```

Цей алгебраїчний вивід є винятково строгим і не вимагає попереднього підрахунку мольних часток у кожній окремій фазі.

### Аналіз лінійної незалежності та матриці Якобі

Щоб система з `P` рівнянь Гіббса — Дюгема була сумісною і мала розв'язок відносно `F` вільних змінних, матриця коефіцієнтів (матриця Якобі `J`) повинна мати ранг `rank(J) = P`.

Матриця Якобі `J` розмірністю `P × (C + 2)` має вигляд:

```
J = | S_m¹   -V_m¹   x_1¹   x_2¹   ...   x_C¹ |
    | S_m²   -V_m²   x_1²   x_2²   ...   x_C² |
    |  ...     ...    ...    ...   ...    ... |
    | S_m^P  -V_m^P  x_1^P  x_2^P  ...   x_C^P|
```

Оскільки ранг матриці не може перевищувати кількості її рядків (`P`) або стовпчиків (`C + 2`), фундаментальне обмеження на кількість фаз становить:

```
P ≤ C + 2
```

Це означає, що число ступеней вільності не може бути від'ємним (`F = C + 2 - P ≥ 0`). Якщо користувач або інженер спробує зафіксувати кількість фаз `P > C + 2`, то ранг матриці Якобі виявиться меншим за число фаз, рівняння стануть лінійно залежними й суперечливими, що відповідає фізично неможливому стану.

### Узагальнене правило фаз для реакційноздатних та іонних систем

Якщо у системі присутні `N` різних хімічних речовин (молекул або іонів), між якими відбуваються `R` незалежних хімічних реакцій виду:

```
∑_{j=1}^N ν_{r, j} · A_j = 0    (де ν_{r, j} — стехіометричні коефіцієнти r-ї реакції)
```

то у стані хімічної рівноваги сума добутків стехіометричних коефіцієнтів на хімічні потенціали дорівнює нулю для кожної з `R` реакцій:

```
∑_{j=1}^N ν_{r, j} · μ_j = 0    (для кожної з R реакцій)
```

Це накладає **`R`** додаткових незалежних рівнянь зв'язку на хімічні потенціали.

Крім того, якщо на систему накладено `r` додаткових співвідношень (наприклад, початкова завантажувальна стехіометрія чи умова електронейтральності іонного розчину `∑ z_j · x_j = 0`), додається ще **`r`** рівнянь.

Тоді кількість незалежних хімічних компонентів `C` становить:

```
C = N - R - r
```

Підставляючи це значення у класичну формулу Гіббса, отримуємо узагальнене правило фаз:

```
F = (N - R - r) - P + 2
  = N - R - r - P + 2
```

### Покрокові розв'язані приклади з детальною алгеброю

#### Приклад 1. Потрійна точка чистої води (H₂O)

Обчислити число ступеней вільності для чистої води, у якій перебувають у рівновазі лід, рідка вода та водяна пара.

```
Крок 1: Підрахунок хімічних речовин N
N = 1 (речовина H₂O)

Крок 2: Хімічні реакції R та додаткові обмеження r
R = 0 (реакції відсутні)
r = 0 (обмеження відсутні)

Крок 3: Кількість незалежних компонентів C
C = N - R - r
  = 1 - 0 - 0 = 1

Крок 4: Кількість співіснуючих фаз P
P = 3 (твердий лід, рідка вода, газова пара)

Крок 5: Обчислення ступеней вільності F
F = C - P + 2
  = 1 - 3 + 2
  = 0 [нонваріантна система]
```

**Висновок:** Для чистої води потрійна точка є інваріантною (`F = 0`). Система не має вільних параметрів: температура `T = 273.16 K` та тиск `P = 611.65 Pa` зафіксовані природою.

#### Приклад 2. Термічний розклад карбонату кальцію (CaCO₃)

Обчислити число ступеней вільності для системи у закритому об'ємі, де протікає реакція:
`CaCO₃(тв) ⇄ CaO(тв) + CO₂(газ)`

```
Крок 1: Підрахунок хімічних речовин N
N = 3 (CaCO₃, CaO, CO₂)

Крок 2: Хімічні реакції R та обмеження r
R = 1 (одна реакція дисоціації)
r = 0 (немає спеціальних додаткових обмежень)

Крок 3: Незалежні компоненти C
C = N - R - r
  = 3 - 1 - 0 = 2

Крок 4: Кількість співіснуючих фаз P
P = 3 (фаза 1: кристали CaCO₃; фаза 2: кристали CaO; фаза 3: газ CO₂)

Крок 5: Обчислення F
F = C - P + 2
  = 2 - 3 + 2
  = 1 [моноваріантна система]
```

**Висновок:** Система є моноваріантною (`F = 1`). При виборі будь-якої температури `T` рівноважний тиск `P_{CO₂}` визначається однозначно.

#### Приклад 3. Водний розчин солі NaCl при постійному тиску (P = const)

Обчислити число умовних ступеней вільності `F'` для водного розчину солі `NaCl`, що перебуває в рівновазі з кристалами `NaCl` при `P = 1` атм.

```
Крок 1: Підрахунок речовин та іонів N
N = 5 (H₂O, Na⁺, Cl⁻, H⁺, OH⁻)

Крок 2: Хімічні реакції дисоціації R
R = 2 (H₂O ⇄ H⁺ + OH⁻  та  NaCl ⇄ Na⁺ + Cl⁻)

Крок 3: Умова електронейтральності розчину r
r = 1 (умова: [Na⁺] + [H⁺] = [Cl⁻] + [OH⁻])

Крок 4: Незалежні компоненти C
C = N - R - r
  = 5 - 2 - 1 = 2 (компоненти H₂O та NaCl)

Крок 5: Фазовий склад P
P = 2 (фаза 1: рідкий водний розчин; фаза 2: тверді кристали NaCl)

Крок 6: Обчислення ізобарних ступеней вільності F' (при P = const)
F' = C - P + 1
   = 2 - 2 + 1
   = 1 [моноваріантний стан]
```

**Висновок:** Система є моноваріантною (`F' = 1`). При заданому тиску зміна температури `T` однозначно задає насичену концентрацію солі `NaCl` у розчині.

#### Приклад 4. Гальванічний елемент Даніеля — Якобі (Електрохімічна рівновага)

Розглянемо гальванічний елемент, що складається з мідного та цинкового електродів, занурених у розчини своїх сульфатів `CuSO₄` та `ZnSO₄`:
`Zn(тв) + Cu²⁺(водн) ⇄ Zn²⁺(водн) + Cu(тв)`

```
Крок 1: Підрахунок речовин N
N = 6 (Zn, Cu, Zn²⁺, Cu²⁺, SO₄²⁻, H₂O)

Крок 2: Хімічні та окисно-відновні реакції R
R = 1 (окисно-відновна реакція перенесення електронів)

Крок 3: Обмеження електронейтральності r
r = 1 (сумарна нейтральність іонних розчинів)

Крок 4: Незалежні компоненти C
C = 6 - 1 - 1 = 4

Крок 5: Фазовий склад P
P = 4 (фаза 1: твердий Zn; фаза 2: тверда Cu; фаза 3: водний розчин ZnSO4; фаза 4: водний розчин CuSO4)

Крок 6: Ступені вільності F
F = C - P + 2
  = 4 - 4 + 2
  = 2 [біваріантний стан]
```

**Висновок:** Електрохімічний елемент має два ступені вільності (`F = 2`). Інженер може незалежно варіювати температуру `T` та співвідношення концентрацій іонів `Zn²⁺` і `Cu²⁺`, після чого електрошішійна сила (ЕРС) елемента визначається однозначно рівнянням Нернста.
