# 🧮 Виведення рівняння ребра та ефективності для ізольованого вершка

Математичний аналіз теплообміну в розширених поверхонь є класичним прикладом застосування методів математичної фізики до задач конвективно-кондуктивного переносу тепла. У цій вставці наведено детальний крок за кроком вивід одновимірного диференціального рівняння теплопровідності ребра постійного поперечного перерізу, строге знаходження констант інтегрування для адіабатичного вершка, виведення рівнянь для трикутного ребра й параболічного профілю Шмідта, а також точне математичне доведення формули ефективності ребра та аналіз її граничних асимптот.

### 1. Тепловий баланс диференціального елемента

Розглянемо суцільне прямокутне ребро постійного поперечного перерізу `A_c` та периметра `P`. Спрямуємо координату `x` уздовж центральної осі ребра від його основи (`x = 0`) до вершка (`x = L`). Вважаємо, що матеріал ребра є однорідним та ізотропним із постійною теплопровідністю `k` (Вт/(м·К)), а навколишнє середовище має постійну температуру `T_∞` і характеризується постійним коефіцієнтом тепловіддачі `h` (Вт/(м²·К)).

Згідно з критерієм Біо, якщо товщина ребра мала порівняно з його довжиною (`Bi_t = h·t/(2k) < 0.1`), то поперечним градієнтом температури можна знехтувати, вважаючи розподіл температури суворо одновимірним: `T = T(x)`.

Виділимо всередині ребра малий елемент завдовжки `dx` між перерізами `x` та `x + dx`. Тепловий потік, що входить у ліву грань елемента за рахунок теплопровідності металу, описується фундаментальним законом Фур'є:

```
Q(x) = -k · A_c · (dT / dx)
```

Тепловий потік, який виходить з правої грані `x + dx`, розкладаємо в ряд Тейлора поблизу точки `x`, обмежуючись першими двома членами розкладу завдяки малості `dx`:

```
Q(x + dx) = Q(x) + (dQ / dx) · dx
= -k · A_c · (dT / dx) + d/dx [ -k · A_c · (dT / dx) ] · dx
= -k · A_c · (dT / dx) - k · A_c · (d²T / dx²) · dx
```

Різниця між вхідним поздовжнім потоком `Q(x)` та вихідним потоком `Q(x + dx)` визначає кількість тепла, яка втрачається через бічну поверхню елемента `d A_s = P · dx` у навколишнє повітря за законом конвективного охолодження Ньютона-Ріхмана:

```
dQ_conv = h · d A_s · (T(x) - T_∞)
= h · P · (T(x) - T_∞) · dx
```

У стаціонарному тепловому режимі температура елемента не змінюється в часі, тому акумуляція тепла всередині контрольного об'єму дорівнює нулю. Загальний закон збереження енергії для виділеного елемента набуває вигляду рівності припливу тепла сумі його відпливів:

```
Q(x) - Q(x + dx) - dQ_conv = 0      [закон збереження енергії у стаціонарному стані]
```

Підставляючи отримані математичні вирази для поздовжнього виходу `Q(x + dx)` та бічної конвекції `dQ_conv`, отримуємо розгорнуте рівняння теплового балансу:

```
-k · A_c · (dT / dx) - [ -k · A_c · (dT / dx) - k · A_c · (d²T / dx²) · dx ] - h · P · (T - T_∞) · dx = 0
= k · A_c · (d²T / dx²) · dx - h · P · (T - T_∞) · dx = 0     [скоротили однакові члени]
```

Поділивши весь алгебраїчний вираз на добуток `k · A_c · dx` та ввівши надлишкову температуру `θ(x) = T(x) - T_∞`, яка вимірює температурний напір ребра відносно довкілля, отримуємо базове диференціальне рівняння переносу тепла у ребрі:

```
d²θ / dx² - (h · P / (k · A_c)) · θ = 0      [диференціальне рівняння балансу]
```

Для спрощення подальшого математичного запису вводиться фундаментальний комбінований параметр згасання ребра `m`, який визначається як квадратний корінь з відношення конвективної спроможності поверхні до кондуктивної спроможності ядра:

```
m = √( (h · P) / (k · A_c) )      [параметр згасання ребра, 1/м]
```

З урахуванням параметра `m`, рівняння балансу зводиться до канонічного вигляду однорідного лінійного диференціального рівняння второго порядку з постійними коефіцієнтами:

```
d²θ / dx² - m² · θ = 0      [канонічне рівняння ребра]
```

### 2. Загальний розв'язок та знаходження констант для адіабатичного вершка

Складаємо характеристичне алгебраїчне рівняння для канонічного диференціального рівняння второго порядку:

```
r² - m² = 0      [характеристичне рівняння]
= (r - m) · (r + m) = 0
```

Корені характеристичного рівняння є дійсними числами з протилежними знаками: `r1 = +m`, `r2 = -m`. Отже, фундаментальна система розв'язків складається з експоненціальних функцій `e^(m·x)` та `e^(-m·x)`. Для інженерних задач зручніше перейти до еквівалентної лінійної комбінації гіперболічних функцій косинуса та синуса:

```
θ(x) = C1 · cosh(m · x) + C2 · sinh(m · x)      [загальний розв'язок через гіперболічні функції]
```

тут `C1` та `C2` — невідомі константи інтегрування, які визначаються з фізичних граничних умов на кінцях ребра.

Розглянемо граничні умови для класичної задачі ребра з теплоізольованим (адіабатичним) вершком:

1. **Гранична умова в основі (`x = 0`):** Основа ребра щільно прилягає до гарячої деталі й має її постійну температуру `T_b`. Це дає фіксоване значення надлишкової температури:
   ```
   θ(0) = T(0) - T_∞ = T_b - T_∞ = θ_b      [гранична умова 1: першого роду в основі]
   ```
2. **Гранична умова на вершку (`x = L`):** Торцева площа ребра на вершку вважається теплоізольованою через малість її площі порівняно з бічною поверхнею. Відсутність теплового потоку через торець за законом Фур'є означає рівність нуля першої похідної температури:
   ```
   (dθ / dx)|_{x=L} = 0      [гранична умова 2: второго роду на вершку]
   ```

Знайдемо першу похідну від загального розв'язку за змінною `x`:

```
dθ / dx = d/dx [ C1 · cosh(m · x) + C2 · sinh(m · x) ]
= C1 · m · sinh(m · x) + C2 · m · cosh(m · x)      [диференціювання гіперболічних функцій]
```

Застосуємо першу граничну умову `x = 0` до загального розв'язку `θ(x)`:

```
θ(0) = C1 · cosh(0) + C2 · sinh(0)
= C1 · 1 + C2 · 0 = C1      [врахували значення cosh(0)=1, sinh(0)=0]
= θ_b
```

Отже, перша константа інтегрування виражається безпосередньо через надлишкову температуру основи: `C1 = θ_b`.

Застосуємо другу граничну умову `x = L` до виразу першої похідної `(dθ/dx)|_{x=L} = 0`:

```
(dθ / dx)|_{x=L} = θ_b · m · sinh(m · L) + C2 · m · cosh(m · L) = 0
= m · [ θ_b · sinh(m · L) + C2 · cosh(m · L) ] = 0
```

Оскільки параметр згасання `m` є строго додатним (`m > 0`), вираз у квадратних дужках мусить дорівнювати нулю:

```
θ_b · sinh(m · L) + C2 · cosh(m · L) = 0
C2 · cosh(m · L) = -θ_b · sinh(m · L)      [перенесення доданка]
C2 = -θ_b · ( sinh(m · L) / cosh(m · L) )      [вираження другої константи]
```

Підставимо знайдені константи `C1 = θ_b` та `C2 = -θ_b · sinh(m·L) / cosh(m·L)` у загальний розв'язок:

```
θ(x) = θ_b · cosh(m · x) - θ_b · ( sinh(m · L) / cosh(m · L) ) · sinh(m · x)
= (θ_b / cosh(m · L)) · [ cosh(m · x) · cosh(m · L) - sinh(m · L) · sinh(m · x) ]      [зведення до спільного знаменника]
```

Використовуючи тотожність гіперболічного косинуса різниці двох аргументів `cosh(A - B) = cosh(A)·cosh(B) - sinh(A)·sinh(B)`, спрощуємо вираз у квадратних дужках:

```
cosh(m · L) · cosh(m · x) - sinh(m · L) · sinh(m · x) = cosh( m · (L - x) )      [застосування тотожності гіперболічного косинуса]
```

Остаточно отримуємо точну аналітичну формулу розподілу надлишкової температури вздовж прямокутного ребра з ізольованим вершком:

```
θ(x) = θ_b · ( cosh( m · (L - x) ) / cosh( m · L ) )      [профіль температури ребра]
```

Ця формула показує, що температура спадає від основи `x = 0` до вершка `x = L` за законом гіперболічного косинуса, причому швидкість спадання визначається величиною безрозмірного добутку `m · L`.

### 3. Порівняння з іншими граничними умовами на вершку

Для повноти математичного розуміння корисно порівняти виведений розв'язок із двома іншими фізичними граничними умовами на вершку ребра:

#### Випадок 1: Нескінченно довге ребро (`L → ∞`)

Якщо ребро дуже довге, то на його вершку температура повністю порівнюється з температурою довкілля: `θ(∞) = 0`. Друга константа інтегрування набуває вигляду `C2 = -θ_b`, а розподіл температури спрощується до чистої експоненти:

```
θ(x) = θ_b · e^(-m · x)      [профіль температури нескінченного ребра]
```

Повний тепловий потік, що входить у корінь нескінченного ребра, дорівнює:

```
Q_inf = √( h · P · k · A_c ) · θ_b      [граничний потік нескінченного ребра]
```

#### Випадок 2: Конвективне охолодження вершка

Якщо торець ребра віддає тепло в повітря з тим самим коефіцієнтом тепловіддачі `h`, гранична умова на вершку `x = L` є умовою третього роду: `-k · (dθ/dx)|_{x=L} = h · θ(L)`. Точний розв'язок має вигляд:

```
θ(x) / θ_b = ( cosh(m·(L-x)) + (h/(m·k))·sinh(m·(L-x)) ) / ( cosh(m·L) + (h/(m·k))·sinh(m·L) )
```

Оскільки відношення `h/(m·k) = √(h·A_c / (k·P))` для тонких металевих ребер становить величину порядку 0.01–0.05, додаток із синусом є мізерним. Саме це математично виправдовує використання концепції скоригованої довжини `L_c = L + t/2` у простішій формулі адіабатичного вершка.

### 4. Розрахунок теплового потоку та виведення ефективності η_f

Тепловий потік `Q_fin`, який розсіюється прямокутним ребром у стаціонарному режимі, обчислимо двома математично незалежними способами для перевірки несуперечливості виводу.

#### Спосіб А: За законом Фур'є в основі ребра (`x = 0`)

Усе тепло, яке входить у ребро і надалі скидається з його поверхні, проходить крізь корінь `x = 0` за рахунок теплопровідності:

```
Q_fin = -k · A_c · (dθ / dx)|_{x=0}      [закон Фур'є в основі]
```

Обчислимо похідну від функції `θ(x) = θ_b · cosh(m·(L - x)) / cosh(m·L)` за змінною `x`:

```
dθ / dx = (θ_b / cosh(m · L)) · d/dx [ cosh( m · (L - x) ) ]
= (θ_b / cosh(m · L)) · sinh( m · (L - x) ) · (-m)      [похідна складеної функції]
= -m · θ_b · ( sinh( m · (L - x) ) / cosh( m · L ) )
```

Підставимо точку `x = 0` у похідну:

```
(dθ / dx)|_{x=0} = -m · θ_b · ( sinh(m · L) / cosh(m · L) )
= -m · θ_b · tanh(m · L)      [визначення гіперболічного тангенса]
```

Підставимо значення похідної у формулу закону Фур'є:

```
Q_fin = -k · A_c · [ -m · θ_b · tanh(m · L) ]
= k · A_c · m · θ_b · tanh(m · L)      [мінус на мінус дав плюс]
```

Підставимо вираз параметра згасання `m = √(h · P / (k · A_c))`:

```
Q_fin = k · A_c · √( (h · P) / (k · A_c) ) · θ_b · tanh(m · L)
= √( (k² · A_c² · h · P) / (k · A_c) ) · θ_b · tanh(m · L)      [знесли k·A_c під корінь]
= √( h · P · k · A_c ) · θ_b · tanh(m · L)      [точний потік тепла з ребра]
```

#### Спосіб Б: Прямим інтегруванням конвекції вздовж поверхні

Сумарне тепло дорівнює визначеному інтегралу від локальної конвекції по всій довжині ребра від `x = 0` до `x = L`:

```
Q_fin = ∫_{0}^{L} h · P · θ(x) dx
= h · P · (θ_b / cosh(m · L)) · ∫_{0}^{L} cosh( m · (L - x) ) dx      [винесли константи за знак інтеграла]
```

Виконаємо заміну змінної в інтегралі: `u = m · (L - x)`, звідси `du = -m · dx`, отже `dx = -du / m`. Зміна меж інтегрування: при `x = 0` маємо `u = m·L`; при `x = L` маємо `u = 0`:

```
∫_{0}^{L} cosh( m · (L - x) ) dx = ∫_{m·L}^{0} cosh(u) · (-du / m)
= (1 / m) · ∫_{0}^{m·L} cosh(u) du      [змінили межі інтегрування за рахунок мінуса]
= (1 / m) · [ sinh(u) ]_{0}^{m·L}
= (1 / m) · [ sinh(m · L) - sinh(0) ]
= sinh(m · L) / m      [врахували sinh(0)=0]
```

Підставимо результат інтегрування у вираз для `Q_fin`:

```
Q_fin = h · P · (θ_b / cosh(m · L)) · ( sinh(m · L) / m )
= ( (h · P) / m ) · θ_b · ( sinh(m · L) / cosh(m · L) )
= ( (h · P) / √(h · P / (k · A_c)) ) · θ_b · tanh(m · L)      [підставили m у знаменник]
= √( h · P · k · A_c ) · θ_b · tanh(m · L)      [отримали тотожний результат]
```

Обидва математичні методи дали абсолютно тотожний результат, що підтверджує строгість та безпомилковість виведення.

### 5. Доведення підсумкової формули ефективності η_f

За визначенням, ефективність ребра `η_f` є відношенням реального потоку `Q_fin` до максимально можливого потоку `Q_max`, який віддавало б ідеальне ізотермічне ребро з температурою основи `T_b`:

```
Q_max = h · A_f · θ_b      [максимальний потік ідеального ребра]
= h · (P · L) · θ_b      [площа бічної поверхні A_f = P·L]
```

Поділимо вираз `Q_fin` на `Q_max`:

```
η_f = Q_fin / Q_max
= [ √(h · P · k · A_c) · θ_b · tanh(m · L) ] / [ h · P · L · θ_b ]      [підставили вирази]
= [ √(h · P · k · A_c) / (h · P) ] · [ tanh(m · L) / L ]      [скоротили надлишкову температуру θ_b]
```

Спростимо перший множник:

```
√(h · P · k · A_c) / (h · P) = √( (h · P · k · A_c) / (h² · P²) )
= √( (k · A_c) / (h · P) )      [скоротили h·P]
= 1 / √( (h · P) / (k · A_c) )
= 1 / m      [за означенням параметра m]
```

Підставимо `1/m` назад у формулу ефективності:

```
η_f = (1 / m) · [ tanh(m · L) / L ]
= tanh(m · L) / (m · L)      [остаточна формула ефективності прямокутного ребра]
```

Математичне доведення повністю завершено. Формула `η_f = tanh(m·L) / (m·L)` виведена строго з фундаментальних законів теплофізики.

### 6. Математичне виведення для циліндричного штиркового ребра

Для циліндричного штиря суцільного круглого перерізу діаметром `D` площа перерізу та периметр становлять:

```
A_c = (π · D²) / 4      [площа круга]
P = π · D      [довжина кола]
```

Підставимо ці вирази у формулу параметра `m`:

```
m = √( (h · P) / (k · A_c) )
= √( (h · π · D) / (k · (π · D² / 4)) )
= √( (4 · h) / (k · D) )      [параметр згасання для циліндричного штиря]
```

Оскільки площа перерізу `A_c` та периметр `P` є постійними вздовж довжини `x`, диференціальне рівняння штиря має абсолютно такий самий вигляд `d²θ/dx² - m²·θ = 0`, а його ефективність обчислюється за тією ж формулою:

```
η_pin = tanh(m · L_c) / (m · L_c)
```

де скоригована довжина для торця штиря дорівнює `L_c = L + D/4`.

### 7. Середньоінтегральна температура ребра T_avg

У багатьох теплофізичних розрахунках (зокрема при обчисленні середовищних теплофізичних властивостей повітря `k_air`, `ν`, `Pr` за визначальною температурою) необхідно знати середню температуру всієї поверхні ребра `T_avg`.

Обчислимо середню надлишкову температуру інтегруванням вздовж довжини `L`:

```
θ_avg = (1 / L) · ∫_{0}^{L} θ(x) dx
= (1 / L) · ∫_{0}^{L} θ_b · ( cosh(m·(L-x)) / cosh(m·L) ) dx
= (θ_b / (m · L)) · tanh(m · L)      [використали результат інтегрування з розділу 4]
= θ_b · η_f      [врахували означення ефективності]
```

Остаточно середня середовищна температура поверхні ребра становить:

```
T_avg = T_∞ + θ_b · η_f = T_∞ + (T_b - T_∞) · η_f      [середньоінтегральна температура ребра]
```

Ця витончена формула показує, що середня температура поверхні ребра є лінійною комбінацією температури довкілля та температури основи, де ваговим коефіцієнтом виступає ефективність ребра `η_f`. При `η_f = 1` маємо `T_avg = T_b` (ізотермічне ребро); при `η_f → 0` маємо `T_avg → T_∞`.

### 8. Математичне виведення для трикутного ребра

Розглянемо поздовжнє ребро клиноподібного (трикутного) профілю завдовжки `L`, товщиною в основі `t_b` та шириною `W`. Товщина ребра спадає лінійно від основи до вершка: `t(x) = t_b · (1 - x/L)`.

Площа поперечного перерізу та периметр тепер залежать від координати `x`:

```
A_c(x) = W · t_b · (1 - x / L)
P(x) ≈ 2 · W      [нехтуючи малою товщиною]
```

Підставляючи змінні `A_c(x)` у диференціальне рівняння балансу тепла `d/dx [ A_c(x) · (dθ/dx) ] - (h·P/k)·θ = 0`, отримуємо:

```
d/dx [ (1 - x / L) · (dθ / dx) ] - (2 · h / (k · t_b)) · θ = 0
= (1 - x / L) · (d²θ / dx²) - (1 / L) · (dθ / dx) - m² · θ = 0      [розкриття похідної добутку]
```

тут `m² = 2 · h / (k · t_b)`.

Вводячи нову безрозмірну змінну `z = 2 · m · √( L · (L - x) )`, це диференціальне рівняння зі змінними коефіцієнтами зводиться до канонічного рівняння Бесселя нульового порядку від уявного аргументу:

```
z² · (d²θ / dz²) + z · (dθ / dz) - z² · θ = 0      [модифіковане рівняння Бесселя]
```

Загальний розв'язок цього рівняння виражається через модифіковані функції Бесселя першого та другого роду нульового порядку (`I_0` та `K_0`):

```
θ(z) = C1 · I_0(z) + C2 · K_0(z)
```

Оскільки на вершку ребра (`x = L`, отже `z = 0`) функція `K_0(0) → ∞` прямує до нескінченності, фізична умова скінченності температури вимагає `C2 = 0`. Константи визначення дають підсумковий профіль температури:

```
θ(x) / θ_b = I_0( 2 · m · √(L · (L - x)) ) / I_0( 2 · m · L )
```

Інтегрування конвективного потоку дає точну формулу ефективності трикутного ребра:

```
η_tri = I_1( 2 · m · L ) / ( m · L · I_0( 2 · m · L ) )      [ефективність трикутного ребра]
```

де `I_1` — модифікована функція Бесселя першого порядку. Ця формула доводить, що за однакового параметра `m·L` трикутне ребро забезпечує практично таку ж тепловіддачу, що й прямокутне, але витрата металу на трикутне ребро становить лише `1/2` від прямокутного, що й забезпечує 37% виграш у питомій масі.

### 9. Варіаційне числення та параболічний профіль Шмідта

Сформулюємо варіаційну задачу Ернста Шмідта (1926): знайти форму профілю ребра `t(x)`, яка при заданій фіксованій масі (і об'ємі `V = W · ∫ t(x) dx = const`) забезпечує максимальний тепловий потік `Q_fin`.

Математично задача зводиться до знаходження екстремуму функціонала теплового потоку за наявності ізопериметричного зв'язку об'єму за допомогою методу невизначених множників Лагранжа:

```
J[t(x)] = ∫_{0}^{L} [ k · W · t(x) · (dT/dx)² + 2 · h · W · (T - T_∞) ] dx + λ · ∫_{0}^{L} W · t(x) dx
```

Записуючи рівняння Ейлера-Лагранжа для функціонала `J[t(x)]`, отримуємо умову, що для оптимального профілю градієнт температури уздовж усього ребра мусить залишатися суворо постійним:

```
dT / dx = const = -C_g      [постійний градієнт температури]
```

Оскільки градієнт температури є постійним, розподіл температури є строго лінійним: `T(x) = T_b - C_g · x`. Підставляючи лінійну температуру в диференціальне рівняння балансу тепла, отримуємо точну параболічну форму профілю ідеального ребра Шмідта:

```
t(x) = t_b · ( 1 - x / L )²      [увігнуте параболічне ребро Шмідта]
```

Увігнуте параболічне ребро Шмідта володіє 100% масовою ефективністю — кожен міліграм металу в ньому навантажений однаковим питомим тепловим потоком.

### 10. Чисельне інтегрування для складних геометрій ребер

У реальних інженерних конструкціях профіль ребра `A_c(x)` або коефіцієнт тепловіддачі `h(x)` часто не описуються простими аналітичними функціями (наприклад, при наявності локальних перфорацій, штампованих засічок чи складної турбулентності).

У таких випадках диференціальне рівняння балансу зі змінними коефіцієнтами розв'язують чисельно за допомогою методу Рунге-Кутти 4-го порядку або методу скінченних різниць. Диференціальне рівняння зводиться до системи двох рівнянь першого порядку:

```
dθ / dx = ψ
dψ / dx = (h(x) · P(x) / (k · A_c(x))) · θ - (1 / A_c(x)) · (d A_c / dx) · ψ
```

Чисельне інтегрування виконується від основи `x = 0` до вершка `x = L`, після чого інтегральний потік тепла обчислюється методом трапецій за локальними значеннями надлишкової температури: `Q_fin = ∫ h(x) · P(x) · θ(x) dx`.

### 11. Математичний зв'язок з еквівалентним тепловим опором R_th

Концепція ефективності ребра тісно пов'язана з теорією [теплового опору](topic:physics/thermal-resistance).

Повний тепловий опір поєднання теплопровідності ребра та його бічної конвекції можна подати як еквівалентний опір `R_th(fin)` між основою `T_b` та довкіллям `T_∞`:

```
R_th(fin) = θ_b / Q_fin
```

Підставимо вираз `Q_fin = η_f · h · A_f · θ_b`:

```
R_th(fin) = θ_b / ( η_f · h · A_f · θ_b )
= 1 / ( η_f · h · A_f )      [еквівалентний тепловий опір ребра]
```

Ця формула має прозорий математичний зміст: конвективний опір ідеальної поверхні площею `A_f` дорівнює `1 / (h · A_f)`. Наявність падіння температури уздовж ребра збільшує цей опір в `1 / η_f` разів.

Для масиву з `N` однакових ребер на спільній основі з незайнятою площею `A_u` сумарний тепловий опір всієї конструкції обчислюється як паралельне з'єднання опору основи `R_u = 1 / (h · A_u)` та опорів окремих ребер `R_fin = 1 / (η_f · h · A_f)`:

```
1 / R_th(total) = 1 / R_u + N / R_fin
= h · A_u + N · η_f · h · A_f
= h · [ A_u + η_f · A_f_total ]
```

Звідси підсумковий опір радіатора дорівнює:

```
R_th(total) = 1 / ( η_o · h · A_total )      [сумарний тепловий опір радіатора]
```

де `η_o = 1 - (A_f_total / A_total) · (1 - η_f)` — загальна ефективність оребреної поверхні.

### 11. Аналіз граничних асимптот формули ефективності

Проаналізуємо математичну поведінку формули `η_f = tanh(m·L) / (m·L)` у двох крайніх граничних випадках.

#### Асимптота 1: Коротке або високотеплопровідне ребро (`m · L → 0`)

Розкладемо гіперболічний тангенс `tanh(y)` у ряд Маклорена (Тейлора поблизу нуля `y = 0`):

```
tanh(y) = y - y³ / 3 + 2·y⁵ / 15 - ...      [ряд Маклорена для tanh(y)]
```

Підставимо цей розклад у формулу ефективності, взявши `y = m · L`:

```
η_f = ( (m · L) - (m · L)³ / 3 + ... ) / (m · L)
= 1 - (m · L)² / 3 + O((m · L)⁴)      [скоротили на m·L]
```

Переходячи до границі при `m · L → 0`:

```
lim_{m·L → 0} η_f = lim_{m·L → 0} [ 1 - (m · L)² / 3 ] = 1.0      [100% ефективність]
```

Фізична інтерпретація: якщо ребро є коротких розмірів (`L → 0`) або володіє високою теплопровідністю (`k → ∞`), опір теплопровідності прямує до нуля, температура уздовж ребра не падає, і ребро розсіює 100% можливого тепла.

#### Асимптота 2: Довге або низькотеплопровідне ребро (`m · L → ∞`)

При великих значеннях аргументу `y >> 1` значення гіперболічного тангенса асимптотично прямує до одиниці:

```
lim_{y → ∞} tanh(y) = 1.0      [асимптота гіперболічного тангенса]
```

Тоді границя ефективності при `m · L → ∞` становить:

```
lim_{m·L → ∞} η_f = lim_{m·L → ∞} [ 1 / (m · L) ] = 0      [падіння ефективності до нуля]
```

Фізична інтерпретація: якщо ребро роблять надмірно довгим, його дальня частина повністю охолоджується до температури довкілля й припиняє участь у теплообміні. Ефективність спадає за зворотним законом `1/(m·L)`, що математично підтверджує наявність термічного замикання й недоцільність нескінченного подовження радіаторів.
