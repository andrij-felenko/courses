# 📑 Довідник формул ефективності ребер та оребрених поверхонь

Цей довідник містить повне інженерне зведення аналітичних формул, характеристичних параметрів, геометричних коефіцієнтів та граничних умов для розрахунку ефективності ребер різної конфігурації, сумарної ефективності оребрених поверхонь, термічних опорів та теплових потоків. Довідник призначений для швидкого пошуку потрібного розрахункового співвідношення та супровідного фізичного роз'яснення при проектуванні теплообмінників, радіаторів електроніки, аерокосмічних систем та енергетичного обладнання.

---

## 1. Основні фізичні величини, визначення та позначення

Розшук та аналіз розширених поверхонь спирається на чітко визначену систему фізичних величин. Нище наведено зведену таблицю фундаментальних параметрів та їхній фізичний зміст у міжнародній системі одиниць SI.

| Позначення | Фізична величина | Одиниці SI | Фізичний зміст та функціональний зв'язок |
| :--- | :--- | :--- | :--- |
| `k` | Теплопровідність матеріалу | Вт/(м·К) | Характеризує здатність металу ребра (алюміній, мідь, сталь, титан) проводити тепловий потік уздовж його довжини. |
| `h` | Коефіцієнт тепловіддачі | Вт/(м²·К) | Характеризує інтенсивність конвективного знімання тепла з бічної поверхні ребра в омиваючий потік повітря або рідини. |
| `T_b` | Температура основи ребра | °C або К | Фіксована або розрахована температура в місці спаю чи прилягання ребра до гарячої поверхні деталі. |
| `T_∞` | Температура довкілля | °C або К | Однорідна температура навколишнього середовища (набігаючого потоку повітря чи охолоджувальної рідини). |
| `θ_b` | Надлишкова температура основи | К | Температурний напір між основою та довкіллям: `θ_b = T_b - T_∞`. |
| `L` | Геометрична довжина ребра | м | Відстань уздовж центральної осі від кореня основи до найвіддаленішого вершка. |
| `L_c` | Скоригована довжина ребра | м | Умовна довжина, що враховує тепловіддачу з відкритого торця: `L_c = L + t/2` (для прямокутника) або `L_c = L + D/4` (для штиря). |
| `t` | Товщина ребра | м | Поперечний розмір ребра. Для трикутних ребер — товщина в основі `t_b`. |
| `W` | Ширина ребра | м | Просторний розмір ребра вздовж площини основи, перпендикулярно до напрямку поздовжнього потоку тепла. |
| `D` | Діаметр штиря | м | Зовнішній діаметр циліндричного або конічного штиркового ребра. |
| `A_c` | Площа поперечного перерізу | м² | Площа перерізу ребра, перпендикулярна до поздовжньої осі `x` і теплового потоку теплопровідності. |
| `P` | Периметр поперечного перерізу | м | Довжина замкненого контуру перерізу, який безпосередньо омивається повітрям. |
| `A_f` | Площа бічної поверхні | м² | Сумарна площа контакту поверхні одного ребра з навколишнім середовищем. |
| `m` | Параметр згасання ребра | 1/м | Комплексний показник: `m = √(h·P / (k·A_c))`. Визначає швидкість падання температури уздовж ребра. |
| `η_f` | Ефективність окремого ребра | безрозмірна | Відношення реального теплового потоку ребра до потоку ідеального ізотермічного ребра: `η_f = Q_fin / Q_max`. |
| `η_o` | Загальна ефективність масиву | безрозмірна | Ефективність усієї оребреної поверхні з урахуванням незайнятих проміжків основи. |
| `R_th(fin)` | Тепловий опір ребра | °C/Вт або К/Вт | Еквівалентний опір переносу тепла від основи до довкілля: `R_th = 1 / (η_f · h · A_f)`. |

## 2. Класифікація фізичних граничних умов на кінцях ребра

Під час математичного моделювання розподілу температури уздовж ребра застосовують 4 типи фізичних граничних умов. Вибір правильної граничної умови визначає точність розрахунку:

1. **Гранична умова 1-го роду в основі (`x = 0`):**
   Припускається, що корінь ребра має постійну фіксовану температуру гарячої основи: `T(0) = T_b`, що відповідає `θ(0) = θ_b`. Ця умова виправдана, якщо опір металевої підошви радіатора є мізерним порівняно з опором ребер.

2. **Гранична умова 2-го роду на вершку (`x = L`) — Адіабатичний вершок:**
   Припускається, що торцева площа ребра на вершку є теплоізольованою, отже поздовжній потік дорівнює нулю: `(dθ/dx)|_{x=L} = 0`. Ця умова дає аналітичний розв'язок у вигляді гіперболічного тангенса `η_f = tanh(m·L) / (m·L)`. Для врахування реального знімання тепла з торця довжину `L` замінюють на скориговану довжину `L_c = L + t/2`.

3. **Гранична умова 3-го роду на вершку (`x = L`) — Конвективний торець:**
   Враховує точний конвективний теплообмін з торцевої площадки: `-k · (dθ/dx)|_{x=L} = h_tip · θ(L)`. Точний розв'язок виражається складною лінійною комбінацією гіперболічних синусів та косинусів.

4. **Гранична умова для нескінченно довгого ребра (`L → ∞`):**
   Припускається, що дальній кінець ребра повністю охолоджується до температури довкілля: `θ(∞) = 0`. Останнє дає чисту експоненту `θ(x) = θ_b · e^(-m·x)` та ефективність `η_f = 1 / (m·L)`.

## 3. Поздовжні ребра постійного та змінного перерізу (Longitudinal Fins)

Поздовжні ребра являють собою металеві пластини або клини, закріплені на плоскій чи циліндричній поверхні вздовж напрямку руху теплоносія.

### 3.1. Прямокутне поздовжнє ребро постійного перерізу

Прямокутне ребро є найпоширенішою геометрією в сучасній електроніці завдяки простоті технологічного виготовлення методом екструзії, штампування чи фрезерування.

#### Фізичний механізм та параметри:
Поздовжнє тепло переноситься вздовж прямокутного перерізу постійної площі `A_c = W · t`. Одночасно тепло віддається з обох бічних поверхонь загальним периметром `P = 2·(W + t)`. Оскільки ширина `W` у сотні разів перевищує товщину `t`, периметр приймають рівним `P ≈ 2·W`.

#### Перелік розрахункових параметрів:
- Площа поперечного перерізу: `A_c = W · t`
- Периметр перерізу: `P = 2 · (W + t) ≈ 2 · W`
- Комплексний параметр згасання: `m = √( (2 · h) / (k · t) )`
- Скоригована довжина для врахування торця: `L_c = L + t / 2`
- Повна площа бічної поверхні: `A_f = 2 · W · L_c`

#### Зведення формул ефективності за різних граничних умов:

1. **Ізольований (адіабатичний) вершок або скоригована довжина `L_c`:**
   Найбільш уживана формула в інженерних розрахунках теплообмінників та кулерів:
   ```
   η_f = tanh(m · L_c) / (m · L_c)
   ```
   *Межі застосування:* Точність цієї апроксимації становить краще 1.5% за умови `h·t / (2·k) < 0.06`.

2. **Конвективне охолодження вершка (без поправки на скориговану довжину):**
   Точний розв'язок за наявності конвекції на торці з тим самим коефіцієнтом `h`:
   ```
   η_f = [ sinh(m·L) + (h/(m·k))·cosh(m·L) ] / [ m·L · ( cosh(m·L) + (h/(m·k))·sinh(m·L) ) ]
   ```

3. **Ніби нескінченно довге ребро (`m · L > 3.0`):**
   Якщо ребро є надто довгим, температура на його кінці повністю прямує до температури довкілля `T_∞`:
   ```
   η_f = 1 / (m · L)
   ```
   *Фізичний наслідок:* При подальшому збільшенні довжини `L` тепловий потік перестає зростати, досягаючи граничної асимптоти `Q_max = √(h·P·k·A_c) · θ_b`.

---

### 3.2. Трикутне (клиноподібне) поздовжнє ребро

Трикутне ребро має лінійно спадну товщину від основи `t_b` до гострого вершка `t = 0`.

#### Фізичний механізм:
У міру віддалення від основи тепловий потік зменшується через віддачу в повітря. Скорочення товщини перерізу `t(x) = t_b · (1 - x/L)` підтримує високу густину теплового потоку в металі, зменшуючи масу ребра удвічі порівняно з прямокутним.

#### Геометричні та розрахункові параметри:
- Товщина в основі: `t_b`
- Товщина на вершку: `0`
- Площа бічної поверхні: `A_f = 2 · W · √(L² + (t_b/2)²) ≈ 2 · W · L`
- Параметр згасання в основі: `m = √( (2 · h) / (k · t_b) )`

#### Формула ефективності:
```
η_tri = I_1( 2 · m · L ) / ( m · L · I_0( 2 · m · L ) )
```
де `I_0` та `I_1` — модифіковані функції Бесселя першого роду нульового та першого порядків відповідно.

*Інженерні переваги:* При одинакових значеннях `m·L` трикутне ребро має ефективність лише на 2–4% нижчу за прямокутне, але потребує на 50% менше маси металу. Це робить його ідеальним вибором для авіакосмічної та автотракторної техніки.

### 3.3. Параболічне увігнуте ребро (Ідеальний профіль Шмідта)

Параболічне увігнуте ребро описується законом товщини `t(x) = t_b · (1 - x/L)²`.

#### Фізичний механізм:
У цьому профілі градієнт температури уздовж довжини є строго постійним: `dT/dx = const`. Кожен міліграм металу навантажений абсолютно однаковим питомим тепловим потоком, що забезпечує 100% термодинамічну оптимізацію маси.

#### Геометричні та розрахункові параметри:
- Товщина в основі: `t_b`
- Об'єм матеріалу ребра: `V = (1/3) · W · t_b · L`
- Параметр згасання в основі: `m = √( (2 · h) / (k · t_b) )`

#### Формула ефективності:
```
η_schmidt = 2 / ( 1 + √( 4 · m² · L² + 1 ) )
```

---

### 3.4. Трапецієподібне поздовжнє ребро

Трапецієподібне ребро є реальним компромісом між прямокутним та трикутним ребрами, оскільки виготовлення суворо гострого трикутного вершка технологічно ускладнено.

#### Геометричні параметри:
- Товщина в основі: `t_1`
- Товщина на вершку: `t_2`
- Відношення товщин: `r_t = t_2 / t_1`
- Усереднений параметр згасання: `m = √( (2 · h) / (k · t_1) )`

#### Формула ефективності:
```
η_trap = η_tri(m · L) · [ 1 + (1 - r_t) / (2 · m · L) ]
```

## 4. Штиркові ребра (Pin Fins / Spines)

Штиркові ребра мають круглий, квадратний або краплеподібний переріз і широко застосовуються у матричних теплознімачах процесорів, світлодіодних масивах та турбінних лопатках.

### 4.1. Циліндричний круглий штир постійного діаметра

#### Фізичний механізм:
Повітряний потік омиває круглий переріз діаметром `D`. Оскільки площа перерізу `A_c = π·D²/4`, а периметр `P = π·D`, параметр згасання дорівнює `m = √(4·h / (k·D))`.

#### Розрахункові параметри:
- Діаметр штиря: `D`
- Площа поперечного перерізу: `A_c = (π · D²) / 4`
- Периметр перерізу: `P = π · D`
- Параметр згасання: `m = √( (4 · h) / (k · D) )`
- Скоригований радіус довжини: `L_c = L + D / 4`
- Площа бічної поверхні: `A_f = π · D · L_c`

#### Формула ефективності:
```
η_pin = tanh(m · L_c) / (m · L_c)
```

---

### 4.2. Конічний штир (Conical Spine)

Конічний штир має діаметр в основі `D_b` та звужується до точки на вершку.

#### Розрахункові параметри:
- Діаметр в основі: `D_b`
- Параметр згасання в основі: `m = √( (4 · h) / (k · D_b) )`

#### Формула ефективності:
```
η_conical = (2 / (m · L)) · ( I_2( 2 · m · L ) / I_1( 2 · m · L ) )
```
де `I_1` та `I_2` — модифіковані функції Бесселя першого роду відповідно 1-го та 2-го порядків.

---

## 5. Кільцеві (радіальні) ребра на трубах (Radial / Annular Fins)

Кільцеві ребра встановлюються на зовнішній поверхні круглих труб для охолодження рідин чи газів, що протікають усередині труб.

#### Геометричні та розрахункові параметри:
- Внутрішній радіус основи (радіус труби): `r_1`
- Зовнішній радіус вершка ребра: `r_2`
- Скоригований зовнішній радіус: `r_2c = r_2 + t / 2`
- Товщина пластини ребра: `t`
- Скоригована довжина: `L_c = r_2c - r_1`
- Площа бічної поверхні ребра: `A_f = 2 · π · (r_2c² - r_1²)`
- Параметр згасання: `m = √( (2 · h) / (k · t) )`

#### Точна формула Мюррея-Гарднера через функції Бесселя:

```
η_annular = (2 · r_1 / (m · (r_2c² - r_1²))) · [ ( K_1(m·r_1)·I_1(m·r_2c) - I_1(m·r_1)·K_1(m·r_2c) ) / ( I_0(m·r_1)·K_1(m·r_2c) + K_0(m·r_1)·I_1(m·r_2c) ) ]
```

де `I_0`, `I_1` — модифіковані функції Бесселя 1-го роду, а `K_0`, `K_1` — модифіковані функції Бесселя 2-го роду.

#### Спрощена апроксимація Шмідта для кільцевих ребер:

Дізнатися ефективність кільцевого ребра можна без обчислення функцій Бесселя за допомогою еквівалентного прямокутного ребра зі скоригованою довжиною:

```
η_annular ≈ η_rect(m · L_c) · cos( 0.35 · ln(r_2c / r_1) )
```
*Точність:* Похибка спрощеної формули Шмідта не перевищує 3% для практичного діапазону відношень радіусів `1.0 < r_2c / r_1 ≤ 3.5`.

## 7. Сумарні характеристики оребрених масивів та теплові опори

При встановленні масиву з `N` однаково спроектованих ребер на спільній підошві підсумкова теплова віддача визначається сумою тепловіддачі бічних поверхонь ребер та гладких міжреберних ділянок основи.

### 7.1. Загальна ефективність поверхні `η_o`

```
η_o = 1 - (A_f_total / A_total) · (1 - η_f)
```
де:
- `A_f_total = N · A_f` — сумарна площа бічних поверхонь усіх `N` ребер.
- `A_u` — площа незайнятої основи між ребрами.
- `A_total = A_u + A_f_total` — повна площа відкритого контакту з довкіллям.

---

### 7.2. Повний тепловий опір оребреного радіатора `R_th`

```
R_th(total) = 1 / ( η_o · h · A_total )
```

Ураховуючи контактний опір між гарячою детальною та підошвою радіатора `R_th(contact)` і опір товщини підошви `R_th(base)`:

```
R_th_system = R_th(contact) + (t_base / (k · A_base)) + 1 / ( η_o · h · A_total )
```

---

### 7.3. Коефіцієнт підсилення тепловіддачі (Fin Effectiveness `ε_f`)

**Коефіцієнт підсилення `ε_f`** (не плутати з ефективністю `η_f`) показує, у скільки разів наявність ребра збільшує тепловий потік порівняно з голою основою такої самої площі поперечного перерізу `A_c`:

```
ε_f = Q_fin / ( h · A_c · θ_b ) = η_f · ( A_f / A_c )
```

**Критерій інженерної доцільності оребрення:** Встановлення ребер є виправданим лише за умови `ε_f ≥ 2.0–3.0`. Якщо `ε_f < 2.0`, додатковий опір теплопровідності металу ребра перевищує виграш від збільшення площі конвективного контакту, і оребрення погіршує теплообмін.

## 8. Покрокова методичка інженерного розрахунку радіатора

Для швидкого розрахунку оребреного радіатора дотримуйтесь такої послідовності кроків:

1. **Крок 1. Визначення вхідних теплових вимог:**
   З'ясуйте максимальну розсіювану потужність `P` (Вт), гранично допустиму температуру основи `T_b_max` (°C) та максимальну температуру навколишнього середовища `T_∞` (°C). Знайдіть необхідний граничний тепловий опір `R_th_req = (T_b_max - T_∞) / P`.

2. **Крок 2. Вибір виду конвекції та коефіцієнта `h`:**
   - При природній конвекції в повітрі приймайте `h ≈ 5–12` Вт/(м²·К).
   - При вимушеній конвекції вентилятором приймайте `h ≈ 30–80` Вт/(м²·К).
   - При рідинному охолодженні водою приймайте `h ≈ 1000–5000` Вт/(м²·К).

3. **Крок 3. Вибір матеріалу й товщини ребер:**
   Оберіть алюміній 6063 (`k = 200` Вт/(м·К)) або мідь (`k = 390` Вт/(м·К)). Оберіть технологічно допустиму товщину ребер `t` (зазвичай 1.0–2.0 мм для алюмінієвої екструзії).

4. **Крок 4. Розрахунок параметра `m` та вибір висоти `L`:**
   Обчисліть `m = √(2·h / (k·t))`. Задайте висоту ребра `L` такою, щоб безрозмірний комплекс лежав у межах `m·L ≈ 0.5–1.0`. Це гарантує високу ефективність `η_f ≈ 75–92%` і запобігає витратам металу на термічно замкнені вершки.

5. **Крок 5. Обчислення ефективності `η_f` та сумарного опору `R_th`:**
   Обчисліть `η_f = tanh(m·L_c) / (m·L_c)`. Підберіть кількість ребер `N` так, щоб підсумковий опір `R_th_total = 1 / (η_o · h · A_total)` був меншим за порогове значення `R_th_req`.

6. **Крок 6. Перевірка коефіцієнта підсилення `ε_f` та зазору `S`:**
   Переконайтеся, що `ε_f = η_f · (A_f / A_c) ≥ 3.0`, а міжреберний зазор `S = (W - N·t)/(N - 1)` є більшим за 1.5 мм при вимушеній конвекції та більшим за 8.0 мм при природній конвекції.

## 9. Аналіз 5 найтиповіших інженерних помилок при виборі та застосуванні формул

Під час практичного застосування наведених довідникових формул інженери-початківці нерідко припускаються системних помилок, які призводять до фатального розходження між розрахунковими та експериментальними значеннями:

1. **Плутанина між ефективністю окремого ребра `η_f` та загальною ефективністю поверхні `η_o`:**
   Ефективність `η_f` враховує лише падіння температури уздовж довжини самого ребра. Якщо підставити `η_f` замість `η_o` у формулу сумарного теплового опору `R_th = 1 / (η · h · A_total)`, це призведе до завищення теплового опору, оскільки площа незайнятої основи між ребрами `A_u` працює зі 100% ККД (`η_u = 1.0`). Завжди слід обчислювати комбіноване значення `η_o = 1 - (A_f_total / A_total) · (1 - η_f)`.

2. **Нехтування контактним опором `R_th(contact)` у підошві:**
   Розрахований за формулами тепловий опір оребреного масиву `R_th(total)` описує лише перенесення тепла від підошви радіатора до повітря. Якщо між підошвою та корпусом напівпровідникового компонента є повітряний зазор чи товстий шар дешевої термопасти, контактний опір `R_th(contact)` може становити 30–50% від сумарного опору всієї системи охолодження.

3. **Застосування формул прямокутного ребра для кільцевих ребер при `r_2 / r_1 > 1.5`:**
   Прямокутне ребро має постійну площу поперечного перерізу `A_c`. У кільцевому ребрі площа перерізу `A_c(r) = 2·π·r·t` лінійно зростає з радіусом `r`. Для труб малого діаметра з великими кільцевими пластинами використання формули гіперболічного тангенса `tanh(m·L_c)/(m·L_c)` замість формули Гарднера через функції Бесселя дає помилку заниження ефективності на 15–25%.

4. **Нехтування обмеженням за критерієм Біо (`Bi_t = h·t / (2·k) < 0.1`):**
   Усі наведені аналітичні формули виведені в одновимірному наближенні `T = T(x)`. Якщо товщина ребра `t` є великою, а коефіцієнт тепловіддачі `h` сягає гігантських значень (наприклад, при охолодженні киплячим фреоном чи водою `h > 10 000` Вт/(м²·К)), поперечний опір металу створює суттєвий градієнт температури від центральної осі ребра до його бічної поверхні. У цьому випадку одновимірні формули стають непридатними, і вимагається розв'язок двовимірного рівняння Лапласа-Пуассона `∂²T/∂x² + ∂²T/∂y² = 0`.

5. **Використання формул стаціонарного режиму для імпульсних навантажень:**
   При короткочасних теплових імпульсах (тривалістю від мікросекунд до кількох секунд) температура ребер регулюється не конвекцією `h`, а питомою теплоємністю металу `c_p` та швидкістю поширення теплової хвилі `a = k/(ρ·c_p)`. Розрахунок за стаціонарними формулами `η_f = tanh(m·L)/(m·L)` дасть хибну висновкову картинку.

## 10. Поліноміальні апроксимації функцій Бесселя для вбудованих обчислювачів

Для швидкого розрахунку трикутних, конічних та кільцевих ребер у мікроконтролерах без підключення важких математичних бібліотек застосовуються високоточні апроксимаційні поліноми Абрамовіца та Стіган (абсолютна похибка `< 10⁻⁻⁶`):

### 9.1. Модифікована функція Бесселя 0-го порядку `I_0(x)` та `K_0(x)`

Введемо нормований параметр `t = x / 3.75`. Для діапазону `0 ≤ x ≤ 3.75`:

```
I_0(x) = 1.0 + 3.5156229·t² + 3.0899424·t⁴ + 1.2067492·t⁶ + 0.2659732·t⁸ + 0.0360768·t¹⁰ + 0.0045813·t¹²
```

Для функції Бесселя 2-го роду нульового порядку `K_0(x)` при `x > 2.0` застосовують асимптотичний розклад:

```
K_0(x) ≈ √( π / (2 · x) ) · e^(-x) · [ 1 - 1/(8·x) + 9/(128·x²) - 75/(1024·x³) ]
```

### 9.2. Модифікована функція Бесселя 1-го порядку `I_1(x)` та `K_1(x)`

Введемо нормований параметр `t = x / 3.75`. Для діапазону `0 ≤ x ≤ 3.75`:

```
I_1(x) = x · [ 0.5 + 0.87890594·t² + 0.51498869·t⁴ + 0.15084934·t⁶ + 0.02658733·t⁸ + 0.00301532·t¹⁰ + 0.00032411·t¹² ]
```

Для функції Бесселя 2-го роду першого порядку `K_1(x)` при `x > 2.0` застосовують асимптотичний розклад:

```
K_1(x) ≈ √( π / (2 · x) ) · e^(-x) · [ 1 + 3/(8·x) - 15/(128·x²) + 105/(1024·x³) ]
```

Застосування цих чотирьох поліномів дає змогу обчислювати трикутні, конічні та кільцеві ребра у вбудованих контролерах систем автоматичного керування терморежимом за мікросекундний час.
