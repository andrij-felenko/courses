# 🧮 Фізична й математична модель витоку заряду та критичного порога активацій

Збій Rowhammer є прямим наслідком порушення енергетичного балансу крихітного конденсатора пам'яті. У сучасних мікросхемах DRAM зберігання одного біта інформації покладено на заряд величиною в лічені десятки фемтокулонів (10⁻¹⁵ Кл), замкнений за закритим кремнієвим транзистором-ключем. Багаторазове комутування сусідніх провідників перетворює квазістатичний режим зберігання на динамічне імпульсне збурення, за якого кілька незалежних фізичних механізмів одночасно відкачують заряд із вузла зберігання. Щоб кількісно спрогнозувати момент перекидання біта, необхідно побудувати спільну математичну модель ємнісного перехресного зв'язку, підпорогового витоку, інжекції гарячих носіїв заряду, генерації в діелектрику, топологічної асиметрії та температурної деградації.

### 1. Електростатичний баланс комірки та поріг чутливості зчитування

Класична комірка динамічної пам'яті Деннарда (1T1C) складається з одного польового транзистора доступу та одного накопичувального конденсатора з ємністю `C_S`. Стан логічної одиниці формується шляхом заряджання конденсатора до повної напруги живлення матриці `V_DD`. Початковий електричний заряд `Q_init`, що зберігається на обкладках конденсатора, описується співвідношенням:

```
Q_init = C_S · V_DD          [початковий заряд повної логічної одиниці]
```

Процес зчитування даних у DRAM має руйнівний характер (*destructive read*). Перед подачею сигналу активації на словесну лінію відповідна розрядна лінія (*Bitline*) попередньо заряджається до проміжного опорного потенціалу попереднього заряду `V_PRE = V_DD / 2`. Коли напруга на словесній лінії відкриває транзистор доступу, замкнений заряд конденсатора змішується із зарядом розрядної лінії. Оскільки фізична довжина розрядної лінії сягає сотень мікрометрів і об'єднує сотні комірок у стовпчику, її паразитна ємність `C_BL` у багато разів перевищує ємність самої комірки `C_S`.

У момент замикання ключа виникає перерозподіл електричного заряду. Потенціал на розрядній лінії зазнає крихітного динамічного відхилення `ΔV_BL`, яке спрямоване вгору (якщо в комірці зберігалася логічна одиниця) або вниз (якщо зберігався нуль):

```
ΔV_BL = ( V_cell - V_DD / 2 ) · ( C_S / (C_S + C_BL) )    [перерозподіл заряду під час читання]
```

Отриманий крихітний імпульс напруги `ΔV_BL` надходить на диференційний підсилювач зчитування (*sense amplifier*), побудований за схемою взаємно зв'язаних CMOS-інверторів. Підсилювач розпізнає полярність відхилення і розганяє сигнал до повних логічних рівнів `V_DD` або `0 В`, після чого автоматично перезаписує відновлений заряд назад у конденсатор комірки. Проте для надійного спрацьовування тригера величина сигнального відхилення `|ΔV_BL|` повинна строго перевищувати власну напругу неузгодженості транзисторів підсилювача `V_offset` та інтегральний тепловий шум матриці `V_noise`:

```
|ΔV_BL| ≥ V_sense_min = V_offset + V_noise_margin         [поріг надійного розпізнавання]
```

Підставивши формулу перерозподілу заряду у вираз граничної чутливості, визначимо мінімальну напругу `V_cell_min`, до якої конденсатор комірки може розрядитися, перш ніж підсилювач помилково сприйме збережену одиницю як логічний нуль:

```
V_cell_min = V_DD / 2 + V_sense_min · ( 1 + C_BL / C_S )  [мінімальна напруга збереження «1»]
```

Граничний рівень залишкового заряду `Q_sense`, який визначає фізичну межу стабільності біта, дорівнює добутку залишкової напруги на власну ємність конденсатора:

```
Q_sense = C_S · V_cell_min                                [граничний залишковий заряд]
```

Відповідно, максимально допустима втрата заряду `Q_loss_max`, яку комірка здатна перенести без збою впродовж стандартного інтервалу між циклами регенерації, виражається різницею початкового та граничного зарядів:

```
Q_loss_max = Q_init - Q_sense
           = C_S · ( V_DD - V_cell_min )                  [критичний бюджет втрати заряду]
```

Проведемо числову оцінку для ультращільних матриць покоління 1x нм із проектними параметрами: ємність комірки `C_S = 12 фФ` (12·10⁻¹⁵ Ф), паразитна ємність розрядної лінії `C_BL = 100 фФ`, напруга живлення матриці `V_DD = 1.2 В`, мінімально необхідне відхилення компаратора `V_sense_min = 35 мВ`.

```
C_BL / C_S = 100 фФ / 12 фФ ≈ 8.33                        [коефіцієнт послаблення сигналу]
V_cell_min = 0.60 В + 0.035 В · ( 1 + 8.33 )
           = 0.60 + 0.035 · 9.33 = 0.60 + 0.327 = 0.927 В [поріг напруги на конденсаторі]
Q_init     = 12·10⁻¹⁵ Ф · 1.20 В = 14.40 фКл              [початковий заряд повної «1»]
Q_sense    = 12·10⁻¹⁵ Ф · 0.927 В = 11.12 фКл             [пороговий заряд зчитування]
Q_loss_max = 14.40 - 11.12 = 3.28 фКл                     [критичний запас заряду до збою]
```

Отримане значення 3.28 фемтокулона відповідає приблизно 20 470 елементарним зарядам електрона. Якщо внаслідок фонового струму витоку або стороннього збурення конденсатор втратить цю мізерну порцію електронів до приходу наступної команди оновлення, біт спонтанно інвертується.

### 2. Паразитний ємнісний подільник та стрибки напруги на затворі

У сучасній архітектурі DRAM масив транзисторів виконується за технологією похованих затворів (BCAT). Словні лінії проходять паралельно у вузьких траншеях кремнієвої підкладки на відстані всього 15–20 нм одна від одної.

У режимі очікування закриті рядки утримуються під постійним негативним потенціалом зміщення `V_NWL ≈ -0.3 В`, що необхідно для мінімізації підпорогового струму витоку. Коли до контролера надходить команда активації рядка-агресора (`WL_A`), напруга на його затворі різко піднімається до високого позитивного рівня відмикання `V_PP ≈ +3.0 В`. Розмах комутаційного сигналу становить:

```
ΔV_WL = V_PP - V_NWL = 3.0 - (-0.3) = 3.3 В               [розмах імпульсу на затворі агресора]
```

Оскільки простір між паралельними лініями заповнений діелектриком із кінцевою проникністю, між словесною лінією агресора `WL_A` та словесною лінією жертви `WL_V` виникає пряма паразитна ємність перехресного зв'язку `C_WL_WL`. У момент перемикання ця ємність разом із власною ємністю лінії жертви відносно підкладки та каналу утворює ємнісний подільник напруги. Сумарна ємність вузла жертви `C_V_total` складається з ємності на підкладку `C_WL_sub`, ємності перекриття затвор-витік `C_GS`, затвор-стік `C_GD` та ємності тіла транзистора `C_GB`:

```
C_V_total = C_WL_sub + C_GS + C_GD + C_GB                 [сумарна паразитна ємність вузла жертви]
ΔV_V = ΔV_WL · ( C_WL_WL / ( C_WL_WL + C_V_total ) )       [наведена паразитна напруга на затворі]
```

У типовому кристалі DRAM при ємності перехресного зв'язку `C_WL_WL = 0.18 фФ` та повній ємності лінії жертви `C_V_total = 1.32 фФ` коефіцієнт ємнісного зв'язку та наведена напруга становлять:

```
K_couple = 0.18 / ( 0.18 + 1.32 ) = 0.18 / 1.50 = 0.12     [коефіцієнт ємнісного ділення 12%]
ΔV_V     = 3.3 В · 0.12 = 0.396 В ≈ 0.40 В                [амплітуда паразитного підскоку напруги]
```

Кожен імпульс відкриття агресора тимчасово підкидає потенціал на затворі транзистора-жертви від базового рівня спокою `-0.30 В` до позитивного значення:

```
V_gate_victim = V_NWL + ΔV_V = -0.30 + 0.40 = +0.10 В     [потенціал затвора під час імпульсу]
```

Хоча напруга `+0.10 В` формально нижча за паспортний поріг повного відмикання n-канального MOSFET (`V_th ≈ 0.55–0.65 В`), вона кардинально змінює провідність закритого каналу, переміщуючи транзистор у зону глибокого підпорогового витоку.

### 3. Експоненційний підпороговий витік та інтеграл струму розряду

У підпороговій області струм через канал MOSFET визначається дифузією носіїв заряду через знижений потенційний бар'єр біля витоку. Він експоненційно залежить від напруги затвор-витік `V_GS`, напруги стік-витік `V_DS` та зміщення підкладки `ΔV_body`:

```
I_sub(V_GS, V_DS) = I_0 · exp( (V_GS - V_th + η·V_DS + γ·ΔV_body) / (n · V_T) ) · ( 1 - exp( -V_DS / V_T ) )
```

У цій формулі задіяні ключові електрофізичні параметри кремнієвого каналу:
- `I_0` — опорний струм транзистора за умови `V_GS = V_th` (типовий порядок величини становить 10⁻⁷ А);
- `V_T = (k·T) / q` — термодинамічний потенціал, який при робочій температурі кристала 85°C (358 К) дорівнює приблизно 30.8 мВ;
- `n` — коефіцієнт підпорогової неідеальності переходу (для сучасних суб-20 нм каналів `n ≈ 1.35`);
- `η` — коефіцієнт зниження потенційного бар'єра стоком (*Drain-Induced Barrier Lowering*, DIBL), що лежить у межах від 0.08 до 0.12;
- `γ` — фактор впливу підкладки;
- `ΔV_body` — локальна флуктуація потенціалу підкладки.

Характеристикою чутливості підпорогової зони є підпороговий розмах напруги (*subthreshold swing* `S`), що позначає зміну напруги на затворі, необхідну для зміни струму витоку на один десятковий порядок:

```
S = ln(10) · n · V_T
  = 2.3026 · 1.35 · 0.0308 В                              [підстановка параметрів при 85°C]
  = 0.0957 В ≈ 95.7 мВ/дек                                [розмах підпорогової характеристики]
```

Оскільки наведений ємнісний стрибок зсуває затвор на величину `ΔV_V = 0.40 В`, кратність зростання підпорогового струму витоку `K_leak_sub` становить:

```
K_leak_sub = 10^( ΔV_V / S )
           = 10^( 0.400 / 0.0957 )                        [відношення імпульсу до розмаху]
           = 10^( 4.180 ) ≈ 15 135                        [прискорення витоку в 15 100 разів!]
```

Якщо в стані спокою статичний струм витоку закритого ключа не перевищує `I_leak_static = 0.8 фА` (0.8·10⁻¹⁵ А), то під час дії кожного імпульсу на лінії агресора цей струм миттєво зростає до рівня пікового імпульсу:

```
I_leak_pulse = I_leak_static · K_leak_sub
             = 0.8·10⁻¹⁵ А · 15 135 ≈ 12.11·10⁻¹² А = 12.11 пА [імпульсний струм витоку]
```

За час одного активного стану агресора `t_RAS ≈ 35 нс` через напіввідкритий канал транзистора встигає стекти імпульсна порція заряду `ΔQ_sub`:

```
ΔQ_sub = I_leak_pulse · t_RAS
       = 12.11·10⁻¹² А · 35·10⁻⁹ с                        [інтеграл струму за час активності]
       = 4.238·10⁻¹⁹ Кл = 0.4238 аКл                      [втрата заряду (аттокулони)]
```

### 4. Інжекція гарячих носіїв, струми в діелектрику та модулювання підкладки

Крім класичного канального витоку, комутація ліній із надкороткими фронтами (час наростання сигналу `t_edge` становить лише 1.0–1.5 нс) збуджує додаткові квантово-механічні та польові процеси.

Напруженість поперечного електричного поля в приповерхневому діелектрику під час комутації сягає критичних значень:

```
E_ox = ΔV_WL / d_ox = 3.3 В / (5.5·10⁻⁹ м) = 6.0·10⁸ В/м = 6.0 МВ/см [напруженість поля]
```

Під дією такого поля електрони набувають значної кінетичної енергії, формуючи популяцію так званих «гарячих електронів». Певна частка цих високоенергетичних носіїв долає потенційний бар'єр на межі кремній-діелектрик `Φ_B ≈ 3.15 еВ` і безпосередньо інжектується в об'єм вузла зберігання або оксид затвора. Відповідно до моделі Люкі (*Lucky-Electron Model*), густина струму інжекції гарячих носіїв виражається експонентою:

```
J_HCI = J_channel · C_inj · exp( -Φ_B / ( q · E_ox · λ_MFP ) ) [струм інжекції гарячих носіїв]
```

де `λ_MFP ≈ 6.5 нм` — середня довжина вільного пробігу електрона в кремнії між зіткненнями з фононами решітки.

Водночас у збідненій області стоку відбувається локальна ударна іонізація. Утворені дірки стікають у спільну p-кишеню підкладки, породжуючи імпульсний струм підкладки `I_well`. Оскільки кремнієва кишеня має кінцевий питомий опір розтікання `R_well ≈ 8 кОм`, протікання цього струму зміщує локальний потенціал тіла транзисторів (*body bounce*):

```
ΔV_body = I_well · R_well                                 [динамічний підскік потенціалу кишені]
```

Позитивне зміщення підкладки `ΔV_body ≈ 0.12 В` зменшує ширину збідненої області та викликає модуляцію порогової напруги `V_th` транзистора жертви:

```
ΔV_th = -γ · ( √( 2·|ϕ_F| ) - √( 2·|ϕ_F| - ΔV_body ) )    [зсув порогової напруги]
```

Для типових параметрів легування (`γ = 0.45 В^(1/2)` та потенціалу Фермі `2|ϕ_F| = 0.72 В`) обчислимо величину зниження порога:

```
ΔV_th = -0.45 · ( √(0.72) - √(0.72 - 0.12) )
      = -0.45 · ( 0.8485 - 0.7746 )
      = -0.45 · 0.0739 = -0.0333 В = -33.3 мВ             [зниження порога транзистора]
```

Це додаткове падіння порога збільшує підпорогову провідність у `K_body` разів:

```
K_body = 10^( |ΔV_th| / S )
       = 10^( 0.0333 / 0.0957 ) = 10^( 0.348 ) ≈ 2.228     [додатковий множник витоку x2.23]
```

Додатковим каналом деградації заряду є струм витоку, індукований затвором на стоці (*Gate-Induced Drain Leakage*, GIDL), та пастки в об'ємі високоефективних high-k діелектриків конденсатора (на основі оксидів цирконію та алюмінію ZrO₂/Al₂O₃/ZrO₂). У сильних полях виникає тунелювання за участю пасток (*Trap-Assisted Tunneling*, TAT), що додає фонову втрату заряду `δq_HCI ≈ 0.065 аКл` за кожен цикл.

Підсумовуючи всі складові, отримуємо сумарну втрату заряду `δq_pulse` за один одиночний цикл активації агресора:

```
δq_pulse = ΔQ_sub · K_body + δq_HCI
         = 0.4238 аКл · 2.228 + 0.0650 аКл                [сумарний імпульсний розряд]
         = 0.9442 аКл + 0.0650 аКл = 1.0092 аКл ≈ 1.01·10⁻¹⁸ Кл
```

### 5. Температурний розгін деградації за законом Арреніуса

Усі механізми витоку мають виражену нелінійну залежність від температури кристала. Термічна генерація електронно-діркових пар через глибокі рівні домішок у забороненій зоні кремнію (механізм Шоклі–Ріда–Холла) та підпорогова емісія підпорядковуються класичному закону Арреніуса з ефективною енергією активації `E_a ≈ 0.75 еВ`:

```
I_leak(T) = I_leak(T_0) · exp( ( E_a / k ) · ( 1 / T_0 - 1 / T ) ) [температурний розгін витоку]
```

Оцінимо зростання струму витоку при нагріванні чіпа пам'яті від кімнатної температури 25°C (298 К) до робочої температури під навантаженням 85°C (358 К):

```
Δ(1/T) = 1/298 - 1/358 = 0.003356 - 0.002793 = 0.000563 K⁻¹
E_a / k = ( 0.75 · 1.602·10⁻¹⁹ ) / ( 1.381·10⁻²³ ) ≈ 8700 K
K_temp  = exp( 8700 · 0.000563 ) = exp( 4.898 ) ≈ 134     [зростання витоку у 134 рази]
```

Зростання температури на кожні 10°C приблизно подвоює фоновий струм витоку. Це пояснює, чому за підвищених температур кристала критичний поріг стійкості до Rowhammer різко падає, а час утримання інформації скорочується.

### 6. Розрахунок критичного порога активацій

Знаючи максимально допустиму втрату заряду `Q_loss_max` та величину заряду, що втрачається за один імпульс `δq_pulse`, ми можемо точно визначити критичну кількість активацій `N_ACT_crit`, необхідну для спонтанного перекидання біта в односторонньому режимі (*Single-Sided Rowhammer*):

```
N_ACT_crit_single = Q_loss_max / δq_pulse
                  = ( 3.28 · 10⁻¹⁵ Кл ) / ( 1.01 · 10⁻¹⁸ Кл )  [ділення бюджету на втрату]
                  = 3 247 активацій                            [поріг одностороннього збурення]
```

У разі реалізації найбільш небезпечного шаблону — двосторонньої атаки (*Double-Sided Rowhammer*), коли рядок-жертва стиснутий між двома активними агресорами, збурення надходить почергово з обох ліній. Сумарна імпульсна втрата заряду подвоюється (`δq_double = 2 · δq_pulse`):

```
N_ACT_crit_double = Q_loss_max / ( 2 · δq_pulse )
                  = ( 3.28 · 10⁻¹⁵ ) / ( 2.02 · 10⁻¹⁸ )        [розрахунок для двох агресорів]
                  = 1 623 активації                            [поріг двосторонньої атаки]
```

### 7. Співвідношення з вікном регенерації

За стандартом комітету JEDEC для мікросхем DDR4 та DDR5 стандартний інтервал повної регенерації всіх рядків масиву становить `t_REFW = 64 мс` (або `32 мс` за підвищеної робочої температури вище 85°C).

Мінімально можливий інтервал між двома послідовними циклами активації одного банку пам'яті задається параметром часового циклу рядка `t_RC` (*Row Cycle time*):

```
t_RC = t_RAS + t_RP ≈ 35 нс + 15 нс = 50 нс               [мінімальний період циклу ACT+PRE]
```

Максимальна теоретична кількість циклів активації `N_max`, яку зловмисник може встигнути виконати в межах одного вікна регенерації тривалістю 64 мс, дорівнює:

```
N_max = t_REFW / t_RC
      = ( 64 · 10⁻³ с ) / ( 50 · 10⁻⁹ с )                 [розрахунок граничної місткості]
      = 1 280 000 активацій                               [максимальне число активацій]
```

Порівняємо максимальну кількість можливих звернень із критичним порогом руйнування біта через індекс вразливості `K_attack`:

```
K_attack = N_max / N_ACT_crit_double
         = 1 280 000 / 1 623                              [відношення можливостей до порога]
         = 788.6                                          [перевищення порога майже у 800 разів!]
```

Оскільки індекс `K_attack` сягає сотень одиниць, атакуючий процес має колосальний запас надійності: навіть за наявності арбітражу шини пам'яті та накладних витрат процесорного конвеєра для гарантованого перекидання біта потрібно використати менше 0.15% часового вікна регенерації.

### 8. Асиметрія комірок: фізика інверсії бітів у топології True-Cell та Anti-Cell

Важливою математичною особливістю збоїв Rowhammer є їхня виражена спрямованість (*bit-flip directionality*). У фізичній реалізації DRAM не всі логічні одиниці кодуються однаковою фізичною напругою на конденсаторі.

З метою мінімізації паразитної ємнісної взаємодії між сусідніми розрядними лініями (*Bitlines*) виробники застосовують чергування полярності кодування. Масив поділяється на два типи фізичних комірок:
1. **Прямі комірки (True-Cells):** Логічна «1» кодується високою напругою `V_cell = V_DD` (наявність заряду на конденсаторі), а логічний «0» — нульовим потенціалом `V_cell = 0 В` (розряджений конденсатор).
2. **Інверсні комірки (Anti-Cells):** Логічна «1» кодується нульовим потенціалом `V_cell = 0 В`, тоді як логічний «0» кодується напругою заряду `V_cell = V_DD`.

Оскільки фізичний вплив Rowhammer завжди призводить до деградації накопиченого заряду (тобто розряджає конденсатор через підпороговий витік у напрямку опорного рівня підкладки або бітової лінії), полярність перекидання бітів у логічному просторі процесора залежить від типу комірки:

```
Тип комірки   Початковий стан   Фізична напруга  Напрямок витоку   Результат збою Rowhammer
─────────────────────────────────────────────────────────────────────────────────────────────
True-Cell     Логічна «1»       V_cell = V_DD    V_cell → 0 В      Інверсія 1 → 0
True-Cell     Логічний «0»      V_cell = 0 В     Без витоку заряду Стійкий (збою немає)
Anti-Cell     Логічна «1»       V_cell = 0 В     Без витоку заряду Стійкий (збою немає)
Anti-Cell     Логічний «0»      V_cell = V_DD    V_cell → 0 В      Інверсія 0 → 1
```

Звідси випливає важливий практичний наслідок для створення експлойтів: зловмисник не може довільно інвертувати біти в обох напрямках у межах однієї комірки. Для перекидання біта комірка повинна обов'язково перебувати у фізично зарядженому стані. Саме тому алгоритми тестування та атаки спеціально підбирають шаблони заповнення пам'яті (шахові патерни `0xAA` або `0x55`, суцільні `0xFF` або `0x00`), що максимізують кількість фізично заряджених конденсаторів у рядках-жертвах.

### 9. Еволюція критичного порога при масштабуванні техпроцесу

Аналіз фізичних параметрів комірок пам'яті різних поколінь наочно ілюструє, як зменшення технологічних норм спровокувало перехід кількісних змін у якісну системну кризу:

```
Вузол     Рік    Ємність C_S  Відстань d_WL  ΔV_WL  N_ACT_crit (Double-Sided)  Статус
─────────────────────────────────────────────────────────────────────────────────────────────
50 нм     2008   35 фФ        48 нм          3.8 В  > 120 000                  Стійкий
30 нм     2012   24 фФ        30 нм          3.5 В  ≈ 55 000                   Рідкісні збої
2x нм     2015   16 фФ        22 нм          3.3 В  ≈ 18 000                   Масова вразливість
1x нм     2018   12 фФ        17 нм          3.1 В  ≈ 8 500                    Критична зона
1y/1z нм  2021   10 фФ        14 нм          2.9 В  ≈ 3 200                    Вразливість 100%
1a/1b нм  2024    8 фФ        11 нм          2.7 В  < 1 800                    Субкритичний режим
```

Геометричне стиснення структури випередило зниження напруги живлення. У результаті питома напруженість електричних полів та взаємна ємність ліній зросли, а запас утримуваного заряду зменшився у 4.5 раза, спричинивши лавиноподібне падіння стійкості комірок DRAM до ефекту Rowhammer.
