# 🧮 Фізика розподілу заряду та межа чутливості DRAM

У комірці динамічної пам'яті 1T1C біт інформації існує виключно у вигляді електричного заряду на крихітному конденсаторі. Під час операції зчитування цей заряд не посилюється локально в самій комірці, а просто перерозподіляється між конденсатором зберігання та металевою лінією стовпця — бітовою лінією (*Bitline*). Розгляньмо строгий математичний апарат, який визначає величину корисного диференціального сигналу на вході підсилювача зчитування, динаміку перехідних процесів, структуру компонентів паразитної ємності, регенераційне підсилення тригера, придушення синфазних завад у складеній бітовій лінії, стійкість до радіаційних збоїв та фізичну причину, чому ємність комірки ніколи не опускається нижче порога 25–30 фемтофарад.

### Виведення рівняння перерозподілу заряду

Перед початком операції зчитування бітова лінія розривається з джерелом живлення та передзаряджається до проміжного опорного потенціалу, який зазвичай дорівнює половині напруги живлення ядра пам'яті:

```
V_pre = V_DD / 2
```

Паразитна ємність бітової лінії `C_BL` утворюється сумою ємностей металевої доріжки на діелектрику та p-n переходів усіх витоків транзисторів доступу, підімкнених до цієї лінії (зазвичай 256 або 512 комірок на один підсилювач). Початковий електричний заряд на розподіленій ємності бітової лінії становить:

```
Q_BL = C_BL · V_pre
= C_BL · (V_DD / 2)              [підстановка потенціалу передзаряду]
```

Конденсатор зберігання комірки `C_s` зберігає напругу `V_cell`, яка залежно від записаного біта становить:
- для логічної одиниці («1»): `V_cell = V_DD`;
- для логічного нуля («0»): `V_cell = 0`.

Початковий заряд на конденсаторі комірки:

```
Q_s = C_s · V_cell
```

Коли лінія слова (*Wordline*) переходить у високий потенціал, транзистор доступу відкривається. Відбувається безпосереднє електричне з'єднання двох паралельних ємностей: ємності комірки `C_s` та паразитної ємності бітової лінії `C_BL`. За фундаментальним законом збереження електричного заряду сумарний заряд ізольованої системи залишається незмінним:

```
Q_total = Q_BL + Q_s
= C_BL · V_pre + C_s · V_cell      [сума початкових зарядів двох ємностей]
= (C_BL + C_s) · V_final          [еквівалентний заряд системи після вирівнювання потенціалів]
```

Виразимо кінцевий рівноважний потенціал бітової лінії `V_final`:

```
V_final
= (C_BL · V_pre + C_s · V_cell) / (C_BL + C_s)                  [поділили сумарний заряд на сумарну ємність]
= (C_BL · V_pre) / (C_BL + C_s) + (C_s · V_cell) / (C_BL + C_s)  [розкрили суму в чисельнику]
```

Корисний сигнал `ΔV_BL`, який фіксує підсилювач зчитування як зсув від початкового рівня передзаряду, дорівнює різниці між кінцевою та початковою напругою:

```
ΔV_BL
= V_final - V_pre                                                [означення стрибка напруги]
= (C_BL · V_pre + C_s · V_cell) / (C_BL + C_s) - V_pre           [підставили вираз для V_final]
= (C_BL · V_pre + C_s · V_cell - (C_BL + C_s) · V_pre) / (C_BL + C_s) [звели до спільного знаменника]
= (C_s · V_cell - C_s · V_pre) / (C_BL + C_s)                    [скоротили добуток C_BL · V_pre]
= (C_s / (C_BL + C_s)) · (V_cell - V_pre)                        [винесли C_s за дужки]
```

Поділимо чисельник і знаменник першого множника на `C_s`:

```
ΔV_BL
= ((C_s / C_s) / ((C_BL + C_s) / C_s)) · (V_cell - V_pre)       [ділення чисельника і знаменника на C_s]
= (1 / (1 + C_BL / C_s)) · (V_cell - V_pre)                      [спрощення дробу]
```

Підставимо значення для читання логічної одиниці (`V_cell = V_DD`, `V_pre = V_DD / 2`):

```
ΔV_BL_1
= (1 / (1 + C_BL / C_s)) · (V_DD - V_DD / 2)                     [підставили рівні напруг для логічної одиниці]
= + (V_DD / 2) · (1 / (1 + C_BL / C_s))                          [отримали позитивний зсув сигналу]
```

Аналогічно, для читання логічного нуля (`V_cell = 0`, `V_pre = V_DD / 2`):

```
ΔV_BL_0
= (1 / (1 + C_BL / C_s)) · (0 - V_DD / 2)                        [підставили рівні напруг для логічного нуля]
= - (V_DD / 2) · (1 / (1 + C_BL / C_s))                          [отримали негативний зсув сигналу]
```

### Фізичний глухий кут: аналітична декомпозиція C_BL

Отриманий вираз демонструє ключову залежність сигналу зчитування від коефіцієнта ємнісного ділення:

```
k_div = 1 / (1 + C_BL / C_s)
```

Паразитна ємність бітової лінії `C_BL` складається з трьох фізично незалежних компонентів, що визначаються геометрією та легуванням:

```
C_BL = C_junction_total + C_wire_ground + C_coupling
```

Розгляньмо математичний опис кожного доданка:

1. **Бар'єрна ємність p-n переходів (*C_junction_total*):**
До бітової лінії підімкнено витоки `N = 256..512` транзисторів доступу. Бар'єрна ємність одного зворотного p-n переходу залежить від прикладеної зворотної напруги зміщення `V_R`:

```
C_j = (A_j · ε_Si) / W_dep + P_j · C_jsw
```
де `W_dep = √((2 · ε_Si · (V_bi + V_R)) / (q · N_A))` — ширина збідненої області переходу, `A_j` — площа донного переходу, `P_j` — периметр бічних стінок витоку, `C_jsw` — питома ємність бічних стінок. Для `N = 512` сумарний внесок становить `C_junction_total ≈ 60–80 фФ`.

2. **Власна ємність металевого провідника на підкладку (*C_wire_ground*):**
Включає плоску ємність провідника шириною `W` над діелектриком товщиною `H` та ємність крайових полів розсіювання (*Fringe Capacitance*):

```
C_wire_ground = L_BL · ε_ILD · (W / H + 2 · π / ln(1 + 2 · H / T_wire))
```
Для довжини лінії `L_BL ≈ 30–50 мкм` цей компонент становить близько `30–45 фФ`.

3. **Перехресна міжделінійна ємність (*C_coupling / C_cc*):**
При зменшенні відстані `S` між сусідніми паралельними бітовими лініями нижче 30 нм зростає бічна ємність:

```
C_coupling = 2 · L_BL · ε_ILD · (T_wire / S)
```
де `T_wire` — товщина металевої доріжки бітової лінії. У щільних нанометрових масивах `C_coupling` сягає `30–50 фФ`, складаючи до 30% усієї паразитної ємності.

У сумі паразитна ємність лінії становить `C_BL ≈ 120–200 фФ`, що зумовлює жорстке співвідношення `C_BL / C_s ≈ 6..8`.

Обчислимо амплітуду корисного сигналу `ΔV_BL` при напрузі живлення `V_DD = 1.0 В`, `C_s = 25 фФ` та `C_BL = 150 фФ`:

```
C_BL / C_s
= 150 фФ / 25 фФ                                                 [підставили значення ємностей]
= 6                                                              [відношення паразитної ємності до ємності комірки]
```

```
V_DD / 2
= 1.0 В / 2                                                      [напруга передзаряду]
= 500 мВ                                                         [рівень передзаряду в мілівольтах]
```

```
ΔV_BL
= 500 мВ / (1 + 6)                                               [підставили коефіцієнт ділення]
= 500 мВ / 7                                                     [розрахунок знаменника]
≈ 71.4 мВ                                                        [амплітуда диференціального сигналу]
```

Стрибок напруги на бітовій лінії становить усього близько `70 мВ`. Цей крихітний імпульс має надійно змусити симетричний тригер підсилювача зчитування перекинутися у правильний стан.

### Динаміка перехідного процесу: RC-затримка встановлення сигналу

Перерозподіл заряду відбувається не миттєво. Еквівалентна електрична схема містить опір відкритого каналу транзистора доступу `R_on` (зазвичай близько `5–10 кОм`), опір металевої бітової лінії `R_BL` (близько `1–2 кОм` на всю довжину стовпця) та ємності `C_s` і `C_BL`.

За моделлю затримок Елмора (*Elmore Delay*), еквівалентна стала часу встановлення заряду на бітовій лінії описується співвідношенням:

```
τ_transfer = R_on · C_s + (R_on + R_BL / 2) · C_BL
```

Розрахуємо тривалість передачі заряду для типових параметрів нанометрової комірки (`R_on = 8 кОм`, `R_BL = 1.5 кОм`, `C_s = 25 фФ`, `C_BL = 150 фФ`):

```
τ_transfer
= 8 · 10³ · 25 · 10⁻¹⁵ + (8 · 10³ + 0.75 · 10³) · 150 · 10⁻¹⁵  [підставили опори та ємності]
= 2 · 10⁻¹⁰ + 8.75 · 10³ · 150 · 10⁻¹⁵                          [обчислення першого доданка]
= 0.2 · 10⁻⁹ + 1.31 · 10⁻⁹                                       [обчислення другого доданка]
≈ 1.51 нс                                                        [еквівалентна стала часу перерозподілу]
```

Щоб сигнал на вході підсилювача зчитування досяг 98% від свого теоретичного максимального значення `ΔV_BL`, необхідно почекати інтервал часу:

```
t_settle
= 4 · τ_transfer                                                 [інтервал досягнення 98% амплітуди експоненти]
= 4 · 1.51 нс                                                    [множення на сталу часу]
≈ 6.0 нс                                                         [тривалість фази зчитування до увімкнення підсилювача]
```

Ці шість наносекунд формують фундаментальний фізичний внесок у затримку активації рядка пам'яті (*Row-to-Column Delay, tRCD*). Якщо зменшити ємність комірки, відношення опорів і ємностей спотворюється, а відносний вплив паразитних шумів лінії під час перехідного процесу багаторазово зростає.

### Динаміка регенераційного підсилення тригера

Після того як на бітовій лінії встановився первинний стрибок `ΔV_BL`, контролер вмикає живлення диференціального тригера підсилювача зчитування. Підсилювач складається з пари взаємозв'язаних інверторів, які охоплені сильним позитивним зворотним зв'язком.

Диференціальна напруга між лініями `v_diff(t) = v_BL(t) - v_BL_bar(t)` на початковому етапі підсилення наростає за експоненційним законом:

```
v_diff(t) = ΔV_BL · exp(t / τ_latch)
```
де `τ_latch = C_BL / g_m` — регенеративна стала часу тригера, `g_m` — крутизна характеристики польових транзисторів підсилювача (типово `g_m ≈ 0.5–1.0 мСм`).

Розрахуємо тривалість повного відновлення рівнів `t_restore` до напруги живлення `V_DD = 1.0 В`:

```
t_restore
= τ_latch · ln(V_DD / ΔV_BL)                                     [логарифмічний час регенерації тригера]
= (C_BL / g_m) · ln(V_DD / ΔV_BL)                                [підстановка сталої часу тригера]
```

Підставимо чисельні параметри (`C_BL = 150 фФ`, `g_m = 0.8 мСм`, `ΔV_BL = 71.4 мВ`):

```
τ_latch
= 150 · 10⁻¹⁵ Ф / (0.8 · 10⁻³ А/В)                               [розрахунок сталої часу]
≈ 0.188 нс                                                       [стала часу тригера]
```

```
t_restore
= 0.188 нс · ln(1.0 В / 0.0714 В)                                [підстановка значень напруг]
= 0.188 нс · ln(14.0)                                            [обчислення відношення напруг]
= 0.188 нс · 2.64                                                [обчислення натурального логарифма]
≈ 0.50 нс                                                        [час регенерації повного розмаху сигналу]
```

Якщо ж через зменшення ємності комірки сигнал впаде до `ΔV_BL = 10 мВ`, тривалість регенерації зросте:

```
t_restore_10mV
= 0.188 нс · ln(1.0 В / 0.010 В)                                 [час підсилення для малого сигналу]
= 0.188 нс · ln(100.0)                                           [відношення зросло до 100]
= 0.188 нс · 4.61                                                [логарифм від 100]
≈ 0.87 нс                                                        [зростання часу відновлення майже вдвічі]
```

Це математично доводить, що мала ємність комірки `C_s` не лише погіршує надійність, але й суттєво сповільнює швидкість регенерації та тактову частоту пам'яті.

### Придушення синфазного шуму: відкрита проти складеної бітової лінії

Величина корисного сигналу `ΔV_BL ≈ 70 мВ` є настільки малою, що будь-яка зовнішня завада може спотворити результат зчитування. У схемотехніці DRAM існують дві конфігурації підключення бітових ліній до диференціального підсилювача: **відкрита бітова лінія** (*Open Bitline*) та **складена бітова лінія** (*Folded Bitline*).

У конфігурації відкритої лінії пряма бітова лінія `BL` знаходиться в одному блоці масиву, а інверсна референтна лінія `BL_bar` — у сусідньому незалежному блоці. Коли активується лінія слова, паразитний ємнісний зв'язок між лінією слова та бітовою лінією індукує стрибок напруги `V_noise_wl`. Оскільки референтна лінія знаходиться в іншому блоці, де лінія слова не перемикається, завада потрапляє лише на одну лінію:

```
V_diff_open
= (V_pre + ΔV_BL + V_noise_wl) - V_pre                           [диференціальний сигнал у відкритій лінії]
= ΔV_BL + V_noise_wl                                             [завада додається безпосередньо до сигналу]
```

Якщо `V_noise_wl ≈ 40 мВ`, вона здатна повністю знищити корисний сигнал `ΔV_BL = 70 мВ`.

Для усунення цієї проблеми застосовують архітектуру складеної бітової лінії (*Folded Bitline*). У ній обидва провідники пари `BL` та `BL_bar` прокладаються паралельно поруч один з одним в одному блоці пам'яті. Лінія слова перетинає обидва провідники, завдяки чому паразитні ємності `C_wl_bl` та `C_wl_blbar` є строго ідентичними.

При активації лінії слова синфазна завада `V_noise_cm` наводиться на обидві лінії з однаковою амплітудою. Диференціальний вхід підсилювача віднімає напруги ліній:

```
V_diff_folded
= (V_pre + ΔV_BL + V_noise_cm) - (V_pre + V_noise_cm)            [диференціальний сигнал у складеній лінії]
= V_pre + ΔV_BL + V_noise_cm - V_pre - V_noise_cm                [розкриття дужок]
= ΔV_BL                                                          [повне придушення синфазного шуму]
```

Завдяки цьому коефіцієнт придушення синфазного сигналу (*Common-Mode Rejection Ratio*, CMRR) у диференціальному підсилювачі зі складеними лініями перевищує 40 дБ, забезпечуючи надійне зчитування сигналу навіть в умовах потужних комутаційних завад на чіпі.

### Теоретичний аналіз статистичної асиметрії підсилювача

Підсилювач зчитування DRAM будується за схемою диференціального тригера на перехресно сполучених CMOS-інверторах. В ідеальному математичному симетричному підсилювачі порогові напруги транзисторів n-типу `V_th_n1` та `V_th_n2` є абсолютно однаковими. Проте в реальному нанометровому кремнії кількість атомів легуючої домішки в каналі транзистора становить усього кілька сотень штук.

Через дискретну природу легування кількість і просторовий розподіл іонів домішки в каналі підпорядковуються закону Пуассона. Це явище має назву статистичної флуктуації кількості домішок (*Random Dopant Fluctuation*, RDF). Стандартне відхилення порогової напруги двох сусідніх транзисторів описується фундаментальним законом Пелгрома (*Pelgrom's Law*):

```
σ(ΔV_th) = A_VT / √(W · L)
```
де `A_VT` — коефіцієнт Пелгрома для даного техпроцесу (типово `1.5–2.5 мВ·мкм`), `W` — ширина каналу транзистора, `L` — довжина каналу.

Для транзисторів підсилювача зчитування з геометрією `W = 60 нм`, `L = 40 нм` площа каналу становить `W · L = 0.0024 мкм²`. Розрахуємо середньоквадратичну асиметрію порога:

```
σ(ΔV_th)
= 2.0 мВ·мкм / √(0.0024 мкм²)                                    [підставили коефіцієнт Пелгрома та площу каналу]
= 2.0 / 0.049                                                    [обчислення кореня з площі]
≈ 40.8 мВ                                                        [середньоквадратичний розкид порогових напруг]
```

У мікросхемі пам'яті ємністю 16 гігабіт працюють десятки мільйонів підсилювачів зчитування. Щоб частка бракованих комірок на чіпі не перевищувала допустимої норми (вимога надійності на рівні шести сигм, `6σ`), максимальне зміщення нуля підсилювача (*Sense Amplifier Offset Voltage*) оцінюється як:

```
V_offset_max
= 3 · σ(ΔV_th)                                                   [критерій надійності тригерної схеми]
≈ 3 · 10 мВ                                                      [з урахуванням спеціальних схем автокалібрування порога]
= 30 мВ                                                          [гарантоване статистичне зміщення порога]
```

### Тепловий шум k_B·T/C на розподіленій ємності

Коли вимикач схеми передзаряду розмикається, на розподіленій ємності бітової лінії `C_BL` фіксується термодинамічний рівноважний тепловий шум (шум Джонсона-Найквіста). За теоремою про рівнорозподіл енергії середня теплова енергія коливань заряду на ємності дорівнює:

```
(1 / 2) · C_BL · ⟨V_noise²⟩ = (1 / 2) · k_B · T
```

Звідси середньоквадратична напруга теплового шуму становить:

```
V_thermal = √(k_B · T / C_BL)
```
де `k_B = 1.38 · 10⁻²³ Дж/К` — стала Больцмана, `T = 358 К` (температура кристала +85 °C при типовому навантаженні), `C_BL = 150 фФ`:

```
k_B · T
= 1.38 · 10⁻²³ Дж/К · 358 К                                      [термічна енергія при 85 градусах Цельсія]
≈ 4.94 · 10⁻²¹ Дж                                                [енергія теплового руху]
```

```
V_thermal
= √(4.94 · 10⁻²¹ Дж / (150 · 10⁻¹⁵ Ф))                           [підставили термічну енергію та ємність лінії]
= √(3.29 · 10⁻⁷ В²)                                              [обчислення відношення під коренем]
≈ 0.57 мВ                                                        [середньоквадратична амплітуда теплового шуму]
```

З урахуванням пікового викиду амплітуди шумів у часі максимальний миттєвий тепловий шум оцінюється величиною:

```
V_thermal_peak
= 3 · V_thermal                                                  [три сигми теплового шуму]
≈ 3 · 0.57 мВ                                                    [множення на піковий фактор]
≈ 1.7 мВ                                                         [пікова амплітуда теплового шуму]
```

### Повний баланс шумів і доведення межі ємності

Підсумуємо всі паразитні фактори, які протидіють корисному сигналу `ΔV_BL`:
1. Статистичне зміщення порога транзисторів підсилювача: `V_offset ≈ 30 мВ`.
2. Піковий тепловий шум передзаряду: `V_thermal_peak ≈ 1.7 мВ`.
3. Перехресні ємнісні наводки від перемикання сусідніх ліній стовпців: `V_crosstalk ≈ 18 мВ`.
4. Падіння потенціалу на паразитних опорах шин живлення та розсіювання заряду: `V_margin ≈ 15 мВ`.

```
V_noise_total
= V_offset + V_thermal_peak + V_crosstalk + V_margin             [сума всіх шумових і статистичних складових]
= 30 мВ + 1.7 мВ + 18 мВ + 15 мВ                                 [підставили чисельні значення складових]
= 64.7 мВ                                                        [сумарний шумовий поріг детектування]
```

Корисний сигнал `ΔV_BL` зобов'язаний перевищувати сумарний шумовий поріг:

```
ΔV_BL > V_noise_total ≈ 65 мВ
```

Розгляньмо наслідок зменшення ємності комірки з `25 фФ` до `10 фФ` при незмінній паразитній ємності бітової лінії `C_BL = 150 фФ`:

```
k_div_10fF
= 1 / (1 + 150 фФ / 10 фФ)                                       [підставили зменшену ємність комірки]
= 1 / (1 + 15)                                                   [розрахунок відношення ємностей]
= 1 / 16                                                         [коефіцієнт ділення сигналу]
```

```
ΔV_BL_10fF
= 500 мВ · (1 / 16)                                              [розрахунок стрибка напруги]
= 31.25 мВ                                                       [отриманий сигнал при ємності 10 фФ]
```

Отримане значення `31.25 мВ` є більш ніж удвічі меншим за поріг шумів `64.7 мВ`. За такої ємності підсилювач не зможе визначити стан комірки, і мікросхема втратить працездатність.

### Відношення сигнал/шум (SNR) масиву пам'яті

Для оцінки стійкості тракту зчитування розрахуємо відношення сигнал/шум (*Signal-to-Noise Ratio*, SNR) у децибелах:

```
SNR = 20 · log_10(ΔV_BL / V_noise_total)
```

Для стандартної ємності комірки `C_s = 25 фФ` (`ΔV_BL = 71.4 мВ`, `V_noise_total = 64.7 мВ`):

```
SNR_25fF
= 20 · log_10(71.4 мВ / 64.7 мВ)                                 [підставили корисний сигнал та шум]
= 20 · log_10(1.103)                                             [обчислення відношення]
= 20 · 0.0428                                                    [обчислення десяткового логарифма]
≈ +0.86 дБ                                                       [позитивний запас сигналу над сумарним шумом]
```

Для зменшеної ємності `C_s = 10 фФ` (`ΔV_BL = 31.25 мВ`, `V_noise_total = 64.7 мВ`):

```
SNR_10fF
= 20 · log_10(31.25 мВ / 64.7 мВ)                                [підставили сигнал для 10 фФ]
= 20 · log_10(0.483)                                             [обчислення відношення]
= 20 · (-0.316)                                                  [обчислення логарифма]
≈ -6.32 дБ                                                       [глибоко від'ємний баланс: сигнал потонув у шумі]
```

Від'ємне значення SNR означає статистичний колапс достовірності зчитування даних.

### Критичний заряд Q_crit та стійкість до радіаційних збоїв

Окрім схемотехнічних шумів, ємність `C_s` безпосередньо визначає чутливість пам'яті до одиночних радіаційних збоїв (*Soft Error Rate*, SER). Радіаційні збої викликаються альфа-частинками природного розпаду мікродомішок у кремнії та корпусі мікросхеми, а також високоенергетичними нейтронами космічних променів.

Коли високоенергетична частинка пролітає крізь кристал, вона іонізує атоми кремнію вздовж свого треку, утворюючи електронно-діркові пари. Лінійні втрати енергії (*Linear Energy Transfer*, LET) для альфа-частинки з енергією 5 МеВ генерують уздовж треку довжиною 10 мкм сумарний заряд близько `Q_gen ≈ 25–40 фКл`.

Критичний заряд `Q_crit`, який може призвести до спонтанного перекидання логічного стану комірки («1» перетворюється на «0» або навпаки), розраховується як:

```
Q_crit = C_s · (V_DD / 2)
```

Обчислимо критичний заряд для комірки `C_s = 25 фФ` при `V_DD = 1.0 В`:

```
Q_crit_25fF
= 25 · 10⁻¹⁵ Ф · 0.5 В                                           [підставили ємність і напіврозмах напруги]
= 12.5 · 10⁻¹⁵ Кл                                                [обчислення добутку]
= 12.5 фКл                                                       [критичний заряд збереження інформації]
```

Згенерований частинкою заряд розтікається по кристалу, і конденсатор комірки збирає лише його частку (коефіцієнт збору `η_coll ≈ 0.2–0.3`):

```
Q_collected
= η_coll · Q_gen                                                 [заряд, захоплений вузлом зберігання]
≈ 0.25 · 35 фКл                                                  [підставили коефіцієнт збору та згенерований заряд]
≈ 8.75 фКл                                                       [зібраний паразитний заряд]
```

Оскільки `Q_collected = 8.75 фКл < Q_crit = 12.5 фКл`, комірка успішно утримує свій стан, і бітова помилка не виникає.

Якщо ж зменшити ємність конденсатора до `C_s = 10 фФ`:

```
Q_crit_10fF
= 10 · 10⁻¹⁵ Ф · 0.5 В                                           [розрахунок для зменшеної ємності]
= 5.0 фКл                                                        [критичний заряд при 10 фФ]
```

У цьому випадку зібраний заряд `Q_collected = 8.75 фКл > Q_crit = 5.0 фКл`, що призводить до миттєвого інвертування біта. Інтенсивність збоїв пам'яті зростає на чотири порядки, перевищуючи допустимий рівень надійності в дата-центрах та авіаційній електроніці.

### Термодинамічна модель Арреніуса для часу утримання заряду

Струми витоку напівпровідникових p-n переходів транзистора доступу та термоелектронна емісія діелектрика конденсатора демонструють сильну експоненційну залежність від температури, яка описується рівнянням Арреніуса:

```
I_leak(T) = I_0 · exp(-E_a / (k_B · T))
```
де `E_a` — енергія активації процесу витоку (для генераційно-рекомбінаційних струмів у кремнії `E_a ≈ 0.6–0.7 еВ`, для емісії Шотткі `E_a ≈ 1.2–1.4 еВ`), `k_B = 8.617 · 10⁻⁵ еВ/К` — стала Больцмана в електрон-вольтах на кельвін.

Порівняємо струм витоку при кімнатній температурі `T_1 = 300 К` (+27 °C) та при робочій температурі серверного процесора `T_2 = 368 К` (+95 °C) для `E_a = 0.65 еВ`:

```
I_leak(T_2) / I_leak(T_1)
= exp((-E_a / k_B) · (1 / T_2 - 1 / T_1))                        [відношення струмів за законом Арреніуса]
= exp((-0.65 / (8.617 · 10⁻⁵)) · (1 / 368 - 1 / 300))            [підставили енергію активації та температури]
= exp(-7543 · (0.002717 - 0.003333))                             [обчислення різниці обернених температур]
= exp(-7543 · (-0.000616))                                       [множення коефіцієнтів]
= exp(4.646)                                                     [значення експоненти]
≈ 104.2                                                          [зростання струму витоку у 104 рази]
```

Зростання температури до +95 °C збільшує струм витоку більш ніж у сто разів. Відповідно, час утримання заряду `t_ret` катастрофічно падає:

```
t_ret(95°C) = t_ret(27°C) / 104
```

За стандартом JEDEC період регенерації рядка при робочій температурі кристала до +85 °C становить `t_REFI = 64 мс`. Звідси визначимо максимально допустимий сумарний струм витоку для комірки з ємністю `C_s = 25 фФ`:

```
I_leak_max
= (C_s · ΔV_crit) / t_REFI                                       [вираз для максимально допустимого струму витоку]
= (25 · 10⁻¹⁵ Ф · 0.2 В) / (64 · 10⁻³ с)                         [підставили параметри ємності, напруги та часу]
= 5 · 10⁻¹⁵ Кл / 0.064 с                                         [обчислення заряду в чисельнику]
≈ 7.8 · 10⁻¹⁴ А                                                  [допустимий струм витоку в амперах]
= 78 фА                                                          [допустимий струм витоку в фемтоамперах]
```

Якщо припустити зменшення ємності комірки до `C_s = 5 фФ`, допустимий струм витоку зменшиться пропорційно:

```
I_leak_max_5fF
= (5 · 10⁻¹⁵ Ф · 0.2 В) / (64 · 10⁻³ с)                          [підставили зменшену ємність 5 фФ]
= 1 · 10⁻¹⁵ Кл / 0.064 с                                         [обчислення заряду]
≈ 1.56 · 10⁻¹⁴ А                                                 [допустимий струм витоку для 5 фФ]
= 15.6 фА                                                        [допустимий струм у фемтоамперах]
```

Утримати струм витоку нанометрового транзистора та квантово-тонкого діелектрика на рівні менше `15 фА` при температурі +85 °C фізично неможливо через термоемісію та дефекти ґратки.

Математичний аналіз доводить: величина ємності комірки `C_s ≥ 25–30 фФ` є абсолютною фізичною константою схемотехніки DRAM. Масштабування площі комірки вимагає еквівалентного вертикального росту 3D-структур або пропорційного зростання діелектричної проникності, щоб зберегти цей інваріант незмінним.
