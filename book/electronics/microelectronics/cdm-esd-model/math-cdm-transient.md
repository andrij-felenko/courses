# 🧮 Аналітична динаміка CDM-розряду: RLC-контур, хвильові процеси та перенапруга затвора

Математичний аналіз моделі зарядженого пристрою (Charged Device Model, CDM) описує точний розрахунок субнаносекундних перехідних процесів: аналітичний розв'язок диференціальних рівнянь розрядного контуру, знаходження пікового струму, максимальної швидкості наростання `di/dt`, енергетичного балансу, нелінійної динаміки іскрового каналу, спектрального розподілу Фур'є, перехідної функції дворівневої захисної мережі, хвильових відбиттів на довгих лініях, міждоменної динаміки зв'язаних контурів та статистичної надійності пробою діелектрика за розподілом Вейбулла.

---

## 1. Еквівалентна RLC-модель розрядного контуру

У моделі зарядженого приладу накопичений електростатичний заряд `Q_0` зосереджений на паразитній ємності кристала, металізації та корпусу відносно заземленого середовища `C_pkg`. У момент утворення субміліметрової повітряної іскри між тестованим виводом мікросхеми та заземленою площиною утворюється замкнений розрядний контур другого порядку.

Параметри розрядного контуру:
- `C_pkg` — ефективна паразитна ємність корпусу і підкладки кристала на землю (типово 1–15 пФ);
- `L_loop` — повна паразитна індуктивність розрядного шляху, що включає індуктивність виводу, внутрішньої розварки або мікростовпчика (англ. *microbump*) та іскрового проміжку (типово 0.5–4.0 нГн);
- `R_loop` — сумарний активний опір контуру, що складається з динамічного опору плазмового каналу іскри `R_spark(t)` та омічного опору металізації кристала і вивідної рамки `R_metal ≈ 0.5–2 Ом`.

Диференціальне рівняння балансу напруг у контурі за другим законом Кірхгофа відносно миттєвого заряду `q(t)` на ємності `C_pkg`:

```
L_loop · (d²q(t) / dt²) + R_loop · (dq(t) / dt) + q(t) / C_pkg = 0
```

Початкові умови в момент виникнення іскрового розряду (`t = 0`):

```
q(0) = Q_0 = C_pkg · V_0       [початковий заряд за напруги заряджання V_0]
i(0) = (dq / dt)|_{t=0} = 0    [струм розряду в початковий момент дорівнює нулю]
```

Введемо фундаментальні характеристики лінійної коливальної системи:
- власна кутова частота коливань: `ω_0 = 1 / √(L_loop · C_pkg)`
- коефіцієнт згасання: `α = R_loop / (2 · L_loop)`
- характеристичний (хвильовий) опір: `Z_0 = √(L_loop / C_pkg)`
- коефіцієнт затухання контуру (добротність): `Q_factor = ω_0 / (2 · α) = Z_0 / R_loop`

## 2. Аналітичний розв'язок для слабозгасаючого режиму

Для реальних інтегральних схем хвильовий опір розрядного контуру перевищує активний опір втрат. Наприклад, при `L_loop = 2 нГн` та `C_pkg = 4 пФ`:

```
Z_0 = √(L_loop / C_pkg)
Z_0 = √(2 × 10⁻⁹ Гн / (4 × 10⁻¹² Ф))
Z_0 = √500 ≈ 22.36 Ом
```

Критичний опір згасання контуру:

```
R_crit = 2 · Z_0 = 2 · 22.36 Ом ≈ 44.72 Ом
```

Оскільки сумарний опір розрядного кола `R_loop ≈ 8–12 Ом` є значно меншим за `R_crit`, система перебуває у **слабозгасаючому коливальному режимі** (`α < ω_0`).

Частота згасаючих коливань розрядного струму:

```
ω_d = √(ω_0² − α²)
```

Характеристичне алгебраїчне рівняння для розв'язку диференціального рівняння:

```
s² + 2·α·s + ω_0² = 0          [характеристичне рівняння]
s_{1,2} = −α ± j·ω_d          [комплексно-спряжені корені]
```

Загальний розв'язок для заряду `q(t)`:

```
q(t) = e^(−α·t) · [A · cos(ω_d·t) + B · sin(ω_d·t)]
```

Визначимо константи `A` та `B` із початкових умов:

```
q(0) = Q_0 ⇒ A = Q_0           [підстановка t = 0 у вираз для заряду]
i(0) = −(dq/dt)|_{t=0} = 0
dq/dt = −α · e^(−α·t) · [A·cos(ω_d·t) + B·sin(ω_d·t)] + e^(−α·t) · [−A·ω_d·sin(ω_d·t) + B·ω_d·cos(ω_d·t)]
(dq/dt)|_{t=0} = −α·A + ω_d·B = 0  [прирівнювання похідної до нуля при t = 0]
B = (α / ω_d) · A = (α / ω_d) · Q_0 [знаходження коефіцієнта B]
```

Підставимо константи у вираз для заряду:

```
q(t) = Q_0 · e^(−α·t) · [cos(ω_d·t) + (α / ω_d) · sin(ω_d·t)]
```

Миттєвий струм розряду `i(t) = − dq(t)/dt`:

```
i(t)
= − d/dt [Q_0 · e^(−α·t) · (cos(ω_d·t) + (α / ω_d) · sin(ω_d·t))]
= Q_0 · α · e^(−α·t) · (cos(ω_d·t) + (α / ω_d) · sin(ω_d·t)) − Q_0 · e^(−α·t) · (−ω_d · sin(ω_d·t) + α · cos(ω_d·t)) [диференціювання добутку]
= Q_0 · e^(−α·t) · [α · cos(ω_d·t) + (α² / ω_d) · sin(ω_d·t) + ω_d · sin(ω_d·t) − α · cos(ω_d·t)]                     [розкриття дужок]
= Q_0 · e^(−α·t) · [(α² + ω_d²) / ω_d] · sin(ω_d·t)                                                                   [зведення подібних доданків]
= Q_0 · e^(−α·t) · (ω_0² / ω_d) · sin(ω_d·t)                                                                         [використання α² + ω_d² = ω_0²]
= (C_pkg · V_0 · ω_0² / ω_d) · e^(−α·t) · sin(ω_d·t)                                                                 [підстановка Q_0 = C_pkg · V_0]
= (V_0 / (ω_d · L_loop)) · e^(−α·t) · sin(ω_d·t)                                                                     [використання C_pkg · ω_0² = 1 / L_loop]
```

Остаточний аналітичний вираз струму розряду:

```
i(t) = (V_0 / (ω_d · L_loop)) · e^(−α·t) · sin(ω_d·t)
```

## 3. Точний розрахунок пікового струму `I_peak` та часу його досягнення `t_peak`

Щоб знайти екстремум струму, прирівняємо першу похідну струму за часом до нуля:

```
di(t)/dt = 0
d/dt [(V_0 / (ω_d · L_loop)) · e^(−α·t) · sin(ω_d·t)] = 0
(V_0 / (ω_d · L_loop)) · e^(−α·t) · [−α · sin(ω_d·t) + ω_d · cos(ω_d·t)] = 0 [диференціювання експоненти та синуса]
ω_d · cos(ω_d·t) = α · sin(ω_d·t)                                           [скорочення на спільний ненульовий множник]
tan(ω_d·t) = ω_d / α                                                         [ділення обох частин на α · cos(ω_d·t)]
```

Точний момент часу досягнення пікового струму:

```
t_peak = (1 / ω_d) · arctan(ω_d / α)
```

Підставимо `t_peak` у формулу для струму:

```
I_peak
= (V_0 / (ω_d · L_loop)) · e^(−α · t_peak) · sin(ω_d · t_peak)
= (V_0 / (ω_d · L_loop)) · exp(−(α / ω_d) · arctan(ω_d / α)) · sin(arctan(ω_d / α))   [підстановка t_peak]
= (V_0 / (ω_d · L_loop)) · exp(−(α / ω_d) · arctan(ω_d / α)) · (ω_d / √(α² + ω_d²))    [використання sin(arctan(x)) = x / √(1 + x²)]
= (V_0 / (L_loop · ω_0)) · exp(−(α / ω_d) · arctan(ω_d / α))                          [скорочення ω_d та підстановка √(α² + ω_d²) = ω_0]
= (V_0 / Z_0) · exp(−(α / ω_d) · arctan(ω_d / α))                                    [врахування L_loop · ω_0 = √(L_loop/C_pkg) = Z_0]
```

**Аналіз асимптотичних меж пікового струму:**
- При нульовому активному опорі контуру (`R_loop → 0`, `α → 0`):
```
I_peak,ideal = V_0 / Z_0 = V_0 · √(C_pkg / L_loop)
```
- При зростанні добротності `Q = ω_0 / (2·α) = Z_0 / R_loop`:
```
ω_d / α = √(4·Q² − 1) ≈ 2·Q     [наближення для високої добротності Q >> 1]
arctan(2·Q) ≈ π/2
exp(−(1 / (2·Q)) · (π/2)) ≈ 1 − π / (4·Q)
```

## 4. Нелінійна динаміка іскрового розряду: закон Теплера

Опір повітряного іскрового проміжку `R_spark(t)` не є сталою величиною, а динамічно колапсує від десятків мегаомів до часток ома в міру іонізації плазмового шнура. За класичним законом Теплера (англ. *Toepler's spark law*), питома провідність іскрового каналу прямо пропорційна заряду, що перенесений крізь плазму:

```
R_spark(t) = (k_T · d_gap) / (∫₀^t i(τ) dτ)
```

де `k_T ≈ 0.5–1.0 × 10⁻⁴ В·с/см` — стала іскроутворення Теплера в сухому повітрі, а `d_gap` — довжина іскрового проміжку (типово 10–50 мкм для напруги 500 В).

На початковій стадії пробою (перші 10–30 пс) опір іскри стрімко зменшується за експоненційним законом:

```
R_spark(t) = R_0 · e^(−t / τ_spark) + R_arc_residual
```

де стала часу формування плазми становить `τ_spark ≈ 20–50 пс`, а залишковий опір розвиненої дуги `R_arc_residual ≈ 2–5 Ом`. Швидкість колапсу опору іскри задає фізичну нижню межу для часу наростання фронту струму в реальному випробуванні за стандартом ANSI/ESDA/JEDEC JS-002: навіть за нульової паразитної індуктивності фронт імпульсу не може бути коротшим за 50–80 пікосекунд через скінченну швидкість ударної іонізації газу.

## 5. Спектральний розподіл енергії імпульсу за Фур'є

Розглянемо спектральну густину амплітуди струму розряду `I(ω)`, застосувавши пряме перетворення Фур'є до аналітичного імпульсу струму `i(t) = (V_0 / (ω_d · L_loop)) · e^(−α·t) · sin(ω_d·t)`:

```
I(ω)
= ∫₀^∞ i(t) · e^(−j·ω·t) dt
= (V_0 / (ω_d · L_loop)) · ∫₀^∞ e^(−(α + j·ω)·t) · sin(ω_d·t) dt
= (V_0 / (ω_d · L_loop)) · [ω_d / ((α + j·ω)² + ω_d²)]           [табличний інтеграл затухаючого синуса]
= (V_0 / L_loop) · (1 / (ω_0² − ω² + 2·j·α·ω))                  [використання α² + ω_d² = ω_0²]
```

Квадрат модуля спектральної густини струму (спектральна густина потужності `S_I(ω)`):

```
|I(ω)|² = (V_0 / L_loop)² · (1 / ((ω_0² − ω²)² + 4·α²·ω²))
```

**Порівняння спектрів CDM та HBM:**
- Для імпульсу HBM з тривалістю 150 нс спектральна енергія спадає зі швидкістю −20 дБ/дек, починаючи з частоти `f_c,HBM = 1 / (π · t_duration) ≈ 2–5 МГц`. Понад 99% енергії HBM зосереджено в діапазоні нижче 50 МГц.
- Для імпульсу CDM з тривалістю фронту 150 пс та власною частотою `f_0 = ω_0 / (2·π) ≈ 1.5–3.0 ГГц` максимум спектральної потужності припадає на частоти **1–4 ГГц**, а високочастотний хвіст спектра простягається до **10–12 ГГц**.

Саме тому під час аналізу розряду CDM неприпустимо розглядати внутрішньокристальні шини як прості зосереджені резистори: на гігагерцових частотах металеві траси працюють як лінії з розподіленими хвильовими параметрами та випромінюють потужні електромагнітні завади на сусідні чутливі вузли.

## 6. Швидкість наростання струму `di/dt` та індуктивний викид

Максимальна крутизна наростання струму досягається в початковий момент часу розряду (`t = 0`):

```
(di/dt)|_{t=0}
= d/dt [(V_0 / (ω_d · L_loop)) · e^(−α·t) · sin(ω_d·t)]|_{t=0}
= (V_0 / (ω_d · L_loop)) · [−α · e^0 · sin(0) + ω_d · e^0 · cos(0)] [розкриття похідної при t = 0]
= (V_0 / (ω_d · L_loop)) · ω_d                                      [врахування sin(0) = 0, cos(0) = 1]
= V_0 / L_loop                                                      [скорочення частоти ω_d]
```

Швидкість наростання струму в початковий момент визначається виключно відношенням напруги заряду до індуктивності розрядного контуру:

```
(di/dt)|_{t=0} = V_0 / L_loop
```

Для тестової напруги `V_0 = 500 В` та паразитної індуктивності `L_loop = 1.5 нГн`:

```
(di/dt)|_{t=0} = 500 В / (1.5 × 10⁻⁹ Гн) = 3.33 × 10¹¹ А/с = 333 А/нс
```

Ця величина означає, що за перші 30 пікосекунд струм розряду досягає амплітуди 10 амперів.

## 7. Баланс енергії розряду та потужність

Загальна початкова енергія електростатичного поля, накопичена в ємності `C_pkg`:

```
W_total = ½ · C_pkg · V_0²
```

Ця енергія під час розряду повністю перетворюється на теплові втрати в активних опорах контуру та випромінювання:

```
W_total = ∫₀^∞ R_loop · i²(t) dt
```

Перевіримо точний енергетичний інтеграл аналітично:

```
∫₀^∞ i²(t) dt
= (V_0 / (ω_d · L_loop))² · ∫₀^∞ e^(−2·α·t) · sin²(ω_d·t) dt
= (V_0 / (ω_d · L_loop))² · [ω_d² / (4 · α · (α² + ω_d²))]   [табличний інтеграл затухаючого квадрата синуса]
= (V_0 / (ω_d · L_loop))² · [ω_d² / (4 · α · ω_0²)]          [підстановка α² + ω_d² = ω_0²]
= V_0² / (4 · α · ω_0² · L_loop²)                            [скорочення ω_d²]
= V_0² / (4 · (R_loop / (2·L_loop)) · (1 / (L_loop·C_pkg)) · L_loop²) [підстановка α та ω_0²]
= V_0² · C_pkg / (2 · R_loop)                                [спрощення алгебраїчного виразу]
```

Помноживши отриманий інтеграл на `R_loop`, отримуємо:

```
W_dissipated = R_loop · ∫₀^∞ i²(t) dt = R_loop · (V_0² · C_pkg / (2 · R_loop)) = ½ · C_pkg · V_0²
```

Закон збереження енергії виконується абсолютно точно.

Миттєва пікова потужність, що виділяється в розрядному контурі в момент `t_peak`:

```
P_peak = R_loop · I_peak²
```

Для `R_loop = 10 Ом` та `I_peak = 15 А`:

```
P_peak = 10 Ом · (15 А)² = 10 · 225 = 2250 Вт = 2.25 кВт
```

Потужність **понад два кіловати** виділяється в мікроскопічному об'ємі кремнію та плазмового каналу іскри протягом часток наносекунди.

## 8. Математична модель перехідного процесу у дворівневій мережі захисту

Розглянемо вхідний каскад із первинним затискачем (Primary Clamp), розділовим резистором затвора `R_gate` та вторинним затискачем (Secondary Clamp), що захищає затвор із вхідною ємністю `C_gate = C_ox + C_sec`.

![Еквівалентна розрахункова схема дворівневого захисту](/book/electronics/microelectronics/cdm-esd-model/img/dual-stage-cdm-protection.svg)
*Еквівалентна дворівнева схема для розрахунку перехідного процесу напруги на затворі V_gate(t) під час дії крутого фронту напруги на контактному майданчику.*

Напруга на контактному майданчику `V_pad(t)` під час спрацьовування первинного затискача з напругою відкривання `V_cl1` та динамічним опором `R_dyn1`:

```
V_pad(t) = V_cl1 + I_primary(t) · R_dyn1 + L_pkg · (di(t) / dt)
```

Диференціальне рівняння вузла затвора:

```
(V_pad(t) − V_gate(t)) / R_gate = C_gate · (dV_gate(t) / dt) + I_sec(V_gate)
```

До моменту відкривання вторинного затискача (`I_sec = 0`), перехідна характеристика вузла затвора описується лінійним операторним співвідношенням у просторі перетворень Лапласа:

```
V_gate(s) = V_pad(s) / (1 + s · τ_rc)          [де τ_rc = R_gate · C_gate]
```

Знайдемо аналітичний відгук вузла затвора на лінійно наростаючий фронт напруги на контактному майданчику:

```
V_pad(t) = S_v · t,  де S_v = V_pad,max / t_rise [крутизна наростання вхідного фронту]
```

Зображення вхідного сигналу за Лапласом:

```
V_pad(s) = S_v / s²
```

Зображення напруги на затворі:

```
V_gate(s) = S_v / [s² · (1 + s · τ_rc)] = S_v · [1/s² − τ_rc/s + τ_rc² / (s + 1/τ_rc)] [розклад на прості дроби]
```

Оригінал перехідної напруги в часовій області:

```
V_gate(t) = S_v · [t − τ_rc · (1 − e^(−t / τ_rc))]
```

Розкладемо експоненту в ряд Тейлора для малих часів (`t << τ_rc`):

```
e^(−t / τ_rc) ≈ 1 − (t / τ_rc) + ½ · (t / τ_rc)² − ...
V_gate(t) ≈ S_v · [t − τ_rc · (t/τ_rc − ½ · t²/τ_rc²)] = ½ · S_v · (t² / τ_rc)
```

**Висновок:** Завдяки резистору `R_gate` напруга на затворі в початкові моменти наростає не лінійно зі швидкістю `S_v`, а параболічно з затримкою, пропорційною `t² / (2 · τ_rc)`. Це дає вторинному затискачу необхідний запас часу для безінерційного відкривання до того, як напруга на затворі досягне небезпечного порогу.

Після відкривання вторинного затискача напруга на затворі жорстко обмежується:

```
V_gate,max = V_cl2 + I_sec,peak · R_dyn2
```

де струм вторинного затискача:

```
I_sec,peak = (V_pad,max − V_cl2) / (R_gate + R_dyn2)
```

### Умова критичного демпфування вторинного вузла затвора

Внутрішня металева траса між розділовим резистором `R_gate` та затвором приймача володіє власною розподіленою індуктивністю `L_int ≈ 0.2–0.5 нГн`. Разом із ємністю затвора `C_gate` вона утворює локальний вторинний коливальний контур. Щоб запобігти високочастотному коливальному дзвенінню (англ. *ringing*) та виникненню локальних резонансних перенапруг на діелектрику затвора, опір `R_gate` повинен задовольняти умову аперіодичного або критичного демпфування:

```
R_gate ≥ R_crit,sec = 2 · √(L_int / C_gate)
```

Для типових значень `L_int = 0.3 нГн` та `C_gate = 50 фФ` (`5 × 10⁻¹⁴ Ф`):

```
R_crit,sec = 2 · √(0.3 × 10⁻⁹ Гн / (5 × 10⁻¹⁴ Ф))
R_crit,sec = 2 · √6000 = 2 · 77.46 ≈ 155 Ом
```

Якщо обрати номінал `R_gate = 180–200 Ом`, контур переходить в аперіодичний режим без перерегулювання (англ. *overshoot*), що гарантує відсутність резонансних сплесків напруги на надтонкому підзатворному оксиді.

## 9. Хвильові процеси та ефект подвоєння напруги на розімкненому затворі

У кристалах із великою площею (SoC, мікропроцесори) довжина металевих шин розводки між контактним майданчиком PAD і вхідним каскадом ядра може досягати кількох міліметрів. Оскільки фронт імпульсу CDM має тривалість `t_rise ≈ 100–200 пс`, довжина хвилі імпульсу в діелектрику кристала становить:

```
λ = (v_prop · t_rise)
λ = ((1.5 × 10⁸ м/с) · (200 × 10⁻¹² с)) = 0.03 м = 30 мм
```

Просторова довжина фронту в діелектрику з діелектричною проникністю `ε_r ≈ 4.0` (діоксид кремнію, швидкість розповсюдження `v_prop = c / √ε_r ≈ 1.5 × 10⁸ м/с`) становить близько 30 мм. Коли довжина шини `l_trace` перевищує `0.1 · λ ≈ 3 мм`, лінія зв'язку поводиться як **довга лінія з розподіленими параметрами** з характеристичним хвильовим опором `Z_line ≈ 50–70 Ом`.

Вхідний опір ізольованого затвора MOSFET на низьких частотах є чисто ємнісним і наближається до нескінченності (`Z_gate → ∞`). Коефіцієнт відбиття напруги від вхідного затвора за формулою Френеля для ліній зв'язку:

```
Γ_gate = (Z_gate − Z_line) / (Z_gate + Z_line)
Γ_gate = (∞ − Z_line) / (∞ + Z_line) = +1.0 [повне синфазне відбиття хвилі]
```

При падінні хвилі напруги амплітудою `V_incident` на незахищений затвор результуюча напруга на вузлі затвора подвоюється через інтерференцію падаючої та відбитої хвиль:

```
V_gate,total = V_incident · (1 + Γ_gate)
V_gate,total = V_incident · (1 + 1.0) = 2.0 · V_incident
```

Цей ефект хвильового подвоєння напруги пояснює, чому віддалені вхідні каскади зазнають пробою діелектрика за амплітуд падаючого імпульсу, які на контактному майданчику здавалися допустимими. Включення розділового резистора `R_gate ≈ Z_line` біля затвора або біля PAD усуває відбиття (`Γ ≈ 0`) і поглинає енергію хвилі.

## 10. Модель теплового руйнування Вунша — Белла проти діелектричного пробою

Для оцінки стійкості напівпровідникових структур історично використовують рівняння теплової дифузії Вунша — Белла (англ. *Wunsch-Bell failure model*), що пов'язує критичну питому потужність руйнування `P_fail / A` з тривалістю імпульсу перенапруги `t_pulse`:

```
P_fail(t) / A = K_wb / √t_pulse + C_thermal
```

де `K_wb = √(π · ρ · c_p · k_th) · (T_melt − T_0)` — константа теплової дифузії кремнію, `T_melt ≈ 1414 °C` — температура плавлення, `ρ` — густина кремнію, `c_p` — питома теплоємність, `k_th` — теплопровідність.

При великих тривалостях імпульсу (`t_pulse > 10 нс`, зона HBM) тепло встигає дифундувати в об'єм кристала, і гранична потужність підпорядковується закону `1/√t`.

При скороченні імпульсу до пікосекундного діапазону (`t_pulse < 1 нс`, зона CDM) теплова дифузія повністю припиняється: глибина дифузії тепла `L_th = √(D_th · t_pulse) = √( (0.9 × 10⁻⁴ м²/с) · 2 × 10⁻¹⁰ с) ≈ 134 нм` стає меншою за розміри p-n переходу. Процес переходить в адіабатичний режим:

```
P_fail,adiabatic = (ρ · c_p · V_active · (T_melt − T_0)) / t_pulse ∝ 1 / t_pulse
```

Проте для підзатворного оксиду тепловий поріг взагалі не досягається, оскільки напруженість електричного поля перевищує критичну межу діелектричної міцності задовго до нагріву:

```
E_ox = V_ox / t_ox > E_critical ≈ 15 МВ/см
```

Таким чином, у часовій області CDM (< 1 нс) відмова визначається виключно **вектором напруженості електричного поля**, а не інтегралом виділеного тепла.

## 11. Динаміка міждоменного розряду: система зв'язаних контурів

У системах на кристалі з розділеними доменами живлення (наприклад, `VDD_IO/VSS_IO` та `VDD_CORE/VSS_CORE`) розрядний контур CDM розгалужується на два взаємопов'язані контури зі спільною міждоменною парою антипаралельних діодів.

Система диференціальних рівнянь зв'язаних контурів за другим законом Кірхгофа:

```
L_IO · (d²q_IO/dt²) + M · (d²q_CORE/dt²) + R_IO · (dq_IO/dt) + q_IO / C_IO + V_cross(t) = 0
L_CORE · (d²q_CORE/dt²) + M · (d²q_IO/dt²) + R_CORE · (dq_CORE/dt) + q_CORE / C_CORE − V_cross(t) = 0
```

де `M = k_m · √(L_IO · L_CORE)` — коефіцієнт взаємної індуктивності між металевими шинами доменів (`k_m ≈ 0.2–0.5`), а `V_cross(t)` — напруга на міждоменних антипаралельних діодах, що описується нелінійним рівнянням Шоклі з урахуванням послідовного динамічного опору:

```
i_cross(t) = I_s · (exp(V_cross(t) / (n · V_T)) − 1) + (V_cross(t) / R_diode_series)
```

Якщо міждоменні діоди мають недостатню площу (зависокий опір `R_diode_series > 2–3 Ом`) або надмірну паразитну індуктивність шин підключення `L_cross > 1 нГн`, міждоменна перенапруга `ΔV_cross = V_SS,IO − V_SS,CORE` сягає значень:

```
ΔV_cross,peak = V_diode_on + I_cross,peak · R_diode_series + L_cross · (di_cross / dt)
```

При струмі перетікання `I_cross = 5 А` та `di/dt = 25 А/нс`:

```
ΔV_cross,peak = 1.0 В + (5 А · 1.5 Ом) + (1.0 × 10⁻⁹ Гн · 25 × 10⁹ А/с) = 1.0 + 7.5 + 25.0 = 33.5 В
```

Цей перепад потенціалів 33.5 В безпосередньо прикладається до підзатворного оксиду приймальних транзисторів міждоменних перетворювачів рівня (level shifters), спричиняючи їхній локальний пробій.

## 12. Статистична модель надійності пробою діелектрика за розподілом Вейбулла

Пробій ультратонких діелектриків за умов пікосекундного електричного стресу підпорядковується статистиці екстремальних значень Вейбулла (англ. *Weibull reliability distribution*). Кумулятивна ймовірність пробою оксиду `F(E, t)` описується рівнянням:

```
F(E, t) = 1 − exp(− (A_gate / A_ref) · (t / η_time)^β · (E_ox / E_0)^γ)
```

де `A_gate` — сумарна площа затворів, підключених до вузла; `A_ref` — еталонна площа тестової структури; `β` — коефіцієнт форми розподілу Вейбулла (для ультратонких оксидів `β ≈ 1.2–1.8`); `γ` — фактор прискорення електричним полем (`γ ≈ 30–45`); `η_time` — характеристичний час до пробою при полі `E_0`.

Логарифмічна форма закону масштабування площі (модель випадкових точкових дефектів Пуассона):

```
ln(−ln(1 − F_die)) = ln(A_die / A_ref) + β · ln(t / η_time) + γ · ln(E_ox / E_0)
```

**Висновки для проектування мікросхем:**
1. **Ефект масштабування площі:** Збільшення сумарної площі вхідних затворів `A_gate` у 10 разів (наприклад, у широких багаторозрядних паралельних шинах або пам'яті) зміщує криву розподілу Вейбулла ліворуч, знижуючи допустиму амплітуду безпечної напруги CDM на 15–25%.
2. **Фактор крутизни поля `γ`:** Через надзвичайно високе значення показника `γ ≈ 40`, перевищення локального електричного поля всього на 10% (наприклад, через крайовий геометричний ефект на кутах затвора) збільшує ймовірність відмови напівпровідникового виробу в `(1.1)⁴⁰ ≈ 45` разів.

## 13. Порівняльний розрахунок параметрів CDM для різних типів корпусів

Залежність пікового струму, швидкості наростання та напруги затвора від типу конструктивного виконання інтегральної мікросхеми при стандартній зарядній напрузі `V_0 = 500 В`:

| Тип корпусу мікросхеми | Ємність C_pkg | Індуктивність L_loop | Хвильовий опір Z_0 | Піковий струм I_peak | Час піку t_peak | Крутизна (di/dt)_max | Напруга без захисту V_gate |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **WLCSP (Wafer-Level CSP)** | 0.8 пФ | 0.5 нГн | 25.0 Ом | 14.8 А | 62 пс | 1000 А/нс | 520 В |
| **QFN (Quad Flat No-Lead)** | 2.5 пФ | 1.2 нГн | 21.9 Ом | 16.2 А | 134 пс | 417 А/нс | 230 В |
| **LQFP (Дротяна розварка)** | 5.0 пФ | 3.0 нГн | 24.5 Ом | 14.2 А | 285 пс | 167 А/нс | 115 В |
| **BGA (Flip-Chip Ball Grid)**| 12.0 пФ | 1.0 нГн | 9.1 Ом | 32.5 А | 172 пс | 500 А/нс | 165 В |
| **2.5D/3D (CoWoS Interposer)**| 20.0 пФ| 0.8 нГн | 6.3 Ом | 46.1 А | 185 пс | 625 А/нс | 180 В |

Розрахунки наочно демонструють, що для великих площ кристалів і багатокристальних модулів (CoWoS / Chiplets) піковий струм CDM може перевищувати **45 амперів**, що вимагає обов'язкового застосування багатоступеневих схем CDM-захисту та точного тривимірного моделювання розрядних контурів.
