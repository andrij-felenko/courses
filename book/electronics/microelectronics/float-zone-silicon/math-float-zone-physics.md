# 🧮 Фізичні моделі зонної плавки: сегрегація, стійкість краплі та пробійна напруга

Безтигельна зонна плавка кремнію описується системою зв'язаних фізичних моделей: рівняннями масопереносу домішок на рухомому фронті кристалізації, тепловим балансом фазового переходу Стефана, гідродинамічним балансом капілярних сил вільної краплі, термокапілярною нестійкістю Марангоні, кінетикою ядерної трансмутації, електродинамікою високочастотного пінч-ефекту та рівняннями електростатики збідненого шару у високовольтних напівпровідникових структурах.

### 1. Рівняння Пфанна для розподілу домішки при однопрохідній плавці

Розглянемо вихідний циліндричний стрижень довжиною `L` зі сталою початковою концентрацією домішки `C_0`. Нехай вздовж стрижня рухається розплавлена зона довжиною `l` зі сталою лінійною швидкістю `v`. Площа поперечного перерізу стрижня `A`.

Позначимо через `x` поточну координату фронту кристалізації (задньої межі розплавленої зони). При переміщенні зони на нескінченно малу відстань `dx`:
1. На передньому фронті плавлення розплавляється порція вихідного матеріалу масою `ρ · A · dx` з концентрацією `C_0`. Кількість домішки, що входить у зону: `dM_in = C_0 · A · dx`.
2. На задньому фронті кристалізується шар кремнію товщиною `dx` з концентрацією `C_s(x)`. Кількість домішки, що виходить у кристал: `dM_out = C_s(x) · A · dx`.

Якщо припустити інтенсивне перемішування розплаву в зоні (концентрація в рідкій зоні `C_L` однорідна по об'єму), зв'язок між концентрацією у щойно застиглому кристалі та розплаві задається коефіцієнтом сегрегації `k`:

```
C_s(x) = k · C_L(x)
```

Загальна маса домішки `S(x)` у розплавленій зоні об'ємом `V = A · l` дорівнює:

```
S(x) = C_L(x) · A · l
= (C_s(x) / k) · A · l                                              [виразили через C_s(x)]
```

Запишемо баланс зміни кількості домішки в зоні `dS` при зміщенні на `dx`:

```
dS = dM_in - dM_out                                                 [різниця надходження та виходу домішки]
= C_0 · A · dx - C_s(x) · A · dx                                    [підставили вирази потоків]
= (C_0 - C_s(x)) · A · dx                                           [винесли спільний множник A · dx]
```

Диференціюємо вираз для повної маси `S(x)` за просторовою координатою `x`:

```
dS / dx = (A · l / k) · (dC_s(x) / dx)
```

Прирівнюємо обидва вирази для похідної `dS / dx`:

```
(A · l / k) · (dC_s(x) / dx) = A · (C_0 - C_s(x))                   [прирівняли диференціали маси]
(l / k) · (dC_s(x) / dx) = C_0 - C_s(x)                             [скоротили на площу A]
dC_s(x) / dx + (k / l) · C_s(x) = (k / l) · C_0                     [звели до стандартного вигляду]
```

Отримали лінійне неоднорідне диференціальне рівняння першого порядку. Розв'яжемо його методом інтегрувального множника `exp(k · x / l)`:

```
(dC_s(x) / dx) · exp(k · x / l) + (k / l) · C_s(x) · exp(k · x / l) = (k / l) · C_0 · exp(k · x / l) [помножили на експоненту]
d/dx [C_s(x) · exp(k · x / l)] = (k / l) · C_0 · exp(k · x / l)      [згорнули ліву частину в похідну добутку]
```

Інтегруємо обидві частини за координатою `x`:

```
C_s(x) · exp(k · x / l) = ∫ (k / l) · C_0 · exp(k · x / l) dx        [записали невизначений інтеграл]
= C_0 · exp(k · x / l) + B                                          [взяли первісну від експоненти]
```

Ділимо обидві частини рівності на `exp(k · x / l)`:

```
C_s(x) = C_0 + B · exp(-k · x / l)
```

Сталу інтегрування `B` знаходимо з початкової умови при `x = 0`. У момент першого розплавлення зони масою `A · l` у ній містилася домішка `S(0) = C_0 · A · l`, тому початкова концентрація в розплаві `C_L(0) = C_0`, а перший закристалізований шар має концентрацію:

```
C_s(0) = k · C_0
```

Підставляємо `x = 0` у загальний розв'язок для знаходження `B`:

```
k · C_0 = C_0 + B                                                   [підставили граничну умову x=0]
B = C_0 · (k - 1)                                                   [виразили константу B]
= -C_0 · (1 - k)                                                    [винесли знак мінус]
```

Підставляємо `B` назад у формулу та отримуємо класичне **рівняння Пфанна для однопрохідної зонної плавки**:

```
C_s(x) = C_0 · [1 - (1 - k) · exp(-k · x / l)]
```

Цей розв'язок справедливий на інтервалі від `x = 0` до `x = L - l`. Коли передній край зони досягає кінця стрижня (`x = L - l`), розплав більше не поповнюється новим твердим кремнієм, і кристалізація залишку довжиною `l` підпорядковується закону нормальної спрямованої кристалізації Шейла (*Scheil equation*):

```
C_s(x) = C_L(L - l) · k · (1 - (x - (L - l)) / l)^(k - 1)
```

При багаторазових проходах (`n → ∞`) розподіл домішки досягає граничного стаціонарного профілю, де прямий потік сегрегації врівноважується зворотним дифузійним потоком:

```
C_∞(x) = B_∞ · exp(A_∞ · x)
```

де константи `A_∞` та `B_∞` пов'язані з коефіцієнтом сегрегації трансцендентним рівнянням:

```
k = (A_∞ · l) / (exp(A_∞ · l) - 1)
```

### 2. Тепловий баланс на фронті кристалізації: задача Стефана

Швидкість переміщення розплавленої зони `v` жорстко обмежена швидкістю відведення прихованої теплоти кристалізації крізь твердий монокристал.

На рухомій межі розділу рідкої та твердої фаз діє гранична умова Стефана, яка виражає фундаментальний закон збереження енергії:

```
k_S · (dT_S / dz) - k_L · (dT_L / dz) = ρ_S · ΔH_f · v
```

де:
- `k_S ≈ 22 Вт/(м · К)` — коефіцієнт теплопровідності твердого кремнію поблизу точки плавлення;
- `k_L ≈ 67 Вт/(м · К)` — коефіцієнт теплопровідності рідкого кремнію (у розплаві теплопровідність вища завдяки металічній природі розплаву та високій концентрації вільних електронів);
- `(dT_S / dz)` — температурний градієнт у твердому кристалі на межі розділу;
- `(dT_L / dz)` — температурний градієнт у рідкому розплаві на межі розділу;
- `ρ_S = 2330 кг/м³` — густина твердого монокристалічного кремнію;
- `ΔH_f = 1.8 · 10⁶ Дж/кг` — питома прихована теплота плавлення кремнію;
- `v` — лінійна швидкість кристалізації.

Звідси максимальна теоретична швидкість вирощування монокристала `v_max` визначається граничним градієнтом охолодження в твердій фазі за умови, що розплав не перегрітий (`dT_L / dz ≈ 0`):

```
v_max = (k_S · (dT_S / dz)) / (ρ_S · ΔH_f)
```

**Числовий розрахунок максимальної швидкості росту:**

Для типового градієнта охолодження монокристала за рахунок радіаційного теплового випромінювання `(dT_S / dz) ≈ 100 К/см = 10 000 К/м`:

```
v_max = (22 Вт/(м · К) × 10 000 К/м) / (2330 кг/м³ × 1.8 · 10⁶ Дж/кг) [підставили константи кремнію]
= 220 000 / (4.194 · 10⁹)                                            [обчислили добуток знаменника]
≈ 5.24 · 10⁻⁵ м/с                                                    [отримали швидкість у м/с]
= 5.24 · 10⁻³ см/с = 3.14 мм/хв                                      [перевели у практичні одиниці мм/хв]
```

Це точно відповідає практичним швидкостям росту промислових FZ-злитків (2.0–3.5 мм/хв). Будь-яка спроба вести процес швидше призводить до виникнення переохолодження розплаву, порушення стабільності плоского фронту кристалізації та утворення полікристалічних блоків.

### 3. Ефективний коефіцієнт сегрегації: модель Бертона–Пріма–Сліхтера (BPS)

Рівноважний коефіцієнт сегрегації `k_0` визначається термодинамікою фазової рівноваги. Проте при реальній швидкості кристалізації `v` перед фронтом утворюється збагачений домішкою дифузійний примежовий шар товщиною `δ`.

Запишемо одновимірне стаціонарне рівняння дифузії домішки в системі координат, пов'язаній із рухомим фронтом (вісь `z` спрямована від фронту кристалізації вглиб розплаву):

```
D · (d²C_L / dz²) + v · (dC_L / dz) = 0
```

де:
- `D` — коефіцієнт дифузії домішки в рідкому кремнії (`~ 5 · 10⁻⁵ см²/с`);
- `v` — лінійна швидкість кристалізації (`1–3 мм/хв ≈ 2–5 · 10⁻³ см/с`);
- `δ` — товщина гідродинамічного примежового шару, яка залежить від швидкості обертання злитка `ω`.

Інтегруємо диференціальне рівняння перший раз:

```
dC_L / dz = K₁ · exp(-v · z / D)
```

Інтегруємо вдруге:

```
C_L(z) = -K₁ · (D / v) · exp(-v · z / D) + K₂
```

Граничні умови для масопереносу на фронті:
1. На межі кристалізації `z = 0` потік домішки, що відкидається кристалом, дорівнює дифузійному потоку в розплав:
   `-D · (dC_L / dz)|_{z=0} = v · (C_L(0) - C_s) = v · C_L(0) · (1 - k_0)`
2. На зовнішній межі примежового шару `z = δ` концентрація сягає середнього значення в об'ємі розплаву: `C_L(δ) = C_bulk`.

Підставляємо першу граничну умову для знаходження коефіцієнта `K₁`:

```
-D · K₁ = v · C_L(0) · (1 - k_0)                                    [гранична умова на межі z=0]
K₁ = -(v / D) · C_L(0) · (1 - k_0)                                  [виразили коефіцієнт K₁]
```

Тоді розподіл концентрації в примежовому шарі набуває вигляду:

```
C_L(z) = C_L(0) · (1 - k_0) · exp(-v · z / D) + K₂
```

Використовуємо значення при `z = 0`:

```
C_L(0) = C_L(0) · (1 - k_0) + K₂                                    [підставили z=0]
K₂ = C_L(0) · k_0                                                   [виразили константу K₂]
= C_s                                                               [за означенням k_0 = C_s / C_L(0)]
```

Отже:

```
C_L(z) = C_L(0) · (1 - k_0) · exp(-v · z / D) + C_L(0) · k_0
```

Застосовуємо умову на межі гідродинамічного шару `z = δ`:

```
C_bulk = C_L(δ) = C_L(0) · [(1 - k_0) · exp(-v · δ / D) + k_0]
```

Визначаємо **ефективний коефіцієнт сегрегації** `k_eff = C_s / C_bulk = (k_0 · C_L(0)) / C_bulk`:

```
k_eff = (k_0 · C_L(0)) / (C_L(0) · [k_0 + (1 - k_0) · exp(-v · δ / D)]) [підставили C_bulk]
= k_0 / (k_0 + (1 - k_0) · exp(-v · δ / D))                         [скоротили на спільний множник C_L(0)]
```

Для гранично тонкого дифузійного шару або надповільного росту (`v · δ / D ≪ 1`):

```
exp(-v · δ / D) ≈ 1                                                 [розклад експоненти для малого аргументу]
k_eff ≈ k_0 / (k_0 + (1 - k_0) · 1)                                 [підставили одиницю]
= k_0                                                               [чиста термодинамічна рівновага]
```

Для надшвидкого росту або повної відсутності перемішування розплаву (`v · δ / D ≫ 1`):

```
exp(-v · δ / D) → 0                                                 [експонента прямує до нуля]
k_eff → k_0 / (k_0 + 0)                                             [підставили граничне значення]
= 1                                                                 [сегрегація зникає, очищення не відбувається]
```

Товщина шару `δ` за теорією Кохрана залежить від кутової швидкості обертання `ω` та кінематичної в'язкості розплаву `ν`:

```
δ ≈ 1.6 · D^(1/3) · ν^(1/6) · ω^(-1/2)
```

Звідси видно: швидке зустрічне обертання злитка зменшує `δ`, наближаючи `k_eff` до його теоретичного мінімуму `k_0`.

### 4. Термокапілярна нестійкість: число Марангоні та смуги мікросегрегації

При безтигельній плавці вільна поверхня розплавленої краплі відчуває сильний радіальний та осьовий градієнт температури `∇T`. Оскільки поверхневий натяг рідкого кремнію падає зі зростанням температури (`dγ/dT ≈ -0.28 · 10⁻³ Н/(м · К)`), виникає сила термокапілярної тяги Марангоні.

Інтенсивність термокапілярного руху характеризується безрозмірним **числом Марангоні** `Ma`:

```
Ma = (|dγ/dT| · ΔT · l) / (μ · α)
```

де:
- `ΔT` — перепад температури вздовж вільної поверхні зони розплаву (`ΔT ≈ 50 – 150 К`);
- `l` — довжина розплавленої зони (`l ≈ 1.5 · 10⁻² м`);
- `μ` — динамічна в'язкість рідкого кремнію (`μ ≈ 0.88 · 10⁻³ Па · с`);
- `α` — коефіцієнт термічної дифузії рідкого кремнію (`α = λ / (ρ · c_p) ≈ 2.1 · 10⁻⁵ м²/с`).

Розрахуємо число Марангоні для типової зони FZ:

```
Ma = (0.28 · 10⁻³ × 100 × 1.5 · 10⁻²) / (0.88 · 10⁻³ × 2.1 · 10⁻⁵)   [підставили фізичні константи розплаву]
= (4.2 · 10⁻⁴) / (1.848 · 10⁻⁷)                                     [виконали множення чисельника й знаменника]
≈ 2270                                                              [отримали безрозмірне число]
```

Критичне число Марангоні для кремнієвого рідкого моста складає `Ma_c ≈ 150 – 300`. Оскільки реальне значення `Ma ≈ 2270 ≫ Ma_c`, стаціонарний ламінарний рух втрачає стійкість і переходить у режим коливальної термокапілярної конвекції (*oscillatory Marangoni flow*).

Швидкість кристалізації на фронті починає періодично пульсувати в часі:

```
v(t) = v_0 + Δv · sin(2π · f_osc · t)
```

Згідно з формулою BPS, коливання швидкості `v(t)` модулюють ефективний коефіцієнт сегрегації `k_eff(t)`, що й породжує періодичні радіальні та осьові смуги легування (*striations*) з флуктуаціями питомого опору до ±30%. Це пояснює математичну необхідність переходу від газового легування до ядерної трансмутації NTD.

### 5. Гідродинамічна стійкість розплавленої зони: межа Гейванга

У вертикальній конфігурації вільна рідка зона кремнію утримується від витікання виключно балансом між капілярним тиском Лапласа на вільній поверхні та гідростатичним тиском гравітації.

Рівняння Юнга–Лапласа для різниці тисків на викривленій поверхні меніска:

```
ΔP_γ = γ · (1 / R_1 + 1 / R_2)
```

де:
- `γ` — коефіцієнт поверхневого натягу рідкого кремнію (`γ ≈ 0.72 Н/м` при `T = 1420 °C`);
- `R_1, R_2` — головні радіуси кривини вільної поверхні меніска розплаву.

Гідростатичний тиск стовпчика рідкого кремнію висотою `h` з густиною `ρ = 2570 кг/м³`:

```
P_hyd = ρ · g · h
```

Умова стійкості рідкого циліндричного моста вимагає, щоб капілярні сили компенсували гідростатичний напір вздовж усієї висоти меніска. Інтегрування нелінійного диференціального рівняння профілю меніска дає теоретичний критерій Гейванга (*Heywang stability limit*) для максимальної висоти зони `h_max`:

```
h_max = C_geom · √(γ / (ρ · g))
```

де константа `C_geom ≈ 2.8` для циліндричних злитків великого діаметра.

Розрахуємо граничну висоту для розплаву кремнію:

```
l_cap = √(γ / (ρ · g))                                              [капілярна довжина рідкого кремнію]
= √(0.72 / (2570 × 9.81))                                           [підставили натяг і густину]
= √(0.72 / 25211.7)                                                 [обчислили знаменник]
= √(2.8558 · 10⁻⁵)                                                  [взяли відношення]
≈ 5.344 · 10⁻³ м = 5.34 мм                                          [добули квадратний корінь]

h_max = 2.8 · l_cap                                                 [критерій стійкості Гейванга]
= 2.8 × 5.344 мм                                                    [підставили l_cap]
≈ 14.96 мм ≈ 1.5 см                                                 [отримали граничну висоту зони]
```

Якщо зона розплаву стає вищою за 15 мм, радіус звуження перешийка меніска прямує до нуля, виникає капілярна нестійкість Релея–Плато, і рідкий кремній неминуче прориває оболонку та стікає.

### 6. Електромагнітні сили голкового індуктора та левітаційний пінч-ефект

Щоб компенсувати гідростатичний напір у злитках діаметром понад 50 мм, індуктор Needle-Eye використовує ефект електромагнітної левітації.

Високочастотний струм `I_0 ≈ 1000 – 3000 А` на частоті `f = 2.5 МГц` протікає по мідній пластині індуктора. Через радіальний розріз (щілину індуктора) струм змушений огинати вузький центральний отвір діаметром 30–40 мм, утворюючи локальне кільце колосальної густини струму. Змінне магнітне поле `H_0`, збуджене цим контуром, проникає в поверхневий скін-шар рідкого кремнію на глибину `δ_skin ≈ 0.28 мм`. Густина індукованого об'ємного вихрового струму в розплаві `J = σ · E` взаємодіє з магнітним полем `B = μ_0 · H`, створюючи векторну густину об'ємної сили Лоренца `f_EM`:

```
f_EM = J × B
= -∇(B² / (2 · μ_0)) + (B · ∇)B / μ_0
```

Для тонкого скін-шару перший градієнтний додаток переважає над натягом ліній поля, створюючи спрямований до осі симетрії еквівалентний магнітний тиск стискання `P_EM`:

```
P_EM = (μ_0 · H_0²) / 2 = B_0² / (2 · μ_0)
```

Цей магнітний тиск діє як безконтактний пружний корсет. Оскільки силові лінії магнітного поля густішають у звуженні між індуктором і розплавом, сила Лоренца має виражену вертикальну складову, спрямовану вгору проти вектора сили тяжіння, що забезпечує часткову квазі-левітацію рідкої краплі кремнію.

**Розрахунок левітаційного тиску:**

Для амплітуди магнітного поля на внутрішньому ребрі голкового отвору індуктора `B_0 = 0.15 Тл`:

```
P_EM = (0.15 Тл)² / (2 × 4π · 10⁻⁷ Гн/м)                            [підставили магнітну індукцію]
= 0.0225 / (2.5133 · 10⁻⁶)                                          [обчислили чисельник і знаменник]
≈ 8952 Па ≈ 9.0 кПа                                                 [отримали електромагнітний тиск]
```

Зіставимо це з гідростатичним тиском стовпчика кремнію висотою `h = 15 мм`:

```
P_hyd = ρ · g · h
= 2570 кг/м³ × 9.81 м/с² × 0.015 м                                  [підставили густину розплаву і висоту]
≈ 378 Па ≈ 0.38 кПа                                                 [отримали гідростатичний тиск]
```

Електромагнітний тиск у зоні звуження індуктора Needle-Eye у багато разів перевищує гідростатичний тиск рідкого стовпчика, надійно утримуючи рідкий конус кремнію від розтікання і дозволяючи монокристалу безпечно розширюватися до діаметра 150–200 мм.

### 7. Кінетика нейтронно-трансмутаційного легування (NTD)

Швидкість утворення атомів фосфору `³¹P` під час опромінення злитка в тепловому спектрі нейтронів описується диференціальними рівняннями радіоактивного накопичення:

```
dN_31Si / dt = σ_c · Φ_flux · N_30Si - λ_31Si · N_31Si
dN_31P / dt = λ_31Si · N_31Si
```

де:
- `N_30Si` — початкова атомна концентрація ізотопу `³⁰Si` (`N_30Si = 0.031 × 5 · 10²² см⁻³ = 1.55 · 10²¹ см⁻³`);
- `σ_c = 0.107 · 10⁻²⁴ см²` — ядерний переріз реакції `³⁰Si(n, γ)³¹Si`;
- `Φ_flux` — густина потоку теплових нейтронів у реакторі (`нейтронів / (см² · с)`);
- `λ_31Si = ln(2) / T_1/2 ≈ 7.34 · 10⁻⁵ с⁻¹` — стала радіоактивного розпаду кремнію-31 (`T_1/2 = 2.62 год = 9432 с`).

Оскільки вигорання цільового ізотопу `³⁰Si` за час опромінення не перевищує часток відсотка (`N_30Si ≈ const`), розв'язок для кількості радіоактивного кремнію `N_31Si(t)` при тривалості опромінення `t_irr` має вигляд:

```
N_31Si(t_irr) = ((σ_c · Φ_flux · N_30Si) / λ_31Si) · [1 - exp(-λ_31Si · t_irr)]
```

Після завершення опромінення та витримки злитка впродовж часу охолодження `t_cool ≫ T_1/2` (практично 5–7 діб) увесь утворений `³¹Si` повністю розпадається на фосфор `³¹P`:

```
N_D(P) = σ_c · N_30Si · (Φ_flux · t_irr)
= σ_c · N_30Si · Φ_total
```

де `Φ_total = Φ_flux · t_irr` — сумарний інтегральний флюенс нейтронів (`нейтронів / см²`).

**Розрахунок необхідної дози опромінення для 3.3 кВ IGBT:**

Для створення бази з концентрацією фосфору `N_D = 3.40 · 10¹³ см⁻³`:

```
Φ_total = N_D / (σ_c · N_30Si)                                      [виразили необхідний флюенс нейтронів]
= (3.40 · 10¹³ см⁻³) / (0.107 · 10⁻²⁴ см² × 1.55 · 10²¹ см⁻³)       [підставили ядерні параметри]
= (3.40 · 10¹³) / (1.6585 · 10⁻⁴)                                   [перемножили знаменник]
≈ 2.05 · 10¹⁷ нейтронів / см²                                        [отримали повну дозу опромінення]
```

При типовому потоці реактора `Φ_flux = 5 · 10¹² нейтронів / (см² · с)` час перебування злитка в реакторі складає:

```
t_irr = Φ_total / Φ_flux                                            [розрахунок часу експозиції]
= (2.05 · 10¹⁷) / (5 · 10¹²)                                        [виконали ділення]
= 41 000 с ≈ 11.4 години                                            [отримали тривалість опромінення]
```

Оскільки флюенс нейтронів контролюється лічильниками з точністю до десятих часток відсотка, результуючий питомий опір злитка потрапляє у заданий номінал з безпрецедентною точністю.

### 8. Кінетика рекомбінації Шоклі–Ріда–Холла та час життя носіїв

Швидкість безвипромінювальної рекомбінації `U_SRH` через глибокі енергетичні пастки (атоми важких металів `Fe, Au, Cu` або кисневі преципітати) з концентрацією `N_t` та глибиною залягання `E_t` описується статистикою Шоклі–Ріда–Холла:

```
U_SRH = (n · p - n_i²) / (τ_p0 · (n + n_1) + τ_n0 · (p + p_1))
```

де:
- `n_1 = N_c · exp(-(E_c - E_t) / (k_B · T))` — густина електронів у зоні провідності, коли рівень Фермі збігається з рівнем пастки `E_t`;
- `p_1 = N_v · exp(-(E_t - E_v) / (k_B · T))` — відповідна густина дірок;
- `τ_n0, τ_p0` — мінімальні часи життя носіїв при захопленні на пастки:

```
τ_n0 = 1 / (N_t · σ_n · v_th,n)
τ_p0 = 1 / (N_t · σ_p · v_th,p)
```

де `σ_n, σ_p` — перерізи захоплення носіїв дефектом (`~ 10⁻¹⁵ – 10⁻¹⁴ см²`), а `v_th ≈ 10⁷ см/с` — теплова швидкість носіїв.

Для чистої слаболегованої `n⁻`-бази FZ-кремнію при високому рівні інжекції (`Δn = Δp ≫ n_0`):

```
τ_eff = τ_n0 + τ_p0
= 1 / (N_t · v_th) · (1 / σ_n + 1 / σ_p)
```

**Оцінка впливу чистоти від заліза на час життя носіїв:**

У кремнії CZ залишковий вміст заліза та кисневих преципітатів складає `N_t ≈ 10¹³ – 10¹⁴ см⁻³`:

```
τ_CZ = 1 / (10¹³ см⁻³ × 10⁻¹⁴ см² × 10⁷ см/с)                       [підставили концентрацію пасток у CZ]
= 1 / 10⁶ с⁻¹                                                       [обчислили знаменник]
= 10⁻⁶ с = 1 мкс                                                    [отримали мікросекундний час життя]
```

У надчистому FZ-кремнії завдяки коефіцієнту сегрегації `k_0(Fe) = 8 · 10⁻⁶` концентрація металевих пасток падає нижче `N_t < 10¹⁰ см⁻³`:

```
τ_FZ = 1 / (10¹⁰ см⁻³ × 10⁻¹⁴ см² × 10⁷ см/с)                       [підставили концентрацію пасток у FZ]
= 1 / 10³ с⁻¹                                                       [обчислили знаменник]
= 10⁻³ с = 1 мс = 1000 мкс                                          [час життя зріс на три порядки]
```

Дифузійна довжина амбіполярного переносу плазми `L_a`:

```
L_a = √(D_a · τ_eff)
= √(18 см²/с × 10⁻³ с)                                              [підставили коефіцієнт амбіполярної дифузії]
= √(0.018 см²)                                                      [обчислили добуток під коренем]
≈ 0.134 см = 1.34 мм = 1340 мкм                                     [дифузійна довжина перевищує товщину пластини]
```

Оскільки `L_a (1340 мкм) ≫ W_d (400–600 мкм)`, інжектована електронно-діркова плазма затоплює всю товщу бази приладу, знижуючи пряме падіння напруги `V_on` від теоретичних десятків вольт до комфортних 1.5–2.2 В при струмах у тисячі ампер.

### 9. Пробійна напруга та питомий опір у високовольтних приладах

Розглянемо високоомну слабколеговану `n⁻`-базу високовольтного IGBT або силового діода на основі FZ-кремнію. 

Розподіл електричного поля `E(x)` у режимі повного зворотного блокування описується 1D-рівнянням Пуассона:

```
d²V / dx² = -dE / dx = -(q · N_D) / (ε_Si · ε_0)
```

де:
- `q = 1.602 · 10⁻¹⁹ Кл` — елементарний заряд;
- `N_D` — концентрація донорної домішки (фосфору) в `n⁻`-базі;
- `ε_Si = 11.7` — відносна діелектрична проникність кремнію;
- `ε_0 = 8.854 · 10⁻¹² Ф/м` — електрична стала (`ε_Si · ε_0 ≈ 1.036 · 10⁻¹⁰ Ф/м`).

Інтегруємо рівняння Пуассона від `x = 0` (p-n перехід) до `x = W_d` (край збідненої області):

```
E(x) = E_max - (q · N_D / (ε_Si · ε_0)) · x
```

Критичне поле лавинного пробою для чистого кремнію `E_crit ≈ 2 · 10⁵ В/см = 2 · 10⁷ В/м`.

Для одностороннього різкого переходу напруга лавинного пробою `V_B` дорівнює площі під трикутним профілем поля `E(x)`:

```
V_B = (1 / 2) · E_crit · W_dep                                     [площа трикутника розподілу поля]
= (1 / 2) · E_crit · ((ε_Si · ε_0 · E_crit) / (q · N_D))           [підставили ширину збіднення W_dep]
= (ε_Si · ε_0 · E_crit²) / (2 · q · N_D)                           [спростили добуток]
```

Зв'язок між концентрацією донорів `N_D` та питомим опором `ρ` кремнію задається рухливістю електронів `μ_n ≈ 1400 см²/(В·с) = 0.14 м²/(В·с)`:

```
ρ = 1 / (q · μ_n · N_D)                                             [означення питомого опору]
N_D = 1 / (q · μ_n · ρ)                                             [виразили концентрацію донорів через опір]
```

Підставляємо `N_D` у вираз для пробійної напруги `V_B`:

```
V_B = (ε_Si · ε_0 · E_crit² · q · μ_n · ρ) / (2 · q)                [підставили N_D у формулу пробою]
= (1 / 2) · ε_Si · ε_0 · μ_n · E_crit² · ρ                          [скоротили заряд електрона q]
```

Бачимо пряму пропорційність: **пробійна напруга прямо пропорційна питомому опору напівпровідника**:

```
V_B ∝ ρ
```

**Числовий розрахунок для силового IGBT на 3300 В:**

Необхідний запас надійності вимагає теоретичної напруги пробою `V_B = 3800 В`.

```
N_D = (ε_Si · ε_0 · E_crit²) / (2 · q · V_B)                        [формула розрахунку необхідного легування]
= (1.036 · 10⁻¹⁰ × (2 · 10⁷)²) / (2 × 1.602 · 10⁻¹⁹ × 3800)         [підставили числові константи]
= (1.036 · 10⁻¹⁰ × 4 · 10¹⁴) / (1.2175 · 10⁻¹⁵)                    [обчислили чисельник і знаменник]
= 4.144 · 10⁴ / 1.2175 · 10⁻¹⁵                                      [спростили степінь]
≈ 3.40 · 10¹⁹ м⁻³ = 3.40 · 10¹³ см⁻³                                [отримали концентрацію донорів]

ρ = 1 / (q · μ_n · N_D)                                             [розрахунок питомого опору кремнію]
= 1 / (1.602 · 10⁻¹⁹ × 1400 × 3.40 · 10¹³)                         [підставили N_D та рухливість]
= 1 / (7.62 · 10⁻³)                                                 [перемножили значення]
≈ 131 Ом·см                                                         [отримали необхідний опір пластини]

W_d = (2 · V_B) / E_crit                                            [товщина бази при трикутному полі]
= (2 × 3800) / (2 · 10⁵ В/см)                                       [підставили напругу і критичне поле]
= 7600 / 200000                                                     [виконали ділення]
= 0.038 см = 380 мкм                                                [отримали товщину збідненої області]
```

Для створення приладу на 3.3 кВ потрібна ідеально однорідна пластина кремнію товщиною понад 380 мкм із наднизькою концентрацією домішок `3.4 · 10¹³ см⁻³` (питомий опір 130 Ом·см). Кремній CZ через наявність кисню з концентрацією `10¹⁸ см⁻³` створив би паразитно термодонори `~ 10¹⁵ см⁻³`, що знизило б опір до 5 Ом·см і обвалило блокувальну напругу нижче 300 В. Тільки надчистий FZ-кремній забезпечує необхідні параметри.
