# 🧮 Розрахунок частоти, меж збудження та термокомпенсації UJT-генератора

Релаксаційний генератор на одноперехідному транзисторі формує періодичні коливання за рахунок циклічного заряду накопичувального конденсатора через резистор до порогової напруги відмикання емітера `V_P` з наступним надшвидким лавиноподібним розрядом до напруги западини `V_V`. Щоб розрахувати точну частоту генерації, гарантувати надійне самозбудження схеми за будь-яких виробничих розкидів параметрів напівпровідника та усунути температурне дрейфування порогу спрацьовування, необхідно вивести аналітичні вирази для кожної фази нелінійного процесу.

### 1. Виведення точного періоду коливань генератора

Розгляньмо процес заряду конденсатора ємністю `C` від стабілізованого джерела постійної напруги `V_BB` через часозадавальний резистор `R`.

У момент завершення попереднього циклу розряду, який ми приймаємо за початок відліку часу `t = 0`, напруга на конденсаторі дорівнює залишковому потенціалу точки западини вольт-амперної характеристики транзистора:

```
V_E(0) = V_V    [початкова умова напруги на конденсаторі]
```

Диференціальне рівняння для струму заряду конденсатора через резистор `R` записується на основі другого закону Кірхгофа для замкненого вхідного контуру:

```
V_BB = i(t)·R + v_C(t)
V_BB = R·C·(dv_C/dt) + v_C(t)    [диференціальне рівняння першого порядку]
```

Розв'язок цього лінійного неоднорідного диференціального рівняння з наведеною початковою умовою `v_C(0) = V_V` описує асимптотичне наближення напруги конденсатора до напруги джерела живлення `V_BB`:

```
V_E(t) = V_BB − (V_BB − V_V)·e^(−t / (R·C))    [експоненціальна траєкторія заряду]
```

Фаза заряду триває до моменту часу `t = T_ch`, коли зростаюча напруга на емітері досягає критичного порогу піку `V_P`. У цей момент p-n перехід емітера відкривається в прямому напрямку, запускаючи лавинну інжекцію дірок у нижню область бази:

```
V_E(T_ch) = V_P    [умова досягнення порогу відмикання]
```

Підставимо умову перемикання в рівняння зарядної кривої:

```
V_P = V_BB − (V_BB − V_V)·e^(−T_ch / (R·C))
```

Розв'яжемо це рівняння відносно тривалості фази заряду `T_ch` крок за кроком:

```
(V_BB − V_V)·e^(−T_ch / (R·C)) = V_BB − V_P    [перенесли доданки для ізоляції експоненти]
e^(−T_ch / (R·C)) = (V_BB − V_P) / (V_BB − V_V)    [поділили обидві частини на різницю (V_BB - V_V)]
e^(T_ch / (R·C)) = (V_BB − V_V) / (V_BB − V_P)    [обернули дріб для зміни знаку степеня]
T_ch / (R·C) = ln((V_BB − V_V) / (V_BB − V_P))    [прологарифмували обидві частини за основою e]
T_ch = R·C·ln((V_BB − V_V) / (V_BB − V_P))    [множення на сталу часу зарядного кола R·C]
```

Після досягнення точки піку опір ділянки «емітер — база B1» лавиноподібно зменшується від десятків кілоомів до величини залишкового динамічного опору насичення `R_B1(on) ≈ 10...30 Ом`. Конденсатор розряджається крізь послідовно з'єднані опір `R_B1(on)` та зовнішній струмовимірювальний резистор `R1`.

Диференціальне рівняння розряду конденсатора від початкової напруги `V_P` до напруги западини `V_V` має вигляд:

```
v_C(t_dis) = V_P · e^(−t_dis / ((R_B1(on) + R1)·C))    [рівняння розряду конденсатора]
```

Тривалість фази розряду `T_dis` визначається часом досягнення напруги западини `V_V`:

```
T_dis = (R_B1(on) + R1)·C·ln(V_P / V_V)    [тривалість фази розряду]
```

Оскільки опір розрядного кола `R_B1(on) + R1` типово становить `30...100 Ом`, а опір зарядного резистора `R` лежить у діапазоні від `10 кОм` до `500 кОм`, відношення тривалостей фаз становить:

```
T_dis / T_ch ≈ (R_B1(on) + R1) / R < 10⁻³    [відношення тривалості розряду до заряду]
```

Таким чином, тривалість розряду складає менше 0.1% від повного періоду. Повний період коливань `T = T_ch + T_dis` з високою інженерною точністю визначається виключно тривалістю заряду:

```
T = R·C·ln((V_BB − V_V) / (V_BB − V_P))    [точний період релаксаційного генератора]
```

### 2. Інженерне наближення періоду через коефіцієнт поділу η

Напруга спрацьовування транзистора `V_P` формується внутрішнім резистивним дільником напруги між базами та прямим падінням напруги на відкритому p-n переході емітера `V_D`:

```
V_P = η·V_BB + V_D    [напруга спрацьовування емітера]
```

де `η = R_B1 / (R_B1 + R_B2)` — коефіцієнт внутрішнього поділу напруги (типово 0.55...0.82 для кремнієвих приладів).

У типових схемах промислової автоматики напруга живлення `V_BB` вибирається в межах від 12 до 30 В. За таких умов пряме падіння на кремнієвому p-n переході `V_D ≈ 0.6...0.7 В` та залишкова напруга западини `V_V ≈ 1.2...2.0 В` є суттєво меншими за величину напруги живлення `V_BB`.

Зробимо асимптотичні наближення для чисельника та знаменника під логарифмом:

```
V_BB − V_V ≈ V_BB    [нехтування малою напругою западини порівняно з V_BB]
V_BB − V_P = V_BB − (η·V_BB + V_D) ≈ V_BB·(1 − η)    [нехтування прямим спадом V_D]
```

Підставимо ці спрощення у формулу для відношення напруг:

```
(V_BB − V_V) / (V_BB − V_P)
= V_BB / (V_BB·(1 − η))    [підстановка наближених виразів]
= 1 / (1 − η)              [скорочення напруги живлення V_BB]
```

Звідси випливає класична формула інженерного розрахунку періоду та частоти коливань:

```
T ≈ R·C·ln(1 / (1 − η))    [базова наближена формула періоду]
f = 1 / T ≈ 1 / (R·C·ln(1 / (1 − η)))    [частота генерації коливань]
```

Це рівняння має фундаментальне значення для схемотехніки: період коливань у першому наближенні **взагалі не залежить від абсолютної напруги живлення `V_BB`**, оскільки як поріг спрацьовування `V_P`, так і швидкість заряду конденсатора прямо пропорційні `V_BB`.

Для приладів із параметром `η = 0.632` коефіцієнт логарифма перетворюється на одиницю:

```
ln(1 / (1 − 0.632)) = ln(1 / 0.368) = ln(e) = 1.000
T = R·C    [період при еталонному значенні η = 0.632]
```

### 3. Генерація лінійної пилкоподібної напруги (заряд стабільним струмом)

Експоненціальний заряд конденсатора через звичайний резистор `R` володіє природною нелінійністю: у міру наближення напруги конденсатора до `V_BB` струм заряду спадає, і швидкість наростання сповільнюється. Коефіцієнт нелінійності пилки визначається відношенням амплітуди пилки до напруги живлення:

```
ε_nonlin = (V_P − V_V) / V_BB ≈ η    [нелінійність експоненціальної пилки]
```

Для вимірювальних систем, осцилографічної розгортки та аналого-цифрових перетворювачів потрібна строго лінійна пилкоподібна напруга. Для цього зарядний резистор `R` замінюють генератором стабільного струму на базі біполярного PNP або польового транзистора зі струмом `I_const`.

Диференціальне рівняння заряду конденсатора постійним струмом має вигляд:

```
i_C(t) = C · (dv_C / dt) = I_const = const    [заряд стабільним струмом]
```

Інтегруючи це рівняння від початкової точки западини `V_V`, отримуємо лінійне зростання напруги:

```
V_E(t) = V_V + (I_const / C) · t    [ідеально лінійна напруга емітера]
```

Фаза прямого ходу триває до досягнення порогу `V_P`:

```
V_P = V_V + (I_const / C) · T_lin
T_lin = C · (V_P − V_V) / I_const    [період лінійного генератора пилки]
```

Підставивши вираз для напруги піку `V_P = η·V_BB + V_D`, отримуємо точний вираз для періоду лінійно-змінної напруги:

```
T_lin = C · (η·V_BB + V_D − V_V) / I_const    [період пилки зі струмовим зарядом]
f_lin = I_const / (C · (η·V_BB + V_D − V_V))    [частота лінійної пилки]
```

У цій конфігурації частота коливань стає лінійно пропорційною керувальному струму `I_const`, що дозволяє використовувати UJT як прецизійний **генератор, керований напругою або струмом** (*VCO / CCO*).

### 4. Фазовий простір та граничний цикл релаксаційних коливань

Математична природа релаксаційних автоколивань описується нелінійною динамічною системою в фазовому просторі змінних стану «напруга на конденсаторі `v_E` — струм емітера `i_E`».

Система описується парою диференціальних рівнянь:

```
C · (dv_E / dt) = (V_BB − v_E) / R − i_E    [динаміка накопичення заряду]
L_par · (di_E / dt) = v_E − v_UJT(i_E)    [динаміка наростання струму з урахуванням паразитної індуктивності]
```

де `v_UJT(i_E)` — нелінійна S-подібна характеристика емітера UJT, а `L_par` — еквівалентна паразитна індуктивність виводів та об'єму напівпровідника (`L_par ≈ 10...50 нГн`).

Оскільки стала часу струму `τ_i = L_par / r_d` є на 4–5 порядків меншою за сталу часу заряду `τ_v = R·C`, фазова траєкторія розпадається на два контрастні типи рухів:
1. **Повільний рух (квазистатичний заряд):** фазова точка повільно дрейфує вздовж гілки відсікання вольт-амперної характеристики від `V_V` до `V_P`, де струм `i_E ≈ I_EO ≈ 0`.
2. **Швидкий стрибок (релаксаційний зрив):** у точці піку `V_E = V_P` динамічна стійкість втрачається (`dv_UJT / di_E < 0`), і фазова точка миттєво зривається по горизонталі вздовж лінії `v_E ≈ const` на праву високопровідну гілку насичення.
3. **Швидкий розряд:** конденсатор стрімко віддає заряд, напруга падає до точки западини `V_V`.
4. **Зрив у закритий стан:** у точці западини струм стає меншим за `I_V`, плазма носіїв рекомбінує, динамічний опір стає додатним, і фазова точка миттєво перескакує назад на гілку відсікання.

Утворюється стійкий замкнений **граничний цикл** (*limit cycle*), що гарантує незагасаючі періодичні коливання.

### 5. Зовнішня синхронізація та поділ частоти

UJT-генератор має унікальну властивість легко захоплювати зовнішні тактові імпульси, що подаються на базу B2 або на емітер. Це дозволяє використовувати його як прецизійний синхронізатор або дільник частоти на ціле число `N`.

Якщо до бази B2 прикласти негативний імпульс напруги амплітудою `ΔV_sync`, міжбазова напруга короткочасно знижується до величини `V_BB − ΔV_sync`. Відповідно, миттєвий поріг спрацьовування емітера зменшується:

```
V_P_dyn = η·(V_BB − ΔV_sync) + V_D = V_P − η·ΔV_sync    [модульований поріг піку]
```

Якщо в момент приходу синхроімпульсу напруга на конденсаторі вже досягла рівня `V_E(t) ≥ V_P_dyn`, транзистор негайно відмикається раніше природного часу `T_ch`.

Смуга захоплення синхронізації (*lock-in range*) за частотою визначається амплітудою синхроімпульсу:

```
T_sync_min = R·C·ln((V_BB − V_V) / (V_BB − V_P_dyn))
f_sync_max = 1 / T_sync_min ≈ f_0 / (1 − (η·ΔV_sync) / (V_BB·(1 − η)))    [верхня межа смуги захоплення]
```

Для реалізації **дільника частоти 1:N** власну частоту генератора налаштовують на величину, дещо меншу за `f_in / N`. Тоді перші `N − 1` вхідних синхроімпульсів приходять, коли напруга на конденсаторі ще недостатня для пробою (`V_E(t) < V_P_dyn`), а `N`-й імпульс скидає конденсатор, видаючи один вихідний імпульс на кожні `N` вхідних.

### 6. Межі стійкого самозбудження: аналіз навантажувальної прямої

Щоб генератор не зупинився в одному з двох статичних рівноважних станів (запирання або постійне насичення), навантажувальна пряма джерела живлення та резистора `R` мусить перетинати статичну вольт-амперну характеристику транзистора **виключно на ділянці з від'ємним диференційним опором** (`dV_E / dI_E < 0`).

Рівняння навантажувальної прямої в координатах `(I_E, V_E)` має вигляд:

```
V_E = V_BB − I_E·R    [статична навантажувальна пряма кола емітера]
```

#### Верхня межа опору R_max (запобігання зависанню у відсіканні)
Щоб схема подолала точку піку `(I_P, V_P)` і перейшла в режим лавинної інжекції, струм, що надходить через резистор `R` при напрузі піку `V_P`, має строго перевищувати піковий струм емітера `I_P`:

```
I_ch(V_P) = (V_BB − V_P) / R > I_P    [умова подолання точки піку]
```

Звідси визначається максимальний допустимий опір часозадавального резистора:

```
R_max = (V_BB − V_P) / I_P    [максимальний опір резистора заряду]
```

Якщо `R > R_max`, струм через резистор не зможе компенсувати витік і запустити модуляцію провідності. Конденсатор зарядиться до рівня нижче `V_P`, і схема назавжди застрягне в закритому стані.

#### Нижня межа опору R_min (запобігання зависанню в насиченні)
Після розряду конденсатора струм від джерела живлення при напрузі западини `V_V` мусить бути меншим за струм утримання западини `I_V`. Інакше транзистор не зможе рекомбінувати надлишкові носії, і в ньому підтримуватиметься безперервний струм насичення:

```
I_ch(V_V) = (V_BB − V_V) / R < I_V    [умова зриву з режиму насичення]
```

Звідси визначається мінімальний допустимий опір часозадавального резистора:

```
R_min = (V_BB − V_V) / I_V    [мінімальний опір резистора заряду]
```

#### Критерій безвідмовної генерації
Поєднуючи обидві умови, отримуємо фундаментальну умову існування релаксаційних автоколивань:

```
(V_BB − V_P) / I_P  >  R  >  (V_BB − V_V) / I_V    [критерій автоколивань]
```

Для типових значень транзистора 2N2646 при `V_BB = 20 В` (`I_P = 2 мкА`, `I_V = 4 мА`, `V_P = 13 В`, `V_V = 2 В`):
- `R_max = (20 − 13) / (2·10⁻⁶) = 3.5 МОм`
- `R_min = (20 − 2) / (4·10⁻³) = 4.5 кОм`

Діапазон допустимих значень `R` становить майже три порядки величини (від 4.5 кОм до 3.5 МОм), що забезпечує надзвичайно широкий діапазон регулювання частоти.

### 7. Чутливість періоду коливань до параметрів компонентів

Проведемо аналіз чутливості періоду коливань `T(R, C, η, V_BB)` до випадкових відхилень параметрів компонентів та напруги живлення за допомогою логарифмічних чутливостей `S_x^T = (x / T) · (∂T / ∂x)`.

#### Чутливість до пасивних компонентів R та C
Оскільки період прямо пропорційний `R` та `C`:

```
S_R^T = (R / T) · (∂T / ∂R) = (R / T) · (C · ln(1 / (1 − η))) = 1.00    [чутливість до R]
S_C^T = (C / T) · (∂T / ∂C) = (C / T) · (R · ln(1 / (1 − η))) = 1.00    [чутливість до C]
```
Похибка номіналів резистора та конденсатора транслюється в похибку періоду у відношенні 1:1 (відхилення ємності на +5% збільшує період рівно на +5%).

#### Чутливість до коефіцієнта внутрішнього поділу η
Знайдемо частинну похідну періоду за параметром `η`:

```
∂T / ∂η
= R·C · d/dη [ln(1 / (1 − η))]    [диференціювання за η]
= R·C · d/dη [−ln(1 − η)]         [властивість логарифма]
= R·C · [−(1 / (1 − η)) · (−1)]   [похідна складеної функції]
= (R·C) / (1 − η)                 [спрощення знаків]
```

Логарифмічна чутливість періоду до зміни коефіцієнта `η`:

```
S_η^T = (η / T) · (∂T / ∂η) = (η / (R·C·ln(1 / (1 − η)))) · ((R·C) / (1 − η)) = η / ((1 − η) · ln(1 / (1 − η)))    [коефіцієнт чутливості до η]
```

Для типового значення `η = 0.65`:
```
S_η^T = 0.65 / ((1 − 0.65) · ln(1 / 0.35)) = 0.65 / (0.35 · 1.0498) = 0.65 / 0.3674 ≈ 1.77
```
Це означає, що технологічний розкид коефіцієнта `η` на 1% призводить до зміни періоду коливань на 1.77%.

### 8. Термокомпенсація порогу спрацьовування резистором R2

Напруга спрацьовування генератора `V_P = η·V_BB + V_D` зазнає температурного дрейфу під впливом двох взаємно протилежних фізичних явищ:

1. **Температурний коефіцієнт спаду на діоді:** контактна різниця потенціалів прямозміщеного p-n переходу зменшується через температурне зростання концентрації неосновних носіїв:
   ```
   dV_D / dT ≈ −2.2 мВ/°C    [ТКН прямого падіння на діоді]
   ```
2. **Температурний коефіцієнт міжбазового опору:** питомий опір слаболегованого кремнію n-типу збільшується при нагріванні внаслідок зменшення рухливості електронів через інтенсивне розсіювання на теплових коливаннях кристалічної ґратки:
   ```
   α_BB = (1 / R_BB) · (dR_BB / dT) ≈ +0.8 %/°C    [ТКО кремнієвої бази]
   ```

Якщо базу B2 увімкнути безпосередньо до шини `+V_BB`, напруга дільника `η·V_BB` залишається постійною, і поріг `V_P(T)` спадає зі швидкістю −2.2 мВ/°C, що спричиняє зростання частоти генератора при нагріванні.

Щоб компенсувати це явище, послідовно з виводом B2 включають резистор `R2`. Тоді міжбазова напруга на кристалі визначається дільником з `R_BB(T)` та `R2`:

```
V_B2B1(T) = V_BB · (R_BB(T) / (R_BB(T) + R2))
V_P(T) = η·V_BB·(R_BB(T) / (R_BB(T) + R2)) + V_D(T)    [напруга піку з урахуванням R2]
```

Знайдемо повну похідну напруги піку за температурою:

```
dV_P / dT
= η·V_BB · d/dT [R_BB / (R_BB + R2)] + dV_D/dT    [диференціювання за температурою]
= η·V_BB · [((dR_BB/dT)·(R_BB + R2) − R_BB·(dR_BB/dT)) / (R_BB + R2)²] + dV_D/dT    [похідна частки]
= η·V_BB · [(R2 · (dR_BB/dT)) / (R_BB + R2)²] + dV_D/dT    [скорочення R_BB·dR_BB/dT]
```

Умова абсолютної температурної компенсації вимагає:

```
dV_P / dT = 0    [умова стабільності порогу спрацьовування]
```

Підставивши умову рівноваги та врахувавши, що `R2 << R_BB` (тому `(R_BB + R2)² ≈ R_BB²`):

```
η·V_BB · [(R2 · (dR_BB/dT)) / R_BB²] = |dV_D/dT|
R2 · [η·V_BB / R_BB] · [(1 / R_BB)·(dR_BB/dT)] = |dV_D/dT|
R2 = |dV_D/dT| / (α_BB · η · (V_BB / R_BB))    [аналітичний вираз для R2]
```

Підставляючи середні фізичні константи кремнієвого переходу `|dV_D/dT| = 0.0022 В/К` та `α_BB = 0.008 К⁻¹`:

```
R2 ≈ 0.0022 / (0.008 · η · (V_BB / R_BB)) = (0.275 · R_BB) / (η · V_BB)    [теоретичний розрахунок R2]
```

З урахуванням внутрішнього саморозігріву та нерівномірності профілю легування в інженерній практиці застосовують калібровану емпіричну формулу:

```
R2 ≈ (0.40...0.70) · R_BB / (η · V_BB)    [інженерна формула вибору R2]
```

### 9. Фізичні обмеження максимальної частоти коливань

Максимальна робоча частота генератора на UJT обмежується не пасивними елементами `R` та `C`, а фундаментальними процесами переносу заряду в напівпровідниковій структурі:

1. **Час прольоту носіїв:** час дрейфу інжектованих дірок від емітера до нижнього контакту B1 під дією електричного поля:
   ```
   t_transit = L_B1² / (μ_p · V_B1)    [час дрейфу дірок до бази 1]
   ```
   де `L_B1 ≈ 0.5...0.8 мм` — довжина нижньої ділянки бази, `μ_p ≈ 450 см²/(В·с)` — рухливість дірок у кремнії. При `V_B1 ≈ 10 В` час прольоту становить `t_transit ≈ 0.1...0.3 мкс`.
2. **Час рекомбінації та розсмоктування плазми:** після розряду конденсатора для повернення нижньої ділянки бази у високомний стан надлишкова електронно-діркова плазма має повністю рекомбінувати:
   ```
   t_recovery ≈ (3...5) · τ_p    [час відновлення високого опору бази]
   ```
   де `τ_p ≈ 1...3 мкс` — час життя неосновних носіїв у слаболегованому кремнії. Час відновлення становить від 3 до 15 мкс.

Якщо період генерації `T` стає співмірним із часом відновлення `t_recovery`, транзистор не встигає відновити свій високий опір `R_B1`, і коливання зриваються в режим постійного насичення. Тому гранична частота для класичних сплавних транзисторів типу 2N2646 становить близько `f_max ≈ 100...200 кГц`, а для швидкодіючих планарних приладів (PUT 2N6027) — до `1...2 МГц`.

### 10. Енергетичний баланс та теплове розсіювання

Потужність, що розсіюється на кристалі UJT, складається з двох компонентів:
1. **Статична потужність міжбазового струму спокою:**
   ```
   P_stat = V_BB² / (R_BB + R2 + R1)    [постійна потужність міжбазового каналу]
   ```
2. **Динамічна потужність імпульсів розряду конденсатора:**
   ```
   P_dyn = f · (1/2) · C · (V_P² − V_V²)    [динамічна комутаційна потужність]
   ```

Сумарна потужність розсіювання кристала:

```
P_total = P_stat + P_dyn = (V_BB² / (R_BB + R2 + R1)) + f · (1/2) · C · (V_P² − V_V²)    [повна теплова потужність]
```

Для типових значень (`V_BB = 15 В`, `R_BB = 7 кОм`, `C = 20 нФ`, `f = 1 кГц`, `V_P = 10.4 В`, `V_V = 1.5 В`):
- `P_stat = 15² / 7407 ≈ 225 / 7407 ≈ 30.4 мВт`
- `P_dyn = 1000 · 0.5 · 20·10⁻⁹ · (10.4² − 1.5²) = 10⁻⁵ · (108.16 − 2.25) ≈ 1.06 мВт`
- `P_total ≈ 31.5 мВт`

Отримана величина суттєво менша за гранично допустиму потужність розсіювання для корпусу TO-92 / TO-18 (`P_max = 300...360 мВт`), що гарантує надійну роботу транзистора без додаткових тепловідводів.

### 11. Наскрізний числовий розрахунок схеми на базі 2N2646

Розрахуймо параметри релаксаційного генератора тактових імпульсів на транзисторі 2N2646 для таких вихідних даних:
- Напруга живлення: `V_BB = 15 В`
- Параметри транзистора 2N2646: `η = 0.65`, `R_BB = 7.0 кОм`, `V_D = 0.65 В`, `I_P = 2.0 мкА`, `I_V = 4.0 мА`, `V_V = 1.5 В`, `R_B1(on) = 25 Ом`
- Бажана частота коливань: `f = 1.0 кГц` (`T = 1.0 мс`)
- Вихідний резистор: `R1 = 47 Ом`

#### Крок 1. Розрахунок порогів перемикання V_P та V_V
```
V_P = η·V_BB + V_D = 0.65 · 15 + 0.65 = 9.75 + 0.65 = 10.40 В
V_V = 1.50 В
```

#### Крок 2. Визначення меж для резистора заряду R
```
R_max = (V_BB − V_P) / I_P = (15 − 10.40) В / (2.0·10⁻⁶ А) = 4.6 В / 2.0 мкА = 2.30 МОм
R_min = (V_BB − V_V) / I_V = (15 − 1.50) В / (4.0·10⁻³ А) = 13.5 В / 4.0 мА = 3.375 кОм
```
Обираємо стандартний номінал резистора `R = 47 кОм`, який з великим запасом потрапляє в інтервал `3.38 кОм < 47 кОм < 2.30 МОм`.

#### Крок 3. Розрахунок ємності конденсатора C
Використаємо точну формулу тривалості заряду для досягнення `T = 1.0 мс`:

```
ln((V_BB − V_V) / (V_BB − V_P)) = ln((15 − 1.50) / (15 − 10.40)) = ln(13.5 / 4.6) = ln(2.935) ≈ 1.0767

C = T / (R · 1.0767) = 1.0·10⁻³ с / (47·10³ Ом · 1.0767) = 1.0·10⁻³ / 50605 ≈ 19.76 нФ
```
Обираємо найближчий стандартний номінал конденсатора з ряду E24: `C = 20 нФ` (або `22 нФ`).

#### Крок 4. Розрахунок термокомпенсувального резистора R2
```
R2 = (0.50 · R_BB) / (η · V_BB) = (0.50 · 7000) / (0.65 · 15) = 3500 / 9.75 ≈ 359 Ом
```
Обираємо стандартний прецизійний номінал з ряду E24: `R2 = 360 Ом` (1%).

#### Крок 5. Розрахунок амплітуди вихідного імпульсу на B1
```
I_B1(peak) = (V_P − V_V) / (R_B1(on) + R1) = (10.40 − 1.50) / (25 + 47) = 8.90 В / 72 Ом ≈ 0.1236 А = 123.6 мА

V_out(peak) = I_B1(peak) · R1 = 0.1236 А · 47 Ом ≈ 5.81 В
```
Отриманий імпульс напруги `5.81 В` з піковим струмом `124 мА` і тривалістю `t_p ≈ (R_B1(on) + R1)·C = 72 Ом · 20 нФ ≈ 1.44 мкс` гарантовано і надійно відмикає будь-який потужний промисловий тиристор або симістор.
