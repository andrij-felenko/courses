# 🧮 Математичний аналіз запасу завадостійкості (SNM) та умов стабільності SRAM

У статичній пам'яті один збережений біт — це динамічна рівновага струмів у двох зустрічно замкнених CMOS-інверторах. Поки до комірки ніхто не звертається, ця рівновага надзвичайно міцна. Але щойно відкриваються транзистори доступу для читання чи запису, внутрішні вузли потрапляють під пряму дію напруг із довгих бітових ліній. Щоб комірка не втрачала інформацію спонтанно і водночас надійно перезаписувалася за частки наносекунди, геометрія її шести транзисторів має підкорятися суворим аналітичним нерівностям.

Розберімо математичний апарат розрахунку статичного запасу завадостійкості (*Static Noise Margin — SNM*), геометрію метеликової кривої через поворот координат Сівінка, динаміку розряду ємності бітової лінії, критичну напругу утримання даних (*Data Retention Voltage — DRV*) та аналітичне виведення ключових співвідношень розмірів транзисторів — коефіцієнта комірки (*Cell Ratio*) та коефіцієнта підтяжки (*Pull-up Ratio*).

### Рівняння вольт-амперних характеристик MOSFET у комірці

Для аналізу статичних і перехідних режимів 6T SRAM скористаємося моделлю струму стоку польового транзистора Шихмана–Ходжеса. Струм N-канального MOSFET залежить від напруг на затворі `V_gs`, стоці `V_ds` та витоку:

1. **Підпороговий режим (відсічка):** при `V_gs < V_th` струм стоку практично дорівнює нулю (нехтуючи експоненційним підпороговим витоком для швидких перемикань):

```
I_ds = 0                                       [відсічка: канал перекритий]
```

2. **Лінійний (тріодний) режим:** при `V_gs ≥ V_th` та `V_ds < V_gs − V_th`:

```
I_ds = β · ((V_gs − V_th) · V_ds − ½ · V_ds²)  [лінійний режим: неперекритий канал]
```

де `β = μ · C_ox · (W / L)` — питомий коефіцієнт крутизни транзистора, `μ` — рухливість носіїв заряду (електронів для nMOS, дірок для pMOS), `C_ox` — питома ємність підзатворного діелектрика, `W` — ширина каналу, `L` — довжина каналу.

3. **Режим насичення:** при `V_gs ≥ V_th` та `V_ds ≥ V_gs − V_th`:

```
I_ds = ½ · β · (V_gs − V_th)² · (1 + λ · V_ds) [режим насичення: пінч-офф біля стоку]
```

де `λ` — коефіцієнт модуляції довжини каналу (для першого наближення беремо `λ ≈ 0`).

### Метеликова крива та перетворення координат Сівінка

Розглянемо два зустрічно включені CMOS-інвертори `INV1` та `INV2`. Їхні передавальні характеристики напруги (*Voltage Transfer Characteristics — VTC*) визначаються функціями:

```
V_QB = VTC₁(V_Q)                               [передавальна характеристика INV1]
V_Q  = VTC₂(V_QB)                              [передавальна характеристика INV2]
```

Якщо побудувати обидва графіки в одній системі координат `(V_Q, V_QB)`, де для `VTC2` осі поміняні місцями (`V_QB` — вхід по вертикалі, `V_Q` — вихід по горизонталі), утворюється замкнена фігура з двох симетричних пелюсток, відома як **метеликова крива** (*butterfly curve*).

Криві перетинаються в трьох точках:
- Дві стійкі точки рівноваги: стан «0» `(0, V_DD)` та стан «1» `(V_DD, 0)`. У цих точках коефіцієнт підсилення кільцевого розімкненого контуру `A_loop = |(d VTC₁ / d V_Q) · (d VTC₂ / d V_QB)| < 1`.
- Одна нестійка (метастабільна) точка `(V_M, V_M)`, де `A_loop > 1`.

#### Геометричне та аналітичне визначення SNM

Статичний запас завадостійкості `SNM` визначається як максимальна напруга постійного шуму `V_noise`, яку можна прикласти до внутрішніх вузлів `Q` або `QB` без зміни логічного стану комірки.

Геометрично `SNM` дорівнює **довжині сторони найбільшого квадрата**, який можна вписати між двома гілками передавальних характеристик `VTC1` та `VTC2` всередині пелюстки метеликової кривої.

Прямий пошук такого квадрата в декартових координатах `(V_Q, V_QB)` ускладнений тим, що сторони квадрата паралельні осям, а його діагональ лежить уздовж лінії з нахилом `−1` (або `+1`). 1987 року інженери Жак Сівінк (*Jacques Seevinck*), Френк Ліст (*Frank List*) та Ян Лостро (*Jan Lohstroh*) запропонували метод: повернути систему координат на 45° проти годинникової стрілки:

```
u = (V_Q − V_QB) ÷ √2                          [вісь різницевого сигналу: діагональ]
v = (V_Q + V_QB) ÷ √2                          [вісь синфазного сигналу: медіана]
```

Обернене перетворення координат:

```
V_Q  = (v + u) ÷ √2                            [вираження напруги V_Q через (u, v)]
V_QB = (v − u) ÷ √2                            [вираження напруги V_QB через (u, v)]
```

У повернутій системі координат різниця між двома гілками характеристик по осі `u` як функція від `v` позначається як `Δu(v) = u₁(v) − u₂(v)`.

Сторона максимального вписаного квадрата досягається в точці локального екстремуму, де похідна різниці дорівнює нулю:

```
d(Δu) / dv = 0                                 [умова максимальної ширини пелюстки]
```

Якщо максимальне значення різницевої координати дорівнює `u_max`, то довжина діагоналі квадрата становить `d = u_max`, а сторона квадрата `SNM` обчислюється як:

```
SNM = u_max ÷ √2                               [перехід від діагоналі до сторони квадрата]
```

### Умова стабільності читання та Cell Ratio (CR)

Найбільш критичний момент у роботі 6T SRAM — це зчитування. Перед відкриттям словесної лінії `WL` обидві бітові лінії `BL` та `BLB` передзаряджені до напруги живлення `V_DD`.

Припустимо, комірка зберігає стан `Q = 0` (`0 В`) та `QB = 1` (`V_DD`).
У цьому стані транзистор `N1` (pull-down) повністю відкритий (`V_gs,N1 = V_QB = V_DD`), а транзистор `P1` закритий (`V_gs,P1 = 0 В`).

Коли словесна лінія `WL` піднімається до `V_DD`, транзистор доступу `AX1` вмикається (`V_gs,AX1 = V_WL − V_Q = V_DD − 0 = V_DD`).

Утворюється шлях протікання струму зчитування `I_read`:
`Шина BL (V_DD) → Транзистор доступу AX1 → Вузол Q → Транзистор стягування N1 → Земля GND (0 В)`.

Цей ланцюг є дільником напруги між відкритим транзистором `AX1` та відкритим транзистором `N1`. У результаті напруга у вузлі `Q` піднімається вище нуля до значення `V_read`:

```
V_Q = V_read > 0 В                             [сплеск напруги в нульовому вузлі при читанні]
```

#### Визначення режимів роботи транзисторів при читанні

З'ясуймо електричні режими транзисторів `AX1` та `N1`:

1. **Транзистор доступу AX1 (nMOS):**
   - Напруга на затворі: `V_g = V_DD`
   - Напруга на витоку: `V_s = V_read` (витік біля вузла Q, бо `V_read < V_BL`)
   - Напруга на стоці: `V_d = V_DD` (підключений до BL)
   - Напруга затвор-витік: `V_gs,AX1 = V_DD − V_read`
   - Напруга стік-витік: `V_ds,AX1 = V_DD − V_read`
   - Оскільки `V_ds,AX1 = V_gs,AX1 > V_gs,AX1 − V_th,AX1`, транзистор `AX1` працює в **режимі насичення**.

```
I_ds,AX1 = ½ · β_AX · (V_DD − V_read − V_th,AX1)² [струм насичення транзистора AX1]
```

2. **Транзистор стягування N1 (nMOS Pull-down):**
   - Напруга на затворі: `V_g = V_QB = V_DD`
   - Напруга на витоку: `V_s = 0 В` (земля)
   - Напруга на стоці: `V_d = V_read`
   - Напруга затвор-витік: `V_gs,N1 = V_DD`
   - Напруга стік-витік: `V_ds,N1 = V_read`
   - Оскільки для збереження стійкості `V_read` має бути малим (`V_read ≪ V_DD − V_th,N1`), виконується умова `V_ds,N1 < V_gs,N1 − V_th,N1`. Отже, транзистор `N1` працює в **лінійному (тріодному) режимі**.

```
I_ds,N1 = β_PD · ((V_DD − V_th,N1) · V_read − ½ · V_read²) [лінійний струм транзистора N1]
```

#### Рівняння балансу струмів і розрахунок сплеску V_read

За першим законом Кірхгофа у вузлі `Q` струм, що втікає через `AX1`, дорівнює струму, що витікає через `N1`:

```
I_ds,AX1 = I_ds,N1                             [баланс струмів у вузлі Q]
```

Підставимо рівняння струмів:

```
½ · β_AX · (V_DD − V_read − V_th,AX1)² = β_PD · ((V_DD − V_th,N1) · V_read − ½ · V_read²)
```

Введемо коефіцієнт комірки **Cell Ratio (CR)** як відношення крутизни pull-down транзистора до крутизни транзистора доступу:

```
CR = β_PD ÷ β_AX = (W_PD / L_PD) ÷ (W_AX / L_AX) [визначення Cell Ratio]
```

Поділимо обидві частини рівняння на `β_AX`:

```
½ · (V_DD − V_read − V_th,AX1)² = CR · ((V_DD − V_th,N1) · V_read − ½ · V_read²)
```

Розкриємо квадрат і знехтуємо квадратичним членом `½ · (1 + CR) · V_read²` у першому лінійному наближенні (оскільки `V_read² ≪ V_DD²`):

```
½ · (V_DD − V_th,AX1)² − (V_DD − V_th,AX1) · V_read ≈ CR · (V_DD − V_th,N1) · V_read
```

Згрупуємо члени з `V_read`:

```
V_read · [CR · (V_DD − V_th,N1) + (V_DD − V_th,AX1)] ≈ ½ · (V_DD − V_th,AX1)²
```

Звідси отримуємо явний вираз для напруги збурення `V_read`:

```
V_read ≈ (V_DD − V_th,AX1)² ÷ [2 · CR · (V_DD − V_th,N1) + 2 · (V_DD − V_th,AX1)]
```

#### Критерій стійкості читання

Щоб комірка не перекинулася під час зчитування, напруга `V_read` у вузлі `Q` не повинна перевищити порогову напругу транзистора `N2` протилежного інвертора:

```
V_read < V_th,N2                               [критична умова неруйнівного читання]
```

Якщо `V_read ≥ V_th,N2`, транзистор `N2` почне відкриватися, опускаючи напругу на вузлі `QB` нижче `V_DD`. Це відкриє транзистор `P1`, що ще сильніше підніме напругу `Q`, і регенеративний зворотний зв'язок миттєво перекине комірку в протилежний стан (помилка читання).

З умови `V_read < V_th,N2` випливає обмеження знизу на коефіцієнт комірки `CR`:

```
CR > [(V_DD − V_th,AX1)² ÷ (2 · V_th,N2 · (V_DD − V_th,N1))] − [(V_DD − V_th,AX1) ÷ (V_DD − V_th,N1)]
```

У практичному проектуванні напівпровідникових мікросхем для забезпечення надійного статичного запасу завадостійкості читання (*Read SNM*) коефіцієнт комірки обирають у діапазоні:

```
CR = β_PD ÷ β_AX = 1.5 … 2.5                  [інженерний діапазон Cell Ratio]
```

### Динаміка розряду бітової лінії та час спрацьовування Sense Amplifier

Зчитування інформації з комірки — це не лише статичний подільник напруги, але й динамічний процес перезаряду ємності довгої бітової лінії `C_BL` (яка складається з ємності металевого провідника та сумарної ємності стоків усіх транзисторів доступу стовпця).

Типова ємність бітової лінії для стовпця з 256 або 512 комірок становить `C_BL ≈ 50 … 200 фФ`, що на два-три порядки перевищує власну внутрішню ємність вузла комірки `C_node ≈ 0.5 … 1 фФ`.

Струм зчитування `I_read`, що протікає крізь послідовно з'єднані транзистори `AX1` та `N1`, розряджає бітову лінію `BL`:

```
I_read = ½ · β_AX · (V_DD − V_read − V_th,AX1)² [струм розряду лінії BL]
```

Швидкість спаду напруги на лінії `BL` визначається фундаментальним рівнянням ємності:

```
d(V_BL) / dt = − I_read ÷ C_BL                 [швидкість розряду бітової лінії]
```

Оскільки диференційний підсилювач зчитування (*Sense Amplifier*) спрацьовує при досягненні мінімального диференційного перепаду `ΔV = V_BLB − V_BL` (типово `ΔV ≈ 50 … 100 мВ`), час формування сигналу зчитування `t_sense` становить:

```
t_sense = (C_BL · ΔV) ÷ I_read                 [час формування дельти напруги для SA]
```

Ця формула безпосередньо демонструє ключовий компроміс швидкодії:
- Збільшення ширини транзистора доступу `W_AX` підвищує `I_read` і скорочує час доступу `t_sense`.
- Проте це зменшує `Cell Ratio` і збільшує сплеск `V_read`, небезпечно знижуючи запас завадостійкості читання `RSNM`.

### Умова успішного запису та Pull-up Ratio (PR)

Під час запису нового значення стан комірки форсується зовнішніми потужними водіями запису (*Write Drivers*). Припустимо, комірка зберігає `Q = 1` (`V_DD`) та `QB = 0` (`0 В`), а ми хочемо записати `0` у вузол `Q`.

Для цього драйвер запису примусово садить лінію `BL` на землю (`BL = 0 В`), а лінію `BLB` підтягує до `V_DD`.

Коли словесна лінія `WL` активується (`WL = V_DD`), виникає протиборство у вузлі `Q`:
- Транзистор `P1` (PMOS pull-up) намагається утримати вузол `Q` на рівні живлення `V_DD` (`V_gs,P1 = V_QB − V_DD = 0 − V_DD = −V_DD`).
- Транзистор доступу `AX1` (NMOS access) намагається стягнути вузол `Q` до нуля лінії `BL` (`V_gs,AX1 = V_WL − V_BL = V_DD − 0 = V_DD`).

Щоб перезапис відбувся, транзистор `AX1` зобов'язаний опустити напругу вузла `Q` нижче напруги перемикання (*trip point* `V_trip`) другого інвертора `P2/N2`:

```
V_Q < V_trip ≈ ½ · V_DD                        [умова активації регенеративного запису]
```

#### Режими транзисторів під час запису нуля

Розглянемо точку, коли напруга на вузлі `Q` знижується до граничного значення `V_Q = V_trip`:

1. **Транзистор доступу AX1 (nMOS):**
   - Напруга на затворі: `V_g = V_DD`
   - Напруга на витоку: `V_s = V_BL = 0 В`
   - Напруга на стоці: `V_d = V_Q = V_trip`
   - Напруга затвор-витік: `V_gs,AX1 = V_DD`
   - Напруга стік-витік: `V_ds,AX1 = V_trip`
   - Якщо `V_trip < V_DD − V_th,AX1`, транзистор `AX1` працює в **лінійному режимі**:

```
I_ds,AX1 = β_AX · ((V_DD − V_th,AX1) · V_trip − ½ · V_trip²) [струм транзистора доступу AX1]
```

2. **Підтягувальний транзистор P1 (pMOS Pull-up):**
   - Напруга на затворі: `V_g = V_QB = 0 В`
   - Напруга на витоку: `V_s = V_DD`
   - Напруга на стоці: `V_d = V_Q = V_trip`
   - Напруга витік-затвор: `V_sg,P1 = V_DD`
   - Напруга витік-стік: `V_sd,P1 = V_DD − V_trip`
   - Оскільки `V_sd,P1 ≥ V_sg,P1 − |V_th,P1|` (при `V_trip ≤ |V_th,P1|`), транзистор `P1` працює в **режимі насичення**:

```
I_sd,P1 = ½ · β_PU · (V_DD − |V_th,P1|)²      [струм насичення транзистора P1]
```

#### Рівняння балансу та визначення Pull-up Ratio

Для успішного запису струм розряду через `AX1` має перевищувати струм підтяжки через `P1` у точці `V_trip`:

```
I_ds,AX1 > I_sd,P1                             [умова пересилення підтяжки]
```

Підставивши вирази струмів:

```
β_AX · ((V_DD − V_th,AX1) · V_trip − ½ · V_trip²) > ½ · β_PU · (V_DD − |V_th,P1|)²
```

Введемо коефіцієнт підтяжки **Pull-up Ratio (PR)** як відношення крутизни pull-up транзистора до крутизни транзистора доступу:

```
PR = β_PU ÷ β_AX = (W_PU / L_PU) ÷ (W_AX / L_AX) [визначення Pull-up Ratio]
```

Поділимо нерівність на `β_AX`:

```
PR < [2 · (V_DD − V_th,AX1) · V_trip − V_trip²] ÷ (V_DD − |V_th,P1|)²
```

Для забезпечення запасу завадостійкості запису (*Write Margin*) коефіцієнт підтяжки проектують у діапазоні:

```
PR = β_PU ÷ β_AX = 0.5 … 1.0                  [інженерний діапазон Pull-up Ratio]
```

Це означає, що транзистор доступу `AX1` повинен бути **сильнішим** за PMOS-транзистор підтяжки `P1`.

### Запас завадостійкості запису (Write Margin)

Запас запису (*Write Margin — WM*, або *Write SNM*) кількісно характеризує легкість перемикання комірки. Існує два взаємопов'язані способи його вимірювання:

1. **Критична напруга бітової лінії (`V_BL,crit`):** це максимальна напруга на лінії `BL`, за якої комірка ще гарантовано перемикається при повній амплітуді словесної лінії `WL = V_DD`:

```
WM_voltage = V_DD − V_BL,crit                  [запас запису по напрузі бітової лінії]
```

Якщо водій запису садить лінію `BL` до нуля, фактичний запас дорівнює `V_DD − V_BL,crit`. Чим вища напруга `V_BL,crit`, тим легше записати біт.

2. **Критична напруга словесної лінії (`V_WL,crit`):** це мінімальна амплітуда імпульсу `WL`, необхідна для перезапису при нульовій напрузі `BL = 0 В`:

```
WM_wordline = V_DD − V_WL,crit                 [запас запису по амплітуді словесної лінії]
```

При моделюванні метеликової кривої в режимі запису (коли `BL = 0 В` та `BLB = V_DD`), характеристика `VTC1` деформується настільки, що ліва пелюстка метелика повністю зникає, залишаючи лише одну точку перетину — цільовий новий стан `Q = 0, QB = 1`.

### Критична напруга утримання даних (DRV)

У режимах глибокого сну (*Deep Sleep / Retention Mode*) напругу живлення матриці SRAM `V_DD` навмисно знижують для мінімізації підпорогових струмів витоку. Граничною межею такого зниження є **напруга утримання даних** (*Data Retention Voltage — DRV*).

Математично `DRV` визначається як мінімальна напруга живлення, за якої статичний запас завадостійкості в режимі збереження ще є додатним:

```
V_DRV = min { V_DD | HSNM(V_DD) > 0 }          [визначення напруги утримання даних]
```

Коли `V_DD` опускається нижче `V_DRV`, підсилення розімкненого контуру інверторів стає меншим за одиницю (`A_loop < 1`) для всіх напруг, дві бістабільні точки рівноваги зливаються в одну центральну точку, і комірка незворотно втрачає збережений біт. У сучасних техпроцесах `V_DRV ≈ 0.35 … 0.50 В`.

### Динамічний запас завадостійкості (Dynamic Noise Margin — DNM)

Реальні завади в інтегральних схемах (наприклад, ємнісні наводки від сусідніх шин або імпульси просідання живлення) мають скінченну часову тривалість `T_pulse`. Статичний `SNM` оцінює стійкість до нескінченно довгого постійного зміщення, тому є найбільш консервативною (песимістичною) оцінкою.

Якщо тривалість імпульсу шуму `T_pulse` менша за власну постійну часу перезаряду вузла комірки `τ_node = R_eff · C_node` (типово `τ_node ≈ 10 … 50 пс`), комірка витримує значно вищі амплітуди шуму `V_noise,dyn > SNM`.

Критерієм перемикання стає критичний заряд завади `Q_crit`:

```
Q_crit = ∫ I_noise(t) dt > C_node · (V_DD − V_trip) [критерій динамічного перемикання]
```

Якщо внесений імпульсом завади заряд не перевищує `Q_crit`, регенеративний зворотний зв'язок інверторів відновлює вихідний рівень напруги після закінчення імпульсу без втрати даних.

### Температурний вплив на стабільність комірки

При зміні робочої температури кристала від кімнатної (`25 °C`) до максимальної робочої (`125 °C`) електричні параметри транзисторів змінюються:

1. **Зниження порогової напруги:** порогова напруга зменшується з коефіцієнтом `d(V_th) / dT ≈ −1.0 … −2.0 мВ/К`:

```
V_th(T) = V_th(T₀) + (d(V_th)/dT) · (T − T₀)  [температурний дрейф порогової напруги]
```

2. **Падіння рухливості носіїв:** розсіювання на теплових коливаннях кристалічної ґратки зменшує рухливість електронів і дірок `μ(T) ∝ T^(−1.5)`.

При нагріванні до `125 °C` порогова напруга `V_th,N2` падає приблизно на `100 … 150 мВ`. Це означає, що критичний бар'єр перемикання `V_read < V_th,N2` стає значно тоншим. Запас завадостійкості зчитування `RSNM` при `125 °C` зменшується на 20–30% порівняно з кімнатною температурою, що робить гарячий кристал особливо вразливим до збоїв читання.

### Практичний чисельний приклад розрахунку транзисторів 6T SRAM

**Вихідні параметри для 28-нм техпроцесу КМОН:**
- Напруга живлення: `V_DD = 0.9 В`
- Порогова напруга nMOS: `V_th,n = 0.30 В`
- Порогова напруга pMOS: `|V_th,p| = 0.30 В`
- Питома крутизна процесу: `k'_n = μ_n · C_ox = 400 мкА/В²`, `k'_p = μ_p · C_ox = 180 мкА/В²`
- Мінімальна довжина каналу для всіх транзисторів: `L = 28 нм`

#### Крок 1. Розрахунок геометрії для забезпечення стабільності читання (CR)

Приймемо мінімальну ширину каналу транзистора доступу: `W_AX = 40 нм`.

Обчислимо крутизну `β_AX`:

```
β_AX = 400 мкА/В² · (40 нм ÷ 28 нм) ≈ 571.4 мкА/В²
```

Встановимо цільовий сплеск напруги читання `V_read ≤ 0.15 В` (що значно менше за `V_th,N2 = 0.30 В`, забезпечуючи двократний запас):

Розрахуємо необхідний коефіцієнт `CR`:

```
CR = ½ · (V_DD − V_th,n)² ÷ [(V_DD − V_th,n) · V_read − ½ · V_read²]
CR = ½ · (0.9 − 0.3)² ÷ [(0.9 − 0.3) · 0.15 − ½ · 0.15²]
CR = ½ · (0.6)² ÷ [0.090 − 0.01125]
CR = 0.18 ÷ 0.07875 ≈ 2.286                   [розрахунковий Cell Ratio]
```

Звідси ширина каналу pull-down транзистора `N1`:

```
W_PD = CR · W_AX
W_PD = 2.286 · 40 нм ≈ 91.4 нм (обираємо 92 нм)
```

Крутизна `β_PD`:

```
β_PD = 400 мкА/В² · (92 нм ÷ 28 нм) ≈ 1314.3 мкА/В²
```

#### Крок 2. Розрахунок геометрії для забезпечення запису (PR)

Оберемо цільовий коефіцієнт підтяжки `PR = 0.60`.

Необхідна крутизна PMOS транзистора `P1`:

```
β_PU = PR · β_AX = 0.60 · 571.4 мкА/В² ≈ 342.8 мкА/В²
```

Обчислимо ширину каналу PMOS транзистора `P1` з урахуванням меншої рухливості дірок `k'_p`:

```
W_PU = (β_PU · L) ÷ k'_p
W_PU = (342.8 мкА/В² · 28 нм) ÷ 180 мкА/В² ≈ 53.3 нм (обираємо 54 нм)
```

#### Перевірка підсумкової ієрархії крутизни:

```
β_PD (1314 мкА/В²) > β_AX (571 мкА/В²) > β_PU (343 мкА/В²)
```

Умова `β_PD > β_AX > β_PU` повністю виконана, що гарантує одночасно високий запас завадостійкості читання `RSNM` та надійний запис `Write Margin`.

### Статистична варіативність Пелгрома та межа Vmin

У нанометрових масштабах ключовим дестабілізуючим фактором є випадкова флуктуація кількості домішок (*Random Dopant Fluctuation — RDF*) у каналі польового транзистора. Відповідно до емпіричного закону Пелгрома (*Pelgrom's Law*), середньоквадратичне відхилення порогової напруги `σ_Vth` обернено пропорційне кореню з площі каналу:

```
σ_Vth = A_VT ÷ √(W · L)                       [закон Пелгрома для дисперсії Vth]
```

де `A_VT` — технологічний коефіцієнт (типово `A_VT ≈ 1.2 … 2.0 мВ·мкм` для сучасних FinFET процесів).

Через малі розміри транзисторів SRAM-комірки площа `W · L` є мінімальною на кристалі, що робить комірки найбільш чутливими до варіативності `V_th`.

У великих масивах кеш-пам'яті (наприклад, 32 МБ L3 кешу містять `2.68 · 10⁸` комірок) для забезпечення безвідмовної роботи вимагається рівень надійності не менше `6σ`:

```
RSNM_mean − 6 · σ_RSNM > 0                     [критерій безвідмовності 6-сигма]
```

При зниженні напруги живлення `V_DD` середнє значення `RSNM_mean` падає лінійно, тоді як `σ_RSNM` залишається практично незмінним. У точці, де `RSNM_mean ≈ 6 · σ_RSNM`, досягається апаратна межа мінімальної напруги функціонування пам'яті — **Vmin Wall** (зазвичай `0.65 … 0.75 В` для 6T). Подолання цього бар'єра нижче 0.6 В вимагає переходу до 8T-архітектури або застосування спеціальних схем динамічного зміщення напруг.
