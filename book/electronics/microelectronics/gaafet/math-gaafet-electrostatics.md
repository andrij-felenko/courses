# 🧮 Електростатичне моделювання наношарів: рівняння Пуассона, натуральна довжина та DIBL

Математичний опис польового транзистора з круговим затвором базується на розв'язанні фундаментального тривимірного рівняння електростатики для просторового розподілу потенціалу всередині надтонкого напівпровідникового паралелепіпеда, оточеного з усіх чотирьох граней шаром діелектрика та металевим електродом. Без точного розрахунку цього розподілу неможливо довести, чому саме чотиристоронній затвор дозволяє скоротити довжину каналу `L_g` нижче 12 нанометрів без катастрофічного витоку струму.

### Тривимірне рівняння Пуассона для повністю збідненого наношару

Розглянемо монокристалічний кремнієвий наношар прямокутного поперечного перерізу, орієнтований уздовж декартових осей:
- Вісь `x` спрямована вздовж довжини каналу від витоку (`x = 0`) до стоку (`x = L_g`);
- Вісь `y` спрямована по вертикалі вздовж товщини наношару від нижньої грані (`y = -T_ns / 2`) до верхньої грані (`y = +T_ns / 2`);
- Вісь `z` спрямована по горизонталі вздовж ширини наношару від лівої бічної грані (`z = -W_ns / 2`) до правої бічної грані (`z = +W_ns / 2`).

У нелегованому або повністю збідненому кремнії густина вільних носіїв заряду та іонізованих домішок у підпороговому режимі є мізерно малою (`N_ch < 10¹⁵ см⁻³`). Тому об'ємна густина заряду `ρ ≈ 0`, і тривимірне рівняння Пуассона спрощується до рівняння Лапласа для електростатичного потенціалу `ψ(x, y, z)`:

```
∂²ψ/∂x² + ∂²ψ/∂y² + ∂²ψ/∂z²
= -ρ / ε_si       [тривимірне рівняння Пуассона для електростатичного потенціалу]
= 0               [наближення повністю збідненого нелегованого тіла: ρ ≈ 0]
```

де `ε_si = 11.7 · ε₀` — діелектрична проникність кремнію, `ε₀ = 8.854 · 10⁻¹² Ф/м` — електрична стала вакууму.

Граничні умови на чотирьох інтерфейсах кремній-діелектрик визначаються неперервністю нормальної складової вектора електричного зміщення `D = ε · E`:

На верхній та нижній горизонтальних гранях (`y = ±T_ns / 2`):

```
ε_si · (∂ψ/∂y)|_{y = ±T_ns/2} = ∓ (ε_ox / t_ox) · (V_gs - V_fb - ψ(x, ±T_ns/2, z))
```

На лівій та правій вертикальних бічних гранях (`z = ±W_ns / 2`):

```
ε_si · (∂ψ/∂z)|_{z = ±W_ns/2} = ∓ (ε_ox / t_ox) · (V_gs - V_fb - ψ(x, y, ±W_ns/2))
```

де `ε_ox` — діелектрична проникність підзатворного оксиду (для High-k діелектрика HfO₂ `ε_ox ≈ 20–25 · ε₀`), `t_ox` — фізична товщина діелектрика, `V_fb` — напруга плоских зон, обумовлена різницею робіт виходу металу затвора та кремнію, `V_gs` — прикладена напруга затвор-витік.

На торцях каналу задаються потенціали витоку й стоку з урахуванням контактної різниці потенціалів `V_bi` (вбудованого потенціалу переходу витік-канал):

```
ψ(0, y, z) = V_bi
ψ(L_g, y, z) = V_bi + V_ds
```

де `V_ds` — прикладена напруга між стоком і витоком транзистора.

### Аналітичний вивід натуральної довжини масштабування λ

Для аналітичного розв'язання тривимірного крайового завдання застосовують метод розділення змінних та параболічне наближення потенціалу за поперечними координатами `y` та `z` (наближення Юнга-Слевіча).

Запишемо двовимірний поперечний профіль потенціалу у вигляді суми парабол, що задовольняють симетрію відносно геометричного центра наношару:

```
ψ(x, y, z) = ψ_c(x) + c_y(x) · y² + c_z(x) · z²
```

де `ψ_c(x) = ψ(x, 0, 0)` — електростатичний потенціал уздовж центральної осьової лінії наношару, де затворний контроль є найслабшим і де за умов укорочення каналу найперше виникає паразитичний струм підпорогового витоку.

Підставивши параболічний профіль у граничні умови на границях діелектрика, знайдемо коефіцієнти `c_y(x)` та `c_z(x)`:

Для координати `y` вздовж товщини `T_ns`:

```
∂ψ/∂y|_{y = T_ns/2} = 2 · c_y(x) · (T_ns / 2) = c_y(x) · T_ns
```

Підставляючи в умову неперервності електричної індукції:

```
c_y(x)
= - (ε_ox / t_ox) · (V_gs - V_fb - ψ_c(x)) / (ε_si · T_ns + (ε_ox / t_ox) · (T_ns² / 4))     [гранична умова на поверхні діелектрика]
≈ - (V_gs - V_fb - ψ_c(x)) / ((ε_si / ε_ox) · t_ox · T_ns)                                  [нехтування квадратичним доданком товщини T_ns²/4]
```

Аналогічно для координати `z` вздовж ширини наношару `W_ns`:

```
c_z(x)
= - (ε_ox / t_ox) · (V_gs - V_fb - ψ_c(x)) / (ε_si · W_ns + (ε_ox / t_ox) · (W_ns² / 4))     [гранична умова на бічній поверхні]
≈ - (V_gs - V_fb - ψ_c(x)) / ((ε_si / ε_ox) · t_ox · W_ns)                                  [нехтування малим доданком W_ns²/4]
```

Обчислимо другі частинні похідні потенціалу за поперечними координатами:

```
∂²ψ/∂y²
= 2 · c_y(x)                                                    [диференціювання параболи c_y · y² двічі за y]
= - 2 · (V_gs - V_fb - ψ_c(x)) / ((ε_si / ε_ox) · t_ox · T_ns)  [підстановка знайденого коефіцієнта c_y]

∂²ψ/∂z²
= 2 · c_z(x)                                                    [диференціювання параболи c_z · z² двічі за z]
= - 2 · (V_gs - V_fb - ψ_c(x)) / ((ε_si / ε_ox) · t_ox · W_ns)  [підстановка знайденого коефіцієнта c_z]
```

Підставимо ці похідні назад у вихідне рівняння Пуассона вздовж центральної осі `y = 0, z = 0`:

```
∂²ψ_c(x)/∂x² + ∂²ψ/∂y² + ∂²ψ/∂z² = 0
```

Перегрупувавши доданки, отримаємо одновимірне рівняння для осьового потенціалу:

```
∂²ψ_c(x)/∂x² - (V_gs - V_fb - ψ_c(x)) · [ (2 · ε_ox) / (ε_si · t_ox · T_ns) + (2 · ε_ox) / (ε_si · t_ox · W_ns) ] = 0
```

Визначимо параметр **натуральної довжини електростатичного масштабування** `λ_gaa` через коефіцієнт при різниці потенціалів:

```
1 / λ_gaa²
= 1 / λ_y² + 1 / λ_z²                                                 [сума внесків вертикальних і горизонтальних обкладок затвора]
= [2 · ε_ox / (ε_si · t_ox · T_ns)] + [2 · ε_ox / (ε_si · t_ox · W_ns)] [підстановка других похідних потенціалу]
= (2 · ε_ox / (ε_si · t_ox)) · (1 / T_ns + 1 / W_ns)                  [винесення спільних множників за дужки]
= (2 · ε_ox / (ε_si · t_ox)) · ((W_ns + T_ns) / (W_ns · T_ns))        [зведення дробів до спільного знаменника]
```

Звідси отримуємо замкнений аналітичний вираз для натуральної довжини масштабування GAAFET:

```
λ_gaa
= √((ε_si · t_ox / (2 · ε_ox)) · ((W_ns · T_ns) / (W_ns + T_ns)))    [обернення дробу та добування квадратного кореня]
= √((ε_si / (2 · ε_ox)) · t_ox · T_ns / (1 + T_ns / W_ns))            [нормування товщини на коефіцієнт форми перерізу]
```

Для типового прямокутного наношару, де ширина значно перевищує товщину (`W_ns >> T_ns`, наприклад `W_ns = 35 нм`, `T_ns = 5 нм`), відношення `T_ns / W_ns ≈ 0.14`. Якщо ж наношар звужується до симетричної квадратної нанодротини (`W_ns = T_ns`), натуральна довжина зменшується до:

```
λ_sq
= √((ε_si / (2 · ε_ox)) · t_ox · T_ns / (1 + 1))  [підстановка W_ns = T_ns у формулу λ_gaa]
= √((ε_si / (4 · ε_ox)) · t_ox · T_ns)            [спрощення знаменника 2 · 2 = 4]
```

### Порівняння масштабних довжин: Planar vs FinFET vs GAAFET

Порівняємо отриману формулу з аналітичними виразами для трьох послідовних поколінь кремнієвих транзисторів:

1. **Планарний MOSFET (1 затвор зверху):**
   Електричне поле діє лише з одного боку через товщину підкладки `t_si`:
   ```
   λ_planar = √((ε_si / ε_ox) · t_ox · t_si)
   ```

2. **FinFET / Tri-Gate (2 бічні стінки + 1 верхня грань):**
   Електростатичний контроль визначається переважно шириною вертикального ребра `W_fin`:
   ```
   λ_fin = √((ε_si / (2 · ε_ox)) · t_ox · W_fin)
   ```

3. **GAAFET Nanosheet (4 замкнені грані навколо наношару):**
   ```
   λ_gaa = √((ε_si / (2 · ε_ox)) · t_ox · T_ns / (1 + T_ns / W_ns))
   ```

Виконаємо строгий чисельний розрахунок для геометрій нанометрових техпроцесів:
- Еквівалентна товщина оксиду: `EOT = (ε_sio2 / ε_ox) · t_ox = 0.8 нм`;
- Співвідношення діелектричних проникностей: `ε_si / ε_sio2 = 11.7 / 3.9 = 3.0`;
- Товщина наношару: `T_ns = 5.0 нм`, ширина `W_ns = 30.0 нм` (для GAAFET);
- Товщина ребра FinFET: `W_fin = 6.0 нм`;
- Товщина збідненої плівки планарного приладу: `t_si = 10.0 нм`.

Розрахуємо натуральну довжину для планарної структури:

```
λ_planar
= √(3.0 · 0.8 нм · 10.0 нм)   [підстановка параметрів: ε_si/ε_ox=3.0, EOT=0.8 нм, t_si=10.0 нм]
= √24.0 нм²                   [множення числових значень]
≈ 4.90 нм                     [добування квадратного кореня]
```

Розрахуємо натуральну довжину для тривимірного ребра FinFET:

```
λ_fin
= √(1.5 · 0.8 нм · 6.0 нм)    [підстановка коефіцієнтів для 2 бічних затворів: 3.0 / 2 = 1.5]
= √7.20 нм²                   [множення числових значень]
≈ 2.68 нм                     [добування квадратного кореня]
```

Розрахуємо натуральну довжину для чотиристороннього наношару GAAFET:

```
λ_gaa
= √(1.5 · 0.8 нм · (5.0 · 30.0 / (30.0 + 5.0)) нм)   [підстановка геометрії наношару T_ns=5, W_ns=30]
= √(1.2 · (150.0 / 35.0) нм²)                        [обчислення ефективної ширини перерізу]
= √(1.2 · 4.286 нм²)                                 [ділення 150 / 35]
= √5.143 нм²                                         [множення на фактор проникності 1.2]
≈ 2.27 нм                                            [добування квадратного кореня]
```

Для запобігання короткоканальному пробою мінімально допустима довжина затвора повинна задовольняти емпіричний критерій масштабування `L_g ≥ 3 · λ`:
- Для планарного MOSFET: `L_g,min ≥ 3 · 4.90 нм = 14.7 нм` (на практиці через витік у масивну підкладку межа становила `L_g ≈ 28–30 нм`);
- Для FinFET: `L_g,min ≥ 3 · 2.68 нм = 8.04 нм` (через витік під основою ребра реальна межа становила `L_g ≈ 14–16 нм`);
- Для GAAFET: `L_g,min ≥ 3 · 2.27 нм = 6.81 нм` (повна ізоляція каналу дозволяє скоротити фізичну довжину до `L_g ≈ 10–12 нм`).

### Квантово-розмірні поправки до порогової напруги (Quantum Confinement)

Коли товщина наношару `T_ns` зменшується до 5 нм і менше, хвильові функції електронів зазнають просторового квантового обмеження у вертикальному напрямку. Наношар перетворюється на одновимірну квантову яму зі скінченною висотою бар'єра.

Енергетичні рівні поперечного руху електронів квантуються за формулою розв'язку одновимірного рівняння Шредінгера:

```
E_n
= ℏ² · π² · n² / (2 · m_conf* · T_ns²)     [енергія n-го квантового підрівня в нескінченній прямокутній ямі]
```

де `ℏ = 1.0546 · 10⁻³⁴ Дж·с` — зведена стала Планка, `n = 1, 2, 3...` — головне квантове число, `m_conf*` — ефективна маса квантового обмеження для кремнію (для долин орієнтації (100) `m_conf* = 0.916 · m₀`, де `m₀ = 9.109 · 10⁻³¹ кг` — маса спокою електрона).

Зсув дна зони провідності вгору на величину енергії першого підрівня `E₁` збільшує ефективну ширину забороненої зони напівпровідника:

```
ΔE_g = E₁ = ℏ² · π² / (2 · m_conf* · T_ns²)
```

Цей енергетичний зсув безпосередньо збільшує порогову напругу транзистора `V_th`:

```
ΔV_th,qm = ΔE_g / q = (ℏ² · π²) / (2 · q · m_conf* · T_ns²)
```

Розрахуємо квантовий зсув порогової напруги для наношару товщиною `T_ns = 5.0 нм`:

```
ΔV_th,qm
= ((1.0546 · 10⁻³⁴)² · 3.14159²) / (2 · 1.6022 · 10⁻¹⁹ · 0.916 · 9.109 · 10⁻³¹ · (5.0 · 10⁻⁹)²)     [підстановка констант]
= (1.1122 · 10⁻⁶⁷ · 9.8696) / (2.6748 · 10⁻⁴⁸ · 25.0 · 10⁻¹⁸)                                      [піднесення до квадрата]
= 1.0977 · 10⁻⁶⁶ / 6.6870 · 10⁻⁶⁵                                                                   [перемноження чисельника й знаменника]
= 0.0164 В                                                                                          [ділення в системі СІ]
= 16.4 мВ                                                                                           [переведення у мілівольти]
```

Якщо ж товщина наношару зменшиться до `T_ns = 3.0 нм`:

```
ΔV_th,qm(3 нм)
= 16.4 мВ · (5.0 / 3.0)²     [обернено пропорційна залежність від квадрата товщини T_ns²]
= 16.4 мВ · 2.778            [квадрат відношення товщин (5/3)²]
= 45.6 мВ                    [результат квантового зсуву для надтонкого шару]
```

Отримана залежність демонструє сувору інженерну вимогу до технології епітаксії: дисперсія товщини наношарів `σ(T_ns)` по площі пластини не повинна перевищувати ±0.2 нм, інакше розкид порогових напруг через квантові ефекти порушить стабільність логічних схем.

### Квазібалістичний перенос і струм насичення в ультракоротких наношарах

При довжині каналу `L_g ≈ 10–12 нм` відстань між витоком і стоком стає порівнянною з довжиною вільного пробігу електронів за розсіюванням на акустичних фононах (`λ_mfp ≈ 10.5 нм` у чистому монокристалічному кремнії при кімнатній температурі). У такому режимі класична дрейфово-дифузійна модель з насиченням дрейфової швидкості втрачає точність, і струм описується **теорією квазібалістичного переносу Наторі-Люндстрома** *(Natori-Lundstrom ballistic model)*.

Згідно з цією теорією, електрони інжектуються з витоку через вершину потенціального бар'єра з тепловою швидкістю інжекції `v_inj`:

```
v_inj
= √(2 · k_B · T / (π · m_cond*))     [термодинамічна швидкість інжекції носіїв через потенціальний бар'єр]
```

де `m_cond* ≈ 0.19 · m₀` — ефективна маса електрона в напрямку провідності вздовж осі (110).

Підставивши фізичні константи для `T = 300 K`:

```
v_inj
= √(2 · 1.3806 · 10⁻²³ · 300 / (3.14159 · 0.19 · 9.109 · 10⁻³¹))     [підстановка констант у формулу швидкості]
= √(8.2836 · 10⁻²¹ / 5.4371 · 10⁻³¹)                                 [обчислення чисельника й знаменника]
= √1.5235 · 10¹⁰                                                     [ділення під коренем]
≈ 1.234 · 10⁵ м/с                                                    [добування квадратного кореня]
= 1.234 · 10⁷ см/с                                                   [переведення в см/с]
```

Швидкість інжекції `v_inj ≈ 1.23 · 10⁷ см/с` помітно перевищує фундаментальну швидкість насичення дрейфу в масивному кремнії (`v_sat ≈ 1.0 · 10⁷ см/с`) внаслідок ефекту балістичного перельоту *(velocity overshoot)*.

Струм квазібалістичного насичення на одиницю ширини каналу визначається коефіцієнтом балістичної передачі `T_bal`:

```
I_d,sat = W_eff · Q_inv(0) · v_inj · ((1 - r) / (1 + r))
```

де `Q_inv(0) = C_ox · (V_gs - V_th)` — інверсійний заряд на вершині бар'єра (біля віртуального витоку), `r = 1 - T_bal` — коефіцієнт зворотного розсіювання носіїв у витік.

Коефіцієнт балістичності `T_bal` описується формулою Мак-Келві:

```
T_bal = λ_mfp / (λ_mfp + l_kT)
```

де `l_kT` — критична довжина приповерхневої області витоку, на якій електростатичний потенціал спадає на величину теплового потенціалу `k_B · T / q ≈ 26 мВ`. Для крутого профілю потенціалу GAAFET довжина `l_kT` становить лише 1.5–2.0 нм.

Розрахуємо коефіцієнт балістичності для GAAFET з довжиною затвора `L_g = 12 нм`:

```
T_bal
= 10.5 нм / (10.5 нм + 1.8 нм)   [підстановка довжини пробігу λ_mfp=10.5 нм та l_kT=1.8 нм]
= 10.5 / 12.3                    [додавання довжин у знаменнику]
≈ 0.854                          [коефіцієнт балістичності перенесення носіїв: 85.4%]
```

Коефіцієнт відбиття електронів становить лише `r = 1 - 0.854 = 0.146`. Фактор балістичного посилення струму:

```
(1 - r) / (1 + r)
= (1 - 0.146) / (1 + 0.146)     [підстановка коефіцієнта зворотного розсіювання]
= 0.854 / 1.146                 [обчислення чисельника й знаменника]
≈ 0.745                         [балістичний коефіцієнт струму насичення]
```

Це доводить, що 75% теоретичного балістичного струму безперешкодно досягає стоку без жодного зіткнення з кристалічною ґраткою кремнію.

### Паразитний послідовний опір витоку та стоку (R_sd)

Реальний струм транзистора в інтегральній схемі обмежений не лише провідністю самого каналу, а й паразитним послідовним опором контактів та епітаксійних областей витоку/стоку `R_sd = R_s + R_d`.

У GAAFET повний опір витоку `R_s` складається з трьох послідовних компонентів:

```
R_s = R_cont + R_geom + R_ext
```

1. **Контактний опір `R_cont` на межі силіцид-напівпровідник:**
   ```
   R_cont = ρ_c / A_cont
   ```
   де `ρ_c` — питомий контактний опір інтерфейсу (для сучасних силіцидів титану TiSi_x на сильно легованому Si:P або SiGe:B `ρ_c ≈ 1.0–1.5 · 10⁻⁹ Ом·см²`), `A_cont` — площа контакту.

2. **Геометричний опір розтікання струму `R_geom`:**
   Опір усередині об'єму гранованого епітаксійного кристала S/D при переході струму від широкого верхнього контакту до окремих тонких наношарів:
   ```
   R_geom ≈ (ρ_sd / (2 · π · W_ns)) · ln(H_stack / T_ns)
   ```
   де `ρ_sd` — питомий опір сильно легованого кремнію витоку (`≈ 0.5–0.8 мОм·см`), `H_stack` — повна висота стосу наношарів.

3. **Опір подовження наношару `R_ext` під внутрішнім спейсером:**
   ```
   R_ext = ρ_ext · L_sp / (N_ns · W_ns · T_ns)
   ```
   де `L_sp` — товщина внутрішнього спейсера (`5–6 нм`), `ρ_ext` — питомий опір слаболегованої перехідної області під спейсером.

Розрахуємо деградацію крутизни характеристики транзистора `g_m` через вплив паразитного опору витоку `R_s`:

```
g_m,ext
= g_m,int / (1 + g_m,int · R_s)     [вплив від'ємного зворотного зв'язку за напругою витоку]
```

Для типових значень GAAFET `g_m,int = 3.2 мСм/мкм` та `R_s = 150 Ом·мкм`:

```
g_m,int · R_s
= 3.2 · 10⁻³ См/мкм · 150 Ом·мкм     [перемноження внутрішньої крутизни на опір витоку]
= 0.48                               [безрозмірний фактор деградації крутизни]

g_m,ext
= 3.2 мСм/мкм / (1 + 0.48)           [підстановка фактора у формулу крутизни]
= 3.2 / 1.48                         [ділення значень]
≈ 2.16 мСм/мкм                       [реальна виміряна крутизна транзистора на контактах]
```

Цей розрахунок доводить, що паразитно втрачається до 32% теоретичного підсилення транзистора, тому зниження контактного опору `ρ_c` та оптимізація форми внутрішніх спейсерів є критично важливими інженерними завданнями на рівні з літографією затвора.

### Повна ємнісна модель: бічні поля розсіювання та оверлап

Динамічна ємність затвора GAAFET визначається не лише площею контакту з чотирма гранями наношарів, а й просторовим розподілом ліній електричного поля на торцях та бічних кутах структури. Повна ємність затвора `C_gg` розкладається на такі складові:

```
C_gg = C_gc + 2 · C_ov + 2 · C_of + C_sp
```

1. **Ємність інверсійного каналу `C_gc`:**
   ```
   C_gc = W_eff · L_g · (ε_ox / t_ox)
   ```
2. **Ємність прямого перекриття затвора з витоком/стоком `C_ov`:**
   Виникає через дифузійне затікання домішок легування S/D під торці металевого затвора на глибину `L_ov ≈ 1.0–1.5 нм`:
   ```
   C_ov = W_eff · L_ov · (ε_ox / t_ox)
   ```
3. **Ємність зовнішнього розсіювання `C_of` (Outer Fringe Capacitance):**
   Лінії поля, що проходять крізь діелектрик верхнього спейсера від бічної стінки металевого затвора до скошеної грані епітаксійного витоку:
   ```
   C_of ≈ (2 · ε_spacer / π) · W_eff · ln(1 + T_gate / t_ox)
   ```
4. **Ємність внутрішнього спейсера `C_sp` (Inner Spacer Capacitance):**
   Електричне поле в проміжках між вертикально сусідніми наношарами крізь діелектрик SiBCN:
   ```
   C_sp = 2 · (N_ns - 1) · (ε_sp / L_sp) · W_ns · T_sus
   ```

### Температурна залежність підпорогового схилу та кріогенне масштабування

Залежність підпорогового схилу від абсолютної температури `T` має фундаментальний лінійний характер:

```
SS(T) = ln(10) · (k_B · T / q) · m
```

Розрахуємо теоретичний і реальний підпороговий схил GAAFET для трьох характерних температурних режимів:

1. **Гарячий кристал під навантаженням (`T = 373 K` / `100 °C`, `m = 1.06`):**
   ```
   SS(373 K)
   = 2.302585 · (1.3806 · 10⁻²³ · 373 / 1.6022 · 10⁻¹⁹) · 1.06   [підстановка робочої температури кристала]
   = 2.302585 · 0.03214 В · 1.06                                  [обчислення термічного потенціалу V_T=32.14 мВ]
   ≈ 78.4 мВ/дек                                                  [підпороговий схил гарячого процесора]
   ```

2. **Кімнатна температура (`T = 300 K` / `27 °C`, `m = 1.06`):**
   ```
   SS(300 K)
   = 2.302585 · 0.02585 В · 1.06                                  [підстановка стандартної температури]
   ≈ 63.1 мВ/дек                                                  [номінальний підпороговий схил]
   ```

3. **Кріогенне охолодження рідким азотом (`T = 77 K` / `-196 °C`, `m = 1.04`):**
   ```
   SS(77 K)
   = 2.302585 · (1.3806 · 10⁻²³ · 77 / 1.6022 · 10⁻¹⁹) · 1.04     [підстановка кріогенної температури азоту]
   = 2.302585 · 0.006635 В · 1.04                                 [термічний потенціал V_T=6.64 мВ]
   ≈ 15.9 мВ/дек                                                  [надкрутий схил при охолодженні рідким азотом]
   ```

Зниження підпорогового схилу до 16 мВ/дек при 77 K дозволяє зменшити напругу живлення процесора `V_dd` з 0.7 В до 0.25 В без збільшення струму витоку, що скорочує динамічне енергоспоживання у `(0.7 / 0.25)² ≈ 7.8` раза.

### Вплив на стабільність SRAM-комірок кеш-пам'яті (SNM)

Підвищення струму `I_on` та зниження розкиду порогових напруг `σ(V_th)` у наношарах кардинально покращує **статичний запас стійкості проти шуму** *(Static Noise Margin, SNM)* у 6-транзисторних комірках SRAM *(6T-SRAM)*.

Запас стійкості комірки пам'яті в режимі зберігання `SNM_hold` визначається діагоналлю найбільшого квадрата, вписаного у метеликоподібну передавальну характеристику двох взаємопов'язаних інверторів:

```
SNM_hold ≈ (V_dd - V_th) / (1 + r_inv)
```

де `r_inv = √(β_n / β_p)` — коефіцієнт асиметрії провідностей nMOS і pMOS транзисторів. Завдяки довільному вибору ширини наношарів `W_ns` схемотехніки вперше змогли встановити ідеальний баланс `β_n = β_p` (`r_inv = 1.00`), збільшивши `SNM_hold` на 22% порівняно з фіксованими ребрами FinFET за напруги живлення `V_dd = 0.65 В`.

### Розподіл потенціалу вздовж каналу та мінімум бар'єра

Одновимірне диференціальне рівняння для центрального потенціалу `ψ_c(x)` вздовж каналу має вигляд:

```
d²ψ_c(x)/dx² - (ψ_c(x) - (V_gs - V_fb)) / λ_gaa² = 0
```

Загальний розв'язок цього лінійного неоднорідного рівняння другого порядку записується через гіперболічні функції:

```
ψ_c(x) = (V_gs - V_fb) + A · sinh((L_g - x) / λ_gaa) / sinh(L_g / λ_gaa) + B · sinh(x / λ_gaa) / sinh(L_g / λ_gaa)
```

де коефіцієнти `A` та `B` визначаються граничними умовами на витоку й стоку:

```
A = V_bi - (V_gs - V_fb)
B = V_bi + V_ds - (V_gs - V_fb)
```

Потенціальний бар'єр для електронів визначається точкою мінімуму функції `ψ_c(x)`: `dψ_c/dx|_{x = x_min} = 0`.
Знайдемо рівняння для положення віртуального витоку `x_min`:

```
dψ_c/dx
= - (A / λ_gaa) · cosh((L_g - x) / λ_gaa) / sinh(L_g / λ_gaa) + (B / λ_gaa) · cosh(x / λ_gaa) / sinh(L_g / λ_gaa) [диференціювання гіперболічного синуса]
= 0                                                                                                                 [умова екстремуму потенціалу]
```

Звідси положення мінімуму бар'єра визначається рівністю:

```
A · cosh((L_g - x_min) / λ_gaa) = B · cosh(x_min / λ_gaa)
```

Для довгого каналу (`L_g >> λ_gaa`) точка мінімуму розташована поблизу середини каналу: `x_min ≈ L_g / 2`.
Мінімальний потенціал на бар'єрі `ψ_min` записується у вигляді:

```
ψ_min
= (V_gs - V_fb) + 2 · √(A · B) · exp(-L_g / (2 · λ_gaa))     [асимптотичний розклад при L_g / λ_gaa >> 1]
```

### Моделювання ефекту DIBL (Drain-Induced Barrier Lowering)

Зниження бар'єра полем стоку (DIBL) вимірює, на скільки мілівольтів зміщується порогова напруга транзистора `V_th` при збільшенні напруги стоку `V_ds` на 1 Вольт:

```
DIBL = - ΔV_th / ΔV_ds = (∂ψ_min / ∂ V_ds) / (∂ψ_min / ∂ V_gs)
```

Диференціюючи вираз для `ψ_min` за `V_ds`:

```
∂ψ_min / ∂ V_ds
= √(A / B) · exp(-L_g / (2 · λ_gaa))
```

У практичних інженерних розрахунках застосовують лінеаризовану формулу DIBL у мВ/В:

```
DIBL = 1000 · (V_bi - 2 · Φ_B) · exp(-L_g / (2 · λ_gaa))
```

де `Φ_B = (k_B · T / q) · ln(N_ch / n_i) ≈ 0.35 В` — потенціал Фермі кремнію, `V_bi ≈ 0.95 В`.

Розрахуємо значення DIBL для техпроцесу 2 нм з довжиною затвора `L_g = 14 нм`:

1. Для FinFET (`λ_fin = 2.68 нм`):
   ```
   DIBL_fin
   = 1000 · (0.95 - 0.70) · exp(-14.0 / (2 · 2.68))   [підстановка L_g=14 нм, λ_fin=2.68 нм]
   = 250 · exp(-2.612)                                [обчислення показника експоненти 14 / 5.36]
   = 250 · 0.0734                                     [обчислення експоненти]
   = 18.35 мВ/В                                       [ідеальне значення; з урахуванням sub-fin витоку: ~70–85 мВ/В]
   ```

2. Для GAAFET Nanosheet (`λ_gaa = 2.27 нм`):
   ```
   DIBL_gaa
   = 1000 · (0.95 - 0.70) · exp(-14.0 / (2 · 2.27))   [підстановка L_g=14 нм, λ_gaa=2.27 нм]
   = 250 · exp(-3.084)                                [обчислення показника експоненти 14 / 4.54]
   = 250 · 0.0458                                     [обчислення експоненти]
   = 11.45 мВ/В                                       [ідеальне значення; реальний вимір на кристалі: < 35 мВ/В]
   ```

### Розрахунок ефективної провідної ширини W_eff та струму Id

Повний струм відкритого транзистора `I_on` прямо пропорційний сумарній ефективній ширині каналу `W_eff`.

Для стосу з `N_ns` вертикально розташованих прямокутних наношарів (де кожен шар оточений затвором по всьому периметру `P = 2 · W_ns + 2 · T_ns`):

```
W_eff,gaa = N_ns · (2 · W_ns + 2 · T_ns)
```

Для стандартного 3-шарового GAAFET (`N_ns = 3`, `W_ns = 35 нм`, `T_ns = 5 нм`):

```
W_eff,gaa
= 3 · (2 · 35 нм + 2 · 5 нм)     [підстановка ширини W_ns=35 нм і товщини T_ns=5 нм для 3 шарів]
= 3 · (70 нм + 10 нм)           [множення граней наношару]
= 3 · 80 нм                     [сума периметра одного наношару]
= 240 нм                        [повна ефективна ширина провідного каналу GAAFET]
```

Порівняємо це з 2-реберним FinFET (`N_fin = 2`, `H_fin = 45 нм`, `W_fin = 6 нм`):

```
W_eff,fin
= N_fin · (2 · H_fin + W_fin)   [формула ефективної ширини ребра FinFET: 2 бічні стінки + верхня грань]
= 2 · (2 · 45 нм + 6 нм)        [підстановка висоти H_fin=45 нм та товщини W_fin=6 нм для 2 ребер]
= 2 · (90 нм + 6 нм)            [множення бічних граней]
= 2 · 96 нм                     [периметр одного ребра]
= 192 нм                        [повна ефективна ширина каналу FinFET]
```

Порівняння провідної ширини на одній площі стандартної комірки:

```
ΔW_eff
= (W_eff,gaa - W_eff,fin) / W_eff,fin   [відносне зростання ефективної провідної ширини]
= (240 нм - 192 нм) / 192 нм            [підстановка значень 240 нм та 192 нм]
= 48 нм / 192 нм                        [різниця провідної ширини]
= +25.0%                                [відносний виграш у провідній ширині каналу]
```

### Динамічна швидкодія та метрика затримки перемикання CV / I

Час затримки перемикання логічного інвертора `t_delay` оцінюється метрикою перезаряджання сумарної вхідної ємності затвора `C_gg` струмом насичення `I_on`:

```
t_delay = (C_gg · V_dd) / I_on
```

Обчислимо інтегральний виграш у швидкодії для робочої напруги `V_dd = 0.7 В`. Завдяки зростанню `W_eff` на +25% струм відкритого стану `I_on` зростає з 1.2 мА до 1.5 мА. При зростанні сумарної ємності `C_gg` лише на +8% (завдяки застосуванню low-k діелектриків SiBCN у внутрішніх спейсерах) динамічна затримка скорочується:

```
t_delay,gaa / t_delay,fin
= (1.08 · C_fin · V_dd / (1.25 · I_fin)) / (C_fin · V_dd / I_fin)   [відношення затримок перемикання]
= 1.08 / 1.25                                                       [скорочення спільних множників]
= 0.864                                                             [коефіцієнт скорочення затримки]
= -13.6%                                                            [чистий виграш у затримці логічного перемикання]
```

Отриманий 14-відсотковий виграш у затримці безпосередньо транслюється у підвищення максимальної тактової частоти процесорних ядер за збереження однакового теплового бюджету.
