Коли довжина затвора тривимірного транзистора [FinFET](book:electronics/finfet) скоротилася нижче 14 нанометрів на технологічних нормах 3 нм і 2 нм, тристоронній електростатичний контроль ребра вичерпав свій фізичний потенціал: електричне поле стоку почало пробивати неізольовану основу ребра в місці його з'єднання з масивною підкладкою, викликаючи неконтрольоване падіння порогової напруги та різке зростання струмів підпорогового витоку. Спроби звузити кремнієве ребро менш ніж до 5 нанометрів спричинили катастрофічну деградацію рухливості електронів через квантове обмеження та поверхневе розсіювання, а збільшення висоти ребра призвело до механічної нестабільності, вигину кремнієвих пластин і вибухового зростання паразитної ємності.

Другим критичним глухим кутом FinFET стала неможливість гнучкого регулювання струму через дискретне квантування ширини каналу: схемотехнік міг обрати лише 1, 2 або 3 цілі ребра на транзистор. У надщільних стандартних комірках висотою 5 треків (5T) вміщувалося лише одне ребро на прилад, що жорстко обмежувало вихідний струм і швидкодію процесорних блоків.

Єдиним фундаментальним вирішенням обох криз став перехід до транзисторів із круговим затвором — **GAAFET** *(Gate-All-Around Field-Effect Transistor)* на горизонтальних **наношарах** *(nanosheets)* або **нанострічках** *(nanoribbons)*, відомих у промисловості також як **MBCFET** *(Multi-Bridge-Channel FET)*. Завдяки розділенню суцільного ребра на стос паралельних надтонких кремнієвих пластин і повному оточенню кожної пластини металевим затвором з усіх чотирьох боків, електростатичний контроль каналу сягнув теоретичного максимуму, повністю ліквідувавши шляхи паразитного витоку через підкладку та повернувши розробникам можливість довільного плавного вибору ширини транзистора.

### Глухий кут FinFET: витік під основою ребра та дискретність ширини каналу

У тривимірному транзисторі FinFET кремнієвий канал піднято над діелектриком STI у вигляді тонкого вертикального ребра, яке затвор огортає з трьох поверхонь: верхньої та двох бічних стінок. Ця геометрія домінувала в мікроелектроніці понад десятиліття — від вузла 22 нм у 2011 році до вузлів 5 нм і 3 нм на початку 2020-х років. Проте подальше геометричне масштабування зіткнулося з трьома фундаментальними фізичними бар'єрами:

1. **Паразитний витік під основою ребра (Sub-Fin Leakage):**
   Основа кремнієвого ребра безпосередньо монолітно з'єднана з об'ємною кремнієвою підкладкою під шаром ізоляції STI. На відміну від бічних стінок, нижня грань ребра не має металевого електрода затвора. При скороченні фізичної довжини затвора `L_g < 14 нм` лінії електричного поля позитивно зміщеного стоку починають вільно проникати крізь товщу слаболегованої підреберної області безпосередньо до витоку. Виникає важкий ефект [зниження бар'єра полем стоку](book:electronics/subthreshold-leakage) *(Drain-Induced Barrier Lowering, DIBL)*, що сягає `80–110 мВ/В`, внаслідок чого закритий транзистор продовжує пропускати масивний [підпороговий струм витоку](book:electronics/subthreshold-leakage) в обхід верхнього керуючого затвора.

2. **Крах рухливості при звуженні ребра:**
   Щоб придушити підпороговий витік за формулою натуральної довжини FinFET `W_fin ≤ L_g / 2`, товщину ребра `W_fin` на вузлах 3 нм довелося зменшити до 5–6 нм. За такої товщини поперечний рух носіїв заряду зазнає квантово-розмірного обмеження: хвильові функції електронів стискаються, а дно зони провідності зміщується вгору. Електрони та дірки починають рухатися в безпосередній близькості до атомних дефектів поверхні поділу Si-HfO₂, що викликає катастрофічне розсіювання на шорсткостях інтерфейсу *(surface roughness scattering)*. Рухливість носіїв падає більш ніж удвічі, зводячи нанівець будь-який приріст провідності від укорочення каналу.

3. **Дискретне квантування ефективної ширини каналу (Width Quantization):**
   Ефективна провідна ширина одного ребра FinFET строго фіксована його геометричною висотою `H_fin` та шириною `W_fin`:
   ```
   W_eff = 2 · H_fin + W_fin
   ```
   Щоб збільшити струм відкритого стану `I_on` у критичних логічних вентилях або підсилювачах, конструктор був змушений додавати друге паралельне ребро, стрибкоподібно подвоюючи ширину (`2 × W_eff`), що подвоювало вхідну ємність і збільшувало площу комірки. Проміжні значення струму були фізично неможливими. У надщільних стандартних комірках висотою 5.0T або 4.5T крок між ребрами *(Fin Pitch ≈ 24–28 нм)* взагалі не дозволяє встановити два ребра поруч: комірка стає строго однореберною (1-Fin), втрачаючи здатність керувати великими ємнісними навантаженнями довгих з'єднань.

![Порівняння планарного MOSFET, FinFET і GAAFET: перехід від 1D до 3D і 4D кругового електростатичного контролю каналу](/book/electronics/microelectronics/gaafet/img/planar-vs-finfet-vs-gaafet.svg)
*Еволюція електростатичного контролю: у планарному транзисторі затвор діє лише зверху, дозволяючи полю стоку пробивати підкладку; у FinFET затвор охоплює ребро з трьох боків, але залишає відкритим дно ребра (sub-fin leakage); у GAAFET кожен горизонтальний наношар повністю оточений металевим затвором з усіх 4 боків, що усуває будь-які паразитичні шляхи витоку.*

Детальніше про те, як світова наука долала ці обмеження протягом 35 років і як перші експерименти Жана-П'єра Коланжа переросли у промислову гонку нанометрових гігантів, викладено в [📜 історії транзисторів із круговим затвором](book:electronics/gaafet/hist-gaafet-evolution.md).

> 🔧 **Навіщо це.** Без переходу на наношари закон масштабування мікросхем зупинився б на вузлі 3 нм: транзистори FinFET споживали б неприпустимо багато енергії у стані спокою через підреберний витік DIBL, а процесори смартфонів та серверів не змогли б нарощувати кількість ядер без ризику теплового розгону кристала.

### Архітектура наношарів (Nanosheet / MBCFET): повне чотиристороннє оточення каналу

Фізична сутність технології GAAFET полягає в перетворенні одного суцільного вертикального ребра на вертикальний стос із кількох (зазвичай 3 або 4) горизонтальних кремнієвих пластин надмалої товщини — **наношарів** *(nanosheets)* або **нанострічок** *(nanoribbons)*, розташованих одна над одною з мікроскопічним проміжком.

Ключовими геометричними параметрами наношару є:
- **Ширина наношару** `W_ns` — від 15 до 50 нм;
- **Товщина наношару** `T_ns` — від 5 до 6 нм;
- **Вертикальний проміжок між шарами** `T_sus` (зазор підвішування) — від 8 до 10 нм;
- **Фізична довжина затвора** `L_g` — від 10 до 14 нм.

Металевий затвор за технологією [HKMG](book:electronics/hkmg) заповнює весь простір навколо наношарів, утворюючи неперервну монолітну сорочку: він огортає верхню грань, нижню грань, ліву бічну стінку та праву бічну стінку кожного окремого шару в стосі.

Повний замкнений контур затвора забезпечує чотири кардинальні фізичні переваги:

1. **Повна ліквідація шляхів паразитного витоку (Нульовий Sub-Fin Leakage):**
   Оскільки найнижчий наношар відділений від кремнієвої підкладки суцільним шаром нижнього металевого затвора та товстим шаром ізолюючого діелектрика, лінії електричного поля стоку не мають жодного фізичного шляху проникнення до витоку через напівпровідникову основу.

2. **Ідеальний підпороговий схил (Subthreshold Swing):**
   Завдяки чотиристоронньому ємнісному стисканню весь об'єм кожного наношару товщиною 5 нм перебуває під безпосереднім електростатичним контролем найближчої металевої обкладки на відстані не більше 2.5 нм. Фактор неідеальності затвора сягає свого теоретичного мінімуму `m ≈ 1.05`, а підпороговий схил наближається до фундаментальної границі Больцмана:
   ```
   SS = ln(10) · (k_B · T / q) · m ≈ 63–65 мВ/дек      [при T = 300 K]
   ```
   Це дозволяє знизити напругу живлення процесорів `V_dd` до 0.65–0.70 В без загрози втрати логічних рівнів.

3. **Радикальне придушення ефекту DIBL:**
   Параметр зниження бар'єра полем стоку у наношарах зменшується до `DIBL < 35–40 мВ/В` (порівняно з `80–100 мВ/В` у FinFET), що усуває зсув порогової напруги при зміні потенціалу на стоці.

4. **Плавне масштабування ефективної ширини каналу W_eff:**
   Сумарна провідна ширина транзистора розраховується як периметр усіх чотирьох граней, помножений на кількість наношарів `N_ns`:
   ```
   W_eff = N_ns · (2 · W_ns + 2 · T_ns)
   ```
   Для стандартного 3-шарового GAAFET із шириною шару `W_ns = 35 нм` та товщиною `T_ns = 5 нм`:
   ```
   W_eff = 3 · (2 · 35 нм + 2 · 5 нм) = 3 · 80 нм = 240 нм
   ```
   У тій самій стандартній комірці висотою 5T три наношари дають на **25–40% більший вихідний струм `I_on`**, ніж однореберний або двореберний FinFET, займаючи істотно меншу площу кристала.

Строге математичне виведення натуральної довжини масштабування `λ_gaa` з тривимірного рівняння Пуассона та розрахунок квантово-розмірних поправок наведено в [🧮 математичному моделюванні електростатики наношарів](book:electronics/gaafet/math-gaafet-electrostatics.md).

### Технологічний маршрут виготовлення: суперґратки Si/SiGe та внутрішні спейсери

Виготовлення транзисторів GAAFET вимагає принципово нових матеріалознавчих і літографічних операцій на межі атомарної точності. Головна складність полягає в тому, що наношари не можна просто вирізати з масивного кремнію зверху вниз за допомогою звичайної плазмохімічної анізотропної літографії — їх формують за допомогою складного хімічного вивільнення підвішених структур.

![Технологічний маршрут виготовлення наношарів GAAFET: від епітаксії суперґратки Si/SiGe до нанесення фінального затвора HKMG](/book/electronics/microelectronics/gaafet/img/gaafet-fabrication-flow.svg)
*Шість ключових фаз виготовлення GAAFET: 1 — епітаксія чергованих шарів Si/SiGe; 2 — формування ребра та фіктивного затвора (Dummy Gate); 3 — бокове вибіркове травлення SiGe і нанесення внутрішніх спейсерів SiBCN; 4 — епітаксійне нарощування контактів витоку/стоку; 5 — вивільнення наношарів селективним розчиненням SiGe; 6 — кругове осадження затвора HKMG навколо кожного шару.*

Технологічний цикл складається з шести послідовних нанометрових етапів:

#### 1. Епітаксійне вирощування суперґратки Si / SiGe
На вихідну монокристалічну кремнієву пластину методом хімічного осадження з газової фази (CVD) почергово осаджують атомарно гладкі епітаксійні шари:
- **Шари каналу:** чистий монокристалічний кремній (Si) товщиною 5–6 нм;
- **Жертовні шари:** псевдоморфний сплав кремній-германію `Si₀.₇₅Ge₀.₂₅` (25% атомів германію) товщиною 8–10 нм.

Утворюється багатошаровий сендвіч (суперґратка) із 3–4 пар шарів. Точність товщини кожного шару контролюється з прецизійністю до одного моноатомного шару (±0.2 нм).

Різниця сталих кристалічної ґратки кремнію (`a_si = 5.431 Å`) та германію (`a_ge = 5.658 Å`) створює внутрішнє псевдоморфне двовісне стиснення шарів SiGe. Щоб запобігти утворенню дислокацій невідповідності (дислокацій Метьюза-Блекслі), товщину кожного шару SiGe витримують суворо нижче критичної межі пружної деформації (менш ніж 12 нм).

#### 2. Травлення ребер та фіктивний затвор (Dummy Gate)
За допомогою [EUV-фотолітографії](book:electronics/photolithography) та анізотропного реактивно-іонного травлення (RIE) багатошаровий пиріг прорізають вертикально вниз, формуючи високі вузькі ребра суперґратки. Потім поперек ребер наносять жертовний фіктивний затвор із полікремнію *(dummy poly gate)*, який тимчасово задає положення майбутнього робочого затвора `L_g`.

#### 3. Формування внутрішніх спейсерів (Inner Spacers)
Це найбільш критичний і технічно складний етап створення GAAFET:
1. За допомогою прецизійного газофазного або рідкого ізотропного травлення кінці жертовних шарів SiGe селективно витравлюють з боків ребра на глибину 5–6 нм всередину під фіктивний затвор, утворюючи крихітні бічні порожнини. Кремнієві шари Si при цьому залишаються абсолютно неушкодженими.
2. Методом конформного атомарно-шарового осадження (ALD) усю пластину вкривають ультратонким шаром діелектрика з низькою проникністю — **SiBCN** або **SiOCN** (`k ≈ 4.0–4.5`).
3. Виконують делікатне ізотропне зворотне травлення діелектрика, залишаючи акуратні діелектричні пробки лише всередині витравлених порожнин SiGe.

Ці діелектричні вставки — **внутрішні спейсери** *(inner spacers)* — виконують вирішальну роль: вони надійно ізолюють майбутній металевий затвор від контакту з областями витоку й стоку, знижуючи паразитну ємність перекриття `C_gd` та `C_gs` на 30–40%.

#### 4. Епітаксійне вирощування витоку й стоку (Source / Drain Epitaxy)
З обох відкритих боків наношарів проводять селективне епітаксійне нарощування сильно легованих кристалів витоку й стоку:
- Для **nMOS**: кремній, легований фосфором або миш'яком *(Si:P / Si:As)* із концентрацією домішок `N_d > 3 · 10²¹ см⁻³`;
- Для **pMOS**: кремній-германій, легований бором *(SiGe:B)* з вмістом германію до 50%, що створює сильне одновісне стиснення кремнієвого каналу вздовж осі (110) для підвищення рухливості дірок.

Грановані епітаксійні кристали зростаються з усіма трьома наношарами одночасно, утворюючи спільні масивні контакти витоку та стоку.

#### 5. Звільнення наношарів (Nanosheet Release)
Пластину заливають діелектриком міжшарової ізоляції (ILD), полірують за допомогою хіміко-механічної планаризації (CMP) до оголення вершини фіктивного затвора і повністю витравлюють полікремнієвий dummy gate.

Крізь утворене вікно затвора подають високоселективний газовий травитель (на основі сухої суміші парів фтористого водню HF чи хлороводню HCl), який має селективність розчинення SiGe відносно чистого Si **понад 150:1**. Усі залишки жертовних шарів SiGe між наношарами повністю вимиваються. У центрі транзистора залишаються три паралельні кремнієві наношари, що **вільно висять у порожнечі**, підтримувані лише внутрішніми спейсерами по краях біля витоку й стоку.

Під час вивільнення наношарів надзвичайно важливо зберегти прямокутний профіль перерізу та уникнути гантелеподібного округлення країв (ефекту dog-bone), оскільки потоншання країв наношару викликає локальне зниження порогової напруги та передчасний кутовий витік струму.

#### 6. Осадження кругового затвора HKMG (Replacement Metal Gate)
Утворені мікроскопічні порожнини між наношарами завширшки лише 8–10 нм заповнюють за технологією RMG методом конформного атомарно-шарового осадження (ALD):
1. **Інтерфейсний оксид:** надтонкий шар SiO₂ або SiON товщиною 0.6–0.8 нм;
2. **High-k діелектрик:** шар діоксиду гафнію HfO₂ товщиною 1.2–1.8 нм;
3. **Метали налаштування роботи виходу (Work-Function Metals, WFM):** черговані нанометрові плівки TiN, TiAlC, TaN, що задають порогову напругу окремо для nMOS і pMOS;
4. **Метал заповнення:** вольфрам (W), рутеній (Ru) або кобальт (Co), що утворює монолітний низькоомний стрижень керуючого затвора.

Метал повністю оточує кожен із трьох підвішених наношарів з усіх чотирьох боків, завершуючи формування транзистора GAAFET.

Про те, як внутрішні спейсери впливають на швидкодію стандартних логічних комірок і як вирішується проблема локального перегріву теплоізольованих наношарів, можна дізнатися у [🔌 компонентному аналізі стандартної комірки на наношарах](book:electronics/gaafet/comp-gaafet-nanosheet-cell.md).

### Метрологічний контроль та діагностика наношарів на фабриках

Масове виробництво структур із зазорами у 8–10 нм вимагає безперервного неруйнівного контролю геометрії безпосередньо у технологічній лінії *(In-line Metrology)*.

Для контролю виходу придатних кристалів використовують такі методи:
- **Оптична спектральна еліпсометрія та розсіювальна спектрометрія (OCD / Scatterometry):** вимірює періодичні дифракційні картини від масивів тестових ґраток наношарів, дозволяючи обчислювати товщину `T_ns` і ширину `W_ns` по всій 300-мм пластині з суб-ангстремною точністю без руйнування зразків;
- **Просвічувальна електронна мікроскопія високої роздільної здатності (HR-TEM):** використовується для прецизійного пошарового аналізу атомної структури інтерфейсів Si-HfO₂ та контролю відсутності злипання наношарів *(nanosheet stiction)* після мокрого травлення;
- **Сканувальна електронна мікроскопія критичних розмірів (CD-SEM):** контролює точність накладання масок затвора та витоку/стоку (Edge Placement Error, EPE < 1.5 нм).

### Промислові втілення: Samsung MBCFET, TSMC N2 та Intel RibbonFET

Перехід на архітектуру GAAFET став головною ареною технологічного протистояння провідних напівпровідникових фабрик світу на вузлах 3 нм та 2 нм:

```
Характеристика             Samsung 3GAP (MBCFET)     TSMC N2 (GAAFET)          Intel 18A (RibbonFET)
Кількість наношарів        3 наношари                3 наношари                4 нанострічки
Ширина наношару W_ns       25–45 нм                  18–42 нм (NanoFlex)       20–50 нм
Товщина наношару T_ns      5.0–5.5 нм                5.0 нм                    5.0 нм
Крок контактів затвора CPP 48 нм                     45 нм                     45 нм
Крок металізації M1        24 нм                     22 нм                     20 нм
Мережа живлення            Frontside (M0–M15)        Backside (SuperPower)     Backside (PowerVia)
Рік серійного випуску      2023–2024                 2025–2026                 2024–2025
```

- **Samsung Foundry (MBCFET):** першою впровадила наношари на вузлі 3GAE/3GAP, використавши брендову назву MBCFET. Головною інновацією стала можливість виготовлення транзисторів різної ширини в одному кристалі шляхом зміни ширини епітаксійного ребра на етапі маскування.
- **TSMC (N2 NanoFlex):** впроваджує GAAFET на вузлі N2. Технологія **NanoFlex** дозволяє розробникам інтегрувати в один блок стандартні комірки висотою 3.2T (наднизьке споживання) та 4.0T (висока продуктивність) без порушення сітки трасування.
- **Intel (RibbonFET):** реалізувала стос із 4 нанострічок у техпроцесах Intel 20A та 18A. Додатковий четвертий наношар забезпечує на 20–25% більший вихідний струм `I_on` на одиницю площі кристала порівняно з 3-шаровими аналогами конкурентів.

### Революція топології: Backside Power Delivery Network (BSPDN / PowerVia)

Паралельно зі зміною архітектури самого транзистора нанометрова мікроелектроніка натрапила на інший фундаментальний бар'єр — **кризу верхніх шарів металізації** *(Interconnect Bottleneck)*.

У традиційній архітектурі **Frontside PDN** як високочастотні інформаційні сигнали, так і потужні шини живлення (VDD та VSS) прокладаються зверху над транзисторами в єдиному багатошаровому стеку металізації (від M0 до M15):
- Шини живлення VDD та VSS змушені конкурувати за вільні доріжки з сигнальними лініями в найнижчих, найбільш вузьких шарах M0 і M1;
- Опір надтонких мідних провідників шириною 12–15 нм через розсіювання електронів на межах зерен різко зростає, спричиняючи катастрофічне резистивне падіння напруги живлення — **IR-drop**, що сягає **10–15% від номінальної напруги `V_dd`**;
- Прохідні отвори між шарами (Vias) створюють паразитні ємнісні наведення на сусідні сигнальні лінії, обмежуючи тактову частоту мікропроцесорів.

![Порівняння традиційного живлення Frontside PDN та зворотної мережі Backside PDN (PowerVia / SuperPower)](/book/electronics/microelectronics/gaafet/img/frontside-vs-backside-power.svg)
*Зліва: у традиційній системі Frontside PDN шини живлення VDD/VSS затиснуті в одному верхньому стеку з сигналами, спричиняючи високий опір IR-drop і тисняву трасування. Справа: у Backside PDN живлення перенесене на зворотний бік кристала й подається через прямі Nano-TSV, звільняючи 100% верхнього стеку для сигналів.*

Кардинальним вирішенням цієї кризи стало **розділення шляхів сигналу та живлення по різні боки кремнієвої пластини** — технологія **Backside Power Delivery Network (BSPDN)**, відома в Intel як **PowerVia**, а в TSMC як **SuperPower**.

Технологічний процес BSPDN реалізується в кілька етапів:
1. На лицьовому боці пластини повністю формують транзистори GAAFET та весь верхній стек сигнальної металізації (M0–M15);
2. Пластину перевертають і приварюють лицьовим боком до тимчасової опорної кремнієвої пластини *(carrier wafer)* методом молекулярного зрощування;
3. Зворотний бік робочої пластини зішліфовують і піддають прецизійному хіміко-механічному поліруванню (CMP), стоншуючи масивний шар кремнію з початкових 750 мікронів **до менш ніж 500 нанометрів**;
4. Зі зворотного боку крізь надтонкий залишок кремнію протравлюють крихітні мікроотвори — **Nano-TSV** *(Through-Silicon Vias)* діаметром 30–50 нм, які виходять безпосередньо на контакти витоку nMOS і pMOS транзисторів;
5. На зворотній поверхні пластини формують товстий, низькоомний стек силової металізації з масивними мідними шинами VDD та VSS.

BSPDN дає колосальні схемотехнічні переваги:
- **Зниження падіння напруги IR-drop на 30–50%:** товсті зворотні шини подають живлення безпосередньо до витоків транзисторів найкоротшим вертикальним шляхом довжиною менш як 1 мкм замість проходження крізь 15 тонких проміжних шарів;
- **Звільнення 100% площі лицьової металізації:** усунення шин VDD/VSS із шарів M0/M1 усуває затори трасування, дозволяючи ущільнити логічні комірки на **15–20%** і скоротити висоту комірок до рекордних **4T**;
- **Зростання тактової частоти на 6–10%:** чисті лінії сигналів позбавлені високочастотного шуму перемикання силових ліній.

### Механізми деградації та надійність наношарів (BTI та TDDB)

Експлуатаційна надійність наношарів GAAFET піддається специфічним деградаційним впливам, зумовленим тривимірною кристалографією поверхні та високими робочими напруженостями електричного поля в надтонкому діелектрику:

1. **Анізотропія кристалографічних граней і BTI:**
   Верхня та нижня горизонтальні грані наношару орієнтовані вздовж кристалографічної площини (100), яка має мінімальну густину поверхневих пасток `D_it`, що забезпечує високу рухливість електронів. Бічні вертикальні стінки наношару орієнтовані вздовж площини (110), де густина обірваних кремнієвих зв'язків є в 2–3 рази вищою. Це призводить до прискореної зарядової деградації за рахунок нестабільності порогової напруги при підвищеній температурі під дією негативного зміщення затвора *(Negative Bias Temperature Instability, NBTI)* у pMOS-транзисторах.

2. **Часозалежний пробій діелектрика (TDDB):**
   Осадження High-k плівки HfO₂ товщиною 1.5 нм всередині вузьких міжнаношарових щілин завширшки 8–10 нм може супроводжуватися локальними дефектами конформності та мікропорами. Під дією електричного поля напруженістю `E_ox > 4–5 МВ/см` у діелектрику генеруються нейтральні вакансії кисню, які з часом утворюють провідний перколяційний ланцюжок між металевим затвором і каналом, викликаючи катастрофічний м'який або твердий діелектричний пробій.

3. **Гарячі носії заряду біля внутрішнього спейсера (HCI):**
   На границі між каналом і внутрішнім спейсером SiBCN біля стоку електричне поле сягає максимуму. Електрони, розігнані до високих кінетичних енергій, бомбардують інтерфейс Si-SiBCN, генеруючи фіксований паразитичний заряд, що зсуває порогову напругу транзистора в процесі тривалої багаторічної експлуатації.

### Наступний горизонт: комплементарні транзистори CFET (3D Stacked CMOS)

Незважаючи на досконалу електростатику наношарів, горизонтальний GAAFET зберігає фундаментальне обмеження класичного [CMOS](book:electronics/cmos): транзистори nMOS та pMOS розташовуються **пліч-о-пліч у горизонтальній площині** пластини, розділені діелектричною ізоляцією STI. Ця ізоляційна канавка займає до 30–40% усієї площі стандартної логічної комірки.

Наступним безальтернативним кроком розвитку мікроелектроніки за межами 1.5 нм стане архітектура **CFET** *(Complementary FET)* — монолітне тривимірне стекування nMOS-транзистора безпосередньо над pMOS-транзистором в єдиному вертикальному стовпчику.

![Архітектура комплементарного транзистора CFET: монолітне 3D-стекування nMOS наношарів над pMOS у єдиному стовпчику](/book/electronics/microelectronics/gaafet/img/cfet-stacked-architecture.svg)
*Зліва: у стандартному CMOS транзистори nMOS і pMOS розміщені поруч, вимагаючи широкої площі та діелектричної канавки STI між ними. Справа: у CFET стос із наношарів nMOS вирощено безпосередньо над стосом pMOS з середнім діелектричним розділювачем, що скорочує площу стандартної комірки на 50% без втрати провідної ширини.*

У структурі CFET:
- Нижній ярус містить стос із 2–3 наношарів SiGe для pMOS;
- Посередині розташований товстий ізолюючий середній діелектричний спейсер *(Middle Dielectric Isolation, MDI)*;
- Верхній ярус містить стос із 2–3 наношарів Si для nMOS;
- Єдиний спільний вертикальний металевий затвор одночасно охоплює обидва яруси або розділяється на два незалежні затвори.

Завдяки вертикальному об'єднанню комплементарної пари логічний інвертор або вентиль NAND2 займає площу рівно **одного транзистора**. Висота стандартної комірки скорочується з 5T до **3.0T–3.5T**, забезпечуючи практично двократне подвоєння щільності розміщення логіки без необхідності подальшого ризикованого скорочення фізичної довжини затвора `L_g`.

### Програмне моделювання провідності та паразитного падіння напруги

Наведений нижче програмний модуль моделює роботу транзистора GAAFET з урахуванням геометрії наношарів, розраховує ефективну ширину `W_eff`, струм насичення з балістичним фактором, а також порівнює падіння напруги IR-drop для традиційного верхнього живлення (Frontside PDN) та зворотної мережі живлення (Backside PDN / PowerVia).

:::tabs
```c
#include <stdio.h>
#include <math.h>

/* Структура геометричних та електричних параметрів наношару GAAFET */
typedef struct {
    double w_ns_nm;       /* Ширина наношару W_ns (нм) */
    double t_ns_nm;       /* Товщина наношару T_ns (нм) */
    double l_gate_nm;     /* Довжина затвора L_g (нм) */
    int    n_sheets;      /* Кількість наношарів у стосі */
    double v_dd;          /* Напруга живлення (В) */
    double r_front_pdn;   /* Опір шини живлення Frontside (Ом) */
    double r_back_pdn;    /* Опір шини живлення Backside / TSV (Ом) */
} gaafet_transistor_sim_t;

/* Структура результатів моделювання */
typedef struct {
    double w_eff_total_nm;      /* Повна ефективна ширина W_eff (нм) */
    double i_drive_ma;          /* Струм відкритого стану I_on (мА) */
    double v_drop_front_mv;     /* Падіння напруги IR-drop у Frontside PDN (мВ) */
    double v_drop_back_mv;      /* Падіння напруги IR-drop у Backside PDN (мВ) */
    double effective_vdd_front; /* Ефективна напруга на транзисторі (Frontside) */
    double effective_vdd_back;  /* Ефективна напруга на транзисторі (Backside) */
    double speedup_percent;     /* Приріст струму завдяки Backside PDN (%) */
} gaafet_sim_results_t;

/* Функція моделювання транзистора та мережі живлення */
gaafet_sim_results_t run_gaafet_simulation(const gaafet_transistor_sim_t *cfg) {
    gaafet_sim_results_t res;

    /* 1. Розрахунок повної ефективної ширини 4-стороннього затвора */
    double perim = 2.0 * cfg->w_ns_nm + 2.0 * cfg->t_ns_nm;
    res.w_eff_total_nm = (double)cfg->n_sheets * perim;

    /* 2. Питомий струм квазібалістичного насичення ~1.42 мА/мкм за V_dd = 0.7 В */
    double base_density_ma_per_um = 1.42;
    double nominal_i_on_ma = (res.w_eff_total_nm / 1000.0) * base_density_ma_per_um;

    /* 3. Розрахунок IR-drop для Frontside PDN (тонкі довгі провідники M0-M15) */
    /* Падіння напруги V_drop = I_total * R_network */
    res.v_drop_front_mv = (nominal_i_on_ma * 1e-3) * cfg->r_front_pdn * 1000.0;
    res.effective_vdd_front = cfg->v_dd - (res.v_drop_front_mv / 1000.0);

    /* 4. Розрахунок IR-drop для Backside PDN (прямі короткі Nano-TSV і товста мідь) */
    res.v_drop_back_mv = (nominal_i_on_ma * 1e-3) * cfg->r_back_pdn * 1000.0;
    res.effective_vdd_back = cfg->v_dd - (res.v_drop_back_mv / 1000.0);

    /* 5. Реальний струм з урахуванням просідання напруги живлення */
    double v_th = 0.22; /* Порогова напруга транзистора (В) */
    double i_front = nominal_i_on_ma * ((res.effective_vdd_front - v_th) / (cfg->v_dd - v_th));
    double i_back  = nominal_i_on_ma * ((res.effective_vdd_back - v_th) / (cfg->v_dd - v_th));

    res.i_drive_ma = i_back;
    res.speedup_percent = ((i_back - i_front) / i_front) * 100.0;

    return res;
}

int main(void) {
    gaafet_transistor_sim_t sim_cfg = {
        .w_ns_nm = 35.0, .t_ns_nm = 5.0, .l_gate_nm = 12.0,
        .n_sheets = 3, .v_dd = 0.70,
```

```cpp
#include <iostream>
#include <cmath>
#include <vector>
#include <span>
#include <string_view>
#include <iomanip>

struct GAAFETConfig {
    double nanosheet_width_nm{35.0};
    double nanosheet_thickness_nm{5.0};
    double gate_length_nm{12.0};
    std::size_t sheet_count{3};
    double nominal_vdd_v{0.70};
    double frontside_pdn_resistance_ohm{85.0};
    double backside_pdn_resistance_ohm{18.0};
};

struct SimulationResult {
    double total_effective_width_nm{0.0};
    double drive_current_ma{0.0};
    double frontside_ir_drop_mv{0.0};
    double backside_ir_drop_mv{0.0};
    double effective_vdd_frontside_v{0.0};
    double effective_vdd_backside_v{0.0};
    double performance_gain_percent{0.0};
};

class GAAFETPowerNetworkSimulator {
public:
    [[nodiscard]] static SimulationResult compute(const GAAFETConfig& cfg) noexcept {
        SimulationResult out;

        // 1. Обчислення повної ефективної провідної ширини наношарів
        const double perimeter = 2.0 * (cfg.nanosheet_width_nm + cfg.nanosheet_thickness_nm);
        out.total_effective_width_nm = static_cast<double>(cfg.sheet_count) * perimeter;

        // 2. Номінальний струм насичення
        constexpr double CurrentDensityMaPerUm = 1.42;
        const double nominal_current_ma = (out.total_effective_width_nm / 1000.0) *
                                          CurrentDensityMaPerUm;

        // 3. Розрахунок резистивного падіння напруги IR-drop
        out.frontside_ir_drop_mv = (nominal_current_ma * 1e-3) *
                                   cfg.frontside_pdn_resistance_ohm * 1000.0;
        out.effective_vdd_frontside_v = cfg.nominal_vdd_v - (out.frontside_ir_drop_mv / 1000.0);

        out.backside_ir_drop_mv = (nominal_current_ma * 1e-3) *
                                  cfg.backside_pdn_resistance_ohm * 1000.0;
        out.effective_vdd_backside_v = cfg.nominal_vdd_v - (out.backside_ir_drop_mv / 1000.0);

        // 4. Оцінка швидкодії за реальної робочої напруги
        constexpr double ThresholdVoltageV = 0.22;
        const double overdrive_nominal = cfg.nominal_vdd_v - ThresholdVoltageV;
        const double i_front = nominal_current_ma *
                               ((out.effective_vdd_frontside_v - ThresholdVoltageV) / overdrive_nominal);
        const double i_back = nominal_current_ma *
                              ((out.effective_vdd_backside_v - ThresholdVoltageV) / overdrive_nominal);

        out.drive_current_ma = i_back;
        out.performance_gain_percent = ((i_back - i_front) / i_front) * 100.0;

        return out;
    }
};

int main() {
    const std::vector<std::pair<std::string_view, GAAFETConfig>> scenarios = {
        {"3-Nanosheet Standard (TSMC N2 / Samsung 3GAP)", GAAFETConfig{.sheet_count = 3}},
        {"4-Nanosheet RibbonFET (Intel 18A)           ", GAAFETConfig{.sheet_count = 4}}
    };

    std::cout << std::fixed << std::setprecision(2);
    std::cout << "=== GAAFET Electrostatic & Power Delivery Network Analysis ===\n";
    for (const auto& [name, cfg] : scenarios) {
        const auto res = GAAFETPowerNetworkSimulator::compute(cfg);
        std::cout << "[" << name << "]\n"
                  << "  W_eff: " << res.total_effective_width_nm << " nm | I_drive: "
                  << res.drive_current_ma << " mA\n"
                  << "  Frontside PDN Drop : " << res.frontside_ir_drop_mv << " mV (V_eff = "
                  << res.effective_vdd_frontside_v << " V)\n"
                  << "  Backside PowerVia  : " << res.backside_ir_drop_mv << " mV (V_eff = "
                  << res.effective_vdd_backside_v << " V)\n"
                  << "  Net Drive Gain     : +" << res.performance_gain_percent << " %\n\n";
    }
    return 0;
}
```
