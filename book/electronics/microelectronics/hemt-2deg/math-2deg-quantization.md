# 🧮 Квантування енергетичного спектра у двовимірному електронному газі

Потенціальний бар'єр на межі двох напівпровідників із різною шириною забороненої зони обмежує рух носіїв заряду в одному просторовому напрямку. Коли просторова ширина утвореної потенціальної ями стає співмірною з де-бройлівською довжиною хвилі електрона, класичний неперервний спектр поперечного руху розпадається на дискретні квантовані енергетичні рівні — підзони. Повний теоретичний опис двовимірного електронного газу (2DEG) вимагає сумісного розв'язання квантовомеханічного рівняння Шредінгера для знаходження хвильових функцій електронів та електростатичного рівняння Пуассона для визначення просторового розподілу електричного потенціалу.

### Квантовомеханічна постановка задачі та наближення обвідної функції

Розглядається рух електрона провідності поблизу межі гетеропереходу (координата `z = 0`), розташованої в площині `xy`. Вісь `z` спрямована перпендикулярно до межі вглиб вузькозонного нелегованого напівпровідника (наприклад, арсеніду галію `i-GaAs` або нітриду галію `GaN`).

У кристалічній ґратці потенціал, що діє на електрон, складається з періодичного потенціалу атомних остовів та плавно змінного макроскопічного потенціалу гетеропереходу. У наближенні обвідної функції (*Envelope Function Approximation, EFA*) швидкі блохівські коливання хвильової функції відокремлюються від повільної просторової зміни амплітуди. Повна тривимірна хвильова функція електрона `Ψ(x, y, z)` у зоні провідності записується як добуток періодичної функції Блоха `u_c(r)` для дна зони провідності, плоскої хвилі для вільного руху в площині `xy` та одновимірної обвідної функції `ψ(z)` для просторово обмеженого руху вздовж осі `z`:

```
Ψ(x, y, z) = (1 / √S) · exp(i · (k_x · x + k_y · y)) · ψ(z) · u_c(r)      [розділення змінних хвильової функції]
```

де `S` — площа гетеропереходу в площині `xy`, `k_x` та `k_y` — декартові компоненти хвильового вектора (квазіімпульсу) електрона в площині 2DEG.

Оскільки періодичні блохівські множники `u_c(r)` є взаємно ортогональними й інтегруються по об'єму елементарної комірки до одиниці, кінетична енергія електрона визначається ефективною масою `m*` на дні зони провідності. Повна енергія електрона `E` складається з енергії поздовжнього вільного руху `E_xy` та дискретної енергії квантованого руху вздовж осі `z`:

```
E = E_i + (ħ² · (k_x² + k_y²)) / (2 · m*)      [адитивний спектр енергії носія в підзоні]
```

де `m*` — ефективна маса електрона провідності (`m* = 0.067 · m₀` для GaAs, `m* = 0.20 · m₀` для GaN), `ħ` — зведена стала Планка (`1.05457 · 10⁻³⁴ Дж·с`), `E_i` — власні значення енергії `i`-ї квантової підзони (`i = 0, 1, 2, ...`).

Для знаходження обвідної функції `ψ(z)` та власних значень `E_i` складається одновимірне стаціонарне рівняння Шредінгера:

```
- (ħ² / (2 · m*)) · (d²ψ(z) / dz²) + V(z) · ψ(z)
= E_i · ψ(z)      [одновимірне стаціонарне рівняння Шредінгера]
```

де `V(z)` — повна потенціальна енергія електрона, сформована електростатичним полем гетеропереходу та розривом зон.

### Наближення трикутної потенціальної ями (Airy well)

Поблизу межі гетеропереходу профіль потенціальної енергії `V(z)` апроксимується асиметричною трикутною ямою зі сталим ефективним електричним полем на поверхні `E_s`. Це наближення ґрунтується на тому, що в зоні локалізації більшості електронів (перші кілька нанометрів від межі) електричне поле просторового заряду змінюється слабо:
- При `z < 0` (у широкозонному бар'єрі AlGaAs або AlGaN) потенціальний бар'єр вважається нескінченно високим: `V(z) = ∞`;
- При `z ≥ 0` (у вузькозонному каналі GaAs або GaN) потенціал зростає лінійно з віддаленням від межі: `V(z) = q · E_s · z`.

де `q` — елементарний електричний заряд (`1.60218 · 10⁻¹⁹ Кл`), `E_s` — середня напруженість електричного поля на гетеропереході.

За цієї крайової постановки диференціальне рівняння Шредінгера в області `z ≥ 0` набуває вигляду:

```
d²ψ(z) / dz² + (2 · m* / ħ²) · (E_i - q · E_s · z) · ψ(z)
= 0      [диференціальне рівняння другого порядку для лінійного потенціалу]
```

Фізичний зміст цього рівняння полягає в тому, що точка `z_t = E_i / (q · E_s)` є класичною точкою повороту: при `z < z_t` кінетична енергія електрона додатна й хвильова функція має осциляційний характер, а при `z > z_t` кінетична енергія стає від'ємною, і хвильова функція експоненційно затухає під бар'єром.

Для переходу до канонічного вигляду виконується заміна змінної:

```
ξ(z) = (2 · m* · q · E_s / ħ²)^(1/3) · (z - E_i / (q · E_s))      [безрозмірна координата Ейрі]
```

Диференціювання за правилом ланцюжка дає зв'язок похідних:

```
dξ / dz = (2 · m* · q · E_s / ħ²)^(1/3)      [похідна першого порядку від заміни змінної]
d²ψ / dz² = ((2 · m* · q · E_s / ħ²)^(2/3)) · (d²ψ / dξ²)      [друга похідна від хвильової функції]
```

Підстановка другої похідної в початкове рівняння:

```
((2 · m* · q · E_s / ħ²)^(2/3)) · (d²ψ / dξ²) - ((2 · m* · q · E_s / ħ²)^(2/3)) · ξ · ψ
= 0      [підстановка заміни координат]
= d²ψ(ξ) / dξ² - ξ · ψ(ξ) = 0      [канонічне диференціальне рівняння Ейрі]
```

Загальний розв'язок рівняння Ейрі є лінійною суперпозицією двох фундаментальних функцій:

```
ψ(ξ) = C₁ · Ai(ξ) + C₂ · Bi(ξ)      [загальний розв'язок через функції Ейрі]
```

Функція Ейрі другого роду `Bi(ξ)` асимптотично зростає при додатних аргументах як `Bi(ξ) ∝ exp((2/3) · ξ^(3/2)) / ξ^(1/4)`. Оскільки квантовомеханічна хвильова функція повинна бути нормовною на нескінченності (`ψ(z → ∞) → 0`), коефіцієнт `C₂` строго дорівнює нулю:

```
C₂ = 0      [вимога квадратичної інтегровності та нормовності хвильової функції]
ψ(z) = C₁ · Ai((2 · m* · q · E_s / ħ²)^(1/3) · (z - E_i / (q · E_s)))      [фізична хвильова функція]
```

Крайова умова абсолютної непроникності бар'єра при `z = 0` вимагає перетворення функції на нуль:

```
ψ(0) = C₁ · Ai(- (2 · m* / (q · ħ · E_s))^(1/3) · (E_i / ħ^(1/3)))
= 0      [крайова умова Діріхле на межі нескінченного бар'єра]
```

Отже, значення аргументу функції `Ai` на межі `z = 0` повинно точно збігатися з від'ємними коренями функції Ейрі `-a_i` (де `Ai(-a_i) = 0`, `i = 0, 1, 2, ...`):

```
(2 · m* / (q · ħ · E_s))^(1/3) · (E_i / ħ^(1/3))
= a_i      [умова квантування власних значень енергії]
```

У квазікласичному наближенні Вентцеля — Крамерса — Бріллюена (ВКБ) фазовий інтеграл дії дорівнює півцілому числу квантів дії:

```
∫ [від 0 до z_t] √(2 · m* · (E_i - q · E_s · z)) dz = π · ħ · (i + 3/4)      [умова квантування Бора — Зоммерфельда]
```

Обчислення цього інтеграла дає квазікласичне наближення коренів функції Ейрі:

```
a_i ≈ ((3 · π / 2) · (i + 3/4))^(2/3)      [квазікласичне наближення коренів функції Ейрі]
```

Звідси отримується явна аналітична формула для квантованих енергетичних рівнів підзон `E_i`:

```
E_i
= ((ħ² / (2 · m*))^(1/3)) · ((3 · π · q · E_s / 2) · (i + 3/4))^(2/3)      [енергетичний рівень i-ї підзони в трикутній ямі]
```

Для перших двох підзон точні числові значення коренів функції Ейрі дорівнюють `a₀ = 2.3381` та `a₁ = 4.0879`:

```
E₀ = 2.3381 · ((ħ² · q² · E_s²) / (2 · m*))^(1/3)      [енергія основного квантового стану]
E₁ = 4.0879 · ((ħ² · q² · E_s²) / (2 · m*))^(1/3)      [енергія першого збудженого стану]
```

### Варіаційний метод Фанга — Говарда

Точний розв'язок через функції Ейрі припускає нескінченно високий бар'єр при `z = 0`. У реальній гетероструктурі висота бар'єра скінченна (`ΔE_c ≈ 0.3 еВ`), тому хвіст хвильової функції тунелює на кілька ангстремів у шар AlGaAs. Для аналітичних розрахунків часто використовують варіаційну хвильову функцію Фанга — Говарда (*Fang-Howard trial wave function*):

```
ψ_FH(z) = √(b³ / 2) · z · exp(- b · z / 2)      [варіаційна хвильова функція основного стану]
```

де `b` — варіаційний параметр, що мінімізує повну енергію електрона.

Мінімізація функціонала енергії за параметром `b` з урахуванням рівняння Пуассона дає оптимальне значення:

```
b = ((12 · m* · q² / (ε · ħ²)) · (F_depl + (11 / 32) · n_s))^(1/3)      [оптимальний варіаційний параметр Фанга — Говарда]
```

Середня просторова координата локалізації двовимірного газу (центроїд 2DEG) обчислюється через хвильову функцію Фанга — Говарда:

```
⟨z₀⟩
= ∫ [від 0 до ∞] z · |ψ_FH(z)|² dz
= 3 / b      [центроїд просторового розподілу заряду 2DEG]
```

Для типових параметрів гетероструктури GaAs (`n_s = 5 · 10¹¹ см⁻²`) центроїд заряду розташований на відстані `⟨z₀⟩ ≈ 3.5–4.0 нм` від гетероінтерфейсу.

### Самоузгоджене електростатичне поле Пуассона

Середнє електростатичне поле `E_s`, що утримує електрони в трикутній ямі, визначається повним поверхневим зарядом двовимірного електронного газу `q · n_s` та зарядом збідненої області підкладки:

```
E_s = (q / ε) · (F_depl + (1 / 2) · n_s)      [ефективне поле усереднення за Пуассоном]
```

де `ε = ε_r · ε₀` — абсолютна діелектрична проникність напівпровідника каналу, `n_s` — поверхнева густина 2DEG, `F_depl` — густина залишкових іонізованих домішок у буферному шарі.

Для високочистого каналу з високою концентрацією 2DEG (`n_s >> F_depl`):

```
E_s ≈ (q · n_s) / (2 · ε)      [середнє поле просторового заряду електронів 2DEG]
```

Підстановка середнього поля у вираз для енергії основного стану дає замкнену аналітичну залежність квантового рівня `E₀` від концентрації двовимірного газу `n_s`:

```
E₀
= 2.3381 · ((ħ² · q⁴ · n_s²) / (8 · m* · ε²))^(1/3)      [самоузгоджена енергія основної підзони]
```

### Двовимірна густина станів та концентрація 2DEG

Густина енергетичних станів у двовимірному просторі виводиться підрахунком кількості квантових станів у плоскому фазовому `k`-просторі площею `S`:

```
dN = 2 · (S / (2π)²) · (2π · k · dk)      [кількість станів у кільці k-простору з урахуванням спіну]
= (S / π) · k · dk      [скорочення спільних множників]
```

Зв'язок між хвильовим числом `k` та кінетичною енергією поздовжнього руху `E_k`:

```
E_k = (ħ² · k²) / (2 · m*)      [параболічний дисперсійний закон]
dE_k = (ħ² · k / m*) · dk      [диференціал кінетичної енергії]
k · dk = (m* / ħ²) · dE_k      [вираження елемента площі через диференціал енергії]
```

Підстановка `k · dk` у вираз для кількості квантових станів:

```
dN = (S · m* / (π · ħ²)) · dE_k      [кількість станів у квантовому інтервалі енергії]
```

Густина станів на одиницю геометричної площі `D_2D(E) = (1 / S) · (dN / dE_k)`:

```
D_2D(E)
= m* / (π · ħ²)      [фундаментальна двовимірна густина станів однієї підзони]
```

Повна ступінчаста густина станів за наявності декількох заповнених підзон виражається сумою функцій Хевісайда `θ(E - E_i)`:

```
D_total(E) = (m* / (π · ħ²)) · ∑ [по i] θ(E - E_i)      [повна двовимірна густина станів]
```

Розрахунок числового значення для `GaAs` (`m* = 0.067 · m₀`):

```
D_2D(GaAs)
= (0.067 · 9.109 · 10⁻³¹ кг) / (π · (1.05457 · 10⁻³⁴ Дж·с)²)      [підстановка фундаментальних констант]
= 1.748 · 10³⁶ Дж⁻¹·м⁻²      [розрахунок у системі SI]
= (1.748 · 10³⁶) · (1.60218 · 10⁻¹⁹) · 10⁻⁴      [переведення в одиниці еВ⁻¹·см⁻²]
= 2.80 · 10¹⁰ еВ⁻¹·см⁻²      [стала густина станів підзони для GaAs]
```

Для матеріалу `GaN` (`m* = 0.20 · m₀`):

```
D_2D(GaN)
= (0.20 · 9.109 · 10⁻³¹ кг) / (π · (1.05457 · 10⁻³⁴ Дж·с)²)      [підстановка параметрів GaN]
= 8.36 · 10¹⁰ еВ⁻¹·см⁻²      [густина станів 2DEG для GaN]
```

Поверхнева концентрація носіїв `n_s` при ненульовій температурі визначається інтегралом розподілу Фермі — Дірака:

```
n_s = (m* · k_B · T / (π · ħ²)) · ln(1 + exp((E_F - E₀) / (k_B · T)))      [концентрація 2DEG при скінченній температурі]
```

При температурі абсолютного нуля (`T → 0 К`):

```
n_s = (m* / (π · ħ²)) · (E_F - E₀)      [лінійний зв'язок концентрації та рівня Фермі при T = 0 К]
E_F - E₀ = (π · ħ² · n_s) / m*      [енергія Фермі 2DEG над дном підзони]
```

Поріг заповнення другої підзони `E₁` досягається за критичної концентрації `n_s,crit`:

```
n_s,crit = (m* / (π · ħ²)) · (E₁ - E₀)      [критична концентрація початку міжпідзонного розсіювання]
```

Для GaAs типове значення `n_s,crit ≈ 7–8 · 10¹¹ см⁻²`. Перевищення цього рівня призводить до заповнення підзони `E₁` та виникнення міжпідзонного розсіювання (*intersubband scattering*), яке дещо знижує рухливість електронів.

### Термодинаміка: температурне розмиття сходинки Фермі

При підвищенні робочої температури ступінчастий розподіл Фермі — Дірака розмивається в енергетичному інтервалі близько `4 · k_B · T` (де `k_B · T ≈ 25.9 меВ` при `300 К`).

Фізичний стан 2DEG визначається ступенем виродження, який характеризується безрозмірним параметром `η = (E_F - E₀) / (k_B · T)`:
- **Сильно вироджений квантовий газ (`η >> 1`):** реалізується при низьких температурах (`T < 77 К`) або надвисоких концентраціях. Електрони підпорядковуються квантовій статистиці Фермі, а їхній розсіювальний переріз визначається станами поблизу поверхні Фермі.
- **Невироджений больцманівський газ (`η << -1`):** реалізується при малих концентраціях або високих температурах (`T > 400–500 К`). Розподіл експоненційно переходить у класичний максвеллівський вигляд `n_s ∝ exp((E_F - E₀) / (k_B · T))`.
- **Проміжний квазівироджений стан (`|η| ≤ 1`):** характерний для кімнатної температури в HEMT. Частина електронів термічно збуджується у вищі підзони `E₁` та `E₂`, що активує міжпідзонні переходи та дещо збільшує ефективну масу ансамблю носіїв.

### Балістичний квантовий транспорт Ландауера

Коли довжина каналу транзистора `L_g` стає меншою за середню довжину вільного пробігу електрона `l_e` (`L_g << l_e`), рух носіїв заряду переходить із дифузійного дрейфового режиму в режим балістичного прольоту без розсіювання.

Згідно з квантовою теорією транспорту Ландауера — Бюттікера, повна електрична провідність балістичного квантового каналу `G` визначається кількістю відкритих поперечних квантових мод (підзон) `M` та їхньою прозорістю `T_trans`:

```
G = (2 · q² / h) · M · T_trans      [формула Ландауера для квантової провідності]
```

де `h / (2 · q²) ≈ 12906.4 Ом` — фундаментальний квантовий опір однієї просторової моди.

Для двовимірного каналу шириною `W` кількість відкритих поперечних мод на рівні Фермі дорівнює:

```
M = (k_F · W) / π = (√(2 · π · n_s) · W) / π      [кількість поперечних мод провідності]
```

Для ідеального балістичного каналу (`T_trans = 1`) максимальний теоретичний струм, який може пропустити одиниця ширини каналу 2DEG без будь-якого розсіювання, становить:

```
I_ballistic / W = (2 · q / h) · √(2 · π · n_s) · (E_F - E_source)      [гранична густина балістичного струму]
```

Цей результат встановлює абсолютну фізичну межу мінімального контактного опору та максимальної крутизни, яка може бути досягнута в суб-10 нанометрових HEMT-транзисторах.

### Екранування кулонівського потенціалу в двовимірному газі

Екранувальні властивості 2DEG суттєво відрізняються від тривимірного напівпровідника. У тривимірному напівпровіднику радіус екранування Дебая — Хюккеля або Томаса — Фермі залежить від концентрації як `r_TF ∝ 1 / √n`. У двовимірному газі хвильовий вектор екранування Томаса — Фермі `q_s` визначається сталою двовимірною густиною станів `D_2D`:

```
q_s = (q² · D_2D) / (2 · ε) = (q² · m*) / (2 · π · ε · ħ²)      [хвильовий вектор двовимірного екранування]
```

Дивовижним фактом є те, що при виродженому стані 2DEG величина `q_s` **взагалі не залежить від концентрації електронів** `n_s`. Двовимірний електронний газ екранує довгохвильові збурення потенціалу на характерній довжині `1 / q_s ≈ 2–3 нм`, що додатково захищає носії заряду від залишкових дефектів кристала.

### Магнітне квантування: рівні Ландау та квантовий ефект Холла

При прикладанні перпендикулярного магнітного поля з індукцією `B` рух електронів у площині `xy` стає замкненим по циклотронних орбітах.

Неперервна двовимірна густина станів розпадається на еквідистантні дискретні піки — **рівні Ландау** з енергіями:

```
E_N = E_i + (N + 1/2) · ħ · ω_c ± (1/2) · g* · μ_B · B      [енергетичний спектр рівнів Ландау зі спіновим розщепленням]
```

де `N = 0, 1, 2, ...` — орбітальне квантове число Ландау, `ω_c = q · B / m*` — циклотрона частота, `g*` — ефективний фактора Ланде, `μ_B = q · ħ / (2 · m₀)` — магнетон Бора.

Виродження кожного рівня Ландау на одиницю площі (кількість квантових станів, що поміщаються на одному рівні) визначається квантом магнітного потоку `Φ₀ = h / q`:

```
n_L = q · B / h      [густина квантових станів одного рівня Ландау]
```

Фактор заповнення `ν` показує кількість повністю заповнених рівнів Ландау:

```
ν = n_s / n_L = (h · n_s) / (q · B)      [фактор заповнення рівнів Ландау]
```

Коли рівень Фермі потрапляє в енергетичну щілину між рівнями Ландау (`ν` є цілим числом), поздовжній опір каналу падає строго до нуля (`ρ_xx = 0`), а поперечний опір Холла квантується з фундаментальною точністю:

```
R_xy = h / (ν · q²) = R_K / ν      [цілочисельний квантовий опір Холла]
```

де `R_K = h / q² = 25812.80745... Ом` — стала фон Клітцинга.

Вимірювання періоду осциляцій поздовжнього опору від оберненого магнітного поля (осциляції Шубнікова — де Гааза) дає прямий прецизійний метод вимірювання концентрації 2DEG:

```
Δ(1 / B) = (2 · q) / (h · n_s)      [період осциляцій Шубнікова — де Гааза]
```

### Ємнісна модель керування зарядом затвора

Поверхнева концентрація електронів `n_s` у працюючому транзисторі модулюється напругою, прикладеною до металевого затвора Шотткі `V_gs`.

Еквівалентна ємність структури затвор-2DEG складається з послідовного з'єднання геометричної ємності бар'єрного шару `C_bar` та квантової ємності двовимірного газу `C_q`:

```
1 / C_tot = 1 / C_bar + 1 / C_q      [послідовне з'єднання геометричної та квантової ємностей]
```

Геометрична ємність на одиницю площі визначається товщиною бар'єра `d_bar` та середнім зміщенням центроїда хвильової функції 2DEG `Δd`:

```
C_bar = ε_bar / (d_bar + Δd)      [геометрична питома ємність підзатворного діелектрика]
```

Квантова ємність 2DEG `C_q` обумовлена скінченною густиною станів `D_2D`:

```
C_q = q² · (dn_s / dE_F) = q² · D_2D = (q² · m*) / (π · ħ²)      [квантова ємність двовимірного газу]
```

Для GaAs квантова ємність становить `C_q ≈ 4.5 мкФ/см²`, що є значно більшим за геометричну ємність бар'єра (`C_bar ≈ 0.3–0.5 мкФ/см²`), тому `C_tot ≈ C_bar`.

Залежність поверхневої концентрації від напруги затвора записується як:

```
n_s(V_gs) = (C_tot / q) · (V_gs - V_th)      [керування концентрацією 2DEG напругою затвора]
```

де `V_th` — порогова напруга відкривання транзистора:

```
V_th = Φ_B - ΔE_c / q - (q · N_d · d_d²) / (2 · ε_bar) - σ_pol / C_bar      [повна порогова напруга HEMT]
```

де `Φ_B` — висота бар'єра Шотткі металу затвора, `d_d` — товщина легованого шару бар'єра, `σ_pol` — поляризаційний заряд (для нітридних структур).

### Крутизна характеристики та граничні частоти f_T і f_max

У режимі насичення швидкості дрейфу струм стоку HEMT визначається добутком заряду на насичену дрейфову швидкість `v_sat` та ширину каналу `W`:

```
I_ds(sat) = q · n_s · v_sat · W
= C_tot · W · v_sat · (V_gs - V_th)      [струм насичення короткоканального HEMT]
```

Внутрішня диференціальна крутизна характеристики `g_m0`:

```
g_m0 = ∂I_ds(sat) / ∂V_gs
= C_tot · W · v_sat
= (ε_bar · W · v_sat) / (d_bar + Δd)      [внутрішня крутизна характеристики транзистора]
```

З урахуванням паразитного послідовного опору витоку `R_s` зовнішня виміряна крутизна `g_m` знижується через від'ємний зворотний зв'язок:

```
g_m = g_m0 / (1 + g_m0 · R_s)      [зовнішня крутизна з урахуванням опору витоку]
```

Повна затримка проходження сигналу крізь транзистор `τ_total` складається з трьох послідовних фізичних компонент:
1. Затримка заряджання вхідної ємності затвора через опір витоку: `τ_c = C_gs · R_s`;
2. Час власного прольоту носіїв під затвором: `τ_tr = L_g / v_sat`;
3. Затримка заряджання вихідної збідненої області стоку: `τ_d = C_gd · (R_s + R_d)`.

Гранична частота одиничного підсилення за струмом `f_T` пов'язана з повною затримкою співвідношенням:

```
f_T = 1 / (2 · π · τ_total) = g_m / (2 · π · (C_gs + C_gd))      [гранична частота зрізу підсилення за струмом]
```

Підстановка виразу для крутизни та ємності затвора `C_gs = C_tot · L_g · W` за умови `C_gs >> C_gd`:

```
f_T
= (C_tot · W · v_sat) / (2 · π · C_tot · L_g · W)      [скорочення ширини каналу та питомої ємності]
= v_sat / (2 · π · L_g)      [гранична частота прольоту носіїв під затвором]
```

Максимальна частота генерації `f_max` (частота одиничного підсилення за потужністю за Мейсоном) враховує вихідну провідність каналу `g_ds`, опір металізації затвора `R_g` та опір витоку `R_s`:

```
f_max
= f_T / (2 · √(g_ds · (R_g + R_s) + 2 · π · f_T · R_g · C_gd))      [максимальна частота підсилення потужності]
```

### Числовий приклад розрахунку параметрів транзистора

Для демонстрації зв'язку між квантовими рівнями та мікрохвильовими характеристиками приладу розглядається транзистор `AlGaAs/GaAs HEMT` із такими проектними параметрами:
- Поверхнева густина 2DEG: `n_s = 5 · 10¹¹ см⁻²` (`5 · 10¹⁵ м⁻²`);
- Довжина затвора: `L_g = 100 нм` (`10⁻⁷ м`);
- Товщина бар'єра `AlGaAs`: `d_bar = 25 нм`, діелектрична проникність `ε_bar = 12.2 · ε₀`;
- Насичена швидкість електронів у GaAs: `v_sat = 1.2 · 10⁷ см/с` (`1.2 · 10⁵ м/с`).

Послідовний розрахунок параметрів:

1. **Середнє електричне поле в квантовій ямі:**

```
E_s
= (q · n_s) / (2 · ε_GaAs)      [формула середнього поля просторового заряду]
= (1.602 · 10⁻¹⁹ · 5 · 10¹⁵) / (2 · 12.9 · 8.854 · 10⁻¹²)      [підстановка числових значень]
= 3.51 · 10⁶ В/м      [напруженість утримувального поля на інтерфейсі]
```

2. **Енергетичне положення основного квантового стану `E₀`:**

```
E₀
= 2.3381 · ((ħ² · q² · E_s²) / (2 · m*))^(1/3)      [розв'язок рівняння Ейрі для i=0]
= 2.3381 · (((1.055 · 10⁻³⁴)² · (1.602 · 10⁻¹⁹)² · (3.51 · 10⁶)²) / (2 · 0.067 · 9.11 · 10⁻³¹))^(1/3)      [підстановка констант]
= 7.42 · 10⁻²¹ Дж      [енергія основного стану в джоулях]
= (7.42 · 10⁻²¹) / (1.602 · 10⁻¹⁹)      [переведення в електрон-вольти]
= 0.0463 еВ = 46.3 меВ      [положення основної підзони над дном ями]
```

3. **Положення рівня Фермі `E_F` відносно `E₀` при `T = 0 К`:**

```
E_F - E₀
= (π · ħ² · n_s) / m*      [вироджена статистика 2DEG]
= (π · (1.055 · 10⁻³⁴)² · 5 · 10¹⁵) / (0.067 · 9.11 · 10⁻³¹)      [підстановка густини носіїв]
= 2.87 · 10⁻²¹ Дж      [енергія Фермі над дном підзони]
= 17.9 меВ      [положення рівня Фермі в міліелектрон-вольтах]
```

Оскільки `E₁ = 1.748 · E₀ = 80.9 меВ`, енергетична відстань до першої збудженої підзони становить `E₁ - E₀ = 34.6 меВ`. Рівень Фермі `E_F - E₀ = 17.9 меВ` знаходиться значно нижче підзони `E₁`, що гарантує відсутність міжпідзонного розсіювання за низьких температур.

4. **Гранична частота підсилення за струмом `f_T`:**

```
f_T
= v_sat / (2 · π · L_g)      [гранична частота прольоту під затвором]
= (1.2 · 10⁵ м/с) / (2 · π · 10⁻⁷ м)      [підстановка швидкості та довжини затвора]
= 1.91 · 10¹¹ Гц = 191 ГГц      [гранична частота AlGaAs/GaAs транзистора]
```

Для порівняння, аналогічний розрахунок для `GaN HEMT` із довжиною затвора `L_g = 50 нм` та насиченою швидкістю `v_sat = 2.0 · 10⁷ см/с` дає:

```
f_T(GaN)
= (2.0 · 10⁵ м/с) / (2 · π · 5 · 10⁻⁸ м)      [розрахунок для суб-100 нм GaN HEMT]
= 6.37 · 10¹¹ Гц = 637 ГГц      [гранична частота нітридного транзистора]
```

Цей числовий результат наочно демонструє, що поєднання високої концентрації квантованого 2DEG та субмікронної літографії затвора виводить HEMT на терагерцові рубежі мікрохвильової електроніки.
