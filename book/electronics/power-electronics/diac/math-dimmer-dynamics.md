# 🧮 Математичний аналіз RC-DIAC генератора та фазового зсуву

Проєктування фазового регулятора потужності на базі [симістора](topic:electronics/triac) та порогового елемента [DIAC](topic:electronics/diac) вимагає точного математичного узгодження двох взаємопов'язаних процесів: повільного накопичення фазового зсуву напруги під дією змінної ЕРС мережі та надшвидкого імпульсного розряду накопиченої енергії в керівний перехід силового кристала.

Якщо обрати ємність конденсатора замалою — енергії розряду не вистачить для подолання порогу струму відмикання симістора `I_GT`, і ключ не відкриється. Якщо обрати опір потенціометра зависоким — амплітуда напруги на конденсаторі взагалі ніколи не сягне напруги пробою `V_BO`, і регулятор раптово згасне на початку шкали. Математичний розрахунок визначає межі працездатності схеми та усуває розриви регулювання.

### 1. Диференціальне рівняння фазозсувного кола при синусоїдальному живленні

Розглянемо класичне первинне коло: резистор `R` (послідовне з'єднання постійного обмежувального резистора `R_min` та змінного потенціометра `R_pot`) і конденсатор `C`, підключені до мережевої напруги змінного струму:

```
v_in(t) = V_m · sin(ω·t)
```

де:
* `V_m = V_rms · √2` — амплітудне значення напруги мережі (для 230 В амплітуда `V_m ≈ 325.3 В`);
* `ω = 2·π·f` — циклічна частота (для 50 Гц `ω ≈ 314.16 рад/с`, для 60 Гц `ω ≈ 376.99 рад/с`).

За [законом напруг Кірхгофа](topic:electronics/kvl) сума спадів напруг на резисторі та конденсаторі дорівнює миттєвій напрузі джерела:

```
v_R(t) + v_C(t) = v_in(t)
i(t) = C · (dv_C / dt)
R · C · (dv_C / dt) + v_C(t) = V_m · sin(ω·t)
```

Це лінійне неоднорідне диференціальне рівняння першого порядку. Його повний розв'язок складається із суми перехідної складової `v_C_trans(t)` та вимушеної періодичної складової `v_C_forced(t)`:

```
v_C(t) = v_C_trans(t) + v_C_forced(t)
```

Перехідна експоненційна складова згасає зі сталою часу `τ = R · C`:

```
v_C_trans(t) = V_0 · e^(-t / (R·C))
```

В усталеному періодичному режимі за кілька періодів експонента повністю затухає, і напругу шукаємо методом комплексних амплітуд:

```
V_C_complex
= V_in_complex / (1 + j·ω·R·C)                                [дільник напруги на R і C]
= V_m / √(1 + (ω·R·C)²) · e^(-j·arctan(ω·R·C))                [перехід до показникової форми]
```

У часовій формі усталена напруга на конденсаторі має вигляд зсунутої за фазою синусоїди:

```
v_C(t) = V_Cm · sin(ω·t - φ)

де:
V_Cm = V_m / √(1 + (ω·R·C)²)   [амплітуда напруги на конденсаторі]
φ = arctan(ω·R·C)              [кут фазового запізнення в радіанах]
```

### 2. Визначення моменту пробою DIAC і кута відсікання

DIAC залишається закритим (струм через нього практично дорівнює нулю), доки модуль напруги на конденсаторі не досягне порогу перемикання `V_BO`:

```
|v_C(t_fire)| = V_BO
```

Підставивши вираз для `v_C(t)`, отримуємо рівняння для знаходження часу спрацьовування `t_fire` та відповідного фазового кута відсікання `α = ω · t_fire`:

```
V_Cm · sin(α - φ) = V_BO
sin(α - φ) = V_BO / V_Cm
α - φ = arcsin(V_BO / V_Cm)
α = φ + arcsin(V_BO / V_Cm)
```

Розгорнемо формулу для кута відсікання через параметри компонентів `R`, `C`, `V_m` та `V_BO`:

```
α = arctan(ω·R·C) + arcsin((V_BO / V_m) · √(1 + (ω·R·C)²))
```

З цього виразу безпосередньо видно, як опір `R` керує кутом відкриття симістора:
1. **Мінімальний опір (`R → 0`):**
   * `φ = arctan(0) = 0`;
   * `α_min = arcsin(V_BO / V_m) = arcsin(32 / 325.3) = arcsin(0.0984) ≈ 5.6° ≈ 0.098 рад`.
   * Симістор відкривається майже на самому початку півхвилі (кутова затримка всього 5.6°), віддаючи навантаженню понад 99.8% потужності.
2. **Зростання опору `R`:**
   * Зростає фазовий зсув `φ` (напруга на конденсаторі запізнюється відносно мережі).
   * Одночасно зменшується амплітуда `V_Cm`, тому відношення `V_BO / V_Cm` зростає, відсуваючи кут `α` ще далі до кінця півхвилі (аж до 150–170°).

### 3. Розрахунок граничного опору потенціометра (умова зриву перемикання)

Щоб DIAC узагалі міг пробитися, амплітуда напруги на конденсаторі `V_Cm` обов'язково повинна перевищувати поріг `V_BO`:

```
V_Cm ≥ V_BO
V_m / √(1 + (ω·R_max·C)²) = V_BO

Виведення граничного опору R_max:
1 + (ω·R_max·C)² = (V_m / V_BO)²           [піднесення обох частин до квадрата]
= (V_m / V_BO)²                            [відокремлення квадратичного члена]
(ω·R_max·C)² = (V_m / V_BO)² - 1           [перенесення одиниці праворуч]
ω·R_max·C = √((V_m / V_BO)² - 1)           [добування квадратного кореня]
R_max = (1 / (ω·C)) · √((V_m / V_BO)² - 1) [ділення на циклічну частоту і ємність]
```

**Числовий приклад розрахунку:**
* Мережа: `V_rms = 230 В` → `V_m = 230 · √2 ≈ 325.3 В`;
* Частота: `f = 50 Гц` → `ω = 2 · π · 50 ≈ 314.16 рад/с`;
* Конденсатор: `C = 100 нФ = 100 · 10⁻⁹ Ф`;
* Поріг DIAC: `V_BO = 32 В`.

Обчислимо максимальний опір `R_max`:

```
R_max
= (1 / (314.16 · 100·10⁻⁹)) · √((325.3 / 32)² - 1)   [підстановка числових значень]
= (1 / 3.1416·10⁻⁵) · √(10.165² - 1)                 [обчислення відношення напруг]
= 31831 · √(103.34 - 1)                              [піднесення до квадрата]
= 31831 · √102.34                                    [віднімання одиниці]
= 31831 · 10.116                                     [добування квадратного кореня]
≈ 322000 Ом                                          [множення: отримуємо 322 кОм]
```

Якщо встановити потенціометр з номіналом 470 кОм чи 1 МОм без розрахунку, у крайньому положенні ручки регулятора напруга на конденсаторі впаде нижче 32 В, і DIAC повністю перестане відкриватися. Оптимальний вибір для даного кола — стандартний потенціометр на **220 кОм або 250 кОм** у парі з постійним захисним резистором на **4.7 кОм**.

### 4. Розрахунок вихідної середньоквадратичної напруги та потужності навантаження

При фазовому регулюванні синусоїдальна напруга пропускається на активне навантаження `R_load` лише починаючи з фазового кута `α` і до кінця кожної півхвилі (кута `π`):

```
v_load(t) = V_m · sin(θ),   при α ≤ θ ≤ π
v_load(t) = 0,             при 0 ≤ θ < α
```

Середньоквадратичне (RMS) значення напруги на навантаженні `V_rms_load` розраховується через інтеграл за півперіод:

```
V_rms_load²
= (1 / π) · ∫[α..π] (V_m · sin(θ))² dθ                       [інтеграл середньоквадратичного значення]
= (V_m² / π) · ∫[α..π] ((1 - cos(2θ)) / 2) dθ                [тригонометрична тотожність півкута]
= (V_m² / (2·π)) · [θ - sin(2θ)/2] від α до π               [первісна інтегрування]
= (V_m² / (2·π)) · [(π - α) + sin(2α)/2]                     [підстановка меж інтегрування]
= (V_m² / 2) · [1 - α/π + sin(2α)/(2·π)]                     [винесення множника]
= V_rms_mains² · [1 - α/π + sin(2α)/(2·π)]                   [заміна амплітуди на V_rms мережі]
```

Остаточний вираз для діючої напруги на навантаженні:

```
V_rms_load = V_rms_mains · √(1 - α/π + sin(2α)/(2·π))
```

Потужність `P(α)`, що виділяється на резистивному навантаженні (наприклад, нагрівачі чи лампі розжарювання):

```
P(α) = P_max · (1 - α/π + sin(2α)/(2·π))
```

де `P_max = V_rms_mains² / R_load` — повна потужність при повному відкритті (`α = 0`).

**Таблиця залежності потужності від кута відсікання `α`:**

| Кут `α` (градуси) | Кут `α` (радіани) | Відносна напруга `V_load / V_mains` | Відносна потужність `P / P_max` |
| :--- | :--- | :--- | :--- |
| **0°** | 0 | 1.000 (100%) | 1.000 (100%) |
| **30°** | π / 6 (0.524) | 0.992 (99.2%) | 0.985 (98.5%) |
| **60°** | π / 3 (1.047) | 0.897 (89.7%) | 0.804 (80.4%) |
| **90°** | π / 2 (1.571) | 0.707 (70.7%) | 0.500 (50.0%) |
| **120°** | 2π / 3 (2.094) | 0.442 (44.2%) | 0.196 (19.6%) |
| **150°** | 5π / 6 (2.618) | 0.124 (12.4%) | 0.015 (1.5%) |
| **180°** | π (3.142) | 0.000 (0%) | 0.000 (0%) |

З таблиці чітко видно, що при куті відсікання 90° (відкриття на піку синусоїди) навантаження отримує рівно 50% номінальної потужності.

### 5. Гармонійний склад напруги та коефіцієнт гармонік (THD)

Фазове відсікання синусоїди неминуче спотворює форму напруги, генеруючи непарні вищі гармоніки (3-тю, 5-ту, 7-му тощо). Розкладемо напругу на навантаженні у ряд Фур'є:

```
v_load(θ) = a_0/2 + ∑[n=1..∞] (a_n · cos(n·θ) + b_n · sin(n·θ))
```

Оскільки напруга симетрична в обох півперіодах (`v(θ + π) = -v(θ)`), постійна складова `a_0 = 0`, а всі парні гармоніки тотожно дорівнюють нулю (`a_2k = b_2k = 0`).

Коефіцієнти для непарних гармонік (`n = 1, 3, 5, ...`):

```
a_n
= (2 / π) · ∫[α..π] V_m · sin(θ) · cos(n·θ) dθ               [інтеграл коефіцієнта Фур'є a_n]
= (V_m / π) · [cos((n-1)·α)/(n-1) - cos((n+1)·α)/(n+1) - 2/(n²-1)] [інтегрування добутку тригонометричних функцій]

b_n
= (2 / π) · ∫[α..π] V_m · sin(θ) · sin(n·θ) dθ               [інтеграл коефіцієнта Фур'є b_n]
= (V_m / π) · [sin((n-1)·α)/(n-1) - sin((n+1)·α)/(n+1)]      [інтегрування добутку синусів]
```

Для першої (основної) гармоніки (`n = 1`):

```
a_1 = (V_m / (2·π)) · (cos(2α) - 1)
b_1 = (V_m / (2·π)) · (2·(π - α) + sin(2α))
V_1_rms = (1 / √2) · √(a_1² + b_1²)
```

Коефіцієнт спотворення синусоїдності (Total Harmonic Distortion, THD) напруги на навантаженні визначається як відношення енергії вищих гармонік до енергії першої гармоніки:

```
THD(α)
= √(V_rms_load² - V_1_rms²) / V_1_rms                        [означення коефіцієнта гармонік THD]
= √((V_rms_load / V_1_rms)² - 1)                             [винесення V_1_rms під корінь]
```

При куті `α = 90°` (половина потужності) розрахунок дає `THD(90°) ≈ 48.3%`. Це величезний рівень спотворень, який генерує значні вищі гармоніки струму в мережі живлення, що робить використання мережевого фільтра (дроселя `L` та конденсатора `X2`) обов'язковою інженерною вимогою.

### 6. Чутливість кута відсікання до нестабільності мережі та компонентів

При проєктуванні прецизійних фазових регуляторів важливо оцінити, як зміна напруги живлення `V_m` чи температури впливає на стабільність вихідної потужності. Знайдемо частинну похідну кута відсікання `α` за амплітудою мережі `V_m`:

```
dα / dV_m
= d/dV_m [arcsin((V_BO / V_m) · √(1 + (ω·R·C)²))]            [диференціювання виразу кута відсікання]
= - (V_BO · √(1 + (ω·R·C)²)) / (V_m² · √(1 - u²))            [похідна арксинуса за аргументом u]
```

де `u = (V_BO / V_m) · √(1 + (ω·R·C)²) = sin(α - φ)`.

Оскільки знак похідної від'ємний (`dα / dV_m < 0`), при випадковому падінні напруги в мережі кут `α` автоматично збільшується. Це означає, що при просіданні мережі регулятор відсікає ще більшу частину півхвилі, посилюючи спад потужності навантаження. Це пояснює, чому прості димери без зворотного зв'язку дуже чутливі до мережевих коливань.

Аналогічно, знайдемо чутливість кута відсікання до розкиду напруги пробою DIAC `V_BO`:

```
dα / dV_BO
= d/dV_BO [arcsin((V_BO / V_m) · √(1 + (ω·R·C)²))]           [диференціювання за порогом V_BO]
= √(1 + (ω·R·C)²) / (V_m · √(1 - u²))                        [похідна за змінною V_BO]
```

Цей вираз показує: чим більший фазовий зсув (чим вищий опір `R`), тим сильніше асиметрія порогів DIAC `ΔV_BO` деформує кути відсікання у сусідніх півперіодах. При паспортній асиметрії `ΔV_BO = 2 В` різниця кутів `Δα = α(+) - α(-)` на малих потужностях може досягати 4–6 градусів, генеруючи небезпечну постійну складову струму.

### 7. Температурний дрейф і взаємна компенсація ТКЕ компонентів

Нагрівання елементів схеми зміщує робочу точку димера. Повна похідна кута відсікання за температурою `T`:

```
dα / dT = (∂α / ∂V_BO) · (dV_BO / dT) + (∂α / ∂C) · (dC / dT) + (∂α / ∂R) · (dR / dT)
```

Розглянемо знаки та величини складових:
* **DIAC:** має додатний температурний коефіцієнт напруги пробою `TC(V_BO) = (1/V_BO)·(dV_BO/dT) ≈ +0.08 %/°C`. З нагріванням `V_BO` зростає, що зміщує кут `α` вправо (затримка зростає, потужність падає).
* **Потенціометр:** металоплівкові та вуглецеві резистори мають помірний ТКС `TC(R) ≈ ±0.02...0.05 %/°C`.
* **Фазовий конденсатор `C`:** залежно від типу діелектрика має кардинально різний ТКЄ:
  * Поліетилентерефталатні плівкові конденсатори (тип MKT / лавсан): `TC(C) ≈ +1.5...2.0 %/°C`. Їхній позитивний ТКЄ лише додається до позитивного дрейфу DIAC, викликаючи сильний спад яскравості при прогріванні димера у закритому підрозетнику (до 15–20% падіння потужності).
  * Поліпропіленові плівкові конденсатори (тип MKP): володіють стабільним **від'ємним** температурним коефіцієнтом ємності `TC(C) ≈ -0.15...-0.25 %/°C`.

При використанні поліпропіленового конденсатора MKP від'ємний дрейф ємності `dC/dT < 0` практично ідеально компенсує позитивний температурний дрейф напруги DIAC `dV_BO/dT > 0`:

```
dα/dT
≈ (∂α/∂V_BO) · (+0.08% · V_BO) + (∂α/∂C) · (-0.18% · C)
≈ 0                                                      [взаємне скасування температурного дрейфу]
```

Саме тому в професійних димерах промислового та побутового класу як фазовий конденсатор `C1` завжди використовують виключно плівкові поліпропіленові конденсатори класу MKP на 400 В / 630 В.

### 8. Енергетика розрядного імпульсу та піковий струм затвора

У момент досягнення напруги `V_BO` конденсатор зберігає накопичену електростатичну енергію:

```
W_initial = (1/2) · C · V_BO²
```

Коли DIAC переходить у провідний стан, він здійснює динамічний спад напруги `ΔV` до залишкової напруги `V_F = V_BO - ΔV`. Після завершення розряду залишок енергії в конденсаторі становить:

```
W_final = (1/2) · C · (V_BO - ΔV)²
```

Енергія `ΔW`, передана в коло керуючого переходу симістора у вигляді імпульсу струму:

```
ΔW
= W_initial - W_final                                    [різниця енергій до і після розряду]
= (1/2) · C · [V_BO² - (V_BO - ΔV)²]                     [підстановка початкової і кінцевої енергії]
= (1/2) · C · [V_BO² - (V_BO² - 2·V_BO·ΔV + ΔV²)]        [розкриття квадрата різниці]
= (1/2) · C · [2·V_BO·ΔV - ΔV²]                          [взаємне знищення членів V_BO²]
= C · ΔV · (V_BO - ΔV / 2)                               [винесення спільного множника за дужки]
```

**Числовий розрахунок енергії імпульсу:**
Для стандартного DIAC DB3 (`V_BO = 32 В`, `ΔV = 10 В`) та конденсатора `C = 100 нФ`:

```
ΔW
= 100·10⁻⁹ · 10 · (32 - 10 / 2)                          [підстановка ємності, спаду і напруги]
= 10⁻⁶ · (32 - 5)                                        [обчислення виразу в дужках]
= 10⁻⁶ · 27                                              [множення коефіцієнтів]
= 27 · 10⁻⁶ Дж                                           [кінцевий результат: 27 мкДж]
```

Ця енергія вивільняється за час розряду конденсатора через внутрішній динамічний опір відкритого DIAC `R_diac` (близько 5–10 Ом) та внутрішній опір переходу затвор-MT1 симістора `R_gate` (близько 5–15 Ом).

Загальний активний опір розрядного контуру:

```
R_loop = R_diac + R_gate ≈ 10 + 10 = 20 Ом
```

Піковий струм розрядного імпульсу:

```
I_peak = (V_BO - V_F - V_GT) / R_loop

де:
V_GT ≈ 1.0 В — пряме падіння на переході затвор-MT1 симістора.

I_peak = (32 - 22 - 1.0) / 20 = 9 / 20 = 0.45 А = 450 мА
```

Стала часу розрядного імпульсу:

```
τ_pulse = R_loop · C = 20 · 100·10⁻⁹ = 2·10⁻⁶ с = 2 мкс
```

Імпульс струму амплітудою близько **0.45–1.0 А** тривалістю **2–5 мкс** володіє величезною швидкістю наростання `dI_G/dt > 1 А/мкс`, що гарантує миттєве й надійне відмикання силового симістора по всій площі його кристала.

### 9. Математична модель подвійного RC-ланцюжка (Double-RC Anti-hysteresis)

В одинарному RC-колі після пробою DIAC напруга на конденсаторі падає не до нуля, а до `V_residual ≈ 22 В`. У наступній півхвилі конденсатор починає заряджатися не з нуля, а з ненульового початкового заряду протилежного знаку, що породжує стрибок яскравості («snap-on effect») при повільному виведенні потенціометра.

Для усунення цього ефекту застосовують каскадний дволанковий фільтр:
* **Перша ланка (головний фазозсувач):** `R1` (потенціометр), `C1` (основна ємність, зазвичай 100 нФ).
* **Друга ланка (ізолююча ємність розряду):** `R2` (фіксований опір 15–33 кОм), `C2` (мала ємність, зазвичай 10–22 нФ).

Складемо систему рівнянь за методом вузлових потенціалів для проміжних вузлів `V_C1` та `V_C2` у комплексній формі:

```
(V_in - V_C1) / R1 = j·ω·C1·V_C1 + (V_C1 - V_C2) / R2
(V_C1 - V_C2) / R2 = j·ω·C2·V_C2
```

Виразивши `V_C1` з другого рівняння:

```
V_C1 = V_C2 · (1 + j·ω·R2·C2)
```

Та підставивши у перше рівняння, отримуємо результуючий комплексний коефієнт передачі ненавантаженого подвійного RC-кола:

```
H(jω) = V_C2(jω) / V_in(jω)
= 1 / [(1 - ω²·R1·C1·R2·C2) + j·ω·(R1·C1 + R2·C2 + R1·C2)]
```

Введемо позначення сталих часу окремих контурів:
* `τ1 = R1 · C1`;
* `τ2 = R2 · C2`;
* `τ12 = R1 · C2`.

Модуль коефіцієнта передачі та сумарний фазовий зсув напруги на керуючому конденсаторі `C2`:

```
|H(jω)| = 1 / √((1 - ω²·τ1·τ2)² + ω²·(τ1 + τ2 + τ12)²)
φ_total = arctan(ω·(τ1 + τ2 + τ12) / (1 - ω²·τ1·τ2))
```

**Чому подвійне коло усуває гістерезис:**
1. Коли DIAC пробивається, розряджається виключно **малий конденсатор `C2`** (`10–22 нФ`).
2. Енергія розряду `C2` у 5–10 разів менша за енергію `C1`, проте її цілком достатньо для імпульсу в затвор завдяки малому опору контуру `C2-DIAC-Gate`.
3. Резистор `R2` (15–33 кОм) має на три порядки більший опір, ніж внутрішній опір відкритого DIAC (10–20 Ом). За короткий час імпульсу (2–3 мкс) через `R2` встигає стекти мізерний заряд:

```
ΔQ_lost
= (V_C1 / R2) · τ_pulse                                  [закон Ома для розв'язуючого резистора]
= (32 / 22000) · 3·10⁻⁶                                  [підстановка напруги, опору і часу]
≈ 4.36 · 10⁻⁹ Кл                                         [отримуємо всього 4.36 нанокулона]
```

4. Основний конденсатор `C1` зберігає заряд `Q1 = C1 · V_C1 = 100·10⁻⁹ · 32 = 3.2·10⁻⁶ Кл = 3200 нКл`. Відтік 4.36 нКл становить менше **0.14%** його сумарного заряду.
5. Головний конденсатор `C1` практично **не відчуває комутаційного розряду** `C2` і безперервно продовжує свій плавний синусоїдальний фазовий рух без стрибка початкових умов.

Завдяки цьому фазовий регулятор на подвійному RC-ланцюжку набуває ідеальної лінійності регулювання, забезпечуючи абсолютно плавний старт яскравості світильника або обертів ротора від 1% до 99% номінальної потужності без жодного стрибка чи тремтіння.

### 10. Динаміка фазового керування на індуктивному навантаженні (RL-ланцюг)

Коли навантаженням симістора є електродвигун або трансформатор з активним опором `R_L` та індуктивністю `L_L`, струм навантаження відстає від напруги на фазовий кут `ψ = arctan(ω·L_L / R_L)`.

Диференціальне рівняння струму навантаження після відмикання симістора у момент `t_on = α / ω`:

```
L_L · (di / dt) + R_L · i(t) = V_m · sin(ω·t)
```

Його аналітичний розв'язок:

```
i(t) = (V_m / |Z_L|) · [sin(ω·t - ψ) - sin(α - ψ) · e^(-(R_L / L_L) · (t - α/ω))]
```

де `|Z_L| = √(R_L² + (ω·L_L)²)`.

Оскільки струм відстає від напруги, він переходить через нуль пізніше за напругу мережі — у момент фазового кута згасання `β > π`. Це означає, що симістор залишається у відкритому стані навіть тоді, коли напруга мережі вже змінила свій знак на протилежний!

У момент згасання струму (`i = 0` при куті `β`) на симісторі миттєво виникає стрибок напруги `V_step = V_m · sin(β)`. Швидкість наростання напруги на закритому симісторі визначається виразом:

```
(dv / dt)_com = ω · V_m · sin(β)
```

Якщо ця швидкість перевищить критичну межу симістора `(dv/dt)_c`, кристал самовільно увімкнеться без імпульсу від DIAC, що викличе неконтрольоване обертання двигуна на повній швидкості. Для обмеження цієї швидкості паралельно симістору встановлюють захисний демпфуючий RC-снабер:

```
C_snub ≥ (V_m · sin(β)) / (R_load · (dv/dt)_crit)
R_snub = 2 · √(L_L / C_snub)                             [умова критичного демпфування коливань]
```

Точний розрахунок параметрів снабера гарантує, що фазовий регулятор із DIAC збереже повну керованість як на суто активному, так і на важкому індуктивному навантаженні.

### 11. Розрахунок LC-фільтра придушення електромагнітних завад (EMI)

Комутація симістора генерує потужні спектральні гармоніки струму з крутим фронтом `di/dt > 50 А/мкс`. Для задоволення стандартів електромагнітної сумісності (EN 55014 / CISPR 14) на вході схеми встановлюють П-подібний або Г-подібний LC-фільтр низьких частот другого порядку з частотою зрізу `f_cutoff`:

```
f_cutoff = 1 / (2 · π · √(L_filter · C_X2))
```

Розрахуємо частоту зрізу для стандартних компонентів:
* Індуктивність дроселя: `L_filter = 100 мкГн = 100 · 10⁻⁶ Гн`;
* Ємність мережевого конденсатора: `C_X2 = 0.1 мкФ = 0.1 · 10⁻⁶ Ф = 100 · 10⁻⁹ Ф`.

```
f_cutoff
= 1 / (2 · π · √(100·10⁻⁶ · 100·10⁻⁹))                   [підстановка індуктивності та ємності]
= 1 / (2 · π · √(10⁻¹¹))                                 [обчислення добутку під коренем]
= 1 / (2 · π · 3.162·10⁻⁶)                               [добування квадратного кореня]
= 1 / (1.987·10⁻⁵)                                       [множення на 2*pi]
≈ 50330 Гц                                               [кінцевий результат: 50.3 кГц]
```

Ослаблення фільтра другого порядку на початковій частоті вимірювань радіозавад (150 кГц):

```
Att(150 кГц)
= 40 · log10(150 кГц / 50.33 кГц)                        [формула затухання фільтра 2-го порядку: 40 дБ/декаду]
= 40 · log10(2.98)                                       [відношення частоти завади до частоти зрізу]
= 40 · 0.474                                             [обчислення десяткового логарифма]
≈ 18.96 дБ                                               [ослаблення високочастотного шуму на ~19 дБ]
```

Це ослаблення зменшує амплітуду випромінюваних радіозавад майже у 9 разів, повністю усуваючи проникнення високочастотного тріску в електромережу будинку.

### 12. Тепловий розрахунок резисторів фазового кола

У крайньому положенні ручки регулятора (`R_pot = 0`) весь струм фазового кола обмежується виключно постійним резистором `R1 = R_min = 4.7 кОм`.

Якби симістор не відкривався, середньоквадратична потужність на резисторі становила б `P = V_rms² / R1 = 230² / 4700 ≈ 11.26 Вт`. Проте оскільки симістор відкривається при досягненні напруги 32 В (кутова затримка `α ≈ 5.6°`), напруга на фазовому колі діє лише малу частку півперіоду:

```
t_conduction
= α / ω                                                  [час наростання напруги до пробою]
= 0.098 рад / 314.16 рад/с                               [підстановка кута і циклічної частоти]
≈ 0.000312 с = 0.312 мс                                  [час дії напруги: 0.312 мс]
```

Коефіцієнт заповнення активної фази становить `D = t_conduction / T_half = 0.312 мс / 10 мс = 0.0312` (3.12%).

Реальна середня теплова потужність, що виділяється на захисному резисторі `R1`:

```
P_R1_real
= P_peak_avg · D                                         [множення середньої потужності на коефіцієнт заповнення]
= 11.26 Вт · 0.0312                                      [підстановка значень]
≈ 0.351 Вт                                               [реальне тепловиділення: ~0.35 Вт]
```

Звідси випливає чітка інженерна вимога: номінальна потужність розсіювання захисного резистора `R1` мусить бути **не менше 0.5 Вт або 1.0 Вт** (з перевагою негорючих металооксидних резисторів типу Flameproof), аби гарантувати надійну та безпечну роботу регулятора в екстремальних режимах.
