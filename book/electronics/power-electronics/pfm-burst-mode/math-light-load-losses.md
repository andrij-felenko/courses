# 🧮 Баланс втрат і математика енергозбереження на малому навантаженні

Коли імпульсний перетворювач живить навантаження в активному режимі (струми від сотень міліампер до десятків ампер), його енергетичний баланс підпорядкований втратам провідності: струм тече крізь опір каналу транзисторів, мідну обмотку дроселя та еквівалентний послідовний опір конденсаторів. Проте при переході пристрою в черговий режим (струми від одиниць мікроампер до кількох міліампер) потужність корисного навантаження зменшується в десятки тисяч разів, тоді як втрати на кожне перемикання залишаються незмінними. Розрахунок енергетичного бюджету на малому навантаженні вимагає математичного розділення втрат на залежні від струму та пропорційні частоті комутації, а також виведення законів регулювання частоти в режимах ЧІМ (PFM) і пачки (Burst Mode).

### Структура втрат перетворювача та критичний струм ККД

Повна потужність втрат імпульсного знижувального перетворювача (Buck) складається з трьох ключових компонентів: втрат провідності, динамічних втрат перемикання та потужності власного споживання схеми керування.

Втрати провідності пропорційні квадрату діючого (RMS) струму й визначаються сумарним опором кола:

```
P_cond = I_out² · R_eq      [R_eq = D·R_ds_hs + (1 - D)·R_ds_ls + R_dcr + ESR_L]
```

Динамічні втрати перемикання виникають під час кожного такту комутації й складаються з чотирьох фізичних процесів:

1. **Перезаряд ємностей затворів силових ключів:** драйвер щотакту заряджає затвор верхнього та нижнього польових транзисторів до напруги керування `V_gate`, розсіюючи енергію затвора:

```
P_gate = f_sw · (Q_g_hs + Q_g_ls) · V_gate
```

2. **Перезаряд вихідної паразитної ємності ключів (`C_oss`):** під час замикання верхнього ключа енергія, накопичена у вихідній ємності комутаційного вузла `C_oss = C_oss_hs + C_oss_ls`, розсіюється в тепло:

```
P_coss = 0.5 · C_oss · V_in² · f_sw
```

3. **Втрати перекриття струму й напруги:** під час фронтів увімкнення (`t_r`) та вимкнення (`t_f`) верхнього ключа через транзистор одночасно протікає струм навантаження при спадаючій або наростаючій напрузі:

```
P_overlap = 0.5 · V_in · I_out · (t_r + t_f) · f_sw
```

4. **Втрати в магнітному осерді дроселя:** перемагнічування феритового чи композитного осердя створює втрати на гістерезис і вихрові струми за емпіричним рівнянням Штейнметца:

```
P_core = V_core · k_core · f_sw^α · ΔB^β
```

5. **Статичні втрати власного споживання контролера:** опорне джерело напруги, генератор пилки, підсилювач помилки та компаратори споживають постійний струм спокою `I_q`:

```
P_q = V_in · I_q
```

Об'єднаємо всі складові, згрупувавши їх за залежністю від робочої частоти `f_sw` та струму навантаження `I_out`:

```
P_loss(I_out, f_sw) = P_q + f_sw · E_cycle + I_out · (0.5 · V_in · (t_r + t_f) · f_sw) + I_out² · R_eq
```

де `E_cycle = (Q_g_hs + Q_g_ls) · V_gate + 0.5 · C_oss · V_in² + E_core` — фіксована енергія, що безповоротно витрачається за один такт комутації.

Коефіцієнт корисної дії перетворювача виражається класичним відношенням корисної вихідної потужності до повної споживаної:

```
η = P_out / (P_out + P_loss)
  = (V_out · I_out) / (V_out · I_out + P_q + f_sw · E_cycle + k_sw · I_out · f_sw + I_out² · R_eq)
```

При високій фіксованій частоті `f_sw = const` (режим неперервної ШІМ) сума `P_q + f_sw · E_cycle` утворює фіксований поріг втрат `P_fix`. Коли струм навантаження прямує до нуля (`I_out → 0`), корисна потужність `P_out = V_out · I_out` прямує до нуля лінійно, тоді як `P_fix` залишається незмінною. Границя ККД дає математичне пояснення катастрофічного падіння енергоефективності:

```
lim(I_out → 0) η = lim(I_out → 0) [ (V_out · I_out) / (V_out · I_out + P_fix) ]
                 = 0
```

Точка максимального ККД досягається, коли змінні втрати провідності зрівнюються з постійними втратами:

```
I_out² · R_eq = P_fix
I_opt = √(P_fix / R_eq)
```

Якщо для номінального струму 2 А значення `I_opt ≈ 0.6 А`, то при переході мікроконтролера в режим сну зі струмом 50 мкА робоча точка віддаляється від оптимуму на чотири порядки, і ККД перетворювача падає нижче 5 %.

### Математична модель частотно-імпульсної модуляції (PFM)

Щоб утримати ККД на рівні 85–95 % при спаданні струму навантаження на кілька порядків, необхідно зробити так, щоб втрати перемикання зменшувалися пропорційно вихідній потужності. Цього досягають у режимі ЧІМ із фіксованою тривалістю фази увімкнення (Constant On-Time, COT) та переривчастим струмом дроселя (DCM).

У режимі DCM струм у дроселі під час кожного такту наростає від нуля до пікового значення:

```
I_pk = ((V_in - V_out) / L) · t_on
```

Час спадання струму до нуля крізь діод або відкритий нижній ключ (діодна емуляція):

```
t_off_dcm = (L · I_pk) / V_out
          = ((V_in - V_out) / V_out) · t_on      [підстановка виразу для I_pk]
```

Повний час передачі енергії дроселем:

```
t_cond = t_on + t_off_dcm
       = t_on · (1 + (V_in - V_out) / V_out)      [підстановка виразу для t_off_dcm]
       = t_on · (V_in / V_out)                   [зведення дробів до спільного знаменника]
```

Енергія, що закачується в дросель за один імпульс:

```
E_L = 0.5 · L · I_pk²
```

Під час фази `t_on` частина енергії передається безпосередньо у вихідний конденсатор і навантаження. Повна енергія, доставлена у вихідне коло за один цикл перемикання:

```
E_packet = 0.5 · L · I_pk² · (V_in / (V_in - V_out))
         = 0.5 · L · (((V_in - V_out) / L) · t_on)² · (V_in / (V_in - V_out))
         = (0.5 · (V_in - V_out) · V_in · t_on²) / L      [скорочення однакових множників]
```

Для підтримки стабільної вихідної напруги середня потужність, що віддається імпульсами з частотою `f_pfm`, повинна точно дорівнювати потужності навантаження:

```
P_delivered = E_packet · f_pfm = V_out · I_out
```

Звідси отримуємо точну залежність робочої частоти ЧІМ від струму навантаження:

```
f_pfm(I_out) = (V_out · I_out) / E_packet
             = (2 · L · V_out · I_out) / ((V_in - V_out) · V_in · t_on²)      [підстановка виразу для E_packet]
```

Оскільки параметри `L`, `V_in`, `V_out` та `t_on` фіксовані схемотехнічно, частота перемикання масштабується строго лінійно від струму навантаження:

```
f_pfm ∝ I_out
```

Підставимо отриману змінну частоту `f_pfm` у рівняння динамічних втрат:

```
P_sw_pfm = f_pfm(I_out) · E_cycle
         = [ (2 · L · V_out · E_cycle) / ((V_in - V_out) · V_in · t_on²) ] · I_out
         = k_pfm · I_out
```

Динамічні втрати перестають бути постійною величиною `P_fix` і стають лінійною функцією струму. Тепер при зменшенні струму навантаження у 1000 разів частота комутації та втрати на перезаряд затворів автоматично падають у 1000 разів, зберігаючи високий ККД:

```
η_pfm = (V_out · I_out) / (V_out · I_out + P_q + k_pfm · I_out + I_out² · R_eq)
```

При струмах, де `P_q ≪ k_pfm · I_out`, ККД виходить на стабільне плато:

```
η_pfm_plateau ≈ V_out / (V_out + k_pfm) = const
```

### Діючий струм (RMS) та втрати провідності в режимі DCM

Окремий математичний інтерес становить поведінка втрат провідності в режимі DCM. Оскільки струм дроселя є кусково-лінійним трикутником із тривалістю провідності `t_cond = t_on + t_off_dcm` та періодом `T_pfm = 1 / f_pfm`, розрахуємо діюче (середньоквадратичне) значення струму `I_rms`:

```
I_rms_dcm² = (1 / T_pfm) · ∫[0..T_pfm] i_L²(t) dt
           = (1 / T_pfm) · [ (I_pk² / 3) · t_on + (I_pk² / 3) · t_off_dcm ]
           = (I_pk² / 3) · (t_cond / T_pfm)
           = (I_pk² / 3) · t_cond · f_pfm
```

Підставимо вирази для `t_cond = t_on · (V_in / V_out)` та `f_pfm`:

```
I_rms_dcm² = (I_pk² / 3) · (t_on · V_in / V_out) · [ (2 · L · V_out · I_out) / ((V_in - V_out) · V_in · t_on²) ]
           = (2 / 3) · I_pk · I_out      [підстановка I_pk = (V_in - V_out)·t_on / L]
```

Таким чином, втрати провідності в режимі ЧІМ/DCM становлять:

```
P_cond_dcm = I_rms_dcm² · R_eq = (2 / 3) · I_pk · R_eq · I_out
```

Зверніть увагу на фундаментальну відмінність: у неперервному режимі CCM втрати провідності пропорційні квадрату струму (`I_out²`), тоді як у режимі переривчастого струму DCM втрати провідності зменшуються строго лінійно зі струмом (`∝ I_out`). Це гарантує, що при спаданні навантаження втрати провідності не перетворюються на перешкоду для ККД.

### Математична модель вихідних пульсацій напруги в PFM

Розмах пульсацій вихідної напруги `ΔV_out_pfm` складається з ємнісної складової (накопичення надлишкового заряду) та падіння на активному опорі конденсатора (ESR):

```
ΔV_out_pfm = ΔV_cap + ΔV_esr
```

Під час фази провідності дроселя `t_cond` у вихідний вузол надходить заряд трикутного імпульсу `Q_in = 0.5 · I_pk · t_cond`. За цей же час навантаження безперервно відбирає заряд `Q_out = I_out · t_cond`. Чистий приріст заряду у вихідному конденсаторі:

```
ΔQ_cap = Q_in - Q_out
       = 0.5 · I_pk · t_cond - I_out · t_cond
       ≈ 0.5 · I_pk · t_cond      [оскільки на легкому навантаженні I_out ≪ I_pk]
```

Ємнісний розмах пульсацій напруги:

```
ΔV_cap = ΔQ_cap / C_out = (0.5 · I_pk · t_cond) / C_out
       = (0.5 · I_pk · t_on · V_in) / (V_out · C_out)
```

Резистивний розмах пульсацій визначається піковим струмом заряду:

```
ΔV_esr = (I_pk - I_out) · ESR ≈ I_pk · ESR
```

Повний розмах вихідних пульсацій:

```
ΔV_out_pfm ≈ (0.5 · I_pk · t_on · V_in) / (V_out · C_out) + I_pk · ESR
```

Формула показує, що на відміну від режиму ШІМ, де пульсація зменшується разом зі струмом навантаження, у режимі COT-PFM розмах пульсації кожного одиночного імпульсу залишається незмінним і визначається виключно піковим струмом `I_pk` та ємністю `C_out`. Зменшується лише частота їхньої появи.

### Математична модель режиму пачки (Burst Mode)

У глибокому мікропотужному діапазоні (струми менше 100 мкА) статичний струм спокою контролера `I_q` (зазвичай 0.5–2 мА для швидких підсилювачів помилки) починає переважати над сумарною потужністю навантаження. Режим пачки вирішує цю проблему за рахунок періодичного вимкнення аналогових вузлів керування.

Гістерезисний контролер задає вікно регулювання вихідної напруги з розмахом `2 · ΔV_burst`:
- верхній поріг зупинки генерації: `V_high = V_out + ΔV_burst`;
- нижній поріг пробудження: `V_low = V_out - ΔV_burst`.

Робочий цикл пачки розбивається на дві фази: активну пачку (`t_burst`) та фазу сну (`t_sleep`).

**1. Фаза активної пачки (`t_burst`):**
Контролер генерує серію з `N` імпульсів із високою локальною частотою `f_burst_clk` (зазвичай 500 кГц – 2 МГц). За кожен імпульс у вихідний конденсатор закачується заряд `q_pulse = I_avg_pulse · T_clk`.
Сумарний струм, що віддається в конденсатор:

```
I_charge_net = I_burst_avg - I_out
```

де `I_burst_avg` — середній струм, що генерується перетворювачем під час активної пачки.
Час тривалості активної пачки:

```
t_burst = (C_out · 2 · ΔV_burst) / (I_burst_avg - I_out)
```

Оскільки на легкому навантаженні `I_burst_avg ≫ I_out`, тривалість пачки спрощується до:

```
t_burst ≈ (2 · C_out · ΔV_burst) / I_burst_avg
```

**2. Фаза глибокого сну (`t_sleep`):**
Коли напруга досягає `V_high`, силові ключі розмикаються (стан Hi-Z), опорні кола вимикаються, а струм спокою падає до значення сну `I_q_sleep` (1–5 мкА). Вихідний конденсатор розряджається струмом навантаження `I_out` до досягнення нижнього порогу `V_low`:

```
t_sleep = (C_out · 2 · ΔV_burst) / I_out
```

Період повторення пачок складає:

```
T_burst = t_burst + t_sleep
        ≈ 2 · C_out · ΔV_burst · (1 / I_burst_avg + 1 / I_out)
        ≈ (2 · C_out · ΔV_burst) / I_out      [оскільки I_out ≪ I_burst_avg]
```

Частота повторення пачок:

```
f_burst_rep = 1 / T_burst ≈ I_out / (2 · C_out · ΔV_burst)
```

Середня потужність власного споживання контролера з урахуванням шпаруватості сну `D_sleep = t_sleep / T_burst`:

```
P_q_avg = (P_q_active · t_burst + P_q_sleep · t_sleep) / T_burst
        = P_q_active · (I_out / I_burst_avg) + P_q_sleep · (1 - I_out / I_burst_avg)    [підстановка виразів для t_burst та t_sleep]
        ≈ P_q_sleep + P_q_active · (I_out / I_burst_avg)                                [оскільки I_out ≪ I_burst_avg]
```

При струмі сну `I_q_sleep = 2 мкА` та `V_in = 12 В` середня статична втрата падає з 12 мВт (активний режим) до:

```
P_q_avg = 12 В · 2 мкА = 24 мкВт
```

Це дозволяє утримувати ККД понад 85 % навіть при навантаженні 50 мкА.

### Тепловий розрахунок перетворювача в режимі очікування

Температура кристала інтегральної мікросхеми перетворювача визначається тепловим опором корпусу до навколишнього середовища `R_th_ja` та сумарною розсіюваною потужністю:

```
T_j = T_amb + P_loss · R_th_ja
```

Для типового корпусу QFN-16 (площа 3×3 мм, `R_th_ja ≈ 55 °C/Вт`) при температурі навколишнього середовища `T_amb = 25 °C`:
- У режимі неперервної ШІМ (FCCM) при струмі навантаження 50 мкА втрати становлять `P_loss_pwm = 83.04 мВт`.
  Перегрів кристала: `ΔT = 0.083 Вт · 55 °C/Вт ≈ 4.57 °C`.
- У режимі Burst Mode втрати становлять `P_loss_burst = 46.32 мкВт`.
  Перегрів кристала: `ΔT = 0.000046 Вт · 55 °C/Вт ≈ 0.0025 °C` (повністю відсутній тепловий дрейф).

### Порівняння з лінійним LDO-стабілізатором на мікрострумах

У практичній інженерії нерідко виникає дилема: що краще використовувати для живлення сплячого мікроконтролера — імпульсний перетворювач у Burst Mode чи лінійний LDO з ультранизьким власним споживанням (наприклад, TPS7A02 з `I_q_ldo = 25 нА`)?

Втрати потужності в LDO складаються з падіння на регулюючому транзисторі та власного споживання:

```
P_loss_ldo = (V_in - V_out) · I_out + V_in · I_q_ldo
```

Для нашої системи (12 В → 3.3 В, `I_out = 50 мкА`):

```
P_loss_ldo = (12 - 3.3) В · 50·10⁻⁶ А + 12 В · 25·10⁻⁹ А
           = 435 мкВт + 0.3 мкВт = 435.3 мкВт

η_ldo = (3.3 · 50) / (3.3 · 50 + 435.3) = 165 / 600.3 ≈ 27.5 %
```

ККД LDO принципово обмежений відношенням напруг `V_out / V_in = 3.3 / 12 = 27.5 %`. Втрати в LDO (435 мкВт) майже в 10 разів перевищують втрати імпульсного перетворювача в Burst Mode (46.3 мкВт). Таким чином, імпульсний перетворювач у режимі пачки забезпечує в 3.6 рази довший термін служби батареї, ніж найкращий нанопотужний LDO.

### Практичний розрахунок енергетичного бюджету

Розглянемо числовий приклад розрахунку вузла живлення автономного датчика:
- Вхідна напруга: `V_in = 12 В`;
- Вихідна напруга: `V_out = 3.3 В`;
- Ємність батареї: `C_bat = 2500 мА·год` (літієвий акумулятор 3-cell або LiFePO4);
- Параметри перетворювача: `f_sw = 1 МГц`, `Q_g_total = 12 нКл`, `V_gate = 5 В`, `C_oss = 120 пФ`, `t_r + t_f = 20 нс`, `R_eq = 0.08 Ом`, `I_q_active = 1.2 мА`, `I_q_sleep = 3 мкА`, `C_out = 47 мкФ`, `ΔV_burst = 30 мВ`.

**Крок 1. Фіксовані втрати за один такт комутації:**

```
E_gate = Q_g_total · V_gate = 12·10⁻⁹ · 5 = 60 нДж
E_coss = 0.5 · C_oss · V_in² = 0.5 · 120·10⁻¹² · 144 = 8.64 нДж
E_cycle ≈ E_gate + E_coss = 68.64 нДж
```

**Крок 2. Робота в режимі безперервної ШІМ (FCCM, 1 МГц) при малому навантаженні I_out = 50 мкА:**

```
P_out = 3.3 В · 50·10⁻⁶ А = 0.165 мВт = 165 мкВт
P_gate = 10⁶ Гц · 60·10⁻⁹ Дж = 60 мВт
P_coss = 10⁶ Гц · 8.64·10⁻⁹ Дж = 8.64 мВт
P_q = 12 В · 1.2·10⁻³ А = 14.4 мВт
P_loss_pwm ≈ 60 + 8.64 + 14.4 = 83.04 мВт = 83040 мкВт

η_pwm = 165 / (165 + 83040) ≈ 0.00198 (0.20 %)
```

Струм, що споживається від батареї 12 В:

```
I_bat_pwm = (P_out + P_loss_pwm) / V_in
          = (0.165 + 83.04) мВт / 12 В ≈ 6.93 мА
```

Час життя батареї 2500 мА·год у режимі постійної ШІМ:

```
T_life_pwm = 2500 мА·год / 6.93 мА ≈ 360.7 годин ≈ 15 діб
```

**Крок 3. Робота в режимі Burst Mode при тому самому навантаженні I_out = 50 мкА:**

Приймемо середній струм під час генерації пачки `I_burst_avg = 400 мА`.
Розрахуємо тривалості фаз:

```
t_burst = (2 · 47·10⁻⁶ · 0.030) / 0.400 = 7.05 мкс
t_sleep = (2 · 47·10⁻⁶ · 0.030) / 50·10⁻⁶ = 56.4 мс = 56400 мкс
T_burst = 7.05 + 56400 ≈ 56.4 мс
f_burst_rep = 1 / 0.0564 ≈ 17.7 Гц
```

Кількість імпульсів у пачці при тактовій частоті 1 МГц:

```
N_pulses = 7.05 мкс · 1 МГц ≈ 7 імпульсів
```

Середня потужність втрат комутації за період:

```
P_sw_avg = (N_pulses · E_cycle) / T_burst
         = (7 · 68.64·10⁻⁹ Дж) / 0.0564 с ≈ 8.52 мкВт
```

Середня потужність статичних втрат:

```
P_q_avg = 12 В · [ 1.2 мА · (7.05·10⁻⁶ / 0.0564) + 3 мкА · (1 - 7.05·10⁻⁶ / 0.0564) ]
        = 12 В · [ 0.15 мкА + 3 мкА ] = 12 В · 3.15 мкА ≈ 37.8 мкВт
```

Повні втрати перетворювача в режимі Burst Mode:

```
P_loss_burst = P_sw_avg + P_q_avg = 8.52 + 37.8 = 46.32 мкВт

η_burst = 165 / (165 + 46.32) ≈ 0.7808 (78.1 %)
```

Струм, що споживається від батареї 12 В:

```
I_bat_burst = (165 + 46.32) мкВт / 12 В ≈ 17.61 мкА
```

Час життя батареї 2500 мА·год у режимі Burst Mode:

```
T_life_burst = 2500 мА·год / 0.01761 мА ≈ 141964 години ≈ 16.2 років
```

Математичний аналіз наочно демонструє: перехід від неперервної ШІМ до режиму пачки зі сном зменшує середній струм споживання автономного вузла у 393 рази, перетворюючи батарею, розряджувану за два тижні, на джерело живлення з терміном служби, обмеженим лише хімічним саморозрядом елемента.
