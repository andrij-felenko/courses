# 🧮 Математичний аналіз перетворювача Ćuk: простір станів, передатні функції та умова нульових пульсацій

Математичний опис імпульсного перетворювача Ćuk вимагає виходу за межі спрощеного квазістатичного аналізу, оскільки наявність чотирьох реактивних накопичувачів енергії (двох індуктивностей `L1`, `L2` та двох ємностей `C1`, `Cвих`) утворює динамічну систему четвертого порядку. Цей розділ містить строге аналітичне виведення рівнянь стану у двох фазах комутації, усереднення матриць простору станів (метод Мідлбрука-Ћука), розрахунок струмових навантажень і пульсацій, точний алгебраїчний доказ умови занулення пульсацій струму у зв'язаних обмотках, а також виведення частотної передатної функції з нулем у правій півплощині (RHPZ).

## 1. Вектор стану та диференціальні рівняння комутаційних фаз

Оберемо як змінні стану фізичні величини, що однозначно визначають запасений у реактивних елементах схеми запас електромагнітної енергії:
- `i_1(t)` — миттєвий струм вхідної індуктивності `L1`, що протікає від джерела живлення до першого комутаційного вузла.
- `i_2(t)` — миттєвий струм вихідної індуктивності `L2`, спрямований від від'ємного вихідного вузла до другого комутаційного вузла.
- `v_1(t)` — миттєва напруга на проміжному передавальному конденсаторі `C1` з додатною полярністю на лівій обкладці.
- `v_2(t)` — миттєва напруга на вихідному фільтруючому конденсаторі `Cвих` (абсолютна величина вихідної напруги на навантаженні, де потенціал вихідного вузла відносно землі становить `v_вих = −v_2`).

Вектор стану нелінійної динамічної системи записується як стовпець змінних:

```
x(t) = [ i_1(t), i_2(t), v_1(t), v_2(t) ]ᵀ
```

Вхідним керуючим та збурюючим впливом для схеми виступає напруга первинного джерела живлення `u(t) = Vвх`.

### Стан 1: Ключ Q1 замкнений, діод D1 розімкнений (тривалість інтервалу D·T)

У відкритому стані силового транзистора `Q1` перший комутаційний вузол `SW1` притягується до спільної шини (0 В). Дослідимо миттєві контурні рівняння за законами Кірхгофа:
- До вхідної котушки `L1` прикладена повна напруга джерела `Vвх`.
- Ліва обкладка конденсатора `C1` сідає на землю, тому його права обкладка набуває від'ємного потенціалу `−v_1`, надійно запираючи випрямний діод `D1`.
- Конденсатор `C1` опиняється увімкненим послідовно з вихідною котушкою `L2` та паралельною парою `Cвих || R`. Напруга на котушці `L2` дорівнює різниці потенціалів `−v_1 + v_2`.
- Струм у навантаження формується сумою струму вихідної індуктивності `i_2` та струму розряду ємності `Cвих`.

Система лінійних диференціальних рівнянь першого комутаційного стану:

```
L1 · (di_1 / dt) = Vвх
L2 · (di_2 / dt) = −v_1 + v_2
C1 · (dv_1 / dt) = −i_2
Cвих · (dv_2 / dt) = i_2 − v_2 / R
```

Запишемо систему в канонічній матричній формі простору станів `dx/dt = A1 · x + B1 · u`:

```
dx/dt = A1 · x + B1 · Vвх

де матриці першого стану:

     ┌   0      0      0     0   ┐        ┌ 1/L1 ┐
     │   0      0    −1/L2  1/L2 │        │  0   │
A1 = │   0    −1/C1    0     0   │ , B1 = │  0   │
     │   0    1/Cвих   0  −1/(R·Cвих) │    │  0   │
     └                           ┘        └      ┘
```

### Стан 2: Ключ Q1 розімкнений, діод D1 замкнений (тривалість інтервалу (1−D)·T)

У вимкненому стані транзистора `Q1` безперервний струм котушки `L1` змушує потенціал вузла `SW2` наростати, відкриваючи випрямний діод `D1`. Діод фіксує правий вивід конденсатора `C1` на нульовому потенціалі землі:
- До вхідної котушки `L1` прикладена різниця напруг між входом і зарядженим конденсатором `Vвх − v_1`.
- Конденсатор `C1` заряджається безпосередньо струмом вхідної індуктивності `i_1`.
- Вихідна котушка `L2` замикається через відкритий діод `D1` на землю, тому до неї прикладена напруга вихідного конденсатора `v_2`.
- Вихідний конденсатор продовжує фільтрувати струм навантаження.

Диференціальні рівняння другого комутаційного стану:

```
L1 · (di_1 / dt) = Vвх − v_1
L2 · (di_2 / dt) = v_2
C1 · (dv_1 / dt) = i_1
Cвих · (dv_2 / dt) = i_2 − v_2 / R
```

Матрична форма другого стану `dx/dt = A2 · x + B2 · u`:

```
     ┌   0      0    −1/L1   0   ┐        ┌ 1/L1 ┐
     │   0      0      0    1/L2 │        │  0   │
A2 = │  1/C1    0      0     0   │ , B2 = │  0   │
     │   0    1/Cвих   0  −1/(R·Cвих) │    │  0   │
     └                           ┘        └      ┘
```

## 2. Метод усереднення у просторі станів (State-Space Averaging)

Для отримання безперервної низькочастотної моделі, придатної для аналізу статики та динаміки, виконаємо зважене усереднення матриць системи за повний період перемикання `T`:

```
A_avg = D · A1 + (1 − D) · A2
B_avg = D · B1 + (1 − D) · B2
```

Обчислимо елементи усередненої матриці динаміки `A_avg`:

```
A_avg =
┌   0         0     −(1−D)/L1      0      ┐
│   0         0       −D/L2       1/L2    │
│ (1−D)/C1  −D/C1       0          0      │
│   0      1/Cвих       0     −1/(R·Cвих) │
└                                         ┘

Усереднена матриця збурення входу:
B_avg = [ 1/L1, 0, 0, 0 ]ᵀ
```

### Розрахунок точки спокою постійного струму (DC Operating Point)

В усталеному рівноважному стані системи всі середні швидкості зміни змінних стану дорівнюють строго нулю: `dx/dt = 0`.
Звідси отримуємо векторне алгебраїчне рівняння для середніх значень `X = [ I_1, I_2, V_1, V_2 ]ᵀ`:

```
A_avg · X + B_avg · Vвх = 0
```

Розгорнемо матричну систему в систему скалярних рівнянь:

```
Рівняння 1: 0 − [(1 − D) / L1] · V_1 + Vвх / L1 = 0
            (1 − D) · V_1 = Vвх
            V_1 = Vвх / (1 − D)                 [середня напруга на C1]

Рівняння 2: 0 − (D / L2) · V_1 + (1 / L2) · V_2 = 0
            V_2 = D · V_1                       [зв'язок вихідної напруги з V_1]
            V_2 = D · [Vвх / (1 − D)]
            V_2 = Vвх · D / (1 − D)             [модуль вихідної напруги |Vвих|]

Рівняння 4: (1 / Cвих) · I_2 − [1 / (R · Cвих)] · V_2 = 0
            I_2 = V_2 / R = Iвих                [середній струм вихідної індуктивності]

Рівняння 3: [(1 − D) / C1] · I_1 − (D / C1) · I_2 = 0
            (1 − D) · I_1 = D · I_2
            I_1 = I_2 · D / (1 − D) = Iвих · D / (1 − D) [вхідний струм Iвх]
```

Отриманий результат строго підтверджує баланс потужностей та формули передачі напруги й струму для ідеального перетворювача без втрат.

## 3. Вплив паразитних активних опорів на коефіцієнт передачі та ККД

В реальних схемах силова енергія розсіюється на паразитному активному опорі обмоток індуктивностей `r_L1`, `r_L2`, активному опорі відкритого каналу польового транзистора `R_on`, еквівалентному послідовному опорі конденсатора `r_C1` та прямому падінні напруги на діоді `V_F` (і його диференційному опорі `r_D`).

Врахуємо сумарний еквівалентний послідовний опір втрат `r_loss`, зведений до струмів індуктивностей:

```
r_loss = r_L1 + r_L2 · [D / (1 − D)]² + R_on · D + r_D · (1 − D) + r_C1 · D · (1 − D)
```

Застосовуючи розширений вольт-секундний баланс із урахуванням падіння напруги на втратах, отримуємо точну залежність реальної вихідної напруги `V_2,real` від опору навантаження `R`:

```
V_2,real = [Vвх · D / (1 − D) − V_F] / [1 + r_loss / (R · (1 − D)²)]
```

Коефіцієнт корисної дії (ККД) перетворювача визначається як:

```
η = 1 / [1 + r_loss / (R · (1 − D)²)]
```

З формули чітко видно фундаментальне фізичне обмеження: при наближенні коефіцієнта заповнення `D → 1` знаменник `(1 − D)²` прямує до нуля. Втрати потужності на паразитних опорах зростають швидше, ніж ідеальний коефіцієнт підвищення напруги. У реальній схемі існує граничний максимум підвищення вихідної напруги, після якого подальше збільшення шпаруватості `D` призводить не до зростання, а до різкого падіння вихідної напруги та лавиноподібного розігріву компонентів.

## 4. Розрахунок пульсацій струмів та напруг

### Пульсація струму вхідної індуктивності L1

Протягом Фази 1 (інтервал `D · T`) до котушки `L1` прикладена постійна напруга `Vвх`. Приріст струму становить:

```
Δi_L1 = ∫ (v_L1 / L1) dt
      = (Vвх / L1) · D · T                   [інтегрування константи]
      = (Vвх · D) / (L1 · f_sw)              [вираз через частоту комутації]
```

### Пульсація струму вихідної індуктивності L2

Протягом Фази 2 (інтервал `(1 − D) · T`) до котушки `L2` прикладена напруга `|Vвих| = V_2`. Зміна струму дорівнює:

```
Δi_L2 = (|Vвих| / L2) · (1 − D) · T
      = [Vвх · D / (1 − D)] · [(1 − D) / (L2 · f_sw)] [підстановка |Vвих|]
      = (Vвх · D) / (L2 · f_sw)              [скорочення співмножника (1-D)]
```

Зверніть увагу на фундаментальну властивість: при однакових індуктивностях `L1 = L2` амплітуди пульсацій струму на вході та на виході **строго однакові** при будь-якому значенні шпаруватості `D`:

```
Δi_L1 = Δi_L2 = (Vвх · D) / (L · f_sw)
```

### Пульсація напруги на проміжному конденсаторі C1

Під час Фази 1 конденсатор `C1` розряджається вихідним струмом `I_2`. Зміна напруги на ньому:

```
Δv_C1 = (1 / C1) · ∫ i_2 dt
      = (I_2 · D · T) / C1                   [інтегрування за інтервал D·T]
      = (Iвих · D) / (C1 · f_sw)             [амплітуда пульсації напруги C1]
```

### Пульсація напруги на виході перетворювача

Оскільки вихідний конденсатор `Cвих` згладжує не прямокутні імпульси, а виключно трикутну пульсацію струму `Δi_L2`, інтеграл приросту заряду дорівнює площі трикутника струму:

```
ΔQ_вих = (1/2) · (T / 2) · (Δi_L2 / 2) = (T · Δi_L2) / 8
Δv_вих = ΔQ_вих / Cвих
       = Δi_L2 / (8 · Cвих · f_sw)
       = (Vвх · D) / (8 · L2 · Cвих · f_sw²) [підстановка виразу для Δi_L2]
```

Квадратична залежність від частоти `f_sw²` та множник `1/8` забезпечують ультранизький рівень шуму вихідної напруги.

## 5. Строгий вивід середньоквадратичного струму (RMS) конденсатора C1

Струм через конденсатор `C1` змінює знак двічі за період, маючи прямокутну форму з накладеними трикутними верхівками. Нехтуючи малими трикутними пульсаціями струмів котушок (`Δi ≪ I`), обчислимо інтеграл середньоквадратичного струму `I_C1,rms`:

Форма струму `i_C1(t)`:
- Інтервал `0 ≤ t < D · T`: `i_C1(t) = −I_2 = −Iвих`
- Інтервал `D · T ≤ t < T`: `i_C1(t) = +I_1 = +Iвх`

За означенням середньоквадратичного значення:

```
I_C1,rms² = (1 / T) · ∫ [i_C1(t)]² dt
          = (1 / T) · [ ∫ (−Iвих)² dt + ∫ (+Iвх)² dt ]
          = (1 / T) · [ Iвих² · (D · T) + Iвх² · ((1 − D) · T) ] [інтегрування]
          = D · Iвих² + (1 − D) · Iвх²               [скорочення періоду T]
```

Підставимо у вираз співвідношення `Iвх = Iвих · D / (1 − D)`:

```
I_C1,rms² = D · Iвих² + (1 − D) · [Iвих · D / (1 − D)]²
          = D · Iвих² + (1 − D) · [Iвих² · D² / (1 − D)²]
          = D · Iвих² + Iвих² · D² / (1 − D)         [скорочення (1-D)]
          = Iвих² · [D + D² / (1 − D)]               [винесення Iвих²]
          = Iвих² · [D · (1 − D) + D²] / (1 − D)     [зведення до спільного знаменника]
          = Iвих² · [D − D² + D²] / (1 − D)          [розкриття дужок]
          = Iвих² · D / (1 − D)                      [спрощення чисельника]
```

Виразимо результат через суму струмів `Iвх + Iвих`:

```
Iвх + Iвих = Iвих · D / (1 − D) + Iвих
           = Iвих · [D / (1 − D) + 1]
           = Iвих / (1 − D)                          [спрощення суми струмів]
```

Перемножимо `(Iвх + Iвих)²` на `D · (1 − D)`:

```
D · (1 − D) · (Iвх + Iвих)² = D · (1 − D) · [Iвих / (1 − D)]²
                            = D · (1 − D) · Iвих² / (1 − D)²
                            = Iвих² · D / (1 − D)
                            = I_C1,rms²              [ідентичність виразів]
```

Добуваючи квадратний корінь, отримуємо остаточну канонічну формулу діючого струму конденсатора `C1`:

```
I_C1,rms = √(D · (1 − D)) · (Iвх + Iвих)
```

Максимум навантаження на конденсатор досягається при шпаруватості `D = 0.5`, де `√(D · (1 − D)) = 0.5`, і струм становить половину від суми вхідного та вихідного струмів.

## 6. Матричний аналіз зв'язаних індуктивностей та умова нульових пульсацій

Розглянемо дві обмотки, намотані на спільному магнітопроводі.
Параметри системи:
- `L1` — власна індуктивність первинної (вхідної) обмотки з кількістю витків `N1`.
- `L2` — власна індуктивність вторинної (вихідної) обмотки з кількістю витків `N2`.
- `M` — взаємна індуктивність між обмотками.
- `k = M / √(L1 · L2)` — коефіцієнт магнітного зв'язку (`0 ≤ k < 1`).
- `n = N2 / N1 = √(L2 / L1)` — коефіцієнт трансформації витків.

Рівняння зв'язаної магнітної пари у часовій області:

```
v_1(t) = L1 · (di_1 / dt) + M · (di_2 / dt)
v_2(t) = M · (di_1 / dt) + L2 · (di_2 / dt)
```

Запишемо систему у векторно-матричній формі:

```
┌ v_1 ┐   ┌ L1   M  ┐   ┌ di_1/dt ┐
│     │ = │         │ · │         │
└ v_2 ┘   └ M    L2 ┘   └ di_2/dt ┘
```

Знайдемо матрицю, обернену до матриці індуктивностей:

```
det(L) = L1 · L2 − M² = L1 · L2 · (1 − k²)

┌ di_1/dt ┐             ┌  L2  −M  ┐   ┌ v_1 ┐
│         │ = [1/det(L)] │          │ · │     │
└ di_2/dt ┘             └ −M   L1  ┘   └ v_2 ┘
```

Розпишемо вираз для похідної струму вихідної обмотки `di_2 / dt`:

```
di_2 / dt = (L1 · v_2 − M · v_1) / [L1 · L2 · (1 − k²)]
```

Враховуючи, що напруги на обмотках синхронно формуються комутацією і пов'язані співвідношенням витків `v_2 = n · v_1`:

```
di_2 / dt = (L1 · n · v_1 − M · v_1) / [L1 · L2 · (1 − k²)]
          = v_1 · (n · L1 − M) / [L1 · L2 · (1 − k²)] [винесення v_1]
```

Підставимо у дужки `M = k · √(L1 · L2)` та `L2 = n² · L1`:

```
M = k · √(L1 · n² · L1) = k · n · L1

di_2 / dt = v_1 · (n · L1 − k · n · L1) / [L1 · L2 · (1 − k²)]
          = v_1 · n · L1 · (1 − k) / [L1 · L2 · (1 − k²)]
```

Якщо коефіцієнт витків `n` розглядається як вільна змінна проектування при фіксованому зв'язку `k` та фіксованій первинній індуктивності `L1`, вимога строгої рівності нулю чисельника дає:

```
L1 · v_2 − M · v_1 = 0  ⇒  v_2 / v_1 = M / L1
```

Оскільки прикладені напруги формуються витками `v_2 / v_1 = N2 / N1 = n`, а взаємоіндукція `M / L1 = k · √(L2/L1) = k · n`:

```
n = k · n  ⇒  приводиться до n = k
```

### Теорема про занулення пульсацій

1. **Умова нульових пульсацій вихідного струму (`di_2 / dt = 0` при будь-якому `v_1 ≠ 0`):**
```
n = k     (де n = N2 / N1, k < 1)
```
При виконанні цієї рівності чисельник похідної вихідного струму перетворюється на тотожний нуль. Пульсація струму вторинної обмотки `Δi_L2` повністю зникає, а швидкість зміни вхідного струму стає:
```
di_1 / dt = v_1 / [L1 · (1 + k)]
```
Вся пульсація без залишку переноситься у первинну обмотку `L1`.

2. **Дзеркальна умова нульових пульсацій вхідного струму (`di_1 / dt = 0`):**
```
n = 1 / k     (де n = N2 / N1 > 1)
```
У цьому випадку повністю обнуляється пульсація вхідного струму `Δi_L1 = 0`, захищаючи джерело живлення від будь-яких високочастотних струмових коливань.

## 7. Малосигнальна динаміка та передатна функція з нулем RHPZ

Для аналізу стійкості замкненої системи керування внесемо малі збурення навколо робочої точки:
```
d(t) = D + d̂(t)
x(t) = X + x̂(t)
v_вих(t) = Vвих + v̂_вих(t)
```

Лінеаризоване рівняння стану малосигнальної моделі:

```
dx̂/dt = A_avg · x̂ + [(A1 − A2) · X + (B1 − B2) · Vвх] · d̂
```

Обчислимо вектор збурення від шпаруватості `B_d = (A1 − A2) · X + (B1 − B2) · Vвх`:

```
B_d = [ V_1 / L1, −V_1 / L2, −(I_1 + I_2) / C1, 0 ]ᵀ
    = [ Vвх / (L1 · (1 − D)), −Vвх / (L2 · (1 − D)), −Iвих / (C1 · (1 − D)), 0 ]ᵀ
```

Застосувавши пряме перетворення Лапласа до системи `s · x̂(s) = A_avg · x̂(s) + B_d · d̂(s)`, отримуємо аналітичний вираз передатної функції від збурення шпаруватості до вихідної напруги `G_vd(s) = v̂_вих(s) / d̂(s)`:

```
G_vd(s) = C_out_mat · (s · I − A_avg)⁻¹ · B_d

G_vd(s) = G_0 · [ (1 − s / ω_z_rhp) · (1 + s / ω_z_esr) ] / D(s)
```

де низькочастотний коефіцієнт підсилення постійного струму:

```
G_0 = Vвх / (1 − D)²
```

Знаменник `D(s) = det(s · I − A_avg)` є характеристичним поліномом четвертого степеня, корені якого утворюють дві пари комплексно-спряжених резонансних полюсів:

```
D(s) = 1 + a1 · s + a2 · s² + a3 · s³ + a4 · s⁴

де наближені резонансні частоти контурів:
ω_p1 ≈ 1 / √(L1 · C1 · (1 − D)²)       [резонанс контуру перенесення енергії]
ω_p2 ≈ 1 / √(L2 · Cвих)                [резонанс контуру вихідного фільтра]
```

### Формула нуля у правій півплощині (RHP Zero)

Чисельник передатної функції містить нуль у правій комплексній півплощині (позитивний корінь `s = +ω_z_rhp`):

```
ω_z_rhp = [R · (1 − D)²] / (D · L1)
```

Або у герцах:

```
f_rhp = [R · (1 − D)²] / (2 · π · D · L1)
```

### Демпфування проміжного резонансу (Критерій Мідлбрука)

Внаслідок високої добротності резонансного контуру `L1 − C1 − L2` на амплітудно-фазовій частотній характеристиці виникає гострий резонансний пік із різким фазовим провалом на 180°. Якщо добротність контуру не обмежити, будь-яка замкнена петля регулювання напруги втратить стійкість і перейде в автоколивальний режим.

Для усунення резонансного піку без погіршення ККД паралельно до конденсатора `C1` підключають послідовний RC-ланцюг демпфування `R_d − C_d`. За критерієм Мідлбрука оптимальні параметри демпфуючої ланки розраховуються як:

```
C_d ≥ 4 · C1                          [ємність демпфера в 4–5 разів більша за C1]
R_d = √(L_eq / C1)                    [де L_eq = (L1 · L2) / (L1 + L2)]
```

Конденсатор `C_d` блокує протікання постійного струму через резистор `R_d`, усуваючи статичні втрати потужності, тоді як на резонансній частоті `ω_p1` резистор `R_d` вводить критичне демпфування, знижуючи добротність полюсів до безпечного значення `Q ≈ 1`.

## 8. Передатна характеристика придушення вхідних збурень (Audio Susceptibility)

Передатна функція від збурення вхідної напруги до вихідної напруги `G_vg(s) = v̂_вих(s) / v̂_вх(s)` описує здатність силової частини перетворювача пригнічувати пульсації первинного джерела живлення:

```
G_vg(s) = C_out_mat · (s · I − A_avg)⁻¹ · B_avg
```

Аналітичний вираз передатної функції має вигляд:

```
G_vg(s) = [D / (1 − D)] · [1 / D(s)] · [1 + s² · L1 · C1 / (1 − D)]
```

На низьких частотах (`s → 0`) коефіцієнт придушення дорівнює статичному коефіцієнту передачі схеми `D / (1 − D)`. На проміжних частотах чисельник містить комплексну пару нулів, які частково компенсують перший резонансний полюс, а на високих частотах вихідний LC-фільтр другого порядку забезпечує спад коефіцієнта передачі зі швидкістю `−40 дБ/дек`.

## 9. Вихідний імпеданс силової частини Z_out(s)

Вихідний імпеданс `Z_out(s) = −v̂_вих(s) / î_нав(s)` визначає величину просідання вихідної напруги при стрибкоподібній зміні струму навантаження:

```
Z_out(s) = [s · L2 + R_L2] || [1 / (s · Cвих) + R_esr] || R_reflected(s)
```

де `R_reflected(s)` — імпеданс вхідного контуру, трансформований через коефіцієнт заповнення:

```
R_reflected(s) = [s · L1 / (1 − D)²] + [1 / (s · C1 · D²)]
```

На нульовій частоті вихідний опір визначається паразитними активними опорами схеми. На частоті вихідного резонансу `ω_p2` імпеданс сягає локального максимуму `Z_max ≈ √(L2 / Cвих) · Q_out`, що вимагає належного фазового запасу в петлі зворотного зв'язку для активного придушення вихідного опору підсилювачем помилки.

## 10. Синтез частотної корекції петлі зворотного зв'язку (Type-III Compensator)

Для компенсації подвійного резонансного полюса `ω_p2` та фазового запізнення від RHP-нуля застосовують аналоговий або цифровий регулятор 3-го типу (Type-III). Його передатна функція має інтегратор у нулі, два нулі та два полюси:

```
G_c(s) = (ω_i / s) · [ (1 + s / ω_zc1) · (1 + s / ω_zc2) ] / [ (1 + s / ω_pc1) · (1 + s / ω_pc2) ]
```

Інженерна методика розміщення частот корекції:
1. **Перший нуль регулятора `ω_zc1`** розміщують трохи нижче першого резонансу: `ω_zc1 = 0.8 · ω_p1`.
2. **Другий нуль регулятора `ω_zc2`** розміщують точно на частоті вихідного резонансу: `ω_zc2 = ω_p2`. Ця пара нулів повністю компенсує фазовий зсув на −180° від реактивних контурів.
3. **Перший високочастотний полюс `ω_pc1`** компенсує нуль від еквівалентного послідовного опору вихідного конденсатора: `ω_pc1 = ω_z_esr = 1 / (R_esr · Cвих)`.
4. **Другий високочастотний полюс `ω_pc2`** розміщують на половині частоти перемикання: `ω_pc2 = π · f_sw` для ефективного придушення високочастотного комутаційного шуму.
5. **Частоту одиничного підсилення (зрізу) петлі `f_c`** обирають у діапазоні:
```
f_c ≤ f_rhp / 4
```

Такий розподіл частот забезпечує запас за фазою `φ_m ≥ 50°` та запас за підсиленням `G_m ≥ 10 дБ`, гарантуючи аперіодичний перехідний процес без перерегулювання при різких накидах струму навантаження.

## 11. Динамічні зміни при переході до зв'язаних індуктивностей

Коли котушки `L1` та `L2` намотуються на спільному осерді з коефіцієнтом зв'язку `k`, матриця стану зазнає істотної трансформації. Взаємоіндукція `M` зв'язує похідні струмів, що приводить до зміщення полюсів характеристичного полінома.

При виконанні умови занулення пульсацій `n = k` індуктивність витоку вторинної обмотки `L_lk2 = L2 · (1 − k²)` ізолює вихідний контур від високочастотних коливань проміжного контуру `L1 − C1`. 

В результаті передатна функція керування `G_vd(s)` спрощується:
- Резонансний пік вихідного фільтра `ω_p2` зсувається в область вищих частот `ω_p2,coupled = 1 / √(L_lk2 · Cвих)`.
- Ефективна добротність контуру знижується природним шляхом через розподіл втрат між магнітними витками.
- Фазовий портрет стає значно більш гладким, зменшуючи вимоги до підсилення компенсатора Type-III та розширюючи граничну смугу пропускання контуру зворотного зв'язку.

## 12. Зведена таблиця аналітичних співвідношень

Для швидкого інженерного використання зведемо ключові аналітичні формули перетворювача Ćuk:
- Статичний коефіцієнт передачі напруги: `|Vвих| / Vвх = D / (1 − D)`.
- Середня напруга на проміжному конденсаторі: `V_C1 = Vвх + |Vвих| = Vвх / (1 − D)`.
- Максимальна запірна напруга на ключах `Q1` та `D1`: `V_sw,max = Vвх + |Vвих|`.
- Діючий (RMS) струм через ємність `C1`: `I_C1,rms = √(D · (1 − D)) · (Iвх + Iвих)`.
- Пульсація струму індуктивностей (незв'язаний випадок): `Δi = (Vвх · D) / (L · f_sw)`.
- Пульсація напруги на навантаженні: `Δv_вих = Δi_L2 / (8 · Cвих · f_sw)`.
- Умова нульових пульсацій вихідного струму: `N2 / N1 = k = M / √(L1 · L2)`.
- Умова нульових пульсацій вхідного струму: `N2 / N1 = 1 / k`.
- Частота нуля у правій півплощині: `f_rhp = [R · (1 − D)²] / (2 · π · D · L1)`.
- Оптимальне демпфування резонансу: `C_d ≥ 4 · C1`, `R_d = √([(L1 · L2) / (L1 + L2)] / C1)`.
