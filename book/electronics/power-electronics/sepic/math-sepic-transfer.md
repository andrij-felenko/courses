# 🧮 Звідки в SEPIC береться D/(1−D): вольт-секунди на двох котушках

> Коефіцієнт передачі SEPIC не постулюють — його виводять, і виводять із **двох** рівнянь, бо котушок у схемі дві. Тут це зроблено з нуля: напруга на послідовному конденсаторі не береться як відома наперед, а виходить із тієї самої алгебри разом із коефіцієнтом. Слідом випадають середні струми обох котушок, діюче значення струму крізь конденсатор і поправка на падіння діода.

### Розмітка: два вузли, дві невідомі

Знаки в SEPIC плутаються легше, ніж у buck, тому спершу домовимося про назви й напрямки — далі буде сама арифметика.

Від входу йде котушка **L1** у вузол **A**. Від A на землю стоїть ключ. Від A крізь послідовний конденсатор **Cs** — у вузол **B**. Від B на землю йде котушка **L2**, а від B крізь діод — на вихід, де сидять вихідний конденсатор і навантаження.

Напруги на котушках міряємо так:

```
Vл1 = Vвх − V(A)      «+» з боку входу
Vл2 = V(B)            «+» у вузлі B, «−» на землі (нижній кінець L2 і так заземлений)
```

Струм у Cs рахуємо додатним у напрямку A → B; струм у L1 — від входу в A; струм у L2 — із землі в B (у такті «ключ розімкнено» обидва котушкові струми зіллються в діод, і саме тому такі напрямки зручні).

Невідомих дві: шукана **Vвих** і напруга на конденсаторі **Vc**. Одне рівняння двох невідомих не визначить — ось де ховається справжня причина, чому в SEPIC баланс пишуть на обидві котушки, а не на одну, як у buck чи boost.

Робочі припущення сталого режиму — три:

```
1) Vвх і Vвих за період не встигають помітно змінитися;
2) Vc теж майже стала (наприкінці перевіримо це числом);
3) струм у котушках не уривається — режим CCM.
```

Далі все спирається на **вольт-секундний баланс**: у періодичному сталому режимі середня напруга на котушці за період дорівнює нулю. Це не окремий закон, а переформульована періодичність — якби середня напруга була ненульова, струм за цикл не повертався б до себе й повз би вгору чи вниз без упину. Його двійник для конденсатора — баланс заряду: середній струм крізь конденсатор теж нуль. Обидва розібрано в окремій вставці про [вольт-секундний баланс](book:electronics/switching-converter/math-volt-second.md).

### Напруги на котушках у двох тактах

**Такт «ключ замкнено», тривалість D·T.** Ключ садить вузол A на землю, тож V(A) = 0. Конденсатор своєю напругою тягне вузол B нижче нуля:

```
V(A) = 0
Vл1 = Vвх − 0 = +Vвх
V(B) = V(A) − Vc = −Vc
Vл2 = −Vc
```

Діод у цей час замкнений: його анод сидить на −Vc, катод — на додатному виході, тобто зміщення зворотне. Це узгоджено з припущенням і потім ще раз підтвердиться числом.

**Такт «ключ розімкнено», тривалість (1−D)·T.** Діод відкрився, вузол B піднявся до виходу, а вузол A — на Vc вище за нього:

```
V(B) = Vвих
Vл2 = +Vвих
V(A) = V(B) + Vc = Vвих + Vc
Vл1 = Vвх − Vвих − Vc
```

Зверніть увагу, що `Vл1` у другому такті поки що виглядає незграбно — у ньому сидить невідома Vc. Саме її й треба спершу здобути.

### Два баланси — два рівняння

Напруга на кожній котушці в межах такту стала, тож інтеграл за період — це просто сума двох прямокутних площ: напруга помножена на тривалість такту.

**Баланс на L2** — рівняння, у якому Vвих і Vc стоять самі, без домішок:

```
(−Vc)·D·T + (+Vвих)·(1−D)·T = 0
```

Скорочуємо T і виражаємо Vc:

```
Vc·D = Vвих·(1−D)

Vc = Vвих·(1−D) / D
```

**Баланс на L1:**

```
(+Vвх)·D·T + (Vвх − Vвих − Vc)·(1−D)·T = 0
```

Скоротимо T і розкриємо дужки. Доданки з Vвх складаються в один, бо `D + (1−D) = 1`:

```
Vвх·D + Vвх·(1−D) − (Vвих + Vc)·(1−D) = 0

Vвх = (Vвих + Vc)·(1−D)
```

Тепер підставляємо Vc із першого рівняння. Дужка згортається дуже охайно:

```
Vвих + Vc = Vвих + Vвих·(1−D)/D = Vвих·[D + (1−D)] / D = Vвих / D
```

Звідки одразу:

```
Vвх = Vвих·(1−D) / D
```

і шуканий коефіцієнт:

```
Vвих / Vвх = D / (1 − D)
```

А тепер безкоштовний подарунок: підставивши цей результат назад у вираз для Vc, дістаємо

```
Vc = Vвих·(1−D)/D = Vвх
```

Тобто **напруга на послідовному конденсаторі дорівнює вхідній** — і це не припущення, з якого починали, а висновок, до якого прийшли. Різниця принципова: за конденсатором тепер стоїть виведене число, а не віра.

### Коротший шлях до Vc — і чому це не хитрість

Є спосіб дістати `Vc = Vвх` в один рядок, узагалі не розписуючи такти. Середня напруга на котушці — нуль, отже середній потенціал вузла A відрізняється від Vвх рівно на цей нуль, а середній потенціал вузла B — на нуль від землі:

```
⟨V(A)⟩ = Vвх − ⟨Vл1⟩ = Vвх
⟨V(B)⟩ = ⟨Vл2⟩ = 0

⟨Vc⟩ = ⟨V(A)⟩ − ⟨V(B)⟩ = Vвх
```

Це та сама фізика, тільки взята в іншому порядку: коротка версія відповідає на питання «скільки на Cs», довга — «чому саме стільки, і що з цього випливає для виходу». Коли Vc уже відома, лишається одне рівняння з однією невідомою — баланс на L1 (або на L2, байдуже) — і коефіцієнт випадає за два рядки.

Але коротка версія має ще одну, значно кориснішу властивість: вона **не залежить від того, що ще стоїть у контурі**. Середня напруга на котушці нульова хоч із ідеальним ключем, хоч із падінням на діоді, хоч із опором доріжок — бо це властивість самої котушки в сталому режимі. Тому `Vc = Vвх` виживе й тоді, коли ми додамо реальні падіння; цим скористаємося трохи згодом.

Підставивши тепер `Vc = Vвх` у напруги двох тактів, дістанемо остаточну картину:

```
такт «замкнено»:   Vл1 = +Vвх     Vл2 = −Vвх
такт «розімкнено»: Vл1 = −Vвих    Vл2 = +Vвих
```

![Дві панелі: напруга на L1 і напруга на L2 протягом одного періоду. На кожній панелі додатний прямокутник за такт D·T і від'ємний за такт (1−D)·T мають однакову площу. Панелі дзеркальні одна одній.](/book/electronics/power-electronics/sepic/img/vs-balance.svg)

*Обидві котушки за такт «замкнено» набирають рівно стільки вольт-секунд, скільки віддають за такт «розімкнено» — звідси й `Vвх·D = Vвих·(1−D)`. Панелі — дзеркальні: напруги рівні за величиною й протилежні за знаком щомиті.*

### Чому обидва баланси дають одне рівняння

Погляньте на ці чотири напруги ще раз: `Vл2 = −Vл1` у кожну мить. Тому баланс на L2 — це баланс на L1, помножений на −1, і як рівняння він нової інформації не несе. Здається, ніби другу котушку рахували даремно.

Це не так, і різниця тонка: **до** того, як знайдено Vc, рівняння різні — в одному сидить Vc з мінусом, у другому з плюсом, і саме їхня пара розплутує дві невідомі. **Після** підстановки вони збігаються. Тобто друге рівняння не зайве — воно витрачене рівно на те, щоб визначити Vc, і після цього справді стає перевіркою.

У рівності `|Vл1| = |Vл2|` ховається практичний наслідок. Швидкість зміни струму в котушці — це напруга, поділена на індуктивність, тож обидві котушки в такті «замкнено» розганяють струм із однаковим нахилом (якщо L1 = L2) і в такті «розімкнено» гальмують теж однаково:

```
ΔI1 = Vвх·D·T / L1
ΔI2 = Vвх·D·T / L2
```

Однакова напруга щомиті — це саме та умова, за якої дві обмотки можна намотати на [одне осердя](book:electronics/coupled-inductor): дві котушки на спільному осерді працюють узгоджено лише тоді, коли прикладені до них напруги збігаються, інакше взаємоіндукція боролася б із власною індуктивністю замість допомагати. Для двох однакових обмоток із коефіцієнтом зв'язку k взаємна індуктивність M = k·L, і оскільки обидві обмотки міняють струм однаково, кожна бачить `L + M`:

```
V = L·(di/dt) + M·(di/dt) = L·(1 + k)·(di/dt)

ΔI = V·D·T / [L·(1 + k)]
```

За щільного зв'язку (k ≈ 1) пульсація в кожній обмотці вдвічі менша, ніж дали б дві окремі котушки тієї самої індуктивності — це не бонус конструкції корпусу, а прямий наслідок рівності напруг.

### Геометрія коефіцієнта

Функцію `M(D) = D/(1−D)` варто побачити, а не лише прочитати. Вона проходить через нуль при D = 0, через одиницю при D = 0.5 і летить у нескінченність, коли D наближається до одиниці. Обернути її теж просто:

```
D = M / (1 + M)   ⇔   D = Vвих / (Vвих + Vвх)
```

Ця форма зручніша для розрахунку: заповнення шукають прямо з двох напруг, без ділення на `1−D`.

![Крива Vвих/Vвх = D/(1−D) від D = 0 до D = 0.8. Крива перетинає одиницю при D = 0.5; позначено вікно однієї банки Li-ion D = 0.44…0.52 та значення нахилу 1/(1−D)² у трьох точках.](/book/electronics/power-electronics/sepic/img/transfer-curve.svg)

*Ліворуч від D = 0.5 схема знижує, праворуч — підвищує, і перехід не має жодної особливої точки: крива гладка, контролер просто проходить її наскрізь.*

Похідна показує, наскільки нерівномірно розподілена «влада» заповнення над виходом:

```
dM/dD = 1 / (1 − D)²

D = 0.50 →  4
D = 0.75 →  16
D = 0.90 →  100
```

Біля D = 0.5 зсув заповнення на 0.01 міняє вихід на 4 % від Vвх — цілком керовано. Біля D = 0.9 той самий зсув на 0.01 додає до виходу **цілий Vвх**. Ось чому SEPIC із великим підвищенням важко тримати: сам об'єкт керування стає в десятки разів чутливішим, тоді як запас за фазою нікуди не збільшується. До цього ще додається [нуль правої півплощини](book:electronics/rhp-zero) — властивість топологій із проміжним накопичувачем, коли перша реакція виходу на збільшення заповнення протилежна бажаній, і його частота теж падає з ростом D. Тому смугу петлі в таких режимах змушено звужують.

### Струмовий бік: що дає баланс заряду

Тепер повторимо той самий фокус для конденсаторів. Крізь Cs у такті «замкнено» тече струм L2 (конденсатор розряджається в неї, тобто в напрямку B → A, з нашим знаком це «мінус»), а в такті «розімкнено» — струм L1, який іншого шляху з вузла A просто не має:

```
такт «замкнено»:   iCs = −i2
такт «розімкнено»: iCs = +i1
```

Середній струм крізь конденсатор — нуль, інакше його напруга повзла б:

```
(−I2)·D + I1·(1−D) = 0

I1 / I2 = D / (1 − D)
```

Друге рівняння дає вихідний конденсатор: увесь заряд, що доходить до виходу, приносить діод, і в середньому це струм навантаження. Діод проводить лише в такті «розімкнено», і несе тоді суму обох котушкових струмів:

```
(I1 + I2)·(1−D) = Iвих
```

Підставляємо `I1 = I2·D/(1−D)` — і сума знову згортається:

```
(I2·D/(1−D) + I2)·(1−D) = I2·D + I2·(1−D) = I2 = Iвих
```

Два несподівано чистих результати:

```
I2 = Iвих                       середній струм L2 дорівнює струму навантаження
I1 = Iвих · D/(1−D) = Iвх       середній струм L1 — це вхідний струм
```

І одразу перевірка на здоровий глузд. Оскільки `D/(1−D) = Vвих/Vвх`, маємо `Iвх/Iвих = Vвих/Vвх`, тобто

```
Vвх·Iвх = Vвих·Iвих
```

Ідеальна модель без втрат зберігає потужність — і цього не було закладено в жодне з рівнянь, воно вийшло само з двох балансів заряду. Коли виведення повертає закон збереження, якого йому не давали, — це найнадійніша перевірка, що ніде не переплутано напрямків.

### Діюче значення струму крізь Cs

Тепер видно, чому Cs — найгарячіша точка схеми. Знехтуємо пульсацією (вона мала проти середніх): струм крізь конденсатор — це прямокутник, що стрибає між `−Iвих` протягом D·T і `+Iвх` протягом (1−D)·T. Діюче значення такої форми — корінь із середнього квадрата, а середній квадрат прямокутної форми — це сума квадратів, зважених часткою часу ([детальніше про форми струму](book:electronics/rms-current)):

```
I²rms = D·Iвих² + (1−D)·Iвх²
```

Підставляємо `Iвх = Iвих·D/(1−D)`:

```
I²rms = D·Iвих² + (1−D)·Iвих²·D²/(1−D)²
      = Iвих²·[ D + D²/(1−D) ]
      = Iвих²·D·[ (1−D) + D ] / (1−D)
      = Iвих²·D/(1−D)
```

Корінь дає напрочуд гарний вираз — той самий коефіцієнт передачі, тільки під коренем:

```
Irms(Cs) = Iвих·√( D/(1−D) ) = Iвих·√( Vвих/Vвх )
```

При D = 0.5 це рівно струм навантаження. У режимі підвищення — більше за нього, у режимі зниження — менше, а росте воно лише як корінь, тож навіть при подвоєнні напруги множник усього ≈ 1.41.

> 🔧 **Навіщо це.** Це число — головний критерій вибору Cs. Керамічний конденсатор із такою пульсацією гріється на власному еквівалентному послідовному опорі втратами `I²rms · ESR`, і саме вони, а не ємність, зазвичай визначають, скільки корпусів доведеться поставити паралельно. Ємність тут відповідає за іншу річ — за просідання `ΔVc = Iвих·D·T/Cs`, тобто за те, наскільки чесним було припущення «Vc стала». Обидва числа треба порахувати, і майже завжди першим програє саме пульсаційний струм; про добір конденсаторів у перетворювачах є [окрема стаття](book:electronics/converter-caps).

### Поправка на реальні падіння

Ідеальна модель не знає ні про падіння на діоді, ні про опір відкритого ключа. Додати їх коштує кількох рядків — і тут вигідно скористатися тим, що `Vc = Vвх` не залежить від вмісту контуру.

Нехай на відкритому ключі падає Vкл (це `I·Rds(on)`), а на діоді — Vf. Тоді у такті «замкнено» вузол A сидить не на нулі, а на Vкл; у такті «розімкнено» вузол B піднімається не до Vвих, а до Vвих + Vf. Баланс на L2:

```
(Vкл − Vc)·D + (Vвих + Vf)·(1−D) = 0

Vc = Vкл + (Vвих + Vf)·(1−D)/D
```

Але Vc = Vвх — це ми вже знаємо задарма. Прирівнюємо:

```
Vвх − Vкл = (Vвих + Vf)·(1−D)/D
```

і дістаємо робочу формулу заповнення:

```
  D / (1 − D) = (Vвих + Vf) / (Vвх − Vкл)

  D = (Vвих + Vf) / (Vвх − Vкл + Vвих + Vf)
```

Ідеальний випадок — окремий випадок цього виразу при Vf = 0 і Vкл = 0. Поправка не косметична: [діод Шотткі](book:electronics/schottky-diode) з падінням 0.35 В на шині 3.3 В — це понад десята частина вихідної напруги, і заповнення зсувається на кілька відсоткових пунктів.

### Числа: 3.3 В з однієї банки Li-ion

Візьмімо конкретну схему й проженімо крізь неї всі здобуті вирази. Вхід 3.0…4.2 В, вихід 3.3 В при 1 А, частота 500 кГц (період T = 2 мкс), дві окремі котушки по 10 мкГ, Cs = 10 мкФ, діод Шотткі Vf = 0.35 В, ключ із падінням Vкл = 0.1 В.

**Заповнення на краях діапазону:**

```
повна банка (Vвх = 4.2 В):
   D = 3.65 / (4.2 − 0.1 + 3.65) = 3.65 / 7.75 = 0.471     (ідеально було б 0.440)

порожня банка (Vвх = 3.0 В):
   D = 3.65 / (3.0 − 0.1 + 3.65) = 3.65 / 6.55 = 0.557     (ідеально було б 0.524)
```

Падіння зсунули обидва значення вгору приблизно на 0.03 — і, що показово, точка «вихід дорівнює входу» тепер припадає вже не на D = 0.5, а трохи правіше.

**Струми у найважчій точці (порожня банка, D = 0.557):**

```
D/(1−D) = 0.557/0.443 = 1.259

I2 = Iвих = 1.000 А
I1 = Iвх  = 1.259 А

Pвх  = 3.0 · 1.259 = 3.776 Вт
Pвих = 3.3 · 1.0   = 3.300 Вт
ККД  = 3.300 / 3.776 = 87.4 %
```

Куди пішла різниця 0.476 Вт — можна порахувати окремо й звірити. Діод у середньому несе струм навантаження, ключ — суму котушкових струмів протягом частки D періоду:

```
діод: Vf·Iвих            = 0.35 · 1.0                = 0.350 Вт
ключ: Vкл·(I1 + I2)·D   = 0.1 · 2.259 · 0.557       = 0.126 Вт
                                              разом  = 0.476 Вт  ✓
```

Сходиться до третього знака — формула заповнення й баланс потужностей узгоджені між собою. (Це, звісно, лише провідні втрати; [втрати перемикання](book:electronics/switching-losses) сюди не входять і на такій частоті додадуть свою частку.)

**Пульсація й пік струму ключа.** У такті «замкнено» на кожній котушці стоїть `Vвх − Vкл = 2.9 В`:

```
ΔI = 2.9 · 0.557 · 2·10⁻⁶ / 10·10⁻⁶ = 0.323 А   (на кожній котушці)

пік ключа = I1 + I2 + (ΔI1 + ΔI2)/2 = 1.259 + 1.000 + 0.323 = 2.58 А
```

Тобто ключ, що віддає в навантаження 1 А, мусить витримувати пік 2.6 А — характерна плата за топологію, у якій ключ несе суму обох котушкових струмів, а не один із них.

**Конденсатор Cs:**

```
Irms = 1.0 · √1.259 = 1.12 А
ΔVc  = Iвих·D·T/Cs = 1.0 · 0.557 · 2·10⁻⁶ / 10·10⁻⁶ = 0.111 В
```

Ось і обіцяна перевірка припущення: просідання 0.111 В на тлі Vc = 3.0 В — це 3.7 %, тож наближення «Vc стала» чесне, і виведений коефіцієнт має право на життя. Якби вийшло 30 %, усю алгебру довелося б переписувати з урахуванням коливань Vc.

### Де це виведення перестає діяти

Кожен рядок вище спирався на те, що обидва такти — це рівно два такти, тобто струм у котушках не уривається. Ця умова має межу.

Особливість SEPIC у тому, що переривається не струм окремої котушки, а **сума**: діод замикається лише тоді, коли на нуль виходить `i1 + i2`. Окремо взятий струм L1 у SEPIC цілком може заходити в мінус, поки сума лишається додатною, — на відміну від buck чи boost, де межа режимів проходить по єдиному котушковому струму.

Середнє значення суми легко порахувати з уже здобутих струмів, а її розмах — це сума розмахів:

```
⟨i1 + i2⟩ = I1 + I2 = Iвих/(1−D)

Δ(i1 + i2) = ΔI1 + ΔI2 = Vвх·D·T·(1/L1 + 1/L2) = Vвх·D·T / Le,   Le = L1 ∥ L2
```

Межа настає, коли дно цієї суми торкається нуля:

```
Iвих/(1−D) = Δ(i1+i2)/2

Iвих,гран = D·(1−D)·Vвх·T / (2·Le)
```

Для нашої схеми (Le = 10 ∥ 10 = 5 мкГ, а замість Vвх — те саме реальне 2.9 В на котушках):

```
Iвих,гран = 0.557 · 0.443 · 2.9 · 2·10⁻⁶ / (2 · 5·10⁻⁶) = 0.143 А
```

Нижче ≈ 0.14 А схема провалюється в переривчастий режим, з'являється третій такт, і коефіцієнт `D/(1−D)` уже не тримається — він стає залежним від навантаження ([про межу режимів окремо](book:electronics/ccm-dcm-boundary)).

Друга межа стосується не сталого режиму, а руху. Усе виведене вище — усереднені величини, воно нічого не каже про те, як схема реагує на зміни. А там дві котушки з двома конденсаторами утворюють систему четвертого порядку зі слабко задемпфованим резонансом Cs із котушками:

```
fрез = 1 / (2π·√((L1 + L2)·Cs)) = 1 / (2π·√(20·10⁻⁶ · 10·10⁻⁶)) ≈ 11.3 кГц
```

Цей резонанс не видно в жодному з наших рівнянь — і саме він, а не статичний коефіцієнт, зазвичай визначає, наскільки швидким можна зробити регулятор. Це вже територія [малосигнальної моделі](book:electronics/small-signal-converter), де усереднений перетворювач перетворюють на передавальну функцію.
