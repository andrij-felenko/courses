# Топології резонансної компенсації: SS, SP, PS, PP та LCC

Бездротова передача енергії через слабко зв'язані котушки вимагає включення конденсаторів як на боці передавача (TX), так і на боці приймача (RX), щоб скомпенсувати великі індуктивності розсіяння. Проте спосіб підключення цих ємностей — послідовно (Series, S) чи паралельно (Parallel, P) до обмоток — кардинально змінює поведінку всієї системи. Від вибору топології залежить, чи зсуватиметься резонансна частота під час руху приймача, як поведеться перетворювач при раптовому знятті навантаження (холостий хід) та чи зможуть ключі інвертора зберігати м'яку комутацію при нулі напруги (ZVS). Цей аналіз порівнює чотири базові двохелементні схеми (SS, SP, PS, PP) та багатоелементну топологію LCC для вибору оптимального інженерного рішення.

## Базові схеми: класифікація за двома літерами

Усі базові схеми компенсації позначаються двома літерами: перша вказує спосіб підключення конденсатора `C₁` у первинному колі (передавач), друга — конденсатора `C₂` у вторинному колі (приймач).

1. **SS (Series-Series)**: первинний конденсатор `C₁` послідовно з котушкою `L₁`, вторинний конденсатор `C₂` послідовно з котушкою `L₂`.
2. **SP (Series-Parallel)**: первинний `C₁` послідовно з `L₁`, вторинний `C₂` паралельно до `L₂`.
3. **PS (Parallel-Series)**: первинний `C₁` паралельно до `L₁`, вторинний `C₂` послідовно з `L₂`.
4. **PP (Parallel-Parallel)**: первинний `C₁` паралельно до `L₁`, вторинний `C₂` паралельно до `L₂`.

## Топологія SS (Series-Series)

Топологія SS є найпоширенішою у малопотужних споживчих пристроях (зокрема, вона стандартизована у WPC Qi для потужностей 5–15 Вт).

### Розрахунок резонансних параметрів

Вторинний контур має власну резонансну частоту:

```
ω₀ = 1 / √(L₂ · C₂)
```

На цій частоті реактивний опір вторинного кола дорівнює нулю, а його повний імпеданс складається лише з активного опору дроту `R₂` та опору навантаження `R_нав`:

```
Z₂ = R₂ + R_нав
```

Відбитий у первинний контур імпеданс:

```
Z_відб = (ωM)² / Z₂ = (ωM)² / (R₂ + R_нав)
```

Оскільки `Z_відб` є суто **активним** (його уявна частина дорівнює нулю), він не вносить жодної додаткової реактивності в первинне коло. Тому первинний компенсаційний конденсатор `C₁` розраховується виключно за власною індуктивністю `L₁`:

```
C₁ = 1 / (ω₀² · L₁)
```

### Ключові властивості SS

- **Незалежність ємностей від коефіцієнта зв'язку `k`**: значення `C₁` та `C₂` залежать лише від власних індуктивностей `L₁` та `L₂`. Навіть якщо користувач зсуває телефон по зарядній панелі (змінюючи `k` від 0.1 до 0.4), резонансна частота обох контурів залишається незмінною.
- **Характеристика джерела струму**: вихідний струм вторинного кола `I₂` на резонансній частоті прямо пропорційний первинній напрузі `U₁` і не залежить від опору навантаження `R_нав`:
  ```
  I₂ = U₁ / (ω₀ · M)
  ```
  Це ідеально підходить для зарядки акумуляторів у режимі стабілізації струму (Constant Current, CC).
- **Небезпека холостого ходу**: якщо вторинний пристрій раптово прибрати (`M → 0` або `R_нав → ∞`), відбитий опір `Z_відб → 0`. У первинному колі залишається лише малий власний опір мідного дроту `R₁` (частки ома). Якщо інвертор продовжить подавати напругу на частоті `ω₀`, у первинній котушці виникне струм короткого замикання `I₁ = U₁ / R₁`, що спричинить тепловий пробій MOSFET. Для запобігання аварії контролер передавача Qi постійно контролює наявність зв'язку та вимикає генерацію за відсутності пакетів даних.

## Топологія SP (Series-Parallel)

У топології SP вторинний конденсатор `C₂` вмикається паралельно до котушки `L₂` та навантаження `R_нав`.

### Розрахунок резонансних параметрів

Еквівалентний імпеданс вторинного кола на паралельному резонансі `ω₀ = 1 / √(L₂C₂)` для випадку `R_нав ≫ ωL₂` наближено дорівнює:

```
Z₂_eq = (ω₀L₂)² / (R_нав + R₂) − j · ω₀L₂
```

Відбитий у первинний контур імпеданс отримує як активну, так і **ємнісну** реактивну складову:

```
Z_відб = (ωM)² / Z₂_eq = R_відб + j · X_відб
X_відб = −j · ω · (k² · L₁)
```

Внесена ємнісна реактивність зменшує еквівалентну індуктивність первинного кола до `L₁·(1 − k²)`. Щоб скомпенсувати первинне коло в резонанс, номінал конденсатора `C₁` повинен враховувати коефіцієнт зв'язку `k`:

```
C₁ = 1 / (ω₀² · L₁ · (1 − k²))
```

### Ключові властивості SP

- **Залежність від відстані**: оскільки `C₁` залежить від `k`, зміна положення приймача або відстані між котушками розстроює первинний резонанс. ККД різко падає при зміщенні осей.
- **Характеристика джерела напруги**: на резонансній частоті вихідна напруга `U₂` майже не залежить від струму навантаження:
  ```
  U₂ = U₁ · (L₂ / M)
  ```
- **Безпечний холостий хід**: при відсутності навантаження (`R_нав → ∞`) відбитий імпеданс у первинному колі прямує до великого значення, запобігаючи струмовому перевантаженню інвертора.

## Топології PS та PP (Паралельний вхід)

Паралельне включення первинного конденсатора `C₁` кардинально змінює вимоги до вхідного джерела живлення.

Паралельний LC-контур на резонансній частоті має високий вхідний імпеданс і мінімальний вхідний струм. Проте для живлення паралельного контуру потрібне джерело **стабільного струму**, а не напруги. Якщо підключити паралельний LC-контур безпосередньо до виходу звичайного H-моста напруги, комутація ключів призведе до миттєвого перезаряду ємності `C₁` від шини живлення з величезними піковими струмами (`I = C · du/dt`), що спричинить катастрофічне руйнування транзисторів.

Тому в схемах PS та PP між випрямлячем мережі та інвертором обов'язково встановлюють великий згладжувальний дросель постійного струму (струмовий інвертор або схему з автотрансформаторним живленням). Через габарити та втрати в додатковому дроселі схеми PS і PP не застосовуються у малогабаритній споживчій електроніці, але зустрічаються у потужних індукційних печах та спеціалізованих безконтактних конвеєрах.

## Багатоелементна топологія LCC (LCC-LCC / LCC-S)

Для передачі великих потужностей (від сотень ват до десятків кіловат у зарядних станціях для електромобілів) базових двох елементів недостатньо: важко одночасно забезпечити роботу без розстроювання при зміщенні та надійний режим комутації при нулі напруги (ZVS) транзисторів у всьому діапазоні навантажень від 0 до 100%.

Топологія LCC додає до кожної котушки додатковий індуктор `L_f` та паралельний конденсатор `C_p`, формуючи Т-подібний резонансний фільтр:
- Послідовний індуктор `L_f1` на виході H-моста.
- Паралельний конденсатор `C_p1`.
- Послідовний конденсатор `C_s1` увімкнений безпосередньо з основною котушкою `L₁`.

### Умови симетричного резонансу LCC

Параметри обираються так, щоб контур `L_f1 − C_p1` резонував на робочій частоті `ω₀`:

```
ω₀ = 1 / √(L_f1 · C_p1)
```

А послідовна гілка компенсувала різницю індуктивностей:

```
ω₀ = 1 / √((L₁ − L_f1) · C_s1)
```

### Переваги топології LCC

1. **Постійний струм котушки TX**: струм у котушці передавача `I₁ = U_вх / (ω₀ · L_f1)` повністю не залежить від опору навантаження `R_нав` та коефіцієнта зв'язку `k`. Це стабілізує випромінюване магнітне поле незалежно від режиму роботи приймача.
2. **Гарантований ZVS без зсуву фаз**: вхідний імпеданс бака LCC залишається злегка індуктивним у всьому робочому діапазоні навантажень, що дозволяє польовим транзисторам інвертора перемикатися при нулі напруги без комутаційних втрат.
3. **Зниження напруги на реактивних елементах**: напруга на компенсаційних конденсаторах ділиться між `C_p` та `C_s`, що дозволяє використовувати конденсатори на меншу робочу напругу.
4. **Висока толерантність до геометричного зміщення**: при радіальному зміщенні котушок одна відносно одної ККД спадає значно повільніше, ніж у схемах SS та SP.

## Вибір конденсаторів та реактивна потужність

У резонансних контурах WPT напруга на конденсаторі `U_C` та реактивна потужність `Q_C` у десятки разів перевищують активну потужність навантаження:

```
U_C = Q · U_вх
Q_C = I_конт² / (ω · C)
```

При потужності передачі 15 Вт струм у котушці передавача досягає `3–5 А (RMS)`, а напруга на послідовному конденсаторі `C₁ ≈ 160 нФ` на частоті 125 кГц сягає:

```
U_C1 = I₁ / (ω · C₁) = 4.0 / (785398 · 160·10⁻⁹) ≈ 31.8 В (RMS) ≈ 45 В (пік)
```

У потужних системах на кіловати напруга на конденсаторах перевищує `1–2 кВ`. Тому до конденсаторів ставляться жорсткі вимоги:
- **Тип діелектрика**: категорично заборонено використовувати стандартні керамічні конденсатори класів X7R/X5R через сильний п'єзоелектричний ефект, залежність ємності від прикладеної напруги (до −70% при номіналі) та великий тангенс кута втрат `tan(δ) ≈ 0.025`, який призводить до розплавлення припою через саморозігрів.
- **Дозволені матеріали**: високочастотна термокомпенсована кераміка **C0G / NP0** (з `tan(δ) < 0.0005`) для плат малої потужності або багатошарові плівкові поліпропіленові конденсатори (**MKP / Metallized Polypropylene**) з наднизьким еквівалентним послідовним опором (ESR) для систем середньої та високої потужності.

## Практичні критерії вибору топології

1. **Для споживчої електроніки малої та середньої потужності (до 15–30 Вт)** стандартом є **SS**: мінімальна кількість пасивних компонентів, незалежність резонансної частоти від взаємного розташування котушок та зручність живлення від стандартного низьковольтного H-моста.
2. **Для високопотужних промислових систем та бездротової зарядки електротранспорту (понад 1 кВт)** обирають **LCC**: вищі початкові витрати на додаткові індуктори окупаються стабільністю ZVS-комутації, високим ККД (`>92–96%`) та стійкістю до значних геометричних зміщень приймача щодо зарядної плити.
