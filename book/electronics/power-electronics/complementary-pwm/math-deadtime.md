# 🧮 Математичний аналіз мертвого часу: втрати, оптимізація та гармонічні спотворення

У силових перетворювачах і трифазних інверторах тривалість мертвого часу безпосередньо визначає межу між електричним пробоєм ключів і деградацією енергетичної ефективності системи. Цей математичний аналіз встановлює аналітичні залежності для розрахунку мінімального безпечного мертвого часу, кількісної оцінки потужності втрат на внутрішніх діодах, виведення спектрального складу гармонічних спотворень вихідної напруги та розрахунку вектора похибки у просторово-векторній модуляції.

---

### 1. Фізико-математична модель мінімального безпечного часу вимкнення

Нижня межа тривалості мертвого часу `t_dead_min` формується сумою фізичних затримок розповсюдження сигналу в схемі керування та часу розсмоктування заряду затвора силового транзистора.

```
t_dead_min = t_d(off)_max + t_f_max + Δt_prop_max + t_margin
```

де:
- `t_d(off)_max` — максимальний паспортний час затримки вимкнення транзистора (час від спаду керувального імпульсу на вході драйвера до початку спаду напруги `V_gs`);
- `t_f_max` — час спаду струму стоку (тривалість перехідного процесу розряду ємності Міллера);
- `Δt_prop_max` — максимальна асиметрія (skew) затримок розповсюдження між верхнім і нижнім каналами драйвера затвора (`Δt_prop = |t_prop_H - t_prop_L|`);
- `t_margin` — інженерний запас надійності (зазвичай 20–30% або абсолютні 20–100 нс) для врахування температурного дрейфу опору драйвера й параметрів кристала.

Час розряду ємності затвора під час проходження активної зони (плато Міллера) описується виразом:

```
I_discharge(t) = V_plateau / (R_gate_int + R_gate_ext + R_driver_sink)
```

Тривалість спаду напруги на стоці `t_f` визначається зарядом затвор-стік `Q_gd`:

```
t_f = Q_gd / I_discharge
```

Підставивши вираз для струму розряду, отримуємо аналітичну залежність часу спаду від параметрів кола затвора:

```
t_f = Q_gd · (R_gate_int + R_gate_ext + R_driver_sink) / V_plateau
```

**Worked-приклад розрахунку t_dead_min для Si-MOSFET:**

Вихідні параметри стійки на польових транзисторах:
- Заряд затвор-стік: `Q_gd = 28 нКл`;
- Напруга плато Міллера: `V_plateau = 4.8 В`;
- Внутрішній опір затвора: `R_gate_int = 1.2 Ом`;
- Зовнішній резистор розряду затвора: `R_gate_ext = 4.7 Ом`;
- Опір відкритого n-канального ключа драйвера (sink): `R_driver_sink = 1.5 Ом`;
- Паспортна затримка вимкнення: `t_d(off)_max = 35 нс`;
- Максимальна розбіжність затримок драйвера: `Δt_prop_max = 12 нс`;
- Коефіцієнт запасу надійності: `k_margin = 1.35`.

Розрахунок покроково:

```
R_total_off = R_gate_int + R_gate_ext + R_driver_sink  [сумарний опір кола розряду затвора]
            = 1.2 + 4.7 + 1.5                         [підстановка значень опорів]
            = 7.4 Ом                                  [результат обчислення]

I_discharge = V_plateau / R_total_off                 [закон Ома для струму розряду на плато Міллера]
            = 4.8 / 7.4                               [підстановка напруги плато та опору]
            = 0.6486 А                                [середній струм розряду]

t_f         = Q_gd / I_discharge                      [тривалість викачування заряду Міллера]
            = 28·10⁻⁹ / 0.6486                        [підстановка заряду та струму]
            = 43.17·10⁻⁹ с ≈ 43.2 нс                  [час спаду струму стоку]

t_switch    = t_d(off)_max + t_f + Δt_prop_max        [повний час фізичного вимикання з асиметрією]
            = 35 + 43.2 + 12                          [сума затримки, спаду та перекосу драйвера]
            = 90.2 нс                                 [найгірший час вимикання]

t_dead_min  = t_switch · k_margin                     [врахування коефіцієнта запасу надійності]
            = 90.2 · 1.35                             [множення на коефіцієнт 1.35]
            = 121.77 нс ≈ 125 нс                      [остаточний мінімальний мертвий час]
```

Отримане значення `t_dead = 125 нс` є строгою нижньою межею, нижче якої виникає прямий наскрізний струм короткого замикання.

### 2. Енергетичний баланс втрат у силовому напівмості

Загальна розсіювана потужність втрат у стійці транзисторів `P_total` складається з втрат провідності відкритих каналів `P_cond_ch`, втрат комутації `P_sw`, втрат провідності внутрішніх body-діодів у моменти мертвого часу `P_dead_diode` та втрат зворотного відновлення діода `P_rr`:

```
P_total = P_cond_ch + P_sw + P_dead_diode + P_rr      [баланс потужності втрат напівмоста]
```

#### Втрати провідності через канал MOSFET

Під час активної провідності верхнього або нижнього ключа струм навантаження тече через низькоомний опір відкритого каналу `R_ds(on)`. З урахуванням того, що сумарна частка мертвого часу за період становить `2 · t_dead / T_sw`, час активної провідності каналів скорочується:

```
P_cond_ch = I_rms² · R_ds(on) · (1 - 2 · f_sw · t_dead)  [втрати у відкритому каналі з урахуванням пауз]
```

де `f_sw = 1 / T_sw` — частота комутації ШІМ.

#### Втрати провідності внутрішнього body-діода під час мертвого часу

Протягом інтервалів `t_dead1` та `t_dead2` обидва транзистори закриті. Неперервний струм дроселя або обмотки двигуна змушений замикатися через антипаралельний body-діод відповідного ключа. Падіння напруги на p-n переході діода дорівнює `V_F` (зазвичай 0.8–1.2 В для Si-MOSFET).

Енергія, що перетворюється на тепло в діоді за один період ШІМ:

```
E_dead_diode = V_F · I_avg_dead · (t_dead1 + t_dead2)    [інтеграл потужності за два інтервали мертвого часу]
```

Якщо `t_dead1 = t_dead2 = t_dead`:

```
P_dead_diode = 2 · f_sw · t_dead · V_F · I_load          [середня потужність розсіювання на body-діоді]
```

#### Втрати зворотного відновлення (Reverse Recovery)

Коли body-діод закінчує проводити струм у кінці мертвого часу і протилежний транзистор відкривається, накопичений у базі діода заряд неосновних носіїв `Q_rr` має бути розсмоктаний під дією повної напруги шини живлення `V_bus`.

```
P_rr = f_sw · Q_rr · V_bus                            [комутаційні втрати розсмоктування заряду відновлення]
```

Заряд `Q_rr` зростає пропорційно тривалості провідності діода `t_dead` та температурі кристала `T_j`:

```
Q_rr(t_dead) ≈ Q_rr_0 · (1 + α · t_dead)              [лінійна апроксимація накопичення заряду від часу провідності]
```

#### Пошук оптимального мертвого часу

Сумарні додаткові втрати, зумовлені наявністю мертвого часу:

```
P_dead_loss(t_dead) = 2 · f_sw · t_dead · (V_F · I_load - I_rms² · R_ds(on)) + f_sw · Q_rr(t_dead) · V_bus
```

Оскільки `V_F · I_load` зазвичай перевищує `I_rms² · R_ds(on)` у 10–25 разів, функція `P_dead_loss(t_dead)` є монотонно зростаючою від `t_dead`. Це математично доводить, що **оптимальний мертвий час `t_dead_opt` завжди дорівнює мінімально можливому безпечному значенню `t_dead_min`**:

```
t_dead_opt = t_dead_min                               [умова мінімізації сумарних втрат перетворювача]
```

Будь-яке перевищення `t_dead` понад `t_dead_min` призводить до лінійного зростання паразитного нагріву за законом:

```
dP_dead / dt_dead = 2 · f_sw · V_F · I_load + f_sw · V_bus · (dQ_rr / dt_dead)  [градієнт зростання теплових втрат]
```

**Worked-приклад розрахунку втрат від завеликого мертвого часу:**

Порівняємо перетворювач Synchronous Buck із параметрами:
- Напруга живлення: `V_bus = 48 В`;
- Струм навантаження: `I_load = 20 А`;
- Частота ШІМ: `f_sw = 200 кГц` (`T_sw = 5000 нс`);
- Опір каналу MOSFET: `R_ds(on) = 4 мОм`;
- Пряме падіння на діоді: `V_F = 0.9 В`;
- Заряд відновлення: `Q_rr = 45 нКл`.

Порівняємо два випадки:
1. Оптимальний розрахований мертвий час: `t_dead = 80 нс`;
2. Недбало обраний «запасний» мертвий час: `t_dead = 500 нс`.

Розрахунок втрат на body-діоді для `t_dead = 80 нс`:

```
P_diode_opt = 2 · f_sw · t_dead · V_F · I_load         [формула потужності діодних втрат]
            = 2 · 200·10³ · 80·10⁻⁹ · 0.9 · 20         [підстановка частоти 200 кГц та часу 80 нс]
            = 0.576 Вт                                 [потужність втрат при оптимальній паузі]
```

Розрахунок втрат на body-діоді для `t_dead = 500 нс`:

```
P_diode_sub = 2 · f_sw · t_dead · V_F · I_load         [формула потужності діодних втрат]
            = 2 · 200·10³ · 500·10⁻⁹ · 0.9 · 20        [підстановка завищеного мертвого часу 500 нс]
            = 3.600 Вт                                 [потужність втрат при завищеній паузі]
```

Різниця втрат:

```
ΔP = P_diode_sub - P_diode_opt                         [різниця потужностей тепловиділення]
   = 3.600 - 0.576                                     [віднімання оптимальних втрат від завищених]
   = 3.024 Вт                                          [додаткова паразитна потужність нагріву]
```

Зайві 3 Вт тепла на один транзистор за габаритів корпусу QFN 5x6 мм піднімають температуру кристала на 120 °C (при тепловому опорі радіатора `R_th_ja = 40 °C/Вт`), що призводить до теплового руйнування компонента виключно через програмну помилку налаштування таймера.

### 3. Вольт-секундна похибка та гармонічний спектр інвертора

В автономних інверторах напруги (трифазний міст для двигунів PMSM/BLDC або однофазний інвертор сонячних панелей) комутація мертвого часу спотворює вихідну фазну напругу.

#### Миттєва похибка напруги

Напруга середнього вузла півмоста `V_SW` під час мертвого часу визначається виключно напрямком струму фази `I_ph`:

```
V_SW_dead = -V_F ≈ 0 В                 [при I_ph > 0, струм витікає з півмоста]
V_SW_dead = V_bus + V_F ≈ V_bus        [при I_ph < 0, струм втікає в півміст]
```

Ідеальна середня напруга за період ШІМ без урахування мертвого часу:

```
V_ideal = d · V_bus
```

де `d` — бажаний коефіцієнт заповнення (`0 ≤ d ≤ 1`).

Реальна середня напруга `V_real` з урахуванням втрати або додавання вольт-секундної площі:

```
V_real = d · V_bus - sign(I_ph) · V_bus · (t_dead / T_sw)
```

Таким чином, функція похибки напруги `ΔV` має вигляд знакозмінної нелінійної сходинки:

```
ΔV(t) = - sign(I_ph(t)) · V_bus · f_sw · t_dead
```

#### Ряд Фур'є для напруги похибки

Оскільки струм навантаження інвертора є гармонічним з основною частотою `ω = 2π · f_out`:

```
I_ph(t) = I_peak · sin(ωt - φ)
```

Функція `sign(I_ph(t))` є періодичним прямокутним меандром із частотою вихідного сигналу `f_out`. Розкладемо її в тригонометричний ряд Фур'є:

```
sign(sin(ωt - φ)) = (4 / π) · ∑ [ sin((2k - 1)·(ωt - φ)) / (2k - 1) ]    для k від 1 до ∞
```

Підставивши розклад у вираз для похибки напруги `ΔV(t)`, отримуємо спектральний склад збурень:

```
ΔV(t) = - (4 / π) · V_bus · f_sw · t_dead · [ sin(ωt - φ) + (1/3)·sin(3(ωt - φ)) + (1/5)·sin(5(ωt - φ)) + (1/7)·sin(7(ωt - φ)) + ... ]
```

#### Аналіз гармонік у трифазній системі

У трифазній трипровідній системі без нейтралі гармоніки, кратні трьом (3-тя, 9-та, 15-та), є синфазними (нульова послідовність) і взаємно знищуються в лінійній напрузі `V_AB = V_A - V_B`:

```
V_line_harmonics = ∑ (5-та, 7-ма, 11-та, 13-та, 17-та, 19-та ...)
```

Амплітуда фундаментальної складової похибки напруги:

```
ΔV_fund = (4 / π) · V_bus · f_sw · t_dead
```

Амплітуди паразитної 5-ї та 7-ї гармонік:

```
V_5 = (1 / 5) · ΔV_fund = (4 / (5π)) · V_bus · f_sw · t_dead
V_7 = (1 / 7) · ΔV_fund = (4 / (7π)) · V_bus · f_sw · t_dead
```

П'ята гармоніка напруги створює в статорі двигуна магнітне поле, що обертається **проти** напрямку обертання ротора, а сьома — поле, що обертається **за** напрямком із семикратною швидкістю. Взаємодія цих полів із постійним полем ротора породжує **пульсації крутного моменту на 6-й гармоніці**:

```
f_torque_ripple = 6 · f_out
```

Коефіцієнт гармонічних спотворень напруги (THD) від мертвого часу становить:

```
THD_dead ≈ (ΔV_fund / V_fundamental) · √( ∑ [ 1 / (2k - 1)² ] )
```

Звідси випливає важливий закон електроприводу: **відносне спотворення напруги від мертвого часу різко зростає при роботі на низьких швидкостях (низьких вихідних напругах `V_fundamental → 0`)**, що призводить до нестабільності позиціонування ротора, вібрацій та акустичного шуму двигуна.

### 4. Вплив мертвого часу на просторово-векторну ШІМ (SVPWM)

У трифазному інверторі вектор напруги статора `V_s` формується в нерухомій системі координат `α-β` за допомогою перемикання восьми базових просторових векторів (шести активних `V_1..V_6` та двох нульових `V_0, V_7`). Мертвий час спотворює положення та амплітуду усередненого вектора напруги залежно від того, в якому з шести секторів струму знаходиться вектор фазних струмів.

Вектор похибки напруги `ΔV_s` в системі координат `α-β` визначається матричним перетворенням Кларк від фазних похибок:

```
ΔV_α = (2 / 3) · (ΔV_A - 0.5 · ΔV_B - 0.5 · ΔV_C)
ΔV_β = (2 / 3) · (√3 / 2) · (ΔV_B - ΔV_C)
```

Розглянемо перший сектор струму, де фазний струм `I_A > 0`, а `I_B < 0` та `I_C < 0` (діапазон кута струму від `-π/6` до `+π/6`):

```
ΔV_A = - ΔV_dead
ΔV_B = + ΔV_dead
ΔV_C = + ΔV_dead
```

Підставивши ці значення в перетворення Кларк, отримуємо просторовий вектор похибки:

```
ΔV_α = (2 / 3) · (-ΔV_dead - 0.5·ΔV_dead - 0.5·ΔV_dead)  [підстановка фазних похибок у перетворення Кларк]
     = (2 / 3) · (-2·ΔV_dead)                             [зведення подібних доданків]
     = - (4 / 3) · ΔV_dead                                [результат для осі альфа]

ΔV_β = (2 / 3) · (√3 / 2) · (ΔV_dead - ΔV_dead)          [різниця похибок фаз B та C]
     = 0                                                  [взаємне скорочення на осі бета]
```

У першому секторі вектор похибки спрямований строго протилежно до осі `α` (на 180° відносно струму фази A). При обертанні вектора струму годограф вектора похибки напруги `ΔV_s` описує замкнений правильний шестикутник у площині `α-β`.

При переході в обертову систему координат `d-q` (орієнтовану за вектором потокозчеплення ротора) цей шестикутник трансформується у постійне зміщення напруги по поздовжній та поперечній осях із накладеними пульсаціями на 6-й гармоніці:

```
ΔV_d = - (4 / π) · ΔV_dead · cos(θ_v - θ_i)
ΔV_q = - (4 / π) · ΔV_dead · sin(θ_v - θ_i)
```

де `θ_v` — миттєвий кут вектора напруги, а `θ_i` — кут вектора струму.

Ця похибка діє як сильне періодичне збурення на входах пропорційно-інтегральних (PI) регуляторів струму `I_d` та `I_q`, викликаючи перехресний зв'язок між каналами та паразитні пульсації електромагнітного моменту `T_e`:

```
T_e = 1.5 · p · [ λ_pm · I_q + (L_d - L_q) · I_d · I_q ]
```

де `p` — кількість пар полюсів, а `λ_pm` — магнітний потік постійних магнітів ротора.

### 5. Динамічний тепловий опір та розрахунок температури кристала

Оскільки імпульс втрат у body-діоді триває лише короткий час `t_dead` (наприклад, 100 нс), пікова потужність `P_peak = V_F · I_load` може сягати десятків або сотень ватів. Для перевірки надійності кристала недостатньо знати лише середню температуру — необхідно розрахувати миттєву пікову температуру переходу `T_j_peak` за допомогою динамічного теплового імпедансу `Z_th_jc(t)`.

Динамічний тепловий опір транзистора на коротких інтервалах описується сумою експоненціальних ланок моделі Фостера або Кауера:

```
Z_th_jc(t) = ∑ [ R_i · (1 - exp(- t / τ_i)) ]    для i від 1 до N
```

де `R_i` та `τ_i = R_i · C_i` — теплові опори та сталі часу окремих шарів кремнію, припою та мідної підкладки корпусу.

На малих часових інтервалах (`t < 1 мкс`) тепло не встигає вийти за межі кремнієвого кристала, і тепловий імпеданс зростає пропорційно квадратному кореню з часу:

```
Z_th_jc(t) ≈ K_th · √t
```

де `K_th` — конструктивний коефіцієнт теплової дифузії кремнію.

Миттєвий стрибок температури напівпровідникового переходу під час мертвого часу:

```
ΔT_j_pulse = P_dead_peak · Z_th_jc(t_dead)
```

Абсолютна пікова температура переходу під час комутації:

```
T_j_peak = T_case + P_total_avg · R_th_jc + ΔT_j_pulse
```

Якщо `T_j_peak` перевищує критичну межу 150–175 °C навіть на 10 нс, кремній втрачає запиральні властивості через генерацію власних термоносіїв, що призводить до негайного теплового пробою кристала.

### 6. Зведена таблиця аналітичних залежностей

| Параметр / Ефект | Розрахункова формула | Залежність від факторів |
| :--- | :--- | :--- |
| **Мінімальний мертвий час** | `t_dead_min = (t_d_off + t_f + Δt_prop) · k_margin` | Зростає з опором драйвера `R_gate` та зарядом `Q_gd` |
| **Втрати на body-діоді** | `P_dead = 2 · f_sw · t_dead · V_F · I_load` | Пропорційні частоті ШІМ, струму та `t_dead` |
| **Втрати зворотного відновлення** | `P_rr = f_sw · Q_rr(t_dead) · V_bus` | Зростають із тривалістю провідності діода |
| **Вольт-секундна похибка** | `ΔV = - sign(I_ph) · V_bus · f_sw · t_dead` | Стрибок при проходженні струму через 0 А |
| **Основна складова похибки** | `ΔV_1 = (4 / π) · V_bus · f_sw · t_dead` | Знижує вихідну напругу під навантаженням |
| **Паразитні 5-та і 7-ма гармоніки** | `V_5 = ΔV_1 / 5`, `V_7 = ΔV_1 / 7` | Створюють 6-кратні пульсації моменту двигуна |
| **Похибка вектора SVPWM** | `ΔV_αβ = - (4 / 3) · ΔV_dead` (для 1-го сектора) | Утворює шестикутний годограф похибки напруги |
| **Піковий нагрів кристала** | `ΔT_j_pulse = V_F · I_load · Z_th_jc(t_dead)` | Визначається тепловою дифузією кремнію за час паузи |

Ці математичні моделі є теоретичною основою для реалізації алгоритмів динамічної компенсації мертвого часу в цифрових сигнальних контролерах.
