# 🧮 Математична теорія балансу сталих часу та частотний аналіз DCR-фільтра

Для прецизійного керування та захисту сучасного імпульсного стабілізатора напруги контролер повинен мати миттєвий і точний сигнал струму дроселя `i_L(t)`. Пряме вимірювання напруги на силових виводах котушки не дає інформації про струм, оскільки слабкий омічний спад маскується потужною комутаційною ЕРС самоіндукції. Математична суть методу DCR-сенсингу полягає у синтезі аналогового фільтра, передатна функція якого формує операторний нуль, що строго скорочує операторний полюс реальної індуктивності в області перетворення Лапласа.

### 1. Операторна модель реальної котушки індуктивності

Будь-яка реальна силова котушка індуктивності в лінійному наближенні моделюється як послідовне з'єднання ідеальної індуктивності `L` та активного омічного опору мідного дроту обмотки `DCR`.

Комплексний імпеданс котушки в операторній формі Лапласа (де `s = σ + j·ω` — комплексна частота) має вигляд:

```
Z_L(s) = s·L + DCR
       = DCR · (1 + s · (L / DCR))   [винесення DCR за дужки]
```

Введемо власну електромагнітну постійну часу дроселя `τ_L`:

```
τ_L = L / DCR
```

Тоді операторний імпеданс записується у факторизованій формі з виділенням нуля передатної функції:

```
Z_L(s) = DCR · (1 + s·τ_L)
```

Відповідно до закону Ома в операторній формі, падіння напруги на котушці `V_L(s)` при протіканні струму `I_L(s)` становить:

```
V_L(s) = I_L(s) · Z_L(s)
       = I_L(s) · DCR · (1 + s·τ_L)   [підстановка Z_L(s)]
```

У часовій області цей вираз відповідає диференціальному рівнянню першого порядку:

```
v_L(t) = DCR · i_L(t) + L · (d i_L(t) / dt)
```

Перший доданок `DCR · i_L(t)` являє собою корисний сигнал, прямо пропорційний миттєвому струму. Другий доданок `L · (d i_L(t) / dt)` — це комутаційна реактивна ЕРС, амплітуда якої в імпульсному перетворювачі сягає десятків вольтів і повністю спотворює вимірювання.

### 2. Передатна функція вимірювального RC-ланцюга

Для виділення омічної складової паралельно котушці підключається пасивний інтегруючий RC-ланцюг першого порядку, що складається з резистора `R_s` та конденсатора `C_s`.

Напруга на вимірювальному конденсаторі `V_C(s)` визначається формулою частотно-залежного дільника напруги:

```
V_C(s) = V_L(s) · [ (1 / (s·C_s)) / (R_s + 1 / (s·C_s)) ]
       = V_L(s) · [ 1 / (1 + s·R_s·C_s) ]                  [множення чисельника й знаменника на s·C_s]
```

Введемо власну сталу часу вимірювального RC-фільтра `τ_RC`:

```
τ_RC = R_s · C_s
```

Передатна характеристика фільтра набуває канонічного вигляду аперіодичної ланки першого порядку:

```
H_RC(s) = V_C(s) / V_L(s)
        = 1 / (1 + s·τ_RC)   [визначення H_RC через постійну часу]
```

Цей ланцюг має єдиний полюс на комплексній площині в точці `s_p = −1 / τ_RC`.

### 3. Умова компенсації нулів і полюсів (Zero-Pole Cancellation)

Підставимо вираз напруги на котушці `V_L(s)` у формулу для напруги на конденсаторі `V_C(s)`:

```
V_C(s) = I_L(s) · DCR · (1 + s·τ_L) · [ 1 / (1 + s·τ_RC) ]
       = I_L(s) · DCR · [ (1 + s·τ_L) / (1 + s·τ_RC) ]      [алгебраїчне об'єднання співмножників]
```

Визначимо передатний сенсорний імпеданс `Z_sense(s)` як відношення вихідної напруги сенсора до вимірюваного струму котушки:

```
Z_sense(s) = V_C(s) / I_L(s)
           = DCR · [ (1 + s·τ_L) / (1 + s·τ_RC) ]   [визначення сенсорного імпедансу]
```

Аналіз виразу показує, що передатна функція містить нуль у точці `s_z = −1 / τ_L` та полюс у точці `s_p = −1 / τ_RC`.

Якщо забезпечити рівність сталих часу котушки та фільтра:

```
τ_L = τ_RC  ⇔  L / DCR = R_s · C_s
```

то чисельник і знаменник дробу стають тотожно рівними для будь-якого значення комплексної частоти `s`:

```
(1 + s·τ_L) / (1 + s·τ_RC) = 1   [за умови τ_L = τ_RC]
```

Сенсорний імпеданс вироджується в чисто дійсний частотно-незалежний опір:

```
Z_sense(s) = DCR = const
```

Переходячи в часову область через зворотне перетворення Лапласа, отримуємо точний зв'язок:

```
v_C(t) = DCR · i_L(t)
```

Це співвідношення виконується **для довільної форми струму** (постійного, синусоїдального, трикутного пилкоподібного чи стрибкоподібного). Напруга на конденсаторі є точним дзеркальним масштабованим відображенням струму котушки без запізнення фази та амплітудних спотворень.

### 4. Динамічний відгук на стрибок струму та аналіз розбалансу

Дослідимо поведінку вимірювального кола при миттєвому ступінчастому збільшенні струму навантаження на величину `ΔI` з нульовими початковими умовами:

```
i_L(t) = ΔI · u(t)   ⇒   I_L(s) = ΔI / s
```

де `u(t)` — одинична функція Гевісайда.

Підставимо `I_L(s)` у вираз для напруги `V_C(s)`:

```
V_C(s) = DCR · ΔI · [ (1 + s·τ_L) / (s · (1 + s·τ_RC)) ]
```

Розкладемо дріб на суму простих дробів методом невизначених коефіцієнтів:

```
(1 + s·τ_L) / [ s · (1 + s·τ_RC) ] = A / s + B / (1 + s·τ_RC)   [розклад на прості дроби]
```

Зведемо до спільного знаменника:

```
1 + s·τ_L = A · (1 + s·τ_RC) + B · s
          = A + s · (A·τ_RC + B)       [групування за степенями s]
```

Прирівнюючи коефіцієнти при однакових степенях `s`:
1. При `s⁰`: `A = 1`.
2. При `s¹`: `τ_L = A·τ_RC + B  ⇒  B = τ_L − τ_RC`.

Підставимо знайдені коефіцієнти:

```
V_C(s) = DCR · ΔI · [ 1 / s + (τ_L − τ_RC) / (1 + s·τ_RC) ]
       = DCR · ΔI · [ 1 / s + (τ_L / τ_RC − 1) · (τ_RC / (1 + s·τ_RC)) ]     [винесення τ_RC]
       = DCR · ΔI · [ 1 / s + (τ_L / τ_RC − 1) · (1 / (s + 1 / τ_RC)) ]       [ділення на τ_RC]
```

Застосуємо зворотне перетворення Лапласа `ℒ⁻¹`:

```
v_C(t) = DCR · ΔI · [ 1 + (τ_L / τ_RC − 1) · exp(−t / τ_RC) ] · u(t)
```

Розглянемо три фізичні режими:

#### Режим 1: Ідеальний баланс (`τ_RC = τ_L`)

При точному узгодженні `τ_L / τ_RC = 1`, експоненційний доданок повністю зануляється:

```
τ_L / τ_RC − 1 = 0
v_C(t) = DCR · ΔI · u(t)   [чиста сходинка без викиду та завалу]
```

Напруга на конденсаторі миттєво повторює сходинку струму.

#### Режим 2: Недофільтрація (`τ_RC < τ_L`)

Якщо стала часу фільтра менша за сталу часу дроселя, експоненційний коефіцієнт стає додатним: `τ_L / τ_RC − 1 > 0`.

У початковий момент часу після комутації `t = 0⁺`:

```
v_C(0⁺) = DCR · ΔI · (τ_L / τ_RC) > DCR · ΔI   [стрибок напруги вище стаціонарного рівня]
```

Напруга зазнає динамічного стрибка, що у `τ_L / τ_RC` разів перевищує реальне стале значення. Після цього сигнал експоненційно спадає до стаціонарного рівня з постійною часу `τ_RC`.

Цей диференційний сплеск хибно детектується компаратором як аварійне перевантаження (OCP), провокуючи передчасне вимикання фази, або спричиняє надмірний динамічний провал вихідної напруги в контурах адаптивного позиціонування напруги (AVP).

#### Режим 3: Перефільтрація (`τ_RC > τ_L`)

Якщо стала часу фільтра більша за сталу часу котушки, коефіцієнт стає від'ємним: `τ_L / τ_RC − 1 < 0`.

У момент часу `t = 0⁺`:

```
v_C(0⁺) = DCR · ΔI · (τ_L / τ_RC) < DCR · ΔI   [занижений початковий відгук]
```

Початковий рівень напруги занижений, і сигнал повільно підтягується до номіналу за аперіодичним законом. Контролер не встигає відстежувати швидкі кидки струму навантаження, через що контур регулювання напруги втрачає динамічну швидкодію та зазнає тривалого коливального відновлення.

### 5. Відгук на струм зі скінченною швидкістю наростання (Ramp Response)

У реальних перетворювачах струм дроселя не може змінитися миттєво (за нескінченно малий час) через обмеження швидкості наростання `di/dt = (V_in − V_out) / L`.

Розглянемо лінійне наростання струму протягом інтервалу часу `t_r`:

```
i_L(t) = ΔI · (t / t_r)   [при 0 ≤ t ≤ t_r]
```

Операторне зображення лінійного наростання струму:

```
I_L(s) = (ΔI / t_r) · (1 / s²)
```

Підставивши у вираз для `V_C(s)` та застосувавши зворотне перетворення Лапласа, отримуємо напругу на конденсаторі під час наростання:

```
v_C(t) = DCR · (ΔI / t_r) · [ t + (τ_L − τ_RC) · (1 − exp(−t / τ_RC)) ]
```

Аналіз цього рівняння демонструє:
- При `τ_L = τ_RC` напруга строго лінійно зростає: `v_C(t) = DCR · ΔI · (t / t_r)`.
- При `τ_RC < τ_L` напруга випереджає струм, створюючи динамічну похибку амплітуди `Δv = DCR · (ΔI / t_r) · (τ_L − τ_RC)`.
- Якщо час наростання струму набагато довший за сталу часу фільтра (`t_r ≫ τ_RC`), експоненційний сплеск згладжується, і пікова похибка розбалансу виявляється менш руйнівною, ніж при чистому сходинковому наближенні.

### 6. Гармонійний аналіз періодичного пилкоподібного струму ШІМ (Fourier Series)

У стаціонарному режимі роботи понижувального перетворювача струм котушки являє собою періодичну пилкоподібну функцію часу з періодом `T_sw = 2·π / ω_sw`:

```
i_L(t) = I_DC + ∑ [ I_n · cos(n·ω_sw·t + θ_n) ]
```

де `I_DC` — постійний середній струм навантаження, а `I_n` — амплітуди гармонійних складових частоти комутації.

Застосуємо принцип суперпозиції для лінійного кола: напруга на вимірювальному конденсаторі дорівнює сумі відгуків на кожну гармоніку окремо:

```
v_C(t) = I_DC · Z_sense(0) + ∑ [ I_n · |Z_sense(n·ω_sw)| · cos(n·ω_sw·t + θ_n + φ(n·ω_sw)) ]
```

Оскільки при виконанні умови узгодження `τ_RC = τ_L`:
1. Модуль імпедансу дорівнює константі для всіх частот: `|Z_sense(n·ω_sw)| = DCR = const`.
2. Фазовий зсув тотожно дорівнює нулю: `φ(n·ω_sw) = 0°`.

Отримуємо:

```
v_C(t) = DCR · I_DC + DCR · ∑ [ I_n · cos(n·ω_sw·t + θ_n) ]
       = DCR · i_L(t)
```

Це доводить, що жодна гармонійна складова струму комутації не зазнає фазового запізнення або амплітудного спотворення. Форма напруги на конденсаторі є абсолютно точним зменшеним двійником форми струму дроселя.

### 7. Оцінка навантажувального впливу вимірювального RC-ланцюга

Перевіримо, чи не вносить вимірювальний RC-ланцюг помітного шунтуючого навантаження на силовий тракт.

Вхідний імпеданс паралельного вимірювального ланцюга:

```
Z_in_RC(s) = R_s + 1 / (s·C_s)
```

При типових значеннях `R_s = 4.7 кОм` та `C_s = 0.1 мкФ` модуль вхідного імпедансу на постійному струмі прямує до нескінченності, а на частоті комутації 600 кГц становить:

```
|Z_in_RC(600 кГц)| = √[ (4700)² + (1 / (2·π · 600·10³ · 0.1·10⁻⁶))² ]
                    = √[ 2.209·10⁷ + (2.65)² ] ≈ 4700 Ом
```

Оскільки опір силового дроселя на цій частоті становить `|Z_L| ≈ 2·π·f·L ≈ 0.56 Ом`, співвідношення імпедансів:

```
|Z_in_RC| / |Z_L| = 4700 / 0.56 ≈ 8390
```

Струм, що відгалужується у вимірювальний фільтр, становить менше 0.012 % від струму дроселя, а потужність, розсіювана на резисторі `R_s`, не перевищує кількох мікроватів. Таким чином, зворотний вплив вимірювального ланцюга на силовий каскад є абсолютно нехтовним.

### 8. Модель у просторі станів (State-Space Formulation)

Для системного аналізу контуру керування запишемо диференціальні рівняння системи у матричній формі простору станів:

Оберемо вектор змінних стану `x(t)` та вхідну дію `u(t)`:

```
x(t) = [ i_L(t),  v_C(t) ]ᵀ
u(t) = v_SW(t) − v_out(t)
```

Застосовуючи закони Кірхгофа для силового та вимірювального контурів:
1. `L · (d i_L / dt) + DCR · i_L = u(t)`
2. `R_s · C_s · (d v_C / dt) + v_C = v_L(t) = u(t)`

Отримуємо матричне диференціальне рівняння стану:

```
d x(t) / dt = A · x(t) + B · u(t)
```

де матриця стану `A` та матриця входу `B` мають вигляд:

```
A = [ −DCR / L        0        ]
    [  0         −1 / (R_s·C_s) ]

B = [ 1 / L            ]
    [ 1 / (R_s · C_s)  ]
```

Власні числа матриці стану `λ_1 = −DCR / L = −1 / τ_L` та `λ_2 = −1 / (R_s · C_s) = −1 / τ_RC` визначають полюси системи. Умова балансу `λ_1 = λ_2` означає злиття власних чисел, що усуває внутрішній динамічний розрив між вимірювальним та силовим трактом.

### 9. Дискретна z-модель та алгоритмічна рекурсія для цифрового керування

У цифрових контролерах з фіксованим періодом дискретизації `T_s` аналоговий фільтр DCR може бути математично відображений у дискретну z-область за допомогою білінійного перетворення Тастіна (Tustin Transform):

```
s = (2 / T_s) · [ (z − 1) / (z + 1) ]
```

Підставивши вираз білінійного перетворення у передатну функцію фільтра `H_RC(s) = 1 / (1 + s·τ_RC)`:

```
H_RC(z) = [ 1 + z⁻¹ ] / [ (1 + 2·τ_RC / T_s) + (1 − 2·τ_RC / T_s) · z⁻¹ ]
```

Ввівши нормовані цифрові коефіцієнти, отримуємо різницеве рівняння першого порядку для обчислення напруги на конденсаторі в цифровому сигнальному процесорі (DSP):

```
v_C[k] = a_1 · v_C[k−1] + b_0 · v_L[k] + b_1 · v_L[k−1]
```

де коефіцієнти розраховуються один раз при ініціалізації контролера:
- `b_0 = b_1 = T_s / (2·τ_RC + T_s)`
- `a_1 = (2·τ_RC − T_s) / (2·τ_RC + T_s)`

Така дискретна модель дозволяє в цифрових системах керування реалізовувати віртуальний DCR-сенсор (Sensorless Current Estimator), повністю емулюючи фізичний RC-фільтр у коді мікроконтролера.

### 10. Стійкість внутрішнього контуру струмового керування (Current-Mode Stability)

У системах керування за піковим струмом (Peak Current Mode Control — PCMC) виміряний сигнал `v_C(t)` безпосередньо порівнюється з вихідним сигналом підсилювача помилки напруги для формування моменту вимикання силового ключа.

Якщо умова балансу порушена (`τ_RC ≠ τ_L`), нахил відновленого сигналу струму `S_n = d v_C / dt` під час відкритого стану верхнього ключа зазнає спотворення:

```
S_n = (DCR / τ_RC) · [ (V_in − V_out) / DCR − (v_C / DCR) ]
```

При недофільтрації (`τ_RC < τ_L`) спостережуваний нахил струму `S_n` виявляється крутішим за реальний. Це штучно знижує ефективний коефіцієнт підсилення контуру струму, але водночас робить перетворювач вразливим до субгармонійних коливань на коефіцієнтах заповнення `D > 0.5`. Для відновлення запасу стійкості за фазою контролер вимагає введення штучного пилкоподібного компенсуючого сигналу (Slope Compensation Ramp `S_e`).

При перефільтрації (`τ_RC > τ_L`) нахил струму згладжується, що збільшує фазове запізнення всередині замкненого контуру струму і може призвести до автоколивань на частоті одиничного підсилення контуру напруги.

### 11. Асиметричний подвійний RC-ланцюг з дільником (Dual-Tap DCR Filter)

У деяких конструкціях VRM амплітуда сигналу `DCR · i_L(t)` перевищує динамічний діапазон вхідного АЦП або вимагає зміщення робочої точки. Для цього застосовують асиметричний дільник із двох резисторів `R_s1`, `R_s2` та конденсатора `C_s`:

```
V_C(s) = V_L(s) · [ R_s2 / (R_s1 + R_s2) ] · [ 1 / (1 + s · (R_s1 ∥ R_s2) · C_s) ]
```

Умова балансу для такої конфігурації модифікується з урахуванням паралельного опору резистивного дільника:

```
(R_s1 · R_s2) / (R_s1 + R_s2) · C_s = L / DCR
```

Коефіцієнт ділення сигналу постійного струму при цьому становить `K_div = R_s2 / (R_s1 + R_s2)`, що дозволяє гнучко масштабувати напругу сенсора під опорні рівні компаратора захисту без порушення компенсації нуля і полюса.

### 12. Частотний аналіз та логарифмічні характеристики Боде

Дослідимо поведінку сенсорного імпедансу у гармонічній частотній області, підставивши `s = j·ω`:

```
Z_sense(j·ω) = DCR · [ (1 + j·ω·τ_L) / (1 + j·ω·τ_RC) ]
```

Амплітудно-частотна характеристика (АЧХ) визначається модулем комплексного імпедансу:

```
|Z_sense(ω)| = DCR · √[ (1 + ω²·τ_L²) / (1 + ω²·τ_RC²) ]
```

Фазо-частотна характеристика (ФЧХ) описується різницею аргументів чисельника та знаменника:

```
φ(ω) = arctan(ω·τ_L) − arctan(ω·τ_RC)
```

Проаналізуємо асимптотичну поведінку схеми у трьох характерних частотних областях:

1. **Низькочастотна область (`ω ≪ 1/τ_L` та `ω ≪ 1/τ_RC`):**
   ```
   |Z_sense(ω)| ≈ DCR   [при ω→0 реактивні складові прямують до 0]
   φ(ω) ≈ 0°
   ```
   На низьких частотах конденсатор `C_s` еквівалентний розриву кола, тому сигнал формується виключно падінням напруги на омічному опорі обмотки.

2. **Високочастотна область (`ω ≫ 1/τ_L` та `ω ≫ 1/τ_RC`):**
   ```
   |Z_sense(ω)| ≈ DCR · (ω·τ_L) / (ω·τ_RC)     [асимптотика при ω ≫ 1/τ]
                = DCR · (L / DCR) / (R_s · C_s) [підстановка τ_L = L/DCR та τ_RC = R_s·C_s]
                = L / (R_s · C_s)               [скорочення спільного множника DCR]
   φ(ω) ≈ 90° − 90° = 0°
   ```
   На високих частотах вимірювана напруга повністю визначається відношенням індуктивності `L` до параметрів сенсорного фільтра `R_s · C_s`.

3. **Область ідеального балансу (`τ_RC = τ_L`):**
   ```
   |Z_sense(ω)| = DCR = const   [строга незалежність від частоти]
   φ(ω) = 0°                    [нульовий фазовий зсув на всіх частотах]
   ```

Якщо баланс порушено:
- При `τ_RC < τ_L` передатна характеристика демонструє високочастотний підйом з нахилом `+20 дБ/дек` в інтервалі між частотами зрізу `1/τ_L` та `1/τ_RC`, працюючи як диференціатор.
- При `τ_RC > τ_L` характеристика має спад з нахилом `−20 дБ/дек` між частотами `1/τ_RC` та `1/τ_L`, працюючи як інтегратор.

### 13. Чутливість схеми та аналіз допусків компонентів

Оцінимо параметричну чутливість сенсорного імпедансу до зміни номіналів компонентів за допомогою логарифмічних функцій чутливості Боде:

```
S_x^{Z_sense} = (∂ Z_sense / ∂ x) · (x / Z_sense)
```

Обчислимо часткову похідну від `Z_sense(s)` за опором фільтра `R_s`:

```
∂ Z_sense / ∂ R_s = DCR · (1 + s·τ_L) · [ −s·C_s / (1 + s·R_s·C_s)² ]
```

Помножимо на нормуючий множник `R_s / Z_sense`:

```
S_{R_s}^{Z_sense} = [ DCR · (1 + s·τ_L) · (−s·C_s) / (1 + s·τ_RC)² ] · [ R_s / (DCR · (1 + s·τ_L) / (1 + s·τ_RC)) ]   [підстановка формул]
                  = −(s·R_s·C_s) / (1 + s·R_s·C_s)                                                                    [скорочення спільного множника]
                  = −(s·τ_RC) / (1 + s·τ_RC)                                                                           [згортання через постійну часу]
```

Аналогічно визначимо чутливість до зміни ємності `C_s`:

```
S_{C_s}^{Z_sense} = −(s·τ_RC) / (1 + s·τ_RC)
```

Чутливість до зміни номіналу індуктивності `L`:

```
S_L^{Z_sense} = (s·τ_L) / (1 + s·τ_L)
```

Чутливість до зміни власного омічного опору `DCR`:

```
S_{DCR}^{Z_sense} = 1 / (1 + s·τ_L)
```

Отримані співвідношення розкривають критичні особливості точності DCR-сенсингу:
- На постійному струмі та низьких частотах (`s → 0`):
  ```
  |S_{R_s}| → 0,   |S_{C_s}| → 0,   |S_L| → 0,   |S_{DCR}| → 1
  ```
  Похибка вимірювання середнього струму навантаження повністю визначається точністю DCR і абсолютно не залежить від точності номіналів `R_s`, `C_s` та `L`.
- На частоті комутації ШІМ (`s ≈ j·ω_sw`, де `ω_sw · τ ≫ 1`):
  ```
  |S_{R_s}| → 1,   |S_{C_s}| → 1,   |S_L| → 1,   |S_{DCR}| → 0
  ```
  Похибка відтворення амплітуди пульсацій струму прямо пропорційна відхиленню номіналів `C_s`, `R_s` та `L`. Похибка конденсатора на 10 % спотворює виміряний розмах пульсацій рівно на 10 %.

### 14. Високочастотні ефекти: скін-ефект, ефект близькості та паразитна ємність

У реальних умовах на частотах комутації від 300 кГц до 2 МГц омічний опір та індуктивність дроселя стають функціями частоти та струму.

Високочастотний опір обмотки зростає через витіснення струму до поверхні провідника (скін-ефект) та вихрові струми від сусідніх витків (ефект близькості):

```
DCR_AC(f) = DCR_DC · [ 1 + F_skin(f) + F_prox(f) ]
```

Товщина скін-шару в мідному провіднику визначається виразом:

```
δ = √(ρ_Cu / (π · μ_0 · f)) ≈ 66 / √f   [мм, де f у Гц]
```

На частоті 500 кГц товщина скін-шару становить `δ ≈ 93 мкм`. Для мінімізації зростання `DCR_AC` обмотки силових дроселів виготовляють із плоскої мідної шини або багатожильного літцендрату.

Крім того, котушка має власну розподілену міжевиткову ємність `C_par`, яка визначає частоту власного резонансу (Self-Resonance Frequency — SRF):

```
f_SRF = 1 / [ 2·π · √(L · C_par) ]
```

На частотах вище `f_SRF` (типово 30–80 МГц) імпеданс котушки набуває ємнісного характеру, пропускаючи надвисокочастотні гармоніки комутації SW безпосередньо у вихідний тракт. Пасивний RC-фільтр з частотою зрізу `1 / (2·π·R_s·C_s) ≈ 300–500 Гц` надійно придушує ці паразитні сплески, захищаючи вхідний підсилювач контролера від перевантаження.
