Коли імпульсний стабілізатор живить сучасний багатоядерний процесор, графічний прискорювач або спеціалізований обчислювальний кристал (ASIC), вихідна напруга живлення опускається до рівня 0.75–1.1 В, тоді як сумарний споживаний струм сягає 100–400 А. Якщо для контролю струму в розрив силової шини встановити навіть прецизійний калібрований резистор номіналом 1 мОм, при постійному струмі 100 А закон Джоуля-Ленца зумовлює розсіювання 10 Вт теплової потужності на одному мініатюрному компоненті. Оскільки вся корисна потужність навантаження при напрузі 1.0 В становить 100 Вт, один лише вимірювальний резистор миттєво знищує 10 % коефіцієнта корисної дії перетворювача, перетворюючи друковану плату на локальний обігрівач із температурою понад 150 °C.

Спроба зменшити опір шунта до 0.1 мОм знижує розсіюване тепло до 1 Вт, однак породжує не менш гостру проблему: при малому навантаженні в 1 А корисний вимірюваний спад напруги становить лише 100 мкВ. У безпосередній близькості від силових транзисторів, де комутаційний вузол генерує перепади напруги зі швидкістю понад 10 В/нс, а струми перемикаються за лічені наносекунди, такий слабкий аналоговий сигнал повністю тоне у високочастотних електромагнітних завадах та брязкоті земляних полігонів.

Виходом із цього глухого кута став перехід до безвтратного вимірювання за власним активним омічним опором силової котушки індуктивності — DCR-сенсингу (англ. *Direct Current Resistance Sensing*). Будь-який реальний дросель містить мідну обмотку, яка фізично не може мати нульового опору: її омічний опір постійному струму (DCR) типово становить від 0.2 до 1.5 мОм. Оскільки силова котушка є обов'язковим компонентом вихідного LC-фільтра стабілізатора, струм навантаження в будь-якому разі протікає крізь неї, а втрати енергії на нагрівання міді вже закладені в тепловий бюджет перетворювача. Використання цього паразитичного опору як вбудованого датчика струму забезпечує нульові додаткові втрати енергії в силі, усуває потребу у дорогих силових шунтах та зберігає компактність монтажу.

Історичну трансформацію силових архітектур — від перших дискретних шунтів у регуляторах Intel VRM 8.x до інтегрованих дзеркал струму та сучасного DCR-моніторингу — [розглянуто в історичній довідці](book:electronics/dcr-current-sense/hist-lossless-sensing.md).

### Фізична модель реального дроселя та дилема комутаційної ЕРС

З точки зору лінійної теорії електричних кіл, реальна силова котушка індуктивності моделюється як послідовне з'єднання ідеального індуктивного елемента з індуктивністю `L` та паразитичного зосередженого активного опору мідного провідника обмотки `DCR`:

```
+──────────────────────────────────────────────────────────────+
|            МОДЕЛЬ РЕАЛЬНОЇ СИЛОВОЇ КОТУШКИ                   |
|                                                              |
|                     ┌───── L ─────┐  ┌─── DCR ───┐           |
|       Вузол SW ─────┤             ├──┤           ├─── V_out  |
|                     └─────────────┘  └───────────┘           |
|                                                              |
|           v_L(t) = L · (d i_L(t) / dt) + DCR · i_L(t)        |
+──────────────────────────────────────────────────────────────+
```

Різниця потенціалів між зовнішніми виводами котушки `v_L(t)` визначається сумою двох фізично різних складових:

```
v_L(t) = L · (d i_L(t) / dt) + DCR · i_L(t)
```

Перший доданок `L · (d i_L(t) / dt)` є електрорушійною силою (ЕРС) самоіндукції, яка виникає внаслідок зміни магнітного потоку в осерді котушки. Під час періодичної комутації силових польових транзисторів потенціал вузла SW стрибкоподібно змінюється між нулем та вхідною напругою (типово 12 В). Внаслідок цього напруга на індуктивності набуває форми потужних прямокутних імпульсів амплітудою від 10 до 12 В.

Другий доданок `DCR · i_L(t)` — це корисний омічний спад напруги на активному опорі міді, який несе пряму інформацію про миттєве значення струму `i_L(t)`. При типовому опорі дроселя `DCR = 0.35 мОм` та струмі навантаження 30 А цей корисний спад напруги становить лише 10.5 мВ.

Якщо спробувати підключити вимірювальний диференційний підсилювач безпосередньо до виводів котушки, система виявиться непрацездатною. Інформативний постійний та низькочастотний сигнал амплітудою в кілька мілівольтів повністю перекривається комутаційними імпульсами з амплітудою в тисячу разів більшою. Для виділення корисного сигналу необхідний спеціальний аналоговий ланцюг, здатний відфільтрувати комутаційну ЕРС без внесення амплітудних спотворень та фазового запізнення в сигнал струму.

*Еквівалентна схема реальної силової котушки з послідовним опором DCR та підключенням паралельного вимірювального RC-фільтра для виділення струмового сигналу.*

### Синтез вимірювального RC-фільтра та умова узгодження сталих часу

Для вирішення проблеми комутаційної ЕРС паралельно виводам котушки індуктивності підключають пасивний інтегруючий RC-ланцюг першого порядку, що складається з прецизійного резистора `R_s` та конденсатора `C_s`.

Розглянемо роботу схеми в частотній області перетворення Лапласа, де комплексна частота позначається змінною `s = σ + j·ω`.

Комплексний імпеданс реальної котушки описується операторним виразом:

```
Z_L(s) = s·L + DCR
       = DCR · (1 + s · (L / DCR))   [винесення DCR за дужки]
```

Введемо електромагнітну постійну часу силового дроселя `τ_L`:

```
τ_L = L / DCR
```

Звідси падіння напруги на котушці через струм `I_L(s)` записується у факторизованому вигляді:

```
V_L(s) = I_L(s) · DCR · (1 + s·τ_L)
```

Вимірювальний RC-ланцюг утворює частотно-залежний дільник напруги. Напруга на обкладках конденсатора `V_C(s)` описується передатною функцією класичної аперіодичної ланки:

```
V_C(s) = V_L(s) · [ (1 / (s·C_s)) / (R_s + 1 / (s·C_s)) ]
       = V_L(s) · [ 1 / (1 + s·R_s·C_s) ]                  [множення чисельника й знаменника на s·C_s]
```

Введемо власну сталу часу вимірювального RC-фільтра `τ_RC`:

```
τ_RC = R_s · C_s
```

Підставимо вираз напруги на котушці `V_L(s)` у рівняння передатної функції конденсатора `V_C(s)`:

```
V_C(s) = I_L(s) · DCR · [ (1 + s·τ_L) / (1 + s·τ_RC) ]
```

Сенсорний передатний імпеданс вимірювального кола `Z_sense(s) = V_C(s) / I_L(s)` має дрібно-раціональний вигляд з нулем передачі в точці `s_z = −1/τ_L` у чисельнику та полюсом передачі в точці `s_p = −1/τ_RC` у знаменнику.

Якщо номінали компонентів вимірювального фільтра підібрані так, що постійна часу RC-ланцюга строго дорівнює постійній часу котушки:

```
R_s · C_s = L / DCR  ⇔  τ_RC = τ_L
```

відбувається точне взаємне скорочення операторного нуля та операторного полюса:

```
(1 + s·τ_L) / (1 + s·τ_RC) = 1   [за умови строгого балансу τ_RC = τ_L]
```

При виконанні цієї фундаментальної умови передатний імпеданс перетворюється на частотно-незалежну дійсну константу:

```
Z_sense(s) = DCR = const
```

Застосовуючи зворотне перетворення Лапласа, переходимо з частотної області в часову область:

```
v_C(t) = DCR · i_L(t)
```

Отриманий результат має фундаментальне значення: напруга на конденсаторі `v_C(t)` у будь-який момент часу строго пропорційна миттєвому струму котушки `i_L(t)` з масштабним коефіцієнтом `DCR`. Цей зв'язок діє для будь-якої часової форми струму: постійної складової струму навантаження, синусоїдальних гармонік, високочастотних трикутних пульсацій ШІМ-комутації та надшвидких аперіодичних перехідних процесів.

Детальні аналітичні виведення, зворотне перетворення Лапласа для сходинкового збудження та логарифмічні амплітудно-фазові характеристики Боде [наведено у математичній вставці](book:electronics/dcr-current-sense/math-rc-balance.md).

### Архітектура аналогового вхідного каскаду ШІМ-контролера

Напруга `v_C(t)` з обкладок вимірювального конденсатора надходить на вхід внутрішнього диференційного підсилювача струму ШІМ-контролера (Current Sense Amplifier — CSA). Для коректного проектування обв'язки необхідно враховувати специфічні характеристики цього каскаду:

```
+──────────────────────────────────────────────────────────────+
|          ВХІДНИЙ ВИМІРЮВАЛЬНИЙ КАСКАД КОНТРОЛЕРА             |
|                                                              |
|          ISEN+ ───────────┬───────[ + ]                      |
|                           │           │   Підсилювач         |
|                         [ C_s ]       ├─── CSA (Av = 10..35) ──► До ШІМ та АЦП
|                           │           │   (CMRR > 70 dB)     |
|          ISEN− ───────────┴───────[ − ]                      |
|                                                              |
|          I_bias+  ────────►       ◄──────── I_bias−          |
|          (Вхідні струми зміщення операційного каскаду)       |
+──────────────────────────────────────────────────────────────+
```

1. **Діапазон синфазної напруги (Common-Mode Voltage Range):** Вхідні виводи `ISEN+` та `ISEN−` підключені до шини вихідної напруги `V_out` (0.7–1.8 В). Вхідний каскад підсилювача повинен підтримувати роботу при синфазних потенціалах, близьких до нуля (Rail-to-Rail Input або спеціалізований P-канальний диференційний каскад).
2. **Коефіцієнт придушення синфазної завади (CMRR):** При перемиканні фаз потенціал шини `V_out` відчуває високочастотний брязкіт амплітудою в десятки мілівольтів. Щоб цей брязкіт не спотворював струмовий сигнал, підсилювач повинен мати `CMRR ≥ 70–80 дБ` на низьких частотах та не менше 40 дБ на частоті комутації ШІМ (500 кГц — 1 МГц).
3. **Вхідний струм зміщення (Input Bias Current `I_bias`):** Входи підсилювача споживають постійний струм витоку порядку `10–100 нА`. Цей струм протікає крізь резистор фільтра `R_s`, створюючи паразитне зміщення нуля `V_offset_ext = I_bias · R_s`. Якщо обрати опір `R_s` занадто великим (наприклад, 100 кОм), паразитне падіння напруги досягне `100 нА · 100 кОм = 10 мВ`, що можна порівняти з усією корисною шкалою вимірювання! З іншого боку, якщо обрати `R_s` занадто малим (менше 500 Ом), для забезпечення постійної часу `τ_RC ≈ 500 мкс` знадобиться конденсатор ємністю понад 1 мкФ, що виключає застосування компактної C0G-кераміки. Тому оптимальний діапазон опору резистора становить `R_s = 2.0–10.0 кОм`.

### Числовий приклад розрахунку компонентів фільтра для фази стабілізатора

Щоб наочно продемонструвати інженерний процес синтезу вимірювального кола, проведемо розрахунок однієї фази сучасного стабілізатора живлення процесора (специфікація Intel VR14 / AMD SVI3):

**Вихідні параметри силового перетворювача:**
- Вхідна напруга: `V_in = 12.0 В`
- Вихідна напруга живлення ядра: `V_out = 1.05 В`
- Номінальний постійний струм фази: `I_phase = 35.0 А`
- Частота комутації ШІМ: `f_sw = 600 кГц` (період `T_sw = 1.667 мкс`)
- Індуктивність силового дроселя: `L = 150 нГн` (0.150 мкГн)
- Номінальний опір обмотки при 25 °C: `DCR = 0.32 мОм` (0.00032 Ом)

**Крок 1. Розрахунок параметрів перетворювача та розмаху пульсацій струму:**
Коефіцієнт заповнення ШІМ становить:

```
D = V_out / V_in = 1.05 / 12.0 = 0.0875  (8.75 %)
```

Тривалість увімкненого стану верхнього польового транзистора:

```
T_on = D · T_sw = 0.0875 · 1.667 мкс = 0.1458 мкс
```

Розмах трикутних комутаційних пульсацій струму котушки від піка до піка:

```
ΔI_L = [ (V_in − V_out) / L ] · T_on
     = [ (12.0 − 1.05) / (150 · 10⁻⁹) ] · (0.1458 · 10⁻⁶)
     = [ 10.95 / (150 · 10⁻⁹) ] · 0.1458 · 10⁻⁶ = 10.64 А
```

**Крок 2. Розрахунок власної сталої часу дроселя:**

```
τ_L = L / DCR = (150 · 10⁻⁹ Гн) / (0.32 · 10⁻³ Ом) = 468.75 · 10⁻⁶ с = 468.75 мкс
```

**Крок 3. Вибір ємності конденсатора сенсингу C_s:**
Обираємо конденсатор із високостабільним діелектриком класу 1 (C0G/NP0) стандартного номіналу `C_s = 0.10 мкФ` (100 нФ).

**Крок 4. Розрахунок опору резистора фільтра R_s:**
З умови ідеального балансу `R_s · C_s = τ_L`:

```
R_s = τ_L / C_s = (468.75 · 10⁻⁶ с) / (0.10 · 10⁻⁶ Ф) = 4687.5 Ом
```

Обираємо найближчий стандартний номінал із прецизійного ряду E96 (допуск 1 %): `R_s = 4.70 кОм` (похибка номіналу становить лише −0.27 %).

**Крок 5. Аналіз рівнів вимірюваної напруги на конденсаторі C_s:**
- Постійна складова напруги при струмі 35 А:
  ```
  V_C_DC = I_phase · DCR = 35.0 А · 0.32 мОм = 11.20 мВ
  ```
- Розмах високочастотних трикутних пульсацій напруги:
  ```
  ΔV_C = ΔI_L · DCR = 10.64 А · 0.32 мОм = 3.40 мВ_pp
  ```
- Максимальна пікова напруга на вході компаратора захисту OCP:
  ```
  V_C_peak = V_C_DC + ΔV_C / 2 = 11.20 + 1.70 = 12.90 мВ
  ```

Ці розрахунки наочно показують, що вхідний підсилювач контролера повинен опрацьовувати сигнали амплітудою в одиниці мілівольтів із рівнем власних шумів менше 50 мкВ.

### Динамічна поведінка при перехідних процесах та розбалансі сталих часу

У реальних умовах експлуатації через виробничі допуски компонентів, температурне нагрівання міді та магнітне підмагнічування осердя строга рівність `τ_RC = τ_L` може порушуватися. Розглянемо відгук вимірювальної напруги `v_C(t)` на миттєве ступінчасте зростання струму навантаження на величину `ΔI` (наприклад, перехід процесора зі стану енергозбереження C-state у режим максимального обчислювального навантаження Turbo Boost):

```
+──────────────────────────────────────────────────────────────+
|              ТРИ РЕЖИМИ ПЕРЕХІДНОЇ ХАРАКТЕРИСТИКИ            |
|                                                              |
|   1. Ідеальне узгодження (τ_RC = τ_L):                       |
|      v_C(t) = DCR · ΔI · u(t)   [ідеальна сходинка]          |
|                                                              |
|   2. Недофільтрація (τ_RC < τ_L):                            |
|      Диференційний сплеск напруги на передньому фронті       |
|                                                              |
|   3. Перефільтрація (τ_RC > τ_L):                            |
|      Інтегральне згладжування та затягування фронту          |
+──────────────────────────────────────────────────────────────+
```

Аналіз трьох динамічних станів:

1. **Ідеальний баланс (`τ_RC = τ_L`):** Напруга на конденсаторі миттєво піднімається на рівень `ΔI · DCR` одночасно з наростанням струму. На сходинку накладаються чисті трикутні пульсації, які точно відображають заряд і розряд індуктивності під час комутації ШІМ. Контролер отримує достовірну інформацію про миттєвий струм без будь-якої затримки фази.
2. **Режим недофільтрації (`τ_RC < τ_L`):** Стала часу фільтра менша за постійну часу дроселя (частота зрізу фільтра завищена). RC-ланцюг не встигає повністю придушити комутаційну ЕРС, тому на високих частотах схема набуває диференціюючих властивостей. У момент стрибка струму напруга на конденсаторі зазнає різкого пікового викиду (overshoot) з початковою амплітудою `v_C(0⁺) = DCR · ΔI · (τ_L / τ_RC) > DCR · ΔI`. Цей динамічний сплеск хибно детектується компаратором як аварійне перевантаження за струмом, викликаючи передчасне вимикання фази або хибне спрацьовування захисту OCP (Overcurrent Protection). У системах з [адаптивним позиціонуванням напруги](book:electronics/adaptive-voltage-positioning) такий викид спричиняє надмірний динамічний провал напруги живлення ядра.
3. **Режим перефільтрації (`τ_RC > τ_L`):** Стала часу фільтра перевищує постійну часу котушки (частота зрізу занижена). Схема працює як повільний інтегратор: напруга на конденсаторі наростає за експоненційним законом із помітним запізненням. Під час різкого накидання навантаження контролер своєчасно «не бачить» стрибка струму і не встигає збільшити шпаруватість ШІМ. Вихідні конденсатори стабілізатора встигають суттєво розрядитися, що призводить до глибокого просідання вихідної напруги живлення та затяжного коливального перехідного процесу.

![Перехідні характеристики напруги на вимірювальному конденсаторі при різних співвідношеннях сталих часу](/book/electronics/power-electronics/dcr-current-sense/img/time-constant-matching.svg)
*Форма вимірюваної напруги на конденсаторі при стрибку струму навантаження: ідеальний баланс, недофільтрація з диференційним викидом та перефільтрація з інтегральним запізненням.*

### Взаємодія з контуром адаптивного позиціонування напруги (AVP / Load-Line)

У стабілізаторах живлення сучасних мікропроцесорів вихідна напруга не підтримується строго постійною, а контрольовано знижується при зростанні струму навантаження відповідно до лінійного закону навантажувальної прямої (Load-Line Droop):

```
V_out(I_load) = V_VID − R_droop · I_load
```

де `V_VID` — базове програмне значення напруги холостого ходу (Voltage Identification Code), а `R_droop` — заданий еквівалентний вихідний опір стабілізатора (типово від 0.5 до 1.5 мОм).

Така техніка [адаптивного позиціонування напруги](book:electronics/adaptive-voltage-positioning) дозволяє зменшити кількість дорогих вихідних керамічних конденсаторів та знизити розсіювану процесором потужність при максимальних обчисленнях.

Контур AVP використовує відновлений DCR-сигнал струму для безпосередньої корекції сигналу зворотного зв'язку за напругою. Якщо в контурі DCR-сенсингу виникає розбалансування сталих часу:
- **При недофільтрації:** Початковий викид напруги струмового сенсора змушує регулятор різко зменшити вихідну напругу `V_out` нижче допустимого рівня специфікації процесора (Under-Voltage Crash), провокуючи скидання обчислень або зависання операційної системи.
- **При перефільтрації:** Затримка струмового сигналу під час раптового скидання навантаження (струм падає від 100 А до 5 А за 50 нс) призводить до того, що стабілізатор продовжує закачувати енергію в котушки. Виникає потужний сплеск вихідної напруги (Over-Voltage Spike), здатний пробити надтонкий оксидний підзатворний діелектрик нанорозмірних польових транзисторів кристала процесора.

### Вплив матеріалу осердя та магнітного насичення L(I)

У потужних стабілізаторах поведінка індуктивності суттєво залежить від типу магнітного матеріалу осердя:

1. **Формовані металопорошкові дроселі (Molded Alloy Powder):** Осердя виготовляють пресуванням дрібнодисперсного порошку сплавів заліза (Carbonyl Iron, Sendust, MegaFlux) з полімерним діелектричним зв'язуючим. Завдяки мільйонам мікроскопічних розподілених зазорів між зернами металу такі дроселі мають характеристику «м'якого насичення» (Soft Saturation): при зростанні струму індуктивність плавно зменшується на 20–30 % без різкого обриву. Це робить їх надзвичайно стійкими до перевантажень, хоча постійна часу `τ_L(I)` зазнає поступового зменшення під великим струмом.
2. **Феритові дроселі з дискретним зазором (Gapped Ferrite):** Мають наднизькі втрати на перемагнічування на частотах 1–2 МГц та строго стабільну індуктивність до певної межі струму. Проте при досягненні струму насичення `I_sat` ферит зазнає «жорсткого насичення» (Hard Saturation): індуктивність лавиноподібно падає у 5–10 разів за незначного приросту струму. Якщо стабілізатор переходить у цю зону, постійна часу дроселя `τ_L` раптово падає нижче `τ_RC`, перетворюючи вимірювальне коло на важкий недофільтрований диференціатор із гігантськими сплесками напруги.

### Високочастотні ефекти в мідній обмотці: скін-ефект та ефект близькості

При частотах комутації ШІМ від 300 кГц до 2 МГц омічний опір провідника струму вже не можна вважати чисто постійною величиною `DCR_DC`.

Високочастотний змінний струм витісняється до поверхні провідника власним змінним магнітним полем (скінефект). Товщина поверхневого шару провідності (скін-шару) для міді визначається виразом:

```
δ = √(ρ_Cu / (π · μ_0 · f)) ≈ 66 / √f   [мм, де f у Гц]
```

На частоті комутації 600 кГц глибина скін-шару становить лише `δ ≈ 85 мкм`.

Крім того, змінне магнітне поле сусідніх витків індукує вихрові струми всередині міді (ефект близькості — proximity effect), що додатково спотворює однорідність густини струму.

Внаслідок цих явищ еквівалентний динамічний опір котушки на частоті комутації `DCR_AC(f)` може перевищувати опір постійному струму `DCR_DC` у 1.5–3 рази. Проте, оскільки постійна складова струму навантаження (DC Current) рівномірно розподіляється по всьому перерізу міді, вимірювання середнього струму базується строго на `DCR_DC`. Для мінімізації високочастотних спотворень пульсацій форми струму сучасні силові дроселі виготовляють із плоскої мідної шини прямокутного перерізу (Flat Wire) або багатожильного літцендрату.

### Температурний дрейф опору міді та схемотехніка лінеаризованої термокомпенсації

Фізичним бар'єром для точності методу DCR є високий позитивний температурний коефіцієнт електричного опору міді (TCR — Temperature Coefficient of Resistance):

```
α_Cu ≈ +0.00393 / °C   [тобто +3930 ppm/K]
```

Опір мідної обмотки при температурі `T` описується лінійним законом:

```
DCR(T) = DCR_25 · [ 1 + α_Cu · (T − 25 °C) ]
```

де `DCR_25` — опір обмотки при кімнатній температурі 25 °C.

Під час тривалої роботи стабілізатора під максимальним навантаженням температура силового дроселя зростає від початкових 25 °C до робочих 100–105 °C (`ΔT ≈ +80 °C`). Опір обмотки при цьому збільшується на:

```
ΔDCR / DCR_25 = 0.00393 · 80 = +0.3144   [тобто +31.4 %]
```

Якщо температурний дрейф не компенсувати, система вимірювання струму отримає систематичну похибку понад 30 %. Поріг захисту від перевантаження, розрахований на струм 100 А, на розігрітій платі спрацює вже при струмі 76 А, передчасно обмежуючи продуктивність системи.

Для стабілізації масштабу вимірювання застосовують терморезистори з від'ємним температурним коефіцієнтом опору — NTC-термістори.

Опір напівпровідникового керамічного NTC-термістора зменшується при нагріванні за експоненційним рівнянням:

```
R_NTC(T) = R_NTC_25 · exp[ B · (1 / T − 1 / T_0) ]
```

де `B` — константа чутливості кераміки (типово 3400–4200 К), а `T_0 = 298.15 К` (25 °C). Температурний коефіцієнт «голого» NTC-термістора при кімнатній температурі становить близько `−4.4 % / °C`, що за абсолютною величиною більш ніж в 11 разів перевищує коефіцієнт міді.

Пряме включення NTC-термістора у вимірювальне коло неприпустиме, оскільки воно призводить до катастрофічної перекомпенсації: вимірювана напруга при нагріванні впаде майже до нуля.

Щоб приборкати круту експоненту терморезистора та сформувати спадний коефіцієнт передачі, дзеркальний до лінійного зростання опору міді, термістор оточують прецизійними постійними резисторами, створюючи лінеаризовану триелементну мережу:

```
+──────────────────────────────────────────────────────────────+
|              ЛІНЕАРИЗОВАНА NTC-МЕРЕЖА ТЕРМОКОМПЕНСАЦІЇ       |
|                                                              |
|                     ┌───── R_p ─────┐                        |
|            Вхід ────┴────[ NTC ]────┴────[ R_s2 ]──── Вихід  |
|                                                              |
|    R_net(T) = R_s2 + (R_p · R_NTC(T)) / (R_p + R_NTC(T))     |
+──────────────────────────────────────────────────────────────+
```

Паралельний резистор `R_p` шунтує NTC-термістор, усуваючи експоненційну крутизну та переводячи його характеристику в лінеаризовану точку перегину. Послідовний резистор `R_s2` задає мінімальний опір мережі при гранично високих температурах.

Коефіцієнт передачі утвореного дільника напруги `G_net(T)` зменшується з ростом температури строго обернено пропорційно до зростання опору міді, завдяки чому результуючий вимірюваний сигнал залишається незмінним:

```
DCR(T) · G_net(T) ≈ const = DCR_25 · G_net(25 °C)
```

![Температурний дрейф опору міді та принцип його лінеаризації за допомогою NTC-мережі](/book/electronics/power-electronics/dcr-current-sense/img/temperature-drift-ntc.svg)
*Температурна залежність опору міді, крива лінеаризованої NTC-мережі та скомпенсована результуюча характеристика сенсорного сигналу.*

Схемотехнічні топології NTC-мереж, аналітичний розрахунок номіналів за методом точки перегину та правила теплового контакту на платі [розкрито в схемотехнічній вставці](book:electronics/dcr-current-sense/comp-ntc-network.md).

### Багатофазні системи: фазове балансування та синтез сумарного струму

У стабілізаторах живлення сучасних процесорів застосовують [багатофазний понижувальний стабілізатор](book:electronics/multiphase-buck), що містить від 4 до 16 паралельних силових каналів (фаз), які працюють із взаємним зсувом за фазою на кут `360° / N`.

У багатофазній архітектурі DCR-сенсинг виконує дві незалежні функції:

1. **Фазове вирівнювання струмів (Phase Current Balancing):** Окремий сенсорний сигнал із кожної фази надходить у локальний контур струмового балансування. Якщо через технологічний розкид параметрів одна з фаз бере на себе надмірний струм, контролер зменшує тривалість її керуючого імпульсу ШІМ, рівномірно розподіляючи теплове навантаження між усіма силовими ключами та дроселями.
2. **Формування сумарного сигналу струму (Total Current Summing):** Для роботи загального струмового захисту та формування лінії спаду вихідної напруги (Load-Line Droop) у системах AVP необхідний інтегральний сигнал сумарного струму перетворювача.

Для апаратного підсумовування виходи окремих фазних RC-фільтрів об'єднують через резистивну зірку резисторів підсумовування `R_sum` на спільному вимірювальному конденсаторі або на віртуальній землі інвертуючого входу операційного підсилювача:

```
+──────────────────────────────────────────────────────────────+
|       СХЕМА ПАРАЛЕЛЬНОГО ПІДСУМОВУВАННЯ СТРУМІВ ФАЗ          |
|                                                              |
|   Фаза 1: C_s1 ────[ R_sum ]────┐                            |
|   Фаза 2: C_s2 ────[ R_sum ]────┼───► ISEN_SUM+ (До ОУ)      |
|   Фаза N: C_sN ────[ R_sum ]────┘                            |
+──────────────────────────────────────────────────────────────+
```

Багатофазне чергування фаз створює ефект множення частоти пульсацій вихідного струму та зменшення їхньої амплітуди завдяки взаємному накладанню фронтів, що значно підвищує якість струмової телеметрії та спрощує вимоги до вихідних фільтрів.

![Схема підсумовування та розподілу струмів у багатофазному імпульсному стабілізаторі](/book/electronics/power-electronics/dcr-current-sense/img/multiphase-summing.svg)
*Схема паралельного підсумовування DCR-сигналів у багатофазному регуляторі для формування загальної телеметрії та лінійного навантажувального спаду.*

### Топологічні правила трасування друкованої плати

Оскільки рівень корисного сигналу на конденсаторі `C_s` становить лише одиниці або десятки мілівольтів, а сусідній комутаційний вузол SW генерує швидкісні перепади напруги з амплітудою понад 12 В та швидкістю `dv/dt ≥ 10–20 В/нс`, помилки в трасуванні друкованої плати можуть повністю спотворити вимірювання.

Для надійного захисту вимірювального тракту застосовують суворі правила проектування друкованих плат:

1. **Кельвінівське 4-провідне підключення до контактних майданчиків:** Силовий струм перетворювача протікає через зовнішні краї паяльних площадок дроселя. Сенсорні вимірювальні доріжки повинні підключатися строго всередині контактного майданчика з його внутрішнього торця, де силовий струм не створює паразитного падіння напруги на шарі припою та міді полігону.
2. **Диференційна пара мінімальної площі:** Доріжки `ISEN+` та `ISEN−` трасують як прецизійну диференційну пару з мінімальною відстанню між провідниками (0.1–0.15 мм) на всій довжині від дроселя до мікросхеми контролера. Це мінімізує площу паразитного контуру, в який може наводитися магнітне поле розсіювання котушки.
3. **Екранування суцільними земляними шарами:** Диференційна пара сенсингу повинна проходити у внутрішніх шарах друкованої плати між двома суцільними опорними полігонами чистої землі (GND Plane). Категорично заборонено перетинати комутаційний полігон SW або розташовувати сенсорні доріжки у сусідньому шарі безпосередньо під силовим вузлом SW.
4. **Розміщення пасивних компонентів біля контролера:** Елементи RC-фільтра (`R_s`, `C_s`) та термокомпенсації розміщують безпосередньо біля виводів мікросхеми ШІМ-контролера, а не біля дроселя. Це забезпечує високий імпеданс перешкодозахищеного сигналу та фільтрацію наведених шумів прямо на вході вимірювального підсилювача.

![Топологія кельвінівського диференційного трасування сенсорних доріжок на друкованій платі](/book/electronics/power-electronics/dcr-current-sense/img/pcb-kelvin-layout.svg)
*Правила топологічного трасування DCR-сенсингу: кельвінівські відводи, диференційна пара під екрануючим полігоном та захист від комутаційного вузла SW.*

### Порівняльний аналіз методів вимірювання струму

Вибір схемотехнічного методу вимірювання струму в імпульсних стабілізаторах визначається балансом між енергетичною ефективністю, точністю, займаною площею плати та собівартістю виробу:

| Метод вимірювання струму | Точність вимірювання | Додаткові втрати енергії | Вплив на ККД при 100 А | Займана площа плати | Складність термокомпенсації | Собівартість реалізації |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Прецизійний шунт** ([вимірювальний шунт](book:electronics/current-monitor)) | Найвища (±0.5–1.0 %) | `I² · R_shunt` (дуже високі) | Знижує ККД на 5–10 % | Велика (масивні SMD 2512/3920) | Мінімальна (TCR манганіну < 20 ppm/K) | Висока (дорогі резистори) |
| **DCR-сенсинг котушки** | Середня (±3.0–5.0 % після NTC) | **0 Вт (повна відсутність втрат)** | **0 % втрат ККД** | Мінімальна (лише пасивні SMD 0402) | Середня (вимагає NTC або цифрової корекції) | Найнижча (дешеві RC-ланцюги) |
| **Сенсинг за R_DS(on) ключів** | Низька (±15–25 %) | 0 Вт (використовує канал польовика) | 0 % втрат ККД | Нульова (без зовнішніх деталей) | Дуже висока (величезний розкид R_DS(on)) | Нульова (вбудовано в драйвер) |
| **Дзеркало струму SPS (DrMOS / IMON)** | Висока (±1.5–2.5 %) | Мінімальні (струм дзеркала 1:10000) | < 0.1 % втрат ККД | Інтегровано в кристал силового модуля | Автоматична (вбудований датчик на кристалі) | Висока (дорожчі силові модулі) |

DCR-сенсинг є безальтернативним рішенням для масових систем живлення високої потужності, де критично важливим є збереження максимального ККД за мінімальної вартості специфікації компонентів (BOM).

### Практичні компроміси, розкид параметрів та калібрування

Незважаючи на відсутність втрат енергії, успішне проектування контурів DCR-сенсингу вимагає врахування таких фізичних особливостей:

1. **Виробничий допуск опору DCR:** Початковий розкид опору мідного провідника від партії до партії становить ±7–10 % через допуски на діаметр дроту та зусилля намотування котушки.
2. **Нелінійність індуктивності при підмагнічуванні `L(I)`:** При великих струмах навантаження феритове або металопорошкове осердя дроселя частково насичується, внаслідок чого індуктивність `L` спадає на 15–30 %. Це порушує баланс `R_s · C_s = L / DCR`, зміщуючи роботу схеми в бік перефільтрації при максимальних навантаженнях.
3. **Вибір діелектрика вимірювального конденсатора `C_s`:** Застосування керамічних конденсаторів класу 2 (X7R, X5R) є грубою помилкою через виражений ефект падіння ємності під постійною напругою зміщення (DC Bias Effect) та високий температурний коефіцієнт ємності. Необхідно застосовувати виключно прецизійні конденсатори класу 1 з діелектриком **C0G (NP0)**, що мають нульовий ефект напруги зміщення та наднизький температурний дрейф (`±30 ppm/K`).

У прецизійних цифрових стабілізаторах ці апаратні нелінійності компенсуються калібруванням зсуву нуля при старті системи та динамічною поліноміальною корекцією в мікроконтролері.

Лабораторну методику осцилографічного налаштування фільтра, алгоритми автокалібрування зсуву нуля та повні приклади програмного коду на C99 і C++20 [представлено в практичному проекті](book:electronics/dcr-current-sense/proj-dcr-tuning.md).

> DCR-сенсинг — фундаментальний стандарт моніторингу струму в сучасній обчислювальній електроніці. Без нього неможливо побудувати материнську плату комп'ютера, відеокарту або серверний модуль живлення: використання дискретних резисторів-шунтів при струмах у 200–500 А розплавило б друковану плату виділенням сотень ватів непотрібного тепла.
