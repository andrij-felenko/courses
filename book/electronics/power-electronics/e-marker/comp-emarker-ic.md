Мікросхема електронного маркера (англ. *Electronically Marked Cable Controller*, E-Marker IC) — це спеціалізований змішано-сигнальний контролер (ASIC або надмалопотужний мікроконтролер), що інтегрується безпосередньо у внутрішню друковану плату (*paddle card*) роз'єму кабелю USB Type-C. Його функціональне призначення полягає в апаратному зберіганні електричного та протокольного паспорта кабельної збірки й наданні цієї інформації порту-джерелу (DFP) або порту-споживачу (UFP) на запит по шині конфігураційного каналу (CC).

Кабелі, здатні пропускати струм понад 3 А (аж до 5 А в режимах 100 Вт SPR та 240 Вт EPR) або передавати високошвидкісні цифрові потоки (USB 3.2 Gen1/Gen2, USB4, Thunderbolt 3/4), не можуть залишатися суто пасивними провідниками. Неконтрольована комутація струму 5 А крізь тонкі провідники перетином AWG 28–30 неминуче спричиняє резистивний перегрів міді, термічну деградацію ізоляції та ризик займання роз'єму. Чип E-Marker усуває цей ризик, виконуючи роль цифрового арбітра безпеки.

## Внутрішня функціональна структура мікросхеми

Типовий чип E-Marker виготовляється за високовольтним технологічним процесом CMOS або BCD (*Bipolar-CMOS-DMOS*) і містить сім ключових апаратних вузлів, розташованих на єдиному напівпровідниковому кристалі.

```
                    ┌────────────────────────────────────────────────────────┐
                    │               E-Marker Controller ASIC                 │
                    │                                                        │
                    │  ┌──────────────┐   ┌─────────────┐   ┌─────────────┐  │
VCONN (3.0–5.5 В) ──┼─►│ LDO Regulator│──►│ 1.2V/1.8V   │──►│   Thermal   │  │
                    │  │   & POR      │   │ Logic Core  │   │   Sensor    │  │
                    │  └──────┬───────┘   └─────────────┘   └─────────────┘  │
                    │         │                                     ▲        │
                    │  ┌──────▼───────┐   ┌─────────────┐           │        │
                    │  │ Ra Pull-down │   │ BMC Analog  │           │        │
                    │  │ Switch (1kΩ) │   │ Front-End   │           │        │
                    │  └──────┬───────┘   └──────┬──────┘           │        │
                    │         │                  │                  │        │
                    │         │           ┌──────▼──────┐   ┌───────┴─────┐  │
CC (BMC I/O) ───────┼─────────┴──────────►│ 4b/5b & CRC │──►│ State Logic │  │
                    │                     │ Transceiver │   │ / Micro-Core│  │
                    │                     └─────────────┘   └───────┬─────┘  │
                    │                                               ▼        │
                    │                                       ┌─────────────┐  │
GND ────────────────┼──────────────────────────────────────►│  OTP / ROM  │  │
                    │                                       │ (VDO Table) │  │
                    │                                       └─────────────┘  │
                    └────────────────────────────────────────────────────────┘
```

### 1. Джерело опорної напруги та лінійний стабілізатор (LDO)

Мікросхема живиться виключно від шини VCONN, на яку контролер джерела або споживача подає номінальну напругу 5.0 В (допустимий робочий діапазон стандарту становить від 3.0 до 5.5 В). Вбудований LDO-стабілізатор понижує цю напругу до внутрішнього рівня 1.2 В або 1.8 В для живлення цифрового ядра. 

Схема містить вузол скидання за живленням (англ. *Power-On Reset*, POR), який гарантує коректну ініціалізацію регістрів та завантаження таблиць дескрипторів лише після стабілізації напруги VCONN понад поріг 2.7 В. Струм власного споживання чипа в активному режимі передачі BMC не перевищує 5–10 мА, а в режимі очікування (*standby*) становить менше 15–30 мкА, що повністю вкладається в ліміт енергоспоживання пасивного кабелю 100 мВт.

### 2. Вхідний аналоговий каскад та комутований опір Ra

На виводі VCONN мікросхеми інтегровано прецизійний резистор підтяжки до землі `Ra` з номінальним значенням 1.0 кОм (допуск стандарту USB Type-C: від 800 Ом до 1200 Ом). Цей опір підключено послідовно через внутрішній польовий транзистор (FET).

Коли кабель не заживлений, опір `Ra` фізично присутній на контакті CC2/VCONN штекера. Джерело живлення, аналізуючи падіння напруги на дільнику `Rp / Ra`, миттєво відрізняє кабель з маркером від споживача (`Rd` = 5.1 кОм). Після детектування та подачі напруги VCONN транзисторний ключ може відмикати внутрішній резистор `Ra`, аби виключити постійне марне розсіювання потужності на ньому під час тривалої роботи кабелю:

```
P = VCONN² / Ra
= (5.0)² / 1000      [напруга VCONN = 5.0 В, опір Ra = 1000 Ом]
= 25 / 1000
= 0.025 Вт           [25 мВт постійної потужності розсіювання]
```

### 3. Аналоговий трансивер BMC (Physical Layer Front-End)

Приймач BMC містить диференційний компаратор з регульованим гістерезисом (зазвичай 50–100 мВ) та схемою динамічного зміщення робочої точки, що дозволяє виділяти логічні переходи напруги амплітудою 1.05–1.20 В на тлі шуму й синфазних завад шини CC. Передавач являє собою симетричний двотактний драйвер із контрольованою крутизною фронтів (*slew-rate control*), що формує перепади напруги тривалістю 100–300 нс, мінімізуючи паразитне електромагнітне випромінювання на радіочастотах.

### 4. Цифровий блок кодування 4b/5b та апаратний CRC-32

Модуль приймання розбиває вхідний потік напівдуплексного сигналу BMC (швидкість передачі 270–330 кбіт/с, номінально 300 кбіт/с) на біти, транслює 5-бітові символи канального кодування у 4-бітові тетради даних і детектує службові послідовності *Ordered Sets*.

Апаратний автомат розпізнає стартові комбінації маркерів початку пакета:
- **SOP'** — комбінація символів K-кодів `Sync-1, Sync-1, Sync-1, Sync-2` (опитування ближнього штекера);
- **SOP''** — комбінація `Sync-1, Sync-1, Sync-3, Sync-3` (опитування протилежного дальнього штекера).

Пакет, адресований порту-партнеру (**SOP**, що складається з `Sync-1, Sync-1, Sync-1, Sync-1`), трансивер E-Marker повністю ігнорує, пропускаючи його транзитом. Обчислення 32-бітової контрольної суми CRC здійснюється на льоту за стандартним поліномом Ethernet/USB PD:

```
G(x) = x³² + x²⁶ + x²³ + x²² + x¹⁶ + x¹² + x¹¹ + x¹⁰ + x⁸ + x⁷ + x⁵ + x⁴ + x² + x + 1
```

Якщо обчислена контрольна сума не збігається із завершальними чотирма байтами повідомлення, пакет відкидається без надсилання відповіді, запобігаючи виконанню спотворених команд.

### 5. Енергонезалежна пам'ять конфігурації (OTP / EEPROM / Flash)

Усі параметри кабелю прошиваються у внутрішній масив пам'яті під час фінального тестування кабельної збірки на заводі. Використовується пам'ять одноразового програмування (OTP — *One-Time Programmable*) на антиперемичках (*antifuse*) або багаторазова EEPROM з апаратним захистом від запису після фіналізації.

Пам'ять зберігає фіксовану послідовність 32-бітових об'єктів даних (VDO — *Vendor Data Objects*):
- Ідентифікатор виробника USB-IF (VID) та код продукту (PID);
- Сертифікаційний номер тестування відповідності (XID);
- Максимальна робоча напруга (20 В для SPR або 50 В для EPR);
- Допустимий струм (3 А або 5 А);
- Гранична швидкість передачі даних лініями USB/DP (USB 2.0, USB 3.2 Gen1, Gen2, USB4 Gen3 40 Гбіт/с, USB4 Gen4 80/120 Гбіт/с);
- Фізична довжина, затримка поширення сигналу (< 10 нс, 10–20 нс, 20–30 нс) та тип конструкції роз'ємів.

### 6. Вбудований датчик температури

Сучасні контролери E-Marker стандарту USB PD 3.1 містять інтегрований кремнієвий датчик температури на базі пропорційної абсолютної температури напруги (*PTAT-елемент*). Датчик відстежує розігрів контактної групи роз'єму під час протікання струму 5 А. У разі аварійного зростання перехідного опору контактів (через окислення, забруднення або механічний знос) чип фіксує температуру понад 85–105 °C і передає тривожний прапорець або значення поточної температури в структурованих полях дескриптора `Passive Cable VDO 2`, дозволяючи джерелу живлення завчасно знизити струм або розірвати силовий контракт.

### 7. Високовольтний захист від перенапруги (OVP) та ESD

Один із найкритичніших вузлів мікросхеми — високовольтний захист вхідних виводів CC та VCONN. У стандарті USB Type-C крок між сусідніми контактами становить лише 0.5 мм. При неакуратному або кутовому витяганні штекера під напругою 48 В силовий контакт VBUS може механічно закоротити сусідній сигнальний контакт CC1 або VCONN.

Звичайний низьковольтний контролер при потраплянні 48 В на пін CC зазнає миттєвого теплового пробою та вигорання кристала. Контролери E-Marker класу EPR проєктуються з внутрішніми TVS-структурами та високовольтними ключами, здатними витримувати постійну напругу зміщення до 50–55 В DC без пошкодження структури кристала.

## Корпусне виконання та топологія друкованої плати (Paddle Card)

Плата Paddle Card є мініатюрною 2-х або 4-шаровою друкованою платою, розташованою всередині литого пластикового корпусу штекера кабелю.

```
       ┌────────────────────────────────────────────────────────┐
       │                      Paddle Card                       │
       │                                                        │
       │  ┌────┐ GND              VBUS (Товстий полігон)   ┌─┐  │
       │  │    │───────────────────────────────────────────│ │  │
       │  │    │                                           │ │  │
       │  │    │ CC1 (Наскрізний)       ┌──────────────┐   │ │  │
       │  │    │───────────────────┬───►│ E-Marker IC  │   │ │  │
       │  │    │                   │    │ [DFN-6 /     │   │ │  │
       │  │    │                   │    │  WLCSP-6]    │   │ │  │
       │  │    │ VCONN / CC2       │    └──────┬───────┘   │ │  │
       │  │    │───────────┬───────┼───────────┘           │ │  │
       │  │    │          ┌┴┐      │                       │ │  │
       │  │    │       C1 └┬┘ 100nF│                       │ │  │
       │  │    │ GND       │       │                       │ │  │
       │  │    │───────────┴───────┴───────────────────────│ │  │
       │  │    │                                           │ │  │
       │  │    │ SuperSpeed Дифпари (Екрановані лінії)     │ │  │
       │  │    │═══════════════════════════════════════════│ │  │
       │  └────┘                                           └─┘  │
       │    ▲                                                ▲  │
       │  Контакти                                       Кабельний│
       │  роз'єму Type-C                                  джгут │
       └────────────────────────────────────────────────────────┘
```

Мікросхеми E-Marker випускаються в надкомпактних безвивідних корпусах:
- **DFN-6 / DFN-8** (розміри 2.0 × 2.0 × 0.75 мм або 2.0 × 3.0 мм, крок виводів 0.5 мм);
- **WLCSP-6** (англ. *Wafer-Level Chip-Scale Package*, розміри 0.8 × 1.2 × 0.4 мм, масив кулькових виводів із кроком 0.4 мм).

### Призначення виводів типового 6-вивідного корпусу DFN-6:

| Вивід | Назва | Тип | Функціональне призначення |
| :--- | :--- | :--- | :--- |
| **1** | `VCONN1` | Живлення / Вхід | Основний вхід живлення 3.0–5.5 В від шини VCONN штекера з внутрішнім резистором Ra |
| **2** | `GND` | Земля | Сигнальна та силова земля кабельної збірки |
| **3** | `CC` | Цифровий I/O | Вхід/вихід трансивера BMC для прийому та передачі пакетів SOP'/SOP'' |
| **4** | `VCONN2` | Живлення / Вхід | Альтернативний вхід VCONN (для конфігурацій з незалежним опитуванням з двох боків) |
| **5** | `TS / VDD` | Аналоговий / Тест | Підключення зовнішнього NTC-термістора або вивід внутрішнього стабілізатора |
| **6** | `NC / PROG` | Спеціальний | Вивід заводського програмування OTP/EEPROM (у роботі не підключається) |

## Схемотехнічні правила монтажу та типові інженерні помилки

При розведенні друкованої плати штекера необхідно суворо дотримуватися таких правил:
1. **Блокувальний конденсатор.** Керамічний конденсатор `C1` ємністю 100 нФ – 1.0 мкФ (діелектрик X7R, робоча напруга не менше 16 В для SPR або 50 В для EPR) розміщується на відстані не більше 1 мм від виводу `VCONN` мікросхеми для придушення високочастотних перехідних коливань при комутації живлення.
2. **Товщина провідників VBUS та GND.** Провідники силового живлення виконуються суцільними мідними полігонами на всіх шарах плати, прошитими густою сіткою перехідних отворів (*vias*), що забезпечує опір лінії менше 10–15 мОм та унеможливлює нагрівання плати при постійному струмі 5 А.
3. **Екранування ліній CC.** Сигнальну доріжку CC трасують із мінімальною паразитною ємністю (не більше 20–30 пФ на всю довжину плати), віддаляючи її від імпульсних високошвидкісних ліній SuperSpeed (TX/RX), аби виключити наведення паразитних перепадів напруги на компаратор BMC.
4. **Розв'язка двох чипів у довгому кабелі.** Якщо кабель містить два чипи E-Marker (по одному в кожному штекері), їхні лінії живлення VCONN обов'язково розв'язуються вбудованими діодними схемами або внутрішньою логікою чипів, щоб уникнути утворення паразитних кілець струму між різними кінцями кабелю.

Конкретний синтаксис пакетів, бітові карти конфігураційних слів та таблиці числових значень VDO, які зберігаються в енергонезалежній пам'яті цих контролерів, стандартизовані специфікацією USB-IF і наведені в довіднику [📋 Дескриптори Structured VDM та VDO](topic:electronics/e-marker/api-vdm-descriptors.md).
