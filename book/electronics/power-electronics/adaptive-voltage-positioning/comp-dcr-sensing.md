# 🔌 Струмовий моніторинг DCR та контур термічної компенсації

Ця вставка розбирає фізику, схемотехніку та проектування контуру безвтратного вимірювання струму котушок індуктивності (Inductor DCR Current Sensing), математичну умову нульової фазової похибки та компенсацію температурного дрейфу опору міді за допомогою термісторних NTC-мереж у багатофазних стабілізаторах напруги VRM.

Без прецизійного вимірювання миттєвого струму фаз неможливо сформувати точний активний спад напруги (droop), збалансувати струми між паралельними фазами та реалізувати швидкий пофазний захист від перевантаження (OCP).

```
+──────────────────────────────────────────────────────────────────────────────+
│                       СХЕМА DCR-СЕНСИНГУ ТА NTC-КОМПЕНСАЦІЇ                  │
│                                                                              │
│       Вузол SW ───[ L ]───[ DCR ]───┬─── VCore (до CPU)                       │
│             │                       │                                        │
│             └───[ R_s ]───┬───[ C_s ]─┘                                      │
│                           │                                                  │
│                        V_Cs(t) = DCR · i_L(t)   [при R_s · C_s = L / DCR]    │
│                           │                                                  │
│                           ▼                                                  │
│                 [ Термомережа NTC ] ───► ISEN / DROOP (VRM-контролер)        │
+──────────────────────────────────────────────────────────────────────────────+
```

---

### 1. Фізичний принцип безвтратного моніторингу DCR

У сильних перетворювачах живлення процесорів (струми 100–300 А) використання класичних вимірювальних шунтів (Current Sense Resistors) неприпустиме через катастрофічні втрати потужності:

```
P_loss = I² · R_shunt
```

Навіть ультранизькоомний шунт опором 0.5 мОм при струмі однієї фази 40 А розсіює:

```
P_loss = (40 А)² · 0.0005 Ом = 0.80 Вт
```

Для 8-фазного стабілізатора це означало б марне перетворення понад 6.4 Вт дорогоцінної енергії на тепло на самій лише вимірювальній частині плати.

Натомість використовують паразитичний опір мідного дроту самої силової котушки — **DCR** (англ. *DC Resistance*). Будь-який реальний дросель є послідовним з'єднанням ідеальної індуктивності `L` та активного опору мідної обмотки `DCR` (зазвичай від 0.15 мОм до 1.0 мОм).

Падіння напруги на реальній котушці в операторній формі становить:

```
V_L(s) = I_L(s) · (s·L + DCR)
```

Ця напруга містить як інформативну складову струму `DCR · I_L(s)`, так і паразитну реактивну ЕРС самоіндукції `s·L · I_L(s)`, яка заважає вимірюванню, створюючи величезні імпульсні сплески при кожному перемиканні ключів.

### 2. Паралельний RC-ланцюг та умова балансу постійних часу

Щоб виділити суто падіння на активному опорі `DCR`, паралельно силовому дроселю підключають пасивний фільтр низьких частот, що складається з резистора `R_s` та керамічного конденсатора `C_s`.

Напруга на вимірювальному конденсаторі `C_s` визначається дільником напруги:

```
V_Cs(s) = V_L(s) · (1 / (s·C_s)) / (R_s + 1 / (s·C_s))
        = V_L(s) / (1 + s·R_s·C_s)
```

Підставимо вираз для напруги котушки `V_L(s)`:

```
V_Cs(s) = I_L(s) · (s·L + DCR) / (1 + s·R_s·C_s)
        = I_L(s) · DCR · (1 + s · (L / DCR)) / (1 + s · (R_s · C_s))
```

Погляньмо на дріб: у чисельнику стоїть нуль передатної функції з постійною часу `τ_L = L / DCR`, а в знаменнику — полюс із постійною часу `τ_RC = R_s · C_s`.

Якщо розрахувати номінали компонентів так, щоб постійні часу збіглися:

```
R_s · C_s = L / DCR
```

тоді чисельник і знаменник скорочуються начисто при будь-якій частоті `s`:

```
(1 + s · (L / DCR)) / (1 + s · (R_s · C_s)) = 1
```

У результаті напруга на конденсаторі `C_s` стає прямо пропорційною миттєвому струму котушки в часовій області без будь-якої фазової затримки чи викривлення форми хвилі:

```
v_Cs(t) = DCR · i_L(t)
```

Конденсатор `C_s` ідеально відтворює як постійну складову струму фази, так і високочастотну трикутну пилку пульсацій без застосування додаткових операційних підсилювачів.

### 3. Наслідки розбалансу постійних часу (τ_RC ≠ τ_L)

У реальному виробництві номінали компонентів мають технологічний розкид: індуктивність `L` має допуск `±10–20%`, опір `DCR` — `±7–10%`, керамічний конденсатор `C_s` (типу X7R) — `±10%`, резистор `R_s` — `±1%`.

Розглянемо два випадки порушення балансу:

```
+──────────────────────────────────────────────────────────────────────────────+
│                      ВПЛИВ РОЗБАЛАНСУ RC-ФІЛЬТРА НА СЕНСИНГ                  │
│                                                                              │
│   Випадок 1: R_s·C_s < L/DCR (Недодемпфований / Швидкий)                     │
│   • Наслідок: Диференціювання стрибка, хибний викид V_Cs при накиданні       │
│   • Ефект у VRM: Зайвий динамічний спад напруги VCore (зайве просідання)     │
│                                                                              │
│   Випадок 2: R_s·C_s > L/DCR (Передемпфований / Повільний)                    │
│   • Наслідок: Інтегрування сигналу, затримка реакції V_Cs на стрибок струму  │
│   • Ефект у VRM: Запізнілий спад напруги, ризик пробою VCore при скиданні    │
+──────────────────────────────────────────────────────────────────────────────+
```

1. **`R_s · C_s < L / DCR` (Under-filtered / High-pass response):**
   Нуль чисельника розташований на нижчій частоті, ніж полюс знаменника. Передатна функція має підйом на високих частотах. При раптовому стрибку струму навантаження напруга `V_Cs` дає штучний викид амплітуди. VRM-контролер «думає», що струм зріс більше, ніж насправді, і занадто сильно просаджує вихідну напругу, порушуючи нижню межу `V_min`.

2. **`R_s · C_s > L / DCR` (Over-filtered / Low-pass response):**
   Полюс знаменника спрацьовує раніше, ніж нуль. Сигнал струму згладжується і запізнюється в часі. Контур активного спаду реагує повільно, через що навантажувальна пряма не встановлюється миттєво, а вихідна напруга ядра зазнає небажаного коливального процесу.

### 4. Температурний коефіцієнт міді та проблема теплового дрейфу

Головним недоліком DCR-моніторингу є сильна залежність питомого опору міді від температури. Температурний коефіцієнт опору міді (TCR) становить:

```
α_Cu ≈ +0.00393 / °C  (+3930 ppm/K при 20 °C)
```

Залежність опору дроселя від температури `T` описується лінійним законом:

```
DCR(T) = DCR_25 · (1 + α_Cu · (T - 25 °C))
```

Під час роботи сучасного процесора під навантаженням силова котушка VRM нагрівається від кімнатної температури (25 °C) до робочої (95–105 °C). Розрахуємо зміну опору:

```
DCR(100 °C) = DCR_25 · (1 + 0.00393 · 75 °C) = 1.295 · DCR_25
```

Опір міді зростає майже на **30%**!

Якщо цю зміну не скомпенсувати, виміряна напруга `V_Cs = DCR(T) · I_L` при тій самій реальній силі струму буде на 30% більшою на гарячій платі. Контролер сформує надмірний спад напруги:

```
R_LL_hot = 1.30 · R_LL_nominal
```

При струмі 150 А і номінальному `R_LL = 1.0 мОм` розрахунковий спад має становити 150 мВ, але на гарячій платі він зросте до 195 мВ. Зайві 45 мВ просідання виведуть напругу ядра далеко за нижню межу `V_min`, викликавши апаратне зависання або аварійне вимкнення процесора (Kernel Panic / BSOD).

### 5. Схемотехніка NTC-термокомпенсації

Для повної нейтралізації температурного дрейфу застосовують терморезистори з негативним температурним коефіцієнтом опору — **NTC** (англ. *Negative Temperature Coefficient*).

Опір NTC-термістора спадає з ростом температури за експоненційним законом Стейнхарта-Харта (або рівнянням B-параметра):

```
R_ntc(T) = R_ntc_25 · exp(B · (1 / T - 1 / T_0))
```

де `T` та `T_0` — абсолютні температури в Кельвінах (`T_0 = 298.15 К`), `B` — константа чутливості матеріалу (зазвичай `B = 3400–4200 К`).

Оскільки опір міді зростає приблизно лінійно (+0.39%/°C), а опір NTC спадає експоненційно (приблизно −4...−5%/°C), голий NTC підключати не можна: він перекомпенсує схему. Його лінеаризують за допомогою додаткових постійних прецизійних резисторів.

Типова схема лінеаризованого NTC-дільника складається з паралельного резистора `R_p`, послідовного резистора `R_s2` та терморезистора `R_ntc`:

```
R_ntc_eq(T) = R_s2 + (R_p · R_ntc(T)) / (R_p + R_ntc(T))
```

Цей еквівалентний блок включається в коло передачі виміряного сигналу до підсилювача сумування струму (Current Sense Amplifier):

```
V_droop(T) = V_Cs(T) · G_ntc(T)
           = [DCR_25 · (1 + α_Cu · ΔT) · i_L] · [K_div / (1 + α_ntc_eff · ΔT)]
```

Підбираючи номінали `R_p`, `R_s2` та `R_ntc_25`, інженери досягають умови:

```
(1 + α_Cu · ΔT) · G_ntc(T) ≈ const      [у робочому діапазоні 25 °C ... 105 °C]
```

Завдяки цьому результуючий коефіцієнт навантажувальної прямої `R_LL` залишається абсолютно стабільним із похибкою менше `±1.5%` у всьому діапазоні нагріву материнської плати.

### 6. Сумування струмів фаз та придушення пульсацій

У багатофазному перетворювачі контролер повинен знати сумарний струм усіх `N` фаз для формування єдиного спаду напруги `VCore`.

Для цього використовують схему сумування на віртуальній землі (Virtual Ground Current Summing Network). Від кожного вимірювального конденсатора `C_s,k` через сумуючий резистор `R_sum` струмовий сигнал заводиться в спільний вузол `CS_SUM`:

```
i_sum(t) = Σ [ (v_Cs,k(t) - VCore) / R_sum ]
         = (DCR / R_sum) · Σ i_L,k(t)
         = (DCR / R_sum) · I_total(t)
```

Оскільки фази перетворювача зсунуті за тактом на кут `360° / N`, високочастотні трикутні пульсації струмів окремих фаз взаємно компенсуються в суматорі. Результуючий сигнал сумарного струму `I_total` має пульсації у `N` разів меншої амплітуди та в `N` разів вищої частоти, що забезпечує ідеальну чистоту сигналу керування без внесення додаткових затримок фільтрації.

### 8. Покроковий числовий розрахунок компонентів для реальної фази VRM

Проведемо інженерний розрахунок сенсорного ланцюга для однієї фази багатофазного стабілізатора VRM14 сервера на процесорі Intel Xeon або AMD EPYC:

**Вихідні дані:**
- Індуктивність силового дроселя: `L = 220 нГн` (0.22 мкГн)
- Опір обмотки котушки при 25 °C: `DCR = 0.28 мОм` (0.00028 Ом)
- Максимальний струм фази: `I_phase_max = 40 А`
- Робоча температура дроселя: `T_max = 100 °C`

**Крок 1. Розрахунок постійної часу котушки:**

```
τ_L = L / DCR
    = (220 · 10⁻⁹ Гн) / (0.28 · 10⁻³ Ом)
    = 7.857 · 10⁻⁴ с ≈ 785.7 мкс
```

**Крок 2. Вибір вимірювального конденсатора C_s:**
Обираємо прецизійний керамічний конденсатор діелектрика X7R або C0G ємністю `C_s = 0.47 мкФ` (470 нФ), щоб забезпечити високу завадостійкість від імпульсних наведень комутації.

**Крок 3. Розрахунок резистора R_s:**

```
R_s = τ_L / C_s
    = (785.7 · 10⁻⁶ с) / (0.47 · 10⁻⁶ Ф)
    = 1671.7 Ом
```

Обираємо найближчий стандартний номінал резистора з ряду E96 точністю 1%: `R_s = 1.69 кОм`.

**Крок 4. Розрахунок розмаху вимірюваного сигналу:**

```
V_Cs_max = I_phase_max · DCR
         = 40 А · 0.28 мОм = 11.20 мВ
```

**Крок 5. Розрахунок термічної мережі компенсації NTC:**
При нагріві до 100 °C опір `DCR` зростає до:

```
DCR(100 °C) = 0.28 мОм · (1 + 0.00393 · (100 - 25)) = 0.3625 мОм
```

Для компенсації зростання сигналу на 29.5% застосовується терморезистор NTC номіналом `10 кОм` (B = 3950 К) у паралель із шунтуючим резистором `R_p = 1.82 кОм` та послідовним резистором `R_s2 = 4.75 кОм`. Такий дільник зменшує свій коефіцієнт передачі рівно в 1.295 раза при зростанні температури від 25 °C до 100 °C, гарантуючи постійну амплітуду струмового сигналу.

### 9. Лабораторна діагностика та осцилографічне калібрування

На етапі налагодження прототипу плати правильність узгодження RC-ланцюга перевіряють за допомогою осцилографа з диференційним щупом, підключеним безпосередньо до виводів конденсатора `C_s`, під час імпульсного накидання навантаження електронним навантажувачем:

1. **Ідеальне налаштування (`R_s · C_s = L / DCR`):**
   Форма сигналу напруги `V_Cs(t)` є ідеальною прямокутною сходинкою, що точно повторює огинаючу струму навантаження з накладеними дрібними трикутними пульсаціями комутації.
2. **Перекомпенсація / повільний відгук (`R_s · C_s > L / DCR`):**
   Напруга на `C_s` повільно наростає за експонентою з заваленим переднім фронтом. Необхідно зменшити номінал резистора `R_s`.
3. **Недокомпенсація / імпульсний викид (`R_s · C_s < L / DCR`):**
   На передньому фронті виникає гострий трикутний сплеск перенапруги (overshoot). Необхідно збільшити номінал резистора `R_s`.

Тільки після досягнення ідеальної прямокутної форми сигналу на всіх фазах стабілізатора дозволяється вмикати процесор і проводити фінальну верифікацію навантажувальної прямої AVP.

### 10. Правила трасування друкованої плати (PCB Layout)

Точність DCR-сенсингу критично залежить від топології мідних доріжок друкованої плати. Вимірювані напруги становлять одиниці мілівольтів (наприклад, при `DCR = 0.28 мОм` і струмі 40 А сигнал становить лише 11.2 мВ).

Головні правила трасування чутливого контуру:

1. **Чотирипровідне підключення Кельвіна (Kelvin Sensing):**
   Вимірювальні провідники повинні підключатися безпосередньо до внутрішніх контактних майданчиків силового дроселя, а не до силових полігонів. Струм навантаження не повинен протікати через вимірювальні перехідні отвори (vias).
2. **Диференціальна пара (Differential Routing):**
   Доріжки від вузла `SW` та вузла `VCore` ведуться строго паралельною парою з мінімальним зазором на внутрішньому шарі плати між двома суцільними площинами землі (GND planes). Це екранує сигнал від колосальних імпульсних наведень `dv/dt` силового вузла `SW` (швидкість наростання понад 10–20 В/нс).
3. **Розміщення компонентів RC-фільтра та NTC:**
   Конденсатор `C_s` та резистор `R_s` повинні розташовуватися максимально близько до виводів контролера VRM, а не біля дроселя. Це мінімізує довжину низькоімпедансної лінії, схильної до наведень.
4. **Теплове спряження NTC-термістора:**
   Терморезистор NTC повинен бути фізично розміщений упритул до корпусу найгарячішої котушки індуктивності (зазвичай це центральні фази стабілізатора) і з'єднаний із її силовим полігоном широким теплопровідним мідним острівцем для мінімізації теплової інерції (Thermal Lag).
