# 🧮 Фізико-математичний розрахунок кабельних обмежень: зарядні струми, скін-ефект і точка беззбитковості

Перевага передачі електроенергії постійним струмом високої напруги *(HVDC)* над трифазним змінним струмом *(HVAC)* на великих відстанях спирається на фундаментальні рівняння електродинаміки Максвелла та термодинамічні обмеження провідників. У лініях змінного струму змінне в часі електромагнітне поле безперервно перезаряджає розподілену ємність діелектрика, витісняє носії заряду до країв жили та збуджує стоячі хвилі напруги, тоді як постійне поле передає енергію в чистому квазістатичному режимі.

Строгий математичний апарат розкриває фізику цих явищ: від формул ємнісного витоку в коаксіальній геометрії до рівнянь телеграфної лінії та моделі точки економічної рівноваги.

### 1. Ємність силового кабелю та зарядний струм

Високовольтний підводний або підземний кабель конструктивно є коаксіальним циліндричним конденсатором: центральна струмопровідна жила радіусом `r_inner` оточена суцільним шаром твердої діелектричної ізоляції (зшитий поліетилен XLPE з відносною діелектричною проникністю `eps_r ≈ 2.3...2.5`) та заземленим металевим екраном внутрішнім радіусом `r_outer`.

Погонна електрична ємність такого кабелю на одиницю довжини визначається інтегруванням напруженості радіального електричного поля `E(r) = q / (2πε₀ε_r · r)` за теоремою Гауса:

```
C_km = (2 · π · ε₀ · ε_r) / ln(r_outer / r_inner) · 10³   [погонна ємність кабелю, Ф/км]
```

Для типового підводного трифазного кабелю 400 кВ (переріз жили 2000 мм², `r_inner = 21.2 мм`, товщина ізоляції `d = 25 мм`, `r_outer = 46.2 мм`, `ε_r = 2.3`):

```
C_km = (2 · π · 8.854·10⁻¹² · 2.3) / ln(46.2 / 21.2) · 10³   [підстановка параметрів кабелю]
     = 1.279·10⁻¹⁰ / ln(2.179) · 10³                          [обчислення чисельника і відношення радіусів]
     = 1.279·10⁻¹⁰ / 0.7788 · 10³                             [обчислення натурального логарифма]
     ≈ 0.164·10⁻⁶ Ф/км = 0.164 мкФ/км                         [результуюча ємність діелектрика]
```

З урахуванням напівпровідних екрануючих шарів реальна погонна ємність силових кабелів 400 кВ становить `C_km ≈ 0.20...0.25 мкФ/км` (у 20–30 разів вище за ємність повітряної ЛЕП).

У мережі змінного струму фазна напруга змінюється гармонійно: `v(t) = V_ph_max · sin(ωt) = √2 · V_ph · sin(ωt)`.

Кожен метр кабелю є конденсатором, що неперервно перезаряджається між жилою та землею. Погонний ємнісний зарядний струм на один кілометр становить:

```
i_c(t) = C_km · (d v(t) / dt)             [струм зміщення крізь діелектрик]
I_c_km = ω · C_km · V_ph                  [діюче значення зарядного струму на км]
```

Для кабельної лінії загальною довжиною `L` струм навантаження від споживача тече крізь жилу разом із наростаючим зарядним струмом. Оскільки напруга розподілена практично рівномірно по довжині, сумарний зарядний струм, який мусить пропустити жила кабелю на вході з підстанції, дорівнює:

```
I_c_total = ω · C_km · V_ph · L           [сумарний зарядний струм лінії]
```

Оскільки ємнісний струм випереджає фазну напругу на кут 90° (чисто реактивний струм), а струм корисного активного навантаження `I_active` збігається за фазою з напругою (при `cos(phi) = 1`), повний струм на вході кабелю визначається геометричною сумою векторів:

```
I_total = √(I_active² + I_c_total²)       [повний струм жили на початку лінії]
```

### 2. Вивід критичної довжини кабелю змінного струму

Будь-який силовий провідник має суворе термодинамічне обмеження за допустимим нагріванням ізоляції струмом, що протікає крізь його опір: `I_total ≤ I_thermal` (де `I_thermal` — тривало допустимий струм жили за стандартом IEC 60287).

Якщо довжина кабелю `L` зростає, зарядний струм `I_c_total` лінійно збільшується, займаючи все більшу частку доступного теплового бюджету кабелю. Доступний корисний активний струм, який кабель може передати споживачеві, неминуче падає:

```
I_active = √(I_thermal² - (ω · C_km · V_ph · L)²)  [корисний струм передачі]
```

**Критичною довжиною кабелю** `L_crit` називають таку довжину лінії, за якої зарядний струм поодинці досягає 100% номінального теплового струму кабелю (`I_c_total = I_thermal`). За такої довжини передача корисної енергії стає фізично неможливою (`I_active = 0`): кабель перегрівається та виходить з ладу виключно від заряджання власної ємності.

Прирівняємо `I_c_total` до `I_thermal` і виразимо `L_crit`:

```
ω · C_km · V_ph · L_crit = I_thermal      [умова вичерпання струму]
L_crit = I_thermal / (ω · C_km · V_ph)    [формула критичної довжини]
```

Обчислимо `L_crit` для типового трифазного підводного кабелю 400 кВ:
- Номінальна міжфазна напруга: `V_LL = 400 кВ` -> Фазна напруга `V_ph = 400 / √3 ≈ 230.94 кВ`.
- Погонна ємність: `C_km = 0.22 мкФ/км = 0.22·10⁻⁶ Ф/км`.
- Кутова частота при 50 Гц: `ω = 2 · π · 50 ≈ 314.16 рад/с`.
- Граничний тепловий струм мідної жили перерізом 2000 мм²: `I_thermal = 1200 А`.

```
L_crit = 1200 / (314.16 · 0.22·10⁻⁶ · 230940)  [підстановка значень]
       = 1200 / 15.96                          [знаменник: погонний зарядний струм 15.96 А/км]
       ≈ 75.2 км                               [гранична фізична довжина]
```

Розрахуємо корисну пропускну здатність кабелю при різній довжині траси:
- При довжині `L = 25 км`: `I_c_total = 15.96 · 25 = 399 А`. Залишковий корисний струм `I_active = √(1200² - 399²) = 1131 А` (втрата 5.7% пропускної здатності).
- При довжині `L = 50 км`: `I_c_total = 15.96 · 50 = 798 А`. Залишковий корисний струм `I_active = √(1200² - 798²) = 896 А` (втрата 25.3% пропускної здатності).
- При довжині `L = 70 км`: `I_c_total = 15.96 · 70 = 1117 А`. Залишковий корисний струм `I_active = √(1200² - 1117²) = 438 А` (втрата 63.5% пропускної здатності).
- При довжині `L = 75.2 км`: `I_c_total = 1200 А` і корисний струм `I_active = 0 А` (кабель заблокований власним ємнісним струмом).

У лінії постійного струму HVDC частота дорівнює нулю (`f = 0`, `ω = 0`), тому `I_c = 0`. Кабель HVDC передає повний активний струм 1200 А на будь-яку відстань (100, 500 чи 1000 км).

### 3. Скін-ефект та збільшення активного опору в AC

Змінний струм високої сили збуджує всередині провідника змінне магнітне поле, яке за законом Фарадея створює вихрові струми. Ці струми спрямовані назустріч основному струму в серцевині провідника і співнапрямлені з ним біля зовнішньої поверхні.

Розподіл густини струму `J(r)` по радіусу суцільного циліндричного провідника описується диференціальним рівнянням у циліндричних координатах через функції Бесселя першого роду нульового порядку `J₀`:

```
d²J / dr² + (1/r) · (dJ / dr) - j · ω · μ · σ · J = 0   [рівняння дифузії поля в провіднику]
```

Глибина проникнення електромагнітного поля (товщина скін-шару `delta`), на якій густина струму спадає в `e ≈ 2.718` раза порівняно з поверхнею:

```
δ = √(ρ / (π · f · μ₀ · μ_r))                 [глибина скін-шару]
```

Обчислимо глибину скін-шару для міді на промисловій частоті 50 Гц:

```
δ = √(1.72·10⁻⁸ / (π · 50 · 4π·10⁻⁷ · 1))   [підстановка параметрів міді та частоти 50 Гц]
  = √(1.72·10⁻⁸ / 1.974·10⁻⁴)               [обчислення добутку в знаменнику]
  = √(8.71·10⁻⁵)                            [ділення під коренем]
  ≈ 0.00933 м = 9.33 мм                     [добування квадратного кореня]
```

Для потужного кабелю або проводу повітряної ЛЕП великого перерізу `S = 2000 мм²` радіус суцільної жили становить `r = √(S / π) = √(2000 / 3.1416) ≈ 25.2 мм`.

Оскільки радіус жили `r = 25.2 мм` майже втричі перевищує глибину проникнення поля `delta = 9.33 мм`, серцевина провідника виявляється практично знеструмленою.

Згідно з методикою IEC 60287, опір жили змінному струму `R_ac` розраховується через опір постійному струму `R_dc` з урахуванням фактора скін-ефекту `y_s`:

```
R_ac = R_dc · (1 + y_s)                   [активний опір провідника в AC]

де:
x_s = (8·π·f / (R_dc · 10³)) · k_s        [безрозмірний аргумент Бесселя]
y_s = x_s⁴ / (192 + 0.8 · x_s⁴)           [коефіцієнт збільшення опору]
```

Для жили перерізом 2000 мм² на частоті 50 Гц фактор `y_s ≈ 0.20...0.28`. Це означає зростання опору жили:

```
R_ac ≈ 1.25 · R_dc                        [опір AC вищий на 25%]
```

При однаковому передаваному струмі `I` теплові втрати Джоуля–Ленца в змінному струмі зростають пропорційно опору:

```
P_loss_AC = I² · R_ac                     [втрати Джоуля-Ленца в AC]
          = I² · (1.25 · R_dc)            [підстановка активного опору AC]
          = 1.25 · P_loss_DC              [втрати AC на 25% вищі за DC]
```

### 4. Діелектричні втрати в ізоляції кабелю

Окрім втрат Джоуля–Ленца в металевій жилі, кабель змінного струму зазнає постійного нагрівання в самому шарі діелектрика через явище діелектричного гістерезису при періодичній переполяризації диполів полімеру.

Потужність діелектричних втрат на одиницю довжини кабелю змінного струму розраховується через тангенс кута діелектричних втрат `tan(delta_d)`:

```
P_diel_AC = ω · C_km · V_ph² · tg(δ_d)    [діелектричні втрати в AC, Вт/км]

де:
ω = 314.16 рад/с (для 50 Гц),
C_km — погонна ємність кабелю (Ф/км),
V_ph — фазна напруга (В),
tg(δ_d) — тангенс кута втрат матеріалу ізоляції (для XLPE tg(δ_d) ≈ 4·10⁻⁴, для паперово-оливної ізоляції MI tg(δ_d) ≈ 3·10⁻³).
```

Для кабелю 400 кВ (`V_ph = 230.9 кВ`, `C_km = 0.22 мкФ/км`) з ізоляцією XLPE діелектричні втрати становлять:

```
P_diel_AC = 314.16 · 0.22·10⁻⁶ · (230940)² · 4·10⁻⁴   [підстановка параметрів 400 кВ XLPE]
          = 314.16 · 0.22·10⁻⁶ · 5.333·10¹⁰ · 4·10⁻⁴   [піднесення фазної напруги до квадрата]
          = 1474 Вт/км = 1.47 кВт/км                   [питомі діелектричні втрати на одну фазу]
```

Для трифазної лінії з трьох кабелів довжиною 100 км сумарні діелектричні втрати лише в ізоляції становлять:

```
P_diel_total = 3 · 1.474 кВт/км · 100 км = 442.2 кВт ≈ 0.44 МВт   [сумарні втрати ізоляції]
```

Ці 442 кВт тепла виділяються всередині ізоляції безперервно, навіть коли лінія працює в режимі холостого ходу без передачі корисної енергії споживачам.

У кабелі постійного струму HVDC переполяризація диполів відсутня (`f = 0` -> `omega = 0`). Діелектричні втрати зводяться виключно до мізерного струму витоку крізь об'ємний опір ізоляції `R_insulation ≈ 10¹⁴...10¹⁶ Ом·м`:

```
P_diel_DC = V_dc² / R_insulation ≈ 0.01...0.05 Вт/км   [втрати витоку в DC]
```

Відсутність внутрішнього діелектричного саморозігріву в системі HVDC дозволяє експлуатувати кабель при вищій напруженості електричного поля (до 20–30 кВ/мм проти 10–15 кВ/мм в AC) та зменшити необхідну товщину ізоляції на 30–40%.

### 5. Ефект Ферранті та зростання напруги в ненавантаженій лінії AC

Ще одним важким наслідком взаємодії розподіленої ємності та індуктивності в лініях змінного струму є **ефект Ферранті** *(Ferranti effect, на честь британського інженера Себастьяна де Ферранті)* — явище зростання напруги в кінці довгої лінії при її холостому ході або малому навантаженні (`V_receive > V_send`).

Розглянемо довгу лінію як ланцюг із розподіленою поздовжньою індуктивністю `L_km` (Гн/км) та поперечною ємністю `C_km` (Ф/км). Запишемо диференціальні телеграфні рівняння для усталеного синусоїдного режиму:

```
dV(x) / dx = -j · ω · L_km · I(x)          [падіння напруги на індуктивності]
dI(x) / dx = -j · ω · C_km · V(x)          [витік струму крізь ємність]
```

Продиференціюємо перше рівняння по `x` і підставимо друге:

```
d²V(x) / dx² = -j·ω·L_km · (-j·ω·C_km · V(x))   [підстановка другого рівняння]
             = -ω² · L_km · C_km · V(x)         [спрощення коефіцієнтів]
             = -β² · V(x)                       [хвильове рівняння напруги]

де:
β = ω · √(L_km · C_km) = 2π / λ                [коефіцієнт фази / хвильове число]
```

Для лінії довжиною `l` у режимі холостого ходу на кінці (`I(l) = 0`) розв'язок має вигляд:

```
V(x) = V_receive · cos(β · (l - x))            [розподіл напруги вздовж лінії]
```

Напруга на початку лінії (`x = 0`) пов'язана з напругою в кінці (`x = l`) співвідношенням:

```
V_send = V_receive · cos(β · l)                [зв'язок напруги на краях лінії]
V_receive = V_send / cos(β · l)                [напруга в кінці ненавантаженої лінії]
```

Розкладемо `cos(beta * l)` у ряд Тейлора для ліній, де `beta * l << 1` (довжина лінії менша за чверть довжини хвилі `lambda/4 = 1500 км` при 50 Гц):

```
cos(β · l) ≈ 1 - (β · l)² / 2                  [розклад косинуса в ряд Тейлора]
V_receive ≈ V_send / (1 - (β · l)² / 2)        [наближення в знаменнику]
          ≈ V_send · (1 + (β · l)² / 2)        [наближення для малого аргументу]
ΔV = V_receive - V_send                        [абсолютне зростання напруги]
   ≈ V_send · (ω² · L_km · C_km · l²) / 2      [підвищення напруги ефекту Ферранті]
```

#### Розрахунок зростання напруги для повітряної ЛЕП 750 кВ

Для повітряної лінії 750 кВ фазова швидкість електромагнітної хвилі близька до швидкості світла: `v = 1 / √(L_km · C_km) ≈ 300 000 км/с`. Хвильове число для частоти 50 Гц:

```
β = 2 · π · 50 / 300 000 ≈ 1.047 · 10⁻³ рад/км   [хвильове число для 50 Гц]
```

Порахуємо напругу на кінці ненавантаженої лінії для різної довжини:

```
Довжина l = 300 км:
  β · l = 1.047·10⁻³ · 300 = 0.314 рад (18.0°)
  cos(β · l) = cos(18.0°) ≈ 0.951
  V_receive = 750 кВ / 0.951 ≈ 788 кВ (зростання на +38 кВ)

Довжина l = 600 км:
  β · l = 1.047·10⁻³ · 600 = 0.628 рад (36.0°)
  cos(β · l) = cos(36.0°) ≈ 0.809
  V_receive = 750 кВ / 0.809 ≈ 927 кВ (небезпечне зростання на +177 кВ, +23.6%)

Довжина l = 900 км:
  β · l = 1.047·10⁻³ · 900 = 0.942 рад (54.0°)
  cos(β · l) = cos(54.0°) ≈ 0.588
  V_receive = 750 кВ / 0.588 ≈ 1275 кВ (катастрофічне зростання на +525 кВ, +70%)
```

Зростання напруги на 70% призводить до електричного перекриття ізоляторів, руйнування вимикачів та вибуху трансформаторів. Щоб уникнути цього в лініях HVAC довжиною понад 400 км, енергетики встановлюють дорогі **шунтові реактори** *(Shunt Reactors)* — гігантські трифазні індуктивності, які спалюють ємнісний струм на землю.

У лінії HVDC `omega = 0` -> `beta = 0` -> `cos(0) = 1`. Ефект Ферранті відсутній у принципі: напруга вздовж лінії постійного струму на холостому ході залишається абсолютно стабільною і не залежить від довжини траси.

### 6. Обмеження кутової синхронної стійкості в мережах змінного струму

У трифазній мережі змінного струму передавана активна потужність між двома енерговузлами з напругами `V_1` та `V_2` жорстко обмежена поздовжнім індуктивним опором лінії `X_line = omega * L_line` та фазовим кутом зсуву синусоїд `delta`:

```
P = (V₁ · V₂ / X_line) · sin(δ)           [формула передачі потужності AC]
```

Залежність потужності від кута `delta` має критичний максимум при `delta = 90°`:

```
P_max = (V₁ · V₂ / X_line)                [гранична статична стійкість лінії]
```

Оскільки індуктивний опір лінії прямо пропорційний її довжині `l` (`X_line = ω · L_km · l`), гранична пропускна здатність лінії HVAC обернено пропорційна відстані:

```
P_max(l) = (V₁ · V₂) / (ω · L_km · l)     [падіння пропускної здатності з відстанню]
```

Для забезпечення динамічної стійкості енергосистеми під час раптових коливань навантаження та коротких замикань робочий кут `delta` ніколи не вибирають понад 30–35° (`sin(30°) = 0.5`). Тобто реальна передавана потужність становить не більше половини від теоретичного максимуму:

```
P_safe ≤ 0.5 · P_max                      [безпечна межа за динамічною стійкістю]
       = (V₁ · V₂) / (2 · ω · L_km · l)   [розрахунок допустимої потужності]
```

Для лінії 500 кВ з типовою індуктивністю `L_km = 1.0 мГн/км` (`X_km = 314.16 · 10⁻³ ≈ 0.314 Ом/км`):
- На відстані `l = 200 км`: `X_line = 62.8 Ом` і `P_safe ≈ (500·10³)² / (2 · 62.8) ≈ 1990 МВт`.
- На відстані `l = 600 км`: `X_line = 188.5 Ом` і `P_safe ≈ (500·10³)² / (2 · 188.5) ≈ 663 МВт` (пропускна здатність впала втричі!).
- На відстані `l = 1000 км`: `X_line = 314.2 Ом` і `P_safe ≈ (500·10³)² / (2 · 314.2) ≈ 398 МВт` (лінія практично непридатна для передачі гігаватів).

У лінії HVDC передавана потужність визначається виключно законом Ома для постійного струму і не залежить від фазового кута:

```
P_dc = V_dc · I_dc                        [потужність постійного струму]
     = V_dc · ((V_rect - V_inv) / R_dc)  [розрахунок струму за різницею напруг]
```

Напруга та струм регулюються електронно за мілісекунди зміною кутів відкриття тиристорів або шириною модуляції IGBT. Лінія HVDC не має поняття «кута стійкості» і здатна передавати 100% номінальної теплової потужності провідників на будь-яку відстань (хоч 3000 км) без жодних проміжних компенсаційних підстанцій.

### 7. Густина передачі потужності в смузі відчуження (Right-of-Way)

Порівняємо необхідну смугу землі для прокладання траси повітряної лінії передачі потужності 3000 МВт:

1. **Варіант HVAC 500 кВ:**
   - Для передачі 3000 МВт з урахуванням обмеження кута стійкості потрібні **дві паралельні дволанцюгові лінії 500 кВ** (разом 4 трифазні кола, тобто 12 високовольтних фазних проводів).
   - Ширина смуги відчуження землі для кожної дволанцюгової опори становить близько 50 м. Між лініями потрібен розрив безпеки 40 м.
   - Загальна ширина коридору: `50 + 40 + 50 = 140 м`.
   - Маса металу опор: близько 80–100 тонн на кілометр траси.

2. **Варіант HVDC ±500 кВ:**
   - Для передачі 3000 МВт достатньо **однієї біполярної лінії ±500 кВ** (лише 2 провідники: позитивний +500 кВ і негативний −500 кВ при струмі 3000 А).
   - Опора HVDC значно компактніша, має Т-подібну форму без середньої фази.
   - Ширина смуги відчуження становить лише **45–50 м**.
   - Маса металу опор: близько 35–45 тонн на кілометр траси (економія металу понад 50%).

```
Густина потужності на метр ширини коридору землі:
  HVAC 500 кВ:  3000 МВт / 140 м = 21.4 МВт/м
  HVDC ±500 кВ: 3000 МВт / 50 м  = 60.0 МВт/м (у 2.8 раза вища ефективність землі!)
```

### 8. Математична модель точки економічної рівноваги (Break-even Distance)

Сумарна вартість життєвого циклу лінії електропередачі складається з капітальних витрат на спорудження станцій *(CAPEX)*, витрат на будівництво самої траси та вартості втрат електроенергії за період експлуатації *(OPEX)*:

```
C_total(L) = C_stations + (C_line + C_losses) · L   [сумарна вартість життєвого циклу лінії]

де:
C_stations — вартість кінцевих підстанцій (фіксована складова),
C_line     — вартість спорудження одного кілометра лінії (опори, кабелі, відведення землі),
C_losses   — капіталізована вартість втрат енергії I²R на 1 км траси,
L          — загальна довжина траси в кілометрах.
```

Запишемо функції сумарної вартості для систем HVAC та HVDC:

```
C_HVAC(L) = 2·C_substation_AC + (C_line_AC + C_loss_AC) · L   [вартість лінії змінного струму]
C_HVDC(L) = 2·C_converter_DC  + (C_line_DC + C_loss_DC) · L   [вартість лінії постійного струму]
```

Співвідношення між складовими:
1. **Підстанції:** Перетворювальні підстанції HVDC (з тиристорними або IGBT-вентилями, реакторами, системами водяного охолодження та автоматикою) у 3–5 разів дорожчі за звичайні підстанції змінного струму: `C_converter_DC >> C_substation_AC`.
2. **Лінія:** Лінія HVDC потребує лише 2 провідники (+ та −) замість 3 фаз HVAC (A, B, C). Опори HVDC компактніші, легші на 30–40%, смуга відчуження землі *(Right-of-Way)* вужча на 40%, а вартість ізоляторів менша: `C_line_DC < C_line_AC`.
3. **Втрати:** Завдяки відсутності скін-ефекту та відсутності реактивних зарядних струмів питомі втрати в лінії DC помітно нижчі: `C_loss_DC < C_loss_AC`.

Точка економічної рівноваги `L_breakeven` — це довжина траси, на якій сумарні витрати обох варіантів зрівнюються (`C_HVAC(L_breakeven) = C_HVDC(L_breakeven)`):

```
2·C_sub_AC + (C_line_AC + C_loss_AC)·L_be = 2·C_conv_DC + (C_line_DC + C_loss_DC)·L_be   [рівність сумарних витрат]
2·(C_conv_DC - C_sub_AC) = [(C_line_AC + C_loss_AC) - (C_line_DC + C_loss_DC)] · L_be     [групування доданків]
L_breakeven = 2·(C_conv_DC - C_sub_AC) / (ΔC_line + ΔC_losses)                             [формула точки беззбитковості]
```

де:
- Чисельник `2·(C_conv_DC - C_sub_AC)` — це додаткові капітальні витрати на перетворювальне обладнання HVDC.
- Знаменник `(ΔC_line + ΔC_losses)` — це питома економія на кожному кілометрі траси HVDC завдяки дешевшим опорам, меншій кількості проводів та меншим втратам енергії.

#### Підсумок граничних значень:
- **Для повітряних ЛЕП:** `ΔC_line` становить близько 15–25% від вартості ЛЕП AC. Точка рівноваги настає на відстані **600–800 км**. На відстанях понад 800 км економія на проводах, опорах і втратах перекриває високу ціну перетворювачів, і HVDC стає економічно вигіднішим.
- **Для підводних і підземних кабелів:** Через високу ціну кабелів `ΔC_line` значна (потрібно 2 кабелі замість 3, а переріз жили використовується на 100% без реактивного баласту). Крім того, у кабелях HVAC довжиною понад 40–50 км виникає технічна необхідність будувати дорогі проміжні морські платформи компенсації реактивної потужності. Тому для кабелів точка рівноваги зміщується до **40–50 км**.
