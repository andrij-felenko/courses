# 🧮 Розрахунок енергії утримання та кривих SOA

Коли первинне джерело живлення зазнає аварії або в системну шину встановлюють нову електронну плату, перехідні процеси тривають від сотень наносекунд до десятків мілісекунд. Схема в цей час живиться виключно від запасеної енергії конденсаторів або розсіює надлишок потужності на кристалі силового польового транзистора. Без точного математичного розрахунку перехідних режимів система або перезавантажиться через просадку напруги нижче порогу вимикання (Brownout), або силовий ключ згорить через вихід за межі області безпечної роботи (Safe Operating Area, SOA).

Нижче наведено виведення інженерних співвідношень та покрокові числові розрахунки для ключових розрахункових задач резервування живлення: визначення утримувальної ємності шини під час комутації джерел, розрахунок корисної енергії суперконденсаторного накопичувача, аналіз теплового імпульсу й обмежень SOA у Hot-Swap контролерах, оцінка індуктивних викидів при надшвидкому відсіканні, виведення похибки розподілу струму, розрахунок надійності систем за марковськими моделями, аналіз стійкості контуру Share Bus, оцінка заряду зворотного відновлення та розрахунок ресурсу конденсаторів.

## 1. Ємність утримання шини під час комутації джерел живлення

Під час раптового відключення або короткого замикання основного джерела живлення виникає часова пауза комутації `t_trans`, упродовж якої обидва джерела фізично від'єднані від навантаження (інтервал Dead-time для виключення наскрізного струму між входами). Цей інтервал складається з часу реакції компаратора відмови `t_det` та часу розмикання/замикання силових ключів `t_sw`:

```
t_trans = t_det + t_sw
```

Увесь цей час навантаження споживає струм виключно за рахунок розряду вихідних конденсаторів шини `C_hold`. Напруга на шині падає від початкового номінального значення `V_nom` до кінцевого значення `V_end`, яке не повинно опускатися нижче мінімально допустимого порогу живлення цифрових мікросхем `V_min_allowed`.

### Випадок А: Навантаження з постійним струмом споживання (I_load = const)

Якщо навантаження живиться через лінійні регулятори або є резистивним, його струм можна вважати приблизно постійним. Виходимо з фундаментального диференціального рівняння ємності:

```
i(t) = C · (dv / dt)          [диференціальне рівняння струму ємності]
dq = C · dv                   [перетворення через заряд]
I_load · dt = C_hold · dv     [за умови I_load = const]
```

Інтегруємо ліву частину за часом від `0` до `t_trans`, а праву — за спадом напруги від `V_nom` до `V_min_allowed`:

```
∫ I_load dt = ∫ C_hold dv     [межі t: 0 -> t_trans; v: V_min_allowed -> V_nom]
I_load · t_trans = C_hold · (V_nom - V_min_allowed)
C_hold = (I_load · t_trans) / (V_nom - V_min_allowed)
```

### Випадок Б: Навантаження з постійною споживаною потужністю (P_load = const)

Сучасні цифрові вузли (процесори, пам'ять DDR, FPGA) живляться від вторинних імпульсних DC-DC перетворювачів (Point-of-Load, POL). Імпульсний стабілізатор підтримує сталу вихідну напругу і стале споживання навантаження `P_load`. Зі зниженням вхідної напруги `v(t)` на шині живлення вхідний струм перетворювача зростає за гіперболічним законом:

```
i(t) = P_load / v(t)
```

Складаємо диференціальне рівняння розряду ємності:

```
C_hold · (dv / dt) = -i(t)
C_hold · (dv / dt) = -P_load / v(t)
v(t) · dv = -(P_load / C_hold) · dt    [розділення змінних]
```

Інтегруємо ліву частину за напругою від `V_nom` до `V_min_allowed`, а праву частину за часом від `0` до `t_trans`:

```
∫ v dv = -(P_load / C_hold) · ∫ dt     [межі ліворуч: V_nom -> V_min; праворуч: 0 -> t_trans]
(1/2) · (V_min_allowed² - V_nom²) = -(P_load / C_hold) · t_trans
(1/2) · (V_nom² - V_min_allowed²) = (P_load · t_trans) / C_hold
C_hold = (2 · P_load · t_trans) / (V_nom² - V_min_allowed²)
```

### Покроковий приклад розрахунку Hold-up ємності

Серверний блок живить процесорну плату із сумарним споживанням `P_load = 600 Вт` від шини `V_nom = 12.0 В`. Мінімальна робоча напруга входу вторинних VRM-модулів становить `V_min_allowed = 10.2 В`. Час виявлення аварії та перемикання ключів `t_trans = 40 мкс`.

```
V_nom² = 12.0² = 144.0 В²
V_min_allowed² = 10.2² = 104.04 В²
Δ(V²) = 144.0 - 104.04 = 39.96 В²

C_hold = (2 · 600 Вт · 40 · 10⁻⁶ с) / 39.96 В²
C_hold = (48 · 10⁻³ Дж) / 39.96 В²
C_hold = 0.0012012 Ф = 1201 мкФ
```

З урахуванням зниження ємності керамічних конденсаторів під дією постійної напруги зміщення (DC Bias Effect, втрата до 40% номіналу для діелектрика X7R/X5R) та температурного запасу 20%, номінальна встановлена ємність банку повинна складати не менше:

```
C_nominal = C_hold / (0.60 · 0.80) = 1201 мкФ / 0.48 = 2502 мкФ
```

Обираємо 26 керамічних конденсаторів типорозміру 1210 номіналом `100 мкФ / 25 В`.

## 2. Розрахунок корисної енергії суперконденсаторного банку (EDLC)

Суперконденсатор накопичує електричний заряд на межі розділу фаз електрод-електроліт без хімічних реакцій. На відміну від електрохімічних акумуляторів, напруга на виводах суперконденсатора падає строго лінійно в процесі відбору заряду.

Для живлення фіксованого навантаження суперконденсатор працює в парі з імпульсним підвищувальним перетворювачем (Boost Converter), який стабілізує вихідну шину системи на рівні `V_sys`.

```
              ┌────────────────────────────────────────────────────────┐
              │           Енергетичні зони суперконденсатора           │
              ├────────────────────────┬───────────────────────────────┤
              │ 0 В ... V_min_boost    │ Недоступна залишкова енергія  │
              │ V_min_boost ... V_max  │ Корисна робоча енергія        │
              │ > V_max                │ Зона деградації електроліту   │
              └────────────────────────┴───────────────────────────────┘
```

Повна теоретична енергія, накопичена в еквівалентній ємності `C_eq` при заряджанні до `V_max`:

```
E_total = (1/2) · C_eq · V_max²
```

Перетворювач Boost припиняє роботу, коли вхідна напруга опускається нижче порогу вимикання його внутрішньої схеми керування `V_min_boost`. Залишкова невикористана енергія в накопичувачі:

```
E_residual = (1/2) · C_eq · V_min_boost²
```

Корисна енергія `E_usable`, передана в навантаження з урахуванням середнього коефіцієнта корисної дії підвищувального перетворювача `η_boost`:

```
E_usable = (E_total - E_residual) · η_boost
E_usable = (1/2) · C_eq · (V_max² - V_min_boost²) · η_boost
```

Час гарантованої підтримки живлення `t_backup` для системи з постійною споживаною потужністю `P_sys`:

```
t_backup = E_usable / P_sys
t_backup = [(1/2) · C_eq · (V_max² - V_min_boost²) · η_boost] / P_sys
```

### Розрахунок балансувального ланцюга для послідовних комірок

Одинична комірка іоністора витримує максимальну напругу 2.7 В. При послідовному з'єднанні двох комірок для отримання 5.4 В через технологічний розкид струмів витоку комірок `I_leak1` та `I_leak2` напруга між ними розподілиться нерівномірно. Якщо струм витоку однієї комірки становить 5 мкА, а другої — 20 мкА, більш якісна комірка перезарядиться до 3.1 В і деградує за лічені тижні.

Для пасивного балансування паралельно до кожної комірки підключають резистор `R_bal`. Струм через балансувальний резистор `I_bal` повинен перевищувати максимальну різницю струмів витоку комірок щонайменше в 10 разів:

```
I_bal = V_cell / R_bal ≥ 10 · ΔI_leak_max
R_bal ≤ V_cell / (10 · ΔI_leak_max)
```

При максимальній різниці витоку `ΔI_leak = 30 мкА` та напрузі комірки `V_cell = 2.7 В`:

```
R_bal ≤ 2.7 В / (10 · 30 · 10⁻⁶ А) = 2.7 / 0.00030 = 9000 Ом
```

Обираємо резистори номіналом `8.2 кОм`. Статична потужність втрат на двох балансувальних резисторах складає:

```
P_loss_bal = 2 · (V_cell² / R_bal) = 2 · (2.7² / 8200) = 2 · (7.29 / 8200) = 1.78 мВт
```

Це абсолютно незначна втрата потужності для стаціонарних промислових блоків живлення.

## 3. Теплова енергія та розрахунок кривих SOA під час Hot-Swap старту

Під час встановлення плати в роз'єм під напругою (Hot-Swap) або активації електронного запобіжника (eFuse) контролер утримує силовий N-MOSFET у лінійному режимі, обмежуючи струм заряду на фіксованому рівні `I_lim`.

Напруга на виході зростає з постійною швидкістю:

```
dV_out / dt = I_lim / C_load
```

Час повного заряджання вихідної ємності `t_charge` від 0 до напруги шини `V_in`:

```
t_charge = (C_load · V_in) / I_lim
```

Напруга стік-витік `V_DS(t)` на транзисторі спадає за лінійним законом:

```
V_DS(t) = V_in · (1 - t / t_charge)
```

Миттєва потужність теплових втрат на кристалі MOSFET:

```
P(t) = V_DS(t) · I_lim = V_in · I_lim · (1 - t / t_charge)
```

Інтегруємо миттєву потужність за весь час заряду `t_charge` для отримання повної теплової енергії `E_FET`, яка виділяється на кремнієвому кристалі:

```
E_FET = ∫ P(t) dt               [інтегрування від 0 до t_charge]
E_FET = V_in · I_lim · ∫ (1 - t / t_charge) dt
E_FET = V_in · I_lim · [t - t² / (2 · t_charge)]   (підстановка меж 0 -> t_charge)
E_FET = V_in · I_lim · [t_charge - t_charge / 2]
E_FET = (1/2) · V_in · I_lim · t_charge
```

Підставляючи вираз `t_charge = (C_load · V_in) / I_lim`:

```
E_FET = (1/2) · V_in · I_lim · (C_load · V_in / I_lim)
E_FET = (1/2) · C_load · V_in²
```

> 📌 **Фізичний закон:** Теплова енергія, що розсіюється на ключі під час лінійного заряду ємності, **в точності дорівнює енергії, накопиченій у самій ємності**, і не залежить від величини обмеження струму `I_lim`. Проте величина `I_lim` задає тривалість імпульсу `t_charge`.

### Динамічний тепловий імпеданс та ефект Спіріто (Spirito Effect)

Зростання температури кристала `ΔT_j` визначається перехідним тепловим опором кристала `Z_thJC(t)`:

```
ΔT_j(t) = P_peak · Z_thJC(t_charge)
T_j_max = T_case + ΔT_j(t) ≤ T_j_limit (зазвичай 150 °C або 175 °C)
```

Для коротких імпульсів (`t < 10 мс`) тепловий потік не встигає поширитися на мідну підкладку корпусу і поглинається безпосередньо теплоємністю тонкого шару кремнію:

```
Z_thJC(t) ≈ K_thermal · √t
```

У сучасних планарних та Trench-MOSFET при високій напрузі `V_DS` та низькій напрузі на затворі `V_GS` виникає ефект Спіріто: температурний коефіцієнт струму стоку стає позитивним (`dI_D / dT > 0`). Струм локалізується у найгарячішій мікроскопічній точці кристала, що призводить до руйнівного теплового пробою (Thermal Instability) за потужностей, значно менших за класичну теплову межу кристала.

## 4. Розрахунок енергії індуктивного викиду та вибір супресора (TVS)

Коли контролер Active ORing виявляє коротке замикання джерела, він вимикає N-MOSFET за час `t_off ≈ 100 нс`. При розриві струму аварії `I_fault = 50 А` магнітна енергія, накопичена в паразитній індуктивності вхідних кабелів та доріжок `L_par`, не може зникнути миттєво.

Запасена індуктивна енергія становить:

```
E_ind = (1/2) · L_par · I_fault²
```

При індуктивності живильного підведення довжиною 1 метр `L_par ≈ 1.2 мкГн` та струмі `50 А`:

```
E_ind = 0.5 · 1.2 · 10⁻⁶ Гн · 50² А² = 0.5 · 1.2 · 10⁻⁶ · 2500 = 1.5 · 10⁻³ Дж = 1.5 мДж
```

Швидкість зміни струму складає:

```
di / dt = I_fault / t_off = 50 А / (100 · 10⁻⁹ с) = 5 · 10⁸ А/с
```

Без захисного супресора індукований викид перенапруги сягає:

```
V_spike = L_par · (di / dt) = 1.2 · 10⁻⁶ Гн · 5 · 10⁸ А/с = 600 В
```

Такий імпульс миттєво пробиває стік-витік будь-якого низьковольтного транзистора. Для поглинання індуктивної енергії паралельно до стоку встановлюють TVS-діод (наприклад, SMCJ15A), пікова імпульсна потужність якого повинна задовольняти умову:

```
P_ppm ≥ V_clamp · I_fault = 24 В · 50 А = 1200 Вт
```

Діод серії SMCJ розрахований на потужність `1500 Вт` для імпульсу 10/1000 мкс, що гарантує надійний захист ключів.

## 5. Математичний аналіз похибки розподілу струмів при Droop Sharing

При паралельному підключенні `N` перетворювачів без сигнальної шини для балансування вводять статичний нахил навантажувальної характеристики:

```
V_out(I) = V_nl - R_droop · I_out
```

Де `V_nl` — напруга холостого ходу (No Load), а `R_droop = ΔV / ΔI` — коефіцієнт нахилу (Droop Resistance).

Розглянемо випадок двох паралельних блоків з уставками `V_nl1` та `V_nl2`, які живлять спільну шину з напругою `V_bus` та сумарним струмом `I_total = I₁ + I₂`:

```
V_bus = V_nl1 - R_droop · I₁
V_bus = V_nl2 - R_droop · I₂

V_nl1 - R_droop · I₁ = V_nl2 - R_droop · I₂
R_droop · (I₁ - I₂) = V_nl1 - V_nl2
ΔI = I₁ - I₂ = (V_nl1 - V_nl2) / R_droop = ΔV_nl / R_droop
```

Підставляючи `I₂ = I_total - I₁`:

```
I₁ - (I_total - I₁) = ΔV_nl / R_droop
2 · I₁ - I_total = ΔV_nl / R_droop
I₁ = (I_total / 2) + ΔV_nl / (2 · R_droop)
I₂ = (I_total / 2) - ΔV_nl / (2 · R_droop)
```

### Аналіз чутливості та інженерний компроміс

Відносна асиметрія розподілу струму `ε_share` виражається формулою:

```
ε_share = |I₁ - I₂| / I_total = ΔV_nl / (R_droop · I_total)
```

З формули видно фундаментальне інженерне протиріччя:
* Щоб мінімізувати похибку розподілу струмів `ε_share`, необхідно **збільшувати** опір `R_droop`.
* Проте збільшення `R_droop` призводить до пропорційного **збільшення просадки** напруги на шині при переході від нуля до номінального струму:
  
  ```
  ΔV_bus_max = R_droop · (I_total_max / 2)
  ```

Якщо розкид опорних джерел двох блоків складає `ΔV_nl = 40 мВ` (±0.17% при 12 В), а максимальний струм `I_total_max = 40 А`, то для забезпечення асиметрії не гірше 10% (`ΔI ≤ 4 А`):

```
R_droop = ΔV_nl / ΔI = 0.040 В / 4 А = 0.010 Ом (10 мОм)
ΔV_bus_max = 0.010 Ом · 20 А = 0.20 В (просадка шини на 1.67%)
```

## 6. Розрахунок коефіцієнта надійності та ймовірності безвідмовної роботи

Для кількісної оцінки надійності резервованих систем застосовують теорію марковських процесів та експоненційний закон надійності. Інтенсивність відмов одного перетворювача позначають як `λ = 1 / MTBF`, а інтенсивність відновлення (ремонту або заміни) як `μ = 1 / MTTR`.

### Одиночний блок без резервування

Імовірність безвідмовної роботи за час `t`:

```
R_single(t) = e^(-λ · t)
MTBF_sys = 1 / λ
```

При `MTBF = 100 000 годин` (`λ = 10⁻⁵ 1/год`) імовірність безперервної роботи протягом 1 року (`t = 8760 годин`):

```
R_single(8760) = e^(-0.0876) = 0.9161 (91.61% імовірності не вийти з ладу)
```

### Резервована система 1+1 (два блоки з можливістю гарячої заміни)

Марковська модель містить три стани:
* Стан 0: Обидва блоки справні.
* Стан 1: Один блок відмовив, система працює на одному блоці, йде заміна зі швидкістю `μ`.
* Стан 2: Відмовили обидва блоки (повна аварія системи).

Інтенсивність переходу в стан повної відмови системи (System Failure Rate `λ_sys`):

```
λ_sys = (2 · λ²) / μ = 2 · λ² · MTTR
MTBF_sys = 1 / λ_sys = μ / (2 · λ²) = MTBF² / (2 · MTTR)
```

Підставляючи числові значення (`MTBF = 100 000 год`, `MTTR = 4 год`):

```
MTBF_sys = (100 000)² / (2 · 4) = 10¹⁰ / 8 = 1 250 000 000 годин (1.25 мільярда годин!)
```

Імовірність безвідмовної роботи за 1 рік:

```
R_sys(8760) = e^(-8760 / 1.25 · 10⁹) = e^(-0.000007) = 0.999993 (99.9993%)
```

## 7. Розрахунок стійкості контуру зворотного зв'язку активної шини Share Bus

Активний розподіл струму додає зовнішній контур регулювання, який підлаштовує опорну напругу або дільник зворотного зв'язку підлеглого стабілізатора.

Передавальна функція підсилювача помилки розподілу струму з інтегрувальною RC-ланкою Type-II:

```
H_share(s) = G_0 · (1 + s / ω_z) / [s · (1 + s / ω_p)]
```

Де частота нуля `ω_z = 1 / (R_comp · C_comp)` обирається нижче частоти зрізу основного контуру стабілізатора напруги `ω_c_volt` щонайменше в 5 разів:

```
ω_z ≤ ω_c_volt / 5
```

Це гарантує розділення частотних смуг регулювання: швидкий контур напруги (смуга 20–50 кГц) відпрацьовує динамічні стрибки струму навантаження, а повільний контур Share Bus (смуга 500–1000 Гц) плавно вирівнює статичні струми між блоками, усуваючи ризик виникнення взаємних автоколивань та циркулюючих струмів між перетворювачами.

## 8. Заряд зворотного відновлення (Q_rr) та динаміка відсікання

Коли транзистор Active ORing проводить струм, частина заряду накопичується в області просторового заряду Body-діода або каналу. Під час раптового закорочування вхідного джерела через транзистор протікає зворотний струм тривалістю `t_rr` (час зворотного відновлення):

```
Q_rr = (1/2) · I_rev_peak · t_rr
```

Піковий зворотний струм `I_rev_peak` визначається швидкістю спаду струму `di/dt`, яка обмежується паразитною індуктивністю контуру `L_loop`:

```
I_rev_peak = (V_bus / L_loop) · t_off_delay
```

Якщо індуктивність контуру `L_loop = 15 нГн`, напруга шини `V_bus = 12 В`, а затримка реакції компаратора `t_off_delay = 50 нс`:

```
I_rev_peak = (12 В / 15 · 10⁻⁹ Гн) · 50 · 10⁻⁹ с = 40.0 А
```

Цей розрахунок підкреслює критичну важливість вибору контролерів із мінімальною затримкою вимкнення (менше 50–100 нс) та використання транзисторів із мінімальним зарядом `Q_rr` для усунення глибоких провалів напруги на резервованій шині.

## 9. Температурний ресурс та старіння електролітичних конденсаторів

Фільтрові конденсатори вихідної шини піддаються постійному нагріванню пульсуючим струмом `I_ripple`. Згідно з тепловим законом Арреніуса для оксидних конденсаторів з рідким електролітом, термін служби `L` залежить від температури корпусу `T_case` та робочої напруги `V_work`:

```
L = L_0 · 2^((T_max - T_case) / 10) · (V_max / V_work)ⁿ
```

Де `L_0` — паспортний ресурс при максимальній температурі `T_max` (зазвичай 2000–5000 годин при 105 °C), а показник `n ≈ 2.0 – 2.5`.

Якщо обрати конденсатор на 25 В для роботи на шині 12 В (`V_max / V_work = 25 / 12 = 2.08`) при температурі корпусу `T_case = 55 °C`:

```
L = 5000 · 2^((105 - 55) / 10) · (2.08)²
L = 5000 · 2⁵ · 4.33 = 5000 · 32 · 4.33 = 692 800 годин (понад 79 років експлуатації!)
```

Ці розрахунки доводять, що правильний вибір робочих запасів за напругою та температурою гарантує десятиліття безвідмовної служби накопичувачів енергії.
