Коли бездротовий сенсор на базі літієвої батарейки CR2032 або акумулятора Li-Ion живить сучасне обчислювальне ядро з радіотрансивером Bluetooth Low Energy, первинна шина живлення постачає напругу від 3.0 до 3.6 В. Проте саме цифрове ядро процесора (наприклад, ARM Cortex-M4, Cortex-M33 або RISC-V), виготовлене за технологічними нормами 90, 40 чи 22 нанометри, фізично не здатне працювати при такій напрузі: надтонкий підзатворний діелектрик польових транзисторів зазнає електричного пробою вже при напрузі понад 1.3–1.4 В. Цифровій логіці, статичній оперативній пам'яті (SRAM) та кешу інструкцій потрібна стабілізована напруга ядра (Vcore) на рівні лише 0.9–1.2 В (типово 1.1 В).

Традиційний підхід до зниження напруги полягав у використанні інтегрованого лінійного стабілізатора з малим падінням напруги (LDO, від англ. *Low Dropout*). Але лінійне перетворення між 3.3 В та 1.1 В має фундаментальне термодинамічне обмеження: дві третини всієї енергії батареї безповоротно розсіюються у вигляді тепла на кремнієвому кристалі. Щоб подолати цей бар'єр, сучасні енергоефективні мікроконтролери (такі як STM32WB, STM32WBA, STM32WL від STMicroelectronics, nRF52840 та nRF5340 від Nordic Semiconductor, ESP32-C6 від Espressif чи RP2350 від Raspberry Pi) інтегрують повноцінний імпульсний знижувальний перетворювач (Buck DC-DC, від англ. *to buck* — протидіяти, знижувати).

### Чому ядро вимагає низької напруги

Зменшення геометрії транзисторів у напівпровідниковому виробництві (закони масштабування Деннарда) змушує виробників пропорційно зменшувати товщину шару діоксиду кремнію (SiO₂) або діелектрика з високою проникністю (High-k) під затвором транзистора. При товщині діелектрика в кілька нанометрів напруженість електричного поля всередині каналу стає колосальною. Підвищення напруги понад номінальні 1.1–1.2 В викликає незворотну деградацію структури транзистора через інжекцію гарячих носіїв заряду (*Hot Carrier Injection*) та тунельний пробій Фаулера–Нордгейма.

Крім того, динамічна потужність (P_dyn), яку споживає цифровий КМОН-процесор під час перемикання логічних вентилів, квадратично залежить від напруги живлення ядра:

```
P_dyn = C_eff · V_core² · f_clk
```

У цій рівності C_eff — ефективна сумарна паразитна ємність комутованих затворів і з'єднань, V_core — напруга живлення цифрового домену, а f_clk — тактова частота процесора.

Якщо порівняти роботу одного й того самого цифрового ядра на частоті 64 МГц при живленні 3.3 В та 1.1 В, зменшення напруги у 3 рази дає виграш у динамічній потужності у 3² = 9 разів. Зниження напруги ядра до 1.1 В є абсолютним технологічним імперативом, проте джерело живлення пристрою (батарея) залишається високовольтним.

### Термодинамічна пастка внутрішнього LDO

Лінійний стабілізатор LDO діє як керований дільник напруги, де роль регулюючого елемента виконує прохідний p-канальний польовий транзистор (PMOS pass transistor). Струм, що надходить від батареї у вхідний вивід мікроконтролера, повністю проходить крізь прохідний транзистор і надходить у цифрове ядро (не враховуючи мізерний власний струм зміщення внутрішнього джерела опорної напруги):

```
I_in_ldo = I_core + I_quiescent ≈ I_core
```

Коефіцієнт корисної дії (ККД, η, від лат. *efficere* — здійснювати) лінійного регулятора математично визначається співвідношенням вихідної та вхідної напруг:

```
η_ldo = P_core / P_in = (V_core · I_core) / (V_in · I_in) = V_core / V_in
```

Підставимо реальні значення для типового вузла Інтернету речей (IoT): вхідна напруга від літієвої батареї V_in = 3.3 В, напруга ядра V_core = 1.1 В.

```
η_ldo = 1.1 В / 3.3 В = 0.333 = 33.3%
```

![ККД живлення ядра MCU](/book/electronics/power-electronics/integrated-dc-dc/img/efficiency-vs-load.svg)
*Залежність ККД від струму навантаження ядра: в активному режимі (струми понад 1 мА) імпульсний DC-DC забезпечує ККД 85–90 %, зменшуючи споживання від батареї в 2.6 раза; на мікроамперних струмах сну DC-DC втрачає ефективність через фіксовані втрати комутації, тому ядро перемикається на ультраекономічний ULP-LDO.*

При споживанні ядром струму 30 мА (робота CPU на частоті 64 МГц із обробкою радіопротоколу BLE) корисна потужність цифрової логіки становить:

```
P_core = 1.1 В · 0.030 А = 0.033 Вт = 33 мВт
```

При цьому від батареї 3.3 В лінійний регулятор відбирає:

```
P_in_ldo = 3.3 В · 0.030 А = 0.099 Вт = 99 мВт
```

Різниця між спожитою та корисною потужністю повністю виділяється у вигляді тепла безпосередньо на напівпровідниковому кристалі мікроконтролера:

```
P_loss_ldo = P_in_ldo − P_core = 99 мВт − 33 мВт = 66 мВт
```

Це означає, що 66.7 % енергії батареї випаровується у вигляді безглуздого нагріву кремнію. Для батарейних пристроїв, що мають автономно працювати від 3 до 10 років від одного елемента живлення (дискової літієвої батарейки CR2032 ємністю 220 мА·год або пари батарейок AAA ємністю 1000 мА·год), така втрата є неприпустимим марнотратством.

### Фізика імпульсного зниження (Buck SMPS) на кристалі

Імпульсний знижувальний перетворювач (SMPS, від англ. *Switched-Mode Power Supply*) принципово змінює спосіб передачі енергії. Замість резистивного гасіння зайвої напруги він періодично комутує вхідне джерело живлення до зовнішньої індуктивності (від лат. *inductio* — наведення), перетворюючи електричну енергію на енергію магнітного поля, а потім передає її у навантаження на зниженому рівні напруги.

Ключовий закон імпульсного перетворення — збереження потужності з урахуванням ККД перетворювача (η ≈ 85–90 %):

```
P_in = P_core / η
V_in · I_in = (V_core · I_core) / η
```

Звідси вхідний струм, що відбирається від первинної шини живлення 3.3 В, становить:

```
I_in_dcdc = (V_core · I_core) / (V_in · η)
```

Підставимо ті самі параметри: V_in = 3.3 В, V_core = 1.1 В, I_core = 30 мА, ККД перетворювача η = 0.88 (88 %):

```
I_in_dcdc = (1.1 · 0.030) / (3.3 · 0.88) = 0.033 / 2.904 ≈ 0.01136 А = 11.36 мА
```

Струм споживання від батареї зменшується з 30 мА (у випадку LDO) до 11.36 мА — тобто рівно в 2.64 раза.

```
Коефіцієнт зменшення струму = 30.0 мА / 11.36 мА ≈ 2.64
```

Втрати потужності на перетворення становлять лише:

```
P_in_dcdc = 3.3 В · 0.01136 А ≈ 37.5 мВт
P_loss_dcdc = P_in_dcdc − P_core = 37.5 мВт − 33.0 мВт = 4.5 мВт
```

Замість 66 мВт тепла на кристалі виділяється лише 4.5 мВт (втрати зменшуються майже у 15 разів). Це кардинально знижує тепловий градієнт кристала і подовжує час автономної роботи бездротового датчика більш ніж у два з половиною рази.

> 🔧 **Навіщо це.** Вбудований DC-DC — це не просто спосіб зекономити енергію, а головний інструмент подолання високого внутрішнього опору дискових батарей. Батарейка CR2032 має внутрішній опір від 10 до 30 Ом (який зростає до 100 Ом наприкінці розряду). При імпульсному струмі 30 мА через LDO падіння напруги на внутрішньому опорі батареї становить 30 мА · 30 Ом = 0.9 В, що може призвести до раптового просідання напруги нижче порога аварійного скидання (BOR). Зниження вхідного струму до 11.4 мА зменшує просідання батареї до 0.34 В, дозволяючи виробити майже 100 % її хімічної ємності.

Детальне порівняння параметрів, рівнів шуму та часових відгуків лінійних і імпульсних топологій наведено в окремому огляді [🔌 Порівняння вбудованого DC-DC та LDO](book:electronics/integrated-dc-dc/comp-dcdc-vs-ldo.md).

### Схемотехнічний поділ: що живе на кристалі, а що зовні

Чому виробники мікроконтролерів називають DC-DC «вбудованим», якщо на друкованій платі поруч із чипом обов'язково розпаюється зовнішній дросель і конденсатор? Відповідь криється у фізиці напівпровідникових інтегральних мікросхем.

![Архітектура вбудованого DC-DC регулятора](/book/electronics/power-electronics/integrated-dc-dc/img/dcdc-mcu-architecture.svg)
*Схемотехнічний поділ системи живлення мікроконтролера: силові ключі, драйвери, ШІМ/PFM контролер та допоміжні LDO інтегровані на кремнієвому кристалі (on-chip); котушка індуктивності та згладжувальний конденсатор розташовані на платі (off-chip).*

#### Що інтегровано на кремнії (On-Chip):
1. **Силові польові транзистори (Power MOSFETs).** Верхній ключ (High-Side Switch, зазвичай PMOS або NMOS із внутрішнім помповим помножувачем заряду) та нижній синхронний ключ (Low-Side NMOS). Оскільки напруга комутації не перевищує 3.6 В, кремнієві польові транзистори субмікронних технологій мають надзвичайно малий питомий опір відкритого каналу (R_ds(on) від 0.2 до 0.8 Ом) і мінімальний заряд затвора (Q_g), що дозволяє їм перемикатися за лічені наносекунди.
2. **Внутрішнє безрезистивне вимірювання струму (Sense-FET Current Sensing).** На відміну від дискретних контролерів живлення, де для контролю струму дроселя потрібен зовнішній низькоомний резистивний шунт, на кристалі мікроконтролера паралельно силовому транзистору інтегрується мініатюрний дзеркальний транзистор із масштабом 1:1000. Це дозволяє точно вимірювати піковий струм котушки та захищати її від насичення без жодних додаткових втрат енергії на нагрів шунта.
3. **Драйвери затворів та логіка мертвого часу (Dead-Time Control).** Щоб запобігти наскрізному струму (*shoot-through* — прямому короткому замиканню вхідної шини VDD на землю через одночасно відкриті верхній і нижній транзистори), внутрішній формувач мертвого часу вводить захисну паузу тривалістю 1–3 нс між закриттям одного ключа та відкриттям іншого.
4. **Модулятор та контур керування (PWM/PFM Controller).** Внутрішній генератор тактової частоти (типово 4–8 МГц), підсилювач помилки зі схемою компенсації зворотного зв'язку, компаратор струму та логіка вибору режиму модуляції.
5. **Матриця допоміжних LDO.** Головний лінійний регулятор (Main LDO) для початкового старту та резервування, а також ультраекономічний LDO (ULP-LDO) для мікроамперних режимів глибокого сну.
6. **Комутаційний селектор живлення (Power Multiplexer).** Електронний безрозривний перемикач, що під'єднує шину живлення ядра Vcore або до виходу зовнішнього LC-фільтра DC-DC, або до внутрішнього виходу LDO.

#### Чому індуктивність неможливо інтегрувати в кремній (Off-Chip):
Інтеграція дроселя номіналом від 0.47 до 4.7 мкГн безпосередньо в структуру кремнієвого кристала стикається з фундаментальними законами електромагнетизму:
- **Низька магнітна проникність.** Кремній і діоксид кремнію є діамагнетиками з відносною магнітною проникністю μ_r ≈ 1. Без феромагнітного або порошкового магнітопроводу для створення індуктивності в кілька мікрогенрі потрібна плоска спіральна котушка з десятками витків діаметром у кілька міліметрів. Така котушка зайняла б площу, що перевищує площу всього мікроконтролера разом із процесором і пам'яттю, збільшивши вартість кристала в десятки разів.
- **Величезний опір металізації (DCR).** Шари металізації на кристалі (алюміній або мідь) мають товщину лише 0.5–2 мкм. Довга і тонка інтегрована спіраль має опір у десятки або сотні ом. При протіканні робочого струму ядра 30–50 мА на цьому опорі виділиться більше тепла, ніж економить сам DC-DC, а добротність (Q-фактор) такої індуктивності буде катастрофічно низькою (Q < 3–5).
- **Вихрові струми у підкладці.** Високочастотне змінне магнітне поле спіралі наводить вихрові струми Фуко в провідній напівпровідниковій підкладці кремнію, створюючи додаткові втрати енергії та наводячи паразитні завади на сусідні аналогові вузли.

Саме тому індуктивність реалізують у вигляді мініатюрного зовнішнього SMD-компонента (розмірів 0805, 0603 або 0402) із феритовим екранованим сердечником і товстим мідним дротом, що має опір постійному струму (DCR) менше 0.1–0.3 Ом та струм насичення (I_sat) понад 200–400 мА.

#### Типи конструкції зовнішніх дроселів: багатошарові проти дротяних

Вибір типу зовнішньої індуктивності визначає компроміс між габаритами, ККД та рівнем електромагнітних завад:
1. **Багатошарові феритові чіп-дроселі (Multilayer Chip Inductors).** Виготовляються за монолітною керамічною технологією (типорозміри 0402 або 0603). Їхня перевага — мінімальна ціна, мала висота (до 0.5–0.8 мм) та чудове магнітне екранування. Проте через малий переріз внутрішніх провідників вони мають підвищений активний опір (DCR = 0.3–0.6 Ом) і різке падіння індуктивності при струмах понад 150–200 мА (*hard saturation*). Вони ідеально підходять для малопотужних сенсорів із максимальним струмом ядра до 30 мА.
2. **Дротяні котушки з металопорошковим сердечником (Wirewound Metal Composite Inductors).** Використовують витки товстого мідного дроту, запресовані в залізо-порошковий компаунд (серії Bourns SRP, Wurth WE-MAPI або Murata DFE). Вони мають надзвичайно низький опір (DCR < 0.08–0.15 Ом), високу добротність (Q > 25–40) та плавну характеристику насичення (*soft saturation*), витримуючи імпульсні струми понад 500–800 мА. Це найкращий вибір для багатоядерних SoC або мікроконтролерів із потужними радіопередавачами (+10..+20 дБм).

### Парадокс мікрострумів: чому DC-DC вимикається у сні

Якщо імпульсний перетворювач має такий високий ККД (85–90 %), чому мікроконтролери не використовують його безперервно? Причина криється в природі втрат енергії імпульсних топологій на малих навантаженнях.

Загальні втрати потужності в імпульсному перетворювачі складаються з трьох основних компонентів:
1. **Провідні втрати (Conduction Losses, P_cond):** розсіювання тепла на опорі відкритих каналів транзисторів R_ds(on) та активному опорі дроселя DCR:

```
P_cond = I_core² · (R_ds(on) + DCR)
```

2. **Динамічні втрати перемикання (Switching Losses, P_sw):** енергія, яка витрачається на перезаряд ємності затворів силових транзисторів (C_gate) та перезаряд паразитної ємності комутаційного вузла SW (C_sw) на кожному періоді тактової частоти f_sw:

```
P_sw = (C_gate · V_in² + ½ · C_sw · V_in²) · f_sw
```

3. **Втрати схеми керування (Controller Quiescent Losses, P_ctrl):** енергія, необхідна для роботи внутрішнього генератора пилкоподібної напруги, джерела опорної напруги (Bandgap Reference) та високошвидкісних компараторів струму:

```
P_ctrl = V_in · I_q_controller
```

Провідні втрати залежать від квадрата струму навантаження, тому при переході ядра в стан глибокого сну (де струм I_core падає від 30 мА до 2 мкА) P_cond практично зникає (падає у 225 мільйонів разів). Проте втрати P_sw та P_ctrl **не залежать від струму навантаження** — вони є фіксованими і залежать виключно від частоти тактування та струму спокою внутрішньої аналогової схеми керування (зазвичай I_q_controller становить від 50 до 200 мкА).

Порахуємо ККД імпульсного DC-DC у режимі глибокого сну, коли ядро споживає лише 2 мкА при напрузі 1.1 В (P_core = 1.1 В · 2 мкА = 2.2 мкВт), а схема керування DC-DC споживає фіксовані 100 мкА від шини 3.3 В (P_ctrl = 3.3 В · 100 мкА = 330 мкВт):

```
P_in = P_core + P_ctrl + P_sw ≈ 2.2 мкВт + 330 мкВт = 332.2 мкВт
η_sleep_dcdc = P_core / P_in = 2.2 мкВт / 332.2 мкВт ≈ 0.0066 = 0.66%
```

ККД імпульсного перетворювача обвалився нижче одного відсотка! Щоб живити ядро потужністю 2.2 мкВт, перетворювач спалює 330 мкВт на власні потреби.

У цей самий момент спеціалізований ультраекономічний лінійний регулятор (ULP-LDO), побудований на субпорогових польових транзисторах, має власний струм спокою лише 150 нА (0.15 мкА). При струмі навантаження 2 мкА його вхідний струм становить лише 2.15 мкА, а споживана від батареї потужність:

```
P_in_ulp = 3.3 В · 2.15 мкА ≈ 7.1 мкВт
```

Порівняння очевидне: у глибокому сні ULP-LDO споживає 7.1 мкВт, тоді як імпульсний DC-DC витрачає 332 мкВт — різниця становить майже 47 разів на користь LDO!

### Динамічне перемикання режимів DCDC ↔ LDO

Щоб досягти максимальної енергоефективності в усіх режимах функціонування, сучасні мікроконтролери використовують динамічний дуалізм:
- **В активному режимі (Active / Run Mode):** обчислення, робота радіотрансивера, опитування швидкісних датчиків. Живлення здійснюється від вбудованого **DC-DC Buck** (ККД 85–90 %, струм від батареї зменшено у 2.6 раза).
- **У режимі глибокого сну (Deep Sleep / Stop / Standby / System OFF):** зупинка тактового генератора, збереження вмісту пам'яті SRAM і регістрів периферії. Живлення передається на **ULP-LDO** (струм спокою сотні наноампер).

![Динамічне перемикання DC-DC та LDO](/book/electronics/power-electronics/integrated-dc-dc/img/transient-handover.svg)
*Часова діаграма динамічного перемикання підсистеми живлення: вхід у сон виконує плавне вимкнення DC-DC і передачу навантаження на ULP-LDO; під час пробудження процесор миттєво стартує на LDO і повертається на DC-DC після виходу котушки на стаціонарний режим.*

Процес передачі живлення (*handover*) між регуляторами вимагає суворої синхронізації апаратних ключів:

1. **Фаза підготовки до сну.** Перед тим, як процесор виконає апаратну інструкцію входу в сон (`__WFI()`), схема керування живленням вмикає паралельний канал ULP-LDO. Потім генератор ШІМ імпульсного регулятора поступово зменшує шпаруватість (*soft-stop*) і переводить силові ключі у закритий стан (Hi-Z). Вихідний конденсатор Cout плавно утримує напругу ядра, запобігаючи стрибкам напруги.
2. **Фаза глибокого сну.** Усі вузли DC-DC (компаратори, драйвери, генератор тактування) повністю знеструмлені. Живлення SRAM підтримується крихітним струмом через ULP-LDO.
3. **Фаза швидкого пробудження.** Коли надходить сигнал переривання (від таймера RTC чи радіомодуля), процесор не може чекати сотні мікросекунд, поки DC-DC розкачає індуктивність і стабілізує вихідну напругу. Тому мікроконтролер миттєво активує головний LDO, і процесор починає виконувати код обробника переривання вже через 2–5 мікросекунд.
4. **Стабілізація та повернення на DC-DC.** Паралельно з виконанням програми апаратний автомат запускає схему плавного старту DC-DC (*soft-start*). Щойно вихідна напруга досягає 1.1 В і компаратор виставляє прапорець готовності (`SMPSRDY`), селектор живлення непомітно перемикає ядро на DC-DC, а LDO вимикається.

Програмну конфігурацію регістрів, захист від зависання та RAII-обгортки для C та C++ детально розглянуто у практичній вставці [⚙️ Програмне керування режимами DC-DC](book:electronics/integrated-dc-dc/proj-power-modes.md).

### Трасування друкованої плати та співіснування з радіотрактом

Впровадження імпульсного перетворювача безпосередньо в мікроконтролер створює серйозний виклик для електромагнітної сумісності (EMC, від англ. *Electromagnetic Compatibility*). Комутаційний вузол (вивід SW або LX) перемикається між 0 В та 3.6 В за час менше 1 наносекунди, що дає швидкість наростання напруги:

```
dV/dt > 3.6 В / 1 нс = 3.6 · 10⁹ В/с = 3.6 В/нс
```

Одночасно струм через силові ключі змінюється зі швидкістю:

```
dI/dt > 0.3 А / 2 нс = 1.5 · 10⁸ А/с = 150 мА/нс
```

Такі високі значення dV/dt та dI/dt породжують електромагнітні завади двох типів:
- **Ємнісні наведення (електричне поле E):** швидкі перепади напруги на мідному майданчику SW наводять струми зміщення через паразитні ємності у сусідні високоімпедансні лінії (доріжки кварцових резонаторів 32 МГц та 32.768 кГц, аналогові входи АЦП).
- **Індуктивні наведення (магнітне поле H):** змінний струм, що протікає по високочастотному контуру комутації (*hot switching loop*), діє як мініатюрна рамкова антена, випромінюючи широкосмуговий шум. Гармоніки комутації (4 МГц, 8 МГц, 12 МГц ... аж до сотень мегагерців) можуть потрапляти в смугу прийому радіотрансивера 2.4 ГГц (Bluetooth LE / Zigbee / Thread) або Sub-GHz (LoRa 868/915 МГц), знижуючи чутливість приймача (*receiver desensitization*) на 5–15 дБ.

![Трасування комутаційного контуру DC-DC](/book/electronics/power-electronics/integrated-dc-dc/img/pcb-switching-loop.svg)
*Топологія друкованої плати: мінімізація площі гарячої комутаційної петлі (SW → L → Cout → VSS_SMPS), розміщення суцільного шару заземлення на Layer 2 та ізоляція земляним бар'єром від чутливого радіотракту 2.4 ГГц і ліній кварцового резонатора.*

#### Правила трасування імпульсного вузла мікроконтролера:

1. **Мінімізація площі петлі комутації.** Контур, утворений виводом SW мікроконтролера, зовнішньою котушкою L, вихідним конденсатором Cout і виводом заземлення перетворювача (VSS_SMPS / PGND), має найвищу швидкість зміни струму dI/dt. Котушка L та конденсатор Cout повинні розташовуватися максимально близько до корпусу мікроконтролера на верхньому шарі (Top Layer). Площа цієї петлі має бути фізично мінімальною.
2. **Короткий і компактний майданчик SW.** Доріжка між виводом SW мікроконтролера та виводом котушки не повинна перетворюватися на випромінювальну антену. Її довжина має становити не більше 1.5–3 мм, а ширина обирається достатньою для протікання пікового струму (зазвичай 0.3–0.5 мм). Категорично заборонено прокладати лінію SW через перехідні отвори на внутрішні шари плати.
3. **Суцільний екран заземлення (Solid Ground Plane) на Layer 2.** Безпосередньо під компонентами DC-DC (L, Cout, Cin) на другому шарі друкованої плати має розташовуватися суцільний, непорізаний полігон заземлення. Зворотний струм високої частоти протікає в шарі заземлення строго під доріжкою провідника, мінімізуючи площу магнітної петлі та компенсуючи власне магнітне поле.
4. **Вибір екранованої котушки (Shielded Inductor).** Необхідно використовувати виключно котушки закритого типу (з монолітним феритовим або металопорошковим екраном). Відкриті котушки з відкритим магнітним сердечником розсіюють магнітний потік назовні, наводячи шум на радіотракт і друковані антени.
5. **Просторове рознесення та захисні бар'єри (Guard Rings).** Вузол DC-DC слід розміщувати на протилежному боці мікросхеми відносно радіочастотного виводу (RF_OUT / ANT) та кварцових резонаторів. Між силовою секцією та радіотрактом прокладають бар'єр із переходних отворів заземлення (*via fence*), що блокує розповсюдження поверхневих електромагнітних хвиль у діелектрику плати.

### Розрахунок параметрів компонентів та приклад аналізу пульсацій

Надійність роботи та рівень пульсацій вихідної напруги DC-DC безпосередньо залежать від параметрів пасивних компонентів:

```
ΔV_ripple ≈ ΔV_cap + ΔV_esr
```

Розмах пульсацій струму в котушці (ΔI_L) визначається законом індукції:

```
ΔI_L = (V_in − V_core) · V_core / (V_in · f_sw · L)
```

**Приклад повного розрахунку пульсацій напруги ядра.** Розглянемо мікроконтролер із вбудованим DC-DC при параметрах: вхідна напруга V_in = 3.3 В, напруга ядра V_core = 1.1 В, частота комутації f_sw = 4 МГц (4·10⁶ Гц), номінал зовнішньої індуктивності L = 2.2 мкГн (2.2·10⁻⁶ Гн) та вихідна ємність C_out = 4.7 мкФ (4.7·10⁻⁶ Ф) з еквівалентним послідовним опором ESR = 10 мОм (0.010 Ом):

1. Розрахуємо розмах пульсацій струму в дроселі:

```
ΔI_L = (3.3 − 1.1) · 1.1 / (3.3 · 4·10⁶ · 2.2·10⁻⁶)    [закон індукції для прямокутної комутації]
     = 2.2 · 1.1 / 29.04                              [спрощення чисельника та знаменника]
     = 2.42 / 29.04                                   [ділення величин]
     ≈ 0.0833 А = 83.3 мА                             [пік-пік пульсація струму дроселя]
```

2. Розрахуємо амплітуду ємнісної складової пульсацій напруги ядра:

```
ΔV_cap = ΔI_L / (8 · f_sw · C_out)                     [інтегрування трикутного струму в ємність]
       = 0.0833 / (8 · 4·10⁶ · 4.7·10⁻⁶)               [підставили f_sw та C_out]
       = 0.0833 / 150.4                                [обчислення знаменника]
       ≈ 0.000554 В = 0.55 мВ                          [ємнісна складова пульсацій]
```

3. Розрахуємо складову пульсацій на активному послідовному опорі конденсатора (ESR):

```
ΔV_esr = ΔI_L · ESR                                    [закон Ома для змінного струму пульсацій]
       = 0.0833 А · 0.010 Ом                           [підставили розмах струму та опір]
       = 0.000833 В = 0.83 мВ                          [резистивна складова пульсацій]
```

4. Повний розмах пульсацій напруги ядра становить:

```
ΔV_total = ΔV_cap + ΔV_esr                             [сума ємнісної та резистивної складових]
         = 0.55 мВ + 0.83 мВ                           [підставили обчислені складові]
         = 1.38 мВ                                     [сумарний розмах пульсацій Vcore]
```

Пульсація на рівні 1.38 мВ (менше 0.15 % від номінальної напруги 1.1 В) є абсолютно безпечною для надійної роботи внутрішньої цифрової логіки ядра.

При виборі вихідного конденсатора слід обов'язково враховувати явище падіння ємності багатошарових керамічних конденсаторів (MLCC) під дією постійної напруги зміщення (*DC Bias Effect*). Керамічний конденсатор ємністю 4.7 мкФ у типорозмірі 0402 при робочій напрузі 1.1 В може втрачати від 10 до 25 % номінальної ємності. Тому для критичних застосувань обирають діелектрик класу X5R або X7R з робочою напругою не менше 6.3 В або 10 В.

Вбудований імпульсний перетворювач перетворився з екзотичної функції на обов'язковий стандарт архітектури сучасних мікроконтролерів. Розуміння його внутрішньої структури, динаміки перехідних процесів та правил електромагнітної ізоляції дозволяє створювати автономні пристрої з багаторічним терміном служби від одного компактного хімічного джерела енергії.
