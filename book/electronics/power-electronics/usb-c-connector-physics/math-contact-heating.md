# 🧮 Математика контакту: опір стягування, нагрів і розряд

Математичний апарат електричного контакту роз'єму USB Type-C спирається на три взаємопов'язані фізичні дисципліни: мікромеханіку деформації шорстких поверхонь, електродинаміку стягування ліній струму та термодинаміку теплового балансу у надмалих об'ємах. Коли роз'єм комутує граничну потужність 240 Вт (напругу 48 В за струму 5 А), ці формули визначають, чи працюватиме інтерфейс роками, чи вийде з ладу через локальний перегрів або ерозію металу.

### 1. Мікромеханіка деформації та дійсна площа дотику

Жодна полірована металева поверхня не є абсолютно пласкою на мікроскопічному рівні. Реальний контакт двох тіл відбувається на верхівках мікронерівностей (мікропагорбів, або *asperities*). Під дією прикладеної нормальної сили `F_n` напруження на верхівках цих пагорбів перевищує границю текучості металу, через що виникає локальна пластична деформація.

Згідно з моделлю пластичного контакту Рагнара Гольма (англ. *Holm contact theory*), сумарна дійсна площа фактичного металевого контакту `A_r` пропорційна нормальній силі притискання `F_n` і обернено пропорційна контактній твердості м'якшого матеріалу покриття за шкалою Віккерса `H`:

```
A_r = F_n / H          [дійсна площа контакту: закон пластичної деформації]
```

Для окремої круглої контактної плями радіуса `a` площа дорівнює `A_i = π · a²`. Якщо поверхні стикаються через `n` однакових мікроплям, сумарна площа контакту становить:

```
A_r = n · π · a_avg²   [сума площ усіх контактних плям]
```

Звідси еквівалентний радіус середньої контактної плями виражається через макроскопічні параметри сили та твердості:

```
a_avg = √(F_n / (n · π · H))  [еквівалентний радіус одиничної a-плями]
```

Підставимо параметри, типові для позолоченого контакту гнізда USB-C. Нормальна сила притискання контактної пелюстки становить `F_n = 0.4 Н`, мікротвердість електролітичного твердого золота, легованого кобальтом (Au-Co), дорівнює `H ≈ 1.5 · 10⁹ Па` (близько 150 HV):

```
A_r
= 0.4 / (1.5 · 10⁹)              [розрахунок дійсної площі контакту]
= 2.67 · 10⁻¹⁰ м²                [A_r = 0.000267 мм²]
```

Якщо видима геометрична площа контактного майданчика становить `A_geom = 0.5 мм × 0.4 мм = 0.2 мм²`, то частка фактичного металевого дотику дорівнює:

```
k_contact
= A_r / A_geom                   [відношення дійсної площі до уявної]
= 0.000267 / 0.2
= 0.001335                       [дійсна площа становить лише 0.13% від видимої!]
```

Цей фундаментальний розрахунок демонструє, що понад 99.8% поверхні контакту розділені мікроскопічним зазором і взагалі не беруть участі у передачі електричного струму.

### 2. Електродинаміка опору стягування (Constriction Resistance)

Оскільки весь струм змушений протікати крізь мікроскопічні плями радіусом у кілька мікрометрів, лінії електричного поля та густини струму різко викривляються і сходяться (стягуються) до точок контакту. Це явище створює додатковий електричний опір, який називають опором стягування `R_c`.

Розподіл електричного потенціалу `ϕ` в об'ємі металу навколо круглої контактної плями описується рівнянням Лапласа:

```
∇²ϕ = 0                           [рівняння потенціального поля у провіднику]
```

Інтегруючи це рівняння в еліпсоїдальних координатах від поверхні дискового контакту радіуса `a` до нескінченності, отримуємо класичну формулу Гольма для опору стягування одного напівнескінченного провідника:

```
R_c1 = ρ / (4 · a)               [опір стягування для одного боку контакту]
```

Оскільки струм спершу стягується у контактній пелюстці гнізда, а потім розширюється в тілі язичка штекера, повний опір стягування для двох однакових металевих тіл із питомим опором `ρ` дорівнює сумі двох половин:

```
R_c
= R_c1 + R_c2                    [сума опорів стягування пелюстки та язичка]
= ρ / (4·a) + ρ / (4·a)          [додавання двох напівпросторів]
= ρ / (2·a)                      [класична формула Гольма для дискової a-плями]
```

Якщо контакт утворено групою з `n` взаємно віддалених мікроплям, лінії струму діляться між ними паралельно:

```
R_c_multi
= ρ / (2 · ∑ a_i)                [опір стягування системи незалежних плям]
```

Проте якщо мікроплями розташовані близько одна до одної (утворюють так званий кластер плям за моделлю Грінвуда-Вільямсона), їхні поля стягування взаємно накладаються. Тоді опір стягування складається з внутрішнього опору окремих плям та зовнішнього опору всього кластера радіуса `r_cluster`:

```
R_c_Greenwood
= ρ / (2 · n · a_avg) + ρ / (2 · r_cluster)  [модель кластерного стягування Грінвуда]
```

Підставимо значення для золотого покриття (`ρ_Au = 2.44 · 10⁻⁸ Ом·м`):

```
a = √(2.67 · 10⁻¹⁰ / π)
= 9.21 · 10⁻⁶ м                  [радіус плями a ≈ 9.2 мкм]

R_c
= (2.44 · 10⁻⁸) / (2 · 9.21 · 10⁻⁶)  [розрахунок опору стягування]
= 1.325 · 10⁻³ Ом                [R_c ≈ 1.33 мОм]
```

Повний опір контактної пари складається з трьох послідовних компонентів:

```
R_total = R_bulk + R_c + R_film  [структура повного опору контактного вузла]
```

де:
- `R_bulk` — об'ємний опір металевих деталей пелюстки та доріжки (типово 15–20 мОм);
- `R_c` — опір стягування на мікроплямах (1–3 мОм);
- `R_film` — опір тунелювання електронів крізь мономолекулярні плівки оксидів і забруднень (5–15 мОм).

Сумарний початковий опір якісного контакту USB-C становить `25–35 мОм`.

### 3. Закон Кольрауша — Гольма та максимальна температура контакту

У зоні стягування густина струму досягає колосальних значень (`j > 10⁶–10⁷ А/см²`). Електричний струм, долаючи опір стягування, нагріває мікрооб'єм металу безпосередньо в точці контакту.

Між падінням напруги на контакті `U_c` та максимальною температурою в контактній зоні `T_max` існує строгий фундаментальний зв'язок, що випливає із закону Відемана — Франца. Цей зв'язок відомий як **теорема Кольрауша — Гольма (англ. *Kohlrausch-Holm temperature-voltage relation*)**:

```
T_max² - T_0² = U_c² / (4 · L)   [зв'язок максимальної температури і напруги контакту]
```

де:
- `T_0` — температура тіла роз'єму далеко від контакту (в Кельвінах);
- `U_c` — спад напруги на контактному опорі (`U_c = I · R_c`);
- `L` — число Лоренца для металів, що визначається фундаментальними фізичними сталими:

```
L
= (π² · k_B²) / (3 · e²)         [число Лоренца з фундаментальних констант]
= 2.44 · 10⁻⁸ В²/К²              [теоретичне значення числа Лоренца]
```

Звідси максимальна температура контактної плями виражається безпосередньо через падіння напруги:

```
T_max = √(T_0² + U_c² / (4 · L)) [максимальна температура в центрі a-плями]
```

Зверніть увагу: температура контактної плями взагалі не залежить від геометрії та площі дотику — вона визначається виключно падінням напруги `U_c`!

Ця формула дозволяє обчислити два критичні порогові значення напруги для будь-якого металу:
1. **Напруга розм'якшення (англ. *Softening voltage* `U_s`):** напруга, за якої температура в контакті досягає точки рекристалізації металу (для золота `T_s ≈ 100 °C = 373 К`, `U_s ≈ 0.08 В`). При досягненні `U_s` мікропагорби починають пластично текти під власною силою притискання, площа контакту зростає, а опір падає.
2. **Напруга плавлення (англ. *Melting voltage* `U_m`):** напруга, за якої метал плавиться (для золота `T_m = 1064 °C = 1337 К`, `U_m ≈ 0.43 В`; для міді `T_m = 1085 °C = 1358 К`, `U_m ≈ 0.43 В`). Якщо на контакті падає напруга понад 0.43 В, точка дотику миттєво перетворюється на краплю рідкого розплавленого металу.

### 4. Теплова постійна часу та динаміка нагріву мікроплями

Швидкість нагрівання мікроплями визначається її тепловою постійною часу `τ_th`:

```
τ_th = a² / α                    [теплова постійна часу контактної плями]
```

де `α = κ / (c_p · d)` — коефіцієнт температуропровідності матеріалу (`κ` — теплопровідність, `c_p` — питома теплоємність, `d` — густина).

Для золота (`α_Au ≈ 1.27 · 10⁻⁴ м²/с`) при радіусі плями `a = 9.2 мкм`:

```
τ_th
= (9.21 · 10⁻⁶)² / (1.27 · 10⁻⁴) [розрахунок теплової інерції мікроплями]
= 8.48 · 10⁻¹¹ / (1.27 · 10⁻⁴)
= 6.68 · 10⁻⁷ с                  [τ_th ≈ 0.67 мкс]
```

Отриманий результат показує, що теплова інерція контакту становить менше однієї мікросекунди! Це означає, що за будь-якого мікрострибка струму або короткочасного розмикання температура в контакті зростає до максимуму практично миттєво.

### 5. Асиметрія розподілу струму між паралельними пінами VBUS

Струм 5 А за стандартом USB PD EPR живить навантаження через 4 контакти `VBUS` (A4, A9, B4, B9) та 4 контакти `GND` (A1, A12, B1, B12). За ідеального розподілу кожен контакт ніс би струм `I_nom = 5 / 4 = 1.25 А`.

Однак через технологічні допуски виготовлення пружин, нерівномірне зношування золотого покриття та перекоси штекера опір кожного з чотирьох пінів відрізняється: `R_1, R_2, R_3, R_4`.

Струм у `k`-му контакті визначається правилом паралельних віток:

```
I_k = I_total · (1 / R_k) / (∑ (1 / R_i))  [розподіл струму за законом Кірхгофа]
```

Якщо три контакти мають номінальний опір `R = 30 мОм`, а четвертий контакт через забруднення або знос має опір `R_4 = 60 мОм`:

```
1/R_eq
= 3 · (1 / 0.030) + 1 / 0.060   [сума провідностей віток]
= 100 + 16.67
= 116.67 См                     [еквівалентна провідність]

I_1 = I_2 = I_3
= 5 · (33.33 / 116.67)          [струм чистих пінів]
= 1.43 А

I_4
= 5 · (16.67 / 116.67)          [струм забрудненого піна]
= 0.71 А
```

Якщо ж, навпаки, три піни через окислення збільшили опір до 50 мОм, а один залишився чистим (30 мОм), струм чистого піна зросте до:

```
1/R_eq = 3 · (1 / 0.050) + 1 / 0.030 = 60 + 33.33 = 93.33 См
I_clean = 5 · (33.33 / 93.33) = 1.785 А
```

Оскільки джоулеві втрати пропорційні квадрату струму (`P = I² · R`), через нелінійність сумарне виділення тепла за асиметричного розподілу завжди перевищує ідеальний випадок:

```
∑ I_k² · R_k > 4 · (I_total / 4)² · R_avg  [нерівність нерівномірного нагріву]
```

Саме тому специфікація роз'єму розраховує тепловий режим кожного одиночного піна не на 1.25 А, а на струм щонайменше `1.875 А` (коефіцієнт запасу 1.5).

### 6. Енергетика дугового розряду під час аварійного розриву 48 В

Під час розмикання кола під напругою `U_0 = 48 В` та струмом `I_0 = 5 А` швидкість відносного руху контактів становить `v ≈ 0.8 м/с`.

У міру розходження контактів довжина рідкого металевого містка зростає до критичного значення `d_crit ≈ 3–8 мкм`, після чого місток вибухає. Простір між контактами іонізується, і спалахує плазмова дуга.

Диференційне рівняння електричного кола, що живить дугу з індуктивністю кабелю `L_cable ≈ 1 мкГн`:

```
U_0 = i(t) · R_load + L_cable · (di/dt) + u_arc(t)  [динамічне рівняння розряду]
```

Вольт-амперна характеристика короткої електричної дуги на металевих парах за моделлю Айртон (Ayrton arc equation):

```
u_arc(t) = V_min + (C + D · d(t)) / i(t)  [вольт-амперна характеристика дуги Айртон]
```

де для міді та золота мінімальна напруга горіння дуги становить `V_min ≈ 12–15 В`, а константи `C` та `D` визначають приріст напруги від довжини розриву `d(t) = v · t`.

Сумарна енергія, що виділяється у мікрооб'ємі плазмової дуги за час її горіння `t_arc`:

```
E_arc = ∫₀^{t_arc} u_arc(t) · i(t) dt     [інтеграл повної теплової енергії дуги]
```

Для некерованого розриву кола без участі лінії CC дуга горить протягом часу `t_arc ≈ 3–6 мс` доти, доки відстань між контактами не перевищить критичну межу згасання (близько 2–3 мм):

```
E_arc_unprotected
≈ U_arc_avg · I_avg · t_arc      [наближений розрахунок енергії дуги]
≈ 20 В · 4 А · 0.004 с
≈ 0.32 Дж                        [320 мДж чистої теплової енергії]
```

Маса металу покриття `Δm`, що випаровується під дією дугового розряду, визначається формулою ерозії:

```
Δm = k_erosion · ∫ i(t) dt       [масова ерозія металу контактної пари]
```

де для золота коефіцієнт питомої ерозії становить `k_erosion ≈ 3.5 · 10⁻⁶ г/Кл`. За енергії 320 мДж з поверхні пелюстки випаровується близько `0.05–0.1 мг` золота. Враховуючи, що вся маса золотого покриття товщиною 0.76 мкм на площі піна становить менш ніж `0.003 мг`, одиничний некерований розряд на 48 В повністю знищує захисне покриття за один цикл!

При захищеному відключенні за сигналом лінії CC контролер закриває силовий польовий транзистор за час `t_off ≤ 300 мкс`, завдяки чому струм спадає до нуля до того, як дуга встигне розвинутися:

```
E_arc_protected
≈ 15 В · 5 А · 0.00015 с
≈ 0.011 Дж                       [11 мДж — енергія нижче порогу випаровування металу]
```

### 7. Високочастотний скін-ефект у горловині a-плями на частотах 10–20 ГГц

Під час передачі цифрових потоків стандартів USB4 (20–40 Гбіт/с) та Thunderbolt 4 тактова частота найвищих спектральних гармонік перевищує `10–20 ГГц`. На таких надвисоких частотах електромагнітна хвиля витісняється до зовнішньої поверхні провідника внаслідок поверхневого ефекту (скін-ефекту).

Товщина скін-шару `δ_s` у золотому покритті (`ρ = 2.44 · 10⁻⁸ Ом·м`, відносна магнітна проникність `μ_r = 1`, магнітна стала `μ_0 = 4π · 10⁻⁷ Гн/м`):

```
δ_s = √(ρ / (π · f · μ_0 · μ_r)) [глибина проникнення поля у метал]
```

Для частоти першої гармоніки `f = 10 ГГц`:

```
δ_s_10GHz
= √((2.44 · 10⁻⁸) / (3.14159 · 10¹⁰ · 1.2566 · 10⁻⁶))  [підстановка констант]
= √(2.44 · 10⁻⁸ / 3.948 · 10⁴)
= √(6.18 · 10⁻¹³)
= 7.86 · 10⁻⁷ м                  [δ_s ≈ 0.786 мкм]
```

Для частоти `f = 20 ГГц` товщина скін-шару зменшується до:

```
δ_s_20GHz = 7.86 · 10⁻⁷ / √2 ≈ 5.56 · 10⁻⁷ м = 0.556 мкм
```

Зверніть увагу на критичне співвідношення розмірів: радіус мікроплями контакту `a ≈ 9.2 мкм` у 12–16 разів перевищує товщину скін-шару `δ_s ≈ 0.78 мкм`!

Це означає, що високочастотний струм протікає не крізь увесь круговий переріз плями дотику, а лише вузьким кільцем по її зовнішньому периметру товщиною `δ_s`. Високочастотний опір стягування `R_c_ac` для дискового контакту в режимі вираженого скін-ефекту описується наближеною формулою:

```
R_c_ac ≈ (ρ / (2 · π · a)) · ln(a / δ_s)  [високочастотний опір стягування]
```

Розрахуємо приріст опору стягування на частоті 10 ГГц:

```
R_c_ac
= (2.44 · 10⁻⁸ / (2 · 3.14159 · 9.21 · 10⁻⁶)) · ln(9.21 · 10⁻⁶ / 7.86 · 10⁻⁷)
= (2.44 · 10⁻⁸ / 5.787 · 10⁻⁵) · ln(11.72)
= 4.216 · 10⁻⁴ · 2.461
= 1.037 · 10⁻³ Ом                [R_c_ac ≈ 1.04 мОм]
```

Високочастотний опір стягування вносить затухання в диференційний тракт передачі даних, викликаючи додаткові втрати потужності сигналу (Insertion Loss) величиною близько `0.15–0.3 дБ` на один роз'ємний перехід.

### 8. Комплексна модель тепловідведення крізь друковану плату

Тепло, що виділяється у восьми силових контактах роз'єму (`P_total ≈ 0.50–0.80 Вт`), розсіюється у навколишній простір через два паралельні фізичні канали:

1. **Конвективне та променеве розсіювання з поверхні металевого кожуха:** площа зовнішнього овалу становить близько `A_shell ≈ 2.5 см²`. За природної конвекції повітря коефіцієнт тепловіддачі дорівнює `h_conv ≈ 15 Вт/(м²·К)`:

```
P_conv = h_conv · A_shell · ΔT   [потужність природної конвекції повітря]
P_conv = 15 · (2.5 · 10⁻⁴) · 25 = 0.09375 Вт  [лише 12–15% загального тепла]
```

2. **Теплопровідність крізь металізовані перехідні отвори у мідні полігони плати:** саме мідні шари друкованої плати відводять понад **85%** усього виділеного тепла.

Тепловий опір `R_th_vias` масиву з `N_via` мідних перехідних отворів із товщиною стінки металізації `t_wall = 25 мкм`, діаметром свердла `d_drill = 0.3 мм` та висотою `L_via = 1.0 мм` (товщина плати):

```
A_cu_via
= π · d_drill · t_wall           [площа поперечного перерізу мідної стінки via]
= 3.14159 · 0.3 · 10⁻³ · 25 · 10⁻⁶
= 2.356 · 10⁻⁸ м²

R_th_single_via
= L_via / (κ_cu · A_cu_via)      [тепловий опір одного перехідного отвору]
= 1.0 · 10⁻³ / (390 · 2.356 · 10⁻⁸)
= 1.0 · 10⁻³ / 9.188 · 10⁻⁶
= 108.8 К/Вт                     [тепловий опір однієї перехідки]
```

Для масиву з `N = 6` паралельних отворів біля виводів живлення сумарний тепловий опір переходу становить:

```
R_th_array
= R_th_single_via / N            [паралельне з'єднання теплових опорів]
= 108.8 / 6
= 18.1 К/Вт                      [ефективне тепловідведення у внутрішні шари]
```

Цей розрахунок доводить, що наявність масиву з щонайменше 4–6 перехідних отворів біля кожного силового виводу знижує перегрів контактного вузла більш ніж удвічі, гарантуючи надійну роботу всього пристрою в межах теплового стандарту USB-IF.

### 9. Математична модель фретинг-зносу та корозії контактів

Під час повсякденної експлуатації роз'єм зазнає постійних мікровібрацій від роботи вентиляторів охолодження, перенесення пристрою та циклічного теплового розширення під час нагрівання/охолодження. Це викликає циклічні мікрозсуви контактної пелюстки відносно ламелі амплітудою `s ≈ 5–20 мкм` (явище фретингу, англ. *fretting wear*).

Об'єм зношеного матеріалу покриття `V_wear` після `N_cyc` циклів мікрозсуву описується законом зношування Арчарда (Archard's wear law):

```
V_wear = (K_wear · F_n · s_total) / H  [закон абразивного зносу Арчарда]
```

де:
- `K_wear` — безрозмірний коефіцієнт зношування пари Au-Co по Au-Co (`K_wear ≈ 10⁻⁴–10⁻⁵`);
- `F_n` — нормальна сила притискання (`0.4 Н`);
- `s_total = 2 · s · N_cyc` — сумарний шлях тертя за `N_cyc` циклів вібрації;
- `H` — твердість покриття (`1.5 · 10⁹ Па`).

Час до повного стирання шару золота товщиною `h_Au = 0.76 мкм` на площі плями `A_spot = π · a²`:

```
N_crit
= (h_Au · A_spot · H) / (2 · K_wear · F_n · s)  [критична кількість циклів вібрації]
```

Підставимо значення для амплітуди мікрозсуву `s = 10 мкм`:

```
N_crit
= (0.76 · 10⁻⁶ · 2.67 · 10⁻¹⁰ · 1.5 · 10⁹) / (2 · 10⁻⁵ · 0.4 · 10 · 10⁻⁶)
= (3.044 · 10⁻⁷) / (8.0 · 10⁻¹¹)
= 3805 циклів                    [поріг початку оголення нікелевого бар'єра]
```

Коли тонкий шар золота вичерпується, оголюється нікелевий підшар. Нікель миттєво реагує з киснем повітря, утворюючи тверду непровідну оксидну плівку `NiO`. Під час наступних мікрорухів крихкий оксид стирається у дрібнодисперсний чорний порошок, який накопичується в контактній зоні.

Зростання контактного опору `R(t)` внаслідок накопичення оксидного порошку описується експоненційною моделлю:

```
R(t) = R_0 + R_inf · (1 - e^{-β · t})  [динаміка зростання опору при фретингу]
```

де `R_0 ≈ 30 мОм`, `R_inf ≈ 500–2000 мОм`, а параметр швидкості деградації `β` залежить від амплітуди вібрації.

Якщо нормальна сила притискання `F_n` підтримується в оптимальному діапазоні `0.3–0.5 Н`, контакт перебуває в зоні пружного мікродеформування (elastic fretting regime), що запобігає виходу з ладу протягом усього 10-річного терміну служби приладу.

### 10. Флуктуаційний шум та спектральна густина 1/f у зоні звуження

У прецизійних вимірювальних трактах або високочутливих аудіоінтерфейсах перехідний контакт роз'єму створює власний електричний шум.

Повний шум контакту складається з двох компонентів:
1. **Тепловий шум Джонсона — Найквіста:** визначається дійсним контактним опором:

```
S_v_thermal = 4 · k_B · T · R_contact  [спектральна густина теплового шуму]
```

2. **Надлишковий контактний флікер-шум (1/f шум Гоґе):** виникає внаслідок мікрофлуктуацій провідності в обмеженому об'ємі стягування ліній струму. Спектральна густина напруги шуму описується емпіричним співвідношенням Гоґе (Hooge's formula):

```
S_v_excess(f) = (α_H · U_c²) / (N_free · f)  [спектральна густина 1/f шуму]
```

де `α_H ≈ 2 · 10⁻³` — константа Гоґе, `N_free` — загальна кількість вільних електронів у малому об'ємі зони стягування `V_constriction ≈ 2 · a³`.

Оскільки об'єм `V_constriction` становить лише частки кубічного мікрона, кількість вільних носіїв заряду `N_free` є відносно невеликою, що робить якість золотого покриття та стабільність сили притискання `F_n` вирішальними факторами для мінімізації фазового джитера на гігагерцових частотах.
