# 🧮 Математична модель імпульсного розряду та релаксації батарей

Точний розрахунок часу автономної роботи мікропотужних бездротових систем вимагає переходу від спрощених емпіричних оцінок до аналітичного опису фізико-хімічних процесів перенесення заряду. Коли навантаження споживає струм у вигляді коротких імпульсів високої амплітуди, розділених тривалими інтервалами глибокого сну, в електроліті виникають локальні градієнти концентрації носіїв, а внутрішній опір змінюється у часі. Математичний апарат теорії розряду об'єднує модифікований інтеграл Пойкерта, двоємнісну кінетичну модель акумулятора (KiBaM), експоненційну модель саморозряду та диференціальні рівняння буферизації заряду накопичувальними конденсаторами.

### 1. Інтегральне узагальнення закону Пойкерта для дискретних профілів

Класичне рівняння Вільгельма Пойкерта справедливе виключно для розряду незмінним за величиною постійним струмом `I`:

```
Iᵏ · t = C_p
```

де `k` — емпіричний показник Пойкерта (`k > 1`), `t` — час розряду до досягнення напруги відсічки, а `C_p` — константа ємності Пойкерта.

Якщо відома номінальна паспортна ємність батареї `C_ном` (в ампер-годинах), виміряна за стандартного тривалого струму розряду `I_ном` (наприклад, розряд за час `T_ном = 20 год` або `100 год`), константу `C_p` визначають підстановкою номінальних параметрів:

```
C_p = I_номᵏ · T_ном = I_номᵏ · (C_ном ÷ I_ном) = I_номᵏ⁻¹ · C_ном
```

Для довільного змінного в часі профілю навантаження `i(t)` пряме застосування класичної формули неможливе, оскільки швидкість виснаження хімічної ємності нелінійно залежить від миттєвої амплітуди струму. Узагальнений інтегральний критерій Пойкерта встановлює, що розряд вважається завершеним у момент часу `T_кін`, коли інтеграл від струму, піднесеного до степеня `k`, досягає константи `C_p`:

```
∫[0 до T_кін] (i(t))ᵏ dt = C_p
```

У мікроконтролерних системах профіль споживання складається з періодичної послідовності `M` дискретних станів. Кожен стан `j` (де `j ∈ {1, 2, ..., M}`) характеризується сталим струмом `I_j` та тривалістю `t_j`. Загальний період одного циклу становить:

```
T_цикл = ∑[j=1 до M] t_j
```

Обчислимо внесок одного періоду `T_цикл` у ліву частину інтегрального критерію Пойкерта. Оскільки струм на кожному інтервалі є кусково-сталим, інтеграл за один період перетворюється на зважену суму:

```
S_цикл = ∑[j=1 до M] (I_jᵏ · t_j)
```

Кількість повних робочих циклів `N_цикл`, яку батарея здатна забезпечити до вичерпання корисної ємності, дорівнює відношенню константи Пойкерта до внеску одного циклу:

```
N_цикл = C_p ÷ S_цикл = (I_номᵏ⁻¹ · C_ном · 3600) ÷ (∑[j=1 до M] I_jᵏ · t_j)
```

де множник 3600 переводить години в секунди, якщо інтервали часу `t_j` задано в секундах, а ємність `C_ном` — в ампер-годинах.

Загальний час автономної роботи системи `T_автоном` (у секундах) розраховують як добуток кількості циклів на період одного циклу:

```
T_автоном = N_цикл · T_цикл = (I_номᵏ⁻¹ · C_ном · 3600 · T_цикл) ÷ (∑[j=1 до M] I_jᵏ · t_j)
```

Еквівалентний ефективний струм розряду `I_пойкерт_екв`, який відображає реальну швидкість хімічного виснаження батареї, визначається зі співвідношення:

```
I_пойкерт_екв = ( (1 ÷ T_цикл) · ∑[j=1 до M] (I_jᵏ · t_j) )^(1 ÷ k)
```

Цей результат наочно демонструє причину втрати ємності: оскільки `k > 1`, за рахунок нелінійності степеневої функції навіть дуже короткі імпульси великого струму (наприклад, 100 мА протягом 50 мс) роблять внесок у величину `I_jᵏ · t_j`, що на кілька порядків перевищує внесок тривалого мікроамперного сну.

### 2. Кінетична двоємнісна модель батареї (KiBaM) та ефект релаксації

Інтеграл Пойкерта не враховує процес відновлення концентрації іонів під час паузи між імпульсами. Для точного опису динаміки імпульсного розряду застосовують кінетичну модель акумулятора **KiBaM** (*Kinetic Battery Model*), розроблену Менвеллом і МакГованом (*J. F. Manwell, J. G. McGowan*).

У моделі KiBaM повний хімічний запас заряду батареї `q_повн` умовно розділено на два сполучені гідравлічні резервуари:
1. **Резервуар доступного заряду (Available Charge Well) `q_1(t)`:** з нього струм навантаження `i(t)` відбирається безпосередньо у зовнішнє електричне коло. Частка повного об'єму, відведена під доступний резервуар, позначається як `c` (де `0 < c < 1`).
2. **Резервуар зв'язаного заряду (Bound Charge Well) `q_2(t)`:** містить хімічно зв'язану енергію в товщі електродів, яка не може бути віддана миттєво. Частка цього резервуара становить `(1 - c)`.

Рівні «електрохімічного потенціалу» в обох резервуарах визначаються як відношення збереженого в них заряду до їхньої місткості:

```
h_1(t) = q_1(t) ÷ c
h_2(t) = q_2(t) ÷ (1 - c)
```

Швидкість перетікання заряду між зв'язаним і доступним резервуарами пропорційна різниці їхніх рівнів `(h_2 - h_1)` і коефіцієнту швидкості хімічної дифузії `k_диф` (с⁻¹). 

Динаміка системи описується системою двох лінійних диференціальних рівнянь першого порядку:

```
dq_1(t) ÷ dt = -i(t) + k_диф · ( (q_2(t) ÷ (1 - c)) - (q_1(t) ÷ c) )
dq_2(t) ÷ dt = -k_диф · ( (q_2(t) ÷ (1 - c)) - (q_1(t) ÷ c) )
```

Зведемо систему до канонічного вигляду, ввівши позначення параметра зв'язку `k' = k_диф ÷ (c · (1 - c))`:

```
dq_1(t) ÷ dt = -i(t) + k_диф · (q_2(t) ÷ (1 - c)) - (k_диф ÷ c) · q_1(t)
dq_2(t) ÷ dt = -k_диф · (q_2(t) ÷ (1 - c)) + (k_диф ÷ c) · q_1(t)
```

Повний заряд системи в будь-який момент часу дорівнює сумі двох компонентів:

```
q_повн(t) = q_1(t) + q_2(t)
dq_повн(t) ÷ dt = dq_1(t) ÷ dt + dq_2(t) ÷ dt = -i(t)
```

#### Аналітичний розв'язок для прямокутного імпульсу струму

Нехай на початку імпульсу при `t = 0` система перебувала в рівноважному стані з початковим зарядом `q_1(0) = q_1_0` та `q_2(0) = q_2_0` (при цьому `h_1(0) = h_2(0) = h_0`). До батареї прикладається постійний струм розряду `i(t) = I_імпульс` тривалістю `t_імп`.

Розв'язок системи для резервуара доступного заряду `q_1(t)` набуває вигляду:

```
q_1(t) = q_1_0 · e^(-k' · t) + ( (q_повн_0 · k_диф · c - I_імпульс) ÷ k' ) · (1 - e^(-k' · t)) - (I_імпульс · c · (k' · t - 1 + e^(-k' · t))) ÷ k'
```

де `q_повн_0 = q_1_0 + q_2_0`.

З аналітичного виразу видно, що під час відбору великого струму `I_імпульс` доступний заряд `q_1(t)` стрімко падає значно швидше, ніж повний заряд батареї `q_повн(t)`. Якщо доступний заряд `q_1(t)` зменшується до нуля, напруга на виводах батареї падає нижче робочого порогу, навіть якщо у зв'язаному резервуарі `q_2(t)` залишається до 80% невитраченої енергії.

#### Аналітичний розв'язок для фази релаксації (глибокий сон)

Після вимкнення активного навантаження при `i(t) = I_сон ≈ 0` починається відновлення доступного заряду за рахунок перетікання носіїв зі зв'язаного резервуара. Для початкових умов на момент завершення імпульсу `q_1(t_імп)` та `q_2(t_імп)` зміна заряду доступного резервуара у часі `t` (де відлік `t` починається після завершення імпульсу) описується виразом:

```
q_1(t) = q_1(t_імп) · e^(-k' · t) + c · q_повн(t_імп) · (1 - e^(-k' · t))
```

При тривалому часі релаксації `t >> 1 ÷ k'` експоненційний член `e^(-k' · t) → 0`, і рівні в обох резервуарах знову вирівнюються:

```
q_1(t → ∞) = c · q_повн(t_імп)
h_1(t → ∞) = h_2(t → ∞) = q_повн(t_імп)
```

Кінетична модель KiBaM строго доводить: чим більша шпаруватість робочого циклу (чим довший інтервал сну між радіосеансами), тим повніше відновлюється доступний приелектродний заряд і тим вищу частку номінальної ємності здатна віддати батарея.

### 3. Експоненційна модель саморозряду та втрати ємності

Внутрішній хімічний саморозряд батареї є незворотним процесом втрати активної маси внаслідок паразитних хімічних реакцій між електродами та електролітом.

Якщо швидкість паразитичної реакції пропорційна концентрації залишкових активних реагентів, зменшення хімічно доступного заряду `Q_хім(t)` описується диференціальним рівнянням першого порядку:

```
dQ_хім(t) ÷ dt = -λ_саморозряд · Q_хім(t)
```

де `λ_саморозряд` — константа швидкості саморозряду (с⁻¹ або рік⁻¹).

Інтегруючи це рівняння від початкового моменту `t = 0` з початковою номінальною ємністю `Q_0 = C_ном`, отримуємо класичний закон радіоактивного / хімічного розпаду:

```
Q_хім(t) = Q_0 · e^(-λ_саморозряд · t)
```

Якщо в паспортних даних виробника вказано річний відсоток саморозряду `S_рік` (наприклад, `S_рік = 1.0%` для Li-SOCl2 за температури +20°C), константу `λ_саморозряд` (у розрахунку на один рік) визначають зі співвідношення:

```
1 - (S_рік ÷ 100%) = e^(-λ_саморозряд · 1 рік)
```

Логарифмуючи обидві частини, отримуємо точне значення константи швидкості:

```
λ_саморозряд = -ln(1 - (S_рік ÷ 100%))
```

Для малих значень річного саморозряду (`S_рік < 5%`) застосовують розклад логарифма в ряд Тейлора:

```
-ln(1 - x) = x + x² ÷ 2 + x³ ÷ 3 + ... ≈ x
```

звідки з високою точністю випливає лінійне наближення: `λ_саморозряд ≈ S_рік ÷ 100%` (на рік).

#### Температурна залежність саморозряду за рівнянням Арреніуса

Константа швидкості хімічного саморозряду `λ_саморозряд` експоненційно зростає з підвищенням абсолютної температури `T` (у Кельвінах) відповідно до закону Сванте Арреніуса:

```
λ_саморозряд(T) = λ_0 · e^(-E_a ÷ (R_газ · T))
```

де `E_a` — енергія активації паразитичної реакції корозії літію (типово `E_a ≈ 45 – 65 кДж/моль`), `R_газ = 8.314 Дж/(моль·К)` — універсальна газова стала, а `λ_0` — передекспоненційний частотний фактор.

Якщо відома константа саморозряду `λ(T_базова)` за базової температури `T_базова = 293.15 К` (+20°C), швидкість саморозряду за довільної експлуатаційної температури `T_робоча` розраховують через температурний коефіцієнт прискорення:

```
λ_саморозряд(T_робоча) = λ_саморозряд(T_базова) · e^( (E_a ÷ R_газ) · ( (1 ÷ T_базова) - (1 ÷ T_робоча) ) )
```

### 4. Динаміка падіння напруги на внутрішньому опорі та умова відсічки

Внутрішній імпеданс батареї у часовій області моделюється еквівалентною схемою Рендлса, яка складається з послідовного активного омічного опору електроліту та струмознімачів `R_омічний`, паралельного RC-ланцюга поляризації поверхні електродів (`R_перенесення_заряду` та ємність подвійного електричного шару `C_дпш`), а також дифузійного елемента Варбурга.

Для імпульсів струму тривалістю понад 5–10 мс перехідний процес поляризації завершується, і повний внутрішній опір комірки можна вважати еквівалентним активним опором `R_внутр(SoC, T)`.

Термінальна напруга на виводах батареї `V_клеми(t)` під час протікання струму навантаження `i(t)` описується рівнянням:

```
V_клеми(t) = V_ocv(SoC(t), T) - i(t) · R_внутр(SoC(t), T)
```

де `V_ocv(SoC, T)` — напруга розімкненого кола (Open Circuit Voltage), яка є нелінійною функцією поточного ступеня зарядженості `SoC` (від 1.0 для повністю зарядженого елемента до 0.0 для розрядженого).

Апаратна відсічка пристрою настає в момент, коли напруга на клемах падає нижче критичного порогу вимкнення стабілізатора або супервізора мікроконтролера `V_мін_UVLO`:

```
V_клеми(t) < V_мін_UVLO
```

Підставивши вираз термінальної напруги, отримуємо точну умову передчасного апаратного вимкнення:

```
V_ocv(SoC, T) - I_пік · R_внутр(SoC, T) < V_мін_UVLO
```

Звідси визначається гранично допустимий внутрішній опір батареї `R_внутр_макс`, перевищення якого призводить до аварійного скидання системи:

```
R_внутр_макс = (V_ocv(SoC, T) - V_мін_UVLO) ÷ I_пік
```

> 🔧 **Навіщо це на практиці.** Нехай елемент Li-SOCl2 наприкінці розряду має `V_ocv = 3.30 В`. Радіомодуль споживає під час передачі `I_пік = 120 мА` (0.12 А), а поріг спрацьовування захисту від зниження напруги становить `V_мін_UVLO = 2.20 В`. Граничний внутрішній опір дорівнює: `R_внутр_макс = (3.30 В - 2.20 В) ÷ 0.12 А = 1.10 В ÷ 0.12 А ≈ 9.17 Ом`. Якщо внаслідок зимового морозу опір батареї зросте до 15 Ом, напруга на клемах під час спроби радіопередачі просяде до `3.30 В - 0.12 А · 15 Ом = 1.50 В`, викликаючи негайне перезавантаження контролера, навіть якщо за хімічним складом батарея заповнена на 50%.

### 5. Аналітичний розрахунок буферного конденсатора

Щоб запобігти падінню напруги на клемах хімічного джерела, паралельно до батареї підключають буферний накопичувач електричного заряду (суперконденсатор або гібридний модуль HLC) ємністю `C_буфер` з еквівалентним послідовним опором `R_esr_конд << R_внутр_бат`.

Розглянемо замкнену систему «батарея — конденсатор — навантаження». За першим законом Кірхгофа струм навантаження `i_навант(t)` у будь-який момент часу формується сумою струму, відданого конденсатором `i_конд(t)`, та струму, що протікає крізь батарею `i_бат(t)`:

```
i_навант(t) = i_конд(t) + i_бат(t)
```

Рівняння для напруги на паралельній шині живлення `v_шина(t)` має вигляд:

```
v_шина(t) = V_ocv - i_бат(t) · R_внутр_бат
i_конд(t) = C_буфер · (dv_шина(t) ÷ dt)
```

Підставивши струм конденсатора, отримуємо диференціальне рівняння першого порядку відносно напруги на шині під час прямокутного імпульсу струму `i_навант(t) = I_пік`:

```
C_буфер · (dv_шина(t) ÷ dt) + ( (v_шина(t) - V_ocv) ÷ R_внутр_бат ) = -I_пік
```

Позначимо постійну часу кола заряду-розряду як `τ_буфер = R_внутр_бат · C_буфер`. Розв'язок рівняння для початкової умови `v_шина(0) = V_ocv` має вигляд:

```
v_шина(t) = V_ocv - I_пік · R_внутр_бат · (1 - e^(-t ÷ τ_буфер))
```

Оскільки тривалість радіоімпульсу `t_імп` (10–50 мс) значно менша за постійну часу буфера `τ_буфер = R_внутр_бат · C_буфер` (яка для ємностей 50–200 мФ і опору 20–50 Ом становить 1–10 секунд), можна скористатися наближенням Тейлора для експоненти при `t << τ`:

```
1 - e^(-t ÷ τ) = (t ÷ τ) - (t² ÷ (2·τ²)) + ... ≈ t ÷ τ
```

Підставляючи лінійне наближення у вираз напруги, отримуємо:

```
v_шина(t) ≈ V_ocv - I_пік · R_внутр_бат · (t ÷ (R_внутр_бат · C_буфер)) = V_ocv - (I_пік · t) ÷ C_буфер
```

Внутрішній опір батареї `R_внутр_бат` повністю скоротився. Це означає, що протягом короткого імпульсу практично весь струм постачає конденсатор, а просадка напруги на шині `ΔV_просадка = V_ocv - v_шина(t_імп)` залежить виключно від ємності буфера:

```
ΔV_просадка = (I_пік · t_імп) ÷ C_буфер
```

Для забезпечення гарантованої працездатності просадка напруги за час імпульсу не повинна перевищувати допустимого запасу `ΔV_допустиме = V_ocv_EOL - V_мін_UVLO - V_запас`. Звідси отримуємо фундаментальне рівняння інженерного вибору ємності буфера:

```
C_буфер ≥ (I_пік · t_імп) ÷ (V_ocv_EOL - V_мін_UVLO - V_запас)
```

### 6. Повний числовий приклад інтегрального розрахунку

Розглянемо вичерпний покроковий числовий розрахунок для автономного ультразвукового лічильника газу з передавачем NB-IoT:

* **Джерело струму:** елемент Li-SOCl2 (розмір D), паспортна ємність `C_ном = 19.0 А·год` (19 000 мА·год), струм вимірювання номіналу `I_ном = 2.0 мА`, показник Пойкерта `k = 1.06`.
* **Річний саморозряд за середньорічної температури +15°C:** `S_рік = 1.0%/рік`.
* **Мінімальна напруга живлення схеми:** `V_мін_UVLO = 2.40 В`, гарантований запас `V_запас = 0.20 В`.
* **Напруга OCV наприкінці життєвого циклу:** `V_ocv_EOL = 3.30 В`.
* **Внутрішній опір батареї на морозі -20°C наприкінці життя:** `R_внутр_EOL_cold = 24.0 Ом`.
* **Профіль навантаження (період циклу `T_період = 3600 с` — один сеанс зв'язку на годину):**
  1. Сон: `I_1 = 3.5 мкА = 0.0035 мА`, `t_1 = 3598.8 с`.
  2. Ультразвукове вимірювання витрати (кожні 10 с, сумарно за годину): `I_2 = 12.0 мА`, `t_2 = 0.8 с`.
  3. Реєстрація в мережі та передача NB-IoT (TX): `I_3 = 220.0 мА`, `t_3 = 0.3 с` (300 мс).
  4. Прийом квитанції базової станції (RX): `I_4 = 40.0 мА`, `t_4 = 0.1 с` (100 мс).

#### Крок 1. Перевірка необхідності буферного конденсатора

Обчислимо напругу на клемах під час передачі NB-IoT (`I_3 = 220 мА = 0.22 А`) без буфера:

```
V_клеми_пік = V_ocv_EOL - I_3 · R_внутр_EOL_cold
= 3.30 В - 0.22 А · 24.0 Ом   [закон Ома для повного кола]
= 3.30 В - 5.28 В            [падіння напруги на внутрішньому опорі]
= -1.98 В < 2.40 В           [неприпустима глибока просадка нижче UVLO]
```

Батарея фізично нездатна забезпечити струм 220 мА без буфера.

Розрахуємо необхідну ємність буферного конденсатора для утримання просадки напруги в межах `ΔV_допустиме = 3.30 В - 2.40 В - 0.20 В = 0.70 В`:

```
C_буфер ≥ (I_3 · t_3) ÷ ΔV_допустиме
= (0.22 А · 0.30 с) ÷ 0.70 В   [інтеграл заряду імпульсу]
= 0.066 Кл ÷ 0.70 В            [кулони ділимо на допустиме падіння]
= 0.0943 Ф = 94.3 мФ           [мінімальна ємність буфера]
```

Обираємо стандартний гібридний літієвий шар HLC1550 ємністю 140 мФ із внутрішнім опором 0.12 Ом і власним струмом витоку `I_витік_конд = 1.0 мкА`.

#### Крок 2. Інтегрування витрати заряду навантаженням за один цикл

```
Q_цикл_кулони = I_1·t_1 + I_2·t_2 + I_3·t_3 + I_4·t_4
= 0.0000035 А · 3598.8 с + 0.012 А · 0.8 с + 0.220 А · 0.3 с + 0.040 А · 0.1 с
= 0.012596 Кл + 0.009600 Кл + 0.066000 Кл + 0.004000 Кл
= 0.092196 Кл за один цикл (1 година)
```

Переведемо заряд одного циклу в міліампер-години:

```
Q_цикл_мАгод = 0.092196 Кл ÷ 3.6 = 0.02561 мА·год/цикл
```

Річна кількість циклів становить `N_рік = 8766 циклів/рік`. Річне споживання електронної схеми:

```
Q_навант_рік = 8766 · 0.02561 мА·год ≈ 224.50 мА·год/рік
```

#### Крок 3. Врахування внутрішнього саморозряду та витоку конденсатора

Річний саморозряд батареї (1.0% від 19 000 мА·год):

```
Q_саморозряд_рік = 19 000 мА·год · 0.010 = 190.00 мА·год/рік
```

Річний струм витоку буферного конденсатора HLC (1.0 мкА):

```
Q_витік_конд_рік = (0.001 мА · 8766 год) = 8.77 мА·год/рік
```

Сумарний річний бюджет витрати заряду:

```
Q_сума_рік = Q_навант_рік + Q_саморозряд_рік + Q_витік_конд_рік
= 224.50 + 190.00 + 8.77 = 423.27 мА·год/рік
```

#### Крок 4. Підсумковий розрахунок терміну служби

Оскільки буферний конденсатор повністю згладжує піки струму і батарея віддає струм у квазістаціонарному режимі підзарядки з амплітудою менше 1.5 мА (що нижче номінального тестового струму 2.0 мА), пойкертівські втрати зведені до мінімуму (`K_пойкерт = 0.98`). Температурний коефіцієнт для помірного клімату становить `K_темп = 0.95`, коефіцієнт відсічки `K_відсічка = 0.96`.

Корисна ємність батареї:

```
C_корисна = 19 000 мА·год · 0.98 · 0.95 · 0.96 ≈ 16 980 мА·год
```

Розрахунковий час автономної роботи:

```
T_експлуатації = C_корисна ÷ Q_сума_рік
= 16 980 мА·год ÷ 423.27 мА·год/рік
≈ 40.1 року
```

З урахуванням коефіцієнта інженерного запасу `K_запас = 0.80` та природного старіння полімерних герметизуючих прокладок корпусу батареї (максимальний гарантований ресурс герметизації становить 20–25 років), отримуємо гарантований термін служби **понад 20 років**.
