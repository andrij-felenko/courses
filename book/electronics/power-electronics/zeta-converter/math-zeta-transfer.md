# 🧮 Звідки в Zeta береться D/(1−D): вольт-секундний баланс та розрахунок ємнісного моста

> Передатна характеристика перетворювача Zeta виводиться з фундаментальних законів збереження: вольт-секундного балансу для двох окремих індуктивностей та ампер-секундного балансу для проміжного розділового конденсатора. Тут наведено строгий математичний аналіз усталеного режиму в неперервному режимі провідності (CCM), визначення середніх і діючих струмів компонентів, виведення умови занулення вихідних пульсацій для зв'язаних індуктивностей, розрахунок межі переривчастого режиму (DCM), а також повний математичний апарат лінеаризації методом усереднення у просторі станів (State-Space Averaging) із виведенням матриць стану, характеристичного многочлена четвертого порядку, аналізом аудіо-сприйнятливості (Audio Susceptibility), вихідного імпедансу та числовим розрахунком нуля у правій півплощині (RHPZ).

### Топологічна розмітка: вузли, напруги та струми

Для математичного опису схеми зафіксуємо позначення вузлів та напрямки електричних величин:

Вхідне джерело постійної напруги `Vвх` підімкнене до вхідного силового ключа `Q1` (верхнє плече, High-Side). За ключем розташований перший комутаційний вузол `SW1`.

Від вузла `SW1` перша індуктивність `L1` підімкнена до спільної шини (GND, 0 В). Також від вузла `SW1` увімкнено проміжний розділовий конденсатор `Cc` (літаючий конденсатор), що з'єднує його з другим комутаційним вузлом `SW2`.

До вузла `SW2` підключено катод випрямного діода `D1` (анод з'єднаний із землею 0 В) та вихідну індуктивність `L2`. Другий кінець котушки `L2` під'єднаний до вихідного фільтруючого конденсатора `Свих` та паралельного навантаження з опором `Rнав`, формуючи стабілізовану додатну напругу `Vвих`.

Визначимо миттєві напруги на реактивних елементах:

```
v_L1 = v_SW1 − 0         [плюс на вузлі SW1, мінус на землі]
v_L2 = v_SW2 − Vвих      [плюс на вузлі SW2, мінус на виході]
v_Cc = v_SW2 − v_SW1     [плюс на обкладці SW2, мінус на обкладці SW1]
```

Додатні напрямки струмів:
- Струм `i_L1` тече від вузла `SW1` у землю через котушку `L1`.
- Струм `i_L2` тече від вузла `SW2` у вихідний вузол через котушку `L2`.
- Струм `i_Cc` тече від вузла `SW1` до вузла `SW2` через конденсатор `Cc`.

Робочі припущення квазістаціонарного аналізу:
1. Пульсації напруги на конденсаторах `Cc` та `Свих` є малими порівняно з їхніми постійними складовими: `Δv_Cc ≪ V_Cc`, `Δv_вих ≪ Vвих` (наближення малої пульсації).
2. Падінням напруги на відкритому транзисторі та діоді тимчасово нехтуємо (`R_DS(on) = 0`, `V_F = 0`), врахувавши їх пізніше як інженерну поправку.
3. Струми в обох індуктивностях не спадають до нуля протягом усього періоду комутації `T = 1 / f_sw` (режим неперервної провідності CCM).

### Напруги на індуктивностях у двох комутаційних тактах

Період перемикання розбивається на дві фази: інтервал замкненого стану ключа `Q1` тривалістю `t_on = D · T` та інтервал розімкненого стану тривалістю `t_off = (1 − D) · T`, де `D` — коефіцієнт заповнення (шпаруватість ШІМ).

#### Фаза 1: Ключ Q1 замкнений, діод D1 закритий (`0 ≤ t < D · T`)

Замикання ключа `Q1` підтягує вузол `SW1` безпосередньо до вхідної напруги:

```
v_SW1 = Vвх
```

Напруга на першій індуктивності `L1`:

```
v_L1(Фаза 1) = v_SW1 − 0 = +Vвх
```

Потенціал другого комутаційного вузла `SW2` визначається сумою потенціалу `SW1` та напруги на зарядженому конденсаторі `Cc`:

```
v_SW2 = v_SW1 + V_Cc = Vвх + V_Cc
```

Оскільки напруга `v_SW2 > 0`, випрямний діод `D1`, увімкнений катодом до `SW2` та анодом до землі (0 В), зміщується у зворотному напрямку. Запірна напруга діода:

```
v_D1 = 0 − v_SW2 = −(Vвх + V_Cc)
```

Напруга на вихідній індуктивності `L2`:

```
v_L2(Фаза 1) = v_SW2 − Vвих = Vвх + V_Cc − Vвих
```

#### Фаза 2: Ключ Q1 розімкнений, діод D1 відкритий (`D · T ≤ t < T`)

Ключ `Q1` розмикається. Струм вихідної індуктивності `i_L2` відмикає діод `D1`, фіксуючи потенціал другого вузла на рівні спільної землі (0 В):

```
v_SW2 = 0
```

Напруга на вихідній індуктивності `L2`:

```
v_L2(Фаза 2) = v_SW2 − Vвих = 0 − Vвих = −Vвих
```

Потенціал першого комутаційного вузла `SW1` через проміжний конденсатор опускається нижче нуля:

```
v_SW1 = v_SW2 − V_Cc = 0 − V_Cc = −V_Cc
```

Напруга на першій індуктивності `L1`:

```
v_L1(Фаза 2) = v_SW1 − 0 = −V_Cc
```

Напруга на розімкненому ключі `Q1`:

```
v_Q1 = Vвх − v_SW1 = Vвх − (−V_Cc) = Vвх + V_Cc
```

### Два вольт-секундні баланси: виведення коефіцієнта передачі та напруги V_Cc

В усталеному періодичному режимі інтеграл напруги на будь-якій індуктивності за повний період дорівнює нулю:

```
∫ v_L(t) dt = 0
```

Запишемо рівняння вольт-секундного балансу для вихідної індуктивності `L2`:

```
v_L2(Фаза 1) · D · T + v_L2(Фаза 2) · (1 − D) · T = 0
(Vвх + V_Cc − Vвих) · D + (−Vвих) · (1 − D) = 0        [підстановка напруг фаз]
Vвх · D + V_Cc · D − Vвих · D − Vвих · (1 − D) = 0      [розкриття дужок]
Vвх · D + V_Cc · D − Vвих · (D + 1 − D) = 0             [групування за Vвих]
Vвх · D + V_Cc · D − Vвих = 0                           [спрощення: D + 1 − D = 1]
Vвих = (Vвх + V_Cc) · D                                 [перше рівняння системи]
```

Тепер запишемо рівняння вольт-секундного балансу для першої індуктивності `L1`:

```
v_L1(Фаза 1) · D · T + v_L1(Фаза 2) · (1 − D) · T = 0
(+Vвх) · D + (−V_Cc) · (1 − D) = 0                      [підстановка напруг фаз]
Vвх · D − V_Cc · (1 − D) = 0                            [перенесення членів]
V_Cc = Vвх · D / (1 − D)                                [друге рівняння системи]
```

Підставимо вираз для середньої напруги конденсатора `V_Cc` у перше рівняння для вихідної напруги:

```
Vвих = [Vвх + Vвх · D / (1 − D)] · D
     = Vвх · [1 + D / (1 − D)] · D                      [винесення Vвх за дужки]
     = Vвх · [(1 − D + D) / (1 − D)] · D                [зведення до спільного знаменника]
     = Vвх · [1 / (1 − D)] · D                          [скорочення D у чисельнику]
     = Vвх · D / (1 − D)                                [підсумкова передатна характеристика]
```

Отримуємо передатну функцію напруги перетворювача Zeta:

```
Vвих / Vвх = D / (1 − D)
```

Зіставляючи два отримані результати, знаходимо фундаментальну рівність:

```
V_Cc = Vвх · D / (1 − D) = Vвих
```

Середня постійна напруга на проміжному розділовому конденсаторі `Cc` завжди строго дорівнює вихідній напрузі `Vвих`, незалежно від величини вхідної напруги `Vвх` та опору навантаження!

#### Пряме доведення через потенціали вузлів

Цей же факт можна отримати миттєво з аналізу постійних потенціалів вузлів схеми. 

Оскільки середня напруга на будь-якій котушці за період дорівнює нулю:
- Середній потенціал вузла `SW1` дорівнює потенціалу землі: `⟨v_SW1⟩ = 0 В` (бо індуктивність `L1` з'єднує `SW1` із землею).
- Середній потенціал вузла `SW2` дорівнює вихідній напрузі: `⟨v_SW2⟩ = Vвих` (бо індуктивність `L2` з'єднує `SW2` з шиною `Vвих`).

Середня напруга на конденсаторі `Cc`, увімкненому між цими вузлами:

```
⟨V_Cc⟩ = ⟨v_SW2⟩ − ⟨v_SW1⟩
       = Vвих − 0
       = Vвих
```

Підставивши `V_Cc = Vвих` у вирази миттєвих напруг на індуктивностях для обох фаз, отримуємо симетричну картину:

```
У Фазі 1 (Q1 ON):    v_L1 = +Vвх,      v_L2 = +Vвх
У Фазі 2 (Q1 OFF):   v_L1 = −Vвих,     v_L2 = −Vвих
```

Змінна напруга на обох індуктивностях у будь-яку мить часу є ідентичною за амплітудою і формою:

```
v_L1(t) = v_L2(t)
```

### Баланс заряду та визначення середніх струмів

Застосуємо закон збереження електричного заряду (ампер-секундний баланс) для конденсаторів схеми в усталеному режимі:

```
∫ i_C(t) dt = 0
```

#### 1. Баланс заряду проміжного конденсатора Cc

Струм через конденсатор `Cc` у двох фазах:
- У Фазі 1 (`0 ≤ t < D · T`): струм тече з вузла `SW1` у вузол `SW2`, живлячи вихідну котушку `L2`. Оскільки діод закритий, струм конденсатора дорівнює струму котушки `i_L2` (із знаком мінус для напрямку розряду): `i_Cc = −i_L2`.
- У Фазі 2 (`D · T ≤ t < T`): ключ `Q1` розімкнений, струм індуктивності `i_L1` замикається через конденсатор `Cc` та відкритий діод `D1`, заряджаючи ємність: `i_Cc = +i_L1`.

Інтегруючи струм за період:

```
(−I_L2) · D · T + (+I_L1) · (1 − D) · T = 0
I_L1 · (1 − D) = I_L2 · D
I_L1 = I_L2 · D / (1 − D)
```

#### 2. Баланс струму вихідного вузла

Оскільки вихідна котушка `L2` включена послідовно безпосередньо у вихідний вузол, весь її струм протікає у вихідний фільтр та навантаження. В усталеному стані постійний струм через вихідний конденсатор `Свих` дорівнює нулю (`⟨i_Свих⟩ = 0`).

Отже, середній струм вихідної індуктивності строго дорівнює струму споживання навантаження:

```
I_L2 = Iвих
```

Підставляючи цей результат у баланс заряду конденсатора `Cc`:

```
I_L1 = Iвих · D / (1 − D)
```

Оскільки в ідеальному перетворювачі струм споживання від джерела `Iвх` протікає лише під час Фази 1 через ключ `Q1`, несучи суму струмів `i_L1 + i_L2`:

```
Iвх = ⟨i_Q1⟩ = (I_L1 + I_L2) · D
    = [Iвих · D / (1 − D) + Iвих] · D        [підстановка I_L1]
    = Iвих · [D / (1 − D) + 1] · D           [винесення Iвих]
    = Iвих · [(D + 1 − D) / (1 − D)] · D     [зведення до спільного знаменника]
    = Iвих · D / (1 − D)                     [середній вхідний струм]
```

Звідси отримуємо точну відповідність середніх струмів котушок:

```
I_L1 = Iвх                       [середній струм L1 дорівнює вхідному струму]
I_L2 = Iвих                      [середній струм L2 дорівнює струму навантаження]
```

Перевіримо збереження балансу потужності:

```
Pвх = Vвх · Iвх
    = Vвх · [Iвих · D / (1 − D)]             [підстановка Iвх]
    = [Vвх · D / (1 − D)] · Iвих             [перегрупування співмножників]
    = Vвих · Iвих                            [підстановка Vвих]
    = Pвих                                   [вихідна потужність]
```

### Розрахунок пульсацій струмів та напруг

#### Пульсації струму в індуктивностях

Оскільки напруга на індуктивностях у Фазі 1 дорівнює `+Vвх`, амплітуда пульсації струму від піку до піку (peak-to-peak ripple) становить:

```
Δi_L1 = Vвх · D · T / L1 = Vвх · D / (L1 · f_sw)
Δi_L2 = Vвх · D · T / L2 = Vвх · D / (L2 · f_sw)
```

Або через вихідну напругу у Фазі 2:

```
Δi_L1 = Vвих · (1 − D) / (L1 · f_sw)
Δi_L2 = Vвих · (1 − D) / (L2 · f_sw)
```

#### Пульсація напруги на проміжному конденсаторі Cc

У Фазі 1 конденсатор `Cc` розряджається струмом навантаження `Iвих` протягом часу `D · T`:

```
ΔV_Cc = Iвих · D · T / Cc = Iвих · D / (Cc · f_sw)
```

#### Пульсація вихідної напруги на навантаженні

Оскільки вихідна котушка `L2` включена послідовно з вихідним вузлом, струм у конденсатор `Свих` подається не прямокутними імпульсами, а неперервною трикутною хвилею з розмахом `Δi_L2`.

Інтеграл заряду трикутної ділянки струму дає класичну формулу знижувального фільтра другого порядку:

```
ΔVвих = Δi_L2 / (8 · Свих · f_sw)
      = [Vвх · D / (L2 · f_sw)] / (8 · Свих · f_sw)
      = Vвх · D / (8 · L2 · Свих · f_sw²)
```

### Навантаження компонентів за напругою та струмом

#### Максимальна напруга блокування

У Фазі 2 комутаційний вузол `SW1` опускається до потенціалу `−Vвих`, а вузол `SW2` заземлюється діодом. Максимальна напруга на закритому транзисторі `Q1`:

```
V_Q1,max = Vвх − (−Vвих) = Vвх + Vвих = Vвх / (1 − D)
```

У Фазі 1 вузол `SW2` піднімається до потенціалу `Vвх + Vвих`. Зворотна запірна напруга на діоді `D1`:

```
V_D1,max = Vвх + Vвих = Vвх / (1 − D)
```

#### Піковий та середньоквадратичний струм ключів

Струм через ключ `Q1` у відкритому стані дорівнює сумі струмів індуктивностей: `i_Q1 = i_L1 + i_L2`.

Піковий струм транзистора `Q1` та діода `D1`:

```
I_pk = I_L1 + I_L2 + (Δi_L1 + Δi_L2) / 2
     = Iвх + Iвих + (Δi_L1 + Δi_L2) / 2
     = Iвих · [1 + D / (1 − D)] + (Δi_L1 + Δi_L2) / 2
     = [Iвих / (1 − D)] + (Δi_L1 + Δi_L2) / 2
```

Діюче (RMS) значення струму транзистора `Q1`:

```
I_Q1,rms = √[ (1 / T) · ∫₀^(D·T) (Iвх + Iвих)² dt ]
         = √(D) · (Iвх + Iвих)
         = √(D) · [Iвих / (1 − D)]
```

Діюче значення струму діода `D1`:

```
I_D1,rms = √[ (1 / T) · ∫_(D·T)^T (Iвх + Iвих)² dt ]
         = √(1 − D) · (Iвх + Iвих)
         = [1 / √(1 − D)] · Iвих
```

Діючий струм пульсацій через проміжний конденсатор `Cc`:

```
I_Cc,rms = √[ D · (−Iвих)² + (1 − D) · (+Iвх)² ]
         = √[ D · Iвих² + (1 − D) · (Iвих · D / (1 − D))² ]
         = Iвих · √[ D + D² / (1 − D) ]
         = Iвих · √[ D · (1 − D + D) / (1 − D) ]
         = Iвих · √( D / (1 − D) )
         = Iвих · √( Vвих / Vвх )
```

### Математика зв'язаних індуктивностей та керування пульсаціями

Розглянемо випадок виконання індуктивностей `L1` та `L2` у вигляді двох обмоток на спільному магнітному осерді з коефіцієнтом зв'язку `k = M / √(L1 · L2)` та числом витків `N1`, `N2`.

Рівняння напруг для пари зв'язаних котушок:

```
v_L1 = L1 · (di_L1 / dt) + M · (di_L2 / dt)
v_L2 = M · (di_L1 / dt) + L2 · (di_L2 / dt)
```

Застосовуючи правило Крамера, розв'яжемо систему відносно швидкості наростання вихідного струму `di_L2 / dt`:

```
di_L2 / dt = (L1 · v_L2 − M · v_L1) / (L1 · L2 − M²)
```

Оскільки напруги на обох котушках строго збігаються у будь-який момент часу (`v_L1(t) = v_L2(t) = v_ac(t)`):

```
di_L2 / dt = v_ac · (L1 − M) / [L1 · L2 · (1 − k²)]
```

Підставимо взаємоіндуктивність `M = k · √(L1 · L2)` та відношення витків `n = N2 / N1 = √(L2 / L1)`:

```
L1 − M = L1 − k · √(L1 · n² · L1) = L1 · (1 − k · n)
```

Звідси швидкість зміни вихідного струму:

```
di_L2 / dt = v_ac · [L1 · (1 − k · n)] / [L1 · L2 · (1 − k²)]
```

#### Умова занулення пульсацій вихідного струму

Якщо співвідношення витків обмоток обрати рівним коефіцієнту магнітного зв'язку:

```
n = N2 / N1 = 1 / k     або при ідентичній намотці k = 1: n = 1
```

Тоді чисельник виразу перетворюється на точний нуль:

```
1 − k · n = 0   ⇒   di_L2 / dt = 0
```

Пульсація струму вихідної індуктивності `Δi_L2` стає **рівною строго нулю**. Змінна ЕРС взаємоіндукції, трансформована з первинної обмотки `L1`, у кожну мить періоду повністю компенсує прикладену зовнішню змінну напругу, перетворюючи струм `i_L2` на ідеально гладку лінію постійного струму.

### Граничний та переривчастий режим провідності (DCM)

При зменшенні струму навантаження перетворювач переходить у переривчастий режим провідності (DCM), коли струм діода `i_D1` спадає до нуля до закінчення інтервалу `(1 − D) · T`.

Струм діода у Фазі 2 дорівнює сумі струмів індуктивностей: `i_D1(t) = i_L1(t) + i_L2(t)`.

Середнє значення цього сумарного струму:

```
⟨i_D1⟩ = (I_L1 + I_L2) · (1 − D) = [Iвих / (1 − D)] · (1 − D) = Iвих
```

Розмах пульсацій сумарного струму:

```
Δi_sum = Δi_L1 + Δi_L2 = Vвих · (1 − D) · T · (1 / L1 + 1 / L2) = Vвих · (1 − D) / (L_eq · f_sw)
де еквівалентна паралельна індуктивність L_eq = (L1 · L2) / (L1 + L2).
```

Межа переходу між CCM та DCM виникає, коли мінімальне миттєве значення струму діода досягає нуля:

```
Iвих,крит = Δi_sum / 2 = Vвих · (1 − D) / (2 · L_eq · f_sw)
```

Враховуючи `1 − D = Vвх / (Vвх + Vвих)`:

```
Iвих,крит = [Vвх · Vвих / (Vвх + Vвих)] / (2 · L_eq · f_sw)
```

Якщо струм навантаження `Iвих < Iвих,крит`, виникає третя комутаційна фаза (інтервал розриву провідності `D3 · T`), де струми індуктивностей замикаються у замкнений коливальний контур через `Cc`, а вихідна напруга зростає і починає залежати від опору навантаження `Rнав`.

### Математичний апарат лінеаризації у просторі станів (State-Space Averaging)

Для точного проектування аналогової або цифрової системи керування перетворювачем Zeta сформуємо систему диференціальних рівнянь у матричній формі простору станів:

```
d x(t) / dt = A_k · x(t) + B_k · u(t)
y(t) = C_k · x(t) + D_k · u(t)
```

Вектор змінних стану системи складається з 4 реактивних величин:

```
x(t) = [ i_L1(t),  i_L2(t),  v_Cc(t),  v_Свих(t) ]ᵀ
```

Вхідний вектор збурень: `u(t) = Vвх(t)`. Вихідна величина: `y(t) = v_Свих(t) = Vвих(t)`.

#### Матриці стану у Фазі 1 (Q1 замкнено, інтервал D · T)

Диференціальні рівняння для струмів і напруг:

```
L1 · (di_L1 / dt) = Vвх
L2 · (di_L2 / dt) = Vвх + v_Cc − v_Свих
Cc · (dv_Cc / dt) = −i_L2
Свих · (dv_Свих / dt) = i_L2 − v_Свих / Rнав
```

Матриця стану `A1` та вхідна матриця `B1`:

```
A1 = [  0       0      0      0    ]       B1 = [ 1 / L1 ]
     [  0       0    1/L2  −1/L2   ]            [ 1 / L2 ]
     [  0    −1/Cc     0      0    ]            [   0    ]
     [  0    1/Свих    0  −1/(R·C) ]            [   0    ]
```

#### Матриці стану у Фазі 2 (Q1 розімкнено, інтервал (1 − D) · T)

Диференціальні рівняння:

```
L1 · (di_L1 / dt) = −v_Cc
L2 · (di_L2 / dt) = −v_Свих
Cc · (dv_Cc / dt) = +i_L1
Свих · (dv_Свих / dt) = i_L2 − v_Свих / Rнав
```

Матриця стану `A2` та вхідна матриця `B2`:

```
A2 = [  0       0   −1/L1     0    ]       B2 = [ 0 ]
     [  0       0      0   −1/L2   ]            [ 0 ]
     [ 1/Cc     0      0      0    ]            [ 0 ]
     [  0    1/Свих    0  −1/(R·C) ]            [ 0 ]
```

#### Усереднена модель системи

Усереднені матриці за повний період комутації розраховуються як зважена сума матриць двох фаз:

```
A = D · A1 + (1 − D) · A2
B = D · B1 + (1 − D) · B2
```

Отримуємо підсумкову усереднену матрицю стану `A`:

```
A = [  0         0     −(1−D)/L1      0      ]
    [  0         0        D/L2     −1/L2     ]
    [ (1−D)/Cc −D/Cc       0          0      ]
    [  0       1/Свих      0      −1/(R·Cвих)]
```

Вхідна усереднена матриця `B`:

```
B = [ D / L1 ]
    [ D / L2 ]
    [   0    ]
    [   0    ]
```

Вектор усталеного стану знаходять із матричного рівняння рівноваги `X = −A⁻¹ · B · Vвх`:

```
X = [ I_L1   ] = [ Vвх · D² / ((1 − D)² · Rнав) ] = [ Iвх  ]
    [ I_L2   ]   [ Vвх · D / ((1 − D) · Rнав)   ]   [ Iвих ]
    [ V_Cc   ]   [ Vвх · D / (1 − D)            ]   [ Vвих ]
    [ V_Свих ]   [ Vвх · D / (1 − D)            ]   [ Vвих ]
```

### Малосигнальна передатна функція та числовий розрахунок нулів і полюсів

Ввівши малі гармонічні збурення `x(t) = X + x̂`, `d(t) = D + d̂`, `u(t) = Vвх + v̂_вх` та розклавши в ряд Тейлора, отримуємо малосигнальне лінеаризоване рівняння стану:

```
d x̂ / dt = A · x̂ + B · v̂_вх + [(A1 − A2) · X + (B1 − B2) · Vвх] · d̂
```

Передатна функція від шпаруватості до вихідної напруги `G_vd(s) = v̂_вих(s) / d̂(s)` визначається формулою резольвенти:

```
G_vd(s) = C · (s · I − A)⁻¹ · [(A1 − A2) · X + (B1 − B2) · Vвх]
```

Після аналітичного розкриття визначника матриці четвертого порядку передатна функція набуває вигляду:

```
G_vd(s) = G_vd0 · [ (1 − s / ω_RHPZ) · (1 + s / ω_z1) ] / [ Δ(s) ]
де характеристичний многочлен четвертого порядку Δ(s) = det(s · I − A).
```

#### Низькочастотний коефіцієнт передачі за постійним струмом

```
G_vd0 = Vвх / (1 − D)²
```

#### Характеристичний многочлен та пари резонансних полюсів

Знаменник `Δ(s)` розпадається на дві пари комплексно-спряжених резонансних полюсів:

```
Δ(s) ≈ [ 1 + s / (Q1 · ω_p1) + s² / ω_p1² ] · [ 1 + s / (Q2 · ω_p2) + s² / ω_p2² ]
```

1. **Низькочастотний резонансний контур перенесення енергії L1 − Cc**:
   ```
   ω_p1 = (1 − D) / √( L1 · Cc )
   f_p1 = ω_p1 / (2 · π)
   ```
2. **Високочастотний вихідний фільтруючий резонансний контур L2 − Свих**:
   ```
   ω_p2 = 1 / √( L2 · Свих )
   f_p2 = ω_p2 / (2 · π)
   ```

#### Частота нуля у правій півплощині (RHPZ)

У режимі CCM при стрибкоподібному збільшенні шпаруватості `d` транзистор `Q1` залишається відкритим довший час. Проміжний конденсатор `Cc` віддає більше енергії, що призводить до тимчасового зменшення напруги на ньому, перш ніж нова збільшена енергія встигне надійти від входу через індуктивність `L1`.

Цей фізичний ефект формує нуль у правій півплощині комплексної змінної `s`:

```
ω_RHPZ = [Rнав · (1 − D)²] / (D · L1)
f_RHPZ = ω_RHPZ / (2 · π) = [Rнав · (1 − D)²] / (2 · π · D · L1)
```

RHP-нуль створює додатковий спад фази на −90° без супутнього спаду амплітудно-частотної характеристики. Для забезпечення стійкості петлі зворотного зв'язку частоту одиничного підсилення контуру регулювання (смугу пропускання `f_c`) обмежують рівнем:

```
f_c ≤ f_RHPZ / 4
```

### Аудіо-сприйнятливість (Audio Susceptibility) та вихідний імпеданс

1. **Передатна функція за вхідною напругою (Audio Susceptibility / Line Regulation)**:
   Показує рівень придушення вхідних пульсацій перетворювачем у розімкненому контурі:
   ```
   G_vg(s) = v̂_вих(s) / v̂_вх(s) = C · (s · I − A)⁻¹ · B
           = [ D / (1 − D) ] · [ 1 / Δ(s) ]
   ```
   На низьких частотах коефіцієнт придушення дорівнює коефіцієнту передачі `D / (1 − D)`, а на високих частотах швидко спадає зі швидкістю −40 дБ/декаду завдяки фільтрації вихідного другого порядку `L2 − Свих`.

2. **Вихідний імпеданс у розімкненому контурі (Open-Loop Output Impedance)**:
   Визначає динамічне просідання напруги при стрибку струму навантаження `î_нав(s)`:
   ```
   Z_out(s) = v̂_вих(s) / î_нав(s) = [ s · L2 ] / [ 1 + s · (L2 / Rнав) + s² · L2 · Свих ]
   ```
   Максимальний пік імпедансу досягається на частоті резонансу вихідного фільтра `f_p2`, де замкнений контур регулювання з глибоким зворотним зв'язком повинен мати достатній коефіцієнт підсилення для придушення імпедансу до рівня менше 50 мОм.

### Числовий приклад розрахунку полюсів і нулів системи

Підставимо числові параметри спроектованого перетворювача:
- Вхідна напруга: `Vвх = 12 В`, вихідна напруга `Vвих = 12 В`, коефіцієнт заповнення `D = 0.5`.
- Опір навантаження: `Rнав = 6.0 Ом` (`Iвих = 2.0 А`).
- Індуктивності: `L1 = 27 мкГн`, `L2 = 33 мкГн`.
- Ємності: `Cc = 14.1 мкФ`, `Свих = 91 мкФ`.

1. **Коефіцієнт передачі за постійним струмом**:
   ```
   G_vd0 = 12 В / (1 − 0.5)² = 12 / 0.25 = 48 В  (33.6 дБ)
   ```

2. **Частота RHP-нуля**:
   ```
   ω_RHPZ = [6.0 · (1 − 0.5)²] / [0.5 · 27 · 10⁻⁶] = [6.0 · 0.25] / 13.5 · 10⁻⁶ = 1.5 / 13.5 · 10⁻⁶ ≈ 111 111 рад/с
   f_RHPZ = 111 111 / (2 · 3.14159) ≈ 17.7 кГц
   ```

3. **Перший резонансний полюс (L1 − Cc)**:
   ```
   ω_p1 = (1 − 0.5) / √( 27 · 10⁻⁶ · 14.1 · 10⁻⁶ ) = 0.5 / √( 380.7 · 10⁻¹² ) = 0.5 / 19.51 · 10⁻⁶ ≈ 25 628 рад/с
   f_p1 = 25 628 / (2 · 3.14159) ≈ 4.08 кГц
   ```

4. **Другий резонансний полюс (L2 − Свих)**:
   ```
   ω_p2 = 1 / √( 33 · 10⁻⁶ · 91 · 10⁻⁶ ) = 1 / √( 3003 · 10⁻¹² ) = 1 / 54.8 · 10⁻⁶ ≈ 18 248 рад/с
   f_p2 = 18 248 / (2 · 3.14159) ≈ 2.90 кГц
   ```

5. **Вибір смуги зрізу регулятора**:
   Оскільки `f_RHPZ ≈ 17.7 кГц`, максимальна безпечна частота зрізу петлі зворотного зв'язку становить:
   ```
   f_c ≤ f_RHPZ / 4 = 17.7 кГц / 4 ≈ 4.4 кГц
   ```

Для стабілізації контуру на частоті `f_c = 3.5 кГц` застосовують компенсатор Type-III із розміщенням двох нулів компенсатора в зоні частот 2.5–3.5 кГц для компенсації фазового запізнення від резонансних полюсів `f_p1` та `f_p2`, забезпечуючи запас за фазою не менше 55°.
