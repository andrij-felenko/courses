# Розрахунок захисту Foldback та обмеження розсіюваної потужності

Схема захисту зі згортанням струму (англ. *foldback current limit*) розв'язує критичну проблему теплового руйнування прохідного транзистора лінійного регулятора під час короткого замикання виходу. За класичного фіксованого обмеження струму, коли регулятор просто переходить у режим джерела незмінного струму `I[max]`, усе вхідне напруження `V[in]` прикладається до силового кристала. Потужність розсіювання стрибає до пікового значення `P[sc] = V[in] · I[max]`, що за високих вхідних напруг виводить робочу точку за межі області безпечної роботи (англ. *Safe Operating Area*, SOA) і спричиняє тепловий або вторинний пробій структури.

Цей математичний розрахунок виводить аналітичні залежності для порогу спрацьовування захисту, точки перегину (коліна) характеристики `I[knee]`, залишкового струму короткого замикання `I[sc]` та траєкторії падіння потужності для резистивної схеми згортання.

### Базова модель класичного струмового обмеження

У найпростішій схемі струмового захисту вимірювальний резистор `R[sense]` вмикається послідовно з емітером або колектором прохідного транзистора `Q[pass]`. Паралельно до `R[sense]` підключається перехід база-емітер захисного біполярного транзистора `Q[limit]`. Коли падіння напруги на `R[sense]` досягає напруги відкриття p-n переходу `V[be] ≈ 0.65 В`, транзистор `Q[limit]` відкривається й шунтує струм бази `Q[pass]`, не дозволяючи вихідному струму зростати далі.

Рівняння статичного обмеження струму:

```
I[limit] = V[be] / R[sense]      [порогова умова відмикання Q_limit]
```

Розсіювана потужність на прохідному транзисторі за нормальної стабілізації напруги `V[out]` та струму навантаження `I[load]`:

```
P[norm] = (V[in] − V[out]) · I[load]      [потужність у лінійному режимі]
```

Під час короткого замикання навантаження вихідна напруга падає до нуля (`V[out] = 0 В`), а струм фіксується на рівні `I[limit]`. Потужність, що перетворюється на тепло:

```
P[sc_classic] = (V[in] − 0) · I[limit]
              = V[in] · I[limit]      [потужність КЗ за класичного обмеження]
```

Для стабілізатора з параметрами `V[in] = 24 В`, `V[out] = 5 В` та `I[limit] = 1.5 А` розсіювання потужності за номінального навантаження становить:

```
P[norm] = (24 − 5) · 1.5
        = 19 · 1.5
        = 28.5 Вт      [номінальний тепловий потік]
```

У момент глухого короткого замикання виходу на землю потужність зростає до:

```
P[sc_classic] = 24 · 1.5
              = 36.0 Вт      [тепловий потік при КЗ: приріст на 26 %]
```

Якщо вхідна напруга становить `V[in] = 35 В`, потужність короткого замикання сягне вже `52.5 Вт`, що створює небезпеку миттєвого теплового пробою без масивного тепловідводу.

### Схема згортання Foldback: топологія та вузловий аналіз

Для зменшення струму короткого замикання база захисного транзистора `Q[limit]` підключається до дільника напруги, утвореного резисторами `R[a]` (між базою `Q[limit]` та виходом `V[out]`) і `R[b]` (між базою `Q[limit]` та виводом емітера `Q[pass]`, де діє потенціал `V[e] = V[out] + I[out] · R[sense]`).

Складемо рівняння за другим законом Кірхгофа для контуру керування захисним транзистором. Потенціал емітера `Q[limit]` зафіксований на рівні вихідної напруги `V[out]`. Потенціал бази `Q[limit]` визначається суперпозицією напруг на резистивному дільнику:

```
V[b] = V[out] + (V[e] − V[out]) · (R[a] / (R[a] + R[b]))      [дільник напруги бази]
```

Підставимо зв'язок `V[e] − V[out] = I[out] · R[sense]`:

```
V[b] = V[out] + I[out] · R[sense] · (R[a] / (R[a] + R[b]))      [напруга вузла бази]
```

Напруга база-емітер захисного транзистора `V[be]` є різницею між потенціалом бази `V[b]` та потенціалом емітера `V[e_limit] = V[out]`:

```
V[be] = V[b] − V[out]
      = I[out] · R[sense] · (R[a] / (R[a] + R[b])) − (V[out] · R[b] / (R[a] + R[b]))      [повна напруга зміщення переходу]
```

Перепишемо це співвідношення у канонічному вигляді, згрупувавши доданки відносно струму та вихідної напруги:

```
V[be] · (R[a] + R[b]) = I[out] · R[sense] · R[a] − V[out] · R[b]      [зведене рівняння балансу]
```

Звідси отримуємо аналітичну залежність граничного струму спрацьовування від миттєвого значення вихідної напруги `V[out]`:

```
I[out](V[out]) = (V[be] · (1 + R[b] / R[a]) + V[out] · (R[b] / R[a])) / R[sense]      [функція згортання струму]
```

Введемо коефіцієнт поділу дільника зворотного зміщення `k = R[b] / R[a]`:

```
I[out](V[out]) = (V[be] · (1 + k) + k · V[out]) / R[sense]      [спрощена форма функції Foldback]
```

### Розрахунок струму коліна та струму короткого замикання

З отриманого лінійного рівняння видно, що струм обмеження прямо пропорційний вихідній напрузі `V[out]`. Це породжує дві характерні граничні точки:

1. **Точка коліна (максимальний робочий струм перед початком просідання напруги)** — відповідає номінальній вихідній напрузі `V[out] = V[nom]`:

```
I[knee] = (V[be] · (1 + k) + k · V[nom]) / R[sense]      [максимальний струм коліна]
```

2. **Точка короткого замикання** — відповідає падінню вихідної напруги до нуля (`V[out] = 0 В`):

```
I[sc] = (V[be] · (1 + k)) / R[sense]      [залишковий струм короткого замикання]
```

Відношення максимального струму навантаження до струму короткого замикання визначає глибину згортання струмової характеристики (англ. *foldback ratio* `M`):

```
M = I[knee] / I[sc]
  = (V[be] · (1 + k) + k · V[nom]) / (V[be] · (1 + k))
  = 1 + (k · V[nom]) / (V[be] · (1 + k))      [коефіцієнт згортання струму]
```

Розв'яжемо це рівняння відносно необхідного коефіцієнта дільника `k`:

```
M − 1 = (k / (1 + k)) · (V[nom] / V[be])      [відокремлення відношення напруг]
(M − 1) · (V[be] / V[nom]) = k / (1 + k)      [нормований вираз]
```

Позначимо допоміжну величину `α = (M − 1) · (V[be] / V[nom])`. Тоді:

```
k = α / (1 − α)      [розрахунковий коефіцієнт резистивного дільника]
```

### Траєкторія розсіювання потужності вздовж лінії згортання

Розсіювана на прохідному транзисторі потужність як функція вихідної напруги вздовж ділянки перевантаження набуває вигляду:

```
P[diss](V[out]) = (V[in] − V[out]) · I[out](V[out])
                = (V[in] − V[out]) · ((V[be] · (1 + k) + k · V[out]) / R[sense])      [потужність перевантаження]
```

Розкриємо дужки для аналізу екстремуму квадратичної функції:

```
P[diss](V[out]) = (1 / R[sense]) · [ V[in]·V[be]·(1+k) + (k·V[in] − V[be]·(1+k))·V[out] − k·V[out]² ]      [параболічна залежність потужності]
```

Оскільки коефіцієнт при `V[out]²` від'ємний (`−k / R[sense] < 0`), графік потужності є параболою з гілками, спрямованими вниз. Знайдемо напругу `V[max_p]`, за якої розсіювання досягає абсолютного піка, взявши похідну за `V[out]` і прирівнявши її до нуля:

```
d(P[diss]) / d(V[out]) = (k·V[in] − V[be]·(1+k) − 2·k·V[out]) / R[sense] = 0      [умова екстремуму потужності]
```

Звідси точка пікового теплового навантаження:

```
V[max_p] = (V[in] / 2) − (V[be] · (1 + k) / (2 · k))
         = (V[in] / 2) − (I[sc] · R[sense] / (2 · k))      [напруга максимального розсіювання]
```

Якщо `V[max_p]` потрапляє в діапазон від `0` до `V[nom]`, регулятор проходить через локальний максимум розсіювання потужності в процесі виходу з короткого замикання.

### Практичний інженерний приклад розрахунку

Розрахуємо параметри схеми Foldback для джерела живлення з наступними вихідними вимогами:
- Вхідна напруга: `V[in] = 20 В`
- Номінальна вихідна напруга: `V[nom] = 5 В`
- Максимальний струм навантаження (струм коліна): `I[knee] = 2.0 А`
- Струм короткого замикання: `I[sc] = 0.5 А` (глибина згортання `M = 2.0 / 0.5 = 4.0`)
- Напруга відмикання транзистора: `V[be] = 0.65 В`

**Крок 1: Розрахунок коефіцієнта дільника `k`**

```
α = (M − 1) · (V[be] / V[nom])
  = (4.0 − 1) · (0.65 / 5.0)
  = 3 · 0.13
  = 0.39      [коефіцієнт альфа]

k = α / (1 − α)
  = 0.39 / (1 − 0.39)
  = 0.39 / 0.61
  ≈ 0.6393      [відношення резисторів Rb / Ra]
```

**Крок 2: Розрахунок струмовимірювального резистора `R[sense]`**

Використаємо вираз для струму короткого замикання:

```
R[sense] = (V[be] · (1 + k)) / I[sc]
         = (0.65 · (1 + 0.6393)) / 0.5
         = (0.65 · 1.6393) / 0.5
         = 1.0655 / 0.5
         ≈ 2.131 Ом      [номінал струмового датчика]
```

Перевіримо струм коліна `I[knee]`:

```
I[knee] = (V[be] · (1 + k) + k · V[nom]) / R[sense]
        = (1.0655 + 0.6393 · 5.0) / 2.131
        = (1.0655 + 3.1965) / 2.131
        = 4.262 / 2.131
        = 2.000 А      [розрахунковий струм збігається точно]
```

**Крок 3: Вибір резисторів дільника `R[a]` та `R[b]`**

Щоб струм дільника не навантажував вихід регулятора, обираємо струм через подільник близько `1 мА`:

```
R[a] + R[b] ≈ V[nom] / 1 мА = 5 кОм      [орієнтовний сумарний опір]
```

При `k = R[b] / R[a] = 0.6393`:

```
R[a] = 5000 / (1 + 0.6393) ≈ 3050 Ом → обираємо стандартний номінал 3.0 кОм (E24)
R[b] = 3000 · 0.6393 ≈ 1918 Ом → обираємо стандартний номінал 2.0 кОм (E24)
```

**Крок 4: Чутливість порогів до допусків компонентів**

В умовах серійного виробництва номінали резисторів `R[sense]`, `R[a]`, `R[b]` та напруга `V[be]` мають технологічний розкид. Оцінимо чутливість струму коліна `I[knee]` до варіації параметрів через частинні похідні логарифмічної функції (коефіцієнти чутливості `S`):

```
S(I[knee], R[sense]) = (d(I[knee]) / d(R[sense])) · (R[sense] / I[knee]) = −1.0      [пряма обернена пропорційність]
```

Похибка номіналу струмового датчика `R[sense]` на `±1 %` дає рівно `∓1 %` зміни струму обмеження.

Чутливість до коефіцієнта дільника `k`:

```
d(I[knee]) / dk = (V[be] + V[nom]) / R[sense]      [похідна струму за коефіцієнтом k]
S(I[knee], k)   = (d(I[knee]) / dk) · (k / I[knee])
                = ((V[be] + V[nom]) · k) / (V[be] · (1 + k) + k · V[nom])      [коефіцієнт чутливості до дільника]
```

Для наших значень (`V[be] = 0.65 В`, `V[nom] = 5.0 В`, `k = 0.6393`):

```
S(I[knee], k) = ((0.65 + 5.0) · 0.6393) / (0.65 · 1.6393 + 0.6393 · 5.0)
              = (5.65 · 0.6393) / (1.0655 + 3.1965)
              = 3.612 / 4.262
              ≈ 0.8475      [коефіцієнт передачі похибки дільника]
```

Використання резисторів із допуском `±1 %` для `R[a]` та `R[b]` створює сумарну похибку `k` до `±2 %`, що викликає зміщення струму коліна `I[knee]` на:

```
ΔI[knee] / I[knee] = 0.8475 · (±2 %) ≈ ±1.70 %      [максимальне відхилення струму від дільника]
```

Найбільший внесок у розкид параметрів вносить нестабільність напруги відмикання `V[be]` (розкид від екземпляра до екземпляра `±30 мВ` або `±4.6 %`), що в дискретних схемах дає сумарну варіацію струму `I[sc]` до `±6 % … 8 %`. В інтегральних схемах цей розкид компенсується лазерним підгоном (англ. *laser trimming*) тонкоплівкових резисторів або використанням прецизійних джерел зміщення на основі забороненої зони (Bandgap).

**Крок 5: Порівняння теплового розсіювання**

1. Потужність під час короткого замикання за класичного обмеження (`I[limit] = 2.0 А`):

```
P[sc_classic] = V[in] · I[limit]
              = 20 В · 2.0 А
              = 40.0 Вт      [катастрофічне нагрівання]
```

2. Потужність під час короткого замикання за схеми Foldback (`I[sc] = 0.5 А`):

```
P[sc_foldback] = V[in] · I[sc]
               = 20 В · 0.5 А
               = 10.0 Вт      [зниження тепловиділення в 4 рази]
```

3. Пікове проміжне значення потужності при переході в КЗ:

```
V[max_p] = (V[in] / 2) − (V[be] · (1 + k) / (2 · k))
         = (20 / 2) − (1.0655 / (2 · 0.6393))
         = 10 − 0.833
         = 9.167 В      [напруга піку потужності перевищує Vnom]
```

Оскільки `V[max_p] = 9.167 В > V[nom] = 5 В`, екстремум параболи лежить поза робочою ділянкою. Максимальна потужність у межах робочого діапазону досягається в точці коліна (`V[out] = 5 В`):

```
P[knee] = (V[in] − V[nom]) · I[knee]
        = (20 − 5) · 2.0
        = 30.0 Вт      [максимальна потужність у робочому діапазоні]
```

### Температурний дрейф та самозахист схеми Foldback

Критичним фактором надійності інтегральних та дискретних стабілізаторів є температурна залежність напруги відкриття переходу `V[be](T)` захисного біполярного транзистора `Q[limit]`. Пряме падіння на кремнієвому p-n переході має від'ємний температурний коефіцієнт напруги (ТКН):

```
d(V[be]) / dT ≈ −2.0 мВ / °C      [температурний коефіцієнт p-n переходу]
```

Виразимо напругу `V[be]` за довільної температури кристала `T[j]`, де `T[0] = 25 °C`:

```
V[be](T[j]) = V[be](T[0]) − γ · (T[j] − T[0])      [лінеаризована температурна модель]
```

де `γ = 2.0 · 10⁻³ В/°C`. Підставимо цю залежність у вирази для струму коліна `I[knee]` та струму короткого замикання `I[sc]`:

```
I[knee](T[j]) = ( (V[be](T[0]) − γ · ΔT) · (1 + k) + k · V[nom] ) / R[sense]      [температурно-залежний струм коліна]
I[sc](T[j])   = ( (V[be](T[0]) − γ · ΔT) · (1 + k) ) / R[sense]                  [температурно-залежний струм КЗ]
```

де `ΔT = T[j] − T[0]`. Продиференціюємо струм короткого замикання за температурою:

```
d(I[sc]) / dT = −(γ · (1 + k)) / R[sense]      [швидкість спаду струму КЗ з нагрівом]
```

Оскільки похідна суворо від'ємна, зі зростанням температури кристала струм короткого замикання автоматично знижується. Це створює внутрішній від'ємний термодинамічний зворотний зв'язок (англ. *thermal foldback*): чим сильніше нагрівається кристал під час аварійного режиму, тим менший струм дозволяє пропустити схема захисту.

Для параметрів нашого числового прикладу (`k = 0.6393`, `R[sense] = 2.131 Ом`):

```
d(I[sc]) / dT = −(0.002 · 1.6393) / 2.131
              ≈ −1.538 мА / °C      [коефіцієнт теплового зниження струму]
```

Якщо під час затяжного замикання температура кристала зростає від `25 °C` до `125 °C` (`ΔT = 100 °C`), струм короткого замикання зменшується:

```
ΔI[sc] = −1.538 мА/°C · 100 °C
       = −153.8 мА = −0.154 А      [абсолютне зменшення струму КЗ]

I[sc](125 °C) = 0.500 − 0.154
              = 0.346 А      [струм КЗ при гарячому кристалі]
```

Відповідно, розсіювана потужність у гарячому стані спадає з `10.0 Вт` до:

```
P[sc](125 °C) = V[in] · I[sc](125 °C)
              = 20 В · 0.346 А
              = 6.92 Вт      [самостійне розвантаження кристала]
```

Цей механізм забезпечує додатковий запас живучості до моменту спрацьовування основного компаратора теплового захисту (англ. *Thermal Shutdown*).

### Реалізація Foldback у CMOS та низьковольтних регуляторах

У сучасних інтегральних CMOS LDO використання послідовного біполярного датчика `R[sense]` небажане через додаткове падіння напруги `V[drop_sense] = I[out] · R[sense] ≈ 0.3 … 0.6 В`, що суперечить концепції низького спаду (Dropout < 100 мВ).

Замість цього застосовують струмове дзеркало типу *SenseFET*. Силовий вихідний транзистор `M[pass]` ділиться на дві паралельні секції:
1. Основна силова секція шириною каналу `W[main]`, крізь яку протікає основний струм `I[out]`.
2. Вимірювальна секція шириною `W[sense] = W[main] / N`, де коефіцієнт масштабування `N` зазвичай лежить у межах `500 … 2000`.

Вимірювальний струм:

```
I[mirr] = I[out] / N      [струм вимірювальної копії]
```

Цей струм спрямовується у внутрішнє низькопотужне дзеркало струму й порівнюється з пороговим струмом `I[ref]`, згенерованим джерелом опорної напруги. Для реалізації характеристики Foldback у струм порівняння додають залежність від вихідної напруги:

```
I[thresh](V[out]) = I[0] + β_fb · V[out]      [динамічний поріг струмового компаратора]
```

де `I[0]` задає струм короткого замикання `I[sc] = N · I[0]`, а `β_fb` — крутизну згортання. У такій реалізації падіння напруги на силовому каналі визначається виключно `R[DS(on)]` основного транзистора, не втрачаючи мілівольтів на зовнішніх шунтах, а функція захисту повністю інтегрується у малосигнальну частину чипа.

### Динаміка відновлення та заряд вихідної ємності

Під час зняття короткого замикання вихідна напруга починає зростати за рахунок заряду вихідного конденсатора `C[out]`. Швидкість зміни напруги визначається різницею між струмом регулятора вздовж лінії Foldback та струмом підключеного навантаження `I[load](V[out])`:

```
C[out] · (d(V[out]) / dt) = I[out](V[out]) − I[load](V[out])      [диференційне рівняння заряду виходу]
```

Підставимо лінійну апроксимацію захисної характеристики `I[out](V[out]) = I[sc] + ((I[knee] − I[sc]) / V[nom]) · V[out]`:

```
d(V[out]) / dt = (1 / C[out]) · [ I[sc] + ((I[knee] − I[sc]) / V[nom]) · V[out] − I[load](V[out]) ]      [швидкість наростання напруги]
```

Розглянемо випадок чисто резистивного навантаження `R[load] = V[nom] / I[nom]`, де струм `I[load](V[out]) = V[out] / R[load]`:

```
d(V[out]) / dt = (1 / C[out]) · [ I[sc] + ( (I[knee] − I[sc])/V[nom] − 1/R[load] ) · V[out] ]      [диференційне рівняння з резистивним навантаженням]
```

Введемо коефіцієнт експоненційного росту `λ`:

```
λ = ( (I[knee] − I[sc]) / V[nom] − 1 / R[load] ) / C[out]      [характеристичний показник динаміки]
```

Розв'язок диференційного рівняння за початкової умови `V[out](0) = 0` (момент зняття замикання):

```
V[out](t) = (I[sc] / (C[out] · λ)) · (exp(λ · t) − 1)      [траєкторія відновлення вихідної напруги]
```

Для гарантованого відновлення номінального режиму показник `λ` повинен задовольняти умові стійкого зростання:

```
(I[knee] − I[sc]) / V[nom] > 1 / R[load] = I[nom] / V[nom]      [критерій безперешкодного старту]
```

Скоротивши на `V[nom]`, отримуємо фундаментальну умову запуску схеми Foldback на активне навантаження:

```
I[knee] − I[sc] > I[nom]      [гранична нерівність безпечного виходу з КЗ]
```

Оскільки за номінального режиму `I[nom] ≤ I[knee]`, перепишемо умову через відношення згортання `M = I[knee] / I[sc]`:

```
I[knee] · (1 − 1 / M) > I[nom]      [критерій через глибину згортання]
```

Якщо навантаження розраховане на повний струм `I[nom] = I[knee]`, то жодна схема з `M > 1` не зможе запуститися на чисто резистивне навантаження без попереднього зменшення струму споживання, оскільки `1 − 1/M < 1`. Саме тому номінальний робочий струм схеми обирають із запасом:

```
I[nom_max] ≤ I[knee] · (1 − 1 / M)      [максимально допустимий робочий струм]
```

Для `M = 4` та `I[knee] = 2.0 А`:

```
I[nom_max] ≤ 2.0 · (1 − 0.25) = 1.5 А      [максимальний струм навантаження для надійного старту]
```

### Зв'язок із зоною безпечної роботи (SOA) та вторинним пробоєм

Тепловий розрахунок схеми Foldback безпосередньо випливає з фізичних меж надійності біполярного транзистора, відображених на діаграмі безпечної роботи (англ. *Safe Operating Area*, SOA). На постійному струмі (DC) граничний струм колектора `I[c_max]` обмежується чотирма незалежними фізичними факторами:

1. **Технологічна межа за струмом (розварювання кристала та насичення):**
```
I[c] ≤ I[c_max_bond]      [горизонтальна лінія на логарифмічній діаграмі]
```

2. **Максимальна температура кристала (теплова гіпербола):**
```
P[diss] = V[ce] · I[c] ≤ (T[j_max] − T[a]) / θ_ja
I[c] ≤ P[max] / V[ce]      [нахил −1 на логарифмічній шкалі (45°)]
```

3. **Межа вторинного пробою (англ. *second breakdown*):**
У біполярних транзисторах при високих напругах `V[ce]` через локальну концентрацію струму та явище шнурування (англ. *current crowding*) гранично допустима потужність стрімко падає швидше за теплову гіперболу:
```
I[sb] = K[sb] / (V[ce])ⁿ      [де n ≈ 1.5 … 2.0]
```
На логарифмічній діаграмі ця лінія має крутіший нахил (від `-1.5` до `-2.0` декади струму на декаду напруги).

4. **Гранична напруга пробою колектор-емітер:**
```
V[ce] ≤ V[ceo_sus]      [вертикальна лінія максимальної напруги]
```

Накладемо навантажувальну пряму короткого замикання для обох схем захисту.

Для класичного фіксованого струмового захисту аварійна точка КЗ знаходиться при координатах `(V[in], I[limit])`. Оскільки `V[in]` велике, ця точка майже завжди потрапляє в заборонену область вторинного пробою під лінією `I[sb]`, що викликає локальний прогар кристала за лічені мікросекунди — задовго до того, як корпус мікросхеми встигне нагрітися до порогу спрацьовування теплового датчика.

Для схеми Foldback аварійна точка КЗ зміщується в координати `(V[in], I[sc])`. За рахунок зниження струму у `M = 4` рази робоча точка безпечно опускається нижче кривої вторинного пробою `I[sb](V[in])`:

```
I[sc] = I[knee] / M < K[sb] / (V[in])ⁿ      [критерій захисту від вторинного пробою]
```

Саме збереження транзистора від вторинного пробою є головною причиною застосування Foldback у високовольтних лінійних стабілізаторах (наприклад, у промислових регуляторах на 24 В, 48 В та 60 В).

### Розрахунок ємності конденсатора м'якого старту для подолання бар'єра

Щоб гарантувати запуск стабілізатора на ємнісне або низькоомне навантаження без потрапляння в стан помилкового блокування (latch-up), час наростання вихідної напруги штучно уповільнюють за допомогою ланцюга м'якого старту (англ. *soft-start*).

Схема м'якого старту керує опорною напругою `V[ref]`, плавно заряджаючи внутрішній конденсатор `C[ss]` постійним струмом `I[ss]`:

```
V[ref](t) = (I[ss] / C[ss]) · t      [лінійно зростаюча опорна напруга]
```

Вихідна напруга слідкує за опорною через петлю підсилювача похибки:

```
V[out](t) = V[ref](t) · (1 + R1 / R2)
          = (I[ss] / C[ss]) · (1 + R1 / R2) · t      [швидкість зростання виходу]
```

Швидкість наростання вихідної напруги:

```
d(V[out]) / dt = (I[ss] / C[ss]) · (1 + R1 / R2)      [темп підйому напруги]
```

Струм, необхідний для заряду зовнішньої фільтруючої ємності `C[load]`:

```
I[cap_charge] = C[load] · (d(V[out]) / dt)
              = C[load] · (I[ss] / C[ss]) · (1 + R1 / R2)      [пусковий струм конденсаторів]
```

Для того щоб пусковий струм заряду ємностей разом із постійним струмом навантаження `I[load]` не перевищив початковий поріг згортання `I[sc]`, повинна виконуватися нерівність:

```
I[cap_charge] + I[load_start] ≤ I[sc]      [умова безпечного пуску]
C[load] · (I[ss] / C[ss]) · (1 + R1 / R2) + I[load_start] ≤ I[sc]
```

Звідси розраховуємо мінімальну ємність конденсатора м'якого старту `C[ss]`:

```
C[ss] ≥ ( C[load] · I[ss] · (1 + R1 / R2) ) / ( I[sc] − I[load_start] )      [розрахункова формула ємності м'якого старту]
```

**Числовий приклад розрахунку ємності `C[ss]`:**
- Ємність навантаження: `C[load] = 470 мкФ = 4.7 · 10⁻⁴ Ф`
- Струм джерела м'якого старту: `I[ss] = 5 мкА = 5.0 · 10⁻⁶ А`
- Коефіцієнт дільника: `1 + R1 / R2 = V[nom] / V[ref] = 5.0 / 1.25 = 4.0`
- Струм КЗ схеми Foldback: `I[sc] = 0.5 А`
- Початковий струм навантаження під час старту: `I[load_start] = 0.1 А`

Підставимо значення у формулу:

```
C[ss] ≥ ( 4.7 · 10⁻⁴ · 5.0 · 10⁻⁶ · 4.0 ) / ( 0.5 − 0.1 )
C[ss] ≥ ( 9.4 · 10⁻⁹ ) / 0.4
C[ss] ≥ 2.35 · 10⁻⁸ Ф = 23.5 нФ      [мінімальна ємність м'якого старту]
```

Обираємо найближчий стандартний номінал ємності `C[ss] = 33 нФ` або `47 нФ`. Час повного виходу на режим:

```
t[start] = (C[ss] · V[ref]) / I[ss]
         = (33 · 10⁻⁹ · 1.25) / (5.0 · 10⁻⁶)
         = 41.25 · 10⁻⁹ / (5.0 · 10⁻⁶)
         ≈ 8.25 мс      [тривалість плавного старту]
```

Завдяки впровадженню часу старту `8.25 мс` пусковий струм становить лише:

```
I[cap_charge] = 470 мкФ · (5.0 В / 8.25 мс)
              = 4.7 · 10⁻⁴ · 606.06
              ≈ 0.285 А      [струм заряду менший за I_sc = 0.5 А]
```

Сумарний струм `0.285 А + 0.100 А = 0.385 А < 0.500 А`, що гарантує надійний вихід стабілізатора на режим без зависання в точці замикання.

### Застереження щодо нелінійних навантажень (Latch-up при старті)

Головний компроміс схеми Foldback полягає у взаємодії з навантаженнями типу «джерело постійного струму» або ланцюгами з низьким динамічним опором під час запуску (наприклад, розряджені ємності великої ємності чи лампи розжарювання).

Якщо навантаження споживає струм `I[load] > I[sc]` при низьких напругах, навантажувальна пряма перетинає характеристику Foldback у двох точках. У результаті стабілізатор може застрягти в стані блокування (англ. *latch-up*) із заниженою вихідною напругою `V[out] < V[nom]` і не вийти на номінальний режим після ввімкнення живлення. Для запобігання цьому явищу коефіцієнт згортання `M` обмежують значеннями `2 … 4`, а паралельно виходу встановлюють схему м'якого старту (англ. *soft-start*), яка тимчасово піднімає поріг струму на час заряду вихідних ємностей.
