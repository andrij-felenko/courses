# ⚙️ Трасування високовольтних бар'єрів у САПР: правила DRC та геометрія пазів

> Практичний алгоритм проектування гальванічно ізольованих друкованих плат у сучасних САПР (KiCad та Altium Designer). Тут розібрано налаштування матриці зазорів правил проектування (DRC Clearance Matrix), створення класів високовольтних кіл (Net Classes), геометрію суцільного розділового бар'єра полігонів (Keepout Barrier), проектування фрезерованих ізоляційних пропилів (Edge.Cuts) з урахуванням механічних напружень склотекстоліту, захисні лакові покриття (Conformal Coating), трасування оптичного зворотного зв'язку (TL431 + оптопара), топологію критичних імпульсних контурів зворотного ходу (Flyback), методи виробничого контролю (Hipot і ROSE-тест) та реалізацію інженерного калькулятора зазорів мовами C та C++.

Навіть якщо принципова електрична схема розроблена бездоганно і містить найнадійніші компоненти, груба помилка в топології друкованої плати може перетворити виріб на джерело смертельної небезпеки або призвести до займання. Система автоматизованого проектування (САПР) за замовчуванням перевіряє зазори на рівні 0.15–0.25 мм. Цього цілком достатньо для сигнальних цифрових ліній 3.3 В, але за напруги 325–400 В такий зазор буде миттєво пробитий електричною дугою.

Інженер зобов'язаний формалізувати вимоги стандартів безпеки (IEC 62368-1, IEC 60664-1 та IEC 60601-1) у вигляді математично строгих правил автоматичної перевірки геометрії плати (DRC — *Design Rule Check*).

## Розподіл топології на домени та класи кіл (Net Classes)

Першим фундаментальним кроком трасування є розбиття електричної схеми на ізольовані домени живлення та присвоєння провідникам відповідних класів кіл (*Net Classes*). Неприпустимо задавати індивідуальні зазори окремим провідникам вручну — це неминуче призведе до помилки при подальших модифікаціях плати.

1. **Домен `HV_Primary` (Гаряча первинна зона):**
   - Вхідні мережеві фазні та нульові лінії: `AC_L`, `AC_N`;
   - Виводи після вхідного випрямляча: `DC_BUS+` (+325 В DC для пасивного випрямляча або +400 В DC після коректора коефіцієнта потужності PFC) та `DC_BUS-` (первинна земля);
   - Імпульсний вузол стоку польового транзистора або колектора IGBT: `DRAIN_HV` (де діють комутаційні піки напруги амплітудою до 650–800 В із крутизною `dv/dt > 50 кВ/мкс`);
   - Первинні та допоміжні обмотки живлення ШІМ-контролера (`AUX_VCC`).
2. **Домен `LV_Secondary` (Холодна вторинна зона / SELV):**
   - Вихідні стабілізовані низьковольтні шини: `+24V`, `+12V`, `+5V`, `+3V3`;
   - Сигнальна та силова вторинні землі: `GND_SELV`;
   - Сигнали мікроконтролера, кола зворотного зв'язку TL431, інтерфейсні лінії USB, UART, CAN, Ethernet.
3. **Домен `PE_Chassis` (Захисне заземлення):**
   - Провідник захисного заземлення мережевої вилки `PE`;
   - Металізовані та неметалізовані монтажні отвори кріплення друкованої плати до металевого корпусу шасі.

```
┌───────────────────────────────────────┬─ ── ── ── ── ── ─┬───────────────────────────────────────┐
│        Домен HV_Primary               │ Ізоляційний      │        Домен LV_Secondary             │
│        (Гаряча зона)                  │ бар'єр           │        (Холодна зона SELV)            │
│                                       │ (≥ 6.0 мм без    │                                       │
│  Полігон DC_BUS+                      │  пропилу /       │  Полігон +5V / +3V3                   │
│  Полігон DC_BUS-                      │  ≥ 4.0 мм із     │  Полігон GND_SELV                     │
│  ШІМ-контролер первинного боку        │  пропилом)       │  Мікроконтролер, роз'єм USB           │
│                                       │                  │                                       │
└───────────────────────────────────────┴─ ── ── ── ── ── ─┴───────────────────────────────────────┘
```

## Налаштування правил проектування (DRC) у KiCad

У сучасних версіях KiCad (версії 7 та 8) система правил проектування підтримує декларативну мову користувацьких правил (*Custom Rules*), яка зберігається у файлі проекту або в розділі *File -> Board Setup -> Design Rules -> Custom Rules*.

Створимо повний набір правил, що гарантує контроль посиленої та базової ізоляції, а також функціональних зазорів:

```kicad
(version 1)

# 1. Посилена ізоляція: Первинний бік проти Вторинного (SELV)
# Вимагає мінімум 6.0 мм для безпечного шляху витоку на плоскій платі FR-4
(rule "Clearance_Primary_to_Secondary_Reinforced"
   (constraint clearance (min 6.0mm))
   (condition "A.NetClass == 'HV_Primary' && B.NetClass == 'LV_Secondary'"))

# 2. Базова ізоляція: Первинний бік проти Захисного заземлення PE
# Захисне заземлення вимагає мінімум 3.0 мм
(rule "Clearance_Primary_to_PE"
   (constraint clearance (min 3.0mm))
   (condition "A.NetClass == 'HV_Primary' && B.NetClass == 'PE_Chassis'"))

# 3. Вторинний бік (SELV) проти Захисного заземлення PE
# Для систем PELV/SELV зазор становить 1.5 мм
(rule "Clearance_Secondary_to_PE"
   (constraint clearance (min 1.5mm))
   (condition "A.NetClass == 'LV_Secondary' && B.NetClass == 'PE_Chassis'"))

# 4. Функціональний зазор між різними колами всередині первинного боку
# Запобігає іскрінню між AC_L і AC_N або між DC_BUS+ і DRAIN
(rule "Clearance_Within_Primary_Functional"
   (constraint clearance (min 2.0mm))
   (condition "A.NetClass == 'HV_Primary' && B.NetClass == 'HV_Primary' && A.Net != B.Net"))

# 5. Відступ високовольтних провідників від контуру плати (Edge.Cuts)
# Запобігає поверхневому пробою по зрізу склотекстоліту на корпус
(rule "Edge_Clearance_HV"
   (constraint edge_clearance (min 4.0mm))
   (condition "A.NetClass == 'HV_Primary'"))
```

Після активації цих правил вбудований трасувальник KiCad (*Router in Walkaround Mode*) не дозволить прокласти доріжку ближче заданої межі, а механізм заливки полігонів автоматично відступить від високовольтних провідників на безпечну відстань.

## Налаштування правил в Altium Designer

В Altium Designer правила ізоляції налаштовуються у діалозі *Design -> Rules -> Electrical -> Clearance*. Для матриці класів створюють спеціальні правила з пріоритетами та фільтрами мови запитів (*Query Language*):

1. **Правило посиленої ізоляції (`Clearance_HV_to_LV`):**
   - First Object Match: `InNetClass('HV_Primary')`
   - Second Object Match: `InNetClass('LV_Secondary')`
   - Minimum Clearance: `6.0 mm`
2. **Правило базової ізоляції до землі (`Clearance_HV_to_PE`):**
   - First Object Match: `InNetClass('HV_Primary')`
   - Second Object Match: `InNetClass('PE_Chassis')`
   - Minimum Clearance: `3.0 mm`
3. **Правило відступу до бар'єрного вирізу (`Clearance_HV_to_Cutout`):**
   - First Object Match: `InNetClass('HV_Primary')`
   - Second Object Match: `IsBoardCutout`
   - Minimum Clearance: `1.5 mm`

## Проектування багатошарових плат: внутрішні шари та зона відчуження

Особлива небезпека при розробці чотиришарових (4-Layer) або шестишарових (6-Layer) плат полягає в тому, що на зовнішніх шарах інженер бачить ізоляційну межу, але на внутрішніх шарах (Internal Ground/Power Planes) суцільна мідна заливка може випадково затекти під бар'єрний компонент.

```
Шар 1 (Top Layer):      [Полігон HV] ─── 6 мм зазор без міді ─── [Полігон LV]
                                       │
Шар 2 (In1 Plane):      [Полігон HV] ──┼─── Зона заборони міді ───┼── [Полігон GND]
                                       │    (Keepout Zone ≥ 8 мм)
Шар 3 (In2 Plane):      [Полігон HV] ──┼─── Зона заборони міді ───┼── [Полігон +5V]
                                       │
Шар 4 (Bottom Layer):   [Полігон HV] ─── 6 мм зазор без міді ─── [Полігон LV]
```

### Алгоритм формування зони заборони (Keepout Zone):
1. Через усю плату — від одного краю до іншого — проводиться неперервна розділова лінія бар'єра;
2. На всіх шарах плати без винятку (Top, In1, In2, Bottom) малюється полігон заборони трасування та міді (*Keepout / Route Inhibit*);
3. Ширина зони відчуження без будь-якої міді повинна становити щонайменше **6.0–8.0 мм**;
4. Єдиними елементами, що фізично перетинають цю лінію, можуть бути виключно сертифіковані бар'єрні компоненти: імпульсний трансформатор, оптопара зворотного зв'язку, цифровий ізолятор та Y1-конденсатор.

## Геометрія фрезерованих ізоляційних пропилів (Isolation Slots)

Коли через жорсткі обмеження розмірів корпусу неможливо витримати поверхневий шлях витоку 6.0 мм на площині текстоліту (наприклад, під стандартним корпусом оптопари SOP-4 або DIP-4, де відстань між рядами ніжок становить лише 4.5–5.0 мм), застосовують **ізоляційний пропил** (*Milled Slot*).

### Механіка збільшення шляху витоку через пропил

Пропил є наскрізним повітряним прорізом у склотекстоліті. Оскільки струм витоку не може перестрибнути крізь повітря (діелектрична міцність повітря 3 кВ/мм надійно тримає напругу), він змушений рухатися по поверхні текстоліту в обхід пазу:

```
       Первинна контактна площадка (Hot)        Вторинна контактна площадка (SELV)
                  ┌──────┐                                ┌──────┐
                  │ Pad  │                                │ Pad  │
                  └──────┘                                └──────┘
                     │                                       │
            ─────────┘                                       └─────────
                     |<──────────── Clearance ──────────────>|
                     |             (по повітрю: 5.0 мм)      |
                                  ┌─────────────┐
                                  │             │
                                  │   Пропил    │
                                  │  (Edge.Cuts)│
                                  │  Ширина     │
                                  │  ≥ 1.2 мм   │
                                  │             │
                                  └─────────────┘
                     |<─── d1 ───>|             |<─── d2 ───>|
```

Розрахунок еквівалентного шляху витоку:

```
Creepage_effective = d1 + Довжина_стінки_пазу + d2
```

Якщо паз заглиблений або має довжину 10 мм, ефективний шлях витоку зростає з початкових 4.5 мм до понад 8.5–10 мм, що повністю перекриває вимоги навіть для високовольтних медичних систем (2x MOPP).

### Виробничі вимоги до контуру пропилу:
1. **Ширина пазу:** суворо **`w_slot ≥ 1.0 мм`** (оптимально **1.2–1.5 мм** під стандартний діаметр кінцевої фрези механічної обробки на виробництві друкованих плат);
2. **Радіусні торці:** торці пазу повинні завершуватися півколом радіусом `R = w_slot / 2`. Гострі внутрішні кути 90° заборонені, оскільки в них виникають пікові механічні напруження при вібраціях або монтажі, що викликає розтріскування мідних доріжок поблизу пазу;
3. **Виступ пазу:** паз повинен виступати за межі проекції корпусу компонента щонайменше на 1.5–2.0 мм у кожен бік.

## Захисні лакові покриття (Conformal Coating) та їхній вплив на зазори

В електронних модулях підвищеної надійності (автомобільна електроніка, авіоніка, зовнішні базові станції зв'язку) застосовують **захисне конформне покриття** (*Conformal Coating* за стандартом IEC 60664-3 та IPC-CC-830).

Нанесення шару спеціалізованого лаку (акрилового AR, поліуретанового UR, силіконового SR чи епоксидного ER) товщиною від 25 до 75 мкм повністю ізолює поверхню текстоліту від прямого контакту з атмосферною вологою, сольовим туманом та електропровідним пилом.

### Інженерний ефект конформного покриття:
1. **Зниження ступеня забруднення:** сертифіковане суцільне покриття переводить поверхню плати зі ступеня забруднення 2 або 3 (PD 2 / PD 3) в еквівалентний ступінь **PD 1** (герметичне чисте середовище);
2. **Зменшення шляху витоку:** за стандартом IEC 62368-1 вимоги до Creepage для покритої плати стають рівними вимогам до базового Clearance (тобто шлях витоку 5.0 мм зменшується до 2.0–2.5 мм), що дозволяє істотно зменшити габарити силового модуля;
3. **Виробничі пастки лакування:**
   - Неприпустимі бульбашки повітря (*voids*) та непрофарбовані тіньові зони під низькопрофільними корпусами компонентів;
   - Заборона нанесення лаку на роз'єми, тестові контрольні точки (Test Points) та підстроювальні елементи (потрібні спеціальні маски захисту при нанесенні розпиленням).

## Трасування оптичного зворотного зв'язку (TL431 + Оптопара)

Контур зворотного зв'язку імпульсного джерела живлення — це найчутливіший сигнальний місток, що перетинає високовольтний бар'єр ізоляції. Будь-які високочастотні наведення, спіймані цим колом, викликають тремтіння шпаруватості ШІМ (фазовий джитер) або зрив стабілізації.

```
Вторинний бік (SELV)                          Первинний бік (Гарячий)
┌─────────────────────────────────┐           ┌─────────────────────────────────┐
│ V_out ──[ Резистор дільника R1 ]│           │ VCC_AUX ──[ Резистор Pull-up ]  │
│               │                 │  Бар'єр   │               │                 │
│          Вхід REF TL431         │  ізоляції │               ├──── Вхід FB ШІМ │
│               │                 │           │               │                 │
│         [ RC-компенсація ]      │ ── ── ─── │        Колектор оптопари        │
│               │                 │           │               │                 │
│         Катод TL431 ──[ LED ]───┼───────────┼──> Фототранзистор ── GND_Primary│
└─────────────────────────────────┘           └─────────────────────────────────┘
```

### Правила трасування кола зворотного зв'язку:
1. **Розділення земель під оптопарою:** під корпусом оптопари не повинно бути жодних провідників або полігонів. Первинний емітер фототранзистора підключається до тихої сигнальної землі контролера `GND_Primary`, а вторинні кола опорного джерела TL431 — до чистої вихідної землі `GND_SELV` після вихідного LC-фільтра;
2. **Фільтрація виводу FB:** паралельно колектору фототранзистора безпосередньо біля ніжки мікросхеми ШІМ встановлюють керамічний конденсатор ємністю 100–470 пФ. Він зрізає високочастотний струм зміщення, який ємність оптопари (близько 0.5–1.0 пФ) перекачує через бар'єр під час перемикання силового ключа;
3. **Кельвінівське підключення дільника:** резистивний дільник напруги виводу REF мікросхеми TL431 підключається окремими тонкими доріжками безпосередньо до вихідних клем навантаження (Kelvin Sense), щоб падіння напруги на силових силових полігонах не спотворювало вихідну стабілізацію.

## Топологія критичних контурів перетворювача зворотного ходу (Flyback)

Практична реалізація ізоляції тісно переплетена з електромагнітною сумісністю (EMC). Розглянемо правила компонування друкованої плати для класичного імпульсного джерела живлення:

```
[Вхідний фільтр & Міст] ──> [C_bulk] ──> [Первинна обмотка Тр] ──> [MOSFET Стік]
                                │                                      │
                                └─── Точка повернення струму (Зірка) ──┴── [R_shunt]
```

### Правила трасування високовольтної частини:
1. **Мінімізація площі імпульсного контуру:** контур «плюс згладжувального конденсатора `C_bulk` → первинна обмотка трансформатора → стік/витік MOSFET → струмовимірювальний шунт `R_shunt` → мінус `C_bulk`» несе потужні імпульсні струми з частотою 65–130 кГц. Його геометрична площа має бути мінімальною. Що більша площа цієї петлі, то потужніше магнітне поле завад випромінюється у простір;
2. **Вузол стоку (Drain Node):** мідний полігон стоку польового транзистора є антеною синфазних завад через високу крутизну напруги `dv/dt`. Цей полігон роблять рівно такого розміру, який потрібен для тепловідводу, і ні в якому разі не розтягують уздовж ізоляційного бар'єра;
3. **Підключення Y-конденсатора:** виводи безпечного Y1-конденсатора повинні підключатися найкоротшими прямими трасами безпосередньо до мінусового виводу первинного конденсатора `C_bulk` та до загального полігону вторинної землі `GND_SELV` біля випрямного діода/синхронного ключа. Неприпустимо підключати Y-конденсатор через довгі тонкі доріжки — їхня паразитна індуктивність (близько 1 нГн/мм) на високих частотах створює значний імпеданс, що зводить нанівець ефективність придушення EMI.

## Виробничий контроль та тестування ізоляції (Hipot і ROSE-тест)

Готова змонтована друкована плата перед встановленням у корпус проходить обов'язковий комплекс вихідного контролю на виробничій лінії:

1. **Тест діелектричної міцності (Hipot Test):**
   - Усі первинні контакти роз'єму живлення (L, N) закорочуються разом в один тестовий полюс;
   - Усі вторинні вихідні клеми (Vout, GND) закорочуються у другий полюс;
   - Прилад прикладає випробувальну напругу (типово 3000 В AC або 4242 В DC для посиленої ізоляції) з наростанням протягом 2 секунд і витримкою 1 секунду (на 100% серійних виробів);
   - Контролюється граничний струм витоку (не більше 5–10 мА). Будь-який іскровий перекрив або перевищення порогу струму призводить до автоматичного відбраковування плати.
2. **Перевірка іонного забруднення (ROSE Test — *Resistivity of Solvent Extract*):**
   - Плата занурюється у випробувальний розчин ізопропілового спирту та деіонізованої води;
   - Вимірюється зміна питомої електропровідності екстракту;
   - Стандарт IPC-6012 вимагає, щоб залишкове іонне забруднення після відмивання не перевищувало **1.56 мкг/см² в еквіваленті NaCl**. Перевищення цієї норми гарантує швидкий розвиток електрохімічної міграції та проростання треків при експлуатації у вологому середовищі.

## Алгоритмічний калькулятор зазорів Creepage і Clearance

Нижче наведено робочий алгоритмічний модуль для автоматизованого розрахунку необхідних параметрів повітряного зазору та шляху витоку за стандартами IEC 62368-1 та IEC 60664-1. Програма враховує робочу напругу, висоту над рівнем моря, ступінь забруднення (Pollution Degree) та групу матеріалу плати (CTI).

#include <stdio.h>
#include <stdbool.h>

/* Ступінь забруднення згідно з IEC 60664-1 */
typedef enum {
    POLLUTION_DEGREE_1 = 1, /* Герметичні корпуси або лаковані плати */
    POLLUTION_DEGREE_2 = 2, /* Побутова та офісна техніка */
    POLLUTION_DEGREE_3 = 3  /* Промислове обладнання з пилом */
} PollutionDegree;

/* Група матеріалу плати за Comparative Tracking Index */
typedef enum {
    MATERIAL_GROUP_I   = 1, /* CTI >= 600 */
    MATERIAL_GROUP_II  = 2, /* 400 <= CTI < 600 */
    MATERIAL_GROUP_IIIA = 3 /* 175 <= CTI < 400 (стандартний FR-4) */
} MaterialGroup;

/* Рівень ізоляції */
typedef enum {
    INSULATION_FUNCTIONAL,
    INSULATION_BASIC,
    INSULATION_REINFORCED
} InsulationType;

/* Розрахунок висотного коефіцієнта за стандартом IEC 60664-1 (Таблиця A.2) */
double calculate_altitude_factor(double altitude_m) {
    if (altitude_m <= 2000.0) return 1.00;
    if (altitude_m <= 3000.0) return 1.14;
    if (altitude_m <= 4000.0) return 1.29;
    if (altitude_m <= 5000.0) return 1.48;
    return 1.70; /* Екстремальні висоти > 5000 м */
}

/* Розрахунок мінімального повітряного зазору (Clearance) у мм */
double calculate_clearance(double v_rms, InsulationType ins_type, double altitude_m) {
    double base_clr = 0.0;
    
    /* Базові значення для категорії перенапруги II (OVC II) */
    if (v_rms <= 150.0) {
        base_clr = 1.0;
    } else if (v_rms <= 300.0) {
        base_clr = (ins_type == INSULATION_REINFORCED) ? 3.0 : 1.5;
    } else {
        base_clr = (ins_type == INSULATION_REINFORCED) ? 6.0 : 3.0;
    }
    
    if (ins_type == INSULATION_FUNCTIONAL) {
        base_clr = 0.5;
    }
    
    double k_alt = calculate_altitude_factor(altitude_m);
    return base_clr * k_alt;
}

/* Розрахунок мінімального шляху витоку (Creepage) у мм */
double calculate_creepage(double v_rms, InsulationType ins_type,
                          PollutionDegree pd, MaterialGroup mg) {
    double base_cr = 0.0;
    
    if (v_rms <= 250.0) {
        if (pd == POLLUTION_DEGREE_1) {
            base_cr = (ins_type == INSULATION_REINFORCED) ? 1.4 : 0.7;
        } else if (pd == POLLUTION_DEGREE_2) {
            switch (mg) {
                case MATERIAL_GROUP_I:
                    base_cr = (ins_type == INSULATION_REINFORCED) ? 3.6 : 1.8;
                    break;
                case MATERIAL_GROUP_II:
                    base_cr = (ins_type == INSULATION_REINFORCED) ? 4.4 : 2.2;
                    break;
                case MATERIAL_GROUP_IIIA:
                default:
                    base_cr = (ins_type == INSULATION_REINFORCED) ? 5.0 : 2.5;
                    break;
            }
        } else { /* PD 3 */
            base_cr = (ins_type == INSULATION_REINFORCED) ? 8.0 : 4.0;
        }
    } else {
        /* Напруга DC-шини 400 В */
        base_cr = (ins_type == INSULATION_REINFORCED) ? 8.0 : 4.0;
    }
    
    return base_cr;
}

int main(void) {
    double v_rms = 250.0;
    double altitude = 3500.0;
    InsulationType ins = INSULATION_REINFORCED;
    PollutionDegree pd = POLLUTION_DEGREE_2;
    MaterialGroup mg = MATERIAL_GROUP_IIIA; /* FR-4 */
    
    double clr = calculate_clearance(v_rms, ins, altitude);
    double crp = calculate_creepage(v_rms, ins, pd, mg);
    
    printf("=== Розрахунок зазорів безпеки друкованої плати (C) ===\n");
    printf("Робоча напруга мережі:        %.1f В RMS\n", v_rms);
    printf("Висота над рівнем моря:       %.0f м\n", altitude);
    printf("Ступінь забруднення:          PD %d\n", (int)pd);
    printf("Матеріал основи:              FR-4 (Група IIIa)\n");
    printf("Тип ізоляції:                 Посилена (Reinforced)\n");
    printf("------------------------------------------------------\n");
    printf("Мінімальний Clearance:        %.2f мм\n", clr);
    printf("Мінімальний Creepage:         %.2f мм\n", crp);
    
    return 0;
}

#include <iostream>
#include <iomanip>
#include <string_view>
#include <expected>

namespace safety {

enum class PollutionDegree {
    CleanDry = 1,     // PD 1: герметичні модулі або лаковані плати
    NormalIndoor = 2, // PD 2: офісна та побутова електроніка
    Industrial = 3    // PD 3: промислове пилове середовище
};

enum class MaterialGroup {
    GroupI,   // CTI >= 600 (фторопласт, кераміка)
    GroupII,  // 400 <= CTI < 600 (спеціальний текстоліт)
    GroupIIIa // 175 <= CTI < 400 (стандартний FR-4 / CEM-1)
};

enum class InsulationClass {
    Functional,
    Basic,
    Reinforced
};

struct IsolationSpec {
    double voltageRms{250.0};
    double altitudeMeters{0.0};
    InsulationClass insulation{InsulationClass::Reinforced};
    PollutionDegree pollution{PollutionDegree::NormalIndoor};
    MaterialGroup material{MaterialGroup::GroupIIIa};
};

struct IsolationRequirements {
    double clearanceMm{0.0};
    double creepageMm{0.0};
    double altitudeMultiplier{1.0};
};

class IsolationCalculator {
public:
    [[nodiscard]] static constexpr double getAltitudeMultiplier(double altitudeMeters) noexcept {
        if (altitudeMeters <= 2000.0) return 1.00;
        if (altitudeMeters <= 3000.0) return 1.14;
        if (altitudeMeters <= 4000.0) return 1.29;
        if (altitudeMeters <= 5000.0) return 1.48;
        return 1.70;
    }

    [[nodiscard]] static std::expected<IsolationRequirements, std::string_view>
    compute(const IsolationSpec& spec) noexcept {
        if (spec.voltageRms <= 0.0) {
            return std::unexpected("Робоча напруга повинна бути більшою за нуль");
        }

        double baseClr = 0.0;
        if (spec.voltageRms <= 150.0) {
            baseClr = 1.0;
        } else if (spec.voltageRms <= 300.0) {
            baseClr = (spec.insulation == InsulationClass::Reinforced) ? 3.0 : 1.5;
        } else {
            baseClr = (spec.insulation == InsulationClass::Reinforced) ? 6.0 : 3.0;
        }

        if (spec.insulation == InsulationClass::Functional) {
            baseClr = 0.5;
        }

        const double altMult = getAltitudeMultiplier(spec.altitudeMeters);
        const double finalClr = baseClr * altMult;

        double baseCrp = 0.0;
        if (spec.pollution == PollutionDegree::CleanDry) {
            baseCrp = (spec.insulation == InsulationClass::Reinforced) ? 1.4 : 0.7;
        } else if (spec.pollution == PollutionDegree::NormalIndoor) {
            switch (spec.material) {
                case MaterialGroup::GroupI:
                    baseCrp = (spec.insulation == InsulationClass::Reinforced) ? 3.6 : 1.8;
                    break;
                case MaterialGroup::GroupII:
                    baseCrp = (spec.insulation == InsulationClass::Reinforced) ? 4.4 : 2.2;
                    break;
                case MaterialGroup::GroupIIIa:
                default:
                    baseCrp = (spec.insulation == InsulationClass::Reinforced) ? 5.0 : 2.5;
                    break;
            }
        } else { // Industrial PD 3
            baseCrp = (spec.insulation == InsulationClass::Reinforced) ? 8.0 : 4.0;
        }

        return IsolationRequirements{
            .clearanceMm = finalClr,
            .creepageMm = baseCrp,
            .altitudeMultiplier = altMult
        };
    }
};

} // namespace safety

int main() {
    using namespace safety;

    constexpr IsolationSpec spec{
        .voltageRms = 250.0,
        .altitudeMeters = 3500.0,
        .insulation = InsulationClass::Reinforced,
        .pollution = PollutionDegree::NormalIndoor,
        .material = MaterialGroup::GroupIIIa
    };

    const auto result = IsolationCalculator::compute(spec);

    if (!result) {
        std::cerr << "Помилка розрахунку: " << result.error() << '\n';
        return 1;
    }

    std::cout << std::fixed << std::setprecision(2);
    std::cout << "=== Розрахунок зазорів безпеки друкованої плати (C++23) ===\n";
    std::cout << "Робоча напруга мережі:        " << spec.voltageRms << " В RMS\n";
    std::cout << "Висота над рівнем моря:       " << spec.altitudeMeters << " м\n";
    std::cout << "Висотний множник k_d:         " << result->altitudeMultiplier << "x\n";
    std::cout << "------------------------------------------------------\n";
    std::cout << "Повітряний зазор (Clearance): " << result->clearanceMm << " мм\n";
    std::cout << "Шлях витоку (Creepage):       " << result->creepageMm << " мм\n";

    return 0;
}

## Іскрові розрядники на платі (PCB Spark Gaps) та пастки їхнього застосування

Інколи на старих платах можна побачити витравлені з міді трикутні зубці, спрямовані вершинами один до одного із зазором 0.5–1.0 мм (так звані *PCB Spark Gaps*).

```
   Первинна мідь (L/N) ───►  ◄─── Захисна земля (PE)
                         ▲    ▲
                         └──┬─┘
                    Зазор 0.8 мм
```

### Фізика роботи та чому це заборонено в сучасних стандартах:
1. **Принцип дії:** загострені кінці міді створюють сильну локальну концентрацію електричного поля (`k_conc > 5 ... 8`). Під час потужного високовольтного імпульсу (наприклад, непрямого удару блискавки амплітудою понад 4–6 кВ) у вузькому зазорі виникає коронний розряд, який переростає в іскрову дугу, скидаючи енергію сплеску на захисну землю PE до того, як вона дійде до трансформатора чи мікросхем;
2. **Неконтрольована напруга спрацьовування:** через нерівномірність хімічного травлення міді, окиснення відкритої поверхні, зміну вологості повітря та атмосферного тиску напруга запалювання дуги на друкованих зубцях коливається в діапазоні ±40–50%;
3. **Закоксовування та руйнування діелектрика:** під час першого ж спрацьовування електрична дуга випаровує частинки міді й обвуглює склотекстоліт під зубцями. На платі утворюється стійкий провідний графітовий місток, який перетворює іскровий розрядник на постійне коротке замикання;
4. **Вимога стандартів:** стандарти IEC 62368-1 та IEC 60664-1 суворо **забороняють** використання друкованих іскрових зазорів на платі для забезпечення безпеки. Усі захисні елементи повинні бути сертифікованими дискретними компонентами: герметичними газонаповненими розрядниками (GDT — *Gas Discharge Tube*) або металооксидними варисторами (MOV), поміщеними у термоусадкові негорючі трубки.

## Інженерний контрольний список перед запуском плати у виробництво

Перед фінальною генерацією виробничих Gerber-файлів перевірте проект за таким списком:

1. **Повна відсутність міді в зоні бар'єра:** виконайте пошаровий перегляд герберів (Gerber Viewer), вимкнувши всі шари крім внутрішніх (Inner Planes). Переконайтеся, що жоден внутрішній полігон живлення чи землі не заходить у зону відчуження під трансформатором, оптопарою чи Y-конденсатором.
2. **Параметри фрезерованих пазів:** перевірте, що шар `Edge.Cuts` містить замкнений контур пропилу шириною не менше 1.2 мм з радіусними скругленнями на торцях.
3. **Металеві елементи кріплення:** перевірте відстань від високовольтних доріжок до отворів під гвинти кріплення. Головка металевого гвинта чи шайба діаметром 6 мм суттєво зменшує фактичний повітряний зазор до корпусу.
4. **Скруглення високовольтних полігонів:** усуньте всі гострі кути 90° на первинних полігонах `DC_BUS+` та `DRAIN`, замінивши їх радіусами скруглення не менше 1.0 мм для зниження локальної концентрації електричного поля.
5. **Паяльна маска:** пам'ятайте, що рідка фотополімерна паяльна маска (LPI Solder Mask) за стандартами IEC не є сертифікованим твердим діелектриком — усі зазори Creepage повинні витримуватися по поверхні самої маски або чистого текстоліту.
6. **Очищення від залишків флюсу:** після монтажу високовольтної плати обов'язкове ультразвукове відмивання у спирто-бензиновій або спеціалізованій розчинниковій суміші. Залишки активованого флюсу містять іонні галогени, які у вологому середовищі створюють провідні доріжки й катастрофічно знижують CTI плати.
