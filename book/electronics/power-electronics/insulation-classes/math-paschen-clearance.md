# 🧮 Фізика пробою газу: закон Пашена та розрахунок зазорів

> Математичне обґрунтування електричної міцності повітряного проміжку й діелектричних поверхонь. Тут наведено строге виведення кривої Пашена з критерію самостійного розряду Таунсенда, аналітичний розрахунок падіння густини атмосфери з висотою за барометричною формулою, математичну модель коефіцієнтів корекції повітряного зазору за стандартом IEC 60664-1, формулу Піка для крайової концентрації поля, фізико-хімічний розрахунок капілярного меніска в ізоляційних пропилах та енергетичний баланс утворення провідного вуглецевого треку на поверхні склотекстоліту.

Повітря між двома провідниками на друкованій платі слугує діелектриком лише доти, доки електричне поле не досягне критичного порогу іонізації. Щоб визначити мінімальний безпечний зазор крізь повітря (англ. *Clearance*) та шлях витоку (англ. *Creepage*), інженер має спиратися не на емпіричні таблиці, а на фундаментальні рівняння фізики розрядів у газах, електродинаміки та теорії електростатичного поля.

## Критерій розряду Таунсенда та виведення закону Пашена

Розглянемо плоский повітряний проміжок між двома електродами на відстані `d` під різницею потенціалів `U`. Однорідне електричне поле в такому зазорі описується виразом:

```
E = U / d
```

Якщо під дією природного радіаційного фону або космічного випромінювання біля катода з'являється один випадковий вільний електрон, поле прискорює його в бік анода. На довжині вільного пробігу електрон набирає кінетичну енергію:

```
W_k = e · E · lambda
```

де:
- `e ≈ 1.602 · 10⁻¹⁹ Кл` — елементарний заряд електрона;
- `lambda` — середня довжина вільного пробігу електрона в газі.

Якщо ця енергія перевищує потенціал іонізації молекул азоту чи кисню (`W_ion ≈ 14.5 ... 15.6 еВ`), при зіткненні вибивається новий вторинний електрон. Обидва електрони знову прискорюються полем і повторюють процес, породжуючи лавину носіїв заряду.

Кількість актів ударної іонізації, яку породжує один електрон на одиниці шляху (1 см), описується першим коефіцієнтом іонізації Таунсенда `alpha`. За кінетичною моделлю Таунсенда:

```
alpha = A · p · exp(-B · p / E)
```

де:
- `p` — абсолютний тиск газу (в мм рт. ст. або Торр, або Па);
- `E` — напруженість електричного поля (В/см або В/м);
- `A` і `B` — константи газу, що залежать від ефективного перерізу іонізації та потенціалу іонізації (для сухого атмосферного повітря `A ≈ 15 1/(см·Торр)`, `B ≈ 365 В/(см·Торр)` у діапазоні `E/p` від 100 до 600 В/(см·Торр)).

Під час руху електронної лавини до анода в зазорі залишається хмара важких позитивних іонів. Під дією поля ці іони повільно дрейфують назад до катода і бомбардують його поверхню. При ударі об катод іон може вибити новий вторинний електрон. Ефективність цього процесу описує другий коефіцієнт Таунсенда `gamma` (коефіцієнт вторинної емісії, для типових металевих поверхонь міді та олова `gamma ≈ 10⁻⁴ ... 10⁻²`).

Загальна кількість електронів, що досягають анода від одного початкового електрона з урахуванням вторинних процесів на катоді, становить:

```
N_e = exp(alpha · d) / (1 - gamma · (exp(alpha · d) - 1))
```

Самостійний іскровий пробій (коли струм зростає лавиноподібно навіть після зникнення зовнішнього джерела іонізації) виникає за умови, коли знаменник прямує до нуля. Це дає фундаментальний **критерій пробою Таунсенда**:

```
gamma · (exp(alpha · d) - 1) = 1
```

Перетворимо цей критерій для отримання критичного значення напруги пробою `U_b` (напруги Пашена):

```
exp(alpha · d) = 1 + 1 / gamma
alpha · d = ln(1 + 1 / gamma)
```

Підставимо вираз для `alpha` та врахуємо зв'язок напруженості поля з напругою `E = U_b / d`:

```
A · p · d · exp(-B · p · d / U_b) = ln(1 + 1 / gamma)
exp(-B · p · d / U_b) = ln(1 + 1 / gamma) / (A · p · d)
-B · p · d / U_b = ln(ln(1 + 1 / gamma) / (A · p · d))
```

Звідси отримуємо аналітичну формулу **закону Пашена**:

```
U_b = (B · p · d) / (ln(A · p · d) - ln(ln(1 + 1 / gamma)))
```

Ця формула доводить найважливіший інваріант високовольтної ізоляції: **напруга електричного пробою в однорідному полі залежить виключно від добутку тиску газу на відстань між провідниками `p · d`**, а не від тиску чи відстані окремо.

```
       U_b (В)
          │
      800 ┼           .
          │          /
      600 ┼         /
          │        /
      400 ┼       /   Крива Пашена для повітря
      327 ┼───.  /    U_min ≈ 327 В при (p·d)_min ≈ 0.56 Торр·см
      200 ┼    ╲╱
          │
        0 ┴───────┬────────────┬─────────────┬──────────> p·d (Торр·см)
                0.1           0.56          5.0
```

### Фізичний зміст мінімуму Пашена

Крива Пашена має глобальний мінімум. Знайдемо екстремум функції, прирівнявши похідну `d(U_b)/d(p·d)` до нуля:

```
(p · d)_min = e · ln(1 + 1 / gamma) / A
```

де `e ≈ 2.71828` — основа натурального логарифма.

Для стандартного повітря за нормальної вологості:
- `(p · d)_min ≈ 0.56 Торр·см = 0.75 Па·м`;
- `U_b_min ≈ 327 В`.

Це означає, що **у звичайному повітрі неможливо запалити іскровий розряд за напруги нижче 327 В за жодного зазору і за жодного тиску**. Якщо робоча пікова напруга в колі нижча за 327 В, повітряний пробій за законом Пашена в однорідному полі теоретично неможливий (хоча реальні мікрозазори обмежуються польовою автоемісією електронів при `E > 10⁷ В/м`).

Фізика двох гілок кривої визначається довжиною вільного пробігу `lambda`:
1. **Права гілка (`p · d > (p · d)_min`):** Тиск або відстань великі. Електрон здійснює сотні зіткнень з молекулами на шляху до анода. На кожному кроці він розсіює імпульс, тому для набору енергії іонізації між зіткненнями потрібна вища напруга `U_b`. У цьому робочому діапазоні працює силова апаратура за нормального атмосферного тиску (`p = 760 Торр`) і зазорів `d > 0.5 мм` (`p · d > 38 Торр·см ≫ 0.56 Торр·см`). Залежність напруги від зазору тут близька до лінійної: діелектрична міцність повітря становить приблизно `E_br ≈ 3 кВ/мм` (для плоских поверхонь).
2. **Ліва гілка (`p · d < (p · d)_min`):** Вакуум або субмікронні проміжки. Молекул газу в проміжку настільки мало, що електрон долітає до анода без жодного зіткнення. Імовірність ударної іонізації прямує до нуля, тому для виникнення розряду потрібна колосальна напруга.

## Зміна тиску з висотою та висотний множник зазору

Коли електронний прилад експлуатується на висоті (гірська місцевість, базові станції зв'язку, авіаційні перетворювачі), барометричний тиск повітря падає, що зміщує робочу точку вліво по кривій Пашена та знижує напругу пробою.

Розглянемо елементарний стовп повітря висотою `dh` та площею `S = 1`. Рівняння рівноваги стовпа газу в полі тяжіння Землі:

```
dp = -rho · g · dh
```

де:
- `rho` — густина повітря;
- `g ≈ 9.80665 м/с²` — прискорення вільного падіння.

Запишемо рівняння стану ідеального газу Менделєєва — Клапейрона:

```
p = (rho / M) · R · T  =>  rho = (p · M) / (R · T)
```

де:
- `M ≈ 0.0289644 кг/моль` — молярна маса сухого повітря;
- `R ≈ 8.31446 Дж/(моль·К)` — універсальна газова стала;
- `T` — термодинамічна температура в Кельвінах.

Підставимо густину `rho` в диференціальне рівняння гідростатики:

```
dp = -((p · M · g) / (R · T)) · dh
dp / p = -((M · g) / (R · T)) · dh
```

Інтегруючи від рівня моря `h = 0` (тиск `p_0 = 101.325 кПа = 760 Торр`) до висоти `h`:

```
ln(p / p_0) = -((M · g) / (R · T)) · h
p(h) = p_0 · exp(-((M · g) / (R · T)) · h)
```

При стандартній міжнародній температурі атмосфери `T_0 = 288.15 К` (+15 °C) розрахуємо характеристичну висоту однорідної атмосфери:

```
H_0 = (R · T) / (M · g)
    = (8.31446 · 288.15) / (0.0289644 · 9.80665)
    ≈ 8435 м
```

Отримуємо барометричну залежність тиску повітря від висоти `h` (у метрах):

```
p(h) = 101.325 · exp(-h / 8435)  [кПа]
```

Розрахуємо точний атмосферний тиск для стандартних інженерних висот:

```
На рівні моря (h = 0 м):
p(0) = 101.325 · exp(0) = 101.325 кПа (760.0 Торр)

На висоті h = 2000 м:
p(2000) = 101.325 · exp(-2000 / 8435)
        = 101.325 · exp(-0.2371)
        = 101.325 · 0.7889
        ≈ 79.94 кПа (599.6 Торр)   [-21.1% тиску]

На висоті h = 3000 м:
p(3000) = 101.325 · exp(-3000 / 8435)
        = 101.325 · exp(-0.3557)
        = 101.325 · 0.7007
        ≈ 71.00 кПа (532.5 Торр)   [-29.9% тиску]

На висоті h = 4000 м:
p(4000) = 101.325 · exp(-4000 / 8435)
        = 101.325 · exp(-0.4742)
        = 101.325 · 0.6224
        ≈ 63.06 кПа (473.0 Торр)   [-37.8% тиску]

На висоті h = 5000 м:
p(5000) = 101.325 · exp(-5000 / 8435)
        = 101.325 · exp(-0.5928)
        = 101.325 · 0.5528
        ≈ 56.01 кПа (420.1 Торр)   [-44.7% тиску]
```

### Виведення висотного коригувального множника k_d

Оскільки на правій гілці закону Пашена електрична міцність залежить від добутку `p · d`, для збереження гарантованої напруги пробою при зменшенні тиску від базового рівня 2000 м (`p_ref ≈ 80 кПа`) до тиску `p(h)` необхідно пропорційно збільшити фізичний повітряний зазор `d`:

```
p_ref · d_ref = p(h) · d(h)
d(h) = d_ref · (p_ref / p(h))
```

Стандарт IEC 60664-1 (Таблиця A.2) стандартизує поправочні коефіцієнти `k_d` для проектування повітряних зазорів на висотах понад 2000 м:

```
d_actual = d_baseline · k_d
```

| Висота над рівнем моря `h` (м) | Барометричний тиск `p` (кПа) | Нормативний коефіцієнт `k_d` (IEC 60664-1) |
| :--- | :--- | :--- |
| **до 2000 м** | 80.0 | **1.00** |
| **2001 – 3000 м** | 70.0 | **1.14** (на практиці беруть 1.15) |
| **3001 – 4000 м** | 62.0 | **1.29** |
| **4001 – 5000 м** | 54.0 | **1.48** |
| **5001 – 6000 м** | 47.0 | **1.70** |
| **6001 – 7000 м** | 41.0 | **1.95** |

**Числовий приклад розрахунку зазору для висоти 5000 м.**
Нехай імпульсний перетворювач розраховується на роботу від мережі 250 В RMS (пікова напруга 354 В, категорія перенапруги II, випробувальний імпульс `U_imp = 2500 В`).
За стандартом базовий посилений повітряний зазор для висоти до 2000 м становить `d_baseline = 3.0 мм`.
Для сертифікації виробу для роботи в гірських умовах до 5000 м (наприклад, для сонячних інверторів або обладнання зв'язку):

```
k_d(5000 м) = 1.48                      [коефіцієнт з таблиці IEC 60664-1]
d_req(5000 м) = d_baseline · k_d        [масштабування базового зазору]
= 3.0 мм · 1.48                         [підстановка значень]
= 4.44 мм                               [підсумковий мінімальний зазор]
```

Якщо зазор залишити рівним 3.0 мм, то на висоті 5000 м при кидку перенапруги 2.5 кВ проміжок проб'ється через збільшену довжину вільного пробігу електронів у розрідженому повітрі.

## Крайовий ефект і концентрація поля біля кутів провідників

У друкованій платі провідники мають прямокутний переріз із товщиною міді `t` (зазвичай 35 мкм для фольги 1 oz або 70 мкм для 2 oz) та мікрорадіусом закруглення кромки `r` (близько 3–10 мкм після хімічного травлення).

На гострому ребрі провідника густина поверхневого заряду різко зростає. Розрахуємо коефіцієнт концентрації поля за методом конформних відображень для профілю Роговського.

Середня напруженість поля в зазорі `d`:

```
E_0 = U / d
```

Максимальна напруженість поля на кромці провідника з радіусом `r` та товщиною `t`:

```
E_max = E_0 · (1 + sqrt(t / (2 · r)))
```

**Числовий розрахунок концентрації поля:**
Нехай `U = 400 В`, `d = 1.0 мм = 1000 мкм`, товщина міді `t = 35 мкм`, радіус кромки `r = 5 мкм`.

```
E_0 = 400 В / 0.001 м = 400 000 В/м = 4.0 кВ/см   [середнє поле в зазорі]
k_conc = 1 + sqrt(35 / (2 · 5))                   [підстановка геометрії кромки]
= 1 + sqrt(3.5)                                   [обчислення підкореневого виразу]
= 1 + 1.8708                                      [добування квадратного кореня]
≈ 2.87                                            [коефіцієнт концентрації]
E_max = E_0 · k_conc                              [пікова напруженість на кромці]
= 4.0 кВ/см · 2.87                                [підстановка значень]
= 11.48 кВ/см                                     [напруженість на вістрі провідника]
```

Локальна напруженість поля виявляється майже втричі вищою за середню по зазору. Саме тому стандарти вимагають скруглювати кути високовольтних полігонів та доріжок радіусом не менше 0.5–1.0 мм, що зменшує `k_conc` практично до 1.05–1.10 і запобігає коронним мікророзрядам.

## Вплив частоти комутації: формула Піка та діелектричний нагрів

У сучасних перетворювачах на GaN і SiC ключах напруга на первинній обмотці та ключах перемикається з частотою від 100 кГц до 2 МГц з крутизною фронтів `dv/dt > 50 ... 100 кВ/мкс`.

Висока частота якісно змінює механізм пробою повітряного зазору. У постійному або повільному полі (50 Гц) позитивні іони встигають за півперіоду дійти до катода й нейтралізуватися. На високих частотах (f > 100 кГц) період коливань стає коротшим за час дрейфу іонів:

```
t_half = 1 / (2 · f) < d / (mu_ion · E)
```

де `mu_ion ≈ 1.5 · 10⁻⁴ м²/(В·с)` — рухливість іонів у повітрі.

Важкі іони не встигають покинути зазор і накопичуються в міжетлектродному просторі, утворюючи просторовий об'ємний заряд. Цей заряд спотворює поле, збільшуючи локальну напруженість, що знижує напругу запалювання коронного та іскрового розряду на 20–40%.

Критична напруженість виникнення коронного розряду у повітрі на високих частотах описується емпіричною формулою Піка з частотною корекцією:

```
E_corona = 31.0 · delta_air · (1 + 0.308 / sqrt(r_eff · delta_air)) · k_freq  [кВ/см]
```

де:
- `delta_air = (p / p_0) · (T_0 / T)` — відносна густина повітря;
- `r_eff` — ефективний радіус кривизни провідника;
- `k_freq ≈ 1 - 0.08 · log10(f / 1 кГц)` — частотний множник зниження міцності.

Крім того, діелектрик плати (FR-4) у високочастотному електричному полі нагрівається внаслідок діелектричних втрат. Питома об'ємна потужність діелектричного нагріву:

```
p_diel = 2 · pi · f · epsilon_0 · epsilon_r · tan(delta) · E²  [Вт/м³]
```

де:
- `epsilon_r ≈ 4.4` — відносна діелектрична проникність FR-4;
- `tan(delta) ≈ 0.02` — тангенс кута діелектричних втрат склотекстоліту.

За `f = 500 кГц` та `E = 2 кВ/мм = 2 · 10⁶ В/м`:

```
p_diel = 2 · 3.14159 · (5 · 10⁵) · (8.854 · 10⁻¹² · 4.4) · 0.02 · (2 · 10⁶)²
       = 3.14159 · 10⁶ · (38.96 · 10⁻¹²) · 0.02 · (4 · 10¹²)
       ≈ 9790 кВт/м³ = 9.79 Вт/см³
```

Цей локальний розігрів прискорює деструкцію епоксидної смоли та вимагає збільшення зазорів при високочастотній комутації.

## Капілярна гідродинаміка та мінімальна ширина пропилу

Чому стандарт IEC 60664-1 суворо вимагає, щоб ширина ізоляційного пропилу на друкованій платі становила не менше `w_slot ≥ 1.0 мм` (для ступеня забруднення 2)?

Фізична причина криється в капілярному ефекті та поверхневому натягу сконденсованої вологи. Якщо ширина пазу менша за критичний капілярний діаметр, крапля води втягується в пропил капілярними силами й утворює суцільний рідкий місток між краями, що повністю анулює ізоляційні властивості пазу.

Умова затягування рідини в щілину описується законом Лапласа для капілярного тиску:

```
Delta P = (2 · sigma_water · cos(theta)) / w_slot
```

де:
- `sigma_water ≈ 0.0728 Н/м` — коефіцієнт поверхневого натягу води при 20 °C;
- `theta` — крайовий кут змочування склотекстоліту водою (для FR-4 з паяльною маскою `theta ≈ 60° ... 75°`, `cos(theta) > 0`, тобто матеріал змочується).

Капілярне підняття рідини в щілині проти сили тяжіння:

```
h_cap = (2 · sigma_water · cos(theta)) / (rho_water · g · w_slot)
```

За `w_slot = 0.5 мм = 5 · 10⁻⁴ м` та `theta = 60°`:

```
h_cap = (2 · 0.0728 · 0.5) / (1000 · 9.81 · 5 · 10⁻⁴)
      = 0.0728 / 4.905
      ≈ 0.0148 м = 14.8 мм
```

У вузькому пазі завширшки 0.5 мм вода легко піднімається на висоту майже 15 мм, надійно закорочуючи плату товщиною 1.6 мм!

Коли ж ширина пазу збільшується до `w_slot ≥ 1.0 ... 1.5 мм`, капілярний тиск різко падає, а власна вага краплі перевищує капілярні сили зчеплення. Крапля розривається під дією гравітації й скочується з країв, залишаючи повітряний бар'єр сухим.

## Енергетична модель утворення треку (Creepage Breakdown)

Шлях витоку вздовж поверхні діелектрика руйнується за тепловим механізмом утворення графітових містків.

Нехай на поверхні склотекстоліту FR-4 осіла плівка вологи та солей товщиною `delta_f` з питомою провідністю `sigma_s`. Поверхневий опір ділянки довжиною `L` і шириною `w`:

```
R_s = (1 / (sigma_s · delta_f)) · (L / w)
```

Під дією прикладеної напруги `U` крізь електроліт тече поверхневий струм витоку:

```
I_leak = U / R_s
```

Цей струм виділяє джоулеве тепло з потужністю:

```
P = I_leak² · R_s = U² / R_s
```

У місці з найтоншою плівкою рідини (найвищим локальним опором) температура локально сягає температури кипіння води `T_boil = 100 °C`. Волога миттєво випаровується, утворюючи мікроскопічну суху зону (англ. *dry band*) шириною `x_dry ≈ 50 ... 200 мкм`.

Оскільки опір сухої зони набагато вищий за опір решти зволоженої поверхні, практично вся напруга `U` падає на вузькому сухому проміжку `x_dry`. Напруженість електричного поля в сухій зоні досягає:

```
E_dry = U / x_dry
```

Якщо `U = 300 В`, а `x_dry = 100 мкм = 0.1 мм`:

```
E_dry = 300 В / 0.0001 м = 3 000 000 В/м = 30 кВ/см
```

Ця напруженість перевищує електричну міцність вологого повітря (близько 15–20 кВ/см). У сухій зоні запалюються мікродуги (іскріння — сцинтиляції). Температура плазми в мікродузі перевищує 1000–1200 °C.

Епоксидна смола склотекстоліту під дією високої температури дуги зазнає термічної деструкції (піролізу). Вуглеводневі ланцюги полімеру розпадаються з утворенням вільного електропровідного вуглецю (графіту):

```
(C_n H_m O_k)_resin  ─[ ΔT > 400 °C ]─>  C_graphite (провідний вуглець) + леткі гази (CO, CO₂, H₂O)
```

Питомий опір висадженого графітового сліду становить лише `10⁻³ ... 10⁻⁵ Ом·м` (порівняно з `10¹² Ом·м` вихідного чистого FR-4). Утворюється провідний мікродендрит.

Критична умова самопідтримуваного зростання треку: швидкість виділення енергії в дузі повинна перевищувати відведення тепла в товщу склотекстоліту:

```
q_arc = I_arc · U_arc > lambda_th · (T_pyrolysis - T_ambient) / d_th
```

Коли графітовий місток проростає на всю відстань між провідниками, відбувається повне коротке замикання з руйнуванням плати.

Саме тому стандартні нормативи вимагають збільшення Creepage у 1.5–2 рази порівняно з Clearance для матеріалів з низьким індексом трекінгостійкості (група IIIa, CTI 175–400 В), а наявність наскрізного ізоляційного пропилу на платі шириною `≥ 1.0 мм` фізично перериває плівку вологи й запобігає утворенню неперервного вуглецевого треку.
