# 🧮 Розрахунок температурного дрейфу й підстроювання частоти

Розрахунок точності годинника реального часу базується на математичному моделюванні фізичних процесів: п'єзоакустичної зміни резонансної частоти камертонного кристала під дією температури, зміщення точки паралельного резонансу навантажувальною ємністю в генераторі Пірса, квантування фазового джитера при цифровому калібруванні, кінетики механічного старіння кристала та енергетичного розряду автономних джерел живлення.

---

### 1. Математична модель параболічного температурного дрейфу

Кварцові резонатори згинальних коливань (камертонні кристали зрізу XY або NT, що працюють на номінальній частоті `f₀ = 32768 Гц`) описуються квадратичною залежністю відносної зміни частоти від температури навколишнього середовища:

```
Δf / f₀ = −k · (T − T₀)²
```

де:
- `Δf = f(T) − f₀` — абсолютне відхилення частоти від номінальної (Гц);
- `f₀ = 32768 Гц` — номінальна частота генератора;
- `k` — температурний коефіцієнт кривизни параболи (для камертонних кварців лежить у діапазоні `0.030 ... 0.042 ppm/°C²`, стандартне паспортне значення `k = 0.035 ppm/°C²`);
- `T` — поточна температура кристала (°C);
- `T₀` — температура вершини параболи (точка нульового температурного коефіцієнта першого порядку, turnover temperature), для більшості годинникових кристалів `T₀ = 25 ± 5 °C`.

Знак «мінус» перед коефіцієнтом кривизни означає, що вершина параболи спрямована вгору: при кімнатній температурі (`T = T₀ = 25 °C`) температурний коефіцієнт частоти дорівнює нулю, а будь-яке відхилення температури — як нагрівання, так і охолодження — спричиняє зменшення частоти (уповільнення годинника).

#### Фізичне обґрунтування ряду Тейлора для зрізу XY
Повний розклад відносної зміни частоти в ряд Тейлора навколо точки `T₀` має вигляд:

```
Δf / f₀ = a₁ · (T − T₀) + a₂ · (T − T₀)² + a₃ · (T − T₀)³ + a₄ · (T − T₀)⁴ + ...
```

Для класичного високочастотного AT-зрізу (товщинний зсув) коефіцієнт другого порядку `a₂ ≈ 0`, а головний внесок робить кубічний член `a₃ · (T − T₀)³`, що утворює S-подібну криву з двома точками перегину. Натомість для згинального камертона (зріз XY або NT):
1. Лінійний коефіцієнт `a₁` дорівнює нулю безпосередньо у вершині параболи `T₀` (`d(Δf/f₀)/dT = 0`);
2. Коефіцієнт другого порядку `a₂ = −k = −0.035 · 10⁻⁶ °C⁻²` визначається температурними змінами коефіцієнтів пружної піддатливості кварцу `s₁₁` та `s₃₃`;
3. Коефіцієнти вищих порядків `a₃` та `a₄` надзвичайно малі (`|a₃| < 10⁻¹⁰ °C⁻³`), тому в усьому промисловому діапазоні від −40 °C до +85 °C квадратична модель описує поведінку кристала з точністю понад 99.5 %.

### 2. Зв'язок відхилення частоти в ppm із накопиченою похибкою часу

Відносна похибка частоти вимірюється в мільйонних частках (`ppm` — parts per million, `1 ppm = 10⁻⁶ = 0.0001 %`).

Якщо генератор має постійне відносне відхилення частоти `δ = Δf / f₀`, то за проміжок часу `t` накопичена похибка відліку часу `Δt` визначається інтегралом:

```
Δt = ∫ δ(τ) dτ
```

При сталій величині `δ`:

```
Δt = δ · t
```

Виведемо коефіцієнти перерахунку похибки з `ppm` у звичні одиниці часу:

**1. Добове відхилення часу (за 24 години = 86 400 секунд):**

```
Δt_day = δ · 86400 с
Δt_day [с/добу] = ppm_val · 10⁻⁶ · 86400 с = ppm_val · 0.0864 с/добу
```

Тобто відхилення на `1 ppm` дає похибку `0.0864 секунди на добу` (або `1 секунду за 11.57 діб`).

**2. Місячне відхилення часу (за 30 діб = 2 592 000 секунд):**

```
Δt_month = δ · 2592000 с
Δt_month [с/міс] = ppm_val · 10⁻⁶ · 2592000 с = ppm_val · 2.592 с/місяць
```

Відхилення на `20 ppm` дає місячну похибку:

```
Δt_month = 20 · 2.592 = 51.84 с/місяць ≈ 52 секунди на місяць
```

**3. Річне відхилення часу (за 365 діб = 31 536 000 секунд):**

```
Δt_year = δ · 31536000 с
Δt_year [хв/рік] = (ppm_val · 10⁻⁶ · 31536000) / 60 ≈ ppm_val · 0.5256 хвилини на рік
```

Відхилення на `20 ppm` дає річне відставання:

```
Δt_year = 20 · 0.5256 = 10.512 хвилини на рік
```

### 3. Розрахунок комбінованого температурного та початкового дрейфу

Загальна похибка некомпенсованого RTC складається з трьох незалежних доданків:
1. Початковий технологічний допуск виготовлення резонатора за кімнатної температури `δ_tol` (типово `±10 ... ±20 ppm`);
2. Похибка узгодження навантажувальної ємності `δ_cap` (типово `±2 ... ±5 ppm`);
3. Температурне відхилення `δ_temp(T) = −k · (T − T₀)²`.

Сумарне відносне відхилення:

```
δ_total(T) = δ_tol + δ_cap − k · (T − T₀)²
```

**Числовий розрахунок для зимових вуличних умов (T = −20 °C):**

Вихідні дані:
- Початковий допуск кристала: `δ_tol = −10 ppm` (відставання при 25 °C);
- Похибка узгодження ємності: `δ_cap = −3 ppm`;
- Коефіцієнт параболи: `k = 0.035 ppm/°C²`;
- Температура: `T = −20 °C`;
- Точка вершини: `T₀ = 25 °C`.

Обчислення:

```
ΔT = T − T₀ = −20 − 25 = −45 °C                                  [відхилення температури від вершини T₀]
δ_temp = −0.035 · (−45)² = −0.035 · 2025 = −70.875 ppm            [параболічний дрейф за формулою -k·ΔT²]

δ_total = −10 + (−3) + (−70.875)                                  [сума: допуск + ємність + температура]
        = −83.875 ppm                                             [результуюче відносне відхилення частоти]

Добова похибка:
Δt_day = −83.875 · 0.0864 = −7.247 с/добу                         [перерахунок ppm у секунди за 86400 с]

Місячна похибка:
Δt_month = −83.875 · 2.592 = −217.4 с/місяць                      [перерахунок ppm у секунди за 30 діб]
         ≈ −3 хвилини 37 секунд на місяць                         [переведення секунд у хвилини]
```

### 4. Чутливість підстроювання частоти навантажувальною ємністю (Pulling Sensitivity)

Еквівалентна схема кварцового резонатора (модель Баттерворта — Ван Дайка, BVD) містить динамічну послідовну гілку (динамічна індуктивність `L₁`, динамічна ємність `C₁`, опір втрат `R₁`) та статичну паралельну ємність електродів і корпусу `C₀`.

Для годинникового камертона 32.768 кГц динамічні параметри мають екстремальні значення порівняно з мегагерцовими кварцами:
- Динамічна індуктивність `L₁` є колосальною: від 4 000 до 10 000 Генрі (через надзвичайно велику еквівалентну масу механічного камертона);
- Динамічна ємність `C₁` мізерна: `2.0 ... 3.5 фФ` (`(2...3.5) · 10⁻¹⁵ Ф`);
- Статична ємність електродів `C₀`: `0.9 ... 1.6 пФ`;
- Добротність: `Q = 2 · π · f₀ · L₁ / R₁ ≈ 50 000 ... 100 000`.

Коли резонатор підключається в схему генератора Пірса з ємністю навантаження `C_L`, результуюча частота паралельного резонансу генерації `f_L` зміщується вище послідовного резонансу `f_s = 1 / (2 · π · √(L₁ · C₁))` згідно з формулою:

```
f_L = f_s · √(1 + C₁ / (C₀ + C_L))
```

Оскільки динамічна ємність кварцу на три порядки менша за навантажувальну (`C₁ << C₀ + C_L`), вираз спрощується через розклад у ряд Тейлора `√(1 + x) ≈ 1 + x / 2`:

```
f_L ≈ f_s · (1 + C₁ / (2 · (C₀ + C_L)))
```

Відносна зміна частоти `Δf_L / f_L` при зміні навантажувальної ємності від номінального значення `C_L1` до нового значення `C_L2`:

```
Δf / f = (C₁ / 2) · [ 1 / (C₀ + C_L2) − 1 / (C₀ + C_L1) ]
```

Диференціальна чутливість затягування частоти (Pulling Sensitivity `S`):

```
S = d(Δf / f) / dC_L = −C₁ / (2 · (C₀ + C_L)²)
```

**Приклад розрахунку аналогового підстроювання частоти:**

Параметри кристала 32.768 кГц:
- `C₁ = 2.5 фФ = 0.0025 пФ`;
- `C₀ = 1.2 пФ`;
- Номінальна ємність: `C_L = 7.0 пФ`.

Чутливість у точці `C_L = 7.0 пФ`:

```
S = −0.0025 / (2 · (1.2 + 7.0)²)       [підстановка параметрів C₁, C₀, C_L]
  = −0.0025 / (2 · (8.2)²)             [сума статичної та навантажувальної ємностей]
  = −0.0025 / (2 · 67.24)              [піднесення суми ємностей до квадрата]
  = −0.0025 / 134.48                   [множення знаменника на 2]
  ≈ −1.86 · 10⁻⁵ пФ⁻¹                  [ділення чисельника на знаменник]
  = −18.6 ppm/пФ                       [переведення у відносні одиниці ppm на пФ]
```

Звідси видно: зміна навантажувальної ємності всього на `0.1 пФ` зміщує частоту генератора на `1.86 ppm` (що еквівалентно похибці `4.8 с/місяць`).

Цей механізм використовується в термокомпенсованих RTC із матрицею цифрових конденсаторів (Switched Capacitor Array): контролер вимірює температуру `T`, розраховує необхідний зсув `Δf_comp = +k · (T − T₀)²` і підключає відповідну комбінацію бінарних ємностей, змінюючи сумарну `C_L` так, щоб скомпенсувати температурне падіння.

### 5. Розрахунок запасу за від'ємним опором (Negative Resistance Margin)

Для надійного збудження автоколивань у генераторі Пірса активний чотириполюсник (КМОН-інвертор з елементами зворотного зв'язку) повинен вносити в коливальний контур еквівалентний від'ємний динамічний опір `R_neg`.

На частоті коливань `ω₀ = 2 · π · f₀` від'ємний опір інвертора з крутістю `g_m` та навантажувальними конденсаторами `C₁`, `C₂` описується формулою:

```
R_neg = −g_m / (ω₀² · C₁ · C₂)
```

Умова стійкого самозбудження за критерієм Баркгаузена вимагає, щоб абсолютна величина від'ємного опору перевищувала еквівалентний послідовний опір контуру кварцу з урахуванням ємнісного дільника `(1 + C₀ / C_L)²`:

```
|R_neg| > ESR · (1 + C₀ / C_L)²
```

Коефіцієнт надійності збудження (Safety Factor `SF`):

```
SF = |R_neg| / ESR
```

**Числовий приклад розрахунку запасу збудження:**
Вихідні дані підсилювача RTC:
- Крутість інвертора: `g_m = 4.0 мкА/В = 4.0 · 10⁻⁶ А/В`;
- Номінальна частота: `f₀ = 32768 Гц` (`ω₀ = 2 · π · 32768 ≈ 205887 рад/с`);
- Конденсатори: `C₁ = C₂ = 18 пФ = 18 · 10⁻¹² Ф`;
- Еквівалентний опір кварцу: `ESR = 50 кОм = 50 000 Ом`.

Розрахунок:

```
ω₀² = (205887)² ≈ 4.2389 · 10¹⁰ рад²/с²                           [квадрат кутової частоти]
C₁ · C₂ = (18 · 10⁻¹²)² = 3.24 · 10⁻²² Ф²                        [добуток ємностей навантаження]
Знаменник = 4.2389 · 10¹⁰ · 3.24 · 10⁻²² ≈ 1.3734 · 10⁻¹¹        [розрахунок знаменника формули R_neg]

|R_neg| = (4.0 · 10⁻⁶) / (1.3734 · 10⁻¹¹)                        [ділення крутості g_m на знаменник]
        ≈ 291 248 Ом ≈ 291.2 кОм                                 [абсолютне значення від'ємного опору]

SF = 291248 / 50000 ≈ 5.82                                       [коефіцієнт надійності: |R_neg| / ESR]
```

Отриманий запас `SF = 5.82` перевищує мінімальний інженерний поріг `SF ≥ 3...5`, що гарантує надійний запуск генератора за екстремально низьких температур і зниженої напруги живлення батареї.

### 6. Математична кінетика довготривалого старіння кристала (Aging)

Старіння кварцового резонатора — це поступова незворотна зміна його власної резонансної частоти з плином часу внаслідок механічної релаксації внутрішніх напружень, мікродифузії атомів металевих електродів та адсорбції залишкових газів у вакуумному корпусі.

Кінетика старіння описується логарифмічною моделлю:

```
Δf_aging(t) / f₀ = A · ln(1 + B · t)
```

де:
- `t` — час експлуатації в днях;
- `A` — коефіцієнт амплітуди старіння (типово `±(0.3 ... 0.8) ppm` для якісних кристалів);
- `B` — константа швидкості релаксації (типово `0.05 ... 0.2 діб⁻¹`).

Оскільки похідна логарифмічної функції `d/dt [ln(1 + Bt)] = B / (1 + Bt)` швидко спадає з часом, понад 60–80 % усього старіння відбувається протягом перших 30–90 днів після герметизації резонатора на заводі. Типовий річний показник старіння для прецизійних годинникових кристалів становить `±1 ... ±3 ppm` за перший рік і падає нижче `±0.2 ... ±0.5 ppm/рік` у наступні роки експлуатації.

### 7. Короткочасна нестабільність та варіація Аллана (Allan Deviation)

Крім довготривалого температурного дрейфу та старіння, частота годинникового генератора зазнає короткочасних випадкових флуктуацій, зумовлених тепловим шумом опору втрат `R₁`, флікер-шумом КМОН-інвертора та механічними мікрофлуктуаціями.

Для кількісної оцінки нестабільності в часовій області використовують двовибіркову варіацію Аллана (Allan Variance `σ_y²(τ)`):

```
σ_y²(τ) = (1 / (2 · (M − 1))) · ∑ (ȳ_{k+1} − ȳ_k)²
```

де:
- `τ` — інтервал усереднення (час спостереження);
- `ȳ_k` — середнє відносне відхилення частоти за `k`-й інтервал часу `τ`;
- `M` — загальна кількість послідовних вибірок.

Для годинникового камертонного резонатора 32.768 кГц крива девіації Аллана `σ_y(τ) = √(σ_y²(τ))` має три характерні зони:
1. **Зона білого фазового шуму (`τ < 1 с`):** девіація спадає пропорційно `1 / τ`, типове значення `σ_y(1 с) ≈ 10⁻⁸ ... 10⁻⁷` (`0.01 ... 0.1 ppm`);
2. **Зона флікер-шуму частоти (`1 с < τ < 100 с`):** девіація досягає мінімального плато (flicker floor), яке для якісних камертонів становить `σ_y ≈ (1 ... 3) · 10⁻⁹` (`0.001 ... 0.003 ppm`);
3. **Зона температурного дрейфу та старіння (`τ > 1000 с`):** девіація починає зростати пропорційно `τ` внаслідок повільних добових коливань температури навколишнього середовища.

Це показує, що на коротких інтервалах (секунди) годинниковий кварц має надзвичайно високу стабільність, а головна похибка накопичується виключно на тривалих інтервалах (години й дні) через температурні коливання.

### 8. Математична модель цифрового калібрування (Digital Trimming)

У мікросхемах RTC із цифровим калібруванням прескалера частота самого аналогового генератора не підлаштовується. Натомість використовується цифровий акумулятор похибки в 15-розрядному подільнику частоти.

Стандартний 15-розрядний дільник ділить тактову частоту на 32768:

```
N_cycles = 32768
```

Якщо генератор поспішає на `+δ` ppm, за базовий період інтегрування (наприклад, за 1 хвилину = 60 секунд, що відповідає `60 · 32768 = 1 966 080` тактам генератора) схема штучно додає кілька імпульсів до коефіцієнта ділення, збільшуючи час рахунку секунди.

Дискретність підстроювання частоти при додаванні або пропуску одного такту за інтервал `M` тактів становить:

```
LSB_trim = (1 / M) · 10⁶ [ppm]
```

Якщо інтервал коригування становить 1 хвилину (`M = 1966080` тактів):

```
LSB_trim = (1 / 1966080) · 10⁶ ≈ 0.5086 ppm
```

Кожен крок цифрового калібрувального регістра змінює середній хід годинника на `≈ 0.51 ppm` (що відповідає `0.044 с/добу`).

#### Фазовий джитер при цифровому калібруванні
Оскільки корекція є дискретною, тривалість окремо взятої секунди може коливатися на величину періоду базової частоти:

```
Δt_jitter = 1 / f₀ = 1 / 32768 с ≈ 30.52 мкс
```

Для відображення календарного часу на годиннику чи логування датчиків фазовий джитер у 30.5 мікросекунд є абсолютно непомітним, оскільки в масштабі повної секунди середня накопичена похибка збігається до нуля. Проте для систем прецизійної частотної синхронізації цей фактор слід враховувати.

### 8. Розрахунок ємностей конденсаторів у генераторі Пірса

У генераторі Пірса повна навантажувальна ємність `C_L`, яку бачить кварцовий кристал між своїми виводами, формується послідовним з'єднанням двох зовнішніх конденсаторів `C₁`, `C₂` та додаванням паразитної ємності монтажу:

```
C_L = (C₁ · C₂) / (C₁ + C₂) + C_stray
```

де:
- `C₁` — конденсатор між входом інвертора `OSCI` та землею `GND`;
- `C₂` — конденсатор між виходом інвертора `OSCO` та землею `GND`;
- `C_stray` — паразитна ємність, що включає ємність контактних майданчиків, доріжок плати та внутрішню ємність виводів мікроконтролера чи RTC (`C_stray = C_pcb + (C_in · C_out)/(C_in + C_out)`). Типове практичне значення `C_stray ≈ 2 ... 5 пФ`.

Для забезпечення симетричного фазового зсуву зазвичай обирають однакові номінали `C₁ = C₂ = C_ext`:

```
C_L = (C_ext · C_ext) / (2 · C_ext) + C_stray = C_ext / 2 + C_stray
```

Звідси формула для розрахунку номіналів зовнішніх конденсаторів:

```
C_ext = 2 · (C_L − C_stray)
```

**Розрахунок для кварцу з номіналом C_L = 12.5 пФ:**
Приймаємо `C_stray = 3.0 пФ`.

```
C_ext = 2 · (12.5 − 3.0) = 2 · 9.5 = 19.0 пФ
```

Обираємо стандартний номінал керамічних конденсаторів класу NP0/C0G: `18 пФ` або `20 пФ` (допуск `±5%`).

**Розрахунок для низькоємнісного кварцу C_L = 6.0 пФ:**
Приймаємо `C_stray = 2.5 пФ`.

```
C_ext = 2 · (6.0 − 2.5) = 2 · 3.5 = 7.0 пФ
```

Обираємо номінал `6.8 пФ` або використовуємо вбудовані програмовані ємності мікросхеми RTC без встановлення зовнішніх компонентів.

### 9. Рівень збудження та потужність розсіювання (Drive Level)

Потужність змінного струму, що розсіюється на кварцовому кристалі в режимі стаціонарних коливань:

```
P_drive = I_q_rms² · ESR
```

де:
- `I_q_rms` — діюче значення струму через кристал;
- `ESR` — еквівалентний послідовний опір резонатора на частоті 32.768 кГц.

Струм через кристал зв'язаний з амплітудою коливань напруги `V_peak` на виводі `OSCI` та ємністю навантаження `C_L`:

```
I_q_rms = (2 · π · f₀ · C_L · V_peak) / √2
```

Підставляючи вираз для струму у формулу потужності:

```
P_drive = 2 · π² · f₀² · C_L² · V_peak² · ESR
```

**Числовий приклад розрахунку рівня збудження:**
- `f₀ = 32768 Гц`;
- `C_L = 12.5 пФ = 12.5 · 10⁻¹² Ф`;
- `ESR = 50 кОм = 50 000 Ом`;
- Амплітуда напруги: `V_peak = 0.4 В`.

```
f₀² = (32768)² ≈ 1.0737 · 10⁹ Гц²
C_L² = (12.5 · 10⁻¹²)² = 1.5625 · 10⁻²² Ф²
V_peak² = (0.4)² = 0.16 В²

P_drive = 2 · (3.14159)² · (1.0737 · 10⁹) · (1.5625 · 10⁻²²) · 0.16 · 50000
        = 2 · 9.8696 · 1.0737 · 10⁹ · 1.5625 · 10⁻²² · 0.16 · 50000
        ≈ 2.65 · 10⁻⁸ Вт = 0.0265 мкВт = 26.5 нВт
```

Отримане значення `0.0265 мкВт` (26.5 нВт) лежить значно нижче гранично допустимого порогу `1.0 мкВт`, що гарантує відсутність механічної втоми та багаторічну стабільність параметрів п'єзоелемента.

### 10. Енергетичний розрахунок тривалості резервного живлення

Час автономної роботи RTC від резервного джерела залежить від енергоємності накопичувача та струму споживання мікросхеми в режимі зберігання часу `I_RTC`.

#### А. Розрахунок часу роботи від суперконденсатора (EDLC)

Суперконденсатор віддає заряд зі спадною лінійною залежністю напруги. Якщо струм споживання RTC прийняти постійним `I_RTC` (для КМОН-схем RTC струм практично не залежить від напруги в діапазоні від 3.3 В до 1.8 В):

```
Q = C · ΔV
I_RTC · t = C · (V_init − V_min)
t_backup = [ C · (V_init − V_min) ] / (I_RTC + I_leak)
```

де:
- `C` — ємність суперконденсатора (Фарад);
- `V_init` — початкова напруга заряду (наприклад, 3.3 В або 3.0 В після діода розв'язки: `V_init = 3.3 − 0.3 = 3.0 В`);
- `V_min` — мінімальна робоча напруга RTC (типово `1.6 ... 1.8 В`);
- `I_RTC` — струм споживання мікросхеми годинника (типово `200 ... 400 нА`);
- `I_leak` — власний струм витоку суперконденсатора (для якісних іоністорів ємністю 0.1–0.47 Ф становить близько `100 ... 300 нА` після 72 годин стабілізації).

**Числовий приклад розрахунку для суперконденсатора 0.47 Ф:**
- `C = 0.47 Ф`;
- `V_init = 3.0 В`;
- `V_min = 1.8 В`;
- `I_RTC = 250 нА = 0.25 · 10⁻⁶ А`;
- `I_leak = 150 нА = 0.15 · 10⁻⁶ А`.

```
ΔV = 3.0 − 1.8 = 1.2 В                                            [корисний перепад робочої напруги]
I_total = 0.25 + 0.15 = 0.40 мкА = 400 · 10⁻⁹ А                   [сумарний струм: RTC + витік суперконденсатора]

t_backup = (0.47 · 1.2) / (400 · 10⁻⁹)                            [формула t = C·ΔV / I_total]
         = 0.564 / (400 · 10⁻⁹)                                   [обчислення заряду Q = C·ΔV]
         = 1 410 000 секунд                                       [розрахунок часу в секундах]

У годинах:
t_hours = 1410000 / 3600 ≈ 391.6 годин                            [переведення секунд у години (3600 с/год)]

У добах:
t_days = 391.6 / 24 ≈ 16.3 доби                                   [переведення годин у доби (24 год/добу)]
```

Суперконденсатор ємністю `0.47 Ф` гарантує понад два тижні безперервного ходу годинника при повному знеструмленні системи без використання хімічних батарей.

#### Б. Розрахунок терміну служби літієвого елемента (CR2032)

Для первинного літієвого дискового елемента типу CR2032 (хімічна система `Li / MnO₂`, номінальна ємність `Q_nom ≈ 220 ... 240 мА·год`, напруга 3.0 В):

```
T_years = Q_eff / ( (I_RTC + I_self) · 8760 годин/рік )
```

де:
- `Q_eff` — ефективна корисна ємність з урахуванням кінцевої напруги відсічки 2.0 В (близько `210 мА·год = 210 000 мкА·год`);
- `I_RTC` — середнє споживання RTC від батареї (наприклад, `0.35 мкА`);
- `I_self` — еквіваленнтний струм внутрішнього саморозряду літієвого елемента (при `+25 °C` саморозряд становить близько `1%` на рік, що відповідає `I_self ≈ (220 000 · 0.01) / 8760 ≈ 0.25 мкА`).

```
I_total = 0.35 + 0.25 = 0.60 мкА                                  [сума струму RTC та власного саморозряду]

T_hours = 210000 / 0.60 = 350 000 годин                           [час роботи в годинах: Q_eff / I_total]
T_years = 350000 / 8760 ≈ 39.9 років                              [переведення годин у роки (8760 год/рік)]
```

Оскільки хімічний ресурс ущільнювальних полімерних прокладок дискових батарей становить 10–15 років (через поступову дифузію вологи та висихання електроліту), реальний термін автономної служби системи обмежується виключно надійністю самої батареї, а не споживанням RTC.
