# 🧮 Розрахунок магнітного опору, випучування поля та енергетичного балансу зазору

Коли інженер розраховує силовий індуктивний елемент — імпульсний трансформатор чи накопичувальний дросель — перед ним постає фундаментальне завдання: визначити точне значення індуктивності, струм насичення та розподіл втрат. Спрощені формули з шкільного курсу фізики розглядають нескінченно довгі соленоїди або ідеальні тороїди без розривів. У реальному пристрої магнітний потік проходить крізь неоднорідні середовища: феромагнітне осердя зі змінною магнітною проникністю та один або кілька технологічних повітряних зазорів. Без суворого математичного зв'язку між рівняннями поля Максвелла, геометричними розмірами осердя та параметрами електричного кола неможливо спроектувати моточний вузол, який не згорить від перегріву чи не піде в насичення при піковому навантаженні.

Цей розділ містить строге математичне виведення закону Гопкінсона, розрахунок релюктансу, аналіз коефіцієнта випучування ліній поля поблизу зазору, фізику вихрових втрат у міді, аналіз температурної стабілізації, порівняння топологій розташування зазору та точний баланс накопиченої енергії.

### 1. Виведення закону Гопкінсона з рівнянь Максвелла

Основою теорії магнітних кіл є два фундаментальні закони електродинаміки у квазістатичному наближенні: закон повного струму (теорема Ампера про циркуляцію) та теорема Гауса для магнітного вектора.

Закон повного струму у векторній інтегральній формі стверджує, що лінійний інтеграл вектора напруженості магнітного поля `H` вздовж довільного замкненого контуру `C` дорівнює сумарному електричному струму, охопленому цим контуром:

```
∮ H · dl = I_total      [закон циркуляції Ампера]
```

Якщо контур охоплює котушку, що містить `N` послідовних витків зі струмом `I`, повний охоплений струм (магніторушійна сила, МРС `F`) становить:

```
I_total = N · I = F      [магніторушійна сила контуру, ампер-витки]
```

Розглянемо замкнений магнітопровід, розбитий на `k` послідовних однорідних ділянок довжиною `l_k` із постійною площею перерізу `A_k` та однорідним ізотропним магнітним середовищем з абсолютною магнітною проникністю `μ_k = μ_0 · μ_r,k`. Лінійний інтеграл розпадається на суму інтегралів за окремими ділянками:

```
∮ H · dl 
= ∑ ∫ (H_k · dl)      [розбиття контуру на k ділянок]
= ∑ (H_k · l_k)       [поле вздовж осі ділянки вважаємо однорідним]
= N · I               [прирівнювання до повної МРС]
```

Зв'язок між вектором магнітної індукції `B` та вектором напруженості `H` у лінійному або лінеаризованому магнітному матеріалі визначається матеріальним рівнянням:

```
B_k = μ_k · H_k  ⇒  H_k = B_k / μ_k      [матеріальне співвідношення]
```

Теорема Гауса для магнітного поля стверджує, що потік вектора магнітної індукції крізь будь-яку замкнену поверхню дорівнює нулю (відсутність магнітних зарядів-монополів):

```
∯ B · dA = 0      [неперервність ліній магнітної індукції]
```

Це означає, що за відсутності бічного витоку через повітря сумарний магнітний потік `Φ`, який пронизує поперечний переріз магнітопроводу, є однаковим для всіх послідовних ділянок контуру:

```
Φ = ∬ B_k · dA = B_k · A_k  ⇒  B_k = Φ / A_k      [магнітний потік через переріз Ak]
```

Підставивши вираз для `B_k` у формулу напруженості `H_k`:

```
H_k = Φ / (μ_k · A_k)      [напруженість поля на k-й ділянці]
```

Тепер підставимо `H_k` у суму циркуляції вздовж усього замкненого контуру:

```
N · I 
= ∑ (H_k · l_k) 
= ∑ (Φ · l_k / (μ_k · A_k)) 
= Φ · ∑ (l_k / (μ_k · A_k))      [винесення спільного потоку Φ за дужки]
```

Введемо величину магнітного опору (релюктансу) для кожної ділянки `R_m,k`:

```
R_m,k = l_k / (μ_k · A_k) = l_k / (μ_0 · μ_r,k · A_k)      [релюктанс ділянки, 1/Гн]
```

Сума релюктансів послідовних ділянок дає повний магнітний опір кола `R_m,total`:

```
R_m,total = ∑ R_m,k      [повний релюктанс нерозгалуженого кола]
```

У результаті отримуємо формулу закону Гопкінсона:

```
F = N · I = Φ · R_m,total      [закон Гопкінсона: МРС = Потік · Релюктанс]
```

Обернена до релюктансу величина називається магнітною провідністю або **пермеансом** `P_m`:

```
P_m = 1 / R_m = μ_0 · μ_r · A / l      [пермеанс, Генрі, Гн]
```

### 2. Зв'язок релюктансу з індуктивністю котушки

За фундаментальним означенням, індуктивність `L` електричного кола — це коефіцієнт пропорційності між електричним струмом `I` у котушці та повним зчепленим із нею магнітним потоком (потокозчепленням `Ψ`):

```
Ψ = N · Φ      [повне потокозчеплення котушки з N витків]
L = Ψ / I = (N · Φ) / I      [означення індуктивності]
```

Виразимо магнітний потік `Φ` через закон Гопкінсона:

```
Φ = F / R_m = (N · I) / R_m      [магнітний потік збудження]
```

Підставимо отриманий вираз для `Φ` у формулу індуктивності:

```
L 
= (N · (N · I / R_m)) / I 
= N² / R_m                     [індуктивність через релюктанс, Гн]
= N² · P_m                     [індуктивність через пермеанс, Гн]
```

У довідниках виробників феритових осердь (TDK/Epcos, Ferroxcube, Würth Elektronik) геометрію магнітопроводу характеризують параметром **фактора індуктивності** `A_L` (*inductance factor*). За означенням:

```
A_L = L / N² = 1 / R_m = P_m      [фактор індуктивності осердя, нГн/вит²]
```

Знаючи паспортне значення `A_L`, інженер розраховує потрібну кількість витків `N` для досягнення цільової індуктивності `L` безпосередньо:

```
N = √(L / A_L)      [кількість витків котушки]
```

### 3. Релюктанс сердечника та повітряного зазору

Розглянемо магнітне коло, що складається з феромагнітного осердя із середньою довжиною магнітної лінії `l_e`, площею перерізу `A_e`, відносною проникністю `μ_r >> 1` та немагнітного зазору довжиною `l_g` (`l_g << l_e`).

Повний магнітний опір контуру є сумою двох послідовних релюктансів:

```
R_m,total = R_core + R_gap      [сумарний релюктанс]
```

Де релюктанс феромагнітного осердя (з урахуванням зменшення довжини фериту на величину зазору `l_e - l_g ≈ l_e`):

```
R_core = l_e / (μ_0 · μ_r · A_e)      [релюктанс матеріалу осердя]
```

Релюктанс повітряного зазору (приймаючи на першому кроці площу зазору рівною перерізу осердя `A_gap = A_e` та `μ_r,gap = 1`):

```
R_gap = l_g / (μ_0 · A_e)      [релюктанс немагнітного зазору]
```

Знайдемо співвідношення між релюктансом зазору та релюктансом осердя:

```
R_gap / R_core 
= (l_g / (μ_0 · A_e)) / (l_e / (μ_0 · μ_r · A_e)) 
= (l_g / l_e) · μ_r      [відношення магнітних опорів]
```

**Кількісний приклад співвідношення:**
Нехай довжина феритового сердечника `l_e = 100 мм`, зазор `l_g = 0.5 мм`, відносна проникність фериту `μ_r = 2000`.

```
l_g / l_e = 0.5 мм / 100 мм = 0.005  (зазор становить лише 0.5% довжини осердя)
R_gap / R_core = 0.005 · 2000 = 10.0
```

Релюктанс міліметрового повітряного проміжку у 10 разів перевищує релюктанс усього стоміліметрового феритового масиву!
Частка зазору в загальному магнітному опорі контуру становить:

```
R_gap / R_m,total = 10 / (1 + 10) = 10 / 11 ≈ 90.9%
```

### 4. Температурна стабілізація індуктивності зазором

Феромагнітні матеріали мають сильний температурний коефіцієнт початкової проникності `TK_μ = (1 / μ_r) · (dμ_r / dT)`, величина якого у силових феритів (наприклад N87 або 3C90) становить `+0.2% ... +0.5% / °C`. У діапазоні температур від −40°C до +100°C проникність фериту без зазору зростає на 40–60%.

Дослідимо, як повітряний зазор пригнічує температурний дрейф індуктивності `TK_L = (1 / L) · (dL / dT)`. Оскільки `L = N² / (R_core + R_gap)`, продиференціюємо `L` за температурою `T`:

```
dL / dT 
= -N² / (R_core + R_gap)² · (dR_core / dT + dR_gap / dT)
= -N² / R_m,total² · (dR_core / dT)      [оскільки dR_gap / dT = 0 для повітря]
```

Похідна релюктансу фериту за температурою:

```
dR_core / dT 
= d/dT [ l_e / (μ_0 · μ_r(T) · A_e) ]
= -l_e / (μ_0 · μ_r² · A_e) · (dμ_r / dT)
= -R_core · (1 / μ_r) · (dμ_r / dT)
= -R_core · TK_μ
```

Підставимо вираз для `dR_core / dT` у формулу для `dL / dT`:

```
dL / dT = N² / R_m,total² · R_core · TK_μ
```

Поділивши на `L = N² / R_m,total`, отримуємо чутливість індуктивності до зміни температури:

```
TK_L = (1 / L) · (dL / dT) = (R_core / R_m,total) · TK_μ
```

**Фундаментальний результат:** Температурний коефіцієнт індуктивності дроселя послаблюється рівно у стільки разів, у скільки повний релюктанс перевищує релюктанс фериту. Якщо `R_core / R_m,total = 0.05` (частка зазору 95%), то температурний дрейф індуктивності становить лише `5%` від дрейфу самого фериту. Замість зміни на 50% індуктивність коливається в межах лише `2.5%`, що критично для прецизійних фільтрів та резонансних перетворювачів.

### 5. Теорема локалізації енергії магнітного поля

Густина енергії магнітного поля `w` в однорідному середовищі виражається через вектори `B` і `H`:

```
w = 0.5 · B · H = 0.5 · B² / μ      [об'ємна густина енергії поля, Дж/м³]
```

Оскільки за неперервністю магнітного потоку `Φ` індукція `B` у фериті та зазорі однакова (`B_core ≈ B_gap = B`), порівняємо густину енергії у фериті `w_core` та в повітряному зазорі `w_gap`:

```
w_core = 0.5 · B² / (μ_0 · μ_r)      [густина енергії у феромагнетику]
w_gap  = 0.5 · B² / μ_0              [густина енергії в повітряному зазорі]
w_gap / w_core = μ_r                 [відношення густин енергії]
```

При `μ_r = 2000` густина енергії в зазорі рівно у 2000 разів вища, ніж усередині фериту.

Обчислимо повну енергію поля, накопичену в об'ємі феритового осердя `V_core = A_e · l_e` та в об'ємі зазору `V_gap = A_e · l_g`:

```
W_core = w_core · V_core = (0.5 · B² / (μ_0 · μ_r)) · (A_e · l_e)
W_gap  = w_gap · V_gap   = (0.5 · B² / μ_0) · (A_e · l_g)
```

Виразимо ці енергії через магнітний потік `Φ = B · A_e` та формули релюктансів `R_core` і `R_gap`:

```
W_core 
= 0.5 · (Φ / A_e)² · (A_e · l_e) / (μ_0 · μ_r) 
= 0.5 · Φ² · (l_e / (μ_0 · μ_r · A_e)) 
= 0.5 · Φ² · R_core      [енергія у фериті через релюктанс]

W_gap 
= 0.5 · (Φ / A_e)² · (A_e · l_g) / μ_0 
= 0.5 · Φ² · (l_g / (μ_0 · A_e)) 
= 0.5 · Φ² · R_gap       [енергія в зазорі через релюктанс]
```

Сумарна накопичена магнітна енергія системи:

```
W_total 
= W_core + W_gap 
= 0.5 · Φ² · (R_core + R_gap) 
= 0.5 · Φ² · R_m,total   [повна енергія магнітного кола]
```

Звідси отримуємо фундаментальне співвідношення локалізації енергії:

```
W_gap / W_total = R_gap / (R_core + R_gap) = R_gap / R_m,total
```

**Висновок:** Частка магнітної енергії, збереженої в об'ємі зазору, точно дорівнює частці релюктансу зазору в повному магнітному опорі кола. Для розглянутого вище прикладу понад 90.9% енергії магнітного поля фізично накопичується у вакуумі зазору, а ферит виконує роль провідника («магнітної труби») із низькими втратами, що транспортує потік до зазору.

### 6. Математичне моделювання крайового випучування потоку (Fringing Flux)

В одновимірній моделі передбачається, що магнітні силові лінії в зазорі є строго паралельними площині полюсів. Насправді через відсутність магнітних ізоляторів лінії поля на зовнішніх межах зазору вигинаються назовні в навколишнє середовище, формуючи опуклі дуги.

#### Аналітичне походження логарифмічного члена (конформне відображення Шварца-Крістоффеля)
Двовимірний крайовий розподіл поля біля кута феритового полюса математично описується конформним відображенням напівплощини на кутову область зазору. Інтегрування вектора напруженості `H(x, y)` вздовж радіальних кругових дуг радіуса `r` (від внутрішньої межі зазору `r = l_g / 2` до зовнішнього габариту вікна `r = G_w`) дає додаткову провідність:

```
d P_fringe = μ_0 · (dr / (π · r)) · L_pole      [елементарний пермеанс кругової трубки]
P_fringe = (μ_0 · L_pole / π) · ∫ (1 / r) dr = (μ_0 · L_pole / π) · ln(2 · G_w / l_g)
```

де `L_pole` — периметр торця полюса. Цей результат суворо доводить появу логарифмічного члена `ln(2·G_w / l_g)` у формулах Картера та Маклаймана.

#### Модель еквівалентного розширення перерізу (модель торцевих смуг)
Для прямокутного перерізу полюса розмірами `a × b` потік випучується з усіх чотирьох боків на відстань порядку половини довжини зазору `l_g / 2`. Ефективні розміри перерізу зазору набувають вигляду:

```
a_eff = a + l_g      [ефективна ширина полюса]
b_eff = b + l_g      [ефективна висота полюса]
A_eff = a_eff · b_eff = (a + l_g) · (b + l_g) = a · b + (a + b) · l_g + l_g²      [ефективна площа зазору]
```

Коефіцієнт випучування (фактор збільшення провідності) `F_fringe`:

```
F_fringe = A_eff / A_e = 1 + ((a + b) / (a · b)) · l_g + (l_g² / (a · b))
```

#### Напівемпірична модель Маклаймана (Colonel Wm. T. McLyman)
Для осердь із замкненим вікном намотки висотою `G_w` (відстань між внутрішніми полицями ярма) випучування обмежене сусідніми металевими стінками. За формулою Маклаймана коефіцієнт випучування становить:

```
F_fringe = 1 + (l_g / √A_e) · ln(2 · G_w / l_g)      [фактор випучування за Маклайманом]
```

Уточнений релюктанс зазору з урахуванням випучування:

```
R_gap,eff = l_g / (μ_0 · A_eff) = R_gap,1D / F_fringe      [скоригований релюктанс зазору]
```

Скоригований фактор індуктивності осердя `A_L,eff`:

```
A_L,eff = 1 / (R_core + R_gap,eff) = 1 / (l_e / (μ_0 · μ_r · A_e) + l_g / (μ_0 · A_e · F_fringe))
```

### 7. Фізика та розрахунок вихрових втрат від випучування у провідниках обмотки

Коли радіальні лінії випучування `B_r(t) = B_r,pk · sin(2π·f·t)` виходять за межі осердя, вони пронизують мідні провідники найближчих шарів обмотки перпендикулярно до їхньої поздовжньої осі.

За законом електромагнітної індукції Фарадея змінний потік збуджує всередині тіла провідника локальні кільцеві вихрові струми. Об'ємна густина потужності втрат на вихрові струми у круглому мідному дроті діаметром `d_cu` становить:

```
p_eddy = (π² · f² · B_r,pk² · d_cu² · σ_cu) / 8      [густина вихрових втрат, Вт/м³]
```

де:
- `f` — робоча частота комутації (Гц);
- `B_r,pk` — амплітуда радіальної складової індукції випучування (Тл);
- `d_cu` — діаметр мідної жили (м);
- `σ_cu` — питома провідність міді (`5.8 · 10⁷ См/м` при 20°C).

Радіальна індукція спадає обернено пропорційно відстані від зазору `r`:

```
B_r(r) ≈ (B_gap / π) · (l_g / r)      [радіальна складова поля на відстані r]
```

Підставивши вираз для `B_r(r)` у формулу втрат, бачимо, що вихрові втрати зростають пропорційно квадрату частоти `f²`, квадрату зазору `l_g²` та спадають як `1 / r²`. Якщо провідники розміщені впритул до зазору (`r < l_g`), локальні втрати на одиницю довжини дроту можуть у 10–50 разів перевищувати звичайні джоулеві втрати постійного струму, що призводить до локального термічного прогару каркаса та міжвиткового замикання.

**Критерій безпечної зони:** Для того, щоб вихрові втрати від зазору не перевищували 5% від омічних втрат, відстань `d_safe` від торця зазору до найближчого витка міді повинна задовольняти умову:

```
d_safe ≥ 2 · l_g  ...  3 · l_g      [правило відступу обмотки від зазору]
```

### 8. Топологія зазору в Ш-осерді: центральний керн проти прокладок

У серійному виробництві застосовують два конструктивні способи введення зазору в Ш-подібні (E/ETD/PQ) осердя:
1. **Шліфування центрального керна (*center-leg gap*):** зазор величиною `l_g` виконується лише на середньому стовпчику, а бічні керни щільно зімкнуті;
2. **Вкладання прокладок на всі три керни (*spacer gap*):** між половинками осердя на всі три керни вкладається діелектрична плівка товщиною `t_pad`.

Порівняємо їхню магнітну поведінку:
- При вкладанні прокладки `t_pad` на всі керни, магнітний потік у кожному контурі перетинає зазор двічі: у центральному керні (`t_pad`) та у бічному керні (`t_pad`). Еквівалентна повна довжина зазору контуру становить `l_g,eq = 2 · t_pad`;
- При шліфованому зазорі в центрі магнітне поле випучування локалізоване суворо всередині вікна намотки і повністю екранується суцільними зовнішніми бічними кернами фериту. Зовнішнє електромагнітне випромінювання (EMI) є мінімальним;
- При використанні прокладок відкриті зазори на бічних кернах випромінюють магнітне поле випучування безпосередньо у навколишній простір, наводячи потужні паразитні ЕРС у сусідніх сигнальних доріжках друкованої плати та нагріваючи металевий екран корпусу.

```
Φ_leak,ext ∝ t_pad / R_air      [зовнішній потік розсіювання при бічних зазорах]
```

Тому для пристроїв із жорсткими вимогами до ЕМС (EMC) та мінімальних втрат перевагу завжди віддають шліфуванню центрального керна.

### 9. Розподілений зазор у порошкових осердях: математичний баланс

Альтернативою зосередженому зазору `l_g` є використання порошкових композитів (Sendust, Kool Mμ, MPP, High Flux), де феромагнітні зерна розділені тонким шаром діелектричної зв'язки товщиною `δ_i`.

Якщо зосереджений зазор довжиною `l_g` розбити на `n` мікрозазорів (`δ_i = l_g / n`), сумарний магнітний опір залишається незмінним:

```
R_gap,dist = ∑ (δ_i / (μ_0 · A_e)) = (n · (l_g / n)) / (μ_0 · A_e) = l_g / (μ_0 · A_e)
```

Проте амплітуда випучування поля для кожного окремого мікрозазору зменшується в `n` разів:

```
B_r,i ∝ δ_i = l_g / n      [радіальне поле мікрозазору]
```

Оскільки вихрові втрати пропорційні сумі квадратів полів:

```
P_eddy,total ∝ n · (B_r,i)² = n · (l_g / n)² = l_g² / n
```

Сумарні вихрові втрати в обмотці поблизу магнітопроводу з розподіленим зазором зменшуються у `n` разів (де `n` може становити сотні тисяч мікрозазорів між зернами). Саме тому порошкові осердя не створюють локальних гарячих точок випучування і дозволяють намотувати дріт безпосередньо на тіло тороїда.

### 10. Наскрізний числовий розрахунок силового дроселя

Проведемо повний розрахунок накопичувального дроселя для DC-DC перетворювача на базі стандартного феритового осердя ETD44 (матеріал N87, TDK/Epcos).

**Вхідні геометричні та фізичні параметри осердя:**
- Ефективна площа перерізу: `A_e = 173 мм² = 1.73 · 10⁻⁴ м²`
- Середня довжина магнітної лінії: `l_e = 103 мм = 0.103 м`
- Висота вікна намотки: `G_w = 29.5 мм = 0.0295 м`
- Початкова відносна проникність матеріалу N87 при 25°C: `μ_r = 2200`
- Магнітна індукція насичення при 100°C: `B_sat = 0.39 Тл`
- Магнітна стала: `μ_0 = 4π · 10⁻⁷ Гн/м ≈ 1.2566 · 10⁻⁶ Гн/м`
- Кількість витків обмотки: `N = 30`
- Довжина зазору в центральному керні: `l_g = 1.2 мм = 1.2 · 10⁻³ м`

**Крок 1. Розрахунок параметрів суцільного осердя (без зазору):**
Обчислимо релюктанс феритового тіла:

```
R_core 
= l_e / (μ_0 · μ_r · A_e)
= 0.103 / (1.2566 · 10⁻⁶ · 2200 · 1.73 · 10⁻⁴)
= 0.103 / (4.7828 · 10⁻⁷)
≈ 2.153 · 10⁵ 1/Гн      [магнітний опір фериту]
```

Фактор індуктивності без зазору:

```
A_L,ungapped = 1 / R_core = 1 / (2.153 · 10⁵) ≈ 4.644 · 10⁻⁶ Гн = 4644 нГн/вит²
```

Індуктивність котушки з 30 витків без зазору:

```
L_ungapped = N² · A_L = 30² · 4644 · 10⁻⁹ Гн = 900 · 4.644 · 10⁻⁶ Гн ≈ 4.18 мГн
```

Максимальний магнітний потік до настання насичення:

```
Φ_sat = B_sat · A_e = 0.39 Тл · 1.73 · 10⁻⁴ м² ≈ 6.747 · 10⁻⁵ Вб
```

Струм насичення без зазору:

```
I_sat,ungapped 
= (Φ_sat · R_core) / N               [струм насичення через закон Гопкінсона]
= (6.747 · 10⁻⁵ · 2.153 · 10⁵) / 30  [підстановка потоку насичення та релюктансу]
= 14.526 / 30                        [обчислення магніторушійної сили]
≈ 0.484 А                            [струм насичення суцільного осердя]
```

Котушка на суцільному осерді входить у насичення вже при струмі менше пів ампера!

**Крок 2. Розрахунок параметрів осердя з повітряним зазором:**
Обчислимо одновимірний релюктанс зазору `R_gap,1D`:

```
R_gap,1D 
= l_g / (μ_0 · A_e)                          [визначення релюктансу зазору]
= 1.2 · 10⁻³ / (1.2566 · 10⁻⁶ · 1.73 · 10⁻⁴) [підстановка геометрії]
= 1.2 · 10⁻³ / (2.1739 · 10⁻¹⁰)              [обчислення пермеансу]
≈ 5.520 · 10⁶ 1/Гн                           [одновимірний опір зазору]
```

Обчислимо коефіцієнт випучування `F_fringe` за моделлю Маклаймана:

```
F_fringe 
= 1 + (l_g / √A_e) · ln(2 · G_w / l_g)                         [формула Маклаймана]
= 1 + (0.0012 / √(1.73 · 10⁻⁴)) · ln(2 · 0.0295 / 0.0012)     [підстановка розмірів вікна]
= 1 + (0.0012 / 0.01315) · ln(0.0590 / 0.0012)                 [відношення геометричних довжин]
= 1 + 0.09125 · ln(49.17)                                      [логарифм крайової трубки]
= 1 + 0.09125 · 3.895                                          [обчислення логарифма]
= 1 + 0.3554                                                   [додаткова провідність країв]
≈ 1.355                                                        [коефіцієнт випучування поля]
```

Завдяки випучуванню потоку магнітна провідність зазору зростає на 35.5%. Скоригований релюктанс зазору:

```
R_gap,eff = R_gap,1D / F_fringe = 5.520 · 10⁶ / 1.355 ≈ 4.074 · 10⁶ 1/Гн      [скоригований релюктанс зазору]
```

Повний скоригований магнітний опір кола:

```
R_m,total 
= R_core + R_gap,eff             [послідовне додавання релюктансів]
= 0.215 · 10⁶ + 4.074 · 10⁶      [підстановка складових]
= 4.289 · 10⁶ 1/Гн               [повний релюктанс кола]
```

Частка зазору в загальному релюктансі:

```
R_gap,eff / R_m,total = 4.074 / 4.289 ≈ 95.0%      [частка магнітного опору зазору]
```

Скоригований фактор індуктивності осердя із зазором:

```
A_L,gapped = 1 / R_m,total = 1 / (4.289 · 10⁶) ≈ 2.332 · 10⁻⁷ Гн = 233.2 нГн/вит²      [фактор індуктивності із зазором]
```

Нова індуктивність дроселя:

```
L_gapped = N² · A_L,gapped = 900 · 233.2 · 10⁻⁹ Гн ≈ 209.9 мкГн      [індуктивність 30 витків із зазором]
```

Новий струм насичення із зазором:

```
I_sat,gapped 
= (Φ_sat · R_m,total) / N               [струм насичення через повний релюктанс]
= (6.747 · 10⁻⁵ · 4.289 · 10⁶) / 30     [підстановка параметрів із зазором]
= 289.38 / 30                           [нова магніторушійна сила насичення]
≈ 9.65 А                                [струм насичення із зазором]
```

**Підсумкове порівняння результатів:**
- Індуктивність зменшилася з `4.18 мГн` до `210 мкГн` (у 20 разів);
- Струм насичення зріс із `0.484 А` до `9.65 А` (у 20 разів!);
- Максимальна накопичена магнітна енергія `W_max = 0.5 · L · I_sat²`:
  - Без зазору: `W_max = 0.5 · 4.18 · 10⁻³ · 0.484² ≈ 0.489 мДж`
  - Із зазором: `W_max = 0.5 · 210 · 10⁻⁶ · 9.65² ≈ 9.778 мДж` (зросла рівно у 20 разів!);
- 95% цієї енергії (`9.29 мДж`) локалізовано безпосередньо у повітряному зазорі об'ємом менше `0.21 см³`.
