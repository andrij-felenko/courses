# 🧮 Аналітична теорія та суперпозиція поля масиву Гальбаха

Аналітичне пояснення ефекту однобічного магнітного потоку ґрунтується на магнітостатиці лінійних середовищ, розв'язанні крайової задачі для магнітного скалярного потенціалу та розкладанні просторового розподілу намагніченості у гармонічний ряд Фур'є. Нижче наведено послідовне виведення поля для ідеального неперервного масиву, доказ повної компенсації на слабкому боці, а також розрахунок коефіцієнта підсилення індукції для дискретних сегментів.

### Крайова задача магнітостатики

Розглянемо нескінченну в напрямку осі `z` магнітну пластину товщиною `d`, розташовану у шарі між `y = -d` та `y = 0`. Простір `y > 0` відповідає верхньому півпростору (робочий «сильний» бік), а простір `y < -d` — нижньому півпростору («слабкий» бік).

Для рідкісноземельних постійних магнітів (NdFeB, SmCo) крива розмагнічування у другому квадранті є строго лінійною, а відносна магнітна проникність `μ_r` надзвичайно близька до одиниці (`μ_r ≈ 1.05`). Тому з високою точністю приймаємо `μ_r = 1`, розглядаючи магніт як вакуум із «замороженим» вектором залишкової намагніченості `M`.

Зв'язок векторів магнітної індукції `B` та напруженості магнітного поля `H`:

```
B = μ₀ · (H + M)      [всередині магнітного шару]
B = μ₀ · H            [у вакуумі за межами шару]
```

Оскільки в системі відсутні вільні електричні струми (`j = 0`), за законом Ампера ротор напруженості дорівнює нулю:

```
∇ × H = 0  ⇒  H = -∇Φ
```

де `Φ(x, y)` — магнітний скалярний потенціал.

З фундаментального рівняння неперервності магнітної індукції `∇ · B = 0` отримуємо:

```
∇ · B = μ₀ · ∇ · (-∇Φ + M) = 0
∇²Φ = ∇ · M
```

Величину `ρ_m = -∇ · M` називають **об'ємною густиною фіктивних магнітних зарядів**. Отже, скалярний потенціал задовольняє рівняння Пуассона всередині магніту та рівняння Лапласа поза ним:

```
∇²Φ = -ρ_m      [-d ≤ y ≤ 0, всередині магніту]
∇²Φ = 0         [y > 0 та y < -d, у вакуумі]
```

На межах розділу `y = 0` та `y = -d` діють граничні умови неперервності тангенціальної складової `H_x` (неперервність потенціалу `Φ`) та нормальної складової індукції `B_y`:

```
Φ(x, 0⁺) = Φ(x, 0⁻)
B_y(x, 0⁺) = B_y(x, 0⁻)  ⇒  -(∂Φ/∂y)|₀₊ = -(∂Φ/∂y)|₀₋ + M_y(x, 0⁻)
```

Стрибок похідної потенціалу на межі визначається **поверхневою густиною магнітних зарядів** `σ_m = M · n̂`:

```
σ_m(y = 0)  = +M_y(x, 0)
σ_m(y = -d) = -M_y(x, -d)
```

### Неперервний розподіл намагніченості

Нехай вектор намагніченості в шарі `-d ≤ y ≤ 0` повертається у площині `(x, y)` із просторовою довжиною хвилі `λ` (хвильове число `k = 2π / λ`):

```
M_x(x) = M₀ · cos(k · x)
M_y(x) = M₀ · sin(k · x)
```

Знайдемо об'ємну густину магнітних зарядів `ρ_m` всередині шару:

```
ρ_m = -(∂M_x/∂x + ∂M_y/∂y)          [означення об'ємного магнітного заряду]
    = -(-k · M₀ · sin(k · x) + 0)   [диференціювання гармонік M_x та M_y]
    = k · M₀ · sin(k · x)           [розкриття дужок і знаків мінус]
```

Поверхневі заряди на верхній і нижній гранях:

```
σ_m(y = 0)  = M_y(x) = M₀ · sin(k · x)
σ_m(y = -d) = -M_y(x) = -M₀ · sin(k · x)
```

### Розв'язання рівнянь для потенціалу

Шукаємо потенціал у вигляді `Φ(x, y) = X(x) · Y(y)`. З огляду на гармонічність джерел уздовж `x`, залежність від `x` має вигляд `sin(k · x)`.

1. **Верхній півпростір (`y > 0`):**
Рівняння `∇²Φ₁ = 0` з умовою згасання потенціалу на нескінченності `Φ₁ → 0` при `y → +∞`:

```
Φ₁(x, y) = A₁ · e^{-k·y} · sin(k · x)
```

2. **Нижній півпростір (`y < -d`):**
Рівняння `∇²Φ₃ = 0` з умовою згасання при `y → -∞`:

```
Φ₃(x, y) = A₃ · e^{k·(y + d)} · sin(k · x)
```

3. **Всередині магнітного шару (`-d ≤ y ≤ 0`):**
Рівняння Пуассона `∂²Φ₂/∂x² + ∂²Φ₂/∂y² = -k · M₀ · sin(k · x)`.
Підставляючи `Φ₂(x, y) = Y₂(y) · sin(k · x)`, маємо:

```
-k² · Y₂ + d²Y₂/dy² = -k · M₀
d²Y₂/dy² - k² · Y₂ = -k · M₀
```

Частинний розв'язок неоднорідного рівняння є константою `Y_{част} = M₀ / k`.
Загальний розв'язок:

```
Φ₂(x, y) = [C₁ · e^{-k·y} + C₂ · e^{k·y} + (M₀ / k)] · sin(k · x)
```

Геометричний зміст цього розв'язку полягає в тому, що магнітні еквіпотенціальні лінії всередині масиву утворюють плавні замкнені дуги, які перенаправляють вектор напруженості `H` у бік верхньої робочої межі. Горизонтальна складова намагніченості діє як розподілений магнітний провідник («віртуальне ярмо»), що транспортує магнітний потік від полюса `S` одного вертикального магніту до полюса `N` сусіднього безпосередньо в товщі матеріалу.

### Зшивання на межах та доказ однобічності

Застосуємо граничні умови неперервності потенціалу `Φ` та стрибка нормальної похідної `∂Φ/∂y` на межах `y = 0` та `y = -d`:

**На межі `y = 0`:**

```
Φ₁(x, 0) = Φ₂(x, 0)
A₁ = C₁ + C₂ + (M₀ / k)                     [1: неперервність потенціалу]

-(∂Φ₁/∂y)|₀ = -(∂Φ₂/∂y)|₀ + M_y
k · A₁ = -k · C₁ + k · C₂ + M₀
A₁ = -C₁ + C₂ + (M₀ / k)                    [2: неперервність індукції B_y]
```

Віднімемо рівняння [2] від рівняння [1]:

```
A₁ - A₁ = (C₁ + C₂ + M₀/k) - (-C₁ + C₂ + M₀/k)
0 = 2 · C₁  ⇒  C₁ = 0
```

Підставивши `C₁ = 0` у рівняння [1], отримуємо:

```
A₁ = C₂ + (M₀ / k)
```

**На межі `y = -d`:**

```
Φ₂(x, -d) = Φ₃(x, -d)
C₂ · e^{-k·d} + (M₀ / k) = A₃               [3: неперервність потенціалу]

-(∂Φ₂/∂y)|_{-d} + M_y = -(∂Φ₃/∂y)|_{-d}
-k · C₂ · e^{-k·d} + M₀ = -k · A₃
C₂ · e^{-k·d} - (M₀ / k) = A₃               [4: неперервність індукції B_y]
```

Прирівняємо ліві частини рівнянь [3] та [4]:

```
C₂ · e^{-k·d} + (M₀ / k) = C₂ · e^{-k·d} - (M₀ / k)
2 · (M₀ / k) = 0
```

Оскільки `M₀ ≠ 0`, рівність можлива лише за умови вибору розв'язку:

```
A₃ = 0
C₂ = -(M₀ / k)
```

Підставивши знайдені коефіцієнти `C₁ = 0` та `C₂ = -(M₀ / k)`:

```
A₁ = -(M₀ / k) · e^{-k·d} + (M₀ / k) = (M₀ / k) · (1 - e^{-k·d})
A₃ = 0
```

Це фундаментальний результат: **коефіцієнт `A₃` строго дорівнює нулю**. Отже, у всьому нижньому півпросторі `y < -d`:

```
Φ₃(x, y) ≡ 0  ⇒  B_x ≡ 0, B_y ≡ 0
```

Магнітне поле під пластиною повністю відсутнє без будь-яких екранів чи магнітопроводів.

### Поле на робочому боці

Обчислимо компоненти магнітної індукції у верхньому півпросторі `y > 0`:

```
B_x(x, y) = -μ₀ · (∂Φ₁/∂x) = -μ₀ · k · A₁ · e^{-k·y} · cos(k · x)
B_y(x, y) = -μ₀ · (∂Φ₁/∂y) =  μ₀ · k · A₁ · e^{-k·y} · sin(k · x)
```

Підставляючи вираз для `A₁` та враховуючи залишкову індукцію матеріалу `B_r = μ₀ · M₀`:

```
B_x(x, y) = -B_r · (1 - e^{-k·d}) · e^{-k·y} · cos(k · x)
B_y(x, y) =  B_r · (1 - e^{-k·d}) · e^{-k·y} · sin(k · x)
```

Модуль результуючого вектора магнітної індукції `|B| = √(B_x² + B_y²)`:

```
|B(x, y)| = √[ B_r² · (1 - e^{-k·d})² · e^{-2ky} · (cos²(kx) + sin²(kx)) ]
|B(y)|    = B_r · (1 - e^{-k·d}) · e^{-k·y}
```

Модуль індукції на заданій висоті `y` над поверхнею є **строго постійним і не залежить від координати `x`**. Вектор індукції зберігає постійну амплітуду, плавно обертаючись у просторі.

### Дискретний масив Гальбаха з M сегментів на період

На практиці неперервний поворот намагніченості апроксимують `M` прямокутними магнітними сегментами на один просторовий період `λ`. Вектор намагніченості кожного наступного блоку повертається на дискретний кут `Δθ = 2π / M`.

Розглянемо просторовий розподіл намагніченості як східчасту функцію. Розкладемо компоненти `M_x(x)` та `M_y(x)` у просторовий ряд Фур'є за просторовими гармоніками `n`:

```
M_x(x) = ∑_{n=1}^∞ M_{x,n} · cos(n · k · x)
M_y(x) = ∑_{n=1}^∞ M_{y,n} · sin(n · k · x)
```

Для прямокутних сегментів шириною `w = λ / M` інтегрування за періодом дає амплітуду n-ї гармоніки:

```
M_{n} = M₀ · [sin(n · π / M) / (n · π / M)] · [2 / (n · π)] · sin(n · π / 2)
```

Для фундаментальної гармоніки (`n = 1`) коефіцієнт дискретизації (коефіцієнт форми / обмотки) дорівнює:

```
k_w(M) = sin(π / M) / (π / M)
```

Амплітуда фундаментальної просторової хвилі магнітної індукції на робочому боці:

```
B₁(y) = B_r · k_w(M) · (1 - e^{-k·d}) · e^{-k·y}
```

Порівняємо класичну систему чергування полюсів та масиви Гальбаха з різною кількістю сегментів на період:

1. **Звичайне чергування (N-S-N-S, M = 2, поворот на 180°):**
Кожен полюс займає половину просторового періоду. Магнітний потік ділиться порівну між верхнім і нижнім півпросторами:

```
k_w(2) = sin(π / 2) / (π / 2) = 1 / (π / 2) = 2 / π ≈ 0.6366
Амплітуда поля на один бік: B_звичайне = 0.5 · (2/π) · B_r = (1/π) · B_r ≈ 0.3183 · B_r
```

2. **Класичний 4-сегментний масив Гальбаха (M = 4, поворот на 90°: ↑ → ↓ ←):**

```
k_w(4) = sin(π / 4) / (π / 4) = (√2 / 2) / (π / 4) = 2√2 / π ≈ 0.9003
```

Оскільки весь потік спрямовано лише в один бік:

```
B_Halbach(4) = (2√2 / π) · B_r · (1 - e^{-k·d}) · e^{-k·y}
```

Відношення амплітуд фундаментального поля 4-сегментного масиву Гальбаха до звичайної двополюсної системи на робочому боці:

```
Boost = k_w(4) / k_w(2)               [відношення коефіцієнтів форми поля]
      = (2√2 / π) / (2 / π)           [підстановка значень для M = 4 та M = 2]
      = √2 ≈ 1.4142                   [скорочення спільного множника 2/π]
```

4-сегментний масив Гальбаха забезпечує зростання магнітної індукції на робочому боці рівно в **`√2 ≈ 1.414` раза** (+41.4%) порівняно зі звичайними чергованими магнітами однакового об'єму без залізного ярма.

3. **8-сегментний масив Гальбаха (M = 8, поворот на 45°):**

```
k_w(8) = sin(π / 8) / (π / 8) = sin(22.5°) / (0.3927) ≈ 0.3827 / 0.3927 ≈ 0.9745
```

8 сегментів на період дають **97.45%** від теоретичного максимуму неперервного ідеального масиву (`k_w = 1.0`).

### Спектральний склад і придушення вищих гармонік

Критичною перевагою дискретного масиву Гальбаха в електромеханіці є фільтрація просторових гармонік поля в повітряному зазорі.

Для класичного 4-сегментного масиву (`M = 4`) розклад у ряд Фур'є показує, що гармоніки з номерами `n = 2, 3, 4, 6, 7, 8` мають строго нульові коефіцієнти:

```
B_n = 0      [для всіх n ≠ 1 + 4·m, де m — ціле число]
```

Першими ненульовими вищими просторовими гармоніками є 5-та (`n = 5`) та 9-та (`n = 9`). Проте просторовий коефіцієнт згасання з віддаленням від поверхні на висоту `y` для n-ї гармоніки дорівнює `e^{-n · k · y}`:

```
Згасання 1-ї гармоніки: e^{-k · y}
Згасання 5-ї гармоніки: e^{-5 · k · y} = (e^{-k · y})⁵
```

Навіть при мінімальному повітряному зазорі `y = 0.1 · λ` (де `k · y = 2π · 0.1 ≈ 0.628`):

```
e^{-k·y}  = e^{-0.628} ≈ 0.533
e^{-5k·y} = e^{-3.14}  ≈ 0.043
```

Амплітуда 5-ї гармоніки слабшає у понад 12 разів сильніше за основну, а 9-ї — у понад 150 разів. Завдяки цьому магнітне поле в робочому зазорі стає практично чистим синусом без вищих просторових паразитних хвиль. Це повністю усуває пульсації магніторушійної сили та унеможливлює виникнення зубцевого моменту (*cogging torque*).

### Оптимальна товщина магніту та межа насичення

Залежність індукції від товщини магнітного шару `d` визначається множником насичення товщини:

```
η(d) = 1 - e^{-k · d} = 1 - e^{-2π · d / λ}
```

Проаналізуємо поведінку функції `η(d)` залежно від відношення товщини до періоду `d / λ`:

```
d = 0.1 · λ  ⇒  η = 1 - e^{-0.628} ≈ 0.466  (46.6% від максимуму)
d = 0.2 · λ  ⇒  η = 1 - e^{-1.257} ≈ 0.715  (71.5% від максимуму)
d = 0.35· λ  ⇒  η = 1 - e^{-2.20}  ≈ 0.889  (88.9% від максимуму)
d = 0.5 · λ  ⇒  η = 1 - e^{-3.14}  ≈ 0.957  (95.7% від максимуму)
d = 1.0 · λ  ⇒  η = 1 - e^{-6.28}  ≈ 0.998  (99.8% від максимуму)
```

Збільшення товщини понад `d = 0.35 · λ … 0.5 · λ` дає менше 4–5% приросту магнітного поля, але подвоює масу та вартість рідкісноземельних магнітів. Тому в інженерній практиці оптимальною вважається товщина магнітів:

```
d_{opt} ≈ λ / (2π) … λ / 4
```

### Сили взаємодії та тензор напружень Максвелла

Сила магнітної взаємодії між масивом Гальбаха та провідним екраном або феромагнетиком розраховується через інтегрування **тензора напружень Максвелла** (*Maxwell stress tensor*) `T_{ij}` по замкненій поверхні `S`, що охоплює масив:

```
T_{xx} = (1 / 2μ₀) · (B_x² - B_y²)
T_{yy} = (1 / 2μ₀) · (B_y² - B_x²)
T_{xy} = (1 / μ₀) · B_x · B_y
```

Підйомна сила (нормальний тиск) на одиницю площі `F_y / S`:

```
P_y = (1 / S) ∫ T_{yy} dS = (1 / 4μ₀) · B₀² · e^{-2ky}
```

де `B₀ = B_r · k_w · (1 - e^{-kd})` — амплітуда поля на поверхні масиву.

Оскільки магнітна енергія пропорційна квадрату індукції `B²`, збільшення індукції у `√2` раза за рахунок масиву Гальбаха призводить до **подвоєння питомої сили притягання/відштовхування**:

```
P_{Halbach} / P_{звичайне} = (√2)² = 2.00
```

Масив Гальбаха створює у **2 рази більшу питому силу** на одиницю площі, ніж звичайне чергування полюсів без ярма.

### Циліндричний масив Гальбаха

Для циліндричного кільця з внутрішнім радіусом `R_{in}` та зовнішнім радіусом `R_{out}`, що містить `p` пар полюсів, просторовий розподіл вектора намагніченості в циліндричних координатах `(r, θ)` задається кутом орієнтації `γ(θ)` вектора `M` відносно радіального напрямку:

```
γ(θ) = (1 ± p) · θ
```

Знак `+` концентрує поле у внутрішньому отворі циліндра (зовні поле `B = 0`), а знак `-` — на зовнішній поверхні (всередині отвору `B = 0`).

Розв'язання рівняння Лапласа в циліндричних координатах для внутрішнього поля циліндричного диполя (`p = 1`, однорідне поперечне поле всередині отвору) дає точний аналітичний інтеграл:

```
B_внутр = B_r · ln(R_{out} / R_{in})      [для ідеального диполя Гальбаха]
```

Для мультипольних систем (`p > 1`, квадруполі прискорювачів та ротори багатополюсних BLDC двигунів):

```
B_внутр(r) = B_r · [p / (p - 1)] · [1 - (R_{in} / R_{out})^{p - 1}] · (r / R_{in})^{p - 1}
```

Фактор `ln(R_{out} / R_{in})` показує, що у дипольному циліндрі Гальбаха магнітна індукція в центрі може перевищувати залишкову намагніченість самого матеріалу `B_r` (наприклад, при `R_{out} / R_{in} > e ≈ 2.718` індукція `B > B_r`), що принципово неможливо отримати у звичайних магнітних системах без концентраторів.

### Електродинамічна левітація Inductrack: виведення сил

Коли лінійний масив Гальбаха рухається зі швидкістю `v` над пасивною провідною колією (наприклад, смугою з поперечними замкненими витками індуктивністю `L` та активним опором `R`), змінне магнітне поле наводить у колії індукційні струми за [законом Фарадея](book:electronics/faraday-law).

Магнітний потік, що пронизує контур колії в точці `x = v · t`:

```
Ф(t) = Ф₀ · cos(k · v · t) = Ф₀ · cos(ω · t)
```

де кутова частота зміни поля `ω = k · v = 2π · v / λ`.

Електрорушійна сила індукції в контурі:

```
E(t) = -dФ/dt = ω · Ф₀ · sin(ω · t)
```

Диференціальне рівняння для струму `I(t)` у замкненому контурі з опором `R` та індуктивністю `L`:

```
L · (dI/dt) + R · I = E(t) = ω · Ф₀ · sin(ω · t)
```

В усталеному режимі струм має амплітуду `I₀` та фазовий зсув `δ`:

```
I(t) = I₀ · sin(ω · t - δ)
I₀   = (ω · Ф₀) / √(R² + ω² · L²)
tan(δ) = (ω · L) / R
```

Сила взаємодії рухомого масиву з індукованими струмами розкладається на дві ортогональні складові: вертикальну **підйомну силу** `F_{lift}` та горизонтальну **силу магнітного гальмування** (опору руху) `F_{drag}`:

```
F_{lift}(v) = F_max · [ v² / (v² + v_c²) ]
F_{drag}(v) = F_max · [ (v · v_c) / (v² + v_c²) ]
```

де `v_c` — **критична швидкість переходу** (*transition velocity*):

```
v_c = R / (k · L) = (R · λ) / (2π · L)
```

а `F_max` — асимптотична гранична підйомна сила при `v → ∞`:

```
F_max = (B₀² · w · l) / (4 · k · L)
```

Проаналізуємо фізичну поведінку сил у двох граничних режимах:

1. **Низька швидкість (`v ≪ v_c`, резистивний режим):**
Індуктивний опір малий порівняно з активним (`ωL ≪ R`), фазовий зсув `δ ≈ 0`. Струм збігається за фазою з ЕРС, створюючи переважно дисипативне гальмування:

```
F_{lift} ∝ v²      [підйомна сила надзвичайно мала]
F_{drag} ∝ v       [гальмування лінійно росте зі швидкістю]
```

2. **Висока швидкість (`v ≫ v_c`, індуктивний режим):**
Індуктивний опір домінує (`ωL ≫ R`), фазовий зсув наближається до 90° (`δ → π/2`). Струм відстає від ЕРС на чверть періоду й стає строго протифазним до магнітного поля масиву, створюючи потужне діамагнітне відштовхування:

```
F_{lift} → F_max   [підйомна сила виходить на постійне плато]
F_{drag} ∝ 1 / v   [магнітний опір спадає обернено пропорційно швидкості]
```

Відношення підйомної сили до сили опору (аеродинамічно-магнітна якість левітації `L/D`):

```
F_{lift} / F_{drag} = v / v_c
```

На високих швидкостях (наприклад, `v = 10 · v_c`) підйомна сила у 10 разів перевищує магнітний опір, забезпечуючи високу енергетичну ефективність левітації. Завдяки високій індукції масиву Гальбаха критична швидкість `v_c` становить лише 10–15 км/год, що дає змогу поїзду підніматися у повітря вже на початку руху.

### Скінченні масиви: крайовий ефект

У реальних інженерних вузлах масив Гальбаха має скінченну довжину `L_{arr} = N · λ`. На лівому та правому кінцях масиву ідеальна симетрія порушується, що спричиняє крайове розсіювання магнітного потоку.

На крайніх магнітних блоках виникає нескомпенсований магнітний заряд, через що на слабкому боці біля торців з'являється локальне поле розсіювання:

```
B_{edge}(x) ≈ B_r · (d / λ) · e^{-k · |x - x_{край}|}
```

Щоб звести крайові збурення до нуля, в прецизійних ондуляторах та роторах застосовують спеціальне закінчення масиву: крайні магніти виконують зменшеної ширини (половинний сегмент `w / 2`) або зі скошеним кутом намагніченості під 45°, що повністю відновлює симетрію замикання потоку всередині структури.

### Метод магнітних зарядів для довільного прямокутного блоку

Для точного чисельного моделювання дискретних масивів кожен магнітний прямокутний блок розміром `[-w/2, w/2] × [-d, 0]` з вектором залишкової намагніченості `M = (M_x, M_y)` представляють еквівалентними поверхневими магнітними зарядами на чотирьох бічних гранях:

```
Верхня грань (y = 0, x ∈ [-w/2, w/2]):    σ_m = +M_y
Нижня грань  (y = -d, x ∈ [-w/2, w/2]):   σ_m = -M_y
Права грань  (x = +w/2, y ∈ [-d, 0]):     σ_m = +M_x
Ліва грань   (x = -w/2, y ∈ [-d, 0]):     σ_m = -M_x
```

Магнітне поле в довільній точці простору `(x, y)` обчислюється аналітичним інтегруванням закону Біо-Савара-Лапласа для кожної зарядженої смуги:

```
B_x(x, y) = (μ₀ / 2π) · [ +M_y · (ln(r₁) - ln(r₂)) - M_y · (ln(r₄) - ln(r₃))
                         + M_x · (θ₂ - θ₁)         - M_x · (θ₃ - θ₄) ]

B_y(x, y) = (μ₀ / 2π) · [ +M_y · (θ₂ - θ₁)         - M_y · (θ₃ - θ₄)
                         - M_x · (ln(r₁) - ln(r₂)) + M_x · (ln(r₄) - ln(r₃)) ]
```

де `r_i = √((x - x_i)² + (y - y_i)²)` — евклідові відстані від точки спостереження до чотирьох вершин прямокутного блоку, а `θ_i = atan2(y - y_i, x - x_i)` — відповідні полярні кути.

Цей замкнений аналітичний вираз не містить сингулярностей за межами тіла магніту й дозволяє точно розрахувати просторовий розподіл поля від довільного ансамблю дискретних сегментів Гальбаха простим підсумовуванням внесків усіх блоків.

### Механічні сили між сусідніми сегментами при складанні

Під час механічного складання масиву Гальбаха виникає серйозний інженерний бар'єр: поперечні магніти (спрямовані горизонтально, `→` або `←`) зазнають гігантської сили виштовхування з боку сусідніх вертикальних магнітів (`↑` та `↓`).

Оцінимо бічну силу зсуву та силу виштовхування, що діє на один горизонтальний блок шириною `w`, висотою `d` та глибиною `l`:

```
F_{repulsion} = ∫ (M · ∇) B dV ≈ (B_r² · d · l) / (2 · μ₀)
```

Для неодимового блоку марки N52 (`B_r = 1.45 Тл`) з поперечним перерізом `d = 10 мм`, `l = 50 мм`:

```
B_r² / (2μ₀) = (1.45)² / (2 × 4π × 10⁻⁷) ≈ 2.1025 / (2.513 × 10⁻⁶) ≈ 8.36 × 10⁵ Па (Н/м²)
Площа полюса: S = d · l = 0.01 м × 0.05 м = 0.0005 м²
Сила виштовхування: F = 8.36 × 10⁵ Па × 0.0005 м² ≈ 418 Н  (еквівалент вантажу ≈ 42.6 кг!)
```

Кожен маленький сантиметровий магніт прагне вискочити зі свого посадкового гнізда із силою у понад 40 кілограм-сил. Це вимагає обов'язкового використання спеціальних прецизійних складальних кондукторів, термореактивних епоксидних компаундів та зовнішніх силових бандажів із вуглецевого волокна або титану.

### Числовий розрахунок реального вузла BLDC ротора

Розглянемо практичний інженерний розрахунок магнітного поля для ротора безколекторного двигуна дрона.

**Вихідні параметри:**
- Матеріал магнітів: Неодим NdFeB марки N52 (`B_r = 1.45 Тл`).
- Просторова довжина періоду: `λ = 24 мм` (`k = 2π / 0.024 ≈ 261.8 рад/м`).
- Товщина магнітів: `d = 4 мм`.
- Кількість сегментів на період: `M = 4` (поворот на 90°).
- Робочий повітряний зазор: `y = 1.0 мм`.

**Покроковий розрахунок:**

```
1. Коефіцієнт дискретизації:
   k_w = sin(π / 4) / (π / 4) = (0.7071) / (0.7854) ≈ 0.9003

2. Множник товщини магніту:
   k · d = 261.8 рад/м × 0.004 м = 1.047 рад
   1 - e^{-k·d} = 1 - e^{-1.047} = 1 - 0.351 = 0.649

3. Множник згасання в повітряному зазорі:
   k · y = 261.8 рад/м × 0.001 м = 0.2618 рад
   e^{-k·y} = e^{-0.2618} ≈ 0.770

4. Амплітуда індукції на поверхні статора:
   B₁ = B_r · k_w · (1 - e^{-k·d}) · e^{-k·y}
      = 1.45 Тл × 0.9003 × 0.649 × 0.770
      ≈ 0.653 Тл

5. Порівняння зі звичайним ротором без ярма:
   B_{conv} = B₁ / √2 = 0.653 / 1.414 ≈ 0.462 Тл
   Приріст індукції: ΔB = +0.191 Тл (+41.4%)
   Приріст питомого крутного моменту (пропорційний B₁): +41.4%
   Приріст питомої сили взаємодії (пропорційний B₁²): +100.0% (у 2.00 раза)
```

Цей числовий розрахунок наочно демонструє, чому масив Гальбаха є безальтернативним рішенням для високомоментних електродвигунів з обмеженими габаритами й масою.
