# 🧮 Перенесення похибок у резистивних колах

Коли в аналогову схему встановлюють компоненти з випадковим виробничим розкидом, вихідні напруги, струми та коефіцієнти підсилення відхиляються від ідеальних розрахункових значень. Математичний апарат теорії чутливості та теорії ймовірностей дає змогу точно розрахувати як детерміновані екстремальні межі похибки (найгірший випадок), так і статистичний розподіл вихідної величини для масового серійного виробництва.

---

### Математичний апарат: розклад у ряд Тейлора та чутливість за Боде

Нехай деяка вихідна характеристика схеми `y` (наприклад, вихідна напруга `V_out`, коефіцієнт передачі `K` або струм `I`) є диференційовною функцією `k` незалежних параметрів компонентів:

```
y = f(R₁, R₂, ..., Rₖ)
```

При малих відхиленнях опорів `ΔRᵢ` від їхніх номінальних значень `Rᵢ₀` функцію розкладають у багатовимірний ряд Тейлора в околі точки номінального режиму:

```
f(R₁₀ + ΔR₁, ..., Rₖ₀ + ΔRₖ)
= f(R₁₀, ..., Rₖ₀) + ∑ [ (∂f / ∂Rᵢ) · ΔRᵢ ] + (1/2) · ∑ ∑ [ (∂²f / ∂Rᵢ∂Rⱼ) · ΔRᵢ·ΔRⱼ ] + ...
```

Для більшості лінійних та слабконелінійних кіл членами другого і вищих порядків нехтують через малість відносних похибок (`|ΔRᵢ / Rᵢ₀| ≪ 1`). Тоді абсолютне відхилення вихідної величини описується лінійною формою:

```
Δy ≈ ∑ [ (∂f / ∂Rᵢ) · ΔRᵢ ]
```

Щоб перейти від абсолютних одиниць (оми, вольти) до зручних безрозмірних відсотків або часток на мільйон (ppm), запроваджують **логарифмічну чутливість за Боде** (англ. *normalized Bode sensitivity*):

```
S(y, Rᵢ) = lim [ (Δy / y₀) / (ΔRᵢ / Rᵢ₀) ]
         = (Rᵢ₀ / y₀) · (∂f / ∂Rᵢ)
         = ∂(ln y) / ∂(ln Rᵢ)
```

Коефіцієнт чутливості `S(y, Rᵢ)` показує, на скільки відсотків зміниться вихідна величина `y`, якщо опір резистора `Rᵢ` зросте на 1 %. За допомогою цих коефіцієнтів відносна похибка схеми записується як зважена сума відносних відхилень усіх резисторів:

```
Δy / y₀ = ∑ [ S(y, Rᵢ) · (ΔRᵢ / Rᵢ₀) ]
```

### Резистивний дільник напруги: ненавантажений та навантажений

#### 1. Ідеальний дільник без навантаження

Розглянемо базовий дільник із двох резисторів `R₁` (верхнє плече) та `R₂` (нижнє плече). Його коефіцієнт передачі:

```
K = V_out / V_in = R₂ / (R₁ + R₂)
```

Знайдемо частинні похідні функції `K(R₁, R₂)` за обома змінними:

```
∂K/∂R₁ = −R₂ / (R₁ + R₂)²
       = −K / (R₁ + R₂)               [використано вираз K = R₂/(R₁+R₂)]

∂K/∂R₂ = (1·(R₁ + R₂) − R₂·1) / (R₁ + R₂)²   [похідна частки за змінною R₂]
       = R₁ / (R₁ + R₂)²              [розкрито дужки у чисельнику]
       = (1 − K) / (R₁ + R₂)          [використано 1−K = R₁/(R₁+R₂)]
```

Обчислимо безрозмірні коефіцієнти чутливості за Боде:

```
S(K, R₁) = (R₁ / K) · (∂K / ∂R₁)
         = (R₁ / K) · (−R₂ / (R₁ + R₂)²)
         = −(R₁ · R₂) / (K · (R₁ + R₂)²)   [об'єднано дроби]
         = −R₁ / (R₁ + R₂)                 [підставлено K = R₂/(R₁+R₂)]
         = −(1 − K)                        [використано 1−K = R₁/(R₁+R₂)]

S(K, R₂) = (R₂ / K) · (∂K / ∂R₂)
         = (R₂ / K) · (R₁ / (R₁ + R₂)²)
         = (R₂ · R₁) / (K · (R₁ + R₂)²)    [об'єднано дроби]
         = R₁ / (R₁ + R₂)                  [скорочено спільні множники]
         = +(1 − K)                        [використано 1−K = R₁/(R₁+R₂)]
```

Підставивши знайдені чутливості у формулу похибки, отримуємо фундаментальне рівняння дільника:

```
ΔV_out / V_out = (1 − K) · [ (ΔR₂ / R₂) − (ΔR₁ / R₁) ]
```

Звідси очевидні два наслідки:
1. **Синфазне відхилення (TCR Tracking):** Якщо обидва резистори змінили опір на однаковий відсоток (`ΔR₁/R₁ = ΔR₂/R₂ = δ`), вихідна напруга дільника взагалі не змінюється: `(1 − K) · (δ − δ) = 0`.
2. **Найгірший випадок (Worst-Case):** Максимальна похибка досягається при протилежних знаках відхилень `ΔR₁/R₁ = −tol` та `ΔR₂/R₂ = +tol`:

```
|ΔV_out / V_out|_max = 2 · (1 − K) · tol
```

Для дільника навпіл (`R₁ = R₂`, де `K = 0.5`): `|ΔV_out / V_out|_max = 2 · (1 − 0.5) · tol = tol`.

#### 2. Дільник з урахуванням опору навантаження

Якщо паралельно нижньому плечу `R₂` підключено вхідний опір вимірювача `R_L`, еквівалентний опір нижньої ланки становить `R_eq = (R₂ · R_L) / (R₂ + R_L)`. Тоді коефіцієнт передачі набуває вигляду:

```
K_L = R_eq / (R₁ + R_eq) = (R₂ · R_L) / (R₁·R₂ + R₁·R_L + R₂·R_L)
```

Чутливість до опору навантаження `R_L`:

```
S(K_L, R_L) = (R_L / K_L) · (∂K_L / ∂R_L)
            = R₁·R₂ / (R₁·R₂ + R₁·R_L + R₂·R_L)       [диференціювання частки та скорочення K_L]
            = (1 − K_L) · (R₂ / (R₂ + R_L))           [виділено множник (1 − K_L)]
```

Якщо вхідний опір вимірювача `R_L` має власний технологічний розкид (наприклад, вхідний опір АЦП коливається в межах ±20 %), цей розкид проникає у вихідну напругу дільника пропорційно відношенню `R₂ / R_L`.

### Диференціальний підсилювач та придушення синфазного сигналу (CMRR)

Класична схема 4-резисторного диференціального підсилювача на операційному підсилювачі (ОП) містить два дільники: дільник `R₁–R₂` на неінвертуючому вході та коло зворотного зв'язку `R₃–R₄` на інвертуючому вході.

Вихідна напруга схеми через два вхідні сигнали `V₁` та `V₂`:

```
V_out = V₂ · [ (R₄ / (R₃ + R₄)) · ((R₁ + R₂) / R₁) ] − V₁ · (R₂ / R₁)
```

При ідеальному узгодженні опорів `R₁ = R₃` та `R₂ = R₄` схема віднімає синфазну напругу `V_cm = (V₁ + V₂) / 2` та підсилює лише диференціальний сигнал `V_diff = V₂ − V₁` з коефіцієнтом `A_d = R₂ / R₁`.

Нехай резистори мають малий технологічний розкид `Rᵢ = Rᵢ₀ · (1 + δᵢ)`, де `δᵢ` — відносне відхилення. Тоді коефіцієнт передачі для синфазного сигналу `A_cm = V_out / V_cm` стає ненульовим:

```
A_cm ≈ (R₂ / R₁) · (δ₁ − δ₂ + δ₄ − δ₃)
```

Коефіцієнт придушення синфазного сигналу (CMRR — *Common-Mode Rejection Ratio*):

```
CMRR = |A_d / A_cm| ≈ 1 / |δ₁ − δ₂ + δ₄ − δ₃|
```

У найгіршому випадку чотирьох резисторів із допуском `±tol`:

```
CMRR_min ≈ 1 / (4 · tol)
```

Переведемо це значення у децибели (`CMRR_дБ = 20 · log₁₀(CMRR)`):

1. **Резистори 1 % (`tol = 0.01`):** `CMRR ≈ 1 / (4 · 0.01) = 25` (лише **28 дБ**!). Синфазна напруга 10 В створить на виході паразитний сигнал 400 мВ.
2. **Резистори 0.1 % (`tol = 0.001`):** `CMRR ≈ 1 / (4 · 0.001) = 250` (**48 дБ**).
3. **Узгоджена матриця 0.01 % (`tol = 0.0001`):** `CMRR ≈ 1 / (4 · 0.0001) = 2500` (**68 дБ**).

Це математично доводить: жоден дорогий операційний підсилювач із паспортним власним CMRR > 120 дБ не зможе придушити синфазну заваду, якщо зовнішні резистори мають розкид 1 % або 0.1 %.

### Міст Вітстона: похибка нуля та лінійність

У мості Вітстона з чотирма плечима `R₁, R₂, R₃, R₄`, що живиться напругою `V_in`, вихідна напруга знімається між виводами двох паралельних дільників:

```
V_out = V_in · [ (R₂ / (R₁ + R₂)) − (R₄ / (R₃ + R₄)) ]
```

Нехай кожне плече містить номінальний опір `R₀` та відносне відхилення `δᵢ`:

```
R₁ = R₀ · (1 + δ₁)
R₂ = R₀ · (1 + δ₂)
R₃ = R₀ · (1 + δ₃)
R₄ = R₀ · (1 + δ₄)
```

Підставимо ці вирази у формулу моста та розкладемо в ряд за малими параметрами `δᵢ`:

```
R₂ / (R₁ + R₂) = [ R₀(1 + δ₂) ] / [ R₀(2 + δ₁ + δ₂) ]
               = (1 + δ₂) / [ 2 · (1 + 0.5·(δ₁ + δ₂)) ]       [винесено множник 2R₀]
               ≈ 0.5 · (1 + δ₂) · (1 − 0.5·(δ₁ + δ₂))         [розклад 1/(1+x) ≈ 1−x]
               ≈ 0.5 · [ 1 + 0.5·(δ₂ − δ₁) ]                  [відкинуто члени другого порядку]
```

Аналогічно для другого плеча:

```
R₄ / (R₃ + R₄) ≈ 0.5 · [ 1 + 0.5·(δ₄ − δ₃) ]                  [за аналогією для R3, R4]
```

Віднімаючи другий дріб від першого, отримуємо лінеаризовану напругу паразитної несиметрії (зсуву нуля) моста:

```
V_offset = V_in · [ 0.5·(1 + 0.5·(δ₂ − δ₁)) − 0.5·(1 + 0.5·(δ₄ − δ₃)) ]
         = (V_in / 4) · (δ₂ − δ₁ − δ₄ + δ₃)                   [зведено подібні доданки]
```

Максимальна напруга зсуву нуля в найгіршому випадку:

```
V_offset_max = (V_in / 4) · ( |tol| + |−tol| + |−tol| + |tol| )
             = V_in · tol
```

Для моста з живленням 5.0 В на дискретних резисторах з допуском 0.1 % (`tol = 0.001`):

```
V_offset_max = 5.0 В · 0.001 = 5.0 мВ
```

Якщо тензометричний датчик тиску генерує повний діапазон сигналу лише 10 мВ при максимальному зусиллі, початковий розкид номіналів дискретних резисторів забирає **половину динамічного діапазону вимірювального тракту**.

### Статистичний розрахунок за методом RSS та коваріація параметрів

Якщо похибки компонентів є випадковими величинами з відомими дисперсіями `σ²(Rᵢ)`, загальна дисперсія вихідної величини розраховується через матрицю коваріацій:

```
σ²_total = ∑ [ (∂f / ∂Rᵢ)² · σ²(Rᵢ) ] + 2 · ∑∑ [ (∂f / ∂Rᵢ) · (∂f / ∂Rⱼ) · cov(Rᵢ, Rⱼ) ]
```

де `cov(Rᵢ, Rⱼ) = ρᵢⱼ · σ(Rᵢ) · σ(Rⱼ)`, а `ρᵢⱼ` — коефіцієнт лінійної кореляції між опорами.

Розглянемо два випадки для дільника з двох резисторів:

1. **Дискретні незалежні резистори (`ρ = 0`):**
Коваріація дорівнює нулю. Загальна середньоквадратична похибка виходу дільника (`K = 0.5`):

```
σ_rel(V_out) = √[ S²(K, R₁)·σ²_R + S²(K, R₂)·σ²_R ]
             = √[ (−0.5)²·σ²_R + (0.5)²·σ²_R ]
             = √[ 0.25·σ²_R + 0.25·σ²_R ]
             = √[ 0.50·σ²_R ]
             = σ_R / √2 ≈ 0.707 · σ_R
```

2. **Інтегральна резистивна матриця з позитивною кореляцією дрейфу (`ρ → +1`):**
Обидва резистори виготовлені на одному кристалі й зазнають однакового температурного нагріву. Їхні відносні дисперсії однакові, а коефіцієнт кореляції `ρ ≈ 0.99`:

```
σ²_rel(V_out) = S²₁·σ²_R + S²₂·σ²_R + 2·S₁·S₂·ρ·σ²_R
              = 0.25·σ²_R + 0.25·σ²_R + 2·(−0.5)·(0.5)·(0.99)·σ²_R   [підставлено S1=-0.5, S2=0.5]
              = 0.50·σ²_R − 0.495·σ²_R                                [перемножено доданки]
              = 0.005·σ²_R                                            [знайдено різницю]
```

Звідси результуюче середньоквадратичне відхилення:

```
σ_rel(V_out) = √(0.005) · σ_R ≈ 0.071 · σ_R
```

Статистична похибка дільника на узгодженій інтегральній матриці **в 14 разів менша**, ніж на окремих некорельованих дискретних резисторах із тими самими індивідуальними допусками.
