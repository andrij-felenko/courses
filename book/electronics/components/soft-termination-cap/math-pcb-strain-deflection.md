# 🧮 Механіка деформації плати та зсувні напруження у виводах MLCC

Розрахунок механічної міцності пасивних компонентів під час складання та експлуатації вимагає точного математичного зв'язку між макроскопічним прогином друкованої плати, поверхневою відносною деформацією текстоліту та напруженнями, що передаються крізь паяне з'єднання на керамічне тіло конденсатора.

Стандарти автомобільної надійності (AEC-Q200-005, IPC/JEDEC-9704, IEC 60384-1) регламентують випробування на триточковий та чотириточковий вигин підкладки (англ. *Substrate Bending Test*). Математична модель пружної балки у поєднанні з теорією зсувного лагу (Shear-Lag Model) та лінійною механікою руйнування Гріффітса — Ірвіна дозволяє аналітично визначити поріг руйнування стандартного MLCC та кількісно обґрунтувати захисну дію еластичного прошарку Soft-Termination.

## 1. Геометрія прогину та поверхнева деформація друкованої плати

Розглянемо друковану плату товщиною `t` як пружну балку довжиною `L_total`, встановлену на дві циліндричні опори з відстанню між ними `L`. Посередині прольоту прикладається навантаження пуансоном, що викликає стрілу прогину `h`.

```
                    Пуансон (F, прогин h)
                            │
                            ▼
          ┌─────────────────▼─────────────────┐   ▲
          │       Конденсатор (розтяг σ)      │   │  Товщина плати t
    ──────┴─────────────────┬─────────────────┴───▼──────
    ▲                       │                       ▲
    │                       │                       │
   Опора 1                  │                      Опора 2
   (x = 0)                  │                      (x = L)
    ◄───────────────────────┴──────────────────────►
                         Проліт L
```

Згідно з класичною теорією вигину тонких пружних балок Ейлера — Бернуллі, рівняння вигнутої серединної лінії балки `w(x)` для симетричного навантаження посередині прольоту `x ∈ [0, L/2]` має вигляд:

```
w(x) = (F / (48 · E_pcb · I)) · (3·L²·x - 4·x³)
```

де:
- `F` — прикладена сила натискання пуансона;
- `E_pcb` — модуль пружності матеріалу плати (для склотекстоліту FR-4 вздовж осі основи `E_pcb ≈ 18...22 ГПа`);
- `I = b · t³ / 12` — осьовий момент інерції прямокутного поперечного перерізу плати шириною `b` і товщиною `t`.

Максимальний прогин `h` досягається в центрі прольоту при `x = L/2`:

```
h = w(L/2)
= (F / (48 · E_pcb · I)) · (3·L²·(L/2) - 4·(L/2)³)    [підстановка x = L/2]
= (F / (48 · E_pcb · I)) · (1.5·L³ - 0.5·L³)          [розкриття степенів]
= F · L³ / (48 · E_pcb · I)                           [зведення подібних]
```

Звідси сила натискання виражається через заданий прогин `h`:

```
F = 48 · E_pcb · I · h / L³                           [вираження сили F через прогин h]
```

### Виведення формули поверхневої деформації

Згинальний момент у центрі прольоту `M_max` для балки на двох опорах становить:

```
M_max = F · L / 4                                      [правило важеля для зосередженої сили]
= (48 · E_pcb · I · h / L³) · (L / 4)                  [підстановка сили F]
= 12 · E_pcb · I · h / L²                              [скорочення коефіцієнтів і довжини L]
```

Кривина балки `κ = 1 / R` у центральній точці пов'язана зі згинальним моментом класичним співвідношенням теорії пружності:

```
κ = 1 / R
= M_max / (E_pcb · I)                                  [диференціальне рівняння осі балки]
= (12 · E_pcb · I · h / L²) / (E_pcb · I)              [підстановка виразу M_max]
= 12 · h / L²                                          [скорочення жорсткості E_pcb · I]
```

Відносна лінійна деформація `ε` шару балки на відстані `y` від нейтральної площини виражається через кривину:

```
ε(y) = y / R = y · κ                                   [геометричне визначення деформації волокна]
```

Для зовнішньої поверхні плати, де встановлений конденсатор, відстань від нейтрального шару дорівнює половині товщини плати `y = t / 2`. Підставляючи `y = t / 2` та радіус кривини `R`, отримуємо формулу поверхневої відносної деформації плати:

```
ε_поверхні = (t / 2) · κ                               [деформація на зовнішньому волокні]
= (t / 2) · (12 · h / L²)                              [підстановка виразу кривини κ]
= 6 · t · h / L²                                       [скорочення коефіцієнтів]
```

У мікроелектроніці деформацію виражають у безрозмірних **мікродеформаціях** (мікрострейн, англ. *microstrain*, позначення `με` або `ppm`, де `1 με = 10⁻⁶ = 0.0001%`):

```
ε [με] = (6 · t · h / L²) · 10⁶                        [переведення у мікродеформації]
```

### Порівняння триточкового та чотириточкового вигину

Стандарт IPC/JEDEC-9704 регламентує також схему чотириточкового вигину, де навантаження прикладається двома симетричними пуансонами на відстані `a` від крайніх опор.

У чотириточковій схемі між внутрішніми пуансонами виникає зона чистого вигину з постійним згинальним моментом `M = F · a / 2` та нульовою перерізуючою силою. У цій зоні кривина балки є строго сталою:

```
ε_4point = 3 · t · h / (a · (3·L - 4·a))              [для 4-точкової схеми навантаження]
```

Триточкова схема за стандартом AEC-Q200-005 створює пікову деформацію безпосередньо під центральним пуансоном, що імітує найжорсткіший випадок локального перекосу плати біля кріпильного гвинта або лінії скрайбування.

## 2. Модель зсувного лагу (Shear-Lag) у багатошаровому контакті

Для визначення того, яка частка деформації плати передається в керамічне тіло конденсатора, застосовується модель зсувного лагу Волькерсена — Кокса.

Розглянемо вузол «друкована плата — припій — металізація виводу — керамічне тіло». Довжина компонента дорівнює `L_c`, ширина — `W_c`, висота — `H_c`. Позначимо координату вздовж поздовжньої осі конденсатора як `x ∈ [-L_c/2, +L_c/2]`, де `x = 0` відповідає центру симетрії деталі.

```
       ┌──────────────────────────────────────────┐
       │   Керамічне тіло MLCC (E_c, A_c)         │
       ├───────────────┬──────────┬───────────────┤
       │ Шар Ag-епоксиду (G_p, t_p)               │
       ├───────────────┼──────────┼───────────────┤
       │ Паяний шов SAC305 (G_s, t_s)             │
       ├───────────────┴──────────┴───────────────┤
       │ Друкована плата FR-4 (E_b, деформація ε_b)│
       └──────────────────────────────────────────┘
```

Рівновага елементарного відрізка керамічного тіла довжиною `dx` описується диференціальним рівнянням:

```
dσ_c(x) / dx = τ(x) / H_c                             [баланс сил між розтягом і зсувом]
```

де `σ_c(x)` — нормальне розтягувальне напруження в кераміці, а `τ(x)` — дотичне зсувне напруження на контактній поверхні.

Зсувне напруження у проміжному шарі пропорційне різниці горизонтальних зміщень плати `u_b(x)` та кераміки `u_c(x)`:

```
τ(x) = K_shear · (u_b(x) - u_c(x))                    [закон Гука для зсувного інтерфейсу]
```

Ефективна зсувна піддатливість `1 / K_shear` визначається послідовним з'єднанням шару припою товщиною `t_s` та полімерного шару Soft-Termination товщиною `t_p`:

```
1 / K_shear = (t_s / G_s) + (t_p / G_p)               [додавання зсувних піддатливостей]
```

де `G_s ≈ 16 ГПа` — модуль зсуву припою SAC305, а `G_p ≈ 1.1 ГПа` — модуль зсуву сріблонаповненого епоксидного полімеру.

Диференціюючи рівняння зсуву двічі по координаті `x`, отримуємо класичне хвильове рівняння розподілу напружень:

```
d²σ_c(x) / dx² - β² · σ_c(x) = -β² · E_c · ε_b        [диференціальне рівняння зсувного лагу]
```

де характеристичний параметр зсувного згасання `β` визначається виразом:

```
β = √( K_shear / (E_c · H_c) )                        [характеристичний коефіцієнт згасання]
```

Розв'язок цього рівняння з граничними умовами відсутності напружень на вільних торцях кераміки `σ_c(±L_c/2) = 0` має вигляд:

```
σ_c(x) = E_c · ε_b · (1 - cosh(β · x) / cosh(β · L_c / 2))  [розподіл розтягувального напруження]
```

Зсувне напруження на межі контакту розподіляється вздовж довжини за гіперболічним синусом:

```
τ(x) = E_c · ε_b · H_c · β · (sinh(β · x) / cosh(β · L_c / 2)) [розподіл зсувного напруження]
```

Максимальне зсувне напруження `τ_max` досягається на зовнішньому краю контакту при `x = L_c / 2`:

```
τ_max = E_c · ε_b · H_c · β · tanh(β · L_c / 2)       [пікове зсувне напруження на торці]
```

### Фізичний зміст параметрів для стандартного та Soft-Termination виводу

1. **Для стандартного конденсатора (без полімеру, `t_p = 0`):**
   Жорсткість контакту визначається виключно припоєм: `K_shear = G_s / t_s ≈ 16 ГПа / 50 мкм = 3.2 × 10¹¹ Па/м`.
   Параметр `β_std` є дуже великим (`β_std ≈ 1500...2000 м⁻¹`), тому `tanh(β · L_c / 2) ≈ 1`. Зсувні напруження різко концентруються на вузькій смузі шириною менше 0.1 мм біля краю галтелі, викликаючи гігантський пік `τ_max`, що перевищує межу сколювання кераміки.

2. **Для конденсатора з Soft-Termination (`t_p = 20 мкм`, `G_p = 1.1 ГПа`):**
   Полімерний шар різко збільшує піддатливість: `1 / K_shear = (50 × 10⁻⁶ / 16 × 10⁹) + (20 × 10⁻⁶ / 1.1 × 10⁹) ≈ 3.1 × 10⁻¹² + 18.2 × 10⁻¹² = 2.13 × 10⁻¹¹ м/Па`.
   Жорсткість падає майже у 7 разів: `K_shear ≈ 4.7 × 10¹⁰ Па/м`.
   Параметр `β_soft` знижується до `500...700 м⁻¹`. Зсувні напруження «розмазуються» по всій площі контакту, а пікове напруження `τ_max` падає у 3.5–4.5 раза, унеможливлюючи зародження тріщини.

## 3. Геометрія галтелі припою та коефіцієнт концентрації напружень K_t

Кут змочування та висота галтелі припою `h_f` формують геометричний надріз (концентратор напружень) у точці сполучення керамічного тіла з металізацією.

За формулою Петерсона для клиноподібного виступу коефіцієнт концентрації напружень `K_t` виражається через кут галтелі припою `θ` та радіус перехідного мікроскруглення `r_fillet`:

```
K_t = 1 + C_geom · √( (h_f / r_fillet) · sin(θ) )      [коефіцієнт концентрації Петерсона]
```

де:
- `θ` — кут нахилу меніска припою відносно поверхні плати (зазвичай `θ ≈ 30°...60°`);
- `r_fillet` — радіус внутрішнього спряження між меніском та торцем чіпа (`r_fillet ≈ 5...15 мкм`);
- `C_geom ≈ 0.65` — безрозмірний фактор форми.

При надлишку паяльної пасти (`h_f > 0.8 · H_c`, `θ > 60°`) коефіцієнт концентрації сягає `K_t ≈ 2.2...2.6`. Локальне напруження у точці переходу зростає більш ніж удвічі. Еластичний шар Soft-Termination знижує ефективне значення `K_t` до `1.1...1.3`, оскільки полімер здатний пластично підлаштовувати свою форму під геометрію меніска.

## 4. Лінійна механіка руйнування (LEFM) та швидкість вивільнення енергії G_I

Для оцінки стійкості кераміки `BaTiO₃` до поширення мікродефектів застосовують апарат лінійної пружної механіки руйнування (LEFM, англ. *Linear Elastic Fracture Mechanics*).

Нехай на поверхні керамічного тіла біля зрізу металізації існує мікроскопічна пора або технологічна мікротріщина глибиною `a` (типовий розмір пори для дрібнозернистої кераміки `a ≈ 2...5 мкм`).

Коефіцієнт інтенсивності напружень для крайової нормальної тріщини розриву (мода I) під дією розтягувального напруження `σ` розраховується за формулою:

```
K_I = Y · σ · √(π · a)                                [коефіцієнт інтенсивності напружень]
```

де `Y ≈ 1.12` — безрозмірний геометричний фактор форми для поверхневої напівеліптичної крайової тріщини в напівбезмежному тілі.

Згідно з критерієм Ірвіна, нестабільне катастрофічне поширення тріщини починається в момент, коли коефіцієнт інтенсивності досягає критичної в'язкості руйнування матеріалу (тріщиностійкості `K_IC`):

```
K_I ≥ K_IC                                            [умова нестабільного росту тріщини]
```

Для титанату барію `BaTiO₃` критичний коефіцієнт становить `K_IC ≈ 1.0 МПа·м^(1/2) = 1.0 × 10⁶ Па·√м`.

Критичне напруження руйнування кераміки `σ_крит` виражається як:

```
σ_крит = K_IC / (Y · √(π · a))                        [критичне напруження початку руйнування]
```

Для дефекту глибиною `a = 3.0 мкм = 3.0 × 10⁻⁶ м`:

```
σ_крит
= (1.0 × 10⁶) / (1.12 · √(π · 3.0 × 10⁻⁶))            [підстановка значень K_IC та a]
= (1.0 × 10⁶) / (1.12 · √(9.425 × 10⁻⁶))              [обчислення підкореневого виразу]
= (1.0 × 10⁶) / (1.12 · 3.07 × 10⁻³)                  [добування квадратного кореня]
= (1.0 × 10⁶) / (3.438 × 10⁻³)                        [множення коефіцієнтів знаменника]
= 2.908 × 10⁸ Па ≈ 290.8 МПа                          [критичне локальне напруження]
```

### Енергетичний критерій Гріффітса (G_I)

Швидкість вивільнення пружної енергії деформації `G_I` для плоского деформованого стану керамічного тіла пов'язана з коефіцієнтом інтенсивності напружень:

```
G_I = (1 - ν_c²) · K_I² / E_c                         [швидкість вивільнення енергії]
```

Критична густина поверхневої енергії руйнування для титанату барію становить `G_IC ≈ 7.0...10.0 Дж/м²`.

У стандартному чіпі при розтягувальному напруженні 550 МПа швидкість вивільнення енергії сягає `G_I ≈ 24.5 Дж/м² > G_IC`, що забезпечує надлишок пружної енергії для миттєвого проростання тріщини крізь усе тіло компонента. У Soft-Termination конденсаторі напруження `σ < 80 МПа` утримує швидкість вивільнення енергії на рівні `G_I < 0.6 Дж/м² ≪ G_IC`, унеможливлюючи будь-який ріст дефектів.

## 5. Термічні деформації та напруження при термоциклуванні

Окрім чистого механічного вигину, паяне з'єднання зазнає знакозмінних напружень внаслідок різниці коефіцієнтів теплового розширення (CTE, англ. *Coefficient of Thermal Expansion*).

При зміні температури від кімнатної `T_0` до екстремальної робочої `T` на величину `ΔT = T - T_0` різниця термічного розширення між платою та конденсатором викликає термічну деформацію невідповідності:

```
ε_терм = (α_pcb - α_c) · ΔT                           [термічна деформація неузгодженості]
```

Для типових значень `α_pcb = 16 ppm/K` (FR-4) та `α_c = 9.5 ppm/K` (титанат барію `BaTiO₃`):

```
Δα = α_pcb - α_c = 16.0 - 9.5 = 6.5 ppm/K             [різниця коефіцієнтів розширення]
```

При охолодженні автомобільної плати до арктичної температури `T = -40 °C` (від температури затвердіння припою `T_solidus ≈ 217 °C`, градієнт `ΔT = -257 K`):

```
ε_терм = (6.5 × 10⁻⁶ 1/K) · (-257 K)                  [підстановка температурного перепаду]
= -1.67 × 10⁻³ = -1670 με                             [стискання/зсув напруження]
```

У двовимірному напруженому стані термомеханічне напруження в жорсткому паяному шві становить:

```
σ_терм = (E_c / (1 - ν_c)) · Δα · ΔT                  [двовісне термічне напруження]
```

Підставляючи `E_c = 130 ГПа` та `ν_c = 0.24`:

```
σ_терм = (130 × 10⁹ / (1 - 0.24)) · (6.5 × 10⁻⁶) · (257) [розрахунок термічного напруження]
= (1.71 × 10¹¹ Па) · (1.67 × 10⁻³)                   [множення компонентів]
= 285.6 МПа                                           [фінальне термічне напруження]
```

Напруження 285.6 МПа перевищує міцність кераміки (120 МПа). У стандартних MLCC це викликає втомні тріщини після кількох сотень циклів. Введення шару Soft-Termination поглинає термічне зміщення `ΔL_терм = ε_терм · L_c / 2` за рахунок пружного зсуву епоксиду, знижуючи циклічне напруження нижче 40 МПа і забезпечуючи ресурс понад 3000 циклів за стандартом AEC-Q200 Grade 0.

## 6. Практичні розрахунки для випробувального стенда

Проведемо покроковий розрахунок параметрів деформації для двох типових сценаріїв тестування за стандартом AEC-Q200-005.

### Вихідні дані стенда:
- Товщина плати FR-4: `t = 1.6 мм = 1.6 × 10⁻³ м`;
- Відстань між опорами: `L = 90 мм = 0.09 м`;
- Довжина чіпа EIA 1206: `L_c = 3.2 мм = 3.2 × 10⁻³ м`;
- Висота чіпа: `H_c = 1.6 мм = 1.6 × 10⁻³ м`;
- Модуль Юнга кераміки: `E_c = 130 ГПа = 1.3 × 10¹¹ Па`;
- Межа міцності кераміки на розтяг: `σ_гранична = 120 МПа = 1.2 × 10⁸ Па`;
- Коефіцієнт концентрації напружень на краю меніска: `K_t = 1.8`.

---

### Розрахунок 1: Стандартний поріг прогину h = 2.0 мм

1. Розрахунок відносної деформації поверхні друкованої плати:

```
ε_поверхні
= 6 · t · h / L²                                      [формула поверхневої деформації балки]
= 6 · (1.6 × 10⁻³) · (2.0 × 10⁻³) / (0.09)²           [підстановка числових значень t, h, L]
= 1.92 × 10⁻⁵ / 8.1 × 10⁻³                            [ділення чисельника на знаменник]
= 2.37 × 10⁻³ = 2370 με                               [результат у мікродеформаціях]
```

2. Розрахунок розтягувального напруження у кераміці стандартного конденсатора з урахуванням концентратора:

```
σ_кераміки
= K_t · E_c · ε_поверхні                              [закон Гука з коефіцієнтом концентрації]
= 1.8 · (1.3 × 10¹¹ Па) · (2.37 × 10⁻³)               [підстановка значень E_c та ε_поверхні]
= 554.6 × 10⁶ Па = 554.6 МПа                          [підсумкове розтягувальне напруження]
```

**Оцінка результату:** Напруження 554.6 МПа у 4.6 раза перевищує межу міцності титанату барію (120 МПа). Без захисного полімерного прошарку стандартний чіп 1206 зазнає крихкого злому під кутом 45°.

---

### Розрахунок 2: Автомобільний підвищений прогин h = 5.0 мм (AEC-Q200 Soft-Term)

1. Розрахунок поверхневої деформації плати:

```
ε_поверхні
= 6 · t · h / L²                                      [формула поверхневої деформації балки]
= 6 · (1.6 × 10⁻³) · (5.0 × 10⁻³) / (0.09)²           [підстановка прогину h = 5.0 мм]
= 4.80 × 10⁻⁵ / 8.1 × 10⁻³                            [ділення чисельника на знаменник]
= 5.93 × 10⁻³ = 5930 με                               [поверхнева деформація 5930 ppm]
```

2. Розрахунок повного зміщення між контактними майданчиками:

```
ΔL_pads
= ε_поверхні · L_c                                    [зміщення бази контактів]
= (5.93 × 10⁻³) · (3.2 × 10⁻³ м)                      [підстановка деформації та довжини чіпа]
= 1.898 × 10⁻⁵ м = 18.98 мкм                          [повне горизонтальне розведення майданчиків]
```

3. Розподіл деформації між двома полімерними виводами Soft-Termination товщиною `t_p = 20 мкм` (по 9.0 мкм зміщення на кожен торець при пружній деформації кераміки ~0.98 мкм):

```
γ_poly
= Δu_poly / t_p                                       [визначення інженерного зсуву]
= 9.0 мкм / 20.0 мкм                                  [ділення зміщення на товщину шару]
= 0.45                                                [зсувна деформація 45%]
```

4. Залишкове розтягувальне напруження у кераміці з урахуванням пластичної релаксації полімерного компаунда:

```
σ_кераміки_SoftTerm
= E_c · ε_кераміки_залишкова                          [закон Гука для захищеного тіла]
= (1.3 × 10¹¹ Па) · (0.98 × 10⁻⁶ м / 3.2 × 10⁻³ м)     [підстановка залишкової деформації кераміки]
= (1.3 × 10¹¹ Па) · (3.06 × 10⁻⁴)                     [обчислення відносного подовження]
= 39.8 × 10⁶ Па ≈ 39.8 МПа                            [напруження в керамічному ядрі]
```

**Оцінка результату:** Напруження 39.8 МПа є у 3 рази меншим за граничну міцність кераміки 120 МПа (коефіцієнт запасу міцності `k_безпеки ≈ 3.0`). Навіть при екстремальному вигині плати 5.0 мм конденсатор повністю зберігає цілісність діелектрика та працездатність.
