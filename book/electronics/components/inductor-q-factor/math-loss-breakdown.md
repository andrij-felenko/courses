# 🧮 Аналітична модель втрат і розрахунок добротності котушки

Розрахунок добротності котушки індуктивності на високих частотах вимагає точного математичного балансу між реактивною енергією магнітного поля та чотирма незалежними фізичними каналами теплових втрат. Оскільки кожен механізм розсіювання енергії має власну частотну та геометричну залежність, підсумкова добротність `Q(f)` є нелінійною функцією з чітко вираженим максимумом, за яким слідує спад до нуля на частоті власного резонансу.

Нижче наведено повне аналітичне виведення еквівалентних компонентів втрат, розрахунок оптимальної частоти піка добротності `f_opt`, оптимізацію геометрії за Вілером, моделювання вихрових струмів за рівняннями Доуелла та Ферейри, а також вплив розподіленої паразитної ємності.

### 1. Фундаментальне енергетичне означення добротності

Нехай крізь котушку з індуктивністю `L` протікає гармонічний струм із круговою частотою `ω = 2π·f` та амплітудним значенням `I_pk`:

```
i(t) = I_pk · cos(ω·t)
```

Миттєва енергія, накопичена в магнітному полі котушки в довільний момент часу `t`, визначається інтегралом потужності:

```
W_m(t) = ½ · L · i²(t) = ½ · L · I_pk² · cos²(ω·t)
```

Максимальне значення запасеної енергії досягається в моменти пікового струму `cos(ω·t) = ±1`:

```
W_max = ½ · L · I_pk²
```

Якщо повний еквівалентний послідовний опір усіх втрат у котушці на даній частоті дорівнює `R_s(f)`, то середня потужність теплових втрат за період коливань `T = 2π / ω` становить:

```
P_loss = ½ · I_pk² · R_s(f) = I_rms² · R_s(f)
```

Енергія, безповоротно розсіяна у вигляді тепла за один повний період коливань `T`, дорівнює добутку середньої потужності на тривалість періоду:

```
ΔW_період = P_loss · T = (½ · I_pk² · R_s(f)) · (2π / ω) = π · I_pk² · R_s(f) / ω
```

За класичним визначенням, добротність `Q` дорівнює відношенню максимальної запасеної енергії до енергії, втраченої за один радіан коливань (тобто втрати за період, поділені на `2π`):

```
Q = 2π · W_max / ΔW_період                             [за класичним означенням Q]
  = 2π · (½ · L · I_pk²) / (π · I_pk² · R_s(f) / ω)     [підстановка W_max та ΔW_період]
  = ω · L / R_s(f)                                     [скорочення спільних множників]
```

Таким чином, уся фізика розрахунку `Q` зводиться до аналітичного знаходження частотно-залежного послідовного опору втрат `R_s(f)`.

### 2. Геометрична оптимізація циліндричної котушки за Вілером

Для одношарової циліндричної котушки без осердя з діаметром каркаса `d_coil`, довжиною намотування `l_coil` та числом витків `N` Гарольд Вілер вивів наближену формулу індуктивності (де лінійні розміри в міліметрах, а `L` у мікрогенрі):

```
L ≈ ( d_coil² · N² ) / ( 450 · d_coil + 1000 · l_coil )   [мкГн]
```

Опір постійному струму обмотки пропорційний довжині дроту `l_wire = N · π · d_coil`:

```
R_dc = ρ_cu · ( N · π · d_coil ) / A_wire
```

Якщо поставити математичну задачу знаходження максимуму відношення `L / R_dc` за фіксованого об'єму міді та заданої індуктивності `L`, оптимізація функції за геометричним фактором форми `k_geom = l_coil / d_coil` дає чіткий оптимум:

```
( l_coil / d_coil )_opt ≈ 0.45
```

Котушка, довжина якої становить приблизно `45%` від її діаметра, забезпечує найкоротшу довжину витка для заданого магнітного потоку. Це мінімізує опір міді `R_dc` та дає найвищу можливу власну добротність `Q₀`. Якщо ж зробити котушку занадто довгою і тонкою (`l ≫ d`), індуктивність падатиме швидше через витік магнітних ліній, а довжина дроту й опір зростатимуть.

### 3. Втрати в провіднику: скін-ефект та одновимірна модель Доуелла

Повний опір мідної обмотки змінному струму `R_ac(f)` складається з опору постійному струму `R_dc` та двох високочастотних факторів викривлення поля:

```
R_ac(f) = R_dc · [ F_skin(ξ) + G_prox(ξ) · (m² − 1) / 3 ]
```

де:
- `R_dc = ρ_cu · l_wire / A_wire` — опір постійному струму (`ρ_cu ≈ 1.72·10⁻⁸ Ом·м` при `20 °C`);
- `m` — кількість шарів обмотки в котушці;
- `ξ` — безрозмірний фактор товщини провідника щодо глибини скін-шару `δ`.

Товщина скін-шару `δ` у мідному провіднику зі зростанням частоти `f` зменшується за формулою:

```
δ = √( ρ_cu / (π · f · μ₀ · μ_r) ) ≈ 0.066 / √f   [метри, де f у Гц]
```

Для круглого дроту діаметром `d` безрозмірний параметр масштабу за Доуеллом дорівнює:

```
ξ = (√π / 2) · (d / δ) · √η ≈ 0.886 · (d / δ) · √η
```

де `η` — коефіцієнт пористості намотування (*porosity factor*), що враховує зазор між витками у шарі: `η = N_layer · d / b_bobbin` (відношення сумарного діаметра витків шару до ширини каркаса `b_bobbin`).

#### Скін-ефект (ізольований провідник)

Скін-ефект витісняє струм до зовнішньої циліндричної поверхні під дією власного внутрішнього змінного магнітного поля дроту. Коефіцієнт зростання опору за рахунок власного скін-ефекту описується функцією Кельвіна (або наближенням Доуелла):

```
F_skin(ξ) = ξ · [ sinh(2ξ) + sin(2ξ) ] / [ cosh(2ξ) − cos(2ξ) ]
```

Асимптотична поведінка функції скін-ефекту:
- На низьких частотах (`d ≪ δ`, тобто `ξ ≪ 1`):
  `F_skin(ξ) ≈ 1 + ξ⁴ / 45`, тобто опір зростає дуже повільно як `f²`.
- На високих частотах (`d ≫ δ`, тобто `ξ ≫ 1`):
  `F_skin(ξ) ≈ ξ ∝ √f`, оскільки струм тече лише в тонкому шарі товщиною `δ` по периметру `π·d`.

#### Ефект близькості витків (Proximity Effect)

У реальній котушці сусідні витки та сусідні шари пронизують провідник зовнішнім поперечним змінним магнітним полем `H_ext`. Це поле наводить у тілі провідника внутрішні вихрові струми, які з одного боку дроту додаються до робочого струму, а з протилежного — віднімаються від нього.

Для багатошарової циліндричної котушки з числом шарів `m` коефіцієнт втрат наближення за одновимірною моделлю Доуелла описується функцією:

```
G_prox(ξ) = 2ξ · [ sinh(ξ) − sin(ξ) ] / [ cosh(ξ) + cos(ξ) ]
```

Асимптотичний аналіз показує драматичну різницю між одношаровою та багатошаровою котушкою:
- При помірних частотах (`ξ < 1`):
  `G_prox(ξ) ≈ 2ξ⁴ / 3 ∝ f²`.
- З урахуванням множника кількості шарів `(m² − 1)`:
  Потужність втрат ефекту близькості зростає пропорційно **квадрату кількості шарів** `m²` і **квадрату частоти** `f²`.

Для тришарової котушки (`m = 3`) множник `(m² − 1) / 3 = (9 − 1) / 3 = 2.67`. Для десятишарової котушки (`m = 10`) цей множник досягає `(100 − 1) / 3 = 33`! Це означає, що на частоті `100 кГц` втрати в десятишаровій котушці будуть у 33 рази більшими, ніж передбачає простий скін-ефект для випрямленого дроту.

### 4. Модель Ферейри для круглих провідників

Одновимірна модель Доуелла виведена для пласких прямокутних шарів фольги. Для круглого дроту Жан Ферейра (J. A. Ferreira) запропонував точніший аналітичний апарат, заснований на спеціальних функціях Бесселя (функціях Кельвіна нульового та першого порядків `ber(x)`, `bei(x)`).

Фактор опору розпадається на суму власного скін-ефекту та ефекту близькості:

```
R_ac = R_dc · [ Ψ_skin(γ) + η · (m² − 1) · Ψ_prox(γ) ]
```

де аргумент `γ = d / (√2 · δ)`.

Функції Ферейри через функції Кельвіна мають вигляд:

```
Ψ_skin(γ) = (γ / 2) · [ ber(γ)·bei'(γ) − bei(γ)·ber'(γ) ] / [ (ber'(γ))² + (bei'(γ))² ]
Ψ_prox(γ) = −2π · γ · [ ber₂(γ)·ber'(γ) + bei₂(γ)·bei'(γ) ] / [ (ber(γ))² + (bei(γ))² ]
```

Ця модель доводить, що якщо діаметр окремої жили перевищує подвійну товщину скін-шару (`d > 2δ`), вихрові втрати ефекту близькості починають переважати над скін-ефектом уже при двох шарах намотування (`m ≥ 2`).

### 5. Еквівалентний послідовний опір втрат у магнітному осерді

Якщо котушка намотана на феромагнітному чи феритовому осерді, магнітна проникність матеріалу є комплексною величиною:

```
μ = μ' − j·μ''
```

де `μ'` відповідає за реактивне накопичення енергії (індуктивність), а `μ''` описує сумарні магнітні втрати (гістерезис і вихрові струми в матеріалі).

Комплексний імпеданс котушки з осердям без урахування активного опору дроту записується через індуктивність у вакуумі `L₀`:

```
Z_core = j · ω · L₀ · μ = j · ω · L₀ · (μ' − j·μ'') = ω · L₀ · μ'' + j · ω · L₀ · μ'
```

Звідси дійсна частина представляє еквівалентний послідовний опір втрат осердя `R_core(f)`:

```
R_core(f) = ω · L₀ · μ'' = ω · L · (μ'' / μ') = ω · L · tan(δ_m)
```

де `tan(δ_m) = μ'' / μ'` — магнітний тангенс кута втрат матеріалу осердя.

#### Зв'язок із рівнянням Штейнмеца для потужності втрат

Для силових індуктивностей та трансформаторів втрати в осерді часто задаються через питому об'ємну густину потужності втрат `P_v` (Вт/м³ або мВт/см³) за емпіричним рівнянням Штейнмеца:

```
P_v = C_m · f^α · B_pk^β
```

де `C_m`, `α`, `β` — коефіцієнти матеріалу (типово `α ≈ 1.2–1.8`, `β ≈ 2.0–2.6`).

Повна потужність втрат в осерді з ефективним об'ємом `V_e = A_e · l_e` дорівнює:

```
P_core = P_v · V_e = C_m · f^α · B_pk^β · V_e
```

Амплітуда магнітної індукції `B_pk` пов'язана з піковим струмом котушки `I_pk` та числом витків `N`:

```
B_pk = μ₀ · μ' · N · I_pk / l_e
```

Оскільки потужність втрат виражається через середньоквадратичний струм як `P_core = I_rms² · R_core = (½ · I_pk²) · R_core`, еквівалентний послідовний опір осердя становить:

```
R_core = 2 · P_core / I_pk² = 2 · C_m · f^α · [ (μ₀·μ'·N / l_e) · I_pk ]^β · V_e / I_pk²
```

У лінійному режимі слабкого сигналу (`β = 2`), опір `R_core` не залежить від амплітуди струму:

```
R_core(f) = 2 · C_m · f^α · (μ₀·μ'·N)² · (A_e / l_e)
```

- при `α = 1` (гістерезисні втрати): `R_hyst ∝ f`;
- при `α = 2` (вихрові струми в матеріалі осердя): `R_eddy ∝ f²`.

### 6. Діелектричні втрати в ізоляції витків

Між сусідніми витками котушки існує електричне поле, яке поляризує лаковий шар дроту, каркас та заливальний компаунд. Діелектрик із відносною проникністю `ε_r` та тангенсом кута втрат `tan(δ_d)` створює паразитну провідність витоку паралельно власній ємності `C_p`:

```
G_diel(f) = ω · C_p · tan(δ_d) = 1 / R_p,diel
```

Щоб додати діелектричні втрати до загального балансу послідовного опору `R_s`, перетворимо паралельну провідність `G_diel` в еквівалентний послідовний опір `R_s,diel` (використовуючи умову високої добротності `Q ≫ 1`):

```
R_s,diel ≈ (ω·L)² · G_diel = ω³ · L² · C_p · tan(δ_d)
```

Зверніть увагу на степінь частоти: діелектричний послідовний опір зростає пропорційно **кубу частоти** `ω³`! Тому на частотах поблизу власного резонансу саме діелектричні втрати в неякісному каркасі (наприклад, текстоліті чи епоксидній смолі) можуть обвалити добротність значно сильніше, ніж опір міді.

### 7. Підсумковий послідовний опір та пошук максимуму Q_max

Сумарний послідовний опір втрат реальної котушки є сумою всіх чотирьох фізичних складових:

```
R_s(f) = R_dc + R_skin(f) + R_prox(f) + R_core(f) + R_s,diel(f)
```

Узагальнена аналітична залежність опору від частоти має вигляд полінома:

```
R_s(f) = R_dc + k₁·√f + k₂·f + k₃·f² + k₄·f³
```

Підставивши цей опір у вираз для істинної добротності магнітної гілки `Q_true(f) = 2π·f·L / R_s(f)`, отримаємо:

```
Q_true(f) = 2π·L · f / ( R_dc + k₁·√f + k₂·f + k₃·f² + k₄·f³ )
```

Поділимо чисельник і знаменник на `f`:

```
Q_true(f) = 2π·L / [ (R_dc / f) + (k₁ / √f) + k₂ + k₃·f + k₄·f² ]
```

Щоб знайти частоту `f_opt`, на якій добротність досягає свого абсолютного максимуму `Q_max`, прирівняємо до нуля похідну знаменника за частотою:

```
d/df [ R_dc · f⁻¹ + k₁ · f⁻¹⁄² + k₂ + k₃ · f + k₄ · f² ] = 0
−R_dc · f⁻² − ½ · k₁ · f⁻³⁄² + k₃ + 2k₄ · f = 0
```

У радіочастотному діапазоні, де головний баланс відбувається між постійним опором міді `R_dc` та квадратичними вихровими втратами (проксиміті й осердя `k₃·f²`):

```
R_dc / f_opt² ≈ k₃   ⇒   f_opt ≈ √( R_dc / k₃ )
```

На цій оптимальній частоті втрати на постійному струмі `R_dc` приблизно дорівнюють сумі високочастотних втрат `k₃·f²`, що забезпечує найвищий ККД коливальної системи.

### 8. Вплив власного резонансу (SRF) на виміряну добротність

Повний комплексний імпеданс котушки з урахуванням паралельної паразитної ємності `C_p` дорівнює:

```
Z_in(jω) = ( R_s + jωL ) || ( 1 / jωC_p )
         = ( R_s + jωL ) / [ 1 − ω²·L·C_p + jω·C_p·R_s ]
```

Частота власного резонансу (*Self-Resonant Frequency*, SRF) визначається умовою компенсації реактивностей:

```
ω_SRF = 1 / √( L · C_p )   ⇒   f_SRF = 1 / ( 2π · √(L · C_p) )
```

Помножимо чисельник і знаменник на комплексно спряжений знаменник `[ (1 − ω²·L·C_p) − jω·C_p·R_s ]`:

```
Re{ Z_in } = R_eff = R_s / [ (1 − ω²·L·C_p)² + (ω·C_p·R_s)² ]
Im{ Z_in } = X_eff = [ ω·L · (1 − ω²·L·C_p) − ω·C_p·R_s² ] / [ (1 − ω²·L·C_p)² + (ω·C_p·R_s)² ]
```

Виділивши відношення уявної частини до дійсної, знайдемо виміряну (уявну) добротність `Q_eff`:

```
Q_eff(f) = X_eff / R_eff = Q_true(f) · [ 1 − (f / f_SRF)² − (R_s² · C_p / L) ]
```

Оскільки для якісних котушок `R_s² ≪ L / C_p` (характеристичний хвильовий опір контуру `Z₀ = √(L/C_p) ≫ R_s`), третім доданком нехтують:

```
Q_eff(f) ≈ Q_true(f) · [ 1 − (f / f_SRF)² ]
```

Висновки з резонансного рівняння:
1. При `f ≪ f_SRF` множник `[1 − (f/f_SRF)²] ≈ 1`, і виміряна добротність збігається з істинною добротністю обмотки.
2. При наближенні частоти до `f_SRF` еквівалентна індуктивність стрімко зростає через резонанс `L_eff = L / [1 − (f/f_SRF)²]`, але еквівалентний послідовний опір зростає ще швидше `R_eff = R_s / [1 − (f/f_SRF)²]²`.
3. У точці `f = f_SRF` реактивний опір перетворюється на нуль, і добротність `Q_eff` спадає строго до нуля.
4. При `f > f_SRF` реактивність змінює знак на ємнісний, і деталь перестає працювати як індуктивність.

### 9. Зв'язок навантаженої та ненавантаженої добротності

У реальному коливальному контурі котушка працює разом із внутрішнім опором джерела сигналу `R_gen` та опором навантаження `R_load`. Розрізняють:
- **Ненавантажену добротність** `Q₀` (*Unloaded Q*): визначається виключно внутрішніми втратами самої котушки `Q₀ = ω₀·L / R_s`.
- **Навантажену добротність** `Q_L` (*Loaded Q*): враховує зовнішнє демпфування контуру.

Для послідовного включення:

```
Q_L = ω₀ · L / [ R_s + R_gen + R_load ] = Q₀ / [ 1 + (R_gen + R_load) / R_s ]
```

Для паралельного резонансного контуру з еквівалентним паралельним опором втрат котушки `R_p,coil ≈ Q₀² · R_s`:

```
1 / Q_L = (1 / Q₀) + (1 / Q_ext) = (1 / Q₀) + (ω₀·L / R_load,par)
```

Смуга пропускання реального контуру на рівні половинної потужності (`−3 дБ`) визначається виключно навантаженою добротністю:

```
Δf_3dB = f₀ / Q_L
```

Тому навіть якщо сама котушка має власну добротність `Q₀ = 400`, некоректне низькоомне навантаження каскаду може знизити результуючу добротність контуру до `Q_L = 20`, розширюючи смугу пропускання у 20 разів.

### 10. Порівняння трьох конструкцій котушки 100 мкГн на 500 кГц

Щоб наочно побачити дію аналітичних рівнянь, порівняємо розрахунковий послідовний опір та добротність трьох різних варіантів виконання котушки `L = 100 мкГн` на частоті `f = 500 кГц` (де `δ = 93.3 мкм`):

1. **Варіант A: Багатошарова котушка суцільним дротом** (`m = 4` шари, діаметр жили `d = 0.5 мм = 500 мкм > 5δ`):
   - Опір `R_dc = 0.45 Ом`.
   - Фактор скін-ефекту: `F_skin ≈ 2.7`.
   - Фактор ефекту близькості за Доуеллом: `(m² − 1) / 3 = (16 − 1) / 3 = 5.0`, `G_prox ≈ 8.2`.
   - Повний змінний опір: `R_ac = 0.45 · (2.7 + 5.0 · 8.2) = 0.45 · 43.7 ≈ 19.67 Ом`.
   - Добротність: `Q = 2π·(5·10⁵)·(10⁻⁴) / 19.67 = 314.16 / 19.67 ≈ 16.0`.
   - *Висновок:* Ефект близькості в 4 шарах збільшив опір у 44 рази й катастрофічно обвалив добротність.

2. **Варіант B: Багатошарова котушка літцендратом** (`m = 4` шари, літцендрат `60 × 0.05 мм`, діаметр жили `d_str = 50 мкм < δ`):
   - Опір `R_dc = 0.48 Ом` (через коефіцієнт скрутки).
   - Оскільки жилки тонші за глибину скін-шару (`d_str / δ ≈ 0.53 < 1`), `F_skin ≈ 1.02`.
   - Завдяки транспозиції жилок у пучку ефект близькості між жилками пригнічено: `G_prox · (m² − 1) / 3 ≈ 0.45`.
   - Повний змінний опір: `R_ac = 0.48 · (1.02 + 0.45) = 0.48 · 1.47 ≈ 0.706 Ом`.
   - Добротність: `Q = 314.16 / 0.706 ≈ 445`.
   - *Висновок:* Літцендрат зменшив ВЧ втрати майже у 28 разів, піднявши `Q` з 16 до 445!

3. **Варіант C: Одношаровий тороїд на NiZn-фериті** (`m = 1`, дріт `0.6 мм`, ферит `NiZn 4C65` з `μ' = 120`, `tan(δ_m) = 0.0015`):
   - Опір `R_dc = 0.09 Ом` (мала довжина дроту завдяки високій проникності осердя).
   - Одношарове намотування: `m = 1 ⇒ G_prox · 0 = 0`, діє лише скін-ефект: `R_skin ≈ 0.35 Ом`.
   - Втрати в осерді: `R_core = ω·L·tan(δ_m) = 314.16 · 0.0015 ≈ 0.471 Ом`.
   - Сумарний опір: `R_s = R_skin + R_core = 0.35 + 0.471 = 0.821 Ом`.
   - Добротність: `Q = 314.16 / 0.821 ≈ 382`.
   - *Висновок:* Ферит дав компактні габарити та високу `Q`, де втрати рівномірно розподілені між міддю та магнітним матеріалом.

### 11. Наскрізний числовий розрахунок одношарової ВЧ-котушки

**Вихідні параметри задачі:**
- Одношарова циліндрична котушка без осердя (повітряна);
- Номінальна індуктивність: `L = 10 мкГн` (`10⁻⁵ Гн`);
- Кількість витків: `N = 30`, крок намотування дорівнює подвійному діаметру дроту;
- Діаметр мідного дроту: `d = 0.8 мм` (`0.8·10⁻³ м`);
- Загальна довжина дроту: `l_wire = 2.4 м`;
- Паразитна ємність обмотки: `C_p = 2.5 пФ` (`2.5·10⁻¹² Ф`);
- Робоча частота розрахунку: `f = 10 МГц` (`10⁷ Гц`).

**Крок 1: Розрахунок власного резонансу f_SRF.**

```
f_SRF = 1 / [ 2π · √( 10·10⁻⁶ · 2.5·10⁻¹² ) ]
      = 1 / [ 2π · √( 2.5·10⁻¹⁷ ) ]
      = 1 / [ 2π · 5·10⁻⁹ ]
      = 1 / [ 3.1416·10⁻⁸ ]
      ≈ 31.83 МГц
```

Коефіцієнт резонансного зменшення добротності на `10 МГц`:

```
K_srf = 1 − (10 / 31.83)² = 1 − (0.314)² = 1 − 0.0987 = 0.9013
```

**Крок 2: Опір постійному струму R_dc.**

```
A_wire = π · (d / 2)² = π · (0.4·10⁻³)² ≈ 5.027·10⁻⁷ м²
R_dc   = 1.72·10⁻⁸ · 2.4 / 5.027·10⁻⁷ ≈ 0.082 Ом
```

**Крок 3: Товщина скін-шару та опір R_skin на 10 МГц.**

```
δ = 0.066 / √(10⁷) = 0.066 / 3162.3 ≈ 2.087·10⁻⁵ м = 20.87 мкм
```

Оскільки `d = 800 мкм ≫ 2δ = 41.74 мкм`, скін-ефект виражений дуже сильно. Ефективна площа поперечного перерізу, в якій тече струм (кільце товщиною `δ` по зовнішньому периметру):

```
A_skin ≈ π · d · δ = π · (0.8·10⁻³) · (2.087·10⁻⁵) ≈ 5.245·10⁻⁸ м²
```

Опір з урахуванням власного скін-ефекту:

```
R_skin = 1.72·10⁻⁸ · 2.4 / 5.245·10⁻⁸ ≈ 0.787 Ом
```

**Крок 4: Внесок ефекту близькості для розрідженого намотування.**

Оскільки крок між витками дорівнює подвійному діаметру дроту (`s = 2d`), магнітне поле сусідніх витків послаблене. Коефіцієнт проксиміті для одношарової котушки з таким кроком додає приблизно `35%` до опору скін-ефекту:

```
R_prox ≈ 0.35 · R_skin = 0.35 · 0.787 ≈ 0.275 Ом
```

Повний послідовний опір втрат на `10 МГц` (втратами в повітрі та діелектрику лаку нехтуємо):

```
R_s = R_skin + R_prox ≈ 0.787 + 0.275 = 1.062 Ом
```

**Крок 5: Розрахунок реактивного опору та підсумкової добротності.**

Реактивний опір індуктивності на частоті `10 МГц`:

```
X_L = 2π · f · L = 2π · 10⁷ · 10⁻⁵ = 200π ≈ 628.32 Ом
```

Істинна добротність магнітної гілки:

```
Q_true = X_L / R_s = 628.32 / 1.062 ≈ 591.6
```

Виміряна ефективна добротність з урахуванням паразитної ємності:

```
Q_eff = Q_true · K_srf = 591.6 · 0.9013 ≈ 533
```

Отримане значення `Q ≈ 533` є типовим для високоякісної радіочастотної котушки короткохвильового діапазону. Якщо замінити суцільний мідний дріт на посріблений, опір скін-шару зменшиться ще на `5–8%` (завдяки меншому питомому опору срібла `1.59·10⁻⁸ Ом·м`), що підніме добротність майже до `570`.
