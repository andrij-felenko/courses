# ⚙️ Алгоритм вимірювання та обчислення добротності котушки

Пряме вимірювання добротності котушки індуктивності цифровим вимірювачем імпедансу (LCR-метром) або векторним аналізатором кіл (VNA) вимагає цифрової обробки масиву частотного сканування. Коли крок сітки генератора дискретний, пік резонансу та точки половинної потужності (`−3 дБ`) майже ніколи не потрапляють точно на виміряні вузли частотної сітки. Спроба обчислити `Q = f₀ / Δf` простим пошуком найближчих дискретних відліків дає систематичну похибку від `15%` до `40%`, спотворюючи уявлення про реальні втрати в компоненті.

Нижче детально розглянуто алгоритми цифрової екстракції параметрів коливальної системи, математичний апарат субпіксельної інтерполяції резонансного піка, метод кола імпедансу (Q-circle fitting) на діаграмі Вольперта-Сміта, методи деімбеддингу вимірювального стенда, калібрування за 12-параметричною моделлю, автоматичне детектування нелінійності осердя, розрахунок власної паразитної ємності методом двох частот та повну реалізацію на мовах C та C++.

### Три лабораторні методи вимірювання добротності

В інженерній практиці для вимірювання добротності котушок індуктивності застосовують три основні схемотехнічні підходи, кожен з яких має свої обмеження за частотою та діапазоном значень `Q`:

#### 1. Класичний резонансний метод (схема Q-метра)
Досліджувану котушку `L` з'єднують послідовно з прецизійним зразковим конденсатором `C_ref` (втратами якого можна знехтувати). Коло збуджується від джерела радіочастотної синусоїдальної напруги `V_in` через прецизійний безіндукційний струмовий шунт наднизького опору `R_shunt` (`0.01–0.05 Ом`).

Високоомний вольтметр змінної напруги вимірює напругу `V_C` безпосередньо на клемах конденсатора. При налаштуванні генератора або конденсатора в резонанс реактивні опори компенсують один одного (`ω₀·L = 1 / (ω₀·C_ref)`), а струм у колі обмежується лише сумою втрат котушки `R_s` та опором шунта:

```
I_res = V_in / ( R_s + R_shunt )
```

Напруга на конденсаторі в момент резонансу становить:

```
V_C = I_res / (ω₀·C_ref) = V_in · [ (ω₀·L) / (R_s + R_shunt) ] = V_in · Q_loaded
```

Знаючи величину `V_in` та вимірявши `V_C`, добротність знаходять безпосередньо як коефіцієнт передачі напруги `Q = V_C / V_in`.

#### 2. Трансмісійний метод слабкого зв'язку (метод S₂₁ на VNA)
Коливальний контур підключають між двома портами векторного аналізатора кіл через надмалі ємності зв'язку `C_c` (`0.1–0.5 пФ`) або індуктивні петлі зв'язку. Мала ємність зв'язку має високий реактивний опір на частоті резонансу (`X_Cc ≫ 50 Ом`), що ізолює контур від демпфувального впливу 50-омного тракту приладу.

Прилад реєструє амплітудно-частотну характеристику коефіцієнта передачі `|S₂₁(f)|`. На резонансній частоті `f₀` коефіцієнт передачі сягає максимуму `S₂₁,max`. Вимірявши ширину резонансного піка `Δf_3dB` на рівні `−3.01 дБ` від максимуму (де потужність сигналу зменшується вдвічі, тобто `|S₂₁| = S₂₁,max / √2`), обчислюють навантажену добротність:

```
Q_L = f₀ / Δf_3dB
```

Якщо зв'язок не є гранично малим (піковий коефіцієнт передачі `|S₂₁(f₀)| > −30 дБ`), прилад вносить помітне додаткове навантаження. У цьому випадку власну (ненавантажену) добротність `Q₀` знаходять через аналітичну корекцію за рівнем втрат на резонансі:

```
Q₀ = Q_L / [ 1 − 10^( S₂₁,max_dB / 20 ) ] = Q_L / [ 1 − |S₂₁(f₀)| ]
```

#### 3. Рефлектометричний метод (метод S₁₁ на колі імпедансу)
Досліджувану котушку підключають до одного порту VNA. Прилад вимірює комплексний коефіцієнт відбиття `S₁₁(f)` і перераховує його у вхідний імпеданс:

```
Z_in(f) = R_in(f) + j · X_in(f) = 50 · [ 1 + S₁₁(f) ] / [ 1 − S₁₁(f) ]
```

Добротність на кожній точці сканування визначається як відношення уявної частини імпедансу (реактивності) до дійсної (активних втрат):

```
Q(f) = | X_in(f) | / R_in(f)
```

Цей метод дозволяє отримати повну криву `Q(f)` у всьому діапазоні частот — від кілогерців до власного резонансу `f_SRF`, проте вимагає ретельного калібрування для виключення опору та індуктивності кабелів.

### Метод кола імпедансу (Q-Circle Fitting) на діаграмі Вольперта-Сміта

Найвищу метрологічну точність при роботі з векторними аналізаторами забезпечує апроксимація годографа комплексного коефіцієнта відбиття `S₁₁(f)`. В околі резонансної частоти крива `S₁₁(f)` на комплексній площині описує майже ідеальне коло, так зване «резонансне коло» (*Q-circle*).

Геометричний аналіз цього кола дозволяє однозначно розв'язати проблему демпфування портом:
1. **Діаметр кола `D`**: безпосередньо задає коефіцієнт зв'язку `β` між котушкою та вимірювальною лінією.
   - Для недозв'язаного резонатора (`β < 1`): `β = D / (2 − D)`.
   - Для перезв'язаного резонатора (`β > 1`): `β = (2 − D) / D`.
   - Радіус кола на площині Сміта становить `R_circle = β / (1 + β)`.
2. **Точки половинної потужності на колі**:
   Точки смуги пропускання `f_low` та `f_high` відповідають кутовому розвороту вектора коефіцієнта відбиття рівно на `±45°` від точки резонансу відносно центра кола. Це дозволяє знаходити смугу пропускання геометричним розрахунком кутів без завалу амплітудних шумів.
3. **Власна добротність `Q₀`** пов'язана з навантаженою добротністю `Q_L` формулою:
   ```
   Q₀ = Q_L · (1 + β)
   ```
4. **Алгебраїчна підгонка кола за Касою (Kåsa fit)**:
   Нехай виміряно `M` комплексних точок `S₁₁[i] = u[i] + j·v[i]`. Мінімізація нев'язки `∑ ( (u[i] − u_c)² + (v[i] − v_c)² − R_c² )²` зводиться до розв'язання системи лінійних рівнянь розмірності `3 × 3`, що дозволяє з субпроцентною точністю визначити координати центра кола `(u_c, v_c)` та його радіус `R_c` навіть за наявності шуму у вимірювальному тракті.

### Векторна корекція похибок: 12-параметрична модель SOLT

При роботі на частотах понад `10 МГц` хвильові процеси в коаксіальних кабелях і перехідниках вносять фазовий зсув та амплітудне спотворення. Для їх компенсації векторний аналізатор застосовує 12-параметричну модель похибок (*12-term error model*).

Основні складові похибок вимірювального порту:
1. **Спрямованість порту `e₀₀` (*Directivity*)**: витік опорного сигналу генератора безпосередньо в приймач відбитої хвилі, що обмежує вимірювання малих коефіцієнтів відбиття.
2. **Узгодження джерела `e₁₁` (*Source Match*)**: паразитні повторні відбиття між виходом приладу та досліджуваною котушкою.
3. **Частотне відстеження відбиття `e₁₀·e₀₁` (*Reflection Tracking*)**: нерівномірність коефіцієнта передачі спрямованого відгалужувача та детекторів у робочій смузі частот.

Калібрування `SOLT` (Short-Open-Load-Thru) перед вимірюванням котушки дозволяє обчислити ці коефіцієнти похибок і в реальному часі розрахувати істинний коефіцієнт відбиття `S₁₁,true`:

```
S₁₁,true = ( S₁₁,meas − e₀₀ ) / [ e₁₀·e₀₁ + e₁₁ · ( S₁₁,meas − e₀₀ ) ]
```

Без цього калібрування виміряний опір втрат `R_s` може виявитися завищеним на кілька омів, що призведе до катастрофічного штучного заниження добротності. Для верифікації якості калібрування стенда перед серією вимірювань підключають прецизійний повітряний коаксіальний резонатор або еталонний безіндукційний резистор `50.0 Ом ± 0.1%`, контролюючи відсутність залишкової паразитної реактивності.

### Автоматичне детектування магнітного насичення та нелінійності

У котушках з магнітними осердями (феритами, залізопорошковими сумішами) добротність суттєво залежить від амплітуди змінного струму. При малих рівнях сигналу домени перемагнічуються в лінійній реверсивній зоні Релея, де гістерезисні втрати малі. Проте зі зростанням розмаху індукції `B_pk` петля гістерезису розширюється, а при наближенні до насичення осердя проникність падає, викликаючи різке зростання струму та падіння `Q`.

Для автоматизованої перевірки лінійності алгоритм вимірювача реалізує двоетапний тест:
1. **Сканування за потужністю генератора (*Power Sweep*)**: вимірювання добротності `Q` на фіксованій резонансній частоті при зміні вихідної потужності від `−30 дБм` (`1 мкВт`) до `+10 дБм` (`10 мВт`) із кроком `5 дБ`.
2. **Критерій нелінійності**: якщо значення добротності `Q(+10 дБм)` відрізняється від `Q(−30 дБм)` більш ніж на `5%`, система фіксує нелінійний режим роботи осердя та повідомляє оператора про необхідність знизити рівень збудження.

### Вимірювання власної ємності C_p методом двох резонансних частот

Розподілена паразитна ємність котушки `C_p` утворюється сумою міжевиткових ємностей та ємності між обмоткою і каркасом. Оскільки безпосередньо підключити вимірювач ємності до котушки неможливо (індуктивність закорочує вимірювальний сигнал на низьких частотах), використовують метод резонансу з двома різними зразковими конденсаторами `C₁` та `C₂`.

Котушку підключають послідовно або паралельно зі зразковим конденсатором `C₁` (наприклад, `100 пФ`) і знаходять резонансну частоту контуру `f₀₁`:

```
f₀₁ = 1 / [ 2π · √( L · (C₁ + C_p) ) ]
```

Потім замінюють конденсатор на `C₂` (наприклад, `25 пФ`) і знаходять другу резонансну частоту `f₀₂`:

```
f₀₂ = 1 / [ 2π · √( L · (C₂ + C_p) ) ]
```

Піднісши обидва вирази до квадрата та склавши їхнє співвідношення, отримуємо систему рівнянь:

```
( f₀₂ / f₀₁ )² = ( C₁ + C_p ) / ( C₂ + C_p )
```

Звідси аналітично виражається шукана паразитна ємність обмотки `C_p`:

```
C_p = ( C₁ · f₀₁² − C₂ · f₀₂² ) / ( f₀₂² − f₀₁² )
```

Після знаходження `C_p` істинна індуктивність `L_true` (без впливу ємності) обчислюється як:

```
L_true = ( f₀₂² − f₀₁² ) / [ 4π² · f₀₁² · f₀₂² · ( C₁ − C₂ ) ]
```

Цей метод дозволяє визначити власну ємність із точністю до десятих часток пікофарада та розрахувати частоту власного резонансу `f_SRF = 1 / [ 2π · √(L_true · C_p) ]` задовго до того, як генератор сягне цієї межі.

### Математичний апарат субпіксельної інтерполяції піка

Під час дискретного частотного сканування з кроком `Δf_step = (f_stop − f_start) / (N − 1)` реальний резонансний пік неперервної функції майже завжди знаходиться між двома сусідніми точками вимірювання.

Нехай дискретний максимум зареєстровано на індексі `k`. Використаємо три відліки:
- центральний відлік: `(f[k], y[k])`;
- лівий сусід: `(f[k-1], y[k-1])`;
- правий сусід: `(f[k+1], y[k+1])`.

Апроксимуємо вершину резонансної кривої квадратичною параболою `y(f) = a·(f − f[k])² + b·(f − f[k]) + c`. Підставивши значення у трьох точках при рівномірному кроці `Δf`, отримуємо систему лінійних рівнянь, розв'язок якої дає точний аналітичний зсув вершини `δ_f` від центральної точки `f[k]`:

```
δ_f = ½ · ( y[k-1] − y[k+1] ) / ( y[k-1] − 2·y[k] + y[k+1] )
f₀  = f[k] + δ_f · Δf
y_max = y[k] − ¼ · ( y[k-1] − y[k+1] ) · δ_f
```

Знаменник `(y[k-1] − 2·y[k] + y[k+1])` є дискретним аналогом другої похідної `d²y/df²`. Оскільки в точці локального максимуму крива опукла вгору, цей знаменник завжди строго від'ємний. Якщо його модуль наближається до нуля (`< 10⁻¹⁵`), це свідчить про вироджені дані або плоску ділянку, і алгоритм повертає помилку розрахунку.

Після знаходження істинного пікового значення `y_max` розраховується пороговий рівень половинної потужності:

```
y_3dB = y_max / √2 ≈ 0.70710678 · y_max
```

Для знаходження лівої граничної частоти `f_low` алгоритм рухається від вершини `k` ліворуч, доки не знайде інтервал між сусідніми точками `j` та `j+1`, де значення перетинає поріг `y_3dB`. Точна частота перетину визначається лінійною інтерполяцією:

```
f_low = f[j] + [ ( y_3dB − y[j] ) / ( y[j+1] − y[j] ) ] · ( f[j+1] − f[j] )
```

Аналогічно, рухаючись від індексу `k` праворуч, знаходиться точка перетину на спадному схилі `f_high`:

```
f_high = f[m] + [ ( y_3dB − y[m] ) / ( y[m+1] − y[m] ) ] · ( f[m+1] − f[m] )
```

Смуга пропускання за рівнем `−3 дБ` та навантажена добротність:

```
BW_3dB = f_high − f_low
Q_L = f₀ / BW_3dB
```

### Покроковий числовий розбір роботи алгоритму

Розглянемо покроковий розрахунок на реальному масиві вимірювання резонансного контуру з номінальною частотою близько `10 МГц` та кроком сканування `100 кГц`:

| Індекс `i` | Частота `f[i]`, МГц | Амплітуда `y[i]` | Опис точки |
| :--- | :--- | :--- | :--- |
| `0` | `9.600` | `0.120` | Далекий лівий схил |
| `1` | `9.700` | `0.220` | Лівий схил |
| `2` | `9.800` | `0.450` | Нижче рівня -3 дБ |
| `3` | `9.900` | `0.780` | Вище рівня -3 дБ |
| `4` | `10.000` | `0.940` | Дискретний максимум `k = 4` |
| `5` | `10.100` | `0.810` | Вище рівня -3 дБ |
| `6` | `10.200` | `0.480` | Нижче рівня -3 дБ |
| `7` | `10.300` | `0.240` | Правий схил |
| `8` | `10.400` | `0.130` | Далекий правий схил |

**Крок 1: Квадратична інтерполяція піка.**
- Дискретний пік на індексі `k = 4`: `f[4] = 10.0 МГц`, `y[4] = 0.940`.
- Сусідні точки: `y[3] = 0.780`, `y[5] = 0.810`.
- Розрахунок знаменника параболи:
  `denom = y[3] − 2·y[4] + y[5] = 0.780 − 2·(0.940) + 0.810 = 0.780 − 1.880 + 0.810 = −0.290`.
- Зсув вершини:
  `δ_f = ½ · ( 0.780 − 0.810 ) / ( −0.290 ) = ½ · ( −0.030 ) / ( −0.290 ) = +0.051724`.
- Істинна резонансна частота:
  `f₀ = 10.000 МГц + 0.051724 · (0.100 МГц) = 10.00517 МГц`.
- Істинний піковий коефіцієнт передачі:
  `y_max = 0.940 − ¼ · ( 0.780 − 0.810 ) · 0.051724 = 0.940 − ¼ · ( −0.030 ) · 0.051724 = 0.94039`.

**Крок 2: Знаходження точок половинної потужності (-3 дБ).**
- Пороговий рівень:
  `y_3dB = 0.94039 · 0.707107 = 0.66495`.
- Лівий перетин (між точками `i = 2` та `i = 3`):
  `y[2] = 0.450 < 0.66495 ≤ y[3] = 0.780`.
  `frac_low = ( 0.66495 − 0.450 ) / ( 0.780 − 0.450 ) = 0.21495 / 0.330 = 0.65136`.
  `f_low = 9.800 + 0.65136 · (9.900 − 9.800) = 9.86514 МГц`.
- Правий перетин (між точками `i = 5` та `i = 6`):
  `y[5] = 0.810 ≥ 0.66495 > y[6] = 0.480`.
  `frac_high = ( 0.810 − 0.66495 ) / ( 0.810 − 0.480 ) = 0.14505 / 0.330 = 0.43955`.
  `f_high = 10.100 + 0.43955 · (10.200 − 10.100) = 10.14395 МГц`.

**Крок 3: Розрахунок добротності та параметрів еквівалентної схеми.**
- Смуга пропускання:
  `BW_3dB = 10.14395 − 9.86514 = 0.27881 МГц = 278.81 кГц`.
- Навантажена добротність:
  `Q_L = 10.00517 / 0.27881 ≈ 35.88`.
- Ненавантажена добротність з урахуванням пікового коефіцієнта передачі `T₀ = y_max = 0.94039`:
  `Q₀ = Q_L / ( 1 − T₀ ) = 35.88 / ( 1 − 0.94039 ) = 35.88 / 0.05961 ≈ 602`.
- Еквівалентний послідовний опір втрат (`Z_sys = 50 Ом`):
  `R_s = (2 · 50) · (1 − 0.94039) / 0.94039 = 100 · 0.05961 / 0.94039 ≈ 6.34 Ом`.
- Індуктивність:
  `ω₀ = 2π · 10.00517·10⁶ ≈ 6.2864·10⁷ рад/с`.
  `L = Q₀ · R_s / ω₀ = 602 · 6.34 / 6.2864·10⁷ ≈ 60.7 мкГн`.

### Реалізація алгоритму на C та C++

Наведений нижче код демонструє завершений модуль для обробки частотного сканування. Код на мові C призначений для вбудованих мікроконтролерних систем вимірювальних приладів (ARM Cortex-M, STM32, ESP32), а версія на C++ надає безпечний об'єктно-орієнтований інтерфейс з використанням сучасних стандартів (`std::span`, `std::optional`, `std::numbers`).

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <stdbool.h>

/* Результати розрахунку добротності та параметрів котушки */
typedef struct {
    double f0_hz;          /* Точна резонансна частота */
    double bw_3db_hz;      /* Смуга пропускання за рівнем -3 дБ */
    double q_loaded;       /* Навантажена добротність */
    double q_unloaded;     /* Ненавантажена (власна) добротність котушки */
    double esr_ohm;        /* Еквівалентний послідовний опір втрат (R_s) */
    double inductance_h;   /* Розрахована індуктивність на резонансі */
    bool is_valid;         /* Ознака успішного розрахунку */
} QFactorResult;

/* Структура вхідної точки вимірювання */
typedef struct {
    double freq_hz;        /* Частота генератора */
    double magnitude;      /* Амплітуда напруги або |S21| */
} SweepPoint;

/**
 * Обчислення добротності та екстракція параметрів котушки.
 * @param sweep Масив точок вимірювання (впорядкований за зростанням частоти)
 * @param count Кількість точок у масиві (мінімум 5)
 * @param z_system Характеристичний опір вимірювальної системи (типово 50.0 Ом)
 */
QFactorResult calculate_q_factor(const SweepPoint *sweep, size_t count, double z_system) {
    QFactorResult res = {0};
    if (!sweep || count < 5) {
        return res;
    }

    /* 1. Пошук грубого дискретного максимуму */
    size_t k = 0;
    double max_val = sweep[0].magnitude;
    for (size_t i = 1; i < count; ++i) {
        if (sweep[i].magnitude > max_val) {
            max_val = sweep[i].magnitude;
            k = i;
        }
    }

    /* Якщо максимум на краях діапазону — резонанс не захоплено */
    if (k == 0 || k == count - 1) {
        return res;
    }

    /* 2. Квадратична субпіксельна інтерполяція вершини */
    double y1 = sweep[k - 1].magnitude;
    double y2 = sweep[k].magnitude;
    double y3 = sweep[k + 1].magnitude;

    double denom = y1 - 2.0 * y2 + y3;
    if (fabs(denom) < 1e-15) {
        return res;
    }

    double delta = 0.5 * (y1 - y3) / denom;
    double df = sweep[k].freq_hz - sweep[k - 1].freq_hz;
    res.f0_hz = sweep[k].freq_hz + delta * df;
    double peak_mag = y2 - 0.25 * (y1 - y3) * delta;

    /* 3. Рівень половинної потужності (-3.01 дБ) */
    double target_3db = peak_mag * 0.7071067811865475;

    /* Пошук лівої межі f_low */
    double f_low = 0.0;
    bool found_low = false;
    for (size_t i = k; i > 0; --i) {
        if (sweep[i - 1].magnitude <= target_3db && sweep[i].magnitude >= target_3db) {
            double dy = sweep[i].magnitude - sweep[i - 1].magnitude;
            if (fabs(dy) > 1e-15) {
                double frac = (target_3db - sweep[i - 1].magnitude) / dy;
                f_low = sweep[i - 1].freq_hz + frac * (sweep[i].freq_hz - sweep[i - 1].freq_hz);
                found_low = true;
                break;
            }
        }
    }

    /* Пошук правої межі f_high */
    double f_high = 0.0;
    bool found_high = false;
    for (size_t i = k; i < count - 1; ++i) {
        if (sweep[i].magnitude >= target_3db && sweep[i + 1].magnitude <= target_3db) {
            double dy = sweep[i].magnitude - sweep[i + 1].magnitude;
            if (fabs(dy) > 1e-15) {
                double frac = (sweep[i].magnitude - target_3db) / dy;
                f_high = sweep[i].freq_hz + frac * (sweep[i + 1].freq_hz - sweep[i].freq_hz);
                found_high = true;
                break;
            }
        }
    }

    if (!found_low || !found_high || f_high <= f_low) {
        return res;
    }

    /* 4. Розрахунок смуги та добротності */
    res.bw_3db_hz = f_high - f_low;
    res.q_loaded = res.f0_hz / res.bw_3db_hz;

    /* Корекція навантаження системи для трансмісійного методу S21 */
    /* Коефіцієнт передачі на резонансі T_0 = peak_mag */
    double t0 = (peak_mag > 1.0) ? 1.0 : peak_mag;
    if (t0 > 0.001) {
        /* Власна ненавантажена добротність: Q0 = Q_L / (1 - T_0) */
        res.q_unloaded = res.q_loaded / (1.0 - t0);
        /* Еквівалентний послідовний опір втрат */
        res.esr_ohm = (2.0 * z_system) * (1.0 - t0) / t0;
    } else {
        res.q_unloaded = res.q_loaded;
        res.esr_ohm = 2.0 * z_system;
    }

    /* Індуктивність: L = Q0 * ESR / (2 * pi * f0) */
    double omega0 = 2.0 * 3.141592653589793 * res.f0_hz;
    res.inductance_h = (res.q_unloaded * res.esr_ohm) / omega0;
    res.is_valid = true;

    return res;
}

int main(void) {
    /* Демонстраційний масив сканування контуру з f0 = 10 МГц */
    SweepPoint data[] = {
        { 9.6e6, 0.120 },
        { 9.7e6, 0.220 },
        { 9.8e6, 0.450 },
        { 9.9e6, 0.780 },
        { 10.0e6, 0.940 },
        { 10.1e6, 0.810 },
        { 10.2e6, 0.480 },
        { 10.3e6, 0.240 },
        { 10.4e6, 0.130 }
    };
    size_t n = sizeof(data) / sizeof(data[0]);

    QFactorResult r = calculate_q_factor(data, n, 50.0);
    if (r.is_valid) {
        printf("Резонансна частота f0 : %.4f МГц\n", r.f0_hz / 1e6);
        printf("Смуга пропускання BW  : %.2f кГц\n", r.bw_3db_hz / 1e3);
        printf("Навантажена Q_L       : %.1f\n", r.q_loaded);
        printf("Власна добротність Q0 : %.1f\n", r.q_unloaded);
        printf("Втрати котушки ESR    : %.3f Ом\n", r.esr_ohm);
        printf("Індуктивність L       : %.2f мкГн\n", r.inductance_h * 1e6);
    } else {
        printf("Помилка розрахунку добротності: резонанс не знайдено.\n");
    }
    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <optional>
#include <span>
#include <numbers>
#include <iomanip>

struct SweepPoint {
    double freq_hz{0.0};
    double magnitude{0.0};
};

struct QFactorResult {
    double f0_hz{0.0};
    double bw_3db_hz{0.0};
    double q_loaded{0.0};
    double q_unloaded{0.0};
    double esr_ohm{0.0};
    double inductance_h{0.0};
};

class QMeterDSP {
public:
    [[nodiscard]] static std::optional<QFactorResult> calculate(
        std::span<const SweepPoint> sweep,
        double z_system = 50.0) noexcept
    {
        if (sweep.size() < 5) {
            return std::nullopt;
        }

        // 1. Пошук грубого дискретного піка
        size_t k = 0;
        double max_val = sweep[0].magnitude;
        for (size_t i = 1; i < sweep.size(); ++i) {
            if (sweep[i].magnitude > max_val) {
                max_val = sweep[i].magnitude;
                k = i;
            }
        }

        if (k == 0 || k == sweep.size() - 1) {
            return std::nullopt;
        }

        // 2. Параболічна інтерполяція вершини
        const double y1 = sweep[k - 1].magnitude;
        const double y2 = sweep[k].magnitude;
        const double y3 = sweep[k + 1].magnitude;

        const double denom = y1 - 2.0 * y2 + y3;
        if (std::abs(denom) < 1e-15) {
            return std::nullopt;
        }

        const double delta = 0.5 * (y1 - y3) / denom;
        const double df = sweep[k].freq_hz - sweep[k - 1].freq_hz;
        const double f0 = sweep[k].freq_hz + delta * df;
        const double peak_mag = y2 - 0.25 * (y1 - y3) * delta;

        // 3. Рівень -3 дБ
        constexpr double inv_sqrt2 = 0.7071067811865475;
        const double target_3db = peak_mag * inv_sqrt2;

        // Пошук лівої точки f_low
        std::optional<double> f_low;
        for (size_t i = k; i > 0; --i) {
            if (sweep[i - 1].magnitude <= target_3db && sweep[i].magnitude >= target_3db) {
                const double dy = sweep[i].magnitude - sweep[i - 1].magnitude;
                if (std::abs(dy) > 1e-15) {
                    const double frac = (target_3db - sweep[i - 1].magnitude) / dy;
                    f_low = sweep[i - 1].freq_hz + frac * (sweep[i].freq_hz - sweep[i - 1].freq_hz);
                    break;
                }
            }
        }

        // Пошук правої точки f_high
        std::optional<double> f_high;
        for (size_t i = k; i < sweep.size() - 1; ++i) {
            if (sweep[i].magnitude >= target_3db && sweep[i + 1].magnitude <= target_3db) {
                const double dy = sweep[i].magnitude - sweep[i + 1].magnitude;
                if (std::abs(dy) > 1e-15) {
                    const double frac = (sweep[i].magnitude - target_3db) / dy;
                    f_high = sweep[i].freq_hz + frac * (sweep[i + 1].freq_hz - sweep[i].freq_hz);
                    break;
                }
            }
        }

        if (!f_low || !f_high || *f_high <= *f_low) {
            return std::nullopt;
        }

        // 4. Розрахунок підсумкових параметрів
        QFactorResult res;
        res.f0_hz = f0;
        res.bw_3db_hz = *f_high - *f_low;
        res.q_loaded = res.f0_hz / res.bw_3db_hz;

        const double t0 = std::min(peak_mag, 1.0);
        if (t0 > 0.001) {
            res.q_unloaded = res.q_loaded / (1.0 - t0);
            res.esr_ohm = (2.0 * z_system) * (1.0 - t0) / t0;
        } else {
            res.q_unloaded = res.q_loaded;
            res.esr_ohm = 2.0 * z_system;
        }

        const double omega0 = 2.0 * std::numbers::pi * res.f0_hz;
        res.inductance_h = (res.q_unloaded * res.esr_ohm) / omega0;

        return res;
    }
};

int main() {

        { 9.6e6, 0.120 },
        { 9.7e6, 0.220 },
        { 9.8e6, 0.450 },
        { 9.9e6, 0.780 },
        { 10.0e6, 0.940 },
        { 10.1e6, 0.810 },
        { 10.2e6, 0.480 },
        { 10.3e6, 0.240 },
        { 10.4e6, 0.130 }
    };

    if (const auto res = QMeterDSP::calculate(data, 50.0)) {
```

### Типові інженерні пастки та джерела похибок

Під час практичної реалізації алгоритму вимірювання добротності необхідно враховувати чотири фундаментальні фізичні джерела похибок:

#### 1. Демпфувальний вплив внутрішнього опору вимірювальних портів (Loading Effect)
Якщо котушку підключити до 50-омного виходу генератора та 50-омного входу осцилографа чи аналізатора спектра без спеціальних заходів розв'язки, сумарний опір демпфування контуру становитиме `100 Ом`. Для котушки з індуктивністю `10 мкГн` на частоті `10 МГц` власний реактивний опір становить `X_L ≈ 628 Ом`. Якщо власний опір втрат котушки дорівнює `R_s = 1.5 Ом` (що відповідає чудовій власній добротності `Q₀ ≈ 418`), підключення приладу збільшує опір до `1.5 + 100 = 101.5 Ом`. Виміряна добротність контуру становитиме:

```
Q_L = 628 / 101.5 ≈ 6.18
```

Похибка вимірювання сягає майже `7000%`! Щоб отримати достовірні результати, обов'язково застосовують:
- ємнісні атенюатори з пікофарадними конденсаторами зв'язку;
- витковий зв'язок (1–2 витки зв'язку поверх обмотки);
- високоомні активні FET-пробники з вхідною ємністю `< 0.5 пФ` та вхідним опором `> 1 МОм`.

#### 2. Паразитна індуктивність та ємність клем вимірювального стенда (Fixture De-embedding)
Будь-який вимірювальний роз'єм, контактна колодка або контактні голки додають паразитні параметри:
- власну індуктивність виводів `L_fixture` (типово `1–2 нГн` на кожен міліметр довжини провідника);
- паразитну міжелектродну ємність `C_fixture` (`0.2–1.5 пФ`);
- контактний опір `R_contact` (`10–50 мОм`).

Для прецизійного вимірювання застосовують алгоритм матричного виключення оснастки (*De-embedding*). Перед вимірюванням котушки виконують калібрування стенда у трьох станах:
1. `OPEN` (розірвані клеми без котушки): вимірюється паразитний вектор провідності `Y_open = G_open + j·ω·C_fixture`.
2. `SHORT` (клеми замкнені прецизійною нульовою перемичкою): вимірюється послідовний паразитний імпеданс `Z_short = R_contact + j·ω·L_fixture`.
3. `DUT` (підключена досліджувана деталь): вимірюється сумарний сирий імпеданс `Z_meas`.

Істинний імпеданс котушки `Z_coil` обчислюється матричним відніманням:

```
Z_coil = [ ( Z_meas − Z_short )⁻¹ − Y_open ]⁻¹
```

Ця процедура дозволяє вимірювати високодобротні SMD-індуктивності на частотах до `3 ГГц` без систематичного заниження добротності.

#### 3. Діелектричні втрати друкованої плати та оснастки
При тестуванні планарних або SMD-котушок на частотах понад `100 МГц` матеріал діелектрика тестової плати стає критичним. Звичайний склотекстоліт `FR-4` має високий тангенс кута втрат `tan(δ_d) ≈ 0.02`. Паразитна ємність між контактними майданчиками та земляним полігоном (навіть `0.3 пФ`) на частоті `500 МГц` створює шунтувальний активний опір `R_p = 1 / (2π · 5·10⁸ · 0.3·10⁻¹² · 0.02) ≈ 53 кОм`. Для високодобротних резонаторів цей опір обмежує добротність величиною `Q_max ≈ 1 / tan(δ_d) = 50`. Для вимірювання надвисоких добротностей тестові плати виготовляють виключно на високочастотних ламінатах (Rogers RO4350B, фторопласт PTFE або кераміка Al₂O₃), де `tan(δ_d) < 0.001`.

#### 4. Нелінійні втрати в осерді від амплітуди вимірювального сигналу
У котушках із феритовими та залізопорошковими осердями площа петлі гістерезису та магнітна проникність `μ` залежать від напруженості поля `H`. Якщо вимірювач подає занадто високу амплітуду струму (понад `10–50 мА`), магнітний матеріал входить у нелінійну ділянку, втрати гістерезису різко зростають, а виміряна добротність падає. Для метрологічної чистоти вимірювання `Q` завжди проводять при рівнях збудження не більше `−10 дБм` (`100 мкВт`, приблизно `70 мВ RMS` на навантаженні `50 Ом`).

#### 5. Температурний дрейф опору міді під час тестування
Температурний коефіцієнт опору міді становить `α_cu ≈ +0.393% / °C`. Якщо котушка випробовується під помірним струмом і нагрівається на `25 °C` відносно кімнатної температури, її омічний опір `R_dc` зростає майже на `10%`, викликаючи відповідне спадання добротності. Тому прецизійні вимірювання виконують короткими радіоімпульсами або в термостатованих камерах.

#### 6. Архітектура апаратного вимірювача на базі мікроконтролера
Для створення автономного лабораторного Q-метра на базі мікроконтролера STM32 або ESP32 типова апаратна архітектура включає:
- генератор прямого цифрового синтезу (DDS) на мікросхемі AD9833 (до 12.5 МГц) або генератор Si5351 (до 200 МГц) для покрокового сканування частоти;
- буферний підсилювач із низьким вихідним опором та фіксованим коефіцієнтом підсилення;
- прецизійний логарифмічний детектор AD8307 або піковий детектор на швидких діодах Шотткі (BAT15, 1N5711) для перетворення амплітуди ВЧ-напруги на постійну напругу;
- вбудований 12-бітний або 16-бітний АЦП мікроконтролера, що зчитує вихід детектора по закінченню перехідного процесу на кожній частоті сканування.

Описаний алгоритм виконується безпосередньо в оперативній пам'яті мікроконтролера за частки мілісекунди після завершення циклу сканування, забезпечуючи миттєве відображення резонансної частоти, власної добротності `Q₀` та опору `ESR` на графічному дисплеї приладу.
