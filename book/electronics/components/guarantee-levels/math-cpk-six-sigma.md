# 🧮 Математика Six Sigma: як розрахувати довірчі межі та індекс Cpk

Коли в технічному описі мікросхеми зазначено гарантований діапазон параметра без проведення суцільного заводського вимірювання кожного чіпа, ця гарантія спирається на статистичну оцінку відтворюваності технологічного процесу через індекси `Cp` та `Cpk`, які пов'язують розкид вимірювань у сигмах із гранично допустимим рівнем браку в одиницях PPM *(англ. parts per million — «часток на мільйон»)*. Математичний апарат статистичного контролю якості дозволяє точно обчислити, з якою ймовірністю кристал вийде за межі специфікації при зміні температури чи напруги живлення, та який запас точності повинен мати фабричний тестер для відсікання дефектів.

### Гаусовий розподіл параметрів кремнієвої пластини

Виробництво напівпровідникових структур підпорядковується законам математичної статистики. Товщина діелектрика, концентрація легуючих домішок, ширина каналу польового транзистора та опір полікремнієвих резисторів коливаються від кристала до кристала під впливом сотень незалежних фізичних факторів. За центральною граничною теоремою теорії ймовірностей, сукупна дія великої кількості незалежних випадкових флуктуацій формує нормальний (гаусовий) розподіл вихідного електричного параметра `X`.

Густина ймовірності неперервної випадкової величини `X` описується класичною функцією Гауса:

```
f(x) = (1 / (σ · √(2·π))) · exp(−(x − μ)² / (2·σ²))
```

де:
* `μ` (мю) — математичне сподівання (середнє значення параметра по генеральній сукупності виготовлених кристалів);
* `σ` (сигма) — генеральне стандартне відхилення, що характеризує ширину статистичного розкиду технологічного процесу;
* `σ²` — дисперсія випадкової величини.

Під час випробування вибірки обсягом `n` кристалів невідомі генеральні параметри `μ` та `σ` оцінюються через вибіркове середнє `x̄` та вибіркове стандартне відхилення `s`:

```
x̄ = (1 / n) · ∑ x[i]              [i від 1 до n]

s = √( (1 / (n − 1)) · ∑ (x[i] − x̄)² )
```

У нормальному розподілі площа під кривою густини ймовірності визначає частку кристалів, значення параметра яких потрапляє у заданий числовий інтервал. Для симетричних інтервалів відносно центру `μ` діє правило розмаху сигм:

```
P(μ − 1·σ ≤ X ≤ μ + 1·σ) ≈ 0.6827      [68.27 % придатних кристалів]
P(μ − 2·σ ≤ X ≤ μ + 2·σ) ≈ 0.9545      [95.45 % придатних кристалів]
P(μ − 3·σ ≤ X ≤ μ + 3·σ) ≈ 0.9973      [99.73 % придатних кристалів]
P(μ − 4·σ ≤ X ≤ μ + 4·σ) ≈ 0.999937    [брак = 63 PPM]
P(μ − 5·σ ≤ X ≤ μ + 5·σ) ≈ 0.99999943  [брак = 0.57 PPM]
P(μ − 6·σ ≤ X ≤ μ + 6·σ) ≈ 0.999999998 [брак = 0.002 PPM]
```

### Довірчі інтервали та похибка вибірки малого обсягу

Під час первинної кваліфікації інженер оперує обмеженою вибіркою обсягом `n` кристалів. Оскільки вибіркове середнє `x̄` та стандартне відхилення `s` самі є випадковими величинами, справжні параметри генеральної сукупності `μ` та `σ` оцінюються через довірчі інтервали за допомогою розподілу Стьюдента та хі-квадрат розподілу:

1. **Довірчий інтервал для середнього значення `μ` з довірчою ймовірністю `1 − α` (типово 95 % або 99 %):**
```
x̄ − t(α/2, n−1) · (s / √n) ≤ μ ≤ x̄ + t(α/2, n−1) · (s / √n)
```
де `t(α/2, n−1)` — квантиль розподілу Стьюдента з `n − 1` ступенями вільності.

2. **Довірчий інтервал для стандартного відхилення `σ`:**
```
s · √((n − 1) / χ²(α/2, n−1)) ≤ σ ≤ s · √((n − 1) / χ²(1 − α/2, n−1))
```

Для того щоб похибка оцінки стандартного відхилення `s` не перевищувала 5 % при довірчій ймовірності 95 %, обсяг кваліфікаційної вибірки `n` повинен становити щонайменше 800–1000 кристалів з різних технологічних партій.

### Індекси придатності процесу: Cp та Cpk

Для інженерного опису якості фабрика встановлює два пороги специфікації в даташиті: нижню межу допуску `LSL` *(англ. Lower Specification Limit)* та верхню межу допуску `USL` *(англ. Upper Specification Limit)*. Ширина дозволеного паспортного вікна становить `USL − LSL`.

Індекс потенційної придатності процесу `Cp` показує відношення ширини паспортного поля допуску до природного розкиду технологічного процесу, що оцінюється як шість стандартних відхилень `6·σ`:

```
Cp = (USL − LSL) / (6·σ)
```

Індекс `Cp` оцінює лише розмах розподілу і нічого не каже про те, де саме розташований центр цього розподілу. Якщо технологічний процес змістився вбік і середнє `μ` підійшло впритул до верхньої межі `USL`, значення `Cp` може залишатися високим, проте фабрика випускатиме суцільний брак.

Тому для реальної оцінки застосовують індекс критичної придатності `Cpk`, який враховує центрованість процесу відносно обох меж специфікації:

```
Cpu = (USL − μ) / (3·σ)          [придатність відносно верхньої межі]

Cpl = (μ − LSL) / (3·σ)          [придатність відносно нижньої межі]

Cpk = min(Cpu, Cpl)
```

Зв'язок між числовим значенням `Cpk` та якістю мікросхем має прямий практичний зміст:
* `Cpk < 1.0` — процес непридатний, ширина розкиду `3·σ` перевищує відстань до найближчої межі специфікації; рівень дефектності перевищує 2700 PPM;
* `Cpk = 1.0` — граничний стан («три сигми»), край розсіювання `μ ± 3·σ` торкається межі специфікації; очікуваний брак становить 1350 PPM на один бік (2700 PPM сумарно);
* `Cpk = 1.33` — стандартний комерційний рівень («чотири сигми»), дефектність становить менше 63 PPM;
* `Cpk = 1.67` — високонадійний рівень («п'ять сигм»), дефектність менше 0.57 PPM;
* `Cpk ≥ 2.0` — світовий стандарт якості Six Sigma («шість сигм»), за якого межа даташита віддалена від середнього значення на відстань `6·σ`.

### Односторонні специфікації та індекс Cpm (Тагучі)

Для багатьох напівпровідникових характеристик фізично нормується лише одна межа допуску:
* для напруги насичення або спаду напруги LDO `V_drop` існує лише верхня межа `USL` (чим ближче до 0, тим краще);
* для коефіцієнта підсилення транзистора `hFE` нормується лише нижня межа `LSL`.

У цьому випадку індекс придатності збігається з відповідною односторонньою оцінкою:
```
Cpk = (USL − μ) / (3·σ)      [для параметрів із верхньою межею]
Cpk = (μ − LSL) / (3·σ)      [для параметрів із нижньою межею]
```

Якщо розробник має цільове значення номіналу `T` *(Target)*, для оцінки втрат якості за функцією Тагучі використовують індекс `Cpm`:
```
Cpm = (USL − LSL) / (6 · √(σ² + (μ − T)²))
```
Індекс `Cpm` суворо карає технологічний процес за будь-яке відхилення середнього `μ` від ідеального цільового центру `T`, навіть якщо весь розкид лежить далеко від меж браку.

### Модель довготривалого дрейфу на 1.5 Сигма

У реальному фабричному виробництві температура в реакторах хімічного осадження пари, знос фотошаблонів, коливання атмосферного тиску та зміна партій кремнієвих злитків спричиняють повільне блукання середнього значення процесу з плином місяців і років.

Емпіричні дослідження компанії Motorola показали, що на тривалих часових інтервалах середнє значення `μ` будь-якого напівпровідникового параметра може дрейфувати на величину до `1.5·σ` в один або інший бік від номінального центру.

З урахуванням цього температурно-технологічного зміщення індекс `Cpk` при початковому розрахунку `6·σ` знижується з `2.0` до `1.5`:

```
Cpk_long_term = (6·σ − 1.5·σ) / (3·σ)      [врахування зсуву середнього на 1.5·σ]
              = 4.5·σ / (3·σ)              [віднімання зсуву від запасу 6·σ]
              = 1.5                        [скорочення виразу на 3·σ]
```

Для процесу зі зсувом на `1.5·σ` ефективна відстань від зміщеного центру до найближчої межі специфікації становить `4.5·σ`. Ймовірність того, що випадкова величина перевищить рівень `4.5·σ`, визначається через функцію стандартизованого нормального розподілу Лапласа:

```
P(X > USL) = 1 − Φ(4.5) ≈ 3.397 · 10⁻⁶ ≈ 3.4 PPM
```

Саме з цього строгого математичного розрахунку виникає фундаментальна константа напівпровідникової надійності: технологічний процес рівня Six Sigma навіть за найнесприятливішого довготривалого дрейфу генерує не більше **3.4 дефектів на один мільйон виготовлених чіпів** (3.4 DPM / PPM).

### Дисперсійний аналіз компонентів варіації (ANOVA та Gage R&R)

Сумарна дисперсія виміряного параметра `σ²_total` складається з фізичної мінливості напівпровідника та похибки самого вимірювального тракту тестера:

```
σ²_total = σ²_process + σ²_gage
```

де:
* `σ²_process = σ²_lot_to_lot + σ²_wafer_to_wafer + σ²_die_to_die` — фізична дисперсія між партіями, між пластинами в партії та між кристалами на одній пластині;
* `σ²_gage = σ²_repeatability + σ²_reproducibility` — метрологічна похибка повторюваності (похибка приладу) та відтворюваності (похибка контактування та оператора).

Стандарт SEMI E10 вимагає, щоб похибка вимірювальної системи `σ_gage` не перевищувала 10 % від ширини допуску даташита `(USL − LSL)`. Якщо `σ_gage` перевищує 30 %, тестер вважається непридатним для статистичної кваліфікації.

### Багатовимірний статистичний аналіз (відстань Махаланобіса)

У складних аналогових чіпах електричні параметри є взаємопов'язаними: наприклад, струм спокою `Iq` корелює зі смугою підсилення `GBW` та швидкістю наростання `SR`. Одновимірний аналіз кожного параметра окремо може пропустити аномальний чіп, у якого кожен параметр лежить у межах `3·σ`, проте комбінація значень є фізично неможливою для справної топології.

Для багатовимірної оцінки застосовують відстань Махаланобіса `D_M`:

```
D_M(x) = √( (x − μ)ᵀ · Σ⁻¹ · (x − μ) )
```

де:
* `x` — вектор виміряних параметрів кристала;
* `μ` — вектор середніх значень;
* `Σ` — коваріаційна матриця процесу.

Якщо `D_M²` перевищує квантиль хі-квадрат розподілу `χ²(p, 0.999)`, кристал відсікається як багатовимірний викид.

### Робота з ненормальними розподілами (струми витоку та перетворення Бокса-Кокса)

Деякі напівпровідникові характеристики за своєю фізичною природою мають різко асиметричний розподіл. Наприклад, струми витоку `I_leak` та час пробою діелектрика під напругою (TDDB) підпорядковуються логнормальному розподілу або розподілу Вейбулла.

Для коректного застосування індексів `Cpk` виконують степеневе перетворення Бокса-Кокса *(Box-Cox transformation)*:

```
y = (x^λ − 1) / λ       [при λ ≠ 0]
y = ln(x)               [при λ = 0, логарифмічне перетворення]
```

Параметр `λ` підбирається методом максимальної правдоподібності так, щоб трансформована змінна `y` мала класичний симетричний розподіл Гауса. Розрахунок `Cpk` проводиться над трансформованими даними `y`, після чого межі специфікації переводяться назад у фізичні одиниці мікроамперів або секунд.

### Статистичне підсумовування похибок у схемотехніці: WCCA проти RSS

Під час проєктування багатокаскадного аналогового тракту інженер розраховує результуючу похибку від кількох компонентів (наприклад, трьох операційних підсилювачів, джерела опорної напруги та резистивного дільника).

Існує два методи розрахунку найгіршого випадку:

1. **Абсолютний найгірший випадок (Extreme Value Analysis, EVA):**
   Передбачає, що всі компоненти схеми одночасно відхилилися до своїх крайніх паспортних меж `Max` в один бік:
   ```
   ΔV_total_eva = |ΔV_1| + |ΔV_2| + |ΔV_3| + ... + |ΔV_k|
   ```
   Цей підхід є надмірно песимістичним, оскільки ймовірність одночасного збігу країв розподілу `6·σ` для п'яти незалежних компонентів становить `(3.4 · 10⁻⁶)⁵ ≈ 4.5 · 10⁻²⁸` (практично нуль).

2. **Середньоквадратичне статистичне сумування (Root-Sum-Square, RSS):**
   Спирається на те, що компоненти зі статусом Guaranteed by Characterization мають незалежні гаусові розподіли:
   ```
   ΔV_total_rss = √( (ΔV_1)² + (ΔV_2)² + (ΔV_3)² + ... + (ΔV_k)² )
   ```
   Розрахунок за методом RSS дає реалістичну оцінку сумарного розкиду системи на рівні `3·σ_system`, дозволяючи створювати високоточні прилади без необґрунтованого здорожчання схемотехніки.

### Порівняння аналітичного розрахунку та симуляції Монте-Карло

У прецизійному моделюванні SPICE аналітичні формули RSS доповнюються прямим числовим методом Монте-Карло:
* Генератор псевдовипадкових чисел запускає `N = 10 000` ітерацій розрахунку схеми.
* Для кожного резистора, конденсатора та транзистора генерується випадкове значення відповідно до його кваліфікаційного закону розподілу Гауса `N(μ, σ)` та кореляційної матриці кристала.
* Будується вихідна гістограма результуючої похибки схеми.

Якщо 99.73 % згенерованих точок вкладаються у вимоги системного бюджету похибок, схема вважається успішно верифікованою за стандартом Six Sigma.

### Практичний розрахунок: кваліфікація опорного джерела напруги

Розглянемо реальну інженерну задачу кваліфікації мікросхеми прецизійного джерела опорної напруги *(bandgap reference)* з номінальним виходом 2.500 В для надання параметру статусу «Guaranteed by Characterization» у діапазоні температур від −40 °C до +125 °C.

**Вихідні умови специфікації:**
* Номінальна напруга: `V_nom = 2.500 В`;
* Допуск за даташитом: `±5.0 мВ` (`±0.2 %`);
* Нижня межа специфікації: `LSL = 2.4950 В`;
* Верхня межа специфікації: `USL = 2.5050 В`.

**Дані кваліфікаційного випробування:**
Під час кваліфікації з трьох технологічних партій (split lots), виготовлених на крайніх кутах техпроцесу (Fast-Fast, Slow-Slow, Nominal), відібрано вибірку обсягом `n = 1000` чіпів. Вимірювання вихідної напруги в кліматичній камері при екстремальній температурі +125 °C дали такі результати:
* Вибіркове середнє: `x̄ = 2.5009 В`;
* Вибіркове стандартне відхилення: `s = 0.00065 В` (0.65 мВ).

**Покрокове обчислення придатності процесу:**

1. Обчислення загального індексу `Cp`:
```
Cp = (USL − LSL) / (6·s)
   = (2.5050 − 2.4950) / (6 · 0.00065)       [підстановка меж і сигми]
   = 0.0100 / 0.00390
   ≈ 2.564                                  [запас поля допуску понад 2.5 раза]
```

2. Обчислення односторонніх індексів `Cpu` та `Cpl`:
```
Cpu = (USL − x̄) / (3·s)
    = (2.5050 − 2.5009) / (3 · 0.00065)     [відстань до верхньої межі]
    = 0.0041 / 0.00195
    ≈ 2.103

Cpl = (x̄ − LSL) / (3·s)
    = (2.5009 − 2.4950) / (3 · 0.00065)     [відстань до нижньої межі]
    = 0.0059 / 0.00195
    ≈ 3.026
```

3. Обчислення підсумкового індексу критичної придатності `Cpk`:
```
Cpk = min(Cpu, Cpl)
    = min(2.103, 3.026)
    = 2.103                                 [визначається ближчою верхньою межею]
```

4. Розрахунок стандартизованого Z-відхилення для найгіршого випадку:
```
Z_upper = (USL − x̄) / s
        = (2.5050 − 2.5009) / 0.00065
        = 0.0041 / 0.00065
        ≈ 6.308                             [верхня межа віддалена на 6.31 сигми]
```

**Інженерний висновок:**
Оскільки отримане значення `Cpk = 2.103` перевищує нормативний поріг `2.0`, а найближча межа віддалена на `6.31·σ`, математична ймовірність виходу вихідної напруги за межі `[2.4950 В, 2.5050 В]` при температурі +125 °C становить менше `1.4 · 10⁻¹⁰` (менше однієї бракованої мікросхеми на 7 мільярдів).

Виробник отримує повне математичне та юридичне право внести діапазон `2.495 В ... 2.505 В` у таблицю Electrical Characteristics із позначкою «Guaranteed by Characterization over −40 °C to +125 °C» і не витрачати кошти на нагрівання кожного окремого чіпа на конвеєрі під час серійного виробництва.

### Метрологічний Guardbanding заводського тестера

Під час проведення 100% суцільного тестування при кімнатній температурі +25 °C сам автоматичний вимірювальний комплекс ATE володіє власною апаратною похибкою вимірювання `σ_ate`.

Якщо вимірюваний чіп має реальний параметр, що лежить упритул до межі специфікації `USL`, випадковий шум тестера може призвести до двох типів помилок:
1. **Помилка I роду (ризик виробника, α):** придатний чіп виміряно з додатною похибкою, внаслідок чого тестер відправляє справний кристал у брак.
2. **Помилка II роду (ризик споживача, β):** дефектний чіп із параметром вище `USL` виміряно з від'ємною похибкою, внаслідок чого бракований чіп потрапляє замовнику.

Щоб повністю виключити ризик споживача, напівпровідникові стандарти (зокрема IEEE 1490 та SEMI E10) вимагають застосування захисної смуги — гардингу *(англ. Guardbanding)*. Апаратні межі відбраковування на тестері `LTL` *(Lower Test Limit)* та `UTL` *(Upper Test Limit)* звужують відносно паспортних меж даташита на величину невизначеності вимірювання `U_ate = 3·σ_ate`:

```
UTL = USL − 3·σ_ate

LTL = LSL + 3·σ_ate
```

```
Повне поле допуску даташита:  [LSL ──────────────────────────────────────── USL]
Апаратні межі тестера ATE:         [LTL ──────────────────────────── UTL]
Захисні смуги Guardband:      |← 3·σ_ate →|                       |← 3·σ_ate →|
```

Завдяки гардингу будь-який кристал, який пройшов 100% заводський контроль (рівень `100% Production Tested`), гарантовано задовольняє паспортним межам `[LSL, USL]` навіть за найнесприятливішого збігу похибок вимірювальної апаратури.

### Зв'язок індексу Cpk із рівнем браку (PPM)

У промисловій статистиці розраховано сувору таблицю відповідності між значенням `Cpk` та рівнем дефектності (із врахуванням зсуву на 1.5 сигми та без нього):
