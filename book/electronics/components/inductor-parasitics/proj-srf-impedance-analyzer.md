# ⚙️ Алгоритм екстракції паразитів котушки за S-параметрами VNA

Точне експериментальне визначення паразитної ємності EPC, опору втрат осердя та власної резонансної частоти SRF реальних котушок індуктивності здійснюється шляхом вимірювання комплексного коефіцієнта відбиття S11 на векторному аналізаторі кіл (VNA) або імпедансному спектрометрі. Оскільки сирі дані векторного аналізатора являють собою лише таблицю дійсної та уявної частин розсіювання S11 на дискретній сітці частот, інженеру необхідний числовий алгоритм для автоматичної екстракції зосереджених параметрів еквівалентної схеми заміщення (L, DCR, EPC, R_core, Q_max).

Нижче наведено повний теоретичний опис вимірювального процесу, апаратні принципи побудови вимірювального тракту, порівняння з автобалансними мостами, аналіз похибок калібрування, детальну інтерпретацію діаграми Сміта, аналіз метрологічних похибок за діапазонами, обробку крайових випадків та завершену реалізацію алгоритму числової екстракції параметрів на мовах C та C++.

---

### Фізичні основи вимірювання імпедансу на VNA

Векторний аналізатор кіл генерує зондувальний синусоїдальний сигнал частотою `f` за допомогою цифрового синтезатора прямого синтезу (DDS) або фазового автопідстроювання частоти (PLL). Цей сигнал спрямовується через вимірювальний міст або спрямований відгалужувач із спрямованістю 35–45 дБ у вимірювальний порт. Частина падаючої хвилі напруги `a_1` відбивається від підключеної котушки індуктивності у вигляді відбитої хвилі `b_1`.

Обидві хвилі потрапляють на квадратурні змішувачі, де перемножуються з опорним гетеродинним сигналом і переносяться на низьку проміжну частоту (IF) від 1 кГц до 100 кГц. Високорозрядні аналого-цифрові перетворювачі (АЦП) з динамічним діапазоном понад 100–120 дБ вимірюють синфазну (I) та квадратурну (Q) складові сигналу, обчислюючи амплітуду та фазовий зсув.

Комплексний коефіцієнт відбиття (параметр розсіювання S11) визначається як відношення амплітуд та фаз відбитої та падаючої хвиль:

```
S11(f) = b_1 / a_1 = |S11| · exp( j · φ ) = S_re + j · S_im
```

Коли котушка є чисто індуктивною (`X_L >> R`), весь сигнал відбивається з фазовим зсувом `+90°` (`S11 ≈ +j`). У точці антирезонансу на частоті SRF, де модуль імпедансу досягає максимуму (десятки кілоом), сигнал відбивається практично у фазі (`S11 ≈ +1.0`). У високочастотній ємнісній зоні фаза відбиття переходить у від'ємну півплощину (`S11 ≈ -j`).

### Траєкторія індуктивності на діаграмі Вольперта-Сміта

Діаграма Сміта відображає комплексну площину коефіцієнта відбиття `S11` всередині одиничного кола `|S11| ≤ 1`:
1. **Низькі частоти (`f → 0`):** Точка імпедансу починається на дійсній осі поблизу лівого краю короткого замикання на рівні `R = DCR`.
2. **Індуктивна область:** Зі зростанням частоти крива рухається за годинниковою стрілкою вздовж верхнього зовнішнього кола діаграми в області додатної реактивності `+jX`.
3. **Точка власного резонансу SRF:** Траєкторія наближається до крайнього правого полюса розриву кола (`Z → ∞`, `S11 → +1.0`), перетинаючи дійсну вісь строго при нульовій реактивності `X = 0`.
4. **Ємнісна зона:** Після проходження SRF крива опускається в нижню півплощину від'ємної реактивності `-jX` (ємнісний опір) і прямує до точки короткого замикання на надвисоких частотах.

### Методи вимірювання: рефлектометрія VNA проти автобалансного моста

В інженерній практиці дослідження імпедансу індуктивностей використовуються два фундаментальні приладові підходи:
1. **Автобалансний міст (Auto-Balancing Bridge):** Використовує 4-термінальне підключення (Four-Terminal Pair, 4TP) з виводами струму (Hc, Lc) та потенціалу (Hp, Lp). Струм зразка компенсується віртуальною землею прецизійного трансімпедансного операційного підсилювача. Забезпечує найвищу точність (до 0.05%) на частотах від 20 Гц до 120 МГц, однак на частотах понад 100–150 МГц швидкість наростання та фазовий зсув підсилювача зворотного зв'язку обмежують працездатність схеми.
2. **Векторна рефлектометрія (VNA RF Reflectometry):** Базується на 1-портовому або 2-портовому вимірюванні розсіювання S-параметрів у 50-омному тракті. Дозволяє проводити вимірювання в гігагерцовому діапазоні (від 100 кГц до 6–20 ГГц), що є критично важливим для точного знаходження власного резонансу SRF високочастотних дроселів та феритових бусин.

### Процедура калібрування SOLT та 12-елементна модель похибок

Для усунення систематичних апаратних похибок кабелів, атенюаторів та внутрішніх відгалужувачів перед початком вимірювань обов'язково проводиться повне 1-портове калібрування за методом SOLT (Short — коротке замикання, Open — розрив, Load — прецизійне навантаження 50.0 Ом).

Граф проходження сигналів векторного приймача містить три фундаментальні коефіцієнти систематичної похибки:
1. **Пряма спрямованість `e_00` (Directivity):** Паразитний сигнал витоку з джерела безпосередньо у приймач повз вимірювальний порт.
2. **Неузгодженість джерела `e_11` (Source Match):** Повторне відбиття відбитої від котушки хвилі назад у порт аналізатора.
3. **Частотне стеження відбиття `e_10 · e_01` (Reflection Tracking):** Комплексна частотна нерівномірність коефіцієнта передачі змішувачів і кабелів.

Зв'язок між виміряним коефіцієнтом `S11_meas` та істинним фізичним коефіцієнтом відбиття котушки `S11_actual` описується рівнянням:

```
S11_meas = e_00 + ( e_10 · e_01 · S11_actual ) / ( 1 - e_11 · S11_actual )
```

Вимірюючи три еталонні навантаження з точно відомими параметрами (`S11_open = +1`, `S11_short = -1`, `S11_load = 0`), мікроконтролер VNA знаходить невідомі коефіцієнти `e_00`, `e_11` та `e_10·e_01`. Після цього для кожного виміряного зразка істинне значення обчислюється аналітично:

```
S11_actual = ( S11_meas - e_00 ) / ( e_10 · e_01 + e_11 · (S11_meas - e_00) )
```

### Де-ембеддинг тестового адаптера (Fixture Open-Short Compensation)

Після калібрувальної площини коаксіального роз'єму SMA залишається паразитна лінія друкованої плати тестового адаптера. Для видалення паразитів адаптера використовується матричний метод компенсації за двома виміряними станами:

1. **Еквівалентні паразити фікстура:** Послідовна індуктивність та омічний опір контактних доріжок `Z_fix = R_fix + j · ω · L_fix` та паралельна ємність контактних площадок `Y_fix = G_fix + j · ω · C_fix`.
2. **Формула де-ембеддингу:**
   ```
   Z_corrected(f) = ( Z_meas(f) - Z_short(f) ) / ( 1 - (Z_meas(f) - Z_short(f)) · Y_open(f) )
   ```
   де `Z_short(f)` — імпеданс, виміряний із замкненими накоротко контактними площадками фікстура, а `Y_open(f)` — адмітанс відкритих площадок без котушки.

### Конструювання вимірювальних плат (RF Test Fixture Design)

Для забезпечення точності вимірювань вище 500 МГц тестова плата повинна задовольняти суворим вимогам НВЧ-топології:
- **Копланарна лінія з заземленням (CBCPW):** Забезпечує хвильовий опір `50.0 ± 0.5 Ом` при мінімальній паразитній ємності.
- **Виріз земляного полігону під контактним виводом (Anti-pad):** Під пайкою центрального виводу роз'єму SMA усувається мідь другого шару для компенсації надлишкової паразитної ємності припою.
- **Екрануючі перехідні отвори (Via Stitching):** Отвори заземлення вздовж лінії розташовуються з кроком не більше `λ_min / 10` для придушення паразитних резонансів підкладки.

### Аналіз метрологічних похибок за діапазонами імпедансу

Векторний аналізатор кіл оптимізований для роботи в 50-омному хвильовому тракті. Залежно від вимірюваного значення імпедансу `Z_dut` динамічний діапазон приладу має характерні особливості:
1. **Зона високої точності (`5 Ом ≤ |Z| ≤ 500 Ом`):** Коефіцієнт відбиття лежить у діапазоні `0.1 ≤ |S11| ≤ 0.8`. Похибка вимірювання модуля та фази імпедансу є мінімальною і не перевищує 0.5–1.0%.
2. **Зона наднизьких імпедансів (`|Z| < 0.5 Ом`):** На низьких частотах, де вимірюється малий опір `DCR = 1…10 мОм`, вектор відбиття `S11` практично зливається з точкою короткого замикання `S11 ≈ -1.0 + j·0.0004`. Однопортовий метод має значну похибку визначення активного опору. У метрологічних лабораторіях для точного вимірювання субміліомних DCR замість 1-портової рефлектометрії застосовують 2-портове шунтове вимірювання (Shunt-Thru S21 measurement).
3. **Зона надвисоких імпедансів (`|Z| > 10 кОм`):** На частоті власного резонансу SRF опір котушки досягає максимуму `Z_peak`. Вектор відбиття наближається до точки розриву кола `S11 ≈ +1.0`. Шум приймача VNA спричиняє розкид оцінки пікового опору до 5–15%, проте положення точки переходу фази через 0° визначається з високою частотною точністю (до частотної сітки синтезатора VNA).

### Алгоритм екстракції частотно-залежного опору втрат в осерді R_core(f)

Повний комплексний адмітанс котушки `Y(f) = 1 / Z(f) = G(f) + j · B(f)` дозволяє розділити втрати у провіднику та втрати в осерді:
- **Активна провідність G(f):** На частотах нижче власного резонансу активна провідність записується як:
  ```
  G(f) = Re( 1 / Z(f) ) = R_s / ( R_s² + (ω·L)² ) + 1 / R_core(f)
  ```
- **Розділення механізмів втрат:** Оскільки перший доданок `R_s / (ω·L)²` монотонно зменшується з частотою (як `1/f`), а провідність осердя `1 / R_core(f)` монотонно зростає внаслідок вихрових струмів та гістерезису, графік `G(f)` має виразний глобальний мінімум. Значення `G_min` дозволяє точно обчислити еквівалентний паралельний опір `R_core` на середніх частотах.

### Обробка крайових випадків у числових алгоритмах екстракції

При автоматизованій обробці тисяч вимірювань у виробничих тестових лініях числовий алгоритм зустрічає специфічні аномалії:
1. **Високодобротні котушки (High-Q RF Chokes, Q > 100):** Резонансний пік настільки гострий, що при логарифмічній сітці вимірювання точна вершина антирезонансу потрапляє між сусідніми точками сітки `f_k` та `f_{k+1}`. Застосування лінійної інтерполяції за реактивним опором `X(f)` забезпечує субдискретну роздільну здатність знаходження `f_SRF` з похибкою менше 0.05%.
2. **Низькодобротні індуктивності та феритові бусини (Q < 1.5):** Реактивний опір сильно демпфований втратами осердя, тому фазовий кут може не досягати 0°. У такому разі алгоритм перемикається з пошуку кореня `X(f) = 0` на пошук локального максимуму модуля повного імпедансу `d|Z(f)|/df = 0`.
3. **Шумові артефакти від'ємного активного опору:** При згині вимірювальних кабелів на частотах вище 1 ГГц дрейф фази може призвести до розрахункового `Re(Z) < 0`. Функція санітизації зобов'язана фільтрувати такі нефізичні відліки.

### Математичний апарат обробки вимірювань

#### 1. Білінійне перетворення S-параметра у комплексний імпеданс Z(f)
Для 1-портового вимірювання зв'язок між нормованим коефіцієнтом відбиття `S11` та комплексним імпедансом навантаження `Z(f) = R(f) + j · X(f)` задається класичним білінійним перетворенням:

```
Z(f) = Z_0 · (1 + S11) / (1 - S11)
```

де `Z_0 = 50.0 Ом` — характеристичний хвильовий опір вимірювального тракту VNA.

Розкладаючи чисельник і знаменник на дійсну та уявну частини:

```
Знаменник = (1 - S_re)² + S_im²
R(f) = Z_0 · (1 - S_re² - S_im²) / Знаменник
X(f) = Z_0 · (2 · S_im) / Знаменник
|Z(f)| = √( R(f)² + X(f)² )
```

#### 2. Ідентифікація низькочастотної індуктивності L_0 та активного опору DCR
На низьких частотах (`f << f_SRF`), де впливом паразитної ємності можна знехтувати, реактивний опір зумовлений чистою номінальною індуктивністю, а активний опір — омічним опором провідника:

```
DCR ≈ Re( Z(f_min) )
L_0 ≈ Im( Z(f_low) ) / (2 · π · f_low)
```

Для підвищення стійкості до шуму оцінка `L_0` виконується усередненням значень у діапазоні частот, де добротність котушки задовольняє умові `1.0 ≤ Q(f) ≤ 10.0`.

#### 3. Виявлення власної резонансної частоти f_SRF
Резонансна частота відповідає точці переходу реактивного опору `X(f)` через нуль зі зміною знака з додатного (індуктивного) на від'ємний (ємнісний):

```
X(f_SRF) = 0   [зміна знака dX/df < 0]
```

Для знаходження точного значення `f_SRF` між дискретними точками частотної сітки вимірювання `f_k` та `f_{k+1}` застосовується лінійна інтерполяція:

```
f_SRF = f_k + (f_{k+1} - f_k) · ( -X_k / (X_{k+1} - X_k) )
```

#### 4. Розрахунок паразитної еквівалентної ємності EPC
Знаючи початкову номінальну індуктивність `L_0` та точно знайдено частоту власного антирезонансу `f_SRF`, еквівалентна паралельна ємність знаходиться з формули Томсона:

```
EPC = 1 / ( (2 · π · f_SRF)² · L_0 )
```

#### 5. Розрахунок частотної характеристики добротності Q(f) та пікового опору
Добротність котушки на кожній частотній точці розраховується як відношення накопиченої реактивної енергії до активних втрат:

```
Q(f) = |Im( Z(f) )| / Re( Z(f) )
```

Піковий еквівалентний паралельний опір втрат на резонансній частоті дорівнює:

```
R_peak = Re( Z(f_SRF) )
```

### Покроковий числовий приклад розрахунку імпедансу за S11

Розглянемо точку вимірювання на частоті `f = 10 МГц`, де VNA зафіксував `S11 = 0.0520 + j · 0.9200`:

1. **Розрахунок знаменника:**
   ```
   Знаменник = (1 - 0.0520)² + (0.9200)² = (0.9480)² + 0.8464 = 0.8987 + 0.8464 = 1.7451
   ```

2. **Розрахунок активного опору R(10 МГц):**
   ```
   Чисельник_R = 1 - (0.0520)² - (0.9200)² = 1 - 0.0027 - 0.8464 = 0.1509
   R(10 МГц) = 50.0 · 0.1509 / 1.7451 = 4.32 Ом
   ```

3. **Розрахунок реактивного опору X(10 МГц):**
   ```
   Чисельник_X = 2 · 0.9200 = 1.8400
   X(10 МГц) = 50.0 · 1.8400 / 1.7451 = 52.72 Ом
   ```

4. **Розрахунок еквівалентної індуктивності та добротності:**
   ```
   L_eq(10 МГц) = 52.72 / (2 · π · 10·10⁶) = 0.839 мкГн
   Q(10 МГц) = 52.72 / 4.32 = 12.2
   ```

### Архітектура та опис алгоритму програмної екстракції

Алгоритмічний конвеєр аналізатора складається з чотирьох послідовних стадій обробки:
1. **Валідація та санітизація вхідного масиву:** Перевірка на коректність частотної сітки (`f > 0`), монотонне зростання частоти та відсутність сингулярностей (знаменник `|1 - S11| > 10⁻¹⁵`).
2. **Векторна конверсія в імпеданс:** Перетворення кожної точки `S11` у комплексний імпеданс `Z(f) = R(f) + j·X(f)` та обчислення поточної добротності `Q(f)`.
3. **Детекція резонансу та інтерполяція:** Пошук перетину нульового рівня реактивної складової `X(f)` від додатних значень до від'ємних. У точці перетину виконується субдискретна лінійна інтерполяція для визначення `f_SRF` та пікового паралельного опору втрат `R_peak`.
4. **Формування вихідної структури моделі:** Розрахунок `EPC`, визначення максимальної добротності `Q_max` та частоти її досягнення `f_Qmax`.

Нижче наведено завершену, самодостатню реалізацію алгоритму двома мовами: чистим C99 з фіксованими структурами та сучасним C++20 з використанням концептів безпеки типів `std::expected` та представлень пам'яті `std::span`.

```c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <stdbool.h>

#ifndef M_PI
#define M_PI 3.14159265358979323846
#endif

typedef struct {
    double freq_hz;
    double s11_re;
    double s11_im;
} VnaPoint;

typedef struct {
    double freq_hz;
    double r_ohm;
    double x_ohm;
    double z_mag;
    double q_factor;
} ImpedancePoint;

typedef struct {
    double dcr_ohm;
    double l0_henry;
    double srf_hz;
    double epc_farad;
    double r_peak_ohm;
    double q_max;
    double q_max_freq_hz;
    bool srf_found;
} InductorModel;

static bool s11_to_z(const VnaPoint* pt, double z0, ImpedancePoint* out_z) {
    double denom = (1.0 - pt->s11_re) * (1.0 - pt->s11_re) + (pt->s11_im * pt->s11_im);
    if (denom < 1e-15) {
        return false;
    }
    
    out_z->freq_hz = pt->freq_hz;
    out_z->r_ohm = z0 * (1.0 - pt->s11_re * pt->s11_re - pt->s11_im * pt->s11_im) / denom;
    out_z->x_ohm = z0 * (2.0 * pt->s11_im) / denom;
    out_z->z_mag = sqrt(out_z->r_ohm * out_z->r_ohm + out_z->x_ohm * out_z->x_ohm);
    
    if (out_z->r_ohm > 1e-9) {
        out_z->q_factor = fabs(out_z->x_ohm) / out_z->r_ohm;
    } else {
        out_z->q_factor = 0.0;
    }
    return true;
}

bool extract_inductor_parasitics(const VnaPoint* points, size_t count, double z0, InductorModel* result) {
    if (!points || count < 3 || !result) {
        return false;
    }

    result->dcr_ohm = 0.0;
    result->l0_henry = 0.0;
    result->srf_hz = 0.0;
    result->epc_farad = 0.0;
    result->r_peak_ohm = 0.0;
    result->q_max = 0.0;
    result->q_max_freq_hz = 0.0;
    result->srf_found = false;

    ImpedancePoint prev_z, curr_z;
    if (!s11_to_z(&points[0], z0, &curr_z)) {
        return false;
    }

    result->dcr_ohm = curr_z.r_ohm;
    
    /* Оцінка L0 на першій ненульовій низькій частоті */
    if (curr_z.freq_hz > 10.0 && curr_z.x_ohm > 0.0) {
        result->l0_henry = curr_z.x_ohm / (2.0 * M_PI * curr_z.freq_hz);
    }

    result->q_max = curr_z.q_factor;
    result->q_max_freq_hz = curr_z.freq_hz;

    for (size_t i = 1; i < count; ++i) {
        prev_z = curr_z;
        if (!s11_to_z(&points[i], z0, &curr_z)) {
            continue;
        }

        /* Оновлення пікової добротності */
        if (curr_z.q_factor > result->q_max && curr_z.x_ohm > 0.0) {
            result->q_max = curr_z.q_factor;
            result->q_max_freq_hz = curr_z.freq_hz;
        }

        /* Уточнення оцінки L0 в індуктивній зоні */
        if (result->l0_henry <= 0.0 && curr_z.x_ohm > 0.0 && curr_z.freq_hz > 100.0) {
            result->l0_henry = curr_z.x_ohm / (2.0 * M_PI * curr_z.freq_hz);
        }

        /* Пошук точки зміни знака реактивного опору (SRF) */
        if (!result->srf_found && prev_z.x_ohm > 0.0 && curr_z.x_ohm <= 0.0) {
            double dx = curr_z.x_ohm - prev_z.x_ohm;
            double frac = (fabs(dx) > 1e-12) ? (-prev_z.x_ohm / dx) : 0.5;
            result->srf_hz = prev_z.freq_hz + frac * (curr_z.freq_hz - prev_z.freq_hz);
            result->r_peak_ohm = prev_z.r_ohm + frac * (curr_z.r_ohm - prev_z.r_ohm);
            result->srf_found = true;
        }
    }

    /* Якщо знайдено SRF та L0, розраховуємо EPC */
    if (result->srf_found && result->l0_henry > 0.0 && result->srf_hz > 0.0) {
        double omega_srf = 2.0 * M_PI * result->srf_hz;
        result->epc_farad = 1.0 / (omega_srf * omega_srf * result->l0_henry);
    }

    return true;
}

int main(void) {
    /* Синтетичні дані вимірювання дроселя 10 мкГн, DCR = 0.15 Ом, EPC = 4.5 пФ (SRF ≈ 23.7 МГц) */
    const size_t num_points = 5;
    VnaPoint dataset[5] = {
        { 100000.0,    0.0029,  0.0628 },   /* 100 кГц */
        { 1000000.0,   0.0035,  0.6270 },   /* 1 МГц */
        { 10000000.0,  0.0520,  0.9200 },   /* 10 МГц */
        { 23720000.0,  0.9650,  0.0010 },   /* 23.72 МГц (SRF) */
        { 50000000.0,  0.0810, -0.8500 }    /* 50 МГц (Ємнісна зона) */
    };

    InductorModel model;
    if (extract_inductor_parasitics(dataset, num_points, 50.0, &model)) {
        printf("--- Результати екстракції моделі котушки ---\n");
        printf("DCR:            %.3f Ом\n", model.dcr_ohm);
        printf("Індуктивність L0: %.3f мкГн\n", model.l0_henry * 1e6);
        if (model.srf_found) {
            printf("Частота SRF:    %.2f МГц\n", model.srf_hz / 1e6);
            printf("Паразитна EPC:  %.2f пФ\n", model.epc_farad * 1e12);
            printf("Піковий опір:   %.1f кОм\n", model.r_peak_ohm / 1e3);
        } else {
            printf("SRF не досягнуто у діапазоні вимірювання\n");
        }
        printf("Макс. добротність Q: %.1f на частоті %.2f МГц\n", 
               model.q_max, model.q_max_freq_hz / 1e6);
    }
    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <span>
#include <complex>
#include <cmath>
#include <numbers>
#include <expected>
#include <string_view>
#include <iomanip>

struct VnaSample {
    double freq_hz;
    std::complex<double> s11;
};

struct ExtractedModel {
    double dcr_ohm{0.0};
    double l0_henry{0.0};
    double srf_hz{0.0};
    double epc_farad{0.0};
    double r_peak_ohm{0.0};
    double q_max{0.0};
    double q_max_freq_hz{0.0};
    bool srf_detected{false};
};

enum class ExtractionError {
    InsufficientData,
    InvalidImpedance,
    ZeroFrequency
};

class InductorExtractor {
public:
    static constexpr double DefaultZ0 = 50.0;

    static std::expected<ExtractedModel, ExtractionError> 
    analyze(std::span<const VnaSample> data, double z0 = DefaultZ0) noexcept {
        if (data.size() < 3) {
            return std::unexpected(ExtractionError::InsufficientData);
        }

        ExtractedModel model;
        std::vector<std::pair<double, std::complex<double>>> z_data;
        z_data.reserve(data.size());

        for (const auto& sample : data) {
            if (sample.freq_hz <= 0.0) {
                return std::unexpected(ExtractionError::ZeroFrequency);
            }
            
            auto denom = 1.0 - sample.s11;
            if (std::abs(denom) < 1e-15) {
                return std::unexpected(ExtractionError::InvalidImpedance);
            }
            
            std::complex<double> z = z0 * (1.0 + sample.s11) / denom;
            z_data.emplace_back(sample.freq_hz, z);
        }

        // 1. DCR та L0 на низьких частотах
        model.dcr_ohm = z_data.front().second.real();
        
        for (const auto& [f, z] : z_data) {
            if (z.imag() > 0.0 && f > 10.0) {
                model.l0_henry = z.imag() / (2.0 * std::numbers::pi * f);
                break;
            }
        }

        // 2. Пошук пікової добротності Q та частоти SRF
        for (size_t i = 0; i < z_data.size(); ++i) {
            const auto& [f, z] = z_data[i];
            
            if (z.real() > 1e-9 && z.imag() > 0.0) {
                double q = z.imag() / z.real();
                if (q > model.q_max) {
                    model.q_max = q;
                    model.q_max_freq_hz = f;
                }
            }

            if (i > 0 && !model.srf_detected) {
                const auto& [prev_f, prev_z] = z_data[i - 1];
                if (prev_z.imag() > 0.0 && z.imag() <= 0.0) {
                    double dx = z.imag() - prev_z.imag();
                    double frac = (std::abs(dx) > 1e-12) ? (-prev_z.imag() / dx) : 0.5;
                    model.srf_hz = prev_f + frac * (f - prev_f);
                    model.r_peak_ohm = prev_z.real() + frac * (z.real() - prev_z.real());
                    model.srf_detected = true;
                }
            }
        }

        // 3. Розрахунок EPC
        if (model.srf_detected && model.l0_henry > 0.0 && model.srf_hz > 0.0) {
            double omega = 2.0 * std::numbers::pi * model.srf_hz;
            model.epc_farad = 1.0 / (omega * omega * model.l0_henry);
        }

        return model;
    }
};

int main() {
    const std::vector<VnaSample> sweepData = {
        { 100'000.0,    { 0.0029,  0.0628 } },
        { 1'000'000.0,  { 0.0035,  0.6270 } },
        { 10'000'000.0, { 0.0520,  0.9200 } },
        { 23'720'000.0, { 0.9650,  0.0010 } },
        { 50'000'000.0, { 0.0810, -0.8500 } }
    };

    auto result = InductorExtractor::analyze(sweepData);
    if (result.has_value()) {
        const auto& m = result.value();
        std::cout << std::fixed << std::setprecision(3);
        std::cout << "=== Параметри еквівалентної схеми котушки (C++20) ===\n";
        std::cout << "DCR:             " << m.dcr_ohm << " Ом\n";
        std::cout << "Індуктивність L: " << (m.l0_henry * 1e6) << " мкГн\n";
        if (m.srf_detected) {
            std::cout << "Резонанс SRF:    " << (m.srf_hz / 1e6) << " МГц\n";
            std::cout << "Паразитна EPC:   " << (m.epc_farad * 1e12) << " пФ\n";
            std::cout << "Піковий опір R:  " << (m.r_peak_ohm / 1e3) << " кОм\n";
        }
        std::cout << "Q_max:           " << std::setprecision(1) << m.q_max 
                  << " на частоті " << (m.q_max_freq_hz / 1e6) << " МГц\n";
    }
    return 0;
}
```

### Практичні інженерні пастки при вимірюванні паразитів VNA

1. **Паразитна індуктивність вимірювальних контактів:** Довжина затискачів або виводів тестового адаптера вносить власну послідовну індуктивність із розрахунку приблизно `1 нГн на 1 мм довжини`. Це штучно завищує значення виміряної індуктивності `L` та зміщує виміряну точку `f_SRF` у бік нижчих частот.
2. **Ємність тестової площадки (Fixture Capacitance):** Металеві контактні площадки друкованої плати адаптера додають паралельну ємність `0.2…1.0 пФ` на землю. Обов'язково проводьте процедуру компенсації Port Extension або 2-портове де-ембеддинг калібрування (Open/Short fixture de-embedding).
3. **Шум поблизу точки антирезонансу:** На частоті `f_SRF` модуль імпедансу досягає десятків або сотень кілоом, що наближає коефіцієнт відбиття `|S11|` майже точно до `+1.0`. Будь-який шум АЦП вимірювача призводить до значних флуктуацій фази. Для точного визначення вершини антирезонансу слід збільшувати усереднення VNA (Averaging Factor ≥ 16) та зменшувати смугу ПЧ (IF Bandwidth ≤ 1 кГц).
4. **Вторинні хвильові резонанси:** У довгих багатошарових котушках після первинного антирезонансу SRF графік імпедансу може містити повторні локальні мінімуми та максимуми на частотах `2·f_SRF`, `3·f_SRF`. Це хвильові стоячі резонанси лінії з розподіленими параметрами, які вимагають переходу від простої 3-елементної схеми до ланцюгової моделі Фостера (Foster network).
5. **Температурний дрейф кабелів:** Високочастотні фазостабільні кабелі змінюють свою електричну довжину при згинанні або нагріванні. При вимірюванні високодобротних котушок навіть мікроскопічний зсув фази на 0.1° на частоті 500 МГц може спотворити значення екстрагованої паразитної ємності EPC на 20–40%.
