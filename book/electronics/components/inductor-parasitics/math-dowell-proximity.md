# 🧮 Аналітична модель Довелла: розрахунок втрат на ефект близькості

Математичний апарат розрахунку високочастотних втрат в обмотках індуктивних компонентів базується на розв'язанні одновимірного диференціального рівняння дифузії електромагнітного поля всередині провідних шарів. Коли крізь котушку протікає високочастотний змінний струм, провідники відчувають одночасну дію власного змінного струму (скін-ефект) та стороннього змінного магнітного поля, створеного всіма іншими витками обмотки (ефект близькості). У багатошарових котушках польовий внесок ефекту близькості багаторазово переважає класичний скін-ефект, викликаючи різке зростання активного опору обмотки.

У 1966 році британський інженер-дослідник П. Довелл (P. L. Dowell) опублікував фундаментальну працю, в якій запропонував замкнену одновимірну аналітичну модель для розрахунку коефіцієнта збільшення активного опору обмотки змінного струму `F_R = R_ac / R_dc`. Модель Довелла дозволяє обчислити дійсні високочастотні втрати для довільної кількості шарів, довільної геометрії та довільної частоти без необхідності числового розв'язання тривимірних рівнянь Максвелла методом скінченних елементів (FEM), зберігаючи високу інженерну точність (похибка не перевищує 5–10% для більшості типів силових магнітних компонентів).

### Одновимірне рівняння магнітної дифузії в шарі провідника

Розглянемо нескінченний плоский шар міді товщиною `h` вздовж просторової осі `x` (координата `x` змінюється в межах від `x = -h/2` до `x = +h/2`), розташований у вікні магнітопроводу ефективною шириною `b_w`. Густина струму `J(x)` спрямована вздовж поздовжньої осі провідника `z`, а вектор напруженості змінного магнітного поля `H(x)` спрямований строго тангенціально (паралельно) до поверхні шару вздовж осі `y`.

Система квазістаціонарних диференціальних рівнянь Максвелла для немагнітного провідного середовища без вільних просторових зарядів записується у вигляді:

```
rot H = J
rot E = - ∂B / ∂t = - μ_0 · μ_r · (∂H / ∂t)
div B = 0
div J = 0
```

де `μ_0 = 4·π·10⁻⁷ Гн/м` — магнітна стала, `μ_r = 1` — відносна проникність міді, а зв'язок між густиною струму та напруженістю електричного поля задається диференціальним законом Ома:

```
J = σ · E = (1 / ρ) · E
```

де `ρ` — питомий опір провідника (для міді при температурі +20 °C `ρ ≈ 1.724·10⁻⁸ Ом·м`, при робочій температурі +100 °C `ρ ≈ 2.26·10⁻⁸ Ом·м`).

Беручи операцію ротора від обох частин першого рівняння Максвелла та підставляючи вирази для `rot E` та закону Ома для синусоїдального гармонічного процесу частотою `ω = 2 · π · f`, отримуємо одновимірне хвильове рівняння Гельмгольца (рівняння магнітної дифузії):

```
d²H(x) / dx² = j · ω · μ_0 · σ · H(x) = γ² · H(x)
```

Комплексний коефіцієнт поширення хвилі в провідному металі `γ` визначається через глибину скін-шару `δ`:

```
γ = √( j · ω · μ_0 · σ ) = (1 + j) / δ
```

де класична товщина скін-шару `δ` дорівнює:

```
δ = √( ρ / (π · f · μ_0 · μ_r) )
```

### Граничні умови та розподіл напруженості поля в m-му шарі

У багатошаровій структурі, складеній із `m` послідовних шарів провідників, загальний магнітний потік, що охоплюється контуром перед кожним наступним шаром, зростає ступінчасто відповідно до закону повного струму Ампера. Нехай кожен окремий шар котушки створює стрибок лінійної густини струму `I' = I / b_w`, де `I` — амплітуда струму обмотки, а `b_w` — ширина вікна намотування.

Для шару під номером `m` (де `m = 1` відповідає шару, найближчому до осі осердя) граничні значення напруженості магнітного поля на внутрішній поверхні (`x = -h/2`) та на зовнішній поверхні (`x = +h/2`) формуються сумарним струмом усіх попередніх шарів:

```
H(-h/2) = (m - 1) · I' = (m - 1) · (I / b_w)
H(+h/2) = m · I' = m · (I / b_w)
```

Загальний розв'язок одновимірного диференціального рівняння другого порядку для напруженості магнітного поля є лінійною комбінацією гіперболічних функцій комплексного аргументу:

```
H(x) = A · sinh(γ · x) + B · cosh(γ · x)
```

Підставляючи граничні умови при `x = ±h/2`, знаходимо невідомі коефіцієнти інтегрування `A` та `B`:

```
A = [ H(+h/2) - H(-h/2) ] / [ 2 · sinh(γ · h / 2) ] = I' / [ 2 · sinh(γ · h / 2) ]
B = [ H(+h/2) + H(-h/2) ] / [ 2 · cosh(γ · h / 2) ] = (2·m - 1) · I' / [ 2 · cosh(γ · h / 2) ]
```

Підставляючи знайдені коефіцієнти в загальний розв'язок, отримуємо просторовий профіль напруженості магнітного поля по всій товщині провідника:

```
H(x) = I' · [ sinh(γ · x) / (2 · sinh(γ · h / 2)) + (2·m - 1) · cosh(γ · x) / (2 · cosh(γ · h / 2)) ]
```

### Густина струму та інтегрування теплових втрат Джоуля

За законом повного струму Ампера густина електричного струму `J(x)` всередині тіла провідника дорівнює просторовій похідній напруженості магнітного поля:

```
J(x) = dH(x) / dx
     = γ · I' · [ cosh(γ · x) / (2 · sinh(γ · h / 2)) + (2·m - 1) · sinh(γ · x) / (2 · cosh(γ · h / 2)) ]
```

Перший доданок у виразі для `J(x)` описує симетричний розподіл струму, зумовлений власним струмом провідника (скін-ефект), тоді як другий доданок описує антисиметричний вихровий струм, індукований зовнішнім магнітним полем решти витків (ефект близькості).

Середня за період активна потужність джоулевих втрат `P_ac(m)`, що розсіюється в одиниці об'єму шару `m`, розраховується інтегруванням квадрата модуля густини струму по всій товщині провідника:

```
P_ac(m) = (ρ · l_w · b_w / 2) · ∫ |J(x)|² dx   [інтегрування від x = -h/2 до x = +h/2]
```

де `l_w` — середня довжина витка в шарі.

Для обчислення інтеграла від добутку гіперболічних функцій комплексного аргументу скористаємося тотожностями для тригонометричних та гіперболічних функцій дійсного аргументу:

```
|cosh(γ · x)|² = cosh²(x/δ) · cos²(x/δ) + sinh²(x/δ) · sin²(x/δ) = (cosh(2x/δ) + cos(2x/δ)) / 2
|sinh(γ · x)|² = sinh²(x/δ) · cos²(x/δ) + cosh²(x/δ) · sin²(x/δ) = (cosh(2x/δ) - cos(2x/δ)) / 2
```

Вводячи безрозмірну нормовану товщину провідника `ξ = h / δ`, після аналітичного інтегрування отримуємо вираз для питомих втрат у шарі під номером `m`:

```
P_ac(m) = R_dc · I² · ξ · [ M(ξ) + (m² - m) · D(ξ) ]
```

де допоміжні гіперболічні функції Довелла `M(ξ)` та `D(ξ)` задаються співвідношеннями:

```
M(ξ) = (sinh(2·ξ) + sin(2·ξ)) / (cosh(2·ξ) - cos(2·ξ))
D(ξ) = 2 · (sinh(ξ) - sin(ξ)) / (cosh(ξ) + cos(ξ))
```

### Сумування втрат по всіх шарах та остаточний фактор Довелла F_R

Щоб знайти сумарні високочастотні втрати всієї обмотки, просумуємо розсіювану потужність по всіх `m` шарах від першого (`m = 1`) до останнього (`m = m_total`):

```
P_ac_total = ∑ P_ac(m) [від m=1 до m_total]
           = R_dc · I² · ξ · [ m_total · M(ξ) + D(ξ) · ∑ (m² - m) ]
```

Використовуючи формулу для суми квадратів послідовних натуральних чисел:

```
∑ m² [від m=1 до m_total] = m_total · (m_total + 1) · (2·m_total + 1) / 6
∑ m  [від m=1 до m_total] = m_total · (m_total + 1) / 2
```

Знаходимо значення суми:

```
∑ (m² - m) = m_total · (m_total² - 1) / 3
```

Ділячи повну активну потужність втрат змінного струму `P_ac_total` на потужність статичних втрат постійного струму `P_dc = m_total · R_dc · I²`, отримуємо фундаментальний **коефіцієнт зростання опору Довелла `F_R`**:

```
F_R = R_ac / R_dc
    = ξ · [ M(ξ) + (2 · (m² - 1) / 3) · D(ξ) ]
```

де `m` позначає повну кількість шарів обмотки (`m = m_total`).

### Асимптотичний аналіз при високих частотах (граничний перехід ξ >> 1)

Розглянемо поведінку моделі Довелла у граничному випадку надзвичайно високих частот або товстих провідників, коли товщина шару значно перевищує товщину скін-шару (`ξ = h / δ >> 1`):

1. При `ξ → ∞` експоненціальні члени `exp(2ξ)` та `exp(ξ)` у гіперболічних функціях значно переважають тригонометричні коливання:
   ```
   M(ξ) = (sinh(2ξ) + sin(2ξ)) / (cosh(2ξ) - cos(2ξ)) → 1.0
   D(ξ) = 2 · (sinh(ξ) - sin(ξ)) / (cosh(ξ) + cos(ξ)) → 2.0
   ```
2. Підставляючи ці граничні значення в рівняння Довелла, отримуємо асимптотичний високочастотний коефіцієнт опору:
   ```
   F_R_inf = ξ · [ 1.0 + (2 · (m² - 1) / 3) · 2.0 ]
           = ξ · [ 1 + (4·m² - 4) / 3 ]
           = ξ · [ (4·m² - 1) / 3 ]
   ```
3. Для 5-шарової котушки (`m = 5`) високочастотний коефіцієнт набуває значення:
   ```
   F_R_inf = ξ · [ (4 · 25 - 1) / 3 ] = 33 · ξ = 33 · (h / δ)
   ```
   Це означає, що при `h = 3·δ` опір обмотки змінного струму зростає рівно в `33 · 3 = 99` разів відносно опору постійному струму!

### Фізичний розклад: скін-ефект проти ефекту близькості

Аналітична структура формули Довелла чітко розмежовує два фундаментальні механізми високочастотних втрат:

```
F_R = F_skin(ξ) + F_proximity(ξ, m)
```

#### 1. Складова власного скін-ефекту: `F_skin = ξ · M(ξ)`
- Ця компонента залежить виключно від відношення геометричної товщини провідника до глибини скін-шару `ξ = h / δ` і абсолютно не залежить від кількості шарів `m`.
- При тонких провідниках (`ξ < 0.5`): розклад у ряд Тейлора дає `M(ξ) ≈ 1/ξ + (4/45)·ξ³`, звідки `F_skin ≈ 1 + (4/45)·ξ⁴ ≈ 1.0` (опір практично не відрізняється від омічного).
- При товстих провідниках (`ξ > 2.0`): функція `M(ξ) → 1.0`, звідки `F_skin ≈ ξ = h / δ` (опір зростає пропорційно `√f`).

#### 2. Складова просторового ефекту близькості: `F_proximity = ξ · [ 2·(m² - 1) / 3 ] · D(ξ)`
- Ця компонента породжена вихровими струмами від поля інших шарів і масштабується квадратично від кількості шарів `m²`.
- Для строго одношарової котушки (`m = 1`) множник `(1² - 1) = 0`, і ефект близькості між шарами повністю відсутній (`F_R = F_skin`).
- Для 2-шарової котушки множник дорівнює `(2² - 1)/3 = 1.0`.
- Для 4-шарової котушки множник зростає до `(4² - 1)/3 = 5.0`.
- Для 8-шарової котушки множник сягає `(8² - 1)/3 = 21.0`!
- Для тонких шарів (`ξ < 1.0`) апроксимація Тейлора дає `D(ξ) ≈ ξ³ / 3`. Тоді втрати на ефект близькості набувають вигляду:

```
F_proximity ≈ (2 / 9) · (m² - 1) · ξ⁴ = (2 / 9) · (m² - 1) · (h / δ)⁴
```

Оскільки товщина скін-шару обернено пропорційна квадратному кореню з частоти `δ ∝ 1/√f`, вираз `(h/δ)⁴` пропорційний квадрату частоти `f²`! Це означає, що в багатошарових котушках високочастотні втрати провідника зростають не за повільним законом скін-ефекту `√f`, а **квадратично від частоти `f²` та квадратично від кількості шарів `m²`**.

### Врахування пористості обмотки (фактор пористості η)

Реальні котушки намотуються круглим дротом з ізоляційним лаком та технологічними проміжками між сусідніми витками. Для перетворення масиву круглих провідників діаметром `d` у безперервний плоский шар Довелла вводять **коефіцієнт пористості (пористість намотування)** `η`:

```
η = N_turns_per_layer · d_copper / b_window
```

де `N_turns_per_layer` — кількість витків у шарі, `d_copper` — діаметр мідної жили, а `b_window` — ширина вікна каркаса. Еквівалентна товщина еквівалентного шару прямокутного перерізу зі збереженням площі міді становить:

```
h_eq = d_copper · √(π / 4) ≈ 0.8862 · d_copper
```

Узагальнена формула Довелла для пористої обмотки модифікується заміною аргументу `ξ` на масштабований параметр `ξ'`:

```
ξ' = (h_eq / δ) · √η
```

та множника близькості:

```
F_R = ξ' · [ M(ξ') + (2 · (m² · η² - 1) / 3) · D(ξ') ]
```

### Розрахунок оптимальної товщини провідника h_opt

Класична інтуїція інженера підказує, що для зменшення втрат потрібно брати якомога товстіший дріт, оскільки опір постійному струму `R_dc` зменшується як `1/h`. Проте в багатошаровій обмотці на високій частоті збільшення товщини дроту викликає настільки колосальне зростання фактора ефекту близькості `F_proximity ∝ h⁴`, що повний дійсний опір `R_ac = R_dc · F_R` починає лавиноподібно зростати.

Диференціюючи повний опір `R_ac(h)` за товщиною `h` та прирівнюючи похідну до нуля `d(R_ac) / dh = 0`, отримуємо співвідношення для **оптимальної нормованої товщини провідника `ξ_opt`**:

```
ξ_opt = (h_opt / δ) · √η ≈ [ 3 / (2 · m² · η²) ]^(1/4)
```

Для типових силових трансформаторів та багатошарових дроселів із кількістю шарів `m = 3…8` значення `ξ_opt` лежить у вузькому діапазоні:

```
ξ_opt ≈ 0.5 … 0.85
```

Звідси випливає фундаментальне правило високовольтної та високочастотної магнітодинаміки: **для мінімізації сумарних втрат товщина дроту в багатошаровій обмотці повинна вибиратися меншою за товщину скін-шару `h_opt < δ(f)`.**

### Модель Довелла для трансформаторів із чергуванням шарів (Interleaving)

У багатообмоткових трансформаторах та дроселях зі зв'язаними обмотками кількість ефективних шарів `m` можна штучно зменшити методом чергування секцій первинної (`P`) та вторинної (`S`) обмоток. Якщо замість структури `P-P-P-P-S-S-S-S` (де `m = 4` для кожної обмотки) застосувати структуру «сендвіч» `P-S-P-S-P-S-P-S`, магнітодинамічний контур розбивається на окремі секції, в кожній з яких магнітне поле спадає до нуля в центрі зазору між обмотками.

Ефективна кількість шарів у формулі Довелла зменшується у відповідну кількість разів:

```
m_eff = m_total / (2 · p_interleaving)
```

де `p_interleaving` — кількість переходів між первинною та вторинною обмотками. Зменшення `m_eff` з 4 до 1 знижує фактор втрат ефекту близькості у `(4² - 1) / (1² - 1 + ε) ≈ 15` разів, що дозволяє суттєво підвищити ККД перетворювача за рахунок правильного чергування шарів.

### Розрахунок втрат у багатожильному літцендраті

Для літцендрату, що складається з `N_strands` тонких ізольованих жил, коефіцієнт збільшення опору розраховується у два ієрархічні етапи:
1. **Внутрішній скін-ефект окремої жили:** Розраховується за функцією Довелла `F_skin(ξ_strand)` для діаметра окремої жили `d_strand`.
2. **Ефект близькості між жилами в пучку:** Оскільки жили скручені з регулярним кроком, зовнішнє поле пронизує пучок рівномірно. Еквівалентний коефіцієнт Довелла пучка становить:
   ```
   F_R_litz = F_skin(ξ_strand) + (2/3) · (N_strands · η_bundle - 1) · D(ξ_strand)
   ```
   де `η_bundle` — фактор заповнення пучка міддю (`η_bundle ≈ 0.40…0.60`). Оскільки `ξ_strand < 0.5`, значення `D(ξ_strand) ≈ 0`, що забезпечує мінімальні сумарні втрати.

### Порівняльний аналіз: круглий дріт проти мідної фольги

При проектуванні високочастотних планарних трансформаторів інженер обирає між круглим проводом та суцільною мідною фольгою:
- **Мідна фольга (Foil Winding):** Займає 100% ширини вікна намотування, тому коефіцієнт пористості `η_foil = 1.0`. Завдяки цьому товщина фольги може бути обрана дуже малою (`h_foil = 0.05…0.15 мм`), що забезпечує `ξ < 0.5` навіть на мегагерцових частотах.
- **Круглий дріт (Round Wire):** Через геометрію кіл коефіцієнт заповнення вікна рідко перевищує `η ≈ 0.70…0.78`. Проте круглий дріт значно дешевший у серійному виробництві та не вимагає спеціальних ізоляційних гнучких підкладок на краях шарів.

### Врахування несинусоїдального струму та шпаруватості ШІМ

У реальних імпульсних джерелах живлення струм дроселя є не чистою синусоїдою, а сумою постійної складової `I_dc` та трикутного або трапецеподібного змінного струму пульсацій `i_ac(t)`. Змінний струм розкладається в ряд Фур'є за гармоніками:

```
i_ac(t) = ∑ I_n · cos(n · ω_sw · t - φ_n)
```

де `I_n` — амплітуда `n`-ї гармоніки частоти комутації `ω_sw = 2 · π · f_sw`.

Для трапецеподібного струму з часом наростання `t_r` та шпаруватістю `D` амплітуди гармонік спадають зі швидкістю −20 дБ/декаду до частоти `f_1 = 1 / (π · D · T)` і зі швидкістю −40 дБ/декаду на частотах вище `f_2 = 1 / (π · t_r)`. При асиметричних шпаруватостях `D < 0.2` або `D > 0.8` коефіцієнт форми струму `k_form = I_rms / I_avg` зростає як `1 / √(D)`, що багаторазово підсилює амплітуди вищих гармонік струму та вимагає суворішого контролю фактора Довелла на частотах вищих порядків.

Повна активна теплова потужність втрат в обмотці знаходиться підсумовуванням втрат від постійної складової та всіх окремих частотних гармонік із відповідними коефіцієнтами Довелла `F_R(n · f_sw)`:

```
P_total = I_dc² · R_dc + ∑ [ (I_n / √2)² · R_dc · F_R(n · f_sw) ]
```

Для більшості практичних розрахунків достатньо врахувати перші 7–11 гармонік робочої частоти комутації перетворювача.

### Покроковий числовий приклад проектування 4-шарового дроселя

**Початкові інженерні параметри:**
- Кількість шарів обмотки: `m = 4`
- Діаметр провідника: `d = 0.80 мм` (`h_eq = 0.709 мм = 7.09·10⁻⁴ м`)
- Коефіцієнт пористості: `η = 0.85`
- Омічний опір постійному струму: `R_dc = 50 мОм`
- Досліджувані частоти комутації: `f_1 = 20 кГц`, `f_2 = 250 кГц`, `f_3 = 1 МГц`

#### 1. Розрахунок глибини скін-шару:
- На частоті 20 кГц: `δ_1 = 66 / √(20000) = 0.467 мм = 4.67·10⁻⁴ м`
- На частоті 250 кГц: `δ_2 = 66 / √(250000) = 0.132 мм = 1.32·10⁻⁴ м`
- На частоті 1 МГц: `δ_3 = 66 / √(1000000) = 0.066 мм = 6.60·10⁻⁵ м`

#### 2. Обчислення нормованого параметра ξ' = (h_eq / δ) · √η:
- При 20 кГц: `ξ'_1 = (0.709 / 0.467) · √0.85 = 1.518 · 0.922 = 1.40`
- При 250 кГц: `ξ'_2 = (0.709 / 0.132) · 0.922 = 4.95`
- При 1 МГц: `ξ'_3 = (0.709 / 0.066) · 0.922 = 9.90`

#### 3. Обчислення коефіцієнтів Довелла M(ξ') та D(ξ'):
- Для `ξ' = 1.40`: `M(1.40) ≈ 1.054`, `D(1.40) ≈ 0.612`
- Для `ξ' = 4.95`: `M(4.95) ≈ 1.000`, `D(4.95) ≈ 2.000`
- Для `ξ' = 9.90`: `M(9.90) ≈ 1.000`, `D(9.90) ≈ 2.000`

#### 4. Розрахунок сумарного множника близькості:
```
K_prox = 2 · (m² · η² - 1) / 3 = 2 · (16 · 0.7225 - 1) / 3 = 2 · (11.56 - 1) / 3 = 7.04
```

- **На частоті 20 кГц:**
  ```
  F_R(20 кГц) = 1.40 · [ 1.054 + 7.04 · 0.612 ] = 1.40 · [ 1.054 + 4.308 ] = 1.40 · 5.362 = 7.51
  R_ac(20 кГц) = 50 мОм · 7.51 = 375.5 мОм (зростання в 7.5 разів)
  ```

- **На частоті 250 кГц:**
  ```
  F_R(250 кГц) = 4.95 · [ 1.000 + 7.04 · 2.000 ] = 4.95 · [ 1.000 + 14.08 ] = 4.95 · 15.08 = 74.6
  R_ac(250 кГц) = 50 мОм · 74.6 = 3730 мОм = 3.73 Ом (зростання у 74.6 разів!)
  ```

- **На частоті 1 МГц:**
  ```
  F_R(1 МГц) = 9.90 · [ 1.000 + 14.08 ] = 9.90 · 15.08 = 149.3
  R_ac(1 МГц) = 50 мОм · 149.3 = 7465 мОм = 7.47 Ом (зростання у 150 разів!)
  ```

#### 5. Розрахунок з оптимізованим літцендратом:
Якщо замість монолітного дроту взяти літцендрат із 100 ізольованих жил діаметром `d_strand = 0.08 мм` (той самий сумарний переріз міді `R_dc = 50 мОм`):
На частоті 250 кГц товщина окремої жили `0.08 мм < δ = 0.132 мм` (`ξ_strand ≈ 0.60`).
Завдяки регулярній просторовій транспозиції жил у пучку зовнішнє поле для кожної жили взаємно компенсується, що еквівалентно роботі з одношаровою структурою `m = 1`.
Коефіцієнт Довелла падає до `F_R(250 кГц) ≈ 1.08`.
Дійсний високочастотний опір становить `R_ac = 50 мОм · 1.08 = 54 мОм` замість `3730 мОм` — активні теплові втрати на змінному струмі **зменшуються рівно у 69 разів**.
