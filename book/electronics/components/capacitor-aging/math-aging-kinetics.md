# 🧮 Математичні моделі старіння діелектриків: логарифмічна релаксація та термодинаміка Арреніуса

Старіння конденсаторів підпорядковується фундаментальним законам статистичної термодинаміки, квантової механіки та фізики твердого тіла. У керамічних діелектриках домінує логарифмічна кінетика релаксації сегнетоелектричних доменів, тоді як у рідких електролітах — експоненційна кінетика випаровування розчинника за законом Арреніуса, ускладнена внутрішнім Джоулевим самонагрівом від струму пульсацій та частотною дисперсією імпедансу. Нижче наведено суворе математичне виведення розрахункових рівнянь, статистичних розподілів надійності та практичний приклад оцінки залишкового ресурсу.

## 1. Статистична фізика релаксації сегнетоелектричних доменів (MLCC)

У кераміці класу II та III на основі титанату барію (`BaTiO3`) діелектрична проникність `ε_r` формується двома фізичними механізмами: зміщенням іонів титану `Ti⁴⁺` усередині елементарної перовскітної комірки (власна поляризація ґратки) та коливальним зміщенням 90-градусних і 180-градусних доменних стінок під дією слабкого змінного електричного поля.

Одразу після проходження точки Кюрі (`T_Curie ≈ +125 °C`) під час охолодження після пайки доменні межі перебувають у метастабільному стані з високою надлишковою пружною та електростатичною енергією. Перехід до стану термодинамічної рівноваги описується релаксацією ансамблю диполів через енергетичні бар'єри різної висоти.

### Від розтягнутої експоненти Кольрауша до логарифмічного закону

У невпорядкованих полікристалічних системах релаксація параметрів у часі підпорядковується розтягнутій експоненті Кольрауша-Вільямса-Воттса (англ. *Kohlrausch-Williams-Watts*, KWW):

```
ΔP(t) = P_0 · exp( − (t / τ)^β )
```

де `β` — показник дисперсії (`0 < β < 1`), що відображає ступінь неоднорідності кристалічних зерен і розподілу локальних механічних напружень, а `τ` — характерний час релаксації.

Згідно з моделлю фізичного старіння Л. Штруйка (англ. *L. Struik*), якщо система володіє неперервним, рівномірним статистичним розподілом енергій активації бар'єрів `g(E) = const` у широкому діапазоні від `E_min` до `E_max`, суперпозиція елементарних релаксаційних процесів Дебая трансформується у логарифмічну функцію часу:

```
P(t) = ∫[0 .. ∞] g(τ) · exp(−t / τ) dτ
```

де час релаксації `τ` пов'язаний з енергією бар'єра `E` термодинамічним співвідношенням Арреніуса:

```
τ(E) = τ_0 · exp( E / (k_B · T) )
```

Диференціюючи інтеграл за часом `t`, отримуємо диференціальне рівняння швидкості релаксації рухливих доменних меж `N(t)`:

```
dN / dt = − ( N_0 · α ) / t
```

де `α` — безрозмірна константа швидкості релаксації, а `t` — час, що минув з моменту останнього проходження точки Кюрі.

Інтегруючи це диференціальне рівняння від початкового базового часу `t_0` до довільного часу `t`:

```
∫[t_0 .. t] dN = − N_0 · α · ∫[t_0 .. t] (1 / u) du
N(t) − N(t_0) = − N_0 · α · ln(t / t_0)
```

Оскільки вимірювана ємність `C(t)` лінійно пов'язана з концентрацією рухливих доменних меж `N(t)` (`C ∝ ε_r ∝ N`), переходимо від натурального логарифма до десяткового (`ln(x) = ln(10) · log10(x) ≈ 2.302585 · log10(x)`):

```
C(t) = C_0 · ( 1 − k · log₁₀(t / t_0) )
```

де `k` — коефіцієнт швидкості старіння (англ. *aging rate*):

```
k = 2.302585 · α = − ( 1 / C_0 ) · ( dC / d(log₁₀ t) )
```

### Температурна залежність коефіцієнта старіння k(T)

Коефіцієнт старіння `k` не є абсолютною константою матеріалу — він залежить від робочої температури зразка `T`. Швидкість дифузії кисневих вакансій `V_O¨`, які блокують доменні стінки (доменний пінінг), визначається коефіцієнтом дифузії:

```
D_v(T) = D_0 · exp( − E_mig / (k_B · T) )
```

де `E_mig ≈ 0.8 ... 1.1 еВ` — енергія міграції кисневої вакансії в перовскітній ґратці `BaTiO3`.

За кріогенних температур (`T < −50 °C`) теплової енергії недостатньо для подолання бар'єру міграції вакансій (`k_B · T << E_mig`), рухливість дефектів практично заморожується, і швидкість старіння прямує до нуля (`k → 0`).

При наближенні до точки Кюрі знизу (+85...+115 °C) теплові коливання інтенсивно розхитують ґратку, тетрагональне спотворення зменшується (`c/a → 1.0`), бар'єри релаксації падають, і коефіцієнт `k` зростає у 2–3 рази.

Вище точки Кюрі (`T > +125 °C`) кубічна симетрія повністю відновлюється, спонтанна поляризація зникає (`P_s = 0`), і старіння миттєво припиняється (фаза де-ейджингу).

## 2. Термодинаміка випаровування розчинника електроліту (Закон Арреніуса)

Ресурс алюмінієвого електролітичного конденсатора з рідким електролітом обмежується швидкістю втрати леткого розчинника (γ-бутиролактону `GBL`, етиленгліколю `EG` або диметилформаміду `DMF`) через мікропори полімерного ущільнювача торцевої пробки шляхом дифузії Кнудсена та молекулярного випаровування.

Згідно з термодинамічною теорією перехідного стану Ейрінга-Арреніуса, швидкість втрати маси розчинника `dm / dt` пропорційна тиску насиченої пари над менісками нанопор і експоненційно залежить від абсолютної температури `T`:

```
dm / dt = − A_evap · exp( − E_a / (k_B · T) )
```

де:
- `A_evap` — передекспоненційний кінетичний множник, що залежить від геометричної площі ущільнювача, пористості гуми та молекулярної маси розчинника;
- `E_a` — енергія активації процесу деградації (`E_a ≈ 0.90 ... 0.98 еВ`, інтегральне середнє `0.94 еВ`);
- `k_B = 8.617333 × 10⁻⁵ еВ/К` — стала Больцмана;
- `T` — абсолютна температура в Кельвінах (`T = t[°C] + 273.15`).

Час життя конденсатора `L` прямо пропорційний початковому об'єму (масі `m_0`) електроліту і обернено пропорційний швидкості його випаровування:

```
L(T) = L_0 · exp[ (E_a / k_B) · ( 1/T − 1/T_0 ) ]
```

### Математичне виведення правила 10 градусів та розрахунок похибки

Розглянемо коефіцієнт прискорення реакції `AF_10` при підвищенні температури на `ΔT = 10 К` від базової температури `T_1` до `T_2 = T_1 + 10`:

```
AF_10(T_1) = exp[ (E_a / k_B) · ( 1/T_1 − 1/(T_1 + 10) ) ] = exp[ (E_a / k_B) · ( 10 / (T_1 · (T_1 + 10)) ) ]
```

Розрахуємо значення `AF_10` для різних температурних діапазонів експлуатації при `E_a = 0.94 еВ` (`E_a / k_B = 0.94 / 8.617333 × 10⁻⁵ ≈ 10908.25 К`):

1. **Низькотемпературний діапазон (+45 °C → +55 °C, `T_1 = 318.15 К`):**
   ```
   Знаменник: 318.15 · 328.15 = 104401 К²
   Показник: 10908.25 · (10 / 104401) = 10908.25 · 0.000095784 = 1.0448
   AF_10 = exp(1.0448) ≈ 2.84
   ```
2. **Середньотемпературний діапазон (+65 °C → +75 °C, `T_1 = 338.15 К`):**
   ```
   Знаменник: 338.15 · 348.15 = 117727 К²
   Показник: 10908.25 · (10 / 117727) = 10908.25 · 0.000084942 = 0.9265
   AF_10 = exp(0.9265) ≈ 2.53
   ```
3. **Робочий діапазон перетворювачів (+85 °C → +95 °C, `T_1 = 358.15 К`):**
   ```
   Знаменник: 358.15 · 368.15 = 131853 К²
   Показник: 10908.25 · (10 / 131853) = 10908.25 · 0.000075841 = 0.8273
   AF_10 = exp(0.8273) ≈ 2.29
   ```
4. **Високотемпературний діапазон (+105 °C → +115 °C, `T_1 = 378.15 К`):**
   ```
   Знаменник: 378.15 · 388.15 = 146779 К²
   Показник: 10908.25 · (10 / 146779) = 10908.25 · 0.000068129 = 0.7432
   AF_10 = exp(0.7432) ≈ 2.10
   ```

У діапазоні температур від +85 °C до +105 °C, де нормуються паспортні випробування конденсаторів, коефіцієнт прискорення лежить у межах `2.10 ... 2.29`. Інженерне округлення до значення `2.0` дає надійну консервативну оцінку знизу, формуючи класичне правило:

```
L_op = L_base · 2^( (T_max − T_core) / 10 )
```

### Моделювання теплового балансу та перегріву серцевини

Диференціальне рівняння нестаціонарного теплового балансу конденсатора має вигляд:

```
C_th · ( d(T_core) / dt ) = P_loss(t) − ( T_core(t) − T_ambient ) / R_th
```

де `C_th` — повна теплоємність компонента (Дж/°C), `R_th` — сумарний тепловий опір корпус-довкілля (°C/Вт), а `P_loss` — потужність активних втрат.

У сталому режимі (`d(T_core)/dt = 0`) перегрів гарячої точки серцевини відносно повітря дорівнює:

```
ΔT_core = T_core − T_ambient = P_loss · R_th = ( I_rms² · ESR(f, T) ) · R_th
```

Опір `ESR(f, T)` складається з трьох фізичних компонентів:

```
ESR(f, T) = R_electrolyte(T) + R_dielectric(f) + R_metal
```

1. `R_electrolyte(T)` — опір електроліту та паперу сепаратора; спадає з температурою внаслідок зростання рухливості іонів, але експоненційно зростає з роками в міру випаровування розчинника;
2. `R_dielectric(f) = tan δ_diel / ( 2π · f · C )` — діелектричні втрати в оксиді `Al2O3`; обернено пропорційні частоті пульсацій `f`;
3. `R_metal` — омічний опір алюмінієвих фольг, контактних пелюсток та виводів (стабільний, порядку 2–5 мОм).

## 3. Моделювання діелектричної абсорбції (Dielectric Absorption)

Діелектрична абсорбція (англ. *Dielectric Absorption*, DA або ефект діелектричної пам'яті / *soakage*) полягає у затримці вивільнення зв'язаного заряду поляризації після короткочасного розряджання конденсатора.

Фізична природа DA пов'язана з повільними механізмами дипольної та міжфазної поляризації Максвелла-Вагнера. В еквівалентній схемі конденсатор моделюється основною ємністю `C_0` та паралельними релаксаційними RC-ланцюгами `(R_i, C_i)` з різними сталими часу `τ_i = R_i · C_i` (від мілісекунд до годин).

Якщо конденсатор, заряджений до напруги `V_0`, замкнути накоротко на короткий час `t_short` (1–5 секунд), швидка ємність `C_0` встигає розрядитися до нуля. Проте заряди на релаксаційних ємностях `C_i` залишаються. Після розмикання виводів повільні ємності починають перерозподіляти свій залишковий заряд назад на основну ємність `C_0`.

Напруга самовідновлення на розімкнених виводах `V_rec(t)` описується рівнянням:

```
V_rec(t) = V_0 · ∑ [ ( C_i / C_0 ) · ( 1 − exp( − t_charge / τ_i ) ) · exp( − t_short / τ_i ) · ( 1 − exp( − t / τ_i ) ) ]
```

Коефіцієнт діелектричної абсорбції визначається як відсоток відновленої напруги `(V_rec / V_0) · 100 %`:
- **Тефлон (PTFE) та полістирол (PS):** `DA ≈ 0.01 ... 0.02 %` (найкращі для прецизійних інтеграторів);
- **Поліпропілен (PP):** `DA ≈ 0.02 ... 0.05 %` (ідеально для схем вибірки-зберігання S&H);
- **Кераміка Клас I (C0G):** `DA ≈ 0.05 ... 0.2 %`;
- **Кераміка Клас II (X7R):** `DA ≈ 1.5 ... 2.5 %`;
- **Алюмінієві електролітичні:** `DA ≈ 5.0 ... 15.0 %` (небезпека відновлення небезпечної для життя напруги до 30–50 В на розряджених високовольтних банках після зняття перемички).

## 4. Суперпозиція DC-bias ефекту та логарифмічного старіння MLCC

У реальній схемі під постійною напругою діють одночасно два механізми зниження ємності: швидке зниження діелектричної проникності через поляризаційне насичення (DC-bias) та повільний часовий дрейф від доменного пінінгу.

Підсумкова розрахункова ємність керамічного конденсатора `C(V, t)` описується мультиплікативною моделлю:

```
C(V, t) = C_nom · F_bias(V / V_rated) · [ 1 − k · log₁₀( t / t_0 ) ]
```

де `F_bias(v)` — функція деградації від напруги (для X7R розміру 0805 напруга `V = 0.6 · V_rated` дає `F_bias ≈ 0.55 ... 0.65`).

## 5. Статистичні моделі надійності: розподіл Вейбулла та B10 Life

Для великих вибірок конденсаторів процес старіння та накопичення дефектів діелектрика описується двопараметричним **розподілом Вейбулла** (англ. *Weibull distribution*, названим на честь шведського інженера Валодді Вейбулла, швед. *Waloddi Weibull*).

Ймовірність безвідмовної роботи `R(t)` протягом часу `t` визначається формулою:

```
R(t) = exp[ − ( t / η )^β ]
```

де:
- `η` (ета) — характерний термін служби або масштабний параметр (англ. *scale parameter*), що відповідає напрацюванню, за якого виходить з ладу `63.2 %` зразків вибірки (`R(η) = exp(−1) ≈ 0.368`);
- `β` (бета) — параметр форми (англ. *shape parameter*):
  - `β < 1` — період ранніх припрацьовувальних відмов (англ. *infant mortality*), зумовлений прихованими виробничими дефектами;
  - `β = 1` — період нормальної експлуатації зі сталою інтенсивністю випадкових відмов `λ = 1 / η` (експоненційний розподіл);
  - `β > 1` (зазвичай `β ≈ 2.5 ... 4.5` для електролітичних та плівкових конденсаторів) — період зносу та деградаційного старіння (англ. *wear-out phase*).

Миттєва інтенсивність відмов `λ(t)` у період зносу невпинно зростає за степеневим законом:

```
λ(t) = − ( 1 / R(t) ) · ( dR / dt ) = ( β / η ) · ( t / η )^(β − 1)
```

Для відповідальних автомобільних та аерокосмічних систем нормують не середній час до відмови (`MTTF`), а термін служби **B10 Life** (час, за який відмовляє рівно 10 % вибірки, тобто `R(t_B10) = 0.90`):

```
ln(0.90) = − ( t_B10 / η )^β
t_B10 = η · [ − ln(0.90) ]^(1 / β) = η · ( 0.10536 )^(1 / β)
```

Якщо для партії алюмінієвих електролітичних конденсаторів з параметром форми `β = 3.0` розрахунковий масштабний ресурс становить `η = 100 000 годин`, то гарантований термін `t_B10` складає:

```
t_B10 = 100 000 · (0.10536)^(1/3) = 100 000 · 0.4723 ≈ 47 230 годин
```

Це показує, що перші 10 % компонентів почнуть досягати межі EoL менш ніж через половину середнього терміну `η`.

## 6. Повний покроковий числовий приклад розрахунку EoL

**Сценарій:**
У трифазному частотному перетворювачі приводу конвеєра на шині постійного струму DC-link 400 В встановлено батарею з 4 паралельно з'єднаних електролітичних конденсаторів ємністю 1000 мкФ кожна.

**Вхідні паспортні та експлуатаційні дані:**
- Номінальна напруга конденсатора: `V_rated = 450 В`;
- Робоча напруга на шині DC-link: `V_op = 385 В`;
- Базовий ресурс: `L_base = 5000 годин` при `T_max = +105 °C`;
- Початковий опір однієї банки: `ESR_0 = 55 мОм = 0.055 Ом` на частоті 100 кГц;
- Сумарний змінний струм пульсацій шини: `I_total_rms = 12.0 А` (по `3.0 А` на кожен конденсатор);
- Тепловий опір алюмінієвого корпусу: `R_th = 28 °C/Вт`;
- Температура повітря у відсіку фільтрів: `T_ambient = +55 °C`;
- Річний графік роботи: `8000 годин/рік`.

**Покроковий аналітичний розрахунок:**

```
1. Розрахунок активних Джоулевих втрат в одній банці:
   P_loss = I_rms² · ESR_0
          = (3.0)² · 0.055                 [квадрат струму на початковий опір]
          = 9.0 · 0.055
          = 0.495 Вт

2. Розрахунок внутрішнього нагріву гарячої точки серцевини (hot-spot):
   ΔT_core = P_loss · R_th
           = 0.495 · 28.0                  [потужність на тепловий опір]
           = 13.86 °C

3. Розрахунок абсолютної температури серцевини:
   T_core = T_ambient + ΔT_core
          = 55.0 + 13.86                   [температура повітря + самонагрів]
          = 68.86 °C

4. Температурний коефіцієнт прискорення Арреніуса (правило 10 °C):
   ΔT_margin = T_max − T_core
             = 105.0 − 68.86               [запас до максимальної паспортної межі]
             = 36.14 °C
   AF_T = 2^( ΔT_margin / 10 )
        = 2^( 3.614 )                      [правило подвоєння на 10 градусів]
        ≈ 12.24

5. Напруговий коефіцієнт прискорення дератингу:
   V_ratio = V_op / V_rated
           = 385.0 / 450.0                 [коефіцієнт завантаження за напругою]
           ≈ 0.855
   Оскільки V_ratio > 0.80, застосовуємо лінійну поправку дератингу:
   AF_V = ( V_rated / V_op )^1.0
        = 450.0 / 385.0                    [відношення номіналу до робочої напруги]
        ≈ 1.169

6. Очікуваний термін служби до досягнення EoL:
   L_total = L_base · AF_T · AF_V
           = 5000 · 12.24 · 1.169          [добуток базового ресурсу на фактори]
           ≈ 71 540 годин

7. Переведення в календарні роки безперервної служби:
   Years_EoL = L_total / 8000
             = 71540 / 8000                [ділення на річне напрацювання]
             ≈ 8.94 років
```

**Критерії бракування на момент настання EoL (через ~9 років):**
- Ємність кожної банки зменшиться від `1000 мкФ` до `≤ 800 мкФ` (`ΔC = −20 %`);
- Опір `ESR` зросте від `55 мОм` до `≥ 110 мОм` (подвоєння втрат);
- Теплові втрати зростуть до `P_loss_end = 9.0 · 0.110 = 0.99 Вт`, а температура серцевини підніметься до `T_core_end = 55.0 + 0.99 · 28.0 = 82.7 °C`, викликаючи фінальний лавиноподібний знос компонента.
