# 🧮 Аналітичне виведення імпедансу, власного резонансу та PDN-антирезонансу

Високочастотний аналіз пасивних кіл, розрахунок шин розподілу живлення (PDN) та проектування демпфувальних ланцюгів неможливі без суворого аналітичного опису частотного відгуку неідеального конденсатора. Інтуїтивне уявлення про конденсатор як про «чисту ємність, опір якої спадає до нуля з ростом частоти» повністю втрачає чинність уже на частотах у кілька сотень кілогерців. Коли швидкість наростання струму в сучасних інтегральних схемах сягає десятків ампер за наносекунду, паразитні реактивні елементи та внутрішній активний опір втрат починають домінувати над номінальною ємністю, визначаючи стабільність напруги та тепловий режим вузла.

Нижче наведено послідовне математичне виведення повної частотної функції імпедансу, аналітичне визначення екстремумів модуля, поведінки добротності, траєкторії полюсів та нулів на комплексній площині, перехідних процесів у часовій області, а також розрахунок амплітуди й частоти паразитних паралельних антирезонансних піків, що виникають при паралельному ввімкненні компонентів різного номіналу.

### Повна операторна та частотна модель чотириполюсника

Повна еквівалентна схема неідеального конденсатора містить послідовну гілку з індуктивності виводів та внутрішньої геометрії `ESL`, сумарного опору втрат `ESR` та ідеальної ємності `C`. Ця послідовна структура шунтується паралельним опором витоку ізоляції `R_leak` (або `R_p`), який моделює кінцеву провідність діелектричного матеріалу на постійному струмі.

Операторний імпеданс послідовної гілки `Z_s(s)` у просторі перетворення Лапласа записується як сума трьох елементів:

```
Z_s(s) = s·ESL + ESR + 1 / (s·C)
       = (s²·ESL·C + s·ESR·C + 1) / (s·C)    [зведення до спільного знаменника]
```

Повний операторний імпеданс `Z(s)` з урахуванням паралельного опору витоку `R_leak` дорівнює паралельному з'єднанню послідовної гілки `Z_s(s)` та опору ізоляції `R_leak`:

```
Z(s) = (Z_s(s) · R_leak) / (Z_s(s) + R_leak)
     = R_leak · (s²·ESL·C + s·ESR·C + 1) / (s²·ESL·C·R_leak + s·(ESR + R_leak)·C + 1)
```

Цей дріб являє собою дробово-раціональну передавальну функцію другого порядку. Нулі цієї функції (корені чисельника) визначають частоти, на яких імпеданс спадає до мінімуму, тоді як полюси (корені знаменника) відповідають точкам потенційного зростання імпедансу.

Перейдемо від простору перетворення Лапласа до усталеного гармонічного режиму коливань. Для цього виконаємо класичну підстановку комплексної частоти `s = j·ω`, де `j = √(-1)` — уявна алгебраїчна одиниця, а `ω = 2·π·f` — циклічна кутова частота прикладеного змінного сигналу:

```
Z(j·ω) = R_leak · (1 - ω²·ESL·C + j·ω·ESR·C) / (1 - ω²·ESL·C·R_leak + j·ω·(ESR + R_leak)·C)
```

**Критерій спрощення до послідовної RLC-моделі:**
Для високоякісних діелектриків (кераміка класів 1 та 2, поліпропіленова плівка, полімерний алюміній) опір ізоляції `R_leak` становить від `10⁶` до `10¹² Ом`. У реальному робочому діапазоні частот `f ≥ 10 Гц` модуль реактивного опору ємності `1 / (ω·C)` становить від десятих часток ома до кількох кілоом, що на багато порядків менше за опір ізоляції `R_leak`.

Формально умова знехтування опором витоку записується через частоту зрізу вхідного RC-кола:

```
ω >> ω_leak = 1 / (R_leak · C)
```

Коли ця умова виконується, паралельний струм активного витоку крізь `R_leak` становить мізерну частку (менше однієї мільйонної) від сумарного струму зміщення крізь ємність. За таких умов повний імпеданс конденсатора з похибкою менше `0.001%` спрощується до класичного послідовного триелементного RLC-кола:

```
Z(j·ω) ≈ Z_s(j·ω) = ESR + j·(ω·ESL - 1 / (ω·C))
```

### Модуль імпедансу, реактивність та фазовий кут

Представимо спрощений імпеданс у канонічній алгебраїчній формі комплексного числа через дійсну та уявну частини `Z(j·ω) = Re(Z) + j·Im(Z)`:

```
Re(Z) = ESR(ω)
Im(Z) = X(ω) = ω·ESL - 1 / (ω·C)    [сумарний реактивний опір кола]
```

Дійсна частина `Re(Z)` відповідає виключно за дисипативні втрати — безповоротне перетворення електромагнітної енергії на тепловий потік Джоуля в металі та діелектрику. Уявна частина `Im(Z) = X(ω)` являє собою різницю двох протилежних реактивних опорів: індуктивного опору виводів `X_L = ω·ESL` (де струм відстає від напруги) та ємнісного опору `X_C = 1 / (ω·C)` (де струм випереджає напругу).

Модуль комплексного імпедансу `|Z(ω)|`, який вимірюється векторними аналізаторами кіл та вимірювачами імітансу LCR, дорівнює довжині радіус-вектора на комплексній площині:

```
|Z(ω)| = √( Re(Z)² + Im(Z)² )
       = √( ESR² + (ω·ESL - 1 / (ω·C))² )
```

Фазовий кут `θ(ω)` між вектором напруги на клемах конденсатора та вектором струму, що протікає крізь нього, визначається арктангенсом відношення реактивної складової до активної:

```
θ(ω) = arctan( Im(Z) / Re(Z) )
     = arctan( (ω·ESL - 1 / (ω·C)) / ESR )
```

Проаналізуємо асимптотичну поведінку фазового кута в трьох характерних частотних зонах:
1. **Низькочастотна ємнісна область (`ω·ESL << 1 / (ω·C)`):**
   Реактивний опір має від'ємний знак `X(ω) ≈ -1 / (ω·C) < 0`. Оскільки опір `ESR` у тисячі разів менший за модуль `1 / (ω·C)`, дріб під знаком арктангенса прямує до `-∞`. Відповідно, фазовий кут прямує до асимптотичного значення `θ(ω) → -π/2` (`-90°`). Струм випереджає напругу на чверть періоду коливань — це чистий ємнісний режим роботи.
2. **Точка переходу (резонанс):**
   Коли `ω·ESL = 1 / (ω·C)`, реактивний опір строго дорівнює нулю `X(ω) = 0`. Чисельник дробу обнуляється, і фазовий кут стає рівним `θ(ω) = 0°`. Напруга і струм збігаються за фазою — коло поводиться як суто омічний резистор опором `ESR`.
3. **Високочастотна індуктивна область (`ω·ESL >> 1 / (ω·C)`):**
   Реактивний опір стає додатним `X(ω) ≈ ω·ESL > 0`. Дріб під знаком арктангенса прямує до `+∞`, а фазовий кут стрімко наближається до `θ(ω) → +π/2` (`+90°`). Струм починає відставати від напруги — конденсатор повністю втрачає ємнісні властивості та починає працювати як дросель із фіксованою індуктивністю `ESL`.

### Аналітичне знаходження власної послідовної резонансної частоти (SRF)

Власна резонансна частота (Self-Resonant Frequency, SRF) за визначенням є точкою, де модуль функції імпедансу `|Z(ω)|` досягає свого абсолютного глобального мінімуму на осі додатних частот. 

Для знаходження точки екстремуму знайдемо першу похідну функції `|Z(ω)|` за кутовою частотою `ω` і прирівняємо її до нуля:

```
d|Z(ω)| / dω = 0
```

Застосовуємо правило диференціювання складної функції:

```
d|Z(ω)| / dω = d( √( ESR² + (ω·ESL - 1 / (ω·C))² ) ) / dω                      [похідна кореневої функції]
             = (1 / (2 · |Z(ω)|)) · d( ESR² + (ω·ESL - 1 / (ω·C))² ) / dω     [правило ланцюга для степеня 1/2]
             = (1 / (2 · |Z(ω)|)) · 2 · (ω·ESL - 1 / (ω·C)) · d( ω·ESL - 1 / (ω·C) ) / dω [диференціювання квадрата різниці]
             = ((ω·ESL - 1 / (ω·C)) / |Z(ω)|) · (ESL + 1 / (ω²·C))             [взяття похідної від реактивного опору]
```

Дослідимо отриманий аналітичний добуток. Знаменник `|Z(ω)| ≥ ESR > 0` завжди додатний і не може звернутися в нескінченність. Другий співмножник у дужках також є строго додатним для будь-яких фізичних компонентів за ненульової частоти:

```
ESL + 1 / (ω²·C) > 0   для всіх ω > 0, оскільки ESL > 0 та C > 0
```

Таким чином, єдиною фізичною умовою обнулення похідної є рівність нулю першого співмножника в чисельнику:

```
ω·ESL - 1 / (ω·C) = 0
ω·ESL = 1 / (ω·C)
ω² · ESL · C = 1
ω² = 1 / (ESL · C)
```

Оскільки частота коливань є суто додатним дійсним числом (`ω > 0`), вилучення квадратного кореня дає єдиний розв'язок для власної кутової частоти послідовного резонансу `ω_SRF`:

```
ω_SRF = 1 / √(ESL · C)
```

Переведемо кутову частоту (рад/с) у звичайну циклічну частоту коливань `f_SRF` (Гц) за співвідношенням `f = ω / (2·π)`:

```
f_SRF = 1 / (2·π · √(ESL · C))
```

Підставимо отримане значення `ω_SRF` назад у вихідну формулу модуля імпедансу:

```
|Z(ω_SRF)| = √( ESR² + (ω_SRF·ESL - 1 / (ω_SRF·C))² )                                    [підстановка кутової частоти]
           = √( ESR² + (1/√(ESL·C) · ESL - 1 / (1/√(ESL·C) · C))² )                      [підстановка ω_SRF = 1/√(ESL·C)]
           = √( ESR² + (√(ESL/C) - √(ESL/C))² )                                          [спрощення дробів під коренем]
           = √( ESR² + 0² )                                                              [взаємне скорочення реактансів]
           = ESR                                                                         [вилучення кореня з квадрата]
```

**Фундаментальні висновки аналізу:**
1. На власній резонансній частоті реактивний опір індуктивності виводів ідеально компенсує реактивний опір ємності діелектрика.
2. Мінімальний імпеданс, який конденсатор здатний забезпечити в електричному колі, строго обмежений значенням `ESR`. Жодне збільшення номінальної ємності не дозволяє опустити криву імпедансу нижче рівня `ESR`.
3. На всіх частотах вище `f_SRF` похідна `d|Z|/dω` є строго додатною, тобто опір компонента монотонно зростає за лінійним законом `|Z| ≈ 2·π·f·ESL`.

### Аналіз чутливості резонансної частоти до допусків компонентів

На практиці номінал ємності `C` та паразитна індуктивність монтажу `ESL` мають технологічний розкид (виробничий допуск, температурний дрейф, зміщення від напруги DC-bias). Знайдемо аналітичний зв'язок між відносними відхиленнями параметрів та зміщенням власної резонансної частоти.

Прологарифмуємо аналітичний вираз для частоти резонансу:

```
ln(f_SRF) = -ln(2·π) - 0.5·ln(ESL) - 0.5·ln(C)
```

Візьмемо повний диференціал від обох частин рівняння:

```
d(ln(f_SRF)) = df_SRF / f_SRF
             = -0.5 · (d(ESL) / ESL) - 0.5 · (dC / C)
```

Отриманий вираз доводить правило чутливості:
- Відносне зміщення резонансної частоти дорівнює півсумі відносних змін індуктивності та ємності, взятій із протилежним знаком.
- Якщо внаслідок ефекту постійного зміщення (DC-bias) ефективна ємність керамічного конденсатора X7R впала на `dC/C = -50%`, його резонансна частота зміститься вгору на:

```
df_SRF / f_SRF = -0.5 · (-0.50) = +0.25 (+25%)
```

Якщо конденсатор номіналом 10 мкФ з індуктивністю 1 нГн мав початковий розрахунковий резонанс на частоті `5.03 МГц`, то під робочою напругою його ємність зменшиться до 5 мкФ, а точка резонансу автоматично зміститься до `7.12 МГц`. Це явище необхідно враховувати при налаштуванні вузькосмугових режекторних фільтрів.

### Фізична дисперсія Дебая та частотна залежність ESR

Еквівалентний послідовний опір `ESR(ω)` не є сталою константою. За класичною релаксаційною моделлю Петера Дебая для полярних діелектриків комплексна відносна діелектрична проникність записується як:

```
ε*(ω) = ε_∞ + (ε_s - ε_∞) / (1 + j·ω·τ)
```

де `ε_s` — статична проникність на постійному струмі, `ε_∞` — високочастотна оптична проникність, `τ` — характерний час дипольної релаксації матеріалу.

Розділимо дійсну `ε'(ω)` та уявну `ε''(ω)` частини:

```
ε'(ω) = ε_∞ + (ε_s - ε_∞) / (1 + ω²·τ²)       [дійсна проникність накопичення заряду]
ε''(ω) = (ε_s - ε_∞) · ω·τ / (1 + ω²·τ²)     [уявна проникність діелектричних втрат]
```

Тангенс кута діелектричних втрат `tan(δ)` визначається як відношення уявної частини до дійсної:

```
tan(δ) = ε''(ω) / ε'(ω) = ((ε_s - ε_∞) · ω·τ) / (ε_s + ε_∞ · ω²·τ²)
```

Активний опір втрат у діелектрику `R_di(ω)` зв'язаний із тангенсом кута втрат та реактивною ємністю співвідношенням:

```
R_di(ω) = tan(δ) / (ω·C) = ((ε_s - ε_∞) · τ) / (C · (ε_s + ε_∞ · ω²·τ²))
```

На низьких і помірних частотах (`ω·τ << 1`), де диполі ще встигають переорієнтовуватися, знаменник спрощується до `C · ε_s`, і ми отримуємо фундаментальну залежність:

```
R_di(ω) ≈ tan(δ) / (2·π·f·C) ~ 1/f
```

Повний еквівалентний послідовний опір `ESR(ω)` є адитивною сумою діелектричних втрат `R_di(ω)` та активного омічного опору металевих обкладинок, виводів і контактних поверхонь `R_ohm(ω)`:

```
ESR(ω) = R_ohm(ω) + R_di(ω) = R_dc · (1 + k_skin · √ω) + tan(δ) / (ω·C)
```

де доданок `k_skin · √ω` кількісно описує зростання опору тонких шарів металізації внаслідок високочастотного [скін-ефекту](book:electronics/skin-effect).

### Диференціальні рівняння перехідного процесу в часовій області

Розглянемо реакцію неідеального конденсатора на стрибок струму споживання навантаження `ΔI` за скінченний час наростання `t_r` (імітація перемикання транзисторів цифрового ядра процесора).

Рівняння напруги на виводах конденсатора у часовій області за другим законом Кірхгофа:

```
v(t) = v_C(t) + v_ESR(t) + v_ESL(t)
     = (1 / C) · ∫ i(t) dt + i(t) · ESR + ESL · (di(t) / dt)
```

Якщо струм споживання наростає лінійно `i(t) = (ΔI / t_r) · t` від `0` до `ΔI` за інтервал часу від `t = 0` до `t = t_r`:

```
1. Індуктивне падіння напруги (триває лише під час фронту наростання 0 < t < t_r):
   V_drop_ESL = ESL · (di/dt) = ESL · (ΔI / t_r)

2. Омічне падіння напруги на послідовному опорі:
   V_drop_ESR(t) = i(t) · ESR   [наприкінці фронту при t = t_r сягає ΔI · ESR]

3. Ємнісний розряд внаслідок віддачі накопиченого заряду:
   V_drop_C(t_r) = (1 / C) · ∫ (ΔI / t_r) · t dt = (ΔI · t_r) / (2 · C)
```

Сумарний провал напруги шини живлення в найкритичніший момент завершення перемикання `t = t_r`:

```
ΔV_total = ESL · (ΔI / t_r) + ΔI · ESR + (ΔI · t_r) / (2 · C)
```

**Числовий аналіз внеску кожного складника:**
Візьмемо типові параметри сучасного процесорного перетворювача VRM: стрибок струму `ΔI = 20 А`, час наростання `t_r = 2 нс` (`di/dt = 10¹⁰ А/с`), вихідний конденсатор ємністю `C = 100 мкФ`, `ESR = 10 мОм`, `ESL = 1.5 нГн`.

Обчислимо внесок кожного фізичного механізму:

```
V_drop_ESL = 1.5·10⁻⁹ Гн · (20 А / 2·10⁻⁹ с) = 15.0 В
V_drop_ESR = 20 А · 0.010 Ом = 0.20 В = 200 мВ
V_drop_C   = (20 А · 2·10⁻⁹ с) / (2 · 100·10⁻⁶ Ф) = 0.0002 В = 0.2 мВ
```

Цей числовий розрахунок наочно доводить фундаментальне правило швидкісної схемотехніки: на наносекундних часових масштабах ємнісний розряд становить менше `0.01%` від загального збурення (`0.2 мВ`), тоді як індуктивне падіння `ESL · (di/dt)` генерує руйнівний імпульс амплітудою `15 В`, здатний миттєво пробити підзатворний діелектрик цифрових транзисторів.

### Аналітичний розрахунок паралельного антирезонансу в шині живлення (PDN)

У шинах живлення процесорів та цифрових НВІС для забезпечення низького імпедансу в широкому спектрі частот паралельно вмикають конденсатори різного технологічного типу:
- **Конденсатор 1 (Bulk, накопичувальний):** велика ємність `C1`, значна індуктивність `ESL1`, опір `ESR1` (наприклад, полімерний алюміній `100 мкФ`, `ESL1 = 2 нГн`, `ESR1 = 15 мОм`).
- **Конденсатор 2 (Decoupling, високочастотний):** мала ємність `C2`, крихітна індуктивність `ESL2`, опір `ESR2` (наприклад, багатошарова кераміка `0.1 мкФ`, `ESL2 = 0.3 нГн`, `ESR2 = 5 мОм`).

Співвідношення номіналів: `C1 >> C2` (у 1000 разів) та `ESL1 >> ESL2` (у 6.7 раза).

Резонансні частоти окремих гілок:

```
f_SRF1 = 1 / (2·π · √(ESL1 · C1)) ≈ 356 кГц
f_SRF2 = 1 / (2·π · √(ESL2 · C2)) ≈ 29.1 МГц
```

У проміжному частотному діапазоні між двома резонансами (`f_SRF1 < f < f_SRF2`):
1. Перший конденсатор уже перейшов власну точку SRF і поводиться як індуктивність `L_eff1 ≈ ESL1`.
2. Другий конденсатор ще не дійшов до власного SRF і поводиться як чиста ємність `C_eff2 ≈ C2`.

Комплексна еквівалентна провідність паралельного з'єднання двох гілок:

```
Y_total(j·ω) = 1 / Z1(j·ω) + 1 / Z2(j·ω)
             = 1 / (ESR1 + j·ω·ESL1) + 1 / (ESR2 + 1 / (j·ω·C2))
```

Зведемо до спільного знаменника та знайдемо сумарний імпеданс `Z_total(j·ω) = 1 / Y_total(j·ω)`:

```
Z_total(j·ω) = ( (ESR1 + j·ω·ESL1) · (ESR2 - j / (ω·C2)) ) / ( (ESR1 + ESR2) + j·(ω·ESL1 - 1 / (ω·C2)) )
```

Антирезонанс відповідає максимуму модуля імпедансу, що виникає при мінімумі знаменника, тобто коли уявна реактивна частина знаменника обнуляється:

```
ω_anti · ESL1 - 1 / (ω_anti · C2) = 0
ω_anti² · ESL1 · C2 = 1
```

Звідси частота паралельного антирезонансу `ω_anti`:

```
ω_anti = 1 / √(ESL1 · C2)
f_anti = 1 / (2·π · √(ESL1 · C2))
```

Підставимо числові значення:

```
f_anti = 1 / (2·π · √(2·10⁻⁹ Гн · 100·10⁻⁹ Ф))   [підстановка параметрів ESL1 та C2]
       = 1 / (2·π · √(200·10⁻¹⁸))                [перемноження індуктивності та ємності]
       ≈ 1 / (2·π · 14.14·10⁻⁹)                  [вилучення квадратного кореня]
       ≈ 11.25 МГц                               [ділення на 2·π та період]
```

Антирезонансна частота `11.25 МГц` потрапляє точно в діапазон між `356 кГц` та `29.1 МГц`.

**Розрахунок амплітуди пікового імпедансу `|Z_peak|`:**
Підставимо `ω_anti` у вираз для `Z_total`, нехтуючи добутками малих величин `ESR1 · ESR2`:

```
|Z_peak| ≈ (ω_anti·ESL1) · (1 / (ω_anti·C2)) / (ESR1 + ESR2)   [наближення для резонансного піку]
         = (ESL1 / C2) / (ESR1 + ESR2)                         [скорочення частоти ω_anti]
```

Знайдемо піковий імпеданс для нашого прикладу:

```
|Z_peak| ≈ (2·10⁻⁹ Гн / 100·10⁻⁹ Ф) / (0.015 Ом + 0.005 Ом)   [підстановка параметрів гілок]
         = 20 / 0.020                                          [обчислення хвильового опору та суми ESR]
         = 1000 мОм = 1.0 Ом                                   [підсумковий модуль пікового імпедансу]
```

**Фізичний парадокс та наслідки:**
Замість очікуваного наднизького імпедансу на рівні `5…15 мОм`, паралельне з'єднання створило на частоті 11.25 МГц гігантський пік імпедансу `1000 мОм` (у 100 разів вище за цільовий рівень!). Якщо мікропроцесор згенерує струмовий сплеск із гармонікою на частоті 11.25 МГц амплітудою 5 А, провал напруги живлення становитиме:

```
ΔV_noise = ΔI · |Z_peak| = 5 А · 1.0 Ом = 5.0 В
```

Такий шум миттєво призведе до апаратного скидання цифрового ядра з номінальною напругою живлення 1.0 В.

### Матричне узагальнення для довільного масиву з N конденсаторів

У реальних схемах живлення потужних графічних процесорів паралельно встановлюють десятки або сотні конденсаторів кількох різних номіналів (наприклад, 470 мкФ полімерні, 22 мкФ кераміка 0805, 1 мкФ кераміка 0402 та 100 нФ кераміка 0201). 

Для математичного розрахунку такого масиву використовують метод вузлових провідностей. Якщо кожен `k`-й конденсатор має комплексний імпеданс `Z_k(j·ω) = ESR_k + j·(ω·ESL_k - 1 / (ω·C_k))`, його комплексна провідність дорівнює:

```
Y_k(j·ω) = 1 / Z_k(j·ω) = (ESR_k - j·X_k(ω)) / (ESR_k² + X_k(ω)²)
```

Сумарна вхідна провідність шини розподілу живлення `Y_PDN(j·ω)` обчислюється як алгебраїчна сума провідностей усіх окремих паралельних гілок:

```
Y_PDN(j·ω) = ∑ [k=1..N] Y_k(j·ω)
           = ∑ [k=1..N] (ESR_k / |Z_k(ω)|²) - j · ∑ [k=1..N] (X_k(ω) / |Z_k(ω)|²)
           = G_PDN(ω) + j · B_PDN(ω)
```

де `G_PDN(ω)` — сумарна активна провідність втрат, а `B_PDN(ω)` — сумарна реактивна провідність (сусцептанс).

Підсумковий модуль імпедансу всієї системи розподілу живлення визначається оберненою величиною модуля сумарної провідності:

```
|Z_PDN(ω)| = 1 / |Y_PDN(j·ω)| = 1 / √( G_PDN(ω)² + B_PDN(ω)² )
```

Антирезонансні піки виникають на тих кутових частотах `ω_anti,m`, де сумарна реактивна провідність обнуляється `B_PDN(ω_anti,m) = 0`, проходячи через нуль зі зміною знака від ємнісного до індуктивного. У цих точках модуль імпедансу шини живлення повністю визначається активною провідністю:

```
|Z_PDN(ω_anti)| = 1 / G_PDN(ω_anti) = 1 / ( ∑ [k=1..N] (ESR_k / |Z_k(ω_anti)|²) )
```

Це матричне формулювання доводить, що збільшення кількості паралельних конденсаторів однакового номіналу лінійно збільшує дійсну частину провідності `G_PDN`, пропорційно знижуючи піковий імпеданс антирезонансу.

### Розрахунок теплових втрат при полігармонічному навантаженні

В імпульсних джерелах живлення струм, що протікає крізь конденсатор фільтра, не є чистою синусоїдою, а містить нескінченний ряд гармонік ряду Фур'є з частотами `f_n = n · f_sw`, де `f_sw` — тактова частота перемикання перетворювача:

```
i(t) = ∑ [n=1..∞] I_n · sin(n·ω_sw·t + φ_n)
```

Оскільки еквівалентний послідовний опір залежить від частоти `ESR = ESR(f)`, розрахунок сумарної теплової потужності втрат `P_total` вимагає інтегрування за всіма гармоніками струму:

```
P_total = ∑ [n=1..∞] I_n,rms² · ESR(n · f_sw)
```

де `I_n,rms = I_n / √2` — діюче значення `n`-ї гармоніки струму.

Підставивши аналітичну модель `ESR(f) = R_ohm + tan(δ)/(2·π·f·C)`, отримуємо формулу розрахунку повного тепловиділення в об'ємі конденсатора:

```
P_total = R_ohm · ∑ [n=1..∞] I_n,rms² + (tan(δ) / (2·π·C·f_sw)) · ∑ [n=1..∞] (I_n,rms² / n)
```

Ця формула суворо пояснює, чому високочастотні імпульсні перетворювачі гріють вихідні конденсатори значно менше, ніж низькочастотні випрямлячі: високочастотні гармоніки струму діляться на номер гармоніки `n` у діелектричній частині втрат, знижуючи сумарне тепловиділення `P_total` за однакового амплітудного струму.

### Виведення умови критичного демпфування (Damping)

Паралельний антирезонансний контур має еквівалентний характеристичний (хвильовий) опір `Z_0`:

```
Z_0 = √( ESL1 / C2 )
```

Його добротність `Q_anti` при сумарних послідовних втратах у гілках `R_s = ESR1 + ESR2`:

```
Q_anti = Z_0 / R_s = √( ESL1 / C2 ) / (ESR1 + ESR2)
```

Щоб повністю придушити паразитний сплеск імпедансу і перевести коливальний контур в аперіодичний режим, добротність контуру необхідно зменшити до величини `Q_anti ≤ 1` (критичне демпфування):

```
R_s_crit ≥ √( ESL1 / C2 )
```

Якщо збільшення власного `ESR` конденсаторів небажане (бо це погіршить згладжування пульсацій на інших частотах), застосовують додатковий паралельний демпфувальний RC-ланцюг (`R_damp + C_damp`).

Для паралельного демпфування оптимальний опір резистора обирають рівним характеристичному хвильовому опору паразитного контуру:

```
R_damp = Z_0 = √( ESL1 / C2 )
```

А ємність блокувального конденсатора `C_damp` обирають у 3–5 разів більшою за ємність високочастотного конденсатора `C2`:

```
C_damp ≥ 4 · C2
```

Таке співвідношення гарантує, що на частоті антирезонансу реактивний опір `C_damp` є зневажливо малим (`1 / (ω_anti·C_damp) << R_damp`), і резистор `R_damp` повністю розсіює енергію коливань між `ESL1` та `C2`, згладжуючи амплітудну характеристику PDN до плавної лінії без перевищення цільового імпедансу `Z_target`.
