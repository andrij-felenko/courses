# 📋 Матриця стандартів змін JEDEC JESD46/48 та рівнів кваліфікації PPAP / AEC-Q100

Під час серійного виробництва електронної апаратури заміна ревізії напівпровідникового компонента, перенесення фабрикації кристалів на іншу лінію (*wafer fab transfer*) або зміна матеріалу зварювальних мікродротів корпусу безпосередньо впливають на надійність, електромагнітну сумісність і тепловий режим готового приладу. Для запобігання раптовим виробничим збоям світова індустрія керується нормативними стандартами комітету JEDEC (*Joint Electron Device Engineering Council*) та Ради з автомобільної електроніки AEC (*Automotive Electronics Council*). Ця довідкова матриця регламентує класифікацію інженерних змін, структуру повідомлень PCN/PDN, 18 елементів пакету документації PPAP та стрес-профілі випробувань надійності AEC-Q100.

---

### 1. Класифікація повідомлень про зміни: стандарт JEDEC JESD46

Стандарт **JEDEC JESD46** (*Customer Notification of Product/Process Changes by Semiconductor Suppliers*) є головним нормативним документом напівпровідникової промисловості, що визначає обов'язкові правила, за якими постачальник мікросхем інформує замовників про будь-які плановані модифікації продукції, матеріалів або технологічних процесів.

#### 1.1. Критерії поділу змін на значущі (Major) та незначні (Minor)

Стандарт базується на концепції незмінності форми, прилягання, функції та якості компонента (*Fit, Form, Function, Quality and Reliability*):

```
+-------------------+-------------------------------------------+-----------------------+-----------------------+
| Рівень зміни      | Приклади виробничих подій                 | Строк сповіщення      | Кваліфікаційні зразки |
+-------------------+-------------------------------------------+-----------------------+-----------------------+
| Major Change      | • Нова маскова ревізія кристала           | Мінімум за 90 днів    | Обов'язково доступні  |
| (Значуща зміна)   | • Перенесення на іншу FAB-фабрику         | до першого відванта-  | не пізніше дати       |
|                   | • Зміна типу корпусу або компаунду        | ження комерційної     | офіційної публікації  |
|                   | • Перехід із золотого дроту на мідний     | партії клієнту        | повідомлення PCN      |
|                   | • Зміна фінального тестового майданчика   |                       |                       |
+-------------------+-------------------------------------------+-----------------------+-----------------------+
| Minor Change      | • Оновлення дизайну маркування коробки    | Не вимагає завчасного | Надаються за запитом  |
| (Незначна зміна)  | • Дрібні оптимізації внутрішніх тестів,   | сповіщення клієнта    | клієнта в разі        |
|                   |   що не впливають на форму, прилягання,   | за стандартом JESD46  | необхідності          |
|                   |   функцію (Fit, Form, Function) та якість |                       |                       |
+-------------------+-------------------------------------------+-----------------------+-----------------------+
```

1. **Значущі зміни (Major Changes):** Будь-яка зміна, яка потенційно здатна вплинути на електричні характеристики, термічний опір, паяність, електромагнітне випромінювання або сумісність із прошивкою. Сюди належать:
   - Введення нового степінгу кремнію (як базового All-layer, так і металевого ECO);
   - Перенесення виробництва пластин на іншу лінію (наприклад, перехід із фабрики TSMC Fab 12 на Fab 15 або заміна діаметра пластини з 200 мм на 300 мм);
   - Зміна матеріалу підкладки або перехід зі зварювальних дротів із чистого золота (Au) на мідні (Cu) або паладієво-мідні (CuPd) сплави;
   - Зміна хімічного складу епоксидного формувального компаунду корпусу (*Mold Compound*) або матеріалу покриття виводів (наприклад, перехід на чисте олово Matte Sn).

2. **Незначні зміни (Minor Changes):** Внутрішні модифікації, які гарантовано не змінюють жодного зовнішнього параметру компонента: оптимізація паперових етикеток на котушках (*Reel Labels*), зміна постачальника захисних антистатичних пакетів, оптимізація внутрішнього програмного забезпечення автоматичного пакувальника. Такі зміни фіксуються у внутрішньому журналі фабрики і не вимагають розсилання сповіщень клієнтам.

#### 1.2. Обов'язкова структура документу PCN (Product Change Notification)

Кожне офіційне повідомлення PCN від виробника напівпровідників містить строго фіксований набір технічних розділів:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       PRODUCT CHANGE NOTIFICATION                           │
│ PCN Tracking Number: PCN20260819001            Issue Date: 19-Aug-2026      │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. Affected Products: Повний перелік комерційних партномерів (OPN).         │
│ 2. Change Description: Детальний опис технічної суті модифікації.           │
│ 3. Reason for Change: Обґрунтування впровадження зміни (еррати / потужність)│
│ 4. Traceability: Маркування, коди дати (Date Code) та біти REVID.           │
│ 5. Qualification Summary: Результати тестів HTOL, HAST, ESD, Cpk.           │
│ 6. Key Milestones & Dates: Графік доступності зразків та відвантажень.      │
│ 7. Customer Response Deadline: 30 днів на надання офіційної відповіді.      │
└─────────────────────────────────────────────────────────────────────────────┘
```

- **Affected Part Numbers:** Вичерпний перелік усіх торгових партномерів мікросхем, яких торкнеться зміна.
- **Detailed Description of Change:** Порівняльний опис стану «До зміни» (*Before Change*) та «Після зміни» (*After Change*). Наприклад: зміна топології блоку тактування, заміна фотошаблону шару металізації Metal-3.
- **Reason for Change:** Чітке виробниче обґрунтування: закриття апаратних дефектів за документом Errata Sheet, підвищення відсотка придатних кристалів (*Yield Enhancement*), виведення з експлуатації застарілої виробничої лінії.
- **Traceability & Identification Method:** Способи відрізнення нової версії чіпа від старої. Описуються як візуальні ознаки (новий символ у верхньому рядку лазерного маркування корпусу, зміна маркування пакувальної коробки), так і програмні засоби (нове значення в системному регістрі ідентифікації `REVID`).
- **Qualification Data Summary:** Таблиця зведених результатів стрес-тестів надійності: тип випробування, тривалість, розмір вибірки та кількість зафіксованих відмов (критерій приймання: строго `0 failures / 231 units`).
- **Key Milestones Schedule:** Календарні дати:
  - *Sample Availability Date:* Дата, починаючи з якої клієнти можуть замовляти тестові зразки нової ревізії;
  - *Qualification Report Availability:* Дата публікації повного фінального звіту випробувань;
  - *First Ship Date (Implementation Date):* Дата першого відвантаження серійної продукції (не менше ніж через 90 днів після дати публікації PCN).
- **Customer Response Period:** Згідно з JESD46 замовник має 30 календарних днів з моменту отримання PCN для надання зворотного зв'язку, запиту додаткових кваліфікаційних зразків або висунення обґрунтованої інженерної відмови. Якщо протягом 30 днів відповіді не надано, зміна вважається прийнятою за замовчуванням (*deemed accepted*).

### 2. Життєвий цикл завершення виробництва: стандарт JEDEC JESD48

Стандарт **JEDEC JESD48** (*Product Discontinuance Notification, PDN*) регулює процедуру зняття компонентів з виробництва (*End of Life, EOL*), гарантуючи системним виробникам стабільний часовий коридор для виконання фінальних закупівель або інженерного перепроектування вузлів плати.

```
                  [Офіційна публікація PDN / EOL]
                                │
                                ▼
    ┌───────────────────────────────────────────────────────┐
    │  Вікно Last Time Buy (LTB): Мінімум 6 місяців        │
    │  Замовник зобов'язаний надати фінальне безокличне     │
    │  замовлення (Non-Cancellable, Non-Returnable — NCNR)  │
    └───────────────────────────┬───────────────────────────┘
                                │
                                ▼
    ┌───────────────────────────────────────────────────────┐
    │  Вікно Last Time Ship (LTS): Мінімум 6 місяців від LTB│
    │  (Сумарно 12 місяців від початкової дати PDN)         │
    │  Виробник виготовляє та відвантажує фінальну партію   │
    └───────────────────────────┬───────────────────────────┘
                                │
                                ▼
                  [Статус компонента: OBSOLETE]
                  Повне зупинення виробничих ліній
```

#### 2.1. Часові нормативи та зобов'язання сторін за JESD48

1. **Період розміщення фінального замовлення (Last Time Buy — LTB):** Стандарт зобов'язує постачальника надати клієнтам не менше **6 місяців** від дати виходу сповіщення PDN до кінцевого терміну розміщення замовлень (*LTB Order Deadline*). Усі замовлення, оформлені в цей період, отримують статус NCNR (*Non-Cancellable, Non-Returnable*) — замовник не має права скасувати або зменшити обсяг закупівлі.
2. **Період завершального відвантаження (Last Time Ship — LTS):** Виробник зобов'язаний виготовити та відвантажити замовлену продукцію протягом щонайменше **6 місяців** після дати закриття вікна LTB (сумарно не менше **12 місяців** від дати початкового повідомлення PDN).
3. **Статус Obsolete:** Після настання дати LTS виробничі маски та оснастка утилізуються, а компонент переходить у статус застарілого (*Obsolete*), роблячи подальші замовлення неможливими.

#### 2.2. Математичний розрахунок стратегічного запасу LTB

Під час отримання повідомлення PDN інженерний та закупівельний відділи підприємства виконують точний розрахунок фінального буферного запасу компонентів на весь залишковий життєвий цикл кінцевого виробу:

```
N_LTB = T_EOL · R_annual · (1 + K_scrap) + N_service
```

Покроковий аналіз компонентів формули:
1. `T_EOL` — прогнозований термін (у роках), протягом якого підприємство планує випускати власний прилад на ринок до його заміни новим поколінням.
2. `R_annual` — плановий середньорічний обсяг випуску приладу (шт/рік).
3. `K_scrap` — технологічний коефіцієнт втрат компонента під час поверхневого монтажу (SMT) на друковану плату. Для корпусів QFP/BGA він типово становить `0.02 ... 0.05` (2–5%).
4. `N_service` — нормативний страховий фонд запасних частин, призначений для виконання гарантійних зобов'язань та планового ремонту виробів у сервісних центрах протягом 5–10 років після припинення їхнього випуску.

### 3. Автомобільна кваліфікація кристалів: стандарт AEC-Q100

Стандарт **AEC-Q100** (*Failure Mechanism Based Stress Test Qualification for Integrated Circuits*) розроблений радою AEC як єдиний міжнародний стандарт надійності інтегральних мікросхем у транспортному машинобудуванні.

#### 3.1. Температурні класи надійності (AEC-Q100 Grades)

Кремнієві кристали, що проходять сертифікацію AEC-Q100, класифікуються за температурними діапазонами навколишнього середовища:

```
+-----------+-------------------------+---------------------------------------------------------+
| Клас      | Діапазон температур     | Типове розташування та застосування в транспорті        |
+-----------+-------------------------+---------------------------------------------------------+
| Grade 0   | −40 °C ... +150 °C      | Підкапотний простір, трансмісія, гальмівні системи, двигун|
| Grade 1   | −40 °C ... +125 °C      | Більшість підкапотних електронних блоків керування (ECU)|
| Grade 2   | −40 °C ... +105 °C      | Електроніка салону, дисплеї, системи допомоги водієві (ADAS)|
| Grade 3   | −40 °C ... +85 °C       | Мультимедіа, інформаційно-розважальні системи (Infotainment)|
+-----------+-------------------------+---------------------------------------------------------+
```

- **Grade 0 (−40 °C ... +150 °C):** Найжорсткіший клас надійності. Застосовується в датчиках тиску моторного масла, контролерах форсунок безпосереднього впорскування та модулях керування гальмами, розташованих безпосередньо на блоці циліндрів або колісних маточинах.
- **Grade 1 (−40 °C ... +125 °C):** Стандартний рівень для 80% електронних блоків керування автомобіля (ECU двигуна, кузовна електроніка BCM, шлюзи безпеки, інвертори тягових електроприводів).
- **Grade 2 (−40 °C ... +105 °C):** Електроніка всередині салону, цифрові панелі приладів, камери кругового огляду, системи автоматичного паркування.
- **Grade 3 (−40 °C ... +85 °C):** Інформаційно-розважальні комплекси, аудіопідсилювачі, мультимедійні дисплеї пасажирів.

#### 3.2. Матриця стрес-тестів надійності AEC-Q100 (Rev H)

Кваліфікаційні випробування інтегральних схем за стандартом AEC-Q100 поділяються на 7 спеціалізованих тестових груп:

```
+-----------+-----------------------------------+-----------------------------------+-----------------------+
| Код тесту | Назва випробування                | Умови та параметри навантаження   | Розмір вибірки/Критерій|
+-----------+-----------------------------------+-----------------------------------+-----------------------+
| HTOL      | High Temperature Operating Life   | 1000 годин при +125 °C (або +150°C)| 3 партії × 77 шт      |
|           | (Високотемпературний ресурстест) | під максимальною напругою V_max   | (231 шт, 0 відмов)    |
+-----------+-----------------------------------+-----------------------------------+-----------------------+
| ELFR      | Early Life Failure Rate           | 48 годин стресу при підвищеній    | 3 партії × 800 шт     |
|           | (Рання смертність кристалів)      | температурі та напрузі (Burn-in)  | (2400 шт, 0 відмов)   |
+-----------+-----------------------------------+-----------------------------------+-----------------------+
| HAST      | Highly Accelerated Stress Test    | 96 годин при +130 °C, вологості   | 3 партії × 77 шт      |
|           | (Стрес-тест тиску і вологості)    | 85% RH та надлишковому тиску      | (231 шт, 0 відмов)    |
+-----------+-----------------------------------+-----------------------------------+-----------------------+
| TC        | Temperature Cycling               | Від −65 °C до +150 °C,            | 3 партії × 77 шт      |
|           | (Термоциклювання)                 | 1000 або 2000 циклів              | (231 шт, 0 відмов)    |
+-----------+-----------------------------------+-----------------------------------+-----------------------+
| ESD HBM   | Human Body Model Electrostatic    | Імпульси 100 пФ / 1.5 кОм,        | По 3 зразки на крок;  |
|           | (Стійкість до розряду тіла)       | цільовий рівень: Class 2 (2000 В) | 0 відмов              |
+-----------+-----------------------------------+-----------------------------------+-----------------------+
| ESD CDM   | Charged Device Model              | Розряд власного корпусу чіпа,     | По 3 зразки на крок;  |
|           | (Розряд зарядженого приладу)      | цільовий рівень: Class C3 (500 В) | 0 відмов              |
+-----------+-----------------------------------+-----------------------------------+-----------------------+
| LU        | Latch-Up (Стійкість до тиристорного| Імпульси струму перевантаження     | 1 партія × 6 шт       |
|           | замикання за JESD78)              | ±100 мА при макс. температурі чіпа| (0 замикань живлення) |
+-----------+-----------------------------------+-----------------------------------+-----------------------+
```

1. **Група A (Accelerated Environment Stress):** Випробування на вплив вологи, температури та термошоку. Включає тест `HAST` (випробування під тиском при підвищеній вологості) та `TC` (жорстке циклічне перемикання від −65 °C до +150 °C для виявлення мікротріщин у кремнії та втомних руйнувань паяних з'єднань кристала з виводами).
2. **Група B (Accelerated Lifetime Simulation):** Тести прискореного старіння кремнію. `HTOL` (1000 годин роботи під граничною напругою та температурою) еквівалентний 15 рокам безперервної експлуатації автомобіля. Тест `ELFR` перевіряє тисячі мікросхем для виявлення дефектів «ранньої смертності» кремнієвих переходів.
3. **Група C (Package Assembly Integrity):** Механічні випробування міцності корпусу: зусилля на відрив зварювального мікродроту (*Wire Bond Pull Test*), зсув кулькового виводу (*Ball Shear Test*) та якість змочування виводів припоєм (*Solderability*).
4. **Група D (Die Fabrication Reliability):** Фізичні тести кристала: електроміграція металевих доріжок при високій щільності струму, деградація підзатворного діелектрика (*Time-Dependent Dielectric Breakdown, TDDB*), ефект гарячих носіїв заряду (*Hot Carrier Injection, HCI*) та температурна нестабільність напруги зміщення (*Negative Bias Temperature Instability, NBTI*).
5. **Група E (Electrical Verification):** Електростатичний захист `ESD HBM` (розряд тіла людини), `ESD CDM` (розряд зарядженого корпусу чіпа) та стійкість до тиристорного замикання `Latch-Up` за стандартом JEDEC JESD78.

### 4. Процедура схвалення виробничої частини PPAP (AIAG)

**PPAP** (*Production Part Approval Process*) — це обов'язковий регламент автомобільної індустрії (створений асоціацією AIAG), який гарантує, що постачальник напівпровідників повністю розуміє вимоги автовиробника і має стабільний виробничий процес, здатний випускати серійну продукцію з нульовим рівнем дефектів (*Zero Defect Strategy*).

#### 4.1. Рівні подання документації PPAP (Submission Levels)

Обсяг документів, що передаються замовнику під час зміни ревізії чіпа, визначається п'ятьма рівнями:

```
+-----------+-----------------------------------------------------------------------------------+
| Рівень    | Обсяг документів, що передаються замовнику                                        |
+-----------+-----------------------------------------------------------------------------------+
| Level 1   | Тільки гарантійний лист відповідності (Part Submission Warrant — PSW).            |
+-----------+-----------------------------------------------------------------------------------+
| Level 2   | Гарантійний лист PSW зі зразками продукції та обмеженим набором даних тестів.    |
+-----------+-----------------------------------------------------------------------------------+
| Level 3   | Повний стандартний пакет PPAP (усі 18 елементів + зразки). Дефолтний автопром.   |
+-----------+-----------------------------------------------------------------------------------+
| Level 4   | Гарантійний лист PSW та спеціальні вимоги, індивідуально визначені замовником.    |
+-----------+-----------------------------------------------------------------------------------+
| Level 5   | Повний пакет документації та фізичний аудит виробничої лінії на фабриці постачальника.|
+-----------+-----------------------------------------------------------------------------------+
```

- **Level 1:** Замовнику надається виключно підсумковий гарантійний лист `PSW`. Використовується лише для дрібних некритичних змін маркування.
- **Level 2:** Лист `PSW` разом із фізичними зразками мікросхем та скороченим звітом кваліфікації.
- **Level 3 (Автомобільний стандарт за замовчуванням):** Вимагає надання повного комплекту з усіх 18 обов'язкових елементів документації, результатів випробувань AEC-Q100 та партії фізичних зразків продукції. Будь-яка зміна ревізії кремнію мікроконтролера чи силового ключа автоматично подається за рівнем Level 3.
- **Level 4:** Індивідуальний обсяг документів, попередньо узгоджений між аудиторами автовиробника та постачальником.
- **Level 5:** Максимальний рівень контролю, що включає передачу всіх документів і проведення виїзного аудиту виробничої лінії на кремнієвій фабриці та складальному майданчику постачальника.

#### 4.2. 18 обов'язкових елементів пакету документації PPAP Level 3

```
+----+----------------------------------------------+---------------------------------------------------+
| №  | Назва елемента документації PPAP             | Суть документа для нової ревізії кремнію          |
+----+----------------------------------------------+---------------------------------------------------+
| 1  | Design Records (Записи проекту)              | Креслення корпусу, топологічні специфікації, даташит|
| 2  | Engineering Change Documents                 | Офіційне повідомлення PCN та опис змін ревізії    |
| 3  | Customer Engineering Approval                | Попереднє погодження інженерів автовиробника      |
| 4  | Design FMEA (DFMEA)                          | Аналіз видів і наслідків потенційних відмов схеми |
| 5  | Process Flow Diagram                         | Блок-схема виготовлення кристала та корпусування  |
| 6  | Process FMEA (PFMEA)                         | Аналіз ризиків дефектів на лінії літографії/збірки|
| 7  | Control Plan (План контролю)                 | Параметри контролю тестування пластин (Wafer Sort)|
| 8  | Measurement System Analysis (MSA)            | Калібрування та повторюваність тестерів ATE       |
| 9  | Dimensional Results                          | Протокол вимірювання фізичних розмірів корпусу    |
| 10 | Material / Performance Test Results          | Звіт випробувань надійності за стандартом AEC-Q100|
| 11 | Initial Process Studies (Cpk / Ppk)          | Індекси стабільності параметрів чіпа (Cpk >= 1.67)|
| 12 | Qualified Laboratory Documentation           | Сертифікати акредитації лабораторій (ISO/IEC 17025)|
| 13 | Appearance Approval Report (AAR)             | Звіт візуального контролю маркування та пакування |
| 14 | Sample Production Parts                      | Фізичні кваліфікаційні зразки нової ревізії чіпа  |
| 15 | Master Sample (Еталонний зразок)             | Зразок-еталон, що зберігається в архіві виробника |
| 16 | Checking Aids (Контрольні пристосування)     | Специфікація тестових сокетів та оснастки адаптерів|
| 17 | Customer-Specific Requirements               | Відповідність внутрішнім стандартам автоконцерну  |
| 18 | Part Submission Warrant (PSW)                | Підсумковий підписаний гарантійний сертифікат     |
+----+----------------------------------------------+---------------------------------------------------+
```

#### Детальний аналіз критичних елементів PPAP:
- **Design FMEA / Process FMEA (Елементи 4 та 6):** Оцінка ризиків виникнення відмов за шкалою RPN (*Risk Priority Number*). Для кожної виправленої еррати доводиться, що внесена зміна в топологію не створила нових прихованих дефектів.
- **Measurement System Analysis — MSA (Елемент 8):** Дослідження повторюваності та відтворюваності вимірювань (*Gauge R&R*). Помилка вимірювальних систем автоматичних тестерів ATE повинна становити менше 10% від ширини поля допуску параметра.
- **Initial Process Studies — Cpk / Ppk (Елемент 11):** Статистичний аналіз стабільності критичних параметрів мікросхеми (струм споживання, опорна напруга джерела живлення, частота тактового генератора). Індекс технологічної придатності процесу `Cpk` для нової ревізії зобов'язаний перевищувати значення `1.67` (що відповідає рівню дефектності менше 1 відмови на мільйон виготовлених чіпів — *PPM < 1*).
- **Part Submission Warrant — PSW (Елемент 18):** Юридичний документ, підписаний керівником служби якості постачальника, який засвідчує повну відповідність нової партії кремнію всім технічним умовам специфікації автовиробника.

### 5. Структура партномерів (Ordering Part Number — OPN) та простежуваність

Для унеможливлення випадкового змішування компонентів різного призначення та ревізій світові напівпровідникові виробники застосовують сувору систему кодування в структурі торгового партномера (*Ordering Part Number, OPN*).

```
Приклад автомобільного маркування: SPC560P50L5BEABR
┌──────┬────┬──┬──┬─┬──┬─┬─┬─┬─┐
│ SPC  │ 56 │0P│50│L│5 │B│E│A│R│
└──┬───┴─┬──┴┬─┴┬─┴┬┴┬─┴┬┴┬┴┬┴┬┘
   │     │   │  │  │ │  │ │ │ └─ Пакування: Tape & Reel (Котушка)
   │     │   │  │  │ │  │ │ └─── Фабрика збірки: Майданчик "A"
   │     │   │  │  │ │  │ └───── Температурний клас: E = −40...+125 °C (AEC-Q100 Grade 1)
   │     │   │  │  │ │  └─────── РЕВІЗІЯ КРЕМНІЮ: B = Степінг B0 (Фікс апаратних еррат)
   │     │   │  │  │ └────────── Напруга живлення: 5.0 В
   │     │   │  │  └──────────── Тип корпусу: LQFP-144
   │     │   │  └─────────────── Розмір пам'яті Flash: 512 КБ
   │     │   └────────────────── Підсімейство: Automotive Chassis & Safety
   │     └────────────────────── Архітектура ядра: Power Architecture 32-bit
   └──────────────────────────── Кваліфікаційний префікс: SPC = Automotive Qualified (AEC-Q100)
```

#### Принципова різниця між комерційними та автомобільними партномерами:

1. **Комерційні та індустріальні OPN (Префікси STM, LPC, ATsam, TMS):**
   Виробник продає чіп під загальним базовим номером (наприклад, `STM32F407VGT6`). За умовами стандартної комерційної специфікації постачальник залишає за собою право змінювати ревізію кремнію з `Rev A` на `Rev Z` або `Rev Y` без зміни партномера, якщо мікросхема зберігає базову функціональну сумісність. Інженер комерційного пристрою дізнається про новий степінг лише за фактом отримання повідомлення PCN або через зчитування системного регістра `DBGMCU_IDCODE`.

2. **Автомобільні та аерокосмічні OPN (Префікси SPC, FS, TMS570, S9S):**
   Кожен автомобільний партномер має виділений символ степінгу кремнію (наприклад, символ `B` у позиції ревізії). Постачальник не має юридичного права замінити кристал на ревізію `C` без відкриття нового партномера, випуску офіційного повідомлення PCN за 90 днів та повторного захисту повного пакету документації PPAP Level 3 перед кожним автовиробником. Така жорстка фіксація запобігає несанкціонованій зміні характеристик у критичних системах управління автомобілем та авіонікою.
