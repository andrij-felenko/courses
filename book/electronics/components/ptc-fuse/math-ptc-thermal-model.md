# 🧮 Теплова динаміка та біфуркація перемикання PPTC

Поведінка самовідновного полімерного запобіжника (PPTC) повністю визначається динамічним балансом між генерацією тепла всередині композиту та розсіюванням цього тепла в довкілля. На відміну від лінійного резистора, функція внутрішнього опору `R(T)` зазнає стрибка на 5 порядків біля температури плавлення полімерної матриці. Ця нелінійність перетворює звичайне теплове рівняння на систему з двома стійкими станами (біфуркацію), що й забезпечує ефект фіксації (*latching*) у розімкненому стані.

### 1. Мікроскопічна модель перколяції та температурного розширення

Провідність полімерного композиту описується статистичною теорією перколяції (від лат. *percolatio* — просочування). Якщо об'ємна частка провідного наповнювача (технічного вуглецю або нікелю) дорівнює `p`, а критичний поріг протікання становить `p_c`, питома електропровідність матеріалу `σ` виражається степеневим законом:

```
σ(p) = σ_0 · (p − p_c)^t    [для p > p_c]
```

де `σ_0` — власна провідність наповнювача, а `t ≈ 1.6...2.0` — критичний індекс перколяції для тривимірної системи.

При нагріванні полімерна матриця зазнає об'ємного теплового розширення з коефіцієнтом `β(T) = (1 / V) · (dV / dT)`. Оскільки маса вуглецевих частинок незмінна, їхня об'ємна концентрація `p(T)` зменшується зі зростанням температури:

```
p(T) = p_0 / [ 1 + β(T) · (T − T_0) ]
```

У напівкристалічному поліетилені високої густини (HDPE) коефіцієнт об'ємного розширення `β(T)` має гострий дельтоподібний пік при температурі плавлення кристалітів `T_m ≈ 125...135 °C`: об'єм стрибкоподібно зростає на `ΔV / V ≈ 10...15%`. 

У цій точці ефективна концентрація часток падає нижче критичного порогу (`p(T) < p_c`), неперервні омічні ланцюжки розриваються, і провідність падає до рівня діелектричної матриці з квантовим тунелюванням через широкі проміжки.

### 2. Динамічне диференціальне рівняння теплового балансу

Розглянемо термодинамічну модель компонента як однорідного тіла з ефективною теплоємністю `C_th` (вимірюється в Дж/К) та сумарним коефіцієнтом тепловідводу в навколишнє середовище `G_th` (вимірюється у Вт/К).

Швидкість зміни внутрішньої енергії тіла під дією електричного струму описується рівнянням балансу потужностей:

```
C_th · (dT / dt) = P_gen(T) − P_diss(T)
```

де складові потужності дорівнюють:
- `P_gen(T) = I^2 · R(T)` — швидкість генерації Джоулевого тепла всередині композиту;
- `P_diss(T) = G_th · (T − T_amb)` — швидкість тепловідведення в повітря та мідні доріжки плати за законом Ньютона при температурі середовища `T_amb`.

Підставивши обидва вирази, отримуємо повне нелінійне диференціальне рівняння теплової динаміки PPTC:

```
C_th · (dT / dt) = I^2 · R(T) − G_th · (T − T_amb)
```

### 3. Стаціонарні стани та виведення порогів I_hold і I_trip

В усталеному режимі температура компонента стабілізується (`dT / dt = 0`). Це дає рівність потужностей нагріву та тепловідводу:

```
I^2 · R(T) = G_th · (T − T_amb)
```

Звідси знайдемо струм `I(T)`, який створює рівноважну температуру `T`:

```
I(T) = √[ G_th · (T − T_amb) / R(T) ]
```

Дослідимо поведінку цієї функції при зміні температури від `T_amb` до температур вище точки фазового переходу:
1. У діапазоні помірного нагріву (`T_amb < T < 80 °C`) опір залишається практично незмінним (`R(T) ≈ R_cold`). Струм `I(T)` повільно монотонно зростає пропорційно квадратному кореню `√(T − T_amb)`.
2. При наближенні до точки плавлення полімеру (`T → T_trip`) опір `R(T)` починає різко зростати за експоненційним законом. У знаменнику під коренем з'являється велетенська величина, яка переважає лінійне зростання чисельника.
3. Отже, функція `I(T)` досягає максимуму при деякій критичній температурі `T_crit < T_trip`, після чого стрімко спадає.

Цей локальний максимум функції визначає точний фізичний поріг **струму утримання** `I_hold`:

```
I_hold = max { I(T) } = √[ G_th · (T_crit − T_amb) / R(T_crit) ]
```

Похідна струму за температурою в точці максимуму перетворюється на нуль:

```
d/dT [ G_th · (T − T_amb) / R(T) ] = 0
```

Розкриємо цю похідну за правилом диференціювання частки:

```
G_th · R(T) − G_th · (T − T_amb) · (dR / dT) = 0
```

Скоротивши на `G_th` і поділивши на `R(T)`, отримуємо точну аналітичну умову межі стійкості:

```
(1 / R) · (dR / dT) = 1 / (T_crit − T_amb)
```

**Фізичний зміст умови:** Стійка рівновага можлива лише доти, доки відносний температурний коефіцієнт опору `α_R = (1 / R) · (dR / dT)` менший за обернену різницю температур `1 / ΔT`. Щойно крутість зростання опору перевищує цей поріг, відведення тепла вже не встигає за саморозігрівом — починається незворотний тепловий розгін.

Мінімальний струм, який гарантовано викликає тепловий розгін при будь-якій тривалості дії, називається **струмом спрацьовування** `I_trip`. Для реальних матеріалів співвідношення між струмами становить:

```
I_trip ≈ (1.8...2.2) · I_hold
```

### 4. Аналітичне виведення температурного девейтингу струму

Оскільки тепловий баланс залежить від різниці температур між деталлю та середовищем `(T_trip − T_amb)`, номінальний струм утримання `I_hold` строго залежить від температури навколишнього середовища `T_amb`.

Знайдемо відношення струму утримання при довільній температурі `T_amb` до базового струму при кімнатній температурі 25 °C (`T_0 = 25 °C`):

```
I_hold(T_amb) / I_hold(25) = √[ (T_trip − T_amb) / (T_trip − T_0) ]
```

Підставивши типову температуру плавлення матриці `T_trip = 130 °C` та `T_0 = 25 °C` (де `T_trip − T_0 = 105 °C`), отримуємо розрахункову залежність фактора девейтингу `k_derate(T_amb)`:

```
k_derate(T_amb) = √[ (130 − T_amb) / 105 ]
```

Розрахуємо теоретичні коефіцієнти для стандартного індустріального ряду температур:
- При морозі `-40 °C`: `k_derate = √[ (130 − (-40)) / 105 ] = √(170 / 105) = √1.619 ≈ 1.27` (струм утримання зростає на +27%);
- При кімнатній `+25 °C`: `k_derate = √[ (130 − 25) / 105 ] = √1.000 = 1.00` (100% базового номіналу);
- При нагріві до `+60 °C`: `k_derate = √[ (130 − 60) / 105 ] = √(70 / 105) = √0.667 ≈ 0.816` (падає до 82%);
- При граничній спеці `+85 °C`: `k_derate = √[ (130 − 85) / 105 ] = √(45 / 105) = √0.428 ≈ 0.654` (падає до 65%).

Ця проста формула пояснює, чому один і той самий запобіжник на 1.5 А в закритому гарячому корпусі при 85 °C може спрацьовувати вже при струмі менше 1 А, тоді як на вулиці взимку при -40 °C він не розімкнеться навіть при струмі 2 А.

### 5. Біфуркація вольт-амперної характеристики та ефект фіксації (Latching)

Коли компонент переходить у високоомний гарячий стан, навантаження практично відключається, і майже вся напруга живлення джерела `U_src` падає безпосередньо на запобіжнику.

Тепер потужність тепловиділення записується через прикладену напругу:

```
P_gen(T) = U_src^2 / R(T)
```

Рівняння стаціонарного стану набуває вигляду:

```
U_src^2 / R(T) = G_th · (T − T_amb)
```

Оскільки `R(T)` у гарячому стані досягає десятків і сотень кілоомів, функція `P_gen(T) = U_src^2 / R(T)` монотонно падає зі зростанням температури. Пряма ж тепловідводу `P_diss(T) = G_th · (T − T_amb)` монотонно зростає. 

Ці дві лінії мають єдину стійку точку перетину при високій температурі `T_latched ≈ 130...145 °C`. 

Стабільність цієї гарячої точки підтверджується знаком похідної від результуючої потужності:

```
d/dT [ P_gen(T) − P_diss(T) ] = − (U_src^2 / R^2) · (dR / dT) − G_th < 0
```

Оскільки похідна строго від'ємна, будь-яке випадкове збурення температури миттєво компенсується:
- Якщо температура трохи впаде, опір `R` зменшиться, потужність нагріву `U^2 / R` зросте, і деталь нагріється назад.
- Якщо температура трохи зросте, опір збільшиться, виділення тепла зменшиться, і деталь охолоне до точки рівноваги.

У цьому полягає **механізм фіксації (latching)**: запобіжник самостійно утримує себе в розімкненому гарячому стані за рахунок мізерного струму витоку `I_leak`:

```
I_leak = U_src / R_hot
P_d = U_src · I_leak = G_th · (T_latched − T_amb)
```

Поки напруга `U_src` не буде повністю знята (або вимикачем, або знеструмленням пристрою), вийти з високоомного стану компонент фізично не може.

### 6. Аналітичний розрахунок часу спрацювання (Time-to-Trip)

Розділимо змінні в базовому динамічному рівнянні та проінтегруємо його від початкового моменту `t = 0` (`T = T_amb`) до моменту завершення фазового переходу `t = t_trip` (`T = T_trip`):

```
dt = C_th · dT / [ I^2 · R(T) − G_th · (T − T_amb) ]
```

```
t_trip = C_th · ∫ [T_amb → T_trip] dT / [ I^2 · R(T) − G_th · (T − T_amb) ]
```

#### Наближення 1. Адіабатичний розрив при потужному короткому замиканні (I >> I_trip)

Якщо струм аварії значно перевищує номінал (`I ≥ 5...10 · I_hold`), швидкість нагрівання настільки висока, що за короткий інтервал часу (мілісекунди) теплообміном із довкіллям можна знехтувати:

```
P_diss = G_th · (T − T_amb) ≈ 0
```

Вважаючи холодний опір усереднено постійним `R(T) ≈ R_cold`, обчислюємо інтеграл:

```
t_trip = C_th · ∫ [T_amb → T_trip] dT / (I^2 · R_cold)
       = C_th · (T_trip − T_amb) / (I^2 · R_cold)
```

Звідси отримуємо фундаментальний критерій комутаційної стійкості — сталість енергетичного інтеграла Джоуля (показника `I^2 · t`):

```
I^2 · t_trip = [ C_th · (T_trip − T_amb) ] / R_cold = const
```

Це означає, що при десятикратному зростанні аварійного струму час відключення скорочується рівно у 100 разів.

#### Наближення 2. Точний неадіабатичний розрахунок для помірних струмів

При помірному перевантаженні (`I ≈ 1.5...3.0 · I_hold`) тепловідведення в плату суттєво сповільнює нагрів. Введемо заміну змінної `ΔT = T − T_amb`:

```
t_trip = C_th · ∫ [0 → ΔT_trip] d(ΔT) / [ I^2 · R_cold − G_th · ΔT ]
```

Винесемо константу `G_th` у знаменнику:

```
t_trip = (C_th / G_th) · ∫ [0 → ΔT_trip] d(ΔT) / [ (I^2 · R_cold / G_th) − ΔT ]
```

Інтегруючи логарифмічний вираз:

```
t_trip = − (C_th / G_th) · [ ln | (I^2 · R_cold / G_th) − ΔT | ] [від 0 до ΔT_trip]
       = − (C_th / G_th) · ln [ 1 − G_th · ΔT_trip / (I^2 · R_cold) ]
```

Введемо теплову сталу часу `τ_th = C_th / G_th` та асимптотичний критичний струм розгону `I_crit = √[ G_th · ΔT_trip / R_cold ]`:

```
t_trip = − τ_th · ln [ 1 − (I_crit / I)^2 ]
```

Графік цієї функції демонструє класичну круту гіперболічну затримку: коли струм наближається до `I_crit` згори, час спрацювання асимптотично прямує до нескінченності.

### 7. Стійкість до ємнісних пускових кидків (Inrush Transients)

При підключенні навантаження з великою вхідною ємністю `C_load` виникає експоненційний імпульс струму:

```
i(t) = (U_src / R_total) · e^(− t / τ_el)
```

де `R_total = R_cold + R_esr + R_line`, а `τ_el = R_total · C_load` — електрична стала часу кола.

Повна теплова енергія, що виділяється у запобіжнику за час заряду ємності:

```
Q_inrush = ∫ [0 → ∞] i(t)^2 · R_cold · dt
         = (U_src^2 · R_cold / R_total^2) · ∫ [0 → ∞] e^(− 2t / τ_el) · dt
         = (U_src^2 · R_cold / R_total^2) · (τ_el / 2)
         = [ R_cold / (2 · R_total) ] · C_load · U_src^2
```

Оскільки тривалість заряду (`τ_el ~ десятки мікросекунд`) набагато менша за теплову сталу часу (`τ_th ~ десятки секунд`), процес є строго адіабатичним. Приріст температури становить:

```
ΔT_inrush = Q_inrush / C_th = [ R_cold · C_load · U_src^2 ] / [ 2 · R_total · C_th ]
```

**Критерій неспрацьовування:** Щоб пусковий кидок заряду конденсатора не викликав хибного відключення, приріст температури повинен не досягати порогу спрацювання:

```
ΔT_inrush < (T_trip − T_amb)
C_load < [ 2 · R_total · C_th · (T_trip − T_amb) ] / [ R_cold · U_src^2 ]
```

Цей розрахунок дозволяє точно визначити максимально допустиму ємність навантаження, яку можна безпечно підключати після PPTC без додаткових обмежувачів пускового струму.

### 8. М'яка комутація в індуктивних колах

При розриві струму в колі з індуктивністю `L` виникає індуктивний викид напруги:

```
U_ind = − L · (di / dt)
```

У звичайних плавких запобіжниках розрив нитки супроводжується спалахом електричної дуги, яка гасне за мікросекунди з гігантською швидкістю спадання струму (`di / dt ~ 10^6...10^8 А/с`), що створює кіловольтні піки ЕРС самоіндукції, здатні пробити напівпровідники.

На противагу цьому, у PPTC зростання опору відбувається плавно в міру фазового розширення полімеру протягом 10–200 мілісекунд. Швидкість спадання струму обмежена тепловою інерцією матриці:

```
di / dt ≈ − [ I_trip / (10...50 мс) ] ~ 10^2...10^4 А/с
```

Завдяки цьому пікова напруга самоіндукції на порядок менша, і PPTC працює як природний безискровий демпфер, безпечний для чутливих транзисторів і мікросхем.

### 9. Кінетика релаксації та деградація при циклічних спрацьовуваннях

Після зняття напруги компонент охолоджується в навколишнє середовище за експоненційним законом тепловіддачі:

```
T(t) = T_amb + (T_trip − T_amb) · e^(− t / τ_th)
```

Проте відновлення низького омічного опору не відбувається миттєво в момент досягнення температури `T_m`. Рекристалізація полімеру підпорядковується кінетичному рівнянню Джонсона–Мела–Аврамі–Колмогорова (ДМАК):

```
X(t) = 1 − exp [ − k · t^n ]
```

де `X(t)` — частка відновленої кристалічної фази, `k` — температурно-залежна швидкість зародкоутворення кристалітів, а `n ≈ 2...3` — геометричний показник зростання сферолітів.

Через затримку реорганізації кристалічних ламелей та механічну релаксацію напружень у полімерній сітці опір повертається до початкових значень із вираженим **гістерезисом**. 

Опір безпосередньо після охолодження до 25 °C (через 1 годину після аварії) позначається в специфікаціях як `R_1max` і зазвичай на 30–50% перевищує початковий опір абсолютно нового компонента `R_min`:

```
R_1max ≈ 1.3...1.5 · R_min
```

При багаторазових циклах спрацьовування (кількість циклів `N`) відбувається поступове накопичення мікротріщин у полімерній зшитій матриці та окислення поверхонь вуглецевих зерен. Емпірична динаміка дрейфу холодного опору описується степеневою залежністю:

```
R_cold(N) = R_initial · [ 1 + γ · N^0.4 ]
```

де `γ ≈ 0.05...0.08` — коефіцієнт циклічної втоми композиту. Після 100 циклів аварійного спрацьовування опір типово подвоюється, що призводить до пропорційного зниження робочого струму утримання `I_hold(N) = I_hold(0) / √(R_cold(N) / R_initial)`.

### 10. Наскрізний числовий розрахунок для SMD1812-150

Проведемо повний розрахунок теплодинамічних параметрів реального самовідновного запобіжника SMD1812 на струм утримання `I_hold = 1.5 А`.

**Паспортні параметри:**
- Початковий холодний опір при 25 °C: `R_cold = 0.04 Ом`;
- Максимальний післяаварійний опір: `R_1max = 0.065 Ом`;
- Опір у гарячому стані фіксації: `R_hot = 30 кОм = 30000 Ом`;
- Ефективна теплоємність деталі з контактними майданчиками: `C_th = 0.36 Дж/К`;
- Коефіцієнт тепловідводу на типовій FR4-платі: `G_th = 0.014 Вт/К`;
- Температура фазового переходу полімеру: `T_trip = 130 °C`;
- Температура навколишнього середовища: `T_amb = 25 °C`;
- Напруга живлення захищуваної лінії: `U_src = 12 В`.

#### Крок 1. Розрахунок теплової сталої та перепаду температур

```
ΔT_trip = T_trip − T_amb = 130 − 25 = 105 K
τ_th = C_th / G_th = 0.36 / 0.014 ≈ 25.71 с
```

#### Крок 2. Розрахунок критичного струму спрацювання

Потужність тепловідведення на порозі перемикання:
```
P_trip = G_th · ΔT_trip = 0.014 · 105 = 1.47 Вт
```

Теоретичний струм спрацювання за відсутності конвекції:
```
I_trip = √(P_trip / R_cold) = √(1.47 / 0.04) = √36.75 ≈ 2.69 А
```
Співвідношення `I_trip / I_hold = 2.69 / 1.5 = 1.79` точно відповідає паспортному ряду деталі.

#### Крок 3. Час спрацювання при подвійному перевантаженні (I = 3.0 А)

Застосуємо точну неадіабатичну формулу:
```
(I_crit / I)^2 = (2.69 / 3.0)^2 = 0.8967^2 ≈ 0.804
1 − (I_crit / I)^2 = 1 − 0.804 = 0.196
ln(0.196) ≈ − 1.6296
t_trip = − 25.71 · (− 1.6296) ≈ 41.9 с
```

При струмі 3.0 А компонент нагрівається майже 42 секунди. Це дозволяє пристрою спокійно переносити законні пускові струми заряджання вхідних ємностей без хибних відключень.

#### Крок 4. Час спрацювання при жорсткому короткому замиканні (I = 15 А)

При струмі короткого замикання 15 А застосуємо адіабатичне наближення:
```
P_gen = I^2 · R_cold = 15^2 · 0.04 = 225 · 0.04 = 9.0 Вт
Q_trip = C_th · ΔT_trip = 0.36 · 105 = 37.8 Дж
t_trip ≈ Q_trip / P_gen = 37.8 / 9.0 = 4.2 с   [при нагріві всього об'єму]
```

*Ефект локалізації (шнурування):* У реальному тонкому SMD-компоненті фазовий перехід починається в найтоншому поперечному мікрошарі товщиною в кілька мікронів, чия теплоємність становить лише `~5%` від повної теплоємності корпусу `C_local ≈ 0.018 Дж/К`. 

Тому локальний розрив перколяційних ланцюжків відбувається значно швидше:
```
t_trip_real ≈ 0.018 · 105 / 9.0 ≈ 0.21 с = 210 мс
```

За 210 мілісекунд коло надійно блокується до того, як розплавляться доріжки друкованої плати чи деградують електролітичні конденсатори.

#### Крок 5. Стан фіксації та струм витоку під напругою 12 В

Після утворення високоомного бар'єра опір становить `R_hot = 30 кОм`:
```
I_leak = U_src / R_hot = 12 / 30000 = 0.0004 А = 0.4 мА
P_hold = U_src · I_leak = 12 · 0.0004 = 0.0048 Вт (4.8 мВт)
```

Локальна потужність у зоні розриву надійно утримує шар полімеру в аморфному стані до вимкнення живлення.

#### Крок 6. Вплив площі мідного полігону на платі на коефіцієнт G_th

Коефіцієнт тепловідводу `G_th` складається з теплопровідності повітря `G_air` та теплопровідності мідних контактних доріжок плати `G_pcb`:

```
G_th = G_air + G_pcb
```

Якщо збільшити площу мідного полігону під виводами запобіжника з 20 мм² до 100 мм², `G_th` зростає з 0.014 Вт/К до 0.024 Вт/К (+71%).

Перерахуємо струм утримання для посиленого охолодження:
```
I_hold_boosted = √( (0.024 · 105) / 0.04 ) = √(2.52 / 0.04) = √63.0 ≈ 7.94 А
```
Тобто якісний тепловідвід на платі здатний істотно підвищити струм утримання компонента без заміни його типорозміру, що важливо враховувати при трасуванні силових шин.

#### Крок 7. Час повного охолодження та готовності до перезапуску

Після розмикання зовнішнього кола охолодження до температури початку рекристалізації (40 °C, де `ΔT_cool = 40 − 25 = 15 K`):
```
15 = 105 · e^(− t_cool / 25.71)
e^(− t_cool / 25.71) = 15 / 105 ≈ 0.1428
t_cool = − 25.71 · ln(0.1428) = − 25.71 · (− 1.946) ≈ 50.0 с
```

Повний тепловий цикл скидання захисту займає близько 50 секунд, після чого схема повертається до штатної працездатності.
