# 🧮 Математичний критерій защіпання: петльове підсилення, шунтувальні опори та вольт-амперна характеристика тиристора

Цей математичний апарат розкриває точні кількісні умови, за яких паразитні біполярні транзистори всередині комплементарної КМОН-структури переходять зі стану глибокого відсікання в режим лавиноподібного самопідтримуваного насичення. Без розрахунку петльового підсилення, струмів утримання та критичного заряду інжекції неможливо оцінити запас стійкості кристала до перехідних завад і спроєктувати надійну топологію інтегральної схеми.

## 1. Струмові рівняння дводіапазонної моделі тиристора

Чотиришарова напівпровідникова структура p⁺–n–p–n⁺ (витік PMOS, n-кишеня, p-підкладка, витік NMOS) представляється схемотехнічним еквівалентом із двох взаємопов'язаних біполярних транзисторів: вертикального PNP (`Q1`) та латерального NPN (`Q2`).

У загальному режимі зі спільною базою повний струм колектора кожного транзистора складається з інжектованого струму емітера, помноженого на коефіцієнт передачі струму `α`, та власного зворотного теплового струму витоку закритого колекторного p-n переходу `I_CBO`:

```text
I_C1 = α_pnp · I_E1 + I_CBO1       [колекторний струм PNP транзистора]
I_C2 = α_npn · I_E2 + I_CBO2       [колекторний струм NPN транзистора]
```

де:
- `α_pnp` та `α_npn` — статичні коефіцієнти передачі струму емітера у схемі зі спільною базою;
- `I_E1`, `I_E2` — повні струми емітерів відповідних транзисторів;
- `I_CBO1`, `I_CBO2` — теплові струми витоку зворотно зміщеного переходу n-кишеня — p-підкладка.

Зв'язок між коефіцієнтом передачі струму емітера `α` та коефіцієнтом підсилення струму бази `β` (у схемі зі спільним емітером) виражається фундаментальним співвідношенням:

```text
α = β / (β + 1)
β = α / (1 - α)
```

Коефіцієнт передачі струму емітера `α` є добутком двох фізичних величин: ефективності емітера `γ_e` (частка струму емітера, перенесена основними носіями емітера) та коефіцієнта переносу носіїв крізь базу `α_T`:

```text
α = γ_e · α_T
```

Розподіл надлишкової концентрації неосновних носіїв `n_p(x)` у квазінейтральній базі описується одновимірним диференційним рівнянням дифузії у стаціонарному стані:

```text
d²n_p(x) / dx² - (n_p(x) / L_n²) = 0
```

з граничними умовами на межі емітерного переходу `n_p(0) = n_p0 · exp(V_BE / V_T)` та на межі колекторного переходу `n_p(W_base) = 0`. Розв'язок цього рівняння дає точний вираз для коефіцієнта переносу крізь базу шириною `W_base`:

```text
α_T = 1 / cosh(W_base / L_n) ≈ 1 - (W_base² / (2 · L_n²))
```

де `L_n = √(D_n · τ_n)` — дифузійна довжина пробігу електронів у підкладці.

## 2. Петльове підсилення та умова регенеративного зриву

Розглянемо випадок, коли до структури підведено зовнішній струм тригерної інжекції `I_ext` (наприклад, імпульс перенапруги на виводі вводу-виводу). Згідно з першим законом Кірхгофа, загальний струм `I`, що протікає крізь чотиришарову структуру між шиною живлення VDD та шиною землі GND, дорівнює сумі колекторних струмів обох транзисторів та зовнішнього збурення:

```text
I = I_C1 + I_C2 + I_ext
```

Підставивши вирази для струмів колектора і врахувавши, що в ідеалізованій нешунтованій структурі струми емітерів збігаються з наскрізним струмом (`I_E1 = I_E2 = I`), отримуємо:

```text
I = (α_pnp · I + I_CBO1) + (α_npn · I + I_CBO2) + I_ext
I - α_pnp · I - α_npn · I = I_CBO1 + I_CBO2 + I_ext
I · [1 - (α_pnp + α_npn)] = I_CBO1 + I_CBO2 + I_ext
```

Виражаємо повний струм крізь структуру:

```text
I = (I_CBO1 + I_CBO2 + I_ext) / [1 - (α_pnp + α_npn)]
```

Аналіз знаменника цього дробу визначає фізичну поведінку системи:
1. **Лінійний підпороговий стан:** коли `(α_pnp + α_npn) << 1`, струм `I` залишається мізерним і визначається виключно сумою теплових струмів витоку `I_CBO`. Схема споживає наноампери.
2. **Критична точка регенеративного зриву:** коли сума коефіцієнтів передачі прямує до одиниці:

```text
α_pnp + α_npn → 1
```

Знаменник прямує до нуля, а загальний струм `I → ∞`. Фізично це означає, що додатний зворотний зв'язок стає нескінченно сильним: струм колектора першого транзистора повністю забезпечує струм бази другого, а струм колектора другого повністю відкриває перший.

Переведемо цю умову у коефіцієнти підсилення бази `β`:

```text
α_pnp + α_npn ≥ 1
[β_pnp / (β_pnp + 1)] + [β_npn / (β_npn + 1)] ≥ 1
β_pnp · (β_npn + 1) + β_npn · (β_pnp + 1) ≥ (β_pnp + 1) · (β_npn + 1)
β_pnp · β_npn + β_pnp + β_pnp · β_npn + β_npn ≥ β_pnp · β_npn + β_pnp + β_npn + 1
β_pnp · β_npn ≥ 1
```

Нерівність `β_pnp · β_npn ≥ 1` є класичним критерієм регенеративного защіпання (latch-up) за відсутності паразитних шунтувальних опорів.

## 3. Вплив шунтувальних опорів кишені та підкладки

У реальній монолітній інтегральній схемі бази біполярних транзисторів з'єднані з шинами живлення не безпосередньо, а через об'ємні опірні ділянки напівпровідника:
- `R_well` — розподілений опір тіла n-кишені між емітером PMOS і найближчим контактом `n⁺` (VDD Tap);
- `R_sub` — розподілений опір тіла p-підкладки між емітером NMOS і найближчим контактом `p⁺` (GND Tap).

Ці опори виконують роль струмових шунтів для емітерно-базових переходів `V_EB1` та `V_BE2`. Поки напруга на цих резисторах менша за контактну різницю потенціалів прямозміщеного p-n переходу (`V_BE(on) ≈ 0.6–0.7 В`), емітерні переходи залишаються закритими, а коефіцієнти `β` прямують до нуля.

Струми емітерів із врахуванням струмів шунтування `I_R_well` та `I_R_sub`:

```text
I_E1 = I_C2 + (V_EB1 / R_well)
I_E2 = I_C1 + (V_BE2 / R_sub)
```

Для того щоб транзистор `Q2` (NPN) почав відкриватися, струм у підкладці `I_sub`, створений колектором `Q1` або зовнішньою інжекцією `I_ext`, має створити критичне падіння напруги:

```text
V_BE2 = I_sub · R_sub ≥ V_BE(on) ≈ 0.65 В
```

Аналогічно для відмикання транзистора `Q1` (PNP):

```text
V_EB1 = I_well · R_well ≥ V_EB(on) ≈ 0.65 В
```

Звідси випливає фундаментальний інженерний висновок: **навіть якщо добуток `β_pnp · β_npn >> 1`, защіпання фізично неможливе, доки струми витоку чи завад не здатні створити падіння напруги 0.65 В на паразитних опорах `R_well` та `R_sub`**.

Критичний тригерний струм запуску `I_trig`, необхідний для збудження защіпання:

```text
I_trig = min( V_EB(on) / R_well,  V_BE(on) / R_sub )
```

Чутливість тригерного струму до варіації опору підкладки виражається частковою похідною:

```text
∂I_trig / ∂R_sub = -V_BE(on) / R_sub²
```

Звідси видно, що кожне двократне зниження `R_sub` викликає лінійне подвоєння стійкості схеми до струмових завад.

## 4. Струм і напруга утримання (Holding Current and Voltage)

Після переходу структури у стан защіпання обидва біполярні транзистори переходять у режим глибокого насичення. Щоб система залишалася в замкненому стані, струм, що протікає крізь структуру, не повинен падати нижче **струму утримання** (`I_hold`).

Струм утримання визначається балансом струмів, необхідних для підтримки обох емітерних переходів у відкритому стані:

```text
I_hold = (V_EB(on) / R_well) · [β_npn / (β_pnp · β_npn - 1)] + (V_BE(on) / R_sub) · [β_pnp / (β_pnp · β_npn - 1)]
```

Якщо `β_pnp · β_npn ≈ 1`, струм утримання суттєво зростає. Якщо ж підсилення велике (`β_pnp · β_npn >> 1`), формула спрощується до суми струмів шунтування:

```text
I_hold ≈ (V_EB(on) / R_well) + (V_BE(on) / R_sub)
```

**Напруга утримання** (`V_hold`) — це мінімальна напруга між виводами VDD та GND, нижче якої структура автоматично виходить із стану защіпання і повертається у високоомний режим. Вона складається з напруги прямого насичення одного переходу та напруги відкритого емітерного переходу іншого:

```text
V_hold = V_CE(sat, npn) + V_EB(on, pnp) + I_hold · R_series
```

Оскільки `V_CE(sat) ≈ 0.1–0.3 В`, а `V_EB(on) ≈ 0.7–0.8 В`, типова напруга утримання для кремнієвих КМОН-чипів становить:

```text
V_hold ≈ 0.9 … 1.5 В
```

Критичний критерій безумовної схемотехнічної безпеки:
- Якщо напруга живлення схеми `V_DD < V_hold`, тригерне замикання не може зафіксуватися. Навіть якщо потужний імпульс збудить паразитний тиристор, після закінчення імпульсу система миттєво відновиться, оскільки напруга джерела живлення недостатня для підтримки регенерації.
- У сучасних низьковольтних мікросхемах із живленням ядра `V_DD = 0.8–1.0 В` latch-up ядра стає фізично неможливим саме через виконання умови `V_DD ≤ V_hold`. Проте блоки введення-виведення (I/O) з живленням 1.8 В, 2.5 В або 3.3 В залишаються вразливими.

## 5. Динамічний тригерний критерій та інтеграл критичного заряду

Під час впливу короткочасних імпульсних перешкод (наприклад, електростатичного розряду ESD тривалістю 1–100 нс або прольоту важкої космічної частинки) амплітуда струму може багаторазово перевищувати статичний `I_trig`, проте защіпання не відбудеться, якщо тривалість імпульсу менша за час дифузійного прольоту носіїв крізь базу біполярних транзисторів.

Динамічна поведінка заряду неосновних носіїв `Q(t)` у квазінейтральній базі описується диференційним рівнянням балансу заряду:

```text
dQ(t) / dt = i_inj(t) - (Q(t) / τ_eff)
```

де `i_inj(t)` — миттєвий струм інжекції, а `τ_eff` — ефективний час життя носіїв у базовій області.

Для прямокутного імпульсу інжекції струму амплітудою `I_p` та тривалістю `t_p` розв'язок має вигляд:

```text
Q(t_p) = I_p · τ_eff · [1 - exp(-t_p / τ_eff)]
```

Защіпання настає лише тоді, коли накопичений заряд досягає критичної межі `Q_crit`:

```text
Q_crit = τ_eff · I_hold
```

Звідси випливає аналітичний вираз для динамічного порогу струму інжекції залежно від тривалості імпульсу:

```text
I_p(t_p) = I_hold / [1 - exp(-t_p / τ_eff)]
```

Аналіз асимптотичної поведінки цієї залежності:
- Для довгих імпульсів (`t_p >> τ_eff`): `I_p → I_hold`, динамічний поріг збігається зі статичним.
- Для надкоротких імпульсів (`t_p << τ_eff`): `I_p ≈ (τ_eff · I_hold) / t_p = Q_crit / t_p`. Амплітуда струму, необхідна для збудження, зростає обернено пропорційно тривалості імпульсу.

Ефективна стала часу регенеративної петлі враховує часи прольоту носіїв та ємності збіднених шарів:

```text
τ_eff = √( τ_pnp · τ_npn ) + (C_well · R_well + C_sub · R_sub)
```

Час переходу структури зі стану збудження у стаціонарний замкнений стан защіпання `t_transit` визначається трикратним значенням ефективної сталої часу:

```text
t_transit ≈ 3 · τ_eff ≈ 1.5 … 4.0 нс
```

Ця залежність пояснює, чому субнаносекундні електростатичні розряди (CDM — Charged Device Model) амплітудою в кілька ампер можуть не викликати latch-up, тоді як відносно слабкі, але тривалі імпульси інжекції (10–50 мкс) надійно запускають паразитний тиристор.

## 6. Малосигнальний аналіз та від'ємний диференційний опір

На ділянці зриву (Snapback) між точкою відмикання `(V_trig, I_trig)` та точкою утримання `(V_hold, I_hold)` чотиришарова структура поводиться як нелінійний двополюсник з від'ємним диференційним опором:

```text
r_diff = dV / dI < 0
```

Малосигнальний вираз для динамічного опору структури в перехідній області виводиться з диференціювання струмових рівнянь Кірхгофа:

```text
r_diff = - [ (R_well · β_pnp + R_sub · β_npn) / (β_pnp · β_npn - 1) ]
```

Оскільки `β_pnp · β_npn > 1`, знаменник додатний, а весь вираз набуває строго від'ємного значення. Наявність від'ємного опору робить проміжний стан абсолютно нестійким: будь-яке нескінченно мале збільшення струму викликає спад напруги на структурі, що миттєво перекидає робочу точку у високострумовий стан короткого замикання.

## 7. Ефект високого рівня інжекції (Ефект Вебстера)

При надвисоких густинах струму у замкненому стані тиристора (`J > 10⁴ А/см²`) концентрація інжектованих неосновних носіїв у базі перевищує фонову концентрацію легуючих домішок (`n_inj >> N_base`).

Цей режим називають **високим рівнем інжекції** (ефект Вебстера). Він супроводжується двома компенсаційними ефектами:
1. Ефективна ширина бази розширюється за рахунок витіснення електричного поля (ефект Кірка).
2. Коефіцієнт підсилення струму бази `β` починає спадати обернено пропорційно струму колектора:

```text
β(I_C) ≈ β_0 / (1 + (I_C / I_knee))
```

де `I_knee` — характерний струм перегину підсилення. Падіння `β` при екстремальних струмах обмежує подальший розгін лавини, стабілізуючи диференційний опір відкритого тиристора на низькому додатному рівні залишкового омічного опору металізації та контактів `R_on ≈ 0.5–1.5 Ом`.

## 8. Термодинаміка локального нагріву та тепловий розгін

Динаміка температури у точці замкненого каналу описується нестаціонарним рівнянням теплопровідності:

```text
C_th · (dT / dt) = V_hold · I_latched - ((T - T_amb) / R_th)
```

де:
- `C_th` — локальна теплоємність кремнієвого об'єму (Дж/К);
- `R_th` — тепловий опір розтікання тепла в підкладку (К/Вт);
- `T_amb` — температура навколишнього середовища.

Оскільки струм `I_latched` сам експоненційно зростає з температурою через генерацію термопар носіїв, виникає позитивний тепловий зворотний зв'язок:

```text
d(P_diss) / dT > 1 / R_th
```

Коли потужність тепловиділення перевищує здатність кристала відводити тепло у підкладку, настає катастрофічний термічний вибух (Thermal Runaway). Характерний час виходу на критичну температуру плавлення контактів (+450 °C) становить від 50 до 300 мікросекунд.

## 9. Температурна залежність параметрів защіпання

Температура навколишнього середовища чинить надзвичайно сильний дестабілізувальний вплив на стійкість до latch-up через одночасну зміну чотирьох ключових фізичних параметрів:

1. **Падіння контактної різниці потенціалів емітерних переходів:**
```text
V_BE(T) = V_BE(T0) - k_T · (T - T0)
```
де температурний коефіцієнт `k_T ≈ 1.8–2.2 мВ/К`. При нагріванні від +25 °C до +125 °C напруга відмикання переходів `V_BE(on)` зменшується з 0.7 В до ≈ 0.48 В (на 30%).

2. **Зростання коефіцієнтів підсилення `β`:**
З підвищенням температури збільшується довжина дифузійного пробігу носіїв заряду `L = √(D · τ)`, зменшується рекомбінація в базі, тому коефіцієнт підсилення зростає за степеневим законом:
```text
β(T) = β(T0) · (T / T0)^γ
```
де `γ ≈ 1.5–2.1`. При +125 °C добуток `β_pnp · β_npn` зростає у 2–3 рази.

3. **Зростання питомого опору кремнію:**
Через розсіювання носіїв на фононах кристалічної ґратки рухливість електронів `μ_n` та дірок `μ_p` падає (`μ ∝ T^(-2.3)`), що призводить до зростання опорів `R_well` та `R_sub` у 1.8–2.5 раза:
```text
R_sub(T) = R_sub(T0) · (T / T0)^2.3
```

Сумарний вплив температури на статичний тригерний струм:

```text
I_trig(T) = V_BE(on, T) / R_sub(T)  ∝  (0.7 - k_T · ΔT) / (R_sub0 · (T/T0)^2.3)
```

При зростанні температури кристала з 25 °C до 125 °C поріг виникнення latch-up струму `I_trig` знижується у **3–5 разів**. Мікросхема, яка демонструє абсолютну стійкість при кімнатній температурі (`I_trig > 250 мА`), може легко перейти в режим самозащіпання при 125 °C від струмового імпульсу всього 50 мА.

## 10. Повний числовий приклад розрахунку запасу стійкості

Розглянемо вихідний каскад вводу-виводу (GPIO Pad), виготовлений за 65-нанометровим техпроцесом КМОН при напрузі живлення `V_DD = 3.3 В`.

**Вихідні геометричні та фізичні параметри:**
- Відстань між PMOS у кишені та NMOS у підкладці: `L_AK = 4.0 мкм`;
- Опір кишені до найближчого VDD-контакту: `R_well = 450 Ом`;
- Опір підкладки до найближчого GND-контакту: `R_sub = 320 Ом`;
- Коефіцієнт підсилення вертикального PNP: `β_pnp = 0.8`;
- Коефіцієнт підсилення латерального NPN: `β_npn = 0.9` (при 25 °C);
- Ефективна стала часу структури: `τ_eff = 1.2 нс`.

**Розрахунок 1: Перевірка умови петльового підсилення при 25 °C:**
```text
Loop_Gain = β_pnp · β_npn = 0.8 · 0.9 = 0.72
```
Оскільки `0.72 < 1.0`, нешунтована структура не здатна до самопідтримуваної защіпки при кімнатній температурі.

**Розрахунок 2: Статичний тригерний струм запуску при 25 °C:**
```text
I_trig_sub = V_BE(on) / R_sub = 0.68 В / 320 Ом = 2.125 мА
I_trig_well = V_EB(on) / R_well = 0.68 В / 450 Ом = 1.511 мА
I_trig(25°C) = min(2.125 мА, 1.511 мА) ≈ 1.51 мА
```

**Розрахунок 3: Перевірка стійкості при максимальній робочій температурі 125 °C:**
Підвищення температури на `ΔT = 100 °C` змінює параметри:
- Напруга відмикання емітерного переходу: `V_BE(125°C) = 0.68 В - (2.0 мВ/К · 100 К) = 0.48 В`;
- Зростання опорів через падіння рухливості: `R_well(125°C) = 450 · (398 / 298)^2.3 ≈ 450 · 1.95 = 877 Ом`;
- Коефіцієнти підсилення: `β_pnp(125°C) = 0.8 · 1.6 = 1.28`, `β_npn(125°C) = 0.9 · 1.6 = 1.44`.

Перевіряємо нове петльове підсилення:
```text
Loop_Gain(125°C) = 1.28 · 1.44 ≈ 1.84  >  1.0
```
Петльове підсилення перевищило критичну одиницю — структура набула здатності до самопідтримуваного утримання.

Обчислюємо тригерний струм при 125 °C:
```text
I_trig_well(125°C) = 0.48 В / 877 Ом ≈ 0.547 мА = 547 мкА
```

**Розрахунок 4: Розрахунок критичного динамічного заряду при 125 °C:**
```text
I_hold(125°C) ≈ (0.48 / 877) + (0.48 / 624) ≈ 0.547 мА + 0.769 мА = 1.316 мА
Q_crit = τ_eff · I_hold = 1.2 · 10⁻⁹ с · 1.316 · 10⁻³ А ≈ 1.58 · 10⁻¹² Кл = 1.58 пКл
```

Якщо короткий імпульс ESD тривалістю `t_p = 100 пс` внесе заряд `Q > 1.58 пКл`, амплітуда струму складе `I_p = 1.58 пКл / 100 пс = 15.8 мА`, що гарантовано запустить latch-up.

Поріг струмового запуску впав майже у 3 рази: струмовий сплеск силою всього 550 мкА при 125 °C переводить мікросхему в режим незворотного короткого замикання. Для запобігання цій аварії тополог зобов'язаний додати охоронне кільце, яке зменшить `R_well` нижче 50 Ом.
