# 🧮 Математична модель теплової динаміки камери та налаштування PI-регулятора

Температурна нестабільність частоти кварцового генератора в термостаті визначається не лише властивостями зрізу кристала, а насамперед якістю роботи системи автоматичного регулювання температури. Якщо контур термостатування має завелике підсилення або невдало скориговану інтегральну ланку, камера входить у режим повільних автоколивань температури з амплітудою в десяті або соті частки градуса. Через температурно-частотний коефіцієнт резонатора ці мікропульсації перетворюються на паразитну частотну модуляцію з періодом у десятки секунд, руйнуючи девіацію Аллана на середніх інтервалах усереднення. Математичний розрахунок теплової динаміки дає змогу обрати параметри пропорційно-інтегрального (PI) регулятора так, щоб забезпечити аперіодичний перехідний процес без коливань і нульову статичну похибку за будь-якої температури навколишнього середовища.

## 1. Тепловий баланс камери як динамічного об'єкта

Термостат генератора складається з масивного металевого осердя (мідь або алюміній) з повною теплоємністю `C_th` (Дж/К), на якому змонтовано нагрівальний елемент потужністю `P_h(t)` (Вт), кварцовий резонатор і чутливий датчик температури (NTC-термістор). Осердя відокремлене від зовнішнього корпусу шаром теплоізоляції з сумарним тепловим опором `R_th` (К/Вт).

Рівняння теплового балансу пов'язує підведену електричну потужність `P_h(t)` зі швидкістю зміни внутрішньої температури камери `T(t)` та витоком тепла в навколишнє середовище з температурою `T_amb`:

```
P_h(t) - (T(t) - T_amb) / R_th = C_th · (dT(t) / dt)
```

Введемо перегрів камери відносно довкілля:

```
ΔT(t) = T(t) - T_amb
```

Підставивши перегрів у вихідне рівняння та помноживши обидві частини на `R_th`, отримуємо лінійне диференціальне рівняння першого порядку:

```
R_th · C_th · (dΔT(t) / dt) + ΔT(t) = R_th · P_h(t)
```

Величина `τ_th = R_th · C_th` є тепловою сталою часу камери (зазвичай від 30 до 120 секунд залежно від маси осердя та якості теплоізолятора). Застосувавши перетворення Лапласа за нульових початкових умов, переходимо до передавальної функції теплового об'єкта в операторній формі:

```
ΔT(s) · (1 + s · τ_th) = R_th · P_h(s)

G_th0(s) = ΔT(s) / P_h(s)
         = R_th / (1 + s · τ_th)
```

## 2. Просторове запізнення поширення тепла

Наведена передавальна функція першого порядку є наближенням ідеально перемішаного ізотермічного тіла. У реальній конструкції нагрівач і чутливий елемент термодатчика просторово рознесені в тілі металевого блоку на відстань `L`. Тепловий потік поширюється крізь кристал і метал шляхом дифузії тепла за рівнянням теплопровідності Фур'є:

```
∂T / ∂t = α_th · ∇²T
```

де `α_th = k_th / (ρ · c_p)` — коефіцієнт температуропровідності металу (м²/с), `k_th` — питома теплопровідність, `ρ` — густина, `c_p` — питома теплоємність матеріалу. Проходження теплового фронту від нагрівача до терморезистора створює фазове запізнення, еквівалентне часу затримки `τ_d`:

```
τ_d ≈ L² / (2 · α_th)
```

Для мідного блоку з відстанню `L = 10 мм` час затримки становить близько `τ_d ≈ 0.3...0.8 с`. У частотній області це запізнення описується експоненційним множником `e^(-s · τ_d)`. Повна динамічна модель теплового об'єкта набуває вигляду:

```
G_th(s) = (R_th / (1 + s · τ_th)) · e^(-s · τ_d)
```

Через наявність фазового зсуву `-ω · τ_d` на високих частотах просте збільшення підсилення пропорційного регулятора неминуче призводить до втрати стійкості петлі.

## 3. Передавальна функція вимірювального мосту та PI-регулятора

Датчик температури — NTC-термістор з опором `R_ntc(T)` — увімкнено в одне з плечей мосту Уїтстона, який живиться від стабілізованої напруги `V_ref`. Залежність опору NTC від температури описується характеристикою з коефіцієнтом чутливості `β_ntc`:

```
R_ntc(T) = R₀ · exp(β_ntc · (1/T - 1/T₀))
```

Поблизу робочої точки термостата `T_turn` (наприклад, 80 °C = 353.15 K) температурний коефіцієнт опору (ТКО) дорівнює:

```
α_ntc = (1 / R_ntc) · (dR_ntc / dT) = -β_ntc / T_turn²
```

Для стандартного NTC з `β_ntc = 3950 K` при 80 °C коефіцієнт становить `α_ntc ≈ -0.0316 К⁻¹` (-3.16 %/°C). Диференціальна напруга вимірювального мосту `ΔV_m(s)` за малих відхилень температури `ΔT(s) = T(s) - T_turn` є лінійною функцією відхилення:

```
K_bridge = (dΔV_m / dT) = (V_ref / 4) · |α_ntc|
```

За `V_ref = 5.0 В` чутливість мосту становить `K_bridge = (5.0 / 4) · 0.0316 ≈ 0.0395 В/К` (39.5 мВ/°C).

Сигнал розбалансу мосту підсилюється аналоговим операційним підсилювачем з пропорційно-інтегральним зворотним зв'язком. Схема складається з резистора вхідного кола `R_in`, резистора зворотного зв'язку `R_f` та послідовного конденсатора `C_f`. Її передавальна функція має вигляд:

```
W_pi(s) = V_out(s) / ΔV_m(s)
        = (R_f + 1 / (s · C_f)) / R_in
        = (R_f / R_in) · (1 + 1 / (s · R_f · C_f))
        = K_p · (1 + 1 / (s · T_i))
```

де `K_p = R_f / R_in` — коефіцієнт пропорційного підсилення, а `T_i = R_f · C_f` — стала часу інтегрування.

Вихідна напруга регулятора керує струмом силового нагрівального транзистора через крутизну перетворення `K_drv = dP_h / dV_out` (Вт/В). Результуючий коефіцієнт передачі електронного тракту дорівнює:

```
K_el(s) = K_bridge · W_pi(s) · K_drv
```

## 4. Аналіз стійкості замкненої системи та розрахунок параметрів

Розімкнена передавальна функція всієї петлі термостатування `L(s)` є добутком передавальних функцій регулятора, нагрівача та теплового об'єкта:

```
L(s) = K_loop · ((1 + s · T_i) / (s · T_i)) · (1 / (1 + s · τ_th)) · e^(-s · τ_d)
```

де статичний коефіцієнт петлі дорівнює:

```
K_loop = K_bridge · K_p · K_drv · R_th
```

Щоб виключити коливальні перехідні процеси й забезпечити максимальну швидкодію без перерегулювання, застосовують метод компенсації домінуючого полюса: сталу часу інтегрування `T_i` обирають рівною власній тепловій сталій часу камери `τ_th`:

```
T_i = τ_th = R_th · C_th
```

За такої умови нуль регулятора `(1 + s · T_i)` точно скорочує тепловий полюс камери `(1 + s · τ_th)`, і розімкнена функція спрощується до ланки з інтегратором та чистим запізненням:

```
L(s) = (K_loop / (s · τ_th)) · e^(-s · τ_d)
```

Фазо-частотна характеристика розімкненої системи дорівнює:

```
φ(ω) = -90° - ω · τ_d · (180° / π)
```

Частота зрізу петлі `ω_c`, на якій амплітуда `|L(jω_c)| = 1`, визначається співвідношенням:

```
K_loop / (ω_c · τ_th) = 1

ω_c = K_loop / τ_th
```

Для забезпечення запасу стійкості за фазою не менше ніж `PM = 60°` фазовий зсув на частоті зрізу не повинен перевищувати `-120°`:

```
-90° - ω_c · τ_d · (180° / π) >= -120°

ω_c · τ_d <= 30° · (π / 180°) = π / 6 ≈ 0.5236 рад
```

Звідси гранична частота зрізу та максимально допустиме петльове підсилення обмежуються виключно часом запізнення тепла `τ_d`:

```
ω_c_max = 0.5236 / τ_d

K_loop_max = ω_c_max · τ_th = 0.5236 · (τ_th / τ_d)
```

## 5. Числовий приклад розрахунку аналогового PI-контуру

Розглянемо параметри типової камери прецизійного OCXO на частоту 10 МГц:
* Маса мідного осердя: `m = 25 г`, питома теплоємність міді `c_p = 385 Дж/(кг·К)`, звідси `C_th = 0.025 · 385 = 9.625 Дж/К`.
* Тепловий опір ізоляції: `R_th = 40 К/Вт`.
* Власна стала часу камери: `τ_th = R_th · C_th = 40 · 9.625 = 385 с`.
* Затримка поширення тепла в осерді: `τ_d = 0.6 с`.
* Чутливість мосту: `K_bridge = 0.04 В/К`.
* Крутизна драйвера нагрівача: `K_drv = 1.5 Вт/В`.

Розрахуємо граничні динамічні параметри регулятора:

```
ω_c = 0.5236 / 0.6 = 0.873 рад/с   [частота зрізу для запасу за фазою 60°]

K_loop = 0.873 · 385 = 336.1       [максимальний коефіцієнт петлі]
```

Знаходимо необхідний коефіцієнт пропорційного підсилення `K_p`:

```
K_p = K_loop / (K_bridge · K_drv · R_th)
    = 336.1 / (0.04 · 1.5 · 40)
    = 336.1 / 2.4
    ≈ 140
```

Обираємо номінали пасивних компонентів для операційного підсилювача:
* Вхідний резистор: `R_in = 10 кОм`.
* Резистор пропорційного підсилення: `R_f = K_p · R_in = 140 · 10 кОм = 1.4 МОм`.
* Інтегруючий конденсатор: `C_f = T_i / R_f = 385 с / 1.4·10⁶ Ом ≈ 275 мкФ`.

Оскільки ємність 275 мкФ для прецизійного плівкового конденсатора є надто великою (електролітичні конденсатори не підходять через значні струми витоку, що спотворюють інтегрування), у практичних схемах застосовують Т-подібний міст або схему інтегратора з попереднім масштабним дільником напруги, що дозволяє зменшити необхідну ємність `C_f` до 1–10 мкФ за збереження сталої часу `T_i = 385 с`.

## 6. Придушення зовнішніх температурних збурень

Замкнена система стабілізації температури камери описується передавальною функцією придушення зовнішніх збурень `S_amb(s) = ΔT(s) / ΔT_amb(s)`:

```
S_amb(s) = 1 / (1 + L(s))
         = (s · τ_th) / (s · τ_th + K_loop · e^(-s · τ_d))
```

Для повільних квазістатичних змін зовнішньої температури (`s -> 0`) модуль передавальної функції прямує до нуля завдяки нескінченному підсиленню інтегральної ланки на постійному струмі. Статичний коефіцієнт придушення температурного дрейфу визначається лише паразитними витоками інтегратора та дрейфом напруги зсуву ОУ `V_os`.

Якщо дрейф напруги зсуву прецизійного zero-drift підсилювача становить `dV_os / dT_amb = 0.05 мкВ/°C`, то еквівалентна похибка підтримання температури камери при зміні температури довкілля на 50 °C становить:

```
ΔT_err = (dV_os / dT_amb · ΔT_amb) / K_bridge
       = (0.05·10⁻⁶ В/°C · 50 °C) / 0.04 В/°C
       = 2.5·10⁻⁶ В / 0.04 В/°C
       = 6.25·10⁻⁵ °C = 0.0625 mK
```

Зміна температури камери на 0.0625 mK біля точки нульового температурного коефіцієнта з параболічним параметром `b = -0.0035 ppm/K²` викликає зміщення частоти генератора:

```
Δf / f = b · (ΔT_err)²
       = -0.0035 · (6.25·10⁻⁵)² ppm
       ≈ -1.37·10⁻¹¹ ppm = -1.37·10⁻¹⁷
```

Цей розрахунок доводить, що за умови коректного налаштування аналогового PI-контуру та вибору робочої точки `T_turn` вплив зовнішньої температури на частоту генератора пригнічується практично до теоретичної межі шумів кристала.
