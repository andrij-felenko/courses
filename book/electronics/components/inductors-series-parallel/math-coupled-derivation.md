# 🧮 Математичне виведення еквівалентної індуктивності зв'язаних кіл

Коли дві або більше котушок мають спільне магнітне поле, напруга на кожній гілці визначається не лише її власною індуктивністю, а й взаємним впливом усіх сусідніх струмів. Без суворого аналітичного виведення неможливо точно передбачити ні еквівалентну індуктивність вузла, ні розподіл струмів між фазами, ні виникнення небезпечних циркулюючих струмів. Нижче наведено покроковий матричний та диференціальний розрахунок послідовного й паралельного з'єднань магнітозв'язаних індуктивностей на основі законів Фарадея та Кірхгофа.

### Базова система рівнянь магнітозв'язаного двополюсника

Розгляньмо пару індуктивностей `L₁` та `L₂`, між якими діє взаємоіндукція `M = k · √(L₁ · L₂)`. За законом електромагнітної індукції Фарадея, повний магнітний потік (потокозчеплення `ψ`), що пронизує кожну з котушок, складається з власного потоку самоіндукції та взаємного потоку, створеного струмом сусідньої обмотки:

```
ψ₁ = L₁ · i₁ ± M · i₂
ψ₂ = ± M · i₁ + L₂ · i₂
```

де знак «+» відповідає згідному напрямку магнітних ліній (струми входять в однойменні виводи, позначені крапками), а знак «−» — зустрічному напрямку магнітних ліній.

Диференціюючи потокозчеплення за часом `t`, знаходимо миттєві напруги на виводах кожної з котушок:

```
v₁(t) = dψ₁/dt = L₁ · (di₁/dt) ± M · (di₂/dt)
v₂(t) = dψ₂/dt = ± M · (di₁/dt) + L₂ · (di₂/dt)
```

У компактній матричній формі ця система лінійних диференціальних рівнянь першого порядку записується як:

```
[ v₁(t) ]   [  L₁   ±M  ]   [ di₁/dt ]
[       ] = [           ] · [        ]
[ v₂(t) ]   [  ±M   L₂  ]   [ di₂/dt ]
```

де симетрична квадратна матриця `[L]` розміром 2×2 є матрицею індуктивностей системи. Її визначник (детермінант) дорівнює:

```
det([L]) = L₁ · L₂ − (±M)² = L₁ · L₂ − M²
```

Оскільки коефіцієнт зв'язку задовольняє термодинамічну умову `0 ≤ k ≤ 1`, детермінант завжди невід'ємний:

```
det([L]) = L₁ · L₂ − k² · L₁ · L₂ = L₁ · L₂ · (1 − k²) ≥ 0
```

Рівність нулю досягається лише в ідеалізованому граничному випадку абсолютної відсутності розсіювання (`k = 1`).

### Аналітичне виведення послідовного з'єднання

При послідовному з'єднанні двох котушок через обидва елементи тече один і той самий струм `i(t)`, а загальна напруга кола `v(t)` складається зі спадів напруг на окремих обмотках згідно із законом напруг Кірхгофа.

#### Випадок 1: Згідне послідовне ввімкнення (Series-Aiding)

Струм входить у виводи з крапками для обох котушок: `i₁(t) = i₂(t) = i(t)`. Звідси похідні струмів збігаються: `di₁/dt = di₂/dt = di/dt`.

```
v(t) = v₁(t) + v₂(t)
     = [L₁ · (di/dt) + M · (di/dt)] + [M · (di/dt) + L₂ · (di/dt)]   [підстановка формул зв'язаних напруг]
     = (L₁ + M + M + L₂) · (di/dt)                                    [винесення спільного множника di/dt]
     = (L₁ + L₂ + 2·M) · (di/dt)                                      [зведення подібних доданків]
     = L_eq_aiding · (di/dt)                                          [за означенням v = L_eq · di/dt]
```

Порівнюючи коефіцієнти перед `di/dt`, отримуємо точний вираз:

```
L_eq_aiding = L₁ + L₂ + 2·M = L₁ + L₂ + 2·k·√(L₁·L₂)
```

Якщо обидві обмотки ідентичні (`L₁ = L₂ = L`):

```
L_eq_aiding = L + L + 2·k·√(L²) = 2·L · (1 + k)
```

За ідеального зв'язку (`k = 1`): `L_eq_aiding = 4·L`.

#### Випадок 2: Зустрічне послідовне ввімкнення (Series-Opposing)

Струм входить у крапку першої котушки й виходить із крапки другої (або одна з обмоток перевернута): `i₁(t) = i(t)`, `i₂(t) = −i(t)`.

```
v(t) = v₁(t) + v₂(t)
     = [L₁ · (di/dt) − M · (di/dt)] + [−M · (di/dt) + L₂ · (di/dt)]   [підстановка напруг із від'ємним знаком зв'язку]
     = (L₁ − M − M + L₂) · (di/dt)                                    [винесення di/dt за дужки]
     = (L₁ + L₂ − 2·M) · (di/dt)                                      [зведення подібних доданків]
     = L_eq_opposing · (di/dt)
```

Звідси еквівалентна індуктивність зустрічного з'єднання:

```
L_eq_opposing = L₁ + L₂ − 2·M = L₁ + L₂ − 2·k·√(L₁·L₂)
```

Для симетричних котушок (`L₁ = L₂ = L`):

```
L_eq_opposing = 2·L · (1 − k)
```

За ідеального зв'язку (`k = 1`): `L_eq_opposing = 2·L · (1 − 1) = 0`.

### Аналітичне виведення паралельного з'єднання

При паралельному з'єднанні до обох котушок прикладена спільна напруга `v₁(t) = v₂(t) = v(t)`, а загальний струм кола дорівнює сумі струмів гілок: `i_total(t) = i₁(t) + i₂(t)`.

Диференціюючи сумарний струм за часом, маємо:

```
di_total/dt = di₁/dt + di₂/dt
```

Знайдімо похідні струмів кожної гілки `di₁/dt` та `di₂/dt`, розв'язавши вихідну матричну систему через обернену матрицю `[L]⁻¹`.

Для матриці 2×2:

```
              1         [  L₂   ∓M  ]
[L]⁻¹ = ————————————— · [           ]
        L₁·L₂ − M²      [ ∓M    L₁  ]
```

Множачи обернену матрицю на вектор напруг `[v, v]ᵀ`, отримуємо похідні струмів:

```
[ di₁/dt ]       1         [  L₂   ∓M  ]   [ v ]
[        ] = ————————————— · [           ] · [   ]
[ di₂/dt ]   L₁·L₂ − M²    [ ∓M    L₁  ]   [ v ]
```

Звідси для кожної гілки окремо:

```
di₁/dt = v · (L₂ ∓ M) / (L₁·L₂ − M²)
di₂/dt = v · (L₁ ∓ M) / (L₁·L₂ − M²)
```

Додаємо обидві похідні для знаходження повної швидкості наростання струму:

```
di_total/dt = di₁/dt + di₂/dt
            = [v · (L₂ ∓ M) + v · (L₁ ∓ M)] / (L₁·L₂ − M²)      [зведення до спільного знаменника]
            = v · (L₁ + L₂ ∓ 2·M) / (L₁·L₂ − M²)                [групування чисельника]
```

За означенням еквівалентної індуктивності `v(t) = L_eq · (di_total/dt)`, отже:

```
L_eq = v / (di_total/dt)
     = (L₁·L₂ − M²) / (L₁ + L₂ ∓ 2·M)
```

- Знак «−» у знаменнику відповідає **згідному паралельному з'єднанню** (однойменні крапки з'єднані разом).
- Знак «+» у знаменнику відповідає **зустрічному паралельному з'єднанню** (крапка першої з'єднана з протилежним кінцем другої).

#### Розбір симетричного випадку L₁ = L₂ = L

Нехай обмотки однакові (`L₁ = L₂ = L`), а зв'язок дорівнює `M = k · L`.

Для згідного паралельного з'єднання:

```
L_eq_aiding = (L² − k²·L²) / (2·L − 2·k·L)
            = L² · (1 − k²) / [2·L · (1 − k)]               [винесення спільних множників]
            = L · (1 − k)·(1 + k) / [2 · (1 − k)]           [розкладання різниці квадратів]
            = L · (1 + k) / 2                               [скорочення на (1 - k)]
```

Для зустрічного паралельного з'єднання:

```
L_eq_opposing = (L² − k²·L²) / (2·L + 2·k·L)
              = L² · (1 − k²) / [2·L · (1 + k)]             [винесення спільних множників]
              = L · (1 − k)·(1 + k) / [2 · (1 + k)]         [розкладання різниці квадратів]
              = L · (1 − k) / 2                             [скорочення на (1 + k)]
```

### Модальний аналіз: синфазний та диференціальний струми

Щоб глибше зрозуміти внутрішню динаміку двох паралельних зв'язаних котушок, перейдемо від координат струмів гілок `(i₁, i₂)` до системи власних мод (модальних координат):

1. **Синфазний струм (Common Mode, CM):** половина повного струму навантаження:
   ```
   i_cm = (i₁ + i₂) / 2   →   i_total = 2 · i_cm
   ```
2. **Диференціальний (циркулюючий) струм (Differential Mode, DM):** контурний струм, що замикається між гілками:
   ```
   i_dm = (i₁ − i₂) / 2
   ```

Зворотне перетворення струмів:

```
i₁ = i_cm + i_dm
i₂ = i_cm − i_dm
```

Підставимо ці вирази у систему диференціальних рівнянь напруг для симетричних котушок `L₁ = L₂ = L`:

```
v = L · d(i_cm + i_dm)/dt ± M · d(i_cm − i_dm)/dt
v = ± M · d(i_cm + i_dm)/dt + L · d(i_cm − i_dm)/dt
```

Додаючи та віднімаючи ці два рівняння між собою, отримуємо розщеплену (діагоналізовану) систему незалежних мод:

Для суми (синфазна мода):

```
2·v = (L ± M) · 2 · (di_cm/dt)   →   v = (L ± M) · (di_cm/dt)
```

Оскільки повний струм `i_total = 2 · i_cm`, то `di_cm/dt = (1/2) · di_total/dt`. Тоді:

```
v = [(L ± M) / 2] · (di_total/dt)   →   L_cm_eq = (L ± M) / 2
```

Для різниці (диференціальна мода):

```
0 = (L ∓ M) · 2 · (di_dm/dt)   →   (L ∓ M) · (di_dm/dt) = 0
```

Еквівалентна індуктивність диференціального контуру дорівнює:

```
L_dm_eq = L ∓ M = L · (1 ∓ k)
```

Цей результат наочно показує фізику процесів:
- При зустрічному паралельному з'єднанні (знак «−») диференціальна індуктивність контуру становить `L_dm = L · (1 − k)`. За сильного зв'язку `k → 1` контурна індуктивність обнуляється (`L_dm → 0`). Будь-яка напруга розбалансу (наприклад, через асиметрію відкривання транзисторів) прикладена до нульового реактивного опору, породжуючи миттєвий стрибок циркулюючого струму.
- При згідному паралельному з'єднанні (знак «+») диференціальна індуктивність контуру максимальна: `L_dm = L · (1 + k) = 2·L`, що надійно блокує будь-які циркуляційні коливання між фазами.

### Операторний аналіз у комплексній площині Лапласа (s-domain) з урахуванням DCR

У реальних інженерних застосуваннях кожна обмотка володіє власним омічним опором постійному струму `DCR`. Для повного опису частотної поведінки та перехідних процесів перейдемо від часової області до операторної форми Лапласа, де оператор диференціювання `d/dt` замінюється комплексною змінною `s = σ + j·ω`.

Матриця повних операторних опорів (імпедансів) системи набуває вигляду:

```
[ V₁(s) ]   [ DCR₁ + s·L₁      ± s·M     ]   [ I₁(s) ]
[       ] = [                            ] · [       ]
[ V₂(s) ]   [    ± s·M      DCR₂ + s·L₂  ]   [ I₂(s) ]
```

Визначник комплексної матриці імпедансів `Z(s)` є квадратним тричленом відносно оператора `s`:

```
det(Z(s)) = (DCR₁ + s·L₁) · (DCR₂ + s·L₂) − s²·M²
          = DCR₁·DCR₂ + s · (DCR₁·L₂ + DCR₂·L₁) + s² · (L₁·L₂ − M²)
```

Цей вираз чітко демонструє структуру полюсів системи: коефіцієнт при `s²` визначається виключно магнітною індуктивністю без розсіювання `L₁·L₂ − M² = L₁·L₂·(1 − k²)`, лінійний коефіцієнт при `s` задається перехресними сталими часу омічних втрат, а вільний член є добутком омічних опорів.

#### Еквівалентний операторний опір паралельного з'єднання

При паралельному з'єднанні `V₁(s) = V₂(s) = V(s)`. Обертаючи матрицю `Z(s)`, знаходимо вираз для сумарного струму `I_total(s) = I₁(s) + I₂(s)`:

```
I_total(s) = V(s) · [ (DCR₁ + DCR₂) + s · (L₁ + L₂ ∓ 2·M) ] / det(Z(s))
```

Звідси еквівалентний операторний імпеданс паралельного вузла `Z_eq(s) = V(s) / I_total(s)` записується у вигляді дробово-раціональної функції:

```
Z_eq(s) = [ s² · (L₁·L₂ − M²) + s · (DCR₁·L₂ + DCR₂·L₁) + DCR₁·DCR₂ ] / [ s · (L₁ + L₂ ∓ 2·M) + (DCR₁ + DCR₂) ]
```

Аналізуючи асимптоти цієї передавальної функції, бачимо:
- При `s → 0` (постійний струм): `Z_eq(0) = (DCR₁ · DCR₂) / (DCR₁ + DCR₂) = DCR_eq`, що відповідає паралельному з'єднанню двох резисторів.
- При `s → ∞` (висока частота): `Z_eq(s) ≈ s · (L₁·L₂ − M²) / (L₁ + L₂ ∓ 2·M) = s · L_eq`, що збігається з виведеною раніше формулою для ідеальних індуктивностей.

Нуль функції `Z_eq(s)` виникає на частоті кросоверу, де омічний розподіл струму змінюється на чисто індуктивний. Якщо сталі часу гілок не узгоджені (`L₁/DCR₁ ≠ L₂/DCR₂`), передавальна функція містить фазовий зсув, що підтверджує виникнення внутрішньої циркуляції реактивної потужності.

### Зв'язок матриці індуктивностей із геометрією осердя (магнітна релюктанція)

Математичний апарат теорії кіл можна безпосередньо зв'язати з польовими рівняннями Максвелла через концепцію магнітного кола. Нехай дві обмотки з кількістю витків `N₁` та `N₂` намотані на осерді з площею поперечного перерізу `A_c`, середньою довжиною магнітної лінії `l_c` та відносною магнітною проникністю `μ_r`.

Магнітний опір (релюктанція) основної ділянки осердя обчислюється за формулою:

```
R_mc = l_c / (μ₀ · μ_r · A_c)
```

де `μ₀ = 4·π·10⁻⁷ Гн/м` — магнітна стала вакууму. Якщо осердя має немагнітний зазор довжиною `l_g`, релюктанція зазору становить:

```
R_mg = l_g / (μ₀ · A_c)
```

Повна релюктанція спільного магнітного шляху дорівнює сумі послідовних опорів: `R_m = R_mc + R_mg`. Обернена до релюктанції величина називається магнітною провідністю (пермеансом) осердя `Λ = 1 / R_m`.

Власні та взаємні індуктивності обмоток прямо виражаються через пермеанс спільного шляху `Λ_m` та пермеанси шляхів розсіювання `Λ_lk1`, `Λ_lk2`:

```
L₁ = N₁² · (Λ_m + Λ_lk1)
L₂ = N₂² · (Λ_m + Λ_lk2)
M  = N₁ · N₂ · Λ_m
```

Коефіцієнт магнітного зв'язку `k` набуває чисто геометричного змісту:

```
k = M / √(L₁·L₂) = Λ_m / √[ (Λ_m + Λ_lk1) · (Λ_m + Λ_lk2) ]
```

Якщо шляхи магнітного розсіювання відсутні (`Λ_lk1 = 0`, `Λ_lk2 = 0`), вираз під коренем спрощується до `Λ_m²`, а коефіцієнт зв'язку стає строго рівним одиниці: `k = Λ_m / Λ_m = 1`.

### Розв'язання часової задачі: відгук на східчастий стрибок напруги

Розгляньмо перехідний процес при підключенні пари паралельних зв'язаних котушок до джерела постійної напруги `V_in` у момент часу `t = 0` (східчаста дія Хевісайда `v(t) = V_in · u(t)`).

Для симетричного випадку `L₁ = L₂ = L`, `DCR₁ = DCR₂ = R` система диференціальних рівнянь у часовій області має вигляд:

```
L · (di₁/dt) ± M · (di₂/dt) + R · i₁ = V_in
± M · (di₁/dt) + L · (di₂/dt) + R · i₂ = V_in
```

Перейдемо до модальних координат синфазного струму `i_cm = (i₁ + i₂)/2` та диференціального струму `i_dm = (i₁ − i₂)/2`.

Для синфазної моди (сума рівнянь):

```
(L ± M) · (di_cm/dt) + R · i_cm = V_in
```

Це класичне диференціальне рівняння першого порядку з початковою умовою `i_cm(0) = 0`. Його точний аналітичний розв'язок:

```
i_cm(t) = (V_in / R) · [ 1 − exp( −t / τ_cm ) ]
```

де стала часу синфазного наростання струму дорівнює:

```
τ_cm = (L ± M) / R
```

Для диференціальної моди (різниця рівнянь):

```
(L ∓ M) · (di_dm/dt) + R · i_dm = 0
```

Якщо в початковий момент часу був присутній початковий розбаланс струмів `i_dm(0) = ΔI₀`, диференціальний циркулюючий струм затухає за експоненційним законом:

```
i_dm(t) = ΔI₀ · exp( −t / τ_dm )
```

де стала часу диференціального контуру становить:

```
τ_dm = (L ∓ M) / R = [ L · (1 ∓ k) ] / R
```

При зустрічному зв'язку зі сильним зчепленням (`k → 1`):
- Синфазна стала часу максимальна: `τ_cm = L·(1 + k)/R ≈ 2·L/R`. Загальний струм навантаження наростає плавно, з мінімальними пульсаціями.
- Диференціальна стала часу прямує до нуля: `τ_dm = L·(1 − k)/R → 0`. Це означає, що будь-який високочастотний динамічний дисбаланс струмів між фазами згасає практично миттєво, а опір диференціальним змінам надзвичайно малий, що забезпечує надшвидкий перерозподіл енергії між фазами.

### Покрокові числові розрахунки практичних задач

#### Задача 1. Розрахунок послідовного зв'язаного дроселя фільтра

**Умова:** Дві однакові секції дроселя з індуктивностями `L₁ = L₂ = 47 мкГн` намотані на спільному тороїдальному осерді з коефіцієнтом зв'язку `k = 0.92`. Визначити еквівалентну індуктивність вузла при згідному та зустрічному послідовному ввімкненні, а також швидкість зміни струму `di/dt` при подачі прямокутного імпульсу напруги 12 В.

**Розв'язання:**
1. Обчислюємо взаємну індуктивність обмоток:
   ```
   M = k · √(L₁ · L₂) = 0.92 · √(47 · 47) = 0.92 · 47 мкГн = 43.24 мкГн
   ```
2. Еквівалентна індуктивність при згідному ввімкненні:
   ```
   L_aiding = L₁ + L₂ + 2·M = 47 + 47 + 2 · 43.24 = 94 + 86.48 = 180.48 мкГн
   ```
   Швидкість наростання струму:
   ```
   di/dt_aiding = V / L_aiding = 12 В / 180.48 мкГн ≈ 0.0665 А/мкс = 66.5 кА/с
   ```
3. Еквівалентна індуктивність при зустрічному ввімкненні:
   ```
   L_opposing = L₁ + L₂ − 2·M = 47 + 47 − 2 · 43.24 = 94 − 86.48 = 7.52 мкГн
   ```
   Швидкість наростання струму:
   ```
   di/dt_opposing = V / L_opposing = 12 В / 7.52 мкГн ≈ 1.596 А/мкс = 1596 кА/с
   ```

**Висновок:** Зміна орієнтації виводів котушки на тому самому осерді змінює її еквівалентну індуктивність у 24 рази (`180.48 / 7.52 = 24`), а швидкість наростання струму зростає у 24 рази.

#### Задача 2. Розрахунок несиметричного паралельного вузла зі зв'язком

**Умова:** Паралельно з'єднано дві котушки з нерівними номіналами через технологічний розкид витків: `L₁ = 20 мкГн`, `L₂ = 30 мкГн`. Коефіцієнт зв'язку `k = 0.75` при зустрічному ввімкненні (знак «+» у знаменнику). До вузла прикладено змінну напругу з амплітудою 10 В. Знайти еквівалентну індуктивність `L_eq` та коефіцієнт розподілу струмів між гілками `di₁/dt` та `di₂/dt`.

**Розв'язання:**
1. Знаходимо взаємну індуктивність:
   ```
   M = k · √(L₁ · L₂) = 0.75 · √(20 · 30) = 0.75 · √600 = 0.75 · 24.495 мкГн ≈ 18.371 мкГн
   ```
2. Обчислюємо детермінант матриці індуктивностей:
   ```
   det([L]) = L₁ · L₂ − M² = 20 · 30 − 18.371² = 600 − 337.5 = 262.5 мкГн²
   ```
3. Обчислюємо еквівалентну індуктивність:
   ```
   L_eq = (L₁·L₂ − M²) / (L₁ + L₂ + 2·M)       [вихідна формула еквівалентної індуктивності]
        = 262.5 / (20 + 30 + 2 · 18.371)        [підстановка знайдених значень det([L]) та M]
        = 262.5 / (50 + 36.742)                 [обчислення доданків знаменника]
        = 262.5 / 86.742                        [знаходження сумарного знаменника]
        ≈ 3.026 мкГн                            [чисельне ділення та округлення]
   ```
4. Обчислюємо швидкості зміни струмів у гілках:
   ```
   di₁/dt = V · (L₂ + M) / det([L]) = 10 · (30 + 18.371) / 262.5 = 10 · 48.371 / 262.5 ≈ 1.843 А/мкс
   di₂/dt = V · (L₁ + M) / det([L]) = 10 · (20 + 18.371) / 262.5 = 10 · 38.371 / 262.5 ≈ 1.462 А/мкс
   ```
5. Перевірка балансу Кірхгофа:
   ```
   di_total/dt = di₁/dt + di₂/dt = 1.843 + 1.462 = 3.305 А/мкс
   di_total_check = V / L_eq = 10 В / 3.026 мкГн ≈ 3.305 А/мкс
   ```
   Співвідношення струмів гілок:
   ```
   (di₁/dt) / (di₂/dt) = 1.843 / 1.462 ≈ 1.261
   ```

**Висновок:** Через несиметрію перша гілка бере на себе на 26% більший струм пульсацій, ніж друга, що має враховуватися при розрахунку перерізу провідника та теплового режиму котушок.

#### Задача 3. Матричний розрахунок трифазного зв'язаного дроселя (3-Phase Coupled VRM)

**Умова:** Трифазний понижувальний перетворювач (3-Phase Interleaved Buck) використовує симетричний зв'язаний дросель, у якому всі фази мають однакову власну індуктивність `L = 100 нГн`, а коефіцієнт взаємного інверсного зв'язку між будь-якою парою сусідніх фаз становить `k = −0.4` (`M = k · L = −40 нГн`). Фази комутуються зі зсувом `120°` (`2·π / 3`). Необхідно:
1. Записати повну матрицю індуктивностей `[L]_(3×3)` та знайти її аналітичний детермінант.
2. Знайти власні числа матриці (еквівалентні індуктивності для різних режимів збудження фаз).
3. Обчислити ефективну індуктивність фази в стаціонарному режимі пульсацій `L_steady` та при синфазному стрибку навантаження `L_transient`.

**Розв'язання:**
1. Матриця індуктивностей для циркулярно-симетричного трифазного дроселя має вигляд:
   ```
   [L] = [  L   M   M  ]   [ 100  −40  −40 ]
         [  M   L   M  ] = [ −40  100  −40 ]  (нГн)
         [  M   M   L  ]   [ −40  −40  100 ]
   ```
   Детермінант симетричної циркулярної матриці 3×3 обчислюється аналітично через формулу:
   ```
   det([L]) = (L − M)² · (L + 2·M)
   ```
   Підставляємо чисельні значення (`M = −40 нГн`):
   ```
   L − M = 100 − (−40) = 140 нГн
   L + 2·M = 100 + 2 · (−40) = 100 − 80 = 20 нГн
   det([L]) = 140² · 20 = 19600 · 20 = 392 000 нГн³
   ```
2. Власні числа матриці `[L]` відповідають власним модам збудження:
   - **Синфазна мода (всі фази вмикаються одночасно при стрибку навантаження, вектор `[1, 1, 1]ᵀ`):**
     ```
     λ_cm = L + 2·M = 100 + 2 · (−40) = 20 нГн
     ```
     Це мінімальна індуктивність системи — чиста індуктивність розсіювання осердя. При раптовому переході процесора зі сплячого режиму у стан максимального споживання всі фази бачать індуктивність лише 20 нГн, що забезпечує надзвичайно швидке наростання сумарного струму:
     ```
     di_total/dt = 3 · (V_in − V_out) / λ_cm = 3 · (12 В − 1 В) / 20 нГн = 33 В / 20 нГн = 1.65 А/нс = 1650 А/мкс
     ```
   - **Диференціальні моди пульсацій (комутація зі зсувом фаз 120°, вектори `[1, e^(j2π/3), e^(j4π/3)]ᵀ`):**
     Матриця має двократно вироджене власне число:
     ```
     λ_dm1 = λ_dm2 = L − M = 100 − (−40) = 140 нГн
     ```
     У стаціонарному режимі чергового перемикання фаз діє підвищена диференціальна індуктивність 140 нГн, яка у 7 разів перевищує перехідну індуктивність (`140 / 20 = 7`) і на 40% більша за власну індуктивність кожної обмотки окремо.
3. Ефективні індуктивності:
   ```
   L_transient = λ_cm = 20 нГн
   L_steady = λ_dm = 140 нГн
   ```

**Висновок:** Застосування спареного трифазного дроселя з інверсним зв'язком `k = −0.4` дозволило одночасно зменшити розмах пульсацій струму у фазах (завдяки робочій індуктивності 140 нГн) та прискорити реакцію на стрибок струму в 5 разів порівняно з дискретними дроселями по 100 нГн (завдяки зменшенню динамічної індуктивності до 20 нГн).

### Узагальнення на N магнітозв'язаних паралельних гілок

Якщо паралельно з'єднано `N` довільних індуктивностей, взаємно зв'язаних між собою симетричною матрицею `[L]_(N×N)`:

```
[ v ]     [  L₁₁   M₁₂  …  M₁N  ]   [ di₁/dt ]
[ v ]     [  M₂₁   L₂₂  …  M₂N  ]   [ di₂/dt ]
[ … ]  =  [   …     …   …   …   ] · [   …    ]
[ v ]     [  MN₁   MN₂  …  LNN  ]   [ di_N/dt]
```

Вектор похідних струмів визначається дією оберненої матриці індуктивності `[Γ] = [L]⁻¹` (матриці інверсних індуктивностей, або матриці магнітної податливості):

```
[ di/dt ] = [L]⁻¹ · [ v ] = [Γ] · [ v ]
```

Повний струм вузла `i_total = ∑ i_k`. Швидкість наростання сумарного струму становить:

```
di_total/dt = ∑_{j=1}^N (di_j/dt) = v · ∑_{j=1}^N ∑_{k=1}^N Γ_{jk}
```

Звідси еквівалентна індуктивність `N` паралельних зв'язаних котушок обчислюється через суму всіх елементів оберненої матриці індуктивностей:

```
1 / L_eq = ∑_{j=1}^N ∑_{k=1}^N Γ_{jk}
```

Матриця `[Γ]` є дійсною, симетричною та додатно визначеною для будь-якої фізично реалізованої системи пасивних індуктивностей без порушення закону збереження енергії. Головні діагональні елементи `Γ_ii` визначають власну динамічну реакцію кожної окремої фази на прикладену напругу, тоді як недіагональні елементи `Γ_ij` кількісно описують перехресне динамічне наведення струму між парами фаз.

Якщо матриця зв'язків має повну циклічну симетрію (всі власні індуктивності рівні `L_ii = L`, а всі взаємні зв'язки між будь-якою парою сусідніх фаз однакові й дорівнюють `M`), обернена матриця обчислюється аналітично через дискретне перетворення Фур'є над циркулярними матрицями, що зводить складну задачу розрахунку до розкладання системи на ортогональні просторові магнітні гармоніки.

Цей універсальний матричний вираз лежить в основі чисельних алгоритмів сучасних SPICE-симуляторів для моделювання складних багатофазних магнітних вузлів.
