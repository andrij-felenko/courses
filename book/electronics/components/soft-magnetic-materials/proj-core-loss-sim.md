# ⚙️ Розрахунок робочої точки та втрат осердя

Проєктування індуктивних компонентів для імпульсних перетворювачів напруги вимагає точного узгодження магнітних параметрів осердя з електричним режимом схеми. У силовій електроніці магнітний компонент (дросель чи трансформатор) є найбільш теплонавантаженим і габаритним вузлом після силових напівпровідникових ключів. Помилка у виборі матеріалу магнітопроводу або неправильний розрахунок амплітуди магнітної індукції призводить до раптового заходу осердя в насичення, катастрофічного струмового перевантаження транзисторів або перевищення температурного ліміту ізоляції обмотки.

Наведений інструмент моделювання реалізує замкнений алгоритм розрахунку силового дроселя для понижувального (Buck) DCDC-перетворювача, що працює в режимі неперервного струму (Continuous Conduction Mode, CCM). Програма розраховує повний магнітний та тепловий стан компонента, оцінюючи струмові пульсації, постійну та змінну складові індукції, теплові втрати в осерді за рівнянням Штейнмеца, джоулеві втрати в мідній обмотці та кінцевий перегрів магнітопроводу над навколишнім середовищем.

---

### Фізико-математичний апарат симулятора

Для коректного проектування силового дроселя необхідно одночасно враховувати взаємодію трьох фізичних процесів: комутаційних процесів у напівпровідниковому контурі, електродинамічних полів у магнітопроводі та теплообміну конструкції з навколишнім повітрям.

```
       [ Вхідні параметри: V_in, V_out, I_out, f_sw, L, N, Геометрія, Матеріал ]
                                        │
                                        ▼
                   ┌─────────────────────────────────────────┐
                   │    1. Електричний аналіз шпаруватості   │
                   │    D = V_out / V_in                     │
                   │    ΔI = (V_in - V_out) · D / (f_sw · L) │
                   │    I_rms = √(I_out² + ΔI² / 12)         │
                   └────────────────────┬────────────────────┘
                                        │
                                        ▼
                   ┌─────────────────────────────────────────┐
                   │    2. Магнітний стан осердя             │
                   │    B_ac = (L · ΔI) / (2 · N · A_e)      │
                   │    B_dc = (L · I_out) / (N · A_e)       │
                   │    B_pk = B_dc + B_ac                   │
                   └────────────────────┬────────────────────┘
                                        │
                                        ▼
                   ┌─────────────────────────────────────────┐
                   │    3. Розрахунок теплових втрат         │
                   │    P_core = C_m · f^α · B_ac^β · V_e    │
                   │    P_cu = I_rms² · R_wire               │
                   │    P_total = P_core + P_cu              │
                   └────────────────────┬────────────────────┘
                                        │
                                        ▼
                   ┌─────────────────────────────────────────┐
                   │    4. Теплова модель та перевірка меж   │
                   │    ΔT = P_total · R_th                  │
                   │    T_final = T_ambient + ΔT             │
                   │    Перевірка: B_pk < B_sat(T_final)     │
                   └─────────────────────────────────────────┘
```

#### 1. Розрахунок електричного режиму
Під час замкненого стану верхнього силового ключа перетворювача до дроселя прикладена пряма різниця напруг `(V_in − V_out)`. За цей інтервал часу струм через індуктивність лінійно зростає зі швидкістю, визначеною законом самоіндукції `di/dt = U_L / L`.

Тривалість відкритого стану ключа визначається шпаруватістю `D` та періодом комутації `T_sw = 1 / f_sw`:

```
t_on = D / f_sw = (V_out / V_in) / f_sw
```

Розмах струмових пульсацій від піку до піку:

```
ΔI = ((V_in − V_out) · t_on) / L
```

Для гарантування роботи в режимі неперервного струму (CCM) середній струм навантаження повинен перевищувати критичну межу переходу в переривчастий режим: `I_out > I_crit = ΔI / 2`. Середньоквадратичний струм (RMS), що визначає нагрів мідного проводу обмотки, враховує як постійну складову струму, так і пилкоподібну форму пульсацій:

```
I_rms = √(I_out² + (ΔI)² / 12)
```

#### 2. Магнітний стан осердя
Магнітний потік в осерді складається з двох компонентів:
- **Постійне зміщення (DC bias):** створюється середнім вихідним струмом навантаження `I_out`. Постійна індукція `B_dc = (L · I_out) / (N · A_e)` не викликає циклічних втрат перемагнічування, але наближає матеріал до насичення.
- **Змінна складова (AC flux):** створюється пульсаціями струму `ΔI`. Амплітуда змінної індукції `B_ac = (L · ΔI) / (2 · N · A_e)` визначає площу часткової петлі гістерезису й генерує тепло в матеріалі.

Повна пікова індукція становить суму двох складових `B_pk = B_dc + B_ac`. Якщо значення `B_pk` перевищує паспортну індукцію насичення матеріалу `B_sat` за робочої температури, диференціальна магнітна проникність осердя падає майже до одиниці, індуктивність дроселя руйнується, а струм через ключ зростає катастрофічно.

#### 3. Втрати потужності та рівняння Штейнмеца
Об'ємна густина втрат у матеріалі осердя `P_v` розраховується за формулою Штейнмеца:

```
P_v = C_m · f_sw^α · B_ac^β
```

де `C_m`, `α`, `β` — коефіцієнти апроксимації кривих втрат виробника матеріалу, а `B_ac` — амплітуда змінної індукції. Повна потужність втрат в осерді обчислюється множенням питомих втрат на ефективний магнітний об'єм осердя `V_e`:

```
P_core = P_v · V_e
```

Втрати в мідній обмотці складаються з джоулевого нагріву активним опором проводу:

```
P_cu = I_rms² · R_wire
```

Загальні теплові втрати дроселя: `P_total = P_core + P_cu`. Для досягнення оптимальних масогабаритних показників індуктивного елемента конструкцію проектують так, щоб втрати в міді та втрати в осерді були приблизно співмірними (`P_core ≈ P_cu`).

#### 4. Теплова модель та перегрів
Тепловий опір між поверхнею тороїдального осердя та навколишнім середовищем за умов природної конвекції повітря оцінюється за емпіричною формулою на основі повної площі зовнішньої поверхні компонента `A_surface` (у см²):

```
R_th ≈ 40 / √A_surface      [°C/Вт]
```

Очікуваний температурний підйом дроселя над температурою навколишнього середовища:

```
ΔT = P_total · R_th
T_final = T_ambient + ΔT
```

Оскільки індукція насичення феритів і порошків знижується з нагрівом (наприклад, для фериту MnZn N87 `B_sat` падає з `0.49 Тл` при `25 °C` до `0.39 Тл` при `100 °C`), перевірка надійності повинна виконуватися саме за температури `T_final`.

### Методологія вибору типорозміру: метод Area Product (Ap)

Перш ніж запустити детальний розрахунок, розробник має визначити необхідні габарити магнітопроводу. Для цього застосовують метод добутку площ (*Area Product*, `A_p`):

```
A_p = A_e · W_a
```

де:
- `A_e` — ефективна площа поперечного перерізу магнітного шляху (м²);
- `W_a` — площа вікна намотування осердя для розміщення мідного проводу (м²).

Мінімально необхідне значення `A_p` для накопичувального дроселя розраховується з енергії, що накопичується у магнітному полі за один період:

```
W_mag = 1/2 · L · I_pk²
A_p = (2 · W_mag) / (K_w · J · B_pk)
```

де:
- `K_w` — коефіцієнт заповнення вікна намотування міддю (для тороїдального ручного намотування `K_w ≈ 0.30...0.35`, для верстатного намотування на каркас `K_w ≈ 0.40...0.45`);
- `J` — допустима густина струму в мідному провіднику (при природному охолодженні обирають `J ≈ 4.0...6.0 А/мм²`, при примусовому обдуві вентилятором — `J ≈ 8.0...10.0 А/мм²`);
- `B_pk` — розрахункова максимальна індукція з урахуванням запасу до насичення.

Знаючи розраховане значення `A_p`, інженер обирає зі стандартного каталогу найближчий більший типорозмір тороїда або Ш-подібного осердя (наприклад, тороїди серій T80, T94, T106, T130 або броньові осердя PQ, RM, ETD).

### Розрахунок активного опору обмотки та довжини середнього витка (MLT)

Активний опір мідної обмотки постійному струму `R_dc` визначається геометричними розмірами тороїда та товщиною проводу:

```
R_dc = ρ_cu · (N · MLT) / A_wire
```

де:
- `ρ_cu ≈ 1.72·10⁻⁸ Ом·м` при `20 °C` та `ρ_cu ≈ 2.15·10⁻⁸ Ом·м` при робочій температурі `80 °C`;
- `N` — кількість витків;
- `A_wire` — площа поперечного перерізу мідної жили (м²);
- `MLT` (*Mean Length per Turn*) — середня довжина одного витка навколо тіла осердя. Для прямокутного перерізу тороїда з висотою `H` та товщиною стінки `W = (OD − ID) / 2`:
  ```
  MLT ≈ 2 · (H + W) + π · d_wire
  ```

### Високочастотні втрати в обмотці: скін-ефект та ефект близькості

На частотах комутації понад `50 кГц` опір обмотки змінному струму `R_ac` стає значно вищим за опір постійному струму `R_dc`. Це зумовлено двома фізичними механізмами:

1. **Скін-ефект у мідному провіднику:**
   Змінне магнітне поле струму всередині провідника наводить зустрічні вихрові струми, які витісняють протікання струму в тонкий приповерхневий шар товщиною `δ`:
   ```
   δ = √(ρ_cu / (π · f_sw · μ_0))
   ```
   Для міді за робочої температури `70 °C` (`ρ_cu = 2.0·10⁻⁸ Ом·м`):
   - на частоті `50 кГц`: `δ ≈ 0.32 мм` (граничний діаметр суцільного проводу `d_max = 2·δ ≈ 0.64 мм`, AWG 22);
   - на частоті `100 кГц`: `δ ≈ 0.22 мм` (`d_max ≈ 0.44 мм`, AWG 25);
   - на частоті `500 кГц`: `δ ≈ 0.10 мм` (`d_max ≈ 0.20 мм`, AWG 32).

2. **Ефект близькості (Proximity Effect):**
   Магнітне поле, створене сусідніми витками обмотки, проникає в товщу провідника й викликає локальні вихрові контури. В результаті струм у багатошаровій обмотці концентрується лише на поверхнях провідників, обернених до сусідніх шарів.
   
   Згідно з одновимірною аналітичною моделлю Довелла (*Dowell's equation*), коефіцієнт зростання опору `F_R = R_ac / R_dc` для обмотки з `p` шарів зростає пропорційно квадрату кількості шарів `p²`. Для усунення ефекту близькості в сильних змінних полях застосовують:
   - одношарове рівномірне намотування витків на тороїді;
   - намотування літцендратом (*Litz wire*) — джгутом з багатьох тонких скручених ізольованих лаком жилок, діаметр кожної з яких менший за `δ`;
   - намотування плоскою мідною фольгою (стрічкою), де товщина шару менша за глибину скін-шару.

### Теплова нестійкість та динаміка DC-Bias

Критичною особливістю силових феритів є нелінійна залежність питомих втрат від температури. На відміну від металів, де питомий опір зростає лінійно з температурою, напівпровідникова оксидна кераміка фериту при сильному нагріві демонструє термоактивоване зростання електропровідності.

Якщо робоча точка фериту перевищує мінімум кривої втрат (`80...100 °C`), подальший нагрів призводить до зростання втрат Штейнмеца, що викликає ще сильніший нагрів і падіння індукції насичення `B_sat`. Виникає небезпека **теплового розгону** (*thermal runaway*): матеріал входить у петлю позитивного зворотного зв'язку «нагрів → зростання втрат → ще більший нагрів → насичення → пробій транзистора».

У порошкових матеріалах такий ефект відсутній: індукція насичення сплавів Sendust та High Flux перевищує `1.0...1.5 Тл` і практично не знижується аж до `200 °C`, а розподілений діелектричний зазор стабілізує магнітну сприйнятливість.

### Програмна реалізація симулятора

Нижче наведено вихідний код симулятора двома мовами програмування: процедурною мовою C (стандарт C99/C11) та об'єктно-орієнтованою мовою C++ (стандарт C++20).

:::tabs
```c
#include <stdio.h>
#include <stdbool.h>
#include <math.h>

/* Опис характеристик магнітного матеріалу */
typedef struct {
    const char *name;
    double b_sat_25c;   /* Індукція насичення при 25 °C (Тл) */
    double b_sat_100c;  /* Індукція насичення при 100 °C (Тл) */
    double cm;          /* Коефіцієнт Штейнмеца Cm (Вт/(м³·Гц^α·Тл^β)) */
    double alpha;       /* Показник степеня частоти */
    double beta;        /* Показник степеня індукції */
    double curie_temp;  /* Точка Кюрі (°C) */
} MagneticMaterial;

/* Геометричні параметри магнітопроводу */
typedef struct {
    const char *part_number;
    double a_e;         /* Ефективна площа перерізу магнітного шляху (м²) */
    double l_e;         /* Ефективна довжина магнітної лінії (м) */
    double v_e;         /* Ефективний магнітний об'єм (м³) */
    double a_surface;   /* Площа зовнішньої поверхні (см²) для тепловідводу */
} CoreGeometry;

/* Робочі параметри схеми перетворювача */
typedef struct {
    double v_in;        /* Вхідна постійна напруга (В) */
    double v_out;       /* Вихідна стабілізована напруга (В) */
    double i_out;       /* Середній струм навантаження (А) */
    double f_sw;        /* Частота комутації силових ключів (Гц) */
    double l_val;       /* Номінальна індуктивність дроселя (Гн) */
    int turns;          /* Кількість витків обмотки */
    double r_wire;      /* Активний опір обмотки постійному струму (Ом) */
    double t_ambient;   /* Температура навколишнього середовища (°C) */
} OperatingCondition;

/* Результати комплексного аналізу */
typedef struct {
    double duty_cycle;
    double delta_i;
    double i_peak;
    double i_rms;
    double b_ac;
    double b_dc;
    double b_peak;
    double p_core;
    double p_copper;
    double p_total;
    double delta_temp;
    double final_temp;
    bool is_saturated;
    bool is_overheated;
} SimulationResult;

/* Обчислювальне ядро аналізу магнітного компонента */
SimulationResult evaluate_magnetic_inductor(
    const MagneticMaterial *mat,
    const CoreGeometry *core,
    const OperatingCondition *op
) {
    SimulationResult res;
    
    /* 1. Розрахунок комутаційного режиму */
    res.duty_cycle = op->v_out / op->v_in;
    double t_on = res.duty_cycle / op->f_sw;
    res.delta_i = (op->v_in - op->v_out) * t_on / op->l_val;
    res.i_peak = op->i_out + res.delta_i / 2.0;
    res.i_rms = sqrt(op->i_out * op->i_out + (res.delta_i * res.delta_i) / 12.0);
    
    /* 2. Розрахунок магнітного поля в осерді */
    double delta_b = (op->l_val * res.delta_i) / (op->turns * core->a_e);
    res.b_ac = delta_b / 2.0;
    res.b_dc = (op->l_val * op->i_out) / (op->turns * core->a_e);
    res.b_peak = res.b_dc + res.b_ac;
    
    /* 3. Оцінка втрат в осерді за рівнянням Штейнмеца */
    double p_v = mat->cm * pow(op->f_sw, mat->alpha) * pow(res.b_ac, mat->beta);
    res.p_core = p_v * core->v_e;
    
    /* 4. Оцінка джоулевих втрат в обмотці */
    res.p_copper = res.i_rms * res.i_rms * op->r_wire;
    res.p_total = res.p_core + res.p_copper;
    
    /* 5. Тепловий розрахунок перегріву */
    double r_th = 40.0 / sqrt(core->a_surface); /* Термічний опір °C/Вт */
    res.delta_temp = res.p_total * r_th;
    res.final_temp = op->t_ambient + res.delta_temp;
    
    /* 6. Діагностика граничних станів */
    double b_sat_limit = (res.final_temp >= 100.0) ? mat->b_sat_100c : mat->b_sat_25c;
    res.is_saturated = (res.b_peak >= b_sat_limit);
    res.is_overheated = (res.final_temp >= mat->curie_temp - 30.0 || res.final_temp > 125.0);
    
    return res;
}

int main(void) {
    /* База даних матеріалів */
    MagneticMaterial sendust = {
        .name = "Sendust (Kool Mu 60u, Fe-Si-Al)",
        .b_sat_25c = 1.05,
        .b_sat_100c = 0.95,
        .cm = 32.5,
        .alpha = 1.45,
        .beta = 2.15,
        .curie_temp = 500.0
    };
    
    MagneticMaterial high_flux = {
        .name = "High Flux (60u, Ni-Fe 50/50)",
        .b_sat_25c = 1.50,
        .b_sat_100c = 1.40,
        .cm = 45.0,
        .alpha = 1.40,
        .beta = 2.10,
```

```cpp
    double r_wire;      // Опір проводу (Ом)

};

// Результат моделювання
struct SimulationResult {
    double duty_cycle;
    double delta_i;
    double i_peak;
    double i_rms;
    double b_ac;
    double b_dc;
    double b_peak;
    double p_core;
    double p_copper;
    double p_total;
    double delta_temp;
    double final_temp;
    bool is_saturated;
    bool is_overheated;
};

// Обчислювальний клас симуляції силових індуктивностей
class InductorCoreSimulator {
public:
    [[nodiscard]] static SimulationResult calculate(
        const MagneticMaterial& mat,
        const CoreGeometry& core,
        const OperatingCondition& op
    ) noexcept {
        SimulationResult res{};
        
        // 1. Аналіз шпаруватості та струму
        res.duty_cycle = op.v_out / op.v_in;
        const double t_on = res.duty_cycle / op.f_sw;
        res.delta_i = (op.v_in - op.v_out) * t_on / op.l_val;
        res.i_peak = op.i_out + res.delta_i / 2.0;
        res.i_rms = std::sqrt(op.i_out * op.i_out + (res.delta_i * res.delta_i) / 12.0);
        
        // 2. Аналіз індукції
        const double delta_b = (op.l_val * res.delta_i) / (op.turns * core.a_e);
        res.b_ac = delta_b / 2.0;
        res.b_dc = (op.l_val * op.i_out) / (op.turns * core.a_e);
        res.b_peak = res.b_dc + res.b_ac;
        
        // 3. Розрахунок втрат в осерді за законом Штейнмеца
        const double p_v = mat.cm * std::pow(op.f_sw, mat.alpha) * std::pow(res.b_ac, mat.beta);
        res.p_core = p_v * core.v_e;
        
        // 4. Джоулеві втрати в обмотці
        res.p_copper = res.i_rms * res.i_rms * op.r_wire;
        res.p_total = res.p_core + res.p_copper;
        
        // 5. Тепловий режим
        const double r_th = 40.0 / std::sqrt(core.a_surface);
        res.delta_temp = res.p_total * r_th;
        res.final_temp = op.t_ambient + res.delta_temp;
        
        // 6. Перевірка обмежень надійності
        const double b_sat_limit = (res.final_temp >= 100.0) ? mat.b_sat_100c : mat.b_sat_25c;
        res.is_saturated = (res.b_peak >= b_sat_limit);
        res.is_overheated = (res.final_temp >= mat->curie_temp - 30.0 || res.final_temp > 125.0);
        
        return res;
    }
};
```

### Оптимізація діаметра проводу та калібр AWG

Для отримання розрахункового опору обмотки `R_wire = 45 мОм` необхідно правильно підібрати переріз мідного провідника:

```
A_w = I_rms / J
= 6.09 А / 5.0 А/мм²
≈ 1.22 мм²
```

Суцільний круглий провідник такого перерізу мав би діаметр `d = √(4 · A_w / π) ≈ 1.25 мм` (AWG 16). Проте на частоті комутації `100 кГц` глибина скін-шару становить `δ ≈ 0.22 мм`, а граничний рекомендований діаметр суцільного проводу становить `d_max = 2 · δ ≈ 0.44 мм` (AWG 25).

Якщо намотати обмотку одним товстим проводом `1.25 мм`, струм витісниться на поверхню, викликаючи зростання ефективного опору змінного струму `R_ac` у 3–4 рази та додатковий тепловий перегрів на `20...30 °C`.

Правильне інженерне рішення:
- Розпаралелити провідник на **джгут із 8 жил діаметром 0.45 мм** (AWG 25), намотаних біфілярно поруч;
- Або використати спеціалізований літцендрат (*Litz wire*) із `60` ізольованих жилок діаметром `0.16 мм` (AWG 34).

```
R_th_forced ≈ R_th_natural / 2.5
```

### Розрахунок коефіцієнта заповнення вікна (Window Fill Factor Kw)

При проектуванні тороїдального індуктивного компонента критичним обмеженням є доступна площа внутрішнього отвору тороїда `W_a`.

Площа вікна тороїдального осердя T106 з внутрішнім діаметром `ID = 14.5 мм`:

```
W_a = π · (ID / 2)²
= π · (7.25·10⁻³)²
≈ 165.1 мм²
```

Повна площа мідних провідників усіх `N = 32` витків обмотки (де кожний виток складається з джгута перерізом `A_wire = 1.22 мм²`):

```
A_cu_total = N · A_wire
= 32 × 1.22 мм²
≈ 39.0 мм²
```

Розрахунковий коефіцієнт заповнення вікна намотування:

```
K_w = A_cu_total / W_a
= 39.0 / 165.1
≈ 0.236 (23.6%)
```

Отримане значення `K_w ≈ 24%` є ідеальним для серійного виробництва:
- Значення `K_w < 30%` гарантує легке проходження човника верстата або ручного намотування через центральний отвір тороїда навіть на останніх витках;
- Залишається вільний центральний канал діаметром понад `8 мм`, що забезпечує вільну циркуляцію конвективних потоків повітря вздовж внутрішньої поверхні осердя;
- Якщо розрахунковий коефіцієнт `K_w` перевищує `40%`, намотування витків стає фізично неможливим без пошкодження ізоляції сусідніх витків.

### Теплова часова стала та реакція на пікові перевантаження

Силовий дросель володіє значною теплоємністю металевого магнітопроводу та мідної обмотки. Для тороїдального осердя T106 масою `m_core ≈ 30 г` та питомою теплоємністю сплаву Sendust `c_specific ≈ 460 Дж/(кг·°C)` повна теплоємність конструкції становить:

```
C_th = m_core · c_specific + m_cu · c_cu
≈ 0.030 кг × 460 Дж/(кг·°C) + 0.015 кг × 385 Дж/(кг·°C)
≈ 13.8 + 5.8
≈ 19.6 Дж/°C
```

Теплова часова стала нагріву дроселя у вільному повітрі:

```
τ_th = R_th · C_th
= 6.76 °C/Вт × 19.6 Дж/°C
≈ 132.5 с (близько 2.2 хвилини)
```

Звідси випливає важливий практичний висновок:
- При короткочасних пікових навантаженнях (наприклад, пусковий струм електродвигуна або розгін процесора тривалістю `2...5 секунд`) температура осердя практично не встигає зрости (`ΔT < 1 °C`), тому дросель не перегріється;
- Проте індукція магнітного поля `B_pk` реагує на стрибок струму **миттєво** (за частки мікросекунди). Тому при проектуванні запас за індукцією насичення `B_pk < B_sat` повинен перевірятися саме для абсолютного пікового струму перевантаження, тоді як тепловий режим розраховується за тривалим середньоквадратичним струмом `I_rms`.

### Оптимізація кількості витків: компроміс міді та осердя

При фіксованих габаритах осердя інженер завжди шукає оптимум кількості витків `N`. Цей вибір є класичним інженерним компромісом:

1. **Якщо зменшити кількість витків `N`:**
   - Довжина проводу зменшується, можна взяти товстіший провідник, тому опір обмотки `R_dc` і джоулеві втрати в міді `P_cu` падають.
   - Проте індукція змінного магнітного поля зростає обернено пропорційно `B_ac ∝ 1/N`.
   - Оскільки втрати в осерді залежать від індукції у степені `β ≈ 2.15`, втрати Штейнмеца стрімко злітають: `P_core ∝ 1 / N^β`. Осердя перегрівається.

2. **Якщо збільшити кількість витків `N`:**
   - Змінна індукція `B_ac` падає, втрати в осерді `P_core` практично зникають.
   - Проте довжина провідника зростає пропорційно `N`, а через обмежене вікно намотування `W_a` доводиться обирати тонший дріт (`A_wire ∝ 1/N`). Опір обмотки зростає квадратично: `R_wire ∝ N²`.
   - Втрати в міді `P_cu = I_rms² · R_wire` стрімко виростають і перепалюють обмотку.

```
Втрати P
  ▲
  │ \                         /  P_total = P_core + P_cu
  │  \      Втрати осердя    /   (Сумарні втрати)
  │   \     P_core ∝ 1/N^β  /
  │    \       \           /   / Втрати міді
  │     \       \         /   /  P_cu ∝ N²
  │      \       \  Opt  /   /
  │       \───────▼─────/───/
  │
  └─────────────────────────────────► Кількість витків N
```

Оптимальна кількість витків `N_opt` відповідає мінімуму функції повних втрат `P_total(N)`, де втрати в осерді та втрати в міді стають приблизно співмірними за величиною: `P_core ≈ P_cu`. Саме цей баланс і перевіряє наш симулятор на кожному кроці розрахунку.

### Експорт теплової та нелінійної моделі у SPICE-симулятори

Для проведення наскрізного схемотехнічного моделювання перехідних процесів усього перетворювача результати розрахунку симулятора перетворюються на поведінкову еквівалентну SPICE-модель дроселя (субсхему для LTspice чи Cadence Spectre).

Еквівалентна схема нелінійного індуктивного елемента з урахуванням втрат та теплового стану містить:
1. **Нелінійну індуктивність `L(I)`:** реалізується за допомогою функції Chan або табличного джерела керованого напругою заряду `B(H)`, де падіння проникності від постійного струму описується рівнянням спаду DC-bias;
2. **Паралельний частотно-залежний опір втрат в осерді `R_core`:** обчислюється з миттєвої потужності втрат Штейнмеца як `R_core = U_L² / P_core`;
3. **Послідовний активний опір обмотки `R_cu(T)`:** моделюється джерелом напруги з лінійним температурним коефіцієнтом опору міді `α_cu = +0.00393 1/°C`;
4. **Теплову RC-ланку:** де потужність повних втрат `P_total` виступає струмом, що втікає у вузол теплоємності `C_th` та теплового опору `R_th`, формуючи напругу вузла, чисельно рівну миттєвій температурі компонента `T_core(t)`.

Такий замкнений електротермічний зв'язок дозволяє інженеру спостерігати в схемному симуляторі динаміку прогріву дроселя, поведінку перетворювача при холодному старті (`-40 °C`) та безпеку роботи при аварійному короткому замиканні виходу. Модель автоматично сигналізує про вихід за безпечну область роботи (SOA) при досягненні критичної температури чи індукції насичення. Інтеграція алгоритму розрахунку осердя на ранніх етапах проектування дозволяє скоротити кількість ітерацій макетування друкованих плат, виключаючи дорогі переробки силових перетворювачів через перегрів або неочікуване насичення магнітних компонентів.
