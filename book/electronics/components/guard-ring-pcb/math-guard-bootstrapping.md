# 🧮 Математичне виведення еквівалентної ємності та придушення витоку

Охоронне кільце на друкованій платі та ведений екран у триосьовому кабелі одночасно розв'язують два фундаментальні фізичні завдання: повністю усувають статичні струми поверхневого та об'ємного витоку крізь діелектрик і динамічно знижують еквівалентну паразитну ємність сигнальної лінії (ефект вольтододавання або bootstrapping).

Нижче наведено строгий математичний аналіз фізичних процесів у захищеному вузлі. Розглянуто вісім взаємопов'язаних математичних моделей:
1. Залишковий струм витоку з урахуванням усіх неідеальностей реального операційного підсилювача (зміщення нуля, скінченне підсилення, синфазне придушення, вхідний струм зміщення).
2. Температурна та вологісна деградація поверхневого опору діелектрика плати.
3. Частотна залежність еквівалентної ємності та динамічний зсув полюса вхідного фільтра.
4. Вплив діелектричних втрат та тангенса кута втрат на ефективність екранування.
5. Часова динаміка перехідного процесу та час встановлення сигналу.
6. Вплив власного шуму буфера Guard на чутливий вузол.
7. Інжекція заряду при перемиканні та динамічна похибка апертури.
8. Фазовий аналіз та абсолютна стійкість контуру активного драйвера Guard при роботі на ємнісне навантаження.

### 1. Залишковий струм витоку через неідеальний буфер Guard

Розглянемо високоомний вузол (High-Z), оточений мідним охоронним кільцем Guard. Нехай потенціал чутливого вузла становить `V_in`, а на сусідній шині живлення діє напруга `V_rail`. Опір поверхневого діелектрика між шиною живлення та охоронним кільцем позначимо як `R_ext`, а опір ізоляційного зазору між кільцем і чутливим вузлом — як `R_guard`.

У незахищеній схемі струм витоку безпосередньо з шини живлення `V_rail` у сигнальний вузол через паразитний опір діелектрика `R_surface` визначається за законом Ома:

```
I_unshielded
= (V_rail - V_in) / R_surface                         [струм витоку незахищеного вузла]
```

При встановленні охоронного кільця напруга на провіднику Guard `V_guard` формується виходом операційного підсилювача-повторювача. У реальному підсилювачі вихідна напруга відрізняється від вхідної через три ключові фактори: напругу зміщення нуля `V_os`, скінченний коефіцієнт підсилення у розімкненому контурі `A_OL` та скінченний коефіцієнт придушення синфазного сигналу `CMRR`.

Напруга на виході буфера описується рівнянням неідеального повторювача:

```
V_guard
= V_in - (V_in / CMRR) ± V_os - (V_guard / A_OL)      [повна модель вихідної напруги ОП-повторювача]
```

Згрупуємо члени для знаходження напруги на кільці `V_guard`:

```
V_guard · (1 + 1/A_OL)
= V_in · (1 - 1/CMRR) ± V_os                          [перенесення члена V_guard / A_OL ліворуч]
V_guard
= [V_in · (1 - 1/CMRR) ± V_os] / (1 + 1/A_OL)        [ділення на коефіцієнт при V_guard]
```

Оскільки коефіцієнт підсилення `A_OL >> 1`, скористаємося наближенням `1 / (1 + 1/A_OL) ≈ 1 - 1/A_OL`:

```
V_guard
≈ [V_in · (1 - 1/CMRR) ± V_os] · (1 - 1/A_OL)         [розклад у ряд Тейлора першого порядку]
= V_in · (1 - 1/CMRR - 1/A_OL) ± V_os                 [нехтуємо добутком нескінченно малих величин 1/(CMRR·A_OL)]
```

Знайдемо залишкову різницю потенціалів між захищеним High-Z вузлом та охоронним кільцем `ΔV = V_in - V_guard`:

```
ΔV
= V_in - V_guard                                      [означення залишкової різниці напруг на захисному зазорі]
= V_in - [V_in · (1 - 1/CMRR - 1/A_OL) ± V_os]        [підстановка знайденого виразу для V_guard]
= V_in · (1/CMRR + 1/A_OL) ∓ V_os                     [результуюча формула залишкової різниці напруг]
```

Струм витоку `I_leak`, що протікає через ізоляційний зазор між кільцем та чутливим вузлом, становить:

```
I_leak
= ΔV / R_guard                                        [закон Ома для ізоляційного зазору]
= [V_in · (1/CMRR + 1/A_OL) ∓ V_os] / R_guard         [підстановка залишкової напруги]
```

Визначимо коефіцієнт пригнічення витоку (Attenuation Ratio `η`) як відношення струму витоку без захисту до залишкового струму із захисним кільцем:

```
η
= I_unshielded / I_leak                               [коефіцієнт ефективності охоронного кільця]
= [(V_rail - V_in) / R_surface] / [ΔV / R_guard]      [відношення струмів витоку]
= [(V_rail - V_in) / ΔV] · (R_guard / R_surface)      [розподіл на масштаб напруг та відношення опорів]
```

Якщо зазори на платі однакові (`R_guard ≈ R_surface`), коефіцієнт придушення повністю визначається відношенням напруги живлення до залишкової напруги зміщення ОП:

```
η
≈ (V_rail - V_in) / [V_in · (1/CMRR + 1/A_OL) + V_os] [спрощена оцінка коефіцієнта придушення]
```

Підставимо числові параметри для прецизійного електрометричного підсилювача:
- Напруга живлення шини: `V_rail = +15 В`;
- Вхідний сигнал: `V_in = +2.5 В`;
- Напруга зміщення: `V_os = 25 мкВ = 2.5×10⁻⁵ В`;
- Коефіцієнт підсилення: `A_OL = 140 дБ = 10⁷`;
- Синфазне придушення: `CMRR = 120 дБ = 10⁶`;
- Поверхневий опір зволоженої плати: `R_surface = R_guard = 10¹⁰ Ом` (10 ГОм).

Розрахуємо поетапно:

```
ΔV
= 2.5 В · (10⁻⁶ + 10⁻⁷) + 2.5×10⁻⁵ В                  [підстановка параметрів у формулу ΔV]
= 2.5 В · (1.1×10⁻⁶) + 2.5×10⁻⁵ В                     [обчислення синфазного внеску]
= 2.75×10⁻⁶ В + 2.5×10⁻⁵ В                            [додавання складових]
= 2.775×10⁻⁵ В ≈ 27.8 мкВ                             [залишкова напруга на внутрішньому зазорі]
```

Порівняємо струми витоку:

```
I_unshielded
= (15 В - 2.5 В) / 10¹⁰ Ом = 12.5 / 10¹⁰ = 1.25×10⁻⁹ А = 1250 пА  [витік без захисту]
I_leak
= 27.75×10⁻⁶ В / 10¹⁰ Ом = 2.775×10⁻¹⁵ А = 2.78 фА    [залишковий витік з Guard Ring]
η
= 1.25×10⁻⁹ А / 2.775×10⁻¹⁵ А ≈ 450 450               [придушення струму витоку в 450 тисяч разів]
```

### 2. Температурна та вологісна залежність опору ізоляції плати

Поверхневий питомий опір склотекстоліту FR-4 `R_s` (Ом/квадрат) експоненційно падає зі зростанням відносної вологості повітря `RH` (Relative Humidity) та температури `T`. Фізична модель описується емпіричним рівнянням адсорбції вологи та термічної активації провідності:

```
R_s(RH, T)
= R_0 · exp(-γ · RH) · exp(E_a / (k_B · T))           [експоненційна модель деградації поверхневого опору]
```

де:
- `R_0` — базовий поверхневий опір абсолютно сухого матеріалу при кімнатній температурі (`≈ 10¹⁴ Ом/кв`);
- `γ` — коефіцієнт гігроскопічності поверхні (`γ ≈ 0.08...0.12 %⁻¹` для невідмитого флюсу);
- `RH` — відносна вологість повітря у відсотках (наприклад, 80%);
- `E_a` — енергія активації іонної провідності поверхневого шару (`≈ 0.6...0.8 еВ`);
- `k_B` — стала Больцмана (`8.617×10⁻⁵ еВ/К`);
- `T` — абсолютна температура в Кельвінах.

Розрахуємо зміну опору ізоляції при зростанні вологості від 30% до 85% при температурі 298 К (25 °C):

```
R_s(85%) / R_s(30%)
= exp(-0.1 · (85 - 30))                               [відношення опорів при зміні вологості на 55%]
= exp(-5.5)                                           [обчислення експоненти]
≈ 0.00408 ≈ 1 / 245                                   [падіння поверхневого опору у 245 разів]
```

Якщо базова плата мала опір `R_s = 10¹² Ом/кв`, то у вологому середовищі опір знижується до `4×10⁹ Ом/кв`. Без охоронного кільця струм витоку пропорційно зростає у 245 разів, тоді як наявність Guard Ring підтримує струм на рівні одиниць фемтоамперів незалежно від змін вологості.

### 3. Динамічне вольтододавання та еквівалентна ємність (Bootstrapping)

Паразитна ємність між сигнальною лінією та навколишнім провідником становить `C_0`. Нехай вхідний сигнал є гармонічною функцією часу:

```
v_in(t) = V_m · e^(jωt)                                [комплексна форма гармонічного вхідного сигналу]
```

Активний буфер Guard має частотно-залежний коефіцієнт передачі `A_v(jω)` з частотою зрізу `ω_b = 2π · f_b`:

```
A_v(jω)
= A_0 / (1 + j·(ω / ω_b))                             [частотна характеристика буфера першого порядку]
```

Для прецизійного повторювача низькочастотний коефіцієнт передачі `A_0 = 1 - ε`, де `ε = 1/A_OL + 1/CMRR ≈ 10⁻⁶`.

Струм `i_c(t)`, що споживається паразитною ємністю `C_0` від вхідного джерела, визначається похідною від миттєвої різниці напруг між сигналом та веденим екраном:

```
i_c(t)
= C_0 · (d/dt)[v_in(t) - v_guard(t)]                  [диференціальне рівняння струму через ємність]
= C_0 · (d/dt)[v_in(t) · (1 - A_v(jω))]               [підстановка v_guard(t) = A_v(jω) · v_in(t)]
= jω · C_0 · [1 - A_v(jω)] · v_in(t)                  [диференціювання гармонічної експоненти]
```

Еквівалентна комплексна вхідна ємність кола `C_eff(jω)` визначається як відношення амплітуди реактивного струму до `jω · v_in`:

```
C_eff(jω)
= C_0 · [1 - A_v(jω)]                                 [загальний вираз для еквівалентної ємності]
```

Підставимо аналітичний вираз для `A_v(jω)`:

```
1 - A_v(jω)
= 1 - [A_0 / (1 + j·(ω / ω_b))]                       [підстановка характеристики підсилювача]
= [(1 - A_0) + j·(ω / ω_b)] / [1 + j·(ω / ω_b)]       [зведення дробів до спільного знаменника]
```

Знайдемо модуль еквівалентної ємності `|C_eff(ω)|`:

```
|C_eff(ω)|
= C_0 · √[ (1 - A_0)² + (ω / ω_b)² ] / √[ 1 + (ω / ω_b)² ]  [модуль комплексної еквівалентної ємності]
```

Розглянемо граничні випадки:

1. **Постійний струм і наднизькі частоти (`ω << ω_b` при `A_0 ≈ 1 - 10⁻⁶`):**
```
|C_eff(0)|
= C_0 · (1 - A_0) = C_0 · 10⁻⁶                        [статичне придушення ємності в 1 000 000 разів]
```
Якщо фізична ємність кабелю становить `C_0 = 100 пФ`, то на низьких частотах джерело сигналу навантажене лише на `0.0001 пФ = 0.1 фФ`.

2. **Проміжний діапазон частот (`(1 - A_0) · ω_b << ω << ω_b`):**
```
|C_eff(ω)|
≈ C_0 · (ω / ω_b)                                     [лінійне зростання ефективної ємності з частотою]
```

3. **Високі частоти вище смуги буфера (`ω >> ω_b`):**
```
|C_eff(∞)|
= C_0 · 1 = C_0                                       [на високих частотах вольтододавання вимикається]
```

### 4. Вплив діелектричних втрат та тангенса кута втрат на ефективність екранування

У змінному електричному полі діелектрик характеризується комплексною діелектричною проникністю:

```
ε*(ω) = ε'(ω) - j·ε''(ω)                              [комплексна діелектрична проникність]
```

Тангенс кута діелектричних втрат `tan(δ) = ε'' / ε'` визначає активні втрати енергії в ізоляторі. Повна комплексна провідність ізоляційного зазору між сигнальним провідником і веденим екраном:

```
Y_d(jω)
= G_d(ω) + jω · C_d(ω)                                [комплексна адмітанс діелектричного проміжку]
= ω · C_d · tan(δ) + jω · C_d                         [розклад на активну та реактивну провідності]
```

При застосуванні веденого екрана Guard напруга на діелектрику знижується до `ΔV(jω) = V_in · [1 - A_v(jω)]`. Відповідно, як ємнісний реактивний струм, так і активні втрати в діелектрику масштабуються на один і той самий коефіцієнт придушення:

```
P_loss,guarded(ω)
= Re{ Y_d(jω) · |ΔV(jω)|² }                           [активна потужність діелектричних втрат]
= ω · C_d · tan(δ) · |V_in|² · |1 - A_v(jω)|²         [зменшення діелектричних втрат у |1 - A_v|² разів]
```

На низьких частотах це знижує діелектричні втрати у склотекстоліті на 10–12 порядків, фактично усуваючи паразитні фазові спотворення та діелектричний шум у вхідному колі.

### 5. Зсув полюса вхідного кола та передавальна характеристика

Високоомне джерело сигналу (наприклад, електрометричний зонд або скляний pH-електрод) має внутрішній опір `R_s`. Разом із паразитною ємністю лінії `C_0` воно утворює вхідний фільтр нижніх частот.

Без веденого екрана передавальна функція вхідного кола має вигляд:

```
H_unshielded(s)
= 1 / (1 + s · R_s · C_0)                             [передавальна функція звичайного RC-кола]
ω_p,unshielded
= 1 / (R_s · C_0)                                     [початкова частота зрізу незахищеного кола]
```

При увімкненні активного Guard еквівалентна ємність лінії замінюється на `C_eff(s) = C_0 · [s / (s + ω_b)]`. Знайдемо повну передавальну функцію замкненої системи `H_guarded(s)`:

```
H_guarded(s)
= 1 / [1 + s · R_s · C_eff(s)]                        [підстановка операторної ємності C_eff(s)]
= 1 / [1 + s · R_s · C_0 · (s / (s + ω_b))]           [розкриття виразу для C_eff(s)]
= (s + ω_b) / [ (s + ω_b) + s² · R_s · C_0 ]          [множення чисельника й знаменника на (s + ω_b)]
= (s + ω_b) / [ s² · R_s · C_0 + s + ω_b ]            [стандартна форма полінома другого порядку]
```

Поділимо знаменник на `R_s · C_0`:

```
H_guarded(s)
= [ (1 / (R_s · C_0)) · (s + ω_b) ] / [ s² + s / (R_s · C_0) + ω_b / (R_s · C_0) ]  [нормалізований вигляд]
```

Порівняємо знаменник із канонічною формою коливальної ланки другого порядку `s² + 2ζω_n · s + ω_n²`:

```
ω_n
= √(ω_b / (R_s · C_0)) = √(ω_b · ω_p,unshielded)     [власна резонансна частота системи]
2ζω_n
= 1 / (R_s · C_0) = ω_p,unshielded                    [коефіцієнт демпфування]
ζ
= ω_p,unshielded / (2 · √(ω_b · ω_p,unshielded))      [коефіцієнт згасання]
= 0.5 · √(ω_p,unshielded / ω_b)                       [співвідношення смуг незахищеного кола та буфера]
```

Оскільки смуга буфера значно більша за вихідну смугу джерела (`ω_b >> ω_p,unshielded`), коефіцієнт згасання `ζ << 1`. Результуюча частота зрізу системи `ω_p,guarded` зсувається вгору до значення `ω_n`:

```
ω_p,guarded
≈ √(ω_b · ω_p,unshielded)                             [нова розширена смуга пропускання]
```

Розрахуємо коефіцієнт розширення смуги пропускання (Bandwidth Extension Ratio `BWR`):

```
BWR
= ω_p,guarded / ω_p,unshielded                        [відношення частот зрізу]
= √(ω_b / ω_p,unshielded)                             [коефіцієнт прискорення реакції кола]
```

**Числовий приклад розрахунку смуги:**
- Внутрішній опір джерела: `R_s = 10 ГОм = 10¹⁰ Ом`;
- Фізична ємність кабелю: `C_0 = 100 пФ = 10⁻¹⁰ Ф`;
- Початкова частота зрізу без Guard:
```
f_p,unshielded
= 1 / (2π · 10¹⁰ · 10⁻¹⁰) = 1 / (2π · 1) ≈ 0.159 Гц   [надзвичайно повільне коло: стала часу 1 секунда]
```
- Смуга пропускання ОП Guard Driver: `f_b = 5 МГц = 5×10⁶ Гц`.
- Розрахуємо нову смугу пропускання:
```
BWR
= √(5×10⁶ Гц / 0.159 Гц) = √(3.14×10⁷) ≈ 5600         [розширення частотної смуги у 5600 разів]
f_p,guarded
= 0.159 Гц · 5600 ≈ 890 Гц                            [реальна смуга зросла з 0.16 Гц до майже 1 кГц]
```

### 6. Часова динаміка перехідного процесу та час встановлення

Час наростання фронту сигналу (Rise Time `t_r`) від 10% до 90% для простого кола першого порядку пов'язаний із частотою зрізу класичним співвідношенням:

```
t_r,unshielded
= 2.197 · R_s · C_0 = ln(9) · τ_0                     [час наростання незахищеного кола]
```

При внутрішньому опорі джерела `R_s = 10 ГОм` та ємності кабелю `C_0 = 100 пФ`:

```
t_r,unshielded
= 2.2 · 10¹⁰ Ом · 10⁻¹⁰ Ф = 2.2 секунди                [неприйнятно повільне встановлення для швидких вимірювань]
```

Час встановлення сигналу з точністю до 0.1% (що відповідає похибці 10-розрядного АЦП) вимагає `7 · τ_0 = 7 секунд`. Для 16-розрядного АЦП (точність 0.0015%) потрібно `11.1 · τ_0 = 11.1 секунди` на кожну точку вимірювання!

При використанні активного Guard ефективна стала часу `τ_eff` зменшується пропорційно коефіцієнту розширення смуги:

```
τ_eff
= 1 / ω_p,guarded = τ_0 / BWR                         [еквівалентна стала часу з веденим екраном]
```

Для наведеного вище прикладу з `BWR = 5600`:

```
τ_eff
= 1.0 с / 5600 ≈ 1.78×10⁻⁴ с = 178 мкс                 [стала часу зменшилася до мікросекунд]
t_r,guarded
= 2.2 · 178 мкс ≈ 392 мкс                              [час наростання скоротився з 2.2 с до 392 мкс]
t_settle(0.1%)
= 7 · 178 мкс ≈ 1.25 мс                                [час встановлення 0.1% зменшився з 7 секунд до 1.25 мс]
```

Це дозволяє збільшити частоту опитування високоомного датчика з одиниць вимірювань за хвилину до сотень вимірювань за секунду.

### 7. Вплив власного шуму буфера Guard на чутливий вузол

Активний операційний підсилювач Guard Driver має власну спектральну густину напруги шуму `e_n,guard` (нВ/√Гц). Цей шум діє безпосередньо на охоронний провідник.

Оскільки між охоронним провідником та захищеним вузлом існує залишковий опір діелектрика `R_guard` та залишкова ємність `C_res`, напруга шуму буфера створює паразитний струм шуму `i_n,injected`, що інжектується у вхідний вузол:

```
i_n,injected(f)
= e_n,guard(f) · |Y_coupling(f)|                      [шумовий струм, інжектований веденим екраном]
```

Комплексна провідність зв'язку `Y_coupling(f)` складається з резистивної та ємнісної гілок:

```
|Y_coupling(f)|
= √[ (1 / R_guard)² + (2π · f · C_res)² ]             [повна провідність зазору між Guard та High-Z]
```

На низьких частотах (f < 10 Гц) домінує резистивна складова. Якщо `R_guard = 10¹¹ Ом`, а шум буфера становить `e_n = 20 нВ/√Гц`:

```
i_n,injected
= 20×10⁻⁹ В/√Гц / 10¹¹ Ом = 2×10⁻¹⁹ А/√Гц = 0.2 аА/√Гц  [нескінченно малий струмовий шум на низьких частотах]
```

Однак на високих частотах ємнісний зв'язок `2π · f · C_res` починає зростати. Якщо залишкова ємність зазору на платі становить `C_res = 0.2 пФ`, то на частоті `f = 10 кГц`:

```
|Y_coupling(10 кГц)|
≈ 2π · 10⁴ · 0.2×10⁻¹² = 1.26×10⁻⁷ См                 [ємнісна провідність зазору на частоті 10 кГц]
i_n,injected(10 кГц)
= 20×10⁻⁹ В/√Гц · 1.26×10⁻⁷ См = 2.5×10⁻¹⁵ А/√Гц = 2.5 фА/√Гц [відчутне зростання шуму на ВЧ]
```

> 🔧 **Інженерне правило вибору драйвера Guard:** операційний підсилювач для Guard Driver повинен мати низький рівень широкосмугового шуму напруги `e_n` (< 10–15 нВ/√Гц) та бути стабільним без високих шумових викидів на високих частотах, щоб не інжектувати високочастотний шум у вхідний вузол через ємність зазору.

### 8. Фазова стійкість активного драйвера Guard

Провідник Guard на багатошаровій платі або внутрішня оплітка триосьового кабелю утворюють значну паразитну ємність відносно зовнішньої сигнальної землі `C_L = C_guard-gnd` (зазвичай від 200 пФ до 5 нФ для кабелів довжиною 2–5 метрів).

Ця ємність навантажує вихід операційного підсилювача Guard Driver. Вихідний імпеданс ОП у розімкненому стані `R_out` разом із ємністю `C_L` створює додатковий фазовий полюс у петлі зворотного зв'язку підсилювача:

```
f_pole,load
= 1 / (2π · R_out · C_L)                              [частота паразитного вихідного полюса]
```

Якщо вихідний опір ОП становить `R_out = 80 Ом`, а ємність кабелю `C_L = 2 нФ`:

```
f_pole,load
= 1 / (2π · 80 · 2×10⁻⁹) ≈ 995 кГц                    [полюс на частоті близько 1 МГц]
```

Якщо частота одиничного підсилення ОП `f_u = 10 МГц`, то паразитний полюс на частоті 1 МГц вносить додатковий фазовий зсув 90° задовго до перетину одиничного підсилення. Сумарний фазовий зсув петлі досягає 180°, запас за фазою стає від'ємним, і буфер Guard перетворюється на високочастотний автогенератор.

Для запобігання автогенерації застосовують **схему вихідної ізоляції з фазовим випередженням** (Dual-feedback Isolation Network):
1. Між виходом ОП та провідником Guard встановлюється ізоляційний резистор `R_iso` (типово 20–100 Ом).
2. Між виходом ОП та інвертуючим входом підключається конденсатор прямого зворотного зв'язку `C_f` (типово 10–47 пФ).
3. Сигнал зворотного зв'язку за постійним струмом знімається після резистора `R_iso` через резистор `R_f` (10–100 кОм).

Передавальна функція петлі зворотного зв'язку з компенсацією має вигляд:

```
T(s)
= A_OL(s) · [ (1 + s · R_iso · C_L) / (1 + s · (R_iso + R_out) · C_L) ] · [ (1 + s · R_f · C_f) / ... ]
```

Нуль передавальної функції, сформований резистором `R_iso` та ємністю навантаження:

```
f_zero,comp
= 1 / (2π · R_iso · C_L)                              [нуль фазового випередження для компенсації полюса]
```

При виборі `R_iso = 50 Ом` для `C_L = 2 нФ`:

```
f_zero,comp
= 1 / (2π · 50 · 2×10⁻⁹) ≈ 1.59 МГц                   [нуль точно компенсує фазове запізнення]
```

Нуль фазового випередження піднімає фазову характеристику петлі на 45–60° поблизу частоти одиничного перетину, забезпечуючи абсолютну фазову стабільність (Phase Margin `> 60°`) та повну відсутність дзвону чи перерегулювання при будь-яких стрибках вхідного сигналу.
