# 🧮 Математична динаміка зворотного відновлення body-діода

Ця вставка містить аналітичне виведення часових інтервалів, пікового зворотного струму, заряду та комутаційних перенапруг процесу зворотного відновлення внутрішнього p-n переходу MOSFET, необхідне для точного розрахунку динамічних втрат і параметрів захисних кіл силових перетворювачів.

### Геометрична модель перехідного струму

У силових імпульсних перетворювачах процес замикання body-діода відбувається під дією зустрічної напруги шини живлення `V_bus` під час відмикання протилежного силового ключа. Зовнішнє коло (швидкість наростання струму транзистора `di/dt`, опір затвора та паразитна індуктивність) формує лінійний спад прямого струму діода від початкового робочого значення `I_F` до нуля, після чого струм переходить у від'ємну область.

Перехідний струм діода `i_D(t)` апроксимують кусково-лінійною (трикутною) функцією часу. Початком відліку `t = 0` обирають момент переходу струму через нуль:

```
i_D(t) = -(di/dt) · t               [лінійне зростання зворотного струму у фазі t_a]
```

Процес відновлення поділяється на два послідовні інтервали:

1. **Фаза розсмоктування заряду `t_a`**: триває від моменту перетину нуля `t = 0` до досягнення пікового зворотного струму `i_D(t_a) = -I_rrm`. Упродовж цієї фази концентрація надлишкових дірок у слаболегованій дрейфовій зоні біля металургійного p-n переходу падає від початкового високого рівня до нуля. Оскільки в об'ємі напівпровідника зберігається високопровідна електронно-діркова плазма, напруга на діоді залишається близькою до нуля (падіння прямої провідності `-V_F ≈ -0.7...-1.2 В`).

2. **Фаза відновлення збідненого шару `t_b`**: триває від піку струму `-I_rrm` до його повного спаду до нуля (або до 10% від пікового значення). Біля p-n переходу формується область просторового заряду (Space Charge Region, SCR), яка розширюється вглиб n-дрейфової зони. Напруга на діоді стрімко зростає від нуля до повної напруги живлення `V_bus`, а зворотний струм спадає від `-I_rrm` до нуля внаслідок рекомбінації носіїв та винесення дірок електричним полем.

Повний час зворотного відновлення дорівнює сумі тривалостей обох фаз:

```
t_rr = t_a + t_b                     [повна тривалість перехідного процесу]
```

### Виведення пікового зворотного струму та складових заряду

Швидкість наростання зворотного струму у фазі `t_a` задається зовнішнім колом керування протилежного транзистора:

```
di/dt = I_rrm / t_a                  [швидкість наростання зворотного струму]
```

Звідси тривалість першої фази виражається через піковий струм:

```
t_a = I_rrm / (di/dt)                [тривалість фази винесення заряду]
```

Заряд `Q_a`, винесений зворотним струмом упродовж фази `t_a`, дорівнює площі трикутника під нульовою віссю на інтервалі `[0, t_a]`:

```
Q_a = ∫₀^{t_a} |i_D(t)| dt
= ∫₀^{t_a} (di/dt) · t dt            [підстановка лінійної функції струму]
= ½ · (di/dt) · t_a²                 [інтегрування степеневої функції]
= ½ · I_rrm · t_a                    [підстановка t_a = I_rrm / (di/dt)]
= ½ · I_rrm² / (di/dt)               [вираз заряду першої фази через піковий струм]
```

У фазі `t_b` струм спадає від `-I_rrm` до нуля зі швидкістю спаду `di_rr/dt = di_b/dt`. Для аналітичного опису форми спаду вводять безрозмірний коефіцієнт м'якості відновлення (Softness Factor) `S`:

```
S = t_b / t_a                        [визначення коефіцієнта м'якості]
```

За лінійної апроксимації спаду струму у фазі `t_b` швидкість спаду становить:

```
di_rr/dt = I_rrm / t_b
= I_rrm / (S · t_a)                  [підстановка t_b = S · t_a]
= (di/dt) / S                        [зв'язок швидкості спаду зі швидкістю наростання]
```

Заряд `Q_b`, винесений у другій фазі, становить:

```
Q_b = ½ · I_rrm · t_b                [площа трикутника спаду струму]
= ½ · S · I_rrm · t_a                [підстановка t_b = S · t_a]
= S · Q_a                            [зв'язок зарядів двох фаз через коефіцієнт м'якості]
```

Повний заряд зворотного відновлення `Q_rr` є сумою зарядів обох фаз:

```
Q_rr = Q_a + Q_b                     [сумарний заряд зворотного відновлення]
= Q_a · (1 + S)                      [винесення Q_a за дужки]
= ½ · (1 + S) · I_rrm · t_a          [розгортання Q_a]
= ½ · I_rrm · (t_a + t_b)            [підстановка t_a · S = t_b]
= ½ · I_rrm · t_rr                   [геометрична площа повного трикутника струму]
```

Підставивши вираз `t_a = I_rrm / (di/dt)` у формулу сумарного заряду `Q_rr`, отримуємо фундаментальне алгебраїчне рівняння, що пов'язує фізичний заряд `Q_rr` із параметрами комутації:

```
Q_rr = ½ · (1 + S) · I_rrm² / (di/dt) [зв'язок заряду, коефіцієнта м'якості та швидкості струму]
```

Розв'язуючи це рівняння відносно пікового зворотного струму `I_rrm`, отримуємо залежність амплітуди кидка струму від заряду, крутості фронту та фактора м'якості:

```
I_rrm = √( (2 · Q_rr · di/dt) / (1 + S) ) [розрахункова формула пікового зворотного струму]
```

Для часу зворотного відновлення `t_rr` маємо вираз:

```
t_rr = t_a · (1 + S)                 [зв'язок t_rr та t_a через коефіцієнт м'якості]
= (I_rrm / (di/dt)) · (1 + S)        [підстановка t_a]
= √( (2 · Q_rr · (1 + S)) / (di/dt) ) [вираз повного часу відновлення]
```

### Вплив коефіцієнта м'якості на швидкість спаду струму та перенапругу

Критичним фактором надійності силового ключа є швидкість спаду струму `di_rr/dt` у фазі `t_b`. У будь-якій реальній друкованій платі та внутрішній конструкції напівпровідникового модуля існує розподілена паразитна індуктивність силового контуру комутації `L_loop` (включає індуктивність виводів транзисторів, шин живлення та блокувальних конденсаторів).

Згідно з законом електромагнітної індукції Фарадея, швидка зміна струму крізь індуктивність контуру генерує індуктивну електрорушійну силу самоіндукції (перенапругу):

```
V_spike = L_loop · (di_rr/dt)        [індуктивний викид напруги на паразитному контурі]
```

Підставивши співвідношення `di_rr/dt = (di/dt) / S`, отримуємо:

```
V_spike = L_loop · (di/dt) / S       [залежність перенапруги від індуктивності та коефіцієнта м'якості]
```

Максимальна миттєва напруга на стоку транзистора, діод якого відновлюється, сягає величини:

```
V_ds_max = V_bus + V_spike
= V_bus + (L_loop · di/dt) / S       [пікова напруга на стоку ключа під час комутації]
```

З цієї формули видно катастрофічний вплив жорсткого відновлення (Snappy Recovery, коли `S ≪ 1`):

1. **При м'якому відновленні (`S ≈ 1...1.5`)**: швидкість спаду `di_rr/dt` порівнянна зі швидкістю наростання `di/dt` (`di_rr/dt ≈ di/dt`). Індуктивний сплеск `V_spike` залишається помірним і зазвичай не перевищує 10–20% від `V_bus`.

2. **При жорсткому відновленні (`S = 0.1...0.2`)**: швидкість спаду `di_rr/dt` зростає у 5–10 разів порівняно з `di/dt`. При типових швидкостях комутації сучасних драйверів `di/dt = 1000 А/мкс` швидкість обриву струму сягає `di_rr/dt = 5000...10000 А/мкс`.

За паразитної індуктивності силового контуру `L_loop = 25 нГн` викид напруги становить:

```
V_spike = 25·10⁻⁹ Гн · 10000·10⁶ А/с = 250 В
```

Якщо напруга шини становить `V_bus = 400 В`, сумарна пікова напруга досягає `V_ds_max = 400 + 250 = 650 В`. Для транзистора з номінальною напругою пробою `V_(BR)DSS = 600 В` це неминуче викликає лавинний пробій ([mosfet-avalanche](book:electronics/mosfet-avalanche)) і високу ймовірність виходу кристала з ладу через локальний перегрів.

### Енергетичні втрати при комутації напівмоста

При відмиканні верхнього транзистора напівмоста `Q_H` на індуктивне навантаження `I_load`, нижній body-діод `D_body_L` проходить процес зворотного відновлення. Сумарні динамічні втрати розподіляються між двома напівпровідниковими структурами:

1. **Додаткові втрати увімкнення верхнього ключа `E_on(Q_H)`**: крізь транзистор `Q_H` під час його відмикання тече не лише струм навантаження `I_load`, а й повний струм зворотного відновлення нижнього діода: `i_QH(t) = I_load + |i_D(t)|`.

Упродовж фази `t_a` напруга на верхньому ключі спадає від `V_bus` до нуля, а струм зростає до `I_load + I_rrm`. Енергія, що додатково розсіюється в каналі верхнього транзистора виключно через заряд відновлення `Q_rr`, обчислюється інтегруванням миттєвої потужності:

```
E_rr_QH = ∫₀^{t_rr} V_bus · |i_D(t)| dt
= V_bus · ∫₀^{t_rr} |i_D(t)| dt      [винесення постійної напруги шини за інтеграл]
= V_bus · Q_rr                       [додаткова енергія втрат увімкнення верхнього ключа]
```

2. **Втрати зворотного відновлення в самому діоді `E_rec(D_body)`**: у фазі `t_b` напруга на діоді наростає від 0 до `V_bus`, поки крізь нього продовжує текти залишковий зворотний струм.

Апроксимуючи наростання напруги на діоді лінійною функцією `v_D(t) = V_bus · (t / t_b)` на інтервалі `[0, t_b]`, а струм — спадною лінією `i_D(t) = I_rrm · (1 - t / t_b)`, інтеграл розсіюваної в діоді енергії дорівнює:

```
E_rec = ∫₀^{t_b} v_D(t) · |i_D(t)| dt
= ∫₀^{t_b} [ V_bus · (t / t_b) ] · [ I_rrm · (1 - t / t_b) ] dt [підстановка функцій напруги та струму]
= (V_bus · I_rrm / t_b) · ∫₀^{t_b} (t - t² / t_b) dt             [винесення сталих коефіцієнтів]
= (V_bus · I_rrm / t_b) · [ ½ · t_b² - ⅓ · t_b² ]                [обчислення первісної на межах 0 і t_b]
= (V_bus · I_rrm / t_b) · (⅙ · t_b²)                             [спрощення різниці дробів ½ - ⅓ = ⅙]
= ⅙ · V_bus · I_rrm · t_b                                        [вираз енергії через параметри фази t_b]
= ⅓ · V_bus · Q_b                                                [підстановка Q_b = ½ · I_rrm · t_b]
= ⅓ · (S / (1 + S)) · V_bus · Q_rr                               [вираз через сумарний заряд Q_rr та фактор S]
```

Сумарні комутаційні втрати півмостового каскаду за один цикл комутації, викликані зворотним відновленням body-діода, становлять:

```
E_rr_total = E_rr_QH + E_rec
= V_bus · Q_rr + ⅓ · (S / (1 + S)) · V_bus · Q_rr                [додавання складових втрат верхнього і нижнього ключів]
= V_bus · Q_rr · [ 1 + ⅓ · (S / (1 + S)) ]                       [винесення спільного множника V_bus · Q_rr]
```

Для типового діапазону `S = 0.5...1.0` коефіцієнт у дужках лежить у межах `1.11...1.17`. Тому в практичних інженерних розрахунках сумарні втрати комутації на відновлення оцінюють за спрощеною базовою формулою:

```
E_rr_total ≈ V_bus · Q_rr                                        [інженерне наближення втрат відновлення]
```

Середня потужність теплових втрат, що виділяється в перетворювачі на частоті комутації `f_sw`, дорівнює добутку енергії одного циклу на частоту:

```
P_rr = E_rr_total · f_sw
≈ V_bus · Q_rr · f_sw                                            [середня потужність динамічних втрат на відновлення]
```

### Аналітичний розрахунок резонансного дзвону та параметрів RC-демпфера

Після завершення фази спаду струму `t_b` у момент `t = t_rr` body-діод замикається, перетворюючись на нелінійну ємність переходу та вихідну ємність MOSFET `C_oss`. Паразитна індуктивність силового контуру `L_loop`, паразитна ємність `C_oss` та активний опір доріжок і контактів `R_loop` утворюють послідовний коливальний контур другого порядку.

Диференціальне рівняння для заряду `q(t)` на вихідній ємності транзистора має вигляд:

```
L_loop · (d²q/dt²) + R_loop · (dq/dt) + q / C_oss = V_bus [диференціальне рівняння коливального контуру]
```

Характеристичне рівняння цього контуру:

```
L_loop · p² + R_loop · p + 1 / C_oss = 0                  [характеристичне рівняння]
```

Корені характеристичного рівняння визначають власну кутову частоту незгасаючих коливань `ω_0` та коефіцієнт згасання `α`:

```
ω_0 = 1 / √(L_loop · C_oss)                               [власна резонансна кутова частота контуру]
α = R_loop / (2 · L_loop)                                 [коефіцієнт згасання коливань]
```

Оскільки активний опір високочастотного контуру друкованої плати надзвичайно малий (`R_loop ≈ 0.05...0.2 Ом`), коефіцієнт згасання набагато менший за власну частоту (`α ≪ ω_0`). Хвильовий (характеристичний) опір контуру становить:

```
Z_0 = √(L_loop / C_oss)                                   [характеристичний імпеданс контуру]
```

Добротність контуру `Q_factor`:

```
Q_factor = Z_0 / R_loop = √(L_loop / C_oss) / R_loop      [добротність високочастотного коливального контуру]
```

При типових значеннях `L_loop = 20 нГн`, `C_oss = 200 пФ` та `R_loop = 0.1 Ом`:

```
ω_0 = 1 / √(20·10⁻⁹ · 200·10⁻¹²) = 1 / √(4·10⁻¹⁸) = 1 / (2·10⁻⁹) = 500·10⁶ рад/с
f_0 = ω_0 / (2·π) ≈ 79.6 МГц                              [резонансна частота дзвону]
Z_0 = √(20·10⁻⁹ / 200·10⁻¹²) = √100 = 10 Ом
Q_factor = 10 / 0.1 = 100                                 [висока добротність контуру]
```

За такої високої добротності контур є слабодемпфованим. Початковий струм у момент обриву `I_snap` породжує коливальний сплеск напруги з теоретичною піковою амплітудою:

```
V_ring_max = V_bus + I_snap · Z_0                         [пікова напруга високочастотного дзвону]
```

Для демпфування цього резонансу паралельно стоку та витоку транзистора встановлюють послідовний демпфуючий RC-ланцюжок (снубер) із параметрами `R_snub` та `C_snub`.

1. **Вибір ємності снубера `C_snub`**:
   Ємність обирають у 2–3 рази більшою за вихідну ємність транзистора `C_oss`, щоб змістити резонансну частоту вниз і перейняти на себе енергію коливань:
   ```
   C_snub = 2 · C_oss                                     [розрахункова ємність демпфера]
   ```

2. **Вибір опору снубера `R_snub`**:
   Опір розраховують для забезпечення аперіодичного режиму розряду (критичного демпфування, коли `Q_factor ≤ 0.5...0.7`), узгоджуючи його з хвильовим імпедансом контуру:
   ```
   R_snub = Z_0 = √(L_loop / C_oss)                       [оптимальний опір демпфера]
   ```

3. **Потужність розсіювання на резисторі снубера `P_snub`**:
   За кожен період комутації ємність `C_snub` двічі перезаряджається до напруги `V_bus` (при вимиканні та вмиканні), розсіюючи енергію на резисторі:
   ```
   W_snub = C_snub · V_bus²                               [енергія перезаряду снубера за один цикл]
   P_snub = C_snub · V_bus² · f_sw                        [середня потужність розсіювання на снубері]
   ```

Для `C_snub = 400 пФ`, `V_bus = 400 В` та `f_sw = 100 кГц`:

```
P_snub = 400·10⁻¹² · 400² · 100·10³ = 400·10⁻¹² · 160000 · 100000 = 6.4 Вт
```

Ці 6.4 Вт розсіюються у вигляді тепла на резисторі `R_snub`, тому резистор має бути безіндуктивним (товстоплівковим SMD або вуглецевим) відповідної номінальної потужності.

### Математична модель накопичення заряду від тривалості мертвого часу

Коли індуктивний струм навантаження `I_load` тече через body-діод під час мертвого часу `t_dead`, процес накопичення неосновних носіїв підпорядковується диференціальному рівнянню неперервності заряду:

```
dQ(t)/dt = I_F - Q(t) / τ                                 [диференціальне рівняння балансу заряду в базі діода]
```

де `Q(t)` — поточний надлишковий заряд дірок у дрейфовій зоні, `I_F` — прямий струм через діод, `τ` — ефективний час життя неосновних носіїв.

Розв'язок цього рівняння з нульовою початковою умовою `Q(0) = 0` (діод до початку мертвого часу не проводив) має вигляд:

```
Q(t) = I_F · τ · [ 1 - exp(-t / τ) ]                      [динаміка накопичення заряду в часі]
```

Залежність накопиченого заряду `Q_rr` від тривалості мертвого часу `t_dead`:

```
Q_rr(t_dead) = I_F · τ · [ 1 - exp(-t_dead / τ) ]         [заряд відновлення як функція тривалості мертвого часу]
```

Оскільки в кремнії час життя носіїв становить `τ ≈ 1000...3000 нс`, а мертвий час у сучасних перетворювачах становить `t_dead ≈ 50...200 нс`, аргумент експоненти малий (`t_dead / τ ≪ 1`). Розкладаючи експоненту в ряд Тейлора `exp(-x) ≈ 1 - x`:

```
Q_rr(t_dead) ≈ I_F · τ · [ 1 - (1 - t_dead / τ) ]
= I_F · t_dead                                            [лінійне наближення накопиченого заряду для малого мертвого часу]
```

Це виведення дає фундаментальний інженерний висновок: **при короткому мертвому часі накопичений заряд прямо пропорційний тривалості мертвого часу `t_dead`**. Скорочення мертвого часу вдвічі зменшує накопичений заряд `Q_rr` також удвічі, що пропорційно знижує піковий струм `I_rrm` та динамічні втрати відновлення.

### Поріг блокування body-діода при синхронному випрямленні

При синхронному випрямленні канал MOSFET відкривається паралельно власному body-діоду. Повна вольт-амперна характеристика еквівалентної структури є сумою лінійної ВАХ омічного каналу та експоненційної ВАХ p-n переходу (рівняння Шоклі):

```
i_total = i_channel + i_diode
= v_DS / R_ds(on) + I_s · [ exp(v_DS / V_T) - 1 ]         [сумарний струм паралельної структури канал-діод]
```

де `I_s` — струм насичення p-n переходу, `V_T = k·T / q ≈ 26 мВ` — температурний потенціал при 300 К.

Body-діод практично не проводить струм і не інжектує носії, доки падіння напруги на каналі не перевищить напругу відмикання p-n переходу `V_F_on ≈ 0.65...0.75 В`:

```
v_channel = I_load · R_ds(on) < V_F_on                    [умова невідмикання внутрішнього body-діода]
```

Звідси визначають критичний струм навантаження `I_crit`, вище якого синхронний канал уже не здатний утримати body-діод закритим:

```
I_crit = V_F_on / R_ds(on)                                [критичний струм відмикання body-діода]
```

Для сучасного низькоомного MOSFET із `R_ds(on) = 10 мОм` та `V_F_on = 0.7 В`:

```
I_crit = 0.7 В / 0.010 Ом = 70 А
```

Доки струм навантаження менший за 70 А, при відкритому затворі весь струм протікає виключно крізь кремнієвий канал із основними носіями, body-діод надійно заблокований, і накопичення заряду `Q_rr` повністю відсутнє (`Q_rr = 0`).

### Температурна залежність заряду відновлення та критерій теплової стійкості

У кремнієвих напівпровідниках час життя неосновних носіїв заряду `τ` визначається швидкістю рекомбінації через глибокі рівні домішок і дефектів за статистикою Шоклі-Ріда-Холла (SRH). При підвищенні абсолютної температури напівпровідника `T` теплова швидкість носіїв зростає пропорційно `T^{0.5}`, але ефективний переріз захоплення носіїв пастками рекомбінації зменшується, а ймовірність теплової генерації носіїв із пасток назад у зону провідності експоненційно збільшується.

Емпірична та теоретична залежність часу життя носіїв `τ` від абсолютної температури описується степеневою функцією:

```
τ(T_j) = τ₀ · (T_j / T₀)^γ                                 [температурна залежність часу життя неосновних носіїв]
```

де `T₀ = 298.15 К` (+25 °C) — базова температура, `τ₀` — час життя носіїв при базовій температурі, `γ ≈ 1.5...2.2` — температурний експонент кремнію.

Оскільки накопичений заряд `Q_rr` при постійному прямому струмі `I_F` пропорційний часу життя носіїв (`Q_rr ≈ I_F · τ`), температурна залежність заряду відновлення має аналогічний вигляд:

```
Q_rr(T_j) = Q_rr_0 · (T_j / T₀)^γ                         [зростання заряду зворотного відновлення з температурою]
```

При нагріванні кристала від `T_j1 = 25 °C` (298 К) до максимальної робочої температури `T_j2 = 150 °C` (423 К) для типового значення `γ = 1.8`:

```
Q_rr(150 °C) / Q_rr(25 °C) = (423.15 / 298.15)^1.8
= (1.419)^1.8 ≈ 1.88                                      [коефіцієнт температурного зростання заряду]
```

У високовольтних планарних MOSFET за рахунок сильнішого впливу рекомбінації в епітаксійному шарі відношення сягає `2.5...3.5`.

Відповідно, піковий зворотний струм `I_rrm` зростає пропорційно квадратному кореню від заряду:

```
I_rrm(T_j) = I_rrm_0 · (T_j / T₀)^{γ / 2}                 [температурне зростання пікового зворотного струму]
```

Оскільки динамічні втрати комутації прямо пропорційні заряду `P_rr = V_bus · Q_rr(T_j) · f_sw`, виникає позитивний тепловий зворотний зв'язок:

```
Нагрів кристала T_j ↑ ──► Зростання часу життя τ ↑ ──► Збільшення заряду Q_rr ↑ ──► Зростання втрат P_rr ↑ ──► Ще більший нагрів T_j ↑
```

Для аналізу теплової стійкості силового ключа записують рівняння стаціонарного теплового балансу:

```
T_j - T_amb = P_total(T_j) · R_th_ja                      [рівняння стаціонарної температури кристала]
```

де `T_amb` — температура навколишнього середовища, `R_th_ja` — сумарний тепловий опір кристал-середовище (включає опір корпус-радіатор та радіатор-повітря), `P_total(T_j)` — сумарна потужність втрат:

```
P_total(T_j) = P_cond(T_j) + P_sw_other + V_bus · Q_rr(T_j) · f_sw [сумарні втрати у напівпровіднику]
```

Умовою теплової стійкості (відсутності теплового розгону, Thermal Runaway) є перевищення швидкості тепловідведення над швидкістю внутрішнього тепловиділення:

```
d P_total(T_j) / d T_j < 1 / R_th_ja                      [критерій теплової стійкості силового напівпровідника]
```

Диференціюючи складову втрат зворотного відновлення по температурі:

```
d P_rr / d T_j = V_bus · f_sw · (d Q_rr / d T_j)
= V_bus · f_sw · γ · Q_rr_0 · (T_j / T₀)^{γ - 1} / T₀     [швидкість приросту втрат відновлення по температурі]
```

Підставляючи в критерій стійкості, отримують аналітичний вираз для граничної критичної частоти комутації `f_crit`, вище якої кремнієвий MOSFET неминуче входить у некерований тепловий розгін:

```
f_crit = [ 1 / R_th_ja - d P_cond / d T_j ] / [ V_bus · γ · Q_rr_0 · (T_j_max / T₀)^{γ - 1} / T₀ ] [критична частота теплової стабільності]
```

Для перетворювача з `V_bus = 400 В`, `R_th_ja = 2.0 °C/Вт`, `Q_rr_0 = 1500 нКл`, `γ = 1.8`, `T_j_max = 423 К`:

```
d P_rr / d T_j = 400 · f_sw · 1.8 · 1500·10⁻⁹ · (1.419)^0.8 / 298.15 [підстановка числових параметрів V_bus, Q_rr, T_j]
= 400 · f_sw · 1.8 · 1500·10⁻⁹ · 1.323 / 298.15                      [піднесення відношення температур до степеня 0.8]
= f_sw · 4.79·10⁻⁶ Вт/(Гц · °C)                                      [перемноження числових коефіцієнтів]
```

З умови `f_crit · 4.79·10⁻⁶ < 1 / 2.0 = 0.5 Вт/°C`:

```
f_crit = 0.5 / (4.79·10⁻⁶) ≈ 104.4 кГц
```

Цей результат чітко показує фундаментальну фізичну межу: робота стандартного кремнієвого MOSFET у жорсткому напівмості на напрузі 400 В на частотах понад 100 кГц є принципово теплово нестійкою без штучного скорочення часу життя носіїв (FRFET) або переходу на WBG-напівпровідники (SiC/GaN).

### Комплексний числовий приклад розрахунку напівмоста

Розглянемо практичний приклад розрахунку комутаційних параметрів і втрат для транзисторів стійки інвертора напруги зі стандартними параметрами:

- Напруга шини живлення: `V_bus = 400 В`;
- Частота комутації: `f_sw = 100 кГц` (`100·10³ Гц`);
- Швидкість наростання струму транзистора: `di/dt = 800 А/мкс` (`800·10⁶ А/с`);
- Паразитна індуктивність силового контуру: `L_loop = 20 нГн` (`20·10⁻⁹ Гн`);
- Параметри body-діода MOSFET (стандартний Silicon Superjunction): `Q_rr = 1200 нКл` (`1200·10⁻⁹ Кл`), коефіцієнт м'якості `S = 0.25` (виражене snappy-відновлення).

**1. Розрахунок пікового зворотного струму `I_rrm`:**

```
I_rrm = √( (2 · 1200·10⁻⁹ · 800·10⁶) / (1 + 0.25) ) [підстановка значень Q_rr, di/dt, S у формулу I_rrm]
= √( 1920 / 1.25 )                                  [множення чисел під коренем]
= √1536 ≈ 39.19 А                                   [добування квадратного кореня]
```

**2. Розрахунок часових інтервалів `t_a`, `t_b`, `t_rr`:**

```
t_a = 39.19 / (800·10⁶) = 48.99·10⁻⁹ с ≈ 49.0 нс     [тривалість фази розсмоктування t_a]
t_b = 0.25 · 48.99 нс ≈ 12.25 нс                    [тривалість фази спаду t_b = S · t_a]
t_rr = 49.0 + 12.25 = 61.25 нс                      [повний час відновлення t_rr = t_a + t_b]
```

**3. Розрахунок швидкості спаду струму `di_rr/dt` та амплітуди перенапруги `V_spike`:**

```
di_rr/dt = (800·10⁶) / 0.25 = 3200·10⁶ А/с = 3200 А/мкс [швидкість спаду струму у фазі t_b]
V_spike = 20·10⁻⁹ · 3200·10⁶ = 64.0 В               [індуктивний викид напруги L_loop · di/dt]
V_ds_max = 400 + 64.0 = 464.0 В                     [пікова напруга на стоку ключа]
```

**4. Розрахунок динамічних втрат енергії та потужності:**

```
E_rr_QH = 400 · 1200·10⁻⁹ = 480·10⁻⁶ Дж = 480 мкДж  [втрати увімкнення верхнього ключа V_bus · Q_rr]
E_rec = ⅓ · (0.25 / 1.25) · 400 · 1200·10⁻⁹ = 32 мкДж [втрати у body-діоді нижнього ключа]
E_rr_total = 480 + 32 = 512 мкДж                    [сумарна енергія втрат за один цикл]
P_rr = 512·10⁻⁶ · 100·10³ = 51.2 Вт                 [середня потужність теплових втрат відновлення]
```

**Порівняння з оптимізованим швидким діодом (Fast Recovery MOSFET, Fast Body Diode):**

Якщо застосувати транзистор із модифікованим часом життя носіїв, для якого `Q_rr = 150 нКл` та `S = 1.0` (Soft recovery):

```
I_rrm_fast = √( (2 · 150·10⁻⁹ · 800·10⁶) / (1 + 1.0) ) = √120 = 10.95 А [піковий зворотний струм]
t_a_fast = 10.95 / (800·10⁶) = 13.69 нс             [час винесення заряду швидкого діода]
t_b_fast = 1.0 · 13.69 нс = 13.69 нс                [час спаду струму м'якого відновлення]
t_rr_fast = 27.38 нс                                [повний час відновлення]
di_rr/dt_fast = (800·10⁶) / 1.0 = 800 А/мкс         [швидкість спаду струму]
V_spike_fast = 20·10⁻⁹ · 800·10⁶ = 16.0 В           [індуктивний викид перенапруги]
P_rr_fast = 400 · 150·10⁻⁹ · 100·10³ · 1.167 = 7.0 Вт [потужність втрат відновлення]
```

Застосування ключа з оптимізованим body-діодом знижує динамічні втрати відновлення з 51.2 Вт до 7.0 Вт (більш ніж у 7 разів), усуваючи необхідність масивного тепловідводу, а викид перенапруги знижується з 64 В до 16 В, забезпечуючи надійний запас міцності силового напівпровідника.
