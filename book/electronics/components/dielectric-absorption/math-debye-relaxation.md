# 🧮 Модель релаксації Дебая та математика діелектричної абсорбції

Цей математичний аналіз встановлює кількісний зв'язок між мікроскопічною динамікою поляризації діелектрика, еквівалентною багатоланковою RC-моделлю та часовою залежністю відновленої напруги на клемах конденсатора. Без строгого математичного апарату релаксації Дебая неможливо аналітично розрахувати похибку пристроїв вибірки-зберігання, спроектувати схеми компенсації діелектричного замочування або розрахувати частотно-залежні втрати конденсатора на наднизьких частотах.

### Диференціальне рівняння дипольної релаксації першого порядку

Розглянемо діелектрик, поміщений в однорідне зовнішнє електричне поле з напруженістю `E`. Повна діелектрична поляризація середовища `P` (дипольний момент одиниці об'єму) складається з двох фізично відмінних компонентів:

```
P = P_inf + P_dip
```

де:
* `P_inf` — квазімиттєва поляризація (електронна та пружна деформаційна іонна), яка встановлюється практично безінерційно за час менше `10⁻¹²` секунди і описується високочастотною діелектричною проникністю `ε_inf`:

```
P_inf = ε_0 · (ε_inf - 1) · E
```

* `P_dip` — релаксаційна (орієнтаційна дипольна та міжфазна) поляризація, встановлення якої вимагає подолання внутрішнього тертя середовища та потенційних бар'єрів кристалічної або аморфної ґратки.

Петер Дебай у 1913 році запропонував феноменологічне рівняння першого порядку, згідно з яким швидкість зміни релаксаційної поляризації прямо пропорційна її відхиленню від термодинамічно рівноважного значення `P_eq`:

```
dP_dip(t) / dt = (P_eq - P_dip(t)) / τ
```

де `τ` — час релаксації (характерний час орієнтації диполів або розсіювання заряду), а рівноважна поляризація за статичної проникності `ε_s` дорівнює:

```
P_eq = ε_0 · (ε_s - ε_inf) · E
```

Розв'яжемо це лінійне неоднорідне диференціальне рівняння для стрибкоподібного ввімкнення постійного поля `E` у момент часу `t = 0` за нульових початкових умов `P_dip(0) = 0`.

Розділимо змінні та проінтегруємо обидві частини рівняння:

```
dP_dip / (P_eq - P_dip) = dt / τ
-ln(P_eq - P_dip) = t / τ + C_const
```

Використовуючи початкову умову `P_dip(0) = 0` при `t = 0`, знаходимо сталу інтегрування:

```
C_const = -ln(P_eq)
```

Підставляючи отриману сталу інтегрування у вихідний вираз:

```
-ln((P_eq - P_dip(t)) / P_eq) = t / τ
(P_eq - P_dip(t)) / P_eq = e^(-t / τ)
P_dip(t) = P_eq · (1 - e^(-t / τ))
```

Отже, повна поляризація діелектрика під час тривалого заряджання зростає за експоненційним законом:

```
P(t) = P_inf + P_eq · (1 - e^(-t / τ))
= ε_0 · (ε_inf - 1) · E + ε_0 · (ε_s - ε_inf) · E · (1 - e^(-t / τ))
```

Коли зовнішнє поле миттєво вимикається у момент часу `t = t_off`, електронна поляризація `P_inf` миттєво спадає до нуля, а релаксаційна складова експоненційно згасає під дією хаотичного теплового руху молекул:

```
P_dip(t) = P_dip(t_off) · e^(-(t - t_off) / τ)
```

### Комплексна діелектрична проникність та тангенс втрат у частотній області

Якщо прикладене поле гармонійно змінюється в часі з кутовою частотою `ω` за законом `E(t) = E_0 · e^(jωt)`, диференціальне рівняння Дебая набуває комплексного алгебраїчного вигляду:

```
jω · P_dip = (ε_0 · (ε_s - ε_inf) · E - P_dip) / τ
```

Виразимо релаксаційну поляризацію `P_dip`:

```
P_dip · (1 + jωτ) = ε_0 · (ε_s - ε_inf) · E
P_dip = (ε_0 · (ε_s - ε_inf) / (1 + jωτ)) · E
```

Повний електричний вектор індукції `D` у діелектрику пов'язаний із полем через комплексну діелектричну проникність `ε*(ω)`:

```
D = ε_0 · E + P = ε_0 · ε*(ω) · E
```

Підставивши вираз для повної поляризації `P = P_inf + P_dip`, отримуємо класичне рівняння Дебая для комплексної проникності:

```
ε*(ω) = ε_inf + (ε_s - ε_inf) / (1 + jωτ)
```

Розділимо дійсну `ε'(ω)` та уявну `ε''(ω)` частини комплексної проникності:

```
ε*(ω) = ε'(ω) - j · ε''(ω)
```

Домножимо чисельник і знаменник дробу на комплексно-спряжений вираз `(1 - jωτ)`:

```
(ε_s - ε_inf) / (1 + jωτ)
= (ε_s - ε_inf) · (1 - jωτ) / (1 + (ωτ)²)                 [домноження на спряжений множник]
= (ε_s - ε_inf) / (1 + (ωτ)²) - j · ((ε_s - ε_inf) · ωτ) / (1 + (ωτ)²)  [розділення дійсної та уявної частин]
```

Звідси знаходимо дійсну та уявну складові діелектричної проникності:

```
ε'(ω) = ε_inf + (ε_s - ε_inf) / (1 + (ωτ)²)      [дійсна частина: ефективна ємність]
ε''(ω) = (ε_s - ε_inf) · ωτ / (1 + (ωτ)²)        [уявна частина: діелектричні втрати]
```

Тангенс кута діелектричних втрат `tan(δ)` дорівнює відношенню уявної частини до дійсної:

```
tan(δ) = ε''(ω) / ε'(ω)
= ((ε_s - ε_inf) · ωτ) / (ε_s + ε_inf · (ωτ)²)
```

Максимум діелектричних втрат `ε''(ω)` досягається на характеристичній частоті релаксації:

```
ω_max = 1 / τ
f_max = 1 / (2π · τ)
```

На цій частоті період коливань зовнішнього поля точно збігається з часом орієнтації диполів, через що диполі зазнають максимального фазового відставання від поля, розсіюючи максимальну кількість енергії у вигляді тепла.

### Діаграма Коул — Коула та узагальнені емпіричні моделі

Якщо побудувати залежність уявної частини проникності `ε''(ω)` від дійсної частини `ε'(ω)` на комплексній площині, класична модель Дебая дає ідеальне півколо з центром на осі дійсних чисел у точці `(ε_s + ε_inf) / 2`.

Проте експерименти з реальними полімерними плівками (PET, PC) та сегнетокерамікою (X7R) показують, що реальна діаграма має вигляд сплюснутої або асиметричної дуги. Це пов'язано з тим, що твердий діелектрик містить не один час релаксації `τ`, а широкий неперервний спектр активаційних бар'єрів.

Для опису реальних спектрів використовують кілька узагальнених математичних моделей:

1. **Модель Коул — Коула (Cole-Cole, 1941)** враховує симетричне розширення спектра констант часу за рахунок введення параметра розподілу `α` (`0 < α ≤ 1`):

```
ε*(ω) = ε_inf + (ε_s - ε_inf) / (1 + (jωτ)^(1 - α))
```

Коли `α = 0`, модель збігається з рівнянням Дебая. Зі збільшенням `α` півколо на діаграмі опускається нижче дійсної осі, центр дуги зміщується у комплексну площину, а пік втрат стає ширшим і нижчим.

2. **Модель Коул — Девідсона (Cole-Davidson, 1950)** враховує асиметричний хвіст релаксації на високих частотах за допомогою параметра `γ` (`0 < γ ≤ 1`):

```
ε*(ω) = ε_inf + (ε_s - ε_inf) / (1 + jωτ)^γ
```

3. **Модель Гаврільяка — Негамі (Havriliak-Negami, 1966)** об'єднує обидва ефекти у загальне п'ятипараметричне рівняння:

```
ε*(ω) = ε_inf + (ε_s - ε_inf) / (1 + (jωτ)^α)^γ
```

У часовій області наявність неперервного спектра бар'єрів призводить до того, що спад поляризації описується не простою експонентою `e^(-t/τ)`, а **розтягнутою експонентою Кольрауша — Вільямса — Воттса (KWW)**:

```
φ(t) = exp(-(t / τ_char)^β)
```

де показник розтягування `0 < β ≤ 1` безпосередньо характеризує ступінь структурного безладу діелектрика.

### Аналітичний розрахунок відновленої напруги за схемою Дебая

Перейдемо до схемотехнічного аналізу еквівалентної багатоланкової схеми Дебая, яка складається з основної швидкої ємності `C0` та `N` паралельних релаксаційних ланок `rᵢ - cᵢ`.

Розглянемо повний цикл випробувань на діелектричну абсорбцію, що складається з трьох послідовних часових фаз:

1. **Фаза 1: Тривалий заряд**. Напруга `V_charge` прикладається до конденсатора протягом часу `t_c` (за стандартом MIL-PRF-19978D `t_c = 900 с`).
2. **Фаза 2: Короткочасне коротке замикання (КЗ)**. Виводи замикаються накоротко на час `t_d` (за стандартом `t_d = 5 с`).
3. **Фаза 3: Розімкнення та вистоювання**. Виводи розмикаються, і на них вимірюється відновлена напруга `V_recovered(t)`.

Знайдемо аналітичний розв'язок для напруги `vᵢ(t)` на кожній внутрішній релаксаційній ємності `cᵢ`.

#### Фаза 1: Накопичення заряду в ємності cᵢ
Кожна гілка `rᵢ - cᵢ` підключена до напруги `V_charge`. Напруга на ємності `cᵢ` наприкінці інтервалу `t_c` дорівнює:

```
vᵢ(t_c) = V_charge · (1 - e^(-t_c / τᵢ))
```

де константа часу гілки: `τᵢ = rᵢ · cᵢ`.

#### Фаза 2: Розряджання під час короткого замикання
Під час замикання клем накоротко напруга на шинах дорівнює 0 В. Швидка ємність `C0` розряджається практично миттєво. Релаксаційні ємності `cᵢ` розряджаються через власні внутрішні опори `rᵢ`.

Напруга на ємності `cᵢ` в момент зняття короткого замикання (через час `t_d`) становить:

```
vᵢ_rem = vᵢ(t_c) · e^(-t_d / τᵢ)
= V_charge · (1 - e^(-t_c / τᵢ)) · e^(-t_d / τᵢ)
```

Залишковий електричний заряд, законсервований усередині гілки `cᵢ`:

```
qᵢ_rem = cᵢ · vᵢ_rem
= cᵢ · V_charge · (1 - e^(-t_c / τᵢ)) · e^(-t_d / τᵢ)
```

#### Фаза 3: Перерозподіл заряду після розмикання кола
У момент розмикання виводів (`t = 0` третьої фази) швидка ємність розряджена (`v_C0(0) = 0`), тоді як на внутрішніх релаксаційних ємностях збережено початкові напруги `vᵢ_rem`.

Запишемо систему диференціальних рівнянь за законами Кірхгофа для вузла відновленої напруги `V(t)`:

```
C0 · (dV(t) / dt) + ∑ [ (V(t) - vᵢ(t)) / rᵢ ] = 0
cᵢ · (dvᵢ(t) / dt) + (vᵢ(t) - V(t)) / rᵢ = 0      [для кожної гілки i = 1...N]
```

Застосуємо пряме перетворення Лапласа за нульової початкової напруги на `C0` та початкових напруг `vᵢ(0) = vᵢ_rem` на ємностях `cᵢ`:

```
s · C0 · V(s) + ∑ [ (V(s) - Vᵢ(s)) / rᵢ ] = 0
s · cᵢ · Vᵢ(s) - cᵢ · vᵢ_rem + (Vᵢ(s) - V(s)) / rᵢ = 0
```

З другого рівняння виразимо зображення напруги `Vᵢ(s)`:

```
Vᵢ(s) · (s · cᵢ + 1 / rᵢ) = (1 / rᵢ) · V(s) + cᵢ · vᵢ_rem
Vᵢ(s) · ((s · rᵢ · cᵢ + 1) / rᵢ) = (1 / rᵢ) · V(s) + cᵢ · vᵢ_rem
Vᵢ(s) = V(s) / (s · τᵢ + 1) + (τᵢ · vᵢ_rem) / (s · τᵢ + 1)
```

Підставимо вираз для `Vᵢ(s)` у перше вузлове рівняння для однієї релаксаційної гілки `(r₁ - c₁)`:

```
s · C0 · V(s) + (V(s) - V₁(s)) / r₁ = 0
s · C0 · V(s) + (V(s) / r₁) · (1 - 1 / (s · τ₁ + 1)) = (c₁ · v₁_rem) / (s · τ₁ + 1)
s · C0 · V(s) + (V(s) / r₁) · (s · τ₁ / (s · τ₁ + 1)) = (c₁ · v₁_rem) / (s · τ₁ + 1)
V(s) · [ s · C0 + (s · c₁) / (s · τ₁ + 1) ] = (c₁ · v₁_rem) / (s · τ₁ + 1)
```

Скоротимо на `s` та помножимо обидві частини на `(s · τ₁ + 1)`:

```
V(s) · [ C0 · (s · τ₁ + 1) + c₁ ] = (c₁ · v₁_rem) / s
V(s) · [ s · C0 · τ₁ + (C0 + c₁) ] = (c₁ · v₁_rem) / s
V(s) = (c₁ · v₁_rem) / [ s · (s · C0 · τ₁ + (C0 + c₁)) ]
```

Розкладемо знаменник на прості множники:

```
V(s) = (v₁_rem · (c₁ / (C0 + c₁))) / [ s · (s · (C0 · τ₁ / (C0 + c₁)) + 1) ]
```

Введемо ефективну константу часу розряджання вузла:

```
τ_eff = τ₁ · (C0 / (C0 + c₁)) = r₁ · (C0 · c₁) / (C0 + c₁)
```

Тоді операторне зображення набуває стандартного вигляду табличного перетворення:

```
V(s) = (v₁_rem · (c₁ / (C0 + c₁))) · (1 / [ s · (s · τ_eff + 1) ])
```

Виконуючи зворотне перетворення Лапласа:

```
V(t) = v₁_rem · (c₁ / (C0 + c₁)) · (1 - e^(-t / τ_eff))
```

Підставивши вираз для початкової залишкової напруги `v₁_rem`:

```
V(t) = V_charge · (c₁ / (C0 + c₁)) · (1 - e^(-t_c / τ₁)) · e^(-t_d / τ₁) · (1 - e^(-t / τ_eff))
```

Оскільки в реальних конденсаторах `c₁ << C0`, відношення ємностей спрощується: `c₁ / (C0 + c₁) ≈ c₁ / C0`, а константа часу вузла `τ_eff ≈ τ₁`.

Для системи з `N` незалежних релаксаційних гілок Дебая, згідно з принципом лінійної суперпозиції, сумарна відновлена напруга дорівнює сумі внесків від усіх гілок:

```
V_recovered(t) = ∑ [ V_charge · (cᵢ / C0) · (1 - e^(-t_c / τᵢ)) · e^(-t_d / τᵢ) · (1 - e^(-t / τᵢ)) ]
```

### Аналіз похибки в схемі вибірки-зберігання (Sample-and-Hold)

Застосуємо отриманий математичний апарат для розрахунку похибки передачі напруги в пристрої вибірки-зберігання (S/H).

Нехай на вхід S/H подається стрибок напруги амплітудою `V_step`. Ключ вибірки замкнено протягом часу `t_sample` (фаза Track), після чого ключ розмикається на час перетворення АЦП `t_hold` (фаза Hold).

Під час фази Track ємність `C0` заряджається до повної напруги `V_step` через малий опір ключа `R_on`. Кожна внутрішня релаксаційна ємність `cᵢ` встигає зарядитися лише до напруги:

```
vᵢ(t_sample) = V_step · (1 - e^(-t_sample / τᵢ))
```

Коли ключ розмикається, на клемах накопичувального конденсатора діє початкова напруга `V(0) = V_step`. За рахунок різниці потенціалів між `C0` та внутрішніми ємностями `cᵢ` заряд починає перерозподілятися.

Динаміка падіння напруги на виході у фазі Hold описується виразом:

```
ΔV_droop(t_hold) = ∑ [ V_step · (cᵢ / C0) · e^(-t_sample / τᵢ) · (1 - e^(-t_hold / τᵢ)) ]
```

Відносна динамічна похибка вибірки `ε_SH` дорівнює:

```
ε_SH = ΔV_droop / V_step
= ∑ [ (cᵢ / C0) · e^(-t_sample / τᵢ) · (1 - e^(-t_hold / τᵢ)) ]
```

З формули видно, що похибка максимальна тоді, коли час вибірки малий (`t_sample << τᵢ`), а час зберігання порівнянний із часом релаксації (`t_hold ≈ τᵢ`).

### Вплив абсорбції на передатну функцію інтегратора на операційному підсилювачі

Розглянемо класичний аналоговий інтегратор на прецизійному операційному підсилювачі з вхідним резистором `R_in` та накопичувальним конденсатором у ланцюзі зворотного зв'язку. В ідеальному випадку комплексний опір конденсатора становить `Z_C(s) = 1 / (s · C0)`, а передатна функція інтегратора в операторній формі Лапласа має вигляд:

```
H_ideal(s) = - 1 / (s · R_in · C0)
```

На синусоїдальному сигналі частоти `ω` це відповідає строгому фазовому зсуву `+90°` та коефіцієнту передачі, обернено пропорційному частоті: `|H_ideal(jω)| = 1 / (ω · R_in · C0)`.

Якщо діелектрик конденсатора має релаксаційні втрати Дебая, комплексна провідність зворотного зв'язку `Y_fb(s)` записується як сума провідностей основної ємності та всіх релаксаційних гілок:

```
Y_fb(s) = s · C0 + ∑ [ (s · cᵢ) / (s · rᵢ · cᵢ + 1) ]
```

Підставивши комплексну провідність зворотного зв'язку у вираз для коефіцієнта передачі інвертуючого підсилювача `H(s) = - 1 / (R_in · Y_fb(s))`:

```
H(s) = - 1 / [ R_in · ( s · C0 + ∑ [ (s · cᵢ) / (s · τᵢ + 1) ] ) ]
```

Для однієї релаксаційної гілки `(r₁ - c₁)` перетворимо вираз до стандартного дробово-раціонального вигляду:

```
H(s) = - (s · τ₁ + 1) / [ R_in · s · (s · C0 · τ₁ + (C0 + c₁)) ]
```

Перейдемо до частотної області, поклавши `s = jω`:

```
H(jω) = - (1 + jωτ₁) / [ jω · R_in · ( (C0 + c₁) + jω · C0 · τ₁ ) ]
```

Звідси видно, що наявність діелектричної абсорбції додає в передатну функцію інтегратора:
1. **Паразитний нуль** на кутовій частоті `ω_zero = 1 / τ₁`.
2. **Паразитний полюс** на вищій кутовій частоті `ω_pole = (C0 + c₁) / (C0 · τ₁) = 1 / τ_eff`.

Через розщеплення полюса і нуля на низьких частотах (`ω << 1 / τ₁`) ефективна ємність інтегрування зростає від `C0` до `C0 + c₁`, а коефіцієнт підсилення зменшується на величину `c₁ / C0`.

Фазовий зсув реального інтегратора відхиляється від ідеальних `90.0°` на кут фазової похибки `Δθ(ω)`:

```
Δθ(ω) ≈ arctan(ω · τ₁) - arctan(ω · τ_eff)
≈ ((c₁ / C0) · ωτ₁) / (1 + (ωτ₁)²)
```

Максимальна фазова похибка досягається на частоті `ω = 1 / τ₁` і становить приблизно:

```
Δθ_max ≈ (c₁ / (2 · C0))  [у радіанах]
```

Для конденсатора з відносною абсорбцією `c₁ / C0 = 0.5%` (0.005) фазова похибка становить `Δθ_max ≈ 0.0025 рад ≈ 0.143°`. У високоточних генераторах квадратурних сигналів, аналогових комп'ютерах та вимірювальних фазометрах така фазова похибка інтегратора викликає фазовий дрейф та систематичну похибку амплітуди коливань.

### Енергетичний баланс та втрати за цикл коливань

Розглянемо енергетичні процеси в конденсаторі з діелектричною абсорбцією при дії гармонійної напруги `v(t) = V_0 · cos(ωt)`.

Миттєва густина енергії, що надходить від джерела у діелектрик за одиницю часу:

```
w(t) = E(t) · (dD(t) / dt)
```

Підставивши вектор електричної індукції `D(t) = ε_0 · ε'(ω) · E(t) + ε_0 · ε''(ω) · (1/ω) · (dE(t)/dt)` та проінтегрувавши за один повний період коливань `T = 2π / ω`:

```
W_loss = ∮ E · dD
= ∫₀^T [ E_0 · cos(ωt) · ( -ω · ε_0 · ε'(ω) · E_0 · sin(ωt) + ω · ε_0 · ε''(ω) · E_0 · cos(ωt) ) ] dt
```

Перший доданок (реактивна складова) містить добуток `sin(ωt) · cos(ωt) = 0.5 · sin(2ωt)`. Інтеграл від нього за повний період строго дорівнює нулю: енергія періодично перетікає з поля в конденсатор і повертається назад у джерело без втрат.

Другий доданок (активна складова втрат) містить `cos²(ωt)`. Інтеграл за період дорівнює:

```
∫₀^T cos²(ωt) dt = T / 2 = π / ω
```

Підставляючи результат інтегрування:

```
W_loss = ω · ε_0 · ε''(ω) · E_0² · (π / ω)
= π · ε_0 · ε''(ω) · E_0²
```

Повна енергія, що розсіюється в об'ємі діелектрика `Vol` за один період коливань:

```
W_period = π · C_eff · V_0² · tan(δ)
```

де `C_eff = ε'(ω) · ε_0 · (A / d)` — дійсна ємність на даній частоті, а `tan(δ) = ε''(ω) / ε'(ω)` — тангенс кута діелектричних втрат.

Цей вираз доводить прямий зв'язок між мікроскопічною моделлю Дебая та макроскопічним нагріванням конденсатора: кожен дипольний перехід під дією змінного поля розсіює фіксовану частку енергії, пропорційну уявному коефіцієнту абсорбції діелектрика.

### Повний числовий приклад розрахунку діелектричної абсорбції

Проведемо повний інженерний розрахунок відновленої напруги для плівкового поліетилентерефталатного (майларового) конденсатора номінальною ємністю `C0 = 100 нФ`, який характеризується трьома домінуючими релаксаційними гілками Дебая.

#### Вихідні параметри еквівалентної схеми:
* Основна ємність: `C0 = 100.0 нФ`
* Початкова напруга заряду: `V_charge = 50.0 В`
* Час заряджання: `t_c = 900 с` (15 хвилин)
* Час короткого замикання: `t_d = 5 с`

Параметри релаксаційних гілок:
* **Гілка 1 (швидка)**: `c₁ = 0.2 нФ`, `r₁ = 5 · 10⁶ Ом`
  `τ₁ = r₁ · c₁ = (5 · 10⁶ Ом) · (0.2 · 10⁻⁹ Ф) = 1.0 с`
* **Гілка 2 (середня)**: `c₂ = 0.5 нФ`, `r₂ = 2 · 10⁸ Ом`
  `τ₂ = r₂ · c₂ = (2 · 10⁸ Ом) · (0.5 · 10⁻⁹ Ф) = 100.0 с`
* **Гілка 3 (повільна)**: `c₃ = 1.0 нФ`, `r₃ = 2 · 10⁹ Ом`
  `τ₃ = r₃ · c₃ = (2 · 10⁹ Ом) · (1.0 · 10⁻⁹ Ф) = 2000.0 с`

#### Крок 1: Обчислення коефіцієнта заряду `K_charge = (1 - e^(-t_c / τᵢ))`
Для кожної гілки після `t_c = 900 с`:

* Гілка 1 (`τ₁ = 1 с`):
  `K_charge_1 = 1 - e^(-900 / 1) = 1 - e^(-900) ≈ 1.000` (повне насичення)
* Гілка 2 (`τ₂ = 100 с`):
  `K_charge_2 = 1 - e^(-900 / 100) = 1 - e^(-9.0) = 1 - 0.000123 = 0.9999`
* Гілка 3 (`τ₃ = 2000 с`):
  `K_charge_3 = 1 - e^(-900 / 2000) = 1 - e^(-0.45) = 1 - 0.6376 = 0.3624`

#### Крок 2: Обчислення коефіцієнта збереження під час КЗ `K_discharge = e^(-t_d / τᵢ)`
Для кожної гілки після `t_d = 5 с`:

* Гілка 1 (`τ₁ = 1 с`):
  `K_discharge_1 = e^(-5 / 1) = e^(-5) ≈ 0.006738` (швидка гілка майже повністю розрядилася)
* Гілка 2 (`τ₂ = 100 с`):
  `K_discharge_2 = e^(-5 / 100) = e^(-0.05) ≈ 0.95123` (втрачено лише 4.9% заряду)
* Гілка 3 (`τ₃ = 2000 с`):
  `K_discharge_3 = e^(-5 / 2000) = e^(-0.0025) ≈ 0.99750` (втрачено лише 0.25% заряду)

#### Крок 3: Обчислення коефіцієнта відновлення через `t = 60 с` після розмикання
Коефіцієнт відновлення `K_rec = (1 - e^(-60 / τᵢ))`:

* Гілка 1 (`τ₁ = 1 с`):
  `K_rec_1 = 1 - e^(-60 / 1) = 1.000`
* Гілка 2 (`τ₂ = 100 с`):
  `K_rec_2 = 1 - e^(-60 / 100) = 1 - e^(-0.6) = 1 - 0.5488 = 0.4512`
* Гілка 3 (`τ₃ = 2000 с`):
  `K_rec_3 = 1 - e^(-60 / 2000) = 1 - e^(-0.03) = 1 - 0.9704 = 0.0296`

#### Крок 4: Підсумовування парціальних внесків від кожної гілки

Обчислимо парціальний внесок `Vᵢ = V_charge · (cᵢ / C0) · K_charge_i · K_discharge_i · K_rec_i`:

Внесок гілки 1:
```
V₁ = 50.0 В · (0.2 / 100.0) · 1.000 · 0.006738 · 1.000
= 50.0 · 0.002 · 0.006738     [перемноження ємнісного дільника на коефіцієнти]
= 0.000674 В                  [обчислення парціальної напруги у вольтах]
= 0.674 мВ                    [переведення у мілівольти]
```

Внесок гілки 2:
```
V₂ = 50.0 В · (0.5 / 100.0) · 0.9999 · 0.95123 · 0.4512
= 50.0 · 0.005 · 0.9511 · 0.4512   [перемноження ємнісного дільника на коефіцієнти]
= 0.1073 В                         [обчислення парціальної напруги у вольтах]
= 107.3 мВ                         [переведення у мілівольти]
```

Внесок гілки 3:
```
V₃ = 50.0 В · (1.0 / 100.0) · 0.3624 · 0.9975 · 0.0296
= 50.0 · 0.01 · 0.3615 · 0.0296   [перемноження ємнісного дільника на коефіцієнти]
= 0.00535 В                       [обчислення парціальної напруги у вольтах]
= 5.35 мВ                         [переведення у мілівольти]
```

Сумарна відновлена напруга через 60 секунд:
```
V_recovered = V₁ + V₂ + V₃
= 0.674 мВ + 107.3 мВ + 5.35 мВ   [додавання внесків трьох гілок Дебая]
= 113.324 мВ                      [сумарна напруга у мілівольтах]
= 0.1133 В                        [переведення у вольти]
```

#### Крок 5: Обчислення коефіцієнта DA за стандартом MIL-PRF-19978D
```
DA = (V_recovered / V_charge) · 100%
= (0.1133 В / 50.0 В) · 100%       [підстановка обчисленої та початкової напруг]
= 0.002266 · 100%                  [ділення величин]
= 0.227%                           [обчислення відсотка діелектричної абсорбції]
```

Цей числовий розрахунок наочно доводить:
* Швидкі релаксаційні гілки (`τ < 1 с`) встигають розрядитися під час 5-секундного короткого замикання і дають менше 0.6% від сумарної відновленої напруги.
* Надважкі повільні гілки (`τ > 1000 с`) не встигають суттєво віддати заряд за 60 секунд вимірювання (дають лише 4.7% внеску).
* **Основний внесок у стандартне вимірювання DA (понад 94.7% похибки) формують середні релаксаційні гілки з константами часу порядку 10–300 секунд.**

Аналітична модель Дебая дозволяє точно прогнозувати поведінку конденсаторів у динамічних режимах та обирати матеріали діелектриків із гарантованим запасом точності.
