# 🔌 Потенціометр: поворот як напруга — перший аналоговий вхід

> Компонентна вставка про потенціометр як джерело напруги для [АЦП](book:electronics/adc) — вузла, що перетворює напругу на число. АЦП зчитує «якусь напругу» з подільника; ось найпростіше джерело тієї напруги — ручка-потенціометр, рукотворний подільник, чий повзунок ти крутиш пальцем. Це перший аналоговий вхід, який варто зчитати, тож розкриваємо його зсередини.

## Що це за деталь

**Потенціометр** (*potentiometer*, «pot») — змінний резистор із трьома виводами: два кінці фіксованого резистивного елемента (доріжка, *track/element*, з повним опором R, наприклад 10 кОм) і **повзунок** (*wiper*), що ковзає вздовж доріжки та знімає напругу в точці контакту. Суть проста: це **подільник напруги з рухомою середньою точкою** — звичайний [подільник напруги](book:electronics/voltage-divider), але співвідношення плечей задаєш не парою постійних резисторів, а поворотом ручки.

Потенціометри виготовляють у кількох форм-факторах: поворотна ручка (*rotary*), повзунковий слайдер (*slide*), підлаштовник під викрутку (*trimmer*). Крім трьох виводів існує й дворивідна схема — реостат (*rheostat*), де використовують лише кінець і повзунок; він керує струмом, а не напругою (про нього — у «Варіаціях класу»).

## Подільник із рухомою точкою — блок-схема

Уявіть, що повний опір R розрізаний повзунком на верхнє плече R_top і нижнє R_bot. Сума цих плечей завжди незмінна:

```
R_top + R_bot = R       (закон збереження)

Vwiper = Vcc · R_bot / (R_top + R_bot) = Vcc · R_bot / R

поворот 0 %   → R_bot = 0     → Vwiper ≈ 0 В
поворот 50 %  → R_bot = R/2   → Vwiper ≈ Vcc/2 = 1.65 В
поворот 100 % → R_bot = R     → Vwiper ≈ Vcc ≈ 3.3 В
```

Важлива деталь: формула залежить лише від частки R_bot/R, а не від абсолютних кілоомів. Це **ратіометрична** (*ratiometric*) залежність — Vwiper пропорційна частці повороту, бо живлення подільника й [опорна напруга](book:electronics/voltage-reference) АЦП — те саме Vcc. Тут достатньо знати, що номінал 10 кОм чи 50 кОм дасть однаковий Vwiper при однаковому куті.

![Потенціометр як подільник напруги з рухомою точкою; лінійний і логарифмічний taper](/book/electronics/components/potentiometer/img/divider-taper.svg)
*Потенціометр = подільник напруги з рухомою точкою; лінійний проти логарифмічного taper.*

Утім, номінал R не зовсім байдужий на практиці: дуже малий R — зайвий наскрізний струм і нагрів; дуже великий R — великий вихідний опір джерела, і АЦП поводиться примхливо (це вже питання [узгодження джерела з входом АЦП](guide:embedded/signal-acquisition)).

> 🔧 **Навіщо знати про taper?** Закон зміни опору вздовж доріжки називається *taper*. **Лінійний (lin, B)**: частка опору пропорційна куту — пряма лінія на графіку. **Логарифмічний (log/audio, A)**: опір зростає нерівномірно, бо людське вухо сприймає гучність за логарифмічним законом. Для вимірювання кута чи положення завжди беріть **лінійний (B)** — інакше шкала виходить «крива».

## Розпіновка: три виводи

На схемах ніжки маркують **1** і **3** (кінці, іноді CW/CCW — «за годинниковою» / «проти») і **2** (середній — повзунок, W). Підключення однозначне:

- кінець **1** або **3** → Vcc (3.3 В)
- протилежний кінець → GND
- повзунок (**W**) → ніжка ADC ESP32

Якщо переплутати кінці між собою — нічого не згорить: просто напруга йтиме у зворотний бік (крутиш праворуч, а Vwiper падає замість того, щоб зростати). Виправляється переполюсовкою кінців або однією командою `4095 - raw` у коді.

Одне важливе обмеження ESP32: повзунок слід підключати до **ніжки ADC1** (GPIO32–39), а не ADC2 — при ввімкненому Wi-Fi канали ADC2 повертають непередбачувані значення (це особливість самого [АЦП](book:electronics/adc) ESP32).

## Підключення

Схема мінімальна: один кінець поту на **3.3 В**, інший — на **GND**, повзунок — на **GPIO ADC1**.

![Підключення потенціометра до ESP32: кінці на 3.3 В і GND, повзунок на ADC1-ніжку](/book/electronics/components/potentiometer/img/wiring.svg)
*Підключення поту до ESP32: кінці на 3.3 В і GND, повзунок на ADC1-ніжку.*

Чому саме **3.3 В**, а не 5 В? Верхня межа шкали АЦП ESP32 — близько 3.3 В. Якщо подати 5 В на кінець поту, при повному повороті ручки Vwiper сягне 5 В і впреться в стелю АЦП (*clipping* — код застряє на 4095), а при перевищенні меж входу виникає ризик пошкодити ніжку мікроконтролера. Звідки береться сама межа шкали — це питання [опорної напруги](book:electronics/voltage-reference) АЦП.

На відміну від [кнопки з підтяжкою](book:electronics/contact-debounce), потенціометр є самодостатнім подільником: зовнішніх резисторів не потрібно. За бажання варто поставити невеликий конденсатор (~100 нФ) між повзунком і GND — найпростіший фільтр від шуму доріжки.

## Перший байт: як заговорити

Протокол читання найпростіший з-поміж аналогових: `analogRead(pin)` повертає ціле число від 0 до 4095 — код щабля, а не вольти (так працює [АЦП](book:electronics/adc)).

**Мінімальний робочий приклад (Arduino-ESP32):**

```cpp
const int POT = 34;            // ADC1-ніжка (Wi-Fi-safe)

void setup() {
  Serial.begin(115200);
  // вхід; виклик opinionated — ADC-ніжки читаються і без pinMode
}

void loop() {
  int raw = analogRead(POT);              // 0…4095 — «номер щабля»
  float v  = raw * 3.3f / 4095.0f;        // назад у вольти: код · опорна / макс. код
  int pct  = map(raw, 0, 4095, 0, 100);   // поворот у відсотках
  Serial.printf("raw=%4d  v=%.2f  pos=%d%%\n", raw, v, pct);
  delay(100);
}
```

`raw` зростає разом із поворотом ручки. Перерахунок у вольти — стандартний для [АЦП](book:electronics/adc) вираз `raw * 3.3 / 4095`. `map` дає зручну «позицію 0…100 %» без плаваючої арифметики.

Є й важливий нюанс: навіть при нерухомій ручці останні розряди `raw` «тремтять» на ±кілька одиниць. Це не вада — це шум доріжки.

## Шум доріжки і дрейф країв

Повзунок ковзає по резистивному шару, зачіпаючи мікронерівності. Миттєвий опір контакту постійно змінюється — особливо під час руху ручки. Звідси **шум повзунка** (*wiper noise / track noise*): останні кілька розрядів коду нестабільні. Стоїть ручка нерухомо — коливання ≤5 одиниць; крутиш — стрибки більші, схожі на «дряпання» (*scratchiness*).

Це та сама фізика контакту, що й [брязкіт кнопки](book:electronics/contact-debounce) — не дефект деталі, а природа ковзного контакту. До цього додається **дрейф країв** (*end-resistance*): дешеві поти часто не дають чистих 0 і 4095 на краях ходу («мертві зони»).

Що з цим робити — не тема цієї вставки, але орієнтир: усередніть кілька читань, візьміть медіану або відловлюйте лише зміни, що перевищили поріг (гістерезис). Це вже частина [узгодження джерела з входом АЦП](guide:embedded/signal-acquisition).

## Типові підводні камені

- **Подали 5 В на кінець.** Частина повороту дає напругу понад шкалу АЦП → значення «впирається у 4095» (*clipping*) і є ризик пошкодити ніжку. Кінець — завжди на 3.3 В.
- **Повзунок на ADC2-ніжку.** При ввімкненому Wi-Fi читання — сміття (відома пастка [АЦП](book:electronics/adc) ESP32). Використовуйте ADC1 (GPIO32–39).
- **Переплутали кінці.** Поворот праворуч зменшує напругу. Не поломка — переполюсуйте кінці або інвертуйте `4095 - raw`.
- **Логарифмічний пот для вимірювання кута.** Шкала виходить «крива» (нелінійна залежність положення). Для вимірювання позиції чи кута — тільки **лінійний (lin/B)**.
- **Одиничне нефільтроване читання як точна позиція.** Останні розряди тремтять (шум доріжки). Усередніть або відфільтруйте — це частина [узгодження джерела з входом АЦП](guide:embedded/signal-acquisition).
- **Дуже високоомний пот (напр. 1 МОм) прямо на АЦП.** Великий вихідний опір → похибки вибірки. Беріть помірний номінал (~1…50 кОм). Деталі — у [роботі джерела з входом АЦП](guide:embedded/signal-acquisition).

## Варіації класу

За форм-фактором поти поділяються на **поворотні** (*rotary*) — дуга ходу ~270° (є й багатооборотні для точного підлаштування), **слайдери** (*slide*) з лінійним ходом (типові в мікшерних пультах) і **підлаштовники** (*trimmer/preset*) — крихітні, під викрутку, що монтуються на платі й зазвичай більше не торкаються. Усі вони різняться корпусом, ходом і номіналом, але принцип «частка повороту → частка напруги» незмінний.

За *taper*: **лінійний (B)** — для вимірювань положення й кута; **логарифмічний/audio (A)** — для регулювання гучності.

За схемою вмикання: три виводи = **потенціометр** (подільник, наш режим); два виводи (кінець + повзунок) = **реостат** (*rheostat*) — змінний опір, що керує струмом, а не дає готової напруги.

Є ще **цифрові потенціометри** (*digital pot*), керовані шиною: той самий подільник, але повзунок рухає не палець, а команда мікроконтролера — цікава деталь, що виходить за межі цієї вставки.
