# 🧮 Розрахунок деформації, згинального моменту та звукового тиску MLCC

Фізичне явище перетворення електричних пульсацій у чутний акустичний шум охоплює три послідовні фізичні середовища: сегнетоелектричний кристал титанату барію, пружну композитну структуру друкованої плати та навколишнє повітря. Розрахункова модель пов'язує амплітуду електричної пульсації напруги з рівнем звукового тиску, вираженим у децибелах акустичної шкали.

## Кристалографічна деформація: п'єзоефект та електрострикція

У сегнетоелектричній кераміці класу II (наприклад, `BaTiO₃` у складі діелектриків X7R та X5R) відносна механічна деформація `S` (безрозмірна величина `ΔL / L`) під дією напруженості електричного поля `E` формується суперпозицією двох фізичних ефектів: зворотного п'єзоелектричного ефекту та електрострикції:

```
S = d · E + M · E²
```

де:
- `d` — п'єзоелектричний модуль (м/В або Кл/Н), що описує лінійний відгук нецентросиметричної кристалічної ґратки;
- `M` — коефіцієнт електрострикції (м²/В²), що описує квадратичний відгук поляризації матеріалу;
- `E` — напруженість електричного поля у шарі діелектрика (В/м).

У повній тензорній формі за нотацією Фойгта (*Voigt notation*) електромеханічний стан поляризованого сегнетоелектрика описується парою зв'язаних рівнянь стану:

```
S_i = s_ij^E · T_j + d_ki · E_k + M_kmi · E_k · E_m
D_k = ε_km^T · E_m + d_kj · T_j
```

де:
- `S_i` — 6-компонентний вектор механічної деформації (`i = 1...6`, де 1, 2, 3 відповідають поздовжнім деформаціям уздовж осей X, Y, Z, а 4, 5, 6 — зсувним деформаціям);
- `T_j` — 6-компонентний вектор механічного напруження (Па);
- `s_ij^E` — матриця пружної піддатливості за постійного електричного поля (м²/Н);
- `d_ki` — матриця п'єзоелектричних модулів (м/В);
- `M_kmi` — тензор коефіцієнтів електрострикції четвертого рангу (м²/В²);
- `D_k` — вектор електричної індукції (Кл/м²);
- `ε_km^T` — тензор діелектричної проникності за постійного механічного напруження.

Для полікристалічної текстурованої кераміки титанату барію з віссю поляризації вздовж осі 3 (вертикальна вісь `Z`, перпендикулярна до площини електродів) матриця п'єзомодулів містить три незалежні ненульові коефіцієнти: `d₃₃` (поздовжній), `d₃₁ = d₃₂` (поперечні) та `d₁₅ = d₂₄` (зсувні).

У сильних змінних полях рух 90-градусних сегнетоелектричних доменних стінок підпорядковується закону Релея для гістерезисного відгуку:

```
d₃₃(E_ac) = d_init + α_R · E_ac
```

де `d_init` — початковий п'єзомодуль за слабкого поля, а `α_R` — релеївський коефіцієнт необоротного руху доменних стінок. Цей механізм пояснює зростання акустичного шуму при великих розмахах змінної напруги пульсацій. При надвисоких полях (`E > 10 МВ/м`) настає насичення діелектричної поляризації за рівнянням Ланжевена, що дещо обмежує подальше квадратичне зростання деформації.

Температурна залежність діелектричної проникності титанату барію вище точки Кюрі `T_c ≈ 125 °C` описується законом Кюрі — Вейсса `ε_r = C_c / (T - T₀)`. При наближенні температури компонента до 120 °C (унаслідок саморозігріву струмами пульсацій) сегнетоелектрична фаза зазнає перебудови, що супроводжується локальним сплеском діелектричної проникності та короткочасним зростанням електрострикційного відгуку.

Після охолодження після паяння оплавленням у кераміці запускається процес часового старіння (*Aging*): спонтанна релаксація внутрішніх механічних напружень викликає повільне закріплення доменних меж. Швидкість старіння становить 1–2% втрати ємності та п'єзоактивності на декаду часу (1 год, 10 год, 100 год, 1000 год), завдяки чому пристрої після 100–200 годин припрацювання демонструють зниження рівня акустичного свисту на 1.5–3 дБ.

Розглянемо конденсатор із товщиною одного керамічного шару `d_layer`. До обкладок прикладено постійну напругу зміщення `V_dc` та гармонічну напругу пульсацій `V_ac(t) = V_pk · sin(ω · t)`. Сумарна напруженість поля в діелектрику вздовж осі 3 становить:

```
E₃(t) = E_dc + E_ac · sin(ω · t)
E_dc = V_dc / d_layer
E_ac = V_pk / d_layer
```

Підставивши вираз поля у рівняння деформації для поздовжньої осі `Z` (напрямок поля, перпендикулярно до площини електродів), отримуємо повний вираз для деформації `S_z(t)`:

```
S_z(t) = d₃₃ · [E_dc + E_ac · sin(ω · t)] + M₃₃ · [E_dc + E_ac · sin(ω · t)]²
```

Розкриваючи дужки та застосовуючи тригонометричне перетворення `sin²(ω · t) = 0.5 · (1 - cos(2 · ω · t))`, отримуємо розклад на три спектральні компоненти:

```
S_z(t) = S_dc + S_fund · sin(ω · t) + S_second · cos(2 · ω · t)
```

де окремі амплітуди деформації дорівнюють:

```
S_dc     = d₃₃ · E_dc + M₃₃ · E_dc² + 0.5 · M₃₃ · E_ac²       [статична деформація]
S_fund   = [d₃₃ + 2 · M₃₃ · E_dc] · E_ac                      [перша гармоніка (частота f = ω / 2π)]
S_second = -0.5 · M₃₃ · E_ac²                                 [друга гармоніка (частота 2f)]
```

### Гармонійний розклад для несинусоїдних пульсацій

У реальних імпульсних стабілізаторах напруга пульсацій на конденсаторі рідко буває чистою синусоїдою. Залежно від режиму перетворювача форма напруги описується рядом Фур'є:

1. **Трикутні пульсації (режим безперервного струму CCM):**
```
V_ac(t) = (8 · V_pk / π²) · [ sin(ωt) - (1/9)·sin(3ωt) + (1/25)·sin(5ωt) - ... ]
```

2. **Пилкоподібні пульсації (пакетний режим PFM / Burst Mode):**
```
V_ac(t) = (2 · V_pk / π) · [ sin(ωt) - (1/2)·sin(2ωt) + (1/3)·sin(3ωt) - ... ]
```

3. **Прямокутна ШІМ-послідовність (LED Dimming із коефіцієнтом заповнення D):**
```
V_ac(t) = V_pk · D + (2 · V_pk / π) · ∑ (1/k) · sin(k · π · D) · cos(k · ω · t)
```

Оскільки амплітуда вищих гармонік у пилкоподібному та імпульсному сигналі спадає повільно (пропорційно `1/k`), PFM-режим та LED-димування збуджують надзвичайно широкий спектр акустичних частот, перекриваючи одразу кілька резонансних мод друкованої плати.

### Ефективний п'єзомодуль під напругою зміщення

Постійне електричне поле зміщення `E_dc` лінеаризує квадратичний ефект електрострикції навколо робочої точки, створюючи ефективний комбінований п'єзоелектричний модуль `d_eff`:

```
d_eff = d₃₃ + 2 · M₃₃ · E_dc
```

Для типової кераміки X7R на основі легованого титанату барію п'єзомодуль за нульового поля становить `d₃₃ ≈ 150...300 × 10⁻¹² м/В`, а коефіцієнт електрострикції `M₃₃ ≈ 1.5...3.0 × 10⁻¹⁶ м²/В²`. За типової товщини шару `d_layer = 2.0 мкм` та робочої напруги `V_dc = 12 В` напруженість постійного поля досягає:

```
E_dc = 12 В / (2.0 × 10⁻⁶ м) = 6.0 × 10⁶ В/м  (6.0 МВ/м)
```

Підставивши числові значення у формулу ефективного модуля першої гармоніки:

```
d_eff = 200 × 10⁻¹² + 2 · (2.0 × 10⁻¹⁶) · (6.0 × 10⁶)
d_eff = 200 × 10⁻¹² + 2400 × 10⁻¹²
d_eff = 2600 × 10⁻¹² м/В  (2.6 нм/В)
```

Під дією високої напруженості поля внесок лінеаризованої електрострикції перевищує власний п'єзомодуль у 10–15 разів.

### Поперечна деформація та коефіцієнт Пуассона

Оскільки діелектричні шари механічно зв'язані в суцільний моноліт, поздовжнє розширення по осі `Z` викликає поперечне стискання вздовж осей `X` (довжина) та `Y` (ширина) через коефіцієнт Пуассона кераміки `ν ≈ 0.30`:

```
S_x(t) = -ν · S_z(t) ≈ -0.30 · S_z(t)
S_y(t) = -ν · S_z(t) ≈ -0.30 · S_z(t)
```

Амплітуда динамічної зміни довжини корпусу конденсатора довжиною `L_cap`:

```
ΔL(t) = S_x(t) · L_cap = -ν · d_eff · E_ac · L_cap · sin(ω · t)
```

Для корпусу 1206 (`L_cap = 3.2 мм`) при амплітуді пульсацій `V_pk = 1.0 В` (`E_ac = 0.5 МВ/м`):

```
ΔL_pk = 0.30 · (2600 × 10⁻¹² м/В) · (0.5 × 10⁶ В/м) · (3.2 × 10⁻³ м)
ΔL_pk = 1.25 × 10⁻⁹ м = 1.25 нм
```

## Механічна передача зусиль через паяні з'єднання

Амплітуда коливань 1.25 нм здається незначною, проте модуль Юнга кераміки `E_cer ≈ 110 ГПа` перетворює цю мікроскопічну деформацію на значне динамічне зусилля `F_x`.

Паяні галтелі припою жорстко зв'язують металізовані торці конденсатора з контактними майданчиками плати. Сила діє на плечі відносно нейтральної лінії згину плати. Динамічний згинальний момент `M_b`, прикладений до друкованої плати парою сил через дві паяні галтелі, визначається виразом:

```
M_b = F_x · h_arm
h_arm = (t_pcb / 2) + h_solder
```

де:
- `t_pcb` — товщина друкованої плати (типово 1.6 мм = `1.6 × 10⁻³ м`);
- `h_solder` — висота контактного майданчика та галтелі над платою (типово `0.1...0.3 мм`);
- `h_arm` — ефективне плече згинального моменту (близько 0.9–1.1 мм);
- `F_x` — амплітуда поперечної сили зсуву:

```
F_x = E_cer · A_cross · S_x
```

Для площі поперечного перерізу конденсатора 1206 `A_cross = W_cap · H_cap = 1.6 мм × 1.6 мм = 2.56 × 10⁻⁶ м²`:

```
F_x_ideal = (110 × 10⁹ Па) · (2.56 × 10⁻⁶ м²) · (3.9 × 10⁻⁴) ≈ 110 Н  (у жорстко затисненому стані)
```

Реальне динамічне зусилля, що передається на текстоліт, обмежене пружною податливістю паяного з'єднання зі свинцево-вісмутового або безсвинцевого припою SAC305 (модуль Юнга припою `E_solder ≈ 50 ГПа`, товщина галтелі `t_solder ≈ 50...100 мкм`). Податливість припою діє як механічний дільник сили з коефіцієнтом передачі `K_joint ≈ 0.01...0.03`.

Фактична передана амплітуда сили становить `F_eff ≈ F_x_ideal · K_joint ≈ 1.0...2.0 Н`, що створює локальний змінний момент:

```
M_b = 1.0 Н · (0.95 × 10⁻³ м) ≈ 0.95 × 10⁻³ Н·м  (0.95 мН·м)
```

Вплив сплаву припою також має суттєве значення: низькотемпературні безсвинцеві припої зі вмістом вісмуту (Sn42Bi58, модуль Юнга `E ≈ 40 ГПа`, але підвищена крихкість) мають вищий рівень концентрації напружень біля контактних площадок, тоді як традиційні свинцеві сплави (Sn63Pb37, `E ≈ 30 ГПа`) забезпечують кращу релаксацію зсувних зусиль завдяки вищій пластичності.

Якщо конденсатор змонтовано під кутом `θ` до головної осі плати `X`, вектор моменту розкладається на дві ортогональні компоненти:

```
M_bx = M_b · cos²(θ)
M_by = M_b · sin²(θ)
M_bxy = M_b · sin(θ) · cos(θ)
```

При куті монтажу `θ = 45°` крутильна складова `M_bxy` частково розсіює енергію в зсувні моди текстоліту, знижуючи збудження основних згинальних мод на 3–5 дБ.

## Згинальні коливання друкованої плати

Друкована плата моделюється як тонка пружна пластина з характеристиками матеріалу FR4 за теорією Кірхгофа — Лява (*Kirchhoff-Love plate theory*). Динамічний поперечний прогин серединної поверхні `w(x, y, t)` описується неоднорідним диференціальним рівнянням четвертого порядку:

```
D · ∇⁴w(x, y, t) + m_pcb · (∂²w / ∂t²) + c_damp · (∂w / ∂t) = P_ext(x, y, t)
```

де:
- `∇⁴ = (∂⁴/∂x⁴) + 2·(∂⁴/∂x²∂y²) + (∂⁴/∂y⁴)` — бігармонічний диференціальний оператор у декартових координатах;
- `m_pcb = ρ_pcb · t_pcb` — поверхнева густина плати (кг/м²); для склотекстоліту FR4 густиною `ρ_pcb = 1850 кг/м³` та товщиною `t_pcb = 1.6 мм`: `m_pcb = 2.96 кг/м²`;
- `c_damp` — коефіцієнт внутрішнього в'язкого демпфування матеріалу;
- `P_ext(x, y, t)` — розподілене динамічне навантаження від пари згинальних моментів;
- `D` — циліндрична згинальна жорсткість пластини:

```
D = E_pcb · t_pcb³ / [12 · (1 - ν_pcb²)]
```

Для типового склотекстоліту FR4 (`E_pcb ≈ 22 ГПа = 22 × 10⁹ Па`, `ν_pcb ≈ 0.14`):

```
D = (22 × 10⁹) · (1.6 × 10⁻³)³ / [12 · (1 - 0.14²)]
D = (22 × 10⁹) · (4.096 × 10⁻⁹) / [12 · 0.9804]
D = 90.11 / 11.765 ≈ 7.66 Н·м
```

### Просторові функції мод та модальна участь

Динамічний прогин серединної поверхні пластини `w(x, y, t)` можна представити у вигляді розкладу за власними функціями коливань `ϕ_mn(x, y)`:

```
w(x, y, t) = ∑ ∑ W_mn(t) · ϕ_mn(x, y)
ϕ_mn(x, y) = sin(m · π · x / L_x) · sin(n · π · y / L_y)
```

Для точкового згинального моменту `M_b`, прикладеного в координатах конденсатора `(x₀, y₀)`, узагальнена модальна сила `F_modal_mn` визначається градієнтом модальної форми:

```
F_modal_mn = M_b · [∂ϕ_mn(x, y) / ∂x]|_(x₀, y₀) = M_b · (m · π / L_x) · cos(m · π · x₀ / L_x) · sin(n · π · y₀ / L_y)
```

Цей аналітичний зв'язок пояснює важливу практичну закономірність: якщо конденсатор розташовано в пучності зміщень моди (де `cos(m · π · x₀ / L_x) = 0`), похідна дорівнює нулю, і даний конденсатор взагалі не збуджує відповідну резонансну моду плати.

### Граничні умови та спектр власних частот

Залежно від способу кріплення плати в корпусі пристрою спектр власних резонансних частот описується узагальненою формулою Релея — Рітца:

```
f_(m,n) = (λ_mn² / (2 · π)) · √[D / (m_pcb · L_x⁴)]
```

де безрозмірний коефіцієнт частоти `λ_mn²` залежить від типу закріплення чотирьох країв пластини:

| Тип закріплення плати | Позначення | Коефіцієнт базової моди λ₁₁² | Відносна частота f₁₁ / f₁₁_ssss |
| :--- | :--- | :--- | :--- |
| **Шарнірне опертя по периметру** | SSSS | `π² · [1 + (L_x / L_y)²]` | 1.00 (базовий рівень) |
| **Жорстке затиснення по периметру** | CCCC | `22.37 · √[1 + 0.605·(L_x/L_y)² + (L_x/L_y)⁴]` | 1.95–2.20 |
| **Два краї затиснуті, два вільні** | CCFF | `3.52...22.0` (сильна анізотропія) | 0.40–1.40 |
| **Вільні краї по периметру** | FFFF | `13.49` (мода скручування) | 0.60–0.85 |
| **Кріплення на 4 кутових стійках** | Corner Screws | `π² · [0.72 + 0.72·(L_x/L_y)²]` | 0.70–0.85 |

Для плати типових габаритів `L_x = 0.12 м` (120 мм) та `L_y = 0.08 м` (80 мм) за шарнірного закріплення:

```
√[D / m_pcb] = √[7.66 / 2.96] = √[2.588] ≈ 1.609 м²/с

f_(1,1) = (π / 2) · 1.609 · [(1 / 0.12)² + (1 / 0.08)²]
f_(1,1) = 2.527 · [69.44 + 156.25] = 2.527 · 225.69 ≈ 570 Гц

f_(2,1) = 2.527 · [(2 / 0.12)² + (1 / 0.08)²] = 2.527 · [277.78 + 156.25] ≈ 1097 Гц
f_(1,2) = 2.527 · [(1 / 0.12)² + (2 / 0.08)²] = 2.527 · [69.44 + 625.00] ≈ 1755 Гц
f_(2,2) = 2.527 · [(2 / 0.12)² + (2 / 0.08)²] = 2.527 · [277.78 + 625.00] ≈ 2281 Гц
f_(3,2) = 2.527 · [(3 / 0.12)² + (2 / 0.08)²] = 2.527 · [625.00 + 625.00] ≈ 3159 Гц
f_(1,3) = 2.527 · [(1 / 0.12)² + (3 / 0.08)²] = 2.527 · [69.44 + 1406.25] ≈ 3730 Гц
```

Усі базові моди лежать у діапазоні 500–4000 Гц — саме там, де чутливість людського слуху досягає абсолютного піку.

### Резонансне підсилення амплітуди коливань

Якщо частота електричних пульсацій `f_ripple` наближається до однієї з власних мод `f_(m,n)`, амплітуда коливань плати підсилюється відповідно до механічної добротності `Q`:

```
w_pk(f) = w_static · Q / √[(1 - (f / f₀)²)² + (f / (Q · f₀))²]
```

Для матеріалу FR4 типовий коефіцієнт механічних втрат становить `η ≈ 0.02...0.05`, що відповідає механічній добротності `Q = 1 / η ≈ 20...50`. На точній резонансній частоті амплітуда зміщення поверхні плати зростає у 20–50 разів (на 26–34 дБ) порівняно з квазістатичним відгуком.

Середньоквадратична швидкість вібрації поверхні плати `v_rms`:

```
v_rms = (ω / √2) · w_pk = (2 · π · f / √2) · w_pk ≈ 4.44 · f · w_pk
```

За амплітуди резонансного прогину `w_pk = 0.45 мкм` на частоті `f = 3.5 кГц`:

```
v_rms = 4.44 · 3500 Гц · (0.45 × 10⁻⁶ м) ≈ 0.0070 м/с  (7.0 мм/с)
```

## Акустичне випромінювання у повітря

Акустична потужність `W_ac`, що випромінюється вібруючою пластиною площею `A_pcb = L_x · L_y` в навколишнє повітря, розраховується через питомий акустичний опір повітря `Z₀ = ρ₀ · c₀` та фактор ефективності випромінювання `σ_rad`:

```
W_ac = σ_rad(f) · ρ₀ · c₀ · A_pcb · <v_rms²>
```

де:
- `ρ₀ = 1.204 кг/м³` — густина повітря за температури 20 °C;
- `c₀ = 343 м/с` — швидкість звуку в повітрі;
- `Z₀ = ρ₀ · c₀ ≈ 413 Па·с/м` — характеристичний імпеданс повітря;
- `A_pcb = 0.12 м × 0.08 м = 0.0096 м²` (96 см²);
- `σ_rad(f)` — коефіцієнт ефективності акустичного випромінювання.

### Критична частота збігу (Coincidence Frequency)

Ефективність випромінювання `σ_rad` залежить від співвідношення між фазовою швидкістю згинальної хвилі в платі `c_b` та швидкістю звуку в повітрі `c₀`. Критична частота `f_crit`, на якій `c_b = c₀`, дорівнює:

```
f_crit = [c₀² / (2 · π)] · √[m_pcb / D]
```

Для розглянутої плати FR4 товщиною 1.6 мм:

```
f_crit = [343² / (2 · π)] · √[2.96 / 7.66]
f_crit = [117649 / 6.283] · √[0.3864]
f_crit = 18725 · 0.6216 ≈ 11640 Гц  (11.64 кГц)
```

Поведінка фактора випромінювання ділиться на три частотні інтервали:
- При `f < f_crit` (докритична область): довжина згинальної хвилі в текстоліті `λ_b` менша за довжину акустичної хвилі в повітрі `λ_air`. Відбувається взаємна компенсація фаз сусідніх антифазних зон вібрації. Випромінювання формується лише на краях плати, і коефіцієнт пропорційний відношенню частот: `σ_rad ≈ (f / f_crit) · (P_perim · c₀ / (4 · π² · A_pcb · f_crit)) ≈ 0.05...0.30`.
- При `f ≈ f_crit` (зона збігу): виникає просторовий хвильовий резонанс, коефіцієнт випромінювання сягає піку: `σ_rad ≥ 1.0...2.0`.
- При `f > f_crit` (надкритична область): згинальні хвилі швидші за звук, кожен елемент плати випромінює як плоский поршень без гідродинамічного перетікання: `σ_rad ≈ 1.0`.

Крім активного випромінювання звуку, реактивна частина імпедансу випромінювання повітряного шару `X_rad` створює ефект приєднаної маси повітря `Δm_air ≈ ρ₀ / k_sound`. Для тонких легких плат цей ефект викликає додаткове невелике зміщення власних резонансних частот униз на 1–3%.

На резонансній моді `f = 3.5 кГц` ефективність випромінювання становить `σ_rad ≈ 0.18`.

Розрахуємо випромінену акустичну потужність:

```
W_ac = 0.18 · (413 Па·с/м) · (0.0096 м²) · (0.0070 м/с)²
W_ac = 0.18 · 413 · 0.0096 · (4.9 × 10⁻⁵)
W_ac = 3.50 × 10⁻⁵ Вт = 35.0 мкВт
```

## Розрахунок рівня звукового тиску (SPL)

Звуковий тиск `p_rms` на відстані `r` від плати у вільному півпросторі (модель півсферичного випромінювання на столі, коефіцієнт спрямованості `Q_dir = 2`) розраховується з енергетичного співвідношення:

```
I_ac = W_ac · Q_dir / (4 · π · r²)
p_rms = √[I_ac · ρ₀ · c₀]
```

На стандартній вимірювальній відстані `r = 0.5 м`:

```
I_ac = (3.50 × 10⁻⁵ Вт) · 2 / [4 · π · (0.5 м)²]
I_ac = 7.0 × 10⁻⁵ / 3.1416 ≈ 2.228 × 10⁻⁵ Вт/м²

p_rms = √[(2.228 × 10⁻⁵) · 413] = √[9.20 × 10⁻³] ≈ 0.0959 Па  (95.9 мПа)
```

Рівень звукового тиску `L_p` у децибелах відносно стандартного порогу чутності `p_ref = 20 мкПа = 20 × 10⁻⁶ Па`:

```
L_p = 20 · log₁₀(p_rms / p_ref)
L_p = 20 · log₁₀(0.0959 / (20 × 10⁻⁶))
L_p = 20 · log₁₀(4795)
L_p = 20 · 3.6808 ≈ 73.6 дБ (SPL)
```

### Зважування за кривою A (dBA)

Чутливість людського вуха залежить від частоти і стандартизується кривою корекції A (IEC 61672-1). Аналітичний вираз коефіцієнта зважування `R_A(f)` має вигляд:

```
R_A(f) = [12194² · f⁴] / [ (f² + 20.6²) · √((f² + 107.7²) · (f² + 737.9²)) · (f² + 12194²) ]
ΔA(f) = 20 · log₁₀(R_A(f)) + 2.00 дБ
```

Поправка `ΔA(f)` на частоті 3.5 кГц становить приблизно `+1.2 дБ`:

```
L_pA = L_p + ΔA(f) = 73.6 + 1.2 = 74.8 дБА
```

Рівень 74.8 дБА на відстані півметра відповідає гучності відкритої розмови на підвищених тонах або дзвінку будильника — це надзвичайно гучний і нестерпний тональний свист, спричинений пульсацією напруги амплітудою всього 1.0 В на крихітному конденсаторі розміром 3.2 × 1.6 мм.

## Енергетичний баланс та електромеханічний ККД

Зіставимо механічну роботу, виконану п'єзоефектом, та випромінену акустичну енергію:

1. **Механічна потужність збудження:**
```
P_mech = 0.5 · F_eff · v_joint = 0.5 · (1.0 Н) · (0.007 м/с) = 3.5 мВт
```

2. **Випромінена акустична потужність:**
```
W_ac = 35.0 мкВт = 0.035 мВт
```

3. **Акустичний коефіцієнт корисної дії:**
```
η_acoustic = W_ac / P_mech = 0.035 / 3.5 = 0.010 = 1.0 %
```

Майже 99% механічної енергії поглинається внутрішнім в'язкопружним тертям у матеріалі склотекстоліту FR4 та паяних з'єднаннях (`P_diss ≈ 3.465 мВт`), перетворюючись на тепло. Проте навіть 1% акустичного ККД створює звуковий тиск понад 74 дБА, що переконливо демонструє виняткову чутливість людського слуху до тональних коливань у кілогерцовому діапазоні.

## Зведена інженерна формула чутності

Об'єднуючи електромеханічні, пружні та акустичні ланки, отримуємо підсумкову аналітичну залежність рівня звукового тиску:

```
L_p ∝ 20 · log₁₀ [ d_eff · (V_pk / d_layer) · L_cap · Q_pcb · σ_rad(f) / (t_pcb² · r) ]
```

З аналізу формули безпосередньо випливають чотири найбільш дієві інженерні важелі зменшення шуму:
1. **Зменшення `d_eff` до нуля** — перехід на діелектрик C0G або танталовий полімер;
2. **Зменшення `V_pk`** — фільтрація пульсацій та збільшення частоти комутації поза межі звукового діапазону (> 25 кГц);
3. **Зменшення передачі сили на плату (`L_cap / t_pcb²`)** — застосування конденсаторів із металевими рамками (Metal Cap) або збільшення товщини плати `t_pcb` (оскільки жорсткість зростає пропорційно кубу товщини `t_pcb³`);
4. **Зниження добротності `Q_pcb`** — фрезерування розвантажувальних пазів навколо контактних майданчиків або монтаж демпфуючих матеріалів.
