# Математичний апарат нелінійної індуктивності та енергії насиченого поля

Розрахунок динамічних процесів у колах із феромагнітними осердями вимагає строгого розмежування понять статичної та диференціальної індуктивності. При переході осердя в область насичення зв'язок між струмом і потокозчепленням втрачає лінійність, через що миттєва реакція дроселя на зміну струму визначається виключно локальною похідною кривої намагнічування.

---

### Виведення диференціальної індуктивності з рівнянь поля

Розглянемо замкнений магнітопровід із довжиною середньої магнітної лінії `l_e`, площею поперечного перерізу `A_e` та кількістю витків обмотки `N`.

За [законом повного струму Ампера](book:electronics/inductor-coil) циркуляція вектора напруженості магнітного поля `H` вздовж замкненого контуру довжиною `l_e` дорівнює повному струму, охопленому цим контуром:

```
∮ H dl = N · i
```

Для однорідного осердя зі сталою площею перерізу напруженість поля `H` рівномірно розподілена вздовж довжини `l_e`:

```
H · l_e = N · i
H = (N · i) / l_e
```

Диференціюючи напруженість поля за струмом обмотки, отримуємо сталий коефіцієнт зв'язку:

```
dH/di = N / l_e
```

Повний магнітний потік `Φ` крізь площу перерізу осердя та повне потокозчеплення `Ψ` котушки виражаються через магнітну індукцію `B`:

```
Φ = B · A_e
Ψ = N · Φ = N · B · A_e
```

За [законом електромагнітної індукції Фарадея](book:electronics/faraday-law), напруга `u_L(t)` на затискачах ідеальної індуктивності дорівнює швидкості зміни потокозчеплення в часі:

```
u_L(t) = dΨ/dt
```

Застосовуючи правило диференціювання складеної функції `Ψ(i(t))`, розкриваємо похідну:

```
u_L(t) = (dΨ/di) · (di/dt)
```

Коефіцієнт пропорційності між наведеною напругою `u_L(t)` та швидкістю зміни струму `di/dt` за фундаментальним означенням є **диференціальною індуктивністю** `L_diff(i)`:

```
L_diff(i) = dΨ/di
```

Розкриємо похідну `dΨ/di`, підставивши геометричні та польові параметри:

```
L_diff(i)
= d(N · A_e · B)/di                       [підстановка Ψ = N · A_e · B]
= N · A_e · (dB/di)                       [винесення геометричних констант N та A_e]
= N · A_e · (dB/dH) · (dH/di)             [ланцюгове правило диференціювання складеної функції]
= N · A_e · (dB/dH) · (N / l_e)           [підстановка похідної dH/di = N / l_e]
= (N² · A_e / l_e) · (dB/dH)              [групування геометричних множників]
```

Оскільки диференціальна магнітна проникність матеріалу `μ_diff` визначається як локальний нахил кривої намагнічування `μ_diff = dB/dH = μ_0 · μ_r_diff`, отримуємо головне рівняння нелінійної індуктивності:

```
L_diff(i) = (N² · A_e / l_e) · μ_0 · μ_r_diff(i)
```

Для порівняння, **статична індуктивність** `L_stat(i)` визначається як абсолютне відношення повного потокозчеплення до миттєвого струму:

```
L_stat(i) = Ψ(i) / i = (N · A_e · B(H)) / (H · l_e / N) = (N² · A_e / l_e) · (B(H) / H)
L_stat(i) = (N² · A_e / l_e) · μ_0 · μ_r_stat(i)
```

У лінійній області ненасиченого осердя, де `B = μ · H`, диференціальна та статична проникності тотожно збігаються (`μ_diff = μ_stat = μ`), відповідно `L_diff = L_stat = L_0`.

При переході за коліно насичення крива `B(H)` виходить на пологе плато. Похідна `dB/dH` падає до абсолютної проникності вакууму `μ_0`, тобто відносна диференціальна проникність `μ_r_diff → 1`. У цій зоні диференціальна індуктивність котушки спадає до залишкового рівня повітряного контуру:

```
L_air = (N² · A_e / l_e) · μ_0
```

Оскільки для силових феритів початкова проникність становить `μ_r = 2000...5000`, диференціальна індуктивність у стані глибокого насичення колапсує рівно в `μ_r` разів (тобто на 99.95–99.98%).

### Математичний розрахунок дроселя з дискретним зазором

У силових дроселях для розширення лінійного діапазону струму в магнітопроводі створюють повітряний зазор довжиною `l_g`. Розрахуємо нелінійну функцію `L_diff(i)` для системи із зазором.

Повний контур довжиною `l_e` складається з двох послідовних ділянок: феромагнітного осердя довжиною `l_c = l_e - l_g ≈ l_e` з нелінійною залежністю `B_c(H_c)` та немагнітного зазору довжиною `l_g` з лінійною проникністю `μ_0`.

За законом повного струму:

```
N · i = H_c · l_c + H_g · l_g
```

За умовою неперервності магнітного потоку (ігноруючи крайове випинання потоку на першому кроці, тобто `A_c = A_g = A_e`):

```
Φ = B_c · A_e = B_g · A_e  ==>  B_c = B_g = B
```

Оскільки для повітряного зазору `B = μ_0 · H_g`, виражаємо напруженість поля в зазорі:

```
H_g = B / μ_0
```

Підставимо `H_g` у рівняння закону повного струму:

```
N · i = H_c(B) · l_c + (B / μ_0) · l_g
```

Диференціюємо обидві частини рівняння за струмом `i`:

```
N = l_c · (dH_c/dB) · (dB/di) + (l_g / μ_0) · (dB/di)
N = (dB/di) · [ l_c / μ_diff_c(B) + l_g / μ_0 ]
```

Звідси знаходимо похідну магнітної індукції за струмом:

```
dB/di = N / [ (l_c / μ_diff_c(B)) + (l_g / μ_0) ]
```

Помноживши на `N · A_e`, отримуємо точний аналітичний вираз для диференціальної індуктивності котушки з зазором:

```
L_diff(i) = (N² · A_e) / [ (l_c / μ_diff_c(B)) + (l_g / μ_0) ]
```

Позначивши магнітний опір осердя як `R_m_c = l_c / (μ_diff_c · A_e)` та магнітний опір зазору як `R_m_g = l_g / (μ_0 · A_e)`:

```
L_diff(i) = N² / [ R_m_c(B(i)) + R_m_g ]
```

#### Аналіз граничних станів:

1. **Ненасичений стан (`B << B_sat`):**
   Проникність фериту дуже висока (`μ_diff_c ≈ 2000 · μ_0`), тому `R_m_c << R_m_g`. Знаменник повністю визначається зазором:
   ```
   L_0 ≈ N² / R_m_g = (N² · A_e · μ_0) / l_g
   ```
   Індуктивність залишається строго сталою і не залежить від нелінійностей фериту.

2. **Стан насичення фериту (`B -> B_sat`):**
   Диференціальна проникність фериту спадає до `μ_diff_c -> μ_0`. Магнітний опір фериту зростає до `R_m_c = l_c / (μ_0 · A_e)`. Тоді сумарний магнітний опір дорівнює:
   ```
   R_m_total = (l_c + l_g) / (μ_0 · A_e) = l_e / (μ_0 · A_e)
   L_diff_sat = (N² · A_e · μ_0) / l_e = L_air
   ```
   Індуктивність падає від значення `(N² · A_e · μ_0) / l_g` до `(N² · A_e · μ_0) / l_e`. Відношення спаду індуктивності точно дорівнює відношенню геометричної довжини осердя до довжини повітряного зазору:
   ```
   L_0 / L_diff_sat = l_e / l_g
   ```
   Для типового осердя з `l_e = 50 мм` та зазором `l_g = 0.5 мм` індуктивність при насиченні фериту падає рівно в `50 / 0.5 = 100` разів.

### Геометричний радіальний ефект насичення в тороїдах

У реальних магнітопроводах напруженість магнітного поля не є ідеально однорідною по перерізу. Розглянемо тороїдальне осердя з внутрішнім радіусом `r_in`, зовнішнім радіусом `r_out` та висотою `h`.

За законом повного струму, напруженість поля на довільному радіусі `r` (`r_in ≤ r ≤ r_out`):

```
H(r) = (N · i) / (2π · r)
```

На внутрішньому радіусі `r_in` напруженість поля максимальна `H_max = (N · i) / (2π · r_in)`, а на зовнішньому радіусі `r_out` — мінімальна `H_min = (N · i) / (2π · r_out)`.

Співвідношення напруженостей поля:

```
H_max / H_min = r_out / r_in
```

Для стандартного тороїда типорозміру T25/15/10 відношення радіусів становить `r_out / r_in = 25 / 15 ≈ 1.67`.

Це означає, що коли внутрішня стінка тороїда вже досягла критичної напруженості коліна насичення і перейшла в стан глибокого насичення (`dB/dH -> μ_0`), зовнішня периферія все ще працює в лінійній області з високою проникністю `μ_r`.

Повний магнітний потік тороїда знаходиться інтегруванням по радіусу:

```
Φ(i) = h · ∫_(r_in)^(r_out) B(H(r, i)) dr
```

Диференціальна індуктивність тороїда з урахуванням радіальної неоднорідності:

```
L_diff(i) = N · (dΦ/di) = N · h · ∫_(r_in)^(r_out) (dB/dH)|_(r) · (dH/di) dr
L_diff(i) = (N² · h / 2π) · ∫_(r_in)^(r_out) μ_diff( (N·i)/(2π·r) ) · (dr / r)
```

Цей радіальний розподіл поля пояснює, чому навіть у монолітних феритах перехід до жорсткого насичення не є абсолютно сингулярним математичним зламом, а має малу зону плавного закруглення шириною 10–15% за струмом.

### Аналітичні моделі нелінійної кривої B(H)

Для моделювання в SPICE-симуляторах та чисельних розрахунків використовують математичні апроксимації кривої початкового намагнічування `B(H)`.

#### 1. Модель Фрьоліха-Кеннеллі (Fröhlich-Kennelly)

Раціональна функція з двома фізичними параметрами:

```
B(H) = H / (a + b · |H|)
```

де `1/a = μ_init` — початкова проникність у слабкому полі, а `1/b = B_sat` — асимптотична індукція насичення при `H -> ∞`.

Диференціальна проникність у моделі Фрьоліха-Кеннеллі:

```
μ_diff(H) = dB/dH = a / (a + b · |H|)² = μ_init / (1 + (μ_init / B_sat) · |H|)²
```

Ця модель забезпечує плавний монотонний спад без стрибків і відмінно описує порошкові матеріали Sendust, MPP та Iron Powder.

#### 2. Тангенціальна гіперболічна модель (Hyperbolic Tangent Model)

Застосовується для матеріалів із вираженим коліном насичення (MnZn ферити, аморфні сплави):

```
B(H) = B_sat · tanh(H / H_k) + μ_0 · H
```

де `H_k = B_sat / (μ_init - μ_0)` — напруженість поля коліна насичення.

Похідна для диференціальної проникності:

```
μ_diff(H) = dB/dH = (B_sat / H_k) · (1 - tanh²(H / H_k)) + μ_0 = (μ_init - μ_0) · sech²(H / H_k) + μ_0
```

Коли поле значно перевищує поріг коліна (`H >> H_k`), функція `sech²(x) = 1 / ch²(x)` експоненційно згасає до нуля, залишаючи лише фундаментальний вакуумний рівень `μ_diff = μ_0`.

#### 3. Модель фізичного гістерезису Джайлса-Атертона (Jiles-Atherton)

Модель Джайлса-Атертона базується на фізиці закріплення доменних стінок на дефектах кристалу (*pinning effect*). Повна намагніченість матеріалу `M` (де `B = μ_0 · (H + M)`) розкладається на безгістерезисну (ідеальну) намагніченість `M_an` та незворотну компоненту `M_irr`:

Безгістерезисна намагніченість описується модифікованою функцією Ланжевена:

```
M_an(H_e) = M_s · [ coth(H_e / a) - a / H_e ]
```

де `M_s` — намагніченість насичення, `a` — параметр міждоменної взаємодії, а `H_e = H + α · M` — ефективне локальне магнітне поле всередині зразка (із врахуванням молекулярного поля Вейсса з коефіцієнтом `α`).

Диференціальне рівняння незворотної намагніченості:

```
dM_irr / dH_e = (M_an - M_irr) / (k · δ)
```

де `k` — коефіцієнт закріплення доменних стінок на дефектах (визначає ширину петлі гістерезису та коерцитивну силу `H_c`), а `δ = sign(dH/dt)` фіксує напрямок руху по петлі (+1 при зростанні поля, -1 при спаданні).

Повна диференціальна намагніченість із врахуванням пружної оборотної складової з коефіцієнтом `c`:

```
dM/dH = ( (1 - c) · (dM_irr/dH_e) + c · (dM_an/dH_e) ) / ( 1 - α · c · (dM_an/dH_e) - α · (1 - c) · (dM_irr/dH_e) )
```

Звідси диференціальна індуктивність дроселя під час повного циклу перемагнічування:

```
L_diff(i) = (N² · A_e / l_e) · μ_0 · ( 1 + dM/dH )
```

Модель Джайлса-Атертона дозволяє точно моделювати несиметричні цикли часткового перемагнічування (*minor loops*) при накладанні імпульсних пульсацій на постійний струм зміщення `I_dc`.

### Реалізація нелінійної індуктивності у SPICE-симуляторах

У програмах схемотехнічного моделювання (LTspice, NGspice, PSpice) нелінійна котушка індуктивності не може задаватися простим параметром `L = f(I)`, оскільки це призводить до порушення закону збереження енергії при обчисленні похідних.

Правильне моделювання в SPICE реалізується через рівняння зв'язку потокозчеплення `Flux(x)` та кероване джерело напруги:

```
* LTspice синтаксис нелінійної індуктивності через функцію потоку:
L_DUT N_pos N_neg Flux = N * A_e * B_sat * tanh( (N * x / l_e) / H_k )
```

де змінна `x` позначає струм крізь індуктивність `i(L_DUT)`. Під час обчислення перехідного процесу (Transient Analysis) симулятор автоматично бере похідну за часом:

```
v(t) = d(Flux(i(t))) / dt = (dFlux / di) · (di / dt) = L_diff(i) · (di / dt)
```

Це гарантує строге збереження магнітної енергії `W_m` та відсутність штучної чисельної генерації енергії на кроках інтегрування. Для забезпечення стійкої збіжності розрахунку в точках надкрутого зламу індуктивності в опціях симулятора задають параметри контролю кроку часу `.options reltol=0.001 abstol=1e-7 trtol=1.0 chgtol=1e-15`, що виключає появу помилок типу «Timestep too small» під час швидкого насичення осердя.

### Числовий приклад розрахунку профілів L_diff(i)

Порівняємо числові значення диференціальної та статичної індуктивностей для тороїдального дроселя без зазору на базі фериту MnZn та порошкового матеріалу Sendust.

**Параметри магнітопроводу:**
- Кількість витків: `N = 20`;
- Площа перерізу: `A_e = 60 мм² = 60 · 10⁻⁶ м²`;
- Довжина магнітної лінії: `l_e = 50 мм = 0.050 м`;
- Матеріал 1 (Ферит MnZn): `B_sat = 0.40 Тл`, `μ_r_init = 2500` (модель tanh);
- Матеріал 2 (Sendust): `B_sat = 1.05 Тл`, `μ_r_init = 125` (модель Фрьоліха-Кеннеллі).

Початкова індуктивність для фериту:

```
L_0_ferrite = (20² × 60 · 10⁻⁶ × 4π · 10⁻⁷ × 2500) / 0.050 ≈ 1.508 · 10⁻³ Гн = 1.51 мГн
H_k = B_sat / (μ_0 · (μ_r_init - 1)) = 0.40 / (4π · 10⁻⁷ × 2499) ≈ 127.3 А/м
```

Для струмів `i = 0.1 А`, `0.5 А`, `1.0 А` напруженість поля становить `H = (20 · i) / 0.050 = 400 · i` (А/м):
- При `i = 0.1 А` (`H = 40 А/м`): `H / H_k = 40 / 127.3 ≈ 0.314`.
  `sech²(0.314) = (1 / ch(0.314))² ≈ (1 / 1.050)² ≈ 0.907`.
  `L_diff(0.1 А) = 1.51 мГн × 0.907 ≈ 1.37 мГн` (збережено 90.7% індуктивності).
- При `i = 0.5 А` (`H = 200 А/м`): `H / H_k = 200 / 127.3 ≈ 1.571`.
  `sech²(1.571) = (1 / ch(1.571))² ≈ (1 / 2.516)² ≈ 0.158`.
  `L_diff(0.5 А) = 1.51 мГн × 0.158 ≈ 0.239 мГн` (індуктивність впала на 84.2%).
- При `i = 1.0 А` (`H = 400 А/м`): `H / H_k = 400 / 127.3 ≈ 3.142`.
  `sech²(3.142) = (1 / ch(3.142))² ≈ (1 / 11.57)² ≈ 0.0075`.
  `L_diff(1.0 А) ≈ 1.51 мГн × 0.0075 ≈ 0.011 мГн = 11 мкГн` (колапс у 137 разів).

Початкова індуктивність для Sendust:

```
L_0_sendust = (20² × 60 · 10⁻⁶ × 4π · 10⁻⁷ × 125) / 0.050 ≈ 75.4 мкГн
```

Розрахунок за моделлю Фрьоліха-Кеннеллі:

```
μ_diff_sendust(H) = μ_init / ( 1 + (μ_0 · μ_r_init · H / B_sat) )²
(μ_0 · μ_r_init / B_sat) = (4π · 10⁻⁷ × 125) / 1.05 ≈ 1.496 · 10⁻⁴ м/А
```

- При `i = 1.0 А` (`H = 400 А/м`): знаменник `(1 + 1.496 · 10⁻⁴ × 400)² = (1 + 0.0598)² ≈ 1.123`.
  `L_diff(1.0 А) = 75.4 мкГн / 1.123 ≈ 67.1 мкГн` (збережено 89.0% індуктивності).
- При `i = 5.0 А` (`H = 2000 А/м`): знаменник `(1 + 1.496 · 10⁻⁴ × 2000)² = (1 + 0.299)² ≈ 1.688`.
  `L_diff(5.0 А) = 75.4 мкГн / 1.688 ≈ 44.7 мкГн` (збережено 59.3% індуктивності).

Цей розрахунок наочно підтверджує: на струмі 1.0 А феритовий тороїд колапсував майже до нуля, тоді як порошковий тороїд Sendust зберіг 89% своєї функціональної індуктивності.

### Динамічний імпеданс малого сигналу під постійним зміщенням

В імпульсних стабілізаторах частотний аналіз стійкості петлі зворотного зв'язку (побудова діаграм Боде) вимагає знання імпедансу дроселя на малих коливаннях навколо робочої точки постійного струму `I_dc`.

Розкладемо струм і потокозчеплення на постійну та малу змінну гармонічну складові:

```
i(t) = I_dc + i_ac · e^(j·ω·t),    де i_ac << I_dc
Ψ(t) = Ψ(I_dc) + (dΨ/di)|_(I_dc) · i_ac · e^(j·ω·t)
```

Напруга малого змінного сигналу на затискачах котушки:

```
u_ac(t) = d(Ψ_ac)/dt + i_ac(t) · R_ac = j·ω · L_diff(I_dc) · i_ac(t) + i_ac(t) · R_ac(ω, I_dc)
```

Комплексний опір дроселя для малого сигналу:

```
Z_small_signal(j·ω, I_dc) = R_ac(ω, I_dc) + j · ω · L_diff(I_dc)
```

де `R_ac(ω, I_dc)` — динамічний активний опір, що враховує скін-ефект у міді та опір гістерезисних втрат осердя `R_core(I_dc)`.

Цей результат є критичним для проєктування кіл компенсації стабілізатора (Type II / Type III): коли струм навантаження зростає і дросель підходить до зони насичення, індуктивність `L_diff(I_dc)` знижується, що зміщує резонансну частоту вихідного LC-фільтра `f_0 = 1 / (2π · √(L_diff · C_out))` у бік вищих частот. Якщо запас фази петлі регулювання не розрахований на цю зміну індуктивності, перетворювач самозбуджується і втрачає стійкість.

### Енергія магнітного поля та коенергія

В ідеальній лінійній котушці енергія магнітного поля виражається класичною формулою `W = (L · I²) / 2`. У нелінійному дроселі ця формула стає принципово хибною і завищує реальну енергію в рази.

Миттєва електрична потужність, що передається в котушку під час зміни струму:

```
p(t) = u_L(t) · i(t) = (dΨ/dt) · i(t)
```

Повна енергія `W_m`, накопичена в магнітному полі при зростанні потокозчеплення від 0 до `Ψ_1`:

```
W_m = ∫₀ᵀ p(t) dt = ∫₀ᵀ i(t) · (dΨ/dt) dt = ∫₀^(Ψ₁) i · dΨ
```

Виражаючи потокозчеплення та струм через індукцію та напруженість поля (`Ψ = N · A_e · B`, `i = H · l_e / N`):

```
W_m = ∫₀^(B₁) (H · l_e / N) · d(N · A_e · B) = (A_e · l_e) · ∫₀^(B₁) H · dB
```

Добуток `V_core = A_e · l_e` дорівнює фізичному об'єму магнітопроводу. Величина `w_m = ∫ H · dB` є **об'ємною густиною енергії магнітного поля** (Дж/м³). На площині `(H, B)` ця енергія чисельно дорівнює площі фігури між кривою намагнічування та **вертикальною віссю B**.

Додаткова енергетична функція стану — **магнітна коенергія** *(magnetic co-energy)* `W_m'`:

```
W_m' = ∫₀^(I₁) Ψ · di = (A_e · l_e) · ∫₀^(H₁) B · dH
```

Коенергія дорівнює площі фігури між кривою намагнічування та **горизонтальною віссю H**.

Сума магнітної енергії та коенергії утворює повну площу прямокутника в координатах `(H, B)`:

```
W_m + W_m' = Ψ₁ · I₁ = V_core · (B₁ · H₁)
```

У лінійному матеріалі без насичення крива `B(H)` є прямою лінією, яка ділить прямокутник рівно навпіл, тому `W_m = W_m' = (L · I²) / 2`.

У зоні насичення крива `B(H)` стає практично горизонтальною (`dB ≈ 0`). Приріст енергії магнітного поля при подальшому зростанні струму припиняється:

```
ΔW_m = V_core · ∫_(B_sat)^(B_sat + ΔB) H · dB ≈ 0
```

Уся додаткова енергія від джерела живлення перетворюється на теплові втрати на омічному опорі обмотки та ключа:

```
P_loss(t) = i²(t) · R_total
```

#### Де насправді запасається енергія в дроселі з зазором

Обчислимо розподіл густини енергії між феритом і повітряним зазором. Густина енергії в немагнітному зазорі:

```
w_gap = ∫₀^(B_max) H_g dB = ∫₀^(B_max) (B / μ_0) dB = B_max² / (2 · μ_0)
```

Густина енергії в ненасиченому фериті:

```
w_core = ∫₀^(B_max) H_c dB = ∫₀^(B_max) (B / (μ_0 · μ_r)) dB = B_max² / (2 · μ_0 · μ_r)
```

Співвідношення густин енергії:

```
w_gap / w_core = μ_r
```

Оскільки для силових феритів `μ_r = 2000...3000`, **густина накопиченої енергії в повітряному зазорі у 2000–3000 разів вища, ніж у самому фериті**.

Повна енергія в зазорі об'ємом `V_gap = A_e · l_g`:

```
W_gap = w_gap · V_gap = (B_max² / (2 · μ_0)) · A_e · l_g
```

Повна енергія у фериті об'ємом `V_core = A_e · l_e`:

```
W_core = w_core · V_core = (B_max² / (2 · μ_0 · μ_r)) · A_e · l_e
```

Відношення повних енергій:

```
W_gap / W_core = μ_r · (l_g / l_e)
```

Для типового дроселя з `l_e = 50 мм`, зазором `l_g = 0.5 мм` та `μ_r = 2500`:

```
W_gap / W_core = 2500 × (0.5 / 50) = 2500 × 0.01 = 25
```

Це доводить фундаментальний висновок магнітостатики: **понад 96% усієї магнітної енергії силового дроселя фізично запасається у мікроскопічному об'ємі повітряного зазору**, тоді як феритове осердя виконує лише роль магнітного провідника з низьким опором для фокусування та доставки магнітного потоку до зазору.

### Розрахунок механічної сили притягання половинок осердя

Магнітне поле в повітряному зазорі створює потужні механічні сили притягання між протилежними торцями сердечника. За принципом віртуальних переміщень, механічна сила `F_mag` дорівнює похідній магнітної коенергії за довжиною зазору `l_g` при фіксованому струмі:

```
F_mag = ∂W_m' / ∂l_g = ∂ [ (B² / (2 · μ_0)) · A_e · l_g ] / ∂l_g = (B² · A_e) / (2 · μ_0)
```

Для силового дроселя на осерді E42/21/20 (`A_e = 240 мм² = 240 · 10⁻⁶ м²`) при піковій індукції `B = 0.35 Тл`:

```
F_mag = (0.35² × 240 · 10⁻⁶) / (2 × 4π · 10⁻⁷) = (0.1225 × 240 · 10⁻⁶) / (2.5133 · 10⁻⁶) ≈ 11.7 Н
```

Сила понад 1.1 кгс діє на половинки осердя з подвоєною частотою комутації ШІМ. Якщо половинки не склеєні жорстким компаундом або не стягнуті спеціальною пружинною кліпсою, змінна сила викликає мікропереміщення торців, що призводить до руйнування діелектричної прокладки зазору та генерації сильного акустичного шуму.
