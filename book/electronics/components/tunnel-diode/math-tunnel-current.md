# 🧮 Квантовий розрахунок тунельного струму та граничних частот

Математичний апарат тунельного діода поєднує квантовомеханічне наближення Вентцеля — Крамерса — Бріллюена (ВКБ) для розрахунку прозорості бар'єра забороненої зони, інтегральне моделювання тунельного струму Есакі за тривимірною густиною станів Фермі — Дірака, теорію фононно-стимульованого непрямого тунелювання, нелінійну теорію автоколивань Ван дер Поля, розрахунок надлишкового струму дефектів, температурний аналіз та оцінку малосигнального імпедансу для визначення коефіцієнтів підсилення, граничних частот і шумових параметрів.

### 1. Рівень Фермі у вироджених напівпровідниках та ступінь занурення

У нелегованих напівпровідниках розподіл електронів описується класичною статистикою Максвелла — Больцмана. Проте коли концентрація донорів `N_D` або акцепторів `N_A` перевищує ефективну густину станів у зоні провідності `N_c` чи валентній зоні `N_v` (`N_c, N_v ≈ 10¹⁸–10¹⁹ см⁻³`), хвильові функції сусідніх домішкових центрів перекриваються, і система переходить у квантовий вироджений стан.

Положення рівня Фермі `E_Fn` відносно дна зони провідності `E_c` розраховується через інтеграл Фермі — Дірака напівцілого порядку `F_{1/2}(η)`:

```
n = N_c · (2 / √π) · ∫ [ √x / (1 + exp(x − η)) ] dx = N_c · F_{1/2}(η)   [концентрація електронів у зоні провідності]
```

де `η = (E_Fn − E_c) / (k_B · T_K)` — безрозмірний ступінь виродження.

За температури абсолютного нуля або сильного виродження (`η ≫ 1`), коли квантовий розмив малий, концентрація електронів виражається прямо через радіус сфери Фермі у хвильовому просторі:

```
k_F = (3 · π² · n)^(1/3)                                    [радіус сфери Фермі у просторі квазіімпульсів]
E_Fn − E_c = (ℏ² · k_F²) / (2 · m_e*) = (ℏ² / (2 · m_e*)) · (3 · π² · n)^(2/3)  [енергія Фермі виродженого електронного газу]
```

Аналогічно для виродженої p-області глибина занурення рівня Фермі `E_Fp` нижче стелі валентної зони `E_v` становить:

```
E_v − E_Fp = (ℏ² / (2 · m_h*)) · (3 · π² · p)^(2/3)         [енергія Фермі діркового газу у валентній зоні]
```

**Числовий розрахунок глибини занурення для n-Ge:**
Розглянемо германій n-типу з концентрацією донорів фосфору `n = 5 · 10¹⁹ см⁻³` та ефективною масою густини станів електрона `m_e* ≈ 0.22 · m_0` (`m_0 = 9.10938 · 10⁻³¹ кг`):

```
3 · π² · n = 3 · 9.8696 · (5 · 10²⁵ м⁻³) ≈ 1.480 · 10²⁷ м⁻³
(3 · π² · n)^(2/3) = (1.480 · 10²⁷)^(2/3) ≈ 1.299 · 10¹⁸ м⁻²
E_Fn − E_c = ((1.05457 · 10⁻³⁴)² / (2 · 0.22 · 9.10938 · 10⁻³¹)) · 1.299 · 10¹⁸
= (1.1121 · 10⁻⁶⁸ / 4.0081 · 10⁻³¹) · 1.299 · 10¹⁸
≈ 2.7746 · 10⁻³⁸ · 1.299 · 10¹⁸ = 3.604 · 10⁻²⁰ Дж
≈ 3.604 · 10⁻²⁰ / (1.60218 · 10⁻¹⁹) ≈ 0.225 еВ (225 меВ)
```

Таким чином, рівень Фермі занурений углиб зони провідності на `225 меВ`, що забезпечує гігантську концентрацію вільних станів для тунелювання.

### 2. Розрахунок прозорості потенціального бар'єра у наближенні ВКБ

Електрон, що рухається крізь кристалічну ґратку виродженого напівпровідника під дією сильного електричного поля, описується одновимірним стаціонарним рівнянням Шредінгера. Потенціальний бар'єр у збідненому шарі формується забороненою зоною матеріалу шириною `E_g`.

У наближенні квазікласичного проходження бар'єра (метод ВКБ) коефіцієнт прозорості `T` для частинки з енергією `E` визначається просторовим інтегралом від модуля хвильового вектора підбар'єрного загасання `k(x)` уздовж координати `x` між класичними точками повороту `x₁` та `x₂`:

```
k(x) = √(2 · m* · (U(x) − E)) / ℏ       [означення хвильового вектора в підбар'єрній області]
```

де `m* = (m_e* · m_h*) / (m_e* + m_h*)` — приведена ефективна маса тунелюючого електрона, `ℏ` — зведена стала Планка (`ℏ = 1.05457 · 10⁻³⁴ Дж·с`), `U(x)` — профіль потенціальної енергії в p-n переході.

Припускаючи однорідне електричне поле у збідненому шарі завтовшки `W` із напруженістю `E_field = (V_bi − V) / W` (де `V_bi` — контактна різниця потенціалів, `V` — прикладена зовнішня напруга), бар'єр забороненої зони має лінійний профіль `U(x) = E_g · (1 − x / W)`. Інтегрування хвильового вектора за товщиною бар'єра від `0` до `W` дає точний вираз для загасання амплітуди хвильової функції:

```
ln(T)
= −2 · ∫ k(x) dx                        [інтеграл загасання фази у наближенні ВКБ]
= −2 · ∫ √(2 · m* · E_g · (1 − x/W)) / ℏ dx  [підстановка лінійного профілю бар'єра]
= −(4 / 3) · (√(2 · m*) / (q · ℏ · E_field)) · E_g^(3/2)  [результат інтегрування по товщині бар'єра]
```

Підносячи експоненту до отриманого степеня, отримуємо формулу Кейна — Есакі для ймовірності прямого міжзонного квантового тунелювання:

```
T(E) = exp( − (4 · √(2 · m*) · E_g^(3/2)) / (3 · q · ℏ · E_field) )
```

У непараболічній моделі Кейна (врахування взаємодії зони провідності та валентної зони) приведений коефіцієнт набуває додаткового множника `(π / 4)`:

```
T_Kane = exp( − (π · √(m*) · E_g^(3/2)) / (2 · √2 · q · ℏ · E_field) )
```

Звідси випливає фундаментальна фізична залежність: прозорість бар'єра експоненційно чутлива до ширини забороненої зони в степені три других `E_g^(3/2)` та кореня з приведеної ефективної маси носіїв `√(m*)`. У прямозонних напівпровідниках із легкою масою електрона (`GaAs`, `GaSb`, `InAs`) коефіцієнт прозорості виявляється на три-чотири порядки вищим, ніж у непрямозонному кремнію.

### 3. Пряме та фононно-стимульоване непряме тунелювання

У прямозонних напівпровідниках (як `GaAs` або `InSb`) мінімум зони провідності та максимум валентної зони розташовані в центрі зони Бріллюена при квазіімпульсі `k = 0` (точка `Γ`). Тунелювання відбувається прямо у хвильовому просторі без зміни квазіімпульсу (`Δk = 0`).

У непрямозонних напівпровідниках (як кремній `Si`, де мінімум зони провідності лежить уздовж осі `[100]`, або германій `Ge`, де мінімуми лежать у точках `L` `[111]`) для здійснення міжзонного переходу електрон мусить змінити квазіімпульс на величину вектора `q_ph = k_min(c) − k_max(v)`.

За квантовою теорією збурень другого порядку такий перехід відбувається з одночасним поглинанням або випромінюванням фонона ґратки з енергією `ℏ·ω_ph`. Коефіцієнт непрямої прозорості записується як:

```
T_indirect = |M_ep|² / (E_inter − E)² · exp( − (4 · √(2 · m_eff) · (E_g ∓ ℏ·ω_ph)^(3/2)) / (3 · q · ℏ · E_field) )
```

де `M_ep` — матричний елемент електрон-фононної взаємодії, `E_inter` — енергія проміжного віртуального стану. Через необхідність тричастинкової взаємодії (електрон + дірка + фонон) імовірність непрямого тунелювання в кремнії приблизно у 100 разів менша, ніж у прямозонних сполуках, що пояснює малі пікові струми та низькі значення `PVCR` у кремнієвих діодах.

### 4. Інтеграл тунельного струму Есакі та густина станів

Густина прямого тунельного струму `J_tu` розраховується як інтеграл за енергією `E` від добутку густини квантових станів зони провідності n-боку `ρ_c(E)`, валентної зони p-боку `ρ_v(E)`, імовірності їх заповнення носіями за розподілом Фермі — Дірака `f_c(E)`, `f_v(E)` та коефіцієнта квантової прозорості `T(E)`:

```
J_tu = (q · m*) / (2 · π² · ℏ³) · ∫ [f_c(E) − f_v(E)] · T(E) · ρ_c(E) · ρ_v(E) dE
```

де функції Фермі — Дірака для носіїв в n- та p-областях визначають імовірність термодинамічного заповнення рівнів:

```
f_c(E) = 1 / ( 1 + exp((E − E_Fn) / (k_B · T_K)) )   [імовірність заповнення станів у зоні провідності]
f_v(E) = 1 / ( 1 + exp((E − E_Fp) / (k_B · T_K)) )   [імовірність заповнення станів у валентній зоні]
```

де `k_B` — стала Больцмана (`1.38065 · 10⁻²³ Дж/К`), `T_K` — абсолютна температура в Кельвінах, `E_Fn` та `E_Fp` — квазірівні Фермі в n- та p-областях. Різниця положень квазірівнів Фермі суворо визначається прикладеною напругою зміщення:

```
E_Fn − E_Fp = q · V
```

Для параболічних тривимірних зон густина станів зростає за законом квадратного кореня від енергії: `ρ_c(E) ∝ √(E − E_c)` та `ρ_v(E) ∝ √(E_v − E)`. Інтегрування за енергетичним вікном перекриття дозволених станів між `E_c(n)` та `E_v(p)` дає інтегральну залежність струму від напруги.

За низьких температур, коли тепловий розмив Фермі-сходинки малий (`k_B · T_K ≪ q · V_P`), інтеграл Есакі з високою точністю апроксимується компактною аналітичною формулою:

```
I_tu(V) = I_P · (V / V_P) · exp( 1 − V / V_P )
```

де `I_P` — піковий тунельний струм, `V_P` — пікова напруга максимального узгодження енергетичних зон.

### 5. Знаходження екстремумів та диференційної провідності

Знайдемо першу похідну тунельного струму за прикладеною напругою `dI/dV`, що визначає диференційну провідність `G_d(V)` діода:

```
dI_tu / dV
= d/dV [ I_P · (V / V_P) · exp(1 − V / V_P) ]     [диференціювання добутку функцій]
= (I_P / V_P) · exp(1 − V / V_P) + I_P · (V / V_P) · (−1 / V_P) · exp(1 − V / V_P)  [правило похідної добутку]
= (I_P / V_P) · (1 − V / V_P) · exp(1 − V / V_P)  [винесення спільного множника]
```

Аналіз знака похідної розкриває три характерні області вольт-амперної характеристики:
1. **Область наростання (`0 < V < V_P`):** Множник `(1 − V / V_P) > 0`, тому похідна додатна `dI/dV > 0`. Прямий тунельний струм монотонно зростає від нуля до піку завдяки розширенню енергетичного перекриття зон.
2. **Точка максимуму (`V = V_P`):** Множник `(1 − V / V_P) = 0`, що дає нульову похідну `dI/dV = 0`. Досягається абсолютний піковий струм `I_P`.
3. **Область спаду / ВДО (`V_P < V < V_V`):** Множник `(1 − V / V_P) < 0`, тому похідна стає строго від'ємною `dI/dV < 0`. Збільшення напруги спричиняє спад струму через розходження зон.

Знайдемо точку максимальної крутизни від'ємного опору (точку перегину ВАХ, де абсолютне значення від'ємної провідності досягає максимуму). Для цього прирівняємо до нуля другу похідну тунельного струму:

```
d²I_tu / dV²
= d/dV [ (I_P / V_P) · (1 − V / V_P) · exp(1 − V / V_P) ]   [диференціювання першої похідної]
= (I_P / V_P²) · [ −1 − (1 − V / V_P) ] · exp(1 − V / V_P)  [правило Лейбніца для добутку]
= (I_P / V_P²) · (V / V_P − 2) · exp(1 − V / V_P)          [зведення подібних доданків]
```

Прирівнюючи другу похідну до нуля, знаходимо напругу точки перегину ВАХ:

```
d²I_tu / dV² = 0  ⇒  V_infl = 2 · V_P
```

Підставляючи напругу `V = 2 · V_P` у вираз для першої похідної, отримуємо точну величину максимальної від'ємної диференційної провідності `G_N_max` та мінімального диференційного опору `-R_N`:

```
G_N_max = |dI/dV|_(V = 2·V_P) = (I_P / V_P) · e⁻¹ ≈ 0.368 · (I_P / V_P)
R_N_min = 1 / G_N_max = (e · V_P) / I_P ≈ 2.718 · (V_P / I_P)
```

**Числовий приклад розрахунку `-R_N`:**
Для типового надвисокочастотного германієвого тунельного діода з паспортними параметрами `I_P = 5 мА` та `V_P = 65 мВ`:
```
R_N = 2.718 · (0.065 В / 0.005 А) = 2.718 · 13 Ом ≈ 35.33 Ом
```

### 6. Коефіцієнт кривини ВАХ та квадратичне детектування

У режимі прямого детектування надвисокочастотних сигналів малої амплітуди струм діода розкладається в ряд Тейлора навколо напруги зміщення `V_0`:

```
I(V_0 + v_rf(t)) = I(V_0) + (dI/dV) · v_rf(t) + (1/2) · (d²I/dV²) · v_rf²(t) + ...
```

Для гармонічного сигналу `v_rf(t) = V_m · cos(ω·t)` усереднений за періодом постійний струм детектування `ΔI_dc` визначається виключно другою похідною:

```
ΔI_dc = (1 / 4) · V_m² · (d²I / dV²)                       [постійна складова продетектованого струму]
```

Головним показником чутливості детектора є **коефіцієнт кривини ВАХ `γ`** (curvance coefficient):

```
γ = (d²I / dV²) / (dI / dV)                                [коефіцієнт відносної кривини вольт-амперної характеристики]
```

Для звичайного випрямного діода Шоклі з ідеальним експоненційним законом коефіцієнт кривини обмежений величиною `q / (k_B · T) ≈ 38.6 В⁻¹` за кімнатної температури. Для тунельних та обернених діодів завдяки різкому квантовому перекриттю зон коефіцієнт `γ` при нульовому зміщенні досягає `40–60 В⁻¹`, що робить їх найчутливішими детекторами слабких міліметрових сигналів без потреби у зовнішньому джерелі живлення.

### 7. Моделювання надлишкового та дифузійного струмів

Повний струм приладу в усьому діапазоні напруг описується тричленною моделлю:

```
I_total(V) = I_tu(V) + I_ex(V) + I_diff(V)
```

1. **Надлишковий струм дефектів `I_ex(V)`:** Описується моделлю Чайновета (Chynoweth) для ступінчастого тунелювання крізь глибокі рівні домішок у забороненій зоні:
   ```
   I_ex(V) = I_V · exp( A_x · (V − V_V) )
   ```
   де `A_x ≈ (4/3) · √(m_x) · E_g^(1/2) / (ℏ · E_field)` — коефіцієнт експоненціальної крутизни струму западини.
2. **Дифузійний струм інжекції `I_diff(V)`:** Класичний струм термоемісії носіїв над бар'єром Шоклі:
   ```
   I_diff(V) = I_0 · [ exp( (q · V) / (n · k_B · T_K) ) − 1 ]
   ```

### 8. Виведення малосигнального імпедансу та граничних частот

Малосигнальна еквівалентна схема на ділянці ВДО містить внутрішній перехід (паралельне з'єднання `-R_N` та `C_j`), послідовний опір омічних втрат кристала і контактів `R_s` та паразитна індуктивність виводів `L_s`.

Знайдемо комплексний вхідний імпеданс схеми `Z(ω)` як функцію кругової частоти `ω = 2 · π · f`:

```
Z(ω)
= R_s + i · ω · L_s + ( (−R_N) || (1 / (i · ω · C_j)) )   [послідовне з'єднання втрат та паралельного контуру переходу]
= R_s + i · ω · L_s + (−R_N) / (1 − i · ω · R_N · C_j)    [формула еквівалентного опору паралельних віток]
= R_s + i · ω · L_s + (−R_N · (1 + i · ω · R_N · C_j)) / (1 + ω² · R_N² · C_j²)  [множення чисельника й знаменника на спряжене число]
= [ R_s − R_N / (1 + ω² · R_N² · C_j²) ] + i · [ ω · L_s − (ω · R_N² · C_j) / (1 + ω² · R_N² · C_j²) ]  [розділення на дійсну та уявну частини]
```

Дійсна (активна) частина імпедансу `Re[Z(ω)]` визначає здатність приладу компенсувати втрати енергії в колі:

```
Re[Z(ω)] = R_s − R_N / (1 + ω² · R_N² · C_j²)
```

Для виникнення незатухаючих автоколивань або підсилення зовнішнього сигналу необхідно, щоб дійсна частина імпедансу була строго від'ємною: `Re[Z(ω)] < 0`.

Прирівнюючи `Re[Z(ω)] = 0`, знаходимо **максимальну резистивну граничну частоту генерації `f_max`**:

```
R_s = R_N / (1 + ω_max² · R_N² · C_j²)                      [умова компенсації активних втрат діода]
1 + ω_max² · R_N² · C_j² = R_N / R_s                        [вираження знаменника через відношення опорів]
ω_max² · R_N² · C_j² = (R_N / R_s) − 1                      [віднімання одиниці від обох частин]
ω_max = (1 / (R_N · C_j)) · √( (R_N / R_s) − 1 )            [добування квадратного кореня]
f_max = (1 / (2 · π · R_N · C_j)) · √( (R_N / R_s) − 1 )    [перехід від кругової частоти до лінійної]
```

З отриманої формули випливають два фундаментальні інженерні критерії:
1. **Критерій фізичної працездатності:** Генерація можлива лише за умови `R_N > R_s`. Якщо послідовний опір втрат перевищує диференційний опір переходу, активна частина імпедансу діода залишається додатною на всіх частотах.
2. **Фактор добротності:** Гранична частота прямо пропорційна кореню зі співвідношення опорів `√(R_N / R_s)` і обернено пропорційна внутрішній часовій константі бар'єра `τ = R_N · C_j`.

**Власна резонансна частота `f_0`** відповідає компенсації реактивного опору індуктивності ємнісним опором переходу (`Im[Z(ω)] = 0`):

```
ω_0 · L_s = (ω_0 · R_N² · C_j) / (1 + ω_0² · R_N² · C_j²)   [рівність реактивних складових індуктивності та ємності]
L_s · (1 + ω_0² · R_N² · C_j²) = R_N² · C_j                 [скорочення на ω_0 та множення на знаменник]
1 + ω_0² · R_N² · C_j² = (R_N² · C_j) / L_s                 [вираження квадратичного члена]
ω_0² = 1 / (L_s · C_j) − 1 / (R_N² · C_j²)                  [розв'язок відносно квадрата частоти]
f_0 = (1 / (2 · π)) · √( 1 / (L_s · C_j) − 1 / (R_N² · C_j²) )  [власна резонансна частота коливань]
```

Для стійкої та передбачуваної роботи НВЧ-генератора конструкція повинна задовольняти умову `f_0 < f_max`. Якщо власна резонансна частота виявляється вищою за граничну резистивну частоту, коливання загасають через теплові втрати на опорі `R_s` до досягнення резонансу.

### 9. Коефіцієнт відбиття та підсилення НВЧ сигналу

У мікрохвильових трактах тунельний діод використовується як регенеративний підсилювач із циркулятором. Якщо діод із комплексним імпедансом `Z_d(ω) = −R_eff(ω) + i · X_d(ω)` підключений до лінії передачі з хвильовим опором `Z_0` (типово 50 Ом), комплексний коефіцієнт відбиття `Γ(ω)` має модуль більший за одиницю:

```
Γ(ω) = (Z_d(ω) − Z_0) / (Z_d(ω) + Z_0)                      [формула коефіцієнта відбиття хвилі]
= (−R_eff + i · X_d − Z_0) / (−R_eff + i · X_d + Z_0)       [підстановка від'ємного активного опору]
= −( (Z_0 + R_eff) − i · X_d ) / ( (Z_0 − R_eff) + i · X_d )  [винесення мінуса в чисельнику]
```

Модуль коефіцієнта підсилення за потужністю `G_p = |Γ|²` дорівнює:

```
|Γ|² = ( (Z_0 + R_eff)² + X_d² ) / ( (Z_0 − R_eff)² + X_d² )   [відношення квадратів модулів чисельника й знаменника]
```

Оскільки `(Z_0 + R_eff)² > (Z_0 − R_eff)²` для будь-якого додатного значення `R_eff > 0`, модуль коефіцієнта відбиття строго більший за одиницю: `|Γ| > 1`. Відбита від діода електромагнітна хвиля повертається у лінію передачі з більшою амплітудою, ніж падаюча хвиля. Застосування феритового триплечового циркулятора дозволяє розділити падаючий і підсилений відбитий сигнали, формуючи повноцінний однонаправлений підсилювач НВЧ потужності.

### 10. Нелінійна динаміка Ван дер Поля та амплітуда коливань

Для розрахунку амплітуди автоколивань апроксимуємо нелінійну вольт-амперну характеристику тунельного діода кубічним поліномом відносно напруги зміщення `V_0` в центрі ділянки ВДО:

```
i(v) = −a₁ · v + a₃ · v³                                   [кубічна апроксимація ВАХ біля точки перегину]
```

де `v = V − V_0`, `a₁ = |dI/dV|_(V_0) = 1 / R_N`, а `a₃ = (1/6) · |d³I/dV³|`.

Диференціальне рівняння для паралельного LC-контуру з діодом набуває форми класичного рівняння Ван дер Поля:

```
C_j · (d²v / dt²) + ( (G_L − a₁) + 3 · a₃ · v² ) · (dv / dt) + (1 / L) · v = 0  [нелінійне рівняння автогенератора]
```

де `G_L = 1 / R_L` — провідність навантаження контуру.

Метод повільно змінних амплітуд (метод Крилова — Боголюбова) дає точний розв'язок для стаціонарної амплітуди напруги коливань `V_osc`:

```
V_osc = 2 · √( (a₁ − G_L) / (3 · a₃) ) = 2 · √( (1/R_N − 1/R_L) / (3 · a₃) )  [стаціонарна амплітуда гармонічних автоколивань]
```

З формули видно, що автоколивання виникають м'яко при виконанні умови самозбудження `a₁ > G_L` (`R_L > R_N`), а їхня амплітуда плавно зростає зі збільшенням перевищення негативної провідності над навантаженням.

### 11. Температурний коефіцієнт пікового струму

Повна температурна похідна пікового струму `dI_P / dT` складається з двох протилежних фізичних внесків:
1. Звуження забороненої зони кристала з температурою за формулою Варшні (`dE_g / dT < 0`), що збільшує прозорість бар'єра `T(E)`.
2. Теплове розмиття функцій розподілу Фермі — Дірака біля рівнів Фермі, що зменшує густину зайнятих електронами станів, здатних брати участь у вузькому вікні тунелювання.

Аналітичний вираз для відносного температурного коефіцієнта має вигляд:

```
(1 / I_P) · (d I_P / dT) = (∂ ln T_tu / ∂ E_g) · (d E_g / dT) − (π² · k_B² · T) / (6 · ζ_n · ζ_p)
```

де `ζ_n = E_Fn − E_c` та `ζ_p = E_v − E_Fp` — параметри виродження. У германії переважає другий член (розмиття Фермі), що дає негативний температурний коефіцієнт близько `−0.1%/°C`. В арсеніді галію через меншу діелектричну проникність та крутіший хід `dE_g/dT` домінує перший член, забезпечуючи слабке додатне зростання пікового струму при кімнатних температурах.

### 12. Аналіз стійкості характеристичного рівняння в s-площині

Для дослідження стійкості кола з тунельним діодом, підключеним до навантаження `R_L`, розглянемо характеристичне рівняння замкненого контуру в операторній формі Лапласа (комплексна змінна `s = σ + i·ω`):

```
Z_total(s) = (R_L + R_s) + s · L_s + (−R_N) / (1 − s · R_N · C_j) = 0
```

Зводячи рівняння до спільного знаменника, отримуємо характеристичний поліном другого порядку:

```
s² · (L_s · R_N · C_j) + s · ( (R_L + R_s) · R_N · C_j − L_s ) + ( R_N − (R_L + R_s) ) = 0
```

За критерієм Рауса — Гурвіца стійкість системи визначається знаками коефіцієнтів квадратного тричлена:
1. **Стійкий вузол (аперіодичне затухання):** Якщо `(R_L + R_s) > R_N` та `(R_L + R_s) · R_N · C_j > L_s`, корені лежать у лівій півплощині `s`. Система має один або два стійкі стани (режим тригера або підсилювача).
2. **Нестійкість та автоколивання:** Якщо `(R_L + R_s) < R_N` або `L_s > (R_L + R_s) · R_N · C_j`, корені зміщуються у праву півплощину `s` (`σ > 0`), викликаючи експоненційне наростання амплітуди коливань до обмеження нелінійною ВАХ (режим автогенератора).

### 13. Практичний розрахунок НВЧ-генератора на GaAs

Розглянемо числовий приклад проектування мікрохвильового генератора на арсенід-галієвому тунельному діоді з такими паспортними параметрами:
- Піковий струм: `I_P = 10 мА` (`0.010 А`);
- Пікова напруга: `V_P = 120 мВ` (`0.120 В`);
- Опір втрат: `R_s = 1.0 Ом`;
- Бар'єрна ємність переходу: `C_j = 1.2 пФ` (`1.2 · 10⁻¹² Ф`);
- Паразитна індуктивність виводів: `L_s = 0.15 нГн` (`0.15 · 10⁻⁹ Гн`).

**Крок 1: Розрахунок мінімального диференційного опору `-R_N`:**
```
R_N = 2.718 · (V_P / I_P) = 2.718 · (0.120 / 0.010) = 2.718 · 12.0 Ом ≈ 32.62 Ом
```

**Крок 2: Розрахунок часової константи переходу `τ`:**
```
τ = R_N · C_j = 32.62 · 1.2 · 10⁻¹² с ≈ 39.14 · 10⁻¹² с = 39.14 пс
```

**Крок 3: Розрахунок граничної частоти генерації `f_max`:**
```
R_N / R_s = 32.62 / 1.0 = 32.62
√( (R_N / R_s) − 1 ) = √(32.62 − 1) = √31.62 ≈ 5.623
f_max = (1 / (2 · π · 39.14 · 10⁻¹²)) · 5.623 = (4.066 · 10⁹) · 5.623 ≈ 22.86 ГГц
```

**Крок 4: Розрахунок власної резонансної частоти `f_0`:**
```
1 / (L_s · C_j) = 1 / (0.15 · 10⁻⁹ · 1.2 · 10⁻¹²) = 1 / (0.18 · 10⁻²¹) ≈ 5.556 · 10²¹ рад²/с²
1 / (R_N² · C_j²) = 1 / (39.14 · 10⁻¹²)² = 1 / (1.532 · 10⁻²⁰) ≈ 0.065 · 10²¹ рад²/с²
ω_0 = √( 5.556 · 10²¹ − 0.065 · 10²¹ ) = √(5.491 · 10²¹) ≈ 7.410 · 10¹⁰ рад/с
f_0 = (7.410 · 10¹⁰) / (2 · π) ≈ 11.79 ГГц
```

**Крок 5: Розрахунок потужності генерації першої гармоніки:**
Максимальна вихідна високочастотна потужність `P_out`, яку тунельний діод здатний віддати у согласоване навантаження, оцінюється за формулою Кіма — Бранда:

```
P_out ≈ (3 / 16) · (V_V − V_P) · (I_P − I_V)                 [максимальна потужність першої гармоніки ВДО]
```

Для розглянутого GaAs діода з `V_V = 0.500 В` та `I_V = 0.001 А`:
```
P_out ≈ (3 / 16) · (0.500 − 0.120) · (0.010 − 0.001)
= 0.1875 · 0.380 В · 0.009 А ≈ 0.000641 Вт = 0.641 мВт (−1.93 дБм)
```

Оскільки `f_0 = 11.79 ГГц < f_max = 22.86 ГГц`, діод має значний запас активної від'ємної провідності на резонансній частоті, що гарантує надійне самозбудження та генерацію коливань у діапазоні до 22.8 ГГц з вихідною потужністю близько 0.64 мВт.
