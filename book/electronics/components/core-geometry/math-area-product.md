# 🧮 Розрахунок габаритної потужності та геометрії осердя (Ap і Kg)

Розрахунок моточного вузла в силовій електроніці завжди починається з вибору мінімально достатнього типорозміру магнітного осердя. Якщо взяти осердя із замалим перерізом керна, воно або ввійде в насичення від магнітного потоку, або вимагатиме занадто багато витків тонкого дроту, які згорять від джоулевого тепла у вікні намотки. Якщо ж узяти надмірно велике осердя, виріб вийде важким, громіздким і дорогим. Нижче наведено суворе математичне виведення факторів Area Product (`A_p`) та коефіцієнта геометрії (`K_g`), розрахунок накопичувальних дроселів із зазором, врахування крайового потоку розсіювання, математичну модель високочастотних втрат у міді за методом Доуелла, специфіку розрахунку планарних трансформаторів на друкованих платах, термодинамічний баланс втрат у міді й магнетику, а також вичерпні покрокові числові розрахунки трансформатора й силового індуктора.

### Виведення рівняння Area Product (Ap = Aw · Ae) для трансформаторів

Показник `A_p` (добуток площ, *Area Product*) пов'язує електричну прохідну потужність перетворювача з двома фундаментальними геометричними розмірами осердя: площею поперечного перерізу центрального керна `A_e` та площею вікна намотки `A_w`.

Виведемо цей зв'язок крок за кроком із базових законів електродинаміки.

#### Крок 1. Закон електромагнітної індукції Фарадея
Змінна напруга `v(t)`, прикладена до первинної обмотки з кількістю витків `N_p`, збуджує в керні змінний магнітний потік `Φ(t) = B(t) · A_e`. Для прямокутної або синусоїдальної форми напруги середньоквадратичне значення напруги `V_in` пов'язане з розмахом магнітної індукції `ΔB` та частотою `f`:

```
V_in = K_f · f · N_p · ΔB · A_e      [закон індукції Фарадея]
```

Тут `K_f` — коефіцієнт форми хвилі:
- `K_f = 4.0` для прямокутної симетричної напруги (двотактні, мостові та напівмостові перетворювачі);
- `K_f = 4.44` для чистої синусоїди (`4 · (π / (2 · √2)) ≈ 4.44`);
- `ΔB = 2 · B_pk` для двотактного симетричного перемагнічування (де `B_pk` — пікова індукція).

Підставивши розмах `ΔB = 2 · B_pk` для прямокутного симетричного сигналу, отримуємо:

```
V_in
= 4.0 · f · N_p · (2 · B_pk) · A_e    [підстановка прямокутної форми та розмаху індукції]
= 8 · f · N_p · B_pk · A_e            [арифметичне спрощення]
```

Звідси виразимо добуток кількості витків на площу перерізу:

```
N_p · A_e = V_in / (4 · K_f_half · f · B_pk)      [де K_f_half = 1 для напівперіоду прямокутника]
```

#### Крок 2. Обмеження вікна обмотки за струмом
Струм первинної обмотки `I_p` вимагає провідника з площею перерізу `A_wire = I_p / J`, де `J` — допустима густина струму в міді (типово `3...6 А/мм²` або `3·10⁶...6·10⁶ А/м²` для природного конвекційного охолодження).

Якщо трансформатор має первинну та вторинну обмотки однакової потужності, вікно намотки `A_w` ділиться порівну між первинною та вторинною міддю. Із загальної площі вікна `A_w` лише частка `k_u` займається чистою міддю (фактор заповнення міддю, *window utilization factor*, типово `k_u = 0.25...0.40` з урахуванням каркаса, міжшарової ізоляції та круглої форми дроту):

```
S_cu_total = k_u · A_w      [повна площа чистої міді у вікні]
```

Оскільки первинна обмотка займає половину доступної міді:

```
N_p · A_wire = 0.5 · k_u · A_w      [розподіл міді 50% на первинну обмотку]
```

Підставивши `A_wire = I_p / J`:

```
N_p · (I_p / J)
= 0.5 · k_u · A_w                   [рівняння площі первинної міді]

N_p · I_p
= 0.5 · k_u · J · A_w               [вираження ампер-витків первинної обмотки]
```

#### Крок 3. Перемноження рівнянь і отримання Area Product
Перемножимо вираз для напруги `V_in` та вираз для ампер-витків `N_p · I_p`:

```
V_in · (N_p · I_p)
= (4 · f · N_p · (2 · B_pk) · A_e) · (0.5 · k_u · J · A_w) / N_p   [підстановка виразів]

P_in
= V_in · I_p                                                        [визначення вхідної потужності]
= 4 · f · B_pk · A_e · k_u · J · A_w                                [скорочення кількості витків N_p]
= 4 · f · B_pk · J · k_u · (A_w · A_e)                              [групування геометричних параметрів]
```

Звідси отримуємо шукану формулу для розрахункового `A_p`:

```
A_p = A_w · A_e
= P_t / (K_topo · f · B_pk · J · k_u)      [рівняння розрахункового Area Product]
```

Тут:
- `P_t` — сумарна уявна габаритна потужність усіх обмоток (`P_t = P_in + P_out ≈ 2 · P_out` для двотактних схем);
- `K_topo` — топологічний коефіцієнт (для симетричного моста/напівмоста `K_topo = 4.0`, для зворотньоходового Flyback `K_topo ≈ 1.4...2.0`).

Розмірність `A_p`: якщо всі величини підставити в системі SI (`P_t` у Вт, `f` у Гц, `B_pk` у Тл, `J` у А/м², `A_w` та `A_e` у м²), результат `A_p` отримаємо в `м⁴`. У довідниках параметри наводять у `см⁴` (`1 м⁴ = 10⁸ см⁴ = 10¹² мм⁴`).

### Виведення Area Product для накопичувальних дроселів (Inductor Ap)

Для силових дроселів (Buck, Boost, Flyback) розрахунок відрізняється від трансформатора, оскільки головною функцією осердя є не передача потужності крізь магнітний потік, а **накопичення енергії** в магнітному полі зазору під постійним струмом підмагнічування.

Енергія `W`, яку дросель індуктивністю `L` запасає при піковому струмі `I_pk`:

```
W = 0.5 · L · I_pk²      [магнітна енергія, Джоулі]
```

Зв'язок між індуктивністю, кількістю витків та магнітним потоком:

```
L · I_pk = N · Φ_pk = N · B_pk · A_e      [потокозчеплення]
```

Підставивши цей вираз в енергію:

```
W
= 0.5 · (N · B_pk · A_e) · I_pk           [підстановка потокозчеплення]
= 0.5 · B_pk · A_e · (N · I_pk)           [перегрупування множників]
```

З іншого боку, вся площа вікна `A_w` заповнена однією обмоткою з коефіцієнтом заповнення `k_u`:

```
N · A_wire = k_u · A_w                    [заповнення площі вікна]
N · (I_rms / J) = k_u · A_w               [підстановка площі провідника]
N · I_rms = k_u · J · A_w                 [вираження ампер-витків для постійного струму]
```

Для постійного струму з помірними пульсаціями `I_rms ≈ I_pk`. Підставивши добуток ампер-витків `N · I_pk = k_u · J · A_w` у формулу енергії:

```
W
= 0.5 · B_pk · A_e · (k_u · J · A_w)      [підстановка ампер-витків]
= 0.5 · B_pk · J · k_u · (A_w · A_e)      [виділення Area Product]
```

Звідси отримуємо рівняння Area Product для дроселя:

```
A_p = A_w · A_e
= (2 · W) / (B_pk · J · k_u)              [розрахунковий Area Product дроселя]
= (L · I_pk · I_rms) / (B_pk · J · k_u)   [через індуктивність і струми]
```

### Розрахунок довжини повітряного зазору з урахуванням Fringing Flux

Коли типорозмір осердя з параметрами `A_e` та `l_e` обрано, необхідну індуктивність `L` задають розрахунком довжини повітряного зазору `l_g`.

Загальний магнітний опір кола (релюктанс) складається з опору фериту `R_m_fe` та опору зазору `R_m_gap`:

```
R_m_tot = R_m_fe + R_m_gap
= l_e / (μ_0 · μ_r · A_e) + l_g / (μ_0 · A_e)      [закон Ома для магнітного кола]
```

Оскільки індуктивність `L = N² / R_m_tot`:

```
L = (μ_0 · N² · A_e) / (l_g + l_e / μ_r)
```

Звідси виразимо довжину зазору `l_g`:

```
l_g = (μ_0 · N² · A_e) / L - l_e / μ_r      [точна формула довжини повітряного зазору]
```

Оскільки проникність фериту `μ_r` дуже велика (`2000...5000`), доданок `l_e / μ_r` для зазорів `l_g > 0.1 мм` складає менше 2–5% і часто ним нехтують:

```
l_g ≈ (μ_0 · N² · A_e) / L                  [наближена формула для розрахунку зазору]
```

#### Поправковий фактор спучування (Fringing Factor F)
У реальному зазорі магнітні силові лінії випинаються у вікно намотки, збільшуючи ефективну площу зазору `A_gap > A_e`. Це призводить до того, що фактична індуктивність виявляється більшою за розраховану без урахування спучування.

Коефіцієнт збільшення провідності зазору `F` описується емпіричною формулою МакЛаймана:

```
F = 1 + (l_g / √(A_e)) · ln(2 · G / l_g)      [коефіцієнт крайового потоку розсіювання]
```

Тут `G` — висота вікна каркаса вздовж зазору. Скоригована індуктивність дроселя:

```
L_actual = F · L_ideal = F · (μ_0 · N² · A_e) / l_g
```

Якщо `F > 1.20` (зазор завеликий порівняно з розміром керна), крайовий потік спричинить значний локальний нагрів витків. У такому разі один великий зазор розбивають на кілька дрібних або обирають осердя з більшою площею `A_e`.

### Коефіцієнт геометрії осердя (Kg)

Фактор `A_p` зручний, коли густина струму `J` відома або фіксована. Проте в багатьох прецизійних розрахунках обмеженням є не густина струму, а допустиме падіння напруги на обмотці, виражене через її опір постійному струму `R_dc`, або конкретний ліміт джоулевих втрат `P_cu`.

Опір обмотки з `N` витків дротом перерізом `A_wire` дорівнює:

```
R_dc = ρ_cu · (N · MLT) / A_wire      [де ρ_cu — питомий опір міді, MLT — середня довжина витка]
```

Підставивши вираз для площі дроту через заповнення вікна `A_wire = (k_u · A_w) / (2 · N)`:

```
R_dc
= ρ_cu · (N · MLT) / ((k_u · A_w) / (2 · N))      [підстановка A_wire]
= (2 · ρ_cu · N² · MLT) / (k_u · A_w)             [спрощення дробу]
```

Згадавши закон Фарадея `N = V_in / (K_geom · f · B_pk · A_e)` і підставивши його в опір `R_dc`, виділимо суто геометричні параметри осердя в окремий коефіцієнт:

```
K_g = (A_e² · A_w) / MLT      [коефіцієнт геометрії осердя, розмірність м⁵ або см⁵]
```

Коефіцієнт `K_g` показує, скільки потужності може передати осердя за фіксованого регулювання напруги та втрат у міді. Зверніть увагу: `K_g` обернено пропорційний довжині середнього витка `MLT`. Саме тому осердя з круглим центральним керном (ETD, PQ, RM) мають коефіцієнт `K_g` на 20–35% вищий, ніж осердя класичної прямокутної форми EE того самого об'єму.

### Високочастотні втрати в міді: модель Доуелла та геометрія вікна

На високих частотах опір обмотки значно перевищує опір постійному струму через два ефекти: скін-ефект (витіснення струму до поверхні провідника власним магнітним полем) та ефект близькості (витіснення струму полем сусідніх провідників і шарів обмотки).

Відношення опору змінного струму до опору постійному струму виражається коефіцієнтом `F_r = R_ac / R_dc`. За одновимірною моделлю Доуелла (*Dowell's equation*), для обмотки з кількістю шарів `m` у вікні намотки:

```
F_r = ξ · ((sinh(2ξ) + sin(2ξ)) / (cosh(2ξ) - cos(2ξ)) + (2 · (m² - 1) / 3) · (sinh(ξ) - sin(ξ)) / (cosh(ξ) + cos(ξ)))
```

Тут `ξ` — відносна товщина провідника:

```
ξ = h_eff / δ      [де h_eff — ефективна радіальна товщина шару міді, δ — глибина скін-шару]
```

Глибина скін-шару для міді за температури +70 °C:

```
δ = √(ρ_cu / (π · f · μ_0)) ≈ 66 / √(f)      [в міліметрах, якщо f у Гц]
```

Фактор пористості обмотки (*porosity factor*) `η_p = N_layer · d_wire / b_w` враховує, яку частку ширини вікна `b_w` займають провідники одного шару:

```
h_eff = d_wire · √(π / 4) · √(η_p)      [ефективна товщина шару]
```

З моделі Доуелла випливають два фундаментальні інженерні висновки щодо форми осердя:
1. **Вплив кількості шарів `m`:** ефект близькості масштабується пропорційно `m²`. Тому геометрії з широким і неглибоким вікном намотки (ETD, планарні осердя), де обмотка вкладається в 1–2 шари, мають у 5–10 разів менший коефіцієнт `F_r`, ніж глибокі вузькі вікна старих чашкових осердь із 6–10 шарами;
2. **Оптимальний діаметр дроту:** для багатошарових обмоток (`m > 3`) мінімальні сумарні втрати досягаються не при товстому монолітному дроті, а при діаметрі `d_wire ≈ δ` або переході на літцендрат.

### Особливості розрахунку планарних трансформаторів на друкованій платі (PCB)

У планарних структурах обмотки виконуються доріжками на внутрішніх і зовнішніх шарах багатошарової друкованої плати. Це кардинально змінює фактори заповнення вікна та теплового розрахунку.

1. **Фактор заповнення міддю (`k_u`):** через велику товщину склотекстоліту FR-4 (типово 0.1–0.3 мм між шарами) та захисні зазори за стандартами безпеки (Clearance & Creepage) коефіцієнт заповнення вікна міддю в планарних трансформаторах становить лише `k_u_planar ≈ 0.10...0.20` (проти `0.30...0.40` у дротових каркасах).
2. **Компенсація через тепловідведення:** попри менший `k_u`, планарні трансформатори дозволяють збільшити допустиму густину струму до `J_planar = 8...15 А/мм²` завдяки чудовому прямому контакту мідних доріжок із великою площею поверхні плати та підключенню до зовнішніх алюмінієвих радіаторів.
3. **Паразитна міжелектродна ємність:** велика площа взаємного перекриття плоских шарів первинної та вторинної обмоток створює значну паразитну ємність `C_p_s`. Розрахунок ємності плоского конденсатора:
```
C_p_s = ε_0 · ε_r · A_overlap / d_diel      [де ε_r ≈ 4.5 для FR-4, d_diel — товщина препрега]
```
Для зменшення струмів зміщення синфазного шуму (Common-Mode EMI) чергування шарів (*interleaving*) оптимізують за компромісом між мінімумом індуктивності розсіювання та допустимою ємністю `C_p_s`.

### Термодинамічний оптимум: баланс втрат P_cu ≈ P_fe

Загальні втрати потужності в моточних вузлах складаються з двох компонентів:

```
P_tot = P_cu + P_fe      [сума втрат у міді та втрат у магнітному матеріалі]
```

1. **Втрати в міді (`P_cu`):** зумовлені омічним опором дроту під робочим струмом. Якщо зменшувати кількість витків `N`, опір `R_dc` падає квадратично, і втрати в міді зменшуються:
```
P_cu ∝ N² / A_w ∝ 1 / B_pk²      [бо для меншої кількості витків індукція B_pk має бути більшою]
```

2. **Втрати в осерді (`P_fe`):** описуються рівнянням Штайнмеца для об'єму осердя `V_e = A_e · l_e`:
```
P_fe = C_m · f^α · B_pk^β · V_e      [де для силового MnZn-фериту α ≈ 1.3...1.7, β ≈ 2.2...2.8]
```

Якщо збільшувати пікову індукцію `B_pk`, втрати в міді стрімко спадають (потрібно менше витків), але втрати в осерді зростають як `B_pk^β` (степінь більша за 2). Мінімум сумарних втрат `dP_tot / dB_pk = 0` досягається в точці, де втрати в міді приблизно дорівнюють втратам у фериті:

```
P_cu ≈ (β / 2) · P_fe ≈ P_fe      [умова оптимального використання об'єму за мінімуму нагріву]
```

Теплове розсіювання осердя масштабується з площею його поверхні, яка пропорційна `A_p^0.5`. Тепловий опір від осердя до навколишнього середовища описується напівемпіричним співвідношенням:

```
R_th ≈ 10 · A_p^(-0.25...-0.5)    [°C/Вт при природній конвекції]
```

Звідси знаходиться оптимальна магнітна індукція `B_opt`, за якої трансформатор віддає максимальну потужність за заданого допустимого перегріву `ΔT = P_tot · R_th`.

### Приклад 1. Розрахунок трансформатора SMPS на 300 Вт

Розрахуємо силовий трансформатор для напівмостового перетворювача (Half-Bridge Converter) за такими вихідними даними:

- Вихідна потужність: `P_out = 300 Вт`;
- ККД трансформатора (оцінка): `η = 0.98` → `P_in = 300 / 0.98 = 306 Вт`;
- Частота комутації: `f = 100 кГц` (`100 000 Гц`);
- Вхідна постійна напруга шини: `V_dc = 310 В` (напівміст подає на первинну обмотку амплітуду `V_p = V_dc / 2 = 155 В`);
- Вихідна напруга: `V_out = 24 В` (струм вторинної обмотки `I_out = 12.5 А`);
- Матеріал осердя: силовий MnZn-ферит N87 (TDK/Epcos), `B_pk = 0.12 Тл` на 100 кГц (для обмеження питомих втрат на рівні `P_v ≈ 80 кВт/м³`);
- Допустима густина струму: `J = 4.5 А/мм² = 4.5·10⁶ А/м²`;
- Коефіцієнт заповнення вікна: `k_u = 0.30`.

#### Крок 1. Розрахунок необхідного показника Area Product (Ap)

Сумарна уявна потужність:

```
P_t
= P_in + P_out      [сума вхідної та вихідної потужностей]
= 306 + 300         [числові значення потужностей]
= 606 Вт            [сумарна розрахункова потужність]
```

Обчислюємо мінімальне значення `A_p`:

```
A_p
= P_t / (4 · f · B_pk · J · k_u)                      [розрахункова формула Area Product]
= 606 / (4 · 100 000 · 0.12 · 4.5·10⁶ · 0.30)         [підстановка числових параметрів]
= 606 / (6.48·10¹⁰)                                   [обчислення знаменника]
= 9.35·10⁻⁹ м⁴                                        [результат у системних одиницях]
= 0.935 см⁴                                           [переведення в сантиметри в четвертому степені]
```

#### Крок 2. Вибір стандартного типорозміру осердя з каталогу

Звернемося до стандартного ряду осердь ETD (Epcos/TDK):
- **ETD29/16/10:** `A_e = 0.76 см²`, `A_w = 0.90 см²` → `A_p = 0.76 · 0.90 = 0.684 см⁴` (замале, `0.684 < 0.935`);
- **ETD34/17/11:** `A_e = 0.97 см² = 9.7·10⁻⁵ м²`, `A_w = 1.23 см² = 1.23·10⁻⁴ м²` → `A_p = 0.97 · 1.23 = 1.19 см⁴` (підходить із запасом `1.19 > 0.935`).

Параметри обраного осердя **ETD34**:
- `A_e = 97 мм² = 9.7·10⁻⁵ м²`;
- `l_e = 78.6 мм = 7.86·10⁻² м`;
- `V_e = 7630 мм³ = 7.63·10⁻⁶ м³`;
- `A_w = 123 мм² = 1.23·10⁻⁴ м²`;
- `MLT ≈ 60 мм = 0.060 м`.

#### Крок 3. Розрахунок кількості витків

Первинна обмотка (для прямокутної напруги напівмоста `V_p = 155 В` та максимального коефіцієнта заповнення імпульсу `D_max = 0.45` на напівперіоді):

```
N_p
= V_p / (4 · f · B_pk · A_e)                       [формула закону індукції Фарадея]
= 155 / (4 · 100 000 · 0.12 · 9.7·10⁻⁵)            [підстановка параметрів первинного кола]
= 155 / 4.656                                      [проміжне ділення]
≈ 33.29 → округлюємо до 34 витків                  [вибір цілого числа витків]
```

Перевіримо фактичну робочу пікову індукцію:

```
B_pk_actual
= 155 / (4 · 100 000 · 34 · 9.7·10⁻⁵)              [перевірочний розрахунок фактичної індукції]
= 155 / 1.3192                                     [обчислення знаменника]
≈ 0.117 Тл                                         [фактична робоча індукція]
```

Вторинна обмотка (для випрямленої напруги `24 В` з урахуванням падіння на діодах Шотткі `V_f ≈ 0.6 В` та `D_max = 0.45`):

```
V_sec_req = (24 + 0.6) / (2 · D_max) = 24.6 / 0.90 = 27.33 В

N_s
= N_p · (V_sec_req / V_p)                          [коефіцієнт трансформації напруг]
= 34 · (27.33 / 155)                               [підстановка напруг та первинних витків]
= 34 · 0.1763                                      [проміжне множення]
≈ 5.99 → округлюємо до 6 витків                    [вибір цілого числа вторинних витків]
```

#### Крок 4. Розрахунок перерізу дротів

1. Первинний струм (діючий): `I_p_rms = P_in / V_p = 306 / 155 ≈ 1.97 А`.
   Необхідний переріз міді: `A_cu_p = 1.97 / 4.5 = 0.438 мм²`.
   Глибина скін-шару на частоті 100 кГц у міді при +70 °C:
   ```
   δ = 66 / √(f) = 66 / √(100 000) ≈ 0.21 мм
   ```
   Максимальний діаметр одиничної жили без суттєвого скін-ефекту: `d_wire ≤ 2 · δ ≈ 0.40 мм` (переріз жили `0.125 мм²`).
   Тому первинну обмотку мотаємо літцендратом або джгутом із 4 жил діаметром 0.38 мм (`4 · 0.113 = 0.452 мм²`).

2. Вторинний струм (діючий): `I_s_rms = 12.5 А · √(0.5) ≈ 8.84 А`.
   Необхідний переріз міді: `A_cu_s = 8.84 / 4.5 = 1.96 мм²`.
   Мотаємо мідною фольгою товщиною `0.15 мм` і шириною `13 мм` (`S = 1.95 мм²`) або літцендратом із 18 жил по 0.38 мм.

#### Крок 5. Перевірка втрат та перегріву

1. **Втрати у фериті:**
   За графіком TDK N87 при `B = 0.117 Тл`, `f = 100 кГц`, `T = 80 °C` питомі втрати складають `P_v ≈ 75 кВт/м³ = 0.075 Вт/см³`.
   ```
   P_fe = P_v · V_e = 0.075 Вт/см³ · 7.63 см³ ≈ 0.572 Вт
   ```

2. **Втрати в міді:**
   Сумарний опір обмоток, приведений до первинної, з урахуванням довжини витка `MLT = 0.06 м` та коефіцієнта змінного струму `F_r ≈ 1.3`, дає:
   ```
   P_cu ≈ 0.65 Вт
   ```

3. **Сумарні втрати та перегрів:**
   ```
   P_tot = P_fe + P_cu = 0.572 + 0.650 = 1.222 Вт
   ```
   Тепловий опір осердя ETD34 з каркасом на платі при природній конвекції: `R_th ≈ 28 °C/Вт`.
   Розрахунковий перегрів:
   ```
   ΔT = P_tot · R_th = 1.222 Вт · 28 °C/Вт ≈ 34.2 °C
   ```

Температура трансформатора за температури навколишнього середовища +25 °C складе `25 + 34.2 = 59.2 °C`, що гарантує великий запас надійності до граничної температури ізоляції класу B (+130 °C).

### Приклад 2. Розрахунок силового накопичувального дроселя (100 мкГн, 5 А)

Розрахуємо силовий дросель понижувального DC-DC перетворювача (Buck Converter):
- Необхідна індуктивність: `L = 100 мкГн = 1.0·10⁻⁴ Гн`;
- Максимальний постійний струм навантаження: `I_dc = 4.0 А`;
- Пульсація струму (розмах): `ΔI = 2.0 А` → піковий струм `I_pk = I_dc + ΔI / 2 = 5.0 А`;
- Середньоквадратичний струм: `I_rms = √(I_dc² + (ΔI / √12)²) = √(16 + 0.33) ≈ 4.04 А`;
- Допустима пікова індукція: `B_pk = 0.30 Тл` (ферит N87 має індукцію насичення `B_sat ≈ 0.39 Тл` при 100 °C, обираємо робочу точку з запасом 25%);
- Допустима густина струму: `J = 5.0 А/мм² = 5.0·10⁶ А/м²`;
- Коефіцієнт заповнення вікна: `k_u = 0.35`.

#### Крок 1. Розрахунок енергії та Area Product

Запасена енергія:

```
W = 0.5 · L · I_pk² = 0.5 · 1.0·10⁻⁴ · 25 = 1.25·10⁻³ Дж = 1.25 мДж
```

Розрахунковий `A_p`:

```
A_p
= (2 · W) / (B_pk · J · k_u)                        [розрахункова формула Area Product дроселя]
= (2 · 1.25·10⁻³) / (0.30 · 5.0·10⁶ · 0.35)         [підстановка W, B_pk, J та k_u]
= 2.5·10⁻³ / (5.25·10⁵)                             [спрощення чисельника та знаменника]
= 4.76·10⁻⁹ м⁴                                      [результат у метрах у четвертому степені]
= 0.476 см⁴                                         [переведення у сантиметри в четвертому степені]
```

#### Крок 2. Вибір осердя

З каталогу осердь типу **E (Ш-подібні)** або **PQ**:
- Обираємо осердя **E25/13/7**:
  - `A_e = 52.5 мм² = 5.25·10⁻⁵ м²`;
  - `A_w = 93 мм² = 9.3·10⁻⁵ м²`;
  - `A_p = 0.525 · 0.93 = 0.488 см⁴` (ідеально покриває розрахункове значення `0.476 см⁴`);
  - `l_e = 57.5 мм = 5.75·10⁻² м`;
  - `MLT ≈ 48 мм = 0.048 м`.

#### Крок 3. Кількість витків та довжина повітряного зазору

Кількість витків:

```
N
= (L · I_pk) / (B_pk · A_e)                         [формула ампер-витків для індуктивності]
= (1.0·10⁻⁴ · 5.0) / (0.30 · 5.25·10⁻⁵)             [підстановка L, I_pk, B_pk та A_e]
= 5.0·10⁻⁴ / (1.575·10⁻⁵)                           [проміжне ділення]
≈ 31.7 → округлюємо до 32 витків                    [округлення до найближчого цілого]
```

Необхідна довжина повітряного зазору `l_g`:

```
l_g
= (μ_0 · N² · A_e) / L                               [формула магнітного опору повітряного зазору]
= (4 · π · 10⁻⁷ · 32² · 5.25·10⁻⁵) / 1.0·10⁻⁴        [підстановка констант і параметрів]
= (1.2566·10⁻⁶ · 1024 · 5.25·10⁻⁵) / 1.0·10⁻⁴        [проміжне множення чисельника]
= 6.755·10⁻⁸ / 1.0·10⁻⁴                              [ділення на індуктивність]
= 6.755·10⁻⁴ м                                       [результат у метрах]
= 0.676 мм                                           [переведення в міліметри]
```

Коефіцієнт крайового потоку (при висоті вікна `G = 15 мм`):

```
F
= 1 + (0.676 / √(52.5)) · ln(2 · 15 / 0.676)        [формула МакЛаймана для крайового фактора]
= 1 + (0.676 / 7.246) · ln(44.38)                    [обчислення кореня та відношення висоти вікна]
= 1 + 0.0933 · 3.793                                 [логарифмування та множення]
≈ 1.354                                              [результуючий коефіцієнт крайового спучування]
```

Через крайове спучування провідність зазору зросла на 35.4%. Щоб зберегти індуктивність рівно `100 мкГн`, скоригуємо зазор:

```
l_g_actual = l_g · F = 0.676 мм · 1.354 ≈ 0.915 мм
```

Зазор величиною `0.92 мм` шліфується на центральному керні осердя. Провідник перерізом `A_wire = 4.04 / 5.0 = 0.81 мм²` (мотаємо джгутом із 7 жил по 0.38 мм) займає у вікні `32 · 7 · (π · 0.19²) ≈ 25.4 мм²` чистої міді, що складає `25.4 / 93 ≈ 27%` площі вікна. Дросель не увійде в насичення до струму `I_sat = 5.6 А` та забезпечить надійну тривалу роботу за помірного нагріву.
