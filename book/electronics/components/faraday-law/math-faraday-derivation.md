# 🧮 Від рівнянь Фарадея–Максвелла до формул самоіндукції та взаємоіндукції

Усі розрахунки індуктивних елементів — від компактного дроселя імпульсного перетворювача до паразитного взаємного зв'язку між доріжками плати — спираються на прямий перехід від польових рівнянь Максвелла до зосереджених параметрів електричних кіл. Нижче наведено послідовне математичне виведення вольт-амперної характеристики котушки, її магнітної енергії, матриці взаємоіндукції, вольт-секундного балансу, диференціального рівняння RLC-снубера, енергетичного балансу TVS-демпфування, аналізу індуктивності розсіювання, коаксіального екранування, планарних котушок, диференціального придушення та напруги завади в сигнальних контурах.

### 1. Інтегральний та диференціальний закон Фарадея–Максвелла

У макроскопічній електродинаміці закон електромагнітної індукції пов'язує циркуляцію напруженості електричного поля вздовж замкненого контуру зі швидкістю зміни магнітного потоку крізь поверхню, обмежену цим контуром:

```
∮ E · dl = −d/dt ∬ B · dA
```

де:
- `∮ E · dl` — циркуляція електричного поля вздовж просторового замкненого контуру (електрорушійна сила `E`);
- `B` — вектор магнітної індукції (тесла, Тл);
- `dA` — диференціальний елемент площі, орієнтований за правилом правого гвинта відносно напрямку обходу контуру;
- `Φ = ∬ B · dA` — повний магнітний потік крізь поверхню (вебер, Вб).

Застосовуючи теорему Стокса, що перетворює лінійний інтеграл циркуляції векторного поля вздовж замкненої межі `∂Σ` на поверхневий інтеграл від ротора цього поля по поверхні `Σ`:

```
∮[∂Σ] E · dl = ∬[Σ] (∇ × E) · dA
```

Підставляючи теорему Стокса в інтегральний закон Фарадея, отримуємо:

```
∬[Σ] (∇ × E) · dA = −∬[Σ] (∂B/∂t) · dA
```

Оскільки це співвідношення виконується для довільної поверхні `Σ` та будь-якого контуру `∂Σ`, підінтегральні вирази мають бути тотожно рівними. Це дає диференціальну форму другого рівняння Максвелла:

```
∇ × E = −∂B/∂t
```

Фізичний зміст цього рівняння: будь-яка часова зміна магнітної індукції `B` безпосередньо створює в тій самій точці простору вихрове електричне поле `E`, лінії напруженості якого замкнені самі на себе.

### 2. Потокозчеплення котушки з N витками

Якщо контур являє собою котушку з `N` послідовно з'єднаних витків, повне потокозчеплення `Λ` (позначається також як `Ψ`) дорівнює сумі магнітних потоків крізь кожен окремий виток:

```
Λ = ∑[k=1..N] Φ[k]
```

Для котушки з однорідним магнітним полем, де кожен виток пронизується однаковим потоком `Φ`:

```
Λ = N · Φ
```

Тоді сумарна електрорушійна сила (ЕРС) індукції, наведена в усіх витках котушки:

```
E = −dΛ/dt = −N · (dΦ/dt)
```

### 3. Виведення індуктивності ідеального соленоїда

Зв'яжемо магнітний потік зі струмом `i(t)`, що протікає крізь котушку довжиною `l`, площею поперечного перерізу `A` та магнітною проникністю середовища `μ = μ₀ · μᵣ`.

За законом циркуляції магнітного поля (теоремою Ампера) для довгого соленоїда:

```
∮ B · dl = μ · I_повне
B · l    = μ · (N · i)       [підсумовано струм N витків]
B        = (μ · N · i) / l   [напруженість поля всередині соленоїда]
```

Підставимо отримане значення індукції `B` у вираз для магнітного потоку одного витка:

```
Φ = B · A
Φ = (μ · N · A · i) / l
```

Обчислимо повне потокозчеплення котушки:

```
Λ = N · Φ
Λ = N · (μ · N · A · i) / l
Λ = (μ · N² · A / l) · i
```

Оскільки геометричні параметри `N`, `A`, `l` та проникність `μ` для лінійного немагнітного або ненасиченого магнітного середовища є константами, коефіцієнт пропорційності між потокозчепленням і струмом визначає **власну індуктивність** `L`:

```
L = Λ / i = (μ · N² · A) / l
```

### 4. Диференціальне рівняння котушки в колах зі струмом

Диференціюємо потокозчеплення за часом для отримання ЕРС самоіндукції:

```
E = −dΛ/dt
  = −d/dt (L · i(t))
  = −L · (di/dt)         [за умови L = const]
```

У теорії електричних кіл використовують пасивну систему знаків (де додатний напрямок напруги `v(t)` збігається з напрямком протікання струму `i(t)` від вищого потенціалу до нижчого). Падіння напруги на виводах котушки протистоїть ЕРС самоіндукції:

```
v(t) = −E = L · (di/dt)
```

Звідси отримуємо інтегральну форму зв'язку між напругою та струмом:

```
i(t) = i(0) + (1/L) · ∫[0..t] v(τ) dτ
```

Цей вираз математично доводить, що струм через індуктивність є інтегралом від прикладеної напруги і не може містити розривів першого роду (стрибків) при скінченних значеннях напруги `v(t)`.

### 5. Виведення енергії магнітного поля

Електрична потужність, яка надходить у котушку в кожен момент часу:

```
p(t) = v(t) · i(t) = (L · di/dt) · i(t)
```

Енергія `W`, накопичена в магнітному полі при зростанні струму від `0` до кінцевого значення `I` за час від `0` до `T`:

```
W = ∫[0..T] p(t) dt
  = ∫[0..T] (L · di/dt) · i(t) dt   [підстановка виразу потужності]
  = L · ∫[0..I] i di                [заміна змінної інтегрування dt → di]
  = L · [i² / 2] від 0 до I          [первісна від струму i]
  = (1/2) · L · I²                  [остаточний інтеграл енергії]
```

Густина енергії магнітного поля `w_m` (енергія на одиницю об'єму соленоїда `V = A · l`):

```
w_m = W / (A · l)                                   [густина: енергія на одиницю об'єму соленоїда]
    = ((1/2) · L · I²) / (A · l)                    [підстановка накопиченої енергії W]
    = (1/2) · ((μ · N² · A / l) · I²) / (A · l)     [підстановка індуктивності L = μ·N²·A/l]
    = (1/2) · μ · ((N · I) / l)²                    [скорочення площі A та перегрупування]
    = (1/2) · (B² / μ)                              [підстановка індукції B = μ·N·I/l]
    = (1/2) · B · H                                 [зв'язок B = μ·H для напруженості поля H]
```

### 6. Взаємоіндукція, формула Неймана та індуктивність розсіювання

Якщо поруч розташовані два замкнені контури зі струмами `i₁` та `i₂`, магнітний потік, що створюється струмом першого контуру, пронизує площу другого контуру.

Потокозчеплення обох контурів записується у вигляді системи рівнянь:

```
Λ₁ = L₁ · i₁ + M₁₂ · i₂
Λ₂ = M₂₁ · i₁ + L₂ · i₂
```

Коефіцієнт взаємної індуктивності `M₁₂` визначається формулою подвійного лінійного інтеграла Франца Ернста Неймана:

```
M₁₂ = (μ₀ / (4 · π)) · ∮[C₁] ∮[C₂] ((dl₁ · dl₂) / r₁₂)
```

де `dl₁` і `dl₂` — диференціальні елементи довжини першого та другого контурів, а `r₁₂` — просторова відстань між ними.

Із симетрії скалярного добутку `dl₁ · dl₂ = dl₂ · dl₁` та відстані `r₁₂ = r₂₁` безпосередньо випливає теорема взаємності:

```
M₁₂ = M₂₁ = M
```

Зв'язок взаємної індуктивності `M` з власними індуктивностями `L₁` та `L₂` задається безрозмірним коефіцієнтом магнітного зв'язку `k` (`0 ≤ k ≤ 1`):

```
M = k · √(L₁ · L₂)
```

У реальному трансформаторі повний магнітний потік первинної обмотки `Φ₁` розділяється на робочий потік взаємного намагнічування `Φ_m` та потік розсіювання `Φ_leak`, який замикається через повітря й не пронизує вторинну обмотку:

```
Φ₁ = Φ_m + Φ_leak
```

Це дозволяє представити повну індуктивність первинної обмотки `L₁` у вигляді суми корисної індуктивності намагнічування `L_m` та паразитної **індуктивності розсіювання** `L_leak`:

```
L_m = k · L₁
L_leak = (1 − k) · L₁
```

При розмиканні первинного ключа flyback-перетворювача енергія магнітного поля намагнічування `(1/2)·L_m·I_pk²` успішно передається у вторинне коло. Проте енергія, накопичена в індуктивності розсіювання:

```
W_leak = (1/2) · L_leak · I_pk²
```

не має магнітного зв'язку зі вторинною обмоткою і за законом Фарадея розряджається безпосередньо в паразитну ємність закритого MOSFET, генеруючи небезпечний викид напруги з амплітудою:

```
V_spike = I_pk · √(L_leak / C_oss)
```

Цей розрахунок обґрунтовує строгу необхідність встановлення RCD-снубера або TVS-супресора паралельно первинній обмотці для поглинання енергії `W_leak`.

### 7. Математичний розрахунок вольт-секундного балансу та пульсацій струму

Розглянемо накопичувальний дросель знижувального (Buck) перетворювача, який працює на частоті комутації `f_sw = 1 / T_sw` з коефіцієнтом заповнення `D = t_on / T_sw`.

Під час фази відкритого ключа `t_on` до котушки прикладено напругу `V_on = V_in − V_out`. Приріст струму:

```
ΔI_on = (1/L) · ∫[0..t_on] (V_in − V_out) dt = ((V_in − V_out) · t_on) / L
```

Під час фази закритого ключа `t_off = (1 − D) · T_sw` до котушки через відкритий діод/синхронний транзистор прикладено зворотну напругу `V_off = −V_out`. Спад струму:

```
ΔI_off = (1/L) · ∫[0..t_off] (−V_out) dt = −(V_out · t_off) / L
```

В усталеному періодичному режимі струм наприкінці періоду повинен дорівнювати початковому (`ΔI_on + ΔI_off = 0`):

```
((V_in − V_out) · t_on) / L − (V_out · t_off) / L = 0
(V_in − V_out) · t_on = V_out · t_off
```

Підставляючи `t_on = D · T_sw` та `t_off = (1 − D) · T_sw`:

```
(V_in − V_out) · D = V_out · (1 − D)     [підстановка тривалостей t_on і t_off]
V_in · D − V_out · D = V_out − V_out · D [розкриття дужок]
V_in · D = V_out                         [додавання V_out·D до обох частин]
V_out = D · V_in                         [коефіцієнт передачі Buck-перетворювача]
```

Розрахунок амплітуди пульсацій струму дроселя `ΔI_L`:

```
ΔI_L = ((V_in − V_out) · D) / (L · f_sw) = (V_out · (1 − D)) / (L · f_sw)
```

Необхідна індуктивність дроселя для забезпечення заданого відносного коефіцієнта пульсацій `r = ΔI_L / I_out`:

```
L = ((V_in − V_out) · V_out) / (r · I_out · V_in · f_sw)
```

### 8. Диференціальне рівняння демпфування RLC-снубера

Коли паразитний індуктивний викид комутується на паразитну ємність `C_p` та демпферний резистор `R_s` із послідовним снуберним конденсатором `C_s` (`C_s ≫ C_p`), еквівалентне коло комутаційного вузла описується лінійним однорідним диференціальним рівнянням другого порядку для струму демпфування `i(t)`:

```
L_p · (d²i/dt²) + R_s · (di/dt) + (1 / C_s) · i(t) = 0
```

Характеристичне рівняння системи:

```
s² + (R_s / L_p) · s + (1 / (L_p · C_s)) = 0
s² + 2 · α · s + ω₀² = 0
```

де:
- `α = R_s / (2 · L_p)` — коефіцієнт загасання контуру;
- `ω₀ = 1 / √(L_p · C_s)` — власна резонансна кутова частота контуру;
- `Q = ω₀ / (2 · α) = (1 / R_s) · √(L_p / C_s)` — добротність коливального контуру.

Для повного усунення високочастотного дзвону (перенапруги та EMI) система повинна перебувати в критичному або аперіодичному режимі (`Q ≤ 0.5`), що вимагає:

```
α ≥ ω₀
R_s / (2 · L_p) ≥ 1 / √(L_p · C_s)
R_s ≥ 2 · √(L_p / C_s)
```

### 9. Енергетичний баланс демпфування індуктивного удару за допомогою TVS

Розглянемо коло розмикання котушки з індуктивністю `L` та початковим струмом `I_0`, захищеної TVS-супресором з напругою фіксації `V_Z` та джерелом живлення `V_CC`.

Після розмикання ключа струм спадає за лінійним законом:

```
i(t) = I_0 · (1 − t / t_off)
```

де час повного спадання струму:

```
t_off = (L · I_0) / (V_Z − V_CC)
```

Енергія `E_TVS`, яка виділяється у вигляді тепла на кристалі супресора:

```
E_TVS = ∫[0..t_off] V_Z · i(t) dt
      = V_Z · ∫[0..t_off] I_0 · (1 − t / t_off) dt
      = V_Z · I_0 · [t − t² / (2 · t_off)] від 0 до t_off
      = V_Z · I_0 · (t_off / 2)
      = V_Z · I_0 · ((L · I_0) / (2 · (V_Z − V_CC)))
      = (1/2) · L · I_0² · (V_Z / (V_Z − V_CC))
```

Цей розрахунок демонструє фундаментальний факт: енергія, яку розсіює супресор, завжди перевищує початкову енергію магнітного поля `W_L = (1/2)·L·I_0²` на коефіцієнт `V_Z / (V_Z − V_CC)`. Додаткова частка енергії надходить від самого джерела живлення `V_CC`, оскільки струм котушки під час вимикання продовжує протікати крізь джерело живлення.

### 10. Точний експоненційний розрахунок спаду струму зі зворотним діодом

Коли паралельно індуктивному навантаженню з опірністю `R_coil` та індуктивністю `L` встановлено звичайний кремнієвий діод із прямим падінням напруги `V_F`, диференціальне рівняння замкненого контуру набуває вигляду:

```
L · (di/dt) + R_coil · i(t) + V_F = 0
```

Розв'язок цього лінійного неоднорідного диференціального рівняння першого порядку з початковою умовою `i(0) = I_0`:

```
i(t) = (I_0 + V_F / R_coil) · e^(−t / τ) − (V_F / R_coil)
```

де стала часу контуру `τ = L / R_coil`.

Час повного згасання струму до нуля `t_zero` знаходиться з умови `i(t_zero) = 0`:

```
(I_0 + V_F / R_coil) · e^(−t_zero / τ) = V_F / R_coil
e^(−t_zero / τ) = (V_F / R_coil) / (I_0 + V_F / R_coil)
t_zero = τ · ln(1 + (I_0 · R_coil) / V_F)
```

Для котушки реле з `L = 100 мГн`, `R_coil = 24 Ом`, `I_0 = 0.5 А` та кремнієвим діодом `V_F = 0.7 В`:
- Стала часу: `τ = 0.1 / 24 ≈ 4.17 мс`;
- Час знеструмлення: `t_zero = 4.17 · ln(1 + (0.5 · 24) / 0.7) = 4.17 · ln(18.14) ≈ 12.1 мс`.

Цей розрахунок доводить, чому зворотний діод затримує механічне розмикання контактів реле більш ніж на 12 мілісекунд.

### 11. Індуктивність мікросмужкової лінії над суцільним шаром землі

Для друкованої плати сигнальна доріжка шириною `w`, розташована на висоті `h` над суцільним шаром землі в діелектрику з відносною проникністю `ε_r`, утворює плоский електромагнітний хвилевід.

Погонна індуктивність такої мікросмужкової лінії `L₀` (індуктивність на одиницю довжини контуру повернення):

```
L₀ = μ₀ · (h / w_eff)
```

де `w_eff` — ефективна електродинамічна ширина провідника з урахуванням крайових полів розсіювання (`w_eff ≈ w + 1.4 · h`).

Повна індуктивність петлі сигнального контуру довжиною `l`:

```
L_loop = L₀ · l = μ₀ · ((h · l) / w_eff)
```

Зменшення товщини діелектрика `h` між сигнальним шаром і землею (наприклад, з 1.6 мм у двошаровій платі до 0.1 мм у чотиришаровій платі зі структурою SIG-GND-PWR-SIG) лінійно зменшує паразитну індуктивність сигнальної петлі в `1.6 / 0.1 = 16` разів, відповідно послаблюючи індуковану проти-ЕРС Фарадея на 24 дБ.

### 12. Індуктивність коаксіального кабелю та екранування

Розглянемо коаксіальний кабель із внутрішнім провідником радіуса `a` та зовнішнім циліндричним екраном внутрішнього радіуса `b`.

За законом Ампера магнітне поле в діелектрику між провідниками (`a < r < b`) при протіканні струму `i`:

```
B(r) = (μ₀ · i) / (2 · π · r)
```

Магнітний потік крізь поздовжній переріз кабелю довжиною `l`:

```
Φ = ∫[a..b] B(r) · l dr
  = ((μ₀ · i · l) / (2 · π)) · ∫[a..b] (1 / r) dr
  = ((μ₀ · i · l) / (2 · π)) · ln(b / a)
```

Повна індуктивність коаксіальної лінії:

```
L = Φ / i = ((μ₀ · l) / (2 · π)) · ln(b / a)
```

За межами коаксіального кабелю (`r > b`) повний охоплений струм дорівнює алгебраїчній сумі прямого струму центральної жили та зворотного струму екрана:

```
I_enclosed = i − i = 0
```

За теоремою Ампера циркуляція поля зовні кабелю тотожно дорівнює нулю:

```
∮[r > b] B · dl = μ₀ · I_enclosed = 0  ⟹  B_ext = 0
```

Оскільки зовнішнє магнітне поле кабелю строго дорівнює нулю, змінний магнітний потік за межами екрана відсутній (`dΦ_ext/dt = 0`). Це математично доводить, що ідеально коаксіальна лінія з симетричним зворотним струмом не створює індуктивних наводок Фарадея на сусідні чутливі кола.

### 13. Індуктивність планарної спіральної котушки на друкованій платі

Для планарних котушок NFC-антен та бездротового передавання енергії на базі друкованих провідників індуктивність розраховують за модифікованою формулою Гарольда Вілера:

```
L_planar = (μ₀ · N² · d_avg · c₁) / 2 · [ln(c₂ / ρ) + c₃ · ρ + c₄ · ρ²]
```

де:
- `d_avg = (d_out + d_in) / 2` — середній геометричний діаметр спіралі;
- `ρ = (d_out − d_in) / (d_out + d_in)` — коефіцієнт заповнення котушки;
- `N` — число витків;
- `c₁, c₂, c₃, c₄` — безрозмірні геометричні коефіцієнти форми, які залежать від геометрії полігону:
  - Квадратна спіраль: `c₁ = 1.27`, `c₂ = 2.07`, `c₃ = 0.18`, `c₄ = 0.13`;
  - Шестикутна спіраль: `c₁ = 1.09`, `c₂ = 2.23`, `c₃ = 0.00`, `c₄ = 0.17`;
  - Восьмикутна спіраль: `c₁ = 1.07`, `c₂ = 2.29`, `c₃ = 0.00`, `c₄ = 0.19`;
  - Кругла спіраль: `c₁ = 1.00`, `c₂ = 2.46`, `c₃ = 0.00`, `c₄ = 0.20`.

Квадратна геометрія забезпечує найбільшу індуктивність на одиницю площі плати завдяки більшій охопленій площі кутових сегментів, тоді як кругла геометрія мінімізує омічний опір провідника та забезпечує максимальну добротність `Q`. Ця модифікована формула Вілера враховує взаємну індукцію між усіма суміжними друкованими сегментами, забезпечуючи точність розрахунку кращу за 2–3% без необхідності тривимірного чисельного моделювання поля.

### 14. Математичне обґрунтування диференціального придушення завади

Розглянемо симетричну диференціальну пару провідників (наприклад, лінії CAN, USB, Ethernet), що піддаються впливу зовнішнього змінного магнітного поля `B_ext(t)`.

Провідники розташовані на малій відстані `s` один від одного. Магнітні потоки, що перетинають перший і другий провідники відносно землі:

```
Φ₁ = ∬[A₁] B_ext · dA
Φ₂ = ∬[A₂] B_ext · dA
```

Індуковані синфазні ЕРС у провідниках:

```
V_noise1 = −dΦ₁/dt
V_noise2 = −dΦ₂/dt
```

Корисний диференціальний сигнал на виході диференціального приймача:

```
V_diff = (V_sig+ + V_noise1) − (V_sig− + V_noise2) [віднімання сигналів на диференціальному вході]
       = (V_sig+ − V_sig−) + (V_noise1 − V_noise2) [перегрупування корисного сигналу та завад]
       = V_signal + (−d/dt (Φ₁ − Φ₂))              [підстановка закону Фарадея для завад]
```

Оскільки провідники розташовані впритул (`s → 0`), градієнт поля між ними незначний, і магнітні потоки практично рівні (`Φ₁ ≈ Φ₂`). Тоді різниця наведених ЕРС прямує до нуля:

```
V_noise_diff = −d/dt (Φ₁ − Φ₂) ≈ 0
```

Цей математичний результат доводить, що диференціальне трасування нейтралізує індуктивну заваду Фарадея за рахунок синфазного віднімання на приймачі, забезпечуючи коефіцієнт придушення синфазного сигналу (CMRR) понад 60–80 дБ.

У витих парах (Twisted Pair) додається просторова інверсія контурів: кожен крок скрутки змінює просторову орієнтацію сусідніх петель на 180°. Сумарна наведена ЕРС уздовж кабелю довжиною із `M` кроками скрутки:

```
V_noise_total = ∑[k=1..M] (−1)^k · (dΦ[k]/dt) ≈ 0
```

Сусідні напівпетлі захоплюють магнітний потік однакової амплітуди, але протилежного знака, що знищує індуктивну наводку навіть у неоднорідних зовнішніх магнітних полях промислової частоти (50/60 Гц).

### 15. Розрахунок паразитної взаємної індуктивності та наводки на платі

Розглянемо дві паралельні доріжки довжиною `l` на друкованій платі, розташовані на відстані `d` одна від одної. Перша доріжка є джерелом імпульсної завади зі струмом `i₁(t)`. Вона утворює сигнальний контур із замкненою площею `A_loop`.

Магнітне поле нескінченно довгого прямого провідника зі струмом на відстані `r`:

```
B(r) = (μ₀ · i₁) / (2 · π · r)
```

Магнітний потік, що пронизує сигнальний контур-жертву шириною від `r₁` до `r₂`:

```
Φ₂₁ = ∫[r₁..r₂] B(r) · l dr                     [інтегрування поля B(r) по площі контуру]
    = ∫[r₁..r₂] ((μ₀ · i₁ · l) / (2 · π · r)) dr [підстановка поля прямого провідника]
    = ((μ₀ · l) / (2 · π)) · ln(r₂ / r₁) · i₁    [первісна від 1/r дорівнює ln(r)]
```

Звідси взаємна індуктивність між агресивним провідником і контуром-жертвою:

```
M = ((μ₀ · l) / (2 · π)) · ln(r₂ / r₁)
```

Індукована завада напруги `V_noise` в контурі-жертві визначається законом Фарадея:

```
V_noise = −dΦ₂₁/dt = −M · (di₁/dt)
```

**Числовий приклад розрахунку наводки на друкованій платі:**
Нехай перемикання силового MOSFET у DC-DC перетворювачі створює швидкість наростання струму `di₁/dt = 2 А / 5 нс = 4 · 10⁸ А/с`.
Паразитна взаємна індуктивність між силовими та чутливими вимірювальними доріжками довжиною `l = 25 мм` становить `M ≈ 5 нГн`.

Розрахунок наведеного імпульсу шуму:

```
V_noise = 5 · 10⁻⁹ Гн · 4 · 10⁸ А/с = 2.0 В
```

Імпульс амплітудою `2.0 В` на чутливій лінії 3.3-вольтової цифрової шини (наприклад, I2C, SPI або тактового сигналу) повністю руйнує логічні рівні й призводить до скидання мікроконтролера. 

З формули видно єдиний інженерний спосіб мінімізації `V_noise`:
1. Зменшення взаємної індуктивності `M` шляхом зближення провідника зі своїм зворотним земляним шаром (тоді `r₂ / r₁ → 1`, а `ln(1) = 0`).
2. Фізичне віддалення сигнальної лінії від джерела завади (збільшення `r₁`).
