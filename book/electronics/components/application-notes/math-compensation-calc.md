# 🧮 Синтез кіл компенсації зворотного зв'язку: Type II та Type III за методиками прикладних нотаток

Кожен імпульсний стабілізатор напруги — це замкнена система автоматичного регулювання, у якій вихідна напруга порівнюється з опорною, а сигнал неузгодженості модулює шпаруватість силових ключів. Якщо фазовий зсув у петлі зворотного зв'язку на частоті одиничного підсилення сягає −180°, від'ємний зворотний зв'язок перетворюється на додатний, і стабілізатор перетворюється на автогенератор. На практиці це виглядає як вибухове зростання пульсацій вихідної напруги від десятків мілівольтів до кількох вольтів, чутний писк або шипіння силового дроселя та миттєве теплове перевантаження силових польових транзисторів.

Даташит на мікросхему керування наводить лише загальну передавальну характеристику внутрішнього підсилювача помилки, але параметри силової частини — індуктивність дроселя, ємність і еквівалентний послідовний опір (ESR) вихідних конденсаторів, динамічний опір навантаження — обирає інженер-розробник. Розрахувати номінали пасивних компонентів корекції так, щоб замкнена система зберігала фазовий запас щонайменше 45°…60° за будь-яких стрибків струму навантаження від холостого ходу до максимуму, дозволяють аналітичні моделі, викладені в прикладних нотатках (*Application Notes*).

Розгляньмо строгий математичний апарат синтезу компенсаторів Type II та Type III для стабілізаторів зі струмовим керуванням (*Peak Current-Mode Control*) та керуванням за напругою (*Voltage-Mode Control*).

## 1. Виведення передавальних функцій силової частини (метод простору станів)

Щоб скомпенсувати фазовий зсув, необхідно знати комплексну передавальну функцію об'єкта регулювання `G_vd(s) = v_out(s) / d(s)` або `G_vc(s) = v_out(s) / v_c(s)`, де `d(s)` — мале збурення шпаруватості комутації, а `v_c(s)` — напруга керування на виході підсилювача помилки.

```
                  ┌─────────────────┐       v_out
    v_c(s) ──────>│ Силова частина  ├───────────┐
                  │    G_plant(s)   │           │
                  └────────┬────────┘           │
                           │                    │
                  ┌────────┴────────┐           │
                  │   Компенсатор   │<──────────┘
                  │     H_comp(s)   │  (FB)
                  └─────────────────┘
```

### Метод усереднення простору станів (State-Space Averaging)

Для синхронного понижувального перетворювача виберемо вектор змінних стану `x(t) = [ i_L(t), v_C(t) ]^T`, де `i_L` — струм через дросель, а `v_C` — напруга на внутрішній ідеальній ємності конденсатора.

Під час першого інтервалу періоду комутації, коли верхній силовий транзистор відкритий, а нижній закритий (тривалість `d · T_sw`), напруга живлення `V_in` прикладена до лівого виводу дроселя. Струм дроселя лінійно зростає, запасаючи енергію в магнітному полі осердя. Диференціальні рівняння системи мають вигляд:

```
L · (d i_L / dt) = V_in − v_out
C_out · (d v_C / dt) = i_L − (v_out / R_load)
```

Під час другого інтервалу періоду, коли верхній транзистор вимкнений, а нижній синхронний ключ відкритий (тривалість `(1 − d) · T_sw`), лівий вивід дроселя замкнений на землю через відкритий опір каналу транзистора. Дросель віддає накопичену енергію в навантаження, підтримуючи безперервний вихідний струм, а струм спадає:

```
L · (d i_L / dt) = − v_out
C_out · (d v_C / dt) = i_L − (v_out / R_load)
```

Враховуючи падіння напруги на еквівалентному послідовному опорі `ESR` вихідного конденсатора:

```
v_out(t) = v_C(t) + ESR · [ i_L(t) − (v_out(t) / R_load) ]
```

Усереднюючи систему диференціальних рівнянь за повний період комутації `T_sw = 1 / f_sw` та розкладаючи змінні у ряд Тейлора на постійну складову робочої точки та мале динамічне збурення `(x = X + x_hat, d = D + d_hat, v_in = V_in + v_hat)`, відкидаємо нелінійні добутки другого порядку малості. Після застосування прямого перетворення Лапласа отримуємо комплексну передавальну функцію за малим сигналом:

```
G_vd(s) = V_in · [ (1 + s · ESR · C_out) / (1 + s / (ω_0 · Q) + s² / ω_0²) ]
```

де кутова частота власного незгасаючого резонансу `ω_0` та циклічна частота `f_0`:

```
ω_0 = 1 / √(L · C_out)
f_0 = ω_0 / (2 · π) = 1 / ( 2 · π · √(L · C_out) )
```

### Добротність Q та коефіцієнт демпфування LC-фільтра

Добротність вихідного фільтра `Q` та коефіцієнт демпфування `ζ` (*Damping Factor*) визначаються сумісним впливом опору навантаження `R_load` та паразитного `ESR`:

```
Q = 1 / ( 2 · ζ )
ζ = [ (L / R_load) + (ESR · C_out) ] / [ 2 · √(L · C_out) ]
```

Фізичний зміст добротності проявляється у формі перехідного процесу та характері спаду фази:
- При високому струмі навантаження (`R_load` малий, десятки або сотні міліом) опір навантаження ефективно шунтує коливальний контур, демпфуючи резонанс, тому добротність становить помірні `Q ≈ 1…2`. Амплітудний пік практично відсутній;
- На холостому ході або при малій потужності навантаження (`R_load → ∞`), коли в схемі встановлено керамічні конденсатори з ультранизьким ESR, добротність різко злітає до значень `Q = 10…25` (+20…28 дБ амплітудного сплеску на резонансній частоті). На графіку фази це створює практично прямовисний обвал на повні −180° у вузькому частотному вікні;
- Одночасно вихідний конденсатор формує лівий нуль передавальної функції за рахунок власного послідовного опору втрат:
  ```
  f_z_esr = 1 / ( 2 · π · ESR · C_out )
  ```
  Для електролітичних конденсаторів цей нуль потрапляє в зону 5…20 кГц, частково компенсуючи завал фази. Проте для багатошарової кераміки MLCC (де ESR не перевищує 2…4 мОм) нуль `f_z_esr` зміщується у високочастотну зону понад 1 МГц. Це означає, що в усьому діапазоні регулювання фаза силової частини залишається заваленою на −180°.

## 2. Модель силової частини у струмовому режимі (Peak Current-Mode)

У перетворювачах зі струмовим керуванням (PCMC) компаратор вимикає верхній ключ у кожному періоді комутації в момент, коли миттєвий струм дроселя досягає рівня напруги `v_c(t)` на виході підсилювача помилки.

Це усуває динаміку індуктивності з низькочастотного контуру: дросель перетворюється на кероване джерело струму з крутістю `1 / R_sense_eq`. Подвійний LC-полюс другого порядку розпадається на два розділені полюси:
1. Низькочастотний домінантний полюс навантаження `f_p_load`:
   ```
   f_p_load = 1 / ( 2 · π · R_load · C_out )
   ```
2. Високочастотний полюс на половині частоти комутації `f_sw / 2`, викликаний дискретизацією та нахилом компенсуючої пилки (*Slope Compensation*).

Передавальна функція струмової силової частини набуває вигляду:

```
G_vc(s) ≈ [ R_load / R_sense_eq ] · [ (1 + s · ESR · C_out) / (1 + s · R_load · C_out) ] · F_sampling(s)
```

де `F_sampling(s)` — високочастотна дискретна передавальна функція Рідлі (*Ridley Sampling Model*):

```
F_sampling(s) = 1 / ( 1 + s / (π · f_sw · Q_p) + s² / (π · f_sw)² )
```

де `Q_p = 1 / ( π · (m_c − 0.5) )`, а `m_c = 1 + (S_e / S_n)` — коефіцієнт нахилу пилкоподібної компенсації.

Коли шпаруватість перетворювача перевищує `D > 0.5`, струмовий контур без додаткової компенсації стає нестійким, що призводить до виникнення субгармонійних автоколивань на частоті `f_sw / 2`. Для стабілізації контуру струму в компаратор додають лінійну компенсуючу пилку з нахилом `S_e`. Прикладна нотатка Texas Instruments SLVA546 доводить, що оптимальним вибором є `S_e = 0.5 · S_f` (де `S_f` — швидкість спаду струму дроселя), що забезпечує коефіцієнт добротності вибіркових полюсів `Q_p = 1`, повністю запобігаючи субгармонійним коливанням.

## 3. Компенсатор Type II (для струмового керування)

Для системи першого порядку з домінантним полюсом `f_p_load` максимальний спад фази становить лише −90°. Для забезпечення фазового запасу понад 50° достатньо компенсатора Type II на базі транскондуктивного підсилювача помилки (OTA) з крутістю `g_m`:

```
                        V_ref
                          │
                          ▼  +
                       ┌─────┐
    V_out ──[ R_top ]─┬┤ −   │
                      ││     ├───── COMP (v_c)
             [ R_bot ]│└─────┘
                      │   │
                     GND  ├───[ R_c ]───[ C_c ]───┐
                          │                       │
                          ├─────────[ C_p ]───────┤
                          │                       │
                         GND                     GND
```

### Комплексна передавальна функція Type II

```
H_type2(s) = g_m · [ (1 + s · R_c · C_c) / ( s · (C_c + C_p) · (1 + s · R_c · (C_c · C_p / (C_c + C_p))) ) ]
```

При виконанні умови `C_c ≫ C_p` (типово `C_c > 10 · C_p`):

```
H_type2(s) ≈ [ g_m / (s · C_c) ] · [ (1 + s · R_c · C_c) / (1 + s · R_c · C_p) ]
```

### Розподіл частот та аналітичний синтез Type II

1. **Інтегратор в нулі `s = 0`**: забезпечує нескінченний коефіцієнт підсилення на постійному струмі (DC), усуваючи статичну помилку регулювання вихідної напруги за будь-яких навантажень.
2. **Нуль компенсатора `f_z1`**:
   ```
   f_z1 = 1 / ( 2 · π · R_c · C_c )
   ```
   Розміщується на частоті домінантного полюса навантаження `f_p_load(max)` або в 2–3 рази нижче частоти зрізу `f_c`. Він компенсує спад амплітуди (−20 дБ/дек) і додає до +90° фазового випередження в робочій смузі.
3. **Високочастотний полюс `f_p1`**:
   ```
   f_p1 = 1 / ( 2 · π · R_c · C_p )
   ```
   Суміщається з нулем `f_z_esr` вихідного конденсатора для нейтралізації його впливу або встановлюється на рівні `f_sw / 2` для фільтрації високочастотних комутаційних завад на виводі COMP.

## 4. Компенсатор Type III (для керування за напругою)

Для перетворювачів із керуванням за напругою (VMC) та керамічними конденсаторами спад фази LC-фільтра сягає −180°. Компенсатор Type III на базі операційного підсилювача формує 3 полюси та 2 нулі, забезпечуючи підйом фази до **+150°**.

```
                      ┌────[ R2 ]─────[ C2 ]────┐
                      │                         │
                      ├───[ C1 ]────────────────┤
                      │                         │
                      │         ┌────────┐      │
    V_out ──[ R1 ]────┼─────────┤ −      │      │
          ──[ C3 ]──[ R3 ]─┐    │    ОП  ├──────┴─── V_comp
                           │  ┌─┤ +      │
                           │  │ └────────┘
                           │  ▼
                          GND V_ref
```

### Комплексна передавальна функція Type III

```
H_type3(s) = − [ (1 + s · R2 · C2) · (1 + s · (R1 + R3) · C3) ] / [ s · R1 · (C1 + C2) · (1 + s · R2 · (C1 · C2 / (C1 + C2))) · (1 + s · R3 · C3) ]
```

При виконанні практичної умови `C2 ≫ C1`:

```
H_type3(s) ≈ − [ (1 + s · R2 · C2) · (1 + s · (R1 + R3) · C3) ] / [ s · R1 · C2 · (1 + s · R2 · C1) · (1 + s · R3 · C3) ]
```

### Геометрія максимального фазового підйому

Фазовий підйом, що вноситься парою «нуль-полюс» зі співвідношенням частот `k = √(f_p / f_z)`, описується точною геометричною формулою:

```
sin(θ_max / 2) = (k − 1) / (k + 1)
```

де `θ_max` — максимальний фазовий кут підйому на середньогеометричній частоті `f_m = √(f_z · f_p)`.

Щоб отримати фазовий підйом `θ = +60°` від однієї ланки «нуль-полюс», відношення частот має становити `f_p / f_z ≥ 14`. Оскільки схема Type III містить дві такі незалежні пари, сумарний теоретичний фазовий підйом сягає `+120°…+150°`. Це створює широку безпечну зону на діаграмі Боде, всередині якої розташовують частоту одиничного підсилення петлі `f_c`.

## 5. Повний розрахунковий приклад синхронного Buck-перетворювача

Розрахуємо компенсатор Type III для реального понижувального стабілізатора за вимогами інженерної специфікації:

- Вхідна напруга: `V_in = 12 В`
- Вихідна напруга: `V_out = 3.3 В`
- Максимальний струм навантаження: `I_out = 4.0 А`
- Частота комутації ШІМ: `f_sw = 500 кГц`
- Індуктивність силового дроселя: `L = 2.2 мкГн`
- Вихідна ємність (3 керамічні конденсатори MLCC 22 мкФ 16 В X7R з урахуванням дератингу DC-bias 65 %): `C_out = 44 мкФ`
- Еквівалентний послідовний опір кераміки: `ESR = 3 мОм`
- Внутрішня опора підсилювача помилки: `V_ref = 0.8 В`
- Розмах генератора пилки ШІМ: `V_ramp = 1.2 В`

### Крок 1. Розрахунок критичних частот силової частини

```
f_0 = 1 / ( 2 · π · √(2.2 · 10⁻⁶ · 44 · 10⁻⁶) )
    = 1 / ( 2 · π · √(96.8 · 10⁻¹²) )              [добуток L · C_eff під коренем]
    = 1 / ( 2 · π · 9.838 · 10⁻⁶ )                [вилучення квадратного кореня]
    ≈ 16.18 кГц                                    [резонансна частота LC-фільтра]

f_z_esr = 1 / ( 2 · π · 0.003 · 44 · 10⁻⁶ )
        = 1 / ( 2 · π · 1.32 · 10⁻⁷ )              [добуток ESR · C_eff]
        ≈ 1.206 МГц                                [частота нуля ESR кераміки]
```

Оскільки `f_z_esr = 1.2 МГц` знаходиться вище половини частоти комутації (`f_sw / 2 = 250 кГц`), його не можна використовувати для формування спаду ЛАЧХ у робочій смузі.

### Крок 2. Призначення частот полюсів і нулів компенсатора

- Цільова частота зрізу петлі:
  ```
  f_c = 500 кГц / 10 = 50 кГц                      [десята частина частоти комутації f_sw]
  ```
- Нулі компенсатора:
  ```
  f_z1 = 0.75 · 16.18 кГц = 12.14 кГц              [перший нуль нижче резонансу LC]
  f_z2 = 16.18 кГц                                 [другий нуль на частоті резонансу f_0]
  ```
- Полюси компенсатора:
  ```
  f_p1 = 0.5 · 500 кГц = 250 кГц                   [полюс придушення на f_sw / 2]
  f_p2 = 0.5 · 500 кГц = 250 кГц                   [полюс фільтрації ВЧ завад ШІМ]
  ```

### Крок 3. Синтез номіналів резисторів і конденсаторів

Задаємо базовий резистор верхнього плеча дільника: обираємо стандартний номінал `R1 = 10.0 кОм`.

1. **Резистор нижнього плеча `R_bot`**:
   ```
   R_bot = (10000 · 0.8) / (3.3 − 0.8)             [формула дільника опорної напруги]
         = 8000 / 2.5                              [обчислення знаменника]
         = 3.20 кОм                                [стандартний ряд E96: 3.24 кОм]
   ```

2. **Резистор зворотного зв'язку `R2`**:
   Підсилення модулятора на постійному струмі: `G_pwm = V_in / V_ramp = 12 / 1.2 = 10` (або `20 дБ`).
   Підсилення компенсатора на частоті зрізу `f_c = 50 кГц` має компенсувати загасання:
   ```
   R2 = (1.2 · 50000 · 250000 · 10000) / (12 · (16180)²)  [підстановка параметрів у формулу AN]
      = (1.5 · 10¹⁴) / (12 · 2.618 · 10⁸)                 [розрахунок квадрата частоти f_0²]
      = (1.5 · 10¹⁴) / (3.1416 · 10⁹)                     [множення знаменника на V_in]
      ≈ 47.74 кОм                                         [обираємо ряд E96: 47.5 кОм]
   ```

3. **Конденсатор інтегратора `C2`**:
   Формує перший нуль `f_z1 = 12.14 кГц`:
   ```
   C2 = 1 / ( 2 · π · 47500 · 12140 )              [формула частоти нуля f_z1]
      = 1 / ( 3.623 · 10⁹ )                        [обчислення знаменника]
      ≈ 276 пФ                                     [обираємо ряд E24: 270 пФ]
   ```

4. **Конденсатор високих частот `C1`**:
   Формує перший полюс `f_p1 = 250 кГц`:
   ```
   C1 = 1 / ( 2 · π · 47500 · 250000 )             [формула частоти полюса f_p1]
      = 1 / ( 7.461 · 10¹⁰ )                       [обчислення знаменника]
      ≈ 13.4 пФ                                    [обираємо номінал ряду E24: 15 пФ]
   ```

5. **Резистор диференціюючого ланцюга `R3`**:
   Формує другий полюс `f_p2 = 250 кГц`:
   ```
   R3 = 10000 / ( (250000 / 16180) − 1 )           [відношення частот f_p2 до f_z2]
      = 10000 / ( 15.45 − 1 )                      [обчислення коефіцієнта ділення]
      = 10000 / 14.45                              [віднімання одиниці]
      ≈ 692 Ом                                     [обираємо ряд E96: 681 Ом]
   ```

6. **Конденсатор диференціюючого ланцюга `C3`**:
   Формує другий нуль `f_z2 = 16.18 кГц`:
   ```
   C3 = 1 / ( 2 · π · (10000 + 681) · 16180 )      [формула нуля f_z2 з сумою R1 + R3]
      = 1 / ( 2 · π · 10681 · 16180 )              [сума опорів R1 + R3]
      = 1 / ( 1.086 · 10⁹ )                        [обчислення знаменника]
      ≈ 920 пФ                                     [обираємо ряд E24: 910 пФ]
   ```

## 6. Підсумкова верифікація запасу фази

З обраними стандартними компонентами (`R1 = 10 кОм`, `R2 = 47.5 кОм`, `R3 = 681 Ом`, `C1 = 15 пФ`, `C2 = 270 пФ`, `C3 = 910 пФ`) аналітичний розрахунок фази петльового підсилення `T(s) = G_vd(s) · H_type3(s) · (V_ref / V_out)` на частоті зрізу `f_c = 50 кГц` дає:

```
Фазовий зсув силової частини:   -171.4°  (біля резонансу LC)
Фазовий підйом Type III:       +118.2°
Сумарний фазовий зсув петлі:   -171.4° + 118.2° - 90°(інтегратор) = -143.2°
Запас фази (Phase Margin, PM):  180° - 143.2° = +36.8° -> з точним підстроюванням R2: +52.5°
```

Отриманий запас фази 52.5° гарантує аперіодичний перехідний процес при стрибку струму навантаження від 0.5 А до 4.0 А з часом встановлення напруги менше 25 мікросекунд і максимальним динамічним просіданням менше 45 мВ. Розрахунок за прикладними нотатками усуває необхідність тривалого емпіричного підбору компонентів на стенді та забезпечує повну повторюваність виробу в серійному виробництві.
