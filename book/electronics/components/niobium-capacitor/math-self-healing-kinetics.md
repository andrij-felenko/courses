# 🧮 Термодинаміка самопасивації та розрахунок надійності ніобієвих конденсаторів

Робота твердотільних оксидних конденсаторів підпорядковується фундаментальним законам термодинаміки хімічних фазових рівноваг, моделям іонного транспорту в нанорозмірних діелектриках, розподіленій імпедансній теорії пористих середовищ та квантово-механічній емісії Френкеля–Пула. Розгляньмо кількісний математичний апарат, що описує енергетику пробою, нестаціонарний тепловий баланс мікродефекту, частотну дисперсію пористого анода та розрахунок надійності (FIT/MTBF).

### Термодинамічний баланс дефектного вузла

Під час локального пробою діелектрика товщиною `d ≈ 20–80 нм` струм короткого замикання локалізується в мікроканалі площею `A_defect ≈ 10⁻¹² м²`. Густина струму досягає `j ≈ 10⁸ А/м²`, спричиняючи точковий нагрів до T > 500 °C.

Порівняймо стандартні термодинамічні ентальпії утворення фаз (ΔH°_f) та теплові баланси реакцій для танталової та оксидно-ніобієвої систем.

#### 1. Танталова система (Ta + MnO₂)
Термічний розклад твердого катода MnO₂ починається за T ≈ 450 °C:
```
2 MnO₂ → Mn₂O₃ + ½ O₂         [ендотермічний розклад: ΔH₁ = +134 кДж/моль]
```
Утворений вільний кисень контактує з металевим анодом Ta:
```
2 Ta + 5/2 O₂ → Ta₂O₅          [бурхливе окиснення металу: ΔH₂ = -2046 кДж/моль]
```
Сумарний тепловий баланс реакції на 1 моль Ta₂O₅:
```
ΔH_total = ΔH₂ + 5 · ΔH₁
ΔH_total = -2046 + 5 · (+134)
ΔH_total = -2046 + 670
ΔH_total = -1376 кДж/моль       [сильно екзотермічна самопідтримувана реакція]
```
Виділення 1.38 МДж тепла на моль оксиду миттєво розігріває зону реакції до T > 2200 °C, що значно перевищує температуру займання металевого порошку танталу. Процес переходить у неконтрольоване теплове розганяння (*thermal runaway*).

#### 2. Оксидно-ніобієва система (NbO + MnO₂)
В оксидно-ніобієвому конденсаторі анод уже містить 50 ат. % кисню (ентальпія утворення монооксиду NbO становить ΔH°_f = -406 кДж/моль).

При локальному нагріві діелектрик Nb₂O₅ відновлюється до напівпровідникового діоксиду NbO₂:
```
Nb₂O₅ → 2 NbO₂ + ½ O₂          [ендотермічна дисоціація: ΔH = +289 кДж/моль]
```
Ця реакція **поглинає тепло** з зони пробою. Питомий опір фаз ніобію суттєво відрізняється:
* Металевий Nb: `ρ ≈ 1.5 × 10⁻⁵ Ом·см` (провідник);
* Монооксид NbO: `ρ ≈ 1.0 × 10⁻⁴ Ом·см` (металева провідність, основа анода);
* Діоксид NbO₂: `ρ ≈ 10² – 10⁴ Ом·см` (високоомний напівпровідник, корок дефекту);
* Пентаоксид Nb₂O₅: `ρ ≈ 10¹² – 10¹⁴ Ом·см` (ізолятор, діелектрик).

Оскільки утворений у каналі пробою NbO₂ має опір на 6–8 порядків вищий за матеріал анода NbO, локальний струм падає:
```
I_defect = V / R_defect → 0
```
Джерело тепловиділення ліквідується в зародку. Конденсатор самопасивується без відкритого горіння.

### Динаміка нестаціонарного теплового балансу в каналі дефекту

Поведінка локальної зони пробою описується диференціальним рівнянням теплопровідності в циліндричних координатах:

```
ρ_m · c_p · (∂T/∂t) = k_th · [ (1/r)·(∂/∂r)(r·∂T/∂r) + ∂²T/∂z² ] + j(r,z,t)² · ρ_el(T)
```

де `ρ_m` — густина речовини, `c_p` — питома теплоємність, `k_th` — коефіцієнт теплопровідності, `j` — густина струму, `ρ_el(T)` — температурно-залежний питомий опір матеріалу.

Інтегруючи по об'єму дефектного циліндра радіусом `r_d` і товщиною `d`, отримуємо спрощену динамічну модель теплового балансу:

```
C_th · (dT/dt) = V² / R_defect(T) - (T - T_ambient) / R_th_defect + Q_chem(T)
```

де `C_th` — теплоємність дефектної зони, `R_th_defect` — тепловий опір відведення тепла в масив анода, `Q_chem` — швидкість виділення/поглинання тепла хімічною реакцією.

Критерій стійкості до теплового розганяння визначається знаком похідної від результуючої потужності нагріву за температурою:

```
d(P_net)/dT = d/dT [ V² / R_defect(T) + Q_chem(T) ] - 1 / R_th_defect
```

1. **Для танталу Ta-MnO₂:** При нагріванні питомий опір діелектрика стрімко падає (`d(R_defect)/dT < 0`), а екзотермічна реакція окиснення танталу різко прискорюється (`dQ_chem/dT >> 0`). У результаті `d(P_net)/dT > 0`, що спричиняє лавиноподібне саморозігрівання до T > 2200 °C.
2. **Для оксиду ніобію NbO-MnO₂:** При досягненні температури фазового переходу T ≈ 500 °C утворюється фаза діоксиду NbO₂, що призводить до стрибкоподібного зростання опору каналу на кілька порядків (`d(R_defect)/dT > 0`). Одночасно хімічна реакція стає ендотермічною (`Q_chem < 0`). Завдяки цьому похідна набуває від'ємного значення:
   ```
   d(P_net)/dT < 0   [стан абсолютної теплової стійкості]
   ```
   Будь-яке випадкове підвищення температури миттєво зменшує електричну потужність, повертаючи систему в рівноважний стан низької температури.

### Електрохімічний ріст оксиду: модель Кабрери–Мотта

Анодне окиснення ніобію в кислому електроліті (0.1% H₃PO₄) підпорядковується закону іонної емісії в сильних електричних полях. Густина іонного струму формування описується рівнянням Кабрери–Мотта:

```
j_ion = j₀ · exp[ -(W - q·a·E) / (k_B · T) ]
```

де:
* `W` — висота потенціального бар'єра для міграції іона ніобію між вузлами сітки (`W ≈ 1.3–1.6 еВ`);
* `a` — половина відстані перескоку між сусідніми положеннями рівноваги в аморфному оксиді (`a ≈ 0.25–0.35 нм`);
* `E = V_form / d` — напруженість електричного поля анодування (`E ≈ (4–6) × 10⁶ В/см`);
* `q = 5 · e` — заряд іона Nb⁵⁺ (`q ≈ 8.01 × 10⁻¹⁹ Кл`);
* `j₀` — передекспоненційний множник (`j₀ ≈ 10⁴ – 10⁶ А/м²`).

Оскільки `q · a · E >> k_B · T`, зовнішнє поле суттєво знижує висоту бар'єра в напрямку поля, забезпечуючи швидкий ріст плівки за кімнатної температури до досягнення рівноважної товщини `d = k_anod · V_form`.

### Вольт-амперна кінетика витоку: ефект Френкеля–Пула

Пентаоксид ніобію Nb₂O₅ є аморфним діелектриком із шириною забороненої зони `Eg ≈ 3.4 еВ`. На відміну від Ta₂O₅ (`Eg ≈ 4.5 еВ`), рівень Фермі в Nb₂O₅ ближчий до зони провідності, а концентрація пасток (кисневих вакансій `V_O¨`) становить `N_t ≈ 10¹⁸ – 10¹⁹ см⁻³`.

Провідність у сильних електричних полях (E > 10⁵ В/см) описується емісією Френкеля–Пула (*Poole-Frenkel emission*) — термопольовою іонізацією пасток:

```
J = J₀ · E · exp[ -(q·Φ_B - β_PF · √E) / (k_B · T) ]
```

де:
* `J` — густина струму витоку (А/м²);
* `E = V / d` — напруженість електричного поля в діелектрику (В/м);
* `q = 1.602 × 10⁻¹⁹ Кл` — елементарний заряд;
* `Φ_B` — глибина залягання пастки (для Nb₂O₅ `Φ_B ≈ 0.8 – 1.1 еВ`);
* `k_B = 1.381 × 10⁻²³ Дж/К` (або `8.617 × 10⁻⁵ еВ/К`) — стала Больцмана;
* `T` — абсолютна температура (К);
* `β_PF` — коефіцієнт Френкеля–Пула:

```
β_PF = √( q³ / (π · ε₀ · ε_r_opt) )
```

Обчислимо коефіцієнт `β_PF` для Nb₂O₅, де оптична діелектрична проникність `ε_r_opt ≈ n² ≈ 2.3² ≈ 5.29`:

```
β_PF = √[ (1.602×10⁻¹⁹)³ / (π · 8.854×10⁻¹² · 5.29) ]
β_PF = √[ 4.113×10⁻⁵⁷ / 1.472×10⁻¹⁰ ]
β_PF = √[ 2.794×10⁻⁴⁷ ]
β_PF ≈ 5.29 × 10⁻²⁴ Дж · (м/В)⁰·⁵  ≈  3.30 × 10⁻⁵ еВ · (м/В)⁰·⁵
```

**Кількісний розрахунок залежності витоку від температури.** Нехай за T₁ = 25 °C (298.15 К) струм витоку конденсатора 100 мкФ / 6.3 В під напругою 5.0 В становить `I_leak(25°C) = 15 мкА`. Яким буде витік за T₂ = 85 °C (358.15 К), якщо ефективна енергія активації пасток становить `E_a = q·Φ_B - β_PF·√E ≈ 0.65 еВ`?

Співвідношення струмів витоку за експоненційним законом Арреніуса:
```
I(T₂) / I(T₁) = exp[ (E_a / k_B) · (1/T₁ - 1/T₂) ]

1/T₁ - 1/T₂ = 1/298.15 - 1/358.15
            = 0.003354 - 0.002792
            = 0.000562 К⁻¹

(E_a / k_B) · Δ(1/T) = (0.65 еВ / 8.617×10⁻⁵ еВ/К) · 0.000562 К⁻¹
                     = 7543.2 · 0.000562
                     = 4.24

I(85°C) = 15 мкА · exp(4.24)
        = 15 мкА · 69.4
        ≈ 1040 мкА = 1.04 мА
```

### Частотна модель пористого електрода де Леві

Спічений пористий анод є розподіленою системою, де струм протікає через вузькі канали твердого катода (MnO₂ або полімеру). За моделлю довгої лінії де Леві (*de Levie transmission line model*) імпеданс одиничної циліндричної пори радіусом `r` і довжиною `l` становить:

```
Z_pore(ω) = √( R_pore / (j·ω·C_pore) ) · coth[ √( j·ω·R_pore·C_pore ) ]
```

де `R_pore = ρ_electrolyte · l / (π·r²)` — поздовжній опір електроліту в порі, а `C_pore = 2π·r·l · (ε₀·ε_r / d)` — ємність стінок пори.

На високих частотах глибина проникнення змінного струму в глибину пори (*penetration depth*) зменшується:

```
λ_pen = √( r · d / (2 · ρ_electrolyte · ε₀ · ε_r · ω) )
```

Коли на частотах понад 100 кГц глибина проникнення `λ_pen` стає меншою за довжину пори `l`, внутрішня площа пор вимикається з роботи. Ефективна ємність спадає як `C_eff ∝ 1/√ω`, а еквівалентний послідовний опір прямує до асимптоти `ESR_HF = √( R_pore / (2·ω·C_pore) )`. Застосування високопровідних полімерів (зменшення `ρ_electrolyte` у 50 разів) розширює робочий частотний діапазон ємності до мегагерцової зони.

### Розрахунок теплового розсіювання від змінного струму пульсацій

Під час роботи у вихідному фільтрі імпульсного стабілізатора через конденсатор протікає змінна складова струму з діючим значенням `I_rms`. Потужність внутрішніх джоулевих втрат:

```
P_loss = I_rms² · ESR(f)
```

Тепловий потік розсіюється через епоксидний компаунд корпусу в навколишнє повітря та друковану плату:

```
ΔT = P_loss · R_th_case
```

де `R_th_case` — тепловий опір корпус–середовище (°C/Вт). Для стандартних SMD типорозмірів тепловий опір становить:
* Case A (EIA 3216): `R_th ≈ 140 °C/Вт`;
* Case B (EIA 3528): `R_th ≈ 110 °C/Вт`;
* Case C (EIA 6032): `R_th ≈ 85 °C/Вт`;
* Case D (EIA 7343): `R_th ≈ 65 °C/Вт`.

**Приклад теплового розрахунку.** Нехай через конденсатор NbO Case B (ESR = 0.20 Ом) протікає струм пульсацій `I_rms = 0.50 А` на частоті 100 кГц:
```
P_loss = (0.50 А)² · 0.20 Ом = 0.050 Вт = 50 мВт
ΔT = 0.050 Вт · 110 °C/Вт = +5.5 °C
```
Перегрів на 5.5 °C повністю вкладається в допустимий норматив `ΔT_max ≤ +10 °C`, гарантуючи відсутність термічної деградації.

### Математична модель надійності: розрахунок FIT та MTBF

Надійність твердотільного конденсатора виражається інтенсивністю відмов `λ` (вимірюється в FIT — *Failures In Time*, відмов на 10⁹ годин):
```
λ = λ_0 · AF_V · AF_T · AF_R
```

де:
1. `AF_V = ( V_op / V_rated )^n` — коефіцієнт прискорення напругою (`n ≈ 3.5` для NbO, `n ≈ 14.0` для Ta-MnO₂).
2. `AF_T = exp[ (E_a / k_B) · (1/T_ref - 1/T_op) ]` — температурний коефіцієнт Арреніуса (`E_a ≈ 0.15 еВ`, `T_ref = 358.15 К`).
3. `AF_R` — коефіцієнт послідовного опору кола (`AF_R = 1.0` при R_series ≥ 0.1 Ом/В).

**Розрахунковий приклад порівняння надійності.**
Конденсатор NbO 100 мкФ / 6.3 В з базовою надійністю `λ_0 = 5000 FIT` за умов V_op = 5.0 В, T_op = +45 °C (318.15 К):

1. Розрахунок `AF_V`:
```
AF_V = (5.0 / 6.3)³·⁵ = (0.7937)³·⁵ ≈ 0.443
```

2. Розрахунок `AF_T`:
```
1/T_ref - 1/T_op = 1/358.15 - 1/318.15 = -0.000351 К⁻¹
(E_a / k_B) · Δ(1/T) = (0.15 / 8.617×10⁻⁵) · (-0.000351) = -0.611
AF_T = exp(-0.611) ≈ 0.543
```

3. Підсумкова інтенсивність відмов:
```
λ = 5000 FIT · 0.443 · 0.543 · 1.0 ≈ 1203 FIT  (0.120 % / 1000 год)
```

4. Середній час між відмовами MTBF:
```
MTBF = 10⁹ / 1203 ≈ 831 250 годин  ≈  94.9 років безперервної роботи
```

Розрахунок доводить: при 20%-му дератингу напруги оксидно-ніобієвий конденсатор гарантує майже століття безперервної надійної експлуатації в промислових та автомобільних контролерах.
