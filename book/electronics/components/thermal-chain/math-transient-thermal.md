# 🧮 Динамічний тепловий імпеданс Zth(t) та трансформація моделей Фостера і Кауера

Статичний тепловий опір описує поведінку напівпровідника лише за постійної розсіюваної потужності після завершення всіх теплових перехідних процесів. У реальних імпульсних схемах — перетворювачах напруги, драйверах двигунів, схемах захисту від короткого замикання та пускових реле — кристали піддаються впливу короткочасних сплесків потужності в десятки або сотні ватів. Розрахунок за статичним опором показує катастрофічний перегрів там, де чип насправді не встигає нагрітися через власну теплоємність кремнію.

Тут наведено математичне виведення динамічного теплового імпедансу `Z_th(t)`, розрахунок перегріву під дією періодичних імпульсів довільної форми, а також точний алгебраїчний алгоритм перетворення математичної моделі Фостера у фізичну модель Кауера.

### 1. Нестаціонарне рівняння теплопровідності та короткочасний режим

Динаміка температури в твердому тілі описується тривимірним диференціальним рівнянням теплопровідності Фур'є:

```
∂T/∂t = α · ∇²T
```

де `α = k / (ρ · c)` [м²/с] — коефіцієнт температуропровідності (thermal diffusivity) матеріалу, `k` [Вт/(м·К)] — коефіцієнт теплопровідності, `ρ` [кг/м³] — густина, `c` [Дж/(кг·К)] — питома теплоємність.

Для кремнію при кімнатній температурі:
- `k_si ≈ 148 Вт/(м·К)`;
- `ρ_si ≈ 2330 кг/м³`;
- `c_si ≈ 712 Дж/(кг·К)`;
- `α_si = 148 / (2330 · 712) ≈ 8.9 × 10⁻⁵ м²/с = 89 мм²/с`.

#### Розв'язок для напівнескінченного простору при ступінчастому нагріві

На коротких інтервалах часу (`t < 100 мкс`) тепловий потік генерується у тонкому приповерхневому шарі p-n переходу (товщиною кілька мікрометрів) і не встигає досягти меж кристала чи мідного фланця.

Кристал можна розглядати як одновимірне напівнескінченне тіло (`0 ≤ x < ∞`) з постійним тепловим потоком `q = P_d / A_die` [Вт/м²] на межі `x = 0`.

Одновимірне рівняння та крайові умови:
```
∂T(x,t)/∂t = α · ∂²T(x,t)/∂x²
-k · ∂T(0,t)/∂x = q           [постійний потік на вході при t > 0]
T(x,0) = T_a                  [початкова температура]
T(∞,t) = T_a                  [нескінченність залишається холодною]
```

Застосовуючи перетворення Лапласа за часом:
```
s · θ(x,s) - 0 = α · d²θ(x,s)/dx²                               [перетворення диференціального рівняння]
d²θ(x,s)/dx² - (s / α) · θ(x,s) = 0                             [зведення до звичайного диференціального рівняння]
```

Загальний розв'язок у просторі Лапласа, що задовольняє умову на нескінченності:
```
θ(x,s) = C · exp(-√(s / α) · x)                                 [експоненціальне згасання вглиб кристала]
```

З крайової умови на поверхні `x = 0`:
```
-k · dθ(0,s)/dx = q / s                                         [густина теплового потоку в просторі Лапласа]
-k · (-√(s / α)) · C = q / s                                    [диференціювання експоненти за x]
C = q / (k · √(s / α) · s)                                      [виділення константи інтегрування]
  = q / (√(k · ρ · c) · s^(3/2))                                [підстановка виразу для коефіцієнта альфа]
```

Температура на поверхні кристала `x = 0` в операторній формі:
```
θ(0,s) = q / (√(k · ρ · c) · s^(3/2))                           [спектральна щільність перегріву поверхні]
```

Виконуючи обернене перетворення Лапласа (оригінал для `1 / s^(3/2)` дорівнює `2 · √(t / π)`):

```
ΔT_j(t) = T_j(t) - T_a                                          [визначення температурного перепаду]
        = (2 · q / √(π · k · ρ · c)) · √t                       [інверсія перетворення Лапласа]
        = (2 · P_d / (A_die · √(π · k · ρ · c))) · √t           [підстановка повної потужності та площі]
```

Визначаючи динамічний тепловий імпеданс `Z_th(t) = ΔT_j(t) / P_d`:

```
Z_th(t) = (2 / (A_die · √(π · k · ρ · c))) · √t                 [теоретичний закон зростання імпедансу]
```

Ключовий фізичний висновок: на початковому етапі нагріву динамічний тепловий імпеданс зростає строго пропорційно кореню квадратному з часу `√t`.

Характерна глибина проникнення теплової хвилі (thermal diffusion length) `L_diff`:

```
L_diff(t) = 2 · √(α · t)                                        [дифузійна довжина теплової хвилі]
```

Для часу `t = 10 мкс`:
```
L_diff = 2 · √(89 × 10⁻⁶ · 10 × 10⁻⁶)                           [підстановка часу 10 мікросекунд]
       = 2 · √(8.9 × 10⁻¹⁰)                                     [обчислення підкореневого виразу]
       = 2 · 2.98 × 10⁻⁵ м                                      [видобування квадратного кореня]
       = 0.0596 мм                                              [глибина проникнення у міліметрах]
       = 59.6 мкм                                               [тепло локалізоване у верхньому шарі кристала]
```

Для часу `t = 1 мс`:
```
L_diff = 2 · √(89 × 10⁻⁶ · 10⁻³)                                [підстановка часу 1 мілісекунда]
       = 2 · √(8.9 × 10⁻⁸)                                      [обчислення добутку під коренем]
       = 2 · 2.98 × 10⁻⁴ м                                      [видобування кореня]
       = 0.596 мм                                               [тепловий фронт пройшов кристал наскрізь]
```

Оскільки товщина стандартного кристала становить `0.2–0.4 мм`, за час `1 мс` тепловий фронт досягає підкладки й переходить у шар припою (die attach).

### 2. Модель Фостера та періодичний імпульсний режим

Для моделювання теплової динаміки в усьому діапазоні часу (від мікросекунд до хвилин) використовують експоненціальне представлення Фостера.

Крива імпедансу для одиночного імпульсу `Z_th(t)` апроксимується сумою `n` паралельних RC-ланок:

```
Z_th(t) = ∑ [i=1 .. n] R_i · (1 - exp(-t / τ_i))
```

де `τ_i = R_i · C_i` — характерні постійні часу окремих теплових зон, а `∑ R_i = θ_JC` — повний статичний тепловий опір.

#### Реакція на періодичну послідовність прямокутних імпульсів

Розглянемо періодичний поїзд імпульсів потужності з амплітудою `P_peak`, тривалістю імпульсу `t_p`, періодом повторення `T` та шпаруватістю (duty cycle) `D = t_p / T`.

Після встановлення стаціонарного коливального режиму пікова температура наприкінці кожного імпульсу визначається сумою внесків від поточного імпульсу та експоненціально згасаючих залишків усіх попередніх циклів.

Для окремої RC-ланки Фостера з постійною часу `τ` піковий імпеданс `Z_pulse(t_p, D)` виводиться через суму нескінченної геометричної прогресії:

```
Z_i,pulse = R_i · [ (1 - exp(-t_p / τ_i)) / (1 - exp(-T / τ_i)) ] [сума відгуків геометричної прогресії]
```

Розкладаючи експоненту в знаменнику та враховуючи зв'язок `T = t_p / D`:

```
Z_th,pulse(t_p, D) = D · θ_JC + (1 - D) · Z_th(t_p) + ∑ [i=1 .. n] R_i · [ (1 - exp(-t_p / τ_i)) · exp(-(T - t_p) / τ_i) ] / [ 1 - exp(-T / τ_i) ]
```

Спрощена інженерна формула для пікового перегріву `T_j,peak`:

```
T_j,peak = T_a + P_peak · Z_th,pulse(t_p, D)
```

Граничні випадки формули:
1. `t_p → 0` при `D = const`: `Z_th,pulse → D · θ_JC` (середньозважений перегрів від середньої потужності `P_avg = D · P_peak`).
2. `t_p → ∞` (постійний струм DC, `D = 1`): `Z_th,pulse → θ_JC` (статичний тепловий опір).
3. `D → 0` (одиночний рідкісний імпульс): `Z_th,pulse → Z_th(t_p)`.

#### Інтеграл згортки Дюамеля для довільної форми сигналу

Якщо електрична потужність змінюється у часі за довільним законом `P(t)` (наприклад, синусоїдальні втрати в інверторі або експоненціальний спад струму розряду індуктивності), перегрів кристала в момент часу `t` обчислюється через інтеграл згортки Дюамеля:

```
ΔT_j(t) = ∫ [0 .. t] P(λ) · (d Z_th(t - λ) / dt) dλ             [інтеграл Дюамеля для теплового імпедансу]
        = P(0) · Z_th(t) + ∫ [0 .. t] (dP(λ) / dλ) · Z_th(t - λ) dλ [інтегрування частинами]
```

Для експоненціальної моделі Фостера похідна імпульсної перехідної функції:

```
d Z_th(t) / dt = ∑ [i=1 .. n] (R_i / τ_i) · exp(-t / τ_i)       [вагова функція теплової пам'яті]
```

Для трикутного комутаційного імпульсу втрат тривалістю `t_sw` з піком `P_max` (`P(t) = P_max · (1 - t / t_sw)`):

```
ΔT_triangular(t_sw) = (P_max / t_sw) · ∑ [i=1 .. n] R_i · [ t_sw - τ_i · (1 - exp(-t_sw / τ_i)) ] [точний аналітичний розв'язок для комутаційного трикутника]
```

Це дозволяє аналітично обчислювати динамічний нагрів транзистора в моменти динамічного увімкнення та вимкнення інвертора без чисельного інтегрування кожного мікросекундного фронту.

### 3. Математична трансформація Фостера в Кауера

Модель Фостера містить резистори й конденсатори, значення яких отримані чистою математичною апроксимацією експериментальної кривої охолодження. Вона має два критичні недоліки:
1. Внутрішні вузли не мають фізичного змісту (не можна поміряти температуру корпусу `T_case` у жодному з проміжних вузлів).
2. Якщо інженер додає зовнішній радіатор з опором `R_sink`, його не можна просто додати послідовно до кінця ланцюжка Фостера, оскільки це спотворить усю частотну характеристику системи.

Фізична модель Кауера (T-ladder) складається з послідовного ланцюга резисторів і заземлених ємностей. Вона зберігає локальну топологію: перша ланка — кристал, друга — die attach, третя — фланець, четверта — радіатор. До вихідного вузла моделі Кауера можна напряму підключати зовнішні теплові ланцюги.

#### Алгоритм розкладу в ланцюговий дріб (Continued Fraction Expansion)

Вхідний тепловий імпеданс моделі Фостера в операторній формі Лапласа `s`:

```
Z_Foster(s) = ∑ [i=1 .. n] R_i / (1 + s · R_i · C_i)
            = ∑ [i=1 .. n] (1 / C_i) / (s + 1/τ_i)
```

Зведемо суму `n` дробів до спільного знаменника:

```
Z(s) = N(s) / D(s) = (b_{n-1}·s^{n-1} + ... + b_1·s + b_0) / (a_n·s^n + ... + a_1·s + a_0)
```

Імпеданс ланцюга Кауера представляється неперервним ланцюговим дробом другого типу (Cauer II form):

```
Z_Cauer(s) = R_c1 + 1 / ( s·C_c1 + 1 / ( R_c2 + 1 / ( s·C_c2 + ... + 1 / ( R_cn + 1 / (s·C_cn) ) ) ) )
```

Коефіцієнти Кауера `R_ci` та `C_ci` знаходять послідовним діленням многочленів за алгоритмом Евкліда при розкладі навколо точки `s = 0` (або `s → ∞` для Cauer I):

Виділення першого опору:
```
R_c1 = lim[s → 0] Z(s)                                          [значення імпедансу на нульовій частоті]
     = b_0 / a_0                                                [відношення молодших коефіцієнтів]
     = ∑ [i=1 .. n] R_i                                         [сума всіх статичних опорів Фостера]
```

Для високочастотної схеми Кауера I (починаючи з ємності біля кристала):
```
Y_1(s) = 1 / Z(s)                                               [перехід до теплової провідності (адмітансу)]
       = D(s) / N(s)                                            [обертання раціонального дробу]

C_c1 = lim[s → ∞] (Y_1(s) / s)                                  [виділення коефіцієнта при старшій степені s]
     = a_n / b_{n-1}                                            [відношення старших коефіцієнтів знаменника й чисельника]
```

Віднімання ємнісної провідності та знаходження залишкової функції:
```
Y_rem1(s) = Y_1(s) - s · C_c1                                   [віднімання першого ємнісного шунта]
          = D_1(s) / N(s)                                       [новий залишковий многочлен]
```

Перехід до імпедансу та виділення послідовного резистора:
```
Z_2(s) = 1 / Y_rem1(s)                                          [перехід назад до імпедансної форми]
       = N(s) / D_1(s)                                          [обертання залишку]

R_c1 = lim[s → ∞] Z_2(s)                                        [виділення наступного послідовного опору]
     = b_{n-1} / a1_{n-1}                                       [відношення старших коефіцієнтів нового залишку]
```

Повторення процедури для решти ланок дає повну послідовність фізичних компонентів `(C_ci, R_ci)`.

### 4. Розрахунковий приклад: 3-ланкова модель силового MOSFET

Даташит силового транзистора в корпусі TO-247 містить 3-ланкову модель Фостера для переходу junction-to-case:

Параметри Фостера:
- `R1 = 0.08 °C/Вт`, `τ1 = 0.2 мс`  (`C1 = τ1 / R1 = 0.2×10⁻³ / 0.08 = 2.5×10⁻³ Дж/°C`);
- `R2 = 0.32 °C/Вт`, `τ2 = 8.0 мс`  (`C2 = τ2 / R2 = 8.0×10⁻³ / 0.32 = 0.025 Дж/°C`);
- `R3 = 0.60 °C/Вт`, `τ3 = 120.0 мс` (`C3 = τ3 / R3 = 0.120 / 0.60 = 0.200 Дж/°C`).

Сумарний опір:
```
θ_JC = R1 + R2 + R3                                             [додавання опорів Фостера]
     = 0.08 + 0.32 + 0.60                                       [підстановка чисел]
     = 1.00 °C/Вт                                               [статичний опір транзистора]
```

Застосовуючи алгоритм розкладу в ланцюговий дріб Кауера I, отримуємо фізичні параметри шарів:
- `R_c1 = 0.095 °C/Вт`, `C_c1 = 1.85 × 10⁻³ Дж/°C` [шар кремнієвого кристала];
- `R_c2 = 0.345 °C/Вт`, `C_c2 = 0.021 Дж/°C`       [шар припою die attach];
- `R_c3 = 0.560 °C/Вт`, `C_c3 = 0.215 Дж/°C`       [мідний тепловий фланець корпусу].

Перевірка статичного опору моделі Кауера:
```
R_c,total = R_c1 + R_c2 + R_c3                                  [сума послідовних опорів ланцюга Кауера]
          = 0.095 + 0.345 + 0.560                               [підстановка значень синтезованих резисторів]
          = 1.00 °C/Вт                                          [повний збіг зі статичним опором кристала]
```

Перевірка закону збереження повної теплоємності:
```
C_foster_sum = C1 + C2 + C3                                     [сума математичних ємностей Фостера]
             = 0.0025 + 0.025 + 0.200                           [підстановка ємностей]
             = 0.2275 Дж/°C                                     [загальна математична ємність]

C_cauer_sum = C_c1 + C_c2 + C_c3                                [сума фізичних ємностей Кауера]
            = 0.00185 + 0.021 + 0.215                           [підстановка ємностей шарів]
            = 0.2378 Дж/°C                                      [фізична теплоємність кремнію та міді фланця]
```

Різниця між ємностями Фостера і Кауера на 4.5% демонструє, що ємності моделі Фостера не мають прямого фізичного сенсу маси матеріалу і є чисто спектральними коефіцієнтами, тоді як ємності Кауера строго відповідають добутку маси шару на його питому теплоємність `m · c`.

#### SPICE-модель напівпровідника для схемного симулятора

Отримані параметри Кауера транслюються в стандартний SPICE subcircuit, де напруга у вузлах еквівалентна температурі в °C, а струм джерела — потужності у ватах:

```spice
* Еквівалентна 3-ланкова теплова модель Кауера TO-247
* Вузли: TJ (кристал), TCASE (фланець), TAMB (середовище)
.SUBCKT THERMAL_TO247 TJ TCASE TAMB
* Шар 1: Кристал кремнію
R1 TJ   N1    0.095
C1 TJ   TAMB  1.85m
* Шар 2: Припій Die Attach
R2 N1   N2    0.345
C2 N1   TAMB  21.0m
* Шар 3: Мідна основа корпусу
R3 N2   TCASE 0.560
C3 N2   TAMB  215.0m
.ENDS THERMAL_TO247
```

Тепер, якщо транзистор встановлюється на радіатор із термопастою (`R_tim = 0.2 °C/Вт`, `R_sink = 2.5 °C/Вт`, `C_sink = 45 Дж/°C`), інженер просто дописує дві додаткові RC-ланки на вихід ланцюга Кауера:

```
Tj ──[R_c1]──┬──[R_c2]──┬──[R_c3]──┬──[R_tim]──┬──[R_sink]──┬── Ta
             │          │          │           │            │
            [C_c1]     [C_c2]     [C_c3]       │           [C_sink]
             │          │          │           │            │
            GND        GND        GND         GND          GND
```

Така модель є повністю фізично адекватною і дозволяє в симуляторі SPICE одночасно контролювати температуру кристала `T_j`, фланця `T_case` і радіатора `T_sink` при будь-яких динамічних профілях навантаження.
