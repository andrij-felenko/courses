# 🧮 Виведення моделі Лісона та передавальної функції фазового шуму

Спектральна густина фазового шуму автогенератора визначається тим, як коливальна система перетворює внутрішні теплові та напівпровідникові флуктуації на випадкові коливання фази вихідної напруги. Мета цього виведення — показати покроковий математичний перехід від рівнянь замкненого кола зі зворотним зв'язком і фазової крутості резонатора до класичного рівняння Лісона, детально обґрунтувавши кожне фізичне припущення та перетворення.

## Лінійна модель автогенератора та критерій Баркгаузена

Будь-який електронний автогенератор складається з двох ключових функціональних блоків: селективного чотириполюсника прямої передачі (коливального контуру або резонатора) з комплексним коефіцієнтом передачі `β(jω)` та активного нелінійного підсилювача з коефіцієнтом підсилення `A(jω)`.

При подачі живлення для надійного запуску коливань з рівня внутрішніх теплових шумів початковий малосигнальний коефіцієнт підсилення підсилювача `A_small` повинен перевищувати втрати контуру: `|A_small(jω₀) · β(jω₀)| > 1`. У міру зростання амплітуди напруги на контурі підсилювач заходить у нелінійний режим відсічки або насичення. Його ефективна крупносигнальна крутість `G_m(V₀)` монотонно спадає доти, доки в усталеному стаціонарному режимі автоколивань на резонансній частоті `ω₀ = 2π·f₀` не виконається [критерій стійкості автоколивань Баркгаузена](book:electronics/colpitts-oscillator):

```
T(jω₀) = A(jω₀) · β(jω₀) = 1 ∠ 0°
```

Петльове підсилення `T(jω)` на частоті `ω₀` має модуль, строго рівний одиниці, і сумарний фазовий зсув, кратний `2π` (або `0°`).

Активний підсилювач компенсує втрати енергії в коливальній системі. Нехай на частоті резонансу коефіцієнт підсилення активного каскаду є суто дійсним і дорівнює `A₀`. Резонатор являє собою паралельний RLC-контур, що характеризується еквівалентним паралельним опором втрат `R_p`, індуктивністю `L`, ємністю `C` та навантаженою добротністю `Q_L`.

## Еквівалентні перетворення та навантажена добротність контуру

У реальних котушках індуктивності та кварцових резонаторах втрати зосереджені у вигляді еквівалентного послідовного омічного опору дроту чи кварцової пластини `R_s` (англ. *Equivalent Series Resistance*, ESR). На високій добротності (`Q₀ >> 1`) послідовне з'єднання індуктивності `L` та опору `R_s` перераховується в еквівалентне паралельне з'єднання індуктивності `L` та паралельного опору втрат `R_p_0`:

```
R_p_0 = R_s · (1 + Q₀²) ≈ Q₀² · R_s
```

де власна (ненавантажена) добротність котушки або резонатора визначається відношенням характеристичного хвильового опору `ρ = √(L / C) = ω₀·L = 1 / (ω₀·C)` до послідовних втрат:

```
Q₀ = (ω₀ · L) / R_s = R_p_0 / (ω₀ · L) = ω₀ · C · R_p_0
```

Для кварцового резонатора, еквівалентна динамічна схема якого містить динамічну індуктивність `L_m`, динамічну ємність `C_m`, опір втрат `R_m` та паралельну статичну ємність корпусних електродів `C₀`, власна добротність сягає гігантських значень `Q₀ = ω₀·L_m / R_m ≈ 10⁴...10⁶` завдяки колосальній динамічній індуктивності (від одиниць до сотень генрі).

Коли до коливального контуру підключаються вхідний опір транзистора `R_in`, його вихідний опір `R_out` та опір навантаження `R_load`, повний еквівалентний паралельний опір коливальної системи зменшується:

```
1 / R_p_total = (1 / R_p_0) + (1 / R_in) + (1 / R_out) + (1 / R_load)
```

Навантажена добротність коливального контуру `Q_L` за фізичним визначенням виражає відношення накопиченої реактивної енергії до повної енергії, що розсіюється за один період коливань з урахуванням усіх підключених зовнішніх кіл:

```
Q_L = R_p_total / (ω₀ · L) = ω₀ · C · R_p_total
```

Комплексний коефіцієнт передачі паралельного коливального контуру як функція абсолютної частоти `ω`:

```
β(jω) = 1 / [ 1 + j · Q_L · (ω / ω₀ − ω₀ / ω) ]
```

Розглянемо малі відхилення частоти `Δω = ω − ω₀` поблизу резонансної точки (`|Δω| << ω₀`). Розкладемо частотний дріб у виразі реактивної складової:

```
(ω / ω₀) − (ω₀ / ω)
= ((ω₀ + Δω) / ω₀) − (ω₀ / (ω₀ + Δω))             [підстановка ω = ω₀ + Δω]
= (1 + Δω / ω₀) − (1 / (1 + Δω / ω₀))             [виділення одиниці]
≈ (1 + Δω / ω₀) − (1 − Δω / ω₀)                   [лінійне наближення Тейлора 1/(1+x) ≈ 1-x]
= 2 · (Δω / ω₀)                                   [алгебраїчне спрощення різниці]
```

Підставляючи це лінійне наближення у вираз коефіцієнта передачі контуру, отримуємо спрощену форму для вузької смуги поблизу резонансу:

```
β(j(ω₀ + Δω)) ≈ 1 / [ 1 + j · 2·Q_L · (Δω / ω₀) ]
```

Фазовий зсув, що вноситься резонатором при зміщенні частоти на `Δω`:

```
φ_res(Δω) = arg(β) = −arctan[ 2·Q_L · (Δω / ω₀) ]
```

Оскільки розглядається поведінка безпосередньо біля резонансу (`Δω << ω₀ / (2·Q_L)`), застосуємо наближення `arctan(x) ≈ x`:

```
φ_res(Δω) ≈ −2·Q_L · (Δω / ω₀)
```

Звідси знаходимо фундаментальну характеристику резонатора — **крутість фазово-частотної характеристики** (фазову крутість контуру) на частоті резонансу:

```
dφ_res / dω = −(2·Q_L) / ω₀
```

Знак мінус свідчить про те, що при зростанні частоти коливань фаза струму резонатора відстає від прикладеної напруги. Величина `τ_tank = 2·Q_L / ω₀ = Q_L / (π·f₀)` має розмірність часу і являє собою еквівалентну постійну часу релаксації фази в коливальному контурі.

## Енергетичний баланс та накопичена реактивна енергія

Фазовий шум можна також проаналізувати через швидкість релаксації накопиченої енергії. Повна реактивна енергія `E_tank`, запасена в коливальному контурі при амплітуді коливань `V₀`:

```
E_tank = ½ · C · V₀²
```

Потужність омічних втрат `P_diss`, яка розсіюється в еквівалентному паралельному опорі втрат `R_p_total`:

```
P_diss = V₀² / (2 · R_p_total) = (E_tank · ω₀) / Q_L
```

Звідси випливає фундаментальне енергетичне співвідношення:

```
E_tank = (P_diss · Q_L) / ω₀
```

Це рівняння показує, що при фіксованій потужності розсіювання (потужності сигналу `P_s = P_diss`) запасення енергії в контурі прямо пропорційне навантаженій добротності `Q_L`. Чим більша накопичена енергія `E_tank` порівняно з енергією одного теплового кванта `k_B·T`, тим менший відносний фазовий зсув створює кожен випадковий тепловий шумовий імпульс.

## Передавальна функція фазових збурень у замкненій петлі

Припустимо, що в коло автоколивань на вході підсилювача потрапляє мале випадкове збурення фази `Δφ_in(t)` з низькочастотним спектром модуляції `ω_m = 2π·f_m`, де `f_m` — частота відступу від несучої.

В автоколивальних системах амплітудні флуктуації жорстко обмежуються нелінійним механізмом насичення підсилювача: при випадковому збільшенні амплітуди коефіцієнт підсилення спадає нижче одиниці, повертаючи амплітуду до стаціонарного значення граничного циклу. Проте для фази сигналу генератор має інваріантність щодо часового зсуву (відсутня повертальна сила за фазою), тому фазові збурення вільно циркулюють по колу зворотного зв'язку.

Вихідне фазове коливання `Δφ_out` складається з безпосередньо внесеного збурення `Δφ_in` та відгуку петлі, що пройшов повний оберт зворотного зв'язку:

```
Δφ_out(jω_m) = Δφ_in(jω_m) + T(j(ω₀ + ω_m)) · Δφ_out(jω_m)
```

Розв'язуючи це рівняння відносно вихідної фази `Δφ_out`, знаходимо комплексну передавальну функцію замкненого кола для фазових збурень:

```
H_φ(jω_m) = Δφ_out(jω_m) / Δφ_in(jω_m)
= 1 / [ 1 − T(j(ω₀ + ω_m)) ]
```

Розкладемо комплексне петльове підсилення `T(j(ω₀ + ω_m))` у ряд Тейлора поблизу стаціонарної точки автоколивань, де за критерієм Баркгаузена `T(jω₀) = 1`:

```
T(j(ω₀ + ω_m))
≈ T(jω₀) + [ d(T(jω)) / dω ]_{ω=ω₀} · ω_m
= 1 + j · [ dφ_res / dω ] · ω_m                   [враховано сталість модуля |T| = 1]
= 1 − j · ((2·Q_L) / ω₀) · ω_m                   [підстановка фазової крутості контуру]
```

Підставимо отриманий розклад у знаменник передавальної функції фазових збурень:

```
H_φ(jω_m)
= 1 / [ 1 − (1 − j · ((2·Q_L) / ω₀) · ω_m) ]       [підстановка наближення Тейлора]
= 1 / [ j · ((2·Q_L · ω_m) / ω₀) ]                 [скорочення одиниць у знаменнику]
= −j · [ ω₀ / (2·Q_L · ω_m) ]                      [винесення уявної одиниці в чисельник]
```

Перейдемо від кругових частот до циклічних частот у герцах (`ω₀ = 2π·f₀`, `ω_m = 2π·f_m`):

```
H_φ(j f_m) = −j · [ f₀ / (2·Q_L · f_m) ]
```

Обчислимо квадрат модуля передавальної функції фазового шуму:

```
|H_φ(f_m)|² = (f₀ / (2·Q_L · f_m))²
```

Отриманий результат розкриває фундаментальну природу автоколивань: **коливальний контур генератора працює як ідеальний інтегратор фазового шуму** для будь-яких частот відступу, що лежать всередині смуги резонатора `f_m < f₀ / (2·Q_L)`. Оскільки інтегрування сигналу в часовій області `∫ dt` еквівалентне діленню на `j·ω_m` у частотній області, спектральна густина потужності набуває множника `1 / f_m²`, що спричиняє спад шуму зі швидкістю 20 дБ на декаду частоти.

Поза смугою пропускання контуру (`f_m > f₀ / (2·Q_L)`) зворотний зв'язок більше не посилює фазові флуктуації, і сигнал проходить безпосередньо з входу на вихід без інтегрування, тобто `|H_φ(f_m)|² → 1`. Об'єднуючи внутрішньосмуговий та позасмуговий режими в єдиний аналітичний вираз, отримуємо повну передавальну функцію резонатора для фазового шуму:

```
|H_φ,total(f_m)|² = 1 + (f₀ / (2·Q_L · f_m))²
```

## Зв'язок флуктуацій частоти та фазового шуму

Зв'язок між миттєвою частотою коливань `f(t)` та повною фазою `Φ(t) = 2π·f₀·t + φ(t)` визначається фундаментальним диференціальним співвідношенням:

```
f(t) = (1 / 2π) · (dΦ / dt) = f₀ + (1 / 2π) · (dφ / dt)
```

Звідси випадкове відхилення частоти (флуктуація частоти) дорівнює похідній від випадкової фази:

```
Δf(t) = (1 / 2π) · (dφ(t) / dt)
```

Переходячи до спектральних густин потужності, диференціювання в часі відповідає множенню на `(2π·f_m)²`:

```
S_Δf(f_m) = f_m² · S_φ(f_m)
```

або, навпаки, спектральна густина фази є інтегралом від спектра частотних флуктуацій:

```
S_φ(f_m) = S_Δf(f_m) / f_m²
```

Цей вираз доводить, що якщо в автогенераторі діє білий шум частоти (`S_Δf = const`), спектральна густина фазового шуму неминуче спадає як `1 / f_m²` (зона білого частотного шуму за Лісоном). Якщо ж у генераторі діє флікер-шум частоти (`S_Δf ∝ 1 / f_m`), спектральна густина фазового шуму спадає як `1 / f_m³` (глибока флікер-зона).

## Спектральна густина вхідного теплового шуму та коефіцієнт шуму F

Основним джерелом вхідних збурень `Δφ_in` є власний [тепловий шум Джонсона-Найквіста](book:electronics/thermal-noise), що генерується омічними втратами резонатора (еквівалентним послідовним опором `ESR` котушки або кварцу), а також тепловий і дробовий шум активного транзистора.

Повна спектральна густина потужності теплового шуму на вході активного каскаду в узгодженому тракті визначається формулою Найквіста з урахуванням ефективного коефіцієнта шуму підсилювача `F`:

```
S_noise,th = k_B · T · F   [Вт/Гц]
```

де:
- `k_B = 1.380649×10⁻²³ Дж/К` — фізична стала Больцмана;
- `T` — абсолютна термодинамічна температура (стандартно приймається `T = 290 К` або `300 К`);
- `F` — крупносигнальний коефіцієнт шуму активного елемента (безрозмірна величина `F ≥ 1`).

У режимі автоколивань транзистор працює з великим розмахом амплітуди, тому його коефіцієнт шуму `F` зазвичай на 3–8 дБ вищий за стандартний паспортний малосигнальний коефіцієнт шуму `NF`. Це зумовлено періодичним перемиканням струму транзистора, стробуванням шумів зміщення та нелінійним змішуванням високочастотних шумів гармонік назад у робочу смугу.

Випадковий тепловий шум є стаціонарним нормальним (гаусовим) білим процесом. Розкладемо вузькосмуговий випадковий шум на квадратурні складові відносно коливання несучої:

```
n(t) = n_I(t) · cos(ω₀·t) − n_Q(t) · sin(ω₀·t)
```

Складова `n_I(t)` збігається за фазою з вектором несучої й створює амплітудну модуляцію (AM-шум), тоді як ортогональна складова `n_Q(t)` спрямована перпендикулярно до вектора коливань і створює чисту фазову модуляцію (PM-шум).

За теоремою про рівнорозподіл енергії між незалежними ортогональними ступенями вільності, повна теплова потужність ділиться рівно навпіл:
- 50% енергії шуму переходить в амплітудні флуктуації: `S_AM = ½ · k_B · T · F`;
- 50% енергії шуму переходить у фазові флуктуації: `S_PM = ½ · k_B · T · F`.

Нормуючи фазову шумову потужність до повної потужності високочастотного сигналу `P_s`, що циркулює в коливальному контурі, отримуємо спектральну густину фазових флуктуацій на вході:

```
S_φ,in = S_PM / P_s = (k_B · T · F) / (2 · P_s)   [рад²/Гц]
```

## Вузькосмугове наближення фазової модуляції (розклад Бесселя)

Розглянемо гармонічне коливання несучої, промодульоване одним випадковим фазовим тоном малої амплітуди `θ_m`:

```
v(t) = V₀ · cos(ω₀·t + θ_m · sin(ω_m·t))
```

Розкриваючи тригонометричний вираз за функціями Бесселя першого роду `J_n(θ_m)`:

```
v(t) = V₀ · [ J₀(θ_m)·cos(ω₀·t) − J₁(θ_m)·(cos((ω₀ − ω_m)t) − cos((ω₀ + ω_m)t)) + ... ]
```

Для малих фазових збурень (`θ_m << 1 рад`) функції Бесселя апроксимуються головними членами степеневих рядів:

```
J₀(θ_m) ≈ 1
J₁(θ_m) ≈ θ_m / 2
```

Тоді напруга утворює центральну несучу та дві симетричні бічні смуги (верхню та нижню):

```
v(t) ≈ V₀ · cos(ω₀·t) − (V₀ · θ_m / 2) · cos((ω₀ − ω_m)t) + (V₀ · θ_m / 2) · cos((ω₀ + ω_m)t)
```

Потужність кожної окремої бічної смуги відносно потужності несучої:

```
P_sideband / P_carrier = ( (V₀ · θ_m / 2)² / 2 ) / ( V₀² / 2 ) = θ_m² / 4
```

Оскільки дисперсія фазового тону становить `σ_φ² = θ_m² / 2`, відношення потужності однієї бічної смуги до несучої дорівнює:

```
P_sideband / P_carrier = σ_φ² / 2
```

Це строго доводить зв'язок між спектральною густиною однієї бічної смуги `L(f_m)` та повною спектральною густиною фази `S_φ(f_m)`:

```
L(f_m) = 10 · log₁₀[ S_φ(f_m) / 2 ]
```

## Врахування низькочастотного флікер-шуму (1/f) та його нелінійна ап-конверсія

У реальних напівпровідникових структурах (біполярних транзисторах BJT, гетероструктурах HBT, польових транзисторах MOSFET і HEMT) поряд із білим шумом існує інтенсивний низькочастотний надлишковий [флікер-шум](book:physics/flicker-noise). Спектральна густина флікер-шуму зростає за гіперболічним законом `1 / f`:

```
S_flicker(f_m) = S_white · (1 + f_c / f_m)
```

де `f_c` — кутова частота флікер-зламу (англ. *flicker corner frequency*), на якій спектральна густина низькочастотного флікер-шуму зрівнюється з рівнем білого шуму.

Оскільки флікер-шум існує на низьких частотах (від одиниць герців до десятків кілогерців), він не може безпосередньо потрапити у високочастотну смугу резонатора `f₀`. Проте в реальному автогенераторі діють нелінійні параметричні механізми:
1. **Варакторний ефект p-n переходів:** Бар'єрна ємність колекторного чи стокового переходу транзистора `C_j(V)` нелінійно залежить від миттєвої напруги. Низькочастотні флуктуації струму створюють повільні коливання напруги зміщення, які модулюють ємність `C_j`, змінюючи резонансну частоту контуру: `Δf(t) = (df₀ / dV) · v_flicker(t)`. Частотна модуляція автоматично перетворюється на фазовий шум.
2. **Нелінійність крутості транзистора:** Модуляція робочої точки змінює середню крутість `g_m` за період коливань, що призводить до динамічного зсуву фази підсилювача `Δφ_amp`.

У результаті нелінійного змішування низькочастотний флікер-шум переноситься на високочастотну несучу, модулюючи внутрішній шумовий спектр контуру за множником `(1 + f_c / f_m)`.

## Складання повного рівняння Лісона

Перемножуючи вхідну густину шуму `S_φ,in`, квадрат передавальної функції контуру `|H_φ,total|²` та коефіцієнт нелінійного перенесення флікер-шуму, отримуємо класичне **рівняння Лісона**:

```
L(f_m) = 10 · log₁₀[ ( (F · k_B · T) / (2 · P_s) ) · (1 + (f₀ / (2·Q_L · f_m))²) · (1 + f_c / f_m) ]
```

## Покроковий аналіз чотирьох фізичних асимптот

Розкриємо вираз під логарифмом у рівнянні Лісона й проаналізуємо нахили спектра фазового шуму залежно від частоти відступу `f_m`:

```
P_SSB(f_m) = [ (F · k_B · T) / (2 · P_s) ] · [ 1 + f_c/f_m + (f₀/(2·Q_L·f_m))² + (f_c·f₀²)/(4·Q_L²·f_m³) ]
```

Це рівняння містить чотири незалежні степені частоти відступу `f_m`:

```
1. Ділянка 1/f_m³:   L(f_m) ∝ 1 / f_m³   → нахил −30 дБ на декаду
2. Ділянка 1/f_m²:   L(f_m) ∝ 1 / f_m²   → нахил −20 дБ на декаду
3. Ділянка 1/f_m¹:   L(f_m) ∝ 1 / f_m¹   → нахил −10 дБ на декаду
4. Ділянка f_m⁰:     L(f_m) = const      → нахил   0 дБ на декаду (шумовий поріг)
```

Детальний фізичний зміст кожної ділянки:

1. **Глибока флікер-зона (`f_m < f_c` та `f_m < f₀ / (2·Q_L)`):**
   Домінує перехресний член `(f_c · f₀²) / (4·Q_L² · f_m³)`. Низькочастотний флікер-шум транзистора модулює частоту генератора, а резонатор інтегрує ці частотні флуктуації у фазові. Подвійне інтегрування дає спад потужності шуму **−30 дБ/декаду**.
2. **Зона білого частотного шуму (`f_c < f_m < f₀ / (2·Q_L)`):**
   Частота відступу перевищила флікер-злам `f_c`, тому флікер-шум спав нижче рівня теплового шуму. Домінує член `(f₀ / (2·Q_L · f_m))²`. Білий тепловий шум інтегрується контуром, утворюючи процес випадкового блукання фази (англ. *random walk of phase*) зі спадом **−20 дБ/декаду**.
3. **Зона флікер-шуму буфера (`f₀ / (2·Q_L) < f_m < f_c,buf`):**
   Частота відступу вийшла за межі смуги резонатора, але вихідний підсилювач-буфер додає власний прямий флікер-шум. Домінує доданок `f_c / f_m`, що дає спад **−10 дБ/декаду**.
4. **Шумовий поріг (`f_m >> f₀ / (2·Q_L)` та `f_m >> f_c`):**
   Усі частотні члени стають зникаюче малими. Залишається плаский некорельований білий тепловий поріг вихідного тракту:
   ```
   L_floor = 10 · log₁₀[ (F · k_B · T) / (2 · P_s) ]
   ```
   Нахил становить **0 дБ/декаду**.

## Роль навантаженої добротності Q_L

Виведення математично доводить вирішальну роль добротності коливальної системи. Оскільки потужність фазового шуму на ділянках `1/f³` та `1/f²` містить множник `1 / Q_L²`, збільшення навантаженої добротності в `K` разів знижує фазовий шум у `K²` разів:

```
ΔL(f_m) = −20 · log₁₀(Q_L,new / Q_L,old)  [дБ]
```

Саме тому перехід від звичайних друкованих LC-контурів (`Q_L ≈ 30...80`) до прецизійних кварцових резонаторів (`Q_L ≈ 10⁴...10⁶`) дозволяє миттєво знизити фазовий шум на 60–100 дБ, перетворюючи розмитий шумовий шлейф на гостру, високостабільну спектральну лінію.
