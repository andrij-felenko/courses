# 🧮 Нестаціонарний тепловий імпеданс: чому імпульс 300 мкс не гріє кристал

Коли в паспорті силового напівпровідника наведено струми в сотні ампер або міліомні опори каналу за температури переходу `T_j = 25 °C`, ці значення отримують за допомогою короткого імпульсного випробування *(pulsed test)* тривалістю `t_pulse ≈ 300 мкс`. Якщо подати таку саму потужність у безперервному режимі, кремнієвий кристал розплавиться за частки секунди. Щоб обґрунтовано проектувати силові каскади й перераховувати лабораторні параметри на реальні умови роботи, необхідно розрахувати динаміку поширення тепла в кремнії та зрозуміти, чому протягом короткого імпульсу температура кристала практично не змінюється.

---

### Фізична модель напівпровідникового кристала

Кремнієвий кристал напівпровідникового приладу становить собою прямокутну пластину товщиною `L_die ≈ 200...400 мкм` і площею `A`, припаяну струмопровідним припоєм або епоксидним компаундом до масивного мідного тепловідводу корпусу *(leadframe)*. 

Активна напівпровідникова зона — канал польового транзистора, емітерний перехід біполярного транзистора або p-n перехід діода — зосереджена у тонкому поверхневому шарі товщиною `x_active < 5...10 мкм` на лицьовому боці кристала. Оскільки товщина активного шару в десятки разів менша за повну товщину пластини, для аналізу коротких теплових процесів джерело тепла вважають нескінченно тонким поверхневим шаром, що генерує питомий тепловий потік `q = P / A` (де `P` — електрична потужність втрат, `A` — площа кристала).

Поширення тепла від поверхні вглиб твердотільного кремнієвого зразка описується одновимірним диференціальним рівнянням теплопровідності Фур'є:

```
∂T(x, t) / ∂t = α · ∂²T(x, t) / ∂x²    [одновимірне рівняння теплопровідності]
```

Тут `α` — коефіцієнт температуропровідності кремнію *(thermal diffusivity)*, який пов'язує теплопровідність матеріалу з його об'ємною теплоємністю:

```
α = k / (ρ · c_p)                     [коефіцієнт температуропровідності]
```

де:
- `k` — питома теплопровідність монокристалічного кремнію (`k ≈ 148 Вт/(м · К)` при температурі 300 К);
- `ρ` — густина кремнію (`ρ ≈ 2330 кг/м³`);
- `c_p` — питома масова теплоємність кремнію (`c_p ≈ 705 Дж/(кг · К)`).

Обчислимо об'ємну теплоємність `c_v` та коефіцієнт температуропровідності `α`:

```
c_v = ρ · c_p                         [об'ємна теплоємність кремнію]
    = 2330 · 705
    = 1.6426 · 10⁶ Дж/(м³ · К)

α = k / c_v                           [температуропровідність кремнію]
  = 148 / (1.6426 · 10⁶)
  = 9.01 · 10⁻⁵ м²/с = 0.901 см²/с
```

### Математичне виведення нестаціонарного теплового імпедансу через перетворення Лапласа

Розглянемо початкову стадію процесу, коли теплова хвиля ще не досягла протилежного боку кристала. За цієї умови кристал можна розглядати як напівобмежене тверде тіло *(semi-infinite body)* із координатним простором `x ≥ 0`, що знаходиться при початковій температурі `T(x, 0) = T_0 = 25 °C`.

Крайові умови задачі мають вигляд:
1. На поверхні нагріву `x = 0` діє постійний ступінчастий тепловий потік:
   ```
   −k · ∂T(0, t) / ∂x = q = P / A     [гранична умова теплового потоку на поверхні]
   ```
2. На нескінченному віддаленні від джерела температура залишається незмінною:
   ```
   lim_{x → ∞} T(x, t) = T_0          [гранична умова на нескінченності]
   ```

Застосуємо пряме перетворення Лапласа за часовою змінною `t` до диференціального рівняння теплопровідності:

```
s · θ(x, s) − 0 = α · d²θ(x, s) / dx²  [диференціальне рівняння в просторі Лапласа]
```

де `θ(x, s) = L{T(x, t) − T_0}` — зображення приросту температури, `s` — комплексна змінна Лапласа.

Загальний розв'язок цього звичайного диференціального рівняння другого порядку має вигляд:

```
θ(x, s) = C1 · exp(−√(s/α) · x) + C2 · exp(+√(s/α) · x)
```

З умови обмеженості температури на нескінченності випливає `C2 = 0`. Підставляючи граничну умову на поверхні `x = 0` у просторі Лапласа:

```
−k · dθ(0, s) / dx = q / s            [потік у просторі Лапласа]
k · √(s/α) · C1 = q / s
C1 = q / (k · s · √(s/α))
```

Отже, просторовий розподіл температури в операторному вигляді записується як:

```
θ(x, s) = (q / (√(k · ρ · c_p) · s^(3/2))) · exp(−√(s/α) · x)
```

Величина `b = √(k · ρ · c_p)` називається коефіцієнтом теплової активності або ефузивності кремнію *(thermal effusivity)*:

```
b = √(148 · 2330 · 705)               [теплова ефузивність кремнію]
  = √(2.431 · 10⁸)
  = 15592 Вт · с^(1/2) / (м² · К)
```

Виконаємо зворотне перетворення Лапласа для температури безпосередньо на поверхні переходу `x = 0`:

```
θ(0, s) = q / (b · s^(3/2))           [зображення температури на поверхні]

ΔT_j(t) = L⁻¹{ q / (b · s^(3/2)) }    [зворотне перетворення Лапласа]
        = (2 · q · √t) / (b · √π)
        = (2 · q · √t) / √(π · k · ρ · c_p)
```

Поділивши приріст температури `ΔT_j(t)` на повну теплову потужність `P = q · A`, отримуємо аналітичний вираз для нестаціонарного теплового імпедансу кремнієвого переходу `Z_th(t)`:

```
Z_th(t) = (2 · √t) / (A · √(π · k · ρ · c_p))   [нестаціонарний тепловий опір поодинокого імпульсу]
```

Ця формула є фундаментальною: **на початковому етапі нагріву тепловий опір зростає строго пропорційно кореню квадратному від тривалості імпульсу `√t` і обернено пропорційно площі кристала `A`**.

### Просторово-часовий профіль температури в товщі пластини

Повний розв'язок рівняння теплопровідності для довільної глибини `x` усередині напівпровідникової пластини отримується за допомогою інтеграла від додаткової функції помилок `ierfc(u)`:

```
ΔT(x, t) = (2 · q · √t / b) · ierfc(x / (2 · √(α · t)))
```

де інтегральна функція помилок визначається співвідношенням:

```
ierfc(u) = (1 / √π) · exp(−u²) − u · erfc(u)
```

На поверхні нагріву `x = 0` аргумент `u = 0`, а значення `ierfc(0) = 1 / √π`, що повертає виведену раніше формулу поверхневої температури.

Обчислимо профіль спаду температури по глибині кремнієвої пластини для моменту часу `t = 300 мкс` (де характерний масштаб дифузії становить `l_0 = 2 · √(α · t) = 329 мкм`):

1. **На глибині `x = 50 мкм`** (зона під каналом): `u = 50 / 329 ≈ 0.152`. Значення `ierfc(0.152) ≈ 0.44`, що відповідає `78%` від максимальної поверхневої температури.
2. **На глибині `x = 150 мкм`** (середина товщини пластини): `u = 150 / 329 ≈ 0.456`. Значення `ierfc(0.456) ≈ 0.21`, що становить лише `37%` від поверхневої температури.
3. **На глибині `x = 300 мкм`** (нижня сторона кристала на межі з припоєм): `u = 300 / 329 ≈ 0.912`. Значення `ierfc(0.912) ≈ 0.06`, тобто приріст температури становить лише `10%` від поверхневого.

Цей строгий математичний результат наочно доводить: протягом перших 300 мікросекунд більше 90% усієї згенерованої теплової енергії зосереджено виключно у верхній половині кремнієвої пластини. Тепловий потік практично не відчуває наявності металевого фланця, паяного шва чи радіатора.

### Числовий розрахунок глибини проникнення тепла

Характерна глибина `l_diff(t)`, на яку проникає тепловий фронт за час `t`, визначається точкою, де приріст температури спадає приблизно в `e` разів:

```
l_diff(t) = 2 · √(α · t)               [глибина проникнення теплової хвилі]
```

Обчислимо глибину дифузії тепла для стандартного імпульсу даташита `t_pulse = 300 мкс`:

```
l_diff(300 мкс) = 2 · √(9.01 · 10⁻⁵ · 300 · 10⁻⁶)  [підстановка температуропровідності та тривалості]
                = 2 · √(2.703 · 10⁻⁸)             [обчислення добутку]
                = 2 · 1.644 · 10⁻⁴                [вилучення квадратного кореня]
                = 3.288 · 10⁻⁴ м ≈ 329 мкм        [глибина дифузії в мікрометрах]
```

Отримане число `329 мкм` ідеально узгоджується з типовою товщиною кремнієвих кристалів силових транзисторів (`250...350 мкм`). Це пояснює вибір тривалості 300 мкс виробниками напівпровідників:
1. За 300 мкс тепловий процес повністю локалізований у межах кремнію.
2. Тепловий потік ще не досяг шару припою під кристалом, не зайшов у мідний фланець корпусу і не залежить від якості зовнішнього монтажу на плату.
3. Виміряні параметри відображають виключно властивості самого кремнію без похибок тепловідводу.

### Перехід від одновимірного (1D) до тривимірного (3D) поширення тепла

Надзвичайно важливо розуміти часову межу між одновимірною та об'ємною тривимірною дифузією тепла в напівпровідниковому приладі:

1. **Фаза 1D одновимірної дифузії (`t < 300 мкс`).** Тепло поширюється у вигляді строго плоского фронту перпендикулярно до поверхні кристала. Бічні краї кристала ще не відчувають нагріву. Тепловий імпеданс описується виведеною формулою `Z_th(t) ∝ √t`.
2. **Фаза переходу до підкладки (`300 мкс < t < 10 мс`).** Тепловий фронт долає шар пайки кристала *(die attach)* і починає поширюватися в товщу масивного мідного фланця корпусу. Оскільки товщина мідного фланця (1–2 мм) значно більша за товщину кристала, теплові лінії починають розходитися під кутом приблизно 45°, формуючи тривимірне конічне поширення.
3. **Фаза тривимірного розтікання тепла (`t > 10 мс`).** Тепловий потік охоплює весь об'єм корпусу. Тепловий опір розтікання *(spreading resistance)* стабілізується на постійному значенні, що залежить від геометричних розмірів кристала та фланця:
   ```
   R_spread ≈ 1 / (2 · k_copper · √(π · A))
   ```
4. **Фаза зовнішньої квазістатики (`t > 1 с`).** Тепло досягає зовнішнього радіатора і розсіюється в повітря за рахунок конвекції та випромінювання. Тепловий імпеданс досягає постійного стаціонарного значення `R_th_total`.

### Частотний аналіз теплового імпедансу при гармонійному нагріві

Коли теплова потужність змінюється за гармонійним законом `P(t) = P_0 · exp(j · ω · t)`, нестаціонарний тепловий процес описується комплексним частотним імпедансом `Z_th(jω)`:

```
Z_th(jω) = ΔT_j(jω) / P(jω) = 1 / (A · √(k · ρ · c_p · j · ω))
```

Враховуючи, що `√j = (1 + j) / √2 = exp(j · π/4)`, отримуємо:

```
Z_th(jω) = (1 / (A · b · √ω)) · exp(−j · π/4)
```

Звідси випливає фундаментальний висновок: **в одновимірному дифузійному режимі коливання температури кристала відстають за фазою від коливань теплової потужності рівно на 45° (π/4 радіан), а амплітуда температурних пульсацій спадає обернено пропорційно кореню з частоти `1 / √ω`**.

На високих частотах (вище 20 кГц) амплітуда коливань температури стає настільки малою, що кристал поводиться як ідеальний тепловий інтегратор, реагуючи виключно на середньоінтегральну потужність втрат за період.

### Розрахунок нагріву для силового транзистора

Розглянемо типовий MOSFET у корпусі TO-220 з площею кристала `A = 4 мм × 4 мм = 16 мм² = 1.6 · 10⁻⁵ м²`.

Обчислимо імпульсний тепловий опір `Z_th` для часу `t = 300 мкс`:

```
Z_th(300 мкс) = (2 · √(300 · 10⁻⁶)) / (1.6 · 10⁻⁵ · √π · 15592)  [підстановка геометрії та ефузивності]
              = (2 · 0.01732) / (1.6 · 10⁻⁵ · 1.7725 · 15592)   [розрахунок коренів і констант]
              = 0.03464 / 0.4422                                [проміжне ділення]
              = 0.0783 °C/Вт                                    [імпульсний тепловий опір]
```

Порівняємо це з постійним тепловим опором того самого приладу:
- Тепловий опір перехід-корпус у статиці: `R_th_JC ≈ 1.0 °C/Вт` (у 13 разів вище).
- Тепловий опір перехід-середовище на платі без радіатора: `R_th_JA ≈ 62 °C/Вт` (у 790 разів вище).

Розрахуємо нагрів кристала при протіканні тестового струму `I_D = 40 А` при опорі відкритого каналу `R_DS(on) = 5 мОм`:

```
P_loss = I_D² · R_DS(on)              [потужність теплових втрат]
       = 40² · 0.005                  [підстановка струму 40 А та опору 5 мОм]
       = 1600 · 0.005                 [піднесення струму до квадрата]
       = 8.0 Вт                       [статична потужність втрат]
```

Приріст температури кристала під час 300-мікросекундного заводського імпульсу:

```
ΔT_j_pulse = P_loss · Z_th(300 мкс)   [імпульсний нагрів]
           = 8.0 · 0.0783             [підстановка потужності та імпульсного імпедансу]
           = 0.626 °C                 [приріст температури переходу]
```

Кристал нагрівається лише на `0.63 °C`. Якщо початкова температура пластини становила 25.0 °C, то на момент фіксації показань АЦП температура напівпровідника дорівнює `25.63 °C`. Це ідеальні ізотермічні умови, які фіксуються в паспорті.

Якщо ж цей самий струм 40 А пропустити через транзистор у безперервному режимі на платі з радіатором (`R_th_total = 20 °C/Вт`):

```
ΔT_j_DC = P_loss · R_th_total         [стаціонарний нагрів]
        = 8.0 · 20                    [множення потужності на статичний тепловий опір]
        = 160 °C                      [перегрів кристала в статиці]

T_j_final = T_ambient + ΔT_j_DC       [підсумкова температура кристала]
          = 40 + 160                  [додавання температури навколишнього середовища]
          = 200 °C                    [перевищення граничного ліміту T_j_max = 175 °C]
```

### Динаміка теплового ланцюжка Кауера та Фостера

Для повного часового діапазону від мікросекунд до десятків секунд тепловий імпеданс описується сумою експонент моделі Фостера:

```
Z_th(t) = ∑_{i=1}^{N} R_i · (1 − exp(−t / τ_i))   [модель Фостера]
```

де `τ_i = R_i · C_i` — характерні сталі часу кожного теплового шару конструкції.

Фізична структура приладу описується ланцюгом Кауера, де кожен шар матеріалу має фізичний тепловий опір і власну теплоємність, підключену до спільної теплової землі:

```
P_in ──┬──[ R1: кристал ]──┬──[ R2: припій ]──┬──[ R3: фланець ]──┬──[ R4: радіатор ]── (T_ambient)
       │                   │                  │                   │
     [ C1 ]              [ C2 ]             [ C3 ]              [ C4 ]
       │                   │                  │                   │
      GND                 GND                GND                 GND
```

Математична модель Фостера є зручним інструментом для швидкого розрахунку перехідної характеристики у SPICE-симуляторах. Вона отримується шляхом розкладання операторного вхідного теплового імпедансу ланцюга Кауера `Z(s)` на прості дроби. Кожна RC-ланка моделі Фостера відповідає окремому полюсу передатної функції.

Типовий розклад для силового напівпровідникового приладу:

| Елемент теплового тракту | Тепловий опір `R_i` | Теплоємність `C_i` | Стала часу `τ_i` |
| :--- | :--- | :--- | :--- |
| **Кремнієвий кристал (Die)** | `0.25 °C/Вт` | `0.002 Дж/°C` | `0.5 мс` |
| **Паяний шар (Die attach)** | `0.15 °C/Вт` | `0.010 Дж/°C` | `1.5 мс` |
| **Мідний фланець (Leadframe)** | `0.60 °C/Вт` | `0.350 Дж/°C` | `210 мс` |
| **Термоінтерфейс (TIM)** | `0.80 °C/Вт` | `0.500 Дж/°C` | `400 мс` |
| **Алюмінієвий радіатор (Heatsink)** | `4.20 °C/Вт` | `25.00 Дж/°C` | `105 с` |

На часах `t ≤ 300 мкс` працює виключно перша експонента з найменшою теплоємністю. Зовнішні теплові опори корпусу та радіатора повністю зашунтовані власними великими теплоємностями `C_leadframe` та `C_heatsink`, тому зовнішнє охолодження не впливає на результат імпульсного вимірювання.

### Експериментальна ідентифікація теплового опору за стандартом JEDEC JESD51-14

Вимірювання теплового опору «перехід-корпус» `R_th_JC` у заводських лабораторіях виконується за стандартом **JESD51-14** методом подвійного інтерфейсу *(Transient Dual Interface Method, TDIM)*.

Метод полягає у реєстрації кривої охолодження кристала після нагріву імпульсом потужності у двох різних станах корпусу:
1. Корпус чіпа встановлено на водяний охолоджувач із високоякісною термопастою (мінімальний зовнішній тепловий опір).
2. Корпус чіпа встановлено на сухий охолоджувач без пасти (високий зовнішній тепловий опір).

Обидві виміряні перехідні теплові криві `Z_th(t)` математично диференціюються для побудови структурограми *(Structure Function)*:

```
K(R_th) = dC_th / dR_th               [кумулятивна структурна функція]
```

До точки виходу тепла з корпусу в радіатор обидві криві абсолютно ідентичні. Точка розходження кривих точно відповідає фізичній межі мідного фланця чіпа. Значення опору в точці розходження приймається як єдине стандартизоване значення `R_th_JC`, зафіксоване в даташиті. Це унеможливлює маніпуляції з боку виробників при вказанні паспортних теплових параметрів і дає розробнику точну метрологічну базу для коректного теплового моделювання пристрою. Інженер отримує інструмент для суворого розрахунку теплових запасів напівпровідника у будь-яких прикладних режимах експлуатації.

### Фізика теплового розгону (Thermal Runaway) при постійному струмі

Розглянемо умову теплової стійкості напівпровідника під час роботи в безперервному режимі (DC). Опір відкритого каналу польового транзистора зростає з температурою за лінійним наближенням:

```
R_DS(T_j) = R_0 · (1 + α_T · (T_j − T_0))   [температурна залежність опору]
```

де `α_T ≈ 0.006...0.008 1/°C` — температурний коефіцієнт опору кремнію, `R_0` — опір при кімнатній температурі `T_0 = 25 °C`.

Розсіювана потужність при постійному струмі стоку `I_D` становить:

```
P(T_j) = I_D² · R_0 · (1 + α_T · (T_j − T_0))  [потужність як функція температури]
```

З іншого боку, потужність, яка відводиться радіатором у навколишнє середовище, дорівнює:

```
P_diss = (T_j − T_ambient) / R_th_total         [тепловідвід радіатора]
```

У стаціонарному тепловому балансі потужність генерації тепла повинна дорівнювати потужності тепловідводу `P(T_j) = P_diss`. Продиференціюємо обидва вирази за температурою `T_j`. Умова теплової стійкості вимагає, щоб швидкість тепловідводу перевищувала швидкість генерації тепла:

```
dP_diss / dT_j > dP / dT_j
1 / R_th_total > I_D² · R_0 · α_T              [критерій теплової стійкості]
```

Звідси отримуємо критичний струм теплового зриву *(thermal runaway current)*:

```
I_max_stable = 1 / √(R_0 · α_T · R_th_total)   [граничний стійкий постійний струм]
```

Якщо робочий струм перевищує `I_max_stable`, будь-яке мале збільшення температури викликає настільки сильне зростання опору, що потужність втрат зростає швидше, ніж радіатор здатний віддати тепло. Виникає лавиноподібний тепловий розгін, який завершується вибухом або розплавленням кристала.

Під час імпульсного тесту тривалістю 300 мкс замість повного теплового опору `R_th_total = 20 °C/Вт` діє крихітний імпульсний імпеданс `Z_th(300 мкс) = 0.078 °C/Вт`. Завдяки цьому критичний струм стійкості в імпульсі виявляється в 16 разів вищим, ніж у безперервному режимі:

```
I_stable_pulse = I_max_stable · √(R_th_total / Z_th(300 мкс))
               = I_max_stable · √(20 / 0.078)
               ≈ 16 · I_max_stable
```

Саме тому транзистор, який у паспорті демонструє стабільну роботу при струмі 100 А під час короткого імпульсу, в реальній схемі зазнає незворотного теплового руйнування вже при 25 А без масивного примусового охолодження.

### Практичний розрахунок еквівалентного теплового опору при ШІМ-комутації

У реальних перетворювачах транзистор працює в режимі широтно-імпульсної модуляції (ШІМ) з періодом `T_period = 10 мкс` (частота 100 кГц) та шпаруватістю `D = t_on / T_period = 0.5`.

Для високих частот комутації (частота вище 10 кГц) період комутації `10 мкс` значно менший за теплову сталу часу кристала `500 мкс`. У цьому випадку пульсації температури переходу навколо середнього значення не перевищують десятих часток градуса. Еквівалентна температура переходу розраховується за середньою потужністю втрат за період:

```
P_avg = D · P_on + (1 − D) · P_off + P_switching   [середня потужність втрат за період]
T_j_avg = T_ambient + P_avg · R_th_total           [середня температура кристала]
```

Таким чином, імпульсні параметри з даташита дають точні характеристики транзистора в активній фазі комутації `t_on`, але тепловий режим схеми повинен проектуватися строго за інтегральною середньою потужністю `P_avg` та стаціонарним тепловим опором `R_th_total`. Це гарантує надійну безаварійну роботу силового каскаду за будь-яких умов експлуатації.
