# 🧮 Електростатика вістря: коефіцієнт підсилення поля та поріг пробою

Друкований іскровий розрядник на платі суттєво відрізняється від плоского повітряного конденсатора: його електроди навмисно роблять гострими. У плоскому зазорі електричне поле однорідне, і для початку ударної іонізації потрібна висока середня напруженість по всій довжині зазору. На гострому ж вістрі вільні заряди концентруються на мінімальній площі, створюючи локальний сплеск напруженості електричного поля, який у рази перевищує середнє значення в проміжку. Це дозволяє запалити розряд при значно меншій різниці потенціалів.

Нижче наведено строгий математичний аналіз розподілу потенціалу навколо витягнутого вістря, виведення коефіцієнта геометрії, критерій лавинного пробою Міка–Ретера, оцінка автоелектронної емісії та числові розрахунки для типових параметрів друкованої плати.

### Модель гіперболоїдного вістря над площиною

Для аналітичного розрахунку форми трикутного мідного зубця на площині використовують модель витягнутого еліпсоїда або гіперболоїда обертання з радіусом кривини кінчика `r_tip` на відстані `d` від протилежного електрода.

Рівняння Лапласа для електростатичного потенціалу `φ` за відсутності об'ємного заряду:

```
∇²φ = 0      [рівняння Лапласа в діелектрику]
```

Вільний простір між вістрям і площиною зручно описати у витягнутих сфероїдальних (пролатних) координатах `(η, ξ, ψ)`, де поверхні сталого `η` утворюють сімейство співфокусних гіперболоїдів, а `ξ` — співфокусних еліпсоїдів. Поверхня вістря задається координатою `η = η₀`, а протилежна площина (або симетричне зустрічне вістря) — `η = 0`.

Розв'язок рівняння Лапласа з граничними умовами `φ(η₀) = U` та `φ(0) = 0` виражається інтегралом:

```
φ(η) = U · ln((1 + η) / (1 - η)) ÷ ln((1 + η₀) / (1 - η₀))      [потенціал у просторі координат]
```

Для тонкого вістря з малим радіусом заокруглення `r_tip << d` параметр фокальної відстані пов'язаний із геометрією зазору співвідношенням:

```
1 - η₀ ≈ r_tip / (2 · d)      [геометричне наближення для гострого вістря]
```

Напруженість електричного поля `E` є градієнтом потенціалу:

```
E(x) = -∇φ      [зв'язок напруженості та потенціалу]
```

Максимальна напруженість поля досягається безпосередньо на вершині вістря (`x = 0`, радіус кривини `r_tip`). Підставляючи просторову похідну та переходячи до фізичних координат відстані `d` і радіуса `r_tip`:

```
E_max = (2 · U) ÷ (r_tip · ln(4 · d / r_tip))      [максимальне поле на вістрі]
```

### Конформне відображення для плоского 2D-клина на платі

Реальний друкований зубець на склотекстоліті є планарною структурою товщиною `t_cu` (типово 18 або 35 мкм для 1 oz міді). Двовимірний розподіл поля біля клина з кутом при вершині `2θ` розраховують за допомогою конформного відображення Шварца–Крістоффеля, що переводить верхню півплощину комплексної площини `w` у зовнішню область клина на площині `z`:

```
z(w) = C · ∫ (w² - 1)^(θ / π - 1/2) dw      [інтеграл Шварца–Крістоффеля]
```

Густина поверхневого заряду `σ(r)` на відстані `r` від вершини клина описується степеневим законом із показником сингулярності:

```
n = (π - 2θ) / (2π - 2θ)      [показник сингулярності заряду на клині]
```

Для гострого трикутного зубця з кутом розкриву `2θ = 60°` (`π/3` радіан):

```
n = (π - π/3) / (2π - π/3)
= (2π/3) / (5π/3)
= 2/5 = 0.40      [сингулярність для кута 60 градусів]
```

Для гострішого кута `2θ = 30°` (`π/6` радіан):

```
n = (π - π/6) / (2π - π/6)
= (5π/6) / (11π/6)
= 5/11 ≈ 0.4545      [сингулярність для кута 30 градусів]
```

Відповідно, напруженість електричного поля біля вершини зростає за законом:

```
E(r) ∝ r^(-n)      [зростання поля при наближенні до вершини r -> 0]
```

У фізичній реальності сингулярність не прямує до нескінченності, а обмежується радіусом заокруглення кінчика `r_tip`, який утворюється в процесі хімічного травлення мідної фольги розчином хлорного заліза або персульфату амонію.

### Коефіцієнт підсилення електричного поля

Середнє (номінальне) електричне поле `E_avg` у зазорі `d` за прикладеної напруги `U` визначається як для плоского конденсатора:

```
E_avg = U / d      [середня напруженість у зазорі]
```

Коефіцієнт геометричного підсилення поля `β` (field enhancement factor) показує, у скільки разів локальне поле на вістрі перевищує середнє поле однорідного зазору:

```
β = E_max / E_avg      [визначення коефіцієнта підсилення]
```

Підставляючи вираз для `E_max`:

```
β = [ (2 · U) ÷ (r_tip · ln(4 · d / r_tip)) ] ÷ (U / d)
= (2 · d) ÷ (r_tip · ln(4 · d / r_tip))      [формула коефіцієнта підсилення вістря]
```

Для зустрічних трикутних шевронів (два однакових вістря, що дивляться одне на одне через зазор `d`) концентрація відбувається на обох кінчиках. У цьому випадку наближена інженерна формула враховує взаємний вплив протилежного вістря:

```
β_pair ≈ d ÷ (r_tip · ln(2 · d / r_tip))      [коефіцієнт для пари зустрічних вістрів]
```

#### Розрахунок коефіцієнта β для типових параметрів плати

Візьмемо стандартний зазор друкованого іскровика `d = 0.3` мм (`300` мкм). Радіус вістря залежить від технології хімічного травлення міді:
- Свіжовитруєне гостре вістря (товщина фольги 35 мкм): `r_tip = 25` мкм (`0.025` мм);
- Згладжене або оплавлене припоєм вістря (HASL): `r_tip = 80` мкм (`0.080` мм);
- Зношене після багаторазових дуг вістря: `r_tip = 150` мкм (`0.150` мм).

Покроковий розрахунок для `r_tip = 25` мкм:

```
4 · d / r_tip
= 4 · 300 / 25
= 48      [відношення геометрії]

ln(48)
= 3.8712      [логарифмічний множник]

β = (2 · 300) / (25 · 3.8712)
= 600 / 96.78
= 6.20      [коефіцієнт підсилення поля гострого вістря]
```

Для `r_tip = 80` мкм (покриття HASL):

```
4 · d / r_tip
= 4 · 300 / 80
= 15      [відношення геометрії]

ln(15)
= 2.708      [логарифмічний множник]

β = (2 · 300) / (80 · 2.708)
= 600 / 216.64
= 2.77      [підсилення поля згладженого вістря]
```

Гострий мідний зубець концентрує поле у 6.2 раза сильніше, ніж плоский електрод. Це означає, що локальне поле досягне критичного порогу іонізації при вшестеро меншій напрузі на клемах.

### Критерій лавинного та стримерного пробою

В однорідному полі пробій газу описується критерієм Таунсенда, де кожен електрон на шляху `d` породжує лавину за рахунок коефіцієнта ударної іонізації `α(E)`:

```
γ · (exp(α · d) - 1) = 1      [критерій самопідтримуваного розряду Таунсенда]
```

де `γ` — коефіцієнт вторинної емісії електронів з катода під дією іонного бомбардування.

У сильно неоднорідному полі вістря напруженість `E(x)` швидко спадає з відстанню `x` від вершини зубця. Залежність коефіцієнта іонізації Таунсенда від локального поля `E` описується емпіричною формулою:

```
α(E) = A · p · exp(-B · p / E)      [перший коефіцієнт Таунсенда для повітря]
```

де для сухого атмосферного повітря за нормального тиску `p = 760` мм рт. ст. (`101.3` кПа):
- `A = 15` см⁻¹ · Торр⁻¹ = `0.01125` В⁻¹;
- `B = 365` В / (см · Торр) = `27.37` кВ/мм.

Оскільки поле високе лише поблизу вістря, електронна лавина розвивається в зоні максимального поля. Коли кількість електронів у голівці первинної лавини досягає критичного значення `N_crit ≈ 10⁸` (число Міка), власний просторовий заряд лавини стає порівнянним із зовнішнім полем. Лавина миттєво перетворюється на самопропагуючий плазмовий канал — стример.

Критерій стримерного пробою Міка–Ретера в неоднорідному полі:

```
∫ α(E(x)) dx = K      [інтегральний критерій стримера від x=0 до x=x_crit]
```

де константа `K ≈ ln(10⁸) ≈ 18.42`, а `x_crit` — межа зони іонізації, де `E(x)` спадає нижче діелектричної міцності повітря `E_crit ≈ 3.0` кВ/мм.

### Оцінка ролі автоелектронної емісії Фаулера–Нордгейма

Чи виникає автоелектронна емісія (холодна емісія електронів за рахунок квантового тунелювання крізь поверхневий потенціальний бар'єр металу) на вістрі друкованого розрядника?

Густина струму польової емісії описується рівнянням Фаулера–Нордгейма:

```
J_FN = C_1 · E² · exp(-C_2 · Φ^(3/2) / E)      [рівняння Фаулера–Нордгейма]
```

де `Φ` — робота виходу електрона з металу (для чистої міді `Φ ≈ 4.65` еВ, для золотого покриття ENIG `Φ ≈ 5.1` еВ), а коефіцієнти становлять `C_1 ≈ 1.54 · 10⁻⁶` А/В² та `C_2 ≈ 6.83 · 10⁹` В / (еВ^(3/2) · м).

Підставимо напруженість поля, що виникає на вістрі розрядника при напрузі `U = 1000` В для `d = 0.3` мм (`E_max ≈ 2 · 10⁷` В/м = `0.02` В/нм):

```
C_2 · Φ^(3/2) / E_max
= (6.83 · 10⁹ · 4.65^(1.5)) / (2 · 10⁷)
= (6.83 · 10⁹ · 10.03) / (2 · 10⁷)
= 6.85 · 10¹⁰ / (2 · 10⁷)
≈ 3425      [показник експоненти]

exp(-3425) ≈ 0      [струм квантового тунелювання зникаюче малий]
```

Польова автоелектронна емісія стає помітною (`J > 10⁻⁶` А/м²) лише за напруженостей поля `E > 10⁹` В/м (1 В/нм). На друкованих платах із мікрозазорами в сотні мікрометрів напруженість поля на 2–3 порядки нижча за цей поріг.

Це означає, що ініціація розряду на друкованій платі відбувається **виключно за рахунок газової іонізації та стримерного механізму**, а не за рахунок виривання електронів із кристалічної решітки міді електричним полем.

### Паразитна ємність друкованого розрядника

Оскільки іскровий проміжок підключається паралельно до сигнальної лінії, його власна статична ємність `C_gap` шунтує високочастотний сигнал.

Аналітичний розрахунок ємності між двома коаксіальними або зустрічними витягнутими клинами:

```
C_gap ≈ (π · ε_r · ε₀ · t_cu) ÷ ln(4 · d / w_base)      [статична ємність зазору]
```

де `ε₀ = 8.854 · 10⁻¹²` Ф/м — електрична стала, `ε_r ≈ 1.0` — діелектрична проникність повітря, `t_cu = 35` мкм — товщина мідної фольги, `w_base = 0.5` мм — ширина основи зубця, `d = 0.3` мм — зазор.

Покроковий розрахунок:

```
4 · d / w_base
= 4 · 0.3 / 0.5
= 2.4      [геометричний аргумент]

ln(2.4) = 0.8755      [знаменник]

C_gap = (3.14159 · 1.0 · 8.854 · 10⁻¹² · 35 · 10⁻⁶) / 0.8755
= (9.735 · 10⁻¹⁶) / 0.8755
≈ 1.11 · 10⁻¹⁵ Ф = 0.0011 пФ      [ємність повітряного зазору]
```

З урахуванням крайового поля через склотекстоліт підкладки FR-4 (`ε_r ≈ 4.4`) сумарна паразитна ємність одиночного шеврона становить не більше **`0.02–0.04 пФ`**.

Для порівняння:
- Напівпровідниковий TVS-діод загального призначення: `C_tvs ≈ 15 ... 50` пФ;
- Спеціалізований ультранизькоємнісний TVS-діод (Ultra-low cap): `C_tvs ≈ 0.2 ... 0.5` пФ;
- Керамічний газорозрядник GDT: `C_gdt ≈ 0.5 ... 1.5` пФ;
- Друкований одиночний іскровик: **`C_gap < 0.04 пФ`**.

Завдяки ємності менше 0.05 пФ друкований іскровий розрядник практично не вносить фазових спотворень і не обмежує смугу пропускання навіть на частотах 10–25 ГГц (інтерфейси PCIe 4.0/5.0, USB4, HDMI 2.1).

### Вплив навколишнього середовища: тиск, температура та вологість

Діелектрична міцність повітряного проміжку не є абсолютною константою. Коефіцієнт іонізації `α` безпосередньо залежить від густини газу `δ`, яка визначається відношенням атмосферного тиску `p` до абсолютної температури `T`:

```
δ = (p / p₀) · (T₀ / T)      [відносна густина повітря]
```

де `p₀ = 101.325` кПа (760 Торр), `T₀ = 293.15` К (+20 °C).

Напруженість поля пробою масштабується пропорційно густині газу:

```
E_crit(p, T) = E_crit_0 · δ      [корекція міцності повітря за густиною]
```

На висоті 2000 метрів над рівнем моря атмосферний тиск падає до `p ≈ 79.5` кПа (`δ ≈ 0.784` за температури 20 °C). Пробивна напруга того самого друкованого іскровика знижується на **21.6%**: прилад, розрахований на спрацювання при 1500 В на рівні моря, у високогірних умовах пробиватиметься вже при **1175 В**.

Вологість повітря діє протилежним чином: молекули водяної пари `H₂O` мають високу спорідненість до електронів. Захоплюючи вільні електрони та перетворюючи їх на важкі негативні іони з низькою рухливістю, волога сповільнює розвиток первинних електронних лавин. При підвищенні відносної вологості від 20% до 80% за температури 25 °C статична напруга пробою повітряного зазору зростає на **8–12%**.

### Порівняльний розрахунок напруги спрацювання для різних зазорів

### Фізична межа Пашена для мікрозазорів

Часто виникає ідея: якщо зменшувати зазор `d` на платі (наприклад, за допомогою лазерного прецизійного різання до 0.05 мм або 0.01 мм), чи можна отримати друкований розрядник із напругою спрацювання 100 В або 50 В для прямого захисту цифрових ліній 3.3 В чи 5 В?

Закон Пашена дає однозначну негативну відповідь. Функція напруги пробою від добутку тиску на зазор `(p · d)`:

```
U_breakdown = (B · p · d) ÷ [ ln(A · p · d) - ln(ln(1 + 1/γ)) ]      [закон Пашена]
```

Функція має глобальний абсолютний мінімум — точку Пашена:

```
(p · d)_min ≈ 0.57 Торр · см = 7.6 · 10⁻⁴ атм · см ≈ 7.6 мкм за нормального тиску
U_min ≈ 327 В      [абсолютний мінімум пробою в повітрі]
```

Нижче напруги `U_min ≈ 327 В` пробити атмосферне повітря за нормальних умов **неможливо за жодного зазору**. При зменшенні зазору нижче 7.6 мкм кількість зіткнень електронів з атомами газу на дистанції між електродами стає недостатньою для утворення лавини, і крива Пашена стрімко злітає вгору.

Тому будь-який друкований розрядник на платі за атмосферного тиску принципово не може мати поріг пробою нижче приблизно **400–500 В**.

### Зміна параметрів під час експлуатації (ерозія вістря)

Кожен електричний розряд випалює мікроскопічну кількість міді з вершини вістря через надвисоку густину енергії в точці контакту дуги.

Якщо внаслідок серії імпульсів радіус кінчика збільшується від `r_tip = 25` мкм до `r_tip = 120` мкм (вістря округлюється):

```
4 · d / r_tip
= 4 · 300 / 120
= 10      [нове відношення]

ln(10)
= 2.3026      [новий логарифмічний множник]

β_worn = (2 · 300) / (120 · 2.3026)
= 600 / 276.31
= 2.17      [деградований коефіцієнт підсилення]
```

Коефіцієнт підсилення поля падає з `6.20` до `2.17`. Відповідно, напруга спрацювання розрядника зростає:

```
ΔU_spark = U_spark_worn - U_spark_initial
≈ 1100 В - 750 В
= +350 В      [дрейф порогу пробою в бік підвищення]
```

Цей дрейф є фундаментальною математичною та фізичною властивістю друкованих розрядників: зі збільшенням кількості спрацьовувань гострота вістря втрачається, розрядник стає «тупим», а напруга його пробою наближається до напруги плоских електродів.
