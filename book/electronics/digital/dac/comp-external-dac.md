# 🔌 Зовнішній ЦАП MCP4725-класу (I²C): коли вбудованого бракує

> Компонентна вставка до теми [«Справжній ЦАП (DAC)»](book:electronics/dac). Вбудований ЦАП ESP32 має межі: 8 біт, два канали, слабкий вихід — а на S3/C3/C6 його взагалі нема. Зовнішній ЦАП по I²C знімає всі чотири обмеження одразу.

## Що це за деталь

Вбудований ЦАП ESP32 дає лише 8 біт роздільної здатності (256 рівнів), обмежений двома каналами і слабким вихідним струмом. На чипах S3, C3 і C6 він взагалі відсутній — там є лише ШІМ. Коли цих можливостей вже не вистачає, беруть окремий чип-ЦАП (digital-to-analog converter, DAC), що слухається по шині I²C і віддає один чистий аналоговий вихід Vout.

Канонічний вибір — **MCP4725-клас**: 12-бітний (4096 рівнів) одноканальний ЦАП по I²C з вбудованою EEPROM. Є споріднений 10-бітний **MCP4726** із програмованим підсиленням — про нього в розділі «Варіації».

Ключова перевага в числах: 12 біт проти 8 — це крок у 16 разів дрібніший. При опорній напрузі (Vref) = VCC = 3.3 В крок ≈ 3.3 / 4095 ≈ **0.8 мВ** проти ≈ 13 мВ у [вбудованого ЦАП](book:electronics/dac). На практиці це різниця між «сходинку видно» і «сходинку не видно».

Друга особливість класу — вбудована **EEPROM**: чип запам'ятовує задане значення і виставляє його на виході одразу при подачі живлення, ще до першого слова від мікроконтролера. Якщо пристрій повинен «знати» вже при вмиканні, яку напругу подавати, — MCP4725 забезпечить це без жодного коду ініціалізації.

## Розпіновка й підключення

Назовні — знайома картина I²C плюс єдиний аналоговий вивід (той самий принцип, що й в інших I²C-модулів — для впізнаваності):

```
VCC, GND   — живлення (воно ж Vref: вихід масштабується від 0 до VCC)
SDA, SCL   — шина I²C (спільна, з підтяжками)
A0         — молодший біт адреси: 0x60 (A0=GND) або 0x61 (A0=VCC)
OUT (Vout) — аналоговий вихід ЦАП, 0…VCC
```

Лінії I²C спільні з рештою пристроїв на шині: підтяжки 4.7 кОм на SDA/SCL вішаються один раз на всю шину. Живлення водночас слугує Vref — тому стабільність VCC безпосередньо визначає точність виходу: брудна мережа → брудна напруга на OUT.

Вивід OUT дає справжню напругу прямо на вхід — без жодного RC-фільтра, на відміну від [«ЦАП для бідних»](book:electronics/rc-filter), де імпульси треба згладжувати конденсатором.

Варто також пам'ятати: лише молодший біт A0 задає адресу, тож на одній шині може бути **максимум два** чипи MCP4725 (0x60 / 0x61). Багато інших I²C-чипів мають по три адресні біти й допускають вісім екземплярів на шині — у MCP4725 адресний простір помітно тісніший. Якщо потрібні одразу чотири аналогових канали, є вихід — MCP4728 (деталі у «Варіаціях»).

## Перший байт

Найважливіший момент — як заговорити з чипом. MCP4725 підтримує «fast write» — мінімальну транзакцію, що оновлює вихід за один I²C-обмін. Чип отримує адресу 0x60, а за нею два байти, де упаковані всі 12 біт нового значення. Старші 4 біти йдуть у молодший ніббл першого байта (два верхні біти якого — нулі, що власне й означає режим «fast write»), решта 8 — цілком у другому байті:

```
старт → адреса 0x60+W
байт1:  0 0 D11 D10 D9 D8   (два старші біти режиму = 0 → fast write)
байт2:  D7 D6 D5 D4 D3 D2 D1 D0
стоп
```

Реальний C/C++ для ESP32 (бібліотека Arduino `Wire`):

```cpp
#include <Wire.h>
const uint8_t DAC = 0x60;        // MCP4725, A0=GND

void dacSet(uint16_t v) {        // v: 0..4095 (12 біт)
    v &= 0x0FFF;
    Wire.beginTransmission(DAC);
    Wire.write(v >> 8);           // fast-write: старші 4 біти
    Wire.write(v & 0xFF);        // молодші 8 біт
    Wire.endTransmission();
}

void setup() {
    Wire.begin();                 // SDA=21, SCL=22 на класичному ESP32
    dacSet(2048);                 // ≈ половина шкали ≈ 1.65 В
}
void loop() {}
```

Одна транзакція — нове значення: мікроконтролер пише, чип негайно переводить вихід на нову напругу. Це оновлення RAM-регістра чипа; для запису в EEPROM (щоб значення збереглося після вимкнення й виставилося самостійно при наступному старті) використовується довша команда з іншим кодом у керівному байті — вона існує, але тут не потрібна, щоб не виходити за обсяг вставки.

## Типові граблі

- **Vref = VCC, тож шум живлення = шум на виході.** На відміну від ЦАП з окремим точним Vref, MCP4725 масштабує від VCC; брудні 3.3 В — брудний аналог. Хочеш точності — стабілізуй живлення і клади розв'язувальний конденсатор 100 нФ прямо біля чипа.

- **Слабкий вихід — та сама проблема, що й у [вбудованого ЦАП](book:electronics/dac).** OUT буферований, але слабкий на струм: високоомний вхід АЦП тягне без проблем, а реальне навантаження (світлодіод, навушник) просадить напругу. Потрібен зовнішній буфер-повторювач на операційному підсилювачі. 12 біт точності марні, якщо вихід просів під навантаженням.

- **Знос EEPROM.** Запис у EEPROM має скінченний ресурс — десятки–сотні тисяч циклів. Класична помилка — писати в EEPROM у швидкому циклі замість fast-write у RAM-регістр. Для «живого» сигналу, що змінюється постійно, — виключно fast-write.

- **Адресний конфлікт / тіснота.** Лише два MCP4725 (0x60/0x61) на шині; адреса 0x60 часто збігається з іншими I²C-пристроями — перевір карту адрес своєї шини перед монтажем.

- **Темп шини = стеля частоти сигналу.** Кожне нове значення — це повна I²C-транзакція (десятки мікросекунд навіть на 400 кГц). Для звукової хвилі (тисячі відліків/с) шина стає вузьким місцем — це принципово не [I2S](book:electronics/dac) (де потік великий). MCP4725 чудово підходить для повільних і опорних напруг, але не для аудіопотоку.

## Варіації класу

**MCP4725** — еталон класу: 12 біт, один канал, I²C, EEPROM. **MCP4726** — те саме з програмованим підсиленням і опціями Vref. **MCP4728** — чотири канали по 12 біт в одному корпусі плюс внутрішнє опорне 2.048 В: Vref більше не залежить від VCC, кілька незалежних аналогових виходів — в одному чипі. **MCP4921/4922-клас** — 12 біт, але по SPI: швидше (ціною окремого CS), коли темп I²C замалий. Критерій вибору: скільки каналів, чи потрібне стабільне Vref, і яка шина — I²C (менше виводів) чи SPI (вища швидкість).

Зовнішній I²C-ЦАП розширює правий стовпець вибору [«ЦАП проти ШІМ»](book:electronics/dac) — справжня напруга там, де вбудованого замало або де його нема зовсім.
