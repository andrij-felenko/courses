# 🧮 Виведення напруги зсуву та температурного дрейфу диференційного каскаду

Коли на обидва входи симетричного диференційного каскаду подано однаковий потенціал, колекторні або стокові струми двох плечей усе одно трохи різняться. Щоб на виході встановився точний нуль напруги, між базами або затворами доводиться прикласти компенсуючу різницю потенціалів. Ця величина є напругою зсуву (англ. *input offset voltage*, `V_os`), а її зміна при нагріванні чи охолодженні — температурним дрейфом (`dV_os/dT`). Нижче наведено повні аналітичні виведення для біполярних, польових (MOSFET) та польових із p-n переходом (JFET) диференційних каскадів із детальним математичним розбором впливу активних навантажень, струмових дзеркал, ефекту Ерлі, синфазного сигналу, нестабільності шин живлення, залишкового зсуву комутованих кіл, статистичного розподілу у виробництві та термоелектричних градієнтів.

---

### 1. Біполярна диференційна пара: виведення формули Vos

Розглянемо класичний диференційний каскад на парі транзисторів типу n-p-n `Q1` та `Q2` зі спільним емітерним джерелом струму `I_хв` і колекторними резисторами навантаження `R_C1` та `R_C2`.

Зв'язок між колекторним струмом `I_C` та напругою база-емітер `V_BE` у нормальному активному режимі описується рівнянням Еберса-Молла:

```
I_C = I_S · exp(V_BE / V_T)
```

де `I_S` — зворотний струм насичення переходу емітер-база, пропорційний площі емітера `A_E` та коефіцієнту дифузії неосновних носіїв, а `V_T = k_B · T / q` — температурний потенціал (при кімнатній температурі `T = 300 К` величина `V_T ≈ 25.86 мВ`).

Виразимо напругу `V_BE` через струм колектора:

```
V_BE = V_T · ln(I_C / I_S)
```

Напруга зсуву `V_os` за означенням є такою різницею вхідних напруг `V_in1 − V_in2 = V_BE1 − V_BE2`, за якої диференційна напруга на колекторах дорівнює нулю (`V_C1 = V_C2`):

```
V_CC − I_C1 · R_C1 = V_CC − I_C2 · R_C2
= I_C1 · R_C1 = I_C2 · R_C2             [відняли V_CC від обох частин]
= I_C1 / I_C2 = R_C2 / R_C1             [поділили на добуток I_C2 · R_C1]
```

Запишемо різницю напруг база-емітер:

```
V_os = V_BE1 − V_BE2
= V_T · ln(I_C1 / I_S1) − V_T · ln(I_C2 / I_S2)           [підставили вираз для V_BE]
= V_T · (ln(I_C1 / I_S1) − ln(I_C2 / I_S2))               [винесли спільний множник V_T]
= V_T · ln((I_C1 / I_C2) · (I_S2 / I_S1))                 [властивість логарифма: ln(a) − ln(b) = ln(a/b)]
= V_T · ln((R_C2 / R_C1) · (I_S2 / I_S1))                 [підставили умову балансу I_C1 / I_C2 = R_C2 / R_C1]
= V_T · ln(R_C2 / R_C1) + V_T · ln(I_S2 / I_S1)           [властивість логарифма: ln(a·b) = ln(a) + ln(b)]
```

Введемо середні значення величин та їхні малі технологічні розбіжності:

```
I_S = (I_S1 + I_S2) / 2
ΔI_S = I_S1 − I_S2

R_C = (R_C1 + R_C2) / 2
ΔR_C = R_C1 − R_C2
```

Тоді відношення записуються через відносні прирости:

```
I_S2 / I_S1 = (I_S − ΔI_S / 2) / (I_S + ΔI_S / 2)
= (1 − ΔI_S / (2 · I_S)) / (1 + ΔI_S / (2 · I_S))         [поділили чисельник і знаменник на середнє I_S]
≈ (1 − ΔI_S / (2 · I_S)) · (1 − ΔI_S / (2 · I_S))         [розклад 1/(1+x) ≈ 1−x для малих величин]
≈ 1 − ΔI_S / I_S                                          [знехтували доданком другого порядку (ΔI_S/I_S)²]

R_C2 / R_C1 = (R_C − ΔR_C / 2) / (R_C + ΔR_C / 2)
= (1 − ΔR_C / (2 · R_C)) / (1 + ΔR_C / (2 · R_C))         [поділили чисельник і знаменник на середнє R_C]
≈ 1 − ΔR_C / R_C                                          [лінеаризація першого порядку для малих розкидів]
```

Застосовуючи наближення Тейлора для логарифма `ln(1 − x) ≈ −x`:

```
ln(I_S2 / I_S1) ≈ ln(1 − ΔI_S / I_S) ≈ −ΔI_S / I_S
ln(R_C2 / R_C1) ≈ ln(1 − ΔR_C / R_C) ≈ −ΔR_C / R_C
```

Підставляючи отримані наближення у вираз для `V_os`:

```
V_os = V_T · (−ΔI_S / I_S − ΔR_C / R_C)
= −V_T · (ΔI_S / I_S + ΔR_C / R_C)                        [винесли мінус за дужки]
```

Модуль вхідної напруги зсуву біполярного диференційного каскаду дорівнює:

```
|V_os| = V_T · (ΔI_S / I_S + ΔR_C / R_C)
```

Вхідний зсув прямо пропорційний абсолютному температурному потенціалу `V_T` та сумі двох технологічних неоднорідностей кристала: відносному розкиду струмів насичення `ΔI_S / I_S` (визначається площею емітерних вікон і глибиною дифузії) та відносному розкиду колекторних навантажень `ΔR_C / R_C` (визначається шириною й опором інтегрованих резисторів).

### 2. Виведення температурного дрейфу dVos/dT

Температурний дрейф напруги зсуву характеризує стабільність робочої точки схеми при зміні абсолютної температури `T`.

Продиференціюємо точний вираз для зсуву `V_os = V_T · ln((R_C2 / R_C1) · (I_S2 / I_S1))` за температурою `T`:

```
dV_os / dT = d/dT [ (k_B · T / q) · ln((R_C2 / R_C1) · (I_S2 / I_S1)) ]
```

Оскільки відношення інтегрованих резисторів `R_C2 / R_C1` та площ емітерів `I_S2 / I_S1` задаються геометрією фотошаблонів і топологією кристала, їхні температурні коефіцієнти однакові й взаємно компенсуються в логарифмі:

```
d/dT [ ln((R_C2 / R_C1) · (I_S2 / I_S1)) ] ≈ 0
```

Тому диференціюванню підлягає лише множник `V_T`:

```
dV_T / dT = d/dT (k_B · T / q) = k_B / q = V_T / T
```

Підставляючи похідну:

```
dV_os / dT = (k_B / q) · ln((R_C2 / R_C1) · (I_S2 / I_S1))
= (V_T / T) · ln((R_C2 / R_C1) · (I_S2 / I_S1))           [підставили k_B / q = V_T / T]
= (1 / T) · [ V_T · ln((R_C2 / R_C1) · (I_S2 / I_S1)) ]   [перегрупували множники]
= V_os / T                                                [застосували вихідне означення V_os]
```

Це співвідношення є ключовим для некомпенсованих диференційних каскадів: **теоретичний температурний дрейф біполярної диференційної пари прямо пропорційний її початковій напрузі зсуву й обернено пропорційний абсолютній температурі**.

За нормальної кімнатної температури `T = 300 К` (`+26.85 °C`):

```
dV_os / dT = V_os / 300 К
= (1 мВ) / 300 К                                          [для каскаду з початковим зсувом 1 мВ]
≈ 3.33 мкВ / К = 3.33 мкВ / °C
```

Якщо підсилювач має початковий зсув `3 мВ`, його дрейф становитиме близько `10 мкВ / °C`. Для досягнення дрейфу нижче `0.5 мкВ / °C` власний нескомпенсований зсув каскаду не повинен перевищувати `150 мкВ`.

### 3. Механізм погіршення дрейфу при ручному балансуванні потенціометром

У багатьох операційних підсилювачах загального призначення (зокрема LM741, OP07) передбачено виводи балансування зсуву (Offset Null), до яких підключають зовнішній змінний резистор. Повзунок потенціометра з'єднують із шиною негативного живлення, регулюючи поділ емітерних струмів.

При цьому рівність колекторних напруг досягається за рахунок штучної розбалансировки струмів колекторів `I_C1 ≠ I_C2`:

```
V_os(T) = V_T · ln(I_S2 / I_S1) + V_T · ln(I_C1 / I_C2)
```

Налаштовуючи потенціометр за температури `T_0`, оператор домагається `V_os(T_0) = 0`, що означає виконання умови:

```
ln(I_C1 / I_C2) = −ln(I_S2 / I_S1)
```

Однак напруга база-емітер біполярного транзистора має власний температурний коефіцієнт:

```
d(V_BE) / dT = (V_BE − V_g0) / T − 3 · (k_B / q)
```

де `V_g0 ≈ 1.205 В` — ширина забороненої зони кремнію, екстрапольована до нуля Кельвіна.

Коли струми `I_C1` та `I_C2` зроблені нерівними, похідні `dV_BE1/dT` та `dV_BE2/dT` перестають компенсувати одна одну:

```
d(V_BE1 − V_BE2) / dT = (k_B / q) · ln(I_C1 / I_C2)
```

Підставляючи умову обнулення зсуву `ln(I_C1 / I_C2) = −V_os(початковий) / V_T(T_0)`:

```
dV_os / dT = (k_B / q) · [ −V_os(початковий) / (k_B · T_0 / q) ]
= −V_os(початковий) / T_0
```

Якщо підсилювач із початковим зсувом `V_os = 6 мВ` збалансувати в нуль зовнішнім потенціометром за `T_0 = 300 К`, то при `25 °C` напруга зсуву дорівнюватиме `0 мкВ`, проте температурний дрейф становитиме:

```
|dV_os / dT| = 6 мВ / 300 К = 20 мкВ / °C
```

Зміна робочої температури всього на `5 °C` спричинить появу паразитної напруги зсуву `100 мкВ`. Саме тому в сучасних високоточних мікросхемах балансування виконують лазерним підрізанням внутрішніх плівкових резисторів без порушення рівності робочих струмів активних транзисторів.

### 4. Диференційний каскад із активним навантаженням (струмовим дзеркалом)

У більшості інтегральних ОП замість пасивних резисторів `R_C` застосовують активне навантаження у вигляді струмового дзеркала на p-n-p (або p-канальних МОН) транзисторах `Q3` і `Q4`.

Вихідне струмове дзеркало має власний коефіцієнт передачі струму `k_m = I_out / I_in = I_C4 / I_C3`. За ідеальної симетрії транзисторів дзеркала `k_m = 1`. Через технологічний розкид площ емітерів `p-n-p` транзисторів `I_S3 ≠ I_S4` коефіцієнт передачі відхиляється на величину `Δk_m = (I_S4 − I_S3) / I_S3 = ΔI_Sp / I_Sp`.

Умова балансу диференційного каскаду полягає в нульовому вихідному струмі у наступний каскад:

```
I_C2 − I_C4 = 0
= I_C2 = I_C4                           [перенесли I_C4 праворуч]
= I_C2 = k_m · I_C1                     [підставили зв'язок дзеркала I_C4 = k_m · I_C1]
= I_C1 / I_C2 = 1 / k_m                 [виразили відношення струмів вхідної пари]
```

Підставляючи це співвідношення у формулу вхідного зсуву:

```
V_os = V_T · ln((I_C1 / I_C2) · (I_S2 / I_S1))
= V_T · ln((1 / k_m) · (I_S2 / I_S1))   [підставили умову балансу струмів]
= V_T · [ −ln(k_m) + ln(I_S2 / I_S1) ]  [властивість логарифма: ln(a/b) = ln(a) − ln(b)]
≈ −V_T · [ Δk_m + ΔI_Sn / I_Sn ]        [лінеаризація логарифмів малих розкидів]
= −V_T · [ ΔI_Sp / I_Sp + ΔI_Sn / I_Sn ] [підставили розкид струмового дзеркала]
```

За модулем сумарна напруга зсуву каскаду з активним навантаженням дорівнює:

```
|V_os| = V_T · (ΔI_Sn / I_Sn + ΔI_Sp / I_Sp)
```

Зсув каскаду з активним навантаженням визначається геометричним розкидом як вхідної n-p-n пари (`ΔI_Sn`), так і навантажувального p-n-p струмового дзеркала (`ΔI_Sp`). Оскільки інтегральні горизонтальні p-n-p транзистори історично мають гірше просторове узгодження (`ΔI_Sp / I_Sp ≈ 3–5 %`), саме струмове дзеркало часто робить домінуючий внесок у початковий зсув біполярного операційного підсилювача.

### 5. Польовий диференційний каскад (MOSFET): виведення Vos

Для n-канальної МОН-пари `M1` та `M2` у режимі насичення залежність струму стоку `I_D` від напруг затвор-витік `V_GS` і сток-витік `V_DS` описується рівнянням Шічмана-Ходжеса:

```
I_D = (1 / 2) · μ_n · C_ox · (W / L) · (V_GS − V_TH)² · (1 + λ · V_DS)
```

де `μ_n` — рухливість електронів, `C_ox` — питома ємність підзатворного оксиду, `W / L` — геометричний фактор каналу, `V_TH` — порогова напруга, `λ` — коефіцієнт модуляції довжини каналу.

Позначимо параметр крутизни як `β = μ_n · C_ox · (W / L)`. Нехтуючи модулюванням каналу (`λ ≈ 0`), виразимо напругу затвор-витік:

```
V_GS = V_TH + √(2 · I_D / β)
```

Напруга зсуву визначається як різниця напруг затворів `V_GS1 − V_GS2`, яка забезпечує рівність стокових потенціалів `V_D1 = V_D2` (тобто `I_D1 · R_D1 = I_D2 · R_D2`):

```
V_os = V_GS1 − V_GS2
= (V_TH1 − V_TH2) + (√(2 · I_D1 / β1) − √(2 · I_D2 / β2))
```

Введемо позначення малих технологічних асиметрій:

```
ΔV_TH = V_TH1 − V_TH2
Δβ = β1 − β2
ΔR_D = R_D1 − R_D2
```

Позначимо середню напругу перевантаження затвора (напругу насичення) як `V_OV = V_GS − V_TH = √(2 · I_D / β)`.

Розкладемо різницю квадратних коренів за формулою Тейлора:

```
√(2 · I_D1 / β1) − √(2 · I_D2 / β2)
= V_OV · [ √( (I_D1 / I_D) · (β / β1) ) − √( (I_D2 / I_D) · (β / β2) ) ]
≈ V_OV · [ (1/2) · (ΔI_D / I_D) − (1/2) · (Δβ / β) ]
= (V_OV / 2) · [ −(ΔR_D / R_D) − (Δ(W/L) / (W/L)) ]
```

Підставляючи отриманий вираз:

```
V_os = ΔV_TH − (V_OV / 2) · [ Δ(W/L) / (W/L) + ΔR_D / R_D ]
```

Повний вираз для напруги зсуву МОН-диференційного каскаду за модулем:

```
|V_os| = |ΔV_TH| + (V_OV / 2) · (Δ(W/L) / (W/L) + ΔR_D / R_D)
```

Порівняння біполярного та МОН-каскадів розкриває фізичну причину підвищеного зсуву польових підсилювачів:

1. **Доданок порогової напруги `ΔV_TH`:** У біполярному транзисторі `V_BE` визначається шириною забороненої зони кремнію, яка є фундаментальною фізичною константою. У МОН-транзисторі `V_TH` залежить від випадкових флуктуацій поверхневого заряду в підзатворному діелектрику та товщини оксиду `t_ox`. Розкид `ΔV_TH` типово становить `1–5 мВ`, що на порядок перевищує біполярний розкид `ΔV_BE`.
2. **Множник геометричного розкиду:** У біполярному транзисторі розкид `ΔR/R` множиться на `V_T ≈ 26 мВ`. У МОН-транзисторі розкид геометрії `Δ(W/L)` та резисторів навантаження множиться на половину напруги перевантаження `V_OV / 2 = (V_GS − V_TH) / 2 ≈ 100–250 мВ`. Це робить польовий каскад у 4–10 разів чутливішим до літографічних похибок геометрії.

### 6. Польовий диференційний каскад із p-n переходом (JFET): виведення Vos

Для каскаду на польових транзисторах із керуючим p-n переходом (JFET) у пологій області вольт-амперної характеристики струм стоку визначається квадратичним законом Шоклі:

```
I_D = I_DSS · (1 − V_GS / V_P)²
```

де `I_DSS` — початковий струм стоку при `V_GS = 0`, а `V_P` — напруга відсікання каналу (від'ємна для n-канального приладу).

Виразимо напругу затвор-витік `V_GS`:

```
1 − V_GS / V_P = √(I_D / I_DSS)
= V_GS = V_P · (1 − √(I_D / I_DSS))
```

Диференціюючи за параметрами `V_P`, `I_DSS`, `I_D`:

```
ΔV_GS = ΔV_P · (1 − √(I_D / I_DSS)) + V_P · d/d(I_D, I_DSS) [1 − √(I_D / I_DSS)]
= ΔV_P · (1 − √(I_D / I_DSS)) − V_P · (1 / (2 · √(I_D / I_DSS))) · (ΔI_D / I_DSS − I_D · ΔI_DSS / I_DSS²)
= ΔV_P · (1 − √(I_D / I_DSS)) − (V_P / 2) · √(I_D / I_DSS) · (ΔI_D / I_D − ΔI_DSS / I_DSS)
```

Враховуючи, що за умови балансу колекторних/стокових напруг `ΔI_D / I_D = −ΔR_D / R_D`, отримуємо вираз для вхідної напруги зсуву JFET-пари:

```
|V_os| = |ΔV_P| · (1 − √(I_D / I_DSS)) + (|V_P| / 2) · √(I_D / I_DSS) · (ΔI_DSS / I_DSS + ΔR_D / R_D)
```

Оскільки напруга відсікання `|V_P|` становить зазвичай від `0.5` до `3 В`, початковий зсув нескомпенсованих JFET-підсилювачів сягає `3–15 мВ`. Головною перевагою JFET залишається надзвичайно малий вхідний струм зсуву (пікоампери), проте за точністю `V_os` вони поступаються біполярним приладам.

### 7. Внесок кінцевого опору джерела струму та синфазний зсув (CMRR)

Реальне джерело струму в емітерах має скінченний вихідний диференційний опір `R_хв` (або `r_o` транзистора джерела струму).

При зміні вхідної синфазної напруги `V_cm` струм хвоста змінюється:

```
I_хв(V_cm) = I_хв0 + (V_cm − V_EE − V_BE) / R_хв
```

Зміна загального струму `ΔI_хв = ΔV_cm / R_хв` перерозподіляється між транзисторами пропорційно їхній асиметрії `ΔI_S / I_S`. Це викликає додатковий зсув робочої точки:

```
ΔV_os(CMR) = V_T · (ΔR_C / R_C) · (ΔI_хв / I_хв)
= V_T · (ΔR_C / R_C) · (ΔV_cm / (I_хв · R_хв))
```

Оскільки коефіцієнт придушення синфазного сигналу каскаду визначається як `CMRR = ΔV_cm / ΔV_os(CMR)`:

```
CMRR = (I_хв · R_хв) / [ V_T · (ΔR_C / R_C) ]
```

Звідси видно, що **коефіцієнт придушення синфазного сигналу CMRR безпосередньо відображає динамічну зміну напруги зсуву під дією синфазної напруги**:

```
ΔV_os = ΔV_cm / CMRR
```

### 8. Вплив пульсацій живлення на зсув (PSRR)

Коли змінюється напруга живлення `V_CC` або `V_EE` на величину `ΔV_живлення`, змінюються колекторні потенціали та струм джерела зміщення `I_хв`:

```
ΔI_хв = ΔV_EE / R_хв
```

Якщо диференційний каскад має колекторні навантаження з технологічним розкидом `ΔR_C / R_C`, виникає несиметричний приріст колекторних напруг:

```
ΔV_вих = ΔV_CC · (ΔR_C / (2 · R_C)) + ΔI_хв · R_C · (ΔR_C / (2 · R_C))
```

Зведена до входу зміна напруги зсуву дорівнює:

```
ΔV_os(PSR) = ΔV_вих / A_д = ΔV_живлення / PSRR
```

де `A_д = g_m · R_C = (I_хв / (2 · V_T)) · R_C` — диференційний коефіцієнт підсилення каскаду.

Підставляючи вирази:

```
PSRR = A_д / (dA_вих / dV_живлення) ≈ (I_хв · R_хв) / (V_T · (ΔR_C / R_C))
```

Будь-які низькочастотні пульсації джерела живлення безпосередньо модулюють вхідну напругу зсуву через несиметрію плечей каскаду.

### 9. Залишковий зсув у схемах із періодичною автокомпенсацією (Auto-Zero та Chopper)

У прецизійних архітектурах із нульовим дрейфом (Zero-Drift) первинний зсув `V_os` компенсується періодичною комутацією. Проте існує фундаментальна межа залишкового зсуву, обумовлена паразитною інжекцією заряду ключами та струмами витоку.

У схемі з автопідстроюванням нуля (Auto-Zero) на фазі калібрування зсув записується на конденсатор збереження `C_H`. У момент розмикання МОН-ключа через ємність перекриття затвор-канал `C_ov` у вузол пам'яті інжектується паразитна порція заряду:

```
Δq_inj = C_ov · (V_CLK − V_TH_ключ) + (1 / 2) · C_ch · (V_CLK − V_TH_ключ)
```

де `C_ch = W · L · C_ox` — повна ємність інверсійного каналу ключа.

Цей заряд створює стрибок напруги на накопичувальному конденсаторі:

```
ΔV_inj = Δq_inj / C_H
```

Зведена до входу залишкова напруга зсуву після одного такту комутації з урахуванням струму витоку `I_витоку` за період `T_clk = 1 / f_clk` дорівнює:

```
V_os_residual(AZ) = Δq_inj / C_H + (I_витоку / C_H) · (1 / (2 · f_clk))
```

Для типових значень `Δq_inj ≈ 0.05 фКл` (50 аКл, при використанні диференційних комплементарних ключів із компенсацією заряду) та `C_H = 50 пФ`:

```
V_os_residual ≈ 0.05 фКл / 50 пФ = 1 мкВ
```

У чоперних підсилювачах (Chopper Stabilization) сигнал модулюється меандром із частотою `f_chop`, підсилюється на змінному струмі (де постійний `V_os` не підсилюється), демодулюється та фільтрується низькочастотним фільтром. Залишковий зсув визначається інтегралом від паразитних сплесків комутації (clock feedthrough glitches):

```
V_os_residual(Chopper) = 2 · f_chop · ∫ V_сплеску(t) dt ≈ 2 · f_chop · R_on · Δq_inj
```

де `R_on` — опір відкритого каналу МОН-ключа.

При `f_chop = 100 кГц`, `R_on = 500 Ом`, `Δq_inj = 0.02 пКл`:

```
V_os_residual ≈ 2 · 10⁵ Гц · 500 Ом · 2 · 10⁻¹⁴ Кл = 2 мкВ
```

### 10. Термоелектрична напруга (ефект Зеєбека) на контактних переходах

При підключенні виводів мікросхеми до мідних доріжок друкованої плати утворюються послідовні з'єднання різнорідних металів: мідь доріжки плати (`Cu`), сплав припою (`Sn-Pb` або `Sn-Ag-Cu`) та ковар (`Kovar`) чи мідний сплав виводу корпусу мікросхеми.

Кожен такий перехід діє як термопара з коефіцієнтом Зеєбека `S_AB = S_A − S_B`:

```
V_термо = ∫ S_AB(T) dT
```

Для типового контакту «мідь — свинець/олово — ковар» термо-ЕРС становить:

```
S_термо ≈ 35–45 мкВ / °C
```

Якщо між двома вхідними контактними майданчиками `IN+` та `IN−` на платі виникає різниця температур `ΔT = T1 − T2`:

```
V_термо_паразитне = S_термо · (T1 − T2) = S_термо · ΔT
```

При температурному градієнті всього в `0.1 °C`:

```
V_термо_паразитне = 40 мкВ / °C · 0.1 °C = 4 мкВ
```

Для прецизійного підсилювача з власним зсувом `1 мкВ` зовнішня паразитна термо-ЕРС у `4 мкВ` стає домінуючим джерелом похибки вимірювання.

### 11. Статистичний розподіл Vos у партії мікросхем

Оскільки технологічні відхилення `ΔI_S`, `ΔV_TH`, `ΔR_C` є результатом великої кількості незалежних випадкових фізичних процесів (флуктуації дози іонної імплантації, гранулярність фоторезисту, дефекти кристалічної ґратки), напруга зсуву `V_os` підпорядковується нормальному розподілу Гаусса з нульовим математичним сподіванням:

```
f(V_os) = (1 / (σ_Vos · √(2 · π))) · exp(−V_os² / (2 · σ_Vos²))
```

де `σ_Vos` — середньоквадратичне відхилення (стандартне відхилення) напруги зсуву для даного технологічного процесу.

У технічній документації (datasheet) виробники зазвичай вказують два параметри:
1. **Типове значення (Typical):** відповідає величині `|V_os| ≈ 0.675 · σ_Vos` (медіана модуля розподілу).
2. **Максимальне значення (Maximum):** гарантована межа для відсортованої партії, що відповідає межі `3 · σ_Vos` (охоплює `99.73 %` придатних кристалів) або рівню відсікання автоматизованого тестового стенда виробника.

При розрахунку сумарного найгіршого бюджету похибки кількох послідовних каскадів використовують статистичне підсумовування за формулою кореня з суми квадратів (англ. *root-sum-square*, RSS):

```
V_os_total_RSS = √(V_os1² + V_os2² / A1² + V_os3² / (A1 · A2)²)
```

де `A1` та `A2` — диференційні коефіцієнти підсилення першого та другого каскадів відповідно. Звідси випливає, що зсув першого каскаду робить переважний внесок у загальну похибку тракту.

### 12. Закон Пелгрома та просторове масштабування площі транзисторів

Неможливо гарантувати точне збігання параметрів транзисторів диференційної пари без збільшення їхніх розмірів. Статистичний розкид параметрів між сусідніми транзисторами на одній кремнієвій пластині описується законом Пелгрома:

```
σ²(ΔV_TH) = A_VT² / (W · L) + S_VT² · D²
```

де:
* `W` і `L` — геометрична ширина й довжина каналу;
* `A_VT` — технологічний коефіцієнт узгодження порогових напруг (типово `2–4 мВ·мкм` для сучасних КМОН-процесів);
* `S_VT` — коефіцієнт просторового градієнта параметрів по пластині;
* `D` — фізична відстань між центрами двох транзисторів.

При симетричному перехресному розташуванні (англ. *common-centroid layout*) центри мас обох транзисторів суміщаються (`D → 0`), і градієнтний доданок нівелюється:

```
σ(ΔV_TH) = A_VT / √(W · L)
```

Цей вираз доводить: **середньоквадратичне значення напруги зсуву обернено пропорційне кореню квадратному з площі затвора транзистора `W · L`**.

Щоб зменшити випадковий розкид `V_os` утричі, площу транзисторів диференційного каскаду на кристалі доводиться збільшувати в `9 разів`. Це фундаментальний компроміс інтегральної схемотехніки: прецизійна точність напруги зсуву вимагає значної площі кристала та збільшення паразитної вхідної ємності.
