# 🧮 Підтяжка відкритого колектора: звідки беруться її межі

Опір підтягувального резистора не береться з повітря — він мусить лягти у **вікно** між двома межами. Знизу його тисне струм, який транзистор виходу здатний поглинути, не зіпсувавши «нуля»; зверху — швидкість, з якою лінія встигає піднятися до «1». Розберімо обидві межі від першопричини, а тоді складемо їх у готове правило вибору.

## Нижня межа: щоб «0» лишався нулем

Коли транзистор виходу відкритий і тягне лінію вниз, крізь підтяжку безперервно тече струм від плюса в землю:

```
I_sink = Vpu / R
```

Увесь цей струм втікає у відкритий транзистор — він мусить його **поглинути** (англ. *sink current*). Але транзистор не ідеальне коротке замикання: у [насиченні](topic:electronics/bjt-regions) на ньому лишається невелика напруга Vol (англ. *output low* — «низький вихід»), і вона тим більша, чим більший струм крізь нього тече. Даташит гарантує: поки струм не перевищує деякого Iol(max), напруга Vol не підскочить вище за гарантований поріг «нуля» (наприклад, 0.4 В). Перевищиш цей струм — і «нуль» поповзе вгору, аж поки приймач перестане впізнавати його як «0».

Звідси **нижня межа опору**: струм крізь підтяжку не має перевищувати того, що транзистор здатний безпечно поглинути.

```
I_sink = Vpu / R ≤ Iol(max)
⇒ R ≥ Vpu / Iol(max)
```

**Нижня межа для типового виходу.**
```
Vpu = 5 В,  Iol(max) = 8 мА (скільки транзистор поглинає, тримаючи Vol ≤ 0.4 В)
R_min = Vpu / Iol(max) = 5 / 0.008 ≈ 625 Ом

Менший опір → струм перевищить 8 мА → «нуль» підніметься вище 0.4 В
і втратить надійність. Тому R беруть НЕ менше ~625 Ом.
```

Якщо на спільній лінії висить багато виходів, але підтяжка одна, то струм усе одно визначає **одна** підтяжка, і поглинає його той **один** транзистор, що зараз тягне лінію вниз. Тому нижня межа рахується на один резистор — додавати виходи її не зсуває. (А от ставити по підтяжці на кожен вихід саме тому й не можна: вони стали б паралельно, сумарний опір упав би, і струм крізь єдиний тягнучий транзистор перевищив би Iol(max).)

## Верхня межа: щоб «1» встигала наростати

Підняти лінію до «1» транзистор не може — це робить лише підтяжка, заряджаючи **ємність лінії** C (ємність дроту, входів усіх приймачів, монтажу). Це звичайне [заряджання ємності крізь опір](topic:electronics/rc-time-constant), і напруга повзе вгору за експонентою зі **сталою часу**:

```
τ = R · C
```

Що більший опір, то більша τ, то повільніший фронт «0 → 1». Лінія має встигнути дорости до надійної «1», перш ніж її знову смикнуть униз, — тобто τ мусить бути помітно меншою за час, відведений на один такт лінії. Практичне правило: фронт (час наростання до «1») беруть приблизно як 2…3·τ, і він має вкластися в дозволений бюджет часу t_rise.

Звідси **верхня межа опору**:

```
τ = R · C ⇒ R ≤ t_rise / (k · C),   k ≈ 2…3
```

**Верхня межа для швидкої лінії.**
```
C = 100 пФ (ємність лінії з кількома приймачами),
t_rise(доступний) = 1 мкс,  візьмемо k = 3 (фронт ≈ 3τ)

R_max = t_rise / (k · C) = 1e-6 / (3 · 100e-12) ≈ 3.3 кОм

Більший опір → фронт довший за 1 мкс → лінія не встигає дорости до «1».
Тому R беруть НЕ більше ~3.3 кОм.
```

Видно головне: верхня межа **залежить від швидкості й ємності**. Повільній лінії з малою ємністю можна дати дуже великий опір (десятки кілоом — і струм мізерний). Швидкій чи довгій лінії з великою ємністю верхня межа різко падає, штовхаючи опір униз, ближче до нижньої межі.

## Вікно придатних значень

Складемо обидві нерівності:

```
Vpu / Iol(max)   ≤   R   ≤   t_rise / (k · C)
   (нижня, струм)            (верхня, швидкість)
```

Для прикладів вище це **625 Ом ≤ R ≤ 3.3 кОм** — широке вікно, у якому будь-яке значення робоче; типово беруть круглі 1…2.2 кОм. Що швидша лінія, то вужче це вікно: верхня межа сповзає вниз і зрештою може **наблизитися до нижньої**. Коли вони майже зійшлися — це сигнал, що звичайна підтяжка вже на межі: лінія або завелика, або зашвидка для пасивного резистора, і час думати про активні рішення (керовану підтяжку чи інший тип виходу).

```
повільна лінія (мала C, є час)   → вікно широке   → беремо великий R, економимо струм
швидка/довга лінія (велика C)    → вікно вузьке    → беремо малий R, миримося зі струмом
вікно зійшлося в точку            → пасивна підтяжка вичерпала себе
```

Отак два прості закони — Ом для нижньої межі й заряджання RC для верхньої — повністю задають, яким може бути підтягувальний резистор: досить великим, щоб не перевантажити транзистор струмом, і досить малим, щоб лінія встигала підніматися до «1».
