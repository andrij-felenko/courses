# 🧮 Чотири родини параметрів двопортовика: виведення, переходи, заготовки

Двопортову коробку ззовні описують чотирма числами — це факт. Але «чотири числа» можна записати щонайменше чотирма різними наборами: Z, Y, h, ABCD. Звідки беруться саме ці набори, що означає кожен окремий коефіцієнт, чому між наборами можна переходити простою алгеброю — і чому один із них перемножується для ланок поспіль, а інші ні? Тут ми виведемо всі чотири родини **від першопричини**: не «запам'ятай таблицю переходів», а **чому** Z переходить у Y саме оберненням матриці, чому гібридні параметри неминуче змішані, і звідки в умові взаємності з'являється то рівність Z₁₂ = Z₂₁, то AD − BC = 1. У кінці — невелика бібліотека готових ланок та робочий C-код, що множить каскад.

Усе нижче припускає, що коробка **[лінійна](book:electronics/linear-circuit)** (струми й напруги пов'язані прямими лініями, без заломів і насичення) і працює в усталеному режимі — тоді кожен «опір» можна розуміти як комплексний [імпеданс](book:math/impedance) Z(ω), а кожну «провідність» — як [адмітанс](book:electronics/admittance) Y(ω). Для постійного струму це просто числа в омах і сименсах; для змінного — ті самі формули, лише з комплексними величинами. Математика від цього не змінюється ні на йоту.

## Чому рівно чотири коефіцієнти: дві свободи, два наслідки

Почнімо з того, **звідки взагалі береться матриця 2×2**, бо без цього всі формули повисають у повітрі. На двох портах живуть чотири величини: U₁, I₁ на вході та U₂, I₂ на виході. Лінійне коло всередині накладає на них зв'язки. Скільки саме зв'язків?

Уявімо найпростіше — усередині коробки лише пасивні елементи, без джерел. Тоді, якщо **знеструмити обидва порти** (нічого не подавати), усе всередині спокійне: U і I скрізь нульові. Це означає, що зв'язок між величинами **однорідний** — без вільного доданка, без зсуву. А однорідний лінійний зв'язок між чотирма величинами, де дві ми вибираємо вільно, а дві визначаються, — це рівно матриця 2×2: чотири коефіцієнти.

Чому саме **дві** величини вільні, а дві визначені? Бо порт фізично пропонує нам **один** важіль на кожен бік. На вхідному порту ми або задаємо напругу й коло саме вирішує, який потече струм, або задаємо струм і коло саме встановлює напругу — але не те й те водночас (це суперечило б одне одному). Тобто на кожен порт — рівно одна вільна величина, на два порти — дві. Решта дві коробка визначає сама. «Дві визначаються через дві лінійно» — і є матриця 2×2.

```
4 величини на портах:  U₁, I₁, U₂, I₂
коло накладає зв'язки:  2 з них вільні (наш вибір), 2 — наслідок
2 наслідки = (матриця 2×2) · 2 причини   →   рівно 4 коефіцієнти
```

А тепер ключове спостереження, з якого виростають **усі чотири родини**: ми ще не сказали, **які саме дві** величини оголосити причиною. Це наш вибір, і кожен вибір дає свій набір коефіцієнтів. Виборів, що мають практичний сенс, рівно стільки, скільки родин:

- причина — **обидва струми** I₁, I₂ → наслідок напруги → родина **Z**;
- причина — **обидві напруги** U₁, U₂ → наслідок струми → родина **Y**;
- причина — **струм входу й напруга виходу** I₁, U₂ → родина **h**;
- причина — **величини виходу** U₂, I₂ → наслідок величини входу → родина **ABCD**.

Чотири родини — це не чотири різні фізики, а чотири різні відповіді на одне питання «що тут причина». Та сама коробка, той самий внутрішній устрій — просто розписаний з різного боку. Тому між родинами **завжди** можна перейти алгеброю: вони описують один і той самий об'єкт.

> 🔧 **Навіщо це.** Розуміння «чотири родини — лише різний вибір причини» рятує від зубріння. Не треба пам'ятати чотири незалежні набори формул; досить тримати в голові одне виведення на родину (поданий нижче дослід над портами) і вміти переходити між ними. У реальній роботі ви берете ту родину, що зручна для **вашої** задачі: транзистор у даташиті — h, фільтр-каскад — ABCD, високочастотна схема з шунтами — Y, — а потім за потреби перераховуєте в іншу.

## Формальне означення: кожен коефіцієнт — окремий дослід

Тепер найважливіше — **що означає кожне окреме число**. Тут криється проста й гарна ідея: щоб «зміряти» один коефіцієнт, треба **прибрати вплив усіх інших**, обнуливши потрібну величину. А обнулити величину на порту можна рівно двома способами — і обидва фізичні.

**Розімкнути порт** (холостий хід, ХХ) — це зробити **струм** на ньому нульовим: I = 0, бо колу нікуди текти. **Закоротити порт** (коротке замикання, КЗ) — це зробити **напругу** нульовою: U = 0, бо перемичка не дає напрузі наростати. Два стани порту → два способи обнуляти → з них і складаються означення всіх коефіцієнтів.

![Кожен коефіцієнт міряють окремим дослідом: розімкнув вихід (I₂=0) — дістаєш опори Z; закоротив вихід (U₂=0) — провідності Y і гібридне h₂₁](/book/electronics/analog/two-port-network/img/recipes.svg)
*Три досліди над тією самою скринькою. Щоб дістати коефіцієнт, обнуляють одну з вихідних величин: розімкнення виходу робить I₂=0 (родина Z), закорочення робить U₂=0 (родини Y та h). Збуджуєш один порт, обнуляєш інший, береш відношення — і коефіцієнт у тебе.*

Розгляньмо це на родині **Z**. Її рівняння кажуть, що напруги — наслідок струмів:

```
U₁ = Z₁₁·I₁ + Z₁₂·I₂
U₂ = Z₂₁·I₁ + Z₂₂·I₂
```

Як виокремити, скажімо, Z₁₁? Очевидно: треба позбутися доданка із I₂. А I₂ обнуляється **розімкненням виходу** (ХХ): немає куди текти струмові — отже I₂ = 0. Тоді з першого рядка лишається U₁ = Z₁₁·I₁, і коефіцієнт виокремлено:

```
Z₁₁ = U₁ / I₁   при   I₂ = 0   (вихід РОЗІМКНЕНО)
```

Це **вхідний опір при розімкненому виході**: подаєш на вхід струм, міряєш напругу на вході, ділиш. Так само й решта трьох Z — кожен витягається обнуленням «зайвого» струму через ХХ відповідного порту:

```
Z₁₁ = U₁/I₁ |_{I₂=0}    вхідний опір  (вихід розімкнено)
Z₁₂ = U₁/I₂ |_{I₁=0}    зворотна передача: напруга входу від струму виходу
Z₂₁ = U₂/I₁ |_{I₂=0}    пряма передача: напруга виходу від струму входу
Z₂₂ = U₂/I₂ |_{I₁=0}    вихідний опір  (вхід розімкнено)
```

Бачите систему: **усі Z — це опори, і всі вони міряються при розімкнених портах** (I = 0). Тому Z-параметри ще звуть **параметрами холостого ходу** (open-circuit parameters). Це не випадкова назва — це просто наслідок того, що струм оголошено причиною: щоб обнулити причину на порту, його розмикають.

Дзеркально влаштована родина **Y**. Тут причина — напруги, наслідок — струми:

```
I₁ = Y₁₁·U₁ + Y₁₂·U₂
I₂ = Y₂₁·U₁ + Y₂₂·U₂
```

Щоб виокремити Y₁₁, треба прибрати доданок із U₂ — а напруга обнуляється **закороченням** (КЗ): перемичка тримає U₂ = 0. Тому всі Y міряються при **закорочених** портах і звуться **параметрами короткого замикання** (short-circuit parameters):

```
Y₁₁ = I₁/U₁ |_{U₂=0}    вхідна провідність  (вихід закорочено)
Y₁₂ = I₁/U₂ |_{U₁=0}    зворотна передача провідності
Y₂₁ = I₂/U₁ |_{U₂=0}    пряма передача провідності (крутість)
Y₂₂ = I₂/U₂ |_{U₁=0}    вихідна провідність  (вхід закорочено)
```

> 🔧 **Навіщо це.** Це не абстракція — це буквальний рецепт лабораторного вимірювання. Хочеш зміряти вихідний опір чужого блока (Z₂₂)? Розімкни його вхід, подай струм у вихід, поділь напругу на струм. Хочеш крутість (Y₂₁)? Закороти вихід, подай напругу на вхід, зміряй струм короткого замикання на виході. Кожен коефіцієнт двопортовика має фізичний дослід, що його дає, — і знати, який саме порт розімкнути чи закоротити, означає вміти зняти параметри реальної коробки приладами.

Тепер видно, **чому гібридні h неминуче змішані**. Їхній вибір причини сам по собі мішаний — струм входу I₁ та напруга виходу U₂:

```
U₁ = h₁₁·I₁ + h₁₂·U₂
I₂ = h₂₁·I₁ + h₂₂·U₂
```

Щоб дістати h₁₁, обнуляємо U₂ — **закорочуємо вихід** (бо обнуляємо напругу): h₁₁ = U₁/I₁ при КЗ виходу — це вхідний опір при закороченому виході, в омах. А щоб дістати h₁₂, обнуляємо I₁ — **розмикаємо вхід** (бо обнуляємо струм): h₁₂ = U₁/U₂ при ХХ входу — безрозмірне відношення напруг. Кожен h-коефіцієнт вимагає **свого** стану портів, і саме тому вони різнорідні:

```
h₁₁ = U₁/I₁ |_{U₂=0}    вхідний опір (вихід КЗ),    Ом
h₁₂ = U₁/U₂ |_{I₁=0}    зворотна передача напруги,  безрозмірне
h₂₁ = I₂/I₁ |_{U₂=0}    підсилення струму (вихід КЗ), безрозмірне  ← це h_FE транзистора
h₂₂ = I₂/U₂ |_{I₁=0}    вихідна провідність (вхід ХХ), Сіменс
```

Та сама «різнорідність», що в назві *гібридний*: омʼ, сименс і два чистих числа в одному наборі. І саме тому h-параметри так гарно лягають на [малосигнальну модель транзистора](book:electronics/bjt-small-signal) — вхід BJT природний для опису опором (h₁₁), вихід — провідністю (h₂₂), а підсилення струму h₂₁ — це той самий h_FE, що ви бачите в даташиті.

## Чому Z і Y переходять одне в одне оберненням матриці

Тепер — перший і найкрасивіший перехід. Z каже «напруги через струми», Y каже «струми через напруги». Це **те саме коло**, лише причина й наслідок помінялися ролями. А «помінятися ролями» в лінійній алгебрі — це і є **обернення матриці**. Проживімо це повільно, бо тут видно глибинну механіку всіх переходів.

Запишімо обидві родини в матричному вигляді. Z пов'язує стовпчик напруг зі стовпчиком струмів:

```
[U₁]   [Z₁₁  Z₁₂] [I₁]
[U₂] = [Z₂₁  Z₂₂]·[I₂]        коротко:  U = Z·I
```

Y пов'язує їх **навпаки** — струми через напруги:

```
[I₁]   [Y₁₁  Y₁₂] [U₁]
[I₂] = [Y₂₁  Y₂₂]·[U₂]        коротко:  I = Y·U
```

Тепер дивимося. З першого: U = Z·I. Помножимо обидві сторони зліва на обернену матрицю Z⁻¹:

```
Z⁻¹·U = Z⁻¹·Z·I = I        тобто   I = Z⁻¹·U
```

Порівняймо з другим рядком, I = Y·U. Маємо два вирази для одного й того ж стовпчика I через один і той самий U. Отже множники збігаються:

```
Y = Z⁻¹       (і дзеркально Z = Y⁻¹)
```

Ось і вся розгадка, **чому Z↔Y — це обернення матриці**: це формальний відбиток того, що ми поміняли причину й наслідок. Обернути функцію «вхід→вихід» означає знайти «вихід→вхід», а для лінійної функції це й є обернення її матриці. Жодного зубріння — сама логіка причинності диктує операцію.

Лишилося розкрити обернення 2×2 у явні формули. Обернена до [[a,b],[c,d]] — це [[d,−b],[−c,a]], поділене на визначник ad−bc. Застосуймо до Z (визначник позначимо ΔZ = Z₁₁·Z₂₂ − Z₁₂·Z₂₁):

```
ΔZ = Z₁₁·Z₂₂ − Z₁₂·Z₂₁

Y₁₁ =  Z₂₂ / ΔZ
Y₁₂ = −Z₁₂ / ΔZ
Y₂₁ = −Z₂₁ / ΔZ
Y₂₂ =  Z₁₁ / ΔZ
```

Зверніть увагу на дрібницю, що багатьох плутає: Y₁₁ виражається через Z₂₂, **не** через Z₁₁. Це не помилка — це сама природа обернення: діагональ міняється місцями. Вхідна провідність усієї коробки залежить від **вихідного** опору, бо при оберненні все переплітається. Інтуїтивно: коли ви закорочуєте вихід (щоб зміряти Y₁₁), ви докорінно міняєте те, що бачить вхід, — і вихідні властивості коробки лізуть у вхідну провідність.

> 🔧 **Навіщо це.** Перехід Z↔Y — найчастіша конвертація на практиці. Z зручний для послідовних з'єднань і живлення струмом; Y — для паралельних з'єднань і для високих частот, де природно міряти при закороченні. Ви знімаєте параметри в тій формі, що зручна приладу, а рахуєте схему в тій, що зручна задачі, — і обернення матриці 2×2 (чотири ділення на визначник) переводить одне в одне за секунди. Той самий прийом стоїть за тим, що паралельні двопортовики складають **Y-матриці**, а послідовні — **Z-матриці**: у відповідній родині з'єднання дає просту суму.

## Перехід h↔Z: коли причина мішана

Перехід до гібридних трохи хитріший, бо тут міняється роллю **лише одна** величина на бік, не обидві. Та сама логіка — алгебра з рівнянь — дає й тут точні формули, і їх корисно вміти виводити, а не лише списувати.

Згадаймо: h бере причиною I₁ (як Z) і U₂ (як Y). Тобто треба взяти Z-рівняння й **перерозв'язати** їх так, щоб ліворуч опинилися U₁ та I₂ (наслідки h), а праворуч — I₁ та U₂ (причини h). Почнімо з другого Z-рівняння й виразимо з нього I₂ (бо I₂ — наслідок у h):

```
U₂ = Z₂₁·I₁ + Z₂₂·I₂      →      I₂ = (U₂ − Z₂₁·I₁) / Z₂₂
```

Це вже дає другий рядок h. Розкривши, читаємо коефіцієнти при I₁ та U₂:

```
I₂ = (−Z₂₁/Z₂₂)·I₁ + (1/Z₂₂)·U₂
тобто   h₂₁ = −Z₂₁/Z₂₂,   h₂₂ = 1/Z₂₂
```

Тепер підставимо цей I₂ у перше Z-рівняння (U₁ = Z₁₁·I₁ + Z₁₂·I₂), щоб вигнати звідти I₂ й лишити тільки причини h:

```
U₁ = Z₁₁·I₁ + Z₁₂·(U₂ − Z₂₁·I₁)/Z₂₂
   = (Z₁₁ − Z₁₂·Z₂₁/Z₂₂)·I₁ + (Z₁₂/Z₂₂)·U₂
   = (ΔZ/Z₂₂)·I₁ + (Z₁₂/Z₂₂)·U₂
```

(де знову ΔZ = Z₁₁·Z₂₂ − Z₁₂·Z₂₁, бо Z₁₁ − Z₁₂·Z₂₁/Z₂₂ = (Z₁₁·Z₂₂ − Z₁₂·Z₂₁)/Z₂₂). Звідси перший рядок h. Зберімо всю четвірку:

```
h₁₁ = ΔZ / Z₂₂
h₁₂ = Z₁₂ / Z₂₂
h₂₁ = −Z₂₁ / Z₂₂
h₂₂ = 1 / Z₂₂
```

Знов та сама механіка: усе ділиться на Z₂₂ (вихідний опір), бо саме його ми «обернули», переводячи вихід зі struму на напругу як причину. h₂₂ = 1/Z₂₂ — буквально: вихідна провідність є обернена до вихідного опору, що очевидно й слугує перевіркою. А h₂₁ = −Z₂₁/Z₂₂ несе той самий мінус, що й при оберненні, — він іще зіграє в умові взаємності.

## Перехід ABCD↔Z: і чому в ABCD інший знак струму

Передавальна родина стоїть осторонь, бо в неї **інша домовленість про напрям вихідного струму**, і це треба тримати в голові під час будь-якого переходу. Нагадаю означення ABCD: вони виражають **величини входу через величини виходу**:

```
U₁ = A·U₂ + B·I₂
I₁ = C·U₂ + D·I₂
```

Тонкість у знаку I₂. У родинах Z, Y, h вихідний струм беруть **втікаючим у порт** (усередину коробки). У ABCD його беруть **витікаючим із порту** — назовні, у наступну ланку. Чому саме так — глибоко пояснено в самій темі про двопортовики через каскадування: щоб вихідний струм однієї ланки дорівнював вхідному струмові наступної й матриці множилися підряд без поправок. Для нас зараз важливий наслідок: **виводячи ABCD з Z, треба пам'ятати, що Z-рівняння записані для I₂ «всередину», а ABCD — для I₂ «назовні»**, тож у місцях, де фігурує вихідний струм, з'являється зміна знаку.

Виведемо A та C — це коефіцієнти при U₂, тобто беруться **при I₂ = 0** (вихід розімкнено). При розімкненому виході знак струму вже не грає (струму нема), тож можна прямо взяти Z-рівняння з I₂ = 0:

```
при I₂ = 0:   U₂ = Z₂₁·I₁   →   I₁ = U₂/Z₂₁
              U₁ = Z₁₁·I₁ = Z₁₁·U₂/Z₂₁

A = U₁/U₂ |_{I₂=0} = Z₁₁/Z₂₁
C = I₁/U₂ |_{I₂=0} = 1/Z₂₁
```

Дивовижно просто: C = 1/Z₂₁ — обернена пряма передача. Тепер B та D — коефіцієнти при I₂, беруться **при U₂ = 0** (вихід закорочено). Ось тут і вилазить знак: у ABCD-означенні I₂ витікає, а в Z-рівняннях він втікав, тож вихідний струм Z-рівнянь дорівнює (−I₂) ABCD. Підставимо U₂ = 0 у друге Z-рівняння, пам'ятаючи цю заміну:

```
при U₂ = 0:   0 = Z₂₁·I₁ + Z₂₂·I₂(внутр)
              I₂(внутр) = −I₂(ABCD, назовні)
              0 = Z₂₁·I₁ − Z₂₂·I₂        →   I₁ = (Z₂₂/Z₂₁)·I₂

D = I₁/I₂ |_{U₂=0} = Z₂₂/Z₂₁
```

А B дістаємо з першого Z-рівняння при U₂ = 0, із тією ж заміною знаку:

```
U₁ = Z₁₁·I₁ + Z₁₂·I₂(внутр) = Z₁₁·(Z₂₂/Z₂₁)·I₂ − Z₁₂·I₂
   = [(Z₁₁·Z₂₂ − Z₁₂·Z₂₁)/Z₂₁]·I₂ = (ΔZ/Z₂₁)·I₂

B = U₁/I₂ |_{U₂=0} = ΔZ/Z₂₁
```

Зберімо повний перехід Z→ABCD — гарний тим, що **всі чотири діляться на Z₂₁** (пряму передачу):

```
A = Z₁₁ / Z₂₁
B = ΔZ / Z₂₁
C = 1   / Z₂₁
D = Z₂₂ / Z₂₁
```

Чому всі через Z₂₁ — теж зрозуміло: ABCD пов'язує вхід із виходом, а саме Z₂₁ є тим коефіцієнтом, що «проводить» сигнал зі входу на вихід. Природно, що вся передавальна родина будується навколо нього. І зверніть увагу: щоб ABCD взагалі існували, потрібно Z₂₁ ≠ 0 — коробка мусить **щось передавати** з входу на вихід. Ідеальний ізолятор (Z₂₁ = 0) не має ABCD-опису, і це логічно: не можна виразити вхід через вихід, якщо між ними нема зв'язку.

> 🔧 **Навіщо це.** ABCD-опис — робочий інструмент розрахунку трактів із ланок поспіль: [фільтри з кількох ланок](book:electronics/lc-rlc-filters), лінії передачі, узгоджувальні кола. Часто параметри ланки відомі в Z чи Y (бо так їх зручно зміряти або вивести зі схеми), а перемножувати треба в ABCD. Ці формули — місток: зняв Z, перевів у ABCD, перемножив каскад, за потреби перевів результат назад у Z чи [еквівалент Тевеніна](book:electronics/thevenin). Без знаку «−» на I₂ цей місток працював би з поправками на кожному стику; з ним — чисте множення матриць.

## Взаємність: одна симетрія, різні обличчя в різних родинах

Тепер — глибока річ, що звʼязує всі родини. У більшості **пасивних** коробок (лише резистори, котушки, конденсатори, трансформатори — без транзисторів та інших активних, спрямованих елементів) параметри не зовсім незалежні: між ними є прихована симетрія, яку звуть **взаємністю** (англ. *reciprocal* — взаємний, зворотний). Фізична суть: передача крізь коробку **однакова в обидва боки** — поміняй вхід і вихід місцями, і відгук той самий.

У родині Z це записується найпростіше:

```
Z₁₂ = Z₂₁        (умова взаємності для Z)
```

Чому саме так? Z₂₁ — це напруга на виході від струму на вході, а Z₁₂ — напруга на вході від такого ж струму на виході. Сказати «передача однакова в обидва боки» — це буквально сказати, що ці два коефіцієнти рівні. Це не властивість конкретної схеми, а наслідок глибокого закону — **теореми взаємності**, яку для електромагнітного поля вивів іще нідерландський фізик **Гендрик Лоренц** (Hendrik Lorentz); її електротехнічний різновид для кіл носить імена Лоренца та інших класиків теорії кіл. *(Усталений результат: аналіз пасивних двопортовиків історично виростає з теорем взаємності Лоренца — це підтверджують стандартні джерела з теорії мереж.)* Звідки взялося саме поняття порту й хто звів усе це в струнку теорію — у [короткій історії](book:electronics/two-port-network/hist-port-parameters.md) теорії портів.

Тепер найцікавіше: **та сама** симетрія в різних родинах виглядає **по-різному**, і це прямо випливає з виведених переходів. Подивімося, на що перетворюється Z₁₂ = Z₂₁ у кожній родині.

У **Y** — так само симетрично, бо Y = Z⁻¹, а обернення зберігає симетрію матриці:

```
Y₁₂ = Y₂₁        (взаємність для Y)
```

У **h** симетрія ламає вигляд через мінус, що ми його зустріли у виведенні. Згадаймо: h₁₂ = Z₁₂/Z₂₂, а h₂₁ = −Z₂₁/Z₂₂. Якщо Z₁₂ = Z₂₁, то h₁₂ = Z₁₂/Z₂₂ = Z₂₁/Z₂₂ = −h₂₁. Отже:

```
h₁₂ = −h₂₁       (взаємність для h)
```

Не рівність, а рівність із мінусом — і тепер видно, **звідки** цей мінус: він народився при переході h↔Z, де h₂₁ дістав знак «−» від перерозв'язання. Симетрія та сама, обличчя інше.

У **ABCD** взаємність набуває зовсім іншого, найвідомішого вигляду — **визначник дорівнює одиниці**:

```
A·D − B·C = 1    (взаємність для ABCD)
```

Перевірмо це прямо з виведених формул Z→ABCD, і ця перевірка — чудова ілюстрація того, як одна умова перетікає між родинами:

```
A·D − B·C = (Z₁₁/Z₂₁)·(Z₂₂/Z₂₁) − (ΔZ/Z₂₁)·(1/Z₂₁)
          = [Z₁₁·Z₂₂ − ΔZ] / Z₂₁²
          = [Z₁₁·Z₂₂ − (Z₁₁·Z₂₂ − Z₁₂·Z₂₁)] / Z₂₁²
          = Z₁₂·Z₂₁ / Z₂₁²
          = Z₁₂ / Z₂₁
```

І ось ключ: A·D − B·C = Z₁₂/Z₂₁. Якщо коробка взаємна (Z₁₂ = Z₂₁), це відношення дорівнює рівно **одиниці**. Тобто **AD − BC = 1 — це і є умова Z₁₂ = Z₂₁, лише перекладена мовою ABCD**. Одна фізична симетрія — три алгебраїчні обличчя: рівність (Z, Y), рівність із мінусом (h), одиничний визначник (ABCD). *(Усе це — усталені, підтверджені співвідношення стандартної теорії двопортовиків.)*

Що це дає по суті? Коли симетрія є, чотири параметри стають по суті **трьома** незалежними. У Z-матриці симетрія Z₁₂ = Z₂₁ лишає вільними лише Z₁₁, Z₂₂ і спільне Z₁₂ = Z₂₁ — три числа замість чотирьох. Пасивна коробка описується ще ощадніше. А підсилювач — **ні**: у ньому є активний, спрямований елемент ([кероване джерело](book:electronics/dependent-sources)), сигнал іде тільки вперед, тож Z₁₂ ≠ Z₂₁ і AD − BC ≠ 1. Порушення взаємності — математичний відбиток того, що в коробці є підсилення: уперед сигнал іде, а назад, із виходу на вхід, не повертається.

## Бібліотека заготовок: готові ABCD простих ланок

Уся сила ABCD розкривається, коли складну ланку складають із **простих цеглинок** і перемножують їхні матриці. Тому варто мати під рукою маленьку бібліотеку — ABCD кількох елементарних ланок, виведених прямо з означення. Виведення щоразу однакове: береш чотири рецепти A, B, C, D (з §«формальне означення», тільки тепер у формі вхід-через-вихід) і застосовуєш до конкретної ланки.

![Готові цеглинки та їхні ABCD: послідовний імпеданс {1,Z,0,1}, паралельний адмітанс {1,0,Y,1}, Г-ланка {1,Z,Y,1+YZ}, T-ланка; усі взаємні (AD−BC=1)](/book/electronics/analog/two-port-network/img/blocks.svg)
*Чотири базові ланки з їхніми ABCD-матрицями. Будь-яку пасивну схему складають із цих цеглинок, перемножуючи матриці в порядку проходження сигналу. У кожної AD − BC = 1 — усі вони взаємні.*

**Послідовний імпеданс Z** — найпростіша ланка: опір Z у верхній гілці, нижня гілка наскрізна. Виведемо. На холостому ході (I₂ = 0) струму через Z немає, падіння нуль, тож U₁ = U₂ → A = U₁/U₂ = 1; той самий струм входу проходить наскрізь, C = I₁/U₂ при I₂=0 = 0 (струм не залежить від U₂ при розімкненні — він просто нуль). При закороченні виходу (U₂ = 0): уся напруга входу падає на Z, U₁ = Z·I₂ → B = Z; струм проходить незмінним, I₁ = I₂ → D = 1:

```
послідовний Z:    [A B]   [1  Z]
                  [C D] = [0  1]
```

**Паралельний адмітанс Y** — дзеркальна цеглинка: елемент Y поперек, між верхньою й нижньою гілками. Тут верхня гілка наскрізна, тож напруга проходить незмінною: A = 1, B = 0 (бо U₁ = U₂ завжди). А струм входу — це струм виходу плюс те, що відгалужується в шунт Y: I₁ = I₂ + Y·U₂, звідки C = I₁/U₂ при I₂=0 = Y, а D = 1:

```
паралельний Y:    [A B]   [1  0]
                  [C D] = [Y  1]
```

Зверніть увагу на гарну дзеркальність: послідовний Z кладе свій елемент у позицію **B**, паралельний Y — у позицію **C**. Це не випадковість: B має розмірність опору (омʼ), C — провідності (сименс), тож послідовний елемент (опір) природно сідає в B, а паралельний (провідність) — у C. Перевірте взаємність: для обох AD − BC = 1·1 − Z·0 = 1 та 1·1 − 0·Y = 1. Обидві цеглинки взаємні, як і має бути для пасивних елементів.

**Ідеальний трансформатор** із відношенням витків n : 1 (тобто n = N₁/N₂, первинних до вторинних). Він масштабує напругу в n разів униз (U₂ = U₁/n) і струм у n разів угору. Прямо з означення: A = U₁/U₂ = n; напруга не залежить від I₂, тож B = 0; струм входу не залежить від U₂, тож C = 0; а D = I₁/I₂ = 1/n (струм трансформується обернено до напруги, бо ідеальний трансформатор зберігає потужність U·I):

```
ідеальний трансформатор n:1:    [A B]   [n    0 ]
                                [C D] = [0   1/n]
```

*(Усталений результат, підтверджений стандартними джерелами: ABCD ідеального n:1-трансформатора є {n, 0, 0, 1/n}.)* Перевірка взаємності: AD − BC = n·(1/n) − 0 = 1. Трансформатор взаємний — він однаково передає в обидва боки, лише з відповідним масштабом.

**Г-ланка (L-секція)** — послідовний Z, за яким паралельний Y (типова цеглинка узгоджувальних кіл і фільтрів). Її ABCD — це просто **добуток** двох уже виведених цеглинок. Тут варто закріпити одне правило множення раз і назавжди: оскільки ABCD виражає вхід через вихід, у добутку **ліворуч стоїть матриця тієї ланки, у яку сигнал входить першою**. Сигнал спершу проходить послідовний Z, потім бачить шунт Y, тож зліва — матриця Z, справа — Y:

```
[A B]   [1  Z] [1  0]   [1 + Z·Y    Z]
[C D] = [0  1]·[Y  1] = [   Y       1]
```

Перевірка взаємності: AD − BC = (1+ZY)·1 − Z·Y = 1 + ZY − ZY = 1. Знов одиниця — Г-ланка з пасивних елементів взаємна. (Поміняй порядок ланок — спершу шунт Y, тоді послідовний Z — і дістанеш іншу, теж законну матрицю [1, Z; Y, 1+YZ]: це вже **інша** ланка, з елементами в іншому порядку, тож і ABCD в неї інша. Головне — множити матриці суворо в порядку, у якому сигнал зустрічає ланки.)

**T-ланка** — послідовний Z₁, шунт Y, послідовний Z₂ (симетрична цеглинка фільтрів). Три матриці поспіль:

```
[A B]   [1  Z₁] [1  0] [1  Z₂]
[C D] = [0   1]·[Y  1]·[0   1]

      = [1 + Y·Z₁     Z₁ + Z₂ + Y·Z₁·Z₂]
        [   Y              1 + Y·Z₂      ]
```

Тут добре видно силу методу: три цеглинки, два перемноження матриць 2×2 — і маєш повний опис T-ланки, який інакше довелося б виводити з системи рівнянь Кірхгофа для всієї схеми. Перевірте, якщо хочете, що AD − BC = 1 і тут (вийде після розкриття — пасивна ланка взаємна).

> 🔧 **Навіщо це.** Ця бібліотека — конструктор. Реальний фільтр, узгоджувач чи модель лінії — це послідовність таких цеглинок. Ви не виводите його ABCD з нуля: береш матриці цеглинок зі своєї пам'яті (чи з коду), перемножуєш у порядку сигналу — і маєш матрицю всього вузла. Додав ще ланку — домножив ще одну матрицю. Саме так у [розрахунку фільтрів і ліній](book:electronics/lc-rlc-filters) складні структури рахуються механічним множенням 2×2 замість громіздких систем.

## Робочий приклад на C: Z→Y і множення каскаду ABCD

Зберімо все в код, яким реально користуються. Дві операції покривають більшість потреб: **перетворення між родинами** (тут Z→Y оберненням 2×2) і **перемноження ABCD каскаду**. Працюємо з дійсними числами для простоти (на постійному струмі або для дійсних опорів); для змінного струму ті самі формули йдуть з комплексними числами — структура коду не міняється.

**Перетворення Z → Y оберненням матриці 2×2.** Беремо чотири Z-параметри, рахуємо визначник, застосовуємо формулу оберненої. Якщо визначник близький до нуля — матриця вироджена, Y не існує (так буває для деяких ідеальних ланок), і це треба ловити.

:::tabs
```cpp
#include <cmath>

struct Zparams { float z11, z12, z21, z22; };
struct Yparams { float y11, y12, y21, y22; };

// Z -> Y оберненням матриці 2×2: Y = Z⁻¹.
// Повертає true при успіху, false якщо матриця вироджена (det ≈ 0, Y не існує).
bool z_to_y(Zparams z, Yparams &y) {
    float det = z.z11 * z.z22 - z.z12 * z.z21;   // ΔZ — визначник
    if (std::fabs(det) < 1e-12f) return false;    // вироджена: Y не існує
    y.y11 =  z.z22 / det;      // діагональ міняється місцями!
    y.y12 = -z.z12 / det;
    y.y21 = -z.z21 / det;
    y.y22 =  z.z11 / det;
    return true;
}
// Приклад: Z = {60, 40, 40, 80} Ом (взаємна, бо z12=z21).
//   det = 60·80 − 40·40 = 4800 − 1600 = 3200
//   y11 = 80/3200 = 0.025 См;  y22 = 60/3200 = 0.01875 См
//   y12 = y21 = −40/3200 = −0.0125 См   ← взаємність збереглася: Y₁₂ = Y₂₁
```
```python
# Z -> Y оберненням матриці 2×2: Y = Z⁻¹.
# Повертає словник Y при успіху, None якщо матриця вироджена (det ≈ 0).
def z_to_y(z):
    det = z["z11"] * z["z22"] - z["z12"] * z["z21"]   # ΔZ — визначник
    if abs(det) < 1e-12:                              # вироджена: Y не існує
        return None
    return {
        "y11":  z["z22"] / det,     # діагональ міняється місцями!
        "y12": -z["z12"] / det,
        "y21": -z["z21"] / det,
        "y22":  z["z11"] / det,
    }
# Приклад: Z = {60, 40, 40, 80} Ом (взаємна, бо z12=z21).
#   det = 60·80 − 40·40 = 4800 − 1600 = 3200
#   y11 = 80/3200 = 0.025 См;  y22 = 60/3200 = 0.01875 См
#   y12 = y21 = −40/3200 = −0.0125 См   ← взаємність збереглася: Y₁₂ = Y₂₁
```

Останній рядок коментаря — важлива перевірка здорового глузду: оскільки вхідна Z-матриця взаємна (z₁₂ = z₂₁ = 40), вихідна Y теж вийшла взаємною (y₁₂ = y₂₁ = −0.0125). Якби в результаті y₁₂ ≠ y₂₁, це сигналізувало б про помилку — обернення **зобов'язане** зберегти симетрію.

**Перемноження ABCD каскаду.** Кожна ланка — матриця {A,B,C,D}; ланки поспіль перемножуються в порядку проходження сигналу. Зберемо невеликий узгоджувач: послідовний опір 50 Ом, тоді паралельна провідність 0.01 См (шунт-резистор 100 Ом), тоді ще послідовні 25 Ом — типова Г-подібна структура.

:::tabs
```cpp
struct ABCD { float A, B, C, D; };

ABCD abcd_mul(ABCD m1, ABCD m2) {     // m1 — перша за сигналом ланка
    ABCD r;
    r.A = m1.A * m2.A + m1.B * m2.C;
    r.B = m1.A * m2.B + m1.B * m2.D;
    r.C = m1.C * m2.A + m1.D * m2.C;
    r.D = m1.C * m2.B + m1.D * m2.D;
    return r;
}

// Цеглинки з бібліотеки:
ABCD series_z(float Z) { return {1.0f, Z,    0.0f, 1.0f}; }  // {1,Z,0,1}
ABCD shunt_y(float Y)  { return {1.0f, 0.0f, Y,    1.0f}; }  // {1,0,Y,1}

// Перевірка взаємності: для пасивної ланки має бути AD − BC ≈ 1.
float reciprocity(ABCD m) { return m.A * m.D - m.B * m.C; }
```

Результат — `AD − BC = 1.000` — підтверджує, що весь каскад вийшов взаємним, як і кожна його пасивна цеглинка (добуток матриць із одиничним визначником сам має одиничний визначник — це властивість визначника множитися: det(M₁·M₂) = det M₁ · det M₂). Це безкоштовна перевірка коректності: якщо після множення каскаду з пасивних ланок AD − BC помітно відхилилося від одиниці, десь закралася помилка в матрицях чи в порядку множення.

На цих двох операціях — обернення для зміни родини та множення для каскаду — тримається практичний розрахунок двопортовиків. Зняв параметри в зручній формі, перевів у потрібну, перемножив ланки, за бажання перевів результат назад — і складний тракт із десятків елементів описано чотирма числами та кількома рядками арифметики. Уся теорія дво- й чотириполюсників саме для цього й існує: щоб **чуже складне** перетворити на **своє просте** — матрицю 2×2, з якою рахуєш, як зі звичайним числом.
