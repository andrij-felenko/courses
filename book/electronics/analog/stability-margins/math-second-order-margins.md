# 🧮 Запас фази через згасання: звідки беруться 45° і 60°

У статті ми сказали, що запас фази **керує** перельотом і дзвоном перехідної характеристики, і навели орієнтири: 45° — невеликий викид, 60° — майже гладко. Звідки ці конкретні числа? Вони не з повітря — їх дає проста модель кола **другого порядку**, і той самий апарат пов'язує запас фази з [добротністю Q](topic:electronics/quality-factor) та коефіцієнтом згасання. Розберімо цей місток від частотної картини (запас фази) до часової (як коло реагує на стрибок).

### Модель: коло другого порядку й коефіцієнт згасання

Більшість петель зворотного зв'язку поблизу частоти зрізу поводяться, як **система другого порядку** — те саме, що [RLC-коло](topic:electronics/lc-resonance) чи маса на пружині з тертям. Її поведінку повністю задає одне безрозмірне число — **коефіцієнт згасання** *(damping ratio)* ζ (грецька «дзета»):

```
ζ → 0     коло майже не згасає — довгий дзвін, ось-ось генерація
ζ = 1     критичне згасання — найшвидший вихід БЕЗ перельоту
ζ > 1     перезгасання — виходить мляво, повільно, без викиду
```

ζ зв'язаний із добротністю просто: ζ = 1/(2Q). Високе Q — слабке згасання — сильний дзвін; це той самий резонансний «дзвін», що в LC-контурі, лише тепер його створює **петля зворотного зв'язку**, а не котушка з конденсатором.

> 🔧 **Навіщо це.** ζ — це місток між тим, що ви **виміряли** аналізатором (запас фази, частотна картина), і тим, що ви **побачите на осцилографі** (переліт і дзвін на стрибку, часова картина). Знаючи запас фази, ви наперед скажете висоту викиду — не паяючи й не вмикаючи.

### Переліг прямо з коефіцієнта згасання

Висота першого викиду над усталеним рівнем (переліг, *overshoot*) у системі другого порядку залежить **лише** від ζ — точною формулою:

```
переліг = exp( −π·ζ / √(1 − ζ²) )        (частка від стрибка)
```

Підставмо кілька значень, щоб відчути шкалу:

```
ζ = 0.1   →  переліг ≈ 0.73   (73% — величезний дзвін)
ζ = 0.45  →  переліг ≈ 0.20   (20% — помірний викид)
ζ = 0.7   →  переліг ≈ 0.046  (4.6% — майже непомітно)
ζ = 1.0   →  переліг = 0      (зовсім без викиду)
```

Видно різкість залежності: при ζ = 0.1 коло перескакує ціль майже вдвічі, при ζ = 0.7 — лише на кілька відсотків. Ось чому інженери так тримаються за «достатнє згасання»: різниця між поганим і добрим переходом — це різниця між ζ ≈ 0.4 і ζ ≈ 0.7.

### Місток: запас фази ≈ ζ, помножене на сто

Лишилося пов'язати ζ із запасом фази. Точного аналітичного зв'язку для довільного кола нема, але для типової петлі (де один полюс домінує поблизу частоти зрізу) працює напрочуд проста й широковживана інженерна оцінка:

```
ζ  ≈  запас фази (у градусах) / 100      (для запасу від 0° до ~60°)
```

Тобто запас фази в градусах — це майже просто коефіцієнт згасання, помножений на сто. Підставмо в неї наші орієнтири — і числа з основної статті стають **зрозумілими, а не завченими**:

**Запас фази 45°.**
```
ζ ≈ 45/100 = 0.45
переліг = exp(−π·0.45/√(1−0.45²)) = exp(−1.414/0.893) = exp(−1.583) ≈ 0.20
```
Звідси й «викид відсотків із двадцять» при 45°: помірний переліг, кілька коливань — і заспокоїлося. Розумний компроміс між швидкодією і чистотою.

**Запас фази 60°.**
```
ζ ≈ 60/100 = 0.60
переліг = exp(−π·0.60/√(1−0.60²)) = exp(−1.885/0.800) = exp(−2.356) ≈ 0.095
```
Викид менший за 10% — перехід уже майже гладкий. Тому 60° — улюблена ціль прецизійних кіл: ще достатньо швидко, але дзвону практично нема.

**Запас фази 20°.**
```
ζ ≈ 0.20  →  переліг = exp(−π·0.20/√(1−0.04)) ≈ exp(−0.641) ≈ 0.53
```
Понад 50% викиду й довгий дзвін — коло ледь тримається по цей бік генерації. Саме такий вигляд має «майже зірвалося» на осцилографі.

### Той самий ζ керує й піком частотної характеристики

Згасання видно не лише в часі (переліг), а й у **частоті** — у формі замкненої характеристики біля частоти зрізу. Слабко згасане коло (малий ζ) дає **горб** *(peaking)* — підйом підсилення над рівним значенням саме там, де петля «дзвенить». Це той самий резонансний пік, що в [RLC-контурі](topic:electronics/rlc-selectivity), лише створений петлею. Висота піку теж залежить лише від ζ:

```
пік замкненої АЧХ  =  1 / ( 2·ζ·√(1 − ζ²) )      (для ζ < 0.707)
ζ ≥ 0.707  →  піку немає взагалі (характеристика монотонно спадає)
```

Підставмо:

```
ζ = 0.3   →  пік ≈ 1.75  (+4.9 дБ — помітний горб, коло дзвенить)
ζ = 0.5   →  пік ≈ 1.16  (+1.2 дБ — ледь-ледь)
ζ = 0.707 →  пік = 1.0   (рівно, без горба — «максимально пласко»)
```

Звідси два корисні висновки. По-перше, ζ = 0.707 (а це запас фази ≈ 65°) — особлива точка: характеристика **щонайпласкіша** без горба, це класичний вибір «Баттерворта». По-друге, горб у замкненій АЧХ — **симптом замалого запасу фази**: побачили на свіп-вимірі підйом перед спадом — знайте, що петля близько до межі, і часова характеристика дзвенітиме.

### Запас фази тягне за собою смугу й час заспокоєння

Раз ζ задає форму, він зачіпає й **швидкодію**. Час заспокоєння (поки переліг і дзвін згаснуть до, скажімо, 2% від кінцевого) у системі другого порядку приблизно:

```
час заспокоєння (2%)  ≈  4 / (ζ · ω_n)
```

де ω_n — власна (резонансна) кругова частота петлі, близька до частоти зрізу. Звідси видно тонкий обмін: тиснути запас фази **надто** високо (ζ → 1 і більше) — означає не лише прибрати дзвін, а й **уповільнити** заспокоєння, бо росте знаменник тільки за рахунок ζ, тоді як надмірне згасання водночас «придавлює» ефективну ω_n. Оптимум за швидкістю заспокоєння лежить десь біля ζ ≈ 0.7 (запас фази ~60–65°): дзвону вже практично нема, а заспокоєння — найшвидше. Це й робить 60° не просто «безпечним», а **найвигіднішим** компромісом між стійкістю і швидкодією.

**Від виміряної пари Боде — до прогнозу заспокоєння.** Хай аналізатор дав запас фази 60° на частоті зрізу 80 кГц. Тоді:
```
ζ ≈ 60/100 = 0.60
ω_n ≈ 2π·80 кГц ≈ 5.03·10⁵ рад/с
час заспокоєння ≈ 4 / (0.60 · 5.03·10⁵) ≈ 1.33·10⁻⁵ с ≈ 13 мкс
переліг = exp(−π·0.60/√(1−0.36)) ≈ 9.5%
```
Дві цифри з частотного виміру — запас фази й частота зрізу — одразу дали обидві часові: ~10% викиду й заспокоєння за ~13 мкс. Жодного осцилографа не знадобилося.

### Що каже число запасу підсилення

Запас фази тягне за собою цілий шлейф наслідків; запас підсилення — простіший, але теж кількісний. Він каже буквально, **у скільки разів** можна збільшити підсилення в контурі, перш ніж коло зірветься. Запас 6 дБ — це множник 2 (підсилення мусило б подвоїтися); 12 дБ — множник 4; 20 дБ — множник 10. Тому «хочу щонайменше 6 дБ» читається як «хочу дворазову подушку по підсиленню»: навіть якщо власне A приладу через розкид чи нагрів виявиться вдвічі більшим за номінал, коло ще не заспіває. Перевести дБ у множник просто:

```
множник = 10^(запас_дБ / 20)      →   6 дБ → ×2,  12 дБ → ×4,  20 дБ → ×10
```

### Де оцінка ламається — і чому нею все одно користуються

Чесно про межі. Зв'язок «ζ ≈ PM/100» — **наближення**, і воно має умови. Воно добре працює, поки петля поблизу частоти зрізу схожа на чисту систему другого порядку з **одним домінантним полюсом**; саме так навмисне роблять із операційними підсилювачами (внутрішня корекція задає один домінантний полюс — звідси й [добуток підсилення на смугу](topic:electronics/gain-bandwidth-product)). Оцінка **псується** для запасів понад ~60–70° і там, де поряд із частотою зрізу тиснуть кілька полюсів і нулів — тоді форма перехідної характеристики складніша, ніж дає проста ζ, і точне число доводиться брати із симуляції чи виміру.

Та навіть із цими застереженнями оцінка безцінна: вона дає **інтуїцію в голові** — почув «запас фази 45°» і одразу уявив 20% викиду й помірний дзвін, не запускаючи нічого. Для першого прикиду й для розуміння, **куди** компенсувати петлю, цього досить майже завжди; точну цифру лишаємо інструментові, а голову тримаємо на простій формулі.

### Чому не можна дивитися лише на одне число

Просте правило «обидва запаси додатні → стійко» має тонку пастку, варту згадки. Воно мовчки припускає, що крива підсилення перетинає 0 дБ **один раз**, а фаза проходить −180° теж **один раз** — звичайна картина простої петлі. Але є **умовно стійкі** контури, де фаза провалюється нижче −180° і потім **повертається** назад вище, перш ніж підсилення впаде до одиниці. У таких петель може бути здоровий запас фази на частоті зрізу — і все одно вони небезпечні: якщо підсилення з якоїсь причини **впаде** (а не зросте), точка зрізу зсунеться в ту западину, де фаза вже за −180°, і коло заспіває **від зменшення** підсилення. Це контрінтуїтивно: зазвичай ми боїмося надлишку підсилення, а тут біду приносить його брак.

Висновок практичний: запас фази й запас підсилення — це два числа з **двох конкретних точок**, а не повна історія кривої. Для звичайної петлі їх досить. Але якщо фазова крива має «пірнання» нижче −180° десь у робочому діапазоні, треба дивитися на **всю** криву (це і є повний критерій Найквіста), а не лише на дві точки перетину. Два запаси — чудовий щоденний інструмент саме тому, що більшість петель прості; пам'ятати про їхню межу варто, щоб не обманутися на хитрій схемі.
