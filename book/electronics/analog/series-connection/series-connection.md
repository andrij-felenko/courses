# Послідовне з'єднання

Найпростіший спосіб з'єднати елементи — поставити їх **одне за одним** в одну гілку, як вагони потяга. Саме таке з'єднання й називають **послідовним** (від латинського *series* — «низка, ряд»): елементи стоять у ряд, у [спільній гілці](book:electronics/nodes-branches-loops), без жодного розгалуження. Уся поведінка такого кола виростає з цієї єдиної обставини — гілка одна, обійти елемент нікуди.

### Два факти: спільний струм, напруги додаються

![Послідовно: струм один, напруги додаються](/book/electronics/analog/series-connection/img/series-two-facts.svg)
*Послідовне коло: елементи стоять одне за одним в одній гілці. Звідси два факти — струм I однаковий у кожному (закон струмів), а повна напруга дорівнює сумі спадів, V = V₁ + V₂ + V₃ (закон напруг).*

Із того, що гілка одна, прямо випливають дві властивості, і обидві — наслідки законів Кірхгофа.

**Струм скрізь однаковий.** Розгалужень нема, тікати зарядам нікуди, тож той самий струм I тече крізь усі елементи поспіль — це [закон струмів](book:electronics/kcl): скільки заряду за секунду входить у вузол, стільки й виходить, а проміжних вузлів у ряду просто немає. **Напруги додаються.** Якщо обійти контур, повна напруга джерела розкладається на спади між елементами: V = V₁ + V₂ + V₃ — це [закон напруг](book:electronics/kvl). Пара **спільний струм, сумарна напруга** — це і є весь послідовний ланцюжок; решта виводиться з неї.

Образ простий: послідовні елементи — як намистини на одній нитці чи машини на вузькій однорядній дорозі. Проїхати можна лише **гуськом**, тож потік (струм) крізь кожну ланку однаковий, а опір усій дорозі складається з усіх ділянок поспіль. Аналогія точна рівно доти, доки дорога одна; щойно з'явиться об'їзд (розгалуження) — це вже не послідовне коло, і струм почне ділитися.

### Опори додаються: R_екв = R₁ + R₂ + …

![Чому опори додаються](/book/electronics/analog/series-connection/img/req-derivation.svg)
*Спільний струм і закон Ома на кожному резисторі дають V = V₁+V₂+V₃ = I·R₁ + I·R₂ + I·R₃ = I·(R₁+R₂+R₃). Порівняння з V = I·R_екв дає R_екв = R₁ + R₂ + R₃.*

Із цих двох фактів випливає напрочуд проста відповідь на питання «який опір у всього ланцюжка?». Виведення коротке. Спад на кожному резисторі — за законом Ома: V₁ = I·R₁, V₂ = I·R₂, V₃ = I·R₃, причому струм I **спільний** для всіх. Сума спадів дає повну напругу:

```
V = V₁ + V₂ + V₃ = I·R₁ + I·R₂ + I·R₃ = I·(R₁ + R₂ + R₃)
```

Поряд стоїть закон Ома для всього кола, V = I·R_екв. Дві формули описують той самий струм при тій самій напрузі, тож множники при I мусять збігтися — і відповідь очевидна: **послідовні опори просто додаються**.

```
R_екв = R₁ + R₂ + R₃ + …
```

Правило діє для скількох завгодно резисторів — додавайте опори по черзі. Для n **однакових** резисторів воно дає зручне R_екв = n·R: п'ять резисторів по 100 Ω поспіль — це рівно 500 Ω.

Сума не залежить від порядку, тож і **порядок резисторів у ряду байдужий**: переставте їх місцями — R_екв, спільний струм і кожен спад лишаться ті самі. Це прямо з того, що додавання комутативне; на практиці означає, що рисувати послідовну групу можна в будь-якому зручному порядку, не боячись змінити результат.

### Один еквівалентний резистор

![Три резистори = один еквівалентний](/book/electronics/analog/series-connection/img/equivalent.svg)
*Для джерела ланцюжок із трьох резисторів нічим не відрізняється від одного еквівалентного R_екв = R₁+R₂+R₃ = 650 Ω. Послідовне з'єднання завжди збільшує опір — R_екв більший за будь-який окремий.*

Гроно послідовних резисторів можна замінити **одним** еквівалентним (від латинського *aequivalens* — «рівнозначний»), і джерело не помітить підміни: той самий струм при тій самій напрузі. А звідси випливає важливий наслідок — **послідовне з'єднання завжди збільшує опір**. Кожен доданий у ряд резистор лише нарощує R_екв, тож еквівалент неминуче **більший за будь-який окремий** опір у ньому. Інтуїтивно це те саме, що подовжити провідник: довше → більший опір, рівно як у формулі [R = ρL/A](book:physics/resistivity).

Заміна групи елементів одним еквівалентним — це основний прийом **спрощення** кіл. Велике плетиво резисторів [розплутують](guide:embedded/circuit-analysis) крок за кроком: знайшли послідовну групу — згорнули її в один R_екв; знайшли [паралельну](book:electronics/parallel-connection) — згорнули й її; і так, доки від цілої схеми не лишиться єдиний еквівалентний опір, з яким струм від джерела рахується одним діленням.

### Приклад: розрахувати коло

**Три резистори 100, 220 і 330 Ω з'єднані послідовно під 12 В. Знайти струм і спад на кожному.**

:::tabs
```c
// Послідовне коло: спершу R_екв, тоді спільний струм, тоді спади
float V = 12.0f;                       // напруга джерела, В
float R1 = 100, R2 = 220, R3 = 330;    // опори, Ω

float Req = R1 + R2 + R3;              // = 650 Ω
float I   = V / Req;                   // = 0.01846 А ≈ 18.5 мА  (струм спільний)
float V1  = I * R1;                    // ≈ 1.85 В
float V2  = I * R2;                    // ≈ 4.07 В
float V3  = I * R3;                    // ≈ 6.08 В
// перевірка KVL: V1 + V2 + V3 = 1.85 + 4.07 + 6.08 ≈ 12.0 В  ✓
```
```python
# Послідовне коло: спершу R_екв, тоді спільний струм, тоді спади
V = 12.0                               # напруга джерела, В
R1, R2, R3 = 100, 220, 330             # опори, Ω

Req = R1 + R2 + R3                     # = 650 Ω
I = V / Req                            # = 0.01846 А ≈ 18.5 мА  (струм спільний)
V1 = I * R1                            # ≈ 1.85 В
V2 = I * R2                            # ≈ 4.07 В
V3 = I * R3                            # ≈ 6.08 В
# перевірка KVL: V1 + V2 + V3 = 1.85 + 4.07 + 6.08 ≈ 12.0 В  ✓
```
:::

![Приклад розрахунку](/book/electronics/analog/series-connection/img/worked.svg)
*Розрахунок: спершу R_екв = 650 Ω, потім спільний струм I = 12/650 ≈ 18.5 мА, далі спад на кожному V = I·R. Сума спадів повертає 12 В — перевірка зійшлася.*

Алгоритм універсальний: **складаємо опори → знаходимо спільний струм → шукаємо спади**. Корисно щоразу перевіряти себе: сума спадів **мусить** дорівнювати напрузі джерела (закон напруг). Не сходиться — десь помилка в розрахунку.

### Прихований послідовний опір

Послідовні опори бувають не лише навмисні. Будь-яке реальне джерело має [внутрішній опір](book:electronics/internal-resistance), увімкнений послідовно з навантаженням; саме на ньому «губиться» частина напруги, тому батарейка під навантаженням **просідає**. Так само послідовно додається [опір довгих дротів](book:physics/resistivity) — звідси падіння напруги на лінії. Рахуючи реальне коло, тримайте в голові ці **сховані** послідовні опори: вони цілком справжні, хоч і не намальовані окремим резистором, і теж **додаються** до загальної суми.

> 🔧 **Навіщо це.** Послідовне з'єднання — щоденний робочий прийом, і три його властивості варто тримати напоготові. **Опори додаються** (R_екв = ΣR) і завжди дають більше за кожен — це найшвидший спосіб підняти опір чи **обмежити струм** (резистор перед світлодіодом). **Напруга ділиться** між елементами — на цьому стоїть [дільник напруги](book:electronics/voltage-divider). І коло **крихке**: будь-який обрив зупиняє все — тому саме послідовно вмикають **запобіжник** (хай рветься він, а не цінне навантаження). Побачили низку елементів «гуськом» — одразу думайте «спільний струм, опори й напруги додаються».

### Де це працює

![Де працює послідовне з'єднання](/book/electronics/analog/series-connection/img/applications.svg)
*Послідовне з'єднання: обмежує струм (резистор перед світлодіодом), складає опір (як один довший провідник, R = ρL/A) — але має слабке місце: розрив у будь-якій ланці гасить усе коло.*

У послідовне коло ставлять [струмообмежувальний резистор](book:electronics/resistor) перед світлодіодом: додатковий опір зменшує струм до безпечного. Скільки саме додати — рахують просто: зайву напругу поділити на бажаний струм (R = V_зайве / I). Так само складають опори чи напруги, коли потрібного номіналу нема під рукою.

Але є й **слабке місце**: струм тече одним шляхом, тож **розрив у будь-якій ланці гасить усе коло**. Класика — старі ялинкові **гірлянди** (від французького *guirlande* — «плетиво квітів»): перегоріла одна лампочка, і темніє вся низка, а шукай потім винну. Це зворотний бік «спільного струму»: ланцюг міцний рівно настільки, наскільки міцна його найслабша ланка. На початку 1970-х це обійшли: до кожної лампи паралельно її нитці додають крихітний **шунт** (англ. *shunt* — «відвід») — кілька витків окисленого дроту. Поки нитка ціла, шунт не проводить; щойно нитка перегоряє, повна напруга лягає на цей проміжок, тонкий окисел пробивається, і струм іде в обхід згаслої лампи — решта низки світить далі.

---

У **послідовному** колі струм **спільний**, напруги **додаються** (V = ΣVᵢ), а опори — теж **додаються**: R_екв = R₁ + R₂ + …, і завжди більший за кожен окремий. Звідси простий алгоритм (скласти опори → струм → спади) і прийом спрощення схем заміною групи на еквівалент. Послідовно обмежують струм і складають напругу, та платять крихкістю: один обрив гасить усе. Дзеркальне з'єднання — [паралельне](book:electronics/parallel-connection), де спільною стає вже напруга, а струм ділиться.
