# ⚙️ Вимірюємо індуктивність: за сталою часу L/R і за резонансом

> Вимірювач індуктивності спирається на [перехідні процеси в RL-ланцюзі](book:electronics/rl-time-constant). Для конденсатора той самий трюк дає [RC-метр](book:electronics/rc-time-constant/proj-capacitance-meter.md) — вимірювач із резистора й таймера; котушка просить дзеркального підходу. Розберемо два способи дістати L самотужки: швидкий «за сталою часу» для великих індуктивностей і точніший «за дзвоном» для дрібних.

### Задача

Є котушка без маркування — намотана вручну, знята з плати, або дросель зі стертим кодом. Дано: відомий резистор, генератор сходинки (хоч вивід мікроконтролера), осцилограф або компаратор із таймером, а для другого способу — відомий конденсатор. Треба L з точністю в кілька відсотків у діапазоні від мікрогенрі до десятків мілігенрі.

### Спосіб 1: сходинка на R–L і час до половини

Це точне дзеркало RC-метра. Послідовно з'єднуємо відомий R і невідому L, подаємо сходинку напруги — струм наростає за експонентою зі [сталою τ = L/R](book:electronics/rl-time-constant). Сам струм осцилографом не побачиш, але **напруга на резисторі йому пропорційна** — тож дивимося на V_R. Найзручніша мітка — **половина** кінцевого рівня: вона настає за t½ = 0.693·τ (та сама арифметика, що в [рівнянні RL](book:electronics/rl-time-constant/math-rl-ode.md)).

![Сходинка на R–L: схема й крива наростання](/book/electronics/analog/rl-time-constant/img/lr-step.svg)
*Відомий резистор + невідома котушка; напруга на R повторює струм. Засікаємо час до половини кінцевого рівня — і L обчислюється одним діленням. Не забути DCR: опір самої обмотки складається з R.*

```
подати ВИСОКО на ланцюжок R–L
чекати, поки V_R сягне половини кінцевого рівня;  засікти t½
L = (R + DCR) · t½ / 0.693
```

**Приклад.** R = 100 Ом, DCR котушки (мультиметром) = 3 Ом, виміряно t½ = 6.9 мкс:

```
τ = t½ / 0.693 = 10 мкс
L = τ · (R + DCR) = 10×10⁻⁶ · 103 ≈ 1.03 мГн
```

Метод чудовий для **великих** L (від сотень мікрогенрі): часи виходять зручні. А от для дроселя на 1 мкГн із тим самим R стала часу — 10 **наносекунд**: таке вже не зловиш ні таймером мікроконтролера, ні дешевим осцилографом. Тут потрібен другий спосіб.

### Спосіб 2: дзвін із відомим конденсатором

Підключимо паралельно котушці **відомий** конденсатор і «стукнемо» по контуру коротким імпульсом через чималий резистор. Контур задзвенить — це той самий [згасаючий дзвін, що й при розриві струму котушки](book:electronics/inductor-kickback) — на власній частоті, яку дає формула Томсона (тут — довідково; її виведення і вся фізика [резонансу LC-контуру](book:electronics/lc-resonance)):

```
f₀ = 1 / (2π·√(L·C))        →        L = 1 / ((2π·f₀)² · C)
```

Виміряти f₀ просто: порахувати на осцилографі **кілька періодів** загасаючого дзвону й поділити час на їх кількість — усереднення за N періодів одразу підвищує точність.

![Дзвін LC-контуру: схема й вимір періоду](/book/electronics/analog/rl-time-constant/img/ringing.svg)
*Імпульс «збуджує» контур із невідомої L і відомого C; далі вони дзвенять самі. Лічимо N періодів, ділимо час на N — маємо f₀, а з нього L. Великий послідовний резистор потрібен, щоб джерело не глушило дзвін.*

```
стукнути контур імпульсом;  зловити дзвін
виміряти час t за N періодів;   f₀ = N / t
L = 1 / ((2π·f₀)² · C)
```

**Приклад.** C = 10 нФ; чотири періоди дзвону вклалися в 25.2 мкс:

```
T = 25.2 / 4 = 6.3 мкс   →   f₀ ≈ 159 кГц
L = 1 / ((2π · 1.59×10⁵)² · 10⁻⁸) ≈ 100 мкГн
```

Резонансний спосіб б'є перший там, де той безсилий: він розтягує вимір крихітної L на багато періодів, працює на **малому** сигналі (без насичення осердя) і не потребує швидкого таймера.

### Що обрати

```
великі L (мГн і більше: реле, трансформатори)   →  спосіб 1, L/R
малі L (мкГн: дроселі, ВЧ-котушки)              →  спосіб 2, дзвін
перевірити насичення силового дроселя           →  спосіб 1 на різних струмах
```

### Пастки

- **Забутий DCR.** Для способу 1 опір обмотки складається з R; не врахували — систематично завищили L. Виміряти мультиметром — десять секунд.
- **Насичення осердя.** L [котушки з осердям залежить від струму](book:electronics/inductor-types): вимір на великому струмі дасть менше, ніж на малому, — і **обидва** результати чесні. Силовий дросель вартує міряти й на робочому струмі.
- **Власна ємність котушки.** У котушки є [паразитна ємність і власний резонанс](book:electronics/inductor-types) (SRF); для способу 2 беріть C хоча б у десятки разів більший за неї, інакше міряєте суміш.
- **Кволий дзвін.** Якщо коливання згасають за один-два періоди (великий DCR, низька добротність), точно виміряти період важко — спробуйте більший C: частота нижчає, періодів стає видно більше.
- **«Брикання» при комутації.** Розриваючи струм котушки в схемі способу 1, пам'ятайте про [сплеск напруги на котушці](book:electronics/inductor-kickback): або розряджайте через той самий R, або дайте захисний діод — особливо якщо сходинку дає вивід мікроконтролера.

Обидва способи — це та сама ідея, що й у RC-метрі: **перетворити невідомий компонент на час**, який легко виміряти. Конденсатор обертається на час заряджання; котушка — на час наростання струму або на період дзвону. Час — найточніша величина, яку вміє міряти будь-який мікроконтролер, і добра половина вимірювальних приладів стоїть саме на цьому трюку.
