# 🧮 Максимум через похідну: dP/dR = 0

> Числова вставка до [узгодження й максимальної передачі потужності](book:electronics/power-matching). Там потужність у навантаженні максимальна при R = R_th, і це «легко вивести, прирівнявши похідну до нуля». Тут цей крок зроблено **повністю**: знаходимо похідну, бачимо, чому вона занулюється рівно при R = R_th, і відкриваємо приємний бонус — пік виявиться «пласкоголовим».

### Задача як задача на максимум

Це класична задача на **екстремум**: маємо функцію однієї змінної й шукаємо її найбільше значення. Інструмент стандартний: узяти [похідну](book:math/derivative) й прирівняти до нуля — у максимумі дотична горизонтальна.

Джерело (V_th, R_th) живить навантаження R. Струм у колі I = V_th/(R_th + R), а потужність у навантаженні:

```
P(R) = I²·R = V_th² · R / (R_th + R)².
```

Це й є функція, яку максимізуємо по R.

### Виведення: беремо похідну

![Крива P(R) з піком при R=Rth і похідна, що там занулюється](/book/electronics/analog/power-matching/img/power-derivative.svg)
*Потужність P(R) росте від нуля, сягає піка й спадає. Її похідна dP/dR = V_th²·(R_th − R)/(R_th + R)³ дорівнює нулю рівно при R = R_th: чисельник (R_th − R) занулюється. Зліва від піка похідна додатна (P росте), справа — від'ємна (P спадає), тож це справді максимум.*

Продиференціюймо P = V_th²·R·(R_th + R)⁻² за правилом добутку:

```
dP/dR = V_th² · [ (R_th+R)⁻² + R·(−2)(R_th+R)⁻³ ]
      = V_th² · (R_th+R)⁻³ · [ (R_th+R) − 2R ]
      = V_th² · (R_th − R) / (R_th + R)³.
```

Тепер прирівняймо до нуля. Знаменник (R_th + R)³ для додатних опорів ніколи не нуль, тож усе вирішує **чисельник**:

```
dP/dR = 0   ⟺   R_th − R = 0   ⟺   R = R_th.
```

Це й шукана умова **узгодження**. Що це **максимум**, а не мінімум, видно зі знаку похідної: при R < R_th чисельник додатний (P **росте**), при R > R_th — від'ємний (P **спадає**). Перехід «+ → −» — це вершина. Підставивши R = R_th у P(R), дістаємо й саму висоту піка:

```
P_max = V_th²·R_th / (2R_th)² = V_th² / (4·R_th),
```

те саме [V_th²/(4R_th)](book:electronics/power-matching), що дає теорема узгодження.

### Бонус: пік «пласкоголовий»

![Нормована потужність і ККД у логарифмічному масштабі](/book/electronics/analog/power-matching/img/flat-top.svg)
*Нормована потужність P/P_max = 4R·R_th/(R+R_th)² має широкий, пологий пік: відхилившись від R_th удвічі (R = 2R_th чи R_th/2), маємо ще 8/9 ≈ 89 % максимуму. Пунктир — ККД η = R/(R+R_th): при узгодженні лише 50 %, а зростає він тільки при R ≫ R_th, де потужність у навантаженні вже мала.*

Похідна каже й більше — наскільки **гострий** максимум. Запишімо потужність у частках від піка: P/P_max = 4R·R_th/(R+R_th)². Підставмо «промах» удвічі: при R = 2·R_th виходить 4·2/(3)² = 8/9 ≈ **0.89**; так само й при R = R_th/2. Тобто, схибивши з опором **у два рази** в будь-який бік, ви все одно віддаєте **майже 90 %** максимальної потужності! Пік «пласкоголовий» — і це чудова новина для практики: точне узгодження не критичне, орієнтовного вистачає. (А математично це означає, що в максимумі мала й **друга** похідна — крива згинається полого.)

### Де працює

Прийом «продиференціюй і прирівняй до нуля» — універсальний ключ до будь-якої задачі на максимум чи мінімум, не лише цієї. Тут він строго довів теорему узгодження (R = R_th) і дав P_max = V_th²/(4R_th). А «пласкоголовість» піка пояснює, чому в реальному [узгодженні](book:electronics/power-matching) (антени, ВЧ-лінії) женуться не за ідеальною рівністю, а за «досить близьким» опором — бо втрати від невеликого промаху мізерні. Той самий метод ще не раз стане в пригоді: скрізь, де треба знайти найкраще значення параметра, починають із dP/dx = 0.
