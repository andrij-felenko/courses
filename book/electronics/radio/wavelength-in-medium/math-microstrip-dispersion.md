# 🧮 Математична теорія ефективної проникності, дисперсії та крайових ефектів мікросмужки

Для точного проектування мікрохвильових пристроїв на друкованих платах наближення однорідного середовища є непридатним. Оскільки сигнальна смужка розміщена на межі між діелектриком підкладки та навколишнім повітрям, структура електромагнітного поля описується неоднорідною крайовою задачею електродинаміки. Цей розділ містить строго формалізовані аналітичні та напівемпіричні математичні моделі, які пов'язують геометричні розміри провідника й фізичні параметри матеріалу з фазовою швидкістю, ефективною проникністю `ε[eff]`, хвильовим опором `Z₀`, частотною дисперсією та крайовим подовженням `Δl`.

## 1. Електростатична крайова задача та конформне відображення

У квазістатичному наближенні (коли поперечні розміри лінії набагато менші за довжину хвилі у діелектрику, `w, h ≪ λ`) просторовий розподіл електричного потенціалу `φ(x, y)` у поперечному перерізі мікросмужки задовольняє двовимірне рівняння Лапласа:

```
∂²φ/∂x² + ∂²φ/∂y² = 0      [рівняння Лапласа для однорідних підобластей]
```

Граничні умови на поверхнях розділу задаються потенціалами провідників та неперервністю тангенціальних складових напруженості поля й нормальних складових електричного зміщення:

```
φ(x, 0) = 0                                       [потенціал нижньої площини заземлення GND]
φ(x, h) = V₀,   при |x| ≤ w/2                     [потенціал сигнальної мікросмужки]
φ(x, y)|y=h⁻ = φ(x, y)|y=h⁺                       [неперервність потенціалу на межі діелектрик-повітря]
ε[r] · (∂φ/∂y)|y=h⁻ = 1.0 · (∂φ/∂y)|y=h⁺          [неперервність нормальної складової вектора D]
```

### Енергетичне визначення коефіцієнта заповнення та ефективної проникності

Повна електростатична енергія `W[e]`, накопичена на одиницю довжини мікросмужкової лінії, є інтегралом від об'ємної густини енергії електричного поля `w[e] = (1/2) · D · E = (1/2) · ε₀ · ε[r](x, y) · |∇φ|²` по всій площині поперечного перерізу `S`:

```
W[e] = (1 / 2) · ∬_S ε₀ · ε(x, y) · (|∂φ/∂x|² + |∂φ/∂y|²) dx dy
```

Цю енергію можна розділити на дві незалежні складові — енергію, зосереджену всередині діелектричної підкладки `W[sub]`, та енергію, зосереджену у відкритому повітряному напівпросторі `W[air]`:

```
W[e] = W[sub] + W[air]
     = (1 / 2) · ε₀ · ε[r] · ∬_sub |∇φ|² dx dy + (1 / 2) · ε₀ · ∬_air |∇φ|² dx dy
```

З іншого боку, через повну погонну ємність лінії `C` та різницю потенціалів `V₀` енергія записується у вигляді `W[e] = (1/2) · C · V₀²`. Якщо подумки вилучити діелектрик підкладки й замінити його повітрям (`ε[r] = 1`), отримаємо вакуумну конфігурацію з ємністю `C₀` та енергією `W₀ = (1/2) · C₀ · V₀² = (1/2) · ε₀ · ∬_S |∇φ₀|² dx dy`.

Ефективна діелектрична проникність `ε[eff]` за фундаментальним фізичним означенням є коефіцієнтом збільшення погонної ємності лінії при внесенні діелектрика:

```
ε[eff] = C / C₀ = W[e] / W₀                       [фундаментальне означення ефективної проникності]
```

Визначаючи безрозмірний геометричний коефіцієнт заповнення діелектриком `q` як відношення енергії поля в підкладці до повної енергії вакуумного аналога:

```
q = (∬_sub |∇φ|² dx dy) / (∬_S |∇φ₀|² dx dy)      [коефіцієнт заповнення підкладки q]
```

Отримуємо строге лінійне розкладання ефективної проникності за коефіцієнтом заповнення:

```
ε[eff] = 1.0 + q · (ε[r] − 1.0)                   [зв'язок ефективної проникності з фактором q]
```

### Зв'язок погонних параметрів із хвильовими характеристиками

Погонна ємність лінії `C` та погонна індуктивність `L` визначають телеграфні параметри лінії передачі. Оскільки немагнітна підкладка (`μ[r] = 1`) не чинить опору магнітному потоку, розподіл магнітного поля збігається з розподілом у вакуумі. Тому погонна індуктивність зв'язана з вакуумною ємністю співвідношенням:

```
L = 1 / (c² · C₀) = μ₀ · ε₀ / C₀                  [погонна індуктивність немагнітної лінії]
```

Підставляючи вирази для `L` та `C = ε[eff] · C₀` у класичні формули хвильового опору та фазової швидкості, отримуємо систему зв'язку параметрів:

```
v[p] = 1 / √(L · C)
     = 1 / √((1 / (c² · C₀)) · (ε[eff] · C₀))
     = c / √(ε[eff])                              [фазова швидкість квазі-ТЕМ хвилі]

Z₀ = √(L / C)
   = √((1 / (c² · C₀)) / (ε[eff] · C₀))
   = 1 / (c · C₀ · √(ε[eff]))                    [хвильовий опір через вакуумну ємність C₀]

λ[g] = v[p] / f
     = c / (f · √(ε[eff]))
     = λ₀ / √(ε[eff])                             [довжина хвилі у мікросмужці]
```

## 2. Аналітичні рівняння Гаммерстада та Єнсена

Для інженерного проектування точний чисельний розв'язок крайової задачі конформного відображення Шварца — Крістоффеля апроксимують аналітичними моделями Еріка Гаммерстада та Ойвінда Єнсена. Їхня точність перевірена методом скінченних елементів (FEM) і забезпечує похибку менше 0.2% у практичних діапазонах параметрів друкованих плат (`0.01 ≤ w/h ≤ 100`, `1 ≤ ε[r] ≤ 128`).

### Прямий аналіз: обчислення ε[eff](0) та Z₀ за відомими w та h

Позначимо нормовану ширину смужки як `u = w / h`.

**Крок 1. Розрахунок геометричних функцій:**

```
a(u) = 1.0 + (1.0 / 49.0) · ln((u⁴ + (u / 52.0)²) / (u⁴ + 0.432)) + (1.0 / 18.7) · ln(1.0 + (u / 18.1)³)
b(ε[r]) = 0.564 · ((ε[r] − 0.9) / (ε[r] + 3.0))⁰·⁰⁵
```

**Крок 2. Розрахунок статичної проникності ε[eff](0):**

```
ε[eff](0) = ((ε[r] + 1.0) / 2.0) + ((ε[r] − 1.0) / 2.0) · (1.0 + 10.0 / u)^(-a(u) · b(ε[r]))
```

**Крок 3. Розрахунок хвильового опору Z₀:**

Для розрахунку використовується характеристичний опір вільного простору `η₀ = √(μ₀ / ε₀) = 376.730313668 Ом`.

Для вузьких ліній (`u = w / h ≤ 1.0`, що зазвичай відповідає високим хвильовим опорам `Z₀ > 45...60 Ом` залежно від діелектрика):

```
F(u) = 6.0 + (2.0 · π − 6.0) · exp(-(30.666 / u)⁰·⁷⁵²)
Z₀(u) = (η₀ / (2.0 · π · √(ε[eff](0)))) · ln(F(u) / u + √(1.0 + (2.0 / u)²))
```

Для широких ліній (`u = w / h > 1.0`, низькоомні узгоджувальні секції та лінії живлення):

```
Z₀(u) = (η₀ / √(ε[eff](0))) · (1.0 / (u + 1.393 + 0.667 · ln(u + 1.444)))
```

### Врахування скінченної товщини мідної фольги t

На реальних платах товщина міді становить `t = 18 мкм` (0.5 oz), `35 мкм` (1.0 oz) або `70 мкм` (2.0 oz). Скінченна товщина збільшує поверхню провідника, створюючи додаткову бічну ємність торців. Цей ефект враховується еквівалентним розширенням смужки `Δu`:

```
Δu = (t / (π · h)) · (1.0 + ln(2.0 · h / t)),   якщо u ≥ 1 / (2π)
Δu = (t / (π · h)) · (1.0 + ln(4.0 · π · w / t)), якщо u < 1 / (2π)

u[eff] = u + Δu · (1.0 − 0.5 · exp(-0.69 · u / Δu))
```

Значення `u[eff]` підставляють у формули для `Z₀` та `ε[eff]` замість геометричного `u`.

### Зворотний синтез: обчислення ширини w за заданим Z₀

Коли потрібно знайти ширину доріжки `w` для отримання цільового хвильового опору `Z₀`, Гаммерстад розробив точні формули прямого синтезу без необхідності чисельних ітерацій.

Спочатку обчислюються допоміжні параметри `A` (для вузьких ліній) та `B` (для широких ліній):

```
A = (Z₀ / 60.0) · √((ε[r] + 1.0) / 2.0) + ((ε[r] − 1.0) / (ε[r] + 1.0)) · (0.23 + 0.11 / ε[r])
B = (377.0 · π) / (2.0 · Z₀ · √(ε[r]))
```

Критерій вибору розрахункової гілки перевіряється за величиною параметра `A`:

Якщо `w / h ≤ 2.0` (що відповідає `A > 1.52`):
```
u = w / h = (8.0 · exp(A)) / (exp(2.0 · A) − 2.0)
```

Якщо `w / h > 2.0` (що відповідає `A ≤ 1.52`):
```
u = w / h = (2.0 / π) · (B − 1.0 − ln(2.0 · B − 1.0) + ((ε[r] − 1.0) / (2.0 · ε[r])) · (ln(B − 1.0) + 0.39 − 0.61 / ε[r]))
```

Фізична ширина мідного провідника отримується простим множенням на товщину підкладки: `w = u · h`.

## 3. Моделювання частотної дисперсії: моделі Гетсінгера та Кіршнінга — Янсена

Із зростанням частоти квазістатичне наближення втрачає точність, оскільки просторовий розподіл електромагнітного поля зазнає динамічної перебудови.

### Фізична модель Вільяма Гетсінгера (Getsinger Dispersion Model)

Вільям Гетсінгер запропонував еквівалентну хвилевідну модель, яка розглядає мікросмужку як неоднорідний хвилевід з двома паралельними діелектричними областями. За Гетсінгером, дисперсія виникає через те, що на високих частотах виникає поперечний резонанс, який змушує поздовжні складові поля підлаштовуватися під граничні умови.

Формула Гетсінгера зв'язує дисперсійну проникність із параметром перехідної частоти `f[50]`:

```
ε[eff](f) = ε[r] − ((ε[r] − ε[eff](0)) / (1.0 + G · (f / f[50])²))
```

Тут `f[50]` — частота, на якій ефективна проникність проходить рівно половину шляху між `ε[eff](0)` та `ε[r]`:

```
f[50] = Z₀ / (2.0 · μ₀ · h) = (Z₀ · c) / (2.0 · η₀ · h) [характеристична частота дисперсії]
G = 0.6 + 0.009 · Z₀                              [емпіричний фактор крутизни дисперсії]
```

Формула Гетсінгера добре пояснює фізику процесу, проте для прецизійного проектування на частотах понад 10 ГГц використовують досконалішу модель Кіршнінга та Янсена.

### Модель Кіршнінга та Янсена (Kirschning-Jansen Dispersion Model)

Ця модель розроблена на основі строгих чисельних розв'язків інтегральних рівнянь методом зважених нев'язок (Spectral Domain Approach, SDA) і діє в діапазоні до 100 ГГц:

```
ε[eff](f) = ε[r] − ((ε[r] − ε[eff](0)) / (1.0 + P(f)))
```

Функція дисперсії `P(f)` визначається через нормовану частоту `f_n = f · h` (де частота `f` задана в ГГц, а товщина діелектрика `h` — у сантиметрах):

```
f_n = f · (h / 10.0)                              [нормована частота в ГГц · см]

P₁ = 0.27488 + (0.6315 + 0.525 / (1.0 + 0.0157 · f_n)²⁰) · u − 0.065683 · exp(-8.7513 · u)
P₂ = 0.33622 · (1.0 − exp(-0.03442 · ε[r]))
P₃ = 0.0363 · exp(-4.6 · u) · (1.0 − exp(-(f_n / 3.87)⁴·⁹⁷))
P₄ = 1.0 + 2.751 · (1.0 − exp(-(ε[r] / 15.916)⁸))

P(f) = P₁ · P₂ · ((0.1844 + P₃ · P₄) · 10.0 · f_n)¹·⁵⁷⁶³
```

### Динамічний хвильовий опір Z₀(f)

Поряд із проникністю `ε[eff](f)`, хвильовий опір мікросмужки також зазнає частотної дисперсії. Оскільки на високих частотах магнітне та електричне поля стягуються під смужку нерівномірно, хвильовий опір повільно зростає з частотою за формулою Янсена — Кіршнінга:

```
Z₀(f) = Z₀(0) · ((ε[eff](0) / ε[eff](f))⁰·⁵) · ((ε[eff](f) − 1.0) / (ε[eff](0) − 1.0))
```

На частотах до 10 ГГц зміна хвильового опору зазвичай не перевищує `0.5...1.5 Ом`, проте для міліметрових радарів (24 ГГц та 77 ГГц) облік `Z₀(f)` є обов'язковим для усунення паразитних відбиттів на переходах.

## 4. Зв'язані мікросмужки: парна та непарна ефективні проникності

Коли дві мікросмужкові лінії розміщені паралельно на відстані `s` одна від одної (диференційна пара або спрямований відгалужувач), взаємний ємнісний та індуктивний зв'язок розщеплює єдину квазі-ТЕМ моду на дві фундаментальні моди:

1. **Парна мода (Even Mode):** струми в обох лініях течуть синфазно і в одному напрямку (`+` і `+`). Між провідниками силові лінії електричного поля відсутні — поле спрямоване суто вертикально до шару заземлення через підкладку.
2. **Непарна мода (Odd Mode):** струми течуть у протифазі (`+` і `−`). Між провідниками виникає сильне горизонтальне електричне поле, значна частина якого замикається через повітряний проміжок над платою.

Через різний розподіл полів у повітрі та підкладці парна та непарна моди мають **різні ефективні діелектричні проникності**:

```
ε[eff,e] > ε[eff,o]                               [парна проникність завжди вища за непарну]
```

Формули Кіршнінга та Янсена для зв'язаних ліній визначають ці моди через нормовані параметри `u = w / h` та `g = s / h`:

```
v[p,even] = c / √(ε[eff,e])                       [фазова швидкість парної моди]
v[p,odd] = c / √(ε[eff,o])                        [фазова швидкість непарної моди]
```

Оскільки `ε[eff,o] < ε[eff,e]`, непарна мода поширюється **швидше** за парну (`v[p,odd] > v[p,even]`). Це фундаментальний недолік відкритих мікросмужкових спрямованих відгалужувачів: різниця фазових швидкостей руйнує спрямованість (Directivity) відгалужувача, обмежуючи її рівнем `15...20 дБ`. Для вирівнювання фазових швидкостей застосовують зубчасті меандри (*Wiggly coupled lines*) або переходять на смужкові лінії (Stripline), де `ε[eff,e] = ε[eff,o] = ε[r]`.

## 5. Загасання у провіднику та інкрементне правило Вілера

Омічні втрати в мідному провіднику мікросмужки `α[c]` викликані скін-ефектом та крайовим витісненням струму (Current Crowding). Густина струму `J[s](x)` по ширині смужки розподілена нерівномірно і має сингулярний сплеск на гострих бічних краях провідника через крайовий електростатичний ефект:

```
J[s](x) ∝ 1.0 / √(1.0 − (2.0 · x / w)²)           [крайове зростання густини струму на ребрах]
```

Для аналітичного розрахунку втрат застосовують **правило інкрементного приросту індуктивності Гарольда Вілера** (Wheeler's Incremental Inductance Rule). За Вілером, поверхневий опір металу `R[s] = √(π · f · μ₀ / σ)` еквівалентний уявній зміні геометричних меж провідника на половину глибини проникнення скін-шару `δ / 2`.

Коефіцієнт згасання в провіднику `α[c]` (у Нп/м) обчислюється через похідні характеристичного імпедансу за геометрією:

```
α[c] = (R[s] / (2.0 · Z₀ · η₀)) · (∂Z₀ / ∂h - ∂Z₀ / ∂w - ∂Z₀ / ∂t)
```

За спрощеною інженерною формулою П'юсела (R. A. Pucel) для широких смужок (`w / h ≥ 1.0`):

```
α[c] ≈ (R[s] / (Z₀ · h)) · (1.0 / π) · (1.0 + (h / w) + (h / (π · w)) · ln(2.0 · h / t))
```

Внутрішня індуктивність скін-шару металу `L[int] = R[s] / ω` також вносить додаткову паразитну затримку фази, сповільнюючи хвилю на частки відсотка на низьких частотах НВЧ-діапазону.

## 6. Математична теорія крайових неоднорідностей та ємності розриву

Будь-яка зміна геометрії мікросмужки (обрив доріжки, сходинка ширини, прямий кут чи Т-подібне з'єднання) викликає локальну деформацію вищих нерозповсюджуваних мод поля, що моделюється еквівалентними LC-ланцюгами розсіяння.

### Електростатичний аналіз розімкненого кінця (Open-End Discontinuity)

На відкритому кінці смужки струм падає до нуля, але напруга досягає максимуму. Силові лінії електричного поля розширюються у тривимірному просторі за межі геометричного краю металізації, накопичуючи додатковий електричний заряд `Q[extra]`.

Інтегральне рівняння зв'язку надлишкового заряду з потенціалом `V₀` дає еквівалентну крайову ємність розриву `C[end]`:

```
C[end] = Q[extra] / V₀ = (1 / V₀) · ∬_end ε(r) · (∇φ · n) dS
```

Ця ємність створює на кінці лінії вхідну реактивну провідність (адмітанс):

```
Y[in, end] = j · ω · C[end]
```

З теорії довгих ліній вхідний адмітанс розімкненого відрізка лінії довжиною `Δl` становить:

```
Y[in, stub] = j · Y₀ · tan(β · Δl)
```

Прирівнюючи провідності для малих довжин (`tan(β · Δl) ≈ β · Δl`), отримуємо зв'язок між ємністю `C[end]` та еквівалентним подовженням `Δl`:

```
j · ω · C[end] = j · Y₀ · β · Δl
Δl = (ω · C[end]) / (Y₀ · β)
   = (ω · C[end]) / ((1 / Z₀) · (ω / v[p]))
   = C[end] · Z₀ · v[p]
   = C[end] / C_length                            [подовження як відношення крайової ємності до погонної]
```

Замкнена аналітична апроксимація Гаммерстада дає точний розрахунок `Δl` через параметри підкладки та геометрію:

```
Δl / h = 0.412 · ((ε[eff] + 0.3) / (ε[eff] − 0.258)) · ((u + 0.264) / (u + 0.8))
```

### Сходинковий перехід ширини (Step Discontinuity)

Коли мікросмужка різко змінює ширину від `w₁` (опір `Z₁`) до `w₂` (опір `Z₂`), виникає сходинкова неоднорідність. Вона моделюється паралельною ємністю сходинки `C[s]` та послідовними індуктивностями `L₁` і `L₂`:

```
C[s] / √(w₁ · w₂) = (1 / 100) · (1.3 · (ε[r] + 1.0) + 0.25 · (ε[r] − 1.0) · ln(w₂ / w₁)) [пФ/мм]
L₁ = L_step · (w₂ / (w₁ + w₂))
L₂ = L_step · (w₁ / (w₁ + w₂))
L_step = 0.000987 · h · (1.0 − (Z₁ / Z₂) · √(ε[eff,1] / ε[eff,2]))² [нГн]
```

### Прямокутний злам лінії (Mitered Bend)

У місці повороту доріжки на 90° виникає надлишок площі металізації, що створює паразитну ємність кута `C[bend]`, яка відбиває високочастотні сигнали. Щоб усунути відбиття, кут зрізають (виконують скіс або мітралізацію — Miter Cut).

Оптимальний відсоток зрізу металізації за формулою Дугласа (Douville and James) становить:

```
M = (100.0 · (w_diag − w) / w)
  = 52.0 + 65.0 · exp(-1.35 · (w / h))            [відсоток зрізу кута M у %]
```

Скошений таким чином злам усуває ємнісний сплеск і зберігає фазову неперервність хвилі аж до частот, де `w / λ[g] < 0.1`.

## 7. Багатосекційні трансформатори: біноміальні та чебишовські переходи

Односекційний чвертьхвильовий трансформатор має обмежену смугу пропускання (зазвичай 10–20%). Для широкосмугового узгодження використовують каскад із `N` чвертьхвильових секцій.

### 7.1. Біноміальний трансформатор (Максимально гладкий)

Коефіцієнт відбиття синтезується через біноміальні коефіцієнти Ньютона:

```
ln(Z[n+1] / Z[n]) = 2⁻ᴺ · (N! / (n! · (N − n)!)) · ln(R[L] / Z₀)
```

Такий трансформатор забезпечує нульові перші `N−1` похідних коефіцієнта відбиття на центральній частоті (`dⁿ|Γ| / dfⁿ = 0`), даючи максимально плоску характеристику без пульсацій у смузі.

### 7.2. Чебишовський трансформатор (Рівнохвильовий)

Для отримання гранично широкої смуги при заданому максимальному коефіцієнті відбиття `Γ[m]` характеристика оптимізується за поліномами Чебишова першого роду `T_N(x)`:

```
Γ(θ) = A · exp(-j · N · θ) · T_N(sec(θ_m) · cos(θ))
```

Відносна смуга пропускання `Δf / f₀` чебишовського переходу визначається граничним кутом `θ_m`:

```
Δf / f₀ = 2.0 − (4.0 / π) · arccos(1.0 / cosh((1.0 / N) · arcosh(ln(R[L] / Z₀) / (2.0 · Γ[m]))))
```

Кожна секція розраховується як самостійна мікросмужка зі своєю власною шириною `w_n`, власною ефективною проникністю `ε[eff,n]` та скоригованою чвертьхвильовою довжиною `L_n = λ[g,n] / 4`.

## 8. Повний матричний розрахунок ланцюга узгодження (ABCD-параметри)

Для розрахунку частотної характеристики та смуги пропускання чвертьхвильового трансформатора використовують апарат класичних матриць передачі (ABCD-параметрів).

Матриця передачі відрізка лінії передачі з хвильовим опором `Z[T]`, коефіцієнтом загасання `α` та фазовою сталою `β(f) = (2π · f / c) · √(ε[eff](f))` довжиною `L` має вигляд:

```
γ = α + j · β(f)                                  [комплексна стала поширення]
[A  B]   [ cosh(γ · L)       Z[T] · sinh(γ · L) ]
[C  D] = [ sinh(γ · L) / Z[T]   cosh(γ · L)     ]
```

Для ідеальної лінії без втрат (`α = 0`, `cosh(jθ) = cos(θ)`, `sinh(jθ) = j · sin(θ)`), де електрична довжина `θ = β(f) · L`:

```
[A  B]   [ cos(θ)        j · Z[T] · sin(θ) ]
[C  D] = [ j · sin(θ) / Z[T]    cos(θ)     ]
```

При підключенні до виходу трансформатора активного навантаження `R[L]` вхідний імпеданс ланцюга `Z[in](f)` виражається через елементи матриці:

```
Z[in](f) = (A · R[L] + B) / (C · R[L] + D)
         = (R[L] · cos(θ) + j · Z[T] · sin(θ)) / (cos(θ) + j · (R[L] / Z[T]) · sin(θ))
```

На центральній резонансній частоті `f₀`, де довжина трансформатора становить рівно чверть хвилі (`θ = π / 2`, `cos(π/2) = 0`, `sin(π/2) = 1`):

```
Z[in](f₀) = (j · Z[T]) / (j · R[L] / Z[T])
          = Z[T]² / R[L]                          [ідеальна трансформація на центральній частоті]
```

Комплексний коефіцієнт відбиття на вході лінії `Γ(f)` відносно тракту `Z₀` становить:

```
Γ(f) = (Z[in](f) − Z₀) / (Z[in](f) + Z₀)
```

Підставляючи вираз для `Z[in](f)`, отримуємо залежність відхилення коефіцієнта відбиття від розстроювання частоти `Δf = f − f₀`:

```
|Γ(θ)| = |R[L] − Z₀| / √(4 · Z₀ · R[L] + (Z[T] − (Z₀ · R[L] / Z[T]))² · cot²(θ))
```

Коефіцієнт стоячої хвилі (КСХ) та зворотні втрати (Return Loss, `RL` у дБ) обчислюються за формулами:

```
VSWR(f) = (1.0 + |Γ(f)|) / (1.0 − |Γ(f)|)
RL(f) = −20.0 · log₁₀(|Γ(f)|)
```

## 9. Покроковий розрахунок трисекційного чебишовського узгоджувача

Розглянемо практичну задачу широкосмугового узгодження тракту `Z₀ = 50 Ом` з навантаженням `R[L] = 200 Ом` на центральній частоті `f₀ = 5.0 ГГц` з максимальним коефіцієнтом відбиття в робочій смузі `Γ[m] = 0.05` (що відповідає `КСХ ≤ 1.105` та `Return Loss ≥ 26.0 дБ`) на підкладці Rogers RO4350B (`ε[r] = 3.66`, `h = 0.508 мм`).

**Крок 1. Розрахунок коефіцієнтів відбиття на переходах:**

Для трисекційного (`N = 3`) трансформатора характеристичний поліном Чебишова має вигляд:

```
T₃(x) = 4 · x³ − 3 · x
```

Знаходимо коефіцієнт масштабування `sec(θ_m)`:

```
sec(θ_m) = cosh((1 / 3) · arcosh(ln(200 / 50) / (2 · 0.05))) [підстановка параметрів R_L, Z₀, Gamma_m]
         = cosh((1 / 3) · arcosh(1.38629 / 0.10))            [обчислення логарифма відношення опорів]
         = cosh((1 / 3) · arcosh(13.8629))                   [ділення на подвоєну пульсацію]
         = cosh((1 / 3) · 3.3204)                            [обчислення оберненого гіперболічного косинуса]
         = cosh(1.1068)                                      [множення на фактор 1/N для N=3]
         = 1.6754                                            [фінальний коефіцієнт масштабування]
```

Граничний кут робочої смуги:

```
θ_m = arccos(1 / 1.6754) = arccos(0.59687) = 0.9312 рад = 53.35°
```

Відносна смуга пропускання трансформатора становить:

```
Δf / f₀ = 2.0 − (4.0 / π) · (53.35° · π / 180°)              [формула смуги для рівнохвильового узгоджувача]
        = 2.0 − (4.0 · 0.9312 / 3.14159)                     [переведення кута у радіани]
        = 2.0 − 1.1856                                       [проміжне спрощення коефіцієнта смуги]
        = 0.8144 (81.4%)                                     [відносна смуга узгодження 81.4%]
```

Тобто узгоджувач працює в діапазоні від `f_min = 2.96 ГГц` до `f_max = 7.04 ГГц` з КСХ не гірше 1.10.

**Крок 2. Розрахунок хвильових опорів трьох секцій:**

За формулами синтезу Чебишова коефіцієнти відбиття на границях секцій становлять:

```
Γ₀ = Γ₃ = (Γ[m] / 2) · sec³(θ_m) = (0.05 / 2) · (1.6754)³ = 0.025 · 4.703 = 0.1176
Γ₁ = Γ₂ = (3 · Γ[m] / 2) · (sec³(θ_m) − sec(θ_m)) = 0.075 · (4.703 − 1.6754) = 0.2271
```

Обчислюємо хвильові опори секцій:

```
Z₁ = Z₀ · exp(2 · Γ₀) = 50.0 · exp(2 · 0.1176) = 50.0 · 1.2651 = 63.26 Ом
Z₂ = Z₁ · exp(2 · Γ₁) = 63.26 · exp(2 · 0.2271) = 63.26 · 1.5749 = 99.63 Ом
Z₃ = Z₂ · exp(2 · Γ₂) = 99.63 · exp(2 · 0.2271) = 99.63 · 1.5749 = 156.91 Ом
Z_check = Z₃ · exp(2 · Γ₃) = 156.91 · 1.2651 = 198.5 Ом ≈ 200 Ом [узгоджено]
```

**Крок 3. Топологічний синтез мікросмужок секцій:**

Для кожної секції на підкладці Rogers RO4350B (`ε[r] = 3.66`, `h = 0.508 мм`) на частоті 5.0 ГГц розраховуємо ширину та довжину:

```
Секція 1 (Z₁ = 63.26 Ом):
  u₁ = w₁ / h = 1.462 -> w₁ = 0.743 мм
  ε[eff,1](5.0 ГГц) = 2.764
  λ[g,1] = (299.79 / 5.0) / √2.764 = 59.96 / 1.6625 = 36.06 мм
  L₁ = λ[g,1] / 4 = 9.02 мм

Секція 2 (Z₂ = 99.63 Ом):
  u₂ = w₂ / h = 0.654 -> w₂ = 0.332 мм
  ε[eff,2](5.0 ГГц) = 2.571
  λ[g,2] = 59.96 / √2.571 = 59.96 / 1.6034 = 37.39 мм
  L₂ = λ[g,2] / 4 = 9.35 мм

Секція 3 (Z₃ = 156.91 Ом):
  u₃ = w₃ / h = 0.208 -> w₃ = 0.106 мм
  ε[eff,3](5.0 ГГц) = 2.443
  λ[g,3] = 59.96 / √2.443 = 59.96 / 1.5630 = 38.36 мм
  L₃ = λ[g,3] / 4 = 9.59 мм
```

Кожна секція має власну фізичну довжину та ширину, що забезпечує ідеальний широкосмуговий перехід без виникнення паразитних фазових спотворень.
