# 🧮 Математика матриць повороту, кватерніонів та кутів Ейлера

У теоретичній механіці, навігації та протоколах обміну просторовими даними орієнтація рухомого твердого тіла описує взаємне геометричне положення між зв'язаним базисом апарата (Body Frame) та опорним навігаційним базисом (Navigation Frame). Математичний опис просторового обертання спирається на три взаємопов'язані апарати: кути послідовних поворотів Тейта-Браяна (Roll, Pitch, Yaw), матрицю напрямних косинусів (Direction Cosine Matrix, DCM) та унітарні кватерніони Гамільтона. Нижче наведено строге виведення матриці повороту, алгебраїчний зв'язок між представленнями, кінематичні диференціальні рівняння та аналітичне доведення сингулярності шарнірного замка (Gimbal Lock).

---

### 1. Геометрична природа поворотів та спеціальна ортогональна група SO(3)

Поворот тривимірного евклідового простору є лінійним перетворенням, яке зберігає довжини будь-яких векторів, кути між ними та правосторонню орієнтацію базису (хіральність). Множина всіх таких перетворень утворює групу Лі, що позначається як **спеціальна ортогональна група порядку 3** — `SO(3)` (англ. *Special Orthogonal Group*).

Будь-який елемент цієї групи представляється дійсною матрицею `R` розміром `3 × 3`, для якої виконуються дві фундаментальні умови:

1. **Ортогональність:** Добуток матриці на її транспоновану дорівнює одиничній матриці `I`:
   ```
   R · Rᵀ = Rᵀ · R = I
   ```
   Звідси випливає, що обернена матриця повороту збігається з транспонованою: `R⁻¹ = Rᵀ`.

2. **Спеціальність (збереження орієнтації):** Визначник матриці строго дорівнює плюс одиниці:
   ```
   det(R) = +1
   ```
   (Матриці з `det(R) = -1` описують дзеркальні відбиття, які змінюють праву трійку векторів на ліву і не є фізичними поворотами твердого тіла).

Стовпці матриці `R_body_to_nav` є одиничними векторами осей зв'язаної системи координат `(X_b, Y_b, Z_b)`, вираженими у проекціях на осі навігаційної системи. Кожен елемент `R_{ij}` дорівнює скалярному добутку відповідних базисних ортів (косинусу просторового кута між ними), звідки й походить назва «матриця напрямних косинусів».

### 2. Покрокове виведення матриці Тейта-Браяна для послідовності Z-Y-X

В авіаційній конвенції Тейта-Браяна перехід від вихідного навігаційного базису `F_nav` до зв'язаного базису корпусу `F_body` здійснюється через три послідовні внутрішні повороти (англ. *intrinsic rotations*):

```
F_nav ──(поворот навколо осі Z на кут ψ)──> F₁ ──(поворот навколо осі Y' на кут θ)──> F₂ ──(поворот навколо осі X'' на кут ϕ)──> F_body
```

#### Крок 1. Поворот рискання (Yaw) навколо осі Z на кут `ψ`:

Вісь Z залишається нерухомою, а площина горизонту `X-Y` повертається за годинниковою стрілкою:

```
R_z(ψ) = [  cos(ψ)   sin(ψ)   0 ]
         [ -sin(ψ)   cos(ψ)   0 ]
         [    0         0     1 ]
```

#### Крок 2. Поворот тангажу (Pitch) навколо проміжної осі Y' на кут `θ`:

Вісь Y' залишається нерухомою, а поздовжня вісь апарата піднімається вище горизонту:

```
R_y(θ) = [  cos(θ)   0  -sin(θ) ]
         [    0      1     0    ]
         [  sin(θ)   0   cos(θ) ]
```

#### Крок 3. Поворот крену (Roll) навколо кінцевої осі носа X'' на кут `ϕ`:

Вісь X'' залишається нерухомою, праве крило опускається вниз:

```
R_x(ϕ) = [  1     0        0    ]
         [  0   cos(ϕ)   sin(ϕ) ]
         [  0  -sin(ϕ)   cos(ϕ) ]
```

#### Повний добуток матриць:

Оскільки внутрішні повороти виконуються відносно рухомих осей, повна матриця переходу від навігаційної системи до зв'язаної формується послідовним множенням зліва направо:

```
R_nav_to_body = R_x(ϕ) · R_y(θ) · R_z(ψ)
```

Виконаємо множення перших двох матриць:

```
R_y(θ) · R_z(ψ) = 
[ cos(θ)cos(ψ)    cos(θ)sin(ψ)   -sin(θ) ]
[   -sin(ψ)         cos(ψ)          0    ]
[ sin(θ)cos(ψ)    sin(θ)sin(ψ)    cos(θ) ]
```

Помноживши результат зліва на матрицю `R_x(ϕ)`, отримуємо повну аналітичну матрицю напрямних косинусів:

```
R_nav_to_body = 
[ cos(θ)cos(ψ)                      cos(θ)sin(ψ)                     -sin(θ)       ]
[ sin(ϕ)sin(θ)cos(ψ) - cos(ϕ)sin(ψ) sin(ϕ)sin(θ)sin(ψ) + cos(ϕ)cos(ψ) sin(ϕ)cos(θ) ]
[ cos(ϕ)sin(θ)cos(ψ) + sin(ϕ)sin(ψ) cos(ϕ)sin(θ)sin(ψ) - sin(ϕ)cos(ψ) cos(ϕ)cos(θ) ]
```

Матриця переходу у зворотному напрямку (перетворення вектора зі зв'язаних осей у навігаційні `v_nav = R_body_to_nav · v_body`) дорівнює транспонованій:

```
R_body_to_nav = (R_nav_to_body)ᵀ = 
[ cos(θ)cos(ψ)   sin(ϕ)sin(θ)cos(ψ) - cos(ϕ)sin(ψ)   cos(ϕ)sin(θ)cos(ψ) + sin(ϕ)sin(ψ) ]
[ cos(θ)sin(ψ)   sin(ϕ)sin(θ)sin(ψ) + cos(ϕ)cos(ψ)   cos(ϕ)sin(θ)sin(ψ) - sin(ϕ)cos(ψ) ]
[   -sin(θ)                 sin(ϕ)cos(θ)                        cos(ϕ)cos(θ)           ]
```

### 3. Гіперкомплексна алгебра Гамільтона та унітарні кватерніони

Кути Ейлера страждають від топологічної проблеми: неможливо покрити гладку групу обертань тривимірного простору трьома глобальними координатами без особливих точок. Для усунення цієї проблеми застосовують чотиривимірний гіперкомплексний простір кватерніонів `ℍ`.

Кватерніон `q` складається зі скалярної частини `w` та трьох уявних одиниць `(i, j, k)`:

```
q = w + x·i + y·j + z·k = [w, x, y, z]ᵀ = [w, q_v]ᵀ
```

Фундаментальні алгебраїчні правила множення уявних одиниць Гамільтона:

```
i² = j² = k² = i·j·k = -1
i·j = k,   j·i = -k
j·k = i,   k·j = -i
k·i = j,   i·k = -j
```

Добуток двох кватерніонів `p` та `q` (позначається `p ⊗ q`) виражається через скалярний `(·)` та векторний `(×)` добутки їхніх тривимірних векторних частин:

```
w_res = w_p · w_q - (p_v · q_v)
v_res = w_p · q_v + w_q · p_v + (p_v × q_v)
```

#### Зв'язок із теоремою Ейлера про вісь та кут повороту:

Згідно з теоремою Ейлера, будь-яка зміна просторової орієнтації твердого тіла еквівалентна одному повороту на кут `α` навколо деякої фіксованої одиничної осі `u = [u_x, u_y, u_z]ᵀ`. Нормований кватерніон компактно кодує цей поворот:

```
w = cos(α / 2)
x = u_x · sin(α / 2)
y = u_y · sin(α / 2)
z = u_z · sin(α / 2)

||q||² = w² + x² + y² + z² = cos²(α/2) + (u_x² + u_y² + u_z²)·sin²(α/2) = cos²(α/2) + 1·sin²(α/2) = 1
```

Кватерніони орієнтації лежать на одиничній тривимірній гіперсфері `S³` у чотиривимірному евклідовому просторі `ℝ⁴`. 

**Властивість подвійного покриття (Double Cover):** Кватерніони `q` та `-q` описують абсолютно однаковий просторовий поворот. Справді, зміна знака відповідає заміні осі `u → -u` та кута `α → 2π - α`, що приводить тіло у те саме положення. Група `S³` є універсальним подвійним накриттям групи `SO(3)`.

### 4. Аналітичні формули переходу між представленнями

#### Перехід: Кути Ейлера (Z-Y-X) → Кватерніон

Послідовне перемноження трьох одновісних кватерніонів повороту дає аналітичні вирази компонент:

```
q_z = [cos(ψ/2), 0, 0, sin(ψ/2)]ᵀ
q_y = [cos(θ/2), 0, sin(θ/2), 0]ᵀ
q_x = [cos(ϕ/2), sin(ϕ/2), 0, 0]ᵀ

q = q_z ⊗ q_y ⊗ q_x

w = cos(ϕ/2)·cos(θ/2)·cos(ψ/2) + sin(ϕ/2)·sin(θ/2)·sin(ψ/2)
x = sin(ϕ/2)·cos(θ/2)·cos(ψ/2) - cos(ϕ/2)·sin(θ/2)·sin(ψ/2)
y = cos(ϕ/2)·sin(θ/2)·cos(ψ/2) + sin(ϕ/2)·cos(θ/2)·sin(ψ/2)
z = cos(ϕ/2)·cos(θ/2)·sin(ψ/2) - sin(ϕ/2)·sin(θ/2)·cos(ψ/2)
```

#### Перехід: Кватерніон → Матриця DCM

Застосовуючи формулу повороту вектора `v' = q ⊗ (0, v) ⊗ q*`, отримуємо прямий зв'язок елементів матриці напрямних косинусів із компонентами кватерніона:

```
R_body_to_nav = 
[ 1 - 2(y² + z²)     2(xy - wz)         2(xz + wy)     ]
[ 2(xy + wz)         1 - 2(x² + z²)     2(yz - wx)     ]
[ 2(xz - wy)         2(yz + wx)         1 - 2(x² + y²) ]
```

#### Перехід: Кватерніон → Кути Ейлера

Порівнюючи матричні елементи `R_body_to_nav` з виведеною раніше матрицею кутів Тейта-Браяна:

```
R₃₁ = -sin(θ) = 2(xz - wy)
=> sin(θ) = 2(wy - xz)
=> θ = arcsin( clamp(2·(w·y - x·z), -1.0, +1.0) )
```

Для визначення кута крену `ϕ` використовуємо елементи третього рядка:

```
R₃₂ / R₃₃ = [ sin(ϕ)cos(θ) ] / [ cos(ϕ)cos(θ) ] = tan(ϕ)
R₃₂ = 2(yz + wx)
R₃₃ = 1 - 2(x² + y²)
=> ϕ = atan2( 2·(w·x + y·z), 1 - 2·(x² + y²) )
```

Для визначення кута рискання `ψ` використовуємо елементи першого стовпця:

```
R₂₁ / R₁₁ = [ cos(θ)sin(ψ) ] / [ cos(θ)cos(ψ) ] = tan(ψ)
R₂₁ = 2(xy + wz)
R₁₁ = 1 - 2(y² + z²)
=> ψ = atan2( 2·(w·z + x·y), 1 - 2·(y² + z²) )
```

*Зауваження щодо чисельної стійкості:* Через похибки округлення чисел із рухомою комою вираз `2(wy - xz)` може набути значення `1.0000001`, що спричинить повернення `NaN` стандартною функцією `asin()`. Тому аргумент функції арксинуса обов'язково обмежують (функція `clamp`) інтервалом `[-1.0, +1.0]`.

### 5. Аналітичне доведення сингулярності Gimbal Lock

Розглянемо критичний стан системи, коли кут тангажу досягає значення `θ = +π/2` (+90°).

Підставимо `sin(θ) = 1` та `cos(θ) = 0` у повну матрицю `R_nav_to_body`:

```
R(ϕ, +π/2, ψ) = 
[    0                         0               -1 ]
[ sin(ϕ)cos(ψ) - cos(ϕ)sin(ψ)  sin(ϕ)sin(ψ) + cos(ϕ)cos(ψ)   0 ]
[ cos(ϕ)cos(ψ) + sin(ϕ)sin(ψ)  cos(ϕ)sin(ψ) - sin(ϕ)cos(ψ)   0 ]
```

Використовуючи тригонометричні тотожності різниці кутів:
```
sin(ϕ - ψ) = sin(ϕ)cos(ψ) - cos(ϕ)sin(ψ)
cos(ϕ - ψ) = cos(ϕ)cos(ψ) + sin(ϕ)sin(ψ)
```

Матриця набуває вигляду:

```
R(ϕ, +π/2, ψ) = 
[      0            0       -1 ]
[  sin(ϕ - ψ)   cos(ϕ - ψ)   0 ]
[  cos(ϕ - ψ)  -sin(ϕ - ψ)   0 ]
```

**Математичний висновок:**
Елементи матриці залежать виключно від різниці кутів `(ϕ - ψ)`. Фізично це означає, що будь-яка нескінченна множина значень `ϕ` та `ψ`, для яких різниця `ϕ - ψ = C` є сталою (наприклад, `ϕ = 30°, ψ = 10°` або `ϕ = 50°, ψ = 30°`), породжує абсолютно ту саму матрицю просторової орієнтації. 

Зворотне перетворення стає невизначеним: неможливо розділити кут крену та кут курсу. Ранг якобіана кутових швидкостей падає з 3 до 2 — система втрачає один ступінь вільності.

### 6. Кінематичні диференціальні рівняння

Кінематичні рівняння пов'язують вектор виміряних кутових швидкостей датчиків IMU `ω_b = [p, q, r]ᵀ` (де `p` — швидкість крену, `q` — тангажу, `r` — рискання) зі швидкістю зміни просторової орієнтації.

#### Диференціальні рівняння для кутів Ейлера:

Проєкція швидкостей зміни кутів на зв'язані осі апарата:

```
[ p ]   [ 1      0         -sin(θ)   ] [ ϕ̇ ]
[ q ] = [ 0   cos(ϕ)    sin(ϕ)cos(θ) ] [ θ̇ ]
[ r ]   [ 0  -sin(ϕ)    cos(ϕ)cos(θ) ] [ ψ̇ ]
```

Обернення матриці переходу дає систему диференціальних рівнянь:

```
[ ϕ̇ ]   [ 1   sin(ϕ)tan(θ)   cos(ϕ)tan(θ) ] [ p ]
[ θ̇ ] = [ 0      cos(ϕ)        -sin(ϕ)     ] [ q ]
[ ψ̇ ]   [ 0   sin(ϕ)/cos(θ)  cos(ϕ)/cos(θ) ] [ r ]
```

**Аналіз розриву:**
При `θ → ±π/2` тригонометричний тангенс `tan(θ) → ±∞`, а знаменник `cos(θ) → 0`. Якщо літак чи дрон пролітає через вертикальне положення (виконання мертвої петлі, вертикальний маневр), чисельний інтегратор автопілота зазнає переповнення та ділення на нуль.

#### Кватерніонне диференціальне рівняння (лінійне та стабільне):

Похідна кватерніона за часом виражається прямим множенням Гамільтона без жодних знаменників і тригонометричних функцій:

```
q̇ = 1/2 · q ⊗ [0, p, q, r]ᵀ
```

У розгорнутій матричній формі:

```
[ ẇ ]         [  0  -p  -q  -r ] [ w ]
[ ẋ ] = 1/2 · [  p   0   r  -q ] [ x ]
[ ẏ ]         [  q  -r   0   p ] [ y ]
[ ż ]         [  r   q  -p   0 ] [ z ]
```

Це лінійна система з кососиметричною матрицею, яка розв'язується стандартними чисельними методами (Рунге-Кутти або Ейлера першого порядку) із гарантованою стійкістю при довільних значеннях просторових кутів.

### 7. Сферична лінійна інтерполяція орієнтацій (SLERP)

Коли автопілот або наземна станція інтерполює орієнтацію між двома послідовними телеметричними пакетами `q₁` та `q₂` з параметром часу `t ∈ [0, 1]`, звичайна лінійна інтерполяція компонент спотворює постійну кутову швидкість.

Стандартом плавного обертання є **сферична лінійна інтерполяція** (англ. *Spherical Linear Interpolation*, SLERP), розроблена Кеном Шумейком у 1985 році:

```
cos(Ω) = q₁ · q₂ = w₁·w₂ + x₁·x₂ + y₁·y₂ + z₁·z₂
```

1. **Перевірка найкоротшого шляху:** Якщо скалярний добуток `cos(Ω) < 0`, кватерніони знаходяться на протилежних півкулях гіперсфери. Оскільки `q ≡ -q`, ми інвертуємо один із кватерніонів: `q₂ ← -q₂` та `cos(Ω) ← -cos(Ω)`. Це гарантує поворот найкоротшим шляхом (на кут менше 180°).
2. **Аналітична формула інтерполяції:**
   ```
   q(t) = [ sin((1 - t)·Ω) / sin(Ω) ] · q₁ + [ sin(t·Ω) / sin(Ω) ] · q₂
   ```
3. **Граничний випадок малих кутів:** Коли `Ω → 0` (кут між кватерніонами наближається до нуля, `cos(Ω) > 0.9995`), ділення на `sin(Ω)` стає чисельно нестабільним. У цьому діапазоні алгоритм перемикається на нормалізовану лінійну інтерполяцію (NLERP):
   ```
   q(t) = normalize( (1 - t)·q₁ + t·q₂ )
   ```

Завдяки SLERP контури візуалізації польоту в QGroundControl та траєкторні генератори забезпечують ідеально рівномірне обертання віртуального горизонту навіть при низькій частоті передачі телеметричних пакетів по радіолінії.
