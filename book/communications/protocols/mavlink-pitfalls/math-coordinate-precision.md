# 🧮 Математика втрати точності координат: плаваюча кома проти цілих чисел

У супутниковій радіонавігації та автономному керуванні безпілотними апаратами точність оцінки положення в просторі безпосередньо залежить від чисельного представлення просторових координат. Використання 32-бітових чисел із плаваючою комою стандарту IEEE-754 для збереження кутових величин широти та довготи в градусах створює суттєву просторову нерівномірність. Через специфіку двійкової експоненти крок просторового квантування змінюється в рази залежно від географічного положення апарата, досягаючи на краях координатних діапазонів похибки в кілька метрів, що робить неможливим використання високоточних фазових вимірювань супутникових систем.

### Геодезична основа та геометрія земного еліпсоїда

Для опису поверхні Землі у супутниковій навігації GPS/GNSS та протоколі MAVLink використовується загальноприйнята геодезична система координат WGS-84 (англ. *World Geodetic System 1984*). У цій моделі Земля апроксимується сплюснутим еліпсоїдом обертання з такими базовими параметрами:
- Велика піввісь (екваторіальний радіус): `a = 6 378 137.0` метрів;
- Стиснення еліпсоїда: `f = 1 ÷ 298.257223563 ≈ 0.00335281066474`;
- Мала піввісь (полярний радіус): `b = a · (1 − f) ≈ 6 356 752.3142` метрів;
- Перший ексцентриситет: `e² = (a² − b²) ÷ a² = 2·f − f² ≈ 0.00669437999014`.

Довжина дуги одного градуса меридіана `M(φ)` та паралелі `N(φ)` на географічній широті `φ` обчислюються через радіуси кривини еліпсоїда.

Радіус кривини меридіана:

```
R_M(φ) = (a · (1 − e²)) ÷ (1 − e² · sin²(φ))¹·⁵
```

Радіус кривини першого вертикалу (відстань від поверхні до осі обертання по нормалі):

```
R_N(φ) = a ÷ √(1 − e² · sin²(φ))
```

Довжина дуги в один градус за широтою (уздовж меридіана):

```
L_lat(φ) = (π ÷ 180) · R_M(φ)
```

Довжина дуги в один градус за довготою (уздовж паралелі):

```
L_lon(φ) = (π ÷ 180) · R_N(φ) · cos(φ)
```

На екваторі (`φ = 0°`), де `sin(0) = 0` та `cos(0) = 1`, радіус кривини першого вертикалу дорівнює великій півосі еліпсоїда `R_N(0) = a = 6 378 137.0` метрів. Довжина дуги одного градуса довготи на екваторі становить:

```
L_deg = (2 · π · a) ÷ 360
= (2 · 3.1415926535 · 6378137.0) ÷ 360   [підстановка радіуса WGS-84]
= 40075016.6856 ÷ 360                   [обчислення довжини екватора]
≈ 111319.4908 м                         [довжина 1° довготи на екваторі]
```

Для довільної широти довжина одного градуса довготи зменшується пропорційно косинусу широти. Наприклад, для географічної широти Києва (`φ ≈ 50.45°`):

```
L_lon(50.45°) ≈ 111319.4908 · cos(50.45°)
= 111319.4908 · 0.636746                [значення косинуса кута 50.45°]
≈ 70882.16 м                            [довжина 1° паралелі в Києві]
```

Ці геометричні співвідношення показують масштаб перетворення кутових величин у метри: зміна кута всього на одну мільйонну частку градуса (`10⁻⁶°`) відповідає лінійному зміщенню на поверхні Землі приблизно на `11.13` сантиметра на екваторі та `7.09` сантиметра в помірних широтах.

### Формат двійкового представлення IEEE-754 Single Precision

Стандарт IEEE-754 визначає двійкове представлення 32-бітових чисел із плаваючою комою одинарної точності (`float`). Бітова структура такого числа складається з трьох послідовних полів:
1. Знаковий біт `s` (1 біт, біт 31): визначає знак числа (`0` для додатних, `1` для від'ємних);
2. Зміщена експонента `e` (8 бітів, біти 30..23): кодує порядок числа зі зсувом `bias = 127` (діапазон значень від `0` до `255`);
3. Дробова частина мантиси `f` (23 біти, біти 22..0): кодує двійковий дріб.

Для нормалізованих чисел (коли значення експоненти лежить у межах `1 ≤ e ≤ 254`) перед дробовою частиною мантиси передбачається неявний старший одиничний біт. Повне значення числа обчислюється за формулою:

```
x = (−1)ˢ · 2ᵉ⁻¹²⁷ · (1 + ∑_{i=1}^{23} b₂₃₋ᵢ · 2⁻ⁱ)
```

Завдяки неявному одиничному біту ефективна розрядність мантиси нормалізованого числа становить рівно `p = 24` двійкові розряди.

Абсолютна відстань між двома сусідніми числами з плаваючою комою називається одиницею останнього розряду (англ. *Unit in the Last Place*, ULP). Для числа `x` з двійковим порядком `E = e − 127 = ⌊log₂(x)⌋` величина кванта дискретизації визначається вагою молодшого біта мантиси:

```
ULP(x) = 2ᴱ · 2⁻²³ = 2ᴱ⁻²³
```

Ця формула математично доводить, що крок дискретизації чисел із плаваючою комою є строго кусково-сталим і подвоюється при кожному переході через ступінь двійки (`1, 2, 4, 8, 16, 32, 64, 128`).

### Аналіз квантування географічної довготи у форматі float32

Географічна довгота приймає значення в замкненому інтервалі `λ ∈ [−180.0°, +180.0°]`. Розглянемо крок дискретизації для різних географічних зон залежно від величини двійкової експоненти.

#### 1. Зона нульового меридіана: `λ ∈ [0.5°, 1.0°)`
Для координат поблизу Гринвіча значення довготи менше одиниці. Двійковий порядок становить `E = −1` (оскільки `2⁻¹ = 0.5 ≤ λ < 1.0`). Значення експоненти в пам'яті: `e = 127 − 1 = 126`.

Крок дискретизації довготи:

```
Δλ₁ = 2⁻¹ · 2⁻²³
= 2⁻²⁴                                  [додавання показників степеня]
≈ 5.960464 · 10⁻⁸ градуса               [квант довготи біля Гринвіча]
```

Лінійна похибка позиціонування на екваторі:

```
Δs₁ = Δλ₁ · L_deg
= (5.960464 · 10⁻⁸) · 111319.4908       [множення на довжину дуги градуса]
≈ 0.006635 м = 6.64 мм                  [міліметрова похибка]
```

У цій зоні формату `float` вистачає для забезпечення міліметрової роздільної здатності.

#### 2. Зона Європи та Близького Сходу: `λ ∈ [16.0°, 32.0°)`
Для території України (`λ ≈ 30°..40°`) двійковий порядок становить `E = 4` для довгот до 32° або `E = 5` для довгот понад 32° (`2⁴ = 16 ≤ λ < 32`).

Крок дискретизації довготи:

```
Δλ₂ = 2⁴ · 2⁻²³
= 2⁻¹⁹                                  [додавання показників степеня]
≈ 1.907348 · 10⁻⁶ градуса               [квант довготи для Центральної Європи]
```

Лінійна похибка позиціонування на широті 50°:

```
Δs₂(50.45°) = Δλ₂ · L_lon(50.45°)
= (1.907348 · 10⁻⁶) · 70882.16          [множення на стиснуту дугу паралелі]
≈ 0.135197 м ≈ 13.52 см                 [похибка понад 13 сантиметрів]
```

Тут похибка вже перевищує допустиму похибку високоточного режиму RTK GNSS (яка становить 1–2 см).

#### 3. Зона Східної Азії та Індії: `λ ∈ [64.0°, 128.0°)`
Для довгот від 64° до 128° (території Індії, Китаю, Японії) двійковий порядок становить `E = 6` (`2⁶ = 64 ≤ λ < 128`).

Крок дискретизації довготи:

```
Δλ₃ = 2⁶ · 2⁻²³
= 2⁻¹⁷                                  [додавання показників степеня]
≈ 7.629395 · 10⁻⁶ градуса               [квант довготи для Азійського регіону]
```

Лінійна похибка квантування на екваторі:

```
Δs₃ = Δλ₃ · L_deg
= (7.629395 · 10⁻⁶) · 111319.4908       [множення на довжину градуса]
≈ 0.849294 м ≈ 85 см                    [похибка майже один метр]
```

#### 4. Зона Тихоокеанського регіону: `λ ∈ [128.0°, 180.0°]`
Для довгот понад 128° (Східний Сибір, Австралія, Нова Зеландія, Океанія, Аляска) двійковий порядок досягає максимуму `E = 7` (`2⁷ = 128 ≤ λ ≤ 180`).

Крок дискретизації довготи:

```
Δλ₄ = 2⁷ · 2⁻²³
= 2⁻¹⁶                                  [додавання показників степеня]
≈ 1.525879 · 10⁻⁵ градуса               [квант довготи біля 180-го меридіана]
```

Лінійна похибка квантування на екваторі:

```
Δs₄ = Δλ₄ · L_deg
= (1.525879 · 10⁻⁵) · 111319.4908       [множення на довжину градуса]
≈ 1.698589 м ≈ 1.70 м                   [похибка майже два метри]
```

Для точки з довготою `179.99°` найближче наступне число з плаваючою комою віддалене на `1.70` метра на екваторі та на `1.08` метра на широті 50°. Якщо безпілотний апарат здійснює автоматичну посадку на майданчик розміром `2 × 2` метри в Новій Зеландії або на сході Австралії, квантування координат у `float32` повністю поглинає габарити цілі, роблячи точне позиціонування математично неможливим.

### Проекція в локальну декартову систему координат (NED)

У польотних контролерах (PX4, ArduPilot) оцінка просторового положення та побудова траєкторій виконується не у сферичних координатах, а в локальній тангенціальній системі координат NED (англ. *North-East-Down* — Північ-Схід-Вниз), центр якої прив'язується до точки старту апарата `(φ₀, λ₀, h₀)`.

Перетворення глобальних геодезичних координат `(φ, λ, h)` у локальні лінійні зміщення `(x_N, y_E, z_D)` виконується за наближеними диференціальними рівняннями:

```
x_N = (φ − φ₀) · (π ÷ 180) · R_M(φ₀)
y_E = (λ − λ₀) · (π ÷ 180) · R_N(φ₀) · cos(φ₀)
z_D = −(h − h₀)
```

Повна просторова евклідова похибка позиціонування обчислюється як корінь із суми квадратів компонент:

```
Δd_NED = √(Δx_N² + Δy_E² + Δz_D²)
```

Якщо різниця довгот `(λ − λ₀)` обчислюється в одинарній точності `float32`, де значення `λ` та `λ₀` є близькими великими числами (наприклад, `150.12345°` та `150.12340°`), виникає ефект катастрофічної втрати точності (англ. *catastrophic cancellation*).

При відніманні двох близьких чисел із плаваючою комою старші біти мантиси, що збігаються, взаємно знищуються, а результат нормалізації витягує випадкові шумові біти молодших розрядів у старші позиції результату. У системі керування це проявляється як раптовий стрибок розрахованої координати `y_E` на кілька метрів при фактично незмінній фізичній позиції апарата.

### Вплив квантування координат на оцінку швидкості в EKF

Похибка квантування координат має катастрофічний вторинний ефект: вона спотворює похідні положення за часом, тобто оцінку швидкості та прискорення в навігаційному фільтрі Калмана (EKF).

Розглянемо випадок, коли апарат зависає на місці або повільно рухається зі швидкістю `v = 0.05` м/с (5 см/с). Датчик супутникової навігації опитується з частотою `f_gps = 5` Гц (інтервал вимірювань `Δt = 0.2` с).

Реальне просторове переміщення за один такт вимірювання становить:

```
Δx_real = v · Δt = 0.05 · 0.2 = 0.01 м = 1.0 см
```

Оскільки крок квантування формату `float32` на довготі 150° становить `Δs = 1.70` м, виміряна координата залишатиметься абсолютно незмінною протягом багатьох тактів поспіль, а потім, при накопиченні суми, миттєво перескочить на один квант `1.70` метра.

Штучний стрибок виміряної швидкості, зафіксований фільтром Калмана на цьому такті:

```
v_spike = Δs ÷ Δt
= 1.698589 ÷ 0.2                         [ділення стрибка координати на dt]
≈ 8.4929 м/с ≈ 8.5 м/с                   [штучний стрибок швидкості 30.6 км/год]
```

Фільтр Калмана сприймає цей стрибок як раптове виникнення потужного вітрового пориву зі швидкістю `30.6` км/год. Диференціальна складова PID-регулятора швидкості миттєво формує максимальний коригувальний сигнал на мотори, викликаючи сильний ривок апарата в протилежний бік.

### Математичне обґрунтування цілочисельного формату degE7

Для усунення просторової нерівномірності стандарт MAVLink використовує 32-бітове ціле знакове число (`int32_t`) з постійним масштабним множником `10⁷` (формат `degE7`).

#### 1. Діапазон значень
Тип `int32_t` кодує цілі числа в діапазоні від `−2 147 483 648` до `+2 147 483 647`. Значення кута в градусах відновлюється діленням на `10 000 000`:

```
λ_min = −2147483648 ÷ 10⁷ = −214.7483648°
λ_max = +2147483647 ÷ 10⁷ = +214.7483647°
```

Цей числовий проміжок повністю покриває максимальний діапазон довготи `[−180.0°, +180.0°]` із запасом у `±34.7°` та діапазон широти `[−90.0°, +90.0°]` із запасом у `±124.7°`, унеможливлюючи переповнення розрядної сітки при будь-яких валідних земних координатах.

#### 2. Просторова роздільна здатність
Крок квантування фіксованого формату є строго постійним у будь-якій точці земної кулі:

```
Δλ_fixed = 1 ÷ 10⁷ = 10⁻⁷ = 0.0000001°
```

Лінійна роздільна здатність на екваторі:

```
Δs_fixed = 10⁻⁷ · L_deg
= 10⁻⁷ · 111319.4908                    [множення на довжину 1° екватора]
≈ 0.0111319 м ≈ 1.11 см                 [стала роздільна здатність 11.1 мм]
```

Лінійна роздільна здатність на широті 50°:

```
Δs_fixed(50.45°) = 10⁻⁷ · L_lon(50.45°)
= 10⁻⁷ · 70882.16                       [множення на довжину 1° паралелі]
≈ 0.007088 м ≈ 7.09 мм                  [субсантиметрова роздільна здатність]
```

Постійна роздільна здатність `1.11` сантиметра на екваторі та `7.1` міліметра в помірних широтах гарантує точність, що впевнено перекриває можливості сучасних супутникових фазових приймачів RTK GNSS.

### Чисельне представлення висоти: метри у float проти міліметрів у int32_t

Аналогічний математичний аналіз застосовується до вимірювання геодезичної висоти `h` (висоти над еліпсоїдом WGS-84 або над середнім рівнем моря MSL).

1. **Плаваюча кома (`float32` у метрах):**
   - На висоті польоту квадрокоптера `h = 100` м (`2⁶ = 64 ≤ 100 < 128`):
     ```
     Δh = 2⁶ · 2⁻²³ = 2⁻¹⁷ ≈ 7.63 · 10⁻⁶ м ≈ 0.0076 мм
     ```
   - На висоті польоту стратосферного аеростата або літака `h = 12 000` м (`2¹³ = 8192 ≤ 12000 < 16384`):
     ```
     Δh = 2¹³ · 2⁻²³ = 2⁻¹⁰ ≈ 0.000976 м ≈ 0.98 мм
     ```
   - На висоті супутника CubeSat `h = 500 000` м (`2¹⁸ = 262144 ≤ 500000 < 524288`):
     ```
     Δh = 2¹⁸ · 2⁻²³ = 2⁻⁵ = 0.03125 м = 3.125 см
     ```
2. **Цілочисельний формат (`int32_t` у міліметрах):**
   - Роздільна здатність є строго сталою: `Δh = 1.0` мм скрізь.
   - Максимальний діапазон висот становить:
     ```
     h_max = 2147483647 мм ≈ 2147.48 км
     ```
     Діапазон `±2147` кілометрів повністю перекриває всю атмосферу Землі та низьку навколоземну орбіту з незмінною міліметровою точністю.

Саме тому всі сучасні навігаційні структури MAVLink використовують комбінацію `int32_t lat` (degE7), `int32_t lon` (degE7) та `int32_t alt` (міліметри), що гарантує абсолютну числову стабільність розрахунків на всій планеті.
