# 📋 Довідник Словника Об'єктів CiA 301 та профілів пристроїв

Словник Об'єктів (Object Dictionary, OD) — це центральний концептуальний елемент будь-якого вузла CANopen, що являє собою впорядковану таблицю всіх параметрів, конфігураційних змінних, робочих даних та системних станів пристрою. Кожен елемент Словника Об'єктів адресується 16-бітним основним індексом (`0x0000`..`0xFFFF`) та 8-бітним субіндексом (`0x00`..`0xFF`), що дає змогу розмістити понад 16 мільйонів окремих змінних у єдиному просторі пам'яті.

Призначення Словника Об'єктів полягає у створенні уніфікованого прикладного інтерфейсу між мережевими протоколами (SDO та PDO) та внутрішньою мікроконтролерною архітектурою пристрою. Протокол SDO використовує індекс та субіндекс для адресації конкретних осередків під час конфігурації, а протокол PDO зв'язує адреси осередків із байтами швидкісних кадрів реального часу за допомогою механізму мапінгу.

### 1. Системні правила адресації та субіндекс 0x00

Структура елементів Словника Об'єктів підпорядковується чітким канонічним правилам специфікації CiA 301:
1. **Пов'язані типи даних**. За індексами `0x0001`..`0x009F` описуються базові стандартизовані типи даних: `BOOLEAN` (`0x0001`), `INTEGER8` (`0x0002`), `INTEGER16` (`0x0003`), `INTEGER32` (`0x0004`), `UNSIGNED8` (`0x0005`), `UNSIGNED16` (`0x0006`), `UNSIGNED32` (`0x0007`), `REAL32` (`0x0008`), `VISIBLE_STRING` (`0x0009`), `OCTET_STRING` (`0x000A`).
2. **Конвенція Субіндексу 0x00**. Якщо елемент Словника Об'єктів за індексом являє собою масив (Array) або складну структуру (Record), то **субіндекс `0x00` завжди містить кількість фактично доступних субіндексів** у цьому записі у вигляді беззнакового 8-бітного числа (`UNSIGNED8`). Це дає змогу клієнту SDO перед читанням елементів масиву дізнатися його точний розмір.
3. **Атрибути доступу**. Кожен субіндекс має жорстко визначені атрибути доступу: `RO` (*Read-Only* — тільки для читання), `WO` (*Write-Only* — тільки для запису), `RW` (*Read-Write* — читання та запис) або `CONST` (*Constant* — постійна константа).
4. **Конфігураційні файли EDS (Electronic Data Sheet)**. Структура Словника Об'єктів конкретного пристрою описується в стандартизованому форматизованому файлі **.EDS** (або **.XDD** для XML-формату). Файл EDS містить текстовий опис усіх індексів, субіндексів, типів даних, значень за замовчуванням та діапазонів припустимих значень. Графічні середовища розробки (наприклад, CODESYS або CANopen Configuration Manager) імпортують EDS-файл і автоматично будують дерево налаштувань для інженера.

### 2. Загальний розподіл адресного простору Словника Об'єктів

Адресний простір стандарту CiA 301 розбитий на п'ять великих функціональних діапазонів, що гарантує відсутність колізій між комунікаційними параметрами, вендорними налаштуваннями та галузевими профілями:

| Діапазон індексів | Назва та призначення розділу | Опис та правила доступу |
| :--- | :--- | :--- |
| `0x0001`..`0x025F` | Типи даних (Data Types) | Означення базових та складених типів даних для інтерпретації значень змінних. |
| `0x1000`..`0x1FFF` | Профіль зв'язку (Communication Profile Area) | Обов'язкові та опціональні параметри CANopen: ідентифікація вузла, конфігурація Heartbeat, SYNC, PDO та SDO. |
| `0x2000`..`0x5FFF` | Специфічний профіль виробника (Manufacturer-Specific) | Вільний простір для унікальних внутрішніх налаштувань, коефіцієнтів PID-регуляторів та прошивок вендора. |
| `0x6000`..`0x9FFF` | Стандартизований профіль пристрою (Standardized Device Profile) | Змінні профілів CiA 401 (I/O) та CiA 402 (Motion Control): регістрами Controlword, Statusword, позиції, швидкості. |
| `0xA000`..`0xBFFF` | Профіль інтерфейсів мережі (Network Variable Area) | Мережеві змінні для міжконтролерного обміну та програмних шлюзів. |

### 3. Обов'язкові та ключові об'єкти Профілю Зв'язку CiA 301 (`0x1000`..`0x1FFF`)

Розділ `0x1000` містить базові реєстри ідентифікації пристрою, аварійні прапорці та параметри таймерів мережевого зв'язку:

| Індекс | Субіндекс | Тип даних | Доступ | Назва та значення об'єкта |
| :--- | :--- | :--- | :--- | :--- |
| `0x1000` | `0x00` | UNSIGNED32 | RO | **Device Type**: тип пристрою та номер використовуваного профілю (наприклад, `0x00020192` вказує на підтримку профілю привода CiA 402). |
| `0x1001` | `0x00` | UNSIGNED8 | RO | **Error Register**: бітова маска помилок (біт 0 = загальна помилка, біт 1 = струм, біт 2 = напруга, біт 3 = температура, біт 4 = зв'язок). |
| `0x1008` | `0x00` | STRING | RO | **Manufacturer Device Name**: текстова назва моделі пристрою для відображення у графічних конфігураторах. |
| `0x1017` | `0x00` | UNSIGNED16 | RW | **Producer Heartbeat Time**: період відправки повідомлень Heartbeat у мілісекундах (`0` = вимкнено). |
| `0x1018` | `0x00` | UNSIGNED8 | RO | **Identity Object**: кількість субіндексів в об'єкті ідентифікації (завжди дорівнює `4`). |
| `0x1018` | `0x01` | UNSIGNED32 | RO | **Vendor ID**: унікальний 32-бітний ідентифікатор виробника, виданий консорціумом CiA. |
| `0x1018` | `0x02` | UNSIGNED32 | RO | **Product Code**: внутрішній артикул або код продукту вендора. |
| `0x1018` | `0x03` | UNSIGNED32 | RO | **Revision Number**: номер ревізії програмного та апаратного забезпечення. |
| `0x1018` | `0x04` | UNSIGNED32 | RO | **Serial Number**: унікальний серійний номер даного конкретного екземпляра пристрою. |

### 4. Паспортизація та налаштування PDO (`0x1400`..`0x1A00`)

Налаштування обміну даними реального часу розділені на дві пов'язані групи об'єктів: комунікаційні параметри (*Communication Parameters*) та параметри мапінгу (*Mapping Parameters*).

#### Комунікаційні параметри TPDO1 (`0x1800`):
- **Subindex `0x01` (UNSIGNED32, RW)**: `COB-ID TPDO1`. Задає ідентифікатор кадру CAN. Бит 31 визначає дійсність кадру (`0` = активний, `1` = вимкнений). Стандартне значення для Node-ID=5 дорівнює `0x40000185`.
- **Subindex `0x02` (UNSIGNED8, RW)**: `Transmission Type`. Вказує режим відправки кадру: `0` = ациклічний синхронний (після кадру SYNC при зміні даних), `1`..`240` = циклічний синхронний (передача кожні N кадрів SYNC), `254` / `255` = асинхронний (за подією або таймером).
- **Subindex `0x03` (UNSIGNED16, RW)**: `Inhibit Time`. Мінімальний інтервал між двома послідовними відправками даного TPDO у десятих частках мілісекунди (100 мкс) для захисту шини від перевантаження.
- **Subindex `0x05` (UNSIGNED16, RW)**: `Event Timer`. Період автоматичної циклічної відправки TPDO у мілісекундах.

#### Параметри відображення TPDO1 (`0x1A00`):
- **Subindex `0x00` (UNSIGNED8, RW)**: Кількість відображених об'єктів у кадрі TPDO1 (від `0` до `8`).
- **Subindex `0x01`..`0x08` (UNSIGNED32, RW)**: 32-бітна структура мапінгу `0xIIII SSS LL`:
  - Біти 31..16: **Індекс (`IIII`)** джерельної змінної у Словнику Об'єктів;
  - Біти 15..8: **Субіндекс (`SSS`)** джерельної змінної;
  - Біти 7..0: **Довжина у бітах (`LL`)** (наприклад, `0x10` = 16 бітів = 2 байти, `0x20` = 32 біти = 4 байти).

### 5. Реєстри профілю сервоприводів та частотників CiA 402 (`0x6040`..`0x607A`)

Профіль CiA 402 регламентує стандартні індекси для керування вектором руху, силою та позицією електроприводів:

| Індекс | Субіндекс | Назва об'єкта | Тип даних | Опис та функціональне призначення |
| :--- | :--- | :--- | :--- | :--- |
| `0x6040` | `0x00` | **Controlword** | UNSIGNED16 | Слово керування автоматом станів приводу (біт 0 = Switch On, біт 1 = Enable Voltage, біт 2 = Quick Stop, біт 3 = Enable Operation, біт 7 = Fault Reset). |
| `0x6041` | `0x00` | **Statusword** | UNSIGNED16 | Слово стану приводу (біт 0 = Ready to Switch On, біт 1 = Switched On, біт 2 = Operation Enabled, біт 3 = Fault, біт 5 = Quick Stop). |
| `0x6060` | `0x00` | **Modes of Operation** | INTEGER8 | Задання режиму роботи приводу: `1` = Profile Position Mode, `3` = Profile Velocity Mode, `4` = Profile Torque Mode, `6` = Homing Mode, `8` = Cyclic Synchronous Position (CSP). |
| `0x6061` | `0x00` | **Modes of Operation Display** | INTEGER8 | Поточний фактично підтверджений режим роботи приводу. |
| `0x6064` | `0x00` | **Position Actual Value** | INTEGER32 | Поточне фактичне положення валу двигуна у кроках енкодера (знакове 32-бітне число). |
| `0x606C` | `0x00` | **Velocity Actual Value** | INTEGER32 | Поточна фактична швидкість обертання валу у внутрішніх одиницях (знакове 32-бітне число). |
| `0x607A` | `0x00` | **Target Position** | INTEGER32 | Цільова позиція для переміщення валу в режимах позиціонування (Profile Position / CSP). |
