# 🧮 Математика радіовипромінювання: розрахунок EIRP, густини потоку MPE та порогів SAR

Радіорегуляторні вимоги базуються на фізичних законах поширення електромагнітних хвиль та поглинання енергії біологічними тканинами. Інженер-розробник бездротової системи зобов'язаний аналітично розраховувати еквівалентну випромінювану потужність, оцінювати густину потоку енергії в зоні перебування персоналу та перевіряти математичні критерії звільнення від дорогих випробувань на питомий коефіцієнт поглинання (SAR).

---

### Розрахунок еквівалентної ізотропно-випромінюваної потужності (EIRP)

Еквівалентна ізотропно-випромінювана потужність (англ. *Equivalent Isotropically Radiated Power*, EIRP) — це гіпотетична потужність, яку мав би випромінювати ідеальний ненаправлений (ізотропний) випромінювач, щоб створити таку саму густину потоку потужності в напрямку головного максимуму діаграми спрямованості реальної антени.

У логарифмічній шкалі децибел-міліватів (дБм) базове співвідношення має вигляд:
```
EIRP = P_cond - L_cable + G_ant
```
де:
- `P_cond` — кондуктивна вихідна потужність передавача (дБм);
- `L_cable` — сумарні втрати у з'єднувальних кабелях, роз'ємах та друкованих доріжках узгодження (дБ);
- `G_ant` — коефіцієнт підсилення антени відносно ідеального ізотропного випромінювача (дБі).

Значення EIRP слугує відправною точкою для всіх подальших розрахунків напруженості поля в дальній зоні, оцінки зон електромагнітної безпеки MPE та перевірки на відповідність регуляторним лімітам потужності.

Якщо вихідну потужність передавача задано у лінійних ватах `P_W`, переведення в децибел-мілівати виконується за формулою:

```
P_dBm
= 10 · log10(P_mW)               [означення логарифмічної потужності]
= 10 · log10(P_W · 1000)         [переведення ватів у мілівати]
= 10 · (log10(P_W) + 3)          [властивість логарифма добутку]
= 10 · log10(P_W) + 30           [розкриття дужок]
```

Зворотне переведення логарифмічної потужності `EIRP` (дБм) у лінійну потужність `P_lin` (мВт):

```
P_lin = 10^(EIRP / 10)
```

#### Співвідношення між EIRP та ERP (європейські стандарти Sub-GHz)
У європейських нормах для діапазону 868 МГц (ETSI EN 300 220) ліміти часто встановлюються не в EIRP, а в еквівалентній випромінюваній потужності відносно напівхвильового диполя (англ. *Effective Radiated Power*, ERP). Оскільки підсилення ідеального напівхвильового диполя у вільному просторі становить `2.15 дБі` відносно ізотропного випромінювача, зв'язок між величинами визначається формулою:

```
ERP
= EIRP - 2.15                    [віднімання підсилення напівхвильового диполя 2.15 дБі]
= P_cond - L_cable + G_ant - 2.15
```

### Межі дальньої зони випромінювання (Fraunhofer Distance)

Розрахунки густини потоку потужності за класичною сферичною формулою `S = EIRP / (4·π·R²)` є справедливими виключно у дальній хвильовій зоні антени (зоні Фраунгофера).

Межа між реактивною ближньою зоною (зоною Френеля) та дальньою зоною `R_ff` визначається найбільшим геометричним розміром апертури антени `D` та довжиною хвилі `λ`:

```
λ = c / f
```
де `c = 3.0 · 10⁸ м/с` — швидкість світла у вакуумі.

Критерій переходу у дальню зону (Fraunhofer Far-Field Distance):

```
R_ff = (2 · D²) / λ
```

Якщо розмір антени малий порівняно з довжиною хвилі (`D < λ/2`, наприклад, для малорозмірної керамічної чип-антени 2.4 ГГц з розміром `D = 5 мм`), межа дальньої зони визначається хвильовим радіусом реактивного ближнього поля:

```
R_reactive = λ / (2 · π)
```

Для частоти `f = 2.44 ГГц` (`λ = 0.123 м = 12.3 см`) реактивна зона закінчується на відстані `R_reactive = 12.3 / (2 · 3.14159) ≈ 1.96 см`. Відповідно, на відстанях `R ≥ 20 см` розрахунок за формулами MPE є повністю точним.

#### Ефективна площа апертури антени та формула Фрііса
Зв'язок між коефіцієнтом підсилення антени `G_ant` та її ефективною площею вловлювання електромагнітної енергії `A_eff` (м²) визначається фундаментальним електродинамічним співвідношенням:

```
A_eff = (G_ant_lin · λ²) / (4 · π)
```

Прийнята приймальною антеною потужність `P_rx` на відстані `R` у вільному просторі обчислюється як добуток густини потоку потужності `S` на ефективну площу приймальної антени `A_eff_rx`:

```
P_rx
= S · A_eff_rx                                       [означення прийнятої потужності]
= (P_tx_EIRP / (4 · π · R²)) · ((G_rx · λ²) / (4 · π)) [підстановка виразів]
= P_tx · G_tx · G_rx · (λ / (4 · π · R))²            [класична формула Фрііса]
```
Це рівняння показує, що втрати на трасі у вільному просторі (Free Space Path Loss, FSPL) зростають квадратично з відстанню та частотою, що вимагає точного обліку кожного децибела підсилення в розрахунках сертифікаційного бюджету потужності.

### Перерахунок між напруженістю поля (дБмкВ/м) та випромінюваною потужністю EIRP (дБм)

Під час випробувань у безвідлунній камері вимірювальний приймач фіксує напруженість електричного поля `E` (у лінійних мкВ/м або логарифмічних дБмкВ/м). Для зіставлення з лімітами кондуктивної потужності інженер виконує аналітичне перетворення:

Зв'язок між густиною потоку потужності `S` та напруженістю електричного поля `E` у вільному просторі (хвильовий опір вакууму `η₀ ≈ 120·π ≈ 377 Ом`):

```
S = E² / η₀ = E² / 377
```

Прирівнюючи два вирази для густини потоку потужності на відстані `R`:

```
E² / 377 = P_EIRP_lin_W / (4 · π · R²)
E² = (377 · P_EIRP_lin_W) / (4 · π · R²)       [множення на 377]
E² = (30 · P_EIRP_lin_W) / R²                  [оскільки 377 / (4·π) ≈ 30]
E = √(30 · P_EIRP_lin_W) / R                   [добування квадратного кореня]
```

Для стандартизованої відстані вимірювання `R = 3.0 метри`:

```
E_V_m = √(30 · P_EIRP_lin_W) / 3.0
```

У логарифмічній шкалі децибел-мікровольтів на метр (дБмкВ/м) для відстані 3 метри формула зводиться до відомої нормативної константи FCC:

```
E_dBuV_m
= EIRP_dBm + 107.0 - 20 · log10(3.0) + 10 · log10(30 / 377 · 4 · π)  [виведення переходу]
= EIRP_dBm + 95.23                             [результат для дистанції 3 метри]
```

Звідси потужність `EIRP` через виміряну напруженість поля на 3 метрах:

```
EIRP_dBm = E_dBuV_m - 95.23
```

Це пояснює походження ліміту смуг обмеженого використання FCC Part 15.205 (500 мкВ/м = 54.0 дБмкВ/м):

```
EIRP_limit
= 54.0 - 95.23                                 [підстановка 54 дБмкВ/м]
= -41.23 дБм EIRP                              [нормативний ліміт FCC §15.209]
```

### Розрахунок густини потоку потужності та безпечної дистанції (MPE)

Для стаціонарних та мобільних передавачів (відстань до тіла людини `R > 20 см`) регулятори (FCC Title 47 CFR §1.1310 та європейські норми за рекомендаціями ICNIRP) обмежують гранично допустиме опромінення (англ. *Maximum Permissible Exposure*, MPE) через густину потоку потужності `S` (Вт/м² або мВт/см²).

У дальній зоні антени випромінювана енергія розподіляється по поверхні сфери радіуса `R`. Густина потоку потужності `S` обчислюється як відношення лінійної ізотропної потужності до площі сфери:

```
S = P_EIRP_lin / (4 · π · R²)
```

Якщо підставити логарифмічний вираз для потужності з урахуванням кондуктивної потужності передавача `P_cond` (дБм), втрат `L` (дБ) та підсилення антени `G` (дБі), отримаємо:

```
S = (10^((P_cond - L + G) / 10)) / (4 · π · R²)
```

#### Виведення мінімальної безпечної відстані (Compliance Boundary)
Для визначення мінімальної безпечної відстані `R_safe`, на якій густина потоку потужності не перевищує регуляторний ліміт `S_limit`, перетворимо формулу:

```
S_limit = P_EIRP_lin / (4 · π · R_safe²)
4 · π · R_safe² = P_EIRP_lin / S_limit           [множення на R_safe² та ділення на S_limit]
R_safe² = P_EIRP_lin / (4 · π · S_limit)         [ділення на 4·π]
R_safe = √(P_EIRP_lin / (4 · π · S_limit))       [добування квадратного кореня]
```

### Критерій звільнення від тестування SAR за правилами FCC (KDB 447498)

Для портативних пристроїв, що експлуатуються на відстані `d ≤ 20 см` від тіла (смартфони, носимі датчики, натільні радіомодеми), пряме лабораторне вимірювання питомого коефіцієнта поглинання (SAR) вимагає використання дорогих манекенів-фантомів, наповнених тканоеквівалентною рідиною, та сканування роботизованим зондом.

Керівництво FCC KDB 447498 D01 General RF Exposure Guidance визначає числовий критерій звільнення від обов'язкового випробування SAR (англ. *SAR Test Exclusion Threshold*). Якщо потужність передавача достатньо мала або відстань до тіла достатня, пристрій визнається апріорі безпечним.

Формула безрозмірного показника виключення `Threshold` для відстаней `d ≤ 50 мм` має вигляд:

```
Threshold = (P_max_mW / d_mm) · √(f_GHz)
```
де:
- `P_max_mW` — максимальна вихідна потужність передавача з урахуванням технологічного допуску виробництва (дБм → мВт), усереднена за часом;
- `d_mm` — мінімальна фізична відстань між антеною (або випромінювальною структурою) та тілом людини (якщо відстань менше 5 мм, для розрахунку приймається `d = 5 мм`);
- `f_GHz` — робоча частота радіоканалу в гігагерцах.

#### Регуляторні умови звільнення:
1. **Для голови та тулуба (Head & Body):** Пристрій звільняється від вимірювань SAR, якщо:
```
Threshold ≤ 3.0
```
2. **Для кінцівок (Extremity — кисті рук, зап'ястя, стопи):** Пристрій звільняється від вимірювань SAR, якщо:
```
Threshold ≤ 7.5
```

Звідси гранична допустима потужність передавача `P_limit_mW` без проходження лабораторного тесту SAR для тулуба становить:

```
(P_limit_mW / d_mm) · √(f_GHz) = 3.0
P_limit_mW / d_mm = 3.0 / √(f_GHz)               [ділення на √(f_GHz)]
P_limit_mW = (3.0 · d_mm) / √(f_GHz)             [множення на d_mm]
```

### Європейський поріг низької потужності за стандартом EN 50663

Європейський гармонізований стандарт EN 50663 (а також базовий стандарт EN 62479) визначає єдиний спрощений поріг низької потужності (Low-power exclusion limit `P_max`).

Якщо середньозважена за часом випромінювана потужність передавача `P_avg` (з урахуванням робочого циклу Duty Cycle `D`) задовольняє умову:

```
P_avg = P_peak · D ≤ 20 мВт  (13 дБм)
```
пристрій вважається відповідним базовим обмеженням безпеки Директиви RED 2014/53/EU за статтею 3.1(a) без проведення вимірювань SAR або MPE для будь-якої відстані до тіла (включаючи прямий контакт `d = 0 мм`).

### Покроковий інженерний розрахунок: телеметричний трансивер БПЛА

**Вихідні дані інженерної задачі:**
Розробляється бортовий телеметричний модуль 2.4 ГГц для безпілотного літального апарата та портативного пульта керування.
- Кондуктивна потужність трансивера: `P_cond = 20 дБм` (100 мВт);
- Втрати у коаксіальному кабелі та роз'ємах U.FL: `L_cable = 0.8 дБ`;
- Коефіцієнт підсилення всеспрямованої дипольної антени: `G_ant = 2.8 дБі`;
- Робоча частота: `f = 2.440 ГГц`;
- Робочий цикл передавача пульта: `D = 25%` (0.25);
- Мінімальна відстань від вбудованої антени до долоні оператора всередині корпусу пульта: `d = 12 мм`.

#### Крок 1. Розрахунок EIRP для перевірки відповідності нормам FCC та ETSI

```
EIRP
= P_cond - L_cable + G_ant
= 20.0 - 0.8 + 2.8               [підстановка параметрів]
= 22.0 дБм                       [результат EIRP]
```

Переведення у мілівати:

```
P_EIRP_lin
= 10^(22.0 / 10)                 [переведення дБм у лінійні мілівати]
= 10^2.2                         [обчислення показника степеня]
= 158.49 мВт                     [значення випромінюваної потужності]
```

**Висновок щодо лімітів потужності:**
- **Для ринку США (FCC Part 15.247):** Ліміт становить `36.0 дБм` EIRP. Розраховане значення `22.0 дБм` є повністю легальним (запас `14.0 дБ`).
- **Для ринку ЄС (ETSI EN 300 328):** Ліміт становить `20.0 дБм` EIRP (100 мВт). Розраховане значення `22.0 дБм` перевищує європейську норму на `2.0 дБ`. Для сертифікації в ЄС необхідно програмно знизити кондуктивну потужність чіпа до `P_cond = 18.0 дБм` (`18.0 - 0.8 + 2.8 = 20.0 дБм`).

#### Крок 2. Розрахунок критерію виключення SAR для пульта керування (FCC KDB 447498)

Враховуємо усереднену за часом кондуктивну потужність пульта з урахуванням коефіцієнта заповнення передачі `D = 25%`:

```
P_avg_lin
= 100.0 мВт · 0.25               [множення пікової потужності на робочий цикл 25%]
= 25.0 мВт                       [усереднена потужність]
```

Обчислюємо корінь робочої частоти:
```
√(f_GHz) = √(2.440) ≈ 1.562
```

Обчислюємо показник порогу виключення FCC:

```
Threshold
= (P_avg_lin / d_mm) · √(f_GHz)  [формула FCC KDB 447498]
= (25.0 / 12.0) · 1.562          [підстановка значень d = 12 мм]
= 2.083 · 1.562                  [проміжне множення]
= 3.254                          [показник FCC Threshold]
```

**Аналіз результату:**
- Для тулуба/голови ліміт становить `3.0`. Оскільки `3.254 > 3.0`, для натільного носіння потрібне лабораторне випробування SAR.
- Для кінцівок (Extremity — руки оператора на пульті) ліміт становить `7.5`. Оскільки `3.254 ≤ 7.5`, пульт керування **повністю звільняється від лабораторного тестування SAR для рук оператора** за правилами FCC!

#### Крок 3. Розрахунок MPE безпечної відстані для бортового модуля БПЛА

Для бортового модуля БПЛА потужність не обмежена робочим циклом (`D = 100%`, `P_EIRP_lin = 158.49 мВт = 0.1585 Вт`).
Регуляторний ліміт FCC MPE на частоті 2.4 ГГц для неконтрольованого середовища (General Population) становить:
```
S_limit = 1.0 мВт/см² = 10.0 Вт/м²
```

Обчислюємо безпечну відстань `R_safe`:

```
R_safe
= √(P_EIRP_lin_W / (4 · π · S_limit)) [формула безпечної дистанції]
= √(0.1585 / (4 · 3.14159 · 10.0))    [підстановка ліміту 10 Вт/м²]
= √(0.1585 / 125.664)                 [обчислення площі сфери]
= √(0.001261)                         [проміжне ділення]
= 0.0355 м = 3.55 см                  [мінімальна дистанція відповідності MPE]
```

Оскільки бортовий модуль БПЛА розташовано далі ніж `3.55 см` від людей (типова відстань польоту > 1 м), вимога MPE виконується із запасом у кілька порядків.

### Одночасне випромінювання співрозташованих передавачів (Co-located Transmitters)

Сучасні пристрої (наприклад, польотні контролери або мультисенсорні хаби) часто інтегрують кілька бездротових інтерфейсів (Wi-Fi 2.4 ГГц + Bluetooth + стільниковий модем 4G/LTE + телеметрія LoRa 868/915 МГц), які функціонують одночасно.

Регулятори (FCC та ETSI) вимагають оцінки кумулятивного електромагнітного впливу. Заборонено просто перевіряти кожен передавач окремо: сумарне опромінення не повинно перевищувати нормативну одиницю.

#### 1. Кумулятивний коефіцієнт MPE (MPE Ratio Summation)
Для мобільних або стаціонарних пристроїв (`d > 20 см`), де діє оцінка за густиною потоку потужності, розраховується сума відносних внесків кожного передавача:

```
Fractional_MPE = ∑ [ S_i / S_limit_i ] ≤ 1.0
```
де `S_i` — фактична густина потоку потужності `i`-го передавача на заданій відстані, а `S_limit_i` — гранично допустимий ліміт для робочої частоти `f_i` даного передавача.

Якщо розписати через потужність кожного передавача `P_EIRP_i`:

```
Fractional_MPE
= ∑ [ P_EIRP_i / (4 · π · R² · S_limit_i) ]               [підстановка густини потоку кожного передавача]
= (1 / (4 · π · R²)) · ∑ [ P_EIRP_i / S_limit_i ] ≤ 1.0   [винесення спільного радіуса за дужки]
```

#### 2. Кумулятивний коефіцієнт SAR та коефіцієнт просторового розділення (SPLSR)
Для портативних пристроїв (`d ≤ 20 см`), якщо в одному корпусі розташовано декілька антен, що випромінюють одночасно, застосовується перевірка сумарного SAR:

```
Total_SAR = ∑ SAR_i ≤ SAR_limit  (1.6 Вт/кг за FCC / 2.0 Вт/кг за ETSI)
```

Якщо сума пікових значень перевищує ліміт (`∑ SAR_i > 1.6 Вт/кг`), FCC (KDB 447498) дозволяє не проводити складне комплексне тестування суміщеного поля за умови виконання критерію відношення сумарного SAR до пікової відстані розділення між антенами (англ. *SAR-to-Peak Location Separation Ratio*, SPLSR):

```
SPLSR = (SAR_1 + SAR_2)^1.5 / R_sep ≤ 0.04
```
де:
- `SAR_1` та `SAR_2` — окремо виміряні максимальні значення 1g SAR для першої та другої антен (Вт/кг);
- `R_sep` — просторова відстань між точками максимальної локалізації SAR першої та другої антен у міліметрах (мм).

Якщо `SPLSR ≤ 0.04`, просторові піки поглинання рознесені достатньо далеко в тілі людини й не накладаються конструктивно, тому пристрій визнається відповідним вимогам безпеки без випробувань одночасного випромінювання.

### Розрахунок бюджету потужності та робочого циклу для LoRa 868 МГц проти 915 МГц

**Вихідні дані інженерної задачі:**
Розробляється промисловий лічильник газу, що передає дані по протоколу LoRaWAN.
- Кондуктивна потужність чіпа Semtech SX1262: `P_cond = 14.0 дБм` (25.1 мВт);
- Коефіцієнт підсилення спіральної антени: `G_ant = 1.5 дБі`;
- Втрати на узгоджувальному LC-фільтрі: `L_match = 0.5 дБ`.

#### 1. Розрахунок ERP для європейського діапазону EU868 (ETSI EN 300 220)
У піддіапазоні 868.0–868.6 МГц (G1) регуляторний ліміт становить `14.0 дБм ERP` (25 мВт ERP).

```
ERP
= P_cond - L_match + G_ant - 2.15     [формула переведення EIRP у ERP]
= 14.0 - 0.5 + 1.5 - 2.15             [підстановка параметрів]
= 15.0 - 2.15                         [проміжне додавання]
= 12.85 дБм ERP                       [результат випромінювання]
```

Оскільки `12.85 дБм ERP < 14.0 дБм ERP`, передавач повністю вкладається в ліміт потужності із запасом `1.15 дБ`.

#### 2. Розрахунок допустимого часу в ефірі (Time on Air) за лімітом Duty Cycle 1%
За європейським стандартом ETSI EN 300 220, максимальний сумарний час передачі в піддіапазоні 868.0–868.6 МГц за 1 годину (`T_hour = 3600 с`) обмежено коефіцієнтом `1%`:

```
T_tx_max
= 3600 с · 0.01                       [множення 3600 с на ліміт 1%]
= 36.0 секунд на годину               [ліміт часу передачі]
```

Якщо тривалість передачі одного пакету LoRa (SF10, смуга 125 кГц, корисне навантаження 32 байти) становить `TimeOnAir = 370 мс = 0.370 с`, максимальна дозволена кількість виходів в ефір на годину становить:

```
N_packets_max
= T_tx_max / TimeOnAir                [відношення сумарного часу до тривалості пакету]
= 36.0 / 0.370                        [ділення сумарного ліміту на тривалість пакету]
= 97.29 ≈ 97 пакетів на годину        [максимальна частота передачі]
```

#### 3. Порівняння з нормами США US915 (FCC Part 15.247)
У США на частоті 915 МГц (902–928 МГц) ліміт Duty Cycle 1% відсутній. Пристрій може транслювати сигнал без обмеження відсотків на годину за умови, що час безперервного перебування на одній частоті (Dwell Time) за режиму стрибкоподібної зміни частоти FHSS задовольняє умову:

```
T_dwell ≤ 400 мс                      [ліміт тривалості одного пакету на одній частоті]
```
Оскільки наш пакет має тривалість `370 мс ≤ 400 мс`, передавач є повністю легальним для ринку США без необхідності зменшення обсягу переданих даних.
