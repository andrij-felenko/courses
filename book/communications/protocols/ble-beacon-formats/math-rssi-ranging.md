# 🧮 Математичні моделі оцінки дистанції та фільтрації шуму RSSI

Оцінка фізичної відстані між бездротовим спостерігачем і радіомаячком за рівнем потужності прийнятого сигналу спирається на теорію поширення електромагнітних хвиль, стохастичні моделі затінення та методи оптимальної статистичної фільтрації дискретних випадкових процесів. Нижче наведено строге математичне виведення рівнянь загасання, аналітичні методи калібрування параметрів, дослідження нелінійних викривлень у логарифмічній шкалі та повний апарат одновимірного фільтра Калмана для стабілізації оцінок відстані в умовах радіозавад.

---

### 1. Фізична основа: розповсюдження електромагнітної хвилі у вільному просторі

Розглянемо випромінювання точкової ізотропної антени маячка у вільному однорідному середовищі без перешкод. Електромагнітна енергія, що випромінюється з потужністю `P_tx` (Ват), рівномірно розсіюється по поверхні уявної сфери радіуса `d` (метри).

Густина потоку потужності `S` (Вт/м²) на поверхні цієї сфери дорівнює повній випроміненій потужності, поділеній на площу сфери `4 · π · d²`:

```
S = P_tx / (4 · π · d²)                                   [визначення густини потоку сферичної хвилі]
```

Приймальна антена сканера з ефективною ізотропною апертурою `A_rx` (м²) перехоплює частину цієї енергії. За фундаментальною теоремою електродинаміки ефективна площа приймальної антени з коефіцієнтом підсилення `G_rx` на довжині хвилі `λ` виражається формулою:

```
A_rx = (λ² · G_rx) / (4 · π)                              [ефективна апертура приймальної антени]
```

Повна потужність сигналу `P_rx`, що виділяється на навантаженні приймача, дорівнює добутку густини потоку потужності на ефективну площу приймальної антени:

```
P_rx
= S · A_rx                                                [добуток густини потоку на площу антени]
= [ (P_tx · G_tx) / (4 · π · d²) ] · [ (λ² · G_rx) / (4 · π) ] [підстановка значень S та A_rx з підсиленням]
= P_tx · G_tx · G_rx · [ λ / (4 · π · d) ]²               [формула передачі Фрііса у лінійній формі]
```

Для переходу до логарифмічної шкали децибел-міліватів (дБм) застосовується співвідношення `P(дБм) = 10 · log₁₀(P(мВт))`:

```
RSSI(d)
= 10 · log₁₀(P_rx / 1 мВт)                                [визначення рівня RSSI у логарифмічній шкалі]
= TxPower + G_tx + G_rx + 20 · log₁₀(λ / (4 · π · d))    [логарифмування добутку множників формули Фрііса]
= TxPower + G_tx + G_rx + 20 · log₁₀(λ / (4 · π)) - 20 · log₁₀(d) [розкриття логарифма частки: log(a/b) = log(a) - log(b)]
```

У радіоканалі BLE на центральній частоті `f = 2.44 ГГц` довжина хвилі дорівнює:

```
λ = c / f = (3 · 10⁸ м/с) / (2.44 · 10⁹ Гц) ≈ 0.123 м
```

Якщо об'єднати випромінену потужність передавача `TxPower`, підсилення обох антен `G_tx`, `G_rx` та константні просторові втрати на відстані `d₀ = 1 м` в єдиний комплексний параметр `MeasuredPower` (потужність на відстані 1 метр, позначається також як `P_0`), формула набуває канонічного вигляду:

```
RSSI(d) = MeasuredPower - 20 · log₁₀(d)                   [спадання сигналу у вільному просторі]
```

З формули видно, що у вільному просторі потужність сигналу спадає рівно на `20 · log₁₀(2) ≈ 6.02 дБ` при кожному подвоєнні відстані між приймачем і передавачем.

### 2. Двопроменева модель відбиття від поверхні (Two-Ray Ground Reflection)

У реальних умовах радіохвиля досягає антени сканера не лише прямим шляхом, а й відбиваючись від підлоги, ґрунту або стелі. Якщо висота антени передавача становить `h_tx`, а висота антени приймача — `h_rx`, то прямий промінь має довжину `d_dir = √(d² + (h_tx - h_rx)²)`, а відбитий промінь проходить шлях `d_ref = √(d² + (h_tx + h_rx)²)`.

При розкладанні різниці фаз прямих і відбитих променів у ряд Тейлора для великих відстаней `d >> (h_tx + h_rx)` інтерференція змінює характер спадання потужності:

```
P_rx_ground ≈ P_tx · G_tx · G_rx · [ (h_tx · h_rx) / d² ]² [асимптотична потужність для двох променів]
```

Логарифмуючи цей вираз, отримуємо закон спадання з коефіцієнтом 4:

```
RSSI_ground(d) = P_ref - 40 · log₁₀(d)                    [спадання за законом 4-го степеня відстані]
```

Це фундаментальне радіофізичне явище пояснює, чому в просторих приміщеннях, коридорах та на відкритих майданчиках показник загасання траси поступово змінюється від `n ≈ 2` на малих дистанціях (де домінує вільний простір) до `n ≈ 4` на великих дистанціях (де починає переважати деструктивне відбиття від підлоги). Критична точка переходу `d_c` визначається висотою підвісу антен: `d_c ≈ (4 · h_tx · h_rx) / λ`.

### 3. Узагальнена модель Log-Distance Path Loss та логнормальне затінення

У закритих приміщеннях із багаторазовими відбиттями від стін, перегородок, меблів та металевих конструкцій теоретичне моделювання кожного окремого променя стає неможливим. Поширення радіохвиль описують емпіричною узагальненою моделлю **Log-Distance Path Loss**:

```
RSSI(d) = MeasuredPower - 10 · n · log₁₀(d / d₀) + X_σ    [узагальнена логарифмічно-дистанційна модель]
```

Параметри моделі мають чіткий фізичний зміст:
* `RSSI(d)` — усереднена потужність сигналу на відстані `d` (дБм);
* `MeasuredPower` — заводськи відкаліброване значення потужності на опорній відстані `d₀ = 1 м` (дБм);
* `n` — безрозмірний показник загасання траси (*Path Loss Exponent*), що відображає швидкість згасання енергії в даному матеріальному середовищі;
* `X_σ` — випадкова величина з нормальним (гаусовим) розподілом `X_σ ~ N(0, σ²)`, яка моделює стохастичне великомасштабне затінення (*Log-normal Shadowing*).

#### Фізичні фактори та діапазони значень показника загасання `n`

Показник загасання `n` залежить від геометрії приміщення, типу будівельних матеріалів та наявності прямої видимості (LOS, *Line-of-Sight*):

| Характеристика простору | Значення `n` | Стандартне відхилення `σ` | Фізичний механізм |
| :--- | :--- | :--- | :--- |
| Вільний вакуум / безлунна камера | `2.0` | `0.5 .. 1.5 дБ` | Ідеальна сферична дивергенція |
| Довгий прямий коридор (LOS) | `1.5 .. 1.8` | `2.0 .. 4.0 дБ` | Хвилеводне спрямування вздовж стін |
| Офіс відкритого типу (Open Space) | `2.4 .. 2.8` | `4.0 .. 6.0 дБ` | Дифракція на краях меблів, стійок |
| Офіс із кабінетним плануванням (NLOS)| `3.0 .. 3.8` | `6.0 .. 9.0 дБ` | Поглинання гіпсокартоном і склом |
| Виробничий цех / складський термінал | `3.5 .. 4.5` | `8.0 .. 12.0 дБ` | Металеві стелажі, екранування |

### 4. Аналітичне виведення відстані та калібрування нульової точки

Для розрахунку фізичної відстані `d` між сканером та маячком виконаємо алгебраїчні перетворення базового рівняння, припускаючи, що миттєвий шум `X_σ` згладжено фільтром:

```
RSSI = MeasuredPower - 10 · n · log₁₀(d)                  [вихідне рівняння зв'язку]

10 · n · log₁₀(d)
= MeasuredPower - RSSI                                    [перенесення доданка з логарифмом ліворуч]

log₁₀(d)
= (MeasuredPower - RSSI) / (10 · n)                       [ділення обох частин на 10·n]

d
= 10 ^ ( (MeasuredPower - RSSI) / (10 · n) )              [піднесення основи 10 до степеня]
```

#### Математичне узгодження калібрувальних точок 0 м та 1 м

Різні стандарти маячків використовують різні системи просторового відліку:
* Apple iBeacon та AltBeacon калібрують рівень потужності на відстані **1 метр** (`MeasuredPower` або `Reference RSSI`);
* Google Eddystone транслює значення `Ranging Data` на виході випромінювача на відстані **0 метрів** (`P_0m`).

Для використання єдиного алгоритму позиціонування необхідно перерахувати каліброване значення Eddystone до стандартної опорної дистанції 1 метр через віднімання втрат вільного простору:

```
FSPL(1m)
= 20 · log₁₀(4 · π · 1 / λ)                              [формула FSPL при d = 1 м]
= 20 · log₁₀(4 · 3.14159 · 1 / 0.123)                    [підстановка констант π та λ]
= 20 · log₁₀(102.16)                                     [обчислення виразу під логарифмом]
≈ 40.19 дБ ≈ 41 дБ                                       [десятковий логарифм та заокруглення]
```

Звідси отримуємо точну формулу нормалізації для кадру Eddystone:

```
MeasuredPower_1m = Eddystone_TxPower_0m - 41              [зведення калібрування Eddystone до 1 метра]
```

### 5. Оцінка показника загасання `n` методом найменших квадратів (OLS)

Для розгортання системи точного позиціонування коефіцієнт `n` не беруть з таблиць, а визначають експериментально на об'єкті. Для цього встановлюють калібрувальний маячок і вимірюють серію з `M` значень потужності `RSSI_i` на строго відомих контрольних відстанях `d_i` (наприклад, 1, 2, 3, 5, 8, 10 метрів).

Сформулюємо задачу лінійної регресії:

```
y_i = n · x_i + ε_i
де:
y_i = MeasuredPower - RSSI_i                              [фактичне загасання на кроці i]
x_i = 10 · log₁₀(d_i)                                     [логарифмічна координата відстані]
ε_i ~ N(0, σ²)                                            [випадкова похибка вимірювання]
```

Цільова функція методу найменших квадратів є сумою квадратів відхилень:

```
S(n) = ∑ [ y_i - n · x_i ]²                               [сума квадратів нев'язок за всіма M точками]
```

Для знаходження мінімуму візьмемо похідну за параметром `n` і прирівняємо її до нуля:

```
dS / dn
= -2 · ∑ x_i · [ y_i - n · x_i ]                          [диференціювання за невідомим параметром n]
= -2 · [ ∑ (x_i · y_i) - n · ∑ (x_i²) ]                   [розкриття дужок у сумі]
= 0                                                       [умова екстремуму]

n = ( ∑ (x_i · y_i) ) / ( ∑ (x_i²) )                      [оптимальна оцінка показника загасання траси]
```

Після знаходження оптимального значення `n` оцінка дисперсії випадкового затінення `σ²` розраховується за формулою залишкової вибіркової дисперсії:

```
σ̂² = (1 / (M - 1)) · ∑ [ (MeasuredPower - RSSI_i) - n · 10 · log₁₀(d_i) ]² [вибіркова дисперсія шуму затінення]
```

### 6. Нелінійні спотворення та нерівність Єнсена

У цифрових системах обробки сигналів поширеною помилкою є перетворення кожного сирого відліку `RSSI` у відстань `d` з наступним усередненням отриманих відстаней. Доведемо, чому такий підхід призводить до систематичної похибки завищення дистанції.

Функція розрахунку дистанції за рівнем RSSI `f(x) = 10^( (P_0 - x) / (10 · n) ) = C · e^( -k · x )` є **строго опуклою** функцією для всіх дійсних `x` (її друга похідна `f''(x) = C · k² · e^(-kx) > 0` строго додатна).

Згідно з **нерівністю Єнсена** для довільної строго опуклої функції `g(X)` та випадкової величини `X` із ненульовою дисперсією виконується строга нерівність:

```
E[ g(X) ] > g( E[X] )                                     [нерівність Єнсена для опуклих функцій]
```

Застосовуючи нерівність до розрахунку відстані для зашумленого сигналу `RSSI = μ + X_σ`:

```
E[ d(RSSI) ]
= E[ 10^( (MeasuredPower - RSSI) / (10 · n) ) ]           [математичне сподівання миттєво обчислених відстаней]
> 10^( (MeasuredPower - E[RSSI]) / (10 · n) )             [відстань, обчислена за усередненим значенням RSSI]
= d( E[RSSI] )                                            [істинна геометрична відстань]
```

Якщо величина затінення підпорядковується нормальному закону `X_σ ~ N(0, σ²)`, аналітичне значення середньої обчисленої дистанції виражається через генератрису моментів:

```
E[ d(RSSI) ] = d_true · exp[ ( (ln(10) / (10 · n)) · σ )² / 2 ] [систематичне зміщення через нелінійність]
```

При типових параметрах приміщення `n = 2.0` та `σ = 6 дБ` коефіцієнт зміщення дорівнює:

```
( (ln(10) / 20) · 6 )² / 2 = (0.1151 · 6)² / 2 = (0.6908)² / 2 ≈ 0.2386
exp(0.2386) ≈ 1.27
```

Це означає, що при усередненні миттєво обчислених відстаней результат буде **завищено на 27% від істинної дистанції**. Тому фільтрацію шуму необхідно виконувати **виключно у логарифмічній шкалі децибелів** над значеннями RSSI, і лише після отримання згладженої оцінки `RSSI_est` проводити однократне перетворення у фізичну відстань.

### 7. Одновимірний дискретний фільтр Калмана для трекінгу RSSI

Для динамічного оцінювання рівня сигналу в реальному часі застосовується одновимірний фільтр Калмана. Фільтр є оптимальним оцінювачем у сенсі мінімуму середньоквадратичної похибки (MMSE) для лінійних систем із гаусовим шумом.

#### Математична формулювання моделі

1. **Динаміка стану (Process Equation):**
   Рівень сигналу на вході приймача моделюється випадковим блуканням із процесорним білим шумом `w[k]`:
   ```
   x[k] = x[k-1] + w[k],   де w[k] ~ N(0, Q)             [квазістатична модель стану сигналу]
   ```
   Тут `x[k]` — істинний невідомий рівень RSSI (дБм), а дисперсія процесорного шуму `Q` відображає динаміку зміни сигналу через фізичний рух об'єкта в просторі.

2. **Модель спостереження (Measurement Equation):**
   Вимірювання від апаратного радіоприймача `z[k]` містить випадковий шум вимірювального тракту та швидкі інтерференційні завмирання `v[k]`:
   ```
   z[k] = x[k] + v[k],     де v[k] ~ N(0, R)             [модель апаратного вимірювання RSSI]
   ```
   Тут `R` — коваріація шуму вимірювання (типово `R = 3.0 .. 9.0 дБ²`).

#### Рекурентний алгоритм фільтрації

На кожному кроці `k` надходження нового пакета алгоритм виконує два етапи:

```
[1. Етап екстраполяції / прогнозу (Predict)]
x̂⁻[k] = x̂[k-1]                                            [апріорна оцінка стану дорівнює попередній оцінці]
P⁻[k] = P[k-1] + Q                                        [прогноз апріорної коваріації помилки оцінки]

[2. Етап корекції / оновлення (Update)]
K[k] = P⁻[k] / (P⁻[k] + R)                                [коефіцієнт підсилення Калмана]
x̂[k] = x̂⁻[k] + K[k] · (z[k] - x̂⁻[k])                     [апостеріорна оцінка стану на основі нев'язки]
P[k] = (1 - K[k]) · P⁻[k]                                 [апостеріорна коваріація помилки оцінки]
```

#### Стаціонарний стан фільтра (Steady-State Riccati Solution)

Для стаціонарного приймача коваріація помилки швидко збігається до постійного значення `P_∞`. Прирівнюючи `P[k] = P[k-1] = P_∞`:

```
P_∞ = (1 - (P_∞ + Q) / (P_∞ + Q + R)) · (P_∞ + Q)        [рівняння Ріккаті для стаціонарного режиму]

P_∞ · (P_∞ + Q + R) = R · (P_∞ + Q)                       [множення на спільний знаменник]

P_∞² + Q · P_∞ - Q · R = 0                                [квадратне алгебраїчне рівняння Ріккаті]

P_∞ = ( -Q + √(Q² + 4 · Q · R) ) / 2                      [додатний корінь квадратного рівняння]
```

Стаціонарний коефіцієнт Калмана `K_∞` становить:

```
K_∞ = ( √(1 + 4 · (R / Q)) - 1 ) / ( 2 · (R / Q) )        [залежність відношення підсилення від балансу шумів R/Q]
```

Це рівняння показує, що динаміка фільтра однозначно визначається безрозмірним відношенням `R / Q`:
* Якщо `Q >> R` (висока рухливість вузла), то `K_∞ → 1`, і фільтр миттєво відстежує сирі вимірювання;
* Якщо `R >> Q` (статичний об'єкт у шумному середовищі), то `K_∞ → 0`, і фільтр сильно згладжує вхідний потік, надійно придушуючи завади.

### 8. Покроковий числовий приклад розрахунку

Продемонструємо збіжність фільтра Калмана на серії з 6 послідовних вимірювань RSSI від маячка з параметрами `MeasuredPower = -59 дБм` та `n = 2.0`.

**Початкові налаштування фільтра:**
* Початкова оцінка: `x̂[0] = -60.0 дБм`, початкова невизначеність `P[0] = 5.0 дБ²`;
* Параметри шумів: `Q = 0.05 дБ²`, `R = 4.0 дБ²`.

Вхідна вибірка містить різкий інтерференційний викид на кроці `k = 4` (`-85.0 дБм` замість середнього `-70 дБм`):

```
z = [ -68.0, -72.0, -69.0, -85.0 (викид), -70.0, -71.0 ]
```

```
Крок k=1: вимірювання z[1] = -68.0 дБм
P⁻[1] = 5.0 + 0.05 = 5.05                                 [прогноз дисперсії: P[0] + Q]
K[1]  = 5.05 / (5.05 + 4.0) = 5.05 / 9.05 ≈ 0.558         [розрахунок підсилення Калмана]
x̂[1]  = -60.0 + 0.558 · (-68.0 - (-60.0)) = -64.46 дБм    [корекція оцінки за нев'язкою]
P[1]  = (1 - 0.558) · 5.05 ≈ 2.23                         [оновлення апостеріорної дисперсії]

Крок k=2: вимірювання z[2] = -72.0 дБм
P⁻[2] = 2.23 + 0.05 = 2.28                                [прогноз дисперсії: P[1] + Q]
K[2]  = 2.28 / (2.28 + 4.0) = 2.28 / 6.28 ≈ 0.363         [розрахунок підсилення Калмана]
x̂[2]  = -64.46 + 0.363 · (-72.0 - (-64.46)) = -67.20 дБм  [корекція оцінки за нев'язкою]
P[2]  = (1 - 0.363) · 2.28 ≈ 1.45                         [оновлення апостеріорної дисперсії]

Крок k=3: вимірювання z[3] = -69.0 дБм
P⁻[3] = 1.45 + 0.05 = 1.50                                [прогноз дисперсії: P[2] + Q]
K[3]  = 1.50 / (1.50 + 4.0) = 1.50 / 5.50 ≈ 0.273         [розрахунок підсилення Калмана]
x̂[3]  = -67.20 + 0.273 · (-69.0 - (-67.20)) = -67.69 дБм  [корекція оцінки за нев'язкою]
P[3]  = (1 - 0.273) · 1.50 ≈ 1.09                         [оновлення апостеріорної дисперсії]

Крок k=4: аномальний інтерференційний викид z[4] = -85.0 дБм
P⁻[4] = 1.09 + 0.05 = 1.14                                [прогноз дисперсії: P[3] + Q]
K[4]  = 1.14 / (1.14 + 4.0) = 1.14 / 5.14 ≈ 0.222         [розрахунок підсилення Калмана]
x̂[4]  = -67.69 + 0.222 · (-85.0 - (-67.69)) = -71.53 дБм  [корекція оцінки: зсув лише на 3.84 дБ замість 17.3 дБ]
P[4]  = (1 - 0.222) · 1.14 ≈ 0.89                         [оновлення апостеріорної дисперсії]

Крок k=5: вимірювання z[5] = -70.0 дБм
P⁻[5] = 0.89 + 0.05 = 0.94                                [прогноз дисперсії: P[4] + Q]
K[5]  = 0.94 / (0.94 + 4.0) = 0.94 / 4.94 ≈ 0.190         [розрахунок підсилення Калмана]
x̂[5]  = -71.53 + 0.190 · (-70.0 - (-71.53)) = -71.24 дБм  [корекція оцінки за нев'язкою]
P[5]  = (1 - 0.190) · 0.94 ≈ 0.76                         [оновлення апостеріорної дисперсії]

Крок k=6: вимірювання z[6] = -71.0 дБм
P⁻[6] = 0.76 + 0.05 = 0.81                                [прогноз дисперсії: P[5] + Q]
K[6]  = 0.81 / (0.81 + 4.0) = 0.81 / 4.81 ≈ 0.168         [розрахунок підсилення Калмана]
x̂[6]  = -71.24 + 0.168 · (-71.0 - (-71.24)) = -71.20 дБм  [корекція оцінки за нев'язкою]
P[6]  = (1 - 0.168) · 0.81 ≈ 0.67                         [оновлення апостеріорної дисперсії]
```

Розрахуємо фінальну фізичну дистанцію за стабілізованим значенням `x̂[6] = -71.20 дБм`:

```
d_est
= 10 ^ ((MeasuredPower - RSSI_est) / (10 · n))           [модель Log-Distance Path Loss]
= 10 ^ ((-59.0 - (-71.20)) / (10 · 2.0))                 [підстановка значень MeasuredPower, RSSI та n]
= 10 ^ (12.20 / 20.0)                                    [віднімання у чисельнику: -59 - (-71.20) = 12.20]
= 10 ^ 0.61                                              [ділення показника степеня]
≈ 4.07 метра                                             [обчислення степеня]
```

Якби на кроці 4 для розрахунку відстані було використано сирий викид `z[4] = -85.0 дБм`, обчислена відстань становила б `10^((-59 - (-85)) / 20) = 10^(1.3) ≈ 19.95 м` — тобто похибка перевищила б 400%. Фільтр Калмана надійно локалізував стрибок завади і зберіг траєкторію в межах фізично адекватного коридору.
