# 🧮 Межа BCH: строгий доказ через визначник Вандермонда

<preknowlist>
- [Лінійні блокові коди](book:communications/linear-block-codes) — код замкнений на додавання: різниця двох кодових слів знову кодове слово. Тому мінімальна відстань коду дорівнює мінімальній **вазі** (кількості ненульових позицій) серед ненульових кодових слів — усе зводиться до «наскільки легким може бути ненульове слово».
- [Скінченні поля Галуа](book:math/finite-fields) — GF(2ᵐ) має 2ᵐ елементів і примітивний елемент α, чиї степені α⁰, α¹, …, α^{n−1} (n = 2ᵐ−1) — усі різні ненульові елементи. Ключова властивість поля: у ньому **немає дільників нуля** — добуток ненульових множників ненульовий.
- [Визначник матриці](book:math/matrix-determinant) — число, що дорівнює нулю тоді й лише тоді, коли рядки (стовпці) лінійно залежні. Однорідна система M·c = 0 має **лише** нульовий розв'язок c = 0 тоді й лише тоді, коли det M ≠ 0.
- [Відстань Геммінга](book:communications/hamming-distance) — код із мінімальною відстанню d впевнено виправляє t = ⌊(d−1)/2⌋ помилок; куля радіуса t навколо кодового слова не налазить на сусідню.
</preknowlist>

Умова коду BCH звучить оманливо просто: кожне кодове слово c(x) мусить обертатися на нуль у 2t сусідніх степенях примітивного елемента, c(α¹) = c(α²) = … = c(α²ᵗ) = 0. З цієї єдиної вимоги нібито «очевидно» випливає, що легких кодових слів не буває — мінімальна відстань не менша за 2t+1. Але «очевидно» тут і є пастка. Занулити многочлен у багатьох точках — обмеження сильне, проте саме по собі воно ще нічого не гарантує: якби ці 2t умов виявилися **надлишковими** (одна випливала з інших), то легке ненульове слово могло б крізь них прослизнути. Уся сила межі тримається на одному-єдиному факті — що ці 2t умов **лінійно незалежні**. А незалежність, своєю чергою, тримається на тому, що степені взяті **поспіль**. Розгорнімо цей ланцюг до кінця: від припущення про легке слово — до визначника Вандермонда, який не має права занулитися над скінченним полем.

## Що саме доводимо

Зафіксуймо твердження без жодної двозначності.

**Межа BCH.** Нехай C — код над GF(2) (біти кодового слова — нулі й одиниці), заданий у полі GF(2ᵐ) через примітивний елемент α порядку n = 2ᵐ−1. Якщо **кожне** кодове слово c(x) задовольняє

```
c(αʲ) = 0     для j = 1, 2, 3, …, 2t
```

(2t сусідніх степенів α), то мінімальна відстань коду d ≥ 2t+1.

Перше спрощення дарує лінійність коду. Відстань між двома словами — це вага їхньої різниці, а різниця двох кодових слів сама є кодовим словом. Тож мінімальна відстань між **парами** дорівнює мінімальній вазі серед **ненульових** кодових слів. Замість «наскільки далеко рознесені слова» доводимо еквівалентне «наскільки легким буває ненульове слово». Мета набуває гострої форми: **показати, що ненульового кодового слова ваги w ≤ 2t не існує.** Доведемо це від супротивного — припустимо, що таке слово є, і зажену його в суперечність.

## Переклад умови на локатори

Нехай усупереч сказаному існує ненульове кодове слово c(x) ваги w ≤ 2t. Вага w означає рівно w ненульових коефіцієнтів; хай вони стоять на позиціях i₁ < i₂ < … < i_w, а самі значення — c_{i₁}, …, c_{i_w} (усі ненульові; для двійкового коду вони одиниці, але жодне міркування нижче цього не потребує). Тоді

```
c(x) = c_{i₁}·x^{i₁} + c_{i₂}·x^{i₂} + … + c_{i_w}·x^{i_w}
```

Підставмо в це слово наші 2t призначених коренів. Для кожного j від 1 до 2t умова c(αʲ) = 0 розписується так:

```
0 = c(αʲ) = c_{i₁}·(αʲ)^{i₁} + … + c_{i_w}·(αʲ)^{i_w}
          = c_{i₁}·(α^{i₁})ʲ + … + c_{i_w}·(α^{i_w})ʲ
```

Тут напрошується заміна, що очищає запис від зайвого. Позначмо **локатор** ℓ-ї ненульової позиції

```
Xₗ = α^{iₗ}       (ℓ = 1 … w)
```

Ці w чисел — різні ненульові елементи поля. Ненульові, бо це степені α. **Різні** — бо позиції iₗ різні, а α має порядок n, тож α^{i} для 0 ≤ i < n усі відмінні один від одного. Цю відмінність варто підкреслити червоним олівцем: саме вона наприкінці врятує весь доказ. У нових позначеннях 2t рівнянь стають напрочуд однорідними:

```
0 = c_{i₁}·X₁ʲ + c_{i₂}·X₂ʲ + … + c_{i_w}·X_wʲ,     j = 1, 2, …, 2t
```

Дивімося на це як на систему лінійних рівнянь щодо невідомих c_{i₁}, …, c_{i_w}. Невідомих рівно w. Рівнянь у нас 2t, і оскільки w ≤ 2t, візьмімо **перші w** із них (j = 1, 2, …, w) — рівно стільки, скільки невідомих. Дістаємо квадратну однорідну систему w×w:

```
X₁¹·c_{i₁} + X₂¹·c_{i₂} + … + X_w¹·c_{i_w} = 0     (j = 1)
X₁²·c_{i₁} + X₂²·c_{i₂} + … + X_w²·c_{i_w} = 0     (j = 2)
   ⋮                                        ⋮
X₁ʷ·c_{i₁} + X₂ʷ·c_{i₂} + … + X_wʷ·c_{i_w} = 0     (j = w)
```

## Інтуїція: скільки важелів, стільки й обмежень

Перш ніж рахувати визначник, варто відчути, чому справа взагалі має скластися. Ненульове слово ваги w має рівно w «важелів свободи» — w невідомих значень c_{iₗ}, які треба тримати ненульовими, аби слово лишалося тим, чим ми його оголосили. Кожне рівняння c(αʲ) = 0 накладає на ці важелі один лінійний зв'язок. Якби зв'язки були **незалежні**, то w незалежних однорідних рівнянь на w невідомих притиснули б усі невідомі до нуля — єдиний розв'язок однорідної системи повного рангу нульовий. А нульові c_{iₗ} суперечать тому, що слово ненульове.

Уся інтрига, отже, в одному слові — **незалежні**. Незалежність не дається задарма: три випадкові лінійні рівняння на три невідомі бувають і виродженими (одне випливає з двох інших), і тоді ненульовий розв'язок існує. Треба довести, що саме **ця** система невироджена — хай яка легка комбінація локаторів у ній сидить. Мірило невиродженості квадратної системи одне: [визначник](book:math/matrix-determinant) її матриці. Якщо він ненульовий, система притискає все до нуля; якщо нуль — лишає лазівку. Тож усе зводиться до обчислення одного визначника.

## Матриця Вандермонда виступає на сцену

Випишімо матрицю коефіцієнтів M нашої системи. Її елемент у рядку j та стовпці ℓ — це Xₗʲ:

```
      ⎡ X₁¹   X₂¹   …   X_w¹ ⎤
      ⎢ X₁²   X₂²   …   X_w² ⎥
M  =  ⎢  ⋮     ⋮         ⋮   ⎥
      ⎣ X₁ʷ   X₂ʷ   …   X_wʷ ⎦
```

У кожному стовпці ℓ спільним множником сидить сам локатор Xₗ: перший елемент Xₗ¹, другий Xₗ², … — усе це Xₗ, помножене на Xₗ⁰, Xₗ¹, …, Xₗ^{w−1}. Винесімо цей множник із кожного стовпця. Визначник — полілінійна функція стовпців, тож множник, винесений зі стовпця, виходить перед увесь визначник:

```
det M = (X₁·X₂·…·X_w) · det V
```

де V — те, що лишилося після винесення, з елементом Vⱼₗ = Xₗ^{j−1} (степені в рядках тепер біжать від 0 до w−1):

```
      ⎡  1     1    …    1   ⎤
      ⎢ X₁    X₂    …   X_w  ⎥
V  =  ⎢ X₁²   X₂²   …   X_w² ⎥
      ⎢  ⋮     ⋮         ⋮   ⎥
      ⎣ X₁ʷ⁻¹ X₂ʷ⁻¹ … X_wʷ⁻¹ ⎦
```

Це **матриця Вандермонда** — квадратна таблиця, у якій ℓ-й стовпець складено зі зростаючих степенів одного числа Xₗ, від 0-го до (w−1)-го. Її поява тут не випадкова, а прямий наслідок того, що ми брали степені α **поспіль**: рівняння j = 1, 2, …, w дали рядки зі степенями 1, 2, …, w, а після винесення локаторів — рівний ряд 0, 1, …, w−1. Візьми ми несусідні степені — рядки збилися б у нерівний набір, і жодної Вандермондової структури не вийшло б. Запам'ятаймо це; повернемося наприкінці.

Множник (X₁·X₂·…·X_w) ненульовий одразу — це добуток ненульових локаторів у полі без дільників нуля. Отже, доля всієї системи повністю в руках одного числа: **det V**.

## Визначник Вандермонда: виводимо формулу від кореня

Тут стається маленьке диво лінійної алгебри. Визначник Вандермонда, попри громіздкий вигляд матриці, згортається у стислий добуток усіх попарних різниць вузлів:

```
det V = ∏  (Xⱼ − Xᵢ)       (добуток по всіх парах i < j)
       i<j
```

Виведімо цю формулу самі, не приймаючи на віру. Найпрозоріший шлях — подивитися на визначник як на **многочлен від одного вузла**. Заморозьмо вузли X₁, …, X_{w−1}, а останній зробімо змінною: назвімо його z замість X_w. Тоді det V стає функцією f(z).

Яка вона? Останній стовпець матриці — це (1, z, z², …, z^{w−1})ᵀ, тобто степені z. Розклавши визначник за цим стовпцем, бачимо: f(z) — многочлен від z степеня не вищого за w−1, і коефіцієнт при найвищому z^{w−1} — це визначник верхнього лівого блоку (w−1)×(w−1), тобто Вандермонд менших вузлів X₁, …, X_{w−1}. Тримаймо цей факт.

Тепер — головний хід. Що станеться, якщо покласти z рівним котромусь із заморожених вузлів, скажімо z = Xₖ (k < w)? Тоді останній стовпець матриці збігається зі стовпцем номер k — два однакові стовпці. А визначник з двома однаковими стовпцями дорівнює нулю. Отже,

```
f(X₁) = f(X₂) = … = f(X_{w−1}) = 0
```

Многочлен f(z) степеня w−1 має w−1 різних коренів X₁, …, X_{w−1}. Многочлен степеня w−1 не може мати більше ніж w−1 коренів, а якщо має рівно стільки — він розкладається на ці корені без остачі:

```
f(z) = C · (z − X₁)(z − X₂)…(z − X_{w−1})
```

де C — старший коефіцієнт, тобто коефіцієнт при z^{w−1}. А його ми вже впізнали: це визначник Вандермонда менших вузлів. Ось і рекурсія. Візьмімо її за основу індукції:

```
базовий крок:  w = 1  →  det V = 1        (порожній добуток, коренів нема)
крок індукції: det V(X₁…X_w) = det V(X₁…X_{w−1}) · (X_w − X₁)(X_w − X₂)…(X_w − X_{w−1})
```

Кожен крок домножає накопичене на різниці нового вузла з усіма попередніми. Розкрутивши рекурсію від w=1 угору, збираємо саме всі попарні різниці:

```
det V = ∏  (Xⱼ − Xᵢ)
       i<j
```

Перевірмо на найменших випадках, щоб формула не була абстракцією:

```
w = 2:  det ⎡ 1   1  ⎤ = X₂ − X₁
            ⎣ X₁  X₂ ⎦

w = 3:  det ⎡ 1    1    1  ⎤
            ⎢ X₁   X₂   X₃ ⎥ = (X₂−X₁)(X₃−X₁)(X₃−X₂)
            ⎣ X₁²  X₂²  X₃² ⎦
```

Кожен множник — різниця двох **різних** вузлів. Уся формула — добуток таких різниць. Тримаймо цю думку: ненульовість визначника тепер повністю зведена до ненульовості кожної різниці.

## Чому цей добуток не має права занулитися над GF(2ᵐ)

Ось де скінченне поле відпрацьовує свою роль до останку. Визначник Вандермонда — добуток попарних різниць Xⱼ − Xᵢ. Два спостереження закривають питання остаточно.

**Перше: кожна різниця ненульова.** Локатори Xₗ = α^{iₗ} усі різні — ми забезпечили це на самому початку, бо позиції iₗ різні, а α примітивний. У будь-якому полі з a ≠ b випливає a − b ≠ 0. Тому кожен множник Xⱼ − Xᵢ (де i < j, отже Xᵢ ≠ Xⱼ) ненульовий.

Тут чигає пастка [характеристики 2](book:math/finite-fields), і її треба знешкодити явно. У GF(2ᵐ) віднімання — це те саме, що додавання (бо −1 = 1), а додавання — побітовий XOR. Тож Xⱼ − Xᵢ = Xⱼ + Xᵢ = Xⱼ ⊕ Xᵢ. Чи не могло б це XOR обернутися на нуль навіть для «різних на вигляд» чисел? XOR двох елементів нульовий **лише** коли вони порозрядно однакові, тобто рівні. Але Xᵢ ≠ Xⱼ. Отже Xⱼ ⊕ Xᵢ ≠ 0. Різність локаторів — не косметика, а сама причина, чому характеристика 2 нас не зраджує.

**Друге: добуток ненульових ненульовий.** Це визначальна риса поля (ширше — цілісного кільця): у ньому **немає дільників нуля**. Якщо a ≠ 0 і b ≠ 0, то a·b ≠ 0. Скінченне поле GF(2ᵐ) — повноцінне поле, ця властивість у ньому виконується. Тому добуток попарних різниць, кожна з яких ненульова, ненульовий сам:

```
det V = ∏ (Xⱼ − Xᵢ) ≠ 0
```

![Квадратна система на невідомі коефіцієнти легкого слова має матрицю Вандермонда; її визначник — добуток попарних різниць локаторів, кожна ненульова, бо вузли різні, а поле не має дільників нуля; тому det ≠ 0, розв'язок лише нульовий, і легке слово неможливе](/book/communications/coding-theory/bch-codes/img/bch-bound.svg)
*Серце доказу на одній картинці. Підстановка w різних локаторів у w сусідніх степенів дає квадратну систему з матрицею Вандермонда V. Її визначник згортається в добуток усіх попарних різниць вузлів; кожна різниця ненульова (локатори різні), а поле GF(2ᵐ) не має дільників нуля — тож увесь добуток ненульовий. Ненульовий визначник лишає системі єдиний розв'язок — нульовий, а це суперечить тому, що слово ненульове.*

Подивімося на це в живих числах, аби ненульовість не лишалася словом. Візьмімо поле GF(2⁴) з твірним многочленом x⁴+x+1 (те саме, у якому будують код BCH(15, 7) на дві помилки) і три різні локатори:

```
поле GF(2⁴), твірний x⁴+x+1, α — примітивний (порядок 15)
локатори:  X₁ = α¹,  X₂ = α²,  X₃ = α³

різниці = XOR бітових векторів [α³ α² α¹ α⁰]:
  X₂ − X₁ = α² ⊕ α  = 0100 ⊕ 0010 = 0110 = α⁵     (≠ 0)
  X₃ − X₁ = α³ ⊕ α  = 1000 ⊕ 0010 = 1010 = α⁹     (≠ 0)
  X₃ − X₂ = α³ ⊕ α² = 1000 ⊕ 0100 = 1100 = α⁶     (≠ 0)

визначник Вандермонда:
  det V = (X₂−X₁)(X₃−X₁)(X₃−X₂) = α⁵·α⁹·α⁶ = α²⁰ = α⁵   (≠ 0)

повний визначник системи:
  det M = (X₁·X₂·X₃)·det V = (α¹·α²·α³)·α⁵ = α⁶·α⁵ = α¹¹ (≠ 0)
```

Жодна з різниць не занулилася, добуток теж — рівно як обіцяла теорія. Ненульовий визначник над скінченним полем — не щаслива випадковість конкретних вузлів, а неминучість самої структури.

## Суперечність — і межа впала

Тепер зберімо все докупи. Наша квадратна система

```
M · (c_{i₁}, c_{i₂}, …, c_{i_w})ᵀ = 0
```

однорідна, а її матриця має ненульовий визначник, det M = (∏Xₗ)·det V ≠ 0. Матриця з ненульовим визначником оборотна; однорідна система з оборотною матрицею має **єдиний** розв'язок — нульовий:

```
c_{i₁} = c_{i₂} = … = c_{i_w} = 0
```

Але це рівно ті коефіцієнти, які ми оголосили **ненульовими** — адже вони стоять на ненульових позиціях слова ваги w. Слово водночас мусить бути ненульовим (за припущенням) і нульовим (за висновком). Суперечність.

Отже, вихідне припущення хибне: ненульового кодового слова ваги w ≤ 2t **не існує**. Кожне ненульове кодове слово має вагу щонайменше 2t+1. А оскільки для лінійного коду мінімальна відстань дорівнює мінімальній ненульовій вазі,

```
d ≥ 2t + 1
```

Це і є **межа BCH**. ∎

## Чому саме сусідні — і чому саме 2t

Доказ пройдено, та в ньому сховані дві тонкощі, що пояснюють, чому конструкція BCH влаштована саме так, а не інакше.

**Чому сусідні степені.** Матриця Вандермонда виникла тільки тому, що показники рівнянь j біжали суцільним рядом 1, 2, …, w. Це дало стовпці зі степенями 0, 1, …, w−1 — рівно ті, з яких складається Вандермонд. Візьмімо натомість несусідні корені — скажімо α¹, α³, α⁷. Підстановка дала б рядки зі степенями Xₗ¹, Xₗ³, Xₗ⁷ — «дірчастий» набір показників. Це вже **узагальнена** матриця Вандермонда, і її визначник — не гарний добуток різниць, а незграбний вираз (симетричний многочлен Шура), який над скінченним полем **цілком може** обернутися на нуль. А занулений визначник — це відчинена лазівка: система дозволяє ненульовий розв'язок, тобто легке кодове слово прослизає, і межа руйнується. Сусідність коренів — не оздоба конструкції, а єдине, що робить визначник гарантовано ненульовим. Ось математичний корінь того, чому BCH завжди замовляє степені **поспіль**.

**Чому рівно 2t.** Щоб заборонити ненульове слово ваги w, треба зібрати квадратну систему w×w, а для цього — мати **щонайменше w** рівнянь. Ми хочемо заборонити всі ваги від 1 до 2t включно. Найважчий випадок — найбільша вага w = 2t: під неї потрібно рівно 2t рівнянь. Тому й призначають рівно 2t сусідніх коренів — ні бітом менше. Кожен зайвий корінь понад 2t підняв би гарантовану відстань іще вище (і подеколи так і роблять), але 2t — це той мінімум, що замикає всі ваги до 2t і купує саме d ≥ 2t+1.

## Наскільки далеко сягає той самий доказ

Варто помітити, що жодне місце доказу не спиралося на дрібні особливості нашого налаштування — і тому він накриває набагато ширше коло, ніж двійковий BCH.

**Будь-який стартовий степінь.** Ми брали корені від α¹. Але якби код занулявся у 2t сусідніх степенях, що починаються з довільного α^b — тобто α^b, α^{b+1}, …, α^{b+2t−1}, — винесення локаторів дало б зі стовпця множник Xₗ^b замість Xₗ, теж ненульовий, а всередині лишився б той самий Вандермонд. Доказ проходить дослівно. Тому байдуже, з якого степеня починати смугу коренів; вибір b = 1 (так званий вузькосенсовий BCH) — лише зручна умовність.

**Будь-яке поле, не лише характеристики 2.** Ми ніде не потребували, щоб символи були бітами. Якби коефіцієнти c_{iₗ} жили в цілому полі GF(q), а локатори були різними його елементами, увесь ланцюг — Вандермонд, добуток різниць, відсутність дільників нуля — лишився б чинним. Саме тому та сама межа обслуговує [Рід–Соломон](book:communications/reed-solomon): це той-таки доказ, тільки коефіцієнти беруть цілі символи поля, а не окремі біти. Машинерія коренів і Вандермонда в обох кодах буквально одна.

**Замовлена відстань — це нижня межа, не точна.** Число 2t+1, яке дає теорема, називають **замовленою** (проєктною) відстанню δ = 2t+1. Це гарантований мінімум: справжня мінімальна відстань коду буває й **більшою** за δ, коли структура конкретного коду щасливо додає ваги. Межа BCH ніколи не бреше вниз, але й не завжди тиснеться до справжнього d. Через це існують гостріші нижні межі для циклічних кодів, що враховують не одну, а кілька смуг сусідніх коренів: межа Гартмана–Цена (*Hartmann–Tzeng*) і межа Рооса (*Roos*) узагальнюють щойно доведену — при одній смузі обидві звужуються рівно до межі BCH. Це радше витончення теорії, ніж поправка: для щоденного інженерного розрахунку працює саме δ = 2t+1.

## Де цей визначник працює в коді

Уся ця алгебра сходиться в одну практичну ручку. Довівши d ≥ 2t+1, ми через [геометрію відстані](book:communications/hamming-distance) одразу дістаємо силу коду:

```
t = ⌊(d − 1)/2⌋ ≥ ⌊(2t+1 − 1)/2⌋ = ⌊2t/2⌋ = t
```

Нерівність замикається на рівності: код із 2t сусідніми замовленими коренями виправляє **рівно** t помилок — стільки, скільки замовляли, ані менше. І напрям читається в обидва боки. Хоче інженер код на t помилок — він призначає δ = 2t+1, тобто 2t сусідніх коренів, і теорема ручається, що жодні t перевернутих бітів не зіллються з чужим кодовим словом. Той самий ненульовий визначник Вандермонда, що заборонив легким словам існувати, на приймачі гарантує ще й **однозначність** декодування: два різні взірці не більш ніж t помилок ніколи не дадуть однакового синдрому, бо це знову вимагало б занулити Вандермонд. Так одне число — det V ≠ 0 над GF(2ᵐ) — стоїть і за силою коду при проєктуванні, і за його правом на єдину відповідь при виправленні.
