# 🧮 Алгебра твірного многочлена

Циклічний код — це не просто список дозволених слів: алгебраїчно він **ідеал** у кільці многочленів, і саме з цього одного факту випливає, що весь код задає один-єдиний многочлен g(x), обов'язково дільник xⁿ − 1. Доведімо це до дна — чому генератор один-єдиний, чому він неодмінно ділить xⁿ − 1, скільки звідси виходить перевірних бітів і що робить перевірний многочлен h(x) — і перелічімо всі циклічні коди довжини 7 як добутки множників x⁷ − 1.

### Кільце, у якому живуть слова

Слово завдовжки n — це многочлен степеня, меншого за n, над [GF(2)](book:math/galois-field): біти стають коефіцієнтами, а додавання коефіцієнтів — це XOR (1 ⊕ 1 = 0). Множаться многочлени **за модулем xⁿ − 1**: перемножили як звичайно, а тоді щоразу, коли виринає xⁿ, замінили його на 1. Над GF(2) знак не важить, тож xⁿ − 1 = xⁿ + 1 — писатимемо перше.

Ця множина з двома діями — [кільце многочленів](book:math/polynomial-rings), яке позначають

```
R = GF(2)[x] / (xⁿ − 1)
```

Циклічний зсув слова — це множення його многочлена на x у цьому кільці: степені підскакують на одиницю, а старший член xⁿ⁻¹ переходить у xⁿ = 1, тобто повертається у вільний член. Отже все, що ми знаємо про код, тепер можна перечитати мовою кільця R — і саме там код виявляє свою будову.

### Циклічний код — це ідеал

[Ідеалом](book:math/ideal) кільця R називають підмножину I, яка, по-перше, замкнена щодо додавання (сума двох її елементів знову в ній), а по-друге, **поглинає** множення: якщо a ∈ I, то r·a ∈ I для **будь-якого** r ∈ R. Друга властивість сильніша за просту підгрупу: ідеал стійкий не лише до додавання «своїх», а й до множення на кого завгодно ззовні.

Покажімо, що циклічний код C — це рівно ідеал R.

Код лінійний, тож замкнений щодо додавання — перша властивість є задарма. Він замкнений щодо множення на x (це і означає «циклічний»). А тоді помножити на x двічі — це двічі лишитися в C, отже C замкнений і щодо x², і щодо x³, і щодо будь-якого степеня xⁱ. Візьмімо тепер довільний многочлен r(x) = r₀ + r₁·x + … + rₙ₋₁·xⁿ⁻¹ і кодове слово c(x):

```
r(x)·c(x) = r₀·c(x) + r₁·(x·c(x)) + r₂·(x²·c(x)) + …
```

Кожен доданок праворуч — зсув слова c (множення на степінь x), тобто кодове слово; сума кодових слів — знову кодове слово (лінійність). Отже r(x)·c(x) ∈ C для будь-якого r(x): код поглинає множення на що завгодно. Це і є друга властивість ідеалу.

Назад теж просто: будь-який ідеал замкнений щодо додавання (лінійний) і щодо множення на x (циклічний зсув). Тому

> Циклічні коди довжини n — це рівно ідеали кільця R = GF(2)[x]/(xⁿ − 1). Ні більше, ні менше.

> 🔧 **Навіщо це.** Слово «ідеал» тут — не прикраса. Уся сила циклічного коду в тому, що він поглинає множення на **будь-який** многочлен: саме звідси за мить випливе, що досить одного породжувального слова, а весь код — його кратні. Без поглинання лишився б просто лінійний код без цього важеля.

### Один многочлен породжує весь код

Серед ненульових кодових слів візьмімо те, чий многочлен має **найменший степінь**, і назвімо його g(x). (Над GF(2) старший коефіцієнт ненульового многочлена завжди 1 — жодного вибору нормування немає, g один із себе.) Твердження: код — це рівно всі кратні g(x).

Візьмімо будь-яке кодове слово c(x) і поділімо його на g(x) з остачею у звичайному кільці многочленів:

```
c(x) = q(x)·g(x) + r(x),     r(x) = 0   або   deg r < deg g
```

Добуток q(x)·g(x) — це g, помножений на многочлен, а множення код витримує (він ідеал), тож q·g ∈ C; його степінь дорівнює степеню c, отже менший за n — жодного зведення за модулем не відбувається, це чесне кодове слово. Тоді й остача

```
r(x) = c(x) − q(x)·g(x)
```

належить коду (сума двох кодових слів). Але deg r < deg g, а g — ненульове слово найменшого степеня. Ненульова остача була б кодовим словом, коротшим за g, — суперечність. Значить r = 0, і

```
c(x) = q(x)·g(x)
```

— кожне кодове слово кратне g. Навпаки, будь-яке кратне m(x)·g(x) степеня, меншого за n, лежить у коді (ідеал поглинає множення). Отже

```
C = { m(x)·g(x) : deg m < n − deg g }
```

Один короткий многочлен — **твірний** (англ. *generator* — той, що породжує) — задає весь код.

**Генератор єдиний.** Хай g і g′ — два ненульові кодові слова найменшого степеня; тоді deg g = deg g′. Їхня сума g + g′ теж у коді, а старші члени (обидва xᵈᵉᵍ ᵍ) над GF(2) знищуються (1 ⊕ 1 = 0), тож deg(g + g′) < deg g. Ненульова сума була б коротшим кодовим словом — не можна. Значить g + g′ = 0, тобто g = g′: генератор один.

### Чому g(x) неодмінно ділить xⁿ − 1

Тут — серце всієї побудови. Поділімо сам xⁿ − 1 на g(x) з остачею:

```
xⁿ − 1 = q(x)·g(x) + r(x),     r = 0   або   deg r < deg g
```

Зведімо цю рівність за модулем xⁿ − 1. Ліворуч xⁿ − 1 ≡ 0. Праворуч q·g — кратне g, тобто кодове слово, і воно за модулем нікуди не дівається. Лишається

```
r(x) ≡ q(x)·g(x)     (mod xⁿ − 1)
```

Отже r(x) — кодове слово. Але deg r < deg g < n, тож r за модулем — це саме воно, без зведення: ненульова остача була б кодовим словом, коротшим за g. Знову суперечність із мінімальністю g. Значить r = 0, і

```
xⁿ − 1 = q(x)·g(x)      →      g(x) ділить xⁿ − 1
```

Це перевертає проєктування коду. Твірним не може бути абищо: щоб дістати циклічний код довжини n, беруть xⁿ − 1, розкладають його на множники над GF(2) і за g(x) беруть добуток частини з них. А частка q(x) = (xⁿ − 1)/g(x) при цьому теж не випадкова — за мить вона стане перевірним многочленом.

### Скільки перевірних бітів: n − k = deg g

Позначмо deg g = n − k. Яка розмірність коду — скільки в ньому незалежних слів? Випишімо k слів:

```
g(x),   x·g(x),   x²·g(x),   …,   xᵏ⁻¹·g(x)
```

Їхні степені — deg g, deg g + 1, …, deg g + k − 1 = n − 1: усі різні й усі менші за n, тож це чесні кодові слова (жодне не «перекручується» за модулем). Різні степені означають лінійну незалежність: у будь-якій ненульовій XOR-комбінації вціліє найстарший з обраних членів, і вона не нуль. А натягують вони весь код — адже кожне кодове слово це m(x)·g(x) з deg m < k, тобто якраз комбінація цих k зсувів.

Отже код має рівно k незалежних слів: це [лінійний код](book:communications/linear-block-codes) розмірності k, себто [n, k]. Число даних-бітів k = n − deg g, а перевірних —

```
n − k = deg g
```

рівно стільки, скільки степінь генератора. Ці k зсувів, викладені рядками, і є твірна матриця — сходинка з бітів g(x), що з'їжджає вправо-вниз:

![Твірна матриця [7,4]-коду: чотири рядки — це g=1101 і його зсуви xg, x²g, x³g, кожен на біт правіше; провідні одиниці утворюють сходинку по діагоналі, а блок g завширшки deg g+1=4 уміщається в семи стовпцях рівно k=4 рази](/book/communications/coding-theory/cyclic-codes/img/staircase-basis.svg)
*k = 4 зсуви g(x) = x³+x+1 (біти 1101) складають твірну матрицю [7, 4]-коду. Блок g завширшки deg g + 1 = 4 з'їжджає вниз-вправо і вміщається в n = 7 стовпцях рівно k = n − deg g = 4 рази — стільки незалежних рядків, стільки й розмірність; перевірних бітів лишається n − k = deg g = 3.*

### Перевірний многочлен h(x)

Оскільки g ділить xⁿ − 1, частка

```
h(x) = (xⁿ − 1) / g(x),      deg h = n − deg g = k
```

— многочлен степеня k, і саме він перевіряє слова. Твердження: слово c(x) (степеня, меншого за n) належить коду тоді й лише тоді, коли

```
c(x)·h(x) ≡ 0      (mod xⁿ − 1)
```

**Уперед.** Якщо c = m·g — кодове слово, то c·h = m·g·h = m·(xⁿ − 1) ≡ 0. Кодове слово h обнуляє.

**Назад.** Хай c·h ≡ 0, тобто xⁿ − 1 ділить c·h. Але xⁿ − 1 = g·h, тож c·h = s·g·h для якогось s, звідки (c − s·g)·h = 0. У кільці многочленів над полем немає дільників нуля, а h ≠ 0 — отже c − s·g = 0, тобто c = s·g кратне g. Слово, що його h обнуляє, неодмінно кодове.

Ось і вся симетрія: **g(x) будує** (кодові слова — його кратні), **h(x) перевіряє** (кодові слова — рівно ті, кого h обнуляє за модулем xⁿ − 1). Множення на h за модулем xⁿ − 1 — алгебраїчний двійник множення на перевірну матрицю H: обидва дають нуль саме на кодових словах. Число перевірних бітів видно й звідси — deg g = n − deg h = n − k.

### Усі циклічні коди довжини 7

Зберімо все на конкретному n = 7. Спершу розкладімо x⁷ − 1 над GF(2). Корінь x = 1 є (1 ⊕ 1 = 0), тож (x + 1) — множник; частка ділиться далі на два кубічні многочлени:

```
x⁷ − 1 = (x + 1)·(x³ + x + 1)·(x³ + x² + 1)      (над GF(2))
```

Обидва кубічні незвідні: жоден не має кореня в GF(2) (підставте 0 і 1 — щоразу виходить 1), а кубічний многочлен без кореня на множники не розкладається. Перевірмо добуток двох кубічних — він має відтворити частку (x⁷ − 1)/(x + 1):

**Множимо (x³ + x + 1)·(x³ + x² + 1) над GF(2):**
```
  x³·(x³ + x² + 1) = x⁶ + x⁵ + x³
  x ·(x³ + x² + 1) = x⁴ + x³ + x
  1 ·(x³ + x² + 1) = x³ + x² + 1
  ──────────────────────────────────  (XOR по стовпцях; x³ тричі → x³)
  = x⁶ + x⁵ + x⁴ + x³ + x² + x + 1
```
рівно (x⁷ − 1)/(x + 1) ✓

Отже x⁷ − 1 має **три** незвідні множники. Кожен циклічний код довжини 7 — це вибір твірного g як добутку якоїсь їх частини, а з трьох множників вибрати можна 2³ = 8 способами. Кожен вибір дає свій код зі своїм deg g = n − k:

```
множники в g              g(x)                       [n, k, d]     код
──────────────────────────────────────────────────────────────────────────────
— (порожньо)              1                          [7, 7, 1]     увесь простір
x+1                       x+1                        [7, 6, 2]     парність
x³+x+1                    x³+x+1                     [7, 4, 3]     Геммінга
x³+x²+1                   x³+x²+1                    [7, 4, 3]     Геммінга (дзерк.)
(x+1)(x³+x+1)             x⁴+x³+x²+1                 [7, 3, 4]     симплексний
(x+1)(x³+x²+1)            x⁴+x²+x+1                  [7, 3, 4]     симплексний (дзерк.)
(x³+x+1)(x³+x²+1)         x⁶+x⁵+x⁴+x³+x²+x+1         [7, 1, 7]     повторення
(x+1)(x³+x+1)(x³+x²+1)    x⁷−1 ≡ 0                   [7, 0, —]     лише нульове слово
```

Крайні випадки промовисті. Порожній добуток g = 1 ділить будь-що — кодом є **увесь** простір із 2⁷ слів (перевіряти нічого, k = 7). Обидва кубічні разом дають g = x⁶ + x⁵ + … + 1 — це слово 1111111, і його єдине ненульове кратне степеня, меншого за 7, — воно саме: код **повторення** {0000000, 1111111}. А всі три множники дають g = x⁷ − 1 ≡ 0 — лишається тільки нульове слово.

Посередині — знайомі коди. Множник x + 1 сам: його кратні — слова з c(1) = 0, тобто **парної ваги**, [7, 6] з одним перевірним бітом. Кожен із двох кубічних окремо дає [7, 4]-код [Геммінга](book:communications/hamming-code) (той із них, де g = x³ + x + 1, — канонічний). А добуток x + 1 на кубічний — це [7, 3]-**симплексний** код, у якому всі сім ненульових слів мають вагу рівно 4; він дуальний до одного з кодів Геммінга.

![Булева ґратка з восьми вузлів: усі дільники x⁷−1 як підмножини трьох множників, згори (g=1, увесь простір [7,7]) донизу (g=x⁷−1, лише нуль); ребро додає до g один множник і веде до підкоду; вузли підписані g(x) і [n,k,d]: парність, два Геммінга, два симплексні, повторення](/book/communications/coding-theory/cyclic-codes/img/divisor-lattice.svg)
*Вісім дільників x⁷ − 1 — вісім циклічних кодів довжини 7. Кожне ребро додає до g один множник: код звужується до підкоду, deg g росте, k падає. Згори вниз — від усього простору [7, 7] до самого нуля [7, 0]; посередині — парність, два коди Геммінга, два симплексні й повторення.*

Одна дія — які множники xⁿ − 1 покласти в g(x) — задає геть усе: довжину перевірної частини (deg g), розмірність (k = n − deg g) і силу коду. Що більше множників у g, то вужчий код і то більша відстань між його словами: від беззахисного [7, 7] угорі ґратки до семиразового повторення внизу.
