# 🧮 Розрахунок часового бюджету та стійкості до джиттеру при передискретизації

В асинхронному інтерфейсі зв'язку приймач і передавач працюють від незалежних генераторів тактової частоти. Оскільки спільний тактовий провідник відсутній, приймач змушений відновлювати фазу кожного кадру виключно за спадним фронтом стартового біта, а далі відлічувати часові інтервали за власним локальним таймером. Якщо частоти двох пристроїв різняться, накопичений фазовий зсув на кожному наступному біті лінійно зростає. Математичний розрахунок часового бюджету дозволяє точно визначити гранично допустиму похибку генераторів, вплив дискретності вибірок і фазового тремтіння (джиттеру, від англ. *jitter* — тремтіння, коливання) на надійність декодування кадру.

Без такого аналізу неможливо обґрунтовано обрати між коефіцієнтами передискретизації 16× та 8× або розрахувати допустиму довжину кабельної лінії та параметри опторозв'язки.

### Математична модель часового інтервалу кадру

Позначимо номінальну бітову швидкість передачі через `f_baud`, а тривалість одного бітового інтервалу передавача як `T_tx = 1 / f_baud_tx`. Приймач налаштовано на номінальну тривалість біта `T_rx = 1 / f_baud_rx`. Стандартний асинхронний кадр 8N1 складається з 10 послідовних бітів:
1. Стартовий біт (індекс `k = 0`, рівень логічного нуля '0').
2. Вісім інформаційних бітів (індекси `k = 1, 2, ..., 8`, молодший біт D0 передається першим).
3. Стоповий біт (індекс `k = 9`, рівень логічної одиниці '1').

Передавач утримує стан `k`-го біта на часовому відрізку:

```
t ∈ [k · T_tx, (k + 1) · T_tx]
```

Ідеальний геометричний центр `k`-го біта на стороні передавача розташований у точці часу:

```
t_center(k) = (k + 0.5) · T_tx
```

Приймач фіксує початок кадру за спадом сигналу на лінії RX і починає внутрішній відлік часу. За коефіцієнта передискретизації `N` (де `N = 16` або `N = 8`) приймач квантує часовий інтервал на субтакти тривалістю `t_sub = T_rx / N`.

Центральне вікно стробування інформаційного значення формується трьома послідовними вибірками навколо середини бітового інтервалу:
- Для режиму `16×`: вибірки `S7`, `S8`, `S9` на субтактах із номерами 7, 8 та 9 (при індексації від 0 до 15).
- Для режиму `8×`: вибірки `S3`, `S4`, `S5` на субтактах із номерами 3, 4 та 5 (при індексації від 0 до 7).

Середня точка стробування для `k`-го біта за внутрішнім годинником приймача розраховується як:

```
t_sample(k) = t_sync + (k + 0.5) · T_rx
```

де `t_sync` — фактичний момент часу, в який приймач зафіксував спадний фронт та скинув свій субтактовий лічильник у нуль.

### Складові похибки часового бюджету

Щоб апаратний мажоритарний селектор безпомилково прочитав переданий біт, усі три центральні вибірки `S_first`, `S_mid`, `S_last` мають потрапити всередину дійсного фізичного інтервалу передавача `[k · T_tx, (k + 1) · T_tx]`, не перетинаючи межі зміни сусідніх бітів.

На часову позицію вибірок впливають п'ять незалежних фізичних факторів:

1. **Дискретність синхронізації фронту (похибка квантування `Δt_quant`)**: спадний фронт старт-біта є неперервною аналоговою подією і може прийти в довільний момент між тактами генератора передискретизації. Оскільки лічильник скидається лише на наступному активному фронті субтакту, початкова затримка синхронізації лежить у діапазоні:

```
0 ≤ Δt_quant ≤ T_rx / N
```

Середнє значення зміщення становить `T_rx / (2 · N)`, а максимальна невизначеність відносно ідеального центру дорівнює `± T_rx / (2 · N)`. Для режиму `16×` це дає `±3.125%` від тривалості біта, а для режиму `8×` — `±6.25%`.

2. **Напівширина вікна мажоритарного голосування (`Δt_vote`)**: для ухвалення рішення за трьома точками крайні вибірки віддалені від центру на один субтакт `t_sub`:

```
Δt_vote = T_rx / N
```

Для режиму `16×` напівширина становить `1 / 16 = 6.25%` біта (повна ширина вікна `S7..S9` дорівнює `2 / 16 = 12.5%`). Для режиму `8×` напівширина становить `1 / 8 = 12.5%` біта (повна ширина вікна `S3..S5` дорівнює `2 / 8 = 25%`).

3. **Асиметрія фронтів лінії та затримка розповсюдження (`Δt_asym`)**: через паразитну ємність кабелю, вихідний опір трансивера або різний час увімкнення та вимкнення оптопар час наростання `t_rise` (перехід `0 → 1`) часто значно перевищує час спаду `t_fall` (перехід `1 → 0`). Різниця затримок розповсюдження зміщує фізичну тривалість імпульсів:

```
Δt_asym = |t_prop_LH − t_prop_HL|
```

У типових оптоізольованих лініях промислових інтерфейсів `Δt_asym` може сягати від 5% до 15% тривалості біта на швидкості 115200 бод.

4. **Випадковий фазовий джиттер (`Δt_jit`)**: фазовий шум генераторів, перехресні наведення (*crosstalk*) у багатожильних кабелях та флуктуації порогів спрацьовування вхідних тригерів Шмітта створюють випадкове тремтіння фронтів, що підпорядковується нормальному розподілу Гауса з середньоквадратичним відхиленням `σ_jit`. Для забезпечення ймовірності помилки менше `10⁻⁹` беруть піковий розмах джиттеру `6 · σ_jit`, який у реальних системах займає від 2% до 5% тривалості біта.

5. **Накопичений дрейф частоти годинника (`Δt_drift`)**: відносна похибка швидкостей генераторів визначається як:

```
δ_f = (f_baud_tx − f_baud_rx) / f_baud_rx
```

На `k`-му бітовому інтервалі різниця частот викликає зміщення точки відліку, що лінійно зростає з часом:

```
Δt_drift(k) = (k + 0.5) · T_tx · |δ_f|
```

Найбільшого значення зсув досягає на останньому біті кадру — стоповому біті при `k = 9` (для кадру 8N1), де часове плече становить `9.5 · T_tx`.

### Вплив дробових дільників швидкості та фазового тремтіння

У сучасних мікроконтролерах тактова частота периферійної шини `f_PCLK` рідко ділиться на бажану швидкість `N · f_baud` без залишку. Для зменшення систематичної похибки швидкості апаратура використовує **дробові дільники** (*fractional baud rate generators*).

Дробовий дільник представляє коефіцієнт ділення як суму цілої частини `DIV_Mantissa` та дробової частини `DIV_Fraction / 2^M` (де `M = 4` для 16-рівневого квантування у STM32). Апаратна реалізація здійснює дізерінг (*dithering*, чергування): на кожні 16 бітових інтервалів дільник генерує частину циклів із коефіцієнтом `DIV_Mantissa`, а частину — з `DIV_Mantissa + 1`.

Математично це призводить до виникнення періодичного фазового стрибка:

```
Δt_frac_max = (1 / f_PCLK) · (1 − DIV_Fraction / 16)
```

Цей додатковий фазовий зсув додається до загальної похибки квантування `Δt_quant`, збільшуючи невизначеність положення вибірки ще на 1–2% від тривалості біта.

### Температурний дрейф кварцових і RC-генераторів

Реальна стабільність частоти генераторів суттєво залежить від їхньої фізичної природи та робочої температури навколишнього середовища:

1. **Кварцові резонатори з AT-зрізом**: температурна характеристика описується кубічною або параболічною залежністю:

```
Δf / f = a · (T − T_0)²
```

де `T_0 ≈ 25 °C`, а коефіцієнт кривизни становить `a ≈ −0.04 ppm/°C²`. У промисловому діапазоні від −40 °C до +85 °C сумарне температурне відхилення кварцу не перевищує `±30..50 ppm` (`±0.005%`), що є абсолютно незначним на фоні допусків UART.

2. **Внутрішні інтегровані RC-генератори (HSI/LSI)**: кремнієві резистивно-ємнісні генератори мають виражену температурну нестабільність, яка сягає `±1.0..2.0%` у повному робочому діапазоні температур, а також чутливі до коливань напруги живлення. За кімнатної температури похибка некаліброваного RC становить близько 0.3–0.5%, проте при нагріванні мікросхеми до +70 °C похибка частоти зростає до 1.5–1.8%, що впритул наближається до критичної межі збою в режимі 8×.

### Критерій безпомилкового прийому кадру

Гранична умова правильного розпізнавання біта полягає в тому, що сумарне відхилення крайньої вибірки мажоритарного вікна від центру біта передавача не повинно перевищувати половини тривалості фізичного біта `0.5 · T_tx`.

Складемо баланс часового бюджету для найбільш критичної точки кадру — стопового біта (`k = 9.5`):

```
Δt_quant_max + Δt_vote + Δt_asym + Δt_jit + Δt_drift(9.5) ≤ 0.5 · T_tx
```

Підставимо аналітичні вирази для кожної складової, нормовані до тривалості біта `T_bit ≈ T_tx ≈ T_rx`:

```
(1 / (2 · N)) + (1 / N) + (Δt_asym / T_bit) + (Δt_jit / T_bit) + 9.5 · |δ_f| ≤ 0.5
```

Об'єднаємо члени, що залежать від коефіцієнта передискретизації `N`:

```
(3 / (2 · N)) + (Δt_asym / T_bit) + (Δt_jit / T_bit) + 9.5 · |δ_f| ≤ 0.5
```

Виразимо гранично допустиму розбіжність тактових частот `|δ_f|_max`:

```
|δ_f|_max = (0.5 − 1.5 / N − (Δt_asym / T_bit) − (Δt_jit / T_bit)) / 9.5
```

### Порівняльний розрахунок для режимів 16× та 8×

Розглянемо випадок ідеальної фізичної лінії без асиметрії фронтів та фазового шуму (`Δt_asym = 0`, `Δt_jit = 0`) та визначимо теоретичний максимум стійкості до розсинхрону частот для обох режимів.

**Розрахунок для режиму 16× (ідеальні умови):**

```
|δ_f|_max_16x
= (0.5 − 1.5 / 16) / 9.5                 [підстановка N = 16]
= (0.5 − 0.09375) / 9.5                  [обчислення втрат на квантування та вікно]
= 0.40625 / 9.5                          [чистий часовий запас на дрейф]
≈ 0.04276                                [граничне значення: 4.28%]
```

У режимі 16× асинхронний приймач здатний витримати сумарну похибку частоти до **4.28%** за ідеального сигналу.

**Розрахунок для режиму 8× (ідеальні умови):**

```
|δ_f|_max_8x
= (0.5 − 1.5 / 8) / 9.5                  [підстановка N = 8]
= (0.5 − 0.1875) / 9.5                   [обчислення втрат на квантування та вікно]
= 0.3125 / 9.5                           [чистий часовий запас на дрейф]
≈ 0.03289                                [граничне значення: 3.29%]
```

У режимі 8× стійкість до розбіжності частот падає до **3.29%**, тобто часовий запас скорочується на 23% через ширше вікно дискретизації та грубішу початкову прив'язку.

### Вплив асиметрії фронтів реального каналу зв'язку

У реальних лініях передачі з оптронами (наприклад, PC817 або 6N137) затримка вимкнення світлодіода створює асиметрію фронтів, яка типово становить `Δt_asym / T_bit = 0.10` (10% тривалості біта). Додатковий випадковий високочастотний джиттер від імпульсних перетворювачів напруги забирає ще близько `Δt_jit / T_bit = 0.04` (4%). Одиночний викид завади тривалістю всього 20 нс може деформувати крутизну фронту.

Порахуймо реальний допустимий бюджет частоти за наявності спотворень каналу:

```
Залишковий запас = 0.5 − 1.5 / N − 0.10 − 0.04
```

**Реальний бюджет для режиму 16×:**

```
|δ_f|_real_16x
= (0.5 − 0.09375 − 0.10 − 0.04) / 9.5    [віднімання асиметрії та джиттеру]
= 0.26625 / 9.5                          [залишок на дрейф годинників]
≈ 0.02802                                [граничне значення: 2.80%]
```

Кожна сторона зв'язку (передавач і приймач) може мати похибку частоти не більше `±1.40%`. Це значення цілком досяжне для якісних керамічних резонаторів або каліброваних внутрішніх RC-генераторів мікроконтролерів.

**Реальний бюджет для режиму 8×:**

```
|δ_f|_real_8x
= (0.5 − 0.1875 − 0.10 − 0.04) / 9.5     [віднімання асиметрії та джиттеру]
= 0.1725 / 9.5                           [залишок на дрейф годинників]
≈ 0.01816                                [граничне значення: 1.82%]
```

У режимі 8× за наявності тих самих фізичних завад допустима похибка кожної зі сторін знижується до **±0.91%**. Дешевий внутрішній RC-генератор з температурним дрейфом ±1.5% у таких умовах гарантовано спричинить помилки кадру (*framing error*), і для надійної роботи стає обов'язковим використання кварцового резонатора.

### Вплив одноточкової вибірки (Single Sample Mode)

Деякі контролери (зокрема сімейство STM32 через біт `ONEBIT` у регістрі `USART_CR3`) дозволяють вимкнути 3-вибіркове мажоритарне голосування та фіксувати значення біта за єдиним центральним субтактом (такт 8 при 16× або такт 4 при 8×).

У цьому випадку напівширина вікна вибірки `Δt_vote` стає рівною нулю, що змінює рівняння балансу:

```
(1 / (2 · N)) + (Δt_asym / T_bit) + (Δt_jit / T_bit) + 9.5 · |δ_f| ≤ 0.5
```

**Теоретичний запас для режиму 8× з одноточковою вибіркою (ідеальні умови):**

```
|δ_f|_single_8x
= (0.5 − 1 / 16) / 9.5                   [N = 8, похибка синхронізації 1/16 біта]
= (0.5 − 0.0625) / 9.5                   [вибірка строго в одній точці]
= 0.4375 / 9.5                           [чистий запас]
≈ 0.04605                                [граничне значення: 4.61%]
```

Одноточкова вибірка повертає часовий запас стійкості до розбіжності швидкостей, але робить приймач абсолютно беззахисним перед одиночними імпульсними завадами на лінії: короткий сплеск шуму тривалістю всього 20 нс, що збігся з моментом вибірки, інвертує біт даних без можливості мажоритарного відновлення.

### Розрахунок для кадру розширеного формату (8E1 та 8N2)

Якщо формат кадру містить додатковий біт парності (8E1 / 8O1, загалом 11 бітів) або два стопових біти (8N2, 11 бітів), плече накопичення фазової похибки для фінального стопового біта зростає з `9.5 · T_tx` до `10.5 · T_tx`.

**Розрахунок для 11-бітового кадру в режимі 16× (ідеальні умови):**

```
|δ_f|_11bit_16x
= (0.5 − 1.5 / 16) / 10.5                [підстановка плеча 10.5 біта]
= 0.40625 / 10.5                         [обчислення запасу]
≈ 0.03869                                [граничне значення: 3.87%]
```

Збільшення довжини кадру на один біт зменшує допустимий розсинхрон частот з 4.28% до **3.87%**.

### Ймовірнісний аналіз завадостійкості мажоритарного селектора

Розглянемо статистичну перевагу мажоритарного голосування 2 з 3 над одноточковим опитуванням в умовах адитивного білого гаусового шуму (AWGN). Позначимо ймовірність помилки одиночної вибірки напруги як `p`. Помилка виникає, коли амплітуда шуму перевищує поріг логічного перемикання.

При одноточковій вибірці ймовірність спотворення біта дорівнює:

```
P_err_single = p
```

При мажоритарному голосуванні біт спотворюється лише тоді, коли щонайменше дві вибірки з трьох виявляються помилковими:

```
P_err_majority
= 3 · p² · (1 − p) + p³                  [ймовірність 2 помилок з 3 плюс 3 помилки з 3]
= 3 · p² − 2 · p³                        [алгебраїчне спрощення]
```

Для типових промислових каналів зв'язку ймовірність поодинокого шумового викиду невелика, наприклад `p = 10⁻³` (один зашумлений субтакт на 1000). Підставимо це значення у вираз:

```
P_err_majority
= 3 · (10⁻³)² − 2 · (10⁻³)³              [підстановка p = 0.001]
= 3 · 10⁻⁶ − 2 · 10⁻⁹                    [обчислення степенів]
≈ 3 · 10⁻⁶                               [результат]
```

Мажоритарне голосування зменшує частоту помилок бітів майже на три порядки (із `10⁻³` до `3 · 10⁻⁶`). Це забезпечує енергетичний виграш завадостійкості, еквівалентний покращенню відношення сигнал/шум (SNR) на 1.5–2.0 дБ без будь-яких апаратних змін у фізичній лінії.

### Розрахунок граничної довжини кабелю та постійної часу RC

Погонна ємність витої пари становить близько `C_spec = 50 пФ/м`. За вихідного динамічного опору передавача `R_out = 50 Ом` та термінального навантаження час наростання фронту напруги через кабель довжиною `L` метрів наближено описується рівнянням заряду ємності:

```
t_rise = 2.2 · R_out · C_spec · L
```

Щоб фронт сигналу не залазив у вікно мажоритарних вибірок, час наростання не повинен перевищувати тривалості безпечної зони біта:

```
t_rise ≤ (6 / N) · T_bit
```

Звідси отримуємо граничну довжину кабельної лінії для заданої швидкості `f_baud` та коефіцієнта передискретизації `N`:

```
L_max = (6 / N) / (2.2 · R_out · C_spec · f_baud)
```

**Приклад розрахунку для швидкості 1 Мбод у режимі 16×:**

```
L_max_16x
= (6 / 16) / (2.2 · 50 · 50 · 10⁻¹² · 10⁶) [підстановка параметрів]
= 0.375 / (5.5 · 10⁻³)                    [обчислення знаменника]
≈ 68.2 метра                              [гранична довжина кабелю]
```

Для режиму 8× безпечний інтервал становить `(2 / 8) · T_bit = 0.25 · T_bit`, що скорочує максимальну довжину лінії до **45.5 метра** за тієї самої швидкості.

### Око-діаграма та розкриття часового вікна

В аналоговому аналізі сигналів надійність прийому оцінюють за допомогою **око-діаграми** (*eye diagram*). Око-діаграма будується накладанням усіх можливих бітових переходів (`0 → 1`, `1 → 0`, `0 → 0`, `1 → 1`) на єдиному часовому відрізку тривалістю `T_bit`.

Горизонтальне розкриття ока визначає часовий інтервал, протягом якого напруга в лінії гарантовано перевищує рівні логічної одиниці `V_IH` або не досягає рівня логічного нуля `V_IL`:

```
T_eye_horizontal = T_bit − t_rise − t_fall − 2 · t_jitter
```

Мажоритарне вікно 3 вибірок вимагає, щоб повне розкриття ока `T_eye_horizontal` було більшим за ширину вікна стробування `W_vote = 2 · T_bit / N` з урахуванням накопиченого дрейфу `Δt_drift(9.5)`:

```
T_eye_horizontal ≥ (2 / N) · T_bit + 2 · Δt_drift(9.5)
```

Якщо внаслідок надмірної ємності кабелю час наростання сигналу `t_rise` перевищує `4 / N · T_bit`, око-діаграма закривається, і крайні вибірки мажоритарного селектора потрапляють у зону невизначеності, викликаючи постійні спрацьовування прапорця шуму `NF` та збої зв'язку.
