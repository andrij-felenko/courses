# 🧮 Математика розмазування секунди: лінійні та тригонометричні профілі частоти

Математична модель розмазування високосної секунди (англ. *leap smearing* або *leap slewing*) розв'язує фундаментальну задачу оптимального керування: як трансформувати дискретний розрив шкали цивільного часу величиною `1.0 с` у плавний, строго неперервний процес зміни частоти генератора, що зберігає монотонність часових міток і не збуджує перехідних коливань у контурах фазового автопідстроювання частоти (PLL).

Ця вставка містить строге аналітичне виведення рівнянь динаміки фази, порівняльний аналіз прямокутних, тригонометричних та поліноміальних вікон корекції частоти, спектральний аналіз впливу розмазування на стабільність генераторів, розрахунок дисперсії Аллана, аналіз похибок часової дискретизації, а також оцінку граничних часових похибок.

---

### Математична постановка задачі керування фазою генератора

Розглянемо математичну модель тактового генератора системи синхронізації. Ідеальний гармонічний сигнал із номінальною частотою `f₀` описується фазовою функцією:

```
θ_ideal(t) = 2π · f₀ · t      [фаза ідеального тактового сигналу]
```

Реальний сигнал фізичного кварцового або атомного генератора містить збурення фази `φ(t)`:

```
θ_real(t) = 2π · f₀ · t + φ(t)      [фаза реального сигналу зі збуренням]
```

Миттєва частота коливань генератора `f(t)` визначається як перша похідна повної фази за часом:

```
f(t) = (1 / 2π) · (dθ_real / dt) = f₀ + (1 / 2π) · (dφ / dt)
```

Нормоване відносне відхилення частоти `y(t)` є безрозмірною величиною, що характеризує швидкість дрейфу фази відносно номінальної шкали:

```
y(t) = (f(t) − f₀) / f₀ = (1 / (2π · f₀)) · (dφ / dt)      [відносне відхилення частоти]
```

Накопичений фазовий зсув часу `Φ(t)` (вимірюється в секундах) на довільному інтервалі часу `[t_start, t]` дорівнює визначеному інтегралу від функції відносного відхилення частоти:

```
Φ(t) = ∫[t_start...t] y(τ) dτ      [інтегральний зв'язок накопиченої фази та частоти]
```

#### Крайові умови задачі розмазування:
Нехай задано часове вікно розмазування тривалістю `T = t_end - t_start`. Необхідно синтезувати таку функцію керування частотою `y(t)`, яка забезпечує заданий сумарний фазовий зсув `ΔΦ` (де `ΔΦ = +1.0 с` для додатної високосної секунди або `ΔΦ = -1.0 с` для від'ємної) за таких крайових обмежень:

```
1. Початковий стан фази:       Φ(t_start) = 0.0 с
2. Кінцевий стан фази:         Φ(t_end)   = −ΔΦ
3. Неперервність частоти:      y(t_start) = 0,  y(t_end) = 0
4. Неперервність прискорення:  dy/dt(t_start) = 0,  dy/dt(t_end) = 0
```

Від'ємний знак кінцевої фази `Φ(t_end) = -ΔΦ = -1.0 с` означає штучне уповільнення генератора, завдяки чому наприкінці доби системний годинник відстає від нерозривної фізичної шкали TAI рівно на одну секунду, що повністю компенсує додаткову секунду цивільного часу UTC без здійснення дискретного стрибка.

### Лінійний профіль зміщення частоти (Linear Slew)

Найпростішим розв'язком є використання прямокутного вікна частоти (Boxcar window), за якого відхилення частоти підтримується постійним протягом усього вікна розмазування: `y_lin(t') = y₀ = const` для нормованого часу `t' = t - t_start ∈ [0, T]`.

Інтегруємо функцію фази на повному інтервалі:

```
Φ_lin(T) = ∫[0...T] y₀ dt = y₀ · T = −ΔΦ      [інтеграл постійної частоти]
```

Звідси константа відносного відхилення частоти дорівнює:

```
y₀ = − ΔΦ / T      [визначення константи лінійного зміщення]
```

Для стандартного 24-годинного інтервалу (`T = 86 400 с`, `ΔΦ = 1.0 с`):

```
y₀ = − 1.0 / 86400 ≈ −1.1574074 · 10⁻⁵ = −11.57407 ppm
```

Функція накопиченої фазової похибки зростає лінійно:

```
Φ_lin(t') = − (t' / T) · ΔΦ = − (t' / 86400)      [лінійна функція фази]
```

#### Спектральний аналіз та обмеження лінійного режиму:
Головним недоліком лінійного розмазування є розрив функції частоти `y_lin(t)` на межах інтервалу. Стрибкоподібна зміна частоти на `11.57 ppm` у моменти `t' = 0` та `t' = T` відповідає нескінченній похідній `dy/dt` (імпульс Дірака `δ(t)`).

У частотній області спектральна густина потужності прямокутного імпульсу частоти спадає пропорційно `1 / ω`:

```
S_lin(ω) ∝ sinc(ω · T / 2) ∝ 1 / ω      [повільне спадання високочастотних гармонік]
```

Таке повільне спадання спектра збуджує перехідні процеси у фазових детекторах систем автопідстроювання частоти (PLL), спричиняючи викиди фазової похибки (ringing/overshoot) у вузькосмугових телекомунікаційних генераторах.

### Гладкий піднесений косинусний профіль (Raised Cosine Slew)

Для усунення спектральних розривів та забезпечення неперервності першої похідної частоти Google розробив косинусний профіль розмазування (Raised Cosine / Hann Window).

Задамо функцію відхилення частоти у гармонічному вигляді:

```
y_cos(t') = A · (1 − cos(2π · t' / T))      [загальний вигляд косинусного вікна]
```

де `A` — шукана амплітуда корекції частоти.

Обчислимо інтеграл фазового зміщення для довільного проміжного моменту часу `t' ∈ [0, T]`:

```
Φ_cos(t') = ∫[0...t'] y_cos(τ) dτ                                    [інтеграл відхилення частоти]
          = A · ∫[0...t'] (1 − cos(2π · τ / T)) dτ                    [підстановка косинусного профілю]
          = A · [ τ − (T / (2π)) · sin(2π · τ / T) ]₀ᵗ'               [інтегрування базових функцій]
          = A · ( t' − (T / (2π)) · sin(2π · t' / T) )                [підстановка меж інтегрування]
```

Підставимо граничну умову повного зміщення в кінцевій точці `t' = T`:

```
Φ_cos(T) = A · ( T − (T / (2π)) · sin(2π) )    [підстановка t' = T]
         = A · ( T − 0 )                        [періодичність тригонометричної функції: sin(2π) = 0]
         = A · T                                [спрощення виразу]
```

Оскільки за початковою умовою `Φ_cos(T) = -ΔΦ = -1.0 с`, знаходимо амплітудний коефіцієнт `A`:

```
A · T = −ΔΦ          [рівняння балансу фази]
A = − ΔΦ / T         [визначення амплітуди через параметри вікна]
```

Остаточна аналітична формула профілю частоти набуває вигляду:

```
y_cos(t') = − (ΔΦ / T) · (1 − cos(2π · t' / T))      [формула косинусного розмазування]
```

А закон зміни фазової поправки описується виразом:

```
Φ_cos(t') = − ΔΦ · ( (t' / T) − (1 / (2π)) · sin(2π · t' / T) )
```

### Дослідження динамічних характеристик косинусного профілю

#### 1. Пікове відхилення частоти (`y_max`)
Максимальне значення відхилення частоти досягається рівно посередині вікна розмазування (`t' = T / 2`), де аргумент косинуса дорівнює `π`, а сам `cos(π) = -1`:

```
y_cos(T/2) = − (ΔΦ / T) · (1 − (−1))      [підстановка t' = T/2: cos(π) = -1]
           = − 2 · (ΔΦ / T)               [арифметика: 1 - (-1) = 2]
           = 2 · y_lin                    [подвоєння амплітуди відносно лінійного режиму]
```

Для доби тривалістю `T = 86 400 с`:

```
y_cos(T/2) = − 2 · (1.0 / 86400) ≈ −2.3148148 · 10⁻⁵ = −23.14815 ppm
```

*Метрологічний висновок:* Пікове відхилення частоти при косинусному розмазуванні становить `-23.15 ppm`, що рівно вдвічі більше за константу лінійного розмазування (`-11.57 ppm`). Обидва значення гарантовано вкладаються в межі діапазону регулювання підсистеми timekeeping ядра Linux (`±500 ppm`).

#### 2. Швидкість дрейфу частоти (перша похідна `dy/dt`)
Диференціюємо функцію `y_cos(t')` за часом:

```
d(y_cos)/dt' = − (ΔΦ / T) · (d/dt')(1 − cos(2π · t' / T))      [похідна складеної функції]
             = − (ΔΦ / T) · ( (2π / T) · sin(2π · t' / T) )    [диференціювання косинуса]
             = − (2π · ΔΦ / T²) · sin(2π · t' / T)             [швидкість зміни частоти]
```

Максимальна за модулем швидкість зміни частоти досягається в точках найбільшої крутизни синусоїди — на чверті та трьох чвертях вікна (`t' = T / 4` та `t' = 3T / 4`), де `|sin| = 1`:

```
|dy/dt|_max = (2π · ΔΦ) / T²
```

Підставимо параметри 24-годинного вікна:

```
|dy/dt|_max = (2 · 3.14159265 · 1.0) / (86400)²
            = 6.2831853 / 7464960000
            ≈ 8.4169 · 10⁻¹⁰ с⁻¹
```

У метрологічних одиницях дрейфу частоти (ppb/s — англ. *parts per billion per second*, `1 ppb = 10⁻⁹`):

```
|dy/dt|_max ≈ 0.8417 ppb/с      [максимальне прискорення фази]
```

Спектральна густина потужності косинусного вікна спадає у частотній області зі швидкістю `1 / ω³`:

```
S_cos(ω) ∝ 1 / ω³      [швидке асимптотичне придушення високочастотних гармонік]
```

Таке стрімке спадання гарантує повну відсутність високочастотного шуму на вході контурів фазового автопідстроювання приймачів синхронного Ethernet (SyncE) та базових станцій мобільного зв'язку 5G.

### Вплив розмазування на дисперсію Аллана та стійкість PLL

Для прецизійних радіофізичних комплексів та систем супутникового стеження важливим параметром є часова стабільність генератора, яка оцінюється двовибірковою дисперсією Аллана (Allan Variance):

```
σ_y²(τ) = (1 / 2) · ⟨ ( y̅_{k+1} − y̅_k )² ⟩      [визначення дисперсії Аллана]
```

де `y̅_k` — середнє значення відносного відхилення частоти на інтервалі усереднення тривалістю `τ`.

Під час застосування алгоритмів розмазування високосної секунди графік девіації Аллана `σ_y(τ)` зазнає характерної тимчасової деформації:

1. **Короткі інтервали усереднення (`τ < 100 с`):**
   На коротких проміжках часу зміна частоти, спричинена смірингом, є мізерною: за `100 с` косинусний профіль змінює частоту менше ніж на `0.08 ppb`. На цих масштабах на графіку `σ_y(τ)` повністю домінує власний білий фазовий та частотний шум кварцового або атомного резонатора.

2. **Середні інтервали усереднення (`1000 с < τ < 20 000 с`):**
   На проміжках у кілька годин детермінований дрейф смірингу починає перевищувати рівень випадкових флуктуацій генератора. На графіку стабільності формується куполоподібний підйом девіації Аллана з піком на рівні близько `1.2 · 10⁻⁵` в районі `τ ≈ 20 000 с` (близько 5.5 годин).

3. **Довгі інтервали усереднення (`τ ≥ 86 400 с`):**
   Оскільки повний фазовий зсув на інтервалі доби строго дорівнює точно одній секунді, після завершення повного вікна середнє відхилення частоти повертається до нуля. Девіація Аллана відновлює свій звичайний асимптотичний спад, характерний для незбуреного еталонного генератора.

#### Реакція контуру автопідстроювання фази (PLL Response):
Передатна функція замкненого контуру PLL другого порядку для похибки фази описується стандартним виразом:

```
H_err(s) = s² / ( s² + 2ζ·ω_n·s + ω_n² )      [передатна функція похибки PLL]
```

де `ω_n` — власна кутова частота контуру, а `ζ` — коефіцієнт демпфування.

Оскільки спектр косинусного профілю сконцентрований на наднизькій частоті `ω_smear = 2π / 86400 ≈ 7.27 · 10⁻⁵ рад/с`, що лежить глибоко нижче смуги зрізу будь-якого промислового PLL-фільтра (`ω_n ≫ ω_smear`), контур відпрацьовує керівний сигнал квазістатично з нульовим динамічним перерегулюванням.

### Аналіз несиметричних вікон та похибок дискретизації

У деяких спеціалізованих мережах (наприклад, внутрішніх сервісах Meta або фінансових шлюзах) застосовують скорочені вікна розмазування.

#### 1. 12-годинне вікно розмазування
Якщо тривалість вікна скорочується вдвічі (`T_short = 43 200 с`, тобто з 00:00 до 12:00 UTC), необхідна поправка частоти зростає зворотно пропорційно тривалості:

```
y_lin_short = − 1.0 / 43200 ≈ −23.148 ppm      [лінійне зміщення для 12 годин]
y_cos_short = 2 · y_lin_short ≈ −46.296 ppm    [косинусний пік для 12 годин]
```

Швидкість зміни частоти зростає у чотири рази:

```
|dy/dt|_short = (2π · 1.0) / (43200)² ≈ 3.367 ppb/с      [зростання прискорення фази]
```

Скорочення вікна дозволяє швидше повернути систему до точного астрономічного часу, проте створює вчетверо більше динамічне навантаження на контури PLL.

#### 2. Похибка дискретного кроку квантування частоти
У реальних програмних реалізаціях демон оновлює частоту `tx.freq` не неперервно, а з кінцевим періодом дискретизації `Δt_step` (наприклад, `500 мс`).

Оцінимо максимальну похибку апроксимації фази від східчастого подання частоти:

```
δΦ_max ≈ (1 / 2) · |dy/dt|_max · (Δt_step)²      [теоретична похибка квантування фази]
```

Підставимо параметри 24-годинного косинусного розмазування та крок `0.5 с`:

```
δΦ_max ≈ (1 / 2) · (8.417 · 10⁻¹⁰) · (0.5)² ≈ 1.052 · 10⁻¹⁰ с = 0.105 наносекунди
```

*Висновок:* Дискретне оновлення частоти ядра двічі на секунду вносить методичну похибку близько `0.1 нс`, що на три порядки перевищує точність субмікросекундних апаратних міток PTP і є абсолютно непомітним для мережевих протоколів.

### Поліноміальні профілі гладкого розмазування

Альтернативою тригонометричним функціям є застосування алгебраїчних поліномів вищих порядків, які не вимагають обчислення трансцендентних функцій у ядрі операційної системи.

#### 1. Кубічний поліном (Cubic Slew / Smoothstep)
Нормована функція частоти з нульовими похідними першого порядку на межах будується на базі полінома третього степеня:

```
y_cubic(u) = − 6 · (ΔΦ / T) · (u − u²)      [кубічний профіль для нормованого часу u = t'/T]
```

Інтегруємо функцію на одиничному інтервалі `u ∈ [0, 1]`:

```
∫[0...1] 6 · (u − u²) du = 6 · [ u²/2 − u³/3 ]₀¹                                    [первісна полінома]
                         = 6 · ( 1/2 − 1/3 )                                        [підстановка меж]
                         = 6 · (1/6) = 1.0                                          [нормування інтегралу]
```

Пікове значення частоти досягається в точці `u = 0.5`:

```
y_cubic(0.5) = − 6 · (ΔΦ / T) · (0.5 − 0.25) = − 1.5 · (ΔΦ / T) = −17.361 ppm
```

Кубічний профіль забезпечує менше пікове відхилення частоти (`-17.36 ppm` проти `-23.15 ppm` у косинуса), проте його друга похідна на межах інтервалу є ненульовою.

#### 2. Квінтичний поліном (Quintic Slew / Smootherstep)
Для забезпечення неперервності як першої (`dy/dt`), так і другої похідної (`d²y/dt²`) застосовують поліном п'ятого степеня:

```
y_quintic(u) = − 30 · (ΔΦ / T) · (u² − 2u³ + u⁴)      [квінтичний профіль розмазування]
```

Пікове значення частоти становить:

```
y_quintic(0.5) = − 30 · (ΔΦ / T) · (0.25 − 0.25 + 0.0625) = − 1.875 · (ΔΦ / T) = −21.701 ppm
```

### Динаміка фазової розбіжності відносно еталону UTC

Під час проходження вікна розмазування системний час `t_smear(t)` відрізняється від істинного астрономічного часу `t_UTC(t)` на величину накопиченого зсуву:

```
t_smear(t) = t_UTC(t) + Φ(t)
```

Нижче наведено порівняння параметрів для симетричного 24-годинного вікна від `12:00:00 UTC (день N)` до `12:00:00 UTC (день N+1)`:

| Точка вікна | Час від старту (`t'`) | Лінійне зміщення `Φ_lin` | Косинусне зміщення `Φ_cos` | Миттєва частота `y_cos` |
| :--- | :--- | :--- | :--- | :--- |
| **Початок вікна (12:00 UTC)** | `0 с` | `0.0000 с` | `0.0000 с` | `0.00 ppm` |
| **Перша чверть (18:00 UTC)** | `21 600 с` | `-0.2500 с` | `-0.0908 с` | `-11.57 ppm` |
| **Опівніч (23:59:59 UTC)** | `43 200 с` | `-0.5000 с` | `-0.5000 с` | `-23.15 ppm` (пік) |
| **Третя чверть (06:00 UTC)** | `64 800 с` | `-0.7500 с` | `-0.9092 с` | `-11.57 ppm` |
| **Завершення (12:00 UTC)** | `86 400 с` | `-1.0000 с` | `-1.0000 с` | `0.00 ppm` |

#### Головні висновки аналітичного моделювання:
1. **Інваріант опівночі:** Рівно в момент настання астрономічної високосної секунди (`t' = T / 2 = 43 200 с`) як лінійний, так і косинусний і поліноміальний методи дають **строго однаковий фазовий зсув рівно `-0.5000 с`**.
2. **Максимальна похибка:** Максимальне абсолютне відхилення розмазаного годинника від еталонного сервера UTC без смірингу ніколи не перевищує `0.5 секунди`.
3. **Гладкість фази:** Косинусний підхід концентрує основну зміну частоти навколо опівночі, забезпечуючи нульові прискорення на стиках вікна, що робить його математично оптимальним вибором для прецизійної мережевої інфраструктури.
