# 🧮 Математика дробового ділення частоти та накопичення фази

В асинхронних цифрових інтерфейсах швидкість передачі даних задається дільником базової тактової частоти мікроконтролера. Якщо тактова частота шини не ділиться націло на добуток швидкості передачі та коефіцієнта передискретизації, простий цілочисельний лічильник змушений округлювати коефіцієнт ділення до найближчого цілого числа. На високих швидкостях або при низьких частотах шини це округлення призводить до неприпустимої систематичної похибки частоти, яка перевищує допустимий бюджет асинхронного приймача. Дробове ділення розв'язує цю проблему шляхом динамічного перемикання коефіцієнта ділення між двома сусідніми цілими числами, формуючи в середньому точно задане раціональне значення частоти без потреби в аналогових фазових автопідстроюваннях (ФАПЧ / PLL).

---

### Постановка задачі раціонального синтезу частоти

Нехай маємо вхідний періодичний тактовий сигнал із частотою `f[in]` та періодом `T[in] = 1 / f[in]`. Необхідно згенерувати вихідну послідовність імпульсів із середньою частотою `f[out]`, яка пов'язана з вхідною частотою раціональним коефіцієнтом ділення `D`:

```
D = f[in] / f[out] = N + F / M
```

Тут `N` — ціла частина коефіцієнта ділення (мантиса, `N = floor(D)`, де `N >= 1`), `F` — чисельник дробової частини (`0 <= F < M`), а `M` — фіксований знаменник дробової дискретизації, що визначається розрядністю апаратного накопичувача (типово `M = 16`, `M = 8` або довільне ціле `M = 2^m`).

Оскільки фізичний цифровий дільник на синхронних тригерах здатен відраховувати лише ціле число тактів вхідної частоти `T[in]`, згенерувати постійний елементарний період тривалістю `D · T[in]` в дискретному часі неможливо. Єдиним розв'язком є синтез квазіперіодичної послідовності, у якій частина вихідних інтервалів має тривалість `T[1] = N · T[in]`, а інша частина — подовжену тривалість `T[2] = (N + 1) · T[in]`.

Нехай у серії з `M` послідовних вихідних циклів рівно `k[1]` циклів мають довжину `N · T[in]`, а `k[2]` циклів — довжину `(N + 1) · T[in]`. Загальна тривалість `M` вихідних циклів повинна точно дорівнювати сумі `M` ідеальних періодів:

```
T[total] = k[1] · N · T[in] + k[2] · (N + 1) · T[in]
```

З урахуванням балансу кількості циклів `k[1] + k[2] = M`:

```
T[total]
= (M - k[2]) · N · T[in] + k[2] · (N + 1) · T[in]     [підстановка k[1] = M - k[2]]
= (M · N - k[2] · N + k[2] · N + k[2]) · T[in]         [розкриття дужок]
= (M · N + k[2]) · T[in]                               [скорочення протилежних доданків]
```

Прирівнюючи загальний час до ідеального значення `T[total] = M · D · T[in] = M · (N + F / M) · T[in] = (M · N + F) · T[in]`, отримуємо тотожність:

```
M · N + k[2] = M · N + F
k[2] = F
k[1] = M - F
```

Отже, у кожному блоці з `M` вихідних тактів дільник повинен виконати рівно `F` подовжених циклів ділення на `N + 1` та `M - F` базових циклів ділення на `N`. Середній коефіцієнт ділення за період блоку становить:

```
D[avg] = ( (M - F) · N + F · (N + 1) ) / M = N + F / M
```

Середня вихідна частота збігається з теоретичною цільовою частотою з абсолютною математичною точністю:

```
f[out_avg] = f[in] / D[avg] = f[in] / (N + F / M)
```

### Рекурентне рівняння фазового акумулятора

Для практичної реалізації дільника критично важливо рівномірно розподілити `F` подовжених тактів серед `M - F` звичайних тактів. Якщо всі `F` подовжених циклів згрупувати на початку блоку, фазовий зсув вихідного сигналу зростатиме лінійно, утворюючи неприпустимий накопичувальний дрейф фази, що спотворить стробування всередині кадру.

Рівномірний розподіл забезпечується числовим фазовим акумулятором (англ. *phase accumulator*). Нехай на кроці `n` (де `n = 0, 1, 2, ...` — номер згенерованого вихідного імпульсу дільника) стан акумулятора позначається `A[n]`, де `0 <= A[n] < M`. На кожному вихідному такті до вмісту акумулятора додається числове значення дробу `F`. Рекурентне співвідношення записується у вигляді:

```
S[n] = A[n] + F
A[n+1] = S[n] mod M
C[n] = floor( S[n] / M )
```

Тут `C[n] ∈ {0, 1}` — сигнал переповнення (біт переносу, *Carry Out*), який безпосередньо керує модулем дільника на наступному циклі:

```
D[n] = N + C[n]
```

Якщо `C[n] = 0`, дільник відраховує `N` вхідних тактів. Якщо `C[n] = 1`, дільник відраховує `N + 1` вхідних тактів, подовжуючи поточний вихідний інтервал на один вхідний такт `T[in]`.

Розгорнемо рекурентний вираз для довільного кроку `k`, прийнявши початковий нульовий стан акумулятора `A[0] = 0`:

```
A[k] = (k · F) mod M
```

Сумарна кількість переповнень `Sum_C(k)`, що відбулися за перші `k` вихідних циклів, дорівнює:

```
Sum_C(k) = sum_{j=0}^{k-1} C[j] = floor( (k · F) / M )
```

Тоді загальний фізичний час `t[k]`, що минув від початку відліку до завершення `k`-го вихідного імпульсу, становить:

```
t[k] = k · N · T[in] + Sum_C(k) · T[in] = ( k · N + floor( (k · F) / M ) ) · T[in]
```

### Ізоморфізм з алгоритмом растеризації Брезенгема

Математична структура виразу для сумарного часу `t[k]` повністю еквівалентна класичному алгоритму Брезенгема (англ. *Bresenham's line algorithm*) для растеризації відрізка прямої лінії на дискретній координатній сітці.

Розглянемо ідеальну неперервну пряму фазового часу `t_ideal(k) = k · D · T[in] = k · (N + F / M) · T[in]`. Перепишемо її через нормовану кількість вхідних тактів `Y(k) = t(k) / T[in]`:

```
Y_ideal(k) = k · N + k · (F / M)
```

Задача полягає у виборі цілочисельної координати сітки `Y[k] ∈ Z` для кожного дискретного кроку `k ∈ Z` так, щоб абсолютне відхилення від ідеальної прямої було строго мінімальним. Різниця між ідеальною координатою та реальним цілим часом у тактів становить:

```
delta[k] = Y_ideal(k) - Y[k] = (k · F / M) - floor( (k · F) / M ) = ( (k · F) mod M ) / M = A[k] / M
```

Оскільки `0 <= A[k] < M`, нормована фазова похибка `delta[k]` строго обмежена півінтервалом:

```
0 <= delta[k] < 1
```

Помноживши похибку на `M`, ми отримуємо цілочисельний акумулятор помилки `e[k] = A[k]`, який оновлюється на кожному кроці простим додаванням `F` та відніманням `M` при досягненні порогу. Це доводить, що фазовий акумулятор генерує оптимальну послідовність цілих інтервалів `N` та `N + 1`, яка мінімізує відхилення дискретного часу від неперервного лінійного тренду для будь-яких раціональних коефіцієнтів `F / M`.

### Зв'язок із модуляцією Дельта-Сигма першого порядку

Фазовий акумулятор дільника частоти можна розглядати як цифровий Дельта-Сигма модулятор першого порядку (англ. *First-Order Delta-Sigma Modulator*), що працює в режимі однобітного квантування з переносом шуму квантування у високочастотну область спектра (англ. *noise shaping*).

У класичній цифровій схемі накопичувач виконує роль дискретного інтегратора:

```
w[n] = w[n-1] + F - M · C[n-1]
```

Тут сигнал `C[n]` є квантованим виходом (0 або 1), а різниця `e[n] = F - M · C[n]` є помилкою квантування. Передатна функція похибки квантування в Z-області має вигляд:

```
H_e(z) = 1 - z^(-1)
```

Цей диференціальний оператор `1 - z^(-1)` діє як фільтр верхніх частот для фазового шуму: потужність шуму на нульовій частоті (постійний струм / DC) строго дорівнює нулю (`H_e(1) = 1 - 1 = 0`). Це означає, що середня частота вихідного сигналу не має систематичного зміщення, а вся енергія похибки квантування виштовхується у високочастотну область, де вона природно фільтрується скінченною тривалістю вибіркового вікна приймача UART.

Чому в дільниках UART не використовують модулятори вищих порядків (MASH 1-1 або MASH 1-1-1)? Модулятори другого та третього порядків переносять шум квантування у ще вищу частотну область, проте вимагають мультибітного квантування з вихідними коефіцієнтами `N-1, N, N+1, N+2`. Це призвело б до збільшення миттєвого фазового джитеру до `2..3 тактів T[in]`, що є небажаним для чутливого асинхронного приймача. Однобітний акумулятор першого порядку забезпечує ідеальний компроміс: мінімальний розмах джитеру (`< 1 такт T[in]`) при нульовій постійній похибці середньої швидкості.

### Періодичність та структура часових інтервалів

Нехай дріб `F / M` скорочується на найбільший спільний дільник:

```
g = gcd(F, M)
F' = F / g
M' = M / g
```

Тоді послідовність станів акумулятора `A[k]` та бітів переносу `C[k]` є строго періодичною з мінімальним періодом `P = M' = M / gcd(F, M)`.

Розглянемо теорему про відстані між послідовними переносами (англ. *Distance Distribution Theorem*). Нехай `L[j]` — кількість базових циклів `N` між двома сусідніми подовженими циклами `N + 1`. Для будь-якого раціонального чисельника `F` та знаменника `M` послідовність `L[j]` може приймати **не більше двох сусідніх цілих значень**:

```
L[j] ∈ { floor( (M - F) / F ), ceil( (M - F) / F ) }
```

Розглянемо приклад синтезу дробової частини для модуля `M = 16` та чисельника `F = 6`:

```
gcd(6, 16) = 2
F' = 3, M' = 8
Період повторення шаблону: P = 8 вихідних циклів
Можливі інтервали між переносами: floor(10/6) = 1 та ceil(10/6) = 2
```

Простежимо стан акумулятора покроково:

```
Крок k=0: A[0] = 0,   S[0] = 0 + 6 = 6   < 16  → C[0] = 0, A[1] = 6,  поділ на N
Крок k=1: A[1] = 6,   S[1] = 6 + 6 = 12  < 16  → C[1] = 0, A[2] = 12, поділ на N
Крок k=2: A[2] = 12,  S[2] = 12 + 6 = 18 >= 16 → C[2] = 1, A[3] = 2,  поділ на N+1
Крок k=3: A[3] = 2,   S[3] = 2 + 6 = 8   < 16  → C[3] = 0, A[4] = 8,  поділ на N
Крок k=4: A[4] = 8,   S[4] = 8 + 6 = 14  < 16  → C[4] = 0, A[5] = 14, поділ на N
Крок k=5: A[5] = 14,  S[5] = 14 + 6 = 20 >= 16 → C[5] = 1, A[6] = 4,  поділ на N+1
Крок k=6: A[6] = 4,   S[6] = 4 + 6 = 10  < 16  → C[6] = 0, A[7] = 10, поділ на N
Крок k=7: A[7] = 10,  S[7] = 10 + 6 = 16 >= 16 → C[7] = 1, A[8] = 0,  поділ на N+1
```

Послідовність дільників на одному періоді `P = 8`:

```
[ N, N, N+1, N, N, N+1, N, N+1 ]
```

Сумарна кількість тактів за період `P = 8`:

```
T[P] = 5 · N + 3 · (N + 1) = 8 · N + 3
D[avg] = (8 · N + 3) / 8 = N + 6 / 16
```

Додаткові такти розподілені максимально рівномірно (інтервали між подовженими циклами становлять 2, 2, 1 базових циклів), що виключає появу низькочастотного фазового шуму.

### Межі миттєвої фазової похибки та розрахунок дисперсії джитеру

Оскільки окремі цикли мають різну фізичну тривалість (`N · T[in]` або `(N + 1) · T[in]`), вихідний сигнал має миттєву фазову похибку (часовий джитер / *phase jitter*). Обчислимо точні верхні та нижні межі цієї похибки та її статистичну дисперсію.

Визначимо абсолютну фазову помилку в секундах `Delta_t(k)` на момент завершення `k`-го вихідного циклу як різницю між реальним часом `t[k]` та ідеальним теоретичним часом `t_ideal(k)`:

```
Delta_t(k) = t[k] - t_ideal(k)
= ( k · N + floor( (k · F) / M ) ) · T[in] - k · ( N + F / M ) · T[in]
= ( floor( (k · F) / M ) - (k · F) / M ) · T[in]
= - ( (k · F) mod M ) / M · T[in]
= - ( A[k] / M ) · T[in]
```

Оскільки стан акумулятора набуває значень `A[k] ∈ {0, 1, ..., M - 1}`, фазова помилка `Delta_t(k)` завжди лежить у строгому діапазоні:

```
- ( (M - 1) / M ) · T[in] <= Delta_t(k) <= 0
```

Якщо змістити початок відліку фази на середину діапазону (центрична фазова помилка), розмах пік-пік (англ. *peak-to-peak jitter*) часового джитеру становить:

```
Jitter[p-p] = ( (M - 1) / M ) · T[in] < 1 · T[in]
```

Цей фундаментальний результат свідчить: **миттєва фазова похибка дільника Брезенгема ніколи не перевищує одного періоду вхідної тактової частоти `T[in]`**, незалежно від тривалості роботи схеми чи кількості переданих байтів.

Обчислимо дисперсію часового джитеру `sigma_t^2`. Якщо дріб `F / M` є взаємно простим (`gcd(F, M) = 1`), значення `A[k]` рівномірно пробігають усі цілі числа від `0` до `M - 1`. Математичне сподівання фазової похибки становить:

```
E[Delta_t] = - ( 1 / M ) · sum_{j=0}^{M-1} ( j / M ) · T[in] = - ( (M - 1) / (2 · M) ) · T[in]
```

Дисперсія фазового шуму дорівнює:

```
sigma_t^2 = E[ (Delta_t - E[Delta_t])^2 ] = ( (M^2 - 1) / (12 · M^2) ) · T[in]^2
```

При великих `M` дисперсія прямує до класичного значення шуму рівномірного квантування `T[in]^2 / 12`, а середньоквадратичне відхилення (RMS Jitter) становить:

```
Jitter_RMS ≈ T[in] / sqrt(12) ≈ 0.2887 · T[in]
```

Переведемо цей фазовий джитер у частки вихідного бітового інтервалу UART `T[bit]`. Оскільки в UART використовується передискретизація `R = 16` або `R = 8` (де `T[bit] = R · T[out] = R · D · T[in]`), відносний піковий джитер одного такт-відліку щодо біта становить:

```
Jitter[bit] = Jitter[p-p] / T[bit] = ( (M - 1) / M · T[in] ) / ( R · D · T[in] ) = (M - 1) / (M · R · D)
```

Для стандартного режиму `R = 16`, `M = 16` та мінімального значення `D >= 1`:

```
Jitter[bit] <= 15 / (16 · 16 · 1) = 15 / 256 ≈ 0.0586 (5.86% від інтервалу біта)
```

За більших значень коефіцієнта ділення `D` (наприклад, `D = 22.8125` для 115200 бод при 42 МГц) джитер стає зникаюче малим:

```
Jitter[bit] = 15 / (16 · 16 · 22.8125) = 15 / 5840 ≈ 0.00257 (0.26% від інтервалу біта)
```

Така величина на порядки нижча за ширину апертури стробування приймача (яка займає 3 відліки з 16, тобто 18.75% у центрі біта), що повністю усуває загрозу помилкового зчитування бітів.

### Фільтрація фазового шуму мажоритарним селектором

Асинхронний приймач UART не використовує миттєве положення окремого такту безпосередньо. Замість цього схема містить цифровий мажоритарний фільтр (англ. *Majority Voting Filter*), який бере 3 вибірки на 7, 8 та 9 тактах передискретизації.

У частотній області такий мажоритарний вибір діє як дискретне віконне інтегрування довжиною у 3 відліки. Його нормована амплітудно-частотна характеристика описується функцією Діріхле:

```
|H_filter(f)| = | sin( 3 · pi · f / f_sample ) / ( 3 · sin( pi · f / f_sample ) ) |
```

На частотах супутніх гармонік дільника `f_spur`, які лежать поблизу частоти Найквіста вибірки `f_sample / 2`, передатна функція фільтра забезпечує додаткове придушення фазового шуму на величину від `9.5 дБ` до `14.2 дБ`. Це доводить, що залишкова дискретність фазового акумулятора природно пригнічується вхідним трактом приймача, не створюючи додаткового бітового шуму.

---

### Порівняння похибки квантування: цілочисельне, 1/8 та 1/16 ділення

Оцінимо максимальну теоретичну похибку встановлення швидкості `epsilon[max]` як функцію розрядності дробової частини `M`.

При виборі найближчого раціонального дільника абсолютна похибка коефіцієнта ділення не перевищує половини дискрети квантування:

```
|Delta_D| <= 1 / (2 · M)
```

Відносна похибка встановлення частоти `epsilon = |f[real] - f[target]| / f[target]` пов'язана з похибкою коефіцієнта ділення через похідну:

```
f = f[in] / D
df / dD = - f[in] / D^2
epsilon ≈ |dD| / D <= 1 / (2 · M · D)
```

Зведемо аналітичні межі похибки для типових апаратних конфігурацій:

| Тип дільника | Знаменник `M` | Квант `Delta_D` | Максимальна похибка `epsilon[max]` |
| :--- | :--- | :--- | :--- |
| **Цілочисельний (Integer)** | `1` | `1.0` | `1 / (2 · D)` |
| **Дробовий 8× (STM32 OVER8=1)** | `8` | `0.125` | `1 / (16 · D)` |
| **Дробовий 16× (STM32 / ESP32)** | `16` | `0.0625` | `1 / (32 · D)` |
| **Дробовий NXP LPC (FDR)** | `15` | `≈ 0.0667` | `1 / (30 · D)` |
| **24-бітний NCO (DDS)** | `2^24 ≈ 16.7·10^6` | `≈ 5.96·10^-8` | `1 / (3.35·10^7 · D)` |

Для критичного випадку високої швидкості (наприклад, `f[in] = 42 МГц`, `Baud = 921 600 бод`, `R = 16`, звідки `D = 2.8489`):

- **Цілочисельний дільник (`M = 1`):** найближче `N = 3`, похибка `|2.8489 - 3| / 2.8489 = 5.30%` (перевищує поріг стійкості кадру `±2.5%`).
- **Дробовий дільник 1/16 (`M = 16`):** дріб `F = 14`, `D[real] = 2 + 14/16 = 2.875`, похибка `|2.8489 - 2.875| / 2.8489 = 0.916%` (у межах норми).
- **Дробовий дільник 8× (`R = 8`, `M = 8`):** `D = 5.6978`, дріб `F = 6`, `D[real] = 5 + 6/8 = 5.750`, або `N=5, F=5 -> 5.625`, а при переході до цільового значення мантиси `N=5, F=6/8` маємо похибку `|5.6978 - 5.700| / 5.6978 = 0.038%` (практично ідеальний синтез).

Математичний аналіз доводить, що введення 4-бітного фазового накопичувача зменшує систематичну похибку квантування рівно в 16 разів при незмінній тактовій частоті шини, що забезпечує надійний прийом безпомилкових кадрів UART у всьому робочому діапазоні швидкостей.
