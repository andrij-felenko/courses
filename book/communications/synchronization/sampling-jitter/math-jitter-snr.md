# 🧮 Математичне виведення деградації SNR та ENOB від джиттеру вибірки

Математичний аналіз впливу часової нестабільності вибірки на якість оцифрування та відновлення аналогових сигналів встановлює фундаментальну теоретичну межу динамічного діапазону будь-якої радіотехнічної системи. Жодне збільшення номінальної розрядності квантувача чи зменшення кроку напруги не здатне підвищити точність перетворення, якщо часова невизначеність моменту фіксації сигналу перевищує допустимий поріг для заданої частоти коливань.

Нижче наведено строге аналітичне виведення дисперсії похибки напруги, спричиненої апертурним джиттером, розраховано теоретичну межу відношення сигнал/шум `SNR_jitter`, побудовано інтегральний баланс шумів системи з урахуванням квантування й теплових флуктуацій, виведено деградацію ефективної розрядності (ENOB), проаналізовано спектральні моделі фазового шуму Лісона та степеневий розклад шуму, досліджено вплив крутизни тактового фронту (Slew Rate), перенесення джиттеру на широкосмугові сигнали через смугу Габора, декомпозицію випадкового та детермінованого джиттеру за моделлю Dual-Dirac, зв'язок із дисперсією Аллана та дзеркальний ефект джиттеру в ЦАП.

## 1. Модель сигналу та лінеаризація миттєвої похибки вибірки

Розглядаємо процес дискретизації гармонічного сигналу з амплітудою `V₀` та циклічною частотою `f_in` (кутова частота `ω_in = 2π · f_in`):

```
V(t) = V₀ · sin(2π · f_in · t)
```

В ідеальному перетворювачі відліки беруться у строго детерміновані моменти часу `t_n = n · T_s`, де `T_s = 1 / f_s` — період дискретизації. У реальному пристрої внаслідок шумів у тактовому генераторі, паразитних наводок на лінії синхронізації та внутрішніх флуктуацій схеми вибірки-зберігання (Sample & Hold) фактичний момент замикання аналогового ключа відхиляється від ідеального на випадкову величину `Δt`:

```
t'_n = t_n + Δt
```

Випадкова величина `Δt` називається **апертурним джиттером** (або часовою невизначеністю вибірки). Вона є центрованим випадковим процесом із нульовим математичним сподіванням `𝔼[Δt] = 0` та середньоквадратичним відхиленням (RMS) `σ_t`:

```
σ_t = √( 𝔼[Δt²] )
```

Миттєве значення вибірки, зафіксоване в момент `t'_n`, записується через розклад функції `V(t)` у ряд Тейлора поблизу точки `t_n`:

```
V(t_n + Δt)
= V(t_n) + V'(t_n) · Δt + (1/2) · V''(t_n) · (Δt)² + ...     [розклад Тейлора]
```

Оскільки середньоквадратичний джиттер `σ_t` у високоякісних системах становить одиниці пікосекунд або частки наносекунди, що на багато порядків менше за період коливання сигналу (`σ_t ≪ 1 / f_in`), членами другого та вищих порядків малості можна знехтувати. Тоді абсолютна похибка напруги `e_v(t_n) = V(t_n + Δt) - V(t_n)` лінійно визначається миттєвою похідною сигналу:

```
e_v(t_n) ≈ V'(t_n) · Δt = [ dV(t) / dt |_{t=t_n} ] · Δt
```

Обчислимо аналітичну похідну вхідного гармонічного коливання:

```
dV(t) / dt
= d [ V₀ · sin(2π · f_in · t) ] / dt                         [диференціювання гармоніки]
= 2π · f_in · V₀ · cos(2π · f_in · t)                        [похідна синуса]
```

Підставляючи похідну у вираз для похибки напруги, отримуємо миттєву амплітудну похибку вибірки:

```
e_v(t_n) = 2π · f_in · V₀ · cos(2π · f_in · t_n) · Δt
```

Звідси очевидно, що похибка напруги прямо пропорційна двом незалежним факторам:
1. Часовому зсуву `Δt` (величині джиттеру);
2. Крутизні сигналу `dV/dt`, яка досягає свого абсолютного максимуму `(dV/dt)_max = 2π · f_in · V₀` у моменти перетину нульового рівня (`cos(2π · f_in · t) = ±1`), де сигнал змінюється найшвидше.

## 2. Статистичне осереднення дисперсії похибки

Похибка напруги `e_v` є добутком двох незалежних випадкових величин: випадкового часового зміщення `Δt` та фазового положення вибірки на синусоїді `cos(2π · f_in · t_n)`. Оскільки фаза сигналу в моменти вибірки розподілена рівномірно на інтервалі `[0, 2π]` (за умови некогерентності частоти сигналу та частоти дискретизації), а джиттер `Δt` не залежить від фази сигналу, повне математичне сподівання квадрата похибки (потужність шуму джиттеру) обчислюється як добуток їхніх дисперсій.

Середнє значення похибки:

```
𝔼[ e_v ]
= 𝔼[ 2π · f_in · V₀ · cos(2π · f_in · t_n) · Δt ]            [підстановка e_v]
= 2π · f_in · V₀ · 𝔼[ cos(2π · f_in · t_n) ] · 𝔼[ Δt ]       [статистична незалежність]
= 2π · f_in · V₀ · 0 · 0                                     [симетрія фази та нульовий джиттер]
= 0
```

Обчислимо середній квадрат похибки напруги `σ_v,jitter² = 𝔼[ e_v² ]`:

```
σ_v,jitter²
= 𝔼[ ( 2π · f_in · V₀ · cos(2π · f_in · t_n) · Δt )² ]       [квадрат похибки]
= (2π · f_in · V₀)² · 𝔼[ cos²(2π · f_in · t_n) ] · 𝔼[ Δt² ]   [винесення констант]
```

Осереднення квадрата косинуса за повний період коливання:

```
𝔼[ cos²(2π · f_in · t_n) ]
= (1 / T) · ∫₀^T cos²(2π · f_in · t) dt                      [інтеграл по періоду]
= (1 / T) · ∫₀^T ( 1 + cos(4π · f_in · t) ) / 2 dt           [тригонометрична тотожність]
= (1 / (2T)) · [ t + sin(4π · f_in · t) / (4π · f_in) ]₀^T   [первісна]
= (1 / (2T)) · [ T - 0 ]                                     [підстановка меж]
= 1 / 2
```

Оскільки за означенням середньоквадратичного джиттеру `𝔼[ Δt² ] = σ_t²`, остаточний вираз для дисперсії похибки напруги набуває вигляду:

```
σ_v,jitter²
= (2π · f_in · V₀)² · (1 / 2) · σ_t²                         [підстановка інтеграла та дисперсії]
= (1 / 2) · ( 2π · f_in · V₀ · σ_t )²                        [потужність шуму джиттеру]
```

Середньоквадратичне значення (RMS) напруги шуму джиттеру:

```
σ_v,jitter = ( V₀ / √2 ) · 2π · f_in · σ_t = V_rms · 2π · f_in · σ_t
```

де `V_rms = V₀ / √2` — діюче значення вхідного гармонічного сигналу.

## 3. Виведення відношення сигнал/шум (SNR_jitter)

Відношення сигнал/шум за потужністю визначається як відношення середньої потужності корисного сигналу `P_sig` до потужності шуму джиттеру `P_jitter`. На одиничному навантаженні потужність гармонічного коливання з амплітудою `V₀` становить:

```
P_sig = V_rms² = V₀² / 2
```

Потужність шуму, породженого джиттером:

```
P_jitter = σ_v,jitter² = (1 / 2) · ( 2π · f_in · V₀ · σ_t )²
```

Обчислимо лінійне відношення сигнал/шум:

```
SNR_jitter,lin
= P_sig / P_jitter                                           [означення SNR]
= ( V₀² / 2 ) / [ (1 / 2) · ( 2π · f_in · V₀ · σ_t )² ]      [підстановка потужностей]
= V₀² / [ ( 2π · f_in · V₀ · σ_t )² ]                        [скорочення коефіцієнта 1/2]
= V₀² / [ V₀² · ( 2π · f_in · σ_t )² ]                       [винесення амплітуди]
= 1 / ( 2π · f_in · σ_t )²                                   [скорочення V₀²]
```

Зауважимо фундаментальний висновок: **лінійне відношення сигнал/шум від джиттеру взагалі не залежить від амплітуди сигналу `V₀`**, а визначається виключно добутком частоти коливань `f_in` та середньоквадратичного часового джиттеру `σ_t`.

Переведемо отримане значення у логарифмічний масштаб децибелів:

```
SNR_jitter [дБ]
= 10 · lg( SNR_jitter,lin )                                  [перехід у децибели]
= 10 · lg[ 1 / ( 2π · f_in · σ_t )² ]                        [підстановка лінійного SNR]
= 10 · lg[ ( 2π · f_in · σ_t )^{-2} ]                        [степенева форма]
= -20 · lg( 2π · f_in · σ_t )                                [властивість логарифма: lg(x^a) = a·lg(x)]
```

Розгорнемо формулу через суму логарифмів окремих множників для зручності інженерних розрахунків:

```
SNR_jitter [дБ]
= -20 · [ lg(2π) + lg(f_in) + lg(σ_t) ]
= -20 · [ 0.79818 + lg(f_in) + lg(σ_t) ]
= -15.964 - 20 · lg(f_in) - 20 · lg(σ_t)
```

Звідси чітко видно крутизну деградації:
- Збільшення частоти сигналу `f_in` в 10 разів (на одну декаду) знижує `SNR_jitter` рівно на 20 дБ;
- Подвоєння частоти сигналу (на одну октаву) знижує `SNR_jitter` на `20 · lg(2) ≈ 6.02 дБ`, що відповідає втраті рівно одного біта розрядності.

## 4. Джиттер для довільних широкосмугових сигналів та середня смуга Габора

Якщо вхідний сигнал не є монохроматичною синусоїдою, а становить широкосмуговий випадковий процес або суму багатьох несучих із енергетичним спектром `S_x(f)`, похибка вибірки визначається інтегралом квадрата похідної сигналу за часом.

Згідно з властивістю диференціювання перетворення Фур'є, спектр похідної сигналу `x'(t)` дорівнює `(2π f) · X(f)`. Відповідно, спектральна густина потужності похідної становить `(2π f)² · S_x(f)`.

Повна середня потужність похибки вибірки широкосмугового сигналу через джиттер `σ_t` записується як:

```
P_jitter,wideband = σ_t² · 𝔼[ (dx(t) / dt)² ] = σ_t² · ∫_{-∞}^{∞} (2π · f)² · S_x(f) df
```

Визначимо **середньоквадратичну ефективну смугу сигналу (смугу Габора)** `f_rms`:

```
f_rms² = [ ∫_{-∞}^{∞} f² · S_x(f) df ] / [ ∫_{-∞}^{∞} S_x(f) df ] = [ 1 / P_sig ] · ∫_{-∞}^{∞} f² · S_x(f) df
```

Тоді сумарна потужність шуму джиттеру виражається через повну потужність сигналу `P_sig` та його смугу Габора:

```
P_jitter,wideband = (2π · f_rms · σ_t)² · P_sig
```

Відповідно, узагальнене відношення сигнал/шум для будь-якого широкосмугового сигналу (зокрема радіосигналів OFDM, сигналів із кодовим розділенням CDMA чи шумоподібних імпульсів) становить:

```
SNR_jitter,wideband [дБ] = -20 · lg( 2π · f_rms · σ_t )
```

Цей результат доводить, що для складних сигналів еквівалентною частотою виступає не гранична частота Найквіста і не частота несучої, а середньозважена середньоквадратична частота спектрального розподілу потужності.

## 5. Декомпозиція джиттеру: Модель Dual-Dirac та зв'язок із BER

У швидкісних інтерфейсах передачі даних та синхронізації повний джиттер (Total Jitter, TJ) складається з двох фундаментально різних компонентів:
1. **Випадковий джиттер (Random Jitter, RJ):** Обумовлений тепловим і дробовим шумом. Має необмежений гаусів розподіл із дисперсією `σ_RJ²`.
2. **Детермінований джиттер (Deterministic Jitter, DJ):** Обумовлений паразитними наводками від імпульсних джерел живлення, міжсимвольною інтерференцією (ISI) та асиметрією порогів перемикання. Має строго обмежений розмах від піку до піку `DJ_pp`.

Відповідно до стандартизованої моделі **Dual-Dirac**, функція густини ймовірності повного джиттеру моделюється як згортка двох дельта-функцій Дірака, рознесених на відстань `DJ_δδ`, із гаусовим розподілом випадкового шуму `σ_RJ`.

Повний розмах джиттеру для заданого коефіцієнта бітових помилок (Bit Error Rate, BER) визначається виразом:

```
TJ(BER) = DJ_δδ + 2 · Q(BER) · σ_RJ
```

де `Q(BER) = √2 · erf^{-1}(1 - 2·BER)` — квантиль нормального розподілу.

Для типових вимог надійності зв'язку:
- Для `BER = 10^{-9}` коефіцієнт `Q ≈ 5.998`, тому `TJ = DJ + 12.0 · σ_RJ`;
- Для `BER = 10^{-12}` коефіцієнт `Q ≈ 7.034`, тому `TJ = DJ + 14.07 · σ_RJ`;
- Для `BER = 10^{-15}` коефіцієнт `Q ≈ 7.942`, тому `TJ = DJ + 15.88 · σ_RJ`.

Ця декомпозиція є критичною: у той час як адитивний фільтр або екранування можуть повністю придушити детермінований джиттер `DJ`, випадковий гаусів джиттер `σ_RJ` є принципово незнищенним і визначає кінцеву межу `SNR_jitter` за формулою `-20 · lg(2π · f_in · σ_RJ)`.

## 6. Гранична частота сигналу для збереження розрядності

Для ідеального `N`-бітного квантувача теоретичне відношення сигнал/шум квантування становить:

```
SNR_quant [дБ] = 6.02 · N + 1.76
```

Щоб шум джиттеру не погіршував номінальну роздільну здатність АЦП (тобто потужність шуму джиттеру не перевищувала потужність шуму квантування `SNR_jitter ≥ SNR_quant`), має виконуватися нерівність:

```
-20 · lg( 2π · f_in · σ_t ) ≥ 6.02 · N + 1.76
```

Розв'яжемо нерівність відносно максимальної допустимої вхідної частоти `f_in,max`:

```
lg( 2π · f_in · σ_t ) ≤ - ( 6.02 · N + 1.76 ) / 20           [ділення на -20 зі зміною знака]
2π · f_in · σ_t ≤ 10^{ - ( 6.02 · N + 1.76 ) / 20 }          [потенціювання за основою 10]
f_in,max = 1 / [ 2π · σ_t · 10^{(6.02 · N + 1.76) / 20} ]    [виділення f_in]
```

Оскільки `10^{(6.02 · N + 1.76) / 20} = 10^{0.30103 · N} · 10^{0.088} = 2^N · √1.5 ≈ 1.2247 · 2^N`, вираз спрощується до елегантного вигляду:

```
f_in,max
= 1 / [ 2π · σ_t · 2^N · √1.5 ]
= 1 / [ 2π · √1.5 · 2^N · σ_t ]
≈ 1 / [ 7.695 · 2^N · σ_t ]
```

**Числовий приклад:**
Нехай використовується 16-бітний АЦП (`N = 16`, `2¹⁶ = 65536`) із сумарним джиттером тактування `σ_t = 1 пс` (`10⁻¹² с`).

Обчислимо граничну частоту:

```
f_in,max
= 1 / [ 7.695 · 65536 · 10⁻¹² ]
= 1 / [ 5.043 × 10⁻⁷ ]
≈ 1.983 МГц
```

Якщо на вхід цього 16-бітного перетворювача подати сигнал проміжної частоти 20 МГц, `SNR_jitter` впаде до:

```
SNR_jitter = -20 · lg( 2π · 20×10⁶ · 10⁻¹² ) = -20 · lg( 1.2566×10⁻⁴ ) = -20 · (-3.9008) = 78.02 дБ
```

Замість теоретичних 98.08 дБ (16 біт) реальний перетворювач забезпечить лише 78.02 дБ, що еквівалентно АЦП з розрядністю менше 13 біт. Три старші розряди перетворювача повністю потонуть у шумі джиттеру.

## 7. Інтегральний баланс шумів системи (SNR_total)

У реальному аналого-цифровому тракті діють три статистично незалежні джерела випадкових похибок:
1. **Шум квантування** `σ_quant² = q² / 12`, де `q = V_FS / 2^N` — крок квантування (LSB);
2. **Тепловий шум тракту та вибірки** `σ_thermal² = k_B · T / C_sample`, де `C_sample` — ємність конденсатора схеми вибірки-зберігання;
3. **Шум апертурного джиттеру** `σ_jitter² = 0.5 · ( 2π · f_in · V₀ · σ_t )²`.

Оскільки ці процеси статистично некорельовані, їхні дисперсії (потужності шумів) додаються лінійно:

```
σ_total² = σ_quant² + σ_thermal² + σ_jitter²
```

Повне відношення сигнал/шум системи `SNR_total`:

```
SNR_total,lin
= P_sig / ( P_quant + P_thermal + P_jitter )                  [означення повного SNR]
= 1 / [ (P_quant / P_sig) + (P_thermal / P_sig) + (P_jitter / P_sig) ] [перетворення дробу]
= 1 / [ (1 / SNR_quant,lin) + (1 / SNR_thermal,lin) + (1 / SNR_jitter,lin) ]
```

У логарифмічній формі сумарний SNR виражається через децибельні складові:

```
SNR_total [дБ] = -10 · lg[ 10^{-SNR_quant/10} + 10^{-SNR_thermal/10} + 10^{-SNR_jitter/10} ]
```

Ця формула описує поведінку системи на всіх ділянках частотного діапазону:
- На низьких частотах (`f_in → 0`) доданок `10^{-SNR_jitter/10} → 0`, і якість обмежена квантуванням та тепловим шумом;
- На високих частотах (`f_in ≫ f_in,max`) доданок `10^{-SNR_jitter/10}` експоненційно домінує, і сумарний SNR асимптотично наближається до чистої межі джиттеру `SNR_jitter`.

## 8. Аналітичний розрахунок деградації ENOB

Ефективна кількість розрядів (Effective Number of Bits, ENOB) пов'язана з повним відношенням сигнал/шум та спотворень (SINAD) стандартним співвідношенням:

```
ENOB = ( SNR_total [дБ] - 1.76 ) / 6.02
```

Розглянемо високочастотну область, де тепловим шумом і шумом квантування можна знехтувати порівняно з шумом джиттеру (`SNR_total ≈ SNR_jitter`):

```
ENOB_jitter
= [ -20 · lg( 2π · f_in · σ_t ) - 1.76 ] / 6.02              [підстановка SNR_jitter]
= [ - (20 / lg(2)) · log₂( 2π · f_in · σ_t ) · lg(2) - 1.76 ] / 6.02  [перехід до двійкового логарифма]
```

Оскільки `20 · lg(2) = 20 · 0.30103 = 6.0206`:

```
ENOB_jitter
= [ -6.0206 · log₂( 2π · f_in · σ_t ) - 1.76 ] / 6.0206     [скорочення коефіцієнтів]
= - log₂( 2π · f_in · σ_t ) - ( 1.76 / 6.0206 )             [розділення дробів]
= - log₂( 2π · f_in · σ_t ) - 0.2923                         [остаточний вигляд]
```

Розгорнемо двійковий логарифм:

```
ENOB_jitter = - log₂(2π) - log₂(f_in) - log₂(σ_t) - 0.2923
ENOB_jitter = - 2.6515 - log₂(f_in) - log₂(σ_t) - 0.2923
ENOB_jitter = - 2.9438 - log₂(f_in) - log₂(σ_t)
```

Цей вираз безпосередньо демонструє двійкову природу втрати інформації: кожне збільшення частоти вхідного коливання `f_in` або джиттеру `σ_t` у `2` рази зменшує ефективну розрядність рівно на `log₂(2) = 1.0 біт`.

## 9. Зв'язок між спектральним фазовим шумом L(f) та часовим джиттером σ_t

У радіотехніці та телекомунікаціях стабільність генераторів задається не часовим джиттером, а **спектральною густиною фазового шуму** (Phase Noise Spectral Density) `L(f)`, вираженою в `дБн/Гц` (децибелах відносно потужності несучої в смузі 1 Гц) як функція зсуву частоти `f` від номінальної несучої `f₀`.

Нестабільний тактовий сигнал генератора записується як:

```
v_clk(t) = A₀ · cos( 2π · f₀ · t + φ(t) )
```

де `φ(t)` — випадковий процес фазових флуктуацій. За умови малості фазових відхилень (`|φ(t)| ≪ 1 рад`), односмугова спектральна густина фазового шуму `L(f)` пов'язана з двобічною спектральною густиною потужності фази `S_φ(f)` співвідношенням:

```
L(f) = 10 · lg[ (1 / 2) · S_φ(f) ]    [дБн/Гц]
```

Звідси лінійна спектральна густина потужності фазових флуктуацій:

```
S_φ(f) = 2 · 10^{ L(f) / 10 }    [рад²/Гц]
```

Повна дисперсія фазового шуму `σ_φ²` (у радіанах у квадраті) в заданій смузі аналізу від нижньої частоти відстроювання `f₁` до верхньої частоти `f₂` обчислюється шляхом інтегрування спектральної густини:

```
σ_φ²
= ∫_{f₁}^{f₂} S_φ(f) df                                       [інтеграл спектральної густини]
= 2 · ∫_{f₁}^{f₂} 10^{ L(f) / 10 } df                         [підстановка L(f)]
```

Середньоквадратичне відхилення фази (RMS Phase Jitter):

```
σ_φ = √( 2 · ∫_{f₁}^{f₂} 10^{ L(f) / 10 } df )    [рад]
```

Оскільки повна фаза `2π` радіан відповідає періоду тактового сигналу `T₀ = 1 / f₀` секунд, перехід від фазової невизначеності `σ_φ` (у радіанах) до часового джиттеру `σ_t` (у секундах) здійснюється через масштабний коефіцієнт кутової швидкості `ω₀ = 2π · f₀`:

```
σ_t = σ_φ / ω₀ = σ_φ / ( 2π · f₀ )
```

Підставляючи вираз для інтеграла фазового шуму, отримуємо фундаментальну формулу розрахунку часового джиттеру:

```
σ_t = ( 1 / ( 2π · f₀ ) ) · √( 2 · ∫_{f₁}^{f₂} 10^{ L(f) / 10 } df )    [с]
```

### Степенева модель фазового шуму (Power-Law Model)

Спектр фазового шуму реальних кварцових та LC-генераторів описується сумою п'яти класичних шумів зі степеневими нахилами:

```
S_φ(f) = h₀ · f⁰ + h_{-1} · f^{-1} + h_{-2} · f^{-2} + h_{-3} · f^{-3} + h_{-4} · f^{-4}
```

1. `h₀ · f⁰` — білий фазовий шум (White Phase Noise), обумовлений тепловим шумом вихідних буферних каскадів;
2. `h_{-1} · f^{-1}` — фліккер-шум фази (Flicker Phase Noise, 1/f), що виникає в транзисторах підсилювача коливань;
3. `h_{-2} · f^{-2}` — білий частотний шум (White Frequency Noise), породжений тепловим шумом у контурі резонатора (модель Лісона);
4. `h_{-3} · f^{-3}` — фліккер-шум частоти (Flicker Frequency Noise, 1/f³), викликаний флуктуаціями параметрів кристала кварцу;
5. `h_{-4} · f^{-4}` — випадкове блукання частоти (Random Walk Frequency), викликане температурними та механічними градієнтами.

Інтегрування кожного компонента за смугою `[f₁, f₂]` дозволяє аналітично визначити внесок кожної фізичної причини в сумарний часовий джиттер `σ_t`.

## 10. Вплив крутизни фронту (Slew Rate) та шуму вхідних буферів

Часто джерелом додаткового джиттеру є не сам первинний кварцовий генератор, а логічні буфери розподілу тактових сигналів (Clock Distribution Buffers, Fanout Buffers).

Якщо на вхід логічного буфера або тригера Шмітта надходить тактовий сигнал із кінцевою швидкістю наростання `SR = dV_clk / dt` [В/с], будь-який адитивний шум напруги на вході буфера `v_n(t)` з дисперсією `σ_vn²` перетворюється на додатковий часовий джиттер перемикання:

```
σ_t,induced = σ_vn / ( dV_clk / dt ) = σ_vn / SR
```

Для гармонічного тактового сигналу з амплітудою `V_clk` та частотою `f₀` максимальна крутизна в момент перетину порогу становить `SR_max = 2π · f₀ · V_clk`. Тоді індукований джиттер:

```
σ_t,induced = σ_vn / ( 2π · f₀ · V_clk )
```

Звідси випливає важливий практичний висновок: **щоб мінімізувати джиттер вибірки, тактовий сигнал АЦП повинен мати максимально можливу амплітуду та найкрутіші фронти (найвищий Slew Rate)**. Використання пологих синусоїдальних тактових сигналів малої амплітуди перетворює власний шум напруги компаратора АЦП на масивний додатковий апертурний джиттер.

## 11. Дзеркальний ефект джиттеру в цифрово-аналогових перетворювачах (ЦАП)

У цифрово-аналогових перетворювачах (ЦАП) процес відновлення сигналу є дзеркальним до оцифрування. Якщо тактові імпульси оновлення вихідного регістра ЦАП зазнають джиттеру `σ_t`, тривалість кожного аналогового ступеня напруги змінюється на випадкову величину `Δt`.

Ступінчастий вихідний сигнал ЦАП при формуванні синусоїди `V(t)` генерує імпульси похибки площею `ΔA = ΔV_step · Δt`, де `ΔV_step` — різниця напруг між сусідніми відліками.

Оскільки `ΔV_step ≈ (dV/dt) · T_s = (2π · f_out · V₀ · cos(2π · f_out · t)) · T_s`, інтегральна потужність шуму джиттеру на виході ЦАП становить:

```
P_jitter,dac = ( 2π · f_out · V_rms · σ_t )² · ( f_s / 2 )
```

Це доводить, що **деградація SNR у ЦАП підпорядковується абсолютно тій самій формулі, що й в АЦП**:

```
SNR_dac,jitter [дБ] = -20 · lg( 2π · f_out · σ_t )
```

У високочастотних генераторах прямого цифрового синтезу (Direct Digital Synthesizers, DDS) джиттер тактового сигналу `f_clk` безпосередньо визначає фазовий шум та рівень паразитної шумової доріжки вихідного синтезованого радіосигналу на частоті `f_out`.
