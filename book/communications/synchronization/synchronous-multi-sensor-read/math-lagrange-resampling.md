# 🧮 Математика узгодження різночасових вибірок та інтерполяції

Коли система керування роботом або безпілотником об'єднує покази давачів із різними частотами вибірки та незбіжними моментами готовності, виникає потреба обчислити значення фізичної величини в довільний проміжний момент часу. Якщо гіроскоп видає кутову швидкість щомілісекунди (1000 Гц), а магнітометр оновлює вектор індукції лише кожні 10 мс (100 Гц) з плаваючим фазовим зсувом, пряме зіставлення їхніх останніх вибірок вносить похибку розбігу фаз. Цей розбір виводить аналітичні моделі інтерполяції дискретних рядів за поліномами Лагранжа, оцінює фазові спотворення у частотній області та формалізує ретроспективне зведення вимірів у просторі станів розширеного фільтра Калмана.

## Поліноміальна інтерполяція Лагранжа для нерівномірних часових сіток

Нехай маємо впорядкований набір із `n + 1` дискретних вимірювань `(t₀, y₀), (t₁, y₁), …, (tₙ, yₙ)`, де часові мітки `t₀ < t₁ < … < tₙ` зафіксовані апаратними таймерами з мікросекундною роздільністю. Потрібно побудувати неперервну функцію `Pₙ(t)`, яка точно проходить крізь усі опорні точки:

```
Pₙ(tᵢ) = yᵢ,   для всіх i ∈ {0, 1, …, n}
```

Інтерполяційний поліном Лагранжа степеня `n` подається як лінійна комбінація опорних значень `yᵢ`, зважених базисними поліномами `ℓᵢ(t)`:

```
Pₙ(t) = ∑ᵢ₌₀ⁿ yᵢ · ℓᵢ(t)
```

де кожен базисний поліном `ℓᵢ(t)` задовольняє умову дельти Кронекера `ℓᵢ(tⱼ) = 1` при `j = i` та `ℓᵢ(tⱼ) = 0` при `j ≠ i`:

```
ℓᵢ(t) = ∏_{j=0, j≠i}ⁿ (t - tⱼ) / (tᵢ - tⱼ)
```

### Квадратична інтерполяція (три опорні точки, n = 2)

Для зведення показів повільного давача (наприклад, магнітометра чи барометра) до моменту вибірки швидкого IMU найчастіше використовують три сусідні точки `(t₀, y₀), (t₁, y₁), (t₂, y₂)`. Розгорнуті базисні поліноми мають вигляд:

```
ℓ₀(t) = ((t - t₁) · (t - t₂)) / ((t₀ - t₁) · (t₀ - t₂))
ℓ₁(t) = ((t - t₀) · (t - t₂)) / ((t₁ - t₀) · (t₁ - t₂))
ℓ₂(t) = ((t - t₀) · (t - t₁)) / ((t₂ - t₀) · (t₂ - t₁))
```

**Крок за кроком: числовий розрахунок інтерполяції вектора магнітного поля**

Маємо три послідовні виміри напруженості магнітного поля вздовж осі `Y` (в мікротеслах, мкТл), зафіксовані давачем з періодом оновлення близько 10 мс:

- Точка 0: `t₀ = 0.000 с`, `y₀ = 24.20 мкТл`
- Точка 1: `t₁ = 0.010 с`, `y₁ = 25.80 мкТл`
- Точка 2: `t₂ = 0.020 с`, `y₂ = 26.60 мкТл`

Потрібно оцінити значення поля `y(τ)` у момент `τ = 0.014 с`, що відповідає черговому кроку швидкого IMU:

```
ℓ₀(0.014)
= ((0.014 - 0.010) · (0.014 - 0.020)) / ((0.000 - 0.010) · (0.000 - 0.020))  [підстановка вузлів у формулу ℓ₀]
= (0.004 · (-0.006)) / ((-0.010) · (-0.020))                                  [обчислення різниць часу]
= -0.000024 / 0.000200                                                        [множення в чисельнику й знаменнику]
= -0.1200                                                                     [нормований базисний коефіцієнт для t₀]

ℓ₁(0.014)
= ((0.014 - 0.000) · (0.014 - 0.020)) / ((0.010 - 0.000) · (0.010 - 0.020))  [підстановка вузлів у формулу ℓ₁]
= (0.014 · (-0.006)) / (0.010 · (-0.010))                                     [обчислення різниць часу]
= -0.000084 / -0.000100                                                       [множення в чисельнику й знаменнику]
= 0.8400                                                                      [нормований базисний коефіцієнт для t₁]

ℓ₂(0.014)
= ((0.014 - 0.000) · (0.014 - 0.010)) / ((0.020 - 0.000) · (0.020 - 0.010))  [підстановка вузлів у формулу ℓ₂]
= (0.014 · 0.004) / (0.020 · 0.010)                                           [обчислення різниць часу]
= 0.000056 / 0.000200                                                         [множення в чисельнику й знаменнику]
= 0.2800                                                                      [нормований базисний коефіцієнт для t₂]
```

Перевірка нормування ваг: `-0.1200 + 0.8400 + 0.2800 = 1.0000`.

Обчислюємо результуюче інтерпольоване значення `P₂(0.014)`:

```
P₂(0.014)
= y₀ · ℓ₀(0.014) + y₁ · ℓ₁(0.014) + y₂ · ℓ₂(0.014)       [лінійна комбінація базисів Лагранжа]
= 24.20 · (-0.1200) + 25.80 · 0.8400 + 26.60 · 0.2800    [підстановка відліків і обчислених ваг]
= -2.904 + 21.672 + 7.448                                 [зважені внески вузлів]
= 26.216 мкТл                                             [підсумкова інтерпольована величина]
```

Порівняння з лінійною інтерполяцією між точками `t₁` та `t₂`:

```
y_lin(0.014)
= y₁ + (y₂ - y₁) · (0.014 - 0.010) / (0.020 - 0.010)     [лінійне відрізкове наближення між t₁ та t₂]
= 25.80 + 0.80 · (0.004 / 0.010)                         [підстановка значень у різницю вимірів]
= 25.80 + 0.32                                           [масштабування кроку приросту]
= 26.120 мкТл                                            [лінійна оцінка в точці 0.014 с]
```

Різниця між квадратичною та лінійною оцінками складає `0.096 мкТл`. При високих кутових швидкостях обертання ця різниця зростає пропорційно квадрату частоти обертання, що безпосередньо впливає на точність оцінки курсу (yaw).

## Кубічні сплайни Ерміта для збереження гладкості похідних

Хоча поліном Лагранжа забезпечує точний збіг у вузлах, на межах сусідніх трійок точок перша похідна `dP/dt` має розрив. Для інерційних алгоритмів навігації стрибки похідної вимірюваного сигналу діють як штучні високочастотні збурення.

Щоб гарантувати неперервність як самого сигналу, так і його першої похідної (`C¹`-гладкість), застосовують кубічну інтерполяцію Ерміта (*Cubic Hermite Spline*).

На інтервалі `t ∈ [t₁, t₂]` нормований локальний час задається як:

```
u = (t - t₁) / (t₂ - t₁),   де u ∈ [0, 1]
```

Інтерполяційний поліном будується на основі значень у вузлах `y₁, y₂` та оцінок дотичних (похідних) `m₁, m₂`:

```
S(u) = h₀₀(u) · y₁ + h₁₀(u) · (t₂ - t₁) · m₁ + h₀₁(u) · y₂ + h₁₁(u) · (t₂ - t₁) · m₂
```

де базисні функції Ерміта мають вигляд:

```
h₀₀(u) = 2 · u³ - 3 · u² + 1
h₁₀(u) = u³ - 2 · u² + u
h₀₁(u) = -2 · u³ + 3 · u²
h₁₁(u) = u³ - u²
```

Для нерівномірної часової сітки дотичні у вузлах оцінюються за схемою Катмулла–Рома (*Catmull-Rom spline*) через центральні скінченні різниці:

```
m₁ = (y₂ - y₀) / (t₂ - t₀)
m₂ = (y₃ - y₁) / (t₃ - t₁)
```

**Числовий розрахунок для кубічного сплайна**

Нехай додано четверту точку вимірювання магнітометра:
- Точка 3: `t₃ = 0.030 с`, `y₃ = 27.00 мкТл`

Обчислюємо похідні у внутрішніх вузлах `t₁` та `t₂`:

```
m₁
= (26.60 - 24.20) / (0.020 - 0.000)                       [центральна різниця для вузла t₁]
= 2.40 / 0.020                                            [обчислення приросту за інтервал]
= 120.0 мкТл/с                                            [оцінка швидкості зміни поля]

m₂
= (27.00 - 25.80) / (0.030 - 0.010)                       [центральна різниця для вузла t₂]
= 1.20 / 0.020                                            [обчислення приросту за інтервал]
= 60.0 мкТл/с                                             [оцінка швидкості зміни поля]
```

Для моменту часу `τ = 0.014 с` нормована змінна:

```
u
= (0.014 - 0.010) / (0.020 - 0.010)                       [нормування локального часу інтервалу]
= 0.004 / 0.010                                           [відносне зміщення точки]
= 0.40                                                    [значення параметра u]
```

Обчислюємо базисні функції для `u = 0.40`:

```
h₀₀(0.4) = 2 · (0.4)³ - 3 · (0.4)² + 1 = 2 · 0.064 - 3 · 0.16 + 1 = 0.128 - 0.48 + 1 = 0.648
h₁₀(0.4) = (0.4)³ - 2 · (0.4)² + 0.4 = 0.064 - 0.32 + 0.4 = 0.144
h₀₁(0.4) = -2 · (0.4)³ + 3 · (0.4)² = -0.128 + 0.48 = 0.352
h₁₁(0.4) = (0.4)³ - (0.4)² = 0.064 - 0.16 = -0.096
```

Обчислюємо значення кубічного сплайна:

```
S(0.4)
= 0.648 · 25.80 + 0.144 · 0.010 · 120.0 + 0.352 · 26.60 + (-0.096) · 0.010 · 60.0  [підстановка базисів і похідних]
= 16.7184 + 0.1728 + 9.3632 - 0.0576                                                [обчислення зважених компонентів]
= 26.1968 мкТл                                                                       [сплайнова оцінка]
```

Кубічний сплайн дає `26.197 мкТл`, що на `0.077 мкТл` точніше за лінійну інтерполяцію та зберігає неперервність кутового прискорення при вході у фільтр орієнтації.

## Частотний аналіз та фазові спотворення інтерполяційних ядер

Щоб зрозуміти поведінку інтерполятора в динаміці, розглянемо його як неперервно-дискретний лінійний фільтр із власною передавальною функцією `H(jω)`.

Нехай вхідний сигнал `x(t)` дискретизується з періодом `T`. Відновлення сигналу в проміжній точці `t = k · T + τ` (де `0 ≤ τ < T`) через лінійну інтерполяцію відповідає згортці дискретного сигналу з трикутним інтерполяційним ядром `h₁(t)`:

```
h₁(t) = 1 - |t| / T,   при |t| ≤ T
h₁(t) = 0,             при |t| > T
```

Перетворення Фур'є цього ядра дає амплітудно-частотну характеристику:

```
H₁(jω) = T · (sin(ω · T / 2) / (ω · T / 2))² = T · sinc²(ω · T / 2)
```

Для сигналу частоти `ω` лінійна інтерполяція вносить дві похибки:
1. **Амплітудне затухання:** на частоті Найквіста `ω_N = π / T` коефіцієнт передачі падає до `sinc²(π/2) = (2/π)² ≈ 0.405` (-7.85 дБ). Високочастотні коливання відчутно згладжуються.
2. **Фазовий зсув (затримка групи):** фазова характеристика лінійного інтерполятора між двома точками вносить затримку `τ_group = T / 2`.

При застосуванні кубічного сплайна Ерміта (який забезпечує неперервність першої похідної `C¹`) передавальна характеристика інтерполятора стає значно ближчою до ідеального прямокутного фільтра:

```
H₃(jω) = T · sinc⁴(ω · T / 2) · (1 + 2 · sin²(ω · T / 2))
```

На частотах до `0.3 · ω_N` кубічний сплайн зберігає амплітуду з точністю вище 98.5 %, а фазова похибка зменшується у 4–6 разів порівняно з лінійним наближенням.

## Аліасинг при децимації та антиаліасингова фільтрація

Коли високочастотні дані (наприклад, IMU на частоті 8 кГц) зводяться до частоти навігаційного фільтра (наприклад, 250 Гц), проста вибірка кожного 32-го відліку (*downsampling*) призводить до накладання спектрів (аліасингу). Вібрації двигунів на частотах 300–800 Гц дзеркально відбиваються в робочу смугу контуру керування (0–30 Гц) у вигляді хибних низькочастотних коливань.

Щоб запобігти аліасингу перед децимацією, обов'язково застосовують цифровий поліфазний фільтр низьких частот із нулями на частотах гармонік дискретизації:

```
y_decim[k] = ∑_{m=0}^{M-1} w[m] · x[k · D - m]
```

де `D` — коефіцієнт децимації (`D = 8000 / 250 = 32`), `w[m]` — коефіцієнти вікна Кайзера або Хеммінга. Це гарантує придушення високочастотного шуму на рівні не менше -60 дБ до моменту передачі у фільтр Калмана.

## Обмеження екстраполяції та розбіжність дисперсії

Фундаментальною відмінністю інтерполяції від екстраполяції є поведінка похибки за межами інтервалу спостереження. Якщо спробувати спрогнозувати значення сигналу вперед на час `t > t_n` за поліномом степеня `n`, похибка за формулою Коші починає зростати степенево:

```
R_extrap(t) ∝ (t - t_n)^{n+1}
```

Будь-який невеликий шум вимірювання у вузлах `y_i` при екстраполяції викликає катастрофічний розгін значень. Саме тому в алгоритмах об'єднання сенсорів екстраполяцію вимірів ніколи не використовують безпосередньо. Замість цього екстраполюють не самі виміри, а вектор стану системи за допомогою повної фізичної моделі руху в фільтрі Калмана, де зростання невизначеності природно обмежується матрицею коваріації шуму процесу `Q`.

## Теоретична похибка апроксимації та вибір степеня полінома

Якщо вимірюваний фізичний процес описується неперервно диференційовною функцією `f(t) ∈ Cⁿ⁺¹[t₀, tₙ]`, то залишковий член інтерполяції (похибка апроксимації) у точці `t` визначається формулою Коші:

```
Rₙ(t) = f(t) - Pₙ(t) = (f⁽ⁿ⁺¹⁾(ξ) / (n + 1)!) · ∏ᵢ₌₀ⁿ (t - tᵢ)
```

де `ξ` — деяка невідома точка всередині інтервалу `[t₀, tₙ]`.

Для гармонічного коливального сигналу `f(t) = A · sin(ω · t + φ)` максимум `(n+1)`-ї похідної дорівнює:

```
max |f⁽ⁿ⁺¹⁾(ξ)| = A · ωⁿ⁺¹
```

Якщо крок дискретизації є сталим `h = tᵢ₊₁ - tᵢ`, то добуток різниць для внутрішньої точки `t ∈ [t₀, tₙ]` обмежений зверху величиною `Cₙ · hⁿ⁺¹`, де константа `Cₙ` залежить від порядку `n`:

- Для лінійної інтерполяції (`n = 1`):
```
|R₁(t)| ≤ (A · ω² · h²) / 8
```

- Для квадратичної інтерполяції (`n = 2`):
```
|R₂(t)| ≤ (A · ω³ · h³) / (9 · √3) ≈ 0.0641 · A · ω³ · h³
```

- Для кубічної інтерполяції Ерміта або Лагранжа (`n = 3`):
```
|R₃(t)| ≤ (A · ω⁴ · h⁴) / 24 ≈ 0.0417 · A · ω⁴ · h⁴
```

Звідси видно закон згасання похибки: підвищення порядку інтерполяції на одиницю зменшує амплітудну похибку пропорційно множнику `(ω · h)`. Оскільки для коректної дискретизації за теоремою Найквіста–Котельникова частота вибірки значно перевищує смугу сигналу (`ω · h ≪ 1`), квадратичний або кубічний поліном забезпечує придушення інтерполяційного шуму на 20–40 дБ краще за лінійне з'єднання.

Однак вибір степеня `n > 3` у реальному часі є небажаним через феномен Рунге (хвилеподібні сплески полінома на краях інтервалу при нерівномірних вузлах) та чутливість вищих похідних до адитивного шуму давача `w_k ~ N(0, σ²)`.

## Поширення дисперсії фазового розбігу в рівняннях орієнтації

Розглянемо, як несинхронність вибірок трансформується у похибку оцінки положення. Нехай гіроскоп вимірює вектор кутової швидкості `ω(t)`, а акселерометр — вектор питомої сили `a(t)`.

У рухомій системі координат апарата швидкість зміни вектора виміряного прискорення внаслідок власного обертання описується рівнянням Кориоліса:

```
da/dt = ȧ_body + ω × a
```

Якщо акселерометр зчитано з запізненням `Δt` відносно гіроскопа, фактично виміряний вектор `a_meas` пов'язаний з істинним вектором `a(t)` лінійним наближенням:

```
a_meas(t + Δt) ≈ a(t) + (da/dt) · Δt = a(t) + (ȧ_body + ω × a) · Δt
```

Похибка фазового розбігу `δa(Δt)` дорівнює:

```
δa(Δt) = a_meas(t + Δt) - a(t) ≈ (ȧ_body + ω × a) · Δt
```

Під час енергійного маневру БПЛА (наприклад, кутова швидкість крену `ω = 4.0 рад/с` ≈ 230°/с, вектор прискорення спрямований вгору `a = [0, 0, -9.81] м/с²`), фазовий розбіг `Δt = 2.5 мс` генерує паразитне тангенціальне прискорення:

```
|δa|
≈ |ω| · |a| · Δt                                          [амплітуда перехресного добутку ω × a]
= 4.0 · 9.81 · 0.0025                                     [підстановка параметрів маневру]
= 0.0981 м/с²                                             [паразитне тангенціальне прискорення]
```

Це паразитне прискорення `0.1 м/с²` фільтр орієнтації сприймає як реальний нахил апарата. Кутова похибка оцінки горизонту `δθ` становить:

```
δθ
≈ |δa| / |a|                                              [наближення малого кута нахилу]
= |ω| · Δt                                                [скорочення модуля прискорення |a|]
= 4.0 · 0.0025                                            [підстановка кутової швидкості й розбігу]
= 0.010 рад ≈ 0.57°                                       [кутова похибка оцінки горизонту]
```

Інтегрування такої систематичної помилки орієнтації протягом 5 секунд призводить до лінійної похибки швидкості `δv = g · sin(δθ) · t ≈ 9.81 · 0.010 · 5 ≈ 0.49 м/с` та координатної похибки понад 1.2 метра.

Коваріаційна матриця похибки через випадковий джиттер часового зсуву `Δt ~ N(0, σ²_Δt)` має вигляд:

```
Σ_skew = E[δa · δaᵀ] = (ω × a) · (ω × a)ᵀ · σ²_Δt
```

Цей результат доводить: у високодинамічних системах випадковий джиттер шини перетворюється на анізотропний шум вимірювань, дисперсія якого квадратично зростає зі збільшенням кутової швидкості апарата.

## Аналітична модель цифрової системи фазового автопідстроювання (DPLL)

Коли сенсор не має зовнішнього тактування, його внутрішній RC-генератор плавно дрейфує за температурою. Щоб знати точний період між вибірками `T_k` у масштабі таймера мікроконтролера, прошивка реалізує програмну систему фазового автопідстроювання (DPLL — *Digital Phase-Locked Loop*).

Нехай `t_{drdy, k}` — апаратно захоплена мітка `k`-го імпульсу DRDY, а `t̂_k` — прогнозований час цього імпульсу. Помилка фази визначається як:

```
ε_k = t_{drdy, k} - t̂_k
```

Дискретний пропорційно-інтегральний фільтр петлі коригує оцінку поточної частоти давача `f̂_k` та фази наступного відліку `t̂_{k+1}`:

```
f̂_{k+1} = f̂_k + K_i · ε_k
t̂_{k+1} = t̂_k + 1 / f̂_{k+1} + K_p · ε_k
```

де `K_p` та `K_i` — коефіцієнти підсилення пропорційної та інтегральної ланок.

Характеристичне рівняння другого порядку в Z-області має вигляд:

```
z² - (2 - K_p - K_i) · z + (1 - K_p) = 0
```

Умови стійкості петлі за критерієм Шура–Кона накладають обмеження на коефіцієнти:

```
0 < K_i < K_p < 2 - K_i / 2
```

При виборі `K_p = 0.05` та `K_i = 0.002` смуга пропускання DPLL становить близько 2–5 Гц. Це дозволяє петлі плавно відстежувати тепловий дрейф кварцу давача, повністю відфільтровуючи високочастотний мікросекундний джиттер лінії DRDY.

## Аугментація станів (State Cloning) для запізнілих вимірювань у EKF

Альтернативою перепрограванню всього буфера є математичний метод аугментації вектора стану (*State Augmentation / Stochastic Cloning*). Він використовується у навігаційних системах, де часова затримка давача `τ_delay` є відомою константою (наприклад, апаратна затримка обробки відеопотоку оптичного потоку або стереокамери).

### Розширення вектора стану

Нехай поточний вектор стану системи в момент `t_k` є `x_k ∈ ℝⁿ`. Якщо вимірювання запізнюється рівно на `d` дискретних тактів (`t_meas = t_{k-d}`), вектор стану фільтра Калмана штучно розширюється за рахунок збереження історичної копії:

```
X_k = [ x_k; x_{k-d} ] ∈ ℝ²ⁿ
```

Матриця коваріації розширеного стану має блочну структуру:

```
P_k = [ P_{k, k}      P_{k, k-d}   ]
      [ P_{k-d, k}    P_{k-d, k-d} ]
```

### Рівняння переходу розширеного стану

На кожному швидкому кроці прогнозу IMU поточний стан еволюціонує згідно з матрицею переходу `F_k`, а клонований історичний стан залишається замороженим:

```
X_{k+1|k} = [ F_k    0 ] · [ x_k     ]
            [ 0      I ]   [ x_{k-d} ]
```

Матриця коваріації прогнозу оновлюється за правилом:

```
P_{k+1|k} = [ F_k · P_{k, k} · F_kᵀ + Q_k     F_k · P_{k, k-d} ]
            [ P_{k-d, k} · F_kᵀ               P_{k-d, k-d}     ]
```

Зверніть увагу на недіагональний блок взаємної коваріації `F_k · P_{k, k-d}`: він фіксує кореляцію між поточним положенням апарата та його минулим станом `d` кроків тому.

### Корекція запізнілим вимірюванням

Коли надходить вимір `z_{delayed} = h(x_{k-d}) + v_k`, матриця спостереження застосовується безпосередньо до клонованого блоку вектора стану:

```
H_aug = [ 0,  H_meas ]
```

Обчислення коефіцієнта підсилення Калмана:

```
S = H_aug · P_{k+1|k} · H_augᵀ + R = H_meas · P_{k-d, k-d} · H_measᵀ + R
K_aug = P_{k+1|k} · H_augᵀ · S⁻¹ = [ P_{k, k-d} · H_measᵀ · S⁻¹     ]
                                   [ P_{k-d, k-d} · H_measᵀ · S⁻¹   ]
```

Верхній блок вектора підсилення `K_now = P_{k, k-d} · H_measᵀ · S⁻¹` безпосередньо коригує *поточний стан* `x_k` на основі нев'язки запізнілого виміру без необхідності повторного інтегрування рівнянь руху. Це забезпечує оптимальну за критерієм мінімуму середньоквадратичної похибки оцінку траєкторії в реальному часі.

## Ретроспективне оновлення станів у розширеному фільтрі Калмана (EKF)

Коли вимірювання від низькочастотного давача (наприклад, GNSS-приймача чи далекоміра) надходить із затримкою передачі `t_delay`, поточний час системи є `t_now`, а вимір фактично відповідає моменту `t_meas = t_now - t_delay`.

Замість екстраполяції запізнілого виміру вперед (що вносить нестабільність через множення шуму на похідні), сучасні навігаційні EKF (зокрема EKF3 в ArduPilot та ECL в PX4) застосовують ретроспективне зведення з буфером станів.

### Структура кільцевого буфера навігаційних станів

Вектор стану `x ∈ ℝ²⁴` містить орієнтацію (кватерніон `q`), лінійну швидкість `v`, координати `p`, зсуви гіроскопів `b_g` та акселерометрів `b_a`.

На кожному швидкому такті IMU `t_k` (1 кГц) виконується пряме інтегрування кінематики:

```
x̂_{k|k-1} = f(x̂_{k-1|k-1}, u_{k-1})
P_{k|k-1} = F_{k-1} · P_{k-1|k-1} · F_{k-1}ᵀ + Q_{k-1}
```

де `u_{k-1} = [a_{k-1}, ω_{k-1}]` — синхронізована вибірка IMU, `F_{k-1} = ∂f/∂x` — матриця Якобі переходу станів, `Q` — коваріація шуму процесу.

Стани `x̂_{k|k-1}` та супутні змінні записуються в кільцевий буфер фіксованої глибини `M` (наприклад, `M = 250` кроків для покриття затримок до 250 мс).

### Алгоритм корекції запізнілим виміром

Нехай у момент `t_now = t_k` надійшов вектор вимірювань `z_meas` із точною апаратною міткою часу `t_meas ∈ [t_{m}, t_{m+1}]`.

1. **Пошук найближчого стану в буфері:**
   Знаходимо індекс `m` у буфері, такий що `t_m ≈ t_meas`. Якщо мітка лежить між дискретами, обчислюється коефіцієнт інтерполяції `α = (t_meas - t_m) / (t_{m+1} - t_m)` і формується інтерпольований історичний стан:

   ```
   x̂_hist = (1 - α) · x̂_m + α · x̂_{m+1}
   ```

2. **Обчислення нев'язки (інновації) на історичному кроці:**
   ```
   y = z_meas - h(x̂_hist)
   ```
   де `h(x)` — функція спостереження (наприклад, проєкція координат GNSS або матриця спрямування на магнітний вектор).

3. **Коваріація інновації та коефіцієнт підсилення Калмана:**
   ```
   H = ∂h/∂x |_{x̂_hist}
   S = H · P_hist · Hᵀ + R
   K = P_hist · Hᵀ · S⁻¹
   ```
   де `R` — коваріація шуму самого давача.

4. **Оновлення вектора приросту стану:**
   ```
   Δx_corr = K · y
   P_m⁺ = (I - K · H) · P_hist
   ```

5. **Пряме перепрогравання (Fast-Forward Re-propagation):**
   Щоб не втратити накопичену інформацію від швидких давачів, вектор поправки `Δx_corr` транслюється вперед від кроку `m` до поточного кроку `k` за допомогою матриці переходу траєкторії:

   ```
   Φ_{k, m} = ∏_{j=m}^{k-1} F_j
   Δx_now = Φ_{k, m} · Δx_corr
   x̂_now⁺ = x̂_now + Δx_now
   ```

Завдяки збереженню повної історії кінематичного тракту такий ретроспективний підхід усуває фазовий зсув вимірювань без внесення фазового випередження чи фільтраційної затримки в контур стабілізації апарата.
