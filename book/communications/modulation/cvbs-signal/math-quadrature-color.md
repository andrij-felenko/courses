# 🧮 Квадратурна модуляція колірної піднесучої та спектральне переплетення

Вставка деталізує математичний апарат розкладу колірного сигналу, перетворення матриць RGB у YUV та YIQ, квадратурну амплітудну модуляцію (QAM), когерентну демодуляцію з фазовою синхронізацією, геометричний аналіз векторскопа для колірних смуг, математику декодерів PAL-D/PAL-S та доказ точного співвідношення частоти колірної піднесучої для систем NTSC та PAL.

### Перетворення колірного простору RGB у YUV

Перед передачею кольорового відео три базові сигнали червоного `R`, зеленого `G` та синього `B` перераховують у колірний простір, що складається з монохромного сигналу яскравості `Y` (*Luminance*) та двох колірно-різницевих сигналів `U` і `V` (*Chrominance*). Сигнал яскравості відповідає фотометричній чутливості людського ока до різних довжин хвиль (стандарт ITU-R BT.601):

```
Y = 0.299·R + 0.587·G + 0.114·B         [вважений фотометричний сумарний сигнал]
```

Колірно-різницеві сигнали утворюються шляхом віднімання яскравості `Y` від синьої та червоної компонент:

```
B - Y = B - (0.299·R + 0.587·G + 0.114·B)   [віднімання яскравості з B]
      = -0.299·R - 0.587·G + 0.886·B        [групування коефіцієнтів біля R, G, B]

R - Y = R - (0.299·R + 0.587·G + 0.114·B)   [віднімання яскравості з R]
      =  0.701·R - 0.587·G - 0.114·B        [групування коефіцієнтів біля R, G, B]
```

Щоб запобігти перевантаженню амплітудного тракту передавача, відносні амплітуди `(B - Y)` та `(R - Y)` нормують коефіцієнтами стиснення `W[B]` та `W[R]`:

```
U = W[B] · (B - Y)                          [масштабування синього різницевого сигналу]
V = W[R] · (R - Y)                          [масштабування червоного різницевого сигналу]
```

Значення коефіцієнтів `W[B] = 0.492111` та `W[R] = 0.877283` обрані з умов обмеження максимального відхилення сумарного колірного сигналу `Y + C` у межах від `-40 IRE` до `+133 IRE` для будь-якого чистого кольору зі 100% насиченістю:

```
W[B] = 0.5 / (1 - 0.114) = 0.5 / 0.886 = 0.492111    [нормування розмаху сигналу U]
W[R] = 0.5 / (1 - 0.299) = 0.5 / 0.701 = 0.877283    [нормування розмаху сигналу V]
```

У прямій матричній формі перетворення `RGB → YUV` записується так:

```
[ Y ]   [  0.2990  0.5870  0.1140 ]   [ R ]
[ U ] = [ -0.1471 -0.2889  0.4360 ] · [ G ]     [пряме матричне перетворення RGB у YUV]
[ V ]   [  0.6150 -0.5150 -0.1000 ]   [ B ]
```

Для відновлення первинних сигналів `R`, `G`, `B` у приймачі виконують обернене матричне перетворення `YUV → RGB`:

```
R = Y + 1.13983·V                           [відновлення червоного каналу]
G = Y - 0.39465·U - 0.58060·V               [відновлення зеленого каналу]
B = Y + 2.03211·U                           [відновлення синього каналу]

[ R ]   [ 1.00000  0.00000  1.13983 ]   [ Y ]
[ G ] = [ 1.00000 -0.39465 -0.58060 ] · [ U ]   [обернена матриця відновлення RGB]
[ B ]   [ 1.00000  2.03211  0.00000 ]   [ V ]
```

### Алгебра колірного простору YIQ (стандарт NTSC)

В оригінальному стандарті NTSC замість вісей `U` та `V` застосували повернуту на кут `33°` систему координат `I` (*In-phase*) та `Q` (*Quadrature*). Такий вибір обґрунтовано фізіологією людського зору: око має значно вищу просторову роздільність уздовж вісі «оранжевий — блакитний» (сигнал `I`), ніж уздовж вісі «пурпуровий — зелений» (сигнал `Q`). Це дозволило звузити смугу частот сигналу `Q` до `0.5 МГц`, а сигналу `I` — залишити `1.3 МГц`, що суттєво зекономило спектральну смугу каналу.

Зв'язок між вісями `(I, Q)` та `(U, V)` задається поворотом системи координат на кут `θ = 33°` (`0.575958` рад):

```
I =  V·cos(33°) - U·sin(33°)               [поворот вісі V на 33 градуси]
  =  0.877283·(R - Y)·0.838671 - 0.492111·(B - Y)·0.544639    [підстановка точних значень cos та sin]
  =  0.7358·(R - Y) - 0.2680·(B - Y)       [лінійна комбінація колірно-різницевих сигналів]

Q =  V·sin(33°) + U·cos(33°)               [поворот вісі U на 33 градуси]
  =  0.877283·(R - Y)·0.544639 + 0.492111·(B - Y)·0.838671    [підстановка точних значень sin та cos]
  =  0.4778·(R - Y) + 0.4127·(B - Y)       [лінійна комбінація колірно-різницевих сигналів]
```

У прямому матричному вигляді перетворення `RGB → YIQ` виражається так:

```
[ Y ]   [  0.29900  0.58700  0.11400 ]   [ R ]
[ I ] = [  0.59590 -0.27410 -0.32180 ] · [ G ]  [пряме матричне перетворення RGB у YIQ]
[ Q ]   [  0.21150 -0.52260  0.31110 ]   [ B ]
```

Обернене перетворення `YIQ → RGB` для декодера NTSC задається оберненою матрицею:

```
R = Y + 0.9563·I + 0.6210·Q                [відновлення R з Y, I, Q]
G = Y - 0.2721·I - 0.6474·Q                [відновлення G з Y, I, Q]
B = Y - 1.1070·I + 1.7046·Q                [відновлення B з Y, I, Q]

[ R ]   [ 1.00000  0.95630  0.62100 ]   [ Y ]
[ G ] = [ 1.00000 -0.27210 -0.64740 ] · [ I ]   [обернена матриця декодування NTSC]
[ B ]   [ 1.00000 -1.10700  1.70460 ]   [ Q ]
```

### Квадратурна амплітудна модуляція піднесучої

Для передачі обох сигналів `U` та `V` (або `I` та `Q`) через один аналоговий канал застосовують квадратурну амплітудну модуляцію (*Quadrature Amplitude Modulation*, QAM) із пригніченою піднесучою частотою `f[sc]`. Сигнал `U` амплітудно модулює синфазну піднесучу `sin(ω[sc]·t)`, а сигнал `V` — квадратурну піднесучу `cos(ω[sc]·t)`, зсунуту за фазою на `90°` (`π/2` рад):

```
C(t) = U(t)·sin(ω[sc]·t) + V(t)·cos(ω[sc]·t)     [квадратурний колірний сигнал]
```

де `ω[sc] = 2·π·f[sc]` — колово-частотна піднесуча (`3.579545 МГц` у NTSC або `4.43361875 МГц` у PAL).

Використовуючи тригонометричну тотожність для суми синуса й косинуса, сумарний колірний сигнал `C(t)` можна подати в полярній формі через миттєву амплітуду `A(t)` та миттєву фазу `φ(t)`:

```
C(t) = A(t)·sin(ω[sc]·t + φ(t))          [полярна форма квадратурної модуляції]

A(t) = √(U²(t) + V²(t))                  [амплітуда = насиченість кольору, Saturation]
φ(t) = arctan(V(t) / U(t))               [фаза = колірний тон, Hue]
```

Амплітуда `A(t)` визначає насиченість кольору (*Saturation*): чим більша амплітуда піднесучої, тим чистіший і яскравіший колір. Фаза `φ(t)` визначає колірний тон (*Hue*).

### Геометрія векторскопа та розрахунок тестових колірних смуг

На вимірювальному приладі — векторскопі — сигнал `U` подається на горизонтальне відхилення `X`, а сигнал `V` — на вертикальне відхилення `Y`. Для стандартного випробувального сигналу 75% колірних смуг (*75% Color Bars*) точні значення параметрів `Y`, `U`, `V`, амплітуди `A` та фазового кута `φ` розраховуються за формулами нормування:

```
R=1, G=1, B=0 (Жовтий):   Y = 0.886,  U = -0.436, V =  0.100, A = 0.447, φ = 167.1°  [жовтий сектор]
R=0, G=1, B=1 (Блакитний):Y = 0.701,  U =  0.147, V = -0.615, A = 0.633, φ = 283.5°  [блакитний сектор]
R=0, G=1, B=0 (Зелений):  Y = 0.587,  U = -0.289, V = -0.515, A = 0.590, φ = 240.7°  [зелений сектор]
R=1, G=0, B=1 (Пурпурний):Y = 0.413,  U =  0.289, V =  0.515, A = 0.590, φ =  60.7°  [пурпурний сектор]
R=1, G=0, B=0 (Червоний): Y = 0.299,  U = -0.147, V =  0.615, A = 0.633, φ = 103.5°  [червоний сектор]
R=0, G=0, B=1 (Синій):    Y = 0.114,  U =  0.436, V = -0.100, A = 0.447, φ = 347.1°  [синій сектор]
```

Для 75% насиченості значення амплітуди `A` множать на `0.75`. Максимальний розмах амплітуди `A[max] = 0.633` спостерігається для червоного та блакитного кольорів, що дає розмах піднесучої `2 · 0.633 = 1.266` (близько `88 IRE` від піку до піку).

### Синхронізація й когерентне демодулювання

Оскільки піднесуча передається із пригніченим носієм (амплітуда `C(t) = 0` у сірих і білих ділянках кадру), приймач повинен мати місцевий гетеродин, синхронізований за частотою й фазою. Для фіксації фази на задньому майданчику кожного рядкового гасіння (*Back Porch*) передається спалах колірної піднесучої (*Color Burst*) — `8–10` періодів опорного коливання з постійною фазою `180°` відносно фази `U` (у NTSC) або зі зміною фази `135°` / `225°` на кожному наступному рядку (у PAL).

Якщо місцевий гетеродин приймача має фазову помилку `Δθ`, відтворені сигнали `U_demod` та `V_demod` отримують взаємні завади (*cross-talk*):

```
U_demod = [U·sin(ω[sc]·t) + V·cos(ω[sc]·t)] · sin(ω[sc]·t + Δθ)   [перемноження в декодері]
        = U·sin(ω[sc]·t)·sin(ω[sc]·t + Δθ) + V·cos(ω[sc]·t)·sin(ω[sc]·t + Δθ)   [розкриття суми]
        = (U/2)·[cos(Δθ) - cos(2ω[sc]·t + Δθ)] + (V/2)·[sin(2ω[sc]·t + Δθ) + sin(Δθ)]  [тригонометричні добутки]
        → (U/2)·cos(Δθ) + (V/2)·sin(Δθ)                           [після НЧ-фільтрації 1.3 МГц]

V_demod → (V/2)·cos(Δθ) - (U/2)·sin(Δθ)                           [після НЧ-фільтрації 1.3 МГц]
```

При `Δθ = 0` вихідний сигнал дорівнює точно `U/2` та `V/2`. Натомість при фазовій помилці `Δθ ≠ 0` виникає перехресне проникання каналів: у NTSC це призводить до спотворення відтінків кольору (*hue shift*).

### Математика PAL декодерів: PAL-S проти PAL-D

У системі PAL фаза компоненти `V` інвертується на кожному другому рядку:

```
C[m](t)   =  U(t)·sin(ω[sc]·t) + V(t)·cos(ω[sc]·t)    [сигнал на рядку m з фазою +V]
C[m+1](t) =  U(t)·sin(ω[sc]·t) - V(t)·cos(ω[sc]·t)    [сигнал на рядку m+1 з фазою -V]
```

#### Простий декодер PAL (PAL-S / Simple PAL)

Декодер PAL-S не має апаратної лінії затримки і здійснює демодуляцію безпосередньо. При наявності фазової помилки `Δθ` в гетеродина виходить:

```
V_demod[m]   =  V·cos(Δθ) - U·sin(Δθ)              [помилка демодуляції на рядку m]
V_demod[m+1] = -V·cos(Δθ) - U·sin(Δθ)              [помилка демодуляції на рядку m+1]
```

При інверсії знаку `V` для рядка `m+1` отримана колірно-різницева величина стає `V' = V·cos(Δθ) + U·sin(Δθ)`. На двох сусідніх рядках виникає протилежна помилка відтінку `+Δφ` та `-Δφ`. Завдяки просторовому інтегруванню оком людини два відтінки усереднюються, усуваючи зсув кольору, але виникає малопомітна структурована завада у вигляді горизонтальних смуг насиченості — «ганноверські смуги» (*Hanover Bars*).

#### Удосконалений декодер PAL із лінією затримки (PAL-D / Delay PAL)

В декодері PAL-D вхідний сигнал розщеплюється на два канали: прямий та затриманий на час одного рядка `T[H] = 64 мкс` за допомогою ультразвукової лінії затримки на склі або цифрового FIFO-буфера.

Отримані сума та різниця двох рядків забезпечують повне математичне розділення компонент `U` та `V`:

```
C_sum(t)  = 0.5 · [ C[m](t) + C[m+1](t) ]
          = 0.5 · [ U·sin(ω[sc]·t) + V·cos(ω[sc]·t) + U·sin(ω[sc]·t) - V·cos(ω[sc]·t) ] [підстановка]
          = U·sin(ω[sc]·t)                        [ідеальне виділення U-каналу]

C_diff(t) = 0.5 · [ C[m](t) - C[m+1](t) ]
          = 0.5 · [ U·sin(ω[sc]·t) + V·cos(ω[sc]·t) - (U·sin(ω[sc]·t) - V·cos(ω[sc]·t)) ] [підстановка]
          = V·cos(ω[sc]·t)                        [ідеальне виділення V-каналу]
```

При наявності фазової помилки `Δθ` амплітуди компонент просто зменшуються на косинусоїдальний множник `cos(Δθ)`, що викликає лише мікроскопічне зниження насиченості кольору без будь-якої зміни відтінку чи появи ганноверських смуг!

### Математичний розрахунок частоти колірної піднесучої NTSC (3.579545 МГц)

В оригінальному чорно-білому стандарті NTSC (525 рядків, 60 Гц) частота рядкової розгортки дорівнювала `f[H,bw] = 15750 Гц`, а звукова піднесуча становила `f[sound] = 4.5 МГц`. 

Під час додавання колірної піднесучої `f[sc]` було виявлено заваду у вигляді биття між колірною піднесучою та звуковою піднесучою на різницевій частоті `f[sound] - f[sc]`. Щоб мінімізувати це биття та зробити заваду непомітною, різниця між звуковою та колірною частотами має бути точно напівкратна від рядкової частоти `f[H]`:

```
f[sound] - f[sc] = (m + 1/2) · f[H]        [умова спектрального переплетення зі звуком]
```

Одночасно колірна піднесуча `f[sc]` має бути напівкратною від рядкової частоти для переплетення із гармоніками яскравості:

```
f[sc] = (n + 1/2) · f[H]                   [умова спектрального переплетення з яскравістю]
```

Додаючи ці два рівняння, отримуємо, що частота звукової піднесучої `f[sound]` має бути строго цілочисельно кратною від рядкової частоти `f[H]`:

```
f[sound] = (n + m + 1) · f[H] = K · f[H]   [ціле кратне число гармонік]
```

Комітет NTSC обрав ціле число `K = 286`. Звідси точна нова частота рядкової розгортки `f[H]` для кольорового NTSC дорівнює:

```
f[H] = f[sound] / 286 = 4 500 000 Гц / 286  [ділення звукової піднесучої на 286]
     = 15 734.265734... Гц                  [точна рядкова частота NTSC]
```

Для колірної піднесучої було обрано число `n = 227`, тобто коефіцієнт `n + 1/2 = 227.5 = 455 / 2`:

```
f[sc] = 227.5 · f[H] = (455 / 2) · (4 500 000 / 286) Гц   [напівкратний співвідношення]
      = (455 · 4 500 000) / 572 Гц                       [спрощення дробу]
      = 2 047 500 000 / 572 Гц                           [точності обчислення числівника]
      = 3 579 545.4545... Гц                             [точна частота піднесучої NTSC]
```

При цьому точна кадрова частота `f[frame]` для 525 рядків розгортки становить:

```
f[frame] = f[H] / 525 = 15 734.265734 / 525 Гц    [ділення на кількість рядків у кадрі]
         = 29.97002615... Гц                      [точна кадрова частота NTSC]
```

Частота полів дорівнює `2 · f[frame] = 59.940052... Гц` замість початкових `60 Гц`.

Зсув фази піднесучої за один рядок `T[H] = 1 / f[H]` дорівнює:

```
Δφ[H] = 2·π · f[sc] · T[H]                        [кутовий зсув фази за один рядок]
      = 2·π · (227.5 · f[H]) · (1 / f[H])         [підстановка f[sc] у формулу]
      = 2·π · 227.5 = 455·π рад                   [скорочення рядкової частоти]
      = 227 · (2π) + π ≡ π рад  (180°)            [227 повних обертів плюс півпауза]
```

Зсув на `180°` означає, що на кожному наступному рядку фаза піднесучої змінює знак на протилежний `C[m+1] = -C[m]`, завдяки чому завада колірності на моніторі просторово взаємно компенсується.

### Математичний розрахунок частоти колірної піднесучої PAL (4.43361875 МГц)

У системі PAL (625 рядків, 50 Гц кадрової розгортки) частота рядків дорівнює `f[H] = 15625 Гц`. Сигнал `V` змінює фазу на `180°` на кожному наступному рядку (*PAL phase alternation*).

Якщо застосувати звичайний напівкратний зсув `f[sc] = (283 + 1/2) · f[H] = 283.5 · 15625 = 4 429 687.5 Гц`, то через періодичну інверсію фази сигналу `V` спектральні піки гармонік `V` змістяться на `+1/2 f[H]` і потраплять **точно на гармоніки яскравості** `k·f[H]`. На екрані виникне груба непорушна сітка завад.

Щоб запобігти збігу спектрів при інверсії `V`, частоту піднесучої в PAL обирають із четвертькратним зсувом рядків (*quarter-line offset*) плюс додатковий кадровий зсув `25 Гц` (`f[V] / 2`):

```
f[sc] = (283 + 3/4) · f[H] + f[frame] / 2           [формула частоти піднесучої PAL]
```

Оскільки кадрова частота PAL `f[frame] = 25 Гц`, а кількість рядків у кадрі дорівнює `625`, маємо `f[frame] = f[H] / 625`. Звідси `f[frame] / 2 = f[H] / 1250 = 0.0008 · f[H]`.

Тоді дробовий коефіцієнт відносно `f[H]` дорівнює:

```
283 + 3/4 + 1/1250 = 283 + 0.75 + 0.0008 = 283.7508   [сумарний коефіцієнт гармоніки PAL]
```

Альтернативно, виражаючи кадровий зсув як `25 Гц` в абсолютних одиницях:

```
(283 + 3/4) · f[H] = 283.75 · 15 625 Гц = 4 433 593.75 Гц   [четвертькратна складова]
f[frame] / 2 = 25 Гц / 2 = 12.5 Гц                          [півкадрова складова зсуву]
```

Підставляючи обидві складові, отримуємо точне математичне значення частоти піднесучої PAL:

```
f[sc] = 4 433 593.75 Гц + 25 Гц               [додавання кадрового зсуву 25 Гц]
      = 4 433 618.75 Гц                        [точна піднесуча частота системи PAL]
```

Розрахуємо кутовий зсув фази піднесучої за один рядок у системі PAL:

```
Δφ[H] = 2·π · f[sc] / f[H]                               [фазовий набіг за один рядок]
      = 2·π · (283.75 + 25 / 15 625)                     [підстановка значення f[sc]/f[H]]
      = 2·π · (283.75 + 0.0016)                          [обчислення дробової частини]
      = 2·π · 283 + 2·π · 0.7516                         [виділення цілої кількості обертів]
      = 566·π + 1.5032·π рад                             [ціла частина плюс дробова]
      ≡ 270° + 0.576° = 270.576°                         [еквівалентний фазовий кут]
```

Завдяки зсуву на `270.576°` (приблизно `270°` або `-90°`) структура завади повертається на `90°` кожні чотири рядки, що розмиває заваду у вигляд дрібних діагональних крапок, непомітних для людського ока.

### Двовимірний просторово-часовий аналіз спектра

Двовимірний розклад відеокадру в просторово-часовій області визначається горизонтальною просторовою частотою `f[x]` (ліній/мм) та вертикальною просторовою частотою `f[y]` (рядків/екран):

```
F(f[x], f[y], f[t]) = ∑[k, m, p] C[k,m,p] · δ(f[x] - k·f[h_pix], f[y] - m·f[H], f[t] - p·f[frame]) [3D спектр]
```

Завдяки 1/2-рядковому зсуву в NTSC піки піднесучої зміщуються у просторовому спектрі на кут `45°` відносно горизонтальної та вертикальної осі:

```
f[y,sc] = (n + 0.5) · f[H]                          [просторова вертикальна частота колірності]
```

Це переміщує енергію піднесучої в область найменшої чутливості зорової системи людини — у кути двовимірного просторового спектра (*high spatial diagonal frequencies*), що й забезпечує високу візуальну чистоту телевізійного зображення.

### Перехідний міжкадровий зсув фази піднесучої NTSC

Окрім міжрядкового зсуву фази, у системі NTSC існує міжкадрове скасування завад. Оскільки один повний кадр NTSC складається з `525` рядків розгортки, загальна кількість періодів колірної піднесучої за один кадр дорівнює:

```
N[sc,frame] = 525 · (227 + 1/2)                     [кількість періодів у 525 рядках]
            = 525 · 227.5                           [підстановка напівкратного коефіцієнта]
            = 119 437.5 періодів                    [дробовий підрахунок кількості періодів]
```

Зсув фази піднесучої за один повний кадр тривалістю `T[frame] = 1 / f[frame]` дорівнює:

```
Δφ[frame] = 2·π · N[sc,frame]                        [кутовий зсув фази за один кадр]
          = 2·π · 119 437.5 = 238 875·π рад         [перемноження періодів на 2π]
          = 119 437 · (2π) + π ≡ π рад  (180°)     [ціла кількість обертів плюс протифаза]
```

Наявність дробової частини `.5` періоду (`π` рад або `180°`) означає, що в кожній точці екрана з координатами `(x, y)` піднесуча кадру `m+1` знаходиться в точній протифазі до піднесучої кадру `m`:

```
C[m+1](x, y, t) = -C[m](x, y, t - T[frame])         [міжкадрова інверсія фази]
```

Завдяки інерційності зору (із часом інтегрування близько `40 мс`) завада колірності, яка не повністю зкомпенсувалася між сусідніми рядками, додатково усереднюється в часі між сусідніми кадрами, роблячи сітку завад абсолютно непомітною.

### Тривимірна адаптивна гребінчаста фільтрація (3D Comb Filter)

Сучасні цифрові відеопроцесори виділяють колірність за допомогою 3D-адаптивного фільтра, який динамічно перемикається між просторовою 2D-фільтрацією та часовою 3D-фільтрацією на основі детектора руху `D(x,y,t)`:

```
D(x, y, t) = | Y[m](x, y, t) - Y[m-1](x, y, t - 2T[frame]) | [детектор просторового руху]
```

#### Часова фільтрація для статичних ділянок кадру (`D < ε`)

Для нерухомого зображення фільтр використовує міжкадрову лінію затримки на два поля (один кадр `T[frame]`):

```
Y_out(t) = 0.5 · [ S(t) + S(t - T[frame]) ]          [міжкадрове додавання ізолює Y]
C_out(t) = 0.5 · [ S(t) - S(t - T[frame]) ]          [міжкадрове віднімання ізолює C]
```

Підставляючи `S(t) = Y(t) + C(t)` та `C(t - T[frame]) = -C(t)` при `Y(t) = Y(t - T[frame])`:

```
Y_out = 0.5 · [ Y(t) + C(t) + Y(t) - C(t) ] = Y(t)   [абсолютно чистий Y без втрати чіткості]
C_out = 0.5 · [ Y(t) + C(t) - (Y(t) - C(t)) ] = C(t) [абсолютно чиста колірність C]
```

#### Просторова 2D-фільтрація для рухомих об'єктів (`D ≥ ε`)

Для рухомих деталей кадру часова фільтрація давала б розмиття (*motion ghosting*), тому декодер перемикається на міжрядковий 3-рядковий вертикальний гребінчастий фільтр:

```
Y_out[m] = 0.25·S[m-1] + 0.5·S[m] + 0.25·S[m+1]     [3-точковий взважений вертикальний фільтр]
C_out[m] = -0.25·S[m-1] + 0.5·S[m] - 0.25·S[m+1]    [виділення вертикальної колірності]
```

### Математика фазового автопідстроювання (ФАПЧ / PLL) за колірним спалахом

Для відновлення опорної піднесучої з точною фазою місцевий гетеродин приймача керується петлею фазового автопідстроювання частоти (ФАПЧ / *PLL*), яка активується строго під час проходження колірного спалаху (*Color Burst*) на задньому майданчику гасіння `Back Porch`.

Вхідний спалах колірності `B(t)` задається виразом:

```
B(t) = A[burst] · sin(ω[sc]·t + π)                  [спалах колірності з фазою 180 градусів у NTSC]
```

Місцевий керований напругою генератор (КНГ / *VCO*) генерує опорний сигнал `S[vco](t)` з поточною фазою `φ[vco](t)`:

```
S[vco](t) = cos(ω[sc]·t + φ[vco](t))                 [опорний сигнал місцевого генератора]
```

Перемноження сигналів у фазовому детекторі дає сигнал помилки `e(t)`:

```
e(t) = B(t) · S[vco](t)                              [перемноження в детекторі]
     = A[burst] · sin(ω[sc]·t + π) · cos(ω[sc]·t + φ[vco](t)) [підстановка сигналів]
     = 0.5·A[burst] · [ sin(2ω[sc]·t + π + φ[vco]) + sin(π - φ[vco]) ] [тригонометричний добуток]
     → 0.5·A[burst] · sin(π - φ[vco])               [після НЧ-фільтрації фазового детектора]
     = 0.5·A[burst] · sin(φ[vco])                   [спрощення за тригонометричною формулою]
```

При малих фазових відхиленнях `sin(φ[vco]) ≈ φ[vco]`, тому вихідний сигнал фазового детектора прямо пропорційний помилці фази `e(t) = K[d] · φ[vco]`, де `K[d] = 0.5 · A[burst]` — коефіцієнт передачі фазового детектора.

Диференціальне рівняння керування петлі ФАПЧ 2-го порядку з пропорційно-інтегральним (ПІ) фільтром має вигляд:

```
dφ[vco]/dt = K[vco] · [ K[p] · e(t) + K[i] · ∫ e(τ) dτ ] [диференціальне рівняння ФАПЧ]
```

У сталому режимі (`dφ[vco]/dt = 0`) інтегральна ланка ПІ-фільтра гарантує строго нульову статичну фазову помилку `φ[vco] = 0`, що забезпечує точне збереження кольору та відсутність фазового дрейфу.

### Порівняльний аналіз: QAM (NTSC/PAL) проти ЧМ (SECAM)

У системі SECAM (*Séquentiel Couleur avec Mémoire*) замість квадратурної модуляції QAM використовується послідовна передача сигналів `D[R]` та `D[B]` на частотній модуляції (ЧМ) з двох різних піднесучих:

```
D[R] = -1.9 · (R - Y)                               [сигнал червоного в SECAM]
D[B] =  1.5 · (B - Y)                               [сигнал синього в SECAM]

f[sc,R](t) = f[0R] + Δf[R] · D[R](t)                [ЧМ піднесуча R: f[0R] = 4.40625 МГц]
f[sc,B](t) = f[0B] + Δf[B] · D[B](t)                [ЧМ піднесуча B: f[0B] = 4.25000 МГц]
```

Математична порівняльна характеристика трьох систем кольорового телебачення:

```
NTSC:  QAM (I, Q)   [вразливість до фази Δθ, потребує ручної ручки HUE]
PAL:   QAM (U, ±V)  [стійкість до фази Δθ за рахунок інверсії V та затримки 1H]
SECAM: ЧМ  (D_R/D_B)[абсолютна нечутливість до фази Δθ, але відсутність QAM сумісності]
```

Таким чином, квадратурна амплітудна модуляція із дробово-напівкратним та четвертькратним зсувом частот у комбінації з 3D-гребінчастою фільтрацією утворюють завершену математично обґрунтовану систему передачі відеосигналу.
