# 🧮 Математика RC-інтегратора та урівнювальних імпульсів

Цей математичний аналіз виводить рівняння накопичення заряду в пасивному RC-інтеграторі кадрової синхронізації та доводить, чому без урівнювальних імпульсів з частотою 2f_H виникає викривлення часового моменту тригера кадру (артефакт парності рядків).

### 1. Фізика перехідного процесу в RC-інтеграторі

У приймачі аналогового відеосигналу або FPV-відеоокулярах відокремлення тривалого кадрового синхроімпульсу від коротких рядкових здійснюється за допомогою пасивного фільтра нижніх частот — інтегрувального RC-ланцюга. Постійна часу фільтра `τ = R·C` обирається так, щоб короткі рядкові імпульси тривалістю `t_h ≈ 4.7 мкс` не встигали зарядити конденсатор до порогової напруги спрацьовування кадрового тригера `V_th`, тоді як тривалий кадровий імпульс `t_v ≈ 160 мкс` заряджає його повністю.

Під час дії активного низького рівня синхроімпульсу (коли напруга падає від рівня гасіння `V_b` до рівня синхро `V_s = 0`), конденсатор заряджається згідно з диференціальним рівнянням першого порядку:

```
V_c(t) = V_b · (1 - e^(-t / τ))
```

Під час паузи між імпульсами (коли напруга повертається до рівня гасіння `V_b`) конденсатор розряджається за експоненційним законом:

```
V_c(t) = V_0 · e^(-t / τ)
```

де `V_0` — початкова напруга на конденсаторі на початку інтервалу розрядки.

### 2. Часова асиметрія полів без урівнювальних імпульсів

Оскільки загальна кількість рядків у кадрі є непарною (`N = 625` для PAL або `N = 525` для NTSC), Поле 1 закінчується на повному рядку, а Поле 2 — на піврядку (`312.5` або `262.5` рядків відповідно).

Розглянемо часовий інтервал від останнього рядкового синхроімпульсу до початку кадрового імпульсу для двох полів:
- **У Полі 1:** інтервал між останнім H-sync і початком V-sync дорівнює повному періоду рядка `T_H = 64 мкс`.
- **У Полі 2:** інтервал між останнім H-sync і початком V-sync дорівнює половині періоду рядка `0.5·T_H = 32 мкс`.

Розрахуємо залишковий заряд конденсатора `V_res` безпосередньо перед прибуттям кадрового імпульсу для обох полів, якщо стаціонарна напруга на початку розрядки становила `V_0`:

```
V_res1 = V_0 · e^(-T_H / τ)                   [Поле 1: тривалість розрядки T_H]
V_res2 = V_0 · e^(-0.5·T_H / τ)               [Поле 2: тривалість розрядки 0.5·T_H]

ΔV_res = V_res2 - V_res1
       = V_0 · (e^(-0.5·T_H / τ) - e^(-T_H / τ))
```

Оскільки `0.5·T_H < T_H`, експонента `e^(-0.5·T_H / τ) > e^(-T_H / τ)`. Це означає, що залишкова напруга на конденсаторі перед початком кадрового імпульсу у Полі 2 є строго більшою, ніж у Полі 1 (`ΔV_res > 0`).

### 3. Зсув моменту спрацьовування V-тригера (парність рядків)

Кадровий генератор розгортки спрацьовує у момент `t_tr`, коли напруга на інтеграторі `V_c(t)` сягає порогового значення `V_th`. Під час дії кадрового імпульсу напруга зростає від початкового залишкового значення `V_res`:

```
V_c(t) = V_res · e^(-t / τ) + V_b · (1 - e^(-t / τ))
       = V_b - (V_b - V_res) · e^(-t / τ)
```

Знайдемо точний час досягнення порогової напруги `t_tr` з умови `V_c(t_tr) = V_th`:

```
V_th = V_b - (V_b - V_res) · e^(-t_tr / τ)
(V_b - V_res) · e^(-t_tr / τ) = V_b - V_th
e^(-t_tr / τ) = (V_b - V_th) / (V_b - V_res)
t_tr = τ · ln((V_b - V_res) / (V_b - V_th))
```

Оскільки залишкова напруга різниться (`V_res2 > V_res1`), значення числівника `(V_b - V_res2) < (V_b - V_res1)`. Це дає пряму різницю в часі спрацьовування кадрового тригера між двома полями:

```
Δt_tr = t_tr1 - t_tr2
      ≈ τ · (ΔV_res / (V_b - V_th))           [лінійна апроксимація Тейлора]
```

Цей часовий зсув `Δt_tr` розлагоджує кадрову розгортку: вертикальне підмітання Поля 2 починається раніше потрібного моменту. В результаті рядки Поля 2 накладаються безпосередньо на рядки Поля 1 (виникає артефакт **злипання або парності рядків**, *line pairing*), і геометрична вертикальна роздільність зображення зменшується вдвічі.

### 4. Математичне усунення асиметрії імпульсами 2f_H

Щоб звести різницю залишкових напруг до нуля (`ΔV_res = 0`), у відеосигнал перед кадровим синхроімпульсом вводять **5 пре-урівнювальних імпульсів** із подвоєною частотою `2·f_H` (з періодом `0.5·T_H = 32 мкс`), сам кадровий імпульс розрізають зубцями з частотою `2·f_H`, а після нього додають **5 пост-урівнювальних імпульсів**.

Завдяки серії з 5 пре-урівнювальних імпульсів протягом `5 × 32 мкс = 160 мкс` перед кадровим імпульсом обидва поля піддаються **абсолютно однаковому** імпульсному впливу. Прослідкуємо за розрядкою конденсатора під час дії 5 імпульсів з періодом `T_eq = 0.5·T_H`:

```
V_c(n) = V_c(n-1) · e^(-T_eq / τ) + V_pulse
```

Після 5 однакових періодів `T_eq` геометрична прогресія згасання залишкового заряду збігається до стаціонарного значення з точністю вище 99%:

```
V_res1(після 5 імпульсів 2f_H) = V_res2(після 5 імпульсів 2f_H)
ΔV_res = 0  ⇒  Δt_tr = 0
```

У результаті момент спрацьовування кадрового тригера `t_tr` стає математично ідентичним для непарного та парного полів, що гарантує точний геометричний зсув рядків на `0.5` кроку без викривлень.

### 5. Розрахунок номіналів RC-ланцюга для сепаратора VSYNC

Для вибору оптимальної постійної часу `τ = R·C` необхідно задовольнити подвійну нерівність:

```
t_h_pulse < τ < t_v_pulse
```

Для стандарту PAL `t_h = 4.7 мкс`, а тривалість кадрового провалу `t_v = 160 мкс`. Типовий вибір постійної часу становить `τ ≈ 40 ... 50 мкс`. Наприклад, при використанні резистора `R = 10 кОм` ємність конденсатора становить:

```
C = τ / R = 47·10⁻⁶ / 10·10³ = 4.7 нФ
```

Такий номінал гарантує, що одиночний рядковий імпульс заряджає конденсатор менше ніж на 10% від рівня `V_th`, тоді як зубчастий кадровий імпульс перетинає поріг `V_th` вже через `35 ... 40 мкс` після свого початку, забезпечуючи чітке й стійке спрацьовування кадрового тригера.

### 6. Вплив температури та нестабільності елементів

У реальних аналогових схемах ТВ-приймачів значення `R` та `C` мають температурний дрейф. Якщо через нагрівання ємність конденсатора зменшується, постійна часу `τ` спадає, і ризик хибного спрацьовування V-тригера від високочастотних завад зростає. Використання пре- та пост-урівнювальних імпульсів створює необхідний інженерний запас стійкості (масивний допуск на дрейф `τ` у межах ±30%), дозволяючи системі синхронізації надійно працювати навіть при значних коливаннях температури навколишнього середовища. Цей математичний висновок ліг в основу міжнародних стандартів CCIR та NTSC.
