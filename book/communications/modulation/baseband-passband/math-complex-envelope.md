# 🧮 Комплексна огинаюча та квадратурне представлення

Будь-який вузькосмуговий радіосигнал у фізичному середовищі є дійсним коливанням високої частоти, але для математичного аналізу та цифрової обробки його виражають через комплексну огинаючу. Цей математичний апарат зводить аналіз високочастотних процесів до низькочастотного еквівалента біля нульової частоти, повністю зберігаючи амплітудну, частотну та фазову інформацію.

### 1. Перетворення Гільберта та аналітичний сигнал

Нехай дійсний смуговий сигнал `s(t)` має спектр `S(f)`, зосереджений у вузькій смузі `2B` навколо несучої частоти `f_c` (де `f_c >> B`). Щоб усунути від'ємні частоти спектра, які дзеркально дублюють додатну частину для дійсних сигналів, будують **аналітичний сигнал** `z(t)`.

Перетворення Гільберта `s_H(t)` для сигналу `s(t)` визначається як згортка з невласним ядром `1 / (π · t)`, що в часовій області відповідає математичному оператору:

```
s_H(t) = (1 / π) · ∫_{-∞}^{+∞} [ s(τ) / (t - τ) ] dτ
```

У частотній області перетворення Гільберта відповідає ідеальному фазообертачу, який зсуває фазу всіх спектральних компонент на `-π/2` (-90°) для додатних частот та на `+π/2` (+90°) для від'ємних частот. Оператор Гільберта у частотній області описується передавальною функцією `H_Hilb(f)`:

```
H_Hilb(f) = -j · sgn(f)
```

де `sgn(f)` — функція знака частоти. Завдяки цій властивості подвійне застосування перетворення Гільберта інвертує знак сигналу: `s_HH(t) = -s(t)`.

Ортогональність сигналу `s(t)` та його перетворення Гільберта `s_H(t)` підтверджується тим, що їхній скалярний добуток у квадратичному просторі L2 дорівнює точного нулю:

```
∫_{-∞}^{+∞} s(t) · s_H(t) dt = 0
```

Це свідчить про те, що перетворення Гільберта генерує геометрично ортогональний сигнал, який не містить спільної енергії з вихідним коливанням.

Аналітичний сигнал `z(t)` утворюється як комплексне коливання, дійсною частиною якого є вихідний сигнал `s(t)`, а уявною — його сопряжене перетворення Гільберта `s_H(t)`:

```
z(t) = s(t) + j · s_H(t)
```

Перейдемо до спектрального представлення аналітичного сигналу `Z(f) = F{ z(t) }`. Застосувавши властивість лінійності перетворення Фур'є, отримуємо:

```
Z(f) = S(f) + j · [ -j · sgn(f) · S(f) ]
     = S(f) + sgn(f) · S(f)                  [множення уявних одиниць: j · (-j) = 1]
     = [ 1 + sgn(f) ] · S(f)                 [винесення спільного множника S(f)]
```

Аналізуючи вираз `1 + sgn(f)`, бачимо, що спектр аналітичного сигналу повністю обнуляється в області від'ємних частот і подвоюється в області додатних частот:

```
Z(f) = 2 · S(f)    при f > 0
Z(f) = S(f)        при f = 0
Z(f) = 0           при f < 0
```

Усунення від'ємних частот позбавляє математичні вирази від спектральної надлишковості, не втрачаючи жодного джоуля корисної інформації про амплітуду й фазу сигналу.

### 2. Визначення та спектральний зсув комплексної огинаючої

Оскільки спектр аналітичного сигналу `Z(f)` локалізований у додатній частотній області навколо несучої частоти `f_c`, ми можемо «знести» цей спектр у низькочастотну область біля нуля Гц. Для цього аналітичний сигнал домножують на комплексно-спряжений фазор `e^{-j · 2π · f_c · t}`:

```
s_l(t) = z(t) · e^{-j · 2π · f_c · t}
```

Величина `s_l(t)` називається **комплексною огинаючою** (*complex envelope*) або **низькочастотним еквівалентом** (*low-pass equivalent*) смугового сигналу. 

За теоремою про зсув у частотній області, множення сигналу в часі на комплексну експоненту `e^{-j 2π f_c t}` призводить до зсуву його спектра вправо на `f_c`. Звідси спектр комплексної огинаючої `S_l(f)` пов'язаний зі спектром аналітичного сигналу співвідношенням:

```
S_l(f) = Z(f + f_c)
```

Підставивши вираз для `Z(f)`, отримуємо зв'язок між спектром вихідного смугового сигналу `S(f)` та спектром комплексної огинаючої `S_l(f)`:

```
S_l(f) = 2 · S(f + f_c)    при f > -f_c
S_l(f) = 0                 при f ≤ -f_c
```

Отже, спектр комплексної огинаючої `S_l(f)` є низькочастотним сигналим, локалізованим у вузькому інтервалі `-B ≤ f ≤ B`. Оскільки несуча частота `f_c >> B`, від'ємний хвіст спектра повністю відсутній, а спектр `S_l(f)` взагалі не залежить від значення несучої частоти `f_c`.

### 3. Квадратурний розклад: I(t) та Q(t)

Оскільки `s_l(t)` є комплексно-значною функцією часу, її у кожний момент часу можна розкласти на дійсну та уявну частини у декартових координатах:

```
s_l(t) = I(t) + j · Q(t)
```

де:
- `I(t) = Re{ s_l(t) }` — **синфазна компонента** (*In-phase component*);
- `Q(t) = Im{ s_l(t) }` — **квадратурна компонента** (*Quadrature component*).

Обидві функції `I(t)` та `Q(t)` є **дійсними низькочастотними сигналами**, найвища частота у спектрі яких не перевищує `B`.

Виведемо математичний зв'язок між квадратурними компонентами `I(t), Q(t)` та фізичним смуговим сигналом `s(t)`. За визначенням аналітичного сигналу та комплексної огинаючої:

```
z(t) = s_l(t) · e^{j · 2π · f_c · t}
     = [ I(t) + j · Q(t) ] · [ cos(2π · f_c · t) + j · sin(2π · f_c · t) ]   [формула Ейлера для експоненти]
     = [ I(t) · cos(2π f_c t) - Q(t) · sin(2π f_c t) ] 
       + j · [ I(t) · sin(2π f_c t) + Q(t) · cos(2π f_c t) ]                [перемноження та розгрупування за дводільною формою]
```

Оскільки фізичний смуговий сигнал є дійсною частиною аналітичного сигналу `s(t) = Re{ z(t) }`, отримуємо підтвердження канонічної квадратурної формули:

```
s(t) = I(t) · cos(2π · f_c · t) - Q(t) · sin(2π · f_c · t)
```

Відповідно, уявна частина `Im{ z(t) }` дає сигнал після перетворення Гільберта:

```
s_H(t) = I(t) · sin(2π · f_c · t) + Q(t) · cos(2π · f_c · t)
```

Звідси квадратурні компоненти `I(t)` та `Q(t)` виражаються безпосередньо через фізичний смуговий сигнал `s(t)` та його сопряжене перетворення Гільберта `s_H(t)`:

```
I(t) = s(t) · cos(2π · f_c · t) + s_H(t) · sin(2π · f_c · t)

Q(t) = s_H(t) · cos(2π · f_c · t) - s(t) · sin(2π · f_c · t)
```

Ці два вирази показують, що будь-який смуговий сигнал є лінійною комбінацією двох високочастотних ортогональних несучих `cos(2π f_c t)` та `sin(2π f_c t)`, модульованих повільними низькочастотними коефіцієнтами `I(t)` та `Q(t)`.

### 4. Представлення у полярних координатах: амплітуда та фаза

Комплексну огинаючу `s_l(t)` можна подати у полярній формі через миттєвий модуль та аргумент:

```
s_l(t) = A(t) · e^{j · φ(t)}
```

де миттєва амплітуда `A(t)` (огинаюча сигналу) та миттєва фаза `φ(t)` визначаються через квадратурні компоненти:

```
A(t) = |s_l(t)| = √( I²(t) + Q²(t) )

φ(t) = arg( s_l(t) ) = arctan( Q(t) / I(t) )
```

Зворотно, синфазна та квадратурна компоненти виражаються через амплітуду та фазу:

```
I(t) = A(t) · cos( φ(t) )

Q(t) = A(t) · sin( φ(t) )
```

Підставивши полярний вигляд у формулу фізичного сигналу `s(t) = Re{ s_l(t) · e^{j 2π f_c t} }`, маємо:

```
s(t) = Re{ A(t) · e^{j · φ(t)} · e^{j · 2π · f_c · t} }
     = Re{ A(t) · e^{j · (2π · f_c · t + φ(t))} }                           [властивість експоненти: e^a · e^b = e^(a+b)]
     = A(t) · cos( 2π · f_c · t + φ(t) )                                    [дійна частина за формулою Ейлера: Re{e^(jθ)} = cos(θ)]
```

Звідси миттєва частота смугового сигналу `f_inst(t)` виражається через похідну від повного фазового кута:

```
2π · f_inst(t) = (d / dt) [ 2π · f_c · t + φ(t) ] = 2π · f_c + φ'(t)
```

Виразимо похідну від миттєвої фази `φ'(t)` безпосередньо через квадратурні компоненти `I(t)` та `Q(t)` і їхні часові похідні `I'(t), Q'(t)`. Оскільки `φ(t) = arctan( Q(t) / I(t) )`, застосувавши правило диференціювання складеної функції, отримуємо:

```
φ'(t) = [ I(t) · Q'(t) - Q(t) · I'(t) ] / [ I²(t) + Q²(t) ]
```

Отже, миттєва частота смугового сигналу обчислюється повністю через низькочастотні масиви `I, Q` та їхні дискретні різниці:

```
f_inst(t) = f_c + (1 / 2π) · [ I(t) · Q'(t) - Q(t) · I'(t) ] / [ I²(t) + Q²(t) ]
```

Це виведення є математичним фундаментом для побудови цифрових частотних демодуляторів (FM детектора) у програмно-визначеному радіо (SDR).

### 5. Спектральне співвідношення та енергетична еквівалентність

Знайдемо зворотний вираз для спектра дійсного смугового сигналу `S(f)` через спектр комплексної огинаючої `S_l(f)`. Оскільки `s(t) = (1/2) · [ s_l(t) · e^{j 2π f_c t} + s_l*(t) · e^{-j 2π f_c t} ]`, застосувавши перетворення Фур'є, отримуємо:

```
S(f) = (1/2) · [ S_l(f - f_c) + S_l*(-f - f_c) ]
```

де `S_l*(f)` — комплексно-спряжений спектр. Цей вираз показує, що спектр дійсного смугового сигналу складається з двох зсунутих копій спектра комплексної огинаючої, розміщених біля `+f_c` та `-f_c`, кожна з яких зменшена за амплітудою вдвічі.

Обчислимо повну енергію смугового сигналу `E_s` на часовому інтервалі:

```
E_s = ∫_{-∞}^{+∞} s²(t) dt
```

Підставимо квадратурну форму `s(t) = I(t) · cos(2π f_c t) - Q(t) · sin(2π f_c t)`:

```
s²(t) = I²(t) · cos²(2π f_c t) + Q²(t) · sin²(2π f_c t) - 2 · I(t) · Q(t) · cos(2π f_c t) · sin(2π f_c t)
```

Застосуємо тригонометричні формули пониження степеня:

```
cos²(θ) = (1/2) · [ 1 + cos(2θ) ]
sin²(θ) = (1/2) · [ 1 - cos(2θ) ]
2 · cos(θ) · sin(θ) = sin(2θ)
```

Отримуємо:

```
s²(t) = (1/2) · [ I²(t) + Q²(t) ] + (1/2) · [ I²(t) - Q²(t) ] · cos(4π f_c t) - I(t) · Q(t) · sin(4π f_c t)
```

Оскільки `I(t)` та `Q(t)` змінюються дуже повільно порівняно з високочастотним коливанням `4π f_c` (бо `f_c >> B`), при інтегруванні за часом високочастотні гармоніки `cos(4π f_c t)` та `sin(4π f_c t)` дають нульовий внесок. Інтеграл спрощується до точного співвідношення:

```
E_s = ∫_{-∞}^{+∞} s²(t) dt
    = (1/2) · ∫_{-∞}^{+∞} [ I²(t) + Q²(t) ] dt     [усереднення швидкоколивальних компонент 4π f_c]
    = (1/2) · ∫_{-∞}^{+∞} |s_l(t)|² dt             [за визначенням модуля |s_l(t)|² = I²(t) + Q²(t)]
    = (1/2) · E_l                                   [за визначенням енергії комплексної огинаючої]
```

Отже, енергія фізичного смугового сигналу `E_s` дорівнює рівно половині енергії його комплексної огинаючої `E_l`. Множник `1/2` виникає через те, що у фізичному середовищі енергія ділиться порівну між додатними та від'ємними частотними смугами.

Згідно з теоремою Парсеваля, енергію сигналу можна обчислити як в часовій, так і у частотній області:

```
E_s = ∫_{-∞}^{+∞} |S(f)|² df = (1/2) · ∫_{-∞}^{+∞} |S_l(f)|² df
```

Це доводить, що спектральна щільність потужності (PSD) смугового сигналу дорівнює половині спектральної щільності потужності його комплексної огинаючої, зсунутої на несучу частоту.

### 6. Еквівалентна низькочастотна фільтрація та матриці MIMO

Найбільша практична користь комплексної огинаючої розкривається при моделюванні проходження сигналу через лінійні стаціонарні системи (фільтри, лінії передачі, радіоканали).

Нехай смуговий фільтр має дійсну імпульсну характеристику `h(t)` зі спектром `H(f)`, зосередженим навколо `f_c`. Комплексна огинаюча імпульсної характеристики фільтра `h_l(t)` визначається аналогічно:

```
h_l(t) = [ h(t) + j · h_H(t) ] · e^{-j · 2π · f_c · t}
```

Вихідний смуговий сигнал `y(t)` дорівнює часовій згортці вхідного сигналу `s(t)` з імпульсною характеристикою `h(t)`:

```
y(t) = ( s * h )(t) = ∫_{-∞}^{+∞} s(τ) · h(t - τ) dτ
```

У частотній області це відповідає множенню спектрів: `Y(f) = S(f) · H(f)`. Оскільки для додатних частот `Z_y(f) = 2 · S(f) · H(f) = (1/2) · Z_s(f) · Z_h(f)`, переходячи до комплексної огинаючої вихідного сигналу `y_l(t)`, отримуємо **теорему про еквівалентну низькочастотну фільтрацію**:

```
y_l(t) = (1/2) · ( s_l * h_l )(t) = (1/2) · ∫_{-∞}^{+∞} s_l(τ) · h_l(t - τ) dτ
```

У частотній області спектр вихідної комплексної огинаючої обчислюється як просте множення низькочастотних спектрів:

```
Y_l(f) = (1/2) · S_l(f) · H_l(f)
```

Розкладемо комплексний коефіцієнт фільтра на синфазну та квадратурну складові `h_l(t) = h_I(t) + j · h_Q(t)`. Згортка у комплексній формі розгортається у систему двох дійсних рівностей:

```
y_I(t) = (1/2) · [ (s_I * h_I)(t) - (s_Q * h_Q)(t) ]

y_Q(t) = (1/2) · [ (s_I * h_Q)(t) + (s_Q * h_I)(t) ]
```

У матричному вигляді це описується як двовимірній фільтраційний тракт:

```
┌ y_I(t) ┐          1   ┌  h_I(t)   -h_Q(t) ┐   ┌ s_I(t) ┐
│        │  =  ─── · │                       │ * │        │
└ y_Q(t) ┘          2   └  h_Q(t)    h_I(t) ┘   └ s_Q(t) ┘
```

Цей фундаментальний матричний вираз лежить в основі роботи всіх сучасних багатоантенних систем MIMO (Wi-Fi 6, 5G NR), де просторове кодування й декодування каналів виконується цифровим процесором суто над низькочастотною комплексною матрицею коефіцієнтів передачі `H_l`.

Завдяки цьому методу обчислювальна складність математичного симулятора радіосистем зменшується в мільйони разів, що уможливлює швидке цифрове моделювання складних супутникових та мобільних мереж зв'язку.
