# 🧮 Виграш сигнально-шумового співвідношення та енергетика 38 кГц

Математичне обґрунтування модуляції інфрачервоного випромінювання високовольтною піднесною частотою спирається на два фізичні ефекти: спектральну фільтрацію флуктуацій фотоструму у вузькому вікні частот та динаміку імпульсного теплового балансу напівпровідникового випромінювача.

### Спектральний аналіз фотоструму та дробовий шум

Розглянемо повне спектральне подання фотоструму `I_photodiode(t)`, що виникає у кремнієвому PIN-фотодіоді під дією сумарного оптичного потоку в приміщенні. Фотодіод виступає як лінійний перетворювач оптичної потужності випромінювання `Ф(t)` у струм з коефіцієнтом струмової чутливості `R_λ ≈ 0.6 А/Вт` для довжини хвилі 940 нм:

```
I_photodiode(t) = I_dc + I_mains(t) + I_ballast(t) + i_shot(t) + i_signal(t)
```

Розберемо спектральний склад кожної із п'яти складових струму:

1. **Постійна складова сонячного засвічування `I_dc`:** Утворює постійний DC-зсув фонового струму величиною від 50 мкА до 2 мА. Спектральна щільність цієї складової зосереджена в точці `f = 0 Гц`.
2. **Мережеві пульсації `I_mains(t)`:** Освітлення від ламп розжарювання та мережевих світлодіодних ламп створює змінний струм на частотах гармонік мережі (100 Гц або 120 Гц) з амплітудою `I_mains0`:
   ```
   I_mains(t) = I_mains0 · cos(2π · 100 · t)
   ```
3. **Високочастотні завади від імпульсних джерел `I_ballast(t)`:** Електронні бастати люмінесцентних ламп та ШІМ-драйвери світлодіодів генерують гармонійний спектр у діапазоні від 20 до 35 кГц.
4. **Дробовий шум фотодіода `i_shot(t)`:** Пуассонівські флуктуації кількості згенерованих фотоелектронів. Спектральна густина потужності дробового шуму описується формулою Шотткі:
   ```
   S_shot(f) = 2 · q · I_dc   (А²/Гц)
   ```
   де `q = 1.602 × 10⁻¹⁹ Кл` — елементарний заряд електрона. Оскільки спектральна густина є білим шумом з рівномірним розподілом по частоті, загальна потужність шуму в широкій смузі `B_raw` без фільтрації визначається інтегралом:
   ```
   P_noise_raw = ∫ S_shot(f) df = 2 · q · I_dc · B_raw + (I_mains0² / 2)
   ```
5. **Корисний інфрачервоний сигнал `i_signal(t)`:** Являє собою прямокутну пачку меандру 38 кГц з амплітудою `I_sig0` та огинаючою `m(t)`. Згідно з теоремою про згортку спектрів, спектр модульованого сигналу є зсунутою копією спектра огинаючої:
   ```
   S_signal(f) = 1/4 · [S_m(f - f_c) + S_m(f + f_c)]
   ```

Якщо приймач має широкосмуговий підсилювач від 0 до `B_raw = 1 МГц` без смугового фільтра, при `I_dc = 500 мкА` потужність дробового шуму обчислюється так:

```
P_noise_raw
= 2 · q · I_dc · B_raw                               [теорема Шотткі для білого дробового шуму]
= 2 · (1.602 × 10⁻¹⁹) · (500 × 10⁻⁶) · 10⁶           [підстановка q, I_dc = 500 мкА, B_raw = 1 МГц]
= 1.602 × 10⁻¹⁵ А²                                    [обчислення повної потужності шуму]
```

### Спектральне перетворення OOK-пачки

Звернемося до математичної форми корисного сигналу `s(t)`. Корисний сигнал утвориться множенням низькочастотної огинаючої протоколу `m(t)` (тривалістю `T_burst ≈ 562.5 мкс`) на високочастотну несучу `c(t) = cos(2π · f_c · t)`:

```
s(t) = m(t) · cos(2π · f_c · t)
```

Перетворення Фур'є прямокутного імпульсу огинаючої `m(t)` шириною `T_burst` дає функцію відношення синуса до аргументу (sinc):

```
M(f) = T_burst · sinc(π · f · T_burst)
```

Після множення на несучу `f_c = 38 кГц` основна енергія корисного сигналу зосереджується у вузькій смузі частот:

```
B_signal
= 2 / T_burst                                       [ширина головної пелюстки спектра sinc]
= 2 / (562.5 × 10⁻⁶)                                [підстановка тривалості пачки T_burst = 562.5 мкс]
≈ 3555 Гц                                           [ширина корисного спектра сигналу ~3.55 кГц]
```

Це означає, що для безперешкодного пропускання корисного імпульсу приймачеві достатньо мати смугу пропускання фільтра близько 4 кГц навколо центральної частоти 38 кГц.

### Математичний виразок смугового фільтра та розрахунок SNR

Припустимо, що приймач містить активний смуговий фільтр 4-го порядку з центральною частотою `f_c = 38 кГц` та добротністю `Q = 9.5`. Передавальна функція другого порядку такого фільтра описується виразом:

```
H(s) = (A_0 · (ω_0 / Q) · s) / (s² + (ω_0 / Q) · s + ω_0²)
```

де `ω_0 = 2π · 38000 rad/s`, а `A_0` — коефіцієнт підсилення на резонансній частоті. Смуга пропускання фільтра по рівню -3 дБ дорівнює:

```
B_bpf
= f_c / Q                                           [визначення смуги пропускання за рівнем -3 дБ]
= 38000 / 9.5                                       [підстановка f_c = 38 кГц та Q = 9.5]
= 4000 Гц                                           [ширина смуги фільтра 4 кГц]
```

Обчислимо модуль коефіцієнта передачі фільтра `|H(j2πf)|` для різних завад:

```
|H(j·2π·0)| = 0                                     [придушення DC: сонячне світло]
|H(j·2π·100)| ≈ 0.00027                             [придушення 100 Гц: -71.3 дБ]
|H(j·2π·38000)| = 1.0                               [резонансне пропускання 38 кГц: 0 дБ]
```

Завдяки цьому постійна складова `I_dc` та мережеві пульсації `I_mains` повністю зникають на виході фільтра. Залишкова потужність шуму визначається лише ділянкою білого дробового шуму у вузькому вікні `B_bpf`:

```
P_noise_filtered
= 2 · q · I_dc · B_bpf                              [інтегрування білого шуму у смузі B_bpf]
= 2 · (1.602 × 10⁻¹⁹) · (500 × 10⁻⁶) · 4000         [підстановка величин q, I_dc та B_bpf]
= 6.408 × 10⁻¹⁸ А²                                  [залишковий шум на виході BPF]
```

Математичний виграш у співвідношенні сигнал/шум (SNR Gain) за потужністю дорівнює відношенню смуг пропускання:

```
G_SNR
= P_noise_raw / P_noise_filtered                    [відношення потужностей шуму до і після BPF]
= B_raw / B_bpf                                     [скорочення послідовного дробового шуму]
= 1 000 000 / 4 000                                 [підстановка B_raw = 1 МГц та B_bpf = 4 кГц]
= 250                                               [коефіцієнт виграшу SNR у 250 разів]

G_SNR_dB
= 10 · log₁₀(250)                                   [перевід виграшу в децибели]
≈ 23.98 дБ                                          [виграш завадостійкості ~24 дБ]
```

Завдяки вузькосмуговій фільтрації рівень завад падає у 250 разів (майже на 24 дБ), що дозволяє підсилити корисний сигнал у сотні тисяч разів без ризику насичення аналогового тракту.

### Термодинаміка імпульсного живлення ІЧ-світлодіода

Максимальна тривала розсіювана потужність світлодіода обмежена перегрівом P-N переходу вище допустимої температури `T_j_max ≈ 125 °C`. Для безперервного режиму (DC) це задає жорстку межу постійного струму `I_dc_max`:

```
P_dc_max
= (T_j_max - T_ambient) / R_th_ja                   [тепловий опір кристал-довкілля]
= (125 - 25) / 200                                  [підстановка T_j_max = 125°C, T_env = 25°C, R_th = 200°C/Вт]
= 0.5 Вт                                            [максимальна розсіювана потужність]

I_dc_max
= P_dc_max / V_forward                              [граничний струм через V_forward = 1.5 В]
= 0.5 / 1.5                                         [обчислення допустимого постійного струму]
≈ 50 мА                                             [межа постійного струму без перегріву]
```

При модуляції меандром 38 кГц зі шпаруватістю `D = T_on / T = 1/3 ≈ 0.33` струм протікає лише протягом часу `T_on = 8.77 мкс`, після чого настає пауза `T_off = 17.54 мкс`.

Теплова постійна часу кремнієвого кристала світлодіода `τ_thermal` становить від 1 до 5 мілісекунд. Оскільки період несучої `T = 26.3 мкс` значно менший за теплову постійну часу (`T ≪ τ_thermal`), температура P-N переходу не встигає відстежувати мікросекундні пульсації струму й реагує лише на **середню розсіювану потужність**:

```
P_avg = D · I_peak · V_forward
```

Прирівнюючи середню потужність `P_avg` до граничної допустимої `P_dc_max`, отримуємо допустимий піковий струм `I_peak`:

```
I_peak
= I_dc_max / D                                      [рівність середньої потужності тривалому ліміту]
= 50 мА / 0.33                                      [підстановка I_dc_max = 50 мА та D = 0.33]
≈ 150 мА                                            [допустимий піковий струм у меандрі]
```

У коротких пачках імпульсів (тривалістю < 1 мс, як у протоколі NEC) теплова маса кристала дозволяє безпечно збільшувати піковий струм до `I_peak_burst ≈ 400..500 мА`.

### Динамічне зростання дальності зв'язку

Оптична потужність випромінювання `Ф_e` (у Вт/ср) інфрачервоного світлодіода прямо пропорційна інжектованому струму через зовнішній квантовий вихід `η_ext`:

```
Ф_e(I) = η_ext · I
```

Освітленість фотодіода `E_e` на відстані `r` від передавача визначається законом обернених квадратів:

```
E_e(r) = Ф_e / r² = (η_ext · I) / r²
```

Щоб демодулятор приймача впевнено сформував логічний рівень, освітленість фотодіода повинна перевищувати порогову чутливість `E_e_min`:

```
E_e(r_max) = (η_ext · I_peak) / r_max² = E_e_min
```

Звідси виражаємо граничну дальність зв'язку `r_max`:

```
r_max = √((η_ext · I_peak) / E_e_min)  ∝  √(I_peak)
```

Порівняємо граничну дальність при безперервному струмі `I_dc = 50 мА` та імпульсному струмі `I_peak = 450 мА` (зі шпаруватістю 33%):

```
r_max_ratio
= r_max_pulse / r_max_dc                            [відношення дальностей при імпульсному та DC струмі]
= √(I_peak / I_dc)                                  [скорочення послідовних параметрів світлодіода]
= √(450 / 50)                                       [підстановка I_peak = 450 мА та I_dc = 50 мА]
= √9                                                [квадратний корінь від відношення струмів]
= 3                                                 [збільшення дальності дії зв'язку втричі]
```

Математичний висновок очевидний: імпульсна модуляція несучою зі шпаруватістю 33% забезпечує 3-кратне збільшення дальності дії зв'язку при збереженні того самого середнього енергоспоживання від автономного джерела живлення.
