# 🧮 Математичний аналіз та динаміка петлі Костаса

Петля Костаса є фазовою системою автопідстройки частоти (PLL), призначеною для відновлення фази когерентної несучої з двосмугового сигналу з пригніченою несучою (DSB-SC) безпосередньо з інформаційних бічних смуг. Математична проблема когерентного детектування DSB-SC полягає у тому, що при зміні знака повідомлення `m(t)` фаза вихідного високочастотного сигналу інвертується на 180°. Класична фазова петля автопідстройки (PLL) сприймає ці стрибки фази як аварійну помилку генератора і втрачає синхронізм. Джон Костас у 1956 році запропонував математичний алгоритм множення квадратурних каналів, який робить сигнал фазової помилки інваріантним до знака повідомлення.

### 1. Математична модель вхідного сигналу та квадратурного розділення

Нехай на вхід приймача надходить DSB-SC сигнал з амплітудою несучої `A_c`, поточним фазовим викривленням `θ(t)` та модулюючим повідомленням `m(t)`:

```
s(t) = A_c · m(t) · cos(ω_c t + θ(t))
```

Локальний керований генератор (VCO / NCO) приймача генерує два квадратурних опорних коливання з поточним значенням оцінки фази `θ̂(t)`:

```
v_I(t) = 2 · cos(ω_c t + θ̂(t))
v_Q(t) = −2 · sin(ω_c t + θ̂(t))
```

Вхідний сигнал паралельно перемножується з опорними коливаннями у двох вітках — синфазній (I) та квадратурній (Q):

```
x_I(t) = s(t) · v_I(t) = 2·A_c·m(t) · cos(ω_c t + θ) · cos(ω_c t + θ̂)
x_Q(t) = s(t) · v_Q(t) = −2·A_c·m(t) · cos(ω_c t + θ) · sin(ω_c t + θ̂)
```

Застосовуючи тригонометричні тотожності добутку косинусів та синусів через суму й різницю аргументів `ϕ(t) = θ(t) − θ̂(t)` (де `ϕ` — поточна фазова помилка між несучою передавача та опорним генератором):

```
cos(A)·cos(B) = ½·[cos(A − B) + cos(A + B)]
cos(A)·sin(B) = ½·[sin(B − A) + sin(A + B)]
```

Отримуємо розкладання сигналів каналів I та Q до проходження низькочастотної фільтрації:

```
x_I(t) = A_c·m(t) · [cos(ϕ) + cos(2ω_c t + θ + θ̂)]         [добуток косинусів]
x_Q(t) = A_c·m(t) · [−sin(ϕ) − sin(2ω_c t + θ + θ̂)]        [добуток косинуса й синуса]
```

Обидва сигнали проходять крізь ідентичні низькочастотні фільтри (ФНЧ) з граничною частотою `f_lpf << f_c`, які повністю пригнічують складові з подвоєною частотою несучої `2ω_c`:

```
I(t) = LPF{x_I(t)} = A_c · m(t) · cos(ϕ)
Q(t) = LPF{x_Q(t)} = −A_c · m(t) · sin(ϕ)
```

Синхфазний вихід `I(t)` містить відновлене інформаційне повідомлення `m(t)`, але його амплітуда зважена на косинус фазової помилки `cos(ϕ)`. Якщо `ϕ = 0`, вихід `I(t) = A_c · m(t)` досягає максимуму. Квадратурний вихід `Q(t)` при `ϕ = 0` дорівнює нулю.

### 2. Дискримінатор фазової помилки та квадрат повідомлення

Щоб сформувати сигнал керування фазою VCO, виходи I та Q перемножуються у фазовому детекторі:

```
e(t) = I(t) · Q(t)
     = [A_c · m(t) · cos(ϕ)] · [−A_c · m(t) · sin(ϕ)]
     = −A_c² · m²(t) · cos(ϕ) · sin(ϕ)
     = −½ · A_c² · m²(t) · sin(2ϕ)                     [синус подвійного кута]
```

Ключова математична властивість виразу `e(t)` полягає в наявності квадрата повідомлення `m²(t)`. Оскільки `m²(t) ≥ 0` завжди додатний незалежно від того, додатне чи від'ємне повідомлення `m(t)` у дану мить, сигнал помилки `e(t)` не змінює знак при зміні полярності мовного чи цифрового сигналу!

Для аналізу динаміки захоплення фази усереднимо сигнал помилки `e(t)` по часу за допомогою середньої потужності повідомлення `P_m = E[m²(t)] > 0`:

```
e_avg(t) = −½ · A_c² · P_m · sin(2ϕ)
```

Характеристика дискримінатора `S(ϕ) = −½ A_c² P_m sin(2ϕ)` є періодичною функцією з періодом `π` (180°). При малих фазових відхиленнях `|ϕ| << 1` застосуємо лінеаризацію `sin(2ϕ) ≈ 2ϕ`:

```
e_avg(t) ≈ −A_c² · P_m · ϕ(t)
```

Отримана залежність показує, що дискримінатор створює відновлювальне зусилля, пропорційне фазовій помилці `ϕ`. Точки стабільної рівноваги дискримінатора відповідають умові `sin(2ϕ) = 0`, тобто:

```
2ϕ = 2kπ  =>  ϕ = kπ  (де k ∈ ℤ)
```

У межах одного періоду несучої існує два точки стійкого захоплення фази:
1. `ϕ = 0` (ідеальний синхронізм): `I(t) = A_c · m(t)` (прямий фазовий вихід);
2. `ϕ = π` (180° інверсія): `I(t) = −A_c · m(t)` (інвертований вихід).

Ця неоднозначність фази на 180° є фундаментальною для всіх систем з пригніченою несучою. У цифрових системах зв'язку вона усувається застосуванням відносного (диференціального) кодування бітів (де передається не абсолютна фаза, а її зміна між сусідніми тактами).

### 3. Передаточна функція замкненої петлі другого порядку

Розглянемо малогерметичну лінійну модель петлі Костаса у s-області Лапласа. Нехай `K_v` — крутизна керованого генератора VCO (рад/(с·В)), а `F(s)` — передаточна функція петльового пропорційно-інтегрального (PI) фільтра:

```
F(s) = K_p + K_i / s
```

Рівняння динаміки фази генератора `Θ_out(s)` відносно сигналу керування `V_ctrl(s)` має вигляд інтегратора:

```
Θ_out(s) = (K_v / s) · V_ctrl(s)
```

Сигнал керування створюється фазовим дискримінатором із коефіцієнтом передачі `K_d = A_c² P_m`:

```
V_ctrl(s) = F(s) · K_d · [Θ_in(s) − Θ_out(s)]
```

Підставляючи `V_ctrl(s)` у рівняння генератора, знаходимо передаточну функцію замкненої петлі `H(s) = Θ_out(s) / Θ_in(s)`:

```
H(s) = (K_d · K_v · F(s)) / (s + K_d · K_v · F(s))
```

Підставляючи передаточну функцію PI-фільтра `F(s) = K_p + K_i / s`, отримуємо канонічне рівняння петлі другого порядку:

```
H(s) = (K_d·K_v·K_p·s + K_d·K_v·K_i) / (s² + K_d·K_v·K_p·s + K_d·K_v·K_i)
```

Зіставляючи знаменник із канонічним рівнянням осцилятора `s² + 2·ζ·ω_n·s + ω_n²`, знаходимо власність частоту петлі `ω_n` та коефіцієнт демпфування `ζ`:

```
ω_n = √(K_d · K_v · K_i)
ζ = (K_d · K_v · K_p) / (2 · ω_n) = ½ · K_p · √( (K_d · K_v) / K_i )
```

Звідси розраховуються практичні коефіцієнти PI-фільтра для заданої частоти петлі `ω_n` та оптимального демпфування `ζ = 0.707` (аперіодичний процес без перерегулювання):

```
K_p = (2 · ζ · ω_n) / (K_d · K_v)
K_i = ω_n² / (K_d · K_v)
```

### 4. Смуга захоплення та смуга утримання (Pull-in Range)

Важливим характеристичним параметром петлі Костаса є максимальне частотне відхилення гетеродина `Δω_max = |ω_c − ω_LO|`, при якому петля здана самостійно захопити фазовий синхронізм без додаткових скануючих систем.

* **Смуга утримання (Lock-in Range, `Δω_L`):** смуга частот, у межах якої вже зсинхронізована петля зберігає фазове захоплення при повільному дрейфі частоти:
  ```
  Δω_L = K_d · K_v · F(0) = K_d · K_v · K_p
  ```
* **Смуга захоплення (Pull-in Range, `Δω_P`):** максимальна частотна расстройка, при якій рассинхронізована петля спроможна затягнути частоту VCO у стан синхронізму за рахунок нелінійного биття дискримінатора:
  ```
  Δω_P ≈ 2 · √(ζ · ω_n · K_d · K_v)
  ```
При перевищенні смуги захоплення `Δω > Δω_P` сигнал помилки `e(t)` перетворюється на високочастотне биття з нульовим середнім значенням, і VCO залишається на власній частоті.

### 5. Вплив шуму та втрати від подвоєння (Squaring Loss)

У присутності аддитивного білого гаусового шуму (AWGN) з двосторонньою спектральною щільністю `N_0 / 2` дисперсія фазової помилки петлі Костаса зростає порівняно з звичайною PLL через так звані **втрати від подвоєння** (англ. *squaring loss*, `S_L`).

Оскільки у фазовому детекторі перемножуються виходи I та Q, які містять як сигнал, так і відфільтровані шумові компоненти `n_I(t)` та `n_Q(t)`:

```
I(t) = A_c·m(t)·cos(ϕ) + n_I(t)
Q(t) = −A_c·m(t)·sin(ϕ) + n_Q(t)
```

Перемноження `I(t) · Q(t)` утворює перехресні шумові доданки типу `сигнал × шум` та `шум × шум`:

```
e(t) = −½ A_c² m²(t) sin(2ϕ) + A_c m(t) [n_Q cos ϕ − n_I sin ϕ] + n_I(t) n_Q(t)
```

Множник `n_I(t) · n_Q(t)` викликає додаткову деградацію відношення сигнал/шум у петлі. За Гарднером, втрати від подвоєння `S_L < 1` розраховуються через співвідношення потужності сигналу до шуму в низькочастотному фільтрі вітки `SNR_in = P_s / (N_0 · B_lpf)`:

```
S_L = 1 / (1 + 1 / (2 · SNR_in))
```

Дисперсія фазового шуму замкненої петлі дорівнює:

```
σ_ϕ² = (B_L · N_0) / (P_s · S_L)
```

де `B_L` — шумова смуга петлі (Гц). При низькому відношенні сигнал/шум (`SNR_in << 1`) втрати `S_L ≈ 2 · SNR_in` суттєво розширюють фазовий джитер, що вимагає звуження смуги петльового фільтра `B_L` для утримання синхронізму.

### 6. Узагальнення для QPSK та квадратурних модуляцій

Математична ідея Костаса щодо усунення фазової неоднозначності поширюється на чотирипозиційну фазову модуляцію (QPSK) та квадратурну модуляцію (QAM). Для QPSK-сигналу фазовий дискримінатор 4-го порядку будується на кубічній комбінації віток I та Q:

```
e_QPSK(t) = I(t) · Q(t) · [I²(t) − Q²(t)] = −⅛ · A_c⁴ · sin(4ϕ)
```

Цей дискримінатор створює стійкі точки захоплення фази через кожні 90° (`ϕ = k π / 2`), уможливлюючи відновлення когерентної несучої у супутникових та мобільних цифрових модемах.
