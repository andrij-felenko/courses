# 📋 Компоненти та схемотехніка балансних модуляторів

Балансний модулятор (англ. *balanced modulator*) — це аналоговий функціональний вузол, призначений для чотириквадрантного перемноження двох сигналів з глибоким пригніченням вихідної несучої частоти. На відміну від звичайних нелінійних змішувачів на одному транзисторі чи діоді, балансні модулятори застосовують симетричну топологію дифкаскадів або діодних мостів. Це дозволяє утворити два протифазні шляхи проходження сигналу несучої, які взаємно компенсують один одного у навантаженні.

Апаратна реалізація балансних модуляторів поділяється на дві великі категорії: пасивні діодні кільцеві збірки та активні інтегральні схеми на базі перемножувальної комірки Гілберта (Gilbert Cell).

### 1. Пасивні діодні змішувачі (ADE-1, SBL-1, TUF-1)

Пасивні балансні модулятори виготовляються у вигляді законсервованих металевих чи керамічних модулів для поверхневого (SMD) або наскрізного (THT) монтажу (наприклад, популярні серії Mini-Circuits ADE-1, SBL-1, TUF-1).

* **Внутрішній устрій:** чотири монолітно підібрані кремнієві діоди Шотткі (Schottky) у замкненій кільцевій конфігурації та два широкосмугові трансформатори на феритових кільцях з центрованими обмотками. Діоди Шотткі мають однакове падіння напруги у прямому напрямку `V_f` (розкид не більше 1–2 мілівольт), що є критичним для виключення асиметрії моста.
* **Призначення виводів (типовий RF-модуль):**
  * `RF` (Radio Frequency) — вихід двосмугового сигналу DSB-SC;
  * `LO` (Local Oscillator) — вхід потужного коливання несучої гетеродина;
  * `IF` (Intermediate Frequency) — вхід низькочастотного повідомлення `m(t)` (від 0 Гц / DC).
* **Класифікація за рівнем потужності гетеродина (LO Level):**
  * *Level 7 (Standard)* — вимагає потужності LO `+7 дБм` (0.5 В RMS на 50 Ом). Застосовується у стандартних приймачах;
  * *Level 13 (High Dynamic)* — вимагає потужності LO `+13 дБм` (1.0 В RMS). Забезпечує підвищену стійкість до завад;
  * *Level 17 (Very High)* — вимагає потужності LO `+17 дБм` (1.4 В RMS). Використовується у високолінійних приладах.
* **Ключові параметри:**
  * Пригнічення несучої (LO-to-RF isolation): **35–50 дБ**;
  * Втрати перетворення (Conversion Loss): **5.5–7.0 дБ**;
  * Точка перехоплення третього порядку (Input IP3): **+15…+25 дБм** (забезпечує надзвичайно високу динамічну стійкість до інтермодуляційних перевантажень).

### 2. Інтегральні активні балансні модулятори (MC1496, SA602/NE602)

Активні модулятори будуються на базі шеститранзисторної перемножувальної комірки Баррі Гілберта (Gilbert Cell). Схема складається з нижньої дифпари перетворювача напруги у струм (каскад крутизни) та верхньої чотиритранзисторної матриці перемикання струмів.

```
                  Vcc
                   │
           ┌───────┴───────┐
         [R_L]           [R_L]
           │               │
      ┌────┴────┐     ┌────┴────┐
     (Q3)      (Q4)  (Q5)      (Q6)  ← Верхній квадрат перемикання (LO)
      │    ╳    │     │    ╳    │
      └────┬────┘     └────┬────┘
           │               │
          (Q1)            (Q2)       ← Нижня дифпара крутизни (Вхід m(t))
           │               │
          [R_e]───────────[R_e]
           │               │
         (I_bias)        (I_bias)
```

* **Принцип роботи комірки Гілберта:**
  Нижня пара транзисторів `Q1-Q2` приймає аналогове повідомлення `m(t)` та перетворює його на протифазні зміннострумові компоненти `I_0 + Δi` та `I_0 − Δi`. Верхня чотиритранзисторна збірка `Q3-Q6` працюва як аналоговий комутатор: під впливом напруги несучої гетеродина `LO` вона по черзі перепрямовує струми колекторів `Q1` та `Q2` у ліве або праве навантаження `R_L`. В результаті навантаження бачить зміну полярності струму з частотою `LO`, виконуючи точне аналогове чотириквадрантне множення.

* **Мікросхема MC1496 (Motorola / ON Semi):** класичний двобалансний модулятор у корпусі DIP-14 / SOIC-14.
  * `Pin 1, 4` — диференціальний вхід інформаційного сигналу `m(t)` (каскад крутизни `Q1-Q2`);
  * `Pin 8, 10` — диференціальний вхід несучої гетеродина `c(t)` (квадрат перемикання `Q3-Q6`);
  * `Pin 6, 12` — диференціальний вихід DSB-SC (відкриті колектори `Q3-Q6`);
  * `Pin 2, 3` — виводи для підключення зовнішнього струмозадаючого резистора дегенерації емітерів `R_e` (регулює лінійність ВАХ та підсилення);
  * `Pin 5` — вхід зсуву внутрішнього джерела струму (Gain Adjust);
  * Пригнічення несучої: **50–65 дБ** на частотах до 100 МГц при ретельному підстроюванні симетрії потенціометром балансу.

* **Мікросхема SA602 / NE602 (NXP / Signetics):** малопотужний активний змішувач з вбудованим транзисторним гетеродином у корпусі SO-8.
  * `Pin 1, 2` — диференціальний вхід високої імпедансності для повідомлення/RF;
  * `Pin 4, 5` — диференціальний вихід з відкритими колекторами (вихідна імпедансність ~1.5 кОм);
  * `Pin 6, 7` — виводи внутрішнього генератора гетеродина (підключення кварцового чи LC-резонатора);
  * Пригнічення несучої: **30–40 дБ** (не вимагає зовнішніх трансформаторів, оптимально для простих прийомопередавачів).

### Схемотехнічні правила монтажу та балансування

1. **Симетрія друкованих провідників:** диференціальні лінії входу несучої та інформаційного сигналу повинні мати однакову довжину й однакову паразитичну ємність відносно землі. Найменша асиметрія друкованого монтажу лише на 1 пікофарад знижує пригнічення несучої на 10–15 децибел на частотах понад 10 МГц.
2. **Балансування по постійному струму:** для досягнення пригнічення понад 50 дБ у схемах на MC1496 застосовують підстроювальний потенціометр між емітерними або колекторними плечима для компенсації технологічного розкиду напруг `V_be` транзисторів (DC offset cancellation).
3. **Рівень потужності гетеродина (LO):** для діодних модуляторів потужність LO повинна повністю переводити діоди у режим насиченого ключа (зазвичай +7 дБм або 0.5 В RMS на 50 Ом). Нестача потужності LO рвучко збільшує втрати перетворення та знижує розв'язку між каналами.
4. **Вибір резистора дегенерації `R_e`:** у комірці Гілберта амплітуда входного сигналу `m(t)` обмежується термічним потенціалом `V_T = k T / q ≈ 26 мВ`. Щоб подавати сигнали амплітудою в кілька вольт без нелінійного спотворення, між емітерами `Q1-Q2` вмикають резистор `R_e`. Крутизна каскаду при цьому стає дорівнювати `g_m ≈ 1 / R_e`, розширюючи динамічний діапазон за рахунок зниження підсилення.
