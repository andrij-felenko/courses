# 🧮 Математика сузір'я QAM: евклідова відстань, енергія та ймовірність помилки

Квадратурна амплітудна модуляція порядку `M` (де `M = 2ᵏ`, `k` — кількість бітів на символ) описується сигнальним сузір'ям на двовимірній евклідовій площині синфазної `I` та квадратурної `Q` складових. Для квадратних сузір'їв (16-QAM, 64-QAM, 256-QAM) геометрична сітка формується незалежним декартовим добутком двох однакових 1D амплітудно-імпульсних модуляцій (PAM) з цифровим алфавітом `√M` рівнів.

### Модель сигналу та геометрія сітки

У неперервному часі переданий символ `s_i(t)` протягом одного символьного інтервалу тривалістю `T_s` подається через амплітуди `a_i` та `b_i`:

```
s_i(t) = a_i · g(t) · cos(ω_c t) - b_i · g(t) · sin(ω_c t),   0 ≤ t ≤ T_s
```

тут `g(t)` — огинаюча форми імпульсу (наприклад, корінь з піднятого косинуса RRC) з нормованою енергією `∫ g²(t) dt = 1`, а дискретні амплітудні коефіцієнти `a_i` та `b_i` набувають непарних цілих значень із симетричного відрізка:

```
a_i, b_i ∈ { ±1, ±3, ±5, ..., ±(√M - 1) }
```

На векторній I/Q площині кожен символ позначається точкою `s_i = (a_i, b_i)`. Найменша відстань між двома сусідніми точками уздовж координатної осі становить `Δ = 2`.

### Обчислення середньої енергії сузір'я

Енергія одного комплексного символу `E_s(a_i, b_i)` пропорційна квадрату його евклідової відстані від початку координат `(0, 0)`:

```
E_s(a_i, b_i) = (a_i² + b_i²) · E_0
```

де `E_0` — енергетичний масштабувальний коефіцієнт (енергія, що відповідає амплітуді 1). Для квадратного сузір'я з `M` точок середня енергія символу `E_avg` обчислюється як математичне сподівання за всіма `M` рівноймовірними станами:

```
E_avg = (1 / M) · ∑_{i=1}^{M} (a_i² + b_i²) · E_0
      = (1 / √M) · ∑_{a_i} a_i² · E_0  +  (1 / √M) · ∑_{b_i} b_i² · E_0     [через симетрію за I та Q]
      = (2 / √M) · ∑_{m=1}^{√M / 2} (2m - 1)² · E_0                         [сума квадратів непарних чисел]
```

Застосовуючи математичну формулу для суми квадратів перших непарних чисел `∑_{m=1}^{N} (2m - 1)² = N · (4N² - 1) / 3` при `N = √M / 2`, отримуємо точний аналітичний вираз:

```
E_avg = (2 / √M) · [ (√M / 2) · (4 · (M / 4) - 1) / 3 ] · E_0               [підстановка N = √M / 2]
      = (2 / 3) · (M - 1) · E_0                                            [точна середня енергія]
```

Звідси параметр масштабування `E_0` через середню енергію символу дорівнює:

```
E_0 = 3 · E_avg / (2 · (M - 1))
```

### Мінімальна евклідова відстань d_min

Мінімальна евклідова відстань між будь-якими двома сусідніми станами в сузір'ї визначена як `d_min = 2 · √E_0`. Виражаючи `d_min` через середню енергію символу `E_avg` та кількість бітів на символ `k = log₂ M`, отримуємо:

```
d_min = 2 · √[ 3 · E_avg / (2 · (M - 1)) ]
      = √[ 6 · E_avg / (M - 1) ]
```

Якщо ж виразити енергію через енергію на один біт `E_b = E_avg / k = E_avg / log₂ M`, то відстань `d_min` набуває вигляду:

```
d_min = √[ 6 · log₂ M · E_b / (M - 1) ]
```

Ця формула явно демонструє штраф за нарощування порядку модуляції `M`: при переході від QPSK (`M=4`) до 16-QAM (`M=16`) та 64-QAM (`M=64`) коефіцієнт `6 · log₂ M / (M - 1)` зменшується від `6 · 2 / 3 = 4.0` для QPSK до `6 · 4 / 15 = 1.6` для 16-QAM та `6 · 6 / 63 = 0.57` для 64-QAM. Щоб утримати ту саму евклідову відстань `d_min` і завадостійкість, енергію сигналу `E_b` доводиться підвищувати.

### Геометрія осередків Вороного та прийняття рішень

Область прийняття рішень для кожної точки сузір'я `s_i` являє собою осередок Вороного — множину точок `y` на I/Q площині, для яких відстань `|y - s_i|` є меншою, ніж до будь-якої іншої точки `s_j`. Для квадратного сузір'я `M`-QAM точки розбиваються на три класи за топологією їхніх меж:

1. **Внутрішні точки (Interior points):** мають 4 найближчі сусідні точки на відстані `d_min`. Кількість таких точок у сузір'ї становить `(√M - 2)²`. Для внутрішньої точки помилка виникає, коли шум за оссю `I` або оссю `Q` перевищує поріг `d_min / 2` в будь-який із 4 боків.
2. **Крайові точки (Edge points):** розташовані на межах сузір'я (крім кутів) і мають 3 найближчих сусідів. Кількість таких точок дорівнює `4 · (√M - 2)`.
3. **Кутові точки (Corner points):** розташовані у 4 кутах квадратного сузір'я і мають лише 2 найближчих сусідів. Їхня кількість завжди дорівнює 4.

Оскільки для кутових точок шумові поштовхи назовні сузір'я не спричиняють помилки прийняття рішень, точне усереднення ймовірності помилки за всіма трьома типами точок дає аналітичну формулу для `M`-QAM.

### Ймовірність символьної та бітової помилки у каналі AWGN

У каналі з аддитивним білим гаусовим шумом (AWGN) двовимірний вектор шуму має незалежні квадратурні складові `n_I, n_Q ~ N(0, σ²)`, де дисперсія шуму на одну вісь становить `σ² = N_0 / 2`.

Оскільки прийняття рішення для квадратного QAM розпадається на два незалежні одновимірні прийняття рішень для 1D PAM за осями `I` та `Q`, ймовірність правильного прийому 2D-символу дорівнює добутку ймовірностей правильного рішення по кожній осі:

```
P_correct = (1 - P_√M)²
```

де `P_√M` — ймовірність помилки для одновимірної модуляції `√M`-PAM. Для внутрішніх точок PAM помилка виникає, коли шум перевищує пороги `± d_min / 2` у два боки, а для крайніх точок — лише в один бік. У середньому для `√M`-PAM:

```
P_√M = 2 · (1 - 1 / √M) · Q( d_min / (2 · σ) )
```

Підставляючи `d_min / (2 · σ) = √[ 6 · E_avg / (M - 1) ] / (2 · √(N_0 / 2)) = √[ 3 · E_avg / ((M - 1) · N_0) ]`, маємо:

```
P_√M = 2 · (1 - 1 / √M) · Q( √[ 3 · E_s / ((M - 1) · N_0) ] )
```

Точна ймовірність символьної помилки (SER) квадратного `M`-QAM становить:

```
P_s = 1 - P_correct
    = 1 - (1 - P_√M)²
    = 2 · P_√M - P_√M²
    ≈ 4 · (1 - 1 / √M) · Q( √[ 3 · E_s / ((M - 1) · N_0) ] )                   [наближення при високому SNR]
```

За умови застосування 2D кодування Грея сусідні точки сузір'я відрізняються лише одним бітом. За високого відношення сигнал/шум домінуючі помилки виникають лише між найближчими сусідніми точками, тому ймовірність бітової помилки (BER) з високою точністю пов'язана з SER співвідношенням:

```
P_b ≈ P_s / (log₂ M)
    ≈ [ 4 / log₂ M ] · (1 - 1 / √M) · Q( √[ 3 · log₂ M · E_b / ((M - 1) · N_0) ] )
```

### Пік-фактор потужності (PAPR) та аналіз нелінійностей

Оскільки точки сузір'я QAM мають різну відстань від початку координат, пікова амплітуда `A_max` суттєво перевищує середньоквадратичну амплітуду `A_rms`. Пік-фактор (PAPR) квадратного `M`-QAM обчислюється як відношення пікової енергії крайнього кутового символу до середньої енергії:

```
PAPR = E_max / E_avg
     = [ 2 · (√M - 1)² · E_0 ] / [ (2 / 3) · (M - 1) · E_0 ]                [кутова точка має a_i = b_i = √M - 1]
     = 3 · (√M - 1)² / (M - 1)
     = 3 · (√M - 1) / (√M + 1)
```

Обчислюючи значення PAPR для різних порядків QAM:

```
QPSK   (M=4)   : PAPR = 3 · (2 - 1) / (2 + 1) = 1.00  (0.00 дБ)
16-QAM (M=16)  : PAPR = 3 · (4 - 1) / (4 + 1) = 1.80  (2.55 дБ)
64-QAM (M=64)  : PAPR = 3 · (8 - 1) / (8 + 1) = 2.33  (3.68 дБ)
256-QAM(M=256) : PAPR = 3 · (16 - 1)/ (16 + 1)= 2.65  (4.23 дБ)
```

Високий пік-фактор вимагає від підсилювачів потужності (PA) передавача широкого лінійного динамічного діапазону. Зайдення піків QAM-сигналу у зону насичення підсилювача викликає нелінійне зрізання (*clipping*), спотворення сузір'я та позасмугове випромінювання (*spectral regrowth*).
