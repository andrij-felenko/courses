# 🧮 Тригонометричний аналіз колірної квадратури та скасування фазової помилки

Передача двох колірно-різницевих сигналів `U(t)` та `V(t)` у повній аналоговій колірності спирається на принципи квадратурної модуляції, де несуче коливання розкладається на дві ортогональні гармоніки. Математична стійкість стандарту PAL проти фазових спотворень каналу зв'язку доводиться тригонометричним аналізом взаємодії 1H лінії затримки та матричних виділювачів.

### 1. Квадратурна модель колірної піднесучої

Нехай `U(t) = 0.493·(B(t) - Y(t))` та `V(t) = 0.877·(R(t) - Y(t))` — нормовані колірно-різницеві сигнали синього та червоного кольорів. Модульований колірний сигнал `C(t)` на піднесучій кутовій частоті `ω[sc] = 2·π·f[sc]` виражається сумою синфазного та квадратурного компонентів:
```
C(t) = U(t)·sin(ω[sc]·t) + V(t)·cos(ω[sc]·t)    [ортогональна сума QAM]
```

За допомогою тригонометричного перетворення `A·sin(x) + B·cos(x) = R·sin(x + θ)` виражаємо сигнал через миттєву амплітуду `R(t)` та фазовий кут `θ(t)`:
```
R(t) = √(U²(t) + V²(t))                         [насиченість кольору / Saturation]
θ(t) = arctan(V(t) / U(t))                      [колірний тон / Hue]

C(t) = R(t)·sin(ω[sc]·t + θ(t))                 [полярна форма піднесучої]
```

Отже, відстань від початку координат до точки у квадратурній площині `U–V` показує насиченість кольору, а кут повороту вектора визначає колірний відтінок (наприклад, червоний `≈ 103°`, зелений `≈ 241°`, синій `≈ 347°`).

Геометрично сигнал піднесучої являє собою обертальний вектор (фазор) у двовимірній декартовій системі координат `(U, V)`. Осі `U` та `V` перпендикулярні одна до одної, а це означає, що їхній скалярний добуток за період піднесучої дорівнює нулю. Це забезпечує математичну ортогональність двох сигналів при когерентній демодуляції.

### 2. Математична модель спотворення NTSC

При поширенні через реальний канал зв'язку (радіоефір або кабель) високочастотна піднесуча зазнає фазового зсуву `Δφ` через багатопроменевість або нелінійність підсилювачів:
```
C[rx](t) = R(t)·sin(ω[sc]·t + θ(t) + Δφ)        [сигнал у приймачі з фазовою помилкою Δφ]
```

Демодуляція у приймачі NTSC виконується шляхом перемножування вхідного сигналу на опорні коливання `sin(ω[sc]·t)` та `cos(ω[sc]·t)` з наступною фільтрацією низьких частот (ФНЧ):
```
U[demod] = ФНЧ{ C[rx](t) · 2·sin(ω[sc]·t) }
         = ФНЧ{ 2·R(t)·sin(ω[sc]·t + θ + Δφ)·sin(ω[sc]·t) }
```

Використовуючи тригонометричну тотожність для добутку синусів `2·sin(A)·sin(B) = cos(A-B) - cos(A+B)`, після видалення подвоєної частоти `2·ω[sc]` ФНЧ отримуємо:
```
U[demod] = R(t)·cos(θ + Δφ)
         = R(t)·[cos(θ)·cos(Δφ) - sin(θ)·sin(Δφ)]
```

Оскільки за означенням `U = R·cos(θ)` та `V = R·sin(θ)`, відновлені компоненти NTSC виражаються матрицею повороту на кут `Δφ`:
```
U[NTSC] = U·cos(Δφ) - V·sin(Δφ)                 [перехресна завада на U у NTSC]
V[NTSC] = V·cos(Δφ) + U·sin(Δφ)                 [перехресна завада на V у NTSC]
```

У матричній формі це перетворення має вигляд класичної матриці повороту вектора:
```
[ U[NTSC] ]   [  cos(Δφ)  -sin(Δφ) ] [ U ]
[ V[NTSC] ] = [  sin(Δφ)   cos(Δφ) ] [ V ]
```

Аналіз цього перетворення показує, що фазовий зсув `Δφ` викликає **перехресне змішування (cross-talk)** між колірними компонентами `U` та `V`. Обчислений відновителем кут тону перетворюється на:
```
θ[NTSC] = arctan(V[NTSC] / U[NTSC]) = θ + Δφ     [зсув тону в NTSC дорівнює Δφ]
```

Фазова помилка `Δφ` напряму додається до колірного тону. Зсув на `Δφ = +10°` повністю змінює натуральний рожевий колір шкіри обличчя на зеленкувато-жовтий, а `Δφ = -10°` — на пурпурово-фіолетовий.

### 3. Алгебра фазового маятника PAL

У стандарті PAL фаза колірно-різницевої компоненти `V(t)` перевертається на `180°` (`cos(ω[sc]·t + π) = -cos(ω[sc]·t)`) на кожному наступному рядку розгортки:
```
C_N(t)   = U·sin(ω[sc]·t) + V·cos(ω[sc]·t)     [рядок N: прямий +V]
C_N1(t)  = U·sin(ω[sc]·t) - V·cos(ω[sc]·t)     [рядок N+1: інверсний -V]
```

При наявності фазового зсуву каналу `Δφ` обидва рядки набувають однакової фазової добавки:
```
C_N_rx(t)  = U·sin(ω[sc]·t + Δφ) + V·cos(ω[sc]·t + Δφ)   [рядок N із завадою]
C_N1_rx(t) = U·sin(ω[sc]·t + Δφ) - V·cos(ω[sc]·t + Δφ)   [рядок N+1 із завадою]
```

У геометричному представленні вектор колірності на рядку `N` повернутий на кут `+(θ + Δφ)`, а на рядку `N+1` після інверсії `V` — на кут `-(θ - Δφ)`. Вектори утворюють симетричний маятник відносно осі `U`.

### 4. Взаємодія з 1H лінією затримки та скасування помилки

У декодері *Standard PAL* вхідний сигнал розгалужується на два паралельні канали: прямий `C_N(t)` та затриманий ультразвуковою лінією на один рядок (`T[H] = 64.0 мкс`) `C_{N-1}(t) ≈ C_{N+1}(t)`. Сигнали надходять на матричний суматор та віднімач.

#### 4.1. Виділення синфазного компонента `U` (Сумування)

Сума двох послідовних рядків дорівнює:
```
S_U(t) = (C_N_rx(t) + C_N1_rx(t)) / 2           [сумування вхідних рядків]
       = U·sin(ω[sc]·t + Δφ)                    [скасування компоненти V]
       = U·[sin(ω[sc]·t)·cos(Δφ) + cos(ω[sc]·t)·sin(Δφ)]
```

При синхронному демодулюванні шляхом множення на `sin(ω[sc]·t)` та фільтрації ФНЧ отримуємо:
```
U[out] = U·cos(Δφ)                             [амплітуда U після НЧ-фільтрації]
```

#### 4.2. Виділення квадратурного компонента `V` (Віднімання)

Різниця двох послідовних рядків дорівнює:
```
D_V(t) = (C_N_rx(t) - C_N1_rx(t)) / 2           [віднімання вхідних рядків]
       = V·cos(ω[sc]·t + Δφ)                    [скасування компоненти U]
       = V·[cos(ω[sc]·t)·cos(Δφ) - sin(ω[sc]·t)·sin(Δφ)]
```

Синхронний демодулятор компонента `V` помножує результат на `cos(ω[sc]·t)` зі змінним знаком `±1` (керованим електронним ключем PAL) та ФНЧ, отримуючи:
```
V[out] = V·cos(Δφ)                             [амплітуда V після НЧ-фільтрації]
```

### 5. Підсумковий доказ скасування спотворення тону

Обчислимо відновлені параметри колірного вектора на виході декодера PAL:

1. **Відновлений колірний тон (`θ[out]`):**
```
θ[out] = arctan(V[out] / U[out])
       = arctan((V·cos(Δφ)) / (U·cos(Δφ)))
       = arctan(V / U) = θ                     [абсолютна точність тону θ]
```

   Множник `cos(Δφ)` у чисельнику та знаменнику скорочується повністю. **Колірний тон `θ[out]` дорівнює початковому тону `θ` і взагалі не залежить від фазової помилки `Δφ`!**

2. **Відновлена насиченість (`R[out]`):**
```
R[out] = √(U[out]² + V[out]²)
       = √((U·cos(Δφ))² + (V·cos(Δφ))²)
       = √(U² + V²) · cos(Δφ) = R_0 · cos(Δφ)  [скалювання насиченості на cos(Δφ)]
```

Насиченість кольору зменшується на множник `cos(Δφ)`. Обчислимо величину цього спаду для реальних фазових розходженнях:

- При `Δφ = 5°`: `cos(5°) ≈ 0.9962` (втрата насиченості всього `0.38%`).
- При `Δφ = 10°`: `cos(10°) ≈ 0.9848` (втрата насиченості всього `1.52%`).
- При `Δφ = 15°`: `cos(15°) ≈ 0.9659` (втрата насиченості всього `3.41%`).
- При `Δφ = 20°`: `cos(20°) ≈ 0.9397` (втрата насиченості `6.03%`).

Оскільки поріг чутливості людського ока до зміни насиченості становить близько `5–8%`, фазова помилка до `15–20°` у системі PAL залишається абсолютно непомітною для глядача. Небезпечне спотворення кольору обличчя повністю трансформувалося у мізерне, фізично невідчутне знебарвлення.

### 6. Спектральне розщеплення та вибір чвертьрядкового зсуву

Періодична інверсія компоненти `V` із частотою `f[H] / 2` математично еквівалентна множенню `V(t)` на прямокутний меандр `m(t)` амплітудою `±1`. Спектр цього меандру складається з непарних гармонік напіврядкової частоти:
```
m(t) = (4 / π) · ∑[k=0..∞] (1 / (2k + 1)) · cos(2·π·(2k + 1)·(f[H] / 2)·t)
```

Внаслідок такого перемноження спектральні піки компонента `V` розщеплюються і зміщуються відносно гармонік яскравості `n·f[H]` на `±f[H] / 2`. 

Щоб запобігти накладанню розщеплених піків `V` на піки `U` та `Y`, у системі PAL частоту піднесучої обрано із чвертьрядковим зсувом `f[H] / 4` та кадровою поправкою `25 Гц`:
```
f[sc] = (284 - 1/4)·f[H] + 25 Гц = 4.43361875 МГц   [формула частоти піднесучої PAL]
```

Цей точний математичний вибір гарантує, що всі три спектральні родинні піки (`Y`, `U`, `V`) розташовані у взаємно ортогональних частотних проміжках, забезпечуючи ідеальне спектральне пакування аналогового телесигналу.

### 7. Комплексна геометрія векторного розкладу

Для глибокого інтуїтивного розуміння корисно розглянути процес компенсації у комплексній площині C.

Нехай початковий сигнал колірності описується комплексним фазором:
```
Z_0 = U + j·V = R_0 · e^(j·θ)
```

У системі NTSC фазова завада каналу еквівалентна множенню фазора на комплексний множник повороту `e^(j·Δφ)`:
```
Z_NTSC = Z_0 · e^(j·Δφ) = R_0 · e^(j·(θ + Δφ))
```
Кут аргументу аргументу комплексного числа прямо приймає відхилення `Δφ`, змінюючи вихідний вектор тону.

У системі PAL на рядку `N` маємо фазор `Z_N = U + j·V`, а на рядку `N+1` — комплексно-спряжений фазор з інверсованою уявною частиною `Z_{N+1} = U - j·V`.

Внесення фазового зсуву `Δφ` обертає обидва фазори у комплексній площині:
```
Z_N_rx    = (U + j·V) · e^(j·Δφ)
Z_N1_rx   = (U - j·V) · e^(j·Δφ)
```

Декодер PAL спрягає уявну частину рядка `N+1` назад (інвертує знак перед `j`), що еквівалентно комплексному спряженню `(Z_{N+1}_rx)*`:
```
Z_N1_rec  = (U + j·V) · e^(-j·Δφ)
```

Сумування двох рядків у декодері дає середнє арифметичне двох комплексних фазорів:
```
Z_avg = 0.5 · (Z_N_rx + Z_N1_rec)
      = 0.5 · (U + j·V) · (e^(j·Δφ) + e^(-j·Δφ))
```

Використовуючи формулу Ейлера `(e^(j·Δφ) + e^(-j·Δφ)) / 2 = cos(Δφ)`, виділяємо остаточний комплексний результат:
```
Z_avg = (U + j·V) · cos(Δφ) = Z_0 · cos(Δφ)
```

Комплексний аналіз беззаперечно доводить: вектор результату `Z_avg` колінеарний початковому вектору `Z_0` (зберігає напрямок фазового кута `θ`), змінюючи лише модуль на дійсний скалярний коефіцієнт `cos(Δφ)`.
