# 🧮 Розрахунок таймінгів комутації шини та обмежень Open-Drain

Фізичні процеси заряду паразитної ємності, затримки перемикання транзисторних ключів і швидкість поширення електромагнітної хвилі в кабелі задають жорсткі математичні межі для швидкості передачі (бодрейту), мінімального захисного часу (Turnaround Time), допустимого розходження частот тактових генераторів, коефіцієнтів відбиття хвилі, запасу завадостійкості, коефіцієнта придушення синфазних завад (CMRR), смуги пропускання лінії за рівнем -3 дБ, теплового навантаження вихідних ключів та вікна очікування відповіді (Response Timeout). Розрахуємо покроково граничні часові та електричні параметри напівдуплексних ліній UART.

### 1. Розрахунок часу наростання фронту та максимальної швидкості Open-Drain

В однопровідній конфігурації з відкритим стоком (*Open-Drain*) спадний фронт формується активним замиканням лінії на землю через транзистор із малим опором відкритого каналу (`R_DS(on) ≈ 10...30 Ом`), тому час спаду `t_f` становить лічені наносекунди.

Наростаючий фронт формується виключно пасивним зарядом сумарної ємності лінії `C_bus` через підтяжний резистор `R_pu`. Напруга на лінії в процесі заряду описується експоненційним рівнянням:

```
V(t) = V_CC · (1 - e^(-t / (R_pu · C_bus)))
```

Виведемо час наростання `t_r` від 10% до 90% від напруги живлення `V_CC`:

```
V(t₁) = 0.1 · V_CC
1 - e^(-t₁ / τ) = 0.1
e^(-t₁ / τ) = 0.9
t₁ = -τ · ln(0.9) = τ · ln(1 / 0.9) ≈ 0.1054 · τ     [де τ = R_pu · C_bus]

V(t₂) = 0.9 · V_CC
1 - e^(-t₂ / τ) = 0.9
e^(-t₂ / τ) = 0.1
t₂ = -τ · ln(0.1) = τ · ln(10) ≈ 2.3026 · τ

t_r = t₂ - t₁
    = τ · (ln(10) - ln(10/9))
    = τ · ln(9)                                      [властивість логарифма: ln(a) - ln(b) = ln(a/b)]
    ≈ 2.1972 · R_pu · C_bus
```

Для стабільного детектування старт-біта та стробування даних приймачем UART час наростання фронту не повинен перевищувати 25% від тривалості одного біта `T_bit`:

```
t_r ≤ 0.25 · T_bit

2.1972 · R_pu · C_bus ≤ 0.25 · (1 / Baud)

Baud_max = 0.25 / (2.1972 · R_pu · C_bus)
         ≈ 0.1138 / (R_pu · C_bus)
```

**Числовий приклад:**
Нехай лінія має довжину 2 метри, сумарну паразитну ємність `C_bus = 200 пФ` (кабель 120 пФ + входи чотирьох мікроконтролерів по 20 пФ) та резистор підтяжки `R_pu = 4.7 кОм`:

```
τ = 4700 Ом · 200 · 10⁻¹² Ф = 0.94 мкс
t_r = 2.1972 · 0.94 мкс ≈ 2.065 мкс

Baud_max = 0.1138 / (4700 · 200 · 10⁻¹²) ≈ 121 000 бод
```

*Висновок:* на такій лінії стандартна швидкість 115200 бод (`T_bit = 8.68 мкс`) є гранично допустимою (`t_r / T_bit ≈ 23.8%`). Для переходу на 460800 бод необхідно зменшувати опір `R_pu` до 1 кОм, що збільшить струм, який споживає відкритий транзистор під час передачі нуля (`I = 3.3 В / 1 кОм = 3.3 мА`).

#### Динамічна потужність розсіювання на підтяжці
Коли на лінії постійно передаються нульові біти, через резистор `R_pu` безперервно тече струм. Потужність, що розсіюється на резисторі, визначається коефіцієнтом заповнення низького рівня `D_zero`:

```
P_avg = (V_CC² / R_pu) · D_zero

При V_CC = 3.3 В, R_pu = 1 кОм та D_zero = 0.5 (рівна кількість нулів і одиниць):
P_avg = (3.3² / 1000) · 0.5 = (10.89 / 1000) · 0.5 ≈ 5.45 мВт
```

### 2. Допустима похибка генераторів частоти при асиметрії фронтів

Приймач UART починає відлік часу за спадним фронтом старт-біта і стробує кожен біт у його центрі (на 8-му такті при 16-кратному оверсемплінгу).

У симетричній двотактній лінії ідеальний центр останнього (стоп) біта розташований на часовій позначці:

```
T_sample_stop = (N_bits - 0.5) · T_bit           [де N_bits = 1 старт + 8 даних + 1 стоп = 10 біт]
T_sample_stop = 9.5 · T_bit
```

Якщо тактові генератори передавача і приймача мають відносне розходження частот `Δf / f`, накопичена похибка вибірки на 10-му біті становить `ΔT = 9.5 · (Δf / f) · T_bit`. Щоб точка вибірки не випала за межі вікна стробування (половина біта `±0.5 · T_bit`), розходження має задовольняти умову:

```
9.5 · (Δf / f) < 0.5 - (t_r / T_bit)
```

У двотактній лінії, де `t_r ≈ 0`, теоретичний запас по частоті становить `Δf / f < 0.5 / 9.5 ≈ 5.26%` (на практиці беруть ліміт `±2.5...3%`).

Проте в лінії Open-Drain наростаючий фронт затягнутий на `t_r = 0.25 · T_bit`. Відповідно, безпечне вікно вибірки зменшується:

```
Δf / f < (0.5 - 0.25) / 9.5
       = 0.25 / 9.5
       ≈ 2.63%
```

Якщо затягування фронту досягає 35% тривалості біта (`t_r = 0.35 · T_bit`), допустима похибка генераторів падає до:

```
Δf / f < (0.5 - 0.35) / 9.5 = 0.15 / 9.5 ≈ 1.58%
```

Це пояснює, чому однопровідний UART на внутрішніх RC-генераторах мікроконтролерів (які мають нестабільність до `±2%` у робочому діапазоні температур) часто зазнає збоїв на швидкостях понад 57600 бод без точного кварцового резонатора.

#### Вплив вибору 8-кратного проти 16-кратного оверсемплінгу
При переході з 16-кратного на 8-кратний оверсемплінг (біт `OVER8 = 1` у регістрі `USART_CR1`) максимальна підтримувана швидкість мікроконтролера подвоюється:

```
Baud_max_8x = f_PCLK / (8 · USARTDIV) = 2 · Baud_max_16x
```

Проте ширина вікна вибірки центру біта зменшується з 3 підтактів (7, 8, 9 із 16) до однієї центральної вибірки (на 4-му підтакті з 8), або трьох стиснених (3, 4, 5). Це знижує стійкість до високочастотних шумових перешкод у 2 рази, роблячи режим `OVER8` придатним виключно для чистих друкованих плат із короткими трасами без довгих кабелів.

### 3. Бюджет часу перемикання шини (Turnaround Time Budget)

Час перемикання шини `T_turnaround` — це мінімальний інтервал між завершенням останнього стоп-біта ведучого та початком генерації старт-біта веденим.

Повний бюджет часу складається з п'яти фізичних компонентів:

```
T_turnaround = t_disable + t_prop + t_settle + t_enable + t_sw_margin
```

1. **`t_disable`:** час вимкнення драйвера ведучого (перехід виходів трансивера у стан Hi-Z). Береться з документації трансивера як `max(t_PLZ, t_PHZ)`.
2. **`t_prop`:** час поширення сигналу кабелем туди й назад. Обчислюється через коефіцієнт укорочення (*Velocity Factor*, `VF ≈ 0.66...0.70` для витої пари з поліетиленовою ізоляцією):
   ```
   v = c · VF ≈ 3 · 10⁸ м/с · 0.67 ≈ 2 · 10⁸ м/с = 200 м/мкс (або 5 нс/м)
   t_prop = 2 · L / v
   ```
3. **`t_settle`:** час релаксації перехідних процесів та розряду залишкової енергії в термінаторах і ємності лінії:
   ```
   t_settle ≈ 3 · R_term · C_total
   ```
4. **`t_enable`:** час увімкнення драйвера веденого вузла (`max(t_PZL, t_PZH)`).
5. **`t_sw_margin`:** програмний запас на фазове тремтіння (джиттер) обробки переривань у мікроконтролері.

**Розрахунок для трьох типових довжин промислової лінії RS-485:**
Параметри: трансивери SN65HVD72 (`t_disable = 150 нс`, `t_enable = 150 нс`), швидкість 115200 бод (`T_bit = 8.68 мкс`), ємність кабелю 50 пФ/м, термінація 60 Ом (еквівалент двох резисторів по 120 Ом).

```
1. Коротка лінія (L = 10 метрів):
   t_prop   = 2 · 10 м · 5 нс/м = 100 нс = 0.10 мкс
   t_settle = 3 · 60 Ом · (10 м · 50 пФ/м) = 180 · 500 пФ = 0.09 мкс
   T_turnaround_min = 0.15 + 0.10 + 0.09 + 0.15 + 8.68 ≈ 9.17 мкс (~1.1 біта)

2. Середня лінія (L = 100 метрів):
   t_prop   = 2 · 100 м · 5 нс/м = 1000 нс = 1.00 мкс
   t_settle = 3 · 60 Ом · (100 м · 50 пФ/м) = 180 · 5 нФ = 0.90 мкс
   T_turnaround_min = 0.15 + 1.00 + 0.90 + 0.15 + 8.68 ≈ 10.88 мкс (~1.25 біта)

3. Довга лінія (L = 600 метрів):
   t_prop   = 2 · 600 м · 5 нс/м = 6000 нс = 6.00 мкс
   t_settle = 3 · 60 Ом · (600 м · 50 пФ/м) = 180 · 30 нФ = 5.40 мкс
   T_turnaround_min = 0.15 + 6.00 + 5.40 + 0.15 + 17.36 ≈ 29.06 мкс (~3.35 біта)
```

*Висновок:* для коротких ліній достатньо захисної паузи в 1–1.5 біта, але на довгих магістралях (600–1200 м) пауза має бути не менше 3.5 бітових інтервалів для гарантованого уникнення зустрічного струму драйверів.

### 4. Розрахунок вікна таймауту очікування відповіді (Master Response Timeout)

Ведучий пристрій після відправки запиту запускає апаратний або програмний таймер таймауту `T_timeout`. Якщо протягом цього інтервалу ведений не почав передачу, ведучий фіксує збій зв'язку і звільняє шину.

Формула розрахунку максимального часу транзакції:

```
T_timeout = T_turnaround_slave + T_frame_slave + T_prop_total + T_margin
```

Де:
- **`T_turnaround_slave`:** час обробки запиту процесором веденого та підготовки відповіді (залежить від алгоритму: від мікросекунд для апаратних датчиків до десятків мілісекунд при читанні зовнішньої пам'ять Flash/EEPROM).
- **`T_frame_slave`:** тривалість передачі пакета відповіді:
  ```
  T_frame_slave = N_bytes · (1 + N_data + N_parity + N_stop) · (1 / Baud)
  ```
- **`T_prop_total`:** подвійна затримка поширення кабелем (`2 · t_prop`).
- **`T_margin`:** захисний запас на розсинхронізацію генераторів бодрейту (±2...3%).

**Приклад для протоколу Modbus RTU (запит читання, відповідь 16 байт на 9600 бод):**

```
Формат кадру: 1 старт + 8 даних + 0 парності + 1 стоп = 10 біт/байт
Час 1 байта = 10 / 9600 ≈ 1.0417 мс

T_frame_slave = 16 байт · 1.0417 мс = 16.67 мс
T_turnaround_slave = 5.00 мс                         [час виконання функції у веденому]
t_prop_total = 0.01 мс                               [кабель 1000 метрів]
T_margin = 0.20 · T_frame_slave ≈ 3.33 мс

T_timeout = 5.00 + 16.67 + 0.01 + 3.33 = 25.01 мс
```

Таймер ведучого слід налаштувати на найближче стандартне значення із запасом — **30 мс**.

### 5. Пропускна здатність та ефективність опитування шини (Polling Efficiency)

Корисна пропускна здатність напівдуплексної шини завжди суттєво нижча за номінальний бодрейт через накладні витрати на чергування запитів, відповідей та захисних інтервалів.

Коефіцієнт корисної утилізації каналу `η` визначається відношенням часу передачі корисних даних до загального часу повної транзакції:

```
η = T_payload / (T_req + T_turnaround1 + T_resp + T_turnaround2 + T_idle)
```

**Порівняльний розрахунок частоти опитування робототехнічної шини (18 сервоприводів Dynamixel):**
Кожен привід опитується коротким пакетом (запит 6 байт, відповідь 8 байт). Довжина кадру: 10 біт на байт.

```
1. На швидкості 115200 бод (T_byte = 86.8 мкс):
   T_req          = 6 · 86.8 мкс = 520.8 мкс
   T_resp         = 8 · 86.8 мкс = 694.4 мкс
   T_turnaround   = 2 · 50 мкс = 100.0 мкс
   T_transaction  = 520.8 + 694.4 + 100.0 = 1315.2 мкс ≈ 1.315 мс

   Час опитування всіх 18 приводів = 18 · 1.315 мс = 23.67 мс
   Максимальна частота оновлення (FPS) = 1 / 0.02367 с ≈ 42.2 Гц

2. На швидкості 1 000 000 бод (T_byte = 10.0 мкс):
   T_req          = 6 · 10.0 мкс = 60.0 мкс
   T_resp         = 8 · 10.0 мкс = 80.0 мкс
   T_turnaround   = 2 · 10 мкс = 20.0 мкс
   T_transaction  = 60.0 + 80.0 + 20.0 = 160.0 мкс = 0.16 мс

   Час опитування всіх 18 приводів = 18 · 0.16 мс = 2.88 мс
   Максимальна частота оновлення (FPS) = 1 / 0.00288 с ≈ 347.2 Гц
```

Збільшення швидкості зв'язку з 115.2 кбіт/с до 1 Мбіт/с підвищує частоту контуру керування роботом у понад 8 разів, що критично для динамічної стабілізації кінцівок крокуючих роботів і маніпуляторів.

### 6. Розрахунок часових інтервалів міжсимвольної тиші (Modbus t1.5 та t3.5)

У багатьох асинхронних напівдуплексних протоколах межі пакетів визначаються не спеціальними керувальними символами (як у текстових протоколах), а **тривалістю пасивного стану лінії (тиші)**:

```
Інтервал t_1.5 (Inter-character timeout) : максимальна пауза між байтами одного кадру
Інтервал t_3.5 (Inter-frame delay)       : мінімальна пауза між завершенням одного кадру та початком наступного
```

Математичні правила обчислення:

1. **Для швидкостей Baud ≤ 19200 бод:**
   Таймінги розраховуються безпосередньо в бітових інтервалах:
   ```
   T_char = 11 · (1 / Baud)                          [11 біт: 1 старт, 8 даних, 1 парність, 1 стоп]
   t_1.5 = 1.5 · T_char = 16.5 / Baud
   t_3.5 = 3.5 · T_char = 38.5 / Baud
   ```

   *На швидкості 9600 бод:*
   ```
   t_1.5 = 16.5 / 9600 ≈ 1.719 мс
   t_3.5 = 38.5 / 9600 ≈ 4.010 мс
   ```

2. **Для швидкостей Baud > 19200 бод:**
   При високих швидкостях чисто бітовий інтервал стає занадто коротким (наприклад, на 115200 бод час `t_3.5` склав би 334 мкс), що перевищує типовий час обробки переривань і перемикання контексту простих мікроконтролерів. Тому стандарт фіксує абсолютні часові межі:
   ```
   t_1.5 = 750 мкс (константа)
   t_3.5 = 1750 мкс = 1.75 мс (константа)
   ```

### 7. Розрахунок коефіцієнта відбиття хвилі та узгодження імпедансу

Коли електромагнітний фронт біта поширюється довгою витою парою з хвильовим опором `Z_0 = 120 Ом`, на кінці кабелю виникає відбиття хвилі, якщо опір навантаження `Z_L` відрізняється від `Z_0`.

Коефіцієнт відбиття напруги `Γ` (Gamma) визначається формулою:

```
Γ = (Z_L - Z_0) / (Z_L + Z_0)
```

Розглянемо три характерні крайові випадки:

1. **Ідеально термінована лінія (`Z_L = 120 Ом`):**
   ```
   Γ = (120 - 120) / (120 + 120) = 0
   ```
   Відбиття відсутнє (`V_refl = 0 В`), уся енергія хвилі повністю поглинається термінатором. Сигнал залишається чистим і прямокутним.

2. **Розімкнений кінець лінії (`Z_L = ∞`, термінатор забули впаяти):**
   ```
   Γ = (∞ - 120) / (∞ + 120) = +1
   ```
   Хвиля повністю відбивається з тією ж полярністю (`V_refl = +V_inc`). На кінці кабелю амплітуда напруги подвоюється (`V_total = 2 · V_inc`), що викликає сильний резонансний дзвін і може перевищити граничну напругу входу приймача.

3. **Коротке замикання на кінці (`Z_L = 0 Ом`):**
   ```
   Γ = (0 - 120) / (0 + 120) = -1
   ```
   Хвиля відбивається в протифазі (`V_refl = -V_inc`), повністю гасячи напругу сигналу в нуль.

### 8. Розрахунок допустимої кількості вузлів для Open-Drain шини

Максимальна кількість вузлів `N_max`, які можна об'єднати на спільній однопровідній лінії Open-Drain, обмежується сумарною паразитною ємністю шини:

```
C_total = C_cable + C_pcb + N · C_node_in ≤ C_bus_max
```

Де:
- `C_bus_max = 0.1138 / (R_pu · Baud)` — гранична ємність за критерієм 25% затягування фронту.
- `C_cable = L · C_spec` — ємність провідника кабелю (типово 50...100 пФ/м).
- `C_node_in` — вхідна ємність виводу мікроконтролера та захисних діодів на платі (типово 10...15 пФ на вузол).

Звідси формула граничної кількості пристроїв:

```
N_max = (C_bus_max - C_cable - C_pcb) / C_node_in
```

**Приклад розрахунку:**
Лінія всередині корпусу робота довжиною `L = 1 метр` (`C_cable = 60 пФ`, `C_pcb = 20 пФ`), опір підтяжки `R_pu = 2.2 кОм`, швидкість 115200 бод, ємність кожного модуля `C_node_in = 12 пФ`:

```
C_bus_max = 0.1138 / (2200 · 115200) ≈ 449 пФ
N_max = (449 - 60 - 20) / 12 = 369 / 12 ≈ 30 вузлів
```

### 9. Омічне падіння напруги та ліміт довжини кабелю за опором жил

При значній довжині магістралі (понад 500 метрів) необхідно враховувати постійний омічний опір мідних провідників витої пари `R_loop`:

```
R_loop = 2 · L · R_wire_per_meter
```

Для стандартного крученого кабелю перерізом AWG 24 (діаметр жили 0.51 мм) опір одного провідника становить близько `0.085 Ом/м` (`R_loop ≈ 0.17 Ом/м`).

При підключенні на кінці лінії термінатора `R_term = 120 Ом` опір петлі утворює подільник напруги з термінатором. Диференційна напруга `V_OD_rx`, що доходить до найвіддаленішого приймача, дорівнює:

```
V_OD_rx = V_OD_tx · (R_term / (R_term + R_loop))
```

**Розрахунок для лінії L = 1000 метрів при V_OD_tx = 2.0 В:**
```
R_loop = 2 · 1000 м · 0.085 Ом/м = 170 Ом
V_OD_rx = 2.0 В · (120 / (120 + 170)) = 2.0 · (120 / 290) ≈ 0.827 В
```

Оскільки отримана напруга `0.827 В` суттєво перевищує мінімальний поріг чутливості приймача RS-485 (`200 мВ`), лінія 1000 метрів за омічним падінням має чотирикратний запас надійності.

### 10. Розрахунок теплового перегріву вихідних ключів при колізії (Bus Contention)

Коли два вузли одночасно активують передавачі (`DE1 = 1`, `DE2 = 1`) із протилежними логічними рівнями на виходах, через вихідний каскад протікає максимальний струм короткого замикання `I_sc` (типово 50...100 мА).

Потужність розсіювання на кристалі трансивера під час колізії становить:

```
P_contention = V_CC · I_sc

При V_CC = 5.0 В та I_sc = 80 мА:
P_contention = 5.0 В · 0.08 А = 0.4 Вт (400 мВт)
```

Перегрів напівпровідникового переходу `ΔT_j` відносно навколишнього середовища обчислюється через тепловий опір корпусу `θ_JA` (для корпусу SOIC-8 типове значення `θ_JA ≈ 160 °C/Вт`):

```
ΔT_j = P_contention · θ_JA = 0.4 Вт · 160 °C/Вт = 64 °C
```

Якщо робоча температура всередині шафи автоматики становить `+50 °C`, температура кристала сягає `T_j = 50 + 64 = 114 °C`, що наближається до порогу спрацьовування внутрішнього теплового захисту (*Thermal Shutdown* на рівні 150 °C).

### 11. Запас завадостійкості та відношення сигнал/шум (SNR)

Диференційний приймач має динамічний діапазон чутливості `V_th = ±200 мВ`. Рівень запасу завадостійкості (*Noise Margin*) визначається перевищенням залишкової диференційної амплітуди над порогом чутливості:

```
V_noise_margin = V_OD_rx - V_th

При V_OD_rx = 0.827 В (довга лінія 1000 м):
V_noise_margin = 827 мВ - 200 мВ = 627 мВ
```

Відношення диференційного сигналу до залишкової синфазної завади, перетвореної на диференційну через асиметрію кабелю (*Common-Mode to Differential Conversion*), обчислюється за формулою:

```
SNR_dB = 20 · log₁₀(V_noise_margin / V_diff_noise)
```

Якщо індукована диференційна завада становить `V_diff_noise = 50 мВ`:

```
SNR_dB = 20 · log₁₀(627 / 50) = 20 · log₁₀(12.54) ≈ 21.97 дБ
```

Запас понад 20 дБ гарантує безпомилкове детектування логічних рівнів в умовах промислового цеху без потреби в повторних передачах пакетів.

### 12. Частотна смуга пропускання лінії за рівнем -3 дБ

Сумарна ємність кабелю та вхідних каскадів приймачів утворює розподілений фільтр низьких частот (ФНЧ) разом із паралельним опором двох термінаторів `R_eq = 120 || 120 = 60 Ом`.

Гранична частота зрізу лінії зв'язку по рівню -3 дБ визначається класичною формулою:

```
f_-3dB = 1 / (2 · π · R_eq · C_total)
```

**Розрахунок для магістралі довжиною 500 метрів (32 вузли):**
```
C_cable = 500 м · 50 пФ/м = 25 000 пФ = 25 нФ
C_nodes = 32 · 15 пФ = 480 пФ ≈ 0.5 нФ
C_total = 25.5 нФ
R_eq = 60 Ом

f_-3dB = 1 / (2 · 3.14159 · 60 · 25.5 · 10⁻⁹)
       = 1 / (9.613 · 10⁻⁶)
       ≈ 104 000 Гц = 104 кГц
```

Для передачі прямокутного сигналу UART без катастрофічного розмивання очної діаграми (*Eye Diagram Closure*) основна гармоніка сигналу `f_0 = Baud / 2` повинна лежати нижче частоти зрізу `f_-3dB`. На швидкості 115200 бод `f_0 = 57.6 кГц < 104 кГц`, що гарантує збереження форми імпульсів.

### 13. Придушення синфазної завади каскадом приймача (CMRR)

Коефіцієнт придушення синфазного сигналу (*Common-Mode Rejection Ratio*, CMRR) показує здатність диференційного підсилювача ігнорувати високовольтні наведення промислової мережі, які однаково діють на обидва проводи витої пари:

```
CMRR_dB = 20 · log₁₀(A_diff / A_cm)
```

Де:
- `A_diff` — коефіцієнт підсилення корисного диференційного сигналу `V_AB`.
- `A_cm` — коефіцієнт передачі паразитної синфазної напруги `V_CM` на вихід компаратора.

Для промислових трансиверів із `CMRR ≥ 70 дБ` імпульсна завада від комутації потужних контакторів амплітудою `V_cm = 50 В` послаблюється вхідним каскадом до еквівалентної диференційної завади:

```
V_diff_equiv = V_cm / 10^(CMRR_dB / 20)           [визначення лінійного послаблення з децибелів]
             = 50 В / 10^(70 / 20)                 [підстановка V_cm = 50 В та CMRR = 70 дБ]
             = 50 В / 3162.28                      [обчислення значення степеня 10^3.5]
             ≈ 0.0158 В = 15.8 мВ                  [остаточний розрахунок залишкової амплітуди]
```

Оскільки `15.8 мВ` значно менше за поріг нечутливості компаратора (`±200 мВ`), високовольтний індукований сплеск повністю фільтрується вхідним симетричним трактом, не створюючи помилкових перемикань логічного рівня.

### 14. Розрахунок енергії розряду паразитної ємності при спадному фронті

Під час кожного переходу з логічної одиниці в нуль накопичена в ємності лінії енергія `E_cap` розсіюється на внутрішньому опорі відкритого транзистора `R_DS(on)`:

```
E_cap = 0.5 · C_total · V_CC²

При C_total = 25.5 нФ (магістраль 500 м) та V_CC = 5.0 В:
E_cap = 0.5 · (25.5 · 10⁻⁹ Ф) · (5.0 В)²
      = 0.5 · 25.5 · 10⁻⁹ · 25
      ≈ 318.75 · 10⁻⁹ Дж = 318.75 нДж
```

Середня потужність розсіювання комутаційних втрат при передачі меандру на швидкості 115200 бод (`f_sw = 57.6 кГц`):

```
P_sw = E_cap · f_sw
     = 318.75 · 10⁻⁹ Дж · 57 600 Гц
     ≈ 18.36 мВт
```

Ці втрати є незначними для дискретних вихідних ключів, але їх слід враховувати при проектуванні низькоспоживаючих автономних батарейних вузлів.
