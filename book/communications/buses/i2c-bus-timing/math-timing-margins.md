# 🧮 Розрахунок часових запасів та RC-затримок шини I²C

Розрахунок часових характеристик шини I²C базується на математичному моделюванні перехідних процесів у пасивному RC-колі, утвореному еквівалентним резистором підтяжки `R_p` та сумарною паразитною ємністю ліній `C_b`. На відміну від двотактних інтерфейсів (SPI, UART), де фронти формуються симетричними комплементарними транзисторами з внутрішнім опором у кілька десятків ом, у шині I²C час наростання напруги є експоненційною функцією ємності монтажу та підтягувального резистора.

Цей документ містить математичне виведення формули часу наростання сигналу, розрахунок допустимого діапазону опорів `R_p(min) ... R_p(max)`, математичну модель впливу послідовних демпферних резисторів `R_s`, оцінку перехресних ємнісних завад (*Cross-Talk*), статистичний аналіз допусків компонентів (найгірший випадок та розкид параметрів), розрахунок динамічного енергоспоживання, аналіз часових запасів встановлення й утримання даних (`t_SU;DAT`, `t_HD;DAT`), а також формулу деградації ефективної пропускної здатності шини при розтягуванні такту веденими пристроями.

---

### Математичне виведення часу наростання напруги `t_r`

Коли відкритий польовий транзистор передавача закривається, лінія переходить у стан високого імпедансу (Hi-Z), і струм від джерела живлення `V_DD` через резистор `R_p` починає заряджати сумарну ємність лінії `C_b`.

Диференціальне рівняння заряду конденсатора в RC-ланцюзі має класичний вигляд:

```
V(t) = V_DD · (1 - e^(-t / (R_p · C_b)))
```

За стандартом NXP UM10204 час наростання `t_r` вимірюється як інтервал часу, за який напруга на лінії зростає від нижнього порогу `V_IL = 0.3 · V_DD` до верхнього порогу `V_IH = 0.7 · V_DD`.

Знайдемо моменти часу `t_1` (досягнення 30% `V_DD`) та `t_2` (досягнення 70% `V_DD`):

```
V(t_1) = 0.3 · V_DD
0.3 · V_DD = V_DD · (1 - e^(-t_1 / (R_p · C_b)))       [рівняння для нижнього порогу]
1 - e^(-t_1 / (R_p · C_b)) = 0.3                      [скорочення на V_DD]
e^(-t_1 / (R_p · C_b)) = 0.7                          [перенесення доданків]
-t_1 / (R_p · C_b) = ln(0.7)                          [логарифмування обох частин]
t_1 = -R_p · C_b · ln(0.7)                           [вираження t_1]
t_1 = R_p · C_b · ln(1 / 0.7) = R_p · C_b · ln(10 / 7)
t_1 ≈ 0.35667 · R_p · C_b                             [числове значення: ln(1.42857)]
```

Аналогічно знайдемо момент часу `t_2`:

```
V(t_2) = 0.7 · V_DD
0.7 · V_DD = V_DD · (1 - e^(-t_2 / (R_p · C_b)))       [рівняння для верхнього порогу]
1 - e^(-t_2 / (R_p · C_b)) = 0.7                      [скорочення на V_DD]
e^(-t_2 / (R_p · C_b)) = 0.3                          [перенесення доданків]
-t_2 / (R_p · C_b) = ln(0.3)                          [логарифмування обох частин]
t_2 = -R_p · C_b · ln(0.3)                           [вираження t_2]
t_2 = R_p · C_b · ln(1 / 0.3) = R_p · C_b · ln(10 / 3)
t_2 ≈ 1.20397 · R_p · C_b                             [числове значення: ln(3.33333)]
```

Тепер обчислимо повний час наростання `t_r` як різницю `t_2 - t_1`:

```
t_r = t_2 - t_1
t_r = R_p · C_b · ln(10 / 3) - R_p · C_b · ln(10 / 7) [підстановка моментів часу]
t_r = R_p · C_b · ln((10 / 3) / (10 / 7))             [властивість логарифма: різниця ln]
t_r = R_p · C_b · ln(7 / 3)                           [спрощення дробу]
t_r = R_p · C_b · ln(2.33333)                         [обчислення константи]
t_r ≈ 0.847298 · R_p · C_b                            [базова формула стандарту I2C]
```

Отримана фундаментальна константа `0.8473` (або спрощено `0.85`) є основою для всіх інженерних розрахунків шини I²C.

### Математичне виведення часу спаду напруги `t_f`

Час спаду `t_f` визначається швидкістю розряду ємності шини `C_b` відкритим N-канальним польовим транзистором. Оскільки на початковому етапі розряду транзистор працює в режимі насичення як генератор стабільного струму стікання `I_OL` (обмеженого внутрішньою геометрією каналу чіпа на рівні 3 мА або 20 мА), процес розряду моделюється лінійною функцією:

```
I_OL = C_b · (dV / dt)
dt = C_b · dV / I_OL
```

Інтегруючи від верхнього порогу `V_IH = 0.7 · V_DD` до нижнього порогу `V_IL = 0.3 · V_DD`:

```
t_f = C_b · (0.7 · V_DD - 0.3 · V_DD) / I_OL
t_f = (0.4 · V_DD · C_b) / I_OL
```

Для типових умов (`V_DD = 3.3 В`, `C_b = 200 пФ`, `I_OL = 3 мА`):

```
t_f = (0.4 · 3.3 · 200 · 10^(-12)) / 0.003
t_f = (1.32 · 200 · 10^(-12)) / 0.003 = 264 · 10^(-12) / 0.003 = 88 · 10^(-9) с = 88 нс
```

Отримане значення `88 нс` із великим запасом вкладається в норматив `t_f(max) = 300 нс`.

### Розрахунок граничних опорів підтяжки `R_p(min)` та `R_p(max)`

Для забезпечення надійної роботи шини опір підтяжки повинен знаходитися у строго визначеному інтервалі:

```
R_p(min) ≤ R_p ≤ R_p(max)
```

#### 1. Верхня межа опору `R_p(max)`
Обмежується максимально допустимим часом наростання `t_r(max)` для обраного швидкісного режиму:

```
t_r = 0.8473 · R_p · C_b ≤ t_r(max)
R_p(max) = t_r(max) / (0.8473 · C_b)
```

- Для **Standard-mode (100 кГц)**: `t_r(max) = 1000 нс`.
```
R_p(max) = 1000 · 10^(-9) / (0.8473 · C_b) = 1180 / C_b  [де C_b у нФ, опір в омах]
```
- Для **Fast-mode (400 кГц)**: `t_r(max) = 300 нс`.
```
R_p(max) = 300 · 10^(-9) / (0.8473 · C_b) = 354 / C_b   [де C_b у нФ, опір в омах]
```
- Для **Fast-mode Plus (1 МГц)**: `t_r(max) = 120 нс`.
```
R_p(max) = 120 · 10^(-9) / (0.8473 · C_b) = 141.6 / C_b [де C_b у нФ, опір в омах]
```

#### 2. Нижня межа опору `R_p(min)`
Обмежується навантажувальною здатністю вихідних N-канальних транзисторів пристроїв на шині. За стандартом при формуванні логічного нуля вихідний каскад повинен витримувати струм стікання `I_OL = 3 мА` (у режимі Fast-mode Plus — `I_OL = 20 мА`), при цьому залишковий рівень напруги на відкритому транзисторі не повинен перевищувати `V_OL(max) = 0.4 В`:

```
I_pullup = (V_DD - V_OL(max)) / R_p ≤ I_OL(max)
R_p(min) = (V_DD - V_OL(max)) / I_OL(max)
```

Для типових напруг живлення:
- При `V_DD = 5.0 В` та `I_OL = 3 мА`:
```
R_p(min) = (5.0 - 0.4) / 0.003 = 4.6 / 0.003 ≈ 1533 Ом  (номінал ряду E24: 1.6 кОм)
```
- При `V_DD = 3.3 В` та `I_OL = 3 мА`:
```
R_p(min) = (3.3 - 0.4) / 0.003 = 2.9 / 0.003 ≈ 967 Ом   (номінал ряду E24: 1.0 кОм)
```
- При `V_DD = 1.8 В` та `I_OL = 3 мА`:
```
R_p(min) = (1.8 - 0.4) / 0.003 = 1.4 / 0.003 ≈ 467 Ом   (номінал ряду E24: 470 Ом)
```

### Вплив послідовних захисних резисторів `R_s`

Для захисту входів мікросхем від електростатичних розрядів (ESD) та демпфування високочастотних відбиттів на довгих лініях послідовно з кожним виводом SDA та SCL часто встановлюють захисні резистори `R_s` (типовий номінал `10 ... 100 Ом`).

Послідовний резистор утворює дільник напруги з резистором підтяжки `R_p` та внутрішнім опором відкритого транзистора `R_DS(on)`:

```
V_OL_actual = V_DD · (R_s + R_DS(on)) / (R_p + R_s + R_DS(on))
```

**Критерій коректності:** Фактичний рівень логічного нуля не повинен перевищувати поріг `V_IL = 0.3 · V_DD` з урахуванням запасу завадостійкості:

```
V_OL_actual ≤ 0.4 В  (або V_OL_actual ≤ 0.2 · V_DD)
(R_s + R_DS(on)) / R_p ≤ 0.15
```

Звідси випливає обмеження на максимальний опір демпферного резистора:

```
R_s(max) ≤ 0.15 · R_p - R_DS(on)
```

### Моделювання перехресного ємнісного наведення (Cross-Talk)

Коли довгі траси ліній SDA та SCL прокладаються паралельно на друкованій платі або в гнучкому шлейфі, між ними виникає паразитна взаємна ємність зв'язку `C_m` (*Mutual Capacitance*).

Швидкий спадний перепад напруги на лінії SCL (`dV_SCL / dt`) індукує через взаємну ємність `C_m` імпульс витоку струму на сусідню лінію SDA:

```
i_cross = C_m · (dV_SCL / dt)
```

Цей струм створює короткочасний сплеск падіння напруги `ΔV_SDA` на еквівалентному вихідному імпедансі лінії SDA (який у стані Hi-Z дорівнює опору резистора підтяжки `R_p`):

```
ΔV_SDA = i_cross · R_p = C_m · R_p · (ΔV_SCL / t_f)
```

**Критерій завадостійкості:** Сплеск напруги `ΔV_SDA` на високому рівні не повинен опускатися нижче порогу `V_IH = 0.7 · V_DD`:

```
ΔV_SDA ≤ 0.2 · V_DD
C_m · R_p · (V_DD / t_f) ≤ 0.2 · V_DD
C_m ≤ 0.2 · t_f / R_p
```

Для режиму Fast-mode (`t_f = 100 нс`, `R_p = 2 кОм`):

```
C_m ≤ (0.2 · 100 · 10^(-9)) / 2000 = 20 · 10^(-9) / 2000 = 10 пФ
```

Якщо взаємна ємність перевищує 10 пФ, перепад на SCL викличе помилковий спадний викид на SDA, який приймач розпізнає як хибну умову START.

### Статистичний аналіз допусків компонентів (Worst-Case Timing Modeling)

В умовах серійного виробництва електронних модулів номінали резисторів `R_p`, паразитна ємність монтажу `C_b`, напруга джерела живлення `V_DD` та температура навколишнього середовища зазнають технологічного розкиду:
- Допуск резисторів підтяжки: `R_p ± 5%` (або `± 1%` для прецизійних SMD);
- Допуск діелектричної проникності склотекстоліту FR-4: `ε_r` змінюється від `4.1` до `4.8`, що дає розкид ємності трас `C_b ± 15%`;
- Температурний дрейф відкритого каналу польового транзистора: `R_DS(on)` збільшується на `+0.6% / °C` при нагріванні від `+25 °C` до `+85 °C`.

**Найгірший випадок для часу наростання (`t_r_worst`):** Виникає при максимальному опорі підтяжки та максимальній ємності лінії:

```
R_p_max = R_p_nominal · 1.05
C_b_max = C_b_nominal · 1.15
t_r_worst = 0.8473 · R_p_max · C_b_max = 0.8473 · (1.05 · R_p) · (1.15 · C_b) ≈ 1.023 · R_p · C_b
```

Таким чином, розкид компонентів збільшує час наростання на 21% порівняно з ідеальним номінальним розрахунком.

### Динамічне енергоспоживання шини I²C

При безперервному обміні даними енергія розсіюється на резисторі підтяжки `R_p` під час фаз низького рівня напруги та витрачається на перезаряджання ємності `C_b`:

1. **Енергія перезаряджання ємності за один такт:** `E_cap = C_b · V_DD^2`.
2. **Енергія статичного витоку на резисторі під час `t_LOW`:** `E_static = (V_DD^2 / R_p) · t_LOW`.
3. **Середня потужність розсіювання на лінії при тактовій частоті `f_SCL`:**

```
P_avg = f_SCL · (C_b · V_DD^2 + (V_DD^2 / R_p) · t_LOW · Duty_LOW)
```

Для типових значень (`V_DD = 3.3 В`, `R_p = 2 кОм`, `C_b = 200 пФ`, `f_SCL = 400 кГц`, `t_LOW = 1.3 мкс`, коефіцієнт передачі нулів 50%):

```
P_cap = 400000 · (200 · 10^(-12) · 3.3^2) = 400000 · (200 · 10^(-12) · 10.89) = 0.87 мВт
P_res = 400000 · ((10.89 / 2000) · 1.3 · 10^(-6) · 0.5) = 400000 · (0.005445 · 0.65 · 10^(-6)) = 1.41 мВт
P_total = 0.87 + 1.41 = 2.28 мВт
```

### Бюджет часових запасів (Timing Margin Analysis)

Надійність цифрового зв'язку визначається наявністю додатного запасу за часом встановлення `Margin_SU` та часом утримання `Margin_HD`.

#### 1. Запас часу встановлення даних (`Margin_SU`)
Час встановлення визначається різницею між тривалістю низького півперіоду такту `t_LOW` та сумою затримок поширення:

```
t_available = t_LOW - t_val(max) - t_r(SDA)
Margin_SU = t_available - t_SU;DAT(min)
```

Де:
- `t_LOW` — тривалість низького рівня SCL, сформована ведучим.
- `t_val(max)` — максимальний час від спадного фронту SCL до встановлення валідних даних на виводі веденого передавача (внутрішня затримка чіпа).
- `t_r(SDA)` — фактичний час наростання лінії SDA при переході в логічну одиницю (`0.8473 · R_p · C_b`).
- `t_SU;DAT(min)` — нормативний мінімум часу встановлення (100 нс для 400 кГц).

**Умова відсутності збоїв:** `Margin_SU > 0`. Якщо `Margin_SU ≤ 0`, сигнал SDA перетне поріг `0.7 · V_DD` пізніше за лінію SCL, що призведе до зчитування попереднього значення або потрапляння тригера в стан метастабільності.

#### 2. Запас часу утримання даних (`Margin_HD`)
Час утримання перевіряє, чи не змінить передавач стан лінії SDA занадто рано, поки приймач ще зчитує поточний біт:

```
Margin_HD = t_prop_min(SDA) - t_f(SCL) - t_HD;DAT(min)
```

Оскільки за стандартом `t_HD;DAT(min) = 0 нс`, для запобігання гонкам сигналів передавач повинен мати внутрішню апаратну затримку комутації `t_prop_min(SDA) ≥ 300 нс` (для подолання невизначеної зони спаду SCL).

### Розрахунок максимальної робочої частоти та деградації пропускної здатності

Повний період одного тактового імпульсу SCL `T_SCL` з урахуванням фізичних перехідних процесів дорівнює:

```
T_SCL = t_LOW + t_HIGH + t_r(SCL) + t_f(SCL)
f_SCL_actual = 1 / T_SCL
```

Якщо ведений пристрій використовує розтягування такту на час `t_stretch`, фактичний низький період подовжується:

```
t_LOW_actual = t_LOW_nominal + t_stretch
T_SCL_stretched = t_LOW_actual + t_HIGH + t_r(SCL) + t_f(SCL)
```

#### Розрахунок ефективної швидкості передачі даних
Для транзакції з читання або запису блоку з `N` байтів загальний час передачі `T_total` складається з:
1. Часу формування умови START: `T_START = t_HD;STA + t_r + t_f`.
2. Часу передачі адресного байта та `N` байтів даних (кожен байт складається з 8 бітів даних та 1 біта ACK = 9 тактів): `9 · (N + 1) · T_SCL`.
3. Загального часу затримок розтягування такту на кожному байті: `(N + 1) · t_stretch`.
4. Часу формування умови STOP: `T_STOP = t_SU;STO + t_BUF`.

```
T_total = T_START + (N + 1) · (9 · T_SCL + t_stretch) + T_STOP
Throughput_effective = (8 · N) / T_total   [біт/с]
```

### Покроковий приклад комплексного розрахунку

**Вихідні інженерні умови:**
- Напруга живлення шини: `V_DD = 3.3 В`.
- Режим роботи: **Fast-mode (400 кГц)**.
- Нормативні параметри стандарту: `t_LOW_min = 1.3 мкс`, `t_HIGH_min = 0.6 мкс`, `t_r_max = 300 нс`, `t_f_max = 300 нс`, `t_SU;DAT_min = 100 нс`.
- Сумарна виміряна ємність шини (друкована плата + 4 датчики + роз'єм): `C_b = 200 пФ`.
- Ведений датчик тиску має максимальний внутрішній час вибірки: `t_val = 600 нс`.
- Ведений датчик утримує такт перед видачею ACK на час: `t_stretch = 15 мкс`.

#### Крок 1. Розрахунок допустимого діапазону резисторів `R_p`
```
R_p(min) = (3.3 - 0.4) / 0.003 = 2.9 / 0.003 ≈ 967 Ом
R_p(max) = 300 · 10^(-9) / (0.8473 · 200 · 10^(-12))
R_p(max) = 300 · 10^(-9) / (169.46 · 10^(-12)) ≈ 1770 Ом
```

Обираємо стандартний номінал резистора з ряду E24 у межах `[967 Ом ... 1770 Ом]`:
```
R_p = 1.5 кОм = 1500 Ом
```

#### Крок 2. Розрахунок фактичного часу наростання фронту `t_r`
```
t_r = 0.8473 · R_p · C_b
t_r = 0.8473 · 1500 · 200 · 10^(-12) = 254.19 · 10^(-9) с ≈ 254 нс
```
Перевірка: `254 нс ≤ 300 нс` (умова виконується із запасом 46 нс).

#### Крок 3. Перевірка запасу часу встановлення даних `Margin_SU`
```
t_available = t_LOW_min - t_val - t_r
t_available = 1300 нс - 600 нс - 254 нс = 446 нс
Margin_SU = t_available - t_SU;DAT_min
Margin_SU = 446 нс - 100 нс = 346 нс
```
Висновок: Запас часу встановлення становить `+346 нс`. Дані зчитуватимуться абсолютно стабільно без ризику виникнення метастабільності.

#### Крок 4. Розрахунок деградації швидкості при опитуванні датчика
Припустимо, ведучий зчитує 6 байтів результату вимірювання (`N = 6`).
1. Номінальний період такту без розтягування (при `t_f = 20 нс`):
```
T_SCL = 1300 нс + 600 нс + 254 нс + 20 нс = 2174 нс ≈ 2.174 мкс
f_SCL = 1 / 2.174 мкс ≈ 460 кГц  (ведучий налаштований на 400 кГц -> T_SCL = 2.5 мкс)
```
2. Час передачі кадру без затримки веденого (`t_stretch = 0`):
```
T_frame_nominal = 9 · (6 + 1) · 2.5 мкс = 63 · 2.5 мкс = 157.5 мкс
Throughput_nominal = (8 · 6) / 157.5 мкс = 48 / 0.0001575 ≈ 304 760 біт/с (38.1 кБ/с)
```
3. Час передачі кадру з розтягуванням такту веденим (`t_stretch = 15 мкс` на кожному з 7 байтів):
```
T_stretch_total = 7 · 15 мкс = 105 мкс
T_frame_actual = 157.5 мкс + 105 мкс = 262.5 мкс
Throughput_actual = 48 / 0.0002625 ≈ 182 857 біт/с (22.8 кБ/с)
```
Висновок: Розтягування такту веденим датчиком на 15 мкс подовжує тривалість транзакції з 157.5 мкс до 262.5 мкс, знижуючи реальну пропускну здатність шини на 40%.
