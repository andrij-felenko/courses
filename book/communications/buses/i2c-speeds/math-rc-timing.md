# 🧮 Розрахунок часу наростання фронту та вибір резисторів підтяжки I2C

Розрахунок опору підтяжки на шині I2C спирається на жорсткий схемотехнічний компроміс: опір резистора мусить бути достатньо малим, щоб зарядити паразитну ємність провідників за нормативний час, але водночас достатньо великим, щоб не перевантажити вихідні транзистори мікросхем під час формування логічного нуля. Якщо резистор обрано неправильно, фронт сигналу затягується, перетворюючись на згладжену пилкоподібну хвилю, або вихідний каскад не може притиснути лінію до безпечного рівня логічного нуля, що призводить до втрати синхронізації та збоїв транзакцій.

Нижче наведено строге аналітичне виведення формули часу наростання фронту для порогів специфікації NXP I2C, розрахунок меж опору підтяжки для різних швидкісних режимів, аналіз впливу початкової залишкової напруги, модель спадного фронту та аналіз енергоспоживання.

---

### Фізична модель заряджання ємності шини

Коли всі під'єднані до лінії транзистори з відкритим стоком закриваються (переходять у стан високого імпедансу), лінія від'єднується від землі. Струм від джерела живлення `V_DD` починає текти через зовнішній підтягувальний резистор `R_p`, заряджаючи еквівалентну ємність шини `C_b` (суму ємностей виводів усіх чіпів, паразитної ємності друкованих доріжок, роз'ємів та кабелів).

Диференціальне рівняння першого порядку, що описує перехідний процес у колі RC (відповідно до законів Ома та Кірхгофа), має вигляд:

```
V_DD - V(t) = R_p · i(t) = R_p · C_b · (dV / dt)

dV / dt + V(t) / (R_p · C_b) = V_DD / (R_p · C_b)
```

Інтегруючи це диференціальне рівняння з початковою умовою `V(0) = 0` (або `V(0) = V_OL ≈ 0`), отримуємо залежність миттєвої напруги на шині від часу:

```
V(t) = V_DD · (1 - e^(-t / (R_p · C_b)))
```

де добуток `τ = R_p · C_b` (грецька літера тау) є характеристичною часовою константою кола.

### Аналітичне виведення часу наростання фронту (t_r)

Специфікація стандарту I2C (зокрема офіційний документ NXP UM10204) визначає час наростання фронту `t_r` (*rise time*, від англ. *rise* — підйом) не від нуля до повного живлення, а строго між двома стандартизованими рівнями логічних порогів приймачів:

1. Поріг гарантованого логічного нуля: `V_IL = 0.3 · V_DD` (нижній рівень входу).
2. Поріг гарантованої логічної одиниці: `V_IH = 0.7 · V_DD` (верхній рівень входу).

Знайдемо моменти часу `t_1` та `t_2`, коли напруга на шині досягає відповідно рівнів `0.3 · V_DD` та `0.7 · V_DD`.

**Крок 1. Визначення моменту досягнення нижнього порогу `t_1`:**

```
V(t_1) = 0.3 · V_DD

V_DD · (1 - e^(-t_1 / (R_p · C_b))) = 0.3 · V_DD        [підстановка формули перехідного процесу]
1 - e^(-t_1 / (R_p · C_b)) = 0.3                        [скорочення на V_DD]
e^(-t_1 / (R_p · C_b)) = 0.7                            [перенесення членів]
-t_1 / (R_p · C_b) = ln(0.7)                            [натуральне логарифмування обох частин]
t_1 = -R_p · C_b · ln(0.7) = R_p · C_b · ln(1 / 0.7)
t_1 = R_p · C_b · ln(10 / 7) ≈ 0.356675 · R_p · C_b    [обчислення десяткового дробу]
```

**Крок 2. Визначення моменту досягнення верхнього порогу `t_2`:**

```
V(t_2) = 0.7 · V_DD

V_DD · (1 - e^(-t_2 / (R_p · C_b))) = 0.7 · V_DD        [підстановка формули перехідного процесу]
1 - e^(-t_2 / (R_p · C_b)) = 0.7                        [скорочення на V_DD]
e^(-t_2 / (R_p · C_b)) = 0.3                            [перенесення членів]
-t_2 / (R_p · C_b) = ln(0.3)                            [натуральне логарифмування обох частин]
t_2 = -R_p · C_b · ln(0.3) = R_p · C_b · ln(1 / 0.3)
t_2 = R_p · C_b · ln(10 / 3) ≈ 1.203973 · R_p · C_b    [обчислення десяткового дробу]
```

**Крок 3. Розрахунок різниці часу `t_r = t_2 - t_1`:**

```
t_r = t_2 - t_1
t_r = R_p · C_b · ln(10 / 3) - R_p · C_b · ln(10 / 7)   [підстановка виразів для t_1 та t_2]
t_r = R_p · C_b · (ln(10 / 3) - ln(10 / 7))             [винесення R_p · C_b за дужки]
t_r = R_p · C_b · ln((10 / 3) / (10 / 7))               [властивість різниці логарифмів]
t_r = R_p · C_b · ln(7 / 3)                             [спрощення дробу]
t_r = R_p · C_b · ln(2.333333...)
t_r ≈ 0.8472978 · R_p · C_b                             [числове значення константи]
```

Отриманий коефіцієнт `0.8473` є фундаментальною константою стандарту I2C для всіх розрахунків часу наростання сигналу з пасивною резистивною підтяжкою.

### Уточнення моделі: врахування ненульової початкової напруги V_OL

У реальних схемах напруга в стані логічного нуля не дорівнює нулю вольтів, а визначається залишковим спаданням напруги на відкритому транзисторі `V_OL` (зазвичай 0.1–0.4 В). Загальне рівняння перехідного процесу з початковою умовою `V(0) = V_OL`:

```
V(t) = V_OL + (V_DD - V_OL) · (1 - e^(-t / (R_p · C_b)))
```

Визначаючи моменти `V(t_1) = 0.3 · V_DD` та `V(t_2) = 0.7 · V_DD`:

```
t_1 = R_p · C_b · ln((V_DD - V_OL) / (0.7 · V_DD - V_OL))
t_2 = R_p · C_b · ln((V_DD - V_OL) / (0.3 · V_DD - V_OL))
t_r = t_2 - t_1 = R_p · C_b · ln((0.7 · V_DD - V_OL) / (0.3 · V_DD - V_OL))
```

Порівняймо коефіцієнт для різних напруг живлення при `V_OL = 0.4 В`:
- При `V_DD = 5.0 В`: `k = ln((3.5 - 0.4) / (1.5 - 0.4)) = ln(3.1 / 1.1) = ln(2.818) ≈ 1.036`
- При `V_DD = 3.3 В`: `k = ln((2.31 - 0.4) / (0.99 - 0.4)) = ln(1.91 / 0.59) = ln(3.237) ≈ 1.175`
- При `V_DD = 1.8 В`: `k = ln((1.26 - 0.4) / (0.54 - 0.4)) = ln(0.86 / 0.14) = ln(6.143) ≈ 1.815`

Це виведення демонструє важливий фізичний ефект: **при зниженні напруги живлення відносна частка залишкової напруги `V_OL` зростає, що суттєво сповільнює вихід із зони логічного нуля**. Для низьковольтних систем (1.8 В) фактичний час наростання при тому самому номіналі `R_p · C_b` зростає більш ніж удвічі порівняно з ідеальною моделлю!

### Розрахунок максимального опору підтяжки (R_p,max)

Щоб сигнал встиг досягти рівня логічної одиниці до початку опитування лінії або зміни тактового сигналу, фактичний час наростання `t_r` не повинен перевищувати нормативного максимуму `t_r,max`, заданого стандартом для обраного швидкісного режиму:

```
t_r ≤ t_r,max
0.8473 · R_p · C_b ≤ t_r,max
R_p ≤ t_r,max / (0.8473 · C_b)
```

Звідси отримуємо робочу формулу для верхньої межі опору резистора:

```
R_p,max = t_r,max / (0.8473 · C_b) ≈ 1.1802 · (t_r,max / C_b)
```

Нормативні значення максимального часу наростання:
- **Standard-mode (100 кбіт/с):** `t_r,max = 1000 нс` (1.0 мкс).
- **Fast-mode (400 кбіт/с):** `t_r,max = 300 нс` (0.3 мкс).
- **Fast-mode Plus (1 Мбіт/с):** `t_r,max = 120 нс` (0.12 мкс).

### Розрахунок мінімального опору підтяжки (R_p,min)

Нижня межа опору підтяжки диктується здатністю вихідних транзисторів мікросхем надійно втягувати струм на землю. Коли будь-який пристрій виставляє на шину логічний нуль, його внутрішній n-канальний MOSFET відкривається і замкнений на землю. Через цей транзистор тече постійний струм від джерела живлення:

```
I_OL = (V_DD - V_OL) / R_p
```

де `V_OL` — залишкове спадання напруги на відкритому каналі польового транзистора (*Output Low Voltage*), а `I_OL` — втягуваний струм (*Low-Level Output Sink Current*).

Стандарт I2C вимагає, щоб при максимальному втягуваному струмі залишковий потенціал на шині не перевищував граничного рівня `V_OL,max = 0.4 В` (при `V_DD > 2.0 В`), або `0.2 · V_DD` (для низьковольтних систем із живленням нижче 2 В).

Звідси випливає обмеження на мінімальний допустимий опір:

```
R_p ≥ (V_DD - V_OL,max) / I_OL,max
R_p,min = (V_DD - 0.4 В) / I_OL
```

Значення допустимого струму `I_OL` для різних режимів:
- **Standard-mode (Sm) та Fast-mode (Fm):** стандартні вихідні драйвери розраховані на гарантований струм `I_OL = 3 мА` при `V_OL = 0.4 В`.
- **Fast-mode Plus (Fm+):** посилені драйвери стандарту здатні втягувати струм `I_OL = 20 мА` при `V_OL = 0.4 В`.

### Числові приклади розрахунку для різних конфігурацій

Зведемо аналітичні розрахунки у конкретні приклади для типових напруг живлення `V_DD = 3.3 В` та `V_DD = 5.0 В`.

#### Приклад 1. Стандартний режим (Standard-mode, 100 кбіт/с, C_b = 400 пФ, V_DD = 3.3 В)

1. Обчислення мінімального опору:
```
R_p,min = (3.3 В - 0.4 В) / 0.003 А = 2.9 В / 0.003 А = 966.7 Ом ≈ 970 Ом
```

2. Обчислення максимального опору:
```
R_p,max = 1000 · 10⁻⁹ с / (0.8473 · 400 · 10⁻¹² Ф) = 1000 / (0.8473 · 0.4) = 2950 Ом ≈ 2.95 кОм
```

**Діапазон вибору:** `970 Ом ≤ R_p ≤ 2950 Ом`. Оптимальним вибором зі стандартного ряду E24 є резистор **2.2 кОм** або **1.5 кОм**.

---

#### Приклад 2. Швидкий режим (Fast-mode, 400 кбіт/с, C_b = 400 пФ, V_DD = 3.3 В)

1. Мінімальний опір (залишається незмінним через стандартний вихідний каскад 3 мА):
```
R_p,min = (3.3 В - 0.4 В) / 0.003 А = 966.7 Ом
```

2. Максимальний опір для скороченого часу наростання `t_r,max = 300 нс`:
```
R_p,max = 300 · 10⁻⁹ с / (0.8473 · 400 · 10⁻¹² Ф) = 300 / (0.8473 · 0.4) = 885.2 Ом
```

**Парадокс розрахунку:** Ми отримали `R_p,max = 885 Ом < R_p,min = 967 Ом`!

Цей важливий результат математично доводить: **при граничній ємності шини 400 пФ неможливо підібрати пасивний резистор підтяжки для Fast-mode**, який одночасно задовольняв би вимоги до часу наростання (`t_r ≤ 300 нс`) та не перевантажував вихідний транзистор за струмом `I_OL ≤ 3 мА`.

Щоб вирішити цю суперечність, інженер має три шляхи:
1. Зменшити ємність шини `C_b` (наприклад, оптимізувати трасування друкованої плати до `C_b = 200 пФ`, тоді `R_p,max = 1.77 кОм`, що дає робоче вікно `970 Ом ... 1.77 кОм`, де ідеальним є номінал `1.2 кОм` або `1.5 кОм`).
2. Використати активний прискорювач наростання фронту (Rise Time Accelerator).
3. Перейти на стандарт Fast-mode Plus (Fm+), де драйвери розраховані на 20 мА.

---

#### Приклад 3. Режим Fast-mode Plus (1 Мбіт/с, C_b = 550 пФ, V_DD = 3.3 В)

1. Обчислення мінімального опору для драйвера 20 мА:
```
R_p,min = (3.3 В - 0.4 В) / 0.020 А = 2.9 В / 0.020 А = 145 Ом
```

2. Обчислення максимального опору для жорсткого фронту `t_r,max = 120 нс`:
```
R_p,max = 120 · 10⁻⁹ с / (0.8473 · 550 · 10⁻¹² Ф) = 120 / (0.8473 · 0.55) = 257.5 Ом
```

**Діапазон вибору:** `145 Ом ≤ R_p ≤ 257 Ом`. Оптимальним номіналом зі стандартного ряду є резистор **180 Ом** або **200 Ом**.

### Бюджет паразитної ємності друкованої плати (C_b)

Паразитна ємність лінії шини `C_b` формується з чотирьох фізичних джерел:

```
C_b = C_trace + sum(C_pin,i) + sum(C_ESD,i) + C_cable
```

1. **Ємність друкованих трас (`C_trace`):** Для типової мікросмужкової лінії над суцільним полігоном землі на діелектрику FR4 (товщина 1.6 мм, ширина траси 0.25 мм, діелектрична проникність `ε_r ≈ 4.3`) погонна ємність становить близько **1.0–1.3 пФ на сантиметр довжини** (2.5–3.3 пФ на дюйм).
2. **Ємність виводів мікросхем (`C_pin`):** Кожен кристал у корпусі додає ємність виводу від 5 до 10 пФ (паразитна ємність контактної площадки, кристалотримача та захисних діодів підкладки). Десять мікросхем на одній шині автоматично формують ємність близько 70–100 пФ лише за рахунок виводів.
3. **Діоди захисту від електростатичного розряду (`C_ESD`):** Дискретні TVS-діоди додають від 3 до 15 пФ на лінію, якщо не використовуються спеціалізовані ультранизькоємнісні збірки.
4. **Кабельні з'єднання (`C_cable`):** Стандартний стрічковий шлейф додає близько 50–70 пФ/метр, а вита пара — до 80–120 пФ/метр.

Знаючи це, гранична фізична довжина трас друкованої плати для Fast-mode (400 кГц, залишкова ємність на траси 150 пФ) становить близько 1.2–1.5 метра, тоді як для Fast-mode Plus із підтяжками 180 Ом довжина шини може досягати 3–4 метрів.

### Аналіз запасу завадостійкості (Noise Margins)

Запас завадостійкості визначає стійкість системи до наведених синфазних і диференціальних шумів:

```
N_ML = V_IL - V_OL = 0.3 · V_DD - V_OL        [запас завадостійкості низького рівня]
N_MH = V_OH - V_IH = V_DD - 0.7 · V_DD = 0.3 · V_DD  [запас завадостійкості високого рівня]
```

Порівняння для різних напруг живлення при `V_OL = 0.4 В`:
- **При 5.0 В:** `N_ML = 1.5 В - 0.4 В = 1.1 В`, `N_MH = 1.5 В` (високий запас).
- **При 3.3 В:** `N_ML = 0.99 В - 0.4 В = 0.59 В`, `N_MH = 0.99 В` (достатній запас).
- **При 1.8 В:** `N_ML = 0.54 В - 0.4 В = 0.14 В`, `N_MH = 0.54 В` (критично вузький запас).

Запас завадостійкості низького рівня при живленні 1.8 В становить лише 140 мВ. Будь-який шум на спільній шині землі або падіння напруги на опорі земляних доріжок плати понад 140 мВ призведе до помилкового сприйняття логічного нуля як невизначеного стану. Саме тому в низьковольтних системах стандартом передбачено зменшення нормативного порогу `V_OL` до `0.2 · V_DD` (0.36 В для 1.8 В).

### Аналіз енергоспоживання та розсіюваної потужності

Вибір резистора підтяжки безпосередньо впливає на енергетичний баланс пристрою, складаючись із двох компонентів: статичної та динамічної потужності.

#### 1. Статична потужність на низькому рівні (P_stat)

Коли лінія утримується в стані логічного нуля (наприклад, під час передачі нульових бітів, підтвердження ACK або утримання такту веденим пристроєм), через резистор безперервно тече струм. Потужність, що виділяється на резисторі у вигляді тепла:

```
P_stat = ((V_DD - V_OL)² / R_p) · D_low
```

де `D_low` — коефіцієнт заповнення низького рівня (частка часу, коли лінія перебуває в нулі, зазвичай 0.4–0.6).

Для живлення 3.3 В та резистора 1.5 кОм у режимі Fast-mode:
```
P_stat,max = (3.3 - 0.4)² / 1500 = 8.41 / 1500 = 5.61 мВт
```

Для режиму Fast-mode Plus з резистором 180 Ом:
```
P_stat,max = (3.3 - 0.4)² / 180 = 8.41 / 180 = 46.72 мВт
```

Це свідчить про те, що платою за швидкість 1 Мбіт/с у режимі Fm+ є майже десятикратне збільшення розсіюваної статичної потужності на підтяжках.

#### 2. Динамічна потужність комутації ємності (P_dyn)

Під час кожного перемикання лінії з нуля в одиницю джерело живлення віддає енергію `E = C_b · V_DD²` на заряджання паразитної ємності, половина якої розсіюється на резисторі підтяжки, а друга половина запасається в електричному полі ємності. Під час перемикання з одиниці в нуль запасена енергія розсіюється на внутрішньому опорі каналу відкритого транзистора.

Сумарна динамічна потужність для тактової лінії SCL при частоті `f_SCL`:

```
P_dyn = C_b · V_DD² · f_SCL
```

Для шини з ємністю `C_b = 400 пФ`, живленням `V_DD = 3.3 В` на частоті `f_SCL = 400 кГц`:
```
P_dyn = 400 · 10⁻¹² · (3.3)² · 400 · 10³ = 400 · 10⁻¹² · 10.89 · 400 · 10³ = 1.74 мВт
```

Ці розрахунки демонструють, що для автономних батарейних систем із низьким енергоспоживанням необхідно мінімізувати фізичну довжину трас шини (зменшуючи `C_b`) та уникати невиправдано малих номіналів `R_p`, обираючи резистор ближче до верхньої межі `R_p,max` для обраної швидкості.
