# 🧮 Математичний аналіз межі V.90 та шуму квантування ІКМ

Математичне обґрунтування швидкості модемного зв'язку базується на двох фундаментальних галузях прикладної математики: теорії інформації Шеннона–Хартлі для аналогових каналів із аддитивним білим гаусовим шумом (AWGN) та теорії квантування нелінійного цифрового кодека G.711 ІКМ (PCM — *Pulse Code Modulation*).

Перехід від суто аналогового зв'язку стандарту V.34 (з межею 33.6 кбіт/с) до асиметричного цифрового зв'язку технології V.90 (з межею 56 кбіт/с) став можливим завдяки математичному усуненню шуму квантування аналогово-цифрового перетворювача (АЦП) у напрямку від провайдера до клієнта.

## 1. Теоретична межа аналогового каналу (Формула Шеннона та V.34)

Стандартна телефонна мережа загального користування (ТФЗК) обмежена смуговим фільтром АТС у діапазоні частот від `f1 = 300 Гц` до `f2 = 3400 Гц`.

```
B = f2 - f1
= 3400 - 300
= 3100 Гц        [ширина смуги пропускання аналогового телефонного каналу]
```

У класичному аналоговому модемному з'єднанні (коли обидва модеми підключені до телефонної мережі через аналогові мідні абонентські лінії) сигнал проходить два етапи перетворення: АЦП на вході станції АТС та ЦАП на виході станції АТС.

Головним джерелом неусувного шуму в такому тракті є нелінійне квантування АЦП за законом μ-law (у Північній Америці та Японії) або A-law (у Європі). Співвідношення сигнал/шум (SNR) для 8-бітного кодека G.711 на аналоговій лінії теоретично обмежене значенням близько 38–39 дБ.

Обчислимо лінійне співвідношення потужностей сигналу й шуму `SNR_linear` для `SNR_dB = 38 дБ`:

```
SNR_linear = 10^(SNR_dB / 10)
= 10^(38 / 10)
= 10^3.8
≈ 6309.57        [лінійне співвідношення потужності сигналу до потужності шуму]
```

Застосуємо теорему Шеннона–Хартлі для обчислення максимальної теоретичної пропускної здатності аналогового каналу `C`:

```
C = B · log2(1 + SNR_linear)
= 3100 · log2(1 + 6309.57)
= 3100 · log2(6310.57)
= 3100 · 12.6237
≈ 39133 біт/с     [абсолютна теоретична стеля Шеннона для аналогового каналу]
```

У реальних умовах через міжсимвольну інтерференцію, згасання на краях смуги частот та фазове тремтіння (Phase Jitter) реальна символьна швидкість стандарту V.34 обмежується величиною `3200 бод` або `3429 бод`. При символьній швидкості `3429 бод` і сигнальному сузір'ї QAM з еквалайзером реальна максимальна швидкість становить:

```
C_v34 = 3429 бод × 9.8 біт/символ
≈ 33600 біт/с     [максимальна практична швидкість стандарту V.34]
```

Таким чином, швидкість 33.6 кбіт/с у V.34 є фундаментальною математичною межею для аналогово-аналогового телефонного тракту.

## 2. Математичний прорив V.90: Ліквідація шуму квантування АЦП

У технології V.90 сервер провайдера (ISP) підключається до цифрової мережі АТС безпосередньо через цифровий потік E1 (2.048 Мбіт/с) або T1 (1.544 Мбіт/с). Сервер надсилає готові 8-бітні байтові відліки ІКМ безпосередньо у цифровий вимикач АТС.

На боці АТС ці 8-бітні числа потрапляють прямо у цифро-аналоговий перетворювач (ЦАП). ЦАП генерує точний дискретний рівень напруги на аналоговій абонентській лінії. На шляху від провайдера до клієнта **відсутній АЦП**, а отже, шум квантування дорівнює нулю (`SNR_quant = ∞`).

Єдиним джерелом шуму на шляху Downstream залишається тепловий шум аналогової крученої пари (Subscriber Loop), де SNR зазвичай перевищує 45–50 дБ.

У кодеку G.711 μ-law аналогова амплітуда `x` квантується за логарифмічною шкалою на 256 дискретних рівнів (8 біт). Формула стиснення μ-law має вигляд:

```
y = sgn(x) · ln(1 + μ·|x|) / ln(1 + μ)    [де μ = 255]
```

Оскільки 8-бітний відлік надсилається кожні `1 / 8000` секунди (частота дискретизації Найквіста для смуги 4 кГц дорівнює 8000 Гц), теоретична швидкість цифрового каналу становить:

```
C_raw = Fs · N_bits
= 8000 Гц × 8 біт
= 64000 біт/с     [симетричний цифровий потік G.711 / ISDN]
```

## 3. Математичне обґрунтування межі 56 кбіт/с

На шляху від 64 кбіт/с до реальних 56 кбіт/с діють три математичні та фізичні обмеження:

### А. Нелінійний інтервал між квантами при високих напругах

Рівні квантування μ-law розподілені нерівномірно. На низьких амплітудах відстань між сусідніми рівнями напруги становить лише `2 мВ`, а на високих амплітудах — досягає `128 мВ`. Через згасання та шум лінії клієнтський аналоговий приймач не здатний надійно розрізнити найближчі високовольтні рівні. Тому V.90 використовує не всі 256 рівнів μ-law, а лише від 64 до 128 найбільш віддалених рівнів.

Якщо з 256 рівнів обрано `M = 96` стабільних точок:

```
bits_per_symbol = log2(M)
= log2(96)
≈ 6.585 біт/символ
```

Обчислимо швидкість передачі даних:

```
C_v90 = Fs · bits_per_symbol
= 8000 × 6.585
≈ 52680 біт/с
```

### Б. Службове крадіння бітів (Robbed-Bit Signaling)

У північноамериканських мережах T1 кожен 6-й кадр використовує наймолодший біт (LSB) 8-бітного відліку для службової сигналізації АТС (передача стану слухавки, виклику тощо).

```
bits_frame_1_to_5 = 8 біт
bits_frame_6      = 7 біт
bits_avg          = (5 · 8 + 1 · 7) / 6
                  = 47 / 6
                  ≈ 7.833 біт/символ

C_robbed = 8000 × 7.833
         = 62666 біт/с
```

Коли неможливо використовувати 8-й біт у кожному 6-му кадрі, максимальне число доступних рівнів квантування зменшується удвічі для цього кадру, що знижує швидкість приблизно на 3.3 кбіт/с.

### В. Обмеження потужності FCC та рівень випромінювання

Федеральна комісія зі зв'язку США (FCC) та стандарти ITU-T обмежують максимальну питому потужність сигналу в телефонній лінії величиною `-12 dBm` для запобігання перехресним наводкам (crosstalk) між сусідніми парами в багатожильному кабелі. Оскільки високі рівні напруги μ-law створюють більшу потужність, модем змушений відмовлятися від найвищих амплітудних рівнів, що фіксує максимальну швидкість V.90 на позначці **56 000 біт/с**.

## 4. Математичне порівняння параметрів V.34 та V.90

```
+--------------------------+-----------------------+-----------------------+
| Параметр                 | V.34 (Аналог–Аналог)  | V.90 (Цифра–Аналог)   |
+--------------------------+-----------------------+-----------------------+
| Символьна швидкість (Fs) | 2400 – 3429 бод       | 8000 відліків/с (ІКМ) |
| Тип модуляції            | QAM / TCM             | PCM (G.711 μ/A-law)   |
| Обмеження АЦП            | Присутнє (~38 дБ SNR) | Відсутнє (Downstream) |
| Бітів на символ          | ~8 – 10 біт           | ~6 – 7 біт            |
| Максимальна швидкість    | 33 600 біт/с          | 56 000 біт/с          |
+--------------------------+-----------------------+-----------------------+
```

Математична краса V.90 полягала в тому, що замість боротьби з шумом АЦП шляхом ускладнення еквалайзерів, інженери змінили саму математичну модель каналу, узгодивши точки сигнального сузір'я з цифровими квантами АТС.
