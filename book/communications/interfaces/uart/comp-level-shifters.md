# 🔌 Класи трансиверів та конвертерів рівнів UART

Цифрове ядро мікроконтролера чи мікропроцесора працює виключно з внутрішніми логічними рівнями напруги живлення — зазвичай 3.3 В або 5 В (CMOS/TTL). Проте реальний світ вимагає передавати послідовний потік даних на різні відстані, у різних завадових умовах та через різні фізичні середовища. Сам по собі периферійний модуль UART генерує лише логічні сигнали `TX` та приймає `RX`. Для того щоб поєднати кремнієві виводи мікроконтролера з кабельними лініями чи комп'ютерними шинами, використовують спеціалізований клас мікросхем — **трансивери та конвертери рівнів**.

Розуміння класів цих пристроїв, їхніх електричних характеристик та типових схемотехнічних пасток є критичним для забезпечення надійного зв'язку без ризику виведення з ладу портів мікроконтролера.

### 1. Однополярні трансивери прямих логічних рівнів (TTL / CMOS)

Найпростіший спосіб з'єднання двох пристроїв через UART — це безпосереднє з'єднання виводів `TX` та `RX` мідними провідниками на одній друкованій платі або між сусідніми модулями.

- **Логічна 1 (Idle / Mark):** відповідає напрузі живлення цифрової схеми V_CC (наприклад +3.3 В або +5 В).
- **Логічний 0 (Space):** відповідає рівню спільного дроту (0 В / GND).

Цей клас з'єднання обходиться взагалі без проміжних трансиверів, але ставить сувору вимогу: обидві мікросхеми мусять мати однакову напругу логічних рівнів.

```
З'єднання TTL/CMOS на одній платі:

   [ MCU A (3.3V) ]                     [ Sensor B (3.3V) ]
   ( TX ) ─────────────────────────────> ( RX )
   ( RX ) <───────────────────────────── ( TX )
   (GND ) ───────────────────────────── (GND )
```

#### Пастка узгодження 5 В та 3.3 В
Поширена інженерна помилка виникає при спробі з'єднати мікроконтролер із живленням 3.3 В (наприклад, STM32 або ESP32) із модулем або давачем, що працює від 5 В (наприклад, класична система на базе AVR або Arduino).

1. **Лінія 5V TX -> 3.3V RX:** Вихід 5 В виставляє напругу логічної одиниці +5 В. Якщо вхідний вивід 3.3 В мікроконтролера не є толерантним до 5 В (*5V tolerant*), струм починає текти через внутрішні захисні діоди виводу в шину живлення 3.3 В. Це спричиняє деградацію напівпровідникового кристала, локальний перегрів або вихід з ладу всієї мікросхеми.
2. **Лінія 3.3V TX -> 5V RX:** Вихід 3.3 В видає логічну одиницю +3.3 В. За стандартом TTL вхідний поріг логічної одиниці становить +2.0 В, тому 3.3 В сприймається впевнено. Проте для стандартів CMOS пороги становлять 0.7 × V_CC = 3.5 В, тож напруга 3.3 В опиняється в невизначеній зоні, що викликає пропуски бітів або збої кадру.

Для безпечного узгодження між 3.3 В та 5 В застосовують **конвертери логічних рівнів**:
- **Резистивні дільники:** Найпростіший дільник із двох резисторів (наприклад, 1 кОм та 2 кОм) знижує 5 В до 3.3 В у напрямку від 5V TX до 3.3V RX.
- **Схеми на польових транзисторах (MOSFET):** Двонаправлені конвертери на N-канальних польових транзисторах із підтягувальними резисторами забезпечують безпечний перенос рівнів в обох напрямках.
- **Спеціалізовані буферні ІС:** Буфери серій 74LVC245, TXB0108 або TXS0108 з роздільними виводами живлення V_CCA та V_CCB.

### 2. Двополярні трансивери інтерфейсу RS-232

Для передачі даних за межі друкованої плати на відстані до 15 метрів у промисловому та комп'ютерному обладнанні традиційно використовується стандарт **RS-232**. Електричні рівні RS-232 суттєво відрізняються від TTL і є **інверсними та двополярними**:

- **Логічна 1 (Mark):** Напруга від **-3 В до -15 В** (типово -9 В або -12 В).
- **Логічний 0 (Space):** Напруга від **+3 В до +15 В** (типово +9 В або +12 В).
- **Зона невизначеності:** Напруги від -3 В до +3 В вважаються завадою.

Подавати сигнали RS-232 безпосередньо на виводи мікроконтролера заборонено: від'ємна напруга -12 В негайно спалить захисні діоди виводу.

```
Структура трансивера RS-232 (на прикладі серії MAX232 / MAX3232):

    [ MCU UART ]                [ Трансивер RS-232 ]                [ Лінія RS-232 ]
    TX (0/3.3V)  ─────────────> [ Інвертор + Зсув ] ─────────────> TXD (-12V/+12V)
    RX (0/3.3V)  <───────────── [ Інвертор + Зсув ] <───────────── RXD (-12V/+12V)
                                [ Charge Pump (C1..C4) ]
```

Трансивери класу MAX232/MAX3232 містять усередині двоканальний перетворювач рівнів та **помпу заряду** (*Charge Pump*) із чотирма зовнішніми конденсаторами. Помпа заряду генерує внутрішні двополярні напруги +10 В та -10 В від одного джерела живлення +3.3 В або +5 В.

Окрім зміни полярності та амплітуди, трансивери RS-232 виконують важливу захисну функцію: вони витримують короткі замикання лінії на землю та сплески статичної електрики (ESD) амплітудою до кількох кіловольт.

### 3. Диференційні трансивери інтерфейсів RS-422 та RS-485

Коли відстань передачі даних зростає до сотень метрів або лінія проходить поруч із потужними електродвигунами чи інверторами, однополярні напруги стають вразливими до індукованого електромагнітного шуму. У таких випадках логічний потік UART подають на [диференційні трансивери RS-422 та RS-485](topic:communications/rs422-rs485).

Замість вимірювання напруги відносно спільної землі, диференційний трансивер перетворює потік UART у різницю потенціалів між двома дротами витої пари (лінії A та B):

- **Логічна 1:** Напруга на лінії V_A > V_B (різниця V_AB > +200 мВ).
- **Логічний 0:** Напруга на лінії V_A < V_B (різниця V_AB < -200 мВ).

```
Перетворення UART -> RS-485 диференційним трансивером:

   [ MCU UART ]             [ Трансивер RS-485 ]           [ Вита пара ]
   TXD ───────────────────> [ Драйвер D ] ───────────────> Лінія A (+)
                            [           ] ───────────────> Лінія B (-)
   RXD <─────────────────── [ Приймач R  ] <─────────────── (Різниця VA - VB)
   DE  ── (Керування TX) ──>
```

Особливістю більшості трансиверів RS-485 (наприклад, MAX485, SP3485) є наявність виводів керування напрямком: `DE` (*Driver Enable*) та `RE` (*Receiver Enable*). Оскільки RS-485 частіше працює в напівдуплексному режимі по одній витій парі, мікроконтролер мусить піднімати сигнал `DE` перед початком передачі байта через UART і опускати його негайно після завершення відправки останнього стоп-біта.

### 4. Мости USB-UART (Virtual COM Port)

У сучасних персональних комп'ютерах і ноутбуках апаратні послідовні RS-232 порти майже повністю поступилися місцем шині USB. Для підключення мікроконтролерного пристрою до ПК використовують **мости USB-UART** (серії CP2102, FT232R, CH340G, PL2303).

Мост USB-UART є повноцінною мікросхемою зі своїм внутрішнім контролером USB, приймачем фізичного рівня USB (PHY) та периферійним блоком UART:

1. З боку ПК мікросхема оголошує себе пристроєм класу USB CDC (*Communication Device Class*) або використовує спеціалізований vendor-драйвер. Операційна система створює **віртуальний COM-порт** (наприклад, `COM3` у Windows або `/dev/ttyUSB0` у Linux).
2. Програми на ПК відкривають віртуальний порт і надсилають дані пакетами USB.
3. Мост USB-UART приймає USB-пакети, витягує з них байти й виштовхує їх через свій апаратний TX-вивід із налаштованою швидкістю baud у вигляді класичного кадру UART.

```
Тракт передачі через USB-UART мост:

   [ Додаток ПК ] ──(POSIX / Win32)──> [ Віртуальний COM-драйвер ]
                                                  │
                                                  ▼ (USB Пакет)
                                        [ Кабель USB (D+/D-) ]
                                                  │
                                                  ▼
                                       [ Мост USB-UART (CH340) ]
                                                  │
                                                  ▼ (Кадр UART 3.3V)
                                       [ RX Pin MCU ]
```

### 5. Оптична та магнітна гальванічна ізоляція

У промислових умовах та автоматиці об'єкти часто розташовані на великій відстані один від одного або живляться від різних фаз електромережі. Різниця потенціалів між заземленнями двох цехів може досягати десятків або сотень вольт. Безпосереднє з'єднання загального дроту (GND) двох мікроконтролерів у таких умовах призводить до протікання вирівнювальних струмів по мідному кабелю, що спричиняє вигорання портів та вихід з ладу обладнання.

Для усунення цієї небезпеки лінії UART підключають через **гальванічні ізолятори**:

- **Оптопари (Optocouplers):** Швидкісні оптопари (наприклад, 6N137 або HCPL-2601) перетворюють електричний сигнал `TX` у світловий імпульс світлодіода, який зчитується фототранзистором на іншій стороні. Електричний зв'язок між первинним і вторинним контурами повністю відсутній, що забезпечує ізоляцію до 2500–5000 В.
- **Цифрові магнітні та ємкісні ізолятори:** Мікросхеми серій ISO7741 або ADUM1201 використовують мікроскопічні кремнієві трансформатори або конденсатори для передачі високочастотних сигналів. Вони споживають значно менше струму, ніж оптопари, та підтримують швидкості обміну до 100 Мбіт/с.
- **Ізольовані DC-DC перетворювачі:** Для живлення вторинної сторони ізольованого трансивера (наприклад, RS-485) застосовують малопотужні ізольовані модулі живлення (наприклад, B0505S-1W), які передають енергію через імпульсний трансформатор.

```
Схема гальванічно ізольованого вузла UART:

   [ MCU ] ──(TX)──> [ Цифровий ізолятор ] ──(TX_ISO)──> [ Трансивер ] ──> [ Лінія ]
   [ 3.3V]           [ (ISO7741 / ADUM1201) ]           [ RS-485 / RS-232 ]
   [ GND1] ───────── [ Первинний контур ]              [ Вторинний GND2 ]
                           │                                  ▲
                           └──────── [ Isolated DC-DC ] ──────┘
```

### Практичні інженерні правила та пастки

1. **Не залишайте вхід RX "висіти в повітрі":** Якщо лінія RX мікроконтролера підключена до зовнішнього роз'єму, від'єднання кабелю залишає вхід у стані високого імпедансу (*Hi-Z*). Електромагнітні наведення створюють хаотичні спади напруги, що сприймається приймачем UART як старт-біти й заповнює буфер сміттям. Завжди вмикайте внутрішній або зовнішній підтягувальний резистор (*Pull-up*) до V_CC (типово 10 кОм).
2. **Перевіряйте кросування TX -> RX:** Головна класична помилка монтажу — підключення `TX` до `TX` та `RX` до `RX`. Вихід передавача `TX` одного пристрою **завжди** мусить підключатися до входу приймача `RX` іншого пристрою.
3. **Спільна земля є обов'язковою:** Для однополярних інтерфейсів (TTL/CMOS, RS-232, USB-UART) з'єднання ліній `GND` двох пристроїв є суворо обов'язковим. Без спільної землі різниця потенціалів між корпусами пристроїв створить паразитні струми або викривить пороги розпізнавання рівнів.
4. **Гальванічна розв'язка у промислових умовах:** У разі великих відстаней або з'єднання обладнання з різними контурами заземлення обов'язково застосовують оптичну або магнітну гальванічну розв'язку (оптопари PC817, ISO7741 або ізольовані трансивери ADM2483). Це захищає цифрові виводи мікроконтролера від вирівнювальних струмів по землі, які можуть досягати десятків ампер під час перехідних процесів у силовій мережі.
