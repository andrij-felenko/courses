# 🔌 Оптопари та компоненти трансиверів струмової петлі

Побудова вузлів струмової петлі (20 мА, 5 мА MIDI та 4–20 мА) спирається на узгодження схемотехніки приймачів і передавачів із вимогами гальванічної ізоляції та точності. Практичний вибір компонентів охоплює класи оптопар за коефіцієнтом передачі струму (CTR) і швидкодією, прецизійні генератори струму на транзисторах та операційних підсилювачах, а також спеціалізовані мікросхеми HART-модемів і цифро-аналогових перетворювачів із живленням безпосередньо від петлі.

---

### Оптопари для цифрової струмової петлі: класифікація та вибір

Приймальний каскад пасивного вузла струмової петлі будується на **оптопарі** (англ. *optocoupler / optoisolator*). Її вхідний інфрачервоний світлодіод вмикається безпосередньо у замкнений струмовий контур, а вихідний фотодетейтор керує електронним входом мікроконтролера або трансивера, забезпечуючи гальванічну розв'язку від 2.5 кВ до 5 кВ.

Під час вибору оптопари для струмової петлі ключовими є два фізичні параметри:
1. **Коефіцієнт передачі струму (CTR — Current Transfer Ratio):** відношення вихідного струму фотодетектора `I_out` до вхідного струму світлодіода `I_in`, виражене у відсотках:
   ```
   CTR = (I_out / I_in) · 100 %
   ```
2. **Час затримки розповсюдження сигналу (t_PLH, t_PHL):** затримка перемикання виходу з низького рівня у високий та навпаки.

За швидкодією та внутрішньою будовою оптопари діляться на три основні класи:

#### 1. Стандартні фототранзисторні оптопари (PC817, 4N25, LTV-817)
Усередині містять ІЧ-світлодіод та кремнієвий фототранзистор. 
- **Переваги:** надзвичайно низька ціна, висока доступність, високий CTR (від 50 % до 300 %).
- **Недоліки:** низька швидкодія. Через високу ємність бази фототранзистора час вимикання `t_PHL` становить від 3 до 18 мікросекунд.
- **Сфера застосування:** повільні інтерфейси до **4800 бод**, низькочастотні аналогові та цифрові входи PLC, опитування датчиків. Для швидкостей 9600 бод і вище потребують складних схем форсування розряду бази (підтяжка бази через резистор до емітера).

#### 2. Оптопари із складеним транзистором Дарлінгтона (6N138, 6N139)
Містять фотодіод, підключений до бази складеного транзистора Дарлінгтона з високим підсиленням.
- **Переваги:** висока чутливість при маплих струмах петлі. При вхідному струмі `I_in` всього **0.5…1.6 мА** CTR досягає **500…3000 %**.
- **Недоліки:** середня швидкодія (частота перемикання до 100 кГц).
- **Сфера застосування:** стандарт **MIDI (5 мА)**, де струм петлі невеликий, а швидкість становить 31.25 кбіт/с.

#### 3. Високошвидкісні оптопари з логічним виходом (6N137, HCPL-2601, HCPL-0600)
Усередині містять ІЧ-світлодіод, фотодіод, високошвидкісний підсилювач та вихідний тригер Шмітта з відкритим колектором або каскадом Totem-Pole.
- **Переваги:** висока швидкість передачі даних — до **10 Мбіт/с**. Затримка розповсюдження не перевищує **75 наносекунд**, а вихідний тригер Шмітта формує круті фронти цифрових імпульсів без брязкіту.
- **Недоліки:** потребують обов'язкового локального живлення VCC (+5 В або +3.3 В) для внутрішньої мікросхеми підсилювача на стороні приймача.
- **Сфера застосування:** високошвидкісна цифрова струмова петля 20 мА (до 115.2 кбіт/с), ізольовані інтерфейси RS-485 та CAN.

```
       Параметри оптопар для струмових петель:
┌───────────┬──────────────┬───────────────┬─────────────────┬──────────────────────┐
│  Модель   │   Тип виходу │ Вхідний струм │     Макс. CTR   │  Макс. швидкість     │
├───────────┼──────────────┼───────────────┼─────────────────┼──────────────────────┤
│ PC817     │ Транзистор   │  5…20 мА      │ 50…300 %        │  4.8 кбіт/с          │
│ 6N138     │ Дарлінгтон   │  0.5…5 мА     │ 500…3000 %      │  100 кбіт/с (MIDI)   │
│ 6N137     │ Логіка (Gate)│  5…10 мА      │ Logic Output    │  10 Мбіт/с           │
└───────────┴──────────────┴───────────────┴─────────────────┴──────────────────────┘
```

### Розрахунок обмежувальних резисторів, старіння CTR та захист входу

Пряме падіння напруги на вхідному світлодіоді оптопари `V_F` зазвичай становить від **1.2 В до 1.7 В** при кімнатній температурі. Обмежувальний резистор `R_in` розраховується за законом Ома з урахуванням напруги джерела живлення петлі `V_loop` та бажаного робочого струму `I_loop`:

```
R_in = (V_loop − V_F − V_sat) / I_loop
```

Де `V_sat` — падіння напруги на вихідному ключі передавача у замкненому стані (типово 0.2…0.6 В для біполярного транзистора).

#### Розрахунок запасу за CTR на старіння
Світлодіоди інфрачервоного випромінювання (GaAs / AlGaAs) піддаються фізичній деградації в процесі експлуатації. З часом їхній оптичний вихід знижується, що призводить до падіння CTR оптопари на **10…25 % за 5 років** безперервної роботи при підвищених температурах (+60 °C).

Для забезпечення надійної роботи на весь термін служби пристрою (10–15 років) розробник зобов'язаний закладати **інженерний запас по CTR не менше 2:1**:

```
CTR_design = 2 · CTR_min_required
```

Якщо для надійного перемикання вихідного транзистора приймача з урахуванням підтягувального резистора `R_pullup = 1 кОм` потрібен струм колектора `I_C = 5 мА`, а струм у петлі становить `I_loop = 10 мА`, мінімальний CTR дорівнює `(5 / 10) · 100% = 50 %`. З урахуванням запасу слід обирати оптопару з документальним `CTR_min ≥ 100 %`.

#### Захист від зворотної напруги та ESD-завад
Максимально припустима зворотна напруга на світлодіоді оптопари `V_R_max` становить всього **3…5 Вольтів**. Якщо під час монтажу кабелю переплутати полярність підключення дротів петлі, світлодіод миттєво зазнає електричного пробою та вийде з ладу.

Для захисту від переполюсовки паралельно світлодіоду оптопари завжди вмикають **зустрічно-паралельний захисний діод** (наприклад, 1N4148 або SD103A).

Окрім того, для промислових ліній, прокладених між будинками, на клемах підключення кабелю встановлюють **двонапрямлені TVS-діоди** (супресори серії SMAJ24CA або P6KE36CA) та обмежувальні резистори PTC (самовідновлювані запобіжники). ТВС-діод обрізає високовольтні сплески грозових наведень та електростатичних розрядів (ESD) до безпечного рівня в 30…40 Вольтів, не даючи їм пробити мікросхеми та ізоляцію.

```
                   Клема +LOOP
                       │
           ┌───────────┼───────────┐
          ┌┴┐          │           │
          │ │ PTC     ─┴─ TVS     ┌┴┐ 1N4148 (Зустрічний діод)
          └┬┘         ▲ ▲ SMAJ24  │ │ 
           │          ───         └┬┘
           ├───────────┼───────────┤
           │           │          ┌┴┐ LED Optocoupler
           │           │          │ │ (6N137 / PC817)
           │           │          └┬┘
           │           │           │
           └───────────┼───────────┘
                       │
                   Клема -LOOP
```

### Схемотехніка генераторів струму активного вузла

Активний вузол струмової петлі зобов'язаний підтримувати стабільний струм (наприклад, 20 мА або 4 мА у стані спокою) незалежно від зміни опору дротів кабелю та коливань напруги живлення `VCC`.

Для побудови активного джерела струму застосовують три основні схемотехнічні рішення:

#### 1. Джерело струму на компенсаційному інтегральному регуляторі (LM317)
Найпростіший двополюсник струму. Регулятор напруги LM317 підтримує опорну напругу `V_ref = 1.25 В` між виводами `OUT` та `ADJ`.

```
        +VCC ───┬───────────┐
                │          ┌┴┐
               ┌┴┐         │ │ R_set = 62.5 Ω (для 20 мА)
               │ │ LM317   └┬┘
               └┬┘          │
                ├───────────┴─── Вихід I_out = 1.25V / R_set
               OUT     ADJ
```

- **Розрахунок резистора:**
  ```
  R_set = V_ref / I_out = 1.25 В / 0.020 А = 62.5 Ом
  ```
- **Особливості:** потребує мінімального падіння напруги між входом і виходом не менше **3 В** (Dropout). При струмі 20 мА та напрузі 24 В резистор розсіює незначну потужність `P = 1.25 · 0.020 = 0.025 Вт`.

#### 2. Джерело струму на операційному підсилювачі та N-канальному MOSFET / NPN транзисторі
Забезпечує високу точність та можливість динамічного керування струмом (наприклад, для формування аналогового сигналу 4–20 мА з ЦАП або ШІМ мікроконтролера).

```
                 +24V VCC
                    │
                 [Резистор навантаження / Петля]
                    │
                 [+LOOP Terminal]
                    │
                 [ -LOOP Terminal]
                    │
                    D (Drain)
                ┌───┴───┐
   V_DAC ──(+)─┤ ОУ    │ FET (N-Ch)
           ──(−)┤ LM358 │
             │  └───┬───┘
             │      S (Source)
             ├──────┴──────┐
             │            ┌┴┐
             │            │ │ R_sense = 10 Ом
             │            └┬┘
             │             │
             └─────────────┴─── GND
```

- **Принцип роботи:** операційний підсилювач охоплений від'ємним зворотним зв'язком за напругою на вимірювальному резисторі `R_sense`. ОУ змінює напругу на затворі транзистора так, щоб падіння напруги на `R_sense` суворо дорівнювало вхідній напрузі `V_DAC`:
  ```
  I_loop = V_DAC / R_sense
  ```
- **Приклад:** при `R_sense = 100 Ом` напруга `V_DAC = 0.4 В` дає струм `4 мА`, а `V_DAC = 2.0 В` дає струм `20 мА`.

### Спеціалізовані мікросхеми для промислової струмової петлі

Для зменшення габаритів друкованих плат та підвищення надійності виробники напівпровідників випускають спеціалізовані інтегральні мікросхеми, які об'єднують джерела струму, ЦАП та модеми у єдиному корпусі:

#### 1. Перетворювачі «ЦАП — Струмова петля» 4–20 мА (AD421, DAC161S997, XTR115/XTR116)
Спеціалізовані мікросхеми для побудови **двопровідних (Loop-Powered)** датчиків:
- **DAC161S997 (Texas Instruments):** 16-бітний ЦАП із цифровим інтерфейсом SPI. Мікросхема живиться безпосередньо від сигнального струму петлі, споживаючи у стані спокою менше **300 мкА**, та точно моделює струм петлі в діапазоні від 3.5 мА до 24 мА.
- **XTR115 / XTR116 (Burr-Brown / TI):** прецизійні струмові підсилювачі (підсилюють вхідний струм у 100 разів). Містять внутрішній термостабільний опорний стабілізатор напруги +5 В (або +4.096 В) для живлення зовнішнього мікроконтролера та датчика.

#### 2. Інтегральні модеми протоколу HART (AD5700, DS8500, SYM2043)
Забезпечують прийом та генерацію синусоїдального FSK-сигналу Bell 202 (1200 Гц / 2200 Гц) з амплітудою ±0.5 мА для накладання цифрових даних поверх 4–20 мА:
- **AD5700 (Analog Devices):** одночіповий HART-модем із вбудованим полосовим фільтром та цифровим фазовим автопідстроюванням частоти (PLL). Живиться від напруги 2.0 В…5.5 В, споживає всього **115 мкА** у режимі прийому, що дозволяє вбудовувати його у двопровідні loop-powered передавачі. Мікросхема підключається до UART мікроконтролера на швидкості 1200 бод і прозоро перетворює біти у синусоїдальні частотні посилки.

```
                   +24V Loop Power
                          │
                   ┌──────┴──────┐
                   │  Датчик     │
                   │  4–20 мА    ├─────────── Analog 4–20 mA Signal
                   └──────┬──────┘
                          │ (AC Coupling Capacitor 10 nF)
                          ├───[ 10 nF ]───┐
                                          │
                                   ┌──────┴──────┐
                                   │  AD5700     │ ── UART TXD/RXD ── Microcontroller
                                   │ HART Modem  │ (1200 baud)
                                   └─────────────┘
```

Вибір компонентного стеку залежить від завдань: для простих ізольованих цифрових ліній достатньо високошвидкісної оптопари типу 6N137; для музичних пристроїв стандартом є 6N138; а для інтелектуальних промислових датчиків застосовують зв'язку з DAC161S997 та AD5700.
