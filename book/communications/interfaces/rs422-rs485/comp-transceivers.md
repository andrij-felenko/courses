# 🔌 Архітектура трансиверів та гальванічна ізоляція RS-485

Цей огляд розкриває внутрішню схемотехніку інтегрованих трансиверів RS-422 та RS-485 як класу пристроїв: від будови диференційного передавача й компаратора приймача до еволюції вхідного навантаження, інтегрованих схем захисту та методів гальванічної ізоляції для розриву земляних контурів.

### Внутрішня структура класичного трансивера

Трансивер RS-485 є спеціалізованою напівпровідниковою мікросхемою, що виконує роль мосту між логічними рівнями мікроконтролера (TTL/CMOS 0..3.3 В або 0..5 В) та диференційними рівнями шини. Вона містить два ключових блока: **передавач (драйвер `D`)** та **приймач (`R`)**.

```
Логічний бік (MCU)                   Фізична шина RS-485
  TXD (DI)  ────────► ┌──────────┐ ───►  A (D+)  Non-inverting
  DE        ────────► │ Драйвер  │ ───►  B (D-)  Inverting
                      │    D     │
  RXD (RO)  ◄──────── │ Приймач  │ ◄───  A
  /RE       ────────► │    R     │ ◄───  B
                      └──────────┘
```

#### 1. Передавач (драйвер D)
Вихідний каскад передавача побудовано за мостовою схемою (*H-bridge*) на потужних комплементарних полевих (MOSFET) або біполярних транзисторах. 
- При передачі логічної одиниці (`DI = 1` при `DE = 1`) передавач підтягує лінію `A` до позитивної шини живлення VCC, а лінію `B` — до землі GND. Диференційна напруга `V_AB = V_A - V_B` стає додатною (типово від +1.5 В до +3.0 В під навантаженням 54 Ом).
- При передачі логічного нуля (`DI = 0` при `DE = 1`) транзистори перемикаються навпаки: лінія `A` з'єднується з GND, а `B` — з VCC. Напруга `V_AB` стає від'ємною (від -1.5 В до -3.0 В).
- При вимкненому дозволі передачі (`DE = 0`) усі чотири ключі моста розмикаються, і виходи переходять у **третій стан (High-Z)** з високим імпедансом (струм витоку не перевищує кількох мікроампер).

#### 2. Приймач (компаратор R)
Приймач є високоточним диференційним компаратором із вбудованим гістерезисом. Він постійно вимірює різницю напруг `V_AB = V_A - V_B`:
- Якщо `V_AB > +200 мВ`, вихід `RO` перевидає логічну одиницю (HIGH).
- Якщо `V_AB < -200 мВ`, вихід `RO` перевидає логічний нуль (LOW).
- Вхідний гістерезис (типово від 25 до 50 мВ) запобігає брязкоту виходу при повільних фронтах сигналу та дрібних високочастотних шумах.

Вхідний сигнал дозволу приймача `/RE` (*Receiver Enable*, інверсний) дає змогу вимкнути вихід `RO` (перевести в High-Z). На багатьох платах виводи `DE` та `/RE` зводять разом і керують ними одним піном мікроконтролера: при HIGH вузол передає дані, при LOW — слухає шину.

### Еволюція вхідного навантаження (Unit Load)

Згідно з початковим стандартом RS-485, класичний приймач характеризувався вхідним опором близько 12 кОм у діапазоні синфазної напруги від -7 В до +12 В. Це значення було прийнято за **1 одиничне навантаження (1 UL, *Unit Load*)**. Стандарт вимагав, щоб передавач міг впевнено працювати на сумарне навантаження до 32 UL (що еквівалентно мінімальному опору шини 375 Ом паралельно з двома термінаторами по 120 Ом).

Розвиток напівпровідникових технологій дозволив значно зменшити вхідні струми витоку компаратора та створити трансивери з дробовим навантаженням:

| Клас приймача | Вхідний опір (R_in) | Струм витоку (при 12V) | Макс. кількість вузлів на сегмент |
| :--- | :--- | :--- | :--- |
| **1 UL** (класичний) | ≥ 12 кОм | ≤ 1.0 мА | 32 вузли |
| **1/2 UL** | ≥ 24 кОм | ≤ 0.5 мА | 64 вузли |
| **1/4 UL** | ≥ 48 кОм | ≤ 0.25 мА | 128 вузлів |
| **1/8 UL** (сучасний) | ≥ 96 кОм | ≤ 0.125 мА | 256 вузлів |

Використання трансиверів класу 1/8 UL дозволяє масштабувати одну фізичну виту пару до 256 пристроїв без використання проміжних повторювачів (*repeaters*).

### Вбудований захисний зсув (True Fail-Safe)

У класичних трансиверах, коли шина перебуває в стані спокою (усі передавачі вимкнені у High-Z), термінатор 120 Ом повністю розряджає лінію, і диференційна напруга стає рівною нулю: `V_AB = 0 мВ`. Це значення потрапляє строго в невизначену зону компаратора `[-200 мВ..+200 мВ]`. Зовнішні наведення та шум викликають хаотичне перемикання виходу `RO`, що сприймається UART мікроконтролера як хибні старт-біти (сміттєві байти).

Для вирішення цієї проблеми розроблено два підходи:

1. **Зовнішня резистивна підтяжка (Fail-Safe Biasing):** Установлення резистора Pull-Up між лінією `A` та VCC і резистора Pull-Down між лінією `B` та GND. Це примусово утримує `V_AB ≈ +200..+300 мВ` при вільній шині.
2. **Інтегровані асиметричні пороги (True Fail-Safe Transceivers):** Сучасні трансивери мають зміщені пороги компаратора — наприклад, від **`-200 мВ` до `-50 мВ`**. При `V_AB = 0 мВ` (і навіть при зниженні різниці до `-50 мВ`) компаратор гарантовано бачить логічну одиницю. Це усуває потребу в зовнішніх резисторах підтяжки, спрощуючи схемотехніку й знижуючи енергоспоживання шини.

### Гальванічна ізоляція та захист від перенапруг

У протяжних промислових мережах земляні потенціали двох віддалених вузлів можуть відрізнятися на десятки або сотні вольтів через нерівномірне навантаження фаз живлення або наведення від грозових розрядів. Якщо з'єднати такі вузли неізольованим кабелем, по провіднику землі потече колосальний вирівнювальний струм, який спалить трансивери та плати керування.

Для захисту обладнання застосовують **гальванічно ізольовані вузли RS-485**.

```
[ МК / Логіка ]  │ │  [ Ізольований трансивер ] ─── A
  TXD, RXD, DE   │ │  [    з лінійним захистом  ] ─── B
                 │ │                            ─── GND_ISO
               Бар'єр
             ізоляції (Оптрони / Магнітні / Ємнісні)
```

Гальванічний бар'єр розриває прямий електричний контакт між мікроконтролером та шиною RS-485. Він складається з двох обов'язкових частин:
- **Ізоляція сигнальних ліній (`TXD`, `RXD`, `DE`):** Використовуються швидкі оптрони або цифрові магнітні/ємнісні ізолятори (наприклад, серії Analog Devices iCoupler або Texas Instruments ISO77xx), що витримують напругу пробою до `2500..5000 V_RMS`.
- **Ізоляція живлення:** Трансивер на боці шини живиться від окремого ізольованого DC-DC перетворювача.

Для додаткового захисту від високовольтних імпульсів (грозові сплески, статичний розряд ESD, комутаційні перенапруги) безпосередньо на входах `A` і `B` встановлюють трирівневий апаратний захист:
1. **TVS-діоди (Transient Voltage Suppressors):** Швидкі супресори (наприклад, SM712, розроблені спеціально для RS-485), що зрізають піки напруги вище `+12 В` та нижче `-7 В`.
2. **Самовідновлювані запобіжники (PTC Resettable Fuses):** Обмежують струм при тривалому попаданні мережевої напруги 220 В на лінію.
3. **Газорозрядники (GDT, *Gas Discharge Tubes*):** Відводят потужні грозові імпульси струму (до десятків кілоампер) на захисне заземлення (*PE*).

Використання ізольованих трансиверів із комплексним захистом робить шину RS-485 здатною роками надійно працювати в найжорсткіших промислових та польових умовах.
