# 🧮 Математика й точні формули перетворення децибельних одиниць

Ця вставка містить математичні виведення, формули перетворення та покрокові розрахунки між основними опорними одиницями децибел (dBm, dBW, dBV, dBu, dBμV, dBi, dBd, dBc, dBHz). Усі логарифмічні співвідношення спираються на десятковий логарифм `log₁₀`.

### 1. Фундаментальне визначення децибела

Децибел є безрозмірним логарифмічним відношенням двох однорідних енергетичних величин (потужностей). Логарифмічне представлення дозволяє замінити множення та ділення фізичних величин у послідовних трактах на звичайне додавання та віднімання.

```
P[dB] = 10 · log₁₀(P₂ / P₁)
```

Для величин поля (напруги `U`, струму `I`, напруженості електричного поля `E`), оскільки потужність пропорційна квадрату напруги (`P = U² / R`), відношення при однаковому опорі навантаження `R` визначається з множником 20. Подвоєння множника випливає з властивості логарифма степеня, де квадрат аргументу виноситься як множник 2 перед логарифмом:

```
U[dB] = 10 · log₁₀(U₂² / U₁²)       [підстановка P = U²/R]
      = 10 · 2 · log₁₀(U₂ / U₁)     [властивість логарифма: log(a²) = 2·log(a)]
      = 20 · log₁₀(U₂ / U₁)        [множення 10 · 2 = 20]
```

### 2. Перетворення абсолютних одиниць потужності: dBm ↔ dBW

Абсолютні одиниці потужності визначаються шляхом вибору конкретної фізичної точки відліку `P[ref]`.
Опорною точкою для `dBm` є потужність `P[ref] = 1 мВт = 10⁻³ Вт`.
Опорною точкою для `dBW` є потужність `P[ref] = 1 Вт`.

Виведення співвідношення між `dBm` та `dBW` спирається на розкладання логарифма частки на різницю логарифмів:

```
P[dBm] = 10 · log₁₀(P[Вт] / 10⁻³ Вт)
       = 10 · (log₁₀(P[Вт]) - log₁₀(10⁻³))  [властивість логарифма: log(a/b) = log(a) - log(b)]
       = 10 · log₁₀(P[Вт]) + 30            [обчислення -10 · log₁₀(10⁻³) = +30]
       = P[dBW] + 30                      [за визначенням P[dBW] = 10·log₁₀(P[Вт])]
```

Відповідно, зворотне перетворення отримуємо шляхом віднімання константи 30:

```
P[dBW] = P[dBm] - 30                      [віднімання 30 від обох частин]
```

Приклади перетворення абсолютних потужностей у повсякденній інженерній практиці:
- Передавач потужністю 1 Вт: `+30 dBm = +30 - 30 = 0 dBW`.
- Підсилювач потужністю 20 Вт: `+43 dBm = +43 - 30 = +13 dBW`.
- Сигнал потужністю 100 мВт: `-10 dBW = -10 + 30 = +20 dBm`.

### 3. Перетворення між напругою (dBμV) та потужністю (dBm) у трактах 50 Ом та 75 Ом

Напруга `U` у мікровольтах (`мкВ`) та потужність `P` у міліватах (`мВт`) пов'язані через хвильовий опір `R` (в Омах). Це співвідношення є критично важливим при використанні аналізаторів спектра, де вимірювальний змішувач реєструє напругу, а індикатор показує абсолютну потужність у `dBm`.

Спочатку виведемо залежність потужності в мВт від напруги в мкВ:

```
P[Вт] = U[В]² / R
P[мВт] = (U[мкВ] · 10⁻⁶)² / R · 10³       [переведення В у мкВ (10⁻⁶) та Вт у мВт (10³)]
       = (U[мкВ]² · 10⁻¹²) / R · 10³       [піднесення до квадрата (10⁻⁶)² = 10⁻¹²]
       = (U[мкВ]² · 10⁻⁹) / R              [спрощення 10⁻¹² · 10³ = 10⁻⁹]
```

Підставимо отриманий вираз для потужності у формулу логарифмічного перетворення `dBm`:

```
P[dBm] = 10 · log₁₀(P[мВт])
       = 10 · log₁₀((U[мкВ]² · 10⁻⁹) / R)                         [підстановка P[мВт] з попередньої формули]
       = 10 · log₁₀(U[мкВ]²) + 10 · log₁₀(10⁻⁹) - 10 · log₁₀(R)   [властивість логарифма добутку й частки]
       = 20 · log₁₀(U[мкВ]) - 90 - 10 · log₁₀(R)                  [степінь логарифма 10·log(U²) = 20·log(U) та 10·log(10⁻⁹) = -90]
       = U[dBμV] - 90 - 10 · log₁₀(R)                             [за визначенням U[dBμV] = 20·log₁₀(U[мкВ])]
```

Тепер обчислимо конкретну константу зсуву для двох стандартних опорів радіочастотних трактів:

**Для системи 50 Ом (стандарт радіозв'язку, RF та НВЧ-техніки):**

```
10 · log₁₀(50) = 10 · 1.69897 = 16.99 дБ  [значення логарифма для R = 50 Ом]

P[dBm] = U[dBμV] - 90 - 16.99
       = U[dBμV] - 106.99                 [віднімання констант 90 + 16.99]
       ≈ U[dBμV] - 107                    [округлення до цілого дБ]
```

Звідси пряме перетворення напруги у потужність у 50-омному тракті:

```
U[dBμV] = P[dBm] + 107                     [перенесення константи 107]
```

**Для системи 75 Ом (стандарт кабельного ТВ та телевізійних мереж):**

```
10 · log₁₀(75) = 10 · 1.87506 = 18.75 дБ  [значення логарифма для R = 75 Ом]

P[dBm] = U[dBμV] - 90 - 18.75
       = U[dBμV] - 108.75                 [віднімання констант 90 + 18.75]
       ≈ U[dBμV] - 108.8                  [округлення до десятої дБ]
```

Звідси зворотне перетворення для 75-омного тракту:

```
U[dBμV] = P[dBm] + 108.8                   [перенесення константи 108.8]
```

Приклад інженерного обчислення:
Якщо високочутливий приймач у 50-омній лінії має поріг чутливості `-107 dBm`, еквівалентна ефективна напруга сигналу на його вході становить:
`U[dBμV] = -107 + 107 = 0 dBμV`, що відповідає напрузі рівно `1 мкВ RMS`.

### 4. Перетворення підсилення антен: dBi ↔ dBd

Коефіцієнт спрямованої дії (підсилення) півхвильового диполя відносно теоретичного ізотропного випромінювача обчислюється шляхом інтегрування квадрата його діаграми спрямованості по сферичній поверхні.

Просторовий розподіл випромінювання півхвильового диполя описується функцією `F(θ) = cos((π/2) · cos(θ)) / sin(θ)`. Інтегрування цієї функції по тілесному куту дає точне значення коефіцієнта спрямованості диполя у напрямку максимуму випромінювання:

```
G[диполь] = 1.643                          [теоретичне відношення спрямованості диполя]
```

Переведемо це відношення у децибели відносно ізотропної сфери (`dBi`):

```
G[dBi] = 10 · log₁₀(1.643)                 [логарифмування відношення потужності]
       = 2.156 дБ ≈ 2.15 dBi               [обчислення 10 · 0.2156 = 2.156]
```

Отже, формула переходу між підсиленням відносно ізотропа (`dBi`) та півхвильового диполя (`dBd`) являє собою постійний зсув на 2.15 дБ:

```
G[dBi] = G[dBd] + 2.15                     [додавання зсуву 2.15 dBi]
G[dBd] = G[dBi] - 2.15                     [віднімання зсуву 2.15 dBi]
```

Приклад: якщо спрямована антена Yagi-Uda має паспортне підсилення `9 dBd`, її ізотропне підсилення становить `G[dBi] = 9 + 2.15 = 11.15 dBi`.

### 5. Спектральна щільність шуму N₀ та відношення C/N₀ у dBHz

Тепловий шум (англ. *thermal noise*) у радіоканалі на вході приймача виникає через хаотичний тепловий рух електронних носіїв заряду у провідниках і описується формулою Найквіста.

Спектральна щільність потужності теплового шуму `N₀` є рівномірною по всій смузі радіочастот (білий шум) і обчислюється за формулою:

```
N₀ = k · T                                 [формула Найквіста для спектральної щільності теплового шуму]
```

де:
- `k = 1.380649 · 10⁻²³ Дж/К` — фундаментальна стала Больцмана.
- `T` — абсолютна температура в Кельвінах (стандартна фізична кімнатна температура прийнята за `T₀ = 290 K`).

Обчислимо спектральну щільність шуму `N₀` при кімнатній температурі 290 K:

```
N₀ = (1.380649 · 10⁻²³ Дж/К) · 290 K       [підстановка k та кімнатної температури T = 290 K]
   = 4.00388 · 10⁻²¹ Вт/Гц                 [множення сталих у Вт/Гц]
   = 4.00388 · 10⁻¹⁸ мВт/Гц                [переведення Вт у мВт (1 Вт = 1000 мВт)]
```

Переведемо отримане значення у децибели відносно 1 мВт у смузі 1 Гц (`dBm/Hz`):

```
N₀[dBm/Hz] = 10 · log₁₀(4.00388 · 10⁻¹⁸)   [переведення мВт/Гц у децибели]
           = 10 · (-17.3975)              [обчислення логарифма log₁₀(4.00388·10⁻¹⁸)]
           = -173.98 dBm/Hz ≈ -174 dBm/Hz [округлення до цілого dBm/Hz]
```

Загальна потужність теплового шуму `N` у довільній смузі частот `B` (виміряній у Гц) обчислюється шляхом додавання логарифма смуги:

```
N[dBm] = N₀[dBm/Hz] + 10 · log₁₀(B[Гц])     [інтегрування шуму у смузі B Гц]
```

Відношення потужності несучої до спектральної щільності шуму `C/N₀` (у `dBHz`):

```
C/N₀ [dBHz] = C[dBm] - N₀[dBm/Hz]           [визначення відношення до спектральної щільності шуму]
            = C[dBm] - (-174 dBm/Hz)       [підстановка N₀ = -174 dBm/Hz]
            = C[dBm] + 174 dBm/Hz          [спрощення знака -(-174) = +174]
```

Якщо відоме загальне інтегральне відношення сигнал/шум `SNR` (у децибелах) у смузі `B`:

```
C/N₀ [dBHz] = SNR[dB] + 10 · log₁₀(B[Гц])  [зв'язок C/N0 та SNR у смузі B]
```

Ці математичні формули є основою для проєктування радіоліній зв'язку, супутникових систем та оцінки граничної пропускної здатності каналу за теоремою Шеннона-Хартлі.

### 6. Вплив неузгодження імпедансу та коефіцієнта відбиття

При перетворенні напруги в потужність припускалося, що хвильовий опір генератора, кабелю та навантаження є ідеально узгодженими (`Z_gen = Z_cable = Z_load = 50 Ом`).

У реальних трактах присутній неузгоджений опір, який описується коефіцієнтом відбиття по напрузі `Γ` (Гамма) та коефіцієнтом стоячої хвилі по напрузі (КСХН, англ. *VSWR*):

```
VSWR = (1 + |Γ|) / (1 - |Γ|)
```

Втрати неузгодження за потужністю (англ. *mismatch loss*) у децибелах обчислюються за формулою:

```
L_mismatch [dB] = -10 · log₁₀(1 - |Γ|²)
```

Якщо `VSWR = 1.5` (типове хороше узгодження антени), `|Γ| = (1.5 - 1)/(1.5 + 1) = 0.2`, а втрати відбиття становлять `L_mismatch = -10 · log₁₀(1 - 0.04) = 0.18 дБ`. Якщо ж `VSWR = 3.0` (погано узгоджена антена), `|Γ| = 0.5`, і втрати за потужністю зростають до `1.25 дБ` (відбивається 25% падаючої потужності).

Ураховувати ці математичні поправки необхідно при вимірюванні абсолютних рівнів сигналу `dBm` прецизійними ватметрами та аналізаторами спектра.
