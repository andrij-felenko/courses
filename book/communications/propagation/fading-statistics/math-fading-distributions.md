# 🧮 Математичні закони розподілів завмирань: Релей, Райс та Накагамі-m

Ця вставка містить строге математичне виведення щільностей імовірності (PDF), кумулятивних функцій розподілу (CDF), статистичних моментів, ймовірності виходу з ладу (outage probability), усередненої ймовірності бітової помилки (BER) та часових динамічних характеристик (LCR і AFD) для трьох основних законів розподілу огинаючої радіосигналу — Релея, Райса та Накагамі-m. Вона розкриває теоретичний апарат, за допомогою якого абстрактні випадкові флуктуації перетворюються на точні аналітичні розрахунки надійності радіозв'язку.

## 1. Розподіл Релея (Rayleigh Distribution)

### Фізична векторна модель та центральна гранична теорема
У середовищі з великою кількістю відбивачів без прямої видимості (NLOS) сумарне електричне поле в точці прийому утворюється додаванням `N` незалежних хвильових копій. Кожна копія має амплітуду `Aₖ` та випадкову фазу `θₖ`. Розклавши кожну хвилю у декартовій системі координат, отримаємо синфазну `I` та квадратурну `Q` складові:

```
I = ∑ [ Aₖ · cos(θₖ) ]                                    [сума синфазних складових]
Q = ∑ [ Aₖ · sin(θₖ) ]                                    [сума квадратурних складових]
```

Оскільки фази `θₖ` рівномірно розподілені від `0` до `2π`, математичне сподівання кожного доданку дорівнює нулю. За центральною граничною теоремою, при `N >> 1` суми `I` та `Q` є незалежними гаусовими випадковими величинами з нульовим середнім значенням і однаковою дисперсією `σ²`:

```
p(I) = (1 / √(2π · σ²)) · exp( -I² / (2σ²) )              [гаусова щільність синфазної складової]
p(Q) = (1 / √(2π · σ²)) · exp( -Q² / (2σ²) )              [гаусова щільність квадратурної складової]
```

Оскільки складові `I` та `Q` ортогональні й статистично незалежні, їхня спільна щільність імовірності `p(I, Q)` дорівнює добутку окремих щільностей:

```
p(I, Q) = p(I) · p(Q)                                      [незалежність I та Q]
        = (1 / (2π · σ²)) · exp( -(I² + Q²) / (2σ²) )      [перемноження гаусових щільностей]
```

### Перехід до полярних координат (амплітуда та фаза)
Для переходу від декартових координат `(I, Q)` до полярних координат амплітуди `r` та фази `ϕ` застосовуємо стандартне геометричне перетворення:

```
I = r · cos(ϕ)                                             [перехід до полярних координат]
Q = r · sin(ϕ)                                             [перехід до полярних координат]
r = √( I² + Q² ),   r ≥ 0                                  [амплітуда як радіус-вектор]
ϕ = arctan( Q / I ),   0 ≤ ϕ < 2π                          [фаза як кут]
```

Якобіан двовимірного перетворення координат дорівнює `|J| = r`. Спільна щільність імовірності `p(r, ϕ)` набуває вигляду:

```
p(r, ϕ) = p(I, Q) · |J|                                    [заміна змінних з якобіаном |J| = r]
        = (r / (2π · σ²)) · exp( -r² / (2σ²) )             [підстановка I² + Q² = r²]
```

Оскільки фаза `ϕ` є рівномірно розподіленою величинаю на інтервалі `[0, 2π)` і не залежить від амплітуди `r`, інтегруємо спільну щільність по всьому діапазону кутів `ϕ`:

```
p(r) = ∫₀²ⁿ p(r, ϕ) dϕ                                     [інтегрування спільної щільності по фазі]
     = (r / (2σ²)) · exp( -r² / (2σ²) ) · ∫₀²ⁿ (1 / 2π) dϕ  [винесення множників, що не залежать від ϕ]
     = (r / σ²) · exp( -r² / (2σ²) ),   r ≥ 0               [інтегрування: ∫ dϕ/2π = 1]
```

Це і є точний вираз щільності ймовірності (PDF) амплітуди Релея.

### Виведення статистичних моментів амплітуди
Обчислимо математичне сподівання амплітуди `E[r]` (перший момент):

```
E[r] = ∫₀∞ r · p(r) dr                                     [означення математичного сподівання]
     = ∫₀∞ (r² / σ²) · exp( -r² / (2σ²) ) dr               [підстановка p(r)]
```

Застосуємо заміну змінних `u = r² / (2σ²)`, звідси `r = σ · √(2u)` та `dr = (σ / √(2u)) du`:

```
E[r] = (σ · √2 / σ²) · ∫₀∞ (2σ² · u) · exp(-u) · (σ / √(2u)) du  [заміна змінних u = r² / (2σ²)]
     = σ · √(2) · ∫₀∞ u^(1/2) · exp(-u) du                 [спрощення коефіцієнтів]
     = σ · √(2) · Γ(3/2)                                   [означення Гамма-функції Eйлера]
     = σ · √(2) · (√π / 2)                                 [підстановка Γ(3/2) = √π / 2]
     = σ · √(π / 2) ≈ 1.2533 · σ                           [остаточний вираз першого моменту]
```

Знайдемо другий момент `E[r²]`, який виражає середню потужність прийнятого сигналу `P_avg`:

```
E[r²] = ∫₀∞ r² · (r / σ²) · exp( -r² / (2σ²) ) dr         [означення другого моменту]
      = 2σ² · ∫₀∞ u · exp(-u) du                          [заміна змінної u = r² / (2σ²)]
      = 2σ² · Γ(2) = 2σ²                                  [підстановка Γ(2) = 1]
```

Отже, середня потужність сигналу дорівнює `P_avg = E[r²] = 2σ²`.

Дисперсія амплітуди `Var[r]` визначається як різниця другого моменту та квадрата першого моменту:

```
Var[r] = E[r²] - (E[r])²                                   [теорема про дисперсію]
       = 2σ² - (σ · √(π / 2))²                             [підстановка моментів]
       = 2σ² - (π / 2) · σ²                                [піднесення до квадрата]
       = (2 - π/2) · σ² ≈ 0.4292 · σ²                      [остаточне значення дисперсії амплітуди]
```

### Кумулятивна функція розподілу (CDF) та Outage Probability
Імовірність того, що миттєва амплітуда `r` виявиться нижчою за встановлений пороговий рівень `R`:

```
P(r ≤ R) = ∫₀ᴿ (r / σ²) · exp( -r² / (2σ²) ) dr            [інтеграл від щільності ймовірності]
         = ∫₀^(R²/(2σ²)) exp(-u) du                         [заміна змінної u = r² / (2σ²)]
         = [ -exp(-u) ]₀^(R²/(2σ²))                        [первісна від exp(-u)]
         = 1 - exp( -R² / (2σ²) )                           [формула Ньютона-Лейбніца]
```

Переходячи до миттєвого відношення сигнал/шум `γ = r² · (E_b / N₀)` та його середнього значення `γ_avg = E[r²] · (E_b / N₀) = 2σ² · (E_b / N₀)`, кумулятивна функція перетворюється на вираз для ймовірності виходу лінії з ладу (**Outage Probability**):

```
P_out(γ_th) = P(γ ≤ γ_th) = 1 - exp( -γ_th / γ_avg )       [кумулятивна функція для SNR]
```

## 2. Середня ймовірність бітової помилки (BER) у каналі Релея

У каналі з аддитивним білим гаусовим шумом (AWGN) без завмирань ймовірність бітової помилки для фазової маніпуляції (BPSK) визначається через Q-функцію помилок:

```
P_b(γ) = Q( √(2γ) )                                        [ймовірність помилки BPSK в AWGN]
```

де `Q(x) = (1 / √(2π)) · ∫ₓ∞ exp(-t² / 2) dt`.

У каналі із завмираннями миттєве SNR `γ` безперервно коливається й має експоненційний розподіл `p(γ) = (1 / γ_avg) · exp(-γ / γ_avg)`. Щоб знайти середню ймовірність бітової помилки `P_bar_b`, необхідно проінтегрувати миттєву ймовірність помилки по всьому спектру можливих значень `γ`:

```
P_bar_b = ∫₀∞ P_b(γ) · p(γ) dγ                             [усереднення ймовірності помилки по закону завмирань]
        = ∫₀∞ Q( √(2γ) ) · (1 / γ_avg) · exp( -γ / γ_avg ) dγ  [підстановка Q-функції та щільності Релея]
```

Використовуючи інтегрування по частинах та властивості спеціальних функцій, отримуємо точну аналітичну формулу:

```
P_bar_b = (1 / 2) · [ 1 - √( γ_avg / (1 + γ_avg) ) ]       [точний вираз середнього BER для BPSK у каналі Релея]
```

При великих значеннях середнього SNR (`γ_avg >> 1`) застосуємо розклад у ряд Тейлора `√(1 / (1 + x)) ≈ 1 - 1/(2x)`:

```
P_bar_b ≈ 1 / (4 · γ_avg)                                  [асимптотичне наближення BER при великому SNR]
```

### Фізичний порівняльний висновок
- У каналі **AWGN** (без завмирань) ймовірність помилки спадає **експоненційно** з ростом SNR: `P_b ∝ exp(-γ)`.
- У каналі **Релея** ймовірність помилки спадає лише **обернено пропорційно** до SNR: `P_bar_b ∝ 1 / γ_avg`.

Це пояснює катастрофічне погіршення завадостійкості під час завмирань: щоб зменшити BER з `10⁻²` до `10⁻³` у каналі AWGN, достатньо підняти SNR лише на 2 дБ; у каналі Релея для цього потрібно збільшити потужність передавача на **10 дБ** (у 10 разів)!

## 3. Розподіл Райса (Rician Distribution)

### Фізична модель з прямою видимістю
Коли існує прямий незатемнений промінь амплітудою `s` з фазою `ϕ₀ = 0`, середнє значення синфазної складової `I` отримує постійний зсув `E[I] = s`, а квадратурна складова лишається з нульовим середнім `E[Q] = 0`:

```
p(I, Q) = (1 / (2π · σ²)) · exp( -((I - s)² + Q²) / (2σ²) )  [гаусова щільність зі зсувом середнього]
```

Перейшовши до полярних координат `I = r · cos(ϕ)` та `Q = r · sin(ϕ)`:

```
(I - s)² + Q² = I² - 2·s·I + s² + Q²                        [розкриття квадрата різниці]
              = r² + s² - 2·s·r·cos(ϕ)                      [підстановка I² + Q² = r² та I = r cos ϕ]
```

Спільна щільність імовірності в полярних координатах дорівнює:

```
p(r, ϕ) = (r / (2π · σ²)) · exp( -(r² + s² - 2·s·r·cos(ϕ)) / (2σ²) )  [підстановка в полярних координатах]
```

### Інтегрування по фазі та функція Бесселя
Інтегруємо спільну щільність по фазі `ϕ` від `0` до `2π`:

```
p(r) = (r / σ²) · exp( -(r² + s²) / (2σ²) ) · [ (1 / 2π) · ∫₀²ⁿ exp( (s·r / σ²) · cos(ϕ) ) dϕ ]  [інтегрування по ϕ]
```

Вираз у квадратних дужках за означенням є модифікованою функцією Бесселя першого роду нульового порядку `I₀(x)`:

```
I₀(x) = (1 / 2π) · ∫₀²ⁿ exp( x · cos(ϕ) ) dϕ                [інтегральне означення функції Бесселя I₀]
```

Тому щільність імовірності амплітуди Райса набуває остаточного вигляду:

```
p(r) = (r / σ²) · exp( -(r² + s²) / (2σ²) ) · I₀( s·r / σ² ),   r ≥ 0  [підстановка функції I₀]
```

### Параметр Райса K та середня потужність
Фактор Райса `K` визначається як відношення потужності прямого променя `P_LOS = s² / 2` до потужності розсіяної компоненти `P_scattered = σ²`:

```
K = s² / (2σ²)                                             [означення фактора Райса K]
```

Загальна середня потужність сигналу у каналі Райса дорівнює `Ω = E[r²] = s² + 2σ² = 2σ² · (K + 1)`.

## 4. Динаміка завмирань у часі: Виведення LCR та AFD

### Частота перетинів рівня (LCR)
Частота перетинів рівня `N_R` визначається як спільне математичне сподівання амплітуди `r` та її похідної в часі `r'` у момент перетину порогового рівня `R_th` у напрямку зростання (`r' > 0`):

```
N_R = ∫₀∞ r' · p(R_th, r') dr'                             [означення частоти перетинів Rice LCR]
```

Похідна амплітуди `r'` має нормальний розподіл з нульовим середнім і дисперсією `σ_r'² = 2π² · f_d² · σ²`, незалежний від самісінької амплітуди `r`. Спільна щільність розкладається в добуток `p(R_th, r') = p(R_th) · p(r')`.

Інтегруючи по `r' > 0`, отримуємо класичну формулу Райса для LCR каналу Релея:

```
N_R = √(2π) · f_d · ρ · exp( -ρ² )                         [формула LCR для нормованого порогу ρ = R_th / R_rms]
```

### Середня тривалість провалу (AFD)
Середня тривалість перебування сигналу нижче порогового рівня `τ_bar` визначається як відношення сумарного часу перебування під порогом `P(r ≤ R_th)` до кількості перетинів `N_R`:

```
τ_bar = P(r ≤ R_th) / N_R                                  [означення середньої тривалості провалу AFD]
      = (1 - exp(-ρ²)) / ( √(2π) · f_d · ρ · exp(-ρ²) )   [підстановка CDF та LCR]
      = (exp(ρ²) - 1) / (ρ · f_d · √(2π))                   [остаточна формула AFD]
```

## 5. Зведена характеристика показника загасання (Amount of Fading)

Нормована дисперсія потужності сигналу дорівнює **показникові загасання AF** (*Amount of Fading*):

```
AF = Var[P] / (E[P])² = (E[r⁴] - (E[r²])²) / (E[r²])²     [означення показника AF]
```

```
Закон розподілу        Показник загасання AF               Фізичний зміст
-----------------------------------------------------------------------------------------
Релей                  AF = 1.0                           Дисперсія потужності = (середнє)²
Райс                   AF = (2K + 1) / (K + 1)²           Зростання K зменшує флуктуації
Накагамі-m             AF = 1 / m                         Зворотна пропорційність до m
```
