# Математичні моделі Ван Влека-Вайскопфа та коефіцієнтів ITU-R P.838

Обчислення згасання електромагнітних хвиль у газах атмосфери та дощових осередках спирається на квантово-механічну теорію спектрального поглинання та макроскопічну теорію розсіювання електромагнітного випромінювання на діелектричних сфероїдах. У цій вставці наведено детальний математичний апарат, що лежить в основі міжнародних стандартів ITU-R P.676, ITU-R P.838 та ITU-R P.618.

---

### Квантово-механічний профіль Ван Влека-Вайскопфа

Поглинання радіохвилі частотою `f` молекулярним газом є сумою внесків окремих квантових переходів. Питомий коефіцієнт поглинання `γ` (у децибелах на кілометр) визначається уявницею частиною комплексної діелектричної проникності середовища `ε = ε' - j·ε"` і описується базовим виразом через комплексний коефіцієнт заломлення `N = N' - j·N"`:

```
γ = 0.1820 · f · N"      [дБ/км]
```

де `f` — частота радіохвилі в ГГц, а `N"` — уявна частина об'ємної комплексної радіозаломлюваності газу (у одиницях N-units).

#### Фізична несоспроможність класичного профілю Лоренца

У класичній спектроскопії оптичного діапазону для опису форм-фактора спектральної лінії традиційно застосовували профіль Лоренца `F_L(f, f_0)`:

```
F_L(f, f_0) = (1 / π) · [ Δf / ((f - f_0)² + Δf²) ]      [1/ГГц]
```

Проте в мікрохвильовому та радіочастотному діапазонах, де частота хвилі `f` стає співмірною з шириною лінії `Δf` або наближається до нуля (`f -> 0`), класичний профіль Лоренца виявляється математично та фізично хибним:
1. Він передбачає ненульове поглинання на нульовій частоті (`f = 0`), що порушує термодинамічну рівновагу та принципи статики.
2. Він не задовольняє дисперсійним співвідношенням Крамерса-Кроніґа для комплексної сприйнятливості середовища при низьких частотах.

#### Формула Ван Влека-Вайскопфа

У 1945 році Джон Ван Влек та Віктор Вайскопф розробили квантово-механічну теорію переривання зіткнень, згідно з якою під час зіткнення молекул відбувається хаотичний перерозподіл орієнтацій дипольного моменту відповідно до стану великої канонічної сукупності Больцмана.

Отриманий ними **форм-фактор лінії Ван Влека-Вайскопфа** `F(f, f_0)` має вигляд:

```
F(f, f_0) = (f / f_0) · [ Δf / ((f_0 - f)² + Δf²) + Δf / ((f_0 + f)² + Δf²) ]      [1/ГГц]
```

тут `Δf` — ширина спектральної лінії за рівнем половинної потужності (параметр розширення тиском), яка залежить від сухого атмосферного тиску `p` (гПа), парціального тиску водяної пари `e` (гПа) та абсолютної температури `T` (К):

```
Δf = Δf_0 · (p / 1013.25) · (300 / T)^x · (1 + b · e / p)      [ГГц]
```

де `x` — температурний показник розширення (зазвичай від 0.5 до 1.0 залежно від квантових чисел молекули), а `b` — коефіцієнт саморозширення водяної пари (self-broadening factor, `b ≈ 4.80`).

Розглянемо структуру виразу форм-фактора `F(f, f_0)` покомпонентно:
- Доданок `(f / f_0)` у чисельнику забезпечує збереження квантової пропорційності поглинання енергії фотонів `h·f`. При `f -> 0` форм-фактор прямує до нуля, що усуває фізичний дефект формули Лоренца.
- Перший член у дужках `Δf / ((f_0 - f)² + Δf²)` описує прямий квантовий резонанс на додатній частоті `+f_0`.
- Другий член у дужках `Δf / ((f_0 + f)² + Δf²)` описує дзеркальний від'ємний резонанс на частоті `-f_0`. На оптичних частотах цим членом можна знехтувати, але на мікрохвилях він дає суттєвий внесок у крила ліній.

#### Підсумовування за фундаментальними лініями

Загальне газове згасання є сумою внесків `N` спектральних ліній кисню `O2` та водяної пари `H2O`:

```
γ_gas(f) = γ_o(f) + γ_w(f)      [дБ/км]

γ_o(f) = f² · p · (300 / T)² · [ ∑ S_o,i · F_o,i(f) + γ_d(f) ]      [дБ/км]

γ_w(f) = f² · e · (300 / T)^2.5 · [ ∑ S_w,j · F_w,j(f) ]            [дБ/км]
```

де `S_o,i` та `S_w,j` — інтенсивності відповідних квантових ліній (в дБ/(км·гПа)), а `γ_d(f)` — непрозоре нерезонансне поглинання сухим повітрям за рахунок тимчасових індукованих дипольних моментів під час подвійних зіткнень молекул `N2-O2` та `O2-O2`.

### Вертикальна стратифікація атмосфери та інтегрування поглинання

Зі збільшенням висоти над рівнем моря `h` (км) тиск повітря `p(h)` та абсолютна вологість `ρ(h)` спадають за експоненційним барометричним законом:

```
p(h) = p_0 · exp(-h / H_p)      [гПа]

ρ(h) = ρ_0 · exp(-h / H_w)      [г/м³]
```

де `p_0 = 1013.25` гПа, `H_p ≈ 8.5` км — шкальна висота сухої атмосфери, а `H_w ≈ 2.0` км — шкальна висота водяної пари (водяна пара зосереджена у нижньому двокілометровому шарі тропосфери).

Повне згасання в атмосфери уздовж вертикального променя від поверхні Землі до космосу `A_gas,vert` обчислюється як інтеграл питомого згасання за висотою:

```
A_gas,vert = ∫ [ γ_o(h) + γ_w(h) ] dh      [дБ]      [від h=0 до h=∞]
```

Підставляючи експоненційні профілі тиску та вологості в формули Ван Влека-Вайскопфа та інтегруючи за висотою `h`, стандарт ITU-R P.676 зводить цей інтеграл до концепції **еквівалентних висот атмосфери**:

```
h_o = ∫ (γ_o(h) / γ_o(0)) dh = 6.0      [км]

h_w = ∫ (γ_w(h) / γ_w(0)) dh = 1.6 + 0.133 · ρ_0      [км]
```

Для будь-якого кута місця антени `θ ≥ 5°` інтегрування уздовж похилої траси через закон заломлення дає:

```
A_gas(θ) = (γ_o(0) · h_o + γ_w(0) · h_w) / sin(θ)      [дБ]
```

Цей красивий аналітичний результат дозволяє замінити складне чисельне інтегрування диференціальних рівнянь променя простою алгебраїчною формулою.

#### Температурна залежність та квантова функція стану

Інтенсивність ліній водяної пари `γ_w(T)` суттєво залежить від абсолютної температури `T` через зміну населеності обертальних рівнів Больцмана.

Квантова обертальна функція стану (partition function) для асиметричного дзиґа `Q_rot(T)` має вигляд:

```
Q_rot(T) = sqrt( (π · (k_B · T)³) / (A · B · C) )      [~ T^1.5]
```

де `A`, `B`, `C` — головні обертальні константи молекули `H2O`.

Оскільки чисельність молекул на конкретному нижчому квантовому рівні `E_j` пропорційна `(1 / Q_rot(T)) · exp(-E_j / (k_B · T))`, а середня швидкість молекулярних зіткнень залежить від швидкості за законом Максвелла `v ~ T^0.5`, результуючий коефіцієнт поглинання водяної пари набуває температурного множника:

```
γ_w(T) = γ_w(288.15) · (288.15 / T)^2.5 · exp( -1350 · (1 / T - 1 / 288.15) )      [дБ/км]
```

Цей вираз пояснює, чому при зниженні температури в зимовий період питоме поглинання водяною парою суттєво спадає навіть за умови збереження відносної вологості.

### Математичний облік кривизни Землі та функція Чапмана

Для малих кутів підвищення антени (`θ < 5°`) наближення плоского шару атмосфери `A_gas = A_vert / sin(θ)` втрачає точність, оскільки при `θ -> 0°` секанс кута `1 / sin(θ)` прямує до нескінченності, що суперечить геометрії сферичної Землі.

Для геометрії сферичної Землі геометричний шлях радіохвилі `s` на висоті `h` обчислюється через теорему косинусів:

```
(R_E + h)² = (R_E + h_s)² + s² + 2 · s · (R_E + h_s) · sin(θ)
```

Звідси диференціал довжини шляху `ds` виражається через висоту `dh`:

```
ds = dh / sqrt( sin²(θ) + 2 · (h - h_s) / R_E + ((h - h_s) / R_E)² )      [км]
```

#### Функція Чапмана

Для експоненційного профілю щільності газу `ρ(h) = ρ_0 · exp(-h / H)` інтеграл згасання уздовж горизонтального чи пологого променя виражається через **функцію Чапмана** `Ch(x, θ)` (де `x = R_E / H` — відносний радіус Землі, `x ≈ 800–3000`):

```
Ch(x, θ) = x · sin(θ) · ∫ exp( -x · (sqrt(1 + 2·y / (x · sin²(θ))) - 1) ) dy      [від y=0 до y=∞]
```

При горизонтальному випромінюванні (`θ = 0°`) функція Чапмана набуває точного граничного значення:

```
Ch(x, 0°) = sqrt( (π · x) / 2 ) ≈ sqrt( (π · R_E) / (2 · H) )
```

Для еквівалентної висоти кисню `h_o = 6.0` км маємо `x = 6371 / 6.0 = 1061.8`, що дає граничний множник `Ch(1061.8, 0°) = sqrt(π · 1061.8 / 2) = 40.8`.

Це означає, що при стрільбі горизонтально вздовж поверхні Землі повне газове згасання товщі атмосфери в **40.8 рази** перевищує згасання у вертикальному зенітному промені.

Стандарт ITU-R P.676 моделює цей ефект через модифіковану довжину траси:

```
F_o(θ) = 1 / ( sqrt(sin²(θ) + 0.0016) + 0.004 / (sin(θ) + 0.008) )
```

### Спрощена апроксимація ITU-R P.676 для інженерних розрахунків

Для практичних обчислень на рівні моря (при `p = 1013.25` гПа, `T = 288.15` К, `ρ = 7.5` г/м³) стандарт ITU-R P.676 пропонує закриті апроксимаційні многочлени:

Для кисню `γ_o(f)` у діапазоні від 1 до 50 ГГц:

```
γ_o(f) = [ 7.27 / (f² + 0.351) + 7.5 / ((f - 57)² + 2.44) ] · f² · 10⁻³      [дБ/км]
```

Для водяної пари `γ_w(f)` у діапазоні від 1 до 350 ГГц біля ліній 22.235 ГГц та 183.31 ГГц:

```
γ_w(f) = [ 0.05 + 0.002·ρ + 3.6 / ((f - 22.235)² + 8.5) + 10.6 / ((f - 183.31)² + 9.0) ] · f² · ρ · 10⁻⁴      [дБ/км]
```

### Математична модель дощового згасання ITU-R P.838

Питоме згасання в дощі `γ_r` залежить від інтенсивності дощу `R` (мм/год) і визначається емпіричним степеневим законом:

```
γ_r = k · R^α      [дБ/км]
```

Коефіцієнти `k` та `α` розраховуються для заданої частоти `f` (ГГц), кута місця антени `θ` та кута нахилу поляризації `τ` (де `τ = 0°` для горизонтальної поляризації, `τ = 90°` для вертикальної, `τ = 45°` для кругової):

```
k = [ k_H + k_V + (k_H - k_V) · cos²(θ) · cos(2τ) ] / 2

α = [ k_H · α_H + k_V · α_V + (k_H · α_H - k_V · α_V) · cos²(θ) · cos(2τ) ] / (2 · k)
```

значення `k_H`, `k_V`, `α_H`, `α_V` обчислюються за логарифмічними поліномами від частоти `f`:

```
log10(k) = ∑ a_j · exp( -((log10(f) - b_j) / c_j)² )

α = ∑ d_j · exp( -((log10(f) - e_j) / f_j)² )
```

#### Математичне походження коефіцієнтів k та α

Параметри `k` та `α` отримано дослідниками ITU-R SG3 шляхом чисельного інтегрування коефіцієнтів послаблення Мі `Q_ext(D, f)` за статистичним спектром розмірів крапель Маршалла-Палмера `N(D)`:

```
γ_r(f) = 4.343 · 10³ · ∫ Q_ext(D, f) · N(D) dD      [дБ/км]
```

Оскільки коефіцієнт ефективності розсіювання Мі `Q_ext` для сплюснутого сфероїда залежить від орієнтації вектора електричного поля `E` відносно великої осі сфероїда, інтеграли для горизонтально та вертикально поляризованих хвиль відрізняються, що й генерує два комплекси табличних коефіцієнтів `(k_H, α_H)` та `(k_V, α_V)`.

#### Матричне перетворення поляризаційного нахилу

Для довільного кута нахилу вектора напруженості електричного поля `τ` відносно горизонтальної площини (де `τ = 0°` відповідає чисто горизонтальній поляризації H, `τ = 90°` — чисто вертикальній V, а `τ = 45°` — круговій поляризації), матричне перетворення Джонса для комплексної амплітуди поля дає узагальнені коефіцієнти поглинання:

```
k = [ k_H + k_V + (k_H - k_V) · cos²(θ) · cos(2τ) ] / 2

α = [ k_H · α_H + k_V · α_V + (k_H · α_H - k_V · α_V) · cos²(θ) · cos(2τ) ] / (2 · k)
```

де тригонометричний член `cos(2τ) = cos²(τ) - sin²(τ)` забезпечує плавну кутову інтерполяцію між лінійними та круговою поляризаціями.

#### Порівняльний розрахунок поляризацій на частоті 30 ГГц

Зокрема, для частоти 30 ГГц (Ka-діапазон) при горизонтальному промені (`θ = 0°`):
- Для горизонтальної поляризації (H): `k_H = 0.2403`, `α_H = 0.9485`
- Для вертикальної поляризації (V): `k_V = 0.2291`, `α_V = 0.9129`

При інтенсивності сильного дощу `R = 50` мм/год алгебраїчний розрахунок дає:

```
γ_r,H = 0.2403 · 50^0.9485 = 0.2403 · 40.73 = 9.79      [дБ/км]

γ_r,V = 0.2291 · 50^0.9129 = 0.2291 · 35.32 = 8.09      [дБ/км]
```

Різниця між горизонтальною та вертикальною поляризацією складає `9.79 - 8.09 = 1.70` дБ/км (на 21% вище для горизонтальної поляризації), що є строгим математичним підтвердженням ефекту сплюснутості крапель дощу під час падіння.

### Рівняння Ейконалу та атмосферна рефракція променя

При обчисленні похилої траси для малих кутів підвищення `θ < 10°` необхідно враховувати не лише поглинання газами, а й скривлення траєкторії променя через атмосферну рефракцію.

Поширення радіохвилі описується **рівнянням Ейконалу** геометрії оптичної електродинаміки:

```
|∇S|² = n²(h) = (1 + N(h) · 10⁻⁶)²
```

де `S(x,y,z)` — функція фазового фронту (ейконал), `n(h)` — коефіцієнт заломлення повітря на висоті `h`, а `N(h)` — радіозаломлюваність у N-одиницях.

Згідно із законом Снеліуса для концентричних сферичних шарів атмосфери, уздовж траєкторії променя виконується інваріант:

```
(R_E + h) · n(h) · cos(θ(h)) = const
```

де `R_E ≈ 6371` км — геометричний радіус Землі, а `θ(h)` — кут між траєкторією променя та місцевим горизонтом.

Через спадання щільності повітря з висотою похідна `dn/dh < 0`, що спричиняє загинання радіопроменя у бік поверхні Землі. Для врахування цього викривлення в супутниковій навігації та радіорелейному зв'язку уводять **еквівалентний радіус Землі** `R_eff = k_earth · R_E` (де `k_earth ≈ 4/3 = 1.33` у стандартній тропосфері).

### Трасовий розрахунок супутникової лінії за ITU-R P.618

Для обчислення повного дощового згасання на похилій трасі земля-супутник для заданого відсотка часу доступності (наприклад, 99.99% часу на рік, що відповідає часовому перевищенню `p = 0.01%`), використовують покроковий алгоритм:

#### Крок 1. Визначення висоти дощу h_R
Визначається висота ізотерми нуль градусів за Цельсієм залежно від географічної широти земної станції `φ`:

```
h_R = 5.0 - 0.075 · (|φ| - 23)      [км]      [для |φ| > 23°]
```

#### Крок 2. Обчислення геометрії похилого шляху L_S
Обчислюється чисто геометрична довжина шляху радіохвилі у дощовому шарі з урахуванням рефракційного радіуса Землі:

```
L_S = (h_R - h_s) / sin(θ)      [км]
```

де `h_s` — висота земної станції над рівнем моря (км), `θ` — кут місця (elevation angle).

#### Крок 3. Обчислення горизонтальної проекції траси L_G

```
L_G = L_S · cos(θ)      [км]
```

#### Крок 4. Обчислення коефіцієнта горизонтального зменшення довжини r_0.01

```
r_0.01 = 1 / (1 + 0.78 · sqrt(L_G · γ_r / f) - 0.38 · (1 - exp(-2 · L_G)))
```

Член `sqrt(L_G · γ_r / f)` у знаменнику враховує просторову кореляцію інтенсивності дощу: що вища частота `f` та що більша інтенсивність зливи `γ_r`, то меншим є горизонтальний розмір дощового осередку високої щільності.

#### Крок 5. Обчислення коефіцієнта вертикального корегування v_0.01

```
v_0.01 = 1 / (1 + sqrt(sin(θ)) · (0.31 · (1 - exp(-θ / 4.5)) · sqrt(L_S · γ_r) / f - 0.45))
```

#### Крок 6. Визначення ефективної довжини шляху у дощі L_E

```
L_E = L_S · r_0.01 · v_0.01      [км]
```

#### Крок 7. Обчислення сумарного послаблення в дощі
Обчислюються підсумкові атмосферні втрати для доступності 99.99% (простій не більше 52 хвилин на рік):

```
A_0.01 = γ_r · L_E      [дБ]
```

Цей математичний алгоритм доводить, що через просторову локалізацію злив реальна ефективна довжина дощового стовпа `L_E` зазвичай удвічі або втричі менша за чисто геометричну довжину `L_S`.

### Єдність квантової фізики та емпіричної інженерії ITU-R

Обчислювальний апарат ITU-R демонструє унікальний приклад того, як квантово-механічна теорія молекулярних переходів Ван Влека-Вайскопфа об'єднується з емпіричною теорією розсіювання Мі для практичного застосування у телекомунікаціях.

Замість того, щоб у кожній інженерній програмі обчислювати складні інтеграли квантових систем та сумувати тисячі спектральних ліній на суперкомп'ютерах, стандарти ITU-R P.676 та ITU-R P.838 згортають фундаментальну фізику у зручні закриті поліноми та логарифмічні табличні коефіцієнти. Це дозволяє обчислювати загасання будь-якої похилої чи горизонтальної траси за мікросекунди прямо в мікроконтролерах радіомодемів реального часу, зберігаючи високу точність збігу з натурними експериментальними вимірюваннями. Таким чином, математичні моделі ITU-R забезпечують точний та фундаментально обґрунтований розрахунок згасання для сучасних та майбутніх бездротових систем.
