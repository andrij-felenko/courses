# 🧮 Математичний вивід радіуса зон Френеля

Ця вставка містить строгий геометричний та алгебраїчний вивід формули радіуса зон Френеля в параксіальному наближенні, перехід до спрощеної інженерної формули у гігагерцах і кілометрах, а також математичне обґрунтування дифракційного згасання на основі інтегралів Френеля та спіралі Корню.

### Геометрія оптичного шляху та параксіальне наближення

Розглянемо передавач `Tx` та приймач `Rx`, розташовані в тривимірному просторі вздовж горизонтальної осі `X`. Відстань між ними дорівнює `d` (метри). Нехай прямолінійний відрізок `Tx-Rx` слугує віссю симетрії радіолінії.

Виберемо довільну площину поперечного перерізу, перпендикулярну до осі `Tx-Rx`, що знаходиться на відстані `d1` від передавача та на відстані `d2` від приймача. Очевидно, що сумарна довжина траси становить:

```
d = d1 + d2      [метри]
```

Нехай точка `P` лежить у цій площині на відстані `R` від осі `Tx-Rx`. Електромагнітна хвиля може поширюватися від `Tx` до `Rx` двома шляхами:
1. **Прямий шлях (LOS):** вздовж осі відрізка завдовжки `d`.
2. **Непрямий шлях:** від `Tx` до точки `P` (довжина `S1`), а потім від `P` до `Rx` (довжина `S2`).

```
           P (точка на межі n-ї зони)
          / \
     S₁  /   \  S₂
        /     \
       /   R   \
Tx ---+---------+--- Rx
     |<-- d₁ -->|<-- d₂ -->|
     |<------- d ------->|
```

За теоремою Піфагора довжини відрізків `S1` та `S2` становлять:

```
S1 = √(d1² + R²)      [м]
S2 = √(d2² + R²)      [м]
```

У практичних радіолініях поперечний радіус зони `R` вимірюється метрами або десятками метрів, тоді як довжини ділянок `d1` та `d2` становлять кілометри або десятки кілометрів. Це означає, що відношення `R / d1` та `R / d2` є надзвичайно малими величинами (типово менше `0.01`). Отже, виконується умова **параксіального наближення** (*paraxial approximation*).

Винесемо `d1` за знак квадратного кореня у виразі для `S1` та застосуємо розклад у статевий ряд Тейлора (біноміальний розклад) `√(1 + x) = 1 + x / 2 - x² / 8 + ...` для малих `x = (R / d1)²`:

```
S1 = d1 · √(1 + (R / d1)²)
   = d1 · (1 + 0.5 · (R / d1)² - 0.125 · (R / d1)⁴ + ...)
   ≈ d1 + R² / (2 · d1)      [крок 1: наближення для S1 з точністю O(R⁴/d₁³)]

S2 = d2 · √(1 + (R / d2)²)
   = d2 · (1 + 0.5 · (R / d2)² - 0.125 · (R / d2)⁴ + ...)
   ≈ d2 + R² / (2 · d2)      [крок 2: наближення для S2 з точністю O(R⁴/d₂³)]
```

Нехтуючи членами четвертого порядку малості `O(R⁴ / d³)`, які для реальних радіоліній дають похибку менше ніж `0.001` міліметра, підсумуємо довжину непрямого шляху `S1 + S2`:

```
S1 + S2 ≈ (d1 + d2) + (R² / 2) · (1 / d1 + 1 / d2)
        = d + (R² / 2) · ((d1 + d2) / (d1 · d2))      [крок 3: сумарний шлях]
```

Різниця ходу `Δ` між непрямим та прямим шляхом дорівнює:

```
Δ = (S1 + S2) - d
  ≈ (R² / 2) · ((d1 + d2) / (d1 · d2))      [крок 4: різниця ходу]
```

### Рівняння межі n-ї зони Френеля

Межа `n`-ї зони Френеля визначається геометричним місцем точок, для яких різниця ходу `Δ` становить строго `n` півхвиль (де `n = 1, 2, 3...` — номер зони, а `λ` — довжина хвилі у метрах):

```
Δ = n · (λ / 2)      [умова фазового зсуву]
```

Прирівняємо алгебраїчний вираз для різниці ходу `Δ` до геометричної умови `n · λ / 2`:

```
(R_n² / 2) · ((d1 + d2) / (d1 · d2)) = n · (λ / 2)
```

Помножимо обидві частини рівняння на `2` та виразимо квадрат радіуса `R_n²`:

```
R_n² · ((d1 + d2) / (d1 · d2)) = n · λ

R_n² = (n · λ · d1 · d2) / (d1 + d2)      [квадрат радіуса n-ї зони]
```

Враховуючи, що `d1 + d2 = d`, добуваємо квадратний корінь і отримуємо фундаментальну **формулу радіуса n-ї зони Френеля**:

```
R_n = √((n · λ · d1 · d2) / d)      [радіус n-ї зони Френеля, м]
```

Для першої (головної) зони Френеля (`n = 1`):

```
R_1 = √((λ · d1 · d2) / d)      [радіус 1-ї зони Френеля, м]
```

Тривимірна геометрія цієї поверхні описується рівнянням еліпсоїда обертання навколо осі `X`. У декартових координатах із центром посередині траси (`x = 0`):

```
(x² / a_n²) + ((y² + z²) / b_n²) = 1      [рівняння еліпсоїда n-ї зони]
```

де:
- Велика піввісь `a_n = (d / 2) + n · λ / 4`;
- Мала піввісь `b_n = R_max_n = 0.5 · √(n · λ · d)`.

Максимальне значення радіуса `R_max` досягається точно посередині траси, де `d1 = d2 = d / 2`:

```
R_max = √((λ · (d / 2) · (d / 2)) / d)
      = √((λ · d²) / (4 · d))
      = 0.5 · √(λ · d)      [максимальний радіус посередині траси, м]
```

### Вивід спрощеної інженерної формули

У практичній радіоінженерії довжина хвилі `λ` визначається через частоту `f` у гігагерцах (`ГГц`), а відстані `d1`, `d2` та `d` вимірюються у кілометрах (`км`).

Зв'язок довжини хвилі та частоти у вакуумі/повітрі (`c ≈ 2.99792458 · 10⁸ м/с ≈ 3·10⁸ м/с`):

```
λ = c / f
  = (3 · 10⁸ м/с) / (f_GHz · 10⁹ Гц)
  = 0.3 / f_GHz      [метри]
```

Переведемо відстані з кілометрів у метри: `d1_м = 1000 · d1_km`, `d2_м = 1000 · d2_km`, `d_м = 1000 · d_km`.

Підставимо ці значення у формулу радіуса першої зони `R_1`:

```
R_1 = √(( (0.3 / f_GHz) · (1000 · d1_km) · (1000 · d2_km) ) / (1000 · d_km))
    = √(( 0.3 · 1000000 · d1_km · d2_km ) / (1000 · f_GHz · d_km))
    = √(( 300000 · d1_km · d2_km ) / (1000 · f_GHz · d_km))
    = √( 300 · (d1_km · d2_km) / (f_GHz · d_km) )      [підрадикальний вираз]
```

Винесемо числове значення `√300` з-під знака кореня:

```
√300 = √(100 · 3) = 10 · √3 ≈ 17.320508
```

Отримуємо класичну **інженерну формулу радіуса першої зони Френеля**:

```
R_1 ≈ 17.32 · √((d1_km · d2_km) / (f_GHz · d_km))      [метри]
```

Для довільної `n`-ї зони формула має вигляд:

```
R_n ≈ 17.32 · √((n · d1_km · d2_km) / (f_GHz · d_km))      [метри]
```

### Дифракційна теорія Френеля-Кірхгофа та спіраль Корню

Обчислення згасання хвилі при частковому або повному перекритті траси непрозорою перешкодою спирається на скалярну теорію дифракції Френеля-Кірхгофа.

Згідно з цією теорією, напруженість електричного поля `E` у точці приймача від відкритої частини хвильового фронту описується поверхневим інтегралом по відкритому апертурному вікну `S`:

```
E = (j · E_0 / λ) · ∬_S ( (e^(-j · k_wave · (S1 + S2))) / (S1 · S2) ) · K(θ) dS
```

де `k_wave = 2 · π / λ` — хвильове число, а `K(θ) ≈ 0.5 · (1 + cos(θ))` — кутовий коефіцієнт нахилу вторинних джерел Гюйгенса.

Для клиноподібної напівнескінченної непрозорої перешкоди (*knife-edge obstacle*) цей двомірний інтеграл зводиться до одномірного комплексного інтеграла через безрозмірний параметр дифракції Френеля-Кірхгофа `v`:

```
v = h · √((2 · (d1 + d2)) / (λ · d1 · d2))
  = h · (√2 / R_1)      [параметр дифракції]
```

де `h` — висота перешкоди відносно осі `LOS` (прийнято `h > 0`, якщо перешкода виступає вище осі `LOS`, та `h < 0`, якщо лінія `LOS` проходить вище перешкоди, утворюючи просвіт).

Відносне комплексне напруження електричного поля `E / E_0` (відносно поля у вільному просторі `E_0`) виражається через канонічні **інтеграли Френеля** `C(v)` та `S(v)`:

```
C(v) = ∫₀ᵛ cos(π · t² / 2) dt
S(v) = ∫₀ᵛ sin(π · t² / 2) dt

E / E_0 = (1 / (1 + j)) · ( (0.5 - C(v)) - j · (0.5 - S(v)) )      [комплексне поле]
```

У графічному зображенні на комплексній площині інтеграли Френеля `C(v)` та `S(v)` утворюють відому **спіраль Корню** (*Cornu spiral* або клотоїду).

```
                     СПІРАЛЬ КОРНЮ ТА ВЕКТОР ПОЛЯ
                     
        S(v) ^
             |             * (0.5, 0.5) - Верхній фокус (вільний простір)
             |           /
             |          /  Вектор напруженості поля E / E_0
             |         /
             |        * (C(v), S(v)) - Точка, відповідаюча межі перешкоди
             +--------------------------> C(v)
            /
           * (-0.5, -0.5) - Нижній фокус
```

Амплітудний модуль прийнятого поля `|E / E_0|` відповідає довжині вектора, що з'єднує точку спіралі з координатним фокусом `(0.5, 0.5)`.

Дифракційне загасання у децибелах `L_diff (дБ)` обчислюється як:

```
L_diff = -20 · log10|E / E_0|      [дБ]
```

Аналіз спіралі Корню пояснює ключові точкові значення загасання:

1. **Повна відсутність перешкоди (`v → -∞`):** Точка на спіралі знаходиться у нижньому фокусі `(-0.5, -0.5)`. Довжина вектора до верхнього фокуса `(0.5, 0.5)` дорівнює `√((0.5 - (-0.5))² + (0.5 - (-0.5))²) = √2`. З урахуванням нормувального множника `1 / |1 + j| = 1 / √2`, модуль поля `|E / E_0| = 1.0`, а втрати `L_diff = 0 дБ`.
2. **Дотикання осі променя (`v = 0`, `h = 0`):** Точка на спіралі знаходиться на початку координат `(0, 0)`. Довжина вектора до фокуса `(0.5, 0.5)` дорівнює `√(0.5² + 0.5²) = 1 / √2`. Модуль поля `|E / E_0| = (1 / √2) / √2 = 0.5`. Напруженість поля зменшується удвічі, а потужність — у 4 рази. Втрати `L_diff = -20 · log10(0.5) = +6.02 дБ`.
3. **Критерій 60% просвіту (`v = -0.6 · √2 ≈ -0.85`, `h = -0.6 · R_1`):** Вектор спіралі Корню досягає першого максимуму, де модуль поля `|E / E_0| ≈ 1.0`, а втрати `L_diff ≈ 0 дБ`.

### Аналітичні апроксимації для інженерних обчислень

Оскільки інтеграли Френеля не виражаються в елементарних функціях, у програмах моделювання радіоліній використовуються високоточні аналітичні апроксимації Міжнародного союзу електрозв'язку (рекомендація **ITU-R P.526-15**) та апроксимація Лі (*Lee approximation*).

Апроксимація ITU-R P.526 для клиноподібного екрана при `v > -0.7`:

```
L_diff(v) = 6.9 + 20 · log10( √( (v - 0.1)² + 1 ) + v - 0.1 )      [дБ]
```

Для випадків складної геометричної форми перешкод використовуються розширені методи:
- **Метод Дейго (Deygout method):** використовується для двох послідовних клиноподібних перешкод (головна перешкода визначає перший екран, а друга обчислюється відносно еквівалентних антен).
- **Метод Епштейна-Петерсона (Epstein-Peterson method):** додає дифракційні втрати від двох окремих клинів із фазовою корекцією.

Цей математичний апарат утворює основу сучасних геоінформаційних систем планування бездротових мереж.
