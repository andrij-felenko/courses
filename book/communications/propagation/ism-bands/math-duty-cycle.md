# 🧮 Розрахунок EIRP, робочого циклу та пропускної здатності неліцензованого каналу

Ця вставка містить детальні математичні виведення, формули та числові розрахунки випромінюваної потужності (EIRP), робочого циклу (Duty Cycle), часу перебування в ефірі (Time-on-Air) для різних типів модуляції та ймовірності колізій у неліцензованих ISM-діапазонах.

### 1. Розрахунок еквівалентної ізотропно-випромінюваної потужності (EIRP)

Регуляторні норми (наприклад, ETSI EN 300 220, регламент НКЕК України чи FCC Part 15 у США) встановлюють гранично допустимі межі випромінюваної потужності не для самого передавача, а для всієї антено-фідерної системи у вигляді EIRP (Effective Isotropic Radiated Power).

EIRP у логарифмічних одиницях (dBm) обчислюється як сума вихідної потужності передавача, коефіцієнта підсилення антени та втрат у високочастотному кабелі чи фідерному тракті:

```text
EIRP [dBm]
= P_tx [dBm] + G_ant [dBi] - L_cable [dB]    [сума потужності передавача та підсилення антени мінус втрати в кабелі]
```

**Приклад розрахунку:**  
Модуль LoRa має вихідну потужність `P_tx = +14 dBm` (25 мВт). Його підключено до напрямленої антени з підсиленням `G_ant = +5 dBi` через коаксіальний кабель із втратами `L_cable = 1.5 dB`.

Обчислимо реальне значення EIRP:

```text
EIRP
= 14 + 5 - 1.5        [підстановка значень P_tx, G_ant, L_cable]
= 17.5 dBm             [підсумкова еквівалентна потужність]
```

Оскільки норматив ETSI для субдіапазону 868.0–868.6 МГц обмежує EIRP величиною `+14 dBm` (25 мВт), дане налаштування є **порушенням регламенту**. Для дотримання закону вихідну потужність передавача слід зменшити до:

```text
P_tx_max
= EIRP_limit - G_ant + L_cable
= 14 - 5 + 1.5         [арифметика обмеження]
= 10.5 dBm             [максимально дозволена потужність Tx]
```

### 2. Час перебування в ефірі (Time-on-Air) та робочий цикл (Duty Cycle)

Робочий цикл `DC` визначає відсоток часу, протягом якого пристрій має право активувати передавач у межах спостережуваного часового вікна `T_obs` (згідно зі стандартом ETSI `T_obs = 1 година = 3600 секунд`):

```text
Duty Cycle [%]
= (sum(T_tx) / T_obs) * 100%    [відсоток часу мовлення відносно вікна в 1 годину]
```

Для FSK-модуляції з бітовою швидкістю `R` біт/с час передачі пакета розміром `B` байт обчислюється просто як:

```text
ToA = (B * 8) / R
```

Для LoRa-модуляції обчислення часу символу `T_sym` та тривалості пакета `ToA` залежить від коефіцієнта розширення спектра (Spreading Factor, SF) та ширини смуги (Bandwidth, BW):

```text
T_sym = (2^SF) / BW
```

При `SF = 12` та `BW = 125 кГц` (125 000 Гц) тривалість одного LoRa-символу становить:

```text
T_sym
= (2^12) / 125000     [обчислення 2^12 = 4096]
= 4096 / 125000       [ділення на ширину смуги]
= 0.032768 секунди    [тривалість 1 символу ≈ 32.77 мс]
```

Якщо пакет LoRa складається з преамбули (8 символів) та корисного навантаження (50 байт, що дає близько 115 символів при SF12), підсумковий час перебування в ефірі становить:

```text
ToA
= (8 + 4.25 + 115) * 0.032768   [сума символів преамбули, службових бітів та даних]
= 127.25 * 0.032768             [множення на тривалість символу]
≈ 4.17 секунди                  [тривалість одного мовлення LoRa SF12]
```

Якщо в даному субдіапазоні 868 МГц діє обмеження робочого циклу `DC = 1%`, то максимальний сумарний час мовлення на годину становить:

```text
T_tx_max
= T_obs * (DC / 100%)
= 3600 * 0.01          [1% від 3600 секунд]
= 36 секунд            [бюджет часу мовлення на годину]
```

При тривалості пакета `ToA = 4.17` с гранична кількість пакетів на годину `N_max` обчислюється як:

```text
N_max
= T_tx_max / ToA
= 36 / 4.17            [ділення бюджету часу на тривалість пакета]
≈ 8.63 пакетів/годину  [максимальна частота відправки]
```

Отже, пристрій LoRa SF12 може відправляти пакет не частіше ніж один раз на:

```text
T_interval_min
= 3600 / 8.63
≈ 417 секунд          [мінімальний інтервал 6.95 хвилини між пакетами]
```

### 3. Модель колізій Пуассона у неліцензованому каналі (Pure ALOHA та Slotted ALOHA)

Коли у спільному неліцензованому ISM-каналі працює `N` автономних вузлів без централізованої синхронізації, пропускна здатність описується моделлю Pure ALOHA.

Нехай сумарна інтенсивність згенерованого трафіку від усіх вузлів становить `lambda` пакетів за секунду. Тоді середня кількість спроб передачі за час тривалості одного пакета `ToA` дорівнює навантаженню каналу `G`:

```text
G = lambda * ToA
```

У системі Pure ALOHA вразливе часове вікно (Vulnerability Window), у якому будь-яка інша передача спричинить колізію та знищення обох пакетів, становить `2 * ToA` (пакет зазнає колізії, якщо інший вузол почне передачу в інтервалі від `t - ToA` до `t + ToA`).

За розподілом Пуассона ймовірність того, що протягом вразливого вікна не буде згенеровано жодного іншого пакета (ймовірність успішної доставки `P_success`), дорівнює:

```text
P_success = exp(-2 * G)
```

Корисна пропускна здатність каналу `S` (частка успішно доставленого часу) обчислюється як:

```text
S
= G * P_success         [визначення корисної пропускної здатності]
= G * exp(-2 * G)       [підстановка ймовірності успіху P_success]
```

Знайдемо точку екстремуму, продиференціювавши `S` по `G`:

```text
dS / dG
= exp(-2 * G) + G * (-2 * exp(-2 * G))   [похідна добутку f'g + fg']
= exp(-2 * G) * (1 - 2 * G)              [винесення спільного множника exp(-2G)]
```

Прирівнявши похідну до нуля, отримуємо максимальну теоретичну пропускну здатність каналу Pure ALOHA:

```text
1 - 2 * G = 0  =>  G = 0.5    [розв'язок рівняння 1 - 2G = 0]
```

Підставивши `G = 0.5` у формулу `S`:

```text
S_max
= 0.5 * exp(-2 * 0.5)   [підстановка точки максимуму G = 0.5]
= 0.5 * exp(-1)         [спрощення показника степеня]
= 0.5 * 0.367879        [значення e^-1]
≈ 0.1839                [підсумкова максимальна утилізація 18.4%]
```

Для порівняння, у синхронізованій системі **Slotted ALOHA**, де час розбито на кванти тривалістю `ToA` і передачі дозволені лише на початку кванта, вразливе вікно скорочується удвічі — до `1 * ToA`. Ймовірність успіху становить `P_success = exp(-G)`, а пропускна здатність дорівнює:

```text
S_slotted
= G * exp(-G)           [формула для Slotted ALOHA]
```

Максимум утилізації досягається при `G = 1.0` і становить:

```text
S_slotted_max
= 1.0 * exp(-1)
≈ 0.3679                [підсумкова максимальна утилізація 36.8%]
```

**Висновок:** У неліцензованому ISM-каналі з випадковим доступом без слухання ефіру (Pure ALOHA) теоретична максимальна утилізація спектра не може перевищувати **18.4%**. Решта 81.6% ємності втрачається через взаємні колізії пакетів. Впровадження часових квантів (Slotted ALOHA) подвоює утилізацію до **36.8%**, а застосування алгоритмів LBT (Listen Before Talk) та CSMA/CA підвищує ефективну утилізацію неліцензованого каналу до 70–80%.


### 4. Згасання у вільному просторі (FSPL) та чутливість приймача

Енергетичний бюджет радіолінії в неліцензованому ефірі обмежується зверху допустимим значенням EIRP. Зі зростанням відстані `d` (у кілометрах) та частоти `f` (у мегагерцах) електромагнітна хвиля зазнає геометрічного згасання у вільному просторі (Free Space Path Loss, FSPL):

```text
FSPL [dB]
= 20 * log10(d) + 20 * log10(f) + 32.44    [формула втрат у вільному просторі]
```

Порівняємо згасання сигналу на відстані `d = 1 км` для трьох ISM-частот:
* **433 МГц:** `FSPL = 20*log10(1) + 20*log10(433) + 32.44 = 0 + 52.73 + 32.44 = 85.17 dB`
* **868 МГц:** `FSPL = 20*log10(1) + 20*log10(868) + 32.44 = 0 + 58.77 + 32.44 = 91.21 dB`
* **2400 МГц:** `FSPL = 20*log10(1) + 20*log10(2400) + 32.44 = 0 + 67.60 + 32.44 = 100.04 dB`

Різниця між 868 МГц та 2.4 ГГц становить майже `8.8 dB`. Це означає, що при однаковій випромінюваній потужності передавача сигнал на 868 МГц зберігає у **7.5 разів більше енергії** на тій самій відстані, що пояснює виняткову дальність субгігагерцових систем.

Порогова чутливість приймача `P_rx_min` обчислюється на основі теплового шуму при кімнатній температурі (`-174 dBm/Гц`), ширини смуги `BW`, коефіцієнта шуму підсилювача `NF` та мінімального необхідного відношення сигнал/шум `SNR_min`:

```text
P_rx_min [dBm]
= -174 + 10 * log10(BW) + NF + SNR_min    [теоретичний поріг чутливості приймача]
```

Для вузькосмугового передавача LoRa (`BW = 125 кГц`, `10*log10(125000) ≈ 51 dB`, `NF = 6 dB`, `SNR_min = -20 dB` при SF12) порогова чутливість приймача становить:

```text
P_rx_min
= -174 + 51 + 6 - 20   [підстановка параметрів LoRa SF12]
= -137 dBm             [надзвичайно висока гранична чутливість]
```

Саме ця наднизька чутливість (`-137 dBm`) дозволяє зчитувати слабкі сигнали LoRa навіть тоді, коли їхня потужність знаходиться глибоко під рівнем природного теплового шуму.
