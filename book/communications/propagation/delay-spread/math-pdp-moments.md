# 🧮 Математика профілю затримки потужності та когерентної смуги

Ця вставка містить суворе математичне виведення числових моментів профілю затримки потужності (PDP), виведення автокореляційної функціональної характеристики каналу в частотній області та аналітичне доведення оберненого зв'язку між середньоквадратичним розкидом затримок `σ_τ` і смугою когерентності `B_c` для різних типів розподілу луни.

---

### 1. Математичне моделювання багатопроменевого каналу

У класичній теорії WSSUS (Wide-Sense Stationary Uncorrelated Scattering), запропонованій Філіпом Белло, часово-просторовий радіоканал описується комплексною імпульсною відповіддю `h(t, τ)`, де `t` позначає поточний момент спостереження, а `τ` — затримку поширення.

Для дискретного каналу з `N` фізичними розсіювачами або відбиваючими об'єктами імпульсна відповідь подається як сума зсунутих дельта-функцій:

```
h(t, τ) = ∑ᵢ₌₁ᴺ aᵢ(t) · exp(-j · 2π · f_c · τᵢ(t) + j · φᵢ(t)) · δ(τ - τᵢ(t))
```

де `aᵢ(t)` — комплексна огинаюча амплітуди `i`-го променя, `f_c` — несуча частота радіосигналу, `τᵢ(t)` — затримка приходу `i`-ї копії хвилі, а `δ(·)` — дельта-функція Дірака.

Завдяки фундаментальному припущенню про некорельованість розсіювання (US), відбиття з різними затримками `τᵢ` та `τⱼ` розглядаються як фазово ортогональні випадкові величини. Це дозволяє усереднити огинаючу за фазовими флуктуаціями та ввести **профіль затримки потужності** (Power Delay Profile, PDP) `P(τ)`, який характеризує статистичний розподіл середньої потужності прийнятого сигналу залежно від часу затримки:

```
P(τ) = E[ |h(t, τ)|² ]
```

Для дискретного набору променів функція `P(τ)` подається у вигляді дискретного спектра потужностей за затримками:

```
P(τ) = ∑ᵢ₌₁ᴺ Pᵢ · δ(τ - τᵢ)
```

де `Pᵢ = E[|aᵢ(t)|²]` — середня лінійна потужність `i`-го відбитого променя.

---

### 2. Строгі математичні моменти PDP

Щоб кількісно описувати часовий розподіл прийнятої енергії без обробки повних графіків імпульсної відповіді, у теорії ймовірностей та математичній статистиці використовують моменти розподілу `P(τ)`.

#### Повна потужність прийнятого сигналу (`P_total`)
Загальна енергія сигналу, що надходить до приймальної антени з усіма відбитими копіями:

```
P_total = ∫₀^∞ P(τ) dτ = ∑ᵢ₌₁ᴺ Pᵢ
```

#### Нормований щільнісний розподіл затримок (`p(τ)`)
Для застосування математичного апарату теорії ймовірностей функцію PDP нормують на повну потужність `P_total`, перетворюючи її на математичну щільність ймовірності часу приходу енергії:

```
p(τ) = P(τ) / P_total
```

Для нормованого розподілу виконується очевидна умова нормування `∫₀^∞ p(τ) dτ = 1` та `∑ᵢ pᵢ = 1`.

#### Середня затримка (Mean Excess Delay, `τ̄`)
Перший початковий момент розподілу `p(τ)`, який задає математичне сподівання (центр ваги) часу приходу енергії сигналу:

```
τ̄ = E[τ] = ∫₀^∞ τ · p(τ) dτ = (∑ᵢ₌₁ᴺ Pᵢ · τᵢ) / P_total
```

Фізично середня затримка `τ̄` показує, на скільки наносекунд або мікросекунд зміщений геометричний центр енергетичного імпульсу відносно моменту приходу першого променя.

#### Другий початковий момент (`τ²_bar`)
Оцінка середнього квадрата часу затримки прийнятої енергії:

```
τ²_bar = E[τ²] = ∫₀^∞ τ² · p(τ) dτ = (∑ᵢ₌₁ᴺ Pᵢ · τᵢ²) / P_total
```

#### Середньоквадратичний розкид затримок (RMS Delay Spread, `σ_τ`)
Корінь із дисперсії (другого центрального моменту) розподілу затримок сигналу за часом:

```
σ_τ = √[ E[(τ - τ̄)²] ] = √[ E[τ²] - (E[τ])² ] = √[ τ²_bar - (τ̄)² ]
```

Розгортаючи квадрат різниці, у дискретній формі підсумкова формула RMS delay spread набуває вигляду:

```
σ_τ = √[ (∑ᵢ Pᵢ · (τᵢ - τ̄)²) / (∑ᵢ Pᵢ) ]
```

Параметр `σ_τ` є фундаментальною характеристикою каналу. Він вимірюється в секундах (нс або мкс) і визначає ефективну часову тривалість імпульсного розмивання сигналу.

### 3. Двоїстість за Фур'є: Частотна автокореляційна функція

Згідно з теоремою Вінера–Хінчина–Белло, статистична кореляція між значеннями комплексної передавальної функції каналу `H(t, f)` на двох різних частотах `f₁` та `f₂ = f₁ + Δf` обчислюється як пряме перетворення Фур'є від профілю затримки потужності `P(τ)`:

```
R_H(Δf) = E[ H*(t, f) · H(t, f + Δf) ] = ∫₀^∞ P(τ) · exp(-j · 2π · Δf · τ) dτ
```

Нормований коефіцієнт частотної кореляції `ρ_H(Δf)` характеризує рівень фазово-амплітудного зв'язку між спектральними складової сигналу, віддаленими на відстань `Δf`:

```
ρ_H(Δf) = R_H(Δf) / R_H(0) = (∫₀^∞ P(τ) · exp(-j · 2π · Δf · τ) dτ) / (∫₀^∞ P(τ) dτ)
```

Смуга когерентності `B_c` визначається як таке значення частотного інтервалу `Δf = B_c`, при якому модуль коефіцієнта частотної кореляції падає до визначеного інженерного порогу `C` (де у практиці обирають `C = 0.5` або `C = 0.9`):

```
|ρ_H(B_c)| = C
```

### 4. Виведення `B_c` для трьох класичних моделей PDP

Зв'язок між середньоквадратичним розкидом `σ_τ` та смугою когерентності `B_c` залежить від аналітичної форми функції профілю `P(τ)`. Нижче наведено детальні розрахунки для трьох найпоширеніших фізичних моделей каналу.

#### Модель А: Експоненційний PDP (Indoor / Urban Macro)
У реальних міських середовищах та закритих приміщеннях кількість відбиваючих об'єктів зростає зі збільшенням радіуса, але потужність відбитого променя спадає експоненційно з відстанню. Це описується неперервною експоненційною функцією:

```
P(τ) = (1 / σ_τ) · exp(-τ / σ_τ),   при τ ≥ 0
```

Обчислимо пряме перетворення Фур'є для даного профілю:

```
R_H(Δf) = ∫₀^∞ (1 / σ_τ) · exp(-τ / σ_τ) · exp(-j · 2π · Δf · τ) dτ
        = (1 / σ_τ) · ∫₀^∞ exp(-τ · (1/σ_τ + j · 2π · Δf)) dτ
        = (1 / σ_τ) · [ -exp(-τ · (1/σ_τ + j · 2π · Δf)) / (1/σ_τ + j · 2π · Δf) ]₀^∞
        = 1 / (1 + j · 2π · Δf · σ_τ)
```

Вам модуль нормованого коефіцієнта частотної кореляції дорівнює:

```
|ρ_H(Δf)| = 1 / √[ 1 + (2π · Δf · σ_τ)² ]
```

##### 1. Поріг кореляції 50% (C = 0.5)
Знайдемо частотний інтервал `B_c`, при якому кореляція падає вдвічі:

```
1 / √[ 1 + (2π · B_c · σ_τ)² ] = 0.5   ⇒   1 + (2π · B_c · σ_τ)² = 4
(2π · B_c · σ_τ)² = 3   ⇒   2π · B_c · σ_τ = √3 ≈ 1.73205
B_c = √3 / (2π · σ_τ) ≈ 1 / (3.627 · σ_τ)
```

Для практичних інженерних розрахунків при порогові 0.5 використовують загальноприйняте наближення:

```
B_c (50%) ≈ 1 / (5 · σ_τ)
```

##### 2. Поріг кореляції 90% (C = 0.9)
Знайдемо частотний інтервал `B_c`, при якому кореляція зберігається на високому рівні 90%:

```
1 / √[ 1 + (2π · B_c · σ_τ)² ] = 0.9   ⇒   1 + (2π · B_c · σ_τ)² = 1 / 0.81 ≈ 1.23457
(2π · B_c · σ_τ)² ≈ 0.23457   ⇒   2π · B_c · σ_τ ≈ 0.48432
B_c = 0.48432 / (2π · σ_τ) ≈ 1 / (12.973 · σ_τ)
```

У суворих стандартах радіозв'язку (GSM, LTE) для 90% кореляції береться консервативна оцінка:

```
B_c (90%) ≈ 1 / (50 · σ_τ)
```

---

#### Модель Б: Прямокутний (рівномірний) PDP
У штучних каналах або обмежених хвилеводах енергія відбивань розподілена рівномірно від `0` до `T_max`:

```
P(τ) = 1 / T_max,   при 0 ≤ τ ≤ T_max
```

Обчислимо моменти цього розподілу:
- Середня затримка: `τ̄ = T_max / 2`
- Другий початковий момент: `τ²_bar = T_max² / 3`
- Дисперсія: `σ_τ² = T_max² / 3 - (T_max / 2)² = T_max² / 12`
- RMS delay spread: `σ_τ = T_max / (2·√3) ≈ 0.2887 · T_max`

Перетворення Фур'є рівномірного прямокутника дає стандартну функцію sinc:

```
R_H(Δf) = (1 / T_max) · ∫₀^{T_max} exp(-j · 2π · Δf · τ) dτ
        = exp(-j · π · Δf · T_max) · sinc(π · Δf · T_max)
```

Модуль кореляції виражається як `|ρ_H(Δf)| = |sinc(π · Δf · T_max)|`.

Розклавши функцію sinc у ряд Тейлора `sinc(x) ≈ 1 - x²/6` при малих `x`, для порогу кореляції `C = 0.5` маємо:

```
π · B_c · T_max ≈ 1.8954   ⇒   B_c ≈ 1.8954 / (π · 2·√3 · σ_τ) ≈ 1 / (5.74 · σ_τ)
```

---

#### Модель В: Двопроменевий PDP (Two-Ray Model)
Найпростіша модель реального інтерферуючого каналу з двох однакових за потужністю променів:

```
P(τ) = 0.5 · δ(τ) + 0.5 · δ(τ - τ₀)
```

Обчислимо моменти цього дискретного розподілу:
- Повна потужність: `P_total = 0.5 + 0.5 = 1.0`
- Середня затримка: `τ̄ = (0.5 · 0 + 0.5 · τ₀) / 1.0 = τ₀ / 2`
- Другий момент: `τ²_bar = (0.5 · 0² + 0.5 · τ₀²) / 1.0 = τ₀² / 2`
- RMS delay spread: `σ_τ = √[ τ₀² / 2 - (τ₀ / 2)² ] = √[ τ₀² / 4 ] = τ₀ / 2`

Автокореляційна функція за частотою стає чистою косинусоїдою:

```
R_H(Δf) = 0.5 + 0.5 · exp(-j · 2π · Δf · τ₀)
|ρ_H(Δf)| = |cos(π · Δf · τ₀)| = |cos(2π · Δf · σ_τ)|
```

Рівняння для знаходження смуги когерентності `B_c` при порогові `0.5`:

```
cos(2π · B_c · σ_τ) = 0.5   ⇒   2π · B_c · σ_τ = π / 3   ⇒   B_c = 1 / (6 · σ_τ)
```

Порівняння трьох моделей показує, що для будь-якої фізичної форми профілю PDP смуга когерентності перебуває в межах `B_c (50%) = (1 / 3.6 ... 1 / 6.0) / σ_τ`. Практичне інженерне правило `B_c ≈ 1 / (5 · σ_τ)` ідеально описує середину цього інтервалу.

### 5. Оцінка порогу помилок (BER Floor) через ISI

Розглянемо передачу двопозиційного сигналу BPSK зі швидкістю `R_s = 1 / T_s` через частотно-селективний канал із затримкою `σ_τ`.

Міжсимвольна інтерференція додає до поточного відліку дисперсію завади `σ_ISI²`, яка пропорційна енергії сигналу `E_s` та відношенню `(σ_τ / T_s)²`:

```
σ_ISI² ≈ E_s · (σ_τ / T_s)²
```

Підсумкове відношення сигналу до шуму з урахуванням AWGN-шуму `N₀` та завади ISI становить:

```
SINR = E_s / (N₀ + σ_ISI²) = (E_s / N₀) / [ 1 + (E_s / N₀) · (σ_τ / T_s)² ]
```

При безмежному зростанні потужності передавача (`E_s / N₀ → ∞`) відношення SINR впирається в абсолютне фізичне насичення:

```
SINR_max = (T_s / σ_τ)²
```

Відповідно, поріг ймовірності помилки BPSK (BER floor) становить:

```
BER_floor = Q(√[ 2 · SINR_max ]) = Q(√2 · T_s / σ_τ)
```

де `Q(x)` — Q-функція помилок Гаусса. Якщо `T_s < 3 · σ_τ`, поріг `BER_floor` перевищує `10⁻²`, що робить прийом даних неможливим без еквалайзера чи циклічного префіксу.

### 6. Покроковий приклад аналітичного розрахунку

Нехай виміряний трипроменевий профіль PDP має наступні значення:

```
Промінь 1: τ₁ = 0 нс,    P₁ = 1.0 (linear)   [прямий промінь LOS]
Промінь 2: τ₂ = 100 нс,  P₂ = 0.5 (linear)   [відбиття від підлоги]
Промінь 3: τ₃ = 300 нс,  P₃ = 0.1 (linear)   [відбиття від стіни]
```

#### Крок 1. Повна потужність
```
P_total = 1.0 + 0.5 + 0.1 = 1.6   [додавання лінійних потужностей променів]
```

#### Крок 2. Середня затримка τ̄
```
τ̄ = (1.0 · 0 + 0.5 · 100 + 0.1 · 300) / 1.6   [взважена сума за затримками променів]
   = (0 + 50 + 30) / 1.6                         [обчислення чисельника]
   = 80 / 1.6 = 50 нс                            [ділення на сумарну потужність P_total]
```

#### Крок 3. Другий початковий момент τ²_bar
```
τ²_bar = (1.0 · 0² + 0.5 · 100² + 0.1 · 300²) / 1.6   [взважена сума квадратів затримок]
       = (0 + 5000 + 9000) / 1.6                        [обчислення квадратів та добутків]
       = 14000 / 1.6 = 8750 нс²                         [ділення на сумарну потужність P_total]
```

#### Крок 4. Обчислення RMS delay spread σ_τ
```
σ_τ = √[ 8750 - 50² ]                      [різниця другого початкового і квадрата першого моменту]
    = √[ 8750 - 2500 ] = √6250             [обчислення дисперсії]
    ≈ 79.057 нс                            [вилучення квадратного кореня]
```

#### Крок 5. Розрахунок смуг когерентності
```
B_c (50%) ≈ 1 / (5 · 79.057 · 10⁻⁹ с) ≈ 2.53 МГц   [оцінка смуги за порогом 0.5]
B_c (90%) ≈ 1 / (50 · 79.057 · 10⁻⁹ с) ≈ 253 кГц   [оцінка смуги за порогом 0.9]
```

Висновок: Сигнал із шириною смуги `B_s = 100 кГц` зазнаватиме плоского завмирання, тоді як широкосмуговий сигнал `B_s = 20 МГц` виявить глибоку частотну селективність і потребуватиме еквалайзера або OFDM.
