# 🧮 Плазмова частота та математика заломлення в іоносфері

Ця вставка містить точний математичний вивід фундаментальних законів іоносферного поширення: плазмової частоти електронного газу `f_p`, коефіцієнта заломлення розрідженої плазми `n`, закону секанса для максимуму придатної частоти (`MUF`), згасання при зіткненнях електронів, інтеграла діючої висоти відбиття, диференціального рівняння Ейконала для геометрії променів, інтегрування затримки Чапмена, аналізу гіромагнітного розщеплення, ефекту Фарадея, фазового шляху та магнітоактивного середовища Землі (теорія Епплтона-Гартрі).

---

### 1. Рівняння руху електрона та коефіцієнт заломлення плазми

Розглянемо вираз для розрідженого іонізованого газу (холодної плазми), що містить `N_e` вільних електронів на один кубічний метр. Нехай на плазму діє електричне поле плоскої монохроматичної радіохвилі частотою `f` (кутова частота `ω = 2·π·f`):

```
E(t) = E₀ · cos(ω·t)
```

Маса іона (протона чи ядра кисню/азоту) перевищує масу електрона більш ніж у 1800 разів, тому зміщенням важких позитивних іонів під дією електричного поля радіохвилі можна знехтувати. Рівняння руху вільного електрона масою `m_e` та зарядом `-e` під дією сили Лоренца без урахування зіткнень з нейтральними частинками має вигляд:

```
m_e · (d²x / dt²) = -e · E(t)
```

Інтегруючи це рівняння по часу `t`, отримуємо швидкість зміщення електрона `v(t)` та його просторову координату `x(t)`:

```
v(t) = -(e / (m_e · ω)) · E₀ · sin(ω·t)
x(t) = (e / (m_e · ω²)) · E₀ · cos(ω·t)
```

Зміщення зарядів створює густину струму провідності в плазмі `J(t) = -e · N_e · v(t)`:

```
J(t) = ((N_e · e²) / (m_e · ω)) · E₀ · sin(ω·t)
```

Вставимо отриману густину струму у друге рівняння Максвелла для ротора магнітного поля `∇ × H = J + ε₀ · (∂E / ∂t)`:

```
J + ε₀ · (∂E / ∂t)
= ((N_e · e²) / (m_e · ω)) · E₀ · sin(ω·t) - ε₀ · ω · E₀ · sin(ω·t)   [підставили струм J(t) та похідну ∂E/∂t]
= -ε₀ · ω · (1 - (N_e · e²) / (ε₀ · m_e · ω²)) · E₀ · sin(ω·t)      [винесли спільний множник -ε₀·ω·E₀·sin(ω·t)]
```

Величину в дужках називають відносною діелектричною проникністю плазми `ε_r`. Вона виражається через фундаментальні константи та концентрацію електронів:

```
ε_r = 1 - (N_e · e²) / (ε₀ · m_e · ω²)
```

### 2. Вивід плазмової частоти та числові значення

Введемо визначення **кутової плазмової частоти** `ω_p` як власної частоти поздовжніх коливань електронного газу відносно важкого іонного остова:

```
ω_p² = (N_e · e²) / (ε₀ · m_e)
```

Тоді плазмова частота `f_p` у герцах становить:

```
f_p = ω_p / (2·π) = (1 / (2·π)) · √((N_e · e²) / (ε₀ · m_e))
```

Підставимо у формулу точні значення фізичних констант:
- Заряд електрона `e = 1.602176 × 10⁻¹⁹ Кл`
- Маса електрона `m_e = 9.109383 × 10⁻³¹ кг`
- Електрична стала `ε₀ = 8.854187 × 10⁻¹² Ф/м`

Обчислюємо коефіцієнт під коренем:

```
(e² / (4 · π² · ε₀ · m_e))
= (1.602176·10⁻¹⁹)² / (4 · 3.14159² · 8.854187·10⁻¹² · 9.109383·10⁻³¹)  [підставили чисельні константи]
≈ 80.616  [м³/с²]                                                      [обчислили добуток і частку]
```

Отримуємо практичні формули плазмової частоти та діелектричної проникності:

```
f_p ≈ √(80.62 · N_e) ≈ 8.98 · √(N_e)     [Гц, де N_e у ел/м³]

ε_r = 1 - (f_p / f)² = 1 - (80.62 · N_e / f²)
```

Коефіцієнт заломлення плазми `n` дорівнює квадратному кореню з діелектричної проникності `n = √(ε_r)`:

```
n = √(1 - (f_p / f)²) = √(1 - 80.62 · N_e / f²)
```

**Важливий фізичний висновок:** Для будь-якої радіохвилі з частотою `f > f_p` коефіцієнт заломлення плазми `n < 1`. Чим вища електронна густина `N_e`, тим менший коефіцієнт заломлення `n`. Оскільки у звичайній атмосфері `n ≈ 1.0003`, потрапляння хвилі в іоносферу є переходом із середовища з більшим `n` у середовище з меншим `n`.

### 3. Фазова та групова швидкість радіохвилі у плазмі

Оскільки коефіцієнт заломлення плазми `n < 1`, фазова швидкість поширення хвильового фронту `v_ph = c / n` виявляється **більшою за швидкість світла у вакуумі**:

```
v_ph = c / √(1 - (f_p / f)²) > c
```

Це не суперечить спеціальній теорії відносності, оскільки фазова швидкість визначає лише рух математичної точки постійної фази монохроматичної хвилі і не здатна переносити інформацію чи енергію. Енергія та сигнал переносяться з **груповою швидкістю** `v_g`, яка визначається формулою Релея:

```
v_g = dω / dk = c · n = c · √(1 - (f_p / f)²) < c
```

Добуток фазової та групової швидкостей в іоносферній плазмі завжди дорівнює квадрату швидкості світла:

```
v_ph · v_g = (c / n) · (c · n) = c²
```

У точці відбиття, де `n → 0`, фазова швидкість прямує до нескінченності `v_ph → ∞`, а групова швидкість згасає до нуля `v_g → 0`. Сигнал зупиняється на висоті відбиття й розвертається назад.

### 4. Діюча висота відбиття (Інтеграл групи)

Оскільки групова швидкість радіоімпульсу в іоносфері `v_g(z) = c · n(z)` падає в міру наближення до точки відбиття, виміряний іонозондом час затримки імпульсу `Δt` виявляється більшим за час проходження тієї ж відстані у вакуумі.

Діюча (віртуальна) висота відбиття `h'`, яку вимірює іонозонд, визначається як інтеграл від сповільненої групової швидкості уздовж реального шляху `z`:

```
h'(f) = ∫ [0 .. z_reflection] (dz / n(z, f)) = ∫ [0 .. z_reflection] (dz / √(1 - (f_p(z) / f)²))
```

Оскільки в усій області підйому `n(z, f) < 1`, діюча висота відбиття `h'` завжди **більша за справжню фізичну висоту** відбиття `z_reflection`:

```
h'(f) > z_reflection
```

Коли частота імпульсу наближається до критичної частоти шару (`f → f_c`), коефіцієнт заломлення у вершині траєкторії прямує до нуля (`n → 0`), а інтеграл затримки прямує до логарифмічної нескінченності (`h' → ∞`). На іонограмі це явище спостерігається як характерне вертикальне злітання кривої затримки (слід асимптоти критичної частоти).

### 5. Аналітичне інтегрування затримки для параболічного шару

Для практичних обчислень профіль електронної густини шару іоносфери поблизу максимуму часто апроксимують параболічною моделлю:

```
N_e(z) = N_max · (1 - ((z - z_m) / y_m)²)
```

де `z_m` — реальна висота максимуму іонізації, а `y_m` — півтовщина шару.

Підставивши параболічний профіль в інтеграл групового шляху `h'(f)`, отримуємо точний аналітичний вираз діючої висоти:

```
h'(f) = z_b + (y_m / 2) · (f / f_c) · ln((f_c + f) / (f_c - f))
```

де `z_b = z_m - y_m` — висота нижньої межі шару. 

Ця формула чітко показує логарифмічну особливість: при `f → f_c` аргумент логарифма `(f_c + f) / (f_c - f) → ∞`, що дає нескінченну діючу затримку сигнального імпульсу ідеального монохроматичного передавача.

### 6. Поглинання хвилі при зіткненнях електронів (Шар D)

У щільних нижніх шарах іоносфери (шар D, 60–90 км) необхідно враховувати зіткнення електронів з нейтральними молекулами азоту й кисню. Введемо еффективну частоту зіткнень `ν` (кількість зіткнень за секунду). Рівняння руху набуває вигляду:

```
m_e · (dv / dt) + m_e · ν · v = -e · E(t)
```

Комплексна діелектрична проникність плазми з урахуванням зіткнень стає комплексною величиною `ε_complex = (n - i·κ)²`:

```
ε_complex = 1 - (ω_p² / (ω · (ω - i·ν))) = 1 - (ω_p² / (ω² + ν²)) - i · ((ω_p² · ν) / (ω · (ω² + ν²)))
```

Уявна частина `κ` відповідає за згасання амплітуди хвилі за законом `E(z) = E₀ · exp(-α · z)`. Для високочастотних хвиль (`ω² >> ν²`) коефіцієнт поглинання `α` становить:

```
α ≈ (e² · N_e · ν) / (2 · m_e · ε₀ · c · (ω² + ν²))     [Непер/м]
```

У децибелах на кілометр загасання виражається як:

```
A_dB/km ≈ 8.686 · 10³ · α ≈ (1.15 · 10⁻⁴ · N_e · ν) / (f² + 0.025 · ν²)     [дБ/км]
```

Формула чітко пояснює фізику шару D:
1. **Загасання прямо пропорційне добутку `N_e · ν`:** У шарі D частота зіткнень `ν ≈ 10⁷ Гц` величезна, тому навіть при невеликій електронній густині `N_e ≈ 10⁹ ел/м³` поглинання стає визначальним.
2. **Загасання падає як `1 / f²`:** Нижні частоти (1.8–3.5 МГц) поглинаються вдень майже повністю, а високі частоти (14–28 МГц) проходять крізь шар D із мінімальними втратами.

### 7. Модель Чапмена та математика профілю іонізації

Вертикальний розподіл електронної густини `N_e(z)` в іоносферному шарі визначається рівнянням Чапмена, яке описує баланс між іонізацією сонячним потоком та об'ємною рекомбінацією:

```
N_e(z, χ) = N_max0 · √(cos χ) · exp(0.5 · (1 - z' - sec χ · exp(-z')))
```

де значення параметрів дорівнюють:
- `N_max0` — максимальна електронна густина при зенітному положенні Сонця (`χ = 0°`);
- `χ` — кут зеніту Сонця (кут між нормаллю та напрямком на Сонце);
- `z' = (z - z_0) / H_s` — безрозмірна нормована висота відносно максимуму іонізації `z_0`;
- `H_s = (k_B · T) / (m_avg · g)` — висота однорідної атмосфери (шкала висоти).

З цієї моделі випливає важливий математичний висновок: критична частота шару Чапмена залежить від кута нахилу сонячних променів як корінь четвертого ступеня:

```
f_c(χ) = f_c0 · (cos χ)^(1/4)
```

Це пояснює, чому критична частота досягає максимуму в місцевий полудень (`χ → 0`, `cos χ → 1`) та монотонно падає до заходу Сонця.

### 8. Рівняння Ейконала та трасування променів у неоднорідній іоносфері

У реальній іоносфері електронна густина `N_e(r)` змінюється не лише з висотою `z`, а й уздовж горизонтальних координат (градієнти день/ніч, полярні дуги). Для обчислення траєкторії променя у тривимірному неоднорідному середовищі використовують наближення геометричної оптики (рівняння Ейконала):

```
(∇S)² = n²(r)
```

де `S(r)` — оптична довжина шляху (ейконал). Диференціальне рівняння траєкторії променя у векторі радіус-вектора `r(s)` уздовж дуги променя `s` має вигляд:

```
(d / ds) (n · (dr / ds)) = ∇n
```

Розкладаючи це векторне рівняння на сферичні компоненти у геоцентричній системі координат `(r, θ, φ)`, отримують систему шести диференціальних рівнянь Гамільтона для трасування променів (Ray Tracing). Сучасні обчислювальні комплекси (наприклад, алгоритм Газельгрова) інтегрують ці рівняння числово для побудови реальних точних траєкторій коротких хвиль крізь тривимірні карти іоносфери.

### 9. Крос-модуляція та нелінійні ефекти (Люксембурзький ефект)

При дуже високих потужностях передавача (понад сотні кіловат у діапазоні довгих чи середніх хвиль) поширення радіохвиль в іоносфері втрачає лінійність. 

Електричне поле потужної хвилі передає вільним електронам шару D стільки кінетичної енергії, що ефективна температура електронного газу `T_e` помітно зростає вище температури нейтральних молекул `T_0`. Оскільки частота зіткнень залежить від температури `ν(T_e) ∝ √(T_e)`, потужна хвиля починає періодично змінювати частоту зіткнень у шарі D з частотою своєї амплітудної модуляції.

Якщо крізь цю ж область іоносфери проходить друга, слабша радіохвиля від іншої станції, її поглинання модулюється частотою першої станції. На приймачі слухач чує накладення звукової програми потужної станції на частоту слабкої — цей ефект уперше виявлено у 1933 році й названо **Люксембурзько-Горьківським ефектом cross-modulation**.

### 10. Залежність гіромагнітної частоти та обертання Фарадея

Електрон, що рухається у геомагнітному полі `B₀`, описує кругову траєкторію з циклотронною (гіромагнітною) частотою:

```
f_H = (e · B₀) / (2 · π · m_e)
```

Підставивши значення модуля геомагнітної індукції для середніх широт (`B₀ ≈ 50 мкТл = 5 · 10⁻⁵ Тл`):

```
f_H = (1.60218·10⁻¹⁹ · 5·10⁻⁵) / (2 · 3.14159 · 9.10938·10⁻³¹) ≈ 1.40 · 10⁶ Гц = 1.40 МГц
```

Кут обертання площини поляризації Фарадея `Ω` для квазіпоздовжнього поширення виражається інтегралом від вздовж променя `s`:

```
Ω = (e³ / (2 · π · m_e² · c² · ε₀ · f²)) · ∫ [0 .. S] (N_e(s) · B₀ · cos Θ · ds)
```

Математично кут обертання `Ω` прямо пропорційний Повному електронному вмісту (**TEC** = `∫ N_e ds`) та обернено пропорційний квадрату частоти `1 / f²`.

### 11. Обчислення фазового шляху та модель IRI

Крім діючого (групового) шляху `h'`, у фазових вимірюваннях використовують **фазовий шлях** `S_ph`, який задає кількість фазових циклів уздовж траєкторії променя:

```
S_ph = ∫ [0 .. S] n(s) ds = ∫ [0 .. S] √(1 - (f_p(s) / f)²) ds
```

Оскільки в іоносфері `n < 1`, фазовий шлях завжди **менший за геодезичну довжину траєкторії**:

```
S_ph < S_geom < h'
```

Для числового розрахунку `S_ph` та `h'` сучасна геофізика спирається на Міжнародну модель іоносфери (**IRI** — International Reference Ionosphere). Модель IRI виражає профіль `N_e(z, lat, lon, month, R_12)` через суму аналітичних Epstein-функцій, що дозволяє виконувати чисельне інтегрування фази та затримки з високою точністю для довільної точки земної кулі.

### 12. Критична частота при зенітному падінні

При вертикальному зондуванні (промінь спрямований прямо у зеніт, кут падіння `θ_i = 0°`) закон Снеліуса вимагає:

```
n(z) · sin(θ(z)) = n₀ · sin(0°) = 0
```

Це означає, що траєкторія променя залишається строго вертикальною, поки `n > 0`. Промінь піднімається на більшу висоту, де `N_e` зростає, а `n` падає. У точці, де `n` звертається в нуль (`n = 0`), хвиля повністю відбивається назад до Землі.

З умови `n = 0` маємо `f = f_p`. Якщо частота хвилі перевищує найвищу плазмову частоту шару `f > f_p(max)`, коефіцієнт заломлення `n` ніде не звертається в нуль, і хвиля пробиває шар наскрізь.

**Критична частота** `f_c` — це максимальна частота радіохвилі, яка відбивається іоносферою при зенітному падінні:

```
f_c = f_p(max) ≈ 8.98 · √(N_max)     [Гц]
```

Якщо `N_max = 1.2 · 10¹² ел/м³` (типове значення для шару F2 вдень):

```
f_c = 8.98 · √(1.2 · 10¹²) = 8.98 · 1.095 · 10⁶ Гц ≈ 9.84 МГц
```

### 13. Вивід Закону секанса та максимуму придатної частоти (MUF)

Розглянемо похиле падіння радіохвилі під кутом `θ_i` до вертикалі (нормалі шару). Згідно із законом Снеліуса для плавно-неоднорідного середовища:

```
n(z) · sin(θ(z)) = n₀ · sin(θ_i)
```

Оскільки на вході в іоносферу (нижня межа) `n₀ ≈ 1`, інваріант закону Снеліуса дорівнює `sin(θ_i)`:

```
n(z) · sin(θ(z)) = sin(θ_i)
```

У найвищій точці відбиття (вершині траєкторії `z_top`) промінь рухається горизонтально, тобто кут між променем і вертикаллю становить `θ(z_top) = 90°`, звідки `sin(90°) = 1`.

Умова відбиття похилого променя на вершині траєкторії:

```
n(z_top) = sin(θ_i)
```

Підставимо формулу коефіцієнта заломлення `n(z_top) = √(1 - (f_c / f)²)`, де `f_c` — критична частота шару:

```
√(1 - (f_c / f)²) = sin(θ_i)              [умова відбиття на вершині траєкторії]
⇒ 1 - (f_c / f)² = sin²(θ_i)              [піднесли обидві частини до квадрата]
⇒ (f_c / f)² = 1 - sin²(θ_i)              [перенесли доданки]
⇒ (f_c / f)² = cos²(θ_i)                  [тригонометрична тотожність: 1 - sin²θ = cos²θ]
⇒ f_c / f = cos(θ_i)                      [добули квадратний корінь з обох частин]
⇒ f = f_c / cos(θ_i)                      [виразили робочу частоту f]
⇒ f = f_c · sec(θ_i)                      [визначення секанса: sec(θ) = 1 / cos(θ)]
```

Отримана формула є **Законом секанса**. Вона задає **Максимум придатної частоти** (Maximum Usable Frequency, MUF) для траси з кутом падіння `θ_i`:

```
MUF = f_c · sec(θ_i)
```

### 14. Сферична геометрія та магнітоактивне розщеплення (Епплтон-Гартрі)

Для однострибкової лінії зв'язку на сферичній Землі радіуса `R_E = 6371 км` з висотою відбивального шару `h` та відстані між передавачем і приймачем `D` ефективний кут падіння модифікується геометрією:

```
sin(θ_sph) = sin(D / (2 · R_E)) / √(1 + (h / R_E)² - 2 · (h / R_E) · cos(D / (2 · R_E)))
MUF = f_c · sec(θ_sph) = f_c · k_sph
```

Множник `k_sph` називають `MUF-фактором`. Для дальніх трас (`D ≈ 3000–4000 км`) через шар F2 (`h ≈ 300 км`) граничне значення `MUF-фактора` досягає `3.3–3.5`.

При наявності магнітного поля Землі `B₀` повний коефіцієнт заломлення описується рівнянням Епплтона-Гартрі:

```
n² = 1 - (2 · X · (1 - X - i·Y_L)) / (2 · (1 - X - i·Y_L) - Y_T² ± √(Y_T⁴ + 4 · Y_L² · (1 - X - i·Y_L)²))
```

де безрозмірні параметри дорівнюють:
- `X = (f_p / f)²` — відношення плазмової частоти до частоти хвилі;
- `Y = f_H / f` — відношення гіромагнітної частоти `f_H = (e · B₀) / (2·π·m_e) ≈ 1.4 МГц` до частоти хвилі;
- `Y_L = Y · cos(Θ)` та `Y_T = Y · sin(Θ)` — поздовжня та поперечна компоненти гірочастоти відносно напрямку поширення хвилі.

Знак «±» під коренем відповідає розщепленню хвилі на **звичайну** («+», O-wave) та **незвичайну** («−», X-wave) компоненти. Критична частота незвичайної хвилі перевищує критичну частоту звичайної хвилі:

```
f_cX ≈ f_cO + f_H / 2 ≈ f_cO + 0.7 МГц
```

Це явище викликає роздвоєння сигнальних треків на іонограмах та поляризаційні завмирання при додаванні двох компонент у приймальній антені.
