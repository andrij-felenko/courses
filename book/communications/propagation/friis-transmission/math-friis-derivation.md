# 🧮 Виведення рівняння Фріїса та ефективна апертура

Ця вставка містить суворе математичне виведення рівняння передачі Фріїса на основі рівнянь Максвелла, вектора Пойнтінга, теореми взаємності та концепції ефективної апертури, а також повний математичний вивід межі дальньої зони (критерію Фраунгофера) через розклад фазової помилки в ряд Тейлора.

### 1. Електродинамічна основа: від векторного потенціалу до вектора Пойнтінга

Електромагнітне випромінювання довільної антени описується системою рівнянь Максвелла. Розглянемо випромінювання елементарного змінного струму — елементарного диполя Герца довжиною `l ≪ λ` із струмом `I(t) = I_0 · cos(ω·t)`.

Згідно з рівняннями електродинаміки, запізнювальний векторний потенціал `A` на відстані `r` від струму дорівнює:

```
A(r, t) = ( μ / (4 · π · r) ) · ∫ J(r', t − r/c) dV      [запізнювальний потенціал]
```

У дальній зоні (де відстань `r` значно більша за довжину хвилі `r ≫ λ`) радіальні компоненти полів згасають як `1/r²` і `1/r³`, тож ними можна знехтувати. Залишаються лише поперечні компоненти електричного поля `E_θ` та магнітного поля `H_φ`, які згасають як `1/r` і перебувають у фазі:

```
E_θ = j · ( (I_0 · l · ω · μ) / (4 · π · r) ) · sin(θ) · exp(−j·k·r)      [електричне поле]
H_φ = E_θ / η_0                                                           [магнітне поле]
```

де `k = 2·π / λ` — хвильове число, `θ` — зенітний кут від осі диполя, а `η_0 = √(μ_0 / ε_0) ≈ 120·π ≈ 377 Ом` — імпеданс вільного простору (хвильовий опір вакууму).

Миттєва густина потоку електромагнітної енергії визначається вектором Пойнтінга `S_vec = E × H`. Середнє за часом значення модуля вектора Пойнтінга (густина потужності випромінювання у Вт/м²) дорівнює:

```
S = (1 / 2) · Re( E_θ · H_φ* ) 
  = |E_θ|² / (2 · η_0)      [середній вектор Пойнтінга]
```

### 2. Сферичне розходження та густина потужності ізотропного випромінювача

Проінтегруймо густину потужності `S` по всьому тілесному куту замкненої сфери радіуса `d`, щоб отримати повну випромінену потужність `P_t`:

```
P_t = ∬ S(d, θ, φ) · dA 
    = ∬ S(d, θ, φ) · d² · sin(θ) dθ dφ      [інтегрування по сфері]
```

Для ідеального ізотропного випромінювача густина потужності `S_0` є однаковою у всіх напрямках (`S(d, θ, φ) = S_0`). Оскільки площа сфери дорівнює `4·π·d²`, маємо:

```
P_t = S_0 · 4 · π · d²                      [інтеграл для ізотропного джерела]
S_0 = P_t / (4 · π · d²)                    [вираження густини потужності]
```

Це рівняння показує фундаментальний закон оберненого квадрата відстані: густина потужності падаючої хвилі падає пропорційно `1/d²` суто через геометричне розширення сферичного хвильового фронту.

### 3. Спрямованість, коефіцієнт корисної дії та підсилення антен

Реальна антена випромінює енергію нерівномірно. Коефіцієнт спрямованості (*directivity*) `D_a(θ, φ)` визначає співвідношення між густиною потужності у даному напрямку `S(d, θ, φ)` та середньою густиною потужності ізотропного випромінювача:

```
D_a(θ, φ) = S(d, θ, φ) / S_0 
          = S(d, θ, φ) / ( P_t / (4 · π · d²) )      [визначення спрямованості]
```

Оскільки реальні антени мають омічні втрати у провідниках та діелектриках, повна випромінена потужність дорівнює `P_рад = η_антени · P_t`, де `η_антени` — коефіцієнт корисної дії (ККД) антени (значення від 0 до 1).

Коефіцієнт підсилення антени `G(θ, φ)` (*antenna gain*) враховує як спрямованість, так і ККД антени:

```
G(θ, φ) = η_антени · D_a(θ, φ)                       [зв'язок підсилення та спрямованості]
```

Отже, у напрямку максимуму випромінювання передавальної антени з підсиленням `G_t`, точна густина потужності `S` на відстані `d` дорівнює:

```
S = (P_t · G_t) / (4 · π · d²)      [Вт/м²]
```

Добуток `P_t · G_t` є ефективною ізотропно випромінюваною потужністю (EIRP).

### 4. Виведення ефективної апертури ізотропного випромінювача

Приймальна антена перетворює потік падаючої хвилі густиною `S` на електричну потужність `P_r` у навантаженні. Ефективна апертура `A_e` визначається як співвідношення:

```
P_r = S · A_e      [Вт]
```

Знайдемо ефективну апертуру ідеальної ізотропної антени `A_e_iso`. Для цього скористаємося теоремою взаємності термодинамічної рівноваги (законом випромінювання Кірхгофа для чорного тіла).

Уявімо безпровідний простір, що перебуває у стані замкненої термодинамічної рівноваги за температури `T`. Розмістимо в ньому дві антени — ізотропну антену 1 та довільну антену 2, підключені до узгоджених навантажень опором `R`.

За законом Найквіста, тепловий шум генерує в кожному навантаженні потужність у смузі частот `Δf`:

```
P_шуму = k_B · T · Δf      [потужність шуму Найквіста]
```

де `k_B` — стала Больцмана.

За умов термодинамічної рівноваги потужність, яку випромінює антена 1 і приймає антена 2, має чітко дорівнювати потужності, яку випромінює антена 2 і приймає антена 1:

```
P_1→2 = P_2→1                                                          [баланс потужностей]
P_шуму · G_1 · ( A_e2 / (4 · π · d²) ) = P_шуму · G_2 · ( A_e1 / (4 · π · d²) )  [рівність потоків]
```

Скоротивши `P_шуму` та геометричний фактор `4·π·d²`, отримуємо фундаментальну пропорцію:

```
A_e1 / G_1 = A_e2 / G_2 = const                                        [універсальне відношення]
```

Оскільки для ізотропної антени підсилення за визначенням дорівнює одиниці (`G_iso = 1`), це універсальне відношення дорівнює ефективній апертурі ізотропного випромінювача `A_e_iso`.

Обчислимо `A_e_iso` через аналіз елементарного короткого диполя Герца без втрат. З теорії антен відомо, що коефіцієнт спрямованості диполя Герца дорівнює `D_диполя = 1.5`, а його опір випромінювання становить `R_рад = 80 · π² · (l / λ)²`. ЕРС, що наводиться у диполі падаючим полем `E`, дорівнює `V_ерс = E · l`.

Потужність у узгодженому навантаженні `R_L = R_рад` становить:

```
P_r = |V_ерс|² / (8 · R_рад) 
    = (E² · l²) / (8 · 80 · π² · (l / λ)²) 
    = (E² · λ²) / (640 · π²)                                           [потужність диполя]
```

Виразимо густину потужності падаючої хвилі через електричне поле `S = E² / (2 · η_0) = E² / (240 · π)`. Поділимо прийняту потужність `P_r` на густину `S`:

```
A_e_диполя = P_r / S 
           = ( (E² · λ²) / (640 · π²) ) / ( E² / (240 · π) ) 
           = (240 · π · λ²) / (640 · π²) 
           = 1.5 · λ² / (4 · π)                                        [апертура диполя]
```

Оскільки для диполя `G_диполя = 1.5`, маємо `A_e_диполя = G_диполя · A_e_iso`. Звідси отримуємо фундаментальну апертуру ізотропної антени:

```
A_e_iso = λ² / (4 · π)                                                [апертура ізотропної антени]
```

Звідси випливає фундаментальний зв'язок між діючою висотою антени `h_eff` та її ефективною апертурою `A_e`. Оскільки `P_r = (E · h_eff)² / (4 · R_рад)` та `S = E² / (2 · η_0)`, отримуємо вираз:

```
A_e = (η_0 / (4 · R_рад)) · h_eff²                                     [зв'язок апертури та висоти]
```

Отже, для довільної антени із коефіцієнтом підсилення `G_r` її ефективна апертура дорівнює:

```
A_e = G_r · λ² / (4 · π)      [м²]
```

### 5. Апертурна ефективність параболічних та рефлекторних антен

Для плоских та рефлекторних апертурних антен (параболічні дзеркала, рупорні антени, решітки патчів) ефективна апертура `A_e` пов'язана з фізичною геометрією апертури `A_фіз` через коефіцієнт використання апертури `η_ап`:

```
A_e = η_ап · A_фіз      [м²]
```

Апертурна ефективність `η_ап` розкладається на добуток кількох часткових коефіцієнтів:

```
η_ап = η_опром · η_розливу · η_фази · η_поляр                      [розклад ефективності]
```

де:
- `η_опром` (*illumination efficiency*) — коефіцієнт рівномірності амплітудного розподілу поля по дзеркалу (для спадного розподілу до країв `η_опром ≈ 0.8...0.9`).
- `η_розливу` (*spillover efficiency*) — частка потужності облучателя, яка потрапляє на дзеркало і не перелітає за його краї (`η_розливу ≈ 0.8...0.9`).
- `η_фази` (*phase efficiency*) — втрати через відхилення фазового фронту від ідеального параболоїда через точність виготовлення поверхні.
- `η_поляр` (*cross-polarization efficiency*) — втрати через наявність паразитних крос-поляризаційних компонент поля.

Для якісних параболічних антен сукупна ефективність `η_ап` становить `0.55...0.70` (55–70%). Підсилення параболічної антени діаметром `D` виражається як:

```
G = η_ап · (π · D / λ)²                                               [підсилення параболоїда]
```

### 6. Покроковий алгебраїчний вивід рівняння Фріїса

Тепер об'єднаємо всі отримані ланки в єдину систему.

```
P_r = S · A_e                                                      [визначення через густину та апертуру]
    = ( (P_t · G_t) / (4 · π · d²) ) · ( (G_r · λ²) / (4 · π) )      [підстановка виразів для S та A_e]
    = P_t · G_t · G_r · ( λ² / (16 · π² · d²) )                    [перемноження знаменників 4π·4π = 16π²]
    = P_t · G_t · G_r · ( λ / (4 · π · d) )²                       [винесення квадрата дробу]
```

Це і є канонічна лінійна форма **рівняння передачі Фріїса**:

```
P_r / P_t = G_t · G_r · ( λ / (4 · π · d) )²
```

Для параболічних апертурних антен із фізичними площами `A_t_фіз` та `A_r_фіз`, формула Фріїса набуває вигляду:

```
P_r / P_t = ( A_t_фіз · A_r_фіз · η_t · η_r ) / ( λ² · d² )
```

### 7. Децибельні коефіцієнти та логарифмічне перетворення

Прологарифмуємо лінійне рівняння Фріїса десятковим логарифмом та помножимо на 10:

```
10·log₁₀(P_r / 1 мВт) 
= 10·log₁₀(P_t / 1 мВт) + 10·log₁₀(G_t) + 10·log₁₀(G_r) + 20·log₁₀( λ / (4·π·d) )      [логарифмування добутку]
```

Позначивши `P_r(дБм) = 10·log₁₀(P_r / 1 мВт)`, `P_t(дБм) = 10·log₁₀(P_t / 1 мВт)`, `G_t(dBi) = 10·log₁₀(G_t)` та `G_r(dBi) = 10·log₁₀(G_r)`, маємо:

```
P_r(дБм) = P_t(дБм) + G_t(dBi) + G_r(dBi) − FSPL(дБ)
```

де втрати у вільному просторі виражаються через модуль:

```
FSPL(дБ) = 20·log₁₀( (4·π·d) / λ )
         = 20·log₁₀(d) + 20·log₁₀(f) + 20·log₁₀(4·π / c)             [розклад логарифма]
```

Підставивши швидкість світла `c ≈ 2.99792 × 10⁸ м/с`, обчислимо сталу:

```
20·log₁₀(4 · π / 2.99792×10⁸) = 20·log₁₀(4.19169 × 10⁻⁸) = −147.55 дБ
```

Якщо відстань `d` вимірювати у кілометрах (`d_км = d / 1000`), а частоту `f` у гігагерцах (`f_ГГц = f / 10⁹`), добавка становить:

```
−147.55 + 20·log₁₀(10³) + 20·log₁₀(10⁹) = −147.55 + 60 + 180 = +92.45 дБ
```

Отримуємо практичну інженерну формулу FSPL:

```
FSPL(дБ) = 20·log₁₀(d_км) + 20·log₁₀(f_ГГц) + 92.45
```

### 8. Математичний вивід межі дальньої зони (критерію Фраунгофера)

Рівняння Фріїса виведено в припущенні, що хвильовий фронт на приймальній антені є плоским. З'ясуємо математичні умови, за яких сферичний фронт від точкового випромінювача можна вважати плоским над апертурою розміром `D`.

Розглянемо круглу плоску апертуру приймача діаметром `D`, розташовану перпендикулярно до осі передавача на відстані `d`.

Відстань від передавача до центру апертури дорівнює `d`. Відстань до краю апертури `d_край` становить:

```
d_край = √( d² + (D / 2)² )                                         [теорема Піфагора]
       = d · √( 1 + (D / (2·d))² )                                  [винесення d за знак кореня]
```

Розкладемо вираз `√(1 + x)` у ряд Тейлора при `x = (D / (2·d))² ≪ 1`:

```
√(1 + x) = 1 + (1/2)·x − (1/8)·x² + ...                             [ряд Тейлора]
d_край ≈ d · ( 1 + (1/2)·(D² / (4·d²)) )
       = d + D² / (8·d)                                             [лінійне наближення]
```

Отже, різниця ходу хвилі між центром та краєм апертури `Δd` становить:

```
Δd = d_край − d = D² / (8·d)                                        [різниця відстаней]
```

Різниця ходу викликає зсув фази `Δφ` між сигналом у центрі та на краях апертури:

```
Δφ = k · Δd 
   = (2 · π / λ) · ( D² / (8 · d) ) 
   = (π · D²) / (4 · λ · d)                                         [обчислення фазової помилки]
```

У теорії антен максимальна припустима фазова помилка над апертурою, яка ще не спричиняє розфокусування променя та спаду підсилення (більше ніж на 0.2–0.5 дБ), становить **`Δφ_макс = π / 8` (22.5 градусів)**.

Встановимо обмеження `Δφ ≤ π / 8`:

```
(π · D²) / (4 · λ · d) ≤ π / 8                                      [критерій фазового допуску]
(D²) / (4 · λ · d) ≤ 1 / 8                                          [скорочення на π]
4 · λ · d ≥ 8 · D²                                                  [перемноження пропорції]
d ≥ (2 · D²) / λ                                                    [остаточна нерівність]
```

Ця мінімальна відстань `d_far = 2·D² / λ` і називається **відстанню Фраунгофера** (*Fraunhofer distance*). Рівняння Фріїса дає математично точний результат лише при виконанні нерівності `d ≥ d_far`.

### 9. Фактор поляризаційної неузгодженості та скалярний добуток векторів

У векторному формулюванні електродинаміки вектори електричного поля випромінюваної хвилі `E_t_vec` та приймальної антени `E_r_vec` визначають **фактор поляризаційних втрат** `PLF` (*Polarization Loss Factor*):

```
PLF = | e_t_vec · e_r_vec* |²                                      [скалярний добуток комплексних ортів]
```

де `e_t_vec` та `e_r_vec` — одиничні комплексні вектори (орти) поляризації хвилі та антени відповідно.

Для двох лінійно поляризованих хвиль, розвернутих на кут `ψ` у площині поперечного перерізу, скалярний добуток дає:

```
PLF = | cos(ψ) |² = cos²(ψ)                                         [закон Малюса для радіохвиль]
```

У децибелах втрати поляризації становлять `L_pol(дБ) = −10 · log₁₀( PLF )`. При `ψ = 0°` втрати дорівнюють 0 дБ, при `ψ = 45°` втрати становлять 3 дБ, а при `ψ = 90°` (ортогональна поляризація) `PLF = 0` (`L_pol → ∞`), що означає повну відсутність прийому сигналу.

### 10. Узагальнене матричне рівняння Фріїса для MIMO систем

У сучасних багатоантенних системах зв'язку MIMO (*Multiple-Input Multiple-Output*) передавач використовує `N_t` антен, а приймач — `N_r` антен. Рівняння Фріїса узагальнюється на матричний вираз для вектора прийнятих сигналів `y_vec`:

```
y_vec = H_mat · x_vec + n_vec                                       [матричний канал MIMO]
```

де `x_vec` — вектор випромінюваних комплексних амплітуд розмірності `N_t × 1`, `y_vec` — вектор прийнятих сигналів `N_r × 1`, `n_vec` — вектор аддитивного білого гаусового шуму, а `H_mat` — матриця каналу розмірності `N_r × N_t`.

Кожен елемент матриці каналу `H_ij` визначається за рівнянням Фріїса з урахуванням фазового набігу між `i`-ю приймальною та `j`-ю передавальною антенами:

```
H_ij = √( G_t_j · G_r_i ) · ( λ / (4·π·d_ij) ) · exp(−j · k · d_ij) [елемент матриці каналу]
```

де `d_ij` — відстань між `j`-м випромінювачем та `i`-м приймальним елементом. Сумарна пропускна здатність MIMO каналу обчислюється за теоремою Шеннона-Нойкаса через визначник матриці каналу.

### 11. Вплив першої зони Френеля на точність рівняння Фріїса

При поширенні електромагнітної хвилі вздовж радіолінії основна енергія хвильового потоку зосереджена всередині об'єму, який називається **першою зоною Френеля**. Це витягнутий еліпсоїд обертання з фокусами у точках розташування передавальної та приймальної антен.

Радіус першої зони Френеля `r_1` у довільній точці на відстані `d_1` від передавача та `d_2` від приймача (`d = d_1 + d_2`) обчислюється за формулою:

```
r_1 = √( (λ · d_1 · d_2) / d )                                      [радіус зони Френеля]
```

У середині траси (`d_1 = d_2 = d / 2`) радіус першої зони Френеля досягає свого максимуму:

```
r_1_макс = (1 / 2) · √( λ · d )                                     [максимальний радіус Френеля]
```

Якщо будь-яка матеріальна перешкода (вершина пагорба, будівля, лісовий масив) проникає всередину першої зони Френеля, виникають дифракційні втрати. Загальноприйнятим інженерним правилом є вимога **вільного просвіту не менше 60% від радіуса першої зони Френеля (`0.6 · r_1`)**.

Якщо просвіт становить `0.6 · r_1`, дифракційні втрати дорівнюють нулю, і прийнята потужність строго відповідає рівнянню Фріїса. Якщо ж перешкода перекриває лінію прямої видимості до вісі траси (`0%` просвіту), то дифракційні втрати на «гострому клині» становлять рівно **6 дБ** (потужність зменшується вчетверо порівняно з рівнянням Фріїса). При подальшому перекритті втрати стрімко зростають за законом дифракції Кірхгофа-Френеля.

### 12. Еквівалентна шумність та добротність антени G/T

У супутниковому зв'язку та радіоастрономії прийнята потужність корисного сигналу за Фріїсом порівнюється з еквівалентною шумною потужністю приймальної системи. Загальна шумність системи характеризується **еквівалентною шумно температурою системи** `T_сист` (у Кельвінах):

```
T_сист = T_антени + T_фіддера + T_мшп                                  [сумарна шумність]
```

де `T_антени` — шумність самої антени (що включає фонове випромінювання Землі та космосу), `T_фіддера` — тепловий шум втрат у фідерному тракті, а `T_мшп` — еквівалентна шумність малошумного підсилювача (LNA).

Параметром якості приймальної станції є **добротність антени `G/T`** (*Figure of Merit*), виражена у дБ/К:

```
(G / T)(дБ/К) = G_r(dBi) − 10·log₁₀( T_сист_К )                         [добротність G/T]
```

Використовуючи співвідношення `G/T`, рівняння Фріїса дозволяє безпосередньо обчислити підсумкове співвідношення потужності сигналу до спектральної густини шуму `C / N_0` на виході демодулятора:

```
(C / N_0)(дБ·Гц) = EIRP(дБм) − FSPL(дБ) + (G / T)(дБ/К) − 10·log₁₀(k_B) [рівняння C/N0]
```

де `10·log₁₀(k_B) = −228.6 дБ(Вт/(Гц·К))` — стала Больцмана у децибельній формі. Це рівняння є вищою формою запису рівняння Фріїса для космічних та супутникових мереж.

### 13. Особливості прийому хвиль із круговою поляризацією (RHCP/LHCP)

При використанні кругової поляризації (правильної RHCP або лівої LHCP) вектор електричного поля обертається з частотою сигналу. Якщо передавальна антена випромінює правополяризовану хвилю RHCP, а приймальна антена розрахована на ліву поляризацію LHCP, коефіцієнт поляризаційного узгодження дорівнює нулю (`PLF = 0`).

Для компенсації фарадеївського обертання поляризації в іоносфері Землі при зв'язку із супутниками LEO/GEO практично завжди застосовують саме кругову поляризацію. Співвідношення осей еліпса поляризації називається еліптичністю (*Axial Ratio*, AR). Якщо еліптичність антени становить `AR_дБ`, додаткові втрати неузгодженості визначаються як:

```
PLF_еліп = (1 / 2) · ( 1 + (2 · AR_t · AR_r) / (AR_t² + 1) / (AR_r² + 1) )  [поляризація еліпса]
```

Це дозволяє точно вираховувати втрати поляризаційного розсогласування у реальних космічних, супутникових та аеронавігаційних радіолініях. Таким чином, математичний апарат Фріїса об'єднує хвильову теорію полів з інженерним розрахунком енергетики радіолінії.
