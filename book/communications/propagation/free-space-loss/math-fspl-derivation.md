# 🧮 Звідки береться формула FSPL = (4π·d/λ)²

Стаття користується формулою втрат вільного простору FSPL = (4π·d/λ)² і децибельним правилом «+32.44» як готовими. Тут ми виводимо їх з нуля — від густини потужності на сфері до точної інженерної сталої, — щоб було видно, звідки береться і квадрат, і множник 20 у децибелах, і чому втрати ростуть із частотою.

### Крок 1. Густина потужності ізотропного джерела

Ізотропний передавач віддає потужність Pₜ рівномірно навсібіч. На відстані r уся ця потужність рівномірно розподілена по поверхні сфери площею 4πr². Густина потужності (потужність на одиницю площі):

```
S(r) = Pₜ / (4·π·r²)      [Вт/м²]
```

Це вже містить закон оберненого квадрата: r у знаменнику піднесене до квадрата, бо площа сфери росте як квадрат радіуса. Жодного поглинання тут немає — лише поділ сталої потужності на зростаючу площу.

### Крок 2. Ефективна апертура приймальної антени

Приймач вловлює не всю сферу, а потужність, що припадає на його **ефективну апертуру** Aₑ:

```
Pприйн = S(r) · Aₑ
```

Для ізотропної приймальної антени теорія антен (через принцип взаємності й термодинамічну рівновагу з тепловим випромінюванням) дає точний результат:

```
Aₑ = λ² / (4·π)
```

Цей вивід — предмет окремої теми [ефективна апертура антени](topic:communications/effective-aperture); тут беремо його як установлений факт. Важливий сам вигляд: апертура пропорційна λ², тобто **квадрату довжини хвилі**. Саме звідси в кінцеву формулу входить частота: коротша хвиля → менша λ² → менший «зачерп».

### Крок 3. Прийнята потужність і означення втрат

Підставляємо Aₑ у прийняту потужність:

```
Pприйн = S(r) · Aₑ = Pₜ/(4·π·r²) · λ²/(4·π)
```

Зберімо множники акуратно. У знаменнику (4·π·r²)·(4·π) = (4·π)²·r², а в чисельнику λ². Отже:

```
Pприйн = Pₜ · λ² / ( (4·π)² · r² ) = Pₜ · ( λ / (4·π·r) )²
```

Втрати вільного простору означують як відношення випроміненої потужності до прийнятої (у скільки разів ослаб сигнал між двома ізотропними антенами):

```
FSPL ≡ Pₜ / Pприйн = ( 4·π·r / λ )²
```

Замінивши λ = c/f (c — швидкість світла, f — частота), отримуємо форму через частоту:

```
FSPL = ( 4·π·r·f / c )²
```

Тепер обидві залежності явні: FSPL росте як квадрат відстані **й** як квадрат частоти.

### Крок 4. Перехід у децибели й точна стала

Децибели беруть 10·log₁₀ від відношення потужностей. Через квадрат це стає 20·log₁₀:

```
FSPL(дБ) = 10·log₁₀( (4·π·r·f/c)² ) = 20·log₁₀( 4·π·r·f / c )
```

Ось звідки множник **20**, а не 10, — прямий наслідок квадрата у формулі. Розкладімо логарифм добутку на суму:

```
FSPL(дБ) = 20·log₁₀(r) + 20·log₁₀(f) + 20·log₁₀(4·π/c)
```

Порахуймо останню сталу (r у метрах, f у герцах, c = 3·10⁸ м/с):

```
4·π / c   = 12.566 / (3·10⁸) = 4.189·10⁻⁸
log₁₀(4.189·10⁻⁸) = 0.622 − 8 = −7.378
20 · (−7.378) = −147.55
```

Отже, у чистих одиницях СІ:

```
FSPL(дБ) = 20·log₁₀(d[м]) + 20·log₁₀(f[Гц]) − 147.55
```

### Крок 5. Зручні інженерні форми

Числа −147.55, метри й герци незручні. Змінимо одиниці — стала поглине множники переведення. Перехід метри→кілометри піднімає сталу на 20·log₁₀(10³) = +60; герци→мегагерци — ще на 20·log₁₀(10⁶) = +120. Сумарно −147.55 + 60 + 120 = +32.44:

```
FSPL(дБ) = 20·log₁₀(d[км]) + 20·log₁₀(f[МГц]) + 32.44
```

Аналогічно для гігагерців (герци→ГГц дають +180):

```
FSPL(дБ) = 20·log₁₀(d[км]) + 20·log₁₀(f[ГГц]) + 92.45
FSPL(дБ) = 20·log₁₀(d[м])  + 20·log₁₀(f[ГГц]) + 32.45
```

Остання пара показує гарний збіг: перехід км→м знімає 60, а МГц→ГГц додає 60 — тож із метрами й гігагерцами стала знову ≈32.45. Це не магія, а просто взаємне скорочення множників.

### Крок 6. Повний робочий приклад

**Приклад (запас лінка на 100 м, 2.4 ГГц).** Візьмімо типове малопотужне радіо: передавач Pₜ = 14 dBm (25 мВт), антени по Gₜ = Gᵣ = 2 dBi, чутливість приймача −100 dBm. Порахуймо втрати, прийняту потужність і запас.

```
FSPL = 20·log₁₀(100) + 20·log₁₀(2.4) + 32.45      (метри + ГГц)
     = 40           + 7.60          + 32.45
     = 80.05 дБ

Pприйн = Pₜ + Gₜ + Gᵣ − FSPL                        (рівняння Фріїса в дБ)
       = 14 + 2  + 2  − 80.05
       = −62.05 dBm

Запас = Pприйн − чутливість
      = −62.05 − (−100)
      = 37.95 дБ
```

Висновок: на 100 метрах у чистому полі лишається ще майже 38 дБ запасу — купа. Але дальність коштує 20 дБ за кожні ×10: на 1 км FSPL уже ≈100 дБ, прийнята потужність падає до −82 dBm, і запас тане з 38 до ≈18 дБ. Ще десятикратно далі, на 10 км, FSPL ≈120 дБ, прийнята потужність −102 dBm — уже **нижче** чутливості −100 dBm, зв'язок обривається. Уся дальність цього лінка вклалася між сотнею метрів і кількома кілометрами — і межу поставила не потужність передавача, а закон оберненого квадрата.
