# 🧮 Математика багатокористувацької різноманітності та ємності OFDMA

Ортогональне частотне мультиплексування з множинним доступом (OFDMA) перетворює частотну вибірковість радіоканалу з руйнівного фактора на джерело додаткової пропускної здатності. Якщо для одного користувача глибоке завмирання на певних частотах означає втрату даних, то в системі з багатьма абонентами ймовірність того, що конкретна піднесна одночасно згасне для всіх, стрімко падає до нуля. Нижче наведено строгий математичний аналіз сумарної ємності OFDMA, виведення виграшу від багатокористувацької різноманітності через теорію порядкових статистик, алгоритм оптимізації водяного наповнення (water-filling) та кількісну оцінку деградації ортогональності через неузгодженість частот і часу.

## Сумарна шеннонівська ємність OFDMA-каналу

Розглянемо систему зв'язку з `K` незалежними абонентами та загальною смугою частот `B`, яка розбита на `N` ортогональних піднесних із кроком `Δf = B / N = 1 / T_s`, де `T_s` — корисна тривалість символу.

Позначимо через `h_{k,n}` комплексну передавальну характеристику радіоканалу між базовою станцією та `k`-м користувачем на `n`-й піднесній (`k ∈ {1, ..., K}`, `n ∈ {0, ..., N-1}`). Миттєве відношення сигнал/шум (SNR) для `k`-го користувача на `n`-й піднесній за умови виділення одиничної потужності становить:

```
γ_{k,n} = (|h_{k,n}|² · P_{k,n}) / (N₀ · Δf)
```

де `P_{k,n}` — потужність передавача, призначена `k`-му користувачу на `n`-й піднесній, а `N₀` — спектральна густина потужності адитивного білого гаусового шуму (AWGN).

У системі OFDMA кожна окрема піднесна в даний момент часу `t` може бути виділена тільки одному користувачеві (щоб уникнути внутрішньоканальної інтерференції). Введемо бінарну змінну призначення:

```
c_{k,n} ∈ {0, 1}
Σ_{k=1}^K c_{k,n} ≤ 1    [для кожного n ∈ {0, ..., N-1}]
```

За теоремою Шеннона сумарна пропускна здатність системи (сумарна ємність за всіма піднесними) визначається як:

```
C_OFDMA = Σ_{n=0}^{N-1} Σ_{k=1}^K c_{k,n} · Δf · log₂(1 + (P_{k,n} · |h_{k,n}|²) / (N₀ · Δf))
```

при обмеженні на загальну потужність передавача базової станції:

```
Σ_{n=0}^{N-1} Σ_{k=1}^K c_{k,n} · P_{k,n} ≤ P_total
```

## Виведення виграшу багатокористувацької різноманітності (Multiuser Diversity Gain)

Припустимо, що потужність розподіляється рівномірно між усіма піднесними (`P_{k,n} = P_total / N = P_sub`), а планувальник призначає кожну `n`-у піднесу тому абоненту, який має на ній максимальний коефіцієнт передачі каналу (опортуністичний шедулінг):

```
k^*(n) = argmax_{k ∈ {1, ..., K}} |h_{k,n}|²
```

Нехай коефіцієнти каналу `|h_{k,n}|` підпорядковуються незалежному релеївському розподілу (fading). Тоді квадрат амплітуди `|h_{k,n}|²`, а отже і миттєве значення SNR `γ_k`, є випадковою величиною з експоненційним розподілом і середнім значенням `Γ = E[γ_k]`.

Функція розподілу ймовірностей (CDF) для `γ_k` має вигляд:

```
F(x) = P(γ_k ≤ x) = 1 − e^{−x / Γ}    [для x ≥ 0]
```

Оскільки канали всіх `K` користувачів просторово рознесені та статистично незалежні, функція розподілу максимального SNR серед `K` користувачів `γ_max = max(γ₁, γ₂, ..., γ_K)` на фіксованій піднесній дорівнює добутку окремих CDF:

```
F_{max}(x) = P(max_{k} γ_k ≤ x)
= ∏_{k=1}^K P(γ_k ≤ x)    [незалежність каналів K користувачів]
= [1 − e^{−x / Γ}]^K     [підстановка CDF експоненційного розподілу]
```

Густина ймовірності (PDF) випадкової величини `γ_max` визначається як похідна від `F_{max}(x)`:

```
f_{max}(x) = d/dx [F_{max}(x)]
= K · [1 − e^{−x / Γ}]^{K−1} · (1/Γ) · e^{−x / Γ}    [диференціювання складеної функції]
```

Знайдемо математичне сподівання максимального SNR `E[γ_max]`:

```
E[γ_max] = ∫₀^∞ x · f_{max}(x) dx
= ∫₀^∞ x · K · [1 − e^{−x / Γ}]^{K−1} · (1/Γ) · e^{−x / Γ} dx    [підстановка густини f_{max}(x)]
```

Застосуємо заміну змінної `u = 1 − e^{−x / Γ}`, звідки `e^{−x / Γ} = 1 − u`, `x = −Γ · ln(1 − u)`, а `dx = (Γ / (1 − u)) du`:

```
E[γ_max] = ∫₀¹ [−Γ · ln(1 − u)] · K · u^{K−1} du    [заміна змінної u = 1 − e^{−x/Γ}]
= Γ · K · ∫₀¹ ln(1 / (1 − u)) · u^{K−1} du         [властивість −ln(1−u) = ln(1/(1−u))]
```

Розкладемо натуральний логарифм у ряд Тейлора: `ln(1 / (1 − u)) = Σ_{m=1}^∞ (u^m / m)`:

```
E[γ_max] = Γ · K · ∫₀¹ [ Σ_{m=1}^∞ (u^{m + K − 1} / m) ] du    [розклад ln(1/(1−u)) у степеневий ряд]
= Γ · K · Σ_{m=1}^∞ (1 / m) · ∫₀¹ u^{m + K − 1} du            [перестановка знаків суми та інтеграла]
= Γ · K · Σ_{m=1}^∞ (1 / m) · [1 / (m + K)]                   [обчислення інтеграла від u^{m+K−1}]
```

Розкладемо дріб `1 / (m · (m + K))` на прості дроби:

```
1 / (m · (m + K)) = (1 / K) · [ (1 / m) − (1 / (m + K)) ]
```

Підставивши цей вираз назад у суму, отримаємо:

```
E[γ_max] = Γ · K · (1 / K) · Σ_{m=1}^∞ [ (1 / m) − (1 / (m + K)) ]                                  [підстановка розкладу на прості дроби]
= Γ · [ (1 + 1/2 + ... + 1/K) + (1/(K+1) + ...) − (1/(K+1) + ...) ]                                 [розкриття телескопічної суми]
= Γ · Σ_{k=1}^K (1 / k)                                                                             [взаємне скорочення спільних хвостів]
= Γ · H_K                                                                                           [за означенням гармонічного числа]
```

де `H_K = Σ_{k=1}^K (1 / k)` — `K`-те гармонічне число.

За асимптотичною формулою Ейлера–Маклорена для гармонічного ряду:

```
H_K = ln(K) + γ_E + O(1 / K)
```

де `γ_E ≈ 0.577215` — стала Ейлера–Маскероні.

Отже, математичне сподівання відношення сигнал/шум при виборі найкращого користувача на кожній піднесній зростає як логарифм від кількості абонентів:

```
E[γ_max] ≈ Γ · (ln(K) + 0.5772)
```

### Фізична природа гармонічного ряду у виграші різноманітності

Поява гармонічного числа `H_K = Σ_{k=1}^K (1 / k)` має глибоку геометричну та статистичну інтерпретацію через властивість відсутності пам'яті показникового розподілу. 

Нехай `γ_{(1)} ≤ γ_{(2)} ≤ ... ≤ γ_{(K)}` — варіаційний ряд (порядкові статистики), утворений упорядкуванням відношень сигнал/шум усіх `K` користувачів за зростанням. Найменше значення `γ_{(1)} = min(γ₁, ..., γ_K)` є мінімумом із `K` незалежних експоненційних випадкових величин із параметром інтенсивності `λ = 1/Γ`. За відомою теоремою теорії ймовірностей, мінімум із `K` експоненційних величин сам є експоненційним із сумарною інтенсивністю `K · λ`, тому його середнє значення дорівнює:

```
E[γ_{(1)}] = Γ / K    [середній мінімум серед K користувачів]
```

Завдяки властивості відсутності пам'яті показникового закону, залишок після відтинання `γ_{(1)}` знову розподілений показниково, але вже серед `K - 1` користувачів, що залишилися. Приріст між першою та другою порядковою статистикою `Δ₁ = γ_{(2)} − γ_{(1)}` є експоненційною величиною з параметром `(K - 1) · λ` і середнім `Γ / (K - 1)`. 

Послідовно підсумовуючи всі `K` незалежних приростів між сусідніми порядковими статистиками, отримуємо точне вираження для максимального SNR:

```
E[γ_max] = E[γ_{(K)}]
= E[γ_{(1)}] + E[γ_{(2)} − γ_{(1)}] + ... + E[γ_{(K)} − γ_{(K−1)}]    [розклад максимуму на суму приростів]
= (Γ / K) + (Γ / (K − 1)) + ... + (Γ / 1)                            [сума середніх значень приростів]
= Γ · Σ_{k=1}^K (1 / k)                                              [винесення спільного множника Γ]
= Γ · H_K                                                            [згортання в гармонічне число]
```

Це доводить, що кожен додатковий абонент у системі приносить спадний маржинальний внесок `Γ / k` у пікову якість каналу. Перші 5–10 абонентів дають вибуховий приріст ємності, тоді як при `K > 50` зростання плавно переходить у чистий логарифмічний режим `ln(K)`.

## Ймовірність зриву зв'язку (Outage Probability)

Важливим критерієм надійності системи зв'язку є ймовірність того, що миттєва пропускна здатність каналу опуститься нижче заданого цільового порогу швидкості `R_target` (стан зриву або завади, англ. *outage*).

Для однієї піднесної цільова швидкість `R_target` вимагає мінімального порогового значення SNR:

```
γ_th = 2^{R_target / Δf} − 1    [пороговий SNR за формулою Шеннона]
```

1. **Для однокористувацького OFDM (K = 1):**
Зрив передачі виникає щоразу, коли релеївське завмирання опускає сигнал абонента нижче `γ_th`:

```
P_outage(1) = P(γ₁ < γ_th) = 1 − e^{−γ_th / Γ}
```
При типовому відношенні `γ_th / Γ = 0.1` ймовірність втрати пакета на піднесній становить близько `1 − e^{−0.1} ≈ 9.5%`.

2. **Для багатокористувацького OFDMA (K незалежних користувачів):**
Зрив на піднесній виникає лише за катастрофічної умови, що канали **всіх** `K` користувачів одночасно впали нижче порогу `γ_th`:

```
P_outage(K) = P(max_{k} γ_k < γ_th)
= [ 1 − e^{−γ_th / Γ} ]^K    [добуток незалежних ймовірностей для K абонентів]
```

Для системи з `K = 8` абонентами за тих самих умов:
```
P_outage(8) = (0.095)⁸ ≈ 6.6 · 10^{−9}
```
Ймовірність глибокого провалу піднесної падає на сім порядків. OFDMA практично повністю ліквідує необхідність у важкому надлишковому перемежовуванні кодів (interleaving), перетворюючи статистично нестабільний радіоканал на детерміновану магістраль.

## Вплив розсіяного та прямого променів: райсівське завмирання

Якщо між базовою станцією та абонентами існує пряма оптична видимість (Line-of-Sight, LoS), амплітуда сигналу підпорядковується не релеївському, а райсівському розподілу (Rician fading), який характеризується коефіцієнтом `K_rice` (відношення потужності прямого променя до потужності розсіяних хвиль).

Коли `K_rice → 0`, канал перетворюється на чистий релеївський із високою випадковою дисперсією амплітуд, де виграш багатокористувацької різноманітності максимальний (`E[γ_max] ∝ ln K`).

Коли `K_rice → ∞`, прямий промінь повністю домінує над відлунням. Канал стає детермінованим гаусовим (AWGN) без частотної вибірковості. У таких умовах `|h_{k,n}|` стає однаковим для всіх піднесних і всіх абонентів на однаковій відстані, через що виграш від вибору піку зникає (`E[γ_max] → Γ`). Багатокористувацька різноманітність OFDMA найбільш ефективна саме у складних міських умовах без прямої видимості (NLoS), де звичайний зв'язок зазнає найбільших втрат.

## Двовимірна оптимізація розподілу потужності (2D Water-Filling)

Якщо планувальник має точну інформацію про стан каналу (CSI) усіх абонентів, максимізація сумарної ємності формулюється як задача опуклого математичного програмування:

```
max_{ {c_{k,n}}, {P_{k,n}} } Σ_{n=0}^{N-1} Σ_{k=1}^K c_{k,n} · Δf · log₂(1 + (P_{k,n} · |h_{k,n}|²) / (N₀ · Δf))
```

за умов:
```
c_{k,n} ∈ {0, 1}
Σ_{k=1}^K c_{k,n} ≤ 1
P_{k,n} ≥ 0
Σ_{n=0}^{N-1} Σ_{k=1}^K c_{k,n} · P_{k,n} ≤ P_total
```

Застосовуючи метод множників Лагранжа, функція Лагранжа набуває вигляду:

```
L({P_{k,n}}, {c_{k,n}}, λ) = Σ_{n=0}^{N-1} Σ_{k=1}^K c_{k,n} · Δf · log₂(1 + P_{k,n} · α_{k,n}) − λ · (Σ_{n,k} c_{k,n} · P_{k,n} − P_total)
```

де `α_{k,n} = |h_{k,n}|² / (N₀ · Δf)` — нормована якість каналу.

Взявши частинну похідну по `P_{k,n}` і прирівнявши її до нуля, отримуємо класичне правило водяного наповнення (англ. *Water-Filling*):

```
∂L / ∂P_{k,n} = (Δf / ln 2) · (α_{k,n} / (1 + P_{k,n} · α_{k,n})) − λ = 0
```

звідки оптимальна потужність дорівнює:

```
P_{k,n}^* = [ (1 / (λ · ln 2)) − (1 / α_{k,n}) ]^+
```

де `[x]^+ = max(0, x)`, а рівень води `1 / (λ · ln 2)` підбирається чисельним пошуком так, щоб сума всіх `P_{k,n}^*` точно дорівнювала `P_total`.

Планувальник спочатку віддає кожну `n`-у піднесу абоненту з максимальним значенням `α_{k,n}`, а потім заливає загальну потужність `P_total` у піднесні з найменшим рівнем шуму `1 / α_{k,n}`.

## Деградація ортогональності від часового розсинхрону (Timing Offset)

Якщо у висхідному каналі сигнал `k`-го користувача прибуває із часовою затримкою `Δt_k`, що не перевищує захисного інтервалу циклічного префікса (`Δt_k < T_{cp} − τ_{max}`), форма хвилі залишається в межах вікна інтегрування FFT. Проте в частотній області часовий зсув `Δt_k` призводить до лінійного набігу фази для кожної `m`-ї піднесної:

```
Y_{k,m} = X_{k,m} · H_{k,m} · e^{−j 2π m Δf Δt_k}    [набіг фази від затримки в часі]
```

Цей фазовий поворот `θ_m = −2π m Δf Δt_k` легко компенсується еквалайзером базової станції за відомими пілотними сигналами (DMRS).

Однак, якщо похибка часової синхронізації перевищує запас циклічного префікса (`Δt_k > T_{cp} − τ_{max}`), вікно демодуляції FFT захоплює відліки з попереднього або наступного символу. Виникає комбіноване руйнування сигналу:
1. **Міжсимвольна інтерференція (ISI):** енергія сусіднього символу додається як некорельований шум дисперсії `σ²_{ISI} ∝ (Δt_k / T_s) · P_{signal}`.
2. **Міжканальна інтерференція (ICI):** втрата неперервності кругової гармоніки призводить до розмиття піку в частоті, через що ортогональність між сусідніми піднесними безповоротно втрачається.

## Руйнування ортогональності: деградація SINR від зсуву частоти (CFO)

Ортогональність піднесних спирається на точне збереження інтервалу `Δf = 1 / T_s`. Якщо у висхідному каналі (UL-OFDMA) гетеродин `k`-го користувача має частотну похибку `Δf_{cfo,k}`, виникає зсув несучої. Позначимо нормований зсув як `ε_k = Δf_{cfo,k} / Δf`.

Комплексний сигнал на `m`-й піднесній після перетворення Фур'є (FFT) на базовій станції містить три компоненти:

```
Y_m = H_{m,m} · X_m · I₀(ε_m) + Σ_{k ≠ m} H_{k,m} · X_k · I_{k−m}(ε_k) + W_m
```

де `I₀(ε)` — коефіцієнт ослаблення власного корисного сигналу, а `I_{k−m}(ε)` — коефіцієнт взаємної міжканальної завади (ICI) від сусідньої `k`-ї піднесної.

Коефіцієнт міжканальної інтерференції виводиться через інтеграл від зсунутої експоненти:

```
I_d(ε) = (1 / T_s) ∫₀^{T_s} e^{j 2π (d + ε) Δf t} dt
= (1 / T_s) · [ (e^{j 2π (d + ε)} − 1) / (j 2π (d + ε) Δf) ]    [інтегрування комплексної експоненти]
= e^{j π (d + ε)} · [ sin(π (d + ε)) / (π (d + ε)) ]            [формула Ейлера: (e^{jx} - 1)/j = 2 e^{jx/2} sin(x/2)]
```

Потужність ослаблення корисного сигналу (`d = 0`):

```
|I₀(ε)|² = sinc²(ε) = (sin(π ε) / (π ε))²
```

Розкладемо функцію `sin(π ε)` у ряд Тейлора при малих `ε ≪ 1`:

```
sin(π ε) = π ε − (π ε)³ / 6 + O(ε⁵)    [ряд Тейлора для синуса]
sinc(ε) = 1 − (π² ε²) / 6 + O(ε⁴)      [ділення ряду на аргумент π ε]
sinc²(ε) ≈ 1 − (π² ε²) / 3             [піднесення до квадрата з відкиданням O(ε⁴)]
```

Потужність сумарної міжканальної завади (ICI), яку генерує зсунута піднесна на всі інші ортогональні канали, за теоремою Парсеваля дорівнює енергії, втраченій корисним піком:

```
P_ICI(ε) = Σ_{d ≠ 0} |I_d(ε)|²
= 1 − |I₀(ε)|²           [теорема Парсеваля: сума енергій усіх гармонік дорівнює 1]
= 1 − sinc²(ε)           [підстановка виразу для потужності головного піку |I₀(ε)|²]
≈ (π² / 3) · ε²          [підстановка наближення sinc²(ε) при малих ε]
```

Підсумкове відношення сигнал/інтерференція (SINR) на піднесній через частотний зсув обмежується зверху величиною:

```
SINR_{CFO} ≈ |I₀(ε)|² / P_ICI(ε)
≈ (1 − (π² ε²) / 3) / ((π² / 3) · ε²)    [підстановка потужностей сигналу та завади ICI]
≈ 3 / (π² · ε²)                          [спрощення дробу при умові (π² ε²)/3 ≪ 1]
```

### Практичні наслідки для вимог до кварцових генераторів

1. Якщо нормована похибка становить `ε = 0.01` (1% від кроку піднесних):
```
SINR_{CFO} ≈ 3 / (π² · 0.0001) ≈ 3 / 0.000987 ≈ 3040 (34.8 дБ)    [розрахунок для похибки 1%]
```
Це дозволяє без спотворень приймати модуляцію 1024-QAM (яка вимагає EVM не гірше −35 дБ).

2. Якщо нормована похибка зростає до `ε = 0.05` (5% від `Δf`):
```
SINR_{CFO} ≈ 3 / (π² · 0.0025) ≈ 121.6 (20.8 дБ)                  [розрахунок для похибки 5%]
```
Шум взаємної завади ICI обмежує демодуляцію рівнем 64-QAM, унеможливлюючи високі швидкості зв'язку навіть при нульовому зовнішньому шумі каналу.

## Доплерівське розширення та вибір нумерології під швидкість руху

Коли термінал рухається зі швидкістю `v` відносно базової станції, випромінювання на несучій частоті `f_c` зазнає доплерівського зсуву, максимальне значення якого визначається як:

```
f_d = (v · f_c) / c    [максимальний доплерівський зсув]
```

де `c ≈ 3 · 10⁸ м/с` — швидкість світла.

Для швидкісного потяга (`v = 300 км/год ≈ 83.3 м/с`) у діапазоні 5G `f_c = 3.5 ГГц`:
```
f_d = (83.3 · 3.5 · 10⁹) / (3 · 10⁸) ≈ 972 Гц    [доплерівський розкид для швидкісного потяга]
```

Оскільки радіохвилі надходять із різних напрямків (спектр Джейкса), доплерівський зсув є неперервним випадковим процесом із дисперсією `σ²_D = f_d² / 2`. Цей процес розмиває кожну піднесу в часі протягом символу `T_s`, породжуючи внутрішньоканальний інтерференційний шум (Doppler ICI).

Потужність доплерівської міжканальної інтерференції виражається через відношення доплерівського зсуву до кроку піднесних `Δf`:

```
P_ICI,Doppler ≈ (π² / 6) · (f_d / Δf)²    [наближення дисперсії доплерівської завади ICI]
```

Якщо в системі 4G LTE з кроком `Δf = 15 кГц` доплерівський зсув становить `f_d = 972 Гц`, нормований зсув дорівнює `f_d / Δf ≈ 0.065` (6.5%), що створює фоновий поріг інтерференції:

```
SINR_{Doppler} ≈ 6 / (π² · 0.065²) ≈ 143.7 (21.5 дБ)    [стеля SINR при Δf = 15 кГц]
```
Цей рівень шуму унеможливлює використання модуляцій 256-QAM та 1024-QAM. 

Перехід у 5G NR до нумерології `μ = 2` з кроком `Δf = 60 кГц` зменшує нормований зсув у чотири рази (`f_d / Δf ≈ 0.016`), піднімаючи поріг SINR на 12 дБ:

```
SINR_{Doppler, 60kHz} ≈ 6 / (π² · 0.016²) ≈ 2370 (33.7 дБ)    [стеля SINR при Δf = 60 кГц]
```
Це математично доводить необхідність збільшення кроку піднесних у високошвидкісному транспорті.

## Просторовий розподіл: інтеграція OFDMA з багатоантенним MU-MIMO

У сучасних системах 5G NR та Wi-Fi 6/7 частотний поділ OFDMA комбінується з просторовим мультиплексуванням MU-MIMO (Multi-User MIMO). Базова станція, оснащена антенною решіткою з `M_tx` передавальними елементами, може призначити один і той самий ресурсний блок одночасно `S` різним абонентам (`S ≤ M_tx`), розділяючи їхні просторові промені за допомогою лінійного прекодування (Zero-Forcing Precoding).

Нехай `H_n ∈ ℂ^{S × M_tx}` — матриця каналу для `S` обраних абонентів на `n`-й піднесній. Прекодувальна матриця Zero-Forcing формується через псевдообернену матрицю Мура–Пенроуза:

```
W_n = H_n^H · (H_n · H_n^H)^{−1}    [матриця прекодування Zero-Forcing]
```

Нормувальний коефіцієнт потужності для кожного `s`-го просторового потоку:

```
β_{s,n} = 1 / √( [ (H_n · H_n^H)^{−1} ]_{s,s} )    [нормування потужності потоку]
```

При застосуванні матриці `W_n` на передавачі базової станції сигнал на антені `s`-го абонента звільняється від просторової міжабонентської інтерференції (Inter-User Interference):

```
y_{s,n} = H_{s,n} · W_{s,n} · x_{s,n} + Σ_{j ≠ s} H_{s,n} · W_{j,n} · x_{j,n} + w_{s,n}
= β_{s,n} · x_{s,n} + 0 + w_{s,n}    [ортогоналізація просторових потоків]
```

Сумарна ємність комбінованої системи MU-MIMO OFDMA досягає:

```
C_{MIMO-OFDMA} = Σ_{n=0}^{N-1} Σ_{s=1}^S Δf · log₂(1 + (P_{s,n} · β_{s,n}²) / (N₀ · Δf))
```

## Аналіз рівноваги SINR при дробовому керуванні потужністю (Fractional Power Control)

У стільниковій мережі висхідний сигнал користувача зазнає втрат на трасі розповсюдження `PL(d) = (d / d_0)^γ`, де `γ ≈ 3.5...4.0` — показник згасання в міській забудові.

Якщо застосувати повну компенсацію втрат (`α = 1.0` у формулі `P_tx = P_0 · PL^α`), сигнал від кожного абонента надходить на базову станцію з точно однаковою потужністю `P_0`. Проте це змушує абонента на межі стільника постійно випромінювати максимальну потужність `P_max`, створюючи сильну міжстільникову інтерференцію (Inter-Cell Interference) для сусідніх базових станцій.

При застосуванні дробової компенсації (`α ≈ 0.6...0.8`):

```
P_{rx}(d) = P_tx / PL(d)
= P_0 · PL(d)^α / PL(d)                   [підстановка формули передавача P_tx]
= P_0 · PL(d)^{α − 1}                     [зведення степенів втрат на трасі]
= P_0 / (d / d_0)^{γ · (1 − α)}           [підстановка степеневого закону розповсюдження]
```

## Зв'язок векторної похибки модуляції (EVM) із сумарним рівнем інтерференції

Векторна похибка модуляції (Error Vector Magnitude, EVM) є головним показником якості апаратного тракту радіопередавача й приймача в OFDMA. Вона вимірює середньоквадратичне відхилення прийнятих символів сузір'я від їхніх ідеальних точок:

```
EVM_{RMS} = √( E[ |Y_{k,n} − S_{ideal}|² ] / E[ |S_{ideal}|² ] )
```

У присутності теплового шуму AWGN, міжканальної інтерференції `P_ICI` від зміщення частоти та залишкової міжсимвольної завади `P_ISI` через затримку в часі, загальний рівень EVM безпосередньо зв'язаний із підсумковим відношенням SINR:

```
EVM_{RMS} = √( 1 / SINR_{total} )
= √( (N₀ · Δf + P_ICI + P_ISI) / P_{signal} )    [зв'язок EVM із сумарними завадами]
```

Для успішного прийому модуляції 1024-QAM стандарт IEEE 802.11ax та 3GPP Rel 17 вимагають `EVM ≤ −35 дБ` (менше 1.77% похибки), що диктує необхідність утримання сумарного `SINR_{total} ≥ 35 дБ`. Це ставить гранично жорсткі вимоги до точності алгоритмів автопідстроювання частоти (AFC) та компенсації затримок (Timing Advance) у всіх абонентських терміналах OFDMA.
