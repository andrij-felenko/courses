# 🧮 Математичне виведення матриць перетворення колірних просторів Y'CbCr

Математична вставка пояснює точний аналітичний вивід коефіцієнтів матриць перетворення з тристимульного простору R'G'B' у колірнорізничний простір Y'CbCr на основі хроматичних координат первинних кольорів CIE 1931 та точки білого D65. Вона необхідна для розуміння того, звідки беруться стандартизовані числа у специфікаціях ITU-R BT.601, BT.709 та BT.2020, як з них обчислюються обернені матриці декодування без втрати енергії сигналу, та як формується похибка неколориметричної яркості (Non-Constant Luminance Error).

Математичний апарат описує геометричний поворот та масштабування тривимірних векторів у колірному тілі, де вихідний куб R'G'B' деформується у прямокутний паралелепіпед Y'CbCr.

## 1. Фізична модель яркості та коефіцієнти W_R, W_G, W_B

Трихроматична теорія зору Юнга-Гельмгольца стверджує, що очне яблуко сприймає світло за допомогою трьох типів колбочок сетчатки, чутливих до довгохвильового (L), середньохвильового (M) та короткохвильового (S) спектрів. Сумарна фотометрична яскравість світлового потоку визначається функцією відносної спектральної світлової ефективності монадного зору `V(λ)`.

При змішуванні трьох монохромних випромінювачів із базовими довжинами хвиль або первинними кольорами монітора `R`, `G`, `B`, загальна яскравість `Y` утворюється як лінійна комбінація світлових потоків кожного з трьох каналів:

```
Y = W_R · R + W_G · G + W_B · B
```

Оскільки повний нормалізований білий колір `[1.0, 1.0, 1.0]` за визначенням має створювати одиничну яскравість `Y = 1.0`, сума вагових коефіцієнтів завжди дорівнює одиниці:

```
W_R + W_G + W_B = 1.0
```

Коефіцієнти `W_R`, `W_G`, `W_B` не є довільними константами. Вони однозначно розраховуються через хроматичні координати `(x, y)` первинних кольорів `R`, `G`, `B` та реперної точки білого світла `W` (стандартний ілюмінант D65 з колірною температурою 6504 К) у колориметричній системі CIE 1931.

Система лінійних рівнянь для зв'язку між координатною системою CIE XYZ та тристимульним простором RGB має вигляд:

```
X = X_r · R + X_g · G + X_b · B
Y = Y_r · R + Y_g · G + Y_b · B
Z = Z_r · R + Z_g · G + Z_b · B
```

Зв'язок між нормалізованими хроматичними координатами `x, y, z` та стимулами `X, Y, Z` задається співвідношеннями:

```
x = X / (X + Y + Z)
y = Y / (X + Y + Z)
z = Z / (X + Y + Z) = 1 - x - y
```

Звідси одиничні стимуляційні коефіцієнти для кожного з трьох кольорових люмінофорів виражаються через їхні хроматичні координати та нормалізуючі множники `C_r, C_g, C_b`:

```
X_r = C_r · (x_r / y_r)
Y_r = C_r
Z_r = C_r · ((1 - x_r - y_r) / y_r)

X_g = C_g · (x_g / y_g)
Y_g = C_g
Z_g = C_g · ((1 - x_g - y_g) / y_g)

X_b = C_b · (x_b / y_b)
Y_b = C_b
Z_b = C_b · ((1 - x_b - y_b) / y_b)
```

Для точки білого D65 з координатами `(x_w, y_w) = (0.3127, 0.3290)` значення тристимульних компонент складають `X_w = x_w / y_w`, `Y_w = 1.0`, `Z_w = (1 - x_w - y_w) / y_w`. Підставляючи `R = 1, G = 1, B = 1` у систему рівнянь, отримуємо систему для обчислення `C_r, C_g, C_b`:

```
C_r · (x_r / y_r) + C_g · (x_g / y_g) + C_b · (x_b / y_b) = x_w / y_w
C_r + C_g + C_b = 1.0
C_r · (z_r / y_r) + C_g · (z_g / y_g) + C_b · (z_b / y_b) = z_w / y_w
```

Оскільки за визначенням `W_R = Y_r = C_r`, `W_G = Y_g = C_g`, `W_B = Y_b = C_b`, розв'язок цієї системи визначає ваги яркості для будь-якого стандарту відео.

### 1.1. Вивід ваг яркості BT.601 (SDTV)

Для аналогового та цифрового телебачення стандартної чіткості BT.601 використовуються люмінофори NTSC / PAL з координатами `R(0.630, 0.340)`, `G(0.310, 0.595)`, `B(0.155, 0.070)` та точкою білого D65.

Розв'язання лінійного матричного рівняння дає точні значення вагових коефіцієнтів яркості BT.601:

```
W_R = 0.2990
W_G = 0.5870
W_B = 0.1140
```

Найбільша частка вагового коефіцієнта припадає на зелений канал (58.7%), оскільки крива зорової чутливості людського ока розрахована на максимальне сприйняття довжини хвиль зеленого світла.

### 1.2. Вивід ваг яркості BT.709 (HDTV)

Для телебачення високої чіткості BT.709 використовуються більш насичені люмінофори з координатами `R(0.640, 0.330)`, `G(0.300, 0.600)`, `B(0.150, 0.060)`. Підстановка цих координат у розв'язок дає значення коефіцієнтів:

```
W_R = 0.2126
W_G = 0.7152
W_B = 0.0722
```

У цьому стандарті частка зеленого каналу зросла до 71.52%, що зумовлено зсувом точних колориметричних параметрів світлофільтрів сучасних рідкокристалічних та світлодіодних екранів.

### 1.3. Вивід ваг яркості BT.2020 (UHDTV)

Для відео ультрависокої чіткості BT.2020 первинні кольори розміщені практично на спектральній межі CIE 1931 з координатами `R(0.708, 0.292)`, `G(0.170, 0.797)`, `B(0.131, 0.046)`. Підстановка координат лазерних монохроматичних випромінювачів визначає коефіцієнти:

```
W_R = 0.2627
W_G = 0.6780
W_B = 0.0593
```

Ці ваги забезпечують максимально можливе колірне охоплення (понад 75% спектрального локусу), доступне цифровим відеосистемам.

## 2. Нормалізація колірнорізничих сигналів Cb та Cr

Аналогові колірнорізничі сигнали описуються як відхилення гамма-корегованих сигналів червоного `R'` та синього `B'` від сигнала яркості `Y'`. Вони формуються шляхом прямого віднімання координати яркості з колірних каналів:

```
E'_Pb = B' - Y'
E'_Pr = R' - Y'
```

Визначимо граничні значення `E'_Pb` та `E'_Pr` при значенні вхідних сигналів `R', G', B'` у нормованому діапазоні `[0.0, 1.0]`.

Для синього колірнорізничого сигналу:
* Максимальне позитивне значення досягається на чистому синьому кольорі `(R'=0, G'=0, B'=1)`:

```
Y' = W_B · 1.0 = W_B
E'_Pb_max = 1.0 - W_B
```

* Максимальне негативне значення досягається на чистому жовтому кольорі `(R'=1, G'=1, B'=0)`:

```
Y' = W_R · 1.0 + W_G · 1.0 = 1.0 - W_B
E'_Pb_min = 0.0 - (1.0 - W_B) = -(1.0 - W_B)
```

Отже, амплітудний розмах сигналу `E'_Pb` складає `[- (1 - W_B), + (1 - W_B)]`.

Для нормалізації сигналу `Cb` у симетричний цифровий діапазон `[-0.5, +0.5]` вводиться масштабуючий коефіцієнт `K_b`:

```
Cb = E'_Pb / K_b = (B' - Y') / (2 · (1 - W_B))
```

Аналогічно для червоного колірнорізничого сигналу:
* Максимальне позитивне значення досягається на чистому червоному кольорі `(R'=1, G'=0, B'=0)`:

```
Y' = W_R · 1.0 = W_R
E'_Pr_max = 1.0 - W_R
```

* Нормалізація `Cr` у діапазон `[-0.5, +0.5]` потребує коефіцієнта `K_r`:

```
Cr = E'_Pr / K_r = (R' - Y') / (2 · (1 - W_R))
```

Введення симетричного діапазону `[-0.5, +0.5]` гарантує рівномірне заповнення бітової сітки аналого-цифрових та цифро-аналогових перетворювачів без ризику асиметричного переповнення одного з півперіодів колірного сигналу.

## 3. Матричний вивід для стандарту BT.709

Підставимо вагові коефіцієнти BT.709 (`W_R = 0.2126`, `W_G = 0.7152`, `W_B = 0.0722`) у формули нормалізації:

```
2 · (1 - W_B) = 2 · (1 - 0.0722) = 2 · 0.9278 = 1.8556
2 · (1 - W_R) = 2 · (1 - 0.2126) = 2 · 0.7874 = 1.5748
```

Обчислимо коефіцієнти розкладу `Cb` через вхідні `R', G', B'`:

```
Cb = (B' - (0.2126·R' + 0.7152·G' + 0.0722·B')) / 1.8556
   = (-0.2126·R' - 0.7152·G' + 0.9278·B') / 1.8556      [розкриття дужок: B' - 0.0722·B' = 0.9278·B']
   = -0.1146·R' - 0.3854·G' + 0.5000·B'                [поділили кожен коефіцієнт на 1.8556]
```

Обчислимо коефіцієнти розкладу `Cr` через вхідні `R', G', B'`:

```
Cr = (R' - (0.2126·R' + 0.7152·G' + 0.0722·B')) / 1.5748
   = (0.7874·R' - 0.7152·G' - 0.0458·B') / 1.5748      [розкриття дужок: R' - 0.2126·R' = 0.7874·R']
   = 0.5000·R' - 0.4542·G' - 0.0458·B'                [поділили кожен коефіцієнт на 1.5748]
```

Пряма матриця перетворення BT.709 у нормованій формі `[0.0, 1.0]` записується у вигляді:

```
[ Y' ]   [  0.2126   0.7152   0.0722 ]   [ R' ]
[ Cb ] = [ -0.1146  -0.3854   0.5000 ] · [ G' ]
[ Cr ]   [  0.5000  -0.4542  -0.0458 ]   [ B' ]
```

Ця матриця характеризується тим, що сума елементів у першому рядку дорівнює 1.0, а суми елементів у другому та третьому рядках строго дорівнюють 0.0. Це підтверджує ортогональність сигналу яркості та колірнорізничих каналів.

## 4. Матричний вивід для стандарту BT.601

Підставимо вагові коефіцієнти BT.601 (`W_R = 0.2990`, `W_G = 0.5870`, `W_B = 0.1140`):

```
2 · (1 - W_B) = 2 · (1 - 0.1140) = 2 · 0.8860 = 1.7720
2 · (1 - W_R) = 2 · (1 - 0.2990) = 2 · 0.7010 = 1.4020
```

Обчислимо коефіцієнти розкладу `Cb` для BT.601:

```
Cb = (B' - (0.2990·R' + 0.5870·G' + 0.1140·B')) / 1.7720
   = (-0.2990·R' - 0.5870·G' + 0.8860·B') / 1.7720      [розкриття дужок: B' - 0.1140·B' = 0.8860·B']
   = -0.1687·R' - 0.3313·G' + 0.5000·B'                [поділили кожен коефіцієнт на 1.7720]
```

Обчислимо коефіцієнти розкладу `Cr` для BT.601:

```
Cr = (R' - (0.2990·R' + 0.5870·G' + 0.1140·B')) / 1.4020
   = (0.7010·R' - 0.5870·G' - 0.1140·B') / 1.4020      [розкриття дужок: R' - 0.2990·R' = 0.7010·R']
   = 0.5000·R' - 0.4187·G' - 0.0813·B'                [поділили кожен коефіцієнт на 1.4020]
```

Пряма матриця перетворення BT.601 у нормованій формі:

```
[ Y' ]   [  0.2990   0.5870   0.1140 ]   [ R' ]
[ Cb ] = [ -0.1687  -0.3313   0.5000 ] · [ G' ]
[ Cr ]   [  0.5000  -0.4187  -0.0813 ]   [ B' ]
```

Порівняння матриць BT.601 та BT.709 демонструє суттєве розходження у другого та третього рядка, що робить їх взаємно несумісними без перематрицювання.

## 5. Аналітичне інвертування матриці Y'CbCr -> R'G'B'

Для відновлення сигналів `R', G', B'` під час відтворення відео необхідно розв'язати систему рівнянь відносно `R', G', B'`.

Покрокове виведення оберненого перетворення:

```
R' = Y' + (R' - Y')
= Y' + 1.5748 · Cr                             [підстановка виразу Cr = (R' - Y') / 1.5748]
```

```
B' = Y' + (B' - Y')
= Y' + 1.8556 · Cb                             [підстановка виразу Cb = (B' - Y') / 1.8556]
```

Для знаходження `G'` використаємо формулу яркості `Y' = W_R·R' + W_G·G' + W_B·B'`:

```
W_G · G' = Y' - W_R · R' - W_B · B'            [ізоляція члена W_G · G']
= Y' - W_R · (Y' + 1.5748·Cr) - W_B · (Y' + 1.8556·Cb) [підстановка виразів R' та B']
= (1 - W_R - W_B) · Y' - W_R · 1.5748 · Cr - W_B · 1.8556 · Cb [групування по Y']
= W_G · Y' - W_R · 1.5748 · Cr - W_B · 1.8556 · Cb [урахування W_R + W_G + W_B = 1]
```

Поділимо обидві частини рівняння на `W_G`:

```
G' = Y' - (W_R · 1.5748 / W_G) · Cr - (W_B · 1.8556 / W_G) · Cb
```

Підставимо числові значення BT.709 (`W_R = 0.2126`, `W_G = 0.7152`, `W_B = 0.0722`):

```
W_R · 1.5748 / W_G = 0.2126 · 1.5748 / 0.7152 = 0.33481 / 0.7152 = 0.4681
W_B · 1.8556 / W_G = 0.0722 · 1.8556 / 0.7152 = 0.13397 / 0.7152 = 0.1873
```

Таким чином, обернена матриця відновлення R'G'B' для BT.709 має вигляд:

```
[ R' ]   [ 1.0000   0.0000   1.5748 ]   [ Y' ]
[ G' ] = [ 1.0000  -0.1873  -0.4681 ] · [ Cb ]
[ B' ]   [ 1.0000   1.8556   0.0000 ]   [ Cr ]
```

Аналогічно для BT.601 обернена матриця відновлення розраховується з вагових коефіцієнтів `W_R = 0.2990`, `W_G = 0.5870`, `W_B = 0.1140`:

```
[ R' ]   [ 1.0000   0.0000   1.4020 ]   [ Y' ]
[ G' ] = [ 1.0000  -0.3441  -0.7141 ] · [ Cb ]
[ B' ]   [ 1.0000   1.7720   0.0000 ]   [ Cr ]
```

Точність визначення елементів зворотної матриці є визначною для запобігання нагромадження похибок двійкового округлення при багаторазовому транскодуванні відеоматеріалу.

## 6. Врахування дискретного квантування Studio Range (8 біт та 10 біт)

У 8-бітному цифровому відео з обмеженим діапазоном (Studio Range) відліки `Y'_8` квантуються в інтервал `[16, 235]` (220 рівнів), а колірнорізничні відліки `Cb_8, Cr_8` — в інтервал `[16, 240]` з нейтральною точкою 128 (224 рівні).

Зв'язок між нормованими значеннями `Y', Cb, Cr ∈ [-0.5, +0.5]` та 8-бітними цілими числами задається формулами:

```
Y'_8 = 219 · Y' + 16
Cb_8 = 224 · Cb + 128
Cr_8 = 224 · Cr + 128
```

Виразимо нормовані величини через 8-бітні значення:

```
Y' = (Y'_8 - 16) / 219
Cb = (Cb_8 - 128) / 224
Cr = (Cr_8 - 128) / 224
```

Підставляючи ці відліки в обернену матрицю відновлення для BT.709, отримуємо прямий вираз для відновлення 8-бітних сигналів `R'_8, G'_8, B'_8 ∈ [0, 255]`:

```
R'_8 = 255 · ( (Y'_8 - 16)/219 + 1.5748 · (Cr_8 - 128)/224 )
     = 1.16438 · (Y'_8 - 16) + 1.79274 · (Cr_8 - 128)
```

```
G'_8 = 255 · ( (Y'_8 - 16)/219 - 0.18732 · (Cb_8 - 128)/224 - 0.46812 · (Cr_8 - 128)/224 )
     = 1.16438 · (Y'_8 - 16) - 0.21325 · (Cb_8 - 128) - 0.53291 · (Cr_8 - 128)
```

```
B'_8 = 255 · ( (Y'_8 - 16)/219 + 1.85560 · (Cb_8 - 128)/224 )
     = 1.16438 · (Y'_8 - 16) + 2.11240 · (Cb_8 - 128)
```

Коефіцієнт `1.16438 = 255 / 219` масштабує звужений діапазон яркості 220 рівнів до повного 8-бітного комп'ютерного діапазону 256 рівнів. Отримані коефіцієнти формують математичний базис для створення обчислювально ефективних цілочисельних конвертерів колірних просторів.

При переході до 10-бітного відео (Studio Range 64..940 для Y' та 64..960 для Cb/Cr) коефіцієнти масштабування залишаються абсолютно ідентичними за рахунок однакового пропорційного співвідношення розмахів (876 рівнів яркості та 896 рівнів колірності).

## 7. Аналіз похибки неколориметричної яркості (Constant Luminance Error)

Оскільки розрахунок яркості `Y'` проводиться над гамма-корегованими сигналами `R'G'B'`, а не лінійними `RGB`, при субдискретизації колірності (наприклад, 4:2:0) виникає систематична похибка переносу яркості. Ця нелінійність зумовлена тим, що математична операція піднесення до степеня гамми та операція матричного множення не є комутативними.

Розглянемо випадок чистого червоного кольору `(R=1, G=0, B=0)`.
1. Справжня лінійна яскравість у системі BT.709:

```
Y_linear = 0.2126 · 1.0 + 0.7152 · 0.0 + 0.0722 · 0.0 = 0.2126
```

2. Нелінійна яскравість Luma при `γ = 2.0`:

```
R' = 1.0^(0.5) = 1.0
Y' = 0.2126 · 1.0 = 0.2126
```

При відтворенні телевізор зводить сигнал яркості у ступінь `γ = 2.0`:

```
Y_reconstructed = (Y')^2 = 0.2126^2 = 0.0452
```

Як бачимо, відновлена яскравість `0.0452` становить лише 21% від справжньої лінійної яркості `0.2126`. Решта 79% енергії яркості була закована у колірнорізничий канал `Cr`. Якщо простір колірності піддається розмиттю або субдискретизації, ця втрачена яскравість розсіюється, створюючи темний контур на висококонтрастних колірних межах. У стандартах BT.2100 ICtCp цей недолік усунено за допомогою строго лінійного обчислення інтенсивності `I`.

## 8. Геометрія перетворення векторних просторів та спектральні локуси

З математичної точки зору, перетворення з простору `R'G'B'` у простір `Y'CbCr` виражається афінним перетворенням `V_out = M · V_in + T`, де `M` — 3×3 детермінантна матриця повороту та масштабування, а `T` — вектор зсуву нейтральної точки.

Детермінант матриці перетворення `det(M)` визначає коефіцієнт зміни тривимірного об'єму колірного куба. Для всіх стандартизованих колірних просторів `det(M) ≠ 0`, що гарантує існування єдиної оберненої матриці `M^(-1)` та повну математичну зворотність перетворення без втрати інформації у неквантованій формі з плаваючою комою.

Спектральний аналіз показує, що геометрична форма об'єму допустимих кольорів Y'CbCr являє собою сплюснутий ромбоедр, вписаний у прямокутний паралелепіпед цілочисельної сітки квантування. Крайові вершини цього ромбоедра відповідають чистим первинним та вторинним кольорам (червоний, зелений, синій, блакитний, пурпуровий, жовтий). Перетворення колірних координат поза межами цього ромбоедра призводить до математичного виходу значень за розмахи `[0, 255]`, що вимагає примусового алгоритмічного відсікання або стиснення колірного охоплення (Gamut Clipping).

## 9. Хроматична адаптація Бредфорда та зміна точки білого

Коли виникає потреба перетворити відеоматеріал із колірного простору з однією точкою білого (наприклад, D50 для друкарської поліграфії або D60 для цифрового кінематографа) у простір із точкою білого D65 (стандарт відео), простого матричного перемноження недосить. Застосовують матрицю хроматичної адаптації Бредфорда (Bradford Transform), яка враховує неколінійну адаптацію колбочок ока до спектрального складу навколишнього освітлення:

```
[ X_d ]   [  0.955576 -0.023039  0.063163 ]   [ X_s ]
[ Y_d ] = [ -0.028289  1.009999  0.021007 ] · [ Y_s ]
[ Z_d ]   [  0.012298 -0.020483  1.329909 ]   [ Z_s ]
```

Аналітичне обчислення матриці Бредфорда виконується через проміжний простір чутливості колбочок LMS шляхом діагонального масштабування співвідношень стимулів джерела та призначення. Це гарантує колориметричну точність збереження колірного тону при транскодуванні медіапотоків між різними стандартами вещання.

## 10. Спектральна інтеграція джерел випромінювання

Математичний базис обчислення тристимульних компонент `XYZ` спирається на інтегрування спектрального розподілу енергії джерела світла `S(λ)` та коефіцієнтів відбиття поверхні `R(λ)` у видимому діапазоні довжин хвиль від 380 до 780 нм. Функції додавання кольорів `xbar(λ)`, `ybar(λ)`, `zbar(λ)` стандартизовані комісією CIE 1931 з кроком 1 нм.

Точні значення тристимульних стимулів визначаються визначеними інтегралами:

```
X = k · ∫ S(λ) · R(λ) · xbar(λ) dλ
Y = k · ∫ S(λ) · R(λ) · ybar(λ) dλ
Z = k · ∫ S(λ) · R(λ) · zbar(λ) dλ
```

Множник `k` розраховується з умови нормалізації точки білого, де `Y = 100` для ідеально білого відбивача (`R(λ) = 1.0`). Отримані стимули передаються в лінійну матрицю перетворення у простір `RGB`, звідки після піднесення до степеня OETF піддаються остаточному матрицюванню у `Y'CbCr`.

Практичне значення точного спектрального розрахунку полягає у тому, що при побудові матриць колірного перетворення у професійній відеоапаратурі (студійні камери, моніторні матриці) інженери обчислюють коефіцієнти з точністю до шостого знака після коми, запобігаючи незворотним викривленням фази колірного тону при багаторазовому транскодуванні медіаматеріалу. Отримані матричні коефіцієнти забезпечують повне збереження колірного балансу в усіх проміжних ланках обробки цифрових сигналів. Це гарантує точну та бездоганну відповідність відтворюваної колірної гами вихідним задумкам авторів відеоконтенту.
