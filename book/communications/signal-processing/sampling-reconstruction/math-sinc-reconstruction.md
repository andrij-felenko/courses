# 🧮 Математичне виведення ідеального відновлення та sinc-інтерполяції

Точне відновлення неперервного аналогового сигналу `x(t)` із його цифрових відліків `x[n]` ґрунтується на фундаментальній математичній еквівалентності операцій у часовій та частотній областях. У цій вставці ми покроково виведемо формулу Віттакера-Котельникова-Шеннона, розберемо алгебраїчні властивості кардинального синуса `sinc(t)`, проведемо доведення ортогональності базису та розберемо математичні причини виникнення пульсацій Гіббса і спаду амплітуди у реальних системах.

---

## 1. Математична модель дискретизації: гребінець Дірака

Для аналітичного аналізу процесу дискретизації неперервний сигнал `x(t)` моделюють як помножений на нескінченний ряд дельта-функцій Дірака `p(t)` з періодом дискретизації `Ts = 1 / fs`. Цю математичну конструкцію називають гребінцем Дірака (*Dirac comb*):

```
p(t) = ∑ δ(t - n·Ts)  [сумування від n = -∞ до +∞]
```

Результатом дискретизації у часовій області є послідовність зважених дельта-імпульсів `xs(t)`:

```
xs(t) = x(t) · p(t)                 [множення сигналу на гребінець Дірака]
      = x(t) · ∑ δ(t - n·Ts)        [підстановка розкладу гребінця p(t)]
      = ∑ x(n·Ts) · δ(t - n·Ts)     [за властивістю множення на дельта-імпульс]
```

Щоб знайти спектр дискретизованого сигналу `Xs(f)`, застосуємо перетворення Фур'є до `xs(t)`. За теоремою про згортку, множенню двох функцій у часовій області відповідає згортка їхніх спектральних характеристик у частотній області:

```
Xs(f) = X(f) * P(f)   [теорема про згортку у частотній області]
```

де `X(f)` — перетворення Фур'є від аналогового сигналу `x(t)`, а `P(f)` — перетворення Фур'є від гребінця Дірака `p(t)`.

За формулою підсумовування Пуассона (*Poisson summation formula*), перетворення Фур'є періодичного гребінця Дірака з періодом `Ts` у часі є також гребінцем Дірака у частотній області з періодом `fs = 1 / Ts` та масштабним коефіцієнтом `fs`:

```
P(f) = fs · ∑ δ(f - k·fs)  [сумування від k = -∞ до +∞]
```

Обчислюючи згортку `X(f)` із гребінцем `P(f)`, отримуємо підсумковий вираз для спектра дискретизованого сигналу:

```
Xs(f) = X(f) * [ fs · ∑ δ(f - k·fs) ]  [підставили спектр P(f)]
      = fs · ∑ [ X(f) * δ(f - k·fs) ]  [дистрибутивність операції згортки]
      = fs · ∑ X(f - k·fs)             [згортка з дельта-функцією дає зсув]
```

Цей вираз доводить фундаментальний факт спектрального аналізу: дискретизація сигналу в часі спричиняє періодичне розмноження його спектра. Первинний спектр `X(f)` нескінченно дублюється з кроком `fs`, створюючи дзеркальні образи (*images*) довкола частот `... -2·fs, -fs, 0, +fs, +2·fs ...`.

## 2. Спектральна фільтрація: ідеальний прямокутний ФНЧ

Нехай початковий сигнал `x(t)` мав обмежений спектр (*band-limited signal*). Це означає, що існує гранична частота `fmax` така, що:

```
X(f) = 0   [умова обмеженості спектра для |f| > fmax]
```

Якщо частота дискретизації відповідає умові Найквіста `fs > 2·fmax`, то найвища частота фундаментальної смуги `fmax` є меншою за `fs / 2`. За цієї умови дзеркальні копії спектрів `X(f - k·fs)` у сумі `Xs(f)` знаходяться на достатній відстані одна від одної й повністю розділені у частотному просторі, не перекриваючись між собою.

Для того щоб повністю відновити первинний аналоговий спектр `X(f)` із періодичного сумарного спектра `Xs(f)`, необхідно ізолювати лише центральну смугу в інтервалі `[-fs/2, +fs/2]` і повністю ліквідувати всі високочастотні дзеркальні копії при `k ≠ 0`.

Цю операцію виконує ідеальний прямокутний фільтр низьких частот із коефіцієнтом передачі `H(f)`:

```
        ┌ Ts,  якщо |f| ≤ fs/2
H(f) = ─┤                       [коефіцієнт передачі ФНЧ]
        └ 0,   якщо |f| > fs/2
```

Помноживши періодичний спектр `Xs(f)` на характеристику фільтра `H(f)`, отримуємо спектр відновленого сигналу `Xr(f)`:

```
Xr(f) = Xs(f) · H(f)                   [спектральна фільтрація]
      = [ fs · ∑ X(f - k·fs) ] · H(f)  [підставили суму спектрів Xs(f)]
```

Оскільки для `k = 0` вираз `H(f) = Ts = 1 / fs`, а для всіх інших `k ≠ 0` функція `H(f)` дорівнює нулю у відповідних діапазонах частот, у добутку залишається лише один перший доданок при `k = 0`:

```
Xr(f) = fs · X(f) · (1 / fs)    [зрізали всі дзеркальні копії при k ≠ 0]
      = X(f)                    [скоротили fs та 1/fs]
```

Таким чином, спектр відновленого сигналу `Xr(f)` є абсолютно ідентичним початковому спектру `X(f)` без будь-яких спотворень.

## 3. Зворотне перетворення Фур'є та виведення імпульсної характеристики

Щоб з'ясувати, як ця спектральна операція виглядає в часовому просторі, обчислимо зворотне перетворення Фур'є від прямокутної характеристики фільтра `H(f)`. За означенням:

```
h(t) = ∫ H(f) · e^(j·2·pi·f·t) df  [зворотне перетворення Фур'є від -∞ до +∞]
```

Підставляємо межі пропускання ідеального фільтра від `-fs/2` до `+fs/2`, де `H(f) = Ts`:

```
h(t) = Ts · ∫ e^(j·2·pi·f·t) df  [інтегрування від -fs/2 до +fs/2]
```

Обчислюємо визначений інтеграл від показниковій функції:

```
h(t) = Ts · [ e^(j·2·pi·f·t) / (j·2·pi·t) ]   [первісна від -fs/2 до +fs/2]
     = Ts · [ e^(j·pi·fs·t) - e^(-j·pi·fs·t) ] / (j·2·pi·t) [підставили межі]
```

За формулою Ейлера `e^(j·θ) - e^(-j·θ) = 2·j·sin(θ)`. Підставляючи це співвідношення у вираз, маємо:

```
h(t) = Ts · [ 2·j · sin(pi·fs·t) ] / (j·2·pi·t)  [за формулою Ейлера]
     = Ts · sin(pi·fs·t) / (pi·t)               [скоротили 2*j]
```

Враховуючи, що `Ts = 1 / fs`, можна внести `fs` у знаменник дробу:

```
h(t) = sin(pi·fs·t) / (pi·fs·t)   [перенесли Ts у знаменник як fs]
```

Ця функція є нормалізованим кардинальним синусом:

```
h(t) = sinc(fs · t) = sinc(t / Ts)  [означення кардинального синуса]
```

Імпульсна характеристика `h(t)` показує відгук ідеального аналогового ФНЧ у часі на один нескінченно вузький вхідний дельта-імпульс одиничної площі.

## 4. Підсумкова формула інтерполяції Віттакера-Котельникова-Шеннона

Оскільки у частотній області спектр відновленого сигналу є добутком `Xr(f) = Xs(f) · H(f)`, у часовій області відновлений сигнал `x(t)` є математичною згорткою дискретизованого сигналу `xs(t)` з імпульсною характеристикою `h(t)`:

```
x(t) = xs(t) * h(t)                    [згортка у часовій області]
     = ∫ xs(τ) · h(t - τ) dτ           [визначення операції згортки]
```

Підставимо вираз для `xs(τ) = ∑ x[n] · δ(τ - n·Ts)` під знак інтеграла:

```
x(t) = ∫ [ ∑ x[n] · δ(τ - n·Ts) ] · h(t - τ) dτ [підставили дискретизований сигнал]
     = ∑ x[n] · ∫ δ(τ - n·Ts) · h(t - τ) dτ     [винесли суму за знак інтеграла]
```

За фільтруючою властивістю дельта-функції Дірака `∫ δ(τ - τ₀) · f(τ) dτ = f(τ₀)`, інтеграл від зсунутої дельта-функції просто вибирає значення функції `h` у точці `τ = n·Ts`:

```
x(t) = ∑ x[n] · h(t - n·Ts)  [за фільтруючою властивістю дельта-функції]
```

Підставляючи раніше виведену імпульсну характеристику `h(t) = sinc(t / Ts)`, отримуємо строкове формульне подання інтерполяційного ряду:

```
x(t) = ∑ x[n] · sinc( (t - n·Ts) / Ts )  [формула Віттакера-Котельникова-Шеннона]
```

Це і є знаменита **формула відновлення Віттакера-Котельникова-Шеннона**. Вона доводить, що будь-який безперервний сигнал із обмеженим спектром є лінійною комбінацією зсунутих у часі кардинальних синусів, де коефіцієнтами розкладу виступають дискретні відліки `x[n]`.

## 5. Властивості функцій sinc та ортогональність у просторі L²

Причина, чому формула відновлення є точним аналітичним розкладом без втрат, полягає у виняткових алгебраїчних та функціональних властивостях базисних функцій `sinc`.

### Нульова міжсимвольна інтерференція (Перший критерій Найквіста)

Розглянемо значення функції `sinc(t / Ts - n)` у момент часу, що відповідає іншому відліку `t = m·Ts` (де `m` та `n` — цілі числа):

```
sinc( (m·Ts - n·Ts) / Ts ) = sinc(m - n)  [скоротили крок дискретизації Ts]
```

За означенням нормалізованого кардинального синуса:

```
            ┌ 1,  якщо m = n                             [при m = n: sinc(0) = 1]
sinc(m - n) = ─┤
            └ sin(pi · (m - n)) / (pi · (m - n)) = 0,   [при m ≠ n: sin(pi*k) = 0]
```

Оскільки для будь-якого цілого різниці `k = m - n ≠ 0` чисельник `sin(pi · k)` строго дорівнює нулю, функція `sinc` звертається в нуль у всіх точках дискретизації, крім своєї власної.

Це означає, що при підстановці моментів часу `t = m·Ts` у загальну формулу відновлення:

```
x(m·Ts) = ∑ x[n] · sinc(m - n)         [підставили t = m*Ts]
        = x[m] · 1 + ∑ [ x[n] · 0 ]    [всі доданки при n ≠ m дорівнюють 0]
        = x[m]                         [підсумкове значення точно дорівнює відліку]
```

Значення відновленої неперервної функції `x(t)` у точках дискретизації строго збігаються з вихідними числами масиву `x[m]`. Чужі відліки не створюють жодних перешкод у мить зчитування.

### Ортогональність базисних функцій

Послідовність зсунутих функцій `φ_n(t) = sinc(t / Ts - n)` утворює ортогональний базис у просторі функцій із квадратним інтегруванням `L²(-∞, +∞)`. Обчислимо скалярний добуток двох різних базисних функцій `φ_n(t)` та `φ_m(t)`:

```
⟨ φ_n, φ_m ⟩ = ∫ sinc(t/Ts - n) · sinc(t/Ts - m) dt  [скалярний добуток в L2]
```

За теоремою Парсеваля, скалярний добуток функцій у часовій області дорівнює скалярному добутку їхніх перетворень Фур'є у частотній області. Спектром функції `sinc(t/Ts - n)` є прямокутне вікно з фазовим множником:

```
Ф_n(f) = Ts · e^(-j · 2·pi · f · n·Ts)   [спектр зсунутого sinc для |f| ≤ fs/2]
```

Обчислюємо інтеграл у частотній області:

```
⟨ φ_n, φ_m ⟩ = ∫ Ф_n(f) · Ф_m*(f) df  [за теоремою Парсеваля від -fs/2 до +fs/2]
             = ∫ [ Ts · e^(-j·2·pi·f·n·Ts) ] · [ Ts · e^(+j·2·pi·f·m·Ts) ] df [підставили Ф_n та Ф_m*]
             = Ts² · ∫ e^(j·2·pi·f·(m - n)·Ts) df  [об'єднали показники експонент]
```

При `n = m` підінтегральний вираз дорівнює `1`, і інтеграл дає:

```
⟨ φ_n, φ_n ⟩ = Ts² · (fs)               [інтеграл від 1 по довжині fs]
             = Ts² · (1 / Ts) = Ts      [скоротили Ts]
```

При `n ≠ m` інтеграл від періодичної експоненти по повному періоду `fs` дорівнює строго `0`. Отже:

```
∫ sinc(t/Ts - n) · sinc(t/Ts - m) dt = Ts · δ[n - m]  [умова ортогональності базису]
```

де `δ[n - m]` — символ Кронекера. Ця ортогональність гарантує, що розклад сигналу за `sinc`-базисом є єдиним і мінімізує середньоквадратичну похибку при обрізанні ряду.

## 6. Аналіз математичних похибок практичної інтерполяції

Оскільки нескінченний ряд `sinc` неможливо обчислити на практиці, його обрізають до скінченної кількості `2·N` відліків. Розглянемо математичні наслідки такого обрізання.

### Ефект Гіббса при усіченні прямокутним вікном

Обрізання ряду відліків еквівалентне множенню нескінченного `sinc`-фільтра на прямокутне вікно тривалістю `2·N·Ts`. У частотній області це множення перетворюється на згортку ідеального прямокутного спектра із відгуком вікна.

Внаслідок згортки на спектрі виникають осциляції (спектральний витік, *spectral leakage*), а в часовій області біля різких перепадів сигналу (наприклад, ступенчастих стрибків напруги) виникають осциляційні викиди амплітуди. 

Максимальна величина першого амплітудного викиду при ступенчатому перепаді не прямує до нуля навіть при збільшенні кількості відліків `N` і становить приблизно **8.95% від висоти стрибка**. Це і є класичний математичний ефект Гіббса.

### Застосування загладжуючих вікон (Lanczos, Hamming)

Щоб придушити пульсації Гіббса, функцію `sinc(t)` множать на плавну віконну функцію `w(t)`, яка плавно зменшує амплітуду хвостів до нуля на межах вікна `|t| = a·Ts`.

Найбільш поширеним у DSP є вікно Ланцоша (*Lanczos window*), де сама віконна функція також обрана у формі масштабованого кардинального синуса:

```
w_lanczos(x) = sinc(x / a)   [для |x| < a, і 0 для |x| ≥ a]
```

Підсумкове ядро інтерполяції Ланцоша радіуса `a` має вираз:

```
L(x) = sinc(x) · sinc(x / a)   [ядро Ланцоша для |x| < a]
```

Завдяки квадратичному згасанню чисельника `sin(pi·x) · sin(pi·x / a)` амплітуда бічних пелюсток у частотній області спадає зі швидкістю `1 / f²` замість `1 / f`, що зменшує рівень пульсацій Гіббса з `-13 дБ` до менш ніж `-50...-80 дБ`.

## 7. Спектральний аналіз відгуку ЦАП із фіксатором ZOH

Наостанок виведемо точний передавальний коефіцієнт апаратного ЦАП із фіксатором нульового порядку (ZOH). 

ZOH перетворює кожен відлік `x[n]` на прямокутний імпульс амплітудою `x[n]` і тривалістю `Ts`. Його імпульсна характеристика у часовій області є прямокутником `rect(t)`:

```
h_zoh(t) = 1  [для 0 ≤ t < Ts, і 0 для всіх інших t]
```

Обчислимо пряме перетворення Фур'є від `h_zoh(t)`:

```
H_zoh(f) = ∫ 1 · e^(-j·2·pi·f·t) dt             [пряме перетворення Фур'є від 0 до Ts]
         = [ e^(-j·2·pi·f·t) / (-j·2·pi·f) ]    [первісна у межах від 0 до Ts]
         = [ 1 - e^(-j·2·pi·f·Ts) ] / (j·2·pi·f) [підставили верхню й нижню межі]
```

Винесемо півфазовий множник `e^(-j·pi·f·Ts)` за дужки:

```
H_zoh(f) = e^(-j·pi·f·Ts) · [ e^(j·pi·f·Ts) - e^(-j·pi·f·Ts) ] / (j·2·pi·f) [винесли півфазу]
```

Використовуючи тотожність `e^(j·θ) - e^(-j·θ) = 2·j·sin(θ)`:

```
H_zoh(f) = e^(-j·pi·f·Ts) · [ 2·j · sin(pi·f·Ts) ] / (j·2·pi·f)  [за тотожністю Ейлера]
         = Ts · e^(-j·pi·f·Ts) · sin(pi·f·Ts) / (pi·f·Ts)       [перегрупували множники]
         = Ts · sinc(f · Ts) · e^(-j · pi · f · Ts)             [через функцію sinc]
```

Отриманий вираз складається з трьох множників:
1. `Ts` — постійний масштабний коефіцієнт посилення ЦАП.
2. `sinc(f · Ts)` — амплітудно-частотна характеристика (АЧХ), яка спричиняє спад високих частот у корисній смузі (sinc roll-off).
3. `e^(-j · pi · f · Ts)` — лінійна фазово-частотна характеристика (ФЧХ), що відповідає чистому запізненню сигналу на половину періоду дискретизації `Ts / 2`.

Обчислимо величину амплітудного затухання ZOH на межі Найквіста `f = fs / 2 = 1 / (2·Ts)`:

```
|H_zoh(fs/2)| / Ts = sinc( (fs/2) · (1/fs) )  [підставили f = fs/2]
                    = sinc(1/2)                 [скоротили fs]
                    = sin(pi / 2) / (pi / 2)    [за означенням sinc]
                    = 1 / (pi / 2)              [врахували sin(pi/2) = 1]
                    = 2 / pi                    [перевернули дріб]
                    ≈ 0.636619                  [обчислили значення]
```

Переведемо отримане затухання в децибели:

```
20 · log10(2 / pi) = 20 · log10(0.636619)      [формула переведення в децибели]
                   = 20 · (-0.1961)             [значення логарифма]
                   ≈ -3.922 дБ                  [підсумкове затухання у дБ]
```

Це суворе математичне доведення показує, що будь-який ступенчастий ЦАП послаблює амплітуду високих частот на межі Найквіста на **3.92 дБ**. Саме тому в прецизійному аудіообладнанні та вимірювальних цифро-аналогових трактах застосовують цифровий компенсаційний фільтр з АЧХ `1 / sinc(f·Ts)` перед ЦАП або підвищують частоту дискретизації методом oversampling.
