# 🧮 Математика й геометрія сіток субдискретизації

У цій вставці виведено просторові частоти Найквіста для колірних каналів, математичні відношення обсягів буферів пам'яті, коефіцієнти просторового розташування відліків (фазування), динамічні діапазони квантування та матричні рівняння RGB ↔ YCbCr для стандартів BT.601, BT.709 та BT.2020.

### 1. Лінійна алгебра колірних просторів: RGB у YCbCr

Перш ніж проводити просторову децимацію відліків, вхідний трикомпонентний сигнал у просторі RGB перетворюється у декорельований простір YCbCr, де яскравість відокремлена від колірнорізничних компонентів.

Загальне лінійне перетворення задається матричним рівнянням:

```
[ Y  ]   [  w_r        w_g        w_b     ]   [ R ]
[ Cb ] = [ -w_r/C_b   -w_g/C_b    0.5     ] · [ G ] + [   0 ]
[ Cr ]   [  0.5       -w_g/C_r   -w_b/C_r ]   [ B ]   [ 128 ]
```

де `w_r`, `w_g`, `w_b` — вагові коефіцієнти фотометричної яскравості люмінофорів, причому `w_r + w_g + w_b = 1`, а нормувальні дільники дорівнюють `C_b = 2·(1 - w_b)` та `C_r = 2·(1 - w_r)`.

#### Стандарт ITU-R BT.601 (SDTV / Застаріле аналогове та цифрове ТБ):
Коефіцієнти фотометричної чутливості: `w_r = 0.299`, `w_g = 0.587`, `w_b = 0.114`.

Матриця прямого перетворення для 8-бітних значень:
```
Y  =  0.299000·R + 0.587000·G + 0.114000·B
Cb = -0.168736·R - 0.331264·G + 0.500000·B + 128
Cr =  0.500000·R - 0.418688·G - 0.081312·B + 128
```

#### Стандарт ITU-R BT.709 (HDTV / FullHD / Монітори ПК / Веб):
Коефіцієнти для люмінофорів сучасних LCD/OLED дисплеїв: `w_r = 0.2126`, `w_g = 0.7152`, `w_b = 0.0722`.

```
Y  =  0.212600·R + 0.715200·G + 0.072200·B
Cb = -0.114572·R - 0.385428·G + 0.500000·B + 128
Cr =  0.500000·R - 0.454153·G - 0.045847·B + 128
```

#### Стандарт ITU-R BT.2020 (UltraHD 4K/8K та 10/12-біт HDR):
Розширене колірне охоплення (Wide Color Gamut): `w_r = 0.2627`, `w_g = 0.6780`, `w_b = 0.0593`.

```
Y  =  0.262700·R + 0.678000·G + 0.059300·B
Cb = -0.139630·R - 0.360370·G + 0.500000·B + 512  (для 10 біт)
Cr =  0.500000·R - 0.435161·G - 0.064839·B + 512  (для 10 біт)
```

Додавання константи `128` (або `512` у 10-бітних системах) зміщує діапазон колірнорізничних компонентів `Cb` та `Cr` у позитивну область `[0 … 255]` з центром у точці `128` (ахроматичний сірий колір, відсутність кольоровості).

Зворотне перетворення з YCbCr у RGB для стандарту BT.709 обчислюється розв'язком оберненої матриці:

```
R = Y + 1.574800·(Cr - 128)
G = Y - 0.187324·(Cb - 128) - 0.468124·(Cr - 128)
B = Y + 1.855600·(Cb - 128)
```

#### Обмежений проти повного динамічного діапазону (Limited vs Full Range)
У комп'ютерній графіці (Full Range / PC Range) усі компоненти `Y`, `Cb`, `Cr` займають повний 8-бітний діапазон `[0 … 255]`.

У телевізійному мовленні (Limited Range / TV Range) задіяно захисні інтервали для запобігання викидам сигналу:
- Канал яркості `Y` масштабується в діапазон `[16 … 235]` (загалом 220 рівнів).
- Колірні канали `Cb`, `Cr` масштабуються в діапазон `[16 … 240]` з центром у точці `128` (загалом 225 рівнів).

Математичний перехід із TV Range у PC Range для яркості виконується за формулою:
```
Y_full = (Y_limited - 16) · 255 / 219
```

### 2. Просторові частоти Найквіста для яркості та хроматеми

Розглянемо двовимірну просторову дискретизацію кадру шириною `W` та висотою `H` пікселів.

Позначимо просторову частоту дискретизації каналу яркості вздовж горизонтальної осі через `fx_y = 1` відлік/піксель, а вздовж вертикальної осі — через `fy_y = 1` відлік/піксель.

Згідно з двовимірною теоремою Найквіста-Котельникова, максимальна просторова частота, яка може бути відтворена без аліасингу в каналі яркості, визначається межею спектральної зони:

```
f_nyq_x(Y) = fx_y / 2 = 0.5  циклів/піксель
f_nyq_y(Y) = fy_y / 2 = 0.5  циклів/піксель
```

При проведенні субдискретизації сітка колірних відліків `Cb` та `Cr` розріджується:

**Для формату 4:2:2:**
- Горизонтальна частота відліків: `fx_c = 0.5` відліків/піксель.
- Вертикальна частота відліків: `fy_c = 1.0` відлік/піксель.
- Межа Найквіста кольору: `f_nyq_x(C) = 0.25` циклів/піксель, `f_nyq_y(C) = 0.5` циклів/піксель.

**Для формату 4:2:0:**
- Горизонтальна частота відліків: `fx_c = 0.5` відліків/піксель.
- Вертикальна частота відліків: `fy_c = 0.5` відліків/піксель.
- Межа Найквіста кольору: `f_nyq_x(C) = 0.25` циклів/піксель, `f_nyq_y(C) = 0.25` циклів/піксель.

Це означає, що будь-яка колірна деталь (наприклад, чергування червоних і синіх ліній), яка змінюється частіше ніж раз на 4 пікселі, перевищує межу `f_nyq_x(C) = 0.25` і при субдискретизації 4:2:0 неминуче утворює просторовий аліасинг, якщо перед децимацією не застосувати двовимірний ФНЧ.

### 3. Формули обсягу даних та середньої бітової щільності

Для кадру розміром `W × H` пікселів із глибиною кодування `b` біт на відлік (наприклад, `b = 8` або `b = 10` біт):

**Формат 4:4:4:**
```
N_samples(Y)  = W · H
N_samples(Cb) = W · H
N_samples(Cr) = W · H
Загальний обсяг = 3 · W · H · b  бітів
Середня щільність (bpp) = 3 · b  біт/піксель
```

**Формат 4:2:2:**
```
N_samples(Y)  = W · H
N_samples(Cb) = (W / 2) · H
N_samples(Cr) = (W / 2) · H
Загальний обсяг = 2 · W · H · b  бітів
Середня щільність (bpp) = 2 · b  біт/піксель
Співвідношення стиснення = 2 / 3 ≈ 66.67% від 4:4:4
```

**Формат 4:2:0:**
```
N_samples(Y)  = W · H
N_samples(Cb) = (W / 2) · (H / 2) = (W · H) / 4
N_samples(Cr) = (W / 2) · (H / 2) = (W · H) / 4
Загальний обсяг = 1.5 · W · H · b  бітів
Середня щільність (bpp) = 1.5 · b  біт/піксель
Співвідношення стиснення = 1.5 / 3.0 = 50.0% від 4:4:4
```

### 4. Фазування відліків: просторовий зсув колірної сітки

Точні координати відліку `Cb(i, j)` та `Cr(i, j)` відносно сітки яркості `Y(x, y)` задаються правилами фазування стандарту.

Якщо `(x, y)` — цілочислові індекси пікселя Y (`x ∈ [0 … W-1]`, `y ∈ [0 … H-1]`), то координати колірного відліку `(i, j)` обчислюються так:

**Центральне фазування (Center-aligned / JPEG / WebP / MPEG-1):**
Колірний відлік розташований у геометричному центрі блоку 2×2 пікселів Y:
```
x_c = 2·i + 0.5
y_c = 2·j + 0.5
```

**Ліве фазування (Left-aligned / Interstitial / MPEG-2 / H.264 / H.265 progressive):**
Колірний відлік збігається по горизонталі з першою колонкою Y, а по вертикалі лежить посередині:
```
x_c = 2·i
y_c = 2·j + 0.5
```

Різниця в 0.5 пікселя між JPEG та H.264 вимагає коригування фази під час інтерполяції. Якщо декодер декодує H.264 відеопотік і приводить його до 4:4:4 за формулами центрального фазування, колірний шар зсувається на півпікселя праворуч, створюючи розмиття колірних контурів.

### 5. Похибка відновлення та спектральна оцінка білінійної інтерполяції

Під час зворотного відновлення сітки 4:4:4 з 4:2:0 білінійна інтерполяція діє як двовимірний згладжувальний ФНЧ із передавальною функцією:

```
H_interp(fx, fy) = (sinc(fx / fx_c) · sinc(fy / fy_c))²
```

Оскільки функція `sinc` не має прямокутного зрізу в частотній області, білінійна інтерполяція пригнічує високі просторові частоти кольору (викликаючи розмиття колірних меж) та пропускає залишки дзеркальних копій спектра вище за `f_nyq = 0.25`.

Для усунення цієї похибки в професійних кодеках використовують бікубічну інтерполяцію (з ядрами Мітчелла-Нетравалі або Ланцоша):

```
W_bicubic(x) = (a + 2)·|x|³ - (a + 3)·|x|² + 1,        для |x| ≤ 1
W_bicubic(x) = a·|x|³ - 5a·|x|² + 8a·|x| - 4a,          для 1 < |x| < 2
```

за значення коефіцієнта `a = -0.5`. Це зменшує похибку відновлення колірних меж більш ніж у 4 рази порівняно з простим білінійним усередненням.
