# 🧮 Вивід лінійного вирівнювача MMSE

Ця математична вставка містить суворий покроковий вивід оптимальної матриці ваг та частотного коефіцієнта лінійного вирівнювача за критерієм мінімуму середньоквадратичної помилки (Minimum Mean Square Error, MMSE). Вона показує, як принцип ортогональності, векторно-матричний аналіз та оптимізація квадратичної функції втрат природним чином ведуть до регулярного вирівнювача, що балансує між придушенням міжсимвольної інтерференції та посиленням шуму.

## 1. Постановка задачі та дискретна модель системи

Розглядається дискретна лінійна модель каналу зв'язку у векторно-матричній формі:

```
y = H·s + w
```

Де позначено математичні об'єкти та їхні статичні властивості:
- `s` — вектор переданих інформаційних символів розмірності `N × 1` із нульовим середнім `E[s] = 0` та кореляційною матрицею `R_ss = E[s·sᴴ] = σ_s² · I_N` (символи незалежні й однаково розподілені з потужністю `σ_s²`);
- `H` — матриця імпульсної характеристики каналу розмірності `M × N` (для часової FIR-моделі або багатоантенної системи MIMO);
- `w` — вектор аддитивного білого гаусового шуму (AWGN) розмірності `M × 1` із нульовим середнім `E[w] = 0` та кореляційною матрицею `R_ww = E[w·wᴴ] = σ_w² · I_M`;
- `y` — вектор прийнятих спотворених відліків розмірності `M × 1`;
- `·ᴴ` — оператор гермітового (комплексно-спряженого) транспонування.

Припускається, що корисний інформаційний сигнал `s` та аддитивний шум `w` є статистично незалежними випадковими векторами: `E[s·wᴴ] = 0` та `E[w·sᴴ] = 0`.

Лінійний оцінювач формує оцінку переданого вектора `s̄` шляхом множення прийнятого вектора `y` на матрицю вирівнювання `W` розмірності `N × M`:

```
s̄ = W · y
```

Вектор помилки оцінювання `e` розмірності `N × 1` визначено як різницю між оцінкою та істинним значенням:

```
e = s̄ - s = W·y - s
```

Цільовою функцією оптимізації MMSE є мінімізація слідів (Trace) матриці автокореляції помилки, що еквівалентно сумі середньоквадратичних помилок усіх компонент вектора `s`:

```
J(W) = E[||e||²] = E[Trace(e·eᴴ)]
```

## 2. Диференціювання функції втрат та числення Віртінгера

Для скалярної мінімізації квадратичної норми у комплекснозначному просторі скористаємося матричним численням Віртінгера (Wirtinger calculus), де комплексні змінні `W` та `W*` розглядаються як алгебраїчно незалежні аргументи.

Розкриємо функціонал середньоквадратичної помилки `J(W)` через скалярні та матричні добутки:

```
J(W) = E[ Trace( (W·y - s) · (W·y - s)ᴴ ) ]
     = E[ Trace( (W·y - s) · (yᴴ·Wᴴ - sᴴ) ) ]
     = E[ Trace( W·y·yᴴ·Wᴴ - W·y·sᴴ - s·yᴴ·Wᴴ + s·sᴴ ) ]
```

Завдяки лінійності операції оператора математичного сподівання `E[·]` та сліду матриці `Trace(·)` вираз розкладається на чотири доданки:

```
J(W) = Trace( W · E[y·yᴴ] · Wᴴ ) - Trace( W · E[y·sᴴ] ) - Trace( E[s·yᴴ] · Wᴴ ) + Trace( E[s·sᴴ] )
     = Trace( W · R_yy · Wᴴ ) - Trace( W · R_ys ) - Trace( R_sy · Wᴴ ) + Trace( R_ss )
```

Обчислимо матричний градієнт функціоналу `J(W)` по комплексно-спряженій матриці `W*` (або за транспонованою гермітовою матрицею `Wᴴ`), застосовуючи тотожності матричного диференціювання `∂ Trace(W A Wᴴ) / ∂ W* = W A` та `∂ Trace(B Wᴴ) / ∂ W* = B`:

```
∇_{W*} J(W) = ∂J / ∂W* = W · R_yy - R_sy
```

Прирівнюючи матричний градієнт до нульової матриці `0_N×M`, отримуємо фундаментальну умову стаціонарності та мінімуму квадратичної помилки:

```
W · R_yy - R_sy = 0
⇒ W · R_yy = R_sy
```

Це рівняння повністю збігається з матричним рівнянням Вінера-Хоффа.

## 3. Застосування принципу ортогональності Вінера-Хоффа

Альтернативним та геометрично наочним способом виводу є принцип ортогональної проекції (принцип ортогональності Вінера-Хоффа). 

Згідно з теоремою про ортогональну проекцію у гіперпросторі випадкових векторів зі скалярним добутком `⟨u, v⟩ = E[u·v*]`, квадратичний функціонал помилки `J(W)` досягає свого єдиного глобального мінімуму тоді й лише тоді, коли вектор помилки `e` є ортогональним до прийнятого вектора спостережень `y` у сенсі математичного сподівання:

```
E[e · yᴴ] = 0_N×M
```

Підставимо вираз для вектора помилки `e = W·y - s` у умову ортогональності:

```
E[(W·y - s) · yᴴ] = 0
E[W·y·yᴴ - s·yᴴ] = 0            [розкриття дужок у матричному добутку]
W · E[y·yᴴ] - E[s·yᴴ] = 0        [винесення лінійного оператора W за знак E[·]]
```

Звідси знову отримуємо рівняння Вінера-Хоффа:

```
W · R_yy = R_sy
```

Де кореляційні матриці визначено як:
- `R_yy = E[y·yᴴ]` — автокореляційна матриця прийнятого сигналу розмірності `M × M`;
- `R_sy = E[s·yᴴ]` — взаємнокореляційна матриця між корисним сигналом та спостереженнями розмірності `N × M`.

## 4. Явний обчислювальний вивід кореляційних матриць

Обчислимо матрицю `R_yy`, підставивши явну модель каналу `y = H·s + w`:

```
R_yy = E[(H·s + w) · (H·s + w)ᴴ]
     = E[(H·s + w) · (sᴴ·Hᴴ + wᴴ)]
     = E[H·s·sᴴ·Hᴴ + H·s·wᴴ + w·sᴴ·Hᴴ + w·wᴴ]     [розкриття множення блоків]
     = H·E[s·sᴴ]·Hᴴ + H·E[s·wᴴ] + E[w·sᴴ]·Hᴴ + E[w·wᴴ] [винесення детермінованої матриці H]
```

Враховуючи статистичну незалежність `s` та `w` (`E[s·wᴴ] = 0`), а також значення автокореляцій `E[s·sᴴ] = σ_s²·I_N` та `E[w·wᴴ] = σ_w²·I_M`:

```
R_yy = H · (σ_s² · I_N) · Hᴴ + σ_w² · I_M
     = σ_s² · H·Hᴴ + σ_w² · I_M
```

Тепер обчислимо взаємнокореляційну матрицю `R_sy`:

```
R_sy = E[s · (H·s + w)ᴴ]
     = E[s · (sᴴ·Hᴴ + wᴴ)]
     = E[s·sᴴ·Hᴴ + s·wᴴ]
     = E[s·sᴴ]·Hᴴ + E[s·wᴴ]
     = (σ_s² · I_N) · Hᴴ + 0
     = σ_s² · Hᴴ
```

## 5. Алгебраїчний вивід оптимальної матриці MMSE та тотожність Вудбері

Підставимо отримані вирази для `R_yy` та `R_sy` у рівняння Вінера-Хоффа `W · R_yy = R_sy`:

```
W · (σ_s² · H·Hᴴ + σ_w² · I_M) = σ_s² · Hᴴ
```

Оскільки матриця `(σ_s² · H·Hᴴ + σ_w² · I_M)` є строго додатно визначеною для будь-якого `σ_w² > 0`, вона є строго невиродженою та оборотною. Помножимо обидві частини рівняння справа на обернену матрицю:

```
W_mmse = σ_s² · Hᴴ · (σ_s² · H·Hᴴ + σ_w² · I_M)⁻¹
```

Винесемо множник `σ_s²` із дужок у знаменнику/оберненій матриці:

```
W_mmse = σ_s² · Hᴴ · [ σ_s² · (H·Hᴴ + (σ_w² / σ_s²) · I_M) ]⁻¹
       = σ_s² · Hᴴ · (1 / σ_s²) · (H·Hᴴ + (σ_w² / σ_s²) · I_M)⁻¹
       = Hᴴ · (H·Hᴴ + (σ_w² / σ_s²) · I_M)⁻¹
```

Ця форма розв'язку вимагає обернення матриці розмірності `M × M` (за кількістю прийнятих відліків). Доведемо її еквівалентність формі `N × N` за допомогою тотожності Мура-Вудбері.

Запишемо матричну тотожність:

```
(Hᴴ·H + γ·I_N) · Hᴴ = Hᴴ·H·Hᴴ + γ·Hᴴ
                     = Hᴴ · (H·Hᴴ + γ·I_M)
```

Помножимо отриману рівність зліва на `(Hᴴ·H + γ·I_N)⁻¹`, а справа на `(H·Hᴴ + γ·I_M)⁻¹`:

```
(Hᴴ·H + γ·I_N)⁻¹ · [ (Hᴴ·H + γ·I_N) · Hᴴ ] · (H·Hᴴ + γ·I_M)⁻¹
= (Hᴴ·H + γ·I_N)⁻¹ · [ Hᴴ · (H·Hᴴ + γ·I_M) ] · (H·Hᴴ + γ·I_M)⁻¹
```

Спрощуючи добутки обернених матриць на ідентичні зліва та справа, отримуємо тотожність Пуш-Тру (Push-Through Identity):

```
Hᴴ · (H·Hᴴ + γ·I_M)⁻¹ = (Hᴴ·H + γ·I_N)⁻¹ · Hᴴ
```

Покладаючи `γ = σ_w² / σ_s² = 1 / SNR`, ми можемо переписати розв'язок через обернення матриці розмірності `N × N` (за кількістю переданих символів):

```
W_mmse = (Hᴴ·H + (σ_w² / σ_s²) · I_N)⁻¹ · Hᴴ
```

Враховуючи, що відношення потужності шуму до потужності сигналу є оберненою величиною до SNR (`1 / SNR = σ_w² / σ_s²`), отримуємо остаточну компактну матричну формулу лінійного вирівнювача MMSE:

```
W_mmse = (Hᴴ·H + (1 / SNR) · I_N)⁻¹ · Hᴴ
```

## 6. Частотна форма вирівнювача MMSE для OFDM та SC-FDE

У широкосмугових системах із мультикарієрною модуляцією (OFDM) або систем із частотним вирівнюванням на одній несучій (SC-FDE) циклічний префікс діагоналізує матрицю каналу `H`. Матриця `H` стає діагональною матрицею `Diag(H[0], H[1], ..., H[N-1])`, де `H[k]` — значення комплексного коефіцієнта передачі каналу на підканалі `k`.

Матричний добуток `Hᴴ·H` перетворюється на діагональну матрицю з елементами `|H[k]|² = H[k] · H*[k]`. У результаті векторно-матричне рівняння MMSE повністю розпадається на `N` незалежних скалярних рівнянь для кожного підканалу `k`:

```
W_mmse[k] = H*[k] / (|H[k]|² + σ_w² / σ_s²)
          = H*[k] / (|H[k]|² + 1 / SNR)
```

Де `H*[k]` — комплексно-спряжений коефіцієнт передачі каналу на підканалі `k`.

## 7. Вивід залишкової середньоквадратичної помилки

Обчислимо кореляційну матрицю помилки `K_ee = E[e·eᴴ]` для вирівнювача MMSE:

```
K_ee = E[(W·y - s) · (W·y - s)ᴴ]
     = W · E[y·yᴴ] · Wᴴ - W · E[y·sᴴ] - E[s·yᴴ] · Wᴴ + E[s·sᴴ]
     = W · R_yy · Wᴴ - W · R_ys - R_sy · Wᴴ + R_ss
```

Підставивши умову Вінера-Хоффа `W · R_yy = R_sy` (та відповідно `R_yy · Wᴴ = R_ys`):

```
K_ee = R_sy · Wᴴ - R_sy · Wᴴ - R_sy · Wᴴ + R_ss
     = R_ss - R_sy · Wᴴ
```

Підставивши вирази `R_ss = σ_s² · I_N`, `R_sy = σ_s² · Hᴴ` та `W_mmseᴴ = H · (H·Hᴴ + (1/SNR)·I)⁻¹`:

```
K_ee = σ_s² · I_N - σ_s² · Hᴴ · (H·Hᴴ + (1/SNR)·I)⁻¹ · H
     = σ_s² · [ I_N - (Hᴴ·H + (1/SNR)·I_N)⁻¹ · Hᴴ·H ]
     = σ_s² · (I_N + SNR · Hᴴ·H)⁻¹
```

У частотній області для окремого підканалу `k` залишкова дисперсія помилки `MSE_mmse[k]` дорівнює відповідному скалярному елементу діагоналі матриці `K_ee`:

```
MSE_mmse[k] = σ_s² / (1 + SNR · |H[k]|²)
```

Для порівняння, залишкова помилка для вирівнювача Zero-Forcing становить:

```
MSE_zf[k] = σ_w² / |H[k]|² = σ_s² / (SNR · |H[k]|²)
```

Порівняння двох виразів показує:
- Оскільки `1 + SNR · |H[k]|² > SNR · |H[k]|²`, значення `MSE_mmse[k]` є строго меншим за `MSE_zf[k]` для будь-яких скінченних відношень сигнал/шум;
- При `|H[k]| → 0` залишкова помилка Zero-Forcing прямує до безкінечності (`MSE_zf → ∞`), тоді як залишкова помилка MMSE безпечно обмежується величиною `σ_s²` (потужністю корисного сигналу).

## 8. Амплітудний зсув та Unbiased MMSE

Проаналізуємо математичне сподівання відновленого символу `S̄_mmse[k] = W_mmse[k] · Y[k]`:

```
E[S̄_mmse[k]] = E[W_mmse[k] · (H[k]·S[k] + W[k])]
              = W_mmse[k] · H[k] · S[k]  +  0
              = [ H*[k] · H[k] / (|H[k]|² + 1/SNR) ] · S[k]
              = [ |H[k]|² / (|H[k]|² + 1/SNR) ] · S[k]
              = α[k] · S[k]
```

Оскільки `1/SNR > 0`, коефіцієнт масштабування `α[k]` строго менший за одиницю: `α[k] < 1`. Це означає, що класична оцінка MMSE є амплітудно-зсунутою (biased estimator). 

Для нейтралізації цього зсуву перед пороговим рішенням у демодуляторі застосовують незсунутий вирівнювач MMSE (Unbiased MMSE Filter):

```
W_unbiased[k] = W_mmse[k] / α[k]
              = H*[k] / |H[k]|²  ·  [ 1 / (1 + 1 / (SNR · |H[k]|²)) ]
```

Оцінка `S̄_unbiased[k] = W_unbiased[k] · Y[k]` має математичне сподівання `E[S̄_unbiased[k]] = S[k]`, що гарантує збереження ідеальних порогових меж прийняття рішень для багатопозиційних сузір'їв 16-QAM/64-QAM/256-QAM.

## 9. Вплив помилок оцінки каналу (Robustness to Channel Estimation Errors)

У реальних приймачах характеристика каналу `H` не є ідеально відомою і оцінюється за пилотними символами з помилкою `ΔH`:

```
H_est = H + ΔH
```

Де `ΔH` — матриця помилки оцінки з коефіцієнтом дисперсії `σ_e²`.

Для вирівнювача Zero-Forcing помилка оцінки `ΔH` вноситься у знаменник `1 / H_est[k]`. В районі спектральних нулів (`|H[k]| → 0`) флуктуації `ΔH[k]` викликають хаотичний вибух коефіцієнта підсилення, що призводить до деградації системи.

Для вирівнювача MMSE доданок регуляризації `1/SNR` відіграє роль демпфера. Оцінка ваг MMSE за наявності помилок оцінки каналу бере вигляд:

```
W_mmse_robust = H_est* / (|H_est|² + σ_w² / σ_s² + σ_e²)
```

Додавання дисперсії помилки каналу `σ_e²` у знаменник додатково стабілізує коефіцієнти фільтра, забезпечуючи високу стійкість (robustness) MMSE-вирівнювача до недосконалостей алгоритмів оцінки каналу в реальних DSP-системах.
