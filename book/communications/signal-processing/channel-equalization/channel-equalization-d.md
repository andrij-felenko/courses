Коли цифровий потік зі швидкістю 100 Мбіт/с передається через реальне середовище — мідну кручену пару довжиною 50 метрів або бездротовий радіоканал діапазону 2.4 ГГц — фізичне середовище діє як лінійний фільтр із обмеженою смугою пропускання та багатопроменевим поширенням. Амплітудно-частотна характеристика такого каналу має нерівномірне згасання, а фазова характеристика — нелінійність. В результаті прямокутний або піднятий косинусоїдальний імпульс тривалістю 10 наносекунд розпливається у часі на 30–50 наносекунд, а його згасаючі хвости накладаються на десятки сусідніх символів. Це явище зветься міжсимвольною інтерференцією (Inter-Symbol Interference, ISI). Без спеціальних заходів відновлення сигналу на приймачі ймовірність бітової помилки (BER) упирається в непереборну підлогу (error floor) на рівні 10⁻¹–10⁻², роблячи зв'язок непридатним незалежно від підведення якої завгодно високої потужності передавача.

Двома фундаментальними алгоритмами цифрового усунення ISI є вирівнювач Zero-Forcing (ZF) та вирівнювач за критерієм мінімуму середньоквадратичної помилки (Minimum Mean Square Error, MMSE). Перший намагається повністю інвертувати викривлення каналу, але наражається на катастрофічне посилення шуму, тоді як другий шукає строго оптимальний математичний компроміс між скасуванням інтерференції та збереженням рівня шуму.

## 1. Фізика викривлення каналу та міжсимвольна інтерференція (ISI)

Передача дискретних символів `s[n]` через фізичний канал описується операцією дискретної лінійної згортки послідовності символів із імпульсною характеристикою каналу `h[n]`. Приймач отримує сигнал `y[n]`, який додатково спотворений аддитивним білим гаусовим шумом (AWGN) `w[n]`:

```
y[n] = (h * s)[n] + w[n]
     = ∑_{k=0}^{L-1} h[k] · s[n - k] + w[n]
     = h[0]·s[n] + ∑_{k=1}^{L-1} h[k]·s[n - k] + w[n]
```

У цьому рівнянні сума чітко розділяється на три фізичні складові:
1. `h[0] · s[n]` — корисний символ, який приймач намагається детектувати у момент часу `n`;
2. `∑_{k=1}^{L-1} h[k] · s[n - k]` — міжсимвольна інтерференція (ISI), тобто сума залишків попередніх `L - 1` символів, які розширилися в часі через дисперсію каналу;
3. `w[n]` — флуктуаційний шум приймального тракту з нульовим середнім та дисперсією `σ_w²`.

Перший критерій Найквіста стверджує: для відсутності міжсимвольної інтерференції сукупна імпульсна характеристика каналу та приймального фільтра `g[n]` повинна дорівнювати нулю у всі відлікові моменти часу, крім нульового: `g[0] = 1`, `g[n] = 0` для всіх `n ≠ 0`. 

У часовій області це означає, що відліки імпульсу в моменти `t = k · T_s` (де `T_s` — період символу) повинні проходить через нуль для всіх `k ≠ 0`. У частотній області еквівалентна умова Найквіста вимагає, щоб періодичні копії спектра сигналу з зсувом на `1/T_s` складалися у константу на всій смузі пропускання.

У реальних кабельних та радіоканалах імпульсна характеристика `h[n]` формується багатопроменевим відбиттям від перешкод та частотно-залежним згасанням. Спектр каналу `H(f)` має нерівномірну амплітудно-частотну характеристику та глибокі провали амплітуди (спектральні нулі, spectral nulls) на окремих частотах, де відбиті хвилі складаються в протифазі. 

Фізичною мірою частотної вибірковості каналу є відношення смуги сигналу `B_signal` до смуги когерентності каналу `B_c`. Смуга когерентності виражається через часовий розкид затримок багатопроменевого поширення (delay spread, `τ_delay`):

```
B_c ≈ 1 / (2·π · τ_delay)
```

Якщо смуга переданого сигналу перевищує смугу когерентності (`B_signal > B_c`), канал стає частотно-вибірковим (frequency-selective fading channel). У часовій області це означає, що часовий розкид затримок перевищує тривалість одного символу (`τ_delay > T_s`). Хвости імпульсу розмиваються на кілька сусідніх символьних інтервалів, руйнуючи умову Найквіста.

Візуальним інструментом діагностики ISI є очкова діаграма (eye diagram), яка формується шляхом накладання осцилограм приймального сигналу на інтервалах тривалістю у кілька символьних періодів. При зростанні ISI очка діаграми закривається:
- **Вертикальне відкриття ока (Eye height)** зменшується, що скорочує запас завадостійкості за амплітудою;
- **Горизонтальне відкриття ока (Eye width)** звужується, що робить систему вкрай чутливою до фазового тремтіння (jitter) та помилок часової синхронізації;
- При повному закритті ока пороговий детектор починає робити помилки навіть за відсутності шуму.

Детальніший опис еволюції інженерних рішень для боротьби з цим ефектом наведено у вставці [Історія вирівнювання каналів](book:communications/channel-equalization/hist-equalizer-history.md).

## 2. Дискретна матрична та частотна модель каналу

Для розробки алгоритмів цифрової обробки сигналів математичну модель каналу записують у векторно-матричній формі. Якщо передається блок із `N` символів `s = [s[0], s[1], ..., s[N-1]]ᵀ`, а імпульсна характеристика каналу має довжину `L`, прийнятий вектор `y` розмірності `M × 1` (де `M = N + L - 1`) виражається як:

```
y = H · s + w
```

Матриця каналу `H` розмірності `M × N` має структуру Тепліца (Toeplitz matrix), в якій кожен стовпець містить зсунуту на один відлік імпульсну характеристику `h = [h[0], h[1], ..., h[L-1]]ᵀ`:

```
    ┌                                   ┐
    │ h[0]   0      0     ...  0        │
    │ h[1]   h[0]   0     ...  0        │
H = │ h[2]   h[1]   h[0]  ...  0        │
    │ ...    ...    ...   ...  ...      │
    │ 0      0      0     ...  h[L-1]   │
    └                                   ┘
```

Фундаментальною математичною характеристикою матриці каналу `H` є її число обумовленості (condition number, `κ(H)`), яке визначається через відношення найбільшого сингулярного числа до найменшого:

```
κ(H) = σ_max(H) / σ_min(H)
```

Якщо канал має глибокі спектральні нулі, найменше сингулярне число `σ_min(H)` прямує до нуля, а число обумовленості прямує до безкінечності (`κ(H) → ∞`). Це означає, що матриця `H` є погано обумовленою (ill-conditioned), і її пряме інвертування є математично нестабільним.

Задача вирівнювача (equalizer) полягає у побудові матриці обробки `W` розмірності `N × M`, яка множиться на прийнятий вектор `y` для формування оцінки переданих символів `s̄`:

```
s̄ = W · y = W · H · s + W · w
```

У мультикарієрних системах (OFDM) за рахунок використання циклічного префіксу (Cyclic Prefix) довжиною `N_cp ≥ L - 1` лінійна згортка перетворюється на циркулярну (кругову). Матриця каналу `H` перетворюється з Тепліцевої на циркулянтну матрицю (Circulant matrix). 

Завдяки властивостям циркулянтних матриць, вони повністю діагоналізуються за допомогою матриці Дискретного Перетворення Фур'є (ДПФ, `F`):

```
H_circ = Fᴴ · Diag(H[0], H[1], ..., H[N-1]) · F
```

В результаті застосування ДПФ на приймачі загальна векторна модель розпадається на `N` повністю незалежних скалярних рівнянь для кожного підканалу (подпередаточного частотного інтервалу) `k`:

```
Y[k] = H[k] · S[k] + W[k],   k = 0, 1, ..., N-1
```

Де:
- `S[k]` — комплексний символ модуляції (наприклад, 16-QAM) на підканалі `k`;
- `H[k]` — комплексний коефіцієнт передачі каналу на частоті підканалу `k`;
- `W[k]` — відлік відносного комплексного гаусового шуму з дисперсією `σ_w²`;
- `Y[k]` — прийнятий комплексний відлік на підканалі `k`.

Таке розщеплення дозволяє розглядати вирівнювання у частотній області як скалярне множення прийнятого комплекснозначного відліку `Y[k]` на коефіцієнт вирівнювача `W[k]`:

```
S̄[k] = W[k] · Y[k]
```

## 3. Критерій Zero-Forcing (ZF): повне скасування інтерференції

### Концепція та інверсія каналу

Головна ідея вирівнювача Zero-Forcing (ZF) полягає у повному обнуленні міжсимвольної інтерференції без урахування наявності шуму. Вимога критерію ZF у матричній формі задається як:

```
W_zf · H = I_N
```

Де `I_N` — одинична матриця розмірності `N × N`. 

Якщо кількість спостережень дорівнює кількості переданих символів (`M = N`) і матриця `H` невироджена, розв'язок є звичайною оберненою матрицею: `W_zf = H⁻¹`. Якщо кількість прийнятих відліків перевищує кількість переданих символів (`M > N`, що характерно для систем із передискретизацією або багаторазовим прийомом), матричне рівняння вирішується через псевдообернену матрицю Мура-Пенроуза (Moore-Penrose pseudoinverse):

```
W_zf = (Hᴴ · H)⁻¹ · Hᴴ
```

Де `Hᴴ` — гермітово-транспонована (комплексно-спряжена та транспонована) матриця каналу.

У частотній області для OFDM-підканалу умова `W_zf[k] · H[k] = 1` дає максимально простий скалярний коефіцієнт:

```
W_zf[k] = 1 / H[k]
```

Оцінка переданого символу `S̄_zf[k]` обчислюється як:

```
S̄_zf[k] = W_zf[k] · Y[k]
        = (1 / H[k]) · (H[k]·S[k] + W[k])
        = S[k] + W[k] / H[k]
```

Як видно з виразу, складова корисного сигналу `S[k]` відновлюється зі стовідсотковою амплітудною та фазовою точністю. Міжсимвольна інтерференція повністю усунена (ISI = 0).

### Фатальний недолік: Посилення шуму (Noise Enhancement)

Попри математичну елегантність, вирівнювач Zero-Forcing має критичну слабкість, яка робить його непридатним для більшості реальних бездротових каналів. Цей недолік — катастрофічне посилення шуму в зонах спектральних нулів каналу.

У матричній формі кореляційна матриця шуму на виході вирівнювача Zero-Forcing дорівнює:

```
R_ww_zf = E[(W_zf · w) · (W_zf · w)ᴴ]
        = W_zf · E[w·wᴴ] · W_zfᴴ
        = σ_w² · (Hᴴ · H)⁻¹
```

Якщо матриця каналу `H` є погано обумовленою (має близькі до нуля сингулярні числа), матриця `(Hᴴ · H)⁻¹` отримує гігантські значення на головній діагоналі, що призводить до вибухового зростання дисперсії шуму.

Розглянемо потужність шуму `P_n_zf[k]` на виході вирівнювача ZF для окремого підканалу `k`:

```
P_n_zf[k] = E[|W_zf[k] · W[k]|²]
          = |1 / H[k]|² · E[|W[k]|²]
          = σ_w² / |H[k]|²
```

Якщо внаслідок інтерференції або частотно-вибіркового згасання амплітуда каналу на певній частоті падає до малого значення, наприклад `|H[k]| = 0.01` (-40 дБ відносно норми), вирівнювач Zero-Forcing обчислює коефіцієнт `W_zf[k] = 1 / 0.01 = 100` (+40 дБ). 

Фільтр намагається «витягнути» провалену частоту, на якій корисний сигнал майже відсутній. У результаті амплітуда аддитивного шуму на цій частоті помножується в 100 разів, а потужність шуму на виході вирівнювача зростає в `100² = 10000` разів (+40 дБ!). Навіть якщо вхідне відношення сигнал/шум (SNR) системи становило комфортні 20 дБ, після вирівнювача ZF на даному підканалі SNR впаде до критичних -20 дБ, викликаючи масові помилки декодування.

## 4. Критерій MMSE: оптимізація компромісу між ISI та шумом

### Формулювання функції втрат

Вирівнювач за критерієм мінімуму середньоквадратичної помилки (Minimum Mean Square Error, MMSE) усуває фатальний недолік Zero-Forcing шляхом зміни цільової математичної функції. Замість вимоги абсолютного скасування ISI, MMSE мінімізує повну математичну сподівану квадратичну відстань між істинним переданим символом `s` та його оцінкою `s̄ = W · y`:

```
J(W) = E[||s̄ - s||²] = E[||W·y - s||²]
```

Розкриваючи норму вектора через вектор помилки `e = W·y - s`, вираз для середньоквадратичної помилки можна розділити на дві незалежні фізичні частини:

```
J(W) = E[||(W·H - I)·s + W·w||²]
     = E[||(W·H - I)·s||²]  +  E[||W·w||²]
     = [Залишкова ISI]       +  [Посилений шум]
```

Перший доданок `E[||(W·H - I)·s||²]` вимірює потужність залишкової міжсимвольної інтерференції (відхилення сукупної характеристики `W·H` від одиничної матриці). Другий доданок `E[||W·w||²]` вимірює потужність шуму на виході фільтра.

Фільтр MMSE знаходить точну математичну точку рівноваги: він погоджується залишити незначну кількість ISI на тих частотах, де її повне вилучення вимагало б надто високої ціни у вигляді посилення шуму.

### Матричний та частотний вивід

Оптимізація функції втрат `J(W)` шляхом диференціювання за матрицею ваг `W` та застосування принципу ортогональності Вінера-Хоффа `E[(W·y - s)·yᴴ] = 0` дає оптимальну матрицю MMSE (повний крок за кроком вивід наведено у вставці [Математичний вивід MMSE](book:communications/channel-equalization/math-mmse-derivation.md)):

```
W_mmse = (Hᴴ · H + (σ_w² / σ_s²) · I_N)⁻¹ · Hᴴ
```

Де:
- `σ_s² = E[|s|²]` — потужність корисного переданого сигналу;
- `σ_w² = E[|w|²]` — потужність аддитивного шуму;
- `σ_w² / σ_s² = 1 / SNR` — величина, обернена до відношення сигнал/шум.

У частотній області для окремого підканалу `k` матричне обернення перетворюється на скалярну формулу частотного коефіцієнта передачі `W_mmse[k]`:

```
W_mmse[k] = H*[k] / (|H[k]|² + σ_w² / σ_s²)
          = H*[k] / (|H[k]|² + 1 / SNR)
```

Де `H*[k]` — комплексне спряження коефіцієнта каналу `H[k]`, а `|H[k]|² = H[k] · H*[k]` — квадрат його модуля (потужнісне згасання каналу).

### Аналіз граничних режимів та регуляризація

Формула MMSE описує адаптивну поведінку фільтра залежно від якості каналу зв'язку. Проаналізуємо два граничні випадки:

#### 1. Режим високого SNR (SNR → ∞, шум відсутній, σ_w² → 0):

```
lim_{SNR → ∞} W_mmse[k] = H*[k] / (|H[k]|² + 0)
                        = H*[k] / (H[k] · H*[k])
                        = 1 / H[k]
                        = W_zf[k]
```

При відсутності шуму доданок `1/SNR` прямує до нуля, і вирівнювач MMSE математично точно збігається з вирівнювачем Zero-Forcing. Коли шум не заважає, кращою стратегією є повне усунення міжсимвольної інтерференції.

#### 2. Режим низького SNR (SNR → 0, сильній шум, 1/SNR → ∞):

```
lim_{SNR → 0} W_mmse[k] ≈ H*[k] / (1 / SNR)
                        = H*[k] · SNR
```

При сильному шумі знаменник визначається доданком `1/SNR`. Передавальна функція вирівнювача стає пропорційною комплексно-спряженій характеристиці каналу `H*[k]`. Фільтр MMSE автоматично перемикається у режим узгодженого фільтра (Matched Filter / Maximal Ratio Combining, MRC). Він більше не намагається ділити на малі амплітуди `|H[k]|`, а навпаки — ослабляє ті частоти, де сигнал затиснутий шумом.

З математичної точки зору доданок `1/SNR` працює як параметр регулярності Тихонова (Tikhonov regularization). Він запобігає діленню на нуль у знаменнику при `|H[k]| → 0`. Максимальний модуль коефіцієнта передачі MMSE на будь-якому підканалі строго обмежений зверху величиною:

```
|W_mmse[k]|_max = √SNR / 2
```

Навіть якщо `|H[k]| = 0`, коефіцієнт MMSE дорівнює нулю (`W_mmse = 0`), а не прямує до безкінечності, як у Zero-Forcing.

## 5. Вплив на сузір'я сигналів та геометрія помилки (IQ Constellation)

Геометричний аналіз розподілу прийнятих відліків на фазовій площині (IQ constellation diagram) наочно демонструє відмінність між ZF та MMSE.

![Сузір'я сигналів: вплив вирівнювання Zero-Forcing та MMSE](/book/communications/signal-processing/channel-equalization/img/constellation-zf-vs-mmse.svg)
*Порівняння IQ-сузір'їв на виході Zero-Forcing (роздута хмара шуму) та MMSE (компактна хмара з легким стисненням).*

На виході вирівнювача Zero-Forcing геометричні центри кластерів точок сузір'я знаходяться строго в ідеальних еталонних позиціях (`E[S̄_zf] = S`). Тобто оцінка ZF є математично незсунутою (unbiased estimate). Проте радіус хмари шуму навколо кожного центру виходить надзвичайно роздутим через посилення шуму на глибоких завадах каналу. Точки легко перетинають пороги прийняття рішень (decision boundaries), що призводить до високого рівня BER.

На виході вирівнювача MMSE радіус хмари шуму навколо точок значно менший (дисперсія шуму мінімізована). Проте математичне сподівання оцінки символу має систематичний амплітудний зсув (bias) у бік початку координат:

```
E[S̄_mmse[k]] = W_mmse[k] · H[k] · S[k]
              = (|H[k]|² / (|H[k]|² + 1 / SNR)) · S[k]
              = α[k] · S[k]
```

Оскільки коефіцієнт стиснення `α[k] = |H[k]|² / (|H[k]|² + 1/SNR) < 1`, сузір'я MMSE злегка стискається до центру. Для багатьох систем із високими порядками модуляції (64-QAM, 256-QAM) таке стиснення може змістити порогові межі порогового детектора. Для нейтралізації цього ефекту у демодуляторах застосовують незсунутий вирівнювач MMSE (Unbiased MMSE), у якому вихідний відлік ділиться на масштабний фактор `α[k]`:

```
S̄_unbiased[k] = S̄_mmse[k] / α[k]
```

Масштабування повертає центри точок на свої місця, зберігаючи при цьому оптимальні властивості вирівнювача щодо мінімізації бітових помилок BER.

## 6. Глибоке порівняння Zero-Forcing та MMSE

Для цілісного розуміння звести ключові характеристики обох методів можна у порівняльну таблицю:

| Параметр / Характеристика | Zero-Forcing (ZF) | Minimum Mean Square Error (MMSE) |
| :--- | :--- | :--- |
| **Цільовий критерій** | Повне скасування ISI (`W·H = I`) | Мінімізація повної помилки `E[||S̄ - S||²]` |
| **Формула (частотна)** | `1 / H[k]` | `H*[k] / (|H[k]|² + 1/SNR)` |
| **Посилення шуму** | Катастрофічне при `|H[k]| → 0` | Строго обмежене рівнем `√SNR / 2` |
| **Залишкова ISI** | Строго 0 | Мала, адаптована до рівня шуму |
| **Зсув оцінки (Bias)** | Незсунута (`E[S̄] = S`) | Зсунута (`E[S̄] = α·S`, `α < 1`) |
| **Необхідна інформація** | Лише оцінка каналу `H[k]` | Оцінка каналу `H[k]` та рівень шуму `σ_w²` |
| **Поведінка при high SNR** | Оптимальна | Збігається з ZF |
| **Поведінка при low SNR** | Непрацездатна (BER → 0.5) | Перетворюється на узгоджений фільтр (MRC) |
| **Обчисливальна складність** | Низька (ділення на `H[k]`) | Поміркована (додається оцінка `σ_w²` та SNR) |

З порівняння чітко видно: вирівнювач ZF має сенс використовувати лише у каналах з високим рівнем SNR та відсутністю глибоких завад (наприклад, у коротких кабельних лініях). У бездротових каналах з багатопроменевим згасанням вирівнювач MMSE є несумнівним стандартом.

## 7. Часове (FIR) проти Частотного (OFDM/FDE) вирівнювання

У класичних одночастотних системах зв'язку (Single-Carrier Systems) вирівнювання виконується у часовій області за допомогою цифрових фільтрів із скінченною імпульсною характеристикою (FIR filter / Tapped-Delay Line).

Схема вирівнювача містить `K` відводів із затримками на один символ `T_s` та комплексами вагами `w = [w_0, w_1, ..., w_{K-1}]ᵀ`. Для обчислення ваг MMSE у часовій області розв'язується класична система матричних рівнянь Вінера-Хоффа:

```
R_yy · w = p_ys
⇒ w_mmse = (R_yy)⁻¹ · p_ys
```

Де `R_yy = E[y_n · y_nᴴ]` — автокореляційна матриця прийнятого сигналу розмірності `K × K`, а `p_ys = E[y_n · s_n*]` — вектор взаємної кореляції.

Головна проблема часового вирівнювання полягає у високій обчислювальній складності. Обчислення оберненої матриці `R_yy⁻¹` має складність `O(K³)` операцій множення. Якщо затримка багатопроменевого каналу охоплює `K = 128` символів, реалізація такого фільтра вимагає мільйонів математичних операцій на один прийнятий символ, що перевантажує DSP та ASIC.

Перехід до частотного вирівнювання (Frequency-Domain Equalization, FDE) у системах OFDM або Single-Carrier FDE (SC-FDE) кардинально змінює обчислювальний ландшафт. У системах SC-FDE (зокрема в uplink-каналах 5G NR на базі DFT-s-OFDM) передавач додає циклічний префікс до блоку символів у часовій області, але сам сигнал зберігає низький пик-фактор (PAPR). На приймачі виконується FFT, скалярне вирівнювання MMSE у частотній області, і зворотне IFFT назад у часову область.

Порівняння обчислювальної складності на блок із `N` символів:
- **Часовий FIR MMSE вирівнювач:** `O(N · K²)` або `O(K³)` операцій;
- **Частотний MMSE вирівнювач (FDE / OFDM):** `O(N log N)` операцій для FFT + `O(N)` скалярних вирівнювань.

Завдяки цьому виграш у продуктивності для великих блоків `N = 1024` або `N = 4096` досягає сотень разів. 

Відносні втрати пропускної здатності через додавання циклічного префіксу визначаються співвідношенням його тривалості `T_cp` до тривалості корисного блоку `T_fft`:

```
Overhead_CP = T_cp / (T_cp + T_fft)
```

У нормальному режимі LTE/5G цей оверхед становить лише близько 7%, що є мінімальною платою за перехід до простих скалярних вирівнювачів.

У багатоантенних системах (MIMO та Massive MIMO) частотне вирівнювання розширюється на просторову область. Для прийому `N_rx` антенами сигналу від `N_tx` передавальних антен на кожному підканалі `k` виконується матричне вирівнювання MMSE:

```
W_mimo_mmse[k] = (H_mimo[k]ᴴ · H_mimo[k] + (1/SNR) · I)⁻¹ · H_mimo[k]ᴴ
```

Де `H_mimo[k]` — матриця каналу розмірності `N_rx × N_tx` для підканалу `k`. Просторове MMSE-вирівнювання дозволяє розділяти суміщені у часі та частоті просторові потоки даних (Spatial Multiplexing), забезпечуючи багатократне зростання пікової швидкості передачі даних.

Детальну програмну реалізацію та порівняльний аналіз швидкодії вирівнювачів ZF та MMSE у частотній області наведено у вставці [Проєкт: симулятор вирівнювачів Zero-Forcing та MMSE](book:communications/channel-equalization/proj-equalizer-sim.md).

## 8. Практичні системи, оцінка каналу та адаптивні фільтри

У реальних трансиверах (наприклад, у стандартах Wi-Fi 6/7, 4G LTE, 5G NR, модемах DOCSIS та VDSL) реальна характеристика каналу `H[k]` заздалегідь невідома і змінюється у часі через рух пристроїв та зміну обстановки.

Для використання вирівнювачів ZF або MMSE приймач спочатку повинен виконати процедуру оцінки каналу (Channel Estimation). У структуру кадру додаються відомі пилотні символи (Pilot symbols / DMRS — Demodulation Reference Signals). 

Приймач вимірює значення `Y_pilot[k]` на пилотних частотах і обчислює сиру оцінку каналу `H̄[k]`:

```
H̄[k] = Y_pilot[k] / S_pilot[k]
```

Після цього застосовується інтерполяція (частотна та часова) для отримання значень `H̄[k]` на всіх інформаційних підканалах.

При використанні MMSE додатково обчислюється дисперсія шуму `σ_w²` шляхом вимірювання потужності відхилень на порожніх підканалах (Guard Subcarriers) або через аналіз залишків пилотних символів. 

Якщо оцінка каналу містить помилки `ΔH[k] = H̄[k] - H[k]`, вирівнювач Zero-Forcing додає додаткову дисперсію помилки `|ΔH[k]|² / |H[k]|⁴`. Вирівнювач MMSE виявляється значно стійкішим до помилок оцінки каналу завдяки вбудованому доданку регуляризації `1/SNR`, який амортизує флуктуації оцінки `H̄[k]`.

У нестаціонарних часових каналах без циклічного префіксу замість прямого матричного обернення застосовують адаптивні градієнтні алгоритми:
- **LMS (Least Mean Squares)** — адаптація ваг із низькою обчислювальною складністю `O(K)` на кожен відлік;
- **RLS (Recursive Least Squares)** — швидка збіжність за рахунок рекурсивного оновлення оцінки кореляційної матриці зі складністю `O(K²)`.

Також для каналів із дуже глибокими спектральними нулями застосовують нелінійний вирівнювач із рішенням у зворотному зв'язку (Decision Feedback Equalizer, DFE). DFE складається з двох фільтрів: прямого (Feedforward), який зменшує попередню ISI та пом'якшує шум за критерієм MMSE, та фільтра зворотного зв'язку (Feedback), який віднімає хвостату ISI від вже прийнятих та рішенням демодулятора розпізнаних попередніх символів.

У сучасних високоефективних системах зв'язку (наприклад, у супутниковому зв'язку DVB-S2X та 5G) вирівнювач працює в ітераційному зв'язку з декодером завадостійкого коду (LDPC або Turbo). Ця технологія зветься Турбо-вирівнюванням (Turbo Equalization). Вирівнювач MMSE приймає від декодера м'які ймовірнісні рішення (Soft Information / Log-Likelihood Ratios, LLR) про значення бітів та використовує їх як апостеріорне знання для подальшого очищення сигналу від міжсимвольної інтерференції на повторних ітераціях.

> 🔧 **Навіщо це.**
> У розробці сучасних радіосистем (SDR, 5G базові станції, Wi-Fi роутери, модеми супутникового зв'язку DVB-S2X) вибір між ZF та MMSE визначає підсумковий бюджет лінії зв'язку (Link Budget). Використання MMSE замість Zero-Forcing у частотно-вибірковому каналі забезпечує виграш у SNR від 3 до 10 дБ при однаковому рівні BER. На практиці це означає можливість збільшити відстань передачі у 1.5–2 рази або підвищити порядок модуляції з QPSK до 16-QAM/64-QAM, подвоюючи реальну швидкість передачі даних без зміни потужності передавача. В реальних DSP-процесорах та FPGA-ядрах вирівнювання MMSE з Unbiased масштабуванням реалізується у вигляді векторного конвеєра на базі фіксованої або плаваючої крапки, обробляючи мільйони підканалів за секунду.
