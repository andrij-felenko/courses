# 🧮 Математика PN-послідовностей: кінцеві поля GF(2), примітивні поліноми та АКФ

Ця вставка містить математичний апарат теорії послідовностей псевдовипадкового шуму (PN-послідовностей), строге виведення властивостей періоду m-послідовностей, рівня їхньої автокореляційної функції (АКФ) та математичні межі взаємної кореляції (ВКФ) ансамблів Ґолда та Касамі.

## 1. Скінченне поле GF(2) та поліноми зворотного зв'язку

LFSR описується в арифметиці алгебри полів Галуа `GF(2)`, де єдиними елементами є `{0, 1}`, додавання відповідає операції побітового виключного АБО (XOR), а множення — логічному І (AND).

Поліном зворотного зв'язку ступеня `m` записується в кільці многочленів `GF(2)[x]` у формі:

```
P(x) = c[m]·xᵐ + c[m-1]·xᵐ⁻¹ + ... + c[1]·x¹ + c[0]
```

де `c[i] ∈ {0, 1}`, причому `c[0] = 1` та `c[m] = 1`.

Двійковий вектор стану регістру `S[n] = [b[n], b[n-1], ..., b[n-m+1]]ᵀ` оновлюється на кожному такті через операторну матрицю переходу `T`:

```
S[n+1] = T · S[n]   (mod 2)
```

Матриця `T` для Фібоначчівського LFSR має супутній вигляд (companion matrix):

```
    | c[1]  c[2]  ...  c[m-1]  c[m] |
    |  1     0    ...    0      0   |
T = |  0     1    ...    0      0   |
    |  .     .    ...    .      .   |
    |  0     0    ...    1      0   |
```

Характеристичний многочлен цієї матриці в полі `GF(2)` дорівнює `det(T - λ·I) = P(λ)`. Згідно з теоремою Гамільтона-Келі, сама матриця `T` задовольняє власне характеристичне рівняння: `P(T) = 0`.

## 2. Класифікація поліномів та умови максимального періоду

Для того щоб послідовність мала максимально можливий період `N = 2ᵐ - 1`, характеристичний поліном `P(x)` повинен задовольняти дві суворі алгебраїчні умови:

1. **Незвідність (Irreducibility):** поліном `P(x)` не розкладається на добуток многочленів менших степенів у кільці `GF(2)[x]`.
2. **Примітивність (Primitivity):** найменшим додатним цілим числом `e`, для якого `P(x)` ділить многочлен `xᵉ - 1` у полі `GF(2)`, є рівно `e = 2ᵐ - 1`.

Якщо `P(x)` є незвідним, але не примітивним, період LFSR буде дільником `2ᵐ - 1`, але не досягне максимуму. Елементи розширеного поля Галуа `GF(2ᵐ)` можна подати як корені `α` примітивного полінома `P(x)`, де `α` є твірним елементом мультиплікативної групи поля `GF(2ᵐ)*`.

### Доведення властивості збалансованості станів

Оскільки матриця переходу `T` є невиродженою (її детермінант над `GF(2)` дорівнює `c[m] = 1`), кожен ненульовий вектор стану має один і лише один зворотний вектор стану `S[n-1] = T⁻¹ · S[n]`.

Оскільки регістр зсуву проходить через усі `2ᵐ - 1` ненульових двійкових векторів за один період, у кожній із `m` позицій вектору стану 0 та 1 з'являються з однаковою частотою, віднесеною до загальної кількості `2ᵐ` векторів (включаючи нульовий стан). Оскільки нульовий стан `[0, 0, ..., 0]` виключено з циклу, кількість одиниць у кожній розрядній позиції дорівнює строго `2ᵐ⁻¹`, а кількість нулів — строго `2ᵐ⁻¹ - 1`.

### Приклад обчислення періоду для m = 3

Розглянемо два поліноми ступеня `m = 3`:

```
Варіант A: P1(x) = x³ + x + 1   (примітивний)
Варіант B: P2(x) = x³ + 1       (звідний: (x+1)(x² + x + 1))
```

Покрокова перевірка ділення `xᵉ - 1` на `P1(x)` у полі `GF(2)`:

```
Для e = 1: x¹ - 1 = x + 1               [не ділиться на x³ + x + 1]
Для e = 3: x³ - 1 = x³ + 1              [не ділиться, остача x]
Для e = 7: x⁷ - 1 = (x³ + x + 1)·(x⁴ + x² + x + 1)  [ділиться без остачі]
```

Отже, найменший період `e = 2³ - 1 = 7`. Послідовність генерації стану з початкового вектора `[0, 0, 1]` для `P1(x)`:

```
Такт 0:  [0, 0, 1]
Такт 1:  [1, 0, 0]  (b[n] = 0^1 = 1)
Такт 2:  [0, 1, 0]
Такт 3:  [1, 1, 0]
Такт 4:  [1, 1, 1]
Такт 5:  [0, 1, 1]
Такт 6:  [0, 0, 1]  (повтор початкового стану через 7 кроків)
```

## 3. Властивість зсуву та додавання (Shift-and-Add)

Фундаментальною алгебраїчною властивістю m-послідовностей є те, що лінійна комбінація (XOR) m-послідовності з її власним циклічним зсувом створює **ту саму m-послідовність**, лише з іншим часовим зсувом.

Нехай `a[n]` — m-послідовність, що задовольняє рекурентне співвідношення зворотного зв'язку:

```
a[n] = c[1]·a[n-1] ⊕ c[2]·a[n-2] ⊕ ... ⊕ c[m]·a[n-m]
```

Оскільки оператор зворотного зв'язку є лінійним над `GF(2)`, для будь-якого фіксованого зсуву `k` послідовність `b[n] = a[n] ⊕ a[n+k]` також задовольняє це саме рекурентне рівняння:

```
b[n] = a[n] ⊕ a[n+k]
     = (∑ c[i]·a[n-i]) ⊕ (∑ c[i]·a[n+k-i])              [підстановка рекурентності]
     = ∑ c[i] · (a[n-i] ⊕ a[n+k-i])                      [лінійність дистрибутивності]
     = ∑ c[i] · b[n-i]                                   [згортка в рекурентне рівняння]
```

Оскільки `b[n]` задовольняє те саме рекурентне співвідношення й не є повністю нульовою послідовністю (бо `a[n]` та `a[n+k]` не збігаються при `k ≠ 0 mod N`), вона **збігається з m-послідовністю `a[n]`, зсунутою на деякий новий інтервал `r(k)`**:

```
a[n] ⊕ a[n+k] = a[n + r(k)]    при k ≠ 0 (mod N)
```

## 4. Математичне виведення ідеальної АКФ m-послідовності

Нехай `a[n] ∈ {0, 1}` — уніполярна m-послідовність періоду `N = 2ᵐ - 1`.
Перетворимо її на біполярну послідовність `s[n] ∈ {+1, -1}` за законом:

```
s[n] = 1 - 2·a[n]   тобто: 0 → +1,  1 → -1
```

Періодична автокореляційна функція `R(k)` для часового зсуву `k` визначається як скалярний добуток послідовності на її зсунуту копію:

```
R(k) = ∑_{n=0}^{N-1} s[n] · s[n+k]
```

Скористаємося тим, що множення в біполярній формі відповідає операції додавання за модулем 2 у двійковій формі:

```
s[n] · s[n+k] = (1 - 2·a[n]) · (1 - 2·a[n+k])
              = 1 - 2·(a[n] ⊕ a[n+k])
```

За властивістю зсуву та додавання, поелементна сума `a[n] ⊕ a[n+k]` m-послідовності з її зсувом на `k ≠ 0 (mod N)` є **тією самою m-послідовністю**, зсунутою на новий інтервал `r(k)`:

```
a[n] ⊕ a[n+k] = a[n + r(k)]   при k ≠ 0 (mod N)
```

Підставимо цей результат у суму автокореляції для двох випадків:

### Випадок 1: Нульовий зсув (k = 0 mod N)

```
R(0) = ∑_{n=0}^{N-1} s[n]² 
     = ∑_{n=0}^{N-1} (+1)² 
     = N
```

### Випадок 2: Ненульовий зсув (k ≠ 0 mod N)

```
R(k) = ∑_{n=0}^{N-1} (1 - 2·a[n + r(k)])
     = N - 2 · ∑_{n=0}^{N-1} a[n + r(k)]                 [розбиття суми]
     = (2ᵐ - 1) - 2 · (2ᵐ⁻¹)                             [підстановка N = 2ᵐ - 1 та суми одиниць 2ᵐ⁻¹]
     = 2ᵐ - 1 - 2ᵐ                                       [спрощення: 2 · 2ᵐ⁻¹ = 2ᵐ]
     = -1                                               [скорочення 2ᵐ - 2ᵐ = 0]
```

Таким чином, для будь-якого ненульового зсуву `k ≠ 0 (mod N)` значення автокореляції строго дорівнює **-1**.

## 5. Межі взаємної кореляції: Велч, Сідельников та коди Ґолда

При одночасному використанні `K` різних послідовностей довжини `N` максимальне значення перехресної взаємної кореляції `R_max = max_{i≠j, k} |R_{ij}(k)|` обмежене знизу межею Велча (Welch Bound):

```
R_max ≥ N · √((K - 1) / (K·N - 1))
```

Для великих `N` ця межа наближається до `√N`.

### Межа Сідельникова
Для будь-якого ансамблю двійкових послідовностей періоду `N`, де розмір ансамблю `K ≥ N`, межа Сідельникова визначає математичний абсолютний мінімум пікової ВКФ:

```
R_max ≥ √(2·N)
```

### Умова побудови переважних пар Ґолда

Нехай `h1(x)` та `h2(x)` — два примітивні поліноми однаковій ступені `m`. Пара називається **переважною парою (preferred pair)**, якщо взаємна кореляція згенерованих m-послідовностей не перевищує межі:

```
|R_{12}(k)| ≤ t(m)
```

де значення `t(m)` визначається через параметр ступеня `m`:

```
t(m) = 1 + 2^((m+1)/2)   для непарних m
t(m) = 1 + 2^((m+2)/2)   для парних m (де m ≠ 0 mod 4)
```

Таблиця переважних поліномів для побудови кодів Ґолда:

| Порядок m | Довжина N | Переважна пара поліномів (у шістнадцятковому виді) | Межа t(m) |
|---|---|---|---|
| 5 | 31 | `0x12` (x⁵+x²+1) та `0x1E` (x⁵+x⁴+x³+x²+1) | 9 |
| 6 | 63 | `0x43` (x⁶+x+1) та `0x57` (x⁶+x⁵+x²+x+1) | 17 |
| 7 | 127 | `0x89` (x⁷+x³+1) та `0x8F` (x⁷+x³+x²+x+1) | 17 |
| 9 | 511 | `0x211` (x⁹+x⁴+1) та `0x241` (x⁹+x⁶+1) | 33 |
| 10 | 1023 | `0x409` (x¹⁰+x³+1) та `0x463` (x¹⁰+x⁶+x⁵+x³+x²+x+1) | 65 |

Сума двох переважних m-послідовностей `u[n] ⊕ v[n+i]` утворює ансамбль з `N + 2` кодів Ґолда, у якому взаємна кореляція між будь-якими двома кодами приймає лише три значення з множини:

```
R_{Gold}(k) ∈ { -t(m),  -1,  t(m) - 2 }
```

Для `m = 5` (`N = 31`): `t(5) = 1 + 2³ = 9`. Значення ВКФ можуть дорівнювати лише **-9, -1, +7**.

## 6. Перетворення Уолша-Адамара та спектральні властивості

Простір двійкових функцій на `GF(2ᵐ)` тісно пов'язаний із ортогональними матрицями Уолша-Адамара. Матриця Адамара `H[k]` порядку `2ᵏ` будується рекурентно:

```
H[0] = [1]
H[k] = | H[k-1]   H[k-1] |
       | H[k-1]  -H[k-1] |
```

Кожен рядок матриці Адамара дорівнює біполярній ортогональній послідовності. Для m-послідовностей перетворення Уолша-Адамара показує, що коефіцієнти спектра є суворо рівномірними за модулем (рівний розподіл енергії), що є математичним еквівалентом білого шуму у скінченних вимірностях.
