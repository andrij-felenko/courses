# 🧮 Математичні властивості перетворення Гільберта

Перетворення Гільберта є лінійним функціональним оператором, який зіставляє довільній дійснозначній функції `x(t)` іншу дійснозначну функцію `x̂(t)`. У часовій області цей оператор визначається через невласний інтеграл у сенсі головного значення Коші (Cauchy Principal Value), а у частотній області відповідає множенню спектра сигналу на оператор фазового зсуву `-j · sgn(f)`.

У цій вставці подано суворі математичні визначення, покрокові виведення та фундаментальні властивості перетворення Гільберта, а також його зв'язок із комплексною аналітичною теорією функцій та фізичними принципами причинності.

## 1. Часова область: Сингулярний інтеграл Коші

Перетворення Гільберта безперервного сигналу `x(t)` визначається як згортка `x(t)` з невласним ядром `1 / (π t)`:

```
x̂(t) = H{x(t)} = (1 / π) · p.v. ∫_{-∞}^{+∞} (x(τ) / (t - τ)) dτ
```

Оскільки ядро `h(t) = 1 / (π t)` має точкову сингулярність (нескінченність) у точці `τ = t`, звичайний інтеграл Рімана в цій точці не існує. Для усунення сингулярності інтегрування виконується в сенсі головного значення за Коші (Cauchy Principal Value), що позначається символом `p.v.` (або `P.V.`):

```
p.v. ∫_{-∞}^{+∞} (x(τ) / (t - τ)) dτ 
= lim_{ε → 0+} [ ∫_{-∞}^{t - ε} (x(τ) / (t - τ)) dτ + ∫_{t + ε}^{+∞} (x(τ) / (t - τ)) dτ ]
```

Геометрично цей процес означає симетричне вирізання околу точки сингулярності радіуса `ε` з наступним спрямуванням `ε` до нуля. Завдяки антисиметрії ядра `1 / (t - τ)` відносно точки `τ = t`, нескінченно великі додатні та від'ємні площі по обидва боки від сингулярності взаємно скорочуються, що дає скінченне значення інтеграла для широкого класу функцій `x(t)`.

Зворотне перетворення Гільберта відновлює початковий сигнал з протилежним знаком:

```
x(t) = H⁻¹{x̂(t)} = -H{x̂(t)} = -(1 / π) · p.v. ∫_{-∞}^{+∞} (x̂(τ) / (t - τ)) dτ
```

Така симетрія показує, що прямому та зворотному перетворенням відповідають майже однакові інтегральні оператори, за винятком знака «мінус».

## 2. Частотна область та спектральна характеристика

Аналіз у частотній області дає найпростіше розуміння оператора Гільберта. За теоремою про згортку, перетворення Фур'є згортки двох функцій дорівнює добутку їхніх перетворень Фур'є.

Обчислимо перетворення Фур'є невласного ядра `h(t) = 1 / (π t)`. Для цього скористаємося зв'язком зі ступенчастою функцією знака `sgn(t)`:

```
H(f) = F{ 1 / (π t) } = -j · sgn(f)
```

де `sgn(f)` — функція знака частоти:

```
         ┌ +1,  при f > 0
sgn(f) = ├  0,  при f = 0
         └ -1,  при f < 0
```

Записавши оператор `H(f)` у показниковій (полярній) формі через комплексний експоненціал:

```
H(f) = -j · sgn(f) = exp(-j · (π/2) · sgn(f))
```

ми бачимо фундаментальні властивості фільтра Гільберта у частотній області:

1. **Модуль амплітудно-частотної характеристики (АЧХ)**: `|H(f)| = |-j · sgn(f)| = 1` для всіх ненульових частот `f ≠ 0`. Це означає, що перетворення Гільберта є **ідеальним всіпрохідним фільтром** (all-pass filter), який не змінює амплітуду жодного гармонічного компонента сигналу.
2. **Фазово-частотна характеристика (ФЧХ)**:
   - Для додатних частот (`f > 0`): фаза кожного компонента зсувається строго на `-π/2` (-90°).
   - Для від'ємних частот (`f < 0`): фаза кожного компонента зсувається строго на `+π/2` (+90°).
   - Для постійної складової (`f = 0`): `H(0) = 0`, що означає повне зрізання постійного зсуву (DC component).

### Покрокове виведення для гармонічного сигналу

Простежимо дію оператора Гільберта на класичну синусоїду `x(t) = cos(2π f₀ t)` при `f₀ > 0`.

Розкладемо косинус на суму двох комплексних експонент за формулою Ейлера:

```
x(t) = cos(2π f₀ t)
= (1/2) · exp(j 2π f₀ t) + (1/2) · exp(-j 2π f₀ t)    [формула Ейлера]
```

Застосуємо перетворення Фур'є, отримуючи два дельта-імпульси на частотах `+f₀` та `-f₀`:

```
F{x(t)} = (1/2) · δ(f - f₀) + (1/2) · δ(f + f₀)       [спектр косинуса]
```

Помножимо спектр на частотну характеристику `H(f) = -j sgn(f)`:

```
F{x̂(t)} = H(f) · F{x(t)}
= -j · sgn(f) · [ (1/2) · δ(f - f₀) + (1/2) · δ(f + f₀) ]
= (1/2) · [ -j · sgn(+f₀) · δ(f - f₀) - j · sgn(-f₀) · δ(f + f₀) ]
= (1/2) · [ -j · δ(f - f₀) + j · δ(f + f₀) ]           [оскільки sgn(+f₀)=1, sgn(-f₀)=-1]
```

Виконаємо зворотне перетворення Фур'є:

```
x̂(t) = F⁻¹{ F{x̂(t)} }
= (1/2) · [ -j · exp(j 2π f₀ t) + j · exp(-j 2π f₀ t) ]
= (1/2j) · [ exp(j 2π f₀ t) - exp(-j 2π f₀ t) ]       [оскільки -j = 1/j, j = -1/j]
= sin(2π f₀ t)                                         [формула Ейлера для синуса]
```

Отже, перетворення Гільберта перетворює косинус на синус: `H{cos(ω t)} = sin(ω t)`.

Аналогічно для синуса `x(t) = sin(2π f₀ t)`:

```
x̂(t) = H{sin(2π f₀ t)} = -cos(2π f₀ t)
```

## 3. Фундаментальні алгебраїчні властивості

Оператор Гільберта задовольняє важливі алгебраїчні співвідношення, які спрощують маніпуляції з аналітичними сигналами.

### 1. Подвійне перетворення (Інволюція)

Подвійне застосування перетворення Гільберта інвертує знак сигналу (для сигналів без постійної складової):

```
H{ H{ x(t) } } = -x(t)
```

*Доведення у частотній області*:

```
F{ H{ H{ x(t) } } } = H(f) · H(f) · X(f)
= (-j · sgn(f)) · (-j · sgn(f)) · X(f)
= (-1) · (sgn(f))² · X(f)
= -X(f)                     [оскільки sgn²(f) = 1 при f ≠ 0]
```

Це означає, що чотириразове застосування оператора Гільберта повертає тотожно початковий сигнал: `H⁴{x(t)} = x(t)`. Оператор Гільберта є аналогом множення на уявну одиницю `j` у просторі функцій, оскільки `j² = -1` і `j⁴ = 1`.

### 2. Взаємна ортогональність сигналу та його спряженого

Дійсний сигнал `x(t)` та його сопряжене перетворення Гільберта `x̂(t)` строго ортогональні на всій часовій осі:

```
∫_{-∞}^{+∞} x(t) · x̂(t) dt = 0
```

*Доведення за теоремою Парсеваля*:

```
∫ x(t) · x̂(t) dt = ∫ X(f) · X̂*(f) df                  [теорема Парсеваля]
= ∫ X(f) · [ -j · sgn(f) · X(f) ]* df
= ∫ X(f) · [ +j · sgn(f) · X*(f) ] df
= j · ∫ sgn(f) · |X(f)|² df
```

Для будь-якого дійснозначного сигналу `x(t)` спектр енергії `|X(f)|²` є парною функцією (`|X(-f)|² = |X(f)|²`), а функція знака `sgn(f)` є строго непарною. Добуток парної та непарної функцій `sgn(f) · |X(f)|²` дає непарну функцію. Інтеграл від непарної функції по симетричній області `[-∞, +∞]` дорівнює нулю.

### 3. Збереження енергії (Теорема Планшереля)

Перетворення Гільберта є унітарним оператором і повністю зберігає енергію сигналу:

```
E = ∫_{-∞}^{+∞} |x(t)|² dt = ∫_{-∞}^{+∞} |x̂(t)|² dt
```

Це випливає з того, що модуль спектральної характеристики `|H(f)| = |-j sgn(f)| = 1`, тому `|X̂(f)|² = |H(f)|² · |X(f)|² = |X(f)|²`.

## 4. Теорема Бедросіана (Bedrosian's Theorem)

У 1963 році американський інженер Едвард Бедросіан (Edward Bedrosian) сформулював теорему, яка визначає умови, за яких перетворення Гільберта від добутку двох сигналів `f(t) · g(t)` можна подати як добуток одного з сигналів на перетворення Гільберта іншого.

### Формулювання теореми

Нехай `f(t)` та `g(t)` — два сигнали зі спектрами Фур'є `F(ν)` та `G(ν)`. Якщо спектральні області сигналів розділені частотною межею `B > 0` так, що:
- Сигнал `f(t)` є строго низькочастотним: `F(ν) = 0` при `|ν| > B`;
- Сигнал `g(t)` є строго високочастотним: `G(ν) = 0` при `|ν| < B`,

то перетворення Гільберта їхнього добутку дорівнює:

```
H{ f(t) · g(t) } = f(t) · H{ g(t) }
```

### Фізичне та практичне значення

Теорема Бедросіана є математичним фундаментом теорії амплітудної модуляції та виділення огинаючої. Якщо вузькосмуговий сигнал побудовано як добуток повільної огинаючої `A(t)` та високочастотної несучої `cos(2π f₀ t)`, то за умови, що спектр огинаючої `A(t)` обмежений частотою `B < f₀`, виконується співвідношення:

```
H{ A(t) · cos(2π f₀ t) } = A(t) · H{ cos(2π f₀ t) } = A(t) · sin(2π f₀ t)
```

Завдяки цьому аналітичний сигнал вузькосмугового процесу набуває точної тотожності:

```
z(t) = A(t) · cos(2π f₀ t) + j · A(t) · sin(2π f₀ t) = A(t) · exp(j 2π f₀ t)
```

Модуль цього комплексного сигналу `|z(t)| = A(t)` в точності відтворює початкову низькочастотну огинаючу без жодних спотворень.

Якщо ж спектр огинаючої `A(t)` заходить у область частот несучої (`B ≥ f₀`), теорема Бедросіана порушується. У цьому випадку уявна частина `x̂(t)` містить додаткові спектральні компоненти, а обчислена огинаюча `|z(t)|` перестає відповідати початковій функції `A(t)`, демонструючи так звані «дефекти розщеплення фази».

## 5. Спектр аналітичного сигналу

Аналітичний сигнал `z(t)` визначається як комплексне поєднання дійснозначного сигналу `x(t)` та його спряженого за Гільбертом `x̂(t)`:

```
z(t) = x(t) + j · x̂(t)
```

Знайдемо спектр `Z(f)` аналітичного сигналу в частотній області:

```
Z(f) = F{ z(t) } = F{ x(t) + j · x̂(t) }
= X(f) + j · X̂(f)                      [лінійність перетворення Фур'є]
= X(f) + j · [ -j · sgn(f) · X(f) ]     [підстановка X̂(f) = H(f)X(f)]
= X(f) + sgn(f) · X(f)                  [оскільки j · (-j) = 1]
= X(f) · [ 1 + sgn(f) ]
```

Аналіз виразу `[1 + sgn(f)]`:
- Для додатних частот (`f > 0`): `sgn(f) = +1`, тому `Z(f) = 2 · X(f)`.
- Для нульової частоти (`f = 0`): `sgn(f) = 0`, тому `Z(0) = X(0)`.
- Для від'ємних частот (`f < 0`): `sgn(f) = -1`, тому `Z(f) = 0`.

У компактному вигляді через ступенчасту функцію Хевісайда `U(f)`:

```
Z(f) = 2 · U(f) · X(f)
```

Цей результат підтверджує головну властивість аналітичного сигналу: його спектр є строго одностороннім (значення для всіх від'ємних частот тотожно дорівнюють нулю), а амплітуда додатних частот подвоєна для збереження загальної енергії сигналу.

## 6. Зв'язок із причинністю та співвідношення Крамерса — Кроніга

Перетворення Гільберта тісно пов'язане з принципом причинності у фізичних системах. Якщо лінійна система є причинною (її імпульсна характеристика `h(t) = 0` при `t < 0`), то дійсна та уявна частини її частотної характеристики `H(f) = U(f) + j V(f)` не є незалежними.

Дійсна частина `U(f)` та уявна частина `V(f)` причинної системи пов'язані між собою через перетворення Гільберта:

```
V(f) = -H{ U(f) }
U(f) = H{ V(f) }
```

У фізиці, оптиці та радіотехніці ці співвідношення відомі як **співвідношення Крамерса — Кроніга** (Kramers-Kronig relations). Вони стверджують, що дисперсія середовища (залежність показника заломлення від частоти, дійсна частина) повністю визначається спектром поглинання середовища (абсорбцією, уявна частина). Таким чином, математична структура перетворення Гільберта є прямою вимогою принципу причинності у фізичному світі.
