# 🧮 Математика інтерполяції: спектральне дзеркалювання та згладжувальний фільтр

Математичний апарат інтерполяції описує перетворення дискретної послідовності `x[n]` із частотою дискретизації `f_s` у нову послідовність `y[m]` із підвищеною частотою `f_s' = L · f_s`, де `L` — цілочислове значення коефіцієнта розширення.

Операція інтерполяції складається з двох математичних етапів: часового розширення за допомогою нульового заповнення та подальшої дискретної фільтрації нижніх частот.

## 1. Зв'язок із неперервним спектром та нульове заповнення

Розглянемо аналоговий неперервний сигнал `x_a(t)` із спектром `X_a(f)`. При дискретизації з частотою `f_s = 1 / T` утворюється дискретна послідовність відліків `x[n] = x_a(n · T)`. Дискретне перетворення Фур'є з часовими відліками (DTFT) визначається як:

```
X(e^{jω}) = ∑_{n = -∞}^{+∞} x[n] · e^{-j·ω·n}
```

Де `ω = 2 · π · f / f_s` є нормованою круговою частотою. Дискретний спектр `X(e^{jω})` пов'язаний із неперервним спектром `X_a(f)` через суму нескінченного числа зсунутих періодичних копій:

```
X(e^{jω}) = (1 / T) · ∑_{k = -∞}^{+∞} X_a( (ω - 2·π·k) / (2·π·T) )
```

Першим кроком інтерполяції є формування нової послідовності `w[m]`, що працює з коротшим інтервалом дискретизації `T' = T / L`. Для цього між кожними двома сусідніми відліками початкового сигналу вставляють `L - 1` нульових значень:

```
w[m] = x[m / L],  якщо m ділиться на L без залишку
w[m] = 0,        якщо m не ділиться на L
```

Знайдемо DTFT для розширеного сигналу `w[m]`. За визначенням перетворення:

```
W(e^{jω'}) = ∑_{m = -∞}^{+∞} w[m] · e^{-j·ω'·m}
```

Оскільки `w[m] = 0` для всіх індексів `m`, які не кратні `L`, підсумовування здійснюється лише за індексами `m = n · L`:

```
W(e^{jω'})
= ∑_{n = -∞}^{+∞} w[n · L] · e^{-j·ω'·n·L}       [підстановка m = n·L]
= ∑_{n = -∞}^{+∞} x[n] · e^{-j·(ω'·L)·n}          [оскільки w[n·L] = x[n]]
= X(e^{j·ω'·L})                                  [визначення DTFT для x[n]]
```

Ключовий висновок: спектр розширеного сигналу `W(e^{jω'})` є масштабованою копією початкового спектра `X(e^{jω})`. Відбувається стискання осі частот у `L` разів: `ω' = ω / L`.

Оскільки початковий спектр `X(e^{jω})` є періодичним із періодом `2·π`, новий спектр `W(e^{jω'})` стає періодичним із коротшим періодом `2·π / L`. Це означає, що у фундаментальному діапазоні нормованих частот `[-π, π]` з'являється `L - 1` додаткових періодичних копій (дзеркальних образів / spectral images) початкового спектра, розташованих навколо частот `2·π·k / L` для `k = 1, 2, ..., L - 1`.

Фізично це пояснюється тим, що нульові відліки у часовій області не змінюють миттєвих значень амплітуди початкових точок, проте зменшують середній енергетичний рівень сигналу на один відлік. Для збереження загальної енергії сигналу дзеркальні образи мають однакову амплітуду з базовою спектральною смугою.

## 2. Перетворення у Z-області

Аналогічне співвідношення отримують у Z-області. За означенням прямого Z-перетворення:

```
X(z) = ∑_{n = -∞}^{+∞} x[n] · z^{-n}
```

Для розширеного сигналу `w[m]`:

```
W(z) 
= ∑_{m = -∞}^{+∞} w[m] · z^{-m}
= ∑_{n = -∞}^{+∞} x[n] · z^{-n·L}
= ∑_{n = -∞}^{+∞} x[n] · (z^L)^{-n}
= X(z^L)
```

Отже, операція розширення `↑L` замінює комплексну змінну `z` на `z^L`. На одиничному колі `z = e^{jω'}` це відповідає підстановці `z^L = e^{j·ω'·L}`, що знову підтверджує стискання частотної осі у `L` разів.

З математичної точки зору, нулі поліноміальної функції `X(z)` на комплексній Z-площині при переході до `W(z) = X(z^L)` розмножуються: кожен полюс чи нуль `z_0` перетворюється на `L` симетричних нулів чи полюсів, розташованих під кутами `2·π·k / L` на тій самій окружності.

## 3. Математика ідеального та реального анти-іміджингового фільтра

Щоб вилучити небажані `L - 1` дзеркальних образів та залишити лише корисний базовий спектр навколо нульової частоти, проміжний сигнал `w[m]` пропускають через згладжувальний ФНЧ із частотною характеристикою `H(e^{jω'})`.

Ідеальна частотна характеристика інтерполяційного фільтра має прямокутний профіль:

```
H(e^{jω'}) = L,   для |ω'| ≤ π / L        [смуга пропускання]
H(e^{jω'}) = 0,   для π / L < |ω'| ≤ π    [смуга загородження]
```

Знайдемо імпульсну характеристику `h[m]` ідеального фільтра через зворотне дискретне перетворення Фур'є:

```
h[m] 
= (1 / (2·π)) · ∫_{-π/L}^{+π/L} L · e^{j·ω'·m} dω'
= (L / (2·π·j·m)) · [e^{j·π·m / L} - e^{-j·π·m / L}]
= (L / (π·m)) · sin(π·m / L)
= sinc(m / L)
```

Отже, ідеальний згладжувальний фільтр має імпульсну характеристику вигляду нормованої функції `sinc(m / L)` із підсиленням `L`.

Коефіцієнт підсилення `L` в смузі пропускання є математично обов'язковим. Оскільки нульове заповнення зменшує середню енергію сигналу на один відлік у `L` разів (лінійна середня амплітуда падає у `L` разів), підсилення `H(0) = L` точно відновлює вихідну амплітуду огинаючої без енергетичних втрат.

### Синтез реальних КІХ-фільтрів через вікно Кейзера (Kaiser Window)

Оскільки нескінченний ряд `sinc(m / L)` не є причинним, його усікають симетричним вікном довжиною `K` відводів: `h_{FIR}[m] = h[m] · w_{window}[m]`.

Нескінченне відсікання викликає пульсації у смузі пропускання та загородження — ефект Ґіббса (Gibbs phenomenon). Для точного контролю придушення дзеркальних образів застосовують вікно Кейзера:

```
w_{kaiser}[m] = I₀( β · √( 1 - (2·m / (K - 1))² ) ) / I₀(β)
```

Де `I₀` — модифікована функція Бесселя нульового порядку першого роду, а параметр `β` задає рівень придушення бокових пелюстків. Наприклад, для придушення дзеркальних образів на `80` дБ вибирають `β = 7.865`.

Порівняння математичних властивостей різних віконних функцій для інтерполяції:
- **Вікно Ханна (Hann)**: придушення бокових пелюстків ~44 дБ, ширина перехідної смуги `8·π / K`.
- **Вікно Геммінга (Hamming)**: придушення бокових пелюстків ~53 дБ, ширина перехідної смуги `8·π / K`.
- **Вікно Блекмана (Blackman)**: придушення бокових пелюстків ~74 дБ, ширина перехідної смуги `12·π / K`.
- **Вікно Кейзера (Kaiser)**: плавне параметричне налаштування рівня придушення від 40 дБ до понад 120 дБ шляхом зміни коефіцієнта `β`.

## 4. Шляхетна тотожність та поліфазне розкладання

Розглянемо передавальну функцію КІХ-фільтра `H(z)` довжиною `K` у Z-області:

```
H(z) = ∑_{k = 0}^{K - 1} h[k] · z^{-k}
```

Розділимо індекс `k` на `L` поліфазних компонент за допомогою розкладання `k = n · L + p`, де `p ∈ [0, L - 1]`:

```
H(z)
= ∑_{p = 0}^{L - 1} ∑_{n = 0}^{K/L - 1} h[n·L + p] · z^{-(n·L + p)}
= ∑_{p = 0}^{L - 1} z^{-p} · ( ∑_{n = 0}^{K/L - 1} h[n·L + p] · (z^L)^{-n} )
= ∑_{p = 0}^{L - 1} z^{-p} · E_p(z^L)
```

Де `E_p(z) = ∑_{n = 0}^{K/L - 1} h[n·L + p] · z^{-n}` є `p`-ю поліфазною компонентою (субфільтром) імпульсної характеристики.

Згідно зі шляхетною тотожністю (Noble Identity for Interpolation), послідовне з'єднання розширювача `↑L` та поліфазної характеристики `E_p(z^L)` еквівалентне обчисленню субфільтра `E_p(z)` на НИЗЬКІЙ частоті `f_s` із наступним вставленням нулів:

```
[ ↑L ] ---> [ E_p(z^L) ]   ≡   [ E_p(z) ] ---> [ ↑L ]
```

Завдяки цьому вихідний відлік `y[m]` на високій частоті `m = n · L + p` обчислюється напряму через відповідну `p`-ту фазу без жодних множень на нуль:

```
y[n · L + p] = ∑_{i = 0}^{K/L - 1} E_p[i] · x[n - i]
```

Це математично підтверджує скорочення обчислювальної складності прямої інтерполяції у `L` разів за збереження ідентичності вихідного сигналу.

### Фазова затримка та фазовий зсув поліфазних компонент

Симетричний КІХ-фільтр довжиною `K` має постійну групову затримку `τ_{group} = (K - 1) / 2` відліків на вихідній високій частоті `L · f_s`.

У поліфазному виконанні ця затримка розкладається на цілу частину вхідних відліків `N_{sub} = ⌊(K - 1) / (2·L)⌋` та точний дробовий фазовий зсув `p / L` для кожної `p`-ї фази. Завдяки цьому поліфазний інтерполятор не змінює лінійність фази початкового сигналу, забезпечуючи ідеальну часову симетрію відновити огинаючу.
