# 🧮 Вивід еквівалентної шумової смуги (ENBW) для аналогових і цифрових фільтрів

Ця математична вставка містить вивід та аналітичні розрахунки еквівалентної шумової смуги (англ. *Equivalent Noise Bandwidth*, ENBW) для аналогових фільтрів першого, другого та довільного `N`-го порядків, а також для цифрових віконних функцій, що використовуються у спектральному аналізі БПФ.

## 1. Постановка задачі та математичне визначення ENBW

У реальних електронних колах та радіоприймачах джерелом фундаментального шуму є тепловий шум резисторів та флікер-шум напівпровідників. У межах робочої смуги цей шум моделюють як білий гауссів шум (канал AWGN) із односторонньою спектральною щільністю потужності `N0` (вимірюється у Вт/Гц).

Коли білий шум проходить через аналоговий або цифровий фільтр із передавальною функцією `H(f)`, його спектральна щільність потужності на виході змінюється згідно з квадратом модуля передавальної функції:

```
S_out(f) = N0 · |H(f)|^2
```

Повна потужність шумового процесу на виході фільтра `P_noise` обчислюється шляхом інтегрування спектральної щільності по всіх частотах від 0 до нескінченності:

```
P_noise = ∫_0^∞ S_out(f) df = N0 · ∫_0^∞ |H(f)|^2 df
```

За теоремою Парсеваля ця потужність дорівнює енергії імпульсної характеристики фільтра `h(t)` у часовій області:

```
∫_0^∞ |H(f)|^2 df = ∫_0^∞ |h(t)|^2 dt
```

Еквівалентна шумова смуга `ENBW` визначається як ширина ідеального прямокутного П-подібного фільтра з підсиленням `H_max`, який у разі подачі того самого білого шуму пропускає на вихід абсолютно таку ж сумарну потужність `P_noise`:

```
P_noise = N0 · |H_max|^2 · ENBW
```

Прирівнюючи два вирази для потужності шуму, отримуємо фундаментальне математичне визначення еквівалентної шумової смуги:

```
ENBW = (1 / |H_max|^2) · ∫_0^∞ |H(f)|^2 df
```

У більшості нормованих фільтрів максимальний коефіцієнт передачі спостерігається на постійному струмі або в центрі смуги пропускання, тобто `|H_max| = 1`.

## 2. Аналітичний вивід для аналогового RC-фільтра 1-го порядку

Розглянемо класичний пасивний низькочастотний RC-фільтр першого порядку. Його передавальна функція в операторній формі має вигляд `H(s) = 1 / (1 + s·R·C)`. Підставляючи `s = j·2·π·f`, знаходимо квадрат модуля АЧХ:

```
|H(f)|^2 = 1 / (1 + (2·π·f·R·C)^2)
```

Ввівши частоту зрізу за рівнем -3 дБ `f_c = 1 / (2·π·R·C)`, переписуємо квадрат модуля АЧХ у нормованому вигляді:

```
|H(f)|^2 = 1 / (1 + (f / f_c)^2)
```

Оскільки на частоті `f = 0` коефіцієнт передачі `|H(0)| = 1`, підставляємо передавальну функцію у загальний інтеграл визначення `ENBW`:

```
ENBW = ∫_0^∞ (1 / (1 + (f / f_c)^2)) df
```

Для обчислення цього інтеграла виконаємо заміну змінної `u = f / f_c`. Тоді диференціал дорівнює `df = f_c · du`, а границі інтегрування `[0, ∞)` лишаються незмінними:

```
ENBW
= ∫_0^∞ (1 / (1 + u^2)) · f_c · du      [заміна змінної u = f / f_c]
= f_c · ∫_0^∞ (1 / (1 + u^2)) du         [винесення константи f_c за знак інтеграла]
= f_c · [arctan(u)]_0^∞                  [використання табличного інтеграла arctan]
= f_c · (lim_{u→∞} arctan(u) - arctan(0)) [підстановка границь інтегрування]
= f_c · (π / 2 - 0)                      [значення границь: arctan(∞) = π/2]
= (π / 2) · f_c ≈ 1.570796 · f_c         [остаточний аналітичний результат]
```

Таким чином, простий однополюсний RC-фільтр першого порядку має еквівалентну шумову смугу, яка на 57.1% перевищує його смугу за рівнем -3 дБ `f_c`. Це пояснюється тим, що АЧХ фільтра першого порядку спадає дуже повільно — зі швидкістю лише -20 дБ на декаду (-6 дБ на октаву), через що високі частоти пропускають значну частину шумової енергії.

## 3. Аналітичний вивід для фільтра Баттерворта 2-го порядку

Фільтр Баттерворта другого порядку забезпечує максимально плоску АЧХ у смузі пропускання. Квадрат модуля його передавальної функції дорівнює:

```
|H(f)|^2 = 1 / (1 + (f / f_c)^4)
```

Обчислимо еквівалентну шумову смугу `ENBW` за допомогою інтегрування:

```
ENBW = ∫_0^∞ (1 / (1 + (f / f_c)^4)) df
```

Використовуємо заміну змінної `u = f / f_c` (`df = f_c · du`):

```
ENBW = f_c · ∫_0^∞ (1 / (1 + u^4)) du
```

Для обчислення визначеного інтеграла `I = ∫_0^∞ (1 / (1 + u^4)) du` застосуємо метод розкладання підінтегрального виразу на прості дроби або лишки в комплексній площині. Розкладемо знаменник: `1 + u^4 = (u^2 + sqrt(2)·u + 1) · (u^2 - sqrt(2)·u + 1)`.

Інтегрування дає наступний точний аналітичний вираз:

```
∫_0^∞ (1 / (1 + u^4)) du
= [(1 / (4·sqrt(2))) · ln((u^2 + sqrt(2)·u + 1) / (u^2 - sqrt(2)·u + 1))
   + (1 / (2·sqrt(2))) · arctan(sqrt(2)·u / (1 - u^2))]_0^∞
= (π / (2·sqrt(2)))                      [значення інтеграла]
≈ 0.785398 / 0.707106 ≈ 1.11072
```

Підставляючи це значення в формулу `ENBW`, отримуємо:

```
ENBW = (π / (2·sqrt(2))) · f_c ≈ 1.1107 · f_c
```

Фільтр другого порядку спадає зі швидкістю -40 дБ на декаду (-12 дБ на октаву), тому його шумова смуга перевищує смугу -3 дБ лише на 11.1%.

## 4. Загальна формула для фільтра Баттерворта N-го порядку

Для аналогового фільтра Баттерворта довільного порядку `N` квадрат модуля АЧХ описується виразом:

```
|H(f)|^2 = 1 / (1 + (f / f_c)^(2·N))
```

Інтеграл еквівалентної шумової смуги має вигляд:

```
ENBW = f_c · ∫_0^∞ (1 / (1 + u^(2·N))) du
```

Застосовуючи теорію лишків комплексному інтегруванню по замкненому контуру у верхній півплощині або відому формулу для інтегралів Ейлера, отримуємо загальний вираз:

```
∫_0^∞ (1 / (1 + u^(2·N))) du = π / (2·N · sin(π / (2·N)))
```

Звідси відношення еквівалентної шумової смуги до смуги -3 дБ для фільтра порядку `N` становить:

```
ENBW / f_c = π / (2·N · sin(π / (2·N)))
```

Проаналізуємо значення цього відношення залежно від порядку фільтра `N`:

```
| Порядок фільтра N | Формула ENBW / f_c            | Числове значення | Відхилення від ідеалу |
|-------------------|--------------------------------|------------------|------------------------|
| N = 1             | π / 2                          | 1.5708           | +57.1%                 |
| N = 2             | π / (2·√2)                     | 1.1107           | +11.1%                 |
| N = 3             | π / 3                          | 1.0472           | +4.7%                  |
| N = 4             | π / (8·sin(π/8))               | 1.0262           | +2.6%                  |
| N = 5             | π / (10·sin(π/10))             | 1.0166           | +1.7%                  |
| N = 6             | π / (12·sin(π/12))             | 1.0115           | +1.15%                 |
| N → ∞             | lim_{N→∞} (ENBW / f_c)         | 1.0000           | 0.0% (Ідеальний П-фільтр)|
```

З таблиці видно, що вже при порядку фільтра `N = 4` еквівалентна шумова смуга перевищує смугу -3 дБ менше ніж на 2.6%. Для більшості практичних радіоприймачів застосування фільтрів 4-го або 5-го порядків дозволяє вважати шумову смугу практично рівною смузі -3 дБ.

## 5. Обчислення ENBW для цифрових віконних функцій БПФ

У цифровому спектральному аналізі неперервний сигнал дискретизується й розбивається на кадри довжиною `M` відліків. Множення кадру на віконну функцію `w[n]` у часовій області зменшує розтікання спектра (англ. *spectral leakage*), але розширює еквівалентну шумову смугу кожного окремого біна БПФ.

Для дискретної віконної функції `w[n]` (`n = 0..M-1`) еквівалентна шумова смуга в одиницях бінів БПФ обчислюється за формулою:

```
ENBW_bins = M · (∑_{n=0}^{M-1} w[n]^2) / (∑_{n=0}^{M-1} w[n])^2
```

Обчислимо `ENBW` для найпоширеніших типів вікон:

### Прямокутне вікно (Rectangular Window)

Для прямокутного вікна `w[n] = 1` для всіх `n = 0..M-1`:

```
∑_{n=0}^{M-1} w[n] = M
∑_{n=0}^{M-1} w[n]^2 = M
ENBW_rect = M · M / M^2 = 1.000 біна
```

Прямокутне вікно забезпечує найвужчу шумову смугу одного біна (1.0 бін), але має дуже високі бічні пелюстки (-13 дБ), що спотворює вимірювання слабких сигналів поруч із сильними.

### Вікно Ганна (Hann Window)

Віконна функція Ганна описується виразом `w[n] = 0.5 - 0.5 · cos(2·π·n / M)`.

Інтегрування квадратів суми дає:

```
∑_{n=0}^{M-1} w[n] ≈ 0.5 · M
∑_{n=0}^{M-1} w[n]^2 ≈ 0.375 · M
ENBW_hann = M · (0.375 · M) / (0.5 · M)^2 = 0.375 / 0.25 = 1.500 біна
```

Вікно Ганна розширює шумову смугу біна в 1.5 раза (на 50%), але придушує бічні пелюстки до -31 дБ.

### Зведена таблиця характеристик цифрових вікон

```
| Тип вікна         | Математична формула w[n]                    | ENBW (бінів) | Рівень бічних пелюсток |
|-------------------|---------------------------------------------|--------------|------------------------|
| Прямокутне        | 1.0                                         | 1.000        | -13 дБ                 |
| Геммінга          | 0.54 - 0.46·cos(2πn/M)                      | 1.363        | -43 дБ                 |
| Ганна             | 0.5 - 0.5·cos(2πn/M)                        | 1.500        | -31 дБ                 |
| Блекмана          | 0.42 - 0.5·cos(2πn/M) + 0.08·cos(4πn/M)     | 1.727        | -58 дБ                 |
| Флетап (Flat-top) | 0.215 - 0.416·cos + 0.277·cos - 0.083·cos ...| 3.770        | -93 дБ                 |
```

## 6. Врахування ENBW у розрахунку теплового шуму приймача

Знання точного значення `ENBW` є критичним для обчислення повної шумової потужності на вході аналого-цифрового перетворювача (АЦП) радіоприймача.

Повна потужність теплового шуму `P_N` (у ватах) обчислюється за формулою Джонсона-Найквіста:

```
P_N = k · T · ENBW · F
```

Де:
* `k = 1.380649 × 10^-23` Дж/К — стала Больцмана;
* `T` — абсолютна температура у кельвінах (для кімнатної температури `T = 290 K`, причому `k · T ≈ 4.00 × 10^-21` Вт/Гц або -174 дБм/Гц);
* `ENBW` — еквівалентна шумова смуга приймального тракту в Гц;
* `F` — лінійний коефіцієнт шуму приймача (Noise Factor).

Якщо смуга приймача за рівнем -3 дБ становить `f_3dB = 10` МГц, а тракту відповідає фільтр Баттерворта 1-го порядку, то справжня шумова смуга дорівнює `ENBW = 15.71` МГц. Ігнорування різниці між `f_3dB` та `ENBW` призведе до помилки в оцінці шуму на `10 · log10(1.571) ≈ 1.96` дБ, що є недопустимим у високоточних вимірювальних систем.
