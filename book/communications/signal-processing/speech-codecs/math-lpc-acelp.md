# 🧮 Математика лінійного передбачення LPC та алгебраїчного збудження ACELP

Цей математичний огляд виводить фундаментальні рівняння модельного кодування мови. Він пояснює, як з мовного сигналу вилучається спектральна огинаюча голосового тракту за допомогою рекурсії Левінсона-Дурбіна, фізичний зміст коефіцієнтів відбиття у трудовому акустичному моделюванні, алгебраїчне перетворення поліномів у лінійні спектральні пари (LSP), а також математичний апарат алгоритму ACELP для мінімізації зваженої помилки синтезу.

## 1. Фізична та авторегресійна модель голосового тракту

У джерельно-фільтровій моделі мови голосовий тракт людини моделюється як послідовність зчленувань циліндричних акустичних трубок різного перерізу (модель Келлі-Лохбаума). З точки зору теорії сигналів та систем така акустична труба описується авторегресійним цифровим фільтром порядку `p` (зазвичай `p = 10` для частоти дискретизації 8 кГц). Відлік мовного сигналу `s[n]` виражається через лінійну комбінацію `p` попередніх відліків та залишкове збудження `e[n]`:

```
s[n] = ∑_{k=1}^{p} a[k] · s[n-k] + e[n]
```

Оцінка передбаченого відліку `ŝ[n]` формується як лінійна комбінація:

```
ŝ[n] = ∑_{k=1}^{p} a[k] · s[n-k]
```

Помилка передбачення (залишок) дорівнює різниці між реальним та передбаченим значеннями:

```
e[n] = s[n] - ŝ[n] = s[n] - ∑_{k=1}^{p} a[k] · s[n-k]
```

Мета LPC-аналізу — знайти вектор коефіцієнтів передбачення `a = [a₁, a₂, ..., aₚ]ᵀ`, який мінімізує сумарну квадратну помилку `E` на кадрі аналізу довжиною `N` відліків (у кодеку G.729 `N = 80` відліків, 10 мс):

```
E = ∑_{n=0}^{N-1} (e[n])² = ∑_{n=0}^{N-1} (s[n] - ∑_{k=1}^{p} a[k] · s[n-k])²
```

Для знаходження мінімуму функціонала `E` б'ється часткова похідна за кожним коефіцієнтом `a[i]` та прирівнюється до нуля:

```
∂E / ∂a[i] = -2 · ∑_{n=0}^{N-1} (s[n] - ∑_{k=1}^{p} a[k] · s[n-k]) · s[n-i] = 0
```

Це приводь до класичної системи нормальних рівнянь Юла-Вокера (Yule-Walker):

```
∑_{k=1}^{p} a[k] · R(|i - k|) = R(i),    для i = 1, 2, ..., p
```

де `R(k)` — автокореляційна функція мовного сигналу на вікні аналізу:

```
R(k) = ∑_{n=0}^{N-1-k} s[n] · s[n+k]
```

У матричній формі система Юла-Вокера має симетричну теплицеву структуру, де елементи на кожній діагоналі є однаковими:

```
| R(0)   R(1)   R(2)   ... R(p-1) |   | a₁ |   | R(1) |
| R(1)   R(0)   R(1)   ... R(p-2) |   | a₂ |   | R(2) |
| R(2)   R(1)   R(0)   ... R(p-3) | · | a₃ | = | R(3) |
|  ...    ...    ...   ...   ...  |   | .. |   |  ..  |
| R(p-1) R(p-2) R(p-3) ... R(0)   |   | aₚ |   | R(p) |
```

## 2. Алгоритм рекурсії Левінсона-Дурбіна та коефіцієнти відбиття

Пряме обернення матриці розміру `p × p` методами Гаусса вимагає `O(p³)` арифметичних операцій. Завдяки теплицевій симетрії автокореляційної матриці застосовується алгоритм рекурсії Левінсона-Дурбіна складністю всего `O(p²)`.

Рекурсія будує послідовність оптимальних фільтрів порядків `k = 1, 2, ..., p`:

```
Початкові умови для порядку k = 0:
E⁽⁰⁾ = R(0)

Для порядку k = 1, 2, ..., p виконуються кроки:

1. Обчислення коефіцієнта відбиття kₖ (Reflection Coefficient):
   kₖ = ( R(k) - ∑_{j=1}^{k-1} aⱼ⁽ᵏ⁻¹⁾ · R(k - j) ) ÷ E⁽ᵏ⁻¹⁾

2. Оновлення коефіцієнтів передбачення для порядку k:
   aₖ⁽ᵏ⁾ = kₖ
   aⱼ⁽ᵏ⁾ = aⱼ⁽ᵏ⁻¹⁾ - kₖ · aₖ₋ⱼ⁽ᵏ⁻¹⁾,    для j = 1, 2, ..., k-1

3. Оновлення мінімальної енергії помилки:
   E⁽ᵏ⁾ = E⁽ᵏ⁻¹⁾ · (1 - (kₖ)²)
```

Фізичний зміст коефіцієнтів `kₖ`: у трудовому акустичному моделюванні мовного тракту `kₖ` виражає коефіцієнт відбиття звукової хвилі на межі переходу між `k`-м та `(k+1)`-м циліндричними сегментами з площами перерізу `Sₖ` та `Sₖ₊₁`:

```
kₖ = ( Sₖ₊₁ - Sₖ ) ÷ ( Sₖ₊₁ + Sₖ )
```

Умова стійкості цифрового фільтра синтезу `1 / A(z)` вимагає, щоб абсолютні значення всіх коефіцієнтів відбиття були суворо меншими за одиницю: `|kₖ| < 1`. Якщо `|kₖ| ≥ 1`, це означає, що площа перерізу труби стає від'ємною або безкінечною, полюси фільтра виходять за межі одиничного кола на z-площині, і синтезований звук безконтрольно самозбуджується.

## 3. Математичне перетворення у лінійні спектральні пари (LSP)

Коефіцієнти прямого полінома `a[k]` дуже чутливі до помилок квантування. Навіть дрібне спотворення одного коефіцієнта при передаванні мережею може вивести полюси `A(z)` за одиничне коло. Тому у стандарту G.729 коефіцієнти перетворюються у лінійні спектральні пари (Line Spectral Pairs, LSP / LSF).

Поліном передбачення 10-го порядку `A(z) = 1 - ∑_{k=1}^{10} a[k] · z⁻ᵏ` розкладається на два симетричні поліноми 11-го порядку `P(z)` та `Q(z)` шляхом додавання та віднімання зворотного полінома:

```
P(z) = A(z) + z⁻¹¹ · A(z⁻¹)    [симетричний поліном, закрита связка]
Q(z) = A(z) - z⁻¹¹ · A(z⁻¹)    [антисиметричний поліном, відкрита связка]
```

Оскільки поліноми `P(z)` та `Q(z)` є симетричними, усі їхні корені лежать суворо на одиничному колі у z-площині (`z = e^(j·ω)`). Корені представлені у вигляді кутових частот `ωᵢ` (від 0 до `π` радіан).

Фундаментальна математична властивість LSP: корені поліномів `P(z)` та `Q(z)` чергуються вздовж частотної осі:

```
0 < ω₁ < ω₂ < ω₃ < ω₄ < ω₅ < ω₆ < ω₇ < ω₈ < ω₉ < ω₁₀ < π
```

де `ω₁, ω₃, ω₅, ω₇, ω₉` є коренями полінома `P(z)`, а `ω₂, ω₄, ω₆, ω₈, ω₁₀` — коренями `Q(z)`.

Завдяки властивості чергування, будь-яке монотонне квантування частот `ωᵢ`, яке зберігає порядок `ω₁ < ω₂ < ... < ω₁₀`, **100% гарантує стійкість** відновленого фільтра синтезу `1 / A(z)`. Відстань між сусідніми частотами `|ωᵢ₊₁ - ωᵢ|` прямо характеризує ширину формантного піку: чим ближче дві частоти одна до одної, тим гострішим та вищим є резонансний пік форманти.

Обчислення коренів `ωᵢ` виконується за допомогою чебишовських поліномів розкладу на відрізку `x = cos(ω) ∈ [-1, 1]`. У кодеку G.729 вектор з 10 частот LSF квантується за допомогою прогнозуючого векторного квантування (Predictive Vector Quantization) всього за 18 біт на кадр.

## 4. Пошук збудження в ACELP та зважена оптимізація

У кодеку G.729 синтезований мовний сигнал `ŝ[n]` формується шляхом пропускання вектора збудження `u[n]` через фільтр синтезу `H = 1 / A(z)`:

```
u[n] = g_p · v[n] + g_c · c[n]
```

де `v[n]` — вектор адаптивного кодбука (pitch), `c[n]` — вектор алгебраїчного кодбука, `g_p` та `g_c` — відповідні коефіцієнти підсилення.

Субкадр містить `N_sub = 40` відліків (5 мс). Вектор алгебраїчного кодбука `c[n]` у G.729 містить рівно 4 ненульові імпульси амплітудою `±1` на фіксованих позиціях:

```
i₀ ∈ {0, 5, 10, 15, 20, 25, 30, 35}     (8 позицій)
i₁ ∈ {1, 6, 11, 16, 21, 26, 31, 36}     (8 позицій)
i₂ ∈ {2, 7, 12, 17, 22, 27, 32, 37}     (8 позицій)
i₃ ∈ {3, 8, 13, 18, 23, 28, 33, 38, 4, 9, 14, 19, 24, 29, 34, 39} (16 позицій)
```

Пошук оптимального вектора `c[n]` виконується шляхом мінімізації середньоквадратичної зваженої помилки `E = ||x - g_c · H_w · c||²`, де `x` — цільовий сигнал за вирахуванням адаптивного збудження, а `H_w` — нижньотрикутна матриця імпульсної характеристики зваженого фільтра синтезу `1 / A(z) · W(z)`.

Мінімізація помилки `E` еквівалентна максимізації критерію `Qₖ`:

```
Max_k { Qₖ } = Max_k { ( Cₖ )² ÷ Eₖ }

Cₖ = dᵀ · cₖ = ∑_{l=0}^{3} s_l · d[i_l]
Eₖ = cₖᵀ · Φ · cₖ = ∑_{l=0}^{3} (d[i_l])² · Φ(i_l, i_l) + 2 · ∑_{l=0}^{2} ∑_{m=l+1}^{3} s_l · s_m · Φ(i_l, i_m)
```

де:
- `d = H_wᵀ · x` — вектор взаємної кореляції між цільовим сигналом та імпульсною характеристикою,
- `Φ = H_wᵀ · H_w` — автокореляційна матриця імпульсної характеристики,
- `s_l ∈ {+1, -1}` — знаки імпульсів на позиціях `i_l`.

Завдяки розрідженій алгебраїчній структурі ACELP, коефіцієнти `d[i]` та матриця `Φ(i, j)` обчислюються заздалегідь перед початком перебору. Пошук по чотирьох кодових сітках скорочується від повного перебору `40⁴ = 2 560 000` комбінацій до всього лише 4096 перевірок у згорнутому циклі, що дозволяє виконувати оптимальний пошук збудження за мікросекунди на простих DSP-процесорах.
