# 🧮 Математична модель Б'янкі: пропускна здатність і оптимум вікна відкату

Протокол CSMA/CA у режимі розподіленої координації (DCF) керує доступом до ефіру за допомогою ймовірнісного механізму: кожна станція обирає випадковий лічильник затримки з вікна змагань `[0, CW]`. Якщо кілька станцій обирають нуль в одному слоті, виникає колізія, після чого вікно подвоюється.

У 2000 році Джузеппе Б'янкі (Giuseppe Bianchi) опублікував у журналі *IEEE Journal on Selected Areas in Communications* математичну модель на основі двовимірного дискретного ланцюга Маркова, яка точно описує насичену пропускну здатність мережі 802.11 як функцію від кількості активних вузлів `n` та параметрів вікна `CWmin` і `CWmax`. Ця модель стала класичним фундаментом для теоретичного аналізу протоколів випадкового доступу до бездротового середовища.

### 1. Базові припущення моделі Б'янкі

Аналіз проводиться в умовах **насичення мережі (Saturation Conditions)**: передбачається, що в черзі кожного з `n` бездротових вузлів завжди є готовий кадр для передачі. Щойно попередній кадр успішно доставлено або скинуто після вичерпання ліміту спроб, наступний кадр негайно завантажується в чергу передавача. Це дозволяє дослідити граничну ємність системи без впливу випадкових пауз між надходженнями пакетів від прикладних програм.

Модель спирається на три фундаментальні припущення:
1. **Ідеальний фізичний канал**: помилки передачі виникають виключно внаслідок колізій (одночасного виходу в ефір двох або більше станцій). Вплив теплового шуму та багатопроменевого затухання на першому етапі вважається знехтовно малим (ймовірність бітової помилки `BER = 0`).
2. **Незмінна та незалежна ймовірність колізії (`p`)**: ймовірність того, що переданий кадр зазнає колізії, є сталою величиною, яка не залежить від історії попередніх спроб передачі даної станції. Це припущення спирається на те, що за великої кількості вузлів змагання в кожному слоті є незалежними подіями.
3. **Симетричність та повна взаємна досяжність**: усі `n` станцій знаходяться в зоні прямої чутності одна одної (відсутні приховані та засвічені вузли), мають однакові апаратні параметри та однакову довжину пакетів.

### 2. Двовимірний ланцюг Маркова для процедури відкату

Стан кожної станції в довільний момент часу описується парою цілих чисел `(s(t), b(t))`:
- `s(t) = i` — поточний ступінь відкату (backoff stage), де `i ∈ [0, m]`. Тут `m` — максимальна кількість повторних спроб подвоєння вікна (`CWmax = 2^m · (CWmin + 1) - 1`). Типово для 802.11a/g/n `CWmin = 15`, `CWmax = 1023`, отже `m = 6`.
- `b(t) = k` — значення лічильника відкату, де `k ∈ [0, W_i - 1]`, а розмір вікна на ступені `i` дорівнює `W_i = 2^i · W_0` (початкове вікно `W_0 = CWmin + 1`).

Позначимо через `p` умовну ймовірність колізії. Ймовірності однокрокових переходів між станами дискретного ланцюга Маркова визначаються правилами функціонування DCF:

```
P{ (i, k) → (i, k - 1) } = 1                           [зворотний відлік у вільному слоті, k ≥ 1]
P{ (0, k) → (0, k) } = (1 - p) / W_0                  [успішна передача скидає ступінь до 0]
P{ (i, k) → (i - 1, 0) } = (1 - p) / W_0              [успіх на ступені i повертає на ступінь 0]
P{ (i, k) → (i, 0) } = p / W_i                         [колізія на ступені i - 1 піднімає ступінь до i]
P{ (m, k) → (m, 0) } = p / W_m                         [на максимальному ступені m вікно більше не росте]
```

Ці правила відображають ключові риси стандарту: декремент лічильника на одиницю в кожному порожньому слоті, рівномірний вибір нового числа відкату з інтервалу `[0, W_i - 1]` та подвоєння діапазону вибору після кожного зіткнення.

### 3. Стаціонарний розподіл станів

Позначимо стаціонарну ймовірність перебування у стані `(i, k)` як `b_{i, k}`.

Для кожного ступеня `i` ймовірність того, що лічильник дорівнює нулю (`k = 0`), пов'язана з нульовим станом попереднього ступеня через імовірність колізії `p`:

```
b_{i, 0} = p · b_{i-1, 0} = p^i · b_{0, 0}             [для всіх 0 < i < m]
b_{m, 0} = (p^m / (1 - p)) · b_{0, 0}                  [для максимального ступеня m]
```

Оскільки лічильник відкату рівномірно зменшується від `k` до `0`, стаціонарні ймовірності для довільного `k ∈ [0, W_i - 1]` виражаються лінійно через `b_{i, 0}`:

```
b_{i, k} = ((W_i - k) / W_i) · b_{i, 0}
```

Сума ймовірностей усіх можливих станів системи повинна дорівнювати одиниці (умова нормування):

```
∑_{i=0}^m ∑_{k=0}^{W_i - 1} b_{i, k} = 1
```

Підставивши вираз для `b_{i, k}` та просумувавши арифметичну прогресію за `k`, маємо:

```
∑_{k=0}^{W_i - 1} ((W_i - k) / W_i) = (W_i + 1) / 2
```

Тоді сума по всіх ступенях `i` набуває вигляду:

```
1 = (b_{0, 0} / 2) · [ ∑_{i=0}^{m-1} p^i · (W_i + 1) + (p^m / (1 - p)) · (W_m + 1) ]
```

Підставляючи `W_i = 2^i · W_0` та обчислюючи суму скінченної геометричної прогресії, отримуємо точний аналітичний вираз для базової ймовірності `b_{0, 0}`:

```
b_{0, 0} = 2 · (1 - 2p) · (1 - p) / [ (1 - 2p) · (W_0 + 1) + p · W_0 · (1 - (2p)^m) ]
```

### 4. Ймовірність передачі в слоті (τ) та нелінійна система

Станція починає передачу в ефір тоді й лише тоді, коли її лічильник відкату сягає нуля, незалежно від поточного ступеня `i`. Отже, ймовірність передачі станції в довільно обраному слоті `τ` дорівнює сумі нульових станів за всіма ступенями відкату:

```
τ = ∑_{i=0}^m b_{i, 0}
= b_{0, 0} / (1 - p)
= 2 · (1 - 2p) / [ (1 - 2p) · (W_0 + 1) + p · W_0 · (1 - (2p)^m) ]
```

З іншого боку, колізія для даної станції настає, якщо хоча б одна з решти `n - 1` станцій також вирішує передавати в цьому ж слоті. Оскільки всі станції діють незалежно і кожна передає з імовірністю `τ`:

```
p = 1 - (1 - τ)^(n - 1)
```

Отримано замкнену систему двох нелінійних рівнянь з двома невідомими `τ` та `p`. Б'янкі довів, що для будь-яких фізичних параметрів `W_0 ≥ 1`, `m ≥ 0` та кількості станцій `n ≥ 2` ця система має єдиний дійсний розв'язок у діапазоні `τ ∈ (0, 1)` і `p ∈ (0, 1)`. 

Розв'язок легко знаходиться чисельно методом простих ітерацій: задається початкове наближення `p_0 = 0`, за першою формулою обчислюється `τ_0`, підставляється у другу формулу для отримання `p_1`, і процес швидко збігається до точного значення за 4–5 кроків.

### 5. Розрахунок нормованої пропускної здатності

Знаючи стаціонарну ймовірність передачі `τ`, визначимо ймовірності ключових подій у системі для одного часового слоту:

1. **Ймовірність зайнятості слоту (`P_tr`)**: ймовірність того, що в ефірі відбувається хоча б одна передача (від однієї або кількох станцій):
   ```
   P_tr = 1 - (1 - τ)^n
   ```

2. **Ймовірність успішної передачі (`P_s`)**: умовна ймовірність того, що зайнятий слот містить передачу рівно однієї станції (без колізії):
   ```
   P_s = (n · τ · (1 - τ)^(n - 1)) / P_tr
   ```

Корисна нормалізована пропускна здатність мережі `S` визначається як частка часу, протягом якої ефір зайнятий передачею корисного навантаження (payload):

```
S = (P_tr · P_s · E[P]) / E[T]
```

де `E[P]` — середній розмір корисних даних кадру (в мікросекундах передачі), а `E[T]` — середня тривалість слоту з урахуванням трьох можливих станів:
- Порожній слот тривалістю `σ` (з імовірністю `1 - P_tr`);
- Успішний слот тривалістю `T_s` (з імовірністю `P_tr · P_s`);
- Слот колізії тривалістю `T_c` (з імовірністю `P_tr · (1 - P_s)`).

Середній час слоту дорівнює:
```
E[T] = (1 - P_tr) · σ + P_tr · P_s · T_s + P_tr · (1 - P_s) · T_c
```

Тривалості успішної передачі `T_s` та колізії `T_c` суттєво залежать від обраного режиму доступу:
- **Базовий доступ (Basic Access)**:
  `T_s = DIFS + T_DATA + SIFS + T_ACK`
  `T_c = DIFS + T_DATA + SIFS + T_ACK_timeout`
- **Доступ із механізмом RTS/CTS**:
  `T_s = DIFS + T_RTS + SIFS + T_CTS + SIFS + T_DATA + SIFS + T_ACK`
  `T_c = DIFS + T_RTS + SIFS + T_CTS_timeout`

### 6. Числовий аналіз та поведінка при зростанні навантаження

Для параметрів фізичного рівня 802.11g (OFDM, 54 Мбіт/с, кадр 1500 байтів, `σ = 9` мкс, `CWmin = 15`, `CWmax = 1023`):

```
 n    |  τ (імовірність TX)  |  p (імовірність колізії) | S (Basic Access) | S (з RTS/CTS)
------+----------------------+--------------------------+------------------+---------------
 2    |        0.089         |          0.089           |      82.4%       |     76.1%
 5    |        0.057         |          0.208           |      74.8%       |     73.4%
 10   |        0.038         |          0.297           |      64.2%       |     70.9%
 20   |        0.024         |          0.375           |      51.1%       |     68.2%
 50   |        0.012         |          0.452           |      33.6%       |     64.7%
```

Ці розрахунки наочно пояснюють фізичну природу поведінки ефіру:
1. За малої кількості абонентів (`n < 5`) базовий доступ без RTS/CTS забезпечує вищу швидкість (82% проти 76%), оскільки чотириетапне рукостискання створює зайвий оверхед часу.
2. При зростанні `n` до 50 станцій пропускна здатність базового доступу зазнає катастрофічного колапсу (падає до 33.6%), тоді як RTS/CTS стабілізує ємність каналу на рівні ~65%.

Диференціюючи вираз для `S` за змінною `τ`, Б'янкі вивів наближену формулу для оптимальної ймовірності передачі:

```
τ_opt ≈ 1 / (n · √( T_c / (2 · σ) ))
```

Звідси випливає теоретично оптимальний розмір вікна змагань:

```
CW_opt ≈ n · √( 2 · T_c / σ )
```

Оскільки в стандартному протоколі `CWmin` є фіксованою величиною, реальна мережа відхиляється від оптимуму при зміні кількості станцій `n`. Це математичне рівняння стало основою для сучасних алгоритмів динамічного регулювання вікна змагань (Adaptive Contention Window) у корпоративних точках доступу Wi-Fi.

### 7. Аномалія різношвидкісних клієнтів (802.11 Performance Anomaly)

Модель Б'янкі також розкриває природу так званої «аномалії продуктивності» (вперше описаної Мартіном Еуссе у 2003 році). Якщо в одній бездротовій комірці працюють швидкі клієнти (наприклад, 54 Мбіт/с) та один повільний застарілий клієнт на межі покриття (наприклад, 802.11b на швидкості 1 Мбіт/с), протокол CSMA/CA надає кожному вузлу рівну ймовірність виграшу в доступі до ефіру (Channel Access Fairness).

Проте передача кадру обсягом 1500 байтів на швидкості 1 Мбіт/с триває близько 12 000 мкс, тоді як передача такого ж кадру на швидкості 54 Мбіт/с займає лише 260 мкс. Повільний клієнт монополізує понад 95% часу ефіру. У результаті пропускна здатність усіх швидких станцій обвалюється до рівня повільного клієнта. Для усунення цієї аномалії в сучасних точках доступу застосовують планувальник рівного часу ефіру (Airtime Fairness), який виділяє клієнтам рівні кванти часу передачі, а не рівну кількість спроб доступу.
