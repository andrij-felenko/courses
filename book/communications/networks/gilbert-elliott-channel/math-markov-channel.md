# 🧮 Математичний апарат моделі Гілберта–Елліота

Ця математична вставка розгортає строгий апарат двостанового марковського каналу з пам'яттю: від спектрального розкладу матриці переходів і точного виведення стаціонарного розподілу до автокореляційної функції помилок, розподілу проміжків між помилками, ймовірності блокових помилок, аналітичного розрахунку виграшу від перемішування, пропускної здатності за Шенноном та методів статистичного оцінювання параметрів за реальними трасами передачі. Без цього апарату неможливо аналітично розрахувати ймовірність переповнення буферів, оптимальну глибину переміжника чи затримку доставки пакетів у протоколах повторної передачі.

## Матричний опис і спектральний розклад

Розглянемо дискретний у часі марковський ланцюг із простором станів `S = {G, B}`, де стан `G` позначає сприятливі умови передачі (Good, добрий стан), а стан `B` — несприятливі (Bad, поганий стан або стан завади). Дискретний час `t ∈ {0, 1, 2, …}` відповідає номерам послідовно переданих символів, бітів або мережевих пакетів.

Ймовірності переходу між станами за один крок позначимо як:

```
P_GB = P(S[t+1] = B | S[t] = G)    [ймовірність деградації каналу]
P_BG = P(S[t+1] = G | S[t] = B)    [ймовірність відновлення каналу]
```

Ймовірності збереження поточного стану становлять `P_GG = 1 - P_GB` та `P_BB = 1 - P_BG`. Матриця перехідних ймовірностей `P` розміром `2 × 2` записується у стохастичній формі, де сума елементів у кожному рядку дорівнює одиниці:

```
P = [ 1 - P_GB    P_GB   ]
    [   P_BG    1 - P_BG ]
```

Для аналізу еволюції каналу в часі знайдемо власні числа матриці `P` із характеристичного рівняння `det(P - λ·I) = 0`:

```
det [ (1 - P_GB) - λ         P_GB         ] = 0
    [      P_BG         (1 - P_BG) - λ    ]

(1 - P_GB - λ)·(1 - P_BG - λ) - P_GB·P_BG = 0
λ² - (2 - P_GB - P_BG)·λ + (1 - P_GB - P_BG + P_GB·P_BG) - P_GB·P_BG = 0
λ² - (2 - P_GB - P_BG)·λ + (1 - P_GB - P_BG) = 0
(λ - 1)·(λ - (1 - P_GB - P_BG)) = 0
```

Звідси отримуємо два корені — спектр матриці `P`:

```
λ₁ = 1
λ₂ = 1 - P_GB - P_BG
```

Перше власне число `λ₁ = 1` відповідає стаціонарному стану ергодичного марковського ланцюга (теорема Перрона–Фробеніуса). Друге власне число `λ₂ = 1 - P_GB - P_BG` визначає коефіцієнт пам'яті каналу: саме воно задає швидкість згасання кореляції між станами в часі. Для стійкого зв'язку з позитивною пам'яттю (схильністю затримуватися в поточному стані) виконується умова `0 < λ₂ < 1`, що еквівалентно `P_GB + P_BG < 1`.

Знайдемо ліві та праві власні вектори для кожного власного числа.

Для `λ₁ = 1`:
Лівий власний вектор `v₁ = [v₁₁, v₁₂]` задовольняє рівняння `v₁ · P = v₁`:

```
v₁₁·(1 - P_GB) + v₁₂·P_BG = v₁₁
-v₁₁·P_GB + v₁₂·P_BG = 0
v₁₁·P_GB = v₁₂·P_BG
```

З урахуванням умови нормування `v₁₁ + v₁₂ = 1`, отримуємо лівий власний вектор `v₁ = [P_BG / (P_GB + P_BG), P_GB / (P_GB + P_BG)] = [π_G, π_B]`, який є стаціонарним розподілом станів. Правий власний вектор для `λ₁ = 1` є одиничним стовпцем `u₁ = [1, 1]ᵀ`, оскільки сума елементів у кожному рядку стохастичної матриці дорівнює 1.

Для `λ₂ = 1 - P_GB - P_BG`:
Лівий власний вектор `v₂ · P = λ₂ · v₂` дає:

```
v₂₁·(1 - P_GB) + v₂₂·P_BG = (1 - P_GB - P_BG)·v₂₁
v₂₁ - v₂₁·P_GB + v₂₂·P_BG = v₂₁ - v₂₁·P_GB - v₂₁·P_BG
v₂₂·P_BG = -v₂₁·P_BG
v₂₂ = -v₂₁
```

Обираючи `v₂ = [1, -1]`, відповідний правий власний вектор `u₂ = [u₂₁, u₂₂]ᵀ` задовольняє `P · u₂ = λ₂ · u₂` та умову ортонормованості `v₂ · u₂ = 1`:

```
v₂ · u₂ = u₂₁ - u₂₂ = 1
u₂ = [ P_GB / (P_GB + P_BG), -P_BG / (P_GB + P_BG) ]ᵀ = [ π_B, -π_G ]ᵀ
```

Застосувавши спектральну теорему розкладу `P = λ₁ · u₁ · v₁ + λ₂ · u₂ · v₂`, матрицю переходу за `k` кроків `Pᵏ` можна подати у замкненій аналітичній формі:

```
Pᵏ = 1ᵏ · [ 1 ] · [ π_G  π_B ] + λ₂ᵏ · [  π_B ] · [ 1  -1 ]
          [ 1 ]                        [ -π_G ]

Pᵏ = [ π_G   π_B ] + (1 - P_GB - P_BG)ᵏ · [  π_B  -π_B ]
     [ π_G   π_B ]                        [ -π_G   π_G ]
```

Покомпонентно для кожного елемента матриці `Pᵏ_{ij}`:

```
Pᵏ_{GG} = P(S[t+k] = G | S[t] = G) = π_G + π_B · (1 - P_GB - P_BG)ᵏ
Pᵏ_{GB} = P(S[t+k] = B | S[t] = G) = π_B - π_B · (1 - P_GB - P_BG)ᵏ
Pᵏ_{BG} = P(S[t+k] = G | S[t] = B) = π_G - π_G · (1 - P_GB - P_BG)ᵏ
Pᵏ_{BB} = P(S[t+k] = B | S[t] = B) = π_B + π_G · (1 - P_GB - P_BG)ᵏ
```

З цієї формули безпосередньо видно, що при `k → ∞`, оскільки `|λ₂| < 1`, складова `λ₂ᵏ → 0`, і матриця `Pᵏ` експоненційно швидко збігається до стаціонарної матриці, рядки якої однакові й дорівнюють `[π_G, π_B]`. Швидкість збіжності повністю визначається величиною `λ₂`.

## Виведення стаціонарного розподілу

Стаціонарний розподіл імовірностей перебування каналу у станах `G` та `B` позначимо рядковим вектором `π = [π_G, π_B]`. За означенням інваріантної міри, вектор `π` задовольняє матричне рівняння балансу й умову нормування:

```
π · P = π
π_G + π_B = 1
```

Розпишемо матричне рівняння покомпонентно:

```
π_G·(1 - P_GB) + π_B·P_BG = π_G    [рівняння балансу для стану G]
π_G·P_GB + π_B·(1 - P_BG) = π_B    [рівняння балансу для стану B]
```

Перенесемо доданки в першому рівнянні:

```
π_G - π_G·P_GB + π_B·P_BG = π_G
-π_G·P_GB + π_B·P_BG = 0
π_G·P_GB = π_B·P_BG                [умова детального балансу]
```

Ця рівність має прозорий фізичний зміст: у сталому режимі середня кількість переходів із стану `G` у стан `B` за одиницю часу в точності дорівнює середній кількості зворотних переходів із `B` у `G`.

Підставимо умову нормування `π_G = 1 - π_B` в отримане рівняння детального балансу:

```
(1 - π_B)·P_GB = π_B·P_BG          [підстановка π_G = 1 - π_B]
P_GB - π_B·P_GB = π_B·P_BG         [розкриття дужок]
P_GB = π_B·(P_GB + P_BG)           [групування доданків з π_B]
π_B = P_GB / (P_GB + P_BG)         [стаціонарна частка поганого стану]
```

Аналогічно, підставивши `π_B = 1 - π_G`:

```
π_G·P_GB = (1 - π_G)·P_BG          [підстановка π_B = 1 - π_G]
π_G·P_GB = P_BG - π_G·P_BG         [розкриття дужок]
π_G·(P_GB + P_BG) = P_BG           [групування доданків з π_G]
π_G = P_BG / (P_GB + P_BG)         [стаціонарна частка доброго стану]
```

Отримані співвідношення показують, що частка часу перебування каналу в кожному стані обернено пропорційна ймовірності виходу з цього стану. Якщо `P_GB ≪ P_BG`, то канал більшу частину часу проводить у доброму стані (`π_G ≈ 1`), зрідка впадаючи в короткочасні збурення.

## Статистика тривалості перебування в станах

Нехай канал увійшов у стан `B` у момент часу `t₀`. Позначимо випадкову величину тривалості безперервного перебування каналу в поганому стані (довжину пачки завади) як `L_B`.

Оскільки марковський ланцюг не має передісторії (пам'ять обмежується лише попереднім кроком), на кожному такті процес залишається у стані `B` з імовірністю `1 - P_BG` і виходить у стан `G` з імовірністю `P_BG`. Подія `{L_B = k}` означає, що канал залишався в `B` рівно `k - 1` тактів поспіль і на `k`-му такті перейшов у `G`:

```
P(L_B = k) = (1 - P_BG)ᵏ⁻¹ · P_BG,    k = 1, 2, 3, …
```

Це класичний дискретний геометричний розподіл з параметром успіху `P_BG`. Знайдемо його математичне сподівання `E[L_B]` за означенням:

```
E[L_B] = ∑_{k=1}^∞ k · P(L_B = k)
       = ∑_{k=1}^∞ k · (1 - P_BG)ᵏ⁻¹ · P_BG
       = P_BG · ∑_{k=1}^∞ k · qᵏ⁻¹           [де q = 1 - P_BG]
```

Скористаємося відомою формулою диференціювання геометричного ряду `∑_{k=0}^∞ qᵏ = 1 / (1 - q)`:

```
d/dq (∑_{k=0}^∞ qᵏ) = ∑_{k=1}^∞ k · qᵏ⁻¹
d/dq (1 / (1 - q)) = 1 / (1 - q)²

∑_{k=1}^∞ k · qᵏ⁻¹ = 1 / (1 - (1 - P_BG))² = 1 / P_BG²
```

Підставивши цей результат у вираз для математичного сподівання:

```
E[L_B] = P_BG · (1 / P_BG²) = 1 / P_BG    [середня довжина пачки]
```

Знайдемо дисперсію тривалості перебування в стані `B`:

```
E[L_B·(L_B - 1)] = ∑_{k=2}^∞ k·(k - 1) · qᵏ⁻¹ · P_BG
                 = P_BG · q · ∑_{k=2}^∞ k·(k - 1) · qᵏ⁻²
                 = P_BG · q · (d²/dq² ∑_{k=0}^∞ qᵏ)
                 = P_BG · q · (2 / (1 - q)³)
                 = P_BG · (1 - P_BG) · (2 / P_BG³)
                 = 2·(1 - P_BG) / P_BG²

E[L_B²] = E[L_B·(L_B - 1)] + E[L_B]
        = 2·(1 - P_BG) / P_BG² + 1 / P_BG
        = (2 - 2·P_BG + P_BG) / P_BG²
        = (2 - P_BG) / P_BG²

Var(L_B) = E[L_B²] - (E[L_B])²
         = (2 - P_BG) / P_BG² - 1 / P_BG²
         = (1 - P_BG) / P_BG²             [дисперсія тривалості пачки]
```

Повністю симетрично, тривалість перебування в доброму стані `L_G` розподілена геометрично з параметром `P_GB`:

```
P(L_G = m) = (1 - P_GB)ᵐ⁻¹ · P_GB,    m = 1, 2, 3, …
E[L_G] = 1 / P_GB                     [середній інтервал між пачками]
Var(L_G) = (1 - P_GB) / P_GB²
```

Геометричний розподіл має високу дисперсію: середньоквадратичне відхилення `σ(L_B) = √(1 - P_BG) / P_BG` співмірне із самим середнім значенням `1 / P_BG`. Це пояснює, чому в реальних мережах окремі пачки помилок можуть у рази перевищувати середнє значення, утворюючи довгі «хвости» затримок і втрат.

## Автокореляція та коваріація помилок

Нехай `E[t] ∈ {0, 1}` — випадковий індикатор помилки на такті `t`, де `E[t] = 1`, якщо переданий біт/пакет зазнав спотворення, і `E[t] = 0`, якщо прийнятий без помилок.

Ймовірність помилки обумовлена поточним прихованим станом каналу:

```
P(E[t] = 1 | S[t] = G) = e_G    [ймовірність помилки в стані G]
P(E[t] = 1 | S[t] = B) = e_B    [ймовірність помилки в стані B]
```

Безумовне математичне сподівання (середній рівень помилок `BER` або `PLR`):

```
⟨e⟩ = E[E[t]]
    = P(S[t] = G)·P(E[t]=1 | S[t]=G) + P(S[t] = B)·P(E[t]=1 | S[t]=B)
    = π_G · e_G + π_B · e_B
    = (P_BG · e_G + P_GB · e_B) / (P_GB + P_BG)
```

Оскільки `E[t] ∈ {0, 1}`, величина `E[t]² = E[t]`, тому дисперсія окремого спостереження дорівнює:

```
Var(E[t]) = ⟨e⟩ · (1 - ⟨e⟩)
```

Знайдемо автокореляційну функцію процесу помилок `R_e(k) = E[E[t] · E[t+k]]` для лагу `k ≥ 1`:

```
E[E[t] · E[t+k]] = ∑_{i ∈ {G,B}} ∑_{j ∈ {G,B}} P(S[t]=i, S[t+k]=j) · P(E[t]=1 | S[t]=i) · P(E[t+k]=1 | S[t+k]=j)
                 = ∑_{i} ∑_{j} π_i · Pᵏ_{ij} · e_i · e_j
```

Підставимо явні вирази для перехідних ймовірностей за `k` кроків `Pᵏ_{ij}`, отримані вище через друге власне число `λ₂ = 1 - P_GB - P_BG`:

```
Pᵏ_{GG} = π_G + π_B · λ₂ᵏ
Pᵏ_{GB} = π_B - π_B · λ₂ᵏ
Pᵏ_{BG} = π_G - π_G · λ₂ᵏ
Pᵏ_{BB} = π_B + π_G · λ₂ᵏ
```

Обчислимо подвійну суму:

```
R_e(k) = π_G·(π_G + π_B·λ₂ᵏ)·e_G² + π_G·(π_B - π_B·λ₂ᵏ)·e_G·e_B
       + π_B·(π_G - π_G·λ₂ᵏ)·e_B·e_G + π_B·(π_B + π_G·λ₂ᵏ)·e_B²
```

Розкриємо дужки та згрупуємо стаціонарні доданки (незалежні від `k`) і доданки при `λ₂ᵏ`:

```
Стаціонарна частина:
  π_G²·e_G² + 2·π_G·π_B·e_G·e_B + π_B²·e_B²
  = (π_G·e_G + π_B·e_B)²
  = ⟨e⟩²

Кореляційна частина при λ₂ᵏ:
  π_G·π_B·λ₂ᵏ·e_G² - 2·π_G·π_B·λ₂ᵏ·e_G·e_B + π_G·π_B·λ₂ᵏ·e_B²
  = π_G·π_B·(e_B - e_G)² · λ₂ᵏ
```

Таким чином, автокореляційна функція має вигляд:

```
R_e(k) = ⟨e⟩² + π_G·π_B·(e_B - e_G)² · (1 - P_GB - P_BG)ᵏ
```

Автоковаріаційна функція `Cov(E[t], E[t+k]) = R_e(k) - ⟨e⟩²` дорівнює:

```
Cov(E[t], E[t+k]) = π_G · π_B · (e_B - e_G)² · (1 - P_GB - P_BG)ᵏ
```

А нормований коефіцієнт автокореляції `ρ(k)`:

```
ρ(k) = Cov(E[t], E[t+k]) / Var(E[t])
     = [ π_G · π_B · (e_B - e_G)² / (⟨e⟩ · (1 - ⟨e⟩)) ] · (1 - P_GB - P_BG)ᵏ
```

Звідси очевидні три фундаментальні висновки:
1. Якщо `P_GB + P_BG = 1`, то `λ₂ = 0`, і `Cov(E[t], E[t+k]) = 0` для всіх `k ≥ 1`. Канал вироджується в канал без пам'яті (двійковий симетричний канал BSC).
2. Якщо `e_B = e_G`, помилки в обох станах однакові, тому коваріація занулюється: стан каналу не впливає на ймовірність виникнення помилки.
3. При `P_GB + P_BG < 1` коваріація спадає строго експоненційно зі швидкістю `λ₂ᵏ`. Характерний час кореляції каналу (тривалість збереження пам'яті) дорівнює:

```
τ_corr = -1 / ln(1 - P_GB - P_BG) ≈ 1 / (P_GB + P_BG)    [при малих P_GB, P_BG]
```

## Розподіл інтервалів між помилками (Gap Distribution)

У класичній моделі Гілберта (`e_G = 0`, `e_B = 1 - h`, де `h` — параметр проникності помилок, часто `e_B = 0.5`) інтерес становить розподіл довжини проміжку `k` послідовних безпомилкових символів між двома сусідніми помилками: `G(k) = P(0ᵏ 1 | 1)`.

Оскільки помилка може статися виключно в стані `B` (бо `e_G = 0`), факт виникнення помилки в момент `t` однозначно фіксує стан каналу: `S[t] = B`.

Позначимо матриці спостережень для безпомилкового кроку `M₀` та кроку з помилкою `M₁`:

```
M₀ = P · [ 1 - e_G      0    ] = [ 1 - P_GB       0      ]    [для e_G = 0]
         [    0      1 - e_B ]   [ P_BG·(1-e_B)  (1-P_BG)·(1-e_B) ]

M₁ = P · [ e_G    0  ] = [    0           0       ]
         [  0    e_B ]   [ P_BG·e_B   (1-P_BG)·e_B ]
```

Тоді ймовірність спостереження `k` нулів поспіль після одиниці записується через вектор-рядок початкового стану в `B` (вектор `[0, 1]`) та одиничний вектор-стовпець `[1, 1]ᵀ`:

```
P(0ᵏ | 1) = [0, 1] · (M₀)ᵏ · [1, 1]ᵀ
```

Для матриці `M₀` характерні власні числа визначають двоекспоненційну структуру спадання проміжків: короткі проміжки всередині пачки (коли канал залишається в `B`, але випадково видає безпомилковий біт із шансом `1 - e_B`) та довгі інтервали між пачками (коли канал переходить у стан `G`).

Функція розподілу проміжків `G(k) = P(0^{k-1} 1 | 1)` набуває форми зваженої суми двох геометричних розподілів:

```
G(k) = A · αᵏ⁻¹ + (1 - A) · βᵏ⁻¹
```

де `α` та `β` — власні числа матриці `M₀`, а коефіцієнт `A` визначається ймовірностями переходів. Саме ця подвійна експонента є характерним підписом пачкового каналу в емпіричних вимірюваннях.

## Ймовірність помилок у блоці коду P(m, N)

Для розрахунку блокових кодів виправлення помилок (наприклад, кодів Ріда–Соломона чи BCH), які виправляють до `t` помилок у кодовому слові довжини `N`, необхідно знати ймовірність появи рівно `m` помилок у блоці довжини `N`: `P(m, N)`.

У каналі без пам'яті ця величина описується біноміальним розподілом `P(m, N) = C(N, m) · pᵐ · (1 - p)ᴺ⁻ᵐ`. У каналі Гілберта–Елліота біноміальна формула непридатна через кореляцію між сусідніми бітами.

Для обчислення `P(m, N)` застосовують рекурентний підхід. Визначимо вектор `f(m, n) = [f_G(m, n), f_B(m, n)]`, де `f_s(m, n)` — ймовірність того, що у блоці з перших `n` символів виникло рівно `m` помилок, а канал після `n`-го символу опинився у стані `s ∈ {G, B}`.

Початкові умови при `n = 0`:

```
f(0, 0) = [π_G, π_B]
f(m, 0) = [0, 0]        для всіх m > 0
```

Рекурентний крок від `n-1` до `n` враховує, чи поточний символ був переданий без помилки (матриця `M₀`), чи з помилкою (матриця `M₁`):

```
f(m, n) = f(m, n-1) · M₀ + f(m-1, n-1) · M₁    [для 0 ≤ m ≤ n]
```

Повна ймовірність `m` помилок у блоці довжини `N` дорівнює сумі компонент вектора `f(m, N)`:

```
P(m, N) = f_G(m, N) + f_B(m, N)
```

Ймовірність невиправної блокової помилки для коду з корекційною здатністю `t`:

```
P_block_error = ∑_{m = t+1}^N P(m, N) = 1 - ∑_{m=0}^t P(m, N)
```

Завдяки рекурентній матричній схемі складність точного розрахунку `P(m, N)` для блоку довжиною `N` становить `O(N²)`, що дозволяє точно оптимізувати параметри блокових кодів без тривалого Монте-Карло моделювання.

## Аналітичний виграш від перемішування (Interleaving Gain)

Переміжники трансформують часову структуру помилок, збільшуючи ефективну відстань між символами одного кодового слова в каналі до величини глибини перемішування `D`.

Якщо `D ≫ τ_corr = 1 / (P_GB + P_BG)`, символи одного кодового слова проходять крізь канал з ефективною матрицею переходів `Pᴰ`. Оскільки `Pᴰ → [ [π_G, π_B], [π_G, π_B] ]` при `D → ∞`, помилки на різних позиціях розкодованого слова стають асимптотично незалежними.

Для коду `(N, K)` з корекцією `t` помилок:
- **Без перемішування (`D = 1`):** Ймовірність руйнування кодового слова визначається ймовірністю потрапляння в блок пачки, що перевищує `t`:
  ```
  P_word_no_int ≈ π_B · P(L_B > t) + π_G · P_GB · N · e_Bᵗ
  ```
  При довгій середній пачці `1 / P_BG ≫ t` майже кожна пачка гарантовано вбиває блок.

- **З ідеальним перемішуванням (`D → ∞`):** Помилки в блоці розподілені за біноміальним законом із середнім `⟨e⟩`:
  ```
  P_word_ideal_int = ∑_{m = t+1}^N C(N, m) · ⟨e⟩ᵐ · (1 - ⟨e⟩)ᴺ⁻ᵐ
  ```

Виграш від перемішування становить:

```
Gain_int = P_word_no_int / P_word_ideal_int
```

У типових системах зв'язку з `⟨e⟩ ≈ 10⁻³` та середньою довжиною пачки `1/P_BG = 20` цей виграш сягає 3–5 порядків величини (від `10⁻²` до `10⁻⁶`), що перетворює непридатний канал на надійне середовище передачі.

## Пропускна здатність каналу Гілберта–Елліота

Пропускна здатність за Шенноном залежить від того, чи відомий стан каналу передавачу й приймачу (наявність Channel State Information, CSI).

### 1. Пропускна здатність з ідеальним знанням стану (CSI на приймачі та передавачі)

Якщо приймач і передавач точно знають поточний стан `S[t]`, канал розпадається на суміш двох двійкових симетричних каналів `BSC(e_G)` та `BSC(e_B)` з пропускними здатностями `C_G = 1 - H(e_G)` та `C_B = 1 - H(e_B)`, де `H(p) = -p·log₂(p) - (1-p)·log₂(1-p)` — двійкова ентропійна функція.

Середня пропускна здатність дорівнює математичному сподіванню:

```
C_CSI = π_G · (1 - H(e_G)) + π_B · (1 - H(e_B))
      = 1 - [ π_G · H(e_G) + π_B · H(e_B) ]
```

### 2. Пропускна здатність без знання стану каналу (No CSI)

Якщо стани каналу приховані, ентропія шуму визначається ентропією марковського процесу з пам'яттю. За теоремою про пропускну здатність каналів зі скінченним числом станів:

```
C_noCSI = 1 - lim_{N→∞} (1/N) · H(E₁, E₂, …, E_N)
```

Через опуклість ентропійної функції `H(p)` завжди виконується фундаментальна нерівність:

```
π_G · H(e_G) + π_B · H(e_B) ≤ H(⟨e⟩) = H(π_G · e_G + π_B · e_B)
```

Звідси випливає важливий парадокс теорії зв'язку: **пропускна здатність каналу з пам'яттю Гілберта–Елліота завжди строго ВИЩА за пропускну здатність каналу без пам'яті з тим самим середнім рівнем помилок `⟨e⟩`**:

```
C_GE ≥ 1 - H(⟨e⟩) = C_BSC
```

Причина полягає в тому, що згрупованість помилок у пачки зменшує невизначеність (ентропію) шуму: якщо попередній біт помилковий, ми з високою ймовірністю знаємо, що наступний біт також спотвориться. Пам'ять каналу несе інформацію про його стан, яку досконалий приймач може використовувати для оптимального декодування.

## Числовий приклад розрахунку системи

Розглянемо реалістичні параметри радіоканалу з повільними завмираннями:
- Ймовірність переходу `G → B`: `P_GB = 0.01` (в середньому одна пачка на кожні 100 бітів).
- Ймовірність відновлення `B → G`: `P_BG = 0.10` (середня тривалість пачки — 10 бітів).
- Рівень помилок у доброму стані: `e_G = 0.001` (1 помилка на 1000 бітів).
- Рівень помилок у поганому стані: `e_B = 0.50` (глибоке завмирання, повна втрата сигналу).

**Крок 1. Розрахунок стаціонарного розподілу:**

```
π_G = P_BG / (P_GB + P_BG) = 0.10 / (0.01 + 0.10) = 0.10 / 0.11 ≈ 0.9091   (90.91%)
π_B = P_GB / (P_GB + P_BG) = 0.01 / (0.01 + 0.10) = 0.01 / 0.11 ≈ 0.0909   (9.09%)
```

**Крок 2. Середня тривалість перебування в станах:**

```
E[L_B] = 1 / P_BG = 1 / 0.10 = 10 бітів     [середня пачка]
E[L_G] = 1 / P_GB = 1 / 0.01 = 100 бітів    [середній чистий інтервал]
```

**Крок 3. Середній коефіцієнт помилок каналу (BER):**

```
⟨e⟩ = π_G · e_G + π_B · e_B                        [формула середнього BER]
    = 0.9091 · 0.001 + 0.0909 · 0.50               [підстановка числових значень часток]
    = 0.0009091 + 0.04545                          [обчислення добутків]
    ≈ 0.04636                                      [підсумок: 4.64% середніх помилок]
```

**Крок 4. Характеристики пам'яті та кореляції:**

```
λ₂ = 1 - P_GB - P_BG = 1 - 0.01 - 0.10 = 0.89
τ_corr = -1 / ln(0.89) ≈ -1 / (-0.1165) ≈ 8.58 бітів
```

Коефіцієнт кореляції двох сусідніх бітів (`k = 1`):

```
Var(E[t]) = ⟨e⟩ · (1 - ⟨e⟩) = 0.04636 · (1 - 0.04636) ≈ 0.04421
Cov(E[t], E[t+1]) = π_G · π_B · (e_B - e_G)² · λ₂  [формула автоковаріації першого лагу]
                  = 0.9091 · 0.0909 · (0.50 - 0.001)² · 0.89 [підстановка параметрів]
                  = 0.08264 · 0.2490 · 0.89        [обчислення проміжних добутків]
                  ≈ 0.01831                        [коваріація на лагу k = 1]
ρ(1) = 0.01831 / 0.04421 ≈ 0.4141
```

Коефіцієнт кореляції `ρ(1) = 0.414` свідчить про виражену пам'ять каналу: якщо поточний біт помилковий, ймовірність помилки в наступному біті становить `P(E[t+1]=1 | E[t]=1) = ⟨e⟩ + Cov / ⟨e⟩ = 0.04636 + 0.01831 / 0.04636 ≈ 0.4413` (44.1%), що майже вдесятеро перевищує середній рівень `4.64%`.

## Оцінювання параметрів за трасами вимірювань

Для налаштування моделі під реальний радіолінк або дротову мережу необхідно оцінити чотири параметри `{P_GB, P_BG, e_G, e_B}` за експериментальною бітовою або пакетною трасою помилок `e = (e₁, e₂, …, e_N)`.

### 1. Метод моментів (для спрощеної моделі з e_G = 0, e_B = 0.5)

Якщо добрий стан вважається безпомилковим (`e_G = 0`), а в поганому стані сигнал повністю деградує (`e_B = 0.5`), модель має лише два невідомих параметри `P_GB` та `P_BG`. За трасою довжиною `N` обчислюємо емпіричні оцінки:
- Частоту помилок: `BER̂ = (1/N) ∑_{t=1}^N e[t]`.
- Умовну ймовірність помилки після помилки: `P̂(E[t]=1 | E[t-1]=1) = ∑_{t=2}^N e[t]·e[t-1] / ∑_{t=1}^{N-1} e[t]`.

Теоретичні значення цих статистик через параметри моделі:

```
⟨e⟩ = π_B · 0.5 = 0.5 · P_GB / (P_GB + P_BG)

P(E[t]=1 | E[t-1]=1) = R_e(1) / ⟨e⟩
                     = [ ⟨e⟩² + π_G·π_B·0.25·(1 - P_GB - P_BG) ] / ⟨e⟩
                     = ⟨e⟩ + 0.5·π_G·(1 - P_GB - P_BG)
                     = 1 - 0.5·P_BG
```

Розв'язуючи систему відносно `P_GB` та `P_BG`:

```
P̂_BG = 2 · (1 - P̂(E[t]=1 | E[t-1]=1))
P̂_GB = 2 · BER̂ · P̂_BG / (1 - 2·BER̂)
```

### 2. Алгоритм Баума–Велша (HMM Baum-Welch / EM)

Для повної моделі Елліота (`e_G > 0, e_B < 1`), де стани є строго прихованими (Hidden Markov Model), застосовують EM-алгоритм (Expectation-Maximization).

**Крок E (Expectation):** За поточними оцінками параметрів обчислюють прямі ймовірності `α_t(i) = P(e₁, …, e_t, S_t = i)` та зворотні ймовірності `β_t(i) = P(e_{t+1}, …, e_N | S_t = i)` за рекурентними формулами:

```
α_t(j) = [ ∑_{i ∈ {G,B}} α_{t-1}(i) · P_{ij} ] · P(e_t | S_t = j)
β_t(i) = ∑_{j ∈ {G,B}} P_{ij} · P(e_{t+1} | S_{t+1} = j) · β_{t+1}(j)
```

Імовірність перебування у стані `i` в момент `t`:

```
γ_t(i) = P(S_t = i | e) = (α_t(i) · β_t(i)) / ∑_{j} (α_t(j) · β_t(j))
```

Імовірність переходу зі стану `i` у стан `j` між моментами `t` та `t+1`:

```
ξ_t(i, j) = P(S_t = i, S_{t+1} = j | e)
          = (α_t(i) · P_{ij} · P(e_{t+1} | S_{t+1} = j) · β_{t+1}(j)) / P(e)
```

**Крок M (Maximization):** Оновлення параметрів максимізує функцію правдоподібності:

```
P̂_{ij} = ∑_{t=1}^{N-1} ξ_t(i, j) / ∑_{t=1}^{N-1} γ_t(i)
ê_i    = ∑_{t=1, e_t=1}^N γ_t(i) / ∑_{t=1}^N γ_t(i)
```

Ітерації повторюють до збіжності за логарифмічною функцією правдоподібності `log P(e)`. Отримані параметри гарантують точне відтворення статистичних властивостей реального каналу в симуляторах мереж.
