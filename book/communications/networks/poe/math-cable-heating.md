# 🧮 Розрахунок втрат, опору петлі та нагріву кабельних джгутів PoE

Передавання електричної потужності по сигнальних кабелях зв'язку підпорядковується фундаментальним законам електродинаміки та теплопередачі. На відміну від силової електропроводки, де провідники мають великий переріз (1.5–2.5 мм²), мідні жили витої пари [UTP](topic:communications/utp-cable) мають діаметр лише 0.5–0.6 мм (переріз 0.20–0.26 мм²). На довжині 100 метрів активний опір кабелю стає вирішальним чинником, що обмежує вихідну потужність, визначає ККД передавання та нагріває кабельні траси.

## Опір провідника та опір шлейфу (Loop Resistance)

Опір суцільного металевого провідника довжиною `L` з площею поперечного перерізу `S` визначається питомим опором матеріалу `ρ`:

```
R_cond = ρ · L / S
```

Для електротехнічної міді за температури 20 °C питомий опір становить `ρ_20 ≈ 1.724 · 10⁻⁸ Ом·м` (або `0.01724 Ом·мм²/м`).

У витій парі провідники скручені між собою з певним кроком звивання, тому фізична довжина мідної жили на 2–4% більша за лінійну довжину оболонки кабелю `L_cable`. Для стандартного 100-метрового кабелю реальна довжина жили становить `L_wire ≈ 102...104 м`.

### Порівняння категорій кабелю за калібром жили (AWG)

Стандартні мережеві кабелі випускаються з жилами двох основних калібрів американського стандарту дротів (AWG, *American Wire Gauge*):
1. **Cat5e (24 AWG):** номінальний діаметр жили `d = 0.511 мм`.
   Площа перерізу: `S = π · d² / 4 = π · (0.511)² / 4 ≈ 0.205 мм²`.
   Опір однієї 100-метрової жили:
   ```
   R_cond = 0.01724 · 103 / 0.205
   ≈ 8.66 Ом                 [номінальний опір жили Cat5e за 20 °C]
   ```
   З урахуванням допусків на товщину міді та нагрів стандарт фіксує граничний максимум `R_cond,max = 9.38 Ом`.
2. **Cat6A (23 AWG):** номінальний діаметр жили `d = 0.574 мм`.
   Площа перерізу: `S = π · (0.574)² / 4 ≈ 0.258 мм²`.
   Опір однієї 100-метрової жили:
   ```
   R_cond = 0.01724 · 103 / 0.258
   ≈ 6.88 Ом                 [номінальний опір жили Cat6A за 20 °C]
   ```
   З урахуванням виробничих допусків стандарт фіксує максимум `R_cond,max = 7.40 Ом`.

### Опір петлі для 2-парного та 4-парного живлення

Струм живлення виходить із джерела PSE, доходить до пристрою PD і повертається назад. Повний опір цього контуру називають **опором петлі постійному струму** (*DC Loop Resistance*, `R_loop`).

#### 1. Двопарне живлення (2-Pair PoE / PoE+: IEEE 802.3af та 802.3at)
Струм тече вперед по двох паралельних жилах однієї пари (наприклад, контакти 1 і 2) і повертається назад по двох паралельних жилах другої пари (контакти 3 і 6):

```
R_fwd = R_cond / 2            [дві жили пари увімкнені паралельно]
R_ret = R_cond / 2            [дві жили зворотного напрямку паралельно]
R_loop,2p = R_fwd + R_ret
= (R_cond / 2) + (R_cond / 2) [додавання опорів прямого і зворотного шляхів]
= R_cond                      [опір шлейфу дорівнює опору однієї жили]
```

Для 100 м кабелю Cat5e номінальний опір петлі становить близько 9.38 Ом. Проте стандарти IEEE 802.3af/at закладають найгірший сценарій: граничний опір постійному струму `R_loop,max = 20.0 Ом` (що враховує перехідні опори патч-панелей, роз'ємів 8P8C та нагрів кабелю до 60 °C).

#### 2. Чотирипарне живлення (4-Pair PoE++: IEEE 802.3bt)
Усі чотири пари несуть струм одночасно. Прямий струм ділиться між чотирма жилами (пари 1-2 та 4-5), а зворотний — між чотирма іншими (пари 3-6 та 7-8):

```
R_fwd,4p = R_cond / 4         [чотири жили прямого напрямку паралельно]
R_ret,4p = R_cond / 4         [чотири жили зворотного напрямку паралельно]
R_loop,4p = R_fwd,4p + R_ret,4p
= (R_cond / 4) + (R_cond / 4) [додавання опорів 4-провідникових гілок]
= R_cond / 2                  [опір зменшився рівно вдвічі]
= R_loop,2p / 2               [співвідношення з 2-парною схемою]
```

Перехід на 4-парне живлення зменшує опір шлейфу **рівно вдвічі**. Для 100 м Cat5e номінальний опір 4-парної петлі становить лише `R_loop,4p ≈ 4.7 Ом` (стандартний розрахунковий максимум — 12.5 Ом).

## Асиметрія опору провідників та насичення трансформаторів

У реальному кабелі опір жил ніколи не є ідеально однаковим. Відхилення діаметра міді, різниця в кроці звивання пар та контактний опір роз'ємів створюють асиметрію.

### 1. Внутрішньопарна асиметрія (In-Pair DC Resistance Unbalance)
Нехай жили однієї пари мають опори `R_wire1` та `R_wire2`. Асиметрія виражається у відсотках:

```
Unbalance_pair = (|R_wire1 - R_wire2| / (R_wire1 + R_wire2)) · 100%
```

Стандарт TIA-568 обмежує цю величину максимум **3%**. Якщо крізь пару тече сумарний струм `I_pair`, то струми в жилах розподіляються за правилом дільника струму:

```
I_1 = I_pair · (R_wire2 / (R_wire1 + R_wire2))
I_2 = I_pair · (R_wire1 / (R_wire1 + R_wire2))
ΔI = |I_1 - I_2| = I_pair · (|R_wire1 - R_wire2| / (R_wire1 + R_wire2))
```

Різницевий постійний струм `ΔI` протікає через половини первинної обмотки трансформатора в одному напрямку і не компенсується, створюючи залишковий постійний магнітний потік у феритовому осерді:

```
Φ_net = ΔI · N_half           [де N_half — число витків напівплеча]
B_net = Φ_net / S_core        [індукція магнітного поля в осерді]
```

Якщо `B_net` наближається до індукції насичення фериту (`B_sat ≈ 0.3...0.4 Тл`), диференційна проникність осердя стрімко падає. У результаті індуктивність сигнального трансформатора падає з нормативних 350 мкГн до менш ніж 50 мкГн, що викликає спотворення високочастотних імпульсів (Pulse Droop) та масову втрату гігабітних пакетів.

### 2. Міжпарна асиметрія (Pair-to-Pair Resistance Unbalance, P2PRU)
Для 4-парного живлення 802.3bt струм ділиться між двома паралельними парами з опорами `R_pairA` та `R_pairB`:

```
P2PRU = (|R_pairA - R_pairB| / (R_pairA + R_pairB)) · 100%
```

Стандарт IEEE 802.3bt вимагає `P2PRU ≤ 7%`. При перевищенні цієї межі одна з пар перевантажується за струмом, що викликає локальний перегрів окремої витої пари всередині оболонки кабелю.

## Нелінійне навантаження постійної потужності (CPL) та стійкість

Імпульсний стабілізатор DC-DC на вході живленого пристрою підтримує стабільну вихідну напругу вторинного кола незалежно від коливань на вході. Якщо внутрішня електроніка споживає постійну потужність `P_PD`, то при падінні вхідної напруги `V_PD` струм споживання не падає, а **зростає**:

```
I = P_PD / V_PD
```

Це фундаментальна властивість імпульсних джерел: вони діють як **навантаження постійної потужності** (*Constant Power Load*, CPL).

Знайдемо диференційний опір такого навантаження:

```
R_diff = dV_PD / dI
= d(P_PD / I) / dI            [визначення похідної функції навантаження]
= - P_PD / I^2                [взяття похідної від 1/I]
= - (V_PD)^2 / P_PD < 0       [підстановка P_PD = V_PD · I]
```

Диференційний опір є **від'ємним**. Зі збільшенням напруги струм падає, а при зниженні напруги — зростає.

### Рівняння робочої точки напруги

Складемо рівняння балансу напруг у колі, де джерело PSE видає напругу `V_PSE`, опір кабелю становить `R_loop`, а навантаження споживає потужність `P_PD`:

```
V_PD = V_PSE - I · R_loop
V_PD = V_PSE - (P_PD / V_PD) · R_loop    [підстановка I = P_PD / V_PD]
V_PD^2 = V_PSE · V_PD - P_PD · R_loop    [множення обох частин на V_PD]
V_PD^2 - V_PSE · V_PD + P_PD · R_loop = 0 [перенесення всіх членів ліворуч]
```

Отримали квадратне рівняння відносно невідомої напруги на пристрої `V_PD`. Його дискримінант:

```
D = V_PSE^2 - 4 · P_PD · R_loop
```

Фізично реальний розв'язок існує лише тоді, коли `D ≥ 0`. Звідси випливає фундаментальна межа максимальної потужності `P_max`, яку взагалі можливо передати по лінії з опором `R_loop` за напруги `V_PSE`:

```
V_PSE^2 - 4 · P_max · R_loop = 0          [умова нульового дискримінанта]
P_max = V_PSE^2 / (4 · R_loop)            [теоретична межа потужності]
```

Розв'язок для робочої напруги:

```
V_PD = (V_PSE + √(V_PSE^2 - 4 · P_PD · R_loop)) / 2
```

> ⚠️ Знак «мінус» перед коренем відповідає нестійкому режиму з низькою напругою та надвисоким струмом, у якому система колапсує. Стійка робота можлива лише за умови `V_PD > V_PSE / 2`, тобто коли спад напруги на кабелі не перевищує половини напруги джерела:
> ```
> R_loop < |R_diff| = (V_PD)^2 / P_PD
> ```

### Покроковий розрахунок для IEEE 802.3at (PoE+)

Нехай комутатор видає `V_PSE = 50.0 В`, опір кабельної петлі становить максимум `R_loop = 20.0 Ом`, а пристрій споживає повну потужність класу 4: `P_PD = 25.5 Вт`.

Порахуймо напругу на пристрої, струм у кабелі та потужність теплових втрат:

```
D = (50.0)^2 - 4 · 25.5 · 20.0
= 2500 - 2040                 [обчислення компонентів дискримінанта]
= 460 В²                      [дискримінант додатний, режим стійкий]

V_PD = (50.0 + √460) / 2
= (50.0 + 21.4476) / 2        [обчислення кореня з дискримінанта]
= 35.72 В                     [напруга на клемах PD]

I = P_PD / V_PD
= 25.5 / 35.72                [підстановка споживаної потужності та напруги]
= 0.714 А                     [робочий струм у петлі кабелю]

P_loss = I^2 · R_loop
= (0.714)^2 · 20.0            [джоулеві втрати в опорі кабелю]
= 10.20 Вт                    [теплова потужність, що нагріває кабель]

P_PSE = P_PD + P_loss
= 25.5 + 10.20                [повна потужність, видана комутатором]
= 35.70 Вт                    [потужність на боці джерела]
```

ККД передавання потужності:

```
η = P_PD / P_PSE
= 25.5 / 35.70                [відношення корисної потужності до повної]
≈ 71.4%                       [коефіцієнт корисної дії каналу]
```

Майже 29% енергії (понад 10 Вт) безповоротно перетворюється на [джоулеве тепло](topic:physics/joule-heating) всередині 100-метрового кабелю.

### Теорема узгодження потужності Якобі проти енергетичного ККД

Знайдемо максимум функції потужності навантаження `P_PD(I) = V_PSE · I - I^2 · R_loop`, взявши її першу похідну за струмом:

```
dP_PD / dI = d(V_PSE · I - I^2 · R_loop) / dI
= V_PSE - 2 · I · R_loop      [диференціювання за струмом]
```

Прирівняємо похідну до нуля, щоб знайти точку екстремуму:

```
V_PSE - 2 · I_opt · R_loop = 0
I_opt = V_PSE / (2 · R_loop)  [струм точки максимальної передачі потужності]
```

Підставимо цей оптимальний струм у вираз для напруги на навантаженні:

```
V_PD,opt = V_PSE - I_opt · R_loop
= V_PSE - (V_PSE / (2 · R_loop)) · R_loop [підстановка оптимального струму]
= V_PSE - (V_PSE / 2)         [скорочення опору шлейфу]
= V_PSE / 2                   [напруга на навантаженні становить рівно половину джерела]
```

Знайдемо еквівалентний опір навантаження в цій точці:

```
R_load,opt = V_PD,opt / I_opt
= (V_PSE / 2) / (V_PSE / (2 · R_loop))    [ділення напруги на струм]
= R_loop                      [умова узгодження Якобі: опір навантаження дорівнює опору лінії]
```

Обчислимо ККД передавання в точці максимальної потужності:

```
η_opt = P_PD,opt / P_PSE,opt
= (V_PD,opt · I_opt) / (V_PSE · I_opt)   [скорочення струму]
= V_PD,opt / V_PSE
= (V_PSE / 2) / V_PSE         [підстановка половини напруги]
= 1 / 2                       [коефіцієнт корисної дії]
= 50.0%                       [половина всієї енергії втрачається на нагрів лінії]
```

Цей класичний висновок (теорема Якобі) показує, що узгодження опорів є прийнятним для радіочастотних сигнальних кіл, але **абсолютно неприпустимим для ліній електроживлення**. Робота в точці максимальної потужності означала б, що комутатор видає 180 Вт, із яких 90 Вт виділяється у вигляді розпеченого кабелю в стіні, а навантаження отримує лише 90 Вт.

Тому стандарти IEEE 802.3 суворо обмежують робочу область лівою частиною характеристики (`I << I_opt`), де напруга навантаження `V_PD ≥ 0.75 · V_PSE`, а коефіцієнт корисної дії становить `η ≥ 75...90%`.

## Фізична небезпека біметалевого кабелю (CCA — Copper-Clad Aluminum)

На ринку кабельної продукції часто зустрічається дешевий кабель із маркуванням **CCA** (обміднений алюміній, *Copper-Clad Aluminum*). У такому кабелі серцевина жили виготовлена з алюмінію, на який гальванічним способом нанесено тонкий шар міді (лише 10–15% за об'ємом).

Для високочастотних сигналів Ethernet (100 МГц) завдяки скін-ефекту струм витісняється до поверхні, тому сигнал проходить по зовнішньому мідному шару, і CCA-кабель формально може пройти базовий тест на передачу даних. Проте для постійного струму PoE скін-ефект відсутній: струм рівномірно тече по всьому перерізу алюмінієвого ядра.

### Порівняльний розрахунок втрат: чиста мідь проти CCA

Питомий опір електротехнічного алюмінію `ρ_Al ≈ 0.0282 Ом·мм²/м`, що в 1.64 раза вище за чисту мідь.

1. **Опір петлі 100 м кабелю CCA (24 AWG):**
   ```
   R_loop,CCA = 1.64 · R_loop,Cu
   = 1.64 · 20.0 Ом
   = 32.8 Ом                  [опір петлі CCA-кабелю]
   ```
2. **Втрати при передачі потужності PoE+ (I = 0.6 А):**
   ```
   P_loss,Cu = (0.6)^2 · 20.0
   = 0.36 · 20.0
   = 7.2 Вт                   [втрати в якісному мідному кабелі]

   P_loss,CCA = (0.6)^2 · 32.8
   = 0.36 · 32.8
   = 11.81 Вт                 [втрати в кабелі CCA зростають на 64%]
   ```
3. **Критичне просідання напруги:**
   ```
   V_drop,CCA = I · R_loop,CCA
   = 0.6 А · 32.8 Ом
   = 19.68 В                  [спад напруги на шлейфі]

   V_PD,CCA = V_PSE - V_drop,CCA
   = 50.0 В - 19.68 В
   = 30.32 В                  [напруга впала нижче порогу UVLO 36 В]
   ```

При спробі живити пристрій PoE+ через 100-метровий кабель CCA напруга на вході просідає нижче порогу блокування `V_UVLO ≈ 36 В`. Контролер PD циклічно вмикається і вимикається (Boot-Looping), а 12 Вт тепла, сконцентровані в тонких алюмінієвих жилах із низькою температурою плавлення, призводять до деградації контактів RJ-45, окиснення алюмінію на ножових контактах і займання кабельних трас. Стандарти IEEE 802.3af/at/bt прямо забороняють використання кабелів CCA.

## Теплова модель нагріву кабельного джгута

Коли одиничний кабель прокладено відкрито в повітрі, він легко розсіює 5–10 Вт тепла через природну конвекцію та випромінювання. Проте в реальних структурованих кабельних системах (СКС) десятки й сотні кабелів зв'язують у **щільні джгути** всередині монтажних лотків, перфорованих коробів або глухих гофрованих труб під фальшстелею.

У щільному джгуті з `N` кабелів тепло, що виділяється внутрішніми кабелями, не може вільно вийти назовні: воно змушене проходити крізь пластикову ізоляцію та повітряні мікрозазори сусідніх шарів кабелів.

### Рівняння радіального теплового потоку

Джгут радіусом `R_b` можна змоделювати як циліндричний масив із рівномірним об'ємним джерелом тепла `q_v` (Вт/м³):

```
q_v = N · P_loss / (π · R_b^2 · L)
```

Стаціонарний перепад температури `ΔT` між гарячим ядром у центрі джгута та температурою навколишнього середовища `T_amb` виражається через ефективний тепловий опір джгута `R_th,bundle`:

```
ΔT = T_core - T_amb
= N · (P_loss / L) · R_th,bundle [перепад температури в ядрі джгута]
```

Тепловий опір залежить від кількості кабелів `N`, типу оболонки (ПВХ або LSZH) та способу прокладання (відкритий дротяний лоток чи закрита труба). Згідно з дослідженнями асоціації TIA (стандарт TIA TSB-184-A) та ISO/IEC TR 29125:
* Для відкритого джгута з 24 кабелів Cat5e під навантаженням PoE+ (30 Вт) нагрів ядра становить `ΔT ≈ +7...10 °C`.
* Для щільного джгута з 96 кабелів Cat5e під навантаженням Type 4 (90 Вт на кабель) перегрів ядра перевищує `ΔT ≥ +35...45 °C`!

### Позитивний зворотний зв'язок самонагріву

Підвищення температури міді призводить до лінійного зростання її питомого опору:

```
R(T) = R_20 · (1 + α · (T - 20))
```

де `α ≈ +0.00393 / °C` — температурний коефіцієнт електричного опору міді.

При нагріванні кабелю від 20 °C до 60 °C його опір збільшується на:

```
ΔR / R_20 = 0.00393 · (60 - 20)
= 0.00393 · 40                [множення коефіцієнта на приріст температури]
≈ +15.7%                      [відносне зростання опору провідника]
```

Зростання опору збільшує втрати `P_loss = I^2 · R`, що викликає додаткове виділення тепла і подальше зростання температури. Якщо тепловий опір короба зависокий, система входить у процес теплового розгону аж до розм'якшення та деструкції полімерної ізоляції жил (максимальна робоча температура для поліетилену ізоляції становить 60–75 °C).

#### Порівняльна таблиця перегріву джгутів: Cat5e проти Cat6A

Асоціація TIA у бюлетені TSB-184-A наводить результати емпіричних вимірювань перегріву `ΔT` у центрі щільного круглого джгута в закритому повітронепроникному просторі за струму 0.6 А на пару (PoE+ 30 Вт на кабель):

```general
Кількість кабелів    Cat5e UTP (24 AWG)    Cat6A UTP (23 AWG)    Cat6A F/UTP (з фольгою)
в джгуті (N)         Перегрів ядра ΔT      Перегрів ядра ΔT      Перегрів ядра ΔT
12 кабелів           +3.8 °C               +2.6 °C               +2.1 °C
24 кабелі            +7.9 °C               +5.4 °C               +4.2 °C
48 кабелів           +15.2 °C              +10.5 °C              +8.1 °C
96 кабелів           +29.4 °C              +20.1 °C              +15.3 °C
192 кабелі           +53.0 °C (неприпустимо)+36.2 °C             +27.8 °C
```

З аналізу таблиці видно три важливі фізичні закономірності:
1. **Ефект калібру міді:** Кабель Cat6A з товстішими жилами 23 AWG має на 25% менший опір, тому за однакового струму він генерує на чверть менше тепла. Перегрів ядра зменшується пропорційно.
2. **Ефект металевого екрана (F/UTP):** Алюмінієва фольга екрана має набагато вищу теплопровідність, ніж полівінілхлорид оболонки. Фольга діє як радіальний тепловий розподільник, ефективно відводячи тепло з глибини джгута до його зовнішньої поверхні.
3. **Нелінійність масштабування:** При подвоєнні кількості кабелів (з 24 до 48 і далі до 96) об'ємне тепловиділення подвоюється, але площа зовнішньої поверхні циліндричного джгута росте лише як корінь квадратний `√N`. Тому перегрів ядра зростає значно швидше, ніж лінійно.

Це вимагає від проєктувальників СКС обмежувати максимальний розмір одного джгута силових кабелів PoE пучками не більше 24–48 кабелів та використовувати просторові металеві гребінки для організації вентиляційних зазорів між окремими пучками.

## Температурний дерейтинг довжини лінії (Thermal Derating)

Крім ризику пожежі та оплавлення, нагрів кабелю викликає різке зростання **загасання високочастотного сигналу Ethernet** (*Insertion Loss*). Кожні +10 °C температури збільшують високочастотні втрати в кабелі на 4% (для неекранованого UTP) або на 2% (для екранованого F/UTP, S/FTP).

Щоб високошвидкісний зв'язок (1G/2.5G/5G/10G) залишався стабільним при передаванні високої потужності PoE, стандарти TIA-568 та ISO 11801 вимагають скорочувати максимальну довжину кабельного тракту зі 100 метрів за формулою температурного дерейтингу:

```
L_max(T) = 100 / (1 + H · (T_amb + ΔT - 20))
```

де `H ≈ 0.004 / °C` для кабелю UTP при температурі вище 40 °C.

Наприклад, якщо температура в кабельному лотку з урахуванням перегріву джгута досягає 60 °C:

```
L_max = 100 / (1 + 0.004 · (60 - 20))
= 100 / (1 + 0.16)            [обчислення знаменника дерейтингу]
= 100 / 1.16                  [ділення базової довжини 100 м]
≈ 86.2 м                      [гранична допустима довжина траси]
```

Максимальну гарантовану довжину каналу зв'язку необхідно скоротити зі 100 м до **86 метрів**. Нехтування цим правилом призводить до постійних циклічних розривів зв'язку (Flapping) та появи помилок контрольної суми CRC в пакетах при зростанні навантаження PoE.
