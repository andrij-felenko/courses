# 🔌 Схемотехніка PD-інтерфейсу та гальванічна розв'язка

Живлений мережевий пристрій (PD, англ. *Powered Device* — IP-камера, точка доступу Wi-Fi, датчик промислової автоматики чи контролер доступу) не може безпосередньо приєднати свій внутрішній стабілізатор напруги до контактів роз'єму 8P8C. Між витою парою та внутрішніми вторинними колами живлення (3.3 В, 5 В чи 12 В) завжди стоїть спеціалізований вхідний вузол — **інтерфейс живленого пристрою** (PD Interface Front-End).

Цей апаратний каскад вирішує три взаємопов'язані інженерні завдання:
1. Забезпечує фізичну сумісність із будь-якою полярністю напруги та будь-яким методом подачі живлення (Alternative A чи Alternative B).
2. Реалізує апаратний протокол багатоступеневого узгодження з джерелом живлення (PSE): підмикання точного резистора детекції, стабілізацію струму класифікації та обмеження пускового струму.
3. Створює обов'язковий бар'єр [гальванічної розв'язки](topic:electronics/galvanic-isolation) напругою 1500 В середньоквадратичного значення (Vrms) між кабельною магістраллю та доступними користувачеві металевими частинами приладу.

## Вхідний випрямний каскад: пасивні діоди проти «ідеального моста»

Згідно зі стандартом IEEE 802.3, пристрій PD зобов'язаний успішно запускатися незалежно від того, як саме під'єднано дріт: прямим чи кросоверним патч-кордом, за стандартом T568A чи T568B, по сигнальних парах 1-2/3-6 чи по вільних парах 4-5/7-8. Ба більше, при використанні передавання Alternative A комутатор із підтримкою Auto-MDIX може подати позитивний потенціал як на пару 1-2, так і на пару 3-6.

Тому на вході живлення завжди встановлюють два випрямні мости (по одному для кожної групи пар):

```general
           Пара 1-2 (Pins 1, 2) ───┐
                                   ├─── [ Випрямний міст A ] ───┐
           Пара 3-6 (Pins 3, 6) ───┘                            │
                                                                ├───► Шина V_PORT (постійна полярність: V+ / V−)
           Пара 4-5 (Pins 4, 5) ───┐                            │
                                   ├─── [ Випрямний міст B ] ───┘
           Пара 7-8 (Pins 7, 8) ───┘
```

У малопотужних пристроях стандарту 802.3af (до 13 Вт) зазвичай використовують звичайні діодні мости на діодах Шотткі. Проте напівпровідниковий діод має прямий спад напруги `V_f ≈ 0.5...0.7 В`. Оскільки струм тече послідовно через два діоди моста (прямий та зворотний провідники), сумарний спад напруги становить `V_loss = 2 · V_f ≈ 1.0...1.4 В`.

Для стандарту 802.3af при струмі 350 мА втрати потужності на діодах становлять:

```
P_loss = V_loss · I
= 1.2 В · 0.35 А
= 0.42 Вт
```

Це прийнятно для бюджету 13 Вт. Але для стандарту 802.3bt Type 4, де сумарний струм сягає 1.7–1.9 А (по майже 0.9 А на кожну пару мостів), звичайні діоди розсіювали б:

```
P_loss = 1.2 В · 1.8 А
= 2.16 Вт
```

Розсіяти понад 2 Вт тепла всередині герметичного корпусу компактної вуличної камери без радіаторів означає перегріти процесор і скоротити термін служби електролітичних конденсаторів.

Тому в сучасних пристроях PoE+ та PoE++ застосовують **активні мости на польових транзисторах** (так звані «ідеальні діоди», *Ideal Diode Bridge*). Схема складається з чотирьох потужних N-канальних MOSFET із наднизьким опором відкритого каналу (`R_DS(on) ≤ 30...50 мОм`) та інтегрованого зарядового насоса (*charge pump*). Керувальна мікросхема відстежує полярність напруги на виводах і відкриває відповідні транзистори. 

Спад напруги на відкритому транзисторі становить усього `V_drop = I · R_DS(on) ≈ 0.9 А · 0.04 Ом = 0.036 В`. Загальні втрати двох мостів падають до менш ніж `0.15 Вт`, що підвищує ККД вхідного каскаду до 99.2%.

## Кола сигнатури детекції та класифікації

Одразу за випрямним мостом починається високовольтна секція контролера PD. Вона керує двома ключовими вимірювальними резисторами:

### 1. Сигнатурний резистор детекції (Detection Signature)
Для розпізнавання пристрою за стандартом IEEE 802.3 використовується високоточний тонкоплівковий резистор номіналом **24.9 кОм з допуском ±1%**. Коли комутатор PSE зондує лінію низькою напругою 2.8–10 В, внутрішній ключ контролера PD тримає цей резистор увімкненим паралельно шині живлення.

Якби цей резистор залишався підключеним постійно під час штатної роботи напругою 54 В, на ньому даремно виділялася б потужність:

```
P_det = V^2 / R_det
= (54 В)^2 / 24900 Ом
≈ 0.117 Вт (117 мВт)
```

Тому контролер містить послідовний MOSFET-перемикач сигнатури: щойно напруга на вході перевищує поріг детекції (~12–14 В), мікросхема автоматично відмикає сигнатурний резистор від силової шини, зводячи струм витоку до нуля.

### 2. Струмове джерело класифікації (Classification Signature)
Між виводами VCLASS і VSS підключається калібрувальний резистор `R_class`. Коли PSE подає напругу класифікації в діапазоні 14.5–20.5 В, контролер PD вмикає точне джерело струму, величина якого однозначно задається номіналом `R_class`. Комутатор вимірює струм, що протікає по кабелю, і визначає клас потужності:

```general
Клас    Струм шини      Номінал R_class     Потужність на PSE
Class 0  0...4 мА        Не встановлено      15.4 Вт (дефолт)
Class 1  9...12 мА       1270 Ом ±1%         4.0 Вт
Class 2  17...20 мА      698 Ом ±1%          7.0 Вт
Class 3  26...30 мА      442 Ом ±1%          15.4 Вт
Class 4  36...44 мА      309 Ом ±1%          30.0 Вт (PoE+)
```

Для стандартів 802.3bt (Class 5–8) контролер використовує динамічне перемикання струмових сигнатур у відповідь на серію імпульсів класифікації від джерела (Multi-Event Handshake).

## Силовий ключ гарячого підключення (Hot-Swap) та плавний пуск

Найнебезпечніший момент роботи PoE — перехід від класифікації до подачі повної робочої напруги 48–57 В. 

На вході вторинного DC-DC перетворювача завжди встановлюють згладжувальний конденсатор високої ємності (`C_bulk` від 100 до 470 мкФ). Якщо подати 54 В на розряджений конденсатор безпосередньо, миттєвий струм заряду визначатиметься лише опором кабелю та ESR конденсатора:

```
I_peak = V_in / (R_cable + ESR)
= 54 В / (10 Ом + 0.1 Ом)
≈ 5.3 А
```

Такий стрибок струму з високою швидкістю наростання `dI/dt` викличе різке просідання напруги на виході комутатора, спрацьовування апаратного захисту від короткого замикання (OCP) на боці PSE та утворення мікроіскри в роз'ємі 8P8C, що поступово руйнує золоте напилення контактів.

Щоб запобігти цьому, контролер PD містить силовий N-канальний польовий транзистор (Pass Switch), увімкнений у розрив негативної шини живлення (між клемою VSS і внутрішньою землею RTN), та інтегратор заряду затвора:

1. **Кероване наростання напруги (dv/dt Control).** Під час увімкнення напруги контролер подає на затвор Pass MOSFET стабільний мікрострум (зазвичай 10–20 мкА). Транзистор плавно виходить із режиму відсічки в лінійний (активний) режим, обмежуючи максимальний пусковий струм на безпечному рівні `I_inrush ≤ 140...400 мА`.
2. **Блокування при зниженні напруги (UVLO, Undervoltage Lockout).** Схема постійно контролює напругу на шині. Поки напруга не досягне порогу стабільної роботи (близько 38–42 В), внутрішній силовий ключ залишається закритим, а імпульсний перетворювач — заблокованим. Пороговий компаратор має вбудований гістерезис 8–10 В (вимкнення відбувається лише при падінні нижче 30–32 В), що запобігає автоколиванням при просіданні напруги під навантаженням.
3. **Сигнал готовності (Power Good / PG).** Щойно напруга на конденсаторі `C_bulk` зрівнюється з вхідною напругою шини, а Pass MOSFET повністю переходить у режим насичення (відкритий канал), мікросхема видає логічний сигнал `PG = 1`. Цей сигнал знімає блокування з виводу Enable вторинного DC-DC перетворювача.

## Захист від імпульсних перенапруг (TVS) та узгодження Боба Сміта

Окрім перетворення живлення, вхідний інтерфейс зобов'язаний захищати чутливу кремнієву структуру від високовольтних викидів природного та індустріального походження (грозові наводки на довгі зовнішні кабелі, комутаційні сплески при перемиканні індуктивних навантажень в електромережі будівлі та електростатичні розряди оператора).

### 1. Діоди придушення перехідних перенапруг (TVS)
Паралельно кожному вхідному діодному мосту та на шині V_PORT встановлюють двонапрямлені супресори (TVS-діоди, *Transient Voltage Suppressor*). 
* Напруга пробою TVS-діода підбирається так, щоб вона перевищувала максимальну робочу напругу PoE (поріг відсічки `V_BR ≈ 58...64 В`).
* При грозовому імпульсі з напругою в кілька кіловольт (тест IEC 61000-4-5) діод лавинно відкривається за одиниці пікосекунд і шунтує струм до десятків ампер, обмежуючи пікову напругу на контролері на безпечному рівні (нижче 80 В, що є максимально допустимою напругою пробою для більшості кремнієвих процесів контролерів PD).

### 2. Термінація Боба Сміта та блокувальні конденсатори
У класичному неекранованому Ethernet для придушення синфазного шуму та узгодження хвильового опору спільних мод використовують схему термінації Боба Сміта (*Bob Smith Termination*): середні точки невикористовуваних або сигнальних обмоток з'єднуються через резистори 75 Ом і високовольтний конденсатор (1–2 нФ, 2–3 кВ) на шасі приладу.

У схемах PoE пряме з'єднання середніх точок трансформаторів із 75-омними резисторами є катастрофічним: постійна напруга 54 В викличе безперервний постійний струм через резистори на землю, що призведе до їхнього миттєвого вигорання:

```
P = V^2 / R
= (54 В)^2 / 75 Ом
= 38.88 Вт (вигорання SMD-резистора)
```

Тому в колах PoE перед кожним 75-омним резистором термінації обов'язково встановлюють високовольтний керамічний конденсатор ємністю 10–100 нФ із робочою напругою не менше 100 В. Конденсатор створює нескінченний опір для постійного струму живлення 54 В, але вільно пропускає високочастотний синфазний шум (десятки та сотні мегагерців) на корпус приладу.

## Гальванічна розв'язка та топологія DC-DC

Стандарт IEEE 802.3 вимагає, щоб між провідниками кабелю Ethernet і будь-якими металевими елементами, доступними оператору (корпус приладу, USB-порти, аудіороз'єми, роз'єми сенсорів), витримувалася **гальванічна ізоляція з діелектричною міцністю 1500 Vrms (частотою 50/60 Гц протягом 60 секунд)** або 2250 В постійного струму.

Ця вимога обумовлена тим, що 100-метровий кабель може пролягати між різними приміщеннями, поверхами або навіть окремими спорудами з різними контурами заземлення. За відсутності розв'язки різниця потенціалів між «землями» спричинить небезпечні струми вирівнювання через екран і провідники кабелю, що створить [земляну петлю](topic:electronics/ground-loops) та спалить порти.

Тому вторинний перетворювач завжди будують за ізольованою топологією:
* Для потужностей до 30 Вт (PoE / PoE+) промисловим стандартом є **зворотноходовий перетворювач (Flyback Converter)**. Він потребує мінімальної кількості компонентів: одного силового трансформатора з ізольованими обмотками, первинного MOSFET-ключа та діода або синхронного випрямляча на вторинному боці. Сигнал зворотного зв'язку за напругою передається через [оптопару](topic:electronics/galvanic-isolation).
* Для потужностей 60–90 Вт (PoE++) використовують **прямоходовий перетворювач із активним обмеженням (Active-Clamp Forward)** або резонансний перетворювач **LLC**, оскільки вони забезпечують менші динамічні втрати перемикання та ККД понад 92–95%.

## Програмний моніторинг телеметрії PSE/PD

У сучасних керованих комутаторах та контролерах PoE діагностика параметрів порту (напруга, миттєвий струм, розсіяна потужність, статус сигнатури детекції та лічильники перевантаження) реалізується через опитування регістрів драйвера по шині I2C/SPI.

Приклад обробки та валідації телеметрії силового порту PSE:

```c
#include <stdint.h>
#include <stdbool.h>

/* Статуси детекції порту PSE за стандартом IEEE 802.3 */
typedef enum {
    POE_DET_UNKNOWN     = 0,
    POE_DET_VALID_25K   = 1, /* Виявлено валідну сигнатуру 24.9 кОм */
    POE_DET_LOW_RES     = 2, /* Занижений опір (коротке замикання) */
    POE_DET_HIGH_RES    = 3, /* Завищений опір або відкрита лінія */
    POE_DET_HIGH_CAP    = 4  /* Ємність лінії > 150 нФ */
} poe_detection_status_t;

/* Сирі дані телеметрії порта з регістрів контролера */
typedef struct {
    uint16_t voltage_raw_mv;   /* Напруга в мілівольтах (наприклад 54000) */
    uint16_t current_raw_ma;   /* Струм у міліамперах */
    uint8_t  detection_code;   /* Код регістру детекції */
    uint8_t  fault_flags;      /* Біти аварій: bit0=OCP, bit1=UVLO, bit2=OTP */
} poe_port_raw_telemetry_t;

/* Обчислений діагностичний звіт */
typedef struct {
    float voltage_v;
    float current_a;
    float power_w;
    poe_detection_status_t status;
    bool is_powered;
    bool has_fault;
} poe_port_metrics_t;

bool poe_parse_telemetry(const poe_port_raw_telemetry_t *raw, poe_port_metrics_t *out) {
    if (!raw || !out) {
        return false;
    }

    out->voltage_v = (float)raw->voltage_raw_mv / 1000.0f;
    out->current_a = (float)raw->current_raw_ma / 1000.0f;
    out->power_w   = out->voltage_v * out->current_a;

    switch (raw->detection_code) {
        case 0x01: out->status = POE_DET_VALID_25K; break;
        case 0x02: out->status = POE_DET_LOW_RES;   break;
        case 0x03: out->status = POE_DET_HIGH_RES;  break;
        case 0x04: out->status = POE_DET_HIGH_CAP;  break;
        default:   out->status = POE_DET_UNKNOWN;   break;
    }

    out->is_powered = (raw->voltage_raw_mv >= 44000);
    out->has_fault  = (raw->fault_flags != 0);

    return true;
}
```
