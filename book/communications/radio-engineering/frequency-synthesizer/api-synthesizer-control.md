# 📋 Апаратний SPI-інтерфейс та конфігурація регістрів синтезатора частот

Сучасні високочастотні мікросхеми синтезаторів частот (наприклад, Analog Devices ADF4351, ADF4350 або Maxim Integrated MAX2870) випускаються у вигляді монолітних КМОН/БіКМОН інтегральних схем. Для взаємодії з мікроконтролером або ПЛІС вони оснащуються послідовним цифровим інтерфейсом SPI (англ. *Serial Peripheral Interface*).

Управління роботою синтезатора здійснюється шляхом програмування внутрішнього блоку 32-бітних регістрів. Налаштування включає обчислення коефіцієнтів ділення дільників, вибір струму помпи заряду, налаштування фазового детектора, вибір режимів екранування та вихідної потужності.

---

### Апаратний інтерфейс SPI та часові діаграми

Для підключення синтезатора до мікроконтролера використовуються чотири цифрові лінії:

1. **SCLK (Serial Clock):** Тактовий сигнал послідовного інтерфейсу. Більшість синтезаторів підтримують тактові частоти SPI до 50 МГц. Записування даних здійснюється за наростаючим фронтом `SCLK`.
2. **SDATA / MOSI (Serial Data In):** Лінія послідовних даних. Дані передаються старшими бітами вперед (MSB First).
3. **LE / CS (Latch Enable / Chip Select):** Сигнал вибору мікросхеми та фіксації даних. Поки `LE` перебуває в низькому логічному рівні (`0`), біти зсуваються у внутрішній зсувний регістр. За позитивним фронтом або високим рівнем `LE` 32-бітне слово перезаписується з внутрішнього зсувного регістра у відповідний паралельний регістр керування.
4. **MUXOUT / LD (Lock Detect Output):** Мультиплексований вихідний пін стану. У робочому режимі він використовується як цифровий індикатор захоплення фази (Lock Detect), на якому встановлюється високий рівень `1`, коли петля ФАПЧ увійшла в стан синхронізму.

При передачі 32-бітного слова старші 29 біт (`[31:3]`) містять конфігураційні дані, а молодші 3 біти (`[2:0]`) є адресою внутрішнього регістра.

### Детальна карта регістрів керування (Register Map)

Чип керується 6 основними 32-бітними регістрами (R0...R5).

```
+----------+-------------------------------------------------------------+
| Регістр  | Поля та функціональне призначення                           |
+----------+-------------------------------------------------------------+
|    R0    | [30:15] INT (16 біт ціла частина) | [14:3] FRAC (12 біт дріб) |
|    R1    | [14:3] MOD (12 біт знаменник) | [27] Prescaler (8/9 чи 4/5) |
|    R2    | [13:3] R-Divider | [12:9] CP Current | [8] PD Polarity          |
|    R3    | [14:3] Clock Divider | [15] VCO Band Select | [18] CP Tri-State|
|    R4    | [4:3] Output Power (-4..+5 дБм) | [5] RF Enable | [6] Aux En   |
|    R5    | [23:22] Lock Detect Pin Mode (LD) | [19:16] Reserved (0x3)  |
+----------+-------------------------------------------------------------+
```

#### Поле-за-полем розбір функціональних бітів:

1. **Регістр R0 (Основне налаштування частоти):**
   - **`[30:15] INT (16 біт):`** Значення цілочисельного дільника у зворотному зв'язку. Допустимий діапазон від 23 до 65535.
   - **`[14:3] FRAC (12 біт):`** Чисельник дробової частини (від 0 до `MOD - 1`). При `FRAC = 0` синтезатор автоматично переходить у цілочисельний режим (Integer-N), вимикаючи Сигма-Дельта модулятор для зниження шумів.

2. **Регістр R1 (Дробові параметри та прескалер):**
   - **`[14:3] MOD (12 біт):`** Знаменник дробового коефіцієнта (від 2 до 4095). Обчислюється виходячи із бажаного кроку налаштування: `MOD = f_PFD / Δf`.
   - **`[27] Prescaler (1 біт):`** Вибір базового двомодульного дільника. `0` відповідає режиму 4/5 (для вихідних частот VCO до 3 ГГц), `1` відповідає режиму 8/9 (для частот вище 3 ГГц).

3. **Регістр R2 (Параметри фазового детектора та помпи заряду):**
   - **`[13:3] R-Divider (10 біт):`** Дільник опорної частоти (від 1 до 1023).
   - **`[12:9] CP Current (4 біти):`** Налаштування вихідного струму помпи заряду `I_cp` (від 0.31 мА до 5.0 мА з кроком 0.31 мА). Вибір струму дозволяє динамічно підлаштовувати коефіцієнт передачі петлі при зміні частоти VCO.
   - **`[8] PD Polarity (1 біт):`** Полярність фазового детектора. `1` обирається для пасивного петльового фільтра (коли збільшення `V_tune` збільшує частоту VCO), `0` обирається при використанні інвертувального активного фільтра на операційному підсилювачі.

4. **Регістр R3 (Допоміжні функції та калібрування):**
   - **`[14:3] Clock Divider (12 біт):`** Внутрішній дільник тактової частоти для роботи часового автомата калібрування VCO.
   - **`[15] VCO Band Select (1 біт):`** Режим швидкого калібрування піддіапазону VCO.

5. **Регістр R4 (Вихідна потужність та управління RF-трактом):**
   - **`[4:3] Output Power (2 біти):`** Регулювання вихідної потужності каскаду: `00 = -4 дБм`, `01 = -1 дБм`, `10 = +2 дБм`, `11 = +5 дБм`.
   - **`[5] RF Enable (1 біт):`** Увімкнення/вимкнення вихідного радіочастотного підсилювача (`1 = On`, `0 = Off/Mute`).
   - **`[22:20] RF Divider (3 біти):`** Вихідний дільник частоти VCO (1, 2, 4, 8, 16, 32, 64), який дозволяє отримувати частоти від 35 МГц при мінімальній частоті VCO 2.2 ГГц.

6. **Регістр R5 (Режим індикації захоплення фази):**
   - **`[23:22] Lock Detect Pin Mode (2 біти):`** Конфігурація виводу `MUXOUT`. `01` налаштовує пін на цифровий вихід Lock Detect (`HIGH` — фаза захоплена), `02` — аналоговий Lock Detect, `00` — тристабільний стан (High Impedance).

### Алгоритм та формула обчислення коефіцієнтів

Для заданої бажаної частоти `f_rf`, опорної частоти `f_osc` та вихідного дільника `RF_DIV` (1, 2, 4, 8, 16, 32, 64):

1. Розраховується необхідна частота гетеродина VCO у межах його фізичного діапазону (наприклад, 2200...4400 МГц):
```
f_vco = f_rf · RF_DIV
```
де `RF_DIV` добирається почерговим подвоєнням (1, 2, 4, 8, 16, 32, 64), поки `f_vco` не потрапить у діапазон 2.2...4.4 ГГц.

2. Розраховується опорна частота на PFD:
```
f_pfd = f_osc / R_DIV
```

3. Обчислюється загальний коефіцієнт ділення:
```
N_total = f_vco / f_pfd
```

4. Ціла частина `INT` виділяється як округлення до меншого цілого:
```
INT = floor( N_total )
```

5. Дробова частина `FRAC` обчислюється для обраного знаменника `MOD` (наприклад, `MOD = 4000`):
```
FRAC = round( ( N_total - INT ) · MOD )
```
Якщо після округлення `FRAC == MOD`, значення `INT` збільшується на 1, а `FRAC` скидається в 0.

### Драйвер керування синтезатором (реалізація мовами C та C++)

Наведений нижче драйвер реалізує повний цикл обчислення 32-бітних слів регістрів R0...R5 для довільної частоти від 35 МГц до 4.4 ГГц та послідовний запис через SPI.

:::tabs
```c
#include <stdint.h>
#include <stdbool.h>
#include <math.h>

/* Макроси адрес регістрів */
#define PLL_REG0 0
#define PLL_REG1 1
#define PLL_REG2 2
#define PLL_REG3 3
#define PLL_REG4 4
#define PLL_REG5 5

/* Структура конфігурації синтезатора */
typedef struct {
    uint32_t regs[6];     /* Обраховані 32-бітні значення R0..R5 */
    double actual_freq_hz;/* Фактично сформована частота */
} pll_synth_driver_t;

/* Прототип зовнішньої функції запису SPI */
extern void spi_write_32bit(uint32_t data);

/* Функція розрахунку регістрів для заданої частоти */
bool pll_synth_tune(pll_synth_driver_t *drv, double target_freq_hz, double ref_osc_hz) {
    if (!drv || target_freq_hz < 35.0e6 || target_freq_hz > 4400.0e6 || ref_osc_hz <= 0.0) {
        return false;
    }

    /* 1. Визначення вихідного дільника RF_DIV (1, 2, 4, 8, 16, 32, 64) */
    uint32_t rf_div = 1;
    uint32_t rf_div_select = 0;
    double vco_freq = target_freq_hz;

    while (vco_freq < 2200.0e6 && rf_div_select < 6) {
        vco_freq *= 2.0;
        rf_div *= 2;
        rf_div_select++;
    }

    /* 2. Фіксований R-дільник = 1, MOD = 4000 (для кроку) */
    uint32_t r_div = 1;
    uint32_t mod = 4000;
    double f_pfd = ref_osc_hz / r_div;

    /* 3. Розрахунок INT та FRAC */
    double n_total = vco_freq / f_pfd;
    uint32_t integer_part = (uint32_t)floor(n_total);
    uint32_t frac_part = (uint32_t)round((n_total - (double)integer_part) * (double)mod);

    if (frac_part >= mod) {
        integer_part++;
        frac_part = 0;
    }

    /* Обчислення фактичної частоти */
    drv->actual_freq_hz = ((double)integer_part + ((double)frac_part / (double)mod)) * f_pfd / (double)rf_div;

    /* 4. Збирання регістрів R0..R5 */
    drv->regs[0] = (integer_part << 15) | (frac_part << 3) | PLL_REG0;
    drv->regs[1] = (1u << 27) | (mod << 3) | PLL_REG1;                  /* Prescaler 8/9 */
    drv->regs[2] = (7u << 9) | (r_div << 3) | (1u << 6) | PLL_REG2;     /* CP = 2.5mA, PD_pol = positive */
    drv->regs[3] = (1u << 15) | (100u << 3) | PLL_REG3;                 /* Clock div = 100 */
    drv->regs[4] = (rf_div_select << 20) | (1u << 5) | (3u << 3) | PLL_REG4; /* Output Power +5dBm, RF_EN */
    drv->regs[5] = (1u << 22) | (3u << 16) | PLL_REG5;                  /* Digital Lock Detect */

    return true;
}

/* Функція послідовного запису регістрів через SPI (від R5 до R0) */
void pll_synth_commit(const pll_synth_driver_t *drv) {
    if (!drv) return;
    for (int i = 5; i >= 0; i--) {
        spi_write_32bit(drv->regs[i]);
    }
}
```

```cpp
#include <cstdint>
#include <cmath>
#include <array>
#include <expected>
#include <numbers>

namespace rf {

enum class SynthError {
    InvalidFrequency,
    InvalidReference,
    SpiFailure
};

class IntegratedSynthesizer {
public:
    static constexpr double MIN_FREQ_HZ = 35.0e6;
    static constexpr double MAX_FREQ_HZ = 4400.0e6;

    struct RegisterMap {
        std::array<uint32_t, 6> raw_registers{};
        double calculated_freq_hz{0.0};
    };

    explicit IntegratedSynthesizer(double ref_osc_hz = 25.0e6) noexcept
        : ref_osc_hz_(ref_osc_hz) {}

    [[nodiscard]] std::expected<RegisterMap, SynthError> prepare_registers(double target_freq_hz) const noexcept {
        if (target_freq_hz < MIN_FREQ_HZ || target_freq_hz > MAX_FREQ_HZ) {
            return std::unexpected(SynthError::InvalidFrequency);
        }
        if (ref_osc_hz_ <= 0.0) {
            return std::unexpected(SynthError::InvalidReference);
        }

        RegisterMap map{};
        uint32_t rf_div = 1;
        uint32_t rf_div_select = 0;
        double vco_freq = target_freq_hz;

        while (vco_freq < 2200.0e6 && rf_div_select < 6) {
            vco_freq *= 2.0;
            rf_div *= 2;
            rf_div_select++;
        }

        constexpr uint32_t r_div = 1;
        constexpr uint32_t mod = 4000;
        const double f_pfd = ref_osc_hz_ / r_div;

        const double n_total = vco_freq / f_pfd;
        auto integer_part = static_cast<uint32_t>(std::floor(n_total));
        auto frac_part = static_cast<uint32_t>(std::round((n_total - integer_part) * mod));

        if (frac_part >= mod) {
            integer_part++;
            frac_part = 0;
        }

        map.calculated_freq_hz = (static_cast<double>(integer_part) +
                                 (static_cast<double>(frac_part) / mod)) * f_pfd / rf_div;

        map.raw_registers[0] = (integer_part << 15) | (frac_part << 3) | 0u;
        map.raw_registers[1] = (1u << 27) | (mod << 3) | 1u;
        map.raw_registers[2] = (7u << 9) | (r_div << 3) | (1u << 6) | 2u;
        map.raw_registers[3] = (1u << 15) | (100u << 3) | 3u;
        map.raw_registers[4] = (rf_div_select << 20) | (1u << 5) | (3u << 3) | 4u;
        map.raw_registers[5] = (1u << 22) | (3u << 16) | 5u;

        return map;
    }

private:
    double ref_osc_hz_;
};

} // namespace rf
```

### Критична послідовність програмування (Programming Sequence)

Для правильного старту синтезатора та виходу його внутрішніх автоматів калібрування у робочий режим необхідно дотримуватися суворого порядку дій:

1. **Подача живлення та стабілізація LDO:** Подати напругу VCC (3.3 В). Зачекати не менше 10 мс для завершення внутрішнього скидання Power-On Reset (POR) та стабілізації виходів опорного кварцю TCXO.
2. **Ініціалізувальний запис у зворотному порядку (R5 → R1):** Спочатку програмуються регістри статичної конфігурації:
   - Записати R5 (конфігурація індикатора захоплення фази LD).
   - Записати R4 (вихідна потужність, увімкнення RF-тракту, вихідний дільник).
   - Записати R3 (тактові дільники автоматики).
   - Записати R2 (R-дільник, струм помпи заряду, полярність PFD).
   - Записати R1 (знаменник `MOD`, прескалер).
3. **Активація калібрування через R0:** Запис у регістр R0 виконується **останнім**. Запис R0 запускає цифровий автомат вибору піддіапазону VCO (VCO Band Select) та скидає лічильники фазового детектора.
4. **Контроль захоплення фази (Lock Detect Verification):** Після запису R0 програма повертає керування та чекає на розрахований час встановлення `t_lock` (типово 20...50 мкс). Після цього опитується стан піна `LD`:
   - Якщо `LD == HIGH (1)` — синтезатор успішно закольцував петлю, напруга `V_tune` перебуває у робочому діапазоні (0.5...4.5 В), вихідна частота точна.
   - Якщо `LD == LOW (0)` — фаза не захоплена. Можливі причини: відсутність опорного сигналу TCXO, некоректні розрахунки `INT`/`FRAC` за межами VCO, або обрив у ланцюзі петльового фільтра.
