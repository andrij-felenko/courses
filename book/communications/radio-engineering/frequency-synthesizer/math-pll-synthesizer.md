# 🧮 Математична динаміка ФАПЧ-синтезатора та розрахунок фазового шуму

Математичний аналіз синтезатора частот на основі фазової автопідстройки частоти (ФАПЧ) базується на теорії автоматичного керування зі зворотним зв'язком. Складна нелінійна система радіочастотного генератора та фазового детектора в режимі утримання (захоплення) фази описується лінійними диференціальними рівняннями в операторній формі (перетворення Лапласа).

---

### 1. Передавальна функція замкненої петлі ФАПЧ

У режимі захоплення фази фазово-частотний детектор (PFD) разом із помпою заряду (CP) генерують струм, пропорційний різниці фаз між опорним сигналом `θ_ref(s)` та поділеним вихідним сигналом `θ_fb(s)`.

Оцінимо коефіцієнт передачі фазового детектора з помпою заряду:

```
K_p = I_cp / (2π)    [А/рад]                                            [коефіцієнт передачі PFD]
```

де `I_cp` — вихідний струм помпи заряду в амперах (типово 1...5 мА).

Генератор керований напругою (VCO) змінює вихідну частоту пропорційно напрузі керування `V_tune`: `Δω_out = K_vco · V_tune`. Оскільки фаза є інтегралом від частоти (`θ(t) = ∫ ω(t) dt`), у комплексному просторі Лапласа передавальна функція VCO має вигляд:

```
K_vco(s) = K_vco / s    [(рад/с) / В]                                   [інтегрувальна характеристика VCO]
```

де `K_vco` — крутизна характеристики VCO у рад/(с·В) (або `2π · K_vco_Hz`, де `K_vco_Hz` у Гц/В).

Дільник у зворотному зв'язку зменшує амплітуду фазового зсуву в `N` разів:

```
H_fb(s) = 1 / N                                                          [коефіцієнт ділення]
```

Петльовий фільтр другої ланки складається з послідовного резистора `R1` та конденсатора `C1`, паралельно до яких підключено згладжувальний конденсатор `C2` (для придушення пульсацій опорної частоти). Його імпеданс `Z(s)` становить:

```
Z(s) = (1 + s · R1 · C1) / [ s · (C1 + C2) · (1 + s · R1 · C_eq) ]       [імпеданс 2-ї ланки LF]
```

де `C_eq = (C1 · C2) / (C1 + C2)`.

Коли `C2 << C1` (що зазвичай виконується для збереження запасу стійкості), імпедансом `C2` на низьких частотах можна знехтувати, спрощуючи `Z(s) ≈ R1 + 1 / (s · C1)`.

Тоді передавальна функція розімкненої петлі `G(s)` набуває вигляду:

```
G(s) = [ K_p · Z(s) · K_vco ] / (s · N)                                 [розімкнена передавальна функція]
     = [ (I_cp · K_vco) / (2π · N) ] · [ (1 + s · R1 · C1) / (s² · C1) ] [розкриття складових]
```

Передавальна функція замкненої петлі по фазі `H(s) = θ_out(s) / θ_ref(s)` визначається стандартним співвідношенням теорії авторегулювання:

```
H(s) = [ N · G(s) ] / [ 1 + G(s) / N ]                                   [замкнена функція за фазою]
     = [ 2·ζ·ω_n · s + ω_n² ] / [ s² + 2·ζ·ω_n · s + ω_n² ]              [канонічний вигляд 2-го порядку]
```

де `ω_n` — власна (резонансна) частота петлі, а `ζ` (дзета) — коефіцієнт демпфування. Вони виражаються через фізичні параметри елементів:

```
ω_n = √[ (I_cp · K_vco) / (2π · N · C1) ]        [рад/с]                [резонансна частота петлі]

ζ = (R1 · C1 / 2) · ω_n = (R1 / 2) · √[ (I_cp · C1 · K_vco) / (2π · N) ] [коефіцієнт демпфування]
```

### 2. Запас стійкості (Phase Margin) та аналіз нулів/полюсів

Для стабільної роботи петлі без автоколивань необхідно забезпечити достатній запас стійкості по фазі `PM` (англ. *Phase Margin*) на частоті зрізу `ω_c`, де модуль розімкненої передавальної функції дорівнює одиниці (`|G(jω_c)| = 1`).

Передавальна функція розімкненої петлі `G(s)` має два полюси в нулі (`s²` у знаменнику, що створює фазовий зсув −180°), один лінійний нуль `ω_z = 1 / (R1 · C1)` (який додає фазу `+arctg(ω/ω_z)`) та один високочастотний полюс `ω_p = 1 / (R1 · C_eq)` (який віднімає фазу `-arctg(ω/ω_p)`).

Запас по фазі обчислюється як різниця фазового зсуву розімкненого тракту та критичної межі −180°:

```
PM = 180° + arctg(ω_c · R1 · C1) - arctg(ω_c · R1 · C_eq) - 180°          [запас стійкості по фазі]
   = arctg(ω_c · R1 · C1) - arctg(ω_c · R1 · C_eq)                       [спрощений вираз для PM]
```

Максимум запасу по фазі досягається строго посередині між нулем та високим полюсом у логарифмічному масштабі частот:

```
ω_c = √[ ω_z · ω_p ] = 1 / [ R1 · √(C1 · C_eq) ]                         [частота максимуму PM]
```

При збігу частоти зрізу з цим максимумом співвідношення ємностей `γ = C1 / C2` прямо пов'язане з масимальним запасом по фазі:

```
sin(PM) = (γ - 1) / (γ + 1)   ⇒   γ = (1 + sin(PM)) / (1 - sin(PM))      [зв'язок ємностей та PM]
```

Для цільового запасу по фазі `PM = 45°` співвідношення ємностей становить `γ = (1 + 0.707) / (1 - 0.707) ≈ 5.8`. Для `PM = 50°` маємо `γ ≈ 7.5`, а для `PM = 60°` отримуємо `γ = 14`. Значення `PM < 30°` призводить до високих перерегулювань та тривалого «дзвінкого» перехідного процесу.

### 3. Функція помилки та час захоплення (Lock Time)

Передавальна функція похибки `E(s) = θ_err(s) / θ_ref(s)` визначає, як система реагує на фазові збурення:

```
E(s) = 1 / [ 1 + G(s) / N ] = s² / [ s² + 2·ζ·ω_n · s + ω_n² ]           [передавальна функція похибки]
```

При стрибку частоти на `Δf_step` (що відповідає стрибку фазової швидкості `Δω_step / s²` в операторній формі) реакція напруги у часовій області `v_tune(t)` описується згасаючим синусоїдальним коливанням:

```
Δf(t) = Δf_step · [ 1 - (1 / √(1 - ζ²)) · e^(-ζ·ω_n·t) · sin( ω_n·√(1 - ζ²)·t + arccos(ζ) ) ]
```

Час встановлення частоти `t_lock` (час, за який вихідна частота входить у задану смугу допуску `Δf_tol` після перемикання каналу) розраховується за наближеною формулою для системи 2-го порядку при `ζ < 1`:

```
t_lock ≈ [ -ln( (Δf_tol / Δf_step) · √(1 - ζ²) ) ] / ( ζ · ω_n )          [формула часу захоплення]
```

Збільшення смуги петлі `ω_n` прискорює встановлення частоти, але пропускає більше шуму фазового детектора та зменшує придушення опорних завад (spurs).

### 4. Суперпозиція джерел фазового шуму та інтегральний джитер

Вихідний спектральний шум ФАПЧ-синтезатора є сумою трьох незалежних джерел:
1. Опорного кварцового генератора та фазового детектора `L_inband(Δf)`.
2. Шуму резисторів петльового фільтра `L_LF(Δf)`.
3. Власного шуму генератора VCO `L_VCO(Δf)`.

Завдяки властивостям замкненої петлі, внутрішньосмугові шуми пропускаються на вихід як фільтр низьких частот `H(s)`, а власний шум VCO придушується усередині смуги як фільтр високих частот `E(s) = [1 - H(s)]`:

```
L_total(Δf) = [ L_ref(Δf) + L_PFD + 20·log₁₀(N) ] · |H(j 2π Δf)|²
             + L_VCO(Δf) · |1 - H(j 2π Δf)|²                            [суперпозиція джерел шуму]
```

де `L_PFD` — власний шумовий поріг фазового детектора (англ. *Figure of Merit*, FOM), нормований на 1 Гц:

```
L_inband_floor = FOM + 10·log₁₀(f_PFD) + 20·log₁₀(N)    [дБн/Гц]        [внутрішньосмуговий шум]
```

Сучасні фазові детектори мають `FOM ≈ -230...-235 дБн/Гц`. Кожне подвоєння коефіцієнта ділення `N` додає 6 дБ до внутрішньосмугового шуму!

#### Інтегрувальний фазовий джитер (RMS Phase Jitter)

Для оцінки деградації цифрових модуляцій обчислюють середньоквадратичний часовий джитер `σ_t` (в пікосекундах чи фемтосекундах) шляхом інтегрування спектральної щільності фазового шуму `L(f)` від нижньої межі `f1` (наприклад, 12 кГц) до верхньої межі `f2` (наприклад, 20 МГц):

```
σ_rad² = 2 · ∫[f1..f2] 10^(L(f)/10) df                                  [дисперсія фази в радіанах]

σ_t = σ_rad / ( 2π · f_out )                                             [RMS джитер у секундах]
```

### 5. Практичний числовий розрахунок синтезатора 2.4 ГГц

Проведемо повний розрахунок петльового фільтра та динаміки синтезатора для бездротового трансивера діапазону 2.4 ГГц.

**Вхідні параметри:**
- Вихідна частота: `f_out = 2400 МГц`
- Частота опорного кварцу: `f_osc = 25 МГц`
- Коефіцієнт ділення опори: `R = 1` (`f_ref = f_PFD = 25 МГц`)
- Струм помпи заряду: `I_cp = 2.5 мА = 0.0025 А`
- Крутизна VCO: `K_vco_Hz = 30 МГц/В` (`K_vco = 2π · 30·10⁶ = 1.885·10⁸ рад/(с·В)`)
- Бажана смуга петлі: `f_c = 100 кГц` (`ω_c = 2π · 100 000 ≈ 628 318 рад/с`)
- Цільовий запас по фазі: `PM = 50°`

**Покроковий розрахунок:**

1. **Розрахунок коефіцієнта ділення N:**
```
N = f_out / f_PFD                 [формула коефіцієнта ділення]
  = 2400 / 25                     [підстановка: f_out = 2400 МГц, f_PFD = 25 МГц]
  = 96                            [цілочисельний коефіцієнт]
```

2. **Розрахунок ємності C1:**
```
C1 = [ I_cp · K_vco ] / [ 2π · N · ω_c² ] · [ cos(PM) ]                  [формула ємності C1]
   = [ 0.0025 · 1.885·10⁸ ] / [ 2π · 96 · (628 318)² ] · cos(50°)         [підстановка числових значень]
   = [ 471 250 ] / [ 603.18 · 3.9478·10¹¹ ] · 0.6428                        [проміжні обчислення чисельника й знаменника]
   = 1.274 · 10⁻⁹ Ф                                                     [підсумковий розрахунок в фарадах]
   ≈ 1.27 нФ                                                            [переведення в нанофаради]
```
Обираємо стандартне значення із ряду E24: `C1 = 1.2 нФ`.

3. **Розрахунок опору R1:**
```
R1 = [ 2 · ζ ] / [ ω_c · C1 ]                                            [формула опору R1]
```
Для `PM = 50°` коефіцієнт демпфування `ζ ≈ 0.65`:
```
R1 = [ 2 · 0.65 ] / [ 628 318 · 1.2·10⁻⁹ ]                               [підстановка значення C1 = 1.2 нФ]
   = 1.30 / 0.000754                                                    [розрахунок добутку]
   = 1724 Ом                                                            [підсумковий опір в омах]
```
Обираємо стандартне значення: `R1 = 1.6 кОм`.

4. **Розрахунок паразитного конденсатора C2:**
Для забезпечення `PM = 50°` співвідношення ємностей `γ = C1 / C2 ≈ 10`:
```
C2 = C1 / 10                                                            [співвідношення для PM = 50°]
   = 1.2 нФ / 10                                                        [підстановка C1]
   = 120 пФ                                                             [ємність C2 в пікофарадах]
```

5. **Оцінка внутрішньосмугового шуму ФАПЧ при FOM = -230 дБн/Гц:**
```
L_inband = FOM + 10·log₁₀(f_PFD) + 20·log₁₀(N)                           [формула внутрішньосмугового шуму]
         = -230 + 10·log₁₀(25·10⁶) + 20·log₁₀(96)                         [підстановка: FOM = -230, f_PFD = 25 МГц, N = 96]
         = -230 + 73.98 + 39.64                                          [обчислення логарифмів]
         = -116.38 дБн/Гц                                                [підсумовування]
```

6. **Розрахунок часу захоплення при стрибку на 80 МГц до точності 1 кГц:**
```
ω_n = √[ (I_cp · K_vco) / (2π · N · C1) ]                               [формула власної частоти]
    = √[ 471 250 / (2π · 96 · 1.2·10⁻³) ]                                [підстановка числових параметрів]
    = √[ 471 250 / 7.238·10⁻⁷ ]                                         [ділення під коренем]
    = √[ 6.51·10¹¹ ]                                                    [підкореневий вираз]
    ≈ 806 870 рад/с                                                     [значення в рад/с]

t_lock ≈ [ -ln(1 000 / 80 000 000) ] / (0.65 · 806 870)                  [підстановка в формулу t_lock]
       = [ -ln(1.25·10⁻⁵) ] / (524 465)                                  [ділення в аргументі логарифма]
       = 11.29 / 524 465                                                [значення натурального логарифма]
       ≈ 21.5 мікросекунди                                              [підсумковий час захоплення]
```

Таким чином, розрахований петльовий фільтр забезпечує вихід на частоту за 21.5 мікросекунди при внутрішньосмуговому фазовому шумі −116.4 дБн/Гц.
