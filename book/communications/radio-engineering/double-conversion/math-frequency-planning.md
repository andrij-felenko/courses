# 🧮 Математика частотного планування та дзеркальних каналів

Ця вставка містить повний алгебраїчний розрахунок частотного плану подвійного перетворення, систему формул для визначення дзеркальних частот першого й другого ступенів, розрахунок загасання завад у фільтрах преселектора та руфінгу, математичне доведення ефекту подвійної інверсії спектра, а також аналіз інтермодуляційних продуктів вищих порядків (IMD3/IIP3) та побічних каналів прийому (Spurs).

### 1. Системи рівнянь першого та другого перетворення

Приймач із подвійним перетворенням здійснює два послідовних нелінійних множення сигналу на коливання двох незалежних гетеродинів. 

Нехай вхідний радіочастотний сигнал описується гармонічною функцією:

```
s_RF(t) = A_RF · cos(2·π·f_RF·t + φ_RF(t))
```

#### Перше перетворення:
Гетеродинний сигнал першого гетеродина має вигляд:

```
s_LO1(t) = A_LO1 · cos(2·π·f_LO1·t)
```

Результат множення у першому змішувачі розкладається за тригонометричною тотожністю:

```
s_mix1(t) = s_RF(t) · s_LO1(t)
= ½ · A_RF · A_LO1 · [ cos(2·π·(f_LO1 − f_RF)·t − φ_RF(t)) + cos(2·π·(f_LO1 + f_RF)·t + φ_RF(t)) ]  [тотожність добутку косинусів]
```

Смуговий фільтр першої проміжної частоти (руфінг-фільтр) відсікає сумарну частоту `f_LO1 + f_RF` і виділяє різницеву складову `f_IF1`:

```
f_IF1 = |f_RF − f_LO1|
```

Залежно від вибору знаку маємо два варіанти інжективання гетеродина:
- **Верхня настройка (High-Side Injection):** `f_LO1 > f_RF` ⇒ `f_IF1 = f_LO1 − f_RF`.
- **Нижня настройка (Low-Side Injection):** `f_LO1 < f_RF` ⇒ `f_IF1 = f_RF − f_LO1`.

#### Дзеркальний канал першого перетворення (f_img1):
Дзеркальною є така частота `f_img1 ≠ f_RF`, яка при змішуванні з тим самим `f_LO1` дає точно таку ж проміжну частоту `f_IF1`.

Для верхньої настройки гетеродина (`f_LO1 = f_RF + f_IF1`):

```
|f_img1 − f_LO1| = f_IF1                                             [умова однакової ПЧ]
⇒ f_img1 = f_LO1 + f_IF1 = (f_RF + f_IF1) + f_IF1                  [підстановка f_LO1 = f_RF + f_IF1]
⇒ f_img1 = f_RF + 2·f_IF1                                          [зведення подібних доданків]
```

```
f_img1 = f_RF + 2·f_IF1      [при f_LO1 > f_RF]
f_img1 = f_RF − 2·f_IF1      [при f_LO1 < f_RF]
```

#### Друге перетворення:
Сигнал першої ПЧ знову перемножується з другим гетеродином `f_LO2`:

```
f_IF2 = |f_IF1 − f_LO2|
```

Для другого змішувача дзеркальна частота першої ПЧ дорівнює:

```
f_img2 = f_IF1 ± 2·f_IF2
```

### 2. Розрахунок загасання дзеркального каналу у вхідному преселекторі

Оцінімо придушення дзеркального каналу одиночним резонаторним контуром із еквівалентною добротністю `Q` та резонансною частотою `f_RF`.

Коефіцієнт передачі одиночного контуру на частоті `f` задається формулою:

```
H(f) = 1 / √( 1 + Q² · (f / f_RF − f_RF / f)² )
```

Послаблення сигналу дзеркального каналу `f_img` у децибелах становить:

```
A_img_dB = 10 · log10( 1 + Q² · (f_img / f_RF − f_RF / f_img)² )
```

#### Розрахунковий приклад: порівняння Однократного та Подвійного перетворення

Розглянемо вхідний сигнал `f_RF = 14.0` МГц та вхідний контур із добротністю `Q = 25`.

**Варіант А: Однократний супергетеродин із низькою ПЧ (f_IF = 455 кГц)**
```
f_img = 14.0 − 2·0.455 = 13.09 МГц                         [дзеркальна частота: f_RF - 2·f_IF]
f_img / f_RF = 13.09 / 14.0 = 0.935                        [відношення дзеркальної до вхідної]
f_RF / f_img = 14.0 / 13.09 = 1.0695                       [обернене відношення]
Δ = 0.935 − 1.0695 = −0.1345                               [розбудова контуру: f_img/f_RF - f_RF/f_img]
A_img_dB = 10 · log10( 1 + 25² · (−0.1345)² )              [підстановка у формулу загасання]
         = 10 · log10( 1 + 625 · 0.0181 )                  [піднесення до квадрата: (-0.1345)²]
         = 10 · log10( 1 + 11.31 )                         [множення: 625 · 0.0181]
         = 10 · log10(12.31) ≈ 10.9 дБ                      [обчислення логарифма]
```
*Висновок:* Придушення всього 10.9 дБ! Сильний дзеркальний сигнал пройде крізь преселектор майже без перешкод.

**Варіант Б: Перше перетворення у подвійній схемі (f_IF1 = 45.0 МГц)**
```
f_img1 = 14.0 + 2·45.0 = 104.0 МГц                         [дзеркальна частота при верхній настройці]
f_img1 / f_RF = 104.0 / 14.0 = 7.4285                      [відношення дзеркальної частоти до вхідної]
f_RF / f_img1 = 14.0 / 104.0 = 0.1346                      [обернене відношення]
Δ = 7.4285 − 0.1346 = 7.2939                               [розбудова контуру]
A_img1_dB = 10 · log10( 1 + 25² · (7.2939)² )              [підстановка у формулу]
          = 10 · log10( 1 + 625 · 53.20 )                  [квадрат розбудови: (7.2939)²]
          = 10 · log10( 1 + 33250 )                         [множення на Q² = 625]
          = 10 · log10(33251) ≈ 45.2 дБ                      [обчислення підсумкового загасання]
```
Для 2-контурного преселектора загасання подвоюється і досягає **90.4 дБ**, що повністю вирішує проблему.

### 3. Загасання другого дзеркального каналу у руфінг-фільтрі

Друга дзеркальна частота `f_img2` віддалена від `f_IF1` на `2·f_IF2`. Для `f_IF2 = 455` кГц це відхилення становить `Δf = 910` кГц.

Послаблення N-полюсного руфінг-фільтра Баттерворта зі смугою пропускання `B_roofing` задається виразом:

```
A_roof_dB = 10 · log10( 1 + ( 2·|f_img2 − f_IF1| / B_roofing )^(2N) )
```

Для 4-кристального руфінг-фільтра (`N = 4`) на 45 МГц із смугою `B_roofing = 15` кГц:

```
відношення розбудови = 2 · 910 кГц / 15 кГц = 121.33       [відносна смуга розбудови]
степеневий фактор = (121.33)^(2·4) = (121.33)^8 ≈ 4.68·10^16 [піднесення до 2N=8 степеня]
A_roof_dB = 10 · log10( 4.68 · 10^16 ) ≈ 166.7 дБ          [десятичний логарифм загасання]
```
*Висновок:* Другий дзеркальний канал пригнічується руфінг-фільтром до рівня шуму ефіру.

### 4. Ефект подвійної інверсії спектра (Double Spectrum Inversion)

Коли гетеродин настроєний вище за вхідний сигнал (`f_LO > f_RF`), відбувається **інверсія спектра** (верхня бічна смуга USB перетворюється на нижню LSB).

Доведемо це алгебраїчно. Нехай вхідний асиметричний сигнал має фазову модуляцію `φ_RF(t)`:

```
s_RF(t) = cos(2·π·f_RF·t + φ_RF(t))
```

При множенні на `cos(2·π·f_LO1·t)` та верхній настройці (`f_LO1 > f_RF`), різницевий аргумент косинуса дорівнює:

```
θ_IF1(t) = 2·π·f_LO1·t − (2·π·f_RF·t + φ_RF(t))             [різниця фаз LO1 та RF]
         = 2·π·(f_LO1 − f_RF)·t − φ_RF(t)                  [розгрупування доданків із t та φ]
         = 2·π·f_IF1·t − φ_RF(t)                            [підстановка f_IF1 = f_LO1 - f_RF]
```

Знак перед фазовою функцією `φ_RF(t)` змінився з `+` на `−` — спектральні компоненти дзеркально перевернулися відносно несучої!

Якщо у другому перетворенні другий гетеродин **також** настроєно вище за першу ПЧ (`f_LO2 > f_IF1`), виникає повторна інверсія:

```
θ_IF2(t) = 2·π·f_LO2·t − (2·π·f_IF1·t − φ_RF(t))             [різниця фаз LO2 та IF1]
         = 2·π·(f_LO2 − f_IF1)·t + φ_RF(t)                  [розкриття дужок: -(-φ_RF) = +φ_RF]
         = 2·π·f_IF2·t + φ_RF(t)                            [підстановка f_IF2 = f_LO2 - f_IF1]
```

Знак при фазі знову став позитивним (`+`)! 

> 💡 **Правило двох інверсій:** Два гетеродини з верхньою інжекцією (`f_LO1 > f_RF` та `f_LO2 > f_IF1`) скасовують інверсію один одного, повертаючи початкову орієнтацію спектра (USB залишається USB). Якщо ж один гетеродин працює зверху, а данный знизу — спектр на виході виявиться інвертованим, і його треба враховувати при демодуляції.

### 5. Матриця комбінаційних завад (Spur Order Equation) та Half-IF канал

Комбінаційні завади виникають при збігу гармонік вхідного сигналу та гетеродинів. Загальне рівняння побічних продуктів для двох змішувачів має вигляд:

```
m · f_RF ± n · f_LO1 = f_IF1       [для 1-го змішувача]
p · f_IF1 ± q · f_LO2 = f_IF2       [для 2-го змішувача]
```

де `m, n, p, q` — цілі числа (`0, 1, 2, 3...`).

Порядок комбінаційної завади `K` визначається як сума абсолютних значень коефіцієнтів:

```
K_1 = |m| + |n|
K_2 = |p| + |q|
```

Чим нижчий порядок `K`, тим більша амплітуда завади. Комбінації з `K ≤ 3` є найнебезпечнішими й вимагають вилучення з частотного плану.

#### Завада на пів-ПЧ (Half-IF Response)
Окремим підступним випадком є завада другого порядку `K = 2 + 2 = 4` на пів-ПЧ. Вона виникає, коли сигнал `f_half` розташований рівно посередині між `f_RF` та `f_LO1`:

```
f_half = f_RF + ½ · f_IF1                                  [частота пів-ПЧ завади]
2 · f_half − 2 · f_LO1 = 2·(f_RF + ½·f_IF1) − 2·(f_RF + f_IF1) [підстановка частоти гетеродина]
                      = 2·f_RF + f_IF1 − 2·f_RF − 2·f_IF1   [розкриття дужок]
                      = −f_IF1                              [результат потрапляє точно в 1-шу ПЧ!]
```

Оскільки 2-га гармоніка сигналу `2·f_half` змішується з 2-ю гармонікою гетеродина `2·f_LO1`, продуктом є точно `f_IF1`. Придушення завади на пів-ПЧ вимагає високого значення `IIP2` першого змішувача.

### 6. Розрахунок динамічного діапазону за інтермодуляцією (SFDR / IIP3)

Динамічний діапазон, вільний від побічних продуктів (SFDR — *Spurious-Free Dynamic Range*), обчислюється на основі точки перетину інтермодуляції 3-го порядку `IIP3` та рівня шуму приймача `P_noise`:

```
P_noise = −174 + 10·log10(B) + NF                          [формула теплового шуму в дБм]
```

де `B` — смуга другого канального фільтра (Гц), `NF` — коефіцієнт шуму приймача (дБ).

Формула SFDR приймача:

```
SFDR = ⅔ · ( IIP3 − P_noise )                              [формула SFDR за IIP3]
```

Для приймача з `IIP3 = +20` дБм, `NF = 10` дБ та `B = 2400` Гц:

```
P_noise = −174 + 10·log10(2400) + 10                      [підстановка параметрів шуму]
        = −174 + 33.8 + 10 = −130.2 дБм                   [обчислення підсумкового рівня шуму]
SFDR = ⅔ · ( +20 − (−130.2) )                              [підстановка в формулу SFDR]
     = ⅔ · ( 150.2 ) ≈ 100.1 дБ                           [обчислення підсумкового SFDR]
```

Це означає, що прийомно-підсилювальний тракт подвійного перетворення здатен одночасно приймати слабкий сигнал −130 дБм при наявності двох потужних завад по −30 дБм без появи хибних фантомних сигналів.
