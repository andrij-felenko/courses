# 🧮 Розрахунок каскадного коефіцієнта шуму та чутливості радіомодуля

Шумові характеристики приймального тракту радіомодуля визначають його межеву чутливість — найслабший рівень радіосигналу на вхідному роз'ємі антени, який приймач здатний достовірно демодулювати й перетворити у цифровий потік байтів без перевищення допустимого рівня помилок. Кожен фізичний елемент високочастотного тракту (вхідний смуговий фільтр, малошумний підсилювач LNA, перемикач T/R Switch, змішувач частот та АЦП трансивера) вносить власні теплові та дробові шуми, погіршуючи вихідне співвідношення сигнал/шум (SNR).

Для обчислення сумарного впливу послідовних каскадів використовується формула Фріїса для каскадного коефіцієнта шуму. Вона показує фундаментальний фізичний закон: підсилення перших каскадів приймального тракту "пригнічує" власні шуми всіх наступних елементів схеми. Саме тому характеристики першого підсилювача та втрати в елементах до нього є визначальними для всієї системи.

### Визначення коефіцієнта шуму та фактора шуму

Фактор шуму (Noise Factor, Фактор `F`) визначається як відношення співвідношення сигнал/шум на вході каскаду до співвідношення сигнал/шум на його виході:

```
F = (SNR_in) / (SNR_out)    [фактор шуму у разах]
```

Оскільки фактор шуму `F` завжди більший за одиницю (будь-який реальний підсилювач додає власні шуми), його зручніше виражати в логарифмічних одиницях — децибелах. Логарифмічна величина називається коефіцієнтом шуму (Noise Figure, Коефіцієнт `NF`):

```
NF = 10 · log10(F)          [коефіцієнт шуму у децибелах]
F  = 10^(NF / 10)           [зворотне перетворення у рази]
```

Якщо елемент є пасивним (наприклад, атенюатор, балун або смуговий фільтр із втратами `IL` дБ), його коефіцієнт шуму `NF` точно дорівнює внесеним втратам `IL` у децибелах, а лінійний коефіцієнт підсилення за потужністю `G` є меншим за одиницю:

```
NF_filter = IL             [втрати у дБ]
G_filter  = 10^(-IL / 10)  [коефіцієнт підсилення у разах, G < 1]
```

### Формула Фріїса для каскаду з N елементів

Для послідовного ланцюжка з кількох радіочастотних каскадів підсумковий фактор шуму всієї системи `F_sys` розраховується за формулою Фріїса:

```
F_sys = F_1 + (F_2 - 1) / G_1 + (F_3 - 1) / (G_1 · G_2) + (F_4 - 1) / (G_1 · G_2 · G_3)
```

де:
- `F_1, F_2, F_3` — лінійні фактори шуму першого, другого та третього каскадів у разах;
- `G_1, G_2, G_3` — лінійні коефіцієнти підсилення за потужністю відповідних каскадів у разах.

З аналізу формули видно два критичних висновки:
1. Власні шуми першого каскаду `F_1` входять у сумарний шум системи повністю, без жодного послаблення.
2. Власні шуми другого каскаду `(F_2 - 1)` діляться на підсилення першого каскаду `G_1`. Якщо перший каскад має високе підсилення (`G_1 >> 1`), то внесок другого та наступних каскадів у загальний шум стає мізерно малим.

Після обчислення підсумкового фактора шуму `F_sys` загальний коефіцієнт шуму радіомодуля у децибелах отримується зворотним логарифмуванням:

```
NF_sys = 10 · log10(F_sys)
```

### Виведення порогу шуму та чутливості приймача

Фізичним порогом чутливості будь-якого радіоприймача є спектральна щільність теплового шуму (Джонсонівський шум) у повністю узгодженому 50-омному резисторі при абсолютній температурі `T_0 = 290 K` (близько +17 °C).

Потужність теплового шуму у смузі 1 Гц обчислюється як:

```
P_thermal = k · T_0 · 1 Гц
= 1.380649 · 10^-23 · 290  [підстановка сталої Больцмана k та T0 = 290 K]
= 4.004 · 10^-21 Вт/Гц     [обчислення спектральної щільності шуму]
```

Переводячи цю потужність у децибели відносно одного мілівата (дБм), отримуємо фундаментальну константу радіотехніки:

```
P_dBm/Гц = 10 · log10(P_thermal · 1000) = -174.0 dBm/Гц
```

Для приймального тракту зі смугою пропускання `B` (в герцах) та коефіцієнтом шуму системи `NF_sys` (у децибелах) загальна потужність шумового порогу `P_noise` становить:

```
P_noise [dBm] = -174.0 + 10 · log10(B) + NF_sys
```

Гранична чутливість приймача `S` (мінімально необхідний рівень сигналу на вхідному роз'ємі антени) визначається додаванням необхідного мінімального співвідношення сигнал/шум модуляції `SNR_min`:

```
S [dBm] = P_noise + SNR_min = -174.0 + 10 · log10(B) + NF_sys + SNR_min
```

### Покроковий практичний розрахунок тракту радіомодуля

Розглянемо реальний приклад розрахунку приймального тракту радіомодуля діапазону 868 МГц, який містить вхідний фільтр, малошумний підсилювач LNA та інтегральний трансивер RFIC.

**Параметри каскадів:**
1. **Каскад 1 (Вхідний смуговий фільтр BPF + T/R Switch)**: внесені втрати `IL = 1.5 дБ`. Підсилення `Gain_1 = -1.5 дБ`, коефіцієнт шуму `NF_1 = 1.5 дБ`.
2. **Каскад 2 (Малошумний підсилювач LNA)**: коефіцієнт підсилення `Gain_2 = 16.0 дБ`, коефіцієнт шуму `NF_2 = 1.8 дБ`.
3. **Каскад 3 (Вхідний змішувач та АЦП трансивера RFIC)**: коефіцієнт шуму `NF_3 = 10.0 дБ`.

**Крок 1. Переведення параметрів із децибелів у лінійні рази:**

```
F_1 = 10^(1.5 / 10)  = 1.413  [фактор шуму фільтра]
G_1 = 10^(-1.5 / 10) = 0.708  [коефіцієнт підсилення фільтра, G < 1]

F_2 = 10^(1.8 / 10)  = 1.514  [фактор шуму LNA]
G_2 = 10^(16.0 / 10) = 39.811 [коефіцієнт підсилення LNA]

F_3 = 10^(10.0 / 10) = 10.000 [фактор шуму трансивера]
```

**Крок 2. Обчислення сумарного фактора шуму `F_sys` за формулою Фріїса:**

```
F_sys = F_1 + (F_2 - 1) / G_1 + (F_3 - 1) / (G_1 · G_2)
= 1.413 + (1.514 - 1) / 0.708 + (10.0 - 1) / (0.708 · 39.811) [підстановка лінійних факторів]
= 1.413 + 0.514 / 0.708 + 9.000 / 28.186                     [обчислення чисельників і знаменників]
= 1.413 + 0.726 + 0.319                                      [ділення факторів шуму каскадів]
= 2.458                                                      [сумування фактора F_sys]
```

**Крок 3. Переведення сумарного фактора `F_sys` у коефіцієнт шуму `NF_sys`:**

```
NF_sys = 10 · log10(F_sys)
= 10 · log10(2.458)  [підстановка F_sys = 2.458]
= 3.91 дБ            [коефіцієнт шуму системи]
```

**Аналіз результату каскадування:**
Мікросхема трансивера без зовнішнього підсилювача мала дуже високий власний коефіцієнт шуму `NF_3 = 10.0 дБ`. Проте додавання малошумного підсилювача LNA з підсиленням 16.0 дБ дозволило знизити загальний коефіцієнт шуму всієї системи до `3.91 дБ`.

Водночас зауваж: втрати 1.5 дБ у фільтрі *перед* LNA додалися до шумового фактора майже 1:1 (`F_1 = 1.413`), оскільки послабили сигнал ще до підсилення. Це демонструє головне правило ВЧ-схемотехніки: **всі втрати у компонентах до першого підсилювача погіршують підсумкову чутливість приймача децибел-у-децибел**.

**Крок 4. Обчислення межевої чутливості для двох типів модуляції:**

Розглянемо два випадки роботи даного радіомодуля при однаковій смузі пропускання `B = 125 кГц` (`10 · log10(125 000) = 50.97 дБ`):

*Випадок А: Стандартна частотна модуляція FSK (`SNR_min = +10.0 дБ`):*

```
P_noise = -174.0 + 10 · log10(125000) + 3.91
= -174.0 + 50.97 + 3.91              [обчислення логарифма смуги]
= -119.12 dBm                        [сумарний поріг шуму]

S_fsk = P_noise + SNR_min
= -119.12 + 10.0                     [підстановка SNR_min = +10.0 дБ для FSK]
= -109.12 dBm                        [підсумкова чутливість FSK]
```

*Випадок Б: Довгосяжна модуляція LoRa SF12 (`SNR_min = -20.0 дБ`):*

```
S_lora = P_noise + SNR_min
= -119.12 + (-20.0)                  [підстановка SNR_min = -20.0 дБ для LoRa SF12]
= -139.12 dBm                        [підсумкова чутливість LoRa SF12]
```

Порівняння показує, що використання спеціалізованої модуляції з розширенням спектра (LoRa SF12) дає виграш у чутливості на 30 дБ (`-139.12 dBm` проти `-109.12 dBm`), що при однакових антенах і потужності передавача збільшує дальність зв'язку в 4–8 разів.
