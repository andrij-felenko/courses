# 🧮 Математика часової рефлектометрії: відбиття, імпеданс та просторова роздільна здатність

Часова рефлектометрія спирається на хвильову теорію довгих ліній та розв'язання крайових задач електродинаміки у часовій області. Нижче наведено послідовне виведення рівнянь поширення перепаду напруги, інверсії імпедансу, реактивного відбиття, алгоритму знімання шарів (Layer Peeling) та диференційних мод.

---

### 1. Рівняння довгих ліній та виведення хвильової швидкості

Розглянемо двопровідниковую лінію передачі, параметри якої розподілені вздовж просторової осі `x`: погонна індуктивність `L` (Гн/м), погонна ємність `C` (Ф/м), погонний активний опір `R` (Ом/м) та погонна провідність ізоляції `G` (См/м).

Розподіл напруги `V(x,t)` та струму `I(x,t)` описується системою дифрівнянь першого порядку (телеграфістськими рівняннями Хевісайда):

```
∂V(x,t) / ∂x = - L · (∂I(x,t) / ∂t) - R · I(x,t)
∂I(x,t) / ∂x = - C · (∂V(x,t) / ∂t) - G · V(x,t)
```

Для високочастотних складових надшвидкого перепаду TDR маємо `ωL >> R` та `ωC >> G`, тому втратами `R` і `G` у першому наближенні можна знехтувати (модель ідеальної лінії без втрат). Диференціюючи перше рівняння за `x`, а друге за `t`, і підставляючи одне в одне, отримуємо однорідне одновимірне хвильове рівняння Д'Аламбера:

```
∂²V(x,t) / ∂x² = L · C · (∂²V(x,t) / ∂t²)
```

Загальний розв'язок рівняння Д'Аламбера представляється у вигляді суми двох хвиль, що поширюються у протилежних напрямках:

```
V(x,t) = V⁺(t - x/v) + V⁻(t + x/v)
```

де `V⁺` — падаюча хвиля, що біжить від генератора у додатному напрямку осі `x`, а `V⁻` — відбита хвиля, що повертається у зворотному напрямку.

Швидкість поширення хвилі `v` та хвильовий опір лінії `Z₀` виражаються через погонні параметри `L` і `C`:

```
v = 1 / √(L · C) = c / √(ε_r · μ_r)
Z₀ = √(L / C)
```

У більшості немагнітних діелектриків плати та кабелів відносна магнітна проникність `μ_r = 1`, тому фазова швидкість виражається суто через відносну діелектричну проникність середовища `ε_r`:

```
v = c / √(ε_r)
```

Оскільки виміряний часовий інтервал `Δt` між падаючим фронтом та відбитою хвилею відповідає подвійному шляху сигналу (туди й назад), точна просторова координата `x` точки неоднорідності дорівнює:

```
x = v · Δt / 2 = (c · Δt) / (2 · √(ε_r))
```

**Приклад розрахунку координати:** Для стеклотекстолітової мікросмужки на платі FR-4 (`ε_r = 4.0`, фазова швидкість `v = 3·10⁸ / √4.0 = 1.5·10⁸ м/с = 15 см/нс`) затримка відбитого піку від перехідного отвору становить `Δt = 0.40 нс`:

```
x = (15 см/нс · 0.40 нс) / 2 = 3.0 см
```

### 2. Виведення коефіцієнта відбиття та інверсії імпедансу

Розглянемо межу двох ділянок лінії в точці `x = 0`: перша ділянка має хвильовий опір `Z₀`, а друга (навантаження або дефект) — локальний опір `Z_L`.

Згідно з законами Кірхгофа, на межі `x = 0` напруги та струми мають бути неперервними:

```
V_total(0,t) = V⁺ + V⁻
I_total(0,t) = I⁺ - I⁻ = (V⁺ / Z₀) - (V⁻ / Z₀)
```

Зв'язок між повним струмом та повною напругою на навантаженні задається законом Ома: `V_total = Z_L · I_total`. Підставляючи вирази для напруги та струму, отримуємо:

```
V⁺ + V⁻ = Z_L · ( (V⁺ / Z₀) - (V⁻ / Z₀) )
```

Поділимо обидві частини рівняння на напругу падаючого перепаду `V⁺` та введемо визначення **коефіцієнта відбиття у часовій області** `Γ = V⁻ / V⁺`:

```
1 + Γ = (Z_L / Z₀) · (1 - Γ)
```

Розкриваємо дужки та групуємо доданки відносно `Γ`:

```
1 + Γ = (Z_L / Z₀) - Γ · (Z_L / Z₀)
Γ · (1 + Z_L / Z₀) = (Z_L / Z₀) - 1
Γ · ( (Z₀ + Z_L) / Z₀ ) = (Z_L - Z₀) / Z₀
```

Помноживши обидві частини на `Z₀`, отримуємо класичну формулу коефіцієнта відбиття:

```
Γ = (Z_L - Z₀) / (Z_L + Z₀)
```

Завдання цифрового осцилографа рефлектометра полягає у розрахунку локального значення опору `Z_L(t)` за виміряним значенням відбитої напруги. Для цього формулу піддають алгебраїчній інверсії:

```
Γ · (Z_L + Z₀) = Z_L - Z₀
Γ · Z_L + Γ · Z₀ = Z_L - Z₀
Z₀ · (1 + Γ) = Z_L · (1 - Γ)

Z_L(t) = Z₀ · (1 + Γ(t)) / (1 - Γ(t))
```

### 3. Математичний аналіз реактивних неоднорідностей

У високочастотній електроніці більшість зосереджених дефектів мають індуктивний або ємнісний характер. Розглянемо виведення часового відгуку для обох випадків.

#### А. Послідовна індуктивність L (роз'єм, розварювальний дріт)

Нехай у точку `x = 0` включено послідовну індуктивність `L`. Диференційне рівняння для напруги на індуктивності має вигляд:

```
V_L(t) = L · (dI(t) / dt)
V⁺(t) + V⁻(t) - Z₀ · I(t) = L · (dI(t) / dt)
```

Враховуючи, що `I(t) = (V⁺(t) - V⁻(t)) / Z₀`, для ідеального ступенястого перепаду `V⁺(t) = V₀ · u(t)` отримуємо диференційне рівняння для відбитої хвилі `V⁻(t)`:

```
2 · V₀ · u(t) - 2 · V⁻(t) = (L / Z₀) · (dV⁻(t) / dt)
```

Розв'язання цього рівняння методом операційного числення Лапласа дає експоненціальний спад напруги:

```
V⁻(t) = V₀ · e^(-t / τ) · u(t)
```

де часова стала спаду `τ` дорівнює:

```
τ = L / (2 · Z₀)
```

Якщо генератор перепаду має скінченну тривалість фронту наростання `t_r`, амплітуда відбитого позитивного піку `Γ_peak` обчислюється шляхом інтегрування свертки:

```
Γ_peak ≈ L / (2 · Z₀ · t_r)      [при L << 2·Z₀·t_r]
```

**Приклад розрахунку індуктивності:** Для ВЧ-роз'єму SMA з паразитною індуктивністю `L = 1.0 нГн` у 50-омній лінії при вимірюванні TDR з фронтом `t_r = 30 пс`:

```
Γ_peak ≈ 1.0·10⁻⁹ / (2 · 50 · 30·10⁻¹²) = 1.0 / 3.0 ≈ 0.333
```

Тобто відбитий пік складе 33.3% від амплітуди перепаду.

#### Б. Паралельна ємність C (контактний майданчик, перехідний отвір Via)

Для паралельно включеної ємності `C` струм через ємність виражається як `I_C(t) = C · (dV_total / dt)`. Рівняння для відбитої хвилі напруги набуває вигляду:

```
V⁻(t) = - V₀ · e^(-t / τ) · u(t)
```

де часова стала відновлення `τ` дорівнює:

```
τ = (Z₀ · C) / 2
```

Для реального фронту з тривалістю `t_r` глибина негативного ємнісного провалу `Γ_dip` дорівнює:

```
Γ_dip ≈ - (Z₀ · C) / (2 · t_r)   [при C << 2·t_r / Z₀]
```

### 4. Алгоритм «знімання шарів» (Layer Peeling) для множинних відбиттів

Коли лінія містить кілька послідовних неоднорідностей `Z₁, Z₂, Z₃...`, первинна відбита хвиля від другої неоднорідності проходить крізь першу неоднорідність у зворотному напрямку, зазнаючи повторного відбиття та затухання.

Коефіцієнт проходження через межу задається як:

```
T = 1 + Γ = 2 · Z_L / (Z₀ + Z_L)
```

Сигнал `V_refl,2`, що повертається до осцилографа від другої неоднорідності, дорівнює:

```
V_refl,2 = V_inc · T₁→₂ · Γ₂ · T₂→₁ = V_inc · (1 + Γ₁) · Γ₂ · (1 - Γ₁) = V_inc · (1 - Γ₁²) · Γ₂
```

Якщо не враховувати множинні відбиття, розрахований імпеданс далеких ділянок плати матиме накопичувальну похибку. Для її усунення використовують алгоритм **Layer Peeling (інверсне розсіяння)**. 

Рекурентна формула відновлення істинного коефіцієнта відбиття `Γ_k` для `k`-го сегмента лінії з урахуванням усіх попередніх поверхів має вигляд:

```
Γ_k = Γ_observed,k / ∏_{j=1}^{k-1} (1 - Γ_j²)
Z_k = Z_{k-1} · (1 + Γ_k) / (1 - Γ_k)
```

### 5. Математика диференційних мод (Odd та Even)

Для пари зв'язаних симетричних мікросмужкових ліній передачі (наприклад, диференційна пара USB або PCIe) система телеграфістських рівнянь записується у матричній формі через індуктивність зв'язку `L_m` та ємність зв'язку `C_m`:

```
[ ∂V₁/∂x ]   [ L    L_m ] [ ∂I₁/∂t ]
[        ] = [          ] [        ]
[ ∂V₂/∂x ]   [ L_m  L   ] [ ∂I₂/∂t ]

[ ∂I₁/∂x ]   [ C    -C_m ] [ ∂V₁/∂t ]
[        ] = [           ] [        ]
[ ∂I₂/∂x ]   [ -C_m  C   ] [ ∂V₂/∂t ]
```

Шляхом діагоналізації матриць систему розкладають на два незалежні власні режими (моди) збудження:

1. **Непарна мода (Odd Mode):** `V₁ = -V₂ = V_diff / 2`. Хвильовий опір непарної моди `Z_odd`:

```
Z_odd = √((L - L_m) / (C + C_m))
Z_diff = 2 · Z_odd = 2 · √((L - L_m) / (C + C_m))
```

2. **Парна мода (Even Mode):** `V₁ = V₂ = V_comm`. Хвильовий опір парної моди `Z_even`:

```
Z_even = √((L + L_m) / (C - C_m))
Z_comm = Z_even / 2 = (1 / 2) · √((L + L_m) / (C - C_m))
```

Амплітуда відбиття у непарній та парній модах задається відповідними коефіцієнтами:

```
Γ_odd = (Z_odd - Z₀) / (Z_odd + Z₀)
Γ_even = (Z_even - Z₀) / (Z_even + Z₀)
```
