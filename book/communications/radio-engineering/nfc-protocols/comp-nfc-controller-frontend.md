# 🧩 Схема аналогового фронтенду NFC-контролерів та схемотехніка антен

Аналоговий фронтенд (Analog Front-End, AFE) NFC-контролера являє собою високочастотну частину трансивера, що здійснює формування радіочастотного поля `13.56 МГц`, амплітудну модуляцію передавача (PCD), а також детектування та квадратурне демодулювання надмалих сигналів відгуку пасивних міток (PICC).

У цьому матеріалі розглядаються принципи побудови аналогових фронтендів на прикладі спеціалізованих мікросхем NXP PN532, NXP PN5180 та STMicroelectronics ST25R3916, схемотехніка узгоджувальних мереж, а також інженерні методи розрахунку антен.

## 1. Узагальнена структурна схема NFC-контролера

Типовий NFC-трансивер складається з двох основних трактів — тракту передавача (TX) та тракту приймача (RX), підключених до мікроконтролерного ядра через цифровий інтерфейс керування (NCI / Host Interface):

```
                        NFC CONTROLLER (AFE)
+-------------------------------------------------------------------+
|  +--------------+    +-------------------+    +----------------+  |
|  | Host Interface| -> | Control & Framing | -> | TX Driver      |==|=> TX1/TX2
|  | (I2C/SPI/NCI)|    | Engine (ISO-DEP)  |    | (Push-Pull)    |  |
|  +--------------+    +-------------------+    +----------------+  |
|                               ^                                   |
|                      +-------------------+    +----------------+  |
|                      | Demodulator / AGC | <- | RX Subcarrier  |<=|<= RX1/RX2
|                      | & IQ ADC Engine   |    | Filter / Mixer |  |
|                      +-------------------+    +----------------+  |
+-------------------------------------------------------------------+
```

### Тракт передавача (Transmitter Track)
1. **Генератор тактової частоти:** Кварцовий резонатор на `27.12 МГц` із внутрішнім дільником на 2 формує точну опорну частоту несучої `13.56 МГц` з точністю не гірше `±50 ppm`.
2. **Вихідні драйвери `TX1` та `TX2`:** Двотактні (Push-Pull) каскади на потужних MOSFET-транзисторах, що працюють у мостовому режим протифазного розгойдування. Вони генерують прямокутне високочастотне коливання амплітудою до `5.0 В` (для PN532) або до `12.0 В` (двополярний вихід у PN5180 та ST25R3916).
3. **Модулятор передавача:** Здійснює керування шпаруватістю та амплітудою вихідного каскаду, формуючи 100% ASK паузи (Type A) або 10% ASK осадження (Type B).

### Тракт приймача (Receiver Track)
1. **Виводи входів `RX1` та `RX2`:** Диференціальні або однополярні входи приймача, захищені від високої напруги передавача обмежувальними діодами та дільником напруги.
2. **Квадратурний змішувач (I/Q Mixer):** Перемножує вхідний відбитий сигнал на косинусоїдальне I та синусоїдальне Q складові опорної несучої `13.56 МГц`, переносячи сигнал піднесучої `848 кГц` на нульову проміжну частоту.
3. **Полосовий фільтр піднесучої:** Виділяє бічні смуги `848 кГц` та пригнічує гармоніки несучої `13.56 МГц`.
4. **АРУ (Автоматичне регулювання посилення, AGC):** Адаптує підсилення аналогового тракту залежно від відстані до мітки, запобігаючи насиченню АЦП при близькому розташуванні мітки (відстань < 5 мм).
5. **Цифровий дедектор та декодер кадру:** АЦП перетворює виділений сигнал у цифровий код, після чого апаратний корелятор шукає стартові символи (SOF/Preamble) та виконує декодування Міллера або Манчестера.

## 2. Порівняльний аналіз чипів PN532, PN5180 та ST25R3916

Різні покоління NFC-контролерів демонструють еволюцію аналогового фронтенду від простих трансиверів з фіксованим узгодженням до інтелектуальних систем із керованими матрицями ємностей та динамічним аналізом імпедансу:

| Характеристика | NXP PN532 (2007) | NXP PN5180 (2016) | STMicroelectronics ST25R3916 (2020) |
| :--- | :--- | :--- | :--- |
| **Максимальна потужність TX** | ~`150 мВт` (`5.0 В`) | ~`2000 мВт` (`12.0 В`) | ~`1600 мВт` (`5.5 В` з посиленням) |
| **Автопідлаштування (AAT)** | Відсутнє | Відсутнє | Присутнє (DVC Capacitor Bank) |
| **Режим LPCD (Card Detect)** | Простий каскадний | Ємнісний/Індуктивний | Автоматичний вимірювач амплітуди та фази |
| **Підтримка Active P2P** | Так (ISO 18092) | Так (ISO 18092) | Так (ISO 18092) |
| **Хост-інтерфейси** | I2C, SPI, HSU (UART) | SPI (до 7 Мбіт/с) | SPI, I2C |
| **Цільове призначення** | POS-термінали, Arduino | Промислові зчитувачі | Смартфони, дверні замки, платіжні POS |

## 3. Режими роботи радіочастотного поля у Peer-to-Peer (Active vs Passive P2P)

Контролери NFC підтримють два принципово різних фізичних режими генерування поля при взаємодії між двома активними пристроями (наприклад, смартфонами у режимі LLCP/SNEP):

1. **Пасивний режим P2P (Passive P2P Mode):** Ініціатор (Initiator) генерує радіочастотне поле `13.56 МГц` безперервно протягом усього сеансу зв'язку. Цільовий пристрій (Target) не вмикає власне поле, а відповідає за допомогою модуляції навантаженням (аналогічно пасивній мітці).
2. **Активний режим P2P (Active P2P Mode):** Обидва пристрої мають власні джерела живлення та генератори поля. Ініціатор вмикає поле `13.56 МГц`, відправляє кадр даних і вимикає своє поле. Після цього Цільовий пристрій вмикає власне поле `13.56 МГц` і передає кадр відповіді. Це дозволяє істотно збільшити дальність зв'язку та забезпечує стабільну передачу даних на швидкостях `212` та `424 кбіт/с`.

## 4. Режим низькоспоживаного виявлення карт (LPCD)

У пристроях з батарейним живленням (смартфони, безконтактні замки) постійна генерація радіочастотного поля `13.56 МГц` призведе до швидкого розряду акумулятора (споживання струму передавача становить `100 – 300 мА`).

Для вирішення цієї проблеми застосовується режим **Low-Power Card Detection (LPCD)**:
- Контролер більшу частину часу перебуває у режимі глибокого сну (Deep Sleep з споживанням струму `< 10 мкА`).
- Періодично (наприклад, кожні `300 мс`) таймер контролера пробуджує аналоговий фронтенд та генерує надкороткий імпульс поля тривалістю всього `5 – 10 мкс`.
- За час імпульсу вимірювальна схема аналізує амплітуду або фазовий зсув напруги на антені. Якщо в зоні дії з'являється металевий предмет або мітка, відбитий імпеданс змінює амплітуду або фазу напруги вище заданого порогу `ΔV_th`.
- Лише при виявленні зміни фази контролер генерує переривання `INT` для основного процесора, який вмикає повну потужність поля та запускає процедуру опитування `REQA`.

## 5. Схемотехніка узгодження антени та фільтрації завад

Вихідний сигнал з виводів `TX1` та `TX2` являє собою прямокутну хвилю з багатим спектром вищих гармонік (`27.12 МГц`, `40.68 МГц` тощо). Для виконання вимог радіозавад (EMC/FCC/ETSI) та передачі максимальної потужності в антену між трансивером та котушкою антени встановлюється трьохкаскадна узгоджувально-фільтруюча мережа:

```
 TX1/TX2  +------------+    +-------------------+    +------------+
 -------->| EMC Filter | -> | Matching Network  | -> | PCB Antenna|
          | (L_emc,    |    | (C_series,        |    | Coil (L1)  |
          |  C_emc)    |    |  C_parallel)      |    +------------+
          +------------+    +-------------------+          |
                                    |                      |
                                    v                      v
                             +--------------+       +--------------+
                             | RX Damping   | <---- | RX Divider   |
                             | Resistors Rq |       | Network      |
                             +--------------+       +--------------+
```

### 1. Фільтр електромагнітної сумісності (EMC Filter)
Фільтр низьких частот другого порядку складається з індуктивностей `L_emc` (типово `470 нГн – 560 нГн`) та ємностей `C_emc` (типово `180 пФ – 220 пФ`). Його частота зрізу розраховується на рівні `14.5 – 15.0 МГц`. Фільтр перетворює прямокутну хвилю передавача на чисту синусоїду частотою `13.56 МГц` та пригнічує другу та третю гармоніки на рівень не менше `-40 дБ`.

### 2. Ланцюг узгодження імпедансу (Matching Network)
Складається з послідовних ємностей `C_series` та паралельних ємностей `C_parallel`. Мета ланцюга — трансформувати комплексний опір антени у симетричний опір `50 Ом` (або `20 Ом` залежно від вихідної потужності каскаду PN5180), компенсуючи індуктивний опір котушки `X_L = ω·L1`.

### 3. Демпфуючі резистори добротності `R_q`
Послідовно з котушкою антени або паралельно контуру включаються демпфуючі резистори `R_q` (типово `1.0 – 3.3 Ом`). Вони знижують власній добротність антени з початкового значення `Q > 40` до оптимального робочого значення:

```
Q_opt = 10 ... 15
```

Занадто висока добротність (`Q > 35`) викликає затягування фронтів модуляційних пауз 100% ASK (Modified Miller), через що мітка втрачає синхронізацію. Занадто низька добротність (`Q < 5`) знижує струм у котушці та зменшує дальність зчитування.

## 6. Хост-інтерфейси керування: I2C, SPI та стандарт NCI

Для зв'язку NFC-контролера з центральним процесором (Host MCU) використовуються такі системні шини та протоколи:

1. **Шина I2C:** Швидкості до `400 кбіт/с` (Fast mode) або `3.4 Мбіт/с` (High-speed mode). Використовується в компактних вбудованих пристроях. Вимагає окремої лінії переривання `INT` для сповіщення процесора про надходження даних з ефіру.
2. **Шина SPI:** Швидкості до `10 Мбіт/с`. Забезпечує найменшу затримку передачі бінарних кадрів. Є основним інтерфейсом для високопродуктивних трансиверів PN5180 та ST25R3916.
3. **Стандарт NCI (NFC Controller Interface):** Протокольний стандарт NFC Forum, що уніфікує команди між ОС (Android, Linux Neard) та NFC-чипом. Команди NCI капсулюються у 3-байтові заголовки: `MT` (Message Type: Command, Response, Notification), `GID` (Group ID: Control, Discovery, RF Management), `OID` (Opcode ID) та `Payload Length`.

## 7. Інженерні розрахунки та правил трасування друкованих плат

При розробці друкованих антен (PCB Antenna) на чотиришарових платах FR-4 розробники стикаються з такими фізичними обмеженнями:

1. **Розрахунок індуктивності друкованої котушки `L1`:**
   Для прямокутної планарної антени індуктивність розраховується за наближеною формулою Гарольда Вілера:
   ```
   L1 ≈ 2.34 · μ0 · N² · d_avg / (1 + 2.75 · ρ)
   ```
   де `N` — кількість витків (типово `N = 2 – 4`), `d_avg` — середній діаметр антени, `ρ` — коефіцієнт заповнення `(d_out - d_in) / (d_out + d_in)`. Типове значення індуктивності становить `L1 ≈ 1.0 – 2.5 мкГн`.

2. **Правила трасування друкованих провідників антени:**
   - Симетричні лінії `TX1` та `TX2` прокладаються диференціальною парою рівної довжини для виключення випромінювання синфазних завад.
   - Під котушкою антени на всіх внутрішніх та зовнішніх шарах плати вирізається суцільний шар землі (Ground Keepout Zone). Наявність суцільного шар міді під котушкою створює короткозамкнений виток, який за рахунок вихрових струмів падає індуктивність антени майже до нуля.

3. **Вплив металевого оточення та феритові екрани:**
   При встановленні антени безпосередньо на металеву кришку акумулятора смартфона або металевий корпус пристрою вихрові струми у металі створюють протилежний магнітний потік. Це розстроює резонансну частоту вгору та зводить індуктивність практично до нуля. Для нейтралізації цього ефекту між друкованою платою антени та металом обов'язково вкладають тонкий лист гнучкого спеченого фериту (Ferrite Absorber Sheet) товщиною `0.1 – 0.3 мм` з високою дійсною проникністю `μ' ≈ 100 – 150` та низькими втратами `μ'' < 5`.

4. **Розстроювання рукою користувача (Hand Detuning):**
   При наближенні людської руки паразитні ємності `C_hand ≈ 5 – 15 пФ` шунтують антенний контур, зсуваючи резонансну частоту з `13.56 МГц` вниз до `12.5 МГц`. Сучасні контролери ST25R3916 включають систему автоматичного підлаштування ємності АТК (Automatic Antenna Tuning, AAT) на базі вбудованих варикапів або керованих ключами конденсаторних матриць, що дозволяє підтримувати точний резонанс у динаміці.
