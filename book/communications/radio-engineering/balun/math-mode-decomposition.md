# 🧮 Математична теорія модового розкладу, S-параметрів та пригнічення спільної моди

Будь-яка двопровідна або коаксіальна лінія передачі під час взаємодії з асиметричним навколишнім середовищем описується сумою двох незалежних хвильових мод: **диференційної моди** (*differential mode*) та **спільної моди** (*common mode*). Метою балуна є безперешкодне пропускання диференційної моди з мінімальним згасанням і максимальне пригнічення спільної моди.

## 1. Алгебраїчний розклад векторів напруг та струмів

Розглянемо довільний паралельний вузол із двох провідників (позначимо їх як клемні лінії 1 та 2) відносно опорного потенціалу землі (Ground).

Нехай `V_1` та `V_2` — комплексні амплітуди напруг на клемах відносно землі, а `I_1` та `I_2` — струми, що входять у ці клеми.

Зв'язок між фізичними фазними величинами та модовими величинами задається лінійним матричним перетворенням:

```
[ V_dm ]   [  1.0  -1.0 ]   [ V_1 ]
[      ] = [            ] · [     ]    [пряме модове перетворення напруг]
[ V_cm ]   [  0.5   0.5 ]   [ V_2 ]

[ I_dm ]   [  0.5  -0.5 ]   [ I_1 ]
[      ] = [            ] · [     ]    [пряме модове перетворення струмів]
[ I_cm ]   [  1.0   1.0 ]   [ I_2 ]
```

Звідси прямі формули розкладу:

```
V_dm = V_1 - V_2             [різниця потенціалів між провідниками]
V_cm = (V_1 + V_2) / 2       [середній потенціал відносно землі]

I_dm = (I_1 - I_2) / 2       [протифазний диференційний струм]
I_cm = I_1 + I_2             [сумарний синфазний струм затікання]
```

Обернене перетворення дозволяє виразити реальні фазні струми через модові складники:

```
I_1 = I_dm + 0.5 · I_cm     [струм першого провідника: сума диференційної та синфазної мод]
I_2 = -I_dm + 0.5 · I_cm    [струм другого провідника: різниця диференційної та синфазної мод]
```

### Фізичний зміст мод:
- **Ідеальний диференційний режим (`I_cm = 0`):** Струми в провідниках рівні за модулем і протилежні за напрямком (`I_1 = -I_2 = I_dm`). Сумарний струм за межі лінії не виходить, зовнішнє випромінювання дорівнює нулю.
- **Спільна мода (`I_cm ≠ 0`):** Струм `I_cm` тече в один бік по обох провідниках і повертається через контур заземлення або зовнішню оплітку коаксіального кабелю. Саме цей струм створює паразитне випромінювання кабелю та збирає завади.

## 2. Матриця S-параметрів змішаного режиму (Mixed-Mode S-Matrix)

Для високочастотної характеристики балуна як чотириполюсника (або трьохполюсника) використовується розширена матриця розсіювання змішаного режиму `S^mm` (*Mixed-Mode Scattering Matrix*).

Для 3-портового балуна (Порт 1 — несиметричний вхід `Unbalanced`, Порти 2 і 3 — симетричний вихід `Balanced`) матриця пов'язує падаючі й відбиті хвилі диференційної та синфазної мод:

```
[ b_unbal ]   [ S_11    S_1d2   S_1c2 ]   [ a_unbal ]
[ b_dm2   ] = [ S_d21   S_dd22  S_dc22 ] · [ a_dm2   ]    [матриця змішаного режиму]
[ b_cm2   ]   [ S_c21   S_cd22  S_cc22 ]   [ a_cm2   ]
```

Зв'язок між класичними однополюсними S-параметрами 3-портової мережі `S_ij` та коефіцієнтами змішаного режиму виводиться лінійним перетворенням:

```
S_d21 = ( S_21 - S_31 ) / √2               [коефіцієнт передачі в диференційну моду]
S_c21 = ( S_21 + S_31 ) / √2               [коефіцієнт модового перетворення в синфазну моду]
S_dd22 = ( S_22 - S_23 - S_32 + S_33 ) / 2 [відбиття диференційної хвилі від виходу]
S_cc22 = ( S_22 + S_23 + S_32 + S_33 ) / 2 [відбиття синфазної хвилі від виходу]
```

Фізичний зміст головних коефіцієнтів змішаної матриці:
1. **`S_d21` (Transmission Coefficient):** Пряме передавання потужності з несиметричного входу в диференційну моду симетричного виходу. У зоні прозорості ідеального балуна `|S_d21| = 1` (`0 dB`).
2. **`S_c21` або `S_cd21` (Mode Conversion Coefficient):** Небажане перетворення несиметричного сигналу в струм спільної моди на виході (перетворення диференційної хвилі в синфазну). Для якісного балуна значення `|S_c21|` має бути якомога меншим (`< -30 dB`).
3. **`S_cc22` (Common-Mode Reflection / Isolation):** Здатність балуна відбивати або затримувати хвилю спільної моди.

## 3. Коефіцієнт пригнічення спільної моди (CMRR)

Головною кількісною мірою якості балуна є **коефіцієнт пригнічення спільної моди** (*Common-Mode Rejection Ratio, CMRR*):

```
CMRR = 20 · log10( |S_d21| / |S_c21| )    [формула пригнічення у логарифмічному масштабі, дБ]
```

Для якісного балуна величина CMRR має становити не менше `25…40 дБ` у робочій смузі частот. Це означає, що потужність витоку спільної моди становить менше 0.1%–0.01% від корисного диференційного сигналу.

### Двопараметричний аналіз амплітудної та фазової несиметрії

Якщо балун видає на плечі антени напруги `V_1` та `V_2`, які мають амплітудну асиметрію `ΔA` (відносне розбалансування амплітуд) та фазове відхилення `Δθ` від ідеальних 180°:

```
V_1 = V_0 · (1 + ΔA/2) · exp(j · Δθ / 2)       [напруга першого плеча з урахуванням відхилень]
V_2 = -V_0 · (1 - ΔA/2) · exp(-j · Δθ / 2)      [напруга другого плеча з урахуванням відхилень]
```

Тоді амплітуда породженої спільної моди відносно диференційної виводиться розкладом у ряд Тейлора при малих відхиленнях:

```
|V_cm / V_dm| ≈ 0.5 · √[ (ΔA)² + (Δθ in rad)² ]    [відносна амплітуда породженої синфазної моди]
```

Наприклад, якщо балун має фазове розбалансування `Δθ = 5°` (`0.087 rad`) та амплітудну асиметрію `ΔA = 5%` (`0.05`), то пригнічення спільної моди обмежене величиною:

```
|V_cm / V_dm| ≈ 0.5 · √[ 0.05² + 0.087² ]          [підстановка значень ΔA та Δθ]
              = 0.5 · 0.100                         [обчислення квадратного кореня]
              = 0.05                                [результат: відносна частка спільної моди]
              ≈ -26 дБ                              [переведення у децибели]
```

Отже, навіть незначний фазовий зсув у 5 градусів знижує CMRR балуна до 26 дБ, незалежно від якості феритового осердя.

## 4. Математична модель струмового дроселя Гуанелла

Розглянемо струмовий балун Гуанелла, намотаний на феритовому тороїді з комплексною магнітною проникністю `μ = μ' - j·μ''`.

Індуктивний опір спільної моди, що створюється дроселем для струму затікання `I_cm`:

```
Z_cm = R_cm + j · X_cm                             [комплексний опір дроселя]
     = 2π · f · L_0 · μ'' + j · 2π · f · L_0 · μ'  [розділення на активні втрати та реактивність]
```

де `L_0 = (4π · 10⁻⁷ · N² · A_e) / l_m` — початкова геометрія осердя (без урахування фериту), `N` — кількість витків, `A_e` — площа перерізу осердя, `l_m` — середня довжина магнітної лінії.

### Еквівалентна схема та ослаблення струму спільної моди

Еквівалентна схема пригнічення струму спільної моди являє собою дільник напруги між імпедансом дроселя `Z_cm` та еквівалентним опором заземлення навантаження `Z_g`:

```
I_cm = V_cm_src / ( Z_cm + 2 · Z_0 + Z_g )          [струм спільної моди в колі з дроселем]
```

Звідси пригнічення струму затікання в децибелах розраховується як:

```
Atten_cm = 20 · log10( 1 + |Z_cm| / (2 · Z_0) )     [загальна формула ослаблення затікання]
```

### Частотна залежність та власна резонансна частота (SRF)

Зі зростанням частоти індуктивний опір дроселя `X_cm = 2π·f·L_cm` зростає, але одночасно діє міжвиткова паразитні ємність обмотки `C_p`. Осердя створює паралельний контур із власною резонансною частотою (Self-Resonant Frequency, SRF):

```
f_SRF = 1 / ( 2π · √(L_cm · C_p) )                 [власна резонансна частота дроселя]
```

На частоті `f = f_SRF` опір `|Z_cm|` досягає свого максимуму (зокрема за рахунок активного опору втрат у фериті `R_cm`), забезпечуючи пікове пригнічення затікання. На частотах `f > f_SRF` дросель переходить у ємнісний режим, і його загороджувальний опір починає падати.

### Числовий приклад розрахунку:
Нехай кабель має `Z_0 = 50 Ом`, а дросель на феритовому тороїді Mix 31 забезпечує індуктивний опір `|Z_cm| = 1000 Ом` на частоті 14 МГц.

```
Atten_cm = 20 · log10( 1 + 1000 / (2 · 50) )       [підстановка Z_cm = 1000 Ом, Z_0 = 50 Ом]
         = 20 · log10( 1 + 10 )                     [обчислення відношення 1000 / 100]
         = 20 · log10( 11 )                         [додавання одиниці в дужках]
         ≈ 20.8 дБ                                  [десятичний логарифм та множення на 20]
```

Якщо опір дроселя підняти до `Z_cm = 5000 Ом` (за рахунок застосування двох послідовних тороїдів або збільшення кількості витків), пригнічення затікання зростає до:

```
Atten_cm = 20 · log10( 1 + 5000 / (2 · 50) )       [підстановка Z_cm = 5000 Ом, Z_0 = 50 Ом]
         = 20 · log10( 1 + 50 )                     [обчислення відношення 5000 / 100]
         = 20 · log10( 51 )                         [додавання одиниці в дужках]
         ≈ 34.1 дБ                                  [десятичний логарифм та множення на 20]
```

При цьому диференційний ВЧ-сигнал усередині 50-омного кабелю проходить крізь балун із згасанням менше `0.05 дБ`.

## 5. Розрахунок граничної магнітної індукції при високій потужності

При роботі балуна під навантаженням ВЧ-потужності `P` в імпедансі `Z_0` діє пікова напруга:

```
V_peak = √( 2 · P · Z_0 )                           [амплітудне значення ВЧ напруги]
```

Магнітна індукція `B_peak` у феритовому тороїдальному осерді з площею перерізу `A_e` (в см²) та кількістю витків `N` обчислюється за формулою Фарадея:

```
B_peak = ( V_peak · 10⁸ ) / ( 4.44 · f · A_e · N )   [пікова магнітна індукція в Гауссах]
```

Для запобігання нелінійним спотворенням та термічному розгону фериту значення `B_peak` у робочому режимі не повинно перевищувати `2000…2500 Гаусс` (`0.2…0.25 Тл`).
