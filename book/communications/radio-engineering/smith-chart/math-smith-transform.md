# 🧮 Математичний вивід конформного відображення Сміта

Для фундаментального геометричного й фізичного розуміння кругової діаграми Сміта необхідно провести математичний вивід її базових кіл та топологічних перетворень з перших принципів аналітичної геометрії та теорії функцій комплексної змінної. Обчислення режимів у фідерних лінійних трактах із розподіленими параметрами базується на зв'язку між нормованим імпедансом навантаження та комплексним коефіцієнтом відбиття хвилі. Цей зв'язок задається дробово-лінійним (мебіусовим) конформним відображенням, яке переводить праве півпростір додатних активних опорів усередину одиничного кола.

---

### 1. Нормалізація імпедансу та перетворення Мебіуса

Розгляньмо фідерну лінію передачі з хвильовим (характеристичним) опором `Z₀` (у радіочастотних трактах зазвичай `Z₀ = 50 Ом` або `75 Ом`), навантажену на довільний комплексний імпеданс `Z = R + jX`. Першим кроком є перехід до безрозмірного нормованого імпедансу `z`:

```
z = Z / Z₀ = (R + jX) / Z₀ = r + jx
```

де `r = R / Z₀ ≥ 0` — нормований активний опір, а `x = X / Z₀` — нормований реактивний опір (`x > 0` відповідає індуктивній реактивності, а `x < 0` — ємнісній реактивності).

Комплексний коефіцієнт відбиття напруги `Γ` (гамма) у точці підключення навантаження виражається через `z` за допомогою виразу:

```
Γ = (z - 1) / (z + 1)
```

Запишемо `Γ` у декартових компонентах на комплексній площині відбиття `(Γ_r, Γ_i)`:

```
Γ = Γ_r + j·Γ_i
```

Підставивши `z = r + jx` у формулу коефіцієнта відбиття, отримуємо:

```
Γ_r + j·Γ_i = (r + jx - 1) / (r + jx + 1)
            = ((r - 1) + jx) / ((r + 1) + jx)
```

Щоб відокремити дійсну та уявну частини, помножимо чисельник і знаменник на комплексне спряження знаменника `((r + 1) - jx)`:

```
Чисельник = ((r - 1) + jx) · ((r + 1) - jx)
          = (r - 1)(r + 1) - jx(r - 1) + jx(r + 1) + x²    [розкрили дужки]
          = (r² - 1 + x²) + j·(2x)                         [звели подібні доданки]

Знаменник = ((r + 1) + jx) · ((r + 1) - jx)
          = (r + 1)² + x²                                  [квадрат модуля знаменника]
```

Розділивши дійсну та уявну частини чисельника на дійсний знаменник, маємо:

```
Γ_r = (r² - 1 + x²) / ((r + 1)² + x²)          [Рівняння 1: дійсна частина]
Γ_i = (2x) / ((r + 1)² + x²)                   [Рівняння 2: уявна частина]
```

Обернене перетворення Мебіуса (вираження нормованого імпедансу `z` через `Γ`) обчислюється шляхом алгебраїчного розв'язання відносно `z`:

```
Γ · (z + 1) = z - 1                            [помножили на знаменник z+1]
Γ·z + Γ = z - 1                                [розкрили дужки]
z · (1 - Γ) = 1 + Γ                            [винесли z за дужки]
z = (1 + Γ) / (1 - Γ)                          [виразили z через Γ]
```

Розклавши `Γ = Γ_r + j·Γ_i` в оберненому перетворенні, отримуємо вирази для `r` та `x` через компоненти `Γ_r` і `Γ_i`:

```
z = r + jx = ((1 + Γ_r) + j·Γ_i) / ((1 - Γ_r) - j·Γ_i)
```

Множенням на спряжений знаменник `((1 - Γ_r) + j·Γ_i)` маємо:

```
r = (1 - Γ_r² - Γ_i²) / ((1 - Γ_r)² + Γ_i²)    [Рівняння 3]
x = (2·Γ_i) / ((1 - Γ_r)² + Γ_i²)             [Рівняння 4]
```

### 2. Математичний вивід кіл постійного активного опору (r-кола)

Знайдемо геометричне місце точок на площині `(Γ_r, Γ_i)`, для яких нормований активний опір дорівнює сталій величині `r = const`.

Використаємо Рівняння 3:

```
r = (1 - Γ_r² - Γ_i²) / ((1 - Γ_r)² + Γ_i²)
```

Розкриємо знаменник і перенесемо його в ліву частину:

```
r · ((1 - Γ_r)² + Γ_i²) = 1 - Γ_r² - Γ_i²
r · (1 - 2·Γ_r + Γ_r² + Γ_i²) = 1 - Γ_r² - Γ_i²
r - 2·r·Γ_r + r·Γ_r² + r·Γ_i² + Γ_r² + Γ_i² = 1
(r + 1)·Γ_r² - 2·r·Γ_r + (r + 1)·Γ_i² = 1 - r
```

Розділимо обидві частини рівняння на `(r + 1)`:

```
Γ_r² - (2·r / (r + 1))·Γ_r + Γ_i² = (1 - r) / (r + 1)
```

Доповнимо вираз для `Γ_r` до повного квадрата, додавши `(r / (r + 1))²` до обох частин рівняння:

```
[Γ_r² - 2·(r / (r + 1))·Γ_r + (r / (r + 1))²] + Γ_i² = (1 - r) / (r + 1) + (r / (r + 1))²
(Γ_r - r / (r + 1))² + Γ_i² = ((1 - r)(r + 1) + r²) / (r + 1)²
(Γ_r - r / (r + 1))² + Γ_i² = (1 - r² + r²) / (r + 1)²
(Γ_r - r / (r + 1))² + Γ_i² = 1 / (r + 1)²
```

Отриманий вираз є канонічним рівнянням кола у координатах `(Γ_r, Γ_i)` вигляду `(x - x₀)² + (y - y₀)² = R²`.

Отже, будь-яка лінія постійного активного опору `r = const` на діаграмі Сміта є колом із параметрами:

```
Центр r-кола:    C_r = (r / (r + 1), 0)
Радіус r-кола:   R_r = 1 / (r + 1)
```

#### Анатомія та межі r-кіл:
* **При `r = 0` (чисто реактивне навантаження):**
  Центр `C_r = (0, 0)`, радіус `R_r = 1`. Це зовнішній контур діаграми `|Γ| = 1`.
* **При `r = 0.5`:**
  Центр `C_r = (1/3, 0) ≈ (0.333, 0)`, радіус `R_r = 2/3 ≈ 0.667`.
* **При `r = 1.0` (узгоджений опір `R = Z₀`):**
  Центр `C_r = (0.5, 0)`, радіус `R_r = 0.5`. Коло проходить через центр діаграми `(0, 0)`.
* **При `r = 2.0`:**
  Центр `C_r = (2/3, 0) ≈ (0.667, 0)`, радіус `R_r = 1/3 ≈ 0.333`.
* **При `r → ∞` (холостий хід):**
  Центр `C_r → (1, 0)`, радіус `R_r → 0`. Коло стискається в точку `(1, 0)`.

Усі r-кола проходять через спільну точку дотику `(1, 0)`, оскільки координата правої точки кожного кола дорівнює:

```
x_max = r / (r + 1) + 1 / (r + 1) = (r + 1) / (r + 1) = 1.0
```

### 3. Математичний вивід дуг постійного реактивного опору (x-дуги)

Знайдемо геометричне місце точок на площині `(Γ_r, Γ_i)`, для яких нормований реактивний опір має сталу величину `x = const`.

Використаємо Рівняння 4:

```
x = (2·Γ_i) / ((1 - Γ_r)² + Γ_i²)
```

Перенесемо знаменник у ліву частину:

```
x · ((1 - Γ_r)² + Γ_i²) = 2·Γ_i
x · (1 - 2·Γ_r + Γ_r² + Γ_i²) = 2·Γ_i
1 - 2·Γ_r + Γ_r² + Γ_i² = (2 / x)·Γ_i
(Γ_r - 1)² + [Γ_i² - (2 / x)·Γ_i] = 0
```

Доповнимо вираз для `Γ_i` до повного квадрата, додавши `(1 / x)²` до обох частин:

```
(Γ_r - 1)² + [Γ_i² - 2·(1 / x)·Γ_i + (1 / x)²] = (1 / x)²
(Γ_r - 1)² + (Γ_i - 1 / x)² = (1 / x)²
```

Це канонічне рівняння кола постійної реактивності `x = const` з параметрами:

```
Центр x-кола:    C_x = (1, 1 / x)
Радіус x-кола:   R_x = 1 / |x|
```

#### Анатомія x-дуг:
* **Індуктивна реактивність (`x > 0`):** Центр у верхній півплощині `(1, 1/x)`. Усередині одиничного кола `|Γ| ≤ 1` зберігається лише дуга у верхній півплощині.
* **Ємнісна реактивність (`x < 0`):** Центр у нижній півплощині `(1, -1/|x|)`. Дуга розташована у нижній півплощині.
* **Резонанс (`x = 0`):** Радіус `R_x → ∞`, центр іде в нескінченність. Коло перетворюється на пряму лінію — горизонтальну дійсну вісь `Γ_i = 0`.
* Усі x-дуги також дотикаються до точки `(1, 0)` на правому краї діаграми.

### 4. Доведення ортогональності сітки Сміта

Математично доведемо, що r-кола та x-дуги перетинаються під кутом `90°` в кожній точці площини.

З аналітичної геометрії відомо: двакола є ортогональними тоді й лише тоді, коли квадрат відстані між їхніми центрами дорівнює сумі квадратів їхніх радіусів (теорема Піфагора для трикутника, утвореного центрами та точкою перетину).

Обчислимо квадрат відстані `d²` між центром r-кола `C_r = (r / (r + 1), 0)` та центром x-кола `C_x = (1, 1 / x)`:

```
d² = (1 - r / (r + 1))² + (1 / x - 0)²                        [квадрат відстані між центрами C_r та C_x]
   = ((r + 1 - r) / (r + 1))² + (1 / x)²                      [звели під спільний знаменник]
   = (1 / (r + 1))² + (1 / x)²                                [спростили чисельник]
```

Згадаємо вирази для радіусів кіл: `R_r = 1 / (r + 1)` та `R_x = 1 / |x|`. Тоді:

```
d² = R_r² + R_x²
```

Рівність `d² = R_r² + R_x²` виконується тотожно для будь-яких допустимих значень `r` та `x`. Це доводить, що **сітка діаграми Сміта є строго ортогональною сіткою кіл**.

### 5. Математичний вивід адмітансної сітки (y-кола)

При паралельному підключенні елементів використовують нормований адмітанс `y = g + jb = 1 / z`.

Зв'язок між `y` та `Γ`:

```
y = (1 - Γ) / (1 + Γ)
```

Порівняємо це з формулою для `z`: `z = (1 + Γ) / (1 - Γ)`. Бачимо, що заміна `z ↦ y` відповідає заміні `Γ ↦ -Γ`.

На комплексній площині операція `Γ ↦ -Γ` означає центральну симетрію відносно початку координат (поворот фазового кута на `180°`).

Рівняння кіл постійної активної провідності `g = const` та постійної реактивної провідності `b = const` отримують інверсією знаків у рівняннях для r та x:

```
(Γ_r + g / (g + 1))² + Γ_i² = (1 / (g + 1))²       [g-кола]
(Γ_r + 1)² + (Γ_i + 1 / b)² = (1 / b)²              [b-дуги]
```

Центри g-кіл розміщені у лівій півплощині в точках `(-g / (g + 1), 0)`, а всі кола дотикаються до лівої точки короткого замикання `(-1, 0)`.

### 6. Покроковий обчислювальний приклад із векторним виводом

Обчислимо точні координати точки на діаграмі Сміта для антени з імпедансом `Z_L = 30 - j40 Ом` у `50`-омному тракті (`Z₀ = 50 Ом`).

**Крок 1. Нормалізація імпедансу:**

```
r = 30 / 50 = 0.6                                              [нормований активний опір]
x = -40 / 50 = -0.8                                             [нормований реактивний опір]
z_L = 0.6 - j·0.8                                              [комплексне z_L]
```

**Крок 2. Обчислення параметрів r-кола та x-дуги:**

```
C_r = (0.6 / (0.6 + 1), 0) = (0.375, 0)                         [центр r-кола]
R_r = 1 / (0.6 + 1) = 0.625                                     [радіус r-кола]

C_x = (1, 1 / (-0.8)) = (1, -1.25)                              [центр x-кола]
R_x = 1 / |-0.8| = 1.25                                         [радіус x-кола]
```

**Крок 3. Обчислення комплексного коефіцієнта відбиття Γ:**

```
Знаменник = (r + 1)² + x²                                      [квадрат знаменника]
          = (0.6 + 1)² + (-0.8)²                               [підставили r=0.6, x=-0.8]
          = 1.6² + 0.64 = 3.20                                 [знаменник = 3.20]

Γ_r = (r² - 1 + x²) / 3.20                                     [дійсна частина Γ]
    = (0.36 - 1 + 0.64) / 3.20 = 0.0 / 3.20 = 0.0              [Γ_r = 0.0]

Γ_i = (2 · (-0.8)) / 3.20 = -1.6 / 3.20 = -0.50                [уявна частина Γ_i = -0.50]
```

Отримуємо результат: `Γ = 0.0 - j·0.50`. Точка лежить строго на вертикальній осі під центром діаграми!

**Крок 4. Перевірка належності точці перетину кіл:**

```
Відстань до C_r: (0.0 - 0.375)² + (-0.50 - 0)² = 0.390625 = 0.625²   [точка на r-колі]
Відстань до C_x: (0.0 - 1.0)² + (-0.50 - (-1.25))² = 1.5625 = 1.25²   [точка на x-дузі]
```

**Крок 5. Обчислення КСХ (SWR) та Return Loss (RL):**

```
|Γ| = √(0.0² + (-0.50)²) = 0.50                                [модуль коефіцієнта відбиття]

SWR = (1 + 0.50) / (1 - 0.50) = 1.50 / 0.50 = 3.00             [обчислення КСХ = 3.00:1]

RL = -20 · log₁₀(0.50) = -20 · (-0.3010) ≈ 6.02                [втрати на відбиття RL = 6.02 дБ]
```

Для імпедансу `30 - j40 Ом` модуль коефіцієнта відбиття дорівнює `0.50`, КСХ становить `3.00:1`, а втрати на відбиття дорівнюють `6.02 дБ`.
