<preknowlist>

- [Передавальні лінії](book:communications/transmission-lines) — хвильовий опір Z₀, фазове зсунення та розподілені параметри.
- [Узгодження імпедансу антени](book:communications/antenna-impedance-matching) — концепція узгодження, прямокутна декартова площина.
</preknowlist>

Коли інженер розробляє надвисокочастотний тракт на частоту 433 МГц, 2.4 ГГц або 5.8 ГГц, кожен сантиметр друкованої доріжки чи коаксіального кабелю перетворюється на систему з розподіленими параметрами. Спроба обчислити зміну вхідного імпедансу вздовж фідера за допомогою прямокутних декартових координат `Z = R + jX` наражається на геометричний та обчислювальний тупик. Активний опір `R` розтягується від нуля до нескінченності, реактивний опір `X` іде у мінус і плюс нескінченність, а трансформація опору вздовж фідера описує складні нелінійні спіралі, які неможливо наочно побудувати на аркуші паперу або швидко інтерпретувати на екрані вимірювального приладу. Кругова номограма, розроблена інженером Філіпом Смітом, вирішує цю проблему шляхом конформного відображення всієї нескінченної площини опорів усередину одного компактного одиничного кола коефіцієнта відбиття.

### Фізичний механізм розподілених ліній та геометрична тупиковість Декарта

У низькочастотній електротехніці довжина фізичного провідника значно менша за довжину електромагнітної хвилі (`l << λ`), тому напруга та струм у всіх точках провідника вважаються однаковими. Проте у високочастотному радіодіапазоні довжина хвилі стає порівнянною з розмірами друкованої плати. Наприклад, на частоті `2.45 ГГц` довжина хвилі у вакуумі становить приблизно `12.2 см`, а у підкладці з текстоліту FR-4 (з відносною діелектричною проникністю `ε_r ≈ 4.4`) вона скорочується до `5.8 см`. Через це вздовж лінії передачі виникають розподілена індуктивність `L_0` (Гн/м) та розподілена ємність `C_0` (Ф/м).

Хвильовий опір такої лінії без втрат визначається співвідношенням розподілених параметрів:

```
Z₀ = √(L_0 / C_0)
```

Якщо лінія навантажена на комплексний опір `Z_L = R_L + jX_L`, що не дорівнює хвильовому опору `Z₀`, виникає відбита хвиля. Падаюча та відбита хвилі, складаючись у кожній точці лінії на відстані `x` від навантаження, утворюють складний розподіл напруги `V(x)` та струму `I(x)`:

```
V(x) = V⁺ · e^(jβx) + V⁻ · e^(-jβx)
I(x) = (V⁺ / Z₀) · e^(jβx) - (V⁻ / Z₀) · e^(-jβx)
```

де `β = 2π / λ` — фазова константа хвилі. Вхідний імпеданс `Z(x) = V(x) / I(x)` на відстані `x` від навантаження виражається фундаментальною формулою фідерної лінії:

```
Z(x) = Z₀ · (Z_L + j·Z₀·tan(βx)) / (Z₀ + j·Z_L·tan(βx))
```

![Перетворення Декартової площини імпедансів у коло коефіцієнта відбиття](/book/communications/radio-engineering/smith-chart/img/mapping-smith.svg)
*Перехід від нескінченного напівпростору імпедансів R ≥ 0 у прямокутних координатах до обмеженого одиничного кола коефіцієнта відбиття |Γ| ≤ 1 за допомогою конформного перетворення Мебіуса.*

Спроба аналізувати цю формулу на прямокутній декартовій площині `Z = R + jX` демонструє трьох принципових дефектів:

1. **Необмеженість графічного масштабу:** Пасивний опір `R` змінюється від `0` (коротке замикання) до `∞` (холостий хід). Спроба показати на одному декартовому графіку низькоомні кола `10 Ом` та високоомні резонансні антени `2000 Ом` вимагає логарифмічного або нескінченного паперу.
2. **Складність ліній постійного відбиття:** Головним показником неузгодження є модуль коефіцієнта відбиття `|Γ|`. На декартовій площині `(R, X)` лінії однакового коефіцієнта відбиття утворюють сімейство ексцентричних кіл із різними центрами й радіусами, які вкрай важко суміщати з прямокутною сіткою.
3. **Нелінійність руху вздовж лінії:** Зміна координати `x` описує складні спіральні криві, обчислення яких у комплексній формі вимагає множення тригонометричних функцій у кожній частотній точці.

Рішенням, що перетворило високочастотну радіотехніку у 1930-х роках, стало відображення імпедансу на **полярну площину комплексного коефіцієнта відбиття** `Γ`.

### Конформне відображення та топологія одиничного кола

Замість того щоб будувати опір `Z` прямо, його спочатку нормують на характеристичний хвильовий опір лінії `Z₀`:

```
z = Z / Z₀ = (R / Z₀) + j·(X / Z₀) = r + jx
```

Нормований опір `z` є безрозмірною величиною. Наприклад, у `50`-омній системі опір `50 Ом` перетворюється на `z = 1.0 + j0`, коротке замикання — на `z = 0`, а холостий хід — на `z = ∞`.

Зв'язок між нормованим імпедансом `z` та комплексним коефіцієнтом відбиття `Γ` описується конформним перетворенням Мебіуса:

```
Γ = (z - 1) / (z + 1)
```

Це перетворення володіє унікальними геометричними властивостями:

* **Пакування пасивного напівпростору у диск:** Оскільки для будь-яких пасивних кіл активний опір невід'ємний (`r ≥ 0`), модуль коефіцієнта відбиття не перевищує одиниці (`|Γ| ≤ 1`). Весь нескінченний напівпростір додатних активних опорів відображається всередину **одиничного кола радіусом 1.0**.
* **Точка короткого замикання (`z = 0`):** Переходить у ліву крайню точку кола `Γ = -1` (фаза `180°`).
* **Точка холостого ходу (`z = ∞`):** Переходить у праву крайню точку кола `Γ = +1` (фаза `0°`).
* **Точка узгодження (`z = 1.0`):** Переходить у центр кола `Γ = 0`.
* **Чисто реактивна межа (`r = 0`):** Усі реактивні навантаження без активних втрат лягають чітко на зовнішнє граничне коло `|Γ| = 1`.

Детальний [історичний контекст створення цього перетворення у 1930-х роках Філіпом Смітом](book:communications/antenna-impedance-matching/hist-smith-chart.md) показує, як графічний аналог замінив ручні тригонометричні обчислення при створенні перших радарів сантиметрового діапазону.

### Анатомія сітки імпедансів: R-кола та X-дуги

Щоб зчитувати активний та реактивний опори безпосередньо з Полярного графіка `Γ`, на одиничне коло наносять криволінійну сітку координат. Ця сітка складається з двох взаємно ортогональних сімейств кіл.

![Анатомія сітки імпедансів: кола активного опору R та дуги реактивності X](/book/communications/radio-engineering/smith-chart/img/anatomy-smith.svg)
*Геометрична структура діаграми Сміта: кола постійного активного опору r (еквіцентричні), дуги постійної реактивності x (ортогональні) та концентричні кола постійного КСХ.*

#### 1. Кола постійного активного опору (r-кола)
Це сімейство кіл, на яких нормований активний опір має стале значення (`r = const`).
* Центр кожного r-кола розташований на горизонтальній осі у точці `(r / (r + 1), 0)`.
* Радіус кола дорівнює `R_r = 1 / (r + 1)`.
* Усі r-кола дотикаються одне до одного у єдиній правій точці холостого ходу `(1, 0)`.
* Коло `r = 1.0` проходить через центр діаграми `(0, 0)`.

#### 2. Дуги постійного реактивного опору (x-дуги)
Це сімейство кіл, на яких нормована реактивність має стале значення (`x = const`).
* Центри кіл розташовані на вертикальній лінії, що проходить через правий край діаграми `(1, 1/x)`, а їхній радіус дорівнює `R_x = 1 / |x|`.
* **Верхня півплощина (`x > 0`):** Відповідає **індуктивній** реактивності (`+jX`). Струм відстає від напруги за фазою.
* **Нижня півплощина (`x < 0`):** Відповідає **ємнісній** реактивності (`-jX`). Струм випереджає напругу.
* **Горизонтальна вісь (`x = 0`):** Чисто активна лінія резонансу.

#### 3. Кола постійного КСХ (SWR-кола)
Модуль коефіцієнта відбиття `|Γ|` виражається через КСХ (SWR) як:

```
|Γ| = (SWR - 1) / (SWR + 1)
```

Оскільки `|Γ|` — це геодезична відстань від центра діаграми `(0,0)`, геометричне місце точок з однаковим КСХ на діаграмі Сміта є **простим концентричним колом із центром у точці узгодження (0,0)**.

Щоб дізнатися КСХ для будь-якої точки імпедансу, достатньо провести циркулем коло через цю точку з центром у `(0,0)` і подивитися, у якій точці воно перетинає праву частину горизонтальної осі `x = 0`. Значення `r` у цій точці строго дорівнює КСХ. Повний [математичний вивід рівнянь r-кіл та x-дуг](book:communications/smith-chart/math-smith-transform.md) розібрано у відповідній вставці.

### Трансформація імпедансу вздовж лінії передачі

Найпотужніша практична властивість діаграми Сміта полягає у зображенні процесів розповсюдження хвиль у фідерах.

У лінії передачі з хвильовим опором `Z₀` та фазовою константою `β = 2π / λ` при переміщенні від навантаження до генератора на відстань `l` комплексна амплітуда відбитої хвилі набуває додаткового фазового набігу `-2βl`. Зміна коефіцієнта відбиття описується виразом:

```
Γ(l) = Γ_L · e^(-j·2βl)
```

![Трансформація імпедансу та обертання точки уздовж лінії передачі](/book/communications/radio-engineering/smith-chart/img/line-rotation.svg)
*Траєкторія руху імпедансу вздовж фідера: у лінії без втрат точка обертається по колу постійного КСХ за годинниковою стрілкою; у лінії з втратами траєкторія звужується у логарифмічну спіраль до центра.*

#### Правила руху по діаграмі:

1. **Рух до генератора (Wavelengths Toward Generator, WTG):** Відповідає збільшенню відстані від антени до передавача. На діаграмі Сміта це означає **обертання точки імпедансу ЗА годинниковою стрілкою** навколо центра.
2. **Рух до навантаження (Wavelengths Toward Load, WTL):** Обертання **ПРОТИ годинникової стрілки**.
3. **Періодичність півхвилі (`λ / 2`):** Повний оборот на `360°` по діаграмі Сміта відповідає зміщенню вздовж лінії на відстань `l = λ / 2` (оскільки `2βl = 2 · (2π / λ) · (λ / 2) = 2π`). Тобто через кожні пів довжини хвилі вхідний імпеданс фідера точно повторюється.
4. **Чвертьхвильовий трансформатор (`λ / 4`):** Поворот на `180°` (на протилежний бік діаграми) відповідає зміщенню на `l = λ / 4`. При цьому відбувається інверсія нормованого імпедансу:

```
z(l = λ/4) = 1 / z_L
```

Якщо на кінці чвертьхвильового кабелю висить коротке замикання (`z = 0`), на вмиканні ми отримуємо нескінченний опір — холостий хід (`z = ∞`). Це фундаментальний принцип роботи чвертьхвильових ізолювальних шлейфів.

#### Лінії з втратами (`α > 0`):
У реальних кабелях згасання хвилі описується коефіцієнтом загасання `α` (непер/метр). Формула коефіцієнта відбиття набуває вигляду:

```
Γ(l) = Γ_L · e^(-2αl) · e^(-j·2βl)
```

Модуль `|Γ|` експоненційно зменшується з довжиною. На діаграмі Сміта точка імпедансу описує **збіжну логарифмічну спіраль**, що скручується до центра `Γ = 0`. Довгий кабель із великими втратами завжди показує ідеальний КСХ `1.0:1` на своєму вході, навіть якщо на його протилежному кінці взагалі немає антени — відбита хвиля просто повністю згасає по дорозі назад.

### Суміщена ZY-діаграма та адмітансна сітка

При проектуванні узгоджувальних кіл радіоінженер зіштовхується як із послідовно ввімкненими елементами (конденсатори, індуктивності), так і з паралельними шлейфами або чип-компонентами.

Для послідовних елементів зручно додавати імпеданси: `Z_total = Z_1 + Z_2`. Проте для паралельних елементів додаються **адмітанси** (комплексні провідності): `Y_total = Y_1 + Y_2`, де `Y = 1 / Z = G + jB` (`G` — активна провідність у сименсах, `B` — реактивна провідність чи реактивне приймання).

Нормований адмітанс дорівнює:

```
y = Y / Y₀ = 1 / z = g + jb
```

де `Y₀ = 1 / Z₀` — хвильова провідність (для `50 Ом` це `0.02 Сименса = 20 мСм`).

![Суміщена ZY-діаграма імпедансів та адмітансів](/book/communications/radio-engineering/smith-chart/img/zy-overlay.svg)
*Суміщена ZY-діаграма Сміта: сітка імпедансів (синя) та дзеркально повернена на 180° сітка адмітансів (зелена). Точкове відображення y = 1/z дозволяє розраховувати паралельні й послідовні кола на одному аркуші.*

Комплексний зв'язок між `y` та `Γ` має вигляд:

```
y = (1 - Γ) / (1 + Γ)
```

Звідси випливає фундаментальне геометричне правило: **точка адмітансу `y` є точним центрально-симетричним відображенням точки імпедансу `z` відносно центра діаграми `Γ = 0`** (поворот на `180°`).

На **суміщеній ZY-діаграмі Сміта** (Impedance-Admittance Smith Chart) дзеркально накладають дві сітки:
1. **Z-сітка (сині кола):** Використовується для послідовних елементів. Рух при додаванні послідовної індуктивності `+jX` відбувається за годинниковою стрілкою вздовж кола постійного активного опору `r`. Додавання послідовної ємності `-jX` — проти годинникової стрілки.
2. **Y-сітка (зелені кола):** Використовується для паралельних елементів. Додавання паралельної ємності `+jB` дає рух за годинниковою стрілкою вздовж кола постійної провідності `g`. Додавання паралельної індуктивності `-jB` — проти годинникової стрілки.

### Практичний синтез узгоджувальних кіл (L-мережі)

Розгляньмо інженерну задачу: як узгодити довільну антену з передавачем `50 Ом` за допомогою найпростішого двоелементного узгоджувального кола (L-мережі, L-matching network).

Мета узгодження — перемістити точку імпедансу антени `z_L` у центр діаграми Сміта `z = 1.0 + j0` (де `Γ = 0`, а КСХ = `1:1`).

![Траєкторія синтезу узгоджувальної L-мережі на діаграмі Сміта](/book/communications/radio-engineering/smith-chart/img/l-matching-path.svg)
*Траєкторія узгодження антени 25 + j50 Ом на частоті 2.45 ГГц: покрокове переміщення з точки z_L уздовж кола провідності g = 0.4 паралельним конденсатором, а потім уздовж кола опору r = 1.0 послідовною індуктивністю.*

#### Універсальний алгоритм графічного синтезу:

1. **Нанесення точки навантаження:** Наносимо нормований імпеданс `z_L = Z_L / Z₀`.
2. **Вибір першого елемента:**
   * Якщо точка `z_L` лежить усередині кола `r = 1.0`, першим умикають **послідовний** реактивний елемент, щоб вийти на коло провідності `g = 1.0`.
   * Якщо точка `z_L` лежить поза колом `r = 1.0` (наприклад, `r < 1.0`), першим умикають **паралельний** елемент, щоб вийти на коло опору `r = 1.0`.
3. **Рух по кола сітки:** 
   * Пересуваємося вздовж кола сітки до перетину з цільовим колом `r = 1.0` або `g = 1.0`.
   * Величина дуги визначає необхідне нормоване реактивне приймання `Δb` або опір `Δx`.
4. **Компенсація реактивності у центр:**
   * Другим елементом рухаємося вздовж кола `r = 1.0` або `g = 1.0` строго у центр діаграми `(1.0 + j0)`.

### Покроковий числовий приклад розрахунку

Здійснимо повний числовий розрахунок узгодження Wi-Fi антени на частоті `f = 2.45 ГГц` (`ω = 2πf ≈ 1.5394 · 10¹⁰ рад/с`).

**Вихідні дані:**
* Опорний імпеданс тракту: `Z₀ = 50 Ом`
* Вхідний імпеданс антени: `Z_L = 25 + j50 Ом`

#### Крок 1: Нормалізація та визначення початкового КСХ

```
z_L = Z_L / Z₀ = (25 + j50) / 50 = 0.5 + j·1.0    [нормалізація на 50 Ом]
```

Обчислимо початковий коефіцієнт відбиття `Γ_L`:

```
Γ_L = (z_L - 1) / (z_L + 1)                       [вираз коефіцієнта відбиття]
= (0.5 + j1.0 - 1) / (0.5 + j1.0 + 1)             [підставили нормоване z_L]
= (-0.5 + j1.0) / (1.5 + j1.0)                    [звели подібні доданки]
= (-0.5 + j1.0) · (1.5 - j1.0) / (1.5² + 1.0²)    [помножили на спряжений знаменник]
= (0.25 + j2.0) / 3.25                            [розкрили дужки чисельника]
≈ 0.0769 + j·0.6154                               [ділення на дійсне число 3.25]
```

Модуль коефіцієнта відбиття та початковий КСХ:

```
|Γ_L| = √(0.0769² + 0.6154²)                      [модуль комплексного числа]
= √(0.0059 + 0.3787)                              [піднесення до квадрата]
= √0.3846 ≈ 0.6201                                [обчислення квадратного кореня]

SWR = (1 + |Γ_L|) / (1 - |Γ_L|)                   [формула КСХ через модуль Гамма]
= (1 + 0.6201) / (1 - 0.6201)                     [підставили значення |Γ_L|]
= 1.6201 / 0.3799 ≈ 4.26                          [підсумкове відношення]
```

КСХ `4.26:1` є незадовільним (відбивається понад `38%` потужності).

#### Крок 2: Перехід до адмітансу для паралельного елемента

Оскільки `r = 0.5 < 1.0`, першим елементом беремо **паралельний конденсатор**. Знайдемо початковий нормований адмітанс `y_L`:

```
y_L = 1 / z_L                                     [визначення нормованої провідності]
= 1 / (0.5 + j1.0)                                [підставили z_L = 0.5 + j1.0]
= (0.5 - j1.0) / (0.5² + 1.0²)                    [множення на спряжений знаменник]
= (0.5 - j1.0) / 1.25                             [обчислення квадрата модуля]
= 0.4 - j·0.8                                     [розподільне ділення]
```

Отже, початкова провідність `g = 0.4`, реактивна провідність `b_L = -0.8`.

#### Крок 3: Розрахунок паралельного конденсатора (C)

Рухаємося від точки `y_L = 0.4 - j0.8` вгору вздовж кола постійної провідності `g = 0.4` за годинниковою стрілкою (додаючи ємнісну провідність `+jΔb`), поки не перетнемо коло активного опору `r = 1.0`.

Точка перетину `y_1` на колі `r = 1.0` має провідність `g = 0.4` та реактивність `b_1 = +j0.49`.

Необхідна додаткова провідність конденсатора `Δb`:

```
Δb = b_1 - b_L = (+0.49) - (-0.80) = +1.29          [різниця провідностей]
```

Переведемо нормовану провідність `Δb` у фізичні фаради:

```
B = Δb · Y₀ = Δb / Z₀ = 1.29 / 50 = 0.0258        [перехід від нормованого значення]

C = B / (2π · f)                                  [ємність через реактивну провідність]
= 0.0258 / (2π · 2.45 · 10⁹)                      [підставили частоту 2.45 ГГц]
≈ 1.676 · 10⁻¹²                                   [отримали 1.68 пФ]
```

#### Крок 4: Розрахунок послідовної індуктивності (L)

Після підключення паралельного конденсатора `1.68 пФ` адмітанс вузла став рівним `y_1 = 0.4 + j0.49`. Знайдемо еквівалентний імпеданс у цій точці `z_1`:

```
z_1 = 1 / y_1                                     [перехід від провідності до опору]
= 1 / (0.4 + j0.49)                               [підставили y_1 = 0.4 + j0.49]
= (0.4 - j0.49) / (0.4² + 0.49²)                  [множення на спряжене]
= (0.4 - j0.49) / 0.4001                          [обчислення знаменника]
≈ 1.0 - j·1.225                                   [розподільне ділення]
```

Активний опір тепер дорівнює `r = 1.0`! Залишилося компенсувати ємнісну реактивність `x_1 = -1.225` за допомогою послідовної індуктивності `+jΔx`.

Необхідна індуктивна реактивність:

```
Δx = +1.225                                       [необхідний послідовний реактивний опір]
```

Переведемо в фізичні генрі:

```
X = Δx · Z₀ = 1.225 · 50 = 61.25                  [перехід до фізичного опору в Омах]

L = X / (2π · f)                                  [індуктивність через реактивний опір]
= 61.25 / (2π · 2.45 · 10⁹)                       [підставили частоту 2.45 ГГц]
≈ 3.979 · 10⁻⁹                                    [отримали 3.98 нГн]
```

#### Підсумок узгодження:
Додавши паралельний конденсатор `1.68 пФ` та послідовну індуктивність `3.98 нГн`, ми трансформували імпеданс антени `25 + j50 Ом` точно у `50 + j0 Ом`. КСХ знизився з `4.26:1` до досконалого `1.00:1`.

Розробку вбудованого [програмного модуля для автоматичного обчислення L-мереж та матриць трансформації](book:communications/smith-chart/proj-smith-calculator.md) на мовах C та C++ подано в практичній вставці.

### Робота з VNA та інтерпретація графіків на радіочастотах

У сучасній радіоелектроніці діаграма Сміта перетворилася на головний екранний інтерфейс векторних аналізаторів кіл (Vector Network Analyzer, VNA, зокрема NanoVNA, RigExpert, Keysight E5071C).

> 🔧 **Навіщо це.**
> При налаштуванні антени або ВЧ-тракту аналізатор сканує діапазон частот і будує на діаграмі Сміта безперервну годографну траєкторію параметра відбиття `S₁₁` (який за фізичним змістом є коефіцієнтом відбиття `Γ`). Вміння з одного погляду на екран VNA прочитати траєкторію дозволяє за лічені секунди діагностувати характер проблеми:

1. **Пошук резонансної частоти:** Точка, у якій годограф перетинає горизонтальну вісь `x = 0`, відповідає резонансу антени (відсутність реактивності).
2. **Оцінка активного опору на резонансі:** 
   * Якщо точка перетину лежить лівіше центра (`r < 1.0`), опір антени занизький (наприклад, `20 Ом`), і потрібне підвищення опору.
   * Якщо правіше (`r > 1.0`) — опір зависокий.
3. **Визначення геометричної довжини антени:**
   * Якщо роблять вимірювання на робочій частоті (наприклад, `433 МГц`), і маркери потрапляють у **нижню півплощину** (`-jX`), антена є **закороткою** (має ємнісний характер). Її треба фізично подовжити або додати подовжувальну індуктивність.
   * Якщо маркер у **верхній півплощині** (`+jX`) — антена **задовга** (індуктивний характер), її слід укоротити.
4. **Паразитні петлі та кабельний ефект:** Некомпенсована довжина вимірювального кабелю викликає додаткове обертання всієї траєкторії по колу. Сучасні VNA дозволяють виконувати процедуру "Port Extension" (електронне зміщення площини відліку), що віртуально «зрізає» кабель і повертає годограф до істинних клем антени.

### Створення та алгоритмізація розрахунків мовами C та C++

Для вбудованих систем вимірювання та автоматизованого синтезу узгоджувальних кіл подаємо кросплатформовий модуль обчислення метрик відбиття.

:::tabs
```c
/* C99: Обчислення коефіцієнта відбиття та КСХ */
#include <stdio.h>
#include <math.h>
#include <complex.h>

typedef struct {
    double complex gamma;
    double vswr;
    double return_loss_db;
} smith_point_t;

smith_point_t smith_analyze_impedance(double complex z_load, double z0) {
    smith_point_t result;
    double complex z_norm = z_load / z0;
    
    /* Γ = (z - 1) / (z + 1) */
    result.gamma = (z_norm - 1.0) / (z_norm + 1.0);
    double g_abs = cabs(result.gamma);
    
    if (g_abs >= 0.9999) {
        result.vswr = 999.0;
        result.return_loss_db = 0.0;
    } else {
        result.vswr = (1.0 + g_abs) / (1.0 - g_abs);
        result.return_loss_db = -20.0 * log10(g_abs);
    }
    
    return result;
}

void print_smith_summary(double complex z_load, double z0) {
    smith_point_t pt = smith_analyze_impedance(z_load, z0);
    printf("Z = %.1f + j%.1f Ом | Γ = %.3f ∠%.1f° | КСХ = %.2f:1 | RL = %.2f дБ\n",
           creal(z_load), cimag(z_load),
           cabs(pt.gamma), carg(pt.gamma) * 180.0 / M_PI,
           pt.vswr, pt.return_loss_db);
}
```
```cpp
// C++17: Обчислення коефіцієнта відбиття та КСХ
#include <iostream>
#include <complex>
#include <cmath>
#include <iomanip>
#include <numbers>

struct SmithPoint {
    std::complex<double> gamma;
    double vswr;
    double return_loss_db;
};

class SmithAnalyzer {
public:
    static SmithPoint analyze(std::complex<double> z_load, double z0 = 50.0) {
        const std::complex<double> z_norm = z_load / z0;
        const std::complex<double> gamma = (z_norm - 1.0) / (z_norm + 1.0);
        const double g_abs = std::abs(gamma);

        if (g_abs >= 0.9999) {
            return {gamma, 999.0, 0.0};
        }

        const double vswr = (1.0 + g_abs) / (1.0 - g_abs);
        const double rl_db = -20.0 * std::log10(g_abs);
        return {gamma, vswr, rl_db};
    }

    static void print_summary(std::complex<double> z_load, double z0 = 50.0) {
        const auto pt = analyze(z_load, z0);
        const double angle_deg = std::arg(pt.gamma) * 180.0 / std::numbers::pi;

        std::cout << std::fixed << std::setprecision(2);
        std::cout << "Z = " << z_load.real() << " + j" << z_load.imag() << " Ом"
                  << " | Γ = " << std::abs(pt.gamma) << " ∠" << angle_deg << "°"
                  << " | КСХ = " << pt.vswr << ":1"
                  << " | RL = " << pt.return_loss_db << " дБ\n";
    }
};
```
