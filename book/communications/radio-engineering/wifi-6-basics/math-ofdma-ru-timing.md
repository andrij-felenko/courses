# 🧮 Математика OFDMA: розкладання піднесучих, тривалість символу та спектральна ефективність

Ця вставка містить строгий математичний апарат фізичного рівня (PHY) стандарту IEEE 802.11ax (Wi-Fi 6). У статті наведено аналітичне виведення піднесучої відстані, частотно-часових параметрів OFDM-символу, геометрії ресурсних блоків (RU), вимог до векторної амплітуди помилки (EVM) модуляції 1024-QAM та покрокові розрахунки граничної спектральної ефективності й фізичної швидкості каналу.

## 1. Математика частотно-часової сітки 802.11ax

В усіх застарілих OFDM-стандартах бездротового зв'язку Wi-Fi (від IEEE 802.11a до 802.11ac) базовий розмір швидкого перетворення Фур'є (FFT/IFFT) для стандартного каналу з шириною смуги `B = 20 МГц` становив `N_FFT = 64` точки.

Відстань між піднесучими частотами `Δf_legacy` обчислювалася за базовою формулою:

```
Δf_legacy = B / N_FFT
= 20000 кГц / 64      [значення: B = 20 МГц, N_FFT = 64]
= 312.5 кГц           [ділення: крок піднесучої legacy]
```

У стандарті 802.11ax розробники застосували **чотириразове збільшення щільності піднесучих** (`4× density`), тобто розмір FFT розширено до `N_FFT = 256` точок для каналу `20 МГц` (і відповідно `512` точок для 40 МГц, `1024` точки для 80 МГц та `2048` точок для 160 МГц).

Нова відстань між піднесучими частотами `Δf_HE` обчислюється як:

```
Δf_HE = B / N_FFT
= 20000 кГц / 256     [значення: B = 20 МГц, N_FFT = 256]
= 78.125 кГц          [ділення: крок піднесучої 802.11ax]
```

### Корисна тривалість символу (Useful Symbol Duration)

З математичних властивостей прямого та оберненого перетворення Фур'є тривалість корисного інформаційного інтервалу OFDM-символу `T_DFT` є величиною, строго оберненою до відстані між піднесучими частотами `Δf`:

```
T_DFT = 1 / Δf_HE
= 1 / 78125 Гц       [підстановка: Δf_HE = 78.125 кГц]
= 12.8 мкс            [обчислення: корисна тривалість символу]
```

Для порівняння, у застарілих стандартах корисна тривалість символу становила `T_DFT_legacy = 1 / 312.5 кГц = 3.2 мкс`.

### Захисний інтервал (Guard Interval) та сумарний період символу

Для запобігання міжсимвольної інтерференції (Inter-Symbol Interference, ISI), викликаної багатопроменевим запізненням сигналу в просторі, до кожного символу додається циклічний префікс (Cyclic Prefix) — захисний інтервал `T_GI`.

Стандарт 802.11ax визначає три варіанти тривалості `T_GI`:
- **Короткий (Short GI):** `T_GI = 0.8 мкс` (для приміщень із малим запізненням променів).
- **Середній (Medium GI):** `T_GI = 1.6 мкс` (стандартне покриття).
- **Довгий (Long GI):** `T_GI = 3.2 мкс` (для відкритих просторів Outdoor та важких умов розсіювання).

Повна тривалість одного OFDM-символу `T_sym` становить:

```
T_sym = T_DFT + T_GI
```

Для трьох режимів значення `T_sym` дорівнюють:

```
T_sym_short  = 12.8 мкс + 0.8 мкс = 13.6 мкс   [overhead GI = 0.8/13.6 ≈ 5.88%]
T_sym_medium = 12.8 мкс + 1.6 мкс = 14.4 мкс   [overhead GI = 1.6/14.4 ≈ 11.11%]
T_sym_long   = 12.8 мкс + 3.2 мкс = 16.0 мкс   [overhead GI = 3.2/16.0 = 20.00%]
```

Завдяки збільшенню `T_DFT` до `12.8 мкс`, відсоток накладних витрат захисного інтервалу `0.8 мкс` впав з `20%` (у 802.11ac) до **`5.88%`** у Wi-Fi 6, що підняло загальну спектральну ефективність.

## 2. Геометрія розкладу Resource Units (RU)

У смузі `20 МГц` із 256 піднесучих не всі несучі використовуються для передачі корисного навантаження. Крайові піднесучі виконують роль захисних інтервалів (Guard Subcarriers), а центральні — усувають постійну складову (DC Subcarriers).

Математичний розклад 256 піднесучих у каналі `20 МГц`:
- Захисні піднесучі зліва: 6
- Захисні піднесучі справа: 5
- Центральні DC піднесучі: 3
- **Корисні піднесучі (Data + Pilot):** `256 - 6 - 5 - 3 = 242`

Ці 242 корисні піднесучі об'єднуються у стандартні конфігурації ресурсних блоків (Resource Unit, RU).

### Ієрархія та розмірності RU

Стандарт 802.11ax регламентує наступні типи RU для каналів різної ширини:

| Тип RU | Кількість піднесучих | Піднесучі даних (Data) | Пілот-піднесучі (Pilot) | Максимальна кількість користувачів у 20 МГц | Максимальна кількість користувачів у 80 МГц |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **RU 26** | 26 | 24 | 2 | 9 | 37 |
| **RU 52** | 52 | 48 | 4 | 4 | 16 |
| **RU 106** | 106 | 102 | 4 | 2 | 8 |
| **RU 242** | 242 | 234 | 8 | 1 (Single-User 20 МГц) | 4 |
| **RU 484** | 484 | 468 | 16 | N/A (потребує 40 МГц) | 2 |
| **RU 996** | 996 | 980 | 16 | N/A (потребує 80 МГц) | 1 |
| **RU 2×996**| 1992 | 1960 | 32 | N/A (потребує 160 МГц) | N/A (1 на 160 МГц) |

### Точна геометрія розташування 9 × RU26 у каналі 20 МГц

Розподіл 242 піднесучих під 9 блоків RU26 обчислюється так:

```
N_total_RU26 = 9 · 26 = 234 піднесучих
N_leftover   = 242 - 234 = 8 невикористаних залишкових піднесучих
```

Ці 8 додаткових піднесучих розміщуються як технологічні проміжки (unused subcarriers) між блоками RU26 для зменшення взаємних завад (Inter-RU Interference) при незалежній передачі від різних пристроїв.

## 3. Модуляція 1024-QAM: математика сузір'я та вимоги EVM

Стандарт 802.11ax ввів нову схему модуляції **1024-QAM** (MCS 10 та MCS 11).

Кількість біт `b`, що кодуються одним символом на одній піднесучій:

```
b = log2(1024) = 10 біт/символ
```

Порівняно з 256-QAM (`b = 8` біт/символ), приріст площної щільності становить:

```
ΔRate = (10 - 8) / 8 = 25%
```

### Відстань між точками сузір'я та вимоги до SNR

Сузір'я 1024-QAM містить 32 рівні амплітуди по осі I та 32 рівні по осі Q (`32 × 32 = 1024`).

Якщо нормувати середнє значення потужності сигналу до одиниці (`E_avg = 1`), то мінімальна відстань `d_min` між сусідніми точками сузір'я обчислюється за формулою:

```
d_min = √( 6 / (M - 1) )
```

Для `M = 1024`:

```
d_min = √( 6 / 1023 )
= √( 0.005865 )       [обчислення частки 6/1023]
≈ 0.07658             [добування квадратного кореня]
```

Для порівняння, у 256-QAM `d_min_256 = √( 6 / 255 ) ≈ 0.1534`. Тобто відстань між станами сигналу зменшилася вдвічі, що робить сузір'я винятково чутливим до шуму та нелінійності.

Мінімальне відношення сигнал/шум `SNR_min`, необхідне для впевненого декодування 1024-QAM при ймовірності бітової помилки `BER < 10⁻⁵`, становить:

```
SNR_min ≥ 35 дБ
```

### Математичне визначення та межа EVM

Векторна амплітуда помилки (Error Vector Magnitude, EVM) виражає відхилення фактично прийнятої точки `Z_k` у комплексному просторі IQ від ідеальної точки сузір'я `S_k`:

```
EVM_RMS = √( ∑ |Z_k - S_k|² / ∑ |S_k|² )
```

У логарифмічних одиницях (дБ):

```
EVM_dB = 20 · log10( EVM_RMS )
```

Вимога специфікації IEEE 802.11ax до приймально-передавального тракту для модуляції 1024-QAM:

```
EVM_req ≤ -35 дБ
```

В абсолютному вираженні `EVM_RMS ≤ 10^(-35/20) ≈ 0.0178` (відносна помилка вектора не повинна перевищувати `1.78%`).

## 4. Покроковий розрахунок максимальної фізичної швидкості (PHY Rate)

Загальна формула фізичної швидкості передачі даних `R_PHY` для кадру HE PPDU має вигляд:

```
R_PHY = ( N_data_subcarriers · b · R_fec · N_SS ) / T_sym
```

Де:
- `N_data_subcarriers` — кількість піднесучих даних у обраній смузі (або RU).
- `b` — кількість біт на символ модуляції (для 1024-QAM `b = 10`).
- `R_fec` — кодова швидкість завадостійкого кодування LDPC (для MCS 11 `R_fec = 5/6`).
- `N_SS` — кількість просторових потоків MIMO (Spatial Streams, від 1 до 8).
- `T_sym = T_DFT + T_GI` — повний період символу (мкс).

### Практичний приклад розрахунку для каналу 80 МГц (RU 996)

Обчислимо граничну швидкість для 8 просторових потоків (`N_SS = 8`), модуляції 1024-QAM, `R_fec = 5/6` та короткого захисного інтервалу `T_GI = 0.8 мкс`.

1. **Кількість піднесучих даних:** У блоці RU 996 `N_data_subcarriers = 980`.
2. **Корисне інформаційне навантаження одного символу (на 1 потік):**

```
N_bits_per_symbol_1SS = 980 · 10 · (5 / 6)
= 9800 · 0.833333     [переведення FEC rate 5/6 у десятковий дріб]
= 8166.666 біт        [множення: біти на символ для 1 просторового потоку]
```

3. **Сумарне навантаження для 8 просторових потоків (8×8 MIMO):**

```
N_bits_total = 8166.666 · 8
= 65333.33 біт        [множення на N_SS = 8 потоків]
```

4. **Тривалість символу:**

```
T_sym = 12.8 мкс + 0.8 мкс = 13.6 мкс = 13.6 · 10⁻⁶ с
```

5. **Фізична швидкість `R_PHY`:**

```
R_PHY = 65333.33 біт / (13.6 · 10⁻⁶ с)
= 4 803 921 568 біт/с [ділення сумарних біт на час T_sym]
≈ 4.804 Гбіт/с        [переведення у Гбіт/с]
```

### Гранична швидкість для каналу 160 МГц (RU 2×996)

Для каналу 160 МГц кількість піднесучих даних подвоюється: `N_data_subcarriers = 1960`.

```
R_PHY_160MHz = ( 1960 · 10 · (5/6) · 8 ) / (13.6 · 10⁻⁶)
= 130666.66 біт / 13.6 мкс   [обчислення інформаційного навантаження 160 МГц]
≈ 9.608 Гбіт/с                [підсумкова фізична швидкість для 160 МГц]
```

Таким чином, абсолютна теоретична межа фізичної швидкості стандарта IEEE 802.11ax становить **9.608 Гбіт/с** (для 8×8 MIMO, 160 МГц, 1024-QAM, GI 0.8 мкс).
