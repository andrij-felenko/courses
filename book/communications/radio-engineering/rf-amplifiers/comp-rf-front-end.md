# 🔌 Радіочастотний передній кінець (RF FEM)

Побудова радіочастотного тракту прийому й передачі вимагає вирішення схемотехнічної задачі ізоляції та узгодженої взаємодії між чутливим малошумним підсилювачем (LNA), потужним підсилювачем передачі (PA) та швидкодіючим перемикачем прийому/передачі (T/R switch). Без належної ізоляції вихідна потужність PA випалює вхідний транзистор LNA або викликає самозбудження тракту, а неузгодженість імпедансів призводить до втрат сигналу та спотворення амплітудно-частотної характеристики. Радіочастотні передні модулі (RF Front-End Modules, FEM) розв'язують цю задачу шляхом об'єднання в єдиній інтегрованій напівпровідниковій мікросхемі або багаточиповій збірці каскадів LNA, PA, перемикачів T/R switch, смугових фільтрів і кіл узгодження імпедансів.

---

### Призначення та типова функціональна структура

У сучасній радіоелектронній апаратурі — від смарт-телефонів, Wi-Fi 6 роутерів та IoT-модулів (LoRa, ESP32) до бортових радіоліній безпілотних апаратів — побудова ВЧ-тракту на дискретних транзисторах, індуктивностях та конденсаторах вимагає значної площі друкованої плати та складної конвеєрної настройки кожної випущеної плати. 

Концепція RF FEM вирішує цю проблему шляхом пакування всього аналогового ВЧ-переднього кінця у компактний суцільний корпус типу QFN або LGA (розміром від 2×2 мм до 5×5 мм). Напівпровідникова техніка виготовлення RF FEM спирається на дві основні архітектури: однокристальну монолітну інтегральну схему (MMIC) або багаточипову збірку у єдиному корпусі (System-in-Package, SiP). У збірках SiP кожен блок створюється за тією технологією, де він має максимальний ККД або найнижчий шум: підсилювач потужності виконано на GaN або GaAs, малошумний підсилювач — на GaAs pHEMT, а перемикач T/R — на високоізольованій кремнієвій підкладці RF SOI. Для підвищення селективності у сучасних SiP-модулях безпосередньо у корпус вбудовують акустичні фільтри (SAW — поверхневі акустичні хвилі, або BAW — об'ємні акустичні хвилі).

Усередині корпусу RF FEM реалізовано такі ключові блоки:
- **Малошумний підсилювач (LNA)** з внутрішніми колами шумового узгодження на 50 Ом.
- **Підсилювач потужності (PA)** із заінтегрованими каскадами попереднього та вихідного підсилення.
- **T/R перемикач** (Transmit/Receive Switch) для підключення LNA або PA до єдиної антени.
- **Обхідні ключі (Bypass Switches)** для відключення LNA при потужних вхідних сигналах.
- **Внутрішня логіка декодування станів та схеми зсуву (Bias Control)**.

```
                      Типова блок-схема RF FEM
                 +--------------------------------+
                 |                                |
  [RX_OUT] <-----|---[LNA] <---+                  |
                 |             |                  |
  [BYPASS] ------>-----------\ |                  |
                 |            v|                  |
                 |         [T/R Switch] <-------->|--- [ANT]
                 |            ^                   |
  [TX_IN]  ----->|---[PA]  ----+                  |
                 |                                |
  [CTRL]   ----->|--- [Логіка керування та Bias]  |
                 |                                |
                 +--------------------------------+
```

### Опис типових виводів (Pinout) та інтерфейсний контракт

Корпус RF FEM містить як високочастотні порти з нормованим хвильовим опором (50 Ом), так і низькочастотні цифрові лінії керування та лінії живлення:

| Назва виводу | Тип | Призначення та електричний контракт |
| :--- | :--- | :--- |
| **ANT** | ВЧ вхід/вихід | Спільний ВЧ-порт для підключення до антени чи зовнішнього смугового фільтра (хвильовий опір 50 Ом). Потребує зовнішнього розділювального конденсатора (DC Block). |
| **TX_IN** | ВЧ вхід | Вхід підсилювача потужності від трансивера/модулятора (хвильовий опір 50 Ом, малосигнальний рівень 0...+5 dBm). |
| **RX_OUT** | ВЧ вихід | Вихід малошумного підсилювача до демодулятора трансивера (хвильовий опір 50 Ом, рівень підсиленого сигналу). |
| **TX_EN** | Цифровий вхід | Логічна одиниця (3.3 В або 1.8 В) вмикає режим передачі: подається зсув на PA, а T/R-перемикач підключає PA до порту `ANT`. |
| **RX_EN** | Цифровий вхід | Логічна одиниця вмикає режим приймання: живиться LNA, а T/R-перемикач підключає порт `ANT` до входу LNA. |
| **BYPASS / GAIN** | Цифровий вхід | Керування коефіцієнтом підсилення LNA. Логічна 1 вимикає LNA і замикає обхідний ключ для захисту від перевантаження сильним сигналом. |
| **VCC_PA** | Живлення | Силова лінія живлення для вихідного каскаду PA (напруга 3.3 В...5.0 В, споживання струму під час передачі від 300 мА до 2 А). |
| **VCC_LNA** | Живлення | Малошумна лінія живлення для LNA та внутрішньої логіки (напруга 1.8 В...3.3 В, споживання струму 5...15 мА). |
| **GND / EPAD** | Земля | Центральний відкритий контакт під корпусом (Exposed Pad), який забезпечує відведення тепла від PA та низькоіндуктивне заземлення ВЧ-струмів. |

### Таблиця режимів роботи (Mode Control Matrix)

Керування мікросхемою відбувається шляхом подачі логічних рівнів на цифрові виводи `TX_EN`, `RX_EN` та `BYPASS`:

| TX_EN | RX_EN | BYPASS | Режим роботи | Електричний стан внутрішніх блоків |
| :---: | :---: | :---: | :--- | :--- |
| 0 | 0 | X | **Shutdown** | Усі внутрішні підсилювачі та генератори зсуву вимкнені. Струм споживання менше 1 мкА. |
| 0 | 1 | 0 | **RX High Gain** | LNA увімкнено (підсилення +15...+20 dB, NF 1.0 dB). T/R ключ з'єднує `ANT` з LNA. PA вимкнено. |
| 0 | 1 | 1 | **RX Bypass** | LNA вимкнено. ВЧ-сигнал від `ANT` прямує на `RX_OUT` через обхідний ключ (втрати ~1.5 dB). |
| 1 | 0 | X | **TX High Power**| PA увімкнено (+20...+30 dBm). T/R ключ з'єднує PA з `ANT`. LNA вимкнено та заізольовано (>35 dB). |
| 1 | 1 | X | *Заборонено* | Неприпустима комбінація! Ризик просочування вихідного сигналу PA на вхід LNA і пошкодження кристала. |

#### Характеристики S-параметрів у різних режимах

Кожен режим роботи RF FEM описується власною матрицею розсіяння:
- **У режимі RX High Gain**:
  - `S21_rx` (підсилення прийому): +15... +18 dB.
  - `NF_rx` (коефіцієнт шуму): 1.2... 1.8 dB.
  - `S11_ant` (вхідний коефіцієнт відбиття): менше -10 dB.
- **У режимі TX High Power**:
  - `S21_tx` (підсилення передачі): +25... +32 dB.
  - `P1dB_tx` (вихідна потужність компресії): +30 dBm (1 Вт).
  - `Isolation_tx_rx` (ізоляція між портом PA і виходом LNA): більше 38 dB.

### Практичні правила трасування на друкованій платі (PCB Layout)

Робота радіочастотного переднього модуля критично залежить від якості конструювання друкованої плати (PCB). Нехтування правилами ВЧ-трасування може перетворити підсилювач потужності на самозбуджуваний генератор або погіршити коефіцієнт шуму LNA на 3–5 dB.

#### 1. Розрахунок копланарних 50-омних ліній

Провідники ВЧ-портів (`ANT`, `TX_IN`, `RX_OUT`) повинні розраховуватися як мікросмужкові або копланарні хвилеводи із заземленим нижнім шаром (*Coplanar Waveguide with Ground*, CPWG) із фіксованим хвильовим опором 50 Ом. Ширина провідника `w` та зазор до бокового земляного полігону `s` розраховуються за формулами конформного відображення залежно від товщини діелектрика `h`, товщини міді `t` та діелектричної проникності матеріалу плати `ε_r` (наприклад, `ε_r = 4.2` для склотекстоліту FR-4 або `ε_r = 3.66` для високочастотного ламінату Rogers RO4350B).

Паразитні втрати в мікросмужковій лінії складаються з дисипативних втрат у діелектрику `α_d` та омічних втрат у провіднику `α_c`. На частотах понад 5 ГГц шорсткість поверхні мідного фольгування починає помітно збільшувати омічний опір через скін-ефект (глибина скін-шару у міді на частоті 2.4 ГГц становить лише 1.33 мкм). Для контактних площадок ВЧ-портів розробники використовують топологію NSMD (*Non-Solder Mask Defined*), де маска пайки розширена відносно мідного контактного п'ятака, що запобігає внеску паразитної ємності маски у хвильовий опір 50 Ом.

Уздовж усієї довжини копланарної лінії на відстані не більше `λ/10` один від одного розміщують заземлюючі Vias (Via Fence), які з'єднують верхній земляний полігон із внутрішнім шаром заземлення для екранування від бокових наводок.

#### 2. Матриця перехідних отворів заземлення (Ground Stitching) та тепловий розрахунок

Центральний вивід під корпусом мікросхеми (Exposed Pad, EPAD) виконує дві фундаментальні функції: відведення тепла від потужного транзистора PA та забезпечення низькоіндуктивного шляху повернення ВЧ-струмів на шар землі. Кожна паразитне індуктивність виводу заземлення `L_g` створює негативний зворотний зв'язок за напругою `V_g = L_g · (di/dt)`, що призводить до падіння вихідної потужності та деградації ККД. Індуктивність одного циліндричного отвору Via виражається формулою `L_via ≈ 0.2 · h · [ln(4·h / d) + 1] nH`, де `h` — висота отвору (товщина плати), `d` — діаметр отвору. Паралельне з'єднання 9 отворів Vias зменшує паразитну індуктивність заземлення до величин менше 0.05 нГн.

Плата під EPAD повинна мати сітку з 4–9 металізованих перехідних отворів (Vias) діаметром 0.2–0.3 мм, з'єднаних із суцільним внутрішнім шаром землі. Відсутність або недостатня кількість Vias під EPAD призводить до зростання індуктивності заземлення `L_g`, через що виникає паразитна негативна зворотний зв'язок у вихідному каскаді, падіння підсилення та тепловий перегрів кристала.

```
                   Топологія заземлення під EPAD
                   
                +---------------------------------+
                |   Корпус RF FEM (QFN / LGA)     |
                +---------------------------------+
                ===================================  <- Паяльний шар
                [via]  [via]  [via]  [via]  [via]    <- Металізовані Vias
                -----------------------------------  <- Внутрішній шар GND
```

Розрахунок теплового опору ланцюжка від напівпровідникового кристала до повітря визначається формулою:

```
R_th_total = R_th_jc + R_th_board + R_th_heatsink
```

де `R_th_jc` — тепловий опір кристал-корпус (вказаний у даташиті), а `R_th_board` — тепловий опір заземлюючих Vias на платі. Заповнення отворів Vias теплопровідним пастоподібним припоєм знижує `R_th_board` у 2–3 рази. При максимальній потужності PA (+30 dBm = 1 Вт) та ККД 50% споживана потужність постійного струму становить 2 Вт, а потужність теплових втрат `P_diss = 1 Вт`. При `R_th_total = 40 K/W` перегрів кристала відносно корпусу становитиме +40 °C. Рекомендовано застосовувати друковані плати з підвищеною товщиною мідного фольгування (2 oz / 70 мкм) для розтікання тепла по верхньому шару.

#### 3. Ієрархія фільтрації ліній живлення

Напруга живлення PA (`VCC_PA`) містить потужні імпульси струму радіочастоти. Для запобігання проникненню ВЧ-сигналу в загальну шину живлення біля кожної ніжки `VCC` встановлюють каскад із трьох паралельних конденсаторів різних номіналів:
1. **10 pF** (корпус 0201) — розташовується **найближче до виводів мікросхеми** (на відстані не більше 1 мм). Його власна резонансна частота відповідає робочій частоті ВЧ-сигналу (наприклад, 2.4 ГГц).
2. **100 nF** (корпус 0402) — фільтрує середньочастотні завади та шуми від імпульсних перетворювачів живлення.
3. **10 µF** (керамічний X7R, 0805 або танталовий) — слугує накопичувачем енергії для забезпечення пікових струмів під час передачі пакунків.

#### 4. Захист від електростатичних розрядів (ESD Protection) та екранування

Вивід `ANT` підключається безпосередньо до антени і є найбільш вразливим місцем пристрою до електростатичних розрядів (статична електрика людини, грозові наведення). Для захисту на лінії `ANT` розміщують надшвидкісний ESD-діод із малою власною ємністю (`C_esd < 0.3 pF`), щоб не розлаштовувати 50-омний імпеданс лінії. Вторинним способом захисту є включення короткозамкненого чвертьхвильового шлейфу (`λ/4` shorted stub), який представляє собою нескінченний опір для робочої частоти, але є короткою замкнутою стежкою на землю для низькочастотних імпульсів статики.

Для захисту від зовнішніх електромагнітних завад (наприклад, імпульсів процесора або цифрових шин SPI/I2C) на друкованій платі над блоком RF FEM монтують штампований металевий екран (RF Shielding Can). Зовнішній рамковий контакт екрана випаюють безперервно по контуру на суцільний полігон землі, що відсікає випромінювальні завади і гарантує виконання норм електромагнітної сумісності (EMC).

Послідовно у лінії `ANT`, `TX_IN` та `RX_OUT` обов'язково вмикають керамічні розділювальні конденсатори (DC Block) ємністю 10–47 pF. Вони відсікають постійну напругу зсуву внутрішніх транзисторів RF FEM від зовнішньої антени та виходу синтезатора.
