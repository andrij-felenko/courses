# 🧮 Математика ВЧ-підсилювачів: шуми за Фріісом та інтермодуляція IP3

Цей математичний розбір містить строге виведення формули Фрііса для каскадного коефіцієнта шуму, математичний аналіз еквівалентної шумової температури, розрахунок шуму атенюаторів та згасаючих ліній за довільних температур, розрахунок коефіцієнта якості G/T супутникових приймачів, аналіз залежності шумів від неузгодження імпедансів, температурну залежність шумів напівпровідників, а також покроковий алгебраїчний вивід виникнення продуктів інтермодуляції 3-го порядку (IMD3) та каскадного IIP3 у нелінійних ВЧ-підсилювачах.

---

### 1. Тепловий шум Джонсона-Найквіста та коефіцієнт шуму

Будь-який електричний провідник або резистор із опором `R`, що перебуває в стані термодинамічної рівноваги при абсолютній температурі `T` (у Кельвінах), генерує на своїх виводах флуктуаційну напругу теплового шуму. Відповідно до теореми Найквіста, середньоквадратичне значення шумової напруги в смузі частот `B` (Гц) виражається формулою:

```
V_noise_rms = √(4 · k · T · R · B)
```

де `k = 1.380649·10^-23 J/K` — стала Больцмана.

Крім теплового шуму, у напівпровідникових пристроях виникає дробовий шум (*Shot Noise*), викликаний випадковими флуктуаціями при проходженні носіїв заряду через потенціальний бар'єр p-n переходу. Його середньоквадратичний струм становить `I_shot_rms = √(2 · q · I_dc · B)`, де `q = 1.602·10^-19 C` — заряд електрона, а `I_dc` — постійний струм зсуву. У низькочастотній області додатково виникає флікер-шум ($1/f$ шум), зумовлений пастками на поверхні напівпровідника.

Якщо резистор із опором `R` підключити до узгодженого навантаження з опором `R_L = R`, то максимальна шумової потужність, яка передається в навантаження (доступна потужність шуму), не залежить від величини опору `R`:

```
P_noise_max = (V_noise_rms / 2)^2 / R
            = (4 · k · T · R · B / 4) / R    [підстановка V_noise_rms]
            = k · T · B                     [скорочення 4 і R]
```

За стандартної нормальної температури `T0 = 290 K` (близько 16.85 °C) спектральна щільність доступної потужності теплового шуму становить:

```
N0 = k · T0 = 1.380649·10^-23 J/K · 290 K = 4.004·10^-21 W/Hz
```

У логарифмічних одиницях (dBm/Hz):

```
N0_dBm = 10 · log10(4.004·10^-21 / 10^-3) = -173.98 dBm/Hz ≈ -174 dBm/Hz
```

#### Визначення лінійного коефіцієнта шуму (Noise Factor F)

Коефіцієнт шуму `F` чотириполюсника (підсилювача, фільтра чи змішувача) визначається як відношення співвідношення сигнал/шум на вході до співвідношення сигнал/шум на виході за умови, що вхідне навантаження має температуру `T0 = 290 K`:

```
F = (S_in / N_in) / (S_out / N_out)
```

Оскільки вихідна потужність корисного сигналу дорівнює `S_out = G · S_in` (де `G` — коефіцієнт підсилення за потужністю), вираз спрощується до:

```
F = N_out / (G · N_in) = N_out / (G · k · T0 · B)
```

Шум на виході реального підсилювача складається з двох компонентів: підсиленого вхідного шуму `G · N_in` та власного шуму підсилювача `N_added`, зведеного до його виходу:

```
N_out = G · N_in + N_added
```

Підставляючи вираз для `N_out` у формулу коефіцієнта шуму:

```
F = (G · N_in + N_added) / (G · N_in)
  = 1 + N_added / (G · k · T0 · B)    [почленне ділення на G·N_in]
```

У логарифмічному масштабі використовують **коефіцієнт шуму в децибелах** (*Noise Figure*, NF):

```
NF = 10 · log10(F)
```

#### Залежність коефіцієнта шуму від неузгодження імпедансу джерела

Залежність лінійного коефіцієнта шуму `F` від коефіцієнта відбиття джерела `Gamma_S` описується рівнянням термодинаміки транзистора:

```
F = F_min + 4 · r_n · |Gamma_S - Gamma_opt|^2 / ((1 - |Gamma_S|^2) · |1 + Gamma_opt|^2)
```

де `F_min` — мінімально можливий коефіцієнт шуму транзистора, `Gamma_opt` — оптимальний коефіцієнт відбиття джерела для шуму, а `r_n = R_n / 50` — нормований шумовий опір транзистора. На діаграмі Сміта ця формула задає родину концентричних **кіл рівного коефіцієнта шуму** (*Noise Circles*).

### 2. Математичне виведення формули Фрііса для каскадів

Розглянемо послідовне з'єднання двох підсилювальних каскадів:
- Каскад 1 має підсилення `G1`, власний шум на виході `N_added1` та коефіцієнт шуму `F1 = 1 + N_added1 / (G1 · k · T0 · B)`.
- Каскад 2 має підсилення `G2`, власний шум на виході `N_added2` та коефіцієнт шуму `F2 = 1 + N_added2 / (G2 · k · T0 · B)`.

З цих формул виразимо власні шуми кожного каскаду:

```
N_added1 = (F1 - 1) · G1 · k · T0 · B
N_added2 = (F2 - 1) · G2 · k · T0 · B
```

Тепер простежимо проходження шумів через усю двокаскадну систему. На вхід першого каскаду надходить шум джерела `N_in = k · T0 · B`.

Шум на виході першого каскаду:

```
N_out1 = G1 · N_in + N_added1
```

Цей шум потрапляє на вхід другого каскаду і підсилюється у `G2` разів. До нього додається власний шум другого каскаду `N_added2`:

```
N_out_sys = N_out1 · G2 + N_added2
          = (G1 · N_in + N_added1) · G2 + N_added2     [підстановка N_out1]
          = G1 · G2 · N_in + G2 · N_added1 + N_added2   [розкриття дужок]
```

Підставимо у цей вираз вирази для `N_added1` та `N_added2`:

```
N_out_sys = G1 · G2 · N_in + G2 · (F1 - 1) · G1 · N_in + (F2 - 1) · G2 · N_in       [підстановка N_added1, N_added2]
          = G1 · G2 · N_in · [1 + (F1 - 1) + (F2 - 1) / G1]                          [винесення спільного множника G1·G2·N_in]
          = G1 · G2 · N_in · [F1 + (F2 - 1) / G1]                                    [спрощення 1 + F1 - 1 = F1]
```

Загальний лінійний коефіцієнт шуму системи виражається як `F_sys = N_out_sys / (G_sys · N_in)`, де сумарне підсилення `G_sys = G1 · G2`:

```
F_sys = (G1 · G2 · N_in · [F1 + (F2 - 1) / G1]) / (G1 · G2 · N_in)                  [підстановка N_out_sys]
      = F1 + (F2 - 1) / G1                                                          [скорочення G1·G2·N_in]
```

Застосовуючи математичну індукцію для `N` послідовних каскадів, отримуємо **загальну формулу Фрііса**:

```
F_total = F1 + (F2 - 1)/G1 + (F3 - 1)/(G1·G2) + ... + (Fn - 1)/(G1·G2·...·Gn-1)
```

Математичний зміст формули Фрііса полягає у тому, що власний шум кожного наступного каскаду ділиться на сумарний коефіцієнт підсилення за потужністю усіх попередніх каскадів.

### 3. Еквівалентна шумової температура та шум атенюаторів

У чутливих НВЧ-системах (наприклад, у супутниковому зв'язку, радіоастрономії та радіолокації) замість `NF` зручніше оперувати **еквівалентною шумовою температурою** `Te` (у Кельвінах). Це температура уявного резистора на вході ідеального підсилювача без шумів, який генерує таку ж потужність шуму, як і власний шум реального підсилювача:

```
Te = T0 · (F - 1)
```

Звідси лінійний коефіцієнт шуму дорівнює:

```
F = 1 + Te / T0
```

У шумових температурах формула Фрііса набуває особливо прозорого вигляду:

```
Te_total = Te1 + Te2 / G1 + Te3 / (G1 · G2) + ...
```

#### Температурна залежність шумів гетероструктурних транзисторів

Зниження фізичної температури напівпровідникового кристала зменшує теплові флуктуації носіїв заряду. Для криогенних малошумних підсилювачів на GaAs pHEMT та InP HEMT еквівалентна шумова температура змінюється за степеневим законом:

```
Te(T) = Te0 · (T / T0)^gamma
```

де `gamma ≈ 1.5...1.8`. При охолодженні LNA до температури рідкого азоту (77 K) шумова температура знижується від `50 K` до `8 K`, що дозволяє досягати рекордного рівня чутливості у радіоастрономічних телескопах та станціях далекого космічного зв'язку.

#### Коефіцієнт шуму пасивних атенюаторів та кабелів

Розглянемо пасивний елемент із втратами (наприклад, коаксіальний кабель або атенюатор) із коефіцієнтом згасання `L` (`L > 1`, при цьому підсилення `G = 1/L`).

Якщо атенюатор перебуває за фізичної температури `T_a`, доступна потужність власного шуму атенюатора виражається як `N_added = k · T_a · B · (1 - 1/L)`.

Обчислимо лінійний коефіцієнт шуму атенюатора за довільної температури `T_a`:

```
F_att = 1 + N_added / (G · k · T0 · B)                                              [визначення F]
      = 1 + [k · T_a · B · (1 - 1/L)] / [(1/L) · k · T0 · B]                        [підстановка N_added та G=1/L]
      = 1 + (T_a / T0) · L · (1 - 1/L)                                              [скорочення k·B]
      = 1 + (T_a / T0) · (L - 1)                                                    [розкриття L·(1 - 1/L)]
```

Якщо фізична температура атенюатора дорівнює стандартній кімнатній температурі `T_a = T0 = 290 K`:

```
F_att = 1 + 1 · (L - 1) = L                                                         [підстановка T_a = T0]
```

**Фундаментальний висновок**: Лінійний коефіцієнт шуму пасивного згасаючого елемента за температури 290 K строго дорівнює його коефіцієнту згасання (`F_att = L`), а коефіцієнт шуму в децибелах дорівнює втратам у децибелах (`NF_att = Loss_dB`). Кабель із втратами 3 dB має `NF = 3 dB`.

#### Шум супутникової приймальної системи (Фактор якості G/T)

Для наземної супутникової станції загальна шумової температура системи виражається як:

```
T_sys = T_ant + T_line + L_line · T_lna
```

де `T_ant` — шумової температура антени (яка спрямована у холодне небо і може становити лише 20–50 K), `T_line = T0 · (L_line - 1)` — шумова температура кабелю зниження з коефіцієнтом згасання `L_line`, а `T_lna` — шумова температура МШУ. Якість всієї станції виражають коефіцієнтом якості `G/T = G_ant_dB - 10·log10(T_sys)`.

### 4. Математична модель нелінійностей, каскадний IIP3 та точка IP3

Вольт-амперну характеристику (ВАХ) активного елемента підсилювача (транзистора) у малосигнальному режимі можна розкласти у степеневий ряд Тейлора навколо робочої точки зсуву:

```
y(t) = a1 · x(t) + a2 · x^2(t) + a3 · x^3(t) + ...
```

де `x(t)` — вхідна напруга, `y(t)` — вихідний струм або напруга, `a1` — коефіцієнт лінійного підсилення, `a2` — коефіцієнт квадратичної нелінійності, `a3` — коефіцієнт кубічної нелінійності.

#### Вплив двотонового сигналу

Подамо на вхід підсилювача двотоновий сигнал із однаковими амплітудами `A` та близькими частотами `w1` та `w2`:

```
x(t) = A · cos(w1 · t) + A · cos(w2 · t)
```

Розглянемо внесок кожного члена ряду Тейлора у вихідний спектр `y(t)`.

##### 1. Лінійний член `a1 · x(t)`
Дає корисні вихідні сигнали на основних частотах:

```
y1(t) = a1 · A · [cos(w1 · t) + cos(w2 · t)]
```

##### 2. Квадратичний член `a2 · x^2(t)`
Застосовуючи тригонометричні тотожності `cos^2(α) = (1 + cos(2α))/2` та `2·cos(α)·cos(β) = cos(α-β) + cos(α+β)`:

```
x^2(t) = A^2 · [cos(w1·t) + cos(w2·t)]^2                                            [квадрат суми]
       = A^2 · [cos^2(w1·t) + 2·cos(w1·t)·cos(w2·t) + cos^2(w2·t)]                  [розкриття дужок]
       = A^2 · [1 + (1/2)·cos(2·w1·t) + (1/2)·cos(2·w2·t) + cos((w1-w2)·t) + cos((w1+w2)·t)]  [тригонометричні тотожності]
```

Квадратична нелінійність породжує постійну складову (DC bias shift), другі гармоніки `2·w1`, `2·w2` та комбінаційні частоти 2-го порядку `w1 - w2` і `w1 + w2`. Усі ці частоти розташовані далеко від робочої смуги `w1, w2` і легко відфільтровуються.

##### 3. Кубічний член `a3 · x^3(t)`
Розкриваємо куб суми двох косинусів:

```
[cos(w1·t) + cos(w2·t)]^3 = cos^3(w1·t) + 3·cos^2(w1·t)·cos(w2·t) + 3·cos(w1·t)·cos^2(w2·t) + cos^3(w2·t)   [куб суми]
```

Використовуючи тотожність `cos^2(α)·cos(β) = (1/2)·cos(β) + (1/4)·[cos(2α - β) + cos(2α + β)]`, виділимо непарні складові. Кубічний член породжує:
- Підсилення на основних частотах: `(9/4) · a3 · A^3 · [cos(w1·t) + cos(w2·t)]` (викликає компресію підсилення, бо `a3 < 0`).
- Треті гармоніки: `(1/4) · a3 · A^3 · [cos(3·w1·t) + cos(3·w2·t)]`.
- **Продукти інтермодуляції 3-го порядку (IMD3)**:

```
y_IMD3(t) = (3/4) · a3 · A^3 · [cos((2·w1 - w2) · t) + cos((2·w2 - w1) · t)]
```

#### Розрахунок точки перетину 3-го порядку (IP3)

Порівняємо амплітуди вихідних сигналів залежно від вхідної амплітуди `A`:
- Амплітуда основного сигналу: `V_fund = a1 · A` (зростає лінійно з нахилом 1:1 в логарифмічному масштабі).
- Амплітуда продукту IMD3: `V_IMD3 = (3/4) · |a3| · A^3` (зростає кубічно з нахилом 3:1 в логарифмічному масштабі).

У точці перетину екстраполяцій (IP3) амплітуди вихідних сигналів зрівнялися б: `V_fund = V_IMD3`.

```
a1 · A_IP3 = (3/4) · |a3| · A_IP3^3                                                [рівність амплітуд]
A_IP3^2 = (4/3) · (a1 / |a3|)                                                      [ділення на A_IP3 та a3]
```

Переведемо ці співвідношення у вирази для вхідної потужності `IIP3` (в dBm). Для довільного вхідного рівня потужності `P_in` (в dBm) та виміряної потужності основного сигналу `P_fund` і продукту інтермодуляції `P_IMD3`:

```
P_fund = P_in + G                                                                   [лінійне підсилення]
P_IMD3 = 3 · P_in + G_IM3                                                           [кубічний нахил 3:1]
```

Різниця потужностей у децибелах (придушення IMD3):

```
ΔP_IMD3 = P_fund - P_IMD3
        = (P_in + G) - (3 · P_in + G_IM3)                                           [підстановка P_fund, P_IMD3]
        = G - G_IM3 - 2 · P_in                                                      [зведення подібних]
```

У точці `P_in = IIP3` придушення прямує до 0 dB (`ΔP_IMD3 = 0`):

```
0 = G - G_IM3 - 2 · IIP3  =>  2 · IIP3 = G - G_IM3                                  [умова IP3]
```

Віднімаючи цей вираз від виразу для `ΔP_IMD3`, отримуємо **практичну формулу для IIP3**:

```
ΔP_IMD3 = 2 · (IIP3 - P_in)                                                         [різниця точок]
IIP3 = P_in + ΔP_IMD3 / 2                                                           [вираження IIP3]
```

А вихідна точка перетину:

```
OIP3 = IIP3 + G = P_fund + ΔP_IMD3 / 2
```

#### Каскадне обчислення IIP3 для системи підсилювачів

На відміну від формули Фрііса для шумів, де перший каскад є панівним, для підсумкової лінійності системи (IIP3) вирішальним є **останній каскад**, оскільки на нього припадають найбільші амплітуди сигналів. Загальна вхідна точка перетину 3-го порядку двокаскадної системи виражається формулою складання нелінійностей:

```
1 / IIP3_sys_linear^2 = 1 / IIP3_1_linear^2 + G1_linear^2 / IIP3_2_linear^2
```

де `IIP3_linear` — значення точки перетину в міліватах (лінійний масштаб). Якщо перший каскад (LNA) має високе підсилення `G1`, він розганяє амплітуду сигналу на вході другого каскаду (змішувача), що різко знижує підсумкову лінійність `IIP3_sys`. Це становить головний системний конфлікт: високе підсилення LNA покращує коефіцієнт шуму `NF_sys`, але погіршує лінійність `IIP3_sys`.

#### Розрахунок вільного від інтермодуляції динамічного діапазону (SFDR)

**Динамічний діапазон, вільний від завад інтермодуляції** (*Spurious-Free Dynamic Range*, SFDR), визначає діапазон вхідних потужностей від шумового порогу `N_floor = k · T0 · B · F` до рівня, при якому продукти IMD3 зрівнюються з рівнем шуму:

```
SFDR = (2/3) · (IIP3 - N_floor)
```

Де `SFDR` вимірюється в dB, а `IIP3` та `N_floor` — в dBm. Цей параметр є головним критерієм якості радіоприймачів, що працюють у складній завадовій обстановці.

Зв'язок між точкою компресії `P1dB` та вхідною точкою `IIP3` для типового транзисторного каскаду з кубічною нелінійністю виражається теоретичним співвідношенням:

```
IIP3 ≈ P1dB_in + 9.6 dB
```

Ця формула дозволяє швидко оцінити лінійність підсилювача за даташитом, де часто вказано лише параметр `P1dB`.

#### Числовий приклад розрахунку SFDR для каналу 5G

Обчислимо динамічний діапазон приймача 5G зі смугою каналу `B = 100 MHz` (`10^8 Hz`), коефіцієнтом шуму `NF = 2.5 dB` (`F = 1.778`) та вхідною точкою перетину `IIP3 = +5 dBm`.

1. Розрахуємо шумові пороги:
```
N_floor_mW = k · T0 · B · F
           = 1.38·10^-23 · 290 · 10^8 · 1.778 = 7.11·10^-13 W = 7.11·10^-10 mW
```
У децибелах:
```
N_floor_dBm = -174 + 10·log10(10^8) + 2.5 = -174 + 80 + 2.5 = -91.5 dBm
```

2. Обчислимо динамічний діапазон SFDR:
```
SFDR = (2/3) · (IIP3 - N_floor)                             [визначення SFDR]
     = (2/3) · (5 - (-91.5))                                [підстановка IIP3=5 та N_floor=-91.5]
     = (2/3) · 96.5                                         [обчислення 5 - (-91.5)]
     = 64.33 dB                                             [множення 96.5 на 2/3]
```

**Висновок**: Приймач здатний одночасно приймати корисні слабкі сигнали на межі чутливості −91.5 dBm та витримувати завади потужністю до `P_in = -91.5 + 64.33 = -27.17 dBm` без виникнення інтермодуляційних завад вище шумового порогу.
