# 🧮 Математика нелінійного змішування, комбінаційних частот та IP3

Ця вставка містить математичний апарат розкладу нелінійних функцій перетворення, математичне виведення побічних комбінаційних частот, теорію спотворень вищих порядків, а також методи розрахунку коефіцієнтів інтермодуляції другого і третього порядків та динамічного діапазону змішувача.

---

### Тейлорівський розклад нелінійної ВАХ

Будь-який нелінійний напівпровідниковий двополюсник (діод Шотткі чи p-n перехід) описується показниковою вольт-амперною характеристикою Шокли:
```
I(V) = I_s · [ exp(q·V / (η·k·T)) − 1 ]
```
При роботі з сигналом малого або помірного рівня навколо статичної точки спокою `V_0` функцію струму `I(V)` розкладають у ряд Тейлора за ступенями приросту напруги `v(t)`:

```
I(v) = I_0 + a_1 · v(t) + a_2 · v²(t) + a_3 · v³(t) + a_4 · v⁴(t) + a_5 · v⁵(t) + ...

де коефіцієнти Тейлора дорівнюють похідним ВАХ у точці спокою:
a_1 = dI / dV |_(V=V_0)         [лінійна крутизна, См]
a_2 = ½ · d²I / dV² |_(V=V_0)     [квадратична нелінійність]
a_3 = ⅙ · d³I / dV³ |_(V=V_0)     [кубічна нелінійність]
a_4 = (1/24) · d⁴I / dV⁴ |_(V=V_0) [нелінійність 4-го порядку]
a_5 = (1/120) · d⁵I / dV⁵ |_(V=V_0) [нелінійність 5-го порядку]
```

Якщо на вхід діода подається сума двох синусоїдальних напруг — ВЧ-сигналу `v_RF(t) = V_RF · cos(ω_RF · t)` та гетеродина `v_LO(t) = V_LO · cos(ω_LO · t)`:
```
v(t) = V_RF · cos(ω_RF · t) + V_LO · cos(ω_LO · t)
```

#### Математичний розбір квадратичного члена `a_2 · v²(t)`
Піднесемо суму двох сигналів до квадрата:
```
v²(t) = [ V_RF · cos(ω_RF · t) + V_LO · cos(ω_LO · t) ]²
      = V_RF² · cos²(ω_RF · t) + 2 · V_RF · V_LO · cos(ω_RF · t) · cos(ω_LO · t) + V_LO² · cos²(ω_LO · t)
```

Застосуємо фундаментальні тригонометричні тотожності пониження степеня та добутку косинусів:
```
cos²(α) = ½ + ½ · cos(2α)
cos(α) · cos(β) = ½ · cos(α − β) + ½ · cos(α + β)

Тоді квадратичний доданок струму дорівнює:
I_2(t) = a_2 · ½ · V_RF² · [1 + cos(2·ω_RF·t)]        [постійна складова та 2-га гармоніка RF]
       + a_2 · ½ · V_LO² · [1 + cos(2·ω_LO·t)]        [постійна складова та 2-га гармоніка LO]
       + a_2 · V_RF · V_LO · cos((ω_RF − ω_LO)·t)     [корисна різницева частота ПЧ]
       + a_2 · V_RF · V_LO · cos((ω_RF + ω_LO)·t)     [сумарна частота]
```
Саме перехресний член `a_2 · V_RF · V_LO · cos((ω_RF − ω_LO)·t)` створює корисний сигнал проміжної частоти `f_IF = |f_RF − f_LO|`.

### Інтермодуляція другого порядку (IMD2) та IIP2 у Zero-IF

Окрім корисного змішування, квадратичний член `a_2 · v²(t)` створює небезпечне явище для приймачів прямого перетворення (Zero-IF). Якщо на вхід потрапляють дві високочастотні завади `f_1` та `f_2`, квадаратична нелінійність породжує низкочастотний різницевий продукт:
```
f_IMD2 = |f_1 − f_2|
```
Якщо дві завади на 2.400 ГГц та 2.401 ГГц мають різницю 1 МГц, ця різницева частота 1 МГц потрапляє безпосередньо у смугу проміжної частоти приймача Zero-IF, не залежно від частоти гетеродина `f_LO`.

Стійкість змішувача до цього ефекту характеризується точкою перехоплення другого порядку `IIP2` (Input Intercept Point 2). У подвійно-балансних змішувачах інтермодуляція IMD2 теоретично відсутня через симетрію, але практично виникає через асиметрію діодів і характеризується значеннями `IIP2 = +40 ... +70 дБм`.

### Походження продуктів інтермодуляції 3-го та 5-го порядків (IMD3 / IMD5)

Розглянемо видок кубічного члена ряду Тейлора `a_3 · v³(t)`. Нехай на вхід змішувача разом із гетеродином потрапляють два близькі завадові сигнали `v_1(t) = V_1 · cos(ω_1 · t)` та `v_2(t) = V_2 · cos(ω_2 · t)`.

Піднесення суми трьох сигналів до куба за формулою Ньютона виділяє перехресні члени вида `3 · V_1² · V_2 · cos²(ω_1 · t) · cos(ω_2 · t)`:

```
cos²(ω_1 · t) · cos(ω_2 · t)
= [ ½ + ½ · cos(2·ω_1·t) ] · cos(ω_2 · t)
= ½ · cos(ω_2 · t) + ¼ · cos((2·ω_1 − ω_2) · t) + ¼ · cos((2·ω_1 + ω_2) · t)
```

Компоненти із частотами `2·f_1 − f_2` та `2·f_2 − f_1` називаються **продуктами інтермодуляції третього порядку (IMD3)**.

**Головна інженерна небезпека:** якщо частоти двох завад `f_1 = 2400 МГц` та `f_2 = 2401 МГц` розташовані поряд із корисним каналом, продукты IMD3 виникають на частотах:
```
f_IMD3_a = 2 · 2400 − 2401 = 2399 МГц
f_IMD3_b = 2 · 2401 − 2400 = 2402 МГц
```
Ці побічні частоти лягають у корисну смугу сусідніх каналів і не піддаються фільтрації на вході.

При подальшому зростанні вхідної потужності починає проявлятися член 5-го порядку `a_5 · v⁵(t)`, який породжує продукти інтермодуляції 5-го порядку (IMD5) вида `3·f_1 − 2·f_2` та `3·f_2 − 2·f_1`. Їхня потужність зростає пропорційно 5-й ступені вхідного сигналу (нахил 5:1 у дБм-масштабі).

### Математичний вивід точки компресії P_1dB та точки перехоплення IP3

Розглянемо випадок подачі одного тону `v(t) = V_in · cos(ω · t)` на ВАХ з урахуванням кубічної нелінійності:
```
I(t) = a_1 · V_in · cos(ω·t) + a_3 · V_in³ · cos³(ω·t)
```
Використовуючи тригонометричну тотожність `cos³(α) = ¾ · cos(α) + ¼ · cos(3α)`:
```
I(t) = ( a_1 · V_in + ¾ · a_3 · V_in³ ) · cos(ω·t) + ¼ · a_3 · V_in³ · cos(3·ω·t)
```
Оскільки для більшості реальних напівпровідникових структур коефіцієнт `a_3` є негативним (`a_3 < 0`), зі зростанням вхідного сигналу `V_in` кубічний член зменшує загальну амплітуду першої гармоніки.

#### Вивід точки компресії 1 дБ (P_1dB)
Точка компресії 1 дБ відповідає амплітуді `V_1dB`, при якій коефіцієнт підсилення зменшується на 1 дБ (що відповідає відношенню амплітуд `10^(−1/20) ≈ 0.891`):

```
( a_1 · V_1dB + ¾ · a_3 · V_1dB³ ) / ( a_1 · V_1dB ) = 0.891
1 + ¾ · (a_3 / a_1) · V_1dB² = 0.891
¾ · |a_3 / a_1| · V_1dB² = 0.109
V_1dB² = 0.145 · |a_1 / a_3|
V_1dB = 0.381 · √( |a_1 / a_3| )
```

#### Вивід точки перехоплення IP3 (IIP3)
Точка IIP3 виводиться з рівності амплітуди основної частоти `a_1 · V_in` та амплітуди продукту IMD3 `¾ · a_3 · V_in³`:
```
a_1 · V_IP3 = ¾ · |a_3| · V_IP3³
V_IP3² = ⁴/₃ · |a_1 / a_3|
V_IP3 = √( ⁴/₃ · |a_1 / a_3| ) = 1.155 · √( |a_1 / a_3| )
```

Порівнюючи значення `V_1dB` та `V_IP3`, отримуємо теоретичне співвідношення між точкою компресії та точкою перехоплення:
```
V_IP3 / V_1dB = 1.155 / 0.381 ≈ 3.03
P_IP3 (дБм) − P_1dB (дБм) = 20 · log₁₀(3.03) ≈ +9.6 дБ
```
У реальних змішувачах із урахуванням вищих нелінійностей різниця `IIP3 − P_1dB` становить від 10 до 12 дБ.

### Обчислювальний приклад каскадного IIP3 та шуму за формулою Фрііса

У радіочастотному тракті змішувач стоїть після малошумного підсилювача (LNA). Для розрахунку загальної лінійності системи використовується каскадна формула Фрііса для IP3:

```
1 / IIP3_total = 1 / IIP3_LNA + G_LNA / IIP3_Mixer
```
де `IIP3_LNA` та `IIP3_Mixer` виражені у разів (Ватт), а `G_LNA` — коефіцієнт підсилення LNA у разів.

#### Практична задача
**Дані:**
- LNA має підсилення `G_LNA = +15 дБ` (31.6 разів) та `IIP3_LNA = +5 дБм` (3.16 мВт).
- Змішувач має `IIP3_Mixer = +15 дБм` (31.6 мВт).

**Обчислення каскадного IIP3:**
1. Переведення дБм у мВт:
   ```
   IIP3_LNA = 10^(5/10) = 3.16 мВт
   IIP3_Mixer = 10^(15/10) = 31.6 мВт
   G_LNA = 10^(15/10) = 31.6 разів
   ```
2. Розрахунок каскадної величини за формулою Фрііса:
   ```
   1 / IIP3_total = (1 / 3.16) + (31.6 / 31.6)
                  = 0.316 + 1.0 = 1.316 (1/мВт)
   IIP3_total = 1 / 1.316 = 0.76 мВт
   ```
3. Переведення назад у дБм:
   ```
   IIP3_total (дБм) = 10 · log₁₀(0.76) = -1.2 дБм
   ```

**Висновок:** Високе підсилення LNA (15 дБ) різко погіршує загальну лінійність тракту (з +5 дБм до -1.2 дБм), оскільки змішувач отримує підсилений сигнал і швидше входить у нелінійний режим.

### Коефіцієнт шуму SSB та DSB

Для змішувачів розрізняють два визначення коефіцієнта шуму:

1. **Односмуговий коефіцієнт шуму (SSB Noise Figure, `NF_SSB`):** застосовується у супергетеродинах, де дзеркальний канал відфільтровано на вході. Приймач приймає шум із двох смуг (корисної та дзеркальної), але сигнал — лише з однієї. Тому:
   ```
   NF_SSB (дБ) = L_c (дБ) + 3 дБ   (для пасивного змішувача)
   ```
2. **Двосмуговий коефіцієнт шуму (DSB Noise Figure, `NF_DSB`):** застосовується у радіоастрономії та прямому перетворенні (Zero-IF), де корисний сигнал присутній в обох смугах відносно гетеродина.
   ```
   NF_DSB (дБ) = NF_SSB (дБ) − 3 дБ
   ```

### Динамічний діапазон, вільний від побічних складових (SFDR)

Вільний від побічних складових динамічний діапазон (англ. *Spurious-Free Dynamic Range*, SFDR) визначає діапазон вхідних потужностей від рівня власних теплових шумів `N_0` до рівня, при якому продукти IMD3 порівнюються з шумами.

Формула розрахунку SFDR виводиться з геометричного співвідношення трикутника на графіку нелінійності:
```
SFDR (дБ) = ⅔ · ( IIP3 (дБм) − N_0 (дБм) )
```

**Приклад:** Для змішувача з `IIP3 = +15 дБм` та рівнем шумів у смузі `N_0 = -105 дБм`:
```
SFDR = ⅔ · ( 15 − (-105) ) = ⅔ · 120 = 80 дБ
```
Це означає, що змішувач здатний приймати корисний сигнал у присутності завад, що перевищують шум на 80 дБ, без ризику хибного детектування продуктів нелінійності.
