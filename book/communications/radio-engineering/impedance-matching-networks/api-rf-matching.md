# 📋 Довідник формул та параметрів узгодження ВЧ-трактів

Цей довідник містить зведені закриті формули, аналітичні рівняння та довідкові параметри для інженерного розрахунку узгоджувальних кіл радіочастотних трактив. Матеріал структуровано за топологіями (L, Pi, T, λ/4, шлейфи) для швидкого підбору номіналів у практичному розрахунку.

Довідник призначений для радіочастотних інженерів, розробників друкованих плат та програмістів, які створюють засоби автоматизованого синтезу ВЧ-компонентів чи прошивки для цифрових антенних тюнерів. Докладний математичний вивід усіх викладених співвідношень наведено у теоретичному матеріалі про [математику узгоджувальних кіл та L-ланок](book:communications/impedance-matching-networks/math-l-network.md), а порівняння параметрів компонентного базису — у розборі [схемотехніки та порівняння топологій узгодження](book:communications/impedance-matching-networks/comp-matching-topologies.md).

### 1. Формули розрахунку L-подібних ланок (Усі 8 топологій)

Позначення та базові величини:
- `R_S` — активний опір джерела сигналу (Ом).
- `R_L` — активний опір навантаження (Ом).
- `R_high = max(R_S, R_L)` — більший з двох активних опорів.
- `R_low = min(R_S, R_L)` — менший з двох активних опорів.
- `Q = √((R_high / R_low) - 1)` — нагружена добротність ланки.
- `ω₀ = 2π · f₀` — кругова робоча частота (рад/с).

Процедура розрахунку L-ланки завжди починається з порівняння значення `R_S` та `R_L`. Головне правило підключення полягає в тому, що **паралельний реактивний елемент обов'язково підключається до сторони з більшим опором `R_high`**. Якщо зхтувати цим правилом, розраховані значення реактивних опорів стануть уявними числами, що свідчить про фізичну неможливість узгодження даною топологією.

#### Група 1: Понижувальні ланки (`R_S > R_L`)
*Паралельний елемент підключається до джерела `R_S`, послідовний — до навантаження `R_L`.*

1. **ФНЧ Понижувальний (Low-Pass Step-Down):**
   Використовується, коли джерело має високий опір, і потрібно придушити вищі гармоніки.
   - Паралельний конденсатор: `C_p = Q / (ω₀ · R_S)`
   - Послідовна індуктивність: `L_s = (Q · R_L) / ω₀`

2. **ФВЧ Понижувальний (High-Pass Step-Down):**
   Застосовується для гальванічного відсікання постійного струму та придушення низькочастотних завад.
   - Паралельна індуктивність: `L_p = R_S / (ω₀ · Q)`
   - Послідовний конденсатор: `C_s = 1 / (ω₀ · Q · R_L)`

#### Група 2: Підвищувальні ланки (`R_S < R_L`)
*Послідовний елемент підключається до джерела `R_S`, паралельний — до навантаження `R_L`.*

3. **ФНЧ Підвищувальний (Low-Pass Step-Up):**
   Стандартна конфігурація для виходу транзисторного підсилювача потужності (наприклад, 10 Ом у 50 Ом).
   - Послідовна індуктивність: `L_s = (Q · R_S) / ω₀`
   - Паралельний конденсатор: `C_p = Q / (ω₀ · R_L)`

4. **ФВЧ Підвищувальний (High-Pass Step-Up):**
   Застосовується у малошумних вхідних каскадах із ємнісною розв'язкою.
   - Послідовний конденсатор: `C_s = 1 / (ω₀ · Q · R_S)`
   - Паралельна індуктивність: `L_p = R_L / (ω₀ · Q)`

#### Група 3: Узгодження комплексних опорів `Z_S = R_S + jX_S` та `Z_L = R_L + jX_L`

Для узгодження комплексних опорів спершу обчислюють номінали `L_calc` та `C_calc` для чисто активних складових `R_S` та `R_L`, після чого компенсують власні реактивності джерела та навантаження шляхом додавання відповідних реактивних опорів зі зворотним знаком:

- **Послідовна компенсація:** `X_L_final = X_L_calc - X_series_parasitic`
- **Паралельна компенсація:** `B_C_final = B_C_calc - B_parallel_parasitic`

Якщо власна індуктивність навантаження більша за розраховану `X_L_calc`, послідовний елемент змінює знак і перетворюється на конденсатор відповідного номіналу.

### 2. Формули розрахунку триелементних кіл (Pi та T ланки)

Триелементні кола дають розробнику додатковий ступінь свободи: можливість незалежно обирати нагружену добротність `Q_node` і регулювати смугу пропускання фільтра.

#### П-подібна ланка (Pi-Network)

Задано: `R_S`, `R_L`, бажана добротність першого вузла `Q_node1`. При розрахунку необхідно враховувати обмеження: `Q_node1` мусить бути більшою за мінімальну добротність L-ланки `Q_min = √((R_high / R_low) - 1)`.

1. Обчислення віртуального проміжного опору `R_v`:
   ```
   R_v = R_S / (1 + Q_node1²)
   ```
2. Обчислення добротності другого вузла `Q_node2`:
   ```
   Q_node2 = √((R_L / R_v) - 1)
   ```
3. Обчислення номіналів елементів для ФНЧ-версії:
   ```
   C1 = Q_node1 / (ω₀ · R_S)
   C2 = Q_node2 / (ω₀ · R_L)
   L = (R_v · (Q_node1 + Q_node2)) / ω₀
   ```

П-подібна ланка забезпечує чудове придушення 2-ї та 3-ї вищих гармонік у підсилювачах потужності завдяки наявності двох шунтувальних ємностей.

#### Т-подібна ланка (T-Network)

Задано: `R_S`, `R_L`, бажана добротність вузла `Q_node1`.

1. Обчислення віртуального проміжного опору `R_v`:
   ```
   R_v = R_low · (1 + Q_node1²)
   ```
2. Обчислення добротності другого вузла `Q_node2`:
   ```
   Q_node2 = √((R_v / R_high) - 1)
   ```
3. Обчислення номіналів елементів для ФВЧ-версії:
   ```
   C1 = 1 / (ω₀ · Q_node1 · R_S)
   C2 = 1 / (ω₀ · Q_node2 · R_L)
   L = R_v / (ω₀ · (Q_node1 + Q_node2))
   ```

Т-подібна ланка є ідеальною для узгодження джерел із дуже низьким активним опором та забезпечення надійного гальванічного відсікання постійного струму живлення.

### 3. Формули розподілених узгоджувальних кіл

На частотах вище 1 ГГц пасивні узгоджувальні кола реалізують у вигляді відрізків мікросмужкових ліній та шлейфів на друкованій платі. Вони характеризуються відсутністю дискретних компонентів та нульовою вартістю виробництва у серійному випуску.

#### Чвертьхвильовий трансформатор (`λ/4`)

1. Хвильовий опір лінії трансформатора:
   ```
   Z_m = √(Z_S · Z_L)
   ```
2. Фізична довжина лінії на друкованій платі з урахуванням укорочення хвилі у диелектрику:
   ```
   l = c / (4 · f₀ · √ε_eff)
   ```
   де `c = 2.9979 · 10⁸ м/с`, `ε_eff` — ефективна діелектрична проникність мікросмужкової лінії.

#### Шлейфове узгодження (Single-Stub Matching)

1. Відстань `d` від навантаження до точки підключення шлейфу (для нормованої провідності `y_L = g_L + jb_L`):
   ```
   d = (λ / 2π) · arctan(√((1 - g_L) / g_L))   при g_L < 1
   ```
2. Довжина короткозамкненого шлейфу `l_stub`:
   ```
   l_stub = (λ / 2π) · arctan(1 / b_stub)
   ```
3. Довжина розімкненого шлейфу `l_stub`:
   ```
   l_stub = (λ / 2π) · arccot(-1 / b_stub)
   ```

### 4. Компенсація паразитичних параметрів конструктиву

При практичному розрахунку розраховані номінали елементів необхідно коригувати з урахуванням геометричних паразитів контактних площадок, доріжок плати та скінченної добротності котушок. Докладний розбір інженерних рішень та калькулятор для автоматизації цього процесу наведено у проєктуванні [калькулятора та симулятора узгоджувальних кіл](book:communications/impedance-matching-networks/proj-l-network-calc.md).

| Паразитичний параметр | Формула корекції розрахованого номіналу | Практичні інженерні рекомендації |
|---|---|---|
| **Ємність контактної площадки `C_pad`** | `C_actual = C_calc - C_pad` | Зменшити розраховану ємність `C` на `0.15..0.25 пФ` для корпусу 0402 |
| **Індуктивність ВЧ-доріжки `L_trace`** | `L_actual = L_calc - L_trace` | Відняти `0.8 нГн` на кожен міліметр підвідної мікросмужкової лінії |
| **Активний опір втрат котушки `R_ESR`** | `R_ESR = (2πf₀ · L) / Q_L` | Обирати котушки з `Q_L ≥ 50` для мінімізації внесеного згасання |
| **Паразитна ємність виводів `C_par`** | `f_SRF = 1 / (2π √(L · C_par))` | Переконатися, що робоча частота `f₀ < 0.5 · f_SRF` |

Враховуючи, що індуктивність доріжки `L_trace ≈ 0.8 нГн/мм` порівнянна з номіналами ВЧ-котушок (які часто становлять від 2 до 10 нГн на частотах біля 1..2 ГГц), нехтування довжиною підвідних доріжок призводить до суттєвого виходу КСХ за межі допустимої норми. Кожен додатковий міліметр доріжки між котушкою та ємністю збільшує еквівалентну індуктивність кола та зміщує резонансну частоту донизу.

### 5. Довідкові коефіцієнти зв'язку між КСХ, |S₁₁| та Return Loss

Для вимірювання якості узгодження радіочастотних трактив застосовують три еквівалентні величини: коефіцієнт відбиття `|S₁₁|` (або `Γ`), коефіцієнт стоячої хвилі `КСХ` (VSWR) та зворотні втрати `Return Loss` (RL).

Формули математичного перерахунку між величинами:

```
|S₁₁| = Γ = (VSWR - 1) / (VSWR + 1)

VSWR = (1 + |S₁₁|) / (1 - |S₁₁|)

Return Loss (дБ) = -20 · log₁₀(|S₁₁|)

Mismatch Loss (дБ) = -10 · log₁₀(1 - |S₁₁|²)
```

Нижче наведено зведену довідкову таблицю переведення значення КСХ у параметри відбиття потужності та втрати неузгодження:

| КСХ (VSWR) | Коефіцієнт відбиття `|S₁₁|` | Зворотні втрати Return Loss (дБ) | Відбита потужність (%) | Втрата на неузгодженні (дБ) |
|---|---|---|---|---|
| **1.00** | 0.000 | ∞ | 0.00% | 0.00 дБ |
| **1.05** | 0.024 | 32.3 дБ | 0.06% | 0.003 дБ |
| **1.15** | 0.070 | 23.1 дБ | 0.49% | 0.021 дБ |
| **1.20** | 0.091 | 20.8 дБ | 0.83% | 0.036 дБ |
| **1.35** | 0.149 | 16.5 дБ | 2.22% | 0.098 дБ |
| **1.50** | 0.200 | 14.0 дБ | 4.00% | 0.177 дБ |
| **2.00** | 0.333 | 9.54 дБ | 11.11% | 0.512 дБ |
| **3.00** | 0.500 | 6.02 дБ | 25.00% | 1.249 дБ |
| **5.00** | 0.667 | 3.52 дБ | 44.44% | 2.553 дБ |

Практичне інженерне правило свідчить: значення `КСХ ≤ 1.5` (що відповідає `|S₁₁| ≤ -14 дБ` та відбиттю не більше 4% потужності) є цілком достатнім для 95% усіх комерційних радіочастотних пристроїв. Прагнення досягти `КСХ = 1.05` чи краще зазвичай вимагає застосування прецизійних підлаштувальних елементів і не виправдовує доданої вартості схеми.
