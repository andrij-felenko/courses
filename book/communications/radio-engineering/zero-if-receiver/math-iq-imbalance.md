# 🧮 Математичний аналіз I/Q дисбалансу та дзеркального приглушення

Цей математичний розбір виводить кількісну залежність коефіцієнта приглушення дзеркального каналу (IRR) від фазового та амплітудного розбалансу квадратурних віток I/Q, а також детально аналізує математику протікання гетеродина та виникнення постійної складової (DC offset) у приймачах прямого перетворення.

### Модель аналогового радіосигналу та квадратурний перенос

Будь-який модульований високочастотний радіосигнал у вузькій смузі довкола несучої частоти `w_0` описується за допомогою синфазної `I(t)` (In-phase) та квадратурної `Q(t)` (Quadrature) обвідних. Математично радіосигнал на вході приймача записується у вигляді комбінації тригонометричних функцій:

```
r(t) = I(t) · cos(w_0 · t) − Q(t) · sin(w_0 · t)
```

У приймачі прямого перетворення (Zero-IF) локальний гетеродин генерує два квадратурних опорних коливання з тією ж частотою `w_0`. Удеальному теоретичному випадку амплітуди обох віток дорівнюють одиниці, а фазовий зсув між ними становить точно 90 градусів (тобто `π/2` радіан):

```
LO_I(t) = cos(w_0 · t)
LO_Q(t) = −sin(w_0 · t)
```

Перемножуючи вхідний сигнал `r(t)` з ідеальними сигналами гетеродина у відповідних змішувачах I та Q та пропускаючи результат через аналоговий фільтр низьких частот (LPF), що відтинає високочастотні компоненти на подвоєній несучій частоті `2 · w_0`, отримуємо чисті компоненти базової смуги. Простежимо математику перетворення для синфазної та квадратурної віток крок за кроком:

```
y_I(t) = LPF{ r(t) · LO_I(t) }
       = LPF{ [I(t)·cos(w_0·t) − Q(t)·sin(w_0·t)] · cos(w_0·t) }
       = LPF{ I(t)·cos²(w_0·t) − Q(t)·sin(w_0·t)·cos(w_0·t) }
       = LPF{ I(t)·½·[1 + cos(2w_0·t)] − Q(t)·½·sin(2w_0·t) }
       = ½ · I(t)                                              [фільтрація 2w_0]

y_Q(t) = LPF{ r(t) · LO_Q(t) }
       = LPF{ [I(t)·cos(w_0·t) − Q(t)·sin(w_0·t)] · (−sin(w_0·t)) }
       = LPF{ −I(t)·sin(w_0·t)·cos(w_0·t) + Q(t)·sin²(w_0·t) }
       = LPF{ −I(t)·½·sin(2w_0·t) + Q(t)·½·[1 − cos(2w_0·t)] }
       = ½ · Q(t)                                              [фільтрація 2w_0]
```

Таким чином, у разі абсолютної ортогональності гетеродинних синусоїд та рівності підсилення віток вихідні канали `y_I(t)` та `y_Q(t)` точно відновлюють первинні інформаційні обвідні `I(t)` і `Q(t)` без жодного взаємного проникнення чи перехресних викривлень.

### Модель I/Q дисбалансу: амплітудна та фазова похибки

В реальних аналогових мікросхемах через технологічні відхилення виготовлення транзисторів, несиметрію друкованих доріжок та розбаланс фазообертачів квадратурні вітки мають двох типів асиметрію:
1. **Амплітудний дисбаланс `ε`**: коефіцієнт підсилення каналу I відрізняється від каналу Q. Якщо прийняти підсилення каналу Q за одиницю, то підсилення каналу I дорівнюватиме `1 + ε`, де `ε` — відносне відхилення.
2. **Фазова похибка `θ`**: фазовий зсув між гетеродинами I та Q відрізняється від ідеальних 90 градусів на малий кут `θ` (виміряний у радіанах).

Враховуючи ці аналогові недосконалості, реальні опорні сигнали гетеродина записуються так:

```
LO_I(t) = (1 + ε) · cos(w_0 · t)
LO_Q(t) = −sin(w_0 · t + θ)
```

Проведемо перемноження вхідного модульованого сигналу `r(t)` з реальними квадратурними коливаннями гетеродина у двох паралельних змішувачах:

```
y_I(t) = LPF{ r(t) · LO_I(t) }
       = LPF{ [I(t)·cos(w_0·t) − Q(t)·sin(w_0·t)] · (1 + ε)·cos(w_0·t) }
       = ½ · (1 + ε) · I(t)                                   [синфазна вітка]

y_Q(t) = LPF{ r(t) · LO_Q(t) }
       = LPF{ [I(t)·cos(w_0·t) − Q(t)·sin(w_0·t)] · (−sin(w_0·t + θ)) }
       = LPF{ −I(t)·cos(w_0·t)·sin(w_0·t + θ) + Q(t)·sin(w_0·t)·sin(w_0·t + θ) }
```

Щоб спростити вираз для квадратурного каналу `y_Q(t)`, застосуємо дві класичні тригонометричні тотожності розкладу добутку синусів і косинусів у суму:

```
cos(A) · sin(B) = ½ · [sin(B − A) + sin(B + A)]
sin(A) · sin(B) = ½ · [cos(A − B) − cos(A + B)]
```

Підставимо ці тригонометричні перетворення у відповідні доданки виразу для `y_Q(t)`:

```
cos(w_0·t) · sin(w_0·t + θ) = ½ · [sin(θ) + sin(2w_0·t + θ)]
sin(w_0·t) · sin(w_0·t + θ) = ½ · [cos(−θ) − cos(2w_0·t + θ)]
                            = ½ · [cos(θ) − cos(2w_0·t + θ)]
```

Після проходження через низькочастотний фільтр LPF усі компоненти з подвоєною частотою `2w_0` повністю пригнічуються. У результаті отримуємо реальний вихід квадратурного каналу `y_Q(t)`:

```
y_Q(t) = −½ · sin(θ) · I(t) + ½ · cos(θ) · Q(t)              [квадратурна вітка]
```

Отримана система рівнянь демонструє фізичну суть аналогового I/Q дисбалансу: через фазову похибку `θ` частина енергії синфазного сигналу `I(t)` протікає у квадратурний канал `Q(t)`, викликаючи перехресну заваду:

```
y_I(t) = ½ · (1 + ε) · I(t)
y_Q(t) = ½ · cos(θ) · Q(t) − ½ · sin(θ) · I(t)
```

### Комплексна спектральна форма та розрахунок IRR

У комплексній формі представлення аналогового базового сигналу сумарний вихідний вектор записується як `z(t) = y_I(t) + j · y_Q(t)`. Здійснюючи пряме перетворення Фур'є, висловимо викривлений спектр `Z(w)` через спектр корисного сигналу `S(w)` та спектр його дзеркального відображення `S*(−w)` відносно zero-частоти:

```
Z(w) = K_1 · S(w) + K_2 · S*(−w)
```

де комплексні коефіцієнти прямої передачі `K_1` та дзеркальної завади `K_2` обчислюються за формулами:

```
K_1 = ½ · [ (1 + ε) + cos(θ) − j · sin(θ) ]
    = ½ · [ (1 + ε) + e^(−j·θ) ]                             [прямий коефіцієнт]

K_2 = ½ · [ (1 + ε) − cos(θ) + j · sin(θ) ]
    = ½ · [ (1 + ε) − e^(j·θ) ]                              [дзеркальний коефіцієнт]
```

Коефіцієнт приглушення дзеркального каналу (Image Rejection Ratio, IRR) визначається як відношення потужності корисного спектрального компонента до потужності дзеркальної завади, яка накладається на нього з протилежного боку спектра:

```
IRR = |K_1|² / |K_2|²
```

Обчислимо квадрати модулів комплексних коефіцієнтів `|K_1|²` та `|K_2|²` через їхні дійсні та уявні частини:

```
|K_1|² = ¼ · | (1 + ε) + cos(θ) − j·sin(θ) |²
       = ¼ · [ ((1 + ε) + cos(θ))² + sin²(θ) ]
       = ¼ · [ (1 + ε)² + 2·(1 + ε)·cos(θ) + cos²(θ) + sin²(θ) ]
       = ¼ · [ 1 + 2·(1 + ε)·cos(θ) + (1 + ε)² ]             [квадрат модуля K_1]

|K_2|² = ¼ · | (1 + ε) − cos(θ) + j·sin(θ) |²
       = ¼ · [ ((1 + ε) − cos(θ))² + sin²(θ) ]
       = ¼ · [ (1 + ε)² − 2·(1 + ε)·cos(θ) + cos²(θ) + sin²(θ) ]
       = ¼ · [ 1 − 2·(1 + ε)·cos(θ) + (1 + ε)² ]             [квадрат модуля K_2]
```

Точна аналітична формула для розрахунку відношення пригнічення дзеркального каналу через геометричний розбаланс має вигляд:

```
IRR = [ 1 + 2·(1 + ε)·cos(θ) + (1 + ε)² ] / [ 1 − 2·(1 + ε)·cos(θ) + (1 + ε)² ]
```

Переводячи отриманий вираз у логарифмічну шкалу децибелів:

```
IRR_dB = 10 · log10( [ 1 + 2·(1 + ε)·cos(θ) + (1 + ε)² ] / [ 1 − 2·(1 + ε)·cos(θ) + (1 + ε)² ] )
```

Для малих практичних похибок (`ε << 1` та `θ << 1` радіан) скористаємося наближеннями розкладу Тейлора: `cos(θ) ≈ 1 − θ²/2` та `(1 + ε)² ≈ 1 + 2ε + ε²`. Тоді чисельник і знаменник суттєво спрощуються:

```
чисельник  ≈ 1 + 2·(1 + ε)·(1 − θ²/2) + 1 + 2ε + ε²
           ≈ 1 + 2 + 2ε − θ² + 1 + 2ε
           ≈ 4                                               [спрощення чисельника]

знаменник  ≈ 1 − 2·(1 + ε)·(1 − θ²/2) + 1 + 2ε + ε²
           ≈ 1 − 2 − 2ε + θ² + 1 + 2ε + ε²
           ≈ ε² + θ²                                         [спрощення знаменника]
```

В результаті підстановки отримуємо інженерну спрощену формулу для розрахунку IRR за малих відхилень:

```
IRR_dB ≈ 10 · log10( 4 / (ε² + θ²) )
```

Проаналізуємо практичні цифрові значення цієї формули для реальних приймальних трактах:
- Якщо амплітудний розбаланс становить `ε = 1%` (тобто 0.01), а фазова похибка дорівнює `θ = 1°` (тобто 0.0175 радіана), то приглушення дзеркального каналу обчислюється як:
  `IRR_dB ≈ 10 · log10( 4 / (0.01² + 0.0175²) ) = 10 · log10( 4 / 0.000406 ) ≈ 39.9 dB`.
- У сучасних системах стільникового зв'язку (LTE/5G) або Wi-Fi для впевненого декодування багатопозиційних модуляцій (256-QAM) вимагається приглушення дзеркального каналу на рівні не менше `60 dB`. З отриманої формули слідує, що для досягнення `IRR = 60 dB` фазова похибка не повинна перевищувати `0.1°`, а амплітудний розбаланс — `0.1%`. Оскільки витримати такі суворі допуски суто аналоговими методами на кремнії неможливо через технологічний розкид, у сучасних радіочипах обов'язково застосовують цифрову DSP-калібровку I/Q дисбалансу.

### Аналіз впливу фазового шуму гетеродина на I/Q каналі

Окрім сталого фазового зсуву `θ`, важливим джерелом деградації чутливості Zero-IF приймача є фазовий шум генератора гетеродина `φ_n(t)`. З урахуванням фазового шуму сигнали гетеродина записуються так:

```
LO_I(t) = cos(w_0 · t + φ_n(t))
LO_Q(t) = −sin(w_0 · t + φ_n(t) + θ)
```

Фазовий шум `φ_n(t)` викликає швидке хаотичне обертання вектора сигнального сузір'я у комплексній площині базової смуги. Якщо для протидії сталій фазовій похибці `θ` достатньо обчислити нерухому матрицю Ґрама-Шмідта, то для компенсації фазового шуму `φ_n(t)` у цифровому модімі застосовують адаптивні петлі автопідстроювання фази несучої (Costas loop або Decision-Directed Carrier Tracking Loop).

### Математика виникнення DC Offset (LO Self-Mixing)

Окрім I/Q дисбалансу, головним ворогом архітектури Zero-IF є виникнення паразитної постійної напруги (DC offset) на виході змішувача. Розглянемо математичну модель її виникнення внаслідок ефекту самозмішування гетеродина (LO Self-Mixing).

Нехай сигнал гетеродина описується як `v_LO(t) = V_LO · cos(w_0 · t)`. Через ємності підкладки мікросхеми та випромінювання доріжок друкованої плати частина напруги гетеродина потрапляє на вхід малошумного підсилювача LNA або безпосередньо на вхідний порт змішувача. 

Паразитний витік на вході змішувача можна записати у вигляді:

```
v_leak(t) = V_leak · cos(w_0 · t + φ_leak)
```

де `V_leak` — амплітуда витоку, а `φ_leak` — фазовий зсув, набутий паразитною хвилею під час проходження через підкладку або відбиття від антени.

Перемножуючи паразитний сигнал витоку з основним опорним коливанням гетеродина у змішувачі:

```
v_out(t) = LPF{ v_leak(t) · v_LO(t) }
         = LPF{ V_leak · cos(w_0·t + φ_leak) · V_LO · cos(w_0·t) }
         = LPF{ ½ · V_leak · V_LO · [ cos(φ_leak) + cos(2w_0·t + φ_leak) ] }
         = ½ · V_leak · V_LO · cos(φ_leak)                     [постійна напруга DC]
```

Отриманий результат показує, що перемноження двох синусоїд одинакової частоти `w_0` породжує чисту постійну напругу `V_DC = ½ · V_leak · V_LO · cos(φ_leak)`. 

Розрахуємо практичний рівень цієї завади: напруга гетеродина в інтегральних змішувачах становить близько `V_LO ≈ 300...500 мВ`. Якщо внаслідок слабкого екранування випливає лише `V_leak = 100 мкВ` напруги гетеродина, на виході змішувача виникає постійне зміщення:

```
V_DC = ½ · 100 мкВ · 500 мВ · cos(φ_leak) ≈ 25 мВ
```

Оскільки корисний радіосигнал від далекого передавача на виході змішувача має амплітуду лише біля `10...50 мкВ`, постійне зміщення у `25 мВ` виявляється у `500...2500 разів` потужнішим за корисний сигнал. Без застосування кіл зрізу постійної складової (AC coupling) або систем автокалібрування DCOC це зміщення негайно заганяє наступні підсилювальні каскади низької частоти та аналого-цифровий перетворювач (АЦП) у глибоке насичення.

### Математика прямого квадратичного детектування (IP2)

Розглянемо виникнення низькочастотної завади внаслідок квадратичної нелінійності підсилювачів та змішувачів. Передавальна характеристика нелінійного елемента описується поліномом Тейлора:

```
v_out(t) = a_1 · v_in(t) + a_2 · v_in²(t) + a_3 · v_in³(t) + ...
```

Нехай на вхід потрапляють дві амплітудно-модульовані радіозавади `v_in(t) = A_1 · cos(w_1 · t) + A_2 · cos(w_2 · t)`. Підставимо їх у квадратичний доданок `a_2 · v_in²(t)`:

```
v_in²(t) = [ A_1 · cos(w_1·t) + A_2 · cos(w_2·t) ]²
         = A_1² · cos²(w_1·t) + A_2² · cos²(w_2·t) + 2 · A_1 · A_2 · cos(w_1·t) · cos(w_2·t)
```

Розкладаючи квадрати та добутки косинусів:

```
A_1² · cos²(w_1·t) = ½ · A_1² + ½ · A_1² · cos(2w_1·t)
2·A_1·A_2·cos(w_1·t)·cos(w_2·t) = A_1·A_2·[ cos((w_1 − w_2)·t) + cos((w_1 + w_2)·t) ]
```

Після проходження через низькочастотний фільтр LPF у смузі базових частот залишаються два низькочастотні доданки:
1. Постійна напруга `½ · a_2 · (A_1² + A_2²)`.
2. Низькочастотна завада різницевої частоти `a_2 · A_1 · A_2 · cos((w_1 − w_2) · t)`.

Якщо частоти завад знаходяться дуже близько одна до одної (`|w_1 − w_2| < B/2`), ця різницева завада потрапляє в центр корисного сигналу. Для вимірювання стійкості приймача до цього ефекту використовують точку перехоплення другого порядку `IIP2`:

```
IIP2_dBm = P_in_dBm + (P_fundamental_dBm − P_IM2_dBm)
```

Високе значення `IIP2 > +70 дБм` досягається суворою диференціальною симетрією змішувачів, у якій парні гармоніки взаємно скасовуються.
