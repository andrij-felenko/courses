# 🧮 Математика хроматичної дисперсії: розклад хвильового вектора та розрахунок розширення імпульсу

Ця математична вставка розгортає суворий аналітичний апарат хроматичної дисперсії: від Тейлорівського розкладу постійної поширення хвилі β(ω) та точного зв'язку між параметрами β₂ та D до розрахунку еволюції часового огибаючого гаусового імпульсу, впливу чірпування й нелінійного рівняння Сельмейєра.

### 1. Фазова й групова швидкості та Тейлорівський розклад β(ω)

При розповсюдженні оптичної хвилі у волокні слід строго розрізняти три швидкості:
1. **Фазова швидкість `v_p`:** швидкість руху окремої фазової гребінки монохроматичної хвилі (`v_p = c / n_eff = ω / β`).
2. **Групова швидкість `v_g`:** швидкість руху обгинаючої оптичного імпульсу (перенесення оптичної енергії та інформації) (`v_g = dω / dβ = 1 / β₁`).
3. **Групове прискорення:** зміна групової швидкості з частотою, яка й визначається параметром дисперсії `β₂ = d²β / dω²`.

Електромагнітна хвиля, що поширюється вздовж осі `z` у одномодовому волокні, описується виразом для комплексного електричного поля `E(z, t)`:

```text
E(z, t) = A(z, t) · exp(i · (β₀ · z − ω₀ · t))
```

де `A(z, t)` — повільно змінювана часова огибаюча імпульсу, `ω₀` — центральна несуча колово частота, а `β(ω)` — постійна поширення моди (*propagation constant*):

```text
β(ω) = n_eff(ω) · (ω / c)
```

Оскільки оптичний імпульс має скінченну спектральну ширину `Δω` навколо `ω₀`, розкладемо функцію `β(ω)` у ряд Тейлора у околі несучої частоти `ω₀`:

```text
β(ω) = β₀ + β₁ · (ω − ω₀) + (1/2) · β₂ · (ω − ω₀)² + (1/6) · β₃ · (ω − ω₀)³ + …
```

де коефіцієнти розкладу виражаються через похідні відповідного порядку по коловій частоті:

```text
β₀ = β(ω₀) = n_eff(ω₀) · ω₀ / c
β₁ = [dβ / dω]|ω₀ = 1 / v_g
β₂ = [d²β / dω²]|ω₀
β₃ = [d³β / dω³]|ω₀
```

Фізичний зміст кожного члена Тейлорівського розкладу:
- **β₀ (фазовий зсув):** набіг фази несучої світлової хвилі на одиницю довжини.
- **β₁ (групова затримка):** величина, обернена до групової швидкості `v_g`. Час прольоту імпульсу через волокно довжиною `L` становить `τ_g = L · β₁ = L / v_g`.
- **β₂ (GVD — Group Velocity Dispersion):** параметр дисперсії групових швидкостей. Вимірюється у `пс²/км` або `с²/м`. Саме β₂ описує симетричне часове розширення оптичного імпульсу.
- **β₃ (TOD — Third-Order Dispersion):** дисперсія третього порядку. Вимірюється у `пс³/км`. Вона відповідає за асиметричне спотворення обгинаючої імпульсу (появу «осцилюючого хвоста») і важить при розповсюдженні ультракоротких фемтосекундних імпульсів або на довжині хвилі нульової дисперсії `β₂ = 0`.

### 2. Математичне доведення зв'язку між β₂ та інженерним коефіцієнтом D

Знайдемо математичний зв'язок між фізичним параметром `β₂ = d²β / dω²` та коефіцієнтом `D = dβ₁ / dλ`.

Оскільки колово частота `ω` та довжина хвилі у вакуумі `λ` пов'язані співвідношенням:

```text
ω = 2 · π · c / λ
```

візьмемо диференціал від цієї функції:

```text
dω / dλ = − 2 · π · c / λ²
```

Застосуємо правило диференціювання складеної функції для коефіцієнта дисперсії `D`:

```text
D = dβ₁ / dλ 
  = (dβ₁ / dω) · (dω / dλ)
  = (d / dω [dβ / dω]) · (− 2 · π · c / λ²)
  = (d²β / dω²) · (− 2 · π · c / λ²)
  = − (2 · π · c / λ²) · β₂
```

Таким чином, маємо точну тотожність:

```text
D = − (2 · π · c / λ²) · β₂
```

Також виведемо обернену формулу для обчислення `β₂` через коефіцієнт `D`:

```text
β₂ = − (λ² / (2 · π · c)) · D
```

#### Числовий розрахунок для 1550 нм:
Нехай для стандартного одномодового волокна SMF-28 на довжині хвилі `λ = 1550 нм` (`1.55 · 10⁻⁶ м`) коефіцієнт дисперсії становить `D = +17 пс/(нм·км)` (`17 · 10⁻⁶ с / м²`). Обчислимо `β₂`:

```text
2·π·c = 2 · 3.1415926 · 2.99792458 · 10⁸      [константи π та c у системи СІ]
      = 1.88365 · 10⁹ м/с                     [обчислення знаменника]

λ² = (1.55 · 10⁻⁶)²                           [довжина хвилі 1550 нм у метрах]
   = 2.4025 · 10⁻¹² м²                        [квадрат довжини хвилі]

β₂ = − (λ² / (2·π·c)) · D                     [формула зв'язку між β₂ та D]
   = − (2.4025·10⁻¹² / 1.88365·10⁹) · (17·10⁻⁶) [підстановка обчислених значень]
   = − (1.27544 · 10⁻²¹) · (17 · 10⁻⁶)         [проміжне ділення]
   = − 2.168 · 10⁻²⁶ с²/м                     [перемноження у СІ: с²/м]
   = − 21.68 пс²/км                           [переведення одиниць у пс²/км]
```

Отже, додатний коефіцієнт `D = +17 пс/(нм·км)` відповідає від'ємному параметру `β₂ = −21.68 пс²/км`.

### 3. Рівняння еволюції гаусового імпульсу та довжина дисперсії L_D

Якщо знехтувати загасанням та нелінійними ефектами, дифференціальне рівняння в частинних похідних для обгинаючої оптичного поля `A(z, t)` у рухомій системі координат `T = t − z/v_g` має вигляд параболічного рівняння типу Шредінгера:

```text
i · (∂A / ∂z) = (1/2) · β₂ · (∂²A / ∂T²)
```

Припустимо, що у початковий момент часу `z = 0` у волокно вводиться гауссів імпульс без чірпування:

```text
A(0, T) = A₀ · exp(− T² / (2 · T₀²))
```

де `T₀` — початкова півширина імпульсу за рівнем `1/e` (зв'язана з тривалістю за напіввисотою `T_FWHM` співвідношенням `T_FWHM ≈ 1.665 · T₀`).

Розв'язуючи це рівняння за допомогою просторового перетворення Фур'є, отримуємо аналітичний вираз для амплітуди імпульсу на довільній відстані `z = L`:

```text
A(L, T) = A₀ · [ T₀ / √(T₀² − i · β₂ · L) ] · exp(− T² / (2 · (T₀² − i · β₂ · L)))
```

Модуль квадрата амплітуди `|A(L, T)|²` описує розподіл інтенсивності розширеного гаусового імпульсу:

```text
|A(L, T)|² = [ A₀² / √(1 + (L / L_D)²) ] · exp(− T² / (T₀² · (1 + (L / L_D)²)))
```

де введені фундаментальний параметр **довжини дисперсії** `L_D`:

```text
L_D = T₀² / |β₂|
```

З цієї формули видно, що на відстані `L = L_D` півширина імпульсу зростає у `√2 ≈ 1.41` рази, а пікова інтенсивність падає у `√2` разів.

Ширина гаусового імпульсу `T(L)` на відстані `L` обчислюється як:

```text
T(L) = T₀ · √(1 + (L / L_D)²)
```

Для великих відстаней (`L ≫ L_D`) ця формула спрощується до лінійного співвідношення:

```text
T(L) ≈ T₀ · (L / L_D) = |β₂| · L / T₀
```

#### Математичний вплив початкового чірпування C
Якщо вхідний імпульс має початкову часову фазову модуляцію (чірп `C`):

```text
A(0, T) = A₀ · exp(− (1 + i · C) · T² / (2 · T₀²))
```

то еволюція ширини імпульсу `T(L)` описується виразом:

```text
T(L) = T₀ · √[ (1 + C · β₂ · L / T₀²)² + (β₂ · L / T₀²)² ]
```

Зверніть увагу на знак добутку `C · β₂`:
- Якщо `C · β₂ > 0` (наприклад, додатний чірп `C > 0` у нормальній дисперсії `β₂ > 0`), розширення імпульсу прискорюється від самого початку.
- Якщо `C · β₂ < 0` (наприклад, від'ємний чірп `C < 0` у аномальній дисперсії `β₂ < 0`), вираз під першим квадратом спочатку зменшується до нуля! 

Це означає, що імпульс **спочатку стискається** у часі до мінімальної ширини `T_min = T₀ / √(1 + C²)`, яка досягається на оптимальній відстані `L_opt`:

```text
L_opt = − [ C / (1 + C²) ] · (T₀² / β₂)
```

Після досягнення точки `L_opt` імпульс починає розширюватися. Ефект початкового стискання широко використовується у лазерних модуляторах для збільшення дальності прогону без пасивних компенсаторів.

### 4. Порівняльний аналіз форматів кодування NRZ та RZ

У математичному моделюванні оптичних систем важливо розрізняти вплив хроматичної дисперсії на різні формати модації обгинаючої:

1. **Format NRZ (Non-Return-to-Zero):** Прямокутний імпульс займає 100% тривалості бітового слота `T_bit`. Оскільки початковий спектр є вужчим, розширення імпульсу відбувається повільніше на коротких відстанях, але міжсимвольна інтерференція швидко руйнує сигнал при перевищенні порогу.
2. **Format RZ (Return-to-Zero):** Оптичний спалах займає лише 50% бітового інтервалу (наприклад, 50 пс при швидкості 10 Гбіт/с). Оскільки початковий імпульс коротший (`T₀` менше), його спектр є ширшим, а довжина дисперсії `L_D = T₀² / |β₂|` виявляється коротшою у 4 рази. Проте RZ-сигнал має вищу стійкість до нелінійних оптичних ефектів у DWDM-системах.

### 5. Розрахунок Sellmeier для плавленного кварцю

Показник заломлення `n(λ)` чистого плавленного кварцю (SiO₂) описується тричленним рівнянням Сельмейєра при температурі 20°C:

```text
n²(λ) = 1 + [ B₁ · λ² / (λ² − C₁) ] + [ B₂ · λ² / (λ² − C₂) ] + [ B₃ · λ² / (λ² − C₃) ]
```

де довжина хвилі `λ` задається в мікрометрах (мкм), а коефіцієнти дорівнюють:

```text
B₁ = 0.69616630,   C₁ = 0.06840430² = 0.004679148 мкм²
B₂ = 0.40794260,   C₂ = 0.11624140² = 0.013512063 мкм²
B₃ = 0.89747940,   C₃ = 97.93400254 мкм²
```

Обчислимо показник заломлення `n(λ)` для трьох робочих довжин хвиль оптичного зв'язку:
1. Для `λ = 0.85 мкм`: `n = 1.4525`
2. Для `λ = 1.31 мкм`: `n = 1.4504`
3. Для `λ = 1.55 мкм`: `n = 1.4440`

Шляхом подвійного чисельного диференціювання виразу `n(λ)` знаходять матеріальну дисперсію `D_M(λ)`:

```text
D_M(λ) = − (λ / c) · (d²n / dλ²)
```

При `λ = 1.273 мкм` друга похідна `d²n/dλ² = 0`, що аналітично підтверджує точку нульової матеріальної дисперсії кварцового скла.
