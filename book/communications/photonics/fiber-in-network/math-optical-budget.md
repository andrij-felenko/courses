# 🧮 Математика оптичного бюджету: загасання, OSNR та межі розщеплення

Цей математичний розділ містить виведення формул оптичного бюджету потужності лінії (*Optical Power Budget*), розрахунок загасання в пасивних мережах (PON), оцінку співвідношення сигнал/шум (OSNR), математичну модель хроматичної дисперсії та обчислення максимального коефіцієнта розщеплення сплітерів.

---

### 1. Перетворення логарифмічних одиниць (дБ та дБм)

В оптичному зв'язку потужність вимірюється в **децибел-міліватах** (дБм / dBm) — абсолютній логарифмічній шкалі відносно 1 мілівата (1 мВт = 10⁻³ Вт):

```text
P [дБм] = 10 · log₁₀( P [мВт] / 1 мВт )
```

Зворотне перетворення логарифмічної потужності в лінійну [мВт]:

```text
P [мВт] = 10^( P [дБм] / 10 )
```

Одиниці підсилення та загасання є відносними децибелами (дБ / dB):

```text
A [дБ] = P_in [дБм] − P_out [дБм]
```

Оскільки віднімання логарифмів відповідає діленню лінійних величин, алгебра логарифмічних одиниць спрощує розрахунок довгого оптичного тракту до додавання та віднімання.

---

### 2. Рівняння бюджету оптичної потужності лінії

Загальне бюджетне рівняння оптичної лінії визначає потужність світла, що досягає фотоприймача:

```text
P_RX = P_TX − A_total − M
```

Де:
- `P_TX` — мінімальна вихідна потужність оптичного передавача [дБм];
- `P_RX` — отримана потужність на вході фотоприймача [дБм];
- `A_total` — сумарне загасання оптичного тракту між передавачем і приймачем [дБ];
- `M` — гарантований інженерний запас лінії (*System Link Margin*, зазвичай 3.0…5.0 дБ).

Щоб лінія працювала без помилок (із рівнем похибки `BER ≤ 10⁻¹²`), виміряна або розрахована потужність `P_RX` має перебувати всередині **динамічного діапазону приймача**:

```text
P_sens ≤ P_RX ≤ P_overload
```

Де `P_sens` — чутливість приймача (найнижчий поріг), `P_overload` — рівень оптичного насичення/перевантаження (найвищий поріг, вище якого фотодіод засліплюється або пошкоджується).

Розгортання складових сумарного загасання `A_total`:

```text
A_total = α_fiber · L + N_splice · A_splice + N_conn · A_conn + A_splitter + A_pen
```

Аналіз складових сумарного загасання `A_total`:
- `α_fiber · L` — загасання волокна довжиною `L` км із коефіцієнтом `α` [дБ/км];
- `N_splice · A_splice` — втрати на `N_splice` зварних з'єднаннях (0.02…0.05 дБ/зварка);
- `N_conn · A_conn` — втрати на `N_conn` рознімних з'єднувачах (0.2…0.5 дБ/роз'єм);
- `A_splitter` — втрати на пасивних optical розгалужувачах (сплітерах);
- `A_pen` — штраф за хроматичну дисперсію та відбиття (1.0…2.0 дБ).

### 3. Математика пасивного оптичного розщеплення (PON Splitter)

Ідеальний оптичний сплітер розділяє вхідну потужність `P_in` порівну між `N` вихідними портами. Збереження енергії в лінійній формі для ідеального 1:N сплітера:

```text
P_out_each [мВт] = P_in [мВт] / N
```

Переведемо ділення у децибели [дБ]:

```text
A_split_ideal = 10 · log₁₀( P_in / P_out_each )
              = 10 · log₁₀( N )      [властивість логарифма: log(A/B) = -log(B/A)]
```

Виведемо точну логарифмічну формулу для сплітера каскадного типу (де `N = 2ᵏ`, а `k` — число ступенів подвоєння):

```text
A_split_ideal
= 10 · log₁₀( 2ᵏ )
= 10 · k · log₁₀( 2 )                [закони логарифмування: log(xᵏ) = k · log(x)]
= 10 · k · 0.30103                   [бо log₁₀(2) ≈ 0.30103]
≈ 3.01 · k [дБ]                      [кожна розвилка 1:2 додає 3.01 дБ втрат]
```

Реальний планарний сплітер (*PLC Splitter*) має додаткові неефективності розсіювання та технологічні втрати вставки (*Insertion Loss*, `A_excess`), тому сумарні втрати реального сплітера 1:N обчислюються як:

```text
A_splitter = 10 · log₁₀( N ) + A_excess
```

Розрахуємо теоретичні та практичні втрати популярних каскадів сплітерів PLC:

```text
 ┌─────────────────┬─────────────────────┬─────────────────────┬─────────────────────┐
 │ Сплітер (1:N)   │ Теоретична межа     │ Втрати вставки PLC  │ Сумарні втрати      │
 │                 │ 10·log₁₀(N) [дБ]    │ A_excess [дБ]       │ A_splitter [дБ]     │
 ├─────────────────┼─────────────────────┼─────────────────────┼─────────────────────┤
 │ 1:2  (k = 1)    │ 3.01                │ 0.60                │ 3.61                │
 │ 1:4  (k = 2)    │ 6.02                │ 0.98                │ 7.00                │
 │ 1:8  (k = 3)    │ 9.03                │ 1.47                │ 10.50               │
 │ 1:16 (k = 4)    │ 12.04               │ 1.76                │ 13.80               │
 │ 1:32 (k = 5)    │ 15.05               │ 2.05                │ 17.10               │
 │ 1:64 (k = 6)    │ 18.06               │ 2.44                │ 20.50               │
 └─────────────────┴─────────────────────┴─────────────────────┴─────────────────────┘
```

### 4. Розрахунок граничної дальності та максимуму розщеплення GPON

Визначимо максимальне число абонентів `N`, яке може обслужити один порт OLT стандарту **GPON Class B+** на відстані `L = 15 км`.

**Вихідні дані стандарту GPON Class B+ (Downstream 1490 нм):**
- Мінімальна потужність передавача OLT: `P_TX_min = +1.5 дБм`
- Чутливість приймача ONU: `P_sens = −27.0 дБм`
- Доступний оптичний бюджет: `B_opt = P_TX_min − P_sens = +1.5 − (−27.0) = 28.5 дБ`
- Загасання волокна на 1490 нм: `α = 0.35 дБ/км`
- Число зварювань: `N_splice = 6` (при `A_splice = 0.05 дБ`)
- Число роз'ємів: `N_conn = 4` (при `A_conn = 0.30 дБ`)
- Гарантований запас системи: `M = 3.0 дБ`

Покрокове обчислення максимальних втрат на сплітер `A_splitter_max`:

```text
B_opt = A_fiber + A_splices + A_connectors + A_splitter + M

A_fiber
= α · L
= 0.35 дБ/км · 15 км
= 5.25 дБ                            [підстановка довжини лінії L=15 км]

A_splices
= N_splice · A_splice
= 6 · 0.05 дБ
= 0.30 дБ                            [втрати на зварювальних стиках]

A_connectors
= N_conn · A_conn
= 4 · 0.30 дБ
= 1.20 дБ                            [втрати на кросових з'єднувачах]

A_line_fixed
= A_fiber + A_splices + A_connectors
= 5.25 + 0.30 + 1.20
= 6.75 дБ                            [сума фіксованих втрат траси]

A_splitter_max
= B_opt − A_line_fixed − M
= 28.5 дБ − 6.75 дБ − 3.0 дБ
= 18.75 дБ                           [максимальний допуск втрат на розгалужувач]
```

Тепер з'ясуємо, чи пройде сплітер 1:64 (втрати 20.50 дБ) чи сплітер 1:32 (втрати 17.10 дБ):

```text
A_splitter(1:64) = 20.50 дБ > 18.75 дБ   [НЕ проходить, бюджет перевищено!]
A_splitter(1:32) = 17.10 дБ ≤ 18.75 дБ   [ПРОХОДИТЬ із запасом!]
```

Обчислимо фактичний залишковий запас лінії `M_real` для сплітера 1:32:

```text
M_real
= B_opt − (A_line_fixed + A_splitter(1:32))
= 28.5 дБ − (6.75 дБ + 17.10 дБ)
= 28.5 дБ − 23.85 дБ
= 4.65 дБ                            [чудовий запас, 4.65 дБ > 3.0 дБ]
```

Отже, для лінії 15 км у класі GPON B+ граничним безпечним коефіцієнтом розщеплення є **1:32**. Щоб підключити 1:64, довелося б перейти на оптичний клас **GPON Class C+** (з бюджетом 32.0 дБ).

### 5. Моделювання штрафу за хроматичну дисперсію

Навіть в одномодовому волокні імпульс світла розширюється в часі через хроматичну дисперсію (*Chromatic Dispersion*, CD). Загальне уширення імпульсу `Δτ` [пс] описується формулою:

```text
Δτ = D · Δλ · L
```

Де:
- `D` — коефіцієнт хроматичної дисперсії волокна [пс / (нм · км)] (наприклад, `D ≈ 17.0 пс/(нм·км)` для стандарту G.652 на довжині хвилі 1550 нм);
- `Δλ` — спектральна ширина випромінювання лазера [нм] (для DFB-лазера `Δλ ≈ 0.1 нм`, для FP-лазера `Δλ ≈ 2.0 нм`);
- `L` — довжина оптичного кабелю [км].

Коли уширення імпульсу `Δτ` перевищує 20% від тривалості бітового інтервалу `T_b = 1 / B` (де `B` — бітова швидкість [Гбіт/с]), виникає міжсимвольна інтерференція (ISI). Енергія імпульсу натікає на сусідні біти, що призводить до штрафу з потужності (*Dispersion Penalty*, `A_disp` [дБ]):

```text
A_disp [дБ] = 5 · log₁₀( 1 + 2π · (D · Δλ · B)² · L² )
```

Розрахуємо дисперсійний штраф для лінії 10 Гбіт/с (`B = 10 Гбіт/с`, `T_b = 100 пс`) довжиною `L = 50 км` з лазером DFB (`Δλ = 0.1 нм`) на волокні G.652 (`D = 17 пс/(нм·км)`):

```text
Δτ
= D · Δλ · L
= 17 · 0.1 · 50
= 85.0 пс                            [уширення імпульсу становить 85 пс]

A_disp
= 5 · log₁₀( 1 + 2π · (17 · 0.1 · 10 · 10⁻³)² · 50² )
= 5 · log₁₀( 1 + 6.283 · (0.017)² · 2500 )
= 5 · log₁₀( 1 + 6.283 · 0.000289 · 2500 )
= 5 · log₁₀( 1 + 4.539 )
= 5 · log₁₀( 5.539 )
= 5 · 0.7434
≈ 3.72 дБ                            [відчутний штраф 3.72 дБ з потужності]
```

Отриманий штраф 3.72 дБ показує, що без компенсаторів дисперсії (DCM) або DSP-процесорів когерентного прийому лінія 10G на звичайному волокні обмежена відстанню близько 40–50 км.

### 6. Оптичне співвідношення сигнал/шум (OSNR) у DWDM-магістралях

У довгих DWDM-лініях із каскадом підсилювачів EDFA обмеженням дальності є не загасання потужності (яке компенсується підсилювачами), а накопичення спонтанного шумового випромінювання (**ASE** — *Amplified Spontaneous Emission*).

Співвідношення оптичного сигналу до шуму **OSNR** описується формулою Гордона-Хауса:

```text
OSNR [дБ] = P_out − L_span − NF − 10 · log₁₀( N_spans ) − 10 · log₁₀( h · ν · Δν )
```

Де:
- `P_out` — оптична потужність сигналу на виході кожного підсилювача [дБм];
- `L_span` — загасання одного прольоту між підсилювачами [дБ] (зазвичай `α · L_span = 0.2 дБ/км · 80 км = 16 дБ`);
- `NF` — коефіцієнт шуму підсилювача EDFA (*Noise Figure*, 4.5…6.0 дБ);
- `N_spans` — кількість каскадних перегонів/підсилювачів;
- `h · ν · Δν` — квантова шумність на довжині хвилі 1550 нм в еталонній смузі вимірювання 0.1 нм (12.5 ГГц), що дорівнює **−58.0 дБм**.

Спрощена інженерна формула OSNR для `N_spans` однакових прольотів:

```text
OSNR [дБ] = P_out [дБм] − L_span [дБ] − NF [дБ] + 58.0 [дБ] − 10 · log₁₀( N_spans )
```

Обчислимо OSNR на кінці магістралі з `N_spans = 10` прольотів по 80 км (`L_span = 16 дБ`), при `P_out = 0 дБм` і `NF = 5.0 дБ`:

```text
OSNR
= 0 − 16 − 5.0 + 58.0 − 10 · log₁₀( 10 ) [підстановка параметрів: P_out=0, L_span=16, NF=5, N=10]
= 37.0 − 10 · 1.0                       [обчислення десяткового логарифма: log₁₀(10) = 1]
= 27.0 дБ                                [підсумкове віднімання: 37.0 − 10.0 = 27.0 дБ]
```

### 7. Співвідношення між OSNR, Q-фактором та рівнем бітових помилок (BER)

Якість цифрового прийому визначається коефіцієнтом помилкових бітів **BER** (*Bit Error Rate*). У фотоприймачі BER пов'язаний із так званим **Q-фактором** (відношенням розмаху оптичного сигналу до сумарного середньоквадратичного шуму «0» та «1»):

```text
BER = 0.5 · erfc( Q / √2 )
```

Де `erfc(x)` — додаткова функція помилок (*complementary error function*). Для досягнення стандартної чистоти лінії без FEC (`BER = 10⁻⁹`) необхідне значення `Q ≥ 6.0`.

Приблизний зв'язок між OSNR та Q-фактором для прямого детектування (NRZ):

```text
Q [дБ] = OSNR [дБ] + 10 · log₁₀( B_ref / B_opt )
```

Застосування завадостійкого кодування **FEC** (*Forward Error Correction*, наприклад RS(255,239) або м'яке декодування Soft-Decision FEC) дозволяє виправляти вхідні помилки рівня `BER_in = 10⁻³` до підсумкового `BER_out = 10⁻¹⁵`. Це знижує необхідний поріг OSNR на 6–9 дБ, що дорівнює подвоєнню дальності перегонів DWDM-магістралей.
