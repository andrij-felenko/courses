# 🧮 Математична модель втрат на оптичному стику та відбиття Френеля

Передача світла через стик двох оптичних волокон описується математичним апаратом електродинаміки діелектричних хвилеводів та теорією сполучення оптичних мод. У фундаментальній моді одномодового волокна (мода `HE₁₁` або `LP₀₁`) розподіл амплітуди електричного поля світлової хвилі у поперечному перерізі ядра з високою точністю описується двовимірним круговим гаусовим розподілом:

```text
E(r) = E₀ · exp(−r² / w²)
```

де `r` — радіальна відстань від осі ядра, `E₀` — амплітуда поля на осі, а `w` — **радіус модового поля** (*Mode Field Radius*, MFR), на якому інтенсивність випромінювання `I(r) = |E(r)|²` зменшується в `e²` разів (приблизно до 13.5% від максимального значення на осі).

Коли два волокна стикуються з геометричними або матеріалознавчими похибками, частка оптичної потужності `T`, що успішно переходить із першого волокна в друге, визначається квадратом модуля інтеграла перекриття (*overlap integral*) амплітудних профілів по торцевій площині `S`:

```text
T = | ∬_S E₁(x, y) · E₂*(x, y) dx dy |² / ( ∬_S |E₁(x,y)|² dx dy · ∬_S |E₂(x,y)|² dx dy )
```

Будь-яке порушення симетрії — геометричне зміщення осей, кутовий нахил, осьовий зазор або відмінність модових радіусів — зменшує значення інтеграла перекриття, що виражається у виникненні оптичних втрат.

---

### 1. Загальне рівняння Маркузе для втрат стикування

Для загального випадку, коли стикуються два волокна з модовими радіусами `w₁` та `w₂`, що мають радіальне зміщення `d`, кутовий незбіг осей `θ` (у радіанах) та осьовий зазор `s` у середовищі з показником заломлення `n₀`, загальний коефіцієнт передачі потужності `T` виражається класичним рівнянням Дитріха Маркузе (*Dietrich Marcuse*):

```text
T = (4 · E / F) · exp(−E · [d² / (w₁² + w₂²) + (π² · w₁² · w₂² · n₀² · θ²) / (λ² · (w₁² + w₂²))])
```

де проміжні коефіцієнти `E` та `F` враховують розширення гаусового пучка за рахунок сферичної дивергенції на осьовому зазорі `s`:

```text
E = 2 / (1 + (2 · s / (k · w₁ · w₂))²)     [хвильове число: k = 2π·n₀ / λ]
F = (1 + (2 · s / (k · w₁ · w₂))²)          [фактор геометричного розширення пучка]
```

Втрати потужності на стику `α` у децибелах (дБ) пов'язані з коефіцієнтом передачі співвідношенням:

```text
α = −10 · log₁₀(T)
```

Розглянемо внесок кожного з дефектів окремо, вивівши спрощені прямокутні формули для інженерних розрахунків.

---

### 2. Втрати від радіального зміщення cores (Lateral Offset)

Якщо волокна ідентичні (`w₁ = w₂ = w`), осьовий зазор та кутовий нахил відсутні (`s = 0`, `θ = 0`), а є лише радіальний зсув осей ядер на відстань `d`, рівняння Маркузе спрощується до вигляду:

```text
T_d = exp(−d² / w²)
```

Логарифмуючи це співвідношення, отримуємо пряму формулу втрат від радіального зміщення `α_d`:

```text
α_d = −10 · log₁₀(exp(−d² / w²))
    = −10 · (−d² / w²) · log₁₀(e)     [властивість логарифма: log₁₀(e^x) = x · log₁₀(e)]
    = 4.343 · (d / w)²                [константа: 10 · log₁₀(e) ≈ 4.343]
```

**Аналіз залежності**: Втрати пропорційні **квадрату** відношення зміщення `d` до радіуса модового поля `w`. Оскільки радіус модового поля одномодового волокна становить лише `w ≈ 4.5...5.2 мкм`, зміщення ядра натягує на себе колосальну чутливість.

Обчислимо втрати для трьох варіантів радіального зміщення при `w = 5.2 мкм` (стандартне волокно SMF-28):
- При `d = 0.2 мкм`:
  ```text
  α_d = 4.343 · (0.2 / 5.2)²           [підстановка d = 0.2 мкм, w = 5.2 мкм]
      = 4.343 · (0.03846)²             [обчислення відношення зміщення]
      = 4.343 · 0.001479               [квадрат відношення]
      = 0.0064 дБ                      [ідеальний зварний шов]
  ```
- При `d = 0.5 мкм`:
  ```text
  α_d = 4.343 · (0.5 / 5.2)²           [підстановка d = 0.5 мкм]
      = 4.343 · 0.009245               [квадрат відношення]
      = 0.040 дБ                       [допустимий польовий шов]
  ```
- При `d = 1.2 мкм`:
  ```text
  α_d = 4.343 · (1.2 / 5.2)²           [підстановка d = 1.2 мкм]
      = 4.343 · 0.05325                [квадрат відношення]
      = 0.231 дБ                       [бракований шов, що вимагає перезварювання]
  ```

Ці розрахунки показують, що для досягнення зварного шва преміум-якості (`α < 0.02 дБ`) система юстування апарата мусить гарантувати зведення ядер із похибкою не більшою ніж `d < 0.35 мкм`.

### 3. Втрати від кутового незбігу осей (Angular Tilt)

Якщо волокна ідентичні (`w₁ = w₂ = w`), зміщення й зазор відсутні (`d = 0`, `s = 0`), але осі волокон перетинаються під кутом `θ` (у радіанах), коефіцієнт передачі дорівнює:

```text
T_θ = exp(−(π · w · n₀ · θ / λ)²)
```

Переводячи в децибели, маємо формулу кутових втрат `α_θ`:

```text
α_θ = 4.343 · (π · w · n₀ · θ / λ)²
```

Якщо кут `θ_deg` задано в градусах, то з урахуванням переводного коефіцієнта `θ = θ_deg · (π / 180)`:

```text
α_θ = 4.343 · ((π² · w · n₀ · θ_deg) / (180 · λ))²
```

Для одномодового волокна на довжині хвилі `λ = 1.31 мкм` з `w = 5.2 мкм` у середовищі кварцу (`n₀ = 1.468`) незбіг осей на `θ_deg = 0.5°` призводить до втрат:

```text
α_θ = 4.343 · ((3.14159² · 5.2 · 1.468 · 0.5) / (180 · 1.31))²     [підстановка параметрів: w=5.2, n₀=1.468, θ=0.5°, λ=1.31]
    = 4.343 · (37.67 / 235.8)²                                     [обчислення чисельника й знаменника]
    = 4.343 · (0.15975)²                                           [відношення кутового фактора]
    = 0.111 дБ                                                     [підсумкові кутові втрати]
```

Це доводить критичну важливість чистоти сколювача волокна: якщо лезо скалювача створює торець із косиною `θ_deg > 0.7°`, зварювальний апарат не зможе вирівняти такий кутовий штам і шов буде забраковано.

### 4. Втрати від неузгодження розрізу мод (MFD Mismatch)

Коли стикуються два волокна різних типів (наприклад, стандартне магістральне волокно G.652 з `w₁ = 5.2 мкм` та спеціальне волокно з високою апертурою або підсилювальне ербієве волокно EDFA з `w₂ = 3.0 мкм`), навіть при ідеальному геометричному центруванні (`d = 0`, `θ = 0`, `s = 0`) виникають втрати через розбіжність геометричних розмірів огинаючих світлового пучка:

```text
T_mfd = (4 · w₁² · w₂²) / (w₁² + w₂²)²
```

Формула втрат неузгодження мод `α_mfd` у децибелах:

```text
α_mfd = −10 · log₁₀((4 · w₁² · w₂²) / (w₁² + w₂²)²)
      = 10 · log₁₀((w₁² + w₂²)² / (4 · w₁² · w₂²))     [інверсія дробу за властивістю логарифма]
```

Розрахуємо втрати при зварюванні волокна SMF-28 (`w₁ = 5.2 мкм`) з волокном EDFA (`w₂ = 3.0 мкм`):

```text
w₁² = 5.2² = 27.04                                            [квадрат модового радіуса SMF-28]
w₂² = 3.0² = 9.00                                             [квадрат модового радіуса EDFA]
α_mfd = 10 · log₁₀((27.04 + 9.00)² / (4 · 27.04 · 9.00))      [підстановка квадратичних радіусів]
      = 10 · log₁₀(36.04² / 973.44)                           [сума чисельника й добуток знаменника]
      = 10 · log₁₀(1298.88 / 973.44)                          [піднесення суми до квадрата]
      = 10 · log₁₀(1.3343)                                    [відношення площ модових полів]
      = 1.25 дБ                                               [підсумкові втрати MFD mismatch]
```

#### Техніка термодифузійного розширення ядра (Thermal Tapering)
Щоб здолати нездоланні 1.25 дБ втрат MFD-неузгодження при монтажі оптичних підсилювачів, інженери застосовують метод **термічного розширення ядра** (*Thermal Core Tapering*). Під час зварювання місце стику витримують під дією дуги зниженої потужності протягом 10–30 секунд. Під дією високої температури легуючі домішки Германію (`GeO₂`), що формують підвищений показник ядра, дифундують убік оболонки. Це створює гладкий адіабатичний перехідний конус ядра, що розширює модовий радіус `w₂` до `w₁`, зменшуючи втрати стикування з 1.25 дБ до менш ніж 0.1 дБ.

### 5. Відбиття Френеля та зворотні втрати (Return Loss)

При механічному з'єднанні волокон, де між торцями залишається повітряний зазор `s` (показник заломлення повітря `n₀ = 1.0`), світло перетинає межу «скло → повітря» та «повітря → скло». Оскільки ядро скла має показник заломлення `n₁ ≈ 1.468`, на кожній межі виникає відбиття Френеля (*Fresnel Reflection*).

Коефіцієнт відбиття потужності `R` від однієї плоскої межі при нормальному падінні дорівнює:

```text
R = ((n₁ − n₀) / (n₁ + n₀))²
```

Підставивши значення для кварцового скла й повітря:

```text
R = ((1.468 − 1.0) / (1.468 + 1.0))²
  = (0.468 / 2.468)²
  = (0.1896)²
  = 0.0359                    [частка відбиття від однієї межі: 3.59%]
```

Оскільки на повітряному зазорі є дві послідовні межі розділу, з урахуванням інтерференції сумарний коефіцієнт відбиття досягає майже `R_sum ≈ 2 · R = 0.0718` (близько 7.2%).

Зворотні втрати (*Optical Return Loss*, `RL`) описують відношення падаючої потужності до відбитої в децибелах:

```text
RL = −10 · log₁₀(R_sum)               [визначення зворотних втрат у дБ]
   = −10 · log₁₀(0.0718)              [підстановка сумарного коефіцієнта R_sum]
   = 11.4 дБ                          [підсумковий рівень зворотних втрат]
```

Це означає, що плоский механічний стик без іммерсійного гелю відкидає назад у бік джерела понад 7% потужності сигнального імпульсу (`RL ≈ 11.4 дБ`), що нищить стабільність лазера. Використання полірування APC (зріз під кутом 8°) або іммерсійного гелю з `n₀ ≈ n₁` знижує відбиття до `RL > 60 дБ` (`R < 0.000001`).
