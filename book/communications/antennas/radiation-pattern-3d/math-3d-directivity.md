# 🧮 Математика 3D-спрямованості та тілесного кута

Обчислення коефіцієнта спрямованої дії (КСД) та еквівалентного тілесного кута вимагає точного математичного інтегрування інтенсивності випромінювання `U(θ, ϕ)` по повній сфері одиничного радіуса. Ця вставка містить аналітичне виведення ключових математичних співвідношень 3D-діаграми для еталонних та реальних антен, а також детальний аналіз оціночних наближень Крауса, Картера та Стуцмана.

---

### Геометрія сфери та диференціал тілесного кута

У тривимірній сферичній системі координат кожна точка на одиничній сфері визначається зенітним кутом `θ ∈ [0, π]` та азимутальним кутом `ϕ ∈ [0, 2π]`. Для обчислення потоку випромінюваної енергії необхідно визначити диференціальний елемент поверхні сфери `dA` на відстані `r` від джерела.

При зміні кута `θ` на малу величину `dθ` дуга уздовж меридіана має довжину `dl_θ = r · dθ`. При зміні азимутального кута `ϕ` на `dϕ` довжина паралельного кола залежить від відстані до осі `Z`, тобто від радіуса `r · sin(θ)`. Відповідно, дуга уздовж паралелі дорівнює `dl_ϕ = r · sin(θ) · dϕ`.

Елемент площі сфери дорівнює добутку цих двох дуг:

```
dA = dl_θ · dl_ϕ = r² · sin(θ) · dθ · dϕ   [елемент площі сфери]
```

Оскільки тілесний кут `dΩ` за визначенням є відношенням елемента площі до квадрата радіуса `dA / r²`, диференціал тілесного кута у сферичних координатах набуває вигляду:

```
dΩ = sin(θ) · dθ · dϕ   [стерадіан]
```

Зверніть увагу на ваговий множник `sin(θ)`: при `θ = 90°` (на екваторі) `sin(90°) = 1`, і площа осередку `dθ · dϕ` є максимальною. При наближенні до полюсів (`θ → 0°` або `θ → π`) `sin(θ) → 0`, тому фізична площа осередка прямує до нуля, хоча кутові кроки `dθ` та `dϕ` залишаються незмінними.

### Загальний інтеграл повної потужності та КСД

Повна випромінювана потужність `P_rad` визначається як подвійний інтеграл від інтенсивності випромінювання `U(θ, ϕ)` по повній сфері:

```
P_rad
= ∫₀²ᵖʰⁱ ∫₀ᵖʰⁱ U(θ, ϕ) · sin(θ) dθ dϕ    [загальна формула повної потужності]
```

Середня інтенсивність випромінювання `U₀` еквівалентної ізотропної антени становить відношення повної потужності до повного тілесного кута сфери `4·π` стерадіан:

```
U₀
= P_rad / (4·π)
= (1 / (4·π)) · ∫₀²ᵖʰⁱ ∫₀ᵖʰⁱ U(θ, ϕ) · sin(θ) dθ dϕ    [середнє значення інтенсивності]
```

Звідси максимальна спрямованість `D_max` виражається як відношення максимальної інтенсивності випромінювання `U_max` до середньої `U₀`:

```
D_max
= U_max / U₀
= 4·π · U_max / P_rad
= 4·π / [ (1 / U_max) · ∫₀²ᵖʰⁱ ∫₀ᵖʰⁱ U(θ, ϕ) · sin(θ) dθ dϕ ]    [формула КСД]
```

Величина у знаменнику називається **просторовим тілесним кутом променя** `Ω_A` (*beam solid angle*):

```
Ω_A
= ∫₀²ᵖʰⁱ ∫₀ᵖʰⁱ [ U(θ, ϕ) / U_max ] · sin(θ) dθ dϕ    [тілесний кут у стерадіанах]
```

Отже, фундаментальний зв'язок між спрямованістю та тілесним кутом виражається простою формулою:

```
D_max = 4·π / Ω_A
```

### Точне аналітичне виведення для еталонних джерел

#### 1. Ізотропний випромінювач

Для ідеальної точкової ізотропної антени випромінювання однакове в усіх напрямках простору: `U(θ, ϕ) = U₀ = const`.

```
P_rad
= U₀ · ∫₀²ᵖʰⁱ dϕ · ∫₀ᵖʰⁱ sin(θ) dθ
= U₀ · (2·π) · [ -cos(θ) ]₀ᵖʰⁱ
= U₀ · 2·π · (1 - (-1))
= 4·π · U₀                              [підтвердження інтеграла сфери]

D_max = 4·π · U₀ / (4·π · U₀) = 1       [0 дБі, нульовий відлік]
```

#### 2. Елементарний (герців) диполь

Інтенсивність випромінювання короткого диполя довжиною `l << λ` описується функцією `U(θ) = U_max · sin²(θ)` і має азимутальну симетрію (не залежить від `ϕ`):

```
P_rad
= U_max · ∫₀²ᵖʰⁱ dϕ · ∫₀ᵖʰⁱ sin³(θ) dθ
= U_max · 2·π · ∫₀ᵖʰⁱ (1 - cos²(θ)) · sin(θ) dθ    [заміна t = cos(θ), dt = -sin(θ) dθ]
= U_max · 2·π · [ -cos(θ) + (1/3)·cos³(θ) ]₀ᵖʰⁱ
= U_max · 2·π · [ (1 - 1/3) - (-1 + 1/3) ]
= U_max · 2·π · (4/3)
= (8·π / 3) · U_max                               [повна потужність герцевого диполя]

D_max
= 4·π · U_max / [ (8·π / 3) · U_max ]
= 12 / 8
= 1.5                                             [1.76 дБі]
```

Тілесний кут герцевого диполя дорівнює:

```
Ω_A = 4·π / 1.5 = (8/3)·π ≈ 8.377 steradians
```

#### 3. Напівхвильовий диполь

Для класичного напівхвильового диполя завдовжки `l = λ/2` функція спрямованості має вигляд:

```
U(θ) = U_max · [ cos( (π/2) · cos(θ) ) / sin(θ) ]²
```

Інтеграл повної потужності обчислюється через спеціальну інтегральну функцію косинуса `Ci(x)` або чисельним інтегруванням:

```
P_rad
= 2·π · U_max · ∫₀ᵖʰⁱ [ cos²( (π/2) · cos(θ) ) / sin(θ) ] dθ
≈ 2·π · U_max · 1.2188
≈ 7.658 · U_max

D_max
= 4·π · U_max / (7.658 · U_max)
≈ 12.566 / 7.658
≈ 1.643                                           [2.15 дБі]
```

Тілесний кут напівхвильового диполя дорівнює:

```
Ω_A = 4·π / 1.643 ≈ 7.648 steradians
```

#### 4. Направлена модель випромінювання cosⁿ(θ)

Для багатьох спрямованих антен (патчів, рупорів, дзеркал) головну пелюстку у передній півсфері `θ ∈ [0, π/2]` апроксимують функцією `U(θ) = U_max · cosⁿ(θ)` (де `n ≥ 1` визначає гостроту променя), а у задній півсфері вважають `U = 0`.

Обчислимо точну випромінювану потужність для такої моделі:

```
P_rad
= U_max · ∫₀²ᵖʰⁱ dϕ · ∫₀ᵖʰⁱ/² cosⁿ(θ) · sin(θ) dθ     [заміна t = cos(θ), dt = -sin(θ) dθ]
= 2·π · U_max · [ -cosⁿ⁺¹(θ) / (n + 1) ]₀ᵖʰⁱ/²
= 2·π · U_max · [ 0 - (-1 / (n + 1)) ]
= (2·π / (n + 1)) · U_max                             [повна потужність для cosⁿ(θ)]

D_max
= 4·π · U_max / [ (2·π / (n + 1)) · U_max ]
= 2 · (n + 1)                                         [строга спрямованість моделі cosⁿ]
```

Ця формула чудово ілюструє фізичний принцип: збільшення показника степеня `n` у 2 рази вдвічі звужує 3D-промінь і практично подвоює спрямованість антени.

### Наближені інженерні формули для гострих 3D-променів

Для антен із високим підсиленням (тарілки, решітки), де промінь вузький і відносно симетричний, обчислення точного сферичного інтеграла в полі можна замінити аналітичними наближеннями, що базуються на ширині променя по рівню половинної потужності (-3 дБ) у двох ортогональних площинах: `HPBW_θ` та `HPBW_ϕ` (в радіанах або градусах).

#### 1. Формула Крауса (Kraus Approximation)

Джон Краус запропонував апроксимувати 3D-промінь прямокутним тілесним кутом `Ω_A ≈ HPBW_θ · HPBW_ϕ` (у радіанах):

```
D_max
≈ 4·π / ( HPBW_θ[рад] · HPBW_ϕ[рад] )             [у радіанах]

D_max
≈ (4·π · (180/π)²) / ( HPBW_θ[град] · HPBW_ϕ[град] )
≈ 41253 / ( HPBW_θ° · HPBW_ϕ° )                   [формула Крауса у градусах]
```

#### 2. Формула Тайлера та Перейри (Tai & Pereira Adjustment)

Формула Крауса дає завищені значення підсилення (помилка 1–2 дБ) для антен із помірним підсиленням через неврахування енергії бокових пелюсток. Удосконалена формула Тайлера враховує бічний витік:

```
D_max ≈ 32400 / ( HPBW_θ° · HPBW_ϕ° )
```

#### 3. Формула Стуцмана (Stutzman Approximation)

Для симетричних круглих апертур (скажімо, параболічних тарілок), де `HPBW_θ = HPBW_ϕ = HPBW`, використовують формулу Стуцмана:

```
D_max ≈ 26000 / (HPBW°)²
```

#### Порівняльний аналіз наближень для різної ширини 3D-променя

```
Ширина променя (HPBW_θ × HPBW_ϕ)  |  Точний D_max  |  Формула Крауса  |  Помилка Крауса
---------------------------------------------------------------------------------------
60° × 60° (помірний промінь)      |  10.2 (10.1 дБі)|  11.5 (10.6 дБі) |  +0.5 дБ
20° × 20° (направлена панель)    |  98.4 (19.9 дБі)|  103.1 (20.1 дБі)|  +0.2 дБ
5° × 5°   (параболічна тарілка)   |  1610 (32.1 дБі)|  1650 (32.2 дБі) |  +0.1 дБ
```

З таблиці видно: чим вужчий тривимірний промінь (чим більша спрямованість), тим точніше формула Крауса описує справжній тілесний кут `Ω_A`.

### Задньо-переднє відношення (F/B) та аналіз 3D-витоків

Окрім спрямованості `D_max`, 3D-діаграма дозволяє математично визначити коефіцієнт захисної дії або задньо-переднє відношення (*Front-to-Back Ratio, F/B*).

Для 3D-діаграми задньо-переднє відношення визначається як відношення пікової інтенсивності у головній півсфері до максимуму інтенсивності у конусі задньої півсфери `θ ∈ [2·π/3, π]`:

```
F/B_ratio = U_max(передній конус) / U_max(задній конус)
F/B_dB = 10 · log₁₀(F/B_ratio)
```

Аналогічно визначають коефіцієнт пригнічення бокових пелюсток (*Side-Lobe Level, SLL*):

```
SLL_dB = 10 · log₁₀( U_sidelobe_max / U_max )
```

У високоточних системах зв'язку знання 3D-параметрів `F/B` та `SLL` дозволяє математично оцінити стійкість приймача до завад із навколишніх напрямків та пригнічення відбиттів від підстилаючої поверхні землі.

### Дискретизація та похибки чисельного інтегрування

При переході від неперервного інтеграла до дискретної суми по сітці `(Δθ, Δϕ)` виникає похибка дискретизації. Повна випромінювана потужність обчислюється як:

```
P_rad ≈ Δθ · Δϕ · ∑ᵢ₌₀ᴺᵗʰᵉᵗᵃ⁻¹ ∑ⱼ₌₀ᴺᵖʰⁱ⁻¹ U(θ_i, ϕ_j) · sin(θ_i)
```

Для мінімізації похибки обчислення дотримуються трьох математичних правил:
1. **Крок дискретизації `Δθ` та `Δϕ`** має бути принаймні в 3–5 разів меншим за ширину найвужчої пелюстки 3D-діаграми `HPBW`.
2. **Обробка полюсів (`θ = 0` та `θ = π`).** Оскільки `sin(0) = sin(π) = 0`, значення `U(0, ϕ)` та `U(π, ϕ)` беруть один раз, не дублюючи їх по всіх кутах `ϕ_j`.
3. **Метод трапецій.** Вузлові точки на межах інтегрування (`i = 0`, `i = N_θ`) та (`j = 0`, `j = N_ϕ`) входять у суму з ваговим коефіцієнтом `1/2`.
