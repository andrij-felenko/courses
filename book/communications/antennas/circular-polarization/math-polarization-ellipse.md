# 🧮 Параметри Стокса, сфера Пуанкаре та математика поляризаційного еліпса

### Алгебраїчне виведення рівняння поляризаційного еліпса

Розглянемо гармонічну плоско-паралельну електромагнітну хвилю, що поширюється вздовж осі `z`. Ортогональні складові вектора електричного поля `E` у площині `z = 0` задаються виразами:

```
E_x(t) = E₀x · cos(ω·t)
E_y(t) = E₀y · cos(ω·t + δ)
```

де `E₀x > 0` та `E₀y > 0` — амплітуди компонент, `ω` — кругова частота, а `δ` — фазовий зсув складової `E_y` відносно `E_x`.

Щоб знайти геометричну траєкторію кінця вектора `E(t)` у площині `(E_x, E_y)`, необхідно виключити часовий параметр `t` із системи рівнянь.

Скористаємося тригонометричним розкладом для `E_y(t)`:

```
E_y / E₀y = cos(ω·t + δ)
          = cos(ω·t)·cos(δ) - sin(ω·t)·sin(δ)      [тригонометрична тотожність додавання фази]
```

З першого рівняння виражаємо `cos(ω·t)` та `sin(ω·t)`:

```
cos(ω·t) = E_x / E₀x
sin(ω·t) = √(1 - (E_x / E₀x)²)                       [основна тригонометрична тотожність]
```

Підставляємо значення `cos(ω·t)` та `sin(ω·t)` у розкладений вираз для `E_y / E₀y`:

```
E_y / E₀y = (E_x / E₀x)·cos(δ) - √(1 - (E_x / E₀x)²)·sin(δ)
```

Переносимо доданок `(E_x / E₀x)·cos(δ)` у ліву частину:

```
(E_y / E₀y) - (E_x / E₀x)·cos(δ) = - √(1 - (E_x / E₀x)²)·sin(δ)
```

Підносимо обидві частини рівняння до квадрата:

```
[(E_y / E₀y) - (E_x / E₀x)·cos(δ)]² = [1 - (E_x / E₀x)²]·sin²(δ)
```

Розкриваємо дужки у лівій частині:

```
(E_y / E₀y)² - 2·(E_x / E₀x)·(E_y / E₀y)·cos(δ) + (E_x / E₀x)²·cos²(δ)
= sin²(δ) - (E_x / E₀x)²·sin²(δ)
```

Переносимо доданок `(E_x / E₀x)²·sin²(δ)` у ліву частину та групуємо за допомогою тотожності `cos²(δ) + sin²(δ) = 1`:

```
(E_x / E₀x)²·[cos²(δ) + sin²(δ)] - 2·(E_x / E₀x)·(E_y / E₀y)·cos(δ) + (E_y / E₀y)² = sin²(δ)
```

Отримуємо **канонічне рівняння поляризаційного еліпса**:

```
(E_x / E₀x)² - 2·(E_x / E₀x)·(E_y / E₀y)·cos(δ) + (E_y / E₀y)² = sin²(δ)
```

Це квадратична форма відносно `E_x` та `E_y`, яка описує еліпс у декартовій системі координат, повернутий на кут нахилу `τ` відносно осі `x`.

### Діагоналізація квадратичної форми та обчислення орієнтації еліпса

Для визначення головних осей еліпса та його кута орієнтації `τ` запишемо отримати квадратичну форму в матричному вигляді:

```
[E_x  E_y] · [    1 / E₀x²        -cos(δ)/(E₀x·E₀y) ] · [ E_x ] = sin²(δ)
             [ -cos(δ)/(E₀x·E₀y)      1 / E₀y²      ]   [ E_y ]
```

Поворотом системи координат на кут `τ` матриця зводиться до діагонального вигляду:

```
(E_x' / a)² + (E_y' / b)² = 1
```

де `a` — велика піввісь еліпса, а `b` — мала піввісь еліпса.

Кут нахилу великої осі `τ` відносно осі `x` визначається з умови обнулення перехресного члена при повороті координат. Використовуючи формули подвійного кута, отримуємо:

```
tan(2·τ) = [2·E₀x·E₀y / (E₀x² - E₀y²)] · cos(δ)
```

Діапазон зміни кута нахилу становить `-90° ≤ τ ≤ 90°` (або `-π/2 ≤ τ ≤ π/2`).

Для обчислення довжин півосей `a` та `b` виведемо інваріанти квадратичної форми:

```
a² + b² = E₀x² + E₀y²
a · b = E₀x · E₀y · |sin(δ)|
```

Ці дві фундаментальні рівності виражають збереження повної енергії електричного поля та площі поляризаційного еліпса.

Аналітичні вирази для великої `a` та малої `b` півосей мають вигляд:

```
a = √[ 0.5 · (E₀x² + E₀y² + √((E₀x² - E₀y²)² + 4·E₀x²·E₀y²·cos²(δ))) ]
b = √[ 0.5 · (E₀x² + E₀y² - √((E₀x² - E₀y²)² + 4·E₀x²·E₀y²·cos²(δ))) ]
```

Кут еліптичності `χ` визначається як тангенс відношення півосей:

```
tan(χ) = ± b / a,   (-45° ≤ χ ≤ 45°)
```

де знак плюс відповідає лівому напрямку обертання (LHCP), а знак мінус — правому (RHCP). Звідси випливає точна формульна залежність:

```
sin(2·χ) = [2·E₀x·E₀y / (E₀x² + E₀y²)] · sin(δ)
```

Осьове відношення `AR` виражається через кут `χ`:

```
AR = a / b = 1 / |tan(χ)| = |cot(χ)|
AR_dB = 20 · log₁₀(a / b)
```

### Параметри Стокса (Stokes Parameters)

У 1852 році Джордж Габрієль Стокс ввів вектор із чотирьох дійсних параметрів `S = [S₀, S₁, S₂, S₃]^T`, кожен з яких має розмірність інтенсивності (потужності) і може бути безпосередньо виміряний за допомогою стандартних поляризаційних фільтрів та детекторів:

```
S₀ = E₀x² + E₀y²                     [загальна інтенсивність хвилі]
S₁ = E₀x² - E₀y²                     [переважання горизонтальної поляризації над вертикальною]
S₂ = 2·E₀x·E₀y·cos(δ)                 [переважання поляризації +45° над −45°]
S₃ = 2·E₀x·E₀y·sin(δ)                 [переважання правої кругової поляризації над лівою]
```

Для повністю поляризованої хвилі між параметрами Стокса існує сувора квадратична тотожність:

```
S₀² = S₁² + S₂² + S₃²
```

Якщо хвиля є частково поляризованою (наприклад, містить тепловий шум або випадкові деполяризовані відбиття), виконується нерівність:

```
S₀² ≥ S₁² + S₂² + S₃²
```

Ступінь поляризації хвилі (*Degree of Polarization*, **DoP**) визначається як відношення інтенсивності поляризованої частини до загальної інтенсивності сигналу:

```
DoP = √(S₁² + S₂² + S₃²) / S₀,   (0 ≤ DoP ≤ 1)
```

Зв'язок параметрів Стокса з геометричними кутами `τ` (нахил) та `χ` (еліптичність):

```
S₁ = S₀ · cos(2·χ) · cos(2·τ)
S₂ = S₀ · cos(2·χ) · sin(2·τ)
S₃ = S₀ · sin(2·χ)
```

Нормовані параметри Стокса утворюються діленням на загальну інтенсивність `S₀`:

```
s₁ = S₁ / S₀,   s₂ = S₂ / S₀,   s₃ = S₃ / S₀
s₁² + s₂² + s₃² = 1.0
```

Геометричний зміст нормованого вектора Стокса `s = (s₁, s₂, s₃)` полягає у вираженні координати точки поляризаційного стану на одиничній сфері Пуанкаре.

### Векторний апарат Джонса (Jones Vectors) та матриці Мюллера

Для обчислення поширення поляризованої хвилі через послідовність пасивних НВЧ-пристроїв (фазоповертачі, поляризатори, атенюатори) використовують дві математичні системи: комплексні вектори Джонса (для повністю поляризованого когерентного сигналу) та реальні матриці Мюллера (для частково поляризованих та некогерентних сигналів).

Вектор Джонса являє собою двохкомпонентний комплексний стовпчик:

```
J = [ E₀x         ]
    [ E₀y · e^(j·δ) ]
```

Нормований вектор Джонса для основних станів поляризації:

1. **Горизонтальна лінійна (H):** `J_H = [1, 0]^T`
2. **Вертикальна лінійна (V):** `J_V = [0, 1]^T`
3. **Лінійна під кутом 45° (D):** `J_D = (1/√2) · [1, 1]^T`
4. **Права колова (RHCP):** `J_RHCP = (1/√2) · [1, -j]^T`
5. **Ліва колова (LHCP):** `J_LHCP = (1/√2) · [1, +j]^T`

Скалярний добуток векторів Джонса передавача `J_t` та приймача `J_r` дозволяє обчислити коефіцієнт поляризаційних втрат:

```
PLF = |J_t · J_r*|²
```

де `J_r*` — комплексно-спряжений вектор приймальної антени.

Матриця Джонса `M` розміром `2×2` описує дію фазоповертача чи поляризатора на вектор хвилі:

```
J_out = M · J_in
```

Наприклад, матриця ідеального 90-градусного фазоповертача для вертикального каналу має вигляд `M_90 = [1, 0; 0, -j]`. Подача на її вхід лінійної хвилі під кутом 45° `J_in = (1/√2)·[1, 1]^T` дає на виході:

```
J_out = (1/√2) · [1, 0; 0, -j] · [1, 1]^T = (1/√2) · [1, -j]^T  (RHCP)
```

Це математично пояснює механізм роботи 90-градусних диференціальних фазових секцій у хвилеводах та квадратурних мостах.

Для некогерентних сигналів проходження хвилі описується дійсною матрицею Мюллера `M_m` розміром `4×4`, яка діє на вектор Стокса:

```
S_out = M_m · S_in
```

### Сфера Пуанкаре (Poincaré Sphere)

Сфера Пуанкаре являє собою тривимірний геометричний простір, де кожен стан 100% поляризованої хвилі відображається унікальною точкою на поверхні сфери радіуса `R = 1`.

Декартовими координатами точки є нормовані параметри Стокса `(s₁, s₂, s₃)`, а сферичними кутами — `(2·τ, 2·χ)`:
- **Довгота:** `2·τ` (від `0°` до `360°`).
- **Широта:** `2·χ` (від `-90°` до `+90°`).

Топологічні властивості сфери Пуанкаре:
1. **Північний полюс (`2·χ = +90°`, `s₃ = +1`):** Чиста колова поляризація RHCP.
2. **Південний полюс (`2·χ = -90°`, `s₃ = -1`):** Чиста колова поляризація LHCP.
3. **Екватор (`2·χ = 0°`, `s₃ = 0`):** Усі лінійні поляризації.
4. **Ортогональні стани:** Два ортогональні стани поляризації (наприклад, RHCP та LHCP) лежать на протилежних кінцях діаметра сфери (антиподи, відстань `180°`).

Кутова відстань `Θ` між двома точками `P₁` та `P₂` на сфері Пуанкаре пов'язана з коефіцієнтом втрат PLF формулою:

```
PLF = cos²(Θ / 2) = 0.5 · [1 + s₁t·s₁r + s₂t·s₂r + s₃t·s₃r]
```

### Практичні приклади покрокового розрахунку

#### Приклад 1: Обчислення параметрів еліпса за амплітудами та фазою

```
[Початкові дані]
Амплітуди поля: E₀x = 2.0 В/м,  E₀y = 1.0 В/м
Різниця фаз: δ = 120°  (2.094 rad)

[Крок 1: Обчислення параметрів Стокса]
S₀ = 2.0² + 1.0² = 4.0 + 1.0 = 5.0
S₁ = 2.0² - 1.0² = 4.0 - 1.0 = 3.0
S₂ = 2 · 2.0 · 1.0 · cos(120°) = 4.0 · (-0.5) = -2.0
S₃ = 2 · 2.0 · 1.0 · sin(120°) = 4.0 · 0.8660 = 3.4641

[Перевірка тотожності Стокса]
S₁² + S₂² + S₃² = 3.0² + (-2.0)² + 3.4641² = 9.0 + 4.0 + 12.0 = 25.0 = S₀²    [ОК]

[Крок 2: Обчислення нормованого вектора Стокса]
s₁ = 3.0 / 5.0 = 0.600
s₂ = -2.0 / 5.0 = -0.400
s₃ = 3.4641 / 5.0 = 0.6928

[Крок 3: Обчислення кутів нахилу τ та еліптичності χ]
two_tau = atan2(S₂, S₁) = atan2(-2.0, 3.0) = -33.69°
tau = -33.69° / 2 = -16.85°

sin_two_chi = s₃ = 0.6928
two_chi = asin(0.6928) = 43.85°
chi = 43.85° / 2 = 21.93°

[Крок 4: Обчислення великої та малої півосей]
a = √(S₀) · cos(chi) = √(5.0) · cos(21.93°) = 2.2361 · 0.9276 = 2.074 В/м
b = √(S₀) · sin(chi) = √(5.0) · sin(21.93°) = 2.2361 · 0.3735 = 0.835 В/м

[Крок 5: Обчислення осьового відношення AR]
AR_linear = a / b = 2.074 / 0.835 = 2.484
AR_dB = 20 · log₁₀(2.484) = 7.90 дБ
Напрямок обертання: s₃ > 0 → Праве обертання (RHCP)
```

#### Приклад 2: Розрахунок втрат PLF між двома еліптичними антенами

```
[Початкові дані]
Передавач (еліптичний стан 1):  s_t = (0.500,  0.500,  0.7071)
Приймач   (еліптичний стан 2):  s_r = (0.000, -0.600,  0.8000)

[Крок 1: Скалярний добуток векторів Стокса]
s_t · s_r = (0.500 · 0.000) + (0.500 · (-0.600)) + (0.7071 · 0.8000)
          = 0.000 - 0.300 + 0.5657
          = 0.2657

[Крок 2: Обчислення PLF]
PLF = 0.5 · (1 + s_t · s_r)
    = 0.5 · (1 + 0.2657)
    = 0.63285

[Крок 3: Переведення у децибели]
Loss_dB = 10 · log₁₀(0.63285) = -1.987 дБ
```

#### Приклад 3: Перетворення вектора Джонса при проходженні через фазову пластину

```
[Початкові дані]
Вхідний вектор Джонса (лінійна під кутом 45°): J_in = (1/√2) · [1, 1]^T
Фазова пластина (зсув фази y-компоненти на 90°): M = [1, 0; 0, e^(-j·π/2)] = [1, 0; 0, -j]

[Розрахунок вихідного вектора]
J_out = M · J_in
      = (1/√2) · [1, 0; 0, -j] · [1, 1]^T
      = (1/√2) · [1, -j]^T

[Аналіз стану]
Амплітуди: |J_x| = 1/√2,  |J_y| = |-j/√2| = 1/√2
Різниця фаз: arg(J_y) - arg(J_x) = -π/2 = -90°
Результат: Ідеальна права колова поляризація (RHCP) з AR = 0.0 дБ
```
