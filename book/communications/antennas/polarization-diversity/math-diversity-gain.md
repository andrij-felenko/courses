# 🧮 Математика виграшу поляризаційного різноманіття

У цьому матеріалі наведено строгий математичний аналіз та виведення статистичних характеристик поляризаційного різноманіття в радіоканалах із замираннями Релея (Rayleigh fading). Розглянуто двовимірні векторні моделі розсіювання електромагнітних хвиль, виведено функціональні залежності ймовірності обриву зв'язку (outage probability) та аналітично розраховано виграш рознесеного прийому (diversity gain) для методів Selection Combining (SC), Equal Gain Combining (EGC) та Maximal Ratio Combining (MRC) з урахуванням взаємної кореляції та дисбалансу потужностей гілок.

---

### 1. Двовимірна векторна модель деполяризації радіоканалу

При поширенні електромагнітної хвилі в багатопроменевому середовищі вектор електричного поля переданого сигналу `E_tx = [E_v, E_h]^T` зазнає лінійного перетворення під дією багаторазових відбиттів від навколишніх об'єктів. Зв'язок між переданим і прийнятим векторами поля описується комплексною матрицею каналу розміром 2×2:

```
┌      ┐   ┌                ┐ ┌      ┐   ┌      ┐
│ E_rx1│ = │ h_vv    h_vh   │ │ E_tx1│ + │ n_1  │
│ E_rx2│   │ h_hv    h_hh   │ │ E_tx2│   │ n_2  │
└      ┘   └                ┘ └      ┘   └      ┘
```

де `h_vv`, `h_hh` — коефіцієнти передачі каналу в основній поляризації (прямі складові), a `h_vh`, `h_hv` — крос-поляризаційні коефіцієнти розсіювання, що виникають унаслідок деполяризації хвиль на рельєфі та будинках.

За відсутності лінії прямої видимості (Line-of-Sight, LoS) усі чотири коефіцієнти `h_ij` можна вважати незалежними комплексними гауссівськими випадковими величинами з нульовим середнім значенням:

```
h_ij = x_ij + j · y_ij     [де x_ij, y_ij ~ N(0, σ_ij²)]
```

Амплітуда прийнятого сигналу `r = |h_ij| = √(x_ij² + y_ij²)` підпорядковується розподілу Релея з густиною ймовірності:

```
p_r(r) = (r / σ²) · exp(−r² / (2 σ²))     [для r ≥ 0, де σ² — дисперсія дійсної та уявної частин]
```

Миттєве відношення сигнал/шум `γ` на прийомі є квадратним функціоналом амплітуди `γ = r² · E_s / N₀`. Переходячи до нової випадкової величини `γ`, отримуємо класичний експоненційний розподіл миттєвого SNR для одного каналу:

```
p(γ) = (1 / γ̄) · exp(−γ / γ̄)     [густина експоненційного розподілу при γ ≥ 0, де γ̄ = E[γ] — середня потужність SNR]
```

### 2. Ймовірність обриву зв'язку для одного каналу (Одноканальний орієнтир)

Ймовірність обриву зв'язку `P_out` визначається як математичне сподівання події, при якій миттєве значення SNR `γ` падає нижче порогового значення `γ_th`, необхідного для роботи демодулятора з заданим рівнем помилок (BER):

```
P_out^(1)(γ_th) = P(γ ≤ γ_th)          [визначення ймовірності обриву як інтегральної функції розподілу CDF]
                = ∫₀^(γ_th) p(γ) dγ     [інтегрування густини експоненційного розподілу від 0 до γ_th]
                = 1 − exp(−γ_th / γ̄)    [первісна експоненти: ∫ exp(−ax) dx = −(1/a) exp(−ax)]
```

Для аналізу поведінки системи в зоні малої ймовірності помилок (`γ_th << γ̄`), використавши розклад функції `exp(−x)` у ряд Тейлора `exp(−x) = 1 − x + x²/2 − …`:

```
P_out^(1)(γ_th) = 1 − (1 − γ_th / γ̄ + O((γ_th / γ̄)²))
                ≈ γ_th / γ̄              [лінійна апроксимація для γ_th << γ̄]
```

Ця формула демонструє фундаментальний висновок: в одноканальному каналі Релея ймовірність обриву зв'язку спадає **першою степеню** від середнього відношення сигнал/шум.

Обчислимо математичне сподівання середнього SNR для 1 каналу:

```
E[γ] = ∫₀^∞ γ · (1 / γ̄) exp(−γ / γ̄) dγ = γ̄     [середнє значення миттєвого SNR дорівнює γ̄]
```

Щоб зменшити ймовірність обриву в 100 разів (наприклад, від 10% до 0.1%), необхідно збільшити середній SNR передавача `γ̄` в 100 разів, тобто додати **20 дБ** до бюджету радіолінії. Це явище називають високою платою за замирання (*fading margin penalty*).

### 3. Вибірне об'єднання (Selection Combining, SC)

При вибірному об'єднанні приймач вимірює миттєві значення `γ₁` та `γ₂` на двох рознесених за поляризацією портах і підключає до демодулятора канал із максимальним значеним SNR:

```
γ_sc = max(γ₁, γ₂)     [алгоритм SC: вибір каналу з максимальним миттєвим SNR]
```

#### Ідеальні незалежні канали (`ρ = 0`)

Якщо замирання в двох поляризаціях повністю незалежні, система виходить із ладу тоді й тільки тоді, коли обидва канали одночасно провалюються нижче порогу `γ_th`:

```
P_out^(2,sc)(γ_th) = P(max(γ₁, γ₂) ≤ γ_th)
                  = P(γ₁ ≤ γ_th AND γ₂ ≤ γ_th)      [умова одночасного провалу обох каналів]
                  = P(γ₁ ≤ γ_th) · P(γ₂ ≤ γ_th)     [добуток ймовірностей для двох незалежних подій]
                  = (1 − exp(−γ_th / γ̄))²          [підстановка одноканальної функції CDF]
```

Застосувавши лінійне наближення Тейлора при `γ_th << γ̄`:

```
P_out^(2,sc)(γ_th) ≈ (γ_th / γ̄)²                    [квадратична залежність ймовірності обриву SC]
```

Обчислимо математичне сподівання середнього SNR на виході SC:

```
E[γ_sc] = ∫₀^∞ (1 − (1 − exp(−γ / γ̄))²) dγ
        = ∫₀^∞ (2 exp(−γ / γ̄) − exp(−2γ / γ̄)) dγ
        = 2 γ̄ − (γ̄ / 2) = 1.5 · γ̄                   [середнє вихідне SNR збільшується у 1.5 раза (1.76 дБ)]
```

Зміна степеня з 1 на 2 означає подвоєння похилу кривої замирань. Знайдемо необхідний запас SNR `γ̄ / γ_th` для різних рівнів надійності лінії:

- Для `P_out = 0.01` (1% обривів):
  `(γ_th / γ̄)² = 0.01` ⇒ `γ̄ / γ_th = √100 = 10` (**10 дБ** запасу замість 20 дБ для 1 антени).
- Для `P_out = 0.001` (0.1% обривів):
  `(γ_th / γ̄)² = 0.001` ⇒ `γ̄ / γ_th = √1000 ≈ 31.6` (**15 дБ** запасу замість 30 дБ для 1 антени).

Чистий виграш рознесення SC (Diversity Gain) на рівні `P_out = 1%`:

```
G_sc = 20 дБ − 10 дБ = 10 дБ     [виграш запасу потужності завдяки SC рознесенню]
```

### 4. Об'єднання з однаковим підсиленням (Equal Gain Combining, EGC)

У схемі EGC вирівнюються лише фази сигналів `θ₁, θ₂`, а амплітуди додаються з однаковими вагами:

```
r_egc = r₁ + r₂     [сума амплітуд сигналів двох гілок]
```

Миттєве значення SNR на виході EGC дорівнює:

```
γ_egc = (r₁ + r₂)² · (E_s / (2 N₀)) = (1/2) · (√γ₁ + √γ₂)² = (1/2) · (γ₁ + γ₂ + 2 √(γ₁ γ₂))
```

Обчислимо математичне сподівання середнього SNR на виході EGC для незалежних каналів (`E[√γ] = (√π / 2) √γ̄`):

```
E[γ_egc] = (1/2) · (γ̄ + γ̄ + 2 (√π / 2)² γ̄)
         = γ̄ · (1 + π / 4) ≈ 1.785 · γ̄              [середній SNR зростає у 1.785 раза (2.51 дБ)]
```

Асимптотична ймовірність обриву EGC для малих `γ_th << γ̄`:

```
P_out^(2,egc)(γ_th) ≈ (1 − π / 4) · (γ_th / γ̄)² ≈ 0.215 · (γ_th / γ̄)²     [квадратична залежність EGC]
```

EGC випереджає SC за виграшем на **1.2 дБ**, поступаючись MRC лише на **0.5 дБ**, але не вимагає вимірювання амплітуд сигналів.

---

### 5. Максимально-пропорційне об'єднання (Maximal Ratio Combining, MRC)

При максимально-пропорційному об'єднанні когерентно підсумовуються сигнали двох поляризацій із ваговими коефіцієнтами, пропорційними комплексно-спряженим амплітудам каналів `w_i = h_i*`.

Результуючий миттєвий SNR дорівнює алгебраїчній сумі миттєвих SNR обох гілок:

```
γ_mrc = γ₁ + γ₂     [пряма сума миттєвих SNR при когерентному MRC об'єднанні]
```

Обчислимо математичне сподівання середнього SNR на виході MRC:

```
E[γ_mrc] = E[γ₁] + E[γ₂] = γ̄ + γ̄ = 2 · γ̄       [середній SNR подвоюється (+3.01 дБ антенного підсилення)]
```

#### Математичний розрахунок густини ймовірності суми

Розподіл суми двох незалежних однакових експоненційних випадкових величин `γ₁, γ₂ ~ Exp(γ̄)` визначається операцією згортки двох густин `p(γ)`:

```
p_mrc(γ) = ∫₀^(γ) p(γ₁) · p(γ − γ₁) dγ₁     [згортка двох експоненційних густин]
         = ∫₀^(γ) (1 / γ̄) e^(−γ₁ / γ̄) · (1 / γ̄) e^(−(γ − γ₁) / γ̄) dγ₁
         = (1 / γ̄²) e^(−γ / γ̄) ∫₀^(γ) 1 dγ₁     [винесення спільного експоненційного множника]
         = (γ / γ̄²) · exp(−γ / γ̄)               [густина розподілу Ерланга 2-го порядку / Хі-квадрат 4 d.o.f.]
```

#### Інтегрування ймовірності обриву MRC

Ймовірність обриву `P_out` обчислюється шляхом інтегрування густини Ерланга від 0 до `γ_th`:

```
P_out^(2,mrc)(γ_th) = ∫₀^(γ_th) (γ / γ̄²) exp(−γ / γ̄) dγ     [інтеграл виходу MRC]
```

Застосуємо метод інтегрування частинами (`∫ u dv = u v − ∫ v du`), узявши `u = γ`, `dv = exp(−γ / γ̄) dγ`:

```
P_out^(2,mrc)(γ_th) = [ −(γ / γ̄) exp(−γ / γ̄) ]₀^(γ_th) + ∫₀^(γ_th) (1 / γ̄) exp(−γ / γ̄) dγ
                    = −(γ_th / γ̄) exp(−γ_th / γ̄) + (1 − exp(−γ_th / γ̄))
                    = 1 − exp(−γ_th / γ̄) · (1 + γ_th / γ̄)     [точний вираз ймовірності обриву MRC]
```

Розкладемо експоненціальний множник у ряд Тейлора другого порядку `exp(−x) = 1 − x + x²/2 − O(x³)`:

```
P_out^(2,mrc)(γ_th) = 1 − (1 − γ_th / γ̄ + (1/2) (γ_th / γ̄)²) · (1 + γ_th / γ̄)
                    = 1 − (1 + γ_th / γ̄ − γ_th / γ̄ − (γ_th / γ̄)² + (1/2) (γ_th / γ̄)² + O(x³))
                    ≈ (1/2) · (γ_th / γ̄)²                     [квадратична апроксимація MRC при γ_th << γ̄]
```

Обчислимо необхідний середній SNR для досягнення `P_out = 0.01` (99% надійності):

```
(1/2) · (γ_th / γ̄)² = 0.01
(γ_th / γ̄)² = 0.02
γ̄ / γ_th = √(1 / 0.02) = √50 ≈ 7.071     [еквівалентно 8.49 дБ]
```

Порівняльний виграш MRC над одноканальним прийомом на рівні `P_out = 1%`:

```
G_mrc = 20 дБ − 8.49 дБ = 11.51 дБ     [чистий виграш рознесення MRC]
```

Додатково за рахунок когерентного підсумування потужності з двох антен MRC забезпечує ще **+3 дБ** антенного накопичення (Array Gain), тому сумарний виграш досягає **14.5 дБ**.

### 6. Моментні твірні функції (MGF) та спектральний розклад корельованого MRC

Строгий вивід сумарного SNR для двох корельованих Релеєвських каналів найзручніше здійснювати через характеристичні функції або моментні твірні функції MGF (Moment Generating Function):

```
M_γ(s) = E[exp(−s · γ)]     [визначення MGF для миттєвого SNR]
```

Для одного каналу Релея MGF дорівнює: `M_γ(s) = 1 / (1 + s · γ̄)`.

У випадку двох корельованих каналів коваріаційна матриця SNR `R_h` має вигляд:

```
R_h = γ̄ · ┌                ┐
           │   1     ρ_c   │
           │  ρ_c*    1    │
           └                ┘
```

Власні значення матриці `R_h` обчислюються з характеристики `det(R_h − λ I) = 0`:

```
(γ̄ − λ)² − |ρ_c|² γ̄² = 0
λ₁ = γ̄ · (1 + |ρ_c|)
λ₂ = γ̄ · (1 − |ρ_c|)     [власні значення коваріаційної матриці 2x2]
```

Моментна твірна функція сумарного SNR на виході MRC дорівнює добутку MGF уздовж власних векторів:

```
M_mrc(s) = det(I + s R_h)⁻¹ = 1 / ((1 + s λ₁) · (1 + s λ₂))     [двополюсна MGF суми MRC]
```

Розкладемо дріб `M_mrc(s)` на прості дроби:

```
M_mrc(s) = (λ₁ / (λ₁ − λ₂)) · (1 / (1 + s λ₁)) − (λ₂ / (λ₁ − λ₂)) · (1 / (1 + s λ₂))
```

Виконаємо обернене перетворення Лапласа для кожного простака `L⁻¹{1 / (1 + s λ)} = (1 / λ) exp(−γ / λ)`:

```
p_mrc_corr(γ) = (1 / (λ₁ − λ₂)) · (exp(−γ / λ₁) − exp(−γ / λ₂))     [аналітична густина MRC при кореляції]
```

Інтегруючи `p_mrc_corr(γ)` від 0 до `γ_th`, отримуємо точний закритий вираз ймовірності обриву:

```
P_out^(2,mrc)(γ_th, ρ) = 1 − (λ₁ exp(−γ_th / λ₁) − λ₂ exp(−γ_th / λ₂)) / (λ₁ − λ₂)
```

Для малих порогів `γ_th << γ̄` розклад у ряд Тейлора дає:

```
P_out^(2,mrc)(γ_th, ρ) ≈ (1/2) · (γ_th / γ̄)² / (1 − |ρ_c|²)     [формула обриву MRC при кореляції]
```

### 7. Спектральний розклад сингулярних чисел (SVD) 2x2 поляризаційної матриці

Для розуміння фізики передачі двох потоків даних у режимі 2x2 MIMO скористаємося сингулярним розкладом (Singular Value Decomposition, SVD) комплексної матриці каналу `H`:

```
H = U · Σ · V^H     [де U, V — унітарні матриці, Σ = diag(σ₁, σ₂) — діагональна матриця сингулярних чисел]
```

Сингулярні числа `σ₁` та `σ₂` визначають коефіцієнти підсилення двох незалежних просторово-поляризаційних модових каналів. Вони зв'язані з власними значеннями матриці `H H^H`:

```
λ_1(H H^H) = σ₁²
λ_2(H H^H) = σ₂²
```

Для незашумленого ортогонального рознесення (`XPD >> 1, ρ = 0`) обидва сингулярні числа однакові `σ₁ ≈ σ₂`, що означає наявність двох абсолютно рівноцінних каналів із однаковою пропускною здатністю.

При високій кореляції (`ρ → 1`) одне з сингулярних чисел прямує до нуля `σ₂ → 0`, матриця каналу стає виродженою (виродження рангу `rank(H) = 1`), і можливість передачі двох незалежних MIMO-потоків зникає — канал повертається до одноканального режиму.

### 8. Аналіз впливу взаємної кореляції каналів ρ та маркумовські інтеграли

Двовимірна густина ймовірності двох корельованих релеєвських огинаючих `r₁, r₂` описується двовимірним розподілом з модифікованою функцією Бесселя нульового порядку `I₀(z)`:

```
p(r₁, r₂) = (r₁ r₂ / (σ⁴ (1 − |ρ_c|²))) · exp( −(r₁² + r₂²) / (2 σ² (1 − |ρ_c|²)) ) · I₀( (|ρ_c| r₁ r₂) / (σ² (1 − |ρ_c|²)) )
```

Інтегрування цього розподілу для схеми вибірного об'єднання SC через Маркумовську функцію `Q₁(a,b)` при малому порозі `γ_th << γ̄` дає асимптотичний вираз ймовірності обриву:

```
P_out^(2,sc)(γ_th, ρ) ≈ (γ_th / γ̄)² / (1 − |ρ_c|²)     [формула обриву SC при наявності кореляції]
```

Оцінимо деградацію виграшу рознесення в децибелах як `L_corr = 10 · log₁₀(1 / (1 − |ρ_c|²))`:

```
|ρ_c| = 0.0 : L_corr = 10 · log₁₀(1 / 1.00) = 0.00 дБ   [ідеальні незалежні канали]
|ρ_c| = 0.3 : L_corr = 10 · log₁₀(1 / 0.91) = 0.41 дБ   [типова міська забудова]
|ρ_c| = 0.5 : L_corr = 10 · log₁₀(1 / 0.75) = 1.25 дБ   [допустимий рівень]
|ρ_c| = 0.7 : L_corr = 10 · log₁₀(1 / 0.51) = 2.92 дБ   [межа ефективності рознесення]
|ρ_c| = 0.9 : L_corr = 10 · log₁₀(1 / 0.19) = 7.21 дБ   [критичне деградування системи]
```

### 9. Середня ймовірність побітових помилок (BER) для BPSK та QAM

Середня ймовірність побітових помилок `P_e` визначається усередненням миттєвої ймовірності помилки `P_e(γ) = Q(√(2γ))` за розподілом MRC:

```
P_e_avg = ∫₀^∞ Q(√(2γ)) · p_mrc(γ) dγ     [усереднення BER за замираннями]
```

Для незалежного MRC двох каналів із фазовою маніпуляцією BPSK точний інтегральний результат дорівнює:

```
P_e_bpsk^(2,mrc) = ((1 − μ) / 2)² · (2 + μ) / 2     [де μ = √(γ̄ / (1 + γ̄))]
```

При великих `γ̄ >> 1` вираз спрощується до:

```
P_e_bpsk^(2,mrc) ≈ (3 / (16 · γ̄²))     [квадратичне зниження ймовірності помилки для BPSK з MRC]
```

В одноканальному режимі `P_e_bpsk^(1) ≈ 1 / (4 γ̄)`. Застосування поляризаційного рознесення переводить залежність BER від `1/γ̄` до `1/γ̄²`, що дозволяє підтримувати передачу даних без помилок при набагато нижчому рівні сигналу.

### 10. Ергодична пропускна здатність за Шенноном (Shannon Ergodic Capacity)

Поляризаційне різноманіття підвищує не лише надійність лінії (outage probability), а й ергодичну пропускну здатність каналу `C` (вимірюється в бітах за секунду на герц, біт/с/Гц).

За формулою Шеннона пропускна здатність каналу з миттєвим SNR `γ` становить:

```
C = log₂(1 + γ)     [біт/с/Гц]
```

Обчислимо математичне сподівання (ергодичну ємність) для одноканальної системи та системи з MRC об'єднанням для двох поляризацій:

```
C_single = E[log₂(1 + γ)] = ∫₀^∞ log₂(1 + γ) · (1 / γ̄) exp(−γ / γ̄) dγ
         = (1 / ln(2)) · exp(1 / γ̄) · E₁(1 / γ̄)    [де E₁(x) — інтегральна експоненціальна функція]
```

Для MRC двох незалежних поляризаційних каналів при високих `γ̄ >> 1`:

```
C_mrc ≈ log₂(γ̄) + log₂(2) − C_euler ≈ log₂(γ̄) + 1 − 0.5772     [приріст на 1 біт/с/Гц за рахунок подвоєння SNR]
```

При переході до 2x2 MIMO з двома поляризаціями на передачі й прийомі, якщо матриця каналу відома й канали ортогональні, пропускна здатність подвоюється:

```
C_mimo = 2 · log₂(1 + γ̄ / 2)     [подвоєння спектральної ефективності у режимі 2x2 MIMO]
```

### 11. Узагальнена M-канальна поляризаційно-просторова решітка

У сучасних антенах Massive MIMO використовується `M` поляризаційно-рознесених випромінювачів. Для `M` незалежних гілок з одинаковою середньою потужністю `γ̄` сумарний SNR на виході MRC описується густиною Ерланга `M`-го порядку:

```
p_mrc_M(γ) = (γ^(M−1) / ((M−1)! · γ̄^M)) · exp(−γ / γ̄)
```

Ймовірність обриву зв'язку при малих порогах `γ_th << γ̄`:

```
P_out^(M,mrc)(γ_th) ≈ (1 / M!) · (γ_th / γ̄)^M     [порядок рознесення d = M]
```

Для `M = 4` (наприклад, 2 рознесені панелі по 2 поляризації у конфігурації 4x4 MIMO), нахил кривої замирань досягає 4 десятиліть ймовірності на 10 дБ, що робить обрив зв'язку майже неможливою подією навіть при сильній завадовій обстановці.

### 12. Статистичні моделі крос-поляризаційного співвідношення (XPR) 3GPP

Згідно з вимірюваннями консорціуму 3GPP (стандарт TR 38.901), дискримінація крос-поляризації `XPR` (Cross-Polarization Ratio) у міських сотах моделюється як логнормальна випадкова величина:

```
10 · log₁₀(XPR) ~ N(μ_xpr, σ_xpr²)     [дБ]
```

Параметри розподілу XPR залежать від наявності прямої видимості (LoS) та середовища поширення:
- **Urban Micro (UMi) LoS:** `μ_xpr = 9 дБ`, `σ_xpr = 3 дБ` (висока чистота поляризації прямого променя).
- **Urban Micro (UMi) NLoS:** `μ_xpr = 8 дБ`, `σ_xpr = 4 дБ` (інтенсивне розсіювання).
- **Urban Macro (UMa) NLoS:** `μ_xpr = 7 дБ`, `σ_xpr = 4 дБ` (сильна деполяризація на великих відстанях).

При `μ_xpr ≈ 7 дБ` енергія крос-поляризаційної складової становить близько 20% від потужності основної поляризації, що гарантує надійне формування другого рознесеного каналу при зсуві Slant ±45°.

### 13. Модель каналу Кронекера для поляризаційно-просторових систем

У комбінованих системах просторового та поляризаційного рознесення кореляційна матриця всього радіоканалу `R_total` подається у вигляді тензорного добутку Кронекера між просторовою кореляцією `R_spatial` та поляризаційною кореляцією `R_polar`:

```
R_total = R_spatial ⊗ R_polar     [модель Кронекера для MIMO каналу]
```

Такий декомпозиційний підхід дозволяє незалежно аналізувати й розраховувати виграш від розсунення антен на вежі та виграш від повороту кута поляризації вібраторів у панелі. Це забезпечує роздільне моделювання просторових і поляризаційних ефектів у довільних конфігураціях антенних решіток.

### 14. Вплив дисбалансу середньої потужності гілок Γ

Якщо через асиметрію відбиття від землі (наприклад, у конфігурації V/H) середня потужність першої гілки `γ̄₁` перевищує середня потужність другої гілки `γ̄₂`, вводиться коефіцієнт дисбалансу `Γ = γ̄₁ / γ̄₂ > 1`.

Ймовірність обриву SC при незалежних каналах із дисбалансом `Γ` має вигляд:

```
P_out^(2,sc)(γ_th, Γ) = (1 − exp(−γ_th / γ̄₁)) · (1 − exp(−γ_th / γ̄₂))
                     ≈ (γ_th / γ̄₁) · (γ_th / (γ̄₁ / Γ))
                     = Γ · (γ_th / γ̄₁)²     [апроксимація обриву при дисбалансі потужності]
```

Втрата виграшу рознесення через дисбаланс потужностей становить:

```
L_bal = 10 · log₁₀(Γ)     [дБ]
```

Для системи V/H з типовим дисбалансом `Γ = 4 дБ` (що відповідає `Γ ≈ 2.51`), втрата виграшу становить `10 · log₁₀(2.51) = 4 дБ`.

Саме тому перехід до похилої поляризації `+45° / −45°`, де `Γ = 1` (0 дБ), дозволяє повністю усунути ці 4 дБ втрат і реалізувати максимальний теоретичний виграш рознесення.

### 15. Визначення порядку рознесення (Diversity Order)

У теорії бездротового зв'язку якість будь-якої схеми рознесення описується покажчиком **порядку рознесення** (*Diversity Order* `d`). Він визначається як границя нахилу кривої ймовірності обриву на логарифмічній шкалі при прямуванні SNR до нескінченності:

```
d = − lim_(γ̄ → ∞) ( log(P_out(γ̄)) / log(γ̄) )     [визначення математичного порядку рознесення]
```

- Для системи з 1 антеною: `d = 1` (одиночний нахил).
- Для 2 поляризаційних антен при `|ρ_c| < 1`: `d = 2` (подвійний нахил).

Доки коефіцієнт кореляції стримується в межах `|ρ_c| < 1`, система з 2 поляризаційними антенами зберігає **другий порядок рознесення** (`d = 2`), що принципово змінює стійкість системи зв'язку до глибоких замирань Релея.
