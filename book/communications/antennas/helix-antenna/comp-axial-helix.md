# 🔌 Конструкція та варіанти виконання спіральних антен

Спіральна антена осьового режиму належить до класу антен біжучої хвилі з просторовою геометричною структурою. Фізичні та електродинамічні параметри реальної антени істотно залежать від точності механічного виготовлення випромінювача, вибору діелектричних матеріалів каркаса та геометрії відбивального екрана.

```
+------------------------------------------------------------------------+
|                      СХЕМА КОНСТРУКЦІЇ СПІРАЛІ                         |
|                                                                        |
|      [Центральний діелектричний стержень (склопластик / PTFE)]          |
|      =======================================================           |
|      / \     / \     / \     / \     / \     / \     / \               |
|     /   \___/   \___/   \___/   \___/   \___/   \___/   \  (Мідний дріт)|
|    |                                                     |             |
|  =============================================================         |
|  ||                   РЕФЛЕКТОР (D >= 0.75 λ)               ||         |
|  =============================================================         |
|             || (Стрічковий трансформатор 140 -> 50 Ом)                  |
|            [===]                                                       |
|             ||                                                         |
|         [SMA/N-коннектор]                                              |
+------------------------------------------------------------------------+
```

### 1. Випромінювальний провідник та скін-ефект

Провідник гелікоїда є головним елементом формування хвилі біжучого струму. Вибір матеріалу та перерізу дроту визначається омічними втратами та механічною жорсткістю:

1. **Ефекти поверхневого шару (Скін-ефект):**
   На надвисоких частотах (НВЧ) струм поширюється у тонкому поверхневому шарі провідника товщиною `δ`:
   ```
   δ = √( 2 / (ω · μ · σ) )
   ```
   На частоті `f = 2.45 ГГц` глибина скін-шару у міді становить всього `δ ≈ 1.33 мкм`. Тому поверхня провідника повинна бути відносно гладкою. Для високоефективних антен (наприклад, у супутниковому зв'язку) використовують мідний дріт із посрібленим покриттям товщиною `3...5 мкм`. Посріблення знижує омічні втрати на `5...8%`, збільшуючи ККД антени.

2. **Діаметр провідника (`d`):**
   Діаметр дроту обирається у межах `0.005 · λ ≤ d ≤ 0.03 · λ`. Для діапазону 2.4 ГГц (`λ = 123 мм`) оптимальним є дріт діаметром `d = 1.5 ... 2.5 мм`. Використання надто тонкого дроту призводить до зростання омічного опору втрат та механічної провисаності витків. Використання надто товстого дроту (або трубки `d > 0.05 · λ`) ускладнює намотування та викликає паразитно випромінювання вихрових струмів.

### 2. Рефлектор (Ground Plane) та його геометрія

Рефлектор слугує для відбиття хвилі назад у напрямку осі `z` та створює умови для формування синфазної хвилі:

1. **Плоский рефлектор:**
   Найпростіший варіант — круглий або квадратний суцільний металевий лист (алюміній, мідь, оцинкована сталь, латунь). Мінімальний розмір сторони або діаметра становить `D_gp ≥ 0.75 · λ`. Збільшення розміру рефлектора до `1.2 · λ` підвищує коефіцієнт підсилення на `0.5 дБ` та зменшує бічні пелюстки.

2. **Сітковий рефлектор (Mesh Reflector):**
   Для зменшення вітрового навантаження (*wind load*) у стаціонарних зовнішніх антенах рефлектор виготовляють із металевої сітки. Відповідно до критерію Левковича, розмір чарунки сітки `a_cell` не повинен перевищувати `0.1 · λ` (для 2.4 ГГц чарунка `< 12 мм`). У цьому випадку сітка поводиться електродинамічно як суцільне металеве дзеркало з коефіцієнтом відбиття понад 98%.

3. **Рефлектор із резонаторною чашею (Cavity-backed Helix):**
   Додання бокових металевих бортів заввишки `H_cavity ≈ 0.25 · λ ... 0.35 · λ` перетворює екран у циліндричний або конічний резонатор. Це придушує заднє випромінювання на `10...15 дБ` (коефіцієнт випромінювання вперед/назад досягає `F/B > 25 дБ`) і додає `1.5...2 дБ` до загального підсилення антени.

### 3. Діелектричні несучі структури та коефіцієнт укорочення

Збереження стабільності кроку `S` та діаметра `D` вздовж всієї довжини спіралі є критичною умовою збереження фазового узгодження:

1. **Суцільний діелектричний сердечник:**
   Намотування спіралі на суцільну трубу з пластику (ПВХ, акрил, фторопласт) є найпростішим технологічним рішенням. Проте діелектрик із проникністю `ε_r > 1` потрапляє у зону сильного електричного поля всередині спіралі. Це викликає уповільнення електромагнітної хвилі (коефіцієнт сповільнення `k_v = 1 / √(ε_eff)`).
   Внаслідок цього ефективна довжина хвилі зменшується, і антена зміщується за частотою вниз на `5...15%`. Для компенсації діаметр намотування `D` та крок `S` слід пропорційно зменшувати на коефіцієнт `k_v`.

2. **Центральний склопластиковий стержень із радіальними розпірками:**
   Для мінімізації об'єму діелектрика використовують центральний несучий стержень із високоміцного склотекстоліту (склопластику), від якого до витків спіралі відходять тонкі хрестоподібні розпірки. Повітряний зазор усередині витків забезпечує `ε_eff ≈ 1.02...1.05`, що зберігає теоретичні розрахункові параметри антени у повітрі.

### 4. Вузли живлення та узгоджувальні елементи

Узгодження вхідного імпедансу спіралі (`140 Ом`) зі стандартним коаксіальним роз'ємом (`50 Ом`) здійснюється у точці виходу центральної жили на рефлектор:

| Конструкція узгоджувача | Принцип дії та монтаж | Електричні параметри |
| :--- | :--- | :--- |
| **Клиноподібний стрічковий трансформатор** | Перший виток біля екрана вирізають із мідної фольги у формі прямокутного трикутника, що плавно звужується від ширини `W = 10...15 мм` (біля екрана) до діаметра дроту спіралі `d`. | Забезпечує найширшу смугу узгодження (`VSWR < 1.2` у смузі понад 40%). |
| **Паралельна мікросмужкова лінія** | Перші `90°` оберту витка прокладають паралельно поверхні рефлектора на дуже малій висоті `h = 1...2 мм` за допомогою діелектричної прокладки з фторопласту. | Дозволяє підстроювати `VSWR` безпосередньо зміною зазору `h` за допомогою регулювального гвинта. |
| **Коаксіальний роз'єм із чашковим адаптером** | Використовують панельний роз'єм N-типу або SMA, корпус якого надійно припаюється по колу до екрана, а центральна жила припаюється до початку узгоджувальної стрічки. | Мінімальна індуктивність виводу, що важливо на частотах понад 3 ГГц. |

### 5. Інженерні помилки та дефекти збирання

Під час самостійного або серійного виготовлення спіральних антен найчастіше виникають такі технічні дефекти:

- **Нерівномірність кроку намотування (`S`):** Прогинання дроту або нестабільність кроку понад `±3%` викликає руйнування синфазності біжучої хвилі струму, що призводить до роздвоєння головної пелюстки діаграми спрямованості та деградації коефіцієнта підсилення на `2...4 дБ`.
- **Плоский екран недостатнього розміру (`D_gp < 0.5 · λ`):** Призначення екрана — відбиття та екранування. Малий екран призводить до протікання вихрових струмів на зворотну сторону екрана та на зовнішній опліт коаксіального кабелю, що різко спотворює діаграму спрямованості.
- **Нехтування діелектричним укороченням:** Використання товстостінної ПВХ-труби без коригування геометричних розмірів `D` та `S` зміщує робочий діапазон антени нижче по частоті, внаслідок чого на розрахунковій частоті антена виходить з осьового режиму.
