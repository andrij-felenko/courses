# 🔌 Способи узгодження опору: петльовий диполь, Гамма-трансформатор та балун

Сильний взаємний електромагнітний зв'язок між елементами антени Яґі-Уда викликає катастрофічне падіння активної складової вхідного опору активного диполя `R_in` — із 73 Ом (для подинокого півхвильового диполя) до **12–25 Ом** у багатоелементних решітках.

Безпосереднє підключення стандартного 50-омного чи 75-омного коаксіального кабелю до такого елемента призводить до великого коефіцієнта стоячої хвилі (`КСХ > 3:1`), суттєвих втрат на відбиття потужності та звуження робочої смуги частот. Для подолання цього бар'єра застосовують три основні конструктивні рішення узгодження.

---

### 1. Петльовий диполь (Folded Dipole): трансформація опору ×4

Петльовий диполь виготовляється із двох паралельних провідників завдовжки близько `λ/2`, замкнених між собою на кінцях. Точка живлення розрізається у центрі лише одного з провідників.

```
+-----------------------------+
|                             |
+--------o           o--------+
         |           |
       Живлення (75 Ом)
```

#### Математичне та фізичне обґрунтування трансформації:
Аналіз роботи петльового диполя базується на методі суперпозиції двох незалежних режимів:
1. **Антенний режим (синфазний):** Рівні струми `I_a` течуть в обох паралельних плечах в одному напрямку. Цей режим формує випромінювання у простір.
2. **Двопровідний режим (протифазний):** Струми `I_t` течуть у протилежних напрямках у паралельній лінії, створюючи реактивну підтримку.

Оскільки струми в обох плечах однакового діаметра є рівними, струм у точці живлення `I_feed` становить лише половину від сумарного струму випромінювання `I_total`:

```
I_feed = I_total / 2
```

Збереження випромінюваної потужності `P = I² · R` вимагає, щоб вхідний опір петльового диполя `Z_in_folded` дорівнював:

```
P = (I_total)² · Z_in_split = (I_feed)² · Z_in_folded
(I_total)² · Z_in_split = (I_total / 2)² · Z_in_folded
Z_in_folded = 4 · Z_in_split
```

Для провідників різного діаметра `r₁` та `r₂`, рознесених на відстань `d`, коефіцієнт трансформації `m` узагальнюється формулою:

```
m = [ 1 + ln(d / r₂) / ln(d / r₁) ]²
```

#### Практичний ефект:
Якщо під впливом рефлектора та директорів опір розрізного диполя впав до `18 Ом`, петльовий диполь трансформує його до `4 · 18 = 72 Ом`, що ідеально збігається зі стандартним хвильовим опором коаксіальних кабелів **75 Ом** (телебачення) або **50 Ом** (через симетруюче U-коліно).

Крім того, петльовий диполь діє як паралельний короткозамкнений шлейф, чия реактивність змінюється у протилежному напрямку до реактивності випромінювання, що суттєво розширює робочу смугу частот антени.

---

### 2. Гамма-узгодження (Gamma Match): живлення заземленої конструкції

Гамма-узгодження дозволяє використовувати суцільний (нерозрізаний) металевий активний елемент, який надійно та жорстко заземлюється безпосередньо на металеву несучу траверсу (бум) у точці нульового потенціалу (в центрі).

```
         Бум (Заземлення)
============[========]============  Активний диполь (суцільний)
            |      ||
    [C_g]---|------||              Гамма-стержень з регульованим хомутом
      |
  Центральна жила коаксіалу (Екран -> на Бум)
```

#### Еквівалентна схема та принцип дії:
1. Конструкція утворює несиметричний автотрансформатор: диполь слугує основним випромінювачем, а паралельний гамма-стержень діаметром `d_g`, з'єднаний з диполем рухомим металевим затискачем (хомутом) на відстані `a` від центру, визначає коефіцієнт трансформації.
2. Зміщенням хомута змінюють трансформований опір від 0 до сотень Ом, знаходячи точну точку узгодження з 50-омним кабелем.
3. Еквівалентна петля гамма-стержня вносить в коло послідовну індуктивність `+j·X_L`. Для її повної компенсації послідовно з центральною жилою коаксіального кабелю вмикають змінний підлаштовий конденсатор `C_g` з реактивним опором `-j·X_C = -j / (ω·C_g)`.

#### Переваги:
- **Механічна міцність:** Всі елементи є суцільнометалевими, без тендітних пластикових ізоляторів.
- **Грозозахист:** Антена є повністю заземленою по постійному струму, що відводить статику та захищає вхідний тракт приймача.
- **Пряме живлення:** Несиметричний коаксіальний кабель підключається безпосередньо (оболонка — на бум, жила — через ємність на гамма-стержень).

---

### 3. Т-подібне та Hairpin-узгодження (Hairpin / Beta Match)

- **Т-узгодження (T-Match):** Симетричний аналог Гамма-узгодження, що складається з двох дзеркальних гамма-стержнів по обидва боки від заземленого центру диполя. Використовується для живлення симетричними двопровідними лініями.
- **Hairpin-узгодження (Beta Match):** Використовує активний диполь, навмисно вкорочений відносно резонансу (`L < λ/2`), що надає йому ємнісного вхідного опору `R_in - j·X_C`. На клеми живлення паралельно підключають короткозамкнену U-подібну індуктивну петлю (hairpin / шпильку). Паралельний індуктивний опір петлі компенсує ємнісну складову диполя та трансформує низький опір `R_in ≈ 15 Ом` до стандартних `50 Ом`.

---

### 4. Симетруючі пристрої (Балуни / Baluns)

Диполь є **симетричною** лінією (потенціали обох плечей дзеркальні відносно землі), а коаксіальний кабель — **несиметричною** (оболонка заземлена, жила сигнальна). 

Безпосереднє підключення коаксіалу до розрізного або петльового диполя спричиняє **затікання струму** на зовнішню поверхню екрана кабелю (*feeder effect*). Це призводить до:
- випромінювання самого кабелю живлення (перекривлення діаграми спрямованості та втрата спрямованості);
- прийому кабелем промислових завад із будівлі.

#### Основні типи балунів для Яґі-Уда:
1. **Напівхвильове U-коліно (Balun 4:1):** Шматок коаксіального кабелю завдовжки `L = (λ/2)·k_v` (де `k_v ≈ 0.66` — коефіцієнт укорочення коаксіалу), підключений паралельно до клем диполя. Створює точну фазову затримку 180°, забезпечуючи ідеальне симетрування та додаткову трансформацію опору 4:1.
2. **Феритовий дросель Гуанелла (Guanella 1:1 Current Balun):** Кілька високочастотних феритових кілець або феритова втулка, одягнута поверх коаксіального кабелю біля точки підключення до антени. Створює високий індуктивний опір для струмів спільної моди на зовнішній оболонці кабелю, повністю блокуючи їхнє затікання без зміни диференційного сигналу всередині кабелю.
