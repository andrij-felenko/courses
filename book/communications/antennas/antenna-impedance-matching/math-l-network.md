# 🧮 Математичний вивід L-подібного узгоджувального ланцюга

Ця вставка містить точний математичний вивід формул для розрахунку реактивних елементів двоелементного узгоджувального L-вузла, який трансформує довільний комплексний імпеданс навантаження `Z_A = R_A + j·X_A` у дійсний хвильовий опір фідерної лінії `Z₀`.

Узгодження вважається досягнутим тоді, коли комплексний вхідний імпеданс узгоджувального кола разом із підключеною антеною дорівнює хвильовому опору лінії `Z₀` (типово 50 Ом). Оскільки реактивна мережа складається виключно з ідеальних індуктивностей та конденсаторів, вона не розсіює активну потужність, а лише змінює співвідношення між амплітудами напруги та струму і компенсує фазовий зсув.

Для двоелементної мережі існує дві принципові топології. Вибір між ними визначається тим, чи є активний опір антени `R_A` більшим або меншим за опір фідеру `Z₀`.

---

### Топологічна умова розв'язності

Перш ніж переходити до алгебраїчних перетворень, встановимо фізичну причину того, чому одна топологія не може задовольнити всі випадки.

Для створення активного опору `Z₀` на вході кола реактивний елемент, увімкнений паралельно, створює коло з провідністю `Y_p = G_p + j·B_p`. При цьому активна провідність `G_p = 1 / R_parallel` завжди менша за вихідну активну провідність антени `1 / R_A`, бо паралельне підключення реактивності зменшує активну частину провідності.

Отже:
- Якщо `R_A > Z₀`, нам потрібно **зменшити** активний опір антени до рівня `Z₀`. Це робиться підключенням паралельного реактивного елемента безпосередньо до антени.
- Якщо `R_A < Z₀`, нам потрібно **підвищити** активний опір антени до рівня `Z₀`. Це робиться підключенням паралельного реактивного елемента з боку 50-омного фідеру.

---

### Випадок 1: Високоомне навантаження (`R_A > Z₀`) — Топологія А

У цієї топології паралельний реактивний елемент з провідністю `B_p` увімкнений паралельно антені `Z_A`, а послідовний реактивний елемент з опором `X_s` підключений між цією паралельною ланкою та генератором.

#### Крок 1. Еквівалентна паралельна провідність антени

Спочатку знайдемо повну адмітанс-провідність `Y_A` самої антени:

```
Y_A = 1 / (R_A + j·X_A)
```

Домноживши чисельник і знаменник на комплексне спряження `R_A - j·X_A`, виділимо дійсну `G_A` та уявну `B_A` частини:

```
G_A = R_A / (R_A² + X_A²)      [активна провідність антени]
B_A = -X_A / (R_A² + X_A²)     [реактивна провідність антени]
```

При підключенні паралельного елемента з провідністю `B_p` сумарна провідність паралельного вузла стає рівною:

```
Y_p = G_A + j · (B_A + B_p)
```

Позначимо сумарну реактивну провідність вузла як `B_total = B_A + B_p`.

#### Крок 2. Перетворення паралельного еквівалента в послідовний імпеданс

Знайдемо комплексний імпеданс цієї паралельної ланки `Z_p = 1 / Y_p`:

```
Z_p = 1 / (G_A + j·B_total) 
= (G_A - j·B_total) / (G_A² + B_total²)
```

Дійсна частина цього імпедансу дорівнює `Re(Z_p) = G_A / (G_A² + B_total²)`, а уявна частина дорівнює `Im(Z_p) = -B_total / (G_A² + B_total²)`.

Тепер підключимо послідовний елемент `X_s`. Загальний вхідний імпеданс кола дорівнює:

```
Z_in = Z_p + j·X_s = [ G_A / (G_A² + B_total²) ] + j · [ X_s - (B_total / (G_A² + B_total²)) ]
```

#### Крок 3. Формулювання умов узгодження та визначення Q

Для ідеального узгодження вхідний імпеданс `Z_in` повинен дорівнювати чисто активному опору лінії `Z₀ + j·0`. Це дає систему з двох незалежних рівнянь:

```
G_A / (G_A² + B_total²) = Z₀                     [Рівняння 1: активне узгодження]
X_s - [ B_total / (G_A² + B_total²) ] = 0       [Рівняння 2: реактивне узгодження]
```

З Рівняння 1 виражаємо квадрат сумарної провідності:

```
G_A² + B_total² = G_A / Z₀
B_total² = (G_A / Z₀) - G_A² = G_A · ( (1 / Z₀) - G_A )
```

Підставимо раніше знайдене значення `G_A = R_A / (R_A² + X_A²)`:

```
B_total = ± √[ (R_A / Z₀) - 1 ] / √(R_A² + X_A²)
```

Величина `Q = √[ (R_A / Z₀) - 1 ]` виражає нагрузочну добротність L-вузла для випадку `R_A > Z₀`.

#### Крок 4. Остаточні формули для `B_p` та `X_s`

Оскільки `B_total = B_A + B_p`, то паралельна провідність елемента вузла дорівнює `B_p = B_total - B_A`:

```
B_p = [ -X_A ± R_A · √((R_A / Z₀) · (1 + (X_A/R_A)²) - 1) ] / (R_A² + X_A²)
```

З Рівняння 2 знаходимо необхідний послідовний реактивний опір `X_s`:

```
X_s = B_total / (G_A / Z₀) = Z₀ · B_total / G_A
X_s = ± Z₀ · √[ (R_A / Z₀) · (1 + (X_A/R_A)²) - 1 ] - (B_p · Z₀ · X_A / R_A)
```

Для чисто активного навантаження без початкової реактивності (`X_A = 0`) формули спрощуються до лаконічного вигляду:

```
Q = √((R_A / Z₀) - 1)
X_s = ± Z₀ · Q
X_p = 1 / B_p = ∓ R_A / Q
```

### Випадок 2: Низькоомне навантаження (`R_A < Z₀`) — Топологія Б

У цієї топології послідовний елемент `X_s` вмикається послідовно з антеною `Z_A`, утворюючи імпеданс `Z_s = R_A + j·(X_A + X_s)`. Паралельний елемент з провідністю `B_p` підключається паралельно цій комбінації з боку 50-омного фідеру.

#### Крок 1. Перетворення послідовної ланки у провідність

Сумарна провідність цієї схеми з боку входу дорівнює:

```
Y_in = (1 / Z_s) + j·B_p = [ 1 / (R_A + j·(X_A + X_s)) ] + j·B_p
```

Раціоналізуємо перший доданок:

```
Y_in = [ R_A / (R_A² + (X_A + X_s)²) ] + j · [ B_p - ((X_A + X_s) / (R_A² + (X_A + X_s)²)) ]
```

#### Крок 2. Умови узгодження та розв'язок для `X_s`, `B_p`

Для узгодження з лінією `Z₀` вхідна провідність повинна дорівнювати `1 / Z₀ + j·0`:

```
R_A / (R_A² + (X_A + X_s)²) = 1 / Z₀             [Рівняння активного узгодження]
B_p - [ (X_A + X_s) / (R_A² + (X_A + X_s)²) ] = 0 [Рівняння реактивного узгодження]
```

З першого рівняння отримуємо:

```
R_A² + (X_A + X_s)² = R_A · Z₀
(X_A + X_s)² = R_A · Z₀ - R_A² = R_A² · ( (Z₀ / R_A) - 1 )
```

Ввівши добротність низькоомного вузла `Q = √((Z₀ / R_A) - 1)`, отримуємо:

```
X_A + X_s = ± R_A · Q
X_s = -X_A ± R_A · Q
```

Тепер з другого рівняння виражаємо паралельну провідність `B_p`:

```
B_p = (X_A + X_s) / (R_A · Z₀) = (± R_A · Q) / (R_A · Z₀) = ± Q / Z₀
```

Паралельний реактивний опір дорівнює `X_p = 1 / B_p = ± Z₀ / Q`.

### Аналіз знаків: вибір між ФНЧ та ФВЧ

Оскільки в обох топологіях квадратний корінь дає два знаки `±`, ми завжди отримуємо **два незалежні фізичні розв'язки**:

1. **Перший розв'язок (`X_s > 0`, `B_p > 0`):**
   Послідовний елемент є індуктивністю `L` (`X_s = 2·π·f·L`), а паралельний — конденсатором `C` (`B_p = 2·π·f·C`). Це топологія **фільтра нижніх частот (ФНЧ)**. Вона є найбільш бажаною при проектуванні передавачів, оскільки індуктивність у послідовному колі та ємність на землю створюють додаткове затухання на вищих гармоніках передавача.

2. **Другий розв'язок (`X_s < 0`, `B_p < 0`):**
   Послідовний елемент є конденсатором `C` (`X_s = -1 / (2·π·f·C)`), а паралельний — індуктивністю `L` (`B_p = -1 / (2·π·f·L)`). Це топологія **фільтра верхніх частот (ФВЧ)**. Вона корисна у приймальних трактах для придушення потужних низькочастотних завад від середньохвильових радіостанцій.

### Практичний чисельний приклад розрахунку

Розглянемо випадок узгодження короткої вертикальної антени для діапазону 145 МГц з імпедансом `Z_A = 15 - j45 Ом` у 50-омній лінії (`Z₀ = 50 Ом`).

Оскільки `R_A = 15 Ом < Z₀ = 50 Ом`, застосовуємо **Топологію Б**:

1. Обчислюємо добротність вузла: `Q = √((50 / 15) - 1) = √(3.333 - 1) = √2.333 ≈ 1.5275`.
2. Розраховуємо розв'язок ФНЧ (`+Q`):
   ```
   X_s = -(-45) + 15 · 1.5275 = 45 + 22.91 = +67.91 Ом (Індуктивність L)
   B_p = 1.5275 / 50 = 0.03055 См  ⇒  X_p = -1 / 0.03055 = -32.73 Ом (Ємність C)
   ```
3. Переводимо реактивності у номінали на частоті `f = 145 МГц` (`ω = 2·π·145·10⁶ ≈ 9.1106·10⁸ рад/с`):
   ```
   L_series = 67.91 / 9.1106·10⁸ ≈ 74.5 нГн
   C_parallel = 0.03055 / 9.1106·10⁸ ≈ 33.5 пФ
   ```

Таким чином, послідовна котушка 74.5 нГн та паралельний конденсатор 33.5 пФ повністю трансформують імпеданс `15 - j45 Ом` у чисті `50 Ом` на частоті 145 МГц.
