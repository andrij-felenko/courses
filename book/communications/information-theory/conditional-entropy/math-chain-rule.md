# 🧮 Алгебра умовної ентропії

Ця вставка розгортає суворий математичний апарат умовної ентропії. Ми доведемо тотожність двох її базових формул, виведемо ланцюгове правило для двох та довільної кількості `n` випадкових величин, обґрунтуємо властивість «обумовлення в середньому не збільшує ентропію» через угнутість та нерівність Єнсена, розглянемо нерівність Фано і розберемо детальний чисельний приклад, у якому окрема підказка піднімає невизначеність.

Усі обчислення наведено у двійкових бітах (логарифм за основою 2). [Ентропія Шеннона](topic:communications/shannon-entropy) для дискретного розподілу з ймовірностями `p(x)` визначається як `H(X) = − ∑ p(x) · log₂ p(x)`. Величина `H(X|Y)` позначає очікуваний залишок непевності про `X` за умови відомого `Y`.

## 1. Еквівалентність формул умовної ентропії

Умовну ентропію в математичній теорії інформації визначають двома способами, які відображають два різні погляди на процес вимірювання залишку непевності.

Перший спосіб будується як математичне сподівання ентропій часткових умовних розподілів. Спочатку аналізується непевність за умови конкретного спостереження `Y = y`, а потім отримані значення усереднюються по всіх можливих виходах `y`:
```
H(X | Y=y) = − ∑ₓ p(x|y) · log₂ p(x|y)
H(X|Y)     = ∑ᵧ p(y) · H(X | Y=y)
```

Другий спосіб задає умовну ентропію безпосередньо через суму по всіх парах спільних подій ансамблю:
```
H(X|Y) = − ∑ₓ,ᵧ p(x,y) · log₂ p(x|y)
```

Доведемо тотожність цих виразів за допомогою послідовних точних еквівалентних перетворень:

```
H(X|Y)
= ∑ᵧ p(y) · [ − ∑ₓ p(x|y) · log₂ p(x|y) ]    [підставили вираз часткової ентропії H(X|Y=y)]
= − ∑ᵧ ∑ₓ p(y) · p(x|y) · log₂ p(x|y)        [внесене скалярне p(y) під знаки сумування]
= − ∑ₓ,ᵧ [ p(y) · p(x|y) ] · log₂ p(x|y)    [об'єднали суми в єдиний подвійний цикл по (x,y)]
= − ∑ₓ,ᵧ p(x,y) · log₂ p(x|y)               [за тотожністю умовної ймовірності: p(y)·p(x|y) = p(x,y)]
```

Зверніть особливу увагу на структуру підсумкового виразу: під значущим логарифмом стоїть умовна ймовірність `p(x|y)` (міра несподіваності події `x`, коли підказка `y` вже відома), тоді як ваговим множником перед логарифмом виступає спільна ймовірність `p(x,y)` (частота одночасної появи цієї пари у випробуваннях).

Математична перевага другого виразу полягає у тому, що він знімає необхідність обчислення проміжних часткових ентропій. Для довільного дискретного ансамблю вибірковий простір обробляється як один подвійний масив, де сумування виконується по усім клітинкам таблиці спільних подій.

> 🔧 **Навіщо це.** Друга форма є основною для практичних обчислень у системних програмах. Маючи експериментальну матрицю сумісних частот `N[i][j]`, ми одразу дістаємо оцінки спільних ймовірностей `p(x,y) = N[i][j] / N_total`. Нам не потрібно розбивати матрицю на окремі тимчасові вектори для кожного `y` й окремо рахувати їхні ентропії — сума `− ∑ p(x,y) · log₂ p(x|y)` підраховується за один подвійний цикл по всіх клітинках матриці.

## 2. Ланцюгове правило для двох та n величин

Ланцюгове правило описує математичний розклад спільної ентропії пари `H(X,Y)` на суму послідовних кроків з'ясування інформації про систему. За означенням спільної ентропії пари:

```
H(X,Y) = − ∑ₓ,ᵧ p(x,y) · log₂ p(x,y)
```

Застосуємо теорему множення ймовірностей `p(x,y) = p(y) · p(x|y)` безпосередньо під знаком логарифма:

```
H(X,Y)
= − ∑ₓ,ᵧ p(x,y) · log₂ [ p(y) · p(x|y) ]
= − ∑ₓ,ᵧ p(x,y) · [ log₂ p(y) + log₂ p(x|y) ]       [за властивістю логарифма добутку]
= − ∑ₓ,ᵧ p(x,y) · log₂ p(y)  −  ∑ₓ,ᵧ p(x,y) · log₂ p(x|y)
  └───────────── A ────────────┘   └───────────── B ────────────┘
```

Детально проаналізуємо перший доданок **A**:
```
− ∑ₓ,ᵧ p(x,y) · log₂ p(y)
= − ∑ᵧ [ ∑ₓ p(x,y) ] · log₂ p(y)    [винесли співмножник log₂ p(y) за внутрішню суму по x]
= − ∑ᵧ p(y) · log₂ p(y)              [за законом маргіналізації: ∑ₓ p(x,y) = p(y)]
= H(Y)                               [за означенням ентропії Шеннона H(Y)]
```

Другий доданок **B** за доведеною в попередньому розділі формулою дорівнює умовній ентропії `H(X|Y)`. Складаючи результати, отримуємо точну рівність:

```
H(X,Y) = H(Y) + H(X|Y)
```

Через повну симетрію спільної ймовірності `p(x,y) = p(x) · p(y|x)` аналогічно доводиться дзеркальне розкладання системи з іншого боку:

```
H(X,Y) = H(X) + H(Y|X)
```

### Узагальнення на n випадкових величин

Для довільної сукупності з `n` випадкових величин `X₁, X₂, ..., Xₙ` загальний спільний розподіл ймовірностей розкладається у ланцюговий добуток послідовних умовних ймовірностей:

```
p(x₁, x₂, ..., xₙ) = ∏ᵢ₌₁ⁿ p(xᵢ | x₁, x₂, ..., xᵢ₌₁)
```

Підставивши цей добуток у формулу спільної ентропії `H(X₁, ..., Xₙ)` і перетворивши логарифм добутку на суму логарифмів, отримуємо **загальне ланцюгове правило Шеннона**:

```
H(X₁, X₂, ..., Xₙ) = ∑ᵢ₌₁ⁿ H(Xᵢ | X₁, X₂, ..., Xᵢ₌₁)
```

Для трьох випадкових змінних `X, Y, Z` це правило розгортається у прозорий вираз:

```
H(X, Y, Z) = H(X) + H(Y|X) + H(Z | X,Y)
```

Фізичний зміст цього закону полягає у тому, що сукупна невизначеність складної багатовимірної системи розпадається на неопосередкований внесок першого елемента плюс залишкові невизначеності кожного наступного елемента за умови, що всі попередні вже досконально вивчені. При цьому порядок вибору елементів може бути довільним — будь-яка з `n!` можливих перестановок дає точно те саме підсумкове число `H(X₁, ..., Xₙ)`.

Цей розклад є основою для багатьох алгоритмів стиснення послідовностей та марковських моделей мови, де ентропія блоку тексту або сигналу обчислюється як сума умовних ентропій символів при відомому контексті попередніх символів.

## 3. Доведення нерівності H(X|Y) ≤ H(X) через угнутість та нерівність Єнсена

Фундаментальна властивість «обумовлення в середньому не збільшує невизначеність» виражається математичною нерівністю `H(X|Y) ≤ H(X)`.

Для строгого доведення звернемо увагу на те, що абсолютний маргінальний розподіл `p(x)` є не чим іншим, як зваженою сумою часткових умовних розподілів:

```
p(x) = ∑ᵧ p(y) · p(x|y)
```

Тому порівняння початкової ентропії `H(X)` та середньої умовної ентропії `H(X|Y)` є зіставленням двох математичних об'єктів:
- `H(X) = H( ∑ᵧ p(y) · p(x|y) )` — ентропія середнього розподілу ймовірностей;
- `H(X|Y) = ∑ᵧ p(y) · H( p(x|y) )` — середнє значення ентропій часткових розподілів.

### Угнутість функції ентропії

Розглянемо базову функцію `φ(t) = − t · log₂ t`, яка визначена на відрізку `t ∈ [0, 1]`. Знайдемо її першу та другу похідні:

```
φ′(t)  = − log₂ t − (1 / ln 2)
φ″(t) = − 1 / (t · ln 2) < 0     для всіх t > 0
```

Оскільки друга похідна `φ″(t)` є строго від'ємною на всьому інтервалі `(0, 1)`, функція `φ(t)` є строго угнутою (геометрично її графік усюди вигинається вгору, а січні хорди лежать під кривою).

Багатовимірна ентропія Шеннона `H(p)` є сумою таких угнутих компонент по кожній координаті вектору ймовірностей `pᵢ`. Сума угнутих функцій є угнутою, отже функція ентропії `H(p)` є строго угнутою функцією векторного аргументу.

### Застосування нерівності Єнсена

За [нерівністю Єнсена](topic:math/convex-functions) для довільної угнутої функції `f` та зваженого набору векторних точок `vⱼ` із довільними невід'ємними вагами `wⱼ ≥ 0` (`∑ wⱼ = 1`):

```
f( ∑ⱼ wⱼ · vⱼ ) ≥ ∑ⱼ wⱼ · f(vⱼ)
```

Поклавши `f = H`, точки `vⱼ = p(x|y)` та ваги `wⱼ = p(y)`, отримуємо точну нерівність:

```
H( ∑ᵧ p(y) · p(x|y) ) ≥ ∑ᵧ p(y) · H( p(x|y) )
   └─────── H(X) ──────┘    └────── H(X|Y) ─────┘
```

Отже, доведено:

```
H(X) ≥ H(X|Y)   або   H(X|Y) ≤ H(X)
```

### Умова досягнення рівності

Рівність `H(X|Y) = H(X)` досягається тоді й лише тоді, коли всі умовні розподіли `p(x|y)` тотожно збігаються з маргінальним розподілом `p(x)` для всіх `y` з ненульовою ймовірністю `p(y) > 0`:

```
p(x|y) = p(x)   для всіх x, y
```

Це означає, що випадкові величини `X` та `Y` є статистично незалежними. Якщо знання `Y` ніяк не змінює розподіл `X`, умовна ентропія залишається рівною початковій ентропії джерела.

### Еквівалентне доведення через розбіжність Кульбака–Лейблера

Те саме співвідношення можна довести через невід'ємність розбіжності Кульбака–Лейблера (відносної ентропії) `D_KL( P(X,Y) ‖ P(X)P(Y) )`. Зменшення ентропії дорівнює взаємній інформації:

```
I(X;Y) = H(X) − H(X|Y) = ∑ₓ,ᵧ p(x,y) · log₂ [ p(x,y) / (p(x)·p(y)) ] = D_KL( P(X,Y) ‖ P(X)P(Y) ) ≥ 0
```

За нерівністю Гіббса розбіжність Кульбака–Лейблера завжди невід'ємна `D_KL ≥ 0`, звідки безпосередньо випливає `H(X) − H(X|Y) ≥ 0`, тобто `H(X|Y) ≤ H(X)`.

## 4. Нерівність Фано (Fano's Inequality) та межі відновлення

Умовна ентропія `H(X|Y)` задає фундаментальну математичну межу на мінімально можливу ймовірність помилки відновлення значень `X` за спостереженим виходом `Y`.

Нехай `X̂ = g(Y)` — довільний вирішальний алгоритм або декодер, який на основі спостереження `Y` оцінює значення входу `X`. Позначимо ймовірність помилки декодування як `Pₑ = P(X̂ ≠ X)`.

**Нерівність Фано** стверджє:

```
H(X|Y) ≤ H(Pₑ) + Pₑ · log₂ ( |X| − 1 )
```

де:
- `H(Pₑ) = − Pₑ · log₂ Pₑ − (1 − Pₑ) · log₂ (1 − Pₑ)` — двійкова ентропія індикатора помилки;
- `|X|` — потужність алфавіту вхідних символів.

Якщо вхідний алфавіт є двійковим (`|X| = 2`), доданок `log₂(|X| - 1) = log₂ 1 = 0`, і нерівність Фано спрощується до виразу:

```
H(X|Y) ≤ H(Pₑ)
```

Це означає: якщо умовна ентропія `H(X|Y)` є високою, жоден вирішальний алгоритм чи декодер `g(Y)` не спроможний досягти малої ймовірності помилки `Pₑ`. Величина залишку `H(X|Y)` встановлює абсолютну фізичну планку помилок відновлення даних у каналах зв'язку та системах штучного інтелекту.

Практичне значення нерівності Фано полягає у тому, що вона дозволяє оцінити нижню межу помилок класифікатора без проведення тривалого тестування, знаючи лише підсумкову матрицю умовної ентропії ознак.

## 5. Детальний чисельний приклад: коли окрема підказка піднімає невизначеність

Покажемо на конкретних числах, що нерівність `H(X|Y) ≤ H(X)` справджується **лише в середньому**, тоді як для окремого значення `y` часткова умовна ентропія `H(X | Y=y)` цілком може бути більшою за початкову ентропію `H(X)`.

### Параметри прикладу

Нехай вхід `X ∈ {0, 1}` передається через канал з виходом `Y ∈ {A, B}`:
- Підказка `Y = A` («чистий канал») виникає у `p(A) = 0.9` випадків. При цьому умовний розподіл дорівнює `p(X=1 | A) = 0.05`, `p(X=0 | A) = 0.95`.
- Підказка `Y = B` («зашумлений канал») виникає у `p(B) = 0.1` випадків. Умовний розподіл стає рівноймовірним: `p(X=1 | B) = 0.5`, `p(X=0 | B) = 0.5`.

### Крок 1. Обчислення умовних ентропій для кожного Y

На першому кроці розрахуємо часткові умовні ентропії `H(X | Y=y)` окремо для кожного з двох можливих результатів спостереження: чистого прийому (`Y = A`) та зашумленого прийому (`Y = B`). Для кожного стану підставимо відповідні умовні ймовірності `p(X|y)` у формулу ентропії Шеннона, щоб оцінити залишок невизначеності в обох випадках:

```
H(X | Y=A)
= − 0.95 · log₂ 0.95 − 0.05 · log₂ 0.05       [за формою ентропії Шеннона]
= − 0.95 · (−0.0740) − 0.05 · (−4.3219)       [значення двійкових логарифмів]
= 0.0703 + 0.2161                             [перемноження ймовірностей та несподіванок]
= 0.2864 біта                                 [підсумковий частковий залишок]

H(X | Y=B)
= − 0.50 · log₂ 0.50 − 0.50 · log₂ 0.50       [за формою для рівноймовірних подій]
= 1.0000 біт                                  [максимальна невизначеність для 2 подій]
```

### Крок 2. Обчислення середньої умовної ентропії H(X|Y)

На другому кроці знаходимо загальну середню умовну ентропію `H(X|Y)` як математичне сподівання часткових залишків. Для цього зважимо обчислені ентропії `H(X | Y=A)` та `H(X | Y=B)` на ймовірності появи відповідних підказок `p(A) = 0.9` і `p(B) = 0.1` та підсумуємо їх:

```
H(X|Y)
= p(A) · H(X | Y=A) + p(B) · H(X | Y=B)        [зважене усереднення залишків по всіх Y]
= 0.9 · 0.2864 + 0.1 · 1.0000                  [підстановка частот появі підказок]
= 0.2578 + 0.1000                              [перемноження частот на часткові залишки]
= 0.3578 біта                                  [середня умовна ентропія]
```

### Крок 3. Обчислення маргінального розподілу та апріорної ентропії H(X)

Знайдемо повну ймовірність `p(X=1)` за формулою повної ймовірності:

```
p(X=1) = p(A) · p(X=1 | A) + p(B) · p(X=1 | B)  [за формулою повної ймовірності]
       = 0.9 · 0.05 + 0.1 · 0.5                [підстановка початкових параметрів]
       = 0.045 + 0.050                          [перемноження гілок подій]
       = 0.0950                                 [маргінальна ймовірність X=1]

p(X=0) = 1 − 0.0950                             [доповнення ймовірності до одиниці]
       = 0.9050                                 [маргінальна ймовірність X=0]
```

Обчислимо початкову невизначеність `H(X)` без спостереження `Y`:

```
H(X)
= − 0.9050 · log₂ 0.9050 − 0.9050 · 0           [за формулою ентропії Шеннона]
= − 0.9050 · (−0.1440) − 0.0950 · (−3.3959)     [обчислення двійкових логарифмів p(X)]
= 0.1303 + 0.3226                               [перемноження ймовірностей та логарифмів]
= 0.4529 біта                                   [апріорна ентропія наосліп]
```

### Порівняння результатів

1. **Середнє співвідношення:**
   `H(X|Y) = 0.3578 біта ≤ 0.4529 біта = H(X)`.
   У середньому спостереження `Y` зменшило невизначеність про `X` на `I(X;Y) = 0.4529 − 0.3578 = 0.0951 біта`.

2. **Окреме спостереження Y = B:**
   `H(X | Y=B) = 1.0000 біт > 0.4529 біта = H(X)`.
   Спостереження рідкісної завади `Y = B` підвищило невизначеність про `X` з `0.4529` до `1.0` біта. Підказка `B` спантеличила спостерігача дужче, ніж повне незнання `Y`.

Цей приклад математично демонструє важливий висновок: **закон ненаростання ентропії при обумовленні є твердженням про математичне сподівання, а не про кожен окремий вимір.** Окремі рідкісні спостереження можуть тимчасово підвищувати невизначеність, але завдяки вищій частоті вдалих спостережень загальне середовище завжди зменшує інформаційний сумнів.
