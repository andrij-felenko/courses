# 🧮 Алгебра умовної ентропії

Тут — сама математика. Доведемо три речі, на яких тримається умовна ентропія: що дві її формули — та сама сума; що вона ланцюгом розкладає невизначеність будь-якого набору величин; і що обумовлення в середньому ніколи ентропію не збільшує. А тоді зберемо приклад, де окрема підказка її таки збільшує, — щоб побачити, що «в середньому» тут слово точне, а не обережне.

Домовимося про запис: усе в бітах, логарифм двійковий. [Ентропія](book:communications/shannon-entropy) розподілу — `H(X) = −Σ p(x)·log₂ p(x)`, середня несподіванка. `H(X|Y)` — залишок непевності про X, коли Y уже відомий. Уся робота нижче — це чесна арифметика логарифма над цими двома означеннями; нового постулату не буде жодного.

### Дві формули — одна сума

Умовну ентропію означують двома кроками. Спершу — залишок за одного конкретного спостереження `Y=y`: беремо звужений розподіл `p(x|y)` й рахуємо його звичайну ентропію.

```
H(X | Y=y) = −Σ p(x|y)·log₂ p(x|y)      (сума по x)
```

Саме `y` випадкове, тож чесне число для каналу — це середнє залишку по всіх `y`, зважене на те, як часто кожне трапляється:

```
H(X|Y) = Σ p(y)·H(X | Y=y)              (сума по y)
```

Ці дві рівності часто пишуть і в третій, компактнішій формі — прямо через спільний розподіл пари. Покажімо, що це не окреме означення, а та сама сума, лише згорнута. Підставмо перше в друге й внесімо вагу `p(y)` під внутрішній знак суми:

```
H(X|Y) = Σ p(y)·[ −Σ p(x|y)·log₂ p(x|y) ]
       = −Σ p(y)·p(x|y)·log₂ p(x|y)      (одна сума по всіх парах x, y)
```

І тут спрацьовує єдина підстановка, на якій усе далі й тримається: добуток ваги на умовну ймовірність за [означенням умовної ймовірності](book:math/conditional-probability) є спільна ймовірність, `p(y)·p(x|y) = p(x,y)`. Це точна тотожність, не наближення. Множник `p(y)` перед дужкою й множник `p(x|y)` під логарифмом зливаються в один `p(x,y)`:

```
H(X|Y) = −Σ p(x,y)·log₂ p(x|y)          (сума по всіх парах x, y)
```

Отже «середнє залишків» і «сума по спільному розподілу» — буквально один вислів. Варто помітити, що під логарифмом лишилося `p(x|y)`, а не `p(x,y)`: несподіванка міряється проти **умовного** розподілу (наскільки дивне x, коли вже бачиш y), а важиться частотою пари `p(x,y)`. Переставиш ці ролі — дістанеш іншу величину, не умовну ентропію.

> 🔧 **Навіщо це.** Друга форма — та, якою рахують на практиці. Маєш матрицю плутанини каналу (скільки разів послане `x` прийнялося як `y`) — це готова таблиця частот `p(x,y)`. Не треба різати її на під-таблиці по кожному `y` й усереднювати: береш кожну клітинку, множиш `p(x,y)` на `log₂ p(x|y)` (а `p(x|y)` — та сама клітинка, поділена на суму свого стовпця), складаєш зі знаком мінус — і одразу маєш `H(X|Y)`.

### Ланцюгове правило й розклад на n величин

Та сама підстановка `p(x,y) = p(y)·p(x|y)` дає ланцюгове правило. Спільна ентропія пари за означенням — `H(X,Y) = −Σ p(x,y)·log₂ p(x,y)`. Розкладемо ймовірність під логарифмом на добуток, а логарифм добутку — на суму логарифмів; сума розпадається на два доданки:

```
H(X,Y) = −Σ p(x,y)·log₂[ p(y)·p(x|y) ]
       = −Σ p(x,y)·log₂ p(y)  −  Σ p(x,y)·log₂ p(x|y)
          └──────── A ───────┘   └──────── B ────────┘
```

Доданок **A**: множник `log₂ p(y)` не залежить від `x`, тож спершу просумуймо по `x`, і `Σ p(x,y) = p(y)` повертає окрему ймовірність `y`; лишається `−Σ p(y)·log₂ p(y) = H(Y)`. Доданок **B** — це буквально друга форма умовної ентропії з попереднього розділу, тобто `H(X|Y)`. Складаємо:

```
H(X,Y) = H(Y) + H(X|Y)
```

Розклад можна почати й з іншого кінця, з `p(x,y) = p(x)·p(y|x)`, — і вийде дзеркальне `H(X,Y) = H(X) + H(Y|X)`. Невизначеність пари стала; ділиться вона на «перше плюс залишок другого» — байдуже, з якого краю заходиш.

Тепер — головне узагальнення, якого на двох величинах не видно. Ланцюг тягнеться на скільки завгодно величин, і доводиться так само, однією арифметикою. Ключ — **ланцюгове правило для самих ймовірностей**: будь-який спільний розподіл розкладається в добуток умовних, де кожна наступна величина обумовлена всіма попередніми.

```
p(x₁,…,xₙ) = ∏ᵢ p(xᵢ | x₁,…,xᵢ₋₁)       (добуток по i = 1…n)
```

Підставмо це під логарифм у означення спільної ентропії. Логарифм добутку — сума логарифмів, а зовнішня сума по `i` виноситься за спільну суму по всіх наборах:

```
H(X₁,…,Xₙ) = −Σ p(x₁,…,xₙ)·log₂ p(x₁,…,xₙ)
           = −Σ p(x₁,…,xₙ)·Σᵢ log₂ p(xᵢ | x₁,…,xᵢ₋₁)
           = Σᵢ [ −Σ p(x₁,…,xₙ)·log₂ p(xᵢ | x₁,…,xᵢ₋₁) ]
```

Розберімо один доданок у квадратних дужках. Під логарифмом стоїть `p(xᵢ | x₁,…,xᵢ₋₁)` — воно залежить лише від перших `i` величин. Просумувавши повний спільний розподіл по всіх пізніших `xᵢ₊₁,…,xₙ`, дістанемо маргінал `p(x₁,…,xᵢ)`, і доданок згортається рівно в означення умовної ентропії `H(Xᵢ | X₁,…,Xᵢ₋₁)`. Отже:

```
H(X₁,…,Xₙ) = Σᵢ H(Xᵢ | X₁,…,Xᵢ₋₁)
```

На трьох величинах це читається зовсім прозоро:

```
H(X₁,X₂,X₃) = H(X₁) + H(X₂|X₁) + H(X₃|X₁,X₂)
```

Невизначеність усього набору пізнаєш по одній величині за раз: перша коштує всю свою ентропію, кожна наступна — лише те, що ще лишилось непевним, коли всі попередні вже в руках. Порядок довільний — будь-яка з `n!` перестановок дає ту саму суму, бо ліва частина `H(X₁,…,Xₙ)` порядку не знає взагалі.

### Обумовлення не збільшує ентропію — і чому лише в середньому

Тепер найтонше: чому `H(X|Y) ≤ H(X)`. Щоб побачити це без зусиль, треба правильно поставити поруч дві величини — і помітити, що вони різняться лише **місцем усереднення**.

Окрема ймовірність `p(x)` — не самостійна річ поряд із `p(x|y)`, а їхнє середнє: `p(x) = Σ p(y)·p(x|y)`, суміш усіх умовних розподілів, зважена частотами підказок. Тож обидві наші величини — це те саме усереднення, застосоване по різні боки функції ентропії:

```
H(X)   = H( Σ p(y)·p(x|y) )      ← ентропія суміші розподілів  (усереднюємо ВСЕРЕДИНІ)
H(X|Y) = Σ p(y)·H( p(x|y) )      ← суміш ентропій               (усереднюємо ЗЗОВНІ)
```

Тут `H(p(x|y))` — ентропія цілого умовного розподілу за фіксованого `y` (це те саме `H(X|Y=y)`), а `H(Σ p(y)·p(x|y))` — ентропія суміші, яка є просто `H(X)`. Різниця між «ентропією середнього» і «середнім ентропій» цілком визначена формою функції `H` — а форма ця **угнута** (concave).

Доведімо угнутість. Ентропія — сума однакових доданків по координатах, `H(p) = Σᵢ φ(pᵢ)`, де `φ(t) = −t·log₂ t`. Друга похідна однієї такої ланки завжди від'ємна:

```
φ(t)  = −t·log₂ t
φ″(t) = −1 / (t·ln2) < 0          для 0 < t < 1
```

Від'ємна друга похідна означає, що `φ` строго угнута — її графік усюди прогинається донизу. А сума угнутих функцій, кожна від своєї координати, угнута як функція всього вектора: візьми два розподіли `p`, `q` і вагу `λ`; для кожної координати угнутість дає `φ(λpᵢ+(1−λ)qᵢ) ≥ λφ(pᵢ)+(1−λ)φ(qᵢ)`, а просумувавши по `i`, дістаєш `H(λp+(1−λ)q) ≥ λH(p)+(1−λ)H(q)`. Те саме з багатьма розподілами й вагами `p(y)` — це і є [нерівність Єнсена](book:math/convex-functions) (доведена данським математиком Йоганом Єнсеном 1906 року) для угнутої функції: значення в середньому не менше за середнє значень.

```
f( Σ wⱼ·vⱼ ) ≥ Σ wⱼ·f(vⱼ)         (f угнута; ваги wⱼ ≥ 0, Σ wⱼ = 1)
```

Підставмо `f = H`, точки `vⱼ = p(x|y)`, ваги `wⱼ = p(y)` — і нерівність лягає точно на наші дві величини:

```
H( Σ p(y)·p(x|y) )  ≥  Σ p(y)·H( p(x|y) )
   └──── H(X) ─────┘     └──── H(X|Y) ────┘
```

Отже `H(X) ≥ H(X|Y)`. Погляд на Y у середньому не робить тебе непевнішим щодо X.

Коли ж рівність? Строга угнутість `φ` означає, що покоординатна нерівність стає рівністю **тільки** там, де `pᵢ = qᵢ`; щоб рівною була вся сума, умовні розподіли `p(x|y)` мусять збігтися для всіх `y` з ненульовою вагою. А «умовний розподіл не залежить від `y`» — це рівно `p(x|y) = p(x)`, тобто **X і Y незалежні**. Тож `H(X|Y) = H(X)` точно тоді, коли підказка про X нічого не каже.

Це той самий факт, лише з іншого боку, що й невід'ємність [розбіжності Кульбака–Лейблера](book:math/kl-divergence): різниця `H(X) − H(X|Y)` дорівнює `Σ p(x,y)·log₂[p(x,y)/(p(x)·p(y))] = D(p(x,y) ‖ p(x)·p(y)) ≥ 0` за [нерівністю Гіббса](book:math/gibbs-inequality), з нулем знову тільки при незалежності. Дві двері — одна кімната.

> 🔧 **Навіщо це.** Угнутість — не технічна дрібниця, а причина всієї гарантії. Вона тримає **зважене середнє** значень функції під значенням у середній точці — і ані слова не каже про окреме значення. Кожне `H(X|Y=y)` — це висота угнутої кривої над однією вершиною; середнє цих висот сидить на хорді, під кривою; а `H(X)` — точка на самій кривій, над хордою. Але окрема вершина вільна стояти де завгодно, зокрема **вище** за `H(X)`. Тому «знання не шкодить» — твердження статистичне: воно про купу спостережень, не про кожне поодинці. Одному сумнівному вимірові довіряти рівно стільки ж підстав, скільки боятися, що воно збило з пантелику дужче за незнання.

*Чому нерівність тримає лише середнє. Крива — двійкова ентропія `H(q)`, угнута. Дві підказки садять X у точки `A` (`q=0.05`, часта) і `B` (`q=0.5`, рідкісна) на кривій. Суміш цих розподілів дає маргінал у точці `q̄=0.095`: на кривій це `H(X)=0.453` біта, а на хорді, точно під нею, — середнє залишків `H(X|Y)=0.358`. Крива над хордою, тож `H(X) ≥ H(X|Y)`, а зазор — це взаємна інформація. Та вершина `B` стоїть на висоті `1.0` — вище за `H(X)`: рідкісна підказка лишає більше непевності, ніж незнання. Угнутість утопила середнє, окрему вершину — ні.*

### Коли підказка шкодить — числа

Побудуймо той випадок навмисне. Хай X — біт (`0` чи `1`), а Y — прапорець якості з двома значеннями. Здебільшого канал чіткий, зрідка глухне:

- `Y=A` («чітко»), трапляється в `p(A)=0.9` випадків: тоді X майже певний, `p(X=1|A)=0.05`.
- `Y=B` («глухо»), у `p(B)=0.1`: тоді X — чистий кидок монети, `p(X=1|B)=0.5`.

Порахуймо залишок за кожної підказки, їхнє середнє, і — окремо — невизначеність X наосліп:

```
H(X|Y=A) = H(0.05) = 0.286 біта          (чітко: майже вгадано)
H(X|Y=B) = H(0.5)  = 1.000 біта          (глухо: повний здогад)

H(X|Y) = 0.9·0.286 + 0.1·1.000 = 0.358 біта     (середній залишок)

p(X=1) = 0.9·0.05 + 0.1·0.5 = 0.095
H(X)   = H(0.095) = 0.453 біта                   (наосліп)
```

(двійкова ентропія: `H(q) = −q·log₂ q − (1−q)·log₂(1−q)`, звідси `H(0.05)=0.286`, `H(0.095)=0.453`.)

Тепер порівняймо. Середнє слухняне: `H(X|Y) = 0.358 ≤ 0.453 = H(X)`, як і обіцяла нерівність. Але окреме значення бунтує: `H(X|Y=B) = 1.000 > 0.453 = H(X)`. Рідкісний прапорець «глухо» лишає **цілий біт** непевності — більше, ніж було наосліп. Це спостереження не прояснило X, а збило: після нього ти певен менше, ніж якби не дивився зовсім.

І все ж середнє тримається — саме так, як велить угнутість. Важка вершина `B` (біт непевності) рідкісна, вага `0.1`; часта вершина `A` (лише `0.286`) її з лишком перекриває, і зважене середнє `0.358` осідає під `H(X)`. Гарантія `H(X|Y) ≤ H(X)` пришпилює тільки цю зважену суму; окрему вершину вона лишає вільною — і та вільно стирчить вище. У цьому вся різниця між «в середньому» й «завжди»: перше — теорема, друге — хибне, і числа показують, де саме воно ламається.
