# 🧮 Математика заторів: Max-Min Fairness, Water-Filling та оптимізація Келлі

Задача розподілу ресурсів у графовій мережі полягає у визначенні вектора швидкостей джерел `x = (x[1], x[2], ..., x[N])` на графі `G = (V, E)` із заданими обмеженнями пропускної здатності ребер `C[e]` для кожного `e ∈ E`. Кожне джерело `i` передає трафік за маршрутом `R[i] ⊆ E`, який є підмножиною ребер графа.

Мережева матриця маршрутизації `A` розміром `|E| × N` визначається елементами:
- `A[e][i] = 1`, якщо потік `i` проходить через ребро `e` (`e ∈ R[i]`).
- `A[e][i] = 0` в іншому випадку.

Тоді сумарний потік через ребро `e` можна записати як векторний добуток `y[e] = (A · x)[e] = ∑_{i=1}^N A[e][i] · x[i]`.

---

## 1. Максимально-мінімальна справедливість (Max-Min Fairness)

Вектор швидкостей `x = (x[1], ..., x[N])` називається допустимим (feasible), якщо він задовольняє дві фундаментальні умови:
1. `x[i] ≥ 0` для всіх `i ∈ {1, ..., N}`.
2. `(A · x)[e] ≤ C[e]` для кожного ребра `e ∈ E`.

### Формальне означення Max-Min Fairness

Допустимий вектор `x` є **максимально-мінімально справедливим (Max-Min Fair)**, якщо для будь-якого іншого допустимого вектора `y`, збільшення швидкості одного з джерел `i` (тобто `y[i] > x[i]`) обов'язково призводить до зменшення швидкості деякого джерела `j`, чия швидкість вже є меншою або рівною швидкості `i` (тобто `y[j] < x[j] ≤ x[i]`).

Фізичний зміст цього означення полягає у тому, що система надає найвищий пріоритет джерелам із найгіршими умовами (найменшими швидкостями). Жоден потік не може покращити своє становище за рахунок потоків, які отримують стільки ж або менше ресурсів.

### Критерій вузького місця (Bottleneck Link Criterion)

Ребро `e ∈ E` називається **вузьким місцем (Bottleneck Link)** для потоку `i`, якщо виконуються дві умови:
1. Ребро повністю завантажене: `(A · x)[e] = C[e]`.
2. Швидкість потоку `i` є максимальною серед усіх потоків, що проходять через ребро `e`: `x[i] ≥ x[j]` для всіх `j` таких, що `A[e][j] = 1`.

**Теорема (Про еквівалентність та єдиність):** 
1. Допустимий вектор швидкостей `x` є максимально-мінімально справедливим тоді і тільки тоді, коли для кожного джерела `i` існує щонайменше одне ребро `e ∈ R[i]`, яке є для нього вузьким місцем.
2. Якщо пропускні здатності `C[e] > 0` і маршрути `R[i]` фіксовані, то вектор Max-Min Fair є єдиним.

## 2. Алгоритм заповнення водойми (Water-Filling Algorithm)

Алгоритм Water-Filling є точним конструктивним методом обчислення Max-Min Fair розподілу пропускної здатності на довільному графі.

### Покрокова процедура

```
Крок 0. Ініціалізація:
  Множина активних потоків A := {1, 2, ..., N}.
  Поточна швидкість усіх потоків x[i] := 0.
  Остаточна швидкість r[i] := 0.
  Залишкова ємність ребер C_rem[e] := C[e].

Поки A ≠ ∅ виконати:
  1. Обчислити рівномірний приріст λ[e] для кожного ребра e ∈ E:
     λ[e] = C_rem[e] / (кількість потоків із A, що проходять через e)

  2. Знайти мінімальний приріст λ_min по всіх ребрах:
     λ_min = min_{e ∈ E} λ[e]

  3. Для кожного потоку i ∈ A:
     x[i] := x[i] + λ_min

  4. Оновити залишкові ємності ребер:
     Для кожного e ∈ E:
       C_rem[e] := C_rem[e] - (кількість потоків із A через e) * λ_min

  5. Виявити насичені ребра (де C_rem[e] == 0).
     Видалити з множини A всі потоки, що проходять через насичені ребра.
```

### Практичний розрахунок для графа

Розглянемо мережевий граф із трьома ребрами:
- `E1` з ємністю `C[E1] = 4`
- `E2` з ємністю `C[E2] = 10`
- `E3` з ємністю `C[E3] = 8`

Чотири потоки мають такі маршрути:
- Потік 1: `R[1] = {E1}`
- Потік 2: `R[2] = {E2}`
- Потік 3: `R[3] = {E2, E3}`
- Потік 4: `R[4] = {E3}`

```
Ітерація 1:
  Активні потоки: A = {1, 2, 3, 4}.
  Навантаження на ребра:
    E1 проходить: {1} (1 потік)   → λ[E1] = 4 / 1 = 4.0
    E2 проходить: {2, 3} (2 потоки) → λ[E2] = 10 / 2 = 5.0
    E3 проходить: {3, 4} (2 потоки) → λ[E3] = 8 / 2 = 4.0

  Мінімальний приріст: λ_min = min(4.0, 5.0, 4.0) = 4.0.
  Додаємо 4.0 до всіх активних потоків:
    x[1] = 4.0,  x[2] = 4.0,  x[3] = 4.0,  x[4] = 4.0

  Оновлення залишкових ємностей:
    C_rem[E1] = 4.0 - 1*4.0 = 0.0  (Насичене!)
    C_rem[E2] = 10.0 - 2*4.0 = 2.0
    C_rem[E3] = 8.0 - 2*4.0 = 0.0  (Насичене!)

  Насичені ребра E1 та E3 блокують потоки {1, 3, 4}.
  Видаляємо їх із A. Нова множина A = {2}.

Ітерація 2:
  Активний потік: A = {2}.
  Ребро E2 має залишкову ємність C_rem[E2] = 2.0.
  Через E2 з активних проходить лише потік 2.
  Приріст для потоку 2:
    λ[E2] = 2.0 / 1 = 2.0.

  Оновлюємо швидкість потоку 2:
    x[2] = 4.0 + 2.0 = 6.0.

  C_rem[E2] = 2.0 - 1*2.0 = 0.0.
  Множина A порожня (A = ∅). Процедуру завершено.

Підсумковий Max-Min Fair вектор:
  x = (x[1]=4.0, x[2]=6.0, x[3]=4.0, x[4]=4.0)
```

## 3. Математика Network Utility Maximization (NUM Келлі)

Формалізація заторів через функції корисності дає неперервну оптимізаційну модель.

### Загальна постановка задачі

Кожне джерело `i` отримує корисність `U[i](x[i])` від швидкості `x[i]`. Функція `U[i]` є двічі неперервно диференційовною, строго зростаючою та строго угнутою (`U''[i](x[i]) < 0`).

Пряма задача (Primal Problem):
```
  max_{x ≥ 0}  ∑_{i=1}^N U[i](x[i])
  s.t.         ∑_{i: e ∈ R[i]} x[i] ≤ C[e]  для всіх e ∈ E
```

Оскільки сума строго угнутих функцій `∑ U[i](x[i])` є строго угнутою на опуклій допустимій множині `A · x ≤ C`, пряма задача має **єдиний глобальний максимум**.

### Подвоїста декомпозиція Лагранжа (Dual Decomposition)

Вводимо вектор множників Лагранжа `p = (p[e] ≥ 0)` для ребер `e ∈ E`, де `p[e]` означає ціну затору на ребрі `e`.

Функція Лагранжа:
```
  L(x, p) = ∑_{i=1}^N U[i](x[i]) - ∑_{e ∈ E} p[e] · ( ∑_{i: e ∈ R[i]} x[i] - C[e] )
```

Перегруповуючи доданки за джерелами `i`:
```
  L(x, p) = ∑_{i=1}^N [ U[i](x[i]) - x[i] · ( ∑_{e ∈ R[i]} p[e] ) ] + ∑_{e ∈ E} p[e] · C[e]
```

Позначимо сумарну ціну шляху потоку `i` як `q[i] = ∑_{e ∈ R[i]} p[e]`.

Оскільки за `x` функція розпадається на `N` незалежних підзадач, кожне джерело `i` розв'язує власну локальну задачу оптимізації:
```
  x[i]*(q[i]) = argmax_{x[i] ≥ 0} [ U[i](x[i]) - q[i] · x[i] ]
```

З умови першого порядку (`d/dx [U[i](x[i]) - q[i] · x[i]] = 0`):
```
  U'[i](x[i]*) = q[i]  ⇒  x[i]*(q[i]) = (U'[i])^{-1} ( ∑_{e ∈ R[i]} p[e] )
```

### Подвоїста задача та градієнтний спуск

Подвоїста функція (Dual Function):
```
  D(p) = max_{x ≥ 0} L(x, p)
```

Подвоїста задача полягає у мінімізації `D(p)` за умови `p ≥ 0`:
```
  min_{p ≥ 0} D(p)
```

Градієнт подвоїстої функції по ціні ребра `p[e]`:
```
  ∂D / ∂p[e] = C[e] - ∑_{i: e ∈ R[i]} x[i]*(q[i])
```

Динамічний градієнтний алгоритм оновлення цін на маршрутизаторах (проектований градієнтний спуск):
```
  p[e](t + 1) = max(0,  p[e](t) + γ · ( y[e](t) - C[e] ) )
```
де `y[e](t) = ∑_{i: e ∈ R[i]} x[i](t)` — сумарний агрегований потік через ребро `e`, а `γ > 0` — крок адаптації.

## 4. Концепція Альфа-справедливості (α-Fairness)

Параметричне сімейство функцій корисності, запроваджене Мо та Валрандом (Mo and Walrand, 2000), об'єднує всі відомі види справедливості через єдиний параметр `α > 0`:

```
  U[i](x) = x^(1 - α) / (1 - α)   при α > 0, α ≠ 1
  U[i](x) = log(x)                 при α = 1
```

Обчислюючи першу похідну `U'[i](x) = x^(-α)` та інвертуючи її, отримуємо зв'язок швидкості джерела від ціни затору `q[i]`:
```
  x[i]*(q[i]) = q[i]^(-1 / α) = ( ∑_{e ∈ R[i]} p[e] )^(-1 / α)
```

### Граничні значення параметру α

1. **`α → 0` (Максимізація пропускної здатності):** `U[i](x) = x`. Система ігнорує справедливість і віддає увесь ресурс найкоротшим потокам для максимізації `∑ x[i]`. Довгі потоки через декілька ребер отримують нульову швидкість (Starvation).
2. **`α = 1` (Пропорційна справедливість, Proportional Fairness):** `U[i](x) = log(x)`. Відносне збільшення швидкості одного потоку компенсує сумарне відносне зменшення інших. Відповідає поведінці TCP Vegas.
3. **`α = 2` (Справедливість, обернена затримці RTT):** `U[i](x) = -1 / x`. Відповідає класичному алгоритму AIMD / TCP Reno, де швидкість потоку обернено пропорційна RTT.
4. **`α → ∞` (Максимально-мінімальна справедливість, Max-Min Fairness):** `U[i](x) = -x^(-∞)`. У границі розв'язок задачі NUM строго збігається до результату алгоритму Water-Filling.

## 5. Доказ асимптотичної стійкості за Ляпуновим

Розглянемо безперервну динамічну систему оновлення цін заторів `p[e](t)` та швидкостей `x[i](t)`:

```
  dx[i] / dt = K[i] · ( U'[i](x[i]) - ∑_{e ∈ R[i]} p[e] )
  dp[e] / dt = γ · ( ∑_{i: e ∈ R[i]} x[i] - C[e] )_{p[e]}^+
```

Для доказу збіжності системи до стаціонарного стану `(x*, p*)` використаємо кандидатну функцію Ляпунова `V(x, p)`:

```
  V(x, p) = ∑_{i=1}^N ∫_{x[i]^*}^{x[i]} ( U'[i](s) - U'[i](x[i]*) ) ds + ∑_{e ∈ E} (1 / (2·γ)) · ( p[e] - p[e]* )²
```

Обчислюючи повну похідну по часу `dV / dt` уздовж траєкторій системи:

```
  dV / dt = ∑_{i=1}^N ( x[i] - x[i]* ) · ( dx[i] / dt ) + ∑_{e ∈ E} (1 / γ) · ( p[e] - p[e]* ) · ( dp[e] / dt )
```

Використовуючи строго угнутість `U[i]` (`(x[i] - x[i]*) · (U'[i](x[i]) - U'[i](x[i]*)) < 0` при `x[i] ≠ x[i]*`), отримуємо:

```
  dV / dt ≤ 0
```

Згідно з теоремою Ляпунова-ЛаСалля (LaSalle's Invariance Principle), похідна `dV / dt` дорівнює нулю тоді і тільки тоді, коли `x(t) = x*` та `p(t) = p*`. Це гарантує глобальну асимптотичну стійкість розподіленого алгоритму управління заторами.

## 6. Теорема дуальності та умови Каруша-Куна-Таккера (KKT)

Зв'язок між прямою задачею оптимізації швидкостей джерел та подвоїстою задачею обчислення цін заторів визначається теоремою строгої дуальності (Strong Duality Theorem).

Оскільки цільова функція `∑ U[i](x[i])` є строго угнутою, а обмеження `A · x ≤ C` є лінійними (що гарантує виконання умови Слейтера), зазор дуальності (Duality Gap) дорівнює нулю:

```
  max_{x ≥ 0} ∑_{i=1}^N U[i](x[i]) = min_{p ≥ 0} D(p)
```

Необхідні та достатні умови оптимальності Каруша-Куна-Таккера (KKT) для вектора `(x*, p*)`:

```
  1. Допустимість прямого розв'язку (Primal Feasibility):
     (A · x*)[e] ≤ C[e]   для всіх e ∈ E

  2. Допустимість подвоїстого розв'язку (Dual Feasibility):
     p*[e] ≥ 0           для всіх e ∈ E

  3. Доповнююча нежорсткість (Complementary Slackness):
     p*[e] · ( C[e] - (A · x*)[e] ) = 0   для всіх e ∈ E

  4. Оптимальність джерел (Stationarity):
     U'[i](x[i]*) = ∑_{e ∈ R[i]} p*[e]     для всіх i = 1, ..., N
```

Фізична інтерпретація умови доповнюючої нежорсткості:
- Якщо ребро `e` є неповністю завантаженим (`(A · x*)[e] < C[e]`), то ціна затору на ньому є строго нульовою (`p*[e] = 0`).
- Якщо ціна затору на ребрі є додатною (`p*[e] > 0`), це ребро обов'язково завантажене на 100% від своєї ємності (`(A · x*)[e] = C[e]`).

Це показує, що ціна затору `p*[e]` діє як економічний балансир: вона виникає лише на вузьких місцях мережевого графа і змушує джерела трафіку знижувати свої швидкості до рівня, що відповідає фізичним обмеженням інфраструктури.
