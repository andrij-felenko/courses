# 🧮 Доведення теорем Кеніга, Холла та Бержа

У комбінаторній теорії графів три класичні фундаментальні теореми — лема Бержа, теорема Кеніга та теорема Холла — утворюють єдину замкнену математичну систему. Вони пов'язують вимір максимального паросполучення, розмір мінімального вершинного покриття та структурні умови існування досконалого розв'язку.

### 1. Лема Бержа про доповнюючі шляхи (1957)

Нехай `G = (V, E)` — довільний граф, а `M ⊆ E` — дещо паросполучення у ньому. Вершина `v ∈ V` називається **вільною** (або непокритою) відносно `M`, якщо жодне ребро з `M` не інцидентне `v`. 

Шлях `P = (v₀, v₁, v₂, ..., vₖ)` називається **змінним** (англ. *alternating path*), якщо його ребра почергово належать `E \ M` та `M`. Якщо додатково обидва кінці `v₀` та `vₖ` є **вільними** вершинами, шлях `P` називається **доповнюючим** (англ. *augmenting path*).

#### Формулювання леми Бержа

Паросполучення `M` є максимальним за потужністю у графі `G` тоді й лише тоді, коли у `G` не існує жодного доповнюючого шляху відносно `M`.

#### Доведення

**Необхідність (⇒):** Нехай у графі `G` існує доповнюючий шлях `P` відносно `M`. Позначимо через `M' = M ⊕ P` симетричну різницю множин ребер `(M \ P) ∪ (P \ M)`. 

Оскільки `P` починається й закінчується вільними вершинами і почергово змінює ребра з `E \ M` та `M`, кількість ребер у `P`, що належать `E \ M`, строго на одиницю більша за кількість ребер з `M`:

```
|P ∩ (E \ M)| = |P ∩ M| + 1
```

Після заміни ребер `P ∩ M` на ребра `P ∩ (E \ M)` кожна внутрішня вершина шляху `P` залишається інцидентною рівно одному ребру з `M'`, а кінцеві вершини `v₀` та `vₖ` стають покритими. Отже, `M'` є коректним паросполученням, і його розмір дорівнює:

```
|M'| = |M| + 1          [завдяки інверсії ребер доповнюючого шляху P]
```

Отже, `M` не було максимальним.

**Достатність (⇐):** Нехай `M` не є максимальним паросполученням. Тоді існує дещо паросполучення `M*` таке, що `|M*| > |M|`. Розглянемо підграф `H = (V, M ⊕ M*)`.

Оскільки в `M` та `M*` з кожної вершини виходить не більше одного ребра, у підграфі `H` кожна вершина має степінь не більше 2 (`deg_H(v) ≤ 2`). Це означає, що кожна зв'язна компонента підграфа `H` є або ізольованою вершиною, або простим шляхом, або простим циклом.

Усі шляхи й цикли в `H` почергово складаються з ребер `M` та `M*`:
1. Жоден цикл не може мати непарну довжину, оскільки ребра почергово змінюються між `M` та `M*`. Отже, у будь-якому циклі кількість ребер з `M` дорівнює кількості ребер з `M*`.
2. Оскільки `|M*| > |M|`, загальна кількість ребер з `M*` у підграфі `H` строго більша за кількість ребер з `M`.
3. Отже, у підграфі `H` обов'язково знайдеться принаймні один шлях `P`, у якому ребер з `M*` більше, ніж ребер з `M`.

Такий шлях `P` мусить починатися й закінчуватися ребрами з `M*`. Це означає, що його кінцеві вершини є вільними відносно `M`. Отже, шлях `P` є доповнюючим шляхом для `M` у графі `G`. Лему Бержа доведено.

### 2. Теорема Кеніга про вершинне покриття (1916)

**Множиною вершинного покриття** (англ. *vertex cover*) графа `G = (V, E)` називається підмножина вершин `C ⊆ V` така, що кожне ребро `e = (u, v) ∈ E` має принаймні один кінець у `C` (`u ∈ C` або `v ∈ C`).

#### Формулювання теореми Кеніга

У будь-якому скінченному дводольному графі `G = (U, V, E)` розмір максимального паросполучення `|M_max|` дорівнює розміру мінімального вершинного покриття `|C_min|`:

```
|M_max| = |C_min|
```

#### Доведення

Для будь-якого графа `G` і будь-якого паросполучення `M` та покриття `C` виконується нерівність `|M| ≤ |C|`, оскільки кожне ребро з `M` має покриватися окремою вершиною з `C`, а ребра з `M` не мають спільних вершин. Отже, `|M_max| ≤ |C_min|`.

Для доведення рівності `|M_max| = |C_min|` у дводольному графі побудуємо покриття `C` розміром строго `|M_max|`.

Нехай `M` — максимальне паросполучення у дводольному графі `G = (U, V, E)`. Позначимо через `U_free ⊆ U` множину вершин частки `U`, які є вільними відносно `M`.

Побудуємо множину `Z ⊆ V(G)` усіх вершин, досяжних із `U_free` за допомогою змінних шляхів відносно `M`. Побудову виконуємо методом обходу:
- Усі вільні вершини `U_free` належать `Z`.
- Якщо `u ∈ Z ∩ U` і `(u, v) ∈ E \ M`, то `v ∈ Z ∩ V`.
- Якщо `v ∈ Z ∩ V` і `(u, v) ∈ M`, то `u ∈ Z ∩ U`.

Сформуємо множину вершин `C`:

```
C = (U \ Z) ∪ (V ∩ Z)
```

Покажемо, що `C` є покриттям і `|C| = |M|`:

1. **`C` є вершинним покриттям:** Припустимо, існує ребро `e = (u, v) ∈ E`, яке не покрите `C`, тобто `u ∉ C` і `v ∉ C`.
   - Оскільки `u ∉ C`, то `u ∈ Z ∩ U` (вершина `u` досяжна зі змінних шляхів).
   - Оскільки `v ∉ C`, то `v ∉ Z ∩ V` (вершина `v` недосяжна).
   - Якщо `(u, v) ∈ E \ M`, то з `u ∈ Z ∩ U` випливає, що `v` також має бути додана до `Z ∩ V`, що суперечить `v ∉ Z`.
   - Якщо `(u, v) ∈ M`, то оскільки `u ∈ Z ∩ U`, вершина `u` була досягнута через ребро з `M` від дещо `v' ∈ Z ∩ V`. Але вершина `u` може мати лише одне парне ребро у `M`, яким і є `(u, v)`. Отже, `v` мала бути в `Z`, що знову дає суперечність.
   - Таким чином, усі ребра графа `E` покриті множиною `C`.

2. **Розмір `|C| = |M|`:**
   - Жодна вільна вершина з `V` не може належати `Z ∩ V`, інакше існував би доповнюючий шлях від `U_free` до цієї вільної вершини з `V`, що суперечило б максимальності `M` за лемою Бержа.
   - Отже, кожна вершина `v ∈ Z ∩ V` є покритою ребром з `M`, причому відповідний парний сусід `u` також належить `Z ∩ U`.
   - Кожна вершина `u ∈ U \ Z` є покритою ребром з `M` (бо `U_free ⊆ Z`).
   - Кожне ребро з `M` містить або одну вершину з `Z ∩ V`, або одну вершину з `U \ Z`, але ніколи дві одразу.
   - Отже, рівно одна вершина з кожного ребра `M` потрапляє до `C`, звідки `|C| = |M|`.

Оскільки `|M_max| ≤ |C_min| ≤ |C| = |M_max|`, маємо строго `|M_max| = |C_min|`. Теорему Кеніга доведено.

### 3. Теорема Холла про весілля (1935)

Для підмножини вершин `S ⊆ U` позначимо через `N(S) ⊆ V` множину всіх сусідів вершин з `S`:

```
N(S) = { v ∈ V | ∃ u ∈ S: (u, v) ∈ E }
```

#### Формулювання теореми Холла

У дводольному графі `G = (U, V, E)` існує паросполучення, яке покриває всі вершини частки `U` (тобто `|M| = |U|`), тоді й лише тоді, коли для будь-якої підмножини `S ⊆ U` виконується **умова Холла**:

```
|N(S)| ≥ |S|
```

#### Доведення

**Необхідність (⇒):** Якщо існує паросполучення `M`, яке покриває `U`, то кожній вершині `u ∈ S` відповідає унікальна парна вершина `v ∈ N(S)`. Оскільки всі ці парні вершини різні, кількість сусідів `|N(S)|` не може бути меншою за `|S|`.

**Достатність (⇐):** Доведемо за допомогою теореми Кеніга. Припустимо, що умова Холла виконується для всіх `S ⊆ U`, але паросполучення розміром `|U|` не існує. 

Це означає, що `|M_max| < |U|`. За теоремою Кеніга існує вершинне покриття `C = A ∪ B`, де `A = C ∩ U` та `B = C ∩ V`, таке що:

```
|C| = |A| + |B| = |M_max| < |U|
```

Розглянемо множину вершин `S = U \ A`. Оскільки `|A| + |B| < |U|`, маємо:

```
|S| = |U| - |A| > |B|          [розмір S строго більший за розмір частини покриття B]
```

Покажемо, що всі сусіді множини `S` лежать у `B`. Припустимо існування ребра `(u, v) ∈ E` такого, що `u ∈ S` і `v ∉ B`. 
Оскільки `u ∈ S = U \ A`, вершина `u ∉ A`. Таким чином, ані `u`, ані `v` не належать покриттю `C = A ∪ B`, тобто ребро `(u, v)` не покрите `C`, що суперечить визначенню покриття.

Отже, `N(S) ⊆ B`. Звідси отримуємо:

```
|N(S)| ≤ |B| < |S|
```

Отримали суперечність з умовою Холла `|N(S)| ≥ |S|`. Отже, припущення невірне, і паросполучення розміру `|U|` завжди існує. Теорему Холла доведено.

### 4. Двоїстість у лінійному програмуванні та цілковита унімодулярність

Теорема Кеніга є яскравим прикладом симетричної двоїстості у теорії лінійного програмування. Запишемо задачу про максимальне дводольне паросполучення як оптимізаційну задачу з 0-1 змінними `x_{e} ∈ {0, 1}` для кожного ребра `e = (u, v) ∈ E`:

Пряма задача (Primal LP):
```text
максимізувати   sum_{e ∈ E} x_{e}
за умов:        sum_{e ∈ δ(u)} x_{e} ≤ 1   для всіх u ∈ U
                sum_{e ∈ δ(v)} x_{e} ≤ 1   для всіх v ∈ V
                x_{e} ≥ 0                   для всіх e ∈ E
```

Двоїста задача (Dual LP) заводиться з двома групами змінних `y_u ≥ 0` для `u ∈ U` та `z_v ≥ 0` для `v ∈ V`:
```text
мінімізувати    sum_{u ∈ U} y_u + sum_{v ∈ V} z_v
за умов:        y_u + z_v ≥ 1              для всіх e = (u, v) ∈ E
                y_u ≥ 0, z_v ≥ 0            для всіх u, v
```

У двоїстій задачі змінні `y_u` та `z_v` приймають значення 1, якщо відповідна вершина потрапляє до покриття `C`, і 0 у протилежному випадку. Нераціональність дробових розв'язків усувається властивістю **цілковитої унімодулярності** (англ. *total unimodularity*):

Матриця інцидентності `A` дводольного графа (де рядки відповідають вершинам, а стовпчики — ребрам) має в кожному стовпчику рівно дві одиниці (одну в частині `U`, одну в частині `V`). Визначник будь-якої квадратної підматриці `A` дорівнює 0, 1 або -1.

Згідно з теоремою Пуанкаре–Гельфанда, якщо матриця обмежень `A` є цілком унімодулярною, а вектор правої частини цілочисельний (у нашому випадку одні одиниці), то всі вершини опуклого багатогранника допустимих розв'язків LP є **строго цілочисельними**. 

Це пояснює, чому невід'ємна релаксація `x_{e} ∈ [0, 1]` дає той самий екстремум, що й дискретне 0-1 програмування, а двоїстий оптимум LP строго дорівнює `|M_max| = |C_min|`.

### 5. Теорема Біркгофа–фон Неймана про подвійно стохастичні матриці

Розвиваючи алгебраїчний підхід до досконалих паросполучень у повних дводольних графах, Гарет Біркгоф (1946) та Джон фон Нейман (1953) довели теорему про структуру подвійно стохастичних матриць.

Квадратна матриця `P` розміром `n × n` називається **подвійно стохастичною**, якщо всі її елементи `p_{i,j} ≥ 0`, а сума елементів у кожному рядку й у кожному стовпчику дорівнює 1:

```text
sum_{j=1}^n p_{i,j} = 1  (для всіх i)
sum_{i=1}^n p_{i,j} = 1  (для всіх j)
```

Матриця `P` називається **матрицею перестановок** (англ. *permutation matrix*), якщо вона містить рівно одну одиницю в кожному рядку й кожному стовпчику, а решта елементів — нулі. Матриця перестановок відповідає досконалому паросполученню у повному дводольному графі `K_{n,n}`.

#### Формулювання теореми Біркгофа–фон Неймана

Множина всіх подвійно стохастичних матриць розміру `n × n` утворює опуклий багатогранник (багатогранник Біркгофа `Ω_n`), вершинними точками якого є рівно `n!` матриць перестановок. Будь-яка подвійно стохастична матриця `P` може бути представлена як опукла комбінація матриць перестановок `P_k`:

```text
P = sum_{k=1}^m λ_k P_k,   де λ_k ≥ 0  та  sum_{k=1}^m λ_k = 1
```

Доведення цієї теореми базується на послідовному виділенні паросполучення за допомогою теореми Холла та індукції за кількістю ненульових елементів матриці `P`.

### 6. Практичний чисельний приклад

Розглянемо дводольний граф `G = (U, V, E)`, де `U = {u₁, u₂, u₃, u₄}`, `V = {v₁, v₂, v₃, v₄}`.
Список ребер:

```
E = { (u₁, v₁), (u₁, v₂), (u₂, v₂), (u₂, v₃), (u₃, v₁), (u₃, v₃), (u₄, v₃) }
```

#### Крок 1. Перевірка умови Холла для підмножини `S = {u₂, u₃, u₄}`

```
N({u₂, u₃, u₄}) = N(u₂) ∪ N(u₃) ∪ N(u₄)
                = {v₂, v₃} ∪ {v₁, v₃} ∪ {v₃}
                = {v₁, v₂, v₃}

|S| = 3
|N(S)| = |{v₁, v₂, v₃}| = 3 >= 3     [умова Холла виконується для S]
```

Однак для підмножини `S' = {u₂, u₄}`:

```
N({u₂, u₄}) = {v₂, v₃}
|S'| = 2, |N(S')| = 2 >= 2
```

Умова Холла виконується для всіх підмножин, отже повне паросполучення існує.

#### Крок 2. Побудова максимального паросполучення `M`

Шляхом послідовного пошуку доповнюючих шляхів отримуємо:

```
M = { (u₁, v₁), (u₂, v₂), (u₃, v₃) }
```

Зараз `u₄` вільна. Спробуємо знайти доповнюючий шлях для `u₄`:
1. `u₄` з'єднана з `v₃`. `v₃` покрита ребром `(u₃, v₃)`.
2. З `u₃` є альтернативне ребро до `v₁`. `v₁` покрита ребром `(u₁, v₁)`.
3. З `u₁` є альтернативне ребро до `v₂`. `v₂` покрита ребром `(u₂, v₂)`.
4. З `u₂` є лише ребро до `v₃`, де ми вже були. Тупік.

Доповнюючий шлях від `u₄` відсутній. Отже `|M_max| = 3`.

#### Крок 3. Побудова мінімального вершинного покриття `C`

Використовуємо алгоритм з доведення теореми Кеніга:
- `U_free = {u₄}`.
- Шукаємо досяжні вершини `Z`:
  - З `u₄` по ребрах поза `M` досягаємо `v₃`.
  - З `v₃` по ребру з `M` досягаємо `u₃`.
  - З `u₃` по ребрах поза `M` досягаємо `v₁`.
  - З `v₁` по ребру з `M` досягаємо `u₁`.
  - З `u₁` по ребрах поза `M` досягаємо `v₂`.
  - З `v₂` по ребру з `M` досягаємо `u₂`.

Отримуємо:

```
Z ∩ U = {u₁, u₂, u₃, u₄}
Z ∩ V = {v₁, v₂, v₃}

C = (U \ Z) ∪ (V ∩ Z)
  = ∅ ∪ {v₁, v₂, v₃}
  = {v₁, v₂, v₃}
```

Перевірка розміру: `|C| = 3 = |M_max|`. Усі ребра графа `E` мають хоча б один кінець у `{v₁, v₂, v₃}`. Теорема Кеніга підтверджена практично.
