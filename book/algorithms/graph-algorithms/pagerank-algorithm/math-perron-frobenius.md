# 🧮 Теорема Перрона — Фробеніуса та збіжність PageRank

Ця математична вставка містить строге обґрунтування існування, єдиності та експоненційної швидкості збіжності вектора PageRank на основі спектральної теорії невід'ємних матриць, топологічних властивостей одиничного симплекса та теореми Перрона — Фробеніуса.

### Стохастичні матриці та спектральний радіус

Нехай `M` — квадратна матриця розміру `N × N` з дійсними елементами. Матриця називається невід'ємною (`M ≥ 0`), якщо всі її елементи задовольняють умову `M[i, j] ≥ 0`.

Матриця `M` називається **стовпчиково-стохастичною** (або марківською), якщо сума елементів у кожному її стовпці строго дорівнює одиниці:

```
∑ M[i, j] = 1    [сума за всіма рядками i від 1 до N для фіксованого стовпця j]
```

Позначимо через `e = [1, 1, ..., 1]ᵀ` вектор-стовпець з одиниць розмірності `N`. Тоді умова стовпчикової стохастичності еквівалентна векторному множенню матриці зліва на транспонований вектор `eᵀ`:

```
eᵀ · M
= [∑ M[i, 1], ∑ M[i, 2], ..., ∑ M[i, N]]    [множення рядка з одиниць на стовпці M]
= [1, 1, ..., 1]                             [за означенням стохастичності стовпців]
= eᵀ                                         [отримали початковий вектор eᵀ]
```

Оскільки `eᵀ · M = 1 · eᵀ`, вектор `e` є лівим власним вектором матриці `M`, що відповідає власному значенню `λ = 1`. Оскільки спектри матриці `M` та її транспонованої `Mᵀ` повністю збігаються, `λ = 1` обов'язково є власним значенням і для правої задачі на власні вектори:

```
M · r = 1 · r
```

Покажемо, що спектральний радіус стохастичної матриці не перевищує одиниці: `ρ(M) = max |λ| ≤ 1`. Нехай `λ` — довільне власне значення, а `x` — відповідний йому правий власний вектор, тобто `M · x = λ · x`. Розглянемо L1-норму обох частин:

```
|λ| · ||x||₁
= ||λ · x||₁         [властивість норми: винесення скаляра за знак модуля]
= ||M · x||₁         [підстановка власного рівняння M · x = λ · x]
= ∑ |∑ M[i, j] · x[j]| [запис L1-норми за означенням]
≤ ∑ ∑ M[i, j] · |x[j]| [нерівність трикутника та невід'ємність елементів M[i, j] ≥ 0]
= ∑ |x[j]| · (∑ M[i, j]) [перестановка порядку сумування за стовпцями]
= ∑ |x[j]| · 1       [стовпчикова стохастичність: ∑_{i} M[i, j] = 1]
= ||x||₁             [запис суми модулів як L1-норми вектора x]
```

Скоротивши обидві частини на `||x||₁ > 0`, отримуємо фундаментальну нерівність:

```
|λ| ≤ 1    [спектральний радіус довільної стохастичної матриці обмежений одиницею]
```

Це доводить, що максимальне за модулем власне значення стовпчиково-стохастичної матриці завжди дорівнює `λ₁ = 1`.

### Побудова матриці Гугла та теорема Перрона

Вихідна матриця гіперпосилань вебграфа `M` містить нульові стовпці для висячих вузлів (сторінок без вихідних посилань) та блочно-діагональні структури для павутинних пасток. Через це власне значення `λ = 1` може мати кратність більше одиниці, а відповідний власний підпростір — містити вектори з нульовими компонентами.

Щоб гарантувати регулярність спектра, будується строго додатна матриця Гугла `G`:

1. Спочатку нульові стовпці висячих вузлів замінюються на рівномірний розподіл `(1 / N) · e`, утворюючи стовпчиково-стохастичну матрицю `M̂`.
2. Потім додається матриця телепортації з коефіцієнтом згасання `d ∈ (0, 1)`:

```
G = d · M̂ + ((1 - d) / N) · e · eᵀ
```

Кожен елемент матриці `G` строго додатний. Оскільки `M̂[i, j] ≥ 0`, а доданок телепортації строго більший за нуль:

```
G[i, j]
= d · M̂[i, j] + (1 - d) / N    [розклад елемента матриці G]
≥ 0 + (1 - d) / N               [оскільки d · M̂[i, j] ≥ 0]
> 0                             [оскільки d < 1 та N ≥ 1]
```

Крім того, матриця `G` зберігає стовпчикову стохастичність:

```
eᵀ · G
= d · (eᵀ · M̂) + ((1 - d) / N) · (eᵀ · e) · eᵀ    [дистрибутивність множення на eᵀ]
= d · eᵀ + ((1 - d) / N) · N · eᵀ                  [оскільки eᵀ · M̂ = eᵀ та eᵀ · e = N]
= d · eᵀ + (1 - d) · eᵀ                            [скорочення N / N = 1]
= (d + 1 - d) · eᵀ                                 [групування скалярних коефіцієнтів]
= 1 · eᵀ                                           [сума елементів у кожному стовпці строго 1]
```

Для строго додатних матриць діє класична **теорема Перрона** (частина фундаментальної спектральної теорії Перрона — Фробеніуса):

> **Теорема Перрона.** Якщо квадратна дійсна матриця `G` строго додатна (`G[i, j] > 0` для всіх `i, j`), то:
> 1. Спектральний радіус `ρ(G) = 1` є простим власним значенням (його алгебраїчна та геометрична кратність строго дорівнює одиниці).
> 2. Відповідний правий власний вектор `r*` (`G · r* = r*`) є строго додатним у всіх своїх компонентах: `r*[i] > 0` для всіх `i = 1, ..., N`.
> 3. Будь-яке інше власне значення `λ` матриці `G` строго менше за модулем: `|λ| < 1`.

#### Топологічне доведення через нерухому точку Брауера

Існування додатного власного вектора можна наочно проілюструвати топологічно. Розглянемо стандартний одиничний симплекс у просторі `ℝᴺ`:

```
Δ = {x ∈ ℝᴺ : x[i] ≥ 0 для всіх i, ∑ x[i] = 1}
```

Множина `Δ` є непорожнім, компактним (замкненим та обмеженим) та опуклим підпростором.

Оскільки матриця `G` невід'ємна та стохастична за стовпцями, для будь-якого вектора `x ∈ Δ` маємо `(G · x)[i] ≥ 0` та `eᵀ · (G · x) = (eᵀ · G) · x = eᵀ · x = 1`. Отже, лінійне відображення `f(x) = G · x` переводить симплекс `Δ` у самого себе: `f(Δ) ⊆ Δ`.

За теоремою Брауера про нерухому точку, будь-яке неперервне відображення компактної опуклої множини в себе має щонайменше одну нерухому точку `r* ∈ Δ`, таку що:

```
G · r* = r*
```

Оскільки `G[i, j] ≥ (1 - d) / N > 0` та `∑ r*[j] = 1`, для кожного компонента маємо:

```
r*[i] = ∑ G[i, j] · r*[j] ≥ ∑ ((1 - d) / N) · r*[j] = (1 - d) / N > 0
```
що строгим чином доводить строгу додатність усіх елементів вектора `r*`.

### Оцінка другого власного значення: спектральний зазор

Швидкість збіжності ітераційних методів знаходження вектора `r*` безпосередньо залежить від величини другого за модулем власного значення `|λ₂|`. Доведемо точну теорему про спектральний зазор матриці Гугла:

```
|λ₂| ≤ d
```

Нехай `λ` — довільне власне значення матриці `G`, відмінне від домінантного `λ₁ = 1`, а `v` — відповідний йому власний вектор: `G · v = λ · v`.

Помножимо це рівняння зліва на одиничний вектор-рядок `eᵀ`:

```
eᵀ · (G · v)
= (eᵀ · G) · v     [асоціативність матричного множення]
= eᵀ · v           [оскільки eᵀ · G = eᵀ за стохастичністю G]
```

З іншого боку, використовуючи властивість власного вектора `G · v = λ · v`:

```
eᵀ · (G · v)
= eᵀ · (λ · v)     [підстановка власного вектора]
= λ · (eᵀ · v)     [винесення скалярного множника λ]
```

Прирівнюючи ліву та праву частини, маємо:

```
1 · (eᵀ · v) = λ · (eᵀ · v)
(1 - λ) · (eᵀ · v) = 0
```

Оскільки за припущенням `λ ≠ 1`, маємо `(1 - λ) ≠ 0`. Отже, єдиним можливим розв'язком є рівність:

```
eᵀ · v = 0    [сума всіх компонентів недомінантного власного вектора дорівнює нулю]
```

Тепер підставимо вектор `v` безпосередньо у визначення матриці Гугла `G · v`:

```
G · v
= (d · M̂ + ((1 - d) / N) · e · eᵀ) · v    [розкриття формули матриці Гугла]
= d · M̂ · v + ((1 - d) / N) · e · (eᵀ · v) [дистрибутивність множення на вектор v]
= d · M̂ · v + ((1 - d) / N) · e · 0        [підстановка знайденої тотожності eᵀ · v = 0]
= d · M̂ · v                                [доданок телепортації повністю зникає]
```

Оскільки `G · v = λ · v`, отримуємо рівність:

```
λ · v = d · M̂ · v
```

Візьмемо L1-норму від обох частин:

```
|λ| · ||v||₁
= ||λ · v||₁        [винесення скаляра за модуль]
= ||d · M̂ · v||₁    [підстановка рівності λ · v = d · M̂ · v]
= d · ||M̂ · v||₁    [винесення додатного скаляра d > 0]
≤ d · ||v||₁        [оскільки операторна L1-норма стохастичної матриці ||M̂||₁ = 1]
```

Скоротивши на `||v||₁ > 0`, отримуємо остаточну нерівність:

```
|λ| ≤ d    [будь-яке недомінантне власне значення за модулем не перевищує коефіцієнт d]
```

Звідси випливає, що спектральний зазор між провідним власним значенням `λ₁ = 1` та всіма іншими власними значеннями задовольняє умову:

```
1 - |λ₂| ≥ 1 - d
```

Для канонічного значення `d = 0.85` спектральний зазор становить щонайменше `0.15`.

### Доведення збіжності степеневого методу

Степеневий метод стартує з довільного вектора розподілу ймовірностей `r⁽⁰⁾ ∈ Δ`, де `r⁽⁰⁾[i] ≥ 0` та `eᵀ · r⁽⁰⁾ = 1`.

Розглянемо вектор похибки на нульовому кроці `w = r⁽⁰⁾ - r*`. Сума його елементів дорівнює нулю:

```
eᵀ · w
= eᵀ · (r⁽⁰⁾ - r*)    [підстановка визначення вектора w]
= eᵀ · r⁽⁰⁾ - eᵀ · r*  [лінійність множення вектора-рядка]
= 1 - 1               [обидва вектори лежать на одиничному симплексі]
= 0                   [вектор похибки належить підпростору з нульовою сумою елементів]
```

Застосуємо `k` кроків степеневого методу `r⁽ᵏ⁾ = Gᵏ · r⁽⁰⁾`:

```
r⁽ᵏ⁾
= Gᵏ · (r* + w)         [підстановка розкладу початкового вектора]
= Gᵏ · r* + Gᵏ · w      [лінійність матричного степеня]
= 1ᵏ · r* + Gᵏ · w      [оскільки r* є власним вектором із λ = 1]
= r* + Gᵏ · w           [одиничний скаляр у довільному степені дорівнює одиниці]
```

Оцінимо L1-норму різниці між поточним наближенням та точним розв'язком:

```
||r⁽ᵏ⁾ - r*||₁
= ||Gᵏ · w||₁          [норма вектора похибки після k ітерацій]
= ||G · (Gᵏ⁻¹ · w)||₁  [виділення останнього кроку множення]
≤ d · ||Gᵏ⁻¹ · w||₁    [застосування нерівності ||G · x||₁ ≤ d · ||x||₁ для eᵀ · x = 0]
≤ d² · ||Gᵏ⁻² · w||₁   [послідовна індукція за всіма кроками]
≤ dᵏ · ||w||₁          [геометричне стягування похибки]
```

Оскільки `||r⁽⁰⁾||₁ = 1` та `||r*||₁ = 1`, за нерівністю трикутника маємо `||w||₁ = ||r⁽⁰⁾ - r*||₁ ≤ ||r⁽⁰⁾||₁ + ||r*||₁ = 2`. Звідси випливає безумовна верхня межа похибки:

```
||r⁽ᵏ⁾ - r*||₁ ≤ 2 · dᵏ
```

### Чутливість ранжування та вибір параметра згасання

Коефіцієнт згасання `d` виконує роль регулятора між двома протилежними вимогами:

1. **Точність відображення структури зв'язків:** при `d → 1` матриця `G` наближається до чистого графа посилань `M̂`, максимально повно враховуючи авторитет донорів. Проте при `d = 0.99` спектральний зазор скорочується до `1 - d = 0.01`, що збільшує кількість необхідних ітерацій у 15 разів.
2. **Чисельна стійкість та захист від спаму:** при `d → 0` спектральний зазор прямує до 1, збіжність стає майже миттєвою, проте вектор рангів вироджується в тривіальний константний вектор `[1/N, ..., 1/N]ᵀ`, повністю втрачаючи інформацію про топологію мережі.

Значення `d = 0.85` є оптимальним компромісом: воно забезпечує високу роздільну здатність ранжування за топологією графа, стійкість до штучних ферм посилань та швидку геометричну збіжність за 40–60 ітерацій.
