# 🧮 Математика інваріантів та доведення алгоритму Беллмана–Форда

Ця вставка містить строге математичне доведення інваріанта k-крокових найкоротших шляхів, леми про обмеження кількості ребер у простих шляхах, властивостей монотонності й збіжності послаблень, а також теорем про критерій від'ємного циклу, системи різницевих обмежень, тропічну алгебру та потенційне перезважування Джонсона.

---

### Постановка задачі та формальні визначення

Нехай задано зважений орієнтований граф `G = (V, E)` із множиною вершин `V` (`|V| = n`) та множиною орієнтованих ребер `E` (`|E| = m`). Кожному ребру `(u, v) ∈ E` приписано дійсну вагу `w(u, v) ∈ ℝ`, яка може бути додатною, нульовою або від'ємною.

Шляхом `P` від стартової вершини `s` до вершини `v` називається послідовність вершин `P = (v₀, v₁, v₂, ..., vₖ)`, де `v₀ = s`, `vₖ = v`, і для всіх `i ∈ {1, ..., k}` виконується `(vᵢ₋₁, vᵢ) ∈ E`. Кількість ребер у шляху дорівнює `k`, а загальна вага шляху `w(P)` визначається як сума ваг його складових ребер:

```
w(P) = ∑_{i=1}^{k} w(v_{i-1}, v_i)
```

Точна найкоротша відстань `δ(s, v)` від джерела `s` до вершини `v` визначається як інфімум ваг усіх можливих шляхів між `s` та `v`:

```
δ(s, v) = min { w(P) : P — шлях від s до v }
```

Якщо між `s` та `v` не існує жодного шляху, то за означенням `δ(s, v) = +∞`. Якщо ж існує принаймні один шлях від `s` до `v`, який проходить через замкнений контур (цикл) із від'ємною сумарною вагою, то шляхи можуть мати довільно малу вагу, і тоді `δ(s, v) = -∞`.

Математична складність задач із від'ємними вагами полягає у втраті властивості фундованості (англ. *well-foundedness*): у множині дійсних чисел з від'ємними додаваннями можна будувати нескінченно спадні послідовності `w(P₁) > w(P₂) > w(P₃) > ...`, де кожен наступний обхід циклу робить оцінку ще меншою. Саме тому динамічне програмування Беллмана–Форда вводить штучне обмеження на кількість ребер у шляху `k`, відновлюючи скінченну дискретну структуру підзадач.

---

### Покроковий приклад обчислення оцінок та підзадач

Щоб проілюструвати обчислювальну алгебру динамічного програмування, розглянемо невеликий граф із 4 вершин `V = {s, v₁, v₂, v₃}` та ребрами:
- `(s, v₁)`, `w = 2`
- `(s, v₂)`, `w = 5`
- `(v₁, v₂)`, `w = -4`
- `(v₂, v₃)`, `w = 3`
- `(v₁, v₃)`, `w = 1`

Простежимо зміну значення `d^(k)[v₂]` для вершини `v₂` на раундах `k = 0, 1, 2` згідно з рекурентним співвідношенням ДП:

```
d^(0)[v₂]
= +∞                                           [базовий стан для v₂ ≠ s]

d^(1)[v₂]
= min( d^(0)[v₂],  d^(0)[s] + w(s, v₂),  d^(0)[v₁] + w(v₁, v₂) )
= min( +∞,  0 + 5,  +∞ + (-4) )                [підстановка оцінок з раунду k=0]
= min( +∞,  5,  +∞ )                           [арифметика з нескінченністю]
= 5                                            [вибір мінімального значення]

d^(2)[v₂]
= min( d^(1)[v₂],  d^(1)[s] + w(s, v₂),  d^(1)[v₁] + w(v₁, v₂) )
= min( 5,  0 + 5,  2 + (-4) )                  [підстановка оцінок з раунду k=1]
= min( 5,  5,  -2 )                            [знаходження шляху через v₁]
= -2                                           [остаточне значення найкоротшої відстані]
```

Отримана послідовність `+∞ → 5 → -2` чітко показує монотонний спад оцінок та покрокове відкриття коротших шляхів, що містять більшу кількість ребер. Зверніть увагу, що на раунді `k = 1` найкращим був прямий шлях `s → v₂` вагою 5, але вже на раунді `k = 2` залучення 2 ребер `s → v₁ → v₂` дало знижку до значення `-2`.

### Тропічна алгебра та матричне формулювання `(min, +)`

Існує вишуканий алгебраїчний погляд на алгоритм Беллмана–Форда через так звану тропічну алгебру (англ. *tropical semiring*). Визначимо математичну структуру над множиною `ℝ ∪ {+∞}`, де роль операції додавання виконує мінімум `a ⊕ b = min(a, b)`, а роль операції множення — звичайне додавання `a ⊗ b = a + b`.

У такій алгебраїчній системі нейтральним елементом по додаванню є `+∞`, а нейтральним елементом по множенню є `0`.

Якщо задати матрицю вагових коефіцієнтів суміжності `A` розміром `V × V`, де `A[i][j] = w(v_i, v_j)`, то рекурентний крок Беллмана–Форда для вектора відстаней `d^(k)` записується у вигляді звичайного векторно-матричного множення в тропічній алгебрі:

```
d^(k) = d^(k-1) ⊗ A
```

Піднесення матриці `A` до степеня `k` в тропічній алгебрі еквівалентне знаходженню найкоротших відстаней між усіма парами вершин з використанням не більше ніж `k` ребер. Оскільки матричне множення є асоціативним `(A ⊗ B) ⊗ C = A ⊗ (B ⊗ C)`, це дозволяє проводити паралельний розрахунок найкоротших шляхів та виявляти спектральні властивості графів.

### Фундаментальні властивості оцінок відстаней та послаблень

Усі доведення коректності алгоритмів найкоротших шляхів спираються на базові математичні властивості.

#### 1. Нерівність трикутника (Triangle Inequality)
Для будь-якого ребра `(u, v) ∈ E` істинні найкоротші відстані від джерела `s` задовольняють нерівність:

```
δ(s, v) ≤ δ(s, u) + w(u, v)
```

*Доведення:* Шлях від `s` до `v`, що утворений з оптимального шляху від `s` до `u` плюс ребро `(u, v)`, є лише одним із можливих шляхів від `s` до `v`. Найкоротший шлях `δ(s, v)` за визначенням мінімуму не може бути довшим за цей конкретний шлях.

#### 2. Властивість верхньої оцінки (Upper-Bound Property)
Для будь-якої вершини `v ∈ V` поточна оцінка відстані `d[v]` завжди залишається не меншою за істинну найкоротшу відстань:

```
d[v] ≥ δ(s, v)
```

Понад те, як тільки оцінка `d[v]` досягає істинного значення `δ(s, v)`, вона більше ніколи не змінюється і не збільшується при подальших релаксаціях.

*Доведення:* Доведемо за індукцією по кількості виконаних релаксацій. База: початково `d[s] = 0 = δ(s, s)` і `d[v] = +∞ ≥ δ(s, v)`. Крок: якщо під час релаксації ребра `(u, v)` оцінка `d[v]` зменшується до `d[u] + w(u, v)`, то за індукційним припущенням `d[u] ≥ δ(s, u)`. Використовуючи нерівність трикутника:

```
d[v] = d[u] + w(u, v) ≥ δ(s, u) + w(u, v) ≥ δ(s, v)
```

#### 3. Властивість монотонності оцінок (Monotonicity Property)
Для будь-якої вершини `v ∈ V` послідовність оцінок `d[v]` під час виконання алгоритму Беллмана–Форда є неузростаючою:

```
d^(0)[v] ≥ d^(1)[v] ≥ d^(2)[v] ≥ ... ≥ d^(V-1)[v] ≥ δ(s, v)
```

*Доведення:* На кожному раунді `k` релаксація виконує оновлення `d^(k)[v] := min(d^(k-1)[v], d^(k-1)[u] + w(u, v))`. Оскільки операція `min(a, b)` за визначенням задовольняє `min(a, b) ≤ a`, то `d^(k)[v] ≤ d^(k-1)[v]`. Тобто значення оцінки може лише зменшуватися або залишатися незмінним.

#### 4. Властивість послідовного послаблення шляху (Path-Relaxation Property)
Якщо `P = (v₀, v₁, ..., vₖ)` є найкоротшим шляхом від `v₀ = s` до `vₖ = v`, і якщо ребра шляху `P` послаблюються у порядку `(v₀, v₁)`, `(v₁, v₂)`, ..., `(vₖ₋₁, vₖ)` (між якими можуть виконуватися довільні інші послаблення), то в результаті виходить:

```
d[v_k] = δ(s, v_k)
```

*Доведення:* За індукцією по `i`. Після релаксації `(v₀, v₁)` маємо `d[v₁] = δ(s, v₁)`. Припускаючи `d[v_{i-1}] = δ(s, v_{i-1})`, під час релаксації `(v_{i-1}, v_i)` отримуємо `d[v_i] ≤ d[v_{i-1}] + w(v_{i-1}, v_i) = δ(s, v_{i-1}) + w(v_{i-1}, v_i) = δ(s, v_i)`. Оскільки `d[v_i] ≥ δ(s, v_i)`, маємо точну рівність `d[v_i] = δ(s, v_i)`.

### Лема 1. Структура простих шляхів за відсутності від'ємних циклів

**Твердження:** Якщо граф `G` не містить від'ємних циклів, досяжних із джерела `s`, то між `s` та будь-якою досяжною вершиною `v` існує найкоротший шлях `P`, який є **простим** (не містить вершин, що повторюються), і кількість ребер у якому не перевищує `|V| - 1`.

**Доведення:**
Розглянемо довільний найкоротший шлях `P` від `s` до `v`. Припустимо від зворотного, що `P` не є простим. Це означає, що існує принаймні одна вершина `u`, яка зустрічається в послідовності вершин шляху `P` більше одного разу.

Тоді шлях `P` можна розбити на три частини: `P₁` (від `s` до першого входу в `u`), `C` (замкнений цикл від `u` до `u`), та `P₂` (від другого виходу з `u` до `v`):

```
w(P) = w(P₁) + w(C) + w(P₂)
```

За умовою леми граф не містить досяжних від'ємних циклів, отже вага циклу `w(C) ≥ 0`.

Якщо ми видалимо цикл `C` із шляху `P`, отримаємо новий шлях `P' = P₁ ∪ P₂` від `s` до `v`. Вага нового шляху дорівнює:

```
w(P') = w(P₁) + w(P₂) = w(P) - w(C) ≤ w(P)
```

Оскільки `P` був найкоротшим шляхом, то `w(P')` не може бути суворо меншим за `w(P)`. Отже, `w(C) = 0`, і новий шлях `P'` також є найкоротшим шляхом від `s` до `v`, але має строго менше ребер.

Повторюючи цю процедуру вилучення невід'ємних циклів скінченну кількість разів, ми зрештою отримаємо найкоротший шлях `P*`, який не містить жодного циклу, тобто є простим.

Оскільки у графі `G` існує рівно `|V|` унікальних вершин, будь-який простий шлях може містити не більше ніж `|V|` вершин, а отже, не більше ніж `|V| - 1` ребер. 

**Лема доведена.** ■

### Теорема 1. Інваріант k-крокових найкоротших шляхів

Нехай `d^(k)[v]` — значення оцінки відстані до вершини `v` після виконання `k` раундів суцільного послаблення ребер алгоритму Беллмана–Форда (де `d^(0)[s] = 0`, а для всіх `v ≠ s` `d^(0)[v] = +∞`).

**Твердження:** Для кожного `k ∈ {0, 1, 2, ..., |V|-1}` та для кожної вершини `v ∈ V` оцінка `d^(k)[v]` не перевищує вагу найкоротшого шляху від `s` до `v`, що складається не більше ніж із `k` ребер:

```
d^(k)[v] ≤ δ^{(k)}(s, v)
```

де `δ^{(k)}(s, v)` — мінімальна вага серед усіх шляхів від `s` до `v`, які містять ≤ `k` ребер.

**Доведення (метод математичної індукції по k):**

**База індукції (k = 0):**
Для `k = 0` єдиний шлях з 0 ребер — це шлях від `s` до `s` порожньої довжини.
- Для `v = s`: `d^(0)[s] = 0` і `δ^{(0)}(s, s) = 0`, отже `d^(0)[s] ≤ δ^{(0)}(s, s)`.
- Для `v ≠ s`: шляхів з 0 ребер від `s` до `v` не існує, тому `δ^{(0)}(s, v) = +∞`. Зважаючи на `d^(0)[v] = +∞`, нерівність `d^(0)[v] ≤ +∞` виконується тривіально.

**Індукційний крок (припустимо правильність для k-1, доведемо для k):**
Розглянемо довільну вершину `v ∈ V`. Якщо `δ^{(k)}(s, v) = +∞`, то за інваріантом релаксації оцінки `d[v]` ніколи не стають більшими за значення на попередніх кроках, тому `d^(k)[v] ≤ d^(k-1)[v] ≤ +∞`.

Якщо ж `δ^{(k)}(s, v) < +∞`, то існує шлях `P` від `s` до `v`, який містить не більше `k` ребер і має мінімальну вагу `w(P) = δ^{(k)}(s, v)`.

Нехай `u` — передостання вершина на цьому шляху `P`, а `(u, v)` — останнє ребро шляху `P`. Тоді префікс шляху `P'` від `s` до `u` містить не більше `k - 1` ребер і є найкоротшим серед усіх таких шляхів, отже `w(P') = δ^{(k-1)}(s, u)`.

За індукційним припущенням, після `k-1` раундів ми маємо:

```
d^(k-1)[u] ≤ δ^{(k-1)}(s, u)
```

Під час `k`-го раунду алгоритм обов'язково розглядає та послаблює ребро `(u, v) ∈ E`. За формулою послаблення `d[v] := min(d[v], d[u] + w(u, v))`, після `k`-го раунду виконується нерівність:

```
d^(k)[v] ≤ d^(k-1)[u] + w(u, v)
```

Підставляючи індукційне припущення для `u`, отримуємо:

```
d^(k)[v] ≤ δ^{(k-1)}(s, u) + w(u, v) = w(P') + w(u, v) = w(P) = δ^{(k)}(s, v)
```

Отже, за принципом математичної індукції твердження виконується для всіх `k ≥ 0`.

**Наслідок з Леми 1 та Теореми 1:**
Якщо граф `G` не містить від'ємних циклів, досяжних із `s`, то найкоротший шлях до будь-якої досяжної вершини `v` містить не більше `|V| - 1` ребер. Тому після `|V| - 1` раундів послаблень оцінка `d^{(|V|-1)}[v]` стає точно рівною глобальній найкоротшій відстані:

```
d^{(|V|-1)}[v] = δ(s, v)
```

### Теорема 2. Детектор від'ємних циклів на раунді |V|

**Твердження:** У графі `G = (V, E)` існує від'ємний цикл, досяжний із стартової вершини `s`, тоді і тільки тоді, коли під час виконання `|V|`-го раунду послаблень знайдеться принаймні одне ребро `(u, v) ∈ E`, таке що:

```
d[u] + w(u, v) < d[v]
```

**Доведення:**

**Необхідність (⇒):**
Припустимо, що у графі існує від'ємний цикл `C = (v₀, v₁, v₂, ..., vₖ = v₀)`, досяжний із `s`, де сумарна вага `w(C) = ∑_{i=1}^{k} w(v_{i-1}, v_i) < 0`.

Припустимо від зворотного, що на `|V|`-му раунді жодне ребро не послаблюється, тобто для всіх ребер графа (зокрема й для всіх ребер циклу `C`) виконується умовний інваріант збіжності:

```
d[v_i] ≤ d[v_{i-1}] + w(v_{i-1}, v_i)   для всіх i ∈ {1, 2, ..., k}
```

Просумуємо ці `k` нерівностей уздовж усього циклу `C`:

```
∑_{i=1}^{k} d[v_i] ≤ ∑_{i=1}^{k} d[v_{i-1}] + ∑_{i=1}^{k} w(v_{i-1}, v_i)
```

Оскільки цикл замикається (`vₖ = v₀`), то ліва сума `∑ d[v_i]` точно дорівнює першому доданку правої суми `∑ d[v_{i-1}]`. Віднімаючи цю скінченну суму з обох боків нерівності, отримуємо:

```
0 ≤ ∑_{i=1}^{k} w(v_{i-1}, v_i) = w(C)
```

Отримали суперечність `0 ≤ w(C)`, оскільки за умовою `w(C) < 0`. Отже, наше припущення було хибним, і на `|V|`-му раунді принаймні одне ребро циклу обов'язково задовольнить умову `d[u] + w(u, v) < d[v]`.

**Достатність (⇐):**
Припустимо, що на `|V|`-му раунді знайшлося ребро `(u, v)`, для якого `d[u] + w(u, v) < d[v]`.

Це означає, що поточна оцінка `d[v]` була сформована шляхом, який містить більше ніж `|V| - 1` ребер (а саме `|V|` ребер). За принципом Диріхле, шлях із `|V|` ребер у графі з `|V|` вершинами обов'язково містить принаймні один замкнений цикл `C`.

Якби цей цикл мав невід'ємну вагу `w(C) ≥ 0`, видалення цього циклу зменшило б кількість ребер без збільшення ваги шляху, і оцінка `d[v]` вже була б остаточно обчислена на одному з попередніх раундів `k ≤ |V| - 1`. Продовження падіння оцінки `d[v]` на `|V|`-му раунді можливе виключно тоді, коли цикл `C` має від'ємну сумарну вагу `w(C) < 0`.

**Теорему доведено.** ■

### Теорема 3. Еквівалентність систем різницевих обмежень та відсутність від'ємних циклів

Розглянемо систему з `m` різницевих нерівностей відносно `n` змінних `x₁, x₂, ..., xₙ`:

```
x_j - x_i ≤ b_k   для кожного k ∈ {1, ..., m}
```

Нехай `G_C = (V, E_C)` — відповідний граф обмежень із вершинами `V = {v₀, v₁, ..., vₙ}` та вагами ребер `w(v_i, v_j) = b_k`.

**Твердження:** Система різницевих обмежень є сумісною тоді і тільки тоді, коли граф `G_C` не містить від'ємних циклів.

**Доведення:**

**Необхідність (⇒):**
Припустимо, що система є сумісною і має розв'язок `x = (x₁, x₂, ..., xₙ)`. Задамо `x₀ = 0`.
Розглянемо довільний цикл `C = (v_{i₀}, v_{i₁}, ..., v_{iₖ} = v_{i₀})` у графі обмежень.
Кожному ребру `(v_{i_{r-1}}, v_{i_r})` відповідає нерівність `x_{i_r} - x_{i_{r-1}} ≤ w(v_{i_{r-1}}, v_{i_r})`.

Просумуємо нерівності вздовж циклу:

```
∑_{r=1}^{k} (x_{i_r} - x_{i_{r-1}}) ≤ ∑_{r=1}^{k} w(v_{i_{r-1}}, v_{i_r}) = w(C)
```

Сума у лівій частині є телескопічною і замикається в 0:

```
(x_{i₁} - x_{i₀}) + (x_{i₂} - x_{i₁}) + ... + (x_{i₀} - x_{i_{k-1}}) = 0
```

Звідси `0 ≤ w(C)`. Тобто кожен цикл у графі обмежень має невід'ємну вагу. Від'ємних циклів у `G_C` не існує.

**Достатність (⇐):**
Припустимо, що `G_C` не містить від'ємних циклів. Запустимо алгоритм Беллмана–Форда від вершини `v₀` та обчислимо найкоротші відстані `d[v_i]` для всіх `i ∈ {1, ..., n}`.

Оскільки `G_C` не містить від'ємних циклів, усі `d[v_i]` є скінченними дійсними числами.
За нерівністю трикутника для кожного ребра `(v_i, v_j)` вагою `b_k`:

```
d[v_j] ≤ d[v_i] + b_k
```

Перенесемо `d[v_i]` у ліву частину:

```
d[v_j] - d[v_i] ≤ b_k
```

Отже, вектор `x = (d[v₁], d[v₂], ..., d[vₙ])` строго задовольняє всі `m` нерівностей і є дійсним розв'язком системи!

**Теорему доведено.** ■

### Лема Джонсона про потенційне перезважування ребер

При розв'язанні задачі найкоротших шляхів між усіма парами вершин (APSP) алгоритм Джонсона змінює ваги ребер, щоб дозволити використання алгоритму Дейкстри.

Геометрично функцію потенціалу `h: V → ℝ` можна уявити як висоту ландшафту вершини над рівнем моря. Зміна ваги ребра `ŵ(u, v) = w(u, v) + h(u) - h(v)` означає, що при русі згори вдолу (`h(u) > h(v)`) ми отримуємо штучну прибавку до довжини шляху, яка повністю нівелює від'ємні схили, вирівнюючи ландшафт графа до строго невід'ємних ваг.

**Лема (Потенційне перезважування):** Нехай `G = (V, E)` — зважений орієнтований граф із вагою `w`, і нехай `h: V → ℝ` — довільна функція потенціалу вершин. Визначимо нову вагову функцію `ŵ`:

```
ŵ(u, v) = w(u, v) + h(u) - h(v)
```

Тоді:
1. Для будь-якого шляху `P = (v₀, v₁, ..., vₖ)` від `v₀` до `vₖ` його нові й старі ваги пов'язані формулою:
   ```
   ŵ(P) = ∑_{i=1}^{k} ŵ(v_{i-1}, v_i)                            [визначення ваги шляху через суму нових ваг]
        = ∑_{i=1}^{k} ( w(v_{i-1}, v_i) + h(v_{i-1}) - h(v_i) )  [підстановка формули потенціалу ŵ]
        = ∑_{i=1}^{k} w(v_{i-1}, v_i) + ∑_{i=1}^{k} ( h(v_{i-1}) - h(v_i) ) [розбиття суми на ваги та потенціали]
        = w(P) + h(v₀) - h(vₖ)                                    [телескопічне скорочення заміжних потенціалів]
   ```
2. Шлях `P` є найкоротшим шляхом від `v₀` до `vₖ` відносно `w` тоді і тільки тоді, коли він є найкоротшим шляхом відносно `ŵ`.
3. Якщо `h(v) = δ(s, v)` обчислено алгоритмом Беллмана–Форда від супер-джерела `s`, то `ŵ(u, v) ≥ 0` для всіх `(u, v) ∈ E`.

*Доведення пункту 1:*
Розпишемо суму нових ваг ребер уздовж шляху `P`:
Друга сума є телескопічною: `(h(v₀) - h(v₁)) + (h(v₁) - h(v₂)) + ... + (h(vₖ₋₁) - h(vₖ)) = h(v₀) - h(vₖ)`.
Отже: `ŵ(P) = w(P) + h(v₀) - h(vₖ)`.

*Доведення пункту 2:*
Оскільки різниця `h(v₀) - h(vₖ)` залежить лише від фіксованих кінцевих вершин шляху `v₀` та `vₖ`, вона є константою для всіх можливих шляхів між `v₀` та `vₖ`. Додавання константи до ваги всіх шляхів не змінює їхнього відносного порядку, а отже, мінімум `w(P)` досягається на тих самих шляхах, що й мінімум `ŵ(P)`.

*Доведення пункту 3:*
За нерівністю трикутника для істинних найкоротших відстаней `h(v) = δ(s, v)` маємо `δ(s, v) ≤ δ(s, u) + w(u, v)`.
Підставляючи `h`: `h(v) ≤ h(u) + w(u, v)`.
Переносячи `h(v)` та `h(u)`: `w(u, v) + h(u) - h(v) ≥ 0`, тобто `ŵ(u, v) ≥ 0`.

**Лема доведена.** ■
