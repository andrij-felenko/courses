# 🧮 Математичне обґрунтування меж висоти червоно-чорного дерева

Головна теоретична й практична перевага червоно-чорного дерева полягає у тому, що воно гарантує строго логарифмічну межу висоти для будь-якого набору даних. Це доведення крок за кроком показує, чому висота `h` дерева з `n` внутрішніми вузлами ніколи не перевищує `2 log₂(n + 1)`.

Усі формули та виведення наведено за допомогою стандартної символьної нотації без використання сторонніх математичних разміток чи LaTeX.

## 1. Визначення чорної висоти та формальні інваріанти

Нехай `x` — будь-який вузол червоно-чорного дерева.

Чорна висота `bh(x)` визначається як кількість чорних вузлів на будь-якому шляху від вузла `x` до листового `NIL`-вказівника у його піддереві. Зауважимо:
- Сам вузол `x` **не включається** до підрахунку своєї чорної висоти `bh(x)`.
- Усі листові фіктивні вузли `NIL` розглядаються як чорні з `bh(NIL) = 0`.
- Завдяки інваріанту 5 (однакова кількість чорних вузлів на всіх шляхах до листків), значення `bh(x)` є однозначно визначеним цілим числом для кожного вузла.

Чорна висота всього дерева дорівнює чорній висоті його кореневої вершини: `bh = bh(корінь)`.

## 2. Лема про мінімальну місткість піддерева

**Лема:** Піддерево з коренем у будь-якому вузлі `x` містить щонайменше `2^(bh(x)) - 1` внутрішніх (не-NIL) вузлів.

**Доведення за допомогою індукції за висотою вузла `h(x)`:**

### База індукції:
Розглянемо вузол із висотою `h(x) = 0`. Це означає, що `x` є фіктивним листком `NIL`.
Чорна висота листка дорівнює `bh(NIL) = 0`.
Кількість внутрішніх вузлів у піддереві листка дорівнює 0.
Обчислимо формулу для `bh(NIL) = 0`:

```
2^(bh(NIL)) - 1 = 2⁰ - 1 = 1 - 1 = 0
```

Результати повністю збігаються. Базу індукції доведено.

### Індукційний крок:
Розглянемо внутрішній вузол `x` із висотою `h(x) > 0` та чорною висотою `bh(x)`. Вузол `x` має двох дітей: `left` та `right`.
Для кожної дитини `y ∈ {left, right}` оцінимо її чорну висоту `bh(y)`:
- Якщо дитина `y` є червоним вузлом, то за інваріантом 5 її чорна висота дорівнює чорній висоті батька: `bh(y) = bh(x)`.
- Якщо дитина `y` є чорним вузлом, то її чорна висота на 1 менша за чорну висоту батька: `bh(y) = bh(x) - 1`.

Отже, у будь-якому випадку для обох дітей виконується нерівність `bh(y) ≥ bh(x) - 1`.

Оскільки висота дітей строго менша за висоту батька (`h(y) < h(x)`), за індукційним припущенням кожне з двох піддерев містить щонайменше `2^(bh(y)) - 1` внутрішніх вузлів. Підставимо нижню межу для `bh(y)`:

```
N(y) ≥ 2^(bh(x) - 1) - 1
```

Тепер обчислимо загальну кількість внутрішніх вузлів `N(x)` у піддереві вузла `x`. Вона дорівнює сумі вузлів у лівому піддереві, правому піддереві та самого вузла `x`:

```
N(x) = 1 + N(left) + N(right)
≥ 1 + (2^(bh(x) - 1) - 1) + (2^(bh(x) - 1) - 1)    [за індукційним припущенням]
= 1 + 2 · (2^(bh(x) - 1) - 1)                       [зведення подібних доданків]
= 1 + 2^(bh(x)) - 2                                 [розкриття дужок]
= 2^(bh(x)) - 1                                     [спрощення]
```

Нерівність доведено для будь-якого вузла `x`. Лема повністю доведена.

## 3. Нерівність між висотою та чорною висотою

За інваріантом 4 червоно-чорного дерева, червоний вузол не може мати червоних дітей. Це означає, що на будь-якому шляху від кореня до листка червоні вузли не можуть іти підряд.

Отже, на найдовшому шляху від кореня до листка щонайменше половина всіх вузлів (не враховуючи сам корінь) є чорними. Якщо загальна висота дерева дорівнює `h` (довжина найдовшого шляху в ребрах), то кількість чорних вузлів на цьому шляху задовольняє нерівності:

```
bh(корінь) ≥ h / 2
```

## 4. Підсумкове виведення верхньої межі висоти

Поєднаємо результат Леми про місткість дерева для `x = корінь` та нерівність для чорної висоти.

Нехай дерево містить `n` внутрішніх вузлів і має висоту `h`. Тоді:

```
n ≥ 2^(bh(корінь)) - 1                             [за Лемою]
n ≥ 2^(h / 2) - 1                                  [підстановка bh ≥ h / 2]
```

Додамо 1 до обох частин нерівності:

```
n + 1 ≥ 2^(h / 2)
```

Візьмемо логарифм за основою 2 від обох частин:

```
log₂(n + 1) ≥ h / 2
```

Помножимо обидві частини на 2:

```
h ≤ 2 log₂(n + 1)
```

Теорему доведено. Висота червоно-чорного дерева з `n` елементами ніколи не перевищує `2 log₂(n + 1)`.

## 5. Алгебраїчний аналіз еквівалентності 2-3-4 дерев

У 2-3-4 дереві кожному вузлу відповідає рівно один чорний вузол у червоно-чорній репрезентації. Позначимо висоту 2-3-4 дерева як `h_234`. Оскільки всі листки 2-3-4 дерева лежать на одній глибині, чорна висота відповідного червоно-чорного дерева дорівнює `bh = h_234`.

У найгіршому випадку, коли 2-3-4 дерево складається виключно з 2-вузлів (кожен вузол містить 1 ключ), відповідне червоно-чорне дерево не містить жодного червоного вузла. Його висота дорівнює `h = bh = log₂(n + 1)`.

У випадку, коли 2-3-4 дерево складається виключно з 4-вузлів (кожен вузол містить 3 ключі та розпадається на 1 чорний та 2 червоних вузли), кількість елементів досягає `n = 4^(h_234) - 1`. Тоді реальна висота бінарного дерева дорівнює `h = 2 · h_234 = 2 log₄(n + 1) = log₂(n + 1)`.

Отже, зв'язок між 2-3-4 деревами та червоно-чорними бінарними структурами пояснює строгу логарифмічну логіку та унеможливлює виродження дерева.

## 6. Оцінка максимальної кількості поворотів при оновленнях

Окрім логарифмічної межі висоти, найважливішою математичною властивістю червоно-чорного дерева є константна межа кількості поворотів (локальних перебудов топології):

1. **Вставка елемента (`rbtree_insert`):** 
   - Випадок 1 (Red Uncle) виконує лише перефарбування і піднімає конфлікт вгору за деревом (до `O(log n)` перефарбувань).
   - Випадок 2 (Zig-Zag) виконує **1 Лівий поворот** і зводить ситуацію до Випадку 3.
   - Випадок 3 (Line) виконує **1 Правий поворот** та перефарбування, після чого процес зупиняється.
   - **Висновок:** Загальна кількість поворотів при вставці не перевищує **2**.

2. **Вилучення елемента (`rbtree_delete`):**
   - Процедура коригування подвійної чорноти `delete_fixup` може виконати максимум **3 повороти** (Випадок 1 перетворює червоного брата на чорного за 1 поворот, Випадок 3 готує конфігурацію за 1 поворот, а Випадок 4 остаточно ліквідує подвійну чорноту за 1 поворот).
   - **Висновок:** Загальна кількість поворотів при вилученні не перевищує **3**.

Саме ця гарантія (`O(1)` поворотів проти можливо `O(log n)` поворотів у AVL-дереві при вилученні) робить червоно-чорні дерева оптимальним вибором для динамичних структур у пам'яті.
