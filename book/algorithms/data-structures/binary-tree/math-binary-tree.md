# 🧮 Математичні властивості та комбінаторика двійкових дерев

Ця вставка містить точні математичні доведення фундаментальних співвідношень між кількістю вузлів, листків, висотою та довжиною шляхів у двійкових деревах, а також виведення комбінаторної формули чисел Каталана для підрахунку кількості топологій дерев.

Зв'язок між кількісними характеристиками двійкового дерева визначається його структурною топологією. Означимо базові величини:
- `n` — загальна кількість вузлів у дереві;
- `I` — кількість внутрішніх вузлів (вузли, що мають принаймні одного нащадка);
- `L` — кількість листків (зовнішніх вузлів без дітей), тобто `n = I + L`;
- `h` — висота дерева (довжина найдовшого шляху від кореня до листка у кількості ребер; порожнє дерево має `h = -1`, дерево з одного кореня має `h = 0`).

---

## 1. Фундаментальна теорема про кількість листків строгих дерев

**Теорема 1.** У будь-якому непорожньому *строгому (повному)* двійковому дереві (де кожен вузол має або 0, або 2 нащадків) кількість листків `L` строго на одиницю більша за кількість внутрішніх вузлів `I`:

```
L = I + 1
```

### Доведення (методом математичної індукції за кількістю внутрішніх вузлів I)

**База індукції:** `I = 0`.
Дерево без внутрішніх вузлів складається лише з одного кореневого вузла. Оскільки у нього 0 дітей, це листок.
Отже, `L = 1`, `I = 0`. Співвідношення `1 = 0 + 1` виконується.

**Індуктивне припущення:** Нехай формула `L' = I' + 1` виконується для всіх строгих дерев з кількістю внутрішніх вузлів `I' < k`.

**Індуктивний крок:** Розглянемо довільне строге двійкове дерево `T` з `I = k` внутрішніми вузлами (`k ≥ 1`).
Оскільки `k ≥ 1`, корінь дерева має два піддерева: ліве `T_L` та праве `T_R`.
Обидва піддерева `T_L` та `T_R` також є строгими двійковими деревами.
Позначимо внутрішні вузли та листки піддерев відповідно через `(I_L, L_L)` та `(I_R, L_R)`.

Сумарна кількість внутрішніх вузлів дерева `T` складається з внутрішніх вузлів обох піддерев плюс сам корінь:

```
I = I_L + I_R + 1
```

Сумарна кількість листків є просто сумою листків обох піддерев:

```
L = L_L + L_R
```

Оскільки `I_L < k` та `I_R < k`, за індуктивним припущенням застосуємо формулу до піддерев:

```
L_L = I_L + 1
L_R = I_R + 1
```

Підставимо ці вирази у формулу загальної кількості листків `L`:

```
L = L_L + L_R
= (I_L + 1) + (I_R + 1)      [за індуктивним припущенням]
= (I_L + I_R + 1) + 1        [асоціативність: групуємо внутрішні вузли]
= I + 1                      [оскільки I = I_L + I_R + 1]
```

Теорему доведено.

**Наслідок:** Загальна кількість вузлів строгого дерева `n = I + L = I + (I + 1) = 2I + 1`. Це означає, що **строге двійкове дерево завжди має непарну кількість вузлів**.

## 2. Узагальнення на k-арні дерева

Розглянемо узагальнення Теореми 1 на `k`-арні дерева, де кожен внутрішній вузол має рівно `k` дітей.

**Теорема 1b.** У будь-якому непорожньому строгому `k`-арному дереві з `I` внутрішніми вузлами кількість листків `L` задається формулою:

```
L = (k - 1) · I + 1            [формула кількості листків для k-арного дерева]
```

### Доведення (через підрахунок ребер)

Кожне ребро у дереві з'єднує батьківський вузол із дитиною.
Оскільки кожен із `n` вузлів, крім кореня, має рівно одного батька, загальна кількість ребер у дереві з `n` вузлами дорівнює:

```
Edges = n - 1
```

З іншого боку, кожне ребро виходить із якогось внутрішнього вузла. Оскільки кожен із `I` внутрішніх вузлів має рівно `k` вихідних ребер, загальна кількість ребер дорівнює:

```
Edges = k · I
```

Прирівняємо обидва вирази для кількості ребер:

```
k · I = n - 1
```

Оскільки загальна кількість вузлів `n = I + L`, підставимо це у рівняння:

```
k · I = (I + L) - 1            [підстановка n = I + L]
k · I - I + 1 = L              [перенесення доданків]
L = (k - 1) · I + 1            [винесення I за дужки]
```

Для двійкового дерева `k = 2`, підстановка дає `L = (2 - 1)I + 1 = I + 1`, що підтверджує Теорему 1.

## 3. Межі висоти двійкового дерева

Висота дерева `h` визначає максимальну довжину шляху від кореня до листка і задає асимптотичну складність операцій обходу та пошуку.

### Мінімальна висота (Ідеальне / Повне дерево)

У дерево висоти `h` на рівні `k` (`0 ≤ k ≤ h`) можна розмістити максимум `2ᵏ` вузлів.
Максимально можлива кількість вузлів у дереві висоти `h` досягається тоді, коли всі рівні від `0` до `h` повністю заповнені (ідеальне двійкове дерево):

```
n_max = 2⁰ + 2¹ + 2² + ... + 2ʰ  [сума кількості вузлів на кожному рівні від 0 до h]
= ∑_{k=0}^{h} 2ᵏ                [сума геометричної прогресії зі знаменником 2]
= 2ʰ⁺¹ - 1                       [формула суми 2⁰ + ... + 2ʰ = 2ʰ⁺¹ - 1]
```

Звідси знайдемо мінімальну висоту `h_min` для дерева з `n` вузлами:

```
n ≤ 2ʰ⁺¹ - 1
n + 1 ≤ 2ʰ⁺¹                    [додали 1 до обох частин]
log₂(n + 1) ≤ h + 1             [логарифмування за основою 2]
h ≥ log₂(n + 1) - 1             [відняли 1 від обох частин]
```

Оскільки висота є цілим числом, мінімальна висота дерева з `n` вузлами дорівнює:

```
h_min = ⌊log₂ n⌋
```

Отже, найкраща висота двійкового дерева масштабується логарифмічно: `O(log n)`.

### Максимальна висота (Вироджене дерево)

Найгірший випадок виникає, коли кожен внутрішній вузол має лише одного нащадка (дерево вироджується в однозв'язний список).
Тоді на кожному рівні від `0` до `h` сидить рівно один вузол:

```
n = h + 1  ⇒  h_max = n - 1
```

У найгіршому випадку висота масштабується лінійно: `O(n)`.

## 4. Співвідношення довжин внутрішніх та зовнішніх шляхів

Для аналізу середнього часу обходу дерева Дональд Кнут увів поняття довжини шляхів:
- **Внутрішня довжина шляху (I_path):** сума глибин усіх внутрішніх вузлів дерева.
- **Зовнішня довжина шляху (E_path):** сума глибин усіх порожніх листків (ззовні структури).

**Теорема 2 (Формула Кнута).** Для будь-якого двійкового дерева з `n` вузлами зовнішня довжина шляху зв'язана з внутрішньою співвідношенням:

```
E_path = I_path + 2n
```

### Доведення (індукцією за n)

**База індукції:** `n = 0` (порожнє дерево).
У порожньому дереві 0 внутрішніх вузлів (`I_path = 0`) і 1 порожнє зовнішнє дерево на глибині 0 (`E_path = 0`).
Рівність `0 = 0 + 2(0)` виконується.

**Крок індукції:** Нехай формула справедлива для дерева з `n - 1` вузлами.
Додавання нового `n`-го вузла перетворює один із порожніх листків (на глибині `d`) у внутрішній вузол і створює два нові порожні листки на глибині `d + 1`.

Обчислимо зміни довжин шляхів:
1. `I_path` збільшується на глибину нового вузла `d`:
   `I_path_new = I_path_old + d`
2. `E_path` втрачає один порожній вузол на глибині `d` і отримує два нові на глибині `d + 1`:
   `E_path_new = E_path_old - d + 2(d + 1) = E_path_old + d + 2`

За індуктивним припущенням `E_path_old = I_path_old + 2(n - 1)`.
Підставимо це значення:

```
E_path_new = (I_path_old + 2n - 2) + d + 2    [за індуктивним припущенням для n-1]
= (I_path_old + d) + 2n                       [групуємо доданки (I_path_old + d) та -2 + 2 = 0]
= I_path_new + 2n                             [підстановка I_path_new = I_path_old + d]
```

Теорему доведено.

## 5. Комбінаторика: [Числа Каталана](topic:math/catalan-numbers) та кількість форм дерев

Скільки існує математично різних двійкових дерев із `n` нерозрізненими вузлами?
Позначимо цю кількість через `Cₙ`.

Якщо дерево має `n` вузлів (`n ≥ 1`), то один вузол витрачається на корінь, а решта `n - 1` вузлів розподіляються між лівим та правим піддеревами.
Якщо ліве піддерево містить `i` вузлів (`0 ≤ i ≤ n - 1`), то праве піддерево містить `n - 1 - i` вузлів.

Оскільки вибір форми лівого та правого піддерев є незалежними подіями, кількість комбінацій для фіксованого `i` дорівнює добутку `Cᵢ · Cₙ₋₁₋ᵢ`.

Підсумовуючи за всіма можливими розмірами лівого піддерева від `0` до `n - 1`, отримуємо **рекурентну формулу Каталана**:

```
C₀ = 1
Cₙ = ∑_{i=0}^{n-1} Cᵢ · Cₙ₋₁₋ᵢ    для n ≥ 1
```

### Обчислення перших чисел Каталана

Покроково обчислимо кількість структур дерев для малої кількості вузлів:

```
n = 0:  C₀ = 1                          [порожнє дерево]
n = 1:  C₁ = C₀·C₀ = 1·1 = 1             [один корінь]
n = 2:  C₂ = C₀·C₁ + C₁·C₀ = 1+1 = 2     [корінь + лівий або корінь + правий]
n = 3:  C₃ = C₀·C₂ + C₁·C₁ + C₂·C₀
        = 1·2 + 1·1 + 2·1 = 2 + 1 + 2 = 5 [підстановка розкладів для 3 вузлів]
n = 4:  C₄ = C₀·C₃ + C₁·C₂ + C₂·C₁ + C₃·C₀
        = 1·5 + 1·2 + 2·1 + 5·1 = 14     [підстановка розкладів для 4 вузлів]
```

## 6. Метод твірних функцій для явного виведення чисел Каталана

Щоб вивести явну формулу для `Cₙ` без обчислення сум, використаємо **метод твірних функцій** (англ. *generating functions*).

Означимо формальний степеневий ряд `C(x)`:

```
C(x) = ∑_{n=0}^{∞} Cₙ · xⁿ = C₀ + C₁·x + C₂·x² + C₃·x³ + ...
```

Зведемо рекурентне співвідношення `Cₙ = ∑_{i=0}^{n-1} Cᵢ · Cₙ₋₁₋ᵢ` у квадратичне рівняння відносно твірної функції `C(x)`:

```
C(x) = 1 + x · C(x)²
```

Розв'яжемо це квадратичне рівняння `x · C²(x) - C(x) + 1 = 0` відносно `C(x)` за допомогою формули коренів квадратного рівняння:

```
C(x) = (1 ± √(1 - 4x)) / (2x)
```

Оскільки `C(0) = C₀ = 1`, вибираємо знак мінус (знак плюс дає нескінченність у нулі):

```
C(x) = (1 - √(1 - 4x)) / (2x)
```

Розкладемо радікал `√(1 - 4x) = (1 - 4x)^(1/2)` у степеневий ряд Тейлора за методом Ньютона через біноміальні коефіцієнти:

```
(1 - 4x)^(1/2) = ∑_{n=0}^{∞} (1/2 \choose n) · (-4x)ⁿ
= 1 - ∑_{n=1}^{∞} (1 / (2n - 1)) · (2n \choose n) / 2^(2n-1) · (4x)ⁿ    [розклад Ньютона]
= 1 - 2x · ∑_{n=0}^{∞} (1 / (n + 1)) · (2n \choose n) · xⁿ              [спрощення коефіцієнтів]
```

Підставивши цей розклад назад у формулу `C(x) = (1 - √(1 - 4x)) / (2x)`, отримуємо точну тотожність:

```
C(x) = ∑_{n=0}^{∞} [ (1 / (n + 1)) · (2n \choose n) ] · xⁿ
```

Порівнюючи коефіцієнти при `xⁿ`, доходимо до точної **явної формули для n-го числа Каталана**:

```
Cₙ = (1 / (n + 1)) · (2n \choose n) = (2n)! / ((n + 1)! · n!)
```

За формулою Стірлінга `n! ≈ √(2πn) · (n/e)ⁿ` асимптотичне зростання кількості форм двійкових дерев становить:

```
Cₙ ≈ 4ⁿ / (n^(3/2) · √π)
```

## 7. Математичне сподівання висоти випадкового дерева

Якщо виділяти двійкове дерево пошуку шляхом послідовної вставки `n` випадкових ключів (де кожна з `n!` перестановок ключів є рівноймовірною), отримана геометрична форма є випадковою змінною.

Математичне сподівання внутрішньої довжини шляху `E[I_path]` у такому випадковому двійковому дереві пошуку задається рекурентним співвідношенням:

```
E[I_path(n)] = (n - 1) + (2 / n) · ∑_{k=0}^{n-1} E[I_path(k)]
```

Розв'язок цього диференціально-рекурентного рівняння дає точний математичний вираз:

```
E[I_path(n)] = 2(n + 1) · H_n - 4n      [де H_n = ∑_{k=1}^{n} (1 / k) — гармонічне число]
≈ 2n · ln(n) + (2γ - 4)n                [асимптотика Стірлінга-Ейлера, γ ≈ 0.5772]
≈ 1.386 · n · log₂(n)
```

Це означає, що середня глибина вузла у випадковому двійковому дереві пошуку дорівнює `d_avg = E[I_path] / n ≈ 1.386 log₂ n`, що лише на 38.6% перевищує висоту ідеального дерева `log₂ n`.

Математичне сподівання **максимальної висоти** випадкового двійкового дерева `E[h(n)]` було доведено Люком Девруа (англ. *Luc Devroye*) у 1986 році:

```
E[h(n)] = c · ln(n) - O(ln ln n)     [де c ≈ 4.31107 — єдиний додатний розв'язок рівняння (c·e/2)^c = e]
```

Отже, навіть випадкове незбалансоване дерево зберігає логарифмічне зростання висоти `O(log n)` з високою ймовірністю.

## 8. Нерівність Крафта для префіксних двійкових дерев

У теорії інформації важливою властивістю двійкових дерев є **нерівність Крафта — Макміллана** (англ. *Kraft-McMillan inequality*).

Якщо двійкове дерево використовується як префіксний код (наприклад, код Гаффмана), де кожному символу з алфавіту відповідає листок на глибині `l_i`:

**Теорема 3 (Нерівність Крафта).** Для будь-якого однозначно декодованого двійкового префіксного коду з довжинами кодових слів `l₁, l₂, ..., lₘ` виконується нерівність:

```
∑_{i=1}^{m} 2^(-l_i) ≤ 1
```

### Доведення (геометричне за заповненням листків)

Розглянемо ідеальне двійкове дерево висоти `L_max = max(l_i)`. На найглибшому рівні це дерево містить `2^(L_max)` листків.
Листок на глибині `l_i` покриває під собою `2^(L_max - l_i)` листків на найглибшому рівні.
Оскільки жоден префіксний код не може бути предком іншого кодового слова, затінені піддерева всіх `m` кодових слів не перетинаються.
Сума покритих листків не може перевищувати загальну кількість листків ідеального дерева:

```
∑_{i=1}^{m} 2^(L_max - l_i) ≤ 2^(L_max)
```

Розділивши обидві частини нерівності на `2^(L_max)`, отримуємо нерівність Крафта:

```
∑_{i=1}^{m} 2^(-l_i) ≤ 1
```

Рівність досягається тоді й лише тоді, коли двійкове дерево коду є строгим і не містить жодного невикористаного листка.

## 9. Підрахунок неізоморфних дерев без розрізнення лівого та правого піддерев

У теоремі Каталана підраховується кількість орієнтованих двійкових дерев, де ліве й праве піддерева вважаються різними. Скільки існує **неорієнтованих (неізоморфних) дерев**, де симетричні двійкові дерева вважаються однаковими?

Позначимо кількість таких неізоморфних структур через `Uₙ`.

Рекурентне співвідношення для `Uₙ` коригується врахуванням симетрії:

```
U₀ = 1
Uₙ₊₁ = (1 / 2) · [ ∑_{i=0}^{n} Uᵢ · Uₙ₋ᵢ + (n % 2 == 0 ? U_{n/2} : 0) ]
```

Для перших значень `n` отримуємо:
- `U₁ = 1`
- `U₂ = 1` (замість `C₂ = 2`)
- `U₃ = 2` (замість `C₃ = 5`)
- `U₄ = 3` (замість `C₄ = 14`)

Асимптотичне зростання кількості неізоморфних дерев виражається формулою Поліа: `Uₙ ≈ b · aⁿ / n^(3/2)`, де `a ≈ 2.4832`, що значно менше за `4ⁿ` у формулі Каталана.

## 10. Середня довжина зовнішнього шляху в ідеальних і строгих деревах

Для оцінки ефективності алгоритмів обходу важливою метрикою є **середня довжина зовнішнього шляху (Average External Path Length)**.

У будь-якому строгому двійковому дереві з `n` внутрішніми вузлами кількість зовнішніх листків дорівнює `L = n + 1`.

Середня глибина зовнішнього листка `E_avg` обчислюється як:

```
E_avg = E_path / (n + 1)
```

Використовуючи формулу Кнута `E_path = I_path + 2n`, отримуємо вираз для середньої глибини зовнішнього листка через внутрішню довжину шляху:

```
E_avg = (I_path + 2n) / (n + 1)
```

Для ідеального двійкового дерева висоти `h`:
- `n = 2ʰ⁺¹ - 1`
- `I_path = ∑_{k=0}^{h} k · 2ᵏ = (h - 1)·2ʰ⁺¹ + 2`
- `E_path = (h - 1)·2ʰ⁺¹ + 2 + 2(2ʰ⁺¹ - 1) = (h + 1)·2ʰ⁺¹`

Звідси середня глибина листка у ідеальному двійковому дереві дорівнює точно:

```
E_avg = (h + 1) · 2ʰ⁺¹ / 2ʰ⁺¹ = h + 1
```

Це доводить, що в ідеальному двійковому дереві всі порожні листки лежать строго на одній і тій самій глибині `h + 1`, що підтверджує його повну збалансованість.

## 11. Рекурентності висоти: Підрахунок дерев з обмеженою висотою

Скільки існує двійкових дерев із висотою, що не перевищує `h`?

Позначимо через `A_h` кількість двійкових дерев висоти `≤ h`.

Порожнє дерево має висоту `-1`, тому `A_{-1} = 1` (одне порожнє дерево).
Дерево висоти `≤ h` складається з кореневого вузла та двох піддерев (лівого та правого), кожне з яких має висоту `≤ h - 1`, або є порожнім.

Звідси отримуємо дуальне квадратичне рекурентне співвідношення:

```
A_{-1} = 1
A_h = 1 + (A_{h-1})²    для h ≥ 0
```

Обчислимо перші значення послідовності `A_h`:
- `A_0 = 1 + (1)² = 2` (порожнє дерево або дерево з одного кореня)
- `A_1 = 1 + (2)² = 5`
- `A_2 = 1 + (5)² = 26`
- `A_3 = 1 + (26)² = 677`
- `A_4 = 1 + (677)² = 458 330`

Асимптотично кількість дерев висоти `≤ h` зростає як подвійна експонента: `A_h ≈ c^(2ʰ)`, де `c ≈ 1.5028368` (стала Райта).
Це надзвичайно швидке зростання показує комбінаторну місткість простору двійкових дерев при збільшенні допустимої висоти.

## 12. Аналіз випадкових остовних дерев та асимптотика Флажоле

У роботах Філіппа Флажоле (фр. *Philippe Flajolet*) та Роберта Седжвіка проведено аналітичний комбінаторний аналіз середньої висоти випадкових бінарних дерев.

Використовуючи комплексний аналіз сингулярностей твірної функції:

```
H(z, u) = ∑_{n, h} H_{n, h} · uʰ · zⁿ
```

доведено, що середня висота невипадкового немаркованого двійкового дерева розміром `n` складає:

```
E[h(n)] = 2 · √(πn) - O(1)
```

Це свідчить про те, що рівноймовірне вибирання випадкового двійкового дерева з усіх можливих `C_n` форм дає значно вищу середню висоту (`O(√n)`), ніж вибирання дерева шляхом послідовної вставки ключів (`O(log n)`). Цей результат є основоположним при розробці алгоритмів генерації випадкових графів та тестуванні синтаксичних аналізаторів.

## 13. Теорема про межі балансу в AVL та Червоно-чорних деревах

Для оцінки висоти самобалансованих двійкових дерев використовуються суворі математичні нерівності:

1. **AVL-дерево:** Максимальна висота `h` для `n` вузлів задовольняє нерівність:
   `h < 1.4404 · log₂(n + 2) - 0.3277`
   Найгіршим випадком AVL-дерева є **дерева Фібоначчі**, де кількість вузлів розраховується як `N_h = N_{h-1} + N_{h-2} + 1`. Зростання висоти при цьому залишається строго логарифмічним, гарантуючи максимальний перекіс не більше ніж у 44% порівняно з ідеальним деревом.

2. **Червоно-чорне дерево:** Максимальна висота `h` для `n` вузлів обмежена нерівністю:
   `h ≤ 2 · log₂(n + 1)`
   Це гарантує, що час пошуку в червоно-чорному дереві навіть у найгіршому випадку не перевищує двох логарифмів від кількості вузлів, роблячи його ідеальним кандидатом для стандартних контейнерів системних бібліотек (`std::map`, `std::set`).

3. **Підсумок математичного аналізу:**
   Математичний аналіз дерев доводить фундаментальний закон комбінаторного розгалуження: додавання двох вказівників у кожен вузол дозволяє стиснути лінійний простір `O(n)` у логарифмічний об'єм `O(log n)`. Представлені виведення є теоретичним фундаментом усіх сучасних структур даних.
