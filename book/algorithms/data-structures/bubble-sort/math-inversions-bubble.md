# 🧮 Математичний аналіз інверсій та складності сортування бульбашкою

Будь-який алгоритм сортування, що оперує виключно порівнянням і перестановкою сусідніх елементів масиву, підпорядковується фундаментальним комбінаторним законам симетричної групи перестановок. Сортування бульбашкою (Bubble Sort) є канонічним представником цього класу: кожна його дія безпосередньо відображається на геометрії перестановки та змінює її ключову топологічну характеристику — число інверсій.

## 1. Формальне означення перестановки та інверсії

Нехай `A = (a₁, a₂, ..., a_N)` — послідовність із `N` попарно різних елементів. Без обмеження загальності можна вважати, що `A` є перестановкою множини перших `N` натуральних чисел:

```
π = (π(1), π(2), ..., π(N)) ∈ S_N
```

де `S_N` — симетрична група перестановок порядку `N!`.

**Означення інверсії:** Інверсією в перестановці `π` називається впорядкована пара індексів `(i, j)` така, що:

```
1 ≤ i < j ≤ N   та   π(i) > π(j)
```

Множину всіх інверсій перестановки `π` позначимо як `Inv(π)`:

```
Inv(π) = { (i, j) : 1 ≤ i < j ≤ N  та  π(i) > π(j) }
```

Потужність цієї множини, тобто загальна кількість інверсій, позначається як `I(π) = |Inv(π)|`.

### Екстремальні значення числа інверсій

1. **Мінімальна кількість інверсій:** Досягається на тотожній перестановці `π_id = (1, 2, ..., N)`, де всі елементи впорядковані за зростанням:
   ```
   I(π_id) = 0
   ```
2. **Максимальна кількість інверсій:** Досягається на строго реверсній перестановці `π_rev = (N, N-1, ..., 2, 1)`, де кожна можлива пара індексів утворює інверсію. Оскільки загальна кількість невпорядкованих пар індексів дорівнює числу сполук `C(N, 2)`:
   ```
   I(π_rev) = N·(N - 1) / 2
   ```

## 2. Код Лемера та таблиця інверсій

Для детального опису структури невпорядкованості перестановки в комбінаториці використовується **код Лемера** (Lehmer code) або вектор інверсій `L(π) = (l₁, l₂, ..., l_N)`.

Для кожного елемента `π(i)` значення `l_i` визначається як кількість елементів, розташованих праворуч від нього, які є меншими за `π(i)`:

```
l_i = |{ j : i < j ≤ N  та  π(i) > π(j) }|
```

Кожне `l_i` задовольняє нерівність `0 ≤ l_i ≤ N - i`.

Код Лемера має дві ключові властивості:
1. **Взаємно однозначна відповідність (бієкція):** Між множиною всіх `N!` перестановок `S_N` та множиною всіх допустимих векторів `(l₁, ..., l_N)` існує бієктивне відображення. Будь-яку перестановку можна однозначно відновити за її кодом Лемера.
2. **Адитивність загального числа інверсій:** Загальна кількість інверсій у перестановці строго дорівнює сумі компонент її коду Лемера:
   ```
   I(π) = ∑_{i=1}^{N} l_i
   ```

У контексті сортування бульбашкою компонента `l_i` має прозорий фізичний зміст: вона точно показує, скільки разів елемент `π(i)` буде зміщений праворуч іншими меншими елементами або скільки разів він сам візьме участь в обміні під час руху праворуч.

## 3. Теорема про локальний обмін суміжних елементів

Сортування бульбашкою виконує елементарну дію над масивом — транспозицію двох сусідніх елементів `(k, k+1)`. Дослідимо, як ця операція змінює число інверсій всієї послідовності.

**Теорема:** Нехай перестановка `π'` отримана з `π` шляхом обміну місцями суміжних елементів `π(k)` та `π(k+1)`. Тоді:
- Якщо `π(k) > π(k+1)`, то `I(π') = I(π) - 1` (кількість інверсій зменшується рівно на 1).
- Якщо `π(k) < π(k+1)`, то `I(π') = I(π) + 1` (кількість інверсій збільшується рівно на 1).

### Доведення

Розглянемо всі можливі пари індексів `(i, j)` де `i < j` у перестановці `π` та розділимо їх на чотири взаємовиключні класи:

1. **Обидва індекси не належать множині `{k, k+1}`:**
   Для будь-якої пари `(i, j)`, де `{i, j} ∩ {k, k+1} = ∅`, значення `π'(i) = π(i)` та `π'(j) = π(j)`. Відносний порядок елементів не змінився, отже статус інверсії для пари `(i, j)` залишається незмінним.

2. **Один індекс ліворуч від точки обміну (`i < k`), а інший входить до пари (`j ∈ {k, k+1}`):**
   Розглянемо елементи `π(i)`, `π(k)` та `π(k+1)`.
   - До обміну парами були `(i, k)` зі значеннями `(π(i), π(k))` та `(i, k+1)` зі значеннями `(π(i), π(k+1))`.
   - Після обміну на позиції `k` опиняється `π(k+1)`, а на позиції `k+1` — `π(k)`.
   - Новими парами є `(π(i), π(k+1))` та `(π(i), π(k))`.
   - Множина значень у парах з індексом `i` залишилася абсолютно тією ж самою, лише переставилися місцями їхні другі компоненти. Кількість інверсій, утворених елементом `π(i)` з елементами на позиціях `k` і `k+1`, сумарно не змінюється.

3. **Один індекс праворуч від точки обміну (`j > k+1`), а інший входить до пари (`i ∈ {k, k+1}`):**
   Аналогічно до попереднього пункту, пари `(π(k), π(j))` та `(π(k+1), π(j))` після транспозиції перетворюються на `(π(k+1), π(j))` та `(π(k), π(j))`. Сумарна кількість інверсій з елементом `π(j)` зберігається.

4. **Пара безпосередніх учасників обміну `(k, k+1)`:**
   Це єдина пара, взаємне розташування якої змінилося на протилежне.
   - Якщо `π(k) > π(k+1)`, то пара `(k, k+1)` утворювала інверсію в `π`. Після транспозиції `π'(k) = π(k+1) < π(k) = π'(k+1)`, тобто в `π'` ця пара більше не є інверсією.
   - Усі інші пари не змінили свого внеску в інверсійний баланс.
   - Отже, `I(π') = I(π) - 1`.

**Наслідок для сортування бульбашкою:** Алгоритм виконує транспозицію `swap(A[k], A[k+1])` **тоді і тільки тоді**, коли `A[k] > A[k+1]`. Тобто кожен окремий обмін у сортуванні бульбашкою знищує рівно одну інверсію і ніколи не створює нових.

Оскільки повністю відсортований масив має `I(π_id) = 0`, сумарна кількість операцій `swap`, виконаних алгоритмом сортування бульбашкою, **строго дорівнює початковій кількості інверсій у вхідному масиві**:

```
TotalSwaps(A) = I(π_A) = ∑_{i=1}^{N} l_i
```

Це рівняння є точним для будь-якої конфігурації вхідних даних.

## 4. Магонієвий розподіл та твірна функція інверсій

Розподіл кількості інверсій на множині всіх `N!` перестановок описується класичною твірною функцією Магона (P. A. MacMahon).

Нехай `I_N(q)` — твірний многочлен для кількості інверсій у групі `S_N`:

```
I_N(q) = ∑_{π ∈ S_N} q^{I(π)}
```

Завдяки незалежності вибору кожної компоненти `l_i` коду Лемера при побудові випадкової перестановки, твірна функція розкладається у добуток q-факторіалів (q-аналог факторіала):

```
I_N(q) = ∏_{k=1}^{N} (1 + q + q² + ... + q^{k-1})
```

Використовуючи метод логарифмічного диференціювання твірної функції в точці `q = 1`, можна точно розрахувати всі статистичні моменти розподілу кількості інверсій.

### Математичне сподівання кількості інверсій

Імовірнісна твірна функція має вигляд `G_N(q) = I_N(q) / N!`. ЇЇ перша похідна в точці `q = 1` визначає математичне сподівання `E[I]`:

```
E[I]
= (N·(N - 1) / 2) · (1/2)     [добуток кількості пар C(N, 2) на ймовірність 1/2]
= N·(N - 1) / 4               [спрощення дробу]
```

Таким чином, для випадкового масиву з `N` елементів середня кількість операцій `swap` у сортуванні бульбашкою складає:

```
E[Swaps] = (N² - N) / 4 ≈ 0.25·N²
```

### Дисперсія кількості інверсій

Для детального розрахунку дисперсії `Var[I]` розглянемо коваріаційну структуру індикаторних випадкових величин `X_{i,j}` (де `X_{i,j} = 1`, якщо `π(i) > π(j)`, і `0` інакше).

Загальна дисперсія суми індикаторів складається з суми їхніх індивідуальних дисперсій та подвоєної суми попарних коваріацій:

```
Var[I] = ∑_{i < j} Var(X_{i,j}) + ∑_{(i,j) ≠ (k,l)} Cov(X_{i,j}, X_{k,l})
```

1. Для окремого індикатора дисперсія становить:
   ```
   Var(X_{i,j}) = E[X_{i,j}²] - (E[X_{i,j}])² = 1/2 - 1/4 = 1/4
   ```
   Сума індивідуальних дисперсій по всіх `N(N - 1) / 2` парах дає `N(N - 1) / 8`.

2. Для пар індикаторів, що мають один спільний індекс (трійки `i < j < k`):
   - Пара `(X_{i,j}, X_{j,k})`: коваріація дорівнює `-1/12`.
   - Пара `(X_{i,k}, X_{j,k})`: коваріація дорівнює `+1/12`.
   - Пара `(X_{i,j}, X_{i,k})`: коваріація дорівнює `+1/12`.

Після акуратного підсумовування внесків від усіх `C(N, 3)` трійок та скорочення протилежних доданків отримуємо класичну формулу Кнута–Феллікса:

```
Var[I] = N·(N - 1)·(2N + 5) / 72
```

При великих `N` дисперсія зростає як `O(N³)`. Це свідчить про те, що стандартне відхилення `sigma = sqrt(Var[I]) = O(N^(1.5))` є відносно малим порівняно з середнім значенням `E[I] = O(N²)`. Згідно з центральною граничною теоремою, нормований розподіл кількості інверсій `(I - E[I]) / sigma` при `N → ∞` строго збігається до стандартного нормального розподілу Гаусса `N(0, 1)`.

## 5. Комбінаторна модель бінарних послідовностей (Діаграми Юнга)

Особливий інтерес становить поведінка сортування бульбашкою на бінарних масивах із множини `{0, 1}^N`, що містять `k` нулів та `N - k` одиниць.

Будь-який бінарний масив можна графічно зобразити як ґратчастий шлях на площині від точки `(0, 0)` до точки `(k, N - k)`: кожна одиниця відповідає кроку праворуч, а кожен нуль — кроку вгору.

Кількість інверсій у бінарному масиві в точності дорівнює площі діаграми Юнга (числу клітинок), обмеженої цим ґратчастим шляхом та координатними осями.
- Кожен обмін сусідньої пари `(1, 0) → (0, 1)` геометрично відповідає видаленню однієї кутової клітинки з діаграми Юнга.
- Один повний прохід сортування бульбашкою зрізає цілий шар зовнішніх кутових клітинок діаграми.
- Кількість проходів, необхідних для повного сортування бінарного масиву, дорівнює висоті найбільшого стовпчика діаграми Юнга, тобто кількості одиниць, що передують останньому нулю.

## 6. Точний аналіз кількості порівнянь у різних варіаціях

### 6.1. Неоптимізований алгоритм (без прапорця)

Базовий алгоритм завжди виконує рівно `N - 1` зовнішніх ітерацій. На `k`-й ітерації (`k` від `1` до `N - 1`) внутрішній цикл робить `N - k` порівнянь суміжних пар. Загальна кількість порівнянь є строго детермінованою константою:

```
C_naive(N)
= ∑_{k=1}^{N-1} (N - k)        [сума порівнянь по всіх N - 1 проходах]
= (N - 1) + (N - 2) + ... + 1  [розгортання арифметичної прогресії]
= N·(N - 1) / 2                [формула суми перших N - 1 натуральних чисел]
```

Кількість порівнянь однакова в найкращому, середньому та найгіршому випадках: `C(N) = 0.5·N² - 0.5·N`.

### 6.2. Оптимізований алгоритм із прапорцем swapped

Якщо під час повного проходу по невідсортованій зоні не відбулося жодного обміну (`swapped = false`), масив уже є відсортованим, і алгоритм негайно завершує роботу.

- **Найкращий випадок (масив уже впорядкований):**
  Виконується лише 1 прохід, що вимагає:
  ```
  C_best(N) = N - 1
  S_best(N) = 0
  ```
  Часова складність становить `O(N)`.

- **Найгірший випадок (масив відсортований у зворотному порядку):**
  Прапорець `swapped` встановлюється в `true` на кожній ітерації. Алгоритм виконує всі `N - 1` проходів:
  ```
  C_worst(N) = N·(N - 1) / 2
  S_worst(N) = N·(N - 1) / 2
  ```

- **Середній випадок:**
  Кількість проходів `K(π)` у сортуванні бульбашкою визначається максимальною відстанню, на яку будь-який елемент має зміститися **ліворуч**. Якщо `π(i)` — початкова позиція елемента, а `i` — його фінальна позиція, то:
  ```
  K(π) = max_{1 ≤ j ≤ N} (j - π⁻¹(j))
  ```
  Оскільки один прохід зліва направо зміщує будь-який елемент ліворуч максимум на 1 позицію, алгоритм потребує щонайменше `K(π)` проходів (плюс один фінальний перевірочний прохід без обмінів для встановлення `swapped = false`).

Математичне сподівання кількості проходів для рівномірно випадкової перестановки асимптотично дорівнює:

```
E[K(N)] = N - sqrt(pi·N / 2) + O(1)
```

Це доводить, що на випадкових даних прапорець `swapped` економить лише `O(sqrt(N))` проходів з кінця, тому середня кількість порівнянь залишається строго асимптотично квадратичною:

```
E[C(N)] = N·(N - 1) / 2 - O(N^(1.5)) ≈ 0.5·N²
```

## 7. Математична модель явища «черепах» (Turtles)

Чому існує критична різниця між переміщенням великих і малих елементів? Розглянемо рух двох конкретних елементів:

1. **Рух «кролика» (великий елемент на початку масиву):**
   Нехай максимальний елемент `N` знаходиться на позиції `1`. Під час першого ж проходу він порівнюється з `A[2]`, оскільки `N > A[2]`, відбувається обмін. Потім він порівнюється з `A[3]` і знову міняється місцями. Таким чином, за один прохід він здійснює `N - 1` послідовних обмінів і опиняється на своїй фінальній позиції `N`. Його швидкість зміщення: `v_right = N - 1` позицій за прохід.

2. **Рух «черепахи» (малий елемент наприкінці масиву):**
   Нехай мінімальний елемент `1` знаходиться на останній позиції `N`. Під час проходу зліва направо внутрішній цикл доходить до пари `(A[N-1], A[N])`. Відбувається обмін, і елемент `1` переміщується на позицію `N-1`. Прохід завершується.
   За весь прохід елемент `1` змістився ліворуч лише на **1 позицію**. Його швидкість зміщення:
   ```
   v_left = 1  позиція за прохід
   ```

Якщо масив має вигляд `(2, 3, 4, ..., N, 1)`, то початкова кількість інверсій дорівнює лише `N - 1` (лише елемент `1` утворює інверсії з усіма іншими). Проте через обмеження `v_left = 1` сортуванню бульбашкою знадобиться рівно `N - 1` проходів, щоб дотягнути одиницю до початку масиву.

Це дає сумарну кількість порівнянь:

```
C = ∑_{k=1}^{N-1} (N - k) = N·(N - 1) / 2
```

## 8. Математичний баланс у Cocktail Shaker Sort

Двонаправлене сортування Cocktail Shaker Sort відновлює симетрію швидкостей.
- Під час прямого проходу максимальний елемент зміщується праворуч на відстань до `N - 1`.
- Під час зворотного проходу мінімальний елемент зміщується ліворуч також на відстань до `N - 1`.

Таким чином, швидкість зміщення екстремумів стає симетричною в обох напрямках: `v_left = N - 1` та `v_right = N - 1`. Кількість проходів у Cocktail Shaker Sort визначається не максимальним лівим зміщенням, а сумою максимального лівого та правого відхилень, що на практичних послідовностях із невеликою кількістю вибитих елементів скорочує час сортування з `O(N²)` до `O(N)`. При цьому загальна кількість обмінів залишається строго інваріантною: `TotalSwaps = I(π)`.
