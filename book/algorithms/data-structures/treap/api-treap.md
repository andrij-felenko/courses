# 📋 Довідник інтерфейсу та складності операцій Treap

Цей довідник містить вичерпну технічну специфікацію функціонального інтерфейсу, внутрішніх структур розміщення в оперативній пам'яті, системних інваріантів та оцінок асимптотичної складності для явного (*Explicit Treap*) та неявного (*Implicit Treap*) декартового дерева. Документ визначає точний контракт виклику примітивів, гарантії безпеки пам'яті, правила взаємодії між лінивими прапорцями та вимоги до інтеграції структури у виробничі програмні комплекси.

## 1. Специфікація структур розміщення в оперативній пам'яті

Декартове дерево проектується як двійкове вузлове дерево. Для явного та неявного варіантів використовуються різні структури вузлів з оптимізованим вирівнюванням полів відповідно до стандартів платформи.

### 1.1. Вузол явного декартового дерева (Explicit Treap Node)

Призначений для представлення впорядкованої динамічної множини (*Set*) або асоціативного словника (*Map*).

:::tabs
```c
typedef struct TreapNode {
    int key;
    uint32_t priority;
    struct TreapNode *left;
    struct TreapNode *right;
} TreapNode;
```
```cpp
template <typename KeyType>
struct TreapNode {
    KeyType key;
    uint32_t priority;
    std::unique_ptr<TreapNode> left{nullptr};
    std::unique_ptr<TreapNode> right{nullptr};
};
```
:::

- `key`: цілочисельний або довільний шаблонний ключ пошуку. Визначає позицію елемента у симетричному обході дерева пошуку. Інваріант вимагає, щоб усі елементи в лівому піддереві мали суворо менші ключі, а в правому — суворо більші.
- `priority`: 32-бітне беззнакове випадкове число, згенероване під час створення вузла. Визначає позицію вузла в ієрархії максимальної купи (*Max-Heap*): пріоритет батьківського вузла завжди строго більший за пріоритети його дочірніх вузлів.
- `left`: покажчик на ліве піддерево. Може бути `NULL` (`nullptr`), якщо лівий нащадок відсутній.
- `right`: покажчик на праве піддерево. Може бути `NULL` (`nullptr`), якщо правий нащадок відсутній.

Загальний розмір структури на 64-бітній архітектурі становить 24 байти (за умови 4-байтного ключа та 4-байтного падінгу) або 32 байти (для 8-байтного ключа).

### 1.2. Вузол неявного декартового дерева (Implicit Treap Node)

Призначений для представлення динамічного масиву (*Sequence*) з підтримкою модифікації підвідрізків та агрегованих функцій.

:::tabs
```c
typedef struct ImpNode {
    long long val;
    long long sum;
    int sz;
    bool rev;
    uint32_t priority;
    struct ImpNode *left;
    struct ImpNode *right;
} ImpNode;
```
```cpp
template <typename ValueType>
struct ImpNode {
    ValueType val;
    ValueType sum;
    int sz{1};
    bool rev{false};
    uint32_t priority;
    std::unique_ptr<ImpNode> left{nullptr};
    std::unique_ptr<ImpNode> right{nullptr};
};
```
:::

- `val`: 64-бітне цілочисельне значення елемента, що зберігається в даному вузлі.
- `sum`: 64-бітна агрегована сума значень усього піддерева, яка обчислюється за формулою `val + left->sum + right->sum`. Підтримує асоціативну операцію додавання.
- `sz`: 32-бітне ціле число, що зберігає кількість вузлів у поточному піддереві (`1 + left->sz + right->sz`). Використовується для динамічного обчислення порядкового індексу елемента.
- `priority`: 32-бітний випадковий пріоритет вузла для підтримки властивості купи.
- `rev`: булевий прапорець відкладеного (лінивого) розвороту піддерева. Якщо прапорець встановлений, логічний порядок елементів у піддереві вважається інвертованим.
- `left` та `right`: 64-бітні покажчики на ліве та праве піддерева відповідно.

Загальний розмір структури становить 48 байтів на 64-бітній архітектурі з урахуванням вирівнювання пам'яті компілятором.

## 2. Інтерфейс операцій явного декартового дерева (Explicit Treap)

Усі операції зберігають два фундаментальні інваріанти: порядок двійкового дерева пошуку за полем `key` та порядок максимальної купи за полем `priority`.

### 2.1. treap_split: розрізання дерева за ключем

Розрізає вхідне дерево `T` на два неперетинних дерева `L` та `R` за числовим порогом `k`.

:::tabs
```c
void treap_split(TreapNode *t, int k, TreapNode **l, TreapNode **r);
```
```cpp
void split(std::unique_ptr<TreapNode<KeyType>> t, const KeyType& k,
           std::unique_ptr<TreapNode<KeyType>>& l,
           std::unique_ptr<TreapNode<KeyType>>& r);
```
:::

- **Призначення:** Фундаментальна операція розбиття множини ключів на дві підмножини відносно граничного значення `k`.
- **Вхідні параметри:**
  - `t` — покажчик на корінь вхідного дерева (може бути порожнім `NULL`).
  - `k` — пороговий ключ розрізання.
  - `l` — вихідний покажчик на дерево, що міститиме всі ключі, менші або рівні за `k`.
  - `r` — вихідний покажчик на дерево, що міститиме всі ключі, строго більші за `k`.
- **Передумови (Preconditions):** Вхідне дерево `t` є валідним декартовим деревом, яке задовольняє інваріанти BST та Max-Heap.
- **Постумови (Postconditions):** Дерева `*l` та `*r` задовольняють інваріанти BST та Max-Heap; жоден вузол не втрачено; всі вузли в `*l` мають `key <= k`, усі в `*r` мають `key > k`.
- **Очікувана часова складність:** `O(log n)`.
- **Найгірша часова складність:** `O(n)` (у випадку патологічної колізії генератора випадкових чисел).
- **Просторова складність:** `O(log n)` додаткової пам'яті в системному стеку викликів для рекурсивного спуску.

### 2.2. treap_merge: злиття двох впорядкованих дерев

Об'єднує два декартових дерева `L` та `R` в одне спільне дерево за умови, що всі ключі в `L` строго менші за ключі в `R`.

:::tabs
```c
TreapNode* treap_merge(TreapNode *l, TreapNode *r);
```
```cpp
std::unique_ptr<TreapNode<KeyType>> merge(std::unique_ptr<TreapNode<KeyType>> l,
                                          std::unique_ptr<TreapNode<KeyType>> r);
```
:::

- **Призначення:** Базовий примітив відновлення та об'єднання розрізаних піддерев.
- **Вхідні параметри:**
  - `l` — покажчик на корінь лівого дерева.
  - `r` — покажчик на корінь правого дерева.
- **Передумови (Preconditions):** Гарантується, що `max_key(l) < min_key(r)`. Якщо одне з дерев є `NULL`, умова вважається виконаною автоматично.
- **Постумови (Postconditions):** Повертає корінь нового збалансованого декартового дерева, яке містить повне об'єднання елементів `l ∪ r`.
- **Очікувана часова складність:** `O(log n)`, де `n = |l| + |r|`.
- **Просторова складність:** `O(log n)` у стеку викликів.

### 2.3. treap_insert: додавання нового ключа

Додає новий елемент із ключем `key` до множини.

:::tabs
```c
TreapNode* treap_insert(TreapNode *root, int key);
```
```cpp
void insert(KeyType key);
```
:::

- **Призначення:** Вставка нового елемента зі збереженням логарифмічного балансу.
- **Вхідні параметри:** `root` — поточний корінь дерева; `key` — ключ для вставки.
- **Постумови:** Створює новий вузол з унікальним пріоритетом і вбудовує його у дерево через композицію операцій `split` та `merge`. Повертає оновлений корінь дерева.
- **Очікувана часова складність:** `O(log n)`.
- **Просторова складність:** `O(1)` динамічної пам'яті під новий вузол + `O(log n)` пам'яті стека.

### 2.4. treap_erase: видалення ключа

Видаляє вузол із заданим значенням ключа з декартового дерева.

:::tabs
```c
TreapNode* treap_erase(TreapNode *root, int key);
```
```cpp
void erase(const KeyType& key);
```
:::

- **Призначення:** Безпечне вилучення елемента з наступним коректним злиттям піддерев.
- **Вхідні параметри:** `root` — поточний корінь дерева; `key` — ключ вузла, який необхідно видалити.
- **Постумови:** Якщо ключ знайдено, пам'ять відповідного вузла звільняється за допомогою виклику `free` або деструктора `unique_ptr`, а ліве і праве піддерева зливаються. Якщо ключ відсутній, структура дерева не змінюється.
- **Очікувана часова складність:** `O(log n)`.
- **Просторова складність:** `O(log n)` у стеку викликів.

### 2.5. treap_find: перевірка наявності ключа

Виконує швидкий пошук ключа у дереві за правилами класичного двійкового дерева пошуку.

:::tabs
```c
bool treap_find(const TreapNode *root, int key);
```
```cpp
[[nodiscard]] bool contains(const KeyType& key) const noexcept;
```
:::

- **Призначення:** Перевірка належності елемента динамічній множині.
- **Вхідні параметри:** `root` — корінь дерева (константний покажчик, операція гарантує незмінність структури); `key` — шуканий ключ.
- **Повертане значення:** `true`, якщо вузол із таким ключем присутній у дереві; `false` в іншому випадку.
- **Очікувана часова складність:** `O(log n)`.
- **Просторова складність:** `O(1)` (ітеративна реалізація без використання стека).

### 2.6. treap_kth_element: пошук k-го порядкового елемента

Знаходить ключ елемента, який займає `k`-те місце у порядку зростання всіх ключів дерева.

:::tabs
```c
int treap_kth_element(const TreapNode *root, int k);
```
```cpp
[[nodiscard]] const KeyType& findByOrder(int k) const;
```
:::

- **Призначення:** Пошук порядкової статистики за логарифмічний час за наявності поля `sz` у вузлах.
- **Вхідні параметри:** `root` — корінь дерева; `k` — номер порядкової статистики (`1 <= k <= sz(root)`).
- **Повертане значення:** Ключ `k`-го за величиною елемента множини.
- **Очікувана часова складність:** `O(log n)`.

### 2.7. treap_count_less: підрахунок елементів, менших за поріг

Обчислює кількість елементів у дереві, чиї ключі строго менші за задане порогове значення `k`.

:::tabs
```c
int treap_count_less(const TreapNode *root, int k);
```
```cpp
[[nodiscard]] int orderOfKey(const KeyType& k) const noexcept;
```
:::

- **Призначення:** Швидке визначення рангу елемента в динамічній множині (аналог функції `std::distance(begin, lower_bound)`).
- **Вхідні параметри:** `root` — корінь дерева; `k` — граничний ключ.
- **Повертане значення:** Кількість вузлів із ключами `< k`.
- **Очікувана часова складність:** `O(log n)`.

## 3. Інтерфейс операцій неявного декартового дерева (Implicit Treap)

У неявному декартовому дереві елементи позиціонуються відповідно до їхнього порядкового номера в симетричному обході (1-based індексація: від `1` до `n`).

### 3.1. imp_split: розрізання за розміром префікса

Розрізає послідовність на префікс довжиною `k` елементів та суфікс із решти елементів.

:::tabs
```c
void imp_split(ImpNode *t, int k, ImpNode **l, ImpNode **r);
```
```cpp
void split(std::unique_ptr<ImpNode<ValueType>> t, int k,
           std::unique_ptr<ImpNode<ValueType>>& l,
           std::unique_ptr<ImpNode<ValueType>>& r);
```
:::

- **Призначення:** Виділення початкового сегмента масиву для виконання блокових операцій.
- **Вхідні параметри:**
  - `t` — корінь вхідного дерева послідовності.
  - `k` — точна кількість елементів, які повинні відійти в ліве піддерево `l`.
  - `l` — вихідний покажчик на піддерево з першими `k` елементами.
  - `r` — вихідний покажчик на піддерево з рештою елементів (`sz(t) - k`).
- **Контракт лінивого проштовхування:** Функція зобов'язана викликати `push_down(t)` перед будь-яким зверненням до дочірніх вузлів і викликати `push_up(t)` перед поверненням керування.
- **Очікувана часова складність:** `O(log n)`.

### 3.2. imp_merge: склеювання двох послідовностей

Зливає дві послідовності в єдиний динамічний масив, дописуючи елементи дерева `r` у хвіст послідовності `l`.

:::tabs
```c
ImpNode* imp_merge(ImpNode *l, ImpNode *r);
```
```cpp
std::unique_ptr<ImpNode<ValueType>> merge(std::unique_ptr<ImpNode<ValueType>> l,
                                          std::unique_ptr<ImpNode<ValueType>> r);
```
:::

- **Призначення:** Конкатенація двох фрагментів масиву без копіювання даних.
- **Вхідні параметри:** `l` — ліва послідовність; `r` — права послідовність.
- **Постумови:** Елементи з `l` займають початкові індекси `1 .. sz(l)`, елементи з `r` отримують зсунуті індекси `sz(l) + 1 .. sz(l) + sz(r)`.
- **Очікувана часова складність:** `O(log n)`.

### 3.3. imp_insert: вставка елемента за індексом

Вставляє нове значення у довільну позицію масиву зі зсувом усіх наступних елементів праворуч.

:::tabs
```c
ImpNode* imp_insert(ImpNode *root, int pos, long long val);
```
```cpp
void insertAt(int pos, ValueType val);
```
:::

- **Призначення:** Динамічна вставка в середину масиву за логарифмічний час замість лінійного копіювання.
- **Вхідні параметри:**
  - `root` — корінь дерева;
  - `pos` — цільовий порядковий номер для нового елемента (`1 <= pos <= sz(root) + 1`);
  - `val` — корисне значення елемента.
- **Очікувана часова складність:** `O(log n)`.

### 3.4. imp_erase: видалення елемента за індексом

Видаляє елемент на позиції `pos` зі зсувом наступних елементів ліворуч.

:::tabs
```c
ImpNode* imp_erase(ImpNode *root, int pos);
```
```cpp
void eraseAt(int pos);
```
:::

- **Призначення:** Видалення елемента з довільної позиції масиву.
- **Вхідні параметри:** `root` — корінь дерева; `pos` — індекс елемента для видалення (`1 <= pos <= sz(root)`).
- **Постумови:** Вузол на позиції `pos` коректно видаляється з пам'яті, а розміри всіх батьківських піддерев зменшуються на одиницю.
- **Очікувана часова складність:** `O(log n)`.

### 3.5. imp_reverse: реверс підвідрізка за O(log n)

Виконує дзеркальний розворот підвідрізка послідовності від індексу `l_idx` до `r_idx` включно.

:::tabs
```c
ImpNode* imp_reverse(ImpNode *root, int l_idx, int r_idx);
```
```cpp
void reverseRange(int lIdx, int rIdx);
```
:::

- **Призначення:** Миттєва інверсія порядку елементів на діапазоні без покрокового перебору елементів.
- **Вхідні параметри:** `root` — корінь дерева; `l_idx`, `r_idx` — межі діапазону (`1 <= l_idx <= r_idx <= sz(root)`).
- **Механізм виконання:** Виділяє піддерево діапазону двома викликами `split`, інвертує прапорець `rev ^= true` на його корені за час `O(1)` та повертає піддерево назад викликами `merge`.
- **Очікувана часова складність:** `O(log n)`.

### 3.6. imp_query_sum: запит суми на підвідрізку

Обчислює суму елементів масиву на підвідрізку `[l_idx, r_idx]`.

:::tabs
```c
long long imp_query_sum(ImpNode **root, int l_idx, int r_idx);
```
```cpp
[[nodiscard]] ValueType querySum(int lIdx, int rIdx);
```
:::

- **Призначення:** Швидке агрегування інтервальних статистик на динамічному масиві.
- **Вхідні параметри:** `root` — покажчик на кореневий покажчик дерева; `l_idx`, `r_idx` — межі запиту.
- **Повертане значення:** 64-бітна сума значень елементів на запитаному інтервалі.
- **Очікувана часова складність:** `O(log n)`.

### 3.7. imp_cut_and_paste: переміщення підвідрізка

Вирізає підвідрізок `[l_idx, r_idx]` із поточної позиції та вставляє його перед елементом `target_pos`.

:::tabs
```c
ImpNode* imp_cut_and_paste(ImpNode *root, int l_idx, int r_idx, int target_pos);
```
```cpp
void cutAndPaste(int lIdx, int rIdx, int targetPos);
```
:::

- **Призначення:** Блокове переміщення фрагментів масиву (операція Cut & Paste у текстових буферах) без копіювання пам'яті.
- **Вхідні параметри:** `root` — корінь дерева; `l_idx`, `r_idx` — межі вихідного підвідрізка; `target_pos` — цільова позиція для вставки.
- **Механізм:** Вирізає піддерево діапазону за допомогою двох операцій `split`, об'єднує залишок масиву, розрізає залишок у точці `target_pos` і вставляє вирізане піддерево.
- **Очікувана часова складність:** `O(log n)`.

## 4. Контракт лінивого проштовхування міток (Lazy Propagation Protocol)

При розширенні неявного декартового дерева додатковими груповими операціями над підвідрізками (додавання константи, присвоєння значення, множення) система повинна дотримуватися суворого протоколу взаємодії міток:

1. **Ідемпотентність та інваріантність:** Проштовхування мітки `push_down(v)` зобов'язане перевести вузол `v` у чистий стан (усі прапорці на `v` скидаються в нейтральні значення), одночасно застосувавши відповідні трансформації до значень його прямих синів `v->left` та `v->right`.
2. **Композиція операцій:** При накладанні нової операції поверх невивантаженої старої мітки на дочірньому вузлі виконується алгебраїчна композиція міток за правилами відповідного напівкільця або моноїда дій.
3. **Оновлення агрегованих характеристик:** Значення агрегованих полів (`sum`, `min`, `max`) на дочірніх вузлах перераховуються миттєво під час накладання мітки з урахуванням розміру піддерева `sz`, не чекаючи подальшого рекурсивного спуску.

## 5. Гарантії обробки помилок та безпеки пам'яті

1. **Безпека нульових покажчиків:** Усі відкриті функції API гарантують коректну роботу з покажчиками `NULL` (`nullptr`) без звернення до неініціалізованої пам'яті. Операція `split(NULL)` повертає два нульові покажчики, а `merge(NULL, R)` миттєво повертає `R`.
2. **Контроль меж діапазонів:** Якщо передані індекси виходять за фактичні межі послідовності (`pos > sz + 1` або `l_idx > r_idx`), реалізація відсікає некоректний діапазон до порожнього піддерева без пошкодження структури пам'яті.
3. **Строга гарантія безпеки винятків (Strong Exception Guarantee):** У реалізації на C++ операції модифікації або успішно завершують перебудову дерева, або у разі вичерпання пам'яті (`std::bad_alloc`) залишають дерево у початковому валідному стані без витоків раніше виділених вузлів.

## 6. Сумісність із ітераторами стандартної бібліотеки C++

Для забезпечення повної сумісності з алгоритмами стандартної бібліотеки C++ (`<algorithm>`) обгортка декартового дерева може надавати двонаправлені ітератори (*Bidirectional Iterators*):

- **Порядок обходу:** Оператор інкременту `++it` переходить до наступного вузла у симетричному порядку in-order за амортизований час `O(1)`.
- **Інвалідація ітераторів:** Будь-яка структурна модифікація дерева (`insert`, `erase`, `split`, `merge`, `reverseRange`) призводить до повної інвалідації всіх раніше створених ітераторів, оскільки рекурсивна зміна зв'язків порушує попередні шляхи до предків.
- **Константність:** Константні ітератори (`cbegin()`, `cend()`) надають гарантію незмінності значень ключів для збереження інваріанта двійкового дерева пошуку.

## 7. Серіалізація та швидке відновлення структури за O(n)

При збереженні декартового дерева у постійну пам'ять або передачі мережею структура серіалізується у вигляді простого впорядкованого масиву пар `(key, priority)`. 

Відновлення дерева зі збереженого відсортованого потоку здійснюється за строго лінійний час `O(n)` через монотонний стек:
- Вхідний потік читається послідовно;
- Кожен новий елемент вбудовується у правий хребет за амортизований час `O(1)`;
- Витрати додаткової пам'яті обмежені розміром стека `O(h) = O(log n)`.

Це дозволяє уникнути повільної послідовної вставки за час `O(n log n)` під час завантаження великих баз даних або збережених версій текстових файлів.
