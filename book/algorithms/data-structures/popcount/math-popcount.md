# 🧮 Математичні основи операції Popcount: булева алгебра, SWAR-тотожності та лаконічні структури

Математичний апарат підрахунку одиничних розрядів спирається на лінійну алгебру над скінченним полем GF(2), булеву спектральну теорію та асимптотичний аналіз лаконічних словників рангу й вибірки.

---

## 1. Векторний простір GF(2)ⁿ та метричні властивості

Розглянемо множину `V = {0, 1}ⁿ` усіх двійкових слів довжини `n`. Ця множина утворює `n`-вимірний векторний простір над простим полем Галуа `GF(2) = (𝔽₂, ⊕, ∧)` із двома елементами {0, 1}, де додавання є операцією XOR (додавання за модулем 2), а множення — операцією AND (кон'юнкція).

### Означення ваги Гемінга

Для довільного вектора `x = (x₀, x₁, ..., xₙ₋₁) ∈ 𝔽₂ⁿ` **вагою Гемінга** (позначається `w_H(x)` або `popcount(x)`) називається кількість його ненульових координат:

```
w_H(x) = ∑_{i=0}^{n-1} xᵢ      [сума над полем дійсних чисел ℝ]
```

З погляду функціонального аналізу вага Гемінга є дискретним аналогом `L₁`-норми у просторі `ℝⁿ`:

```
‖x‖₁ = ∑_{i=0}^{n-1} |xᵢ| = w_H(x)      [оскільки xᵢ ∈ {0, 1}]
```

### Властивості норми та відстані Гемінга

Відстань Гемінга між двома векторами `x, y ∈ 𝔽₂ⁿ` задається через вагу їхньої покомпонентної різниці:

```
d_H(x, y) = w_H(x ⊕ y)
```

Функція `d_H(x, y)` задовольняє всі аксіоми метричного простору `(𝔽₂ⁿ, d_H)`:
1. **Невід'ємність та тотожність нерозрізнюваних**: `d_H(x, y) ≥ 0`, причому `d_H(x, y) = 0 ⇔ x = y`.
2. **Симетричність**: `d_H(x, y) = d_H(y, x)`, оскільки `x ⊕ y = y ⊕ x`.
3. **Нерівність трикутника (субадитивність)**: для будь-яких `x, y, z ∈ 𝔽₂ⁿ`:

```
d_H(x, z) ≤ d_H(x, y) + d_H(y, z)
```

Доведення нерівності трикутника випливає з побітового розгляду. Для довільного індексу `i`:

```
(xᵢ ⊕ zᵢ) = (xᵢ ⊕ yᵢ) ⊕ (yᵢ ⊕ zᵢ)
```

Застосовуючи числову нерівність для двійкових змінних `a ⊕ b ≤ a + b` (де `1 ⊕ 1 = 0 ≤ 1 + 1 = 2`), отримуємо:

```
w_H(x ⊕ z)
= ∑_{i=0}^{n-1} (xᵢ ⊕ zᵢ)
= ∑_{i=0}^{n-1} ((xᵢ ⊕ yᵢ) ⊕ (yᵢ ⊕ zᵢ))    [асоціативність додавання за модулем 2]
≤ ∑_{i=0}^{n-1} ((xᵢ ⊕ yᵢ) + (yᵢ ⊕ zᵢ))    [поелементна числова нерівність]
= ∑_{i=0}^{n-1} (xᵢ ⊕ yᵢ) + ∑_{i=0}^{n-1} (yᵢ ⊕ zᵢ) [дистрибутивність суми]
= w_H(x ⊕ y) + w_H(y ⊕ z)                 [за означенням ваги Гемінга]
```

### Формула перетину та об'єднання бітових множин

Якщо розглядати вектори `x, y ∈ {0, 1}ⁿ` як характеристичні вектори підмножин `A, B ⊆ {0, 1, ..., n-1}`, то операції над множинами виражаються через вагу Гемінга:

```
|A ∩ B| = w_H(x ∧ y)
|A ∪ B| = w_H(x ∨ y)
|A \ B| = w_H(x ∧ ¬y)
```

Відома формула включень-виключень для двох множин набуває строгого побітового вигляду:

```
w_H(x ∨ y)
= w_H(x) + w_H(y) - w_H(x ∧ y)      [оскільки xᵢ ∨ yᵢ = xᵢ + yᵢ - (xᵢ ∧ yᵢ)]
```

## 2. Алгебраїчне виведення SWAR-тотожностей додавання

Паралельний алгоритм підрахунку одиниць усередині регістра (SWAR — *SIMD Within A Register*) будується як збалансоване бінарне дерево редукції. Розглянемо суворе виведення кожного етапу.

### Перший рівень: двобітні суматори без переносу

Нехай двобітне число `x = (b₁, b₀)₂ = 2·b₁ + b₀`, де `b₁, b₀ ∈ {0, 1}`. Кількість одиниць у цьому числі дорівнює алгебраїчній сумі `b₁ + b₀`.

Знайдемо спосіб обчислити `b₁ + b₀` без виходу за межі 2-бітного поля:

```
b₁ + b₀
= 2·b₁ + b₀ - b₁      [додали й відняли b₁]
= x - b₁              [оскільки x = 2·b₁ + b₀]
= x - (x >> 1)        [оскільки x >> 1 = b₁ для 2-бітного числа]
```

Для 64-бітного слова, що складається з 32 пар бітів `(b₂ᵢ₊₁, b₂ᵢ)`, застосовуємо константну бітову маску `M₁ = 0x5555555555555555 = 01010101...₂`:

```
x₁ = x - ((x >> 1) & M₁)
```

Перевіримо коректність для всіх чотирьох можливих значень 2-бітного блоку:
- Якщо `(b₁, b₀) = 00₂ = 0`: `0 - (0 & 1) = 0` (0 одиниць);
- Якщо `(b₁, b₀) = 01₂ = 1`: `1 - (0 & 1) = 1` (1 одиниця);
- Якщо `(b₁, b₀) = 10₂ = 2`: `2 - (1 & 1) = 1` (1 одиниця, двійкове `01₂`);
- Якщо `(b₁, b₀) = 11₂ = 3`: `3 - (1 & 1) = 2` (2 одиниці, двійкове `10₂`).

Оскільки значення `b₁ + b₀ ≤ 2`, результат завжди вміщується у 2 біти й ніколи не створює від'ємного переносу (позики) у сусіднє 2-бітне поле.

### Другий рівень: 4-бітні поля

Після першого кроку кожне 2-бітне поле містить значення в діапазоні `[0..2]`. Додамо сусідні 2-бітні поля попарно, утворивши 4-бітні поля.

Застосуємо маску `M₂ = 0x3333333333333333 = 00110011...₂`:

```
x₂ = (x₁ & M₂) + ((x₁ >> 2) & M₂)
```

Максимальна сума двох сусідніх 2-бітних лічильників дорівнює `2 + 2 = 4`, що у двійковому вигляді записується як `0100₂` і гарантовано вміщується у 4 біти (максимальна місткість 4-бітного поля дорівнює 15).

### Третій рівень: 8-бітні поля та усунення проміжної маски

Сума двох сусідніх 4-бітних лічильників дорівнює максимум `4 + 4 = 8`, що у двійковій системі дорівнює `1000₂` і вміщується у 4 біти. Оскільки результат додавання вміщується в нижню половину 8-бітного байта, маскування `M₄ = 0x0F0F0F0F0F0F0F0F` можна виконати **після** операції додавання:

```
x₃ = (x₂ + (x₂ >> 4)) & M₄
```

Це економить одну інструкцію порозрядного `AND`, зменшуючи критичний шлях виконання.

## 3. Модульна арифметика та згортка множенням

Після третього кроку 64-бітне слово складається з 8 байтів `(B₇, B₆, ..., B₀)`, де кожен байт `Bᵢ ∈ {0, 1, ..., 8}` містить кількість одиниць у відповідному 8-бітному сегменті вхідного слова. Загальна кількість одиниць у слові дорівнює сумі всіх байтів:

```
S = ∑_{i=0}^{7} Bᵢ ≤ 64
```

### Теорема про згортку множенням на константу

Нехай слово `X = ∑_{i=0}^{7} Bᵢ · 2⁸ⁱ`. Розглянемо множення числа `X` на константу `C = ∑_{j=0}^{7} 2⁸ʲ = 0x0101010101010101`.

**Твердження:** Старший байт добутку `(X · C) mod 2⁶⁴` дорівнює сумі `∑_{i=0}^{7} Bᵢ`.

**Доведення:** Запишемо добуток двох поліномів відносно базису `2⁸`:

```
X · C
= (∑_{i=0}^{7} Bᵢ · 2⁸ⁱ) · (∑_{j=0}^{7} 2⁸ʲ)
= ∑_{k=0}^{14} (∑_{i+j=k} Bᵢ) · 2⁸ᵏ
```

Розглянемо коефіцієнт при `2⁵⁶` (розряди від 56 до 63, тобто старший байт 64-бітного слова):

```
Коефіцієнт при 2⁵⁶ (k = 7) = ∑_{i+j=7} Bᵢ = ∑_{i=0}^{7} Bᵢ
```

Оскільки максимальна можлива сума `∑_{i=0}^{7} Bᵢ = 64 < 256`, переноси з молодших розрядів `k < 7` не можуть спотворити старший байт більше ніж на величину переносу. Оцінимо максимальний перенос з коефіцієнта при `2⁴⁸` (`k = 6`):

```
Коефіцієнт при 2⁴⁸ = ∑_{i=0}^{6} Bᵢ ≤ 56 < 256
```

Оскільки сума для `k = 6` строго менша за 256, вона генерує нульовий перенос у розряд `2⁵⁶`. Отже:

```
(X · 0x0101010101010101ULL) >> 56 = ∑_{i=0}^{7} Bᵢ = popcount(x)
```

Це доводить, що всі 8 байтів згортаються в єдиний результат за одну операцію 64-бітного цілочисельного множення та один зсув.

## 4. Лаконічні структури даних: теорема Якобсона та ранг

У компактних структурах даних бітовий вектор `B[0..N-1]` підтримує фундаментальну операцію **рангу**:

```
rank₁(i) = w_H(B[0..i]) = ∑_{j=0}^{i} B[j]
```

### Інформаційно-теоретичні межі

Ентропія довільного бітового вектора довжини `N` дорівнює `N` бітів. Згідно з фундаментальною теоремою Гая Якобсона (англ. *Guy Jacobson*, 1989), словник рангу можна побудувати з використанням `N + o(N)` бітів пам'яті, забезпечуючи час відповіді на запит `O(1)`.

### Дворівнева схема індексації

Для досягнення межі Якобсона бітовий масив розбивається на дворівневу ієрархію блоків:

1. **Суперблоки (Superblocks)** розміру `L₁ = ⌊(log₂ N)²⌋` бітів. Для кожного суперблока зберігається абсолютне значення `rank₁(k · L₁)`.
   - Кількість суперблоків: `N / L₁ = N / (log₂ N)²`;
   - Розмір одного запису: `⌈log₂ N⌉` бітів;
   - Загальний обсяг пам'яті: `(N / (log₂ N)²) · log₂ N = N / log₂ N = o(N)` бітів.

2. **Базові блоки (Basic blocks)** розміру `L₂ = ⌊(log₂ N) / 2⌋` бітів усередині суперблока. Для кожного базового блоку зберігається відносне зміщення рангу від початку суперблока.
   - Кількість базових блоків: `N / L₂ = 2N / log₂ N`;
   - Максимальне значення відносного рангу: `L₁ = (log₂ N)²`;
   - Розмір одного запису: `⌈log₂ ((log₂ N)²)⌉ = 2 ⌈log₂ log₂ N⌉` бітів;
   - Загальний обсяг пам'яті: `(2N / log₂ N) · 2 log₂ log₂ N = O(N · log log N / log N) = o(N)` бітів.

3. **Залишок усередині блоку**: розмір залишку становить `≤ L₂ = (log₂ N) / 2` бітів.
   Завдяки тому, що розмір слова сучасного процесора `W = 64 ≥ L₂`, кількість одиниць у залишку обчислюється рівно за одну апаратну інструкцію `popcount`:

```
rank₁(i) = Superblock[⌊i / L₁⌋] + BlockOffset[⌊i / L₂⌋] + popcount(B[word] & mask)
```

Загальна додаткова пам'ять складає:

```
Space = N + o(N) = N + O(N · log log N / log N) бітів
```

При цьому час запиту становить строго `O(1)` операцій читання з пам'яті та один виклик `popcount`.

## 5. Спектральні властивості та перетворення Волша-Адамара

Вага Гемінга визначає знак базисних функцій у гармонічному аналізі булевих функцій.

Для вектора `x ∈ {0, 1}ⁿ` функція парності (характер групи `𝔽₂ⁿ`) визначається як:

```
χ_u(x) = (-1)^{u · x} = (-1)^{popcount(u ∧ x)}
```

Швидке перетворення Волша-Адамара (FWHT — *Fast Walsh-Hadamard Transform*) перетворює функцію `f: {0, 1}ⁿ → ℝ` у спектральну область за формулою:

```
f̂(u) = ∑_{x ∈ {0, 1}ⁿ} f(x) · (-1)^{popcount(u ∧ x)}
```

Спектральний аналіз через `popcount(u ∧ x)` лежить в основі розрахунку нелінійності криптографічних S-блоків (критерій строгого лавинного ефекту SAC), оцінки кореляційного імунітету булевих функцій та алгоритмів швидкої згортки на підмножинах (SOS DP — *Sum Over Subsets Dynamic Programming*).
