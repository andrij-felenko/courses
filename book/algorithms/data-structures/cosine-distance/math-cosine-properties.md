# 🧮 Математичні властивості та геометрія косинусної відстані

Ця вставка містить строге математичне обґрунтування геометрії косинусної відстані, доведення нерівності Коші — Буняковського — Шварца, аналіз трикутних нерівностей та порівняння з кутовою метрикою (Angular Distance) у гільбертових та евклідових просторах.

## 1. Скалярний добуток та нерівність Коші — Буняковського — Шварца

Нехай `V = ℝᵈ` — дійснозначний векторний простір вимірності `d`. Скалярним добутком двох векторів `u = [u₁, u₂, ..., u_d]` та `v = [v₁, v₂, ..., v_d]` називається скалярна величина:

```
u · v = ∑ᵢ₌₁ᵈ (uᵢ · vᵢ)
```

Норма (довжина) вектора `u` визначається як евклідова норма `L₂`:

```
||u|| = √(u · u) = √(∑ᵢ₌₁ᵈ uᵢ²)
```

Щоб поняття косинуса кута між двома векторами було математично коректним у `d`-вимірному просторі, вираз `(u · v) / (||u|| · ||v||)` повинен строго знаходитися в межах замкненого інтервалу `[-1, 1]`. Це гарантується фундаментальною **нерівністю Коші — Буняковського — Шварца**.

### Доведення нерівності Коші — Буняковського — Шварца

Для будь-яких векторів `u, v ∈ ℝᵈ` виконується нерівність:

```
|u · v| ≤ ||u|| · ||v||
```

**Доведення:**
Розглянемо квадрат норми лінійної комбінації векторів `t · u + v`, де `t ∈ ℝ` — довільний дійсний параметр. Оскільки квадрат норми будь-якого вектора за означенням є невід'ємним, маємо:

```
P(t) = ||t · u + v||² ≥ 0
```

Розкриємо квадрат норми через скалярний добуток, використовуючи його білінійність та симетричність:

```
P(t) = (t · u + v) · (t · u + v)
     = t² · (u · u) + 2t · (u · v) + (v · v)   [розкриття дужок за дистрибутивністю]
     = t² · ||u||² + 2t · (u · v) + ||v||²     [означення норми: u · u = ||u||²]
```

Отриманий вираз `P(t)` є квадратним тричленом відносно змінної `t` із коефіцієнтами:

```
A = ||u||²
B = 2(u · v)
C = ||v||²
```

Оскільки `P(t) ≥ 0` для всіх `t ∈ ℝ`, цей квадратний тричлен може мати не більше одного дійсного кореня. Отже, його дискримінант `D` повинен бути непозитивним (`D ≤ 0`):

```
D = B² - 4AC ≤ 0
D = (2(u · v))² - 4 · ||u||² · ||v||² ≤ 0
4(u · v)² - 4 · ||u||² · ||v||² ≤ 0
(u · v)² ≤ ||u||² · ||v||²
```

Взявши квадратний корінь з обох частин нерівності, отримуємо:

```
|u · v| ≤ ||u|| · ||v||
```

Що й треба було довести. ∎

З нерівності Коші — Буняковського — Шварца безпосередньо випливає, що для довільних ненульових векторів `u` та `v`:

```
-1 ≤ (u · v) / (||u|| · ||v||) ≤ 1
```

Це дозволяє однозначно визначити кут `θ ∈ [0, π]` між векторами через арккосинус.

## 2. Формальне означення косинусної схожості та косинусної відстані

**Косинусна схожість (Cosine Similarity)** між векторами `u` та `v` визначається як:

```
CosSim(u, v) = cos(θ) = (u · v) / (||u|| · ||v||) = ∑(uᵢ · vᵢ) / (√(∑ uᵢ²) · √(∑ vᵢ²))
```

**Косинусна відстань (Cosine Distance)** визначається як доповнення косинусної схожості до одиниці:

```
d_cos(u, v) = 1 - CosSim(u, v) = 1 - (u · v) / (||u|| · ||v||)
```

Властивості областей значень:
- Якщо вектори співнапрямлені (`θ = 0°`), то `cos(θ) = 1` та `d_cos(u, v) = 0`.
- Якщо вектори ортогональні (`θ = 90°`), то `cos(θ) = 0` та `d_cos(u, v) = 1`.
- Якщо вектори протилежно напрямлені (`θ = 180°`), то `cos(θ) = -1` та `d_cos(u, v) = 2`.

Для невід'ємних векторів (наприклад, у задачах `TF-IDF` або після активації `ReLU` в нейронних мережах, де `uᵢ ≥ 0`, `vᵢ ≥ 0`), скалярний добуток завжди невід'ємний `u · v ≥ 0`. У цьому випадку `cos(θ) ∈ [0, 1]`, а косинусна відстань лежить у межах `d_cos(u, v) ∈ [0, 1]`.

## 3. Тотожність із Евклідовою відстанню на одиничній гіперсфері

Нехай вектори `ū` та `v̄` є L2-нормалізованими, тобто належать одиничній гіперсфері `Sᵈ⁻¹ = {x ∈ ℝᵈ : ||x|| = 1}`:

```
ū = u / ||u||,   v̄ = v / ||v||
```

Обчислимо квадрат Евклідової відстані між нормалізованими точками `ū` та `v̄`:

```
d_E²(ū, v̄)
= ||ū - v̄||²                    [квадрат евклідової відстані між точками ū та v̄]
= (ū - v̄) · (ū - v̄)            [означення квадрата норми через скалярний добуток]
= ū · ū - 2(ū · v̄) + v̄ · v̄     [розкриття дужок за дистрибутивністю]
= ||ū||² + ||v̄||² - 2(ū · v̄)    [заміна ū · ū = ||ū||² та v̄ · v̄ = ||v̄||²]
```

Оскільки `||ū|| = 1` та `||v̄|| = 1`, підставимо ці значення:

```
d_E²(ū, v̄)
= 1 + 1 - 2(ū · v̄)             [підстановка одиничних норм: ||ū|| = 1, ||v̄|| = 1]
= 2 - 2(ū · v̄)                 [скалярна арифметика: 1 + 1 = 2]
= 2(1 - ū · v̄)                [винесення 2 за дужки]
= 2 · d_cos(u, v)              [підстановка означення косинусної відстані]
```

Звідси отримуємо фундаментальну тотожність між Евклідовою та Косинусною відстанню на одиничній сфері:

```
d_cos(u, v) = 1/2 · d_E²(ū, v̄)
d_E(ū, v̄)   = √(2 · d_cos(u, v))
```

**Наслідок для оптимізації:**
Оскільки функція `f(x) = 1/2 · x²` є строго монотонно зростаючою для `x ≥ 0`, **порядкове впорядкування (ранжування) елементів за косинусною відстанню на одиничній сфері повністю збігається з впорядкуванням за Евклідовою відстанню**. Це дозволяє використовувати будь-які алгоритми та індекси, спроектовані для метрики `L₂` (наприклад, `kd-дерева` чи `HNSW`), для пошуку за косинусною відстанню за умови попередньої нормалізації векторів.

## 4. Чому косинусна відстань є псевдометрикою (Порушення аксіом метрики)

Математичний простір `(X, d)` називається **метричним простором**, якщо функція відстані `d: X × X → ℝ` задовольняє чотири фундаментальні аксіоми для будь-яких `x, y, z ∈ X`:

1. **Невід'ємність:** `d(x, y) ≥ 0`.
2. **Тотожність нерозрізнюваних:** `d(x, y) = 0 ⇔ x = y`.
3. **Симетрія:** `d(x, y) = d(y, x)`.
4. **Нерівність трикутника:** `d(x, z) ≤ d(x, y) + d(y, z)`.

Перевіримо виконання цих аксіом для косинусної відстані `d_cos(u, v) = 1 - cos(θ)`:

### Перевірка Аксіоми 2 (Тотожність нерозрізнюваних)

Якщо `d_cos(u, v) = 0`, це означає `cos(θ) = 1`, тобто кут `θ = 0°`. Це свідчить про те, що вектори `u` та `v` є співнапрямленими (`v = c · u`, де `c > 0`).

Проте вектори `u = [1, 2]` та `v = [2, 4]` є різними елементами простору `ℝ²` (`u ≠ v`), але косинусна відстань між ними дорівнює нулю: `d_cos(u, v) = 0`.
Отже, у загальному просторі `ℝᵈ` Аксіома 2 **не виконується**. Вона виконується лише за умови обмеження простору до одиничної гіперсфери `Sᵈ⁻¹`.

### Перевірка Аксіоми 4 (Нерівність трикутника) — ПОРУШЕННЯ

Косинусна відстань **строго порушує нерівність трикутника**.

**Доведення через контрприклад:**
Розглянемо три вектори на двовимірній площині `ℝ²`:

```
u = [1, 0]             (кут 0°)
v = [1/√2, 1/√2]       (кут 45°)
w = [0, 1]             (кут 90°)
```

Обчислимо косинусні відстані між усіма парами:

1. Відстань `d_cos(u, v)`:
   `cos(θ_uv) = cos(45°) = 1/√2 ≈ 0.7071`
   `d_cos(u, v) = 1 - 1/√2 ≈ 0.2929`

2. Відстань `d_cos(v, w)`:
   `cos(θ_vw) = cos(45°) = 1/√2 ≈ 0.7071`
   `d_cos(v, w) = 1 - 1/√2 ≈ 0.2929`

3. Відстань `d_cos(u, w)`:
   `cos(θ_uw) = cos(90°) = 0.0`
   `d_cos(u, w) = 1 - 0.0 = 1.0`

Перевіримо нерівність трикутника `d_cos(u, w) ≤ d_cos(u, v) + d_cos(v, w)`:

```
d_cos(u, w) = 1.0
d_cos(u, v) + d_cos(v, w) = 0.2929 + 0.2929 = 0.5858

Отримуємо: 1.0 ≤ 0.5858  ──► ХИБНІСТЬ!
```

Нерівність не виконується (`1.0 > 0.5858`). Косинусна відстань порушує нерівність трикутника, тому вона **не є справжньою метрикою**, а є **псевдометрикою** (або семіметрикою).

**Наслідок для алгоритмів:** Через порушення нерівності трикутника косинусну відстань **неможливо безпосередньо використовувати** у класичних метричних деревних структурах (таких як `VP-дерева`, `BK-дерева` чи `M-дерева`), які фундаментально спираються на відсікання гілок за нерівністю трикутника `d(x, z) ≤ d(x, y) + d(y, z)`.

## 5. Кутова відстань (Angular Distance) як справжня метрика

Щоб отримати повноцінну метрику, яка задовольняє всі чотири аксіоми (включаючи нерівність трикутника) і описує кутову схожість, використовують **Кутову відстань (Angular Distance)**.

Кутова відстань визначається як дугова довжина (найкоротша геодезична лінія на одиничній сфері), дуговий кут `θ`, нормований на `π`:

```
d_ang(u, v) = θ / π = arccos(cos(θ)) / π = arccos((u · v) / (||u|| · ||v||)) / π
```

Область значень кутової відстані: `d_ang(u, v) ∈ [0, 1]`.

Оскільки кутова відстань `d_ang` вимірює довжину дуги великого кола на одиничній сфері, вона повністю відповідає сферичній геометрії і **строго задовольняє нерівність трикутника** для будь-яких трьох точок сфери:

```
θ_uw ≤ θ_uv + θ_vw  ──►  d_ang(u, w) ≤ d_ang(u, v) + d_ang(v, w)
```

Перевірка для нашого попереднього контрприкладу:
- `d_ang(u, v) = 45° / 180° = 0.25`
- `d_ang(v, w) = 45° / 180° = 0.25`
- `d_ang(u, w) = 90° / 180° = 0.50`
- `0.50 ≤ 0.25 + 0.25 = 0.50` — Нерівність трикутника виконується точно.

У практичному програмуванні обчислення `arccos` вимагає додаткових обчислювальних витрат процесора (трансцендентна функція), тому у високонавантажених індексах найчастіше застосовують саме `d_cos = 1 - cos(θ)` або скалярний добуток на нормалізованих векторах, а кутову відстань `d_ang` використовують у теоретичних доведеннях та в алгоритмах, які критично вимагають виконання нерівності трикутника.
