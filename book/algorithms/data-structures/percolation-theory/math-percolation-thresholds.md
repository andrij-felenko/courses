# 🧮 Точні розв'язки, двоїстість ґраток та масштабні інваріанти перколації

Теорія перколації досліджує геометричний фазовий перехід, де мікроскопічна випадковість породжує макроскопічну топологічну зв'язність. Ця вставка містить строгі математичні виведення точних порогів перколації на основі планарної двоїстості та зірко-трикутного перетворення, аналітичний опис масштабних законів у критичній області, універсальні співвідношення між критичними індексами та математичний апарат біноміальної згортки мікроканонічних ансамблів.

## Планарна двоїстість та поріг квадратної ґратки

Розглянемо нескінченний планарний граф `G = (V, E)`, що утворює квадратну ґратку з кроком 1. Кожне ребро `e ∈ E` відкрите з ймовірністю `p` та закрите з ймовірністю `1 - p` незалежно від решти ребер. Це відповідає реберній перколації.

Побудуємо двоїстий граф `G* = (V*, E*)`. Вершини `V*` розташовані в геометричних центрах кожної комірки (грані) прямої ґратки `G`. Кожному ребру `e ∈ E` відповідає рівно одне двоїсте ребро `e* ∈ E*`, що перетинає `e` перпендикулярно. Двоїсте ребро `e*` вважається відкритим на двоїстій ґратці тоді й лише тоді, коли відповідне пряме ребро `e` закрите на прямій ґратці.

Таким чином, якщо пряме ребро `e` відкрите з ймовірністю `p`, то двоїсте ребро `e*` відкрите з ймовірністю:

```
p* = 1 - p
```

Нехай `R(L, M)` — прямокутний блок ґратки `G` розміром `L × M` комірок. Позначимо через `π_H(p, L, M)` ймовірність існування неперервного відкритого горизонтального шляху зліва направо через блок `R`. За класичною топологічною теоремою на площині, горизонтальний відкритий шлях у `G` не існує тоді й лише тоді, коли існує неперервний відкритий вертикальний шлях згори донизу на двоїстій ґратці `G*`, що перетинає прямокутник і блокує прямий прохід.

Оскільки вертикальний блокуючий бар'єр утворюється ребрами двоїстої ґратки з ймовірністю `p* = 1 - p`, точна сума ймовірностей взаємовиключних подій задовольняє тотожність:

```
π_H(p, L, M) + π_V*(1 - p, M, L) = 1
```

Для квадратної ґратки двоїстий граф `G*` ізоморфний прямому графу `G` (властивість самодвоїстості: `G* ≅ G`). З міркувань поворотної симетрії на квадратному блоці `L × L`:

```
π_V*(1 - p, L, L) = π_H(1 - p, L, L)
```

Підставляючи це у співвідношення перетину прямокутника, маємо:

```
π_H(p, L, L) + π_H(1 - p, L, L) = 1
```

У критичній точці `p_c`, коли розмір системи прямує до нескінченності `L → ∞`, функція ймовірності перетину зазнає різкого стрибка. Єдиною точкою симетрії, де система не віддає переваги ні прямим, ні двоїстим зв'язкам, є розв'язок рівняння:

```
p_c = 1 - p_c
```

Розв'язуючи це лінійне рівняння відносно критичного порогу:

```
2 · p_c = 1           [додавання p_c до обох частин]
= p_c = 1 / 2         [ділення обох частин на 2]
```

Це дає точне аналітичне значення критичного порогу реберної перколації на двовимірній квадратній ґратці: `p_c(bond) = 0.5`.

## Точний розв'язок на ґратці Бете через породжувальні функції

Ґратка Бете (нескінченне регулярне дерево Келі) з координаційним числом `z` є еталонною моделлю, де відсутність замкнених циклів дозволяє знайти точні аналітичні розв'язки для всіх статистичних величин за допомогою апарату гілкуючих процесів.

Нехай кожен вузол має `z` сусідів. Оберімо кореневий вузол `0` та спрямуймо зв'язки назовні. Кожен вузол наступного покоління породжує `z - 1` нових гілок. Позначимо через `Q` ймовірність того, що промінь, випущений із даного вузла вздовж фіксованого ребра, не веде до нескінченності (ймовірність згасання гілки).

Гілка згасає у двох випадках:
1. Початкове ребро закрите (ймовірність `1 - p`).
2. Початкове ребро відкрите (ймовірність `p`), але всі `z - 1` наступних дочірніх променів також згасають незалежно один від одного (ймовірність `Qᶻ⁻¹`).

Це породжує самоузгоджене нелінійне рівняння для ймовірності `Q`:

```
Q = (1 - p) + p · Qᶻ⁻¹
```

Очевидним тривіальним розв'язком для будь-якого `p` є `Q = 1` (нескінченного кластера немає). Щоб знайти нетривіальний фізичний розв'язок `Q < 1`, перепишемо рівняння, виділивши множник `(1 - Q)`:

```
1 - Q = p · (1 - Qᶻ⁻¹)
```

Застосовуючи формулу суми геометричної прогресії `1 - Qᶻ⁻¹ = (1 - Q) · (1 + Q + Q² + ... + Qᶻ⁻²)` та скорочуючи на `1 - Q ≠ 0`:

```
1 = p · ∑ₖ₌₀ᶻ⁻² Qᵏ
```

Критичний поріг `p_c` відповідає точці, де нетривіальний розв'язок зароджується при `Q → 1⁻`. Підставляючи `Q = 1` у розгорнуту суму:

```
1 = p_c · (z - 1)
```

Звідси отримуємо фундаментальний поріг перколації на ґратці Бете:

```
p_c = 1 / (z - 1)
```

Потужність нескінченного кластера `P_∞(p)` (ймовірність того, що центральний вузол належить до нескінченного кластера) обчислюється через ймовірність того, що не всі його `z` зв'язків згасають:

```
P_∞(p) = 1 - Qᶻ
```

Розкладаючи `Q(p)` в околі `p_c` при `p > p_c`, отримуємо лінійне зростання `P_∞(p) ∝ (p - p_c)¹`, що доводить значення критичного індексу `β = 1` для теорії середнього поля.

## Теорія Руссо–Сеймура–Велша (RSW) та формула Карді

Для двовимірних систем фундаментальним інструментом строгого аналізу є лема Руссо–Сеймура–Велша (*RSW theory*). Вона стверджує, що якщо ймовірність перетину квадрата `L × L` у критичній точці обмежена знизу додатною сталою `c > 0` незалежно від `L`:

```
π_H(p_c, L, L) ≥ c > 0
```

то ймовірність перетину витягнутого прямокутника `kL × L` для будь-якого фіксованого коефіцієнта пропорційності `k > 1` також обмежена знизу додатною величиною `c_k > 0`, що не залежить від масштабу `L`:

```
π_H(p_c, kL, L) ≥ c_k > 0,   де L → ∞
```

Це доводить, що перколяційні кластери в критичній точці мають фрактальну структуру та пронизують систему на всіх масштабах без експоненційного згасання зв'язності.

У 1992 році Джон Карді (*John Cardy*) передбачив точну формулу для граничної ймовірності перетину конформного прямокутника з модулем `m` (відношенням довжини до ширини) для вузлової перколації на трикутній ґратці:

```
π_H(m) = (Γ(2/3) / (Γ(1/3) · Γ(4/3))) · η¹/³ · ₂F₁(1/3, 2/3; 4/3; η)
```

де `₂F₁` — гіпергеометрична функція Гаусса, а `η` — модуль конформного відображення області на верхню півплощину. Це співвідношення було строго доведено Станіславом Смирновим у 2001 році через побудову дискретних голоморфних мартингалів на трикутній ґратці.

## Зірко-трикутне перетворення: трикутна та стільникова ґратки

Трикутна ґратка `T` та стільникова (шестикутна) ґратка `H` не є самодвоїстими, проте вони утворюють двоїсту пару: `T* ≅ H` та `H* ≅ T`. Зв'язок між їхніми критичними порогами встановлюється за допомогою операції зірка–трикутник (Y–Δ перетворення), запропонованого Майклом Сайксом (*Sykes*) та Джоном Ессамом (*Essam*).

Розглянемо трикутник із трьох ребер, кожне з яких відкрите з ймовірністю `p_T`, та еквівалентну зірку з центральним вузлом і трьома променями з ймовірністю відкриття `p_H`. Вимагаючи рівності ймовірностей зв'язності між будь-якою парою з трьох зовнішніх терміналів у обох конфігураціях, отримуємо кубічне рівняння для критичних концентрацій:

```
1 - 3 · p_c(bond, T) + p_c(bond, T)³ = 0
```

Застосовуючи тригонометричну формулу Вієта для коренів кубічного рівняння, отримуємо точний розв'язок для реберної перколації на трикутній ґратці:

```
p_c(bond, T) = 2 · sin(π / 18) ≈ 0.347296
```

Оскільки стільникова ґратка є двоїстою до трикутної, її поріг реберної перколації виражається як:

```
p_c(bond, H) = 1 - p_c(bond, T)
= 1 - 2 · sin(π / 18) [підстановка точного порогу трикутної ґратки]
≈ 0.652704            [чисельне значення]
```

Для вузлової перколації на трикутній ґратці кожні три сусідні вершини утворюють грань-трикутник. Самодвоїстість заповнення трикутників дозволяє застосувати теорему Кестена–Смирнова, яка дає точний поріг:

```
p_c(site, T) = 1 / 2 = 0.5
```

Для квадратної ґратки вузлова перколація не володіє простою топологічною самодвоїстістю (бо діагональні зв'язки між порожніми сайтами блокують ортогональні зв'язки зайнятих), тому поріг не є раціональним числом і визначається чисельно з надзвичайно високою точністю:

```
p_c(site, square) ≈ 0.59274605079210
```

## Критичні індекси та масштабні закони

Поблизу критичної точки `p → p_c` термодинамічні та геометричні величини характеризуються неаналітичною поведінкою, що підпорядковується степеневим законам. Поведінка системи описується набором критичних індексів.

Введемо відхилення від критичної концентрації `ε = (p - p_c) / p_c`.

1. **Параметр порядку (потужність нескінченного кластера `P_∞`)**:
Частка зайнятих вузлів, що належать до макроскопічного зв'язного кластера, дорівнює нулю при `p < p_c`, а при `p > p_c` зростає за законом:

```
P_∞(p) ∝ (p - p_c)ᵝ,   де p > p_c
```

2. **Радіус кореляції (характерний розмір кластерів `ξ`)**:
Середня відстань між двома вузлами, що належать до одного скінченного кластера, розбігається при наближенні до порогу з обох боків:

```
ξ(p) ∝ |p - p_c|⁻ᵛ
```

3. **Сприйнятливість (середній розмір скінченного кластера `χ` або `S`)**:
Середня кількість вузлів у кластері, до якого належить довільно вибраний вузол (за винятком нескінченного кластера):

```
χ(p) = ∑ₛ s² · n_s(p) ∝ |p - p_c|⁻ᵞ
```

4. **Розподіл кластерів за розмірами `n_s(p)`**:
Кількість кластерів розміру `s` на один вузол ґратки безпосередньо в критичній точці `p = p_c` спадає степеневим чином:

```
n_s(p_c) ∝ s⁻ᵀ
```

При відхиленні від порогу `p ≠ p_c` розподіл набуває експоненційного обрізання:

```
n_s(p) ∝ s⁻ᵀ · exp(-s / s_max),   де s_max ∝ |p - p_c|⁻¹/ᵒ
```

Критичні індекси не є незалежними. Завдяки гіпотезі масштабної інваріантності (скейлінгу) між ними існують фундаментальні співвідношення:

- **Рівність Рашбрука (Rushbrooke)**:

```
α + 2 · β + γ = 2
```

- **Рівність Відіма (Widom)**:

```
γ = β · (δ - 1)
```

- **Гіперскейлінгове співвідношення Джозефсона (Josephson)** для простору розмірності `d`:

```
d · ν = 2 - α
```

- **Зв'язок індексів розподілу кластерів**:

```
τ = 2 + β / (β + γ) = 2 + β · σ
```

```
γ = (3 - τ) / σ
```

У двовимірному просторі (`d = 2`) значення критичних індексів знайдено строго за допомогою конформної теорії поля та стохастичної еволюції Шрамма–Левнера `SLE(6)`:

```
β = 5 / 36   ≈ 0.138889
γ = 43 / 18  ≈ 2.388889
ν = 4 / 3    ≈ 1.333333
α = -2 / 3   ≈ -0.666667
τ = 187 / 91 ≈ 2.054945
σ = 36 / 91  ≈ 0.395604
```

Для просторів високої розмірності (`d ≥ 6`) флуктуації стають несуттєвими, і система переходить у клас універсальності теорії середнього поля (еквівалентний ґратці Бете):

```
β = 1
γ = 1
ν = 1 / 2
α = -1
τ = 5 / 2
σ = 1 / 2
```

## Ренормалізаційна група простору: децимація на трикутній ґратці

Метод ренормалізаційної групи (РГ), розроблений Лео Кадановим та Кеннетом Вільсоном у фізиці твердого тіла, дає потужний інтуїтивний та аналітичний інструмент для розуміння масштабності перколації.

Розглянемо вузлову перколацію на двовимірній трикутній ґратці. Об'єднаємо вузли у трикутні блоки-комірки розміром `b = √3`, що містять по 3 сайти кожен. Застосуємо **правило більшості** (*majority rule*): укрупнений макроскопічний блок вважається відкритим (зайнятим), якщо принаймні два з трьох його початкових сайтів є відкритими.

Ймовірність того, що укрупнена комірка відкрита, позначається `p'` і виражається через початкову ймовірність `p` як поліном ренормалізаційного перетворення `R(p)`:

```
p' = R(p) = p³ + 3 · p² · (1 - p)
= p³ + 3 · p² - 3 · p³       [розкриття дужок]
= 3 · p² - 2 · p³           [зведення подібних членів]
```

Фізичні фазові стани системи відповідають **нерухомим точкам** ренормалізаційного перетворення, які задовольняють рівняння `R(p*) = p*`:

```
3 · (p*)² - 2 · (p*)³ = p*
```

Переносячи всі члени в ліву частину та розкладаючи поліном на множники:

```
2 · (p*)³ - 3 · (p*)² + p* = 0
= p* · (2 · (p*)² - 3 · p* + 1) = 0   [винесення спільного множника p*]
= p* · (2 · p* - 1) · (p* - 1) = 0   [розклад квадратного тричлена]
```

Отримуємо три нерухомі точки:
1. `p* = 0` — стійка тривіальна нерухома точка порожньої ґратки.
2. `p* = 1` — стійка тривіальна нерухома точка повністю заповненої ґратки.
3. `p* = 1 / 2 = 0.5` — **нестійка критична нерухома точка**, яка точно відповідає критичному порогу `p_c` вузлової перколації на трикутній ґратці.

Критичний індекс радіуса кореляції `ν` обчислюється через похідну ренормалізаційного перетворення в критичній точці `λ = dR/dp |_{p*}`:

```
λ = 6 · p* - 6 · (p*)²
= 6 · (1/2) - 6 · (1/4)      [підстановка p* = 1/2]
= 3 - 3/2 = 3/2 = 1.5        [обчислення власного значення РГ]
```

Оскільки радіус кореляції масштабується як `ξ' = ξ / b`, звідки `λ = b¹/ᵛ`, отримуємо оцінку критичного індексу:

```
ν = ln(b) / ln(λ)
= ln(√3) / ln(1.5)           [підстановка b = √3 та λ = 1.5]
≈ 0.549306 / 0.405465
≈ 1.3547                     [РГ-оцінка індексу кореляції]
```

Це наближення методом найпростішого блокування дає дивовижно точний збіг із точним конформним значенням `ν = 4 / 3 ≈ 1.3333` (похибка становить менше 1.6%).

## Фрактальна геометрія меж: конформні ансамблі петель та SLE(6)

У критичній точці `p = p_c` межі перколяційних кластерів не є гладкими кривими. Вони утворюють складні несамоперетинні фрактальні контури, які описуються **стохастичною еволюцією Шрамма — Левнера** з параметром дифузії `κ = 6` (`SLE(6)`).

Теорія виділяє дві ключові розмірності межі кластера:
1. **Повна межа (Hull)**: включає всі зовнішні та внутрішні контури кластера з урахуванням глибоких фьордів і петель. Її фрактальна розмірність дорівнює:

```
D_hull = 1 + κ / 8
= 1 + 6 / 8 = 7 / 4 = 1.75   [точна розмірність оболонки за SLE(6)]
```

2. **Зовнішній доступний периметр (External accessible perimeter)**: лінія контакту кластера з навколишнім простором, до якої можна доторкнутися ззовні, не заходячи у вузькі фьорди (проходи шириною в один крок ґратки). Її розмірність описується дуальним процесом `SLE(8/3)`:

```
D_ext = 1 + 8 / (8 · κ) = 1 + 1/3 = 4 / 3 ≈ 1.3333
```

Це доводить, що фрактальна розмірність зовнішньої межі перколяційного кластера строго збігається з розмірністю траєкторії самовибіркового випадкового блукання (*Self-Avoiding Walk, SAW*).

## Скінченновимірний скейлінг та кумулянти Біндера

У чисельному моделюванні ґратка завжди має скінченний лінійний розмір `L`, через що ідеальний сингулярний фазовий перехід розмивається у гладкий кросовер. Для екстраполяції результатів до нескінченної термодинамічної межі `L → ∞` застосовують теорію скінченновимірного скейлінгу (*Finite-Size Scaling, FSS*).

Згідно з FSS-гіпотезою Фішера, довільна фізична величина `X(p, L)`, яка в нескінченній системі розбігається як `|p - p_c|⁻ˣ`, на скінченній ґратці масштабується за універсальним законом:

```
X(p, L) = Lˣ/ᵛ · f_X((p - p_c) · L¹/ᵛ)
```

де `f_X(x)` — універсальна безрозмірна скейлінгова функція відношення лінійного розміру системи до радіуса кореляції `L / ξ ∝ (p - p_c) · L¹/ᵛ`.

Зокрема, для потужності найбільшого кластера `P_∞(p, L)` та сприйнятливості `χ(p, L)`:

```
P_∞(p, L) = L⁻ᵝ/ᵛ · f_P((p - p_c) · L¹/ᵛ)
```

```
χ(p, L) = Lᵞ/ᵛ · f_χ((p - p_c) · L¹/ᵛ)
```

Для високоточного знаходження критичного порогу `p_c` без попереднього знання критичних індексів використовують четвертий кумулянт Біндера (*Binder cumulant*) розподілу розмірів кластерів:

```
U₄(p, L) = 1 - (⟨s⁴⟩ / (3 · ⟨s²⟩²))
```

Оскільки в критичній точці аргумент універсальної функції `(p - p_c) · L¹/ᵛ = 0`, значення кумулянта Біндера `U₄(p_c, L)` стає абсолютно незалежним від розміру `L`. Графіки залежності `U₄(p, L)` для різних розмірів ґраток `L₁, L₂, L₃` перетинаються в одній єдиній інваріантній точці, яка точно визначає `p_c`.

## Біноміальна згортка: від мікроканонічного до канонічного ансамблю

У чисельному моделюванні розрізняють два статистичні ансамблі:
- **Мікроканонічний ансамбль**: фіксована точна кількість відкритих вузлів `n` у ґратці з загальною кількістю `N` вузлів.
- **Канонічний ансамбль**: кожен вузол відкривається незалежно з неперервною ймовірністю `p`.

Нехай `A_n` — деяка фізична величина (наприклад, розмір найбільшого кластера або прапорець наявності наскрізного протікання), виміряна на конфігурації з рівно `n` відкритими сайтами. Кількість способів обрати `n` відкритих вузлів серед `N` можливих дорівнює біноміальному коефіцієнту `C(N, n)`.

Ймовірність того, що в канонічному ансамблі з параметром `p` відкриється рівно `n` вузлів, задається біноміальним розподілом:

```
