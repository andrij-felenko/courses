# 🧮 Математичне доведення алгоритму Кадане та властивості оптимуму

Задача про максимальний підмасив (Maximum Subarray Problem) формулюється так: для заданого одновимірного масиву дійсних чисел `A = [a₀, a₁, ..., a_{n-1}]` знайти неперервний діапазон індексів `[i .. j]`, де `0 ≤ i ≤ j < n`, що максимізує суму:

```
S(i, j) = ∑_{k=i}^{j} a_k
```

Нижче наведено формальне математичне доведення коректності алгоритму Кадане методом математичної індукції, обґрунтування інваріантів динамічного програмування, еквівалентність формулюванню через біжучі префіксні суми, аналіз задачі про максимальний добуток, доведення нижньої межі складності, строгі доведення редукцій для кільцевих масивів та двовимірних матриць, алгебраїчну формалізацію через тропічні напівкільця, а також доведення потокової онлайнової оптимальності.

---

## 1. Формальне розбиття простору пошуку та локальний оптимум

Простір усіх можливих неперервних підмасивів масиву довжини `n` має комбінаторну потужність `n(n + 1) / 2`. Позначимо цю повну множину як `Ω`.

Розіб'ємо множину `Ω` на `n` підмножин `Ω₀, Ω₁, ..., Ω_{n-1}` за ознакою правого кінцевого індексу підмасиву:

```
Ω_j = { A[i .. j] | 0 ≤ i ≤ j }      [підмасиви, що закінчуються рівно в індексі j]
```

Перевіримо фундаментальні топологічні властивості цього розбиття:
1. **Неперетинність:** Якщо `j₁ ≠ j₂`, то класи `Ω_{j₁}` та `Ω_{j₂}` не мають жодного спільного елемента, оскільки жоден підмасив не може одночасно мати два різні праві кінці:

```
Ω_{j₁} ∩ Ω_{j₂} = ∅      [для будь-яких j₁ ≠ j₂]
```

2. **Повнота покриття:** Будь-який підмасив `A[i .. j]` має правий кінець `j ∈ {0, ..., n-1}`, отже обов'язково належить рівно одному класу `Ω_j`:

```
Ω = ⋃_{j=0}^{n-1} Ω_j      [об'єднання неперетинних класів еквівалентності]
```

Визначимо функцію локального максимуму `M(j)` як найбільшу суму серед усіх підмасивів, що належать класу `Ω_j`:

```
M(j) = max_{0 ≤ i ≤ j} S(i, j)      [локальний максимум для позиції j]
```

Оскільки оператор взяття максимуму є дистрибутивним відносно операції диз'юнктного об'єднання скінченних множин, глобальний оптимум `OPT` однозначно виражається через максимум від локальних оптимумів:

```
OPT
= max_{A[i..j] ∈ Ω} S(i, j)                 [означення глобального максимуму]
= max_{0 ≤ j < n} ( max_{0 ≤ i ≤ j} S(i, j) ) [розбиття множини Ω на підмножини Ω_j]
= max_{0 ≤ j < n} M(j)                        [підстановка локального максимуму M(j)]
```

Таким чином, комбінаторна задача перебору квадратичної кількості відрізків зводиться до послідовного обчислення значень `M(0), M(1), ..., M(n-1)`.

## 2. Рекурентне співвідношення та оптимальна підструктура

### Теорема 1 (Рекурентність Кадане)
Для будь-якого індексу `j ≥ 1` значення локального максимуму `M(j)` задовольняє алгебраїчне рівняння:

```
M(j) = max(a_j, M(j - 1) + a_j)
```

### Доведення теореми 1
Розглянемо довільний підмасив `A[i .. j] ∈ Ω_j`. Його сума розкладається на два компоненти: суму префікса та останній елемент:

```
S(i, j)
= ∑_{k=i}^{j} a_k                  [означення суми підмасиву]
= ( ∑_{k=i}^{j-1} a_k ) + a_j       [виділення останнього доданка]
= S(i, j - 1) + a_j                [підстановка суми префікса]
```

Множина `Ω_j` розпадається на два взаємовиключні випадки:
- Випадок `i = j`: підмасив складається лише з одного елемента `A[j .. j]`, і його сума дорівнює `S(j, j) = a_j`.
- Випадок `0 ≤ i ≤ j - 1`: підмасив утворюється дописуванням елемента `a_j` до деякого підмасиву `A[i .. j - 1] ∈ Ω_{j-1}`.

Застосуємо оператор максимізації до множини `Ω_j`:

```
M(j)
= max_{0 ≤ i ≤ j} S(i, j)                                         [означення M(j)]
= max( S(j, j), max_{0 ≤ i ≤ j-1} S(i, j) )                       [відокремлення випадку i = j]
= max( a_j, max_{0 ≤ i ≤ j-1} (S(i, j - 1) + a_j) )               [підстановка алгебраїчного розкладу]
= max( a_j, ( max_{0 ≤ i ≤ j-1} S(i, j - 1) ) + a_j )             [дистрибутивність додавання відносно max]
= max( a_j, M(j - 1) + a_j )                                      [підстановка означення M(j-1)]
```

Теорему доведено.

### Алгебраїчний висновок про поріг скидання стану
Винесемо доданок `a_j` за дужки:

```
M(j) = a_j + max(0, M(j - 1))
```

З цього випливає прямий критерій поведінки оптимального розв'язку:
- Якщо `M(j - 1) > 0`, значення `max(0, M(j - 1)) = M(j - 1)`, отже, попередній накопичений підмасив збільшує суму поточного елемента `a_j`. Оптимально продовжити підмасив.
- Якщо `M(j - 1) ≤ 0`, значення `max(0, M(j - 1)) = 0`, отже, попередній підмасив є шкідливим баластом, який зменшує значення `a_j`. Оптимально скинути стан і почати новий підмасив з індексу `j`.

## 3. Доведення коректності за індукцією

Доведемо, що алгоритм Кадане коректно обчислює глобальний максимум `OPT` для масиву будь-якої скінченної довжини `n ≥ 1`.

### Індукційне твердження P(k)
Для кожного кроку `k ∈ {0, 1, ..., n-1}` алгоритм гарантує точне виконання двох інваріантів стану:
1. Змінна `current_sum` дорівнює `M(k)` — максимуму підмасивів, що завершуються в індексі `k`.
2. Змінна `best_so_far` дорівнює `max_{0 ≤ j ≤ k} M(j)` — глобальному оптимуму на префіксі `A[0 .. k]`.

### База індукції (k = 0)
Для `k = 0` існує лише один підмасив `A[0 .. 0] = [a₀]`.
- Множина `Ω₀ = { A[0 .. 0] }`, тому `M(0) = S(0, 0) = a₀`.
- Алгоритм ініціалізує змінні значеннями `current_sum = a₀` та `best_so_far = a₀`.
- Оскільки `max_{0 ≤ j ≤ 0} M(j) = M(0) = a₀`, твердження `P(0)` є істинним.

### Індукційний перехід (P(k) ⇒ P(k + 1))
Припустимо, що індукційне твердження `P(k)` виконується для деякого `k < n - 1`:

```
current_sum = M(k)
best_so_far = max_{0 ≤ j ≤ k} M(j)
```

На кроці `k + 1` алгоритм зчитує елемент `a_{k+1}` і виконує обчислення:

```
current_sum' = max(a_{k+1}, current_sum + a_{k+1})
best_so_far' = max(best_so_far, current_sum')
```

Підставимо індукційну гіпотезу у вираз для `current_sum'`:

```
current_sum'
= max(a_{k+1}, M(k) + a_{k+1})      [підстановка гіпотези current_sum = M(k)]
= M(k + 1)                          [за Теоремою 1]
```

Тепер обчислимо нове значення `best_so_far'`:

```
best_so_far'
= max(best_so_far, current_sum')                   [правило оновлення в алгоритмі]
= max( max_{0 ≤ j ≤ k} M(j), M(k + 1) )             [підстановка гіпотези для best_so_far та значення current_sum']
= max_{0 ≤ j ≤ k+1} M(j)                            [асоціативність оператора взяття максимуму]
```

Обидва інваріанти збережено для індексу `k + 1`. Отже, твердження `P(k + 1)` є істинним.

За принципом математичної індукції твердження `P(k)` виконується для всіх `k ∈ {0, 1, ..., n-1}`. На фінальному кроці `k = n - 1` змінна `best_so_far` містить значення:

```
best_so_far = max_{0 ≤ j < n} M(j) = OPT
```

Коректність алгоритму доведено повністю.

## 4. Еквівалентність через масив префіксних сум

Існує прямий алгебраїчний зв'язок між рекурентністю Кадане та геометрією префіксних сум.

Нехай `P` — масив префіксних сум довжини `n + 1`, де:

```
P[0] = 0
P[k] = ∑_{m=0}^{k-1} a_m      [для 1 ≤ k ≤ n]
```

Сума будь-якого підмасиву `A[i .. j]` строго дорівнює різниці двох значень префіксів:

```
S(i, j) = P[j + 1] - P[i]
```

Зафіксуємо правий кінець `j`. Тоді локальний максимум `M(j)` набуває вигляду:

```
M(j)
= max_{0 ≤ i ≤ j} ( P[j + 1] - P[i] )               [підстановка формули префіксних сум]
= P[j + 1] - min_{0 ≤ i ≤ j} P[i]                   [винесення константи P[j+1] за межі оператора max]
```

Позначимо `min_prefix(j) = min_{0 ≤ i ≤ j} P[i]`. Ця величина задовольняє очевидну покрокову рекурентність:

```
min_prefix(j) = min(min_prefix(j - 1), P[j])
```

Звідси випливає геометрична інтерпретація алгоритму Кадане: максимальний підмасив, що закінчується в точці `j`, утворюється відніманням від поточної точки графіка префіксних сум `P[j+1]` найглибшої западини (абсолютного мінімуму) `min_prefix(j)`, яка зустрічалася на графіку до цієї позиції.

Алгоритм Кадане неявно відстежує цю мінімальну точку за `O(1)` простору без збереження всього масиву `P`.

## 5. Доведення для відстеження індексів меж (Start / End Invariant)

Для знаходження самих координат `[best_start .. best_end]` алгоритм підтримує змінну `current_start`, яка вказує на ліву межу поточного накопиченого відрізка.

### Теорема 2 (Інваріант меж)
Якщо на кроці `j` виконується умова `M(j - 1) ≤ 0`, то початок оптимального підмасиву для класу `Ω_j` встановлюється в `current_start = j`. Якщо ж `M(j - 1) > 0`, початок зберігається без змін: `current_start = current_start_{попередній}`.

### Доведення теореми 2
1. Якщо `M(j - 1) ≤ 0`, згідно з Теоремою 1 єдиним оптимальним вибором у класі `Ω_j` є одиночний елемент `A[j .. j]`. Його ліва межа строго дорівнює `i = j`. Тому встановлення `current_start = j` є необхідним і достатнім.
2. Якщо `M(j - 1) > 0`, оптимальний підмасив класу `Ω_j` отримується приєднанням елемента `a_j` до оптимального підмасиву класу `Ω_{j-1}`. Отже, ліва межа підмасиву `Ω_j` точно збігається з лівою межею оптимального підмасиву для `Ω_{j-1}`.

Оновлення глобальних меж `best_start = current_start` та `best_end = j` виконується щоразу, коли `current_sum > best_so_far`, що гарантує збереження координат першого виявленого глобального максимуму.

## 6. Доведення для циклічного підмасиву (Maximum Circular Subarray)

У кільцевому масиві довжини `n` підмасиви можуть переходити через умовну межу від індексу `n - 1` до `0`.

### Теорема 3 (Теорема про доповнення)
Для будь-якого циклічного підмасиву `W = A[0 .. k] ∪ A[m .. n-1]` (де `0 ≤ k < m < n`), сума його елементів строго пов'язана з сумою внутрішнього лінійного підмасиву `C = A[k + 1 .. m - 1]` співвідношенням:

```
Sum(W) = TotalSum - Sum(C)
```

де `TotalSum = ∑_{i=0}^{n-1} a_i`.

### Доведення теореми 3
Множина індексів кругового масиву `I = {0, 1, ..., n-1}` є диз'юнктним об'єднанням множин індексів підмасиву `W` та його доповнення `C`:

```
I = W ∪ C,   причому   W ∩ C = ∅
```

За адитивністю суми на скінченних множинах:

```
TotalSum = ∑_{i ∈ I} a_i = ∑_{i ∈ W} a_i + ∑_{i ∈ C} a_i = Sum(W) + Sum(C)
```

Віднявши `Sum(C)` від обох частин, отримуємо шукану рівність:

```
Sum(W) = TotalSum - Sum(C)
```

Оскільки `TotalSum` є константою для заданого масиву, задача знаходження максимуму `Sum(W)` еквівалентна знаходженню мінімуму `Sum(C)`:

```
max_{W} Sum(W)
= max_{C} ( TotalSum - Sum(C) )               [підстановка тотожності]
= TotalSum - min_{C} Sum(C)                   [властивість max(K - f(x)) = K - min(f(x))]
= TotalSum - MinSubarraySum(A)                [редукція до лінійного пошуку мінімуму]
```

### Аналіз граничного випадку суто від'ємного масиву
Якщо всі елементи `a_i < 0`:
- Максимальний непорожній підмасив `MaxSubarraySum(A)` дорівнює найбільшому (найменш від'ємному) числу масиву: `max_{i} a_i < 0`.
- Мінімальний підмасив `MinSubarraySum(A)` обирає всі елементи масиву повністю, тому `MinSubarraySum(A) = TotalSum`.
- Різниця `TotalSum - MinSubarraySum(A) = TotalSum - TotalSum = 0`.

Число `0` відповідає порожній множині елементів `W = ∅`. Проте за умовою непорожності порожній підмасив заборонено. Тому для суто від'ємного масиву циклічний максимум не розглядається, а відповіддю залишається `MaxSubarraySum(A)`.

Підсумкова формула:

```
OPT_circ = max(MaxSubarraySum(A), TotalSum - MinSubarraySum(A))     [якщо MaxSubarraySum(A) > 0]
OPT_circ = MaxSubarraySum(A)                                         [якщо MaxSubarraySum(A) ≤ 0]
```

## 7. Двовимірна редукція матриці (2D Maximum Subarray)

Для матриці `A` розміром `R × C` шукається прямокутна підматриця з координатами рядків `[r₁ .. r₂]` та стовпців `[c₁ .. c₂]`, що максимізує подвійну суму:

```
S(r₁, r₂, c₁, c₂) = ∑_{r=r₁}^{r₂} ∑_{c=c₁}^{c₂} A[r][c]
```

Загальна кількість можливих підматриць дорівнює:

```
N_submatrices = ( R(R + 1) / 2 ) · ( C(C + 1) / 2 ) = O(R² · C²)
```

Зафіксуємо довільну пару рядків `(r₁, r₂)`, де `0 ≤ r₁ ≤ r₂ < R`.
Визначимо одновимірний масив стиснених сум стовпців `V` довжини `C`:

```
V[c] = ∑_{r=r₁}^{r₂} A[r][c]
```

Тоді подвійна сума підматриці перетворюється на суму одновимірного підмасиву вектора `V`:

```
S(r₁, r₂, c₁, c₂)
= ∑_{c=c₁}^{c₂} ( ∑_{r=r₁}^{r₂} A[r][c] )      [перестановка порядку підсумовування]
= ∑_{c=c₁}^{c₂} V[c]                           [підстановка визначення V[c]]
```

Максимізація за індексами `c₁, c₂` для фіксованої пари `(r₁, r₂)` є стандартною одновимірною задачею Кадане над вектором `V`, що виконується за час `O(C)`.

При переході від рядка `r₂ - 1` до `r₂` вектор `V` оновлюється за формулою:

```
V_{r₂}[c] = V_{r₂ - 1}[c] + A[r₂][c]      [поелементне додавання за O(C)]
```

Загальна часова складність двовимірного алгоритму становить:

```
T(R, C) = ∑_{r₁=0}^{R-1} ∑_{r₂=r₁}^{R-1} O(C) = ( R(R + 1) / 2 ) · O(C) = O(R² · C)
```

Якщо `R > C`, матрицю можна транспонувати, отримавши складність `O(min(R, C)² · max(R, C))` та пам'ять `O(max(R, C))`.

## 8. Задача про максимальний добуток (Maximum Product Subarray)

У задачі про максимальний добуток шукається підмасив `A[i .. j]`, що максимізує:

```
P(i, j) = ∏_{k=i}^{j} a_k
```

На відміну від додавання, операція множення не є монотонною на множині дійсних чисел через зміну знаків: множення двох великих за модулем від'ємних чисел дає велике додатне число.

### Теорема 4 (Подвійний інваріант добутку)
Для кожного кроку `j ≥ 1` локальний максимум добутку `MaxP(j)` та локальний мінімум добутку `MinP(j)` для підмасивів, що завершуються в `j`, задовольняють систему:

```
MaxP(j) = max( a_j, max( MaxP(j - 1) · a_j, MinP(j - 1) · a_j ) )
MinP(j) = min( a_j, min( MaxP(j - 1) · a_j, MinP(j - 1) · a_j ) )
```

### Доведення теореми 4
Розглянемо знак поточного множника `a_j`:
1. Якщо `a_j > 0`:
   - Множення на додатне число зберігає порядок нерівностей: якщо `x ≤ y`, то `x · a_j ≤ y · a_j`.
   - Тому `MaxP(j) = max(a_j, MaxP(j - 1) · a_j)`, а `MinP(j) = min(a_j, MinP(j - 1) · a_j)`.
2. Якщо `a_j < 0`:
   - Множення на від'ємне число інвертує порядок нерівностей: якщо `x ≤ y`, то `x · a_j ≥ y · a_j`.
   - Найбільше додатне значення виникає при множенні найбільш від'ємного попереднього результату `MinP(j - 1)` на `a_j`.
   - Тому `MaxP(j) = max(a_j, MinP(j - 1) · a_j)`, а `MinP(j) = min(a_j, MaxP(j - 1) · a_j)`.
3. Якщо `a_j = 0`:
   - Будь-який добуток, що містить `a_j`, перетворюється на `0`.
   - `MaxP(j) = 0`, `MinP(j) = 0`, що автоматично скидає накопичення для наступних кроків.

Об'єднуючи всі три випадки через оператори `max` та `min` над трійкою значень `{ a_j, MaxP(j - 1) · a_j, MinP(j - 1) · a_j }`, отримуємо інваріант, що охоплює довільні комбінації знаків за час `O(n)` та пам'ять `O(1)`.

## 9. Алгебраїчна інтерпретація: тропічне напівкільце та моноід Кадане

Алгоритм Кадане має глибоку алгебраїчну структуру, яку можна сформулювати двома взаємодоповнювальними способами.

### Формулювання у тропічному напівкільці (Tropical Semiring)
Розглянемо тропічне напівкільце (макс-плюс алгебру) `(ℝ ∪ {-∞}, ⊕, ⊗)`, де операції додавання та множення перевизначено як:

```
x ⊕ y = max(x, y)      [тропічне додавання]
x ⊗ y = x + y          [тропічне множення]
```

Нейтральним елементом відносно додавання `⊕` є `-∞`, а нейтральним елементом відносно множення `⊗` є `0`.

У цій алгебрі крок алгоритму Кадане набуває форми класичного лінійного динамічного перетворення над вектором станів `v_j = [ M(j), 0 ]ᵀ`:

```
v_j = [ M(j-1) ⊗ a_j ⊕ a_j, 0 ]ᵀ = [ max(M(j-1) + a_j, a_j), 0 ]ᵀ
```

Це показує, що пошук максимального підмасиву еквівалентний знаходженню найдовшого шляху в ациклічному орієнтованому графі (DAG) станів із вагами ребер `a_j`.

### Асоціативний моноід станів для паралельних обчислень
Для обробки масиву на багатьох процесорах або побудови динамічного відрізкового дерева (Segment Tree) кожен неперервний блок масиву описується кортежем із чотирьох параметрів:

```
Node = ( TotalSum, MaxPrefix, MaxSuffix, MaxSubarray )
```

де:
- `TotalSum` — алгебраїчна сума всіх елементів блоку;
- `MaxPrefix` — максимальна сума непорожнього префікса;
- `MaxSuffix` — максимальна сума непорожнього суфікса;
- `MaxSubarray` — максимальна сума довільного підмасиву всередині блоку.

### Операція злиття (Merge) двох суміжних блоків L та R
Нехай блок `L` розташований безпосередньо ліворуч від блоку `R`. Стан об'єднаного блоку `Node(L ∪ R)` обчислюється за правилами:

```
TotalSum(L ∪ R)    = TotalSum(L) + TotalSum(R)
MaxPrefix(L ∪ R)   = max( MaxPrefix(L), TotalSum(L) + MaxPrefix(R) )
MaxSuffix(L ∪ R)   = max( MaxSuffix(R), TotalSum(R) + MaxSuffix(L) )
MaxSubarray(L ∪ R) = max( MaxSubarray(L), max( MaxSubarray(R), MaxSuffix(L) + MaxPrefix(R) ) )
```

### Теорема 5 (Асоціативність моноіда Кадане)
Операція `Merge(L, R)` є строго асоціативною:

```
Merge( Merge(A, B), C ) = Merge( A, Merge(B, C) )
```

### Доведення теореми 5
Перевіримо асоціативність для кожної компоненти кортежу:
1. Для `TotalSum`: звичайна асоціативність додавання дійсних чисел `(a + b) + c = a + (b + c)`.
2. Для `MaxPrefix`:
   `MaxPrefix((A ∪ B) ∪ C) = max( MaxPrefix(A ∪ B), TotalSum(A ∪ B) + MaxPrefix(C) ) = max( MaxPrefix(A), TotalSum(A) + MaxPrefix(B), TotalSum(A) + TotalSum(B) + MaxPrefix(C) )`.
   Розкриття виразу `MaxPrefix(A ∪ (B ∪ C))` дає тотожний вираз.
3. Для `MaxSuffix`: доводиться симетрично до `MaxPrefix`.
4. Для `MaxSubarray`: будь-який неперервний підмасив у блоці `(A ∪ B ∪ C)` або повністю лежить в одному з блоків `A, B, C`, або перетинає спільну межу між `A` і `B`, або межу між `B` і `C`, або охоплює блок `B` повністю разом із суфіксом `A` та префіксом `C`. Обидва порядки застосування операції `Merge` перебирають одну й ту саму множину з 6 можливих варіантів максимуму.

Оскільки операція `Merge` є асоціативною, множина станів утворює напівгрупу (а з додаванням нейтрального елемента — **моноід**). За теоремою Блеллоха про паралельний префіксний скан (Blelloch parallel scan), масив довжини `n` може бути оброблений на `p` паралельних процесорних ядрах за полілогарифмічний час:

```
T_parallel(n, p) = O(n / p + log p)
```

## 10. Властивості онлайнової потокової обробки (Streaming Model)

У сучасних системах обробки великих даних послідовність чисел надходить як нескінченний потік елементів `a₀, a₁, a₂, ...`, де довжина потоку заздалегідь невідома, а доступна оперативна пам'ять жорстко обмежена константою `O(1)`.

### Теорема 6 (Потокова оптимальність)
Алгоритм Кадане є строго онлайновим потоковим алгоритмом (online streaming algorithm): для будь-якого моменту часу `t ≥ 0` поточний стан `(current_sum_t, best_so_far_t)` повністю визначається лише попереднім станом `(current_sum_{t-1}, best_so_far_{t-1})` та новим елементом `a_t`, не вимагаючи збереження історії та доступу до майбутніх елементів (lookahead = 0).

### Доведення теореми 6
Твердження випливає безпосередньо з марковської властивості переходу станів у рекурентності:

```
current_sum_t = max(a_t, current_sum_{t-1} + a_t)
best_so_far_t = max(best_so_far_{t-1}, current_sum_t)
```

Обидві формули залежать виключно від інформації на кроці `t - 1` та значення `a_t`. Проміжний стан займає рівно 2 числові комірки пам'яті (16 байтів для 64-бітних дійсних чисел `double`), що задовольняє найсуворіші вимоги потокової моделі.

## 11. Доведення теоретичної нижньої межі складності Ω(n)

### Теорема 7 (Нижня межа)
Будь-який детермінований або ймовірнісний алгоритм, що знаходить максимальний підмасив у довільному масиві довжини `n`, вимагає щонайменше `n` операцій читання елементів у найгіршому випадку:

```
T(n) = Ω(n)
```

### Доведення теореми 7 (метод оракула-противника / Adversary Argument)
Припустимо супротивне: існує алгоритм `ALG`, який завжди коректно розв'язує задачу, прочитавши строго менше ніж `n` елементів. Тобто існує хоча б один індекс `p ∈ {0, ..., n-1}`, значення `a_p` якого алгоритм `ALG` не зчитував.

Розглянемо два вхідні масиви:
- **Масив 1:** `A₁ = [-1, -1, ..., -1]` (усі елементи дорівнюють `-1`). Алгоритм не читає елемент на позиції `p` і повертає відповідь `-1` (одиночний елемент).
- **Масив 2:** Сконструюємо масив `A₂`, який повністю ідентичний до `A₁` на всіх позиціях `k ≠ p`, але на прихованій позиції `p` містить значення `a_p = +100`.

Оскільки алгоритм `ALG` не звертається до позиції `p`, його покрокова поведінка та послідовність внутрішніх станів для масивів `A₁` та `A₂` будуть абсолютно однаковими. Тому на масиві `A₂` алгоритм `ALG` видасть той самий результат `-1`.

Проте точний глобальний максимум для масиву `A₂` дорівнює `+100` (підмасив `A₂[p .. p]`). Отримано суперечність із припущенням про коректність алгоритму `ALG`.

Отже, алгоритм зобов'язаний зчитати кожен із `n` елементів масиву принаймні один раз. Нижня межа складності дорівнює `Ω(n)`.

Оскільки послідовний алгоритм Кадане досягає часової оцінки `O(n)`, він є **асимптотично оптимальним алгоритмом** (asymptotically optimal algorithm) у своєму класі задач.
