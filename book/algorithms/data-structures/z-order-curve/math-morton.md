# 🧮 Математичні властивості Z-порядку

Вставка розкриває математичну формулізацію відображення двовимірного та тривимірного простору в одновимірний, властивості бієкції побітового переплетення, оцінку локальності (Dilation Bound) та математичний вивід алгоритму обчислення меж BIGMIN і LITMAX.

## 1. Формальне означення бієкції переплетення бітів

Нехай задано d-вимірний дискретний простір, де кожна координата є цілим неот'ємним числом з k бітів: x, y ∈ {0, 1, ..., 2ᵏ − 1}.

Двійковий розклад координат має вигляд:

```
x = ∑ (x[i] · 2ⁱ)    для i від 0 до k−1,  x[i] ∈ {0, 1}
y = ∑ (y[i] · 2ⁱ)    для i від 0 до k−1,  y[i] ∈ {0, 1}
```

Відображення Morton f: {0, ..., 2ᵏ − 1}² → {0, ..., 2²ᵏ − 1} визначається як формальне переплетення бітів розрядів:

```
z = f(x, y) = ∑ (x[i] · 2²ⁱ + y[i] · 2²ⁱ⁺¹)   для i від 0 до k−1
```

Для 3D простору з трьома координатами (x, y, z) кожна координата розгортається на три позиції:

```
key = f(x, y, z) = ∑ (x[i] · 2³ⁱ + y[i] · 2³ⁱ⁺¹ + z[i] · 2³ⁱ⁺²)
```

### Строгий доказ бієктивності

Щоб довести, що відображення f є бієкцією (взаємно однозначним відображенням), необхідно перевірити дві властивості: ін'єктивність (різним координатам відповідають різні Morton-коди) та сюр'єктивність (кожен можливий код має свою точку).

1. **Доказ ін'єктивності:**
   Розглянемо дві двовимірні точки A = (x_A, y_A) та B = (x_B, y_B). Якщо A ≠ B, то існує хоча б один бітовий індекс i, у якому x_A[i] ≠ x_B[i] або y_A[i] ≠ y_B[i].
   У результуючому Morton-коді z = f(x, y) біт x[i] розташований у розряді 2i, а біт y[i] — у розряді 2i + 1. Оскільки всі розряди 2i та 2i + 1 є строго унікальними та не перетинаються між собою для будь-яких i ∈ {0, ..., k−1}, зміна будь-якого біта координат змінює відповідний унікальний розряд у числа z.
   Отже, якщо A ≠ B, то f(A) ≠ f(B). Відображення є **ін'єктивним**.

2. **Доказ сюр'єктивності:**
   Розглянемо довільне ціле число z ∈ {0, ..., 2²ᵏ − 1}. Будь-яке таке число має унікальний 2k-бітний двійковий розклад:
   `z = ∑ (z[j] · 2ʲ)` для j від 0 до 2k−1.

   Визначимо координати x та y за наступними правилами відбору бітів:

```
x[i] = z[2i]        [парні біти числа z стають бітами x]
y[i] = z[2i + 1]    [непарні біти числа z стають бітами y]
```

```
x[i] = (z ≫ 2i) AND 1          [витягуємо парний біт розряду 2i]
y[i] = (z ≫ (2i + 1)) AND 1    [витягуємо непарний біт розряду 2i+1]
```

   Для будь-якого z числа x та y належать множині {0, ..., 2ᵏ − 1}, і за означенням f(x, y) = z. Отже, відображення є **сюр'єктивним**.

3. Оскільки потужності області визначення (|S| = 2ᵏ · 2ᵏ = 2²ᵏ) та області значень (|Z| = 2²ᵏ) збігаються, ін'єктивне та сюр'єктивне відображення скінченних множин є **бієкцією**.

## 2. Локальність та коефіцієнт розтягу (Dilation Bound)

Крива Z-порядку зберігає просторову локальність *здебільшого*, але на межах квадрантів виникають математичні розриви.

Розглянемо відстань між двома точками A = (x_A, y_A) та B = (x_B, y_B) на площині в евклідовій метриці d_E(A, B) = √((x_A − x_B)² + (y_A − y_B)²) порівняно з кодовою відстанню вздовж кривої d_Z(A, B) = |f(A) − f(B)|.

### Найгірший випадок розриву (Discontinuity)

Розглянемо дві точки, розташовані на межі центрального квадранта сітки розміром 2ᵏ × 2ᵏ:

```
A = (2ᵏ⁻¹ − 1,  2ᵏ⁻¹ − 1)   [підквадрант 0, крайня точка]
B = (2ᵏ⁻¹,      2ᵏ⁻¹ − 1)   [підквадрант 1, сусідня точка]
```

Евклідова відстань між точками A і B дорівнює 1 одиниці:

```
d_E(A, B) = √((2ᵏ⁻¹ − (2ᵏ⁻¹ − 1))² + 0) = √1 = 1
```

Обчислимо ключі Мортона f(A) та f(B):

```
f(A) = 001111...11₂ = 2²ᵏ⁻² − 1    [усі біти розрядів від 0 до k-2 є одиницями]
f(B) = 010000...00₂ = 2²ᵏ⁻²        [старший біт розряду k-1 дорівнює одиниці]
```

Відстань вздовж Z-кривої між сусідніми точками A і B:

```
d_Z(A, B) = f(B) − f(A) = 2²ᵏ⁻² − (2²ᵏ⁻² − 1) = 1
```

Однак для точки C = (2ᵏ⁻¹ − 1, 2ᵏ⁻¹) [підквадрант 2]:

```
f(C) = 100000...00₂ = 2²ᵏ⁻¹        [біти розрядів y утворюють значення 2²ᵏ⁻¹]
```

Різниця `d_Z(A, C) = 2²ᵏ⁻¹ − (2²ᵏ⁻² − 1) = 2²ᵏ⁻² + 1`.

Математично доведено (Gätzschmann, 2008), що **найбільше відношення відстаней** (Bounding Dilation) для 2D Z-кривої становить:

```
max (d_Z(A, B) / (d_E(A, B))²) = O(2ᵏ)
```

Це означає, що відношення відстані вздовж кривої до фізичної відстані може зростати лінійно від розміру сітки, що пояснює наявність скачків на фрактальних межах.

## 3. Математичне виведення алгоритму BIGMIN / LITMAX

Під час виконання прямокутного запиту Q = [x_min, x_max] × [y_min, y_max] ми шукаємо ключі z ∈ [z_min, z_max], які належать Q.

Якщо поточний Morton-код z_curr випадає з прямокутника Q (z_curr ∉ Q), він ділить простір ключа на дві категорії:
1. Чужі ключі, більші за z_curr, які також не можуть входити у Q до певної межі.
2. Перший код, більший за z_curr, який **гарантовано входить** у прямокутник Q — цей код називається **BIGMIN**.

### Математичний алгоритм знаходження BIGMIN

Нехай z_curr ∉ Q. Знаходимо найстарший біт (Most Significant Bit, MSB) в якому z_curr виходить за межі прямокутника Q.

Розглянемо побітовий аналіз вектора координат:

```
1. Декодуємо z_curr -> (x_c, y_c).
2. Обчислюємо побітові маски розбіжностей:
   - if x_c < x_min: біти x мають бути збільшені
   - if y_c < y_min: біти y мають бути збільшені
3. Знаходимо найстарший позиційний розряд p:
   p = max_bit_index( (x_c ^ x_min) | (y_c ^ y_min) )

4. Будуємо нове значення BIGMIN:
   - Усі розряди вище p залишаємо незмінними.
   - Розряд p встановлюємо в 1.
   - Усі розряди нижче p заповнюємо мінімально можливими бітами з Q.
```

Формальне виведення оператора маскування для розрядної межі:

```
mask_p = 1 ≪ p                    [маска найстаршого біта розбіжності]
prefix = z_curr AND ~(mask_p - 1) [збереження вищого префіксу]
BIGMIN = prefix | mask_p | z_min_suffix
```

Ця операція виконується за логарифмічний час O(k) від кількості бітів або за O(1) за допомогою бітових інструкцій `CLZ` (Count Leading Zeros), що дозволяє обходити тисячі чужих елементів за одну інструкцію процесора.

## 4. Порівняння просторової локальності: Z-Order vs Hilbert Curve

Для оцінки якості геометричної локальності в теорії просторових індексів використовують поняття **L2-розтягу** (Locality Dilation Ratio).

Нехай задано геометричну область розміром N × N. Обчислимо середньоквадратичну різницю відношення відстаней для всіх пар сусідніх осередків сітки:

```
MeanDilation = (1 / N²) · ∑ ( |f(A) - f(B)| / d_E(A, B) )
```

| Крива | Середнє значення розтягу | Максимальне значення розтягу | Складність кодування |
| :--- | :--- | :--- | :--- |
| **Z-Order (Morton)** | 3.12 | O(2ᵏ) [високий скачок] | **O(1)** [1 інструкція `PDEP`] |
| **Hilbert Curve** | **2.00** | O(3) [константна межа] | O(k) [State Machine / повороти] |
| **Gray Code Order** | 4.25 | O(2ᵏ) | O(1) [Побітовий XOR] |

Математичний аналіз показує, що хоча крива Гільберта має менший середній розтяг (2.00 проти 3.12) і відсутність великих розривів, крива Z-порядку перемагає за обчислювальною швидкістю. Вона дозволяє обчислювати індекси на порядку швидше, компенсуючи розриви локальності застосуванням алгоритму BIGMIN.
