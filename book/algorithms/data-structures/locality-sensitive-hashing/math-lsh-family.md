# 🧮 Математичні основи LSH-сімейств

Ця вставка містить суворі математичні виведення, ймовірнісні доведення та розрахунки підсилювальних характеристик (S-подібних кривих) для основних сімейств функцій хешування з урахуванням локальності (Locality-Sensitive Hashing). Вона призначена для глибокого розуміння теоретичних гарантій та ймовірнісних меж алгоритму.

## 1. Формальне математичне визначення LSH-сімейства

Нехай `(M, d)` — метричний простір, де `M` — множина об'єктів, а `d: M × M → [0, ∞)` — функція відстані, яка задовольняє аксіоми метрики (невід'ємність, симетрія, тотожність невidsлічуваних та нерівність трикутника).

Нехай `H` — скінченне сімейство відображень (функцій хешування) з `M` у скінченну множину індексів або комірок `U`.

### Означення `(r₁, r₂, p₁, p₂)`-чутливого сімейства

Сімейство функцій `H` називається **`(r₁, r₂, p₁, p₂)`-чутливим** для метрики `d`, якщо для будь-якої пари елементів `x, y ∈ M` та для випадково вибраної з рівномірним розподілом функції `h ∈ H` виконуються дві умови:

1. **Умова збереження близьких елементів (High Collision for Similar Points)**:
   Якщо `d(x, y) ≤ r₁`, то `P_{h ∈ H}[h(x) = h(y)] ≥ p₁`.

2. **Умова розділення далеких елементів (Low Collision for Distant Points)**:
   Якщо `d(x, y) ≥ r₂`, то `P_{h ∈ H}[h(x) = h(y)] ≤ p₂`.

При цьому за визначенням вимагається дотримання суворих умов на параметри:

```
r₁ < r₂       [радіус близькості менший за радіус віддаленості]
p₁ > p₂       [ймовірність колізії близьких точок більша за ймовірність колізії далеких]
```

Чим більший розрив між `p₁` та `p₂` при фіксованому відносному відстані `r₂ / r₁`, тим ефективнішим є LSH-сімейство і тим менше смуг знадобиться для розділення кандидатів.

## 2. Теорема MinHash для коефіцієнта Жаккара

Розглянемо метричний простір скінченних множин `M = P(Ω)`, де `Ω` — універсум елементів (наприклад, множина всіх можливих `k`-грам або слів).

Для двох множин `A, B ⊆ Ω` коефіцієнт схожості Жаккара визначається як:

```
J(A, B) = |A ∩ B| / |A ∪ B|
```

Відстань Жаккара дорівнює `d_J(A, B) = 1 - J(A, B)`.

### Виведення ймовірності колізії MinHash

Нехай `π: Ω → {1, 2, ..., |Ω|}` — випадкова перестановка універсуму `Ω`, вибрана з рівномірним розподілом із множини всіх `|Ω|!` перестановок.

Визначимо хеш-функцію `h_π(A)` як мінімальний індекс елемента множини `A` після застосування перестановки `π`:

```
h_π(A) = min_{x ∈ A} π(x)
```

**Теорема**: Для будь-яких двох невипорожнених множин `A` та `B`:

```
P_{π}[h_π(A) = h_π(B)] = J(A, B)
```

**Доведення**:

Розглянемо об'єднання множин `C = A ∪ B`. 

Оскільки перестановка `π` обирається абсолютно випадково та рівномірно, будь-який елемент `z ∈ C` має однакову ймовірність `1 / |C|` виявитися елементом із мінімальним значенням `π(z)` серед усіх елементів множини `C`.

Нехай `z* = argmin_{z ∈ C} π(z)` — елемент із об'єднання `C`, який отримав найменший номер при перестановці.

Події `h_π(A) = h_π(B)` відповідає ситуація, коли елемент `z*` належить ОДНОЧАСНО і множині `A`, і множині `B`:

```
z* ∈ A ∩ B
```

Якщо `z* ∈ A \ B`, то `h_π(A) = π(z*)`, але `h_π(B) > π(z*)`, отже `h_π(A) ≠ h_π(B)`.
Аналогічно, якщо `z* ∈ B \ A`, то `h_π(A) ≠ h_π(B)`.

Отже, рівність хешів `h_π(A) = h_π(B)` виконується тоді і тільки тоді, коли найменший елемент об'єднання належить їхньому перетину.

Кількість сприятливих елементів у `C` дорівнює `|A ∩ B|`.
Загальна кількість рівноможливих елементів у `C` дорівнює `|A ∪ B|`.

Обчислюємо ймовірність за класичним визначенням:

```
P_{π}[h_π(A) = h_π(B)] 
= |A ∩ B| / |A ∪ B|              [кількість елементів перетину до кількості елементів об'єднання]
= J(A, B)                        [за визначенням коефіцієнта Жаккара]
```

Отже, MinHash є абсолютно точним `(r₁, r₂, 1 - r₁, 1 - r₂)`-чутливим сімейством для відстані Жаккара.

## 3. Теорема SimHash (випадкові гіперплощини) для косинусної відстані

Розглянемо вектори у евклідовому просторі `Rᵈ`. Косинусна схожість між векторами `u` та `v` дорівнює:

```
cos(u, v) = (u · v) / (||u||₂ · ||v||₂)
```

Геометричний кут `θ ∈ [0, π]` між векторами дорівнює `θ = arccos(cos(u, v))`.

### Виведення ймовірності колізії SimHash

Нехай `r ~ N(0, I_d)` — випадковий вектор, компоненти якого згенеровані з стандартного нормального розподілу. Вектор `r` визначає гіперплощину із нормаллю `r`, яка проходить через початок координат.

Визначимо хеш-функцію SimHash як знак скалярного добутку:

```
h_r(u) = sign(r · u) = 1,  якщо (r · u) ≥ 0
                       0,  якщо (r · u) < 0
```

**Теорема**: Для будь-яких двох векторів `u, v ∈ Rᵈ`:

```
P_{r}[h_r(u) = h_r(v)] = 1 - θ / π
```

**Доведення**:

Розглянемо двовимірну площину `P`, у якій лежать вектори `u` та `v`.

Проекція випадкового вектора `r` на площину `P` є випадковим двовимірним вектором, напрямок якого розподілений абсолютно рівномірно по колу `2π` (360 градусів) завдяки сферичній симетрії багатовимірного нормального розподілу Гаусса.

Гіперплощина з нормаллю `r` ділить площину `P` на дві півплощини перпендикулярною лінією `L`.

Збіг хешів `h_r(u) = h_r(v)` означає, що вектори `u` та `v` лежать по один бік від перпендикулярної лінії `L`.

Неідеальний збіг `h_r(u) ≠ h_r(v)` відбувається тоді і тільки тоді, коли лінія `L` проходить усередині кута `θ` між векторами `u` та `v`.

Оскільки лінія `L` орієнтована абсолютно випадково та рівномірно в діапазоні кутів `π` (180 градусів):

```
P[h_r(u) ≠ h_r(v)] 
= θ / π                          [відношення кута між векторами до повного розгортання півкола π]

P[h_r(u) = h_r(v)] 
= 1 - P[h_r(u) ≠ h_r(v)]         [ймовірність протилежної події]
= 1 - θ / π                      [підстановка ймовірності розходження]
```

Отже, ймовірність збігу хешів SimHash лінійно залежить від кута між векторами.

## 4. Виведення ймовірності для p-стабільних L2 евклідових проекцій

Для евклідової відстані `c = ||x - y||₂` LSH-функція має вигляд `h_{a, b}(x) = floor((a · x + b) / w)`, де `a ~ N(0, I_d)`, `b ~ U(0, w)`.

Розглянемо різницю проекцій двох векторів `v = x - y`. Оскільки `a ~ N(0, I_d)`, скалярний добуток `a · v` має нормальний розподіл `c · Z`, де `Z ~ N(0, 1)`, а `c = ||v||₂`.

Нехай `X = |a · v| = c · |Z|` — абсолютне значення різниці проекцій.

Дві точки `x` та `y` потрапляють в один бакет ширинною `w` із випадковим зсувом `b`, якщо різниця проекцій `X` не перевищує ширину бакета і зсув `b` не перетинає границю цілочисельного квантування `floor`.

Для фіксованого значення проекції `X = u` ймовірність того, що випадковий зсув `b ~ U(0, w)` збереже обидві точки в одному інтервалі, дорівнює:

```
P(колізія | X = u) = max(0, 1 - u / w)
```

Інтегруючи по щільності нормального розподілу `f_Z(u) = sqrt(2/π) · exp(-u² / 2c²)`, отримуємо точну формулу ймовірності колізії як функцію від евклідової відстані `c`:

```
p(c) = ∫₀ʷ (1 / c) · sqrt(2/π) · (1 - u/w) · exp(-u² / (2c²)) du
```

Виконуючи заміну змінної `t = u / c`, отримуємо інтегральну формулу Датара-Індіка:

```
p(c) = 2 · Φ(w / c) - sqrt(2/π) · (c / w) · (1 - exp(-w² / (2c²)))
```

Де `Φ(z)` — функція стандартного нормального cumulative distribution function (CDF). Ця формула дозволяє обчислити точні ймовірності `p₁` та `p₂` для будь-якої евклідової відстані `c` та обраної ширини бакета `w`.

## 5. Лема Джонсона-Лінденштраусса та випадкові проекції

Фундаментальною математичною опорою для багатьох LSH-методів є **Лема Джонсона-Лінденштраусса (Johnson-Lindenstrauss Lemma, 1984)**.

**Лема**: Для будь-якого `0 < ε < 1` та будь-якої множини з `N` точок `V ⊂ Rᵈ`, існує лінійне відображення `f: Rᵈ → Rᵏ` у простір вимірності `k = O(log N / ε²)`, таке що для всіх `u, v ∈ V` виконується збереження евклідової відстані із точністю `1 ± ε`:

```
(1 - ε) · ||u - v||² ≤ ||f(u) - f(v)||² ≤ (1 + ε) · ||u - v||²
```

Це доводить, що високопросторові вектори (наприклад, `d = 10000`) можна спроектувати у значно нижчу вимірність `k = 500` за допомогою випадкової матриці Гаусса без суттєвих викривлень геометрії відстаней.

## 6. Математичний аналіз підсилення (Banding & AND-OR S-Curve)

Окремо взята хеш-функція має слабку роздільну здатність. Щоб перетворити м'яку лінійну ймовірність на круту порогову S-подібну криву (S-Curve), застосовують схему підсилення:
1. Застосовують `M = k · L` хеш-функцій.
2. Групують їх у `L` незалежних смуг (Bands), по `k` функцій у кожній смузі.
3. Елементи вважаються кандидатами, якщо вони повністю збігаються по всіх `k` функціях **хоч в одній** із `L` смуг.

### Виведення формули ймовірності відбору кандидатів

Нехай `p = P[h(x) = h(y)]` — ймовірність колізії для однієї хеш-функції при схожості об'єктів `s`.

```
1. P[збіг усіх k функцій в 1 конкретній смузі]
= pᵏ                             [правило добутку для k незалежних функцій (AND)]

2. P[НЕзбіг хоча б в одній із k функцій цієї смуги]
= 1 - pᵏ                         [ймовірність протилежної події]

3. P[НЕзбіг у ВСІХ L смугах одночасно]
= (1 - pᵏ)ᴸ                      [правило добутку для L незалежних смуг]

4. P[Кандидат: збіг принаймні в 1 із L смуг]
= 1 - (1 - pᵏ)ᴸ                  [підсумкова ймовірність (OR між смугами)]
```

### Аналіз точки перегіну (Threshold Inflection Point)

Функція `F(p) = 1 - (1 - pᵏ)ᴸ` має характерну S-подібну форму. Знайдемо точку перегіну `p₀`, де друга похідна дорівнює нулю: `F''(p₀) = 0`.

Обчислимо першу похідну:

```
F'(p) 
= d/dp (1 - (1 - pᵏ)ᴸ)           [похідна суми]
= -L · (1 - pᵏ)ᴸ⁻¹ · (-k · pᵏ⁻¹) [похідна складеної функції за правилом ланцюга]
= k · L · pᵏ⁻¹ · (1 - pᵏ)ᴸ⁻¹     [спрощення знаків]
```

Обчислимо другу похідну та прирівняємо її до нуля:

```
F''(p) 
= k·L · [(k-1)·pᵏ⁻² · (1-pᵏ)ᴸ⁻¹ - pᵏ⁻¹ · (L-1)·(1-pᵏ)ᴸ⁻² · (k·pᵏ⁻¹)] = 0

(k-1) · (1 - pᵏ) - k · (L - 1) · pᵏ = 0      [скорочення спільних множників]

k - 1 - pᵏ · (k - 1 + k·L - k) = 0           [розкриття дужок]

k - 1 = pᵏ · (k·L - 1)                      [перенесення членів з p^k]

p₀ᵏ = (k - 1) / (k·L - 1)                   [знаходження p^k у точці перегіну]
```

Для великих значень `k` та `L` маємо наближення `(k - 1) / (k·L - 1) ≈ 1 / L`.

Отже, порогова схожість `p₀` (точка найкрутішого підйому S-кривої) наближено становить:

```
p₀ ≈ (1 / L)^(1 / k)
```

### Приклад розрахунку параметрів

Якщо ми хочемо встановити поріг схожості `s₀ = 0.5`:
* При `k = 5` та `L = 20`: `p₀ ≈ (1 / 20)^(1 / 5) ≈ 0.549`.
* Для схожості `s = 0.8`: `P(Кандидат) = 1 - (1 - 0.8⁵)²⁰ = 1 - (1 - 0.32768)²⁰ ≈ 0.9992` (Recall 99.9%).
* Для схожості `s = 0.2`: `P(Кандидат) = 1 - (1 - 0.2⁵)²⁰ = 1 - (1 - 0.00032)²⁰ ≈ 0.0063` (False Positives 0.6%).

Ці суворі ймовірнісні межі гарантують високу точність відсікання нерелевантних векторів.
