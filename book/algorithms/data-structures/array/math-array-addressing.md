# 🧮 Математика адресації та геометрія n-вимірних масивів

Ця математична вставка містить точне алгебраїчне виведення формул адресації для одновимірних, двовимірних та n-вимірних масивів, аналіз просторових зсувів (strides), а також математичний апарат обчислення вирівнювання пам'яті (memory alignment padding). Вона надає формальний доказ того, як довільна n-вимірна сітка проєктується у плаский 1D-адресний простір без втрати бієктивності та без перекриття комірок.

У практичному програмуванні та лінійній алгебрі математика адресації лежить в основі роботи тензорних обчислювальних ядер (PyTorch, TensorFlow, NumPy), де відображення багатовимірних індексів на лінійні адреси визначає можливість виконання паралельних матричних операцій.

## Одномірна адресація та лінійний векторний простір

Нехай оперативна пам'ять комп'ютера представлена у вигляді послідовності байтових комірок із дискретними адресами `A ∈ ℕ₀`. Масив із `N` елементів типу `T` розміщується в неперервному діапазоні пам'яті, починаючи з базової адреси `B = BaseAddress`.

Позначиємо розмір одного елемента типу `T` у байтах як `S = sizeof(T)`. Оскільки всі елементи мають однаковий розмір `S`, зміщення `k`-го елемента від початку масиву виражається як добуток індексу на розмір типу.

Точна фізична адреса елемента з індексом `i` (де `0 ≤ i < N`) обчислюється за виразом:

```
Address(i) = B + i · S
```

Доведемо, що для будь-яких двох різних індексів `i, j` діапазони пам'яті відповідних елементів не перекриваються.

```
Елемент i займає інтервал пам'яті: [B + i·S, B + (i+1)·S - 1]
Елемент j займає інтервал пам'яті: [B + j·S, B + (j+1)·S - 1]

Нехай i < j. Тоді i + 1 ≤ j.
Множимо на S > 0:
(i + 1)·S ≤ j·S

Додаємо базовану адресу B:
B + (i + 1)·S ≤ B + j·S
```

Отже, кінець області елемента `i` строго передує початку області елемента `j`, що гарантує відсутність руйнування даних між сусідніми комірками.

## Двовимірна матриця: Row-Major та Column-Major

Розглянемо двовимірну матрицю `M` розміром `R × C`, де `R` — кількість рядків (rows), а `C` — кількість стовпчиків (columns). Індекс рядка `i ∈ [0, R - 1]`, індекс стовпчика `j ∈ [0, C - 1]`.

Матриця має бути відображена на одновимірний масив із `R · C` елементів. Існує дві канонічні бієктивні функції відображення пара індексів `(i, j) ↦ k`, де `k ∈ [0, R·C - 1]`.

### 1. Порядок за рядками (Row-Major Order)

У порядку за рядками спочатку розміщуються всі елементи 0-го рядка, потім 1-го рядка і так далі. Кожен повний рядок містить `C` елементів.

Щоб дістатися елемента `(i, j)`, необхідно пропустити `i` повних рядків (кожен довжиною `C`) та зміститися на `j` елементів усередині почного рядка.

```
k_row = i · C + j
```

Формула фізичної адреси в байтах:

```
Address_row(i, j) = B + (i · C + j) · S
```

Виведемо крок (stride) зміщення адреси при переході між сусідніми елементами:
- Перехід до наступного стовпчика `(i, j + 1)`: Зміна адреси = `S` байтів.
- Перехід до наступного рядка `(i + 1, j)`: Зміна адреси = `C · S` байтів.

### 2. Порядок за стовпчиками (Column-Major Order)

У порядку за стовпчиками спочатку розміщуються всі елементи 0-го стовпчика (кожен містить `R` елементів), потім 1-го стовпчика і так далі.

```
k_col = j · R + i
```

Формула фізичної адреси в байтах:

```
Address_col(i, j) = B + (j · R + i) · S
```

Кроки зміщення адреси (strides):
- Перехід до наступного рядка `(i + 1, j)`: Зміна адреси = `S` байтів.
- Перехід до наступного стовпчика `(i, j + 1)`: Зміна адреси = `R · S` байтів.

## N-вимірні тензори та загальна формула зсувів (Strides)

Розглянемо загальний випадок `n`-вимірного масиву (тензора) з розмірами вимірів `D = (d₀, d₁, d₂, ..., dₙ⌠)`.
Довільний елемент задається кортежем індексів `I = (i₀, i₁, i₂, ..., iₙ⌠)`, де `0 ≤ iₖ < dₖ` для кожного `k ∈ [0, n - 1]`.

Для порядку Row-Major (де останній індекс змінюється найшвидше) лінійний індекс `k` обчислюється за формулою полинома числення:

```
k = i₀ · (d₁ · d₂ · ... · dₙ⌠) + i₁ · (d₂ · d₃ · ... · dₙ⌠) + ... + iₙ₋₂ · dₙ⌠ + iₙ⌠
```

Введемо поняття **вектора кроків** (stride vector) `W = (w₀, w₁, ..., wₙ⌠)` елементів, де `wₖ` виражає кількість елементів, яку потрібно пропустити при збільшенні індексу `iₖ` на одиницю.

Вектор кроків обчислюється рекурентно справа наліво:

```
wₙ⌠ = 1
wₖ = wₖ₊₁ · dₖ₊₁   для k = n - 2, n - 3, ..., 0
```

Тоді лінійний індекс `k` виражається у вигляді скалярного добутку вектора індексів `I` та вектора кроків `W`:

```
k = ∑ (iₘ · wₘ)   для m = 0..n-1
```

А підсумкова байтова адреса становить:

```
Address(I) = B + ( ∑ (iₘ · wₘ) ) · S
```

### Алгебра тензорних зрізів (Tensor Strides & Zero-Copy Views)
Завдяки використання вектора кроків `W`, бібліотеки глибинного навчання (PyTorch/NumPy) підтримують операції обрізання, транспонування та транспонованих уявлень за `O(1)` часу без копіювання даних у пам'яті.

При виконанні операції `tensor.transpose(0, 1)` система не переставляє елементи в оперативній пам'яті. Вона лише міняє місцями відповідні значення в масиві кроків `W` та масиві розмірностей `D`. Наприклад, для 2D-тензора розміром `3 × 4` із початковими кроками `W = (4, 1)` транспонування створює нове уявлення з кроками `W' = (1, 4)`.

При зверненні до транспонованого уявлення за індексом `[i][j]` адреса обчислюється як:

```
Index = i · 1 + j · 4
```

Це дозволяє миттєво інтерпретувати той самий блок пам'яті в різній геометричній конфігурації. Однако при виконанні розрахунків над неперервним (Non-Contiguous) тензором процесор втрачає частину просторової кеш-локальності, тому перед гарячими SIMD-обчисленнями викликають метод `.contiguous()`, який фізично перезаписує елементи у пам'ять згідно з новим порядком `Row-Major`.

## Математика вирівнювання пам'яті (Alignment Padding)

Сучасні процесорні архітектури вимагають, щоб дані розміром `S` байтів розміщувалися за адресами, кратними `S` (або кратними розміру кеш-лінії `A_align`, зазвичай 64 байти).

Припустимо, ми маємо базову адресу `B` і хочемо обчислити найближчу вирівняну адресу `B_aligned ≥ B`, яка кратна `A_align` (де `A_align` є ступенем двійки: `2^p`).

Застосуємо цілочисельну алгебру та бітові операції:

```
B_aligned = (B + A_align - 1) & ~(A_align - 1)
```

Доведемо цю формулу для `A_align = 8` (двійковий код `00001000₂`):

```
1. Нехай A_align = 8.
   Тоді (A_align - 1) = 7 (двійковий код 00000111₂).
2. Побітове заперечення ~(A_align - 1) дає маску з одиницями в старших бітах:
   ~7 = ...11111000₂.
3. Додавання (B + 7) примусово переносить одиницю в 3-й біт, якщо молодші біти B були ненульовими.
4. Побітове І з маскою ~7 обнуляє молодші 3 біти, гарантуючи кратність 8.
```

Обсяг заповнювача (padding bytes) між елементами або наприкінці структури обчислюється як:

```
Padding = (A_align - (B mod A_align)) mod A_align
```

При побудові масивів структур (Array of Structures) сумарний розмір однієї структури завжди вирівнюється компілятором до величини, кратної найбільшому члену структури. Якщо структура містить поля `double` (8 байтів) та `char` (1 байт), розмір всієї структури доповнюється заповнювачем до величини, кратної 8, щоб у масиві кожен наступний елемент зберігав вирівнювання свого поля `double`.

## Практичний чисельний приклад розрахунку адреси

Обчислимо точну байтову адресу елемента `M[2][3][1]` у тривимірному тензорі `M` розміром `3 × 4 × 5`.

**Вхідні дані:**
- Тип елемента: `double` (розмір `S = 8` байтів).
- Розмірності: `d₀ = 3`, `d₁ = 4`, `d₂ = 5`.
- Базова адреса: `B = 0x1000` (у десятковій системі: `4096`).
- Індекси цільового елемента: `i₀ = 2`, `i₁ = 3`, `i₂ = 1`.

**Покроковий розрахунок:**

```
1. Обчислюємо вектор кроків (strides):
   w₂ = 1                                  [останній вимір]
   w₁ = w₂ · d₂ = 1 · 5 = 5               [крок по 1-му виміру]
   w₀ = w₁ · d₁ = 5 · 4 = 20              [крок по 0-му виміру]

2. Обчислюємо лінійний індекс k:
   k = i₀ · w₀ + i₁ · w₁ + i₂ · w₂
   k = 2 · 20 + 3 · 5 + 1 · 1              [підстановка індексів]
   k = 40 + 15 + 1                         [множення]
   k = 56                                  [лінійний зміщення елемента]

3. Обчислюємо зміщення в байтах:
   Offset_bytes = k · S
   Offset_bytes = 56 · 8 = 448 байтів

4. Обчислюємо фінальну фізичну адресу:
   Address = B + Offset_bytes
   Address = 4096 + 448 = 4544
   4544 у шістнадцятковій системі = 0x11C0
```

Висновок: елемент `M[2][3][1]` розташований точно за адресою `0x11C0` у пам'яті. Обчислення виконано за `O(1)` арифметичних операцій без потреби проходу по проміжних елементах.
