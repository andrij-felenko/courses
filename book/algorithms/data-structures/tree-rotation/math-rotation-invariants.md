# 🧮 Математика повертань дерев: інваріанти та граф асоціаедра

Поворот дерева — це не просто практичний трюк із перебудови вказівників у пам'яті комп'ютера, а точна алгебраїчна операція над скінченними граф-структурами. З математичної точки зору двійкове дерево пошуку є географічним представленням розстановки дужок у некомутативному виразі над бінарною операцією, а поворот відповідає застосуванню фундаментального закону асоціативності. Розглянемо суворі інваріанти впорядкованості, потенціальні функції для оцінки амортизованої складності, топологічний простір повертань та гіперболічну геометрію асоціаедра.

## 1. Формальне доведення інваріанта центрового обходу (In-order Preservation)

Головна алгебраїчна властивість двійкового дерева пошуку — дотримання суворого порядку ключів при центровому обході. Формально, дерево `T` є двійковим деревом пошуку над повністю впорядкованою множиною `(K, <)`, якщо для кожної вершини `V ∈ T` з ключем `k(V)` виконуються дві умови на множини ключів лівого піддерева `L_V` та правого піддерева `R_V`:

```
∀ x ∈ L_V:  k(x) < k(V)
∀ y ∈ R_V:  k(y) > k(V)
```

Операція центрового обходу `InOrder(T)` визначається рекурсивно як послідовність ключів:

```
InOrder(∅) = ()
InOrder(T) = InOrder(L_T) ∘ (k(root(T))) ∘ InOrder(R_T)
```

де `∘` позначує операцію конкатенації послідовностей.

Доведемо теорему про збереження центрового обходу при правому повороті.

**Теорема 1 (Інваріантність центрового обходу):**
*Нехай T_1 — двійкове дерево пошуку з коренем Y, лівим сином X та піддеревами A, B, C. Нехай T_2 — дерево, отримане з T_1 шляхом правого повороту навколо Y. Тоді InOrder(T_1) = InOrder(T_2).*

**Доведення:**
Розглянемо структуру дерева `T_1` до правого повороту:
- Корінь `T_1` — вершина `Y`.
- Ліве піддерево `L_Y` має корінь `X`, з лівим піддеревом `A` та правим піддеревом `B`.
- Праве піддерево `R_Y` є піддеревом `C`.

Застосуємо означення `InOrder` до `T_1`:

```
InOrder(T_1) 
= InOrder(L_Y) ∘ (k(Y)) ∘ InOrder(R_Y)               [означення InOrder для кореня Y]
= (InOrder(A) ∘ (k(X)) ∘ InOrder(B)) ∘ (k(Y)) ∘ InOrder(C) [розклад InOrder для кореня X]
= InOrder(A) ∘ (k(X)) ∘ InOrder(B) ∘ (k(Y)) ∘ InOrder(C) [асоціативність конкатенації]
```

Тепер розглянемо структуру дерева `T_2` після правого повороту:
- Корінь `T_2` — вершина `X`.
- Ліве піддерево `L_X` є піддеревом `A`.
- Праве піддерево `R_X` має корінь `Y`, з лівим піддеревом `B` та правим піддеревом `C`.

Застосуємо означення `InOrder` до `T_2`:

```
InOrder(T_2)
= InOrder(L_X) ∘ (k(X)) ∘ InOrder(R_X)               [означення InOrder для кореня X]
= InOrder(A) ∘ (k(X)) ∘ (InOrder(B) ∘ (k(Y)) ∘ InOrder(C)) [розклад InOrder для кореня Y]
= InOrder(A) ∘ (k(X)) ∘ InOrder(B) ∘ (k(Y)) ∘ InOrder(C) [асоціативність конкатенації]
```

Обидва вирази дають абсолютно тотожну послідовність елементів. Оскільки центрова послідовність зберігається, а для двійкового дерева пошуку порядок `InOrder(T)` строго зростає, дерево `T_2` залишається валідним двійковим деревом пошуку. Теорему доведено.

З алгебраїчної точки зору, якщо ми визначимо некомутативний оператор згортання `(L * R)`, то правому повороту відповідає тотожність:

```
(A * X * B) * Y * C  ≡  A * X * (B * Y * C)
```

Це доводить, що поворот є просторовою ізоморфією ізоморфного представлення асоціативного закону.

## 2. Динаміка глибини та аналіз методом потенціалу

Хоча послідовність елементів при центровому обході є інваріантною, індивідуальна глибина вузлів зазнає чітко визначених змін.

Нехай `depth(v, T)` — відстань від кореня дерева `T` до вершини `v`. При правому повороті навколо `Y` (де `X = Y->left`):
- Для будь-якого вузла `v ∈ A`: `depth(v, T_2) = depth(v, T_1) - 1` (піддерево піднімається на 1 рівень).
- Для будь-якого вузла `v ∈ C`: `depth(v, T_2) = depth(v, T_1) + 1` (піддерево опускається на 1 рівень).
- Для будь-якого вузла `v ∈ B`: `depth(v, T_2) = depth(v, T_1)` (глибина елементів піддерева B залишається незмінною відносно нового кореня).
- Для самого вузла `X`: `depth(X, T_2) = depth(X, T_1) - 1`.
- Для самого вузла `Y`: `depth(Y, T_2) = depth(Y, T_1) + 1`.

Внутрішня довжина шляху дерева визначається як сума глибин усіх його вузлів:

```
I(T) = ∑_{v ∈ T} depth(v, T)
```

Зміна внутрішньої довжини шляху `ΔI(T) = I(T_2) - I(T_1)` обчислюється як:

```
ΔI(T) = I(T_після) - I(T_до)     [означення зміни внутрішньої довжини шляху]
      = (|C| + 1) - (|A| + 1)    [глибина елементів у C зросла на 1, у A зменшилася на 1]
      = |C| - |A|                [скорочення сталих доданків]
```

Отже, якщо піддерево `A` є "важчим" за піддерево `C` (`|A| > |C|`), правий поворот строго зменшує сумарну глибину вузлів дерева, роблячи його компактнішим.

### Метод потенціалу Слейтора-Тар'яна для Splay-дерев

Для оцінки [амортизованого аналізу](topic:algorithms/amortized-analysis) послідовності повертань Денієл Слейтор та Роберт Тар'ян винайшли метод потенціалу над логарифмічними рангами вузлів.

Нехай `|T_v|` — кількість вузлів у піддереві з коренем у `v`. Визначимо ранг вузла `v` як:

```
r(v) = log₂(|T_v|)
```

Функція потенціалу всього дерева `Φ(T)` визначається як сума рангів усіх його вузлів:

```
Φ(T) = ∑_{v ∈ T} r(v)
```

Амортизована вартість операції повороту `a_i` визначається через реальну вартість `c_i = 1` та зміну потенціалу `ΔΦ = Φ(T_після) - Φ(T_до)`:

```
a_i = c_i + ΔΦ = 1 + r'(x) + r'(y) - r(x) - r(y)
```

де `r` позначує ранги до повороту, а `r'` — ранги після повороту.

Оскільки після правого повороту вузол `x` стає новим коренем усього піддерева, яке раніше очолював `y`, маємо `r'(x) = r(y)`. Більше того, оскільки `x` та `y` ділять вузли піддерева, з угнутості логарифмічної функції виводиться **Основна лема про викочування (Access Lemma)**:

```
a_i ≤ 3 · (r'(x) - r(x)) + 1
```

При послідовному викочуванні вузла `x` до кореня дерева через серію повертань `zig`, `zig-zig` та `zig-zag` сума змін потенціалу **телескопує**:

```
∑ a_i ≤ ∑ (3 · (r_i(x) - r_{i-1}(x)) + 1) = 3 · (r_{final}(x) - r_{initial}(x)) + O(k)
```

Оскільки максимальний ранг будь-якого вузла не перевищує `log₂ n`, а початковий ранг `r(x) ≥ 0`, амортизована складність всієї серії повертань для довільного вузла строго обмежується виразом:

```
a_{total} ≤ 3 · log₂ n + 1 = O(log n)
```

Це математично гарантує, що незважаючи на відсутність явних метаданих про баланс, Splay-дерево виконує будь-яку послідовність з `m` операцій за час `O(m log n)`.

## 3. Граф повертань, Решітка Тамарі та Асоціаедр Стішеффа

Розглянемо множину всіх можливих двійкових дерев пошуку з `n` вузлами як вершини мета-графа — **графа повертань** (англ. *rotation graph*). Ребро між двома вершинами-деревами існує тоді й лише тоді, коли одне дерево можна перетворити на інше рівно за один поворот (лівий або правий).

Загальна кількість різних двійкових дерев пошуку з `n` вузлами описується `n`-м **числом Каталана**:

```
C_n = (1 / (n + 1)) · (2n choose n) = (2n)! / ((n + 1)! · n!)
```

Для кількох перших `n` значення `C_n` становлять:

```
n   | C_n  | Структури двійкових дерев
----|------|----------------------------------------------------
1   |  1   | (1)
2   |  2   | (1(2)), ((1)2)
3   |  5   | (1(2(3))), (1((2)3)), ((1)2(3)), ((1(2))3), (((1)2)3)
4   | 14   | 14 різних топологій дерев
5   | 42   | 42 різні топології дерев
```

Граф повертань має багату алгебраїчну та топологічну структуру:

### 1. Решітка Тамарі (Tamari Lattice)
Якщо надати орієнтацію ребрам графа повертань (спрямувавши ребро в бік правого повороту), граф утворює частково впорядковану множину (посет), відому як **решітка Тамарі**. Найнижчим елементом решітки є вироджене ліве дерево (найменший елемент), а найвищим — вироджене праве дерево.

### 2. Асоціаедр Стішеффа (Stasheff Associahedron)
У 1963 році американський математик Джим Стішефф (Jim Stasheff) відкрив, що граф повертань для `n` елементів є скелетом `(n - 1)`-вимірного опуклого многогранника — **асоціаедра** `K_{n+1}`.
- Вершинам багатогранника відповідають двійкові дерева з `n` вузлами (або еквівалентні триангуляції `(n + 2)`-кутника).
- Ребрам багатогранника відповідають поодинокі повороти дерев (або перекидання діагоналі в триангуляції — англ. *flip*).
- Граням багатогранника відповідають частково визначені дужкові структури.

```
Вимірність | Позначення | Кількість вершин (C_n) | Геометрична форма
-----------|------------|------------------------|---------------------------
    0D     |    K_3     |           1            | Точка
    1D     |    K_4     |           2            | Відрізок (1 поворот)
    2D     |    K_5     |           5            | П'ятикутник (5 повертань у циклі)
    3D     |    K_6     |          14            | Тринадцятигранник (14 вершин, 21 ребро)
```

## 4. Відстань повороту та Теорема Слейтора-Тар'яна-Терстона

**Відстань повороту** `d(T_1, T_2)` між двома двійковими деревами пошуку `T_1` та `T_2` визначеного розміру `n` — це мінімальна кількість повертань, необхідна для перетворення `T_1` на `T_2`.

Тривалий час залишалося відкритим питання: наскільки віддаленими можуть бути два двійкових дерева пошуку у графі повертань?

У 1988 році Денієл Слейтор, Роберт Тар'ян та лауреат Філдсівської премії Вільям Терстон (William Thurston) опублікували доведення точної верхньої межі відстані повороту.

**Теорема 2 (Слейтор-Тар'ян-Терстон, 1988):**
*Для будь-яких двох двійкових дерев пошуку T_1 та T_2 з n вузлами (при n > 11) відстань повороту строго обмежується виразом:*

```
d(T_1, T_2) ≤ 2n - 6
```

**Схема доведення:**
Доведення спирається на геометричне співвідношення між повертаннями дерев та тріангуляціями опуклих багатокутників у тривимірному гіперболічному просторі `H^3`.
1. Кожному двійковому дереву з `n` вузлами зіставляється триангуляція опуклого `(n + 2)`-кутника.
2. Поворот дерева відповідає перекиданню спільної діагоналі між двома суміжними трикутниками (операція *flip*).
3. Два поверхневих `(n + 2)`-кутники об'єднуються у тривимірний многогранник (ідеальний тетраедричний комплекс у гіперболічному просторі).
4. Об'єм цього гіперболічного многогранника обмежується зверху через об'єм ідеального тетраедра, що після обчислення градієнта дає точну межу `2n - 6`.

Цей результат довів, що простір повертань двійкових дерев є напрочуд компактним: будь-які два дерева розміру `n` можна перетворити одне в інше за лінійну кількість повертань `O(n)`.
