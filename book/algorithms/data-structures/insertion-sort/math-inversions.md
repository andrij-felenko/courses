# 🧮 Математичний аналіз інверсій та складності сортування вставками

Ця математична вставка містить суворе виведення характеристик сортування вставками: точне обчислення математичного сподівання та дисперсії кількості інверсій у випадкових перестановках за допомогою коду Лемера, теорему про збереження пар при суміжних зсувах та формальне індукційне доведення коректності інваріанта циклу.

## 1. Простір перестановок та формальне означення інверсій

Нехай `A = [a₁, a₂, ..., aₙ]` — послідовність із `n` попарно різних елементів, визначених на лінійно впорядкованій множині. Без обмеження загальності ми можемо вважати множину елементів перестановкою перших `n` натуральних чисел: `π ∈ Sₙ`, де `Sₙ` — симетрична група перестановок порядку `n!`.

**Означення інверсії:** Інверсією в перестановці `π = (π(1), π(2), ..., π(n))` називається впорядкована пара індексів `(i, j)`, для якої одночасно виконуються дві умови:
1. `1 ≤ i < j ≤ n` (індекс `i` передує індексу `j`);
2. `π(i) > π(j)` (значення елемента з меншим індексом строго більше за значення елемента з більшим індексом).

Загальна кількість інверсій у перестановці `π` позначається як `I(π)` та визначається сумою індикаторних випадкових величин для всіх можливих пар індексів:

```
I(π) = ∑ [π(i) > π(j)]     [сумування за всіма парами 1 ≤ i < j ≤ n]
```

де дужки Айверсона `[P]` дорівнюють `1`, якщо предикат `P` істинний, і `0`, якщо хибний.

Кількість можливих невпорядкованих пар індексів у послідовності довжини `n` дорівнює біноміальному коефіцієнту:

```
C(n, 2)
= n · (n - 1) / 2          [загальна кількість пар індексів]
```

Звідси випливають тривіальні екстремальні межі для кількості інверсій:
- **Мінімальне значення:** `I(π) = 0` досягається тоді й лише тоді, коли перестановка вже відсортована за зростанням: `π = (1, 2, ..., n)`.
- **Максимальне значення:** `I(π) = n(n - 1) / 2` досягається тоді й лише тоді, коли перестановка відсортована у строго зворотному порядку: `π = (n, n - 1, ..., 1)`.

## 2. Математичне сподівання кількості інверсій

Розглянемо ймовірнісний простір, де кожна з `n!` можливих перестановок множини `Sₙ` з'являється з однаковою ймовірністю `P(π) = 1 / n!`.

Для кожної фіксованої пари індексів `(i, j)`, де `i < j`, введемо бінарну індикаторну випадкову величину `X_{i,j}`:
- `X_{i,j} = 1`, якщо `π(i) > π(j)` (пара утворює інверсію);
- `X_{i,j} = 0`, якщо `π(i) < π(j)`.

В силу симетрії випадкового вибору в множині всіх перестановок рівно половина перестановок містить `π(i) > π(j)`, а інша половина — `π(i) < π(j)`. Отже, ймовірність появи інверсії для будь-якої конкретної пари становить:

```
P(X_{i,j} = 1)
= 1 / 2                    [симетрія взаємного розташування двох елементів]
```

Математичне сподівання індикатора дорівнює ймовірності його одиничного значення:

```
E[X_{i,j}]
= 1 · P(X_{i,j} = 1) + 0 · P(X_{i,j} = 0)
= 1 / 2                    [математичне сподівання індикатора]
```

Оскільки сумарна кількість інверсій є сумою всіх індикаторів `I(π) = ∑_{1 ≤ i < j ≤ n} X_{i,j}`, застосуємо фундаментальну властивість лінійності математичного сподівання (яка справедлива навіть для залежних випадкових величин):

```
E[I]
= E[ ∑ X_{i,j} ]           [за означенням сумарної кількості інверсій]
= ∑ E[X_{i,j}]             [лінійність математичного сподівання]
= ∑ (1 / 2)                [підстановка математичного сподівання індикатора]
= (1 / 2) · C(n, 2)        [множення на кількість пар]
= (1 / 2) · (n · (n - 1) / 2) [розкриття біноміального коефіцієнта]
= n · (n - 1) / 4          [фінальне математичне сподівання інверсій]
```

Це доводить, що у випадковому масиві з `n` елементів очікувана кількість інверсій становить рівно половину від теоретичного максимуму: `E[I] = n(n - 1) / 4`.

## 3. Таблиця інверсій (код Лемера) та точне виведення дисперсії

Безпосереднє обчислення дисперсії `Var[I]` через індикатори `X_{i,j}` ускладнюється тим, що індикатори зі спільними індексами (наприклад, `X_{i,j}` та `X_{j,k}`) є корельованими величинами: події `π(i) > π(j)` та `π(j) > π(k)` суттєво впливають на ймовірність `π(i) > π(k)`.

Для усунення кореляції використаємо витончений апарат алгебраїчної комбінаторики — **таблицю інверсій** (відому також як код Лемера, Lehmer code).

Для кожного індексу `j` від `1` до `n` визначимо величину `c_j` як кількість елементів, розташованих ліворуч від `j`, які є строго більшими за `π(j)`:

```
c_j = |{ i : 1 ≤ i < j  і  π(i) > π(j) }|
```

За побудовою, величина `c_j` може набувати будь-якого цілого значення з множини `{0, 1, 2, ..., j - 1}`. Загальна кількість інверсій перестановки строго дорівнює сумі компонент її коду Лемера:

```
I(π) = c₁ + c₂ + c₃ + ... + cₙ = ∑ c_j   [сума елементів таблиці інверсій]
```

### Теорема про незалежність компонент коду Лемера

У рівномірному ймовірнісному просторі перестановок `Sₙ` випадкові величини `c₁, c₂, ..., cₙ` є **повністю взаємно незалежними**, і кожна величина `c_j` має дискретний рівномірний розподіл на множині `{0, 1, ..., j - 1}`:

```
P(c_j = k)
= 1 / j                    [для будь-якого k ∈ {0, 1, ..., j - 1}]
```

*Доведення незалежності:* Коли ми формуємо випадкову перестановку шляхом послідовної вставки елементів `1, 2, ..., n` на довільні вільні позиції, елемент `j` може зайняти будь-яку з `j` доступних позицій відносно вже розміщених менших елементів `1, ..., j - 1` з рівною ймовірністю `1 / j`. Вибір цієї позиції однозначно задає значення `c_j` і абсолютно не залежить від відносного порядку попередніх елементів.

### Обчислення дисперсії окремої компоненти

Для випадкової величини `c_j`, розподіленої рівномірно на `{0, 1, ..., j - 1}`, обчислимо математичне сподівання та другий момент:

```
E[c_j]
= (1 / j) · ∑ k            [сума k від 0 до j - 1]
= (1 / j) · ((j - 1) · j / 2) [формула суми арифметичної прогресії]
= (j - 1) / 2              [математичне сподівання c_j]
```

Обчислимо другий момент `E[c_j²]`:

```
E[c_j²]
= (1 / j) · ∑ k²           [сума k² від 0 до j - 1]
= (1 / j) · ((j - 1) · j · (2j - 1) / 6) [сума квадратів перших j-1 чисел]
= (j - 1) · (2j - 1) / 6   [другий момент c_j]
```

Тепер обчислимо дисперсію `Var[c_j] = E[c_j²] - (E[c_j])²`:

```
Var[c_j]
= (j - 1) · (2j - 1) / 6 - ((j - 1) / 2)²  [за означенням дисперсії]
= (j - 1) · [ (2j - 1) / 6 - (j - 1) / 4 ] [винесення спільного множника]
= (j - 1) · [ (4j - 2 - 3j + 3) / 12 ]     [зведення до спільного знаменника]
= (j - 1) · (j + 1) / 12                   [спрощення чисельника]
= (j² - 1) / 12                            [формула різниці квадратів]
```

### Підсумовування дисперсій

Оскільки випадкові величини `c_j` взаємно незалежні, дисперсія суми дорівнює сумі дисперсій доданків:

```
Var[I]
= Var[ ∑ c_j ]             [за означенням суми інверсій через код Лемера]
= ∑ Var[c_j]               [внаслідок взаємної незалежності величин c_j]
= ∑ (j² - 1) / 12          [підстановка дисперсії кожної компоненти]
= (1 / 12) · [ ∑ j² - ∑ 1 ] [розбиття суми на дві окремі суми від j=1 до n]
= (1 / 12) · [ n(n + 1)(2n + 1)/6 - n ] [підстановка табличних формул сум]
= (n / 72) · [ (n + 1)(2n + 1) - 6 ]    [винесення n/72 за дужки]
= (n / 72) · [ 2n² + 3n + 1 - 6 ]       [розкриття добутку в дужках]
= (n / 72) · [ 2n² + 3n - 5 ]           [спрощення виразу]
= (n / 72) · (n - 1) · (2n + 5)         [розкладання квадратного тричлена на множники]
= n · (n - 1) · (2n + 5) / 72           [фінальна точна дисперсія кількості інверсій]
```

Це фундаментальний результат Дональда Кнута: дисперсія кількості інверсій у випадковому масиві асимптотично зростає як `Θ(n³)`. Стандартне відхилення дорівнює:

```
σ(I) = √(Var[I]) ≈ √(2n³ / 72) = n^(3/2) / 6
```

Оскільки математичне сподівання росте як `Θ(n²)`, а стандартне відхилення — як `Θ(n^(3/2))`, відносне коливання `σ(I) / E[I] ≈ (n^(3/2) / 6) / (n² / 4) = 2 / (3√n)` стрімко прямує до нуля при зростанні `n`. Це означає, що розподіл кількості інверсій є висококонцентрованим навколо свого середнього значення `n²/4`.

## 4. Теорема про зсув суміжних елементів та час роботи

**Теорема (про суміжний обмін):** Нехай `A = [..., x, y, ...]` — масив, у якому елементи `x` та `y` розташовані на сусідніх позиціях `k` та `k+1`, причому `x > y`. Тоді обмін місцями елементів `x` та `y` зменшує загальну кількість інверсій у масиві рівно на одиницю: `I(A') = I(A) - 1`.

*Доведення:*
Розглянемо довільний третій елемент `z`, що займає позицію `m` у масиві:
1. Якщо `m < k` (елемент `z` стоїть ліворуч від пари): взаємне розташування пар `(z, x)` та `(z, y)` до обміну було `(m, k)` та `(m, k+1)`. Після обміну воно стає `(m, k+1)` та `(m, k)`. В обох випадках `z` передує і `x`, і `y`. Тому статус інверсій для пар `(z, x)` та `(z, y)` не змінився.
2. Якщо `m > k + 1` (елемент `z` стоїть праворуч від пари): аналогічно, і `x`, і `y` передують `z` як до, так і після обміну. Статус інверсій не змінюється.
3. Для самої пари `(x, y)`: до обміну `x` стояв на позиції `k`, а `y` — на `k+1`. Оскільки `x > y`, пара `(x, y)` утворювала інверсію. Після обміну `y` стоїть на `k`, а `x` — на `k+1`. Оскільки `y < x`, пара `(y, x)` більше не утворює інверсії.

Отже, жодна інверсія за участю інших елементів не з'явилася і не зникла, а інверсія між `x` та `y` була ліквідована. Кількість інверсій зменшилася строго на `1`.

**Наслідок:** Оскільки сортування вставками під час просування ключа вліво виконує послідовність суміжних зсувів елементів, кожен зсув ліквідує рівно одну інверсію. Звідси випливає, що **загальна кількість операцій зсуву комірок масиву за весь час роботи алгоритму строго дорівнює початковій кількості інверсій `I` у вхідному масиві**.

Часова складність алгоритму визначається як:

```
T(n) = c₁ · n + c₂ · I = O(n + I)
```

де `c₁` — накладні витрати на зовнішній цикл (перевірка межі, виймання ключа), а `c₂` — вартість одного внутрішнього зсуву та порівняння.

## 5. Відстань Кендалла (Kendall tau distance)

Поняття кількості інверсій безпосередньо пов'язане з метрикою тау-відстані Кендалла (Maurice Kendall, 1938), яка вимірює ступінь несхожості між двома довільними перестановками `σ, π ∈ Sₙ`.

Відстань Кендалла `K(σ, π)` визначається як кількість пар елементів, на яких перестановки мають протилежний відносний порядок:

```
K(σ, π) = ∑ [ (σ(i) - σ(j)) · (π(i) - π(j)) < 0 ]   [сума за 1 ≤ i < j ≤ n]
```

Якщо одна з перестановок є тотожною (впорядкованою) `id = (1, 2, ..., n)`, відстань Кендалла точно збігається з кількістю інверсій:

```
K(π, id) = I(π)
```

Метрика Кендалла задовольняє всі аксіоми метричного простору:
1. `K(σ, π) ≥ 0`, причому `K(σ, π) = 0 ⇔ σ = π` (невід'ємність та тотожність);
2. `K(σ, π) = K(π, σ)` (симетричність);
3. `K(σ, ρ) ≤ K(σ, π) + K(π, ρ)` (нерівність трикутника).

У термінах метричних просторів сортування вставками можна інтерпретувати як побудову найкоротшого геодезичного шляху в графі Келі симетричної групи `Sₙ` (із генераторами у вигляді суміжних транспозицій `(k, k+1)`) від вершини початкового стану `π` до вершини цільового стану `id`.

## 6. Формальне доведення інваріанта циклу за Хоаром

Для доведення коректності алгоритму сортування вставками сформулюємо предикат інваріанта зовнішнього циклу (Loop Invariant).

Нехай `A[0...n-1]` — масив, що сортується.

**Інваріант `Inv(i)`:** На початку кожної ітерації зовнішнього циклу для фіксованого індексу `i` (де `1 ≤ i ≤ n`):
1. Підмасив `A[0...i-1]` складається з тих самих елементів, які початково займали позиції від `0` до `i-1` (тобто є їхньою перестановкою);
2. Підмасив `A[0...i-1]` є повністю впорядкованим: `A[0] ≤ A[1] ≤ A[2] ≤ ... ≤ A[i-1]`.

Доведемо коректність за класичною схемою індукції Флойда–Хоара:

### База індукції (ініціалізація, `i = 1`)
Перед першою ітерацією зовнішнього циклу `i = 1`. Підмасив `A[0...0]` містить рівно один елемент. Будь-яка послідовність із одного елемента є тривіально впорядкованою і складається з елементів вихідного підмасиву на позиції `0`. Предикат `Inv(1)` істинний.

### Індукційний крок (збереження, `Inv(i) ⇒ Inv(i+1)`)
Припустимо, що предикат `Inv(i)` виконується. На кроці `i` алгоритм копіює значення `key = A[i]`.
Внутрішній цикл послідовно порівнює `key` з елементами `A[j]` (для `j = i-1, i-2, ...`):
- Якщо `A[j] > key`, елемент `A[j]` зсувається на позицію `j+1`.
- Цикл зупиняється на першому індексі `j`, для якого виконується умова `A[j] ≤ key`, або коли `j` досягає значення `-1` (усі елементи більші за `key`).

Позначимо індекс зупинки через `p = j + 1` (де `0 ≤ p ≤ i`).
Усі елементи `A[p...i-1]`, які були більшими за `key`, змістилися на один осередок вправо на позиції `A[p+1...i]`. Комірка `A[p]` звільнилася, і в неї записується значення `key`.

Оскільки до початку ітерації підмасив `A[0...i-1]` був впорядкований:
- Для всіх `0 ≤ k < p` виконується `A[k] ≤ key` (бо цикл зупинився на `A[p-1] ≤ key`);
- Для всіх `p < k ≤ i` виконується `key < A[k]` (бо ці елементи були зсунуті як строго більші за `key`).

Отже, після вставки масив задовольняє умову `A[0] ≤ ... ≤ A[p-1] ≤ A[p] ≤ A[p+1] ≤ ... ≤ A[i]`. Підмасив `A[0...i]` містить усі елементи з `A[0...i-1]` плюс новий елемент `key`, тобто є їхньою впорядкованою перестановкою. Предикат `Inv(i+1)` істинний.

### Завершення циклу (`i = n`)
Зовнішній цикл завершує роботу, коли лічильник `i` досягає значення `n`.
Згідно зі збереженням інваріанта, підмасив `A[0...n-1]` містить усі вихідні елементи масиву від індексу `0` до `n-1` і є повністю відсортованим: `A[0] ≤ A[1] ≤ ... ≤ A[n-1]`.

Коректність алгоритму сортування вставками математично доведена.

## 7. Твірна функція інверсій та q-аналог факторіала (формула Магона)

Найглибший аналіз розподілу кількості інверсій у комбінаториці забезпечує використання апарату твірних функцій.

Нехай `I_n(q) = ∑_{π ∈ S_n} q^{I(π)}` — поліноміальна твірна функція для кількості інверсій на симетричній групі `S_n`. Коефіцієнт при `q^k` у цьому многочлені дорівнює точній кількості перестановок із `n` елементів, що мають рівно `k` інверсій (відомі як числа Магона, Mahonian numbers).

Використовуючи незалежність компонент коду Лемера `c_j ∈ {0, 1, ..., j - 1}`, твірна функція суми незалежних величин розкладається в добуток твірних функцій окремих компонент:

```
I_n(q)
= ∏ (1 + q + q² + ... + q^{j-1})  [добуток геометричних прогресій для j від 1 до n]
= [n]_q!                          [визначення q-факторіала (q-analog of factorial)]
```

де кожна дужка `[j]_q = 1 + q + q² + ... + q^{j-1} = (1 - q^j) / (1 - q)` є класичним q-числом Гаусса–Магона.

Ця елегантна формула дозволяє обчислювати статистичні моменти розподілу інверсій безпосередньо через логарифмічне диференціювання твірної функції:

1. **Нормалізація:** Поклавши `q = 1`, отримуємо загальну кількість перестановок:
```
I_n(1) = 1 · 2 · 3 · ... · n = n!
```

2. **Математичне сподівання через похідну:**
Ймовірнісна твірна функція має вигляд `G_n(q) = I_n(q) / n! = ∏_{j=1}^n ( (1 + q + ... + q^{j-1}) / j )`.
Обчислимо логарифмічну похідну `G_n'(1)`:
```
E[I]
= G_n'(1)                                             [значення похідної твірної функції при q=1]
= ∑ [ (d/dq) ((1 + q + ... + q^{j-1}) / j) ] |_{q=1} [диференціювання добутку твірних функцій]
= ∑ ( (0 + 1 + 2 + ... + (j - 1)) / j )               [підстановка q=1 у степеневі члени]
= ∑ ( (j - 1) / 2 )                                   [формула суми арифметичної прогресії]
= n · (n - 1) / 4                                     [підсумовування за j від 1 до n]
```

3. **Дисперсія через другу похідну:**
Аналогічно, обчислення другої логарифмічної похідної `G_n''(1) + G_n'(1) - (G_n'(1))²` дає точний вираз для дисперсії: `n(n - 1)(2n + 5) / 72`.

Твірна функція Магона також доводить, що розподіл кількості інверсій є строго симетричним відносно свого центру `M = n(n - 1) / 4` (поліном є унімодальним та симетричним: коефіцієнт при `q^k` дорівнює коефіцієнту при `q^{M - k}`). При `n → ∞` стандартизований розподіл інверсій за центральною граничною теоремою для незалежних величин Ляпунова асимптотично збігається до класичного нормального (гауссового) розподілу `N(0, 1)`.

## 8. Теоретико-інформаційна межа бінарних вставок

У модифікації Binary Insertion Sort місце вставки елемента `A[i]` у відсортований префікс `A[0...i-1]` визначається за допомогою двійкового пошуку.

Оскільки префікс містить `i` елементів, існує рівно `i + 1` можливих точок вставки (перед першим елементом, між будь-якими двома сусідніми або після останнього). Для однозначного визначення однієї з `i + 1` альтернатив алгоритм порівнянь повинен розрізнити `i + 1` листків у дереві рішень.

Згідно з інформаційною ентропією Шеннона, мінімальна кількість бінарних порівнянь для вибору серед `i + 1` варіантів становить:

```
C_i = ⌈log₂ (i + 1)⌉
```

Підсумуємо кількість порівнянь, необхідних для впорядкування всього масиву з `n` елементів від `i = 1` до `n - 1`:

```
C_total
= ∑ ⌈log₂ (i + 1)⌉         [сума для i від 1 до n - 1]
= ∑ ⌈log₂ k⌉               [заміна індексу k = i + 1 від 2 до n]
= ⌈log₂ (n!)⌉              [логарифм факторіала цілих чисел]
```

Застосуємо асимптотичне наближення Стірлінга для факторіала `ln(n!) = n ln n - n + O(log n)`:

```
C_total
= log₂ (n!)                             [загальна кількість порівнянь]
= ln(n!) / ln 2                         [перехід до натурального логарифма]
= (n ln n - n + O(log n)) / ln 2        [підстановка асимптотики Стірлінга]
= n log₂ n - n · log₂ e + O(log n)      [розподіл знаменника ln 2]
= n log₂ n - 1.442695 · n + O(log n)    [обчислення константи log₂ e]
```

Звідси випливають три фундаментальні математичні висновки:
1. **Асимптотична оптимальність за порівняннями:** Binary Insertion Sort виконує `n log₂ n + O(n)` порівнянь, що досягає теоретико-інформаційного бар'єру `Ω(n log n)` для будь-яких алгоритмів сортування порівняннями.
2. **Втрата чутливості до початкового порядку:** На відміну від лінійних вставок, де кількість порівнянь на відсортованому масиві становить `n - 1`, двійковий пошук завжди змушений виконати всі `⌈log₂ (i + 1)⌉` перевірок, щоб локалізувати точку вставки. Тому для Binary Insertion Sort кількість порівнянь у найкращому, середньому та найгіршому випадках завжди становить `Θ(n log n)`.
3. **Незмінність квадратичних зсувів:** Хоча кількість порівнянь скорочується до `O(n log n)`, загальна кількість фізичних переміщень елементів у пам'яті визначається виключно кількістю інверсій `I` і в найгіршому випадку залишається рівною `n(n - 1) / 2 = O(n²)`.

## 9. Аналіз складності на k-майже відсортованих послідовностях

У багатьох прикладних системах зустрічаються масиви, які є локально збуреними: елементи не віддаляються занадто далеко від своїх фінальних позицій у відсортованому стані.

**Означення k-майже відсортованого масиву:** Масив `A[0...n-1]` називається `k`-майже відсортованим (або `k`-зсунутим), якщо для кожного елемента з початковим індексом `i` його остаточний індекс `π(i)` у відсортованому масиві задовольняє умову:

```
|i - π(i)| ≤ k
```

де `k` — фіксована додатна константа або параметр масштабу (`k ≪ n`).

Оцінимо максимальну кількість інверсій у такому масиві:
- Кожен елемент `A[i]` може брати участь в інверсіях лише з елементами, розташованими на відстані не більше ніж `2k` позицій від нього.
- Кількість інверсій, утворених одним елементом, не перевищує `2k`.
- Сумарна кількість інверсій для всього масиву обмежена зверху величиною:
```
I(A) ≤ k · n
```

Оскільки часова складність класичного сортування вставками становить `T(n) = O(n + I)`, підстановка обмеження на кількість інверсій дає:

```
T(n) = O(n + k · n) = O(k · n)
```

**Теорема про лінійність:** Якщо ступінь збурення `k` є константою відносно розміру масиву (наприклад, `k ≤ 10` при `n = 1 000 000`), сортування вставками виконує сортування за **строго лінійний час `O(n)`**, перевершуючи будь-які неадаптивні алгоритми `O(n log n)` як теоретично, так і практично.
