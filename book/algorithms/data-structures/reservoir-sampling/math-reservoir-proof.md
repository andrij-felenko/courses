# 🧮 Математичний апарат вибірки з резервуара: індукція, стрибки та ваги

Коли обчислювальна система отримує потік даних із невідомою загальною кількістю елементів `N`, класичні комбінаторні методи вибору випадкової підмножини виявляються безсилими. Класична схема вимагає спочатку згенерувати випадкові індекси в діапазоні від `1` до `N`, що неможливо без знання точного значення `N`. Якщо ж спробувати наївно включати кожен вхідний елемент із фіксованою ймовірністю `p`, розмір результуючої вибірки виявиться випадковою величиною з біноміальним розподілом, математичне сподівання якої дорівнює `p · N`, а дисперсія — `p · (1 - p) · N`. У результаті вибірка або переповнить виділений буфер пам'яті, або виявиться занадто малою для статистичного аналізу.

Математична задача вибірки з резервуара (Reservoir Sampling) полягає у формуванні детермінованого за розміром масиву з рівно `k` елементів (`k ≤ N`) таким чином, щоб у будь-який момент часу `n ≥ k` кожен із уже оброблених елементів `x_1, x_2, ..., x_n` перебував у вибірці з абсолютно однаковою ймовірністю `P(x_i ∈ R_n) = k/n`, а всі можливі комбінації підмножин потужності `k` мали однакову ймовірність реалізації.

## Формалізація інваріанта потокового стану

Нехай `X = (x_1, x_2, ..., x_n, ...)` — нескінченна або скінченна послідовність елементів потоку.
Позначимо через `R_n` стан резервуара після надходження перших `n` елементів.

Для будь-якого кроку `n ≥ k` резервуар `R_n` є підмножиною множини `X_n = {x_1, x_2, ..., x_n}`, що задовольняє дві умови:
1. Потужність підмножини строго фіксована: `|R_n| = k`.
2. Гранична ймовірність включення для довільного елемента `x_i` (`1 ≤ i ≤ n`) дорівнює відношенню розміру резервуара до поточної довжини потоку:

```text
[інваріант рівномірного включення]
P(x_i ∈ R_n) = k / n
```

Крім того, для довільної фіксованої підмножини `S ⊂ X_n` потужністю `|S| = k` ймовірність того, що стан резервуара `R_n` збігається з `S`, мусить бути строго рівномірною:

```text
P(R_n = S) = 1 / C(n, k) = k! · (n - k)! / n!
```

## Доведення коректності алгоритму R методом математичної індукції

Алгоритм R (Вотермана — Кнута) визначає такі правила зміни стану:
* **Ініціалізація (`n = k`)**: перші `k` елементів розміщуються в резервуарі `R_k = {x_1, x_2, ..., x_k}`.
* **Перехід (`n → n + 1`)**: для елемента `x_{n+1}` генерується випадкове ціле число `j` із рівномірного дискретного розподілу `Uniform{1, 2, ..., n + 1}`.
  * Якщо `j ≤ k`, елемент `x_{n+1}` записується в комірку `R[j - 1]`, витісняючи старий елемент.
  * Якщо `j > k`, елемент `x_{n+1}` ігнорується, а стан `R_n` залишається незмінним.

Доведемо інваріант `P(x_i ∈ R_n) = k/n` для всіх `n ≥ k` та всіх `1 ≤ i ≤ n`.

### База індукції (`n = k`)

На кроці `n = k` резервуар містить усі `k` перших елементів потоку:

```text
R_k = {x_1, x_2, ..., x_k}
```

Для будь-якого `i ∈ {1, 2, ..., k}` подія `x_i ∈ R_k` є достовірною:

```text
P(x_i ∈ R_k) = 1
= k / k          [підстановка n = k]
```

База індукції виконується.

### Індукційне припущення

Припустимо, що на кроці `n` (де `n ≥ k`) інваріант виконується для кожного елемента `x_i` (`1 ≤ i ≤ n`), тобто:

```text
P(x_i ∈ R_n) = k / n
```

### Індукційний перехід (`n → n + 1`)

Розглянемо стан резервуара `R_{n+1}` після обробки нового елемента `x_{n+1}`. Необхідно довести, що для всіх `i ∈ {1, 2, ..., n + 1}` справджується рівність `P(x_i ∈ R_{n+1}) = k / (n + 1)`.

Розглянемо два випадки: новий елемент `x_{n+1}` та довільний старий елемент `x_i` (`1 ≤ i ≤ n`).

**Випадок 1: Новий елемент `x_{n+1}`.**
Елемент `x_{n+1}` потрапляє до `R_{n+1}` тоді й лише тоді, коли згенерований індекс `j ∈ {1, ..., n + 1}` задовольняє умову `j ≤ k`. Оскільки `j` розподілено рівномірно на множині потужністю `n + 1`, кількість сприятливих наслідків дорівнює `k`:

```text
P(x_{n+1} ∈ R_{n+1})
= P(j ≤ k)                      [визначення умови прийняття нового елемента]
= k / (n + 1)                   [рівномірний розподіл j на множині {1, ..., n+1}]
```

Для нового елемента твердження доведено.

**Випадок 2: Довільний старий елемент `x_i` (`1 ≤ i ≤ n`).**
Елемент `x_i` перебуває в резервуарі `R_{n+1}` тоді й лише тоді, коли виконуються дві одночасні умови:
1. Він уже перебував у резервуарі на кроці `n` (подія `A: x_i ∈ R_n`).
2. Він не був витіснений новим елементом `x_{n+1}` на кроці `n + 1` (подія `B`).

За формулою умовної ймовірності:

```text
P(x_i ∈ R_{n+1}) = P(x_i ∈ R_n) · P(x_i залишається в R_{n+1} | x_i ∈ R_n)
```

Елемент `x_i` буде витіснений з резервуара лише за умови, що одночасно:
* новий елемент `x_{n+1}` обрано для включення (ймовірність `k / (n + 1)`);
* із `k` наявних слотів резервуара випадковий вибір витіснення впав саме на слот, де зберігається `x_i`. Оскільки слот обирається рівномірно серед `k` можливих, умовна ймовірність становить `1/k`.

Ймовірність витіснення елемента `x_i`:

```text
P(x_i витіснено | x_i ∈ R_n)
= P(новий додано) · P(обрано слот x_i | новий додано)  [формула добутку умовних ймовірностей]
= (k / (n + 1)) · (1 / k)                             [підстановка ймовірностей додавання та вибору слота]
= 1 / (n + 1)                                         [скорочення множника k]
```

Відповідно, ймовірність збереження елемента `x_i` в резервуарі дорівнює:

```text
P(x_i залишається | x_i ∈ R_n)
= 1 - P(x_i витіснено | x_i ∈ R_n)   [ймовірність протилежної події]
= 1 - 1 / (n + 1)                    [підстановка розрахованої ймовірності витіснення]
= n / (n + 1)                        [зведення до спільного знаменника]
```

Підставляючи індукційне припущення та умовну ймовірність у формулу добутку, отримуємо:

```text
P(x_i ∈ R_{n+1})
= P(x_i ∈ R_n) · P(x_i залишається | x_i ∈ R_n)
= (k / n) · (n / (n + 1))     [скорочення спільного множника n]
= k / (n + 1)
```

Індукційний перехід доведено для всіх `1 ≤ i ≤ n + 1`. За принципом математичної індукції рівномірність вибірки зберігається на будь-якому кроці обробки потоку.

## Доведення рівноймовірності довільної підмножини (Joint Distribution)

Маргінальна рівноймовірність включення кожного окремого елемента `P(x_i ∈ R_n) = k/n` є необхідною, але недостатньою умовою повноцінної випадкової вибірки. Справжня випадкова вибірка вимагає, щоб будь-яка з `C(n, k)` можливих підмножин розміру `k` мала абсолютно однаковий шанс виявитися фінальним станом резервуара.

Доведемо за індукцією, що для будь-якої фіксованої підмножини `S ⊂ {x_1, x_2, ..., x_n}` потужністю `|S| = k` ймовірність її вибору дорівнює:

```text
P(R_n = S) = 1 / C(n, k) = (k! · (n - k)!) / n!
```

### База індукції (`n = k`)

При `n = k` існує лише одна підмножина потужністю `k` — вся множина `{x_1, ..., x_k}`. Кількість комбінацій `C(k, k) = 1`. Резервуар містить усі `k` елементів із ймовірністю `1 = 1 / C(k, k)`.

### Індукційний перехід

Припустимо, що на кроці `n` кожна підмножина з `n` елементів обирається з імовірністю `1 / C(n, k)`. Розглянемо фіксовану підмножину `S' ⊂ {x_1, ..., x_n, x_{n+1}}` потужністю `|S'| = k`.

Можливі два випадки залежно від того, чи містить `S'` новий елемент `x_{n+1}`:

**Випадок А: Підмножина `S'` НЕ містить новий елемент `x_{n+1}` (`x_{n+1} ∉ S'`).**
Це означає, що `S' ⊂ {x_1, ..., x_n}`. Стан `R_{n+1} = S'` досягається тоді й лише тоді, коли:
1. На попередньому кроці резервуар уже містив саме `S'` (ймовірність `1 / C(n, k)` за індукційним припущенням);
2. Новий елемент `x_{n+1}` був відкинутий (ймовірність `1 - k / (n + 1) = (n + 1 - k) / (n + 1)`).

Оскільки ці події умовно незалежні, загальна ймовірність дорівнює їхньому добутку:

```text
P(R_{n+1} = S')
= P(R_n = S') · P(x_{n+1} відкинуто)                  [правило множення незалежних подій]
= (1 / C(n, k)) · ((n + 1 - k) / (n + 1))             [підстановка індукційного припущення]
= ( (k! · (n - k)!) / n! ) · ((n + 1 - k) / (n + 1))  [розкриття формули біноміального коефіцієнта]
= (k! · (n + 1 - k)!) / (n + 1)!                      [перегрупування множників у факторіали]
= 1 / C(n + 1, k)                                     [згортання у вираз для C(n + 1, k)]
```

**Випадок Б: Підмножина `S'` МІСТИТЬ новий елемент `x_{n+1}` (`x_{n+1} ∈ S'`).**
Нехай `S' = S_0 ∪ {x_{n+1}}`, де `S_0 ⊂ {x_1, ..., x_n}` — деяка підмножина потужністю `|S_0| = k - 1`.
Щоб утворити конфігурацію `S'`, на кроці `n` резервуар мусив містити підмножину `S_0 ∪ {y}`, де `y` — довільний елемент із залишкової множини `{x_1, ..., x_n} \ S_0`. Кількість таких можливих кандидатів `y` становить `n - (k - 1) = n - k + 1`.

Для кожного фіксованого `y` перехід у стан `S'` відбувається, коли:
1. `R_n = S_0 ∪ {y}` (ймовірність `1 / C(n, k)`);
2. `x_{n+1}` приймається до резервуара (ймовірність `k / (n + 1)`);
3. Елемент `x_{n+1}` витісняє саме елемент `y` (ймовірність `1/k`).

Підсумовуючи по всіх `n - k + 1` взаємовиключних варіантах вибору `y`:

```text
P(R_{n+1} = S')
= ∑_{y} P(R_n = S_0 ∪ {y}) · P(прийнято x_{n+1}) · P(витіснено y)  [формула повної ймовірності по всіх y]
= (n - k + 1) · (1 / C(n, k)) · (k / (n + 1)) · (1 / k)            [підстановка значень для кожного з доданків]
= (n - k + 1) · ( (k! · (n - k)!) / n! ) · (1 / (n + 1))           [скорочення множника k]
= (k! · (n + 1 - k)!) / (n + 1)!                                   [об'єднання факторіалів у знаменнику]
= 1 / C(n + 1, k)                                                  [запис через біноміальний коефіцієнт]
```

В обох випадках ймовірність отримання будь-якої конкретної підмножини `S'` дорівнює `1 / C(n + 1, k)`. Це повністю доводить, що алгоритм генерує строго незміщену рівномірну вибірку без взаємних кореляцій між елементами.

## Статистичні характеристики кількості замін

Позначимо через `I_m` індикаторну випадкову величину того, що `m`-й елемент потоку (`m > k`) потрапив до резервуара:

```text
I_m = 1, якщо j ≤ k (елемент замінив слот у резервуарі)
I_m = 0, якщо j > k (елемент відкинуто)
```

Розподіл величини `I_m` є розподілом Бернуллі з параметром успіху:

```text
p_m = P(I_m = 1) = k / m
```

Загальна кількість операцій оновлення резервуара після надходження `N` елементів становить:

```text
T_N = k + ∑_{m=k+1}^N I_m
```

### Математичне сподівання кількості замін

За лінійністю математичного сподівання:

```text
E[T_N]
= k + ∑_{m=k+1}^N E[I_m]        [лінійність математичного сподівання]
= k + k · ∑_{m=k+1}^N (1 / m)   [підстановка математичного сподівання індикатора]
= k · (1 + H_N - H_k)           [запис суми через гармонічні числа]
```

де `H_N = ∑_{m=1}^N (1/m)` — `N`-те гармонічне число. Використовуючи асимптотичний розклад `H_N = ln(N) + γ + O(1/N)` (де `γ ≈ 0.57721` — стала Ейлера — Маскероні), отримуємо:

```text
E[T_N] ≈ k · (1 + ln(N / k))
```

### Дисперсія кількості замін

Оскільки події заміни на різних кроках `m` є взаємно незалежними випадковими величинами, дисперсія суми дорівнює сумі дисперсій:

```text
Var(T_N)
= ∑_{m=k+1}^N Var(I_m)                  [дисперсія суми незалежних індикаторів]
= ∑_{m=k+1}^N p_m · (1 - p_m)           [дисперсія бернуллівської величини I_m]
= ∑_{m=k+1}^N (k / m) · (1 - k / m)     [підстановка p_m = k / m]
= k · (H_N - H_k) - k² · ∑_{m=k+1}^N (1 / m²)  [розкриття дужок через гармонічні числа]
```

Оскільки ряд `∑_{m=1}^∞ (1 / m²) = π² / 6` збігається, дисперсія також зростає логарифмічно:

```text
Var(T_N) ≈ k · ln(N / k) - O(k²)
```

Це доводить, що кількість оновлень пам'яті резервуара зростає надзвичайно повільно (логарифмічно від довжини потоку), що робить алгоритм асимптотично стабільним.

## Математичне моделювання інтервалу пропуску (Алгоритм L та Z)

Низька ефективність алгоритму R зумовлена тим, що при `N ≫ k` величина `p_m = k/m` прямує до нуля, проте генератор випадкових чисел викликається на кожному кроці.

Нехай на кроці `n` відбулася заміна. Визначимо випадкову величину `S` — кількість послідовних елементів, які будуть пропущені до наступної заміни в резервуарі. Подія `S = s` означає, що елементи `x_{n+1}, x_{n+2}, ..., x_{n+s}` були відкинуті, а елемент `x_{n+s+1}` був прийнятий.

Ймовірність того, що інтервал пропуску перевищує `s` кроків (`S > s`), дорівнює добутку ймовірностей відкидання:

```text
P(S > s) = ∏_{j=1}^{s+1} (1 - k / (n + j))
= ∏_{j=1}^{s+1} ((n + j - k) / (n + j))
```

Розкриваючи телескопічний добуток:

```text
P(S > s)
= ((n + 1 - k) · (n + 2 - k) · ... · (n + s + 1 - k)) / ((n + 1) · (n + 2) · ... · (n + s + 1))  [розкриття добутку дробів]
= ( (n + s + 1 - k)! / (n - k)! ) / ( (n + s + 1)! / n! )                                       [перехід до факторіальних виразів]
= (n! / (n - k)!) / ( (n + s + 1)! / (n + s + 1 - k)! )                                         [групування чисельника та знаменника]
```

У неперервному наближенні Віттера ця функція моделюється через степеневий закон `(1 - W)^s`, де `W = exp(ln(U) / k)` — вагова випадкова величина з бета-розподілу, а `U ~ Uniform(0, 1)`.

Застосовуючи метод зворотного перетворення функції розподілу (Inverse Transform Sampling), випадковий стрибок `S` обчислюється аналітично:

```text
U = (1 - W)^S
ln(U) = S · ln(1 - W)
S = ⌊ln(U) / ln(1 - W)⌋
```

Після виконання стрибка довжиною `S` лічильник потоку одразу збільшується на `S + 1`, елемент `x_{n + S + 1}` записується у випадковий слот `R[RandInt(0, k-1)]`, а параметр `W` оновлюється за правилом `W ← W · exp(ln(U_new) / k)`.

Це скорочує кількість викликів генератора випадкових чисел із `O(N)` до `O(k · log(N/k))`, зберігаючи абсолютну точність ймовірнісного розподілу.

## Математичне обґрунтування зваженої вибірки (A-Res)

У зваженій вибірці без повернення (WRS) кожен елемент `x_i` має вагу `w_i > 0`. Необхідно забезпечити, щоб на кожному кроці вибору ймовірність обрання елемента була пропорційною його вазі серед усіх ще не обраних елементів.

Алгоритм Ефраімідіса — Спіракіса генерує для кожного елемента випадковий ключ:

```text
k_i = u_i^(1 / w_i),  де u_i ~ Uniform(0, 1)
```

Перейдемо до логарифмічної шкали, визначивши трансформований ключ `r_i`:

```text
r_i = -ln(k_i) = -ln(u_i) / w_i
```

Оскільки `u_i ~ Uniform(0, 1)`, випадкова величина `E_i = -ln(u_i)` має стандартний експоненційний розподіл із параметром `λ = 1`:

```text
P(E_i ≤ t) = 1 - e^(-t),  t ≥ 0
```

Відповідно, величина `r_i = E_i / w_i` має експоненційний розподіл із параметром масштабу `w_i`:

```text
P(r_i > t) = P(E_i > w_i · t) = e^(-w_i · t)
```

Розглянемо множину з `m` незалежних випадкових величин `r_1, r_2, ..., r_m`, де `r_j ~ Exp(w_j)`. Знайдемо ймовірність того, що саме величина `r_i` виявиться найменшою серед усіх:

```text
P(r_i = min(r_1, ..., r_m))
= ∫_0^∞ P(r_i = t) · ∏_{j ≠ i} P(r_j > t) dt     [інтегрування за значенням мінімуму t]
= ∫_0^∞ (w_i · e^(-w_i · t)) · (∏_{j ≠ i} e^(-w_j · t)) dt  [густина r_i та функції виживання r_j]
= w_i · ∫_0^∞ e^(-(∑_{j=1}^m w_j) · t) dt        [об'єднання показників експонент]
= w_i / (∑_{j=1}^m w_j)                          [інтегрування експоненційної функції]
```

Це фундаментальна властивість експоненційного розподілу: **ймовірність того, що випадкова величина `r_i` досягне мінімуму першою, строго дорівнює нормалізованій вазі `w_i / W`**.

Завдяки властивості відсутності післядії експоненційного закону (Memoryless property), видалення мінімального елемента та вибір наступного мінімуму серед решти `m - 1` величин знову дає ймовірність, строго пропорційну вагам залишкової підмножини.

Отже, збереження `k` елементів із найменшими значеннями `r_i` (або, що еквівалентно, `k` елементів із найбільшими значеннями `k_i = u_i^(1/w_i)`) за допомогою мін-купи в точності генерує послідовну зважену випадкову вибірку без повернення в один прохід потоку.

## Степеневі порядкові статистики та еквівалентність A-Res

Проаналізуємо прямий розподіл випадкових ключів `k_i = u_i^(1 / w_i)` без логарифмування. Оскільки `u_i` розподілено рівномірно на `(0, 1)`, знайдемо функцію кумулятивного розподілу величини `k_i`:

```text
F_{k_i}(t) = P(k_i ≤ t) = P(u_i^(1 / w_i) ≤ t) = P(u_i ≤ t^{w_i}) = t^{w_i},  t ∈ (0, 1)
```

Диференціюючи за `t`, отримуємо густину ймовірності:

```text
f_{k_i}(t) = w_i · t^{w_i - 1}
```

Нехай у потоці надійшло `m` елементів із вагами `w_1, w_2, ..., w_m`. Ймовірність того, що елемент `x_i` матиме строго найбільший ключ серед усіх `m` елементів:

```text
P(k_i = max(k_1, ..., k_m))
= ∫_0^1 f_{k_i}(t) · (∏_{j ≠ i} F_{k_j}(t)) dt   [інтегрування за граничним значенням максимуму]
= ∫_0^1 (w_i · t^{w_i - 1}) · (∏_{j ≠ i} t^{w_j}) dt  [підстановка густини та функцій розподілу]
= ∫_0^1 w_i · t^{(∑_{j=1}^m w_j) - 1} dt         [зведення степенів t до спільної суми ваг]
= w_i · [ t^(∑ w_j) / (∑ w_j) ]_0^1              [первісна степеневої функції]
= w_i / (∑_{j=1}^m w_j)                          [підстановка меж інтегрування 0 та 1]
```

Це доводить, що найбільший ключ `k_i` належить елементу `x_i` з імовірністю, яка строго дорівнює відносній вазі елемента `w_i / W`.

Після знаходження першого елемента вибірки (максимальний ключ) умовний розподіл другого максимуму серед залишкових елементів знову підпорядковується тій самій теоремі для усіченого інтервалу, що гарантує точність послідовного вибору без повернення для всіх `k` слотів.

## Оцінювання сумарних характеристик потоку за вибіркою (Оцінювач Горвіца — Томпсона)

Коли вибірка з резервуара `R_N` розміру `k` сформована, постає задача оцінки суми деякої числової функції `f(x)` по всьому невідомому потоку `Y = ∑_{i=1}^N f(x_i)`.

Для рівномірної вибірки з резервуара (де `P(x_i ∈ R_N) = π_i = k / N`) незміщений статистичний оцінювач Горвіца — Томпсона (Horvitz — Thompson estimator) має вигляд:

```text
Ŷ = ∑_{x_i ∈ R_N} (f(x_i) / π_i) = (N / k) · ∑_{x_i ∈ R_N} f(x_i)
```

Перевіримо незміщеність оцінювача через індикаторні змінні включення `I_i = 1(x_i ∈ R_N)`:

```text
E[Ŷ]
= E[ ∑_{i=1}^N I_i · (f(x_i) / π_i) ]   [запис вибіркової суми через індикатори]
= ∑_{i=1}^N E[I_i] · (f(x_i) / π_i)     [лінійність математичного сподівання]
= ∑_{i=1}^N π_i · (f(x_i) / π_i)        [математичне сподівання індикатора дорівнює π_i]
= ∑_{i=1}^N f(x_i)                      [скорочення ймовірності π_i]
= Y                                     [справжнє значення суми по всьому потоку]
```

Математичне сподівання оцінювача строго збігається зі справжньою сумою потоку, що дозволяє отримувати незміщені агрегати (суми, середні значення, перцентилі) без збереження всього обсягу даних у пам'яті.

### Дисперсія та довірчі інтервали оцінювача

Дисперсія оцінювача Горвіца — Томпсона для вибірки без повернення залежить від коваріації включення пар елементів `π_{ij} = P(x_i ∈ R_N ∧ x_j ∈ R_N) = (k · (k - 1)) / (N · (N - 1))`:

```text
Var(Ŷ) = ∑_{i=1}^N ∑_{j=1}^N (π_{ij} - π_i · π_j) · (f(x_i) / π_i) · (f(x_j) / π_j)
```

Спрощуючи для фіксованого розміру `k`, формулу можна записати у вигляді Сеня — Єйтса — Гранді (Sen — Yates — Grundy):

```text
Var(Ŷ) = (1 / 2) · ∑_{i=1}^N ∑_{j=1}^N (π_i · π_j - π_{ij}) · (f(x_i) / π_i - f(x_j) / π_j)²
```

Оскільки `π_i · π_j - π_{ij} = (k / N)² - (k · (k - 1)) / (N · (N - 1)) = (k · (N - k)) / (N² · (N - 1)) > 0`, усі коефіцієнти є строго додатними. Це гарантує, що оцінювач дисперсії є стабільним та невід'ємним для будь-якого вхідного розподілу значень.

Застосовуючи нерівність Чебишова, для довільного `ε > 0` отримуємо граничну оцінку похибки вибіркового середнього:

```text
P(|Ŷ - Y| ≥ ε · Y) ≤ Var(Ŷ) / (ε² · Y²)
```

Це надає строге математичне обґрунтування вибору розміру резервуара `k`: для досягнення відносної похибки `ε` з надійністю `1 - δ` достатньо обрати `k = O(1 / (ε² · δ))`, незалежно від загальної довжини потоку `N`.

## Чисельна стійкість та арифметика в просторі логарифмів

Пряме обчислення ключа `k_i = u_i^(1 / w_i)` у стандартному 64-бітному форматі з плаваючою комою IEEE 754 стикається з катастрофічною втратою точності (underflow/overflow):
* Якщо вага елемента `w_i` велика (наприклад, `w_i = 1000`), значення `1 / w_i = 0.001`. Для будь-якого `u_i ∈ (0, 1)` степінь `u_i^0.001` лежить у надзвичайно вузькому діапазоні `[0.993, 1.0)`. Різниця між ключами різних елементів стає меншою за машинне епсилон `ε_mach ≈ 2.22 × 10^(-16)`, що призводить до хибного виродження ключів у `1.0` та втрати випадкового порядку.
* Якщо вага елемента крихітна (`w_i = 10^(-4)`), показник степеня `1 / w_i = 10 000` призводить до експоненційного зникнення `u_i^10000 → 0` (попадання в діапазон денормалізованих чисел).

Перехід до логарифмічних ключів `r_i = -ln(u_i) / w_i` повністю усуває цю проблему. Випадкова величина `-ln(u_i)` для `u_i ∈ (10^(-15), 1 - 10^(-15))` лежить у зручному діапазоні `[10^(-15), 34.5]`. Ділення на `w_i` зберігає повний динамічний діапазон чисел подвійної точності від `10^(-308)` до `10^308` без жодної втрати 53-бітної значущої мантиси.

## Теорема про злиття розподілених резервуарів

У розподілених системах потік ділиться між `M` незалежними вузлами. Нехай `m`-й вузол обробив фрагмент потоку довжиною `N_m` і сформував локальний резервуар `R^{(m)}` розміру `k` (де `∑_{m=1}^M N_m = N`).

Існує дві еквівалентні стратегії коректного агрегування:

### Стратегія 1: Паралельний алгоритм A-Res (найпростіша та універсальна)
Кожен вузол обчислює ключі `k_i = u_i^(1/w_i)` і зберігає локальний топ-`k`. Координатор збирає `M · k` пар `(k_i, x_i)` і знаходить загальний глобальний топ-`k`. Оскільки генерація ключів `k_i` не залежить від порядку обробки та розбиття на партиції, результат глобального топу строго еквівалентний однопоточному виконанню A-Res на об'єднаному потоці.

### Стратегія 2: Зважене злиття однорідних резервуарів
Якщо локальні вузли використовували звичайний алгоритм R (без збереження ключів), координатор може об'єднати `M` резервуарів, призначивши кожному елементу з резервуара `R^{(m)}` вагу `w = N_m / k`. Після цього координатор застосовує алгоритм A-Res для вибору фінальних `k` елементів.

Ймовірність потрапляння довільного елемента `x` із `m`-го вузла у фінальну вибірку:

```text
P(x ∈ R_final)
= P(x ∈ R^{(m)}) · P(обрано з R^{(m)} при злитті)            [формула добутку умовних ймовірностей]
= (k / N_m) · ( (N_m / k) / (∑_{j=1}^M (N_j / k) · k) ) · k  [підстановка зважених ймовірностей злиття]
= (k / N_m) · ( (N_m / k) / N ) · k                         [спрощення знаменника до повної суми N]
= k / N                                                     [скорочення проміжних множників N_m та k]
```

Таким чином, інваріант абсолютної рівномірності `k/N` строго зберігається при довільній кількості рівнів ієрархічного розподіленого агрегування (MapReduce / Spark tree reduce).
