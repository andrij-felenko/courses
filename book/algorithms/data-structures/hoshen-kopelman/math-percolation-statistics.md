# 🧮 Статистична теорія та математичний апарат перколаційних кластерів

У статистичній фізиці перколація на регулярних ґратках слугує базовою математичною моделлю для опису фазових переходів другого роду, критичних явищ та формування геометричних структур у невпорядкованих середовищах. Алгоритм Гошена–Копельмана розроблено саме як обчислювальний інструмент для вимірювання статистичних моментів розподілу кластерів. Без строгого математичного апарату розподілу за розмірами, радіуса гірації та кореляційної довжини чисельні мітки, отримані алгоритмом, залишаються лише масивом цілих чисел.

Нижче наведено формальне математичне виведення величин, які безпосередньо обчислюються на основі результатів маркування ґратки.

## 1. Формалізація ґратки та мікростанів

Розглянемо `d`-вимірну регулярну гіперкубічну ґратку `Λ` розміром `L^d` вузлів із періодичними або відкритими граничними умовами. Загальна кількість вузлів дорівнює `N = L^d`.

Кожен вузол `i ∈ Λ` описується бінарною випадковою величиною `t_i ∈ {0, 1}`:
- `t_i = 1` (вузол зайнятий) з імовірністю `p`;
- `t_i = 0` (вузол порожній) з імовірністю `1 - p`.

Усі випадкові величини `t_i` є взаємно незалежними та однаково розподіленими (схема Бернуллі). Ймовірність реалізації конкретного мікростану ґратки `T = {t_1, t_2, ..., t_N}` із загальною кількістю зайнятих вузлів `N_occ = ∑ t_i` визначається формулою:

```
P(T)
= p^(N_occ) · (1 - p)^(N - N_occ)    [ймовірність незалежних подій Бернуллі]
```

Два зайняті вузли `i, j ∈ Λ` називаються сусідніми, якщо евклідова відстань між ними дорівнює періоду ґратки `|r_i - r_j| = 1` (для 4-зв'язності у 2D або 6-зв'язності у 3D). Кластером `C` розміру `s` називається максимальна зв'язана підмножина зайнятих вузлів `C ⊆ Λ`, така що між будь-якими двома вузлами `u, v ∈ C` існує неперервний шлях із сусідніх зайнятих вузлів, що належать `C`.

## 2. Точні комбінаторні поліноми для малих кластерів

Для малих розмірів кластерів `s` питома концентрація `n_s(p)` може бути обчислена аналітично через геометричний периметр кластера. Периметром `t` називається кількість порожніх вузлів ґратки, що безпосередньо межують із вузлами даного кластера.

Ймовірність появи кластера розміру `s` із периметром `t` пропорційна `p^s · (1 - p)^t`. Загальна формула комбінаторного розкладу має вигляд:

```
n_s(p)
= ∑_{t} g_{s, t} · p^s · (1 - p)^t    [сума за всіма неізоморфними конфігураціями периметра]
```

де `g_{s, t}` — кількість топологічно різних конфігурацій кластера розміру `s` із периметром `t` на один вузол ґратки.

Розглянемо точні аналітичні вирази для квадратної ґратки (`d = 2`, координаційне число `z = 4`):

1. **Мономер (одиночний вузол, `s = 1`)**:
Одиночний вузол вимагає, щоб сам вузол був зайнятий (ймовірність `p`), а всі його 4 сусіди були порожніми (ймовірність `(1 - p)^4`). Оскільки конфігурація єдина (`g_{1, 4} = 1`), маємо:

```
n_1(p)
= p · (1 - p)⁴    [одиночний зайнятий вузол в оточенні 4 порожніх]
```

2. **Димер (кластер із двох вузлів, `s = 2`)**:
Два вузли можуть утворювати горизонтальну або вертикальну пару (2 орієнтації на вузол, `g_{2, 6} = 2`). Периметр такого димера складається з 6 порожніх сусідніх вузлів:

```
n_2(p)
= 2 · p² · (1 - p)⁶    [пара сусідніх вузлів у двох орієнтаціях]
```

3. **Тример (кластер із трьох вузлів, `s = 3`)**:
Кластер із трьох вузлів може мати лінійну форму (2 орієнтації: горизонтальна і вертикальна, периметр `t = 8`) або кутову L-подібну форму (4 орієнтації, периметр `t = 7`):

```
n_3(p)
= 2 · p³ · (1 - p)⁸ + 4 · p³ · (1 - p)⁷    [сума лінійних та кутових тримерів]
= 2 · p³ · (1 - p)⁷ · ((1 - p) + 2)         [винесення спільного множника]
= 2 · p³ · (1 - p)⁷ · (3 - p)               [зведення подібних доданків]
```

4. **Тетрамер (кластер із чотирьох вузлів, `s = 4`)**:
Включає лінійні смуги (`t = 10`), T-подібні трійники (`t = 9`), L-подібні куточки (`t = 9`), зигзаги (`t = 9`) та квадратні блоки `2 × 2` (`t = 8`):

```
n_4(p)
= p⁴ · (1 - p)⁸ · (1 + 12 · (1 - p) + 11 · (1 - p)²)    [повний поліном конфігурацій тетрамера]
```

Алгоритм Гошена–Копельмана при малому заповненні `p ≪ 1` емпірично відтворює ці поліноми, слугуючи тестом на коректність реалізації структури даних.

## 3. Точний розв'язок для одновимірної ґратки (d = 1)

В одновимірному ланцюжку вузлів довжиною `L` кластер розміру `s` — це неперервний відрізок із `s` зайнятих вузлів, обмежений з обох боків порожніми вузлами.

Ймовірність знайти такий кластер, що починається в довільному фіксованому вузлі, дорівнює добутку ймовірностей `p^s` (для `s` зайнятих вузлів) та `(1 - p)²` (для двох граничних порожніх вузлів):

```
n_s(p)
= p^s · (1 - p)²    [точний розподіл для одновимірного ланцюжка]
```

Перевіримо баланс повної маси системи, підсумувавши частку вузлів у всіх кластерах:

```
∑_{s=1}^∞ s · n_s(p)
= (1 - p)² · ∑_{s=1}^∞ s · p^s                           [винесення множника (1-p)²]
= (1 - p)² · p · d/dp [∑_{s=0}^∞ p^s]                    [диференціювання геометричного ряду]
= (1 - p)² · p · d/dp [1 / (1 - p)]                      [сума геометричної прогресії 1/(1-p)]
= (1 - p)² · p · (1 / (1 - p)²)                          [похідна d/dp (1-p)⁻¹ = (1-p)⁻²]
= p                                                      [скорочення множника (1-p)²]
```

Оскільки сума рівна `p` для всіх `p < 1`, потужність нескінченного кластера `P_inf(p) = p - p = 0`. Нескінченний кластер в 1D з'являється лише при абсолютному заповненні `p = 1`, тобто критичний поріг `p_c = 1`.

Обчислимо середній розмір кластера `S(p)` в одновимірному випадку:

```
M_2(p)
= ∑_{s=1}^∞ s² · n_s(p)                                  [визначення другого моменту]
= (1 - p)² · ∑_{s=1}^∞ s² · p^s                          [винесення (1-p)²]
= (1 - p)² · (p · (1 + p) / (1 - p)³)                    [сума ряду ∑ s² p^s]
= p · (1 + p) / (1 - p)                                  [скорочення (1-p)²]
```

Тоді середній розмір кластера дорівнює:

```
S(p)
= M_2(p) / M_1(p)                                        [відношення моментів S = M_2 / M_1]
= (p · (1 + p) / (1 - p)) / p                            [підстановка M_1 = p]
= (1 + p) / (1 - p)                                      [скорочення p]
```

При наближенні до критичної точки `p → 1⁻` позначимо відхилення `ε = 1 - p = p_c - p`:

```
S(p)
= (2 - ε) / ε                                            [підстановка p = 1 - ε]
= 2 / ε - 1                                              [почленне ділення]
≈ 2 · (p_c - p)⁻¹                                        [асимптотика при ε → 0]
```

Звідси для одновимірної системи критичний індекс сприйнятливості дорівнює `γ = 1`.

## 4. Точний розв'язок на дереві Бете (гратці Келі)

Дерево Бете з координаційним числом `z` (де кожен вузол має `z` сусідів без замкнених циклів) є класичною моделлю середнього поля для перколації.

Розглянемо ймовірність `Q` того, що рухаючись уздовж фіксованого ребра від обраного вузла, ми не потрапимо в нескінченний кластер. Для цього сайт на кінці ребра повинен бути або порожнім (ймовірність `1 - p`), або зайнятим (ймовірність `p`), але жодна з його решти `z - 1` вихідних гілок не повинна вести до нескінченності (ймовірність `Q^(z-1)`).

Отримуємо самоузгоджене трансцендентне рівняння:

```
Q
= (1 - p) + p · Q^(z - 1)    [рівняння самоузгодження для дерева Бете]
```

Тривіальний розв'язок `Q = 1` відповідає відсутності нескінченного кластера (`p ≤ p_c`). Нетривіальний розв'язок `Q < 1` з'являється в точці біфуркації, де похідна правої частини по `Q` при `Q = 1` стає рівною 1:

```
d/dQ [(1 - p) + p · Q^(z - 1)]|_{Q=1}
= p · (z - 1) · 1^(z - 2)    [взяття похідної степеневої функції]
= p · (z - 1)                [спрощення 1^(z-2) = 1]
= 1                          [умова біфуркації критичної точки]
```

Звідси поріг перколації на дереві Бете виражається строго:

```
p_c
= 1 / (z - 1)    [критичний поріг перколації на дереві Бете]
```

Для дерева Бете критичні індекси збігаються з теорією середнього поля Ландау: `β = 1`, `γ = 1`, `σ = 1/2`, `τ = 5/2`.

## 5. Розподіл кластерів за розмірами та масштабна гіпотеза Стауффера

У просторах скінченної розмірності `d = 2, 3` наявність замкнених циклів унеможливлює точний аналітичний розв'язок для всіх `p`. Поблизу критичної точки `p ≈ p_c` розміри кластерів зазнають сильних флуктуацій. Згідно з масштабною гіпотезою Дітріха Стауффера (1975), розподіл кластерів `n_s(p)` для великих `s` описується універсальною асимптотичною функцією:

```
n_s(p)
= s^(-τ) · f((p - p_c) · s^σ)    [масштабний анзац Стауффера]
```

де:
- `τ` (індекс Фішера) — критичний показник спадання розподілу кластерів у самій точці перколації `p = p_c`;
- `σ` — критичний показник відсікання, що визначає характерний максимальний розмір скінченних кластерів `s_max ∝ |p - p_c|^(-1/σ)`;
- `f(z)` — універсальна безрозмірна масштабна функція.

Аналітичні властивості функції `f(z)`:
1. При `z = 0` (тобто `p = p_c`) функція прямує до константи `f(0) = A = const`, звідки маємо чистий степеневий закон:

```
n_s(p_c)
= A · s^(-τ)    [розподіл кластерів у критичній точці]
```

2. При `|z| ≫ 1` функція швидко прямує до нуля за експоненційним або суб-експоненційним законом:

```
f(z)
≈ exp(-B · |z|^θ)    [експоненційне відсікання при відхиленні від p_c]
```

Для двовимірних систем (`d = 2`) конформна теорія поля дає точні раціональні значення індексів:
```
τ = 187 / 91 ≈ 2.0549
σ = 36 / 91  ≈ 0.3956
```

## 6. Статистичні моменти розподілу та середня маса кластера

Алгоритм Гошена–Копельмана після підрахунку масиву розмірів усіх кластерів дозволяє безпосередньо обчислити статистичні моменти `M_k(p)`:

```
M_k(p)
= ∑_{s=1}^∞ s^k · n_s(p)    [визначення k-го моменту розподілу]
```

Розглянемо фізичний зміст перших трьох моментів:

1. **Нульовий момент `M_0(p)`** — загальна питома кількість кластерів на один вузол:
```
M_0(p)
= ∑_{s=1}^∞ n_s(p) = N_clusters / N    [повна кількість кластерів на вузол]
```

2. **Перший момент `M_1(p)`** — середня частка вузлів, що перебувають у скінченних кластерах:
```
M_1(p)
= ∑_{s=1}^∞ s · n_s(p) = p - P_inf(p)    [маса скінченних кластерів]
```

3. **Другий момент `M_2(p)`** — визначає середній розмір кластера `S(p)`, до якого потрапляє випадково обраний зайнятий вузол (за винятком нескінченного кластера):

```
S(p)
= ⟨s⟩ = (∑ s · w_s(p)) / (∑ w_s(p))          [визначення середньозваженого розміру]
= (∑ s² · n_s(p)) / (∑ s · n_s(p))           [підстановка w_s = s · n_s]
= M_2(p) / M_1(p)                            [відношення другого моменту до першого]
```

Поведінка середнього розміру кластера `S(p)` поблизу критичної точки `p_c` демонструє степеневу розбіжність, аналогічну магнітній сприйнятливості у феромагнетиках:

```
S(p)
∝ |p - p_c|^(-γ)    [критична розбіжність середнього розміру кластера]
```

Виведемо зв'язок між критичним індексом `γ` та масштабними індексами `τ, σ`. Для цього підставимо масштабний анзац `n_s(p) = s^(-τ) f(z)` у вираз для другого моменту:

```
M_2(p)
= ∑_{s=1}^∞ s² · s^(-τ) · f((p - p_c) · s^σ)                                           [підстановка анзацу Стауффера]
≈ ∫₀^∞ s^(2 - τ) · f((p - p_c) · s^σ) ds                                               [перехід до неперервного інтеграла]
= ∫₀^∞ (z / (p - p_c))^((2 - τ)/σ) · f(z) · (1/σ) · (p - p_c)^(-1/σ) · z^(1/σ - 1) dz [заміна z = (p - p_c) · s^σ]
= (p - p_c)^(-(3 - τ)/σ) · (1/σ) · ∫₀^∞ z^((3 - τ - σ)/σ) · f(z) dz                   [винесення множника (p - p_c)]
= C · |p - p_c|^(-(3 - τ)/σ)                                                           [інтеграл по z є безрозмірною константою C]
```

Порівнюючи отриманий степінь із визначенням `S(p) ∝ |p - p_c|^(-γ)`, отримуємо точне співвідношення скейлінгу:

```
γ
= (3 - τ) / σ                [скейлінгове співвідношення для індексу сприйнятливості]
= (3 - 187/91) / (36/91)     [підстановка τ = 187/91 та σ = 36/91]
= (86/91) / (36/91)          [обчислення чисельника 3 · 91 - 187 = 86]
= 86 / 36                    [скорочення знаменника 91]
= 43 / 18 ≈ 2.3889           [скорочення на 2]
```

Аналогічно виводиться співвідношення для показника потужності нескінченного кластера `β`:

```
β
= (τ - 2) / σ                [індекс потужності нескінченного кластера]
= (187/91 - 2) / (36/91)     [підстановка значень індексів]
= (5/91) / (36/91)           [обчислення чисельника 187 - 182 = 5]
= 5 / 36 ≈ 0.1389            [скорочення знаменника 91]
```

## 7. Радіус гірації та кореляційна довжина

Для кількісного опису просторової протяжності та геометричної форми кластера розміру `s` використовується радіус гірації `R_s` (radius of gyration).

Нехай кластер `C` складається із `s` вузлів із радіус-векторами `{r_1, r_2, ..., r_s}`. Центр мас кластера `r_cm` визначається як:

```
r_cm
= (1 / s) · ∑_{i=1}^s r_i    [центр мас кластера]
```

Квадрат радіуса гірації `R_s²` визначається як середньоквадратична відстань вузлів кластера від його центру мас:

```
R_s²
= (1 / s) · ∑_{i=1}^s |r_i - r_cm|²    [визначення через центр мас]
```

Еквівалентно, `R_s²` можна виразити через попарні відстані між усіма парами вузлів кластера без явного обчислення центру мас:

```
R_s²
= (1 / (2 · s²)) · ∑_{i=1}^s ∑_{j=1}^s |r_i - r_j|²    [попарне представлення радіуса гірації]
```

Доведемо тотожність цих двох виразів:

```
(1 / (2 · s²)) · ∑_{i=1}^s ∑_{j=1}^s |r_i - r_j|²
= (1 / (2 · s²)) · ∑_{i=1}^s ∑_{j=1}^s (|r_i - r_cm|² + |r_j - r_cm|² - 2 · (r_i - r_cm) · (r_j - r_cm))    [розклад вектора r_i - r_j через r_cm]
= (1 / (2 · s²)) · (s · ∑ |r_i - r_cm|² + s · ∑ |r_j - r_cm|² - 2 · (∑ (r_i - r_cm)) · (∑ (r_j - r_cm)))     [розкриття подвійної суми за індексами i та j]
= (1 / (2 · s²)) · (2 · s · ∑ |r_i - r_cm|² - 0)                                                             [оскільки за визначенням ∑ (r_i - r_cm) = 0]
= (1 / s) · ∑_{i=1}^s |r_i - r_cm|²                                                                           [скорочення множника 2s у чисельнику й знаменнику]
= R_s²                                                                                                       [тотожність доведена]
```

### Фрактальна розмірність кластерів

У критичній точці `p = p_c` кластери є самоподібними фрактальними об'єктами. Їхня маса (кількість вузлів `s`) пов'язана з лінійним розміром `R_s` через фрактальну розмірність `d_f`:

```
s
∝ (R_s)^(d_f)    [фрактальний закон масштабування маси]
R_s
∝ s^(1 / d_f)    [залежність радіуса гірації від розміру кластера]
```

Фрактальна розмірність `d_f` виражається через критичні індекси простору:

```
d_f
= d - β / ν                [зв'язок фрактальної розмірності з індексами β та ν]
= 2 - (5/36) / (4/3)       [підстановка d = 2, β = 5/36, ν = 4/3]
= 2 - 5 / 48               [ділення дробів: (5/36) · (3/4) = 5/48]
= 91 / 48 ≈ 1.8958         [обчислення 96/48 - 5/48 = 91/48]
```

### Кореляційна довжина ξ(p)

Кореляційна довжина `ξ(p)` характеризує типову максимальну просторову відстань, на якій два зайняті вузли належать до одного скінченного кластера. Вона визначається як зважений середній радіус гірації за всіма скінченними кластерами:

```
ξ²(p)
= (2 · ∑_{s=1}^∞ R_s² · s² · n_s(p)) / (∑_{s=1}^∞ s² · n_s(p))    [визначення кореляційної довжини]
```

При наближенні до критичної точки кореляційна довжина розбігається:

```
ξ(p)
∝ |p - p_c|^(-ν)    [критична розбіжність кореляційної довжини]
```

де для `d = 2` критичний індекс кореляційної довжини становить `ν = 4/3 ≈ 1.3333`.

## 8. Гіперскейлінгові співвідношення та універсальність

Усі критичні індекси перколації пов'язані між собою універсальними законами масштабування (Hyperscaling Relations), що випливають із гіпотези про єдиний характерний масштаб довжини `ξ`:

1. **Співвідношення Рашбрука (Rushbrooke)**:
```
α + 2 · β + γ
= 2    [закон збереження вільної енергії / сингулярності кластерної густини]
```
де `α` — критичний показник особливості нульового моменту `M_0(p) ∝ |p - p_c|^(2 - α)`. Для 2D перколації `α = -2/3`.

2. **Гіперскейлінг Джозефсона (Josephson)**:
```
d · ν
= 2 - α    [зв'язок розмірності простору d з індексами ν та α]
```
Перевірка для 2D: `2 · (4/3) = 8/3 = 2 - (-2/3) = 8/3`.

3. **Співвідношення Фішера (Fisher)** для кореляційної функції зв'язності `G(r) ∝ r^{-(d - 2 + η)}`:
```
η
= 2 - d + 2 · (β / ν)        [індекс аномальної розмірності]
= 2 - 2 + 2 · ((5/36)/(4/3)) [підстановка d = 2 та індексів]
= 2 · (5/48)                 [спрощення дробу]
= 5 / 24 ≈ 0.2083            [результат для 2D перколації]
```

## 9. Теорія скінченно-розмірного масштабування (Finite-Size Scaling)

У реальному комп'ютерному експерименті алгоритм Гошена–Копельмана застосовується до ґратки скінченного розміру `L × L`. Через обмеженість системи кореляційна довжина не може перевищити розмір зразка: `ξ(p) ≤ L`.

Це згладжує сингулярності критичних величин та зміщує ефективний поріг перколації `p_c(L)`. Згідно з теорією скінченно-розмірного масштабування, ймовірність появи протікаючого кластера `П(p, L)` (spanning probability) задовольняє співвідношення:

```
П(p, L)
= Φ((p - p_c) · L^(1 / ν))    [масштабна функція протікання]
```

Ефективний поріг перколації `p_c(L)`, визначений як точка, де `П(p_c(L), L) = 1/2`, зміщується відносно істинного значення `p_c(∞)` за законом:

```
|p_c(L) - p_c(∞)|
∝ L^(-1 / ν)    [зсув ефективного порогу в скінченній системі]
```

Для 2D ґратки з `ν = 4/3` показник зміщення становить `1/ν = 3/4 = 0.75`. Вимірюючи `П(p, L)` для серії розмірів ґратки (наприклад, `L = 64, 128, 256, 512, 1024`) за допомогою алгоритму Гошена–Копельмана та знаходячи точку перетину кривих, фізики знаходять поріг перколації `p_c` з точністю до `10⁻⁶`.

## 10. Конформна інваріантність та формула Карді

Одним із найглибших теоретичних досягнень кінця XX століття у теорії перколації стало відкриття конформної інваріантності критичної перколації у двовимірному просторі (Джон Карді, 1992; строге доведення Станіслава Смирнова для трикутної ґратки, 2001).

Розглянемо прямокутну область розміром `L_x × L_y` із модульними співвідношенням сторін `r = L_x / L_y`. Ймовірність горизонтального протікання `P_cross(r)` при `p = p_c` залежить виключно від конформного модуля `r` і описується точною аналітичною формулою Карді через гіпергеометричну функцію:

```
P_cross(η)
= ((3 · Γ(2/3)) / (Γ(1/3))²) · η^(1/3) · ₂F₁(1/3, 2/3; 4/3; η)    [формула Карді для ймовірності перетину]
```

де параметр конформного відображення `η` пов'язаний із геометрією прямокутника через модулярні еліптичні функції або формулу Шварца–Крістоффеля.

Для квадратного зразка зі співвідношенням сторін `r = 1` формула Карді дає точне граничне значення:

```
P_cross(1)
= 1 / 2    [ізотропна симетрія протікання у квадраті]
```

Для прямокутників із різним аспектом `r`:
- якщо `r = 2` (витягнутий горизонтально), `P_cross(2) ≈ 0.8165`;
- якщо `r = 0.5` (витягнутий вертикально), `P_cross(0.5) ≈ 0.1835`.

Ці конформні інваріанти слугують найточнішим еталоном для перевірки реалізації алгоритму Гошена–Копельмана при моделюванні великих систем.

## 11. Топологічні ймовірності обгортання на торі (Periodic Boundary Conditions)

Коли ґратка моделюється з періодичними граничними умовами (топологія двовимірного тора `T²`), протікання визначається не дотиком до геометричних границь, а нетривіальним топологічним обгортанням кластера навколо утворюючих тора (non-contractible loops).

Для тора `L × L` розрізняють три незалежні ймовірності обгортання:
1. `R_x(p, L)` — ймовірність існування кластера, що замикається вздовж горизонтальної осі `X`.
2. `R_y(p, L)` — ймовірність замикання вздовж вертикальної осі `Y`.
3. `R_b(p, L)` — ймовірність одночасного незалежного замикання в обох напрямках `X` та `Y`.

У критичній точці `p = p_c` ці ймовірності прямують до універсальних констант (Pinson, 1994):

```
R_x(p_c) = R_y(p_c) ≈ 0.521058...    [універсальна ймовірність одноосьового замикання на торі]
R_b(p_c)            ≈ 0.315024...    [універсальна ймовірність двоосьового замикання на торі]
```

Алгоритм Гошена–Копельмана з підтримкою періодичних границь виявляє обгортання шляхом відстеження різниці координат між сайтами при виявленні колізій, що перетворює його на високоефективний інструмент топологічного аналізу графів.

## 12. Фрактальна розмірність оболонки кластера (Cluster Hull)

Окрім повної маси кластера `s`, фундаментальний інтерес становить структура його зовнішньої границі — оболонки (Hull) або зовнішнього периметра. Зовнішня межа кластера є фрактальною кривою без самоперетинів.

У 1980-х роках Бернар Саповаль (Bernard Sapoval) та Манфред Россо (Manfred Rosso) показали, що кількість вузлів на зовнішньому периметрі `h` масштабується з лінійним розміром кластера `R_s` за власним фрактальним законом:

```
h
∝ (R_s)^(d_h)    [масштабування маси оболонки кластера]
```

де `d_h` — фрактальна розмірність оболонки. Конформна теорія поля та еволюція Шрамма–Левнера (Schramm–Loewner Evolution з параметром `κ = 6`, що описує межі перколяційних кластерів) дають строге значення:

```
d_h
= 1 + 1 / ν            [зв'язок розмірності оболонки з кореляційним індексом ν]
= 1 + 1 / (4/3)        [підстановка ν = 4/3]
= 1 + 3 / 4            [обернення дробу]
= 7 / 4 = 1.7500       [точна розмірність зовнішньої границі]
```

Знання величини `d_h = 1.75` має вирішальне значення при моделюванні дифузійно-обмеженої агрегації, корозії металів та гідродинамічної фільтрації через пористі мембрани.

## 13. Дуальність Крамерса–Ваньє та точні пороги перколації зв'язків

Для перколації зв'язків (bond percolation) на двовимірній квадратній ґратці точне значення порогу `p_c = 1/2` виводиться з топологічної самодуальності ґратки.

Кожній конфігурації зв'язків на прямій ґратці `G` взаємно однозначно відповідає конфігурація розірваних зв'язків на дуальній ґратці `G*`, вузли якої розташовані в центрах граней вихідної ґратки:
- Якщо зв'язок на `G` замкнений (провідний) з імовірністю `p`, то відповідне йому ребро на `G*` вважається відкритим (не блокує потік).
- Якщо зв'язок на `G` розірваний (імовірність `1 - p`), ребро на `G*` блокує перколяційний шлях.

Горизонтальне протікання на прямокутнику `L × L` на ґратці `G` блокується тоді й лише тоді, коли існує вертикальний шлях із розірваних зв'язків на дуальній ґратці `G*`:

```
P_cross(p) + P*_cross(1 - p)
= 1    [теорема дуальності для ймовірностей перетину]
```

Оскільки для квадратної ґратки дуальна ґратка також є квадратною (`G* ≅ G`), то в точці фазового переходу з міркувань просторової симетрії `P_cross(p_c) = P*_cross(p_c) = 1/2`:

```
p_c
= 1 - p_c        [умова самодуальності]
2 · p_c = 1      [перенесення доданка]
p_c = 1 / 2      [точний поріг для квадратної ґратки зв'язків]
```

Для трикутної та стільникової ґраток, які є дуальними одна до одної (`G_tri* ≅ G_hc`), співвідношення зірка-трикутник (перетворення Ізінга–Онсагера) дає точні аналітичні пороги зв'язків:
- для трикутної ґратки: `p_c = 2 · sin(π / 18) ≈ 0.347296...`;
- для стільникової ґратки: `p_c = 1 - 2 · sin(π / 18) ≈ 0.652704...`.
