# 🧮 Метод потенціалів та логарифмічна теорема про доступ Splay-дерев

Математичне обґрунтування ефективності Splay-дерев ґрунтується на [методі потенціалів](book:algorithms/amortized-analysis), розробленому Робертом Тарджаном. Без строгого аналізу зміни рангового потенціалу неможливо довести, чому сукупність операцій виконується за логарифмічний час `O(log N)`, попри те, що окремий запит може коштувати лінійного часу `O(N)`.

## Рангова функція та потенціал дерева

Нехай `T` — двійкове дерево пошуку. Кожному вузлу `x ∈ T` зіставляється довільна додатна вага `w(x) > 0`. Вага є фіксованим параметром математичного аналізу і не зберігається у фізичних вузлах структури даних.

Визначимо такі математичні величини:

1. **Розмір піддерева** `s(x)` — сума ваг усіх вузлів у піддереві з коренем у `x` (включно із самим `x`):
```
s(x) = ∑ w(y)    [де y належить піддереву вузла x]
```
Повна вага всього дерева позначається як `W = s(root) = ∑ w(y)` для всіх `y ∈ T`.

2. **Ранг вузла** `r(x)` — двійковий логарифм розміру його піддерева:
```
r(x) = log2(s(x))
```
Оскільки `w(x) > 0` для кожного вузла, функція `s(x)` строго монотонно зростає під час руху від листків до кореня дерева: якщо `y` є нащадком `x`, то `s(y) < s(x)` та `r(y) < r(x)`. Для кореня дерева його ранг завжди дорівнює:
```
r(root) = log2(W)
```

3. **Потенціал конфігурації дерева** `Φ(T)` — сума рангів усіх вузлів дерева:
```
Φ(T) = ∑ r(x)    [де x ∈ T]
```

Чому саме логарифмічна сума рангів є правильною функцією потенціалу? Якщо вибрати лінійну суму `∑ s(x)`, то під час поворотів виродженого ланцюга потенціал змінюється на величину `O(N²)`, що не дозволяє компенсувати реальну вартість `O(N)` одинарних операцій. Логарифм стискає ваги піддерев: зміна рангу при обертаннях збалансованого дерева близька до нуля, а при розгортанні довгого ланцюга вивільняє достатньо накопиченого потенціалу для оплати реальної роботи.

## Амортизована вартість операції

Нехай на кроці `i` виконується операція, яка змінює стан дерева з `T_{i-1}` на `T_i`.

Реальна вартість операції `t_i` вимірюється кількістю одинарних поворотів (або 1, якщо поворотів не було). Амортизована вартість `â_i` визначається класичним рівнянням методу потенціалів:

```
â_i = t_i + Φ(T_i) - Φ(T_{i-1})    [визначення амортизованої вартості за методом потенціалів]
    = t_i + ΔΦ_i                   [де ΔΦ_i — зміна потенціалу структури на кроці i]
```

Якщо послідовність складається з `m` операцій, сумарна реальна вартість обмежена зверху сумою амортизованих вартостей плюс початковий і кінцевий потенціал:

```
∑ t_i = ∑ â_i + Φ(T_0) - Φ(T_m)    [телескопічна сума різниць потенціалів]
```

Якщо кінцевий потенціал не менший за початковий (`Φ(T_m) ≥ Φ(T_0)`), або різниця між ними обмежена константою від розміру задачі, сума амортизованих вартостей є строгою верхньою оцінкою сумарного реального часу роботи алгоритму.

## Допоміжна лема про угнутість логарифма

Для виведення оцінок кроків Splay ключову роль відіграє властивість строгої угнутості (concavity) функції двійкового логарифма `log2(u)`.

Якщо `a > 0` та `b > 0`, то з нерівності між середнім геометричним та середнім арифметичним випливає:

```
log2(a) + log2(b) = 2 · (log2(a) + log2(b)) / 2       [тотожне перетворення через множення на 2/2]
                  = 2 · log2(√(a · b))                [властивість суми логарифмів: log(a)+log(b)=log(ab)]
                  ≤ 2 · log2((a + b) / 2)             [угнутість log2: √(ab) ≤ (a+b)/2 за нерівністю Коші]
                  = 2 · (log2(a + b) - log2(2))       [логарифм частки: log((a+b)/2) = log(a+b) - 1]
                  = 2 · log2(a + b) - 2               [оскільки log2(2) = 1]
```

Звідси отримуємо фундаментальну нерівність:

```
2 · log2(a + b) - log2(a) - log2(b) ≥ 2    [перенесення членів нерівності угнутості]
```

Ця нерівність дозволяє перетворити константу вартості поворотів `2` у різницю рангів піддерев.

## Теорема: Лема про доступ (Access Lemma)

Нехай `t` — корінь дерева `T`. Амортизована вартість виконання операції `splay(x)` у дереві `T` за будь-якого призначення додатних ваг `w` задовольняє нерівність:

```
â(splay(x)) ≤ 3 · (r(t) - r(x)) + 1           [амортизована межа через різницю рангів]
            = 3 · log2(W / s(x)) + 1          [підстановка r(t) = log2(W) та r(x) = log2(s(x))]
            ≤ 3 · log2(W / w(x)) + 1          [оскільки s(x) ≥ w(x) за означенням розміру піддерева]
```

### Доведення для окремих кроків splay

Операція `splay(x)` складається з послідовності кроків Zig-Zig та Zig-Zag, що завершуються щонайбільше одним кроком Zig (коли батько `p` є коренем).

Позначимо через `s(y)` та `r(y)` розмір і ранг вузла `y` до виконання одного кроку повороту, а через `s'(y)` та `r'(y)` — після його виконання. Зауважимо, що ранги всіх вузлів поза трійкою `{x, p, g}` (або парою `{x, p}`) не змінюються, оскільки їхні піддерева структурно не зазнали змін.

#### 1. Крок Zig (термінальний одинарний поворот)

Вузол `x` є сином кореня `p`. Виконується один поворот.
Реальна вартість: `t = 1`.

Зміна потенціалу:
```
ΔΦ = r'(x) + r'(p) - r(x) - r(p)    [зміна рангів вузлів x та p, решта не змінилися]
```

Оскільки після повороту `x` стає коренем піддерева, маємо `s'(x) = s(p)`, отже `r'(x) = r(p)`. Крім того, піддерево `p` зменшилося: `s'(p) < s'(x)`, тому `r'(p) < r'(x)`. Підставимо це у вираз для амортизованої вартості:

```
â_zig = 1 + ΔΦ                                [визначення амортизованої вартості кроку]
      = 1 + r'(x) + r'(p) - r(x) - r(p)       [підставили ΔΦ для вузлів x та p]
      = 1 + r'(p) - r(x)                      [скоротили r'(x) = r(p) за рівністю розмірів піддерев]
      ≤ 1 + r'(x) - r(x)                      [оскільки r'(p) < r'(x) через зменшення піддерева p]
      ≤ 1 + 3 · (r'(x) - r(x))                [оскільки r'(x) ≥ r(x) і коефіцієнт 3 ≥ 1]
```

#### 2. Крок Zig-Zig (одностороннє подвійне обертання)

Вузол `x` та його батько `p` мають однаковий напрямок: або обидва ліві нащадки, або обидва праві. Нехай для визначеності `x = p->left` і `p = g->left`.
Порядок операцій: спочатку поворот навколо `(p, g)`, потім поворот навколо `(x, p)`.
Реальна вартість: `t = 2`.

Зміна потенціалу:
```
ΔΦ = r'(x) + r'(p) + r'(g) - r(x) - r(p) - r(g)    [зміна рангів трійки вузлів x, p, g]
```

Аналізуємо розміри піддерев:
- Вузол `x` після двох поворотів охоплює все початкове піддерево `g`, тому `s'(x) = s(g)` і `r'(x) = r(g)`.
- До поворотів `x` містився всередині піддерева `p`: `s(x) < s(p)`, тому `r(x) ≤ r(p)`.
- Після поворотів `p` міститься всередині піддерева `x`: `s'(p) < s'(x)`, тому `r'(p) ≤ r'(x)`.

Підставляємо ці співвідношення у формулу амортизованої вартості:

```
â_zz = 2 + ΔΦ                                           [реальна вартість 2 повороти плюс зміна потенціалу]
     = 2 + r'(x) + r'(p) + r'(g) - r(x) - r(p) - r(g)   [підставили вираз для ΔΦ]
     = 2 + r'(p) + r'(g) - r(x) - r(p)                  [скоротили r'(x) і r(g), оскільки s'(x) = s(g)]
     ≤ 2 + r'(x) + r'(g) - 2 · r(x)                     [застосували r'(p) ≤ r'(x) та -r(p) ≤ -r(x)]
```

Тепер застосуємо лему про угнутість логарифма. Зверніть увагу на склад піддерев після повороту: піддерево `x` до повороту містило ліве та праве піддерева `x` плюс сам вузол `x`. Піддерево `g` після повороту містить піддерева `C` і `D` плюс вузол `g`. Оскільки всі ці множини вузлів взаємно не перетинаються і повністю входять у нове піддерево `x`, маємо нерівність:

```
s(x) + s'(g) ≤ s'(x)    [піддерева x до повороту та g після повороту не перетинаються]
```

Застосовуючи угнутість логарифма для `a = s(x)` та `b = s'(g)`:

```
log2(s(x)) + log2(s'(g)) ≤ 2 · log2(s'(x)) - 2    [застосування нерівності угнутості логарифма]
r(x) + r'(g) ≤ 2 · r'(x) - 2                      [перехід до рангових позначень r=log2(s)]
```

Перенесемо константу:
```
2 ≤ 2 · r'(x) - r(x) - r'(g)    [виразили константу вартості поворотів через ранги]
```

Підставимо цю оцінку замість двійки у вираз для `â_zz`:

```
â_zz ≤ [2 · r'(x) - r(x) - r'(g)] + r'(x) + r'(g) - 2 · r(x)    [підставили верхню оцінку для двійки]
     = 3 · r'(x) - 3 · r(x)                                      [звели подібні члени: скоротилися r'(g)]
     = 3 · (r'(x) - r(x))                                        [винесли множник 3 за дужки]
```

Це доводить, що амортизована вартість кроку Zig-Zig строго обмежена величиною `3 · (r'(x) - r(x))`.

#### 3. Крок Zig-Zag (двостороннє подвійне обертання)

Вузол `x` та батько `p` мають протилежні напрямки: наприклад, `x = p->right`, а `p = g->left`.
Порядок операцій: спочатку поворот навколо `(x, p)`, потім навколо `(x, g)`.
Реальна вартість: `t = 2`.

Зміна потенціалу:
```
ΔΦ = r'(x) + r'(p) + r'(g) - r(x) - r(p) - r(g)    [зміна рангів вузлів x, p, g]
```

Як і раніше, `s'(x) = s(g)`, звідки `r'(x) = r(g)`. Крім того, `r(x) ≤ r(p)`. Тому:

```
â_zg = 2 + r'(p) + r'(g) - r(x) - r(p)    [скоротили r'(x) = r(g)]
     ≤ 2 + r'(p) + r'(g) - 2 · r(x)        [оскільки -r(p) ≤ -r(x)]
```

Після кроку Zig-Zag вузли `p` та `g` стають лівим і правим нащадками `x`. Їхні піддерева не перетинаються, а їхнє об'єднання міститься всередині піддерева `x`:
```
s'(p) + s'(g) ≤ s'(x)    [піддерева p і g після повороту є прямими нащадками x]
```

Застосовуючи угнутість логарифма для `a = s'(p)` та `b = s'(g)`:
```
r'(p) + r'(g) ≤ 2 · r'(x) - 2    [нерівність угнутості логарифма для розмірів s'(p) та s'(g)]
2 ≤ 2 · r'(x) - r'(p) - r'(g)    [виразили константу 2 через ранги]
```

Підставляючи у вираз для амортизованої вартості:
```
â_zg ≤ [2 · r'(x) - r'(p) - r'(g)] + r'(p) + r'(g) - 2 · r(x)    [підставили оцінку для двійки]
     = 2 · (r'(x) - r(x))                                        [скоротилися r'(p) та r'(g)]
     ≤ 3 · (r'(x) - r(x))                                        [оскільки r'(x) ≥ r(x)]
```

### Телескопічна сума вздовж усього шляху

Повна операція `splay(x)` складається з `k` кроків (де `k-1` кроків — це Zig-Zig або Zig-Zag, і щонайбільше 1 термінальний крок Zig). Нехай ранги вузла `x` на кожному кроці становлять `r_0(x), r_1(x), r_2(x), ..., r_k(x)`.

Сумарна амортизована вартість:

```
â(splay(x)) = â_1 + â_2 + ... + â_k                                                                     [сума амортизованих вартостей усіх k кроків]
            ≤ 3 · (r_1(x) - r_0(x)) + 3 · (r_2(x) - r_1(x)) + ... + 3 · (r_k(x) - r_{k-1}(x)) + 1   [підсумували оцінки для кожного з k кроків]
            = 3 · (r_k(x) - r_0(x)) + 1                                                               [телескопічне скорочення проміжних рангів]
            = 3 · (r(root) - r(x)) + 1                                                                [оскільки r_k(x) = r(root), а r_0(x) = r(x)]
```

Оскільки `r(root) = log2(W)` та `r(x) = log2(s(x)) ≥ log2(w(x))`, отримуємо остаточну оцінку Леми про доступ:

```
â(splay(x)) ≤ 3 · log2(W / w(x)) + 1    [остаточна оцінка Леми про доступ]
```

## Амортизований аналіз операцій модифікації

Окрім чистого доступу `find`, Splay-дерево підтримує операції вставки, видалення, розрізання та злиття. Доведемо, що кожна з них має амортизовану складність `O(log N)`.

### 1. Операція Split(T, k)

Операція `Split` складається з `splay(k)` (або найближчого вузла) та розриву правого ребра кореня.
- Амортизована вартість `splay(k)` дорівнює `O(log(W / w(k))) = O(log N)`.
- Розрив ребра розділяє дерево `T` на `T_L` та `T_R`. Ранги всіх вузлів у відокремлених піддеревах або не змінюються, або зменшуються (оскільки розміри піддерев зменшилися).
- Зміна потенціалу: `ΔΦ_split = Φ(T_L) + Φ(T_R) - Φ(T) ≤ 0`.
- Отже, амортизована вартість `Split` не перевищує вартості операції `splay`: `â(Split) = O(log N)`.

### 2. Операція Join(T_L, T_R)

Операція `Join` складається з `splay(max(T_L))` та під'єднання `T_R` як правого сина.
- Амортизована вартість `splay(max(T_L))` становить `O(log(W_L / w(max))) = O(log N)`.
- Під'єднання `T_R` збільшує ранг кореня `T_L` від `log2(W_L)` до `log2(W_L + W_R)`.
- Зміна потенціалу при злитті: `ΔΦ_join = log2(W_L + W_R) - log2(W_L) = log2((W_L + W_R) / W_L) ≤ log2(W) = O(log N)`.
- Сумарна амортизована вартість: `â(Join) = O(log N)`.

### 3. Операції Insert та Delete

- **Insert(k)** виконує `Split(T, k)` та створює новий корінь. Додавання нового вузла додає до потенціалу його власний ранг `log2(W + w(k)) = O(log N)`. Амортизована вартість вставки становить строго `O(log N)`.
- **Delete(k)** виконує `splay(k)` та `Join(root->left, root->right)`. Знищення кореня лише зменшує потенціал. Сумарна амортизована вартість видалення складає `O(log N)`.

## Наслідки та фундаментальні теореми

### 1. Рівномірний розподіл ваг (Uniform Access)

Покладемо `w(x) = 1` для кожного з `N` вузлів. Тоді:
- Повна вага: `W = N`.
- Вага будь-якого вузла: `w(x) = 1`.
- Амортизована вартість операції `splay(x)`:
```
â(splay(x)) ≤ 3 · log2(N / 1) + 1 = 3 · log2(N) + 1 = O(log N)
```

Початковий потенціал порожнього або збалансованого дерева: `Φ(T_0) = O(N log N)`. Навіть якщо дерево спочатку було повністю виродженим у ланцюг, `Φ(T_0) ≤ N log2(N)`. Після `m` операцій сумарний час:
```
T_total = O((m + N) · log N)
```
За умови `m ≥ N` середній час однієї операції становить строго `O(log N)`.

### 2. Теорема про статичну оптимальність (Static Optimality Theorem)

Нехай кожен елемент `i` запитується з відомою фіксованою ймовірністю `p_i > 0`, де `∑ p_i = 1`. Нехай загальна кількість операцій дорівнює `m`, а елемент `i` запитується `q_i = m · p_i` разів.

Призначимо вагу кожного вузла рівною його частоті запитів: `w(i) = q_i / m = p_i`. Тоді сумарна вага `W = ∑ p_i = 1`.
Амортизована вартість одного доступу до елемента `i`:
```
â_i ≤ 3 · log2(1 / p_i) + 1 = 3 · log2(1 / p_i) + 1
```

Сумарна вартість `m` операцій:
```
∑ â_i ≤ ∑ q_i · (3 · log2(1 / p_i) + 1)                      [підставили оцінку â_i для кожного ключа i]
      = 3 · ∑ (m · p_i) · log2(1 / p_i) + ∑ q_i              [врахували q_i = m · p_i]
      = 3 · m · ∑ p_i · log2(1 / p_i) + m                    [винесли m за дужки, ∑ q_i = m]
      = 3 · m · H(P) + m                                     [за означенням ентропії H(P) = -∑ p_i log2(p_i)]
      = O(m · (1 + H(P)))                                    [асимптотичне спрощення лінійної залежності]
```
де `H(P) = -∑ p_i · log2(p_i)` — ентропія Шеннона розподілу запитів. За теоремою Шеннона жодне статичне двійкове дерево пошуку не може виконати запити швидше, ніж `m · H(P)`. Таким чином, Splay-дерево без знання ймовірностей наперед асимптотично досягає теоретичної ентропійної межі будь-якого оптимального статичного BST.

### 3. Теорема про робочу множину (Working Set Theorem)

Нехай `t(x)` — кількість унікальних ключів, до яких відбулося звернення з моменту останнього доступу до елемента `x`. Призначивши динамічні ваги, що спадають пропорційно часу останнього використання:
```
w(y) = 1 / (t(y) + 1)²
```
Слітор і Тарджан довели, що сума ваг `W` збігається до константи (`∑ 1/k² = π²/6 = O(1)`), а амортизований час доступу до `x` становить:

```
â(x) = O(log(t(x) + 1))
```

Якщо програма інтенсивно працює з фіксованою робочою множиною розміру `k` елементів (`k << N`), усі запити до цієї множини виконуються за `O(log k)` часу незалежно від загального розміру дерева `N`.

### 4. Теорема про динамічний палець (Dynamic Finger Theorem)

Нехай `x` та `y` — два послідовно запитані ключі. Нехай `d(x, y) = |rank(x) - rank(y)|` — кількість елементів між `x` та `y` у симетричному порядку ключів.
Річард Коул у 2000 році строго довів, що амортизований час переходу від `x` до `y` задовольняє оцінку:

```
â(x -> y) = O(log(d(x, y) + 1))
```

Якщо запити демонструють просторову локальність (наприклад, сканування діапазону ключів), Splay-дерево працює швидше за будь-яке стандартне BST, витрачаючи `O(1)` часу на сусідні елементи.

### 5. Теорема про послідовне сканування (Scanning Theorem)

Якщо до всіх `N` елементів Splay-дерева звернутися у відсортованому за зростанням порядку ключів `1, 2, ..., N`, то сумарний час виконання всієї послідовності становить `O(N)`, тобто в середньому `O(1)` на один елемент. Доведення цього результату використовує спеціальну вагову функцію, де ранг змінюється лише на константу при кожному наступному кроці.
