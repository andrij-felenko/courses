# 🧮 Виведення формул чисел Каталана

Математичне виведення формул чисел Каталана базується на трьох принципово різних підходах: комбінаторній геометричній бієкції (принцип віддзеркалення Андре), аналітичній алгебрі твірних функцій та асимптотичному наближенні за формулою Стірлінга.

## 1. Геометричне доведення за принципом віддзеркалення Андре

Розглянемо двовимірну цілочисельну ґратку `ℤ × ℤ`. **Шлях Дюка** довжини `2n` — це послідовність із `n` кроків праворуч `R = (1, 0)` та `n` кроків угору `U = (0, 1)`, яка починається в початковій точці `(0, 0)`, закінчується в точці `(n, n)` і задовольняє умову `y ≤ x` для всіх проміжних точок.

### Загальна кількість траєкторій на ґратці
Будь-який шлях від `(0, 0)` до `(n, n)` складається із задекларованої суми `2n` кроків, з яких точно `n` кроків мають бути спрямовані праворуч. Кількість усіх можливих траєкторій на ґратці без обмеження на діагональ обчислюється за вибором позицій для кроків `R` як біноміальний коефіцієнт:

```
N_total = (2n \ n) = (2n)! / (n! · n!)
```

### Відсікання невалідних шляхів
Шлях вважається невалідним (поганим), якщо він бодай в одній точці порушує умову `y ≤ x`, тобто перетинає головну діагональ і торкається прямої `y = x + 1`.

Нехай `P` — перший крок невалідного шляху, який досягає прямої `y = x + 1`. Позначимо точку цього першого торкання як `(k, k + 1)`. Віддзеркалимо частину шляху від точки `(k, k + 1)` до кінцевої точки `(n, n)` відносно прямої `y = x + 1`.

При віддзеркаленні кожен подальший крок праворуч `R = (1, 0)` переходить у крок угору `U = (0, 1)`, а кожен крок угору `U = (0, 1)` переходить у крок праворуч `R = (1, 0)`.

- Початкова частина шляху від `(0, 0)` до `(k, k + 1)` містила `k` кроків `R` та `k + 1` кроків `U`.
- Залишкова частина шляху містила `n - k` кроків `R` та `n - k - 1` кроків `U`.
- Після віддзеркалення залишкова частина містить `n - k` кроків `U` та `n - k - 1` кроків `R`.

Сумарна кількість кроків нового віддзеркаленого шляху:
- Кроки праворуч `R`: `k + (n - k - 1) = n - 1`.
- Кроки угору `U`: `(k + 1) + (n - k) = n + 1`.

Отже, будь-який невалідний шлях після віддзеркалення закінчується в точці `(n - 1, n + 1)`. Оскільки це перетворення є бієктивним (оборотним), кількість невалідних шляхів точно дорівнює кількості довільних шляхів від `(0, 0)` до `(n - 1, n + 1)`:

```
N_bad = (2n \ n - 1) = (2n)! / ((n - 1)! · (n + 1)!)
```

### Підсумковий розрахунок числа Каталана
Кількість валідних шляхів Дюка `Cₙ` дорівнює різниці між загальною кількістю шляхів та кількістю невалідних:

```
Cₙ = N_total - N_bad
   = (2n \ n) - (2n \ n - 1)                      [різниця комбінаторних шляхів]
   = (2n)! / (n! · n!) - (2n)! / ((n - 1)! · (n + 1)!) [розкриття через факторіали]
   = ((2n)! / (n! · n!)) · [1 - n / (n + 1)]       [винесення спільного множника]
   = ((2n)! / (n! · n!)) · [1 / (n + 1)]           [спрощення дужки: (n+1-n)/(n+1)]
   = (1 / (n + 1)) · (2n \ n)                     [остаточна закрита форма]
```

## 2. Алгебраїчний вивід через твірні функції

Згорткове рекурентне співвідношення для чисел Каталана має вигляд:

```
C₀ = 1
Cₙ = ∑ᵢ₌₀ⁿ⁻¹ Cᵢ · Cₙ⋇⋇    [для n ≥ 1]
```

Введемо формальний статевий ряд (твірну функцію):

```
C(x) = ∑ₙ₌₀⁺∞ Cₙ · xⁿ = C₀ + C₁·x + C₂·x² + C₃·x³ + ...
```

### Піднесення твірної функції до квадрата
Піднесемо ряд `C(x)` до квадрата за правилом множення Коші для статевих рядів:

```
C(x)² = (∑ᵢ₌₀⁺∞ Cᵢ · xⁱ) · (∑ⱼ₌₀⁺∞ Cⱼ · xʲ)
      = ∑ₙ₌₀⁺∞ (∑ᵢ₌₀ⁿ Cᵢ · Cₙ⋇) · xⁿ           [правило Коші для множення рядів]
```

Зсунемо індекс коефіцієнтів рекурентності:

```
x · C(x)² = ∑ₙ₌₀⁺∞ (∑ᵢ₌₀ⁿ Cᵢ · Cₙ⋇) · xⁿ⁺¹       [домноження ряду на змінну x]
          = ∑ₙ₌₁⁺∞ (∑ᵢ₌₀ⁿ⁻¹ Cᵢ · Cₙ⋇⋇) · xⁿ     [зсув індексу підсумовування n]
          = ∑ₙ₌₁⁺∞ Cₙ · xⁿ                       [підстановка рекурентності Зегнера]
          = C(x) - C₀                            [доповнення до повного ряду C(x)]
          = C(x) - 1                             [застосування початкової умови C₀ = 1]
```

Ми отримали квадратне алгебраїчне рівняння відносно функції `C(x)`:

```
x · C(x)² - C(x) + 1 = 0
```

### Розв'язання квадратного рівняння
За формулою коренів квадратного рівняння `a·y² + b·y + c = 0`:

```
C(x) = (1 ± √(1 - 4x)) / (2x)
```

Оскільки `C(0) = C₀ = 1`, ми повинні вибрати знак перед коренем, який дає збіжність при `x → 0`. Якщо вибрати знак `+`, границя `(1 + 1) / 0` прямує до безкінечності. Тому єдиним фізично правильним розв'язком є знак `-`:

```
C(x) = (1 - √(1 - 4x)) / (2x)
```

### Розклад у біноміальний ряд Ньютона
Загальна формула Ньютона для виразу `(1 + z)ᵃ`:

```
(1 + z)ᵃ = ∑ₖ₌₀⁺∞ (a \ k) · zᵏ
```

Покладемо `a = 1/2` та `z = -4x`:

```
√(1 - 4x) = ∑ₖ₌₀⁺∞ (1/2 \ k) · (-4x)ᵏ
```

Обчислимо біноміальний коефіцієнт `(1/2 \ k)` для `k ≥ 1`:

```
(1/2 \ k) = [(1/2) · (1/2 - 1) · (1/2 - 2) · ... · (1/2 - k + 1)] / k!   [означення біноміального коефіцієнта]
          = [1 · (-1) · (-3) · ... · (-(2k - 3))] / (2ᵏ · k!)           [зведення знаменника 2^k]
          = (-1)ᵏ⁻¹ · (2k - 2)! / (2²ᵏ⁻¹ · k! · (k - 1)!)                [перегрупування добутків непарних чисел]
```

Підставивши цей розклад у вираз `C(x) = (1 - √(1 - 4x)) / (2x)`, для кожного коефіцієнта при `xⁿ` отримуємо точну закриту формулу:

```
Cₙ = (1 / (n + 1)) · (2n \ n)
```

## 3. Мультиплікативна рекурентність та алгебраїчне спрощення

Для прямого обчислення `Cₙ` без обчислення великих факторіалів виведемо співвідношення двох сусідніх чисел `Cₙ` та `Cₙ⋇`:

```
Cₙ / Cₙ⋇ = [(1 / (n + 1)) · (2n \ n)] / [(1 / n) · (2n - 2 \ n - 1)]    [співвідношення двох послідовних членів]
          = [n / (n + 1)] · [(2n)! / (n! · n!)] / [(2n - 2)! / ((n - 1)! · (n - 1)!)] [розкриття через факторіали]
          = [n / (n + 1)] · [(2n · (2n - 1)) / (n · n)]               [скорочення факторів (2n-2)! та (n-1)!]
          = (2 · (2n - 1)) / (n + 1)                                  [скорочення n у чисельнику та знаменнику]
          = (4n - 2) / (n + 1)                                        [розкриття дужок у чисельнику]
```

Таким чином, маємо лінійну мультиплікативну формулу:

```
C₀ = 1
Cₙ = Cₙ⋇ · (4n - 2) / (n + 1)    [для n ≥ 1]
```

Ця формула дозволяє обчислити `Cₙ` за `O(n)` арифметичних операцій з використанням лише `O(1)` додаткової пам'яті.

## 4. Асимптотична оцінка за формулою Стірлінга

Для аналізу складності алгоритмів важливо знати швидкість зростання `Cₙ` при `n → ∞`. Застосуємо формулу Стірлінга для асимптотики факторіала:

```
k! ≈ √(2πk) · (k / e)ᵏ
```

Підставимо асимптотику в явну формулу `Cₙ = (2n)! / ((n + 1)! · n!) ≈ (2n)! / (n! · n! · n)`:

```
(2n)! ≈ √(4πn) · (2n / e)²ⁿ = 2 · √(πn) · (2n / e)²ⁿ
n!    ≈ √(2πn) · (n / e)ⁿ
(n!)² ≈ 2πn · (n / e)²ⁿ
```

Підставилим знайдені факторіали у відношення:

```
Cₙ ≈ [2 · √(πn) · (2n / e)²ⁿ] / [n · 2πn · (n / e)²ⁿ]                  [підстановка асимптотик Стірлінга]
   = [2 · √(πn) · 2²ⁿ · (n / e)²ⁿ] / [2π · n² · (n / e)²ⁿ]              [розкриття (2n)^2n як 2^2n · n^2n]
   = (2²ⁿ · √(πn)) / (π · n²)                                           [скорочення (n/e)^2n та 2]
   = 4ⁿ / (n^(3/2) · √π)                                                [спрощення степеня n та кореня π]
```

Отже, асимптотична поведінка чисел Каталана описується виразом:

```
Cₙ = Θ(4ⁿ / n^(3/2))
```

Це доводить, що простір комбінаторних топологій зростає експоненційно з основою 4, стримуваний лише степеневим дільником `n^(3/2)`.

## 5. Додаткові комбінаторні тотожності та аналітичні властивості

Окрім базових формул, числа Каталана задовольняють низку фундаментальних комбінаторних тотожностей, які застосовуються при аналізі алгоритмів та структур даних:

1. **Тотожність суми квадратів**: Сума квадратів чисел Каталана описує кількість пар неперетинних шляхів та розбиття матриць:
```
∑ₖ⌠ⁿ (Cₖ)² = C₂ₙ₊₁ / 2
```
2. **Подільність та парність**: Число Каталана `Cₙ` є непарним тоді й лише тоді, коли `n = 2ᵏ - 1` (тобто `n` на одиницю менше за степінь двійки, як-от 1, 3, 7, 15, 31). Для всіх інших `n` число `Cₙ` є парним. Ця властивість використовується у швидких бітових тестах парності комбінаторних топологій без повного обчислення факторіалів.
3. **Асимптотичний коефіцієнт збіжності**: Відношення двох сусідніх чисел Каталана в границі прямує строго до 4:
```
limₙ⌠∞ (Cₙ₊₁ / Cₙ) = limₙ⌠∞ [(4n + 2) / (n + 2)] = 4
```
Це означає, що середня кількість додаткових топологічних конфігурацій при додаванні нового вузла збільшується рівно в 4 рази.

4. **Зв'язок із числами Нараяни (Narayana Numbers)**: Числа Каталана є сумою чисел Нараяни `N(n, k)`, які підраховують кількість дерев Каталана з `k` листками:
```
Cₙ = ∑ₖ⌠ⁿ N(n, k) = ∑ₖ⌠ⁿ (1 / n) · (n \ k) · (n \ k - 1)
```
Це співвідношення дає змогу точно аналізувати середній розподіл листків і глибину розгалуження в незаповнених двійкових деревах пошуку.

5. **Інтегральне подання через дільники та спектральну щільність**:
Числа Каталана можна виразити як момент ймовірнісного розподілу на відрізку `[0, 4]` за законами напівкола Вігнера:
```
Cₙ = (1 / (2π)) · ∫₀⁴ xⁿ · √((4 - x) / x) dx
```
Цей інтеграл показує зв'язок комбінаторики Каталана з теорією випадкових матриць, спектральним аналізом графів та фізикою квантових систем.

6. **Узагальнення на вищі виміри (Числа Фусса — Каталана)**:
Узагальненням послідовності для багатовимірних дерев із `m`-арним розгалуженням є числа Фусса — Каталана:
```
Cₙᵐ = (1 / (m·n + 1)) · (m·n + 1 \ n)
```
Ця формула визначає кількість структур `m`-арних дерев розбору та конфігурацій гіперграфів.
