# 🧮 Дерева станів, Pruning та оцінка складності O(b^d)

Математичний апарат пошуку з поверненням (backtracking) спирається на формальне моделювання процесів прийняття комбінаторних рішень за допомогою дерев простору станів (State Space Trees), аналіз алгебраїчних властивостей предикатів допустимості та оцінку ефективного коефіцієнта розгалуження.

Головна математична мета backtracking — доказове скорочення кількості відвіданих вузлів експоненціального або факторіального дерева пошуку порівняно з повним непрямим перебором. У цій вставці ми розберемо суворі формулювання цих моделей та метод імовірнісної оцінки Кнута.

---

## Формальна модель дерева простору станів

Нехай S — простір усіх можливих часткових рішень задачі. Процес побудови розв'язку подається у вигляді орієнтованого впорядкованого дерева T = (V, E), яке називається **деревом простору станів**.

1. **Корінь дерева r ∈ V**: відповідає початковому порожньому стану r = (), коли жодного рішення чи вибору ще не зроблено.
2. **Вузли дерева v ∈ V**: кожен вузол на рівні k є впорядкованим кортежем v = (x₁, x₂, ..., xₖ), де кожна компонента xᵢ належить скінченній множині допустимих альтернатив Xᵢ на кроці i.
3. **Глибина дерева d**: максимальна кількість кроків прийняття рішень, необхідна для формування повного розв'язку v = (x₁, x₂, ..., xₘ).
4. **Коефіцієнт розгалуження b**: кількість допустимих виборів для наступного елемента |Xₖ₊₁|. Якщо кількість виборів однакова на всіх рівнях, коефіцієнт розгалуження є константою b.

Якщо перебір здійснюється без будь-яких обмежень і на кожному з d кроків є b рівноправних альтернатив, загальна кількість вузлів у повному дереві перебору N_total обчислюється як сума геометричної прогресії:

```
N_total = 1 + b + b² + b³ + ... + bᵈ
        = (bᵈ⁺¹ - 1) / (b - 1)
        = O(bᵈ)
```

Для задач комбінаторних перестановок n елементів (наприклад, розташування n об'єктів у n позиціях без повторень), кількість альтернатив на кожному кроці зменшується: |X₁| = n, |X₂| = n - 1, ..., |Xₙ| = 1. Тоді кількість вузлів у повному дереві становить:

```
N_perm  = 1 + n + n·(n - 1) + n·(n - 1)·(n - 2) + ... + n!
        = ∑ (k = 0 .. n) [ n! / (n - k)! ]
        ≈ e · n!
        = O(n!)
```

Експоненціальне O(bᵈ) та факторіальне O(n!) зростання роблять повний перебір повністю непридатним уже для n ≥ 20. Наприклад, для n = 20 значення 20! дорівнює приблизно 2.43 × 10¹⁸, що вимагало б десятиліть обчислень навіть на найпотужніших суперкомп'ютерах.

## Предикати допустимості та математика відтинання (Pruning)

Ключовим елементом, що відрізняє backtracking від прямолінійного перебору, є **функція обмеження** або **предикат допустимості (Feasibility Predicate)** P(v).

Предикат P(v) приймає частковий стан v = (x₁, x₂, ..., xₖ) і повертає булеве значення:
- P(v) = true: частковий розв'язок не порушує жодного з визначених обмежень задачі. Пошук можна продовжувати вглиб.
- P(v) = false: частковий розв'язок містить міжатрибутний конфлікт. Жодне розширення цього стану не може бути допустимим розв'язком.

Математичною основою відтинання є **властивість монотонності обмежень**:

```
Якщо P(x₁, x₂, ..., xₖ) = false,
то для будь-якого розширення v' = (x₁, x₂, ..., xₖ, xₖ₊₁, ..., xₘ)
також виконується P(v') = false.
```

Ця фундаментальна властивість гарантує алгебраїчну коректність відтинання: якщо предикат повертає `false` для часткового стану, алгоритм може з повною математичною впевненістю вилучити все піддерево без ризику втратити бодай один дійсний розв'язок.

Якщо на рівні k ми отримуємо P(v) = false, піддерево T(v) з коренем у вузлі v негайно вилучається з розгляду. Кількість вузлів N_pruned, які оминаються завдяки одному відтинанню на рівні k у дереві з постійним розгалуженням b, дорівнює:

```
N_pruned = b + b² + b³ + ... + bᵈ⁻ᵏ
         = (bᵈ⁻ᵏ⁺¹ - b) / (b - 1)
         = O(bᵈ⁻ᵏ)
```

Отже, чим раніше (тобто на меншій глибині k) спрацьовує предикат обмеження, тим експоненціально більша кількість вузлів відтинається від обходу за один крок. Відтинання на рівні k = 1 зберігає O(bᵈ⁻¹) обчислювальних кроків, тоді як відтинання на останньому рівні k = d - 1 зберігає лише b вузлів.

## Ефективний коефіцієнт розгалуження (b_eff)

Оскільки реальна форма відтятого дерева станів стає нерівномірною через різну глибину спрацьовування предикатів, для оцінки практичної складності використовують концепцію **ефективного коефіцієнта розгалуження (Effective Branching Factor, b_eff)**.

Якщо під час розв'язання задачі з глибиною дерева d алгоритм фактично відвідав N_actual вузлів, то b_eff визначається як єдиний додатній корінь поліноміального рівняння:

```
1 + b_eff + b_eff² + ... + b_effᵈ = N_actual
```

### Математичний розрахунок на прикладі 8 Ферзів

Проілюструємо потужність відтинання на класичному прикладі задачі про 8 ферзів (d = 8).

1. **Повний бездумний перебір (без обмежень)**:
   Розміщення 8 ферзів на 64 клітинках:
   ```
   N_brute = 64! / (56! · 8!) = 4 426 165 368 вузлів
   ```

2. **Обмеження «один ферзь у стовпчику»**:
   Вибір позиції у кожному з 8 стовпчиків:
   ```
   N_cols  = 8⁸ = 16 777 216 вузлів
   ```

3. **Обмеження «один ферзь у стовпчику та рядку» (перестановки)**:
   ```
   N_perm  = ∑ (k = 0 .. 8) [ 8! / (8 - k)! ] = 109 601 вузол
   ```

4. **Повний Backtracking (відтинання по рядках, стовпчиках і діагоналях)**:
   Фактична кількість відвіданих вузлів дерева становить лише:
   ```
   N_backtrack = 2 057 вузлів!
   ```

Обчислимо ефективний коефіцієнт розгалуження b_eff для backtracking:

```
1 + b_eff + b_eff² + ... + b_eff⁸ = 2 057
b_eff ≈ 1.87
```

Завдяки предикатам відтинання теоретичний коефіцієнт розгалуження b = 8 зменшився до b_eff ≈ 1.87. Це означає, що алгоритм досліджує лише 0.012% від простору перестановок і 0.000046% від повного простору розміщень.

## Метод оцінки Кнута (Knuth's Estimator)

Оскільки точний обчислювальний обсяг N_actual залежить від конкретної інстанції задачі і не завжди може бути знайдений аналітично, Дональд Кнут (Donald Knuth) розробив імовірнісний метод оцінки розміру дерева пошуку за допомогою Монте-Карло семплювання.

Метод полягає у випадковому спуску від кореня дерева до будь-якого листка:

1. Починаємо в корені r. Призначимо початкову вагу оцінки W = 1.
2. На кожному кроці i (починаючи з i = 0):
   - Знаходимо множину всіх Cⲕ допустимих наступників вузла, для яких P(v) = true.
   - Якщо d_i = |Cⲕ| == 0 (глухий кут або розв'язок), процес зупиняється.
   - Інакше вибираємо одного наступника **рівноймовірно** з імовірністю 1 / d_i.
   - Оновлюємо вагу: W = W · d_i.
3. Оцінка загальної кількості вузлів для одного випадкового проходу обчислюється як:

```
N_est = 1 + d₀ + (d₀ · d₁) + (d₀ · d₁ · d₂) + ... + W
```

Математичне сподівання величини N_est строго дорівнює точній кількості вузлів у дереві: E[N_est] = N_actual. 

Усереднення N_est за кількома десятками випадкових проходів дає незміщену математичну оцінку реального розміру дерева станів без необхідності його повного виснажливого обходу. Це дозволяє заздалегідь оцінити час виконання програми для великих комбінаторних задач.
