# 🧮 Викладки високої розмірності: об'єм, розкид і дві теореми

З d координатами геометрія робить лише дві речі: перемножує їх — так рахується об'єм, і додає — так рахується квадрат відстані. Обидві дії мають точні формули, і саме з них випливають обидві теореми, на яких тримається пошук за схожістю.

## Об'єм кулі: звідки там гамма-функція

Об'єм d-вимірної кулі не вгадується з площі круга, зате виводиться рекурсією. Розріжте кулю площиною двох перших координат: над кожною точкою (x, y) одиничного круга стоїть (d−2)-вимірна куля радіуса √(1−x²−y²). Лишається зінтегрувати її об'єм по кругу, зручніше в полярних координатах:

```
V_d(1) = ∫∫ V_(d−2)(√(1−x²−y²)) dx dy        по кругу x²+y² ≤ 1
       = V_(d−2)(1) · 2π · ∫₀¹ r·(1−r²)^((d−2)/2) dr
       = V_(d−2)(1) · 2π/d
```

Внутрішній інтеграл береться заміною u = 1−r²: ∫₀¹ r(1−r²)^m dr = 1/(2(m+1)), а при m = (d−2)/2 це рівно 1/d. Два початкові значення відомі напряму: V₁(1) = 2 — довжина відрізка від −1 до 1, V₂(1) = π — площа круга.

Ось тут і з'являється гамма-функція. Рекурсія крокує через два виміри, тож замкнений вираз мусить містити функцію, яка при кроці на одиницю аргументу множиться на сам аргумент: саме таку властивість Γ(z+1) = z·Γ(z) має [гамма-функція](book:math/gamma-function) — неперервне продовження факторіала на дробові аргументи. Вона підходить точно:

```
V_d(r) = π^(d/2) · r^d / Γ(d/2 + 1)

перевірка:  V_d/V_(d−2) = π · Γ(d/2)/Γ(d/2+1) = π/(d/2) = 2π/d   ✓
```

Множник 2π/d стає меншим за одиницю, щойно d > 2π ≈ 6.28. Тому об'єм одиничної кулі спершу росте, а тоді починає танути; максимум над цілими вимірами припадає на d = 5.

```
d :  1     2     3     4     5     6     7     10     13
V :  2.00  3.14  4.19  4.93  5.26  5.17  4.72  2.55   0.91
```

Тепер упишімо кулю в одиничний куб — радіус 1/2, об'єм куба одиничний:

```
V_d(1/2) = π^(d/2) / (2^d · Γ(d/2+1)) = V_d(1) · 0.5^d

d =   2  →  0.785           d =  20  →  2.46·10⁻⁸
d =   3  →  0.524           d =  50  →  1.54·10⁻²⁸
d =  10  →  2.49·10⁻³       d = 100  →  1.87·10⁻⁷⁰
```

Правий бік першого рядка вартий уваги: частка куба, яку займає вписана куля, — це об'єм одиничної кулі, помножений на 0.5^d. Другий множник — чиста експонента, а перший, як щойно з'ясувалося, після п'ятого виміру теж тане. Добуток двох спадань і спадає швидше за експоненту.

Наскільки швидше, показує [формула Стірлінга](book:math/stirling-approximation) Γ(z+1) ≈ √(2πz)·(z/e)^z при z = d/2:

```
V_d(1/2) ≈ (1/√(πd)) · (πe/(2d))^(d/2)
```

Наближення добре вже на малих вимірах: +1.7% при d = 10 і +0.17% при d = 100. Корінь d-го степеня з цього виразу — це √(πe/(2d)), і він прямує до нуля, тоді як у будь-якої експоненти c^d корінь d-го степеня сталий і дорівнює c. Отже, для кожного фіксованого c > 0 знайдеться вимір, після якого куля займає менше за c^d частку куба. Для c = 1/2 цей злам настає на d = 13, а при d = 100 куля вже в 4·10³⁹ разів дрібніша за 0.5¹⁰⁰.

![Ліворуч — стовпчики об'єму кулі радіуса 1 для вимірів від першого до чотирнадцятого: висота росте до п'ятого стовпчика, де сягає 5.26, а далі неухильно спадає, до 0.91 на тринадцятому. Праворуч — логарифмічна крива частки куба, яку займає вписана куля: вона починається від одиниці, проходить 10⁻³ на десятому вимірі й 10⁻⁷⁰ на сотому, весь час вигинаючись донизу від пунктирної прямої, що зображує чисту експоненту 0.5 у степені d](/book/algorithms/string-geometry-streaming/curse-of-dimensionality/img/ball-volume-collapse.svg)
*На логарифмічній шкалі будь-яка експонента — пряма лінія. Крива вписаної кулі відходить від прямої вниз і відстає від неї дедалі більше: це і є «швидше за будь-яку експоненту».*

Той самий показник d керує й тим, де об'єм лежить. Стиснути тіло до частки (1−ε) початкового радіуса — означає помножити об'єм на (1−ε)^d, бо об'єм однорідний степеня d за масштабом. Отже, у шкаралупі завтовшки ε від краю сидить

```
1 − (1−ε)^d
d =  100,  ε = 0.01   →  63.4%
d = 1000,  ε = 0.01   →  99.996%
```

Питати зручніше навпаки: якої товщини шкаралупа, у якій рівно половина об'єму? З рівняння (1−ε)^d = 1/2 виходить ε = 1 − 2^(−1/d) ≈ ln2/d. При d = 100 це 0.69% радіуса: половина кулі лежить у плівці завтовшки менш ніж сота частка її розміру.

## Розкид відстаней: повне виведення для рівномірних координат

Нехай координати точок незалежні й однаково розподілені. Тоді квадрат відстані розкладається на d незалежних однакових доданків:

```
D² = Σᵢ Wᵢ²,   Wᵢ = xᵢ − yᵢ
E[D²]   = d · E[W²]
Var[D²] = d · Var[W²]
```

Обидва рядки — це звичайне [додавання середніх і дисперсій](book:math/mean-variance) незалежних доданків: обидві суми ростуть пропорційно d, але розкид міряють коренем із дисперсії, тож він росте лише як √d.

Лишається порахувати два числа для конкретного розподілу. Для рівномірних координат на [0, 1] потрібна густина різниці W = x − y — це [згортка](book:math/convolution) двох рівномірних густин:

```
f(w) = ∫ f_x(t) · f_y(t−w) dt
```

Підінтегральний вираз дорівнює одиниці там, де водночас t ∈ [0, 1] (тобто x у своєму відрізку) і t−w ∈ [0, 1] (тобто y у своєму), тобто t ∈ [w, 1+w]. Значення інтеграла — це просто довжина спільної частини двох відрізків однакової довжини, зсунутих на w:

```
f(w) = 1 − |w|,   |w| ≤ 1
```

![Ліворуч — три горизонтальні смуги: верхня позначає значення t, за яких x потрапляє у відрізок від нуля до одиниці; середня, зсунута праворуч на w, позначає значення t, за яких y потрапляє у свій відрізок; нижня, зелена й коротша, — спільна частина двох попередніх, підписана «1 − |w|». Праворуч — сама густина: рівнобедрений трикутник із вершиною одиничної висоти над нулем і основою від мінус одиниці до одиниці, з підписами «площа під кривою = 1», «E[W²] = 1/6», «Var[W²] = 7/180»](/book/algorithms/string-geometry-streaming/curse-of-dimensionality/img/difference-density.svg)
*Густина різниці двох рівномірних величин трикутна, бо міряє довжину перекриття двох відрізків: воно найбільше при нульовому зсуві й лінійно зникає до країв.*

Далі — два інтеграли по цій густині, обидва парні, тому беремо подвоєну половину:

```
E[W²] = 2·∫₀¹ u²(1−u) du = 2·(1/3 − 1/4) = 1/6
E[W⁴] = 2·∫₀¹ u⁴(1−u) du = 2·(1/5 − 1/6) = 1/15

Var[W²] = E[W⁴] − (E[W²])² = 1/15 − 1/36 = 7/180
```

Тепер відносний розкид квадрата відстані рахується без жодних наближень:

```
Var[D²] / E[D²]² = (d·7/180) / (d/6)² = 7/(5d) = 1.4/d
σ[D²] / E[D²]    = √(1.4/d) = 1.1832/√d
```

Це не асимптотика, а точна рівність для кожного d. А от перехід до самої відстані D = √(D²) точним уже не буде. Позначмо D² = E[D²]·(1+δ), де E[δ] = 0, а E[δ²] = R = 1.4/d. [Ряд Тейлора](book:math/taylor-series) для кореня дає √(1+δ) = 1 + δ/2 − δ²/8 + …, звідки видно і головний множник ½, і першу поправку:

```
E[D]        ≈ √E[D²] · (1 − R/8)
σ[D]        ≈ √E[D²] · √R/2
σ[D]/E[D]   ≈ (√R/2)·(1 + R/8) = 0.5916/√d · (1 + 0.175/d)
```

Множник ½ з'являється просто тому, що корінь — це степінь ½: відносне відхилення під коренем перетворюється на вдвічі менше відносне відхилення кореня. Розкладання ж іде за степенями R = 1.4/d, тож наближення тим гірше, чим менша розмірність:

```
d       справжнє   0.5916/√d   з поправкою
2       0.4755     0.4183      0.4549
3       0.3770     0.3416      0.3615
10      0.1935     0.1871      0.1904
200     0.0419     0.0418      0.0419
```

Для d = 2 середню відстань між випадковими точками квадрата знають у замкненому вигляді, (2 + √2 + 5·ln(1+√2))/15 = 0.52141, а E[D²] = 1/3 дає точну дисперсію; решта рядків — чисельний експеримент на 400 тисячах пар. Причина зламу видна з тієї ж викладки: лінеаризація кореня вимагає, щоб D² трималося подалі від нуля, а при d = 2 помітна частка пар лежить удвічі ближче за середнє, де корінь від лінійного далекий. При d = 200 обидва наближення збігаються з виміром до третьої значущої цифри.

## Теорема Бейєра — Ґолдстайна — Рамакрішнана — Шафта

Порахований щойно відносний розкид — це рівно та величина, якою сформульовано умову теореми 1 із праці Кевіна Бейєра, Джонатана Ґолдстайна, Рагу Рамакрішнана й Урі Шафта «When Is "Nearest Neighbor" Meaningful?» (ICDT'99, LNCS 1540, с. 217–235).

Умови такі: кількість точок бази n **фіксована** й не залежить від розмірності; точки P₍m,1₎, …, P₍m,n₎ незалежні й однаково розподілені; запит Q_m від них не залежить; d_m — довільна функція відстані, p > 0 — стале число. Якщо

```
lim   Var( d_m(P₍m,1₎, Q_m)^p / E[d_m(P₍m,1₎, Q_m)^p] ) = 0
m→∞
```

то для кожного ε > 0

```
lim   P[ DMAX_m ≤ (1+ε)·DMIN_m ] = 1
m→∞
```

де DMIN_m і DMAX_m — найменша й найбільша з n відстаней від запиту до точок бази. Інакше кажучи, DMAX/DMIN прямує до одиниці за ймовірністю.

Доведення — три кроки. Величина V_m = d^p/E[d^p] має середнє рівно одиницю за побудовою, а її дисперсія за умовою прямує до нуля; за [нерівністю Чебишова](book:math/chebyshev-inequality) цього досить, щоб V_m збігалася до одиниці за ймовірністю. Далі вектор із n таких величин збігається до (1, …, 1). Нарешті мінімум і максимум — неперервні функції, тому збіжність переноситься й на них, а відношення двох збіжностей із ненульовою границею дає одиницю; цей крок автори роблять теоремою Слуцького (Євген Слуцький — український математик і статистик, що викладав у Київському комерційному інституті).

Три застереження, без яких теорему легко прочитати ширше, ніж вона твердить.

Перше: n фіксоване. Розмірність росте, а база — ні. Про випадок, коли база росте разом із розмірністю, теорема не каже нічого.

Друге: умова стосується самої лише відносної дисперсії, а не незалежності координат. Автори наголошують, що їхні умови ширші за припущення про незалежні однаково розподілені виміри, і наводять приклад, до якого [закон великих чисел](book:math/law-of-large-numbers) незастосовний, а умова теореми виконана. Наша рівність 1.4/d — це просто найпростіший спосіб цю умову задовольнити: при p = 2 і рівномірних координатах вона прямує до нуля, отже, теорема застосовна.

Третє: імплікація одностороння. Якщо відносна дисперсія до нуля не прямує, теорема мовчить. Обернене твердження довели пізніше Роберт Даррант і Ата Кабан (*Journal of Complexity*, 25(4), 2009, с. 385–397): для лінійних моделей із прихованими змінними евклідова відстань **не** концентрується, поки кількість «значущих» напрямів росте не повільніше за загальну розмірність. Це і є точне формулювання того, що заощаджує пошук на справжніх даних.

## Скільки вимірів досить: оцінка Дасгупти — Ґупти

Зворотний бік тієї самої концентрації — [випадкова проєкція](book:algorithms/random-projection). Санджой Дасгупта й Анупам Ґупта дали лемі Джонсона — Лінденштрауса коротке доведення з явною сталою (*Random Structures & Algorithms*, 22(1), 2003, с. 60–65). Теорема 2.1 їхньої праці:

```
для будь-яких 0 < ε < 1 і цілого n візьмімо ціле
    k ≥ 4·ln n / (ε²/2 − ε³/3)
тоді для будь-якої множини V з n точок у ℝ^d існує відображення f: ℝ^d → ℝ^k,
для якого при всіх u, v ∈ V
    (1−ε)·‖u−v‖² ≤ ‖f(u)−f(v)‖² ≤ (1+ε)·‖u−v‖²
```

Кожна частина цієї оцінки має просте походження. Відображення f — це проєкція на випадковий k-вимірний підпростір, помножена на √(d/k). Квадрат довжини проєкції одиничного вектора має середнє k/d, а хвости оцінюються звичайною нерівністю Чернова через суму квадратів k незалежних [нормальних](book:math/normal-distribution) величин; для верхнього хвоста виходить exp(−k(ε²/2 − ε³/3)/2), для нижнього — exp(−kε²/4). Пар точок менше за n²/2, тож щоб об'єднавча нерівність лишила ймовірність невдачі нижче одиниці, кожен хвіст має бути не більшим за n⁻². Прирівнявши показник до 2·ln n, дістаємо саме 4·ln n у чисельнику: двійка від n² пар і ще двійка від множника ½ у показнику. Знаменник ε²/2 − ε³/3 — це показник Чернова для верхнього хвоста, і саме він тут вирішує: нижній хвіст сам по собі вимагав би лише 8·ln n/ε². Тобто k призначає страх перед розтягом відстані, а не перед стисненням.

**Скільки координат треба на n точок при заданій похибці ε:**

```
n = 10⁶,  ε = 0.5  →  k ≥ 663.1    →  664
n = 10⁹,  ε = 0.5  →  k ≥ 994.7    →  995
n = 10⁶,  ε = 0.2  →  k ≥ 3188.2   →  3189
n = 10⁶,  ε = 0.1  →  k ≥ 11841.9  →  11842
```

Перші два рядки — про ln n: база більша в тисячу разів, а координат треба лише в півтора раза більше. Останні два — про ε⁻²: удвічі точніші відстані коштують у 3.7 раза більше координат, а перехід від ε = 0.5 до ε = 0.1 — у 17.9 раза (чиста квадратична залежність обіцяла б 25; різницю дає той самий доданок −ε³/3, що при великих ε помітно роздуває оцінку).

Оцінка щільна за побудовою, і це видно на числах:

```
n = 10⁶, ε = 0.5, k = 664
показник хвоста:  k·(ε²/2 − ε³/3)/2 = 664 · 0.08333 / 2 = 27.67
ймовірність:      e^(−27.67) = 9.6·10⁻¹³   <   n⁻² = 10⁻¹²
```

Запасу в сталій 4 немає: вона рівно така, якою її робить вимога, щоб у мільйона точок не знайшлося жодної зіпсованої пари.

Лишається помітити, чим тут узагалі забезпечено точність. Відносний розкид квадрата довжини проєкції дорівнює √(2/k): при k = 664 це 5.5%, тож дозволена похибка ε = 0.5 лежить аж за дев'ять стандартних відхилень від середнього. Та сама 1/√розмірності, що злиплює відстані між сусідами, тут і дає всі гарантії — з тією різницею, що k ми обираємо самі.
