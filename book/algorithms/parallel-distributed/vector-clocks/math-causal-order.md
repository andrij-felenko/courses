# 🧮 Математичні основи причинного порядку та векторних ґраток

Розподілена система без спільної пам'яті описується множиною подій, пов'язаних відношенням передачі інформації. Щоб точно відрізняти причину від наслідку й виявляти паралельні дії, простір подій формалізують як частково впорядковану множину (посет), а часові мітки — як вектори в алгебраїчній ґратці.

Математична задача полягає в побудові відображення з множини подій у числовий векторний простір, яке є строгим порядковим ізоморфізмом.

## Модель розподіленої системи та відношення Лампорта

Нехай розподілена система складається зі скінченної множини з `n` процесів:
```
P = {P₁, P₂, ..., Pₙ}
```

Кожен процес `P_i` виконує строго послідовну послідовність внутрішніх дій, відправлень та отримань повідомлень. Множина всіх подій у системі позначається через `E`. Для кожного процесу `P_i` множина його локальних подій `E_i ⊂ E` лінійно впорядкована локальним відношенням слідування `<_i`.

На множині `E` вводиться бінарне відношення **причинного слідування** (відношення Лампорта `→`, або *happened-before*), яке визначається трьома правилами:

1. **Локальний порядок:** Якщо події `a, b ∈ E_i` відбулися в межах одного процесу `P_i`, і `a <_i b`, то `a → b`.
2. **Передача повідомлення:** Якщо подія `s ∈ E` є відправленням повідомлення процесом `P_i`, а подія `r ∈ E` — отриманням цього ж повідомлення процесом `P_j`, то `s → r`.
3. **Транзитивність:** Якщо `a → b` і `b → c`, то `a → c`.

### Властивості відношення `→`

Відношення `→` є **строгим частковим порядком** на множині `E`:
- **Іррефлексивність:** Для будь-якої події `a ∈ E` вираз `a → a` є хибним (подія не може бути власною причиною за відсутності часових петель у фізичній передачі сигналів).
- **Асиметричність:** Якщо `a → b`, то вираз `b → a` обов'язково є хибним.
- **Транзитивність:** Прямо зафіксована правилом 3.

Пара `(E, →)` утворює частково впорядковану множину (англ. *partially ordered set*, або *poset*).

### Конкурентність (паралельність) подій

Дві події `a, b ∈ E` називаються **конкурентними** (або незалежними, позначається `a ∥ b`), якщо між ними немає прямого або опосередкованого причинного зв'язку:
```
a ∥ b ⟺ ¬(a → b) ∧ ¬(b → a)
```

Геометрично кожна подія `e` ділить простір подій `E` на чотири неперетинні підмножини:
- **Причинне минуле (минулий конус):** `Past(e) = { x ∈ E | x → e }`
- **Причинне майбутнє (майбутній конус):** `Future(e) = { x ∈ E | e → x }`
- **Сама подія:** `{e}`
- **Причинно незалежні події (конкурентна зона):** `Conc(e) = { x ∈ E | x ∥ e }`

Будь-яка підмножина взаємно паралельних подій `A ⊆ E` (де `∀ x, y ∈ A, x ≠ y ⟹ x ∥ y`) у теорії порядків називається **антиланцюгом** (англ. *antichain*).

## Векторні простори міток та їхній порядок

Для фіксації часткового порядку `(E, →)` кожній події `e ∈ E` ставиться у відповідність вектор із `n` цілих невід'ємних чисел у просторі `ℕⁿ`:
```
V(e) = [v₁, v₂, ..., vₙ]
```
де компонент `v_k = V(e)[k]` дорівнює кількості подій процесу `P_k`, які причинно передують події `e` (включаючи саму подію `e`, якщо вона належить процесу `P_k`).

### Порядкові відношення над векторами

Для двох векторів `u, v ∈ ℕⁿ` вводяться такі стандартні операції та відношення:

**1. Частковий нестрогий порядок (`≤`):**
```
u ≤ v ⟺ ∀ k ∈ {1, ..., n}: u[k] ≤ v[k]
```
Вектор `u` не перевищує `v` тоді й лише тоді, коли кожен компонент `u` менший або рівний за відповідний компонент `v`.

**2. Строгий частковий порядок (`<`):**
```
u < v ⟺ (u ≤ v) ∧ (u ≠ v)
```
Еквівалентно: `u ≤ v` і існує хоча б один індекс `j ∈ {1, ..., n}` такий, що `u[j] < v[j]`.

**3. Непорівнянність (конкурентність) векторів (`∥`):**
```
u ∥ v ⟺ ¬(u ≤ v) ∧ ¬(v ≤ u)
```
Це означає існування хоча б двох різних індексів `i, j` таких, що `u[i] < v[i]`, але `u[j] > v[j]`.

## Теорема про ізоморфізм Фіджа — Маттерна

Головний теоретичний результат, що лежить в основі векторних годинників, формулюється наступною теоремою.

**Теорема (Характеризація причинності через векторні мітки):**
Нехай векторні мітки призначаються подіям за правилами алгоритму векторного годинника. Тоді для будь-яких двох подій `a, b ∈ E`:
```
a → b ⟺ V(a) < V(b)
a ∥ b ⟺ V(a) ∥ V(b)
```

### Доведення (Пряма та зворотна імплікації)

**Частина 1: `a → b ⟹ V(a) < V(b)`**

Доведення проводиться індукцією за довжиною найкоротшого причинного ланцюга від `a` до `b`.

*База індукції:* Нехай `b` є безпосереднім наслідком `a`. Можливі два випадки:
1. Події відбулися в одному процесі `P_i`, причому `b` слідує одразу за `a`. За алгоритмом векторного годинника:
   ```
   V(b)[i] = V(a)[i] + 1
   V(b)[k] = V(a)[k]  (для всіх k ≠ i)
   ```
   Звідси `V(a) ≤ V(b)` і `V(a)[i] < V(b)[i]`, отже `V(a) < V(b)`.
2. Подія `a` — це відправлення повідомлення процесом `P_i`, а `b` — його отримання процесом `P_j` (`i ≠ j`). Перед відправленням процес `P_i` зафіксував вектор `V(a)`. При отриманні `P_j` обчислює:
   ```
   V(b)[k] = max(V_local[k], V(a)[k])  (для всіх k ≠ j)
   V(b)[j] = max(V_local[j], V(a)[j]) + 1
   ```
   Для всіх `k` маємо `V(b)[k] ≥ V(a)[k]`. Крім того, оскільки локальний лічильник `P_j` додатково інкрементується, маємо `V(a) < V(b)`.

*Крок індукції:* Якщо ланцюг складається з `m` кроків `a = e₀ → e₁ → ... → e_m = b`, то за припущенням індукції `V(a) < V(e₁) < ... < V(b)`. З транзитивності строгого порядку на `ℕⁿ` випливає `V(a) < V(b)`.

**Частина 2: `V(a) < V(b) ⟹ a → b`**

Нехай подія `a` сталася на процесі `P_i`, тобто `a ∈ E_i`. За конструкцією алгоритму, компонент `V(e)[i]` збільшується **виключно** під час виконання локальних подій на процесі `P_i`. Будь-який інший процес `P_j` може збільшити свій `i`-й компонент лише шляхом отримання повідомлення, яке містить вектор із вищим значенням `i`-го лічильника.

Оскільки `V(a) < V(b)`, то зокрема:
```
V(a)[i] ≤ V(b)[i]
```
Значення `V(a)[i]` відповідає точному порядковому номеру події `a` у послідовності процесу `P_i`. Щоб процес, на якому сталася подія `b`, мав значення `i`-ї координати не менше ніж `V(a)[i]`, інформація про подію `a` мусила дійти до події `b` через послідовність передачі повідомлень або локальних переходів. Отже, подія `a` належить причинному минулому події `b`:
```
a ∈ Past(b) ⟹ a → b
```

Оскільки відношення `→` та `<` є строгими порядками, еквівалентність для паралельних подій випливає як прямий логічний наслідок:
```
a ∥ b ⟺ ¬(a → b) ∧ ¬(b → a) ⟺ ¬(V(a) < V(b)) ∧ ¬(V(b) < V(a)) ⟺ V(a) ∥ V(b)
```
Теорему доведено повністю.

## Алгебраїчна структура: Ґратка векторів

Множина векторів `ℕⁿ` разом із частковим порядком `≤` утворює **дистрибутивну повну напівґратку об'єднання** (join-semilattice) і повну ґратку (lattice).

Для будь-яких двох векторів `u, v ∈ ℕⁿ`:

**1. Операція об'єднання (Join / Супремум `⊔`):**
```
(u ⊔ v)[k] = max(u[k], v[k])   (для всіх k ∈ {1, ..., n})
```
Вектор `u ⊔ v` є найменшою спільною верхньою межею (least upper bound): він представляє мінімальний причинний стан, що охоплює всю історію подій, відому як у `u`, так і в `v`.

Властивості операції `⊔`:
- **Комутативність:** `u ⊔ v = v ⊔ u`
- **Асоціативність:** `(u ⊔ v) ⊔ w = u ⊔ (v ⊔ w)`
- **Ідемпотентність:** `u ⊔ u = u`
- **Монотонність:** `u ≤ v ⟹ (u ⊔ w) ≤ (v ⊔ w)`

**2. Операція перетину (Meet / Інфімум `⊓`):**
```
(u ⊓ v)[k] = min(u[k], v[k])   (для всіх k ∈ {1, ..., n})
```
Вектор `u ⊓ v` представляє найбільшу спільну нижню межу (greatest lower bound) — спільну причинну історію двох спостережень.

## Теорема Шаррон-Боста про розмірність векторів (1991)

Природним є запитання: чи можна зменшити розмір векторної мітки (наприклад, стиснути її до `k < n` чисел), зберігши при цьому строгий ізоморфізм причинності?

У 1991 році французька дослідниця Бернадетт Шаррон-Бост (Bernadette Charron-Bost) опублікувала фундаментальну теорему про розмірність простору логічного часу.

**Теорема Шаррон-Боста:**
Для довільної розподіленої системи з `n` взаємодіючих процесів розмірність часткового порядку причинності `dim(E, →)` у загальному випадку дорівнює `n`. Отже, будь-яке відображення подій у векторний простір `ℝ^k` або `ℕ^k`, що зберігає частковий порядок `a → b ⟺ V(a) < V(b)`, вимагає розмірності:
```
k ≥ n
```

Це доводить, що векторні годинники розміру `n` є математично мінімально можливим точним представленням причинності в розподілених системах без додаткових топологічних обмежень.
