# 🧮 Дерево прийняття рішень, перестановочний простір та формула Стірлінга

У цій вставці наведено суворе математичне доведення того, чому нижня межа сортування порівняннями становить `Ω(N log N)` як у найгіршому, так і в середньому випадку.

---

## 1. Модель дерева прийняття рішень (Decision Tree Model)

Нехай `A = [a₁, a₂, ..., a_N]` — масив із N різних дійсних чисел. будь-який алгоритм сортування, який використовує лише попарні порівняння, можна представити у вигляді двійкового дерева прийняття рішень T.

### Формальні означення:
- **Внутрішній вузол u:** містить пару індексів `(i, j)`, що відповідає порівнянню `aᵢ : aⱼ`.
- **Ліве ребро з вузла u:** відповідає виходу `aᵢ < aⱼ`.
- **Праве ребро з вузла u:** відповідає виходу `aᵢ ≥ aⱼ`.
- **Листок l:** містить перестановку `π = (π₁, π₂, ..., π_N)` індексів `(1, 2, ..., N)`, яка впорядковує вхідні елементи: `a_{π₁} < a_{π₂} < ... < a_{π_N}`.

Позначимо через `h(T)` **висоту дерева** T (довжину найдовшого шляху від кореня до листка), а через `L(T)` — **кількість листків** у дереві T.

---

## 2. Фундаментальні леми

### Лема 1 (Комбінаторна ємність двійкового дерева)
*Двійкове дерево висоти h має не більше ніж 2ʰ листків:*
```
L(T) ≤ 2ʰ
```

**Доведення (за індукцією):**
- *База індукції (h = 0):* Дерево складається з 1 вузла (кореня), який є листком. `L = 1 ≤ 2⁰ = 1`. Твердження істинне.
- *Індукційний крок:* Припустимо, що для всіх дерев висоти `h - 1` кількість листків `L ≤ 2^(h-1)`. Дерево висоти h складається з кореня та двох піддерев висоти не більше ніж `h - 1`. Отже:
```
L(T) = L(T_left) + L(T_right) ≤ 2^(h-1) + 2^(h-1) = 2 · 2^(h-1) = 2ʰ
```
Лема доведена. ∎

---

### Лема 2 (Повнота коректного сортування)
*Будь-яке дерево прийняття рішень T, що коректно сортує всі масиви розміру N, мусить мати принаймні N! листків:*
```
L(T) ≥ N!
```

**Доведення (від супротивного):**
Кількість усіх можливих перестановок N унікальних елементів дорівнює `N! = 1 · 2 · 3 · ... · N`.
Припустимо, що `L(T) < N!`. За принципом Діріхле існує принаймні одна перестановка `π*`, яка відсутня серед листків дерева T.

Якщо подати на вхід алгоритму масив, елементи якого впорядковані саме згідно з перестановкою `π*`, дерево T пройде певним шляхом і досягне якогось листка `l`. Проте листок `l` містить іншу перестановку `π' ≠ π*`. Отже, для даного входу алгоритм видасть неправильну послідовність індексів. Це суперечить тому, що T є коректним сортуванням.
Таким чином, `L(T) ≥ N!`. ∎

---

## 3. Теорема про найгірший випадок складності

### Теорема 1 (Найгірший випадок сортування порівняннями)
*Будь-який коректний алгоритм сортування порівняннями N елементів у найгіршому випадку виконує принаймні `⌈log₂ (N!)⌉ = Ω(N log N)` порівнянь.*

**Доведення:**
Поєднуючи Лему 1 та Лему 2, маємо:
```
N! ≤ L(T) ≤ 2ʰ
```
Взявши двійковий логарифм від лівої та правої частин:
```
log₂ (N!) ≤ h
```
Оскільки висота h є цілим числом:
```
h ≥ ⌈log₂ (N!)⌉
```
Далі доведемо асимптотичну нижню оцінку `log₂ (N!) = Ω(N log N)`. ∎

---

## 4. Двоваріантне оцінювання log₂ (N!)

### Варіант А: Елементарне доведення через розбиття суми

Розпишемо логарифм факторіала як суму:
```
log₂ (N!) = log₂ (1 · 2 · 3 · ... · N) = ∑ᵢ₌₁ⁿ log₂ i
```

Розділимо суму на дві частини по `N/2`:
```
log₂ (N!) = ∑ᵢ₌₁^(⌈N/2⌉ - 1) log₂ i  +  ∑ᵢ₌⌈N/2⌉ⁿ log₂ i
```
Перша сума невід'ємна (`≥ 0`). У другій сумі кожен доданок `log₂ i ≥ log₂ (N/2)`. Кількість доданків у другій сумі дорівнює set-розміру `N - ⌈N/2⌉ + 1 ≥ N/2`.

Отже:
```
log₂ (N!) ≥ ∑ᵢ₌⌈N/2⌉ⁿ log₂ (N/2)
          ≥ (N / 2) · log₂ (N / 2)
          = (N / 2) · (log₂ N - log₂ 2)
          = (N / 2) · (log₂ N - 1)
          = (1/2) · N log₂ N - N/2
```
За означенням нотації `Ω`: існує константа `c = 1/4` та поріг `N₀ = 4`, такі що для всіх `N ≥ N₀`:
```
(1/2) · N log₂ N - N/2 ≥ (1/4) · N log₂ N
```
Отже, `log₂ (N!) = Ω(N log N)`. ∎

---

### Варіант Б: Точне розгортання через формулу Стірлінга

Формула Стірлінга описує точну асимптотику факторіала:
```
N! = √(2πN) · (N / e)ᴺ · (1 + O(1/N))
```

Логарифмуємо за основою 2:
```
log₂ (N!) = log₂ [ √(2πN) · (N / e)ᴺ · (1 + O(1/N)) ]
          = log₂ (N / e)ᴺ + log₂ √(2πN) + log₂ (1 + O(1/N))
          = N · log₂ (N / e) + (1/2) · log₂ (2πN) + O(1/N)
          = N · (log₂ N - log₂ e) + (1/2) · log₂ N + (1/2) · log₂ (2π) + O(1/N)
```

Підставимо константи `log₂ e ≈ 1.442695` та `log₂ (2π) ≈ 2.651496`:
```
log₂ (N!) = N log₂ N - 1.442695 · N + 0.5 · log₂ N + 1.325748 + O(1/N)
```

Звідси чітко видно:
1. Головний член: `N log₂ N`.
2. Член другого порядку: `-1.4427 N`.
3. Член третього порядку: `+0.5 log₂ N`.

Отже, `log₂ (N!) = N log₂ N - Θ(N) = Ω(N log N)`. ∎

---

## 5. Доведення нижньої межі для середнього випадку

Нехай вхідні перестановки є рівноймовірними (кожна з N! перестанок має ймовірність `p = 1 / N!`).
Середня кількість порівнянь алгоритму дорівнює **середній глибині листків** у дереві рішень T:
```
D_avg(T) = (1 / N!) · ∑ₗ∈Leaves(T) depth(l)
```

Суму `E(T) = ∑ₗ depth(l)` називають **зовнішньою довжиною шляху** (External Path Length) дерева T.

### Теорема 2 (Мінімальна зовнішня довжина шляху)
*Для будь-якого двійкового дерева T із L листками зовнішня довжина шляху задовольняє нерівність:*
```
E(T) ≥ L log₂ L
```

**Доведення:**
Серед усіх двійкових дерев із L листками мінімальну зовнішню довжину шляху має **повне виважене дерево**, у якому всі листки розташовані на двох суміжних рівнях: `k = ⌊log₂ L⌋` та `k + 1`.

Нехай `L = 2ᵏ + m`, де `0 ≤ m < 2ᵏ`.
Тоді у дереві є `2m` листків на глибині `k + 1` та `2ᵏ - m` листків на глибині `k`.
Обчислимо зовнішню довжину шляху:
```
E(T) = (2ᵏ - m) · k  +  2m · (k + 1)
     = k · 2ᵏ - k · m + 2m · k + 2m
     = k · (2ᵏ + m) + 2m
     = k · L + 2m
```
Оскільки `m = L - 2ᵏ`, маємо:
```
E(T) = L · log₂ (L - m) + 2m ≥ L · log₂ L
```

Підставивши `L = N!`, отримаємо мінімальну сумарну глибину всіх листків:
```
E(T) ≥ N! · log₂ (N!)
```

Поділивши на кількість перестановок N!, знайдемо середню кількість порівнянь:
```
D_avg = E(T) / N! ≥ log₂ (N!) = Ω(N log N)
```

Таким чином доведено: **жодне сортування порівняннями не може працювати швидше за `Ω(N log N)` навіть у середньому випадку**. ∎
