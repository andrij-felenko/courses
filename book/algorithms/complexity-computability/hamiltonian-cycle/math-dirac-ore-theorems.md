## Теорема Дірака (1952): Доведення через максимальний шлях

**Теорема (Gabriel Dirac, 1952):** Нехай `G = (V, E)` — простий неупорядкований граф з кількістю вершин `n ≥ 3`. Якщо для кожної вершини `v ∈ V` її степінь задовольняє умову:

```
deg(v) ≥ n / 2
```

то граф `G` містить гамільтонів цикл.

### Доведення (методом від супротивного та максимального шляху)

Припустимо протилежне: існує граф `G`, який задовольняє умову `deg(v) ≥ n/2` для всіх `v`, але не має гамільтонового циклу.

**Крок 1: Доведення зв'язності графа.**
Перевіримо, чи може граф `G` бути незв'язним. Припустимо, `G` розпадається на дві або більше компонент зв'язності. Нехай `C₁` — одна з компонент зв'язності, яка містить `n₁` вершин. Для будь-якої вершини `v ∈ C₁` її степінь обмежений кількістю вершин у цій компоненті:

```
deg(v) ≤ n₁ - 1
```

Оскільки за умовою теореми `deg(v) ≥ n/2`, маємо нерівність:

```
n₁ - 1 ≥ n / 2
= n₁ ≥ n / 2 + 1      [перенесення 1 у праву частину]
```

Якщо компонента `C₁` має принаймні `n/2 + 1` вершин, то будь-яка інша компонента `C₂` може мати не більше ніж `n - (n/2 + 1) = n/2 - 1` вершин. Але тоді для будь-якої вершини `u ∈ C₂` її степінь не перевищуватиме `n/2 - 2`, що суперечить умові `deg(u) ≥ n/2`. Отже, граф `G` є **зв'язним**.

**Крок 2: Побудова найдовшого простого шляху.**
Розглянемо найдовший простий шлях у графі `G`. Позначимо його вершини послідовно:

```
P = (v₁, v₂, v₃, ..., vₖ)
```

Оскільки шлях `P` є найдовшим із можливих у `G`, вершина `v₁` не може мати сусідів за межами шляху `P`. Усі сусіди `v₁` мусять лежати на самому шляху `P`. Аналогічно, усі сусіди `vₖ` також належать шляху `P`.

Позначимо множину індексів вершин шляху `P`, які є сусідами початкової вершини `v₁`:

```
S₁ = { i | (v₁, vᵢ) ∈ E }
```

Оскільки `(v₁, v₁)` не є ребом (граф простий), `S₁ ⊆ {2, 3, ..., k}`. Кількість елементів `|S₁| = deg(v₁) ≥ n/2`.

Розглянемо тепер кінцеву вершину `vₖ`. Позначимо множину зсунутих індексів вершин, для яких `vₖ` має ребро до попередника `v_{i-1}`:

```
Sₖ = { i | (v_{i-1}, vₖ) ∈ E }
```

Кількість елементів `|Sₖ| = deg(vₖ) ≥ n/2`. Елементи `Sₖ` лежать у множині індексів `{2, 3, ..., k}`.

**Крок 3: Застосування принципу Діріхле (принцип комірок).**
Обидві множини `S₁` та `Sₖ` є підмножинами множини `{2, 3, ..., k}`, яка містить `k - 1` елемент. За властивістю шляху `k ≤ n`, тому кількість доступних індексів не перевищує `n - 1`.

Обчислимо суму розмірів множин `S₁` та `Sₖ`:

```
|S₁| + |Sₖ| = deg(v₁) + deg(vₖ)
≥ n/2 + n/2
= n
```

Оскільки сума розмірів двох множин `|S₁| + |Sₖ| ≥ n`, а вони лежать у множині розміром `k - 1 ≤ n - 1`, за принципом Діріхле ці множини мусять мати хоча б один спільний елемент:

```
S₁ ∩ Sₖ ≠ ∅
```

Це означає, що існує такий індекс `j ∈ {2, 3, ..., k}`, для якого одночасно виконуються дві умови:
1. `(v₁, vⱼ) ∈ E` (існує ребро від початкової вершини до `vⱼ`).
2. `(v_{j-1}, vₖ) ∈ E` (існує ребро від попередника `v_{j-1}` до кінцевої вершини `vₖ`).

**Крок 4: Замикання шляху в цикл.**
Знайдений індекс `j` дозволяє перебудувати шлях `P` у замкнений цикл `C` тієї ж довжини `k`:

```
C = (v₁, vⱼ, v_{j+1}, ..., vₖ, v_{j-1}, v_{j-2}, ..., v₁)
```

Цей цикл `C` відвідує всі `k` вершин шляху `P`.

**Крок 5: Доведення того, що цикл є гамільтоновим (`k = n`).**
Якщо `k = n`, то цикл `C` відвідує всі `n` вершин графа `G`, отже є гамільтоновим циклом, що суперечить вихідному припущенню про відсутність таких циклів.

Якщо `k < n`, то за умови зв'язності графа `G` існує хоча б одна вершина `u ∉ C`, яка є сусідом дещо з вершин циклу `C` (нехай `vₘ ∈ C`). Але тоді можна розірвати цикл `C` у вершині `vₘ` та приєднати вершину `u`, отримавши новий простий шлях довжини `k + 1`:

```
P' = (u, vₘ, v_{m+1}, ..., vₖ, ..., v₁, ..., v_{m-1})
```

Це суперечить тому, що початковий шлях `P` мав максимально можливу довжину `k`.

Отже, припущення про відсутність гамільтонового циклу є хибним. **Теорему доведено.** `∎`

## Теорема Оре (1960): Узагальнення на несуміжні пари

Норвезький математик Ойстейн Оре у 1960 році послабив вимогу теореми Дірака, показавши, що високі степені потрібні не для *кожної* вершини, а лише в середньому для кожної парної несуміжності.

**Теорема (Øystein Ore, 1960):** Нехай `G = (V, E)` — простий неупорядкований граф з `n ≥ 3` вершинами. Якщо для кожної пари **несуміжних** вершин `u, v ∈ V` (тобто `(u, v) ∉ E`) виконується умова:

```
deg(u) + deg(v) ≥ n
```

то граф `G` містить гамільтонів цикл.

### Доведення (через замикання графа)

Доведення теореми Оре повністю аналогічне крокам 2–5 доведення теореми Дірака. Якщо взяти найдовший шлях `P = (v₁, vₖ)` у максимальному не-гамільтоновому графі, вершини `v₁` та `vₖ` не можуть бути суміжними (інакше шлях одразу згортається у цикл).

За умовою теореми Оре для цієї несуміжної пари `(v₁, vₖ)` маємо `deg(v₁) + deg(vₖ) ≥ n`. Застосовуючи той самий принцип Діріхле для суми степенів `deg(v₁) + deg(vₖ) ≥ n` на індексах шляху розміром `k - 1 ≤ n - 1`, отримуємо перетин сусідів `S₁ ∩ Sₖ ≠ ∅`, що примусово формує цикл тієї ж довжини та призводить до суперечності. `∎`

## Лема про замикання Бонді-Хватала (1976)

У 1976 році Джон Адріан Бонді та Вацлав Хватал розробили потужний метод аналізу гамільтоновості за допомогою оператора замикання графа `cl(G)`.

**Означення:** **Замиканням графа** `G = (V, E)` називається граф `cl(G)`, отриманий з `G` шляхом рекурсивного додавання ребер між несуміжними вершинами `u, v`, які задовольняють умову `deg(u) + deg(v) ≥ n`, доки такі пари існують.

**Лема (Bondy-Chvátal, 1976):** Граф `G` є гамільтоновим тоді й лише тоді, коли його замикання `cl(G)` є гамільтоновим.

```
G є гамільтоновим ⇔ cl(G) є гамільтоновим
```

### Доведення леми

Достатньо довести, що якщо додавання одного ребра `e = (u, v)` між несуміжними вершинами з `deg(u) + deg(v) ≥ n` створює новий гамільтонів цикл, то такий цикл вже існував у вихідному графі без цього ребра.

Нехай `G' = G + (u, v)` містить гамільтонів цикл `C'`. Якщо `C'` не використовує нове ребро `(u, v)`, то `C'` існує і в `G`.

Якщо ж `C'` обов'язково використовує ребро `(u, v)`, то прибравши це ребро, ми отримуємо у графі `G` гамільтонів шлях між `u` та `v` довжиною `n - 1`. Позначаючи `u = v₁` та `v = vₙ`, ми потрапляємо у ситуацію доведення теореми Оре: оскільки `deg(u) + deg(v) ≥ n`, у графі `G` обов'язково знайдеться така проміжна вершина `vⱼ`, яка дозволяє замкнути цей шлях у гамільтонів цикл без використання ребра `(u, v)`. `∎`

## Строге доведення NP-повноти: Звідність 3SAT ≤ₚ Directed Hamiltonian Cycle

Щоб довести, що задача визначення наявності гамільтонового циклу є NP-повною, необхідно виконати дві умови:
1. Довести, що задача належить до класу **NP**.
2. Побудувати поліноміальну звідність від відомої NP-повної задачі (наприклад, **3SAT**) до задачі гамільтонового циклу.

![Конструкція звідності 3SAT до Гамільтонового циклу](/book/algorithms/complexity-computability/hamiltonian-cycle/img/fig4-3sat-to-hc-gadgets.svg)
*Конструкція змінних ланцюгів та вершин диз'юнктів у звідності Карпа.*

### 1. Належність до класу NP

Сертифікатом для задачі гамільтонового циклу є впорядкована послідовність вершин `C = (v₁, v₂, ..., vₙ)`.

Алгоритм перевірки сертифіката:
1. Перевірити, що довжина послідовності дорівнює `n` (кількості вершин графа).
2. Перевірити, що всі вершини у послідовності є унікальними (відсутні повтори).
3. Для кожного `i` від 1 до `n - 1` перевірити наявність ребра `(vᵢ, v_{i+1}) ∈ E`.
4. Перевірити наявність замикаючого ребра `(vₙ, v₁) ∈ E`.

Усі перевірки виконуються за час `O(n)` або `O(n log n)`, що є поліноміальним від розміру входу. Отже, **Hamiltonian Cycle ∈ NP**.

### 2. Конструкція звідності 3SAT ≤ₚ Directed Hamiltonian Cycle

Нехай задано булеву формулу `Φ` у 3-кон'юнктивній нормальній формі (3-КНФ), яка містить `n` змінних `x₁, x₂, ..., x♁` та `m` диз'юнктів `C₁, C₂, ..., Cₘ`. Кожен диз'юнкт містить рівно 3 літерали.

Побудуємо орієнтований граф `G = (V, E)` за такими правилами:

**Крок А: Гаджети змінних.**
Для кожної змінної `xᵢ` створюємо двонаправлений трек із `2m + 2` вершин:

```
Lᵢ, w_{i,1}, w_{i,2}, ..., w_{i,2m}, Rᵢ
```

Ребра між сусідніми вершинами треку додаються в обох напрямках: `(w_{i,j}, w_{i,j+1})` та `(w_{i,j+1}, w_{i,j})`.

Цей трек має рівно два способи повного обходу гамільтоновим циклом:
- **Напрямок Lᵢ → Rᵢ (зліва направо):** інтерпретується як присвоєння значення **`xᵢ = TRUE`**.
- **Напрямок Rᵢ → Lᵢ (справа наліво):** інтерпретується як присвоєння значення **`xᵢ = FALSE`**.

Траєкторії змінних з'єднуються послідовно: вершина `Rᵢ` з'єднується з `L_{i+1}` для всіх `i ∈ {1, ..., n-1}`.

**Крок Б: Гаджети диз'юнктів.**
Для кожного диз'юнкта `Cⱼ` створюємо одну окрему вершину `cⱼ`.

Якщо диз'юнкт `Cⱼ` містить позитивний літерал `xᵢ`, ми додаємо розгалуження з треку `xᵢ` напрямку TRUE до вершини `cⱼ` і назад:

```
(w_{i, 2j-1}, cⱼ)  та  (cⱼ, w_{i, 2j})
```

Якщо диз'юнкт `Cⱼ` містить заперечний літерал `¬xᵢ`, ми додаємо розгалуження з треку `xᵢ` напрямку FALSE до вершини `cⱼ` і назад:

```
(w_{i, 2j}, cⱼ)  та  (cⱼ, w_{i, 2j-1})
```

### Еквівалентність розв'язків

- **Якщо формула `Φ` є виконуваною:** існує набір значень змінних, що робить кожний диз'юнкт істинним. Ми обираємо напрямок обходу кожного треку `xᵢ` відповідно до цього значення. Оскільки кожен диз'юнкт `Cⱼ` містить принаймні один істинний літерал, відповідний трек дозволяє гамільтоновому циклу "зробити крок убік", відвідати вершину `cⱼ` і повернутися на трек, не порушуючи цілісності обходу решти вершин. Отже, у графі `G` існує гамільтонів цикл.
- **Якщо у графі `G` існує гамільтонів цикл:** він мусить пройти через кожен змінний трек повністю в одному з двох напрямків (`L → R` або `R → L`). Оскільки кожна вершина диз'юнкта `cⱼ` відвідана рівно один раз, це відвідування можливе лише через відгалуження від того треку, де напрямок обходу збігається з істинним літералом. Це задає виконання формули `Φ`.

Часова складність побудови графа `G` становить `O((n · m)²)` операцій, що є поліноміальним часом. **Звідність доведено.** `∎`
