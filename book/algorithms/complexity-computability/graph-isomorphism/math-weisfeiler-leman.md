# 🧮 Алгоритм Вейсфайлера — Лемана та його алгебраїчні межі

Алгоритм Вейсфайлера — Лемана (Weisfeiler-Leman algorithm, WL) — це фундаментальне комбінаторно-алгебраїчне сімейство алгоритмів ущільнення розбиття (partition refinement), розроблене Борисом Вейсфайлером та Андрієм Леманом у 1968 році. Початково створений як евристичний метод комбінаторного тестування ізоморфізму графів, алгоритм WL сьогодні пронизує теорію обчислювальної складності, алгебраїчну теорію графів, скінченну теорію моделей та теорію графових нейронних мереж (GNN).

Ця вставка містить суворе математичне виведення ітерацій 1-WL та k-WL, алгебраїчний аналіз їхньої стабілізації через когерентні конфігурації (coherent configurations), схеми асоціацій Бозе — Меснера та матричні матриці суміжності, зв'язок із логікою першого порядку з кванторами лічби (`Cᵏ`), а також формальний опис контрприкладів Цай — Фюрера — Іммермана (CFI), які демонструють межі виражальної здатності сімейства WL.

## Формальна математична модель 1-WL (Color Refinement)

Нехай `G = (V, E)` — простий неорієнтований граф із множиною вершин `V` та множиною ребер `E`. Позначимо через `N(v) = {u ∈ V : (v, u) ∈ E}` множину відкритих сусідів вершини `v`.

Алгоритм 1-WL будує послідовність розфарбувань `c⁽⁰⁾, c⁽¹⁾, c⁽²⁾, ...`, де `c⁽ᵗ⁾: V → C` відображає кожну вершину в абстрактну множину кольорів `C`.

### 1. Початковий стан (крок t = 0)
У найпростішому випадку всі вершини отримують одинаковий колір. Якщо граф містить початкові позначки (або при застосуванні комбінаторних евристик), початковий колір визначається степенем вершини:

```
c⁽⁰⁾(v) = deg(v) = |N(v)|
```

### 2. Ітерація ущільнення (крок t + 1)
На кожному кроці `t ≥ 0` колір вершини `v` оновлюється шляхом агрегації її поточного кольору та мультимножини (multiset) кольорів її сусідів:

```
c⁽ᵗ⁺¹⁾(v) = H(c⁽ᵗ⁾(v), {{ c⁽ᵗ⁾(u) : u ∈ N(v) }})
```

де `{{ ... }}` позначує мультимножину (у якій дублікати є значущими), а `H` — довільна ін'єктивна хеш-функція, що відображає пару `(поточний колір, мультимножина сусідів)` у новий унікальний колір.

### 3. Стабілізація розбиття
Для кожного кроку `t` розфарбування `c⁽ᵗ⁾` задає розбиття (partition) множини вершин `V` на класи еквівалентності (осередки кольорів). Розбиття на кроці `t + 1` є суворішим ущільненням розбиття на кроці `t`:

```
c⁽ᵗ⁺¹⁾(u) = c⁽ᵗ⁺¹⁾(v)  ⇒  c⁽ᵗ⁾(u) = c⁽ᵗ⁾(v)
```

Оскільки кількість вершин `|V| = n` є скінченною, кількість осередків у розбитті не може зростати нескінченно. Якщо на деякому кроці `k` кількість кольорів не змінюється:

```
|{ c⁽ᵏ⁺¹⁾(v) : v ∈ V }| = |{ c⁽ᵏ⁾(v) : v ∈ V }|
```

то розбиття стабілізується. Позначимо стабільне розфарбування через `c* = c⁽ᵏ⁾`.

**Теорема стабілізації 1-WL:**
Алгоритм 1-WL досягає стабільного розфарбування `c*` не більше ніж за `n - 1` ітерацій, а його обчислювальна складність становить `O((V + E) log V)` при використанні структури даних впорядкованих черг та інвертованих індексів.

### 4. Мультимножинний гістограмний підпис
Для перевірки ізоморфізму двох графів `G₁` та `G₂` обчислюються їхні стабільні розфарбування `c₁*` та `c₂*`. Гістограмний підпис графа `H(G)` визначається як мультимножина підсумкових кольорів:

```
H(G) = {{ c*(v) : v ∈ V(G) }}
```

**Критерій 1-WL:**
Якщо `H(G₁) ≠ H(G₂)`, то графи `G₁` та `G₂` є **гарантовано неізоморфними** (`G₁ ≇ G₂`).
Якщо `H(G₁) = H(G₂)`, алгоритм 1-WL оголошує графи **потенційно ізоморфними**.

## Алгебраїчна інтерпретація: Матричні алгебри, когерентні конфігурації та алгебри Бозе — Меснера

1-WL та 2-WL алгоритми мають глибоке алгебраїчне вираження через клетинні алгебри (cellular algebras) та схеми асоціацій (association schemes).

Розглянемо множину двомісних матриць `A⁽ᵏ⁾ ∈ {0, 1}ⁿˣⁿ`, де кожна матриця відповідає одному з кольорів пар вершин `(u, v)` після стабілізації 2-WL. Позначимо `M` як лінійну оболонку цих матриць над полем `ℂ`:

```
M = span_ℂ { A⁽¹⁾, A⁽²⁾, ..., A⁽ᵐ⁾ }
```

Множина `M` утворює **когерентну алгебру Вейсфайлера — Лемана**, якщо вона задовольняє наступні аксіоми:
1. **Одиниця та тотожність:** Одинична матриця `Iₙ ∈ M` та матриця з усіх одиниць `Jₙ ∈ M`.
2. **Замкненість відносно транспонування:** Якщо `A ∈ M`, то `Aᵀ ∈ M`.
3. **Замкненість відносно звичайного множення:** Для будь-яких `A, B ∈ M` їхній матричний добуток `A · B ∈ M`.
4. **Замкненість відносно покомпонентного (Адамарового) множення:** Для будь-яких `A, B ∈ M` їхній добуток Адамара `A ⊙ B ∈ M`.

З аксіоми 3 випливає існування структурових констант `pᵢⱼᵏ` (структурні числа когерентної конфігурації):

```
A⁽ⁱ⁾ · A⁽ʲ⁾ = ∑ₖ pᵢⱼᵏ · A⁽ᵏ⁾
```

Значення `pᵢⱼᵏ` показує кількість вершин `w ∈ V`, таких що `(u, w)` має колір `i`, а `(w, v)` має колір `j`, для будь-якої пари `(u, v)` кольору `k`. Якщо два графи мають різні структурні константи `pᵢⱼᵏ`, алгоритм 2-WL миттєво розрізняє їх.

### Схеми асоціацій Бозе — Меснера (Bose-Mesner Algebras)

Якщо алгебра `M` є комутативною відносно звичайного множення матриць (`A · B = B · A` для всіх `A, B ∈ M`), вона називається **схемою асоціацій**. Алгебри Бозе — Меснера виникають природно при стабілізації 2-WL на сильно регулярних графах. Базис алгебри складається з трьох матриць:
- `A₀ = I` (матриця тотожності, відносини рівності вершин);
- `A₁ = A` (матриця суміжності графа, відносини суміжності);
- `A₂ = J - I - A` (матриця суміжності доповнення графа).

Структурні константи схеми асоціацій `p₁₁¹ = λ` та `p₁₁² = μ` повністю визначають параметр сильно регулярного графа `(n, k, λ, μ)`.

## Багатовимірне узагальнення: k-WL алгоритм

Оскільки 1-WL не здатен розрізнити будь-яку пару неізоморфних сильно регулярних графів з однаковими параметрами `(n, k, λ, μ)`, математики узагальнили підхід від розфарбовування поодиноких вершин до розфарбовування **k-кортежів вершин**.

Нехай `Vᵏ` — множина усіх `k`-кортежів вершин `x = (v₁, v₂, ..., vⲕ) ∈ Vᵏ`.

### 1. Базове розфарбування (t = 0)
Початковий колір `c⁽⁰⁾(x)` кортежу `x = (v₁, ..., vⲕ)` визначається **ізоморфним типом** підграфа, індукованого даними `k` вершинами. Тобто колір кодує:
- Рівності між елементами: які `vᵢ = vⱼ`;
- Наявність ребер: які pairs `(vᵢ, vⱼ) ∈ E`.

### 2. Ітерація ущільнення k-WL (t + 1)
Для кортежу `x = (v₁, ..., vⲕ)` та довільної вершини `w ∈ V` позначимо через `x[i ↦ w]` кортеж, отриманий заміною `i`-го елемента `vᵢ` на `w`:

```
x[i ↦ w] = (v₁, ..., vᵢ₋₁, w, vᵢ₊₁, ..., vⲕ)
```

На кроці `t + 1` колір кортежу `x` обчислюється як:

```
c⁽ᵗ⁺¹⁾(x) = H( c⁽ᵗ⁾(x), M⁽ᵗ⁾(x) )
```

де мультимножина `M⁽ᵗ⁾(x)` агрегує кольорові типи при всіляких замінах вершин:

```
M⁽ᵗ⁾(x) = {{ ( c⁽ᵗ⁾(x[1 ↦ w]), c⁽ᵗ⁾(x[2 ↦ w]), ..., c⁽ᵗ⁾(x[k ↦ w]) ) : w ∈ V }}
```

### 3. Ієрархічна сила k-WL
Алгоритм k-WL будує послідовно потужніші еквівалентності. Для будь-якого `k ≥ 2`:
- Якщо `k-WL` розрізняє дві графи, то `(k+1)-WL` також гарантовано їх розрізняє.
- Складність однієї ітерації k-WL становить `O(nᵏ⁺¹ log n)`.

## Логічний еквівалент: Лічильна логіка Cᵏ⁺¹

Фундаментальне відкриття Нейла Іммермана (Neil Immerman) та Еріка Ландера (Eric Lander) полягає у встановленні точного еквіваленту між алгоритмами k-WL та виражальною здатністю математичної логіки.

Позначимо через `Cᵏ` мову логіки першого порядку, обмежену задоволенням двох умов:
1. Використовується не більше ніж `k` різних змінних `x₁, x₂, ..., xⲕ`;
2. Дозволено використання кванторів лічби `∃₯ x` («існує щонайменше `m` елементів `x`, таких що...»).

**Теорема Іммермана — Ландера (1990):**
Два графи `G₁` та `G₂` дають однаковий гістограмний підпис під дією алгоритму `k-WL` тоді й тільки тоді, коли вони задовольняють абсолютно однакові формули логіки `Cᵏ⁺¹` (з `k + 1` змінною).

Це показує, що обмеження k-WL мають глибоку логіко-модельну природу: k-WL здатний перевіряти лише ті властивості графів, які можна виразити скінченним числом змінних із кванторами лічби.

## Межі алгоритму: Графи Цай — Фюрера — Іммермана (CFI)

Протягом тривалого часу існувала гіпотеза, що існує деяке мале фіксоване `k` (наприклад, `k = 4` або `k = 9`), для якого `k-WL` здатен розрізнити **абсолютно всі** неізоморфні графи.

У 1992 році Джин-Ї Цай (Jin-Yi Cai), Мартін Фюрер (Martin Fürer) та Нейл Іммерман спростували цю гіпотезу, сконструювавши сімейство графів, яке сьогодні відоме як графи CFI.

### Алгебраїчна конструкція CFI-графів

1. **Базовий граф:** Береться `d`-регулярний зв'язний граф `G = (V, E)` із високим обхватом (girth).
2. **Заміна вершин гаджетами:** Кожна вершина `v ∈ V` замінюється спеціальним комбінаторним гаджетом `Xᵥ`, який складається з `2ᵈ⁻¹` вершин. Гаджет кодує всі можливі парні підмножини інцидентних ребер.
3. **Парність зв'язків (Parity Check):** Ребра між гаджетами з'єднуються двома паралельними шляхами (двопровідна лінія).
4. **Конструювання пари (X, Y):**
   - Граф `X` будується без інверсії парності.
   - Граф `Y` будується шляхом інверсії («закручування») парності ребер в еквівалентному довільно обраному гаджеті.

### Формальна теорема Цай — Фюрера — Іммермана

**Теорема CFI (1992):**
Для будь-якого `k ≥ 1` існують два неізоморфних підпланарних графи `Gₖ` та `Hₖ` розміром `n = O(k)` вершин із максимальним степенем 3, такі що:

```
Gₖ ≇ Hₖ,  але  k-WL(Gₖ) = k-WL(Hₖ)
```

**Наслідок:**
Щоб розрізнити пару графів CFI розміру `n`, алгоритм `k-WL` вимагає розмірності `k = Ω(n)`.
Оскільки складність `k-WL` становить `O(nᵏ⁺¹)`, для таких графів алгоритм WL потребує часу:

```
T(n) = O(n^(Ω(n))) = exp(Ω(n log n))
```

Це доводить, що чистий комбінаторний метод ущільнення кольорів `k-WL` **не може** розв'язати загальну задачу ізоморфізму графів за поліноміальний час без залучення групово-теоретичних розділень.
