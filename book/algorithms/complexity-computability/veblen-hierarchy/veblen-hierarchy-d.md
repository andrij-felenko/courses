Коли автоматичний доводжувач теорем або оптимізуючий компілятор аналізує складну систему переписування термів, йому необхідно строго гарантувати, що ланцюг редукцій виразів ніколи не зациклиться і обов'язково зупиниться за скінченну кількість кроків. Для простих функцій достатньо звичайного натурального лічильника кроків або лексикографічного впорядкування пар чисел. Проте для вкладених оптимізацій вищого порядку, перетворень функціональних програм зі зв'язуванням змінних та алгебр з асоціативно-комутативними законами скінченних лічильників принципово бракує: алгоритм вимагає зіставлення кожному виразу спеціального трансфінітного порядкового числа (ординала), яке суворо зменшується на кожному кроці спрощення.

Якщо система спирається на класичну нормальну форму Кантора з основою `ω`, то при спробі верифікувати складні вкладені правила вона неминуче стикається з катастрофічним колапсом. На певному рівні вкладеності виникає ординал `ε₀` (епсилон-нуль), для якого показник степеня стає рівним самому числу: `ω^ε₀ = ε₀`. Спроба синтаксичного розкладу вимагає нескінченного самопосилання, аналізатор завершуваності не може побудувати спадний ланцюг і аварійно завершує роботу з помилкою неможливості доведення термінації.

Щоб подолати цей бар'єр самозамикання та надати комп'ютерним системам можливість працювати з ординалами, які лежать далеко за межами можливостей арифметики Пеано, застосовується ієрархія Веблена (лат. *hierarchia*, з грец. *hierarchia* — священний порядок). Вона вводить універсальний механізм трансфінітних похідних операцій, що перелічують спільні нерухомі точки зростаючих функцій і відкривають шлях до строгої класифікації надскладних обчислювальних процесів аж до межі предикативного аналізу `Γ₀`.

## Межі нормальної форми Кантора та проблема нерухомих точок

Щоб зрозуміти, чому традиційна трансфінітна арифметика вичерпує себе, розглянемо, як влаштоване позиційне представлення ординалів за Ґеорґом Кантором. Будь-яке порядкове число `α`, що лежить нижче певного порогу, можна однозначно розкласти у скінченну суму спадних степенів першого нескінченного ординала `ω`:

```
α = ω^(α₁) · c₁ + ω^(α₂) · c₂ + ... + ω^(α_k) · c_k
```

де натуральні коефіцієнти `c_i > 0`, а показники степенів утворюють строго спадний ланцюг `α > α₁ > α₂ > ... > α_k`.

Оскільки кожен показник `α_i` є строго меншим за саме число `α`, розклад застосовується рекурсивно до кожного `α_i`. Це дозволяє комп'ютерній програмі зберігати ординал як скінченне кореневе дерево. Порівняння двох ординалів у пам'яті комп'ютера зводиться до поелементного лексикографічного порівняння їхніх дерев розкладу.

Проте якщо ми почнемо будувати послідовність дедалі вищих веж експонент:

```
ω,  ω^ω,  ω^(ω^ω),  ω^(ω^(ω^ω)),  ...
```

та розглянемо її границю (найменшу верхню грань, або супремум), ми отримаємо ординал `ε₀`. За самим своїм означенням `ε₀` є найменшим розв'язком рівняння:

```
ω^α = α
```

У цій точці стандартна нормальна форма Кантора повністю розпадається: спроба виразити `ε₀` через основу `ω` вимагає записати `ε₀` у власний показник степеня, що призводить до нескінченного циклу без жодного синтаксичного спрощення. Ординал `ε₀` стає нерозкладним атомом, для представлення якого в системі позначень Кантора немає засобів.

Ба більше, `ε₀` — це лише перший крок. Якщо ми візьмемо наступник `ε₀ + 1`, збудуємо над ним вежу `ω^(ε₀ + 1) = ε₀ · ω`, ми отримаємо новий ланцюг, чия границя дасть ординал `ε₁` — наступний розв'язок рівняння `ω^α = α`. Далі виникають `ε₂`, `ε_ω`, `ε_{ε₀}` тощо. Виникає нескінченна драбина нерухомих точок, кожна з яких блокує канторів розклад. Для подолання цього глухого кута знадобився принципово новий математичний підхід.

## Нормальні функції та оператор взяття похідної Веблена

Розв'язання проблеми нерухомих точок базується на фундаментальному відкритті, зробленому американським математиком Освальдом Вебленом у 1908 році. Веблен запропонував розглядати не окремі числові вирази, а аналізувати загальні властивості монотонних операцій над класом ординальних чисел `On`.

Функція `f: On → On` називається **нормальною** (англ. *normal function*), якщо вона задовольняє дві ключові умови:
1. **Сувора монотонність:** Для будь-яких `α < β` виконується `f(α) < f(β)`.
2. **Неперервність у границях:** Для будь-якого граничного ординала `λ` значення дорівнює границі значень на попередніх кроках: `f(λ) = sup { f(ξ) | ξ < λ }`.

Будь-яка нормальна функція має важливу властивість: вона зростає щонайменше так само швидко, як тотожне відображення, тобто `f(α) ≥ α` для кожного ординала `α`.

Ординал `γ` називається **нерухомою точкою** нормальної функції `f`, якщо застосування функції не змінює його значення: `f(γ) = γ`.

Головна теорема Веблена стверджує, що для будь-якої нормальної функції `f` клас її нерухомих точок `Fix(f)` не просто нескінченний, а є замкненим і необмеженим класом у трансфінітному просторі. Це означає, що для будь-якого наперед заданого ординала `α` гарантовано існує нерухома точка `γ > α`.

Цю точку можна явно сконструювати за допомогою зліченної ітерації:

```
α₀ = α + 1
α₁ = f(α₀)
α₂ = f(α₁)
...
α_{n+1} = f(α_n)
```

Супремум цього ланцюга `γ = sup_{n < ω} α_n` є найменшою нерухомою точкою функції `f`, що перевищує `α`.

Оскільки сукупність нерухомих точок `Fix(f)` є цілком упорядкованою та необмеженою, існує єдина нормальна функція, яка перелічує ці точки у порядку зростання. Веблен назвав цю функцію **похідною функцією** (англ. *derivative function*) і позначив її як `f'`:
- `f'(0)` — найменша нерухома точка функції `f`;
- `f'(β + 1)` — найменша нерухома точка `f`, строго більша за `f'(β)`;
- `f'(λ) = sup_{ξ < λ} f'(ξ)` для будь-якого граничного ординала `λ`.

Оператор взяття похідної `f ↦ f'` є тим генеративним мотором, який перетворює важкодоступні нерухомі точки на регулярну індексовану послідовність.

## Побудова ієрархії: від φ₀ до φ_ω

Поклавши в основу найпростішу нетривіальну нормальну функцію — трансфінітну експоненту з основою `ω`, Веблен визначив ціле трансфінітне сімейство функцій `(φ_α)_{α ∈ On}` за допомогою трансфінітної індукції за індексом `α`:

```
1. Базовий рівень (α = 0):
   φ₀(β) = ω^β

2. Крок наступника (α = γ + 1):
   φ_{γ + 1}(β) = (φ_γ)'(β)   [похідна функції попереднього рівня]

3. Граничний крок (α = λ):
   φ_λ(β) монотонно перелічує спільні нерухомі точки всіх молодших функцій:
   Fix(φ_λ) = ⋂_{ξ < λ} Fix(φ_ξ)
```

Об'єднавши індекс `α` та аргумент `β` у єдиний запис, ми отримуємо бінарну функцію Веблена `φ(α, β)`.

![Драбина похідних функцій Веблена](/book/algorithms/complexity-computability/veblen-hierarchy/img/fig1-veblen-fixed-points.svg)
*Драбина похідних функцій Веблена φ_α(β) та їхні нерухомі точки від омега-експоненти до граничного ординала.*

Простежимо детально поведінку перших рівнів ієрархії:

На нульовому рівні `φ₀(β) = ω^β` функція генерує класичні степені Кантора: `φ₀(0) = 1`, `φ₀(1) = ω`, `φ₀(2) = ω²`, `φ₀(ω) = ω^ω`.

На першому рівні `φ₁(β)` функція перелічує нерухомі точки рівняння `ω^γ = γ`. Її значення є знаменитими епсилон-числами:
- `φ₁(0) = ε₀` — перша нерухома точка експоненти;
- `φ₁(1) = ε₁` — друга нерухома точка експоненти;
- `φ₁(ω) = ε_ω = sup { ε₀, ε₁, ε₂, ... }`.

На другому рівні `φ₂(β)` функція бере похідну від `φ₁` і перелічує нерухомі точки сімейства `ε`, тобто розв'язки рівняння `ε_γ = γ`:
- `φ₂(0) = ζ₀` (дзета-нуль) — найменший ординал, для якого `ε_{ζ₀} = ζ₀`;
- `φ₂(1) = ζ₁`;
- `φ₂(β) = ζ_β`.

На третьому рівні `φ₃(β)` ми отримуємо перелік розв'язків рівняння `ζ_γ = γ`, які позначаються числами `η_β` (ета-числа): `φ₃(0) = η₀`.

Коли індекс досягає першого нескінченного ординала `ω`, функція `φ_ω(0)` визначається як супремум перших елементів усіх скінченних рівнів:

```
φ_ω(0) = sup { φ₁(0), φ₂(0), φ₃(0), φ₄(0), ... } = sup { ε₀, ζ₀, η₀, ... }
```

Функція `φ_{ω+1}(0)` стає першою спільною нерухомою точкою для всіх функцій `φ_n` зі скінченними індексами `n < ω`.

Повний математичний апарат властивостей нормальних функцій, доведення теореми про замкненість множини нерухомих точок та виведення правил монотонності викладено у вставці [🧮 Математичний апарат функцій Веблена, нерухомих точок та нормальної форми](book:algorithms/complexity-computability/veblen-hierarchy/math-veblen-fixed-points.md).

## Діагоналізація та ординал Фефермана — Шютте Γ₀

Здатність бінарної функції Веблена `φ(α, β)` породжувати дедалі потужніші ординали здається необмеженою. Ми можемо збільшувати перший аргумент: `φ(ω, 0)`, `φ(ω^ω, 0)`, `φ(ε₀, 0)`, `φ(ζ₀, 0)`.

Проте на цьому шляху неминуче виникає мета-бар'єр другого порядку — діагональне самозамикання.

Розглянемо діагональну функцію `d(α) = φ(α, 0)`. Ця функція зіставляє кожному ординалу `α` нульове значення `α`-го рівня ієрархії Веблена. Оскільки функція `d(α)` сама є нормальною функцією, вона обов'язково має власні нерухомі точки, для яких:

```
φ(α, 0) = α
```

Найменша нерухома точка діагональної функції називається **ординалом Фефермана — Шютте** (англ. *Feferman–Schütte ordinal*) і позначається як `Γ₀` (Гамма-нуль).

![Процес діагоналізації та граничний перехід до Γ₀](/book/algorithms/complexity-computability/veblen-hierarchy/img/fig2-gamma-zero-limit.svg)
*Процес діагоналізації та граничний перехід до ординалу Фефермана — Шютте Γ₀ як нерухомої точки діагоналі.*

Ординал `Γ₀` досягається через нескінченний ланцюг самовкладень аргументу у власний перший індекс:

```
α₀ = 0
α₁ = φ(0, 0) = 1
α₂ = φ(1, 0) = ε₀
α₃ = φ(ε₀, 0)
α₄ = φ(φ(ε₀, 0), 0)
...
Γ₀ = sup_{n < ω} α_n
```

У точці `Γ₀` бінарна функція Веблена зазнає такого самого краху виразної сили, як нормальна форма Кантора на `ε₀`. Щоб записати `Γ₀` через функцію `φ`, необхідно у перший аргумент помістити `Γ₀`, що утворює нескінченну рекурсію `φ(Γ₀, 0) = Γ₀`.

Ординал `Γ₀` має колосальне значення у математичній логіці та комп'ютерних науках: він є точною межею предикативного математичного аналізу (системи `ATR₀` у реверсивній математиці) та визначає граничну складність алгоритмів, завершуваність яких можна довести без залучення непредикативних концепцій.

Детальний історичний огляд відкриття ієрархії Веблена, її ролі у програмі Давида Гільберта, доведенні несуперечливості арифметики Ґергардом Ґентценом та встановленні меж предикативності Куртом Шютте й Соломоном Феферманом наведено у вставці [📜 Народження ієрархії Веблена: від кризи нормальної форми Кантора до меж предикативності](book:algorithms/complexity-computability/veblen-hierarchy/hist-veblen-origins.md).

## Ординали як синтаксичні дерева: нормальна форма Веблена

Для практичного використання в комп'ютерних системах трансфінітні ординали нижче `Γ₀` представляються у вигляді конструктивних синтаксичних дерев — **нормальної форми Веблена** (англ. *Veblen Normal Form*, VNF).

Кожен ненульовий ординал `α < Γ₀` однозначно розкладається у скінченну суму адитивно головних членів:

```
α = φ(γ₁, β₁) + φ(γ₂, β₂) + ... + φ(γ_k, β_k)
```

за дотримання двох суворих структурних інваріантів:
1. **Монотонне спадання доданків:** `φ(γ₁, β₁) ≥ φ(γ₂, β₂) ≥ ... ≥ φ(γ_k, β_k)`.
2. **Критерій нескоротності:** Для кожного доданка виконується `γ_i < φ(γ_i, β_i)` та `β_i < φ(γ_i, β_i)`.

![Синтаксичне дерево нормальної форми Веблена](/book/algorithms/complexity-computability/veblen-hierarchy/img/fig3-ordinal-notation-tree.svg)
*Синтаксичне дерево представлення ординалу в нормальній формі Веблена та його інваріанти валідності.*

### Алгоритм порівняння синтаксичних дерев
Коли програмі потрібно з'ясувати, чи передує один ординал іншому (`A < B`), де `A = φ(γ_A, β_A)` та `B = φ(γ_B, β_B)`, застосовується наступний алгоритм:

1. Якщо індекс лівого терму менший (`γ_A < γ_B`), то `A < B` тоді й лише тоді, коли аргумент `β_A < B`.
2. Якщо індекси однакові (`γ_A = γ_B`), порядок повністю визначається другим аргументом: `β_A < β_B`.
3. Якщо індекс лівого терму більший (`γ_A > γ_B`), то `A < B` тоді й лише тоді, коли `A ≤ β_B`.

Цей алгоритм є повністю детермінованим, працює виключно зі структурою дерев і не вимагає жодних наближених числових обчислень.

> В автоматичному доведенні завершуваності програм (наприклад, у верифікаторах систем переписування термів TRS, засобах перевірки контрактів та компіляторах мов Coq, Lean, Agda) кожній синтаксичній конструкції зіставляється ординал у нормальній формі Веблена. Якщо кожне переписування виразу суворо зменшує відповідне дерево ординалу, теорема про цілковите впорядкування гарантує, що нескінченне зациклення алгоритму неможливе: процес обов'язково зупиниться за скінченну кількість кроків.

Повну програмну реалізацію обчислювального рушія, структур даних, алгоритмів канонічного додавання з поглинанням та рекурсивного порівняння мовами C та C++ подано у вставці [⚙️ Реалізація обчислювального рушія ординалів Веблена мовами C та C++](book:algorithms/complexity-computability/veblen-hierarchy/proj-veblen-ordinals.md).

Повну специфікацію програмного інтерфейсу бібліотеки, структури вузлів, таблицю переходів та формальну EBNF-граматику викладено у вставці [📋 Специфікація програмного інтерфейсу Veblen Ordinal Engine](book:algorithms/complexity-computability/veblen-hierarchy/api-veblen-tree.md).

## Механізм редукції термів та індукція за ординалами

Щоб наочно побачити, як ієрархія Веблена працює в комп'ютерних алгоритмах, розглянемо процес верифікації системи переписування термів. Нехай система оперує рекурсивними виразами, що містять вкладені функціональні виклики.

Кожному виразу `E` алгоритм зіставляє порядковий тип `ord(E)`. Якщо правило переписування трансформує вираз `E₁ 	o E₂`, компілятор перевіряє умову `ord(E₂) < ord(E₁)`. Завдяки властивості цілковитого впорядкування (відсутності нескінченних спадних ланцюгів у класі ординалів) будь-яка послідовність редукцій:

```
E₁ → E₂ → E₃ → ... → E_m
```

гарантовано завершується за скінченну кількість кроків `m`. Якщо ж складність функцій виходить за рамки примітивної рекурсії (наприклад, узагальнена функція Аккермана багатьох змінних), ординали звичайної експоненти Кантора не можуть виразити міру складності виразу: значення перевищує `ε₀`. У цей момент підключається функція Веблена `φ(γ, β)`, надаючи точну оцінку глибини дерева редукції.

## Гра в Гідру та теорема Краскала

Класичним прикладом обчислювального процесу, складність якого неможливо оцінити без ієрархії Веблена, є математична **Гра в Гідру** (англ. *Hydra game*), запропонована Лоуренсом Кірбі та Джеффом Парісом у 1982 році.

Гідра є скінченним кореневим деревом. На кожному кроці гравець відтинає одну з голів Гідри (листову вершину). Якщо відтята голова росла безпосередньо з кореня, вона просто зникає. Якщо ж голова росла з проміжного вузла `u`, Гідра миттєво відрощує `n` нових копій піддерева з коренем у батьківському вузлі для `u`, де `n` — номер поточного раунду гри.

Попри те, що Гідра на кожному кроці може вибухоподібно розростатися на мільярди нових гілок, гравець завжди перемагає: дерево завжди повністю знищується за скінченну кількість ходів. Проте довести цей факт у межах стандартної арифметики Пеано (`PA`) принципово неможливо.

Справа в тому, що кожному стану Гідри зіставляється ординал у нормальній формі Веблена:
- Лист відповідає `0`;
- Вузол з нащадками `α₁, α₂, ..., α_k` перетворюється на суму `ω^(α₁) + ω^(α₂) + ... + ω^(α_k)`.

Кожен крок редукції Гідри строго зменшує ординал дерева. Оскільки початковий стан дерева може досягати ординала `ε₀`, скінченність гри еквівалентна принципу трансфінітної індукції до `ε₀`.

Узагальнені ігри в Гідру з мітками на ребрах (англ. *labeled Hydra*) та наслідки теореми Краскала про вкладення дерев вимагають індукцій до рівнів `ζ₀`, `η₀` та ординала `Γ₀`. Без формального апарату ієрархії Веблена аналіз таких алгоритмів був би неможливим.

## Зворотна математика та програма Фрідмана — Сімпсона

Ієрархія Веблена є фундаментальним вимірювальним компасом у сучасній програмі **зворотної математики** (англ. *Reverse Mathematics*), заснованій Гарві Фрідманом та розвиненій Стівеном Сімпсоном у фундаментальній монографії *Subsystems of Second-Order Arithmetic*.

Головне питання реверсивної математики звучить так: які саме мінімальні аксіоми необхідні для доведення конкретної математичної теореми? Для цього розглядають п'ять класичних підсистем арифметики другого порядку, які утворюють так звану «Велику п'ятірку» (англ. *Big Five*).

Кожна з цих підсистем має точно калібрований теоретико-доказовий ординал в ієрархії Веблена:

1. **Система `RCA₀` (Recursive Comprehension Axiom):** Базова інтуїціоністська система, що включає аксіоми Пеано для додавання й множення та схему виділення множин для обчислюваних (рекурсивних) предикатів `Δ⁰₁`. Її теоретико-доказовий ординал дорівнює `ω^ω`. Вона відповідає обчислюваній математиці і здатна доводити базові теореми дискретної математики.
2. **Система `WKL₀` (Weak Kőnig's Lemma):** Розширює `RCA₀` слабкою лемою Кьоніґа про нескінченні бінарні дерева. Ця система має той самий теоретико-доказовий ординал `ω^ω`, що й `RCA₀` (є консервативним розширенням для `Π⁰₂`-висловлювань), але дозволяє доводити теорему Гейне — Бореля про компактність відрізка та теорему Вейєрштрасса про неперервні функції.
3. **Система `ACA₀` (Arithmetical Comprehension Axiom):** Дозволяє утворювати множини за довільними арифметичними формулами першого порядку. Її теоретико-доказовий ординал дорівнює `ε₀ = φ(1, 0)`. У цій системі доводяться теорема Больцано — Вейєрштрасса, теорема про збіжність монотонної послідовності та нескінченна теорема Рамсея.
4. **Система `ATR₀` (Arithmetical Transfinite Recursion):** Дозволяє проводити трансфінітну ітерацію арифметичних предикатів уздовж будь-якого цілком упорядкованого лінійного порядку. Її теоретико-доказовим ординалом є саме **ординал Фефермана — Шютте** `Γ₀ = φ(1, 0, 0)`. Ця система є точним математичним еквівалентом предикативної математики. Вона необхідна для доведення теореми Ульма про класифікацію зліченних абелевих груп, теореми Лузіна про поділ борелівських множин та аналізу ігор на деревах.
5. **Система `Π¹₁-CA₀` (Pi-1-1 Comprehension Axiom):** Перша повноцінно непредикативна система, що дозволяє виділення множин за формулами з кванторами над довільними нескінченними множинами. Її ординал лежить далеко за межами функцій Веблена і вимагає функцій колапсу ординалів (ординал Бахмана — Говарда `BHO`).

Таким чином, ієрархія Веблена не просто описує швидкість зростання окремих функцій, а слугує фундаментальною шкалою класифікації всієї математичної істини від елементарних числових алгоритмів до найглибших глибин абстрактного аналізу.

## Багатоаргументні функції та вихід у непредикативну область

Щоб перетнути бар'єр `Γ₀`, функцію Веблена узагальнюють на більшу кількість аргументів. Замість двох змінних вводиться функція зі скінченним кортежем параметрів:

```
φ(α_n, α_{n-1}, ..., α₁, α₀)
```

де значення з нулями на початку відповідають бінарній функції: `φ(0, ..., 0, α, β) = φ(α, β)`. Кожен новий аргумент зліва діє як оператор діагоналізації над функціями з меншою кількістю змінних:
- `φ(1, 0, 0) = Γ₀` — ординал Фефермана — Шютте;
- `φ(1, 0, 1) = ε_{Γ₀ + 1}`;
- `φ(1, 1, 0)` — найменша нерухома точка `α ↦ φ(1, 0, α)`;
- `φ(2, 0, 0)` — результат діагоналізації за старшим індексом.

Супремум усіх ординалів, які можна виразити за допомогою функцій Веблена з довільною скінченною кількістю аргументів, називається **Малим ординалом Веблена** (англ. *Small Veblen Ordinal*, SVO).

Якщо дозволити функції приймати нескінченну послідовність ординальних індексів, у якій лише скінченна кількість елементів є ненульовими (послідовності зі скінченним носієм), ми отримуємо **Великий ординал Веблена** (англ. *Large Veblen Ordinal*, LVO).

Великий ординал Веблена позначає абсолютну вершину виразної сили чистого методу нерухомих точок. Щоб піднятися ще вище (до ординала Бахмана — Говарда `BHO` та меж аналізу другого порядку), математикам довелося винайти принципово інший інструмент — функції колапсу ординалів (англ. *ordinal collapsing functions*), які проектують незліченні ординали `Ω` у зліченний простір.

## Теоретико-доказова сила формальних теорій

Ієрархія Веблена слугує головною вимірювальною шкалою логічної та обчислювальної сили формальних математичних систем. Кожній системі аксіом зіставляється її теоретико-доказовий ординал, який визначає, наскільки складні рекурсивні алгоритми ця система здатна визнати тотальними (всюди визначеними).

![Шкала доказової сили логічних теорій](/book/algorithms/complexity-computability/veblen-hierarchy/img/fig4-proof-theoretic-strength.svg)
*Шкала доказової сили логічних теорій та їхні теоретико-доказові ординали від елементарної арифметики до предикативної межі.*

Простежимо відповідність між логічними теоріями та рівнями ієрархії Веблена:

1. **Елементарна арифметика функцій (`EFA`):** теоретико-доказовий ординал `ω³`. Описує обчислення у класі елементарних функцій за Кальмаром (обмежені вежі експонент).
2. **Примітивно-рекурсивна арифметика (`PRA`):** ординал `ω^ω`. Охоплює всі алгоритми без необмеженого пошуку (примітивна рекурсія).
3. **Арифметика Пеано першого порядку (`PA`) та система `ACA₀`:** теоретико-доказовий ординал `ε₀ = φ(1, 0)`. Тут доводяться теорема Ґудстейна та завершуваність стандартних ігор у Гідру на скінченних деревах.
4. **Теорія індуктивних дефініцій (`ID₁`):** ординал `φ(ε₀, 0)`. Дозволяє обґрунтовувати завершуваність рекурсивних процесів із багаторазовими вкладеними предикатами.
5. **Арифметична трансфінітна рекурсія (`ATR₀`):** теоретико-доказовий ординал `Γ₀ = φ(1, 0, 0)`. Ця система є точним еквівалентом предикативного аналізу та дозволяє доводити завершуваність нетривіальних алгоритмів нормалізації термів та теорем комбінаторики нескінченних дерев.
6. **Система `ATR` з трансфінітними індукціями:** досягає Малого та Великого ординалів Веблена (`SVO`, `LVO`), відкриваючи можливість аналізу розширених комбінаторних ігор над маркованими графами.

У швидкозростаючій ієрархії функцій (FGH) рівень `F_{Γ₀}(n)` демонструє таку швидкість зростання, яка перевершує будь-яку функцію, тотальність якої можна довести в межах предикативних систем.

## Обчислювальна складність та зв'язок зі швидкозростаючою ієрархією

Трансфінітна ієрархія функцій швидкості росту FGH (англ. *Fast-Growing Hierarchy*) безпосередньо використовує ординали ієрархії Веблена як індекси рівнів складності. Нагадаємо, що функція `F_α(n)` будується за правилом діагоналізації:

```
F₀(n) = n + 1
F_{α + 1}(n) = F_α^(n)(n)
F_λ(n) = F_{λ[n]}(n)
```

де `λ[n]` — `n`-й член канонічної фундаментальної послідовності для граничного ординала `λ`.

Коли індекс `α` досягає ординалів ієрархії Веблена, темп зростання функцій стає незбагненно вибуховим:
- Рівень `F_{ε₀}(n)` обганяє будь-яку функцію, обчислюваність якої можна довести в арифметиці Пеано.
- Рівень `F_{ζ₀}(n) = F_{φ(2,0)}(n)` переростає будь-яку ітерацію функцій рівня `ε₀`.
- Рівень `F_{Γ₀}(n)` мажорує будь-яку загальнорекурсивну функцію, доведення тотальності якої можливе засобами предикативного математичного аналізу `ATR₀`.

З практичної точки зору це означає, що ієрархія Веблена надає повну математичну карту складності для тих алгоритмів, чий час роботи принципово не вміщується у рамки традиційного поліноміального чи експоненціального аналізу.

## Практичні рекомендації для реалізації в доводжувачах теорем

При проектуванні математичних ядер автоматичних систем доведення теорем (таких як Lean 4, Coq, Agda чи Isabelle) застосування ієрархії Веблена вимагає дотримання кількох важливих інженерних правил:

- **Хеш-консинг (Hash-Consing) та структурне розділення:** Оскільки трансфінітні дерева в нормальній формі Веблена є незмінними (immutable), використання глобальної таблиці унікальних вузлів дозволяє звести перевірку рівності двох виразів на `O(1)` (просте порівняння вказівників).
- **Кешування рангу та висоти:** Збереження обчисленої висоти піддерева у кожному вузлі дозволяє функції `compare` миттєво відсікати нерівні гілки без глибокого рекурсивного спуску.
- **Захист від переповнення стека:** Для обчислень з екстремально глибокими деревами (наприклад, моделювання сотень тисяч кроків гри в Гідру) рекурсивні алгоритми мають бути оптимізовані за допомогою явного стека у купі або хвостової рекурсії.

## Синтез і практичне значення для алгоритмічної теорії

Ієрархія Веблена є унікальним мостом між абстрактними конструкціями трансфінітної теорії множин, структурними деревами комп'ютерної алгебри та фундаментальними межами обчислювальності. Вона демонструє, що нерухомі точки математичних операцій є не випадковими перешкодами, а закономірними сходами, що ведуть на якісно вищі рівні обчислювальної складності.

Завдяки нормальній формі Веблена нескінченні ординали перестають бути суто теоретичними концептами й перетворюються на практичний інструмент розробника: точні синтаксичні типи даних, що дозволяють компіляторам, системам верифікації та автоматичним доводжувачам теорем гарантувати коректність найскладніших обчислювальних алгоритмів сучасності.

## Алгоритмічні властивості нормалізатора Кантора

Трансфінітна нормалізація є серцем будь-якого комп'ютерного рушія для роботи з нескінченностями. На відміну від звичайної арифметики дійсних або цілих чисел, де додавання є комутативним (`a + b = b + a`), трансфінітне додавання ординалів строго залежить від порядку операндів.

Розглянемо фізичний механізм цього явища на рівні впорядкованих множин:

1. **Додавання скінченного числа зліва (`1 + ω = ω`):**
   Ординал `1` являє собою одну дискретну точку `{0}`. Ординал `ω` являє собою нескінченну послідовність натуральних чисел `{0, 1, 2, 3, ...}`. Якщо ми розміщуємо одну точку перед нескінченною послідовністю, новий порядок має вигляд `{0*, 0, 1, 2, 3, ...}`. Ця множина є ізоморфною до звичайного ряду `ω` (достатньо перенумерувати `0* ↦ 0`, `0 ↦ 1`, `1 ↦ 2` тощо). Таким чином, одиниця повністю розчиняється в нескінченності.
2. **Додавання скінченного числа справа (`ω + 1 > ω`):**
   Якщо ми розміщуємо точку після нескінченної послідовності `{0, 1, 2, 3, ... ; ω}`, новий елемент стає недосяжною граничною точкою, яка строго більша за всі попередні натуральні числа. Цей порядок не можна стиснути або зсунути назад: виникає якісно новий ординал `ω + 1`.
3. **Поглинання вищих степенів (`ω + ω² = ω²`):**
   Помноживши `ω` на себе, ми отримуємо `ω` блоків довжини `ω`. Додавання одного блоку довжини `ω` на початку не змінює порядкового типу всієї послідовності, тому `ω + ω² = ω²`. Проте додавання справа `ω² + ω` створює новий блок після нескінченної матриці, утворюючи незвідний ординал.

Комп'ютерний рушій реалізує це правило через рекурсивний аналіз провідних членів Кантора. Якщо новий доданок має ранг, більший або рівний за лівий операнд, лівий операнд миттєво відкидається (поглинається), що запобігає роздуванню синтаксичного дерева та гарантує канонічність представлення даних у пам'яті.

## Аналіз термінації рекурсивних функцій вищих типів

У сучасних мовах програмування із залежними типами (таких як Agda, Idris, Lean 4) та верифікаторах систем зі складними типами даних (Haskell, Coq) обчислювальний модуль термінації (англ. *termination checker*) постійно розв'язує задачу обґрунтування тотальності функцій.

Коли рекурсивна функція викликає саму себе з аргументами, які не є прямими структурними підтермами вхідних даних (наприклад, узагальнена багатовимірна функція Аккермана або функції нормалізації для числення конструкцій), компілятор не може застосувати стандартну структурну індукцію.

У цьому випадку єдиним математичним інструментом є зіставлення кожному стану обчислення ординала з ієрархії Веблена. Якщо кожний крок обчислення суворо зменшує ранг у нормальній формі Веблена:

```
ord(state_{k+1}) < ord(state_k)
```

теорема про цілковите впорядкування трансфінітних чисел гарантує, що програма завершиться за скінченну кількість тактів процесора і не увійде в нескінченне зациклення.
