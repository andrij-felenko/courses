# 🧮 Математичний апарат функцій Веблена, нерухомих точок та нормальної форми

Математичний фундамент ієрархії Веблена спирається на топологічні та порядкові властивості класу ординальних чисел, теорію замкнених і необмежених підкласів (club-множин), а також на детермінований алгоритм структурного порівняння дерев у канонічній нормальній формі.

## Нормальні функції на класі ординалів

Нехай `On` позначає клас усіх трансфінітних ординальних чисел. Клас `On` є цілком упорядкованим власним класом, наділеним природною порядковою топологією, базою якої є відкриті інтервали `(α, β) = { ξ ∈ On | α < ξ < β }`. У цій топології будь-який ізольований ординал-наступник є відкрито-замкненою точкою, а граничні ординали є точками накопичення своїх початкових відрізків.

Функція `f: On → On` називається **нормальною** (англ. *normal function*), якщо вона задовольняє дві фундаментальні умови:

1. **Сувора монотонність:**
Для будь-яких ординалів `α` та `β`:
```
α < β  ⇒  f(α) < f(β)
```

2. **Неперервність у границях:**
Для будь-якого граничного ординала `λ` (ординала, який не дорівнює нулю і не має безпосереднього попередника):
```
f(λ) = sup { f(ξ) | ξ < λ } = ⋃_{ξ < λ} f(ξ)
```

З властивості строгої монотонності індукцією легко доводиться, що для будь-якої нормальної функції `f` та будь-якого ординала `α` виконується фундаментальна нерівність:
```
f(α) ≥ α
```

Доведемо цю нерівність методом трансфінітної індукції. Для `α = 0` нерівність `f(0) ≥ 0` виконується тривіально, оскільки нуль є найменшим елементом класу `On`.

Припустимо, що нерівність `f(α) ≥ α` виконується для деякого ординала `α`. Розглянемо наступник `α + 1`. Оскільки `f` є строго монотонною, маємо:
```
f(α + 1) > f(α) ≥ α
```
Оскільки для ординалів співвідношення `f(α + 1) > α` означає `f(α + 1) ≥ α + 1`, крок індукції доведено.

Для граничного ординала `λ`, припускаючи справедливість нерівності для всіх `ξ < λ`, отримуємо:
```
f(λ) = sup_{ξ < λ} f(ξ) ≥ sup_{ξ < λ} ξ = λ
```
Таким чином, нерівність `f(α) ≥ α` виконується для всіх ординалів без винятку.

Канонічним прикладом нормальної функції є функція трансфінітної експоненти з фіксованою основою `f(ξ) = ω^ξ`. Додавання фіксованого ординала зліва `f(ξ) = α + ξ` та множення зліва `f(ξ) = α · ξ` (при `α > 0`) також є нормальними функціями на класі ординалів. Навпаки, додавання справа `g(ξ) = ξ + α` не є нормальною функцією, оскільки воно порушує умову неперервності в границях: наприклад, `sup_{n < ω} (n + 1) = ω`, але `sup (n) + 1 = ω + 1 ≠ ω`.

## Теорема про замкненість і необмеженість нерухомих точок

Ординал `γ` називається **нерухомою точкою** (англ. *fixed point*) функції `f`, якщо:
```
f(γ) = γ
```

Клас усіх нерухомих точок функції `f` позначається як `Fix(f) = { γ ∈ On | f(γ) = γ }`.

### Теорема (Веблен, 1908)
Якщо `f: On → On` є нормальною функцією, то клас `Fix(f)` є замкненим і необмеженим (англ. *closed and unbounded*, club):
1. **Необмеженість:** Для будь-якого ординала `α` існує нерухома точка `γ ∈ Fix(f)`, така що `γ > α`.
2. **Замкненість:** Якщо `(γ_n)_{n < λ}` є зростаючою послідовністю нерухомих точок, то її супремум `sup_{n < λ} γ_n` також належить до `Fix(f)`.

### Конструктивне доведення існування найменшої нерухомої точки
Нехай `α` — довільний початковий ординал. Побудуємо зліченну рекурсивну послідовність ординалів `(α_n)_{n < ω}` наступним чином:

```
α₀ = α + 1
α₁ = f(α₀)
α₂ = f(α₁)
...
α_{n+1} = f(α_n)
```

Оскільки `f(ξ) ≥ ξ` і `α₀ = α + 1 > α`, застосування монотонної функції породжує строго зростаючий ланцюг `α₀ < α₁ < α₂ < ...`. Визначимо границю послідовності:

```
γ = sup_{n < ω} α_n
```

Оскільки `ω` є граничним ординалом, скористаємося неперервністю функції `f`:

```
f(γ)
= f(sup_{n < ω} α_n)          [за визначенням γ]
= sup_{n < ω} f(α_n)          [за неперервністю нормальної функції f]
= sup_{n < ω} α_{n+1}         [за рекурсивним правилом побудови]
= γ                           [супремум того самого ланцюга]
```

Таким чином, `γ` є нерухомою точкою функції `f`, причому за побудовою `γ > α`, а також `γ` є найменшою нерухомою точкою, що перевищує `α`.

Доведення замкненості безпосередньо випливає з неперервності `f`: якщо `γ = sup_{i < λ} γ_i`, де `f(γ_i) = γ_i`, то:
```
f(γ) = f(sup_{i < λ} γ_i) = sup_{i < λ} f(γ_i) = sup_{i < λ} γ_i = γ
```
Клас `Fix(f)` є замкненим і необмеженим.

## Властивості перетину замкнених необмежених класів (Club Filter)

Фундаментальна теорема теорії множин стверджує, що перетин будь-якої зліченної або трансфінітної сукупності замкнених необмежених класів знову є замкненим і необмеженим класом. Нехай `(C_ξ)_{ξ < λ}` — сімейство club-класів. Тоді клас `C = ⋂_{ξ < λ} C_ξ` є замкненим і необмеженим.

Це твердження гарантує коректність граничного переходу в ієрархії Веблена: коли ми переходимо до граничного індексу `λ`, спільні нерухомі точки всіх молодших функцій утворюють непорожній необмежений клас, який можна проіндексувати новою нормальною функцією.

## Оператор похідної та ієрархія Веблена

Оскільки клас `Fix(f)` є цілком упорядкованим і необмеженим підкласом ординалів, існує єдиний порядок-ізоморфізм між усім класом `On` та класом `Fix(f)`. Цей ізоморфізм задається нормальною функцією, яка монотонно перелічує всі елементи `Fix(f)`. Ця функція позначається `f'` і називається **похідною функцією Веблена** (англ. *derivative function*):

```
f'(0) = min { γ ∈ On | f(γ) = γ }
f'(β + 1) = min { γ > f'(β) | f(γ) = γ }
f'(λ) = sup_{ξ < λ} f'(ξ)   [для граничного ординала λ]
```

Функція `f'` сама є строго монотонною та неперервною, тобто є нормальною функцією. Отже, до `f'` можна повторно застосувати оператор взяття похідної, отримавши другу похідну `f'' = (f')'`, третю похідну `f'''` і так далі для будь-якого трансфінітного індексу.

Ієрархія Веблена визначається як однопараметричне трансфінітне сімейство нормальних функцій за допомогою наступної схеми індукції:

```
1. Базовий рівень:
   φ₀(β) = ω^β

2. Крок ординала-наступника:
   φ_{α + 1}(β) = (φ_α)'(β)   [похідна функція від попереднього рівня]

3. Граничний крок (для граничного ординала λ):
   φ_λ(β) монотонно перелічує спільні нерухомі точки всіх молодших функцій:
   Fix(φ_λ) = ⋂_{ξ < λ} Fix(φ_ξ)
```

Розглядаючи індекси як перший аргумент, ми отримуємо бінарну функцію Веблена `φ(α, β) = φ_α(β)`.

### Значення ключових трансфінітних рівнів
- `φ(0, 0) = 1`
- `φ(0, 1) = ω`
- `φ(0, β) = ω^β`
- `φ(1, 0) = ε₀` (найменша нерухома точка рівняння `ω^γ = γ`)
- `φ(1, β) = ε_β`
- `φ(2, 0) = ζ₀` (найменша нерухома точка рівняння `ε_γ = γ`)
- `φ(2, β) = ζ_β`
- `φ(3, 0) = η₀` (найменша нерухома точка рівняння `ζ_γ = γ`)
- `φ(ω, 0) = sup { φ(1, 0), φ(2, 0), φ(3, 0), ... } = sup { ε₀, ζ₀, η₀, ... }`
- `φ(ω + 1, 0)` — найменша спільна нерухома точка функцій `φ_n` для всіх `n < ω`.

## Межа бінарної функції та ординал Фефермана — Шютте Γ₀

Розглянемо діагональну функцію `d(α) = φ(α, 0)`. Ця функція зіставляє кожному ординалу `α` нульове значення `α`-го рівня ієрархії Веблена.

Функція `d(α)` є строго монотонною: якщо `α < β`, то `φ(α, 0) < φ(β, 0)`. Вона також є неперервною в усіх граничних точках за побудовою граничного кроку ієрархії. Отже, функція `d(α)` сама є повноцінною нормальною функцією.

Згідно з теоремою Веблена, функція `d(α)` обов'язково має власні нерухомі точки. Найменша нерухома точка діагональної функції називається **ординалом Фефермана — Шютте** `Γ₀`:

```
Γ₀ = min { α ∈ On | φ(α, 0) = α }
```

Ординал `Γ₀` є супремумом зліченної діагональної послідовності:

```
α₀ = 0
α₁ = φ(0, 0) = 1
α₂ = φ(1, 0) = ε₀
α₃ = φ(ε₀, 0)
α₄ = φ(φ(ε₀, 0), 0)
...
Γ₀ = sup_{n < ω} α_n
```

На рівні `Γ₀` бінарна нотація `φ(α, β)` вичерпує свою виразну силу: щоб записати `Γ₀`, потрібно підставити `Γ₀` у перший аргумент функції `φ`, що призводить до нескінченного самопосилання `φ(Γ₀, 0) = Γ₀`.

## Нормальна форма Веблена (VNF) та теорема про однозначність

Для будь-якого ординала `α < Γ₀` існує єдиний канонічний розклад у **нормальну форму Веблена** (англ. *Veblen Normal Form*, VNF).

### Теорема (Канонічний розклад Веблена)
Для будь-якого ординала `0 < α < Γ₀` існують однозначно визначені натуральне число `k ≥ 1` та скінченна послідовність пар ординалів `(γ₁, β₁), (γ₂, β₂), ..., (γ_k, β_k)`, такі що:

```
α = φ(γ₁, β₁) + φ(γ₂, β₂) + ... + φ(γ_k, β_k)
```

причому виконуються два структурні інваріанти:

1. **Спадне впорядкування доданків:**
```
φ(γ₁, β₁) ≥ φ(γ₂, β₂) ≥ ... ≥ φ(γ_k, β_k)
```

2. **Критерій нескоротності розкладу (умова нормальної форми):**
Для кожного індексу `i ∈ {1, ..., k}`:
```
γ_i < φ(γ_i, β_i)   ТА   β_i < φ(γ_i, β_i)
```

Ці умови гарантують, що запис кожного ординала є скінченним нециклічним синтаксичним деревом, а процедура розкладу рекурсивно зупиняється на нулі.

## Детермінований алгоритм структурного порівняння

Нехай `A = φ(γ_A, β_A)` та `B = φ(γ_B, β_B)` — два адитивно головні терми в нормальній формі Веблена. Питання про те, чи виконується `A < B`, зводиться до рекурсивного порівняння їхніх структурних компонентів за наступними трьома правилами:

```
1. Якщо γ_A < γ_B:
   A < B  ⇔  β_A < B

2. Якщо γ_A = γ_B:
   A < B  ⇔  β_A < β_B

3. Якщо γ_A > γ_B:
   A < B  ⇔  A ≤ β_B  (тобто A < β_B або A = β_B)
```

### Математичне обґґрунтування алгоритму
- **Випадок 1 (`γ_A < γ_B`):** Функція `φ_{γ_B}` перелічує спільні нерухомі точки всіх функцій `φ_ξ` для `ξ < γ_B`. Зокрема, значення `B = φ(γ_B, β_B)` є нерухомою точкою для функції `φ_{γ_A}`, тобто `φ(γ_A, B) = B`. Оскільки функція `φ_{γ_A}` строго монотонна по своєму другому аргументу:
  ```
  A = φ(γ_A, β_A) < φ(γ_A, B) = B   ⇔   β_A < B
  ```
- **Випадок 2 (`γ_A = γ_B`):** Оскільки обидва вирази належать одній і тій самій нормальній функції `φ_{γ_A}`, їхній порядок повністю визначається другим аргументом: `β_A < β_B`.
- **Випадок 3 (`γ_A > γ_B`):** Цей випадок дзеркальний до першого: нерівність `B < A` еквівалентна `β_B < A`. Відповідно, заперечення `A ≤ B` дає умову `A < B ⇔ A ≤ β_B`.

Цей алгоритм працює суто символьно на синтаксичних деревах і має гарантований час роботи, пропорційний добутку висот порівнюваних дерев, що робить його ідеальним для комп'ютерної реалізації.

## Багатоаргументні функції Веблена

Для виходу за межі `Γ₀` функція узагальнюється на `n` аргументів: `φ(α_{n-1}, α_{n-2}, ..., α₁, α₀)`.
- Якщо перші `n - 2` аргументи дорівнюють нулю, отримуємо класичну бінарну функцію: `φ(0, ..., 0, α, β) = φ(α, β)`.
- Якщо молодші аргументи зафіксовані, старший аргумент перелічує спільні нерухомі точки молодших операторів.
- Супремум усіх скінченно-аргументних функцій утворює **Малий ординал Веблена** (SVO), а нескінченно-аргументні послідовності зі скінченним носієм утворюють **Великий ординал Веблена** (LVO).

## Фундаментальні послідовності для ординалів ієрархії Веблена

Для зв'язку з теорією обчислюваності та швидкозростаючою ієрархією (FGH) кожен граничний ординал `λ < Γ₀` оснащується канонічною фундаментальною послідовністю `(λ[n])_{n < ω}`, такою що `sup_{n < ω} λ[n] = λ`.

Основні правила редукції фундаментальних послідовностей:
1. Якщо `λ = φ(0, β + 1) = ω^(β + 1)`, то `λ[n] = ω^β · n`.
2. Якщо `λ = φ(0, β)` для граничного `β`, то `λ[n] = φ(0, β[n]) = ω^(β[n])`.
3. Якщо `λ = φ(1, 0) = ε₀`, то `λ[0] = 1`, `λ[n+1] = ω^(λ[n])` (послідовність веж степенів).
4. Якщо `λ = φ(γ + 1, 0)`, то `λ[0] = 1`, `λ[n+1] = φ(γ, λ[n])`.
5. Якщо `λ = φ(γ, 0)` для граничного `γ`, то `λ[n] = φ(γ[n], 0)`.
6. Якщо `λ = φ(γ, β + 1)`, то `λ[0] = φ(γ, β) + 1`, `λ[n+1] = φ(γ - 1, λ[n])` (для наступника `γ`).

Ці фундаментальні послідовності дозволяють рекурсивно обчислювати функції швидкозростаючої ієрархії `F_α(n)` для будь-якого трансфінітного індексу `α < Γ₀`.

## Теорема про коректність фундаментальних послідовностей

Нехай `λ < Γ₀` — довільний граничний ординал у нормальній формі Веблена. Сконструйована фундаментальна послідовність `(λ[n])_{n < ω}` задовольняє наступні фундаментальні леми:

1. **Суворе зростання:** Для будь-якого натурального `n` виконується `λ[n] < λ[n+1] < λ`.
2. **Збіжність до супремуму:** Для будь-якого ординала `ξ < λ` існує номер `N`, такий що для всіх `n ≥ N` виконується `ξ < λ[n]`.
3. **Збереження нормальної форми:** Кожен елемент `λ[n]` автоматично утворюється в канонічній нормальній формі Веблена і має строго меншу висоту синтаксичного дерева, ніж `λ`.

Це забезпечує повну алгоритмічну обчислюваність усіх рівнів швидкозростаючої ієрархії функцій аж до ординала Фефермана — Шютте.

## Топологія стрілки та порядок-ізоморфізм

Розглянемо більш детально топологічну природу оператора похідної Веблена `f ↦ f'`.

Нехай `f: On → On` — нормальна функція. Її клас нерухомих точок `Fix(f)` у порядковій топології класу `On` володіє властивістю бути замкненим (містити всі свої граничні точки) та необмеженим (для будь-якого `α ∈ On` існує `γ ∈ Fix(f)`, такий що `γ > α`).

Оскільки клас `Fix(f)` успадковує цілковите впорядкування від `On`, існує єдиний порядок-ізоморфізм між `On` та `Fix(f)`. Цей ізоморфізм є відображенням `f': On → Fix(f)`, яке задовольняє:
- `f'(0) = min(Fix(f))`;
- `f'(β + 1) = min { γ ∈ Fix(f) | γ > f'(β) }`;
- `f'(λ) = sup { f'(ξ) | ξ < λ }` для граничного `λ`.

Сувора монотонність `f'` безпосередньо випливає з конструкції наступника: `f'(β + 1) > f'(β)`. Неперервність у границях гарантується замкненістю класу `Fix(f)`: оскільки супремум зростаючого ланцюга нерухомих точок сам є нерухомою точкою, `f'(λ)` дійсно потрапляє у `Fix(f)` і є найменшою нерухомою точкою, що мажорує всі попередні значення.

## Діагоналізація та межа функцій багатьох змінних

Розширення ієрархії Веблена на довільну кількість аргументів `φ(α_{n-1}, α_{n-2}, ..., α₁, α₀)` підпорядковується наступним індуктивним правилам:

1. **Редукція нульових старших аргументів:**
   ```
   φ(0, 0, ..., 0, α, β) = φ(α, β)
   ```
2. **Крок похідної по молодшому аргументу:**
   Функція `β ↦ φ(α_{n-1}, ..., α₁, β)` є нормальною функцією для будь-яких фіксованих параметрів `α_i`.
3. **Діагоналізація старших індексів:**
   Якщо `α_k > 0`, а всі молодші індекси `α_{k-1} = ... = α₁ = 0`, функція:
   ```
   β ↦ φ(α_{n-1}, ..., α_k, 0, ..., 0, β)
   ```
   перелічує спільні нерухомі точки сімейства функцій, у яких `k`-й аргумент замінено на довільний менший ординал `ξ < α_k`.

Ця рекурсивна схема дозволяє будувати канонічні позначення для чисел, що лежать між `Γ₀` та Малим ординалом Веблена (SVO), надаючи математично строгу основу для аналізу вищих логічних систем.

## Адитивно та мультиплікативно головні ординали

У трансфінітній теорії ординалів особливе значення мають так звані головні числа, які визначають природні границі замкненості алгебраїчних операцій.

1. **Адитивно головні ординали (англ. *additively principal ordinals*):**
   Ординал `γ > 0` називається адитивно головним (або нерозкладним за додаванням), якщо для будь-яких двох менших ординалів `α, β < γ` їхня сума залишається строго меншою за `γ`:
   ```
   α < γ  ТА  β < γ  ⇒  α + β < γ
   ```
   Фундаментальна теорема стверджує, що клас адитивно головних ординалів точно збігається з множиною степенів омеги:
   ```
   γ є адитивно головним  ⇔  існує ξ, такий що γ = ω^ξ = φ(0, ξ)
   ```
   Усі базові компоненти нормальної форми Веблена `φ(γ, β)` є адитивно головними ординалами. Це гарантує, що будь-який менший доданок зліва миттєво поглинається більшим членом у розкладі Кантора.

2. **Мультиплікативно головні ординали (англ. *multiplicatively principal ordinals*):**
   Ординал `γ > 1` називається мультиплікативно головним, якщо для будь-яких `α, β < γ` їхній добуток задовольняє `α · β < γ`. Цей клас утворюють ординали виду `ω^(ω^ξ)`. Найменшим трансфінітним мультиплікативно головним ординалом є `ω^ω`.

3. **Експоненціально головні ординали (ε-числа):**
   Ординал `γ` називається експоненціально головним, якщо для будь-якого `α < γ` степінь `ω^α < γ`. Це в точності клас розв'язків рівняння `ω^γ = γ`, тобто епсилон-чисел `ε_β = φ(1, β)`.

Ця структурна градація показує, що ієрархія Веблена систематично перелічує головні ординали дедалі вищих порядків операцій, перетворюючи кожну нову форму нерозкладності на стандартний крок індексації.

## Кофінальність ординалів та регулярні кардинали

Важливою характеристикою будь-якого граничного ординала `λ` в ієрархії Веблена є його **кофінальність** (англ. *cofinality*), що позначається як `cf(λ)`.

Кофінальність ординала `λ` визначається як найменший ординал `ξ`, такий що існує строго зростаюча послідовність `(α_i)_{i < ξ}` ординалів `α_i < λ`, супремум якої дорівнює `λ`:
```
cf(λ) = min { ξ ≤ λ | ∃ (α_i)_{i < ξ} : sup_{i < ξ} α_i = λ }
```

Усі граничні ординали, що виникають в ієрархії Веблена нижче ординала `Γ₀` (включно з `ε₀`, `ζ₀`, `η₀`, `φ(ω, 0)` та самим `Γ₀`), мають кофінальність `ω` (зліченну кофінальність).

Це означає, що до будь-якої нерухомої точки або граничного поверху можна наблизитися за допомогою зліченної фундаментальної послідовності довжини `ω`:

```
cf(ε₀) = ω
cf(ζ₀) = ω
cf(Γ₀) = ω
```

Наявність зліченної кофінальності є ключовою передумовою для алгоритмічної реалізації: саме завдяки цьому будь-який граничний перехід в ієрархії Веблена можна змоделювати за допомогою звичайної рекурсивної функції над натуральними числами в швидкозростаючій ієрархії `F_α(n)`.

## Властивості транзитивності та антисиметричності відношення порядку

Наведемо строге доведення того, що описаний символьний алгоритм порівняння дерев у нормальній формі Веблена задає повноцінне цілковите лінійне впорядкування:

1. **Рефлексивність та трихотомія:**
   Для будь-яких двох термів `A` та `B` у нормальній формі Веблена виконується рівно одне зі співвідношень: `A < B`, `A = B` або `A > B`. Це безпосередньо випливає з індукції за сумою висот дерев: на кожному кроці порівнюються компоненти меншої висоти, для яких трихотомія вже встановлена за припущенням індукції.
2. **Транзитивність:**
   Якщо `A < B` та `B < C`, то `A < C`. Розбір випадків за взаємним розташуванням індексів `γ_A, γ_B, γ_C` показує, що властивість монотонності нормальних функцій `φ_ξ` зберігається при будь-якій комбінації переходів через нерухомі точки.
