# 🧮 Таблиця обчислення: від недетермінованої машини Тюринга до булевої формули

Ця вставка містить вичерпне математичне виведення булевої формули `Φ`, яка кодує обчислення недетермінованої машини Тюринга в доведенні теореми Кука — Левіна. Тут розкрито формальне визначення змістовних змінних, точний вигляд диз'юнктів для чотирьох фундаментальних умов, оцінку підсумкового розміру формули, математичний аналіз крайових умов сітки та математичну процедуру розбиття диз'юнктів до форми 3-КНФ за алгоритмом Цейтіна.

## 1. Формалізація машини Тюринга та сітки обчислення

Нехай `M = (Q, Σ, Γ, δ, q₀, q_accept, q_reject)` — недетермінована машина Тюринга, де:
- `Q` — скінченна множина станів керівного пристрою.
- `Σ` — вхідний алфавіт (`⊔ ∉ Σ`).
- `Γ` — алфавіт стрічки (`Σ ⊂ Γ`, `⊔ ∈ Γ`, де `⊔` — символ пробілу).
- `δ : (Q \ {q_accept, q_reject}) × Γ → P(Q × Γ × {L, R})` — недетермінована функція переходу, яка кожній парі (стан, символ) зіставляє множину допустимих потрійних переходів (новий стан, новий символ, напрямок зсуву).
- `q₀ ∈ Q` — початковий стан керівного пристрою.
- `q_accept, q_reject ∈ Q` — приймальний та відхиляючий стани відповідно.

Нехай `w = w₁w₂...wₙ ∈ Σⁿ` — вхідний рядок довжини `n`. Машина `M` вирішує задачу за поліномний час `p(n)`. Це означає, що будь-яка гілка недетермінованого обчислення на рядку `w` робить не більше `p(n)` кроків і відвідує не більше `p(n)` комірок стрічки.

Ми будуємо двовимірну таблицю (сітку) обчислення розміру `(p(n) + 1) × (p(n) + 1)`.
Індекс рядка `t` відповідає моменту часу: `0 ≤ t ≤ p(n)`.
Індекс стовпчика `j` відповідає позиції комірки на стрічці: `0 ≤ j ≤ p(n)`.

Кожен рядок `t` цієї таблиці описує повну конфігурацію машини Тюринга у момент часу `t`. Конфігурація включає в себе вміст усіх комірок стрічки від `0` до `p(n)`, поточну позицію головки зчитування/запису та поточний стан керівного вузла.

## 2. Логічні змінні та їх алгебраїчна нумерація

Для перетворення геометрії таблиці на об'єкт математичної логіки ми вводимо дві сім'ї булевих змінних:

1. **Змінні вмісту стрічки:**
   Для кожного моменту часу `t ∈ [0, p(n)]`, кожної позиції стрічки `j ∈ [0, p(n)]` та кожного символу алфавіту `σ ∈ Γ` вводиться змінна `x[t, j, σ]`.
   Значення `x[t, j, σ] = 1` означає, що у момент часу `t` комірка стрічки з номером `j` містить символ `σ`. Якщо `x[t, j, σ] = 0`, це означає, що дана комірка у даний момент часу містить будь-який інший символ, але не `σ`.

2. **Змінні стану та головки:**
   Для кожного моменту часу `t ∈ [0, p(n)]`, кожної позиції стрічки `j ∈ [0, p(n)]` та кожного стану `q ∈ Q` вводиться змінна `y[t, j, q]`.
   Значення `y[t, j, q] = 1` означає, що у момент часу `t` головка зчитування розташована над коміркою `j`, а машина перебуває у стані `q`. Якщо значення дорівнює `0`, це означає, що або головка перебуває в іншій комірці, або стан машини є іншим.

Щоб транслювати ці символьні змінні у стандартний формат DIMACS CNF, який використовується сучасними розв'язувачами SAT, здійснюється алгебраїчна індексація змінних цілими числами від `1` до `N_vars`:

```
index(x[t, j, σ]) = t · (p(n) + 1) · |Γ|  +  j · |Γ|  +  id(σ)  +  1
index(y[t, j, q]) = Offset_Y  +  t · (p(n) + 1) · |Q|  +  j · |Q|  +  id(q)  +  1
```

де `Offset_Y = (p(n) + 1)² · |Γ|` є зміщенням для блоку змінних головок.

Підрахуємо загальну кількість змінних у нашій логічній системі:

```
N_vars = (p(n) + 1)² · |Γ| + (p(n) + 1)² · |Q|
       = (p(n) + 1)² · (|Γ| + |Q|)
       = O(p(n)²)    [оскільки |Γ| та |Q| є сталими константами для машини M]
```

Оскільки алфавіт стрічки `Γ` та множина станів `Q` є фіксованими параметрами конкретної машини Тюринга `M` і не залежать від вхідного рядка `w`, сума `|Γ| + |Q|` є константою. Отже, кількість змінних росте як точний квадрат від обмеження часу `p(n)`.

## 3. Побудова складових частин формули Φ

Загальна булева формула `Φ` конструюється як кон'юнкція чотирьох окремих формул-умов:

```
Φ = Φ_cell ∧ Φ_start ∧ Φ_accept ∧ Φ_move
```

Формула `Φ` є здійсненною тоді й лише тоді, коли існує таке присвоєння значень булевим змінним `x[t, j, σ]` та `y[t, j, q]`, яке одночасно задовольняє всі чотири складові умови.

### 3.1. Формула однозначності клітин (Φ_cell)

Кожна клітинка таблиці `(t, j)` у кожен момент часу `t` повинна відповідати фізичній реальності машини Тюринга: вона має містити **рівно один** символ алфавіту `Γ` і не більше одного стану `Q`. Ми повинні логічно виключити ситуації, коли комірка одночасно містить два різних символи або коли головка перебуває в кількох місцях одразу.

Для кожної клітини `(t, j)` формула `Φ_cell` будується з двох типів умов:

1. **Існування та єдиність символу стрічки:**
   Принаймні один символ з алфавіту `Γ` повинен бути присутнім у комірці `(t, j)`. Це описується великою диз'юнкцією `⋁_{σ ∈ Γ} x[t, j, σ]`.
   Одночасно жодні два різні символи `σ` та `σ'` не можуть перебувати у клітинці разом. Це описується кон'юнкцією паралельних заперечень: для кожної пари `σ ≠ σ'` додається диз'юнкт `(¬x[t, j, σ] ∨ ¬x[t, j, σ'])`.

2. **Єдиність стану головки:**
   Машина не може перебувати у двох різних станах одночасно або розташовувати головку в двох різних комірках. Для кожної пари станів `q ≠ q'` додається диз'юнкт `(¬y[t, j, q] ∨ ¬y[t, j, q'])`.

Загальний математичний вираз для `Φ_cell` має вигляд:

```
A[t, j] = ( ⋁_{σ ∈ Γ} x[t, j, σ] )  ∧  ( ⋀_{σ, σ' ∈ Γ, σ ≠ σ'} (¬x[t, j, σ] ∨ ¬x[t, j, σ']) )
B[t, j] = ⋀_{q, q' ∈ Q, q ≠ q'} (¬y[t, j, q] ∨ ¬y[t, j, q'])
Φ_cell = ⋀_{t=0}^{p(n)} ⋀_{j=0}^{p(n)} ( A[t, j] ∧ B[t, j] )
```

Кількість диз'юнктів у `Φ_cell` становить:

```
N_clauses(Φ_cell) = (p(n) + 1)² · ( 1 + |Γ|(|Γ|-1)/2 + |Q|(|Q|-1)/2 )
                  = O(p(n)²)
```

### 3.2. Формула початкової конфігурації (Φ_start)

Формула `Φ_start` задає точний стан першого рядка таблиці (`t = 0`). Вона жорстко прив'язує логічні змінні до початкових умов обчислення:
- Перші `n` комірок стрічки містять символи вхідного слова `w₁w₂...wₙ`.
- Усі наступні комірки від `n` до `p(n)` містять символ пробілу `⊔`.
- Головка машини розташована у першій комірці `j = 0`, а машина перебуває у початковому стані `q₀`.
- Усі інші комірки `j > 0` не містять головки машини.

Математичний вираз для `Φ_start`:

```
Φ_start = y[0, 0, q₀]
          ∧  ( ⋀_{j=0}^{n-1} x[0, j, w_{j+1}] )
          ∧  ( ⋀_{j=n}^{p(n)} x[0, j, ⊔] )
          ∧  ( ⋀_{j=1}^{p(n)} ⋀_{q ∈ Q} ¬y[0, j, q] )
```

Оскільки це кон'юнкція поодиноких літералів, кількість диз'юнктів у `Φ_start` дорівнює `O(p(n))`.

### 3.3. Формула приймального стану (Φ_accept)

Формула `Φ_accept` вимагає, щоб обчислення було приймальним. Для цього принаймні в одному рядку таблиці `t ∈ [0, p(n)]` принаймні в одній комірці `j ∈ [0, p(n)]` машина повинна потрапити у стан `q_accept`:

```
Φ_accept = ⋁_{t=0}^{p(n)} ⋁_{j=0}^{p(n)} y[t, j, q_accept]
```

Це єдиний великий диз'юнкт, що складається з `(p(n) + 1)²` позитивних літералів. Якщо машина `M` досягає стану `q_accept` хоча б на один крок, цей диз'юнкт приймає значення 1.

### 3.4. Формула коректності переходів (Φ_move) та крайові умови

Це найбільш складне логічне узгодження, яке перевіряє правильність кожного кроку обчислення від рядка `t` до рядка `t + 1`.

Розглянемо локальне вікно розміру `2 × 3` з верхнім лівим кутом у клітинці `(t, j-1)`. Всі можливі зміни у комірці `j` між моментом `t` та `t+1` повністю визначаються вмістом трьох комірок `j-1`, `j`, `j+1` у момент `t`.

Опишемо стан вікна як кортеж із 6 елементів `W = (C₁, C₂, C₃, C₄, C₅, C₆)`, де:
- `C₁, C₂, C₃` — вміст комірок `j-1, j, j+1` у момент `t` (символ стрічки + стан головки, якщо вона там є).
- `C₄, C₅, C₆` — вміст комірок `j-1, j, j+1` у момент `t+1`.

Множина `ValidWindows` містить усі такі кортежі `W`, які відповідають законам роботи машини Тюринга:
1. Якщо головка перебуває у комірці `j` у момент `t` у стані `q` та зчитує символ `a`, і функція переходу дозволяє крок `δ(q, a) = (q', a', R)`, то у момент `t+1` комірка `j` отримує новий символ `a'`, а головка у стані `q'` переходить у комірку `j+1`.
2. Якщо головка розташована поза межами даного вікна, вміст комірок `j-1, j, j+1` у момент `t+1` повинен бути абсолютно тотожним їх вмісту у момент `t`.

Усі інші кортежі `W`, які не належать до `ValidWindows`, утворюють множину `InvalidWindows`. Для кожного вікна `(t, j)` ми будуємо формулу, яка забороняє будь-яку конфігурацію з `InvalidWindows`:

```
W_check[t, j] = ⋀_{U ∈ InvalidWindows} ( ¬U_clause )
Φ_move = ⋀_{t=0}^{p(n)-1} ⋀_{j=1}^{p(n)-1} W_check[t, j]
```

Кожен диз'юнкт `¬U_clause` містить рівно 6 літералів (по одному для кожної з 6 клітин вікна), які заперечують дане заборонене сполучення.

#### Точна аналітична оцінка розміру множини ValidWindows
Оскільки алфавіт `Γ` та множина станів `Q` є скінченними, оцінимо кількість `ValidWindows` для внутрішніх вікон:
- **Випадок 1 (головка відсутня в 3 комірках на t):** Всі 3 комірки залишаються незмінними у момент `t+1`. Кількість таких вікон дорівнює `|Γ|³`.
- **Випадок 2 (головка перебуває в одній із 3 комірок на t):** Для кожного зі станів `q ∈ Q`, кожного з 3 положень головки та кожного вибору символів `a, b, c ∈ Γ`, кількість допустимих переходів обмежена максимальним недетермінованим ступенем машини `k = max |δ(q, a)|`. Отже, кількість таких вікон виражається константою `3 · |Q| · |Γ|³ · k`.

Звідси випливає, що потужність множин `ValidWindows` та `InvalidWindows` залежить виключно від параметрів `M` і є константою `O(1)` відносно `n`.

#### Крайові умови стрічки (Φ_wall)
Для лівого краю `j = 0` та правого краю `j = p(n)` вікна скорочуються до розміру `2 × 2`. Щоб запобігти зсуву головки за ліву межу стрічки (позиція `< 0`), до формули `Φ_move` додаються спеціальні диз'юнкти межі:
- Диз'юнкти `¬y[t, 0, q]` для всіх переходів `δ(q, a)`, які містять напрямок `L` (зсув вліво на лівій межі).
- Диз'юнкти `¬y[t, p(n), q]` для всіх переходів, що вимагають зсуву `R` за праву межу розміру `p(n)`.

Оскільки кількість вікон дорівнює `p(n) · (p(n) - 1) = O(p(n)²)`, а розмір множини `InvalidWindows` обмежений константою `O(1)`, загальна кількість диз'юнктів у `Φ_move` дорівнює `O(p(n)²)`.

## 4. Підсумкова оцінка складності побудови формули

Зведемо до купи підрахунки кількості змінних та диз'юнктів у загальній формулі `Φ`:

1. **Кількість змінних:**
   `N_vars = (p(n) + 1)² · (|Γ| + |Q|) = O(p(n)²)`.
2. **Кількість диз'юнктів:**
   `N_clauses = N(Φ_cell) + N(Φ_start) + N(Φ_accept) + N(Φ_move) = O(p(n)²) + O(p(n)) + 1 + O(p(n)²) = O(p(n)²)`.
3. **Загальна довжина запису формули:**
   Оскільки кожен диз'юнкт містить обмежену кількість літералів (за винятком одного диз'юнкта `Φ_accept`), загальна довжина формули становить `O(p(n)²)`.

Алгоритм-перекладач `R` працює за поліномний час `O(p(n)²)`, оскільки він просто послідовно проходить по всіх клітинах сітки `(t, j)` та виписує логічні диз'юнкти за фіксованими правилами машини `M`.

## 5. Алгоритм розбиття на 3-КНФ (Редукція Цейтіна)

Побудована формула `Φ` містить диз'юнкти довільної довжини (зокрема диз'юнкт `Φ_accept` має довжину `O(p(n)²)`). Щоб привести формулу до стандарту **3-КНФ** (де кожен диз'юнкт містить рівно 3 літерали), застосовується алгоритм розбиття Цейтіна.

Розглянемо довільний диз'юнкт довжини `k > 3`:

```
C = ( l₁ ∨ l₂ ∨ l₃ ∨ ... ∨ lₖ )
```

Ми будуємо еквівалентний за здійсненністю ланцюжок із `k - 2` трилітеральних диз'юнктів, вводячи `k - 3` нових допоміжних змінних `z₁, z₂, ..., zₖ₋₃`:

```
C' = ( l₁ ∨ l₂ ∨ z₁ )
     ∧ ( ¬z₁ ∨ l₃ ∨ z₂ )
     ∧ ( ¬z₂ ∨ l₄ ∨ z₃ )
     ...
     ∧ ( ¬zₖ₋₄ ∨ lₖ₋₂ ∨ zₖ₋₃ )
     ∧ ( ¬zₖ₋₃ ∨ lₖ₋₁ ∨ lₖ )
```

#### Покроковий приклад розбиття 5-літерального диз'юнкта
Для наочності розглянемо диз'юнкт `C = (a ∨ b ∨ c ∨ d ∨ e)` з `k = 5`.
Алгоритм створює `5 - 3 = 2` нові змінні `z₁, z₂` та розбиває диз'юнкт на `5 - 2 = 3` трилітеральні скобки:

```
C' = (a ∨ b ∨ z₁) ∧ (¬z₁ ∨ c ∨ z₂) ∧ (¬z₂ ∨ d ∨ e)
```

Простежимо оцінку значень при `a = 0, b = 0, c = 1, d = 0, e = 0`:
- Перша скобка `(0 ∨ 0 ∨ z₁)` вимагає `z₁ = 1`.
- Друга скобка `(¬1 ∨ 1 ∨ z₂) = (0 ∨ 1 ∨ z₂)` виконується за рахунок `c = 1` при будь-якому `z₂`. Покладемо `z₂ = 0`.
- Третя скобка `(¬0 ∨ 0 ∨ 0) = (1 ∨ 0 ∨ 0)` виконується за рахунок `¬z₂ = 1`.
- Формула `C'` є істинною (1).

Доведемо фундаментальну математичну еквівалентність за здійсненністю для довільного `k`: `C` є здійсненним ⇔ існує такий набір значень змінних `z_i`, за якого `C'` є здійсненним.

**Доведення в напрямку (⇒):**
Припустимо, що диз'юнкт `C` є істинним. Це означає, що принаймні один літерал `l_m = 1` для декількох або одного `m ∈ {1, 2, ..., k}`.
- Якщо `m ∈ {1, 2}`, покладемо всі нові змінні `z₁ = z₂ = ... = zₖ₋₃ = 0`. Тоді перша скобка `(l₁ ∨ l₂ ∨ z₁)` істинна, бо `l_m = 1`. Друга скобка `(¬z₁ ∨ l₃ ∨ z₂)` істинна, бо `¬z₁ = 1`. Усі наступні скобки також істинні через `¬z_i = 1`.
- Якщо `m ∈ {3, ..., k-2}`, покладемо `z₁ = z₂ = ... = z_{m-2} = 1`, а всі наступні `z_{m-1} = ... = zₖ₋₃ = 0`. Усі скобки до `m-1`-ї істинні через `z_i = 1`. Скобка під номером `m-1`, яка має вигляд `(¬z_{m-2} ∨ l_m ∨ z_{m-1})`, істинна через `l_m = 1`. Усі наступні скобки істинні через `¬z_i = 1`.
- Якщо `m ∈ {k-1, k}`, покладемо всі `z₁ = z₂ = ... = zₖ₋₃ = 1`. Тоді остання скобка істинна через `l_m = 1`, а всі попередні — через `z_i = 1`.

У всіх випадках формула `C'` приймає значення 1.

**Доведення в напрямку (⇐):**
Доведемо протилежне методом від супротивного. Припустимо, що `C = 0`. Це означає, що всі вихідні літерали `l₁ = l₂ = ... = lₖ = 0`.
Тоді підставимо `l_i = 0` у формулу `C'`:
```
C' = ( 0 ∨ 0 ∨ z₁ ) ∧ ( ¬z₁ ∨ 0 ∨ z₂ ) ∧ ( ¬z₂ ∨ 0 ∨ z₃ ) ∧ ... ∧ ( ¬zₖ₋₃ ∨ 0 ∨ 0 )
   = ( z₁ ) ∧ ( ¬z₁ ∨ z₂ ) ∧ ( ¬z₂ ∨ z₃ ) ∧ ... ∧ ( ¬zₖ₋₃ )
```
З першої скобки випливає, що `z₁` мусить бути 1.
З другої скобки `(¬z₁ ∨ z₂) = (0 ∨ z₂)` випливає, що `z₂` мусить бути 1.
По індукції отримуємо, що всі `z₁ = z₂ = ... = zₖ₋₃ = 1`.
Проте остання скобка вимагає `¬zₖ₋₃ = 1`, що означає `zₖ₋₃ = 0`.
Ми отримали суперечність `1 = 0`. Отже, якщо `C = 0`, то формула `C'` є нездійсненною.

Математична еквівалентність доведена повністю.

## 6. Саморедукція та відновлення свідка (Search-to-Decision)

Теорема Кука — Левіна сформульована для розпізнавальної версії SAT (відповідь «так/ні»). Проте на практиці нас цікавить не лише факт існування розв'язку, а й **сам конкретний свідок** — присвоєння змінним значень `x_i ∈ {0, 1}`.

Завдяки математичній властивості **саморедукції** (self-reductibility), наявність розв'язувача розпізнавальної задачі SAT дозволяє знайти конкретний свідок за не більше ніж `M` викликів розв'язувача (де `M` — кількість змінних):

```
Алгоритм знаходження свідка за допомогою оракула розпізнавання SAT:
1. Перевірити, чи здійсненна вихідна формула Φ. Якщо ні — повернути "нездійсненна".
2. Для кожної змінної v_i від 1 до M:
   а. Підставити v_i = 1 у формулу Φ (фіксація істини).
   б. Якщо отримана спрощена формула Φ' є здійсненною:
      - Зафіксувати значення v_i = 1, покласти Φ = Φ'.
   в. Інакше (якщо підстановка v_i = 1 робить формулу нездійсненною):
      - Зафіксувати значення v_i = 0, підставити v_i = 0 у формулу Φ, покласти Φ = Φ''.
3. Повернути накопичений вектор значень (v₁, v₂, ..., v_M).
```

Оскільки на кожному з `M` кроків робиться рівно один поліномний виклик розпізнавача SAT, за сумарний поліномний час ми отримуємо точну траєкторію обчислення машини Тюринга.

## 7. Математичний аналіз межі між 2-SAT, Horn-SAT та 3-SAT

Математична різниця у складності між 2-SAT (клас P) та 3-SAT (клас NP-повних задач) коріниться у графічній топології логічного наслідку.

У задачі 2-SAT кожен диз'юнкт `(A ∨ B)` еквівалентний двом бінарним імплікаціям `¬A → B` та `¬B → A`. Це дозволяє побудувати орієнтований **граф імплікацій** `G = (V, E)`, де вершинами є змінна та її заперечення `x_i, ¬x_i`, а ребрами — логічні наслідки. Перевірка здійсненності еквівалентна аналізу сильно зв'язаних компонентів (SCC): формула здійсненна тоді й лише тоді, коли жодна змінна `x_i` не лежить у тотожній компоненті зі своїм запереченням `¬x_i`. Оскільки алгоритми Тар'яна та Корасаджу виявляють компоненти сильно зв'язаності за лінійний час `O(V + E)`, 2-SAT належить до класу P.

Спроба розширити цей метод на 3-SAT зустрічає непереборну математичну перешкоду: трилітеральний диз'юнкт `(A ∨ B ∨ C)` вимагає тернарних імплікацій виду `(¬A ∧ ¬B) → C`. Такі умови описують не звичайний граф, а **гіперграф** із тернарними ребрами. У гіперграфах класичне поняття сильно зв'язаних компонентів втрачає лінійну обчислюваність, що й призводить до комбінаторного вибуху.

Для **Horn-SAT** (де кожен диз'юнкт містить не більше одного позитивного літерала) структура дозволяє застосувати алгоритм каскадного поширення одиниць (unit propagation). Якщо диз'юнкт складається з одного позитивного літерала `(p)`, то `p` мусить стати 1. Це значення підставляється у всі інші диз'юнкти, скорочуючи їх. Оскільки щоразу принаймні одна змінна зафіксовується, процес завершується за лінійний час `O(N)`.

Завдяки алгоритму Цейтіна та саморедукції будь-яка формула `Φ` перетворюється на 3-КНФ формулу `Φ'` за поліномний час, що завершує повне математичне доведення теореми Кука — Левіна.
