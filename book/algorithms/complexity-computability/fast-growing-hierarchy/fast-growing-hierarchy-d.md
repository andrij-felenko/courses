- [Порядкові числа (ординали)](book:math/ordinal-numbers) — трансфінітна лічба, ω, ε₀, цілковите впорядкування та канторова нормальна форма.

Коли алгоритміст оцінює складність сортування злиттям чи пошуку в глибину, йому цілком вистачає класичних асимптотичних виразів `O(n log n)` або `O(n²)`. Навіть у найважчих криптографічних алгоритмах, при розв'язанні комбінаторних задач повного перебору чи аналізі булевих схем часові оцінки рідко виходять за межі експоненціального росту `O(2ⁿ)` чи факторіалу `O(n!)`. У крайніх випадках, як-от при побудові найгірших випадків сортування або перевірці досяжності в графах станів, ми стикаємося з гіперекспоненціальними оцінками.

Проте у теоретичній інформатиці, автоматичному верифікуванні програм, системному аналізі процедур переписування термів та математичній логіці виникають обчислювальні процеси, чий час виконання росте не просто швидше за будь-яку скінченну вежу експонент, а перевищує обчислювальні можливості будь-якої формальної системи, побудованої на аксіомах арифметики Пеано.

Для аналізу, систематизації та строгої класифікації таких ультрашвидких процесів стандартна нотація O великого виявляється повністю непридатною. Коли темп зростання обчислювальної складності обганяє будь-які поліноми, експоненти й тетрації, виникає потреба у спеціальній трансфінітній шкалі складності. Такою шкалою є швидкозростаюча ієрархія (лат. *hierarchia*, з грец. *hierarchia* — священний порядок), яка індексується трансфінітними ординальними числами та задає універсальну систему координат для класифікації загальнорекурсивних функцій за швидкістю їхнього росту.

## Межа елементарного світу та потреба у трансфінітній класифікації

Класична теорія складності обчислень оперує стандартними класами `P`, `NP`, `PSPACE` та `EXPTIME`. Усі ці класи містяться у межах так званих елементарних функцій за Кальмаром (англ. *Kalmár elementary functions*). Функція називається елементарною, якщо вона побудована з операцій додавання, віднімання, множення та піднесення до степеня за допомогою скінченного числа композицій та обмежених підсумовувань. Верхня межа зростання будь-якої елементарної функції завжди обмежена вежею експонент фіксованої висоти `2 ↑↑ k` для деякого скінченного `k`.

Однак під час розробки автоматичних доводжувачів теорем (наприклад, Coq, Lean, Isabelle/HOL), аналізу системи розв'язання рівнянь у вільних моноідах або верифікації алгоритмів усунення критичних пар Knuth-Bendix дослідники зустріли процеси, чия тривалість роботи принципово перевищує будь-яку скінченну вежу експонент. Наприклад, алгоритми уніфікації термів із порядковими обмеженнями або перевірка завершуваності систем переписування термів (англ. *term rewriting systems*, TRS) можуть виконувати кількість кроків, яка не описується жодним елементарним поліномом чи експонентою.

У таких умовах виникає «асимптотична сліпота»: традиційне O-велике втрачає роздільну здатність, оскільки порівняння двох функцій, що виходять за межі веж експонент, вимагає значно точнішого інструменту. Таким інструментом стали ординальні числа Георга Кантора. Вони надають нескінченну послідовність «порядок-типів» цілком упорядкованих множин, які дозволяють побудувати неперервну драбину складніших і складніших функцій.

Швидкозростаюча ієрархія вирішує задачу вимірювання складності шляхом присвоєння кожному алгоритму або формальній теорії власного ординального індексу `α`. Чим більшим є ординал `α`, тим швидше зростає супутна функція `F_α`, і тим більша доказова сила вимагається від формальної теорії для підтвердження тотальності цього алгоритму.

## Рекурсивне визначення та базові рівні FGH

Швидкозростаюча ієрархія (англ. *Fast-Growing Hierarchy*, FGH) є послідовністю тотальних обчислювальних функцій `(F_α)_{α < µ}`, де індекс `α` належить до множини зліченних трансфінітних ординалів, а аргумент `n` є додатним натуральним числом (`n ∈ ℕ`).

Вся математична шкала будується за допомогою трьох фундаментальних правил, які строго відповідають трихотомічній природі ординальних чисел (нуль, ординал-наступник, граничний ординал):

1. **Базовий крок (нульовий ординал `α = 0`):**
```
F₀(n) = n + 1
```
Функція `F₀` здійснює найпростішу базову операцію над натуральним числом — інкремент (додавання одиниці).

2. **Крок ординала-наступника (`α + 1`):**
```
F_{α + 1}(n) = F_α^(n)(n)
```
де позначення `F_α^(n)(n)` означає `n`-кратну суперпозицію (ітерацію) функції `F_α`, застосовану до власного вхідного аргументу `n`:
```
F_α^(n)(n) = F_α(F_α(...F_α(n)...))    [n разів повторено виклик F_α]
```
Кожен новий рівень `α + 1` отримується шляхом «діагоналізації» та повторення операцій попереднього рівня `α` стільки разів, чому дорівнює поточне вхідне число `n`.

3. **Граничний крок (`α = λ`):**
```
F_λ(n) = F_{λ[n]}(n)
```
де `(λ[n])_{n ∈ ℕ}` є строго визначеною канонічною фундаментальною послідовністю натуральних чисел або менших ординалів, яка збігається до граничного ординала `λ`.

![Рівні швидкозростаючої ієрархії](/book/algorithms/complexity-computability/fast-growing-hierarchy/img/fig1-fgh-levels.svg)
*Рівні швидкозростаючої ієрархії F_α(n) та їхні обчислювальні межі від лінійного інкременту до межі арифметики Пеано.*

Щоб детально простежити, як ітерація операцій формує вибуховий ріст обчислювальної складності, розгорнемо перші скінченні рівні ієрархії для довільного аргументу `n`:

На рівні `F₁` ми повторюємо додавання одиниці `n` разів:
```
F₁(n) = F₀^(n)(n) = n + 1 + 1 + ... + 1 = 2n
```
Отримуємо скалярне множення аргументу на 2 (лінійне зростання).

На рівні `F₂` ми здійснюємо `n`-кратну ітерацію функції подвоєння `F₁`:
```
F₂(n) = F₁^(n)(n) = 2 · 2 · ... · 2 · n = n · 2ⁿ
```
Функція `F₂` демонструє експоненціальний ріст, поєднуючи поліноміальний та показникові множники.

На рівні `F₃` відбувається якісний, фундаментальний стрибок у гіперекспоненціальний простір. Виконаємо `n`-кратну ітерацію функції `F₂`:
```
F₃(n) = F₂^(n)(n)
```
Якщо для `n = 1` значення дорівнює `F₃(1) = F₂(1) = 1 · 2¹ = 2`, то вже для `n = 2` отримуємо:
```
F₃(2) = F₂(F₂(2)) = F₂(2 · 2²) = F₂(8) = 8 · 2⁸ = 2048
```
Для аргументу `n = 3` значення `F₃(3)` обчислюється через трьохрівневу вкладеність експонент:
```
F₂(3) = 3 · 2³ = 24
F₂(24) = 24 · 2²⁴ = 402653184
F₃(3) = F₂(402653184) = 402653184 · 2⁴⁰²⁶⁵³¹⁸⁴
```
Отримане число `F₃(3)` перевищує `10¹21175671`. Воно містить понад 120 мільйонів десяткових цифр і є незрівнянно більшим за кількість елементарних частинок у всьому спостережуваному Всесвіті (`~10⁸⁰`) чи кількість планковських об'ємів у ньому (`~10¹⁸⁵`). Рівень `F₃` відповідає операції тетрації (піднесенню до степеня у вежу експонент `2 ↑↑ n`).

На рівні `F₄` ітерація застосовується вже до веж степеней `F₃`, створюючи операцію пентації (`2 ↑↑↑ n`), а для загального скінченного `k` функція `F_k` описує `k`-й рівень операцій Гіпероператора (англ. *hyperoperator*).

Важливою алгебраїчною властивістю ієрархії є її сувора монотонність. Вона доводиться за допомогою трьох допоміжних лем:
- **Лема 1 (Монотонність аргументу):** Для будь-якого фіксованого ординала `α` та натуральних чисел `m < n` маємо `F_α(m) < F_α(n)`.
- **Лема 2 (Монотонність ординального індексу):** Для будь-яких ординалів `α < β` та аргументу `n ≥ 2` виконується `F_α(n) < F_β(n)`.
- **Лема 3 (Мажорування ітерацій):** Ітерація вищого ординала завжди обганяє скінченну композицію молодших рівнів.

Це означає, що підвищення індексу ординала гарантує незворотний, якісний стрибок складності обчислень.

## Трансфінітна діагоналізація: від ω до ω^ω

Справжня сила швидкозростаючої ієрархії розкривається тоді, коли індекс `α` перетинає межу скінченних чисел `ℕ` та входить у область трансфінітних ординалів Кантора.

Першим нескінченним ординалом є `ω` (омега). Оскільки `ω` є граничним ординалом, його значення визначається через канонічну фундаментальну послідовність `ω[n] = n`. Застосовуючи правило для граничних ординалів, отримуємо:
```
F_ω(n) = F_{ω[n]}(n) = F_n(n)
```
Це твердження є основою механізму **трансфінітної діагоналізації** (грец. *diagonios* — по діагоналі). Функція `F_ω` не обмежена жодним скінченним рівнем `k`: для кожного вхідного значення `n` вона обчислює значення елемента `n`-го рівня `F_n(n)`.

За швидкістю росту функція `F_ω` точно відповідає класичній функції Аккермана `A(n, n)`. Оскільки функція Аккермана мажорує будь-яку примітивно-рекурсивну функцію, рівень `F_ω` слугує чітким вододілом у теорії алгоритмів:
- Усі функції `F_k` при скінченному `k < ω` є примітивно-рекурсивними (англ. *primitive recursive functions*). Їхнє виконання завжди можна запрограмувати за допомогою вкладених циклів `for` із наперед відомими межами.
- Функція `F_ω` та всі наступні рівні `F_α` (для `α ≥ ω`) виходять за межі примітивної рекурсії та є загальнорекурсивними функціями вищого порядку, що вимагають циклів `while` з невизначеним часом зупинки.

За ординалом `ω` розміщуються ординали-наступники `ω + 1, ω + 2, ...`. Значення `F_{ω+1}(n)` обчислюється як `n`-кратна ітерація самісінької функції Аккермана:
```
F_{ω+1}(n) = F_ω^(n)(n)
```
Далі виникають нові граничні ординали вигляду `ω · 2`, `ω · 3`, ..., `ω²`, ..., `ω^k`, ..., `ω^ω`.

Для обчислення швидкозростаючої ієрархії на цих рівнях кожен ординал подається у канонічній **нормальній формі Кантора** (CNF):
```
α = ω^(β₁) · c₁ + ω^(β₂) · c₂ + ... + ω^(βₖ) · cₖ
```
де `β₁ > β₂ > ... > βₖ ≥ 0`, а `cᵢ` — додатні цілі числа.

![Дерево Кантора та фундаментальні послідовності](/book/algorithms/complexity-computability/fast-growing-hierarchy/img/fig2-ordinal-tree.svg)
*Представлення ординалів у канонічній формі Кантора та редукція фундаментальної послідовності λ[n] для обчислення F_λ(n).*

Ординальна арифметика Кантора суттєво відрізняється від звичайної числової алгебри через некомутативність операцій додавання та множення. Наприклад, `1 + ω = ω`, проте `ω + 1 > ω`. Аналогічно, `2 · ω = ω`, але `ω · 2 = ω + ω > ω`. Канонічна форма Кантора усуває цю неоднозначність, зводячи будь-який вираз до впорядкованого спадного рядка старших доданків.

Канонічні фундаментальні послідовності для вищих ординалів визначаються за наступними алгебраїчними правилами:
1. Для степеня `ω^(α + 1)`: `(ω^(α + 1))[n] = ω^α · n`.
2. Для граничного показника `ω^λ`: `(ω^λ)[n] = ω^(λ[n])`.
3. Для суми `γ + ω^β`: `(γ + ω^β)[n] = γ + (ω^β)[n]`.

Простежимо кроки редукції для ординала `ω^ω`. За правилом для граничного показника фундаментальна послідовність має вигляд `(ω^ω)[n] = ωⁿ`. Отже:
```
F_{ω^ω}(n) = F_{ωⁿ}(n)
```
Якщо обрати `n = 3`, функція `F_{ω^ω}(3)` перетворюється на `F_{ω³}(3)`. Застосовуючи правило для степеня далі:
```
(ω³)[3] = (ω^(2 + 1))[3] = ω² · 3 = ω² + ω² + ω²
```
Звідси отримуємо `F_{ω² + ω² + ω²}(3)`. Кожен наступний крок знижує найбільший доступний показник степеня, замінюючи його на потрійну суму молодших доданків, поки вираз не спуститься до скінченних чисел.

Детальний математичний апарат побудови фундаментальних послідовностей, доведення монотонності та теореми про мажорування наведено у вставці [🧮 Фундаментальні послідовності та трансфінітні доведення FGH](book:algorithms/complexity-computability/fast-growing-hierarchy/math-fundamental-sequences.md).

## Межа арифметики Пеано та ординал ε_0

Зі збільшенням показників степеня ординали у формі Кантора утворюють послідовність `ω, ω^ω, ω^(ω^ω), ω^(ω^(ω^ω)), ...`. Границею цієї нескінченної вежі степеней є ординал `ε₀` (епсилон-нуль), визначений як найменше число, для якого виконується тотожність:
```
ω^(ε₀) = ε₀
```
Ординал `ε₀` займає особливе, центральне місце у математичній логіці та теорії обчислюваності. У 1936 році Гергард Ґентцен довів несуперечливість формальної арифметики Пеано (`PA`), використавши трансфінітну індукцію до ординала `ε₀`. Ґентцен застосував метод усунення розрізів (англ. *cut-elimination theorem*) у секційному численні, показавши, що будь-яке формальне доведення у `PA` можна спростити, а висота синтаксичного дерева спрощення оцінюється ординалами, меншими за `ε₀`.

Фундаментальна послідовність для `ε₀` будується як вежа степеней омеги:
```
ε₀[0] = 0
ε₀[n + 1] = ω^(ε₀[n])
```
Звідси маємо: `ε₀[1] = 1`, `ε₀[2] = ω`, `ε₀[3] = ω^ω`, `ε₀[4] = ω^(ω^ω)`.

Стенлі Вайнер довів фундаментальну теорему про доказову тотальність (англ. *provably total recursive functions*):

> **Теорема Вайнера.** Обчислювана функція `f: ℕ → ℕ` є доказово тотальною у формальній арифметиці Пеано `PA` (тобто `PA ⊢ ∀x ∃y T(e, x, y)`) тоді й лише тоді, коли її швидкість зростання мажорується функцією `F_α` для деякого ординала `α < ε₀`.

![Спектр доказової сили формальних систем](/book/algorithms/complexity-computability/fast-growing-hierarchy/img/fig3-peano-provability.svg)
*Спектр доказової сили логічних систем та відповідні межі швидкозростаючої ієрархії.*

Наслідки цієї теореми є колосальними для всієї інформатики:
1. Для будь-якого `α < ε₀` тотальність (завершуваність для всіх вхідних даних) функції `F_α` можна довести засобами класичної арифметики Пеано.
2. Проте функція `F_{ε₀}` росте настільки швидко, що її тотальність **неможливо** довести в арифметиці Пеано. Спроба довести у `PA`, що `F_{ε₀}(n)` завершує роботу для кожного `n`, призвела б до доведення несуперечливості самісінької `PA`, що заборонено другою теоремою Ґеделя про неповноту.

## Застосування у системах переписування термів та верифікації

Швидкозростаюча ієрархія знаходить пряме практичне застосування в комп'ютерній інженерії, теорії мов програмування та розробці компіляторів функціональних мов:

1. **Системи переписування термів (TRS):** У системах символьних обчислень та автоматичного спрощення виразів підтвердження завершуваності правил спирається на порядкові впорядкування (англ. *Lexicographic Path Order*, LPO, та *Recursive Path Order*, RPO). Присвоєння термам ординальних ваг дозволяє довести, що спрощення виразу завжди зупиниться за скінченну кількість дій. Часова складність найгіршого випадку таких алгоритмів описується рівнями FGH (`F_{ω^ω}` або `F_{ε₀}`). Наприклад, вимірювання складності спрощення виразів у комбінаторній логіці `SKI` або модулях уніфікації `λ`-числення вимагає трансфінітних оцінок за шкалою FGH.
2. **Інтерактивні доводжувачі теорем (Coq, Lean, Isabelle):** Коли розробник пише рекурсивну функцію у мовах Coq або Lean, систему цікавить доведення завершуваності. Якщо рекурсія не є прямою структурною рекурсією за індуктивним типом даних, програміст повинен вказати міру спадання (англ. *well-founded measure*) в ординальній шкалі через предикат цілковитої впорядкованості `Acc R x`. Оцінка складності обчислення цієї міри напряму виражається через фундаментальні послідовності FGH.
3. **Оцінка складності процедур завершення Кнута — Бендікса:** Алгоритм Кнута — Бендікса (англ. *Knuth–Bendix completion*) поповнює набір правил переписування для перетворення їх на конфлюентну систему. Часова складність цього алгоритму виражається через швидкозростаючі функції трансфінітного рівня.

## Синтез та роль ієрархії у сучасній інформатиці

Швидкозростаюча ієрархія — це не просто математичний курйоз для генерації колосальних чисел. Вона є фундаментальним інструментом у сучасній теоретичній інформатиці.

Вона слугує універсальним містом між абстрактною ординальною математикою Кантора та прагматичним світом обчислювальних алгоритмів. Класифікуючи функції за ординальним індексом `α`, швидкозростаюча ієрархія окреслює межі обчислюваності та доводжуваності, вказуючи межі того, що може бути виконано у формальних комп'ютерних системах. Вона забезпечує єдиний синтаксичний та семантичний базис для порівняння доказової сили логік, оцінки найгіршого часу виконання складних розв'язувачів та гарантії надійності відповідальних програмних систем.

Завдяки цьому математичному інструментарію теорія алгоритмів отримує об'єктивне мірило, яке пов'язує глибину синтаксичного рекурсивного розгортання із граничною складністю логічних систем.

Значення ієрархії полегає у тому, що вона перетворює абстрактні логічні теореми на конкретні числові виміри. Кожен трансфінітний ординал виступає не лише символом нескінченності, а й точним показником обчислювальних витрат, вимагаючи відповідної глибини рекурсії та потужності аксіоматичних систем. Завдяки цьому швидкозростаюча ієрархія залишається одним із найважливіших концептуальних досягнень математичної думки XX століття, що поєднує теоретичну математику з практичною інформатикою.

Таким чином, швидкозростаюча ієрархія слугує непохитним фундаментальним орієнтиром, який дає змогу виражати найскладніші обчислювальні інваріанти у вигляді елегантних та строгих ординальних формул. Вона надійно поєднує теоретичну математику з практичними інструментами автоматизованої верифікації коду.

Тривалий час існувала гіпотеза, що функції рівня `F_{ε₀}` є штучними математичними абстракціями. Проте подальші відкриття спростували це:

### Послідовності Ґудстейна та механізм спадкової бази
У 1944 році Рубен Ґудстейн сформулював арифметичний процес, який здається простим, але виходить за межі `PA`. Для кожного числа `n` ми записуємо його у спадковій системі числення з базой `b = 2` (де не лише числа, але й показники степеней записуються у тій самій базі `2`). Потім ми здійснюємо два кроки:
1. Замінюємо всі входження бази `b` на `b + 1` (збільшуємо базу).
2. Віднімаємо від отриманого числа одиницю.

Потім ми повторюємо ці дії для нової бази `b = 3`, далі `b = 4` і так далі. Простежимо короткий числовий приклад для початкового числа `n = 3`:
- У базі `2`: `3 = 2¹ + 1`. 
- Крок 1 (база `2 → 3`): замінюємо `2` на `3`, отримуємо `3¹ + 1 = 4`. Віднімаємо 1: `3 = 1 · 3¹ + 0`.
- Крок 2 (база `3 → 4`): замінюємо `3` на `4`, отримуємо `4¹ = 4`. Віднімаємо 1: `3 = 3 · 4⁰`.
- Крок 3 (база `4 → 5`): замінюємо `4` на `5`, отримуємо `3 · 5⁰ = 3`. Віднімаємо 1: `2`.
- Крок 4: `2 → 1 → 0`. Послідовність обнулилася за 5 кроків.

Проте вже для `n = 4` початковий запис `4 = 2²` при зміні бази дає `3³ = 27`, далі `4² · 3 = 48`, і значення вибухають до числа з тисячами цифр, перш ніж почати спадати. 

Математично доведено, що послідовність Ґудстейна **завжди** врешті-решт спадає до `0`. Для доведення цього кожному кроку зіставляють ординал, замінюючи базу `b` на трансфінітну змінну `ω`. Оскільки віднімання 1 на кожному кроці зменшує ординал, за властивістю цілковитого впорядкування ординалів нескінченний спад неможливий, і послідовність обнуляється. Але тривалість цього процесу росте як `F_{ε₀}(n)`, тому аксіоми `PA` не здатні це довести.

### Механізм усунення розрізів Ґентцена
Для розуміння того, чому саме ординал `ε₀` виникає у доведенні несуперечливості `PA`, розглянемо теорему Ґентцена про усунення розрізів (англ. *cut-elimination theorem*). У секційному численні логичний вивід може містити правило розрізу (лат. *cut*), яке відповідає використанню проміжних лем у математичному доведенні.

Ґентцен розробив синтаксичну процедуру підстановки, яка послідовно усуває розрізи з логічного виводу. Кожен крок усунення розрізу з логічною складністю `d` подвоює вежу експонент висоти синтаксичного дерева доведення. Якщо доведення використовує індукцію за логічною формулою з `k` кванторами, усунення цих розрізів вимагає `k`-кратної вежі степеней омеги `ω^(ω^(...))`. Оскільки у формальній арифметиці Пеано індукція може застосовуватися до формул довільної кванторної складності, сукупна висота усіх можливих доведень обмежена найменшою нерухомою точкою `ε₀ = sup { ω, ω^ω, ω^(ω^ω), ... }`.

### Гра з Гідрою Кербі — Паріса
У 1982 році Лорі Кербі та Джефф Паріс вигадали гру з багатоголовим деревом-Гідрою. Гідра являє собою скінченне вкорінене дерево. На кожному кроці Геракл стинає одну з голів-листків Гідри. Після цього Гідра відрощує нові піддерева за таким правилом: якщо відтинати голову, з'єднану з батьківським вузлом `V`, то з вузла `V` виростає `n` нових копій всього піддерева, яке веде до `V` (де `n` — номер поточного кроку гри).

Якщо голова росте безпосередньо з кореня, додаткові копії не виростають. Попри те, що Гідра після кожного удару мультиплікує свої гілки мільйони разів, Геракл **завжди** перемагає за скінченну кількість кроків. Кожному стану Гідри відповідає ординал `α < ε₀`. Стинання голови суворо зменшує цей ординал. Оскільки ординали не можуть спадати нескінченно, Гідра буде повністю знищена. Проте кількість кроків у цій грі росте зі швидкістю `F_{ε₀}(n)`, тому доведення завершуваності гри неможливе в арифметиці Пеано.

### Теорема Паріса — Гаррінгтона
У 1977 році Джефф Паріс та Лео Гаррінгтон довели перший природний приклад недовідної комбінаторної теореми у `PA`. Вона є посиленням скінченної теореми Рамсея: для будь-яких чисел `n, k, m` існує таке `N`, що при будь-якому розфарбуванні `k`-елементних підмножин множини `{1, 2, ..., N}` у `m` кольорів існує однорідна підмножина `Y`, розмір якої не менший за її найменший елемент (`|Y| ≥ min(Y)`). Функція обчислення найменшого необхідного `N` мажорується `F_{ε₀}`, що робить твердження недовідним у `PA`.

Детальний аналіз історичного шляху від програми Гільберта та доведення Ґентцена до відкриття недовідних комбінаторних теорем викладено у вставці [📜 Історія виникнення швидкозростаючої ієрархії та теорія доведень](book:algorithms/complexity-computability/fast-growing-hierarchy/hist-fgh-origins.md).

## За межами Пеано: ординали Веблена, Γ₀ та Бахмана — Говарда

За межею `ε₀` швидкозростаюча ієрархія не зупиняється. Для дослідження сильніших формальних теорій другої порядку (імпредикативної аналітики) математики використовують вищі системи ординальних нотацій.

Основним інструментом розширення шкали над `ε₀` є ієрархія функцій Освальда Веблена (англ. *Oswald Veblen*, 1908) `ϕ_α(β)`:
- `ϕ₀(β) = ω^β`.
- `ϕ₁(β) = ε_β` (послідовність нерухомих точок `ω^α = α`).
- `ϕ_{α+1}(β)` перелічує спільні нерухомі точки усіх попередніх функцій `ϕ_γ` для `γ ≤ α`.

Першою нерухомою точкою ієрархії Веблена, для якої `ϕ_α(0) = α`, є **ординал Фейфермана — Лева** (або малий ординал Веблена) `Γ₀` (гамма-нуль). Ординал `Γ₀` визначає межу доказової сили для підпредикативної аналітики — формальної системи `ATR₀` (англ. *Arithmetical Transfinite Recursion*). Тотальність функції `F_{Γ₀}` мажорує всі функції, тотальність яких доводиться в `ATR₀`.

Ще вище розміщується **ординал Бахмана — Говарда** (англ. *Bachmann–Howard ordinal* `Ψ(ε_{Ω+1})`), який виражається через функції колапсу ординалів (англ. *ordinal collapsing functions*) і позначає межу доводжуваності системи `Π¹₁-CA₀` (компрегенції другого порядку). На цьому рівні FGH описує складності таких комбінаторних теорем, як теорема Краскала про дерева та теорема Робертсона — Сеймура про мінори графів.

## Порівняння з ієрархіями Гарді та Джирарда

У математичній логіці поруч із швидкозростаючою ієрархією Вайнера — Швіхтенберга використовуються інші трансфінітні шкали. Найважливішими з них є ієрархія Гарді `(H_α)` та повільнозростаюча ієрархія Джирарда `(G_α)`.

### Ієрархія Гарді (H_α)
Ієрархія Ґодфрі Гарді визначається зсувом аргументу замість ітерації:
1. `H₀(n) = n`.
2. `H_{α + 1}(n) = H_α(n + 1)`.
3. `H_λ(n) = H_{λ[n]}(n)`.

Замість того, щоб викликати функцію `n` разів у вкладеній рекурсії, ієрархія Гарді лише збільшує аргумент `n → n + 1` на кожному кроці ординала-наступника.

Зв'язок між ієрархією Гарді та швидкозростаючою ієрархією описується точним тотожним співвідношенням:
```
F_α(n) = H_{ω^α}(n)
```
Це означає, що ієрархія Гарді росте повільніше за FGH за ординальним індексом: рівень `F_α` відповідає значно вищому ординалу `ω^α` у шкалі Гарді. Наприклад, `F_ω(n) = H_{ω^ω}(n)`.

### Повільнозростаюча ієрархія Джирарда (G_α)
Жан-Ів Джирард (фр. *Jean-Yves Girard*) запропонував повільнозростаючу ієрархію `(G_α)` для аналізу імпредикативних формальних систем:
1. `G₀(n) = 0`.
2. `G_{α + 1}(n) = G_α(n) + 1`.
3. `G_λ(n) = G_{λ[n]}(n)`.

На скінченних ординалах `G_k(n) = k`, а для `G_ω(n) = n`. Навіть на рівні `ε₀` функція `G_{ε₀}(n)` росте лише як помірна експонента. Повільнозростаюча ієрархія наздоганяє швидкозростаючу ієрархію лише на велетенських ординалах, таких як ординал Бахмана — Говарда або `Γ₀`, де виконується співвідношення `G_Ω(n) ≈ F_{ε₀}(n)`.

## Алгоритмічна реалізація: символьні дерева та обчислювальний двигун

Для практичного моделювання та аналізу функцій швидкозростаючої ієрархії в програмному коді необхідно створити структури даних для представлення ординалів у пам'яті комп'ютера та реалізувати символьний редуктор фундаментальних послідовностей.

У мовах програмування C та C++ ординал у формі Кантора моделюється у вигляді рекурсивного абстрактного синтаксичного дерева (AST). Кожен вузол містить тег типу (`ORD_ZERO`, `ORD_FINITE`, `ORD_TERM`), чисельне значення для скінченної частини, а також вказівники на піддерево-показник `exponent` та піддерево-хвіст `tail`.

При обчисленні `F_α(n)` алгоритм виконує наступні кроки:
1. Якщо `α == 0`, повертається `n + 1`.
2. Якщо `α` є скінченним числом `k`, виконується цикл із `n` повторних викликів `F_{k-1}`.
3. Якщо `α` є граничним ординалом `λ`, запускається процедура символьної редукції `λ[n]`, яка повертає нове дерево ординала, після чого виклик повторюється рекурсивно.

Головною інженерною проблемою при реалізації FGH є **вибухове зростання рекурсивного стека** та кількості кроків редукції. Наприклад, спроба обчислити `F_ω(3)` в лоб вимагає розгортання `F₃(3)` через тисячі проміжних дерев, що миттєво викличу переповнення 64-бітових регістрів та стека викликів. Тому чинний двигун повинен підтримувати:
- Лічильник точної кількості здійснених кроків (`total_steps`).
- Захисну стелю максимальної кількості кроків (`max_steps`), після досягнення якої обчислення безпечно переривається.
- Моніторинг пикової глибини стека рекурсії (`max_depth`).

Повний вихідний код реалізації двигуна обчислення FGH мовами C та C++ з використанням розумних вказівників `std::unique_ptr` та суворим контролем ресурсів наведено у вставці [⚙️ Обчислювальний двигун швидкозростаючої ієрархії C/C++](book:algorithms/complexity-computability/fast-growing-hierarchy/proj-fgh-evaluator.md).

Детальний довідник програмного інтерфейсу, таблицю структур даних, типів вузлів та специфікацію кодів помилок викладено у вставці [📋 Специфікація програмного інтерфейсу FGH Engine](book:algorithms/complexity-computability/fast-growing-hierarchy/api-fgh-evaluator.md).
