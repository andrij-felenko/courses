# 🧮 Фундаментальні послідовності та трансфінітні доведення FGH

Математичний апарат швидкозростаючої ієрархії спирається на теорію зліченних трансфінітних ординалів, канонічне представлення Кантора та систему фундаментальних послідовностей, які визначають спосіб наближення до граничних ординалів звичайними натуральними числами.

В основі побудови всієї ієрархії лежить строго узгоджений алгебраїчний механізм: кожному граничному ординалу `λ` зіставляється монотонно зростаюча послідовність менших ординалів `(λ[n])_{n ∈ ℕ}`, чия верхня межа (супремум) дорівнює самісінькому ординалу `λ`:

```
sup { λ[n] | n ∈ ℕ } = λ
```

Вибір цієї послідовності є критичним, оскільки саме він визначає точний темп зростання функції `F_λ(n) = F_{λ[n]}(n)`.

## Форма Кантора та алгебраїчна структура ординалів

Ординальне число (лат. *ordinalis* — порядковий) у сенсі Георга Кантора та Джона фон Неймана описує тип цілком упорядкованої множини. Кожен скінченний ординал тотожно збігається з відповідним натуральним числом `0, 1, 2, ...`. Першим нескінченним ординалом є `ω` (омега), який задає порядковий тип множини всіх натуральних чисел `ℕ`, упорядкованих за величиною.

Для роботи з ординалами у комп'ютерній логіці використовують канонічне подання у **нормальній формі Кантора** (CNF). Будь-який трансфінітний ординал `α < ε₀` можна єдиним чином розкласти у скінченну суму степеней омеги:

```
α = ω^(β₁) · c₁ + ω^(β₂) · c₂ + ... + ω^(βₖ) · cₖ
```

При цьому форма Кантора вимагає виконання трьох строго визначених алгебраїчних умов:
1. Показники степенів впорядковані за суворим спаданням: `β₁ > β₂ > ... > βₖ ≥ 0`.
2. Коефіцієнти `c₁, c₂, ..., cₖ` є додатними натуральними числами (`cᵢ ∈ ℕ, cᵢ > 0`).
3. Кожен показник `βᵢ` у разі потреби також рекурсивно подається у формі Кантора.

Якщо найнижчий показник `βₖ = 0`, ординал `α` є **ординалом-наступником** і виражається як `α = γ + 1` (де `γ` — решта суми). Якщо ж `βₖ > 0`, ординал `α` не має безпосереднього попередника і є **граничним ординалом** (позначається символом `λ`).

## Алгебра ординальних операцій та некомутативність

Арифметика ординалів суттєво відрізняється від алгебри дійсних чи натуральних чисел через некомутативність додавання та множення:

1. **Некомутативність додавання:**
```
1 + ω = sup { 1 + n | n ∈ ℕ } = ω
ω + 1 = { 0, 1, 2, ..., ω } > ω
```
Отже, `1 + ω = ω ≠ ω + 1`. Додавання скінченного числа зліва поглинається нескінченним ординалом `ω`.

2. **Некомутативність множення:**
```
2 · ω = sup { 2 · n | n ∈ ℕ } = ω
ω · 2 = ω + ω > ω
```
Отже, `2 · ω = ω ≠ ω · 2`. Ліве множення на скінченну константу поглинається омегою, тоді як праве множення подвоює ординал.

Канонічна форма Кантора усуває цю неоднозначність, зводячи будь-який складний ординальний вираз до стандартизованого спадного рядка старших доданків.

## Канонічна система фундаментальних послідовностей

Для обчислення швидкозростаючої ієрархії на граничних кроках використовується канонічна система фундаментальних послідовностей Вайнера — Швіхтенберга. Вона визначається наступним набором рекурсивних правил:

1. **Базовий граничний ординал `ω`:**
```
ω[n] = n
```
Для `n = 1, 2, 3, ...` послідовність дає `1, 2, 3, ...`, чия границя дорівнює `ω`.

2. **Степінь з додатною константою `ω^(α + 1)`:**
```
(ω^(α + 1))[n] = ω^α · n
```
Для окремого важливого випадку `α = 0` маємо: `(ω¹)[n] = ω⁰ · n = 1 · n = n`.

3. **Степінь з граничним показником `ω^λ`:**
```
(ω^λ)[n] = ω^(λ[n])
```
У цьому випадку фундаментальна послідовність рекурсивно спускається вглиб показника степеня.

4. **Сума у формі Кантора `α = γ + ω^β` (де `β > 0`):**
```
α[n] = γ + (ω^β)[n]
```
Правило фундаментальної послідовності модифікує виключно найменший (правий) трансфінітний доданок нормальної форми Кантора, залишаючи старші доданки `γ` недоторканими.

5. **Граничний ординал `ε₀` (епсилон-нуль):**
Ординал `ε₀` визначено як найменший розв'язок нерухомої точки тотожності `ω^α = α`. Його фундаментальна послідовність будується як вежа степеней:
```
ε₀[0] = 0
ε₀[n + 1] = ω^(ε₀[n])
```
Звідси отримуємо перші елементи: `ε₀[1] = 1`, `ε₀[2] = ω`, `ε₀[3] = ω^ω`, `ε₀[4] = ω^(ω^ω)` і так далі.

## Покроковий математичний вивід нижніх рівнів FGH

Розглянемо покрокове розгортання та точні алгебраїчні формули для базових рівнів швидкозростаючої ієрархії:

### Рівень F₁(n)
За визначенням `F₁(n)` є `n`-кратною ітерацією базового інкременту `F₀(x) = x + 1`:
```
F₁(n) = F₀^(n)(n)
      = F₀(F₀(...F₀(n)...))    [n разів застосовано F₀]
      = n + 1 + 1 + ... + 1    [додано n одиниць]
      = n + n = 2n
```
Таким чином, рівень `F₁` описує лінійну функцію подвоєння аргументу.

### Рівень F₂(n)
За аналогією `F₂(n)` є `n`-кратною ітерацією функції `F₁(x) = 2x`:
```
F₂(n) = F₁^(n)(n)
      = F₁(F₁( ... F₁(n) ... ))  [n разів застосовано F₁]
      = 2 · 2 · ... · 2 · n    [n множень на 2]
      = n · 2ⁿ
```
Рівень `F₂` виражає експоненціальний ріст аргументу.

### Рівень F₃(n) та аналіз гіперекспоненціального росту
Для обчислення `F₃(n)` виконується `n`-кратна ітерація функції `F₂`:
```
F₃(1) = F₂¹(1) = F₂(1) = 1 · 2¹ = 2
F₃(2) = F₂²(2) = F₂(F₂(2)) = F₂(2 · 2²) = F₂(8) = 8 · 2⁸ = 2048
F₃(3) = F₂³(3) = F₂(F₂(F₂(3)))
```
Розпишемо проміжні обчислювальні кроки для `F₃(3)`:
```
F₂(3) = 3 · 2³ = 24
F₂(24) = 24 · 2²⁴ = 24 · 16777216 = 402653184
F₃(3) = F₂(402653184) = 402653184 · 2⁴⁰²⁶⁵³¹⁸⁴
```
Значення `F₃(3)` виражається числом з 120 мільйонами десяткових знаків (`~10¹21175671`), що демонструє неподоланний розрив між класичними алгебраїчними функціями та гіперекспоненціальними рівнями FGH.

## Теорема про строго зростаючий характер та монотонність FGH

Коректність використання швидкозростаючої ієрархії як шкали складності гарантується трьома фундаментальними лемами про монотонність та мажорування:

### Лема 1 (Сувора монотонність аргументу)
Для будь-якого фіксованого ординала `α` та натурального числа `n ≥ 1` виконується сувора нерівність:
```
F_α(n) < F_α(n + 1)
```

### Доведення Леми 1 за індукцією:
- **Базовий крок (`α = 0`):** `F₀(n) = n + 1 < n + 2 = F₀(n + 1)`. Твердження істинне.
- **Індукційний крок для `α + 1`:** Припустимо, що `F_α(m) < F_α(m + 1)` для всіх `m`. Розглянемо `F_{α+1}(n) = F_α^(n)(n)`. За індукційним припущенням застосування `F_α` є монотонним оператором. Отже, ітерована суперпозиція збереже монотонність: `F_α^(n)(n) < F_α^(n+1)(n + 1) = F_{α+1}(n + 1)`.
- **Граничний крок (`α = λ`):** `F_λ(n) = F_{λ[n]}(n) < F_{λ[n+1]}(n + 1) = F_λ(n + 1)` за рахунок монотонності фундаментальної послідовності `λ[n] < λ[n+1]`.

### Лема 2 (Мажорування ітерацій за індексом ординала)
Для будь-яких ординалів `α < β` та натуральних чисел `n ≥ 2` виконується нерівність:
```
F_α(n) < F_β(n)
```
Це означає, що вищий ординальний індекс `β` завжди гарантує суворо більшу швидкість зростання функції на достатньо великих аргументах.

### Мажорування примітивно-рекурсивного класу функцією F_ω
За визначенням `F_ω(n) = F_{ω[n]}(n) = F_n(n)`.
Оскільки за лемою 2 для кожного фіксованого скінченного `k` при `n > k` виконується `F_k(n) < F_n(n) = F_ω(n)`, функція `F_ω` росте швидше за будь-яку конкретну примітивно-рекурсивну функцію `F_k`.

Прямий зв'язок із класичною функцією Аккермана `A(m, n)` встановлюється співвідношенням `F_ω(n) > A(n, n)`. Це доводить, що діагоналізація `F_ω` слугує нижньою межею для загальнорекурсивних функцій вищого порядку.

## Зв'язок із ієрархією Гарді H_α

Математичне співвідношення між швидкозростаючою ієрархією Вайнера — Швіхтенберга та ієрархією Гарді виражається теоремою про тотожність індексів:

```
F_α(n) = H_{ω^α}(n)
```

Це означає, що один рекурсивний крок ітерації у FGH відповідає піднесенню омеги до степеня у шкалі Гарді. Наприклад, операція тетрації `F₃(n)` виражається через `H_{ω³}(n)`, а функція Аккермана `F_ω(n)` дорівнює `H_{ω^ω}(n)`. Дане співвідношення дозволяє взаємооднозначно перераховувати оцінки складності між різними формальними системами доведень.
