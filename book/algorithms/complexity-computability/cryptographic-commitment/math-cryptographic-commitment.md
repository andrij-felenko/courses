# 🧮 Математичні доведення стійкості зобов'язань Педерсена та KZG

Схеми криптографічного зобов'язання оцінюються за двома фундаментальними критеріями стійкості: **приховуванням** (Hiding) та **зв'язуванням** (Binding). Нижче наведено строгі алгебраїчні доведення цих властивостей для схеми Педерсена, поліноміальної схеми KZG (Kate-Zaverucha-Goldberg) та векторної схеми на основі дерев Меркла.

## 1. Схема Педерсена у циклічній групі

Нехай `G` — циклічна група простого порядку `q` з генератором `g`. Нехай `h = g^x ∈ G` — другий генератор, де значення `x = log_g(h)` є невідомим для доводжувача (значення `x` згенеровано під час бекдоно-безпечної процедури або обрано випадково).

Зобов'язання для повідомлення `m ∈ Z_q` з випадковим елементом (blinding factor) `r ∈ Z_q` обчислюється як:

```
c = g^m · h^r mod p
```

### 1.1 Доведення безумовного (інформаційно-теоретичного) приховування

**Теорема 1.** *Схема Педерсена володіє досконалим (інформаційно-теоретичним) приховуванням. Для будь-якої пари повідомлень m₁, m₂ ∈ Z_q розподіли відповідних зобов'язань c₁ та c₂ є тотожно рівномірними на групі G.*

*Доведення.*
Розглянемо довільний елемент групи `y ∈ G` та зафіксоване повідомлення `m ∈ Z_q`.
Рівняння зобов'язання має вигляд:

```
c = g^m · h^r = y
```

Перенесемо `g^m` у праву частину рівняння, помноживши обидві частини на `(g^m)⁻¹`:

```
h^r = y · g⁻ᵐ
```

Оскільки `h` є генератором циклічної групи `G` порядку `q`, логарифмування за основою `h` дає:

```
r = log_h(y · g⁻ᵐ) mod q
```

Оскільки `y` зафіксовано, а `g, h, m` є константами, існує **єдиний** елемент `r ∈ Z_q`, який задовольняє це рівняння.
Оскільки випадковий фактор `r` обирається доводжувачем **абсолютно рівномірно** з множини `Z_q` (з ймовірністю `1 / q`), значення `c = g^m · h^r` набуває будь-якого значення `y ∈ G` з точною ймовірністю:

```
Pr[c = y | m] = Pr[r = log_h(y · g⁻ᵐ)] = 1 / q
```

Ця ймовірність є сталою `1 / q` і повністю **не залежить від значення повідомлення m**. Отже, розподіли імовірностей `P(c | m₁)` та `P(c | m₂)` є ідентичними. Супротивник з нескінченною обчислювальною потужністю отримує 0 біт інформації про `m`. (Q.E.D.)

### 1.2 Доведення обчислювального зв'язування

**Теорема 2.** *Якщо доводжувач здатний знайти дві різні пари (m₁, r₁) та (m₂, r₂) такі, що m₁ ≠ m₂ і Commit(m₁, r₁) = Commit(m₂, r₂), то він може обчислити дискретний логарифм x = log_g(h) за поліноміальний час.*

*Доведення.*
Припустимо, доводжувач знайшов колізію:

```
g^m₁ · h^r₁ = g^m₂ · h^r₂ mod p
```

Згрупуємо степені `g` в лівій частині, а степені `h` — у правій:

```
g^(m₁ - m₂) = h^(r₂ - r₁) mod p
```

Оскільки `m₁ ≠ m₂ mod q`, різниця `Δm = (m₁ - m₂) mod q` не дорівнює нулю (`Δm ≠ 0 mod q`). Оскільки `q` — просте число, для `Δm` існує єдиний мультиплікативний обернений елемент `(Δm)⁻¹ mod q`.

Піднесемо обидві частини рівняння до степеня `(Δm)⁻¹ mod q`:

```
g = h^((r₂ - r₁) · (m₁ - m₂)⁻¹) mod p
```

Згадаємо, що за означенням `h = g^x`, звідки `g = h^(1/x)`. Отже:

```
1 / x = (r₂ - r₁) · (m₁ - m₂)⁻¹ mod q
```

Звідси невідомий дискретний логарифм `x = log_g(h)` обчислюється як:

```
x = (m₁ - m₂) · (r₂ - r₁)⁻¹ mod q
```

Отже, якщо доводжувач здатний порушити властивість зв'язування схеми Педерсена, він автоматично розв'язує складну задачу дискретного логарифмування в `G`. За припущення важкості дискретного логарифма (Discrete Logarithm Assumption), ймовірність успіху будь-якого поліноміального алгоритму є нехтовно малою. (Q.E.D.)

## 2. Поліноміальні зобов'язання KZG (Kate-Zaverucha-Goldberg)

Нехай `(G₁, G₂, G_T, e, p)` — дуальна парна структура з білінійним спарюванням `e: G₁ × G₂ → G_T`.
Нехай `τ ∈ Z_p` — секретна точка оцінювання, вилучена під час Trusted Setup. Публічні параметри системи мають вигляд:

```
SRS = ([1]₁, [τ]₁, [τ²]₁, ..., [τᵈ]₁, [1]₂, [τ]₂)
```

де `[k]₁ = k · g₁ ∈ G₁` та `[k]₂ = k · g₂ ∈ G₂`.

Зобов'язання для полінома `f(X) = ∑_{i=0}^d a_i X^i` обчислюється як:

```
C = [f(τ)]₁ = ∑_{i=0}^d a_i · [τⁱ]₁ ∈ G₁
```

### 2.1 Доказовий вихід та верифікація оцінки полінома

Для підтвердження того, що `f(z) = y`, доводжувач будує частковий поліном:

```
q(X) = (f(X) - y) / (X - z)
```

Оскільки `f(z) = y`, число `z` є коренем полінома `f(X) - y`, а отже ділення виконується без остачі, і `q(X)` є коректним поліномом ступеня `d - 1`.

Доказ оцінки являє собою елемент `π = [q(τ)]₁ ∈ G₁`.

Верифікатор перевіряє рівняння білінійного спарювання:

```
e(C - [y]₁, [1]₂) =?= e(π, [τ - z]₂)
```

### 2.2 Алгебраїчна коректність верифікації KZG

Розкриємо ліву частину спарювання:

```
e(C - [y]₁, [1]₂)
= e([f(τ) - y]₁, [1]₂)
= e((f(τ) - y) · g₁, g₂)
= (f(τ) - y) · e(g₁, g₂)
```

Розкриємо праву частину спарювання:

```
e(π, [τ - z]₂)
= e([q(τ)]₁, (τ - z) · g₂)
= e(q(τ) · g₁, (τ - z) · g₂)
= q(τ) · (τ - z) · e(g₁, g₂)
```

Оскільки за означенням `q(X) · (X - z) = f(X) - y`, підстановка `X = τ` дає рівність `q(τ) · (τ - z) = f(τ) - y`.
Отже, ліва частина дорівнює правій частині:

```
(f(τ) - y) · e(g₁, g₂) = q(τ) · (τ - z) · e(g₁, g₂)
```

Це доводить абсолютну алгебраїчну коректність верифікації оцінки KZG за один виклик білінійного спарювання. (Q.E.D.)

### 2.3 Доведення обчислювального зв'язування KZG припущенням q-SBDH

**Теорема 3.** *За припущення важкості сильної задачи Строгого Дискретного Логарифма Дьєфі-Геллмана (q-Strong Bilinear Diffie-Hellman Assumption / q-SBDH), жоден поліноміальний доводжувач не може надати два різних значення y₁ ≠ y₂ такі, що обчислення e(C - [y₁]₁, [1]₂) = e(π₁, [τ - z]₂) та e(C - [y₂]₁, [1]₂) = e(π₂, [τ - z]₂) одночасно проходять верифікацію.*

*Доведення.*
Припустимо, доводжувач знайшов два підроблених докази `π₁` та `π₂` для різних значень `y₁ ≠ y₂` у тій самій точці `z`.
Тоді маємо два рівняння спарювання:

```
e(C - [y₁]₁, [1]₂) = e(π₁, [τ - z]₂)
e(C - [y₂]₁, [1]₂) = e(π₂, [τ - z]₂)
```

Поділимо перше рівняння на друге у групі `G_T`:

```
e([y₂ - y₁]₁, [1]₂) = e(π₁ - π₂, [τ - z]₂)
```

Скориставшись білінійністю спарювання, перенесемо скаляр `(y₂ - y₁)` у праву частину:

```
e((y₂ - y₁) · g₁, g₂) = e((π₁ - π₂), (τ - z) · g₂)
```

Оскільки `y₁ ≠ y₂`, значення `(y₂ - y₁)` має обернений елемент `(y₂ - y₁)⁻¹ mod p`. Помноживши вираз у експоненті, отримаємо:

```
e(g₁, g₂) = e((y₂ - y₁)⁻¹ · (π₁ - π₂), (τ - z) · g₂)
```

Звідси випливає, що доводжувач обчислив елемент `γ = (y₂ - y₁)⁻¹ · (π₁ - π₂) ∈ G₁` такий, що:

```
e(γ, (τ - z) · g₂) = e(g₁, g₂)
```

Це означає, що `γ = (1 / (τ - z)) · g₁`.
Здатність обчислити елемент `[1 / (τ - z)]₁` на основі `SRS = ([τⁱ]₁)` без знання `τ` еквівалентна розв'язанню задачі q-SBDH, що вважається обчислювально неможливим у криптографічних групах з білінійними спарюваннями. (Q.E.D.)

## 3. Формальний аналіз Vector Commitment на основі Меркла

Нехай `H: {0,1}* → {0,1}^k` — криптографічна хеш-функція, стійка до пошуку колізій.

Вектор `V = (v₁, v₂, ..., v_N)` зафіксовано в корінці дерева Меркла `Root = Commitment(V)`.

### 3.1 Доведення обчислювального зв'язування для елемента вектора

**Теорема 4.** *Якщо доводжувач здатний надати для позиції i два різних елементи v_i ≠ v'_i з відповідними шляхами верифікації Path_i та Path'_i, що проходять перевірку відносно одного кореня Root, він може знайти колізію для хеш-функції H за поліноміальний час.*

*Доведення.*
Нехай `Path_i = (h₁, h₂, ..., h_d)` — послідовність сусідніх хешів на шляху від листа до кореня довжини `d = log₂ N`.
Для значення `v_i` обчислюється ланцюжок хешів:

```
H₀ = H(v_i)
H₁ = H(H₀ || h₁)
...
H_d = Root
```

Для альтернативного значення `v'_i` обчислюється альтернативний ланцюжок:

```
H'₀ = H(v'_i)
H'₁ = H(H'₀ || h'₁)
...
H'_d = Root
```

Оскільки `v_i ≠ v'_i`, їхні первинні хеші відрізняються: `H₀ = H(v_i) ≠ H(v'_i) = H'₀`.
Проте фінальні хеші збігаються: `H_d = H'_d = Root`.

Розглянемо найменший індекс `k ∈ {1, ..., d}` такий, що `H_k = H'_k`, але вхідні пари перед обчисленням цього хешу відрізнялися (`(H_{k-1} || h_k) ≠ (H'_{k-1} || h'_k)`).
Оскільки виходи хеш-функції збігаються `H(A) = H(B)` для двох різних входів `A ≠ B`, пара `(A, B)` утворює явну колізію `H`. Отже, стійкість зв'язування векторних зобов'язань Меркла випливає зі стійкості `H` до колізій. (Q.E.D.)
