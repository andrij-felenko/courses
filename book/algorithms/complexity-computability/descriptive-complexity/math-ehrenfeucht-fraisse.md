# 🧮 Математичний апарат ігор Еренфойхта — Фрессе та доведення невиражуваності

Визначення меж виражальної сили логічних мов на скінченних математичних структурах вимагає строгих комбінаторних методологій, оскільки класичні інструменти теорії моделей (такі як теорема компактності Гьоделя) на скінченних множинах не працюють. Теоретичним фундаментом для доведення неможливості вираження властивостей у логіці першого порядку (First-Order Logic, FO) є ігри Еренфойхта — Фрессе (Ehrenfeucht-Fraïssé games). Ця методологія зводить складний логічний аналіз формул до комбінаторного аналізу виграшних стратегій у кооперованій грі двох гравців на графі або реляційній структурі.

## 1. Реляційні структури, сигнатура та кванторна глибина

Розглянемо формальну сигнатуру `σ = (R₁ᵃ¹, R₂ᵃ², ..., Rₘᵃᵐ)`, яка складається з предикатних символів `Rᵢ` відповідної арності `aᵢ`. **Скінченна реляційна структура** `A = (Uᴬ, R₁ᴬ, ..., Rₘᴬ)` описується носієм (доменом) `Uᴬ` — скінченною множиною елементів, та конкретними інтерпретаціями відношень `Rᵢᴬ ⊆ (Uᴬ)ᵃⁱ`.

Складність логічної формули `φ` у логіці FO описується її **кванторною глибиною (quantifier depth)** `qr(φ)`, яка визначає максимальну кількість вкладених кванторів `∀` та `∃` у синтаксичному дереві формули.

Формально кванторна глибина `qr(φ)` обчислюється рекурсивно за такими правилами:

```
qr(P(t₁, ..., tₐ)) = 0                       [атомарна формула / предикат]
qr(t₁ = t₂)          = 0                       [атомарна рівність]
qr(¬φ)               = qr(φ)                   [заперечення]
qr(φ₁ ∧ φ₂)          = max(qr(φ₁), qr(φ₂))     [кон'юнкція]
qr(φ₁ ∨ φ₂)          = max(qr(φ₁), qr(φ₂))     [диз'юнкція]
qr(∃x φ)             = qr(φ) + 1               [екзистенційний квантор]
qr(∀x φ)             = qr(φ) + 1               [універсальний квантор]
```

Дві структури `A` та `B` однієї сигнатури `σ` називаються **елементарно еквівалентними до глибини `k`** (позначається `A ≡ₖ B`), якщо для будь-якої формули `φ` логіки першого порядку з кванторною глибиною `qr(φ) ≤ k` виконується еквівалентність:

```
A ⊨ φ   ⇔   B ⊨ φ
```

Якщо для будь-якого `k ≥ 1` можна побудувати дві структури `Aₖ` та `Bₖ` такі, що `Aₖ` має властивість `P`, `Bₖ` не має властивості `P`, але при цьому `Aₖ ≡ₖ Bₖ`, то властивість `P` **принципово невиражувана** в логіці першого порядку.

## 2. Формалізація k-раундової гри Еренфойхта — Фрессе

Гра Еренфойхта — Фрессе `Gₖ(A, B)` проходить на двох скінченних структурах `A` та `B` протягом `k` раундів між двома гравцями: **Spoiler (Руйнівник)** та **Duplicator (Захисник)**.

У кожного гравця є набір із `k` пар фішок `(a₁, b₁), (a₂, b₂), ..., (aₖ, bₖ)`.

У кожному раунді `i` (від `1` до `k`) гра проходить за такими правилами:

1. **Крок Spoiler'а:** Spoiler обирає один із двох доменів (`Uᴬ` або `Uᵇ`), вибирає в ньому довільний елемент (наприклад, `aᵢ ∈ Uᴬ` або `bᵢ ∈ Uᵇ`) та ставить на нього відповідну фішку з номером `i`.
2. **Крок Duplicator'а:** Duplicator мусить відповісти вибором елемента у протилежному домені (відповідно `bᵢ ∈ Uᵇ` або `aᵢ ∈ Uᴬ`) та поставити на нього парну фішку з номером `i`.

Після завершення `k` раундів сформовано дві послідовності обраних елементів: `(a₁, a₂, ..., aₖ) ∈ (Uᴬ)ᵏ` та `(b₁, b₂, ..., bₖ) ∈ (Uᵇ)ᵏ`.

> **Умова виграшу Duplicator'а.** Duplicator виграє в грі `Gₖ(A, B)`, якщо відображення `f: aᵢ ↦ bᵢ` для всіх `i = 1, ..., k` є **частковим ізоморфізмом** між структурами `A` та `B`.

Формально відображення `f` є частковим ізоморфізмом, якщо для всіх `i, j ∈ {1, ..., k}`:

1. **Збереження рівності:** `aᵢ = aⱼ  ⇔  bᵢ = bⱼ`.
2. **Збереження відношень:** Для кожного предикатного символу `R` арності `m` та довільного набору індексів `(i₁, i₂, ..., iₘ)` виконується:

```
(aᵢ₁, aᵢ₂, ..., aᵢₘ) ∈ Rᴬ   ⇔   (bᵢ₁, bᵢ₂, ..., bᵢₘ) ∈ Rᵇ
```

Якщо після `k` раундів відображення `f` порушує хоча б один предикат або умову рівності, виграє Spoiler.

## 3. Теорема Еренфойхта — Фрессе

Фундаментальна теорема пов'язує існування виграшної стратегії в комбінаторній грі із логічною еквівалентністю структур.

> **Теорема Еренфойхта — Фрессе.** Для довільних двох скінченних реляційних структур `A` та `B` сигнатури `σ` та будь-якого цілого `k ≥ 1` наступні твердження еквівалентні:
> 1. Structures `A` and `B` are elementary equivalent up to quantifier depth `k` (`A ≡ₖ B`).
> 2. Duplicator має виграшну стратегію в `k`-раундовій грі Еренфойхта — Фрессе `Gₖ(A, B)`.

### Схема доведення (в один бік):
Якщо існує формула `φ` з `qr(φ) = k` така, що `A ⊨ φ`, але `B ⊭ φ`, то Spoiler може використати синтаксичне дерево формули `φ` як інструкцію для своїх ходів. Квантор `∃x` вказує Spoiler'у зробити хід у тій структурі, де елемент існує, а `∀x` вимагає відповісти на універсальний вибір. Наприкінці `k` раундів обрана послідовність елементів зробить атомарну підформулу істинною в `A` та хибною в `B`, що порушить частковий ізоморфізм.

Навпаки, якщо Duplicator має виграшну стратегію для всіх ходів Spoiler'а, жодна формула глибини `k` не спроможна розрізнити `A` та `B`.

## 4. Строге доведення невиражуваності зв'язності графів у FO

Застосуємо апарат ігор Еренфойхта — Фрессе, щоб довести, що властивість **зв'язності графа (Graph Connectivity)** принципово не виражається у логіці першого порядку.

### Формулювання проблеми
Сигнатура графа складається з одного бінарного предиката ребра `σ = (E²)`. Властивість зв'язності `CONNECTIVITY` визначається так: граф `G = (V, E)` належить мові, якщо між будь-якими двома вершинами `u, v ∈ V` існує шлях з ребер `E`.

### Побудова контрструктур Aₖ та Bₖ
Для фіксованого значення кванторної глибини `k ≥ 1` оберемо число `N = 2ᵏ⁺¹`.

Задамо дві реляційні структури:
- **Граф Aₖ:** Один простий цикл довжиною `2N` вершин, позначений `C₂ₙ`. Граф `Aₖ` є строго **зв'язаним**.
- **Граф Bₖ:** Незв'язане об'єднання двох неперетинних простих циклів довжиною `N` вершин у кожному (`Cₙ ∪ Cₙ`). Граф `Bₖ` є строго **незв'язаним**.

```
Aₖ (Цикл C₂ₙ):     v₁ ── v₂ ── v₃ ── ... ── v₂ₙ ── (повернення до v₁)   [Зв'язаний]

Bₖ (Два Cₙ):       u₁ ── u₂ ── ... ── u♙ ── (назад до u₁)              [Незв'язаний]
                   w₁ ── w₂ ── ... ── w♙ ── (назад до w₁)
```

### Виграшна стратегія Duplicator'а
Для доведення того, що логіка FO не може розрізнити `Aₖ` та `Bₖ`, достатньо показати, що Duplicator має виграшну стратегію в грі `Gₖ(Aₖ, Bₖ)`.

Стратегія Duplicator'а спирається на збереження відстаней у графах за модулем `2ᵏ⁻ⁱ⁺¹` на раунді `i`.

Нехай у раунді `i` Spoiler обирає вершину `x` в одного з графів. Окіл цієї вершини виглядає як локальний лінійний ланцюг. Оскільки загальна довжина циклів `N = 2ᵏ⁺¹` перевищує `2ᵏ`, окіл радіуса `2ᵏ⁻ⁱ` навколо обраної вершини не замикається у цикл протягом `k` раундів.

Формально визначимо відстань `d(u, v)` як довжину найкоротшого шляху у графі між вершинами `u` та `v`.

Duplicator обирає відповідну вершину `y` у протилежному графі так, щоб виконувалися рівності відстаней між усіма раніше обраними фішками `(aⱼ, bⱼ)` для `j < i`:

```
d_A(aᵢ, aⱼ) = d_B(bᵢ, bⱼ)       [якщо d_A(aᵢ, aⱼ) ≤ 2ᵏ⁻ⁱ]
```

Якщо Spoiler обирає вершину на далекій відстані від усіх раніше виставлених фішок (`d > 2ᵏ⁻ⁱ`), Duplicator відповідає вибором аналогічно «далекої» вершини у протилежному графі (наприклад, у другому циклі графа `Bₖ`).

Оскільки на кожному кроці відстань до межі видимості скорочується вдвічі, за `k` раундів Spoiler не зможе обійти весь цикл довжиною `2ᵏ⁺¹` і виявити розрив між двома циклами у `Bₖ`.

### Висновок
Після `k` раундів відображення `aᵢ ↦ bᵢ` зберігає рівність та предикат ребер `E(aᵢ, aⱼ) ⇔ E(bᵢ, bⱼ)`.

Отже, Duplicator виграє у грі `Gₖ(Aₖ, Bₖ)`, що означає:

```
Aₖ ≡ₖ Bₖ
```

Оскільки `Aₖ ∈ CONNECTIVITY`, а `Bₖ ∉ CONNECTIVITY`, жодна формула логіки першого порядку з кванторною глибиною `qr(φ) ≤ k` не може виразити зв'язність графа.

Оскільки це міркування справедливе для довільного `k ≥ 1`, мова `CONNECTIVITY` **не виражається у логіці першого порядку FO**.

## 5. Локальність Гайфмана, лема Ханфа та обчислювальний зміст

Альтернативним алгебраїчним інструментом доведення невиражуваності є **Теорема локальності Гайфмана (Gaifman's Locality Theorem)** та **Лема Ханфа (Hanf's Lemma)**.

Для реляційної структури `A` будується її **граф Гайфмана** `G(A)`, вершинами якого є елементи носія `Uᴬ`, а ребро існує між `u` та `v`, якщо вони одночасно входять до одного кортежу якогось відношення `Rᵢᴬ`.

> **Теорема Гайфмана.** Будь-яка формула `φ(x)` логіки першого порядку є логічно еквівалентною булевій комбінації **локальних формул**. Локальна формула здатна аналізувати лише сферу (окіл) радіуса `r ≤ 2ᵏ` навколо своїх вільних змінних у графі Гайфмана.

Лема Ханфа доповнює Гайфмана: якщо дві структури `A` та `B` мають однакову кількість ізоморфних локальних сфер радіуса `r` для кожного ізоморфного типу сфери, то `A ≡ₖ B`.

Оскільки обчислення глобальних властивостей (таких як транзитивне замикання, парність елементів чи 2-розфарбовуваність) вимагає аналізу графів необмеженого радіуса `O(n)`, локальність Гайфмана ставить безумовний бар'єр виражальності логіки FO. Для подолання цього бар'єра і вираження складніших класів складності (L, NL, P) виникає математична необхідність у введенні операторів транзитивного замикання та нерухомих точок.
