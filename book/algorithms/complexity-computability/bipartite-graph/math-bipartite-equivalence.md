# 🧮 Математичні доведення теорем двочастковості, Кеніга, Голла та тотожностей Галлаї

Ця вставка містить строгі математичні доведення фундаментальних теорем комбінаторики графів: критерію відсутності непарних циклів, теореми Денеша Кеніга про двоїстість паросполучень і покриттів, теореми Філіпа Голла про умову існування повного паросполучення, її дефектної модифікації, а також тотожностей Галлаї.

## 1. Теорема про критерій двочастковості (Кеніг, 1916)

**Твердження.** Неорієнтований граф `G = (V, E)` є двочастковим (тобто його множину вершин можна розбити на дві незалежні множини `U` та `V`, такі що `V = U ∪ V` та `U ∩ V = ∅`) тоді й лише тоді, коли `G` не містить жодного циклу непарної довжини.

### 1.1. Доведення у прямому напрямку (⇒)

Припустимо, що граф `G = (U ∪ V, E)` є двочастковим. Розглянемо довільний цикл `C` у графі `G`, що складається з послідовності вершин `v₀, v₁, v₂, ..., vₖ, v₀`.

Без втрати загальності нехай `v₀ ∈ U`. Оскільки всі ребра графа з'єднують лише вершини з протилежних часток, належність вершин до часток змінюється на кожному кроці:

```
v₀ ∈ U
v₁ ∈ V      [бо (v₀, v₁) ∈ E]
v₂ ∈ U      [бо (v₁, v₂) ∈ E]
v₃ ∈ V      [бо (v₂, v₃) ∈ E]
...
vᵢ ∈ U      якщо i — парне
vᵢ ∈ V      якщо i — непарне
```

Оскільки цикл замикається ребром `(vₖ, v₀)` і `v₀ ∈ U`, вершина `vₖ` обов'язково повинна належати до частки `V`. Отже, індекс `k` має бути непарним числом.

Кількість ребер у циклі `C` дорівнює `k + 1`. Оскільки `k` — непарне, `k + 1` є парним числом. Отже, будь-який цикл у двочастковому графі має парну довжину. Пряме твердження доведено.

### 1.2. Доведення в оберненому напрямку (⇐)

Припустимо, що граф `G = (V, E)` не містить жодного непарного циклу. Доведемо, що `G` є двочастковим, побудувавши явне розбиття на частки `U` та `V`.

Без втрати загальності вважаємо граф `G` зв'язним (якщо граф незв'язний, розбиття будується незалежно для кожної компоненти зв'язності).

1. Фіксуємо довільну початкову вершину `r ∈ V`.
2. Для кожної вершини `x ∈ V` визначимо `d(r, x)` як довжину найкоротшого шляху від `r` до `x` у графі `G`.
3. Розбіємо множину вершин `V` на дві підмножини `U` та `V` за парністю відстані від `r`:

```
U = { x ∈ V | d(r, x) є парним }
V = { y ∈ V | d(r, y) є непарним }
```

Очевидно, що `U ∪ V = V` та `U ∩ V = ∅`. Залишилося довести, що жодне ребро не з'єднує дві вершини всередині однієї частки.

Припустимо від супротивного, що існує ребро `(x, y) ∈ E`, таке що обидві вершини належать до однієї частки (наприклад, `x, y ∈ U`). Це означає, що відстані `d(r, x)` та `d(r, y)` мають однакову парність.

Нехай `Pₓ` — найкоротший шлях від `r` до `x` довжини `d(r, x)`, а `Pᵧ` — найкоротший шлях від `r` до `y` довжини `d(r, y)`. Нехай `z` — остання спільна вершина шляхів `Pₓ` та `Pᵧ` при русі від `r`.

Ділянки шляхів від `r` до `z` є найкоротшими шляхами до `z`, тому їхні довжини однакові: `d(r, z)`. Тоді довжини залишкових шляхів від `z` до `x` (позначаємо `Lₓ`) та від `z` до `y` (позначаємо `Lᵧ`) дорівнюють:

```
Lₓ = d(r, x) - d(r, z)
Lᵧ = d(r, y) - d(r, z)
```

Оскільки `d(r, x)` та `d(r, y)` мають однакову парність, значення `Lₓ` та `Lᵧ` також мають однакову парність (їхня сума `Lₓ + Lᵧ` є парним числом).

Тепер розглянемо цикл `C`, утворений шляхом від `z` до `x` у вздовж `Pₓ`, ребром `(x, y)` та шляхом від `y` до `z` у зворотному напрямку вздовж `Pᵧ`. Довжина цього циклу `|C|` дорівнює:

```
|C| = Lₓ + 1 + Lᵧ        [підрахунок ребер у циклі C]
    = (Lₓ + Lᵧ) + 1      [перегрупування доданків]
```

Оскільки `Lₓ + Lᵧ` є парним, `|C| = (парне) + 1 = непарне число`. Ми отримали непарний цикл `C` у графі `G`, що суперечить умові.

Отже, припущення хибне, і жодне ребро не з'єднує вершини однієї частки. Граф `G` є двочастковим. Теорему повністю доведено. ∎

## 2. Теорема Кеніга про паросполучення та покриття (Кеніг, 1931)

**Твердження.** У довільному двочастковому графі `G = (U ∪ V, E)` розмір максимального паросполучення `ν(G) = |M*|` дорівнює розміру мінімального вершинного покриття `τ(G) = |C*|`:

```
ν(G) = τ(G)
```

### 2.1. Доведення нерівності ν(G) ≤ τ(G)

Нехай `M` — довільне паросполучення у графі `G`, а `C` — довільне вершинне покриття.

За визначенням паросполучення, жодні два ребра з `M` не мають спільних вершин. З іншого боку, за визначенням вершинного покриття, для кожного ребра `e = (u, v) ∈ M` принаймні одна з його кінцевих вершин `u` або `v` повинна належати до `C`.

Оскільки всі ребра з `M` є вершино-диз'юнктними, покриття `C` повинно містити принаймні одну окрему вершину для кожного ребра з `M`. Звідси випливає нерівність `|M| ≤ |C|` для довільних паросполучень і покриттів, а отже і для оптимальних:

```
ν(G) ≤ τ(G)
```

### 2.2. Побудова покриття розміру |M| та доведення рівності

Доведемо, що для максимального паросполучення `M` можна побудувати вершинне покриття `C` розміру `|C| = |M|`.

Нехай `M` — максимальне паросполучення у двочастковому графі `G = (U ∪ V, E)`. Позначимо через `U₀ ⊆ U` множину вершин частки `U`, які є вільними (не покритими паросполученням `M`).

Визначимо множину `Z ⊆ V` як множину всіх вершин графа `G`, до яких можна дістатися з вершин `U₀` за допомогою `M`-чередувальних шляхів (тобто шляхів, у яких ребра по черзі не належать і належать до `M`).

Розбіємо `Z` на дві частини у відповідних частках: `Z_U = Z ∩ U` та `Z_V = Z ∩ V`.

Побудуємо множину вершин `C` за наступним правилом:

```
C = (U \ Z_U) ∪ Z_V
```

#### Крок 1: C є вершинним покриттям

Припустимо від супротивного, що існує ребро `(u, v) ∈ E`, не покрите `C`. Це означає, що `u ∉ C` та `v ∉ C`.

За визначенням `C`, з `u ∉ C` випливає `u ∈ Z_U`, тобто вершина `u` досяжна з `U₀` чередувальним шляхом. З `v ∉ C` випливає `v ∉ Z_V`.

Якщо ребро `(u, v) ∉ M`, ми можемо продовжити чередувальний шлях від `u` до `v` цим ребром, тож `v ∈ Z_V`, суперечність. Якщо ж `(u, v) ∈ M`, то оскільки `u ∈ Z_U`, ребро `(u, v)` входить до `M` і переходить у `Z_V`, тобто `v ∈ Z_V`, суперечність.

Отже, всі ребра покриті множиною `C`.

#### Крок 2: |C| = |M|

Кожне ребро `(u, v) ∈ M` має ровно одну вершину в `C`:
- Якщо `u ∈ Z_U`, то `v ∈ Z_V`. Тоді `u ∉ (U \ Z_U)` і `v ∈ Z_V`, отже в `C` є лише `v`.
- Якщо `u ∉ Z_U`, то `v ∉ Z_V`. Тоді `u ∈ (U \ Z_U)` і `v ∉ Z_V`, отже в `C` є лише `u`.

Вільні вершини `U₀` входять до `Z_U`, тому вони відсутні в `U \ Z_U`. А вершини з `V`, досяжні з `U₀`, не можуть бути вільними (інакше існував би збільшуючий шлях, що суперечить максимальності `M`).

Таким чином, кожна вершина з `C` відповідає унікальному ребру з `M`, звідки `|C| = |M|`. Оскільки `|M| = ν(G)` та `|C| ≥ τ(G)`, маємо `ν(G) = |M| = |C| ≥ τ(G)`. Поєднуючи з нерівністю `ν(G) ≤ τ(G)`, отримуємо `ν(G) = τ(G)`. Теорему Кеніга доведено. ∎

## 3. Теорема Галлаї про фундаментальні тотожності (Gallai, 1959)

**Твердження.** Для будь-якого графа `G = (V, E)` без ізольованих вершин сума розміру максимальної незалежної множини `α(G)` та розміру мінімального вершинного покриття `τ(G)` дорівнює загальній кількості вершин `|V|`:

```
α(G) + τ(G) = |V|
```

### Доведення

Нехай `S ⊆ V` — довільна підмножина вершин графа `G`.

Підмножина `S` є незалежною множиною (жодне ребро не з'єднує вершини з `S`) тоді й лише тоді, коли її доповнення `V \ S` торкається кожного ребра графа `E` (тобто `V \ S` є вершинним покриттям).

Звідси випливає взаємно однозначна відповідність між незалежними множинами та вершинними покриттями. Для максимальної незалежної множини `S*` розміром `α(G)` її доповнення `V \ S*` є мінімальним вершинним покриттям розміром `τ(G) = |V| - α(G)`. Переносячи `α(G)` у ліву частину, отримуємо тотожність: `α(G) + τ(G) = |V|`.

Завдяки теоремі Кеніга `τ(G) = ν(G)` у двочасткових графах, маємо прямий наслідок для двочасткових графів:

```
α(G) + ν(G) = |V|
```

Це дозволяє знаходити розмір максимальної незалежної множини двочасткового графа просто як `|V| - ν(G)`.

## 4. Теорема Голла про шлюб (Hall, 1935)

**Твердження.** У двочастковому графі `G = (U ∪ V, E)` існує паросполучення, що покриває всі вершини частки `U` (`|M| = |U|`), тоді й лише тоді, коли виконується умова Голла:

```
∀ S ⊆ U : |N(S)| ≥ |S|
```

### 4.1. Доведення у прямому напрямку (⇒)

Нехай існує паросполучення `M`, яке повністю покриває частку `U`. Це означає наявність ін'єктивного відображення `m: U → V`, де `(u, m(u)) ∈ M`.

Для будь-якої підмножини `S ⊆ U` її образ `m(S) = {m(u) | u ∈ S} ⊆ V` має розмір `|m(S)| = |S|`. Оскільки всі ці вершини суміжні з `S`, маємо `m(S) ⊆ N(S)`, звідки `|N(S)| ≥ |m(S)| = |S|`. Пряме твердження доведено.

### 4.2. Доведення в оберненому напрямку (⇐) через теорему Кеніга

Припустимо, що умова Голла виконується. За теоремою Кеніга, розмір максимального паросполучення `ν(G) = τ(G)`. Доведемо, що мінімальне вершинне покриття `C` має розмір `|C| ≥ |U|`.

Нехай `C` — довільне вершинне покриття. Позначимо `C_U = C ∩ U` та `C_V = C ∩ V`. Розглянемо непокриті вершини `S = U \ C_U`.

Усі ребра, що виходять із `S`, повинні покриватися вершинами з `C_V`. Це означає, що `N(S) ⊆ C_V`, звідки `|C_V| ≥ |N(S)|`.

Застосовуючи умову Голла `|N(S)| ≥ |S|`, маємо:

```
|C| = |C_U| + |C_V|      [аддитивність покриття за частками]
    ≥ |C_U| + |N(S)|     [підстановка нерівності |C_V| ≥ |N(S)|]
    ≥ |C_U| + |S|        [застосування умови Голла |N(S)| ≥ |S|]
    = |C_U| + |U \ C_U|  [заміна S на визначення U \ C_U]
    = |U|                [об'єднання неперетинних множин C_U та U \ C_U]
```

Отже, будь-яке вершинне покриття має розмір принаймні `|U|`. Покриття `C = U` має розмір `|U|`, отже `τ(G) = |U|`. Звідси `ν(G) = τ(G) = |U|`, тобто максимальне паросполучення повністю покриває частку `U`. Теорему Голла доведено. ∎

## 5. Теорема про регулярні двочасткові графи

**Твердження.** Будь-який `r`-регулярний двочастковий граф `G = (U ∪ V, E)` із степенем вершин `r ≥ 1` має однакові розміри часток (`|U| = |V|`) і містить досконале паросполучення (perfect matching).

### Доведення

Підрахуємо загальну кількість ребер `|E|`, підсумовуючи степені вершин частки `U`, а потім частки `V`:

```
|E| = r · |U| = r · |V|
```

Оскільки `r ≥ 1`, діленням на `r` отримуємо `|U| = |V|`.

Тепер перевіримо умову Голла для довільної підмножини `S ⊆ U`. Підрахуємо кількість ребер `E(S, N(S))`, що виходять із `S`. З одного боку, з `S` виходить точно `r · |S|` ребер. З іншого боку, усі ці ребра входять у `N(S)`, тому їхня кількість не перевищує сумарного ступеня вершин у `N(S)`:

```
r · |S| ≤ r · |N(S)|
```

Діленням на `r` отримуємо `|S| ≤ |N(S)|`. Умова Голла виконується для будь-якого `S ⊆ U`, отже граф містить паросполучення розміру `|U|`. Оскільки `|U| = |V|`, це паросполучення є досконалим. ∎
