# 🧮 Теорема Ейлера — Гіргольцера та теорема BEST

Строгий математичний критерій існування ейлерового циклу ґрунтується на топологічній рівновазі вершин графа — рівності степеней входу та виходу або парності степеней усіх вершин у зв'язному компоненті — а кількісний підрахунок таких циклів задається теоремою BEST через алгебраїчні визначники матрицій та кістякові дерева.

У цьому математичному розділі наведено суворі алгебраїчні та комбінаторні доведення необхідних і достатніх умов існування ейлерових шляхів і циклів для неорієнтованих та орієнтованих графів, розкрито лему про декомпозицію на реберно-диз'юнктні цикли, виведено алгебраїчну структуру простору циклів, а також виведено теорему BEST для обчислення кількості ейлерових циклів через орієнтовану матричну теорему Кірхгофа.

---

## Формальні означення та базові інваріанти

Нехай `G = (V, E)` — скінченний мультиграф (орієнтований або неорієнтований), де `V` — множина вершин, `E` — мультимножина ребер.

- **Ейлерів шлях** (*Eulerian path*) — це послідовність ребер `(e₁, e₂, ..., eₘ)`, яка містить кожне ребро `e ∈ E` рівно один раз.
- **Ейлерів цикл** (*Eulerian circuit*) — це замкнений ейлерів шлях, у якому початкова вершина першого ребра збігається з кінцевою вершиною останнього ребра.
- **Ейлерів граф** — граф, який містить принаймні один ейлерів цикл.

Для будь-якого неорієнтованого графа фундаментальним інваріантом є **лема про рукостискання** (*Handshaking Lemma*):

```
∑_{v ∈ V} deg(v) = 2 · |E|
```

### Доведення леми про рукостискання:
Кожне ребро `e = (u, w)` має два кінці. При обчисленні суми степеней усіх вершин кожне ребро додає 1 до степеня вершини `u` та 1 до степеня вершини `w`. Отже, у загальну суму кожне ребро робить внесок, рівний 2. Загальна сума степеней дорівнює `2 · |E|`.

З цієї леми безпосередньо випливає **наслідок про парність кількості непарних вершин**: кількість вершин із непарним степенем у будь-якому неорієнтованому графі є строго парною.

#### Формальне виведення наслідку:
Розділимо множину вершин `V` на дві множини, що не перетинаються: `V_even` (вершини з парним степенем) та `V_odd` (вершини з непарним степенем).

```
∑_{v ∈ V} deg(v) = ∑_{v ∈ V_even} deg(v) + ∑_{v ∈ V_odd} deg(v) = 2 · |E|
```

Перенесемо суму парних степеней у праву частину:

```
∑_{v ∈ V_odd} deg(v) = 2 · |E| - ∑_{v ∈ V_even} deg(v)
```

Права частина рівняння є різницею двох парних чисел, а отже, є парним числом. У лівій частині ми маємо суму непарних чисел. Сума непарних чисел може бути парним числом тоді й лише тоді, коли кількість доданків (тобто кількість вершин у `V_odd`) є **парним числом**.

Таким чином, у будь-якому неорієнтованому графі кількість вершин із непарним степенем завжди є парною: `|V_odd| ∈ {0, 2, 4, 6, ...}`.

## Теорема Ейлера — Гіргольцера для неорієнтованих графів

### Теорема 1 (Критерій існування Ейлерового циклу)
Зв'язний неорієнтований мультиграф `G = (V, E)` містить ейлерів цикл тоді й лише тоді, коли степінь кожної його вершини є парним числом:

```
∀ v ∈ V : deg(v) ≡ 0 (mod 2)
```

#### 1. Доведення необхідності (⇒)
Припустимо, що у графі `G` існує ейлерів цикл `C = (v₀, e₁, v₁, e₂, ..., eₘ, v₀)`, де `m = |E|`.

Розглянемо довільну вершину `u ∈ V`. Кожного разу, коли цикл `C` проходить через вершину `u`, він входить у `u` по деякому ребра `e_in` і виходить з `u` по іншому ребру `e_out`. Оскільки цикл відвідує кожне ребро графа `G` рівно один раз і є замкненим (початкова вершина `v₀` має перше ребро виходу та останнє ребро входу), кожне входження в `u` споживає строго два ребра.

Отже, загальний степінь `deg(u)` дорівнює подвоєній кількості входжень циклу `C` у вершину `u`:

```
deg(u) = 2 · visits(u)
```

Оскільки `visits(u)` є цілим числом, `deg(u)` обов'язково є парним числом для всіх `u ∈ V`. Необхідність доведено.

#### 2. Доведення достатності (⇐)
Припустимо, що в усіх вершин зв'язного графа `G` степені є парними числами, і `|E| > 0`. Доведемо наявність ейлерового циклу методом індукції за кількістю ребер `|E|` або за допомогою декомпозиції на цикли.

##### Лема 1 (Існування простого циклу)
Якщо у скінченному графі `G` степінь кожної вершини задовольняє умові `deg(v) >= 2`, то граф `G` містить принаймні один простий цикл.

*Доведення леми 1*: Почнемо з довільної вершини `u₁` і будемо будувати шлях `u₁ -> u₂ -> u₃ -> ...`, обираючи невідвідані ребра. Оскільки множина вершин `V` скінченна, а з кожної вершини є принаймні 2 ребра (отже, впасти в тупик на першому ж переході неможливо), на якомусь кроці ми обов'язково влучимо у вершину `uₖ`, яка вже була відвідана раніше на цьому шляху. Частина шляху між першим і другим візитом до `uₖ` утворює простий цикл `K₁`.

##### Крок індукції та декомпозиція:
1. Знайдемо у графі `G` простий цикл `K₁` (за лемою 1).
2. Вилучимо з графа `G` всі ребра, що входять до циклу `K₁`. Отримаємо новий граф `G' = (V, E \ E(K₁))`.
3. Оскільки цикл `K₁` містить для кожної своєї вершини рівно 2 ребра, вилучення `K₁` зменшує степінь кожної вершини `v ∈ K₁` строго на 2:

```
deg_G'(v) = deg_G(v) - deg_K₁(v)
deg_G'(v) = deg_G(v) - 2  ≡ 0 (mod 2)
```

   Для вершин, які не входили до `K₁`, степінь не змінився. Отже, у графі `G'` степені всіх вершин залишаються парними числами.
4. Граф `G'` може розпадатися на декілька зв'язних компонент `G'₁, G'₂, ..., G'ₖ`. За індуктивним припущенням (оскільки кожна компонента має менше ніж `|E|` ребер), у кожній компоненті `G'ᵢ` існує свій ейлерів цикл `Cᵢ`.
5. Оскільки початковий граф `G` був зв'язним, кожна компонента `G'ᵢ` має принаймні одну спільну вершину `wᵢ` з базовим циклом `K₁`.
6. Об'єднуємо (зрощуємо) цикли: обходимо цикл `K₁`, і при досягненні вершини `wᵢ` робимо повний обхід циклу `Cᵢ`, після чого продовжуємо рух по `K₁`. Отриманий результуючий цикл проходить через усі ребра `E` рівно один раз. Достатність доведено.

### Теорема 1a (Критерій існування Ейлерового шляху)
Зв'язний неорієнтований мультиграф `G = (V, E)` містить розімкнений ейлерів шлях від вершини `s` до вершини `t` (`s != t`) тоді й лише тоді, коли степені вершин `s` та `t` є непарними числами, а степені всіх інших вершин — парними:

```
deg(s) ≡ 1 (mod 2),  deg(t) ≡ 1 (mod 2)
∀ v ∈ V \ {s, t} : deg(v) ≡ 0 (mod 2)
```

#### Доведення:
Додамо до графа `G` фіктивне ребро `e_new = (s, t)`. U нового графа `G* = (V, E ∪ {e_new})` степені вершин `s` та `t` збільшаться на 1 і стануть парними:

```
deg_G*(s) = deg_G(s) + 1  [непарне + 1 = парне]
deg_G*(t) = deg_G(t) + 1  [непарне + 1 = парне]
```

Усі інші вершини зберегли свої парні степені. Отже, за Теоремою 1 граф `G*` задовольняє умовам існування ейлерового циклу `C*`.

Вилучивши ребро `e_new` з циклу `C*`, ми розриваємо його у вершинах `s` та `t`, перетворюючи на ейлерів шлях від `s` до `t` у початковому графі `G`.

## Теорема Ейлера — Гіргольцера для орієнтованих графів

### Теорема 2 (Орієнтований Ейлерів цикл)
Орієнтований мультиграф `G = (V, E)` містить орієнтований ейлерів цикл тоді й лише тоді, коли:
1. Для кожної вершини `v ∈ V` вхідний степінь дорівнює вихідному: `deg⁻(v) = deg⁺(v)`.
2. Усі вершини з ненульовим степенем належать єдиній сильно зв'язній компоненті.

*Доведення* аналогічне неорієнтованому випадку: кожен вхід у вершину `v` вимагає виходу по іншому орієнтованому ребра, що дає суворий баланс `deg⁻(v) = deg⁺(v)`.

## Теорема BEST для підрахунку кількості Ейлерових циклів

Підрахунок кількості різних ейлерових циклів у неорієнтованих графах є `♯P-повною` задачею. Проте для **орієнтованих графів** це завдання розв'язується за поліноміальний час `O(|V|³)` за допомогою **теореми BEST** (де Брейнен, ван Аарденне-Еренфест, Сміт, Татт).

### Формулювання теореми BEST
Нехай `G = (V, E)` — орієнтований збалансований ейлерів граф. Кількість ейлерових циклів `N(G, v)` з фіксованою початковою вершиною `v ∈ V` задається формулою:

```
N(G, v) = t_v(G) · ∏_{u ∈ V} (deg⁺(u) - 1)!
```

де:
- `t_v(G)` — кількість орієнтованих кістякових дерев графа `G` із коренем у вершині `v`, де всі ребра спрямовані у напрямку до кореня `v`;
- `deg⁺(u)` — вихідний степінь вершини `u`;
- `!` — факторіал.

Зі збалансованості графа випливає, що значення `t_v(G)` не залежить від вибору кореневої вершини `v`: `t_u(G) = t_v(G)` для всіх `u, v ∈ V`.

Загальна кількість орієнтованих ейлерових циклів у графі `G` з точністю до циклічного зсуву дорівнює:

```
N_total(G) = t_v(G) · [ ∏_{u ∈ V} (deg⁺(u) - 1)! ] / |E|
```

### Обчислення `t_v(G)` за орієнтованою матричною теоремою Кірхгофа
Значення `t_v(G)` обчислюється через алгебраїчні доповнення орієнтованої матриці Лапласа `L` розміром `|V| × |V|`:

```
L[i, j] = {  deg⁺(v_i),           якщо i = j
          { -k_ij,                якщо i ≠ j, де k_ij — кількість ребер v_i -> v_j
```

За теоремою Кірхгофа:

```
t_v(G) = det(L^(i, i))
```

де `L^(i, i)` — матриця, отримана вилученням `i`-го рядка та `i`-го стовпця з `L`. Обчислення визначника `det(L^(i, i))` через Гаусове вилучення займає час `O(|V|³)`.

### Формальне пояснення структури формули BEST:
1. **Факторіальний множник `∏ (deg⁺(u) - 1)!`**: У кожній вершині `u` ми можемо довільно впорядкувати вихідні ребра, за винятком останнього ребра, яке входить до кістякового дерева `t_v(G)`. Це дає `(deg⁺(u) - 1)!` комбінацій виборів у кожному вузлі.
2. **Кістякове дерево `t_v(G)`**: Забезпечує, що з будь-якої вершини існує єдиний вихідний шлях до кореня, що гарантує зв'язність і відсутність передчасних замкнених тупиків при обході.

## Алгебра простору циклів (Cycle Space Homology)

Для формалізації топології графів застосовується алгебраїчна комплексна гомологія 1-вимірних комплекаів.

Нехай `C₀` — векторний простір вершин (нульмірні ланцюги), `C₁` — векторний простір ребер (одномірні ланцюги) над полем `GF(2)`.
Граничний оператор `∂: C₁ -> C₀` задається на ребрах `e = (u, w)` як:

```
∂(e) = u + w  (модулем 2)
```

Ядро граничного оператора `Ker(∂)` являє собою точно **простір циклів `Z(G)`**:

```
Z(G) = Ker(∂) = { c ∈ C₁ | ∂(c) = 0 }
```

Рівняння `∂(c) = 0` вимагає, щоб для кожної вершини інцидентна кількість ребер у ланцюгу `c` була парною. Тим самим теорема Ейлера про парність степеней є твердженням про те, що ейлерів шлях належить ядру граничного оператора `Ker(∂)` над `GF(2)`.
