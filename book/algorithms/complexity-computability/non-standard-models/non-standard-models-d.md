Коли програміст реалізує алгоритм сортування масиву з `n` елементів або інженер верифікує складний розподілений протокол за допомогою формальних методів, вони спираються на базову інтуїцію: натуральні числа `0, 1, 2, 3, ...` утворюють абсолютно прозорий, скінченно-побудований ряд, у якому кожен наступний елемент отримується додаванням одиниці до попереднього. Вважається, що якщо формалізувати фундаментальні аксіоми додавання, множення та індукції в системі Пеано, то ця аксіоматика суворо й однозначно виокремить єдиний можливий числовий світ. Однак спроба зафіксувати стандартний ряд натуральних чисел засобами формальної логіки першого порядку призводить до несподіваного ефекту: поряд із звичайними числами неминуче виникають сторонні, нескінченно великі елементи, які перевищують будь-якое стандартне натуральне число, але повністю задовольняють усім аксіомам формальної арифметики.

Ці альтернативні математичні структури називають нестандартними моделями (лат. *modelus* — міра, зразок). Вони показують, що синтаксис формальної мови не здатний повністю контролювати власну семантику. Вивчення нестандартних моделей є не просто абстрактною вправою з математичної логіки, а ключем до розуміння меж алгоритмічної виразності, нерозв'язності проблеми зупинки Тюринга, теорії складності обчислень та методів символьного аналізу програм у сучасних верифікаторах.

## Семантичний розрив між аксіомами та об'єктами

Для розуміння природи нестандартних моделей необхідно розмежувати синтаксичний та семантичний рівні формальних систем. Синтаксис складається зі скінченного набору символів, правил побудови формул та правил виведення доказів. Семантика задає математичні об'єкти (носій моделі), на яких інтерпретуються символи мови та оцінюється істинність формул.

Класична формальна арифметика Пеано першого порядку (позначається `PA`) описується в сигнатурі мови `L_PA = {0, 1, +, ·, <, =}` і включає три фундаментальні групи аксіом:
1. **Аксіоми дорівнювання та порядку:**
   - Рефлексивність, симетричність та транзитивність рівності `=`.
   - Закон трихотомії порядку: `∀x ∀y (x < y ∨ x = y ∨ y < x)`.
   - Транзитивність порядку: `∀x ∀y ∀z (x < y ∧ y < z → x < z)`.
   - Відсутність від'ємних елементів: `∀x ¬(x < 0)`.
2. **Алгебраїчні аксіоми додавання та множення:**
   - Нейтральний елемент додавання: `∀x (x + 0 = x)`.
   - Додавання наступника: `∀x ∀y (x + (y + 1) = (x + y) + 1)`.
   - Нейтральний елемент множення: `∀x (x · 0 = 0)`.
   - Дистрибутивність та множення наступника: `∀x ∀y (x · (y + 1) = (x · y) + x)`.
3. **Нескінченне сімейство (схема) аксіом математичної індукції:**
   Для кожної логічної формули `ϕ(x)` з мови `L_PA` з вільними змінними:
```
[ϕ(0) ∧ ∀x (ϕ(x) → ϕ(x + 1))] → ∀x ϕ(x)
```

З точки зору класичної теорії множин існує інтуїтивно зрозуміла **стандартна модель** `ℕ = ({0, 1, 2, 3, ...}, 0, 1, +, ·, <, =)`. У цій моделі носієм є звичайні скінченні натуральні числа, а математичні операції та відношення мають свій звичний зміст.

Модель `M` називається **нестандартною моделлю арифметики**, якщо `M` задовольняє абсолютно усім аксіомам Пеано (`M ⊨ PA`), але при цьому `M` не є ізоморфною стандартній моделі `ℕ`. Це означає, що всередині `M` існують такі елементи `H ∈ M`, які знаходяться поза початковим сегментом стандартних чисел:

```
H > 0,   H > 1,   H > 2,   H > 3,   ...,   H > n  для всіх n ∈ ℕ
```

Такі елементи `H` називають нескінченно великими або нестандартними натуральними числами. При цьому з точки зору внутрішньої логіки моделі `M` число `H` поводиться як звичайне натуральне число: у нього є попередник `H - 1`, є наступник `H + 1`, воно має парність, ділиться або не ділиться на прості числа і підпорядковується усім законам арифметики.

Внутрішньо формальна система не спроможна помітити «нескінченність» елемента `H`, оскільки для будь-якої формули `ϕ` з мови `L_PA` аксіома індукції гарантує, що не існує першого елемента, на якому індуктивний ланцюжок розривається без синтаксичного скасування. Нестандартність є зовнішнім відношенням, яке бачить лише спостерігач метатеорії, зіставляючи модель `M` із базовим рядом `ℕ`.

## Механізм виникнення нестандартних елементів через теорему про компактність

Чому формальна арифметика `PA` не здатна заборонити існування нескінченно великих чисел? Головною причиною є фундаментальна властивість логіки першого порядку — **теорема про компактність**, доведена Куртом Ґьоделем у 1930 році як наслідок теореми про повноту числення предикатів.

Теорема про компактність стверджує: *множина логічних формул першого порядку T має модель тоді й лише тоді, коли кожна її скінченна підмножина T₀ ⊂ T має модель.*

За допомогою цієї теореми можна математично сконструювати нестандартну модель за шість послідовних кроків:

[Крок 1] Розглянемо канонічні аксіоми арифметики Пеано `PA` в мові `L_PA`.

[Крок 2] Збагатимо мову `L_PA`, додавши один новий константний символ `c`.

[Крок 3] Утворимо розширену теорію `T'`, додавши до `PA` нескінченну множину нових аксіом:
```
T' = PA ∪ { c > 0,  c > 1,  c > 2,  c > 3,  ...,  c > n,  ... }  для всіх n ∈ ℕ
```

[Крок 4] Перевіримо сумісність довільної скінченної підмножини `T₀ ⊂ T'`. Будь-яка скінченна підмножина `T₀` містить лише скінченне число аксіом з `PA` та скінченну кількість нерівностей вида `c > nᵢ`. Нехай `n_max = max {nᵢ | (c > nᵢ) ∈ T₀}` — найбільше число серед усіх нерівностей у `T₀`. Якщо ми проінтерпретуємо символ `c` у стандартній моделі `ℕ` як конкретне натуральне число `c_val = n_max + 1`, то стандартна модель `ℕ` разом із цим значенням `c_val` буде істинною для всіх формул з `T₀` (`ℕ ⊨ T₀`).

[Крок 5] Оскільки довільна скінченна підмножина `T₀` має модель, за теоремою про компактність уся нескінченна теорія `T'` має модель `M ⊨ T'`.

[Крок 6] Оскільки `M ⊨ T'`, модель `M` задовольняє всім аксіомам Пеано (`M ⊨ PA`), а значення константи `c^M` є елементом моделі `M`, який задовольняє нерівностям `c^M > n^M` для всіх `n ∈ ℕ`.

Отже, елемент `c^M` є строго більшим за будь-яке стандартне натуральне число. Модель `M` побудовано: вона містить нестандартні числа і є неізоморфною `ℕ`.

Альтернативним алгебраїчним способом побудови нестандартних моделей є метод **ультрадобутків** (теорема Єжи Лося), де нестандартна модель будується як фактор-множина нескінченних послідовностей натуральних чисел `ℕ^ℕ` за неглавним ультрафільтром `U`. У такій моделі два елементи (послідовності `f` та `g`) вважаються рівними, якщо множина індексів `{i ∈ ℕ | f(i) = g(i)}` належить ультрафільтру `U`. Якщо покласти `f(i) = i`, клас еквівалентності цієї послідовності `[id]_U` дає нестандартне число `H`, оскільки для кожного стандартного `n` множина `{i ∈ ℕ | i > n}` є коскінченною, а отже належить неглавному ультрафільтру `U`.

Завдяки теоремі Лося всі властивості логіки першого порядку переносяться зі стандартної моделі `ℕ` на ультрастепінь `*ℕ`. Якщо формула `ϕ(x)` є істинною для всіх чисел у `ℕ`, вона залишається істинною для елементів `*ℕ`, забезпечуючи повне дотримання аксіом арифметики `PA`. Побудова ультрадобутків дає змогу явно маніпулювати нестандартними числами як класами еквівалентності нескінченно зростаючих числових послідовностей. Наприклад, послідовність `f(n) = n²` кодує нестандартне число `H²`, а послідовність `g(n) = 2ⁿ` кодує нестандартний елемент `2^H`.

## Топологічна та впорядкована анатомія моделі: структура ℕ + ℤ × ℚ

Який вигляд має лінійний порядок нестандартної моделі арифметики? На відміну від стандартного ряду `ℕ`, який є просто простим променем із початком у `0`, впорядкована структура нестандартної моделі має складну ієрархічну будову.

Нехай `M` — зліченна нестандартна модель арифметики `PA`. Усі елементи моделі `M` за своєю величиною розбиваються на дві принципово різні частини:

1. **Стандартний початковий сегмент (`ℕ`):** Це елементи `0, 1, 2, 3, ...`, які отримуються від нуля за скінченну кількість застосувань функції наступника `x ↦ x + 1`. Цей відрізок утворює початковий промінь моделі і є ізоморфним звичайним натуральним числам. Він має найменший елемент `0` і дискретний крок `1`.

2. **Нестандартний сегмент (`M \ ℕ`):** Це елементи, які перевищують будь-яке число зі стандартного початкового сегмента. Якщо ми візьмемо довільне нестандартне число `H ∈ M \ ℕ`, то в арифметиці Пеано для нього обов'язково визначені елементи:
```
...,  H - 3,  H - 2,  H - 1,  H,  H + 1,  H + 2,  H + 3,  ...
```
Множина усіх елементів вида `H + k` (де `k ∈ ℤ` — стандартне ціле число) утворює дискретну копию цілих чисел, яку називають `ℤ`-блоком елемента `H`.

![Лінійний порядок нестандартної моделі арифметики N + Z x Q](/book/algorithms/complexity-computability/non-standard-models/img/fig1-order-structure.svg)
*Лінійний порядок нестандартної моделі арифметики: початковий сегмент ℕ та щільне сімейство цілочисельних блоків ℤ × ℚ.*

Розглянемо властивості порядку між цими `ℤ`-блоками в нестандартному сегменті `M \ ℕ`:

- **Відсутність найменшого та найбільшого блоку:** Для будь-якого нестандартного елемента `H` в `PA` можна довести існування чисел `⌊H / 2⌋` та `2H`. Елемент `2H` лежить на нескінченній відстані від `H` (`2H - H = H ∉ ℕ`), тому блок `[2H]_ℤ` лежить строго вище за блок `[H]_ℤ`. Аналогічно, блок `[⌊H / 2⌋]_ℤ` лежить строго нижче за `[H]_ℤ`, але все одно вище за стандартний сегмент `ℕ`. Отже, у нестандартному сегменті немає ні найменшого, ні найбільшого `ℤ`-блоку.
- **Щільність порядку блоків:** Якщо ми візьмемо два різні нестандартні блоки `[A]_ℤ < [B]_ℤ`, то їхнє середнє арифметичне `C = ⌊(A + B) / 2⌋` утворює новий `ℤ`-блок `[C]_ℤ`, який знаходиться на нескінченній відстані як від `A`, так і від `B`. Отже, між будь-якими двома нестандартними `ℤ`-блоками завжди знайдеться третій `ℤ`-блок.

За класичною теоремою Георга Кантора, будь-яка зліченна щільно впорядкована множина без найменшого та найбільшого елемента є ізоморфною раціональним числам `ℚ`.

Таким чином, будь-яка зліченна нестандартна модель арифметики Пеано як лінійно впорядкована множина має строго фіксовану структуру:

```
Order(M) = ℕ + ℤ × ℚ
```

Це означає, що за стандартним початковим променем `ℕ` іде нескінченне сімейство цілочисельних блоків `ℤ`, впорядкованих щільно, як раціональні числа `ℚ`.

Важливо підкреслити, що алгебраїчна операція додавання та множення у цій структурі є цілісною. Наприклад, якщо ми помножимо нестандартний елемент `H` на `2`, ми перемістимося з блоку `[H]_ℤ` у нескінченно віддалений блок `[2H]_ℤ`. Якщо піднесемо до квадрата `H²`, перемістимося у ще вищий блок. Аналогічно, добуток двох елементів з різних блоків `A · B` дає третій блок, позиція якого визначається законами впорядкування раціональних чисел `ℚ`.

## Логічні межі: Принципи Переливу (Overspill) та Андерспілу (Underspill)

Чому аксіома математичної індукції у формальній арифметиці не змогла «вирізати» нестандартну частину `ℤ × ℚ` і залишити лише `ℕ`?

В логіці другого порядку аксіома індукції звучить так: *«Для ДО ВІЛЬНОЇ підмножини S ⊆ ℕ, якщо 0 ∈ S і (x ∈ S → x + 1 ∈ S), то S = ℕ»*. У логіці другого порядку нестандартних моделей не існує, тому що підмножина `S`, що відповідає стандартним числам `ℕ`, існує у самій моделі і за індукцією відсікає будь-які нестандартні елементи.

Проте у логіці першого порядку ми не можемо квантифікувати за підмножинами. Схема індукції дозволяє використовувати лише підмножини, які визначаються **формальними формулами першого порядку** `ϕ(x)` з мови `L_PA`.

Звідси випливає фундаментальний факт: **стандартний початковий сегмент `ℕ` є логічно невиражуваним всередині нестандартної моделі `M`**. Не існує такої формули першого порядку `ϕ(x)`, яка була б істинною для елементів `x ∈ M` тоді й лише тоді, коли `x` є стандартним числом (`x ∈ ℕ`).

З невиражуваності `ℕ` випливають два найважливіші методичні інструменти логіки — принципи Переливу (Overspill) та Андерспілу (Underspill).

![Принцип оверспілу (переливу) та андерспілу](/book/algorithms/complexity-computability/non-standard-models/img/fig2-overspill-principle.svg)
*Принцип оверспілу (переливу) та андерспілу (недоливу): виливання логічних предикатів зі стандартного початкового сегмента ℕ у нестандартну область M \ ℕ.*

**Теорема про Оверспіл (Принцип Переливу):**
Нехай `M` — нестандартна модель `PA`, а `ϕ(x)` — формула мови `L_PA`. Якщо предикат `ϕ(n)` є істинним для всіх стандартних натуральних чисел `n ∈ ℕ`, то існує нестандартне число `H ∈ M \ ℕ`, таке що `ϕ(x)` істинне для всіх `x ≤ H`.

*Логіка доведення:* Якщо припустити, що `ϕ(x)` істинне *тільки* на стандартних числах `ℕ` і стає хибним для всіх нестандартних чисел, то формула `ψ(y) ≡ ∀x ≤ y ϕ(x)` задавала б точну межу стандартного сегмента `ℕ`. Тоді за аксіомою індукції першого порядку для `ψ(y)` формула мала б бути істинною для всіх елементів моделі `M`, що суперечить припущенню. Отже, істинність предикату неминуче «виливається» (overspills) через межу `ℕ` у нестандартну область `M \ ℕ`.

**Теорема про Андерспіл (Принцип Недоливу):**
Якщо формула `ψ(x)` є істинною для довільно малих нестандартних чисел (тобто для кожного `H ∈ M \ ℕ` існує нестандартне `K ≤ H` таке, що `ψ(K)`), то існує стандартне натуральне число `n ∈ ℕ`, для якого `ψ(n)` є істинним.

Практичне значення принципів Переливу та Андерспілу для аналізу алгоритмів полягає в тому, що вони дозволяють переношувати скінченні властивості програм на нескінченні елементи. Наприклад, якщо програма доказово завершується за `n²` кроків для кожного стандартного числа `n`, за принципом Оверспілу вона залишається спроможною виконатися за `H²` кроків у нестандартному часі `H`.

Також принцип Оверспілу широко використовується в комбінаториці для створення некомутативних або нестандартних графових конструкцій, де локальні скінченні властивості графів гарантовано зберігаються на нестандартно великих розмірах вершин.

## Фундаментальний обчислювальний бар'єр: Теорема Тенненбаума (1959)

З точки зору теорії алгоритмів виникає природне запитання: якщо нестандартна модель `M` є зліченною, її елементи можна пронумерувати звичайними натуральними числами `0, 1, 2, 3, ...`. Чи можна побудувати таку нумерацію елементів моделі, щоб внутрішні математичні операції додавання `+_M` та множення `·_M` виявилися звичайними обчислюваними (рекурсивними) функціями над їхніми кодами?

У 1959 році американський логік Стенлі Тенненбаум навів категоричну негативну відповідь, довівши одну з найважливіших теорем математичної логіки ХХ століття.

**Теорема Тенненбаума:**
Жодна нестандартна модель арифметики Пеано `PA` не має обчислювальних (рекурсивних) операцій додавання чи множення над стандартними натуральними кодами.

![Теорема Тенненбаума та необчислюваність нестандартних операцій](/book/algorithms/complexity-computability/non-standard-models/img/fig3-tennenbaum-theorem.svg)
*Теорема Тенненбаума: рекурсивна невідокремлюваність та необчислюваність арифметичних операцій у нестандартних моделях.*

Схема доведення теореми Тенненбаума спирається на використання рекурсивно невідокремлюваних множин з теорії алгоритмів:

1. У теорії обчислюваності існують дві рекурсивно перелічувані множини `A, B ⊂ ℕ`, які не перетинаються (`A ∩ B = ∅`), але для яких не існує жодної обчислювальної множини `C`, яка б містила `A` і не перетиналася з `B` (`A ⊆ C` та `B ∩ C = ∅`).
2. Користуючись [китайською теоремою про залишки](book:math/chinese-remainder-theorem) та кодуванням послідовностей простими числами `p₀ = 2, p₁ = 3, p₂ = 5, ...`, у кожній скінченній моделі можна підібрати число `x`, яке ділиться на `p_i` для `i ∈ A` і не ділиться на `p_i` для `i ∈ B`.
3. За принципом Оверспілу в нестандартній моделі `M` існує нестандартний елемент `E ∈ M`, який одночасно кодує нескінченну інформацію про всі елементи множини `A`: для кожного стандартного `i ∈ ℕ` просте число `p_i` ділить `E` в моделі `M` тоді й лише тоді, коли `i ∈ A`.
4. Якби операції додавання `+_M` або множення `·_M` у моделі `M` були алгоритмічно обчислюваними, то перевірка подільності `p_i | E` у моделі `M` для кожного стандартного `i` виконувалася б за скінченний обчислювальний час.
5. Це дозволило б побудувати алгоритм, який для кожного `i` розпізнає, чи належить воно `A` чи `B`, утворюючи обчислювальний сепаратор `C`. Це суперечить рекурсивній невідокремлюваності множин `A` та `B`.

Отже, арифметика в нестандартних моделях фундаментально необчислювана. Це встановлює жорстку межу: жодна реальна електронно-обчислювальна машина чи програмний інтерпретатор не спроможні точно моделювати нестандартну арифметику.

Більш того, теорема Тенненбаума підкреслює глибокий зв'язок між фундаментальною нерозв'язністю проблеми зупинки Тюринга та геометрією логічних моделей. Якби нестандартну модель можна було реалізувати обчислювальними операціями над масивом пам'яті, ми отримали б алгоритмічний оракул, здатний розв'язувати нерозв'язні проблеми з вищих рівнів арифметичної ієрархії. Неможливість існування такого оракулу запевняє цілісність класичної теорії алгоритмів.

Цікаво зауважити, що теорема Тенненбаума вимагає істинності всієї системи аксіом Пеано `PA` (зокрема індукції для всіх формул). Якщо ж розглянути значно слабші фрагменти арифметики, де індукцію обмежено лише базовими кванторами (наприклад, система `IE₁`), то для них існують нестандартні моделі з обчислюваним додаванням, але необчислюваним множенням.

Детальний логіко-історичний контекст відкриттів Сколема та Тенненбаума викладено у вставці [📜 Історія виникнення нестандартних моделей та теореми Тенненбаума](book:algorithms/complexity-computability/non-standard-models/hist-skolem-tennenbaum.md).

Строгий математичний апарат побудови ультрадобутків та повне крок-за-кроком доведення теореми Тенненбаума наведено у вставці [🧮 Математичний апарат нестандартних моделей та доведення теореми Тенненбаума](book:algorithms/complexity-computability/non-standard-models/math-tennenbaum-proof.md).

## Нестандартні машини Тюринга, Гіпер-обчислення та Теорема Ґьоделя

Поняття нестандартних моделей нерозривно пов'язане з теорією автоматів та машин Тюринга. Оскільки програма машини Тюринга та стан її стрічки кодуються натуральними числами (числами Ґьоделя `e ∈ ℕ`), ми можемо розглянути машини Тюринга всередині нестандартної моделі `M`.

У моделі `M` виникають два класи нестандартних обчислювальних об'єктів:

1. **Нестандартні машини Тюринга:** Це машини, кодовий номер яких `e ∈ M \ ℕ` є нескінченно великим нестандартним числом. Така «машина» має нескінченно великий за розміром синтаксичний код (нескінченну кількість станів з точки зору стандартного спостерігача), але всередині `M` вона підпорядковується звичайним правилам виконання переходів.

2. **Нестандартні часові траєкторії (Гіпер-час):** Це виконання звичайної машини Тюринга протягом нестандартної кількості кроків `H ∈ M \ ℕ`.

![Траєкторія виконання нестандартної машини Тюринга](/book/algorithms/complexity-computability/non-standard-models/img/fig4-nonstandard-turing-execution.svg)
*Траєкторія виконання нестандартної машини Тюринга: стандартний часовий відрізок та нестандартний гіпер-час H.*

Це розрізнення пояснює один із найважчих парадоксів другої теореми Ґьоделя про неповноту. За другою теоремою Ґьоделя, якщо арифметика `PA` є несуперечливою, вона не може довести власну несуперечливість (`PA ⊬ Con(PA)`).

З семантичного боку це означає, що існує така нестандартна модель `M ⊨ PA + ¬Con(PA)`.

Як у моделі `M` може бути істинним твердження `¬Con(PA)` (що стверджує існування доказу суперечності `0 = 1` у `PA`), якщо сама арифметика `PA` є насправді несуперечливою?

Відповідь дають нестандартні числа: у моделі `M` доказом суперечності `0 = 1` є **нестандартне число Ґьоделя** `P ∈ M \ ℕ`. З точки зору логіки моделі `M`, число `P` кодує скінченну послідовність виводів. Проте для стандартного спостерігача (який дивиться ззовні з `ℕ`) цей «доказ» має нескінченну довжину і містить нестандартні формули, тому він не є реальним доказом у звичайному розумінні.

Аналогічно, проблема зупинки машини Тюринга в нестандартній моделі набуває гіпер-часового виміру: машина може не зупинятися на жодному стандартному кроці `n ∈ ℕ`, але вважатися такою, що зупинилася в моделі `M` за нестандартне число кроків `H`.

Ці спостереження привели до виникнення галузі нестандартних обчислень та зворотної математики (англ. *Reverse Mathematics*), заснованої Стівеном Сімпсоном (Stephen G. Simpson). У зворотній математиці дослідники з'ясовують, які саме аксіоми необхідні для доведення конкретних математичних теорем, аналізуючи існування нестандартних моделей у слабких формальних системах `RCA₀`, `WKL₀`, `ACA₀`.

Дослідження таких принципів невиражуваності та недовідності призвело також до відкриття знаменитої теореми [Паріса — Гаррінгтона](book:algorithms/paris-harrington-theorem), яка продемонструвала перший строгий комбінаторний приклад твердження, недовідного в `PA` через оверспіл у нестандартні моделі.

## Рекурсивна насиченість та внутрішні типи моделі

Важливим поняттям у вивченні обчислювальних властивостей нестандартних структур є **рекурсивна насиченість** (англ. *Recursive Saturation*), введена Грантом та Барвайсом.

Модель `M` називається рекурсивно насиченою, якщо для будь-якого скінченного набору параметрів `a₁, ..., aₖ ∈ M` та для будь-якої обчислювальної (рекурсивної) множини формул `Γ(x, a₁, ..., aₖ)` виконується наступне правило:
Якщо кожна скінченна підмножина `Γ₀ ⊂ Γ` є виконуваною у `M` (тобто існує елемент `b ∈ M`, який задовольняє формулам `Γ₀`), то існує єдиний елемент `b_full ∈ M`, який одночасно задовольняє **усім** нескінченним формулам множини `Γ`.

Рекурсивно насичені нестандартні моделі мають унікальні властивості:
- У них реалізуються всі обчислювальні типи даних, що не суперечать скінченній логіці моделі.
- Вони містять нестандартні елементи, які діляться на всі стандартні прості числа одночасно (так звані прості нестандартні дільники).
- Будь-які дві зліченні рекурсивно насичені моделі, що мають однакові елементарні теорії, є ізоморфними.

Це робить рекурсивно насичені моделі універсальними лабораторіями для оцінки меж виразності логіки першого порядку та перевірки алгоритмічних інваріантів у теоретичній інформатиці.

## Застосування у теорії складності та обмеженій арифметиці

У сучасній теоретичній інформатиці нестандартні моделі активно застосовуються в теорії складності обчислень через систему обмеженої арифметики (англ. *Bounded Arithmetic*), розроблену Семом Буссом (Samuel Buss), Яном Країчеком (Jan Krajíček) та Алексом Wilkie.

У класичній арифметиці `PA` квантори є необмеженими (`∃x`, `∀x`). В обмеженій арифметиці (наприклад, у системах `IΔ_0` або `S²₁`) усі квантори обмежені основними термами (наприклад, `∃x ≤ t`). Бусс довів, що доказові можливості системи `S²₁` точно відповідають класу складності `P` (поліноміальний час), а вищі рівні ієрархії відповідають поліноміальній ієрархії `PH`.

Для аналізу того, чи можна наявними математичними засобами довести фундаментальну гіпотезу `P ≠ NP`, вчені будують нестандартні моделі систем обмеженої арифметики:

1. **Нестандартні поліноми:** У нестандартній моделі обмеженої арифметики поліноміальна межа `n^H` (де `H ∈ M \ ℕ`) з точки зору моделі вважається «поліноміальною», але з точки зору стандартного світу `ℕ` вона зростає швидше за будь-яку стандартну експоненту.
2. **Нестандартна складність схем (Circuit Complexity):** Будуються нестандартні булеві схеми з нестандартною кількістю вентилів `H`. Якщо у такій моделі алгоритм виконується за нестандартний поліноміальний час, це пояснює, чому слабкі формальні системи не в змозі довести нижні оцінки складності для конкретних задач.

Якщо вдається побудувати нестандартну модель теорії `S²₁`, у якій проблема `NP` вирішується за «нестандартний поліноміальний час», це є строгим доказом того, що дана формальна система фундаментально не здатна довести `P ≠ NP`. Це дає змогу логікам пояснити, чому наявні методи низькорівневих доказів не спрацьовують для розв'язання великих проблем складності обчислень.

Завдяки побудові моделей із суперполіноміальною висотою можна суворо обмежувати потужність методів доведення (наприклад, методів розрізання та площин / Cutting Planes, Resolution або Nullstellensatz) у доказовій складності (Proof Complexity).

## Програмна інженерія та формальна верифікація

> 🔧 **Навіщо це.**
> Знання нестандартних моделей та принципів Переливу критично необхідне розробникам сучасних SMT-соліверів (Z3, CVC5, Vampire), інженерам із формальної верифікації програмного забезпечення та проектувальникам мов специфікацій (TLA+, Coq, Lean, Dafny). Під час автоматичного аналізу зациклень у коді, абстрактного виконання (Symbolic Execution) або верифікації безпеки пам'яті SMT-солівери працюють із логікою першого порядку над цілими числами (теоретична теорія `LIA` — Linear Integer Arithmetic). Якщо верифікатор намагається довести відсутність переповнення буфера у нескінченному циклі за допомогою кванторів першого порядку, він стикається з ефектом Оверспілу: солівер може згенерувати фіктивну контр-модель з «нескінченно великим цілим числом», що призводить до хибно-позитивних тривог (False Positives) під час статичного аналізу коду. Розуміння структури `ℕ + ℤ × ℚ` дозволяє розробникам правильно обирати інваріанти циклів та застосовувати теорію індукції вищого порядку для фіксації стандартного сегмента обчислень.

Під час совування кванторних виразів у SMT-соліверах (наприклад, `∀x (P(x) → Q(x))`) рушії використовують підстановки E-matching. Оскільки стандартний сегмент `ℕ` є невиражуваним у теорії `LIA`, E-matching може потрапляти у нескінченні індуктивні петлі підстановки, генеруючи нестандартні контр-моделі (Non-standard Countermodels). Розробники формальних специфікацій у мовах Dafny або Lean використовують леми підсумовування та обмежену індукцію для запобігання генерації нестандартних контр-прикладів у солівері.

Крім того, в аналізі алгоритмів та теорії типів концепція нестандартних моделей використовується при розробці не-архімедових типів даних та аналітиків профілювання ресурсів. Коли статичний аналізатор аналізує обчислимість складних рекурсивних функцій або алгоритмів обробки графів, він може будувати символьні абстракції, у яких розміри даних описуються як символьні поліноми виду `n + H`. Це дозволяє виявляти потенційні витоки пам'яті чи нескінченні зациклення ще на етапі компіляції проекту, не виконуючи реального коду на вхідних даних.

Нестандартний аналіз (Non-standard Analysis) Робінсона також застосовується у неперервній симуляції кіберфізичних систем (Hybrid Systems) та робототехніці, де комбінація дискретних переходів контролера та неперервного фізичного часу моделюється через розширене поле гіперреальних чисел `*ℝ`. Це спрощує доказати стійкість алгоритмів управління без складних `ε-δ` апаратів, переводячи диференціальні рівняння в прямі алгебраїчні маніпуляції з диференціалами `dx = 1/H`. Оволодіння апаратом нестандартних моделей дає науковцям та розробникам потужний інструмент для суворого мапування нескінченних теоретичних моделей на скінченні обчислювальні архітектури сучасних комп'ютерів.

Практичну реалізацію програмного симулятора нестандартних числових систем та траєкторій машин Тюринга наведено у вставці [⚙️ Реалізація симулятора нестандартної арифметики та машин Тюринга](book:algorithms/complexity-computability/non-standard-models/proj-nonstandard-sim.md).
