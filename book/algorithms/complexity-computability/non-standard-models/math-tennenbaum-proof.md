# 🧮 Математичний апарат нестандартних моделей та доведення теореми Тенненбаума

Ця вставка містить строге формальне доведення фундаментальних властивостей нестандартних моделей арифметики Пеано (`PA`), зокрема теореми про побудову моделей через ультрадобутки, теореми про лінійний порядок `ℕ + ℤ × ℚ`, принципів Переливу (Overspill) та Андерспілу (Underspill), а також повного доведення теореми Тенненбаума про необчислюваність нестандартних арифметичних операцій.

## 1. Побудова нестандартних моделей: Теорема про компактність та ультрадобутки

Логіка першого порядку має фундаментальну властивість: семантичну виражуваність через теорії моделей. Мова арифметики `L_PA = {0, 1, +, ·, <, =}` описує структуру натуральних чисел.

### Спосіб А: Конструкція через теорему про компактність

Нехай `PA` — формальна арифметика Пеано першого порядку. Розширимо мову `L_PA` новим константним символом `c`. Сформуємо нескінченну множину аксіом `T'`:

```
T' = PA ∪ {c > 0, c > 1, c > 2, ..., c > n, ...}  для всіх n ∈ ℕ
```

Доведемо, що теорія `T'` є сумісною (має модель).

[Крок 1] Розглянемо довільну скінченну підмножину `T₀ ⊂ T'`.
[Крок 2] Множина `T₀` містить лише скінченну кількість нерівностей вида `c > nᵢ`. Нехай `n_max = max {nᵢ | (c > nᵢ) ∈ T₀}`.
[Крок 3] Заінтерпретуємо символ `c` у стандартній моделі `ℕ` як натуральне число `c_val = n_max + 1`.
[Крок 4] Тоді стандартна модель `ℕ` з константою `c_val` задовольняє всім аксіомам `T₀` (`ℕ ⊨ T₀`).
[Крок 5] За теоремою про компактність логіки першого порядку, якщо кожна скінченна підмножина теорії `T'` має модель, то й уся нескінченна теорія `T'` має модель `M ⊨ T'`.
[Крок 6] У моделі `M` інтерпретація константи `c^M` задовольняє нерівності `c^M > n^M` для кожного стандартного натурального числа `n`. Отже, `c^M` є нескінченно великим елементом, а модель `M` є нестандартною.

### Спосіб Б: Конструкція через ультрадобуток (Los's Theorem)

Нехай `U` — неглавний ультрафільтр над множиною натуральних чисел `ℕ` (тобто ультрафільтр, що містить усі коскінченні підмножини `ℕ`).

Розглянемо множину усіх послідовностей натуральних чисел `ℕ^ℕ = {f | f: ℕ → ℕ}`. Запровадимо відношення еквівалентності `~_U` на послідовностях:

```
f ~_U g  ⟺  {i ∈ ℕ | f(i) = g(i)} ∈ U
```

Множина еквівалентності `M = ℕ^ℕ / ~_U` називається ультрастепенем стандартної моделі `ℕ* = ∏_U ℕ`.

Операції та відношення на класах еквівалентності `[f]_U` визначаються покомпонентно:

```
[f]_U +_M [g]_U = [i ↦ f(i) + g(i)]_U
[f]_U ·_M [g]_U = [i ↦ f(i) · g(i)]_U
[f]_U <_M [g]_U ⟺ {i ∈ ℕ | f(i) < g(i)} ∈ U
```

За теоремою Єжи Лося (англ. *Jerzy Łoś Theorem*), для довільної формули логіки першого порядку `ϕ(x₁, ..., xₖ)` та послідовностей `f₁, ..., fₖ`:

```
M ⊨ ϕ([f₁]_U, ..., [fₖ]_U)  ⟺  {i ∈ ℕ | ℕ ⊨ ϕ(f₁(i), ..., fₖ(i))} ∈ U
```

Стандартні числа вкладаються в `M` як тотожно константні послідовності `c_n(i) = n`. Якщо ж ми розглянемо послідовність `id(i) = i`, її клас еквівалентності `H = [id]_U` задовольняє умовам:

```
{i ∈ ℕ | id(i) > n} = {n+1, n+2, n+3, ...} ∈ U
```

Оскільки коскінченна множина належить неглавному ультрафільтру `U`, елемент `H = [id]_U` є строго більшим за кожне константне число `c_n`, тобто `H` є нескінченно великим нестандартним числом.

## 2. Теорема про топологічну структуру лінійного порядку ℕ + ℤ × ℚ

З'ясуємо алгебраїчну структуру порядку будь-якої зліченної нестандартної моделі `M ⊨ PA`.

Нехай `M` — зліченна нестандартна модель. Визначимо відношення еквівалентності на `M`: елементи `a, b ∈ M` належать одному цілочисельному блоку (позначимо `a ~_ℤ b`), якщо відстань між ними є скінченною, тобто існує стандартне натуральне число `n ∈ ℕ`, таке що:

```
|a - b|^M ≤ n
```

Для кожного `a ∈ M` клас еквівалентності `[a]_ℤ = {b ∈ M | a ~_ℤ b}` називається `ℤ`-блоком елемента `a`.

Доведемо теорему про структуру порядку `M`.

**Теорема (Структура зліченних нестандартних моделей):**
Будь-яка зліченна нестандартна модель арифметики `M` як лінійно впорядкована множина є ізоморфною структурі:

```
Order(M) = ℕ + ℤ × ℚ
```

*Доведення (покрокова виведення):*

[Крок 1] **Початковий відрізок:** Розглянемо елементи `a ∈ M`, які є скінченними (тобто `a < n` для деякого стандартного `n ∈ ℕ`). Цей початковий сегмент ізоморфний звичайному ряду натуральних чисел `ℕ = {0, 1, 2, 3, ...}` з найменшим елементом `0`.

[Крок 2] **Будова нестандартного блоку:** Нехай `H ∈ M \ ℕ` — нестандартне число. Оскільки `M ⊨ PA`, для `H` визначено наступник `H + 1`, `H + 2`, ..., а також попередники `H - 1`, `H - 2`, ... Множина усіх елементів вида `H + k` (де `k ∈ ℤ` — стандартне ціле число) утворює дискретний впорядкований блок, ізоморфний цілим числам `ℤ`.

[Крок 3] **Відсутність найменшого та найбільшого блоку:** Для будь-якого нестандартного елемента `H ∈ M \ ℕ` в арифметиці `PA` доводиться існування елементів `⌊H / 2⌋` та `2H`.
 Оскільки `H` нестандартне, відстань між `H` та `2H` є нескінченною (`2H - H = H ∉ ℕ`), тож блок `[2H]_ℤ` строго більший за блок `[H]_ℤ`.
 Аналогічно, блок `[⌊H / 2⌋]_ℤ` строго менший за блок `[H]_ℤ`, але більший за `ℕ`.
 Отже, множина нестандартних `ℤ`-блоків не має найменшого та найбільшого елемента.

[Крок 4] **Щільність порядку блоків:** Нехай `[A]_ℤ < [B]_ℤ` — два різні нестандартні блоки. Розглянемо середнє арифметичне `C = ⌊(A + B) / 2⌋`.
 В арифметиці `PA` маємо:

```
A < C < B
C - A = ⌊(B - A) / 2⌋
```

Оскільки відстань `B - A` була нескінченною, відстань `C - A` також є нескінченною (`⌊(B - A) / 2⌋ ∉ ℕ`).
Отже, блок `[C]_ℤ` лежить строго між `[A]_ℤ` та `[B]_ℤ` (`[A]_ℤ < [C]_ℤ < [B]_ℤ`).
Порядок між `ℤ`-блоками є щільним.

[Крок 5] **Застосування теореми Кантора:** Множина `ℤ`-блоків у зліченній моделі `M` є зліченною, щільно впорядкованою і не має крайніх точок. За теоремою Георга Кантора, будь-який злічений щільний лінійний порядок без крайніх точок ізоморфний раціональним числам `ℚ`.

Таким чином, порядок всієї моделі `M` складається зі стандартного початкового променя `ℕ`, за яким іде щільне нескінченне сімейство цілочисельних блоків `ℤ`, впорядкованих як `ℚ`. ∎

## 3. Принципи Переливу (Overspill) та Андерспілу (Underspill)

Невиражуваність стандартного відрізка `ℕ` всередині мови першого порядку породжує дві важливі теореми про межі значень логічних формул.

**Теорема (Принцип Оверспілу / Переливу):**
Нехай `M` — нестандартна модель `PA`, а `ϕ(x)` — формула мови `L_PA` (можливо з параметрами з `M`). Якщо `ϕ(n)` істинна для всіх стандартних натуральних чисел `n ∈ ℕ`, то існує нестандартний елемент `H ∈ M \ ℕ`, такий що `ϕ(x)` істинна для всіх `x ≤ H`.

*Доведення:*
Припустимо протилежне: для кожного нестандартного `H ∈ M \ ℕ` існує таке `x ≤ H`, що `¬ϕ(x)`.
Розглянемо формулу `ψ(y) ≡ ∀x ≤ y ϕ(x)`.
За умовою, `ψ(n)` істинна для кожного стандартного `n ∈ ℕ`.
Якщо для всіх нестандартних `H` значення `ψ(H)` хибне, то формула `ψ(y)` визначає точно стандартний сегмент `ℕ`:

```
y ∈ ℕ  ⟺  M ⊨ ψ(y)
```

Але `M ⊨ PA`, тому для формули `ψ(y)` має виконуватися аксіома індукції:

```
ψ(0) ∧ (∀y (ψ(y) → ψ(y + 1)))  ⇒  ∀y ψ(y)
```

Оскільки `ψ(0)` істинне і `ψ(y) → ψ(y + 1)` істинне для всіх `y ∈ ℕ`, за індукцією у `M` формула `∀y ψ(y)` мала б бути істинною для всіх елементів `M`, зокрема й нестандартних. Суперечність. ∎

**Теорема (Принцип Андерспілу / Недоливу):**
Якщо формула `ϕ(x)` істинна для довільно малих нестандартних чисел (тобто для кожного `H ∈ M \ ℕ` існує нестандартне `K ≤ H` таке, що `ϕ(K)`), то існує стандартне число `n ∈ ℕ`, для якого `ϕ(n)` істинне.

## 4. Повне доведення теореми Тенненбаума

Тепер наведемо строге доведення теореми Стенлі Тенненбаума (1959).

**Теорема Тенненбаума:**
Нехай `M ⊨ PA` — зліченна нестандартна модель арифметики Пеано. Не існує такої бієктивної кодувальної функції `n: M → ℕ`, щоб індуковані операції додавання `+_M` та множення `·_M` на натуральних числах:

```
x ⊕ y = n(n⁻¹(x) +_M n⁻¹(y))
x ⊗ y = n(n⁻¹(x) ·_M n⁻¹(y))
```

були обчислюваними (рекурсивними) функціями nad `ℕ`.

*Доведення (покроковий алгоритмічний вивід):*

[Крок 1] **Вибір рекурсивно невідокремлюваних множин:**
З теорії обчислюваності відомо, що існують дві рекурсивно перелічувані множини `A, B ⊂ ℕ`, які є диз'юнктними (`A ∩ B = ∅`) і рекурсивно невідокремлюваними. Це означає, що не існує жодної обчислювальної множини `C ⊂ ℕ`, такої що:

```
A ⊆ C  та  B ∩ C = ∅
```

[Крок 2] **Конструювання предикату кодування:**
Оскільки `A` та `B` рекурсивно перелічувані, існують обчислювальні предикати `R_A(i, s)` та `R_B(i, s)` без необмежених кванторів, такі що:

```
i ∈ A ⟺ ∃s R_A(i, s)
i ∈ B ⟺ ∃s R_B(i, s)
```

Оскільки `A ∩ B = ∅`, для кожного `i` не можуть одночасно виконуватися `∃s R_A(i, s)` та `∃s R_B(i, s)`.

[Крок 3] **Формулювання кодувального висловлювання в PA:**
Розглянемо прості числа `p₀ = 2, p₁ = 3, p₂ = 5, p₃ = 7, ...`, де `p_i` — `i`-те просте число. Функція `i ↦ p_i` є обчислюваною.
Для кожного натурального числа `x` визначимо предикат "просте `p_i` ділить `x`":

```
Div(i, x) ≡ ∃q (x = p_i · q)
```

В арифметиці `PA` доводиться теорема про існування числового коду для довільної скінченної послідовності бітів (за китайською теоремою про залишки або Ґьоделевою `β`-функцією).
Для кожного стандартного `n ∈ ℕ` існує число `x_n ∈ ℕ`, таке що для всіх `i < n`:

```
Div(i, x_n)  ⟺  i ∈ A
```

[Крок 4] **Застосування Оверспілу:**
Розглянемо формулу логіки першого порядку `ϕ(y)`, яка стверджує:

```
ϕ(y) ≡ ∃x ∀i < y [ (∃s < y R_A(i, s) → Div(i, x)) ∧ (∃s < y R_B(i, s) → ¬Div(i, x)) ]
```

Для кожного стандартного `n ∈ ℕ` формула `ϕ(n)` є істинною у стандартній моделі `ℕ` (оскільки для скінченної кількості елементів `i < n` ми завжди можемо підібрати таке `x`, яке ділиться на `p_i` для `i ∈ A` і не ділиться для `i ∈ B`).
Оскільки `M ⊨ PA`, формула `ϕ(n)` істинна у моделі `M` для всіх `n ∈ ℕ`.
За принципом Оверспілу, формула `ϕ` виливається в нестандартну частину моделі: існує нестандартний елемент `H ∈ M \ ℕ` та елемент `E ∈ M`, такі що для всіх стандартних `i ∈ ℕ`:

```
M ⊨ Div(i, E)   якщо  i ∈ A
M ⊨ ¬Div(i, E)  якщо  i ∈ B
```

[Крок 5] **Виведення суперечності з обчислюваністю:**
Припустимо, що операція множення `·_M` (або додавання `+_M`) у моделі `M` є обчислюваною над натуральними кодами.
Тоді предикат дільності `Div(i, E)` для фіксованого нестандартного елемента `E` виявиться алгоритмічно розв'язним для кожного стандартного числа `i ∈ ℕ`:

```
Div(i, E) ⟺ ∃q ∈ M (E = p_i ·_M q)
```

За теоремою про ділення з остачею в `PA`, предикат `p_i | E` перевіряється обчислювально, оскільки ми можемо алгоритмічно перебрати залишок від ділення `E` на `p_i` у моделі `M`.
Визначимо множину `C ⊂ ℕ`:

```
C = { i ∈ ℕ | M ⊨ Div(i, E) }
```

Якщо операція `·_M` обчислювана, то множина `C` є повністю обчислювальною підмножиною `ℕ`.
Проте за побудовою елемента `E`:
 - Якщо `i ∈ A`, то `M ⊨ Div(i, E)`, отже `i ∈ C` (`A ⊆ C`).
 - Якщо `i ∈ B`, то `M ⊨ ¬Div(i, E)`, отже `i ∉ C` (`B ∩ C = ∅`).

Отримали, що обчислювальна множина `C` розділяє рекурсивно невідокремлювані множини `A` та `B`. Це суперечить вибору множин `A` і `B`.

Отже, припущення про обчислюваність операцій `+_M` або `·_M` було хибним. Жодна нестандартна модель арифметики Пеано не може мати рекурсивного додавання або множення. ∎
