# 🧮 Математичні оцінки складності та лема монотонності алгоритму Дініца

Цей математичний аналіз містить строгі доведення фундаментальних властивостей алгоритму Дініца: леми про сувору монотонність відстаней між фазами, амортизаційної оцінки часу роботи однієї фази, зменшених меж складності для спеціальних класів мереж (одиничних місткостей та двочасткових паросполучень), техніки масштабування місткостей (Capacity Scaling) та теореми виділення мінімального розрізу.

## 1. Формальна модель мережі та рівневого графа

Нехай задано орієнтований граф `G = (V, E)` з множиною вершин `V`, множиною ребер `E`, виділеним джерелом `s ∈ V`, стоком `t ∈ V` та функцією пропускної спроможності `c: V × V → ℝ⁺`, де `c(u, v) = 0`, якщо `(u, v) ∉ E`.

Потоком у мережі називається функція `f: V × V → ℝ`, що задовольняє три аксіоми:
1. **Обмеження місткості:** `f(u, v) ≤ c(u, v)` для всіх `u, v ∈ V`.
2. **Антисиметричність:** `f(u, v) = -f(v, u)` для всіх `u, v ∈ V`.
3. **Збереження потоку:** для кожної вершини `u ∈ V \ {s, t}` виконується рівність:

```
∑ f(u, v) = 0   [сума потоків по всіх v ∈ V дорівнює нулю]
```

Для поточного потоку `f` залишкова пропускна спроможність ребра визначається як `c_f(u, v) = c(u, v) - f(u, v)`. Залишкова мережа `G_f = (V, E_f)` складається з ребер з додатною залишковою місткістю:

```
E_f = { (u, v) ∈ V × V : c_f(u, v) > 0 }
```

Позначимо через `dist_f(u, v)` найкоротшу відстань (кількість ребер) від `u` до `v` в незваженому графі `G_f`. Якщо шляху не існує, `dist_f(u, v) = ∞`. Для скорочення запису визначимо функцію рівня вершини як відстань від джерела: `d(v) = dist_f(s, v)`.

Рівневий граф (layered network) `G_L = (V, E_L)` визначається як підграф залишкової мережі `G_f`, що містить лише ребра, які з'єднують вершини суміжних рівнів у напрямку збільшення відстані:

```
E_L = { (u, v) ∈ E_f : d(v) = d(u) + 1 }
```

Потік `f_b` у графі `G_L` називається **блокуючим** (blocking flow), якщо будь-який орієнтований шлях від `s` до `t` в `G_L` містить хоча б одне ребро `(u, v) ∈ E_L`, на якому потік досягає повної залишкової місткості: `f_b(u, v) = c_f(u, v)`.

## 2. Лема про монотонність відстаней (Level Monotonicity Lemma)

Фундаментальна теорема Дініца стверджує, що оновлення потоку за допомогою блокуючого потоку в рівневому графі не може зменшити відстані від джерела до будь-якої вершини, а відстань до стоку суворо збільшується.

### Лема 1 (Слабке зростання відстаней до всіх вершин)
Нехай `f` — потік у мережі, `G_L` — відповідний рівневий граф, `f_b` — блокуючий потік у `G_L`, а `f' = f + f_b` — новий потік після проштовхування. Тоді для кожної вершини `v ∈ V` виконується нерівність:

```
dist_{f'}(s, v) ≥ dist_f(s, v)
```

**Доведення.** Проведемо індукцію за значенням `k = dist_{f'}(s, v)`.
- База індукції: для `k = 0` маємо `v = s`, тому `dist_{f'}(s, s) = 0 = dist_f(s, s)`. Нерівність виконується.
- Індукційний перехід: припустимо, що твердження доведено для всіх вершин з `dist_{f'}(s, u) < k`. Розглянемо довільну вершину `v` з `dist_{f'}(s, v) = k`.

Нехай `P` — найкоротший шлях від `s` до `v` в новій залишковій мережі `G_{f'}`, і нехай `(u, v)` — останнє ребро на цьому шляху. Тоді `dist_{f'}(s, u) = k - 1`. За індукційним припущенням:

```
dist_f(s, u) ≤ dist_{f'}(s, u) = k - 1
```

Розглянемо статус ребра `(u, v)` у попередній залишковій мережі `G_f`:

Випадок А: ребро `(u, v) ∈ E_f`. За визначенням найкоротшої відстані в `G_f`:
```
dist_f(s, v) ≤ dist_f(s, u) + 1
≤ (k - 1) + 1           [за індукційним припущенням для u]
= k                     [арифметичне спрощення]
= dist_{f'}(s, v)       [за визначенням k]
```

Випадок Б: ребро `(u, v) ∉ E_f`. Це означає, що ребро `(u, v)` з'явилося в залишковій мережі `G_{f'}` лише тому, що блокуючий потік проштовхнув потік у протилежному напрямку вздовж ребра `(v, u)` в `G_L`, тобто `f_b(v, u) > 0`.

Але ребро `(v, u)` могло належати `E_L` лише за умови, що воно вело на наступний рівень у `G_f`:
```
dist_f(s, u) = dist_f(s, v) + 1   [властивість ребер рівневого графа G_L]
```

Звідси виражаємо відстань до `v`:
```
dist_f(s, v) = dist_f(s, u) - 1   [перенесення доданка]
≤ (k - 1) - 1                     [підстановка індукційної оцінки для u]
= k - 2                           [спрощення]
< k = dist_{f'}(s, v)             [строга меншість]
```

В обох випадках `dist_f(s, v) ≤ dist_{f'}(s, v)`. Індукційний перехід доведено для всіх `v ∈ V`.

### Лема 2 (Строге збільшення відстані до стоку)
Якщо після проштовхування блокуючого потоку `f_b` стік `t` залишається досяжним з `s` у `G_{f'}`, то:

```
dist_{f'}(s, t) > dist_f(s, t)
```

**Доведення.** Від супротивного. Припустимо, що `dist_{f'}(s, t) ≤ dist_f(s, t)`. З Леми 1 ми вже знаємо, що `dist_{f'}(s, t) ≥ dist_f(s, t)`. Отже, має виконуватися точна рівність:

```
dist_{f'}(s, t) = dist_f(s, t) = L
```

Розглянемо найкоротший шлях `P = (v₀, v₁, v₂, ..., v_L)` від `s = v₀` до `t = v_L` у мережі `G_{f'}`. Довжина цього шляху дорівнює `L`. 

Для кожного ребра `(v_i, v_{i+1})` на шляху `P`:
1. За Лемою 1: `dist_f(s, v_i) ≤ dist_{f'}(s, v_i) = i` та `dist_f(s, v_{i+1}) ≤ dist_{f'}(s, v_{i+1}) = i + 1`.
2. Оскільки шлях у `G_f` від `s` до `t` через `(v_i, v_{i+1})` не може мати довжину менше `L`, для всіх `i` повинна виконуватися точна рівність `dist_f(s, v_i) = i`.
3. Це означає, що `dist_f(s, v_{i+1}) = dist_f(s, v_i) + 1`, тобто кожне ребро `(v_i, v_{i+1})` було допустимим ребром у рівневому графі `G_L` на попередньому кроці: `(v_i, v_{i+1}) ∈ E_L`.
4. Жодне ребро `(v_i, v_{i+1})` не могло бути зворотним ребром до ребра з `f_b > 0`, оскільки в такому разі, як доведено у Випадку Б Леми 1, відстань зменшилася б на 2, що неможливо для найкоротшого шляху довжини `L`.

Таким чином, весь шлях `P` складався виключно з ребер початкового рівневого графа `E_L`, і всі його ребра зберегли додатну залишкову місткість у `G_{f'}`.

Це означає, що на шляху `P` не було насичено жодного ребра: `f_b(v_i, v_{i+1}) < c_f(v_i, v_{i+1})` для всіх `i`. Але це суперечить визначенню блокуючого потоку `f_b`, який зобов'язаний наситити хоча б одне ребро на кожному шляху від `s` до `t` в `G_L`.

Отримане протиріччя доводить, що `dist_{f'}(s, t) ≥ dist_f(s, t) + 1`.

## 3. Теорема про кількість фаз

### Теорема 1 (Верхня межа кількості фаз)
Алгоритм Дініца завершує роботу не більше ніж за `|V| - 1` фазу.

**Доведення.** На першій фазі відстань `dist(s, t) ≥ 1`. Після кожної фази, в якій знайдено ненульовий блокуючий потік, відстань `dist(s, t)` збільшується щонайменше на 1. Найкоротший простий шлях у графі з `|V|` вершинами може містити максимум `|V| - 1` ребро.

Якщо відстань `dist(s, t) ≥ |V|`, це означає, що простого шляху не існує, отже, стік `t` недосяжний з джерела `s` у залишковій мережі `G_f`. За теоремою Форда — Фалкерсона досягнуто максимального потоку. Таким чином, кількість фаз із пошуком блокуючого потоку не перевищує `|V| - 1`.

## 4. Складність пошуку блокуючого потоку в одній фазі

У кожній фазі рівневий граф `G_L` є орієнтованим ациклічним графом (DAG). Пошук блокуючого потоку виконується за допомогою пошуку в глибину (DFS) зі збереженням вказівників на поточні невикористані ребра для кожної вершини — масиву `ptr[u]`.

### Аналіз операцій DFS з оптимізацією ptr:

Операції пошуку розбиваються на три неперетинні класи:
1. **Просування вперед (Advance):** перехід по допустимому ребру `(u, v) ∈ E_L`. Додає вершину до поточного шляху.
2. **Відступ назад (Retreat / Dead End):** якщо з поточної вершини `u` немає вихідних ребер з додатною місткістю до вершин наступного рівня, вершина `u` вилучається з розгляду до кінця поточної фази шляхом збільшення вказівника `ptr[u]`.
3. **Проштовхування (Augment):** досягнуто стік `t`. Обчислюється пляшкове горло `Δ = min c_f(e)` вздовж знайденого шляху `P`, потік збільшується на `Δ`, і всі ребра з `c_f(e) = 0` стають насиченими.

Підрахуємо сумарну кількість операцій кожного типу за всю фазу:

- **Кількість відступів (Retreats):** кожен відступ пересуває вказівник `ptr[u]` на наступне ребро у списку суміжності. Оскільки кожне ребро графа розглядається як тупикове не більше одного разу за фазу, сумарна кількість відступів обмежена кількістю ребер `|E|`. Вартість усіх відступів — `O(E)`.
- **Кількість проштовхувань (Augments):** кожне проштовхування насичує щонайменше одне критичне ребро на шляху. Оскільки насичене ребро має залишок `c_f = 0`, воно більше не використовується в поточній фазі. Отже, за одну фазу може відбутися не більше `|E|` операцій проштовхування. Довжина шляху в рівневому графі не перевищує `|V|`. Тому оновлення потоку вздовж шляху займає `O(V)` часу. Сумарний час усіх проштовхувань за фазу становить `|E| · O(V) = O(V · E)`.
- **Кількість просувань вперед (Advances):** кожне просування вперед або завершується відступом (Retreat), або є частиною успішного шляху до стоку (Augment). Отже, сумарна кількість просувань обмежена:

```
Кількість_Advances ≤ Кількість_Retreats + (Довжина_Шляху · Кількість_Augments)
≤ |E| + |V| · |E|       [підстановка меж для відступів та проштовхувань]
= O(V · E)              [асимптотичне домінування головного члена]
```

Сумарна складність однієї фази обчислюється як:

```
Час_фази = Час_BFS + Час_Retreats + Час_Augments + Час_Advances
= O(V + E) + O(E) + O(V · E) + O(V · E)   [підстановка складових]
= O(V · E)                                [підсумкова асимптотика фази]
```

Поєднуючи кількість фаз і час однієї фази, отримуємо загальну складність алгоритму Дініца:

```
Загальний_час = Кількість_фаз · Час_фази
≤ (|V| - 1) · O(V · E)   [підстановка меж кількості та часу фази]
= O(V² · E)              [загальна оцінка алгоритму Дініца]
```

## 5. Графи з одиничними пропускними спроможностями

Розглянемо мережі, де кожне ребро має одиничну пропускну спроможність: `c(e) = 1` для всіх `e ∈ E`.

У такій мережі кожне успішне проштовхування потоку вздовж шляху насичує **всі** ребра цього шляху. Отже, жодне ребро не може брати участь у двох різних операціях `Augment` в межах однієї фази. Це дає дві важливі властивості:
1. Час виконання однієї фази становить суворо `O(E)`.
2. Загальна кількість фаз скорочується завдяки швидкому зростанню відстаней.

### Теорема 2 (Оцінка через кількість вершин)
Для мережі з одиничними ребрами кількість фаз алгоритму Дініца обмежена `O(V^(2/3))`.

**Доведення.** Нехай алгоритм виконав `k` фаз. Відстань від `s` до `t` у поточній залишковій мережі `G_f` становить `d = dist_f(s, t) ≥ k`.
Розглянемо розбиття вершин на шари `V_i = { v ∈ V : dist_f(s, v) = i }` для `i = 0, 1, ..., d`.

Оскільки всі множини `V_i` попарно не перетинаються, сума їхніх розмірів дорівнює:
```
∑ |V_i| ≤ |V|   [сума по i від 0 до d]
```

За принципом Діріхле, серед `d` шарів існують два сусідніх шари `V_p` та `V_{p+1}`, добуток розмірів яких не перевищує `(|V| / d)²`. Кількість ребер між шарами `V_p` та `V_{p+1}` у залишковій мережі обмежена величиною `|V_p| · |V_{p+1}|`.

Множина ребер між `V_p` та `V_{p+1}` утворює розріз, що відділяє `s` від `t`. Отже, за теоремою про максимальний потік і мінімальний розріз, величина залишкового максимального потоку `|f* - f|` не перевищує пропускної спроможності цього розрізу:

```
|f* - f| ≤ |V_p| · |V_{p+1}| ≤ (2 · |V| / k)²
```

Оскільки кожна наступна фаза збільшує потік щонайменше на 1, кількість фаз, що залишилися, не перевищує `|f* - f| ≤ 4 · |V|² / k²`.
Загальна кількість фаз обмежена сумою:

```
Фази_разом ≤ k + 4 · |V|² / k²
```

Мінімізуючи цю функцію вибором `k = |V|^(2/3)`, отримуємо:

```
Фази_разом = |V|^(2/3) + 4 · |V|² / (|V|^(2/3))²
= |V|^(2/3) + 4 · |V|^(2/3)   [спрощення степенів: 2 - 4/3 = 2/3]
= O(V^(2/3))                  [асимптотична межа кількості фаз]
```

Звідси загальний час роботи: `O(E · V^(2/3))`.

### Теорема 3 (Оцінка через кількість ребер)
Для мережі з одиничними ребрами кількість фаз обмежена `O(E^(1/2))`.

**Доведення.** Нехай після `k` фаз відстань `dist_f(s, t) ≥ k`. Залишковий максимальний потік `|f* - f|` можна декомпонувати на `M = |f* - f|` реберно-неперетинних шляхів у залишковій мережі.
Кожен такий шлях має довжину щонайменше `k` ребер. Оскільки всі ребра мають одиничну місткість і шляхи не перетинаються по ребрах, загальна кількість ребер у цих шляхах не перевищує загальної кількості ребер графа:

```
M · k ≤ |E|   [сумарна кількість ребер у M шляхах довжини ≥ k]
```

Звідси величина залишкового потоку:

```
M = |f* - f| ≤ |E| / k
```

Загальна кількість фаз обмежена величиною `k + M ≤ k + |E| / k`. Обираючи `k = √|E|}`, маємо:

```
Фази_разом ≤ √|E| + |E| / √|E|
= 2 · √|E|   [додавання однакових доданків]
= O(√E)      [асимптотична межа]
```

Поєднуючи обидва результати, отримуємо строгу складність для одиничних ребер:

```
Час_Unit_Networks = O(E · min(V^(2/3), E^(1/2)))
```

## 6. Одиничні мережі та двочасткове паросполучення

Одиничною мережею (Unit Network) називається мережа, в якій кожна вершина `v ∈ V \ {s, t}` задовольняє одну з двох умов:
1. `deg_{in}(v) ≤ 1` (максимум одне вхідне ребро з місткістю 1);
2. `deg_{out}(v) ≤ 1` (максимум одне вихідне ребро з місткістю 1).

Класичним представником одиничних мереж є редукція задачі про максимальне паросполучення в двочастковому графі `G = (L ∪ R, E_b)`:
- Джерело `s` з'єднується з кожною вершиною `u ∈ L` ребром місткості 1 (`deg_{in}(u) = 1`).
- Кожна вершина `w ∈ R` з'єднується зі стоком `t` ребром місткості 1 (`deg_{out}(w) = 1`).
- Усі ребра між `L` та `R` мають місткість 1 і спрямовані від `L` до `R`.

### Властивість вершинної неперетинності шляхів
В одиничній мережі будь-які два шляхи з додатним потоком у залишковій мережі є **вершинно-неперетинними** (за винятком джерела `s` та стоку `t`).

Якщо після `k` фаз залишковий максимальний потік дорівнює `M = |f* - f|`, його можна розкласти на `M` вершинно-неперетинних шляхів, кожен з яких містить щонайменше `k` вершин. Оскільки загальна кількість вершин дорівнює `|V|`:

```
M · k ≤ |V|   [сума вершин на M шляхах не перевищує |V|]
```

Звідси залишковий потік обмежений:
```
M ≤ |V| / k
```

Загальна кількість фаз алгоритму Дініца на одиничній мережі становить:
```
Фази ≤ k + |V| / k
```

Обираючи `k = √|V|`, отримуємо максимум `2 · √|V|` фаз. Оскільки час виконання однієї фази в одиничній мережі становить `O(E)`, сумарний час роботи дорівнює:

```
Час_Паросполучення = (2 · √|V|) · O(E)
= O(E · √V)   [складність алгоритму Гопкрофта — Карпа]
```

Це строго доводить, що алгоритм Гопкрофта — Карпа для двочасткових графів є безпосереднім наслідком алгоритму Дініца на одиничних мережах без жодних модифікацій базової логіки алгоритму.

## 7. Модифікація з масштабуванням місткостей (Capacity Scaling)

Якщо пропускні спроможності ребер є довільними цілими числами, обмеженими значенням `U = max c(e)`, класичний алгоритм Дініца можна прискорити за допомогою бітового масштабування (Capacity Scaling).

Ідея полягає у введенні масштабного коефіцієнта `Δ = 2^⌊log₂ U⌋`, який на кожному етапі ділиться на 2. На кожному масштабному кроці `Δ` алгоритм Дініца запускається лише на підграфі `Δ`-залишкової мережі:

```
E_f(Δ) = { (u, v) ∈ E_f : c_f(u, v) ≥ Δ }
```

### Складність масштабованого алгоритму Дініца:
1. **Кількість масштабних етапів:** оскільки початкове `Δ ≤ U`, а кінцеве `Δ = 1`, кількість етапів становить `⌊log₂ U⌋ + 1 = O(log U)`.
2. **Кількість фаз на одному масштабному кроці:** на початку етапу `Δ` залишковий потік від попереднього етапу `2Δ` обмежений величиною `2 · |E| · Δ`. Оскільки кожна фаза з параметром `Δ` проштовхує шлях місткістю щонайменше `Δ`, на поточному етапі алгоритм Дініца виконує не більше `O(V)` рівневих фаз.
3. **Час одного етапу:** `O(V) · O(E) = O(V · E)`.

Підсумкова оцінка складності масштабованого алгоритму Дініца:

```
Час_Scaling = Кількість_етапів · Час_етапу
= O(log U) · O(V · E)   [добуток кількості етапів на час одного етапу]
= O(V · E · log U)      [загальна оцінка для цілочисельних місткостей]
```

Цей результат усуває слабку залежність від щільності графа на мережах із помірними цілими пропускними спроможностями.

## 8. Виділення мінімального s-t розрізу

З фундаментальної теореми Форда — Фалкерсона випливає, що величина максимального потоку дорівнює пропускній спроможності мінімального розрізу: `max val(f) = min cap(S, T)`.

Після завершення роботи алгоритму Дініца, коли стік `t` стає недосяжним у залишковій мережі `G_f` (тобто `dist_f(s, t) = ∞`), мінімальний розріз `(S, T)` виділяється за один лінійний прохід BFS/DFS:
- Множина `S` складається з усіх вершин `u ∈ V`, досяжних з джерела `s` у фінальній залишковій мережі `G_f`: `S = { u ∈ V : dist_f(s, u) < ∞ }`.
- Множина `T = V \ S` містить усі недосяжні вершини, включаючи стік `t`.

### Доведення мінімальності розрізу:
Для кожного ребра `(u, v) ∈ E`, де `u ∈ S` та `v ∈ T`:
1. Залишкова місткість `c_f(u, v) = 0`, інакше вершина `v` була б досяжною з `u` в `G_f`, що суперечило б належності `v ∈ T`.
2. Це означає, що прямий потік через ребро повністю насичує його початкову місткість: `f(u, v) = c(u, v)`.
3. Для кожного зворотного ребра `(w, z) ∈ E`, де `w ∈ T` та `z ∈ S`, потік `f(w, z) = 0`, інакше залишкова місткість `c_f(z, w) = f(w, z) > 0` створила б ребро `(z, w) ∈ E_f`, що зробило б `w` досяжною з `S`.

Сумарний потік через розріз дорівнює:
```
val(f) = ∑_{u ∈ S, v ∈ T} f(u, v) - ∑_{w ∈ T, z ∈ S} f(w, z)
= ∑_{u ∈ S, v ∈ T} c(u, v) - 0   [підстановка f(u,v) = c(u,v) та f(w,z) = 0]
= cap(S, T)                      [за визначенням місткості розрізу]
```

Оскільки величина будь-якого допустимого потоку ніколи не перевищує пропускну спроможність довільного розрізу (`val(f) ≤ cap(S', T')`), досягнення точної рівності `val(f) = cap(S, T)` строго доводить, що знайдений потік є глобально максимальним, а розріз `(S, T)` — мінімальним.
