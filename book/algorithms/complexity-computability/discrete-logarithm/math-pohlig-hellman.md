# 𝔮 Математичний апарат алгоритмів дискретного логарифмування

Вставка викладає строгий математичний апарат, алгебраїчні доведення, теореми, алгоритмічні редукції та аналітичні оцінки складності для проблеми дискретного логарифма (DLP). Документ охоплює фундаментальну теорему декомпозиції Поліґа — Геллмана, комбінаторну тотожність алгоритму «Крок немовляти — крок велетня» (BSGS), імовірнісну теорію колізій `ρ`-алгоритму Полларда на основі парадоксу днів народження, а також аналітичний апарат методу індексу факторів та функції гладкості Дікмана.

## 1. Алгебраїчний фундамент та ізоморфізм скінченних груп

Нехай `G` — скінченна циклічна група порядку `N = |G|`, записана мультиплікативно. За означенням циклічної групи, у `G` існує принаймні один твірний елемент (генератор) `g ∈ G`, послідовні степені якого вичерпують усю множину елементів групи:

```
G = ⟨g⟩ = {g⁰, g¹, g², ..., gᴺ⁻¹}    [циклічна група порядку N]
```

Число генераторів у циклічній групі порядку `N` дорівнює значенню функції Ейлера `φ(N)`.

Для довільного елемента `y ∈ G` **проблема дискретного логарифма** полягає у знаходженні єдиного значення `x` у кільці залишків `ℤ_N = {0, 1, ..., N - 1}`, яке задовольняє групове рівняння:

```
gˣ = y      [основне рівняння DLP]
```

### Теорема про груповий ізоморфізм
Відображення `f: ℤ_N → G`, задане формулою `f(x) = gˣ`, встановлює строгий **ізоморфізм груп** між аддитивною групою залишків `(ℤ_N, +)` та мультиплікативною групою `(G, ·)`.

*Доведення.*
1. **Гомоморфізм:** Для довільних `a, b ∈ ℤ_N`:
   ```
   f(a + b mod N) = g^{a + b mod N} = g^{a + b} = gᵃ · gᵇ = f(a) · f(b)
   ```
   оскільки порядок елемента `g` дорівнює `N`, і `gᴺ = 1`.
2. **Сюрективність:** Оскільки `g` — генератор групи `G`, для будь-якого `y ∈ G` існує `x ∈ ℤ_N` такий, що `gˣ = y`.
3. **Ін'єктивність:** Якщо `f(a) = f(b)`, тобто `gᵃ = gᵇ`, то `g^{a - b} = 1`. Оскільки `N` — найменший додатний степінь, для якого `gᴺ = 1`, різниця `a - b` мусить ділитися на `N`, отже `a ≡ b (mod N)`.

Знаходження дискретного логарифма є операцією обчислення оберненого ізоморфізму `f⁻¹(y) = log_g y`. Хоча прямому ізоморфізму `f(x) = gˣ` відповідає швидкий алгоритм піднесення до степеня за час `O(log N)`, обернене відображення `f⁻¹` у загальному випадку не має відомого класичного алгоритму поліноміальної складності.

## 2. Математична теорема та декомпозиція Поліґа — Геллмана

Алгоритм Поліґа — Геллмана показує, що складності розв'язання DLP у групі `G` визначаються розміром її найзапеклішого простого дільника порядку.

### 2.1. Теорема про декомпозицію
Нехай порядок групи `N = |G|` розкладається на прості множники:

```
N = p₁ᵉ¹ · p₂ᵉ² · ... · pₖᵉnk      [канонічний розклад N]
```

Тоді обчислення `x = log_g y mod N` строго еквівалентне обчисленню залишків `xᵢ = x mod pᵢᵉⁱ` для кожного `i ∈ {1, ..., k}` з подальшим об'єднанням результатів за Китайською теоремою про лишки (CRT).

### 2.2. Покроковий вивід p-адичних цифр

Розглянемо один із простих дільників `p = pᵢ` з показником степеня `e = eᵢ`. Наша мета — обчислити значення `x mod pᵉ`. Представимо `x mod pᵉ` у вигляді `p`-адичного розкладу:

```
x mod pᵉ = z₀ + z₁·p + z₂·p² + ... + zₑ₋₁·pᵉ⁻¹    [де 0 ≤ zⱼ < p]
```

#### Крок 1: Обчислення наймолодшої цифри z₀
Піднесемо початкове рівняння `gˣ = y` до степеня `N / p`:

```
(gˣ)^{N/p} = y^{N/p}
```

Запишемо `x` у вигляді `x = z₀ + p · K`, де `K` — деяке ціле число. Підставимо цей вираз:

```
g^{(z₀ + p·K) · (N/p)} = y^{N/p}
g^{z₀·(N/p) + K·N} = y^{N/p}
(g^{N/p})^{z₀} · (gᴺ) K = y^{N/p}
```

Оскільки `gᴺ = 1`, другий множник дорівнює 1. Позначивши `g' = g^{N/p}` та `y' = y^{N/p}`, отримуємо рівняння у підгрупі порядку `p`:

```
(g')^{z₀} = y'      [DLP у підгрупі простого порядку p]
```

Оскільки порядок елемента `g'` дорівнює `p` (бо `(g')ᵖ = gᴺ = 1`), значення `z₀` можна знайти універсальним алгоритмом (BSGS або Pollard's Rho) у межах підгрупи порядку `p` за час `O(√p)`.

#### Крок 2: Обчислення наступних цифр z₁, z₂, ...
Після знаходження `z₀` сформуємо новий цільовий елемент `y₁ = y · g^{-z₀}`. Рівняння набуває вигляду:

```
g^{x - z₀} = y₁
```

Оскільки `x - z₀ = z₁·p + z₂·p² + ...`, піднесемо обидві частини до степеня `N / p²`:

```
(g^{N/p})^{z₁} = (y₁)^{N/p²}
```

Це знову дає рівняння відносно невідомого `z₁` у підгрупі порядку `p`. Повторюючи цей процес `e` разів, ми обчислюємо всі цифри `z₀, z₁, ..., zₑ₋₁` і повністю відновлюємо `x mod pᵉ`.

### 2.3. Реконструкція за Китайською теоремою про лишки (CRT)
Отримавши систему з `k` порівнянь:

```
x ≡ x₁ (mod p₁ᵉ¹)
x ≡ x₂ (mod p₂ᵉ²)
...
x ≡ xₖ (mod pₖᵉnk)
```

значення `x mod N` відновлюється єдиним чином за формулою:

```
x = ∑ (xᵢ · Mᵢ · Mᵢ⁻¹ mod pᵢᵉⁱ) mod N    [формула CRT]
```

де `Mᵢ = N / pᵢᵉⁱ`, а `Mᵢ⁻¹` — модульне обернене до `Mᵢ` за модулем `pᵢᵉⁱ` (тобто `Mᵢ · Mᵢ⁻¹ ≡ 1 (mod pᵢᵉⁱ)`).

### 2.4. Сумарна складність
Для кожного дільника `pᵢᵉⁱ` виконується `eᵢ` кроків, кожен з яких вимагає розв'язання DLP у групі порядку `pᵢ` за час `O(√pᵢ)`. Сумарна складність Поліґа — Геллмана дорівнює:

```
O(∑ eᵢ · (log N + √pᵢ))    [асимптотична оцінка Поліґа — Геллмана]
```

Якщо всі дільники `pᵢ` є малими (порядок `N` є гладким), складність стає поліноміальною відносно `log N`.

## 3. Математичний апарат алгоритму Shanks BSGS

Алгоритм «Крок немовляти — крок велетня» (Baby-Step Giant-Step) є універсальним детермінованим алгоритмом.

### 3.1. Доведення повноти та коректності
Покладемо `m = ⌈√N⌉`. Розглянемо множину чисел `S = {i·m - j | 1 ≤ i ≤ m, 0 ≤ j < m}`.

*Лема.* Множина `S` покриває всі цілі числа від `0` до `m² - 1`. Оскільки `m² ≥ N`, множина `S` гарантовано містить шуканий логарифм `x ∈ {0, 1, ..., N - 1}`.

*Доведення.* Для довільного `x` розділимо `x` на `m` із остачею. Нехай `x = q·m + r`, де `0 ≤ r < m` та `0 ≤ q < m`.
Запишемо це у формі `x = (q + 1)·m - (m - r)`.
Позначивши `i = q + 1` (тоді `1 ≤ i ≤ m`) та `j = m - r` (тоді `1 ≤ j ≤ m`), ми отримали потрібне представлення `x = i·m - j`.

Підставляючи `x = i·m - j` у рівняння `gˣ = y`, маємо:

```
g^{i·m - j} = y  ⇒  g^{i·m} · g^{-j} = y  ⇒  g^{i·m} = y · gʲ    [тотожність BSGS]
```

### 3.2. Комбінаторні оцінки
- Кількість елементів у хеш-таблиці baby steps `(y · gʲ)` дорівнює `m = ⌈√N⌉`.
- Кількість кроків у циклі giant steps `(gᵐ)ⁱ` дорівнює `m = ⌈√N⌉`.
- Сумарна кількість групових множень: `2 · ⌈√N⌉ = O(√N)`.
- Необхідний обсяг оперативної пам'яті: `m · sizeof(entry) = O(√N)`.

## 4. Імовірнісна теорія колізій в алгоритмі Pollard's Rho

`ρ`-алгоритм Полларда моделює псевдовипадкове блукання у скінченній множині `G` для знаходження колізії двох траєкторій.

### 4.1. Аналіз парадоксу днів народження
Нехай `G` — скінченна множина з `N` елементів. Виберемо послідовно та незалежно `k` випадкових елементів `w₁, w₂, ..., w_k ∈ G`. Ймовірність того, що всі `k` елементів є попарно різними, дорівнює:

```
P_diff(k) = ∏ (1 - (j - 1)/N)  [для j від 1 до k]
```

Застосовуючи наближення `1 - x ≈ exp(-x)` для малих `x`:

```
P_diff(k) ≈ ∏ exp(-(j - 1)/N) = exp(- ∑ (j - 1)/N) = exp(- k·(k - 1) / (2N))
```

Отже, ймовірність виникнення принаймні однієї колізії `P_coll(k) = 1 - P_diff(k)` досягає `50%` (`P_coll ≈ 0.5`) при:

```
exp(- k² / (2N)) = 0.5  ⇒  k² / (2N) = ln 2  ⇒  k = √(2 ln 2 · N) ≈ 1.177 · √N
```

Таким чином, математичне сподівання кількості кроків до виникнення колізії становить `O(√N)`.

### 4.2. Алгоритм Флойда та розв'язання колізійного рівняння
Для пошуку колізії без збереження траєкторії в пам'яті будуються дві послідовні точки: «черепаха» `W_k` та «заєць» `W_{2k}`. Оскільки траєкторія у скінченній множині неминуче утворює цикл (структуру у формі грецької літери `ρ`), «заєць» обов'язково наздожене «черепаху» всередині циклу за час, що не перевищує довжину хвоста плюс довжину циклу (`O(√N)` кроків).

У момент збігу `W_k = W_{2k}` маємо тотожність:

```
g^{a_k} · y^{b_k} = g^{a_{2k}} · y^{b_{2k}}
```

Оскільки `y = gˣ`, підставимо `y`:

```
g^{a_k + x·b_k} = g^{a_{2k} + x·b_{2k}}
a_k + x·b_k ≡ a_{2k} + x·b_{2k} (mod N)
(b_k - b_{2k}) · x ≡ a_{2k} - a_k (mod N)
```

Позначивши `Δb = (b_k - b_{2k}) mod N` та `Δa = (a_{2k} - a_k) mod N`, маємо лінійне порівняння:

```
Δb · x ≡ Δa (mod N)    [основне колізійне рівняння]
```

Якщо `НСД(Δb, N) = 1`, рівняння має єдиний розв'язок: `x = Δa · (Δb⁻¹ mod N) mod N`.

Якщо `d = НСД(Δb, N) > 1`, рівняння має `d` можливих розв'язків у `ℤ_N`. Для малих `d` можна перебрати всі `d` кандидатів `x′ = (Δa / d) · (Δb / d)⁻¹ + m · (N / d)` і перевірити умову `g^{x′} = y`. Якщо `d` велике, виконання перезапускається з новими випадковими початковими станами `a₀, b₀`.

## 5. Субекспоненціальний апарат Index Calculus та функція Дікмана

Аналітичний апарат субекспоненціальних алгоритмів спирається на теорію **гладких чисел**.

### 5.1. Поняття S-гладкості та функція Дікмана
Ціле число `n` називається **`B`-гладким**, якщо всі його прості множники не перевищують межу `B` (тобто якщо `n = ∏ pᵢᵉⁱ`, то всі `pᵢ ≤ B`).

Ймовірність того, що випадково обране ціле число `n ≤ x` є `B`-гладким, описується **функцією Дікмана — Де Брьойна** `ρ(u)`:

```
Ψ(x, B) / x ≈ ρ(u)    [де u = ln x / ln B]
```

Функція `ρ(u)` задовольняє диференціально-різницеве рівняння `u · ρ′(u) + ρ(u - 1) = 0` і для великих `u` має асимптотику:

```
ρ(u) = exp(- u · (ln u + ln ln u - 1 + o(1)))    [асимптотика Дікмана]
```

### 5.2. Вивід оптимуму L-нотації
При генерації співвідношень у полях `𝔽ₚ*` ми шукаємо `S`-гладкі числа серед елементів `v = gᵏ mod p < p`.
Тут `x = p`, параметр `u = ln p / ln B`.

Час генерації одного співвідношення дорівнює `1 / ρ(u)`. Щоб знайти `|S| = B / ln B` незалежних співвідношень для розв'язання системи САРР з `B` невідомими, загальний час генерації становить:

```
T_gen ≈ B · (1 / ρ(u)) = B · exp(u · ln u)
```

Час розв'язання системи лінійних рівнянь розміром `B × B` методами розрідженої алгебри становить `T_lin ≈ B²`.

Оптимальна межа `B` вибирається з умови балансу витрат часу `T_gen ≈ T_lin`:

```
B² = B · exp(u · ln u)  ⇒  B = exp(u · ln u)
```

Підставляючи `u = ln p / ln B` та приймаючи `ln B = c · √(ln p · ln ln p)`, отримуємо оптимальне значення `c = 1/√2` і підсумкову субекспоненціальну складність:

```
Lₚ[1/2, 1] = exp((1 + o(1)) · √(ln p · ln ln p))    [субекспоненціальна межа Index Calculus]
```

Цей аналіз показує фундаментальну відмінність: у той час як універсальні алгоритми типу Pollard's Rho вимагають експоненціальної кількості кроків від довжини бітів модуля `O(2^{b/2})`, алгоритми індексу факторів у полях `𝔽ₚ*` зменшують ростіть складності до субекспоненціального рівня завдяки високій щільності гладких чисел.
