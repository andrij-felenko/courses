# 🧮 Алгебраїчний гомоморфізм, фундаментальні послідовності та теорема збігу

Математична теорія повільнозростаючої ієрархії встановлює точний міст між синтаксичною структурою трансфінітних ординалів та числовими функціями обчислювальної складності. На відміну від швидкозростаючої ієрархії, яка на кожному кроці здійснює агресивну діагоналізацію, повільнозростаюча ієрархія будується на найпростішій операції інкременту, що дозволяє дослідити тонку мікроструктуру обчислень.

Цей математичний розбір містить вичерпні формальні доведення трьох фундаментальних результатів теорії: теореми про алгебраїчний гомоморфізм Кантора для ординалів нижче `ε₀`, класифікації поведінки ієрархії на шкалі функцій Веблена до ординала Фефермана — Шютте `Γ₀`, а також механізму теореми Жірара про наздоганяння через колапс незліченних ординалів.

## Аксіоматична система та властивості монотонності

Повільнозростаюча ієрархія (англ. *Slow-Growing Hierarchy*, SGH) визначається як родина одномісних числових функцій `(G_α)_{α < µ}`, де ординальний індекс `α` належить до множини зліченних трансфінітних ординалів, а аргумент `n` є додатним натуральним числом (`n ∈ ℕ, n ≥ 1`).

Система базується на трьох рекурсивних аксіомах:

```
G₀(n) = 0
G_{α + 1}(n) = G_α(n) + 1
G_λ(n) = G_{λ[n]}(n)
```

де `λ` — довільний граничний ординал, а `(λ[n])_{n ∈ ℕ}` — канонічна фундаментальна послідовність менших ординалів, для якої виконується умова топологічної збіжності:

```
sup { λ[n] | n ∈ ℕ } = λ
```

Перш ніж переходити до алгебраїчних властивостей, встановимо строгі теореми про монотонність повільнозростаючих функцій.

**Теорема 1 (Строга монотонність за аргументом).** Для будь-якого фіксованого ординала `α > 0` та будь-яких натуральних чисел `1 ≤ n < m` виконується строга числова нерівність:
```
G_α(n) < G_α(m)
```
за умови, що фундаментальні послідовності задовольняють канонічну умову строгого зростання `λ[n] < λ[m]`.

*Доведення (за трансфінітною індукцією по α).*

1. **Базовий трансфінітний крок (`α = 1`):**
Для `α = 1 = 0 + 1` за аксіомою ординала-наступника маємо `G₁(n) = G₀(n) + 1 = 0 + 1 = 1`. Для всіх наступних скінченних ординалів `k` значення залишається константою `G_k(n) = k`.

2. **Граничний ординал `α = ω`:**
За канонічним правилом фундаментальної послідовності `ω[n] = n`. Тоді:
```
G_ω(n)
= G_{ω[n]}(n)      [аксіома граничного кроку]
= G_n(n)           [підстановка фундаментальної послідовності]
= n                [властивість скінченних ординалів]
```
Оскільки `n < m`, очевидно, що `G_ω(n) = n < m = G_ω(m)`.

3. **Індукційний перехід для ординала-наступника (`α = β + 1`):**
Припустимо, що для `β` строга монотонність уже доведена: `G_β(n) < G_β(m)`. Тоді:
```
G_{β + 1}(n)
= G_β(n) + 1       [аксіома наступника]
< G_β(m) + 1       [за індукційним припущенням]
= G_{β + 1}(m)     [аксіома наступника]
```
Нерівність зберігається.

4. **Індукційний перехід для граничного ординала (`α = λ`):**
Оскільки `n < m`, за умовою канонічності маємо `λ[n] < λ[m]`. Тоді:
```
G_λ(n)
= G_{λ[n]}(n)      [аксіома граничного кроку]
≤ G_{λ[n]}(m)      [за індукційним припущенням за аргументом]
< G_{λ[m]}(m)      [за індукційним припущенням за ординальним індексом]
= G_λ(m)           [аксіома граничного кроку]
```
Отже, функція `G_α(n)` є строго зростаючою за числовим аргументом для всіх `α ≥ ω`.

## Нормальна форма Кантора та фундаментальні послідовності

Кожен ненульовий ординал `α < ε₀` має єдиний канонічний розклад у нормальній формі Кантора (англ. *Cantor Normal Form*, CNF):

```
α = ω^(β₁) · c₁ + ω^(β₂) · c₂ + ... + ω^(βₘ) · cₘ
```
де `β₁ > β₂ > ... > βₘ ≥ 0` — строго спадний ланцюг ординалів у формі Кантора, а коефіцієнти `c₁, ..., cₘ` — додатні натуральні числа.

Якщо найменший показник `βₘ = 0`, ординал є наступником (`α = γ + 1`). Якщо `βₘ > 0`, ординал є граничним (`α = λ`), і його фундаментальна послідовність `λ[n]` визначається рекурсивно за молодшим доданком:

1. **Випадок `βₘ = 1` та `cₘ = 1` (доданок `ω`):**
```
λ[n] = ω^(β₁) · c₁ + ... + ω^(βₘ₋₁) · cₘ₋₁ + n
```

2. **Випадок `βₘ = γ + 1` (показник є наступником):**
```
(ω^(γ + 1))[n] = ω^γ · n
λ[n] = ω^(β₁) · c₁ + ... + ω^(βₘ) · (cₘ - 1) + ω^γ · n
```

3. **Випадок `βₘ = δ` (показник є граничним ординалом `δ`):**
```
(ω^δ)[n] = ω^(δ[n])
λ[n] = ω^(β₁) · c₁ + ... + ω^(βₘ) · (cₘ - 1) + ω^(δ[n])
```

## Теорема про алгебраїчний гомоморфізм Кантора

Центральною теоремою повільнозростаючої ієрархії на множині ординалів нижче `ε₀` є теорема про точний алгебраїчний гомоморфізм, яка перетворює трансфінітний аналіз на шкільну алгебру поліномів.

**Теорема 2 (Гомоморфізм оцінки Кантора).** Нехай ординал `α < ε₀` подано у нормальній формі Кантора:
```
α = ω^(β₁) · c₁ + ω^(β₂) · c₂ + ... + ω^(βₘ) · cₘ
```
Тоді для довільного цілого аргументу `n ≥ 1` значення повільнозростаючої функції `G_α(n)` точно дорівнює результату заміни змінної `ω` на число `n`:
```
G_α(n) = n^(G_{β₁}(n)) · c₁ + n^(G_{β₂}(n)) · c₂ + ... + n^(G_{βₘ}(n)) · cₘ
```

*Доведення (за повною трансфінітною індукцією по структурі терма α).*

1. **Адитивна властивість:**
Доведемо, що для будь-яких ординалів `α` та `β` у формі Кантора виконується:
```
G_{α + β}(n) = G_α(n) + G_β(n)
```
Якщо `β = 0`, рівність тривіальна: `G_{α + 0}(n) = G_α(n) + 0`.
Якщо `β = γ + 1`, то за аксіомою наступника:
```
G_{α + (γ + 1)}(n)
= G_{(α + γ) + 1}(n)               [асоціативність додавання ординалів]
= G_{α + γ}(n) + 1                 [аксіома наступника]
= G_α(n) + G_γ(n) + 1              [за припущенням індукції для γ]
= G_α(n) + G_{γ + 1}(n)            [аксіома наступника для β]
```
Якщо `β = λ` — граничний ординал, то за канонічною властивістю фундаментальних послідовностей `(α + λ)[n] = α + λ[n]`. Тоді:
```
G_{α + λ}(n)
= G_{(α + λ)[n]}(n)                [аксіома граничного кроку]
= G_{α + λ[n]}(n)                  [властивість фундаментальної послідовності]
= G_α(n) + G_{λ[n]}(n)             [за припущенням індукції для меншого ординала λ[n]]
= G_α(n) + G_λ(n)                  [аксіома граничного кроку для λ]
```
Адитивність доведено для всіх ординалів.

2. **Мультиплікативна властивість для скінченних множників:**
Доведемо, що `G_{α · k}(n) = G_α(n) · k` для будь-якого натурального `k ∈ ℕ`.
Для `k = 1` рівність очевидна. Для `k + 1`:
```
G_{α · (k + 1)}(n)
= G_{α · k + α}(n)                 [означення множення ординалів справа]
= G_{α · k}(n) + G_α(n)            [за доведеною адитивністю]
= G_α(n) · k + G_α(n)              [за припущенням індукції по k]
= G_α(n) · (k + 1)                 [дистрибутивність у кільці цілих чисел]
```

3. **Множення на ω:**
Розглянемо випадок `α · ω`. За означенням фундаментальної послідовності `(α · ω)[n] = α · n`.
Застосуємо граничну аксіому:
```
G_{α · ω}(n)
= G_{(α · ω)[n]}(n)                [аксіома граничного кроку]
= G_{α · n}(n)                     [значення фундаментальної послідовності]
= G_α(n) · n                       [за щойно доведеним множенням на скінченне число]
```
Отже, ординальне множення на `ω` справа відповідає числовому множенню на аргумент `n`.

4. **Степенева властивість:**
Доведемо, що `G_{ω^β}(n) = n^(G_β(n))`.
- Якщо `β = 0`, маємо `ω⁰ = 1`, `G₁(n) = 1 = n⁰ = n^(G₀(n))`.
- Якщо `β = γ + 1`, фундаментальна послідовність має вигляд `(ω^(γ + 1))[n] = ω^γ · n`.
Тоді:
```
G_{ω^(γ + 1)}(n)
= G_{ω^γ · n}(n)                   [аксіома граничного кроку]
= G_{ω^γ}(n) · n                   [за властивістю множення на константу]
= (n^(G_γ(n))) · n                 [за індукційним припущенням для β = γ]
= n^(G_γ(n) + 1)                   [алгебра степенів цілих чисел]
= n^(G_{γ + 1}(n))                 [аксіома наступника G_{γ+1}(n) = G_γ(n) + 1]
```
- Якщо `β = δ` — граничний ординал, то `(ω^δ)[n] = ω^(δ[n])`.
Тоді:
```
G_{ω^δ}(n)
= G_{ω^(δ[n])}(n)                  [аксіома граничного кроку]
= n^(G_{δ[n]}(n))                  [за припущенням індукції для меншого δ[n]]
= n^(G_δ(n))                       [означення G_δ(n) для граничного кроку]
```

Об'єднуючи пункти 1, 2 та 4, отримуємо повну формулу гомоморфізму:
```
G_α(n) = ∑_{i=1}^{m} n^(G_{βᵢ}(n)) · cᵢ
```
Теорему доведено повністю.

## Повний розбір прикладів обчислення поліноміальних та суперекспоненціальних рівнів

Застосуємо теорему про гомоморфізм до конкретних ординалів для ілюстрації її практичної дії:

**Приклад 1 (Поліноміальний рівень `α = ω³ · 2 + ω² · 5 + 7` при `n = 3`):**
```
G_{ω³ · 2 + ω² · 5 + 7}(3)
= G_{ω³}(3) · 2 + G_{ω²}(3) · 5 + G_7(3)     [адитивність та масштабування]
= (3³) · 2 + (3²) · 5 + 7                   [степеневий гомоморфізм]
= 27 · 2 + 9 · 5 + 7                        [арифметичні обчислення]
= 54 + 45 + 7
= 106
```

**Приклад 2 (Суперекспоненціальний рівень `α = ω^(ω + 1)` при `n = 2`):**
```
G_{ω^(ω + 1)}(2)
= 2^(G_{ω + 1}(2))                          [степеневий гомоморфізм]
= 2^(G_ω(2) + 1)                            [аксіома наступника]
= 2^(2 + 1)                                 [підстановка G_ω(2) = 2]
= 2³
= 8
```

**Приклад 3 (Рівень тетрації `α = ω^(ω^ω)` при `n = 2`):**
```
G_{ω^(ω^ω)}(2)
= 2^(G_{ω^ω}(2))                            [степеневий гомоморфізм]
= 2^(2^(G_ω(2)))                            [повторне застосування гомоморфізму]
= 2^(2²)                                    [підстановка G_ω(2) = 2]
= 2⁴
= 16
```

## Доведення властивості Бахмана для канонічних послідовностей

Чому вибір фундаментальної послідовності є критичним саме для повільнозростаючої ієрархії?

Розглянемо штучний контрприклад. Якби для граничного ординала `ω` ми обрали альтернативну послідовність `ω'[n] = 2n`, тоді значення функції `G_ω(n)` дорівнювало б `2n` замість `n`. Це автоматично подвоїло б значення всіх похідних рівнів, зруйнувавши канонічний зв'язок `G_{ω^k}(n) = n^k` та призвівши до некоректного поліноміального масштабування.

Щоб повільнозростаюча ієрархія була строго узгодженою та зберігала монотонність на всіх рівнях, система фундаментальних послідовностей повинна задовольняти **властивість Бахмана** (англ. *Bachmann's property* або *coherence property*):

```
∀ n < m : λ[n] < λ[m]
∀ n < m : (λ[m])[n] ≤ λ[n]
```

**Теорема 3 (Узгодженість канонічної системи Кантора).** Канонічна система фундаментальних послідовностей для ординалів `α < ε₀` у формі Кантора задовольняє властивість Бахмана.

*Доведення.*
1. Для базового випадку `λ = ω` маємо `ω[n] = n`. Для `n < m` очевидно `n < m`, а оскільки `m` є скінченним числом, його власна редукція `m[n]` збігається з `n`, отже `(ω[m])[n] = m[n] = n = ω[n]`.
2. Для доданка `ω^(γ + 1)` маємо `(ω^(γ + 1))[n] = ω^γ · n`. Для `n < m` маємо `ω^γ · n < ω^γ · m`. При повторній підстановці:
```
((ω^(γ + 1))[m])[n]
= (ω^γ · m)[n]                     [значення першої редукції]
= ω^γ · (m - 1) + n                [за правилом редукції множення на скінченне число]
```
Оскільки для `m > n` старша частина `ω^γ · (m - 1)` не перевищує початкової межі при наступних скороченнях, умова `(λ[m])[n] ≤ λ[n]` виконується для всіх показників у формі Кантора.

Властивість Бахмана гарантує, що сітка наближень граничних ординалів є «вкладеною»: наближення з більшим індексом `m` при подальшій редукції з кроком `n` повертає нас у межі початкового наближення `λ[n]`. Саме виконання цієї властивості забезпечує строгість та однозначність обчислень SGH.

## Ієрархія Веблена та предикативний ординал Фефермана — Шютте Γ₀

Коли ми переходимо за межу ординала `ε₀`, форма Кантора перестає бути ефективною, оскільки `ε₀` є найменшим коренем рівняння `ω^α = α`.

Для позначення більших ординалів Освальд Веблен (англ. *Oswald Veblen*) у 1908 році ввів ієрархію функцій `φ_γ(β)`:
- `φ₀(β) = ω^β` (звичайна експонента Кантора);
- `φ₁(β) = ε_β` (послідовність епсилон-ординалів: `ε₀, ε₁, ε₂, ...`);
- `φ₂(β) = ζ_β` (послідовність дзета-ординалів: фіксовані точки `ε_α = α`);
- `φ_{γ + 1}(β)` перелічує спільні нерухомі точки всіх попередніх функцій `φ_γ`.

Фундаментальні послідовності для функцій Веблена будуються за наступними правилами:
1. Для `ε_0 = φ₁(0)`: `ε₀[n] = ω ↑↑ n`.
2. Для `ε_{β + 1} = φ₁(β + 1)`: `(ε_{β + 1})[0] = ε_β + 1`, `(ε_{β + 1})[n + 1] = ω^( (ε_{β + 1})[n] )`.
3. Для `Γ₀ = sup { φ_α(0) | α < Γ₀ }` (ординал Фефермана — Шютте): `Γ₀[0] = 0`, `Γ₀[n + 1] = φ_{Γ₀[n]}(0)`.

Обчислення повільнозростаючої ієрархії на шкалі Веблена демонструє контрольований перехід через класи надвисокої складності:

1. **На рівні ε₀:**
```
G_{ε₀}(n) = G_{ω ↑↑ n}(n) = n ↑↑ n
```
Функція `G_{ε₀}` має швидкість росту повної тетрації (рівень `F₃` швидкозростаючої шкали або функція Аккермана).

2. **На рівні ε₁:**
```
G_{ε₁}(n) = n ↑↑ (n ↑↑ n) = n ↑↑² 2
```
Це відповідає пентації — наступному гіпероператору над тетрацією.

3. **На рівні Γ₀ (межа предикативності):**
Оскільки `Γ₀` діагоналізує над усіма скінченними та трансфінітними рівнями функцій Веблена, повільнозростаюча функція `G_{Γ₀}(n)` виходить за межі всіх примітивно-рекурсивних та елементарних операцій, досягаючи рівня `F_ω` (рівень повної функції Аккермана з довільним змінним індексом).

## Порівняння трьох трансфінітних ієрархій: G_α, h_α та F_α

Щоб зрозуміти місце SGH у загальній картині теорії обчислюваності, зіставимо три головні ієрархії:

1. **Повільнозростаюча ієрархія (SGH):**
```
G₀(n) = 0,    G_{α+1}(n) = G_α(n) + 1,    G_λ(n) = G_{λ[n]}(n)
```
*Крок:* інкремент `+ 1`. *Швидкість на малих ординалах:* від констант до поліномів.

2. **Ієрархія Гарді (англ. Hardy hierarchy):**
```
h₀(n) = n,    h_{α+1}(n) = h_α(n + 1),    h_λ(n) = h_{λ[n]}(n)
```
*Крок:* зсув аргументу `n ↦ n + 1`.
*Властивість композиції:* `h_{α + β}(n) = h_α(h_β(n))`.
Для скінченних рівнів `h_k(n) = n + k`. На рівні `ω`: `h_ω(n) = h_n(n) = 2n`. На рівні `ω²`: `h_{ω²}(n) = n · 2ⁿ`.

3. **Швидкозростаюча ієрархія (FGH):**
```
F₀(n) = n + 1,    F_{α+1}(n) = F_α^(n)(n),    F_λ(n) = F_{λ[n]}(n)
```
*Крок:* `n`-кратна ітерація попереднього рівня.

**Теорема 3 (Вейнер, Швіхтенберг, Цихон).** Для будь-якого ординала `α < ε₀` виконується точний зв'язок між ієрархією Гарді та швидкозростаючою ієрархією:
```
h_{ω^α}(n) = F_α(n)
```

Зв'язок між повільнозростаючою та швидкозростаючою ієрархіями на до-`ε₀` ординалах встановлюється через композицію:
```
F_α(n) = h_{ω^α}(n)
G_{ω^α}(n) = n^(G_α(n))
```
Ці співвідношення показують, що повільна ієрархія діє як логарифмічний проектор для швидкозростаючої ієрархії.

## Теорема Цихона — Вейнера для нормованих систем ординалів

У 1983 році Едвард Цихон та Стенлі Вейнер узагальнили оцінку поведінки повільнозростаючої ієрархії через поняття **норми ординала** (англ. *ordinal norm*).

Нехай кожному ординалу `α` зіставляється його синтаксична довжина (норма) `|α| ∈ ℕ`, що визначається рекурсивно як кількість символів `ω`, `+`, `·` та скінченних констант у мінімальному дереві виразу:
```
|0| = 0
|α + 1| = |α| + 1
|ω^β · c + γ| = |β| + c + |γ|
```

Цихон і Вейнер довели наступну фундаментальну теорему про обмеження довжини редукцій:

**Теорема 4 (Обмеження нормалізації через норми).** Нехай послідовність редукцій термів або кроків гри в Гідру генерує спадний ланцюг ординалів `α₀ > α₁ > α₂ > ... > αₖ = 0`, де на кожному кроці `i` фундаментальна підстановка здійснюється з параметром `n + i`:
```
α_{i + 1} = α_i[n + i]
```
Тоді загальна довжина ланцюга редукції `k` строго обмежена значенням повільнозростаючої функції:
```
k ≤ G_{α₀}(n + |α₀|)
```

Цей результат доводить, що повільнозростаюча ієрархія є не просто математичною абстракцією, а природним фізичним таймером будь-якого процесу трансфінітного спуску, де розмір реплікації дерева обмежений лінійним кроком.

## Теорія колапсу Жірара та ординал Бахмана — Говарда

Справжній тріумф математичного аналізу SGH полягає у доведенні того, як повільна ієрархія наздоганяє швидку на ординалі Бахмана — Говарда `ψ(ε_{Ω+1})`.

Нехай `Ω = ω₁` — перший незліченний кардинал. Ординальна колапсувальна функція Бухгольца `ψ` відображає ординали, побудовані з використанням `Ω`, у зліченні ординали.

Канонічне правило фундаментальної послідовності для колапсованого незліченного символу задається як:
```
Ω[n] = n
```

Розглянемо колапс ординального виразу `α = ψ(Ω^ω)`.
Обчислимо перші кроки редукції фундаментальної послідовності:

```
(ψ(Ω^ω))[n]
= ψ((Ω^ω)[n])                      [комутативність колапсу та граничного переходу]
= ψ(Ω^(ω[n]))                      [правило фундаментальної послідовності степеня]
= ψ(Ωⁿ)                            [підстановка ω[n] = n]
```

Тепер застосуємо рекурсивну підстановку фундаментальної послідовності для незліченної бази `Ω`:
```
(ψ(Ωⁿ))[n]
= ψ(Ωⁿ⁻¹ · n)                      [редукція старшого незліченного степеня]
= ψ(Ωⁿ⁻² · n · n) = ...
= ψ(nⁿ)                            [n-кратний колапс незліченних множників]
```

Коли ми застосовуємо функцію `G` до отриманого ординального виразу, виникає ефект лавиноподібного вкладення:
```
G_{ψ(Ω^ω)}(n)
= G_{ψ(nⁿ)}(n)
```
Оскільки внутрішній член `ψ(nⁿ)` містить `nⁿ` рекурсивно вкладених граничних переходів, кожне наступне розкриття колапсу генерує повну ітерацію швидкості росту попереднього ступеня.

**Теорема 5 (Теорема Жірара про порівняння ієрархій).**
У системі фундаментальних послідовностей Бухгольца існує точний асимптотичний збіг між повільнозростаючою ієрархією на ординалі Бахмана — Говарда та швидкозростаючою ієрархією на ординалі Пеано:
```
G_{ψ(Ω^ω)}(n) ≈ F_{ε₀}(n)
```

Більше того, для вищих ординалів колапсу систем другого порядку `Π¹₁-CA₀` повільнозростаюча ієрархія повністю відновлює весь спектр швидкозростаючої ієрархії:
```
G_{ψ(Ω_{α + 1})}(n) ≈ F_{ψ(Ω_α)}(n)
```

## Зв'язок із класами Ґжеґорчика та субрекурсивними замиканнями

У класичній теорії складності обчислень функції класифікують за класами Ґжеґорчика `Eⁿ`. Повільнозростаюча ієрархія дозволяє встановити точну границю між класами Ґжеґорчика через ординальні індекси форми Кантора:

1. **Клас E⁰ (константи та інкремент):** відповідає скінченним ординалам `k < ω`. Для кожного `k` функція `G_k(n) = k` належить до `E⁰`.
2. **Клас E¹ (лінійні функції):** породжується ординалами вигляду `ω · k`. Функції `G_{ω·k}(n) = k · n` є базовими генераторами класу лінійної складності.
3. **Клас E² (поліноми та множення):** відповідає ординалам `α < ω^ω`. Будь-який поліном степеня `k` кодується ординалом `ω^k`, тому клас `E²` тотожно збігається із субрекурсивним замиканням функцій `{ G_α | α < ω^ω }`.
4. **Клас E³ (елементарні функції за Кальмаром, експоненти та тетрації):** відповідає ординалам `α < ε₀`. Усі скінченні вежі степенів генеруються ординалами `ω ↑↑ k`.
5. **Клас примітивно-рекурсивних функцій PR:** відповідає ординалу Фефермана — Шютте `Γ₀` у повільнозростаючій ієрархії, оскільки `G_{Γ₀}` вперше виходить за межі будь-якого фіксованого примітивно-рекурсивного опису.

Цей ізоморфізм показує, що повільнозростаюча ієрархія є неперервною лінійкою, яка калібрує класи складності від елементарної арифметики до трансфінітних меж теорії доведень.

## Комбінаторні застосування: Гідри Бухгольца та повільні послідовності Ґудстейна

У комбінаториці нескінченних дерев повільнозростаюча ієрархія надає точну кількісну оцінку для модифікованих ігор у Гідру та повільних послідовностей Ґудстейна.

У класичній грі в Гідру Кірбі — Паріса відтинання голови з міткою `0` призводить до відростання `n` копій зрізаної гілки, а ординал дерева спадає відповідно до фундаментальної послідовності `FGH`. Загальна кількість кроків до загибелі Гідри оцінюється швидкозростаючою функцією `F_{ε₀}(n)`.

Проте у **повільній грі в Гідру** (англ. *Slow Hydra battle*), де за один крок відтинається лише одиничний сегмент мітки або приріст копій обмежений константою 1, час життя дерева зменшується настільки плавно, що кількість кроків описується саме повільнозростаючою ієрархією:
```
Steps_{slow}(T_α, n) = G_α(n)
```

Аналогічно, у повільних послідовностях Ґудстейна за Андреасом Ваєрманом зміна бази числення відбувається за правилом `b_{k+1} = b_k + 1/b_k` або з дробовим сповільненням. Тоді як звичайні послідовності Ґудстейна вимагають `F_{ε₀}` кроків для повернення до нуля, повільні послідовності Ґудстейна повністю калібруються функціями `G_{ω^k}` та `G_{ε₀}`.

Ці результати підтверджують, що повільнозростаюча ієрархія є не просто формальним аналогом `FGH`, а фундаментальним математичним інваріантом мікродинаміки комбінаторних процесів. Вона дозволяє розв'язувати задачі верифікації та доведення завершуваності алгоритмів із максимальною роздільною здатністю, де кожен крок редукції отримує строге кількісне обґрунтування.

## Алгебраїчний висновок та теорема про єдиність розкладу

Підсумовуючи математичний апарат повільнозростаючої ієрархії, зазначимо ключовий структурний висновок: оператор оцінки `Eval(α, ω ↦ n)` задає єдиний ізоморфізм між напівкільцем ординалів Кантора з операціями природного додавання та множення Гессенберга і напівкільцем поліномів з додатними коефіцієнтами `ℕ[x]`. Будь-яка теорема про збіжність або обмеженість обчислень над ординалами Кантора автоматично транслюється у числову нерівність над натуральними числами, що робить `G_α` незамінним інструментом конструктивної математики та теоретичного аналізу складності.
