Дві криптографічні системи обмінюються параметрами кривих у короткій формі Вейєрштрасса: перша генерує рівняння `y² = x³ - 3x + 1`, а друга — `y² = x³ - 48x + 64`. На перший погляд коефіцієнти лінійного та вільного членів різняться в десятки разів, а графіки кривих мають різні перетини з осями координат. Проте заміна змінних `x ↦ 4x`, `y ↦ 8y` перетворює перше рівняння на друге з абсолютною точністю. Геометрично та алгебраїчно ці дві моделі є одним і тим самим математичним об'єктом: їхні групи точок ізоморфні, порядок кривої над будь-яким скінченним полем однаковий, а дискретний логарифм має ідентичну криптографічну складність.

Координатна форма запису еліптичної кривої не є унікальною. Будь-яке афінне масштабування координат породжує нескінченну кількість зовні відмінних рівнянь. Щоб однозначно ідентифікувати криву з точністю до ізоморфізму над алгебраїчно замкненим полем, потрібна числова характеристика, інваріантна щодо будь-яких допустимих замін координат. Такою універсальною величиною є j-інваріант.

## 1. Допустимі перетворення координат та алгебраїчні коваріанти

Загальне кубічне рівняння площини, що задає гладку еліптичну криву над довільним полем `K`, записується у повній формі Вейєрштрасса Тейта — Делінга:

```
y² + a₁xy + a₃y = x³ + a₂x² + a₄x + a₆
```

Коефіцієнти `a₁, a₂, a₃, a₄, a₆` належать полю `K`. Єдиним класом змін змінних у проєктивній площині `ℙ²(K)`, що зберігає структуру нейтрального елемента (нескінченно віддаленої точки `𝒪 = [0:1:0]`) та канонічний вигляд форми Вейєрштрасса, є група допустимих афінних перетворень:

```
x ↦ u²x + r
y ↦ u³y + su²x + t
```

де `u ∈ K* = K \ {0}`, а `r, s, t ∈ K`.

Градуювання змінних у ваговій проєктивній площині `ℙ(2, 3, 1)` визначає природні ваги коефіцієнтів: змінна `x` має вагу 2, змінна `y` — вагу 3, а коефіцієнти `aᵢ` мають вагу `i`. Відповідно, при перетворенні координат коефіцієнти `aᵢ` зазнають поліноміальних трансформацій, які повністю зберігають геометрію кривої.

### 1.1. Редукція до короткої форми Вейєрштрасса

Якщо характеристика поля `\text{char}(K) ∉ {2, 3}`, підстановка `y ↦ y - (a₁x + a₃)/2` зводить рівняння до вигляду:

```
y² = x³ + (a₂ + a₁²/4)x² + (a₄ + a₁a₃/2)x + (a₆ + a₃²/4)
```

Подальший зсув абсциси `x ↦ x - (a₂ + a₁²/4)/3` остаточно усуває квадратичний член `x²`. У результаті крива набуває класичної короткої форми Вейєрштрасса:

```
y² = x³ + Ax + B
```

де коефіцієнти `A` та `B` виражаються через інваріанти Тейта `c₄` та `c₆`:

```
A = -c₄ / 48
B = -c₆ / 864
```

Інваріанти `c₄`, `c₆` та дискримінант `Δ` обчислюються через коефіцієнти повної форми через допоміжні величини Тейта `b₂, b₄, b₆, b₈`:

```
b₂ = a₁² + 4a₂
b₄ = 2a₄ + a₁a₃
b₆ = a₃² + 4a₆
b₈ = a₁²a₆ + 4a₂a₆ - a₁a₃a₄ + a₂a₃² - a₄²

c₄ = b₂² - 24b₄
c₆ = -b₂³ + 36b₂b₄ - 216b₆
Δ = -b₂²b₈ - 8b₄³ - 27b₆² + 9b₂b₄b₆
```

Для короткої форми Вейєрштрасса `y² = x³ + Ax + B` формули спрощуються до фундаментальних виразів:

```
c₄ = -48A
c₆ = -864B
Δ = -16(4A³ + 27B²)
```

Умова гладкості кривої вимагає, щоб кубічний многочлен у правій частині не мав кратних коренів. Це еквівалентно умові ненульового дискримінанта `Δ ≠ 0`. Якщо `Δ = 0`, крива стає сингулярною: вона містить або вузол (англ. *node*, коли `c₄ ≠ 0`), або загострення (англ. *cusp*, коли `c₄ = 0`).

При переході між ізоморфними моделями під дією масштабування `(x, y) ↦ (u²x, u³y)` величини `c₄`, `c₆` та `Δ` масштабуються строго визначеними степенями фактора `u`:

```
c₄ ↦ u⁴ · c₄
c₆ ↦ u⁶ · c₆
Δ  ↦ u¹² · Δ
```

### 1.2. Криві над полями характеристик 2 та 3

У полях малих характеристик редукція до короткої форми Вейєрштрасса `y² = x³ + Ax + B` неможлива через ділення на 2 або 3. Проте загальне означення інваріанта через величини Тейта лишається універсальним:

* **Характеристика `\text{char}(K) = 2`:**
  * Якщо `a₁ ≠ 0` (звичайна крива), заміна координат приводить рівняння до форми `y² + xy = x³ + a₂x² + a₆`. У цьому разі дискримінант `Δ = a₆`, а j-інваріант дорівнює `j = 1 / a₆`.
  * Якщо `a₁ = 0` (надсингулярна крива), рівняння зводиться до `y² + a₃y = x³ + a₄x + a₆`. Тут `Δ = a₃⁴`, `c₄ = 0`, і відповідно `j = 0`.
* **Характеристика `\text{char}(K) = 3`:**
  * Якщо `b₂ ≠ 0` (звичайна крива), рівняння набуває вигляду `y² = x³ + a₂x² + a₆`. Дискримінант `Δ = -a₂³a₆`, а j-інваріант дорівнює `j = -a₂³ / a₆`.
  * Якщо `b₂ = 0` (надсингулярна крива), рівняння зводиться до `y² = x³ + a₄x + a₆`. У цьому разі `c₄ = 0`, тому `j = 0`.

## 2. Означення та фундаментальні властивості j-інваріанта

Оскільки чисельник `c₄³` масштабується як `(u⁴)³ = u¹²`, а знаменник `Δ` масштабується як `u¹²`, їхнє відношення є абсолютно інваріантним щодо довільних виборів масштабного параметра `u`:

```
j = c₄³ / Δ
```

Підставляючи коефіцієнти короткої форми Вейєрштрасса `c₄ = -48A` та `Δ = -16(4A³ + 27B²)`, отримуємо класичний канонічний вираз:

```
j = (-48A)³ / (-16(4A³ + 27B²)) = 110592 · A³ / (16 · (4A³ + 27B²)) = 1728 · 4A³ / (4A³ + 27B²)
```

Константа `1728 = 12³` виникає природним чином з нормалізації коефіцієнтів рядів Фур'є модулярних форм та перетворень Ейзенштейна.

Повне аналітичне та алгебраїчне виведення єдиності цього дробу та теореми про критерій ізоморфізму наведено в окремому документі: [строге алгебраїчне виведення теореми про ізоморфізм та геометрія форми Лежандра](book:algorithms/complexity-computability/j-invariant/math-isomorphism-proof.md).

### 2.1. Універсальна теорема про класифікацію

Для будь-якого алгебраїчно замкненого поля `K`:
1. Дві еліптичні криві `E₁` та `E₂` над `K` є ізоморфними тоді й лише тоді, коли їхні j-інваріанти збігаються: `j(E₁) = j(E₂)`.
2. Для будь-якого елемента `j₀ ∈ K` існує еліптична крива над `K`, чий j-інваріант дорівнює `j₀`.

Явна конструкція канонічної кривої Вейєрштрасса за числовим значенням `j₀` здійснюється за правилом:
* Якщо `j₀ = 0`: крива задається рівнянням `y² = x³ + 1` (`A = 0, B = 1`).
* Якщо `j₀ = 1728`: крива задається рівнянням `y² = x³ + x` (`A = 1, B = 0`).
* Якщо `j₀ ∉ {0, 1728}`: коефіцієнти обираються як `A = 3j₀(1728 - j₀)` та `B = 2j₀(1728 - j₀)²`.

Перевіримо підстановкою:
```
4A³ = 4 · 27 · j₀³(1728 - j₀)³ = 108 · j₀³(1728 - j₀)³
27B² = 27 · 4 · j₀²(1728 - j₀)⁴ = 108 · j₀²(1728 - j₀)⁴
4A³ + 27B² = 108 · j₀²(1728 - j₀)³ · [j₀ + (1728 - j₀)] = 108 · 1728 · j₀²(1728 - j₀)³
```

Обчислюємо j-інваріант:
```
j = 1728 · (108 · j₀³(1728 - j₀)³) / (108 · 1728 · j₀²(1728 - j₀)³) = j₀
```

Рівність виконується тотожно для будь-якого `j₀`.

## 3. Комплексна геометрія та модулярна група

Над полем комплексних чисел `ℂ` будь-яка еліптична крива конформно еквівалентна комплексному тору `ℂ / Λ`, де `Λ = ℤω₁ + ℤω₂` — двовимірна ґратка з базисом `(ω₁, ω₂)`, причому відношення базисних періодів `τ = ω₁ / ω₂` належить верхній півплощині `ℍ = {τ ∈ ℂ ∣ \text{Im}(τ) > 0}`.

![](/book/algorithms/complexity-computability/j-invariant/img/jinv-fundamental-domain.svg)
*Фундаментальна область модулярної групи PSL₂(ℤ) у верхній комплексній півплощині та особливі точки j-інваріанта*

Відображення комплексного тора `ℂ / Λ` в проєктивну площину здійснюється за допомогою еліптичної функції Вейєрштрасса `℘(z)` та її похідної:

```
℘(z; Λ) = 1/z² + ∑_{ω ∈ Λ \ {0}} (1/(z - ω)² - 1/ω²)
```

Функція `℘(z)` задовольняє диференціальне рівняння першого порядку:

```
(℘'(z))² = 4℘(z)³ - g₂(Λ)℘(z) - g₃(Λ)
```

де `g₂` та `g₃` — ряди Ейзенштейна парних ваг 4 та 6:

```
g₂(Λ) = 60 ∑_{ω ∈ Λ \ {0}} 1/ω⁴
g₃(Λ) = 140 ∑_{ω ∈ Λ \ {0}} 1/ω⁶
```

Дискримінант ґратки визначається модулярною формою ваги 12:

```
Δ(Λ) = g₂(Λ)³ - 27g₃(Λ)² = (2π)¹² · η(τ)²⁴
```

де `η(τ) = q^{1/24} ∏_{n=1}^∞ (1 - qⁿ)` — дзета-функція Дедекінда. Тоді j-інваріант ґратки (та відповідної кривої `y² = 4x³ - g₂x - g₃`) визначається як голоморфна функція параметра `τ`:

```
j(τ) = 1728 · g₂(τ)³ / (g₂(τ)³ - 27g₃(τ)²) = 1728 · g₂(τ)³ / Δ(τ)
```

### 3.1. Модулярна інваріантність та фундаментальна область

Зміна базису ґратки `Λ` унімодулярним цілочисельним перетворенням матриці з групи `\text{SL}₂(ℤ)` переводить параметр `τ` за правилом дробово-лінійної трансформації:

```
τ ↦ (aτ + b) / (cτ + d),  де a, b, c, d ∈ ℤ, ad - bc = 1
```

Група `\text{PSL}₂(ℤ) = \text{SL}₂(ℤ) / {±I}` породжується двома елементарними операціями:
1. Зсув періоду на одиницю: `T: τ ↦ τ + 1` (відповідає матриці `[[1, 1], [0, 1]]`).
2. Комплексна інверсія: `S: τ ↦ -1/τ` (відповідає матриці `[[0, -1], [1, 0]]`).

Функція `j(τ)` є автоморфною формою ваги 0 (модулярною функцією), тобто задовольняє умову:

```
j((aτ + b) / (cτ + d)) = j(τ)  для всіх [[a, b], [c, d]] ∈ \text{SL}₂(ℤ)
```

Фундаментальна область `ℱ` модулярної групи у верхній півплощині `ℍ` задається нерівностями:

```
ℱ = {τ ∈ ℍ ∣ |Re(τ)| ≤ 1/2, |τ| ≥ 1}
```

Відображення `j: ℱ → ℂ` є конформним бієктивним ізоморфізмом (рімановою поверхнею сфери Рімана без нескінченності). Особливу роль відіграють фіксовані точки підгруп автоморфізмів:
* **Точка `τ = i`:** фіксована точка відбиття `S(i) = -1/i = i`. Ґратка `Λ = ℤ + iℤ` має вигляд квадратної сітки. У цій точці `g₃(i) = 0`, тому `j(i) = 1728`. Крива має додатковий автоморфізм `(x, y) ↦ (-x, iy)` порядку 4.
* **Точка `τ = ρ = e^{2πi/3} = (-1 + i√3)/2`:** фіксована точка повороту `ST(ρ) = ρ`. Ґратка `Λ = ℤ + ρℤ` має форму правильних шестикутників (гексагональна решітка Ейзенштейна). У цій точці `g₂(ρ) = 0`, тому `j(ρ) = 0`. Крива має автоморфізм `(x, y) ↦ (e^{2πi/3}x, -y)` порядку 6.
* **Вершина на нескінченності `τ → i∞` (касп):** параметр `q = e^{2πiτ} → 0`. Ряд Тейлора — Фур'є має простий полюс першого порядку:

```
j(τ) = 1/q + 744 + 196884q + 21493760q² + 864299970q³ + ⋯
```

Глибокий зв'язок коефіцієнтів цього ряду з теорією простих скінченних груп та групою «Монстр» висвітлено в нарисі: [детальний історичний екскурс про відкриття модулярних функцій та гіпотезу Monstrous Moonshine](book:algorithms/complexity-computability/j-invariant/hist-klein-modular.md).

### 3.2. Комплексне множення та сингулярні модулі

У загальному випадку кільце ендоморфізмів комплексного тора `\text{End}(ℂ / Λ)` ізоморфне кільцю цілих чисел `ℤ` (єдиними ендоморфізмами є множення на ціле число `n: z ↦ nz`).

Якщо ж відношення періодів `τ` є елементом уявного квадратного поля `K = ℚ(√-d)`, ґратка допускає додаткові симетрії. Кільце ендоморфізмів розширюється до порядку `𝒪_D` в квадратичному полі `K`. Це явище називається **комплексним множенням** (англ. *Complex Multiplication*, CM).

Значення j-інваріанта `j(τ)` у точках комплексного множення називаються **сингулярними модулями** (англ. *singular moduli*). За основною теоремою теорії комплексного множення Вебера — Гільберта:
* Сингулярний модуль `j(τ)` є цілим алгебраїчним числом.
* Поле `ℚ(j(τ))` є абелевим розширенням поля `K` і збігається з полем класів Гільберта `H_K` (максимальним нерозгалуженим абелевим розширенням).
* Мінімальний многочлен числа `j(τ)` над `ℚ` називається **поліномом класів Гільберта** `H_D(X)`:

```
H_D(X) = ∏_{[a, b, c]} (X - j((-b + √D) / (2a)))
```

Степінь многочлена `H_D(X)` дорівнює числу класів ідеалів `h(D)`. Для `h(D) = 1` (дев'ять чисел Хегнера `D ∈ {-3, -4, -7, -8, -11, -19, -43, -67, -163}`) значення `j(τ)` є раціональними цілими числами:
* `D = -3` (`τ = e^{2πi/3}`): `j = 0`
* `D = -4` (`τ = i`): `j = 1728 = 12³`
* `D = -7`: `j = -3375 = -15³`
* `D = -8`: `j = 8000 = 20³`
* `D = -11`: `j = -32768 = -32³`
* `D = -19`: `j = -884736 = -96³`
* `D = -43`: `j = -884736000 = -960³`
* `D = -67`: `j = -147197952000 = -5280³`
* `D = -163`: `j = -262537412640768000 = -640320³`

Останнє значення пояснює знамените наближення Рамануджана: `e^{π√163} ≈ 640320³ + 744 = 262537412640768743.99999999999925...`

## 4. Криві над скінченними полями та геометрія твістів

Нехай `K = 𝔽_q` — скінченне поле з `q = pⁿ` елементів. Дві криві `E₁` та `E₂`, визначені над `𝔽_q`, можуть мати однаковий j-інваріант `j(E₁) = j(E₂) = j₀`, але не бути ізоморфними над самим полем `𝔽_q`.

У такому разі крива `E₂` називається **твістом** (скрутом) кривої `E₁`. Ізоморфізм між ними існує над алгебраїчним замиканням `𝔽̄_q`, а мінімальний степінь розширення поля `d = [L : 𝔽_q]`, над яким з'являється ізоморфізм, називається степенем твісту.

Класифікація твістів визначається групою автоморфізмів кривої `\text{Aut}(E)` над `𝔽̄_q` та когомологіями Галуа `H¹(\text{Gal}(\bar{K}/K), \text{Aut}(\bar{E}))`:

| j-інваріант | Група автоморфізмів `\text{Aut}(E)` | Можливі степені твісту `d` | Канонічна модель над `𝔽_q` |
|---|---|---|---|
| `j ∉ {0, 1728}` | `ℤ₂ = {±1}` | `d = 2` (квадратичний) | `y² = x³ + Ax + B` |
| `j = 1728` | `ℤ₄ = {±1, ±i}` | `d ∈ {2, 4}` (квартичний) | `y² = x³ + Ax` |
| `j = 0` | `ℤ₆ = {±1, ±ζ₃, ±ζ₃²}` | `d ∈ {2, 3, 6}` (секстичний) | `y² = x³ + B` |

### 4.1. Квадратичний твіст

Для довільної кривої `E: y² = x³ + Ax + B` з `j ∉ {0, 1728}` квадратичний твіст задається неквадратом `g ∈ 𝔽_q*`:

```
E': y² = x³ + Ag²x + Bg³
```

Заміна змінних `x' = gx`, `y' = g^{3/2}y` зводить `E'` до `E` над квадратичним розширенням `𝔽_{q²}`.

Якщо крива `E` має `#E(𝔽_q) = q + 1 - t` точок (де `t` — слід ендоморфізму Фробеніуса), то квадратичний твіст `E'` завжди має строго доповняльну кількість точок:

```
#E'(𝔽_q) = q + 1 + t
```

Ця фундаментальна властивість використовується для захисту від атак по побічних каналах: якщо випадкова точка не потрапляє на криву `E`, вона автоматично потрапляє на її квадратичний твіст `E'`, запобігаючи витоку інформації про секретний скаляр.

### 4.2. Вищі твісти: квартичні та секстичні

При особливих значеннях j-інваріанта геометрія кривої стає багатшою:

1. **Квартичні твісти (`j = 1728`):** рівняння кривої має вигляд `y² = x³ + Ax`. Група автоморфізмів циклічна порядку 4 і породжується відображенням `[i](x, y) = (-x, iy)`. Для довільного елемента `c ∈ 𝔽_q* \ (𝔽_q*)^4` крива `y² = x³ + Acx` є квартичним твістом степеня 4 (або 2, якщо `c` є квадратом, але не 4-м степенем). Кількість точок на твістах набуває значень `q + 1 ± t` або `q + 1 ± 2y`, де `t² + 4y² = 4q`.
2. **Секстичні твісти (`j = 0`):** рівняння кривої має вигляд `y² = x³ + B`. Група автоморфізмів циклічна порядку 6 і породжується перетворенням `[ζ₆](x, y) = (ζ₆²x, -y)`. Твісти мають вигляд `y² = x³ + Bc` для `c ∈ 𝔽_q* \ (𝔽_q*)^6`. Вони класифікуються за степенями розширення 2, 3 та 6.

## 5. Форма Лежандра та перетворення симетричної групи S₃

Будь-яку еліптичну криву, всі три 2-точки кручення якої визначені над базовим полем, можна записати у формі Лежандра з параметром `λ ∉ {0, 1}`:

```
y² = x(x - 1)(x - λ)
```

Корені кубічного многочлена в правій частині дорівнюють `0`, `1` та `λ`. Проєктивне перетворення Мебіуса `ℙ¹ → ℙ¹`, що переставляє чотири особливі точки `{0, 1, λ, ∞}`, породжує дію симетричної групи перестановок `S₃` порядку 6 на просторі параметрів `λ`. Орбіта параметра складається з шести взаємопов'язаних значень:

```
λ,  1/λ,  1 - λ,  1/(1 - λ),  (λ - 1)/λ,  λ/(λ - 1)
```

Всі шість значень `λ` відповідають одній і тій самій еліптичній кривій з точністю до ізоморфізму. Пряме обчислення коефіцієнтів Вейєрштрасса дає вираз j-інваріанта через `λ`:

```
j(λ) = 256 · (λ² - λ + 1)³ / (λ² · (λ - 1)²)
```

Цей дріб є симетричним інваріантом орбіти `S₃`. Наприклад, для `λ = -1` отримуємо `j(-1) = 256 · (1 + 1 + 1)³ / (1 · 4) = 256 · 27 / 4 = 1728`.

### 5.1. Диференціальні рівняння Пікара — Фукса

Періоди еліптичного інтеграла першого роду на формі Лежандра:

```
K(λ) = ∫₀¹ dx / √(x(x - 1)(x - λ)) = (π/2) · ₂F₁(1/2, 1/2; 1; λ)
```

задовольняють лінійне диференціальне рівняння другого порядку Пікара — Фукса:

```
λ(1 - λ) d²w/dλ² + (1 - 2λ) dw/dλ - (1/4)w = 0
```

Відношення двох лінійно незалежних розв'язків цього рівняння `τ(λ) = i K'(λ) / K(λ)` задає обернене відображення модулярної функції `λ(τ) = θ₂⁴(q) / θ₃⁴(q)`, пов'язуючи теорію j-інваріанта з тета-функціями Якобі.

## 6. Швидкі криптографічні моделі: Монтгомері, Едвардс та Гессе

У сучасній практичній криптографії (протоколи Signal, TLS 1.3, SSH, цифрові підписи Ed25519) замість короткої форми Вейєрштрасса застосовують форми, що забезпечують захист від атак за часом виконання.

### 6.1. Форма Монтгомері

Рівняння кривої Монтгомері має вигляд:

```
M_{A, B}: B · y² = x³ + A · x² + x
```

де `B(A² - 4) ≠ 0`. Підстановкою `x ↦ x/B - A/(3B)` та `y ↦ y/B` рівняння зводиться до форми Вейєрштрасса, а j-інваріант виражається безпосередньо через коефіцієнт `A`:

```
j(M_{A, B}) = 256 · (A² - 3)³ / (A² - 4)
```

Зверніть увагу: значення `j` взагалі не залежить від масштабувального параметра `B`. Зміна `B` на квадратичний нелишок породжує квадратичний твіст над `𝔽_p`.

Для кривої **Curve25519** (`p = 2²⁵⁵ - 19`, `A = 486662`, `B = 1`):
```
j = 256 · (486662² - 3)³ / (486662² - 4) mod (2²⁵⁵ - 19)
```

### 6.2. Скручена форма Едвардса

Рівняння скрученої кривої Едвардса записується як:

```
E_{a, d}: a · x² + y² = 1 + d · x² · y²
```

де `a · d(a - d) ≠ 0`. Будь-яка крива Едвардса біраціонально еквівалентна кривій Монтгомері з коефіцієнтами `A = 2(a + d)/(a - d)` та `B = 4/(a - d)`. Підставляючи `A` у формулу Монтгомері, отримуємо прямий вираз j-інваріанта кривої Едвардса:

```
j(E_{a, d}) = 16 · (a² + 14ad + d²)³ / (a · d · (a - d)⁴)
```

Криві Едвардса володіють унікальною властивістю: якщо коефіцієнт `a` є квадратом у полі, а `d` не є квадратом, закон додавання точок є **повним** (англ. *complete addition law*). Це означає відсутність особливих випадків для подвоєння точки чи додавання протилежних точок, що унеможливлює атаки по побічних каналах на рівні базового коду.

### 6.3. Форма Гессе

Кубічна крива у формі Гессе задається рівнянням:

```
x³ + y³ + 1 = 3d · x · y
```

де `d³ ≠ 1`. Її j-інваріант обчислюється за формулою:

```
j(d) = 27 · d³ · (d³ + 8)³ / (d³ - 1)³
```

Форма Гессе володіє високою симетрією: група 3-кручення `E[3]` повністю раціональна і збігається з точками перегину кубіки.

## 7. Поліноми поділу кручення та раціональні формули Велю

Поліноми поділу `\psi_m(x, y) \in \mathbb{Z}[A, B, x, y]` задають алгебраїчні рівняння для точок порядку `m` на еліптичній кривій `E: y² = x³ + Ax + B`:

```
\psi_1 = 1
\psi_2 = 2y
\psi_3 = 3x⁴ + 6Ax² + 12Bx - A²
\psi_4 = 4y(x⁶ + 5Ax⁴ + 20Bx³ - 5A²x² - 4ABx - 8B² - A³)
```

Для вищих індексів поліноми обчислюються за рекурентними формулами:

```
\psi_{2m+1} = \psi_{m+2}\psi_m³ - \psi_{m-1}\psi_{m+1}³  (для m \ge 2)
2y \cdot \psi_{2m} = \psi_m(\psi_{m+2}\psi_{m-1}² - \psi_{m-2}\psi_{m+1}²)  (для m \ge 3)
```

Точка `P = (x, y)` задовольняє умову `mP = \mathcal{O}` тоді й лише тоді, коли `\psi_m(x, y) = 0`.

### 7.1. Раціональні формули Велю для факторизації кривих

Нехай `G \subset E` — скінченна підгрупа порядку `\ell`. За теоремою Велю фактор-крива `E' = E / G` є гладкою еліптичною кривою, а канонічна ізогенія `\phi: E \to E'` задається раціональними функціями координат:

```
x(\phi(P)) = x(P) + \sum_{Q \in G \setminus \{\mathcal{O}\}} [x(P + Q) - x(Q)]
y(\phi(P)) = y(P) + \sum_{Q \in G \setminus \{\mathcal{O}\}} [y(P + Q) - y(Q)]
```

Коефіцієнти нової кривої `E': y² = x³ + A'x + B'` виражаються явно:

```
A' = A - 5 \sum_{Q \in S} t_Q
B' = B - 7 \sum_{Q \in S} w_Q
```

де `S \subset G \setminus \{\mathcal{O}\}` містить по одному представнику з кожної пари `{Q, -Q}`, `t_Q = 3x_Q² + A`, а `w_Q = 2y_Q² + x_Q \cdot t_Q`.

Зміна j-інваріанта `j(E) \mapsto j(E')` під дією формул Велю задає дискретний крок уздовж ребра графа ізогеній.

## 8. Модулярні многочлени та алгоритм Схуфа — Елкіса — Аткіна (SEA)

Задача підрахунку точок `#E(𝔽_q)` на еліптичній кривій є фундаментальною для криптографії (перевірка криптографічної стійкості проти атак Поліга — Геллмана). Алгоритм Схуфа розв'язує цю задачу за поліноміальний час `O(\log⁸ q)`, обчислюючи слід Фробеніуса `t \bmod ℓ` для малих простих чисел `ℓ` за допомогою поліномів поділу степеня `(ℓ² - 1)/2`.

Модифікація Елкіса та Аткіна (алгоритм SEA) прискорює цей процес до `O(\log⁴ q)`, використовуючи класичні модулярні многочлени `Φ_ℓ(X, Y)`.

![](/book/algorithms/complexity-computability/j-invariant/img/jinv-isogeny-graph.svg)
*Фрагмент графа 2-ізогеній над скінченним полем з виділенням циклів та надсингулярних компонент*

Модулярний многочлен `Φ_ℓ(X, Y) ∈ ℤ[X, Y]` — це симетричний двовимірний цілочисельний многочлен ступеня `ℓ + 1` за кожною змінною, що задає алгебраїчне рівняння модулярної кривої `X₀(ℓ)`. Його фундаментальна властивість:

```
Φ_ℓ(j(E₁), j(E₂)) = 0  тоді й лише тоді, коли між E₁ та E₂ існує циклічна ℓ-ізогенія
```

Для `ℓ = 2` класичний модулярний поліном має вигляд:

```
Φ₂(X, Y) = X³ + Y³ - X²Y² + 1488(X²Y + XY²) - 162000(X² + Y²) + 40773375XY + 8748000000(X + Y) - 157464000000000
```

### 8.1. Класифікація простих чисел Елкіса та Аткіна

Для заданої кривої `E` з j-інваріантом `j₀` над полем `𝔽_q` розглядається одновимірний многочлен `f(Y) = Φ_ℓ(j₀, Y) \bmod q`:
1. **Просте число Елкіса:** многочлен `f(Y)` має корінь `j' ∈ 𝔽_q`. Це означає, що ендоморфізм Фробеніуса зберігає циклічну підгрупу порядку `ℓ`. Слід Фробеніуса задовольняє характеристичне рівняння `t² - 4q ≡ y² \pmod ℓ`, що дозволяє знайти `t \bmod ℓ` за допомогою фактор-полінома степеня лише `(ℓ - 1)/2` замість `(ℓ² - 1)/2`.
2. **Просте число Аткіна:** многочлен `f(Y)` не має коренів у `𝔽_q`, а розкладається на незвідні множники вищих степенів. Це обмежує можливі значення сліду `t \bmod ℓ` до невеликої підмножини лишків.

Комбінація простих чисел Елкіса та Аткіна разом із китайською теоремою про залишки (CRT) дозволяє відновити точне значення сліду `t` за частки секунди для кривих розміром 256–512 біт.

## 9. Графи надсингулярних ізогеній та постквантова криптографія

Еліптична крива `E` над полем характеристики `p > 0` називається **надсингулярною** (англ. *supersingular*), якщо її група `p`-кручення є тривіальною: `E[p](𝔽̄_p) = {𝒪}`. В іншому разі крива називається **звичайною** (англ. *ordinary*).

Надсингулярність є геометричною властивістю, що повністю визначається j-інваріантом кривої:
* Усі надсингулярні j-інваріанти лежать у квадратичному розширенні `𝔽_{p²}`.
* Загальна кількість надсингулярних j-інваріантів над `𝔽_{p²}` скінченна і дорівнює:

```
N_p = ⌊p / 12⌋ + ε,  де ε ∈ {0, 1, 2} залежно від p \bmod 12
```

Кільце ендоморфізмів `\text{End}(E)` надсингулярної кривої ізоморфне максимальному порядку в алгебрі кватерніонів `B_{p, ∞}` з розгалуженням у точках `p` та `∞`.

### 9.1. Графи Пайзера та властивості розширювачів Рамануджана

Нехай `ℓ` — фіксоване мале просте число (`ℓ ≠ p`). Граф надсингулярних `ℓ`-ізогеній (граф Пайзера `\mathcal{G}_ℓ(p)`) будується так:
* **Вершини:** класи ізоморфізму надсингулярних еліптичних кривих, що ототожнюються зі своїми j-інваріантами `j ∈ 𝔽_{p²}`.
* **Ребра:** класи еквівалентності циклічних `ℓ`-ізогеній між кривими.

Граф `\mathcal{G}_ℓ(p)` має визначні властивості:
1. **Регулярність:** кожен вузол має рівно `ℓ + 1` вихідних ребер (з урахуванням кратностей і петель).
2. **Зв'язність:** граф є повністю зв'язаним над `𝔽_{p²}`.
3. **Властивість Рамануджана:** друге за величиною власне число матриці суміжності графа `λ₁` задовольняє сувору границю Алона — Боппани:

```
|λ₁| ≤ 2√ℓ
```

Завдяки цьому випадкове блукання довжини `O(\log p)` по графу ізогеній досягає рівномірного розподілу вершин (експоненційно швидке перемішування). Знаходження шляху між двома заданими j-інваріантами у надсингулярному графі ізогеній є NP-складною задачею як для класичних, так і для квантових комп'ютерів.

### 9.2. Відповідність Деурінга та протоколи CSIDH і SQISign

Відповідність Деурінга встановлює взаємно однозначний зв'язок між:
1. Класами надсингулярних еліптичних кривих над `𝔽_{p²}`.
2. Класами спряженості максимальних порядків у кватерніонній алгебрі `B_{p, ∞}`.
3. Ізогеніями між кривими та правими ідеалами цих порядків.

У протоколі **CSIDH** (англ. *Commutative Supersingular Isogeny Diffie-Hellman*) секретний ключ задається вектором степенів простих ідеалів, дія яких переводить початковий j-інваріант `j₀` у новий інваріант `j_A = [𝔞] * j₀`. Комутативність групи класів ідеалів забезпечує можливість побудови протоколу узгодження ключів, стійкого до алгоритму Шора.

У протоколі **SQISign** (англ. *Short Quaternion and Isogeny Signature*) відповідність Деурінга використовується через алгоритм KLPT для знаходження ультракоротких шляхів ізогеній, забезпечуючи найменший розмір відкритого ключа (64 байти) та підпису (204 байти) серед усіх відомих постквантових схем.

Повний програмний комплекс для обходу графа ізогеній, пошуку сусідів через модулярні поліноми та перевірки надсингулярності реалізовано у проєкті: [практична реалізація побудови графа ізогеній та перевірки ізоморфізму на C і C++](book:algorithms/complexity-computability/j-invariant/proj-isogeny-graph.md).

## 10. p-адичні властивості та канонічний підйом Серра — Тейта

У чисельній теорії чисел та сучасних алгоритмах підрахунку точок Сатоха важливу роль відіграє поведінка j-інваріанта в полі `p`-адичних чисел `\mathbb{Q}_p`:

* **Добра редукція (Good Reduction):** значення j-інваріанта є цілим `p`-адичним числом `v_p(j) \ge 0`, а редукована крива над `\mathbb{F}_p` залишається неособливою (`\Delta \not\equiv 0 \pmod p`).
* **Мультиплікативна редукція (Multiplicative Reduction):** дискримінант ділиться на `p` (`v_p(\Delta) > 0`), але коваріант Тейта `c_4` не ділиться на `p` (`v_p(c_4) = 0`). У цьому випадку значення j-інваріанта має полюс: `v_p(j) = -v_p(\Delta) < 0`. За теоремою Тейта така крива над `\mathbb{Q}_p` аналітично ізоморфна мультиплікативній групі тора Тейта `\mathbb{Q}_p^* / q^\mathbb{Z}`, де `q \in p\mathbb{Z}_p` — `p`-адичний параметр розкладу `j = 1/q + 744 + \dots`.
* **Адитивна редукція (Additive Reduction):** як `\Delta`, так і `c_4` діляться на `p` (`v_p(c_4) > 0` та `v_p(\Delta) > 0`). Редукована крива має загострення (касп), а j-інваріант задовольняє нерівність `v_p(j) \ge 0`.

### 10.1. Алгоритм Сатоха для підрахунку точок через канонічний підйом

Для звичайної еліптичної кривої `E` над `\mathbb{F}_{p^n}` теорема Серра — Тейта гарантує існування єдиного **канонічного підйому** (англ. *canonical lift*) `\tilde{E}` над кільцем нерозгалужених `p`-адичних цілих чисел `W(\mathbb{F}_{p^n})`, для якого ендоморфізм Фробеніуса піднімається разом із кривою.

Алгоритм Сатоха знаходить j-інваріант канонічного підйому `\tilde{j}` як нерухому точку модулярного рівняння:

```
\Phi_p(\tilde{j}, \tilde{j}^\sigma) = 0
```

де `\sigma` — автоморфізм Фробеніуса на кільці Вітта `W(\mathbb{F}_{p^n})`. Розв'язання цього рівняння методом Ньютона — Рафсона з `p`-адичною точністю `O(p^{n/2})` дозволяє обчислити слід ендоморфізму Фробеніуса за квазілінійний час `\tilde{O}(n^2 \cdot p^2)`, що є рекордним показником для малих характеристик `p = 2, 3`.

## 11. Криптографічний аудит та класифікація слабких кривих

Обчислення j-інваріанта та пов'язаних параметрів є першим кроком у криптографічному аудиті параметрів еліптичних кривих перед їхнім затвердженням у стандартах:

1. **Аномальні криві (`#E(\mathbb{F}_p) = p`):**
   Криві з порядком, що точно дорівнює характеристиці базового поля, вразливі до поліноміальної атаки Смарта — Сатоха — Аракі — Семаєва. `p`-адичний логарифм `\log_E: E(\mathbb{Q}_p) \to p\mathbb{Z}_p` ізоморфно відображає підгрупу точок у лінійну адитивну групу `\mathbb{F}_p`, зводячи дискретний логарифм до одного ділення.
2. **Криві з малим степенем занурення (`k \le 6`):**
   Якщо число `p^k - 1` ділиться на порядок підгрупи кривої для малого цілого `k`, спарювання Вейля чи Тейта відображає задачу дискретного логарифму з еліптичної кривої в мультиплікативну групу скінченного поля `\mathbb{F}_{p^k}^*`. Це відкриває можливість застосування субекспоненційного методу решета числового поля (Index Calculus), руйнуючи очікувану експоненційну стійкість.
3. **Криві з малим дискримінантом комплексного множення (`|D| < 10^8`):**
   Криві, побудовані методом CM з малим дискримінантом `D`, мають ефективні ендоморфізми (метод Галланта — Ламберта — Ванстоуна, GLV), що прискорює скалярне множення у 2 рази, але вимагає додаткового аналізу на стійкість проти атак зі зменшенням розмірності простору пошуку.

## 12. Простір модулів та модулярні криві X₀(N), X₁(N), X(N)

У мові алгебраїчної геометрії значення j-інваріанта параметризує простір модулів еліптичних кривих `\mathcal{M}_{1, 1}`. Факторизація верхньої півплощини за конгруенц-підгрупами модулярної групи породжує компактні модулярні криві:

* `X(1) = \text{PSL}_2(\mathbb{Z}) \backslash \mathbb{H}^* \cong \mathbb{P}^1`: координатою на цій сфері є сама функція `j(\tau)`. Доповнення до каспа `Y(1) = \text{PSL}_2(\mathbb{Z}) \backslash \mathbb{H} \cong \mathbb{A}^1` є афінною прямою, де кожна точка однозначно задає клас ізоморфізму гладких еліптичних кривих.
* `X_0(N) = \Gamma_0(N) \backslash \mathbb{H}^*`: класифікує пари `(E, C_N)`, де `C_N` — циклічна підгрупа порядку `N`.
* `X_1(N) = \Gamma_1(N) \backslash \mathbb{H}^*`: класифікує пари `(E, P_N)`, де `P_N` — точка строгого порядку `N`.
* `X(N) = \Gamma(N) \backslash \mathbb{H}^*`: класифікує трійки `(E, P_N, Q_N)` з фіксованим базисом повного `N`-кручення `E[N]`.

Для рівнів `N \in \{2, 3, 4, 5, 6, 7, 8, 9, 10, 12, 13, 16, 18, 25\}` модулярна крива `X_0(N)` має рід 0. Поле модулярних функцій на ній є раціональним `\mathbb{C}(X_0(N)) \cong \mathbb{C}(w)`, а генератор `w(\tau)` називається **головним модулем** (нім. *Hauptmodul*).

Зв'язок між головним модулем `w` та j-інваріантом задається раціональним відображенням високого степеня. Наприклад, для рівня `N = 2` функція Фріке — Клейна `w(\tau) = (\eta(\tau)/\eta(2\tau))^{24}` виражає j-інваріант через формулу:

```
j(\tau) = (w(\tau) + 256)³ / w(\tau)²
```

Ці раціональні параметризації дозволяють ефективно генерувати криві з наперед заданими підгрупами кручення та будувати швидкі алгоритми підйому точок.

## 13. Відкриті теоретичні проблеми та сучасний фронт досліджень

Геометрія j-інваріанта перебуває на перетині найважливіших нерозв'язаних проблем сучасної математики:

1. **Гіпотеза Берча і Свіннертона-Даєра (BSD) та точки Хегнера:**
   У знаменитій теоремі Гросса — Цагіра та Коливагіна доведено, що висота Нерона — Тейта точок Хегнера, побудованих за допомогою сингулярних модулів `j(\tau)` для уявних квадратичних полів, пропорційна першій похідній L-функції еліптичної кривої `L'(E, 1)`. Це дало перший суворий доказ гіпотези BSD для кривих аналітичного рангу 1 над `\mathbb{Q}`.
2. **Гіпотеза Андре — Оорта для модулярних многовидів:**
   Гіпотеза стверджує, що алгебраїчна крива на прямому добутку модулярних кривих `\mathbb{C} \times \mathbb{C}` (просторі пар j-інваріантів `(j_1, j_2)`), яка містить нескінченно багато спеціальних точок (точок з комплексним множенням), є або вертикальною/горизонтальною прямою, або модулярною кривою `\Phi_N(X, Y) = 0` для деякого натурального `N`. Нещодавнє повне доведення цієї гіпотези методами теорії моделювання та o-мінімальності стало визначним тріумфом сучасної арифметичної алгебраїчної геометрії.
3. **Квантова стійкість пошуку шляхів ізогеній:**
   Попри успішні атаки Кастрика — Декру на схему SIDH (що спиралася на передачу додаткових образів точок кручення), загальна задача знаходження шляху між двома заданими надсингулярними j-інваріантами `j_1, j_2 \in \mathbb{F}_{p^2}` у графі Пайзера залишається квантово стійкою, формуючи математичний фундамент стандартизованої постквантової криптографії наступного покоління.

## 14. Аналітичні методи швидкого обчислення j-інваріанта

Для комплексних ґраток високої точності пряме сумування рядів Ейзенштейна `g₂` та `g₃` є неефективним через повільну збіжність. Замість цього застосовують алгоритм арифметико-геометричного середнього (AGM) Гауса:

Нехай `a₀ = 1`, `b₀ = \sqrt{1 - \lambda}`. Послідовності обчислюються за правилом:

```
a_{n+1} = (a_n + b_n) / 2
b_{n+1} = \sqrt{a_n · b_n}
```

Границя `M(1, \sqrt{1 - \lambda})` збігається квадратично: кожна ітерація подвоює кількість вірних знаків. Повний період кривої виражається як `K(\lambda) = \pi / (2 M(1, \sqrt{1 - \lambda}))`.

Далі відношення періодів `\tau = i K'(1 - \lambda) / K(\lambda)` підставляється в експоненційний q-розклад, що дає значення j-інваріанта з точністю до 1000 десяткових знаків за кілька мілісекунд. Алгоритм AGM також лежить в основі надшвидких методів обчислення фундаментальних математичних констант, алгоритмів Саламіна — Брента для високоточного обчислення числа `\pi` та чисельного інвертування повних еліптичних інтегралів Лежандра в аналітичній теорії чисел.

## 15. Програмна інженерія та довідник API

Для використання математичного апарату класифікації еліптичних кривих у реальних високонавантажених системах розроблено оптимізовану бібліотеку `libjinv`. Бібліотека надає повний спектр функцій: від базового розрахунку дискримінантів та відношень Тейта до матричного пакетного інвертування Монтгомері та паралельного обходу графів Рамануджана.

| Модель кривої | Канонічне рівняння | Формула j-інваріанта | Галузь застосування |
|---|---|---|---|

Завдяки модульній інваріантності класифікація кривих перетворюється на практичний інструмент сучасної математики та безпеки даних.
