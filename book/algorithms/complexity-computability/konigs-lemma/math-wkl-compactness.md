# 🧮 Математичний апарат: від принципу Діріхле до топології Кантора

Строге математичне доведення леми Кеніґа спирається на нескінченний принцип Діріхле та аксіоматику теорії множин, розкриваючи глибинну еквівалентність між деревною комбінаторикою та топологічною компактністю канторового простору. Формалізація цього математичного апарату пояснює, чому слабка лема Кеніґа WKL є точним вимірником компактності та доказової сили у сучасній зворотній математиці.

## 1. Формальні означення та класи графів

Розглянемо нескінченний граф G = (V, E), де V — множина вершин, E ⊆ V × V — множина ребер. Для строгості ми сприймаємо графи як ациклічні зв'язані структури з коренем.

Означення 1 (Локальна скінченність):
Граф G називається локально скінченним (locally finite), якщо для кожної вершини v ∈ V її степінь deg(v) є скінченним цілим числом:
```
∀ v ∈ V: deg(v) = |{ u ∈ V : (v, u) ∈ E }| < ∞
```
Зауважимо, що умова локальної скінченності не вимагає існування єдиної константи M такої, що deg(v) ≤ M для всіх v ∈ V. Степені вершин можуть зростати до нескінченності при віддаленні від кореня, якщо для кожного окремого вузла це значення є скінченним.

Означення 2 (Дерево з коренем):
Деревом T з коренем r називається зв'язаний ациклічний граф, у якому виділено вершину r ∈ V. Для кожної вершини v ∈ V існує єдиний простий шлях від r до v. Довжина цього шляху називається глибиною (або рівнем) вершини v і позначається depth(v).

Позначимо через T[v] піддерево з коренем у вершині v, що складається з v та всіх її нащадків:
```
T[v] = { u ∈ V : шлях від r до u проходить через v }
```

Формулювання Леми Кеніґа (Infinity Lemma):
Нехай T — нескінченне локально скінченне дерево з коренем r. Тоді у T існує принаймні один нескінченний простий шлях P = (v₀, v₁, v₂, ...), де v₀ = r і (vᵢ, vᵢ₊₁) ∈ E для всіх i ≥ 0.

## 2. Строге формальне доведення Леми Кеніґа

Побудуємо нескінченний шлях P = (v₀, v₁, v₂, ...) індуктивно.

### База індукції:
Обираємо v₀ = r. За умовою теореми, множина вершин дерева T нескінченна, тобто:
```
|T[v₀]| = |T| = ∞
```

### Індукційний крок:
Припустимо, що за припущенням індукції ми вже обирали послідовність вершин v₀, v₁, ..., vₖ таку, що піддерево T[vₖ] містить нескінченну кількість вершин:
```
|T[vₖ]| = ∞
```

Розглянемо множину безпосередніх нащадків вершини vₖ:
```
Children(vₖ) = { c₁, c₂, ..., c☵ }
```
Оскільки T є локально скінченним деревом, степінь deg(vₖ) є скінченним числом, а отже множина Children(vₖ) є строго скінченною (m < ∞).

Множину вершин піддерева T[vₖ] можна подати як об'єднання вершини vₖ та піддерев її дітей:
```
T[vₖ] = { vₖ } ∪ T[c₁] ∪ T[c₂] ∪ ... ∪ T[c☵]
```

Обчислимо потужність множини вершин T[vₖ]:
```
|T[vₖ]|
= 1 + |T[c₁]| + |T[c₂]| + ... + |T[c☵]|    [розбиття на диз'юнктні множини]
= ∞                                         [за припущенням індукції]
```

За нескінченним принципом Діріхле (Pigeonhole Principle for infinite sets): якщо скінченне об'єднання m множин має нескінченну потужність, то принаймні одна з цих множин повинна мати нескінченну потужність.

Отже, існує принаймні один нащадок cⱼ ∈ Children(vₖ) такий, що:
```
|T[cⱼ]| = ∞
```

Обираємо vₖ₊₁ = cⱼ. За побудовою vₖ₊₁ є суміжним з vₖ, а піддерево T[vₖ₊₁] лишається нескінченним.

За принципом математичної індукції (із застосуванням аксіоми залежного вибору DC у загальному випадку), ми отримуємо нескінченну послідовність (v₀, v₁, v₂, ...), яка утворює нескінченний шлях у T. Доведення завершено. ∎

## 3. Чому необхідна локальна скінченність: контраприклад

Покажемо, що вимога локальної скінченності є істотною і її вилучення руйнує теорему. Побудуємо нескінченне дерево T_inf, яке має нескінченне розгалуження в корені і не містить жодного нескінченного шляху.

### Конструкція:
Нехай корінь r має зліченну кількість дітей { u₁, u₂, u₃, ... }.
Для кожного n ≥ 1, піддерево під вершиною uₙ являє собою простий скінченний ланцюжок завдовжки n вершин:
```
uₙ,1 -> uₙ,2 -> ... -> uₙ,ₙ
```

Загальна кількість вершин у дереві T_inf дорівнює:
```
|T_inf|
= 1 + ∑ₙ₌₁^∞ n                               [сума довжин ланцюжків]
= 1 + 1 + 2 + 3 + 4 + ...
= ∞                                           [розбіжний ряд]
```

Отже, дерево T_inf містить нескінченну кількість вершин. Проте будь-який шлях, що починається з кореня r, має вигляд:
```
Path(n) = (r, uₙ,1, uₙ,2, ..., uₙ,ₙ)
```
Довжина такого шляху дорівнює n + 1, що є скінченним числом для кожного n. Отже, у дереві T_inf немає жодного нескінченного шляху. 

Причина провалу: корінь r має нескінченний степінь deg(r) = ∞. Нескінченна сума скінченних чисел може бути нескінченною без існування бодай одного нескінченного доданка.

## 4. Слабка Лема Кеніґа (WKL) та Канторів простір

У математичній логіці окремий інтерес становить **Слабка Лема Кеніґа** (Weak König's Lemma, WKL), яка обмежує розгалуження дерев строго бінарними виборами.

Нехай 2^{<ω} — множина всіх скінченних бінарних слів (послідовностей з 0 та 1). Дерево T ⊆ 2^{<ω} називається піддеревом, якщо воно замкнене відносно префіксів:
```
∀ σ, τ ∈ 2^{<ω}: (τ ∈ T ∧ σ ⊆ τ) ⇒ σ ∈ T
```

Формулювання WKL:
Кожне нескінченне бінарне дерево T ⊆ 2^{<ω} містить принаймні одну нескінченну гілку f ∈ 2^ω (де f : N -> {0, 1} і f|ₙ ∈ T для всіх n ∈ N).

### Еквівалентність компактності Канторового простору

Розглянемо топологічний простір Кантора 2^ω з продуктовою топологією (яка еквівалентна метричному простору з відстанню d(f, g) = 2^{-k}, де k — найменший індекс, у якому f(k) ≠ g(k)).

Теорема (Еквівалентність WKL та компактності):
Слабка Лема Кеніґа WKL еквівалентна твердженню, що канторів простір 2^ω є топологічно компактним (теорема Тіхонова для зліченного добутку двоточкових компактів).

Доведення (схема):
Нехай K ⊆ 2^ω — замкнена множина. Кожній замкненій множині в 2^ω відповідає дерево префіксів T_K ⊆ 2^{<ω}:
```
T_K = { σ ∈ 2^{<ω} : ∃ f ∈ K (σ ⊂ f) }
```
Якщо множина K порожня (K = ∅), то для кожного n існує рівень, на якому жодне слово не продовжується до елемента K. За скінченною структурою рівня це означає, що дерево T_K є скінченним.
Якщо ж дерево T_K нескінченне, за лемою WKL існує нескінченна гілка f ∈ 2^ω. Оскільки K замкнена, f ∈ K, а отже K ≠ ∅.
Звідси випливає, що з будь-якого відкритого покриття 2^ω можна виділити скінченне підпокриття. ∎

## 5. Обчислимісний аналіз та Теорема Кліні про базис

Коли дерево T задано характеристичною функцією, виникає питання про обчислимісну складність нескінченної гілки f.

Теорема Кліні про базис (Kleene's Basis Theorem):
Нехай T ⊆ 2^{<ω} — обчислюване (рекурсивне) нескінченне бінарне дерево. Тоді у T існує нескінченна гілка f ∈ 2^ω, яка є обчислювальною відносно оракула проблеми зупинки 0' (тобто f ∈ Δ₂⁰ в арифметичній ієрархії).

Доведення (конструкція найлівішої гілки):
Визначимо найлівішу нескінченну гілку f_left індуктивно.
Нехай σₖ — префікс довжини k. Перевіримо, чи є піддерево T[σₖ ˆ 0] нескінченним.
Зауважимо, що предикат «піддерево T[σ] є нескінченним» виражається формулою квантора Π₁⁰:
```
IsInfinite(σ) ≡ ∀ n ∈ N ∃ τ ∈ T (σ ⊆ τ ∧ |τ| ≥ n)
```
Предикат Π₁⁰ розв’язується з використанням оракула проблеми зупинки 0'.

Алгоритм вибору значення f_left(k):
```
Якщо IsInfinite(σₖ ˆ 0) = True:
    f_left(k) = 0
Інакше:
    f_left(k) = 1
```
Оскільки принаймні одне з піддерев T[σₖ ˆ 0] або T[σₖ ˆ 1] є нескінченним, ця процедура побудує послідовність f_left, яка є нескінченною гілкою і обчислюється алгоритмом з оракулом 0'. ∎

Оцінка складності за Постом:
```
f_left ∈ Δ₂⁰ = Σ₂⁰ ∩ Π₂⁰   [обчислюваність з оракулом K = 0']
```
Це доводить строго, що нескінченна гілка не обов'язково є обчислювальною (Δ₁⁰), але завжди лежить у межах другого рівня арифметичної ієрархії (Δ₂⁰).

## 6. Зворотна математика та підсистема WKL₀

У програмі зворотної математики (Simpson, 1999) вивчаються формальні підсистеми арифметики другого порядку над базовою системою RCA₀ (Recursive Comprehension Axiom).

Формалізація аксіоми WKL₀:
```
WKL₀ ≡ RCA₀ + (Кожне нескінченне піддерево T ⊆ 2^{<ω} має нескінченну гілку f ∈ 2^ω)
```

Система WKL₀ займає проміжне становище між предикативною математикою RCA₀ та арифметичною компрігенцією ACA₀:
```
RCA₀  ⊢  (WKL₀ ⇔ Теорема Гейне-Бореля для [0, 1])
RCA₀  ⊢  (WKL₀ ⇔ Теорема про проміжне значення)
RCA₀  ⊢  (WKL₀ ⇔ Теорема Стоуна-Вейєрштрасса)
```

Ці еквівалентності показують, що Славка Лема Кеніґа є точним формально-логічним еквівалентом компактності замкнених інтервалів у класичному аналізі.

## 7. Доведення детермінованості нескінченних ігор Гейла-Стюарта

Розглянемо детальний математичний зв'язок між WKL та детермінованістю відкритих ігор Гейла-Стюарта.

Нехай гра відкрита для Гравця I, тобто його виграшна множина W ⊆ 2^ω відкрита в топології Кантора. Це означає, що W подається як об'єднання циліндричних множин:
```
W = ⋃ { [σ] : σ ∈ S }
```
де S ⊆ 2^{<ω} — деяка множина скінченних виграшних слів.

Побудуємо дерево T_loss позицій Гравця II, у яких Гравець I ще не виграв:
```
T_loss = { τ ∈ 2^{<ω} : ∀ σ ⊆ τ (σ ∉ S) }
```

Якщо дерево T_loss нескінченне, то за лемою WKL воно містить нескінченну гілку f ∈ 2^ω. За побудовою T_loss, для будь-якого префікса f|ₙ маємо f|ₙ ∉ S. Отже, послідовність f ∉ W, що означає виграш Гравця II.

Якщо ж дерево T_loss скінченне, Гравець I має виграшну стратегію досягнення множини S за скінченне число кроків. Отже, гра строго детермінована. ∎

## 8. Доведення теореми про проміжне значення через WKL₀

Покажемо, як WKL₀ використовується для побудови кореня неперервної функції f: [0, 1] -> R такої, що f(0) < 0 та f(1) > 0.

Побудуємо бінарне дерево трихотомічного ділення інтервалу T_IVT.
На кожному рівні k розглянемо відрізок I_σ довжиною 2^{-k}, що відповідає бінарному слову σ ∈ {0, 1}ᵏ:
1. Корінь σ = ∅ відповідає інтервалу [0, 1].
2. Вершина σ належить дереву T_IVT тоді й лише тоді, коли функція f приймає значення різних знаків або близькі до нуля на кінцях інтервалу I_σ:
```
f(left(I_σ)) ≤ 2^{-k} ∧ f(right(I_σ)) ≥ -2^{-k}
```

За теоремою про проміжне значення для скінченних наближень, на кожному рівні k існує принаймні один такий інтервал I_σ. Отже, дерево T_IVT є нескінченним і локально скінченним (бінарним).

За лемою WKL₀, у T_IVT існує нескінченна гілка c ∈ 2^ω. Ця гілка задає послідовність вкладених інтервалів, перетин яких за теоремою про вкладені відрізки визначає точку c ∈ [0, 1] таку, що f(c) = 0. ∎

## 9. Побудова Генкіна для повноти логіки першого порядку

Розглянемо формалізацію доведення теореми Ґеделя-Генкіна про повноту з використанням бінарного дерева часткових семантичних оцінок T_Henkin.

Нехай L — мова першого порядку з константами Генкіна c₁, c₂, c₃, ..., а Γ — несуперечлива множина речень.
Побудуємо перелік усіх можливих речень мови L: φ₁, φ₂, φ₃, ...

Кожна вершина на рівні n бінарного дерева T_Henkin описується словом σ = (b₁, b₂, ..., b♙) ∈ {0, 1}ⁿ, де bᵢ = 1 означає прийняття речення φᵢ, а bᵢ = 0 — його заперечення ¬φᵢ.

Вершина σ належить дереву T_Henkin тоді й лише тоді, коли кон'юнкція обраних речень разом із Γ є скінченно несуперечливою (тобто не виводиться суперечність ⊥ за скінченне число кроків доведення).

За умовою несуперечливості Γ, на кожному рівні n існує хоча б один сумісний префікс σ. Отже, дерево T_Henkin є нескінченним бінарним деревом.

За лемою WKL₀, існує нескінченна гілка H ∈ 2^ω. Ця гілка утворює максимальну несуперечливу множину речень Генкіна (Henkin maximal consistent set), з якої канонічно будується алгебраїчна модель M ⊨ Γ. 

Вирішальним фактором у побудові Генкіна є сколемізація кванторів існування: для кожного речення ∃ x ψ(x) додаєтьсяведена константа Генкіна cₖ така, що ψ(cₖ) входить у списки речень на відповідному рівні розгортання дерева. Завдяки WKL₀ процедура Сколема не створює суперечностей і гарантує зліченність побудованої канонічної моделі M. 

З алгебраїчної точки зору, побудова Генкіна еквівалентна теоремі про ультрафільтри у булевих алгебрах (Boolean Prime Ideal Theorem, BPI). Лема WKL₀ є строго слабшою за ZORN та AC, надаючи мінімально необхідну базисну силу для побудови моделей зліченних теорій. ∎
