# 🧮 Математичний метод пріоритету та оператор стрибка

Ця вставка містить математичний апарат теорії ступенів Тюринга: строге визначення оракульної обчислюваності через функцію використання, побудову непорівнянних ступенів за методом Кліні — Поста, повне доведення теореми Фрідберга — Мучника методом пріоритету з скінченними пошкодженнями та аналіз властивостей оператора стрибка Тюринга.

## 1. Строгий формалізм Тюрингової зведенності

Нехай `A` та `B` — підмножини множини натуральних чисел `N`. Характеристичною функцією множини `B` є функція `χ_B : N → {0, 1}`, де `χ_B(x) = 1`, якщо `x ∈ B`, і `χ_B(x) = 0`, якщо `x ∉ B`.

Оракульна машина Тюринга `M^B` під час обчислення на вхідному значенні `x` виконує скінченну кількість запитів до оракула `B`. Позначимо через `u(x)` **функцію використання** (англ. *use function*), яка дорівнює `1 + max {y | під час обчислення M^B(x) відбувся запит 'чи y ∈ B?'}`. Якщо обчислення `M^B(x)` зупиняється за `T` кроків, то за один крок машина може записати на стрічку запиту номер комірки, що не перевищує `T`. Отже, значення `u(x)` є скінченним і обмеженим кількістю кроків обчислення:

```
[Обчислення M^B(x)] ── Запити до оракула: y_1, y_2, ..., y_k ──> u(x) = 1 + max(y_i)
```

**Означення 1 (Зведенність за Тюрингом).** Множина `A` є зведеною за Тюрингом до множини `B` (`A ≤_T B`), якщо існує номер оракульної машини `e` такий, що для кожного `x ∈ N` обчислення `M_e^B(x)` зупиняється і повертає значення `χ_A(x)`.

**Властивість локальності:** Оскільки `u(x)` є скінченним числом, результати обчислення `M_e^B(x)` залежать лише від скінченного початкового відрізка характеристичного рядка `B`, а саме від `B ↾ u(x) = {y ∈ B | y < u(x)}`. Якщо інша множина `C` збігається з `B` на всіх елементах, менших за `u(x)`, то `M_e^C(x) = M_e^B(x)`.

**Означення 2 (Ступінь Тюринга).** Відношення `A ≡_T B ⇔ (A ≤_T B ∧ B ≤_T A)` є відношенням еквівалентності на `P(N)`. Клас еквівалентності множини `A` позначується як `deg(A)` або `a`. Множина всіх ступенів Тюринга позначується через `D_T`.

Частковий порядок на `D_T` задається умовою: `deg(A) ≤ deg(B) ⇔ A ≤_T B`.

**Верхня напівґратка:** Для будь-яких двох множин `A` та `B` їхнім точним верхнім обмеженням (англ. *join*) є ступінь множини симетричного об'єднання `A ⊕ B = {2x | x ∈ A} ∪ {2x + 1 | x ∈ B}`. Ступінь `deg(A ⊕ B)` є найменшим ступенем `c`, для якого `deg(A) ≤ c` та `deg(B) ≤ c`. Отже, `(D_T, ≤, ∨)` утворює верхню напівґратку з найменшим елементом `0 = deg(∅)`.

## 2. Метод скінченних розширень Кліні — Поста

Доведемо існування непорівнянних ступенів Тюринга нижче ступеня `0'`.

**Теорема 1 (Кліні — Пост, 1954).** Існують такі множини `A, B ⊆ N`, що `A ≰_T B` та `B ≰_T A`.

**Доведення:**
Побудуємо характеристичні рядки `α_s` та `β_s` (скінченні бінарні послідовності) покроково так, щоб множини `A = lim_s α_s` та `B = lim_s β_s` задовольняли дві нескінченні серії вимог для кожного `e ∈ N`:

```
P_e : A ≠ M_e^B   (гарантує A ≰_T B)
Q_e : B ≠ M_e^A   (гарантує B ≰_T A)
```

Впорядкуємо вимоги в єдиний список: `P_0, Q_0, P_1, Q_1, ...`

**Крок s = 2e (Задоволення вимоги P_e):**
Маємо поточні скінченні послідовності `α_s` та `β_s`. Обираємо свідок `x = |α_s|` (довжина послідовності `α_s`).
Шукаємо скінченне розширення `β'` послідовності `β_s` таке, що машина `M_e^{β'}(x)` зупиняється за деяку кількість кроків.

- **Випадок 1:** Таке розширення `β'` існує.
  Нехай `M_e^{β'}(x) = v`. Обираємо `α_{s+1} = α_s ˆ (1 - v)` (призначаємо `χ_A(x) = 1 - v`, що гарантує відмінність від значення `v`) та `β_{s+1} = β'`.
  Оскільки `χ_A(x) ≠ M_e^B(x)`, вимога `P_e` виконана.

- **Випадок 2:** Такого розширення `β'` не існує.
  Це означає, що для будь-якого розширення `β'` машина `M_e^{β'}(x)` розбігається (працює нескінченно).
  Тоді покладаємо `α_{s+1} = α_s ˆ 0` та `β_{s+1} = β_s`. Оскільки `M_e^B(x)` розбігається, функція `M_e^B` не є всюди визначеною, тому `A ≠ M_e^B`. Вимога `P_e` виконана.

**Крок s = 2e + 1 (Задоволення вимоги Q_e):**
Симетрично обираємо свідок `y = |β_s|` та шукаємо розширення `α'` для послідовності `α_s`.

Оскільки на кожному кроці `s` довжини послідовностей зростають щонайменше на `1`, граничні множини `A` та `B` є всюди визначеними. Усі вимоги `P_e` та `Q_e` задовольняються, отже, `A ≰_T B` та `B ≰_T A`. Множини `A` та `B` є обчислюваними відносно `0'`, проте не є рекурсивно перелічними. ∎

## 3. Теорема Фрідберга — Мучника та метод пріоритету

Щоб розв'язати проблему Поста, множини `A` та `B` повинні бути рекурсивно перелічними (р.п.). Це означає, що ми можемо лише **додавати** елементи до `A` та `B` під час побудови, але ніколи не можемо їх вилучати.

**Теорема 2 (Фрідберг — Мучник, 1956/1957).** Існують рекурсивно перелічні множини `A, B ⊆ N` такі, що `0 <_T A <_T 0'`, `0 <_T B <_T 0'`, причому `A ≰_T B` та `B ≰_T A`.

**Доведення (Метод пріоритету з скінченними пошкодженнями):**

Сформулюємо нескінченний набір вимог:
```
R_{2e}   : A ≠ M_e^B   (забезпечується свідком x_e)
R_{2e+1} : B ≠ M_e^A   (забезпечується свідком y_e)
```

Вимоги мають природний пріоритет: `R_0 > R_1 > R_2 > ... > R_n > ...`

Для кожної вимоги `R_{2e}` ми призначаємо рухомий свідок `x_e[s]`. Початково `x_e[0]` призначається з вільних натуральних чисел.

**Стратегія для вимоги R_{2e} на кроці s:**
1. Очікуємо, поки обчислення `M_e^{B_s}(x_e[s])` зупиниться за `≤ s` кроків і поверне `0`.
2. Якщо обчислення зупинилося і повернуло `0`, вимога `R_{2e}` хоче внести свідок `x_e[s]` до множини `A_{s+1}`. Це змінить `χ_A(x_e[s])` з `0` на `1`, гарантуючи `A(x_e[s]) ≠ M_e^B(x_e[s])`.
3. Аби обчислення `M_e^{B_s}(x_e[s])` не змінило свого результату у майбутньому, вимога `R_{2e}` встановлює **обмеження** (англ. *restraint*) `r_{2e}[s] = u(x_e[s])`. Множина `B` не повинна змінюватися на елементах, менших за `r_{2e}[s]`.

**Конфлікт (Пошкодження, англ. *Injury*):**
Якщо вимога нижчого пріоритету `R_{2e+1}` (де `2e+1 > 2e`) додає свій свідок `y_e` до множини `B`, щоб задовольнити власну умову, це додавання може порушити оракульні відповіді для `M_e^B(x_e)`, за якими спостерігала вимога `R_{2e}`. Якщо `y_e < r_{2e}[s]`, кажуть, що вимога `R_{2e}` зазнала **пошкодження**.

**Правило пріоритету:**
Вимога `R_i` має право додати свій свідок до відповідної множини тільки тоді, коли цей свідок перевищує всі обмеження вимог з вищим пріоритетом `R_j` (де `j < i`).

```
Вимоги вищого пріоритету: R_0, R_1, ..., R_{i-1}
Обмеження (Restraint):   R_max = max_{j < i} r_j[s]
              │
              ▼
Вимога R_i додає свідок z лише якщо z > R_max
```

**Алгоритм побудови на кроці s+1:**
1. Запускаємо машини `M_0, M_1, ..., M_s` на свідках `x_e[s], y_e[s]` протягом `s` кроків.
2. Знаходимо вимогу `R_k` з найменшим індексом `k ≤ s`, яка є ненаситненою, для якої обчислення зупинилося з результатом `0`, і свідок якої більший за обмеження всіх вимог `R_j` з `j < k`.
3. Якщо таку вимогу `R_k` знайдено:
   - Якщо `k = 2e`, додаємо `x_e[s]` до `A_{s+1}`.
   - Якщо `k = 2e+1`, додаємо `y_e[s]` до `B_{s+1}`.
   - Вимога `R_k` оголошується насиченою.
   - Усі вимоги `R_m` нижчого пріоритету (`m > k`) вважаються пошкодженими: їхні свідки скидаються і перевизначаються новими значеннями, більшими за всі використані числа.

**Доведення стабілізації (Індукція за індексом вимоги k):**

*База індукції (k = 0):* Вимога `R_0` має найвищий пріоритет. Вона ніколи не зазнає пошкоджень від інших вимог. Її свідок `x_0` призначається один раз. Якщо `M_0^B(x_0)` розбігається або повертає значення, відмінне від `0`, свідок `x_0` ніколи не входить до `A`, тому `A(x_0) ≠ M_0^B(x_0)`. Якщо ж `M_0^B(x_0) = 0`, свідок `x_0` додається до `A`, після чого `R_0` стає насиченою назавжди. Обмеження `r_0` стабілізується.

*Індукційний крок:* Припустимо, що всі вимоги `R_0, R_1, ..., R_{k-1}` стабілізувалися до кроку `s_0` і більше ніколи не змінюють своїх станів та обмежень. Нехай `R_max = max_{j < k} r_j` — підсумкове фіксоване обмеження. Після кроку `s_0` вимога `R_k` більше ніколи не зазнає пошкоджень. Вона отримує остаточний свідок `z > R_max`. Після кроку `s_0` вимога `R_k` може діяти щонайбільше один раз. Після цього вона стає насиченою назавжди.

Отже, кожна вимога `R_k` зазнає лише скінченної кількості пошкоджень. Усі вимоги задовольняються, тому побудовані рекурсивно перелічні множини `A` та `B` є Тюринг-непорівнянними: `A ≰_T B` та `B ≰_T A`. З цього безпосередньо випливає `0 <_T A <_T 0'` та `0 <_T B <_T 0'`. Теорему доведено. ∎

## 4. Оператор стрибка Тюринга та Теорема Поста

Для довільної множини `A ⊆ N` оператор стрибка Тюринга визначається як універсальна р.п. відносно `A` множина:

```
A' = {e ∈ N | M_e^A(e) зупиняється}
```

### Властивості стрибка Тюринга:
1. **Необчислюваність відносно носія:** Для будь-якої множини `A` виконується `A <_T A'`. Враховуючи `A ≤_T A'`, діагональний аргумент доводить `A' ≰_T A`.
2. **Монотонність:** Якщо `A ≤_T B`, то `A' ≤_T B'`.
3. **Інваріантність відносно ступенів:** Якщо `A ≡_T B`, то `A' ≡_T B'`. Це дозволяє коректно визначити стрибок на ступенях: `(deg(A))' = deg(A')`.

**Ітерації стрибка:**
Starting from `0 = deg(∅)`:
- `0'` — ступінь класичної проблеми зупинки `K = {e | M_e(e) ↓}`.
- `0'' = (0')'` — ступінь проблеми зупинки для оракула `K`.
- `0^{(n)}` — `n`-кратний стрибок порожньої множини.

**Теорема 3 (Поста про арифметичну ієрархію).**
Нехай `n ≥ 1`. Множина `A ⊆ N` належить до класу `Σ_n^0` арифметичної ієрархії тоді й лише тоді, коли `A` є рекурсивно перелічною відносно оракула `0^{(n-1)}`. Крім того, `A ∈ Δ_{n+1}^0 ⇔ A ≤_T 0^{(n)}`.

**Зв'язок класичних проблем зі ступенями стрибка:**
- Множина `Fin = {e | W_e є скінченною}` є `Σ_2^0`-повною, отже `Fin ≡_T 0''`.
- Множина `Cof = {e | W_e є коскінченною}` є `Σ_3^0`-повною, отже `Cof ≡_T 0'''`.

**Теорема 4 (Фрідберга про обернення стрибка, 1957).**
Для будь-якого ступеня `b ∈ D_T` такого, що `b ≥ 0'`, існує ступінь `a ∈ D_T` такий, що `a' = b`.

Це означає, що область значень оператора стрибка `a ↦ a'` збігається з конусом ступенів `{b ∈ D_T | b ≥ 0'}`.
