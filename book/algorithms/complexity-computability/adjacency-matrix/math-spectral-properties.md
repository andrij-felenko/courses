# 🧮 Спектральні та алгебраїчні властивості матриці суміжності

Ця математична вставка містить формальне виведення алгебраїчних властивостей матриці суміжності, доведення теореми про кількість шляхів через піднесення до степеня, формулу підрахунку трикутників через слід матриці та аналіз її спектрального спектра.

Матриця суміжності є сполучною ланкою між дискретною топологією графа та безперервною лінійною алгеброю. Представлення графа у вигляді квадратної дійсної матриці дозволяє застосовувати весь потужний апарат векторних просторів, власних векторів та спектрального розкладу для виявлення прихованих геометричних і комбінаторних системних властивостей.

## 1. Алгебраїчне визначення та операція піднесення до степеня

Нехай `G = (V, E)` — простий граф із `N` вершинами, пронумерованими від `0` до `N - 1`. Його **матрицею суміжності** `A` є квадратна матриця розмірності `N × N`, елементи якої визначені як:

```
A[i][j] = 1,  якщо (i, j) ∈ E
A[i][j] = 0,  якщо (i, j) ∉ E
```

Для неорієнтованого графа матриця `A` є симетричною (`A = Aᵀ`), а для графа без петлі всі діагональні елементи дорівнюють нулю (`A[i][i] = 0`).

### Теорема про кількість шляхів

**Теорема.** Для будь-якого натурального числа `k ≥ 1` елемент `(Aᵏ)[i][j]` k-го степеня матриці суміжності дорівнює точній кількості маршрутів (walks) довжини `k` від вершини `i` до вершини `j`.

**Доведення (метод математичної індукції).**

*База індукції (`k = 1`).* За визначенням матриці суміжності `(A¹)[i][j] = A[i][j]`. Якщо ребро `(i, j)` існує, є рівно 1 маршрут довжини 1. Якщо ребра немає — 0 маршрутів. База справджується.

*Індукційний крок.* Припустимо, що твердження вірне для `k - 1`, тобто `(Aᵏ⁻¹)[i][m]` дорівнює кількості маршрутів довжини `k - 1` від `i` до `m`.

Розглянемо множення матриць `Aᵏ = Aᵏ⁻¹ · A`. За визначенням матричного множення елемент на позиції `(i, j)` обчислюється як:

```
(Aᵏ)[i][j] 
= ∑ₘ (Aᵏ⁻¹)[i][m] · A[m][j]     [за визначенням добутку матриць]
```

Розберемо кожен додаток у цій сумі:
1. `(Aᵏ⁻¹)[i][m]` — це кількість маршрутів довжини `k - 1` від `i` до проміжної вершини `m` (за припущенням індукції).
2. `A[m][j]` — це прапорець (1 або 0), який показує, чи можна зробити останній `k`-й крок із вершини `m` у вершину `j`.

Отже, добуток `(Aᵏ⁻¹)[i][m] · A[m][j]` дає кількість маршрутів довжини `k`, які проходять через вершину `m` безпосередньо перед фінішем у `j`. Підсумовуючи по всіх можливих проміжних вершинах `m ∈ V`, ми отримуємо повну кількість маршрутів довжини `k` від `i` до `j`. Теорему доведено.

## 2. Слід матриці та обчислення комбінаторних структур

Слідом квадратної матриці `Tr(A)` називається сума її діагональних елементів:

```
Tr(A) = ∑ᵢ A[i][i]
```

Оскільки в графі без петель `A[i][i] = 0`, слід самої матриці `Tr(A) = 0`. 

### Квадрат матриці та кількість ребер `Tr(A²)`

Слід квадрата матриці `Tr(A²)` дає сумарну кількість замкнених маршрутів довжини 2. Оскільки в неорієнтованому графі кожен маршрут довжини 2 від `i` до `i` відповідає переходу `i → m → i` по існуючому ребру `(i, m)`, маємо:

```
Tr(A²) = ∑ᵢ (A²)[i][i] 
       = ∑ᵢ ∑ₘ A[i][m] · A[m][i]
       = ∑ᵢ ∑ₘ (A[i][m])²           [бо A[i][m] = A[m][i]]
       = 2 · M                     [де M — загальна кількість ребер]
```

Таким чином, `Tr(A²) / 2 = M` дає точну кількість ребер графа.

### Куб матриці та кількість трикутників `Tr(A³)`

Обчислимо слід третього степеня матриці суміжності `Tr(A³)` для неорієнтованого графа:

```
(A³)[i][i] = ∑ⱼ ∑ₘ A[i][j] · A[j][m] · A[m][i]
```

Доданок `A[i][j] · A[j][m] · A[m][i]` дорівнює `1` тоді й лише тоді, коли в графі існують ребра `(i, j)`, `(j, m)` та `(m, i)`. Ця трійка вершин утворює трикутник (кліку розміру 3).

Кожен конкретний трикутник із вершинами `{u, v, w}` підраховується в сумі `Tr(A³)` кілька разів:
1. Початковою вершиною `i` може бути будь-яка з 3 вершин (`u`, `v` або `w`).
2. Для обраної початкової вершини напрямок обходу трикутника можна обрати 2 способами (за годинниковою стрілкою або проти неї).

Отже, один трикутник робить внесок `3 × 2 = 6` у загальну суму `Tr(A³)`:

```
Tr(A³) = 6 · T
⇒ T = Tr(A³) / 6
```

де `T` — точна кількість підграфів-трикутників у графі `G`.

### Четвертий степінь матриці `Tr(A⁴)` та чотирикутники

Аналогічно, слід `Tr(A⁴)` відповідає замкненим маршрутам довжини 4. Внесок у `Tr(A⁴)` роблять не лише прості цикли довжини 4 (`C₄`), але й маршрути виду `u → v → u → v → u` та «зірки» з 2 ребер. Точна формула для кількості підграфів-чотирикутників `C₄`:

```
C₄ = (Tr(A⁴) - 2M - 2 ∑ᵢ deg(i)(deg(i) - 1)) / 8
```

## 3. Спектр матриці суміжності та його властивості

Оскільки для неорієнтованого графа матриця суміжності `A` є дійсною та симетричною (`A = Aᵀ`), за **спектральною теоремою** вона має `N` дійсних власних значень (з урахуванням кратності):

```
λ₁ ≥ λ₂ ≥ ... ≥ λₙ
```

Множина цих власних значень називається **спектром графа** `Spec(G)`.

Характеристичний многочлен графа визначено як:

```
P_A(λ) = det(λ I - A) = λⁿ - c₁ λⁿ⁻¹ + c₂ λⁿ⁻² - c₃ λⁿ⁻³ + ...
```

Коефіцієнти характеристичного многочлена відображають комбінаторні структури графа:
* `c₁ = Tr(A) = 0`
* `c₂ = M` (кількість ребер)
* `c₃ = 2T` (подвоєна кількість трикутників)

### Максимальне власне значення (Perron-Frobenius)

За теоремою Перрона — Фробеніуса для невід'ємних матриць найбільше власне значення `λ₁` (спектральний радіус) задовольняє нерівності:

```
d_avg ≤ λ₁ ≤ d_max
```

де `d_avg = 2M / N` — середня степінь вершин графа, а `d_max` — максимальна степінь вершини.

Якщо граф є **k-регулярним** (степінь кожної вершини дорівнює `k`), то `λ₁ = k`, а відповідним власним вектором є вектор з усіх одиниць `x = (1, 1, ..., 1)ᵀ`, оскільки:

```
(A · x)ᵢ = ∑ⱼ A[i][j] · 1 = deg(i) = k = k · xᵢ
```

### Симетрія спектра двочасткових графів

**Теорема.** Неорієнтований граф `G` є двочастковим тоді й лише тоді, коли його спектр симетричний відносно нуля. Тобто якщо `λ` є власним значенням `A`, то `-λ` також є власним значенням з тією самою кратністю.

*Доведення.* У двочастковому графі вершини можна розбити на дві множини `V₁` та `V₂` такі, що ребра існують лише між `V₁` та `V₂`. Перестановою індексів матрицю суміжності можна звести до блочного вигляду:

```
    [  0   B ]
A = [        ]
    [ Bᵀ   0 ]
```

Нехай `x = (u, v)ᵀ` — власний вектор, що відповідає власному значенню `λ`:

```
[  0   B ]   [ u ]     [   B · v   ]     [ λ · u ]
[        ] · [   ]  =  [           ]  =  [       ]
[ Bᵀ   0 ]   [ v ]     [  Bᵀ · u   ]     [ λ · v ]
```

Розглянемо вектор `y = (u, -v)ᵀ`. Помножимо `A` на `y`:

```
[  0   B ]   [  u ]     [  -B · v   ]     [ -λ · u ]
[        ] · [    ]  =  [           ]  =  [        ] = -λ · y
[ Bᵀ   0 ]   [ -v ]     [   Bᵀ · u  ]     [  λ · v ]
```

Отже, `y` є власним вектором для власних значень `-λ`. Симетрію доведено.

### Спектральний розрив та експандери

Різниця між першим та другим власними значеннями `λ₁ - λ₂` називається **спектральним розривом** (Spectral Gap). Чим більший спектральний розрив, тим швидше випадкове блукання (Random Walk) на графі збігається до рівномірного розподілу. Графи з великим спектральним розривом називаються **експандерами** (Expander Graphs) і використовуються в теорії кодування та мережевих топологіях.

## 4. Зв'язок із матрицею Лапласа та доповненням графа

Матриця суміжності `A` є базою для побудови інших фундаментальних операторів теорії графів.

### Матриця Лапласа (Laplacian Matrix)

Матриця Лапласа `L` визначається як різниця між діагональною матрицею ступенів `D` (`D[i][i] = deg(i)`) та матрицею суміжності `A`:

```
L = D - A
```

Компоненти матриці `L`:
```
L[i][j] =  deg(i),  якщо i = j
L[i][j] = -1,      якщо i ≠ j та (i, j) ∈ E
L[i][j] =  0,      якщо i ≠ j та (i, j) ∉ E
```

Найменше власне значення `L` завжди дорівнює `μ₁ = 0`. Друге за величиною власне значення `μ₂` (називається **алгебраїчною зв'язністю** або вектором Фідлера) є більше нуля (`μ₂ > 0`) тоді й лише тоді, коли граф є зв'язаним.

### Нормалізована матриця Лапласа

Для графів із нерівномірним розподілом ступенів використовують нормалізовану матрицю Лапласа `L_norm`:

```
L_norm = D⁻¹/² · L · D⁻¹/² = I - D⁻¹/² · A · D⁻¹/²
```

Елементи `L_norm[i][j]` дорівнюють `-1 / √(deg(i) · deg(j))` при наявності ребра, що усуває вплив вершин-хабів при спектральній кластеризації.

### Матриця доповнення графа

Доповненням графа `Ḡ` називається граф на тих самих вершинах, де ребро існує тоді й лише тоді, коли його немає в `G`. Матриця суміжності доповнення `A(Ḡ)` виражається через матрицю з усіх одиниць `J` та одиничну матрицю `I`:

```
A(Ḡ) = J - I - A(G)
```

Ця формула дозволяє миттєво обчислювати властивості доповнення графа без перебудови структур даних.
