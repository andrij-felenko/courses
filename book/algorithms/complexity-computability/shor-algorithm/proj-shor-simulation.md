# ⚙️ Програмна емуляція квантового пошуку періоду та факторизації Шора

Алгоритм Шора є гібридною обчислювальною системою: квантове ядро розв'язує задачу пошуку періоду функції модульного піднесення до степеня за поліноміальний час, а класичний процесор виконує початкову підготовку, розклад фази у неперервні дроби та фінальне вилучення простих множників через алгоритм Евкліда. Дослідження фізичних принципів квантової інтерференції та квантової заплутаності найзручніше здійснювати шляхом побудови повнофункціонального симулятора квантового вектора стану.

Розгляньмо інженерну архітектуру класичного емулятора квантових вентилів, спосіб представлення квантового стану в пам'яті, методику імітації квантової заплутаності між регістрами, алгоритм оберненого квантового перетворення Фур'є, квантові схеми модульного додавання, порівняння парадигм симуляції, механізм вилучення періоду неперервними дробами, повноцінну реалізацію на C, C++ та Python, а також детальний розбір граничних режимів і числових експериментів.

## 1. Архітектурні виклики симуляції квантових систем

Класичне моделювання квантових вентильних схем стикається з фундаментальним обмеженням архітектури фон Неймана — експоненційним зростанням гільбертового простору. Квантовий регістр з `m` кубітів вимагає збереження вектора з `2ᵐ` комплексних амплітуд `c_j ∈ ℂ`. При виборі подвійної точності (`double complex`, 16 байтів на амплітуду) обсяг оперативної пам'яті підпорядковується закону:

```
Memory(m) = 2ᵐ · 16 байтів
```

Для демонстраційних задач факторизації чисел `N < 100` достатньо регістра з `m = 10..14` кубітів, що вимагає від 16 КБ до 256 КБ RAM. Проте для криптографічного ключа RSA-2048 (`n = 2048` біт, `m = 2n = 4096` кубітів) розмірність вектора `2⁴⁰⁹⁶` перевищує кількість елементарних часток у Всесвіті.

Чому для симуляції алгоритму Шора неможливо застосувати ефективні стабілізаторні симулятори типу Ааронсона — Готтесмана? Теорема Готтесмана — Кнілла стверджує, що квантові схеми, які містять лише вентилі групи Кліффорда (Hadamard, CNOT, Phase S), можуть моделюватися на класичному комп'ютері за поліноміальний час `O(m²)`. Однак алгоритм Шора принципово використовує операції, що виходять за межі групи Кліффорда:
- Контрольовані фазові повороти `R_k` на довільні кути `2π / 2ᵏ` у схемі QFT.
- Модульне піднесення до степеня `|x⟩|y⟩ ↦ |x⟩|(y · aˣ) mod N⟩`, яке є сильно заплутувальною нелінійною операцією над базисними станами.

Модульне множення породжує стан з об'ємним законом ентропії заплутаності (*Volume-Law Entanglement*), через що методи матричних добутків станів (Matrix Product States, MPS) та тензорних мереж також втрачають ефективність і вимагають експоненційного рангу зв'язку (*bond dimension*). Отже, пряма симуляція повного вектора стану залишається єдиним точним інструментом класичного аналізу.

## 2. Парадигми класичної симуляції квантових алгоритмів

У сучасній комп'ютерній інженерії застосовують чотири основні парадигми емуляції квантових обчислень:

1. **Симулятори вектора стану (Statevector Simulators):** Зберігають повний масив із `2ᵐ` комплексних чисел і оновлюють його застосуванням унітарних матриць `2 × 2` або `4 × 4`. Перевагою є абсолютна точність і підтримка довільних вентилів. Недоліком є жорсткий бар'єр пам'яті (до `m ≈ 35..40` кубітів на суперкомп'ютерах з терабайтами RAM).
2. **Тензорні мережі та MPS (Tensor Network / MPS):** Представляють хвильову функцію як згортку тензорів низького рангу. Ефективні для слабозаплутаних 1D-систем (площинний закон ентропії), але для алгоритму Шора зазнають колапсу продуктивності через високу заплутаність між бітами після модульного множення.
3. **Стабілізаторні емулятори (Clifford / Tableau):** Зберігають квантовий стан як генератори групи Паулі розміром `2m × 2m` бітів. Працюють за поліноміальний час для мільйонів кубітів, але не підтримують вентилі Т та фазові повороти QFT без експоненційного розширення так званої T-магії (*Magic State Rank*).
4. **Діаграми квантових рішень (QMDD / Decision Diagrams):** Стискають регулярні та симетричні вектори амплітуд у зважені спрямовані ациклічні графи. Оскільки стан регістра Шора є періодичною гребінкою з повторюваними блоками, QMDD-симулятори здатні ефективно стискати вектор стану і факторизувати модулі більшої розрядності, ніж прямий масив.

Для навчальних і дослідницьких цілей найкращим вибором є симулятор вектора стану, оскільки він дозволяє безпосередньо простежити амплітуду кожного базисного стану на всіх етапах обчислення.

## 3. Квантові схеми модульного додавання та множення

У реальних квантових процесорах операція `|x⟩|0⟩ ↦ |x⟩|aˣ mod N⟩` не є базовим фізичним вентилем, а синтезується з ланцюжка квантових модульних суматорів:

- **Піднесення до степеня через послідовні множення:** Значення `x` подається двійковими розрядами `x = ∑_{i=0}^{2n-1} x_i 2ⁱ`. Вираз розкладається у добуток `aˣ mod N = ∏_{i=0}^{2n-1} (a^(2ⁱ) mod N)^(x_i) mod N`. Кожен розряд `x_i` керує одним унітарним вентилем модульного множення на сталу `a^(2ⁱ) mod N`.
- **Квантовий суматор Беджореґарда (Beauregard Adder, 2003):** Використовує фазове представлення Дрейпера (QFT-суматор), де додавання виконується простими фазовими зсувами в просторі Фур'є без перенесення розрядів, вимагаючи всього `2n + 3` кубіти.
- **Суматор Куккаро (Cuccaro Ripple-Carry Adder, 2004):** Оптимізована булева схема з лінійною кількістю вентилів CNOT та Toffoli, що зменшує глибину схеми.

У нашому програмному емуляторі ми моделюємо результат дії квантового оракула аналітично, використовуючи властивість колапсу квантового стану при вимірюванні другого регістра.

## 4. Моделювання заплутаності та вимірювання другого регістра

У повному квантовому комп'ютері задіяні два регістри:
1. **Керівний регістр (Register 1):** містить `m = 2n` кубітів і призначений для створення суперпозиції та виконання QFT. Розмірність `Q = 2ᵐ`.
2. **Цільовий регістр (Register 2):** містить `n = ⌈log₂ N⌉` кубітів і зберігає результат обчислення `aˣ mod N`.

Спільний стан двох регістрів після застосування вентилів Адамара та модульного оракула описується вектором у гільбертовому просторі `ℋ₁ ⊗ ℋ₂`:

```
|Ψ⟩ = (1 / √Q) · ∑_{x=0}^{Q-1} |x⟩ ⊗ |aˣ mod N⟩
```

Створення повного комбінованого вектора розмірності `2^(3n)` є надлишковим для симулятора. Ми можемо скористатися квантовомеханічним принципом еквівалентності вимірювань:
- Вимірювання цільового регістра дає випадковий результат `y₀ = a^(x₀) mod N` для деякого `x₀ ∈ {0, 1, ..., r - 1}`.
- За постулатом редукції фон Неймана, перший регістр колапсує у стан, що є проєкцією на підпростір, відповідний власному значенню `y₀`:

```
|ψ₁⟩ = (1 / √M) · ∑_{x: aˣ mod N = y₀} |x⟩ = (1 / √M) · ∑_{k=0}^{M-1} |x₀ + k · r⟩
```

де `M` — точна кількість повторень лишку `y₀` на інтервалі `[0, Q - 1]`.

Ця редукція дозволяє симулятору працювати виключно з вектором першого регістра розмірності `Q = 2ᵐ`, не виділяючи пам'ять під другий регістр. Симулятор генерує випадкове `x₀`, обчислює цільовий лишок `y₀ = a^(x₀) mod N`, знаходить усі індекси `x`, де `aˣ mod N == y₀`, встановлює їхні амплітуди рівними `1 / √M`, а решту амплітуд обнуляє.

## 5. Алгоритм дискретного перетворення Фур'є над вектором амплітуд

Після підготовки періодичної гребінки до вектора стану застосовується оператор оберненого дискретного перетворення Фур'є `F_Q†`. Для кожного вихідного стану `|y⟩` амплітуда обчислюється як скалярний добуток:

```
c_y = (1 / √Q) · ∑_{x=0}^{Q-1} state[x] · exp(-2πi · x · y / Q)
```

У програмній реалізації матрично-векторне множення виконується за `O(Q²)` операцій, що є швидким для `Q ≤ 4096`. Для більших розмірностей можна застосувати швидке перетворення Фур'є (FFT) за `O(Q · log Q)`.

Оскільки `state[x]` містить ненульові значення лише у точках гребінки `x = x₀ + k · r`, сума згортається у геометричну прогресію. Усі некратні фази зазнають взаємного знищення через деструктивну інтерференцію, формуючи гострі інтерференційні максимуми у точках `y ≈ s · Q / r`.

## 6. Класичне декодування періоду методом неперервних дробів

Квантове вимірювання моделюється генератором псевдовипадкових чисел: кожному індексу `y ∈ {0, 1, ..., Q - 1}` зіставляється ймовірність `P(y) = |c_y|²`. Семплер обирає випадкове значення `y` відповідно до цього розподілу.

Отримане ціле число `y` дає наближення фази `θ = y / Q ≈ s / r`. Знаменник `r` відновлюється алгоритмом неперервних дробів (Continued Fraction Expansion, CFE):

1. Число `θ` розкладається у ланцюговий дріб `[a₀; a₁, a₂, ...]`, де `a_k = ⌊θ_k⌋`, а `θ_(k+1) = 1 / (θ_k - a_k)`.
2. Обчислюються чисельники та знаменники підхідних дробів:
   ```
   p_k = a_k · p_(k-1) + p_(k-2)
   q_k = a_k · q_(k-1) + q_(k-2)
   ```
3. Для кожного знаменника `q_k < N` виконується перевірка умови порядку:
   ```
   a^(q_k) ≡ 1 (mod N)
   ```
4. Якщо умова виконується, знаменник `q_k` є шуканим періодом `r`.

// Швидке модульне піднесення до степеня (a^exp mod n)
uint64_t mod_exp(uint64_t base, uint64_t exp, uint64_t mod) {
    uint64_t res = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) res = (__uint128_t(res) * base) % mod;
        base = (__uint128_t(base) * base) % mod;
        exp >>= 1;
    }
    return res;
}

// Обернене квантове перетворення Фур'є над вектором квантового стану
void apply_inverse_qft(std::span<Complex> state) {
    const size_t q = state.size();
    std::vector<Complex> out(q, Complex(0.0, 0.0));
    const double inv_sqrt_q = 1.0 / std::sqrt(static_cast<double>(q));
    const double two_pi = 2.0 * std::numbers::pi;

    for (size_t y = 0; y < q; ++y) {
        Complex sum(0.0, 0.0);
        for (size_t x = 0; x < q; ++x) {
            double angle = -two_pi * static_cast<double>(x * y) / static_cast<double>(q);
            Complex phase(std::cos(angle), std::sin(angle));
            sum += state[x] * phase;
        }
        out[y] = sum * inv_sqrt_q;
    }
    std::copy(out.begin(), out.end(), state.begin());
}

// Розклад у неперервний дріб для знаходження періоду r
std::vector<uint64_t> continued_fraction_convergents(uint64_t y, uint64_t q, uint64_t n) {
    std::vector<uint64_t> r_candidates;
    uint64_t a_num = y, a_den = q;
    int64_t p_prev2 = 0, p_prev1 = 1;
    int64_t q_prev2 = 1, q_prev1 = 0;

    while (a_den != 0) {
        uint64_t quot = a_num / a_den;
        uint64_t rem = a_num % a_den;

        int64_t p_curr = quot * p_prev1 + p_prev2;
        int64_t q_curr = quot * q_prev1 + q_prev2;

        if (q_curr >= static_cast<int64_t>(n)) break;
        if (q_curr > 0) {
            r_candidates.push_back(static_cast<uint64_t>(q_curr));
        }

        p_prev2 = p_prev1;
        p_prev1 = p_curr;
        q_prev2 = q_prev1;
        q_prev1 = q_curr;

        a_num = a_den;
        a_den = rem;
    }
    return r_candidates;
}

// Симуляція квантового пошуку періоду r для функції f(x) = a^x mod n
std::optional<uint64_t> quantum_find_period(uint64_t a, uint64_t n, std::mt19937_64& rng) {
    // Обираємо розмірність Q = 2^m >= n^2
    size_t m = 1;
    while ((1ULL << m) < n * n) ++m;
    const size_t q = 1ULL << m;

    std::vector<Complex> state(q, Complex(0.0, 0.0));

    // Моделювання вимірювання другого регістра (обрання випадкового x0)
    std::uniform_int_distribution<size_t> dist_x0(0, n);
    size_t x0 = dist_x0(rng);
    uint64_t target_val = mod_exp(a, x0, n);

    // Перший регістр колапсує у періодичну гребінку станів
    size_t count = 0;
    for (size_t x = 0; x < q; ++x) {
        if (mod_exp(a, x, n) == target_val) {
            state[x] = Complex(1.0, 0.0);
            ++count;
        }
    }
    if (count == 0) return std::nullopt;

    double norm = 1.0 / std::sqrt(static_cast<double>(count));
    for (size_t x = 0; x < q; ++x) {
        state[x] *= norm;
    }

    // Застосовуємо квантове перетворення Фур'є
    apply_inverse_qft(state);

    // Семплінг вимірювання за розподілом імовірностей |amplitude|^2
    std::vector<double> probs(q);
    for (size_t y = 0; y < q; ++y) {
        probs[y] = std::norm(state[y]);
    }

    std::discrete_distribution<size_t> dist_sample(probs.begin(), probs.end());
    size_t measured_y = dist_sample(rng);

    if (measured_y == 0) return std::nullopt;

    // Класичний розклад у неперервний дріб
    auto candidates = continued_fraction_convergents(measured_y, q, n);
    for (uint64_t cand_r : candidates) {
        if (cand_r > 1 && mod_exp(a, cand_r, n) == 1) {
            return cand_r;
        }
    }
    return std::nullopt;
}

// Повний алгоритм факторизації Шора
std::pair<uint64_t, uint64_t> shor_factorize(uint64_t n) {
    if (n % 2 == 0) return {2, n / 2};

    std::random_device rd;
    std::mt19937_64 rng(rd());
    std::uniform_int_distribution<uint64_t> dist_a(2, n - 2);

    for (int attempt = 1; attempt <= 100; ++attempt) {
        uint64_t a = dist_a(rng);
        uint64_t g = std::gcd(a, n);
        if (g > 1) {
            return {g, n / g}; // Випадковий спільний дільник
        }

        auto maybe_r = quantum_find_period(a, n, rng);
        if (!maybe_r.has_value()) continue;

        uint64_t r = maybe_r.value();
        if (r % 2 != 0) continue; // Період має бути парним

        uint64_t half_pow = mod_exp(a, r / 2, n);
        if (half_pow == n - 1) continue; // a^(r/2) != -1 mod n

        uint64_t factor1 = std::gcd(half_pow - 1, n);
        uint64_t factor2 = std::gcd(half_pow + 1, n);

        if (factor1 > 1 && factor1 < n) return {factor1, n / factor1};
        if (factor2 > 1 && factor2 < n) return {factor2, n / factor2};
    }
    return {1, n}; // Не вдалося знайти дільник за 100 спроб
}

int main() {
    uint64_t n = 15;
    auto [p, q] = shor_factorize(n);
    std::cout << "Факторизація N = " << n << " -> " << p << " * " << q << std::endl;
    return 0;
}

// Швидке модульне піднесення до степеня (a^exp mod n)

// Обчислення найбільшого спільного дільника (алгоритм Евкліда)
uint64_t gcd_u64(uint64_t a, uint64_t b) {
    while (b != 0) {
        uint64_t temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

// Обернене QFT над вектором амплітуд
void apply_inverse_qft_c(double complex *state, size_t q) {
    double complex *out = (double complex *)malloc(q * sizeof(double complex));
    if (!out) return;

    double inv_sqrt_q = 1.0 / sqrt((double)q);
    double two_pi = 2.0 * M_PI_VAL;

    for (size_t y = 0; y < q; ++y) {
        double complex sum = 0.0 + 0.0 * I;
        for (size_t x = 0; x < q; ++x) {
            double angle = -two_pi * ((double)(x * y)) / ((double)q);
            sum += state[x] * (cos(angle) + sin(angle) * I);
        }
        out[y] = sum * inv_sqrt_q;
    }

    for (size_t i = 0; i < q; ++i) {
        state[i] = out[i];
    }
    free(out);
}

// Знаходження періоду методом неперервних дробів
uint64_t extract_period_c(uint64_t y, uint64_t q, uint64_t a, uint64_t n) {
    uint64_t a_num = y, a_den = q;
    int64_t p_prev2 = 0, p_prev1 = 1;
    int64_t q_prev2 = 1, q_prev1 = 0;

    while (a_den != 0) {
        uint64_t quot = a_num / a_den;
        uint64_t rem = a_num % a_den;

        int64_t q_curr = quot * q_prev1 + q_prev2;
        int64_t p_curr = quot * p_prev1 + p_prev2;

        if (q_curr >= (int64_t)n) break;
        if (q_curr > 1) {
            uint64_t cand_r = (uint64_t)q_curr;
            if (mod_exp(a, cand_r, n) == 1) {
                return cand_r;
            }
        }

        p_prev2 = p_prev1;
        p_prev1 = p_curr;
        q_prev2 = q_prev1;
        q_prev1 = q_curr;

        a_num = a_den;
        a_den = rem;
    }
    return 0;
}

// Емуляція квантового пошуку періоду
uint64_t quantum_find_period_c(uint64_t a, uint64_t n) {
    size_t m = 1;
    while ((1ULL << m) < n * n) ++m;
    size_t q = 1ULL << m;

    double complex *state = (double complex *)calloc(q, sizeof(double complex));
    if (!state) return 0;

    size_t x0 = rand() % n;
    uint64_t target_val = mod_exp(a, x0, n);

    size_t count = 0;
    for (size_t x = 0; x < q; ++x) {
        if (mod_exp(a, x, n) == target_val) {
            state[x] = 1.0 + 0.0 * I;
            ++count;
        }
    }
    if (count == 0) {
        free(state);
        return 0;
    }

    double norm = 1.0 / sqrt((double)count);
    for (size_t x = 0; x < q; ++x) {
        state[x] *= norm;
    }

    apply_inverse_qft_c(state, q);

    // Семплінг вимірювання
    double r_val = (double)rand() / (double)RAND_MAX;
    double cum_prob = 0.0;
    size_t measured_y = 0;

    for (size_t y = 0; y < q; ++y) {
        double p = cabs(state[y]) * cabs(state[y]);
        cum_prob += p;
        if (r_val <= cum_prob) {
            measured_y = y;
            break;
        }
    }

    free(state);
    if (measured_y == 0) return 0;

    return extract_period_c(measured_y, q, a, n);
}

int main(void) {
    uint64_t n = 15;
    uint64_t p = 0, q_fact = 0;

    for (int attempt = 0; attempt < 50; ++attempt) {
        uint64_t a = 2 + (rand() % (n - 3));
        uint64_t g = gcd_u64(a, n);
        if (g > 1) {
            p = g;
            q_fact = n / g;
            break;
        }

        uint64_t r = quantum_find_period_c(a, n);
        if (r > 0 && r % 2 == 0) {
            uint64_t half_pow = mod_exp(a, r / 2, n);
            if (half_pow != n - 1) {
                uint64_t f1 = gcd_u64(half_pow - 1, n);
                uint64_t f2 = gcd_u64(half_pow + 1, n);
                if (f1 > 1 && f1 < n) { p = f1; q_fact = n / f1; break; }
                if (f2 > 1 && f2 < n) { p = f2; q_fact = n / f2; break; }
            }
        }
    }

    printf("Факторизація N = %llu -> %llu * %llu\n", n, p, q_fact);
    return 0;
}

```python
import math
import random
import cmath

def mod_exp(base: int, exp: int, mod: int) -> int:
    return pow(base, exp, mod)

def apply_inverse_qft(state: list[complex]) -> list[complex]:
    q = len(state)
    out = [complex(0, 0)] * q
    inv_sqrt_q = 1.0 / math.sqrt(q)
    two_pi = 2.0 * math.pi

    for y in range(q):
        s = complex(0, 0)
        for x in range(q):
            angle = -two_pi * (x * y) / q
            s += state[x] * cmath.exp(complex(0, angle))
        out[y] = s * inv_sqrt_q
    return out

def continued_fraction_convergents(y: int, q: int, n: int) -> list[int]:
    candidates = []
    a_num, a_den = y, q
    p_prev2, p_prev1 = 0, 1
    q_prev2, q_prev1 = 1, 0

    while a_den != 0:
        quot = a_num // a_den
        rem = a_num % a_den

        p_curr = quot * p_prev1 + p_prev2
        q_curr = quot * q_prev1 + q_prev2

        if q_curr >= n:
            break
        if q_curr > 0:
            candidates.append(q_curr)

        p_prev2, p_prev1 = p_prev1, p_curr
        q_prev2, q_prev1 = q_prev1, q_curr
        a_num, a_den = a_den, rem

    return candidates

def quantum_find_period(a: int, n: int) -> int | None:
    m = 1
    while (1 << m) < n * n:
        m += 1
    q = 1 << m

    x0 = random.randint(0, n - 1)
    target_val = mod_exp(a, x0, n)

    state = [complex(0, 0)] * q
    count = 0
    for x in range(q):
        if mod_exp(a, x, n) == target_val:
            state[x] = complex(1, 0)
            count += 1

    if count == 0:
        return None

    norm = 1.0 / math.sqrt(count)
    state = [s * norm for s in state]

    transformed = apply_inverse_qft(state)
    probs = [abs(c) ** 2 for c in transformed]

    measured_y = random.choices(range(q), weights=probs, k=1)[0]
    if measured_y == 0:
        return None

    for cand_r in continued_fraction_convergents(measured_y, q, n):
        if cand_r > 1 and mod_exp(a, cand_r, n) == 1:
            return cand_r
    return None

def shor_factorize(n: int) -> tuple[int, int]:
    if n % 2 == 0:
        return 2, n // 2

    for _ in range(100):
        a = random.randint(2, n - 2)
        g = math.gcd(a, n)
        if g > 1:
            return g, n // g

        r = quantum_find_period(a, n)
        if r is None or r % 2 != 0:
            continue

        half_pow = mod_exp(a, r // 2, n)
        if half_pow == n - 1:
            continue

        f1 = math.gcd(half_pow - 1, n)
        f2 = math.gcd(half_pow + 1, n)

        if 1 < f1 < n:
            return f1, n // f1
        if 1 < f2 < n:
            return f2, n // f2

    return 1, n

if __name__ == "__main__":
    n = 15
    p, q = shor_factorize(n)
    print(f"Факторизація N = {n} -> {p} * {q}")
```

## 8. Покроковий розбір виконання: факторизація N = 15, N = 21 та N = 35

Простежимо роботу симулятора для трьох тестових випадків складених чисел, які демонструють різні сценарії роботи квантового алгоритму.

### Тестовий випадок 1: N = 15, a = 7 (ідеальний подільний випадок)

1. **Параметри квантового простору:**
   - Для `N = 15` умова `Q = 2ᵐ ≥ N²` дає `256 ≥ 225` при `m = 8`. Вектор стану містить 256 амплітуд.
2. **Модульний оракул:**
   - Послідовність `7ˣ mod 15`: `1, 7, 4, 13, 1, 7, 4, 13, ...` з періодом `r = 4`.
   - Випадковий вибір зміщення `x₀ = 0` формує суперпозицію станів `|0⟩, |4⟩, |8⟩, ..., |252⟩` (разом 64 стани). Нормалізація дає `c_x = 1 / √64 = 0.125`.
3. **Результат оберненого QFT:**
   - Оскільки `r = 4` точно ділить `Q = 256`, інтерференція концентрується виключно в чотирьох базисних станах `y ∈ {0, 64, 128, 192}`.
   - Імовірність вимірювання кожного з цих чотирьох станів становить строго `P(y) = 25%`. Ймовірність вимірювання решти 252 станів дорівнює нулю.
4. **Квантовий вимір:**
   - Семплер повертає значення `y = 192`.
5. **Неперервний дріб:**
   - Фаза `θ = 192 / 256 = 3 / 4`.
   - Розклад дає єдиний значущий підхідний дріб `3 / 4` зі знаменником `q = 4`.
   - Перевірка: `7⁴ mod 15 = 2401 mod 15 = 1`. Знаменник є точним періодом `r = 4`.
6. **Алгебраїчні дільники:**
   - Період `r = 4` парний.
   - Напівстепінь: `a^(r/2) = 7² = 49 ≡ 4 (mod 15)`.
   - Дільники: `p = НСД(4 - 1, 15) = 3` та `q = НСД(4 + 1, 15) = 5`.

### Тестовий випадок 2: N = 21, a = 2 (загальний випадок без точного ділення)

1. **Параметри квантового простору:**
   - Для `N = 21` умова `Q ≥ 21² = 441` вимагає `m = 9`, `Q = 512`.
2. **Модульний оракул:**
   - Послідовність `2ˣ mod 21`: `1, 2, 4, 8, 16, 11, 1, 2, ...` з періодом `r = 6`.
   - Оскільки `512` не ділиться на `6`, період не є дільником розмірності регістра (`512 / 6 = 85.333`).
3. **Результат оберненого QFT:**
   - Піки ймовірностей дещо розмиті й зосереджені навколо найближчих цілих `y_s = ⌊s · 512 / 6⌉`:
     - `s = 1`: `y₁ = 85`, `P(85) ≈ 13.5%`
     - `s = 2`: `y₂ = 171`, `P(171) ≈ 13.5%`
     - `s = 3`: `y₃ = 256`, `P(256) ≈ 13.5%`
     - `s = 4`: `y₄ = 341`, `P(341) ≈ 13.5%`
     - `s = 5`: `y₅ = 427`, `P(427) ≈ 13.5%`
4. **Квантовий вимір та ланцюговий дріб:**
   - Нехай виміряно `y = 85`. Дріб `85 / 512 ≈ 0.1660156`.
   - Розклад: `85 / 512 = 0 + 1 / (6 + 1 / (40 / 17)) = [0; 6, 40, ...]`.
   - Перший підхідний дріб: `p₁ / q₁ = 1 / 6`.
   - Перевірка знаменника `q₁ = 6`: `2⁶ mod 21 = 64 mod 21 = 1`. Період `r = 6` підтверджено.
5. **Алгебраїчні дільники:**
   - `a^(r/2) = 2³ = 8 ≢ -1 (mod 21)`.
   - `p = НСД(8 - 1, 21) = НСД(7, 21) = 7`.
   - `q = НСД(8 + 1, 21) = НСД(9, 21) = 3`.

### Тестовий випадок 3: N = 35, a = 3 (колізія дільників та відновлення через НСК)

1. **Параметри:** `N = 35`, `Q = 2¹¹ = 2048 ≥ 1225`. Період `3ˣ mod 35` становить `r = 12`.
2. **Перший запуск:**
   - Виміряно стан `y = 512`. Фаза `512 / 2048 = 1 / 4`.
   - Підхідний дріб дає знаменник `r'₁ = 4`.
   - Перевірка: `3⁴ mod 35 = 81 mod 35 = 11 ≠ 1`. Знайдено дільник періоду, а не повний період (відбулося скорочення `s / r = 3 / 12 = 1 / 4`).
3. **Другий запуск:**
   - Виміряно стан `y = 1195`. Фаза `1195 / 2048 ≈ 0.583496`.
   - Підхідний дріб дає `p / q = 7 / 12`. Знаменник `r'₂ = 12`.
   - Перевірка: `3¹² mod 35 = 1`. Повний період відновлено: `r = НСК(4, 12) = 12`.
4. **Дільники:**
   - `a^(r/2) = 3⁶ = 729 ≡ 29 ≡ -6 (mod 35)`.
   - `p = НСД(29 - 1, 35) = НСД(28, 35) = 7`.
   - `q = НСД(29 + 1, 35) = НСД(30, 35) = 5`.

## 9. Практичні пастки та крайові випадки симуляції

Під час програмної розробки квантових симуляторів необхідно враховувати низку специфічних апаратних та алгоритмічних пасток:

1. **Катастрофічна втрата точності при обчисленні тригонометричних фаз:**
   У виразі `exp(-2πi · x · y / Q)` добуток індексів `x · y` для `Q = 2²⁰` досягає величини `2⁴⁰`. Обчислення `(double)(x * y)` призводить до переповнення стандартного 32-бітного цілого типу та втрати молодших значущих бітів при зведенні до діапазону `[0, 2π)`. Необхідно або використовувати 64-бітні типи `uint64_t` з модульною редукцією `(x * y) % Q`, або застосовувати аналітичне приведення кута перед викликом `cos`/`sin`.

2. **Обробка тривіального квантового вимірювання `y = 0`:**
   Стан `|0⟩` завжди має ненульову ймовірність вимірювання, оскільки відповідає індексу `s = 0`. Значення `y = 0` відповідає нульовій фазі `0 / Q` і дає знаменник `1`, який не несе корисної інформації про період. Алгоритм має явно розпізнавати випадок `y = 0` та перезапускати квантову схему.

3. **Випадкове виявлення дільника на етапі ініціалізації:**
   Якщо випадково згенерована основа `a` не є взаємно простою з `N` (`НСД(a, N) = d > 1`), алгоритм Евкліда миттєво знаходить нетривіальний дільник без потреби в квантових обчисленнях. Програма має перевіряти `НСД(a, N)` на першому ж кроці як швидку класичну оптимізацію.

4. **Проблема непарного періоду або кореня `-1`:**
   У випадках, коли обрана основа `a` породжує непарний період `r` або `a^(r/2) ≡ N - 1 (mod N)`, обчислення `НСД(a^(r/2) + 1, N)` дає тривіальний результат `N`. Це не є помилкою симулятора — для таких основ факторизація через різницю квадратів неможлива. Симулятор має детерміновано відкинути поточне значення `a` та повторити спробу з новою випадковою основою.
