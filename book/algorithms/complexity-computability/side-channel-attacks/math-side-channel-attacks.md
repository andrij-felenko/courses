# 🧮 Математичні моделі фізичного витоку та статистичні розрізнювачі

Безпека криптографічного алгоритму в моделі витоку інформації оцінюється не тільки через асимптотичну складність обернення математичних функцій, а й через статистичну розрізнюваність фізичних еманацій. Коли обчислювальний пристрій перемикає логічні вентилі, оновлює регістри або звертається до ліній кеш-пам'яті, виникає функціональна залежність між внутрішніми проміжними значеннями шифру та вимірюваними фізичними величинами: струмом, часом або магнітною індукцією. Нижче наведено строгий математичний апарат моделювання фізичних побічних каналів, виведення оцінок вибіркової складності статистичних розрізнювачів, аналіз кеш-колізій, модульних редукцій Монтгомері, атак вищих порядків та доведення стійкості схем маскування в зондовій моделі Ішая — Сахая — Вагнера (ISW).

## 1. Фізичні моделі потужності та співвідношення сигнал/шум (SNR)

У цифрових напівпровідникових мікросхемах КМОН (англ. *CMOS*) статичний струм витоку через закриті транзистори є малим, а основна частка енергії розсіюється динамічно під час перезаряджання ємностей навантаження `C_L` при логічних переходах `0 -> 1` та `1 -> 0`.

### 1.1 Модель ваги Геммінґа (Hamming Weight Model)

Якщо процесор завантажує 8-бітне або 32-бітне слово `v` із пам'яті на шину даних, попередньо скинуту в нульовий стан (англ. *pre-charged to 0*), струм, необхідний для заряджання шини, пропорційний кількості одиничних бітів у слові `v`.

Для двійкового вектора `v = (v[0], v[1], ..., v[n-1]) ∈ {0, 1}ⁿ` вага Геммінґа `HW(v)` визначається як сума його координат:

```
HW(v) = ∑_{j=0}^{n-1} v[j]
```

Фізична виміряна потужність `P(t)` у фіксований момент часу `t` моделюється лінійним рівнянням:

```
P(t) = α · HW(v) + β + N(t)
```

де:
- `α` — коефіцієнт фізичної чутливості (приріст споживаного струму на кожен одиничний біт);
- `β` — фонове споживання незв'язаних блоків кристала (тактовий генератор, периферія);
- `N(t)` — некорельований фізичний шум вимірювання, що моделюється центрованим гауссовим розподілом із дисперсією `σ_N²`, тобто `N(t) ~ N(0, σ_N²)`.

### 1.2 Модель дистанції Геммінґа (Hamming Distance Model)

Якщо шина даних не скидається перед записом, а зберігає попередній стан `v_prev`, струм пропорційний кількості інвертованих бітів при переході `v_prev -> v_curr`.

Дистанція Геммінґа `HD(v_prev, v_curr)` дорівнює вазі Геммінґа побітового додавання за модулем 2 (XOR):

```
HD(v_prev, v_curr) = HW(v_prev ⊕ v_curr)
```

Рівняння споживання струму для синхронних шин та регістрових переходів набуває вигляду:

```
P(t) = α · HD(v_prev, v_curr) + β + N(t)
```

### 1.3 Співвідношення сигнал/шум (Signal-to-Noise Ratio, SNR)

Нехай `V` — випадкова величина цільового проміжного стану шифру, рівномірно розподілена на просторі `n`-бітних слів `{0, 1}ⁿ`. Кожен біт `V[j]` є незалежною бернуллівською випадковою величиною з параметром `p = 1/2`.

Математичне сподівання та дисперсія ваги Геммінґа `HW(V)` розраховуються аналітично:

```
E[HW(V)]
= E[∑_{j=0}^{n-1} V[j]]
= ∑_{j=0}^{n-1} E[V[j]]
= n · 1/2
= n / 2

Var(HW(V))
= Var(∑_{j=0}^{n-1} V[j])
= ∑_{j=0}^{n-1} Var(V[j])    [незалежність бітів V[j]]
= n · (p · (1 - p))
= n · (1/2 · 1/2)
= n / 4
```

Для стандартного 8-бітного байта (`n = 8`):
```
E[HW(V)] = 8 / 2 = 4
Var(HW(V)) = 8 / 4 = 2
```

Корисний фізичний сигнал `S` дорівнює `α · HW(V)`. Його дисперсія:
```
Var(S) = Var(α · HW(V)) = α² · Var(HW(V)) = α² · (n / 4)
```

Співвідношення сигнал/шум (SNR) криптографічного каналу витоку визначається як відношення дисперсії детермінованого сигналу до дисперсії фізичного шуму:

```
SNR
= Var(S) / Var(N)         [означення співвідношення сигнал/шум]
= (α² · n / 4) / σ_N²     [підстановка дисперсій сигналу та шуму]
= (n · α²) / (4 · σ_N²)   [спрощення дробу]
```

## 2. Статистичні розрізнювачі: DPA та CPA

Мета атакуючого полягає в перевірці гіпотез щодо невеликого фрагмента секретного ключа (наприклад, 1 байта `k* ∈ {0, 1, ..., 255}`). Для кожної з `256` гіпотез `k_g` атакуючий моделює проміжне значення шифру `v_{i, k_g} = f(m_i, k_g)` для `N` відомих відкритих повідомлень `m_1, m_2, ..., m_N` і порівнює прогноз із виміряними осцилограмами `T_i(t)`.

### 2.1 Диференційний аналіз потужності (Difference of Means, DoM)

У класичному DPA Кохера обирається одномісний предикат селекції `D(m_i, k_g) ∈ {0, 1}` (наприклад, значення наймолодшого біта виходу S-box: `D = LSB(Sbox(m_i ⊕ k_g))`).

Усі виміряні траси `T_i(t)` розбиваються на дві підмножини:
- `S₁ = { T_i(t) | D(m_i, k_g) = 1 }` потужністю `N₁`;
- `S₀ = { T_i(t) | D(m_i, k_g) = 0 }` потужністю `N₀`.

Диференційна траса `Δ(k_g, t)` визначається як різниця вибіркових середніх:

```
Δ(k_g, t) = (1 / N₁) · ∑_{T_i ∈ S₁} T_i(t) - (1 / N₀) · ∑_{T_i ∈ S₀} T_i(t)
```

Розглянемо математичне сподівання `E[Δ(k_g, t)]` у момент часу `t*`, коли виконується цільова операція підстановки:

1. **Якщо гіпотеза ключа правильна (`k_g = k*`):**
   Предикат `D` точно відповідає фізичному стану біта. Оскільки значення інших бітів `n - 1` залишаються випадковими:
   ```
   E[HW(V) | D = 1] = 1 + (n - 1) / 2
   E[HW(V) | D = 0] = 0 + (n - 1) / 2
   E[HW(V) | D = 1] - E[HW(V) | D = 0] = 1
   ```
   Підставляючи в модель потужності, отримуємо ненульовий детермінований сплеск:
   ```
   E[Δ(k*, t*)]
   = α · (E[HW(V) | D = 1] - E[HW(V) | D = 0])
   = α · 1
   = α
   ```

2. **Якщо гіпотеза ключа хибна (`k_g ≠ k*`):**
   Через нелінійні властивості розсіювання S-box предикат `D(m_i, k_g)` не корелює з реальним станом кристала. Обидві підмножини `S₁` та `S₀` є випадковими вибірками з однаковим середнім:
   ```
   E[HW(V) | D = 1] = E[HW(V) | D = 0] = n / 2
   E[Δ(k_g, t*)] = α · 0 = 0
   ```

### 2.2 Кореляційний аналіз потужності (CPA)

Кореляційний аналіз потужності використовує інформацію про всі біти проміжного значення, зіставляючи вектор прогнозів ваги Геммінґа `H_{k_g} = (HW(f(m_1, k_g)), ..., HW(f(m_N, k_g)))` із вектором виміряних напруг `T(t) = (T_1(t), ..., T_N(t))` за допомогою вибіркового коефіцієнта лінійної кореляції Пірсона `r(k_g, t)`:

```
r(k_g, t) = ∑_{i=1}^N (H_{i, k_g} - H̄_{k_g}) · (T_i(t) - T̄(t)) / √[ ∑_{i=1}^N (H_{i, k_g} - H̄_{k_g})² · ∑_{i=1}^N (T_i(t) - T̄(t))² ]
```

Теоретичний коефіцієнт кореляції `ρ(k*, t*)` для істинного ключа розраховується через коваріацію:

```
Cov(H, P)
= Cov(HW(V), α · HW(V) + β + N)
= α · Var(HW(V))

Var(P)
= Var(α · HW(V) + β + N)
= α² · Var(HW(V)) + σ_N²

ρ(k*, t*)
= Cov(H, P) / √[ Var(H) · Var(P) ]
= (α · Var(HW(V))) / √[ Var(HW(V)) · (α² · Var(HW(V)) + σ_N²) ]
= (α · √(Var(HW(V)))) / √(α² · Var(HW(V)) + σ_N²)
= 1 / √(1 + σ_N² / (α² · Var(HW(V))))
= 1 / √(1 + 1 / SNR)
```

Звідси випливає фундаментальний висновок:
- За відсутності шуму (`σ_N² -> 0`, `SNR -> ∞`) кореляція прямує до `1`.
- За високого рівня шуму (`SNR << 1`) коефіцієнт кореляції наближається до `√SNR`:
```
ρ ≈ √SNR = (α · √n) / (2 · σ_N)
```

## 3. Виведення оцінки вибіркової складності (Sample Complexity)

Вибірковою складністю (англ. *sample complexity*) називають мінімальну кількість фізичних трас `N`, необхідну для надійного вилучення ключа з імовірністю успіху не менше `1 - ε`.

Нехай для правильної гіпотези вибіркова кореляція `R* ~ N(ρ*, (1 - (ρ*)²)² / N)`.
Для хибних гіпотез теоретична кореляція дорівнює нулю: `R_wrong ~ N(0, 1 / N)`.

Для розрізнення правильної гіпотези від 255 хибних із рівнем значущості `z_{1-α}` та потужністю критерію `z_{1-β}` різниця між середніми повинна перевищувати суму критичних інтервалів:

```
ρ* - 0 ≥ (z_{1-α} + z_{1-β}) / √N
```

Підносячи до квадрата та підставляючи асимптотику `ρ* ≈ √SNR`:

```
N ≥ (z_{1-α} + z_{1-β})² / (ρ*)²
N ≥ (z_{1-α} + z_{1-β})² · (1 + 1 / SNR)
```

Для типових інженерних вимог (`99.9%` успішної атаки, де константа `c = (z_{1-α} + z_{1-β})² ≈ 9 ÷ 16`):

```
N_samples ≈ c / SNR = (4 · c · σ_N²) / (n · α²)
```

Це доводить закон квадратичного зростання вибірки: якщо шум вимірювання `σ_N` зростає у `k` разів, кількість трас, необхідних для злому, зростає у `k²` разів.

## 4. Математична модель витоку в кеш-пам'яті процесора

Кеш-пам'ять сучасних процесорів організована у вигляді множинно-асоціативних наборів (Set-Associative Cache). Фізична адреса пам'яті розбивається на три бітові поля:
```
Адреса = [ Tag (високі біти) | Set Index (s бітів) | Line Offset (b бітів) ]
```
де `b = 6` бітів для стандартного розміру рядка `L = 64` байти, а `s` визначає кількість наборів `S = 2ˢ`.

Таблиця підстановок S-box розміром 256 байтів займає в пам'яті рівно:
```
Рядків = 256 / 64 = 4 лінії кешу
```

Коли алгоритм шифрування звертається до елемента `T[k ⊕ p]`, номер кеш-лінії, що підлягає вибірці, визначається старшими двома бітами індексу:
```
LineIndex = ⌊(k ⊕ p) / 64⌋ = (k ⊕ p) >> 6
```

Час доступу до адреси `Addr` моделюється випадковою величиною:
```
T_access = I_hit · T_hit + (1 - I_hit) · T_miss + ξ
```
де `I_hit ∈ {0, 1}` — індикатор наявності лінії в кеші, `T_hit ≈ 4 ÷ 12` тактів (L1/L2), `T_miss ≈ 150 ÷ 300` тактів (DRAM), а `ξ ~ N(0, σ_cache²)` — флуктуації шини пам'яті.

Взаємна інформація між байтом секретного ключа `K` та спостережуваним часом доступу `T_access` становить:
```
I(K; T_access)
= H(T_access) - H(T_access | K)
= - ∑_{t} Pr[T = t] log₂ Pr[T = t] - ( - ∑_{k, t} Pr[K = k, T = t] log₂ Pr[T = t | K = k] )
```
Для незахищеної реалізації S-box `I(K; T_access) ≈ 2.0` біта на кожне відкрите звернення, що дозволяє відновити всі 16 байтів ключа AES за кількасот спостережень затримки.

## 5. Моделювання витоків модульної редукції Монтгомері (Walter's Attack)

У криптосистемах RSA та DSA модульне множення реалізують через редукцію Монтгомері: `MontMul(a, b) = (a · b + q · M) / R`, де `R = 2ʳ > M`, а `q = ((a · b mod R) · M') mod R`.

Проміжний результат `x = (a · b + q · M) / R` належить інтервалу `[0, 2M - 1]`. Щоб повернути результат у канонічний діапазон `[0, M - 1]`, наївний алгоритм виконує умовне віднімання:
```
if (x >= M) x = x - M;
```

Колін Волтер (Colin Walter) математично вивів точну ймовірність необхідності додаткового віднімання:
```
Pr[x ≥ M | a, b] = (a · b) / (2 · R · M)
```

При послідовному піднесенні до степеня `mᵈ mod M` методом квадратів та множень, якщо черговий біт ключа `d[i] = 1`, виконується множення на базу `m`:
```
a_new = MontMul(a_curr, m)
```
Якщо операнд `m` має велику величину (`m ≈ M`), імовірність виконання додаткового віднімання зростає до `Pr ≈ 0.5`. Якщо `m` мале, ймовірність падає до `Pr ≈ 0`. Оскільки умовне віднімання збільшує час виконання на `ΔT ≈ 15 ÷ 40` тактів, розподіл сумарного часу обчислення має математичне сподівання:
```
E[T_total | d] = ∑_{i=0}^{k-1} T_sqr + ∑_{i: d[i]=1} (T_mul + Pr[x ≥ M] · ΔT)
```
Це створює пряму лінійну залежність між часом підпису та бітами секретного експонента `d`.

## 6. Атаки вищих порядків (Higher-Order DPA) та комбінація сигналів

Коли в криптосистемі застосовано маскування першого порядку (`x` розбито на `x_0 = x ⊕ m` та `x_1 = m`), окремі витоки в моменти часу `t_1` (обробка `x_0`) та `t_2` (обробка `x_1`) не корелюють із секретом `x`.

Для злому схеми маскування першого порядку атакуючий застосовує центровану функцію добутку (Centered Product Combination):

```
C(t_1, t_2) = (T(t_1) - T̄(t_1)) · (T(t_2) - T̄(t_2))
```

Обчислимо математичне сподівання добутку за умови фіксованого секретного біта `x`:

```
E[C(t_1, t_2) | x]
= E[ (α · (HW(x ⊕ M) - n/2) + N_1) · (α · (HW(M) - n/2) + N_2) | x ]
= α² · E[ (HW(x ⊕ M) - n/2) · (HW(M) - n/2) | x ] + 0
```

Для 1-бітного значення (`n = 1`):
- Якщо `x = 0`, то `x ⊕ M = M`. Тоді `(M - 1/2) · (M - 1/2) = (M - 1/2)² = 1/4`.
- Якщо `x = 1`, то `x ⊕ M = 1 - M`. Тоді `(1 - M - 1/2) · (M - 1/2) = -(M - 1/2)² = -1/4`.

Отже:
```
E[C(t_1, t_2) | x] = α² · (1/4 - x/2)
```
Математичне сподівання добутку лінійно залежить від секретного біта `x`. Однак дисперсія шуму комбінованого сигналу суттєво зростає:
```
Var(C) ≈ Var(N_1) · Var(N_2) = σ_N⁴
```
Ефективне співвідношення сигнал/шум для атаки 2-го порядку становить:
```
SNR₂ ≈ (SNR₁)² / 2
```
Для маскування довільного порядку `d` вибіркова складність зростає експоненційно за степенем `d`:
```
N_{d-order} ≈ c · (1 / SNR₁)^d = c · (4 · σ_N² / (n · α²))^d
```

## 7. Інформаційно-теоретичний аналіз взаємної ентропії (MIA)

Коли лінійна модель ваги Геммінґа є неадекватною (наприклад, у схемах із нелінійною логікою або дуально-рейковими лініями з асиметричними затримками), класичний CPA втрачає ефективність. Універсальним розрізнювачем є аналіз взаємної інформації (англ. *Mutual Information Analysis, MIA*), запропонований Бенедіктом Гірліхсом та співавторами.

Взаємна інформація `I(V_{k_g}; T)` між прогнозованим значенням `V_{k_g}` та виміряною трасою `T` визначається через ентропії Шеннона:

```
I(V_{k_g}; T) = H(V_{k_g}) + H(T) - H(V_{k_g}, T)
```

Для неперервного розподілу напруг трас диференційна ентропія обчислюється через оцінку ядерної густини (Kernel Density Estimation, KDE):

```
p̂(t) = (1 / (N · h)) · ∑_{i=1}^N K((t - T_i) / h)
```

де `K(u) = (1 / √(2π)) · exp(-u² / 2)` — гауссове ядро, а `h` — ширина вікна згладжування (параметр Сільвермана).

Істинний ключ `k*` максимізує взаємну інформацію:
```
k* = argmax_{k_g} I(V_{k_g}; T)
```
Оскільки `I(X; Y) = 0` тоді й лише тоді, коли `X` та `Y` є статистично незалежними, MIA знаходить витік довільної функціональної форми, незалежно від лінійності чи монотонності каналу.

## 8. Статистичний критерій виявлення витоків TVLA (Welch's t-test)

У промисловому тестуванні (FIPS 140-3, ISO/IEC 17825) застосовують стандартизовану методологію оцінки витоків TVLA (англ. *Test Vector Leakage Assessment*), яка не вимагає перебору гіпотез ключів, а перевіряє наявність будь-якого статистичного витоку через критерій Велча для двох вибірок (Fixed vs Random t-test).

Пристрій шифрує дві черговані множини блоків:
- Множина `A` (Fixed): однаковий фіксований відкритий текст `m_fix`;
- Множина `B` (Random): випадкові рівномірні відкриті тексти `m_rand`.

Статистика критерію Велча `t(t)` у кожній точці часу обчислюється як:

```
t(t) = (X̄_A(t) - X̄_B(t)) / √[ s_A²(t) / N_A + s_B²(t) / N_B ]
```

де `X̄_A, X̄_B` — вибіркові середні напруг, `s_A², s_B²` — вибіркові дисперсії, а `N_A, N_B` — обсяги вибірок.

Ефективне число ступенів вільного вибору `ν` визначається рівнянням Велча — Саттертуейта:

```
ν = [ s_A² / N_A + s_B² / N_B ]² / [ (s_A² / N_A)² / (N_A - 1) + (s_B² / N_B)² / (N_B - 1) ]
```

**Критерій прийняття рішення:** Якщо в будь-який момент часу `t` виконується умова:
```
|t(t)| > 4.5
```
нульова гіпотеза про відсутність витоку відхиляється з рівнем довіри `p < 10⁻⁵` (ймовірність хибного спрацьовування менше `0.00001`). Пристрій визнається вразливим до атак по побічних каналах.

## 9. Зондова модель безпеки Ішая — Сахая — Вагнера (ISW Probing Security)

Для математичного доведення стійкості алгоритмів проти витоків Юваль Ішай (Yuval Ishai), Аміт Сахай (Amit Sahai) та Девід Вагнер (David Wagner) у 2003 році сформулювали модель `d`-зондового супротивника (англ. *d-probing model*).

### 9.1 Формальне означення d-зондової моделі

Нехай криптографічна схема представлена булевою логічною схемою `C`, що складається з логічних вентилів (NOT, XOR, AND) та проводів `W = {w_1, w_2, ..., w_M}`.

**Означення (d-зондовий супротивник):** Супротивник `A` має право вибрати довільну підмножину з не більше ніж `d` проміжних проводів схеми `I ⊆ W, |I| ≤ d` і спостерігати точні двійкові значення, які проходять цими проводами під час обчислення.

**Означення (Стійкість за зондовою моделлю):** Логічна схема `C` є приватною порядку `d` (англ. *d-probing secure*), якщо для будь-якої підмножини зондів `I` потужністю `|I| ≤ d` існує ймовірнісний симулятор поліноміального часу `Sim`, який генерує розподіл значень на проводах `I`, використовуючи не більше ніж `d` часток кожного секретного входу.

### 9.2 Схема булевого маскування порядку d

Будь-який секретний біт `x ∈ {0, 1}` розбивається на `d + 1` випадкових часток (англ. *shares*) `(x_0, x_1, ..., x_d)` за допомогою схеми розділення секрету:

```
x_1, x_2, ..., x_d ←_R {0, 1}     [рівномірно випадкові незалежні біти]
x_0 = x ⊕ x_1 ⊕ x_2 ⊕ ... ⊕ x_d
```

Властивість ідеального приховування: будь-яка підмножина з `k ≤ d` часток `(x_{i_1}, ..., x_{i_k})` є абсолютно незалежною від початкового біта `x`:

```
Pr[x_{i_1} = b_1, ..., x_{i_k} = b_k | x = 0] = Pr[x_{i_1} = b_1, ..., x_{i_k} = b_k | x = 1] = (1/2)^k
```

### 9.3 Лінійні операції (XOR)

Додавання двох замаскованих бітів `z = x ⊕ y` виконується почастково без перехревних зв'язків:

```
z_i = x_i ⊕ y_i   для всіх i ∈ {0, 1, ..., d}
```

Коректність відновлення:
```
⨁_{i=0}^d z_i
= ⨁_{i=0}^d (x_i ⊕ y_i)             [підстановка почасткової суми]
= (⨁_{i=0}^d x_i) ⊕ (⨁_{i=0}^d y_i)  [асоціативність та комутативність XOR]
= x ⊕ y                             [властивість маскування часток]
= z                                 [означення підсумкового значення]
```

Оскільки кожна частка `z_i` обчислюється ізольовано, кожен зонд на вентилі XOR дає інформацію максимум про одну частку `x_i` та одну частку `y_i`.

### 9.4 Нелінійний гаджет множення ISW (AND-вентиль)

Обчислення логічного добутку `z = x ∧ y` для замаскованих змінних вимагає обчислення всіх попарних добутків часток `x_i ∧ y_j`. Для захисту від зондування проміжних значень використовується матриця свіжих випадкових бітів `r_{i, j}`:

1. Для кожної пари `0 ≤ i < j ≤ d` генерується незалежний випадковий біт `r_{i, j} ←_R {0, 1}`.
2. Для індексів `j < i` встановлюється значення:
   ```
   r_{j, i} = (r_{i, j} ⊕ (x_i ∧ y_j)) ⊕ (x_j ∧ y_i)
   ```
3. Вихідні частки `z_i` обчислюються як:
   ```
   z_i = (x_i ∧ y_i) ⊕ ⨁_{j \neq i} r_{i, j}
   ```

**Доведення коректності обчислення:**
Підсумуємо всі вихідні частки `z_i` за модулем 2:

```
⨁_{i=0}^d z_i
= ⨁_{i=0}^d ( (x_i ∧ y_i) ⊕ ⨁_{j \neq i} r_{i, j} )            [підстановка виразу для z_i]
= ⨁_{i=0}^d (x_i ∧ y_i) ⊕ ⨁_{0 ≤ i < j ≤ d} ( r_{i, j} ⊕ r_{j, i} )  [групування симетричних пар масок]
```

Розкриємо внутрішній вираз `r_{i, j} ⊕ r_{j, i}`:
```
r_{i, j} ⊕ r_{j, i}
= r_{i, j} ⊕ (r_{i, j} ⊕ (x_i ∧ y_j) ⊕ (x_j ∧ y_i))    [підстановка формули для r_{j, i}]
= (r_{i, j} ⊕ r_{i, j}) ⊕ ((x_i ∧ y_j) ⊕ (x_j ∧ y_i))  [асоціативність додавання за модулем 2]
= 0 ⊕ ((x_i ∧ y_j) ⊕ (x_j ∧ y_i))                      [властивість самоінверсії r ⊕ r = 0]
= (x_i ∧ y_j) ⊕ (x_j ∧ y_i)                            [нейтральність нуля 0 ⊕ a = a]
```

Підставляючи отриману рівність у суму:
```
⨁_{i=0}^d z_i
= ⨁_{i=0}^d (x_i ∧ y_i) ⊕ ⨁_{0 ≤ i < j ≤ d} ( (x_i ∧ y_j) ⊕ (x_j ∧ y_i) )  [підстановка спрощених пар]
= ⨁_{i=0}^d ⨁_{j=0}^d (x_i ∧ y_j)                                          [об'єднання діагональних і позадіагональних членів]
= (⨁_{i=0}^d x_i) ∧ (⨁_{j=0}^d y_j)                                        [дистрибутивність кон'юнкції відносно XOR]
= x ∧ y                                                                    [відновлення з часток x та y]
= z                                                                        [означення результату множення]
```

**Теорема (Стійкість множення ISW):** Гаджет множення ISW є строго стійким у моделі `d`-зондування. Для моделювання будь-якої множини з `k ≤ d` спостережуваних проводів достатньо знати не більше ніж `k` часток входу `x` та `k` часток входу `y`.

*Ідея доведення:* Кожен проміжний дріт всередині гаджета або містить свіжий незалежний випадковий біт `r_{i, j}`, який маскує добуток `x_i ∧ y_j`, або є лінійною комбінацією, залежною від фіксованої частки `x_i`. Оскільки кількість зондів `|I| ≤ d < d + 1`, завжди існує хоча б один індекс `m ∈ {0, 1, ..., d}`, частка `x_m` якого не торкається жодним зондом. Завдяки цьому сумісний розподіл зондів не залежить від нерозподіленого секрету `x`.

Ця математична конструкція лежить в основі всіх формально верифікованих апаратних реалізацій криптографічних блоків AES, Keccak (SHA-3) та Kyber, гарантуючи, що для злому системи порядку `d` атакуючий змушений аналізувати спільний статистичний момент `(d+1)`-го порядку, вибіркова складність якого зростає експоненційно: `N_samples ∝ σ_N^{2(d+1)}`.
