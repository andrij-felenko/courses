# 📜 Історія гіпотези про чутливість (Sensitivity Conjecture)

Історія гіпотези про чутливість — це одна з найвидовищніших драматичних сторінок у теоретичній інформатиці. Упродовж чверті століття просте й наче природне запитання про фундаментальну структуру булевих функцій лишалося нерозв'язаним, чинячи опір зусиллям найвидатніших математиків світу, поки у 2019 році не було подолане прозорим двосторінковим доведенням за допомогою спектральної теорії графів.

## Витоки моделі дерев рішень (1970–1980-ті)

У 1970-х роках із розвитком аналізу алгоритмів виникла потреба оцінювати складність задач незалежно від детальних особливостей конкретної обчислювальної машини чи наборів інструкцій процесора. Якщо алгоритм обробляє вхідний бітовий рядок, скільки окремих бітів йому необхідно фізично перевірити, щоб надати гарантовано правильну відповідь?

Так народилася модель **складності за запитами (Query Complexity)**, або модель дерев рішень. У цій абстракції кожен крок обчислення полягає у запиті значення одного біта входу `x[i]`. Вартістю алгоритму є кількість виконаних запитів у найгіршому випадку (глибина дерева).

Наприкінці 1980-х років дослідники з'ясували, що складність булевої функції можна вимірювати не лише детермінованими деревами рішень `D(f)`, а й цілою низкою інших математичних показників:
- **`R(f)`** — ймовірнісна складність (запити з використанням монети);
- **`Q(f)`** — квантова складність за запитами (запити через суперпозицію та квантові алгоритми типу Гровера);
- **`C(f)`** — складність сертифікатів (мінімальна кількість бітів, що фіксують значення функції);
- **`deg(f)`** — алгебраїчний степінь точного многочлена, що представляє булеву функцію над дійсними числами.

У 1989 році ізраїльський науковець Ноам Нісан (Noam Nisan) зробив фундаментальний прорив: він увів поняття **блокової чутливості (`bs(f)`)** і довів, що практично всі відомі показники складності тотальних булевих функцій є поліноміально еквівалентними між собою. Зокрема, Нісан показав, що детермінована складність обмежена кубом блокової чутливості: `D(f) ≤ bs(f)³`.

## Формулювання гіпотези Нісана — Сегеді (1994)

Незважно на успіх у пов'язуванні між собою блокової чутливості, алгебраїчного степеня та складності сертифікатів, у теоретичній картині залишалася одна муляюча біла пляма. Це була **проста чутливість (`s(f)`)** — найбільш інтуїтивний і легко обчислювальний показник.

Чутливість функції `f` на вході `x` визначається як кількість окремих бітів `x[i]`, зміна кожного з яких поодинці змінює вихідне значення функції `f(x)` на протилежне.

Зрозуміло, що блокова чутливість не менша за звичайну чутливість (`bs(f) ≥ s(f)`), оскільки кожен окремий біт є частковим випадком блоку розміру 1. Проте чи може блокова чутливість виявитися суперполіноміально чи експоненціально більшою за звичайну чутливість?

У 1994 році Ноам Нісан та Маріо Сегеді (Mario Szegedy) опублікували фундаментальну працю, в якій формально сформулювали **Гіпотезу про чутливість (Sensitivity Conjecture)**:

> **Гіпотеза про чутливість:** Для будь-якої тотальної булевої функції `f: {0, 1}ⁿ → {0, 1}` блокова чутливість `bs(f)` обмежена деяким фіксованим поліномом від простої чутливості `s(f)`. Тобто існують константи `C, k > 0` такі, що `bs(f) ≤ C · s(f)ᵏ`.

Як наслідок, якщо гіпотеза правильна, то **абсолютно всі** комбінаторні, алгебраїчні, ймовірнісні та квантові заходи складності дерев рішень для тотальних булевих функцій перебувають в одному поліноміальному класі еквівалентності. Якщо ж ні — чутливість стоїть осторонь усіх інших параметрів як чужорідний об'єкт.

## Чверть століття глухого кута (1994–2019)

Невдовзі після формулювання гіпотеза набула статусу однієї з головних відкритих проблем теоретичної інформатики. Упродовж 25 років наукова спільнота намагалася підібратися до неї з різних боків.

У 1995 році Девід Рубінштейн (David Rubinstein) побудував приклад булевої функції, для якої блокова чутливість була квадратично більшою за звичайну:
```
bs(f) = (1/2) · s(f)²
```
Ця конструкція довела, що межа `k` у поліноміальній нерівності `bs(f) = O(s(f)ᵏ)` не може бути меншою за 2.

Протягом наступних десятиліть математики доводили гіпотезу для окремих вузьких класів булевих функцій:
- **Монотонні функції:** для них `s(f) = bs(f)`, тобто показники збігаються тотожно.
- **Симметричні функції:** чутливість прямо пов'язана з алгебраїчним степенем.
- **Формули одноразового читання (Read-Once Formulas):** де кожна змінна зустрічається лише один раз.

Проте для довільних булевих функцій найкраща відома верхня межа блокової чутливості через звичайну чутливість залишалася експоненціальною: `bs(f) ≤ O(eˢ⁽ᶠ⁾)`. Спроби застосувати стандартні інструменти математичного аналізу, теорії наближення многочленами та Фур'є-аналізу булевих функцій щоразу впиралися в непоборні технічні бар'єри.

## 2019 рік: Двосторінковий прорив Хао Хуана

У липні 2019 року Хао Хуан (Hao Huang), 33-річний асистент-професор математики Університету Еморі (Emory University, Атланта, США), опублікував на архіві препринтів arXiv коротку статтю обсягом усього дві сторінки під назвою *«A full proof of the Sensitivity Conjecture via algebraic properties of the hypercube»*.

Замість того, щоб ускладнювати громіздкі комбінаторні конструкції, Хуан перевів задачу в площину **спектральної теорії графів**. Він переформулював проблему чутливості як геометричне запитання про підграфи булевого гіперкуба `Q♁`.

Булевий гіперкуб `Q♁` має `2ⁿ` вершин, які відповідають усім можливим бітовим векторам довжини `n`. Дві вершини з'єднані ребром тоді й лише тоді, коли вони відрізняються рівно в одному біті.

Хуан довів дивовижно просту геометричну лему:

> **Лема Хуана:** Будь-який індукований підграф `H` гіперкуба `Q♁`, що містить більше ніж половину вершин (тобто `|V(H)| ≥ 2ⁿ⁻¹ + 1`), обов'язково має принаймні одну вершину, ступінь якої в підграфі `H` становить щонайменше `√n`.

Для доведення цієї леми Хуан застосував класичну **теорему Коші про переплетення власних значень (Cauchy Interlacing Theorem)** до симетричної матриці суміжності гіперкуба зі спеціально розставленими знаками `±1`.

Оскільки чутливість булевої функції `s(f)` математично еквівалентна максимальному ступеню вершин у відповідних підграфах гіперкуба, з леми Хуана негайно виплив фундаментальний результат:

```
s(f) ≥ √deg(f)   ⟹   deg(f) ≤ s(f)²
```

Поєднуючи цей результат із раніше відомою нерівністю Нісана — Сегеді `bs(f) ≤ 2 · deg(f)²`, світ отримав остаточну й непохитну оцінку:

```
bs(f) ≤ 2 · s(f)⁴
```

## Наслідки та значення для науки

Стаття Хао Хуана стала справжньою сенсацією у математичному світі. Елегантність і лаконічність доведення 25-річної проблеми вразила фахівців: математичний апарат, необхідний для розуміння доведення Хуана, не виходить за межі стандартного першокурсного курсу лінійної алгебри.

Завдяки доведенню Гіпотези про чутливість було остаточно зафіксовано грандіозну структуру еквівалентності заходів складності:

1. **Усі ключові заходи складності булевих функцій поліноміально пов'язані між собою:**
   ```
   s(f) ⟷ bs(f) ⟷ C(f) ⟷ deg(f) ⟷ D(f) ⟷ R(f) ⟷ Q(f)
   ```
2. **Квантове прискорення обмежене поліномом:** квантовий алгоритм не може надати експоненціального прискорення порівняно з детермінованим деревом рішень для обчислення тотальної булевої функції (максимальне квантове прискорення обмежене 6-м степенем `D(f) ≤ O(Q(f)⁶)`).
3. **Фундаментальна єдність теорії:** поняття чутливості, яке виникло в комбінаториці, виявилося нерозривно пов'язаним зі спектром матриць, многочленами та квантовою інформатикою.
