Коли сервери пошукової системи обробляють запити серед мільярдів веб-сторінок, або коли автономний робот будує карту невідомого приміщення з обмеженим обсягом оперативної пам'яті, класичні детерміновані алгоритми обходу графів — такі як пошук у глибину чи в ширину — стають непридатними. Пошук у ширину вимагає збереження у пам'яті фронту відвіданих вершин, що для графа з мільярдом вузлів потребує десятків гігабайтів оперативної пам'яті. Якщо замість планового детермінованого обходу змусити обчислювальний процес здійснювати повністю випадкові кроки — переходити у довільну сусідню вершину з імовірністю, обернено пропорційною її ступеню, — система набуває здатності досліджувати глобальну структуру графа з майже нульовими витратами оперативної пам'яті.

Випадкові блукання у графах (від англійського *Random Walks*, де латинський корінь *stochastikos* позначає вміння вгадувати чи прогнозувати) являють собою дискретний стохастичний процес, у якому частинка або обчислювальний агент пересувається між вершинами графа, обираючи кожен наступний крок незалежно від минулої траєкторії. Незважаючи на локальну хаотичність окремих кроків, глобальна поведінка блукача підпорядковується суворим алгебраїчним та спектральним законам. Випадкові блукання пов'язують теорію графів із лінійною алгебраїчною теорією, спектральною геометрією, теорією електричних кіл та квантовими обчисленнями.

## 1. Математична модель та стохастична матриця переходів

Розглянемо скінченний зв'язний неорієнтований граф `G = (V, E)` без петльових ребер та кратності, де `V` — множина з `n = |V|` вершин, а `E` — множина з `m = |E|` ребер. Для кожної вершини `u ∈ V` позначимо через `d(u)` її степінь, тобто кількість ребер, що з неї виходять.

Процес випадкового блукання визначається послідовністю випадкових величин `X₀, X₁, X₂, ..., X_t, ...`, де `X_t ∈ V` позначає вершину, у якій блукач перебуває на кроці `t`. Перехід із поточного стану `X_t = u` у наступний стан `X_{t+1} = v` виконується за ймовірнісним правилом:

```
P(X_{t+1} = v | X_t = u) = 1 / d(u)   якщо {u, v} ∈ E
P(X_{t+1} = v | X_t = u) = 0          якщо {u, v} ∉ E
```

Ймовірність переходу залежить виключно від поточної вершини `u` і не залежить від того, які вершини блукач відвідував на кроках `0, 1, ..., t-1`. Ця властивість відсутності пам'яті визначає **марківський характер** процесу. Формально, для довільної послідовності вершин `v₀, v₁, ..., v_t` виконується фундаментальна умова:

```
P(X_{t+1} = v_{t+1} | X_t = v_t, X_{t-1} = v_{t-1}, ..., X₀ = v₀) = P(X_{t+1} = v_{t+1} | X_t = v_t)
```

Для алгебраїчного опису блукання вводиться **матриця переходів** `P` розміру `n × n`. Нехай `A` — матриця суміжності графа `G` (`A_{uv} = 1`, якщо існує ребро `{u, v}`, і `A_{uv} = 0` інакше), а `D` — діагональна матриця степенів вершин, де `D_{uu} = d(u)`. Матриця переходів `P` визначається як добуток оберненої матриці степенів на матрицю суміжності:

```
P = D⁻¹ · A
```

Кожен елемент `P_{uv} = A_{uv} / d(u)` задає ймовірність переходу з `u` у `v`. Завдяки такій нормалізації сума елементів у кожному рядку матриці `P` дорівнює строго `1`:

```
∑_{v ∈ V} P_{uv} = ∑_{v ~ u} 1 / d(u) = d(u) / d(u) = 1
```

Матриця з такими властивостями називається **правостохастичною**.

Для зважених графів, де кожне ребро `{u, v}` має додатну вагу `w_{uv} > 0`, поняття степеня узагальнюється до взваженого об'єму вершини `c(u) = ∑_{v ~ u} w_{uv}`. У цьому випадку матриця переходів визначається співвідношенням `P_{uv} = w_{uv} / c(u)`. Тобто блукач частіше обирає ребра з більшою вагою (провідністю).

![Матриця стохастичних переходів](/book/algorithms/complexity-computability/random-walks/img/random-walk-transition-matrix.svg)
*Зв'язок топології графа G та відповідної стохастичної матриці переходів P = D⁻¹ A. Сума елементів кожного рядка дорівнює 1.*

Нехай `π⁽ᵗ⁾ = (π⁽ᵗ⁾(v₁), π⁽ᵗ⁾(v₂), ..., π⁽ᵗ⁾(vₙ))` — вектор-рядок розподілу ймовірностей знаходження блукача у вершинах графа на кроці `t`, де `∑_i π⁽ᵗ⁾(v_i) = 1`. Динаміка змінення цього розподілу описується векторно-матричним множенням:

```
π⁽ᵗ⁺¹⁾ = π⁽ᵗ⁾ · P
π⁽ᵗ⁾ = π⁽⁰⁾ · Pᵗ
```

Багатокрокові переходи підпорядковуються **рівнянням Чепмена — Колмогорова**: для будь-яких цілих `t, s ≥ 0` матриця переходів за `t + s` кроків є добутком матриць `P^{t+s} = Pᵗ · Pˢ`. Завдяки цьому комірка `(Pᵗ)_{uv}` містить у собі сумарну ймовірність усіх можливих шляхів довжиною `t` між `u` та `v`, зважених за добутком ймовірностей окремих кроків.

### Прямий розрахунок на прикладі 4-вершинного графа
Розглянемо конкретний приклад графа `G` з чотирма вершинами `{v₁, v₂, v₃, v₄}`, де вершина `v₁` з'єднана з `v₂`, `v₃`, `v₄`, вершина `v₂` з'єднана з `v₃`, а `v₄` є висячою вершиною, з'єднаною лише з `v₁`. Степені вершин дорівнюють `d(v₁) = 3`, `d(v₂) = 2`, `d(v₃) = 2`, `d(v₄) = 1`.

Матриця переходів `P` має вигляд:

```
    ┌                     ┐
    │  0    1/3  1/3  1/3 │
P = │ 1/2    0   1/2   0  │
    │ 1/2   1/2   0    0  │
    │  1     0    0    0  │
    └                     ┘
```

Якщо блукач починає з вершини `v₄` (початковий вектор `π⁽⁰⁾ = (0, 0, 0, 1)`), то після першого кроку `π⁽¹⁾ = π⁽⁰⁾ P = (1, 0, 0, 0)` він строго переходить у `v₁`. На другому кроці `π⁽²⁾ = (0, 1/3, 1/3, 1/3)`. На третьому кроці `π⁽³⁾ = (1/2, 1/6, 1/6, 0)`. Продовжуючи множення на `P`, розподіл швидко наближається до стаціонарного вектора `π = (3/8, 2/8, 2/8, 1/8) = (0.375, 0.25, 0.25, 0.125)`.

## 2. Існування, єдиність та оборотність стаціонарного розподілу

Центральним питанням теорії блукань є дослідження асимптотичної поведінки розподілу `π⁽ᵗ⁾` при `t → ∞`. Чи прямує розподіл ймовірностей до деякого граничного стаціонарного стану, і чи залежить цей стан від того, з якої саме вершини `X₀` блукач розпочав свій рух?

Розподіл ймовірностей `π` називається **стаціонарним розподілом** (або рівноважним станом), якщо він є лівим власним вектором матриці `P`, що відповідає власному значенню `λ = 1`:

```
π · P = π      при умові нормування ∑_{v ∈ V} π(v) = 1
```

Для будь-якого зв'язного неорієнтованого графа стаціонарний розподіл можна обчислити в явному вигляді без розв'язання складних систем лінійних рівнянь.

### Теорема про стаціонарний розподіл
Для зв'язного неорієнтованого графа `G = (V, E)` з `m` ребрами стаціонарний розподіл `π` існує, є єдиним і для кожної вершини `v ∈ V` визначається формулою:

```
π(v) = d(v) / (2m)
```

Математичний зміст цього результату глибокий і простий: **ймовірність знайти випадкового блукача у вершині `v` після тривалого блукання строго пропорційна її ступеню `d(v)`**. Вершини з великою кількістю зв'язків (хаби) притягують блукача частіше, тоді як периферійні вершини відвідуються рідше.

Для підтвердження стаціонарності виконаємо пряме підсумовування:

```
(π · P)_v = ∑_{u ∈ V} π(u) · P_{uv}
          = ∑_{u ~ v} (d(u) / (2m)) · (1 / d(u))      [оскільки P_{uv} = 1/d(u)]
          = ∑_{u ~ v} 1 / (2m)                        [скорочення степеня d(u)]
          = d(v) / (2m)                              [підсумовування d(v) доданків]
          = π(v)
```

Повна сума ймовірностей дорівнює `∑_{v ∈ V} d(v)/(2m) = (2m)/(2m) = 1`, що підтверджує коректність нормування.

### Умова детального балансу та оборотність у часі
Випадкове блукання на неорієнтованому графі є **оборотним марківським ланцюгом** (Reversible Markov Chain). Це означає, що процес задовольняє **рівнянню детального балансу**:

```
π(u) · P_{uv} = π(v) · P_{vu}    для всіх u, v ∈ V
```

Перевіримо це співвідношення безпосередньо:

```
π(u) · P_{uv} = (d(u) / (2m)) · (1 / d(u)) = 1 / (2m)
π(v) · P_{vu} = (d(v) / (2m)) · (1 / d(v)) = 1 / (2m)
```

Фізичний зміст детального балансу полягає у тому, що в умовах стаціонарної рівноваги середня кількість переходів з `u` у `v` за одиницю часу строго дорівнює середній кількості зворотних переходів з `v` у `u`. Відсутність результуючого потоку ймовірності створює термодинамічну аналогію з рівноважним станом фізичної системи з нульовим виробництвом ентропії.

### Умови збіжності: незвідність та неперіодичність
Для того, щоб довільний початковий розподіл `π⁽⁰⁾` гарантовано збігався до стаціонарного `π` при `t → ∞`, марківський ланцюг повинен задовольняти дві фундаментальні вимоги Ергодичної теореми Перрона — Фробеніуса:

1. **Незвідність (Irreducibility):** Граф `G` має бути зв'язним. З будь-якої вершини `u` можна дістатися до будь-якої іншої вершини `v` за скінченну кількість кроків. У незв'язному графі блукач назавжди залишається всередині початкової компоненти зв'язності, а стаціонарний розподіл стає неєдиним і залежить від вибору компоненти.
2. **Неперіодичність (Aperiodicity):** Граф `G` не повинен бути дводольним.

Якщо граф є дводольним (bipartite), його вершини розбиваються на дві множини `V = V₁ ∪ V₂`, де ребра проходять виключно між `V₁` та `V₂`. Блукач на парних кроках перебуває у `V₁`, а на непарних — у `V₂`. У результаті вектор `π⁽ᵗ⁾` не збігається до стаціонарного значення, а нескінченно осцилює між двома частками графа.

Щоб ліквідувати дводольність та гарантувати неперіодичність у довільному графі, застосовують **ледаче випадкове блукання** (Lazy Random Walk). На кожному кроці блукач із ймовірністю `1/2` залишається у поточній вершині, і з імовірністю `1/2` здійснює перехід у випадкового сусіда:

```
P_lazy = (I + P) / 2 = 1/2 · I + 1/2 · D⁻¹ A
```

Матриця `P_lazy` має строго позитивні діагональні елементи `P_{vv} = 1/2`, що полностью усуває періодичність і забезпечує гарантовану збіжність до тотожного стаціонарного розподілу `π(v) = d(v)/(2m)`.

## 3. Спектральний зазор, розширення графів та час перемішування

Як швидко розподіл ймовірностей `π⁽ᵗ⁾` наближається до стаціонарного стану `π`? Відповідь на це запитання дає спектральний аналіз матриці переходів `P`.

Хоча матриця `P = D⁻¹ A` загалом не є симетричною, вона подібна до дійсної симетричної матриці `N = D⁻¹/² A D⁻¹/²` (нормалізованої матриці суміжності). Оскільки перетворення `N = D¹/² P D⁻¹/²` є перетворенням подібності, матриці `P` та `N` мають **тотожний спектр власних значень**.

За спектральною теоремою симетрична матриця `N` має `n` дійсних власних значень, які можна впорядкувати за спаданням:

```
1 = λ₁ ≥ λ₂ ≥ λ₃ ≥ ... ≥ λₙ ≥ -1
```

Найбільше власне значення `λ₁ = 1` відповідає стаціонарному стану. **Спектральний зазор** (spectral gap) `γ` визначається як різниця між першим та другим за величиною власними значеннями:

```
γ = 1 - λ₂
```

(Для ледачого блукання всі власні значення є невід'ємними `μ_i ∈ [0, 1]`, тому `λ₂ = max_{i ≥ 2} |λ_i|`).

### Час перемішування (Mixing Time)
Відстань між поточним розподілом `π⁽ᵗ⁾` та стаціонарним розподілом `π` вимірюють за допомогою **відстані за повною варіацією** (Total Variation Distance):

```
d_TV(π⁽ᵗ⁾, π) = 1/2 · ∑_{v ∈ V} |π⁽ᵗ⁾(v) - π(v)|
```

**Час перемішування** `t_mix(ε)` визначається як мінімальна кількість кроків, необхідна для того, щоб відстань за повною варіацією стала меншою за обраний поріг `ε` (за канонічний стандарт приймають `ε = 1/4` або `0.01`):

```
t_mix(ε) = min { t : d_TV(π⁽ᵗ⁾, π) ≤ ε }
```

Застосовуючи спектральний розклад вектора початкового розподілу за базисом власних векторів матриці `N`, можна довести нерівність експоненційного згасання:

```
d_TV(π⁽ᵗ⁾, π) ≤ exp(-γ · t) · √(d_max / d_min)
```

Звідси випливає фундаментальний зв'язок між спектральним зазором та часом перемішування:

```
t_mix(ε) = O((1 / γ) · log(n / ε))
```

![Спектральний зазор та швидкість перемішування](/book/algorithms/complexity-computability/random-walks/img/spectral-gap-mixing.svg)
*Спектр власних значень матриці P та експоненційне згасання відстані до стаціонарного розподілу. Великий спектральний зазор γ забезпечує швидке перемішування.*

### Порівняльний аналіз швидкості перемішування у різних топологіях
Швидкість перемішування суттєво відрізняється залежно від алгебраїчної структури графа:
- **Простий цикл `C_n`:** Спектральний зазор `γ = Θ(1/n²)`, відповідно час перемішування становить `t_mix = Θ(n²)`. Блукач повільно дифундує уздовж кільця.
- **Двовимірна ґратка `Z_n × Z_n`:** Спектральний зазор `γ = Θ(1/n²)`, час перемішування `t_mix = Θ(n²)`.
- **Гіперкуб `{0, 1}ᵈ` (`n = 2ᵈ` вершин):** Спектральний зазор `γ = 2/d = Θ(1/log n)`, час перемішування `t_mix = Θ(d log d) = Θ(log n · log log n)`.
- **`d`-регулярний граф Рамануджана (Ramanujan Graph):** Спектральний зазор `γ = 1 - 2√(d-1)/d = Ω(1)`, час перемішування логарифмічний `t_mix = Θ(log n)`.

### Феномен фазового зрізу (Cutoff Phenomenon)
У багатьох топологіях графів (наприклад, на `d`-вимірному гіперкубі чи випадкових регулярних графах) відстань за повною варіацією `d_TV(t)` залишається близькою до 1 протягом тривалого часу, після чого протягом невеликого часового вікна `o(t_mix)` різко падає майже до нуля. Цей феномен фазового переходу називається **феноменом зрізу** (Cutoff Phenomenon). Він показує, що перемішування відбувається не поступово, а стрибкоподібно після досягнення критичної кількості кроків.

### Графи-експандери та нерівність Чигера
Геометричним аналогом спектрального зазору є **кондуктанс** (або стала Чигера) графа `Ф(G)`. Кондуктанс показує мінімальне відношення кількості ребер, що виходять з підмножини вершин `S`, до загального об'єму (суми степенів) цієї підмножини:

```
Ф(S) = |E(S, V \ S)| / vol(S)         де vol(S) = ∑_{v ∈ S} d(v) ≤ m
Ф(G) = min_{S ⊂ V, 0 < vol(S) ≤ m} Ф(S)
```

Графи з великим кондуктансом `Ф(G) = Ω(1)` називаються **графами-експандерами** (Expander Graphs). У таких графах немає «вузьких шийок» (bottlenecks): будь-яка група вершин має величезну кількість зовнішніх зв'язків.

Зв'язок між алгебраїчним зазором `γ` та геометричним кондуктансом `Ф(G)` задається відомою **нерівністю Чигера для графів** (Alon — Milman, Jerrum — Sinclair):

```
γ / 2 ≤ Ф(G) ≤ √(2γ)
```

Цей висновок має вирішальне значення для теорії обчислень:
- У **графах-експандерах** спектральний зазор `γ = Ω(1)`, тому час перемішування є логарифмічним `t_mix = O(log n)`. Блукач досягає рівномірно-стаціонарного розподілу майже миттєво.
- У графах із **вузькими шийками** (наприклад, два великих кластери, з'єднані одним ребром) кондуктанс `Ф(G)` є експоненційно малим, зазор `γ → 0`, і блукач застрягає в одній половині графа на тривалий час `t_mix = O(n²)`.

Детальний алгебраїчний вивід спектрального розкладу та нерівності Чигера наведено у вставці [🧮 Спектральний зазор, кондуктанс та ефективний опір у графах](book:algorithms/random-walks/math-random-walks.md).

## 4. Часові характеристики: Hit Time, Commute Time та Cover Time

Під час аналізу випадкових блукань виникає потреба оцінити три ключові часові параметри, які описують тривалість досягнення окремих вершин чи повного покриття всього графа.

### 1. Час досягнення (Hit Time / Access Time)
**Hit Time `H(u, v)`** — це математичне сподівання кількості кроків, необхідних блукачу для першого досягнення цільової вершини `v` за умови старту з вершини `u`:

```
H(u, v) = E [ min { t ≥ 0 : X_t = v | X₀ = u } ]
```

За визначенням `H(v, v) = 0`. Для `u ≠ v` час досягнення задовольняє системі рекурентних рівнянь першого кроку:

```
H(u, v) = 1 + ∑_{w ~ u} 1 / d(u) · H(w, v)
```

Важливо підкреслити асиметрію часу досягнення: у загальному випадку `H(u, v) ≠ H(v, u)`. Наприклад, блукач легко опускається з листка дерева до його кореня, але повернення з кореня до конкретного листка вимагає значно більше часу через розгалуження.

### 2. Час комутації (Commute Time)
**Commute Time `C(u, v)`** — це очікувана кількість кроків, необхідна блукачу для виходу з вершини `u`, відвідування вершини `v` та наступного повернення у початкову вершину `u`:

```
C(u, v) = H(u, v) + H(v, u)
```

На відміну від `H(u, v)`, час комутації є строго симетричною метрикою: `C(u, v) = C(v, u)`. Він визначає затримку кругового маршруту між двома вузлами мережі.

### 3. Час покриття (Cover Time)
**Cover Time `C(G)`** — це очікувана кількість кроків, необхідна випадковому блукачу для того, щоб відвідати **абсолютно всі** вершини графа `G` при найгіршому виборі початкової вершини:

```
C(G) = max_{u ∈ V} E [ min { t : ∀ v ∈ V, ∃ s ≤ t, X_s = v | X₀ = u } ]
```

![Час покриття у різних топологіях](/book/algorithms/complexity-computability/random-walks/img/cover-time-comparison.svg)
*Залежність Cover Time від топологічної структури графа: від Θ(n log n) у повному графі K_n до Θ(n³) у графі «Леденець» L_n.*

Час покриття суттєво залежить від топології графа:
- **Повний граф `K_n`:** Усі вершини рівноправні. Граф еквівалентний задачі про збирача купонів (Coupon Collector's Problem). Час покриття становить `C(K_n) = Θ(n log n)`.
- **Простий шлях або цикл `P_n / C_n`:** Блукач здійснює одновимірний поворотний рух. Час покриття становить `C(P_n) = Θ(n²)`.
- **Граф «Леденець» (Lollipop Graph `L_n`):** Граф складається з кліки розміру `n/2` та приєднаного до неї лінійного хвоста завдовжки `n/2`. Це найгірша топологія для випадкового блукання: блукач постійно застрягає всередині щільної кліки й виходить у хвіст з імовірністю лише `O(1/n)`. Час покриття становить `C(L_n) = Θ(n³)`.

### Нерівність Меттьюза (Matthews Bound)
Пітер Меттьюз (Peter Matthews, 1989) довів фундаментальний зв'язок між максимальним часом досягнення між будь-якою парою вершин `H_max = max_{u,v} H(u, v)` та часом покриття `C(G)`:

```
H_max ≤ C(G) ≤ H_max · H_n
```

де `H_n = ∑_{i=1}ⁿ 1/i = ln n + O(1)` — `n`-те гармонічне число. Ця нерівність дозволяє легко обчислювати межі Cover Time, знаючи лише мажоранту для Hit Time.

Теорема Алелюнаса стверджує, що для **будь-якого** зв'язного неорієнтованого графа з `n` вершинами та `m` ребрами час покриття обмежений зверху величиною:

```
C(G) ≤ 2m · (n - 1) ≤ n³
```

Ця універсальна кубічна межа гарантує, що випадковий блукач не може блукати нескінченно довго, не покривши весь граф: навіть у найгіршій топології всі вершини будуть відвідані за поліноміальний час `O(n³)`.

## 5. Дуальність із електричними колами та ефективний опір

Одним із найдивовижніших відкриттів у теорії алгоритмів є точна математична еквівалентність між випадковими блуканнями на графах та класичною електродинамікою розрахунку резистивних кіл (Peter Doyle & J. Laurie Snell, 1984).

Представимо граф `G = (V, E)` як електричну схему, у якій кожне ребро `{u, v}` є провідником з електричним опором `R_{uv} = 1` Ом (провідність `C_{uv} = 1`).

Подамо від зовнішнього джерела струм величиною `I = 1` Ампер у вершину `u` (джерело) та відберемо струм `1` А з вершини `v` (стік). За законами Ома та Кірхгофа у кожному вузлі мережі виникає електричний потенціал `V(x)`.

Крайова задача Діріхле для дискретних гармонічних функцій вимагає розв'язання рівняння Лапласа `(Δ V)(x) = 0` для всіх внутрішніх вузлів `x ≠ u, v` з фіксованими потенціалами на межі `V(u) = 1` та `V(v) = 0`. Імовірність досягнення вузла `u` раніше за `v` строго дорівнює електричному потенціалу `V(x)` у цій точці.

**Ефективний опір `R_eff(u, v)`** між вершинами `u` та `v` дорівнює різниці потенціалів `V(u) - V(v)` при проходженні одиничного струму `1` А.

![Дуальність з електричними колами](/book/algorithms/complexity-computability/random-walks/img/electric-network-duality.svg)
*Точна дуальність стохастичного світу блукань та фізичного світу електричних кіл (Теорема Тетта — Дойч-Снелла).*

### Теорема Тетта — Дойч-Снелла (Tet — Doyle — Snell)
Для будь-якої пари вершин `u, v` у зв'язному неорієнтованому графі `G` з `m` ребрами час комутації `C(u, v)` зв'язаний з ефективним опором `R_eff(u, v)` точним тотожним співвідношенням:

```
C(u, v) = 2m · R_eff(u, v)
```

Цей результат дозволяє обчислювати складні часові характеристики блукання за допомогою лінійної алгебри. Знайшовши псевдообернену матрицю Лапласа графа `L⁺ = (D - A)⁺`, ефективний опір обчислюється як:

```
R_eff(u, v) = L⁺_{uu} + L⁺_{vv} - 2 L⁺_{uv}
```

### Ймовірність втечі (Escape Probability) та теорема Пойя
Електрична аналогія дозволяє пояснити класичну теорему Пойя про повернення блукача на ґратках `Zᵈ`. **Ймовірність втечі `P_escape(u)`** — це ймовірність того, що блукач, викресливши початкову вершину `u`, більше ніколи в неї не повернеться. Вона зв'язана з ефективним опором між `u` та нескінченністю `R_eff(u, ∞)` формулою:

```
P_escape(u) = 1 / (d(u) · R_eff(u, ∞))
```

- Для ґраток `Z¹` та `Z²` опір нескінченності `R_eff(u, ∞) = ∞`, тому `P_escape = 0` (блукач повертається з імовірністю 1).
- Для ґраток `Z³` опір нескінченності є скінченним `R_eff(u, ∞) < ∞`, тому `P_escape > 0` (блукач може розсіятись у просторі й не повернутися).

### Фізичні принципи у стохастичній інтерпретації
Електрична аналогія пояснює базові властивості блукань через фундаментальні фізичні закони:
- **Закон монотонності Релея (Rayleigh's Monotonicity Law):** Додавання нових ребер у граф (або зменшення опору наявних ребер) може лише **зменшити** ефективний опір `R_eff(u, v)`, а отже, прискорює час комутації `C(u, v)`.
- **Принцип мінімуму енергії Томсона (Thomson's Principle):** Струм розтікається по паралельних шляхах графа так, щоб мінімізувати сумарну теплову дисипацію Джоуля `E = ∑_{edge} I_{edge}² R_{edge}`. Аналогічно випадковий блукач обирає альтернативні паралельні маршрути між вузлами.
- **Теорема Фостера (Foster's Theorem):** Сума ефективних опорів між усіма суміжними вершинами графа дорівнює кількості вершин мінус один:

```
∑_{(u,v) ∈ E} R_eff(u, v) = n - 1
```

- **Оцінка часу покриття через остовні дерева (Chandra et al., 1989):** Для будь-якого кістякового дерева `T` графа `G`:

```
C(G) ≤ 2m · ∑_{(u,v) ∈ T} R_eff(u, v)
```

Оскільки опір між сусідніми вершинами вздовж ребра `R_eff(u, v) ≤ 1`, сума опорів уздовж дерева з `n - 1` ребер не перевищує `n - 1`, що миттєво дає універсальну верхню межу `C(G) ≤ 2m (n - 1)`.

Суворе математичне доведення теореми Тетта через метод суперпозиції потенціалів наведено у вставці [🧮 Спектральний зазор, кондуктанс та ефективний опір у графах](book:algorithms/random-walks/math-random-walks.md).

## 6. Алгоритмічні застосування: USTCON, PageRank та алгоритм Уїлсона

Завдяки своїй локальності та відсутності потреби у глобальному збереженні стану, випадкові блукання стали основою для низки класичних алгоритмів теоретичної та прикладної інформатики.

### 1. s-t зв'язність у логарифмічній пам'яті (Клас RL)
Задача перевірки досяжності вершини `t` з вершини `s` у неорієнтованому графі (`USTCON`) розв'язується випадковим блукачем з використанням лише **`O(log n)` біт пам'яті**.

Алгоритм Алелюнаса — Карпа — Ліптона — Ловаса — Рака (1979) виконує блукання протягом `N_steps = 2m · n` кроків. Програмі не потрібно зберігати масив відвіданих вершин: достатньо мати два регістри пам'яті — для поточної вершини та для лічильника кроків.
- Якщо за `N_steps` кроків вершина `t` відвідана — повертаємо `true`.
- Якщо вершину `t` не відвідано — за нерівністю Маркова ймовірність помилки (повернення `false`, коли шлях насправді існує) не перевищує `1/2`.

Повторивши блукання `k` разів, імовірність помилки падає до експоненційно малого рівня `2⁻ᵏ`. У 2005 році Омер Реінголд побудував детермінований алгоритм розв'язання `USTCON` за `O(log n)` пам'яті, використавши операцію зигзаг-добутку експандерних графів.

### 2. Ранжування веб-сторінок PageRank
У 1998 році Ларрі Пейдж та Сергій Брін застосували випадкові блукання для створення алгоритму **PageRank**.

Веб представляється у вигляді орієнтованого графа. Щоб запобігти застряганню блукача у тупиках (вісячих вершинах без вихідних посилань), вводиться параметр демпфування `α ≈ 0.85`. На кожному кроці випадковий серфер:
- З імовірністю `α` переходить за випадковим вихідним посиланням з поточної сторінки.
- З імовірністю `1 - α` (або якщо вихідних посилань немає) телепортується на довільну сторінку мережі, обрану рівномірно випадково.

Матриця переходів модифікованого блукання має вигляд:

```
P_PageRank = α · P + (1 - α) / n · E
```

де `E` — матриця з усіх одиниць. Завдяки додаванню `(1 - α)/n E` матриця `P_PageRank` стає строго позитивною (`P_{uv} > 0`), що гарантує існування єдиного стаціонарного розподілу `π`. Значення `π(v)` визначає авторитетність (ранг) сторінки `v`.

Для персоналізованого пошуку (Personalized PageRank) вектор телепортації замінюється на специфічний вектор інтересів користувача `v_pers`, що дозволяє будувати локалізовані рекомендаційні системи. В алгоритмах Random Walk with Restarts (RWR) блукач із ймовірністю `1 - α` завжди повертається до обраної початкової вершини `s`, що вимірює структурну близькість інших вузлів графа до `s`.

### 3. Рівномірно випадкові кістякові дерева (Алгоритм Уїлсона)
Алгоритм Девід Уїлсона (1996) генерує строго рівномірний розподіл над множиною усіх кістякових дерев графа за допомогою **блукання з вилученням циклів** (Loop-Erased Random Walk, LERW).

Процес будується наступним чином:
1. Обираємо довільну початкову вершину `r` і додаємо її до дерева `T = {r}`.
2. Поки дерево `T` не охопить усі вершини графа:
   - Обираємо невідвідану вершину `u ∉ T` і випускаємо з неї випадковий блукач.
   - Під час руху блукача зберігаємо його траєкторію. Якщо блукач утворює цикл (влучає у вершину, яка вже є у поточному шляху), цей цикл **стирається** з траєкторії.
   - Як тільки блукач влучає у будь-яку вершину, що вже належить дереву `T`, весь вилучений від циклів шлях додається до дерева `T`.

Уїлсон довів, що цей процес будує кістякове дерево з абсолютно рівномірним розподілом за очікуваний час `O(m · R_eff(max))`.

Опис C/C++ API бібліотеки `GraphWalkEngine` міститься у специфікації [📋 Специфікація інтерфейсу випадкових блукань та стохастичного аналізу](book:algorithms/random-walks/api-random-walks.md).

> Випадкові блукання є основним інструментом у сучасних алгоритмах обробки великих графів (Graph Mining), рекомендаційних системах (Random Walk with Restarts), генерації випадкових графів та методах машинного навчання на графах (Node2Vec, Graph Neural Networks).

## 7. Порівняльний аналіз, межі застосовності та сучасні розширення

Випадкові блукання пропонують унікальний обчислювальний компроміс між просторовою складністю та часом виконання.

| Властивість / Алгоритм | Пошук у ширину (BFS) | Випадкове блукання (Aleliunas Walk) | Алгоритм Уїлсона (UST) | Алгоритм PageRank |
| :--- | :--- | :--- | :--- | :--- |
| **Детермінованість** | Детермінований | Стохастичний (Monte Carlo) | Стохастичний (Las Vegas) | Дійсний числовий |
| **Просторова складність** | `O(n)` біт | `O(log n)` біт | `O(n)` біт | `O(n)` біт |
| **Часова складність** | `O(n + m)` | `O(m · n)` | `O(m · R_eff)` | `O(k · m)` |
| **Вимоги до пам'яті** | Збереження черги/visited | Лише поточна вершина | Збереження дерева `next[]` | Два вектори весов |
| **Чутливість до топології** | Незначна | Висока (падає на `L_n`) | Середня | Залежить від зазору `1 - α` |

### Переваги випадкових блукань
1. **Екстремально мала пам'ять:** Алгоритми на основі блукань вимагають зберігання лише поточного стану, що робить їх ідеальними для обчислень у логарифмічній пам'яті (`RL`) та для розподілених систем.
2. **Локальність дій:** Блукач не потребує завантаження всього графа в оперативну пам'ять: достатньо отримувати список сусідів поточної вершини через зовнішній API (за принципом Streaming Graph або Local Computation).
3. **Стійкість до шуму:** Стохастична природа робить блукання стійкими до локальних пошкоджень ребер чи змін у структурі графа.

### Межі та недоліки
1. **Високий час виконання на «поганих» топологіях:** У графах із малим кондуктансом або структурами типу «Леденець» час покриття зростає до `O(n³)`, що робить блукання повільнішими за детерміновані обходи.
2. **Помилки першого/другого роду:** Ймовірнісні алгоритми на блуканнях вимагають мажоритарної ампліфікації для досягнення високої надійності результату.

### Сучасні розширення: від Node2Vec до квантових блукань
У сучасному аналізі даних випадкові блукання вийшли далеко за межі традиційного обходу графів:
- **MCMC та метод Метрополіса — Гейстінгса:** Модифікація ймовірностей переходів `P'_{uv} = P_{uv} · min(1, (π_target(v) P_{vu}) / (π_target(u) P_{uv}))` дозволяє генерувати випадкові вибірки з довільного складного цільового розподілу `π_target`.
- **Node2Vec та DeepWalk:** Алгоритми машинного навчання генерують траєкторії блукань на графах й передають їх у нейромережеві моделі типу Skip-gram (Word2Vec) для отримання векторних занурень (embeddings) вершин у неперервному векторному просторі. Використання параметрів `p` (повернення) та `q` (дослідження) дозволяє Node2Vec плавно балансувати між виявленням гомофілії (локальних кластерів) та структурної еквівалентності (ролі вершин у графі).
- **Графові нейронні мережі (GNN):** Архітектури типу GraphSAGE та Random Walk Neural Networks застосовують стохастичні блукання для агрегації інформації з локальних околиць великої розмірності, що дозволяє масштабувати навчання нейромереж на графах із мільярдами ребер.
- **Квантові випадкові блукання (Quantum Random Walks):** Заміна класичної монети на квантовий кубіт із унітарними операторами дозволяє блукачу перебувати у суперпозиції станів. Квантові блукання досягають квадратичного прискорення (квадратично менший час покриття `O(n)` замість `O(n²)` на лінійних ґратках), що є основою квантових пошукових алгоритмів.
