# 🧮 Математика природних доведень: Формальний бар'єр Разборова–Рудіча

Ця вставка містить суворе математичне формулювання та виведення мета-теореми Олександра Разборова та Стівена Рудіча (1997), яка доводить неможливість розділення складнісних класів `P/poly` та `NP` за допомогою натуральних комбінаторних властивостей за умови існування стійких криптографічних псевдовипадкових генераторів.

---

## 1. Формальний простір булевих функцій та схемна складність

Розглянемо фундаментальний обчислювальний простір усіх булевих функцій. Нехай `F♮ = {f: {0,1}^n → {0,1}}` позначує множину всіх можливих булевих функцій від `n` бінарних змінних `x = (x₁, x₂, ..., x♮)`.

Точна кількість різних функцій у просторі `F♮` дорівнює подвійній експоненті від кількості змінних:

```
|F♮| = 2^{2^n}
```

Таблиця істинності (англ. *truth table*) довільної функції `f ∈ F♮` представляється бінарним вектор-рядком `T_f ∈ {0,1}^N` довжини `N`, яка дорівнює кількості можливих вхідних комбінацій:

```
N = 2^n
```

Кожна позиція `x ∈ {0,1}^n` у таблиці істинності кодує значення `f(x) ∈ {0,1}`.

### Модель булевих схем та складність

Булева схема `C` над впорядкованим базисом вентилів `B = {AND, OR, NOT}` являє собою орієнтований ациклічний граф. 

Для будь-якої булевої функції `f ∈ F♮` її **схемна складність** `CircuitSize(f)` визначається як мінімальна кількість вентилів у схемі `C`, яка обчислює значення `f(x)` для всіх входів `x ∈ {0,1}^n`:

```
CircuitSize(f) = min { Size(C) | C обчислює f }
```

За знаменитою теоремою Клода Шеннона (1949), з використанням комбінаторного підрахунку кількість усіх можливих схем розміру `S` обмежується як `(c · S)^S`. Оскільки кількість функцій `2^{2^n}` зростає незрівнянно швидше за кількість малих схем, для випадково обраної булевої функції `R ∈ F♮` з імовірністю, що прямує до одиниці при `n → ∞`, виконується асимптотична нижня оцінка:

```
CircuitSize(R) > (1 - ε) · 2^n / n
```

Проте імовірнісний підхід Шеннона не дає змоги вказати на жодну конкретну конструктивну функцію з класу `NP`.

## 2. Формальне означення Натуральної властивості

Послідовність підмножин `C = {C♮}_{n=1}^∞`, де `C♮ ⊆ F♮`, називається **натуральною властивістю з параметрами (T(N), δ(n), S(n))**, якщо вона задовольняє три суворі математичні умови:

### 1. Умова Конструктивності (Constructiveness)

Властивість `C` називається **конструктивною з часовим бар'єром T(N)**, якщо існує детермінований алгоритм `A`, який за вхідним бінарним вектор-рядком `T_f` довжини `N = 2^n` обчислює предикат належності `A(T_f) = 1 ⇔ f ∈ C♮` за час, що поліноміально залежить від довжини таблиці істинності `N`:

```
Time(A(T_f)) ≤ T(N) = poly(N) = 2^{O(n)}
```

Це означає, що алгоритм перевірки `A` є ефективним відносно розміру таблиці істинності. Йому не потрібно виконувати повний експоненційний перебір усіх `2^{2^n}` можливих функцій чи схем, а достатньо застосувати доступні комбінаторні обчислення над рядком `T_f`.

### 2. Умова Великості (Largeness)

Властивість `C` називається **векою**, якщо частка функцій у просторі `F♮`, які володіють властивістю `C♮`, обмежується знизу вагомою поліноміальною або помітною експоненційною функцією від кількості змінних:

```
Pr_{R ∈ F♮}[ R ∈ C♮ ] = |C♮| / |F♮| ≥ δ(n)
```

де `δ(n) ≥ 1 / poly(n)` (у послабленій формі допускається `δ(n) ≥ 2^{-c n}`).

Інтуїтивно це означає, що критерій складності `C♮` охоплює статистично значущу частину простору `F♮`, тобто є притаманним «майже всім» випадковим булевим функціям.

### 3. Умова Корисності проти схем розміру S(n) (Usefulness)

Властивість `C` називається **корисною проти схем розміру S(n)**, якщо для кожної послідовності функцій `f = {f♮}_{n=1}^∞`, якщо `f♮ ∈ C♮` для всіх достатньо великих `n`, то її схемна складність суворо перевищує `S(n)`:

```
CircuitSize(f♮) > S(n)
```

Еквівалентно через контрапозицію: якщо функцію `g` можна обчислити схемою малого розміру `CircuitSize(g) ≤ S(n)`, то вона **гарантовано не володіє** властивістю `C♮`:

```
CircuitSize(g) ≤ S(n)  ⇒  g ∉ C♮  ⇒  A(T_g) = 0
```

## 3. Криптографічна модель псевдовипадкових генераторів функцій (PRF)

Формалізуємо криптографічну модель псевдовипадковості, на якій тримається стійкість сучасної асиметричної та симетричної криптографії.

Нехай `k = n^ε` (де `0 < ε < 1`) — довжина короткого криптографічного зерна (англ. *seed*). 

Сімейство функцій `G = {G_s: {0,1}^n → {0,1}}_{s ∈ {0,1}^k}` називається **псевдовипадковим генератором функцій (PRF) складності S(n)**, якщо виконуються дві умови:

### 1. Мала схемна складність поліноміального розміру

Для кожного зерна `s ∈ {0,1}^k` булева функція `f_s(x) = G_s(x)` обчислюється булевою схемою дуже малого поліноміального розміру:

```
CircuitSize(f_s) ≤ S_G(n) < S(n)
```

де `S_G(n) = poly(n)`.

За побудовою Голдрейха–Голдвассер–Мікалі (GGM, 1986), якщо існують односторонні генератори псевдовипадкових послідовностей (PRG), то розгортання зерна `s` у бінарному дереві глибини `n` дає сімейство PRF, кожна функція якого обчислюється схемою розміру `O(n · poly(k))`.

### 2. Криптографічна нерозрізненість від справжнього хаосу

Для будь-якого детермінованого або імовірнісного алгоритму `D` (розрізнювача), який працює за час `poly(N) = 2^{O(n)}` від довжини таблиці істинності `N = 2^n`, перевага розрізнення (англ. *distinguishing advantage*) є нехтовно малою:

```
Adv_G(D) = | Pr_{s ∈ {0,1}^k}[ D(T_{f_s}) = 1 ] - Pr_{R ∈ F♮}[ D(T_R) = 1 ] |  <  μ(n)
```

де `μ(n) = o(δ(n))` є нехтовною функцією, меншою за будь-яку обернено-поліноміальну величину `1 / n^c`.

## 4. Строге доведення теореми Разборова–Рудіча

Сформулюємо та доведемо головну мета-теорему Разборова–Рудіча.

```
Теорема (Razborov & Rudich, 1997):
Якщо існують псевдовипадкові генератори функцій PRF складності S(n),
то не існує жодної натуральної властивості C, корисної проти схем розміру S(n).
```

### Доведення (методом побудови розрізнювача):

Припустимо від супротивного, що існує натуральна властивість `C = {C♮}_{n=1}^∞` з параметрами `(poly(N), δ(n), S(n))`, корисна проти схем розміру `S(n)`.

Сконструюємо детермінований алгоритм-розрізнювач `D`, який отримує на вхід бінарну таблицю істинності `T_g ∈ {0,1}^N` невідомої булевої функції `g ∈ F♮`:

1. Алгоритм `D` викликає детермінований перевіряч конструктивної властивості `A(T_g)`.
2. Якщо `A(T_g) = 1` (функція володіє властивістю `C♮`), розрізнювач повертає `1`.
3. Якщо `A(T_g) = 0`, розрізнювач повертає `0`.

Проаналізуємо час роботи та поведінку розрізнювача `D` на двох можливих джерелах вхідних функцій:

#### Крок 1. Час роботи розрізнювача D

За умовою **Конструктивності**, час роботи алгоритму `A(T_g)` обмежений величиною `T(N) = poly(N)`. Оскільки довжина вхідного вектор-рядка `T_g` дорівнює `N = 2^n`, алгоритм `D` працює за поліноміальний час від розміру входу `N`. Це відповідає вимогам до допустимого криптографічного розрізнювача.

#### Крок 2. Оцінка ймовірності прийняття псевдовипадкових функцій f_s

Нехай на вхід розрізнювача подається псевдовипадкова функція `f_s`, згенерована зерном `s ∈ {0,1}^k`.

За властивістю PRF, схемна складність кожної псевдовипадкової функції обмежена: `CircuitSize(f_s) ≤ S_G(n) < S(n)`.

Проте за умовою **Корисності**, будь-яка функція `h ∈ C♮` вимагає схемної складності, суворо більшої за `S(n)` (`CircuitSize(h) > S(n)`).

Звідси негайно випливає, що жодна псевдовипадкова функція `f_s` не може володіти властивістю `C♮`:

```
∀ s ∈ {0,1}^k:  f_s ∉ C♮  ⇒  A(T_{f_s}) = 0  ⇒  D(T_{f_s}) = 0
```

Отже, ймовірність того, що розрізнювач видасть 1 на псевдовипадковій функції, є тотожно нульовою:

```
Pr_{s ∈ {0,1}^k}[ D(T_{f_s}) = 1 ] = 0
```

#### Крок 3. Оцінка ймовірності прийняття справді випадкових функцій R

Нехай на вхід розрізнювача подається справді випадкова функція `R ∈ F♮`, обрана за рівномірним розподілом з усіх `2^{2^n}` функцій.

За умовою **Великості**, ймовірність того, що випадкова функція задовольняє властивість `C♮`, обмежується знизу величиною `δ(n)`:

```
Pr_{R ∈ F♮}[ D(T_R) = 1 ] = Pr_{R ∈ F♮}[ A(T_R) = 1 ] = Pr_{R ∈ F♮}[ R ∈ C♮ ] ≥ δ(n)
```

#### Крок 4. Обчислення переваги розрізнення (Advantage)

Обчислимо статистичну перевагу розрізнювача `D` у відрізненні псевдовипадкових функцій від справді випадкових:

```
Adv_G(D) = | Pr_{s ∈ {0,1}^k}[ D(T_{f_s}) = 1 ] - Pr_{R ∈ F♮}[ D(T_R) = 1 ] |
         = | 0 - Pr_{R ∈ F♮}[ R ∈ C♮ ] |
         = Pr_{R ∈ F♮}[ R ∈ C♮ ]
         ≥ δ(n)
```

Оскільки за умовою **Великості** `δ(n) ≥ 1 / poly(n)`, перевага `Adv_G(D)` є помітною (не-нехтовною) обернено-поліноміальною величиною.

Це означає, що побудований алгоритм `D` повністю зламує псевдовипадковий генератор `G`, успішно відрізняючи його виходи від справжнього хаосу.

Це суперечить вихідному припущенню про криптографічну стійкість PRF. 

Таким чином, **жодна натуральна властивість не може бути корисною для доведення нижніх оцінок складності загальних булевих схем `P/poly`**. Теорему доведено. `■`

## 5. Порівняльний аналіз межі застосовності нижніх оцінок

Чому ж натуральні доведення спрацювали для `AC⁰` та `AC⁰[p]`, але виявилися безсилими проти `TC⁰` та `P/poly`? 

Проаналізуємо це через призму існування PRF у відповідних схемних класах:

```
+-----------------------------------------------------------------------+
| Схемний клас | Чи існують PRF? | Чи можливі Натуральні Доведення?     |
+--------------+-----------------+--------------------------------------+
| AC⁰          | НІ (Гостад)     | ТАК (Лема про перемикання Гостада)    |
| AC⁰[p]       | НІ (Смоленський)| ТАК (Поліноміальний метод)           |
| TC⁰          | ТАК (DDH, NR)   | НІ (Бар'єр Разборова-Рудіча)          |
| NC¹          | ТАК (GGM, AES)  | НІ (Бар'єр Разборова-Рудіча)          |
| P/poly       | ТАК (OWF)       | НІ (Бар'єр Разборова-Рудіча)          |
+-----------------------------------------------------------------------+
```

Математична межа проходить точно по лінії виникнення криптографічної псевдовипадковості: як тільки схемний клас стає достатньо потужним для реалізації псевдовипадкових генераторів (рівень `TC⁰`), натуральні доведення негайно стають зброєю зламу цієї ж псевдовипадковості, блокуючи можливість доведення нижніх оцінок.
