# 𝔮 Алгебраїчні виведення ізоморфізмів шестикратного твісту

Математична теорія твістів спирається на когомології Ґалуа (Galois cohomology, від імені французького математика Еваріста ҐАЛУА) та алгебраїчну структуру автоморфізмів еліптичних кривих. Еліптична крива `E`, визначена над скінченним полем `K = 𝔽_q`, описується коротким рівнянням Вейєрштрасса:

```
y² = x³ + a·x + b
```

Твістом еліптичної кривої `E` над розширенням `L / K` називається еліптична крива `E'`, визначена над `K`, яка є ізоморфною до `E` над полем `L` (тобто `E ≅ E'` над `L`), але не обов'язково є ізоморфною над полем `K`. Мінімальний ступінь розширення `d = [L : K]`, для якого існує такий ізоморфізм, називається степенем або порядком твісту (degree of twist).

Алгебраїчно поняття твісту класифікується через теорію когомологій. Класи `K`-ізоморфізму кривих, що стають ізоморфними над замиканням `K̄`, перебувають у бієктивній відповідності з елементами першої множини когомологій Ґалуа `H¹(Gal(K̄/K), Aut(E))`, де `Aut(E)` — група `K̄`-автоморфізмів кривої `E`. Якщо група автоморфізмів є циклічною групою порядку `d`, то множина когомологій зображується через елементи фактор-групи `K^* / (K^*)^d`, що визначає рівно `d` різних класів твістів.

Формально два твісти вважаються еквівалентними над полем `K`, якщо існує зміна змінних у `K`, яка переводить рівняння однієї кривої в рівняння іншої. Якщо ж такий ізоморфізм існує лише над полем розширення `L`, криві утворюють різні `K`-класи еквівалентності. Вибір конкретного нелишкового елемента поля породжує відповідний клас твістованої кривої.

Кожен клас твістованої кривої характеризується власним порядком групи точок `#E'(𝔽_{p^2})`. Алгебраїчний вираз порядку точок твістованої кривої пов'язаний зі слідом Фробеніуса `t` базової кривої `E(𝔽_p)` та характеристичним многочленом комплексного множення.

Множина всіх шести твістів степеня 6 ділиться на дві дзеркальні трійки залежно від спряженості нелишкових елементів у фактор-групі `𝔽_{p^2}^* / (𝔽_{p^2}^*)^6`. Три твісти відповідають D-type формалізації, а інші три — M-type формалізації, що дає повну алгебраїчну класифікацію.

Теорія комплексного множення розглядає кільце ендоморфізмів `End(E)`. Для кривих з `j = 0` кільце `End(E)` є окропом цілих чисел у фазовому уявному квадратичному полі `ℚ(√-3)`. Максимальний порядок у цьому полі утворений кільцем цілих чисел Ейзенштейна `ℤ[ω]`, де `ω = (-1 + √-3)/2` є примітивним кубічним коренем з одиниці.

## 1. Автоморфізми та клас кривих з j = 0

Множина `K`-автоморфізмів кривої `E` утворює групу `Aut(E)`. Для загальної кривої із `j`-інваріантом `j ≠ 0` та `j ≠ 1728` єдиними автоморфізмами є тотожне відображення та інверсія `(x, y) ↦ (x, -y)`, тому `Aut(E) ≅ ℤ_2`, що припускає існування лише квадратичних твістів (`d = 2`).

Для кривих із `j = 0` коефіцієнт `a = 0`, і рівняння кривої спрощується до вигляду `y² = x³ + b`.

Нехай `ζ_6` — примітивний корінь 6-го степеня з одиниці в алгебраїчному замиканні поля `K̄`, який задовольняє рівняння `ζ_6^6 = 1`. Задамо відображення `σ: E → E`:

```
σ(x, y) = (ζ_6² · x,  ζ_6³ · y) = (ζ_3 · x,  -y)
```

Перевіримо виконання рівняння кривої під дією відображення `σ`:

```
(-y)² = y²
(ζ_3 · x)³ + b = ζ_3³ · x³ + b = 1 · x³ + b = x³ + b
```

Отже, відображення `σ` зберігає криву `E`, а його повторні застосування генерують циклічну групу автоморфізмів `Aut(E) ≅ ℤ_6`.

Оскільки `Aut(E) ≅ ℤ_6`, перша множина когомологій Ґалуа `H¹(Gal(K̄/K), ℤ_6)` вимірюється елементами `K^* / (K^*)^6`. Це доводить існування шести алгебраїчно розрізнюваних класів твістів, а максимальний можливий ступінь розширення для ізоморфізму дорівнює `d = 6`.

Циклічна структура групи автоморфізмів `ℤ_6` гарантує, що при піднесенні відображення `σ` до степенів 2, 3 та 4 виникають підгрупи автоморфізмів другого та третього порядків. Це пояснює, чому криві з `j = 0` одночасно володіють квадратичними (`d = 2`), кубічними (`d = 3`) та шестикратними (`d = 6`) твістами.

Побудова шести різних класів твістів здійснюється вибором шести неконгруентних елементів `ξ_i ∈ 𝔽_{p^2}` у фактор-групі `𝔽_{p^2}^* / (𝔽_{p^2}^*)^6`. Кожен вибір породжує власне рівняння кривої `y'^2 = x'^3 + b / ξ_i`, де порядки точок беруть значення з множини коренів характеристичного многочлена.

Математично порядки точок для шести різних твістів над полем `𝔽_p` обчислюються через слід Фробеніуса `t` та число `y` з рівняння `4p = t^2 + 3y^2`. Шість можливих порядків групи дорівнюють `p + 1 - t`, `p + 1 + t`, `p + 1 - (t + 3y)/2`, `p + 1 + (t + 3y)/2`, `p + 1 - (t - 3y)/2` та `p + 1 + (t - 3y)/2`.

Структура підгруп автоморфізмів відображає підполя `𝔽_{p^2}` та `𝔽_{p^4}`. Підгрупа другого порядку `ℤ_2 = {id, σ^3}` відповідає інверсії `(x, -y)` та формує квадратичний твіст. Підгрупа третього порядку `ℤ_3 = {id, σ^2, σ^4}` описує кубічний твіст через скалювання `(ζ_3 x, y)`. Повний шестикратний твіст об'єднує обоє перетворень у єдину шестиступеневу вежу.

Зв'язок між автоморфізмами еліптичної кривої та ендоморфізмами полем розширення описується через кільцеве розширення `ℤ[ζ_6]`. Генератор групи автоморфізмів `σ` виступає як множник у кільці `ℤ[ζ_6]`, що діє на групу точок `E(K̄)`.

Точна декомпозиція множини когомологій показує, що клас твісту повністю фіксується вибором кубічного та квадратичного символу Нерона-Севері. Це створює канонічний алгебраїчний базис.

Алгебраїчна множина класів твістів володіє властивістю групової симетрії під дією автоморфізмів поля. Кожен твіст зберігає кривільну структуру вихідного рівняння Вейєрштрасса.

Застосування автоморфізму `σ` дозволяє класифікувати нерозкладні многочлени над `𝔽_{p^2}`. Будь-який корінь `w` багаточлена `t^6 - ξ` утворює циклічний базис `1, w, w^2, w^3, w^4, w^5`, який є стійким відносно операцій поля.

Розклад елементів полем розширення за канонічним базисом автоморфізму `σ` є детермінованим та унікальним для кожного класу твісту. Це забезпечує однозначність математичного відображення.

Геометричний та алгебраїчний аналіз показує, що наявність шостого кореня з одиниці `ζ_6` у замиканні поля виступає необхідною і достатньою умовою існування ізоморфізму `ψ_D`.

Кінцевий результат класифікації гарантує, що жоден інший класичний ізоморфізм степеня 6 не може існувати над кривими іншої кривизни.

## 2. Вежа розширень полів 𝔽_{p¹²}

Для спарувально-дружніх кривих із степенем занурення `k = 12` (таких як BN254 або BLS12-381) поле розширення `𝔽_{p¹²}` будується як вежа квадратичних та кубічних розширень:

```
𝔽_p
 └── 𝔽_{p²} = 𝔽_p[u] / (u² - β)         [β ∈ 𝔽_p не є квадратом]
      └── 𝔽_{p⁶} = 𝔽_{p²}[v] / (v³ - ξ)   [ξ ∈ 𝔽_{p²} не є квадратом і кубом]
           └── 𝔽_{p¹²} = 𝔽_{p⁶}[w] / (w² - v)
```

У цій вежі елемент `v ∈ 𝔽_{p^6}` задовольняє `v^3 = ξ`, а елемент `w ∈ 𝔽_{p^{12}}` задовольняє `w^2 = v`. Звідси отримуємо послідовні степені елемента `w`:

```
w² = v
w³ = v · w
w⁶ = (w²)³ = v³ = ξ ∈ 𝔽_{p²}
```

Таким чином, елемент `w` є коренем 6-го степеня з елемента `ξ ∈ 𝔽_{p²}`. Оскільки `ξ` не є ні квадратом, ні кубом у `𝔽_{p²}`, двочлен `t⁶ - ξ` є нерозкладним багаточленом над `𝔽_{p²}`, що забезпечує будування непривідного розширення `𝔽_{p¹²} / 𝔽_{p²}` степеня 6.

Така розбіжність вежі дає змогу подати будь-який елемент `A ∈ 𝔽_{p^{12}}` у формі полінома від `w` степеня менше 6 з коефіцієнтами у квадратичному полем `𝔽_{p^2}`: `A = c_0 + c_1 w + c_2 w^2 + c_3 w^3 + c_4 w^4 + c_5 w^5`.

Умови незвідності многочлена `t^6 - ξ` перевіряються через теорію символів Лежандра та Якобі над полем `𝔽_{p^2}`. Для того щоб `ξ` був нелишковим елементом 6-го степеня, норма `N(ξ) ∈ 𝔽_p` не повинна бути квадратичним чи кубічним лишком у базовому полі `𝔽_p`.

Утворена алгебраїчна вежа має важливу арифметичну перевагу: множення елемента `A ∈ 𝔽_{p^{12}}` на степінь базисного елемента `w^k` зводиться до цикла простого зсуву коефіцієнтів `c_i` з множенням на відповідні powers нелишкового елемента `ξ ∈ 𝔽_{p^2}`. Це усуває потребу у розгортанні складних множень поверхонь.

Формально група Ґалуа розширення `Gal(𝔽_{p^{12}} / 𝔽_{p^2})` є циклічною групою 6-го порядку, генерованою автоморфізмом `w ↦ ζ_6 · w`. Дія генератора Ґалуа ізоморфна дії геометрії автоморфізмів `σ` на твістованій кривій.

Основним наслідком вежової структури є спрощення нормальних підполів: `𝔽_{p^2}` утворює фіксоване поле (fixed field) для дії твістованого Фробеніуса. Кожен елемент `𝔽_{p^2}` залишається інваріантним під дією розгортання степенів `p^2`, що робить арифметику твістованої кривої `E'(𝔽_{p^2})` стабільною.

Послідовність розширень вежі `𝔽_p ⊂ 𝔽_{p^2} ⊂ 𝔽_{p^6} ⊂ 𝔽_{p^{12}}` дозволяє реалізувати нормове відображення `Norm_{𝔽_{p^{12}} / 𝔽_{p^2}}(A)` як послідовність проміжних норм над кубічним та квадратичним підполями. Це виявляється критичним під час обчислення фінального піднесення до степеня (final exponentiation) у кінці спарування.

## 3. Виведення D-type та M-type твістів

Залежно від того, як елемент `ξ` входить у рівняння твістованої кривої `E'`, розрізняють два типи шестикратного твісту: D-type (Divisive twist) та M-type (Multiplicative twist).

### 3.1 D-type твіст

D-type твіст визначається наданням відображення `ψ_D: E' → E` у вигляді:

```
ψ_D(x', y') = (x' · w²,  y' · w³)
```

Підставимо ці координати `(x, y) = (x' · w², y' · w³)` у рівняння базової кривої `E: y² = x³ + b`:

```
(y' · w³)² = (x' · w²)³ + b
y'² · w⁶ = x'³ · w⁶ + b                [використано закон степенів]
y'² · ξ = x'³ · ξ + b                  [підстановка w⁶ = ξ]
y'² = x'³ + b / ξ                      [поділено обидві частини на ξ]
```

Отже, рівняння D-type твістованої кривої `E'_D` над полем `𝔽_{p²}` має вигляд:

```
E'_D: y'² = x'³ + b / ξ
```

Обернене відображення стиснення `ψ_D⁻¹: E → E'_D` переводить точку `(x, y) ∈ E(𝔽_{p¹²})` у точку твістованої кривої над `𝔽_{p²}`:

```
ψ_D⁻¹(x, y) = (x / w²,  y / w³)
```

Геометричний зміст D-type твісту полягає у скалюванні координат точки за допомогою квадратного та кубічного коренів з елемента `ξ`. Оскільки `w^2 ∈ 𝔽_{p^6}` та `w^3 ∈ 𝔽_{p^6}`, координати розтвістованої точки `x = x' w^2` та `y = y' w^3` розгортаються у відповідні компоненти вежі полів `𝔽_{p^{12}}`.

### 3.2 M-type твіст

M-type твіст використовує обернений коефіцієнт у відображенні `ψ_M: E' → E`:

```
ψ_M(x', y') = (x' / w²,  y' / w³)
```

Підставимо `(x, y) = (x' / w², y' / w³)` у рівняння `y² = x³ + b`:

```
(y' / w³)² = (x' / w²)³ + b
y'² / w⁶ = x'³ / w⁶ + b
y'² / ξ = x'³ / ξ + b                  [підстановка w⁶ = ξ]
y'² = x'³ + b · ξ                      [помножено обидві частини на ξ]
```

Таким чином, рівняння M-type твістованої кривої `E'_M` над `𝔽_{p²}` набрало вигляду:

```
E'_M: y'² = x'³ + b · ξ
```

Вибір між D-type та M-type залежить від того, який із елементів `b/ξ` чи `b·ξ` створює зручніші коефіцієнти для арифметики в полях `𝔽_{p²}`. Наприклад, для кривої BLS12-381 використовується D-type твіст з `b = 4` та `ξ = 1 + u`, тоді як для BN254 (alt_bn128) застосовується M-type твіст з `b = 3` та `ξ = 9 + u`.

У разі M-type твісту обернене відображення `ψ_M⁻¹` множить координату `x` на `w^2`, а координату `y` на `w^3`. Це приводить до протилежного розподілу розріджених коефіцієнтів у лінійній функції алгоритму Міллера.

Формульний розклад координат для M-type прямовисно змінює позиції множників: `c_2` перетворюється на коефіцієнт біля `w^4`, а `c_3` — біля `w^3`. Ця протилежна симетрія повністю зберігає розрідженість лінійного елемента.

Окремим математичним критерієм вибору між D-type та M-type є властивість вирівнювання коефіцієнтів при виконанні кроку подвоєння точки в Якобієвих координатах. Для D-type константа `b / ξ` підходить для систем з нераціональним модулем, а M-type мінімізує число модульних віднімань.

Алгебраїчна сумісність D-type та M-type зображується через подвійний ізоморфізм над полем `𝔽_{p^{12}}`. Обидві твістовані криві є ізоморфними між собою над полем розширення `𝔽_{p^{12}}` через скалювальне відображення `(x'', y'') ↦ (x'' w^4, y'' w^6)`.

## 4. Алгебраїчна сумісність закону додавання точок

Щоб відображення `ψ: E'(𝔽_{p²}) → E(𝔽_{p¹²})` було груповим ізоморфізмом, воно має зберігати закон додавання точок: `ψ(P' + Q') = ψ(P') + ψ(Q')`.

Доведемо це для довільних точок `P' = (x₁', y₁')` та `Q' = (x₂', y₂')` на D-type кривій `E'_D`. Нахил січної `λ'` на твістованій кривій дорівнює:

```
λ' = (y₂' - y₁') / (x₂' - x₁')
```

Сума `R' = P' + Q' = (x₃', y₃')` обчислюється за формулами Вейєрштрасса:

```
x₃' = λ'² - x₁' - x₂'
y₃' = λ' · (x₁' - x₃') - y₁'
```

Застосуємо відображення `ψ_D` до точки `R'`:

```
ψ_D(x₃', y₃') = (x₃' · w²,  y₃' · w³)
              = ((λ'² - x₁' - x₂') · w²,  (λ' · (x₁' - x₃') - y₁') · w³)
```

Обчислимо нахил січної `λ` між розтвістованими точками `P = (x₁' w², y₁' w³)` та `Q = (x₂' w², y₂' w³)` на кривій `E`:

```
λ = (y₂' w³ - y₁' w³) / (x₂' w² - x₁' w²)   [визначення нахилу січної на кривій E]
  = (w³ · (y₂' - y₁')) / (w² · (x₂' - x₁'))  [винесення спільних множників w³ та w²]
  = w · λ'                                  [скорочення на w² та підстановка λ']
```

Тепер обчислимо координату `x₃` суми `P + Q` на базовій кривій `E`:

```
x₃ = λ² - x₁ - x₂                            [формула Вейєрштрасса для x-координати суми]
   = (w · λ')² - x₁' w² - x₂' w²              [підстановка λ = w·λ' та x_i = x_i'·w²]
   = λ'² w² - x₁' w² - x₂' w²                 [розкриття квадрата (w·λ')² = w²·λ'²]
   = (λ'² - x₁' - x₂') · w²                    [винесення спільного множника w²]
   = x₃' · w²                                 [підстановка x₃' = λ'² - x₁' - x₂']
```

Аналогічно для координати `y₃`:

```
y₃ = λ · (x₁ - x₃) - y₁                      [формула Вейєрштрасса для y-координати суми]
   = (w · λ') · (x₁' w² - x₃' w²) - y₁' w³     [підстановка λ, x₁, x₃ та y₁]
   = w · λ' · w² · (x₁' - x₃') - y₁' w³        [винесення w² з дужок різниці координат]
   = w³ · (λ' · (x₁' - x₃') - y₁')             [винесення спільного множника w³]
   = y₃' · w³                                 [підстановка y₃' = λ'·(x₁' - x₃') - y₁']
```

Результат повністю збігається з `ψ_D(R')`, що доводить алгебраїчну гомоморфність відображення `ψ` для всіх точок групи.

Доведення для випадку подвоєння точки `P' = Q'` виконується за аналогічною схемою: нахил дотичної `λ'_{tan} = (3 x_1'^2) / (2 y_1')` на кривій `E'` перетворюється у нахил `λ_{tan} = w · λ'_{tan}` на кривій `E`, що гарантує збереження операції `2P'`.

Геометрична гомоморфність зберігається також і при роботі у проєктивних координатах Якобі `(X', Y', Z')`. Твістоване розтвістування у координатах Якобі переводить трійку `(X', Y', Z')` у `(X' w^2, Y' w^3, Z')`, що дозволяє обходити без проміжних інверсій у полі розширення.

Алгебраїчна сумісність групового закону поширюється на всі операції скалярного множення. Для довільного цілого скаляра `m` виконується тотожність `ψ([m]P') = [m]ψ(P')`, що підтверджує повну еквівалентність підгрупи `G_2' ⊂ E'(𝔽_{p^2})` та підгрупи `G_2 ⊂ E(𝔽_{p^{12}})`.

## 5. Дія ендоморфізму Фробеніуса на твістованій кривій

Ендоморфізм Фробеніуса `π_p: E → E` підносить координати точки до степеня `p`: `π_p(x, y) = (x^p, y^p)`. На початковій кривій `E(𝔽_{p¹²})` точка `Q ∈ G₂` задовольняє характеристичний многочлен `π_p² - t·π_p + p = 0`, де `t` — слід Фробеніуса (trace of Frobenius).

Перенесемо дію ендоморфізму на твістовану криву `E'(𝔽_{p²})` за допомогою спряження `π_p' = ψ⁻¹ ∘ π_p ∘ ψ`.

Для D-type твісту обчислимо дію `π_p'` на точку `Q' = (x', y') ∈ E'(𝔽_{p²})`:

```
π_p'(Q') = ψ⁻¹( π_p( ψ(x', y') ) )            [визначення спряженого ендоморфізму]
         = ψ⁻¹( π_p( x' w²,  y' w³ ) )        [підстановка розтвістування ψ(x', y')]
         = ψ⁻¹( (x')^p · (w²)^p,  (y')^p · (w³)^p )  [дія Фробеніуса π_p(a,b) = (a^p, b^p)]
```

Оскільки `w⁶ = ξ ∈ 𝔽_{p²}`, степінь `w^p` розкладається як:

```
w^p = w^{p mod 6} · (w⁶)^{(p - (p mod 6))/6} = w^{p mod 6} · ξ^{(p - (p mod 6))/6}
```

Для BN-кривих та BLS12-381 модуль `p ≡ 1 (mod 6)`. Позначимо `γ = w^{p-1} = ξ^{(p-1)/6} ∈ 𝔽_{p²}`. Тоді `(w²)^p = w² · γ²` та `(w³)^p = w³ · γ³`.

Підставимо ці вирази у зворотне відображення `ψ⁻¹`:

```
π_p'(x', y') = ( ((x')^p · w² · γ²) / w²,   ((y')^p · w³ · γ³) / w³ )
             = ( (x')^p · γ²,   (y')^p · γ³ )
```

Звідси випливає, що обчислення ендоморфізму Фробеніуса на твістованій кривій `E'(𝔽_{p²})` вимагає лише спряження коефіцієнтів у `𝔽_{p²}` (піднесення до степеня `p`) та двох множень на константи `γ², γ³ ∈ 𝔽_{p²}`.

Ця властивість уможливлює розклад 256-бітного скаляра `k` за методом Ґалбрайта-Лінсона-Скотта (GLS method) у підгрупі `G_2`. Скаляр `k` зводиться до пари коротких 128-бітних скалярів `k_0, k_1`, а скалярне множення `[k]Q'` замінюється паралельним обчисленням `[k_0]Q' + [k_1] π_p'(Q')`. Це скорочує кількість ітерацій в алгоритмі Double-and-Add у два рази, оптимізуючи загальний час виконання криптографічних підписів BLS та перевірки доказів ZK-SNARK.

Алгебраїчна еквівалентність ендоморфізму Фробеніуса множенню на власний скаляр `λ` доводиться через характеристичний многочлен групи `G_2`. Оскільки підгрупа `G_2` утворена елементами власних просторів ендоморфізму Фробеніуса для власного значення `p`, операція `π_p'(Q')` діє як явне множення на число `λ = p mod r`. Це дає змогу будувати надшвидкі операції очищення кофактора (cofactor clearing) за формулою Скотта, минаючи пряме скалярне множення на 305-бітний кофактор `h'`.

Аналітичний матричний вираз ендоморфізму Фробеніуса у двовимірному векторному просторі над `𝔽_r` має вигляд квадратного оператора з нульовим слідом над підгрупою. Це гарантує стабільність розкладу GLS для будь-якої точки підгрупи `G_2` і робить його стійким до атак методом витоку через побічні канали.

Власні значення оператора Фробеніуса на `E'(𝔽_{p^2})` утворюють корені характеристичного многочлена `λ^2 - t' λ + p^2 = 0`, де `t'` — слід Фробеніуса над розширеним полем. Використання властивостей цього многочлена дозволяє підтверджувати належність точки до `G_2` без явного виконання повного розкладу на множники.

Формальний доказ власного значення спирається на мінімальний поліном циклічної підгрупи. Оскільки порядок точки дорівнює простим `r`, власне значення `λ` є первісним коренем `λ^6 ≡ 1 mod r`. Звідси ендоморфізм Фробеніуса шостого порядку виступає тотожним відображенням `(π_p')^6 = id` над підгрупою `G_2`, що повністю завершує строге математичне обґрунтування шестикратного твісту.
