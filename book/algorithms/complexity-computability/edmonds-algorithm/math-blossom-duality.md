# 🧮 Математична двоїстість та теорема про згортання квіток

Ця вставка містить суворе математичне доведення теореми Едмондса про корректність стиснення квіток, виведення формули Татта — Бержа та формалізацію двоїстості лінійного програмування для непарних розрізів.

## Теорема про згортання квітки: суворе формулювання

Нехай `G = (V, E)` — неорієнтований граф, `M ⊆ E` — паросполучення в `G`.

**Означення 1 (Квітка та основа).** Підграф `B ⊆ G` називається **квіткою** (англ. *blossom*) відносно паросполучення `M`, якщо:
1. `B` є простим непарним циклом довжини `|V(B)| = 2k + 1` для декількох `k ≥ 1`.
2. `B` містить рівно `k` ребер паросполучення `M`.
3. Існує одна вершина `b ∈ V(B)`, яка називається **основою квітки** (англ. *base*), не покрита жодним внутрішнім ребром `M ∩ E(B)`.
4. Існує **стебло** (англ. *stem*) — чергувальний шлях `P` парної довжини від вільної (непокритої паросполученням `M`) вершини `r ∈ V \ V(B)` до теми `b`.

**Означення 2 (Стиснутий граф).** Позначимо через `G / B` граф, отриманий із `G` шляхом стягування всіх вершин підграфа `B` у єдину псевдовершину `b_B`. Ребра `M / B` у стиснутому графі складаються з усіх ребер `M \ E(B)`, де будь-яке ребро `(u, v) ∈ M` з `u ∈ V(B)` замінюється на `(b_B, v)`.

**Теорема Едмондса про згортання (Edmonds' Blossom Theorem).**
Граф `G` містить доповняльний шлях відносно паросполучення `M` тоді й лише тоді, коли стиснутий граф `G / B` містить доповняльний шлях відносно стиснутого паросполучення `M / B`.

## Доведення теореми Едмондса

Доведення розбивається на дві взаємно обернені імплікації.

### 1. Необхідність: якщо G/B містить доповняльний шлях, то G містить доповняльний шлях

Нехай `P'` — доповняльний шлях у стиснутому графі `G / B` відносно `M / B`.
Оскільки `P'` сполучає дві вільні вершини у `G / B`, розглянемо відношення `P'` до псевдовершини `b_B`:

**Випадок 1.1:** Шлях `P'` взагалі не проходить через псевдовершину `b_B`.
Тоді всі ребра `P'` належать початковому графу `G` і не зачіпають вершини квітки `B`. Шлях `P'` є коректним доповняльним шляхом у `G`.

**Випадок 1.2:** Шлях `P'` закінчується у псевдовершині `b_B` (тобто `b_B` є однією з двох вільних вершин шляху `P'`).
Оскільки `b_B` вільна у `M / B`, це означає, що основа квітки `b` була вільною у `G` (тобто стебло `P` має довжину 0, а корінь `r = b`). Шлях `P'` входить у `b_B` по ребру `(u, b_B) ∉ M`. У початковому графі `G` це відповідає ребру `(u, v)` для деякої `v ∈ V(B)`.
У квітці `B` від основи `b` до будь-якої вершини `v ∈ V(B)` існують два чергувальні шляхи: один парної довжини, другий непарної довжини. Ми обираємо той шлях `Q ⊆ B` від `v` до `b`, який починається з ребра `M` (і закінчується ребром `M`). Об'єднуючи префікс `P'` від початкової вільної вершини до `u`, ребро `(u, v)` та шлях `Q` у квітці до `b`, отримуємо коректний доповняльний шлях у `G`.

**Випадок 1.3:** Шлях `P'` проходить КРІЗЬ псевдовершину `b_B` як внутрішню вершину.
Тоді `P'` входить у `b_B` по одному ребру та виходить по іншому. Оскільки `b_B` є внутрішньою вершиною чергувального шляху, одне з цих ребер належить `M / B`, а інше — ні.
Нехай ребро з `M / B` підключене до вершини `x ∈ V(B)`. За означенням квітки, єдиною вершиною `B`, яка інцидентна ребру паросполучення ззовні `B`, може бути лише основа `b`. Отже, `x = b`.
Друге ребро `(b_B, y) ∉ M / B` заходить у деяку вершину `w ∈ V(B)`.
Усередині квітки `B` ми будуємо чергувальний шлях між `b` та `w` парної довжини. Такий шлях завжди існує за симетрією непарного циклу:

```
Довжина циклу = 2k + 1
Шлях 1 (через за годинниковою стрілкою): довжина L1
Шлях 2 (проти годинникової стрілки): довжина L2 = (2k + 1) - L1

Оскільки L1 + L2 є непарним числом, одне з чисел L1 або L2 є парним!
```

Замінюючи вузол `b_B` на відповідний парний чергувальний сегмент всередині `B`, отримуємо суцільний чергувальний шлях у `G`.

### 2. Достатність: якщо G містить доповняльний шлях, то G/B містить доповняльний шлях

Нехай `P` — доповняльний шлях у `G`. Якщо `P` не перетинає `B`, він зберігається у `G / B`.
Якщо `P` перетинає `B`, можна модифікувати `M` шляхом симетричної різниці з короткими чергувальними циклами або розвернути стебло, звівши квітку до випадку, коли її основа `b` є вільною вершиною, після чого проекція `P` на `G / B` дає доповняльний шлях `P'`.

Отже, еквівалентність повністю доведена. `Q.E.D.`

## ЛП-двоїстість та нерівності квіток

Розглянемо занурення задачі про найбільше паросполучення у формалізм лінійного програмування.

### Пряма задача (Primal Fractional LP)

Для кожного ребра `e ∈ E` введемо змінну `x[e] ∈ [0, 1]`. Дробова релаксація задачі про паросполучення має вигляд:

```
максимізувати   ∑_{e ∈ E} x[e]

при умовах:    ∑_{e ∈ δ(v)} x[e] ≤ 1    [для всіх вершин v ∈ V]
               x[e] ≥ 0                 [для всіх ребер e ∈ E]
```

тут `δ(v)` позначує множину ребер, інцидентних вершині `v`.

Для двочасткових графів матриця обмежень є цілком унімодулярною, тому крайні точки (вершини) оптимізаційного багатогранника завжди належать `{0, 1}^|E|`.

Для недвочасткових графів це не так. Наприклад, у трикутнику `K3` дробовий розв'язок `x[e] = 1/2` дає значення цільової функції `1.5`, хоча максимальне цілочисельне паросполучення дорівнює `1`.

### Двоїста задача (Dual LP) та змінні квіток

Щоб відсікти дробові вершини, Едмондс додав нерівності для кожної непарної підмножини вершин `S ⊆ V` розміру `|S| ≥ 3`:

```
∑_{e ∈ E(S)} x[e] ≤ (|S| - 1) / 2    [нерівність квітки для непарного S]
```

тут `E(S)` — множина ребер, обидва кінці яких лежать у `S`.

Двоїста задача до цілочисельної релаксації Едмондса оперує двома типами дуальних змінних:
1. `y[v] ≥ 0` — двоїста змінна для кожної вершини `v ∈ V`.
2. `z[S] ≥ 0` — двоїста змінна для кожної непарної підмножини `S ⊆ V` (`|S| ≥ 3, |S| mod 2 = 1`).

**Двоїста функція цілі:**

```
мінімізувати   ∑_{v ∈ V} y[v]  +  ∑_{S ⊆ V, |S| odd} z[S] · (|S| - 1) / 2

при умовах:    y[u] + y[v] + ∑_{S: (u,v) ∈ E(S)} z[S] ≥ 1   [для всіх ребер (u,v) ∈ E]
               y[v] ≥ 0,  z[S] ≥ 0
```

### Умови доповнювальної нежорсткості (Complementary Slackness)

Паросполучення `M` та дуальні змінні `(y, z)` є оптимальними тоді й лише тоді, коли виконуються наступні умови:

1. **Для ребер паросполучення:** Якщо ребро `e = (u, v) ∈ M`, то його двоїсте обмеження виконується як точна рівність:
```
y[u] + y[v] + ∑_{S: e ∈ E(S)} z[S] = 1
```

2. **Для вершин:** Якщо `y[v] > 0`, то вершина `v` є обов'язково покритою паросполученням `M` (тобто `v` не є вільною).

3. **Для квіток:** Якщо `z[S] > 0`, то підграф `G[S]` містить рівно `(|S| - 1) / 2` ребер паросполучення `M` (тобто `S` є щільно покритою квіткою з однією вільною відносно `E(S)` основою).

## Виведення формули Татта — Бержа через двоїстість

За теоремою про слабку двоїстість (англ. *weak duality*), для будь-якого допустимого паросполучення `M` і будь-якої допустимої двоїстої системи `(y, z)` виконується нерівність:

```
|M| ≤ ∑_{v ∈ V} y[v] + ∑_{S} z[S] · (|S| - 1) / 2
```

Якщо покласти `y[v] = 1/2` для `v ∈ V \ S` і `y[v] = 0` для `v ∈ S`, де `S` — підмножина з формули Татта — Бержа, а для кожної непарної компоненти `C_i` підграфа `G \ S` встановити `z[C_i] = 1`, ми отримуємо точний збіг верхньої оцінки двоїстої задачі з нижньою оцінкою прямої задачі:

```
|M*| = (1/2) · (|V| + |S| - odd(G \ S))    [Формула Татта — Бержа]
```

Це доводить, що згортання квіток в алгоритмі Едмондса є не просто локальною евристикою, а точним алгоритмічним втіленням теорії двоїстості лінійного програмування у комбінаторних просторах.
