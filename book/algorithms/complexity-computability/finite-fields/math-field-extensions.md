# 𝔮 Строге доведення існування, єдиності та алгебраїчної структури GF(p^m)

Ця математична вставка містить строгі алгебраїчні доведення фундаментальних теорем теорії скінченних полів. Подані обґрунтування розкривають коректність побудови фактор-кілець багаточленів, розраховують точну кількість незвідних поліномів за формулою Гаусса, доводять циклічність мультиплікативної групи, встановлюють необхідні й достатні умови існування підполів та аналізують алгебраїчні властивості ендоморфізму Фробеніуса. Викладений апарат забезпечує повне теоретичне підґрунтя для застосування полів Галуа у сучасних алгоритмах криптографії та теорії складних обчислень.

## 1. Фактор-кільце GF(p)[x] / (f(x)) як алгебраїчне поле

Нехай `GF(p) = Z_p` — просте поле за модулем простого числа `p`. Кільце многочленів `GF(p)[x]` є евклідовим кільцем (і отже, кільцем головних ідеалів та факторіальним кільцем), у якому визначено алгоритм ділення залишком.

> **Теорема 1.** Фактор-кільце `R = GF(p)[x] / (f(x))` є алгебраїчним полем тоді й лише тоді, коли многочлен `f(x) ∈ GF(p)[x]` степеня `m ≥ 1` є незвідним над полем `GF(p)`.

### Доведення (Необхідність та достатність)

1. **Достатність (якщо `f(x)` є незвідним, то `R` є полем).**
   Нехай `f(x)` є незвідним многочленом степеня `m`. Оскільки `GF(p)[x]` є кільцем головних ідеалів, то головний ідеал `(f(x))` є максимальним ідеалом кільця `GF(p)[x]`. Фактор-кільце за максимальним ідеалом завжди утворює поле.

   Простежимо це конструктивно через доведення існування мультиплікативно оберненого елемента для будь-якого ненульового елемента `R`. Нехай `A(x) + (f(x))` є ненульовим елементом у `R`, що означає: многочлен `A(x) ∈ GF(p)[x]` не ділиться на `f(x)`.

   Оскільки `f(x)` — незвідний многочлен, єдиними дільниками `f(x)` є константи та многочлени, кратні `f(x)`. Оскільки `A(x)` не ділиться на `f(x)`, їхній найбільший спільний дільник у кільці `GF(p)[x]` дорівнює одиниці:

```
gcd(A(x), f(x)) = 1
```

   За тотожністю Безу для кільця многочленів існують многочлени `U(x), V(x) ∈ GF(p)[x]` такі, що виконується співвідношення:

```
U(x) · A(x) + V(x) · f(x) = 1
```

   Переходячи до розгляду даної тотожності за модулем ідеалу `(f(x))`, маємо:

```
U(x) · A(x) ≡ 1  (mod f(x))
```

   Отже, елемент `U(x) mod f(x)` є мультиплікативно оберненим до `A(x)` у фактор-кільці `R`. Оскільки кожен ненульовий елемент `R` має обернений, фактор-кільце `R` є алгебраїчним полем.

2. **Необхідність (якщо `R` є полем, то `f(x)` є незвідним).**
   Припустимо протилежне: `f(x)` є звідним многочленом, тобто розкладається у добуток двох многочленів нижчих степенів:

```
f(x) = g(x) · h(x)
```

   де `1 ≤ deg(g), deg(h) < m`.

   Розглянемо класи еквівалентності `g(x) + (f(x))` та `h(x) + (f(x))` у фактор-кільці `R`. Оскільки степені `g(x)` та `h(x)` строго менші за `m`, жоден з них не ділиться на `f(x)`, тому ці класи є ненульовими елементами `R`. 
   Проте їхній добуток у `R` дорівнює:

```
(g(x) + (f(x))) · (h(x) + (f(x)))
= g(x)·h(x) + (f(x))      [означення множення класу еквівалентності у фактор-кільці]
= f(x) + (f(x))           [підстановка f(x) = g(x)·h(x)]
= 0 + (f(x))              [оскільки f(x) ≡ 0 (mod f(x))]
```

   Отже, у кільці `R` існують дільники нуля. За аксіоматикою поля у ньому не може існувати дільників нуля (якщо `a · b = 0`, то `a = 0` або `b = 0`). Отримане протиріччя доводить, що `f(x)` обов'язково є незвідним.

### Порядок поля `|R| = pᵐ`

Будь-який клас еквівалентності у `GF(p)[x] / (f(x))` має єдиного канонічного представника `r(x)` степеня `deg(r) < m`:

```
r(x) = cₘ₋₁·xᵐ⁻¹ + cₘ₋₂·xᵐ⁻² + ... + c₁·x + c₀
```

Кожен коефіцієнт `cᵢ` обирається з простого поля `GF(p)` незалежно, тому загальна кількість різних представників обчислюється як:

```
|R| = p · p · ... · p  [m множників]
    = pᵐ
```

## 2. Кількість незвідних багаточленів та формула Гаусса

Гарантія існування поля `GF(pᵐ)` спирається на наявність принаймні одного незвідного многочлена степеня `m` над полем `GF(p)`.

> **Теорема 2 (Формула Гаусса).** Кількість `N_p(m)` нормованих незвідних многочленів степеня `m` над полем `GF(p)` обчислюється за формулою обернення Мьобіуса:

```
N_p(m) = (1 / m) · ∑_{d | m} μ(d) · p^{m / d}
```

де `μ(d)` — функція Мьобіуса, а сумування виконується за всіма дільниками `d` числа `m`.

### Вивід формули та обґрунтування існування

Розглянемо канонічний розклад многочлена `x^{pᵐ} - x` на незвідні множники у кільці `GF(p)[x]`:

```
x^{pᵐ} - x = ∏_{d | m} ∏_{f ∈ I_p(d)} f(x)
```

де `I_p(d)` — множина усіх нормованих незвідних многочленів степеня `d` над `GF(p)`. Прирівнюючи степені лівої та правої частин цієї тотожності, отримуємо:

```
pᵐ = ∑_{d | m} d · N_p(d)
```

Позначимо `g(m) = m · N_p(m)`. Тоді дана сума набуває вигляду `pᵐ = ∑_{d | m} g(d)`. Застосовуючи класичну формулу обернення Мьобіуса до функції `g(m)`, маємо:

```
m · N_p(m) = ∑_{d | m} μ(d) · p^{m / d}
```

Діленням обох частин на `m` отримуємо формулу Гаусса. 

Проаналізуємо значення `N_p(m)` для найгіршого випадку. Головний член суми `pᵐ` завжди домінує над сумою решти членів:

```
m · N_p(m) ≥ pᵐ - ∑_{k=0}^{⌊m/2⌋} pᵏ = pᵐ - (p^{⌊m/2⌋+1} - 1) / (p - 1) > 0
```

Оскільки `N_p(m) > 0` для будь-яких `p` та `m ≥ 1`, над будь-яким простим полем `GF(p)` завжди існує принаймні один незвідний многочлен довільного степеня `m`. Це гарантує існування скінченного поля `GF(pᵐ)`.

## 3. Строге доведення циклічності мультиплікативної групи GF(q)*

Нехай `GF(q)` — скінченне поле з `q = pᵐ` елементів, а `GF(q)* = GF(q) \ {0}` — його мультиплікативна група порядку `q - 1`.

> **Теорема 3.** Мультиплікативна група `GF(q)*` скінченного поля `GF(q)` є циклічною.

### Доведення

За фундаментальною теоремою про структуру скінченних абелевих груп, групу `GF(q)*` можна розкласти у прямий добуток циклічних груп:

```
GF(q)* ≅ Z_{e₁} × Z_{e₂} × ... × Z_{e_k}
```

де порядки факторів задовольняють умові подільності: `e₁ | e₂ | ... | e_k`. 

Позначимо `e = e_k` як найбільший порядок елемента у групі `GF(q)*` (експоненту групи). Оскільки порядки всіх факторів ділять `e_k`, порядок будь-якого елемента `g ∈ GF(q)*` ділить `e`. Звідси для кожного елемента `a ∈ GF(q)*` виконується тотожність:

```
aᵉ = 1
```

Це означає, що всі `q - 1` ненульових елементів поля `GF(q)` є коренями одного поліноміального рівняння:

```
P(x) = xᵉ - 1 = 0
```

у полі `GF(q)`. 

За основною теоремою алгебри для полів, ненульовий многочлен степеня `e` над полем `GF(q)` може мати **щонайбільше `e` різних коренів**. Звідси отримуємо нерівність:

```
q - 1 ≤ e
```

З іншого боку, за теоремою Лагранжа для скінченних груп, порядок будь-якого елемента ділить порядок всієї групи `q - 1`, звідки `e` ділить `q - 1`, що дає протилежну нерівність:

```
e ≤ q - 1
```

Поєднуючи обидві нерівності, отримуємо строго:

```
e = q - 1
```

Отже, у групі `GF(q)*` існує елемент `α` порядку `q - 1`. Цей елемент породжує всю групу:

```
GF(q)* = {α⁰, α¹, α², ..., α^{q-2}}
```

Що повністю доводить циклічність мультиплікативної групи `GF(q)*`. Елемент `α` називається **примітивним елементом (порошувачем)** поля `GF(q)`.

## 4. Критерій існування та структура підполів

Зв'язок між розширеннями скінченних полів повністю описується подільністю степенів розширення.

> **Теорема 4 (Критерій підполя).** Поле `GF(pᵏ)` є підполем поля `GF(pᵐ)` тоді й лише тоді, коли `k` ділить `m` (`k | m`).

### Доведення

1. **Необхідність (`GF(pᵏ) ⊆ GF(pᵐ) ⇒ k | m`).**
   Припустимо, що `K = GF(pᵏ)` є підполем `F = GF(pᵐ)`. Тоді поле `F` можна розглядати як векторний простір над полем `K`. Нехай `d = [F : K]` — вимірність цього векторного простору.
   Тоді кожен елемент `F` однозначно представляється вектором з `d` коефіцієнтами з `K`. Звідси кількість елементів у `F` дорівнює:

```
|F| = |K|^d  ⇒  pᵐ = (pᵏ)^d = p^{k·d}  ⇒  m = k · d
```

   Отже, `k` ділить `m`.

2. **Достатність (`k | m ⇒ GF(pᵏ) ⊆ GF(pᵐ)`).**
   Припустимо, що `k | m`, тобто `m = k · d`. Розглянемо подільність чисел `pᵏ - 1` та `pᵐ - 1`:

```
pᵐ - 1 = p^{k·d} - 1 = (pᵏ - 1) · ((pᵏ)^{d-1} + (pᵏ)^{d-2} + ... + 1)
```

   Звідси число `(pᵏ - 1)` ділить число `(pᵐ - 1)`. 
   Розглянемо многочлени `x^{pᵏ-1} - 1` та `x^{pᵐ-1} - 1` у кільці `GF(p)[x]`. Оскільки `(pᵏ - 1) | (pᵐ - 1)`, то `x^{pᵏ-1} - 1` ділить `x^{pᵐ-1} - 1`. Помноживши обидва многочлени на `x`, отримуємо:

```
(x^{pᵏ} - x)  ділить  (x^{pᵐ} - x)
```

   Множина елементів поля `GF(pᵐ)` складається з усіх `pᵐ` коренів многочлена `x^{pᵐ} - x`. Оскільки `x^{pᵏ} - x` ділить `x^{pᵐ} - x`, усі `pᵏ` коренів многочлена `x^{pᵏ} - x` також належать до множини коренів `x^{pᵐ} - x`, а отже повністю містяться у `GF(pᵐ)` і утворюють підполе, ізоморфне `GF(pᵏ)`.

## 5. Автоморфізм Фробеніуса та його лінійність

Оператор піднесення до степеня характеристики `p` є головним автоморфізмом у теорії скінченних полів.

> **Означення та Теорема 5.** Відображення `σ: GF(pᵐ) → GF(pᵐ)`, визначене як:

```
σ(x) = xᵖ
```

називається **автоморфізмом Фробеніуса**. Воно зберігає операції додавання та множення і є лінійним ендоморфізмом поля.

### Доведення лінійності (Перша мрія першокурсника)

1. **Збереження множення:**

```
σ(a · b) = (a · b)ᵖ
        = aᵖ · bᵖ        [комутативність множення в полі]
        = σ(a) · σ(b)
```

2. **Збереження додавання:**
   За формулою бінома Ньютона для елементів поля `a, b ∈ GF(pᵐ)`:

```
(a + b)ᵖ = aᵖ + (∑_{i=1}^{p-1} C_p^i · a^{p-i} · b^i) + bᵖ
```

   Проаналізуємо біноміальні коефіцієнти `C_p^i` для `1 ≤ i ≤ p - 1`:

```
C_p^i = p! / (i! · (p - i)!)
```

   Чисельник розкладу містить просте число `p`. Оскільки `i < p` та `(p - i) < p`, жоден з множників у знаменнику `i! · (p - i)!` не ділиться на `p`. Оскільки `p` — просте число, воно не скорочується зі знаменником, тому кожен біноміальний коефіцієнт `C_p^i` ділиться на `p` націло:

```
C_p^i ≡ 0  (mod p)  для всіх 1 ≤ i ≤ p - 1
```

   Оскільки характеристика поля дорівнює `p`, елемент `p · 1 = 0`. Отже, всі проміжні члени суми перетворюються на нуль:

```
(a + b)ᵖ = aᵖ + 0 + bᵖ = aᵖ + bᵖ
```

   Звідси `σ(a + b) = σ(a) + σ(b)`.

Автоморфізм Фробеніуса утворює циклічну групу автоморфізмів `Gal(GF(pᵐ) / GF(p))` порядку `m`, де тотожне відображення повертається на `m`-му кроці: `σᵐ(x) = x^{pᵐ} = x`.

## 6. Приклад покрокового обчислення поля GF(2^3)

Проілюструємо побудову поля `GF(2³)` з незвідним многочленом `f(x) = x³ + x + 1`.

1. **Елементи поля:** Поле містить `2³ = 8` елементів: `{0, 1, x, x+1, x², x²+1, x²+x, x²+x+1}`.
2. **Правило редукції:** Оскільки `f(x) = x³ + x + 1 = 0 (mod 2)`, маємо `x³ = x + 1`.
3. **Обчислення добутку двох елементів `A = x² + 1` (101₂) та `B = x² + x` (110₂):**

```
A(x) · B(x) = (x² + 1) · (x² + x)
            = x⁴ + x³ + x² + x      [поліноміальне множення]
```

   Застосовуємо редукцію `x³ = x + 1`:

```
x⁴ = x · x³ = x · (x + 1) = x² + x
```

   Підставляємо `x⁴` та `x³` у добуток:

```
A(x) · B(x) = (x² + x) + (x + 1) + x² + x
            = (x² + x²) + (x + x + x) + 1
            = 0 + x + 1
            = x + 1                [результат 011₂]
```

Таким чином, у полі `GF(2³)` добуток `(x² + 1) · (x² + x) = x + 1`.
