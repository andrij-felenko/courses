# 🧮 Нестандартні моделі арифметики Пеано та теорема Сколема

Ця вставка розкриває модельно-теоретичні властивості арифметики Пеано першого порядку, доводячи існування нестандартних моделей з нескінченно великими елементами через теорему Сколема, теорему про компактність та ультрадобутки.

Одним із найдивовижніших відкриттів математичної логіки XX століття стало те, що формальна арифметика Пеано першого порядку `PA` описує не лише звичний нам ряд натуральних чисел `ℕ = {0, 1, 2, 3, ...}`, а й принципово інші математичні структури, що містять «нескінченно великі» числа. Ці структури називаються **нестандартними моделями арифметики**.

## 1. Категоричність проти обмежень першої порядковості

У логіці другого порядку арифметика Пеано є **категоричною**: аксіома індукції другої порядковості охоплює абсолютно *всі* підмножини `X ⊆ ℕ`. Завдяки цьому будь-яка модель `M ⊨ PA₂` є ізоморфною стандартній моделі `ℕ`.

Проте у логіці першого порядку ми змушені замінити єдину аксіому індукції на **зліченну схему аксіом індукції**:

```
(φ(0) ∧ ∀x (φ(x) → φ(S(x)))) → ∀x φ(x)
```

де `φ` — синтаксично коректна формула мови `L_PA`. Оскільки синтаксичних формул мови `L_PA` є лише зліченна кількість `ℵ₀`, а підмножин натуральних чисел є континуум `2^ℵ₀`, схема індукції першого порядку здатна контролювати лише зліченне сімейство «виражуваних» підмножин. Це залишає «синтаксичну прогалину», крізь яку проникають нестандартні моделі.

## 2. Теорема Сколема та побудова нестандартної моделі (1934)

Норвезький математик Тораф Сколем (Thoralf Skolem) у 1934 році довів фундаментальну теорему: **існують нестандартні моделі арифметики Пеано першого порядку**.

Доведення існування такої моделі спирається на **теорему про компактність** логіки першого порядку: множина формул `T` має модель тоді й лише тоді, коли кожна її скінченна підмножина має модель.

### 2.1. Конструкція Сколема через розширення мови

1. Розширимо сигнатуру мови арифметики `L_PA`, додавши новий константний символ `c`.
2. Сформуємо нову формальну теорію `T*`, що складається з усіх аксіом `PA` та нескінченної множини нових нерівностей:

```
T* = PA ∪ { c > 0̄, c > 1̄, c > 2̄, ..., c > n̄, ... }
```

де `n̄ = S(S(...0...))` — нумерал числа `n`.

3. Розглянемо довільну *скінченну* підмножину `T_fin ⊂ T*`. Вона містить лише скінченне число нерівностей `c > k̄₁`, `c > k̄₂`, ..., `c > k̄_m`. Нехай `K = max(k₁, ..., k_m)`.
4. Складемо модель для `T_fin`: інтерпретуємо константу `c` як стандартне число `K + 1 ∈ ℕ`. Тоді всі аксіоми з `T_fin` виконуються у стандартній арифметиці `ℕ`.
5. За теоремою про компактність, оскільки кожна скінченна підмножина `T_fin` є виконуваною, то й уся нескінченна теорія `T*` має деяку модель `M*`.

У цій моделі `M*` елемент `c` є **нестандартним натуральним числом**: він більший за кожне стандартне число `n ∈ ℕ`.

### 2.2. Побудова через ультрадобуток (Ultraproduct Construction)

Альтернативний конструктивний спосіб отримати нестандартну модель `M*` спирається на теорію ультрафільтрів.

Нехай `U` — неголовний (вільний) ультрафільтр на множині натуральних чисел `ℕ`. Розглянемо декартовий добуток зліченної кількості копій `ℕ`:

```
ℕ^ℕ = { (a₀, a₁, a₂, ...) | a_i ∈ ℕ }
```

Визначимо відношення еквівалентності `~_U` на послідовностях: дві послідовності `a = (a_i)` та `b = (b_i)` є еквівалентними, якщо множина індексів, на яких вони збігаються, належить ультрафільтру `U`:

```
a ~_U b   ⇔   { i ∈ ℕ | a_i = b_i } ∈ U
```

Фактор-множина `M* = ℕ^ℕ / ~_U` з покомпонентно визначеними операціями `+` та `·` за **теоремою Лося** (Łoś's Theorem) задовольняє точно ті самі формули першого порядку, що й стандартна модель `ℕ`.

Послідовність `c = (0, 1, 2, 3, 4, ...)` дає клас еквівалентності, який є строго більшим за будь-яку константну послідовність `n̄ = (n, n, n, ...)` відносно ультрафільтра `U`. Отже, `[c]_U` є нестандартним елементом у `M*`.

## 3. Топологічна та алгебраїчна структура нестандартної моделі

Як виглядає нестандартна модель `M* ⊨ PA` з точки зору порядкової структури?

Будь-яка зліченна нестандартна модель `M*` має дуже чітку порядок-теоретичну будову:

```
M* ≅ ℕ + ℤ · ℚ
```

Це означає, що модель складається з двох принципово різних частин:

1. **Початковий сегмент (Стандартне ядро):** ізоморфна копія звичайних натуральних чисел `ℕ = {0, 1, 2, 3, ...}`.
2. **Нескінченна частина:** нескінченний набір «галактик» (блоків), кожна з яких ізоморфна впорядкованій множині цілих чисел `ℤ`. Самі ці галактики впорядковані між собою щільно без найменшого та найбільшого елемента — так само, як множина раціональних чисел `ℚ`.

```
[0, 1, 2, 3...] < [... c-2, c-1, c, c+1, c+2 ...] < [... d-2, d-1, d, d+1, d+2 ...]
  (Ядро N)                (Галактика c)                 (Галактика d)
```

### Алгебраїчні дива у нестандартній моделі:

- **Парність та ділимість:** Елемент `c` у нестандартній моделі є натуральним числом з точки зору `PA`. Отже, у `M*` виконується твердження `∀x (Even(x) ∨ Odd(x))`. Це означає, що `c` є або строго парним, або строго непарним! Якщо `c` парне, то існує нестандартне число `c / 2`, яке також лежить у нескінченній галактиці.
- **Прості числа:** У `M*` існують нескінченно великі прості числа. Тобто існують нестандартні елементи `p ∈ M* \ ℕ`, які не мають дільників, крім `1` та `p`, у сенсі мови `PA`.
- **Завершення кодувань:** Нестандартне число `c` може кодувати нестандартно довгу послідовність чисел або гіпотетичний «нескінченно довгий» текст доведення.

## 4. Принцип переповнення (Overspill Principle)

Принцип переповнення — це потужний інструмент модельно-теоретичного аналізу `PA`, який демонструє нездатність формул першого порядку відокремити стандартні числа від нестандартних.

### Теорема (Принцип переповнення / Overspill):
Нехай `M*` — нестандартна модель `PA`, а `φ(x)` — формула мови `L_PA` (можливо з параметрами з `M*`). Якщо `φ(n)` істинне для всіх стандартних натуральних чисел `n ∈ ℕ`, то існує нестандартний елемент `c ∈ M* \ ℕ` такий, що `φ(c)` також є істинним.

**Доведення:**
Припустимо протилежне: `φ(x)` істинне для всіх `x ∈ ℕ`, але хибне для всіх нестандартних `x ∈ M* \ ℕ`.
Розглянемо формулу `ψ(x) ≡ ∀y (y ≤ x → φ(y))`.
За припущенням, `ψ(0)` істинне. Також якщо `ψ(k)` істинне для стандартного `k`, то `ψ(k + 1)` також істинне.
За аксіомою індукції для формули `ψ` у моделі `M*`, ми мали б виснувати `∀x ψ(x)`. Це означає, що `φ(x)` мало б виконуватися для *всіх* елементів `M*`, включаючи нестандартні. Суперечність. ∎

Принцип переповнення доводить, що **підмножина стандартних чисел `ℕ` не є виражуваною жодною формулою першого порядку у нестандартній моделі `M*`**. Стандартне ядро `ℕ` є «невидимим» для внутрішньої мови `PA`.

Існує також дзеркальний **Принцип недоповнення (Underspill Principle)**: якщо формула `φ(x)` виконується для довільно малих нестандартних елементів, то вона повинна виконуватися і для нескінченно багатьох стандартних натуральних чисел.

## 5. Зв'язок із комбінаторною недоведеністю: Теорема Парижа — Гаррінгтона

Нестандартні моделі надають прозору геометрію для доведення недоведеності певних математичних тверджень у `PA`.

У 1977 році Джефф Паріс (Jeff Paris) та Лео Гаррінгтон (Leo Harrington) сформулювали посилену скінченну теорему Рамсея (**Strong Finite Ramsey Theorem**). Це було перше природне комбінаторне твердження (без кодування Ґеделя чи самореферентності), яке є істинним у `ℕ`, але недовідним у `PA`.

Сформулюємо це твердження: для будь-яких натуральних чисел `n, k, m` існує таке натуральне число `N`, що для будь-якого розфарбування `k`-елементних підмножин множини `{0, 1, ..., N - 1}` у `m` кольорів існує монохроматична підмножина `Y`, яка є не лише розміру принаймні `n`, а й є **великою** у сенсі: `|Y| ≥ min(Y)`.

З точки зору нестандартних моделей, недоведеність теореми Парижа — Гаррінгтона пояснюється так: існує нестандартна модель `M* ⊨ PA`, у якій для певного нестандартного розміру `N ∈ M* \ ℕ` не існує відповідного розфарбування графу, оскільки необхідний розмір монохроматичної підмножини виходить за межі моделі («переповнює» стандартне ядро).

Аналогічно, **теорема Ґудстейна** та **гра Гідри Кірбі — Паріса** термінують у стандартній моделі `ℕ` за скінченне число кроків, але довжина ланцюжка росте настільки швидко (як функція Аккермана або ординал `ε₀`), що у нестандартній моделі `M*` цей процес перетворюється на нескорочувану нескінченну послідовність, що унеможливлює доведення термінації засобами першої порядковості `PA`.
