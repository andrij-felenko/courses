# 📜 Історія формалізації арифметики: від Грассмана та Дедекінда до Пеано

Наприкінці XIX століття математика опинилася перед необхідністю переосмислення своїх найпервинніших засад. Тисячоліттями натуральні числа `ℕ = {0, 1, 2, 3, ...}` сприймалися як наочна понятійна основа, надана людському розуму безпосередньо через просторово-часову інтуїцію. Проте стрімкий розвиток математичного аналізу, виявлення неевклідових геометрій та побудова дивних патологічних функцій (наприклад, безперервних, але ніде не диференційовних функцій Вейєрштрасса) продемонстрували, що наочна геометрична та числова інтуїція часто підводить математиків і призводить до прямих суперечностей.

Усвідомлення цієї крихкості спонукало провідних науковців до фундаментальної програми: звести весь математичний аналіз до суворої арифметики натуральних чисел («арифметизація аналізу»), а саму арифметику натуральних чисел побудувати на основі абсолютно прозорих, простих та суворих логічних аксіом.

## 1. Перші кроки: Герман Грассман та рекурсивне визначення операцій (1861)

Перший рішучий крок у напрямку формального обґрунтування арифметики зробив німецький математик, філолог і механік Герман Грассман (Hermann Grassmann, 1809–1877). У своїй праці *Lehrbuch der Arithmetik* («Підручник арифметики», 1861) Грассман поставив за мету вивести всі фундаментальні алгебраїчні властивості додавання та множення (асоціативність, комутативність, дистрибутивність) із простішої унарної операції — взяття наступного елемента `S(n) = n + 1`.

Грассман уперше в історії математики запропонував строгі індуктивні (рекурсивні) визначення додавання та множення:

```
a + 0 = a
a + (b + 1) = (a + b) + 1

a · 0 = 0
a · (b + 1) = (a · b) + a
```

Спираючись на ці рекурсивні рівності, Грассман довів комутативність додавання `a + b = b + a` за допомогою послідовних кроків індукції за змінною `b`. Хоча Грассман ще не сформулював аксіому індукції як окреме абстрактне правило логічного виведення у явному предикатному синтаксисі, його робота продемонструвала фундаментальну ідею: алгебраїчна структура натуральних чисел повністю визначається початковим елементом `0`, операцією послідовника `S` та принципом індуктивного розгортання.

## 2. Теоретико-множинне обґрунтування Ріхарда Дедекінда (1888)

Вирішальний прорив у математичному розумінні глибокої впорядкованої структури натуральних чисел здійснив німецький математик Ріхард Дедекінд (Richard Dedekind, 1831–1916). У своїй епохальній монографії *Was sind und was sollen die Zahlen?* («Що таке і для чого служать числа?», 1888) Дедекінд дав перше строге обґрунтування натуральних чисел у термінах теорії множин та відображень.

Дедекінд увів поняття **простої нескінченної системи** (системи Дедекінда). Він визначив множину натуральних чисел як будь-яку множину `N`, для якої існує ін'єктивне відображення `φ: N → N` та виділений елемент `e ∈ N` такі, що:

1. Елемент `e` не належить образу відображення: `e ∉ φ(N)`.
2. Множина `N` є найменшою множиною, яка містить `e` і є замкненою відносно відображення `φ` (тобто не містить власних підмножин з такими властивостями).

Для опису цієї «найменшості» Дедекінд розробив математичну теорію **ланцюгів** (Ketten). Ланцюгом підмножини `A ⊆ N` називається найменша підмножина, яка містить `A` і замкнена відносно `φ`. Індуктивне визначення природного ряду чисел у Дедекінда спиралося на перетин усіх таких замкнених множин.

Дедекінд математично довів фундаментальну **теорему про рекурсію**, яка стверджує, що для довільної множини `A`, її елемента `a₀ ∈ A` та функції `g: A → A` існує єдина функція `f: N → A` така, що:

```
f(e) = a₀
f(φ(n)) = g(f(n))   для всіх n ∈ N
```

Більше того, Дедекінд довів теорему про **категоричність**: будь-які дві системи, що задовольняють його аксіоми, є ізоморфними. Це означало, що аксіоми Дедекінда фіксують натуральні числа з точністю до унікальної ізоморфної алгебраїчної структури.

## 3. Джузеппе Пеано та символічний формалізм (1889)

Італійський математик і логік Джузеппе Пеано (Giuseppe Peano, 1858–1932) у праці *Arithmetices principia, nova methodo exposita* («Принципи арифметики, викладені новим методом», 1889) переклав теоретико-множинні ідеї Дедекінда та рекурсивні рівності Грассмана на мову строгої символічної логіки.

Пеано працював у Туринському університеті та прагнув усунути з математичних міркувань будь-які залишки природної мови, які могли б приховувати логічні прогалини. Саме у цій праці Пеано розробив більшість логічних символів, якими математичний світ користується дотепер: символи належності `∈` (від грецького εστί — «є»), включення `⊂`, об'єднання `∪`, перетину `∩` та квантора існування `∃`.

Оригінальна система аксіом Пеано 1889 року була сформульована латинською мовою і складалася з 9 аксіом. Перші чотири описували загальні рефлексивні, симетричні та транзитивні властивості рівності, а решта п'ять — безпосередньо властивості чисел:

```
1. 1 є натуральним числом (1 ∈ N).
2. Якщо x є натуральним числом, то x = x.
3. Якщо x = y, то y = x.
4. Якщо x = y та y = z, то x = z.
5. Якщо a = b та a ∈ N, то b ∈ N.
6. Якщо x є натуральним числом, то x + 1 (наступник) є натуральним числом.
7. Якщо x та y є натуральними числами і x = y, то x + 1 = y + 1.
8. Якщо x є натуральним числом, то x + 1 ≠ 1.
9. Якщо K є множиною такою, що 1 ∈ K, і для кожного x ∈ K з умови x ∈ K випливає x + 1 ∈ K, то N ⊂ K.
```

Пізніше Пеано та його послідовники спростили цей перелік: аксіоми рівності винесли у загальну логіку числення предикатів, а початковий елемент `1` замінили на `0` для зручності побудови теорії графіків, алгебри та комбінаторики.

Пеано чесно визнавав у своїх працях, що основні математичні результати щодо структури індуктивних множин були отримані Дедекіндом. Проте внесок Пеано виявився вирішальним у перетворенні математики на формальну синтаксичну систему, придатною для механічної перевірки виведень.

## 4. Логіцизм Готлоба Фреге та парадокс Рассела

Паралельно з Пеано німецький логік, математик і філософ Готлоб Фреге (Gottlob Frege, 1848–1925) розробляв грандіозний проект **логіцизму** у працях *Die Grundlagen der Arithmetik* («Основи арифметики», 1884) та *Grundgesetze der Arithmetik* («Основні закони арифметики», 1893–1903). Фреге прагнув довести, що арифметика взагалі не потребує спеціальних математичних аксіом, а є прямим продовженням чистої логіки.

Фреге визначив число `0` як обсяг поняття «не рівний самому собі» (оскільки жоден об'єкт не задовольняє цю умову, обсяг містить порожню множину). Кожне наступне число `n + 1` визначалося як клас усіх множин, які містять `n + 1` елемент.

Проте у червні 1902 року, коли другий том *Grundgesetze* вже знаходився у друкарні, британський філософ і логік Бертран Рассел (Bertrand Russell) надіслав Фреге знаменитий лист, у якому описав парадокс: якщо розглянути множину всіх множин, які не містять себе як елемент `R = {x | x ∉ x}`, то виникає пряма суперечність `R ∈ R ⇔ R ∉ R`.

Парадокс Рассела завдав нищівного удару по наївній теорії множин та проекту Фреге. Стало зрозуміло, що аксіому індукції не можна просто сформулювати для «довільного поняття чи будь-якої множини» без жорстких синтаксичних обмежень.

## 5. Програма Гільберта, Гьоттінгенська школа та формування PA

У 1920-х роках у Гьоттінгенському університеті під керівництвом Давида Гільберта (David Hilbert) сформувалася формалістична школа (Пауль Бернайс, Вільгельм Аккерман, Джон фон Нойман, Герхард Ґентцен).

Гільберт висунув концепцію **доказової теорії** (Beweistheorie). Для усунення парадоксів Гільберт запропонував:
1. Зафіксувати арифметику як суворо синтаксичну систему першого порядку без семантичних припущень.
2. Відокремити логіку першого порядку (де квантори застосовуються лише до елементів-чисел) від логіки другого порядку.
3. Довести несуперечливість цієї системи чисто фінітними засобами.

Саме у працях Гільберта, Бернайса та норвезького математика Торафа Сколема у 1920–1930-х роках сформувалося сучасне обличчя **Арифметика Пеано першого порядку (PA)**. Вони замінили аксіому індукції другої порядковості Дедекінда-Пеано на **зліченну схему аксіом індукції** для кожної синтаксично коректної формули мови `L_PA`.

У 1936 році Герхард Ґентцен (Gerhard Gentzen) здійснив видатне доведення несуперечливості `PA`. Він довів, що арифметика Пеано є несуперечливою, якщо до звичайних правил виведення додати трансфінітну індукцію до ординалу `ε₀` (ординал Кантора). Це доведення точнісінько окреслило межу синтаксичної сили арифметики Пеано: `PA` здана довести індукцію для будь-якого ординала `α < ε₀`, але безпорадна перед самим ординалом `ε₀`.
