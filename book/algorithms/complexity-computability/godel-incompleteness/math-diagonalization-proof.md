# 🧮 Математичне доведення теорем Ґеделя та леми про нерухому точку

Ця вставка містить вичерпне математичне виведення Леми про нерухому точку (діагональної леми), Першої та Другої теорем Ґеделя про неповноту, а також підходу Барклі Россера та умов довідності Гільберта-Бернайса-Льоб. Вона будує суворі ланцюжки логічних еквівалентностей та синтаксичних виведень для читача, якому необхідна формальна математична точність кожного кроку доведення.

## 1. Формальний синтаксис та репрезентовність у арифметиці Пеано

Розглядається формальна теорія першого порядку — арифметика Пеано (`PA`). Сигнатура мови `L_PA` складається з константи `0`, одномісного функціонального символу `S` (наступник), двомісних функціональних символів `+` та `·`, а також предикату рівності `=`.

Терми мови `L_PA` будуються індуктивно:

```
t ::= 0 | x | S(t) | (t₁ + t₂) | (t₁ · t₂)
```

Для кожного натурального числа `n ∈ ℕ` визначено відповідний **нумерал** `n̄` у мові `L_PA`:

```
0̄ = 0
1̄ = S(0)
2̄ = S(S(0))
n̄ = Sⁿ(0)
```

Теорія `PA` складається з аксіом рівності, шести алгебраїчних аксіом для `S`, `+`, `·` та нескінченної схеми аксіом індукції для довільної формули `φ(v)`:

```
[φ(0) ∧ ∀x (φ(x) → φ(S(x)))] → ∀x φ(x)
```

### Означення репрезентовності

Функція `f: ℕᵏ → ℕ` називається **репрезентовною (зображуваною)** у `PA`, якщо існує формула мови `L_PA` з `k + 1` вільними змінними `Ψ_f(v₁, ..., vₖ, y)` така, що для будь-якого набору чисел `(n₁, ..., nₖ) ∈ ℕᵏ`:

```
f(n₁, ..., nₖ) = m  ⇒  PA ⊢ ∀y (Ψ_f(n̄₁, ..., n̄ₖ, y) ↔ y = m̄)
```

Предикат `R ⊆ ℕᵏ` називається **репрезентовним** у `PA`, якщо його характеристична функція `χ_R` є репрезентовною, тобто існує формула `Φ_R(v₁, ..., vₖ)` така, що:

```
(n₁, ..., nₖ) ∈ R  ⇒  PA ⊢ Φ_R(n̄₁, ..., n̄ₖ)
(n₁, ..., nₖ) ∉ R  ⇒  PA ⊢ ¬Φ_R(n̄₁, ..., n̄ₖ)
```

**Фундаментальна теорема кодування:** Усі примітивно-рекурсивні функції та предикати є репрезентовними у `PA`. Це означає, що формальна теорія `PA` спроможна моделювати та обчислювати результати будь-яких детермінованих алгоритмів із фіксованою кількістю обчислювальних кроків безпосередньо через предикати першого порядку.

## 2. Арифметизація: Ґеделева нумерація та предикат довідності

Нехай `┌φ┐ ∈ ℕ` позначує унікальний Ґеделів номер формули або терму `φ`. Нумерація здійснюється шляхом зіставлення кожному символу алфавіту числового коду та обчислення степеневого добутку послідовних простих чисел `p₁ˢ¹ · p₂ˢ² · ... · pₖˢᵏ`.

Оскільки синтаксичний аналіз формули та перевірка кроків доведення є примітивно-рекурсивними процесами, відношення «`y` є Ґеделевим номером послідовності формул, яка являє собою коректне формальне доведення у `PA` формули з Ґеделевим номером `x`» задається примітивно-рекурсивним предикатом:

```
ProofPA(x, y) ⊆ ℕ × ℕ
```

Отже, за фундаментальною теоремою репрезентовності існує формула мови `L_PA` — `Prf_PA(x, y)`, яка строго репрезентує цей предикат:

```
y є доведенням φ   ⇒  PA ⊢ Prf_PA(┌φ┐̄, ȳ)
y не є доведенням φ ⇒  PA ⊢ ¬Prf_PA(┌φ┐̄, ȳ)
```

Предикат довідності `Prov_PA(x)` будується через застосування квантора існування по коду доведення:

```
Prov_PA(x) ≡ ∃y Prf_PA(x, y)
```

Зауважимо важливу відмінність: предикат `Prov_PA(x)` вже не є примітивно-рекурсивним; він описує рекурсивно перелічувану множину номерів довідних формул і не є алгоритмічно розв'язним у загальному випадку.

Також існує примітивно-рекурсивна функція діагонального підставлення `subst(x, y)`, яка за Ґеделевим номером формули `A(v)` з однією вільною змінною `v` та числом `y` повертає Ґеделів номер формули, одержаної заміною вільної змінної `v` на нумерал `ȳ`:

```
subst(┌A(v)┐, y) = ┌A(ȳ)┐
```

У мові `L_PA` функція `subst` репрезентується відповідною формулою `SubstFunc(x, y, z)`.

## 3. Суворість та доведення Леми про нерухому точку (Діагональної леми)

Лема про нерухому точку гарантує можливість побудови самореферентного твердження у формальній мові без використання порочного кола у синтаксичних означеннях.

> **Лема про нерухому точку.** Для довільної формули `P(v)` мови `L_PA` з однією вільною змінною `v` існує замкнена формула (речення) `Ψ` така, що у теорії `PA` доводиться еквівалентність:
>
> ```
> PA ⊢ Ψ ↔ P(┌Ψ┐̄)
> ```

### Кроки формального алгебраїчного доведення:

**Крок 1.** Зафіксуємо довільну формулу `P(v)`. Розглянемо допоміжну формулу `D(x)` з однією вільною змінною `x`, яка виражає застосування предикату `P` до результату діагонального підставлення:

```
D(x) ≡ ∃z (SubstFunc(x, x, z) ∧ P(z))
```

Змістовно формула `D(x)` стверджує: «Якщо підставити число `x` як нумерал замість вільної змінної у формулу з Ґеделевим номером `x`, то для одержаного результату виконується предикат `P`».

**Крок 2.** Позначимо Ґеделів номер формули `D(x)` через натуральне число `d ∈ ℕ`:

```
d = ┌D(x)┐
```

**Крок 3.** Сформулюємо підсумкове речення `Ψ` шляхом підставлення нумералу `d̄` замість змінної `x` у формулу `D(x)`:

```
Ψ ≡ D(d̄) ≡ ∃z (SubstFunc(d̄, d̄, z) ∧ P(z))
```

**Крок 4.** Обчислимо Ґеделів номер речення `Ψ`. За означенням функції `subst`:

```
subst(d, d) = subst(┌D(x)┐, d) = ┌D(d̄)┐ = ┌Ψ┐
```

**Крок 5.** Оскільки функція `subst` є репрезентовною у `PA`, маємо довідне еквівалентне твердження для унікального результату підставлення:

```
PA ⊢ SubstFunc(d̄, d̄, z) ↔ (z = ┌Ψ┐̄)
```

**Крок 6.** Підставляємо одержану рівність у формулу `Ψ` та використовуємо правила предикатного числення:

```
Ψ ≡ ∃z (SubstFunc(d̄, d̄, z) ∧ P(z))
⇔ ∃z ((z = ┌Ψ┐̄) ∧ P(z))                [за властивістю репрезентовності]
⇔ P(┌Ψ┐̄)                                 [за аксіомами рівності]
```

Отже, у теорії `PA` виводиться синтаксична еквівалентність:

```
PA ⊢ Ψ ↔ P(┌Ψ┐̄)
```

Лема про нерухому точку повністю доведена. Вона показує, що для будь-якої властивості `P` можна побудувати речення `Ψ`, яке стверджує: «Я маю властивість P».

## 4. Формальне доведення Першої теореми Ґеделя про неповноту

Застосуємо Лему про нерухому точку до заперечення предиката довідності `P(v) ≡ ¬Prov_PA(v)`.

За лемою існує речення `G` (речення Ґеделя) таке, що у `PA` доводиться:

```
PA ⊢ G ↔ ¬Prov_PA(┌G┐̄)
```

Речення `G` стверджує: **«Формула G є недовідною у системі PA»**.

### Аналіз довідності речення G

> **Теорема (Перша теорема Ґеделя).** Якщо теорія `PA` є несуперечливою, то `PA ⊬ G`. Якщо теорія `PA` є ω-несуперечливою, то `PA ⊬ ¬G`.

#### Частина A: Доведення того, що PA ⊬ G

Припустимо від супротивного, що речення `G` є довідним у `PA`, тобто `PA ⊢ G`.

1. Якщо `PA ⊢ G`, то існує конкретне натуральне число `k ∈ ℕ`, яке є Ґеделевим номером доведення речення `G`.
2. Оскільки предикат `Prf_PA` є примітивно-рекурсивним та строго репрезентовним у `PA`, маємо довідне твердження:

```
PA ⊢ Prf_PA(┌G┐̄, k̄)
```

3. Застосовуючи квантор існування по другому аргументу, отримуємо:

```
PA ⊢ ∃y Prf_PA(┌G┐̄, y)
⇒ PA ⊢ Prov_PA(┌G┐̄)
```

4. З іншого боку, за конструкцією речення `G` маємо `PA ⊢ G ↔ ¬Prov_PA(┌G┐̄)`. Зі припущення `PA ⊢ G` за правилом Modus Ponens випливає:

```
PA ⊢ ¬Prov_PA(┌G┐̄)
```

5. Одержали, що у `PA` виводиться і `Prov_PA(┌G┐̄)`, і `¬Prov_PA(┌G┐̄)`. Отже, теорія `PA` є суперечливою.
6. Якщо `PA` несуперечлива, таке виведення неможливе. Отже, **`PA ⊬ G`**.

#### Частина B: Доведення того, що PA ⊬ ¬G (при ω-несуперечливості)

Припустимо від супротивного, що заперечення речення `G` є довідним у `PA`, тобто `PA ⊢ ¬G`.

1. З еквівалентності `G ↔ ¬Prov_PA(┌G┐̄)` випливає, що `¬G ↔ Prov_PA(┌G┐̄)`.
2. Отже, зі припущення `PA ⊢ ¬G` випливає:

```
PA ⊢ Prov_PA(┌G┐̄)  ≡  PA ⊢ ∃y Prf_PA(┌G┐̄, y)
```

3. З іншого боку, оскільки теорія `PA` є несуперечливою, з Частини A випливає, що `PA ⊬ G`.
4. Це означає, що жодне натуральне число `n ∈ ℕ` не є кодом доведення `G`.
5. Оскільки предикат `Prf_PA` строго репрезентовний, для кожного натурального числа `n ∈ ℕ` маємо:

```
PA ⊢ ¬Prf_PA(┌G┐̄, n̄)   для всіх n = 0, 1, 2, 3...
```

6. Маємо ситуацію: `PA ⊢ ∃y Prf_PA(┌G┐̄, y)`, але водночас для кожного конкретного `n ∈ ℕ` доводиться `PA ⊢ ¬Prf_PA(┌G┐̄, n̄)`.
7. Це означає за означенням, що теорія `PA` є **ω-суперечливою** (виводить існування елемента з властивістю, хоча для кожного конкретного елемента доводить відсутність цієї властивості).
8. Отже, якщо `PA` є ω-несуперечливою, то **`PA ⊬ ¬G`**.

Висновок: речення `G` є синтаксично нерозв'язним у `PA`.

## 5. Підхід Россера: підсилення до звичайної несуперечливості

У 1936 році Барклі Россер усунув потребу у вимозі ω-несуперечливості, сконструювавши модифіковане речення `R` за допомогою предикату порівняння мінімальних кодів доведень.

Визначимо предикат Россера:

```
ProvR(x) ≡ ∃y (Prf_PA(x, y) ∧ ∀z (z ≤ y → ¬Prf_PA(neg(x), z)))
```

де `neg(x)` — примітивно-рекурсивна функція заперечення формули (`neg(┌φ┐) = ┌¬φ┐`).

За лемою про нерухому точку будуємо речення Россера `R`:

```
PA ⊢ R ↔ ¬ProvR(┌R┐̄)
```

Змістовно речення `R` стверджує: «Якщо існує доведення `R`, то існує менше за кодом доведення для `¬R`».

> **Теорема Россера.** Якщо `PA` є звичайно несуперечливою (без додаткових вимог ω-несуперечливості), то `PA ⊬ R` та `PA ⊬ ¬R`.

Доведення теореми Россера будується аналізом найменшого коду доведення: якщо існує доведення `R` з кодом `y`, то у `PA` виводиться відсутність доведень `¬R` з кодами `z ≤ y`, що приводить до суперечності. Аналогічно доводиться неможливість виведення `¬R`.

## 6. Друга теорема Ґеделя та умови довідності Гільберта-Бернайса-Льоб

Формалізуємо несуперечливість `PA` як арифметичне речення:

```
Consis(PA) ≡ ¬Prov_PA(┌0 = 1┐̄)
```

Двомісний предикат довідності `Prov_PA(x)` задовольняє три **умови довідності Гільберта-Бернайса-Льоб**:

```
[HBL1]  Якщо PA ⊢ φ, то PA ⊢ Prov_PA(┌φ┐̄)
[HBL2]  PA ⊢ Prov_PA(┌φ → ψ┐̄) → (Prov_PA(┌φ┐̄) → Prov_PA(┌ψ┐̄))
[HBL3]  PA ⊢ Prov_PA(┌φ┐̄) → Prov_PA(┌Prov_PA(┌φ┐̄)┐̄)
```

### Формалізація доведення Першої теореми всередині PA

Оскільки Перша теорема Ґеделя доводиться елементарними синтаксичними маніпуляціями, її доведення можна повністю формалізувати мовою самісінької `PA`:

```
PA ⊢ Consis(PA) → ¬Prov_PA(┌G┐̄)
```

Зважаючи на те, що `PA ⊢ G ↔ ¬Prov_PA(┌G┐̄)`, маємо:

```
PA ⊢ Consis(PA) → G
```

Застосуємо предикат `Prov_PA` до обох частин цієї імпликації та використаємо умову `[HBL2]`:

```
PA ⊢ Prov_PA(┌Consis(PA)┐̄) → Prov_PA(┌G┐̄)
```

Тепер припустимо від супротивного, що теорія `PA` спроможна довести власну несуперечливість, тобто `PA ⊢ Consis(PA)`.

1. За першою умовою довідності `[HBL1]` випливає: `PA ⊢ Prov_PA(┌Consis(PA)┐̄)`.
2. За правилом Modus Ponens маємо: `PA ⊢ Prov_PA(┌G┐̄)`.
3. Але оскільки `PA ⊢ G ↔ ¬Prov_PA(┌G┐̄)`, це за еквівалентністю дає: `PA ⊢ G`.
4. Проте з Першої теореми Ґеделя відомо, що якщо `PA` є несуперечливою, то `PA ⊬ G`.
5. Одержали суперечність із несуперечливістю `PA`.

Отже, **якщо `PA` є несуперечливою формальною теорією, то `PA ⊬ Consis(PA)`**.

Це повністю завершує строге математичне доведення Другої теореми Ґеделя про неповноту.
