У 1900 році на II Міжнародному конгресі математиків у Парижі Давид Гільберт поставив перед світовою науковою спільнотою амбітне завдання: побудувати повну, несуперечливу та алгоритмічно розв'язну аксіоматичну основу для всієї математики. Математики були переконані, що кожне істинне твердження про натуральні числа можна формально вивести за допомогою скінченного ланцюжка логічних правил із невеликої множини базових аксіом. Проте спроба створити такий ідеальний механізм автоматичної верифікації наразилася на нездоланну синтаксичну перешкоду: будь-яка формальна аксіоматична система, яка містить елементарну арифметику, є або суперечливою, або принципово неповною.

Теореми Курта Ґеделя про неповноту, сформульовані у 1931 році, встановили фундаментальну межу між математичною істиною та формальною довідністю. Доведення Ґеделя показало, що поняття «істинне твердження» є строго ширшим за поняття «довідне твердження». Цей результат не лише реструктуризував математичну логіку, а й став фундаментом для теорії алгоритмів, сформувавши сучасне розуміння меж обчислювальності, верифікації програмного забезпечення та автоматичного доведення теорем.

## 1. Крах формалізму Гільберта та межі автоматичного доведення

На початку XX століття математика переживала глибоку методологічну кризу, викликану виявленням парадоксів у наївній теорії множин — зокрема парадоксу Рассела. Парадокс Рассела продемонстрував, що спроба розглядати «множину всіх множин, які не містять себе як елемент» без жорстких синтаксичних обмежень негайно призводить до прямої суперечності `A ∧ ¬A`. Прагнучи усунути будь-які парадокси та відновити абсолютну строгість науки, Давид Гільберт запропонував концепцію **формалізму**.

Ідея формалізму полягала у перетворенні всіх математичних тверджень на беззмістовні синтаксичні послідовності символів, а процес доведення — на чисто механічну маніпуляцію цими символами за наперед заданими строгими правилами виведення, абстрагуючись від їхньої семантичної інтерпретації. Гільберт прагнув звести всю математичну практику до фінітного маніпулювання скінченними синтаксичними об'єктами.

Програма Гільберта висувала три жорсткі вимоги до ідеальної аксіоматичної системи `F`:

1. **Формальна повнота (Completeness):** для будь-якої замкненої формули `φ` мови системи `F` у самій системі існує формальне виведення `F ⊢ φ` або виведення заперечення `F ⊢ ¬φ`. У такій системі не повинно залишатися «сірих зон» чи нерозв'язних питань.
2. **Формальна несуперечливість (Consistency):** у системі `F` неможливо вивести суперечність, тобто вирази `F ⊢ 0 = 1` або `F ⊢ φ ∧ ¬φ` є принципово недосяжними за правилами виведення.
3. **Алгоритмічна розв'язність (Entscheidungsproblem):** існує універсальний детермінований алгоритм, який за скінченне число кроків аналізує довільну формулу `φ` і відповідає, чи є вона довідною у `F`.

Вичерпний опис історичного контексту, дискусій між Рудольфом Карнапом, Джоном фон Нойманом та зміщення парадигми після 1931 року наведено у вставці [📜 Історія програми Гільберта та відкриття Ґеделя](book:algorithms/complexity-computability/godel-incompleteness/hist-godel-hilbert.md).

![Формалізм Гільберта проти реальності Ґеделя](/book/algorithms/complexity-computability/godel-incompleteness/img/fig1-hilbert-vs-godel.svg)
*Порівняння оптимістичної програми Давида Гільберта з фундаментальними межами формальних систем, доведеними Куртом Ґеделем у 1931 році.*

Центральний конфлікт формалізму полягав у припущенні, що синтаксична довідність `F ⊢ φ` повністю збігається з семантичною істинністю `M ⊨ φ` у стандартній модельній арифметиці `ℕ`. Гільберт припускав, що формальне доведення є лише дзеркальним відображенням істини. Проте Ґедель довів, що це припущення помилкове: жодна скінченно аксіоматизована або ефективно згенерована формальна система не здатна охопити всі арифметичні істини.

## 2. Арифметика Пеано та мова формальних теорій першого порядку

Щоб зробити міркування про неповноту математично строгими, слід чітко зафіксувати об'єкт дослідження — мову та аксіоматику формальної **арифметики Пеано (PA)** у логіці першого порядку.

Сигнатура мови `L_PA` містить такі фундаментальні елементи:

- Константу `0` (нуль).
- Унарний функціональний символ `S` (операція створення наступного натурального числа `S(x) = x + 1`).
- Бінарні функціональні символи `+` (додавання) та `·` (множення).
- Бінарний предикат рівності `=`.

Нумерал для довільного числа `n ∈ ℕ` конструюється послідовним застосуванням оператора `S` до константи `0`:

```
0̄ = 0
1̄ = S(0)
2̄ = S(S(0))
n̄ = S(S(...S(0)...))    [n разів]
```

Аксіоми `PA` включають класичні логічні аксіоми числення предикатів, аксіоми рівності, шість алгебраїчних аксіом для арифметичних операцій та нескінченну схему аксіом індукції.

### Алгебраїчні аксіоми арифметики Пеано:

```
1. ∀x ¬(S(x) = 0)                       [нуль не є наступником жодного числа]
2. ∀x ∀y (S(x) = S(y) → x = y)           [ін'єктивність оператора наступника]
3. ∀x (x + 0 = x)                       [база додавання]
4. ∀x ∀y (x + S(y) = S(x + y))           [рекурсія додавання]
5. ∀x (x · 0 = 0)                       [база множення]
6. ∀x ∀y (x · S(y) = (x · y) + x)        [рекурсія множення]
```

Додатково для довільної логічної формули `φ(v)` з вільною змінною `v` вводиться **схема аксіом індукції**:

```
[φ(0) ∧ ∀x (φ(x) → φ(S(x)))] → ∀x φ(x)
```

Оскільки схема індукції генерує окрему аксіому для кожної логічної формули `φ`, теорія `PA` має нескінченну, але **ефективно перелічувану** множину аксіом. Це означає, що існує алгоритм, який за скінченний час перевіряє, чи є довільний рядок символів аксіомою `PA`.

Зауважимо фундаментальну різницю між двома поняттями, які у класичній математиці часто вважалися тотожними:

- **Синтаксична довідність (`PA ⊢ φ`):** існування скінченної послідовності формул `φ₁, φ₂, ..., φ⡭ = φ`, де кожна формула є або аксіомою `PA`, або одержана з попередніх за правилом Modus Ponens (`A` та `A → B` ⊢ `B`).
- **Семантична істинність (`ℕ ⊨ φ`):** формула `φ` є істинною у стандартній моделі натуральних чисел `ℕ = {0, 1, 2, 3, ...}` зі звичайним додаванням та множенням.

Система `PA` є **несуперечливою (Consistent)**, якщо не існує такої формули `φ`, для якої одночасно `PA ⊢ φ` та `PA ⊢ ¬φ`. Система є **синтаксично повною (Syntactically Complete)**, якщо для будь-якої замкненої формули `φ` виконується `PA ⊢ φ` або `PA ⊢ ¬φ`.

### Нестандартні моделі арифметики та теорема Сколема

Важливим аспектом логіки першого порядку є існування **нестандартних моделей**. За [теоремою Сколема](book:math/skolem-paradox) про пониження потужності (а також за теоремою про компактність), арифметика Пеано першого порядку має моделі `M`, які не є ізоморфними стандартному ряду `ℕ`.

У нестандартній моделі `M` існують «нескінченно великі цілі числа» `ω`, які є більшими за будь-яке стандартне натуральне число `n̄`. При цьому самі аксіоми `PA` виконуються у `M` безумовно. Неповнота Ґеделя демонструє, що аксіоми першого порядку не спроможні унікально зафіксувати лише стандартну модель `ℕ`: завжди існують речення, які істинні у `ℕ`, але хибні у деяких нестандартних моделях `M`.

## 3. Арифметизація синтаксису: Кодування Ґеделя

Головний методологічний прорив, розроблений Ґеделем, полягає у **арифметизації синтаксису**. До Ґеделя метаматематика вважалася зовнішньою дисципліною, яка описує формули «згори». Ґедель показав, що синтаксичні об'єкти (символи, терми, формули, послідовності виведення) можна безвтратно перетворити на натуральні числа, а відношення між ними — на звичайні арифметичні операції усередині самісінької теорії.

Кожному базовому синтаксичному символу мови `L_PA` призначається унікальне непарне натуральне число:

```
'0' → 1,   'S' → 3,   '+' → 5,   '·' → 7,   '=' → 9,   '¬' → 11,   '→' → 13,   '∀' → 15,   '(' → 17,   ')' → 19
```

Змінним `v₁, v₂, v₃, ...` призначаються парні числа `2, 4, 6, ...`.

Довільна послідовність символів `s = (s₁, s₂, ..., s⡭)` кодується в унікальне натуральне число `┌s┐` — **Ґеделів номер** — за допомогою степеневого добутку послідовних простих чисел:

```
┌s┐ = 2ˢ¹ · 3ˢ² · 5ˢ³ · ... · p⡭ˢᵏ
```

де `pᵢ` — `i`-те просте число (`p₁ = 2, p₂ = 3, p₃ = 5, p₄ = 7, p₅ = 11...`).

![Схема арифметизації синтаксису Ґеделя](/book/algorithms/complexity-computability/godel-incompleteness/img/fig2-godel-numbering.svg)
*Процес перетворення логічних символів, формул та послідовностей доведення у унікальні натуральні числа Ґеделя через піднесення простих чисел до степенів.*

Завдяки Основній теоремі арифметики про унікальність розкладу будь-якого натурального числа на прості множники, за Ґеделевим номером `g = ┌s┐` можна алгоритмічно відновлювати вихідну послідовність токенів `s`. Показник степеня при першому простому числі `2` дає код першого символу, при `3` — другого, і так далі до досягнення частки 1.

Для кодування довільних скінченних послідовностей натуральних чисел без використання простих множників Ґедель також створив **β-функцію Ґеделя**, яка базується на Китайській теоремі про залишки і дозволяє представляти довші масиви за допомогою лише двох фіксованих чисел `a` та `b`:

```
β(a, b, i) = a mod (1 + (i + 1)b)
```

Це довело, що будь-який обчислювальний процес та рекурсивне кодування можна виразити виключно через арифметичні операції додавання та множення над цілими числами.

Доведення у системі `PA` являє собою скінченну послідовність формул `(F₁, F₂, ..., F⡭)`. Його Ґеделів номер `π` кодується аналогічним чином через Ґеделеві номери окремих формул:

```
π = ┌(F₁, F₂, ..., F⡭)┐ = 2^{┌F₁┐} · 3^{┌F₂┐} · ... · p⡭^{┌F☘┐}
```

Таким чином, складне метаматематичне твердження «послідовність `π` є доведенням формули `φ` у системі `PA`» перетворюється на звичайне арифметичне відношення між натуральними числами `ProofPA(┌φ┐, π)`.

## 4. Примітивно-рекурсивні предикати та репрезентовність довідності

Арифметизація синтаксису була б лише декоративним кодуванням, якби відношення між Ґеделевими номерами не можна було обчислювати у самій арифметиці Пеано. Ґедель довів, що предикат перевірки доведення є **примітивно-рекурсивним**.

Класична теорія алгоритмів визначає примітивно-рекурсивні функції як клас обчислювальних операцій, які будуються з базових функцій (нуль `Z(x) = 0`, наступник `S(x) = x + 1`, вибір аргументу `Iₙᵏ(x₁, ..., xₙ) = xₖ`) за допомогою операцій операторної підстановки та примітивної рекурсії. Примітивно-рекурсивні функції завжди є тотально визначеними та обчислюваними за гарантований скінченний час без зациклень.

### Теорема про репрезентовність

Усі примітивно-рекурсивні предикати є **репрезентовними (зображуваними)** в арифметиці Пеано. Це означає, що існує формула мови `L_PA` `Prf_PA(x, y)` з двома вільними змінними `x` та `y` така, що для будь-яких конкретних чисел `n, m ∈ ℕ`:

```
Якщо m є кодом доведення формули з кодом n  ⇒  PA ⊢ Prf_PA(n̄, m̄)
Якщо m не є кодом доведення формули з кодом n ⇒ PA ⊢ ¬Prf_PA(n̄, m̄)
```

Зауважимо важливу властивість: перевірка `Prf_PA(n̄, m̄)` є чисто локальною та механічною. Для будь-якої конкретної пари чисел `(n, m)` теорія `PA` за скінченне число символьних кроків виводить або `Prf_PA(n̄, m̄)`, або `¬Prf_PA(n̄, m̄)`.

Визначимо загальний предикат довідності `Prov_PA(x)` через застосування квантора існування по коду доведення:

```
Prov_PA(x) ≡ ∃y Prf_PA(x, y)
```

Предикат `Prov_PA(x)` стверджує: «Існує таке число `y`, яке є Ґеделевим номером доведення формули з Ґеделевим номером `x`». На відміну від `Prf_PA`, предикат `Prov_PA` вже не є примітивно-рекурсивним; він описує рекурсивно перелічувану множину номерів довідних формул і є алгоритмічно нерозв'язним у загальному випадку.

Також існує примітивно-рекурсивна функція діагонального підставлення `subst(x, y)`, яка за Ґеделевим номером формули `A(v)` з вільною змінною `v` та числом `y` повертає Ґеделів номер формули `A(ȳ)`:

```
subst(┌A(v)┐, y) = ┌A(ȳ)┐
```

У мові `L_PA` функція `subst` репрезентується відповідною формулою `SubstFunc(x, y, z)`.

Технічну специфікацію структур даних, сигнатур функцій кодування/декодування та верифікатора доведень наведено у вставці [📋 Інтерфейс та специфікація модулів системи формальної верифікації](book:algorithms/complexity-computability/godel-incompleteness/api-proof-checker.md).

## 5. Лема про нерухому точку (Діагоналізація Ґеделя)

Для формулювання парадоксального речення Ґеделю знадобився механізм самореференції. У звичайній мові самореференція створюється займенниками (*«Це твердження...»*). У формальній мові `L_PA` пряма самореференція заборонена синтаксисом: формула не може містити власний Ґеделів номер усередині себе як узагальнений терм, оскільки це призвело б до нескінченної рекурсії при обчисленні номера (`┌φ(┌φ┐)┐ > ┌φ┐`).

Ґедель обійшов це обмеження за допомогою **Леми про нерухому точку (Діагональної леми)**.

> **Лема про нерухому точку.** Для довільної формули `P(v)` мови `L_PA` з однією вільною змінною `v` існує замкнена формула (речення) `Ψ` така, що в арифметиці Пеано доводиться синтаксична еквівалентність:
>
> ```
> PA ⊢ Ψ ↔ P(┌Ψ┐̄)
> ```

![Схема діагоналізації та лема про нерухому точку](/book/algorithms/complexity-computability/godel-incompleteness/img/fig3-diagonalization-fixedpoint.svg)
*Конструкція леми про нерухому точку: побудова самореферентного речення G через діагональне підставлення власного Ґеделевого номера.*

Схема побудови нерухомої точки спирається на функцію підставлення `subst`:

1. Беремо вхідний предикат `P(v)`.
2. Конструюємо допоміжну формулу `D(x) ≡ ∃z (SubstFunc(x, x, z) ∧ P(z))`. Формула `D(x)` стверджує: «Якщо підставити номер формули `x` у саму формулу `x`, то для одержаного результату виконується предикат `P`».
3. Фіксуємо Ґеделів номер цієї допоміжної формули: `d = ┌D(x)┐`.
4. Будуємо шукане речення `Ψ` шляхом підставлення нумерала `d̄` у формулу `D(x)`: `Ψ ≡ D(d̄) ≡ ∃z (SubstFunc(d̄, d̄, z) ∧ P(z))`.

Оскільки `subst(d, d) = ┌D(d̄)┐ = ┌Ψ┐`, маємо `PA ⊢ SubstFunc(d̄, d̄, z) ↔ (z = ┌Ψ┐̄)`. Підставляючи цю еквівалентність у формулу `Ψ`, отримуємо `PA ⊢ Ψ ↔ P(┌Ψ┐̄)`.

Таким чином, формула `Ψ` стверджує: «Формула, одержана діагоналізацією `d`, має властивість `P`», що є синтаксично еквівалентним `P(┌Ψ┐̄)`.

Повне строге алгебраїчне виведення Діагональної леми, першої та другої теорем наведено у вставці [🧮 Математичне доведення теорем Ґеделя та леми про нерухому точку](book:algorithms/complexity-computability/godel-incompleteness/math-diagonalization-proof.md).

## 6. Перша теорема Ґеделя про неповноту

Застосуємо Лему про нерухому точку до заперечення предикату довідності `P(v) ≡ ¬Prov_PA(v)`.

За лемою існує речення `G` (речення Ґеделя) таке, що у `PA` виводиться:

```
PA ⊢ G ↔ ¬Prov_PA(┌G┐̄)
```

Змістовно речення `G` стверджує: **«Це речення не має формального доведення у системі PA»**.

> **Перша теорема Ґеделя про неповноту.** Якщо арифметика Пеано `PA` є несуперечливою, то `PA ⊬ G`. Якщо `PA` є ω-несуперечливою, то `PA ⊬ ¬G`. Таким чином, речення `G` є синтаксично нерозв'язним у `PA`.

Доведемо теорему від супротивного у два кроки.

### Крок 1: Доведення того, що PA ⊬ G

Припустимо, що `PA ⊢ G` (тобто речення `G` є довідним у `PA`).

1. Якщо `PA ⊢ G`, то існує конкретне натуральне число `k ∈ ℕ`, яке є Ґеделевим номером доведення речення `G`.
2. Оскільки предикат `Prf_PA` є примітивно-рекурсивним та строго репрезентовним, маємо: `PA ⊢ Prf_PA(┌G┐̄, k̄)`.
3. Застосовуючи квантор існування по другому аргументу, отримуємо: `PA ⊢ ∃y Prf_PA(┌G┐̄, y)`, що за означенням означає `PA ⊢ Prov_PA(┌G┐̄)`.
4. З іншого боку, за конструкцією речення `G` маємо `PA ⊢ G ↔ ¬Prov_PA(┌G┐̄)`. Зі припущення `PA ⊢ G` випливає: `PA ⊢ ¬Prov_PA(┌G┐̄)`.
5. Одержали, що у `PA` одночасно доводяться `Prov_PA(┌G┐̄)` та `¬Prov_PA(┌G┐̄)`. Це означає, що система `PA` є суперечливою.
6. Отже, якщо `PA` несуперечлива, то **`PA ⊬ G`**.

### Крок 2: Доведення того, що PA ⊬ ¬G

Припустимо, що `PA ⊢ ¬G` (тобто заперечення `G` є довідним у `PA`).

1. З еквівалентності `G ↔ ¬Prov_PA(┌G┐̄)` випливає: `PA ⊢ Prov_PA(┌G┐̄)`, тобто `PA ⊢ ∃y Prf_PA(┌G┐̄, y)`.
2. З іншого боку, оскільки `PA` несуперечлива, з Кроку 1 відомо, що `PA ⊬ G`. Це означає, що жодне натуральне число `n ∈ ℕ` не є кодом доведення `G`.
3. За репрезентовністю предикату `Prf_PA`, для кожного конкретного `n ∈ ℕ` виконується: `PA ⊢ ¬Prf_PA(┌G┐̄, n̄)`.
4. Маємо ситуацію: система `PA` виводить існування коду доведення `∃y Prf_PA(┌G┐̄, y)`, але для кожного конкретного числа `n` виводить, що `n` не є кодом доведення.
5. Така властивість називається **ω-суперечливістю**. Якщо `PA` є ω-несуперечливою, то **`PA ⊬ ¬G`**.

### Посилення Барклі Россера (1936)

Умова ω-несуперечливості виглядала дещо штучною, оскільки вона вимагала відсутність суперечностей не лише у скінченних виведеннях, а й у нескінченній сімейці цілих чисел. У 1936 році Барклі Россер модифікував конструкцію речення, використавши порівняння мінімальних кодів доведеннь твердження та його заперечення:

```
R ≡ «Для кожного доведення R існує менше за кодом доведення ¬R»
```

Предикат Россера `ProvR(x)` враховує порядок пошуку доведень: якщо знайдено доведення `R` з кодом `y`, то у `PA` доводиться відсутність доведень `¬R` з кодами `z ≤ y`.

Теорема Россера довела, що для недоводжуваності `R` та `¬R` достатньо лише **звичайної несуперечливості** теорії `PA`.

### Семантичний наслідок

Оскільки `PA ⊬ G`, речення `G` справді не має доведення у `PA`. Але саме це й стверджує речення `G`! Отже, речення `G` є **істинним у стандартній моделі натуральних чисел `ℕ`**, але недоводжуваним формальними засобами `PA`.

Це доводить існування принципової прірви між істиною (`ℕ ⊨ G`) та формальним виведенням (`PA ⊬ G`).

## 7. Друга теорема Ґеделя про неповноту: Сумісність неможливо довести зсередини

Перша теорема Ґеделя показує недосяжність повноти. Друга теорема завдає ще нищівнішого удару по програмі Гільберта, доводячи неможливість внутрішнього доведення несуперечливості.

Формалізуємо несуперечливість системи `PA` як логічне речення:

```
Consis(PA) ≡ ¬Prov_PA(┌0 = 1┐̄)
```

Речення `Consis(PA)` стверджує: «У системі `PA` не існує доведення для хибної рівності `0 = 1`».

> **Друга теорема Ґеделя про неповноту.** Якщо арифметика Пеано `PA` є несуперечливою, то її несуперечливість `Consis(PA)` не може бути доведена засобами самісінької системи `PA`:
>
> ```
> PA ⊬ Consis(PA)
> ```

Доведення спирається на формалізацію Першої теореми Ґеделя усередині самісінької системи `PA`.

Предикат довідності `Prov_PA(x)` задовольняє три **умови довідності Гільберта-Бернайса-Льоб**:

```
[HBL1]  Якщо PA ⊢ φ, то PA ⊢ Prov_PA(┌φ┐̄)
[HBL2]  PA ⊢ Prov_PA(┌φ → ψ┐̄) → (Prov_PA(┌φ┐̄) → Prov_PA(┌ψ┐̄))
[HBL3]  PA ⊢ Prov_PA(┌φ┐̄) → Prov_PA(┌Prov_PA(┌φ┐̄)┐̄)
```

Оскільки міркування Першої теореми Ґеделя («якщо `PA` несуперечлива, то `G` недоводжуване») будуються чисто синтаксичними кроками, цей імпликативний ланцюжок можна повністю вивести усередині `PA`:

```
PA ⊢ Consis(PA) → ¬Prov_PA(┌G┐̄)
```

Зважаючи на те, що `PA ⊢ G ↔ ¬Prov_PA(┌G┐̄)`, маємо:

```
PA ⊢ Consis(PA) → G
```

Застосуємо предикат `Prov_PA` до обох частин цієї імпликації та використаємо умову `[HBL2]`:

```
PA ⊢ Prov_PA(┌Consis(PA)┐̄) → Prov_PA(┌G┐̄)
```

Тепер припустимо від супротивного, що `PA` спроможна довести власну несуперечливість, тобто `PA ⊢ Consis(PA)`.

1. За першою умовою довідності `[HBL1]` випливає: `PA ⊢ Prov_PA(┌Consis(PA)┐̄)`.
2. За правилом Modus Ponens маємо: `PA ⊢ Prov_PA(┌G┐̄)`.
3. Але оскільки `PA ⊢ G ↔ ¬Prov_PA(┌G┐̄)`, це за еквівалентністю дає: `PA ⊢ G`.
4. Проте з Першої теореми Ґеделя відомо, що якщо `PA` несуперечлива, то `PA ⊬ G`. Одержали суперечність.

Отже, **якщо `PA` є несуперечливою, то `PA ⊬ Consis(PA)`**.

Узагальненням цього результату є **Теорема Льоб (Löb's Theorem)** 1955 року, яка стверджує: для будь-якої формули `φ`, якщо `PA ⊢ Prov_PA(┌φ┐̄) → φ`, то обов'язково `PA ⊢ φ`.

Для доведення несуперечливості системи `F` неодмінно потрібна сильніша формальна система `F'`, яка володіє виражальними засобами, недоступними для `F`. Наприклад, Гергард Ґенцен у 1936 році довів несуперечливість `PA`, проте для цього довелося вийти за межі першого порядку і застосувати принцип транссфінітної індукції до ординала `ε₀`. Також пізніші комбінаторні твердження — такі як [теорема Паріса — Гаррінгтона](book:algorithms/paris-harrington-theorem) та **теорема Гудстейна** — є прикладами природних комбінаторних істин про цілі числа, які є істинними у `ℕ`, проте принципово недоводжуваними в арифметиці Пеано.

## 8. Алгоритмічний еквівалент: Зв'язок із Тюрингом, Россером та складністю обчислень

Теореми Ґеделя мають прямий еквівалент у теорії алгоритмів та обчислювальної складності. У 1936 році Алан Тюринг довів алгоритмічну нерозв'язність **Проблеми зупинки (Halting Problem)**.

Паралель між логікою Ґеделя та обчисленнями Тюринга є математично точною:

- **Логіка Ґеделя:** не існує повної формальної системи для арифметики.
- **Обчислення Тюринга:** не існує алгоритму, який визначає зупинку довільної програми.

![Зв'язок теореми Ґеделя з проблемами зупинки Тюринга та складністю](/book/algorithms/complexity-computability/godel-incompleteness/img/fig4-incompleteness-halting-bridge.svg)
*Еквівалентність між неприводимістю Ґеделівських тверджень, нерозв'язністю проблеми зупинки Тюринга та інформаційними межами Колмогорова.*

### Еквівалентне доведення Ґеделя через Проблему зупинки

Припустимо від супротивного, що існує формальна система `F`, яка є одночасно повною та несуперечливою. Побудуємо на її основі алгоритм для розв'язання проблеми зупинки машини Тюринга `M` на вході `w`:

1. Запускаємо паралельний перебір усіх можливих доведень у системі `F` у порядку збільшення їхніх Ґеделевих номерів.
2. Для кожного доведення перевіряємо, чи виводить воно твердження `T₁ ≡ «Машина M(w) зупиняється»` або `T₂ ≡ «Машина M(w) не зупиняється»`.
3. Оскільки система `F` є повною, одне з двох доведень обов'язково буде знайдене за скінченний час.
4. Оскільки система `F` є несуперечливою, знайдене доведення буде гарантовано істинним.

Такий перебір давав би алгоритм розв'язання проблеми зупинки. Але за теоремою Тюринга проблему зупинки алгоритмічно розв'язати неможливо. Отже, припущення про існування повної та несуперечливої системи `F` є хибним.

### Інформаційна неповнота за Чейтіном та Константа Ω

Грегорі Чейтін сформулював теорему про неповноту мовою [складності за Колмогоровим](book:algorithms/kolmogorov-complexity) та ввів поняття константи Чейтіна `Ω` (ймовірність зупинки випадкової машини Тюринга).

[Складність за Колмогоровим](book:algorithms/kolmogorov-complexity) `K(x)` рядка `x` — це довжина найкоротшої програми, яка генерує рядок `x`. Рядок `x` називається випадковим (несжимаємим), якщо `K(x) ≥ |x|`.

> **Теорема Чейтіна про неповноту.** Спеціалізована формальна система `F`, опис якої (аксіоми та правила) складається з `L` бітів інформації, не спроможна довести, що складність конкретного рядка `x` перевищує `L + c` (де `c` — константа):
>
> ```
> F ⊬ «K(x) > L + c»
> ```

Число `Ω` є реальним числом між 0 та 1, біти якого є алгоритмічно випадковими та повністю необчислюваними. Доведення значень перших `k` бітів числа `Ω` вимагає формальної системи, аксіоми якої містять щонайменше `k` бітів інформації.

Це показує, що неповнота є результатом інформаційного обмеження потужності аксіом: система не може згенерувати більше інформації, ніж закодовано у самісіньких її аксіомах.

Практичну програмну реалізацію кодування Ґеделя та верифікації наведено у вставці [⚙️ Реалізація нумерації Ґеделя та автоматична перевірка формальних доведень](book:algorithms/complexity-computability/godel-incompleteness/proj-godel-numbering-evaluator.md).

> 🔧 **Навіщо це.**
>
> Теореми Ґеделя про неповноту виявилися не абстрактною філософською конструкцією, а фундаментальним практичним інваріантом комп'ютерних наук та системної розробки:
>
> 1. **Межі статичного аналізу та тайпчекінгу:** системи типів у мовах програмування з залежними типами (Coq, Agda, Lean, Idris) або розширеними шаблонами (C++ constexpr / Rust trait solver) являють собою формальні логічні системи за [ізоморфізмом Каррі — Говарда](book:math/curry-howard-isomorphism) (програма = доведення, тип = формула). Неповнота означає, що жоден компілятор не спроможний автоматично перевірити всі довільні інваріанти програми за скінченний час без допомоги людино-машинних підказок чи ризику зациклення.
> 2. **Захист від вірусів та верифікація безпеки:** не існує ідеального статичного аналізатора коду або антивірусу, який би зі 100% точністю визначав, чи містить програма шкідливу поведінку або витік пам'яті (наслідок неповноти та [теореми Райса](book:math/rice-theorem)).
> 3. **Автоматичні доводчики теорем (SMT Solvers):** сучасні системи автоматичного виведення (наприклад, Z3, CVC5) свідомо обмежують вхідні логічні fragments до вирішуваних теорій (арифметика Пресбургера без множення, теорія бітових векторів, теорія рогівських диз'юнктів), оскільки повноцінна першопорядкова арифметика Пеано з множенням є алгоритмічно нерозв'язною.
> 4. **Формальні специфікації критичного ПЗ:** при верифікації ядер ОС (seL4) або авіаційного коду розробники знають, що автоматичні інструменти виведення покривають лише обмежені класи властивостей, а фундаментальна коректність вимагає побудови індуктивних інваріантів вручну.

## 10. Синтез та висновки

Теореми Курта Ґеделя про неповноту перекреслили наївні сподівання на побудову єдиного закритого аксіоматичного механізму, здатного автоматично згенерувати всі математичні істини. Вони довели, що математичне знання є принципово відкритим: додавання будь-якої недоводжуваної істинної формули `G` як нової аксіоми створює сильнішу систему `PA' = PA ∪ {G}`, у якій негайно виникає власне нове недоводжуване речення Ґеделя `G'`.

У комп'ютерних науках Ґеделева нумерація та діагоналізація стали прототипом для універсального кодування даних, створення інтерпретаторів, компіляторів та визначення меж алгоритмічної обчислюваності. Неповнота визначає межі інструментальної автоматизації, нагадуючи, що верифікація та проектирування складних обчислювальних систем завжди вимагатимуть людської інтуїції, вибору належних абстракцій та створення нових формальних моделей.
