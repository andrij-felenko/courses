# 🧮 Математична складність та алгоритми елімінації кванторів Пресбургера

Арифметика Пресбургера є формальною теорією першого порядку для цілих (або натуральних) чисел з операцією додавання та відношенням порядку, але без множення змінних між собою. Цей математичний апарат становить теоретичний фундамент для сучасних SMT-сольверів у фрагментах `LIA` (Linear Integer Arithmetic) та `QF_LIA` (Quantifier-Free LIA).

## 1. Формальний синтаксис та розширена сигнатура

Класична мова арифметики Пресбургера визначається у сигнатурі першого порядку:

```
Σ_Pres = ⟨ 0, 1, +, -, ≤, = ⟩
```

де `0` та `1` — константні символи, `+` та `-` — бінарні функціональні символи додавання та віднімання, а `≤` та `=` — бінарні предикатні символи порядку та рівності. Множення на константне ціле число `c ∈ Z` розглядається як скорочений запис багаторазового додавання:

```
c · x = x + x + ... + x    [c разів для c > 0]
```

Для забезпечення синтаксичної замкненості щодо елімінації кванторів сигнатуру `Σ_Pres` розширюють зліченним сімейством унарних предикатів подільності (конгруенцій) для кожного фіксованого цілого модуля `d ∈ Z_{>0}`:

```
d | t  ⟺  ∃k ∈ Z. (t = d · k)
```

Заперечення подільності позначається як `d ∤ t` або `¬(d | t)`. Розширена сигнатура `Σ_Pres^* = Σ_Pres ∪ { d | · }_{d \ge 2}` має фундаментальну властивість: будь-яка формула з кванторами у сигнатурі `Σ_Pres^*` алгоритмічно зводиться до еквівалентної формули без кванторів у тій самій сигнатурі.

## 2. Алгоритм елімінації кванторів Купера

Алгоритм Дерека Купера (1972) виконує елімінацію квантора існування для формул вигляду `∃x. F(x)`, де `F(x)` є безкванторною формулою. Оскільки квантор загальності виражається через квантор існування як `∀x. F(x) ≡ ¬(∃x. ¬F(x))`, процедури усунення `∃` достатньо для повної кванторної елімінації довільної глибини.

Процедура складається з п'яти послідовних математичних кроків:

### Крок 1. Зведення до нормальної форми заперечень (NNF)

Усі логічні зв'язки зводяться до кон'юнкцій `∧`, диз'юнкцій `∨` та заперечень `¬`, причому заперечення опускаються безпосередньо до атомарних предикатів за законами де Моргана. Заперечення нерівностей та рівностей перетворюються за правилами:

```
¬(s ≤ t)      ⟺  t + 1 ≤ s
¬(s = t)      ⟺  (s + 1 ≤ t) ∨ (t + 1 ≤ s)
s = t         ⟺  (s ≤ t) ∧ (t ≤ s)
¬(d | t)      ⟺  d ∤ t
¬(d ∤ t)      ⟺  d | t
```

У результаті формула `F(x)` містить змінну `x` лише в атомах чотирьох типів:
1. Нижні межі: `a ≤ c · x`
2. Верхні межі: `c · x ≤ b`
3. Конгруенції подільності: `d | (c · x + t)`
4. Конгруенції неподільності: `d ∤ (c · x + t)`

де `c ∈ Z_{>0}`, а терми `a, b, t` не містять змінної `x`.

### Крок 2. Уніфікація коефіцієнтів (Масштабування)

Нехай коефіцієнти при змінній `x` в атомах формули дорівнюють `c₁, c₂, ..., c_k`. Обчислюється їхнє найменше спільне кратне:

```
m = НСК(c₁, c₂, ..., c_k)
```

Кожен атом домножується на відповідний цілий множник `m / c_i`, що дозволяє замінити входження `c_i · x` на спільний вираз `m · x`. Далі виконується заміна змінної: вводиться нова змінна `x' = m · x` разом із додаванням обов'язкової умови подільності `m | x'`:

```
∃x. F(c₁·x, ..., c_k·x)  ⟺  ∃x'. ( F(x', ..., x') ∧ (m | x') )
```

Після цієї трансформації в усіх атомах формули коефіцієнт при квантифікованій змінній строго дорівнює `1`. Перепозначимо `x'` назад як `x`.

### Крок 3. Виділення періоду конгруенцій

Формула `F(x)` розбивається на атоми нерівностей та атоми подільності. Нехай модулі конгруенцій у формулі дорівнюють `d₁, d₂, ..., d_p`. Обчислюється фундаментальний період ґратки:

```
δ = НСК(d₁, d₂, ..., d_p)
```

Якщо до змінної `x` додати будь-яке число, кратне `δ`, значення всіх конгруентних предикатів `d_i | (x + t)` та `d_i ∤ (x + t)` залишаються абсолютно незмінними.

### Крок 4. Побудова множини тестових точок Купера

Нехай множина всіх нижніх меж для `x` у формулі має вигляд:

```
B = { b₁ + 1, b₂ + 1, ..., b_r + 1 }    [для нерівностей вигляду b_i < x, тобто b_i + 1 ≤ x]
```

Розглядається гранична поведінка формули при `x → -∞`. Позначимо як `F_{-∞}` формулу, отриману з `F(x)` заміною всіх нижніх меж `b_i + 1 ≤ x` на хибу `0`, а всіх верхніх меж `x ≤ a_i` на істину `1`. Атоми подільності залишаються без змін, оскільки вони періодичні.

Теорема Купера стверджує: якщо існує цілочисельний розв'язок `x ∈ Z`, такий що `F(x) = 1`, то існує розв'язок або у довільно віддаленій від'ємній області з періодом `δ`, або на відстані не більше `δ` кроків праворуч від однієї з нижніх меж `b ∈ B`.

Формальна еквівалентність записується як скінченна диз'юнкція:

```
∃x. F(x)  ⟺  ( ∨_{j=1}^δ F_{-∞}(j) )  ∨  ( ∨_{b ∈ B} ∨_{j=1}^δ F(b + j) )
```

### Доведення коректності розбиття на тестові точки

Доведемо теорему Купера:
1. **Імплікація справа наліво (`⇐`):** Будь-яка точка `x = b + j` або точка `x = j - k · δ` (для достатньо великого `k`), що задовольняє диз'юнкцію, є конкретним цілим числом, на якому `F(x) = 1`. Отже, `∃x. F(x)` істинне.
2. **Імплікація зліва направо (`⇒`):** Нехай існує `x₀ ∈ Z`, для якого `F(x₀) = 1`.
   - Випадок А: `x₀` менше за всі нижні межі у множині `B` (тобто для всіх `b ∈ B` виконується `x₀ < b`). Тоді всі нижні межі в `F(x₀)` хибні. Оскільки атоми подільності `δ`-періодичні, значення `F(x₀)` збігається зі значенням `F_{-∞}(j)`, де `j ≡ x₀ (mod δ)` та `1 ≤ j ≤ δ`. Отже, істинною є перша частина диз'юнкції `∨_{j=1}^δ F_{-∞}(j)`.
   - Випадок Б: `x₀` не менше за деяку нижню межу. Нехай `b* ∈ B` — найбільша нижня межа, для якої `b* ≤ x₀`. Тоді між `b*` та `x₀` немає жодної іншої нижньої межі. Віднімемо від `x₀` кратне періоду `k · δ` так, щоб потрапити в інтервал `b* < x₀ - k · δ ≤ b* + δ`. Оскільки при цьому ми не перетнули жодної нижньої межі (бо `b*` була найближчою зліва) і не збільшили значення (верхні межі не порушилися), а конгруенції інваріантні щодо додавання `k · δ`, точка `x' = b* + j` (де `j = x₀ - k·δ - b* ∈ {1, ..., δ}`) також задовольняє `F(x') = 1`. Отже, істинною є друга частина диз'юнкції.

### Крок 5. Числовий приклад елімінації

Розглянемо кванторну формулу:

```
∃x. ( (2 ≤ x) ∧ (x ≤ 5) ∧ (3 | (x + 1)) )
```

Виконуємо елімінацію за кроками:
1. Коефіцієнт при `x` скрізь дорівнює `1`, тому масштабування не потрібне (`m = 1`).
2. Модуль подільності один: `d₁ = 3`, тому період `δ = 3`.
3. Множина нижніх меж: нерівність `2 ≤ x` дає `b₁ = 2`, отже `B = { 2 }`.
4. Тестові точки від нижньої межі: `b₁ + j` для `j ∈ {0, 1, 2}`: точки `{ 2, 3, 4 }` (або `b + j` для `j ∈ {1, 2, 3}` від `b = 1`: точки `{ 2, 3, 4 }`).
5. Формула `F_{-∞}` містить атом `(2 ≤ -∞)`, що перетворюється на хибу `0`, тому ліва гілка `∨_{j=1}^3 F_{-∞}(j) = 0`.
6. Підставляємо кандидатів:
   - При `x = 2`: `(2 ≤ 2) ∧ (2 ≤ 5) ∧ (3 | 3) = 1 ∧ 1 ∧ 1 = 1` (Істина).
   - При `x = 3`: `(2 ≤ 3) ∧ (3 ≤ 5) ∧ (3 | 4) = 1 ∧ 1 ∧ 0 = 0` (Хиба).
   - При `x = 4`: `(2 ≤ 4) ∧ (4 ≤ 5) ∧ (3 | 5) = 1 ∧ 1 ∧ 0 = 0` (Хиба).

Формула спрощується до безкванторної константи `1` (формула здійсненна, розв'язком є `x = 2`).

## 3. Математика Омега-тесту та проекційні тіні

Омега-тест Вільяма П'ю (1991) є цілочисельним розширенням неперервного методу елімінації Фур'є — Моцкіна. Нехай задано пару нерівностей, що обмежують змінну `x` знизу та зверху:

```
L ≤ a · x
b · x ≤ U
```

де `a, b ∈ Z_{>0}`, а `L, U` — лінійні вирази від решти змінних `y = (x₂, ..., x_n)`.

### Дійсна тінь (Real Shadow)

У неперервному випадку над `R` змінна `x` існує тоді й лише тоді, коли нижня межа не перевищує верхню після домноження на коефіцієнти:

```
b · L ≤ a · b · x ≤ a · U   ⟹   b · L ≤ a · U
```

Нерівність `b · L ≤ a · U` утворює **дійсну тінь (Real Shadow)**. Якщо дійсна тінь не містить жодного дійсного розв'язку, то цілочисельний розв'язок також гарантовано відсутній (формула `UNSAT`).

### Темна тінь (Dark Shadow)

Для існування цілого числа `x ∈ Z` у неперервному інтервалі `[L/a, U/b]` довжина інтервалу має бути достатньою, щоб гарантувати наявність хоча б одного цілого числа. Відстань між кінцями інтервалу становить:

```
U/b - L/a = (a · U - b · L) / (a · b)
```

Ціле число гарантовано існує в інтервалі, якщо його довжина строго більша за `(a - 1)/a + (b - 1)/b = 1 - 1/(a·b)`, що після домноження на `a · b` дає нерівність:

```
a · U - b · L ≥ (a - 1) · (b - 1) + 1   ⟺   a · U - b · L ≥ a · b - a - b + 2
```

Це співвідношення визначає **темну тінь (Dark Shadow)**. Якщо проекція вектора `y` потрапляє в темну тінь, існування цілого `x ∈ Z` гарантоване на 100% (формула `SAT`), і подальший перебір не потрібен.

### Сіра тінь (Gray Shadow)

Область між дійсною та темною тінями називається **сірою тінню (Gray Shadow)**:

```
b · L ≤ a · U ≤ b · L + (a - 1) · (b - 1)
```

У сірій тіні неперервний розв'язок існує, але цілий розв'язок може як бути, так і не бути. Для точок сірої тіні Омега-тест розгалужується на скінченну кількість точних цілочисельних перевірок для кожного можливого залишку:

```
a · x = L + i,    де 0 ≤ i ≤ (a · b - a - b) / a
```

## 4. Нижня часова межа Фішера — Рабіна

Для повної кванторної арифметики Пресбургера фундаментальну теорему про нижню межу складності довели Майкл Фішер та Майкл Рабін (1974).

**Теорема Фішера — Рабіна:**
Будь-яка детермінована машина Тюрінга, яка перевіряє істинність формули арифметики Пресбургера довжини `n`, у найгіршому випадку вимагає часу:

```
T(n) ≥ 2^( 2^(c · n) )
```

для деякої додатної універсальної константи `c > 0`.

### Ідея математичного доведення

Нижня оцінка базується на ефективному кодуванні обчислень детермінованої машини Тюрінга, яка працює за час `2^(2^k)`.

1. **Кодування великих чисел.** Формула без множення не може безпосередньо виразити `y = 2^x`. Проте за допомогою кванторів можна побудувати предикат `P_k(x, y)`, який стверджує, що `y = 2^(2^k) · x`, використовуючи довжину формули лише `O(k)`.
2. **Кванторне скорочення.** Якщо записати рекурсивне відношення наївно:
   ```
   P_{k+1}(x, y) ≡ ∃z. ( P_k(x, z) ∧ P_k(z, y) )
   ```
   то довжина формули подвоюватиметься на кожному кроці, що призведе до розміру `O(2^k)`.
3. **Метод Тарського — Нельсона.** Використовуючи квантори загальності `∀`, два рекурсивні виклики об'єднуються в один:
   ```
   P_{k+1}(x, y) ≡ ∃z. ∀u. ∀v. ( ( (u = x ∧ v = z) ∨ (u = z ∧ v = y) ) → P_k(u, v) )
   ```
   Довжина формули `P_{k+1}` збільшується лише на фіксовану константу `O(1)`. Отже, формула `P_k(x, y)` має довжину `O(k)`.
4. **Імітація конфігурації.** За допомогою предиката `P_k` кодується конфігурація машини Тюрінга з пам'яттю та часом `2^(2^k)` як одне ціле число. Формула довжини `O(k)` перевіряє коректність переходу між послідовними конфігураціями.

Оскільки задача зупинки машини Тюрінга за час `2^(2^k)` вимагає `Ω(2^(2^k))` кроків за теоремою про часову ієрархію, алгоритм перевірки формул Пресбургера довжини `n = O(k)` зобов'язаний витрачати щонайменше подвійно експоненційний час `2^(2^(c·n))`.

Верхня межа для кванторної арифметики Пресбургера становить трикратну експоненту `2^(2^(2^(c·n)))` за часом або `2^(2^(O(n)))` за пам'яттю (результат Леонарда Бермана, 1980).

## 5. Складність безкванторного фрагмента QF_LIA

На відміну від повної теорії з кванторами, безкванторний фрагмент `QF_LIA` (Quantifier-Free Linear Integer Arithmetic), що є основою SMT-сольверів, має принципово меншу складність.

**Теорема про складність QF_LIA:**
Проблема здійсненності довільної безкванторної формули лінійної цілочисельної арифметики (`QF_LIA`) є **NP-повною**.

### Доведення NP-трудності (Зведення з 3-SAT)

Нехай задано булеву 3-КНФ формулу `φ = C₁ ∧ C₂ ∧ ... ∧ C_m` від булевих змінних `u₁, ..., u_k`. Побудуємо еквівалентну систему цілочисельних лінійних обмежень:

1. Для кожної булевої змінної `u_i` вводиться цілочисельна змінна `x_i ∈ Z` та обмеження діапазону:
   ```
   0 ≤ x_i  ∧  x_i ≤ 1
   ```
   Це гарантує, що `x_i` приймає значення строго `0` (хиба) або `1` (істина).
2. Кожен булевий диз'юнкт `C_j = (l₁ ∨ l₂ ∨ l₃)` транслюється у лінійну нерівність. Позитивний літерал `u_i` транслюється як `x_i`, а негативний `¬u_i` — як `(1 - x_i)`. Вимагається, щоб сума літералів була не меншою за одиницю:
   ```
   l₁ + l₂ + l₃ ≥ 1
   ```
   Наприклад, диз'юнкт `(u₁ ∨ ¬u₂ ∨ u₃)` перетворюється на:
   ```
   x₁ + (1 - x₂) + x₃ ≥ 1   ⟺   x₁ - x₂ + x₃ ≥ 0
   ```

Булева формула `φ` здійсненна тоді й лише тоді, коли побудована система лінійних цілочисельних нерівностей має розв'язок у цілих числах `Z^k`. Трансляція виконується за лінійний час `O(n)`, що доводить NP-трудність.

### Доведення належності до класу NP (Теорема Пападімітріу)

Щоб довести належність до NP, необхідно гарантувати існування короткого поліноміального сертифіката (розв'язку), який недетермінована машина Тюрінга може вгадати та перевірити за поліноміальний час.

Христос Пападімітріу (1981) встановив фундаментальну оцінку розміру цілочисельних розв'язків для систем `A · x ≤ b`, де `A ∈ Z^{m × n}` та `b ∈ Z^m`.

**Лема Пападімітріу:**
Якщо система цілочисельних лінійних нерівностей `A · x ≤ b` має розв'язок `x ∈ Z^n`, то вона обов'язково має розв'язок `x*`, кожна координата якого обмежена величиною:

```
||x*||_∞ ≤ (n + 1)! · M^n
```

де `M = max( ||A||_∞, ||b||_∞ )` — максимальний за абсолютним значенням числовий коефіцієнт у системі.

Кількість бітів для двійкового запису кожної координати `x_i^*` оцінюється через логарифм:

```
log₂ ||x*||_∞ ≤ log₂( (n + 1)! ) + n · log₂(M)
              ≤ (n + 1) · log₂(n + 1) + n · log₂(M)
```

Ця величина є поліномом від розміру вхідних даних `L = size(A, b)`. Отже, сертифікат має поліноміальну довжину `O(n · log n + n · L)`, а підстановка вектора `x*` у систему `A · x ≤ b` та перевірка нерівностей займає поліноміальний час. Це доводить, що `QF_LIA ∈ NP`, а отже, `QF_LIA` є **NP-повною**.

## 6. Математичне виведення відтинань Гоморі

У практичних SMT-сольверах для розв'язання `QF_LIA` використовується комбінація симплекс-методу над дійсними числами `Q` із генерацією відтинальних площин Гоморі (Gomory Cutting Planes).

Нехай симплекс-метод знайшов дійсний розв'язок системи, у якому деяка базисна змінна `x_i` набула дробового значення. Розглянемо відповідний рядок симплекс-таблиці, виражений через небазисні змінні `x_j` (`j ∈ N`):

```
x_i + ∑_{j ∈ N} a_{ij} · x_j = a_{i0}
```

де `a_{i0} ∉ Z` (дробове число), а всі змінні задовольняють умову невід'ємності `x ≥ 0` та цілочисельності `x ∈ Z_{≥0}`.

Представимо кожне раціональне число `a_{ij}` та `a_{i0}` як суму його цілої частини `⌊a⌋` та дробової частини `f = a - ⌊a⌋`, де за означенням `0 ≤ f < 1`:

```
a_{i0} = ⌊a_{i0}⌋ + f_{i0}       [де 0 < f_{i0} < 1, оскільки a_{i0} неціле]
a_{ij} = ⌊a_{ij}⌋ + f_{ij}       [де 0 ≤ f_{ij} < 1]
```

Підставимо це розкладання у рівняння рядка та згрупуємо члени:

```
x_i + ∑_{j ∈ N} ( ⌊a_{ij}⌋ + f_{ij} ) · x_j = ⌊a_{i0}⌋ + f_{i0}
x_i + ∑_{j ∈ N} ⌊a_{ij}⌋ · x_j - ⌊a_{i0}⌋ = f_{i0} - ∑_{j ∈ N} f_{ij} · x_j
```

Проаналізуємо ліву та праву частини для довільного допустимого цілочисельного розв'язку `x ∈ Z_{≥0}`:
1. Ліва частина складається виключно з цілих чисел та їхніх добутків, отже, вона обов'язково є **цілим числом**.
2. Звідси випливає, що права частина `f_{i0} - ∑_{j ∈ N} f_{ij} · x_j` також зобов'язана бути цілим числом.
3. Оскільки `f_{i0} < 1`, а всі `f_{ij} ≥ 0` та `x_j ≥ 0`, значення виразу `f_{i0} - ∑_{j ∈ N} f_{ij} · x_j` є строго меншим за `1`:
   ```
   f_{i0} - ∑_{j ∈ N} f_{ij} · x_j ≤ f_{i0} < 1
   ```
4. Єдиним цілим числом, що є строго меншим за 1, може бути лише число `≤ 0`.

Отже, для будь-якого цілочисельного розв'язку виконується нерівність:

```
f_{i0} - ∑_{j ∈ N} f_{ij} · x_j ≤ 0   ⟺   ∑_{j ∈ N} f_{ij} · x_j ≥ f_{i0}
```

Це і є **відтинальна площина Гоморі (Gomory Cut)**.

### Числовий приклад побудови відтинання

Нехай розв'язок симплекс-таблиці дав дробовий рядок:

```
x₁ + (3/4) · x₂ - (5/6) · x₃ = 11/4
```

Обчислимо дробові частини коефіцієнтів:
- Для вільного члена: `a_{10} = 11/4 = 2 + 3/4`, отже `⌊a_{10}⌋ = 2`, `f_{10} = 3/4`.
- Для `x₂`: `a_{12} = 3/4 = 0 + 3/4`, отже `⌊a_{12}⌋ = 0`, `f_{12} = 3/4`.
- Для `x₃`: `a_{13} = -5/6 = -1 + 1/6`, отже `⌊a_{13}⌋ = -1`, `f_{13} = 1/6`.

Складаємо нерівність Гоморі `∑ f_{1j} · x_j ≥ f_{10}`:

```
(3/4) · x₂ + (1/6) · x₃ ≥ 3/4
```

Домноживши на 12 для приведення до цілих коефіцієнтів, отримуємо відтинання:

```
9 · x₂ + 2 · x₃ ≥ 9
```

У поточному симплекс-розв'язку небазисні змінні дорівнюють нулю (`x₂ = 0, x₃ = 0`), тому `9·0 + 2·0 = 0 ≥ 9` — умова порушується, і дробова точка відтинається.

## 7. Неопуклість LIA та комбінація Нельсона — Оппена

Важливою математичною особливістю теорії `LIA` є її **неопуклість (Non-convexity)**.

Теорія `T` називається опуклою, якщо для будь-якої кон'юнкції літералів `Γ` та диз'юнкції рівностей змінних `∨_{i=1}^k (x_i = y_i)` з умови `Γ ⊨ ∨_{i=1}^k (x_i = y_i)` обов'язково випливає, що `Γ ⊨ x_i = y_i` для деякого конкретного `i`.

Теорія дійсних чисел `LRA` є опуклою. Натомість `LIA` є **неопуклою**. Розглянемо контрприклад:

```
Γ = (1 ≤ x) ∧ (x ≤ 2) ∧ (y = 1) ∧ (z = 2)
```

Оскільки `x ∈ Z`, єдиними можливими значеннями `x` є 1 або 2. Звідси семантично випливає диз'юнкція рівностей:

```
Γ ⊨ (x = y ∨ x = z)
```

Проте окремо ані `Γ ⊨ x = y`, ані `Γ ⊨ x = z` не виконується. Через це у процедурі Нельсона — Оппена для комбінації `LIA` з іншими теоріями (наприклад, теорією неінтерпретованих функцій EUF) неможливо обійтися простим детермінованим поширенням рівностей: SMT-сольвер зобов'язаний виконувати комбінаторне розгалуження (case splitting) за диз'юнкціями рівностей або застосовувати Model-Based Nelson-Oppen (MBNO).
