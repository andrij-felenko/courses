# 🧮 Математичний аналіз Horn-SAT: теорема про перетин моделей, коректність каскаду та P-повнота

Теоретична унікальність хорнівських диз'юнктів спирається на три математичні стовпи: замкненість множини розв'язків відносно покомпонентного кон'юнкту (перетину моделей), існування єдиної мінімальної моделі та належність до класу P-повних задач. На відміну від загальної задачі здійсненності булевих формул (SAT), де простір рішень може мати довільну фрактальну структуру, простір моделей Horn-SAT утворює напівґрати зі строго виділеною нижньою межею.

## Формальні означення та класифікація диз'юнктів

Нехай `V = {x₁, x₂, ..., xₙ}` — скінченна множина булевих змінних. **Літералом** називається сама змінна `xᵢ` (позитивний літерал) або її заперечення `¬xᵢ` (негативний літерал).

**Диз'юнктом Хорна** називається диз'юнкція літералів, яка містить **не більше одного позитивного літерала**:

```
C = ¬p₁ ∨ ¬p₂ ∨ ... ∨ ¬pₖ ∨ [q]
```

З точки зору булевої алгебри існує три фундаментальні типи хорнівських диз'юнктів:

1. **Стверджувальне правило** (англ. *definite clause*): містить рівно один позитивний літерал `q` та `k ≥ 1` негативних літералів:
   ```
   ¬p₁ ∨ ¬p₂ ∨ ... ∨ ¬pₖ ∨ q  ≡  (p₁ ∧ p₂ ∧ ... ∧ pₖ) → q
   ```
2. **Атом / Факт** (англ. *fact / unit positive clause*): містить рівно один позитивний літерал і нуль негативних (`k = 0`):
   ```
   q  ≡  ⊤ → q
   ```
3. **Негативне обмеження / Диз'юнкт-мета** (англ. *integrity constraint / goal clause*): містить нуль позитивних літералів та `m ≥ 1` негативних:
   ```
   ¬p₁ ∨ ¬p₂ ∨ ... ∨ ¬pₘ  ≡  (p₁ ∧ p₂ ∧ ... ∧ pₘ) → ⊥
   ```

Булева формула `Φ` називається **хорнівською формулою**, якщо вона є кон'юнкцією хорнівських диз'юнктів: `Φ = C₁ ∧ C₂ ∧ ... ∧ Cₘ`.

Інтерпретація або **модель** `M` є функцією присвоєння значень `M: V → {0, 1}`, яку зручно подавати як множину змінних, приймаючих значення 1: `M = {x ∈ V | M(x) = 1}`.

## Алгебраїчна дуальність: Теорема про замкненість щодо перетину моделей

Головною алгебраїчною властивістю хорнівських формул, яка відрізняє їх від довільних КНФ, є замкненість відносно покомпонентного кон'юнкту істинності.

Для двох моделей `M₁` та `M₂` визначимо їхній **покомпонентний кон'юнкт** `M₁ ∧ M₂` як присвоєння:
```
(M₁ ∧ M₂)(x) = M₁(x) · M₂(x)    для всіх x ∈ V
```
У множинній термінології це відповідає звичайному перетину множин істинних змінних: `M₁ ∧ M₂ = M₁ ∩ M₂`.

> **Теорема 1 (McKinsey, 1943; Horn, 1951).** 
> Нехай `Φ` — хорнівська формула. Якщо `M₁ ⊨ Φ` та `M₂ ⊨ Φ` (обидва набори задовольняють формулу `Φ`), то їхній покомпонентний кон'юнкт також задовольняє формулу:
> ```
> (M₁ ∧ M₂) ⊨ Φ
> ```

### Доведення

Розглянемо довільний хорнівський диз'юнкт `C` з формули `Φ`. Оскільки `M₁ ⊨ Φ` та `M₂ ⊨ Φ`, значення `C` дорівнює 1 на обох інтерпретаціях: `M₁(C) = 1` та `M₂(C) = 1`. Покажемо, що `(M₁ ∧ M₂)(C) = 1` для кожного з трьох типів диз'юнктів.

**Випадок 1: Диз'юнкт є негативним обмеженням `C = (p₁ ∧ ... ∧ pₘ) → ⊥`.**
Щоб обмеження було істинним на `M₁`, принаймні одна змінна `pᵢ` має дорівнювати 0 у `M₁` (тобто `pᵢ ∉ M₁`). 
Аналогічно для `M₂` існує принаймні одна змінна `pⱼ ∉ M₂`.
У перетині `M₁ ∩ M₂` змінна `pᵢ` точно не належить перетину (бо `pᵢ ∉ M₁`). 
Отже, кон'юнкція `(p₁ ∧ ... ∧ pₘ)` у підстановці `M₁ ∩ M₂` містить принаймні один нуль і дорівнює 0. 
Імплікація `0 → ⊥` є істинною (`1`). Диз'юнкт виконано.

**Випадок 2: Диз'юнкт є стверджувальним правилом `C = (p₁ ∧ ... ∧ pₖ) → q`.**
Розглянемо значення лівого боку в підстановці `M₁ ∩ M₂`. Якщо хоча б одна змінна `pᵢ ∉ M₁ ∩ M₂`, то ліва частина дорівнює 0, і вся імплікація `0 → q` є істинною (`1`).
Якщо ж усі змінні умові істинні в перетині (`p₁ ∈ M₁ ∩ M₂, ..., pₖ ∈ M₁ ∩ M₂`), це означає, що:
- Усі `pᵢ ∈ M₁`, тому ліва частина імплікації істинна в `M₁`. Оскільки `M₁ ⊨ C`, маємо `q ∈ M₁`.
- Усі `pᵢ ∈ M₂`, тому ліва частина імплікації істинна в `M₂`. Оскільки `M₂ ⊨ C`, маємо `q ∈ M₂`.
Звідси випливає, що `q ∈ M₁ ∩ M₂`, тобто `(M₁ ∧ M₂)(q) = 1`. 
Імплікація `1 → 1` є істинною. Диз'юнкт виконано.

**Випадок 3: Диз'юнкт є фактом `C = ⊤ → q`.**
Оскільки `M₁ ⊨ C` та `M₂ ⊨ C`, маємо `q ∈ M₁` та `q ∈ M₂`. 
Отже, `q ∈ M₁ ∩ M₂`, що гарантує виконання факту на інтерпретації `M₁ ∩ M₂`.

Оскільки кожен диз'юнкт формули `Φ` виконано на `M₁ ∧ M₂`, маємо `(M₁ ∧ M₂) ⊨ Φ`. Теорему доведено.

### Наслідок: Існування єдиної мінімальної моделі

> **Наслідок 1.** Якщо хорнівська формула `Φ` є здійсненною (існує хоча б одна модель `M ⊨ Φ`), то існує **єдина мінімальна за включенням модель** `Mₘᵢₙ`, яка задовольняє `Φ`:
> ```
> Mₘᵢₙ = ⋂ { M ⊆ V | M ⊨ Φ }
> ```

Мінімальна модель `Mₘᵢₙ` містить лише ті змінні, які **необхідно** мають бути істинними у будь-якому розв'язку. Жодна загальна КНФ-формула (наприклад, `x ∨ y`) не має такої властивості: для `x ∨ y` моделі `M₁ = {x}` та `M₂ = {y}` у перетині дають `M₁ ∩ M₂ = ∅`, але порожня множина `∅` не задовольняє `x ∨ y`.

## Математичне обґрунтування каскаду (Unit Propagation)

Процедура розв'язання Horn-SAT спирається на побудову послідовності множин істинних змінних `S₀, S₁, S₂, ...`:

```
S₀ = { q ∈ V | (⊤ → q) ∈ Φ }
Sₜ₊₁ = Sₜ ∪ { q ∈ V | ∃ ((p₁ ∧ ... ∧ pₖ) → q) ∈ Φ  такі, що  {p₁, ..., pₖ} ⊆ Sₜ }
```

Оскільки множина змінних `V` скінченна і оператор `F(Sₜ) = Sₜ₊₁` є монотонним (`Sₜ ⊆ Sₜ₊₁`), за принципом Тарського — Кнастера послідовність досягає нерухомої точки `S* = Sₙ` за не більше ніж `n` кроків: `F(S*) = S*`.

> **Теорема 2 (Коректність та повнота каскаду).**
> 1. Якщо існує негативне обмеження `((p₁ ∧ ... ∧ pₘ) → ⊥) ∈ Φ` таке, що `{p₁, ..., pₘ} ⊆ S*`, то формула `Φ` є **нездійсненною** (UNSAT).
> 2. Якщо жодне негативне обмеження не порушене на `S*`, то формула `Φ` є **здійсненною** (SAT), а множина `S*` утворює **єдину мінімальну модель** `Mₘᵢₙ = S*`.

### Доведення

1. За індукцією легко показати, що для будь-якої моделі `M ⊨ Φ` виконується включення `S* ⊆ M`. Справді, всі факти `S₀` повинні виходити істинними в `M`. Якщо `Sₜ ⊆ M`, то для будь-якого правила `(p₁ ∧ ... ∧ pₖ) → q` із `pᵢ ∈ Sₜ ⊆ M` атом `q` також мусить належати `M`. Отже, `S* ⊆ M`. 
Якщо при цьому `{p₁, ..., pₘ} ⊆ S*`, то для будь-якої можливої моделі `M` мали б `{p₁, ..., pₘ} ⊆ M`, що порушує обмеження `(p₁ ∧ ... ∧ pₘ) → ⊥`. Значить, жодної моделі `M` не існує, і формула `Φ` є UNSAT.

2. Якщо всі обмеження задоволені на `S*`, перевіримо всі диз'юнкти `Φ` на інтерпретації `M* = S*`:
   - Факти `⊤ → q`: `q ∈ S₀ ⊆ S*`, отже виконано.
   - Правила `(p₁ ∧ ... ∧ pₖ) → q`: якщо `{p₁, ..., pₖ} ⊆ S*`, то за означенням нерухомої точки `q ∈ F(S*) = S*`. Отже, `1 → 1` виконано. Якщо ж хоча б один `pᵢ ∉ S*`, то `0 → M*(q)` виконано.
   - Обмеження `(p₁ ∧ ... ∧ pₘ) → ⊥`: за припущенням жодне обмеження не містить усіх умов у `S*`, тому лівий бік дорівнює 0. `0 → 0` виконано.
Отже, `M* ⊨ Φ`. Оскільки `M* = S* ⊆ M` для будь-якої іншої моделі `M`, `M*` є мінімальною моделлю `Mₘᵢₙ`. Теорему доведено.

## Доведення P-повноти: Зведення від Monotone Circuit Value Problem (CVP)

Щоб довести, що Horn-SAT є P-повною задачею, необхідно показати, що до неї логарифмічно за пам'яттю зводиться будь-яка задача з класу `P`. Скористаємося класичною P-повною задачею — **значення монотонної булевої схеми (Monotone Circuit Value Problem, MCVP)**.

У задачі MCVP дано направлений ациклічний граф (схему), де вхідні вершини мають фіксовані константні значення 0 або 1, а внутрішні вершини є логічними елементами `AND` та `OR`. Необхідно обчислити значення вихідної вершини `z_out`.

Побудуємо алгоритм-зведення `R`, який перекладає вентилі схеми у формулу Horn-SAT `Φ`:

```
Схема (MCVP)                         Хорнівські диз'юнкти (Φ)
-----------------------------------------------------------------------
Вхідний вентиль v = 1             →  ⊤ → v                 (факт)
Вхідний вентиль v = 0             →  (нічого не додаємо)
Вентиль AND: z = x ∧ y            →  (x ∧ y) → z           (стверджувальне правило)
Вентиль OR:  z = x ∨ y            →  (x → z) ∧ (y → z)     (два стверджувальні правила)
Перевірка виходу z_out = 1        →  z_out → ⊥             (негативне обмеження)
```

Математичні властивості побудованого зведення:
1. **Синтаксична відповідність:** Усі згенеровані диз'юнкти є хорнівськими (не більше одного позитивного літерала).
2. **Логарифмічна пам'ять:** Для обробки кожного вентиля схеми алгоритму-перекладачу достатньо підтримувати лічильники та покажчики почного вентиля, що вимагає `O(log |G|)` пам'яті.
3. **Еквівалентність розв'язку:** 
   - Якщо вихід схеми `z_out = 1`, то каскад хвилі `S*` опише точно ті вентилі, що приймають значення 1. Звідси `z_out ∈ S*`, що призведе до порушення обмеження `z_out → ⊥`. Формула `Φ` буде **UNSAT**.
   - Якщо вихід схеми `z_out = 0`, то `z_out ∉ S*`. Обмеження `z_out → ⊥` не буде порушене, і формула `Φ` буде **SAT**.

Таким чином, маємо логарифмічне зведення `MCVP ≤ₗₒℊ Horn-SAT`. Оскільки MCVP є P-повною, задача **Horn-SAT є P-повною**.

Цей результат підтверджує фундаментальний факт: Horn-SAT лежить на самій межі детермінованих поліномних обчислень, поєднуючи строго лінійний час виконання `O(N)` із внутрішньою послідовністю каскадного виведення.
