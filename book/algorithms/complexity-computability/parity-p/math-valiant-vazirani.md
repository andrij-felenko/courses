# 🧮 Математика: Лема Валіанта–Вазірані та лінійне ізолювання над 𝔽₂

Лема Валіанта–Вазірані (Valiant–Vazirani Isolation Lemma) дає суворий математичний інструмент для зменшення кількості розв'язків комбінаторної задачі до **рівно одного** з контрольованою ймовірністю. Вона слугує теоретичним містом між недетермінованим пошуком існування (NP) та підрахунком парності (⊕P).

## Математична постановка задачі та афінний простір над 𝔽₂

Нехай `S ⊆ {0,1}ⁿ` — непорожня множина здійсненних наборів (розв'язків) булевої формули, де `n` — кількість змінних. Позначимо через `k = |S|` розмір цієї множини, де `1 ≤ k ≤ 2ⁿ`. Булів куб `{0,1}ⁿ` розглядається як `n`-вимірний векторний простір над скінченним алгебраїчним полем `𝔽₂ = ({0, 1}, +, ·)`.

Наше завдання — побудувати таке випадкове лінійне афінне відображення `h: {0,1}ⁿ → {0,1}ᵐ` над полем `𝔽₂`, щоб звужена множина розв'язків `S' = {x ∈ S : h(x) = 0}` містила **рівно один** елемент (`|S'| = 1`) з імовірністю, обмеженою знизу фіксованою константою `p ≥ 1/8`.

Геометричний зміст цього відображення полягає в тому, що кожна з `m` компонент рівняння `h(x) = 0` визначає `(n - 1)`-вимірну афінну гіперплощину в просторі `𝔽₂ⁿ`. Перетин `m` таких випадкових гіперплощин утворює афінний підпростір розмірності `n - m`. Якщо підібрати кількість рівнянь `m` так, щоб розмірність підпростору збігалася з логарифмом кількості розв'язків (`2ᵐ ≈ k`), то у перетині з множиною `S` з високою ймовірністю залишиться єдиний свідок.

## Попарно незалежні хеш-функції над 𝔽₂

Сконструюємо хеш-функцію `h` за допомогою випадкової матриці `A` розміру `m × n` із елементами з поля `𝔽₂` та випадкового вектора зсуву `b ∈ {0,1}ᵐ`. Значення `h(x)` обчислюється як матричний добуток з додаванням за модулем 2:

```
h(x) = A · x + b  (mod 2)
```

Розглянемо двох довільних різних векторів `x, y ∈ {0,1}ⁿ` (`x ≠ y`). Оскільки `x ≠ y`, існує хоча б одна координата `i`, у якій `xᵢ ≠ yᵢ`. Без втрати загальності припустимо `x₁ = 0` та `y₁ = 1`.

Для будь-яких цільових векторів `α, β ∈ {0,1}ᵐ` обчислимо ймовірність події `(h(x) = α ∧ h(y) = β)`:

```
h(x) = A · x + b = α
h(y) = A · y + b = β
```

Віднімемо перше рівняння від другого у полі `𝔽₂` (оскільки `-1 ≡ +1 mod 2`, віднімання тотожне додаванню):

```
A · (y - x) = β - α  (mod 2)
```

Оскільки `y - x ≠ 0`, вектор `y - x` має принаймні один ненульовий елемент. Матриця `A` складається з `m · n` випадкових незалежних бітів. Тому добуток `A · (y - x)` приймає кожне з `2ᵐ` можливих значень із однаковою ймовірністю `2⁻ᵐ`. Після фіксації значення `A · (y - x) = β - α`, вектор зсуву `b` однозначно визначає `h(x) = α` з ймовірністю `2⁻ᵐ`.

Звідси випливає фундаментальна властивість **попарної незалежності**:

```
P(h(x) = α  ∧  h(y) = β)
= P(h(x) = α) · P(h(y) = β | h(x) = α)   [правило множення ймовірностей]
= (1 / 2ᵐ) · (1 / 2ᵐ)
= 1 / 2²ᵐ                               [попарна незалежність вибору A та b]
```

Отже, імовірність того, що конкретний вектор `x` потрапить у ядро відображення (`h(x) = 0`), становить `P(h(x) = 0) = 2⁻ᵐ`. Кожна комбінація лінійних обмежень діє як ідеальний 2-універсальний хеш.

## Оцінка ймовірності ізолювання: Доведення нерівності

Припустимо спочатку, що розмір множини розв'язків `k = |S|` задовольняє нерівність `2ᵐ⁻² ≤ k ≤ 2ᵐ⁻¹` для деякого обраного цілого числа `m` (`1 ≤ m ≤ n + 1`).

Позначимо через `E(x)` подію, яка означає, що вектор `x ∈ S` є єдиним елементом, що задовольняє `h(x) = 0`:

```
E(x) ⇔ (h(x) = 0)  ∧  (∀ y ∈ S \ {x}: h(y) ≠ 0)
```

Подія ізолювання `|S'| = 1` є об'єднанням взаємно виключних подій `E(x)` по всіх `x ∈ S`:

```
P(|S'| = 1) = ∑_{x ∈ S} P(E(x))
```

Для кожного фіксованого `x ∈ S` застосуємо перші дві нерівності Бонферроні (формулу включень-виключень):

```
P(E(x))
= P(h(x) = 0  ∧  ⋀_{y ∈ S \ {x}} h(y) ≠ 0)
≥ P(h(x) = 0) - ∑_{y ∈ S \ {x}} P(h(x) = 0  ∧  h(y) = 0)
```

Підставимо раніше обчислені попарні ймовірності хеш-функції над `𝔽₂`:

```
P(h(x) = 0) = 2⁻ᵐ
P(h(x) = 0 ∧ h(y) = 0) = 2⁻²ᵐ
```

Здійснимо покрокове обчислення суми по всіх `k` елементах множини `S`:

```
P(|S'| = 1)
≥ ∑_{x ∈ S} ( 2⁻ᵐ - (k - 1) · 2⁻²ᵐ )     [підстановка попарних ймовірностей]
= k · 2⁻ᵐ - k · (k - 1) · 2⁻²ᵐ           [сумування по k однаковим доданках]
= k · 2⁻ᵐ · (1 - (k - 1) · 2⁻ᵐ)          [винесення спільного множника k · 2⁻ᵐ]
≥ k · 2⁻ᵐ · (1 - k · 2⁻ᵐ)                [посилення нерівності за рахунок (k-1) < k]
```

Введемо нормовану змінну `γ = k · 2⁻ᵐ`. Оскільки ми обрали `m` так, що `2ᵐ⁻² ≤ k ≤ 2ᵐ⁻¹`, межі для `γ` мають вигляд:

```
2ᵐ⁻² · 2⁻ᵐ ≤ γ ≤ 2ᵐ⁻¹ · 2⁻ᵐ
1/4 ≤ γ ≤ 1/2
```

Дослідимо параболічну функцію `f(γ) = γ · (1 - γ)` на закритому інтервалі `[1/4, 1/2]`. Похідна `f'(γ) = 1 - 2γ` є додатною при `γ < 1/2`, тому функція строго зростає на `[1/4, 1/2]`.

Мінімум функції `f(γ)` на цьому відрізку досягається у лівій граничній точці `γ = 1/4`:

```
f(1/4) = (1/4) · (1 - 1/4) = (1/4) · (3/4) = 3/16 = 0.1875
f(1/2) = (1/2) · (1 - 1/2) = (1/2) · (1/2) = 1/4  = 0.2500
```

Отже, ймовірність ізолювання єдиного розв'язку строго обмежена знизу:

```
P(|S'| = 1) ≥ 3/16 > 1/8 = 0.125
```

Таким чином, якщо розмір множини `k` відомий з точністю до множника 2, вибір випадкової системи з `m` лінійних рівнянь над `𝔽₂` дає рівно один розв'язок із імовірністю щонайменше `3/16` (що строго більше `1/8`).

## Випадок невідомого розміру множини розв'язків `|S|`

У реальних комбінаторних задачах ми заздалегідь не знаємо число `k = |S|`. Воно може бути будь-яким цілим числом від 1 до `2ⁿ`.

Аби подолати цю невизначеність, імовірнісний алгоритм Валіанта–Вазірані вибирає кількість лінійних рівнянь `m` рівномірно випадковим чином із множини варіантів `{1, 2, ..., n + 1}`.

Оскільки множина `{1, 2, ..., n + 1}` містить `n + 1` можливих значень `m`, а для будь-якого `k ∈ [1, 2ⁿ]` існує принаймні одне значення `m`, яке задовольняє нерівність `2ᵐ⁻² ≤ k ≤ 2ᵐ⁻¹`, імовірність обрати саме це «правильне» `m` дорівнює:

```
P(правильне m) = 1 / (n + 1)
```

Обчислимо повну ймовірність успішного ізолювання розв'язку за один імовірнісний прохід:

```
P_success
≥ P(правильне m) · P(|S'| = 1 | правильне m)
≥ (1 / (n + 1)) · (3 / 16)
= 3 / (16 · (n + 1))
```

Оскільки ця ймовірність є зворотньо-поліноміальною від кількості змінних `n` (`Ω(1/n)`), її можна підсилити до будь-якої високої точності.

## Підсилення ймовірності (Amplification)

Щоб зменшити ймовірність помилки до малої величини `δ > 0`, алгоритм повторює процедуру вибору `m` та генерації лінійних обмежень `N` разів незалежно.

Обчислимо необхідну кількість повторень `N`:

```
P(усі N спроб невдалі) = (1 - P_success)ⁿ ≤ exp(- N · P_success) ≤ δ
```

Прогарифмувавши нерівність, отримуємо:

```
- N · P_success ≤ ln(δ)
N ≥ (1 / P_success) · ln(1 / δ) = O(n · log(1 / δ))
```

Отже, за `O(n · log(1/δ))` незалежних викликів оракула ⊕P ми здатні визначити здійсненність початкової формули з ймовірністю успіху `1 - δ`.

## Алгебраїчний зв'язок із непарністю (модуль 2)

Чому факт існування **рівно 1** розв'язку є критичним для теорії складності?

Для довільного числа розв'язків `|S'|` оракул парності повертає біт `|S'| mod 2`. Якщо `|S'| = 4` (наприклад, для формули з двома вільними змінними), то оракул повернув би `0`, хоча формула є здійсненною. Через це оракул парності на довільних формулах не здатний прямо відповісти на питання існування NP.

Проте коли `|S'| = 1`, число 1 є строго **непарним** (`1 mod 2 = 1`). Якщо ж початкова формула взагалі не мала розв'язків (`|S| = 0`), то після додавання будь-яких рівнянь `|S'| = 0`, що є **парним** (`0 mod 2 = 0`).

Отже, оракул парності ⊕P на ізольованій формулі гарантовано повертає `1` тоді й лише тоді, коли вихідна формула мала розв'язки. Це дає строге алгебраїчне зведення NP-задач до оракула парності ⊕P.

## Геометрична інтерпретація та дисперсія розв'язків

Щоб глибше зрозуміти, чому попарно незалежні хеш-функції над `𝔽₂` працюють так ефективно, обчислимо математичне сподівання та дисперсію кількості розв'язків у зрізаній множині `S'`.

Визначимо випадкову величину `X = |S'| = ∑_{x ∈ S} I(h(x) = 0)`, де `I` — індикаторна функція.

Обчислимо математичне сподівання `E[X]`:

```
E[X] = ∑_{x ∈ S} E[I(h(x) = 0)] = ∑_{x ∈ S} P(h(x) = 0) = k · 2⁻ᵐ
```

Обчислимо дисперсію `Var[X]`:

```
Var[X] = E[X²] - (E[X])²
```

Оскільки `X² = (∑_{x ∈ S} I_x)² = ∑_{x ∈ S} I_x² + ∑_{x ≠ y} I_x I_y`, а `I_x² = I_x`:

```
E[X²] = ∑_{x ∈ S} P(h(x) = 0) + ∑_{x ≠ y} P(h(x) = 0 ∧ h(y) = 0)
= k · 2⁻ᵐ + k · (k - 1) · 2⁻²ᵐ
```

Підставимо у формулу дисперсії:

```
Var[X] = k · 2⁻ᵐ + k · (k - 1) · 2⁻²ᵐ - (k · 2⁻ᵐ)²
= k · 2⁻ᵐ - k · 2⁻²ᵐ = E[X] · (1 - 2⁻ᵐ) < E[X]
```

Оскільки дисперсія є малою (`Var[X] < E[X]`), значення випадкової величини `X` щільно згруповане навколо її математичного сподівання `E[X] ≈ 1` при `m ≈ log₂ k`. Це пояснює високу стійкість випадкового лінійного ізолювання над алгебраїчним полем `𝔽₂`.
