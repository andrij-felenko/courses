# Математика решіток, алгоритм LLL та параметризація LWE

Математична міцність решіткової криптографії базується на геометрії дискретних підгруп евклідового простору та алгебрі модулів над кільцями.

## 1. Геометрія решіток, дуальні решітки та геометрія чисел

Нехай `b[1], b[2], ..., b[n]` — лінійно незалежні вектори у векторному просторі `R^m` (де `m ≥ n`).

**Означення 1 (Решітка).** Решіткою `L`, згенерованою базисом `B = [b[1] | b[2] | ... | b[n]] ∈ R^(m × n)`, називається множина всіх цілочисельних лінійних комбінацій цих векторів:

```
L(B) = { ∑ (i = 1..n) z[i] · b[i]  |  z[i] ∈ Z }
```

Число `n` називається **рангом** решітки, а `m` — її **розмірністю**. Якщо `m = n`, решітка називається **повноранговою**.

### Дискретність та фундаментальна область

Решітка є дискретною підгрупою адитивної групи `R^m`. Це означає, що для будь-якої точки решітки існує відкрита куля в `R^m`, яка не містить жодної іншої точки цієї решітки.

Фундаментальна паралелепіпедна область `P(B)` визначається як множина векторів:

```
P(B) = { ∑ (i = 1..n) x[i] · b[i]  |  0 ≤ x[i] < 1 }
```

Об'єм цієї області називається **детермінантом решітки** `det(L)` (або інваріантним об'ємом фундаментальної комірки) і не залежить від вибору конкретного базису:

```
det(L) = √det(Bᵀ · B)
```

Для повнорангової решітки (`m = n`) детермінант дорівнює модулю визначника базисної матриці: `det(L) = |det(B)|`. Якщо ми змінимо базис `B` на `B' = B · U`, де `U` — цілочисельна унімодулярна матриця з `det(U) = ±1`, то `det(B') = |det(B · U)| = |det(B)| · |det(U)| = det(L)`.

### Неравество Адамара

Для будь-якого базису `B` детермінант решітки обмежений зверху добутком евклідових довжин її базисних векторів:

```
det(L) ≤ ∏ (i = 1..n) ‖b[i]‖
```

Рівність досягається тоді й лише тоді, коли вектори базису є попарно ортогональними. Відношення `H(B) = det(L) / ∏ ‖b[i]‖` називається ортогональним коефіцієнтом Адамара. Чим ближче `H(B)` до 1, тим кращим і коротшим є даний базис.

### Дуальна (обернена) решітка

Для будь-якої решітки `L ⊂ R^n` визначається її **дуальна решітка** `L*`, що складається з усіх векторів у просторі, які дають цілочисельний скалярний добуток із кожним вектором вихідної решітки:

```
L* = { y ∈ R^n  |  ∀ x ∈ L, ⟨x, y⟩ ∈ Z }
```

Якщо матриця `B` утворює базис повнорангової решітки `L`, то матриця `B* = (B⁻¹)ᵀ` є базисом дуальної решітки `L*`. Детермінант дуальної решітки пов'язаний із вихідним співвідношенням: `det(L*) = 1 / det(L)`. Дуальні решітки відіграють вирішальну роль у квантових зведеннях Реґева та аналізі криптосистеми LWE.

## 2. Послідовні мінімуми та теореми Мінковського

Для вимірювання геометричної щільності точок у решітці німецький математик Герман Мінковський увів поняття **послідовних мінімумів**.

**Означення 2 (i-й мінімум).** Для `i ∈ {1, ..., n}`, `i`-й послідовний мінімум `λ[i](L)` — це найменше додатне дійсне число `r`, таке що замкнена куля радіуса `r` з центром у початку координат містить принаймні `i` лінійно незалежних векторів решітки:

```
λ[i](L) = inf { r > 0  |  dim(span(L ∩ B(0, r))) ≥ i }
```

Зокрема, `λ[1](L)` — це довжина найкоротшого ненульового вектора в решітці. Значення `λ[n](L)` відповідає радіусу найменшої кулі, яка містить повний набір з `n` лінійно незалежних векторів.

### Перша теорема Мінковського про випуклі тіла

Нехай `L` — повнорангова решітка в `R^n`. Будь-яке центрально-симетричне випукле тіло `K ⊂ R^n` (тобто таке, що для `x ∈ K` виконується `-x ∈ K`) з об'ємом `vol(K) > 2ⁿ · det(L)` містить принаймні одну ненульову точку решітки `L`.

Застосовуючи цю теорему до `n`-вимірної евклідової кулі `B(0, r)` з об'ємом `vol(B(0, r)) = v[n] · rⁿ`, ми отримуємо фундаментальну верхню межу для найкоротшого вектора будь-якої решітки:

```
λ[1](L) ≤ √n · (det(L))^(1/n)
```

Величина `γ[n] = (λ[1](L))² / (det(L))^(2/n)` називається **константою Ерміта**.

### Друга теорема Мінковського

Друга теорема Мінковського узагальнює нерівність для всіх послідовних мінімумів, обмежуючи їхній добуток об'ємом фундаментальної області:

```
(2 / n!) · det(L) ≤ ∏ (i = 1..n) λ[i](L) ≤ (2ⁿ / v[n]) · det(L)
```

Ця нерівність доводить, що послідовні мінімуми не можуть бути довільно великими: якщо один із мінімумів росте, інші змушені зменшуватися, зберігаючи об'ємну балансувальну константу.

## 3. Алгоритм Ленстри–Ленстри–Ловаса (LLL)

Алгоритм LLL (Arjen Lenstra, Hendrik Lenstra, László Lovász, 1982) є першим ефективним поліноміальним алгоритмом для знаходження «досить короткого» базису решітки.

### Ортогоналізація Грама–Шмідта

Нехай `b[1], ..., b[n]` — базис. Його ортогоналізована послідовність `b*[1], ..., b*[n]` обчислюється як:

```
b*[i] = b[i] - ∑ (j = 1..i-1) μ[i,j] · b*[j]
```

де коефіцієнти проекції `μ[i,j]` дорівнюють:

```
μ[i,j] = ⟨b[i], b*[j]⟩ / ‖b*[j]‖²
```

Вектори `b*[i]` є попарно ортогональними, проте вони не належать самій решітці `L`, оскільки коефіцієнти `μ[i,j]` є дійсними або раціональними числами, а не цілими.

### Означення LLL-редукованого базису

Базис `B` називається `δ`-LLL-редукованим (для `1/4 < δ < 1`, зазвичай `δ = 3/4`), якщо справджуються дві умови:

1. **Розмірна редукція**: для всіх `1 ≤ j < i ≤ n`:
   ```
   |μ[i,j]| ≤ 1/2
   ```
   Ця умова означає, що вектори `b[i]` ортогоналізовані відносно попередніх векторів із максимально можливим цілочисельним зсувом.

2. **Умова Ловаса**: для всіх `1 < i ≤ n`:
   ```
   δ · ‖b*[i-1]‖² ≤ ‖b*[i] + μ[i,i-1] · b*[i-1]‖²
   ```
   Умова Ловаса гарантує, що ортогональні проекції векторів не зменшуються надто стрімко при збільшенні індексу. Вона вимагає, щоб сусідні вектори перебували у належному порядку за довжиною.

### Реалізація алгоритму LLL

Нижче наведено робочу реалізацію алгоритму LLL точної арифметики мовою Python:

```python
def grams_schmidt(B):
    n = len(B)
    B_star = [[0.0]*len(B[0]) for _ in range(n)]
    mu = [[0.0]*n for _ in range(n)]
    for i in range(n):
        B_star[i] = list(B[i])
        for j in range(i):
            dot_bb = sum(B[i][k] * B_star[j][k] for k in range(len(B[0])))
            dot_star = sum(B_star[j][k] ** 2 for k in range(len(B[0])))
            mu[i][j] = dot_bb / dot_star if dot_star != 0 else 0.0
            for k in range(len(B[0])):
                B_star[i][k] -= mu[i][j] * B_star[j][k]
    return B_star, mu

def lll_reduce(B, delta=0.75):
    n = len(B)
    B = [list(row) for row in B]
    k = 1
    while k < n:
        B_star, mu = grams_schmidt(B)
        # 1. Розмірна редукція для k по відношенню до j
        for j in range(k - 1, -1, -1):
            if abs(mu[k][j]) > 0.5:
                q = round(mu[k][j])
                for m in range(len(B[0])):
                    B[k][m] -= q * B[j][m]
                B_star, mu = grams_schmidt(B)

        # 2. Перевірка умови Ловаса
        dot_k = sum(B_star[k][m]**2 for m in range(len(B[0])))
        dot_k1 = sum(B_star[k-1][m]**2 for m in range(len(B[0])))
        if dot_k >= (delta - mu[k][k-1]**2) * dot_k1:
            k += 1
        else:
            # Обмін векторів місцями
            B[k], B[k-1] = B[k-1], B[k]
            k = max(k - 1, 1)
    return B

# Приклад застосування
B_bad = [[1, 15], [0, 1]]
B_good = lll_reduce(B_bad)
```

### Доведення термінації та гарантії LLL

Щоб довести, що LLL завершується за поліноміальний час, вводиться потенційна функція потенціалу решітки `Φ`:

```
d[i] = det(L(b[1], ..., b[i]))² = ∏ (j = 1..i) ‖b*[j]‖²
Φ = ∏ (i = 1..n-1) d[i]
```

Значення `d[i]` є цілим числом для цілочисельних решіток. При кожному обміні двох векторів `b[k-1]` та `b[k]`, коли умова Ловаса порушується, детермінант підрешітки `d[k-1]` зменшується принаймні у `1 / √δ` разів. Оскільки потенціал `Φ` обмежений знизу одиницею і зменшується при кожному обміні, кількість ітерацій LLL обмежена поліномом `O(n² · log B_max)`.

Теоретичні гарантії першого вектора `b[1]` LLL-редукованого базису для `δ = 3/4` складають:

```
‖b[1]‖ ≤ 2^((n-1)/2) · λ₁(L)
‖b[1]‖ ≤ 2^((n-1)/4) · (det(L))^(1/n)
```

Хоча `2^((n-1)/2)` росте експоненціально, поліноміальність LLL зробила його головним інструментом у криптоаналізі для малих розмірностей `n < 100`.

## 4. Специфікація LWE та вибір розподілу шуму

**Розподіл помилки.** У проблемі LWE шум `e` вибирається з дискретного гаусового розподілу `D_(Z, σ)` над цілими числами з центром у 0 і середньоквадратичним відхиленням `σ = α · q`.

Ймовірність вибору цілого числа `x ∈ Z` пропорційна значенню гаусової функції: `P(x) ∝ exp(-π · x² / σ²)`.

Щоб криптосистема на основі LWE була одночасно **стійкою** і мала **надійне декодування без помилок**, параметри `(n, m, q, σ)` вибираються згідно з строгими математичними критеріями:

1. **Гарантія декодування**: Сумарний шум при розшифруванні `e' = eᵀ · r` не повинен перевищувати `q / 4`. Для бінарного вектора `r ∈ {0,1}ᵐ` евклідова норма шуму за нерівністю Хефдінга обмежена як `|e'| ≤ 6 · σ · √m` із ймовірністю помилки менше `2⁻⁵⁰`. Звідси:

```
6 · σ · √m < q / 4  ⇒  α < 1 / (24 · √m)
```

2. **Гарантія квантової стійкості**: Зведення Реґева вимагає, щоб відносний шум `α · q` був не меншим за `2 · √n`, що унеможливлює використання алгоритмів згладжування решіток через квантовий перебір.

Ці математичні обмеження визначають точні цифрові параметри сучасних постквантових стандартів, таких як ML-KEM та ML-DSA.
