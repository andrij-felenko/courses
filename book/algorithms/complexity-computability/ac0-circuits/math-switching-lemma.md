# 𝔮 Лема про перемикання Гастада та доведення нижньої межі PARITY

Ця вставка містить повне математичне та комбінаторне доведення Леми про перемикання Гастада (Håstad's Switching Lemma) та її застосування для встановлення експоненціальної нижньої межі розміру булевих схем константної глибини (класу AC⁰), що обчислюють функцію парності `PARITY`. Матеріал розкриває ймовірнісний метод випадкових обмежень, алгебру спрощення ДНФ/КНФ форм та концепцію Дерев Рішень.

## 1. Формалізм випадкових обмежень та простір R_p

Нехай `X = {x₁, x₂, ..., x♙}` — множина булевих змінних, а `f: {0, 1}ⁿ → {0, 1}` — булева функція від `n` змінних.

> **Означення обмеження.** Обмеженням `ρ` називається функція `ρ: X → {0, 1, *}`, яка призначає кожній змінній `xᵢ` значення 0, 1 або залишає її невідфіксованою (позначається символом `*`).

Для булевої функції `f(x₁, ..., x♙)` звуження `f|ₚ` являє собою нову булеву функцію, яка залежить лише від тих змінних `xᵢ`, для яких `ρ(xᵢ) = *`. Якщо змінній `xᵢ` призначено значення 0 або 1, ця змінна підставляється у всі відповідні літерали функції `f`, здійснюючи логічне спрощення за правилами:

```
0 ∧ A = 0,   1 ∧ A = A,   0 ∨ A = A,   1 ∨ A = 1
```

> **Ймовірнісний простір обмежень Rₚⁿ.** Позначимо через `Rₚⁿ` імовірнісний розподіл над обмеженнями `ρ`, у якому для кожної змінної `xᵢ` незалежно обирається значення:
>
> ```
>        ┌ 0 ,  з імовірністю (1 - p) / 2
> ρ(xᵢ) = ├ 1 ,  з імовірністю (1 - p) / 2
>        └ * ,  з імовірністю p
> ```

Параметр `p ∈ (0, 1)` визначає математичне сподівання кількості невідфіксованих змінних: `E[|ρ⁻¹(*)|] = p · n`. Ймовірність того, що змінна буде зафіксована значенням 0 дорівнює `(1 - p)/2`, і так само значенням 1.

## 2. Дерева рішень та параметр глибини DT(f)

> **Означення Дерева Рішень.** Дерево Рішень (англ. *Decision Tree*) для булевої функції `f` є бінарним деревом, у якому кожна внутрішня вершина розмічена змінною `xᵢ`, вихідні ребра з вершини відповідають значенням 0 та 1, а листки розмічені підсумковими значеннями `f(x) ∈ {0, 1}`.
>
> **Глибина Дерева Рішень `DT(f)`** — це максимальна кількість змінних, опитуваних уздовж найдовшого шляху від кореня до листка для найгіршого вхідного вектора.

Параметр `DT(f)` є фундаментальною мірою складності обчислення булевої функції у квазіпослідовній моделлі. Якщо `DT(f) = r`, це означає, що для визначення значення функції `f` для будь-якого входу достатньо послідовно адаптивно опитати значення не більше ніж `r` змінних.

Між Деревами Рішень та ДНФ/КНФ формами існує суворий зв'язок:

1. Якщо `DT(f) ≤ r`, то функція `f` може бути представлена у вигляді `r`-ДНФ (диз'юнкції кон'юнкцій, де кожен терм має валентність `≤ r`). Кожен шлях від кореня до листка зі значенням 1 відповідає одній кон'юнкції літералів довжини `≤ r`.
2. Аналогічно, функція `f` з `DT(f) ≤ r` виражається у вигляді `r`-КНФ (кон'юнкції диз'юнкцій з довжиною диз'юнкцій `≤ r`), де кожен шлях до листка зі значенням 0 відповідає диз'юнктивному диз'юнкту.

## 3. Точне формулювання Леми про перемикання Гастада

> **Лема про перемикання (Гастад, 1986).** Нехай `f` є `k`-ДНФ формулою від `n` змінних (тобто `f = T₁ ∨ T₂ ∨ ... ∨ T☤`, де кожен терм `Tᵢ` містить щонайбільше `k` літералів). Для довільних `p ∈ (0, 1)` та `r ≥ 1` імовірність того, що звужена функція `f|ₚ` не виражається Деревом Рішень глибини менше `r`, обмежена нерівністю:
>
> ```
> Pr_{ρ ∈ Rₚⁿ}[ DT(f|ₚ) ≥ r ] ≤ (5 · p · k)ʳ
> ```

### Комбінаторна ідея доведення (Метод кодування)

Доведення здійснюється за допомогою комбінаторного ін'єктивного кодування (англ. *encoding argument*). Ми припускаємо існування плохих обмежень `ρ`, для яких `DT(f|ₚ) ≥ r`, і будуємо ін'єктивне відображення з множини «поганих» обмежень у множину обмежень з більшою кількістю зафіксованих змінних `R_{p'}ⁿ`.

Нехай `T₁` — перший терм у `f`, який не обнулився під дією `ρ`. Оскільки `DT(f|ₚ) ≥ r`, існує канонічний шлях у дереві рішень глибини `r`, який визначає присвоєння `σ` для змінних із `T₁`. Замінюючи вільні змінні значеннями `σ`, ми трансформуємо обмеження `ρ` у нове обмеження `ρ'`.

Детальний аналіз комбінаторних варіантів розширення свідчить:
1. Загальна кількість таких канонічних розширень обмежена значенням `(5 · k)ʳ`.
2. Оскільки імовірність вибору розширеного обмеження менша у `pʳ` разів за вибір початкового обмеження `ρ`, підсумкова імовірність не перевищує добуток цих комбінаторних множників:

```
Pr[ DT(f|ₚ) ≥ r ] ≤ (5 · k)ʳ · pʳ = (5 · p · k)ʳ
```

Якщо підставити значення `p = 1 / (10 · k)`, вираз під піднесенням до степеня стає дорівнювати `5 · (1 / (10 · k)) · k = 1 / 2`. У результаті отримуємо експоненціально малу імовірність `(1 / 2)ʳ = 2⁻ʳ`.

## 4. Індуктивне спрощення схем глибини d

Розглянемо булеву схему `C` глибини `d` та розміру `S = size(C)` у шаруватому вигляді (альтернативні шари `AND` та `OR`).

Позначимо параметри на рівні `i`:
- `kᵢ` — максимальна вхідна валентність гейтів на рівні `i`.
- `pᵢ` — параметр випадкового обмеження на кроці `i`.

Застосуємо лему про перемикання до вентилів першого шару схемы `C`. 

Оберемо параметр `p = 1 / (10 · k)`. За лемою про перемикання з імовірністю `≥ 1 - S · (1/2)ʳ` кожен гейт `k`-ДНФ першого рівня спрощується до Дерева Рішень глибини `r`, яке трансформується у `r`-КНФ.

Після заміни `k`-ДНФ на `r`-КНФ ми отримуємо два послідовних шари гейтів `AND` (новий шар із КНФ та вищий шар `AND` початкової схеми). За асоціативністю логічного `AND` ці два шари **зливаються в один шар**:

```
Початковий шар 1: OR над AND (ДНФ)  [Fan-in = k]
Після перемикання: AND над OR (КНФ) [Fan-in = r]
Злиття з шаром 2: AND(AND(OR))  ⇒  AND над OR
```

У результаті глибина схеми зменшується з `d` до `d - 1`, а максимальна валентність гейтів нижнього шару стає дорівнювати `r`.

Цей крок перемикання та злиття шарів виконується індуктивно `d - 2` разів. На кожному кроці глибина схеми зменшується на 1, а розмір схеми не зростає, оскільки кожен гейт лише спрощується під дією обмеження.

## 5. Доведення нижньої межі розміру для PARITY

Застосуємо процес індуктивного спрощення до схеми `C` глибини `d`, яка обчислює функцію `PARITY(x₁, ..., x♙)`.

Послідовно оберемо `d - 2` випадкових обмежень `ρ₁, ρ₂, ..., ρ_{d-2}` з параметрами:

```
p = 1 / (10 · n^{1/(d-1)})
r = n^{1/(d-1)}
```

Після застосування `d - 2` обмежень загальна кількість невідфіксованих (вільних) змінних у схемі дорівнює:

```
s = p^{d-2} · n = (n^{-1/(d-1)})^{d-2} · n = n^{1/(d-1)} = r
```

Нехай `ρ* = ρ₁ ∘ ρ₂ ∘ ... ∘ ρ_{d-2}` — композиція всіх `d - 2` обмежень. 

Схема `C|ₚ*` спростилася до Дерева Рішень глибини менше `r = s`. Отже, звужена схема обчислюється Деревом Рішень, яке ставить питання щонайбільше про `s - 1` змінну.

Проте розглянемо поведінку функції `PARITY` під дією будь-якого фіксованого обмеження `ρ*`:

```
PARITY|ₚ*(x) = PARITY(x_{free}) ⊕ const
```

Значення `const ∈ {0, 1}` є фіксованим бітом парності тих Variables, які були зафіксовані у 1 під дією `ρ*`. 

Функція `PARITY` від `s` вільних змінних істотно залежить від **усіх** `s` бітів: якщо не опитати хоча б один біт `xᵢ`, значення парності неможливо визначити однозначно (оскільки для будь-якого фіксованого значення решти `s - 1` бітів значення `xᵢ = 0` та `xᵢ = 1` дають протилежні виходи PARITY).

Тому будь-яке Дерево Рішень, яке обчислює `PARITY` від `s` змінних, зобов'язане мати глибину точної рівності:

```
DT(PARITY|ₚ*) = s
```

Отримано суперечність: з одного боку, спрощена схема дає `DT(C|ₚ*) < r = s`, з іншого боку, функція парності вимагає `DT(PARITY|ₚ*) = s`.

Ця суперечність виникла з припущення, що початковий розмір схеми `S = size(C)` був занадто малим і ймовірність збереження хоча б одного «не спрощеного» гейта була менша за 1.

Щоб уникнути суперечності, сумарна імовірність помилки повинна бути не меншою за 1, що вимагає:

```
S · 2⁻ʳ ≥ 1  ⇒  S ≥ 2ʳ = 2^{n^{1/(d-1)}}
```

Враховуючи константи в оцінці Гастада `p = 1 / (10 · n^{1/(d-1)})`, остаточна нижня межа розміру становить:

```
size(C) ≥ 2^{c · n^{1/(d-1)}}
```

де `c = 1 / 10`.

Математичне доведення завершено: будь-яка булева схема константної глибини `d`, яка обчислює парність, вимагає експоненціальної кількості гейтів від розрядності входу `n`.
