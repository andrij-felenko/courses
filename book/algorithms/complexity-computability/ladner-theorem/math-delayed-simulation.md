# 🧮 Математичний доказ теореми Леднера та побудова функції затримання

Цей математичний розбір містить суворе формальне доведення існування NP-проміжних мов за допомогою конструювання повільно зростаючої функції `H(n)` та детального аналізу її обчислювальної складності.

## Формалізація та вхідні припущення

Припустимо, що `P ≠ NP`. Нехай `SAT` — задача здійсненності булевих формул, яка за теоремою Кука — Левіна є NP-повною. Оскільки `P ≠ NP`, мова `SAT` належить до `NP \ P`.

Зафіксуємо формальні канонічні нумерації:
1. Нумерація детермінованих машин Тюринга поліномного часу: `M₁, M₂, M₃, ...`, де машина `Mᵢ` працює за час, що не перевищує `nⁱ + i`.
2. Нумерація поліномних зведень Карпа: `R₁, R₂, R₃, ...`, де алгоритм зведення `Rᵢ` працює за час, що не перевищує `nⁱ + i`.

Наша мета — побудувати мову `A ∈ NP` таку, що:
1. `A ∉ P` (мова `A` не розв'язується жодною детермінованою поліномною машиною `Mᵢ`).
2. `SAT ≰ₚ A` (мова `SAT` не зводиться поліномно до `A` жодною функцією `Rᵢ`).

## Конструювання функції затримання `H(n)`

Визначимо функцію `H: ℕ → ℕ` рекурсивно. Обчислення значення `H(n)` для входу довжини `n` полягає у симуляції обчислювального процесу протягом строго фіксованого часового бюджету в `n³` кроків.

Значення `H(n)` обчислюється так:
- Для `n = 0` та `n = 1` покладаємо `H(0) = 0` та `H(1) = 0`.
- Для `n > 1`: запускаємо процес обчислення значення `H(n - 1)`. Якщо цей запит виходить за бюджет `n³` кроків, повертаємо `0`. В іншому разі нехай `k = H(n - 1)`.

Далі поведінка залежить від парності `k`:

### Випадок 1: `k = 2i` (парне значення — фаза спростування приналежності до P)
Ми намагаємося довести, що машина `Mᵢ` не розв'язує мову `A`.
Протягом бюджету `n³` кроків ми шукаємо найменший вхідний рядок `z` (у лексикографічному порядку) такий, що:

```
Mᵢ(z) ≠ A(z)
```

де значення `A(z)` обчислюється як `SAT(z)`, оскільки `H(|z|)` на попередніх кроках є парним.
- Якщо такий рядок `z` знайдено в межах `n³` кроків, ми покладаємо `H(n) = k + 1 = 2i + 1` (переходимо до непарної фази).
- Якщо такий рядок `z` не знайдено за `n³` кроків, покладаємо `H(n) = k = 2i`.

### Випадок 2: `k = 2i + 1` (непарне значення — фаза спростування NP-повноти)
Ми намагаємося довести, що зведення `Rᵢ` не зводить `SAT` до `A`.
Протягом бюджету `n³` кроків ми шукаємо найменший вхідний рядок `z` такий, що:

```
z ∈ SAT  і  Rᵢ(z) ∉ A
```

або

```
z ∉ SAT  і  Rᵢ(z) ∈ A
```

де для обчислення належності `Rᵢ(z)` до `A` виконується перевірка парності `H(|Rᵢ(z)|)`.
- Якщо такий рядок `z` знайдено в межах `n³` кроків, ми покладаємо `H(n) = k + 1 = 2i + 2` (переходимо до наступної парної фази).
- Якщо такий рядок `z` не знайдено за `n³` кроків, покладаємо `H(n) = k = 2i + 1`.

## Визначення мови Леднера `A`

Маючи побудовану функцію `H(n)`, мова `A` формально визначається так:

```
A = { x ∈ SAT | H(|x|) є парним числом }
```

Якщо `H(|x|)` є непарним числом, то рядок `x` категорично відхиляється і не належить до `A`.

## Лема 1: Обчислюваність `H(n)` за поліномний час

> **Лема 1.** Значення `H(n)` для довільного `n` можна обчислити за детермінований час `O(n⁴)`.

### Доведення Леми 1
Для обчислення `H(n)` ми послідовно обчислюємо `H(0), H(1), ..., H(n-1)`.
На кожному рівні `m ≤ n` симулятор здійснює пошук контрекземпляра `z` довжини `|z| ≤ m`.
Для кожного випробуваного рядка `z` перевірка `Mᵢ(z) ≠ SAT(z)` або `z ∈ SAT ⇔ Rᵢ(z) ∈ A` вимагає точно визначеного часу:
- Перевірка `z ∈ SAT` для малого рядка `|z| ≤ m` виконується вичерпним пошуком за час `O(2^|z|) = O(2^m)`.
- Проте наш глобальний бюджет симуляції на кроці `n` жорстко обмежений величиною `n³` кроків!

Якщо симуляція перевищує `n³` кроків, алгоритм зупиняється і повертає поточне значення `H(n-1)`.
Таким чином, обчислення `H(n)` виконується за часовою межею:

```
T_H(n) = T_H(n - 1) + O(n³)
= O(n⁴)
```

Оскільки `O(n⁴)` є поліномом від `n`, функція `H(n)` є детерміновано обчислюваною за поліномний час від довжини входу `n`.

## Лема 2: Приналежність `A` до класу NP

> **Лема 2.** Мова `A` належить до класу NP (`A ∈ NP`).

### Доведення Леми 2
Побудуємо недетерміновану машину Тюринга `V_A` для перевірки належності рядка `x` до мови `A`:
1. На вхідному рядку `x` довжини `n = |x|` детерміновано обчислюємо значення `H(n)`. За Лемою 1 це займає `O(n⁴)` часу.
2. Якщо `H(n)` є непарним числом, машина `V_A` негайно відхиляє рядок `x`.
3. Якщо `H(n)` є парним числом, машина `V_A` недетерміновано вгадує сертифікат (істиннісний набір змінних) для булевої формули `x` та перевіряє його за поліномний час `O(n²)`.

Оскільки обидва кроки виконуються за поліномний час від `n`, мова `A` за визначенням належить до `NP`.

## Лема 3: Спростування приналежності `A` до класу P (`A ∉ P`)

> **Лема 3.** Мова `A` не належить до класу P (`A ∉ P`).

### Доведення Леми 3
Доводимо від супротивного. Припустимо, що `A ∈ P`.
Тоді існує детермінована поліномна машина Тюринга `M_k` з нумерації, яка розв'язує мову `A` за поліномний час `n^k + k`.

Розглянемо поведінку функції `H(n)`. Оскільки `H(n)` є монотонно неспадною цілочисельною функцією, існує таке граничне значення `K`, до якого `H(n)` прямує при `n → ∞`.

Розглянемо момент, коли `H(n)` досягає значення `2k` (парного):
- Поки `H(n) = 2k`, для всіх входів `x` відповідної довжини мова `A(x)` за визначенням тотожно збігається з `SAT(x)`.
- Якщо `M_k` правильно розв'язує `A` на всіх вхідних рядках, то `M_k` правильно розв'язує і `SAT` на всіх вхідних рядках.
- Це означає, що `M_k` є поліномним алгоритмом для `SAT`, звідки випливає `SAT ∈ P`.
- Але за початковим припущенням `SAT ∉ P` (бо `P ≠ NP`).

Отже, існує хоча б один вхідний рядок `z_k` такий, що `M_k(z_k) ≠ SAT(z_k)`.
При зростанні `n` бюджет симуляції `n³` неодмінно стане достатнім для того, щоб виявити цей рядок `z_k`.
Як тільки симуляція знаходить `z_k`, функція `H(n)` переключається у значення `2k + 1`.
Це суперечить тому, що `M_k` розв'язує `A` на всіх вхідних рядках.
Отже, `A ∉ P`.

## Лема 4: Спростування NP-повноти мови `A` (`SAT ≰ₚ A`)

> **Лема 4.** Задача `SAT` не зводиться поліномно до `A` (`SAT ≰ₚ A`).

### Доведення Леми 4
Доводимо від супротивного. Припустимо, що `SAT ≤ₚ A` за допомогою поліномної функції зведення `R_k`.
Розглянемо момент, коли функція `H(n)` досягає непарного значення `2k + 1`:
- Поки `H(n) = 2k + 1`, для всіх входів `x` відповідної довжини `H(|x|)` є непарним, а отже, `A(x) = 0` (мова `A` поводиться як порожня мова `∅`).
- Оскільки порожня мова `∅` належить до класу P, якщо `R_k` є правильним зведенням `SAT ≤ₚ A`, то за допомогою `R_k` ми могли б розв'язувати `SAT` за поліномний час (перевіряючи, чи належить `R_k(x)` до `A`).
- Оскільки `SAT ∉ P`, зведення `R_k` неодмінно зробить помилку на деякому рядку `z_k ∈ SAT`, спрямувавши його у рядок `R_k(z_k) ∉ A`.

При достатньо великому `n` симуляційний бюджет `n³` виявить цю помилку зведення `R_k`, і функція `H(n)` переключиться у значення `2k + 2`.
Це означає, що зведення `R_k` не може бути коректним для всіх входів `SAT`.
Отже, `SAT ≰ₚ A`.

З Лем 2, 3 та 4 випливає головне твердження теореми Леднера: мова `A` є NP-проміжною (`A ∈ NP \ P` і `A` не є NP-повною).

## Доведення властивості щільності ступенів складності

Загальніше твердження теореми Леднера стверджує:

> **Теорема (Щільність NP).** Нехай `A` та `B` — дві мови з класу NP такі, що `A <ₚ B` (тобто `A ≤ₚ B` і `B ≰ₚ A`). Тоді існує мова `C ∈ NP` така, що `A <ₚ C <ₚ B`.

### Схема доведення
Замість порожньої мови `∅` та `SAT` ми використовуємо безпосередньо мови `A` та `B`.
Визначимо мову `C` через функцію розредження `H(n)`:

```
C = { x ∈ B | H(|x|) є парним } ∪ { x ∈ A | H(|x|) є непарним }
```

1. Коли `H(n)` є парним, мова `C` локально збігається з `B`. Оскільки `B ≰ₚ A`, жодне поліномне зведення не зможе звести `C` до `A`, що гарантує `C ≰ₚ A`.
2. Коли `H(n)` є непарним, мова `C` локально збігається з `A`. Оскільки `B ≰ₚ A`, мова `B` не зможе звестися до `C`, що гарантує `B ≰ₚ C`.

Таким чином, побудована мова `C` строго лежить між `A` та `B` за складністю зведення (`A <ₚ C <ₚ B`), що доводить щільність частково впорядкованої множини поліномних ступенів у `NP`.
