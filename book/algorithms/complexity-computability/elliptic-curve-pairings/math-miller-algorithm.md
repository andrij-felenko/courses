# 𝔮 Математичне виведення алгоритму Міллера та теорія дивізорів

Математичний апарат алгоритму Міллера та теорії дивізорів опирається на рекурентні співвідношення між раціональними функціями, алгебраїчні доведення теореми Абеля — Якобі для головних дивізорів, аналітичні виводи прямих на кривих Вейєрштрасса, а також на строгому обґрунтуванні властивостей білінійності, невиродженості та знакоперемінності спарювань Вейля, Тейта й Ате.

---

## 1. Алгебраїчна група дивізорів та Якобіан кривої

Нехай `E` — еліптична крива, визначена над скінченним полем `F_q` рівнянням Вейєрштрасса `y² = x³ + a·x + b`. Позначимо через `F̄_q` алгебраїчне замикання поля `F_q`.

Групою дивізорів `Div(E)` називається вільна абелева група, генераторами якої є формальні символи `(P)` для кожної точки `P ∈ E(F̄_q)`:

```
D = ∑_{P ∈ E} n_P · (P),  де n_P ∈ Z, і лише скінченна кількість n_P ≠ 0
```

Для кожного дивізора `D` визначаються дві фундаментальні характеристики:

1. **Ступінь дивізора (англ. *degree*):**
   ```
   deg(D) = ∑_{P ∈ E} n_P  ∈ Z
   ```
2. **Сума дивізора на кривій (англ. *sum map*):**
   ```
   sum(D) = ∑_{P ∈ E} [n_P] P  ∈ E(F̄_q)
   ```

Множина дивізорів ступеня 0 утворює підгрупу `Div⁰(E) = Ker(deg)`.

### Головні дивізори та теорема Абеля — Якобі

Нехай `f ∈ F_q(E)*` — ненульова раціональна функція на кривій `E`. Дивізор функції `f`, позначуваний як `div(f)`, визначається формальною сумою її нулів та полюсів з урахуванням їхніх кратностей:

```
div(f) = ∑_{P ∈ E} ord_P(f) · (P)
```

Де `ord_P(f) > 0`, якщо точка `P` є нулем функції `f` кратності `ord_P(f)`, і `ord_P(f) < 0`, якщо точка `P` є полюсом кратності `|ord_P(f)|`.

**Теорема Абеля — Якобі:** Дивізор `D ∈ Div(E)` є дивізором деякої раціональної функції `f` (тобто є головним дивізором, `D = div(f)`) тоді і тільки тоді, коли виконуються дві необхідні та достатні умови:
1. `deg(D) = 0` (ступінь дивізора дорівнює нулю).
2. `sum(D) = O` (сума точок за правилом додавання на еліптичній кривій дорівнює нейтральному елементу `O`).

Множина всіх головних дивізорів утворює підгрупу `Prin(E) ⊂ Div⁰(E)`. Факторгрупа `Pic⁰(E) = Div⁰(E) / Prin(E)` називається **групою Пікара** (або Якобіаном кривої). За теоремою Абеля — Якобі відображення `sum: Pic⁰(E) → E` є ізоморфізмом груп:

```
Pic⁰(E) ≅ E(F̄_q)
```

## 2. Конструкція функцій Міллера та рекурентна тотожність

Для будь-якого цілого числа `m ∈ Z` та точки `P ∈ E[r]` вимога `deg(D) = 0` та `sum(D) = O` виконується для дивізора:

```
D_m = m · (P) - ( [m]P ) - (m - 1) · (O)
```

**Перевірка умов Абеля — Якобі:**
```
deg(D_m) = m - 1 - (m - 1) = 0
sum(D_m) = [m]P - [m]P - (m-1)O = O
```

Отже, за теоремою Абеля — Якобі для кожного `m` існує єдина (з точністю до множення на константу `c ∈ F_q*`) раціональна функція `f_{m,P}`, дивізором якої є `div(f_{m,P}) = D_m`.

Розглянемо крайні випадки значення `m`:
- При `m = 1`: `D_1 = 1·(P) - (P) - 0·(O) = 0`. Отже, `f_{1,P} = 1`.
- При `m = 2`: `D_2 = 2·(P) - ([2]P) - (O)`. Функція `f_{2,P} = l_{P,P} / v_{[2]P}`.
- При `m = r` (де `[r]P = O`):
  ```
  div(f_{r,P}) = r · (P) - r · (O)
  ```

### Аналітичний вивід прямих на кривій Вейєрштрасса

Для обчислення функцій прямих у циклі Міллера розглянемо дві точки `T = (x_T, y_T)` та `R = (x_R, y_R)`.

1. **Січна пряма `l_{T, R}` при `T ≠ R`:**
   Кутовий коефіцієнт прямої дорівнює:
   ```
   λ = (y_R - y_T) / (x_R - x_T)
   ```
   Рівняння січної прямої через точки `T` та `R`:
   ```
   l_{T, R}(x, y) = (y - y_T) - λ · (x - x_T)
   ```

2. **Дотична пряма `l_{T, T}` при `T = R`:**
   Беручи неявне диференціювання рівняння кривої `y² = x³ + a·x + b`:
   ```
   2 · y · dy = (3 · x² + a) · dx
   λ = dy / dx = (3 · x_T² + a) / (2 · y_T)
   ```
   Рівняння дотичної прямої:
   ```
   l_{T, T}(x, y) = (y - y_T) - λ · (x - x_T)
   ```

3. **Вертикальна пряма `v_{T+R}`:**
   Проходить через точку `T + R = (x_{T+R}, y_{T+R})` та протилежну точку `-(T + R) = (x_{T+R}, -y_{T+R})`:
   ```
   v_{T+R}(x, y) = x - x_{T+R}
   ```

### Вивід рекурентного рівняння Міллера

Розглянемо суму двох цілих чисел `m` та `n`. За означенням дивізори мають вигляд:

```
div(f_{m,P})   = m · (P) - ( [m]P ) - (m - 1) · (O)
div(f_{n,P})   = n · (P) - ( [n]P ) - (n - 1) · (O)
div(f_{m+n,P}) = (m + n) · (P) - ( [m+n]P ) - (m + n - 1) · (O)
```

Обчислимо суму дивізорів `div(f_{m,P}) + div(f_{n,P})`:

```
div(f_{m,P}) + div(f_{n,P})
= (m + n) · (P) - ( [m]P ) - ( [n]P ) - (m + n - 2) · (O)
```

Різниця між `div(f_{m+n,P})` та `div(f_{m,P}) + div(f_{n,P})` дорівнює:

```
div(f_{m+n,P}) - ( div(f_{m,P}) + div(f_{n,P}) )
= ( [m]P ) + ( [n]P ) - ( [m+n]P ) - (O)
```

Зазначимо, що відношення прямих `l_{[m]P, [n]P} / v_{[m+n]P}` має точно такий самий дивізор:

```
div( l_{[m]P, [n]P} / v_{[m+n]P} )
= ( [m]P ) + ( [n]P ) - ( [m+n]P ) - (O)
```

Зіставляючи дивізори, отримуємо **фундаментальне рекурентне співвідношення Міллера**:

```
f_{m+n, P} = f_{m, P} · f_{n, P} · ( l_{[m]P, [n]P} / v_{[m+n]P} )
```

У окремому випадку подвоєння (`m = n`):

```
f_{2m, P} = (f_{m, P})² · ( l_{[m]P, [m]P} / v_{[2m]P} )
```

## 3. Крайові випадки та виродження прямих у циклі Міллера

При виконанні циклу Міллера виникають геометричні виродження, які вимагають окремої математичної обробки:

1. **Додавання протилежних точок `T = -R`:**
   У цьому випадку `T + R = O`. Пряма `l_{T, -T}` стає вертикальною прямою `x = x_T`. Її дивізором є `div(l) = (T) + (-T) - 2·(O)`. Знаменник `v_O` стає тотожно рівним 1. Відношення прямих вироджується у значення `x - x_T`.
2. **Додавання нейтрального елемента `T = O` або `R = O`:**
   Якщо `T = O`, функція прямої дорівнює 1, а поточна точка `T` оновлюється значенням `R`. Множення накопичувача `f` на функцію прямої пропускається.
3. **Крок з кратністю у точці order 2 (`y_T = 0`):**
   У точках кручення 2-го порядку дотична пряма є вертикальною `x = x_T`. Кутовий коефіцієнт `λ` прямує до нескінченності, а пряма додавання збігається з вертикальною прямою, даючи відношення `1`.

## 4. Математичне доведення властивостей спарювання Тейта

Зведене спарювання Тейта визначається як:

```
t_r(P, Q) = f_{r,P}(Q)^( (q - 1) / r )
```

Де `q = p^k`, `P ∈ E(F_p)[r]`, `Q ∈ E(F_{p^k})`.

### Доведення білінійності за першим аргументом

Доведемо, що `t_r(P1 + P2, Q) = t_r(P1, Q) · t_r(P2, Q)`.

За рекурентним співвідношенням Міллера для `m = r` та точок `P1, P2`:
```
f_{r, P1+P2} = f_{r, P1} · f_{r, P2} · ( h / v )
```
Де `h` та `v` — відповідні раціональні функції прямих.

Оцінюючи цю функцію в точці `Q` та підносячи до степеня `e = (q - 1) / r`:
```
t_r(P1 + P2, Q)
= ( f_{r, P1}(Q) · f_{r, P2}(Q) · (h(Q) / v(Q)) )^( (q - 1) / r )  [за рекурентною формулою Міллера для f_{r, P1+P2}]
= f_{r, P1}(Q)^e · f_{r, P2}(Q)^e · (h(Q) / v(Q))^e                 [де e = (q - 1) / r, за дистрибутивністю степеня]
= f_{r, P1}(Q)^e · f_{r, P2}(Q)^e · 1                              [бо (h(Q)/v(Q))^(q-1) = 1 у мультиплікативній групі F_{p^k}*]
= t_r(P1, Q) · t_r(P2, Q)                                           [за означенням спарювання Тейта]
```

Оскільки `h(Q), v(Q) ∈ F_{p^k}*`, піднесення до степеня `(q - 1)` будь-якого ненульового елемента поля `F_{p^k}*` дає `1` (за малою теоремою Ферма для скінченних полів):
```
( h(Q) / v(Q) )^( (q - 1) / r ) = ( (h(Q) / v(Q))^(q - 1) )^(1 / r) = 1^(1 / r) = 1
```

Отже:
```
t_r(P1 + P2, Q) = t_r(P1, Q) · t_r(P2, Q)
```
Що доводить білінійність за першим аргументом.

### Доведення білінійності за другим аргументом

Доведемо, що `t_r(P, Q1 + Q2) = t_r(P, Q1) · t_r(P, Q2)`.

За теоремою Вейля про взаємність дивізорів (англ. *Weil reciprocity theorem*), для двох раціональних функцій `f, g` з взаємно неперетинними носіями дивізорів виконується рівність `f(div(g)) = g(div(f))`.

Застосовуючи взаємність Вейля до функції `f_{r,P}` та функції `g`, дивізором якої є `(Q1 + Q2) - (Q1) - (Q2) + (O)`, ми отримуємо тотожність:

```
f_{r,P}(Q1 + Q2) / ( f_{r,P}(Q1) · f_{r,P}(Q2) ) = g(P)^r
```

Підносячи обидві частини до степеня `(q - 1) / r`:

```
( f_{r,P}(Q1 + Q2) / ( f_{r,P}(Q1) · f_{r,P}(Q2) ) )^( (q - 1) / r )
= ( g(P)^r )^( (q - 1) / r )  [за тотожністю взаємності Вейля для дивізорів]
= g(P)^(q - 1)                [за скороченням показників степеня r · (1/r)]
= 1                           [за малою теоремою Ферма у полі F_{p^k}*]
```

Звідси негайно випливає:

```
t_r(P, Q1 + Q2) = t_r(P, Q1) · t_r(P, Q2)
```

## 5. Конкретний приклад розкладу дивізорів на кривій Вейєрштрасса

Для закріплення обчислимо явний вигляд дивізора раціональної функції `f(x, y) = (y - 1) / x` на кривій `E: y² = x³ + 1` над полем `F_{19}`.

1. **Нулі та полюси функції `y - 1`:**
   Рівняння `y = 1` перетинає криву `y² = x³ + 1` при `1 = x³ + 1 ⇒ x³ = 0 ⇒ x = 0` (потрійний корінь).
   Отже, точка `P = (0, 1)` є нулем функції `y - 1` кратності 3. На нескінченності `O` функція має полюс кратності 3.
   ```
   div(y - 1) = 3 · ( (0, 1) ) - 3 · (O)
   ```

2. **Нулі та полюси функції `x`:**
   Рівняння `x = 0` перетинає криву при `y² = 1 ⇒ y = 1` та `y = -1 ≡ 18 (mod 19)`.
   Отже, точки `(0, 1)` та `(0, 18)` є нулями кратності 1. На нескінченності `O` функція `x` має полюс кратності 2.
   ```
   div(x) = ( (0, 1) ) + ( (0, 18) ) - 2 · (O)
   ```

3. **Дивізор відношення `f(x, y) = (y - 1) / x`:**
   ```
   div( (y - 1) / x ) = div(y - 1) - div(x)
   = [ 3·((0, 1)) - 3·(O) ] - [ ((0, 1)) + ((0, 18)) - 2·(O) ]
   = 2 · ( (0, 1) ) - ( (0, 18) ) - (O)
   ```

Отриманий дивізор задовольняє умови Абеля — Якобі:
- `deg = 2 - 1 - 1 = 0`.
- `sum = 2·(0, 1) - (0, 18) = (0, 18) - (0, 18) = O`.

Цей розклад у точності відповідає функції `f_{2,P}` для точки `P = (0, 1)` порядку `r = 3`.

## 6. Математичне обґрунтування спарювання Optimal Ate та решіткова оптимізація

У спарюванні Ате аргументи міняються місцями: `Q ∈ G2 = E'(F_{p^{k/d}})[r]`, `P ∈ G1 = E(F_p)[r]`.

Характеристичне рівняння ендоморфізму Фробеніуса `π_p` має вигляд:
```
π_p(Q) = [p]Q
```

Оскільки `r | (p^k - 1)`, виразимо `p` через `t` (слід Фробеніуса): `p ≡ t - 1 (mod r)`.
Позначивши `T = t - 1`, ми маємо `[T]Q = [p]Q` у групі `G2`.

У спарюванні Optimal Ate пошук мінімального циклу Міллера зводиться до знаходження найкоротшого вектора у решітці тотожностей `L ⊂ Z²`, утвореній векторами `v = (c_0, c_1)` такими, що:

```
c_0 + c_1 · p ≡ 0 (mod r)
```

За допомогою алгоритму редукції решіток LLL (Ленстра — Ленстра — Ловас) знаходять вектор із нормами `|c_0|, |c_1| O(r^{1/φ(k)})`.

Тоді раціональна функція спарювання подається у вигляді:

```
f_{c_0, Q}(P) · ( f_{c_1, Q}(P) )^p · l_{[c_0]Q, [c_1·p]Q}(P)
```

Оскільки піднесення до степеня `p` у полях `F_{p^k}` зводиться до швидкого автоморфізму Фробеніуса, обчислення циклу Міллера виконується за `log2(|c_0|) ≈ log2(r) / φ(k)` кроків.

Для кривих BLS12 порядок `r` має довжину 255 бітів, а слід Фробеніуса `T` параметризується значенням `x` довжиною всього 64 біти. Математична заміна `r` на `T` дає скорочення довжини алгоритму Міллера з 255 ітерацій до 64 ітерацій, що математично доводить чотирикратне прискорення циклу Міллера порівняно зі спарюванням Тейта.
