# 🧮 Математичний аналіз NW-генератора та лема про реконструкцію

Математична краса та сила генератора Нісана–Вігдерсона (NW PRG) полягає в довідній зведеній схемі: якщо існує статистичний розрізнювач, який помічає відхилення псевдовипадкового виходу NW-генератора від справжнього хаосу, то цей розрізнювач можна ефективно перебудувати в малу булеву схему, яка обчислює вихідну «складну» функцію. Цей математичний екскурс містить точне формальне визначення комбінаторних дизайнів, їхню явну алгебраїчну побудову над скінченними полями Галуа, формальний аналіз генератора NW та покрокове математичне виведення леми про реконструкцію (англ. *reconstruction lemma*).

---

## 1. Комбінаторні дизайни (Combinatorial Designs)

Основою для розширення короткої насінини `z` у довгий псевдовипадковий рядок `y` є спеціальне сімейство підмножин, перетин яких строго обмежений.

### Формальне означення

Сімейство підмножин `S₁, S₂, ..., Sⴘ ⊂ {1, 2, ..., d}` називається `(m, l, d, γ)`-дизайном, якщо виконуються дві умовні вимоги:
1. Для кожного індексу `i ∈ {1, ..., m}` потужність підмножини строго дорівнює `l`: `|Sᵢ| = l`.
2. Для будь-якої пари різних індексів `i ≠ j` розмір їхнього перетину не перевищує задану межу `γ`: `|Sᵢ ∩ Sⱼ| ≤ γ`.

Параметри `m`, `l`, `d`, `γ` підбираються залежно від потрібного ступеня дерандомізації. У класичному варіанті для дерандомізації ймовірнісного класу `BPP` до детермінованого `P` обирають `l = c · log m`, `γ = log m`, що дозволяє досягти довжини вхідного насіння `d = O(log m)`.

### Явна побудова дизайнів через багаточлени над скінченними полями GF(q)

Для доведення існування таких підмножин Нісан та Вігдерсон запропонували точний алгебраїчний алгоритм побудови дизайнів із використанням скінченних полів Галуа `GF(q)`.

Нехай `q = 2ᵏ` — потужність скінченного поля. Розглянемо універсальну множину елементів `U = GF(q) × GF(q)`. Кількість елементів універсальної множини дорівнює `d = |U| = q²`.

Для створення кожної підмножини `Sᵢ` використаємо багаточлен `Pᵢ(x)` степеня не вище `r` над полем `GF(q)`:

```
Pᵢ(x) = a₀ + a₁·x + a₂·x² + ... + aᵣ·xʳ,   де aⱼ ∈ GF(q)
```

Зазначимо, що загальна кількість різних багаточленів степеня не вище `r` над `GF(q)` дорівнює `qʳ⁺¹`. Покладемо кількість підмножин `m = qʳ⁺¹`.

Визначимо підмножину `Sᵢ` як графік багаточлена `Pᵢ(x)` над усім полем `GF(q)`:

```
Sᵢ = { (x, Pᵢ(x)) ∣ x ∈ GF(q) } ⊂ GF(q) × GF(q)
```

Перевіримо виконання обох умов дизайну:

1. **Розмір підмножини**: Оскільки змінна `x` приймає `q` різних значень у полі `GF(q)`, кожен графік містить рівно `q` точок: `|Sᵢ| = q = l`.
2. **Обмеження перетину**: Розглянемо перетин двох різних підмножин `Sᵢ` та `Sⱼ`, заданих багаточленами `Pᵢ(x)` та `Pⱼ(x)` відповідно (`Pᵢ ≠ Pⱼ`). Точка `(x, y)` належить перетину `Sᵢ ∩ Sⱼ` тоді й лише тоді, коли `Pᵢ(x) = Pⱼ(x)`, що еквівалентно умові:

```
(Pᵢ - Pⱼ)(x) = 0
```

Оскільки різниця `Pᵢ - Pⱼ` є ненульовим багаточленом степеня не вище `r`, за основною теоремою алгебри для скінченних полів він може мати **не більше ніж `r` коренів** у полі `GF(q)`. Отже:

```
|Sᵢ ∩ Sⱼ| ≤ r = γ
```

Таким чином, алгебраїчна побудова над `GF(q)` дає явний `(qʳ⁺¹, q, q², r)`-дизайн з параметрами `d = q²`, `l = q`, `m = qʳ⁺¹`, `γ = r`.

## 2. Формальна конструкція генератора NW

Нехай `f: {0,1}ˡ → {0,1}` — булева функція від `l` змінних (таблиця істинності довжини `2ˡ`), а `S = (S₁, ..., Sⴘ)` — комбінаторний `(m, l, d, γ)`-дизайн.

Відображення `NW_f: {0,1}ᵈ → {0,1}ᵐ` задається формальним співвідношенням:

```
NW_f(z) = ( f(z|S₁),  f(z|S₂),  ...,  f(z|Sⴘ) )
```

де `z|Sᵢ` позначає проекцію вектора `z ∈ {0,1}ᵈ` на координати, визначені підмножиною `Sᵢ`. Оскільки `|Sᵢ| = l`, вектор `z|Sᵢ` має довжину `l`, і застосування функції `f` є коректно визначеним.

```
Вхідне насіння z (d біт):   [ z₁ | z₂ | z₃ | z₄ | z₅ | z₆ | ... | zᵈ ]
                                 │      │         │
Виділення проекції z|Sᵢ:         [ z₂   │   z₄    │   z₆ ]  (l біт)
                                        ▼
Обчислення базової функції:         f(z|Sᵢ) ──► біт yᵢ
```

## 3. Лема про реконструкцію (Reconstruction Lemma)

Головне математичне твердження про генератор Нісана–Вігдерсона полягає у тому, що обчислювальна нестійкість генератора дозволяє обчислити базову функцію `f` новою малою булевою схемою.

**Теорема (Нісан, Вігдерсон).** Нехай `D: {0,1}ᵐ → {0,1}` — булева схема розміру `S`, яка розрізняє вихід `NW_f(z)` від рівномірно випадкового рядка `r ∈_R {0,1}ᵐ` з перевагою принаймні `ε`:

```
| Pr_{z}[ D(NW_f(z)) = 1 ] - Pr_{r}[ D(r) = 1 ] | ≥ ε
```

Тоді існує булева схема `C` для обчислення базової функції `f: {0,1}ˡ → {0,1}` розміру:

```
Size(C) ≤ Size(D) + m · 2gamma
```

## 4. Покрокове доведення через гібридний аргумент Яо

Доведення теореми розбивається на три послідовні математичні етапи.

### Етап 1: Побудова гібридних розподілів та телескопічний розклад

Визначимо родинний масив з `m + 1` гібридних рядків `H₀, H₁, ..., Hⴘ` над множиною бітових послідовностей `{0,1}ᵐ`. Для кожного індексу `i ∈ {0, ..., m}` гібридний рядок `Hᵢ` будується поєднанням перших `i` бітів від NW PRG та останніх `m - i` випадкових бітів:

```
Hᵢ = ( f(z|S₁),  f(z|S₂),  ...,  f(z|Sᵢ),  rᵢ₊₁,  rᵢ₊₂,  ...,  rⴘ )
```

Зокрема:
- `H₀ = (r₁, r₂, ..., rⴘ) = r` (абсолютно випадковий рядок).
- `Hⴘ = (f(z|S₁), f(z|S₂), ..., f(z|Sⴘ)) = NW_f(z)` (повний вихід псевдовипадкового генератора).

За вихідною умовою теореми різниця ймовірностей для крайніх гібридних розподілів становить `ε`:

```
| Pr[D(Hⴘ) = 1] - Pr[D(H₀) = 1] | ≥ ε
```

Розгорнемо цю різницю через телескопічну суму та застосуємо нерівність трикутника:

```
| Pr[D(Hⴘ) = 1] - Pr[D(H₀) = 1] |
= | ∑_{i=1}^m ( Pr[D(Hᵢ) = 1] - Pr[D(Hᵢ₋₁) = 1] ) |
≤ ∑_{i=1}^m | Pr[D(Hᵢ) = 1] - Pr[D(Hᵢ₋₁) = 1] |
```

Звідси за математичним принципом Діріхле (pigeonhole principle) обов'язково існує принаймні один фіксований індекс `i ∈ {1, ..., m}`, для якого сусідні гібриди розрізняються з перевагою не меншою за `ε / m`:

```
| Pr[D(Hᵢ) = 1] - Pr[D(Hᵢ₋₁) = 1] | ≥ ε / m
```

### Етап 2: Перехід від розрізнення до передбачення біта (Лема Яо)

Зафіксуємо знайдений індекс `i`. Порівняємо між собою сусідні гібридні рядки `Hᵢ` та `Hᵢ₋₁`:
- `Hᵢ   = ( f(z|S₁), ..., f(z|Sᵢ₋₁),  f(z|Sᵢ), rᵢ₊₁, ..., rⴘ )`
- `Hᵢ₋₁ = ( f(z|S₁), ..., f(z|Sᵢ₋₁),  rᵢ,       rᵢ₊₁, ..., rⴘ )`

Вони є абсолютно однаковими у всіх позиціях, окрім `i`-тої: у `Hᵢ` на цій позиції стоїть детерміноване значення `f(z|Sᵢ)`, а у `Hᵢ₋₁` — незалежний рівномірно випадковий біт `rᵢ`.

За універсальною лемою Яо про предиктор біта, якщо схема розрізняє справжній біт `f(z|Sᵢ)` від випадкового біта `rᵢ`, її можна безпосередньо перетворити на передбачувач (англ. *predictor*), який обчислює `f(z|Sᵢ)` за рештою бітів із ймовірністю успіху:

```
Pr[ Predictor(f(z|S₁), ..., f(z|Sᵢ₋₁), rᵢ₊₁, ..., rⴘ) = f(z|Sᵢ) ] ≥ 1/2 + ε / m
```

### Етап 3: Фіксація зовнішніх змінних та оцінка розміру нової схеми

Позначимо вхід базової функції `f`, який ми прагнемо обчислити, як вектор `x = z|Sᵢ ∈ {0,1}ˡ`.

Зауважимо, що всі біти вхідного насіння `z`, які не входять до підмножини `Sᵢ` (тобто біти `z` з індексами поза `Sᵢ`), а також суфіксні випадкові біти `rᵢ₊₁, ..., rⴘ` можна зафіксувати деякими постійними константами `0` або `1`. За імовірнісним методом Середнього Значення (Averaging Argument) завжди існує такий конкретний вибір фіксованих констант, який зберігає чи навіть збільшує ймовірність правильного передбачення біта:

```
Pr_{x ∈ {0,1}ˡ}[ Predictor_fixed(x) = f(x) ] ≥ 1/2 + ε / m
```

Згадаймо ключовий інваріант комбінаторного дизайну: для будь-якого `j < i` розмір перетину підмножин підпорядковується межі `|Sⱼ ∩ Sᵢ| ≤ γ`.

Це означає, що після фіксації всіх змінних насіння поза `Sᵢ`, значення проекційного входу `z|Sⱼ` залежить лише від тими бітами, які входять у перетин `Sⱼ ∩ Sᵢ`. А кількість таких вільних змінних не перевищує `γ`!

Отже, кожна з префіксних функцій `f(z|Sⱼ)` для `j < i` перетворюється на булеву функцію від **не більше ніж `γ` змінних** основного входу `x`.

```
Кількість змінних у кожній префіксній функції f(z|Sⱼ) для j < i:   |Sⱼ ∩ Sᵢ| ≤ γ
Розмірність таблиці істинності кожної такої функції:                2gamma біт
Максимальна схемна складність обчислення однієї функції:           ≤ 2gamma вентилів
```

Загальна кількість префіксних функцій `j < i` обмежена числом `m`. Отже, для обчислення всіх вхідних сигналів перед подачею у схему розрізнювача `D` потрібно побудувати додаткову сітку вентилів розміру:

```
Size(додаткових вентилів) ≤ (i - 1) · 2gamma ≤ m · 2gamma
```

Об'єднуючи схему розрізнювача `D` та додаткову сітку вентилів для обчислення префіксних функцій, ми отримуємо підсумкову булеву схему `C` для точного обчислення значення `f(x)`:

```
Size(C) = Size(D) + Size(додаткових вентилів)
        ≤ Size(D) + m · 2gamma
```

Це повністю завершує формальне математичне доведення леми про реконструкцію.

## 5. Асимптотичні наслідки для теорії складності

Отримана лема про реконструкцію дає математичний інструмент для дерандомізації класів обчислень.

Якщо обрати базову функцію `f ∈ E = DTIME(2^(O(n)))` з граничною схемною складністю `Size(f) = 2^(Ω(l))` та встановити розмір підмножини `l = c · log m` і межу перетину `γ = log m`, то верхня межа схемного розміру складе:

```
Size(C) ≤ Size(D) + m · 2^(log m) = Size(D) + m²
```

Якби існував розрізнювач `D` поліноміального розміру `Size(D) ≤ poly(m)`, то схема `C` мала б поліноміальний розмір `poly(m) = poly(2ˡ) = 2^(O(l))`, що вступає у суперечність з експоненціальною складністю обраної функції `f`.

Отже, жоден розрізнювач поліноміального розміру не здатний зламати NW-генератор, і його вихід є абсолютним псевдовипадковим джерелом для всіх схем розміру `poly(m)`.
