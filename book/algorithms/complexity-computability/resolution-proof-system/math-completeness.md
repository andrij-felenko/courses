# 🧮 Обґрунтованість, спростувальна повнота та теорема про ширину резолюції

Математичний фундамент системи резолюційних виводів спирається на строгий зв'язок між синтаксичним виводом (символьне застосування синтаксичного правила елімінації) та семантичною істинністю (моделі булевих інтерпретацій). Ця вставка містить формальне доведення фундаментальних теорем обґрунтованості (корректності) та спростувальної повноти резолюції, математичний аналіз геометричної різниці між деревним і графним виводом, а також повне виведення теореми Бен-Сассона — Вігдерсона про зв'язок ширини та довжини доведення.

## 1. Теорема про обґрунтованість (Soundness)

Обґрунтованість означає, що синтаксичний резолюційний вивід є семантично правильним і не здатний генерувати хибних наслідків з істинних посилок.

**Теорема 1 (Обґрунтованість резолюційного кроку).** Нехай `C₁` та `C₂` — два диз'юнкти у КНФ, що містять протилежні літерали за змінною `x`:

```
C₁ = A ∨ x
C₂ = B ∨ ¬x
```

де `A` та `B` — довільні (можливо порожні) диз'юнкції літералів. Тоді резольвента `C = Res(C₁, C₂) = A ∨ B` є семантичним наслідком множини `{C₁, C₂}`. Позначається: `{C₁, C₂} ⊨ A ∨ B`.

*Доведення.* Нехай `I: Var → {0, 1}` — довільна булева інтерпретація (призначення істинності змінним), яка задовольняє обидва початкові диз'юнкти: `I(C₁) = 1` та `I(C₂) = 1`.

Розглянемо два можливі та виключні випадки для значення змінної `x` в інтерпретації `I`:

1. **Випадок 1: `I(x) = 0`**.
   Оскільки `I(C₁) = I(A ∨ x) = 1`, а `I(x) = 0`, за означенням булевої диз'юнкції значення `I(A)` мусить дорівнювати `1`. Звідси `I(A ∨ B) = I(A) ∨ I(B) = 1 ∨ I(B) = 1`.

2. **Випадок 2: `I(x) = 1`**.
   Тоді заперечення `I(¬x) = 0`. Оскільки `I(C₂) = I(B ∨ ¬x) = 1`, а `I(¬x) = 0`, значення `I(B)` мусить дорівнювати `1`. Звідси `I(A ∨ B) = I(A) ∨ I(B) = I(A) ∨ 1 = 1`.

В обох можливих випадках значення `I(A ∨ B) = 1`. Отже, кожна інтерпретація, що робить істинними диз'юнкти `C₁` та `C₂`, гарантовано робить істинною їхню резольвенту `A ∨ B`. Теорему доведено.

**Наслідок 1.** Якщо множина дизюнктів `F` виводить порожній диз'юнкт `⊥` шляхом послідовності резолюційних кроків `F ⊢_Res ⊥`, то формула `F` є нездійсненною (`F ⊨ ⊥`).

*Доведення математичною індукцією.* Проведемо індукцію за довжиною виводу `k` (кількістю кроків резолюції).

*База індукції (`k = 0`).* Порожній диз'юнкт міститься у початковій формулі: `⊥ ∈ F`. Оскільки порожній диз'юнкт `⊥` не містить літералів, за означенням для будь-якої інтерпретації `I` маємо `I(⊥) = 0`. Отже, формула `F` не має жодної моделі і є нездійсненною (`F ⊨ ⊥`).

*Крок індукції.* Припустимо, що всі диз'юнкти `C₁, C₂, ..., Cₘ`, виведені на кроках від 1 до `m`, є семантичними наслідками `F`. Нехай `C_{m+1}` — диз'юнкт, виведений на кроці `m + 1` з дизюнктів `C_i` та `C_j` (де `i, j ≤ m`). За Теоремою 1, `{C_i, C_j} ⊨ C_{m+1}`. За припущенням індукції, `F ⊨ C_i` та `F ⊨ C_j`. За транзитивністю відношення семантичного наслідку, `F ⊨ C_{m+1}`.

Якщо результатом виводу є `C_k = ⊥`, то `F ⊨ ⊥`, тобто формула `F` не має жодної моделі.

## 2. Теорема про спростувальну повноту (Refutational Completeness)

Система резолюцій не є дедуктивно повною в загальному сенсі: з порожньої множини дизюнктів `∅` або з `{A}` неможливо вивести тавтологію `B ∨ ¬B`, оскільки резолюція лише зменшує або комбінує наявні літерали і не має аксіом. Проте резолюція є **спростувально повною** (refutationally complete): для будь-якої нездійсненної КНФ-формули існує резолюційний вивід порожнього диз'юнкта.

**Теорема 2 (Спростувальна повнота резолюції).** Нехай `F` — скінченна множина дизюнктів у КНФ від `n` булевих змінних `Var = {x₁, x₂, ..., xₙ}`. Якщо `F` нездійсненна (`F ⊨ ⊥`), то існує скінченний резолюційний вивід порожнього диз'юнкта з `F`:

```
F ⊢_Res ⊥
```

*Доведення.* Проведемо доведення математичною індукцією за кількістю змінних `n` у формулі `F`.

**База індукції (`n = 0` або `n = 1`).**
- Якщо `n = 0`, єдиною нездійсненною множиною дизюнктів є множина, що містить порожній диз'юнкт: `F = {⊥}`. Вивід складається з 0 кроків.
- Якщо `n = 1`, змінна одна (`x₁`). Єдиною нездійсненною множиною дизюнктів є `F = {{x₁}, {¬x₁}}`. Застосовуючи 1 крок резолюції за змінною `x₁`:

```
C₁ = x₁
C₂ = ¬x₁
------------------- [Res за x₁]
Res(C₁, C₂) = ⊥
```

Базу індукції доведено.

**Крок індукції.** Припустимо, що теорема виконується для всіх нездійсненних КНФ-формул з кількістю змінних, меншою або рівною `n - 1`. Доведемо її для формули `F` від `n` змінних `{x₁, x₂, ..., xₙ}`.

Зафіксуємо змінну `xₙ` та розглянемо дві звужені (профіксовані) формули:
- `F|_{xₙ=0}`: отримано вилученням усіх диз'юнктів, що містять `¬xₙ`, та видаленням літерала `xₙ` з решти диз'юнктів.
- `F|_{xₙ=1}`: отримано вилученням усіх диз'юнктів, що містять `xₙ`, та видаленням літерала `¬xₙ` з решти диз'юнктів.

Формально, для довільного диз'юнкта `C` операція фіксації визначається як:

```
C|_{xₙ=0} = C \ {xₙ},   якщо ¬xₙ ∉ C;  інакше 1 (вилучається)
C|_{xₙ=1} = C \ {¬xₙ},  якщо xₙ ∉ C;   інакше 1 (вилучається)
```

Оскільки початкова формула `F` нездійсненна, обидві підформули `F|_{xₙ=0}` та `F|_{xₙ=1}` також є нездійсненними (якби одна з них мала модель `I'`, то розширення `I' ∪ {xₙ=0}` або `I' ∪ {xₙ=1}` дало б модель для `F`).

Оскільки `F|_{xₙ=0}` та `F|_{xₙ=1}` містять лише `n - 1` змінних, за припущенням індукції для кожної з них існують резолюційні виводи порожнього диз'юнкта:

```
π₀: F|_{xₙ=0} ⊢_Res ⊥
π₁: F|_{xₙ=1} ⊢_Res ⊥
```

Відновимо фіксацію змінної `xₙ` у цих двох виводах:
1. Якщо у виводі `π₀` повернути назад вилучений літерал `xₙ`, ми отримаємо валідний резолюційний вивід з початкової формули `F`, результатом якого буде або порожній диз'юнкт `⊥`, або одиничний диз'юнкт `{xₙ}`:
   ```
   F ⊢_Res {xₙ}   (або F ⊢_Res ⊥)
   ```
2. Аналогічно, якщо у виводі `π₁` повернути назад вилучений літерал `¬xₙ`, ми отримаємо валідний резолюційний вивід з `F`, результатом якого буде або `⊥`, або одиничний диз'юнкт `{¬xₙ}`:
   ```
   F ⊢_Res {¬xₙ}  (або F ⊢_Res ⊥)
   ```

Якщо хоча б один із двох виводів сформував `⊥`, доведення завершено. Якщо ж виводи сформували диз'юнкти `{xₙ}` та `{¬xₙ}`, то останній додатковий крок резолюції дає:

```
C₁ = xₙ
C₂ = ¬xₙ
------------------- [Остаточна резолюція]
Res(C₁, C₂) = ⊥
```

Отже, ми побудували повний резолюційний вивід `F ⊢_Res ⊥`. За принципом математичної індукції теорему доведено для будь-якого `n`.

## 3. Співвідношення складності Деревної (Tree) та Графної (DAG) Резолюції

Формально резолюційний вивід описується спрямованим ациклічним графом (DAG), де вершинами є диз'юнкти, вхідні ребра ведуть із батьківських дизюнктів, а єдиний вихідний сток (sink) є порожнім диз'юнктом `⊥`.

Введемо два показники складності спростування формули `F`:
- **Розмір графної резолюції `S_dag(F ⊢ ⊥)`**: мінімальна кількість диз'юнктів у довільному резолюційному DAG-виводі.
- **Розмір деревної резолюції `S_tree(F ⊢ ⊥)`**: мінімальна кількість диз'юнктів у резолюційному виводі, граф якого є деревом (кожна проміжна резольвента має вихідний степінь 1 і не може перевикористовуватися).

**Теорема 3 (Експоненційний розрив між деревним і графним виводом).** Існує послідовність КНФ-формул `Fₙ` (зокрема, модифіковані формули Цейтіна на графах), для яких розмір графної резолюції є поліноміальним, тоді як розмір деревної резолюцій є строго експоненційним:

```
S_dag(Fₙ ⊢ ⊥) = O(n)
S_tree(Fₙ ⊢ ⊥) = 2^{Ω(n)}
```

*Доведення (ідея).* У деревній резолюції будь-який проміжний диз'юнкт `C`, необхідний для підтвердження декількох наступних гілок, мусить виводитися заново з початкових диз'юнктів `F`. Це спричиняє рекурсивне дублювання дерев підвиводу й експоненційне зростання загальної кількості вузлів дерева `2^h`, де `h` — висота дерева. Включення пам'яті для зберігання резольвент перетворює дерево на DAG і знижує складність з `2^{Ω(n)}` до `O(n)`.

## 4. Теорема Бен-Сассона — Вігдерсона про Ширину та Довжину

Оцінка нижніх меж довжини виводів прямим аналізом графа є надзвичайно складною комбінаторною задачею. У 1999 році Елі Бен-Сассон та Аві Вігдерсон запропонували потужний аналітичний метод, що зводить оцінку **довжини** (кількості диз'юнктів) до оцінки **ширини** (максимальної кількості літералів у диз'юнкті).

Введемо поняття ширини:
- Ширина диз'юнкта `w(C)`: кількість літералів у `C`.
- Ширина формули `w(F)`: `max { w(C) | C ∈ F }`.
- Ширина спростування `w(F ⊢ ⊥)`: мінімальне значення `W` таке, що існує вивід `F ⊢ ⊥`, у якому кожен диз'юнкт має ширину `w(C) ≤ W`.

**Теорема 4 (Бен-Сассон — Вігдерсон, 1999).** Нехай `F` — нездійсненна `k`-КНФ формула від `n` змінних (де `w(F) ≤ k`). Тоді мінімальний розмір графного резолюційного спростування `S_dag(F ⊢ ⊥)` пов'язаний із шириною спростування `w(F ⊢ ⊥)` нерівністю:

```
S_dag(F ⊢ ⊥) ≥ exp( Ω( ((w(F ⊢ ⊥) - w(F))²) / n ) )
```

А для деревного виводу зв'язок є ще суворішим:

```
S_tree(F ⊢ ⊥) ≥ 2^{w(F ⊢ ⊥) - w(F)}
```

*Виведення та математичний зміст.*
Бен-Сассон та Вігдерсон довели, що якщо формула `F` має коротке спростування довжини `S`, то з нього можна сконструювати нове спростування, ширина якого не перевищує:

```
w(F ⊢ ⊥) ≤ w(F) + O( √(n · ln S) )
```

Виражаючи `S` через ширину `w(F ⊢ ⊥)`, отримаємо:

```
ln S ≥ Ω( ((w(F ⊢ ⊥) - w(F))²) / n )
S ≥ exp( Ω( ((w(F ⊢ ⊥) - w(F))²) / n ) )
```

*Практичне значення.* Нерівність Бен-Сассона — Вігдерсона дає універсальний алгоритм доведення нижніх меж складності:
1. Щоб довести, що формула `F` вимагає експоненційної кількості кроків резолюції (`S_dag = 2^{Ω(n)}`), достатньо показати, що будь-яке спростування `F` мусить містити хоча б один «широкий» диз'юнкт із шириною `w(C) = Ω(n)`.
2. Це дало спрощене і красиве доведення експоненційної нижньої межі Хакена для принципу дірочок Діріхле `PHP_n^{n+1}` та формул Цейтіна, перетворивши важкі симетричні підрахунки Хакена на аналіз геометричної ширини диз'юнктів.
