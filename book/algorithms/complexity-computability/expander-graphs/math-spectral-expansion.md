# 🧮 Математичний апарат спектральної розширюваності та нерівності Чігера

Ця математична вставка містить строге виведення алгебраїчних та спектральних властивостей `d`-регулярних графів-розширювачів. У ній розкрито математичний зв'язок між комбінаторним ізопериметричним числом (константою Чігера `h(G)`), спектральною щілиною матриці суміжності `d - λ₂` та лемою про змішування розширювачів (Expander Mixing Lemma).

## Алгебраїчне представлення та коефіцієнт Реле

Нехай `G = (V, E)` — неорієнтований `d`-регулярний граф із `n = |V|` вершинами. Позначимо через `A` його `n × n` матрицю суміжності:

```
A[i, j] = 1, якщо (i, j) ∈ E
A[i, j] = 0, якщо (i, j) ∉ E
```

Оскільки граф є `d`-регулярним, сума елементів у кожному рядку матриці `A` дорівнює `d`. Нормована матриця перехідних імовірностей марківського блукання `M` визначається як:

```
M = (1 / d) · A
```

Матриця `A` є дійсною та симетричною (`A = Aᵀ`), тому за спектральною теоремою вона має `n` дійсних власних значень `λ₁ ≥ λ₂ ≥ ... ≥ λ♮` та повний ортонормований базис власних векторів `v₁, v₂, ..., v♮` у просторі `ℝⁿ`.

Властивості спектра `A`:
1. **Перше власне значення:** `λ₁ = d`. Йому відповідає власна функція (вектор) `v₁ = (1 / √n) · (1, 1, ..., 1)ᵀ`, оскільки:
   ```
   A · (1, 1, ..., 1)ᵀ = d · (1, 1, ..., 1)ᵀ
   ```
2. **Обмеженість спектра:** Для всіх `i = 1, ..., n` виконується `-d ≤ λᵢ ≤ d`.
3. **Двочастковість:** `λ♮ = -d` тоді й лише тоді, коли граф `G` є двочастковим.

Нормований оператор Лапласа (Laplacian Matrix) `L` визначається як:

```
L = I - M = I - (1 / d) · A
```

Його власні значення є нормованими й дорівнюють `νᵢ = 1 - (λᵢ / d)`. Зокрема, найменше власне значення `ν₁ = 1 - d/d = 0`, а друге власне значення `ν₂ = 1 - (λ₂ / d)` відповідає спектральні щілині графа.

Для будь-якого ненульового вектора `f ∈ ℝⁿ` відношення Реле (Rayleigh Quotient) для матриці `M` визначається як:

```
R(f) = ⟨f, M f⟩ / ⟨f, f⟩ = (fᵀ M f) / (fᵀ f)
```

За теоремою Куранта — Фішера, друге за величиною власне значення `μ₂ = λ₂ / d` описується як максимум відношення Реле на ортогональному доповненні до першого власного вектора `v₁`:

```
μ₂ = max { (fᵀ M f) / (fᵀ f)  |  f ⊥ v₁, f ≠ 0 }
```

Умова `f ⊥ v₁` означає, що сума елементів вектора дорівнює нулю: `∑ᵢ f[i] = 0`.

## Доведення та аналіз Нерівності Чігера

Комбінаторна константа Чігера `h(G)` (ізопериметричне число графа) вимірює найгірше відносне розширення серед усіх підмножин вершин `S` обсягом не більше `n/2`:

```
h(G) = min_{0 < |S| ≤ n/2} |δ(S)| / |S|
```

де `δ(S) = { (u, v) ∈ E | u ∈ S, v ∉ S }` — кількість ребер, які перетинають межу множини `S`.

Нерівність Чігера встановлює фундаментальний двосторонній зв'язок між алгебраїчною спектральною щілиною `γ = d - λ₂` та комбінаторним розширенням `h(G)`:

```
(d - λ₂) / 2 ≤ h(G) ≤ √(2 · d · (d - λ₂))
```

### 1. Доведення нижньої межі (Легша частина)

Оцінимо `h(G)` знизу через `(d - λ₂) / 2`.
Нехай `S ⊂ V` — довільна множина вершин розміром `s = |S| ≤ n/2`. Побудуємо індикаторний вектор `f ∈ ℝⁿ`:

```
f[u] = n - s,  якщо u ∈ S
f[u] = -s,     якщо u ∉ S
```

Перевіримо ортогональність `f ⊥ v₁`:
```
∑ᵤ f[u] = s · (n - s) + (n - s) · (-s) = 0
```

Обчислимо скалярний добуток `⟨f, f⟩`:
```
⟨f, f⟩ = ∑ᵤ f[u]²
       = s · (n - s)² + (n - s) · s²             [розклад суми за двома частками S та V\S]
       = s · (n - s) · (n - s + s)                [винесення спільного множника s·(n-s)]
       = n · s · (n - s)                          [спрощення виразу: n-s+s = n]
```

Тепер обчислимо квадратичний вираз для Лапласіана `⟨f, (d I - A) f⟩`:
```
⟨f, (d I - A) f⟩ = (1/2) · ∑_{(u,v) ∈ E} (f[u] - f[v])²
```

Для кожної пари вершин `(u, v)`:
* Якщо `u, v ∈ S` або `u, v ∉ S`, різниця `f[u] - f[v] = 0`.
* Якщо ребро `(u, v)` перетинає межу `δ(S)` (тобто `u ∈ S, v ∉ S`), різниця `f[u] - f[v] = (n - s) - (-s) = n`.

Отже:
```
⟨f, (d I - A) f⟩ = (1/2) · |δ(S)| · n² + (1/2) · |δ(S)| · n²
                 = n² · |δ(S)|                    [сумування нетривіальних ребер межі δ(S)]
```

За мінімаксним принципом Реле для другого власного значення `d - λ₂`:
```
d - λ₂ ≤ ⟨f, (d I - A) f⟩ / ⟨f, f⟩                [мінімаксна властивість другого власного значення]
       = (n² · |δ(S)|) / (n · s · (n - s))        [підстановка обчислених чисельника та знаменника]
       = (n / (n - s)) · (|δ(S)| / s)             [скорочення n у чисельнику та знаменнику]
```

Оскільки `s ≤ n/2`, коефіцієнт `n / (n - s) ≤ n / (n/2) = 2`.
Звідси отримуємо:

```
d - λ₂ ≤ 2 · (|δ(S)| / s)
```

Оскільки це виконується для довільної множини `S`, беручи мінімум за всіма `S`, маємо:

```
h(G) ≥ (d - λ₂) / 2
```

### 2. Верхня межа Нерівності Чігера

Верхня межа `h(G) ≤ √(2 d (d - λ₂))` доводить, що якщо спектральна щілина є малою, то у графі обов'язково існує комбінаторне вузьке місце. Доведення будується конструктивно за допомогою аналізу спектрального замітання (Cheeger Sweep).

Для вектора `f ∈ ℝⁿ`, ортогонального до `v₁`, сортуються елементи `f[u₁] ≤ f[u₂] ≤ ... ≤ f[u♮]`. Розглядаються всі `n - 1` префіксні підмножини `S_k = {u₁, ..., u_k}`. За допомогою нерівності Коші — Буняковського — Шварца доводиться, що існує принаймні один префікс `S_k`, для якого відношення розширення `|δ(S_k)| / |S_k|` не перевищує `√(2 d (d - λ₂))`.

Це доводить строговість спектральної оцінки: ізопериметричне число графа й спектральна щілина знаходяться у нерозривному поліноміальному зв'язку.

## Доведення Лемми про змішування розширювачів (Expander Mixing Lemma)

Лема про змішування розширювачів доводить, що у графі з малою величиною `λ₂` кількість ребер між будь-якими двома множинами вершин `S` та `T` дуже близька до очікуваного значення у псевдовипадковому графі Ердеша — Реньї `G(n, p = d/n)`.

### Формулювання леми

Нехай `G = (V, E)` — `d`-регулярний граф із `n` вершинами та другим власним значенням матриці суміжності `λ₂ = max_{i ≥ 2} |λᵢ|`. Тоді для довільних підмножин вершин `S, T ⊆ V`:

```
| e(S, T) - (d · |S| · |T|) / n | ≤ λ₂ · √(|S| · |T| · (1 - |S|/n) · (1 - |T|/n))
```

де `e(S, T)` — кількість впорядкованих пар `(u, v)` таких, що `u ∈ S`, `v ∈ T` та `(u, v) ∈ E`.

### Строге математичне виведення

Нехай `1_S` та `1_T` — індикаторні вектори множин `S` та `T` відповідно:
```
1_S[u] = 1, якщо u ∈ S; інакше 0
1_T[v] = 1, якщо v ∈ T; інакше 0
```

Кількість ребер `e(S, T)` тотожно дорівнює скалярному добутку:

```
e(S, T) = ⟨1_S, A · 1_T⟩ = 1_Sᵀ A 1_T
```

Розкладемо вектори `1_S` та `1_T` за ортонормованим базисом власних векторів `v₁, v₂, ..., v♮` матриці `A`:

```
1_S = ∑ᵢ αᵢ vᵢ ,  де αᵢ = ⟨1_S, vᵢ⟩
1_T = ∑ᵢ βᵢ vᵢ ,  де βᵢ = ⟨1_T, vᵢ⟩
```

Обчислимо перші коефіцієнти `α₁` та `β₁` для головного власного вектора `v₁ = (1 / √n) · (1, 1, ..., 1)ᵀ`:

```
α₁ = ⟨1_S, v₁⟩ = ∑_{u ∈ S} (1 / √n) = |S| / √n
β₁ = ⟨1_T, v₁⟩ = ∑_{v ∈ T} (1 / √n) = |T| / √n
```

Підставимо розклад у вираз `1_Sᵀ A 1_T`:

```
1_Sᵀ A 1_T = 1_Sᵀ · A (∑ᵢ βᵢ vᵢ)               [розклад вектора 1_T за власною основою]
           = 1_Sᵀ · (∑ᵢ βᵢ λᵢ vᵢ)              [застосування дії матриці A: A v_i = λ_i v_i]
           = ∑ᵢ λᵢ αᵢ βᵢ                       [ортонормованість базису: 1_S^T v_i = α_i]
           = λ₁ α₁ β₁ + ∑_{i=2}ⁿ λᵢ αᵢ βᵢ      [відокремлення першої компоненти λ_1]
```

Перший додаток суми відповідає рівномірному розподілу:

```
λ₁ α₁ β₁ = d · (|S| / √n) · (|T| / √n) = (d · |S| · |T|) / n
```

Отже, різниця між фактичною кількістю ребер та очікуваним рівномірним значенням дорівнює:

```
e(S, T) - (d · |S| · |T|) / n = ∑_{i=2}ⁿ λᵢ αᵢ βᵢ
```

Застосуємо модуль та нерівність трикутника:

```
| e(S, T) - (d · |S| · |T|) / n | = | ∑_{i=2}ⁿ λᵢ αᵢ βᵢ |
                                   ≤ ∑_{i=2}ⁿ |λᵢ| · |αᵢ| · |βᵢ|
                                   ≤ λ₂ · ∑_{i=2}ⁿ |αᵢ| · |βᵢ|
```

Застосуємо нерівність Коші — Буняковського — Шварца до сум `∑_{i=2}ⁿ |αᵢ| |βᵢ|`:

```
∑_{i=2}ⁿ |αᵢ| |βᵢ| ≤ √( ∑_{i=2}ⁿ αᵢ² ) · √( ∑_{i=2}ⁿ βᵢ² )
```

За тотожністю Парсеваля для ортонормованого базису:

```
∑_{i=1}ⁿ αᵢ² = ‖1_S‖² = |S|
⇒ ∑_{i=2}ⁿ αᵢ² = |S| - α₁² = |S| - (|S|² / n) = |S| · (1 - |S|/n)
```

Аналогічно для `β`:

```
∑_{i=2}ⁿ βᵢ² = |T| - β₁² = |T| - (|T|² / n) = |T| · (1 - |T|/n)
```

Об'єднуючи отримані нерівності, маємо остаточний результат:

```
| e(S, T) - (d · |S| · |T|) / n | ≤ λ₂ · √(|S| · (1 - |S|/n)) · √(|T| · (1 - |T|/n))
                                   ≤ λ₂ · √(|S| · |T|)
```

Це завершує доведення Лемми про змішування розширювачів.

## Швидкість збіжності випадкових блукань та час змішування

Нехай `p₀` — довільний початковий вектор розподілу ймовірностей на вершинах графа `G` (`∑ᵢ p₀[i] = 1`). Після `k` кроків випадкового блукання розподіл описується вектором `pⵟ = Mᵏ p₀`.

Розкладемо вектор `p₀` за базисом власних векторів:

```
p₀ = (1 / n) · (1, ..., 1)ᵀ + ∑_{i=2}ⁿ cᵢ vᵢ = u + w₀
```

де `u = (1/n, ..., 1/n)ᵀ` — стаціонарний (рівномірний) розподіл, а `w₀ ⊥ u`.

Застосовуючи оператор `Mᵏ = ( (1/d) A )ᵏ`:

```
pⵟ = Mᵏ u + Mᵏ w₀
   = u + ∑_{i=2}ⁿ cᵢ · (λᵢ / d)ᵏ vᵢ
```

Обчислимо евклідову норму відхилення від рівномірного розподілу `‖pⵟ - u‖₂`:

```
‖pⵟ - u‖₂² = ∑_{i=2}ⁿ cᵢ² · (λᵢ / d)²ᵏ
            ≤ (λ₂ / d)²ᵏ · ∑_{i=2}ⁿ cᵢ²           [оцінка максимум зваженого додатка λ_2]
            = (λ₂ / d)²ᵏ · ‖p₀ - u‖₂²             [тотожність Парсеваля для w_0]
```

Отже:

```
‖pⵟ - u‖₂ ≤ (λ₂ / d)ᵏ · ‖p₀ - u‖₂
```

Це доводить, що якщо спектральне відношення `λ₂ / d ≤ c < 1`, то випадкове блукання на графі-розширювачі збігається до стаціонарного рівномірного розподілу з експоненціальною швидкістю. Для досягнення відхилення `ε` достатньо зробити лише `k = O(log(1/ε) / (1 - λ₂/d))` кроків.

Час змішування (Mixing Time) `t_mix(ε)` визначається як кількість кроків `k`, необхідна для зменшення відстані за повного варіацією `‖p_k - u‖_TV` до величини `ε < 1/4`. Для графів-розширювачів час змішування є строго логарифмічним:

```
t_mix(ε) = O(log n / (1 - λ₂ / d))
```

Це є фундаментальною основою використання розширювачів у вибірковому аналізі та псевдовипадкових генераторах.

## Спектральний аналіз двочасткових графів-розширювачів

Для двочасткового `d`-регулярного графа `G = (U ∪ V, E)` із частками `|U| = |V| = n/2` матриця суміжності `A` має блочну структуру:

```
A = [ 0   B ]
    [ Bᵀ  0 ]
```

Спектр симетричної матриці `A` є симетричним відносно нуля: якщо `λ` є власним значенням `A`, то `-λ` також є власним значенням `A`. Зокрема, `λ₁ = d`, а `λ♮ = -d`.

Спектральна щілиною двочасткового графа-розширювача називається величина `d - λ₂`, де `λ₂` — друге за величиною додатне власне значення.

Для двочасткового розширювача матриця `B Bᵀ` описує двокрокові переходи всередині лівої частки `U`. Власні значення `B Bᵀ` дорівнюють `λᵢ²`. Отже, спектральний аналіз двочасткового розширювача зводиться до дослідження спектра невід'ємно визначеної матриці `B Bᵀ`. Це дозволяє будувати безвтратні розширювачі (Lossless Expanders), які застосовуються у теорії стиснення вимірювань (Compressed Sensing) та кодуванні.
