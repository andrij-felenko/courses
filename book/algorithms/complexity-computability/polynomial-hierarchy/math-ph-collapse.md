# 🧮 Математичний апарат PH: квантори, зведення та доведення теореми про обвал

Ця вставка містить строге математичне формулювання Поліноміальної ієрархії (PH), доведення її основних властивостей, детальний доказ **Теореми про обвал ієрархії** (Collapse Theorem), математичний розбір повноти задачі Quantified SAT (QSATₖ), а також алгебраїчний огляд механізмів теореми Тоди та теореми Карпа–ЛІптона.

---

## 1. Формальне означення через мови та детерміновані предикати

Нехай Σ = {0, 1} — алфавіт. Позначимо через Σ* множину всіх скінченних бітових рядків. Для рядка x ∈ Σ* його довжина позначується як |x|.

### Означення 1 (Клас Σₖᵖ)
Мова L ⊆ Σ* належить до класу **Σₖᵖ** (де k ≥ 1), якщо існує детермінована машина Тюринга M, яка працює за поліномний час, та поліном p(n) такі, що для будь-якого x ∈ Σ*:

`x ∈ L  ⟺  ∃ y₁ ∈ Σᵖ⁽ⁿ⁾  ∀ y₂ ∈ Σᵖ⁽ⁿ⁾  ∃ y₃ ∈ Σᵖ⁽ⁿ⁾ ... Qₖ yₖ ∈ Σᵖ⁽ⁿ⁾ [ M(x, y₁, y₂, ..., yₖ) = 1 ]`

де n = |x|, а останній квантор Qₖ є ∃, якщо k — непарне число, і ∀, якщо k — парне число.

### Означення 2 (Клас Πₖᵖ)
Мова L ⊆ Σ* належить до класу **Πₖᵖ** (де k ≥ 1), якщо її доповнення L̄ = Σ* \ L належить до Σₖᵖ.
Еквівалентно, L ∈ Πₖᵖ тоді й тільки тоді, коли:

`x ∈ L  ⟺  ∀ y₁ ∈ Σᵖ⁽ⁿ⁾  ∃ y₂ ∈ Σᵖ⁽ⁿ⁾  ∀ y₃ ∈ Σᵖ⁽ⁿ⁾ ... Q̄ₖ yₖ ∈ Σᵖ⁽ⁿ⁾ [ M(x, y₁, y₂, ..., yₖ) = 1 ]`

де Q̄ₖ є ∀, якщо k — непарне, і ∃, якщо k — парне.

### Означення 3 (Клас Δₖᵖ)
Для будь-якого k ≥ 1 клас **Δₖᵖ** визначається через детерміновані поліномні оракульні машини:
`Δₖᵖ = P^(Σₖ₋₁ᵖ)`

Зауважте, що `Δ₁ᵖ = P^P = P`, `Σ₁ᵖ = NP`, `Π₁ᵖ = coNP`.

## 2. Теорема про обвал ієрархії (Collapse Theorem): Повний математичний доказ

Головною властивістю Поліноміальної ієрархії є те, що якщо на якомусь рівні k дзеркальні класи збігаються, увесь нескінченний паркан класів вище цього рівня сплющується.

### Теорема 1 (Обвал ієрархії)
Якщо для деякого цілого k ≥ 1 виконується `Σₖᵖ = Πₖᵖ`, то для всіх i ≥ 0:
`Σₖ₊ᵢᵖ = Πₖ₊ᵢᵖ = Σₖᵖ`
Отже, вся ієрархія обвалюється до рівня k: `PH = Σₖᵖ`.

### Доведення (методом математичної індукції за кроком i)

**База індукції (i = 1):**
Нам задано, що `Σₖᵖ = Πₖᵖ`. Треба довести, що `Σₖ₊₁ᵖ = Σₖᵖ`.

Розглянемо довільну мову L ∈ Σₖ₊₁ᵖ.
За Означенням 1, існує поліномний детермінований предикат R та поліном p(n) такі, що:
`x ∈ L  ⟺  ∃ y₁ ∈ Σᵖ⁽ⁿ⁾ [ ∀ y₂ ∃ y₃ ... Qₖ₊₁ yₖ₊₁  R(x, y₁, y₂, ..., yₖ₊₁) = 1 ]`

Зверніть увагу на вираз у квадратних дужках. Позначимо його як новий предикат Q(x, y₁):
`Q(x, y₁)  ⟺  ∀ y₂ ∃ y₃ ... Qₖ₊₁ yₖ₊₁  R(x, y₁, y₂, ..., yₖ₊₁) = 1`

Розглянемо мову пар рядків:
`L_Q = { (x, y₁) ∣ Q(x, y₁) = 1 }`

Скільки кванторів містить вираз для Q(x, y₁)?
Він починається з квантора ∀ і містить k кванторних блоків (від y₂ до yₖ₊₁).
Отже, за Означенням 2, мова L_Q належить до класу **Πₖᵖ**!

Тепер застосуємо умову теореми (`Σₖᵖ = Πₖᵖ`):
Оскільки L_Q ∈ Πₖᵖ і Πₖᵖ = Σₖᵖ, мова L_Q **також належить до Σₖᵖ**!

Це означає, що за Означенням 1 існує інший детермінований предикат S та поліном q(n) такий, що твердження Q(x, y₁) можна переписати через квантори **Σₖᵖ** (починаючи з ∃):
`Q(x, y₁)  ⟺  ∃ z₁ ∀ z₂ ∃ z₃ ... Qₖ zₖ [ S(x, y₁, z₁, z₂, ..., zₖ) = 1 ]`

Тепер підставимо цей новий вираз для Q(x, y₁) назад у початкове визначення мови L:
`x ∈ L  ⟺  ∃ y₁ [ ∃ z₁ ∀ z₂ ∃ z₃ ... Qₖ zₖ  S(x, y₁, z₁, z₂, ..., zₖ) = 1 ]`

Подивіться на два квантори існування поспіль на початку: `∃ y₁ ∃ z₁`.
Оскільки два сусідніх однакові квантори можна об'єднати в один вектор w₁ = (y₁, z₁) поліномної довжини |w₁| ≤ p(|x|) + q(|x|), отримуємо:
`x ∈ L  ⟺  ∃ w₁ ∀ z₂ ∃ z₃ ... Qₖ zₖ [ S'(x, w₁, z₂, ..., zₖ) = 1 ]`

Порахуймо кількість кванторів у цьому виразі:
Він починається з ∃ і містить точно **k** кванторних блоків (w₁, z₂, ..., zₖ)!
Отже, за Означенням 1:
`L ∈ Σₖᵖ`

Ми довели, що для довільної L ∈ Σₖ₊₁ᵖ справджується L ∈ Σₖᵖ.
Оскільки очевидно, що Σₖᵖ ⊆ Σₖ₊₁ᵖ, ми отримуємо рівність:
`Σₖ₊₁ᵖ = Σₖᵖ`

Беручи доповнення, маємо також `Πₖ₊₁ᵖ = Πₖᵖ = Σₖᵖ`.

**Крок індукції (від i до i + 1):**
Припустимо, що `Σₖ₊ᵢᵖ = Σₖᵖ`.
Тоді `Σₖ₊ᵢ₊₁ᵖ = NP^(Σₖ₊ᵢᵖ) = NP^(Σₖᵖ) = Σₖ₊₁ᵖ = Σₖᵖ`.

Таким чином, за індукцією для всіх i ≥ 0 маємо `Σₖ₊ᵢᵖ = Σₖᵖ`, і весь нескінченний паркан ієрархії обвалюється до рівня k: `PH = Σₖᵖ`. **Теорему доведено.** ∎

## 3. QSATₖ: Повність та поліномні зведення

Аналогічно до теореми Кука–Левіна для NP, для кожного рівня Σₖᵖ існує своя канонічна повна задача відносно поліномних зведень Карпа (≤ₚ).

### Означення 4 (Задача QSATₖ)
Вхід: Булева формула ϕ(X₁, X₂, ..., Xₖ) у кон'юнктивній нормальній формі (КНФ), де змінні розбиті на k диз'юнктних наборів.
Питання: Чи істинна формульна кванторна форма:
`Φ = ∃ X₁  ∀ X₂  ∃ X₃ ... Qₖ Xₖ [ ϕ(X₁, X₂, ..., Xₖ) ]`

```
Крок зведення недетермінованої машини з оракулом до QSATₖ:
1. Конфігурація недетермінованої машини M за p(n) кроків кодується змінними X₁.
2. Запити до оракула Σₖ₋₁ᵖ кодуються кванторними блоками (X₂, ..., Xₖ).
3. Перевірочна матриця ϕ(X₁, ..., Xₖ) будується поліномним кодуванням за Куком–Левіном.
```

### Теорема 2
Для будь-якого k ≥ 1 задача QSATₖ є **Σₖᵖ-повною**.

## 4. Теорема Карпа–ЛІптона (Karp-Lipton Theorem)

Теорема Карпа–ЛІптона пов'язує уніформну складність (машини Тюринга) з неуніформною складністю (логічні схеми).

Позначимо через **P/poly** клас мов, які розв'язуються послідовністю логічних схем поліномного розміру.

### Теорема 3 (Карп, Ліптон, 1980)
Якщо `NP ⊆ P/poly`, то Поліноміальна ієрархія обвалюється на другий рівень:
`PH = Σ₂ᵖ = Π₂ᵖ`

### Ідея доведення:
Якщо `SAT ∈ P/poly`, то існує послідовність схем Cₙ розміру poly(n), які розв'язують SAT. За допомогою властивості самозводжуваності SAT (self-reducibility), схема Cₙ може не лише відповідати «так/ні», але й видавати сам виконуваний набір змінних.

Розглянемо довільну мову L ∈ Π₂ᵖ. За означенням:
`x ∈ L  ⟺  ∀ y ∈ Σᵖ⁽ⁿ⁾ ∃ z ∈ Σᵖ⁽ⁿ⁾ [ R(x, y, z) = 1 ]`

Внутрішнє питання `∃ z [ R(x, y, z) = 1 ]` є задачею з NP!
За припущенням `NP ⊆ P/poly`, існує мала схема C, яка замість недетермінованого пошуку z миттєво знаходить розв'язок z = C(x, y).

Тоді ми можемо переписати кванторне твердження для L без квантора ∃:
`x ∈ L  ⟺  ∃ C (розміру poly)  ∀ y [ R(x, y, C(x, y)) = 1 ]`

Останній вираз починається з квантора ∃ C і містить квантор ∀ y. Це формула класу **Σ₂ᵖ**!
Отже, `Π₂ᵖ ⊆ Σ₂ᵖ`, що за Теоремою 1 викликає обвал `PH = Σ₂ᵖ`. ∎

## 5. Алгебраїчний механізм Теореми Тоди: PH ⊆ P^(#P)

Доведення Сейносуке Тоди (1989) про те, що вся поліноміальна ієрархія міститься всередині детермінованого поліномного часу з одним запитом до оракула підрахунку #P, спирається на два глибоких алгебраїчних кроки:

### Крок 1: Імовірнісне зведення кванторів до класу ⊕P (Parity-P)
Клас **⊕P** (Parity-P) містить задачі визначення того, чи є кількість виконуваних наборів формули **непарною**.
Тода використав лему Валіанта–Вазірані (Valiant-Vazirani Lemma): довільну формулу ϕ за допомогою випадково підібраних лінійних рівнянь за модулем 2 можна звести до формули ϕ', яка з високою ймовірністю має **рівно один** виконуваний набір (якщо ϕ була здійсненною).

Для одного квантора ∃ або ∀ операція Parity-P повертає 1 тоді й тільки тоді, коли кількість розв'язків непарна. Тода показав, що за допомогою арифметики многочленів над скінченними кільцями Z_(2^m) можна узагальнити цей оператор так, щоб він поглинав k кванторних чергувань ∃∀∃... за один раз!

### Крок 2: Зведення ⊕P до #P
Оракул підрахунку **#P** повертає точне ціле число розв'язків N. Знаючи N, детермінована поліномна машина може миттєво обчислити `N mod 2^m`, діставши відповідь для всієї кванторної формули PH.

Це показує, що операція підрахунку #P є алгебраїчно потужнішою за будь-яке скінченне кванторне гілкування.
