# 🧮 Алгебра замикання та вежова оцінка класу Кальмара

Клас елементарних функцій за Кальмаром (позначається символом `E` або `\mathcal{E}`) будується як найменший клас числових функцій `f : ℕᵏ → ℕ`, який містить фіксований набір елементарних початкових операцій та є замкненим відносно операцій суперпозиції (підстановки), скінченного обмеженого підсумовування та скінченного обмеженого добутку.

Ця математична конструкція усуває неконтрольоване розростання обчислювальної складності, яке виникає у класичній схемі примітивної рекурсії, і водночас надає повний апарат для вираження всіх операцій дискретної математики, аналітичної теорії чисел та математичної логіки.

## Формальне визначення базису та операторів

Клас Кальмара `E` визначається індуктивно через початкові функції та правила побудови нових функцій.

### Початкові базисні функції

1. **Функція константи нуля:**
```
Z(x) = 0
```

2. **Функція взяття наступника (інкремент):**
```
S(x) = x + 1
```

3. **Функції проекції (вибір i-го аргументу з n-арного кортежу):**
```
Pᵢⁿ(x₁, x₂, ..., xₙ) = xᵢ,    де 1 ≤ i ≤ n
```

4. **Базові арифметичні операції:**
- Додавання: `Add(x, y) = x + y`
- Зрізане віднімання (монічне або усічене віднімання):
```
x ∸ y = x - y,    якщо x ≥ y
x ∸ y = 0,        якщо x < y
```
- Множення: `Mul(x, y) = x · y`
- Цілочисельне ділення (частка з відкиданням дробової частини):
```
Div(x, y) = ⌊x / y⌋,    якщо y > 0
Div(x, 0) = 0
```
- Піднесення до степеня (експонента):
```
Exp(x, y) = xʸ,    причому 0⁰ = 1
```

### Оператори замикання

Клас `E` замкнений відносно трьох алгебраїчних операцій:

1. **Суперпозиція (композиція):**
Якщо функція `g : ℕᵐ → ℕ` та функції `h₁, h₂, ..., hₘ : ℕⁿ → ℕ` належать до класу `E`, то функція `f : ℕⁿ → ℕ`, визначена формулою:
```
f(x₁, ..., xₙ) = g(h₁(x₁, ..., xₙ), h₂(x₁, ..., xₙ), ..., hₘ(x₁, ..., xₙ))
```
також належить до класу `E`.

2. **Обмежене підсумовування (Bounded Sum):**
Якщо функція `g : ℕⁿ⁺¹ → ℕ` належить до `E`, то функція `f : ℕⁿ⁺¹ → ℕ`, визначена як сума значень `g` за цілочисельним параметром `z` від `0` до верхньої межі `y`:
```
f(y, x₁, ..., xₙ) = ∑_{z ≤ y} g(z, x₁, ..., xₙ)
```
також належить до класу `E`.

3. **Обмежений добуток (Bounded Product):**
Якщо функція `g : ℕⁿ⁺¹ → ℕ` належить до `E`, то функція `f : ℕⁿ⁺¹ → ℕ`, визначена як добуток значень `g` за цілочисельним параметром `z` від `0` до верхньої межі `y`:
```
f(y, x₁, ..., xₙ) = ∏_{z ≤ y} g(z, x₁, ..., xₙ)
```
також належить до класу `E`.

## Замикання логічних предикатів та кванторів

Предикатом називається довільне відношення `P(x₁, ..., xₙ) ⊆ ℕⁿ`. Предикат називається елементарним у сенсі Кальмара, якщо його характеристична функція `χ_P : ℕⁿ → {0, 1}` належить до класу `E`:
```
χ_P(x₁, ..., xₙ) = 1,    якщо P(x₁, ..., xₙ) істинне
χ_P(x₁, ..., xₙ) = 0,    якщо P(x₁, ..., xₙ) хибне
```

### Булеві зв'язки над елементарними предикатами

Нехай `P` та `Q` є елементарними предикатами з характеристичними функціями `χ_P` та `χ_Q`. Тоді їхні логічні комбінації також є елементарними за Кальмаром, оскільки вони виражаються через арифметичні операції базису:

1. **Заперечення (`¬P`):**
```
χ_{¬P}(x) = 1 ∸ χ_P(x)
```
Якщо `χ_P(x) = 1`, то `1 ∸ 1 = 0`. Якщо `χ_P(x) = 0`, то `1 ∸ 0 = 1`.

2. **Кон'юнкція (`P ∧ Q`):**
```
χ_{P ∧ Q}(x) = χ_P(x) · χ_Q(x)
```
Добуток дорівнює `1` тоді й лише тоді, коли обидва множники дорівнюють `1`.

3. **Диз'юнкція (`P ∨ Q`):**
За законом де Моргана `P ∨ Q ≡ ¬(¬P ∧ ¬Q)`:
```
χ_{P ∨ Q}(x) = 1 ∸ ((1 ∸ χ_P(x)) · (1 ∸ χ_Q(x)))
```

4. **Імплікація (`P → Q`):**
Оскільки `P → Q ≡ ¬P ∨ Q`:
```
χ_{P → Q}(x) = 1 ∸ (χ_P(x) · (1 ∸ χ_Q(x)))
```

5. **Предикат рівності чисел (`x == y`):**
Рівність перевіряється через відсутність як додатної, так і від'ємної різниці:
```
χ_{==}(x, y) = (1 ∸ (x ∸ y)) · (1 ∸ (y ∸ x))
```
Якщо `x == y`, то `x ∸ y = 0` та `y ∸ x = 0`, тому добуток `(1 ∸ 0) · (1 ∸ 0) = 1`. Якщо ж `x ≠ y`, одна з різниць більша або дорівнює `1`, і відповідний множник перетворюється на `0`.

6. **Предикат нестрогого порядку (`x ≤ y`):**
```
χ_{≤}(x, y) = 1 ∸ (x ∸ y)
```

7. **Предикат строгого порядку (`x < y`):**
```
χ_{<}(x, y) = χ_{≤}(x + 1, y) = 1 ∸ ((x + 1) ∸ y)
```

### Обмежені квантори загальності та існування

Логічні квантори в класі Кальмара завжди мають скінченну верхню межу.

1. **Обмежений квантор загальності (`∀z ≤ y P(z, x)`):**
Висловлювання істинне, якщо `P(z, x)` виконується для кожного `z ∈ [0, y]`. Це відповідає скінченній кон'юнкції, яка в арифметиці виражається через обмежений добуток:
```
χ_{∀z ≤ y P}(y, x) = ∏_{z ≤ y} χ_P(z, x)
```
Якщо хоча б для одного `z` значення `χ_P(z, x) = 0`, весь добуток стає нулем. Якщо ж для всіх `z` значення дорівнює `1`, добуток одиниць дорівнює `1`.

2. **Обмежений квантор існування (`∃z ≤ y P(z, x)`):**
За законом подвійності `∃z ≤ y P(z, x) ≡ ¬(∀z ≤ y ¬P(z, x))`:
```
χ_{∃z ≤ y P}(y, x) = 1 ∸ ∏_{z ≤ y} (1 ∸ χ_P(z, x))
```
Якщо існує хоча б один свідок `z ≤ y`, для якого `χ_P(z, x) = 1`, відповідний множник дорівнює `0`, весь добуток стає `0`, а підсумковий результат `1 ∸ 0 = 1`.

## Замикання відносно обмеженої мінімізації (обмеженого μ-пошуку)

Оператор найменшого кореня (μ-оператор) знаходить найменше значення аргументу, при якому предикат стає істинним. У загальній теорії алгоритмів необмежений пошук `μ z [P(z, x) = 1]` робить функцію частковою та виводить її за межі примітивної рекурсії.

Проте **обмежений μ-оператор** шукає найменший корінь лише до наперед заданої числової межі `y`:
```
f(y, x) = μ z ≤ y [P(z, x) == 1]
```
Якщо розв'язок `z ≤ y` існує, функція повертає найменший такий `z`. Якщо ж для всіх `z ∈ [0, y]` умова не виконується, функція повертає значення за замовчуванням `y`.

### Конструктивне доведення еквівалентності через суми та добутки

Нехай `P(z, x)` є елементарним предикатом із характеристичною функцією `χ_P(z, x) ∈ E`.

Побудуємо допоміжну функцію накопичення `H(t, x)`, яка сигналізує, чи не з'явився розв'язок на відрізку `[0, t]`:
```
H(t, x) = ∏_{j ≤ t} (1 ∸ χ_P(j, x))
```
Властивості функції `H(t, x)`:
- Якщо для всіх `j ≤ t` маємо `χ_P(j, x) = 0` (розв'язку ще немає), кожен множник дорівнює `1 ∸ 0 = 1`, тому `H(t, x) = 1`.
- Як тільки при деякому найменшому `j₀ ≤ t` виконується `χ_P(j₀, x) = 1`, відповідний множник стає `1 ∸ 1 = 0`. Внаслідок властивості нуля весь добуток `H(t, x)` дорівнює `0` для всіх `t ≥ j₀`.

Тепер визначимо функцію пошуку через суму значень `H(t, x)` за всіма `t < y`:
```
f(y, x) = ∑_{t < y} H(t, x)
```

Розгорнемо покроковий розрахунок цього виразу для випадку, коли найменший розв'язок існує і дорівнює `z = k` (де `k ≤ y`):
```
f(y, x)
= ∑_{t < y} H(t, x)                                 [за визначенням через суму]
= ∑_{t < k} H(t, x) + ∑_{k ≤ t < y} H(t, x)          [розбиття інтервалу індексу t]
= ∑_{t < k} 1 + ∑_{k ≤ t < y} 0                      [H(t,x)=1 при t<k та H(t,x)=0 при t≥k]
= k + 0                                            [сума k одиниць дає число k]
= k                                                [знайдено найменший індекс k]
```

Якщо ж розв'язку на відрізку `[0, y]` не існує, то `H(t, x) = 1` для всіх `t < y`, і сума дає граничне значення `y`.

Оскільки `H(t, x)` побудовано через обмежений добуток і зрізане віднімання, а фінальний результат — через обмежену суму, функція обмеженого пошуку `f(y, x)` повністю належить до класу `E`.

## Застосування: виразність теорії чисел та кодування послідовностей

Завдяки замкненості відносно обмежених сум, добутків та кванторів, клас Кальмара містить усі фундаментальні функції теорії чисел, комбінаторики та синтаксису формальних мов.

### Предикат подільності та остача

Цілочисельна остача від ділення `x mod y` виражається через базові операції віднімання й множення:
```
Rem(x, y) = x ∸ (y · Div(x, y))
```

Предикат подільності «x ділиться на d без остачі» (`d | x`):
```
Divisible(x, d) ≡ (Rem(x, d) == 0)
```
Або через обмежений квантор існування:
```
Divisible(x, d) ≡ ∃z ≤ x (d · z == x)
```

### Факторіал та біноміальні коефіцієнти

Функція факторіалу `Factorial(n) = n!` будується безпосередньо через обмежений добуток:
```
Factorial(n) = ∏_{z < n} (z + 1)
```
Біноміальний коефіцієнт «з n по k» (`C(n, k)` або `Binomial(n, k)`):
```
Binomial(n, k) = Div(Factorial(n), Factorial(k) · Factorial(n ∸ k))
```
Обидві функції належать до `E`. Їхній ріст мажорується як `n! ≤ nⁿ ≤ 2 ↑↑ 2 (n)`.

### Простота числа та n-те просте число

Предикат простоти числа `IsPrime(x)` формулюється через квантор загальності:
```
IsPrime(x) ≡ (x ≥ 2) ∧ ∀d ≤ x (Divisible(x, d) → (d == 1 ∨ d == x))
```

Кількість простих чисел, що не перевищують `y` (функція `π(y)`):
```
PrimePi(y) = ∑_{z ≤ y} χ_{IsPrime}(z)
```

Функція `p_n`, яка повертає `n`-те за порядком просте число (`p₀ = 2, p₁ = 3, p₂ = 5, ...`), будується за допомогою обмеженого μ-пошуку. За теоремою Евкліда верхня межа для `n`-го простого числа не перевищує `2^(2ⁿ)`:
```
p_n ≤ 2^(2ⁿ)
```
Тоді `p_n` визначається в класі `E` як:
```
p_n = μ z ≤ 2^(2ⁿ) [IsPrime(z) ∧ (PrimePi(z) == n + 1)]
```

### Показник простого дільника та канонічний розклад

Функція `ExpFactor(n, p)`, яка обчислює кратність входження простого числа `p` у розклад числа `n` (найбільший степінь `k`, такий що `pᵏ | n`), визначається через суму або обмежений пошук:
```
ExpFactor(n, p) = ∑_{k ≤ n} χ_{Divisible}(n, pᵏ) ∸ 1
```
Або еквівалентно через обмежену мінімізацію:
```
ExpFactor(n, p) = (μ k ≤ n [¬Divisible(n, p^(k + 1))])
```

Канонічна факторизація числа `n = ∏ pᵢ^(aᵢ)` є повністю елементарною операцією:
```
n = ∏_{i ≤ n} (p_i)^(ExpFactor(n, p_i))
```

### Кодування пар Кантора та функція Ґеделя

Парна функція Кантора `Pair(x, y)` задає взаємно-однозначну бієкцію між множинами `ℕ × ℕ` та `ℕ`:
```
Pair(x, y) = Div((x + y) · (x + y + 1), 2) + y
```
Функції декодування першого та другого елемента пари будуються через обмежений пошук серед чисел, що не перевищують код `z`:
```
Left(z) = μ x ≤ z [ ∃y ≤ z (Pair(x, y) == z) ]
Right(z) = μ y ≤ z [ ∃x ≤ z (Pair(x, y) == z) ]
```

Для кодування послідовностей довільної довжини Курт Ґедель запропонував свою знамениту `β`-функцію (англ. *Gödel's beta function*), яка базується на китайській теоремі про остачі:
```
Beta(c, d, i) = Rem(c, 1 + (i + 1) · d)
```
Лема Ґеделя стверджує: для будь-якої скінченної послідовності чисел `(a₀, a₁, ..., a_k)` існують такі натуральні числа `c` та `d`, що для всіх `i ≤ k`:
```
Beta(c, d, i) = a_i
```
Оскільки функція `Beta(c, d, i)` використовує лише операцію взяття остачі `Rem`, додавання та множення, вона належить до класу `E`. Числа `c` та `d` обмежені зверху величиною `(max(a_i) + k + 1)^(2(k+1))`, що лежить у межах експоненти від вхідних даних.

## Арифметизація синтаксису та формальних доведень

Одним із найважливіших наслідків елементарності кодування послідовностей є те, що вся синтаксична структура математичної логіки виявляється елементарною за Кальмаром.

Нехай символам алфавіту формальної теорії (змінні, логічні зв'язки `¬, ∧, ∨, →`, квантори `∀, ∃`, дужки, символ рівності) зіставлено унікальні натуральні числа (ґеделівські номери).

Формула являє собою рядок символів `s = (c₀, c₁, ..., c_{m-1})`. Її ґеделівський код `G(s)` будується через степеневий добуток простих чисел або через позиційний запис:
```
G(s) = ∏_{i < m} p_i^(c_i + 1)
```

Операція обчислення довжини закодованого рядка `Len(A)` визначається як кількість ненульових показників простих чисел:
```
Len(A) = ∑_{i ≤ A} χ_{>0}(ExpFactor(A, p_i))
```

Операція конкатенації двох формул з кодами `A` та `B` (де довжини послідовностей є `Len(A)` та `Len(B)`):
```
Concat(A, B) = A · ∏_{j < Len(B)} (p_{Len(A) + j})^(ExpFactor(B, p_j))
```
Ця функція належить до класу `E`, оскільки верхня межа індексів простих чисел обмежена величиною `Len(A) + Len(B) ≤ A + B`.

Предикат перевірки коректності формули `IsWellFormedFormula(x)`, предикат належності до аксіом арифметики Пеано `IsAxiom(x)` та правило виводу Modus Ponens:
```
IsModusPonens(f₁, f₂, f₃) ≡ (f₂ == ConcatCode(ImplicationSymbol, f₁, f₃))
```
є елементарними за Кальмаром.

Операція заміни вільної змінної на числовий терм `Subst(F, v, t)` реалізується покроковим перебором символів за допомогою обмеженого добутку та суми позиційних зміщень. Усі ці перетворення мають поліноміальну або експоненціальну довжину від вихідного коду формули.

Отже, предикат доказовості Ґеделя `IsProof(P, F)` («послідовність з кодом P є коректним формальним доведенням формули з кодом F»):
```
IsProof(P, F) ≡ (Elem(P, Len(P) ∸ 1) == F) ∧
                 ∀i < Len(P) (IsAxiom(Elem(P, i)) ∨ 
                              ∃j < i ∃k < i IsModusPonens(Elem(P, j), Elem(P, k), Elem(P, i)))
```
є чисто елементарним предикатом класу `E`. Це доводить, що метаматематика, розпізнавання синтаксичної коректності виведення та верифікація формальних доведень за своєю суттю не вимагають виходу за межі класу Кальмара.

## Розмежування рівнів Гжегорчика E² та E³

Важливим теоретичним питанням є: чому експонента `2ˣ` вимагає виокремлення цілого класу `E³` і не може бути отримана з класу поліномів `E²`?

Рівень `E²` в ієрархії Гжегорчика визначається замиканням операцій додавання та множення через обмежені суми.
Якщо `P(x)` є поліномом степеня `d`, то його обмежена сума за формулою Фаульхабера або інтегральною оцінкою:
```
S_P(y) = ∑_{z ≤ y} P(z)
```
є поліномом степеня `d + 1`.

Будь-яка функція `g(x) ∈ E²` мажорується деяким фіксованим поліномом `P_g(x) = c · xᵈ`.
Оскільки функція `2ˣ` зростає асимптотично швидше за будь-який поліном фіксованого степеня:
```
∀d ∈ ℕ, c > 0   lim_{x → ∞} (c · xᵈ / 2ˣ) = 0
```
експонента `2ˣ` строго не належить до класу `E²`. Рівень Кальмара `E³` є строго ширшим за рівень поліноміальних функцій `E²`.

## Замикання відносно обмеженої рекурсії

Схема обмеженої рекурсії (англ. *bounded primitive recursion*) визначає функцію `f(y, x)` за допомогою індуктивного кроку за числовим параметром, але з наявністю відомої елементарної мажоранти `b(y, x) ∈ E`:
```
f(0, x) = g(x)
f(y + 1, x) = h(y, f(y, x), x)
за умови: ∀y, x  f(y, x) ≤ b(y, x)
```

### Доведення належності обмеженої рекурсії до класу E

Для доведення застосовується метод арифметизації обчислень Ґеделя через позиційне кодування послідовностей.

Весь протокол виконання обчислення довжини `y + 1` являє собою послідовність проміжних значень `(v₀, v₁, ..., v_y)`, де:
```
v₀ = g(x)
v_{i+1} = h(i, v_i, x)    для всіх i < y
```

Оскільки кожне проміжне значення за умовою обмежене величиною `M = b(y, x)`, уся послідовність може бути упакована в одне натуральне число `C` за основою системи числення `B = M + 1`:
```
C = ∑_{i ≤ y} v_i · Bⁱ
```
Верхня межа кодового числа `C` оцінюється як:
```
C ≤ ∑_{i ≤ y} M · Bⁱ < B^(y + 1) = (b(y, x) + 1)^(y + 1)
```
Оскільки операція піднесення до степеня входить до базового набору класу `E`, межа `(b(y, x) + 1)^(y + 1)` є обчислюваною функцією з `E`.

Функція вилучення `i`-го елемента послідовності `Elem(C, i, B)` визначається як:
```
Elem(C, i, B) = Rem(Div(C, Bⁱ), B)
```
Ця функція належить до `E`, оскільки цілочисельне ділення, остача та степінь є базовими операціями.

Тепер умова того, що число `C` кодує коректний протокол рекурсивного обчислення, записується як елементарний предикат:
```
IsTrace(C, y, x, B) ≡ (Elem(C, 0, B) == g(x)) ∧ 
                       ∀i < y (Elem(C, i + 1, B) == h(i, Elem(C, i, B), x))
```

Тоді значення шуканої функції `f(y, x)` обчислюється через обмежений μ-пошук:
```
C_opt = μ C ≤ B^(y + 1) [IsTrace(C, y, x, B) == 1]
f(y, x) = Elem(C_opt, y, B)
```
Це доводить, що будь-яка функція, визначена за схемою рекурсії з явною елементарною мажорантою, належить до класу Кальмара `E`.

## Теорема про мажорування вежею експонент (Tower Bound)

Фундаментальною характеристикою класу Кальмара є те, що швидкість зростання будь-якої функції з `E` обмежена зверху вежею експонент фіксованої висоти.

Введемо позначення вежі експонент `2 ↑↑ k (m)` висоти `k` над числом `m`:
```
2 ↑↑ 0 (m) = m
2 ↑↑ 1 (m) = 2ᵐ
2 ↑↑ 2 (m) = 2^(2ᵐ)
2 ↑↑ (k + 1) (m) = 2^(2 ↑↑ k (m))
```

### Формулювання теореми

Для будь-якої функції `f(x₁, ..., xₙ) ∈ E` існує фіксоване натуральне число `k ≥ 1`, таке що для всіх вхідних наборів `(x₁, ..., xₙ)` виконується нерівність:
```
f(x₁, ..., xₙ) ≤ 2 ↑↑ k (max(x₁, ..., xₙ))
```
де `max(x₁, ..., xₙ)` — максимальний із аргументів.

### Доведення структурною індукцією

Доведення проводиться індукцією за структурою побудови формули `f` у класі `E`. Позначимо `m = max(x₁, ..., xₙ)`. Припустимо без обмеження загальності, що `m ≥ 2`.

#### Базовий крок індукції

1. **Константа нуля:**
```
Z(x) = 0 ≤ 2 ↑↑ 1 (m) = 2ᵐ
```

2. **Інкремент:**
```
S(x) = x + 1 ≤ 2ᵐ = 2 ↑↑ 1 (m)    [для всіх m ≥ 1]
```

3. **Проекція:**
```
Pᵢⁿ(x₁, ..., xₙ) = xᵢ ≤ m ≤ 2 ↑↑ 1 (m)
```

4. **Додавання:**
```
x + y ≤ m + m = 2m ≤ 2ᵐ = 2 ↑↑ 1 (m)    [для m ≥ 2]
```

5. **Зрізане віднімання:**
```
x ∸ y ≤ x ≤ m ≤ 2 ↑↑ 1 (m)
```

6. **Множення:**
```
x · y ≤ m · m = m² ≤ 2ᵐ ≤ 2^(2ᵐ) = 2 ↑↑ 2 (m)    [для m ≥ 2]
```

7. **Піднесення до степеня:**
```
xʸ ≤ mᵐ ≤ (2ᵐ)ᵐ = 2^(m²) ≤ 2^(2ᵐ) = 2 ↑↑ 2 (m)    [оскільки m² ≤ 2ᵐ при m ≥ 4]
```
Для всіх початкових операцій висота вежі не перевищує `k = 2`.

#### Індукційний перехід

**Крок 1. Суперпозиція:**
Нехай `f(x) = g(h₁(x), ..., h_p(x))`, де за припущенням індукції:
```
hᵢ(x) ≤ 2 ↑↑ k₁ (m)    для всіх i ∈ [1, p]
g(u₁, ..., u_p) ≤ 2 ↑↑ k₂ (max(uᵢ))
```
Тоді:
```
f(x)
= g(h₁(x), ..., h_p(x))                                [визначення композиції]
≤ 2 ↑↑ k₂ (max(hᵢ(x)))                                [оцінка за індукційним припущенням для g]
≤ 2 ↑↑ k₂ (2 ↑↑ k₁ (m))                               [монотонність вежі експонент]
= 2 ↑↑ (k₁ + k₂) (m)                                  [властивість згортки висоти вежі]
```
Висота підсумкової вежі дорівнює `k = k₁ + k₂`, що є скінченною константою.

**Крок 2. Обмежене підсумовування:**
Нехай `f(y, x) = ∑_{z ≤ y} g(z, x)`, де `g(z, x) ≤ 2 ↑↑ k (max(y, x)) = 2 ↑↑ k (m)`.
```
f(y, x)
= ∑_{z ≤ y} g(z, x)                                   [визначення обмеженої суми]
≤ (y + 1) · (2 ↑↑ k (m))                              [сума y+1 однакових мажорант]
≤ (m + 1) · (2 ↑↑ k (m))                              [оскільки y ≤ m]
≤ 2ᵐ · (2 ↑↑ k (m))                                   [оскільки m+1 ≤ 2ᵐ при m ≥ 1]
≤ (2 ↑↑ k (m)) · (2 ↑↑ k (m))                         [оскільки 2ᵐ ≤ 2 ↑↑ k (m) при k ≥ 1]
= (2 ↑↑ k (m))²                                       [квадрат мажоранти]
≤ 2^(2 ↑↑ k (m))                                      [оскільки u² ≤ 2ᵘ для u ≥ 4]
= 2 ↑↑ (k + 1) (m)                                    [додавання одного рівня вежі]
```
Висота вежі збільшується рівно на `+1`.

**Крок 3. Обмежений добуток:**
Нехай `f(y, x) = ∏_{z ≤ y} g(z, x)`, де `g(z, x) ≤ 2 ↑↑ k (m)`.
```
f(y, x)
= ∏_{z ≤ y} g(z, x)                                   [визначення обмеженого добутку]
≤ (2 ↑↑ k (m))^(y + 1)                                [добуток y+1 мажорант]
≤ (2 ↑↑ k (m))^(2ᵐ)                                   [оскільки y+1 ≤ 2ᵐ]
= (2^(2 ↑↑ (k - 1) (m)))^(2ᵐ)                         [розгортання верхнього рівня вежі]
= 2^( (2 ↑↑ (k - 1) (m)) · 2ᵐ )                       [властивість степеня степеня]
≤ 2^( (2 ↑↑ (k - 1) (m)) · (2 ↑↑ (k - 1) (m)) )       [оскільки 2ᵐ ≤ 2 ↑↑ (k - 1) (m) при k ≥ 2]
= 2^( (2 ↑↑ (k - 1) (m))² )                           [квадрат виразу]
≤ 2^( 2^(2 ↑↑ (k - 1) (m)) )                          [оскільки u² ≤ 2ᵘ]
= 2^( 2 ↑↑ k (m) )                                    [згортання за визначенням вежі]
= 2 ↑↑ (k + 1) (m)                                    [підсумкова вежа висоти k+1]
```
У кожному з випадків висота підсумкової вежі `k` залишається фіксованим натуральним числом, яке залежить виключно від синтаксичного дерева формули і не залежить від числових значень вхідних даних. Теорему повністю доведено.

## Доведення неделементарності функції тетрації

Функція тетрації (англ. *tetration*) `T(n) = 2 ↑↑ n` визначається як вежа двійок, висота якої дорівнює самому вхідному числу `n`:
```
T(0) = 1
T(n + 1) = 2^(T(n))
```

### Доведення від супротивного

Припустимо, що функція тетрації `T(n)` належить до класу елементарних функцій Кальмара `E`.

Тоді за теоремою про мажорування вежею експонент для функції `T(n)` має існувати деяке фіксоване число `k ≥ 1`, таке що для всіх `n ≥ 0` виконується нерівність:
```
T(n) ≤ 2 ↑↑ k (n)
```

Розглянемо значення аргументу `n = k + 1`.

Обчислимо значення лівої та правої частини нерівності:
```
Ліва частина:   T(k + 1) = 2 ↑↑ (k + 1) (1)
Права частина:  2 ↑↑ k (k + 1)
```

Оскільки операція піднесення до степеня є строго монотонною, для всіх `n > k + 2`:
```
T(n) = 2 ↑↑ n (1) > 2 ↑↑ k (n)
```
Оскільки для довільного фіксованого `k` кількість експоненціальних поверхів у лівій частині дорівнює `n` (і необмежено зростає разом із `n`), а в правій частині кількість поверхів строго зафіксована числом `k`, функція `T(n)` неминуче перевершує `2 ↑↑ k (n)`.

Отримане протиріччя доводить, що тетрація `T(n) = 2 ↑↑ n` **не належить** до класу елементарних функцій Кальмара `E`. Вона утворює наступний якісний поверх обчислювальної складності — клас `E⁴` в ієрархії Гжегорчика.
