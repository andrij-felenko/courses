# ⚙️ Алгоритм вирішення MAJSAT: пороговий підрахунок виконуючих наборів

Задача більшості (Majority SAT, або MAJSAT) є канонічною PP-повною задачею рішення: для заданої булевої формули в кон'юнктивній нормальній формі (КНФ) із `n` змінними необхідно визначити, чи існує строго більше ніж `2ⁿ⁻¹` інтерпретацій (наборів значень змінних), які перетворюють формулу на істину (TRUE). Ця вставка містить концептуальний аналіз алгоритму підрахунку більшості задовольняльних наборів, практичну реалізацію MAJSAT-солвера мовами C та C++, а також розбір асимптотичної складності, покрокового трасування обчислень та методів оптимізації через відтинання гілок рекурсії.

## Практична постановка проблеми та особливості порогового пошуку

Звичайна задача SAT (з класу NP) вимагає знайти хоча б один задовольняльний набір (умова `N_sat ≥ 1`). Для її розв'язання сучасні CDCL-солвери (Conflict-Driven Clause Learning) використовують евристики, які дозволяють миттєво зрізати величезні піддерева пошуку: як тільки знайшовся один дійсний вектор змінних, обчислення відразу припиняється із позитивним результатом.

У задачі MAJSAT критерієм є строга більшість: `N_sat > 2ⁿ⁻¹`. Жоден поодинокий знайдений задовольняльний набір не дає відповіді про належність формули до MAJSAT. Ми зобов'язані або порахувати точний внесок усіх `2ⁿ` гілок обчислювального дерева, або довести за допомогою математичних меж, що сума задовольняльних наборів строго перевищує порогове значення.

Розглянемо структуру КНФ-формули:
- Формула складається з `M` диз'юнктів (clauses), з'єднаних операцією логічного І (AND).
- Кожен диз'юнкт містить літерали — змінні `x[i]` або їх заперечення `x̄[i]`, з'єднані операцією логічного АБО (OR).
- Усього у формулі бере участь `N` змінних, що утворює простір із `2ᴺ` можливих бінарних векторів оцінки.

Алгоритм обходу дерева рішень будується на рекурсивному розщепленні (метод Девіса-Патнама-Логемана-Лавленда, DPLL). На кожному кроці рекурсії обирається одна невизначена змінна `x[k]`, і процес розгалужується на два піддерева: `x[k] = 0` та `x[k] = 1`. Ключовою оптимізацією для порогового підрахунку є раннє визначення стану КНФ-формули при частковому призначенні змінних:

1. **Ранній конфлікт (Zero Clause):** Якщо хоча б один диз'юнкт стає повністю хибним (усі його літерали прийняли значення FALSE), вся формула стає хибною незалежно від значень решти `N - k` змінних. Це дозволяє відтяти `2ᴺ⁻ᵏ` потенційних гілок за один крок.
2. **Ранній успіх (Satisfied Formula):** Якщо після призначення `k` змінних усі диз'юнкти формули вже стали істинними (у кожному диз'юнкті є хоча б один літерал зі значенням TRUE), то всі `2ᴺ⁻ᵏ` нащадків у цьому піддереві гарантовано будуть виконуючими наборами. Ми повертаємо значення `2ᴺ⁻ᵏ` без подальшого розгалуження рекурсії.

## Механізм трасування рекурсивного дерева для КНФ-формули

Щоб докладно продемонструвати обхід рекурсивного дерева та дію порогового відтинання, розберемо приклад роботи солвера на формулі з `N = 4` змінними та `M = 3` диз'юнктами:

```
φ(x₁, x₂, x₃, x₄) = (x₁ ∨ x₂) ∧ (¬x₁ ∨ x₃) ∧ (x₂ ∨ ¬x₄)
```

Загальна кількість обчислювальних шляхів дорівнює `2⁴ = 16`. Поріг більшості для MAJSAT становить `16 / 2 = 8`. Формула належить до MAJSAT тоді й лише тоді, коли `N_sat > 8` (тобто `N_sat ≥ 9`).

Простежимо кроки рекурсивного солвера:

- **Крок 1 (x₁ = 0):**
  Перший диз'юнкт `(x₁ ∨ x₂)` спрощується до `(x₂)`.
  Другий диз'юнкт `(¬x₁ ∨ x₃)` стає істинним, оскільки `¬x₁ = 1`.
  Третій диз'юнкт залишається `(x₂ ∨ ¬x₄)`.
  Формула звужується до: `(x₂) ∧ (x₂ ∨ ¬x₄)`.

  - **Крок 1.1 (x₁ = 0, x₂ = 0):**
    Перший диз'юнкт `(x₂)` стає хибним (`0`).
    Формула стає хибною! Ми відтинаємо відразу `2⁴⁻² = 4` піддерева `(x₁=0, x₂=0, x₃, x₄)`. Повертаємо `0` виконуючих наборів.

  - **Крок 1.2 (x₁ = 0, x₂ = 1):**
    Диюнкт `(x₂)` стає істинним.
    Диз'юнкт `(x₂ ∨ ¬x₄)` стає істинним.
    Усі 3 диз'юнкти формули задоволено! Не залежно від значень `x₃` та `x₄`, усе піддерево прийняте.
    Відтинаємо рекурсію та повертаємо за 1 крок `2⁴⁻² = 4` виконуючі набори.

  Сума для гілки `x₁ = 0` становить `0 + 4 = 4` виконуючі набори.

- **Крок 2 (x₁ = 1):**
  Перший диз'юнкт `(x₁ ∨ x₂)` стає істинним.
  Другий диз'юнкт `(¬x₁ ∨ x₃)` спрощується до `(x₃)`.
  Третій диз'юнкт залишається `(x₂ ∨ ¬x₄)`.
  Формула звужується до: `(x₃) ∧ (x₂ ∨ ¬x₄)`.

  - **Крок 2.1 (x₁ = 1, x₃ = 0):**
    Диз'юнкт `(x₃)` стає хибним (`0`).
    Формула стає хибною! Відтинаємо `2⁴⁻² = 4` піддерева `(x₁=1, x₃=0, x₂, x₄)`. Повертаємо `0`.

  - **Крок 2.2 (x₁ = 1, x₃ = 1):**
    Диз'юнкт `(x₃)` стає істинним. Формула звужується до `(x₂ ∨ ¬x₄)`.

    - **Крок 2.2.1 (x₁ = 1, x₃ = 1, x₂ = 1):**
      Диз'юнкт `(x₂ ∨ ¬x₄)` стає істинним. Усі диз'юнкти задоволено!
      Повертаємо `2⁴⁻³ = 2` виконуючі набори.

    - **Крок 2.2.2 (x₁ = 1, x₃ = 1, x₂ = 0):**
      Формула звужується до `(¬x₄)`.
      При `x₄ = 0` диз'юнкт істинний (+1).
      При `x₄ = 1` диз'юнкт хибний (+0).
      Повертаємо `1` задовольняльний набір.

  Сума для гілки `x₁ = 1` становить `0 + 2 + 1 = 3` виконуючі набори.

Загальна кількість задовольняльних наборів склала `N_sat = 4 + 3 = 7`.
Перевіряємо умову більшості: `7 > 8` є ХИБНИМ. Формула `φ` не належить до MAJSAT.

Завдяки оптимізації DPLL солвер перевірив лише 7 вузлів дерева замість повного перебору 16 листків!

## Евристики вибору змінних для порогового підрахунку

У практичних солверах підрахунку розв'язків порядок вибору змінних для розгалуження рекурсії принципово впливає на швидкість обчислень.

1. **Евристика найчастіших літералів (MOMs — Maximum Occurrences in clauses of Minimum size):**
   Солвер аналізує диз'юнкти найменшої довжини і обирає змінну, яка трапляється там найчастіше. Призначення цієї змінної з високою імовірністю або миттєво задовольнить диз'юнкт, або спричинить ранній конфлікт і відтне велике піддерево.

2. **Одноголосний поширення (Unit Propagation):**
   Якщо у формулі з'являється диз'юнкт, який містить лише один невизначений літерал (unit clause), його значення стає вимушеним. Солвер відразу присвоює відповідне значення без створення двох гілок рекурсії, що скорочує дерево обчислень.

3. **Мажоритарна динамічна межа (Dynamic Threshold Bounding):**
   Під час обходу рекурсивного дерева солвер підтримує два числа: поточну кількість вже знайдених виконуючих наборів `N_current` та максимально можливу кількість виконуючих наборів у ще недосліджених гілках `N_max_remaining`.
   - Якщо `N_current > 2ⁿ⁻¹`, солвер миттєво перериває рекурсію і повертає TRUE (формально доведено належність до MAJSAT).
   - Якщо `N_current + N_max_remaining ≤ 2ⁿ⁻¹`, солвер миттєво перериває рекурсію і повертає FALSE (навіть якщо всі решта гілок стануть виконуючими, поріг більшості досягнуто не буде).

## Реалізація MAJSAT-солвера

Наведена нижче реалізація демонструє рекурсивний алгоритм підрахунку виконуючих наборів із оптимізованим раннім поверненням, коли поріг більшості досягнуто або коли залишкової кількості гілок недостатньо для перетирання порогу.

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <stdint.h>

/* Структура для представлення диз'юнкта (clause):
 * Літерали кодуються цілими числами:
 * +1 означає x1, -1 означає NOT x1. 
 */
typedef struct {
    int* lits;
    size_t lit_count;
} Clause;

typedef struct {
    size_t var_count;
    size_t clause_count;
    Clause* clauses;
} CNFFormula;

/* Оцінка диз'юнкта при частковому або повному призначенні:
 * Повертає 1 (TRUE), 0 (FALSE), або -1 (НЕВИЗНАЧЕНО).
 */
static int eval_clause(const Clause* c, const int8_t* assignment) {
    bool has_undef = false;
    for (size_t i = 0; i < c->lit_count; ++i) {
        int lit = c->lits[i];
        size_t var_idx = (size_t)(abs(lit) - 1);
        int8_t val = assignment[var_idx];
        
        if (val == -1) {
            has_undef = true;
        } else if ((lit > 0 && val == 1) || (lit < 0 && val == 0)) {
            return 1; /* Диз'юнкт істинний */
        }
    }
    return has_undef ? -1 : 0;
}

/* Оцінка всієї КНФ-формули */
static int eval_formula(const CNFFormula* f, const int8_t* assignment) {
    bool has_undef = false;
    for (size_t i = 0; i < f->clause_count; ++i) {
        int res = eval_clause(&f->clauses[i], assignment);
        if (res == 0) return 0; /* Один хибний диз'юнкт робить усю формулу хибною */
        if (res == -1) has_undef = true;
    }
    return has_undef ? -1 : 1;
}

/* Рекурсивний підрахунок кількості виконуючих наборів */
static uint64_t count_sat_rec(const CNFFormula* f, size_t var_idx, int8_t* assignment, uint64_t threshold) {
    int status = eval_formula(f, assignment);
    
    if (status == 0) {
        return 0; /* Раннє відтинання: формула вже хибна */
    }
    
    if (var_idx == f->var_count) {
        return (status == 1) ? 1ULL : 0ULL;
    }
    
    /* Якщо всі диз'юнкти вже істинні, всі залишок 2^(N - var_idx) гілок будуть істинними */
    if (status == 1) {
        return 1ULL << (f->var_count - var_idx);
    }

    /* Гілка 1: присвоюємо var_idx = 0 */
    assignment[var_idx] = 0;
    uint64_t count_left = count_sat_rec(f, var_idx + 1, assignment, threshold);

    /* Гілка 2: присвоюємо var_idx = 1 */
    assignment[var_idx] = 1;
    uint64_t count_right = count_sat_rec(f, var_idx + 1, assignment, threshold);

    /* Відновлюємо стан для зворотного ходу */
    assignment[var_idx] = -1;

    return count_left + count_right;
}

/* Головна функція перевірки належності до MAJSAT */
bool solve_majsat(const CNFFormula* f, uint64_t* out_sat_count) {
    int8_t* assignment = (int8_t*)malloc(f->var_count * sizeof(int8_t));
    for (size_t i = 0; i < f->var_count; ++i) {
        assignment[i] = -1; /* -1 означає невизначену змінну */
    }

    uint64_t total_paths = 1ULL << f->var_count;
    uint64_t threshold = total_paths / 2;

    uint64_t sat_count = count_sat_rec(f, 0, assignment, threshold);
    free(assignment);

    if (out_sat_count) {
        *out_sat_count = sat_count;
    }

    return sat_count > threshold;
}

int main(void) {
    /* Приклад КНФ з 3 змінними: (x1 OR x2) AND (NOT x1 OR x3) */
    size_t num_vars = 3;
    size_t num_clauses = 2;

    Clause clauses[2];
    int c1_lits[] = {1, 2};   /* x1 OR x2 */
    int c2_lits[] = {-1, 3};  /* NOT x1 OR x3 */

    clauses[0].lits = c1_lits; clauses[0].lit_count = 2;
    clauses[1].lits = c2_lits; clauses[1].lit_count = 2;

    CNFFormula formula = {num_vars, num_clauses, clauses};

    uint64_t sat_count = 0;
    bool is_majsat = solve_majsat(&formula, &sat_count);

    printf("Кількість змінних: %zu (всього гілок: %llu)\n", num_vars, 1ULL << num_vars);
    printf("Кількість виконуючих наборів N_sat: %llu\n", (unsigned long long)sat_count);
    printf("Поріг більшості (> %llu): %s\n", (unsigned long long)((1ULL << num_vars) / 2),
           is_majsat ? "ТАК (належить до MAJSAT)" : "НІ (не належить до MAJSAT)");

    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <cstdint>
#include <optional>

/* Клас ідіоматичного представлення КНФ-формули в C++ */
class CNFFormula {
public:
    struct Clause {
        std::vector<int> lits; // +1 для x1, -1 для NOT x1
    };

    size_t var_count;
    std::vector<Clause> clauses;

    CNFFormula(size_t vars) : var_count(vars) {}

    void add_clause(std::initializer_list<int> lits) {
        clauses.push_back(Clause{std::vector<int>(lits)});
    }

    /* Оцінка всієї формули при частковому призначення змінних */
    int evaluate(const std::vector<int8_t>& assignment) const {
        bool has_undef = false;
        for (const auto& clause : clauses) {
            bool clause_sat = false;
            bool clause_undef = false;

            for (int lit : clause.lits) {
                size_t var_idx = static_cast<size_t>(std::abs(lit) - 1);
                int8_t val = assignment[var_idx];

                if (val == -1) {
                    clause_undef = true;
                } else if ((lit > 0 && val == 1) || (lit < 0 && val == 0)) {
                    clause_sat = true;
                    break;
                }
            }

            if (!clause_sat && !clause_undef) {
                return 0; // Диз'юнкт хибний -> формула хибна
            }
            if (!clause_sat && clause_undef) {
                has_undef = true;
            }
        }
        return has_undef ? -1 : 1;
    }
};

/* Клас розв'язувача MAJSAT з використанням RAII та стану */
class MAJSATSolver {
public:
    struct Result {
        uint64_t sat_count;
        uint64_t total_paths;
        bool is_majority;
    };

    static Result solve(const CNFFormula& formula) {
        std::vector<int8_t> assignment(formula.var_count, -1);
        uint64_t total_paths = 1ULL << formula.var_count;
        uint64_t threshold = total_paths / 2;

        uint64_t sat_count = count_recursive(formula, 0, assignment);
        return Result{sat_count, total_paths, sat_count > threshold};
    }

private:
    static uint64_t count_recursive(const CNFFormula& formula, size_t var_idx, std::vector<int8_t>& assignment) {
        int status = formula.evaluate(assignment);

        if (status == 0) {
            return 0; // Раннє відтинання хибної гілки
        }

        if (var_idx == formula.var_count) {
            return (status == 1) ? 1ULL : 0ULL;
        }

        if (status == 1) {
            // Усі диз'юнкти задоволено -> усі 2^(N - var_idx) нащадків будуть виконуючими
            return 1ULL << (formula.var_count - var_idx);
        }

        // Гілка 0
        assignment[var_idx] = 0;
        uint64_t count_0 = count_recursive(formula, var_idx + 1, assignment);

        // Гілка 1
        assignment[var_idx] = 1;
        uint64_t count_1 = count_recursive(formula, var_idx + 1, assignment);

        // Відновлення стану
        assignment[var_idx] = -1;

        return count_0 + count_1;
    }
};

int main() {
    // Створюємо формулу: (x1 OR x2) AND (NOT x1 OR x3)
    CNFFormula formula(3);
    formula.add_clause({1, 2});
    formula.add_clause({-1, 3});

    auto result = MAJSATSolver::solve(formula);

    std::cout << "Кількість змінних: " << formula.var_count 
              << " (всього гілок: " << result.total_paths << ")\n";
    std::cout << "Кількість виконуючих наборів N_sat: " << result.sat_count << "\n";
    std::cout << "Поріг більшості (> " << (result.total_paths / 2) << "): "
              << (result.is_majority ? "ТАК (належить до MAJSAT)" : "НІ (не належить до MAJSAT)") << "\n";

    return 0;
}
```

## Аналіз складності та оптимізації

1. **Часова складність у найгіршому випадку:**
   У найгіршому випадку (коли жоден диз'юнкт не стає хибним чи істинним до останньої змінної) алгоритм обходить усе бінарне дерево обчислень. Загальна часова складність дорівнює:
   ```
   T(N) = O(2ᴺ · M · L)
   ```
   де `N` — кількість змінних, `M` — кількість диз'юнктів, `L` — середня довжина диз'юнкта.

2. **Просторова складність:**
   Алгоритм використовує лише стек рекурсії глибиною `N` та масив призначення довжиною `N`. Просторова складність становить:
   ```
   S(N) = O(N + M · L)
   ```
   Це демонструє, чому MAJSAT і весь клас PP належать до PSPACE: обчислення експоненційної кількості гілок вимагає лише поліноміальної пам'яті.

3. **Оптимізація через відтинання гілок (Pruning):**
   - **Раннє згасання (Conflict Pruning):** Якщо часткова оцінка дає set 0 на диз'юнкті, ми миттєво відтинаємо `2ᴺ⁻ᵏ` піддерев.
   - **Повне задоволення (Satisfied Subtree Pruning):** Якщо всі диз'юнкти вже дорівнюють 1, ми повертаємо `2ᴺ⁻ᵏ` за 1 крок без подальшої рекурсії.
   - **Мажоритарні межі (Threshold Bounding):** Якщо поточна сума знайдених виконуючих наборів плюс максимально можлива залишкова кількість гілок `2ᴺ⁻ᵏ` стає меншою або дорівнює порогу `2ᴺ⁻¹`, можна негайно завершити обчислення з відповіддю FALSE. Або навпаки: як тільки поточна сума перевищує `2ᴺ⁻¹`, алгоритм миттєво повертає TRUE.
