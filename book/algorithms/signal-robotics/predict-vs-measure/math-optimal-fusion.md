# 🧮 Чому ваги обернені до дисперсій: виведення оптимального сплаву

Тут строго виводиться те, що зважувати двоє незалежних гаусових свідчень треба **обернено до їхніх дисперсій** — не з міркувань зручності, а тому, що лише такий вибір дає оцінку з найменшою можливою похибкою. Пройдемо цей висновок двома дорогами — як задачу на дно параболи й як байєсів апостеріор — і обидві зійдуться в одну формулу з тими самими центром і шириною.

## Постановка: одна невідома, двоє незалежних свідків

Є невідома істинна величина *x* (скажімо, справжнє положення). Про неї маємо два свідчення, кожне — незміщена оцінка *x* зі своїм розкидом:

```
передбачення:  центр a,  дисперсія σ²_пер
вимір:         центр b,  дисперсія σ²_вим
```

**Незміщена** означає, що в середньому свідок не бреше: E[a] = x і E[b] = x — помилка гуляє навколо правди, а не збита систематично вбік. **Незалежні** — що їхні помилки не змовляються: знання однієї нічого не каже про другу. Обидва припущення нам знадобляться, і кожне лишить чіткий слід у відповіді.

Зведену оцінку шукаємо як лінійну комбінацію двох центрів:

```
x̂ = w·a + (1 − w)·b        # w — частка довіри до передбачення
```

Чому саме одна вага *w*, а решта (1 − w) сама лягає на вимір? Цього вимагає незміщеність. Візьмімо на мить дві вільні ваги, x̂ = w₁·a + w₂·b, і подивімось, коли оцінка лишається чесною:

```
E[x̂] = w₁·E[a] + w₂·E[b] = w₁·x + w₂·x = (w₁ + w₂)·x
```

Щоб це дорівнювало *x* за **будь-якого** *x*, конче w₁ + w₂ = 1. Отже друга вага не вільна: w₂ = 1 − w₁. Однопараметрична сім'я `w·a + (1−w)·b` — це рівно **множина всіх незміщених лінійних комбінацій** двох свідчень, ні ширша, ні вужча. Лишилась одна ручка *w*, і все питання — куди її крутнути.

## Дорога перша: дно параболи

Ручку крутитимемо за об'єктивним мірилом: оберемо те *w*, за якого зведена оцінка **найменше розкидана** — має найменшу власну дисперсію. Порахуймо цю дисперсію. Дисперсія суми незалежних доданків додається, а сталий множник виходить із дисперсії у квадраті — це дві базові властивості [середнього й дисперсії](book:math/mean-variance): Var(a + b) = Var(a) + Var(b) для незалежних, і Var(c·a) = c²·Var(a). Застосуймо їх:

```
f(w) = Var(x̂) = w²·σ²_пер + (1 − w)²·σ²_вим
```

Саме тут спрацювала незалежність: якби помилки корелювали, до цієї суми додався б іще перехресний член, і вся подальша арифметика поїхала б. А так маємо чисту квадратичну функцію від *w* — **параболу**. Велике *w* тягне в оцінку повний розкид передбачення σ²_пер, мале *w* — розкид виміру σ²_вим; десь між крайнощами ховається дно.

Дно параболи беруть похідною. Диференціюємо f по *w* і прирівнюємо до нуля:

```
f′(w) = 2w·σ²_пер − 2(1 − w)·σ²_вим = 0
        w·σ²_пер = (1 − w)·σ²_вим
        w·σ²_пер + w·σ²_вим = σ²_вим
        w·(σ²_пер + σ²_вим) = σ²_вим
```

звідки

```
w* = σ²_вим / (σ²_пер + σ²_вим)
```

Ось вона: вага передбачення дорівнює дисперсії **виміру**, поділеній на суму дисперсій. Прочитаймо це вголос — чим шумніший вимір (більша σ²_вим), тим більша вага *w* на передбачення; чим точніший вимір (мала σ²_вим), тим менша. Кожне свідчення входить у сплав обернено до власної недовіри.

Та критична точка сама по собі могла б бути й вершиною параболи, а не дном. Перевірмо другою похідною:

```
f″(w) = 2·σ²_пер + 2·σ²_вим = 2·(σ²_пер + σ²_вим) > 0
```

Дисперсії додатні, тож f″ додатна **скрізь**: парабола опукла, вітки дивляться вгору, єдина критична точка — мінімум. Не вершина, а справжнє дно. Геометрично весь висновок лягає на долоню:

![Парабола σ²(w): спадає від чистого виміру ліворуч до дна в точці w*, тоді зростає до чистого передбачення праворуч; у дні горизонтальна дотична](/book/algorithms/signal-robotics/predict-vs-measure/img/variance-parabola.svg)
*Дисперсія зведеної оцінки як функція ваги — опукла парабола. На лівому кінці (w = 0) довіряємо лише виміру, і дисперсія дорівнює σ²_вим; на правому (w = 1) — лише передбаченню, дисперсія σ²_пер. Дно — там, де дотична горизонтальна (нахил 0): вага w* = σ²_вим/(σ²_пер + σ²_вим). І дно лежить нижче за обидва кінці — сплав розкиданий менше, ніж будь-яке свідчення окремо.*

## Оптимальна дисперсія: точності додаються

Ми знаємо найкраще *w*. Підставмо його назад у f, щоб дістати саму найменшу дисперсію. Позначмо суму S = σ²_пер + σ²_вим; тоді w* = σ²_вим/S і 1 − w* = σ²_пер/S. Рахуємо f(w*):

```
σ²_опт = (σ²_вим/S)²·σ²_пер + (σ²_пер/S)²·σ²_вим
       = [ σ²_пер·σ²_вим² + σ²_пер²·σ²_вим ] / S²
       = σ²_пер·σ²_вим·(σ²_вим + σ²_пер) / S²
       = σ²_пер·σ²_вим·S / S²
       = σ²_пер·σ²_вим / (σ²_пер + σ²_вим)
```

Формула гарна, та справжня її краса відкривається, коли її **перевернути**. Візьмімо обернену дисперсію й назвімо її точністю: чим вужча хмара, тим вища точність. Обертаємо σ²_опт:

```
1/σ²_опт = (σ²_пер + σ²_вим) / (σ²_пер·σ²_вим)
         = σ²_пер/(σ²_пер·σ²_вим) + σ²_вим/(σ²_пер·σ²_вим)
         = 1/σ²_вим + 1/σ²_пер
```

тобто

```
1/σ²_опт = 1/σ²_пер + 1/σ²_вим
```

**Точності просто додаються.** І звідси — головне: сума двох додатних чисел більша за кожен доданок, тож 1/σ²_опт більша і за 1/σ²_пер, і за 1/σ²_вим. А обернено — σ²_опт **менша за обидві** вхідні дисперсії. Зведена хмара виходить вужчою за будь-яку, з якої зроблена: два незалежні погляди несуть більше знання, ніж один, і мінімізація чесно виловлює це знання в ширину.

Підставмо числа, щоб побачити результат на дотик — хай σ²_пер = 4, σ²_вим = 1:

```
w*     = 1 / (4 + 1)   = 0.2
σ²_опт = 4·1 / (4 + 1) = 0.8
перевірка через точності:  1/σ²_опт = 1/4 + 1/1 = 1.25  →  σ²_опт = 0.8   ✓
```

Вага передбачення 0.2, виміру — 0.8: давач учетверо точніший (дисперсія вчетверо менша), тож і слухаємо його вчетверо охочіше. А зведена дисперсія 0.8 менша й за 4, і за 1.

За цією алгеброю ховається дуже фізична картина. Перепишімо оцінку не через дисперсії, а через точності. Домноживши чисельник і знаменник w* на добуток точностей 1/(σ²_пер·σ²_вим), дістанемо w* = (1/σ²_пер)/(1/σ²_пер + 1/σ²_вим); тоді

```
      a·(1/σ²_пер) + b·(1/σ²_вим)
x̂ = ─────────────────────────────
        1/σ²_пер + 1/σ²_вим
```

Це **зважене середнє центрів із вагами-точностями** — а така формула є не що інше, як **центр мас**: постав у точку *a* масу, рівну точності передбачення 1/σ²_пер, у точку *b* — масу, рівну точності виміру 1/σ²_вим, і оцінка ляже точно в точку рівноваги важеля.

![Важіль: маси-точності 1/σ²_пер у точці a=10 і 1/σ²_вим у точці b=16; опора-оцінка в точці рівноваги 14.8, ближче до важчої, тобто точнішої, маси](/book/algorithms/signal-robotics/predict-vs-measure/img/precision-lever.svg)
*Оптимальна оцінка як точка рівноваги важеля. Маси дорівнюють точностям: точніший вимір (мала σ²_вим → велика маса 1/σ²_вим) важчий, тож опора зсувається до нього. Площа кружка тут ∝ маса, тому вимір-маса вчетверо більша за передбачення-масу — і рівновага стоїть на 14.8, близько до виміру. А сумарна маса важеля 1/σ²_пер + 1/σ²_вим — це і є сумарна точність 1/σ²_опт: додаючи друге свідчення, додаємо масу-точність, і вся система стає «важчою», певнішою.*

Важіль пояснює обидва наші результати заразом. Точка рівноваги (центр мас) — це оптимальна оцінка, зсунута до важчої, отже точнішої, маси. А сумарна маса важеля — це сумарна точність: додавання другого свідка додає маси всій системі, і саме тому точності складаються, а хмара звужується.

## Що саме ми довели

Варто чітко назвати наслідок. Ми перебрали не одне-два зважування, а **всю** сім'ю незміщених лінійних комбінацій (кожне *w* дає незміщену оцінку) і серед них знайшли те єдине, що має найменшу дисперсію. Отже обернено-дисперсійний сплав — це оцінка з найменшою можливою похибкою **серед усіх лінійних незміщених** оцінок двох свідчень: кращого не досягти, не зламавши лінійності чи не припустивши зміщення. А для гаусів, як зараз покаже друга дорога, це водночас і найкраще взагалі, не лише серед лінійних.

## Дорога друга: байєсів апостеріор

Ту саму формулу можна дістати, ні разу не мінімізуючи параболу, — самою теорією ймовірностей. Погляньмо на свідчення як на **густини**. Передбачення — це апріорне переконання про *x*: [дзвоноподібна густина](book:math/normal-distribution) з центром *a* і шириною σ²_пер, тобто пропорційна exp(−(x − a)²/(2·σ²_пер)). Вимір *b* — це зашумлене спостереження *x* із шумом σ²_вим, тобто правдоподібність, пропорційна exp(−(b − x)²/(2·σ²_вим)). За [правилом Баєса](book:math/bayesian-estimation) апостеріор пропорційний добуткові правдоподібності на апріор:

```
p(x | b)  ∝  exp( −(x−a)² / (2·σ²_пер) ) · exp( −(x−b)² / (2·σ²_вим) )
          =  exp( −½ · [ (x−a)²/σ²_пер + (x−b)²/σ²_вим ] )
```

Уся дія — в показнику. Позначмо точності p₁ = 1/σ²_пер і p₂ = 1/σ²_вим та розкриймо квадрати:

```
Q(x) = p₁·(x−a)² + p₂·(x−b)²
     = (p₁ + p₂)·x²  −  2·(p₁·a + p₂·b)·x  +  (p₁·a² + p₂·b²)
```

Це знову квадратний тричлен по *x* — отже добуток двох дзвонів **сам є дзвоном**. Лишилось прочитати з нього центр і ширину, а для цього — **виділити повний квадрат**. Винесімо (p₁ + p₂):

```
Q(x) = (p₁ + p₂)·[ x² − 2·μ·x ] + const,     де  μ = (p₁·a + p₂·b)/(p₁ + p₂)
     = (p₁ + p₂)·(x − μ)² + const′
```

Усе, що не залежить від *x*, зібралося в сталу — на форму дзвона вона не впливає, бо йде в множник нормування. Отже апостеріор пропорційний exp(−½·(p₁ + p₂)·(x − μ)²) — це дзвін із такими центром і точністю:

```
центр:     μ = (p₁·a + p₂·b)/(p₁ + p₂) = (a/σ²_пер + b/σ²_вим) / (1/σ²_пер + 1/σ²_вим)
точність:  p₁ + p₂ = 1/σ²_пер + 1/σ²_вим
```

Порівняймо з першою дорогою. Центр μ — це точнісно-зважене середнє, тобто **той самий** `x̂`, що дала мінімізація параболи. Точність апостеріора — сума точностей, тобто **та сама** `1/σ²_опт`. Дві геть різні дороги — «найменша дисперсія серед лінійних незміщених» і «апостеріор за Баєсом» — привели в одну точку, з тими самими центром і шириною.

І це не збіг, а глибша істина. Для гаусів оптимальне лінійне зважування **дорівнює** повному байєсовому апостеріору. У загальному випадку Баєс дав би якусь складну криву, а лінійна оцінка була б лише її найкращим наближенням; але дзвін замикає обидва підходи в одне — бо добуток дзвонів є дзвін, і його центр із шириною рівно ті, що виводить мінімізація похибки. Тому та скромна формула w = σ²_вим/(σ²_пер + σ²_вим) несе весь тягар оптимального оцінювання: вона одночасно й найточніша лінійна незміщена, і байєсівськи вичерпна.
