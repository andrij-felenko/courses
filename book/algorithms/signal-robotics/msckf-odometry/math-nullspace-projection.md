# 🧮 Математичне виведення нуль-просторової проєкції MSCKF

Математичне серце фільтра MSCKF полягає в точному аналітичному виключенні невідомих просторових координат 3D-орієнтирів із рівнянь спостереження камери без втрати інформації про взаємний рух між кадрами. Щоб реалізувати цей алгоритм у коді або дослідити його чисельну стабільність, необхідно розібрати повний ланцюг аналітичних виведень: від диференціювання центральної проєкції точки в групі Лі `SO(3)` до ортогональної проєкції на лівий нуль-простір, перевірки спостережуваності та стиснення вимірів через тонкий QR-розклад.

## Модель спостереження та просторові системи координат

Нехай просторова точка з глобальними координатами `p_G = [X, Y, Z]ᵀ` у світовій системі відліку `G` спостерігається камерою з позиції `i`, зафіксованої в момент часу `t_i`.

Положення та орієнтація камери в системі `G` задаються вектором зміщення `p_Ci` та матрицею повороту `R_Ci` (яка перетворює вектор із локальної системи камери `C_i` у світову систему `G`). Координати точки в локальній системі координат камери `p_Ci,f` обчислюються за правилом зміни базису:

```
p_Ci,f = R_Ciᵀ · (p_G - p_Ci) = [ X_c,  Y_c,  Z_c ]ᵀ
```

Камера з попередньо каліброваною матрицею внутрішніх параметрів виконує центральну проєкцію точки на площину сенсора. У нормованих координатах площини зображення вектор спостереження `z_i = [u_i, v_i]ᵀ` формується діленням просторових компонентів на глибину:

```
z_i = h(p_Ci,f) + v_i = [ X_c / Z_c ] + v_i
                        [ Y_c / Z_c ]
```

де `v_i ~ N(0, σ² · I₂)` — вимірювальний гаусів шум детектора пікселів з ізотропною дисперсією `σ²`.

## Параметризація простору похибок у групі Лі SO(3)

Для уникнення сингулярностей кутів Ейлера (явища гіроскопічного замка) та надлишковості 4-компонентних кватерніонів оцінка орієнтації будується в термінах малого вектора кутової похибки `δθ ∈ ℝ³` у дотичному просторі алгебри Лі `so(3)`.

Справжня матриця повороту `R` пов'язана з поточною оцінкою фільтра `R̂` через матричне експоненційне відображення:

```
R = R̂ · exp( [δθ]× ) ≈ R̂ · ( I₃ + [δθ]× )
```

де `[δθ]×` — кососиметрична матриця оператора векторного добутку:

```
[δθ]× = [   0    -δθ_z   δθ_y ]
        [  δθ_z    0    -δθ_x ]
        [ -δθ_y   δθ_x    0   ]
```

Для просторового положення камери та просторових координат орієнтира векторні похибки визначаються лінійним відніманням істинної величини від розрахованої:

```
p_Ci = p̂_Ci + δp_Ci
p_G  = p̂_G  + δp_G
```

## Лінеаризація та обчислення матриць Якобі

Підставимо визначені похибки орієнтації та положення у вектор координат точки в системі камери:

```
p_Ci,f = ( R̂_Ci · (I + [δθ_Ci]×) )ᵀ · ( p̂_G + δp_G - (p̂_Ci + δp_Ci) )
       = ( I - [δθ_Ci]× ) · R̂_Ciᵀ · ( (p̂_G - p̂_Ci) + (δp_G - δp_Ci) )   [транспонування малого повороту]
       = p̂_Ci,f + R̂_Ciᵀ · δp_G - R̂_Ciᵀ · δp_Ci - [δθ_Ci]× · p̂_Ci,f      [розкриття дужок і згрупування]
       = p̂_Ci,f + R̂_Ciᵀ · δp_G - R̂_Ciᵀ · δp_Ci + [p̂_Ci,f]× · δθ_Ci      [антисиметрія: -[a]× · b = [b]× · a]
```

У виведенні використано фундаментальну антисиметричну властивість векторного добутку: `-[a]× · b = [b]× · a`.

Диференціюючи функцію нормованої проєкції `h(p_Ci,f)` за локальними координатами точки `p_Ci,f = [X_c, Y_c, Z_c]ᵀ`, отримуємо матрицю якобіана оптичної проєкції `J_proj`:

```
J_proj = ∂h / ∂p_Ci,f = [ 1 / Z_c       0       -X_c / Z_c² ]
                        [    0       1 / Z_c    -Y_c / Z_c² ]
```

Застосовуючи ланцюгове правило диференціювання складеної функції, знаходимо шукані аналітичні блоки якобіанів для лінеаризованої нев'язки `r_i = z_i - h(p̂_Ci,f)`:

```
r_i ≈ H_θ,i · δθ_Ci + H_p,i · δp_Ci + H_f,i · δp_G + v_i
```

де матричні блоки визначаються співвідношеннями:

```
H_θ,i = J_proj · [p̂_Ci,f]×       [розмірність 2 × 3]
H_p,i = -J_proj · R̂_Ciᵀ          [розмірність 2 × 3]
H_f,i = J_proj · R̂_Ciᵀ           [розмірність 2 × 3]
```

Якобіан відносно повної 6-вимірної пози камери `C_i` записується спільним блоком `H_Ci = [ H_θ,i,  H_p,i ]` розмірністю `2 × 6`.

## Формування системи обмежень для багатьох спостережень

Якщо один нерухомий орієнтир `p_G` спостерігався з `M` різних поз у ковзному вікні (збережених у векторі стану фільтра), ми об'єднуємо всі `M` спостережень у вертикальний векторний стек:

```
r_j = [  r₁,j  ]       H_X,j = [ H_C1,j   0   ...   0   ]       H_f,j = [ H_f,1,j ]
      [  r₂,j  ]               [   0    H_C2,j ...  0   ]               [ H_f,2,j ]
      [   ...  ]               [          ...           ]               [   ...   ]
      [  r_M,j ]               [   0      0   ... H_CM,j]               [ H_f,M,j ]
```

Повна лінеаризована система рівнянь для одного орієнтира набуває вигляду:

```
r_j = H_X,j · x̃ + H_f,j · δp_G + v_j
```

де складові мають чіткі фізичні розмірності:
- `r_j ∈ ℝ^(2M)` — вертикальний вектор піксельних нев'язок усіх кадрів;
- `H_X,j ∈ ℝ^(2M × (15 + 6N))` — якобіан нев'язки відносно повного вектора похибок стану системи;
- `H_f,j ∈ ℝ^(2M × 3)` — матриця чутливості спостережень до тривимірних координат орієнтира;
- `δp_G ∈ ℝ³` — похибка оцінки координат 3D-точки;
- `v_j ~ N(0, σ² · I_(2M))` — коваріація вихідного некорельованого піксельного шуму.

## Теорема про проєкцію на лівий нуль-простір

Для виключення невідомого вектора `δp_G` виконаємо повний QR-розклад прямокутної матриці чутливості точки `H_f,j`:

```
H_f,j = Q · R_full = [ Q₁   Q₂ ] · [ R ]
                                   [ 0 ]
```

де:
- `Q ∈ ℝ^(2M × 2M)` — повна ортогональна матриця, для якої виконується умова `Qᵀ · Q = I_(2M)`;
- `Q₁ ∈ ℝ^(2M × 3)` — матриця, стовпці якої покривають простір стовпців матриці `H_f,j`;
- `Q₂ ∈ ℝ^(2M × (2M - 3))` — матриця, стовпці якої утворюють ортонормований базис лівого нуль-простору `H_f,j`;
- `R ∈ ℝ^(3 × 3)` — верхня трикутна невироджена матриця (за умови наявності ненульового просторового паралаксу між кадрами).

### Доведення анулювання 3D-похибки

За структурою матричного множення QR-розкладу маємо точну тотожність:

```
H_f,j = Q₁ · R + Q₂ · 0 = Q₁ · R
```

Помножимо обидві частини рівності зліва на транспонований блок лівого нуль-простору `Q₂ᵀ`:

```
Q₂ᵀ · H_f,j
= Q₂ᵀ · (Q₁ · R)                     [підстановка QR-розкладу]
= (Q₂ᵀ · Q₁) · R                     [асоціативність множення матриць]
= 0 · R                              [ортогональність блоків матриці Q: Q₂ᵀ · Q₁ = 0]
= 0                                  [доведено: член анулюється тотожно]
```

Застосуємо оператор лівої проєкції `Q₂ᵀ` до повного лінеаризованого рівняння спостереження `r_j`:

```
r_o,j = Q₂ᵀ · r_j
      = Q₂ᵀ · H_X,j · x̃ + Q₂ᵀ · H_f,j · δp_G + Q₂ᵀ · v_j   [підстановка вихідної нев'язки]
      = Q₂ᵀ · H_X,j · x̃ + 0 · δp_G + Q₂ᵀ · v_j             [ортогональність нуль-простору: Q₂ᵀ · H_f = 0]
      = H_o,j · x̃ + v_o,j                                  [згортання матриці обмеження H_o,j]
```

де спроєктована матриця спостереження стану дорівнює `H_o,j = Q₂ᵀ · H_X,j ∈ ℝ^((2M - 3) × (15 + 6N))`.

### Доведення збереження статистичних властивостей шуму

Перевіримо математичне сподівання та коваріацію спроєктованого шуму вимірювання `v_o,j = Q₂ᵀ · v_j`:

```
E[v_o,j] = E[Q₂ᵀ · v_j] = Q₂ᵀ · E[v_j] = 0

Cov(v_o,j) = E[ v_o,j · v_o,jᵀ ]
           = E[ (Q₂ᵀ · v_j) · (Q₂ᵀ · v_j)ᵀ ]                 [підстановка визначення спроєктованого шуму]
           = Q₂ᵀ · E[ v_j · v_jᵀ ] · Q₂                      [винесення сталих матриць за матсподівання]
           = Q₂ᵀ · (σ² · I_(2M)) · Q₂                        [коваріація початкового білого шуму]
           = σ² · (Q₂ᵀ · Q₂)                                 [винесення скаляра σ²]
           = σ² · I_(2M - 3)                                 [ортонормованість стовпців Q₂: Q₂ᵀ · Q₂ = I]
```

Оскільки стовпці матриці `Q₂` взаємно ортонормовані (`Q₂ᵀ · Q₂ = I`), лінійна проєкція не спотворює шум сенсора: він залишається білим, некорельованим і має вихідну дисперсію `σ²`.

## Чисельне стиснення вимірів через тонкий QR-розклад

Коли на поточному кроці завершується відстеження `L` різних орієнтирів, усі спроєктовані нев'язки та якобіани складаються в єдиний вертикальний блок:

```
r_total = [ r_o,1;  r_o,2;  ...;  r_o,L ] ∈ ℝ^S
H_total = [ H_o,1;  H_o,2;  ...;  H_o,L ] ∈ ℝ^(S × D)
```

де `S = ∑ (2M_l - 3)` — сумарна кількість рядків обмежень (часто `500...2000`), а `D = 15 + 6N` — розмірність вектора похибки стану (типово `105...195`).

Прямий розрахунок приросту Калмана вимагав би обернення велетенської матриці `S × S`. Для скорочення обчислювальної складності виконується тонкий QR-розклад матриці `H_total`:

```
H_total = [ Q_H1   Q_H2 ] · [ T_H ]
                            [  0  ]
```

де `Q_H1 ∈ ℝ^(S × D)`, `Q_H2 ∈ ℝ^(S × (S - D))`, а `T_H ∈ ℝ^(D × D)` — верхня трикутна матриця.

Множачи систему зліва на транспоновану матрицю `Q_Hᵀ = [ Q_H1ᵀ;  Q_H2ᵀ ]`, розділяємо її на два незалежні векторні блоки:

```
Q_H1ᵀ · r_total = T_H · x̃ + Q_H1ᵀ · v_total
Q_H2ᵀ · r_total = 0 · x̃ + Q_H2ᵀ · v_total
```

Нижній блок не містить інформації про стан системи `x̃` і несе винятково некорисний залишковий шум, тому він відкидається без втрати інформації. Фінальні компактні змінні для формул оновлення Калмана набувають вигляду:

```
r_compressed = Q_H1ᵀ · r_total      [розмірність D × 1]
H_compressed = T_H                  [розмірність D × D]
R_compressed = σ² · I_D             [розмірність D × D]
```

Завдяки цьому розмірність оберненої матриці `(H_compressed · P · H_compressedᵀ + R_compressed)⁻¹` фіксується на рівні `D × D`, забезпечуючи сталу та передбачувану швидкість роботи бортового алгоритму.

## Аналіз конзистентності та проблема FEJ

Незважаючи на аналітичну витонченість, стандартний фільтр Калмана з лінеаризацією навколо поточних оцінок (EKF) у задачі VIO страждає від порушення конзистентності.

Справжня візуально-інерціальна система за відсутності абсолютних просторових маяків має неспостережуваний підпростір розмірності 4:
1. Тривимірний паралельний зсув усієї траєкторії в просторі `(X, Y, Z)`.
2. Одновимірний поворот навколо вектора гравітації (кут курсу / рискання, `yaw`).

В ідеальному оцінювачі матриця спостережуваності `O` повинна мати нуль-простір розмірності щонайменше 4 (`rank(O) = dim(x̃) - 4`). Проте, коли матриці переходу стану `Φ_k` та якобіани спостереження `H_k` обчислюються навколо щойно скоригованих оцінок стану, оцінки точки лінеаризації в різні моменти часу виявляються неузгодженими між собою.

У результаті цього лінеаризаційного розриву матриця спостережуваності штучно набуває повного рангу по куту курсу. Фільтр починає «вірити», що він бачить абсолютний магнітний курс без компаса, і необґрунтовано занижує коваріацію похибки орієнтації вздовж вертикальної осі. Це явище називається надмірною самовпевненістю оцінювача (англ. *estimator overconfidence*).

Для розв'язання цієї проблеми в модифікації FEJ-MSCKF (First-Estimate Jacobian MSCKF) діє жорстке правило конзистентності: усі якобіани переходу стану `Φ` та проєкційні якобіани `H_X`, `H_f` обчислюються суто в точці першої оцінки відповідного стану. Зафіксувавши точку лінеаризації, алгоритм гарантує точне збереження 4-вимірного неспостережуваного підпростору та унеможливлює розбіжність фільтра під час тривалих маневрів.
