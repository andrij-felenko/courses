# 🧮 Математичне моделювання зупинки пліток та динаміки Push-Pull

Епідемічне розповсюдження інформації у розподілених системах спирається на стохастичні моделі популяційної динаміки. Коли вузол генерує оновлення або отримує нову чутку, виникає дилема: якщо поширювати плітку нескінченно, мережа захлинеться від надлишкового трафіку `O(N²)`; якщо ж зупинити процес занадто рано, частина вузлів назавжди залишиться у застарілому стані. Ця вставка розгортає математичний апарат епідемічного поширення: виводить рівняння класичної моделі SIR, обчислює залишкову частку неінфікованих вузлів для сліпої та зворотнісної зупинки пліток, а також строго доводить асиметричну швидкість збіжності стратегій Push, Pull та Push-Pull.

---

## Епідемічна модель SIR у дискретних раундах

Розглянемо замкнену систему з `N` вузлів. У кожен дискретний момент часу (раунд) `t` кожен вузол перебуває в одному з трьох станів за аналогією з епідеміологічною моделлю Кермака — Маккендріка (SIR):

```
S (Susceptible)  — сприйнятливий: вузол ще не знає оновлення (стан застарілий).
I (Infectious)   — інфікований: вузол знає оновлення та активно поширює його.
R (Removed/Dead) — вилучений: вузол знає оновлення, але припинив поширення (замовк).
```

Нехай `s[t]`, `i[t]`, `r[t]` позначають частки вузлів у відповідних станах у раунді `t`, де:

```
s[t] + i[t] + r[t] = 1
```

У кожному раунді кожен інфікований вузол `I` обирає рівномірно та незалежно `k` випадкових партнерів із загальної популяції `N` (параметр `k` називається коефіцієнтом розгалуження або *fanout*).

## Динаміка стратегії Push: швидкий старт та логарифмічний хвіст

У чистій моделі Push оновлення передає виключно інфікований вузол `I`. Знайдемо ймовірність того, що конкретний сприйнятливий вузол `S` **не буде** обраний жодним із `N · i[t]` інфікованих вузлів протягом одного раунду.

Один інфікований вузол робить `k` незалежних виборів. Ймовірність не обрати даний вузол за одну спробу дорівнює:

```
P_miss_single = 1 - 1 / (N - 1) ≈ 1 - 1 / N      [для великих N]
```

Оскільки в системі діє `N · i[t]` інфікованих вузлів, кожен з яких робить `k` спроб, сумарна кількість незалежних виборів становить `k · N · i[t]`. Ймовірність того, що сприйнятливий вузол уникне інфікування в поточному раунді, визначається границею експоненти:

```
P_uninfected
= (1 - 1 / N)^(k · N · i[t])                     [ймовірність уникнути всіх k·N·i[t] контактів]
= ((1 - 1 / N)^N)^(k · i[t])                     [властивість степеня]
= e^(-k · i[t])                                  [за визначенням другої чудової границі при N → ∞]
```

Звідси отримуємо рекурентне співвідношення для частки сприйнятливих вузлів на наступному кроці:

```
s[t+1]
= s[t] · P_uninfected                            [частка вузлів, які залишилися неінфікованими]
= s[t] · e^(-k · i[t])                           [підстановка граничної ймовірності]
```

### Фаза експоненційного зростання (початок)

На початковому етапі, коли інфікована лише мізерна частка кластера (`i[t] ≈ 0`, `s[t] ≈ 1`), наближення Тейлора першого порядку дає:

```
e^(-k · i[t]) ≈ 1 - k · i[t]                     [лінеаризація експоненти при малих i[t]]
```

Підставляючи це у вираз для `s[t+1]`, знаходимо динаміку приросту інфікованих вузлів (вважаючи `r[t] = 0` на старті):

```
s[t+1]
= s[t] · (1 - k · i[t])                          [підстановка лінійного наближення]
= (1 - i[t]) · (1 - k · i[t])                    [оскільки s[t] = 1 - i[t]]
= 1 - (1 + k) · i[t] + k · (i[t])²               [розкриття дужок]
≈ 1 - (1 + k) · i[t]                             [знехтування квадратичним членом другого порядку]
```

Оскільки `i[t+1] = 1 - s[t+1]`, отримуємо:

```
i[t+1]
= 1 - (1 - (1 + k) · i[t])                       [підстановка s[t+1]]
= (1 + k) · i[t]                                 [експоненційне розмноження інфекції]
```

Кількість інфікованих вузлів на початковому етапі зростає за геометричною прогресією зі знаменником `(1 + k)`:

```
i[t] = i[0] · (1 + k)^t                          [чисельність інфікованих після t раундів]
```

### Проблема купонів колекціонера та деградація хвоста

Коли переважна більшість кластера вже інфікована (`s[t] ≪ 1`), інфіковані вузли марнують майже весь свій мережевий бюджет на надсилання оновлень тим, хто вже володіє цим станом. 

Нехай у системі залишився лише один неінфікований вузол (`s[t] = 1 / N`). Ймовірність того, що чергове повідомлення випадково влучить саме в нього, становить `1 / N`. Математичне сподівання кількості раундів для інфікування останнього вузла описується класичною задачею про купони колекціонера:

```
E[T_last_node] = N · ln(N)                       [сумарна кількість контактів для покриття останнього елемента]
```

Через це чистий Push вимагає `O(log N)` раундів для інфікування 99% вузлів, але подальше доведення до 100% сповільнюється, генеруючи надлишковий трафік `O(N · log N)`.

## Динаміка стратегії Pull: квадратичний фініш

У моделі Pull неінфікований вузол `S` періодично сам опитує `k` випадкових сусідів, запитуючи їхній стан.

Вузол `S` залишиться неінфікованим у поточному раунді лише в тому разі, якщо **всі** `k` опитаних ним партнерів також виявляться неінфікованими (перебувають у стані `S`). Оскільки вибір партнерів є незалежним, ймовірність цього становить:

```
P_pull_miss = (s[t])^k                           [ймовірність обрати k неінфікованих сусідів поспіль]
```

Тоді частка неінфікованих вузлів на наступному кроці становить:

```
s[t+1]
= s[t] · P_pull_miss                             [частка вузлів, які не знайшли оновлення]
= s[t] · (s[t])^k                                [підстановка ймовірності]
= (s[t])^(k + 1)                                 [супер-експоненційне / квадратичне згасання залишку]
```

### Порівняння фаз збіжності:

```
1. Старт Pull (s[t] ≈ 1):
   • Якщо інфіковано лише 1 вузол: i[0] = 1 / N, s[0] = 1 - 1 / N.
   • Ймовірність натрапити на інфікований вузол: 1 - (1 - 1/N)^k ≈ k / N.
   • Висновок: На старті Pull вкрай неефективний, оскільки ймовірність знайти єдине джерело близька до 0.

2. Фініш Pull (s[t] = ε, де ε ≪ 1):
   • Якщо при k = 1 залишок становив 1% (s[t] = 0.01):
     s[t+1] = (0.01)² = 0.0001 (0.01% за один раунд).
   • Якщо при k = 2 залишок становив 1%:
     s[t+1] = (0.01)³ = 0.000001 (один на мільйон).
   • Висновок: Pull забезпечує миттєве детерміноване очищення залишку ентропії.
```

Комбінована стратегія **Push-Pull** запускає експоненційний ріст через Push (`i[t] ~ (1+k)^t`) і перемикається на надшвидкий фініш через Pull (`s[t+1] = s[t]^(k+1)`), досягаючи узгодженості всього кластера за строго `O(log N)` раундів із найменшою можливою дисперсією.

## Зупинка пліток (Rumor Mongering): ймовірнісний залишок

У протоколах поширення чуток вузол не може пліткувати вічно. Використовують два класи правил переходу зі стану `I` (Infectious) у стан `R` (Removed):

1. **Правило монети (Coin Toss / Blind stopping):** щоразу після надсилання чутки вузол кидає ймовірнісну монету з шансом `1 / k_stop` перейти в стан `R`.
2. **Зворотнісне правило лічильника (Feedback counter):** якщо вузол надсилає плітку партнеру, а той відповідає, що **вже знає** цю новину, лічильник дублікатів інкрементується. При досягненні порога `k_feedback` вузол замовкає (`I → R`).

### Розрахунок граничної частки неінфікованих вузлів

Нехай вузол припиняє поширення з імовірністю `1 / k_stop` у кожному контакті, де партнер виявився інфікованим. У неперервному наближенні зміна кількості неінфікованих вузлів `S` та інфікованих `I` описується системою диференціальних рівнянь:

```
ds / dt = - (k + 1) · s · i                      [швидкість інфікування нових вузлів]
di / dt = (k + 1) · s · i - (1 / k_stop) · i · (1 - s) [приріст мінус замовкання при контактах з (1-s)]
```

Розділивши перше рівняння на друге для випадку `k_stop = 1` (замовкання при першому ж дублікаті), отримуємо співвідношення між фінальною часткою тих, хто ніколи не дізнався новину (`s_∞`), та початковим станом:

```
ln(s_∞)
= - (k + 1) · (1 - s_∞)                          [інтегрування диференціального рівняння]
```

Потенціюючи обидві частини рівності:

```
s_∞ = e^(-(k + 1) · (1 - s_∞))                   [трансцендентне рівняння для залишкової частки]
```

### Аналітичний розв'язок через W-функцію Ламберта

Трансцендентне рівняння `s = e^(-(k+1)(1-s))` зводиться до аналітичного вигляду за допомогою W-функції Ламберта `W(x)`, яка є оберненою до функції `f(w) = w · e^w`:

```
s · e^((k + 1) · (1 - s)) = 1                    [множення на знаменник]
s · e^(-(k + 1) · s) = e^(-(k + 1))              [ділення на e^(k+1)]
-(k + 1) · s · e^(-(k + 1) · s) = -(k + 1) · e^(-(k + 1)) [множення на -(k+1)]
```

Застосовуючи визначення W-функції Ламберта до обох частин:

```
-(k + 1) · s = W(- (k + 1) · e^(-(k + 1)))       [взяття головної гілки W_0]
s_∞ = - W(- (k + 1) · e^(-(k + 1))) / (k + 1)    [точний аналітичний розв'язок]
```

### Числові значення залишкової частки `s_∞` від порога зупинки `k`:

```
+----------------+--------------------------+-------------------------------+
| Початковий k   | Залишкова частка s_∞ (%) | Ймовірність втрати на N=10000 |
+----------------+--------------------------+-------------------------------+
| k = 1          | 20.32 %                  | ~ 2032 вузли не отримають     |
| k = 2          | 5.95 %                   | ~ 595 вузлів не отримають     |
| k = 3          | 1.80 %                   | ~ 180 вузлів не отримають     |
| k = 4          | 0.51 %                   | ~ 51 вузол не отримає         |
| k = 5          | 0.14 %                   | ~ 14 вузлів не отримають      |
| k = 6          | 0.038 %                  | ~ 4 вузли не отримають        |
| k = 8          | 0.0025 %                 | < 1 вузла (практично 0)       |
+----------------+--------------------------+-------------------------------+
```

Цей результат доводить фундаментальну теорему епідемічного розповсюдження: **жоден чистий протокол чуток (Rumor Mongering) із кінцевим часом життя не здатен математично гарантувати 100% доставку інформації**. Зі збільшенням коефіцієнта розгалуження `k` залишок спадає експоненційно як `e^(-(k+1))`, однак завжди залишається строго більшим за нуль.

Саме тому сучасні високонадійні системи (такі як Cassandra, Consul чи Amazon Dynamo) використовують гібридний конвеєр: швидкі чутки (Rumor Mongering) забезпечують доставку 99.9% вузлів за мілісекунди, а фонова анти-ентропія (Anti-Entropy) періодично очищує залишок `s_∞`, доводячи узгодженість до абсолютної одиниці.
