# 🧮 Математичні основи причинного порядку та векторних просторів

Розподілене обчислення моделюється як сукупність скінченної кількості процесів `P = {P₁, P₂, ..., P_N}`, кожен із яких генерує послідовність локальних дій. Множину всіх подій, що відбуваються в системі, позначимо як `E`. Подія належить до одного з трьох типів: локальна дія процесу, надсилання повідомлення або отримання повідомлення.

Мета математичної формалізації — встановити відношення порядку на множині `E`, яке дозволяє детерміновано визначати, чи могла одна подія вплинути на стан іншої без посилання на абсолютний фізичний час.

### Частково впорядкована множина подій (Poset)

Причинно-наслідковий зв'язок формалізується через бінарне відношення «сталося-раніше» (англ. *happened-before relation*), яке позначається символом `→` та визначається трьома аксіомами Леслі Лампорта:

1. **Локальний порядок:** якщо події `a` та `b` відбулися на одному процесі `P_i`, і подія `a` передувала `b` у внутрішньому журналі процесу, то `a → b`.
2. **Передача повідомлення:** якщо подія `s` є відправленням повідомлення процесом `P_i`, а подія `r` — отриманням цього ж повідомлення процесом `P_j`, то `s → r`.
3. **Транзитивність:** якщо `a → b` та `b → c`, то `a → c`.

Математично структура `(E, →)` є **строгим частковим порядком** (англ. *strict partial order*), оскільки для будь-яких `a, b, c ∈ E` виконуються такі фундаментальні властивості:

```
Іррефлексивність:
¬(a → a)                         [подія не може передувати самій собі]

Асиметричність:
a → b ⇒ ¬(b → a)                 [відсутність причинних петель у часі]

Транзитивність:
a → b ∧ b → c ⇒ a → c           [поширення впливу вздовж ланцюжка]
```

#### Паралельність (Конкурентність)

Якщо між двома подіями `a` та `b` немає прямого чи опосередкованого причинного зв'язку, вони називаються **паралельними** або **конкурентними** (позначається `a ∥ b`):

```
a ∥ b ⇔ ¬(a → b) ∧ ¬(b → a) ∧ (a ≠ b)
```

Властивість паралельності є симетричною (`a ∥ b ⇔ b ∥ a`), але **не є транзитивною**: якщо `a ∥ b` та `b ∥ c`, це не гарантує, що `a ∥ c`. Події `a` та `c` цілком можуть бути причинно пов'язаними ланцюжком `a → c`, про який проміжний процес з подією `b` нічого не знав.

### Причинні конуси та конуси історії

Для кожної події `e ∈ E` визначимо її **причинне минуле** (або замкнений донизу ідеал часткового порядку, англ. *causal past* або *down-set*), яке позначається як `J(e)`:

```
J(e) = { x ∈ E | x → e } ∪ { e }
```

Множина `J(e)` містить саму подію `e` та всі події системи, що причинно передували їй. На основі теорії частково впорядкованих множин встановлюється фундаментальний зв'язок між включенням множин та причинністю:

```
a → b ⇔ J(a) ⊂ J(b)             [строге включення причинних історій]
```

Доведення цього твердження розпадається на дві частини:
1. Якщо `a → b`, то для будь-якого `x ∈ J(a)` маємо `x → a` або `x = a`. За транзитивністю `x → b`, отже `x ∈ J(b)`. Оскільки `b ∈ J(b)`, але `b ∉ J(a)` (через асиметричність `b → a` неможливе), отримуємо строге включення `J(a) ⊂ J(b)`.
2. Якщо `J(a) ⊂ J(b)`, то оскільки `a ∈ J(a)`, маємо `a ∈ J(b)`. За означенням `J(b)`, це означає `a → b` або `a = b`. Оскільки включення строге (`J(a) ≠ J(b)`), `a ≠ b`, отже `a → b`.

### Векторний годинник як проекція потужностей причинних множин

Розділимо множину всіх подій `E` на неперетинні підмножини локальних подій кожного процесу:

```
E = E₁ ∪ E₂ ∪ ... ∪ E_N, де E_i ∩ E_j = ∅ при i ≠ j
```

Оскільки локальні події процесу `P_k` утворюють лінійний порядок `e_k,1 < e_k,2 < ... < e_k,m`, перетин причинного минулого `J(e)` з множиною подій `E_k` являє собою початковий префікс локальної історії процесу `P_k`:

```
J_k(e) = J(e) ∩ E_k = { e_k,1, e_k,2, ..., e_k,p }
```

**Векторний годинник** події `e`, який позначається `V(e)`, є вектором цілих невід'ємних чисел розмірності `N`, де кожна координата `k` дорівнює кількості подій процесу `P_k`, що увійшли до причинного минулого події `e`:

```
V(e) = [ v₁, v₂, ..., v_N ], де v_k = |J_k(e)| = |J(e) ∩ E_k|
```

#### Правила порівняння векторів

Для двох векторів `u = [u₁, ..., u_N]` та `w = [w₁, ..., w_N]` операції відношення порядку визначаються покоординатно:

```
u ≤ w ⇔ ∀k ∈ {1, ..., N}: u_k ≤ w_k
u < w ⇔ (u ≤ w) ∧ (u ≠ w) ⇔ (∀k: u_k ≤ w_k) ∧ (∃j: u_j < w_j)
u ∥ w ⇔ ¬(u ≤ w) ∧ ¬(w ≤ u)
```

#### Теорема про ізоморфізм причинності та векторного порядку

**Теорема:** Для будь-яких двох подій `a, b ∈ E` виконується еквівалентність:

```
a → b ⇔ V(a) < V(b)
a ∥ b ⇔ V(a) ∥ V(b)
```

**Доведення:**
Розглянемо прямий та зворотний напрямки:

```
a → b
⇒ J(a) ⊂ J(b)                   [властивість конусів історії]
⇒ ∀k: (J(a) ∩ E_k) ⊆ (J(b) ∩ E_k) [звуження на кожен процес]
⇒ ∀k: |J(a) ∩ E_k| ≤ |J(b) ∩ E_k| [монотонність потужності скінченних множин]
⇒ ∀k: V(a)[k] ≤ V(b)[k]          [за означенням векторного годинника]
⇒ V(a) ≤ V(b)

Оскільки J(a) ⊂ J(b), існує елемент x ∈ J(b) такий, що x ∉ J(a).
Нехай x належить процесу P_j (тобто x ∈ E_j).
Тоді |J(a) ∩ E_j| < |J(b) ∩ E_j|, отже V(a)[j] < V(b)[j].
Звідси V(a) < V(b).
```

Зворотне доведення базується на тому, що оскільки множина локальних подій процесу `P_k` є лінійно впорядкованим префіксом, число `V(e)[k] = p` однозначно ідентифікує конкретну підмножину `{e_k,1, ..., e_k,p}`. Якщо `V(a)[k] ≤ V(b)[k]` для всіх `k`, то `(J(a) ∩ E_k) ⊆ (J(b) ∩ E_k)` для кожного `k`. Об'єднуючи за всіма процесами, отримуємо:

```
J(a) = ⋃ (J(a) ∩ E_k) ⊆ ⋃ (J(b) ∩ E_k) = J(b)
```

Якщо `V(a) < V(b)`, то рівність неможлива, отже `J(a) ⊂ J(b)`, що за попередньою лемою означає `a → b`. Звідси ізоморфізм доведено повністю.

### Теорема Шаррон-Бост про мінімальну розмірність простору

Часто виникає інженерна спокуса стиснути вектор розмірності `N` до меншої кількості чисел (наприклад, до двох або трьох псевдо-вимірів чи хешів), щоб зменшити витрати мережевого трафіку.

У 1991 році французька дослідниця Бернадетт Шаррон-Бост (Bernadette Charron-Bost) опублікувала фундаментальну працю «Concerning the Size of Logical Clocks in Distributed Systems», у якій довела неможливість такого стиснення без втрати точності.

**Розмірність часткового порядку:** Розмірністю часткового порядку `poset-dim(E, →)` називається мінімальна кількість лінійних порядків `L₁, L₂, ..., L_d`, перетин яких точно відтворює відношення `→` (тобто `a → b ⇔ ∀i ∈ {1..d}: a <_L_i b`).

**Теорема Шаррон-Бост:** У системі з `N` взаємодіючих процесів розмірність часткового порядку причинності може досягати `N`:

```
max { poset-dim(E, →) } = N
```

**Наслідок:** Будь-яка схема логічних міток, що використовує вектори фіксованого розміру `d < N`, не здатна в загальному випадку зберегти точний причинний ізоморфізм. Зменшення розмірності веде до однієї з двох математичних помилок:
1. **Помилкова причинність (False Causality):** система вважає, що `a → b`, хоча насправді `a ∥ b`.
2. **Помилкова конкурентність (False Concurrency):** система вважає, що `a ∥ b`, хоча насправді `a → b` (ризик небезпечного перезапису або створення зайвих конфліктів).

Отже, вектор розмірності `N` є мінімально необхідною та достатньою інформаційною структурою для фіксації точного причинного порядку в системі з `N` процесів.

### Алгебраїчна ґратка глобальних станів (Lattice of Global Cuts)

Векторні годинники утворюють **дистрибутивну ґратку** (англ. *distributive lattice*) відносно операцій покомпонентного мінімуму та максимуму:

```
Точна верхня межа (Join / Об'єднання станів):
(u ⊔ w)[k] = max(u_k, w_k)      [найменший стан, що бачив історію обох подій]

Точна нижня межа (Meet / Перетин станів):
(u ⊓ w)[k] = min(u_k, w_k)      [найбільший спільний причинний предок]
```

Ці операції задовольняють законам комутативності, асоціативності, ідемпотентності та дистрибутивності:

```
u ⊔ (w ⊓ z) = (u ⊔ w) ⊓ (u ⊔ z)
u ⊓ (w ⊔ z) = (u ⊓ w) ⊔ (u ⊓ z)
```

### Теорема Біркгофа та структура простору узгоджених зрізів

Зв'язок між частковим порядком подій `(E, →)` та простором глобальних станів системи строго описується **теоремою Біркгофа про представлення скінченних дистрибутивних ґраток** (англ. *Birkhoff's Representation Theorem*):

```
Будь-яка скінченна дистрибутивна ґратка L ізоморфна ґратці замкнених донизу
підмножин (ідеалів) частково впорядкованої множини своїх нерозкладних елементів:
L ≅ J(Poset(L))
```

У контексті розподілених систем це означає:
- **Глобальний стан (Global Snapshot / Cut):** підмножина подій `C ⊆ E` називається **узгодженим зрізом** (англ. *consistent cut*), якщо вона замкнена відносно причинності:
  `∀ e ∈ C: J(e) ⊆ C` (якщо подія потрапила у зріз, усі її причинні попередники також належать цьому зрізу).
- **Векторне представлення зрізу:** будь-який узгоджений зріз `C` однозначно кодується вектором `V_C = [c₁, c₂, ..., c_N]`, де `c_k = |C ∩ E_k|` — кількість подій кожного процесу, що увійшли до зрізу.
- **Діаграма Хассе простору станів:** множина всіх можливих узгоджених зрізів системи утворює дистрибутивну ґратку відносно операцій `∪` (Join / об'єднання знань) та `∩` (Meet / спільне минуле).

```
Векторне обчислення зрізів:
(V_C1 ⊔ V_C2)[k] = max(V_C1[k], V_C2[k])  [найменший спільний зріз-нащадок]
(V_C1 ⊓ V_C2)[k] = min(V_C1[k], V_C2[k])  [найбільший спільний зріз-предок]
```

Завдяки теоремі Біркгофа алгоритми створення розподілених знімків (наприклад, алгоритм Чанді-Лампорта) та перевірки глобальних предикатів можуть шукати узгоджені стани безпосередньо у векторному просторі, спираючись на властивості дистрибутивних ґраток без повного перебору всіх можливих перестановок подій.
