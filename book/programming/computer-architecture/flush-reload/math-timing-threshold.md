# 🧮 Статистична сепарація часових розподілів та калібрування порогу

Точність відновлення секретної інформації через сайд-канал Flush+Reload безпосередньо залежить від математичної якості бінарного класифікатора, який за виміряним часом доступу `t` (у процесорних тактах) вирішує: перебувала лінія пам'яті в кеші (подія `Hit`) чи її довелося завантажувати з оперативної пам'яті (подія `Miss`). Через асинхронний шум шини, системні переривання, конкуренцію за контролер DRAM та динамічну зміну тактової частоти ядер час вимірювання є не детермінованою константою, а неперервною випадковою величиною `T`.

### Статистична модель суміші розподілів

Узагальнений розподіл виміряного часу доступу моделюється як суміш двох одновимірних імовірнісних розподілів:

```
f(t) = w_hit · f_hit(t) + w_miss · f_miss(t)
```

де `w_hit` та `w_miss` — апріорні ймовірності звернення жертви до досліджуваної лінії (`w_hit + w_miss = 1`), а `f_hit(t)` та `f_miss(t)` — умовні густини ймовірності часу відгуку для кешованого та некешованого станів відповідно.

В ідеальних умовах обидва розподіли наближаються до нормальних (гаусових) законів:

```
f_hit(t)  = (1 / (σ_hit · √(2π))) · exp( −(t − μ_hit)² / (2 · σ_hit²) )
f_miss(t) = (1 / (σ_miss · √(2π))) · exp( −(t − μ_miss)² / (2 · σ_miss²) )
```

Типові емпіричні параметри для мікроархітектур x86-64 (наприклад, Intel Skylake/Coffee Lake на частоті 3.6 ГГц):
* **Кешований стан (L1/L2/LLC Hit):** математичне сподівання `μ_hit ≈ 42–65` тактів, середньоквадратичне відхилення `σ_hit ≈ 4–8` тактів.
* **Некешований стан (DRAM Miss):** математичне сподівання `μ_miss ≈ 210–260` тактів, середньоквадратичне відхилення `σ_miss ≈ 20–35` тактів.

```
Густина ймовірності
  ^
  |        f_hit(t)                              f_miss(t)
  |        [ Кеш ]                                [ DRAM ]
  |          /\                                      /\
  |         /  \                                    /  \
  |        /    \                                  /    \
  |_______/______\_______________|________________/______\________> Час t (такти)
                 μ_hit       T_thresh             μ_miss
```

### Тримодальна модель для багаторівневої ієрархії кешів

На практиці кешований стан `Hit` не є монолітним: час зчитування залежить від того, на якому саме рівні ієрархії зупинився пошук даних. Повна мікроархітектурна модель є сумішшю чотирьох компонентів:

```
f(t) = w_L1 · f_L1(t) + w_L2 · f_L2(t) + w_LLC · f_LLC(t) + w_DRAM · f_DRAM(t)
```

1. **L1D Hit (`μ_L1 ≈ 4–5` тактів, `σ_L1 ≈ 1` такт):** дані присутні безпосередньо у приватному кеші поточного ядра (найвища швидкість, мінімальна дисперсія).
2. **L2 Hit (`μ_L2 ≈ 12–14` тактів, `σ_L2 ≈ 2` такти):** дані витіснені з L1D, але збереглися у проміжному кеші ядра.
3. **LLC / L3 Hit (`μ_LLC ≈ 45–65` тактів, `σ_LLC ≈ 6` тактів):** дані були підтягнуті жертвою на іншому ядрі й перебувають у спільному інклюзивному кеші сокета.
4. **DRAM Miss (`μ_DRAM ≈ 200–260` тактів, `σ_DRAM ≈ 25` тактів):** повний промах усіх кешів, завантаження з шини пам'яті.

Багаторівневий аналіз дозволяє досліднику не лише зафіксувати факт звернення, а й оцінити часову свіжість доступу: чи виконувала жертва операцію безпосередньо перед заміром (L1/L2), чи пройшов значний інтервал часу, за який дані встигли опуститися до L3.

### Відношення сигнал/шум (SNR) та критерій Фішера

Якість фізичного розділення двох станів визначається коефіцієнтом сепарації Фішера (Fisher's Discriminant Ratio), який виступає мікроархітектурним еквівалентом відношення сигнал/шум (SNR):

```
SNR = (μ_miss − μ_hit)² / (σ_miss² + σ_hit²)
```

Якщо підставити характерні апаратні значення:

```
SNR
= (230 − 50)² / (25² + 6²)      [підстановка параметрів x86]
= 180² / (625 + 36)             [обчислення різниці та дисперсій]
= 32400 / 661                   [сума дисперсій у знаменнику]
≈ 49.0                          [високий рівень розділення станів]
```

Значення `SNR >> 1` означає, що відстань між математичними сподіваннями багаторазово перевищує сумарну дисперсію шуму. Це пояснює фундаментальну перевагу Flush+Reload над колізійними атаками типу Prime+Probe, де `SNR` часто коливається в діапазоні від `0.5` до `2.0` через накладання різних фізичних сторінок на один набір кешу.

### Ймовірності помилок класифікації та функція помилок

При фіксованому порозі прийняття рішення `T` правило класифікації формулюється як:

```
Рішення = Hit,   якщо t < T
Рішення = Miss,  якщо t ≥ T
```

Це правило породжує два типи помилок:

1. **Хибне спрацьовування (False Positive, помилка I роду):** лінія не була в кеші (Miss), але через затримку вимірювання або викид класифікована як Hit:
   ```
   FPR(T) = P(T < T | Miss) = (1/2) · [1 + erf( (T − μ_miss) / (σ_miss · √2) )]
   ```
2. **Пропуск цілі (False Negative, помилка II роду):** лінія була в кеші (Hit), але через переривання ядра чи конфлікт шини читання тривало довше за `T` і зараховане як Miss:
   ```
   FNR(T) = P(T ≥ T | Hit) = (1/2) · [1 − erf( (T − μ_hit) / (σ_hit · √2) )]
   ```

де `erf(x) = (2 / √π) · ∫_0^x exp(−u²) du` — стандартна функція помилок Гаусса.

### Мінімізація баєсового ризику з асиметричними штрафами

У реальних криптографічних атаках ціна помилок часто є асиметричною: хибний пропуск активності жертви (False Negative) може призвести до втрати ключового біта в послідовності RSA, тоді як поодиноке хибне спрацьовування (False Positive) легко фільтрується наступними статистичними раундами.

Введемо штрафи `C_FP` за помилку I роду та `C_FN` за помилку II роду. Тоді узагальнений баєсів ризик записується як:

```
R(T) = C_FP · w_miss · FPR(T) + C_FN · w_hit · FNR(T)
```

Для мінімізації ризику `R(T)` знайдемо похідну за порогом `T` і прирівняємо її до нуля:

```
dR(T) / dT = C_FP · w_miss · f_miss(T) − C_FN · w_hit · f_hit(T) = 0
```

Звідси отримуємо узагальнене рівняння відношення правдоподібності:

```
f_hit(T_opt) / f_miss(T_opt) = (C_FP · w_miss) / (C_FN · w_hit)
```

Підставивши вирази гаусових густин та прологарифмувавши обидві частини рівності, отримуємо точне квадратне рівняння відносно оптимального порогу `T_opt`:

```
A·T² + B·T + C = 0
```

де коефіцієнти визначаються параметрами апаратури та штрафами:
* `A = σ_miss² − σ_hit²`
* `B = 2 · (μ_miss · σ_hit² − μ_hit · σ_miss²)`
* `C = μ_hit² · σ_miss² − μ_miss² · σ_hit² − 2 · σ_hit² · σ_miss² · ln( (σ_miss · C_FP · w_miss) / (σ_hit · C_FN · w_hit) )`

Якщо дисперсії станів можна вважати приблизно рівними (`σ_hit ≈ σ_miss`), коефіцієнт `A → 0`, і рівняння вироджується в лінійне, даючи класичний симетричний поріг:

```
T_opt = (μ_hit + μ_miss) / 2
```

Для типових значень тестового стенду (`μ_hit = 50` та `μ_miss = 230` тактів) це дає аналітичний поріг `T_opt = (50 + 230) / 2 = 140` тактів.

### Оцінка необхідного обсягу калібрувальної вибірки

Щоб оцінити математичні сподівання `μ_hit` та `μ_miss` з похибкою не більше `ε = 2` такти з довірчою ймовірністю `1 − α = 0.99` (рівень довіри 99%), скористаємося центральною граничною теоремою:

```
N ≥ (z_{α/2} · σ / ε)²
```

де `z_{0.005} ≈ 2.576` — квантиль стандартного нормального розподілу.

Для некешованого стану з дисперсією `σ_miss = 25` тактів мінімальний обсяг вимірювань становить:

```
N_miss
≥ (2.576 · 25 / 2)²             [підстановка параметрів]
= (64.4 / 2)²                   [обчислення чисельника]
= 32.2²                         [ділення на похибку]
≈ 1037 вимірювань               [мінімальна кількість раундів]
```

Саме тому в інженерних реалізаціях зондів кількість калібрувальних раундів обирають рівною `2000` або `5000` ітерацій, що гарантує абсолютну стабільність знайденого порогу.

### Інформаційна пропускна здатність каналу витоку

З погляду теорії інформації Шеннона, сайд-канал Flush+Reload є **двійковим асиметричним каналом** (Binary Asymmetric Channel, BAC), де вхідний символ `X ∈ {0, 1}` позначає факт доступу жертви, а вихідний символ `Y ∈ {0, 1}` — результат вимірювання затримки відносно порогу `T`.

Матриця перехідних ймовірностей каналу має вигляд:

```
P(Y=0 | X=0) = 1 − FPR(T)       P(Y=1 | X=0) = FPR(T)
P(Y=0 | X=1) = FNR(T)           P(Y=1 | X=1) = 1 − FNR(T)
```

Пропускна здатність каналу `C` (у бітах на одне вимірювання) визначається максимумом взаємної інформації `I(X; Y)`:

```
C = max_{P(X)} I(X; Y) = max_{P(X)} [ H(Y) − H(Y | X) ]
```

Оскільки для Flush+Reload значення `FPR` та `FNR` на відкаліброваному порозі становлять менше `0.01` (помилка менше 1%), ентропія шуму `H(Y | X)` наближається до нуля:

```
C ≈ 1 − h_2(FPR) ≈ 1 − 0.08 = 0.92 біта/замір
```

Це означає, що канал передає інформацію майже з максимальною теоретичною швидкістю: кожен цикл Flush+Reload надійно екстрагує майже повний біт секретного стану.

### Автоматичне калібрування методом Оцу

На практиці точні параметри `μ` та `σ` заздалегідь невідомі й залежать від поточної частоти процесора (DVFS), типу материнської плати та таймінгів оперативної пам'яті. Для автоматичного знаходження порогу під час ініціалізації вимірювального зонда застосовують **метод Оцу** (Otsu's thresholding method).

Метод Оцу знаходить такий поріг `T`, який максимізує міжкласову дисперсію `σ_B²(T)` дискретної гістограми спостережень `H[0..K]`:

```
σ_B²(T) = ω_0(T) · ω_1(T) · (μ_0(T) − μ_1(T))²
```

де:
* `ω_0(T) = ∑_{i=0}^{T} p_i` — сумарна ймовірність значень лівіше від порогу (клас Hit);
* `ω_1(T) = ∑_{i=T+1}^{K} p_i = 1 − ω_0(T)` — сумарна ймовірність значень правіше від порогу (клас Miss);
* `μ_0(T) = (∑_{i=0}^{T} i · p_i) / ω_0(T)` — середнє значення класу Hit;
* `μ_1(T) = (∑_{i=T+1}^{K} i · p_i) / ω_1(T)` — середнє значення класу Miss.

```
Алгоритм калібрування:
1. Зібрати N вимірювань завідомо кешованих адрес (Hit).
2. Зібрати N вимірювань завідомо витіснених адрес (Miss).
3. Побудувати спільну гістограму H[t].
4. Обчислити міжкласову дисперсію σ_B²(T) для всіх кандидатів T ∈ [0, 400].
5. Вибрати T_calib = argmax_T σ_B²(T).
```

Отримане значення `T_calib` гарантує мінімальний рівень шуму при реєстрації доступу жертви без необхідності ручного підбору констант під кожен окремий процесор.
