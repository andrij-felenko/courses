# 🔌 Довідник API атомарних операцій ядра Linux

Цей довідник містить повну вичерпну таблицю стандартних атомарних операцій ядра Linux для типів `atomic_t`, `atomic64_t` та розширеного безпечного лічильника посилань `refcount_t`.

Усі функції оголошені в заголовочних файлах `<linux/atomic.h>` та `<linux/refcount.h>` і є стандартним стандартизованим інтерфейсом ядра для всіх апаратних архітектур (x86_64, ARM64, RISC-V, MIPS, PowerPC).

## Повна таблиця функцій для atomic_t та atomic64_t

| Сигнатура функції | Повертає значення | Повний опис дії та механізм |
| :--- | :--- | :--- |
| `ATOMIC_INIT(int i)` | `atomic_t` | Макрос статичної ініціалізації структури `atomic_t` початковим значенням `i`. |
| `atomic_read(const atomic_t *v)` | `int` | Атомарно зчитує поточне значення змінної `v` із пам'яті. |
| `atomic_set(atomic_t *v, int i)` | `void` | Атомарно встановлює значення змінної `v = i`. |
| `atomic_add(int i, atomic_t *v)` | `void` | Атомарно додає значення `i` до змінної `v`. |
| `atomic_sub(int i, atomic_t *v)` | `void` | Атомарно віднімає значення `i` від змінної `v`. |
| `atomic_inc(atomic_t *v)` | `void` | Атомарно збільшує значення `v` на 1 (`v++`). |
| `atomic_dec(atomic_t *v)` | `void` | Атомарно зменшує значення `v` на 1 (`v--`). |
| `atomic_inc_return(atomic_t *v)` | `int` | Атомарно збільшує `v` на 1 і повертає **НОВЕ** отримане значення. |
| `atomic_dec_return(atomic_t *v)` | `int` | Атомарно зменшує `v` на 1 і повертає **НОВЕ** отримане значення. |
| `atomic_fetch_add(int i, atomic_t *v)` | `int` | Атомарно додає `i` до `v` і повертає **СТАРЕ** значення, яке було до додавання. |
| `atomic_dec_and_test(atomic_t *v)` | `bool` | Зменшує `v` на 1 і повертає `true`, якщо після зменшення результат дорівнює `0`. |
| `atomic_cmpxchg(atomic_t *v, int old, int new)` | `int` | Замінює `v` на `new`, якщо початкове значення `v == old`. Повертає початкове значення `v`. |

## Безпечні лічильники посилань refcount_t

У сучасному ядрі Linux для лічильників посилань замість `atomic_t` застосовується тип `refcount_t`, який додає апаратні перевірки переповнення:

| Сигнатура функції | Повний опис захисного механізму |
| :--- | :--- |
| `REFCOUNT_INIT(int i)` | Ініціалізує лічильник посилань `refcount_t` значенням `i`. |
| `refcount_inc(refcount_t *r)` | Атомарно збільшує `r`. Захищає від overflow (насичує на `INT_MAX`) та блокує використання після звільнення. |
| `refcount_dec_and_test(refcount_t *r)` | Зменшує `r` і повертає `true`, якщо результат став `0`. Безпечно тригерить деалокацію пам'яті. |
