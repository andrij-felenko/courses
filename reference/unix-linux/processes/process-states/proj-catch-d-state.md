РЈСЃСЏ СЃРєР»Р°РґРЅС–СЃС‚СЊ РїРѕР»СЏРіР°С” РІ С‚РѕРјСѓ, С‰РѕР± РЅР°РґС–Р№РЅРѕ Р·Р°С„С–РєСЃСѓРІР°С‚Рё СЃС‚Р°РЅ `D`. РўРѕР±С‚Рѕ С‰РѕР± РїРѕР±Р°С‡РёС‚Рё С‚Р°РєРёР№ РєРѕСЂРѕС‚РєРёР№ `D` Р±РѕРґР°Р№ РѕРґРёРЅ СЂР°Р·, С‚СЂРµР±Р° Р·РіРµРЅРµСЂСѓРІР°С‚Рё СЃРѕС‚РЅС– РїРѕСЃР»С–РґРѕРІРЅРёС… РѕРїРµСЂР°С†С–Р№ РІРІРѕРґСѓ-РІРёРІРѕРґСѓ. РљРѕСЂРѕС‚РєРёС… СЃРїР»РµСЃРєС–РІ Р·РІРёС‡Р°Р№РЅРёРј РїРµСЂС–РѕРґРёС‡РЅРёРј РѕРїРёС‚СѓРІР°РЅРЅСЏРј `/proc` РЅРµ СЃРїС–Р№РјР°С‚Рё вЂ” РґР»СЏ РЅРёС… РІРёРєРѕСЂРёСЃС‚РѕРІСѓСЋС‚СЊ РїРѕРґС–Р№РЅС– С‚СЂР°СЃСѓРІР°Р»СЊРЅС– С‚РѕС‡РєРё СЏРґСЂР°, РїСЂРѕ СЏРєС– Р№РґРµС‚СЊСЃСЏ РЅР°РїСЂРёРєС–РЅС†С–.

РћС‚Р¶Рµ, РґР»СЏ РЅР°РґС–Р№РЅРѕРіРѕ СЃРїРѕСЃС‚РµСЂРµР¶РµРЅРЅСЏ РїРѕС‚СЂС–Р±РµРЅ РЅРµРїРµСЂРµСЂРёРІРЅРёР№ СЃРѕРЅ, СЏРєРёР№ С‚СЂРёРІР°С” **РєРµСЂРѕРІР°РЅРѕ РґРѕРІРіРѕ**. РўР°РєРёС… СЃРїРѕСЃРѕР±С–РІ С–СЃРЅСѓС” РґРІР°, С– РІРѕРЅРё С†С–РЅРЅС– СЃР°РјРµ С‚РёРј, С‰Рѕ РґРµРјРѕРЅСЃС‚СЂСѓСЋС‚СЊ `D` СЂС–Р·РЅРѕС— РїСЂРёСЂРѕРґРё: РѕРґРёРЅ вЂ” С†Рµ РіС–Р±СЂРёРґРЅРёР№ РЅРµРїРµСЂРµСЂРёРІРЅРёР№ СЃРѕРЅ `TASK_KILLABLE`, СЏРєРёР№ РјРѕР¶РЅР° РїРµСЂРµСЂРІР°С‚Рё СЃРјРµСЂС‚РµР»СЊРЅРёРј СЃРёРіРЅР°Р»РѕРј, Р° РґСЂСѓРіРёР№ вЂ” РЅРµРїРµСЂРµСЂРёРІРЅРёР№ СЃРѕРЅ Сѓ С‡РёСЃС‚РѕРјСѓ РІРёРіР»СЏРґС– `TASK_UNINTERRUPTIBLE`, СЏРєРёР№ С–РіРЅРѕСЂСѓС” РЅР°РІС–С‚СЊ `SIGKILL`.

## РЎРїРѕСЃС–Р± РїРµСЂС€РёР№: СЃРѕРЅ, СЏРєРёР№ РґР°СЂСѓС” vfork

РќР°Р№РґРµС€РµРІС€РёР№ С– РЅР°Р№РїСЂРѕСЃС‚С–С€РёР№ `D` РЅРµ РїРѕС‚СЂРµР±СѓС” РЅС– РїСЂРёРІС–Р»РµС—РІ `root`, РЅС– СЃРїСЂР°РІР¶РЅСЊРѕРіРѕ РґРёСЃРєР°, РЅС– РґРѕРґР°С‚РєРѕРІРёС… РїСЂРёСЃС‚СЂРѕС—РІ. Р™РѕРіРѕ РґР°С” СЃРёСЃС‚РµРјРЅРёР№ РІРёРєР»РёРє `vfork()` Р°Р±Рѕ `clone(CLONE_VFORK)`.

РљРѕР»Рё РїСЂРѕС†РµСЃ РїРѕСЂРѕРґР¶СѓС” РґРёС‚РёРЅСѓ Р· РїСЂР°РїРѕСЂС†РµРј `CLONE_VFORK`, СЏРґСЂРѕ Р·СѓРїРёРЅСЏС” **Р±Р°С‚СЊРєС–РІСЃСЊРєРёР№ РїСЂРѕС†РµСЃ** С– С‚СЂРёРјР°С” Р№РѕРіРѕ Р·Р°Р±Р»РѕРєРѕРІР°РЅРёРј РґРѕС‚Рё, РґРѕРєРё РґРёС‚РёРЅР° РЅРµ РІРёРєР»РёС‡Рµ `execve()` Р°Р±Рѕ РЅРµ Р·Р°РІРµСЂС€РёС‚СЊСЃСЏ С‡РµСЂРµР· `_exit()`. Р’РЅСѓС‚СЂС–С€РЅСЊРѕ СЏРґСЂРѕ СЂРµР°Р»С–Р·СѓС” С†Рµ С‡РµСЂРµР· СЃС‚СЂСѓРєС‚СѓСЂСѓ РїСЂРёРјС–С‚РёРІР° СЃРёРЅС…СЂРѕРЅС–Р·Р°С†С–С— `completion` (`vfork_done`). Р¦Рµ С– С” С‚РѕР№ СЂС–РґРєС–СЃРЅРёР№ РІРёРїР°РґРѕРє, РєРѕР»Рё С‡РµРєР°РЅРЅСЏ РЅРµРїРµСЂРµСЂРёРІРЅРѕРіРѕ СЃРЅСѓ С†С–Р»РєРѕРј РїС–РґРєРѕРЅС‚СЂРѕР»СЊРЅРµ РЅР°С€РѕРјСѓ РєРѕРґСѓ: СЃРєС–Р»СЊРєРё СЃРµРєСѓРЅРґ РґРёС‚РёРЅР° РїСЂРѕСЃРїРёС‚СЊ Сѓ `nanosleep()`, СЃС‚С–Р»СЊРєРё Р±Р°С‚СЊРєРѕ Р№ РїСЂРѕСЃС‚РѕС—С‚СЊ Сѓ РѕС‡С–РєСѓРІР°РЅРЅС–. РЎРёСЃС‚РµРјРЅРёР№ РІРёРєР»РёРє `clone()` С” СѓР·Р°РіР°Р»СЊРЅРµРЅРЅСЏРј `fork()`, РґРµ РЅР°Р±РѕСЂРѕРј РїСЂР°РїРѕСЂС†С–РІ Р·Р°РґР°С”С‚СЊСЃСЏ, СЏРєС– СЃР°РјРµ СЂРµСЃСѓСЂСЃРё РґРёС‚РёРЅР° РїРѕРґС–Р»РёС‚СЊ С–Р· Р±Р°С‚СЊРєРѕРј. РЎС‚Р°РЅРґР°СЂС‚РЅРёР№ `vfork()` Сѓ Р±С–Р±Р»С–РѕС‚РµС†С– glibc СЂРµР°Р»С–Р·РѕРІР°РЅРѕ СЃР°РјРµ С‡РµСЂРµР· `clone()` С–Р· РїСЂР°РїРѕСЂС†СЏРјРё `CLONE_VM | CLONE_VFORK` ([vfork, posix_spawn С– clone](book:unix-linux/spawn-alternatives)).

РўРµРїРµСЂ РЅР°Р№С†С–РєР°РІС–С€Рµ вЂ” Сѓ СЏРєРѕРјСѓ СЃР°РјРµ СЃС‚Р°РЅС– С‡РµРєР°С” Р±Р°С‚СЊРєС–РІСЃСЊРєРёР№ РїСЂРѕС†РµСЃ. РЈ РєРѕРґС– СЏРґСЂР° С†Рµ РІРёРєР»РёРє `wait_for_completion_state()` С–Р· `kernel/fork.c`:

```c

{
    unsigned int state = TASK_KILLABLE|TASK_FREEZABLE;
    ...
    killed = wait_for_completion_state(vfork, state);
```

РЎРїРµС†С–Р°Р»СЊРЅРµ РєРѕРЅСЃС‚Р°РЅС‚РЅРµ Р·РЅР°С‡РµРЅРЅСЏ `TASK_KILLABLE` вЂ” С†Рµ РЅРµ РѕРєСЂРµРјРёР№ СЃР°РјРѕСЃС‚С–Р№РЅРёР№ СЃС‚Р°РЅ СЏРґСЂР°, Р° СЃСѓРјР° РґРІРѕС… Р±С–С‚РѕРІРёС… РїСЂР°РїРѕСЂС†С–РІ: `TASK_UNINTERRUPTIBLE` (0x0002) РїР»СЋСЃ `TASK_WAKEKILL` (0x0100). РџСЂРѕС‚Рµ РЅР°Р·РѕРІРЅС– Сѓ РїСЂРѕСЃС‚С–СЂ РєРѕСЂРёСЃС‚СѓРІР°С‡Р° `/proc` РІС–РґРґР°С” РЅРµ РІСЃС– Р±С–С‚Рё `__state`, Р° Р»РёС€Рµ С‚С–, СЏРєС– РїСЂРѕС…РѕРґСЏС‚СЊ РєСЂС–Р·СЊ РјР°СЃРєСѓ `TASK_REPORT`; РїСЂР°РїРѕСЂРµС†СЊ `TASK_WAKEKILL` РґРѕ С†С–С”С— РјР°СЃРєРё РЅРµ РІС…РѕРґРёС‚СЊ. Р— РґРІРѕС… РїСЂР°РїРѕСЂС†С–РІ Сѓ РїС–РґСЃСѓРјРєРѕРІСѓ Р»С–С‚РµСЂСѓ РїРµСЂРµС‚РІРѕСЂСЋС”С‚СЊСЃСЏ Р»РёС€Рµ РїРµСЂС€РёР№ вЂ” С– СѓС‚РёР»С–С‚Рё `ps` С‡Рё `top` С‡РµСЃРЅРѕ РґСЂСѓРєСѓСЋС‚СЊ Р»С–С‚РµСЂСѓ `D`.

Р’РёС…РѕРґРёС‚СЊ СЂС–РІРЅРѕ С‚Р° СЃРёС‚СѓР°С†С–СЏ, Р·Р°СЂР°РґРё СЏРєРѕС— РґРѕСЃР»С–Рґ С– СЃС‚Р°РІРёС‚СЊСЃСЏ: РїРµСЂРµРґ РЅР°РјРё `D`, СЏРєРёР№ РІРёРіР»СЏРґР°С” СЏРє Р±РµР·РЅР°РґС–Р№РЅРµ Р·Р°РІРёСЃР°РЅРЅСЏ, Р° РЅР°СЃРїСЂР°РІРґС– СЃР»СѓС…Р°С”С‚СЊСЃСЏ `SIGKILL`. ## РџС–РґРґРѕСЃР»С–РґРЅРёР№

РџСЂРѕРіСЂР°РјР° РЅС–С‡РѕРіРѕ РЅРµ РѕР±С‡РёСЃР»СЋС” вЂ” РІРѕРЅР° Р»РёС€Рµ РїРѕ С‡РµСЂР·С– СЃС‚Р°С” РІ РєРѕР¶РµРЅ Р·С– СЃС‚Р°РЅС–РІ С– РіРѕР»РѕСЃРЅРѕ РїРѕРІС–РґРѕРјР»СЏС”, Сѓ СЏРєРёР№ СЃР°РјРµ. РќРёР¶РЅС– РІРёРєР»РёРєРё `clone()`, `raise()`, `_exit()` вЂ” С†Рµ СЃРёСЃС‚РµРјРЅС– РІРёРєР»РёРєРё, СЏРєС– РґРµРјРѕРЅСЃС‚СЂСѓСЋС‚СЊ РїРѕРІРµРґС–РЅРєСѓ СЏРґСЂР° Р±РµР· РїРѕСЃСЃРµСЂРµРґРЅРёРєС–РІ.

```c
/* states.c вЂ” РїС–РґРґРѕСЃР»С–РґРЅРёР№: СЃР°Рј СЃРµР±Рµ РїСЂРѕРІРѕРґРёС‚Рё РєСЂС–Р·СЊ R, S, T, Z С– D.
 * Р—Р±С–СЂРєР°:  cc -O2 -o states states.c
 * Р—Р°РїСѓСЃРє:  ./states &   (Сѓ С„РѕРЅС–, Р±Рѕ С„Р°Р·Р° T Р·СѓРїРёРЅСЏС” РїСЂРѕС†РµСЃ)

#define _GNU_SOURCE
#include <sched.h>

#include <stdio.h>
#include <string.h>

static double now(void)
{
    struct timespec ts;
    clock_gettime(CLOCK_MONOTONIC, &ts);
    return ts.tv_sec + ts.tv_nsec * 1e-9;
}

static double t0;

static void banner(const char *tag, const char *why)
{
    fprintf(stderr, "%7.3f  [%s] %s\n", now() - t0, tag, why);
    fflush(stderr);
}

/* Р›С–С‚РµСЂР° СЃС‚Р°РЅСѓ Р· /proc/PID/stat.
   Р”СЂСѓРіРµ РїРѕР»Рµ вЂ” С–Рј'СЏ РїСЂРѕРіСЂР°РјРё РІ РґСѓР¶РєР°С…, С– РІРѕРЅРѕ РјРѕР¶Рµ РјС–СЃС‚РёС‚Рё С– РїСЂРѕР±С–Р»Рё,
   С– СЃР°РјС– РґСѓР¶РєРё. РўРѕРјСѓ С”РґРёРЅРёР№ РЅР°РґС–Р№РЅРёР№ СЃРїРѕСЃС–Р± вЂ” С€СѓРєР°С‚Рё РћРЎРўРђРќРќР® ')'. */
static char state_of(pid_t pid)
{
    char path[64], buf[512];
    snprintf(path, sizeof path, "/proc/%d/stat", (int)pid);
    FILE *f = fopen(path, "r");
    if (!f) return '?';
    size_t n = fread(buf, 1, sizeof buf - 1, f);
    fclose(f);
    buf[n] = '\0';
    char *p = strrchr(buf, ')');
    return (p && p[1] && p[2]) ? p[2] : '?';
}

/* в”Ђв”Ђ R: РЅС–С‡РѕРіРѕ РЅРµ Р±СЂР°РєСѓС”, РєСЂС–Рј РІС–Р»СЊРЅРѕРіРѕ СЏРґСЂР° в”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђ */
static void phase_running(double secs)
{
    banner("R", "РїРѕСЂРѕР¶РЅС–Р№ С†РёРєР»: Р·Р°РґР°С‡Р° СЃС‚РѕС—С‚СЊ Сѓ С‡РµСЂР·С– РіРѕС‚РѕРІРёС…");
    double end = now() + secs;
    volatile unsigned long x = 0;
    while (now() < end)
        for (int i = 0; i < 100000; i++) x++;
}

/* в”Ђв”Ђ S: СЃРѕРЅ, СЏРєРёР№ Р±СѓРґРёС‚СЊ С– С‚Р°Р№РјРµСЂ, С– СЃРёРіРЅР°Р» в”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђ */
static void phase_sleeping(int secs)
{
    banner("S", "nanosleep: РїРµСЂРµСЂРёРІРЅРёР№ СЃРѕРЅ");
    struct timespec ts = { secs, 0 };
    nanosleep(&ts, NULL);

/* в”Ђв”Ђ T: Р·Р°РґР°С‡Р° РЅРµ С‡РµРєР°С” РЅС–С‡РѕРіРѕ, С—Р№ Р·Р°Р±РѕСЂРѕРЅРµРЅРѕ Р±С–РіС‚Рё в”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђ */
static void phase_stopped(void)
{
    banner("T", "raise(SIGSTOP): РІРёР№С‚Рё РјРѕР¶РЅР° Р»РёС€Рµ С‡РµСЂРµР· SIGCONT");
    raise(SIGSTOP);
    banner("T", "РїСЂРёР№С€РѕРІ SIGCONT вЂ” Р·РЅРѕРІСѓ РІ С‡РµСЂР·С– РіРѕС‚РѕРІРёС…");
}

/* в”Ђв”Ђ Z: Р·РѕРјР±С–. Р¦Рµ РѕРєСЂРµРјРёР№ PID вЂ” РЅР°С€Р° РґРёС‚РёРЅР°, РЅРµ РјРё в”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђ */
static void phase_zombie(int secs)
{
    pid_t kid = fork();
    if (kid == 0) _exit(42);

    struct timespec ts = { 0, 50 * 1000 * 1000 };
    nanosleep(&ts, NULL);                  /* РґР°С‚Рё РґРёС‚РёРЅС– РІРёР№С‚Рё */
    fprintf(stderr, "%7.3f  [Z] РґРёС‚РёРЅР° %d Сѓ СЃС‚Р°РЅС– '%c' вЂ” РєРѕРґ РІРёС…РѕРґСѓ С‰Рµ РЅС–С‡РёР№\n",
            now() - t0, (int)kid, state_of(kid));

    ts.tv_sec = secs; ts.tv_nsec = 0;
    nanosleep(&ts, NULL);
    waitpid(kid, NULL, 0);
    banner("Z", "wait() Р·Р°Р±СЂР°РІ РєРѕРґ РІРёС…РѕРґСѓ вЂ” Р·Р°РїРёСЃ Р·РЅРёРє");
}

/* в”Ђв”Ђ D: РЅРµРїРµСЂРµСЂРёРІРЅРёР№ СЃРѕРЅ РЅР° Р·Р°РјРѕРІР»РµРЅРЅСЏ в”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђв”Ђ */
#define STACK_SZ (256 * 1024)
static int hold_seconds;

static int vfork_child(void *arg)
{
    struct timespec ts = { *(int *)arg, 0 };
    nanosleep(&ts, NULL);
    _exit(0);
}

static void phase_disk_sleep(int secs)
{
    void *stack = mmap(NULL, STACK_SZ, PROT_READ | PROT_WRITE,
                       MAP_PRIVATE | MAP_ANONYMOUS | MAP_STACK, -1, 0);
    if (stack == MAP_FAILED) { perror("mmap"); return; }

    hold_seconds = secs;
    banner("D", "clone(CLONE_VFORK): Р±Р°С‚СЊРєРѕ СЃС‚РѕС—С‚СЊ, РїРѕРєРё РґРёС‚РёРЅР° РЅРµ РІРёР№РґРµ");
    fprintf(stderr, "         СЃРїСЂРѕР±СѓР№С‚Рµ РІ С–РЅС€РѕРјСѓ С‚РµСЂРјС–РЅР°Р»С–:  kill -TERM %d\n"
                    "         Р° РїРѕС‚С–Рј:                       kill -9 %d\n",
            (int)getpid(), (int)getpid());
    fflush(stderr);

    pid_t kid = clone(vfork_child, (char *)stack + STACK_SZ,
                      CLONE_VFORK | SIGCHLD, &hold_seconds);
    if (kid < 0) { perror("clone"); return; }

    waitpid(kid, NULL, 0);
    munmap(stack, STACK_SZ);
    banner("D", "РґРёС‚РёРЅР° РІРёР№С€Р»Р° вЂ” Р±Р°С‚СЊРєРѕ РїСЂРѕРєРёРЅСѓРІСЃСЏ");
}

РўРѕС‡РЅРёР№ СЃРёРјРІРѕР» Сѓ `wchan` Р·Р°Р»РµР¶РёС‚СЊ РІС–Рґ РІРµСЂСЃС–С— СЏРґСЂР° Р№ РІС–Рґ С‚РѕРіРѕ, С‰Рѕ С–РЅР»Р°Р№РЅРµСЂ Р·Р»РёРІ С–Р· СЃСѓСЃС–РґРЅСЊРѕСЋ С„СѓРЅРєС†С–С”СЋ; `kernel_clone`, `wait_for_completion_state` С– РїСЂРѕСЃС‚Рѕ `0` вЂ” СѓСЃРµ С†Рµ РЅРѕСЂРјР°Р»СЊРЅС– РІС–РґРїРѕРІС–РґС–, С– Р¶РѕРґРЅР° Р· РЅРёС… РЅРµ С” РѕР·РЅР°РєРѕСЋ Р±С–РґРё.

![Рџ'СЏС‚СЊ С„Р°Р· РїС–РґРґРѕСЃР»С–РґРЅРѕРіРѕ С– С‰Рѕ РІРёРІРѕРґРёС‚СЊ Р№РѕРіРѕ Р· РєРѕР¶РЅРѕС—](/reference/unix-linux/processes/process-states/img/lab-run.svg)

*Р›С–С‚РµСЂР° РєР°Р¶Рµ, С‡РѕРјСѓ Р·Р°РґР°С‡С– РЅРµРјР°С” РЅР° РїСЂРѕС†РµСЃРѕСЂС–; РїРѕРІРµСЂРЅСѓС‚Рё С—С— РјРѕР¶Рµ С‰РѕСЂР°Р·Сѓ С–РЅС€Р° РїРѕРґС–СЏ вЂ” С– СЃР°РјРµ С‚РѕРјСѓ СЃС‚Р°РЅС–РІ РєС–Р»СЊРєР°, Р° РЅРµ РґРІР°.*

РўРµРїРµСЂ РіРѕР»РѕРІРЅРµ. РџРѕРєРё РїСЂРѕРіСЂР°РјР° СЃС‚РѕС—С‚СЊ Сѓ `D`, РІ С–РЅС€РѕРјСѓ С‚РµСЂРјС–РЅР°Р»С– РЅР°РґС–С€Р»С–С‚СЊ `kill -TERM`. РќРµ СЃС‚Р°РЅРµС‚СЊСЃСЏ РЅС–С‡РѕРіРѕ: СЃРёРіРЅР°Р» Р»СЏР¶Рµ РІ РЅР°Р±С–СЂ РЅРµРґРѕРїСЂР°РІР»РµРЅРёС… С– С‡РµРєР°С‚РёРјРµ. Рђ `kill -9` СѓР±'С” РїСЂРѕС†РµСЃ РЅРµРіР°Р№РЅРѕ вЂ” Р±Рѕ С†РµР№ `D` РЅР°СЃРїСЂР°РІРґС– `TASK_KILLABLE`. Р›С–С‚РµСЂР° С‚Р° СЃР°РјР°, РїРѕРІРµРґС–РЅРєР° СЂС–Р·РЅР°, С– `ps` С†С–С”С— СЂС–Р·РЅРёС†С– РЅРµ РїРѕРєР°Р·СѓС” РЅС–СЏРє.

## РЎРїРѕСЃС–Р± РґСЂСѓРіРёР№: РґРёСЃРє, СЏРєРёР№ РІС–РґРїРѕРІС–РґР°С” С‡РµСЂРµР· С‚СЂРё СЃРµРєСѓРЅРґРё

Р©РѕР± РїРѕР±Р°С‡РёС‚Рё `D`, Р· СЏРєРѕРіРѕ РЅРµ РІРёРІРѕРґРёС‚СЊ РЅР°РІС–С‚СЊ `SIGKILL`, РїРѕС‚СЂС–Р±РµРЅ РїСЂРёСЃС‚СЂС–Р№, СЏРєРёР№ РїРѕРІРѕРґРёС‚СЊСЃСЏ РїРѕРІС–Р»СЊРЅРѕ, Р°Р»Рµ РїРµСЂРµРґР±Р°С‡СѓРІР°РЅРѕ. Р›Р°РјР°С‚Рё РЅС–С‡РѕРіРѕ РЅРµ С‚СЂРµР±Р° вЂ” С‚Р°РєРёР№ РїСЂРёСЃС‚СЂС–Р№ Р·Р±РёСЂР°С”С‚СЊСЃСЏ Р· С„Р°Р№Р»Сѓ Р·Р° С‚СЂРё РєРѕРјР°РЅРґРё.

Device mapper вЂ” РїС–РґСЃРёСЃС‚РµРјР° СЏРґСЂР°, СЏРєР° СЂРѕР±РёС‚СЊ Р±Р»РѕРєРѕРІРёР№ РїСЂРёСЃС‚СЂС–Р№ С–Р· **С‚Р°Р±Р»РёС†С– РІС–РґРѕР±СЂР°Р¶РµРЅСЊ**: РєРѕР¶РµРЅ СЂСЏРґРѕРє РєР°Р¶Рµ, СЏРєРёР№ РґС–Р°РїР°Р·РѕРЅ СЃРµРєС‚РѕСЂС–РІ РєРѕРјСѓ РІС–РґРґР°РІР°С‚Рё Р№ С‡РµСЂРµР· СЏРєРёР№ С€Р°СЂ РѕР±СЂРѕР±РєРё. РЎРµСЂРµРґ С†РёС… С€Р°СЂС–РІ С” `delay` вЂ” РІС–РЅ РїСЂРѕСЃС‚Рѕ Р·Р°С‚СЂРёРјСѓС” РєРѕР¶РµРЅ Р·Р°РїРёС‚ РЅР° Р·Р°РґР°РЅСѓ РєС–Р»СЊРєС–СЃС‚СЊ РјС–Р»С–СЃРµРєСѓРЅРґ ([device mapper](book:unix-linux/device-mapper)). РўРѕР±С‚Рѕ РїРѕРІС–Р»СЊРЅРёР№ РґРёСЃРє РјРѕР¶РЅР° РЅРµ С€СѓРєР°С‚Рё, Р° РѕРїРёСЃР°С‚Рё.

Р”СЂСѓРіРёР№ С–РЅРіСЂРµРґС–С”РЅС‚ вЂ” `O_DIRECT`. Р—РІРёС‡Р°Р№РЅРµ С‡РёС‚Р°РЅРЅСЏ СЃРїРµСЂС€Сѓ Р·Р°Р·РёСЂР°С” РІ РєРµС€ СЃС‚РѕСЂС–РЅРѕРє С–, СЏРєС‰Рѕ Р±Р»РѕРє С‚Р°Рј СѓР¶Рµ С”, РїРѕРІРµСЂС‚Р°С”С‚СЊСЃСЏ РјРёС‚С‚С”РІРѕ, РЅРµ С‚СѓСЂР±СѓСЋС‡Рё РїСЂРёСЃС‚СЂС–Р№ СѓР·Р°РіР°Р»С–; Р· С‚Р°РєРёРј С‡РёС‚Р°РЅРЅСЏРј РґРѕСЃР»С–Рґ РїСЂРѕСЃС‚Рѕ РЅРµ РІС–РґР±СѓРІСЃСЏ Р±. РџСЂР°РїРѕСЂРµС†СЊ `O_DIRECT` РєР°Р¶Рµ СЏРґСЂСѓ РЅРµСЃС‚Рё РґР°РЅС– РїРѕРІР· РєРµС€, РїСЂСЏРјРѕ РјС–Р¶ РїСЂРёСЃС‚СЂРѕС”Рј С– Р±СѓС„РµСЂРѕРј РїСЂРѕРіСЂР°РјРё ([Р±СѓС„РµСЂРёР·РѕРІР°РЅРёР№ С– РїСЂСЏРјРёР№ РІРІС–Рґ-РІРёРІС–Рґ](book:unix-linux/buffered-and-direct-io)). Р—Р°РґР°С‡Р°, СЏРєР° РїРѕРґР°Р»Р° С‚Р°РєРµ С‡РёС‚Р°РЅРЅСЏ, С‡РµРєР°С” РЅР° Р·Р°РІРµСЂС€РµРЅРЅСЏ РѕРїРµСЂР°С†С–С— РІ `TASK_UNINTERRUPTIBLE` вЂ” С‚РѕРјСѓ С‰Рѕ РѕРїРµСЂР°С†С–СЋ РІР¶Рµ РІС–РґРґР°РЅРѕ РєРѕРЅС‚СЂРѕР»РµСЂСѓ Р№ РІС–РґРєР»РёРєР°С‚Рё С—С— РЅРµРјР° СЏРє.

```sh
#!/bin/bash
# slow-disk.sh вЂ” РїРѕС‚СЂС–Р±РЅС– РїСЂР°РІР° root. Р РѕР±РёС‚СЊ D, Р· СЏРєРѕРіРѕ РЅРµ РІРёРІРѕРґРёС‚СЊ SIGKILL.
set -e
IMG=/var/tmp/slow.img

modprobe dm-delay || true
truncate -s 64M "$IMG"
LOOP=$(losetup --find --show "$IMG")
dmsetup create slowdisk --table "0 $(blockdev --getsz "$LOOP") delay $LOOP 0 3000"

dd if=/dev/mapper/slowdisk of=/dev/null bs=4k count=1 iflag=direct &
victim=$!

sleep 0.5
echo "--- РїРѕРєРё С‚СЂРёРІР°С” С‡РёС‚Р°РЅРЅСЏ:"
ps -o pid,stat,wchan:28,comm -p $victim

kill -9 $victim
sleep 0.5
echo "--- С‡РµСЂРµР· РїС–РІСЃРµРєСѓРЅРґРё РїС–СЃР»СЏ kill -9:"
ps -o pid,stat,wchan:28,comm -p $victim

wait $victim || true
echo "--- РѕРїРµСЂР°С†С–СЏ Р·Р°РІРµСЂС€РёР»Р°СЃСЏ вЂ” Р°Р¶ С‚РµРїРµСЂ СЃРёРіРЅР°Р» РїРѕРґС–СЏРІ"

dmsetup remove slowdisk
losetup -d "$LOOP"
rm -f "$IMG"
```

РћР±РёРґРІР° РІРёРєР»РёРєРё `ps` РїРѕРєР°Р¶СѓС‚СЊ С‚РѕР№ СЃР°РјРёР№ СЂСЏРґРѕРє Р·С– СЃС‚Р°РЅРѕРј `D`. РЎРјРµСЂС‚РµР»СЊРЅРёР№ СЃРёРіРЅР°Р» СѓР¶Рµ РґРѕРїСЂР°РІР»РµРЅРѕ, РІС–РЅ СѓР¶Рµ Р»РµР¶РёС‚СЊ Сѓ РЅР°Р±РѕСЂС– РЅРµРґРѕРїСЂР°РІР»РµРЅРёС… Сѓ `task_struct->pending` вЂ” С– РЅРµ СЂРѕР±РёС‚СЊ РЅС–С‡РѕРіРѕ, РїРѕРєРё `dm-delay` РЅРµ РІС–РґР»С–С‡РёС‚СЊ СЃРІРѕС— С‚СЂРё СЃРµРєСѓРЅРґРё С– РЅРµ РІРёРєР»РёС‡Рµ Р°СЃРёРЅС…СЂРѕРЅРЅРµ Р·Р°РІРµСЂС€РµРЅРЅСЏ `bio_endio()`. РџРѕСЂС–РІРЅСЏР№С‚Рµ С†Рµ Р· РїРѕРїРµСЂРµРґРЅС–Рј РґРѕСЃР»С–РґРѕРј: С‚Р°Рј `kill -9` СЃРїСЂР°С†СЋРІР°РІ РјРёС‚С‚С”РІРѕ С‡РµСЂРµР· РїСЂР°РїРѕСЂРµС†СЊ `TASK_WAKEKILL` Сѓ СЃРЅС– `vfork()`, Р° С‚СѓС‚ РЅРµ СЃРїСЂР°С†СЋРІР°РІ Р·РѕРІСЃС–Рј, Р±Рѕ РїС–РґСЃРёСЃС‚РµРјР° Р±Р»РѕРєРѕРІРѕРіРѕ РІРІРѕРґСѓ-РІРёРІРѕРґСѓ С‡РµРєР°С” С„С–Р·РёС‡РЅРѕРіРѕ Р·Р°РІРµСЂС€РµРЅРЅСЏ `bio`. Р›С–С‚РµСЂР° РІ РѕР±РѕС… РІРёРїР°РґРєР°С… РѕРґРЅР° вЂ” `D`.

![РџРѕРІС–Р»СЊРЅРёР№ РґРёСЃРє, Р·С–Р±СЂР°РЅРёР№ С–Р· С„Р°Р№Р»Сѓ: РґРµ СЃР°РјРµ Р±РµСЂСѓС‚СЊСЃСЏ С‚СЂРё СЃРµРєСѓРЅРґРё](/reference/unix-linux/processes/process-states/img/slow-disk-stack.svg)

*Р—Р°С‚СЂРёРјРєСѓ РІРЅРµСЃРµРЅРѕ РІ РѕРґРёРЅ-С”РґРёРЅРёР№ С€Р°СЂ, Р° СЃС‚РѕС—С‚СЊ С‡РµСЂРµР· РЅРµС— РїСЂРѕС†РµСЃ РЅР°РіРѕСЂС– вЂ” С– СЃС‚РѕС—С‚СЊ РЅРµРїРµСЂРµСЂРёРІРЅРѕ, Р±Рѕ Р·Р°РїРёС‚ СѓР¶Рµ РїС–С€РѕРІ СѓРЅРёР·.*

Р—Р°С‚СЂРёРјРєСѓ РІР°СЂС‚Рѕ РїС–РґРЅСЏС‚Рё РґРѕ `dmsetup create ... delay $LOOP 0 130000` С– РЅРµ РІР±РёРІР°С‚Рё РїСЂРѕС†РµСЃ СѓР·Р°РіР°Р»СЊ РІР·Р°РіР°Р»С–: Р·Р° 120 СЃРµРєСѓРЅРґ РїРѕС‚С–Рє `khungtaskd` РЅР°РїРёС€Рµ РІ Р¶СѓСЂРЅР°Р» СЏРґСЂР° СЃРІС–Р№ СЂСЏРґРѕРє РїСЂРѕ Р·Р°Р±Р»РѕРєРѕРІР°РЅСѓ Р·Р°РґР°С‡Сѓ, С– РІРё РїРѕР±Р°С‡РёС‚Рµ С‚Рµ СЃР°РјРµ РїРѕРІС–РґРѕРјР»РµРЅРЅСЏ `INFO: task blocked for more than 120 seconds`, С‰Рѕ Р·Р°Р·РІРёС‡Р°Р№ РїСЂРёС…РѕРґРёС‚СЊ С–Р· Р±РѕР№РѕРІРѕРіРѕ СЃРµСЂРІРµСЂР°, вЂ” С‚С–Р»СЊРєРё РЅР° РІР»Р°СЃРЅРѕРјСѓ Р»Р°Р±РѕСЂР°С‚РѕСЂРЅРѕРјСѓ СЃС‚РµРЅРґС– Р№ С–Р· РЅР°РїРµСЂРµРґ РІС–РґРѕРјРѕСЋ РїСЂРёС‡РёРЅРѕСЋ.

## РџР°СЃС‚РєРё

**РћРїРёС‚СѓРІР°РЅРЅСЏРј `/proc` РєРѕСЂРѕС‚РєС– СЃС‚Р°РЅРё РЅРµ Р»РѕРІР»СЏС‚СЊСЃСЏ.** Р¦Рµ РЅРµ С…РёР±Р° СЃРїРѕСЃС‚РµСЂС–РіР°С‡Р°, Р° С„СѓРЅРґР°РјРµРЅС‚Р°Р»СЊРЅРµ РѕР±РјРµР¶РµРЅРЅСЏ РѕРїРёС‚СѓРІР°Р»СЊРЅРѕРіРѕ РјРµС‚РѕРґСѓ: РµРїС–Р·РѕРґ СЃРЅСѓ С‡Рё РѕР±С‡РёСЃР»РµРЅСЊ, РєРѕСЂРѕС‚С€РёР№ Р·Р° РїРµСЂС–РѕРґ РІРёР±С–СЂРєРё (РЅР°РїСЂРёРєР»Р°Рґ, 100 РјС–РєСЂРѕСЃРµРєСѓРЅРґ РЅР° NVMe-РґРёСЃРєСѓ РїСЂРё РїРµСЂС–РѕРґС– 50 РјС–Р»С–СЃРµРєСѓРЅРґ), РїРѕС‚СЂР°РїР»СЏС” Сѓ РІРёР±С–СЂРєСѓ Р»РёС€Рµ Р· С–РјРѕРІС–СЂРЅС–СЃС‚СЋ С‡Р°СЃС‚РєРё РІС–РґСЃРѕС‚РєР°. РљРѕР»Рё С‚СЂРµР±Р° РїРѕСЂР°С…СѓРІР°С‚Рё РІСЃС– Р±РµР· РІРёРЅСЏС‚РєСѓ РµРїС–Р·РѕРґРё `D`, Р° РЅРµ Р»РёС€Рµ РїРѕРґРёРІРёС‚РёСЃСЏ РЅР° РґРѕРІРіРѕС‚СЂРёРІР°Р»С– Р·Р°РІРёСЃР°РЅРЅСЏ, РїРѕС‚СЂС–Р±РЅС– С‚СЂР°СЃСѓРІР°Р»СЊРЅС– С‚РѕС‡РєРё СЏРґСЂР°. РўРѕС‡РєР° `sched_switch` СЃРїСЂР°С†СЊРѕРІСѓС” РЅР° РєРѕР¶РЅРѕРјСѓ РїРµСЂРµРјРёРєР°РЅРЅС– РєРѕРЅС‚РµРєСЃС‚Сѓ РїСЂРѕС†РµСЃРѕСЂР° Р№ СЃРµСЂРµРґ С–РЅС€РѕРіРѕ РґСЂСѓРєСѓС” РїРѕР»Рµ `prev_state` вЂ” С‚Сѓ СЃР°РјСѓ Р»С–С‚РµСЂСѓ СЃС‚Р°РЅСѓ Р·Р°РґР°С‡С–, СЏРєСѓ Р·РЅС–РјР°СЋС‚СЊ Р· РїСЂРѕС†РµСЃРѕСЂР° ([ftrace С– С‚СЂР°СЃСѓРІР°Р»СЊРЅС– С‚РѕС‡РєРё](book:unix-linux/ftrace-kernel-tracing)):

```sh
cd /sys/kernel/tracing
echo 1 > events/sched/sched_switch/enable
grep --line-buffered 'prev_state=D' trace_pipe
```

Р“РѕС‚РѕРІРёР№ С–РЅСЃС‚СЂСѓРјРµРЅС‚ РґР»СЏ С†СЊРѕРіРѕ Р¶ вЂ” `offcputime` Р· РЅР°Р±РѕСЂСѓ bcc / bpftrace: РІС–РЅ Р·Р±РёСЂР°С” СЃС‚РµРєРё СЏРґСЂР°, Сѓ СЏРєРёС… Р·Р°РґР°С‡Р° СЃС…РѕРґРёР»Р° Р· РїСЂРѕС†РµСЃРѕСЂР°, С– РІРјС–С” С„С–Р»СЊС‚СЂСѓРІР°С‚Рё Р·Р° РјР°СЃРєРѕСЋ СЃС‚Р°РЅСѓ (`--state 2` вЂ” С†Рµ СЂС–РІРЅРѕ `TASK_UNINTERRUPTIBLE`). Р†РЅСЃС‚СЂСѓРјРµРЅС‚ РїСЂР°С†СЋС” С‡РµСЂРµР· [eBPF](book:unix-linux/ebpf-extended-berkeley-packet-filter) Р±РµР· СЃСѓС‚С‚С”РІРѕРіРѕ РЅР°РІР°РЅС‚Р°Р¶РµРЅРЅСЏ РЅР° СЃРёСЃС‚РµРјСѓ Р№ РґРѕР·РІРѕР»СЏС” РїРѕР±СѓРґСѓРІР°С‚Рё С‚РѕС‡РЅРёР№ РіС–СЃС‚РѕРіСЂР°РјРЅРёР№ СЂРѕР·РїРѕРґС–Р» Р·Р°С‚СЂРёРјРѕРє.

**`ps` Р·Р° Р·Р°РјРѕРІС‡СѓРІР°РЅРЅСЏРј Р·РІРѕРґРёС‚СЊ РїРѕС‚РѕРєРё РІ РѕРґРёРЅ СЂСЏРґРѕРє.** РЎС‚Р°РЅ Р»РµР¶РёС‚СЊ Сѓ РїРѕР»С– `__state` РєРѕРЅРєСЂРµС‚РЅРѕС— Р·Р°РґР°С‡С– (`task_struct`), Р° РЅРµ РїСЂРѕС†РµСЃСѓ РІ С†С–Р»РѕРјСѓ, С‚РѕР¶ Сѓ Р±Р°РіР°С‚РѕРїРѕС‚РѕРєРѕРІРѕС— РїСЂРѕРіСЂР°РјРё СЃС‚Р°РЅС–РІ СЃС‚С–Р»СЊРєРё, СЃРєС–Р»СЊРєРё РїРѕС‚РѕРєС–РІ ([РїРѕС‚РѕРєРё СЏРє Р·Р°РґР°С‡С–](book:unix-linux/threads-as-tasks)). РћРґРЅРѕРіРѕ РїРѕС‚РѕРєСѓ, РЅР°РјРµСЂС‚РІРѕ Р·Р°СЃС‚СЂСЏРіР»РѕРіРѕ РІ `D`, Сѓ Р·РІРёС‡Р°Р№РЅРѕРјСѓ `ps` РЅРµ РІРёРґРЅРѕ РІР·Р°РіР°Р»С– вЂ” РїСЂРѕС†РµСЃ РїРѕРєР°Р·СѓС”С‚СЊСЃСЏ СЏРє `S`, РѕСЃРєС–Р»СЊРєРё РіРѕР»РѕРІРЅРёР№ РїРѕС‚С–Рє СЃРїРёС‚СЊ Сѓ РїРµСЂРµСЂРёРІРЅРѕРјСѓ СЃРЅС–. Р”РёРІРёС‚РёСЃСЏ С‚СЂРµР±Р° С‡РµСЂРµР· `ps -L -p <pid>` Р°Р±Рѕ С–РЅСЃРїРµРєС‚СѓРІР°С‚Рё РІРјС–СЃС‚ С‚РµРєРё `/proc/<pid>/task/`.

**`wchan` С‡Р°СЃС‚Рѕ РґРѕСЂС–РІРЅСЋС” `0`, С– С†Рµ РЅРµ РїРѕРјРёР»РєР°.** РЇРґСЂРѕ РІС–РґРґР°С” СЃРёРјРІРѕР»СЊРЅРµ С–Рј'СЏ С„СѓРЅРєС†С–С— Р»РёС€Рµ С‚РѕРјСѓ СЃРїРѕСЃС‚РµСЂС–РіР°С‡РµРІС–, СЏРєРѕРјСѓ РґРѕР·РІРѕР»РµРЅРѕ РґРѕСЃС‚СѓРї СЂС–РІРЅСЏ `ptrace_may_access()` РґРѕ С†С–С”С— Р·Р°РґР°С‡С– вЂ” С–РЅР°РєС€Рµ Р· РјС–СЂРєСѓРІР°РЅСЊ Р±РµР·РїРµРєРё РґСЂСѓРєСѓС”С‚СЊСЃСЏ РЅСѓР»СЊ (С‰РѕР± Р·Р°РїРѕР±С–РіС‚Рё РІРёС‚РѕРєСѓ СЂРѕР·РєР»Р°РґРєРё Р°РґСЂРµСЃРЅРѕС— РїР°Рј'СЏС‚С– СЏРґСЂР° KASLR). РќСѓР»СЊ РІРёР№РґРµ Р№ С‚РѕРґС–, РєРѕР»Рё Р·Р°РґР°С‡Р° РЅРµ СЃРїРёС‚СЊ (РїРµСЂРµР±СѓРІР°С” РІ `R`), С– С‚РѕРґС–, РєРѕР»Рё СЃРёРјРІРѕР» С„СѓРЅРєС†С–С— РЅРµ РІРґР°Р»РѕСЃСЏ СЂРѕР·РїС–Р·РЅР°С‚Рё. РўР°Рє СЃР°РјРѕ РїРѕРІРѕРґСЏС‚СЊСЃСЏ `/proc/<pid>/stack` (РїРѕС‚СЂС–Р±РЅС– РїСЂР°РІР° root С‚Р° СЏРґСЂРѕ, Р·С–Р±СЂР°РЅРµ Р· РїС–РґС‚СЂРёРјРєРѕСЋ `CONFIG_STACKTRACE`) С‚Р° СЂРµС€С‚Р° РіР»РёР±РѕРєРёС… РїРѕР»С–РІ [procfs](book:unix-linux/proc-filesystem).

**Р¤Р°Р·Р° `T` вЂ” С†Рµ РїР°СЃС‚РєР° РґР»СЏ С‚РѕРіРѕ, С…С‚Рѕ Р·Р°РїСѓСЃС‚РёРІ.** РЎРёРіРЅР°Р» `SIGSTOP` РЅРµ РјРёРЅР°С” РЅС– РІС–Рґ С‡Р°СЃСѓ, РЅС– РІС–Рґ Р·Р°РєСЂРёС‚С‚СЏ СЃРµР°РЅСЃСѓ С‚РµСЂРјС–РЅР°Р»Р°. РЇРєС‰Рѕ Р·Р°РїСѓСЃС‚РёС‚Рё РїС–РґРґРѕСЃР»С–РґРЅРѕРіРѕ Р±РµР· СЃРїРѕСЃС‚РµСЂС–РіР°С‡Р°, РІС–РЅ Р·СѓРїРёРЅРёС‚СЊСЃСЏ РЅР°Р·Р°РІР¶РґРё Р№ РІРёСЃС–С‚РёРјРµ РІ СЃРїРёСЃРєСѓ РїСЂРѕС†РµСЃС–РІ; РІРёРІРѕРґРёС‚СЊ Р№РѕРіРѕ Р»РёС€Рµ `kill -CONT <pid>`. РўРѕРјСѓ РІ РЅР°С€РѕРјСѓ Р»Р°Р±РѕСЂР°С‚РѕСЂРЅРѕРјСѓ СЃС†РµРЅР°СЂС–С— СЃРёРіРЅР°Р» `SIGCONT` РЅР°РґСЃРёР»Р°С” СЃР°Рј СЃРїРѕСЃС‚РµСЂС–РіР°С‡, Р° РЅРµ Р»СЋРґРёРЅР° вЂ” РїС–РґРґРѕСЃР»С–РґРЅР° РїСЂРѕРіСЂР°РјР° РЅРµ РїРѕРІРёРЅРЅР° Р·Р°РІРёСЃР°С‚Рё, СЏРєС‰Рѕ Р·Р° РЅРµСЋ РЅРµ СЃС‚РµР¶Р°С‚СЊ.

**`dm-delay` РЅРµ РЅР°РІРѕРґСЏС‚СЊ РЅР° СЂРѕР±РѕС‡РёР№ РґРёСЃРє.** РЈ С‚Р°Р±Р»РёС†С– device-mapper РІРё РІРєР°Р·СѓС”С‚Рµ Р±Р»РѕРєРѕРІРёР№ РїСЂРёСЃС‚СЂС–Р№, С– РїРѕРјРёР»РєР° Сѓ РІРёР·РЅР°С‡РµРЅРЅС– С–РјРµРЅС– С‚РѕРјР° РєРѕС€С‚СѓС” РІС‚СЂР°С‚Рё РґР°РЅРёС…. РЈ РґРѕСЃР»С–РґС– РїС–РґРєР»Р°РґРєРѕСЋ РЅР°РІРјРёСЃРЅРѕ СЃР»СѓР¶РёС‚СЊ С„Р°Р№Р» С‡РµСЂРµР· loop-РїСЂРёСЃС‚СЂС–Р№ (`/dev/loopX`): РЅР°Р№РіС–СЂС€Рµ, С‰Рѕ СЃС‚Р°РЅРµС‚СЊСЃСЏ РїСЂРё РїРѕРјРёР»С†С–, вЂ” Р·С–РїСЃСѓСЋС‚СЊСЃСЏ 64 РјРµРіР°Р±Р°Р№С‚Рё С‚РёРјС‡Р°СЃРѕРІРѕРіРѕ С„Р°Р№Р»Сѓ РІ `/var/tmp`. Р РѕР·Р±РёСЂР°С‚Рё С‚РµСЃС‚РѕРІСѓ РєРѕРЅСЃС‚СЂСѓРєС†С–СЋ С‚СЂРµР±Р° СЃСѓРІРѕСЂРѕ РІ Р·РІРѕСЂРѕС‚РЅРѕРјСѓ РїРѕСЂСЏРґРєСѓ вЂ” СЃРїРµСЂС€Сѓ `dmsetup remove slowdisk`, РїРѕС‚С–Рј `losetup -d $LOOP`, С– Р»РёС€Рµ РЅР°РїСЂРёРєС–РЅС†С– РІРёРґР°Р»СЏС‚Рё С„Р°Р№Р». РЇРєС‰Рѕ `dmsetup remove` РєР°Р¶Рµ `device-mapper: remove ioctl failed: Device or resource busy`, С†Рµ РѕР·РЅР°С‡Р°С”, С‰Рѕ РїСЂРѕС†РµСЃ `dd` Р°Р±Рѕ С–РЅС€РёР№ РїСЂРѕС†РµСЃ С–С‰Рµ С‚СЂРёРјР°С” РїСЂРёСЃС‚СЂС–Р№ РІС–РґРєСЂРёС‚РёРј, С– Р№РѕРіРѕ PID СЃР»С–Рґ Р·РЅР°Р№С‚Рё С‡РµСЂРµР· `lsof /dev/mapper/slowdisk`.

**РќРµ РІСЃСЋРґРё С” Р· С‡РѕРіРѕ Р±СѓРґСѓРІР°С‚Рё.** РЈ РєРѕРЅС‚РµР№РЅРµСЂР°С… Docker/Kubernetes Р±РµР· РїСЂР°РїРѕСЂС†СЏ `--privileged` РЅРµРјР°С” РґРѕСЃС‚СѓРїСѓ РґРѕ `/dev/mapper` С‚Р° РЅРµРјР°С” РїСЂР°РІР° Р·Р°РІР°РЅС‚Р°Р¶СѓРІР°С‚Рё РјРѕРґСѓР»С– СЏРґСЂР°; Сѓ WSL2 СЏРґСЂРѕ Linux СЃРїСЂР°РІР¶РЅС”, Р°Р»Рµ Р·С–Р±СЂР°РЅРµ Р· РјС–РЅС–РјР°Р»СЊРЅРёРј РЅР°Р±РѕСЂРѕРј РјРѕРґСѓР»С–РІ, С– РјРѕРґСѓР»СЏ `dm-delay` Сѓ РЅСЊРѕРјСѓ РјРѕР¶Рµ Р±СѓС‚Рё РЅРµ РїРµСЂРµРґР±Р°С‡РµРЅРѕ. РЎРїРѕСЃС–Р± С‡РµСЂРµР· `CLONE_VFORK` РїСЂР°С†СЋС” СЃРєСЂС–Р·СЊ, РґРµ С” СЃС‚Р°РЅРґР°СЂС‚РЅРµ СЏРґСЂРѕ Linux, РЅРµР·Р°Р»РµР¶РЅРѕ РІС–Рґ РїСЂР°РІ РєРѕСЂРёСЃС‚СѓРІР°С‡Р° С‡Рё РЅР°СЏРІРЅРѕСЃС‚С– РјРѕРґСѓР»С–РІ РїСЂРёСЃС‚СЂРѕС—РІ.

**РЎРїРѕСЃС‚РµСЂС–РіР°С‡ СЃР°Рј С” РїСЂРѕС†РµСЃРѕРј.** РљРѕР¶РЅР° РІРёР±С–СЂРєР° СЃС‚Р°РЅСѓ вЂ” С†Рµ СЃРёСЃС‚РµРјРЅС– РІРёРєР»РёРєРё `open`, `read`, `close` РїРѕ `/proc`, Р° Сѓ РІРµСЂСЃС–С— РЅР° РѕР±РѕР»РѕРЅС†С– bash С‰Рµ Р№ С„РѕСЂРє РЅРѕРІРёС… РїСЂРѕС†РµСЃС–РІ `cat` С‚Р° `awk`. РџСЂРё РїРµСЂС–РѕРґС– РѕРїРёС‚СѓРІР°РЅРЅСЏ 50 РјС–Р»С–СЃРµРєСѓРЅРґ С†Рµ РЅР°РІР°РЅС‚Р°Р¶РµРЅРЅСЏ С” РЅРµРїРѕРјС–С‚РЅРёРј, Р°Р»Рµ РїСЂРё СЃРїСЂРѕР±С– РїСЂРёСЃРєРѕСЂРёС‚Рё РѕРїРёС‚СѓРІР°РЅРЅСЏ РґРѕ 1 РјС–Р»С–СЃРµРєСѓРЅРґРё СЃРїРѕСЃС‚РµСЂС–РіР°С‡ РїРѕС‡РёРЅР°С” СЃС‚РІРѕСЂСЋРІР°С‚Рё РІРёСЃРѕРєСѓ РєРѕРЅРєСѓСЂРµРЅС†С–СЋ Р·Р° РїСЂРѕС†РµСЃРѕСЂРЅРµ СЏРґСЂРѕ Р№ СЃРїРѕС‚РІРѕСЂСЋС” СЂРµР·СѓР»СЊС‚Р°С‚Рё РІРёРјС–СЂСЋРІР°РЅРЅСЏ. РЇРєС‰Рѕ РЅРµРѕР±С…С–РґРЅР° С‚Р°РєР° СЂРѕР·РґС–Р»СЊРЅР° Р·РґР°С‚РЅС–СЃС‚СЊ, СЃР»С–Рґ РІРёРєРѕСЂРёСЃС‚РѕРІСѓРІР°С‚Рё РїРѕРґС–Р№РЅС– С‚СЂР°СЃСѓРІР°Р»СЊРЅС– С‚РѕС‡РєРё СЏРґСЂР° Р°Р±Рѕ С–РЅСЃС‚СЂСѓРјРµРЅС‚Рё eBPF Р·Р°РјС–СЃС‚СЊ РѕРїРёС‚СѓРІР°РЅРЅСЏ С‡РµСЂРµР· `/proc`.
