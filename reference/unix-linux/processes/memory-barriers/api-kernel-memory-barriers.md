# 🔌 Довідник бар'єрів пам'яті в ядрі Linux

Цей довідник містить зведений повний перелік усіх стандартних примітивів бар'єрів пам'яті ядра Linux, їхню поведінку, правила спарювання та апаратні інструкції, у які вони розгортаються на архітектурах x86_64 та ARM64.

Усі макроси та функції оголошені в заголовочних файлах `<linux/compiler.h>` та `<asm/barrier.h>`.

## Загальні бар'єри пам'яті ядра Linux

| Примітив ядра | Тип бар'єра | Область дії та розгортання в ассемблері |
| :--- | :--- | :--- |
| `barrier()` | Компіляторний | Забороняє GCC/Clang переставляти читання та записи у C-коді. Не генерує жодних апаратних інструкцій CPU (`__asm__ __volatile__("":::"memory")`). |
| `smp_mb()` | Повний (SMP) | Повний двосторонній бар'єр пам'яті. Гарантує впорядкування всіх читань і записів відносно бар'єра для всіх ядер у багатопроцесорній системі. На x86_64: `MFENCE` або `LOCK ADD`. |
| `smp_rmb()` | Читання (SMP) | Бар'єр читання. Гарантує впорядкування всіх читань (`Read->Read`) до і після бар'єра. На x86_64: `barrier()` (оскільки x86 не реодерить читання). |
| `smp_wmb()` | Запис (SMP) | Бар'єр запису. Гарантує впорядкування всіх записів (`Write->Write`) до і після бар'єра. На x86_64: `barrier()` (оскільки x86 не реодерить записи). |

## Семантика впорядкування Acquire / Release

| Примітив ядра | Призначення та апаратна семантика |
| :--- | :--- |
| `smp_store_release(ptr, val)` | Атомарно зберігає значення `val` за адресою `ptr` із семантикою Release. Жоден запис до цієї функції не може виплисти за межу виклику. На ARM64: інструкція `STLR`. |
| `smp_load_acquire(ptr)` | Атомарно зчитує значення за адресою `ptr` із семантикою Acquire. Жодне читання після цієї функції не може з'їхати вище точки виклику. На ARM64: інструкція `LDAR`. |

## Примітиви взаємодії з апаратурою та периферією (MMIO)

При роботі з прапорцями пристроїв та регістрами через шину PCIe/MMIO класичних SMP-бар'єрів недостатньо, оскільки шинні контролери пристроїв можуть виконувати власне впорядкування записів:
- `wmb()`: Повний апаратний бар'єр запису для пристроїв I/O (примушує скинути всі MMIO записи на шину).
- `rmb()`: Повний апаратний бар'єр читання для пристроїв I/O.
- `mb()`: Повний двосторонній апаратний бар'єр I/O.
