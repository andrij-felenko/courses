# API Керованих каталогів systemd

Коли ви використовуєте директиви керування каталогами, systemd передає шляхи до них у процес вашої служби через змінні середовища. Це дозволяє зробити конфігурацію вашої програми повністю незалежною від жорстко закодованих шляхів в системі.

| Директива systemd | Змінна середовища | Стандартний шлях | Призначення |
| :--- | :--- | :--- | :--- |
| `RuntimeDirectory=` | `$RUNTIME_DIRECTORY` | `/run/` | Тимчасові файли, сокети, PID. Зникають при ребуті або зупинці. |
| `StateDirectory=` | `$STATE_DIRECTORY` | `/var/lib/` | Постійні дані, бази даних. Зберігаються між перезавантаженнями. |
| `CacheDirectory=` | `$CACHE_DIRECTORY` | `/var/cache/` | Тимчасові, але не критичні дані (кеші), що можуть пережити ребут. |
| `LogsDirectory=` | `$LOGS_DIRECTORY` | `/var/log/` | Постійні логи служби (бажано використовувати journald). |
| `ConfigurationDirectory=` | `$CONFIGURATION_DIRECTORY` | `/etc/` | Конфігураційні файли служби. |

> **Зауваження:** Якщо в директиві вказано кілька каталогів через пробіл (наприклад, `RuntimeDirectory=foo bar`), змінна середовища міститиме їх як абсолютні шляхи, розділені двокрапкою: `/run/foo:/run/bar`.
