# Фреймворк тестування ядра KUnit та відлагоджувачі KASAN/KCSAN/KFENCE

## Вступ до KUnit

KUnit — це фреймворк для написання та виконання модульних тестів (unit tests) безпосередньо всередині ядра Linux. Він дозволяє тестувати окремі функції або підсистеми ізольовано, що значно спрощує процес розробки та підвищує надійність коду.

### Архітектура та можливості

KUnit базується на архітектурі, що дозволяє запускати тести як у віртуалізованому середовищі (User Mode Linux, UML), так і на реальному обладнанні.

Основні переваги KUnit:
- **Ізольованість**: Тестування окремих компонентів.
- **Швидкість**: Швидкий запуск тестів через UML.
- **Інтеграція**: Підтримка `kunit.py` для автоматизації.

## Відлагоджувачі пам'яті (Sanitizers)

Разом з KUnit часто використовуються відлагоджувачі для виявлення помилок пам'яті та багатопоточності.

### KASAN (Kernel Address Sanitizer)

KASAN — це інструмент для виявлення помилок пам'яті, таких як use-after-free та out-of-bounds. Він працює шляхом додавання перевірок під час компіляції та використання "тіньової пам'яті" (shadow memory).

### KCSAN (Kernel Concurrency Sanitizer)

KCSAN призначений для виявлення станів гонитви (race conditions) у ядрі. Він використовує механізми вибіркової перевірки доступу до пам'яті, щоб знайти конфлікти між потоками.

### KFENCE (Kernel Electric-Fence)

KFENCE — це низьковитратний відлагоджувач пам'яті, який можна використовувати у production-середовищі. Він виявляє use-after-free та out-of-bounds, але працює з меншим навантаженням порівняно з KASAN.

## Інтеграція у CI/CD

Використання KUnit разом з KASAN/KCSAN/KFENCE є стандартом для сучасних CI/CD пайплайнів розробки ядра. Скрипт `tools/testing/kunit/kunit.py` дозволяє легко інтегрувати ці інструменти у Jenkins, GitLab CI або GitHub Actions.

## Висновок

KUnit та набір відлагоджувачів надають потужний інструментарій для забезпечення якості коду ядра Linux. Їх використання допомагає виявляти помилки на ранніх етапах розробки та гарантує стабільність системи.
