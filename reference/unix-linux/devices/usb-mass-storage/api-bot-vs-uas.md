# API BOT та UAS

BOT (Bulk-Only Transport) API та UAS (USB Attached SCSI) API відрізняються підходом до передачі команд SCSI поверх USB.
- **BOT**: Використовує дві Bulk точки (In/Out). Команди упаковуються у CBW (Command Block Wrapper), дані передаються, а потім очікується статус у CSW (Command Status Wrapper). Процес повністю синхронний і вимагає завершення попередньої команди перед початком нової.
- **UAS**: Використовує чотири окремі канали (Command, Status, Data IN, Data OUT). Підтримує мультиплексування і Native Command Queuing (NCQ). Дозволяє паралельно надсилати команди і отримувати статуси та дані, що значно прискорює роботу під багатопотоковим навантаженням.
