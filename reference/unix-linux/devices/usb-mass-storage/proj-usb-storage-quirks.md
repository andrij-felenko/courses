# USB Storage Quirks (Особливості)

Деякі старі чи нестандартні пристрої USB Mass Storage некоректно реалізують протокол BOT або UAS. Наприклад, можуть зависати при отриманні певних SCSI команд або не підтримувати запит розміру кешу.
Для вирішення цього у ядрі Linux драйвер `usb-storage` містить механізм **quirks**. У модулі можна вказати параметр, наприклад, `usb-storage.quirks=abcd:1234:u`, який вимкне підтримку UAS для пристрою з Vendor/Product ID `abcd:1234` і змусить його працювати у режимі BOT, обходячи баги прошивки. Літери після ідентифікаторів — це і є перелік особливостей: розбирає їх `usb_stor_adjust_quirks()` (`drivers/usb/storage/usb.c`), і саме `u` означає прапорець `US_FL_IGNORE_UAS`.

Два практичні наслідки. По-перше, список читається **під час прив'язки драйвера**, а не постійно: рядок можна дописати й на живій системі (`/sys/module/usb_storage/parameters/quirks` відкрито на запис), але подіє він лише на наступному під'єднанні пристрою — тож потрібне переввімкнення або `usb-storage.quirks=…` у рядку завантаження ядра. По-друге, той самий список читає й `uas_use_uas_driver()` перед вибором драйвера, тому `:u` не «перемикає режим» уже працюючого пристрою, а прибирає його з-під `uas` ще до того, як той візьметься за роботу.
