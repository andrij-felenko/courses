# Історія еволюції USB Storage

Спершу USB Storage пристрої використовували різні протоколи (CBI - Control/Bulk/Interrupt), що було повільним. Для USB флешок створили Bulk-Only Transport (BOT). Його цілком вистачало для USB 2.0. З появою USB 3.0 та швидких SSD синхронний BOT став вузьким місцем. Тоді було створено UAS (USB Attached SCSI Protocol), який використав нові можливості USB 3.0 Streams, дозволивши повноцінне паралельне виконання команд SCSI з використанням NCQ.
