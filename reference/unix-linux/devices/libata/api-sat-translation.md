# Деталі трансляції (SAT API)

Специфікація SAT (SCSI / ATA Translation) визначає чіткі правила перетворення. Розглянемо приклад ідентифікації пристрою. У світі SCSI для цього використовується команда `INQUIRY`. ATA-диски не розуміють `INQUIRY`, але вони мають аналогічну команду `IDENTIFY DEVICE`.

Коли програма відправляє `INQUIRY`, `libata` перехоплює цей запит, надсилає диску `IDENTIFY DEVICE`, отримує 512 байт метаданих (серійний номер, модель, функції), і переформатовує їх у стандартну відповідь SCSI `INQUIRY`. 

Аналогічно, команди керування живленням SCSI `START STOP UNIT` транслюються в команди ATA `STANDBY IMMEDIATE` або `SLEEP`. Таким чином, утиліти простору користувача (наприклад, `lsscsi`) отримують коректну інформацію про пристрій та можуть ним керувати, навіть не маючи прямої підтримки ATA-протоколу.
