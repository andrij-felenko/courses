# Практика: дослідження libata через sysfs

Ви можете самостійно дослідити, як ваш ATA-диск відображається в ієрархії пристроїв Linux. Знайдіть свій диск (наприклад, `sda`) та перевірте його "родовід":

```bash
ls -l /sys/block/sda/device
```
Цей символічний лінк приведе вас до директорії SCSI-пристрою (наприклад, `.../target0:0:0/0:0:0:0`).
Проте якщо ви підніметеся деревом `sysfs` вище, ви знайдете батьківський вузол ATA-порту (наприклад, `ata1`):

```bash
ls -l /sys/block/sda/device/../../../../
```

Ви також можете переглянути параметри, специфічні для `libata`. Наприклад, перевірити поточну швидкість лінку SATA (1.5, 3.0 або 6.0 Gbps):
```bash
cat /sys/class/ata_link/link1/sata_spd
```
Цей поділ на класи `scsi_device`, `scsi_host` та `ata_link` яскраво ілюструє концептуальну структуру драйвера `libata`.
