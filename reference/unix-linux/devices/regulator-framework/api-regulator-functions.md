# 📋 API: Функції керування регуляторами (Consumer)

Ядро Linux надає набір функцій (Consumer API), які драйвери використовують для управління живленням своїх пристроїв. Ці функції дозволяють отримати доступ до регулятора, змінити його стан та параметри. Усі прототипи знаходяться в `<linux/regulator/consumer.h>`.

### Отримання та звільнення регулятора

Для того, щоб драйвер міг керувати живленням, він спершу має отримати об'єкт-посилання на регулятор, який живить пристрій (зазвичай прив'язка описана у Device Tree).

*   `struct regulator *regulator_get(struct device *dev, const char *id);`
    Запитує регулятор за його ідентифікатором для конкретного пристрою (наприклад, `"vdd"` або `"vcc"`).
*   `struct regulator *devm_regulator_get(struct device *dev, const char *id);`
    Managed-версія `regulator_get`: отриманий регулятор автоматично звільняється під час видалення пристрою (`devm` інфраструктура), що значно спрощує обробку помилок у функції `probe`.
*   `void regulator_put(struct regulator *regulator);`
    Звільняє регулятор, якщо використовувалася звичайна, не `devm`-версія.

### Увімкнення та вимкнення

Регулятор вмикається і вимикається на основі лічильника посилань (use count). Це важливо, адже до одного регулятора можуть бути підключені кілька пристроїв.

*   `int regulator_enable(struct regulator *regulator);`
    Вмикає регулятор. Якщо він уже увімкнений (наприклад, іншим споживачем або системним завантажувачем), лічильник посилань просто збільшується.
*   `int regulator_disable(struct regulator *regulator);`
    Зменшує лічильник посилань. Тільки коли лічильник досягає нуля, ядро надсилає команду апаратній мікросхемі на фізичне вимкнення напруги.
*   `int regulator_is_enabled(struct regulator *regulator);`
    Перевіряє, чи увімкнено живлення на цьому регуляторі.
*   `int regulator_force_disable(struct regulator *regulator);`
    Примусово вимикає регулятор, ігноруючи лічильник посилань. Використовується в критичних ситуаціях, наприклад, при перегріві чи паніці ядра.

### Керування напругою та струмом

*   `int regulator_set_voltage(struct regulator *regulator, int min_uV, int max_uV);`
    Запитує зміну напруги в заданому діапазоні (від `min_uV` до `max_uV` мікровольт). Фреймворк агрегує запити від усіх споживачів цього регулятора і знаходить напругу, яка задовольняє найжорсткіші вимоги (перетин діапазонів).
*   `int regulator_get_voltage(struct regulator *regulator);`
    Повертає поточну фактичну напругу (в мікровольтах).
*   `int regulator_set_current_limit(struct regulator *regulator, int min_uA, int max_uA);`
    Встановлює обмеження споживання струму (у мікроамперах), якщо регулятор (наприклад, LDO або зарядний пристрій) апаратно підтримує лімітування струму.
