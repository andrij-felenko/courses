# 🧮 Скільки коштує звільнити зону: підсилення запису при Zone Reclaim

Процес Zone Reclaim вимагає переміщення даних. Якщо зона, що реорганізується, містить `V` валідних секторів і `I` невалідних, то для її очищення треба зчитати `V` секторів, об'єднати їх з новими даними і записати в нову зону.

Коефіцієнт підсилення запису (Write Amplification Factor, WAF) через Zone Reclaim можна наблизити формулою:

```
WAF = (усього записано на носій) / (записано від хоста) ≈ 1 + V/I
```

Чим більше валідних даних `V` доводиться постійно переміщувати для звільнення місця, тим вищий WAF, що призводить до падіння швидкодії та швидшого зносу SSD-накопичувачів. Межі видно просто: при `V = 0` зону досить скинути без жодного копіювання і WAF = 1, а при `I → 0` звільнення зони не дає майже нічого корисного — тому під переробку вигідно брати зони, де невалідних блоків найбільше.
