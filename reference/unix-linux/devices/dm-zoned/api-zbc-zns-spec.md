# 📋 Команди, якими розмовляють із зонованим носієм: ZBC, ZAC і ZNS

Zoned Block Commands (ZBC) для SAS та Zoned ATA Command Set (ZAC) для SATA — це стандарти, що описують набір команд для роботи зі SMR дисками. Zoned Namespace (ZNS) — це аналогічний стандарт для NVMe SSD.

Вони додають нові команди до стандартного набору:
- **Report Zones:** Отримати список зон, їх тип, розмір та стан (Empty, Full, Open, Closed).
- **Reset Zone:** Очистити SWR-зону (Write Pointer повертається на початок зони).
- **Open / Close / Finish Zone:** Керування станом зон. Накопичувачі мають два різні обмеження: на кількість одночасно **відкритих** зон (Maximum Open Zones) і на кількість **активних**, тобто відкритих або закритих, але ще не заповнених (Maximum Active Zones). Друге завжди не менше за перше.

Розуміння цих команд необхідне для написання власного ПЗ, що працює з зонованими дисками безпосередньо (Zoned Storage API), минаючи `dm-zoned`.
