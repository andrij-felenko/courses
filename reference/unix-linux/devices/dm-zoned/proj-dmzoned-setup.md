# ⚙️ Зібрати dm-zoned із двох дисків: SSD під кеш, SMR під дані

Якщо ваш зонований диск не має достатньо Conventional зон, `dm-zoned` дозволяє використовувати звичайний SSD як кеш.

```bash
# /dev/nvme0n1 - звичайний швидкий SSD
# /dev/sda - зонований SMR HDD
# Порядок аргументів обов'язковий: звичайний пристрій ПЕРШИЙ, зонований — за ним
sudo dmzadm --format /dev/nvme0n1 /dev/sda
sudo dmzadm --start /dev/nvme0n1 /dev/sda
```
У цьому випадку всі випадкові записи спочатку йдуть на швидкий NVMe SSD. Коли він заповнюється, фоновий процес Zone Reclaim збирає дані з нього і послідовно скидає їх у зони SMR HDD. Це значно підвищує загальну продуктивність системи порівняно з використанням лише HDD.
