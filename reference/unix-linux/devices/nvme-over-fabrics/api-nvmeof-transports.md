# Транспортні протоколи NVMe-oF

Специфікація NVMe-oF визначає різні типи транспорту:

1. **RDMA (Remote Direct Memory Access):**
   - **RoCEv2 (RDMA over Converged Ethernet):** Інкапсулює RDMA поверх UDP/IP. Вимагає мережевих комутаторів з підтримкою DCB (Data Center Bridging) для забезпечення безвтратної передачі (PFC).
   - **iWARP:** RDMA поверх TCP. Легше розгорнути на існуючій інфраструктурі, але має трохи вищі затримки.
   - **InfiniBand:** Спеціалізована високошвидкісна мережа, що має нативну підтримку RDMA.

2. **TCP:**
   - NVMe/TCP став стандартом де-факто для масового розгортання, оскільки він не вимагає спеціальних мережевих карт (RNIC) чи комутаторів. Може використовувати стандартні технології прискорення TCP в ядрі Linux.

3. **Fibre Channel (FC-NVMe):**
   - Дозволяє використовувати інфраструктуру FC SAN (Storage Area Network) для передачі команд NVMe, паралельно з традиційним FCP (SCSI).
