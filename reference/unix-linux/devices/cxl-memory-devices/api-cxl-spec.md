# Протоколи CXL: .io, .cache, .mem

CXL базується на фізичному рівні PCIe, але використовує динамічне мультиплексування трьох різних протоколів:

- **CXL.io**: Аналог стандартного PCIe (конфігурація, виявлення пристроїв, переривання, MMIO). Обов'язковий для всіх пристроїв CXL.
- **CXL.cache**: Дозволяє пристрою запитувати доступ до кешу процесора. Наприклад, мережева карта може прочитати або змінити рядок кешу, і процесор гарантує, що його локальний кеш залишиться узгодженим. Це усуває необхідність вручну викликати інструкції `clflush` або надсилати DMA-запити.
- **CXL.mem**: Дозволяє процесору звертатися до пам'яті на CXL-пристрої. Процесор керує кешуванням цієї пам'яті у своїх власних L1/L2/L3 кешах.

Різні типи пристроїв використовують різні комбінації. Type 3 пристрої (пам'ять) використовують лише `.io` (для управління) та `.mem` (для доступу до даних). Пристрої Type 1 (розумні кешуючі прискорювачі) — `.io` та `.cache`. Пристрої Type 2 (наприклад, GPU) використовують усі три: `.io`, `.cache` (для доступу до пам'яті хоста) та `.mem` (щоб хост міг звернутися до VRAM GPU).
