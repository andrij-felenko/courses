# Практика: утиліта CXL CLI

У Linux керування CXL-пам'яттю здійснюється через набір інструментів `ndctl` (зокрема утиліту `cxl`).

Встановлення в сучасних дистрибутивах:
```bash
sudo dnf install ndctl cxl-cli  # RHEL/Fedora
sudo apt install ndctl cxl-cli  # Ubuntu/Debian
```

Основні команди:
1. `cxl list -M`: Показати всі знайдені пристрої CXL-пам'яті (memdevs).
2. `cxl list -B -P -E -D`: Показати топологію підключень — шини, порти, кінцеві точки й декодери (додати `-T`, і до декодерів долучаться їхні цілі — низхідні порти).
3. `cxl create-region`: Зібрати кілька пристроїв пам'яті в єдиний логічний регіон (аналог RAID0 для пропускної здатності шини). Наприклад: `cxl create-region -m -d decoder0.0 -w 2`.
4. `cxl destroy-region`: Видалити регіон.
5. Запис у логи: ядро Linux виводить події гарячого підключення пам'яті CXL у `dmesg`. Ви побачите повідомлення виду `cxl_mem mem0: ...` та ініціалізацію нового NUMA-вузла без процесора.
