# Api Hid Report Items

### Типи елементів дескриптора (Items)

У HID-дескрипторі елементи бувають трьох типів:
- **Main Items** (Основні): Визначають самі дані. Наприклад, `Input` (дані від пристрою до хоста), `Output` (від хоста до пристрою, наприклад для світлодіодів), `Feature` (конфігураційні дані).
- **Global Items** (Глобальні): Встановлюють стан для всіх наступних `Main Items`. Це такі параметри як `Usage Page`, `Logical Minimum/Maximum`, `Report Size`, `Report Count`.
- **Local Items** (Локальні): Застосовуються лише до наступного `Main Item`. Наприклад, конкретний `Usage` (вісь X, кнопка 1).
