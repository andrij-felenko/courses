# Hist Hid Standard

### Історія створення HID

Стандарт USB HID був одним з перших, розроблених для шини USB в середині 1990-х років. До появи USB, миші та клавіатури підключалися через різноманітні пропрієтарні роз'єми (наприклад, різні роз'єми для мишей Microsoft та Apple) або стандартизовані інтерфейси типу PS/2 та послідовного порту. У кожному випадку операційній системі потрібен був спеціальний драйвер для перетворення апаратних сигналів у рух курсора.

Головною ідеєю, яку запропонували інженери з різних компаній (зокрема з Microsoft) у комітеті USB-IF, було створення пристрою, який сам описував би свої можливості. Замість фіксованих команд, вони придумали мову дескрипторів, що дозволило виробникам розширювати можливості своїх пристроїв (додаючи коліщатка, нові кнопки) без необхідності оновлювати драйвери в операційних системах.
