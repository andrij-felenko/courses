# Команди SCSI PR

Стандарт визначає дві основні команди для роботи з Persistent Reservations (коди піддій — за SPC; у ядрі Linux той самий перелік лежить у `drivers/target/target_core_pr.h`, константи `PRO_*`):

- `PERSISTENT RESERVE IN` (читання стану диска):
  - **Read Keys**: Отримати список усіх зареєстрованих ключів від усіх вузлів.
  - **Read Reservation**: Отримати інформацію про поточну встановлену резервацію (ключ власника та тип).
- `PERSISTENT RESERVE OUT` (зміна стану диска):
  - **Register** (0x00): Зареєструвати новий ключ вузла, замінити існуючий або видалити свій ключ.
  - **Reserve** (0x01): Встановити резервацію певного типу, маючи зареєстрований ключ.
  - **Release** (0x02): Зняти поточну резервацію (доступно лише власнику).
  - **Preempt** (0x04): Примусово видалити реєстрацію іншого ключа і перехопити його резервацію. Команди, які диск уже прийняв від цього ключа, дограються.
  - **Preempt and Abort** (0x05): Те саме, але додатково обриває всі незавершені команди перехопленого ключа. Саме цієї піддії вимагає `fence_scsi(8)` — без обриву хвоста fencing не миттєвий.
  - **Clear** (0x03): Очистити всі ключі та резервації на диску (радикальна дія, використовується для скидання).
