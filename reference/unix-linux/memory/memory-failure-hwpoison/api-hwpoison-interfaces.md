# API інтерфейси для керування hwpoison

Окрім перехоплення `SIGBUS`, простір користувача (userspace) може взаємодіяти з підсистемою hwpoison через спеціальні системні виклики та псевдофайлові системи `procfs` і `debugfs`.

1. **prctl(PR_MCE_KILL)**:
   - Дозволяє потоку налаштувати свою політику щодо отримання `SIGBUS` при фоновому (AO) виявленні помилки пам'яті.
   - `PR_MCE_KILL_EARLY`: Надіслати `SIGBUS` (`BUS_MCEERR_AO`) одразу, як тільки ядро виявить помилку у відображеній пам'яті (навіть якщо до неї зараз немає звернень).
   - `PR_MCE_KILL_LATE`: Чекати до останнього — поки процес фактично не звернеться до пошкодженої адреси; тоді сигнал прийде вже з кодом `BUS_MCEERR_AR`.
   - `PR_MCE_KILL_DEFAULT`: Використовувати загальносистемне налаштування (див. нижче — типово це late kill).

   Прапорець живе на потоці: щоб AO-сигнали ловив виділений потік, `prctl` треба покликати саме в ньому, інакше сигнал піде головному (`Documentation/mm/hwpoison.rst`).

2. **sysctl `vm.memory_failure_early_kill`**:
   - `0` (**типове значення**): «only unmap the corrupted page from all processes and only kill a process who tries to access it» — сторінку лише знімають з таблиць, сигнал отримає тільки той, хто до неї звернеться.
   - `1`: розіслати `SIGBUS` усім, хто відображає непоправну сторінку, одразу після виявлення.
   - Джерело: `Documentation/admin-guide/sysctl/vm.rst`; нуль як типове значення видно з оголошення `static int sysctl_memory_failure_early_kill __read_mostly;` у `mm/memory-failure.c` (без ініціалізатора).
   - Сусідній `vm.memory_failure_recovery`: `1` — пробувати відновитися, `0` — завжди панікувати при апаратній помилці пам'яті.

3. **madvise(MADV_HWPOISON)**:
   - Штучно «отруює» сторінку. Вимагає привілеїв (`CAP_SYS_ADMIN`). Використовується виключно для тестування RAS-інфраструктури.

4. **procfs і debugfs**:
   - Поточний стан системи і кількість отруєних сторінок можна побачити через `/proc/meminfo` (поле `HardwareCorrupted`).
   - Для розробників ядра доступний інтерфейс в `/sys/kernel/debug/hwpoison/` для налаштування симуляції та поведінки.
