# Проєкт: обробник SIGBUS

У цьому невеликому проєкті ви спробуєте реалізувати обробник `SIGBUS` у програмі на C.

**Завдання:**
1. Виділити сторінку пам'яті за допомогою `mmap`.
2. Зареєструвати обробник `SIGBUS` (через `sigaction` із прапорцем `SA_SIGINFO`).
3. Викликати `madvise(MADV_HWPOISON)` для виділеної сторінки.
4. Спробувати прочитати 1 байт з отруєної сторінки.
5. В обробнику `SIGBUS` перевірити, чи дорівнює `si_code` значенню `BUS_MCEERR_AR`. Якщо так — надрукувати «Action Required error handled» і вийти з програми за допомогою `_exit()`.

Саме `BUS_MCEERR_AR`, а не `AO`: у ненастроєній системі діє late kill, тож сигнал приходить не від `madvise`, а від сторінкового збою на кроці 4 (`arch/x86/mm/fault.c`, `do_sigbus()`).

**Додаткове завдання:** Додайте перед `madvise` виклик `prctl(PR_MCE_KILL, PR_MCE_KILL_SET, PR_MCE_KILL_EARLY, 0, 0)` і переконайтесь, що тепер процес отримує `SIGBUS` із кодом `BUS_MCEERR_AO` ще *до* того, як спробує прочитати пам'ять. Порівняйте два запуски: без `prctl` крок 4 обов'язковий, з ним — зайвий.
