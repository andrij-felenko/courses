# 🔌 Довідник системних дерев Btrfs

Ця вставка пояснює 🔌 довідник системних дерев btrfs та дозволяє зрозуміти її детальніше. Цей довідник містить повну таблицю всіх спеціалізованих B-дерев Btrfs з їхніми ID (`objectid`) у Root Tree та призначенням у ядрі.

## Картографія дерев Btrfs

| Назва дерева | Object ID у ядрі | Призначення |
| :--- | :--- | :--- |
| **`ROOT_TREE`** | `1ULL` | Головне дерево метаданих, що містить посилання на коріння всіх інших дерев. |
| **`EXTENT_TREE`** | `2ULL` | Веде облік алокації фізичних блоків диска та лічильників CoW-посилань. |
| **`CHUNK_TREE`** | `3ULL` | Карта трансляції логічних віртуальних адрес у фізичні диски (RAID-шар). |
| **`DEV_TREE`** | `4ULL` | Метадані про підключені блочні пристрої файлової системи. |
| **`FS_TREE`** | `5ULL` | Головне дерево файлової системи за замовчуванням (Default Subvolume). |
| **`CSUM_TREE`** | `7ULL` | Глобальна база контрольних сум усіх даних файлів (CRC32c/xxHash). |
| **`QUOTA_TREE`** | `8ULL` | Облік квот дискового простору для субтомів та qgroups. |
| **`UUID_TREE`** | `9ULL` | Індекс відповідності UUID субтомів та їхніх `objectid`. |
| **`FREE_SPACE_TREE`** | `10ULL` | Швидка бітова карта вільних екстентів для прискорення алокації. |

## Основні типи ключів у листі (Key Types)

- `BTRFS_INODE_ITEM_KEY` (`1`): Метадані іноди (розмір, UID, GID, mtime).
- `BTRFS_INODE_REF_KEY` (`12`): Батьківська директорія та ім'я файлу.
- `BTRFS_XATTR_ITEM_KEY` (`24`): Розширені атрибути файлу (xattrs, SELinux).
- `BTRFS_DIR_ITEM_KEY` (`84`): Елемент директорії (посилання на іноду за ім'ям).
- `BTRFS_EXTENT_DATA_KEY` (`108`): Вказівник на екстент вмісту файлу.
