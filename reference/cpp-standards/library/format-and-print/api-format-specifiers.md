# 📋 Довідник специфікаторів формату та API std::formatter

У цьому довіднику зібрано повну граматику специфікаторів форматування `std::format`, деталізовані таблиці модифікаторів для всіх стандартних типів даних мови C++, особливості форматування часових точок заголовочного файла `<chrono>` та діапазонів `<ranges>`, а також публічний інтерфейс шаблону `std::formatter<T>` для розширення системи форматування власними типами даних.

## Повна граматика форматного рядка (format-spec)

Рядок форматування у C++20 складається з трьох типів елементів:
1. Звичайних символів (символи `{` та `}` екрануються як `{{` та `}}`).
2. Замінників вида `{}` або `{arg_id}`.
3. Специфікаторів формату вида `{arg_id:format-spec}`.

Формальний синтаксис граматики `format-spec` регулюється стандартом ISO/IEC 14882. Загальна послідовність полів усередині двоеточія має суворий порядок:

```
format-spec     ::= [[fill]align] [sign] [#] [0] [width] [.precision] [L] [type]
fill            ::= будь-який символ (окрім '{' та '}')
align           ::= '<' | '>' | '^'
sign            ::= '+' | '-' | ' '
width           ::= positive-integer | '{' [arg_id] '}'
precision       ::= non-negative-integer | '{' [arg_id] '}'
type            ::= 'a' | 'A' | 'b' | 'B' | 'c' | 'd' | 'e' | 'E' | 'f' | 'F' | 'g' | 'G' | 'o' | 'p' | 's' | 'x' | 'X' | '?'
```

### 1. Вирівнювання та заповнювач (fill & align)

Параметр `align` задає вирівнювання значення в межах виділеного поля ширини:
- `<` — вирівнювання за лівим краєм (значення за замовчуванням для більшості типів, окрім чисел та покажчиків).
- `>` — вирівнювання за правим краєм (значення за замовчуванням для числових типів та покажчиків).
- `^` — вирівнювання за центром (падинг розподіляється порівну з обох боків значення).

Символ `fill` розташовується безпосередньо перед модифікатором вирівнювання і визначає символ-заповнювач. Якщо `fill` не вказано, за замовчуванням використовується звичайний пробіл `' '`.

Варто зауважити, що якщо розробник вказує символ заповнювача `fill`, він обов'язково повинен супроводжуватися модифікатором вирівнювання `align`. Окремо вказати заповнювач без символу вирівнювання заборонено граматикою стандарту, оскільки компілятор не зможе відрізнити заповнювач від інших прапорців.

```cpp
#include <format>
#include <string>

// Приклади вирівнювання та використання заповнювачів
std::string s1 = std::format("{:<10}", 42);    // "42        " (вирівнювання ліворуч)
std::string s2 = std::format("{:>10}", 42);    // "        42" (вирівнювання праворуч)
std::string s3 = std::format("{:^10}", 42);    // "    42    " (вирівнювання по центру)
std::string s4 = std::format("{:*^10}", 42);   // "****42****" (заповнювач '*')
```

### 2. Знак, альтернативна форма та нульовий падинг (sign, #, 0)

Спеціальні прапорці `sign`, `#` та `0` контролюють візуальне представлення знаків чисел, префіксів систем числення та заповнення провідними нулями:

| Модифікатор | Опис та правила застосування | Приклад виклику | Результат виводу |
| :--- | :--- | :--- | :--- |
| `+` | Завжди друкувати знак (і для додатніх `+`, і для від'ємних `-`) | `std::format("{:+d}", 42)` | `"+42"` |
| `-` | Друкувати знак лише для від'ємних чисел (поведінка за замовчуванням) | `std::format("{:-d}", 42)` | `"42"` |
| `' '` | Друкувати пробіл для додатніх чисел, знак `-` для від'ємних | `std::format("{: d}", 42)` | `" 42"` |
| `#` | Альтернативна форма (префікси `0x`/`0b`, примусова десяткова крапка) | `std::format("{:#x}", 255)` | `"0xff"` |
| `0` | Заповнювати ширину провідними нулями (знак числа передує нулям) | `std::format("{:05d}", 42)` | `"00042"` |

Прапорець альтернативної форми `#` змінює поведінку виводу залежно від типу аргументу:
- Для двійкових чисел (`b`/`B`) додає префікс `0b` або `0B`.
- Для вісімкових чисел (`o`) додає префікс `0`.
- Для шістнадцяткових чисел (`x`/`X`) додає префікс `0x` або `0X`.
- Для чисел з плаваючою крапкою примусово зберігає десяткову крапку, навіть якщо дробова частина дорівнює нулю.

### 3. Динамічна ширина та точність (width & precision)

Ширина `width` та точність `precision` можуть задаватися як константними значеннями безпосередньо у рядку формату, так і розраховуватися динамічно під час виконання програми шляхом передачі додаткових аргументів у фігурних дужках `{}`:

```cpp
int field_width = 10;
int precision_val = 3;
double val = 3.14159265;

// Динамічна ширина та точність з параметрів виклику
std::string s = std::format("{:{}.{}f}", val, field_width, precision_val); 
// Результат: "     3.142" (загальна ширина 10, 3 знаки після коми)
```

При використанні динамічних аргументів ширини та точності підсистема `std::format` перевіряє типи відповідних аргументів. Значення ширини та точності повинні бути невід'ємними цілими числами (`int` або `size_t`). Якщо передати від'ємне значення або тип з плаваючою крапкою, під час виконання буде кинуто виняток `std::format_error`.

## Специфікатори типів (type)

Специфікатор `type` контролює спосіб інтерпретації та конвертації аргументу у підсумкову текстовую послідовність.

### Цілочисельні типи (char, int, long, uint64_t)

- `d` — десяткове число (decimal, за замовчуванням для цілих типів).
- `b` / `B` — двійкове число (binary), малі або великі літери префіксу (`0b1010` або `0B1010` при прапорці `#`).
- `x` / `X` — шістнадцяткове число (hexadecimal), малі або великі літери (`0xaf` / `0XAF`).
- `o` — вісімкове число (octal, наприклад `0777`).
- `c` — вивід цілого числа як відповідного символу за кодовою таблицею ASCII/Unicode.

### Числа з плаваючою крапкою (float, double, long double)

- `f` / `F` — запис із фіксованою крапкою (`3.141593`).
- `e` / `E` — экспоненційний запис (`3.141593e+00` / `3.141593E+00`).
- `g` / `G` — загальний формат (автоматичний вибір між `f` та `e` залежно від величини значення).
- `a` / `A` — шістнадцятковий экспоненційний запис (`0x1.921fb54442d18p+1`).

### Рядки та вказівники (string_view, char*, void*)

- `s` — вивід рядка (значення за замовчуванням для `std::string`, `std::string_view`, `const char*`).
- `p` — вивід адреси вказівника у шістнадцятковому форматі `0x...` (вимагає приведення типу до `const void*`).
- `?` — **Debug Formatting (C++23)**: вивід рядка або символу з автоматичним екрануванням спецсимволів (`\n`, `\t`, `\0`) та огортанням у подвійні лапки.

```cpp
// C++23 Debug formatting для логування недрукованих символів
std::string raw = "Header\nLine2\tEnd";
std::string debug_out = std::format("{:?}", raw); 
// Результат: "\"Header\\nLine2\\tEnd\""
```

Специфікатор `?` надзвичайно корисний під час написання модульних тестів та інструментів налагодження. Він автоматично замінює службові символи табуляції, переведення рядка та керуючі коди ASCII їх візуальними екранованими послідовностями (`\t`, `\n`, `\r`, `\0`, `\x1b`), що робить приховані помилки у текстових буферах одразу помітними для розробника.

## Форматування дату й часу (<chrono>)

Починаючи з стандарту C++20, заголовочний файл `<chrono>` тісно інтегровано із підсистемою `<format>`. Специфікатори форматування часових точок та тривалостей оперують прапорцями, аналогічними POSIX-функції `strftime`:

```cpp
#include <format>
#include <chrono>

auto now = std::chrono::system_clock::now();

// Форматування дати й часу за специфікаторами strftime
std::string time_str = std::format("{:%Y-%m-%d %H:%M:%S}", now);
// Приклад: "2026-08-14 19:25:00"

// Днів тижня та місяців
std::string verbose_date = std::format("{:%A, %B %d, %Y}", now);
// Приклад: "Friday, August 14, 2026"
```

Ключові специфікатори часу:
- `%Y` / `%y` — рік з чотирьох цифр (`2026`) / двозначний рік (`26`).
- `%m` / `%d` — місяць (`01`..`12`) / день місяця (`01`..`31`).
- `%H` / `%M` / `%S` — години (`00`..`23`), хвилини (`00`..`59`), секунди (`00`..`59`).
- `%F` — еквівалент скороченого запису `%Y-%m-%d`.
- `%T` — еквівалент скороченого запису `%H:%M:%S`.
- `%z` / `%Z` — часовий пояс у форматі зміщення (`+0300`) або абревіатури (`EEST`).

## Форматування діапазонів та контейнерів (C++23 Ranges Formatting)

Стандарт **C++23** додав підтримку автоматичного форматування контейнерів стандартної бібліотеки (`std::vector`, `std::array`, `std::map`, `std::set`, `std::span` тощо) у заголовочний файл `<format>`.

```cpp
#include <format>
#include <vector>
#include <map>
#include <string>

std::vector<int> nums = {10, 20, 30};
std::string v_out = std::format("{}", nums); // "[10, 20, 30]"

std::map<std::string, int> ages = {{"Alice", 25}, {"Bob", 30}};
std::string m_out = std::format("{}", ages); // "{\"Alice\": 25, \"Bob\": 30}"

// Специфікатор 'n' відключає зовнішні дужки контейнера
std::string raw_nums = std::format("{::#x}", nums); // "[0xa, 0x14, 0x1e]" (з внутрішнім специфікатором елемента)
```

Синтаксис розширеного специфікатора діапазонів має вигляд `{:[range-spec][::element-spec]}`. Подвійне двоеточіє `::` слугує роздільником між прапорцями самого діапазону (наприклад, `n` для відключення дужок) та специфікаціями форматування кожного індивідуального елемента всередині масиву.

## Публічний інтерфейс шаблону std::formatter<T>

Для додавання підтримки форматування власного типу `T` розробник створює явну спеціалізацію шаблону `std::formatter<T, CharT>` у просторі імен `std`.

Спеціалізація повинна надавати два обов'язкові класи методів:

```cpp
namespace std {
    template <typename CharT>
    struct formatter<MyType, CharT> {
        // 1. Метод розбору специфікатора формату у consteval/constexpr контексті
        constexpr auto parse(basic_format_parse_context<CharT>& ctx) 
            -> typename basic_format_parse_context<CharT>::iterator;

        // 2. Метод запису заформатованого значення у вихідний ітератор під час виконання
        template <typename FormatContext>
        auto format(const MyType& val, FormatContext& ctx) const 
            -> typename FormatContext::iterator;
    };
}
```

### Деталізований API контекстів розбору та форматування

#### 1. Клас std::basic_format_parse_context<CharT>

Об'єкт `parse_context` надає методи для розбору підрядка специфікації під час компіляції:
- `constexpr iterator begin() const noexcept` — повертає ітератор на перший символ після двоеточія `:`.
- `constexpr iterator end() const noexcept` — повертає ітератор на кінець рядка формату.
- `constexpr void advance_to(iterator it)` — переміщує поточний ітератор контексту у позицію `it`.
- `constexpr size_t next_arg_id()` — повертає наступний автоматичний індекс аргументу або кидає виняток при змішуванні з позиційними аргументами.
- `constexpr void check_arg_id(size_t id)` — перевіряє валідність позиційного індексу `id`.

#### 2. Клас std::basic_format_context<OutIt, CharT>

Об'єкт `format_context` надає доступ до вихідного ітератора та стертих аргументів у runtime:
- `iterator out()` — повертає вихідний ітератор для запису генеруємих символів.
- `basic_format_arg<basic_format_context> arg(size_t id) const` — повертає стертий аргумент за його індексом `id`.
- `std::locale locale()` — повертає локаль контексту (якщо її було передано у `std::vformat_to`).

Розглянемо повноцінний практичний приклад спеціалізації шаблону `std::formatter` для структури `Point3D`, яка підтримує кілька режимів виводу:

```cpp
// Детальний приклад спеціалізації для власного типу Point3D із повноцінною обробкою
#include <format>
#include <string_view>
#include <cstdint>

struct Point3D {
    double x, y, z;
};

template <>
struct std::formatter<Point3D> {
    enum class Mode { Default, Compact, Hex };
    Mode mode = Mode::Default;
    int precision = 2;

    // 1. Розбір специфікації у constexpr контексті
    constexpr auto parse(std::format_parse_context& ctx) {
        auto it = ctx.begin();
        auto end = ctx.end();

        if (it != end && *it != '}') {
            if (*it == 'c') { mode = Mode::Compact; ++it; }
            else if (*it == 'x') { mode = Mode::Hex; ++it; }
        }

        if (it != end && *it == '.') {
            ++it;
            if (it != end && *it >= '0' && *it <= '9') {
                precision = *it - '0';
                ++it;
            }
        }

        if (it != end && *it != '}') {
            throw std::format_error("Invalid format specifier for Point3D");
        }
        return it;
    }

    // 2. Генерація текстового виводу у вихідний ітератор
    template <typename FormatContext>
    auto format(const Point3D& pt, FormatContext& ctx) const {
        if (mode == Mode::Hex) {
            return std::format_to(ctx.out(), "({:a}, {:a}, {:a})", pt.x, pt.y, pt.z);
        } else if (mode == Mode::Compact) {
            return std::format_to(ctx.out(), "{:.{}f},{:.{}f},{:.{}f}", 
                                  pt.x, precision, pt.y, precision, pt.z, precision);
        }
        return std::format_to(ctx.out(), "Point3D(x={:.{}f}, y={:.{}f}, z={:.{}f})", 
                              pt.x, precision, pt.y, precision, pt.z, precision);
    }
};
```

### Вбудовані форматирувальники стандартної бібліотеки

Стандартні заголовочні файли C++20 та C++23 містять готові спеціалізації `std::formatter` для наступних типів:
- **Базові скалярні типи:** `int`, `long`, `double`, `char`, `bool`, `void*`, `nullptr_t`.
- **Строкові типи:** `std::string`, `std::string_view`, `const char*`, `std::u8string`.
- **Контейнери та діапазони (C++23):** `std::vector`, `std::array`, `std::deque`, `std::list`, `std::map`, `std::set`, `std::span`.
- **Утиліти:** `std::pair`, `std::tuple`, `std::optional`, `std::variant` (через debug/ranges formatters).
- **Час та шляхи:** `std::chrono::system_clock::time_point`, `std::chrono::duration`, `std::filesystem::path`.

При такому підході тип `Point3D` отримує повноцінну підтримку форматування з компиляційною перевіркою синтаксису: виклик `std::format("{:.3f}", Point3D{1.1, 2.2, 3.3})` згенерує `"Point3D(x=1.100, y=2.200, z=3.300)"`, а помічена помилка `std::format("{:z}", Point3D{})` викликає помилку компіляції ще на етапі збірки проєкту.
