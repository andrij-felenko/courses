# Книга — HTML-обгортка над курсом

Гарна навігована «книжка», що збирається **прямо в браузері** з тих самих `.md`-файлів,
якими пишеться курс. Без збірки: закомітив новий розділ — і він у книзі.

## Розкладка репозиторію

```
/                 ← обгортка (її обслуговує GitHub Pages «from root»)
  index.html      оболонка (сайдбар + вміст), точка входу
  book.css        стилі (палітра й компоненти з прототипу ch01.html)
  book.js         рушій без залежностей: парсер Markdown, hash-роутер, навігація
  manifest.js     СТРУКТУРА книги — повна мапа курсу (7 модулів · 60 розділів); єдине, що редагується вручну
  chem.html       друга книга — «Хімія без зубріння» (та сама обгортка, інший manifest)
  manifest-chem.js  структура хімічної книги (нумерація М.Р, теми М.Р.Т)
  README.md       цей файл
  LICENSE
  embedded/       ← КОНТЕНТ: .md розділів, історії, img/*.svg, figs.py (як і був)
  chemistry/      ← КОНТЕНТ другої книги: AUTHORING.md, PLAN.md, m1…m5 з .md/figs.py/img
```

Обгортка в корені, контент у `embedded/` — бо GitHub Pages вміє віддавати лише `root`
або `/docs`, а вкладену `embedded/` не дозволяє. Звʼязок задає один рядок у `manifest.js`:
`basePath: "embedded/"`.

Старий рукотворний прототип `embedded/block-1-…/ch01-…/ch01.html` більше не потрібен
(його замінює спільний рушій) — можна лишити як зразок або видалити.

## Як подивитися локально

`index.html` тягне `.md` через `fetch`, а він **не працює** з `file://`. Тому — будь-який
локальний сервер **із кореня репозиторію**:

```
python -m http.server
```

і відкрий <http://localhost:8000/>. (Обкладинка/зміст показуються навіть без сервера —
бо беруться з `manifest.js`; а от вміст розділів потребує саме `http://`.)

## Як викласти на GitHub Pages

**Settings → Pages → Deploy from branch**, гілка `main`, папка **`/ (root)`**. Книга буде на:

```
https://<користувач>.github.io/<репозиторій>/
```

Чистий URL, без `/embedded/`. Усі шляхи в обгортці **відносні**, тож і локально, і на
Pages працює без змін.

> Альтернатива — тримати все в одній теці: перейменуй `embedded/` → `docs/`, постав у
> `manifest.js` `basePath: ""` і вибери в Pages папку `/docs`. Тоді обгортку теж поклади
> в `docs/`. (Поточний варіант із коренем простіший і нічого не перейменовує.)

## Як додати готовий розділ у книгу

Відкрий `manifest.js`, знайди потрібний розділ і додай йому поля (приклад — Розділ 2.1;
`n` — номер розділу **всередині модуля**):

```js
{
  n: 1, status: "done",              // розділ 2.1 = модуль 2, n: 1
  title: "Конденсатор",
  dir: "block-2-components-analog/ch07-capacitor",  // від embedded/ (без префікса);
                                     // старі папки chNN-…, нові розділи — rРР-…
  main: "ch07-capacitor.md",
  histories: [                       // у порядку читання; заголовки тягнуться з файлів
    "ch07-history-leyden-jar.md"
  ]
}
```

Більше нічого: сайдбар (теми + історії), якорі, перехресні `.md`-лінки й мапа курсу
зберуться самі. Поки `status: "pending"` — розділ показується в змісті сірим («незабаром»).

## Друга книга — «Хімія без зубріння»

Той самий рушій `book.js`, інша точка входу: локально <http://localhost:8000/chem.html>,
на Pages — `…/chem.html`. Контент — у `chemistry/` (правила — `chemistry/AUTHORING.md`,
розбивка і /loop-команди — `chemistry/PLAN.md`). Нумерація — та сама **М.Р.Т**
(модуль.розділ.тема), що тепер і в embedded: заголовки тем `## 1.2.3 Назва`; рушій
розуміє і старі двочислові, і тричислові номери. Додаткові callout-и хімії: `> 🏠 …` (де це вдома),
`> 🧪 …` (спробуй сам), `> 💡 …` (одним реченням); історії там — мікро-вставки `> 📜 …`
прямо в тексті, без окремих файлів.

## Що рушій розуміє в Markdown (конвенції курсу)

- `## М.Р.Т Назва` (модуль.розділ.тема, напр. `## 1.2.3 …`) → тема з якорем `#ch=<slug>&at=sec-М-Р-Т`; `###`/`####` — підзаголовки.
- `> 🔧 …` → інженерна рамка «Навіщо це»; `> 📜 …` → історична; `> ▶️ …` → навігаційна.
- `![alt](img/fig.svg)` + наступний рядок `*Рис. М.Р.Т.k. …*` → `<figure>` з підписом.
- Код-блоки ``` ``` ``` → моноширинні формули/обчислення (Unicode-математика — як є).
- `[текст](файл.md)` і `[§М.Р.Т](../папка-розділу/файл.md)` → переписуються на маршрути книги
  (історії того ж розділу — внутрішні якорі; інші розділи — перехід між сторінками).
- Історичні файли (`# 📜 …`) додаються як окремі блоки в кінці своєї сторінки-розділу.
