# 📋 Довідник конфігурації GNU Readline: директиви, змінні та прив'язки клавіш

Бібліотека GNU Readline керує посимвольним введенням, історією та автодоповненням у більшості інтерактивних консольних програм Unix — від оболонки Bash і зневаджувача GDB до інтерпретаторів Python, Ruby та клієнтів баз даних PostgreSQL і SQLite. Файл конфігурації `~/.inputrc` (або системний `/etc/inputrc`) визначає поведінку рядкового редактора глобально для всіх цих утиліт одночасно.

Робота бібліотеки базується на переведенні термінала у сирий неканонічний режим (`termios RAW mode`). У цьому режимі дисципліна лінії ядра Linux перестає самостійно обробляти символи видалення та переведення рядка, а передає кожен отриманий байт безпосередньо процесу програми. Readline перехоплює цей потік байтів, зіставляє його з активною таблицею прив'язок клавіш (`keymap`), модифікує внутрішній буфер рядка в оперативній пам'яті та керує перемальовуванням тексту на екрані емулятора термінала.

Нижче наведено повну специфікацію директив налаштування, синтаксис прив'язки клавіш, правила роботи з макросами, умовні конструкції та коди дій для тонкого налаштування поведінки інтерактивних програм.

## Ієрархія ініціалізації та синтаксис файлу inputrc

Під час запуску будь-яка програма, зібрана з підтримкою GNU Readline, виконує пошук конфігураційного файлу в такому порядку:
1. Значення змінної середовища `INPUTRC` (якщо змінну експортовано, бібліотека читає лише вказаний у ній файл).
2. Індивідуальний файл конфігурації користувача `~/.inputrc`.
3. Глобальний системний файл `/etc/inputrc`.

Якщо жоден із цих файлів не знайдено, Readline застосовує вбудовану за замовчуванням конфігурацію в режимі Emacs.

Синтаксис конфігураційного файлу підтримує три основні типи конструкцій:
- Встановлення внутрішніх змінних поведінки: `set <назва-змінної> <значення>`.
- Прив'язка комбінацій клавіш до функцій або макросів: `"послідовність": назва-функції` або `назва-функції: послідовність`.
- Умовні блоки для фільтрації налаштувань: `$if ... $else ... $endif`.

Рядки, що починаються з символу `#`, вважаються коментарями. Порожні рядки ігноруються парсером.

## Повна матриця змінних GNU Readline

Внутрішні змінні змінюють логіку обробки вводу, швидкість реакції на ескейп-послідовності, поведінку алгоритму автодоповнення та візуалізацію курсора.

| Змінна | Дефолт | Допустимі значення | Архітектурна дія та призначення |
|---|---|---|---|
| `completion-ignore-case` | `off` | `on`, `off` | Вмикає регістронезалежне зіставлення імен файлів, команд та параметрів. Якщо параметр увімкнено, введення `doc` знайде файл `Documents.pdf`. |
| `show-all-if-ambiguous` | `off` | `on`, `off` | Змінює логіку клавіші Tab при неоднозначному збігу. Замість звукового сигналу при першому натисканні та очікування другого Tab, список варіантів виводиться негайно. |
| `show-all-if-unmodified` | `off` | `on`, `off` | Виводить список доступних варіантів доповнення, якщо часткове автодоповнення не змогло дописати жодного нового символу до рядка. |
| `colored-stats` | `off` | `on`, `off` | Вмикає колірне маркування типів файлів у списку автодоповнення на основі змінної оточення `$LS_COLORS` (каталоги, сокети, виконувані файли). |
| `colored-completion-prefix` | `off` | `on`, `off` | Підсвічує іншим кольором префікс, який користувач уже набрав власноруч, візуально виділяючи спільну частину слів. |
| `mark-symlinked-directories` | `off` | `on`, `off` | Додає скісну риску `/` в кінець символічних посилань, якщо вони вказують на каталоги, запобігаючи помилковому сприйняттю їх як звичайних файлів. |
| `mark-directories` | `on` | `on`, `off` | Автоматично дописує скісну риску `/` до імен завершених каталогів під час автодоповнення шляхів. |
| `completion-query-items` | `100` | Ціле число ≥ 0 | Поріг кількості збігів, після якого бібліотека запитує підтвердження `Display all N possibilities? (y or n)`. Значення `0` повністю вимикає це обмеження. |
| `menu-complete-display-prefix` | `off` | `on`, `off` | Під час циклічного перебору варіантів через функцію `menu-complete` зберігає на екрані спільний префікс набраного тексту. |
| `match-hidden-files` | `on` | `on`, `off` | Дозволяє автодоповненню шукати приховані файли та каталоги (що починаються з крапки), навіть якщо користувач явно не ввів крапку першим символом. |
| `editing-mode` | `emacs` | `emacs`, `vi` | Визначає парадигму редагування. Режим `emacs` є безмодальним, тоді як `vi` емулює модальний автомат редактора Vim з режимами команд і вставки. |
| `show-mode-in-prompt` | `off` | `on`, `off` | Додає індикатор поточного режиму редагування Vi на початку рядка підказки (символ `+` для вставки, `:` для командного режиму). |
| `vi-ins-mode-string` | `(ins)` | Рядок з `\1` та `\2` | Текстовий або керівний рядок для режиму вставки Vi. Дозволяє надсилати терміналу VT100-команди для зміни форми курсора на тонку вертикальну риску (beam). |
| `vi-cmd-mode-string` | `(cmd)` | Рядок з `\1` та `\2` | Керівний рядок для командного режиму Vi. Використовується для перемикання курсора термінала на монолітний блок (block). |
| `keyseq-timeout` | `500` | Число (мс) | Інтервал очікування чергового байта в багатобайтовій ескейп-послідовності. Зменшення значення до `10–50` усуває відчутну затримку при натисканні Escape у режимі Vi. |
| `bell-style` | `audible` | `none`, `visible`, `audible` | Спосіб сигналізації про помилку або межу буфера: `none` глушить будь-які сигнали, `visible` викликає візуальне мерехтіння термінала, `audible` надсилає байт `0x07` (BEL). |
| `echo-control-characters` | `on` | `on`, `off` | Визначає, чи друкувати у термінал символи на кшталт `^C` або `^Z`, коли користувач надсилає сигнали керування завданнями з клавіатури. |
| `revert-all-at-newline` | `off` | `on`, `off` | Скасовує всі локальні правки в переглянутих рядках історії команд після натискання Enter, повертаючи історію до початкового стану. |
| `expand-tilde` | `off` | `on`, `off` | Автоматично замінює тильду `~` на абсолютний шлях до домашнього каталогу під час виконання автодоповнення слів. |
| `enable-bracketed-paste` | `on` | `on`, `off` | Вмикає режим безпечної вставки тексту з буфера обміну, обрамляючи вставлені дані спеціальними кодами для запобігання передчасному виконанню команд. |

## Синтаксис опису клавіш та керуючих кодів

Для прив'язки клавіш у файлі `~/.inputrc` застосовується спеціальний символьний синтаксис, що дозволяє описувати комбінації клавіш модифікаторів Control, Alt/Meta та функціональних клавіш:
- `\C-` або `\c` — клавіша Control. Наприклад, `\C-a` позначає комбінацію Ctrl+A (байт `0x01`).
- `\M-` або `\e` — клавіша Meta (у сучасних терміналах — клавіша Alt або префіксний код Escape `0x1B`). Наприклад, `\M-b` позначає Alt+B.
- `\e` — керівний символ Escape (`\033`, десятковий код 27).
- `\t` — символ горизонтальної табуляції (код `0x09`).
- `\n` та `\r` — символи нового рядка (LF) та повернення каретки (CR).
- `\\`, `\"`, `\'` — екранування службових символів для запобігання передчасному закриттю рядка в парсері.

Функціональні клавіші та стрілки передаються емулятором термінала як послідовності ANSI/VT100:
- `\e[A` — Стрілка вгору (Up Arrow).
- `\e[B` — Стрілка вниз (Down Arrow).
- `\e[C` — Стрілка праворуч (Right Arrow).
- `\e[D` — Стрілка ліворуч (Left Arrow).
- `\e[H` або `\e[1~` — Клавіша Home.
- `\e[F` або `\e[4~` — Клавіша End.
- `\e[3~` — Клавіша Delete.
- `\e[Z` — Комбінація Shift+Tab.
- `\e[1;5C` та `\e[1;5D` — Комбінації Ctrl+Right та Ctrl+Left у терміналах xterm-сумісного типу.

## Каталог вбудованих функцій редагування

Readline містить десятки вбудованих функцій маніпуляції текстом, які можна призначати на довільні клавіші.

### 1. Навігація по рядку

- `beginning-of-line` — переміщує курсор на перший символ активного рядка (дефолт: `\C-a`).
- `end-of-line` — переміщує курсор у кінець поточного рядка (дефолт: `\C-e`).
- `forward-char` — зсуває курсор на одну позицію праворуч (дефолт: `\C-f`).
- `backward-char` — зсуває курсор на одну позицію ліворуч (дефолт: `\C-b`).
- `forward-word` — стрибок курсора вперед до кінця поточного або наступного слова (дефолт: `\M-f`).
- `backward-word` — стрибок курсора назад до початку поточного слова (дефолт: `\M-b`).
- `clear-screen` — надсилає терміналу код очищення екрана зі збереженням набраного тексту в поточному рядку (дефолт: `\C-l`).

### 2. Редагування, видалення та буфер Kill Ring

Усі операції видалення фрагментів довжиною понад один символ зберігають вирізаний текст у кільцевому буфері пам'яті (`kill-ring`). Це дозволяє відновлювати та циклічно перебирати видалені фрагменти.

- `delete-char` — видаляє символ безпосередньо під курсором (дефолт: `\C-d`).
- `backward-delete-char` — видаляє символ ліворуч від курсора (клавіша Backspace, `\C-h`).
- `kill-line` — вирізає весь текст від поточної позиції курсора до кінця рядка в буфер (дефолт: `\C-k`).
- `backward-kill-line` — вирізає текст від початку рядка до поточної позиції курсора.
- `unix-line-discard` — повністю очищає поточний рядок з перенесенням тексту в буфер (дефолт: `\C-u`).
- `kill-word` — вирізає символи від курсора до кінця поточного слова (дефолт: `\M-d`).
- `backward-kill-word` — вирізає символи від курсора до початку слова за правилами мов програмування (дефолт: `\M-\C-h`).
- `unix-word-rubout` — вирізає слово ліворуч від курсора, використовуючи лише пробіли як роздільники слів (дефолт: `\C-w`). Дуже зручно для швидкого обрізання шляхів до файлів.
- `yank` — вставляє останній вирізаний елемент із кільцевого буфера в поточну позицію курсора (дефолт: `\C-y`).
- `yank-pop` — циклічно замінює щойно вставлений текст на попередній елемент із кільцевого буфера (дефолт: `\M-y`). Працює лише безпосередньо після виконання команди `yank`.

### 3. Пошук в історії команд

- `reverse-search-history` — вмикає режим інкрементального пошуку у зворотному напрямку за набраним підрядком (дефолт: `\C-r`).
- `forward-search-history` — інкрементальний пошук уперед (дефолт: `\C-s`).
- `history-search-backward` — шукає в історії попередню команду, яка починається з тексту, уже набраного в рядку до поточної позиції курсора.
- `history-search-forward` — шукає наступну команду в історії за набраним префіксом.
- `beginning-of-history` — перехід до найпершої збереженої команди в історії (дефолт: `\M-<`).
- `end-of-history` — перехід до найостаннішої команди в історії (дефолт: `\M->`).

### 4. Автодоповнення та контекстне розкриття

- `complete` — стандартна дія автодоповнення шляху, команди або змінної (дефолт: `\t`).
- `menu-complete` — циклічно підставляє перший знайдений варіант автодоповнення прямо в рядок, а кожне наступне натискання замінює його на наступний варіант зі списку.
- `menu-complete-backward` — виконує перебір варіантів доповнення у зворотному порядку (рекомендовано прив'язувати на Shift+Tab).
- `possible-completions` — виводить список усіх можливих варіантів доповнення без модифікації рядка редагування (дефолт: `\M-?`).
- `insert-completions` — вставляє всі знайдені варіанти автодоповнення безпосередньо в рядок команди через пробіл (дефолт: `\M-*`).

## Умовні блоки ($if ... $else ... $endif)

Директиви розгалуження дозволяють ізолювати налаштування для конкретних застосунків, терміналів або режимів в одному спільному файлі `~/.inputrc`.

### 1. Фільтрація за іменем програми ($if <застосунок>)

Readline порівнює назву програми, передану при ініціалізації через внутрішню змінну `rl_readline_name`.

```text
# Специфічні правила для командної оболонки Bash
$if Bash
    # Префіксний пошук на стрілках вгору та вниз
    "\e[A": history-search-backward
    "\e[B": history-search-forward
    
    # Видалення цілого слова шляху назад
    "\C-w": unix-word-rubout
$endif

# Налаштування для інтерактивного клієнта баз даних PostgreSQL
$if psql
    set expand-tilde on
    set show-all-if-ambiguous on
$endif

# Налаштування для зневаджувача GDB
$if gdb
    set editing-mode emacs
    "\e[A": previous-history
    "\e[B": next-history
$endif
```

### 2. Фільтрація за режимом редагування ($if mode=...)

Дозволяє визначити різні комбінації для режимів `emacs`, `vi`, `vi-insert` та `vi-command`.

```text
$if mode=vi
    # Зменшуємо затримку реакції на клавішу Escape
    set keyseq-timeout 15
    set show-mode-in-prompt on

    # Перемикання форми курсора термінала через послідовності VT100:
    # \e[2 q — суцільний прямокутний блок для командного режиму (cmd)
    # \e[6 q — тонка вертикальна риска для режиму вставки (ins)
    # Коди \1 та \2 позначають невидимі байти нульової ширини
    set vi-cmd-mode-string "\1\e[2 q\2"
    set vi-ins-mode-string "\1\e[6 q\2"

    # Прив'язки для режиму вставки
    set keymap vi-insert
    "jk": vi-movement-mode
    "\C-w": backward-kill-word

    # Прив'язки для командного режиму
    set keymap vi-command
    "H": beginning-of-line
    "L": end-of-line
$else
    set show-mode-in-prompt off
$endif
```

### 3. Фільтрація за типом термінала ($if term=...)

Використовується для адаптації під можливості середовища, зазначені в змінній `$TERM`.

```text
$if term=xterm-256color
    set colored-stats on
    set colored-completion-prefix on
$endif

$if term=linux
    # На апаратній віртуальній консолі Linux ядра вимикаємо розширені кольори
    set colored-stats off
    set bell-style visible
$endif
```

## Механізм макросів та текстових підстановок

Якщо права частина прив'язки клавіші записана в лапках як рядок тексту, а не назва вбудованої функції, Readline розглядає її як клавіатурний макрос. Під час натискання комбінації бібліотека вставляє вказаний текст так, ніби його було набрано на клавіатурі.

Спеціальний суфікс `\C-m` або `\C-j` у макросі автоматично ініціює натискання клавіші Enter, викликаючи негайне виконання підставленої команди.

```text
# Макрос: швидке очищення екрана та друк списку файлів
"\C-x\C-l": "clear; ls -la\C-m"

# Макрос: обгортання попередньої команди в sudo
"\C-xs": "\C-asudo \C-e\C-m"

# Макрос: виклик git status з негайним виконанням
"\C-xg": "git status\C-m"
```

## Еталонна production-конфігурація ~/.inputrc

Зведений приклад стабільного, продуктивного файлу налаштувань, оптимізованого для щоденної розробки та системного адміністрування:

```text
# ~/.inputrc — Оптимізована конфігурація GNU Readline

# 1. Загальні параметри введення та кодування UTF-8
set input-meta on
set output-meta on
set convert-meta off
set bell-style none
set enable-bracketed-paste on

# 2. Оптимізація та підсвічування автодоповнення
set completion-ignore-case on
set show-all-if-ambiguous on
set show-all-if-unmodified on
set colored-stats on
set colored-completion-prefix on
set mark-symlinked-directories on
set mark-directories on
set completion-query-items 200

# 3. Навігація по історії за набраним префіксом (Up / Down)
"\e[A": history-search-backward
```
