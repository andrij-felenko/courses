# 📋 Інженерний чекліст діагностики мікросхеми

Коли цифровий периферійний чіп не відповідає на запити керуючого мікроконтролера, хаотична зміна параметрів прошивки лише заплутує пошук проблеми. Надійна локалізація несправності вимагає суворого дотримання послідовності апаратних і протокольних вимірювань. Нижче наведено зведену матрицю контрольних точок, граничних електричних параметрів, часових бюджетів та алгоритмів усунення типових збоїв для інтерфейсів I2C та SPI.

### Матриця покрокових вимірювань та критеріїв норми

Усі первинні вимірювання виконуються безпосередньо на металевих виводах корпусу чіпа, а не на роз'ємах плати чи контактах джерела живлення.

```
+----+-----------------------+----------------------------------+--------------------------------------+----------------------------------------+
| №  | Вузол / Лінія         | Точка вимірювання                | Критерій норми                       | Характерна ознака несправності         |
+----+-----------------------+----------------------------------+--------------------------------------+----------------------------------------+
| 1  | Напруга VDD           | Безпосередньо на ніжці чіпа      | V_min <= V_DD <= V_max (±3%)         | Падіння > 100 мВ, просадки під час TX  |
| 2  | Рівень GND            | Ніжка GND чіпа відносно GND МК   | Напруга < 20 мВ                      | Зсув потенціалу через опір перехідного |
| 3  | Пульсації живлення    | Вивід VDD (режим AC осцилографа) | Пульсації < 30 мВ peak-to-peak       | Високочастотний дзвін імпульсника      |
| 4  | Лінія Reset (nRST)    | Ніжка /RESET мікросхеми          | V > 0.8·V_DD (для active-low)        | Плаваючий рівень або постійний нуль    |
| 5  | Enable / Shutdown     | Виводи CE, EN, /SHDN             | Активний логічний рівень за даташитом| Вивід залишено висіти в повітрі        |
| 6  | Підтяжка I2C (SCL/SDA)| Лінії шини у стані спокою        | Напруга = V_DD, опір 2.2k..4.7k      | Рівень < 0.7·V_DD, затягнутий фронт tr |
| 7  | Вибір кристала (CS)   | Вивід CS / SS шини SPI           | Активний рівень під час передачі     | Рівень не змінюється при виклику SPI   |

| 10 | Тактові строби SCK/SCL| Осцилограф під час транзакції    | Чіткі прямокутні імпульси заданої f  | Постійний рівень 0 або 1 (немає стробу)|
+----+-----------------------+----------------------------------+--------------------------------------+----------------------------------------+
```

### Граничні параметри логічних рівнів та часових інтервалів

Для забезпечення сумісності між мікроконтролером (3.3 В) та веденими чіпами діють стандартні обмеження для КМОН-логіки (CMOS). Якщо рівень напруги на лінії потрапляє в проміжну заборонену зону між `V_IL(max)` та `V_IH(min)`, вхідний тригер Шмітта мікросхеми може зафіксувати випадковий стан або почати високочастотне самозбудження:

```
+------------------------------------+--------------------------+--------------------------+
| Електричний параметр               | Рівень живлення 3.3 В    | Рівень живлення 5.0 В    |
+------------------------------------+--------------------------+--------------------------+
| Максимальний рівень нуля (V_IL)    | <= 0.3 · V_DD (0.99 В)   | <= 0.3 · V_DD (1.50 В)   |
| Мінімальний рівень одиниці (V_IH)  | >= 0.7 · V_DD (2.31 В)   | >= 0.7 · V_DD (3.50 В)   |
| Запас завадостійкості нуля (V_NML) | >= 0.1 · V_DD (0.33 В)   | >= 0.1 · V_DD (0.50 В)   |
| Запас завадостійкості од. (V_NMH)  | >= 0.1 · V_DD (0.33 В)   | >= 0.1 · V_DD (0.50 В)   |
| Час наростання I2C Standard (t_r)  | <= 1000 нс               | <= 1000 нс               |
| Час наростання I2C Fast (t_r)      | <= 300 нс                | <= 300 нс                |
| Час спаду сигналу I2C (t_f)        | <= 300 нс                | <= 300 нс                |
| Сумарна ємність шини I2C (C_b)     | <= 400 пФ                | <= 400 пФ                |
+------------------------------------+--------------------------+--------------------------+
```

### Контроль послідовності подачі живлення (Power Sequencing) та тактування

Багатофункціональні цифрові мікросхеми (наприклад, сучасні GNSS-приймачі, радіомодулі Wi-Fi/Bluetooth, мікроконтролери та складні IMU) мають роздільні домени живлення:
- `V_DD_IO` — живлення інтерфейсних буферів вводу-виводу (зазвичай 1.8 В або 3.3 В);
- `V_DD_CORE` — живлення цифрового обчислювального ядра (1.1 В, 1.2 В або 1.8 В);
- `V_DDA` / `V_REF` — аналогове живлення чутливих сенсорів, генераторів та АЦП.

```
+------------------------------------+----------------------------------+----------------------------------------------------+
| Параметр послідовності живлення    | Критерій норми за даташитом      | Небезпечний наслідок порушення послідовності       |
+------------------------------------+----------------------------------+----------------------------------------------------+
| Порядок появи напруг               | V_DD_CORE раніше або разом з IO  | Ефект тиристорного замикання (Latch-up) кристала   |
| Швидкість наростання (Slew Rate)   | 0.05 В/мс <= dV/dt <= 50 В/мс    | Збій внутрішнього детектора POR, зависання логіки  |
| Різниця між доменами напруг        | |V_DDA - V_DDD| < 0.3 В          | Струми витоку через мікроструктури ізоляції кремнію|
| Частота зовнішнього кварцу (XTAL)  | Номінал ±30 ppm, V_pp > 0.8·V_DD | Генератор не запускається через завеликі C_load    |
+------------------------------------+----------------------------------+----------------------------------------------------+
```

Якщо напруга живлення інтерфейсу `V_DD_IO` подається раніше, ніж увімкнеться основне живлення ядра `V_DD_CORE`, струм через захисні діоди виводів вводу-виводу може почати паразитно підживлювати кристал зсередини (фантомне живлення, англ. *Phantom Powering*). У цьому стані кристал гріється, струм споживання зростає у десятки разів, а інтерфейс зв'язку повністю блокується.

### Профілювання споживання струму у статиці та динаміці

Вимірювання струму в розриві лінії живлення мікросхеми (за допомогою прецизійного мікроамперметра або шунта опором 1–10 Ом з інструментальним підсилювачем) дозволяє миттєво локалізувати стан кристала:
1. **Струм дорівнює строго 0.00 мкА:** повний обрив лінії `V_DD` або `GND` (холодна пайка, відсутність контакту виводу BGA/QFN із контактним майданчиком).
2. **Струм становить одиниці мікроамперів (`I ≤ 10 мкА`):** чіп перебуває у стані глибокого сну (Power-Down) або апаратного скидання. Це вказує на некоректний рівень на виводах `nRST`, `EN` або `/SHDN`.
3. **Струм відповідає активному режиму (`I = 1..15 мА`), але змінюється під час передачі:** кристал успішно запустився, внутрішнє ядро працює; проблему слід шукати у фізиці шини або адресації.
4. **Струм аномально високий (`I > 50..100 мА`) або чіп відчутно нагрівається:** внутрішній тепловий пробій, замикання між доменами живлення або тиристорний ефект защіпки (Latch-up). Необхідно негайно знеструмити схему для запобігання повному вигорянню доріжок.

### Налаштування вимірювальних приладів для діагностики шин

#### Осцилограф (Signal Integrity Check)
1. **Смуга пропускання:** не менше 50–100 МГц (для коректного відображення фронтів тривалістю менше 20 нс).
2. **Тип щупа:** пасивний щуп із дільником 10X (вхідна ємність `≤ 10 пФ`, вхідний опір `10 МОм`). Використання щупа в режимі 1X додає до лінії до 100 пФ паразитної ємності, що саме по собі спотворює форму фронтів I2C.
3. **Заземлення щупа:** виключно коротка заземлювальна пружина на наконечнику щупа, встановлена на найближчий земляний полігон. Довгий гнучкий провід із «крокодилом» створює паразитну індуктивність контуру до 50–100 нГн, яка формує на екрані фальшивий високочастотний дзвін амплітудою до 0.5–1.0 В.
4. **Синхронізація (Trigger):**
   - Для I2C: запуск за умовою спадного фронту SDA при високому рівні SCL (детектування умови START) або за тривалістю імпульсу (Pulse Width);
   - Для SPI: запуск за спадним фронтом сигналу Chip Select (`CS`).

#### Логічний аналізатор (Protocol Decoding)
1. **Частота дискретизації (Sampling Rate):** повинна щонайменше у 4–10 разів перевищувати максимальну частоту тактування шини.
   - Для I2C Standard Mode (100 кГц) → частота дискретизації не менше 1–2 Мвиб/с;
   - Для I2C Fast Mode (400 кГц) → частота дискретизації не менше 4–10 Мвиб/с;
   - Для SPI (10 МГц) → частота дискретизації не менше 50–100 Мвиб/с.
2. **Поріг спрацьовування (Threshold Voltage):**
   - Для логіки 3.3 В виставляється поріг `1.5 В` – `1.65 В`;
   - Для логіки 1.8 В виставляється поріг `0.9 В`.

### Експрес-діагностика захисних діодів (ESD Diode Test)

Якщо мікросхема перестала відповідати після контакту з руками, перепайки або підключення на гарячу, вхідні транзистори могли вийти з ладу через електростатичний розряд:
1. Повністю знеструмте плату та розрядіть усі фільтруючі конденсатори.
2. Увімкніть цифровий мультиметр у режим перевірки діодів (*Diode Check*).
3. Червоний (плюсовий) щуп мультиметра підключіть до виводу `GND` мікросхеми.
4. Чорним (мінусовим) щупом торкніться по черзі кожного цифрового виводу (`SDA`, `SCL`, `MOSI`, `MISO`, `SCK`, `nRST`, `CS`).
5. На справному кристалі прилад покаже пряме падіння напруги на внутрішньому захисному PN-переході в межах **`0.5 В .. 0.7 В`** (для стандартних кремнієвих діодів захисту) або `0.2 В .. 0.3 В` (для діодів Шотткі).
6. Тепер поміняйте полярність: чорний щуп підключіть до виводу `V_DD`, а червоним торкайтеся цифрових виводів. Прилад також має показати пряме падіння на верхніх діодах захисту до шини живлення (`0.5 В .. 0.7 В`).
7. Якщо мультиметр показує падіння `0.00 В` (коротке замикання через розплавлений p-n перехід) або `OL / нескінченність` в обох напрямках (обрив зв'язуючого золотого мікродротика всередині корпусу чіпа) — вхідний каскад мікросхеми випалено статикою, кристал підлягає обов'язковій заміні.
