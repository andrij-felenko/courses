# 🧮 Розрахунок резистивного дільника 6-позиційного перемикача режимів

Ця математична вставка містить аналітичний розрахунок номіналів резистивного дільника для 6-позиційного поворотного перемикача польотних режимів, виведення функції відображення напруги в мікросекундну тривалість імпульсу та строгий розрахунок допусків опору для гарантування стабільності режимів при зміні температури й шумі аналого-цифрового перетворювача (АЦП).

Помилка вибору польотного режиму внаслідок температурного дрейфу або похибки резисторів призводить до того, що польотний контролер замість режиму утримання позиції (Loiter) раптово активує ручний пілотаж (Acro) або автопосадку (Land). Нижче наведено інженерний математичний апарат, що дозволяє розрахувати надійний дільник із гарантованими запасами завадостійкості, враховуючи вхідний імпеданс тракту вибірки-зберігання АЦП.

---

## 1. Аналітична модель резистивного дільника на 6 позицій

Розглянемо послідовний ланцюг із шести постійних резисторів `R₁`, `R₂`, `R₃`, `R₄`, `R₅`, `R₆`, підключених між шиною живлення опорної напруги `V_cc` (зазвичай `3.3 В` від стабілізатора передавача) та загальним проводом (`GND` = `0 В`).

Повний еквівалентний опір ланцюга `R_total`:

```
R_total = R₁ + R₂ + R₃ + R₄ + R₅ + R₆
```

Струм `I_div`, що протікає крізь дільник у стаціонарному стані:

```
I_div = V_cc / R_total
```

У кожній `k`-й позиції селектора (`k ∈ {1, 2, 3, 4, 5, 6}`) вихідна напруга `U_out(k)` знімається з відповідного вузла дільника відносно землі. Якщо позиція 1 відповідає найнижчій напрузі над `R₆`, а позиція 6 — найвищій напрузі біля `V_cc`:

```
U_out(1) = V_cc · R_bottom / R_total
U_out(2) = V_cc · (R_bottom + R₅) / R_total
U_out(3) = V_cc · (R_bottom + R₅ + R₄) / R_total
U_out(4) = V_cc · (R_bottom + R₅ + R₄ + R₃) / R_total
U_out(5) = V_cc · (R_bottom + R₅ + R₄ + R₃ + R₂) / R_total
U_out(6) = V_cc · (R_total - R_top) / R_total
```

У загальному вигляді для довільного вузла `k`:

```
U_out(k) = V_cc · (∑_{i=1}^k R_lower_i) / R_total   [поділ напруги послідовного ланцюга]
```

де `R_lower_i` — сумарний опір усіх резисторів, розташованих між `k`-м контактом селектора та шиною заземлення.

## 2. Функція відображення напруги в тривалість імпульсу ШІМ / значення каналу

Мікроконтролер пульта вимірює напругу `U_out(k)` за допомогою внутрішнього АЦП розрядністю `N_adc = 12 біт` (діапазон вимірювання `0...4095` відліків).

Код АЦП `D_adc(k)`:

```
D_adc(k)
= (U_out(k) / V_cc) · (2¹² - 1)              [лінійне квантування 12-бітного АЦП]
= (U_out(k) / V_cc) · 4095
```

Прошивка передавача (EdgeTX / OpenTX) транслює виміряне значення каналу в нормалізований імпульс каналу керування `T_pwm` у діапазоні від `T_min = 988 мкс` (або `1000 мкс`) до `T_max = 2012 мкс` (або `2000 мкс`):

```
T_pwm(k)
= T_min + (D_adc(k) / 4095) · (T_max - T_min)     [масштабування коду АЦП у тривалість ШІМ]
= T_min + (U_out(k) / V_cc) · ΔT_full             [підстановка співвідношення напруг]
```

де `ΔT_full = T_max - T_min = 2012 - 988 = 1024 мкс`.

Польотні стеки ArduPilot та PX4 очікують такі цільові значення `T_target` для шести режимів польоту:
- Режим 1: `T₁ = 1165 мкс` (центральне вікно `988...1230 мкс`)
- Режим 2: `T₂ = 1295 мкс` (центральне вікно `1231...1360 мкс`)
- Режим 3: `T₃ = 1425 мкс` (центральне вікно `1361...1490 мкс`)
- Режим 4: `T₄ = 1555 мкс` (центральне вікно `1491...1620 мкс`)
- Режим 5: `T₅ = 1685 мкс` (центральне вікно `1621...1749 мкс`)
- Режим 6: `T₆ = 1815 мкс` (центральне вікно `1750...2012 мкс`)

Крок між сусідніми режимами є рівномірним і становить:

```
ΔT_step = 1295 - 1165 = 130 мкс
```

Ширина кожного вікна декодування становить `130 мкс`, отже, максимальне допустиме відхилення імпульсу від центру вікна без ризику помилкового перемикання становить:

```
ΔT_margin = ΔT_step / 2 = 130 / 2 = ±65 мкс
```

## 3. Виведення номіналів резисторів стандартного ряду E24 / E96

Знайдемо необхідні відносні напруги `u_k = U_out(k) / V_cc` для отримання цільових значень `T_k`:

```
u_k = (T_k - T_min) / ΔT_full
```

Обчислимо точні значення для кожного режиму при `T_min = 988 мкс` та `ΔT_full = 1024 мкс`:

```
u₁ = (1165 - 988) / 1024 = 177 / 1024 ≈ 0.17285   [частка напруги для режиму 1]
u₂ = (1295 - 988) / 1024 = 307 / 1024 ≈ 0.29980   [частка напруги для режиму 2]
u₃ = (1425 - 988) / 1024 = 437 / 1024 ≈ 0.42676   [частка напруги для режиму 3]
u₄ = (1555 - 988) / 1024 = 567 / 1024 ≈ 0.55371   [частка напруги для режиму 4]
u₅ = (1685 - 988) / 1024 = 697 / 1024 ≈ 0.68066   [частка напруги для режиму 5]
u₆ = (1815 - 988) / 1024 = 827 / 1024 ≈ 0.80762   [частка напруги для режиму 6]
```

Оскільки різниця між усіма сусідніми частками `Δu = u_{k+1} - u_k ≈ 0.12695` є постійною величиною, чотири внутрішні резистори дільника `R₂`, `R₃`, `R₄`, `R₅` повинні мати однаковий номінал `R_mid`.

Нехай `R_mid = 1.00 кОм`. Тоді:

```
Δu = R_mid / R_total
R_total = R_mid / Δu = 1.00 кОм / 0.12695 ≈ 7.877 кОм
```

Звідси знаходимо крайні резистори дільника:
- Нижній резистор `R_bottom` (від землі до позиції 1):
```
R_bottom = u₁ · R_total = 0.17285 · 7.877 кОм = 1.362 кОм
```
- Верхній резистор `R_top` (від позиції 6 до `V_cc`):
```
R_top
= R_total · (1 - u₆)                         [залишок опору до шини V_cc]
= 7.877 кОм · (1 - 0.80762)
= 7.877 · 0.19238 ≈ 1.515 кОм
```

Для практичної реалізації зі стандартного ряду прецизійних резисторів E96 (точність 1%) обираємо:
- `R₁ (R_top) = 1.50 кОм`
- `R₂ = 1.00 кОм`
- `R₃ = 1.00 кОм`
- `R₄ = 1.00 кОм`
- `R₅ = 1.00 кОм`
- `R₆ (R_bottom) = 1.37 кОм`

Фактичний сумарний опір ланцюга:

```
R_total_fact
= 1.50 + 1.00 + 1.00 + 1.00 + 1.00 + 1.37   [сума номіналів E96]
= 6.87 кОм
```

Розрахуємо струм споживання дільника від шини 3.3 В:

```
I_div = 3.3 В / 6.87 кОм = 0.48 мА
```

Струм споживання менше ніж `0.5 мА`, що забезпечує мінімальне навантаження на акумулятор передавача та виключає локальний саморозігрів резисторів.

## 4. Вплив вхідного імпедансу АЦП та динаміки вибірки-зберігання

Кожен аналоговий вхід мікроконтролера STM32 / ESP32 оснащений схемою вибірки та зберігання (англ. *Sample and Hold*, S/H). Вона складається з вхідного аналогового ключа з внутрішнім опором `R_switch ≈ 1...3 кОм` та конденсатора вибірки ємністю `C_sample ≈ 5...12 пФ`.

Еквівалентний вихідний опір дільника напруги за теоремою Тевеніна для найгіршого випадку (центральна позиція 3):

```
R_thevenin_max
= (R_lower · R_upper) / R_total              [еквівалентний паралельний опір вузла]
= (3.37 кОм · 3.50 кОм) / 6.87 кОм
= 11.795 / 6.87 ≈ 1.717 кОм
```

Повний опір зарядного контуру конденсатора вибірки:

```
R_charge = R_thevenin_max + R_switch = 1.717 кОм + 2.0 кОм = 3.717 кОм
```

Постійна часу заряду кола вибірки `τ_sample`:

```
τ_sample = R_charge · C_sample = 3.717 кОм · 10 пФ = 37.17 нс
```

Щоб похибка заряду ємності для 12-бітного АЦП не перевищувала половини молодшого значущого розряду (`1/2 LSB` = `1 / 8192` від повної шкали), мінімальний час перетворення вибірки `t_sample` повинен задовольняти умову:

```
e^(-t_sample / τ_sample) ≤ 1 / 8192
t_sample ≥ ln(8192) · τ_sample = 9.01 · 37.17 нс ≈ 335 нс
```

При тактовій частоті АЦП `f_adc = 14 МГц` один такт становить `71.4 нс`. Час вибірки в `15 тактів АЦП` (`1071 нс`) повністю перевищує мінімальний поріг `335 нс` утричі, що гарантує відсутність динамічної похибки вимірювання від внутрішнього опору дільника.

## 5. Аналіз чутливості та розрахунок найгіршого випадку похибки (Worst-Case Analysis)

Оцінимо максимальне відхилення вихідної напруги `ΔU_max` при використанні резисторів із виробничим допуском `δ_R = ±1%` (`0.01`).

Функція вихідної напруги для `k`-го вузла:

```
U_k(R₁, R₂, ..., R₆) = V_cc · (R_lower_k / R_total)
```

Логарифмічне диференціювання дає вираз для відносної похибки коефіцієнта поділу:

```
d(ln U_k) = (d R_lower_k / R_lower_k) - (d R_total / R_total)
```

У найгіршому випадку (англ. *worst-case scenario*), коли всі нижні резистори ланцюга відхилилися на `+δ_R`, а верхні на `-δ_R`, абсолютна зміна частки напруги `Δu_max` обмежується виразом:

```
Δu_max ≈ 2 · δ_R · u_k · (1 - u_k)
```

Максимум функції `u_k · (1 - u_k)` досягається посередині шкали при `u_k = 0.5`:

```
max(u_k · (1 - u_k)) = 0.5 · 0.5 = 0.25
```

Звідси максимальне відхилення частки напруги для резисторів 1%:

```
Δu_max = 2 · 0.01 · 0.25 = 0.0050   (0.50% від повної шкали)
```

Переведемо це відхилення в еквівалентну похибку тривалості імпульсу `ΔT_res`:

```
ΔT_res
= Δu_max · ΔT_full                           [масштабування похибки в мікросекунди]
= 0.0050 · 1024 мкс
= ±5.12 мкс
```

## 6. Вплив температури та квантування АЦП

Врахуємо додаткові джерела невизначеності під час реальної експлуатації:
1. **Температурний дрейф резисторів (TCR):** металоплівкові резистори мають температурний коефіцієнт опору `TCR = ±50 ppm/°C` (`±0.005%/°C`). При перепаді температури на `ΔT_temp = 50 °C` (від кімнатної `+20 °C` до польової `-30 °C` або `+70 °C`) розбіжність коефіцієнтів між різними резисторами становить не більше `100 ppm/°C`:
```
Δu_temp = 100 · 10⁻⁶ · 50 °C · 0.25 = 0.00125  (0.125%)
ΔT_temp = 0.00125 · 1024 мкс = ±1.28 мкс
```
2. **Шум та нелінійність АЦП (INL + DNL + Noise):** для 12-бітного АЦП інтегральна нелінійність та шум становлять не більше `±4 LSB`:
```
ΔT_adc = (4 / 4095) · 1024 мкс = ±1.00 мкс
```

Сумарна похибка найгіршого випадку `ΔT_total_worst`:

```
ΔT_total_worst
= ΔT_res + ΔT_temp + ΔT_adc                 [лінійна сума всіх джерел нестабільності]
= 5.12 + 1.28 + 1.00
= ±7.40 мкс
```

## 7. Висновок щодо коефіцієнта запасу надійності

Порівняємо сумарне відхилення з допустимою напівшириною вікна польотного контролера `ΔT_margin`:

```
Коефіцієнт запасу K_safety
= ΔT_margin / ΔT_total_worst                [відношення захисного інтервалу до похибки]
= 65.0 мкс / 7.40 мкс
= 8.78
```

Коефіцієнт запасу `K_safety ≈ 8.8` доводить, що застосування резистивного дільника з металоплівковими резисторами 1% забезпечує майже дев'ятикратний запас надійності. Навіть при екстремальних температурних коливаннях та радіочастотних наведеннях вихідний імпульс кожної позиції перемикача гарантовано потрапляє в центр відповідного вікна декодування польотного контролера, виключаючи самовільне перемикання режимів.
