# 🧮 Алгебраїчна та нелінійна підгонка еліпсоїда: розклад квадратичної форми та Levenberg-Marquardt

<preknowlist>

- [Матриці як дії](root:math-algebra/matrices-as-operations) — лінійні оператори, поворот базису, масштабування осей і квадратичні форми.
- [Матриці повороту](root:math-algebra/rotation-matrices) — ортогональні перетворення базису та діагоналізація головних осей еліпсоїда.
- [Метод Гаусса](root:math-algebra/gauss-elimination) — розв'язання систем лінійних алгебраїчних рівнянь при обчисленні кроку оптимізації.
</preknowlist>

Коли тривісний магнітометр закріплений усередині конструкції безпілотного апарата, просторовий годограф його вимірів під час довільних обертань описує тривимірний деформований еліпсоїд. Фізична мета калібрування полягає у знаходженні такого афінного перетворення, яке переводить цей викривлений еліпсоїд у канонічну сферу відомого радіуса `B_earth` із центром у початку координат `(0, 0, 0)`.

Розгляньмо строгий математичний апарат двох взаємодоповнювальних підходів: прямого алгебраїчного методу підгонки квадратичної поверхні за схемою Ферше — Лі (Ferschee / Li-Shen) та ітераційного нелінійного спуску Левенберга — Марквардта (Levenberg-Marquardt).

## 1. Пряма модель спотворення та зворотне калібрувальне перетворення

Позначимо істинний вектор індукції геомагнітного поля Землі в системі координат давача як `B_earth`. Модуль цього вектора є фізичною константою для конкретної точки простору:

```
‖B_earth‖ = √( (B_earth_x)² + (B_earth_y)² + (B_earth_z)² ) = B_0
```

У результаті накладання постійного намагнічування феромагнітних деталей рами (Hard Iron) утворюється вектор статичного зміщення `V_0 = [V_0x, V_0y, V_0z]ᵀ`. Водночас елементи конструкції з високою магнітною проникністю концентрують і спотворюють лінії поля (Soft Iron), що описується несингулярною матрицею перекосу й масштабу `A_soft` розміром 3×3.

Пряма модель формування сирого сигналу `B_raw` на виході АЦП магнітометра має вигляд:

```
B_raw = A_soft · B_earth + V_0 + η
```

де `η` — вектор власного випадкового шуму чутливого елемента й тракту оцифрування.

Задача калібрування полягає у знаходженні зворотного оператора — вектора зсуву `V_0` та матриці корекції `W`:

```
B_cal = W · ( B_raw − V_0 )
```

де матриця `W` є оберненою до матриці м'якого заліза `W = (A_soft)⁻¹` і нормована так, щоб зберігати істинну амплітуду поля `B_0`.

Виправлений вектор вимірів `B_cal` зобов'язаний задовольняти рівняння сфери радіуса `B_0`:

```
‖ B_cal ‖² = (B_cal)ᵀ · B_cal = B_0²
```

Підставимо вираз для `B_cal` в умову сферичності:

```
( W · ( B_raw − V_0 ) )ᵀ · ( W · ( B_raw − V_0 ) ) = B_0²
( B_raw − V_0 )ᵀ · ( Wᵀ · W ) · ( B_raw − V_0 ) = B_0²
```

Позначимо симетричну додатно визначену матрицю `M = Wᵀ · W / B_0²`. Тоді рівняння спотвореного еліпсоїда в центрованій формі записується як:

```
( B_raw − V_0 )ᵀ · M · ( B_raw − V_0 ) = 1
```

Будь-яка точка `B_raw = [x, y, z]ᵀ`, що лежить на поверхні цього еліпсоїда, перетворюється матрицею `W` на точку сфери радіуса `B_0`.

## 2. Загальна алгебраїчна форма еліпсоїда

Розкриємо матричний добуток центрованої форми еліпсоїда. Матриця `M` є симетричною і містить 6 незалежних елементів:

```
M = ⎡ M_11  M_12  M_13 ⎤
    ⎢ M_12  M_22  M_23 ⎥
    ⎣ M_13  M_23  M_33 ⎦
```

Розкриваючи дужки у виразі `(B_raw − V_0)ᵀ · M · (B_raw − V_0) = 1`, отримуємо повне поліноміальне рівняння квадрики другого порядку відносно просторових координат `x, y, z`:

```
a·x² + b·y² + c·z² + 2·d·x·y + 2·e·x·z + 2·f·y·z + 2·g·x + 2·h·y + 2·p·z + k = 0
```

Порівняння коефіцієнтів дає точну алгебраїчну відповідність між параметрами квадратичної форми та матрицею `M` і вектором `V_0`:

```
M_11 = a
M_22 = b
M_33 = c
M_12 = d
M_13 = e
M_23 = f
```

Лінійні коефіцієнти `g, h, p` визначаються добутком матриці `M` на вектор зміщення центру `V_0`:

```
⎡ g ⎤       ⎡ V_0x ⎤
⎢ h ⎥ = − M ⎢ V_0y ⎥
⎣ p ⎦       ⎣ V_0z ⎦
```

Звідси координати центра еліпсоїда (вектор твердого заліза `V_0`) знаходять безпосереднім розв'язанням лінійної системи 3×3:

```
V_0 = − M⁻¹ · ⎡ g ⎤
              ⎢ h ⎥
              ⎣ p ⎦
```

Вільний член `k` пов'язує нормувальний множник із квадратичною формою зміщення:

```
k = V_0ᵀ · M · V_0 − 1
```

Отже, якщо за експериментальними даними оцінити вектор параметрів квадратики `p = [a, b, c, d, e, f, g, h, p_z, k]ᵀ`, геометричні параметри `V_0` та `W` відновлюються точно аналітичним шляхом.

## 3. Лінеаризована алгебраїчна підгонка (метод найменших квадратів)

Нехай у процесі просторового обертання апарата знято масив із `N` вимірів магнітометра `(x_i, y_i, z_i)`, де `i = 1, 2, ..., N` (`N ≫ 9`).

Оскільки рівняння квадратики однорідне (множення всіх коефіцієнтів на довільне ненульове число не змінює геометричної поверхні), зафіксуємо масштаб, поклавши, наприклад, `k = −1` (або використавши умову нормування `‖p‖ = 1`).

Поклавши `k = −1`, перенесемо вільний член у праву частину й побудуємо систему лінійних рівнянь для 9 невідомих параметрів `v = [a, b, c, d, e, f, g, h, p_z]ᵀ`:

```
x_i²·a + y_i²·b + z_i²·c + 2·x_i·y_i·d + 2·x_i·z_i·e + 2·y_i·z_i·f + 2·x_i·g + 2·y_i·h + 2·z_i·p_z = 1
```

Сформуємо матрицю плану експерименту (матрицю Вандермонда для другого порядку) `D` розмірністю `N × 9`:

```
D = ⎡ x_1²   y_1²   z_1²   2·x_1·y_1   2·x_1·z_1   2·y_1·z_1   2·x_1   2·y_1   2·z_1 ⎤
    ⎢ x_2²   y_2²   z_2²   2·x_2·y_2   2·x_2·z_2   2·y_2·z_2   2·x_2   2·y_2   2·z_2 ⎥
    ⎢  ⋮      ⋮      ⋮         ⋮           ⋮           ⋮        ⋮       ⋮       ⋮    ⎥
    ⎣ x_N²   y_N²   z_N²   2·x_N·y_N   2·x_N·z_N   2·y_N·z_N   2·x_N   2·y_N   2·z_N ⎦
```

Та вектор правої частини `Y = [1, 1, ..., 1]ᵀ` розмірністю `N × 1`.

Задача зводиться до класичного методу найменших квадратів:

```
D · v = Y
Dᵀ · D · v = Dᵀ · Y      [множення зліва на Dᵀ для утворення нормальних рівнянь]
v = (Dᵀ · D)⁻¹ · Dᵀ · Y   [розв'язання нормальної системи 9×9]
```

Матриця `Dᵀ · D` має компактний розмір 9×9 і формується за один прохід по накопиченому масиву вимірів без необхідності зберігати повну матрицю `D` у пам'яті мікроконтролера:

```
(Dᵀ · D)_jk = ∑_{i=1}^N D_ij · D_ik
(Dᵀ · Y)_j  = ∑_{i=1}^N D_ij
```

## 4. Вилучення матриці Soft Iron та розклад Холецького

Отримавши розв'язок `v`, формуємо симетричну матрицю форми `M_raw` розміром 3×3 та лінійний вектор `G = [g, h, p_z]ᵀ`.

Обчислюємо вектор зміщення центру `V_0`:

```
V_0 = − (M_raw)⁻¹ · G
```

Обчислюємо константу переносу початку координат `c_scale`:

```
c_scale = V_0ᵀ · M_raw · V_0 − k
```

Нормуємо матрицю форми, щоб отримати істинну метричну матрицю еліпсоїда:

```
M_norm = M_raw / c_scale
```

Матриця `M_norm` є дійсною, симетричною та строго додатно визначеною (якщо набір вимірів утворює замкнений еліпсоїд, а не гіперболоїд). Нам необхідно знайти калібрувальну матрицю `W` таку, що:

```
Wᵀ · W = B_0² · M_norm
```

Існує два еквівалентні способи обчислення матриці `W`:

### Спосіб А: Спектральний розклад (Eigenvalue Decomposition)

Оскільки `M_norm` симетрична, її можна діагоналізувати за допомогою ортогональної матриці власних векторів `R`:

```
M_norm = R · Λ · Rᵀ
```

де `Λ = diag(λ_1, λ_2, λ_3)` — діагональна матриця дійсних додатних власних значень, а `R` — матриця поворотів головних осей еліпсоїда.

Тоді матриця корекції `W` обчислюється як:

```
W = B_0 · R · ⎡ √λ_1    0      0   ⎤ · Rᵀ
              ⎢   0    √λ_2    0   ⎥
              ⎣   0      0    √λ_3 ⎦
```

Така матриця `W` є симетричною, не вносить додаткового небажаного повороту навколо осі курсу (чиста деформація та масштабування) і точно трансформує еліпсоїд у сферу радіуса `B_0`.

### Спосіб Б: Факторизація Холецького (Cholesky Decomposition)

Якщо шукати матрицю `W` у класі верхньотрикутних матриць, застосовують розклад Холецького матриці `A = B_0² · M_norm`:

```
A = Uᵀ · U
W = U
```

де `U` — верхньотрикутна матриця. Цей метод обчислювально дешевший, оскільки не вимагає пошуку коренів характеристичного полінома третього степеня для знаходження власних чисел.

## 5. Нелінійна геометрична оптимізація: алгоритм Левенберга — Марквардта

Алгебраїчний метод має один суттєвий недолік: він мінімізує алгебраїчну нев'язку полінома `(D·v − 1)²`, а не геометричну відстань від точок до поверхні сфери. Через це за наявності шумів чи неповної сферичної хмари оцінка зміщується у бік звуження форми.

Для усунення цього зміщення результат алгебраїчного розв'язку використовують як початкове наближення для ітераційного методу Левенберга — Марквардта.

### Цільова функція геометричної нев'язки

Нехай параметрами оптимізації є 9 компонентів: 3 координати зсуву `V_0 = [x_0, y_0, z_0]ᵀ` та 6 незалежних елементів симетричної матриці `W`:

```
p = [ x_0, y_0, z_0, W_11, W_12, W_13, W_22, W_23, W_33 ]ᵀ
```

Для кожного виміру `B_raw_i` обчислюємо калібрований вектор:

```
B_cal_i(p) = W(p) · ( B_raw_i − V_0(p) )
```

Скалярна геометрична нев'язка точки `i` визначається як різниця між радіусом відкаліброваного вектора та еталонною індукцією поля `B_0`:

```
r_i(p) = ‖ B_cal_i(p) ‖ − B_0
```

Мінімізується зважена сума квадратів нев'язок:

```
S(p) = 1/2 · ∑_{i=1}^N ( r_i(p) )² = 1/2 · ‖ r(p) ‖²
```

### Обчислення Якобіана

Рядок матриці Якобі `J_i` розмірністю 1×9 для `i`-го виміру містить частинні похідні нев'язки `r_i` за всіма параметрами:

```
J_i = ∂r_i / ∂p = (1 / ‖B_cal_i‖) · (B_cal_i)ᵀ · ( ∂B_cal_i / ∂p )
```

Позначимо одиничний вектор напрямку `u_i = B_cal_i / ‖B_cal_i‖ = [u_x, u_y, u_z]ᵀ` та вектор відхилення `d_i = B_raw_i − V_0 = [d_x, d_y, d_z]ᵀ`.

Частинні похідні за координатами центру `V_0`:

```
∂r_i / ∂V_0 = − u_iᵀ · W
```

Частинні похідні за елементами симетричної матриці `W`:

```
∂r_i / ∂W_11 = u_x · d_x
∂r_i / ∂W_22 = u_y · d_y
∂r_i / ∂W_33 = u_z · d_z
∂r_i / ∂W_12 = u_x · d_y + u_y · d_x
∂r_i / ∂W_13 = u_x · d_z + u_z · d_x
∂r_i / ∂W_23 = u_y · d_z + u_z · d_y
```

### Ітераційний крок Левенберга — Марквардта

На кожній ітерації `k` обчислюється вектор нев'язок `r(p_k)` та повна матриця Якобі `J(p_k)` розміром `N × 9`.

Крок оновлення параметрів `Δp` знаходиться розв'язанням регуляризованої системи лінійних рівнянь:

```
( Jᵀ · J + λ · diag(Jᵀ · J) ) · Δp = − Jᵀ · r
```

де:
- `Jᵀ · J` — наближена матриця Гессе (акумулюється як сума зовнішніх добутків `∑ J_iᵀ · J_i`);
- `Jᵀ · r` — вектор градієнта цільової функції `∑ J_iᵀ · r_i`;
- `λ` — адаптивний параметр демпфування Левенберга.

### Адаптація параметра демпфування (стратегія Марквардта)

1. Обчислюємо пробний вектор параметрів `p_trial = p_k + Δp`.
2. Обчислюємо нове значення суми квадратів нев'язок `S(p_trial)`.
3. Якщо `S(p_trial) < S(p_k)`:
   - Крок успішний: приймаємо `p_{k+1} = p_trial`.
   - Зменшуємо параметр регуляризації: `λ = max(λ / 5, 10⁻⁷)` (наближення до швидкого методу Гаусса — Ньютона).
4. Якщо `S(p_trial) ≥ S(p_k)`:
   - Крок невдалий: відхиляємо `p_trial`, залишаємо `p_{k+1} = p_k`.
   - Збільшуємо параметр регуляризації: `λ = min(λ · 10, 10⁷)` (перехід до надійного градієнтного спуску з малим кроком).

Критерієм збіжності є виконання умови відносної зміни норми параметрів `‖Δp‖ / ‖p‖ < 10⁻⁵` або досягнення граничної кількості ітерацій (зазвичай 10–20 кроків).

Комбінація алгебраїчного методу для ініціалізації та методу Левенберга — Марквардта для фінішного доведення гарантує знаходження глобального мінімуму геометричної похибки без ризику застрягання в хибних локальних екстремумах.
