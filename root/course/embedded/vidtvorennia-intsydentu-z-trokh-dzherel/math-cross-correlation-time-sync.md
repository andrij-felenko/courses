# 🧮 Взаємна кореляція та оцінка дрейфу годинників при злитті телеметрії

Коли бортовий польотний контролер, наземна станція керування та камера записують перебіг польоту, кожен із цих трьох пристроїв веде відлік за власним фізичним кварцовим генератором. Навіть якщо перед зльотом годинники були виставлені за сигналом GPS, різниця робочих температур, старіння резонаторів і похибки переривань створюють два незалежні спотворення: постійне фазове зміщення `β` (англ. *clock offset*) та неперервний темпоральний дрейф `α` (англ. *clock drift*). Без математичного вирівнювання шкал аналітик не здатний визначити, чи кутовий удар на відео з камери передував сплеску струму в логу регуляторів, чи був його наслідком.

Ця вставка містить строге математичне виведення алгоритму дискретної взаємної кореляції для пошуку оптимального часового зсуву, аналітичний розв'язок методу найменших квадратів для компенсації лінійного дрейфу генераторів та оцінку спектральної кореляції між акустичним шумом моторів на відеозаписі й телеметрією обертів DShot.

## 1. Дискретна взаємна кореляція асинхронних часових рядів

Нехай маємо два дискретні часові ряди однакової фізичної величини (наприклад, оцінка кута тангажа `Pitch`):
- `x[n]` — дискретизований бортовий сигнал із високою частотою опитування `f_b` (наприклад, 200 Гц, інтервал `Δt_b = 5` мс), де `n = 0, 1, ..., N - 1`;
- `y[m]` — телеметричний сигнал наземної станції з нижчою частотою `f_g` (наприклад, 10 Гц, інтервал `Δt_g = 100` мс), де `m = 0, 1, ..., M - 1`.

Перед кореляційним аналізом сигнал `y[m]` інтерполюється (лінійно або кубічними сплайнами) на сітку вимірювань бортового сигналу з кроком `Δt_b`. Позначимо отриманий ресемплований сигнал як `ỹ[n]`. Оскільки вихідний сигнал наземної станції має значно нижчу смугу пропускання через обмеження радіоканалу, перед інтерполяцією до нього застосовують цифровий фільтр низьких частот для усунення високочастотного аліасингу (англ. *anti-aliasing filter*).

Для усунення постійної складової (зміщення нульового рівня давача) обидва сигнали центрують і нормують за їхньою дисперсією:

```
μ_x = (1 / N) · ∑ x[n]          [математичне сподівання сигналу x]
μ_y = (1 / N) · ∑ ỹ[n]          [математичне сподівання інтерпольованого сигналу y]

σ_x = √ ( (1 / N) · ∑ (x[n] - μ_x)² )    [середньоквадратичне відхилення сигналу x]
σ_y = √ ( (1 / N) · ∑ (ỹ[n] - μ_y)² )    [середньоквадратичне відхилення сигналу y]
```

Нормована дискретна функція взаємної кореляції (англ. *Normalized Cross-Correlation, NCC*) для цілочисельного лагу `k` (де `-K ≤ k ≤ K`) визначається як:

```
R_xy[k] = (1 / (N · σ_x · σ_y)) · ∑ (x[n] - μ_x) · (ỹ[n + k] - μ_y)
```

де сумування ведеться за спільним інтервалом перекриття сигналів. Нормування на добуток середньоквадратичних відхилень `σ_x · σ_y` гарантує, що значення функції лежить у межах `[-1.0, 1.0]`, де `1.0` відповідає ідеальному синхронному збігу форми кривих.

Оптимальний фазовий зсув `k_opt` у відліках знаходиться з умови максимізації коефіцієнта кореляції:

```
k_opt = argmax_k ( R_xy[k] )    [пошук максимуму функції збігу]
```

Фізичне зміщення в секундах `τ_offset` обчислюється множенням знайденого оптимального індексу на період дискретизації високочастотної сітки:

```
τ_offset = k_opt · Δt_b
```

### Субдискретна параболічна інтерполяція піка

Оскільки реальний фізичний максимум кореляції майже ніколи не збігається точно з дискретними відліками часу й лежить між сусідніми значеннями індексів, для досягнення субмілісекундної точності застосовують параболічну інтерполяцію трьох точок довкола знайденого піка: `R_0 = R_xy[k_opt]`, `R_- = R_xy[k_opt - 1]`, `R_+ = R_xy[k_opt + 1]`.

Апроксимуючи вершину параболою `p(δ) = a · δ² + b · δ + c`, знаходимо дрібний зсув екстремуму `δ_opt ∈ [-0.5, 0.5]`:

```
dp/dδ = 2·a·δ + b = 0           [умова екстремуму параболи]
δ_opt = - b / (2·a)             [аналітична координата вершини]

b = (R_+ - R_-) / 2             [центральна скінченна різниця]
a = (R_+ - 2·R_0 + R_-) / 2     [друга скінченна різниця]

δ_opt = (R_- - R_+) / (2 · (R_+ - 2·R_0 + R_-))    [уточнений субпіксельний зсув]
```

Уточнений час початкового фазового зміщення дорівнює:

```
τ_fine = (k_opt + δ_opt) · Δt_b
```

Завдяки цьому субдискретному наближенню навіть за базового кроку дискретизації телеметрії 100 мс вдається оцінити зсув із роздільною здатністю до 1–2 мс, за умови що сигнал має виражені високочастотні компоненти (кутові ривки або динамічні маневри).

## 2. Метод найменших квадратів для оцінки лінійного дрейфу

Кварцові генератори мають відносну нестабільність номінальної резонансної частоти `Δf / f`, яка вимірюється в мільйонних частках (англ. *parts per million, ppm*). Типовий кристал мікроконтролера STM32 без термокомпенсації має дрейф від 10 до 50 ppm залежно від нагрівання плати польотного контролера внутрішніми стабілізаторами. Це призводить до накопичення розбіжності від 36 до 180 мілісекунд за кожну годину безперервного запису, що повністю спотворює хронологію швидких фізичних процесів під час аварії.

Модель зв'язку між часом наземної станції `t_gcs` та бортовим монотонним часом `t_boot` описується лінійним рівнянням першого порядку:

```
t_gcs(i) = α · t_boot(i) + β + ε(i)
```

де:
- `α = 1 + (Δf / f)` — безрозмірний коефіцієнт дрейфу масштабу часу;
- `β` — абсолютне початкове зміщення шкали (епоха старту GCS відносно скидання мікроконтролера);
- `ε(i)` — випадкова похибка вимірювання мітки часу через мережевий джитер радіопакета.

Маючи множину з `P` опорних точок синхронізації `(t_boot[i], t_gcs[i])` (наприклад, події армінгу, зміни польотних режимів, скидання цільових точок і моменту зіткнення), параметри `α` та `β` знаходять мінімізацією суми квадратів нев'язок:

```
S(α, β) = ∑ ( t_gcs[i] - (α · t_boot[i] + β) )²    [критерій методу найменших квадратів]
```

Беручи частинні похідні за невідомими параметрами та прирівнюючи їх до нуля:

```
∂S/∂α = -2 · ∑ t_boot[i] · ( t_gcs[i] - α · t_boot[i] - β ) = 0    [умова мінімуму за α]
∂S/∂β = -2 · ∑ ( t_gcs[i] - α · t_boot[i] - β ) = 0                [умова мінімуму за β]
```

Розкриваючи дужки, отримуємо нормальну систему двох лінійних алгебраїчних рівнянь:

```
α · ∑ t_boot[i]² + β · ∑ t_boot[i] = ∑ t_boot[i] · t_gcs[i]
α · ∑ t_boot[i]  + β · P            = ∑ t_gcs[i]
```

Позначимо середні значення координат опорних точок як `t̄_boot = (1/P) · ∑ t_boot[i]` та `t̄_gcs = (1/P) · ∑ t_gcs[i]`. Вираз для нахилу прямої `α` спрощується до класичного відношення коваріації до дисперсії:

```
α = ( ∑ (t_boot[i] - t̄_boot) · (t_gcs[i] - t̄_gcs) ) / ( ∑ (t_boot[i] - t̄_boot)² )
β = t̄_gcs - α · t̄_boot
```

Величина апаратного дрейфу генератора в одиницях ppm обчислюється як:

```
ppm_drift = (α - 1.0) · 10⁶
```

Якщо масив опорних точок містить грубі викиди (наприклад, пакет MAVLink, який застряг у буфері переповторів радіомодема на 800 мс), класичний метод найменших квадратів зазнає зміщення оцінки. У таких випадках застосовують робастну регресію з функцією втрат Хьюбера (англ. *Huber Loss*) або алгоритм RANSAC, який автоматично відсікає аномальні затримки передачі пакетів.

## 3. Спектральне узгодження відеоаудіо та обертів ESC

Якщо відеозапис з екшн-камери не містить екранної телеметрії (OSD) або зображення розмите через швидке обертання під час падіння, єдиним джерелом об'єктивної фізичної прив'язки стає аудіодоріжка зі звуком обертання пропелерів.

Електрична частота комутації безколекторного двигуна `f_elec` (яку фіксує бортовий лог через протокол DShot у повідомленнях `ESC.RPM`) пов'язана з акустичною частотою проходження лопатей (англ. *Blade Passing Frequency, BPF*) через кількість полюсів ротора `N_poles` і кількість лопатей гвинта `N_blades`:

```
RPM_mech = (2 / N_poles) · f_elec · 60    [механічна швидкість обертання у хв⁻¹]
f_acoustic = (RPM_mech / 60) · N_blades   [основна гармоніка звуку гвинта, Гц]
```

Підставляючи механічні оберти у вираз для акустичної частоти:

```
f_acoustic = (2 · N_blades / N_poles) · f_elec    [зв'язок акустичної та електричної частот]
```

Для типового безколекторного мотора типорозміру 2207 із 14 постійними магнітами ротора (`N_poles = 14`) та трилопатевого пропелера (`N_blades = 3`):

```
f_acoustic = (2 · 3 / 14) · f_elec      [підстановка параметрів мотора: N_poles=14, N_blades=3]
= (6 / 14) · f_elec                     [множення чисельника]
= (3 / 7) · f_elec                      [скорочення дробу на 2]
≈ 0.4286 · f_elec                       [десяткове наближення коефіцієнта]
```

### Алгоритм кореляції спектрограми зі струмом мотора

Для автоматичного вилучення частотного профілю з аудіопотоку та його зіставлення з бортовим логом застосовують наступний чотирикроковий конвеєр:

1. **Короткочасне перетворення Фур'є (STFT):**
   До аудіодоріжки з частотою дискретизації `f_audio = 48000` Гц застосовують віконне перетворення Фур'є з вікном Ганна довжиною `N_w = 2048` відліків і кроком зсуву вікна `H = 512` відліків (перекриття 75%):

   ```
   X[m, k] = ∑_{n=0}^{N_w-1} s[m·H + n] · w[n] · e^{-j · 2π · k · n / N_w}
   ```

   Часова роздільна здатність фреймів спектрограми становить `Δt_stft = H / f_audio = 512 / 48000 ≈ 10.67` мс, а частотна роздільна здатність бінів спектра — `Δf_bin = f_audio / N_w = 48000 / 2048 ≈ 23.44` Гц.

2. **Детектування домінантної гармоніки обертів:**
   Для кожного часового фрейму `m` знаходять бінг екстремуму спектральної густини потужності в очікуваному робочому діапазоні частот гвинтів (150–900 Гц):

   ```
   k_peak[m] = argmax_{k ∈ [k_min, k_max]} |X[m, k]|²
   f_peak[m] = k_peak[m] · (f_audio / N_w)
   ```

3. **Перерахунок у механічні оберти:**
   Отриманий часовий ряд акустичних частот `f_peak[m]` перераховують в оцінку механічної швидкості обертання двигунів:
   
   ```
   RPM_audio[m] = (f_peak[m] / N_blades) · 60
   ```

4. **Крос-кореляційне суміщення з бортовою телеметрією:**
   Розраховують нормовану взаємну кореляцію між вектором `RPM_audio` та бортовим каналом середніх обертів чотирьох моторів `ESC_RPM_mean(t_boot)`, зафіксованим у DataFlash/ULog. Пік кореляційної функції визначає абсолютний зсув між першим кадром відеофайлу MP4 та нульовою відміткою мікроконтролера з точністю до одного відеокадру (16.6 мс при 60 fps або 8.3 мс при 120 fps).
