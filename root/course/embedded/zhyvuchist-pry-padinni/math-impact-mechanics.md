# 🧮 Механіка удару: розрахунок енергії, гальмівного шляху та зрізних зусиль

Математичний апарат динаміки удару дозволяє точно розрахувати пікові сили, тривалість зіткнення, контактні напруження та величину перевантаження, щоб підібрати розміри захисних зон, товщину демпферів і переріз жертовних кріплень без зайвої маси.

## Кінетична енергія та інтеграл роботи деформації

Під час польоту апарат масою `m` зі швидкістю `v` володіє кінетичною енергією поступального руху `E_k` та кутовою енергією обертання `E_rot`:

```
E_k = (m · v²) / 2
E_rot = (I · ω²) / 2
```

При зіткненні з нерухомою перешкодою вся ця енергія повинна перейти в роботу зовнішніх і внутрішніх сил опору `W` на шляху гальмування `Δx`:

```
E_k = ∫ F(x) dx    [інтегрування сили опору від 0 до Δx]
```

Характер розподілу сили `F(x)` уздовж шляху деформації визначає пікове перевантаження, яке передається на внутрішні вузли.

---

## Порівняння моделей гальмування

### 1. Модель постійного опору (ідеальне пластичне зминання)

Якщо деформовний елемент (наприклад, спеціальна пориста зона або зминальний бампер) забезпечує постійну силу опору `F(x) = F_const` протягом усього переміщення `Δx`, робота деформації дорівнює:

```
E_k = F_const · Δx
F_const = (m · v²) / (2 · Δx)
```

При постійній силі гальмування прискорення апарата `a` є сталим:

```
a = F_const / m
= (v²) / (2 · Δx)      [підстановка виразу сили]
```

Безрозмірне перевантаження `G` (виражене в одиницях прискорення вільного падіння `g ≈ 9.81 м/с²`):

```
G = a / g
= (v²) / (2 · g · Δx)
```

Час гальмування `Δt` при сталій силі:

```
Δt = (2 · Δx) / v
```

**Приклад числового розрахунку:**
Дрон масою `m = 0.8 кг` стикається зі стіною на швидкості `v = 15 м/с` (54 км/год).
Кінетична енергія: `E_k = (0.8 · 15²) / 2 = 90 Дж`.

* Варіант А (жорсткий торець без демпфера, деформація карбону `Δx = 1.5 мм = 0.0015 м`):
```
F_avg = 90 / 0.0015 = 60 000 Н  (60 кН ≈ 6.1 тонни-сили)
G_avg = 15² / (2 · 9.81 · 0.0015) ≈ 7645 g
Δt = (2 · 0.0015) / 15 = 0.0002 с = 0.2 мс
```
При такому імпульсі руйнується кристалічна структура напівпровідників усередині корпусів мікросхем, тріскається кремній IMU та відриваються BGA-виводи.

* Варіант Б (TPU-бампер та зминальний наконечник променя з ходом `Δx = 30 мм = 0.03 м`):
```
F_avg = 90 / 0.03 = 3 000 Н  (3 кН ≈ 305 кгс)
G_avg = 15² / (2 · 9.81 · 0.03) ≈ 382 g
Δt = (2 · 0.03) / 15 = 0.004 с = 4.0 мс
```
Шлях гальмування збільшився у 20 разів — відповідно, пікова сила та перевантаження зменшилися рівно у 20 разів.

---

### 2. Лінійно-пружна модель (удар об пружну балку)

Коли опір конструкції підпорядковується закону Гука `F(x) = k · x` (де `k` — жорсткість консолі променя), енергія деформації становить:

```
E_k = (k · Δx_max²) / 2
```

Максимальна сила в точці максимального прогину `Δx_max`:

```
F_peak = k · Δx_max
= (2 · E_k) / Δx_max   [підстановка пружної енергії E_k = k · Δx_max² / 2]
= (m · v²) / Δx_max    [заміна повної енергії на кінетичну E_k = m · v² / 2]
```

Порівняння показує, що при однаковому загальному ході `Δx_max` пікова сила пружного удару рівно **вдвічі перевищує** силу ідеального пластичного зминання:

```
F_peak = 2 · F_const
G_peak = (v²) / (g · Δx_max)
```

Після досягнення максимального прогину пружна балка повертає накопичену енергію назад, викликаючи зворотний відскок і вторинні високочастотні коливання, що створюють додаткові знакозмінні напруження в пайці.

### 3. В'язкопружна гістерезисна модель (TPU еластомер)

Термополіуретан (TPU 95A) поєднує пружні та в'язкі властивості. На діаграмі напруження-деформація крива навантаження йде вище кривої розвантаження. Площа всередині петлі гістерезису `ΔW_hyst` перетворюється безпосередньо на внутрішнє тепло за рахунок міжмолекулярного тертя полімерних ланцюгів:

```
η_diss = ΔW_hyst / W_total   [коефіцієнт дисипації енергії]
```

Для TPU марки 95A коефіцієнт розсіювання `η_diss` становить `0.55–0.70`. Це означає, що від 55% до 70% поглинутої ударом енергії не повертається у вигляді пружного відскоку, а безповоротно розсіюється в матеріалі бампера, захищаючи раму від резонансного розгойдування:

```
E_returned = E_absorbed · (1 - η_diss)
```

## Контактні напруження Герца при локальному точковому ударі

Коли гострий край перешкоди (наприклад, кут бетонної плити радіусом `R_imp = 2 мм`) контактує з пласкою карбоновою декою товщиною `h = 2 мм`, локальний контактний тиск `p_0` розраховується за теорією Герца для контакту сферичного індентора з пружним півпростором.

Зведений модуль пружності `E_star`:

```
1 / E_star = ((1 - ν_1²) / E_1) + ((1 - ν_2²) / E_2)
```

Для пари сталь-карбон (`E_carbon ≈ 70 ГПа`, `ν_carbon ≈ 0.3`, `E_steel ≈ 210 ГПа`, `ν_steel ≈ 0.3`) зведений модуль складає `E_star ≈ 58 ГПа`.

Радіус плями контактного відбитка `a_contact`:

```
a_contact = ((3 · F_imp · R_imp) / (4 · E_star))^(1/3)
```

Максимальний тиск у центрі плями контакту `p_0`:

```
p_0 = (3 · F_imp) / (2 · π · a_contact²)
```

При навіть помірній силі удару `F_imp = 500 Н` радіус контактної плями складає всього `a_contact ≈ 0.23 мм`, а контактний тиск сягає:

```
p_0 ≈ (3 · 500) / (2 · π · (0.23 · 10⁻³)²)
≈ 4 500 МПа  (4.5 ГПа)
```

Оскільки границя міцності епоксидної матриці карбону на стиск становить лише `σ_comp ≈ 180–250 МПа`, безпосередній контакт призводить до миттєвого розколювання матриці та викришування волокон.

Встановлення шару TPU товщиною всього 2 мм (`E_TPU ≈ 0.08 ГПа = 80 МПа`) зменшує зведений модуль `E_star` у 700 разів, збільшує площу контакту у 80 разів і знижує піковий контактний тиск до безпечних `p_0 < 30 МПа`, що повністю усуває локальне розшарування вуглепластику.

## Розрахунок зрізного гвинта променя (механічний запобіжник)

Розглянемо схему кріплення променя на двох точках:
1. Сталевий осьовий болт біля основи (шарнір обертання).
2. Жертовний нейлоновий гвинт на відстані `d_bolt` від осі шарніра.

При ударі перешкоди по зовнішньому кінцю променя (на плечі `L_arm` від осі шарніра) виникає згинальний момент `M_imp`:

```
M_imp = F_imp · L_arm
```

Цей момент врівноважується парою сил, де зрізне зусилля `F_shear`, що діє на жертвенний гвинт, дорівнює:

```
F_shear · d_bolt = F_imp · L_arm
F_shear = F_imp · (L_arm / d_bolt)
```

### Умова зрізу болта

Напруження зрізу `τ` у перерізі болта діаметром `d`:

```
τ = F_shear / A_core
= F_shear / ((π · d_core²) / 4)  [розкриття площі круга A_core]
= (4 · F_shear) / (π · d_core²)  [перенесення знаменника дробу в чисельник]
```

Для стандартного різьблення M3 діаметр внутрішнього тіла (core diameter) з урахуванням западини різьби становить `d_core ≈ 2.45 мм`. Площа робочого перерізу:

```
A_core = (π · 2.45²) / 4 ≈ 4.71 мм² = 4.71 · 10⁻⁶ м²
```

Граничне напруження зрізу для поліаміду PA66 (нейлон): `τ_ult ≈ 65 МПа = 65 · 10⁶ Па`.

Граничне зусилля зрізу на один зрізний шар гвинта:

```
F_shear_crit = τ_ult · A_core
= 65 · 10⁶ · 4.71 · 10⁻⁶  [підстановка граничного напруження та площі]
≈ 306 Н                   [обчислення критичного зусилля (≈ 31.2 кгс)]
```

Якщо гвинт працює на подвійний зріз (затиснутий між верхньою і нижньою деками), критичне зусилля подвоюється: `F_shear_crit_double ≈ 612 Н`.

### Критична сила удару на кінці променя

При співвідношенні плечей `L_arm = 140 мм`, `d_bolt = 28 мм` (важіль `k_lever = 140 / 28 = 5`):

```
F_imp_crit = F_shear_crit / k_lever
= 306 / 5               [підстановка критичного зусилля та коефіцієнта важеля]
= 61.2 Н                [обчислення граничної ударної сили (≈ 6.2 кгс)]
```

Якщо сила удару об перешкоду перевищує `61.2 Н`, нейлоновий гвинт миттєво зрізається. Промінь повертається навколо сталевого шарніра, переводячи енергію удару в обертання і зсув, а карбонова пластина деки товщиною 2.0 мм зазнає напруження значно нижче своєї межі плинності `σ_carbon > 600 МПа`, залишаючись повністю цілою.

## Розрахунок зриву різьби в алюмінієвих стійках

Коли вертикальна стійка рами піддається розтягу або згину, сталевий гвинт M3 з кроком `P = 0.5 мм` передає навантаження на внутрішню різьбу алюмінієвої стійки.

Площа зрізу внутрішньої різьби `A_thread` на глибині загвинчування `L_eng`:

```
A_thread = π · d_nom · (5/8) · L_eng
```

Для різьби M3 (`d_nom = 3.0 мм`):

```
A_thread ≈ 5.89 · L_eng   [площа зрізу в мм² на кожен міліметр глибини]
```

Для алюмінію 6061-T6 границя міцності на зріз становить `τ_al_6061 ≈ 150 МПа`, тоді як для сплаву 7075-T6 — `τ_al_7075 ≈ 300 МПа`.

Критична сила зриву різьби при глибині вкручування `L_eng = 4 мм`:

```
F_strip_6061 = 150 · 10⁶ · (5.89 · 4 · 10⁻⁶) ≈ 3534 Н  (353 кгс)
F_strip_7075 = 300 · 10⁶ · (5.89 · 4 · 10⁻⁶) ≈ 7068 Н  (707 кгс)
```

При ударах з діагональним вириванням стійки сплав 7075-T6 витримує вдвічі більше навантаження, запобігаючи миттєвому зриву різьби та розпаду захисного каркаса рами.

## Розрахунок натягу ременя батареї при кутовому гальмуванні

При кутовому падінні (удар одним променем з подальшим обертанням дрона, так званий "cartwheel crash") кутове сповільнення `ε = dω/dt` створює на масі акумулятора `m_bat` дотичну силу інерції:

```
F_tan = m_bat · ε · r_bat
```

Крім того, відцентрова сила намагається відірвати батарею від деки:

```
F_norm = m_bat · ω² · r_bat
```

Сумарна зсувна сила `F_slip`, яка намагається зрушити батарею з деки:

```
F_slip = √(F_tan² + (m_bat · a_lin)²)
```

Сила тертя спокою `F_fric`, що утримує батарею завдяки попередньому натягу ременів `T_strap`:

```
F_fric = μ · (2 · T_strap + F_norm_clamp)
```

* Без силіконової прокладки (гладкий карбон по термоусадці LiPo): `μ ≈ 0.20`.
Щоб утримати батарею масою `0.45 кг` при поздовжньому перевантаженні `30 g` (`F_slip = 0.45 · 30 · 9.81 = 132.4 Н`):
```
T_strap_req = F_slip / (2 · μ)
= 132.4 / (2 · 0.20)    [підстановка сили зсуву та коефіцієнта тертя]
= 331 Н                 [обчислення необхідного натягу (≈ 33.7 кгс)]
```
Такий натяг деформує пакети LiPo та часто призводить до розриву одинарного ременя.

* З силіконовою протиковзкою накладкою (`μ ≈ 0.85`):
```
T_strap_req = 132.4 / (2 · 0.85)  [підстановка зсувної сили та коефіцієнта тертя]
= 77.9 Н                          [обчислення необхідного натягу (≈ 7.9 кгс)]
```
Коефіцієнт тертя знижує необхідну силу попереднього затягування ременя більш ніж у 4 рази, гарантуючи надійне утримання акумулятора без ризику роздавити м'які елементи живлення.
