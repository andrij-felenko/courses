# 🧮 Розрахунок ємності буферного конденсатора при аварійному знеструмленні

Коли зовнішнє живлення вбудованого пристрою раптово обривається, мікроконтролер має лічені мілісекунди на те, щоб коректно завершити активну операцію запису сторінки у Flash-пам'ять і зафіксувати транзакційні маркери цілісності. Цей критичний інтервал часу забезпечується виключно залишком електричного заряду, накопиченим у буферному конденсаторі шини живлення.

Цей розрахунок виводить строгу математичну залежність між часом фіксації транзакції, динамічним профілем струму споживання плати, порогами компараторів PVD/BOR та необхідною номінальною ємністю накопичувача з урахуванням ефекту деградації діелектрика керамічних конденсаторів під постійним зміщенням.

## 1. Енергетичний баланс розряду конденсатора

Розгляньмо систему, у якій вбудований програмований детектор напруги (PVD) налаштований на поріг завчасного попередження `V[PVD]`, а апаратний блок скидання за низькою напругою (BOR) утримує процесорне ядро в працездатному стані до досягнення критичної межі `V[BOR]`.

Повна потенційна енергія електричного поля, запасена в конденсаторі ємністю `C` при початковій напрузі спрацьовування детектора `V[PVD]`:

```
E[start] = (1/2) · C · V[PVD]²
```

Залишкова енергія, яка залишається в конденсаторі в мить спрацьовування апаратного скидання BOR і вимкнення цифрової логіки:

```
E[end] = (1/2) · C · V[BOR]²
```

Корисна енергія `ΔE`, яку накопичувач здатний передати в навантаження під час падіння напруги в робочому коридорі від `V[PVD]` до `V[BOR]`:

```
ΔE = E[start] - E[end]
   = (1/2) · C · (V[PVD]² - V[BOR]²)
```

Якщо плата живиться через імпульсний понижувальний стабілізатор (Buck converter) із коефіцієнтом корисної дії `η`, стабілізатор підтримує постійну напругу на ядрі, працюючи як навантаження постійної потужності `P[load] = const`. Закон збереження енергії для інтервалу аварійного скидання кешу `t[hold]` набуває вигляду:

```
ΔE ≥ (P[load] · t[hold]) / η
(1/2) · C · (V[PVD]² - V[BOR]²) ≥ (P[load] · t[hold]) / η
```

Звідси виражаємо мінімально необхідну теоретичну ємність `C[min_buck]` для схеми з імпульсним перетворювачем:

```
C[min_buck] = (2 · P[load] · t[hold]) / (η · (V[PVD]² - V[BOR]²))
```

## 2. Модель постійного струму для лінійного живлення (LDO)

Якщо мікроконтролер та енергонезалежна Flash-пам'ять підключені безпосередньо до буферизованої шини 3.3 В або живляться через лінійний стабілізатор LDO в режимі насичення регулюючого транзистора (Drop-out state), струм споживання `I[total]` залишається практично незмінним під час спаду напруги.

Швидкість зміни заряду на обкладках конденсатора описується класичним диференціальним рівнянням:

```
I[total](t) = -C · (dV(t) / dt)
```

Вважаючи сумарний струм споживання константою `I[total] = const`, розділяємо змінні та інтегруємо за часом від моменту фіксації аварії `t = 0` (`V = V[PVD]`) до моменту апаратного скидання ядра `t = t[hold]` (`V = V[BOR]`):

```
∫[0..t_hold] dt = - (C / I[total]) · ∫[V_PVD..V_BOR] dV
t[hold]         = (C · (V[PVD] - V[BOR])) / I[total]
```

Виражаємо мінімальну теоретичну ємність для лінійної моделі розряду:

```
C[min_linear] = (I[total] · t[hold]) / (V[PVD] - V[BOR])
```

### Вплив еквівалентного послідовного опору (ESR)

Коли внутрішня помпа заряду Flash-пам'яті вмикається для програмування сторінки, виникає імпульсний сплеск струму `I[peak]`. Цей струм проходить крізь еквівалентний послідовний опір конденсатора `R[esr]`, викликаючи миттєвий ступінчастий спад напруги на виводах:

```
ΔV[esr] = I[peak] · R[esr]
```

Цей стрибок безпосередньо зменшує корисний динамічний діапазон між порогами PVD та BOR:

```
ΔV[effective] = (V[PVD] - V[BOR]) - (I[peak] · R[esr])
```

### Формула підсумкового інженерного запасу

З урахуванням усіх деградаційних множників необхідна номінальна ємність `C[nominal]` становить:

```
C[nominal] = C[min] / (k[dc] · k[tol] · k[temp] · k[age])
```

## 5. Повний числовий приклад проектування вузла

Розрахуймо параметри аварійного накопичувача для телеметричного реєстратора на базі мікроконтролера STM32G474 та зовнішньої пам'яті SPI NOR Flash Winbond W25Q128JV.

### Вхідні дані системи:
- Номінальна напруга живлення плати: `V[nom] = 3.30 В`
- Поріг спрацьовування детектора PVD (Level 5): `V[PVD] = 2.90 В`
- Поріг апаратного скидання BOR (Level 2): `V[BOR] = 2.50 В`
- Струм споживання ядра мікроконтролера на частоті 64 МГц: `I[mcu] = 24.0 мА`
- Струм програмування сторінки Flash за документацією: `I[flash_prog] = 16.0 мА`
- Допоміжний струм давачів та ліній підтяжки: `I[aux] = 4.0 мА`
- Піковий струм увімкнення помпи помножувача Flash: `I[peak] = 52.0 мА`
- Максимальний час запису 256-байтової сторінки (`Page Program time` t_PP max): `t[page_prog] = 1.6 мс`
- Час виконання переривання PVD (запис фінального заголовка та CRC32): `t[pvd_isr] = 0.3 мс`
- Необхідний загальний час утримання напруги: `t[hold] = 1.6 мс + 0.3 мс = 1.9 мс`

### Крок 1: Обчислення сумарного середнього струму споживання

```
I[total] = I[mcu] + I[flash_prog] + I[aux]
         = 24.0 мА + 16.0 мА + 4.0 мА
         = 44.0 мА = 0.044 А
```

### Крок 2: Оцінка втрат на ESR

Обираємо комбінований блок із керамічних конденсаторів із результуючим еквівалентним опором `R[esr] = 0.04 Ом`:

```
ΔV[esr] = I[peak] · R[esr]
        = 0.052 А · 0.04 Ом
        = 0.00208 В ≈ 0.002 В

ΔV[effective] = (2.90 В - 2.50 В) - 0.002 В
              = 0.398 В
```

### Крок 3: Розрахунок мінімальної ідеальної ємності

```
C[min] = (I[total] · t[hold]) / ΔV[effective]
       = (0.044 А · 0.0019 с) / 0.398 В
       = 0.0000836 / 0.398
       = 2.1005 · 10⁻⁴ Ф
       ≈ 210 мкФ
```

### Крок 4: Застосування коефіцієнтів реальної експлуатації

Для поверхневого монтажу обираємо керамічні конденсатори ємністю 100 мкФ типорозміру 1206 із діелектриком X7R та номінальною напругою 10 В. За графіком залежності ємності від напруги зміщення для напруги 3.3 В:
- `k[dc] = 0.58` (втрата 42% ємності під постійною напругою 3.3 В)
- `k[tol] = 0.80` (виробничий допуск ±20%)
- `k[temp] = 0.88` (робочий температурний діапазон від -20 до +70 °C)
- `k[age] = 0.95` (старіння кристаліту за три роки експлуатації)

Результуючий коефіцієнт ефективності:

```
K[effective] = k[dc] · k[tol] · k[temp] · k[age]
             = 0.58 · 0.80 · 0.88 · 0.95
             = 0.3879
```

Розрахунок номінальної ємності конденсаторного масиву:

```
C[nominal] = C[min] / K[effective]
           = 210 мкФ / 0.3879
           = 541.38 мкФ
```

### Крок 5: Формування остаточної схеми накопичувача

Для забезпечення надійного запасу на друковану плату встановлюється батарея з **шести паралельних керамічних конденсаторів по 100 мкФ / 10 В (X7R, 1206)** сумарним номіналом `600 мкФ`, або один танталовий полімерний конденсатор ємністю **470 мкФ / 6.3 В** у парі з двома керамічними конденсаторами по **47 мкФ** для придушення високочастотного шуму.

Така конфігурація гарантує розрахунковий час утримання шини `t[real_hold] ≥ 2.15 мс`, що повністю перекриває найгірший випадок тривалості циклу програмування Flash і забезпечує 100% збереження транзакційних метаданих при раптовому вимкненні живлення.
