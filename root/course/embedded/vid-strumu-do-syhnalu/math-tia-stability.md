# 🧮 Виведення стабільності трансімпедансного підсилювача та розрахунок фазового запасу

Трансімпедансний підсилювач (TIA) перетворює вхідний струм I_in на вихідну напругу V_out за допомогою резистора зворотного зв'язку R_f. Проте будь-який реальний давач струму (фотодіод, п'єзодатчик, іонізаційна камера) має власну ємність C_d, до якої додаються вхідна ємність операційного підсилювача та монтажу плати. Ця сумарна вхідна ємність C_in разом із резистором R_f утворює фазовий зсув у петлі зворотного зв'язку, що знижує запас за фазою аж до нуля і перетворює підсилювач на автогенератор. Ця вставка містить аналітичне виведення передавальної функції петльового підсилення, критерію стійкості за Боде та точної формули компенсуючого конденсатора C_f.

## 1. Еквівалентна схема та вхідний імпеданс

Розглянемо схему на операційному підсилювачі з неінвертувальним входом, з'єднаним із землею. До інвертувального входу під'єднано фотодіод, а між інвертувальним входом та виходом встановлено паралельну R_f·C_f-ланку.

Сумарна ємність, підключена до інвертувального входу підсилювача на землю:

```
C_in = C_d + C_diff + C_cm + C_pcb   [сума ємності діода, диференціальної та синфазної ємностей ОП і паразитної ємності доріжок]
```

Імпеданс вхідного кола Z_in (між інвертувальним входом і землею):

```
Z_in(s) = 1 / (s · C_in)              [ємнісний опір вхідного вузла]
```

Імпеданс ланки зворотного зв'язку Z_f (між виходом та інвертувальним входом):

```
Z_f(s) = R_f || (1 / (s · C_f))       [паралельне з'єднання резистора та ємності]
       = R_f / (1 + s · R_f · C_f)    [еквівалентний комплексний імпеданс ланки зворотного зв'язку]
```

## 2. Передавальна функція зворотного зв'язку та шумове підсилення

Коефіцієнт передачі ланки зворотного зв'язку β(s) визначає, яка частка вихідної напруги повертається на інвертувальний вхід:

```
β(s) = Z_in(s) / (Z_in(s) + Z_f(s))                           [дільник напруги між виходом і землею]
     = (1 / (s · C_in)) / ( (1 / (s · C_in)) + Z_f(s) )        [підстановка імпедансу входу]
     = 1 / (1 + s · C_in · Z_f(s))                             [спрощення дробу множенням на s·Cin]
     = 1 / ( 1 + s · C_in · (R_f / (1 + s · R_f · C_f)) )      [підстановка Zf]
     = (1 + s · R_f · C_f) / ( 1 + s · R_f · (C_in + C_f) )   [остаточний вираз для коефіцієнта зворотного зв'язку]
```

Шумове підсилення (Noise Gain), або зворотна величина 1/β(s), показує, як підсилювач підсилює власні внутрішні шуми та напругу зсуву V_os:

```
1 / β(s) = ( 1 + s · R_f · (C_in + C_f) ) / ( 1 + s · R_f · C_f )   [шумове підсилення петлі]
```

У частотній області (s = j·ω) шумове підсилення 1/β(j·ω) має один нуль f_z і один полюс f_p:

```
f_z = 1 / ( 2π · R_f · (C_in + C_f) )   [частота нуля, де шумове підсилення починає зростати з нахилом +20 дБ/дек]
f_p = 1 / ( 2π · R_f · C_f )            [частота полюса, де шумове підсилення вирівнюється на плато (Cin + Cf) / Cf]
```

## 3. Механізм нестійкості без компенсуючого конденсатора

Якщо компенсаційний конденсатор відсутній (C_f = 0), вираз для шумового підсилення спрощується:

```
1 / β(s) = 1 + s · R_f · C_in   [шумове підсилення зростає без обмеження на високих частотах]
```

Частота початку зростання:

```
f_z0 = 1 / ( 2π · R_f · C_in )   [нуль петлі за відсутності компенсації]
```

Частотна характеристика операційного підсилювача у розімкненому стані (Open-Loop Gain) A_ol(f) спадає з нахилом −20 дБ/декаду через внутрішню корекцію ОП (домінуючий полюс), починаючи від частоти зрізу до частоти одиничного підсилення GBW (Gain-Bandwidth Product):

```
A_ol(f) ≈ GBW / f   [підсилення у зоні спаду]
```

На частоті перетину f_x, де амплітуда власного підсилення ОП дорівнює шумовому підсиленню (|A_ol(f_x)| = |1/β(f_x)|):
- Крива A_ol(f) спадає зі швидкістю −20 дБ/декаду, створюючи фазовий зсув −90°;
- Крива 1/β(f) зростає зі швидкістю +20 дБ/декаду, що еквівалентно додатковому фазовому запізненню петльового коефіцієнта β(f) на −90°.

Швидкість зближення (Rate of Closure) характеристик на частоті перетину становить:

```
Швидкість зближення = 20 дБ/дек − (−20 дБ/дек) = 40 дБ/дек   [ознака нульового фазового запасу]
```

Сумарний фазовий набіг петлі T(j·ω) = A_ol(j·ω) · β(j·ω) у точці одиничного петльового підсилення досягає:

```
Фазовий зсув = −90° + (−90°) = −180°   [від'ємний зворотний зв'язок стає додатним]
Фазовий запас = 180° − 180° = 0°       [критерій Баркгаузена: підсилювач самозбуджується]
```

Навіть якщо автогенерація не переходить у постійний синусоїдальний сигнал через насичення, перехідний відгук на імпульс струму матиме сильний дзвін (ringing) та тривале встановлення.

## 4. Виведення формули компенсуючого конденсатора

Щоб забезпечити стійкість і комфортний запас за фазою (Φ_m = 45°...65°), необхідно за допомогою конденсатора C_f сформувати полюс f_p = 1 / (2π · R_f · C_f) точно на частоті перетину f_x. Тоді нахил 1/β(f) у точці перетину стає нульовим (плато), швидкість зближення падає до безпечних 20 дБ/декаду, а фазовий запас повертається до норми.

Знайдемо частоту перетину f_x. За визначенням, f_x є геометричним середнім між початковим нулем f_z та граничною частотою GBW:

```
f_x = √( GBW · f_z )                                     [частота одиничного петльового підсилення]
    = √( GBW / (2π · R_f · (C_in + C_f)) )               [підстановка виразу для f_z]
```

Оскільки зазвичай C_f ≪ C_in, можна записати наближення:

```
f_x ≈ √( GBW / (2π · R_f · C_in) )                       [визначення частоти перетину через параметри схеми]
```

Для досягнення запасу за фазою Φ_m = 45° частота полюса f_p повинна точно збігатися з частотою перетину f_x:

```
f_p = f_x                                                [умова оптимального зсуву фази 45°]
1 / ( 2π · R_f · C_f ) = √( GBW / (2π · R_f · C_in) )    [прирівнювання лівої і правої частин]
```

Піднесемо обидві частини рівняння до квадрата:

```
1 / ( 4π² · R_f² · C_f² ) = GBW / ( 2π · R_f · C_in )    [піднесення до квадрата]
C_f² = ( 2π · R_f · C_in ) / ( 4π² · R_f² · GBW )        [вираження квадрата невідомої ємності]
C_f² = C_in / ( 2π · R_f · GBW )                         [скорочення спільних множників 2π та Rf]
```

Добуваємо квадратний корінь і отримуємо формулу ємності зворотного зв'язку для запасу фази Φ_m = 45°:

```
C_f = √( C_in / (2π · R_f · GBW) )                       [формула компенсації для фазового запасу 45°]
```

Якщо потрібен відгук Баттерворта другого порядку з максимально пласкою АЧХ та нульовим викидом на перехідній характеристиці (фазовий запас Φ_m ≈ 65°), частоту полюса обирають трохи нижчою, що збільшує ємність у √2 разів:

```
C_f_butterworth = √( (2 · C_in) / (2π · R_f · GBW) )     [формула компенсації для відгуку Баттерворта 65°]
```

Результуюча смуга пропускання замкненого TIA за рівнем −3 дБ при оптимальній компенсації визначається співвідношенням:

```
f_(-3dB) = √( GBW / (2π · R_f · C_in) )                  [гранична смуга пропускання скомпенсованого TIA]
```

## 5. Практичний числовий розрахунок

Розрахуємо каскад прецизійного оптичного вимірювача:
- Фотодіод: власна ємність переходу C_d = 120 пФ;
- Операційний підсилювач: GBW = 20 МГц, вхідна диференціальна ємність C_diff = 3 пФ, синфазна ємність C_cm = 4 пФ;
- Монтаж друкованої плати: паразитна ємність вхідного вузла C_pcb = 3 пФ;
- Необхідний коефіцієнт перетворення струму в напругу: R_f = 500 кОм.

### Крок 1. Обчислення повної вхідної ємності

```
C_in = 120 + 3 + 4 + 3 = 130 пФ                          [сумарна ємність вузла віртуальної землі]
```

### Крок 2. Обчислення частоти нуля нескомпенсованої схеми

```
f_z = 1 / ( 2π · 500·10³ · 130·10⁻¹² )                   [підстановка номіналів Rf та Cin]
    = 1 / ( 2 · 3.14159 · 500000 · 0.000000000130 )      [підстановка чисел]
    ≈ 2448.5 Гц ≈ 2.45 кГц                               [частота, вище якої шум підсилювача зростає]
```

Без компенсації шум та фазовий зсув наростали б від 2.45 кГц аж до перетину з A_ol біля 220 кГц, викликаючи неминучу автогенерацію.

### Крок 3. Розрахунок компенсуючого конденсатора C_f

Для фазового запасу Φ_m = 45°:

```
C_f = √( 130·10⁻¹² / ( 2π · 500·10³ · 20·10⁶ ) )         [підстановка параметрів у формулу]
    = √( 130·10⁻¹² / ( 6.28318 · 10¹³ ) )                [обчислення знаменника]
    = √( 2.069·10⁻²⁴ )                                   [вираз під коренем]
    ≈ 1.439·10⁻¹² Ф = 1.44 пФ                            [розрахункова ємність для запасу 45°]
```

Для відгуку Баттерворта (Φ_m ≈ 65°, без перерегулювання):

```
C_f_butterworth = 1.44 пФ · √2 ≈ 2.03 пФ                 [практичний вибір: стандартний номінал NP0 2.0 або 2.2 пФ]
```

### Крок 4. Розрахунок підсумкової смуги пропускання

```
f_(-3dB) = √( 20·10⁶ / ( 2π · 500·10³ · 130·10⁻¹² ) )    [підстановка GBW, Rf та Cin]
         = √( 20·10⁶ · 2448.5 )                          [проміжне множення]
         = √( 4.897·10¹⁰ )                               [добуток під коренем]
         ≈ 221.3 кГц                                     [робоча смуга частот оптичного каналу]
```

Додавання мініатюрного конденсатора номіналом 2.0 пФ перетворює нестійкий каскад на стабільний підсилювач із смугою пропускання понад 220 кГц та бездоганною перехідною характеристикою.
