# Від струму до сигналу

<preknowlist>
- [Закон Ома](root:hw-analog/ohms-law) — зв'язок напруги, струму й опору: V = I · R.
- [Правила Кірхгофа](root:hw-analog/kcl) — закон збереження заряду у вузлі: сума струмів, що входять, дорівнює сумі струмів, що виходять.
- [Операційний підсилювач](root:hw-analog/opamp) — диференціальний підсилювач із високим підсиленням у схемі з від'ємним зворотним зв'язком.
- [Віртуальна земля](root:hw-analog/virtual-ground) — утримання потенціалу інвертувального входу на рівні неінвертувального зусиллями зворотного зв'язку.
- [Вимірювальний підсилювач](root:hw-analog/instrumentation-amp) — прецизійне підсилення малих диференціальних сигналів на тлі високої синфазної напруги.
</preknowlist>

Уявімо типовий промисловий об'єкт: на трубопроводі високого тиску за триста метрів від операторської змонтовано прецизійний давач тиску, що видає аналоговий сигнал напруги від 0 до 10 В. Між давачем та щитом керування прокладено мідний кабель перерізом 0.5 мм². Якщо виміряти напругу на клемах контролера, виявиться, що прилад показує не тиск у системі, а суміш випадкових похибок: показники плавають на 200–300 мВ залежно від навантаження в цеху, тремтять із частотою 50 Гц від сусіднього силового кабелю і змінюються щоразу, коли вмикається потужний насос. Звичайна передача потенціалом на довгій лінії виявляється безпорадною перед опором дротів, паразитними ємностями та різницею потенціалів між точками заземлення. Щоб сигнал дійшов до мікроконтролера неушкодженим, фізичний носій інформації змінюють: замість напруги інформацію кодують електричним струмом.

## Фізичний носій інформації: напруга проти струму

Напруга за своєю фізичною природою є різницею потенціалів між двома конкретними точками простору. Коли ми передаємо сигнал напругою, приймач вимірює різницю між сигнальним проводом та проводом опорного потенціалу (землею). На коротких відстанях у межах однієї друкованої плати це працює бездоганно. Та щойно лінія зв'язку подовжується на десятки чи сотні метрів, починають діяти три непереборні фізичні чинники:

1. **Падіння напруги на активному опорі лінії.** Мідний провід перерізом 0.5 мм² має опір близько 36 Ом на кілометр. Для лінії завдовжки 300 м прямий та зворотний проводи разом дають опір 21.6 Ом. Навіть мікроамперні струми витоку кабелю або вхідні струми приймача утворюють на цьому опорі паразитне спадання напруги, яке віднімається від корисного сигналу.
2. **Земляні петлі (Ground Loops).** Земля на давачі в цеху і земля контролера в шафі автоматики — це фізично різні точки заземлення, розташовані на відстані сотень метрів. Через нерівномірні струми витоку промислового обладнання та роботу частотно-регульованих приводів між цими землями завжди існує змінна різниця потенціалів ΔV_gnd, яка може сягати від сотень мілівольтів до десятків вольтів. Ця паразитна напруга додається безпосередньо до вимірюваного сигналу, спотворюючи покази.
3. **Чутливість до ємнісних наведень.** Вхід аналого-цифрового перетворювача (АЦП) або вимірювального підсилювача має величезний вхідний опір (від 1 МОм до 10 ГОм). Будь-яка паразитна ємність монтажу між сигнальним проводом і сусіднім силовим кабелем напругою 230/400 В утворює дільник напруги: навіть ємність у кілька пікофарад на частоті мережі індукує на високоомному вході вольти завади.

![Порівняння передачі сигналу напругою та струмовою петлею на довгій лінії](/root/course/embedded/vid-strumu-do-syhnalu/img/voltage-vs-current-line.svg)
*Ліворуч: передача напругою страждає від падіння на дротах, різниці потенціалів земель ΔV_gnd та ємнісних завад на високоомному вході АЦП. Праворуч: струмова петля спирається на перший закон Кірхгофа — струм однаковий по всій довжині замкненого контуру, а низький опір шунта миттєво зливає наведені завади.*

Якщо ж як носій сигналу обрати електричний струм, фізика процесу докорінно змінюється.

За першим законом Кірхгофа (KCL), для будь-якого нерозгалуженого замкненого електричного кола струм у кожному перерізі провідника є суворо однаковим. Якщо передавач виштовхує в лінію струм силою 12.00 мА, то рівно ті самі 12.00 мА пройдуть крізь сотні метрів кабелю і потраплять у приймач. Опір лінії R_line (чи то 5 Ом, чи 100 Ом) жодним чином не змінює силу струму: передавач працює як активне кероване джерело струму з гігантським вихідним динамічним опором (R_out → ∞), автоматично підвищуючи або знижуючи вихідну напругу, щоб підтримувати заданий струм.

Крім того, приймач струмового сигналу має дуже низький вхідний опір — це вимірювальний шунт номіналом 100–250 Ом. Струм наведеної ємнісної завади від силової мережі становить частки мікроампера; протікаючи крізь низькоомний шунт, він створює падіння напруги в мікровольти, що цілком губиться в молодших розрядах АЦП. А різниця потенціалів між віддаленими точками заземлення взагалі не впливає на вимір, оскільки струм у замкненій петлі циркулює незалежно від потенціалу навколишнього середовища.

## Промислова струмова петля 4–20 мА: живий нуль та схемотехніка

У світовій промисловій автоматизації де-факто абсолютним стандартом аналогового зв'язку стала струмова петля діапазону **4–20 мА** (стандарти ANSI/ISA-50.1 та IEC 60381-1).

### Концепція «живого нуля» (Live Zero)

Вибір нижньої межі діапазону на рівні 4 мА замість 0 мА — це глибоке інженерне рішення, яке вирішує два фундаментальні завдання:

1. **Миттєве розпізнавання аварій та обриву дроту.** Якщо сигнальний струм падає до 0 мА, система керування однозначно фіксує апаратну аварію: обрив кабелю, зникнення напруги живлення або вихід давача з ладу. Якби нульове значення фізичної величини (наприклад, тиск 0 бар) кодувалося нульовим струмом 0 мА, контролер не міг би відрізнити штатні нульові покази від перебитого екскаватором дроту.
2. **Двопровідне живлення від самої сигнальної лінії (Loop-Powered / 2-Wire).** Мінімальний гарантований струм 4 мА дозволяє живити всю внутрішню електроніку давача прямо від сигнальних дротів, не прокладаючи до нього окремих силових кабелів.

Діагностичні пороги струмової петлі детально регламентовані стандартом **NAMUR NE 43**:
- `I < 3.6 мА` — фізичний обрив лінії або критична несправність давача;
- `3.6 мА ≤ I < 3.8 мА` — зона виходу за нижню межу вимірювання (Under-range warning);
- `3.8 мА ≤ I ≤ 20.5 мА` — штатна робоча зона вимірювання фізичної величини (0..100% шкали плюс невеликий запас);
- `20.5 мА < I ≤ 21.0 мА` — зона виходу за верхню межу (Over-range warning);
- `I > 21.0 мА` — коротке замикання в лінії або аварія первинного перетворювача.

![Схемотехніка двопровідної струмової петлі 4–20 мА](/root/course/embedded/vid-strumu-do-syhnalu/img/current-loop-4-20ma.svg)
*Повна топологія двопровідної петлі: у щиті встановлено джерело +24 В та прецизійний шунт 250 Ом (перетворює 4–20 мА на 1–5 В). У полі віддалений давач живить свій сенсор і МК мікропотужним стабілізатором (споживання < 3.5 мА), а кероване джерело струму на ОП і транзисторі модулює сумарний струм петлі за командою ЦАП.*

### Схемотехніка передавача (Voltage-to-Current Converter)

Серцем польового передавача є кероване джерело струму (V-I перетворювач). Операційний підсилювач замкнений у петлю від'ємного зворотного зв'язку через вимірювальний резистор R_s, включений в емітерне (або витокове) коло регулюючого транзистора.

Вхідна напруга V_dac з виходу мікроконтролера подається на неінвертувальний вхід ОП. Оскільки зворотний зв'язок змушує підсилювач утримувати різницю напруг між входами рівною нулю, напруга на емітерному резисторі R_s стає суворо рівною V_dac:

```
V_Rs = V_dac                                [умова віртуального замикання входів ОП]
I_loop = V_dac / R_s                        [струм через струмовий шунт передавача]
```

Якщо напруга живлення петлі змінюється (наприклад, просідає з 24 В до 20 В) або опір лінії зростає від нагрівання кабелю, струм петлі на мить зменшується. Падіння напруги на R_s падає нижче V_dac, вихід ОП негайно піднімає напругу на затворі транзистора, відкриваючи його сильніше й точно відновлюючи заданий струм.

Вся внутрішня схема давача (чутливий елемент, мікроконтролер, джерело опорної напруги, ОП) споживає струм спокою I_supply, який не повинен перевищувати 3.5 мА за будь-яких умов. Цей струм протікає крізь клеми живлення давача і додається до загального струму петлі. Транзистор V-I перетворювача бере на себе регулювання залишкового струму:

```
I_loop = I_supply + I_transistor = 4.0 ... 20.0 мА   [баланс струмів у двопровідному давачі]
```

### Бюджет напруги петлі (Compliance Voltage Budget)

Щоб струмове джерело зберігало працездатність, джерело живлення 24 В мусить покривати всі послідовні падіння напруги в контурі за максимального струму I_max = 20 мА:

```
V_supply ≥ V_sensor_min + (I_max · R_line) + (I_max · R_load)   [бюджет напруги петлі]
```

Якщо давач вимагає для нормальної роботи мінімум V_sensor_min = 12.0 В, опір лінії становить R_line = 50 Ом, а на приймачі встановлено шунт R_load = 250 Ом, порахуємо загальне падіння:
- Падіння на шунті приймача: 20 мА · 250 Ом = 5.0 В;
- Падіння на проводах лінії: 20 мА · 50 Ом = 1.0 В;
- Падіння на давачі: 12.0 В.
- Сумарно: 5.0 + 1.0 + 12.0 = 18.0 В.

Оскільки стандартне джерело видає 24.0 В, запас за напругою (compliance margin) становить 6.0 В. Цього запасу вистачить навіть на те, щоб лінія мала додатковий опір R = 6 В / 0.02 А = 300 Ом, або на послідовне включення додаткового стрілочного індикатора.

Повна програмна обробка та калібрування такого каналу з розпізнаванням станів NAMUR NE 43 наведені у проектній вставці [Програмна обробка сигналу 4–20 мА та діагностика лінії за стандартом NAMUR NE 43](root:embedded/vid-strumu-do-syhnalu/proj-current-loop-adc.md).

## Прецизійне перетворення струму в напругу: шунти та вимірювальні підсилювачі

Більшість давачів у мікроелектроніці видають сигнал у вигляді струму:
- Фотодіоди та фотопомножувачі генерують зворотний фотострум, пропорційний світловому потоку;
- Вимірювальні трансформатори струму (Current Transformers, CT) та котушки Роговського видають вторинний струм, пропорційний струму в силовому проводі;
- Шунти в силових колах перетворюють струм споживання двигунів, інверторів чи батарей на вимірювану напругу.

### Компроміс номіналу шунта

Найпростіший спосіб виміряти струм — пропустити його крізь резистор відомого номіналу R_shunt і виміряти падіння напруги за законом Ома:

```
V_shunt = I · R_shunt   [закон Ома для вимірювального резистора]
```

Вибір номіналу R_shunt — це завжди гострий компроміс між амплітудою сигналу та тепловими втратами:

1. **Великий опір шунта (наприклад 1–10 Ом у силовому колі):** дає велику вихідну напругу (при 1 А це 1–10 В), яку легко зчитувати будь-яким вбудованим АЦП без додаткового підсилення. Але падіння напруги на шунті (Burden Voltage) відбирає живлення у навантаження, а теплові втрати P = I² · R спричиняють сильний нагрів резистора. Нагрівання змінює опір через температурний коефіцієнт (ТКС), спотворюючи вимір.
2. **Малий опір шунта (міліоми, наприклад 1–10 мОм):** мінімізує втрати потужності й падіння напруги, дозволяючи пропускати десятки амперів без перегріву. Але вихідний сигнал стає мікровольтовим: струм 100 мА на шунті 5 мОм дає напругу лише 500 мкВ. За такого сигналу власна напруга зміщення звичайного операційного підсилювача (V_os = 1...5 мВ) повністю перекриває корисний сигнал. Для роботи з такими шунтами потрібні підсилювачі класу Zero-Drift з автоматичною компенсацією зсуву (чоперні підсилювачі з V_os < 10 мкВ).

![Топології включення струмового шунта: Low-Side проти High-Side та 4-провідне підключення Кельвіна](/root/course/embedded/vid-strumu-do-syhnalu/img/shunt-low-vs-high-side.svg)
*Порівняння Low-Side та High-Side включення шунта. Low-Side зручний низьким рівнем синфазної напруги, але створює 'підстрибування' землі. High-Side зберігає землю непорушною та виявляє замикання на корпус, але вимагає спеціалізованого підсилювача CSA. Чотирипровідне підключення Кельвіна усуває паразитрий опір пайки.*

### Топології вимірювання: Low-Side проти High-Side

За місцем встановлення шунта в колі розрізняють дві фундаментальні схеми:

1. **Low-Side вимірювання (шунт у мінусовому проводі між навантаженням і землею).**
   - *Переваги:* Синфазна напруга на шунті близька до нуля (V_cm ≈ 0 В). Сигнал можна знімати простим однополярним операційним підсилювачем rail-to-rail, що живиться від тих самих 3.3 В або 5 В, що й мікроконтролер.
   - *Недоліки:* Земля навантаження піднімається над системною землею на величину V_ground_bounce = I_load · R_shunt. Якщо навантаження зв'язане з мікроконтролером цифровими інтерфейсами (UART, I2C, SPI), зміщення землі спотворює логічні рівні й може призвести до збоїв або пробою портів. Крім того, якщо провід після навантаження випадково замкнеться на заземлений металевий корпус, аварійний струм піде в обхід шунта, і система захисту не помітить короткого замикання.
2. **High-Side вимірювання (шунт у плюсовому проводі між шиною живлення V_bus і навантаженням).**
   - *Переваги:* Земля навантаження залишається жорстко з'єднаною з землею всієї системи. Будь-яке коротке замикання всередині навантаження на корпус проходить крізь шунт і миттєво реєструється.
   - *Складність:* Обидва виводи шунта перебувають під високим потенціалом шини живлення V_bus (12 В, 24 В, 48 В або більше). Звичайний ОП із живленням 3.3 В вийде з ладу або увійде в глибоке насичення.
   - *Рішення:* Спеціалізовані підсилювачі струму — **Current Sense Amplifiers (CSA)**, такі як INA180, INA240, MAX4080. Завдяки внутрішнім прецизійним дільникам або каскадам на високовольтних польових транзисторах вони здатні підсилювати мілівольтові диференціальні сигнали при синфазній напрузі до 80 В і більше, володіючи при цьому коефіцієнтом придушення синфазного сигналу (CMRR) понад 100–120 дБ.

### Чотирипровідне підключення Кельвіна (Kelvin Connection)

Під час роботи з низькоомними шунтами (1–10 мОм) критичного значення набуває опір доріжок друкованої плати та паяних з'єднань. Мідна доріжка плати завширшки 1 мм і завдовжки 10 мм має опір близько 5 мОм, а дві контактні площадки припою додають ще 1–2 мОм. Якщо підключити підсилювач до звичайних кінців шунта, опір монтажу (7 мОм) перевищить номінал самого шунта (5 мОм), створивши похибку вимірювання понад 140%!

Щоб усунути цей паразитарний опір, застосовують **підключення Кельвіна**:
- Силовий струм підводиться до двох масивних зовнішніх контактів шунта;
- Вимірювальні провідники (Sense+ та Sense−) підключаються до двох окремих тонких внутрішніх площадок безпосередньо біля резистивного тіла компонента.

Оскільки входи підсилювача споживають мізерний струм (пікоампери), падіння напруги на вимірювальних доріжках дорівнює нулю. Підсилювач вимірює напругу суворо на самому резистивному елементі, повністю ігноруючи опір пайки та силових ліній.

## Трансімпедансні підсилювачі (TIA): слабкі струми без втрати швидкості

Коли джерелом сигналу є фотодіод, рентгенівський детектор чи іонізаційний датчик, вихідний струм лежить у діапазоні від пікоамперів до десятків мікроамперів.

Спроба виміряти такий струм наївним способом — підключивши паралельно до фотодіода високоомний резистор R = 1 МОм на землю і подавши напругу на вхід повторювача — призводить до двох фізичних глухих кутів:

1. **Нелінійність через зміну напруги зміщення.** При зміні освітленості напруга на резисторі коливається в межах 0...1 В. Відповідно, напруга на PN-переході фотодіода також змінюється. Зміна напруги на діоді модулює ширину збідненої зони та струм витоку, руйнуючи пропорційність між світловим потоком і фотострумом.
2. **Катастрофічне звуження смуги пропускання.** Фотодіод має власну бар'єрну ємність PN-переходу C_d (зазвичай 50–200 пФ), до якої додається ємність монтажу. Разом із навантажувальним резистором R = 1 МОм ця ємність утворює RC-фільтр нижніх частот зі сталою часу:

```
τ = R · C_d = 10⁶ Ом · 100·10⁻¹² Ф = 100 мкс
f_зрізу = 1 / (2π · τ) ≈ 1.59 кГц            [обвал частотної смуги фотодетектора]
```

Оптичний приймач стає безнадійно повільним і не може реєструвати швидкі імпульси чи модульоване світло.

![Схема трансімпедансного підсилювача (TIA) та діаграма шумового підсилення з компенсацією](/root/course/embedded/vid-strumu-do-syhnalu/img/tia-circuit-stability.svg)
*Схема TIA: інвертувальний вхід утримується зворотним зв'язком на потенціалі віртуальної землі (0 В), тому напруга на фотодіоді не коливається і його ємність не перезаряджається сигналом. Праворуч: графік Боде шумового підсилення 1/β, де конденсатор Cf запобігає автогенерації на високих частотах.*

### Механізм віртуальної землі у TIA

Цю проблему елегантно вирішує **трансімпедансний підсилювач** (Transimpedance Amplifier, TIA).

Фотодіод підключається до інвертувального входу операційного підсилювача, неінвертувальний вхід з'єднується із землею (або опорною напругою V_ref), а резистор зворотного зв'язку R_f встановлюється між виходом та інвертувальним входом.

Завдяки гігантському коефіцієнту підсилення ОП у схемі з від'ємним зворотним зв'язком виникає явище **віртуальної землі**: підсилювач миттєво підлаштовує свою вихідну напругу так, щоб потенціал інвертувального входу залишався рівним потенціалу неінвертувального — тобто рівно 0 В.

Фізичні наслідки віртуальної землі:
- Потенціал анода й катода фотодіода зафіксований на постійному рівні. Сигнал більше не викликає коливань напруги на діоді, тому паразитна ємність C_d не перезаряджається вхідним сигналом, а ширина переходу не модулюється;
- Весь вхідний фотострум I_in, не маючи змоги затекти у високоомний вхід ОП, цілком спрямовується крізь резистор зворотного зв'язку R_f;
- Вихідна напруга підсилювача лінійно пропорційна вхідному струму:

```
V_out = −I_in · R_f                         [двополярне живлення ОП]
V_out = V_ref − I_in · R_f                  [однополярне живлення з опорною напругою]
```

Коефіцієнт перетворення схеми має розмірність опору (Вольт / Ампер = Ом) і називається **трансімпедансом**.

### Стійкість TIA та розрахунок ємності зворотного зв'язку C_f

Попри усунення впливу ємності C_in на затримку сигналу, ця ємність залишається підключеною до інвертувального входу ОП і діє на власні шуми та напругу зміщення підсилювача.

Разом із резистором зворотного зв'язку R_f вхідна ємність C_in утворює нуль у функції шумового підсилення (Noise Gain 1/β) на частоті:

```
f_z = 1 / ( 2π · R_f · C_in )               [нуль шумового підсилення]
```

Починаючи з цієї частоти, шумове підсилення починає зростати з нахилом +20 дБ/декаду. Одночасно підсилення самого операційного підсилювача A_ol(f) спадає зі швидкістю −20 дБ/декаду. На частоті їх перетину швидкість зближення характеристик досягає 40 дБ/декаду, що дає фазовий зсув у петлі зворотного зв'язку 180° і призводить до втрати запасу за фазою (фазовий запас Φ_m → 0°). Схема перетворюється на генератор гармонійних коливань або відгукується на кожен оптичний імпульс тривалим дзвіном.

Щоб стабілізувати підсилювач, паралельно до резистора R_f встановлюють компенсуючий конденсатор C_f. Він вводить у характеристику зворотного зв'язку полюс, який зупиняє підйом шумового підсилення і відновлює безпечний запас за фазою.

Оптимальне значення компенсуючої ємності C_f для досягнення запасу фази 45° становить:

```
C_f = √( C_in / (2π · R_f · GBW) )          [розрахунок ємності компенсації TIA]
```

де GBW — частота одиничного підсилення (Gain-Bandwidth Product) операційного підсилювача в герцах.

Повне аналітичне виведення петльових функцій, критерію стійкості та розрахунку для відгуку Баттерворта наведено у математичній вставці [Виведення стабільності TIA та розрахунок фазового запасу](root:embedded/vid-strumu-do-syhnalu/math-tia-stability.md).

## Струмові дзеркала та базові джерела струму

В аналоговій схемотехніці та всередині інтегральних мікросхем керовані струмові джерела та дзеркала є базовими будівельними блоками: вони задають струми спокою диференціальних каскадів, виступають динамічним активним навантаженням із опором у мегаоми та живлять світлодіоди оптопар.

![Схеми джерел струму: прецизійне джерело на ОП та струмове дзеркало на узгодженій парі транзисторів](/root/course/embedded/vid-strumu-do-syhnalu/img/current-mirror-basic.svg)
*Ліворуч: джерело витікаючого/втікаючого струму на ОП та транзисторі, де струм фіксується опорною напругою V_ref на емітерному резисторі. Праворуч: струмове дзеркало на узгодженій парі транзисторів, де напруга V_be першого транзистора в діодному включенні точно дублюється на другому транзисторі.*

### Прецизійне транзисторне джерело струму на ОП

Для отримання стабільного струму навантаження на дискретних компонентах застосовують схему, де операційний підсилювач контролює напругу на емітерному резисторі R_e відносно джерела стабільної опорної напруги V_ref (наприклад, мікросхеми TL431 або внутрішнього ЦАП):

```
I_load ≈ I_emitter = V_ref / R_e            [стабільний струм навантаження]
```

Оскільки ОП автоматично коригує напругу бази транзистора при зміні опору навантаження або напруги живлення V_cc, струм навантаження залишається стабільним із точністю до десятих часток відсотка.

### Струмове дзеркало (Current Mirror)

Струмове дзеркало призначене для копіювання опорного струму I_ref однієї гілки схеми в одну або декілька вихідних гілок I_out.

Класичне дзеркало на біполярних транзисторах складається з двох ідентичних транзисторів Q1 та Q2, виготовлених на одному напівпровідниковому кристалі (узгоджена пара — Matched Pair):
1. Транзистор Q1 увімкнений у діодному режимі: його колектор закорочений на базу. Еталонний струм I_ref, що протікає крізь резистор R_ref, створює на переході база-емітер транзистора Q1 суворо визначену напругу:

```
V_be = V_T · ln( I_ref / I_s )              [рівняння Еберса-Молла для PN-переходу]
```

2. База транзистора Q2 з'єднана з базою Q1, а його емітер — з емітером Q1. Оскільки напруга V_be_2 повністю ідентична V_be_1, а транзистори мають однаковий струм насичення I_s і температуру кристала, колекторний струм другого транзистора дзеркально повторює перший:

```
I_out = I_ref · ( 1 / (1 + 2/β_bjt) ) ≈ I_ref   [струм вихідної гілки дзеркала]
```

Головним фактором відхилення в реальних схемах є **ефект Ерлі** (модуляція ширини бази від напруги колектор-емітер V_ce). Через це вихідний струм трохи зростає при збільшенні напруги на навантаженні. Для боротьби з цим ефектом застосовують складніші топології: дзеркало Вілсона або каскодні дзеркала, що підвищують динамічний вихідний опір до сотень мегаомів.

## Фільтрація та захист сигнальних струмових ліній від завад

Промислове середовище наповнене потужними електромагнітними завадами: комутаційними сплесками індуктивних навантажень, високовольтними імпульсами пускачів, розрядами блискавок та електростатикою (ESD). Довгий сигнальний кабель працює як антена, що збирає ці наведення.

Щоб захистити чутливий вхідний тракт мікроконтролера та зберегти точність вимірювань, застосовують багаторівневий апаратний захист:

```
Кабель лінії ─── [PPTC PolySwitch] ───┬─── [R_filter] ───┬─── До входу АЦП
                                      │                  │
                                   [TVS]              [C_filter]
                                      │                  │
                                   [GND]              [GND]
```

### 1. Перший рівень: обмеження енергії перенапруг (TVS та PPTC)

- **TVS-діод (супресор):** встановлюється паралельно до клем сигнального входу (наприклад, двонаправлений SMAJ30CA або однонаправлений супресор на 3.6 В прямо на шунті). При виникненні імпульсного сплеску напруги понад поріг відкривання TVS-діод за частки наносекунди переходить у провідний стан, скидаючи струм сплеску в землю та зрізаючи напругу на безпечному рівні.
- **Самовідновний запобіжник (PPTC PolySwitch):** встановлюється послідовно в сигнальний провід перед шунтом (номінал струму спрацьовування 50–100 мА). Якщо монтажник помилково подасть напругу 24 В або 230 В прямо на клеми шунта, запобіжник миттєво розігріється, його опір підскочить до мегаомів і він розірве аварійне коло, захистивши шунт і плату від вигорання.

### 2. Другий рівень: фільтрація високочастотного шуму

Перед подачею напруги з шунта на вхід АЦП обов'язково встановлюють низькочастотний RC-фільтр:
- Послідовний резистор R_filter (1–10 кОм) обмежує струм у захисні діоди мікроконтролера при перевантаженні;
- Конденсатор C_filter (100 нФ – 1 мкФ) з високостабільним діелектриком (X7R, C0G/NP0) утворює з резистором фільтр нижніх частот із частотою зрізу:

```
f_cut = 1 / ( 2π · R_filter · C_filter )     [частота зрізу вхідного RC-фільтра]
```

Для значень R = 1 кОм та C = 100 нФ частота зрізу становить близько 1.59 кГц, що надійно відсікає високочастотний цифровий шум та радіонаведення.

### 3. Правила екранування та боротьби із земляними петлями

- Сигнальну струмову петлю прокладають виключно **екранованою витою парою (Shielded Twisted Pair, STP)**. Скручування проводів гарантує, що магнітна завада наводить однакову проти-ЕРС в обидва проводи, яка взаємно компенсується в диференціальному контурі;
- **Екран кабелю заземлюють суворо в одній точці** — як правило, з боку щита керування на головну шину заземлення (PE). Категорично заборонено заземлювати екран з обох кінців кабелю: через різницю потенціалів земель ΔV_gnd по екрану потече вирівнювальний струм у кілька амперів, який створить потужну магнітну наводку на сигнальні жили всередині кабелю.

## Програмна обробка та архітектура вимірювального тракту

У вбудованій системі сигнал зі струмового приймача перетворюється на фізичну величину через кілька послідовних стадій:

1. **Оцифрування та апаратне усереднення:** запуск вибірки АЦП з оверсемплінгом (наприклад, накопичення 16 або 64 вибірок через DMA) для придушення випадкового шуму квантування;
2. **Цифрова фільтрація:** обробка цифровим фільтром нижніх частот (експоненційним згладжувачем першого порядку) для усунення пульсацій промислової частоти 50/100 Гц;
3. **Діагностика лінії (NAMUR NE 43):** перевірка меж струму для виявлення обриву або короткого замикання кабелю;
4. **Масштабування та калібрування:** лінійна інтерполяція струму в одиниці фізичної величини (тиск у барах, температура в градусах Цельсія) з урахуванням індивідуального калібрувального зсуву нуля та коефіцієнта нахилу.

Нижче наведено завершену реалізацію вимірювального модуля з діагностикою лінії за стандартом NAMUR NE 43:

:::tabs
```c
#include <stdint.h>
#include <stdbool.h>

// Діагностичні статуси струмової петлі за NAMUR NE 43
typedef enum {
    LOOP_STATE_OK = 0,
    LOOP_STATE_UNDER_RANGE_WARN,
    LOOP_STATE_OVER_RANGE_WARN,
    LOOP_STATE_FAULT_WIRE_BREAK,
    LOOP_STATE_FAULT_SHORT_CIRCUIT
} LoopDiagnosticState;

// Конфігурація аналогового струмового каналу
typedef struct {
    float r_shunt_ohms;      // Номінал шунта (наприклад, 100.0 Ом)
    float v_reference_volts; // Опорна напруга АЦП (3.30 В)
    uint32_t adc_resolution; // Максимальний код АЦП (4095 для 12 біт)
    float filter_weight;     // Коефіцієнт експоненційного фільтра (0.05..0.2)
    float phys_scale_zero;   // Значення величини при 4.0 мА (0.0 бар)
    float phys_scale_span;   // Значення величини при 20.0 мА (16.0 бар)
    
    // Внутрішній стан каналу
    float smoothed_voltage;  // Згладжена напруга шунта (В)
    bool is_warmed_up;       // Прапорець завершення ініціалізації
} AnalogCurrentLoop;

// Результат вимірювання
typedef struct {
    float current_milliamps; // Розрахований струм лінії (мА)
    float measured_value;    // Фізична величина
    LoopDiagnosticState state; // Стан лінії
} LoopReading;

void analog_loop_init(AnalogCurrentLoop *inst, float r_shunt, float v_ref, 
                      uint32_t adc_max, float alpha, float p_zero, float p_span) {
    inst->r_shunt_ohms = r_shunt;
    inst->v_reference_volts = v_ref;
    inst->adc_resolution = adc_max;
    inst->filter_weight = alpha;
    inst->phys_scale_zero = p_zero;
    inst->phys_scale_span = p_span;
    inst->smoothed_voltage = 0.0f;
    inst->is_warmed_up = false;
}

LoopReading analog_loop_update(AnalogCurrentLoop *inst, uint16_t adc_raw_code) {
    LoopReading out;
    
    // Перетворення вибірки АЦП на напругу на клемах шунта
    float instant_voltage = ((float)adc_raw_code / (float)inst->adc_resolution) * inst->v_reference_volts;
    
    // Експоненційне згладжування шуму: y[k] = y[k-1] + alpha * (x[k] - y[k-1])
    if (!inst->is_warmed_up) {
        inst->smoothed_voltage = instant_voltage;
        inst->is_warmed_up = true;
    } else {
        inst->smoothed_voltage += inst->filter_weight * (instant_voltage - inst->smoothed_voltage);
    }
    
    // Струм петлі в міліамперах: I = (V / R) * 1000
    float current_ma = (inst->smoothed_voltage / inst->r_shunt_ohms) * 1000.0f;
    out.current_milliamps = current_ma;
    
    // Діагностика лінії за критеріями NAMUR NE 43
    if (current_ma < 3.60f) {
        out.state = LOOP_STATE_FAULT_WIRE_BREAK;
        out.measured_value = inst->phys_scale_zero;
    } else if (current_ma < 3.80f) {
        out.state = LOOP_STATE_UNDER_RANGE_WARN;
        out.measured_value = inst->phys_scale_zero;
    } else if (current_ma > 21.00f) {
        out.state = LOOP_STATE_FAULT_SHORT_CIRCUIT;
        out.measured_value = inst->phys_scale_span;
    } else if (current_ma > 20.50f) {
        out.state = LOOP_STATE_OVER_RANGE_WARN;
        out.measured_value = inst->phys_scale_span;
    } else {
        out.state = LOOP_STATE_OK;
        // Лінійне масштабування: 4.0 мА -> Zero, 20.0 мА -> Span
        float fraction = (current_ma - 4.0f) / (20.0f - 4.0f);
        out.measured_value = inst->phys_scale_zero + fraction * (inst->phys_scale_span - inst->phys_scale_zero);
    }
    
    return out;
}
```

```cpp
#include <cstdint>
#include <algorithm>

namespace embedded {

enum class DiagnosticStatus : uint8_t {
    Normal,
    UnderRangeWarning,
    OverRangeWarning,
    FaultWireBreak,
    FaultShortCircuit
};

struct ChannelParameters {
    float shunt_resistance_ohms{100.0f};
    float adc_vref_volts{3.30f};
    uint32_t adc_max_count{4095};
    float smoothing_factor{0.10f};
    float scale_at_4ma{0.0f};
    float scale_at_20ma{16.0f};
};

struct ChannelOutput {
    float loop_current_ma;
    float scaled_physics;
    DiagnosticStatus diagnostics;
};

class CurrentLoopProcessor {
public:
    explicit constexpr CurrentLoopProcessor(const ChannelParameters& params) noexcept
        : params_{params}, filtered_voltage_{0.0f}, is_ready_{false} {}

    [[nodiscard]] ChannelOutput process_sample(uint16_t adc_code) noexcept {
        const float sample_voltage = (static_cast<float>(adc_code) / 
                                      static_cast<float>(params_.adc_max_count)) * params_.adc_vref_volts;
        
        if (!is_ready_) {
            filtered_voltage_ = sample_voltage;
            is_ready_ = true;
        } else {
            filtered_voltage_ += params_.smoothing_factor * (sample_voltage - filtered_voltage_);
        }

        const float current_ma = (filtered_voltage_ / params_.shunt_resistance_ohms) * 1000.0f;
        const auto diag = classify_namur(current_ma);
        const float physics = compute_scale(current_ma);

        return ChannelOutput{
            .loop_current_ma = current_ma,
            .scaled_physics = physics,
            .diagnostics = diag
        };
    }

    void reset() noexcept {
        is_ready_ = false;
        filtered_voltage_ = 0.0f;
    }

private:
    [[nodiscard]] static constexpr DiagnosticStatus classify_namur(float current_ma) noexcept {
        if (current_ma < 3.60f) return DiagnosticStatus::FaultWireBreak;
        if (current_ma < 3.80f) return DiagnosticStatus::UnderRangeWarning;
        if (current_ma > 21.00f) return DiagnosticStatus::FaultShortCircuit;
        if (current_ma > 20.50f) return DiagnosticStatus::OverRangeWarning;
        return DiagnosticStatus::Normal;
    }

    [[nodiscard]] constexpr float compute_scale(float current_ma) const noexcept {
        const float bounded_current = std::clamp(current_ma, 4.0f, 20.0f);
        const float normalized = (bounded_current - 4.0f) / 16.0f;
        return params_.scale_at_4ma + normalized * (params_.scale_at_20ma - params_.scale_at_4ma);
    }

    ChannelParameters params_;
    float filtered_voltage_;
    bool is_ready_;
};

} // namespace embedded
```

## Підсумковий синтез

Перетворення електричного струму на інформаційний сигнал — це перехід від простоти схеми до стійкості системи.

Передача напругою доцільна лише там, де лінія коротка, опір дротів мізерний, а земля єдина — всередині однієї плати або блоку. Щойно сигнал виходить у реальний світ довгих кабелів, потужних електродвигунів та рознесених заземлень, струм стає безальтернативним носієм:
- Струмова петля 4–20 мА нівелює опір дротів та різницю потенціалів земель завдяки першому закону Кірхгофа, забезпечуючи надійну передачу даних на відстані до кілометра та миттєву діагностику обриву лінії;
- Прецизійні шунти з 4-провідним підключенням Кельвіна та підсилювачі струму High-Side дозволяють контролювати струми від міліамперів до сотень амперів без спотворення системної землі;
- Трансімпедансні підсилювачі (TIA) на базі віртуальної землі операційного підсилювача перетворюють надслабкі фотоструми в напругу без перезаряджання бар'єрної ємності давача, поєднуючи субнаноамперну чутливість із широкою частотною смугою.
