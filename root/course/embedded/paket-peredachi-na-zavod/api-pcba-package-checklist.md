# 📋 Чекліст і структура пакета передачі PCBA у виробництво

Контракт між командою розробки та контрактним виробником (EMS) тримається на структурі релізного архіву. Неповний список файлів, відсутність контрольних сум або неоднозначні назви колонок у таблицях монтажу призводять до зупинки ліній або браку цілих партій. Нижче наведено стандартну структуру виробничого пакета, вимоги до кожного типу файлів і обов'язкові поля специфікацій.

## 1. Ієрархія файлової структури релізного архіву

Виробничий реліз формується у вигляді єдиного архіву з фіксованою назвою за шаблоном `PROJECT_HW-REV_PCBA-REV_DATE.zip` (наприклад, `TELEMETRY-NODE_REV-B_PCBA-1.2_2026-08-28.zip`). Усередині архіву файли розподіляються за чотирма ізольованими каталогами відповідно до виробничих постів заводу:

```text
RELEASE_PACKAGE_v2.1.0/
├── 01_PCB_Fabrication/
│   ├── Gerbers/
│   │   ├── F_Cu.gbr               [Верхній шар міді / L1 Top]
│   │   ├── In1_Cu.gbr             [Внутрішній шар міді / L2 Ground]
│   │   ├── In2_Cu.gbr             [Внутрішній шар міді / L3 Power]
│   │   ├── B_Cu.gbr               [Нижній шар міді / L4 Bottom]
│   │   ├── F_Mask.gbr             [Верхня паяльна маска]
│   │   ├── B_Mask.gbr             [Нижня паяльна маска]
│   │   ├── F_Silk.gbr             [Верхня шовкографія]
│   │   ├── B_Silk.gbr             [Нижня шовкографія]
│   │   └── Edge_Cuts.gbr          [Контур плати, пази, вирізи]
│   ├── Drill/
│   │   ├── PCB-PTH.drl            [Отвори з металізацією / Plated]
│   │   ├── PCB-NPTH.drl           [Отвори без металізації / Non-plated]
│   │   └── PCB-Drill-Map.pdf      [Креслення карти отворів та таблиця інструментів]
│   ├── IPC-D-356_Netlist.ipc      [Електричний нетліст для тестування голої плати]
│   ├── PCB_Stackup_Spec.pdf       [Специфікація структури шарів і діелектриків]
│   └── PCB_Fab_Drawing.pdf        [Креслення механічної обробки та вимоги виготовлення]
├── 02_SMT_Assembly/
│   ├── BOM_Production.csv         [Відомість матеріалів у машинозчитуваному форматі]
│   ├── BOM_Production.xlsx        [Відомість матеріалів для закупівельників]
│   ├── Centroid_PickAndPlace.csv  [Координати й кути монтажу компонентів / CPL]
│   ├── Paste_Mask/
│   │   ├── F_Paste.gbr            [Верхній шар паяльної пасти для трафарету]
│   │   └── B_Paste.gbr            [Нижній шар паяльної пасти для трафарету]
│   ├── Assembly_Drawing_Top.pdf   [Складальне креслення верхньої сторони з ключами]
│   └── Assembly_Drawing_Bottom.pdf[Складальне креслення нижньої сторони з ключами]
├── 03_Firmware_Provisioning/
│   ├── bootloader.bin             [Первинний завантажувач]
│   ├── partition_table.bin        [Таблиця розділів Flash]
│   ├── firmware_app_v2.1.0.bin    [Основний виконуваний образ прошивки]
│   ├── flash_image_merged.bin     [Монолітний образ для первинного програматора]
│   ├── fuse_configuration.json    [Конфігурація апаратних ф'юзів і бітів захисту]
│   ├── provisioning_schema.json   [Структура унікальних даних: MAC, UUID, ключі]
│   ├── flash_production.sh        [Скрипт прошивання для Linux станції (OpenOCD/J-Link)]
│   └── flash_production.bat       [Скрипт прошивання для Windows станції]
├── 04_Testing_QA/
│   ├── Test_Procedure_SOP.pdf     [Покрокова робоча інструкція тестування для оператора]
│   ├── ICT_TestPoints_List.csv    [Список координат і сигналів тест-точок]

├── RELEASE_NOTES.md               [Опис змін поточної ревізії (ECO summary)]
└── SHA256SUMS.txt                 [Контрольні суми SHA-256 кожного файлу в пакеті]
```

## 2. Специфікація колонок відомості матеріалів (BOM)

Таблиця `BOM_Production.csv` повинна містити повний набір даних, необхідних для автоматизованої системи закупівель (ERP) та конвеєрного обліку. Кодування файлу — UTF-8 без BOM-заголовка, роздільник — кома або крапка з комою (без змішування).

| Назва колонки | Тип даних | Приклад значення | Обов'язковість | Опис та призначення |
|---|---|---|---|---|
| `Item` | Ціле число | `1`, `2`, `3` | Так | Порядковий номер рядка у специфікації. |
| `Designator` | Рядок | `C1, C2, C4, C7` | Так | Позиційні позначення компонентів через кому. |
| `Qty` | Ціле число | `4` | Так | Кількість компонентів цього рядка на одну плату. |
| `Manufacturer` | Рядок | `Murata Electronics` | Так | Офіційна назва компанії-виробника компонента. |
| `MPN` | Рядок | `GRM155R71C104KA88D` | Так | Manufacturer Part Number — повний код замовлення. |
| `Value` | Рядок | `100nF` | Так | Номінальне значення (ємність, опір, індуктивність). |
| `Description` | Рядок | `CAP CER 0.1UF 16V X7R 0402` | Так | Повний інженерний опис із допусками й напругою. |
| `Package` | Рядок | `0402 (1005 Metric)` | Так | Типорозмір корпусу деталі. |
| `Mount_Type` | Перелік | `SMT` або `THT` | Так | Спосіб монтажу: поверхневий чи в отвори. |
| `DNP` | Прапорець | `0` (або `1` для DNP) | Так | Do Not Populate: 1 — деталь не встановлюється. |
| `Alternate_MPN` | Рядок | `CL05B104KO5NNNC` | Ні | Дозволена заміна (Second Source) для закупівлі. |
| `MSL` | Рядок | `MSL 1` / `MSL 3` | Ні | Рівень чутливості до вологи (Moisture Sensitivity). |

## 3. Специфікація файлу Pick-and-Place (CPL / Centroid)

Файл координат `Centroid_PickAndPlace.csv` використовується керуючою програмою Pick-and-Place автомата. Координати задаються для геометричного центру посадкового місця (а не для виводу №1) у міліметрах відносно технологічного початку координат плати (Origin), узгодженого з контуром Edge.Cuts.

| Колонка | Формат | Приклад | Вимоги та узгодження |
|---|---|---|---|
| `Designator` | Текст | `U3` | Повинен суворо відповідати позиційному імені в BOM. |
| `Val` | Текст | `STM32G030F6P6` | Номінал/найменування для верифікації оператором. |
| `Package` | Текст | `TSSOP-20` | Назва фупрінта в бібліотеці САПР. |
| `Layer` | `Top` / `Bottom` | `Top` | Шар монтажу, на якому розміщено деталь. |
| `PosX` | Дійсне число (мм) | `24.500` | Координата центру за віссю X (точність 3 знаки). |
| `PosY` | Дійсне число (мм) | `18.320` | Координата центру за віссю Y (точність 3 знаки). |
| `Rot` | Дійсне число (°) | `90.0` | Кут повороту: від 0.0 до 359.9 градусів проти годинникової. |

Для панелізованих плат додається файл `Centroid_Panel.csv`, де вказано координати зміщення кожної суб-плати в матриці панелі та координати глобальних оптичних реперів (Global Fiducials) панелі.

## 4. Вимоги до трафарету та модифікації апертур (Paste Mask)

Шари паяльної пасти (`F_Paste.gbr`, `B_Paste.gbr`) потребують попередньої оптимізації під лазерне різання сталевого трафарету товщиною 100–120 мкм:

1. **Мікросхеми з тепловими майданчиками (QFN/DFN/PowerPAD):** суцільне відкриття пасти заборонено. Апертура розбивається на матрицю з вікон розміром 1.0×1.0 мм із містками 0.2 мм, сумарна площа нанесення пасти становить 50–65% від площі мідного майданчика;
2. **Пасивні компоненти типорозмірів 0402 та 0201:** зменшення площі вікон на 10–15% за технологією Home Plate або розширення внутрішніх країв для запобігання утворенню кульок припою (solder beads);
3. **BGA мікросхеми з малим кроком (0.4–0.5 мм):** круглі апертури трафарету зменшуються на 10% від діаметра мідного п'ятачка для збереження коефіцієнта площі (Area Ratio >= 0.66).

## 5. Вимоги до технологічних креслень (Fab Notes)

Креслення `PCB_Fab_Drawing.pdf` та специфікація `PCB_Stackup_Spec.pdf` фіксують вимоги до голої друкованої плати, які неможливо виразити у векторних герберах:

1. **Матеріал діелектрика:** тип основи (FR-4 Standard Tg 130–140 °C, Mid-Tg 150 °C або High-Tg ≥ 170 °C для безсвинцевого паяння).
2. **Товщина плати:** загальна товщина з допусками (наприклад, `1.60 мм ± 10%`).
3. **Товщина міді:** базовий шар фольги для зовнішніх і внутрішніх шарів (`35 мкм / 1 oz` або `18 мкм / 0.5 oz` із фінішним нарощуванням).
4. **Фінішне покриття майданчиків:**
   - `HASL Lead-Free` — гаряче лудіння без свинцю (дешеве, але має нерівну поверхню, непридатне для тонких QFN/BGA з кроком менше 0.5 мм);
   - `ENIG` (Electroless Nickel Immersion Gold) — хімічний нікель (3–5 мкм) + іммерсійне золото (0.05–0.1 мкм), ідеально пласке для BGA/QFN;
   - `OSP` (Organic Solderability Preservative) — органічне захисне покриття міді.
5. **Колір і тип паяльної маски:** зелений/чорний/синій/білий, матовий або глянцевий. Мінімальний місток маски між ніжками мікросхем (Solder Mask Dam ≥ 0.1 мм).
6. **Колір шовкографії:** білий/чорний. Мінімальна товщина лінії тексту ≥ 0.15 мм, висота символів ≥ 0.8 мм.
7. **Контроль хвильового опору (Impedance Control):** таблиця цільових ліній (наприклад, `Microstrip Single-Ended 50 Ом ± 10%`, `Differential Pair 90 Ом ± 10% для USB D+/D-`) із зазначенням ширини провідника та шару опорної землі.
8. **Обробка перехідних отворів (Via Protection):** Tented (закриті маскою), Plugged (заповнені неелектропровідною пастою) або Via-in-Pad з гальванічним мідним перекриттям (VIPPO для BGA з дрібним кроком).
9. **Механічна панелізація:** вимоги до контурного фрезерування (Routing), надрізання V-Score (кут 30°/45°, залишковий шар діелектрика `0.40 мм ± 0.05 мм`) або перфорацій із «мишачими укусами» (Mouse Bites).
10. **Електричний нетліст (IPC-D-356):** файл опису електричних зв'язків між усіма тестовими точками й майданчиками для 100% верифікації відсутності обривів і замикань на голому текстоліті тестером із летючими щупами (Flying Probe Tester).

## 6. Вимоги до складальних креслень (Assembly Drawings)

Складальне креслення `Assembly_Drawing_Top.pdf` / `Assembly_Drawing_Bottom.pdf` слугує візуальним еталоном для оператора лінії та інспектора ВТК (відділу технічного контролю):

- **Позначення орієнтації мікросхем:** виразний трикутник або крапка біля виводу №1 кожного чипа (Pin 1 Indicator), що дублюється малюнком на шовкографії.
- **Полярність компонентів:**
  - Діоди: чітка риска катода (Cathode Band);
  - Електролітичні й танталові конденсатори: жирний знак «+» біля анодного виводу;
  - Світлодіоди: позначення катода/анода символом діода або кутовим зрізом.
- **Орієнтація роз'ємів:** позначення ключа фіксатора (Latch / Keyway) або першого контакту (Pin 1) кабельних штекерів.
- **Реперні знаки (Fiducials):** мінімум 3 оптичні мітки на кутах панелі та 2 локальні мітки по діагоналі для кожного корпусу QFN/BGA з дрібним кроком.
