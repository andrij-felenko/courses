# ⚙️ Практичне керування силовими навантаженнями з ШІМ

Комутація силових навантажень постійного струму (світлодіодні стрічки 12/24 В, колекторні DC-двигуни, нагрівальні столи 3D-принтерів) за допомогою широтно-імпульсної модуляції (ШІМ) вимагає суворого узгодження швидкодії апаратного ключа з алгоритмом прошивки мікроконтролера. 

Головна пастка програмно-апаратного стику полягає в динамічних втратах: на низьких частотах (100–300 Гц) транзистор майже весь час перебуває або в повністю відкритому, або в закритому стані. Проте спроба підняти частоту ШІМ до 20–30 кГц (щоб усунути неприємний акустичний писк обмоток двигуна чи уникнути стробоскопічного мерехтіння світла на камерах) різко збільшує частку часу, яку транзистор проводить у **динамічному переході** через лінійну область. У цей момент на кристалі одночасно присутні і висока напруга живлення, і повний струм навантаження.

## 1. Розрахунок теплового балансу та заряду затвора

Повна потужність втрат на польовому транзисторі `P_total` складається зі статичних втрат провідності `P_cond` та динамічних комутаційних втрат перемикання `P_sw`:

```
P_total = P_cond + P_sw
```

Статичні втрати у відкритому стані визначаються струмом навантаження та опором відкритого каналу:

```
P_cond = I_load² · R_ds(on) · D
```

де `D` — коефіцієнт заповнення ШІМ *(Duty Cycle)* у діапазоні від 0.0 до 1.0.

Динамічні втрати перемикання пропорційні частоті комутації `f_sw`:

```
P_sw = ½ · V_supply · I_load · (t_rise + t_fall) · f_sw
```

де `t_rise` та `t_fall` — тривалість фронтів наростання та спадання напруги на затворі транзистора.

### Фізика перезаряджання заряду затвора Q_g

Тривалість фронтів перемикання визначається не просто ємністю `C_iss`, а повним зарядом затвора `Q_g` *(Total Gate Charge)*, який враховує плато Міллера *(Miller plateau)* — інтервал часу, протягом якого напруга на стоку падає, а ємність `C_gd` перезаряджається:

```
t_sw ≈ Q_g / I_drive
```

де `I_drive` — піковий вихідний струм каскаду керування (GPIO мікроконтролера або спеціалізованого драйвера).

**Порівняльний розрахунок для силового транзистора IRLZ44N (`Q_g = 48 нКл`):**

1. **Пряме керування від GPIO мікроконтролера (`I_gpio = 15 мА`):**
```
t_sw ≈ 48 нКл / 0.015 А = 3200 нс = 3.2 мкс
```
Якщо такий ключ комутує мотор 24 В / 5 А на частоті ШІМ 25 кГц:
```
P_sw = ½ · 24 В · 5 А · (3.2·10⁻⁶ с + 3.2·10⁻⁶ с) · 25000 Гц = 9.6 Вт
```
Транзистор виділяє майже 10 Вт тепла тільки на динамічних втратах перемикання і згорає без масивного радіатора з активним обдувом.

2. **Керування через інтегральний драйвер затвора TC4427 (`I_driver = 1.5 А`):**
```
t_sw ≈ 48 нКл / 1.5 А = 32 нс = 0.032 мкс
```
Динамічні втрати перемикання падають пропорційно швидкості наростання фронту:
```
P_sw = ½ · 24 В · 5 А · (32·10⁻⁹ с + 32·10⁻⁹ с) · 25000 Гц = 0.096 Вт = 96 мВт
```
Ключ залишається холодним навіть у мініатюрному SMD-виконанні.

## 2. Реалізація драйвера навантаження з плавним пуском

Холодна нитка розжарення лампи, розряджені ємності світлодіодної стрічки або нерухомий якір електродвигуна в момент увімкнення мають опір у 5–10 разів нижчий за номінальний. Стрибкоподібна подача 100% потужності генерує пусковий струм *(Inrush Current)* величиною 20–50 А. Це викликає різку просадку напруги живлення мікроконтролера і призводить до раптового циклічного перезавантаження чипа *(Brown-out Reset)*.

Надійний вбудований драйвер силового ключа обов'язково повинен реалізовувати **програмну рампу наростання потужності (Soft-Start)**.

## 3. Бутстрепне живлення для High-Side N-MOSFET при ШІМ

Коли в схемі комутації верхнього плеча застосовують N-MOSFET (наприклад, у напівмостовому H-мості керування реверсом двигуна), для його відмикання використовують так звану **бутстрепну схему** *(Bootstrap Circuit)*:

```
               + 12 В ─────┬──────────────┐
                           │              │
                         ┌─┴─┐ D_boot   ┌─┴─┐
                         ▲   │ (Шотткі) │   │ High-Side N-MOSFET
                         └─┬─┘          │   │
                           ├──────┐     └──┬┘
                         ┌─┴─┐    │        │
                         ─── C_boot        ├────────► До двигуна (Phase OUT)
                         ───      │        │
                           │      │      ┌─┴─┐
                           └──────┴──────┤   │ Low-Side N-MOSFET
                                         │   │
                                         └──┬┘
                                            │
                                           ─── GND
```

1. Коли відкритий нижній транзистор (Low-Side), вихідна точка `Phase OUT` притягнута до землі. Бутстрепний конденсатор `C_boot` заряджається від джерела 12 В через діод Шотткі `D_boot` до напруги близько 11.6 В.
2. Коли нижній транзистор закривається, а верхній відкривається, точка `Phase OUT` піднімається до +12 В. Потенціал верхньої обкладки `C_boot` автоматично піднімається до `12 В + 11.6 В = 23.6 В`. Це забезпечує повноцінні 11.6 В між затвором і витоком верхнього N-MOSFET, утримуючи його у відкритому стані.

### Розрахунок ємності C_boot
Мінімальна ємність бутстрепного конденсатора розраховується з умови, що заряд затвора `Q_g` не повинен просаджувати напругу на конденсаторі більше ніж на `ΔV_boot ≈ 0.5..1.0 В`:

```
C_boot ≥ (2 · Q_g) / ΔV_boot
```

Для транзистора з `Q_g = 50 нКл` при допустимій просадці `ΔV_boot = 0.5 В`:

```
C_boot ≥ (2 · 50·10⁻⁹ Кл) / 0.5 В = 200·10⁻⁹ Ф = 200 нФ
```
Зазвичай встановлюють керамічний конденсатор ємністю 0.47–1.0 мкФ з діелектриком X7R. 

**Критичне обмеження бутстрепа:** схема не може працювати при постійній 100% шпаруватості ШІМ (`Duty Cycle = 1.0`), оскільки конденсатор поступово розряджається струмами витоку драйвера. Максимальний коефіцієнт заповнення обмежують на рівні 95–98%, щоб нижній транзистор регулярно вмикався на короткий час для підзарядки `C_boot`.

## 4. Типові апаратно-програмні пастки комутації

1. **Плаваючий затвор під час прошивки або завантаження МК:**
   - *Проблема:* Під час апаратного скидання (Reset) чи роботи заводського бутлоадера всі виводи GPIO мікроконтролера переводяться у високоімпедансний стан *(High-Z)*. Якщо в схемі відсутній фізичний стягувальний резистор `R_pull` (10–47 кОм на землю для N-MOSFET), затвор заряджається статикою чи струмами витоку плати. Транзистор входить у напівпровідний лінійний стан і вигорає за 1–2 секунди.
   - *Виправлення:* Завжди встановлювати дискретний резистор pull-down безпосередньо біля виводів затвора та витоку транзистора.
2. **Зсув потенціалу землі силовим струмом:**
   - *Проблема:* При протіканні струму 10 А опір довгої тонкої доріжки землі друкованої плати в 0.05 Ом створює динамічне падіння напруги `10 А · 0.05 Ом = 0.5 В`. Потенціал витоку транзистора піднімається над землею мікроконтролера. Керуюча напруга `V_gs = V_gpio − V_source` зменшується з 3.3 В до 2.8 В. Опір `R_ds(on)` зростає в кілька разів, що викликає лавиноподібний перегрів ключа.
   - *Виправлення:* Розділяти цифрову землю мікроконтролера (DGND) та силову землю комутатора (PGND), з'єднуючи їх виключно в одній зіркоподібній точці безпосередньо біля вихідного фільтрувального конденсатора джерела живлення.
3. **Повільний діод при високочастотній ШІМ:**
   - *Проблема:* Використання випрямного діода 1N4007 паралельно мотору при частоті ШІМ 20 кГц. Оскільки час зворотного відновлення `t_rr` звичайного діода становить 2–4 мкс, транзистор на початку кожного такту відкривається на прямопровідний діод, викликаючи короткі замикання шини живлення струмом до 30 А.
   - *Виправлення:* Застосовувати виключно діоди Шотткі (SS34, 1N5819, MBR1045) з часом відновлення менше 10–20 нс.
