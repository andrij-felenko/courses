# 🔌 Інтелектуальні силові ключі верхнього плеча

Інтелектуальний силовий ключ верхнього плеча *(Smart High-Side Power Switch, комерційні родини PROFET, TPS2xxx, BTSxxx, VN5Exxx)* об'єднує на одному кристалі або в єдиному корпусі силовий транзистор, схему накачування заряду, струмове дзеркало для вимірювання струму та апаратний комплекс захисту від короткого замикання, перегріву й зворотної полярності.

У бортовій електроніці автомобілів, авіоніці дронів та промислових контролерах комутація навантаження по плюсовій шині живлення *(High-Side)* є безальтернативною вимогою безпеки: будь-яке пошкодження ізоляції та замикання сигнального або силового джгута на металевий корпус чи масу призводить до знеструмлення кола запобіжником, а не до аварійного самовільного запуску виконавчого механізму. Проте побудова дискретного комутатора на P-канальному польовому транзисторі вимагає проміжного NPN-ключа для зсуву логічних рівнів, захисних стабілітронів у затворі, вимірювального шунта з диференційним підсилювачем та схеми відсікання струму при аварії. Інтелектуальні ключі інтегрують весь цей схемотехнічний вузол у компактний корпус (від SOT-223 до TO-263 та DFN).

## Внутрішня структура та принцип роботи

Головний парадокс комутації верхнього плеча полягає в тому, що n-канальні транзистори *(N-MOSFET)* мають у 2.5–3 рази менший питомий опір відкритого каналу `R_ds(on)` на одиницю площі кремнію порівняно з p-канальними аналогами *(P-MOSFET)* завдяки вищій рухливості електронів порівняно з дірками. Використання n-каналу на верхньому плечі суттєво зменшує нагрів кристала, але вимагає подачі на затвор напруги, яка перевищує потенціал витоку (а отже, і шини живлення `V_bat`) щонайменше на 5–10 В.

Інтелектуальний ключ вирішує цю проблему за допомогою вбудованого генератора підкачування заряду *(charge pump)*.

```
                  ┌─────────────────────────────────────────────────────────┐
                  │                 ІНТЕЛЕКТУАЛЬНИЙ КЛЮЧ                    │
                  │                                                         │
V_bat (+12..24 В) ─────┬────────────────────────────────┬───┐               │
                  │    │                                │   │ Drain         │
                  │ ┌──┴─────────────┐          ┌───────▼───┴─────────────┐ │
                  │ │  Charge Pump   ├─────────►│     Силовий N-MOSFET    ├───► OUT (Навантаження)
                  │ └──┬─────────────┘ V_gate   │     R_ds = 10..50 мОм   │ │
                  │    │                        └───────┬───┬─────────────┘ │
IN (GPIO 3.3 В)   ────►┤ Логічний інтерфейс             │   │ Source        │
                  │    │ і тригер аварії                │   │               │
                  │ ┌──┴─────────────┐                  │   │               │
                  │ │ Захист: КЗ,    │◄─────────────────┘   │               │
                  │ │ T_j > 150 °C,  │                      │               │
                  │ │ Clamping 45 В  │                      │               │
                  │ └──┬─────────────┘                      │               │
                  │    │                        ┌───────────▼─────────────┐ │
IS (Струм/Статус) ◄────┴────────────────────────┤    Струмове дзеркало    │ │
                  │                             │  I_IS = I_LOAD / k_ILIS │ │
                  │                             └─────────────────────────┘ │
GND               ──────────────────────────────────────────────────────────┘
```

1. **Вхідний логічний каскад (IN):** приймає стандартні сигнали рівнів 3.3 В або 5 В безпосередньо з виводу GPIO мікроконтролера. Вхід оснащений тригером Шмітта з гістерезисом та внутрішнім резистором підтяжки до землі, що гарантує надійне закриття ключа під час скидання або переходу піна МК у високоімпедансний стан *(Hi-Z)*.
2. **Помпа заряду (Charge Pump):** внутрішній генератор частотою 100–500 кГц на перемикальних ємностях піднімає напругу живлення затвора до рівня `V_bat + 8..10 В`. Це гарантує повне відкриття силового N-MOSFET з мінімально можливим опором провідності незалежно від коливань бортової напруги.
3. **Силовий перемикач:** вертикальний n-канальний DMOS-транзистор із вбудованим діодом зворотної провідності та каскадом активного обмеження напруги *(active clamp)*. При відключенні індуктивного навантаження внутрішній стабілітрон відкриває канал транзистора при досягненні напруги пробою `V_ds(clamp) ≈ 45..65 В`, розсіюючи енергію індуктивного викиду прямо на кристалі без зовнішнього діода.
4. **Блок діагностики та вимірювання (IS / CS):** вивід струмового дзеркала *(Current Sense)* генерує пропорційний струм `I_IS`, величина якого в точно задану кількість разів `k_ILIS` менша за реальний струм навантаження `I_load`.

## Діагностика та аналоговий струмовий вихід

Традиційне вимірювання струму через виносний шунт на верхньому плечі вимагає окремого спеціалізованого підсилювача *(High-Side Current Sense Amplifier)*, стійкого до високої синфазної напруги. Інтелектуальний ключ формує струмовий сигнал відносно спільної землі схеми завдяки пропорційному відгалуженню частини площі силового каналу транзистора.

Відношення струму навантаження до струму діагностичного виводу позначається як `k_ILIS` *(Current Sense Ratio)*:

```
I_IS = I_load / k_ILIS
```

Типове значення `k_ILIS` для ключів середньої потужності становить від 1000 до 5000. Наприклад, при коефіцієнті `k_ILIS = 2000` та струмі навантаження `I_load = 4 А` вихідний струм піна `IS` дорівнює:

```
I_IS
= 4 А / 2000
= 2 мА
```

Щоб зняти ці дані аналого-цифровим перетворювачем (АЦП) мікроконтролера, між виводом `IS` і землею встановлюють прецизійний вимірювальний резистор `R_IS`. Напруга на вході АЦП обчислюється як:

```
V_IS
= I_IS · R_IS
= (I_load / k_ILIS) · R_IS
```

Якщо опорна напруга АЦП становить 3.3 В, а максимальний робочий струм каналу становить 6 А при `k_ILIS = 2000`:

```
R_IS
= (V_ADC_max · k_ILIS) / I_load_max
= (3.3 В · 2000) / 6 А
= 1100 Ом
```

Обирають найближчий номінал зі стандартного ряду 1% резисторів — 1.1 кОм (або 1.0 кОм із запасом на діапазон вимірювання).

```
                      ┌──────────────────────┐
                      │  Smart Switch (IS)   │
                      └──────────┬───────────┘
                                 │ I_IS
                                 ├─────────────────────────► До піна АЦП МК
                                 │
                               ┌─┴─┐
                               │   │ R_IS (1.0 кОм, 1%)
                               │   │
                               └─┬─┘
                                 │
                                ─── GND
```

### Кодування аварійних станів на піні IS

Крім лінійного вимірювання струму, вивід `IS` передає цифрову діагностику стану каналу:
- **Нормальна робота:** струм `I_IS` лінійно пропорційний струму навантаження в діапазоні від мінімального порогу чутливості до порогу спрацьовування захисту.
- **Обрив навантаження (Open Load):** при увімкненому стані ключа струм не протікає, вихідна напруга підтягується майже до напруги живлення, а вивід `IS` видає нульовий струм (або формує спеціальний рівень струму витоку `I_IS(OL)`).
- **Спрацьовування теплового захисту / Коротке замикання:** внутрішнє джерело струму примусово інжектує у вивід `IS` фіксований аварійний струм несправності `I_IS(fault) ≈ 4..8 мА`. На вимірювальному резисторі `R_IS` формується напруга, що перевищує верхню межу нормального діапазону вимірювання (наприклад, 4.5 В, яка обмежується вхідним захисним діодом МК або стабілітроном), що фіксується прошивкою як апаратна аварія без залучення додаткових ліній зв'язку.

## Апаратний комплекс захисту

Головна перевага інтелектуального перемикача над дискретним польовим транзистором — час реакції на аварійні стани, який становить від одиниць до десятків мікросекунд без жодної участі центрального процесора:

1. **Захист від короткого замикання та перевантаження струму:** у момент різкого падіння опору навантаження швидка схема підсилювача миттєво обмежує струм каналу на рівні `I_L(LIM)` (наприклад, 25 А). Це запобігає руйнуванню провідників друкованої плати та зварюванню контактів роз'ємів.
2. **Температурний захист кристала (Thermal Shutdown):** внутрішній термодатчик вимірює температуру безпосередньо в активній зоні кремнію DMOS-структури. При досягненні критичної позначки `T_j(trip) ≈ 150..175 °C` ключ миттєво знеструмлює навантаження. Відновлення відбувається автоматично після охолодження кристала на величину гістерезису `ΔT_j ≈ 15..20 °C` (режим перезапуску *Restart*) або блокується до перевмикання керуючого сигналу (режим защіпки *Latch*).
3. **Захист від зникнення землі (Loss of Ground):** якщо мінусовий контакт мікросхеми відривається під час роботи, дискретний транзистор може стати некерованим. Інтелектуальний ключ має внутрішній каскад захисту, який у разі втрати власної землі автоматично закриває силовий канал струмом витоку через навантаження.
4. **Захист від зворотної полярності (Reversave / Inverse Current):** при переполюсовці акумулятора ключ або витримує зворотну напругу завдяки вбудованим діодам, або активує інверсну схему відмикання силового каналу для мінімізації нагріву body-діода великим зворотним струмом.

## Практичні обмеження та вибір компонента

Попри універсальність, інтелектуальні ключі мають специфічні фізичні межі застосування:
- **Швидкість комутації та ШІМ:** вбудована помпа заряду має обмежену швидкість накачування ємності затвора. Час увімкнення `t_on` становить типово 20–100 мкс. Через це інтелектуальні ключі загального призначення не розраховані на високочастотну ШІМ (понад 1–5 кГц), оскільки динамічні втрати перемикання перевищать статичні. Їхня стандартна сфера — постійна комутація, плавний пуск або низькочастотний ШІМ-димеринг (100–400 Гц для ламп і нагрівачів).
- **Ціна каналу:** інтегроване рішення дорожче за окремий польовий транзистор, проте окупається вилученням із плати шунтів, підсилювачів, оптопар і тригерів захисту, знижуючи площу друкованої плати в 3–5 разів.
