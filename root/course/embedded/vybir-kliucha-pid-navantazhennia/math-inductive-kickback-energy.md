# 🧮 Енергія індуктивного викиду та час розсіювання в котушці

При розмиканні електричного кола з індуктивним навантаженням (обмотка електромагнітного реле, соленоїд клапана, обмотка крокового чи колекторного двигуна) струм в індуктивності не може змінитися стрибком. Спроба транзисторного ключа обірвати струм за малий проміжок часу `dt` викликає генерацію зворотної електрорушійної сили самоіндукції, яка прагне підтримати протікання струму в попередньому напрямку за законом Фарадея:

```
e = −L · (di/dt)
```

Оскільки тривалість перемикання сучасного польового або біполярного транзистора `dt` становить від десятків наносекунд до одиниць мікросекунд, похідна струму `di/dt` набуває величезного за модулем від'ємного значення. Напруга на закритому комутаторі стрибає до сотень або тисяч вольт. Якщо схема не має спеціалізованих демпферних чи шунтуючих контурів, вся накопичена магнітна енергія виділяється безпосередньо в кремнієвій структурі напівпровідника під час лавинного пробою.

## 1. Баланс накопиченої магнітної енергії

Енергія магнітного поля `E_L`, накопичена в індуктивності `L` при протіканні постійного струму утримання `I_0`, визначається через інтегрування миттєвої електричної потужності `p(t) = u(t) · i(t)` за час наростання струму від 0 до `I_0`:

```
E_L
= ∫ [0..T] p(t) dt                     [означення енергії через інтеграл потужності]
= ∫ [0..I_0] (L · (di/dt) · i) dt      [підстановка напруги самоіндукції u = L·di/dt]
= L · ∫ [0..I_0] i di                  [винесення сталої індуктивності L за знак інтеграла]
= ½ · L · I_0²                         [інтегрування лінійної функції струму]
```

**Числовий розрахунок для типової обмотки автомобільного реле 12 В:**
- Індуктивність котушки у втягнутому стані якоря: `L = 200 мГн = 0.2 Гн`
- Активний опір дроту обмотки: `R_coil = 400 Ом`
- Струм утримання: `I_0 = V_supply / R_coil = 12 В / 400 Ом = 0.03 А = 30 мА`

```
E_L
= ½ · 0.2 Гн · (0.03 А)²               [підстановка параметрів котушки реле]
= 0.1 · 0.0009                         [обчислення квадрата струму]
= 0.00009 Дж = 90 мкДж                 [кінцева енергія магнітного поля]
```

**Числовий розрахунок для потужного гідравлічного соленоїда 24 В:**
- Індуктивність обмотки: `L = 50 мГн = 0.05 Гн`
- Робочий струм котушки: `I_0 = 4 А`

```
E_L
= ½ · 0.05 Гн · (4 А)²                 [підстановка параметрів соленоїда]
= 0.025 · 16                           [обчислення добутку]
= 0.4 Дж                               [кінцева енергія магнітного поля]
```

### Лавинний пробій транзистора (Avalanche Breakdown)
Якщо захисний діод відсутній, у момент вимкнення напруга на стоку транзистора зростає до напруги пробою внутрішнього p-n переходу `V_ds(BR)`. Транзистор переходить у режим лавинної провідності. У даташитах польових транзисторів цей параметр нормується як допустима енергія одиночного лавинного імпульсу *(Single Pulse Avalanche Energy, `E_AS`)*. 

Якщо накопичена енергія `E_L` перевищує паспортне значення `E_AS` (для мініатюрних MOSFET у корпусі SOT-23 величина `E_AS` часто не перевищує 5–20 мДж), кристал локально плавиться від надвисокої густини струму на дефектах кристалічної решітки.

## 2. Гасіння викиду стандартним зворотним діодом (Flyback Diode)

Найпоширеніший спосіб захисту ключа полягає у підключенні напівпровідникового діода паралельно до індуктивності катодом до плюсової шини живлення.

У момент розмикання силового ключа струм індуктивності миттєво перемикається у внутрішній контур, утворений самою котушкою та прямозміщеним діодом. Рівняння контуру за другим законом Кірхгофа:

```
L · (di/dt) + R_coil · i(t) + V_f = 0
```

де `V_f` — прямий спад напруги на відкритому діоді (близько 0.7 В для стандартного кремнієвого діода або 0.35 В для діода Шотткі).

Розв'язок диференціального рівняння для миттєвого струму `i(t)` при початковій умові `i(0) = I_0`:

```
i(t) = (I_0 + V_f / R_coil) · e^(−t / τ) − (V_f / R_coil)
```

де стала часу контуру:

```
τ = L / R_coil
```

Струм спадає до повного нуля за час `t_decay`, коли `i(t_decay) = 0`:

```
(I_0 + V_f / R_coil) · e^(−t_decay / τ) = V_f / R_coil       [умова повного згасання струму i(t)=0]
e^(−t_decay / τ) = (V_f / R_coil) / (I_0 + V_f / R_coil)     [ділення обох частин на амплітудний множник]
t_decay = τ · ln(1 + (I_0 · R_coil) / V_f)                   [логарифмування та вираження t_decay]
```

Враховуючи, що в усталеному режимі `I_0 · R_coil = V_supply`:

```
t_decay = (L / R_coil) · ln(1 + V_supply / V_f)
```

**Приклад обчислення часу розряду з діодом 1N4007 (`V_f = 0.7 В`):**
Для котушки реле з `L = 0.2 Гн`, `R_coil = 400 Ом`, `V_supply = 12 В`:

```
τ = 0.2 Гн / 400 Ом = 0.0005 с = 0.5 мс                      [обчислення сталої часу кола]
t_decay
= 0.5 мс · ln(1 + 12 В / 0.7 В)                              [підстановка параметрів схеми]
= 0.5 мс · ln(1 + 17.143)                                    [ділення напруг]
= 0.5 мс · ln(18.143)                                        [додавання одиниці під логарифмом]
= 0.5 мс · 2.898                                             [обчислення натурального логарифма]
≈ 1.45 мс                                                    [кінцевий час спадання струму]
```

### Фізична проблема повільного згасання струму
Оскільки прямий спад напруги на діоді `V_f ≈ 0.7 В` є малим порівняно з напругою живлення 12 В, майже вся магнітна енергія розсіюється на активному опорі мідного дроту самої котушки `R_coil`. Спад магнітного потоку відбувається мляво. 

Для електромагнітного реле це створює критичну небезпеку: механічний якір відходить від магнітопроводу дуже повільно. У момент розриву контактів швидкість розходження поверхонь низька, між ними запалюється електрична дуга, що плавить металеві напайки контактів, викликає їхню ерозію та скорочує комутаційний ресурс з 100 000 спрацьовувань до кількох тисяч.

## 3. Прискорене гасіння: діод + стабілітрон (Zener Clamp)

Для скорочення часу відпускання котушки послідовно із захисним діодом зустрічно вмикають стабілітрон (або супресор TVS) з напругою стабілізації `V_z`.

```
          + V_supply (12 В) ──────┐
              │                   │
           [ КОТУШКА ]          ┌─┴─┐ Діод (катод до +)
              │                 └─┬─┘
              │                   ├──────┐
              │                 ┌─┴─┐    │ V_clamp = V_z + V_f
              │                 ▲ Z │    │
              │                 └─┬─┘    │
              ├───────────────────┴──────┘
           [ КЛЮЧ ]
              │
             GND
```

У момент розмикання ключа напруга на колекторі або стоку транзистора фіксується на безпечному рівні:

```
V_switch = V_supply + V_z + V_f
```

Напруга обмеження на виводах самої індуктивності становить:

```
V_clamp = V_z + V_f
```

Рівняння розряду набуває вигляду:

```
L · (di/dt) = − (V_clamp + R_coil · i(t))
```

Оскільки напруга стабілітрона `V_z` (наприклад, 24..36 В) значно перевищує спад на активному опорі обмотки `R_coil · i(t)`, спадання струму відбувається майже лінійно з постійною швидкістю:

```
di/dt ≈ − V_clamp / L
```

Час повного згасання струму скорочується до:

```
t_fast_decay
≈ (L · I_0) / V_clamp
= (L · I_0) / (V_z + V_f)
```

**Порівняльний розрахунок часу згасання зі стабілітроном `V_z = 33 В`:**

```
t_fast_decay
= (0.2 Гн · 0.03 А) / (33 В + 0.7 В)                         [підстановка значень для схеми з Zener]
= 0.006 / 33.7                                               [обчислення добутку L·I_0]
≈ 0.000178 с = 0.18 мс                                       [час повного згасання струму]
```

Час гасіння зменшився з 1.45 мс до 0.18 мс — **у 8 разів швидше**. Механічні контакти реле розмикаються миттєво під дією зворотної пружини, запобігаючи зварюванню та перегріву контактної групи. При цьому транзистор повинен мати запас по напрузі `V_ds_max > 12 В + 33 В + 0.7 В = 45.7 В` (застосовують транзистори на 55–60 В, наприклад IRLZ44N).

## 4. Демпферний RC-ланцюжок (Snubber) для ШІМ та змінного струму

У колах керування електродвигунами або при комутації змінного струму, де застосування однополярного діода неможливе, паралельно ключу або котушці встановлюють послідовний RC-демпфер *(Resistor-Capacitor Snubber)*.

```
                + VCC ──────────────┐
                  │                 │
              [ КОТУШКА L ]       ┌─┴─┐ R_s
                  │               │   │
                  │               └─┬─┘
                  │                 ├───── RC-ланцюжок
                  │               ┌─┴─┐
                  │               ─── C_s
                  │               ───
                  │                 │
                  ├─────────────────┘
              [  КЛЮЧ  ]
                  │
                 GND
```

Конденсатор `C_s` поглинає струмовий сплеск у перші наносекунди розриву кола, обмежуючи швидкість наростання напруги `dv/dt`, а резистор `R_s` забезпечує розсіювання коливальної енергії та демпфує резонансний LC-контур.

### Крок 1. Розрахунок мінімальної ємності `C_s`
Ємність демпфера розраховують з умови повного поглинання магнітної енергії `E_L` без перевищення пікової допустимої напруги на ключі `V_max`:

```
½ · C_s · (V_max − V_supply)² ≥ ½ · L · I_0²                 [баланс енергії котушки та конденсатора]
C_s ≥ (L · I_0²) / (V_max − V_supply)²                       [вираження ємності C_s]
```

### Крок 2. Розрахунок демпферного резистора `R_s`
Для запобігання високочастотним автоколиванням контур повинен мати коефіцієнт згасання `ζ ≥ 1` (критичне демпфування):

```
ζ = (R_s / 2) · √(C_s / L) = 1                               [умова критичного демпфування коливань]
R_s = 2 · √(L / C_s)                                         [розрахунковий опір демпферного резистора]
```

На практиці номінал обирають у межах `R_s ≈ (1..2) · √(L / C_s)`.

### Крок 3. Теплова потужність розсіювання на резисторі `P_R`
При роботі ключа в режимі ШІМ на частоті `f_sw` конденсатор `C_s` перезаряджається двічі за період. Потужність, що безперервно розсіюється на резисторі:

```
P_R = C_s · V_supply² · f_sw
```

Якщо `C_s = 10 нФ`, `V_supply = 24 В`, `f_sw = 20 кГц`:

```
P_R
= 10·10⁻⁹ Ф · (24 В)² · 20000 Гц                             [підстановка параметрів демпфера]
= 10·10⁻⁹ · 576 · 20000                                      [обчислення квадрата напруги]
= 0.115 Вт                                                   [необхідна потужність розсіювання резистора]
```

Для такого режиму обирають резистор потужністю не менше 0.25–0.5 Вт у безіндуктивному товстоплівковому виконанні.
