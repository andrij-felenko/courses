# Математична модель оптимізації шпаруватості

Енергетичний розрахунок автономного бездротового вузла спирається на інтегрування профілю струму в часі та знаходження балансу між енергією активного імпульсу та енергією фази сну. Математична формалізація цього процесу дозволяє визначити асимптотичні межі енергозбереження, обчислити точку енергетичного паритету, врахувати нелінійні втрати хімічного джерела живлення, оцінити ефективність пакетування вимірювань та знайти оптимальний період виходу на зв'язок за заданим критерієм ефективності.

## Загальне інтегральне формулювання середнього струму

Миттєвий струм споживання вбудованої системи є періодичною функцією часу `i(t)` з періодом `T`. Електричний заряд `Q`, вилучений з джерела живлення за один повний цикл, визначається визначеним інтегралом:

```
Q = ∫₀ᵀ i(t) dt      [повний інтегральний заряд за один період T]
```

Якщо розбити період `T` на активний інтервал `[0, t_on]` та сплячий інтервал `[t_on, T]`:

```
Q = ∫₀^{t_on} i_active(t) dt + ∫_{t_on}^T i_sleep(t) dt
```

Вважаючи струм сну постійною величиною `i_sleep(t) = I_sleep`, а активну фазу характеризуючи еквівалентним середнім активним струмом:

```
I_on = (1 / t_on) · ∫₀^{t_on} i_active(t) dt
```

Отримуємо точний вираз для середнього інтегрального струму `I_avg`:

```
I_avg = Q / T
      = (1 / T) · [ I_on · t_on + I_sleep · (T - t_on) ]  [підстановка інтегралів фаз]
      = I_on · (t_on / T) + I_sleep · (1 - t_on / T)      [розкриття дужок і групування за T]
```

Позначаючи безрозмірний коефіцієнт шпаруватості `D = t_on / T`:

```
I_avg(D) = I_on · D + I_sleep · (1 - D)
         = (I_on - I_sleep) · D + I_sleep                 [лінійна функція відносно шпаруватості D]
```

## Дослідження граничної поведінки при розтягуванні періоду

Розглянемо поведінку середнього струму `I_avg` як функції періоду `T` при фіксованій тривалості активного спалаху `t_on`:

```
I_avg(T) = (I_on - I_sleep) · t_on / T + I_sleep
```

Обчислимо границю функції при прямуванні періоду до нескінченності:

```
lim_{T → ∞} I_avg(T)
= lim_{T → ∞} [ (I_on - I_sleep) · t_on · (1 / T) + I_sleep ]
= (I_on - I_sleep) · t_on · 0 + I_sleep
= I_sleep                                                 [асимптотична межа струму]
```

Звідси випливає фундаментальний наслідок: жодне збільшення періоду сну не здатне знизити середній струм системи нижче апаратного струму спокою `I_sleep`.

## Чутливість середнього струму та спадна ефективність оптимізації

Знайдемо першу похідну функції середнього струму за періодом `T`:

```
d(I_avg) / dT
= d/dT [ (I_on - I_sleep) · t_on · T⁻¹ + I_sleep ]
= - (I_on - I_sleep) · t_on · T⁻²
= - (I_on - I_sleep) · t_on / T²                          [швидкість зміни струму від періоду]
```

Оскільки `I_on > I_sleep`, похідна строго від'ємна (`d(I_avg)/dT < 0`), що підтверджує монотонне спадання струму зі зростанням `T`.

Знайдемо другу похідну функції `I_avg(T)`:

```
d²(I_avg) / dT²
= d/dT [ - (I_on - I_sleep) · t_on · T⁻² ]
= 2 · (I_on - I_sleep) · t_on · T⁻³
= 2 · (I_on - I_sleep) · t_on / T³                        [опуклість функції графіка струму]
```

Оскільки друга похідна строго додатна (`d²(I_avg)/dT² > 0`) для всіх `T > 0`, функція `I_avg(T)` є строго опуклою. Це математично доводить закон спадної віддачі: абсолютне зменшення струму `|ΔI_avg|` на кожен фіксований приріст інтервалу `ΔT` зменшується пропорційно кубу періоду `T³`.

## Критерії визначення точок перегину та насичення

Введемо коефіцієнт енергетичного співвідношення фаз `k`:

```
k = Q_sleep / Q_active
  = (I_sleep · t_off) / (I_on · t_on)        [підстановка зарядів фаз]
  = (I_sleep · (T - t_on)) / (I_on · t_on)  [заміна тривалості сну через t_off = T - t_on]
```

При малих значеннях шпаруватості (`t_on ≪ T`), наближено:

```
k ≈ (I_sleep · T) / (I_on · t_on)            [наближення для t_on ≪ T]
```

Розв'язуючи це рівняння відносно `T` для різних значень `k`:

1. **Точка паритету енергій (`k = 1`):**
   ```
   T_parity = (I_on · t_on) / I_sleep                     [період однакових витрат на роботу і сон]
   ```
   У цій точці рівно 50% енергії батареї витрачається на корисну активність, а 50% — на підтримку режиму сну.

2. **Точка практичного насичення 90% (`k = 9`):**
   ```
   T_90 = 9 · (I_on · t_on) / I_sleep                     [період 90% домінування струму сну]
   ```
   У цій точці 90% енергії батареї з'їдає струм сну, і лише 10% йде на передачу даних.

3. **Точка граничного насичення 95% (`k = 19`):**
   ```
   T_95 = 19 · (I_on · t_on) / I_sleep                    [період 95% домінування струму сну]
   ```

## Математичне обґрунтування пакетування вимірювань

При періодичному моніторингу виникає питання: чи слід надсилати кожен вимір одразу після отримання, чи вигідніше накопичувати `N` вимірів у буфері оперативної пам'яті та передавати їх одним об'єднаним пакетом?

Кожен сеанс бездротового зв'язку містить фіксовані накладні витрати енергії `E_overhead`, які не залежать від розміру корисних даних: розгін кварцу, вихід синтезатора частоти на режим, випромінювання радіопреамбули та очікування квитанції ACK:

```
E_overhead = I_wu · t_wu · V + I_preamble · t_preamble · V + I_rx · t_ack_wait · V
```

Корисна енергія передачі залежить від обсягу корисного навантаження:

```
E_payload(L) = I_tx · (L · 8 / R_bit) · V                 [енергія передачі L байтів даних]
```

Порівняємо енергетичні витрати для двох стратегій отримання `N` вимірювань:

**Стратегія A: Негайне надсилання кожного виміру (`N` окремих пакетів).**
Кожен пакет містить заголовок `L_hdr` (наприклад, 13 байтів) та один вимір `L_sample` (наприклад, 4 байти):

```
E_separate = N · [ E_overhead + E_payload(L_hdr + L_sample) ]
```

**Стратегія B: Пакетоване надсилання (`1` об'єднаний пакет із `N` вимірами).**
Один пакет містить один заголовок `L_hdr` та масив із `N` вимірів `N · L_sample`:

```
E_bundled = E_overhead + E_payload(L_hdr + N · L_sample)
```

Обчислимо абсолютну економію енергії від пакетування:

```
ΔE = E_separate - E_bundled
   = (N - 1) · E_overhead + (N - 1) · E_payload(L_hdr)    [виграш від усунення повторних накладних витрат]
```

Оскільки накладні витрати `E_overhead` у протоколах LoRaWAN або NB-IoT становлять від 60% до 85% усієї енергії передачі короткого повідомлення, пакетування `N = 10` відліків скорочує сумарну енергію радіообміну в 4–7 разів порівняно з поштучною передачею.

## Модель нелінійного розряду хімічного джерела живлення

У спрощених розрахунках ємність батареї вважається незмінною константою `C_nom`. У реальних умовах ефективна віддана ємність `C_eff` зменшується під дією трьох фізичних факторів:
1. **Саморозряд батареї:** річна втрата заряду через внутрішні хімічні реакції зі швидкістю `alpha_self` (%/рік).
2. **Температурний коефіцієнт `k_temp`:** падіння рухливості іонів електроліту при мінусових температурах.
3. **Імпульсне просідання напруги на внутрішньому опорі `R_int`:** під час активного імпульсу струм `I_pulse` викликає спад напруги `ΔV = I_pulse · R_int`. Коли напруга на виводах падає нижче порогу вимкнення мікроконтролера `V_cutoff` (Brown-out Reset), пристрій перезавантажується ще до вичерпання хімічної ємності.

Математична модель ефективної корисної ємності за період експлуатації `L_years`:

```
C_eff = C_nom · k_temp · (1 - alpha_self · L_years) · eta_cutoff      [розрахунок реальної ємності]
```

де `eta_cutoff` — коефіцієнт використання розрядної кривої до моменту спрацьовування захисту від просідання:

```
V_cell_min = V_cutoff + I_pulse · R_int                               [мінімальна напруга ХХ елемента]
```

Якщо для батарейки CR2032 з внутрішнім опором `R_int = 15 Ом` імпульсний струм передавача становить `I_pulse = 30 мА`, спад напруги дорівнює:

```
ΔV = 0.030 А · 15 Ом
   = 0.45 В                                                           [падіння напруги на внутрішньому опорі]
```

Якщо поріг перезавантаження мікроконтролера становить `V_cutoff = 2.0 В`, батарейка виявиться «розрядженою» в момент, коли напруга холостого ходу впаде до `2.0 В + 0.45 В = 2.45 В`, залишивши невикористаними до 30% залишкового заряду.

## Модель буферного накопичувача для безакумуляторних систем

У системах збору енергії з довкілля (Energy Harvesting: сонячні елементи, п'єзогенератори, термоелементи) джерело генерує малий безперервний струм `I_harv` (10–100 мкА), якого недостатньо для прямого живлення передавача під час спалаху (50 мА). Енергія накопичується в буферному конденсаторі або іоністорі ємністю `C_buf`.

Розрахунок мінімальної ємності накопичувача базується на законі збереження енергії: енергія, віддана конденсатором при розряді від робочої напруги `V_max` до мінімальної `V_min`, має покривати активний імпульс:

```
E_cap = 0.5 · C_buf · (V_max² - V_min²)                               [корисна енергія накопичувача]
E_active = I_on · V_avg · t_on                                        [енергія активного імпульсу]
```

Прирівнюючи енергії:

```
0.5 · C_buf · (V_max² - V_min²) ≥ I_on · V_avg · t_on

C_buf ≥ (2 · I_on · V_avg · t_on) / (V_max² - V_min²)                 [формула розрахунку буферного конденсатора]
```

Час накопичення заряду між спалахами (мінімальний період циклу `T_harvest`):

```
T_harvest = C_buf · (V_max - V_min) / I_harv                          [час заряду від джерела збору енергії]
```

## Числовий приклад розрахунку точок насичення

Нехай бездротовий датчик має параметри:
- `I_on = 50 мА = 50000 мкА`
- `t_on = 20 мс = 0.020 с`
- `I_sleep = 2.5 мкА`

Активний заряд за один сеанс зв'язку:

```
Q_on = 50000 мкА · 0.020 с
     = 1000 мкА·с                                                     [добуток активного струму на час імпульсу]
```

Обчислимо критичні періоди циклу:

```
T_parity = 1000 мкА·с / 2.5 мкА
         = 400 с
         ≈ 6.67 хвилини    [до 6.67 хв домінує активний передавач]

T_90     = 9 · 400 с
         = 3600 с
         = 1.0 година      [при періоді 1 год 90% заряду йде на сон]

T_95     = 19 · 400 с
         = 7600 с
         ≈ 2.11 години     [при періоді 2.11 год 95% заряду йде на сон]
```

Порівняємо середній струм для різних періодів:
- При `T = 6.67 хв (400 с)`: `I_avg = (1000 + 2.5 · 400) / 400 = 2000 / 400 = 5.0 мкА`.
- При `T = 1.0 год (3600 с)`: `I_avg = (1000 + 2.5 · 3600) / 3600 = 10000 / 3600 ≈ 2.78 мкА`.
- При `T = 24.0 год (86400 с)`: `I_avg = (1000 + 2.5 · 86400) / 86400 = 217000 / 86400 ≈ 2.51 мкА`.

Перехід від періоду 1 година до періоду 24 години (збільшення паузи у 24 рази) зменшує середній струм лише з 2.78 мкА до 2.51 мкА (виграш всього 0.27 мкА, або менше 10% автономності), практично ліквідуючи цінність вимірювального приладу як джерела оперативних даних.
