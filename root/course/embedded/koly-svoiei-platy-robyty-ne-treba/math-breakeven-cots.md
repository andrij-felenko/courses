# 🧮 Розрахунок точки беззбитковості: власна плата проти COTS

Цей математичний апарат формалізує фінансово-інженерне порівняння між закупівлею готового серійного промислового виробу (COTS — Commercial Off-The-Shelf) та розробкою власної друкованої плати (Custom PCB), визначаючи точний тираж беззбитковості та фінансові ризики затримки виходу на ринок.

## Математична модель сукупної вартості володіння (TCO)

Сукупні витрати на випуск тиражу з `N` пристроїв складаються з двох компонентів: одноразових фіксованих інженерних витрат (NRE — Non-Recurring Engineering) та змінних витрат на виробництво кожної одиниці виробу (Unit Cost):

```
TCO(N) = NRE + N · C_unit
```

### Складові для готового COTS-блоку

Для серійного промислового модуля (ПЛК, готовий шлюз на DIN-рейку, смарт-давач) фіксовані інженерні витрати зведені до мінімуму, оскільки схемотехніка, топологія, розведення друкованої плати, тестування та сертифікація вже виконані й оплачені виробником:

```
NRE_cots = T_cfg · R_eng + C_eval + C_mount_nre
```
де:
* `T_cfg` — час на конфігурацію, параметризацію та інтеграцію готового блоку в систему (години);
* `R_eng` — погодинна ставка інженера-інтегратора ($/год);
* `C_eval` — вартість одного-двох тестових зразків для лабораторної оцінки ($);
* `C_mount_nre` — проектування простого монтажного кронштейна чи кабельного джгута ($).

Змінна собівартість одиниці COTS:
```
C_unit_cots = P_cots + C_mount_hw + T_install · R_tech
```
де:
* `P_cots` — ціна закупівлі готового пристрою в дистриб'ютора ($);
* `C_mount_hw` — вартість монтажних елементів (DIN-рейка, роз'єми, кабель) ($);
* `T_install` — час монтажу та підключення стандартного блока (години);
* `R_tech` — погодинна ставка монтажника ($/год).

### Складові для власної плати (Custom PCB)

Для власної розробки фіксовані витрати NRE включають повний цикл створення радіоелектронної апаратури:

```
NRE_custom = NRE_rd + NRE_proto + NRE_test + NRE_cert + NRE_sw
```

Розгорнута структура кожного члена NRE:

1. **Інженерна розробка апаратури (R&D):**
```
NRE_rd = (T_sch + T_pcb + T_sim + T_dfm) · R_hw_eng
```
де `T_sch` — розробка електричної принципової схеми (40–120 год), `T_pcb` — трасування багатошарової плати (60–160 год), `T_sim` — моделювання цілісності сигналів та живлення (20–40 год), `T_dfm` — підготовка до виробництва за вимогами фабрики (20–30 год), `R_hw_eng` — ставка провідного схемотехніка-трасувальника ($40–$100/год).

2. **Ітерації прототипів заліза (Rev A, Rev B, Rev C):**
```
NRE_proto = k_iter · (C_pcb_fab + C_smd_setup + C_proto_bom + C_proto_labor)
```
де `k_iter` — кількість необхідних ітерацій виправлення помилок (типово `k_iter = 2` або `3`), `C_pcb_fab` — експрес-виготовлення плат ($300–$1500), `C_smd_setup` — підготовка трафарету та налаштування лінійки SMD-монтажу ($400–$1200), `C_proto_bom` — закупівля компонентів для прототипів за роздрібними цінами ($500–$2000), `C_proto_labor` — налагодження та запуск ревізії на столі інженера (30–80 год).

3. **Виробнича тестувальна інфраструктура:**
```
NRE_test = C_jig_hw + T_jig_sw · R_sw_eng
```
де `C_jig_hw` — виготовлення стенда тестових голок (pogo-pin test fixture, $1500–$6000), `T_jig_sw` — написання мікропрограми функціонального вихідного тестування (40–100 год).

4. **Обов'язкова регуляторна сертифікація:**
```
NRE_cert = C_lab_emc + C_lab_safety + C_lab_rf + k_cert_fail · C_retest
```
де `C_lab_emc` — випробування на електромагнітну сумісність EMC/EMI ($4000–$12000), `C_lab_safety` — низьковольтна безпека LVD/UL ($3000–$8000), `C_lab_rf` — сертифікація радіоінтерфейсів RED/FCC ($8000–$25000), `k_cert_fail` — коефіцієнт повторного тестування у разі перевищення норм випромінювання (0.3–0.6).

5. **Базове програмне забезпечення (BSP):**
```
NRE_sw = (T_bsp + T_drivers + T_bringup) · R_fw_eng
```
де розробка платоспецифічних драйверів та низькорівневого коду ініціалізації вимагає 80–240 годин роботи embedded-розробника.

Змінна собівартість власної плати на одиницю виробу:
```
C_unit_custom = (BOM_chips + BOM_passives + BOM_connectors) · (1 + k_scrap)
                + C_pcb_unit + C_smd_unit + C_box_custom
                + T_test_unit · R_tech + C_warranty_risk
```
де:
* `k_scrap` — технологічний коефіцієнт браку монтажу та пошкодження компонентів (зазвичай 2–5%, тобто `k_scrap = 0.02..0.05`);
* `C_pcb_unit` — вартість «голого» текстоліту в серійній панелі ($2–$10);
* `C_smd_unit` — вартість автоматичного поверхневого монтажу компонентів ($3–$12);
* `C_box_custom` — власний корпус, фрезерування отворів або прес-форма ($5–$35);
* `T_test_unit` — час тестування та прошивки на стенді (3–8 хв = 0.05–0.13 год);
* `C_warranty_risk` — резерв на гарантійне обслуговування польових відмов:
```
C_warranty_risk = P_fail · (C_service_trip + C_unit_custom)
```
де `P_fail` — статистична ймовірність польової відмови протягом гарантійного терміну (типово 0.02–0.05 для нових невідпрацьованих дизайнів), `C_service_trip` — вартість виїзду сервісного інженера для заміни плати на об'єкті ($200–$800).

## Виведення формули точки беззбитковості (Break-even Volume)

Точка беззбитковості `N_BEP` — це мінімальний обсяг тиражу, за якого сукупні витрати на власну розробку стають рівними сукупним витратам на закупівлю COTS-рішення:

```
TCO_custom(N_BEP) = TCO_cots(N_BEP)
```

Покрокове алгебраїчне виведення:

```
NRE_custom + N_BEP · C_unit_custom = NRE_cots + N_BEP · C_unit_cots   [початкова рівність TCO]
NRE_custom - NRE_cots = N_BEP · C_unit_cots - N_BEP · C_unit_custom   [групування NRE зліва, змінних справа]
NRE_custom - NRE_cots = N_BEP · (C_unit_cots - C_unit_custom)         [винесення N_BEP за дужки]
N_BEP = (NRE_custom - NRE_cots) / (C_unit_cots - C_unit_custom)       [ділення на дельту одиничної вартості]
```

Остаточна аналітична формула:

```
N_BEP = ΔNRE / ΔC_unit
```
де `ΔNRE = NRE_custom - NRE_cots` — додаткові фіксовані інвестиції в R&D, оснастку та сертифікацію власної плати;
`ΔC_unit = C_unit_cots - C_unit_custom` — маржинальна економія на виробництві кожної фізичної одиниці заліза.

### Умова фізичної здійсненності

Проект власної плати має економічний сенс лише за виконання двох фундаментальних умов:

1. `C_unit_custom < C_unit_cots` (тобто `ΔC_unit > 0`). Якщо через малі серії, дорогі корпуси чи складний ручний монтаж собівартість власної плати виявиться вищою або рівною ціні COTS, знаменник прямує до нуля або стає від'ємним — власна плата **не окупиться ні за якого тиражу**.
2. Запланований життєвий обсяг випуску `N_total > N_BEP`. Якщо реальний попит на виріб менший за `N_BEP`, кожен вироблений екземпляр генерує чистий збиток порівняно з COTS.

## Числовий розрахунок на трьох прикладних сценаріях

Розгляньмо типову інженерну задачу: створення системи моніторингу вібрації та температури промислових насосних агрегатів (4 канали АЦП 24-біт, інтерфейс RS-485 Modbus RTU, ізольоване живлення 24 В, монтаж на DIN-рейку в шафі керування).

### Вихідні фінансові параметри моделей

**Параметри COTS-варіанту:**
* Готовий модуль збору даних на DIN-рейку (Advantech / ICP DAS / Seneca): `P_cots = $320`;
* Кабельний монтаж та параметризація: `C_mount_hw = $15`, `T_install · R_tech = 0.5 год · $30/год = $15`;
* Разом `C_unit_cots = $320 + $15 + $15 = $350`;
* Початкова інтеграція в систему та написання конфігуратора: `NRE_cots = 40 год · $50/год + 2 зразки = $2000 + $640 = $2640`.

**Параметри власної плати (Custom PCB):**
* Прямий BOM (MCU STM32, 24-бітний АЦП, ізолятори ADuM, DC-DC перетворювач, клемники Phoenix Contact, захисні TVS): `$32.00`;
* Врахування браку 3%: `$32.00 · 1.03 = $32.96`;
* 4-шаровий склотекстоліт FR-4 (серія 500 шт): `$3.50`;
* Автоматичний SMD-монтаж: `$7.50`;
* Пластиковий корпус на DIN-рейку (D-Sub / Phoenix): `$8.00`;
* Тестування на стенді (5 хв): `0.083 год · $30/год = $2.50`;
* Гарантійний резерв (3% відмов при ціні заміни $250): `0.03 · $250 = $7.50`;
* Разом `C_unit_custom = 32.96 + 3.50 + 7.50 + 8.00 + 2.50 + 7.50 = $61.96 ≈ $62.00`.
* Економія на одиниці: `ΔC_unit = $350 - $62 = $288.00`.

**Витрати NRE на власну плату:**
* Схемотехніка та трасування: 160 год · $50/год = `$8,000`;
* 2 ітерації прототипів (Rev A + Rev B): `$4,200`;
* Проектування та збірка test fixture (pogo-pins): `$3,500`;
* Базова сертифікація EMC/LVD (промислова зона EN 61000-6-2 / EN 61000-6-4): `$11,500`;
* Розробка прошивки та драйверів АЦП: 120 год · $50/год = `$6,000`;
* Разом `NRE_custom = 8000 + 4200 + 3500 + 11500 + 6000 = $33,200`.
* Дельта інвестицій: `ΔNRE = $33,200 - $2,640 = $30,560`.

### Розрахунок точки беззбитковості:

```
N_BEP = $30,560 / $288 = 106.11 ≈ 107 штук
```

Порівняння витрат для трьох різних масштабів виробництва подано нижче:

```
Порівняння сукупних витрат TCO для трьох тиражів:
┌──────────┬──────────────────────┬──────────────────────┬──────────────────────┐
│  Тираж   │      Варіант COTS    │ Варіант Custom PCB   │  Різниця (Custom vs  │
│    N     │ NRE ($2.6k) + N·$350 │ NRE ($33.2k) + N·$62 │        COTS)         │
├──────────┼──────────────────────┼──────────────────────┼──────────────────────┤
│ 30 шт    │ $13,140 ($438/шт)    │ $35,060 ($1,168/шт)  │ Збиток: −$21,920     │
│ 107 шт   │ $40,090 ($374/шт)    │ $39,834 ($372/шт)    │ Паритет (Break-even) │
│ 500 шт   │ $177,640 ($355/шт)   │ $64,200 ($128/шт)    │ Економія: +$113,440  │
│ 3000 шт  │ $1,052,640 ($351/шт) │ $219,200 ($73/шт)    │ Економія: +$833,440  │
└──────────┴──────────────────────┴──────────────────────┴──────────────────────┘
```

### Висновки з моделі:

1. **При тиражі 30 штук** власна розробка є комерційною катастрофою: реальна собівартість однієї плати з урахуванням амортизації R&D складає **$1,168** проти **$438** у COTS. Чистий прямий збиток компанії — майже $22,000.
2. **Точка перегину лежить на відмітці ~107 штук.** Лише після випуску 108-ї плати компанія починає отримувати реальну економічну віддачу від створення власного заліза.
3. **При тиражі 500+ штук** власна плата окупає всі ризики та дає шестизначну економію коштів, повністю виправдовуючи витрати на сертифікацію та стенди.

## Фактор часу: розрахунок ціни затримки (Cost of Delay)

Класична формула `N_BEP` розглядає витрати у статичному просторі. Проте в реальному бізнесі розробка власної плати вимагає **7–11 місяців**, тоді як інтеграція COTS-рішення займає **1–2 місяці**.

Затримка виходу виробу на ринок на `ΔT` місяців створює втрачену вигоду (Cost of Delay, `CoD`), яка включає неотриману виручку від продажу абонентських послуг чи експлуатації обладнання:

```
CoD = ΔT · (M_units_per_month · Rev_per_unit + Lost_Contract_Value)
```
де `M_units_per_month` — щомісячний темп підключення нових клієнтів, `Rev_per_unit` — щомісячний дохід з одиниці, `Lost_Contract_Value` — штрафи за зрив термінів здачі промислового об'єкта.

Скоригована точка беззбитковості з урахуванням дисконтованого часу та втраченої вигоди:

```
N_BEP_dynamic = (ΔNRE + CoD) / ΔC_unit
```

Якщо затримка на 6 місяців коштує компанії $45,000 втраченого операційного прибутку, динамічна точка беззбитковості зміщується:

```
N_BEP_dynamic = ($30,560 + $45,000) / $288 = $75,560 / $288 ≈ 263 штуки
```

Врахування часового фактора збільшує поріг доцільності власної плати більш ніж удвічі: проекти з тиражем до 250–300 штук на рік при наявності ринкового вікна повинні беззастережно реалізовуватися на базі готових COTS-блоків.
