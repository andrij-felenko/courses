# 🧮 Геометрична прогресія рядів номіналів E6–E192

Коли інженерний розрахунок електронного кола дає точне значення опору на зразок `348.6 Ом` чи ємності `4.17 нФ`, на практиці неможливо знайти пасивний компонент з таким випадковим числом. Усі резистори, конденсатори та індуктивності промислового виготовлення випускаються за стандартизованими рядами номіналів (міжнародний стандарт IEC 60063). В основі побудови цих рядів лежить логарифмічний закон: номінали формують геометричну прогресію, де знаменник кроку прямо пов'язаний із виробничим допуском і забезпечує взаємне перекриття полів похибки сусідніх значень без прогалин і надлишкового дублювання. Лінійна сітка номіналів була б технологічно й економічно непридатною для масового виробництва, тоді як геометрична шкала дозволяє покрити будь-який діапазон мінімальною кількістю типономіналів та однозначно визначає систему кодового маркування прецизійних компонентів EIA-96.

### Чому лінійний крок непридатний для номіналів

Уявімо, що номінали резисторів виготовлялися б із постійним лінійним кроком, наприклад `ΔR = 10 Ом`. Тоді в діапазоні від `10 Ом` до `100 Ом` ми мали б набір значень `10, 20, 30, 40, ..., 100 Ом`.

Погляньмо на відносну різницю між сусідніми значеннями на початку і в кінці шкали опорів:

```text
δ_10 = (20 − 10) / 10
     = 10 / 10         [абсолютний приріст на початку шкали]
     = 1.00            [відносний крок становить +100%]

δ_1000 = (1010 − 1000) / 1000
       = 10 / 1000     [той самий абсолютний приріст у кінці шкали]
       = 0.01          [відносний крок становить лише +1%]
```

Виникає фундаментальна невідповідність. На малих опорах крок між сусідніми номіналами величезний (стрибок у два рази, `+100%`), що створює гігантські прогалини у виборі. Натомість на великих опорах той самий крок стає надлишково густим (`+1%` і менше). Щоб покрити діапазон від `1 Ом` до `10 МОм` з кроком `1 Ом`, фабриці знадобилося б виготовити десять мільйонів окремих типів резисторів, більшість з яких відрізнялися б на мізерні частки відсотка.

В інженерних розрахунках важлива не абсолютна різниця `ΔR`, а **відносна роздільна здатність**:

```text
ΔR / R = const         [відносний крок має бути сталим у будь-якій точці шкали]
```

Якщо відносний крок однаковий, то в логарифмічному просторі відстань між будь-якими двома сусідніми номіналами є строго сталою величиною:

```text
log10(R[k+1]) − log10(R[k]) = const = 1 / N
```

де `N` — кількість номіналів у межах однієї декади (від `1` до `10`, від `10` до `100`, від `100` до `1000` тощо).

### Виведення знаменника геометричної прогресії Ренара

Ідея логарифмічного структурування параметричних рядів належить французькому військовому інженеру Шарлю Ренару (фр. *Charles Renard*), який у 1870-х роках запропонував геометричну прогресію для стандартизації товщини канатів для повітроплавання. Згодом Міжнародна електротехнічна комісія (IEC) поклала цей принцип в основу стандарту IEC 60063 для електронних компонентів.

Ряд значень у межах однієї декади утворює геометричну прогресію з початковим членом `R₀ = 1` і кінцевим членом `R_N = 10`.

Позначимо знаменник прогресії як `r`. Тоді кожен наступний номінал виражається через попередній:

```text
R[k] = R₀ · rᵏ = 1 · rᵏ
```

Оскільки `N`-й крок повинен точно давати початок наступної декади `10`:

```text
R[N] = rᴺ = 10
r = 10^(1 / N)         [знаменник геометричної прогресії Ренара]
```

Отже, теоретичне значення `k`-го номіналу в декаді обчислюється за формулою:

```text
R[k] = 10^(k / N)      [де k = 0, 1, 2, ..., N−1]
```

Відносний крок між двома сусідніми номіналами `R[k]` та `R[k+1]` дорівнює:

```text
ΔR / R[k] = (R[k+1] − R[k]) / R[k]
          = (10^((k+1)/N) − 10^(k/N)) / 10^(k/N)  [підстановка формули прогресії]
          = 10^(1/N) − 1                          [скорочення на 10^(k/N)]
```

Обчислімо точний відносний крок для всіх стандартизованих рядів IEC 60063:

* **Ряд E6 (`N = 6`):**
```text
r = 10^(1/6)
  ≈ 1.4678             [знаменник прогресії для 6 значень]
ΔR / R ≈ 46.8%         [типовий для електролітичних конденсаторів з допуском ±20%]
```

* **Ряд E12 (`N = 12`):**
```text
r = 10^(1/12)
  ≈ 1.2115             [знаменник прогресії для 12 значень]
ΔR / R ≈ 21.15%        [стандарт для компонентів з допуском ±10%]
```

* **Ряд E24 (`N = 24`):**
```text
r = 10^(1/24)
  ≈ 1.1007             [знаменник прогресії для 24 значень]
ΔR / R ≈ 10.07%        [стандарт для резисторів 5% та керамічних конденсаторів]
```

* **Ряд E48 (`N = 48`):**
```text
r = 10^(1/48)
  ≈ 1.0491             [знаменник прогресії для 48 значень]
ΔR / R ≈ 4.91%         [стандарт для резисторів з допуском ±2%]
```

* **Ряд E96 (`N = 96`):**
```text
r = 10^(1/96)
  ≈ 1.0243             [знаменник прогресії для 96 значень]
ΔR / R ≈ 2.43%         [основний інженерний ряд для точних резисторів ±1%]
```

* **Ряд E192 (`N = 192`):**
```text
r = 10^(1/192)
  ≈ 1.0121             [знаменник прогресії для 192 значень]
ΔR / R ≈ 1.21%         [прецизійні резистори з допуском ±0.5%, ±0.25%, ±0.1%]
```

### Математичний зв'язок між допуском і кількістю номіналів

Чому для кожного ряду обрано саме таке число `N`? Чому ряд E12 асоціюється з допуском `±10%`, а ряд E24 — з `±5%`?

Ключова вимога до промислового ряду номіналів полягає у **відсутності прогалин між смугами допусків**. Це означає, що верхня границя можливого опору для номіналу `R[k]` з технологічним допуском `tol` повинна бути не меншою за нижню границю наступного номіналу `R[k+1]`:

```text
R[k] · (1 + tol) ≥ R[k+1] · (1 − tol)
```

Підставимо зв'язок `R[k+1] = R[k] · 10^(1/N)`:

```text
R[k] · (1 + tol) ≥ R[k] · 10^(1/N) · (1 − tol)
(1 + tol) / (1 − tol) ≥ 10^(1/N)
```

Розкладемо ліву частину в ряд Тейлора для малих значень допуску (`tol << 1`):

```text
(1 + tol) / (1 − tol) = (1 + tol) · (1 + tol + tol² + ...)
                      ≈ 1 + 2·tol                      [лінійне наближення Тейлора]
```

Праву частину також розкладемо через експоненту:

```text
10^(1/N) = e^(ln(10) / N)
         ≈ 1 + ln(10) / N                              [лінійне наближення експоненти]
         ≈ 1 + 2.3026 / N                              [підстановка ln(10) ≈ 2.3026]
```

Прирівнявши граничні випадки для безперервного покриття шкали:

```text
1 + 2·tol ≈ 1 + 2.3026 / N
2·tol ≈ 2.3026 / N                                     [віднімання одиниці від обох частин]
tol ≈ 1.1513 / N                                       [ділення на 2]
```

Перевіримо теоретичний розрахунок для практичних рядів:

* **Для ряду E12 (`N = 12`):**
```text
tol_min = (10^(1/12) − 1) / (10^(1/12) + 1)
        = (1.2115 − 1) / (1.2115 + 1)                  [підстановка значення 10^(1/12)]
        = 0.2115 / 2.2115                              [обчислення чисельника і знаменника]
        ≈ 0.0956 ≈ 9.6%                                [теоретичний мінімальний допуск]
```
Стандартний виробничий допуск `tol = 10%` (`0.10`) трохи перевищує мінімально необхідні `9.6%`. Це означає, що сусідні смуги допуску `[R[k]·0.9 .. R[k]·1.1]` та `[R[k+1]·0.9 .. R[k+1]·1.1]` не просто торкаються, а злегка перекриваються на `~0.4%`, повністю виключаючи «мертві зони».

* **Для ряду E24 (`N = 24`):**
```text
tol_min = (10^(1/24) − 1) / (10^(1/24) + 1)
        = (1.1007 − 1) / (1.1007 + 1)                  [підстановка значення 10^(1/24)]
        = 0.1007 / 2.1007                              [обчислення чисельника і знаменника]
        ≈ 0.0479 ≈ 4.8%                                [теоретичний мінімальний допуск]
```
Стандартний допуск `tol = 5%` перевищує мінімальний `4.8%`, забезпечуючи безперервне покриття.

* **Для ряду E96 (`N = 96`):**
```text
tol_min = (10^(1/96) − 1) / (10^(1/96) + 1)
        = (1.0243 − 1) / (1.0243 + 1)                  [підстановка значення 10^(1/96)]
        = 0.0243 / 2.0243                              [обчислення чисельника і знаменника]
        ≈ 0.0120 ≈ 1.2%                                [теоретичний мінімальний допуск]
```
Стандартний допуск `tol = 1%` дає практично ідеальне сполучення для прецизійних резисторів.

### Округлення та історичні поправки IEC 60063

Пряме обчислення за формулою `10^(k/N)` дає незручні ірраціональні дроби. Для практичного маркування ці числа були округлені:
* Ряди E6, E12, E24 округлені до **двох значущих цифр**;
* Ряди E48, E96, E192 округлені до **трьох значущих цифр**.

У рядах E12 та E24 деякі значення були історично скориговані для зручності:
* Теоретичне `10^(6/12) = √10 ≈ 3.162` було замінено на стандартизоване `3.3`;
* Теоретичне `10^(8/12) ≈ 4.642` було замінено на `4.7`;
* Теоретичне `10^(11/12) ≈ 8.254` було замінено на `8.2`.

Ось повна таблиця 24 базових значень ряду E24 (перші 12 значень утворюють ряд E12):

```text
E12:  10,   12,   15,   18,   22,   27,   33,   39,   47,   56,   68,   82
E24:  10, 11, 12, 13, 15, 16, 18, 20, 22, 24, 27, 30, 33, 36, 39, 43, 47, 51, 56, 62, 68, 75, 82, 91
```

### Система тризначного маркування EIA-96 для SMD-резисторів

На мініатюрних резисторах типорозміру 0603 і менше неможливо надрукувати чотиризначне число `4992` (що означає `49.9 кОм`). Тому асоціація EIA розробила компактну систему **EIA-96**, яка використовує рівно три символи: **дві цифри для індексу номіналу** та **одну літеру для множника**.

Дві цифри кодують порядковий номер номіналу в ряді E96 (від `01` для `100` до `96` для `976`):
* `01` = 100, `02` = 102, `03` = 105, ..., `68` = 499, ..., `96` = 976.

Літерний код позначає степінь десятки (десятковий множник):
* `Z` = `10⁻¹` (`0.1`)
* `Y` = `10⁻²` (`0.01`)
* `A` = `10⁰` (`1`)
* `B` = `10¹` (`10`)
* `C` = `10²` (`100`)
* `D` = `10³` (`1000`)
* `E` = `10⁴` (`10 000`)
* `F` = `10⁵` (`100 000`)

Приклади розшифровки:
* **`01A`** = `100 · 10⁰ = 100 Ом` (1%);
* **`68C`** = `499 · 10² = 49.9 кОм` (1%);
* **`01Y`** = `100 · 10⁻² = 1.00 Ом` (1%);
* **`30D`** = `200 · 10³ = 200 кОм` (1%).

### Алгоритм вибору найближчого стандартного номіналу

Коли в САПР, калькуляторі чи скрипті оптимізації потрібно програмно знайти найближчий стандартний номінал для розрахункового значення `R_target`, виконують такий алгоритм:

1. Виділяють порядок величини (декаду):
```text
decade = floor(log10(R_target))
R_normalized = R_target / 10^decade     [нормалізація в діапазон від 1.0 до 10.0]
```

2. Обчислюють теоретичний дробовий індекс `k` у ряді з `N` номіналів:
```text
k_float = N · log10(R_normalized)
k_index = round(k_float)                [округлення до найближчого цілого індексу]
```

3. Якщо `k_index == N`, це означає перехід у початок наступної декади (`decade + 1`, `k_index = 0`).

4. Обирають остаточне значення з таблиці стандарту IEC 60063:
```text
R_standard = Table_E[k_index] · 10^decade
```

Завдяки геометричній природі ряду максимальна можлива відносна похибка між ідеальним розрахунковим значенням та найближчим стандартним номіналом ніколи не перевищує половини кроку ряду:
* Для E24: максимум `±5.0%`;
* Для E96: максимум `±1.2%`;
* Для E192: максимум `±0.6%`.
