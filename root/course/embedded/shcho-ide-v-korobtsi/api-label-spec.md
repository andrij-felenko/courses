# 📋 Специфікація структури даних наліпки та схеми маркування

Ця специфікація встановлює уніфікований бінарний і текстовий формат кодування даних на апаратному шильдику виробу та зовнішній упаковці, необхідний для автоматизованого сканування на виробничих лініях, точного вхідного контролю на складах і безпомилкового введення в експлуатацію вбудованого вузла. Без чіткої та стандартизованої схеми полів оптичні сканери зчитують сирий неструктурований текст, що призводить до критичних помилок прив'язки криптографічних сертифікатів до фізичних екземплярів, плутанини в апаратних ревізіях і блокування автоматизованої реєстрації в хмарних платформах керування парком пристроїв.

---

## 1. Загальна архітектура та топологія маркування

Кожен випущений серійний виріб оснащується двома взаємопов'язаними носіями ідентифікаційних та регуляторних даних:

1. **Апаратний шильдик (Rating Plate):** зносостійка незмивна етикетка, розташована безпосередньо на металевому або пластиковому корпусі пристрою. Вона містить обов'язкові регуляторні знаки відповідності (CE, FCC, UKCA, WEEE, RoHS), електричні параметри живлення, серійний номер, MAC-адреси мережевих інтерфейсів та компактний двовимірний матричний код (2D DataMatrix) високої щільності.
2. **Складська логістична етикетка (Box Label):** термотрансферна наліпка на зовнішній картонній упаковці. Вона містить дубльовані лінійні штрихкоди (1D Code 128) для швидкого зчитування складськими терміналами збору даних (ТЗД) з відстані до одного метра та розширений 2D QR-код швидкого онбордингу для кінцевого монтажника або оператора системи.

## 2. Стандарт структури серійного номера (S/N)

Серійний номер формується за фіксованим 14-символьним форматом у кодуванні ASCII без використання пробілів і спеціальних розділових знаків, що унеможливлює помилки оптичного розпізнавання (OCR) та ручного введення з клавіатури:

```
Формат:  [ПП][РР][ТТ][МММ][НННН][К]
Приклад:  SN  26  34  001  0123  7
```

| Поле | Довжина | Тип | Опис та правила валідації |
|---|---|---|---|
| `ПП` (Префікс) | 2 симв. | `[A-Z]{2}` | Префікс сімейства продукту (`SN` = Sensor Node, `GW` = Gateway, `CT` = Controller). |
| `РР` (Рік) | 2 симв. | `[0-9]{2}` | Останні дві цифри року виробництва (`26` відповідає 2026 календарному року). |
| `ТТ` (Тиждень) | 2 симв. | `01..53` | Порядковий номер виробничого тижня за стандартом ISO 8601 (`34` = серпень). |
| `МММ` (Модель) | 3 симв. | `[0-9]{3}` | Числовий код апаратної модифікації платформи (`001` = Ethernet, `002` = LTE). |
| `НННН` (Номер) | 4 симв. | `0001..9999` | Порядковий номер екземпляра в межах поточного виробничого тижня. |
| `К` (Контроль) | 1 симв. | `0..9` | Контрольна цифра за алгоритмом Луна (Luhn mod 10), розрахована для 11 числових розрядів. |

Алгоритм Луна забезпечує виявлення будь-якої одиночної помилки введення цифри, а також майже всіх перестановок сусідніх цифр, що дозволяє миттєво відсікати некоректні дані ще до відправлення запиту до виробничої бази даних.

## 3. Схема бінарного кодування 2D DataMatrix на корпусі (ECC 200)

Для апаратного шильдика використовується компактний бінарний формат Tag-Length-Value (TLV). Завдяки відсутності текстової надлишковості такий код займає мінімальну площу на платі (від 6×6 мм при роздільній здатності друку 300 або 600 DPI) і забезпечує корекцію помилок Reed-Solomon (ECC 200), що гарантує зчитування навіть при пошкодженні до 30% площі символу.

| Тег (Tag) | Довжина (Length) | Тип даних | Назва та зміст поля | Приклад значення |
|---|---|---|---|---|
| `0x01` | 14 байтів | ASCII | Повний серійний номер виробу (S/N) | `SN263400101237` |
| `0x02` | 6 байтів | Binary | Базова MAC-адреса інтерфейсу (EUI-48) | `0x00, 0x1A, 0x22, 0x3B, 0x4C, 0x5D` |
| `0x03` | 2 байти | uint16_t | Апаратна ревізія друкованої плати (Major.Minor) | `0x0201` (відповідає Rev 2.1) |
| `0x04` | 4 байти | uint32_t | Дата прошивання (UNIX Epoch Timestamp) | `1787616000` (2026-08-25 UTC) |
| `0x05` | 8 байтів | Binary | Хеш публічного ключа апаратної автентифікації | `0xA4, 0xF8, 0x33, 0xC1, 0x88, 0x09, 0x9B, 0x12` |
| `0xFE` | 2 байти | uint16_t | Контрольна сума всього пакету (CRC16-CCITT) | `0x3F8A` (поліном `0x1021`) |

## 4. Схема кодування 2D QR-коду швидкого онбордингу на коробці

QR-код на зовнішній упаковці оптимізований для розпізнавання стандартними камерами мобільних телефонів монтажників і формується у вигляді захищеного уніфікованого ідентифікатора ресурсу (URI):

```
https://onboard.acme-iot.com/pair?v=1&sn=SN263400101237&mac=001A223B4C5D&pin=849201&t=a4f833c188099b12
```

### Параметри запиту (URI Query Parameters):

- `v` (Schema Version): версія протоколу онбордингу (поточна актуальна версія — `1`).
- `sn` (Serial Number): повний 14-символьний серійний номер екземпляра.
- `mac` (MAC Address): 12-символьний шістнадцятковий рядок базової фізичної адреси без розділових двокрапок.
- `pin` (Setup PIN): одноразовий 6-значний заводський пін-код для первинного підключення до локальної точки доступу Wi-Fi (SoftAP) або спарювання через Bluetooth Low Energy (BLE).
- `t` (Security Token): усічений до 16 hex-символів криптографічний відбиток (Ed25519 Fingerprint), згенерований під час фабричного провізіонування для запобігання підробці упаковки.

## 5. Стандарти якості друку та геометричні зони безпеки (Quiet Zones)

Для стабільного оптичного декодування сканерами різної оптичної роздільної здатності встановлюються жорсткі вимоги до геометрії друку та контрасту:

1. **Для 1D штрихкодів (ISO/IEC 15416):** контролюються мінімальний коефіцієнт відбиття (`R_min`), контрастність символу (`SC`), модуляція (`MOD`) та дефекти країв штрихів. Загальний бал якості друку повинен бути не нижчим за **Grade A (4.0/3.5)** або **Grade B (3.0)**. Обов'язкова наявність вільних білих полів (Quiet Zones) ліворуч і праворуч від штрихкоду шириною не менше 10 номінальних ширин вузького штриха (`10 × X-dimension`) або не менше 5 мм.
2. **Для 2D кодів DataMatrix та QR (ISO/IEC 15415):** вимірюються пошкодження шаблону пошуку (Fixed Pattern Damage), осьова неоднорідність (Axial Nonuniformity), сіткова неоднорідність (Grid Nonuniformity) та запас невикористаної корекції помилок (Unused Error Correction). Неприпустимим є випуск етикеток із рівнем якості нижче **Grade B (3.0)**. Вільна зона навколо матриці DataMatrix повинна складати щонайменше 1 повний модуль з усіх чотирьох боків, а для QR-коду — не менше 4 модулів.

## 7. Фізичні вимоги до матеріалів етикеток

1. **Стійкість до стирання та хімікатів:** для шильдика на корпусі застосовується білий глянцевий або матовий поліестер товщиною 50 мкм із перманентним акриловим клеєм, сертифікований за стандартами UL 969 та CSA C22.2 No. 0.15. Друк здійснюється суто смоляним ріббоном (Full Resin Ribbon), який витримує тест на стирання за стандартом IEC 62368-1 (50 подвійних протирань ганчіркою, змоченою 96% ізопропіловим спиртом або водою, під притискним зусиллям 10 Н).
2. **Температурний діапазон:** клейовий шар повинен зберігати міцність на відрив (не менше 18 Н/25 мм на сталі) у діапазоні температур від `-40 °C` до `+125 °C`.
3. **Пломби контролю розтину (Tamper-Evident Seals):** коробкові захисні наліпки виготовляються з руйнівного вінілу (Destructible Vinyl) або містять прихований розривний шар, який при спробі відклеювання незворотно залишає на картоні чіткий шаховий малюнок та напис `VOID`.
