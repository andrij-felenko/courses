# 🔌 Порівняння типових комплектів пакування за класами виробу

Ця вставка порівнює інженерні вимоги, склад фізичного комплекту та структуру супровідної документації для трьох різних категорій вбудованих пристроїв: промислового контролера на DIN-рейку, споживчого розумного пристрою (Consumer IoT) та польового захищеного комплексу (Rugged / Defense). Без розуміння специфіки свого сегмента розробники або перевантажують споживчу коробку непотрібними паперами, або постачають промисловий прилад у тонкому картоні без клемників, змушуючи монтажника шукати деталі в полі.

---

## 1. Порівняльна матриця комплектації за сегментами

| Параметр / Елемент | Промисловий шлюз / контролер (Industrial) | Споживчий розумний ґаджет (Consumer IoT) | Захищений польовий вузол (Rugged / Field) |
|---|---|---|---|
| **Цільовий користувач** | Кваліфікований інженер, монтажник щитового обладнання | Звичайний покупець без технічної освіти | Оператор у польових умовах, військовий технік |
| **Зовнішнє пакування** | Технічний гофрокартон нейтрального кольору з логістичною етикеткою | Повноколірна глянцева коробка з магнітним замком та рендерами | Ударостійкий герметичний кейс (Pelican/Nanuk) або армована тара |
| **Внутрішня фіксація** | Вирізані вкладиші з мікрокартону або EPE-піни | Термоформований ложемент (PET/целюлоза) з тактильним покриттям | Фрезерований ложемент із щільної демпферної піни EVA високої густини |
| **Захист від середовища** | Антистатичний металізований пакет (ESD Shielding), десикант | Тонка захисна поліетиленова плівка на глянцевих панелях | Вологопоглинач із колірним індикатором вологості (HIC-картка), клапан скидання тиску |
| **Комплект живлення** | Знімні гвинтові/пружинні клемники (Phoenix Contact), без БЖ | Компактний блок живлення 5V/12V або кабель USB-C у фірмовому обплетенні | Армований кабель із герметичним байонетним роз'ємом (Amphenol / MIL-DTL) |
| **Антенне господарство** | Промислова штирова антена SMA або виносна магнітна база | Вбудована PCB-антена (зовнішні антени відсутні) | Комплект всеспрямованих та спрямованих антен із захисними ковпачками |
| **Друковані матеріали** | 1-сторінковий Quick Start Guide (схема клем), Паспорт виробу, CE DoC | Складений мінібуклет із піктограмами, Safety Card, наліпки з брендом | Ламінована пам'ятка швидкого розгортання, таблиця кодів помилок, журнал формуляра |
| **Додаткові аксесуари** | Кронштейн кріплення на DIN-рейку, термінатор RS-485 120 Ом | Двосторонній скотч 3M VHB, скріпка для кнопки Reset, дюбелі | Запасні ущільнювальні кільця (O-rings), гермовводи, інструмент розбирання |

## 2. Промисловий сегмент: максимальна утилітарність та швидкість монтажу

Для промислових виробів розпакування відбувається у виробничому цеху або безпосередньо біля відкритої електромонтажної шафи:

1. **Мінімізація сміття та швидкість доступу:** монтажні бригади встановлюють десятки приладів за одну робочу зміну. Упаковка повинна відкриватися одним рухом руки без застосування канцелярського ножа, для чого застосовують конструкцію коробок із самоблокованими замками типу «скринька» (FEFCO 0427) без суцільного обмотування скотчем.
2. **Липкі маркери в комплекті:** у кожну коробку обов'язково вкладається аркуш із двома-чотирма перфорованими наліпками-дублікатами, де надруковано серійний номер (S/N), MAC-адресу та лінійний штрихкод. Електромонтажник наклеює один дублікат у кабельний журнал, другий — на фасадну схему шафи, третій — у паспорт об'єкта. Це виключає необхідність лізти з ліхтариком углиб змонтованого щита, щоб переписати MAC-адресу з корпусу приладу.
3. **Обов'язкова наявність клемників:** якщо на друкованій платі розпаяно вилку роз'єму (Terminal Block Header), відповідна розеткова частина під затискання дротів (Plug) повинна обов'язково входити до комплекту. Вимагати від замовника окремо купувати сумісні клемники із кроком 3.5 мм чи 5.08 мм є неприпустимою помилкою, яка гальмує здачу об'єкта та генерує прямі збитки замовника через простий монтажної бригади.

## 3. Споживчий сегмент: емоційний досвід та мінімізація повернень

У споживчій електроніці перші хвилини розпакування визначають рівень повернення товару в магазин (Return Rate) через уявні дефекти або складність запуску:

1. **Принцип «Device First»:** відкриваючи кришку, користувач повинен миттєво бачити сам виріб у центрі ложемента, а не купу безладно змотаних кабелів чи нудний чорно-білий посібник.
2. **Нуль складності на першому кроці:** перший друкований аркуш, який зустрічає користувача, містить мінімум слів: великий QR-код для встановлення мобільного застосунку (iOS / Android) та три візуальні піктограми послідовності: «Увімкни в розетку» → «Відкрий додаток» → «Піднеси телефон до приладу».
3. **Захисні плівки з виразними язичками (Pull Tabs):** глянцеві пластикові деталі та оптичні вікна датчиків захищаються транспортувальною плівкою, яка обов'язково повинна мати виступаючий кольоровий язичок. Якщо плівка обрізана точно по контуру деталі, користувач часто не помічає її на об'єктиві камери або вікні датчика освітленості, що призводить до скарг на каламутне зображення чи неправильні вимірювання.

## 4. Захищений польовий сегмент: надійність у бруді та холоді

Для обладнання тактичного призначення, геологічних станцій чи автономних метеорологічних зондів умови розгортання є екстремальними:

1. **Хімічний контроль вологи (HIC-картка):** усередині герметичного металізованого пакета обов'язково розміщують картку-індикатор вологості (Humidity Indicator Card). Перед увімкненням високовольтного живлення в польових умовах технік зобов'язаний поглянути на індикатор: якщо сектор 30% став рожевим, це свідчить про порушення герметичності пакета під час тривалого зберігання, і прилад потребує попереднього сушіння для уникнення внутрішнього пробою.
2. **Водостійкі синтетичні інструкції:** стандартний папір у польових умовах розмокає під дощем або замащується дизельним пальним за кілька хвилин. Короткі інструкції для польового обладнання друкують на синтетичному пластиковому папері (наприклад, Yupo або Polyart) на основі поліпропілену або ламінують товстою матовою антибліковою плівкою.
3. **Розрахунок на багаторазове укладання:** внутрішній ложемент виконується з пружної піни EVA високої щільності, стійкої до розривів, оскільки кейс використовується щодня як для транспортування на точку вимірювання, так і для зберігання після згортання робіт.
