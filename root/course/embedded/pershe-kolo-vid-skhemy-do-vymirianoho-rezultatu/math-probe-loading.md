# 🧮 Математична модель впливу вимірювальних приладів і паразитів монтажу

Цей аналітичний опис виводить точні математичні рівняння для похибок навантаження приладів за постійним струмом (DC loading), розширення фронтів імпульсів через ємнісне навантаження (AC probe loading) та розрахунку частоти й перерегулювання паразитного RLC-дзвоніння в петлі заземлення осцилографічного щупа. Без цих виведень неможливо чисельно відокремити власні властивості схеми від артефактів самого вимірювального тракту.

### 1. Статичний режим: навантаження контуру вольтметром

Будь-яке лінійне резистивне коло відносно двох точок підключення вимірювального приладу згортається в лінійний еквівалент Тевеніна з напругою холостого ходу U_th та еквівалентним вихідним опором R_th.

Коли до вузла підключається реальний вольтметр із кінцевим вхідним опором R_m, він утворює додатковий паралельний шлях для струму. Виміряна напруга U_meas становить:

```
U_meas = U_th · R_m / (R_th + R_m)                [дільник напруги між джерелом і вольтметром]
       = U_th · 1 / (1 + R_th / R_m)              [ділення чисельника і знаменника на R_m]
```

Абсолютна похибка вимірювання напруги через ефект навантаження дорівнює:

```
ΔU = U_meas − U_th                                [визначення абсолютної похибки]
   = U_th · (R_m / (R_th + R_m) − 1)              [підстановка виразу для U_meas]
   = − U_th · R_th / (R_th + R_m)                 [зведення до спільного знаменника]
```

Відносна похибка вимірювання ε_V визначається співвідношенням еквівалентного опору схеми та опору приладу:

```
ε_V = ΔU / U_th                                   [визначення відносної похибки]
    = − R_th / (R_th + R_m)                       [підстановка виразу для ΔU]
    = − 1 / (1 + R_m / R_th)                      [перехід до безрозмірного відношення]
```

Якщо R_m ≫ R_th, то застосовуючи розклад у степеневий ряд першого порядку 1/(1 + x) ≈ 1 − x, отримуємо наближену інженерну оцінку похибки:

```
ε_V ≈ − R_th / R_m                                [наближення для випадку R_m ≫ R_th]
```

Для досягнення відносної похибки навантаження менше ніж 1% (ε_V < 0.01) необхідно дотримуватися умови:

```
R_m ≥ 99 · R_th ≈ 100 · R_th                      [критерій допустимого опору вольтметра]
```

#### Падіння напруги на амперметрі (Burden Voltage)

Реальний амперметр вимірює струм шляхом зняття падіння напруги на внутрішньому вимірювальному шунті з опором R_shunt. Введення амперметра в коло з напругою джерела U_s та опором навантаження R_load змінює струм у колі:

```
I_ideal = U_s / R_load                            [теоретичний струм без приладу]
I_meas  = U_s / (R_load + R_shunt)                [виміряний струм із шунтом у колі]
```

Відносна похибка вимірювання струму ε_I через внесення опору шунта:

```
ε_I = (I_meas − I_ideal) / I_ideal                [визначення відносної похибки]
    = − R_shunt / (R_load + R_shunt)              [зведення дробів]
    ≈ − R_shunt / R_load                          [наближення для R_load ≫ R_shunt]
```

Падіння напруги на клемах амперметра (напруга тягаря U_burden) дорівнює:

```
U_burden = I_meas · R_shunt                       [падіння напруги на внутрішньому шунті]
```

У низьковольтних схемах живлення (наприклад, 1.2 В чи 1.8 В) при струмі 500 мА та опорі шунта 0.5 Ом падіння U_burden = 250 мВ призводить до просідання напруги на навантаженні на 14–20%, що може перевести активні компоненти в неробочий режим.

### 2. Динамічний режим: ємнісне навантаження та час наростання фронту

Щуп осцилографа разом із вхідним каскадом каналу приладу моделюється паралельним з'єднанням активного опору R_p та вхідної ємності C_p.
Для щупа в режимі 1X: R_p = 1 МОм, C_p ≈ 80–120 пФ (з урахуванням погонної ємності коаксіального кабелю ≈ 70–100 пФ/м).
Для щупа в режимі 10X: R_p = 10 МОм, C_p ≈ 10–15 пФ.

Комплексний вхідний імпеданс щупа Z_p(ω) на кутовій частоті ω становить:

```
Z_p(jω) = R_p / (1 + j · ω · R_p · C_p)           [паралельне з'єднання опору та ємності]
|Z_p(ω)| = R_p / √(1 + (ω · R_p · C_p)²)          [модуль комплексного імпедансу]
```

На високих частотах (ω ≫ 1 / (R_p · C_p)) імпеданс визначається виключно ємнісним опором:

```
|Z_p(ω)| ≈ 1 / (ω · C_p) = 1 / (2 · π · f · C_p)   [високочастотна асимптота імпедансу]
```

Для частоти f = 50 МГц та ємності щупа C_p = 15 пФ модуль вхідного опору падає до:

```
|Z_p(50 МГц)| = 1 / (2 · 3.14159 · 50·10⁶ · 15·10⁻¹²)
              = 1 / (4.712 · 10⁻³) ≈ 212 Ом        [вхідний опір замість очікуваних 10 МОм!]
```

#### Завал фронту наростання (Rise Time Degradation)

Коли джерело сигналу з вихідним опором Тевеніна R_th генерує ідеальний ступінчастий імпульс із нульовим власним часом наростання, навантаження ємністю C_total = C_circuit + C_p перетворює вузол на інтегрувальне RC-коло першого порядку.

Перехідна характеристика напруги u(t) на ємності описується диференціальним рівнянням:

```
R_eq · C_total · (du/dt) + u(t) = U_step          [диференціальне рівняння заряду ємності]
```

де R_eq = R_th ∥ R_p ≈ R_th (оскільки R_p ≫ R_th).

Розв'язок для нульових початкових умов u(0) = 0:

```
u(t) = U_step · (1 − e^(− t / τ))                 [експоненційне наростання напруги]
τ    = R_eq · C_total                             [постійна часу RC-кола]
```

Час наростання t_r за стандартним інженерним критерієм від 10% до 90% амплітуди:

```
u(t_10) = 0.10 · U_step  ⇒  t_10 = − τ · ln(0.90) ≈ 0.1054 · τ   [час досягнення рівня 10%]
u(t_90) = 0.90 · U_step  ⇒  t_90 = − τ · ln(0.10) ≈ 2.3026 · τ   [час досягнення рівня 90%]
```

Різниця між цими моментами дає класичну формулу зв'язку часу наростання з постійною часу τ:

```
t_r = t_90 − t_10                                 [визначення часу наростання 10-90%]
    = τ · (2.3026 − 0.1054)                       [підстановка логарифмічних коефіцієнтів]
    = 2.1972 · τ ≈ 2.2 · R_eq · C_total           [інженерна формула часу наростання]
```

Смуга пропускання за рівнем −3 дБ (f_-3dB) однополюсного RC-кола пов'язана з часом наростання співвідношенням:

```
f_-3dB = 1 / (2 · π · τ)                          [частота зрізу за рівнем половинної потужності]
t_r · f_-3dB = (2.197 · τ) · (1 / (2 · π · τ))
             = 2.197 / (2 · π) ≈ 0.35             [фундаментальна константа для фільтра 1-го порядку]
```

Реальний час наростання t_r_meas, зареєстрований на екрані осцилографа, є результатом квадратичної суперпозиції (згортки гаусових фронтів) власного фронту сигналу t_r_sig, часу реакції самого осцилографа t_r_scope, часу реакції щупа t_r_probe та додаткового RC-завалу від навантаження ємністю щупа t_r_load:

```
t_r_meas = √(t_r_sig² + t_r_scope² + t_r_probe² + (2.2 · R_th · C_p)²)  [сумарний час наростання]
```

### 3. Модель паразитного контуру заземлення: послідовний RLC-резонатор

Дріт заземлення осцилографічного щупа (стандартний гнучкий провідник завдовжки l ≈ 12–15 см із затискачем типу «крокодил») володіє власною паразитною індуктивністю L_loop.

Погонна індуктивність прямолінійного круглого провідника радіуса r та довжини l у повітрі розраховується за формулою:

```
L_loop = (μ₀ · l / (2 · π)) · (ln(2 · l / r) − 0.75)   [індуктивність циліндричного провідника]
```

де μ₀ = 4 · π · 10⁻⁷ Гн/м — магнітна стала.

Для провідника l = 15 см (0.15 м) та радіуса жили r = 0.5 мм (0.0005 м):

```
L_loop = (2 · 10⁻⁷ · 0.15) · (ln(2 · 0.15 / 0.0005) − 0.75)
       = 3.0 · 10⁻⁸ · (ln(600) − 0.75)
       = 3.0 · 10⁻⁸ · (6.397 − 0.75)
       = 3.0 · 10⁻⁸ · 5.647 ≈ 1.69 · 10⁻⁷ Гн ≈ 170 нГн  [індуктивність стандартного дроту заземлення]
```

#### Диференціальне рівняння другого порядку для RLC-контуру

Разом із вихідним опором джерела сигналу R_eq та вхідною ємністю щупа C_p індуктивність петлі L_loop формує послідовний коливальний RLC-контур, що описується диференціальним рівнянням:

```
L_loop · C_p · (d²u_c / dt²) + R_total · C_p · (du_c / dt) + u_c(t) = U_in(t)   [рівняння RLC-кола]
```

де R_total = R_source + R_ground_wire + R_contact — повний опір втрат у контурі.

Приведення до канонічної форми коливальної ланки другого порядку:

```
(d²u_c / dt²) + 2 · ζ · ω₀ · (du_c / dt) + ω₀² · u_c(t) = ω₀² · U_in(t)  [канонічна форма]
```

де:
- незгасна резонансна кутова частота:
```
ω₀ = 1 / √(L_loop · C_p)                          [власна резонансна частота контуру]
f₀ = ω₀ / (2 · π) = 1 / (2 · π · √(L_loop · C_p))  [частота власних коливань у герцах]
```
- коефіцієнт демпфування (затухання) ζ:
```
ζ = (R_total / 2) · √(C_p / L_loop)                [коефіцієнт згасання контуру]
```
- добротність контуру Q:
```
Q = 1 / (2 · ζ) = (1 / R_total) · √(L_loop / C_p)  [добротність резонансної системи]
```

#### Режими перехідного процесу при ступінчастому збудженні

Характеристичне алгебраїчне рівняння s² + 2·ζ·ω₀·s + ω₀² = 0 має корені:

```
s_1,2 = − ζ · ω₀ ± ω₀ · √(ζ² − 1)                 [корені характеристичного полінома]
```

Залежно від величини коефіцієнта демпфування ζ можливі три фізичні режими:

1. **Аперіодичний режим (надкритичне затухання, ζ > 1):**
Корені дійсні й від'ємні. Коливання відсутні, але наростання сигналу суттєво уповільнюється.

2. **Критичне затухання (ζ = 1, R_crit = 2 · √(L_loop / C_p)):**
Найшвидше можливе наростання сигналу без появи перерегулювання та коливань.

3. **Коливальний режим (підкритичне затухання, ζ < 1):**
Корені комплексно-спряжені: s_1,2 = − α ± j · ω_d, де коефіцієнт згасання α = ζ · ω₀, а частота згасаючих коливань (дзвоніння):

```
ω_d = ω₀ · √(1 − ζ²)                              [частота згасаючих коливань ringing]
f_d = f₀ · √(1 − ζ²)                              [вимірювана частота дзвону на екрані]
```

Перехідна характеристика u_c(t) при подачі одиничного перепаду напруги амплітудою U₀:

```
u_c(t) = U₀ · (1 − (e^(− ζ · ω₀ · t) / √(1 − ζ²)) · sin(ω_d · t + φ))   [форма дзвоніння]
φ      = arctan(√(1 − ζ²) / ζ)                    [початковий фазовий зсув]
```

#### Розрахунок перерегулювання (Overshoot)

Максимальне значення напруги U_peak досягається в перший момент екстремуму при t_peak = π / ω_d:

```
u_c(t_peak) = U₀ · (1 + e^(− π · ζ / √(1 − ζ²)))  [пікове значення напруги]
```

Відносне перерегулювання M_p (у відсотках від встановленого значення):

```
M_p = ((U_peak − U₀) / U₀) · 100%                 [визначення відсотка перерегулювання]
    = e^(− π · ζ / √(1 − ζ²)) · 100%              [формула перерегулювання через коефіцієнт ζ]
```

Звідси можна розрахувати коефіцієнт демпфування ζ безпосередньо за виміряним на екрані перерегулюванням M_p:

```
ln(M_p / 100) = − π · ζ / √(1 − ζ²)               [логарифмування виразу]
ζ = |ln(M_p / 100)| / √(π² + ln²(M_p / 100))      [обчислення коефіцієнта згасання за осцилограмою]
```

#### Числовий приклад розрахунку паразитного дзвоніння

Вихідні параметри реального робочого місця:
- Щуп 10X: C_p = 15 пФ
- Довгий крокодил заземлення l = 15 см: L_loop = 160 нГн
- Сумарний опір виходу цифрового драйвера та контакту: R_total = 25 Ом

1. Розрахунок власної резонансної частоти:
```
ω₀ = 1 / √(160 · 10⁻⁹ · 15 · 10⁻¹²) = 1 / √(2.4 · 10⁻¹⁸)
   = 1 / (1.549 · 10⁻⁹) ≈ 6.455 · 10⁸ рад/с
f₀ = 6.455 · 10⁸ / (2 · π) ≈ 102.7 МГц             [резонансна частота потрапляє в смугу приладу]
```

2. Розрахунок коефіцієнта демпфування:
```
ζ = (25 / 2) · √(15 · 10⁻¹² / 160 · 10⁻⁹)
  = 12.5 · √(9.375 · 10⁻⁵)
  = 12.5 · 9.682 · 10⁻³ ≈ 0.121                   [сильно недодемпфований контур: ζ ≪ 1]
```

3. Розрахунок частоти спостережуваного дзвоніння:
```
f_d = 102.7 · √(1 − 0.121²) = 102.7 · √(0.9854) ≈ 102.0 МГц
```

4. Розрахунок амплітуди викиду (перерегулювання):
```
M_p = e^(− 3.14159 · 0.121 / √(1 − 0.121²)) · 100%
    = e^(− 0.3801 / 0.9927) · 100%
    = e^(− 0.3829) · 100% ≈ 68.2%                 [викид на 68% вище номінального рівня сигналу!]
```

Якщо напруга логічного рівня становить 3.3 В, осцилограф покаже перший викид до рівня:

```
U_peak = 3.3 В · (1 + 0.682) = 5.55 В             [хибне свідчення небезпечного перевищення напруги]
```

Цей розрахунок наочно доводить, що сплеск напруги до 5.55 В є виключно вимірювальним артефактом паразитного контуру L_loop · C_p. Якщо замінити крокодил на короткий пружинний контакт (L_loop ≈ 5 нГн), параметри контуру змінюються:
- Резонансна частота зміщується: f₀ = 1 / (2·π·√(5·10⁻⁹ · 15·10⁻¹²)) ≈ 580 МГц (поза смугою пропускання більшості 100–200 МГц осцилографів).
- Коефіцієнт демпфування зростає: ζ = 12.5 · √(15·10⁻¹² / 5·10⁻⁹) = 12.5 · 0.0548 ≈ 0.685.
- Перерегулювання падає: M_p = e^(− π · 0.685 / √(1 − 0.685²)) · 100% = e^(− 2.95) · 100% ≈ 5.2%.

Форма сигналу стає достовірною, а уявний «викид» зникає.
