# 🧮 Виведення точки нульового перекидного моменту (ZMP) для зв'язки шасі-маніпулятор

Точний розрахунок динамічної стійкості рухомої платформи з маніпулятором спирається на пошук точки на опорній поверхні, навколо якої результуючий перекидний момент від сил тяжіння, інерції та кутових прискорень ланок дорівнює нулю. Ця точка називається **точкою нульового перекидного моменту** (*Zero Moment Point*, ZMP). Якщо ZMP лежить усередині опорного багатокутника коліс чи гусениць, сили реакції ґрунту здатні компенсувати збурення без відриву коліс. Щойно ZMP виходить на межу контуру, платформа починає перекидатися навколо відповідного ребра опори.

Нижче наведено строге виведення координат ZMP та динамічного запасу стійкості (DSM) для системи твердих тіл, що рухаються зі змінними лінійними та кутовими прискореннями, розширення для довільно нахиленої поверхні та числовий розбір граничного прискорення.

## 1. Постановка динамічної задачі системи багатьох тіл

Розглянемо мобільну платформу (ланка 0) та змонтований на ній маніпулятор із `N` ланками (ланки 1, 2, ..., `N`). Загальна кількість рухомих твердих тіл у системі становить `N + 1`.

Оберемо глобальну інерціальну систему координат `OXYZ`, де площина `OXY` збігається з горизонтальною опорною поверхнею ґрунту (`z = 0`), а вісь `OZ` спрямована вертикально вгору проти вектора вільного падіння `g_vec = [0, 0, -g]^T`.

Для кожної ланки `i` від 0 до `N` визначено:
- масу `m_i`;
- радіус-вектор центру мас `r_i = [x_i, y_i, z_i]^T`;
- лінійну швидкість `ṙ_i = [ẋ_i, ẏ_i, ż_i]^T` та прискорення `r̈_i = [ẍ_i, ÿ_i, z̈_i]^T`;
- тензор інерції відносно власного центру мас `I_i`;
- вектор кутової швидкості `ω_i` та кутового прискорення `ω̇_i`;
- швидкість зміни власного кутового моменту (кінетичного моменту) `Ḣ_i = I_i · ω̇_i + ω_i × (I_i · ω_i)`.

За принципом Д'Аламбера кожна ланка зазнає дії гравітаційної сили `m_i · g_vec` та фіктивної сили інерції `−m_i · r̈_i`. Разом вони утворюють повну гравітаційно-інерційну силу:

```
F_i = m_i · (g_vec − r̈_i)                   [гравітаційно-інерційна сила ланки i]
    = [ −m_i·ẍ_i,  −m_i·ÿ_i,  −m_i·(g + z̈_i) ]^T
```

Сумарний момент цієї сили та динамічного обертального моменту ланки відносно початку координат `O` дорівнює:

```
M_O,i = r_i × F_i − Ḣ_i                     [момент інерційних та вагових сил ланки i]
```

## 2. Сумарні сили та моменти на опорну поверхню

Підсумуємо внесок усіх `N + 1` ланок системи. Результуючий головний вектор сил `F_total` та головний момент `M_O` у початку координат мають вигляд:

```
F_total = ∑ m_i · (g_vec − r̈_i)             [головний вектор гравітаційно-інерційних сил]
M_O     = ∑ ( r_i × m_i·(g_vec − r̈_i) − Ḣ_i ) [головний момент відносно початку O]
```

Розпишемо компоненти векторного добутку `r_i × F_i` покоординатно:

```
(r_i × F_i)_x = −m_i · y_i · (g + z̈_i) + m_i · z_i · ÿ_i
(r_i × F_i)_y =  m_i · x_i · (g + z̈_i) − m_i · z_i · ẍ_i
(r_i × F_i)_z = −m_i · x_i · ÿ_i + m_i · y_i · ẍ_i
```

Додаючи власні моменти інерції `Ḣ_i = [Ḣ_x,i, Ḣ_y,i, Ḣ_z,i]^T`, отримуємо проєкції сумарного моменту системи на осі `OX` та `OY`:

```
M_Ox = ∑ ( −m_i · y_i · (g + z̈_i) + m_i · z_i · ÿ_i − Ḣ_x,i )
M_Oy = ∑ (  m_i · x_i · (g + z̈_i) − m_i · z_i · ẍ_i − Ḣ_y,i )
```

## 3. Умова ZMP на опорній площині

Нехай точка `P = [x_zmp, y_zmp, 0]^T` лежить на площині контакту `z = 0`. Обчислимо сумарний момент `M_P` активних та інерційних сил відносно точки `P`:

```
M_P = M_O − r_P × F_total                   [перенесення точки приведення моменту в P]
```

Векторний добуток `r_P × F_total` для точки на площині `z = 0` має вигляд:

```
(r_P × F_total)_x = y_zmp · F_total,z       [бо z_zmp = 0]
(r_P × F_total)_y = −x_zmp · F_total,z      [бо z_zmp = 0]
(r_P × F_total)_z = x_zmp · F_total,y − y_zmp · F_total,x
```

Означення ZMP за Вукобратовичем вимагає, щоб результуючий момент навколо горизонтальних осей `PX` та `PY` дорівнював нулю:

```
M_Px = 0                                    [відсутність перекидного моменту навколо осі X]
M_Py = 0                                    [відсутність перекидного моменту навколо осі Y]
```

Підставимо розгорнуті вирази:

```
M_Px = M_Ox − y_zmp · F_total,z = 0
M_Py = M_Oy + x_zmp · F_total,z = 0
```

Оскільки `F_total,z = −∑ m_i · (g + z̈_i)`, отримуємо систему двох незалежних лінійних рівнянь:

```
y_zmp · ∑ m_i · (g + z̈_i) = −M_Ox
x_zmp · ∑ m_i · (g + z̈_i) =  M_Oy
```

## 4. Фінальні координати точки нульового моменту

Розв'язуючи систему відносно `x_zmp` та `y_zmp`, отримуємо аналітичні координати ZMP:

```
x_zmp = [ ∑ m_i·x_i·(g + z̈_i) − ∑ m_i·z_i·ẍ_i − ∑ Ḣ_y,i ] / [ ∑ m_i·(g + z̈_i) ]
y_zmp = [ ∑ m_i·y_i·(g + z̈_i) − ∑ m_i·z_i·ÿ_i + ∑ Ḣ_x,i ] / [ ∑ m_i·(g + z̈_i) ]
```

### Структурний аналіз складових частин ZMP

У чисельнику кожного виразу чітко виділяються три фізичні фактори:

1. **Статичний ваговий член:**
   ```
   x_stat = [ ∑ m_i · x_i · g ] / [ ∑ m_i · g ] = x_CoM
   ```
   У стані повного спокою (`r̈_i = 0`, `ω̇_i = 0`) точка ZMP строго збігається з вертикальною проєкцією центру мас системи на землю.

2. **Динамічний лінійний зсув Д'Аламбера:**
   ```
   Δx_trans = − [ ∑ m_i · z_i · ẍ_i ] / [ ∑ m_i · (g + z̈_i) ]
   ```
   Що вище розташована рухома ланка (більше плече `z_i`) і що вище її горизонтальне прискорення `ẍ_i`, то далі точка тиску зсувається в протилежний від прискорення бік. При гальмуванні руки вперед (`ẍ_i < 0`) ZMP зміщується вперед (`Δx > 0`), перевантажуючи передні колеса.

3. **Гіроскопічний та кутовий інерційний член:**
   ```
   Δx_rot = − [ ∑ Ḣ_y,i ] / [ ∑ m_i · (g + z̈_i) ]
   ```
   Швидкий розгін важких роторів приводів маніпулятора та кутове прискорення масивних сегментів руки генерують реактивні моменти `Ḣ_i`, які безпосередньо зсувають ZMP навіть тоді, коли лінійне прискорення центру мас незначне.

## 5. Узагальнення для руху похилою поверхнею

Якщо мобільний робот працює на схилі з кутом нахилу `θ` (тангаж) та `φ` (крен), вектор прискорення вільного падіння в системі координат опорної площини платформи має три ненульові проєкції:

```
g_x = −g · sin(θ)
g_y =  g · sin(φ) · cos(θ)
g_z = −g · cos(φ) · cos(θ)
```

Підставляючи ці проєкції у векторні рівняння рівноваги, отримуємо узагальнені рівняння координат ZMP на похилій площині:

```
x_zmp_накл = [ ∑ m_i·x_i·(−g_z + z̈_i) − ∑ m_i·z_i·(ẍ_i − g_x) − ∑ Ḣ_y,i ] / [ ∑ m_i·(−g_z + z̈_i) ]
y_zmp_накл = [ ∑ m_i·y_i·(−g_z + z̈_i) − ∑ m_i·z_i·(ÿ_i − g_y) + ∑ Ḣ_x,i ] / [ ∑ m_i·(−g_z + z̈_i) ]
```

Тут гравітаційні складові `g_x` та `g_y` створюють постійний бічний і поздовжній статичний зсув, що значно звужує доступний динамічний запас стійкості ще до початку будь-якого руху маніпулятора.

## 6. Обчислення динамічного запасу стійкості (DSM)

Маючи координати `P_ZMP = [x_zmp, y_zmp]^T`, необхідно оцінити її положення відносно опуклого багатокутника опори `S`, утвореного `K` точками контакту коліс або опор `[V_1, V_2, ..., V_K]`.

Вершини багатокутника впорядковано проти годинникової стрілки: `V_k = [x_k, y_k]^T`, `V_{K+1} ≡ V_1`.

Кожне ребро `k` від 1 до `K` формує перекидну вісь із напрямним вектором `t_k = V_{k+1} − V_k = [Δx_k, Δy_k]^T` довжиною `L_k = sqrt(Δx_k^2 + Δy_k^2)`.

Одиничний внутрішній нормальний вектор до ребра дорівнює:

```
n_k = [ −Δy_k / L_k,  Δx_k / L_k ]^T         [нормаль, спрямована всередину багатокутника]
```

Знакова відстань від точки `P_ZMP` до `k`-го ребра обчислюється як скалярний добуток вектора від вершини `V_k` до ZMP на внутрішню нормаль:

```
d_k = (P_ZMP − V_k) · n_k
    = [ −Δy_k · (x_zmp − x_k) + Δx_k · (y_zmp − y_k) ] / L_k
```

**Динамічний запас стійкості** (*Dynamic Stability Margin*, DSM) визначається як мінімальна знакова відстань до всіх обмежувальних ребер:

```
DSM = min { d_1, d_2, ..., d_K }            [найкоротша відстань до межі перекидання]
```

### Фізична інтерпретація величини DSM:
- `DSM > 0` — система динамічно стійка. Усі колеса/гусениці притиснуті до ґрунту з ненульовою нормальною силою реакції (`F_N,k > 0`).
- `DSM = 0` — критична межа стійкості. ZMP вийшла на вісь перекидання; протилежні колеса повністю розвантажилися (`F_N → 0`), платформа перебуває у стані нестійкої рівноваги на двох точках опори.
- `DSM < 0` — відрив опор і активне перекидання платформи. Момент сил інерції перевищив відновлювальний момент сили тяжіння, система набуває кутового прискорення навколо опорного ребра.

## 7. Числовий розрахунок граничного прискорення маніпулятора

Розглянемо практичний числовий приклад розрахунку стійкості для чотириколісного ровера:
- Маса шасі: `m_0 = 40` кг, центр мас `[0.00, 0.00, 0.15]` м.
- Маса маніпулятора з вантажем: `m_1 = 10` кг, винесена вперед: `[0.35, 0.00, 0.50]` м.
- Колісна база: передні колеса на `x = +0.30` м, задні на `x = −0.30` м. Ширина колії `0.50` м.

Розрахуємо статичний центр мас системи вздовж поздовжньої осі `X`:

```
x_CoM = ( 40 · 0.00 + 10 · 0.35 ) / ( 40 + 10 ) [підстановка мас і координат ланок]
      = 3.5 / 50                                  [обчислення зваженої суми]
      = 0.070 м = +70 мм                          [координата центру мас уздовж осі X]
```

Статичний запас стійкості до передньої осі (`x = +0.30` м):

```
SSM = 0.30 − 0.07 = 0.230 м = 230 мм
```

Нехай маніпулятор під час різкого гальмування вперед уповільнює вантаж із прискоренням `ẍ_1 = −6.0` м/с² (вертикальне прискорення відсутнє, `z̈ = 0`). Кутові прискорення малі (`Ḣ ≈ 0`).

Обчислимо динамічне положення ZMP:

```
Чисельник x_zmp = ( 40·0.00·9.81 + 10·0.35·9.81 ) − ( 40·0.15·0.00 + 10·0.50·(−6.0) ) [підстановка у формулу ZMP]
                = ( 0 + 34.335 ) − ( 0 − 30.0 )                                         [розкриття дужок]
                = 34.335 + 30.0                                                          [додавання інерційного моменту]
                = 64.335 Н·м                                                             [сумарний момент чисельника]

Знаменник x_zmp = ( 40 + 10 ) · 9.81 = 490.5 Н

x_zmp = 64.335 / 490.5 ≈ 0.1311 м = +131.1 мм
```

Динамічний запас стійкості зменшився до:

```
DSM = 0.300 − 0.1311 = 0.1689 м ≈ 169 мм
```

Тепер знайдемо критичне прискорення сповільнення `ẍ_крит`, за якого точка ZMP досягне передньої осі перекидання (`x_zmp = 0.300` м):

```
0.300 = [ 34.335 − 10 · 0.50 · ẍ_крит ] / 490.5 [умова ZMP на передній осі перекидання]
0.300 · 490.5 = 34.335 − 5.0 · ẍ_крит           [множення на знаменник]
147.15 = 34.335 − 5.0 · ẍ_крит                  [обчислення лівої частини]
5.0 · ẍ_крит = 34.335 − 147.15 = −112.815       [перенесення доданків]
ẍ_крит = −112.815 / 5.0 = −22.56 м/с²           [ділення на коефіцієнт при прискоренні]
```

Таким чином, горизонтальне сповільнення понад 22.56 м/с² гарантовано викличе відрив задніх коліс ровера від землі та перекидання вперед. Запас безпеки задають так, щоб реальне прискорення не перевищувало 40–50% від критичного значення.
