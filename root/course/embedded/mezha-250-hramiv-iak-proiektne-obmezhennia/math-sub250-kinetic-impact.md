# 🧮 Розрахунок кінетичної енергії удару та термінальної швидкості суб-250г дронів

Ця математична вставка містить аналітичне виведення термінальної швидкості вільного падіння безпілотного апарата, розрахунок граничної кінетичної енергії зіткнення та фізичне обґрунтування біомеханічного порогу безпеки 80 Джоулів, що ліг в основу регуляторної межі 250 грамів.

## 1. Динаміка падіння з квадратичним аеродинамічним опором

Розглянемо некероване падіння апарата масою `m` у спокійній атмосфері з однорідною густиною `ρ`. На апарат діють дві протилежно спрямовані сили: гравітаційне тяжіння `F_g = m · g` (спрямоване вниз) та сила аеродинамічного опору середовища `F_d` (спрямована вгору проти вектора швидкості `v`).

При числах Рейнольдса `Re > 10⁴`, характерних для падіння тіла розміром 10–20 см зі швидкістю понад 10 м/с, переважає турбулентний режим обтікання, де сила опору пропорційна квадрату швидкості:

```
F_d = (1/2) · ρ · C_d · S · v²
```

де:
- `ρ` — густина повітря на рівні моря за стандартної атмосфери ISA (`ρ = 1.225 кг/м³`);
- `C_d` — безрозмірний коефіцієнт лобового опору (для квадрокоптера довільної орієнтації `C_d ≈ 0.9 – 1.3`);
- `S` — характерна площа міделевого перерізу апарата (проекція на площину, перпендикулярну вектору руху, `м²`);
- `v` — миттєва вертикальна швидкість падіння (`м/с`).

Диференціальне рівняння вертикального руху за другим законом Ньютона набуває вигляду:

```
m · (dv / dt) = m · g - (1/2) · ρ · C_d · S · v²
```

Розділимо змінні та запишемо рівняння для знаходження швидкості `v(t)` за початкової нульової швидкості `v(0) = 0`:

```
dv / (g - (ρ · C_d · S / (2 · m)) · v²) = dt
```

Позначимо константу аеродинамічного гальмування `k`:

```
k = (ρ · C_d · S) / (2 · m)
```

Інтегруючи ліву частину через табличний інтеграл `∫ dx / (a² - x²) = (1 / a) · artanh(x / a)`, отримуємо закон зміни швидкості в часі:

```
v(t) = √(g / k) · tanh(√(g · k) · t)
```

Оскільки гіперболічний тангенс `tanh(x) → 1` при `x → ∞`, швидкість асимптотично наближається до свого граничного значення — всталеної (термінальної) швидкості `v_t`.

## 2. Виведення термінальної швидкості

Всталена швидкість досягається в точці динамічної рівноваги, коли сила аеродинамічного опору повністю компенсує силу тяжіння (`dv / dt = 0` та `F_d = F_g`):

```
m · g = (1/2) · ρ · C_d · S · v_t²
(1/2) · ρ · C_d · S · v_t² = m · g              [прирівняли силу опору до сили ваги]
v_t² = (2 · m · g) / (ρ · C_d · S)              [помножили на 2 та поділили на rho·Cd·S]
v_t = √((2 · m · g) / (ρ · C_d · S))            [добули квадратний корінь з обох частин]
```

Термінальна швидкість прямо пропорційна кореню з маси `√m` та обернено пропорційна кореню з площі міделя `√S` та коефіцієнта опору `√C_d`.

## 3. Гранична кінетична енергія удару

Кінетична енергія `E_k`, яку накопичує тіло масою `m` при досягненні термінальної швидкості `v_t`, визначається класичним виразом:

```
E_k = (1/2) · m · v_t²
```

Підставимо отриманий вираз для `v_t²` у формулу кінетичної енергії:

```
E_k = (1/2) · m · ((2 · m · g) / (ρ · C_d · S))
= (2 · m² · g) / (2 · ρ · C_d · S)               [перемножили чисельники та знаменники]
= (m² · g) / (ρ · C_d · S)                       [скоротили спільний множник 2]
```

Отримане співвідношення виявляє фундаментальний фізичний закон для вільного падіння БПЛА: **кінетична енергія удару на термінальній швидкості зростає пропорційно квадрату маси апарата `m²`**, якщо геометричні розміри та форма змінюються повільніше за масу.

Це пояснює, чому збільшення маси дрона з 250 г до 500 г (у 2 рази) збільшує енергію потенційного удару не вдвічі, а майже в 4 рази.

## 4. Числовий розрахунок для різних класів БПЛА

Проведемо зіставлення трьох характерних вагових категорій цивільних дронів за стандартних умов атмосфери (`ρ = 1.225 кг/м³`, `g = 9.81 м/с²`).

### Варіант А: Граничний суб-250г квадрокоптер (Micro / Ultralight)
- Повна маса: `m = 0.249 кг` (249 г);
- Характерна площа проєкції (плашмя / кувиркання): `S = 0.022 м²` (діагональ рами 140 мм);
- Усереднений коефіцієнт опору при безладному обертанні (tumbling): `C_d = 1.10`.

Розрахунок термінальної швидкості:

```
v_t = √((2 · 0.249 · 9.81) / (1.225 · 1.10 · 0.022))
= √(4.8854 / 0.029645)                          [обчислили добутки чисельника й знаменника]
= √164.796                                      [виконали ділення під коренем]
≈ 12.84 м/с                                     [добули корінь: швидкість ≈ 46.2 км/год]
```

Розрахунок кінетичної енергії удару на швидкості 12.84 м/с:

```
E_k = (1/2) · 0.249 · (12.84)²
= 0.1245 · 164.865                              [піднесли швидкість до квадрата і помножили на 0.5m]
≈ 20.53 Дж                                      [базове значення при плашковому падінні]
```

Навіть якщо припустити найнесприятливіший балістичний сценарій — падіння променем або батареєю вперед із мінімальним міделем (`S = 0.012 м²`, `C_d = 0.85`), термінальна швидкість складе:

```
v_t_max = √((2 · 0.249 · 9.81) / (1.225 · 0.85 · 0.012))
= √(4.8854 / 0.012495)                          [обчислили добутки]
= √390.988                                      [виконали ділення]
≈ 19.77 м/с                                     [максимальна вертикальна швидкість ≈ 71.2 км/год]
```

Відповідна максимальна кінетична енергія удару:

```
E_k_max = (1/2) · 0.249 · (19.77)²
= 0.1245 · 390.85                               [обчислили добуток]
≈ 48.66 Дж                                      [значно нижче порогу 80 Дж]
```

### Варіант Б: Стандартний квадрокоптер класу 500 г (Open A2 / C1)
- Повна маса: `m = 0.500 кг` (500 г);
- Характерна площа: `S = 0.028 м²`;
- Коефіцієнт опору: `C_d = 1.00`.

```
v_t = √((2 · 0.500 · 9.81) / (1.225 · 1.00 · 0.028))
= √(9.81 / 0.0343)                              [обчислили добутки]
= √285.99                                       [виконали ділення]
≈ 16.91 м/с                                     [швидкість падіння ≈ 60.9 км/год]
```

Кінетична енергія удару:

```
E_k = (1/2) · 0.500 · (16.91)²
= 0.250 · 285.95                                [обчислили добуток]
≈ 71.49 Дж                                      [наближається до критичної межі]
```

При балістичному падінні носом униз (`S = 0.016 м²`, `C_d = 0.8`):
`v_t ≈ 25.0 м/с`, а кінетична енергія сягає `E_k = 0.5 · 0.5 · 625 = 156.25 Дж`, що майже вдвічі перевищує безпечний поріг.

### Варіант В: Класичний 5-дюймовий дрон (Freestyle / Cine 900 г)
- Повна маса: `m = 0.900 кг` (900 г);
- Характерна площа: `S = 0.035 м²`;
- Коефіцієнт опору: `C_d = 0.95`.

```
v_t = √((2 · 0.900 · 9.81) / (1.225 · 0.95 · 0.035))
= √(17.658 / 0.04073)                           [обчислили добутки]
= √433.53                                       [виконали ділення]
≈ 20.82 м/с                                     [швидкість ≈ 75.0 км/год]
```

Кінетична енергія удару:

```
E_k = (1/2) · 0.900 · (20.82)²
= 0.450 · 433.47                                [обчислили добуток]
≈ 195.06 Дж                                     [у 2.4 раза перевищує летальний поріг]
```

## 5. Біомеханічна основа порогу 80 Дж

Звідки взялося саме число 80 Дж у нормативних документах авіаційних регуляторів (FAA Micro UAS ARC, EASA Opinion 01/2018, військовий стандарт Range Commanders Council RCC 321-07)?

Дослідження травматології тупого удару (Blunt Trauma Criterion) та шкали ушкоджень голови HIC (Head Injury Criterion) показали, що ймовірність летального наслідку або важкої черепно-мозкової травми при прямому зіткненні компактного твердого тіла з головою незахищеної людини залежить від питомої кінетичної енергії:

1. **Нижче 25–35 Дж**: синці, легкі розсічення м'яких тканин шкіри, нульова ймовірність проникної травми чи перелому склепіння черепа;
2. **35–65 Дж**: помірні травми, струси мозку легкого ступеня, ймовірність перелому кісток черепа менше 1%;
3. **80 Дж**: критична межа перегину сигмоїдальної кривої ризику ураження (Shelton Lethality Model). При `E_k ≥ 80 Дж` ймовірність фатальної травми для випадкового пішохода перевищує поріг 1–2%, що за нормами цивільної авіації вважається неприпустимим рівнем суспільного ризику для несертифікованих польотів над людьми;
4. **Понад 150–200 Дж**: гарантований перелом кісток черепа з імовірністю важких інвалідизуючих ушкоджень понад 50%.

Звідси випливає фундаментальний інженерний висновок: апарат масою до 249 грамів за будь-яких фізично можливих умов некерованого падіння з висоти (навіть із 100–500 метрів) внаслідок аеродинамічного самогальмування не здатен розігнатися до швидкості, за якої його кінетична енергія досягне 80 Дж. Саме це математичне співвідношення перетворило масу 250 г на універсальний міжнародний вододіл безпеки.
