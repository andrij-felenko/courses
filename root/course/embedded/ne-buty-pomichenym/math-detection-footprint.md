# Розрахунок енергетичної помітності та зони перехоплення

Математичний апарат розрахунку енергетичного балансу виявлення радіосигналу дозволяє точно визначити, на якій відстані комплекс радіоелектронної розвідки (РЕР) здатний зафіксувати передавач за заданої випромінюваної потужності, тривалості імпульсу та діаграми спрямованості антени. Цей розрахунок дає кількісну оцінку ефективності засобів зменшення помітності (LPI/LPD): адаптивного регулювання потужності, стиснення часу передачі та просторового фокусування променя.

### 1. Відношення дальності перехоплення до дальності зв'язку

Розгляньмо радіолінк між передавачем TX та законним приймачем RX, а також комплекс РЕР, що намагається виявити випромінювання TX.

Потужність сигналу на вході законного приймача `P_rx` на відстані `R_comm` у вільному просторі описується формулою Фрііса:

```
P_rx = (P_tx · G_tx · G_rx · λ²) / (16 · π² · R_comm²)
```

де `P_tx` — потужність передавача на клемах антени (Вт), `G_tx` — коефіцієнт підсилення передавальної антени в напрямку приймача (безрозмірний), `G_rx` — коефіцієнт підсилення приймальної антени, `λ` — довжина хвилі (м). Добуток `P_tx · G_tx` визначає еквівалентну ізотропно-випромінювану потужність (EIRP).

Гранична дальність зв'язку `R_comm` досягається, коли потужність `P_rx` падає до рівня чутливості законного приймача `S_comm`:

```
R_comm = (λ / (4 · π)) · sqrt((P_tx · G_tx · G_rx) / S_comm)
```

Аналогічно, потужність сигналу на вході приймача РЕР на відстані `R_det` становить:

```
P_esm = (P_tx · G_tx_esm · G_esm · λ²) / (16 · π² · R_det²)
```

де `G_tx_esm` — коефіцієнт підсилення антени передавача в напрямку пеленгатора РЕР, `G_esm` — коефіцієнт підсилення антени РЕР, `S_esm` — мінімальна потужність, необхідна пеленгатору для достовірного виявлення сигналу (чутливість виявлення).

Гранична дальність виявлення пеленгатором `R_det`:

```
R_det = (λ / (4 · π)) · sqrt((P_tx · G_tx_esm · G_esm) / S_esm)
```

Знайдімо відношення дальності перехоплення до дальності зв'язку:

```
R_det / R_comm = sqrt( ((P_tx · G_tx_esm · G_esm) / S_esm) / ((P_tx · G_tx · G_rx) / S_comm) )
               = sqrt( (G_tx_esm · G_esm · S_comm) / (G_tx · G_rx · S_esm) )   [скорочення потужності P_tx та геометрії хвилі λ]
```

Для всеспрямованої антени передавача (`G_tx = G_tx_esm`):

```
R_det / R_comm = sqrt( (G_esm / G_rx) · (S_comm / S_esm) )
```

З цього виведення видно фундаментальну небезпеку: **дальність виявлення не залежить від випромінюваної потужності передавача `P_tx` у відносному вираженні**. Якщо пеленгатор РЕР має потужнішу антенну решітку (`G_esm > G_rx`) та вищу енергетичну чутливість (`S_esm < S_comm`), він виявляє передавач значно далі, ніж сягає корисний зв'язок (`R_det > R_comm`), за будь-якої фіксованої потужності.

### 2. Чутливість радіометричного виявлення (Рівняння радіометра)

Пеленгатори РЕР часто не знають точної структури сигналу, кодових послідовностей та модуляції, тому використовують енергетичний детектор (радіометр) або спектральний аналізатор на основі БПФ (FFT channelizer).

Енергетичний детектор вимірює сумарну енергію в смузі аналізу `B` протягом часу спостереження (інтегрування) `τ`.

Для низького вхідного відношення сигнал/шум `(S/N)_in << 1`, вихідне відношення сигнал/шум після інтегратора `(S/N)_out` описується рівнянням радіометра:

```
(S/N)_out = (S/N)_in² · B · τ
```

Виразимо вхідне відношення сигнал/шум, необхідне для досягнення порогу виявлення `(S/N)_out,min`:

```
(S/N)_in = sqrt( (S/N)_out,min / (B · τ) )
```

Оскільки потужність шуму на вході приймача становить `P_noise = k · T_sys · B` (де `k` — стала Больцмана, `T_sys` — еквівалентна шумова температура системи в кельвінах), мінімальна потужність сигналу `S_esm`, яку здатен виявити радіометр:

```
S_esm = (S/N)_in · P_noise
      = sqrt( (S/N)_out,min / (B · τ) ) · (k · T_sys · B)
      = k · T_sys · sqrt( (B · (S/N)_out,min) / τ )   [піднесення B під корінь]
```

Звідси випливає залежність чутливості від параметрів випромінювання:
1. Якщо тривалість пакету в ефірі (Time on Air, `ToA`) зменшується, час інтегрування пеленгатора обмежений `τ = ToA`. Мінімальна виявна потужність зростає обернено пропорційно `sqrt(ToA)`:

```
S_esm ∝ 1 / sqrt(ToA)
```

2. Коротший пакет змушує станцію РЕР вимагати вищої миттєвої потужності сигналу для виявлення, що безпосередньо зменшує радіус перехоплення `R_det`:

```
R_det ∝ 1 / sqrt(S_esm) ∝ (ToA)^(1/4)
```

Зменшення часу перебування в ефірі `ToA` у 16 разів (наприклад, стиснення пакета з 32 мс до 2 мс шляхом збільшення швидкості модуляції) скорочує дальність виявлення пеленгатором удвічі (`16^(1/4) = 2`), а площу зони виявлення — у 4 рази.

### 3. Розрахунок площі зони перехоплення (Interception Footprint)

Площа території, на якій комплекс РЕР може запеленгувати передавач, визначає просторову помітність пристрою.

#### А. Всеспрямована антена

Для ізотропного або слабоспрямованого випромінювача (диполь, штир) зона перехоплення є кругом радіуса `R_det`:

```
Area_omni = π · R_det²                                              [геометрія площі круга]
          = π · (λ² / (16 · π²)) · ((P_tx · G_tx · G_esm) / S_esm) [підстановка R_det з формули Фрііса]
          = (λ² / (16 · π)) · (EIRP · G_esm / S_esm)               [скорочення π та групування EIRP]
```

Площа перехоплення **прямо пропорційна EIRP передавача**. Зниження потужності передавача за допомогою адаптивного керування (TPC) на 10 дБ (фактор 10) зменшує площу демаскування рівно в 10 разів.

#### Б. Спрямована антена з придушенням бокових пелюсток

Нехай передавач використовує спрямовану антену з шириною головної пелюстки за рівнем половинної потужності `θ_3dB` (у радіанах), підсиленням головної пелюстки `G_main` та середнім підсиленням бокових і задніх пелюсток `G_side`.

Дальність виявлення в напрямку головного променя `R_main`:

```
R_main = (λ / (4 · π)) · sqrt((P_tx · G_main · G_esm) / S_esm)
```

Дальність виявлення з бокових і тильних напрямків `R_side`:

```
R_side = (λ / (4 · π)) · sqrt((P_tx · G_side · G_esm) / S_esm)
       = R_main · sqrt(G_side / G_main)                             [вираження через дальність головного променя]
```

Сумарна площа зони перехоплення складається із сектора головної пелюстки та фонового сектора бокового випромінювання:

```
Area_dir = (θ_3dB / 2) · R_main² + ((2·π - θ_3dB) / 2) · R_side²                   [сума площ двох кругових секторів]
         = (θ_3dB / 2) · R_main² + ((2·π - θ_3dB) / 2) · R_main² · (G_side/G_main) [підстановка R_side через R_main]
         = (R_main² / 2) · ( θ_3dB + (2·π - θ_3dB) · (G_side / G_main) )          [винесення R_main² / 2 за дужки]
```

Порівняймо площу виявлення спрямованої антени `Area_dir` із всеспрямованою антеною `Area_omni`, що забезпечує ту саму дальність зв'язку `R_comm`. Для досягнення тієї самої дальності зв'язку потужність `P_tx` у випадку спрямованої антени може бути зменшена пропорційно `G_omni / G_main`.

Відношення площ демаскування:

```
Area_dir / Area_omni = (θ_3dB / (2·π)) + (1 - θ_3dB / (2·π)) · (G_side / G_main)
```

**Числовий приклад:**
Нехай ширина променя антени `θ_3dB = 30° = π/6` рад (`θ_3dB / (2·π) = 1/12 ≈ 0.0833`).
Придушення бокових пелюсток становить 20 дБ, тобто `G_side / G_main = 0.01` (1%).

```
Area_dir / Area_omni = (1 / 12) + (11 / 12) · 0.01
                     = 0.0833 + 0.0092
                     = 0.0925    [зменшення площі перехоплення в 10.8 раза, або на 10.3 дБ]
```

Якщо придушення бокових пелюсток покращити до 30 дБ (`G_side / G_main = 0.001`), зона перехоплення звужується майже суто до головного променя (`Area_dir / Area_omni ≈ 0.0842`, зменшення в 11.9 раза).

### 4. Зведений баланс параметрів LPI

Сумарний виграш у скритності (зниження ймовірності виявлення `P_det` та площі `Area_det`) досягається комплексним застосуванням трьох факторів:

```
ΔFootprint_дБ = ΔP_TPC + ΔPattern_Gain + ΔToA_Processing
```

де:
- `ΔP_TPC = 10 · log₁₀(P_max / P_adaptive)` — виграш від роботи на мінімальній потужності (типово 10–18 дБ);
- `ΔPattern_Gain = 10 · log₁₀(Area_omni / Area_dir)` — виграш від просторової фільтрації (типово 10–15 дБ);
- `ΔToA_Processing = 5 · log₁₀(ToA_slow / ToA_burst)` — енергетичний програш радіометра через стиснення пачки (типово 5–8 дБ).

Сумарне стиснення зони перехоплення становить від 25 до 40 дБ (у 300–10 000 разів за площею), що перетворює помітний на десятки кілометрів радіовузол на локальну точкову ціль, виявну лише з безпосередньої близькості в межах вузького азимутального кута.
