# Аналіз кіл — детально

Базовий крок дав нам робочий рецепт: спрости групи, знайди повний струм, розгорни назад дільниками, а як не згортається — пиши систему Кірхгофа й перевіряй трьома самоперевірками. Цього досить, щоб узяти більшість схем на столі. Але «досить, щоб узяти» і «розумію до дна, чому воно взагалі мусить працювати» — це дві різні впевненості, і саме другу ми тепер здобуватимемо.

Тут ми не повторюватимемо рецепт, а **розберемо його механіку зсередини**: чому чотирьох знарядь справді досить і звідки вони самі беруться; як точно порахувати, скільки рівнянь потрібно, а не вгадувати; як довести до чисел вузловий метод, про який базовий крок лише згадав; що робити з місточком, який, як ми чесно визнали раніше, **не згортається** — і як його все-таки згорнути перетворенням, про яке там не йшлося; як обійти громіздку систему двома різними обхідними шляхами (накладанням і зведенням до джерела з опором); і, нарешті, де кожен метод **ламається** — бо інженер, що знає межі свого інструмента, вартий десятьох, що вірять йому наосліп.

Нитку ведемо просту: **спершу — фундамент** (звідки взялися знаряддя і скільки рівнянь треба), **тоді — три сильні методи**, яких базовий крок не розгортав (вузловий до чисел, Y-Δ, накладання, Тевенен–Нортон), **наприкінці — граничні випадки й пастки**. Усе спирається на вже пройдене; нового закону фізики попереду немає — є глибше володіння тими самими двома законами збереження.

### Чому чотирьох знарядь досить — і звідки вони беруться

У базовому кроці ми назвали чотири знаряддя так, ніби вони рівноправні: закон Ома, зведення груп, закон струмів, закон напруг. Це зручна брехня для початку. Насправді **незалежних знарядь лише три** — [закон Ома](book:electronics/ohms-law) та два закони Кірхгофа, — а зведення груп і дільники **не окремі закони, а їхні прямі наслідки**. Побачити це важливо не заради педантизму: коли розумієш, що дільник — це просто закони Кірхгофа, згорнуті в готову формулу, ти перестаєш його **заучувати** й починаєш **виводити на місці** щоразу, коли забув знак чи котре плече в чисельнику.

Виведімо всі чотири «похідні» знаряддя з трьох базових — це заразом найкраща розминка перед складнішими методами.

**Послідовне з'єднання.** Хай через ланцюжок резисторів R₁, R₂, …, Rₙ, з'єднаних [послідовно](book:electronics/series-connection), тече струм. [Закон струмів](book:electronics/kcl) у кожній точці стику каже: скільки заряду втекло, стільки й витекло, — а що гілка одна, деватися струмові нікуди, тож **через усі резистори тече той самий I**. [Закон напруг](book:electronics/kvl) для контуру «джерело → ланцюжок → назад» дає V = V₁ + V₂ + … + Vₙ. Підставляємо в кожен спад закон Ома Vₖ = I·Rₖ:

```
V = I·R₁ + I·R₂ + … + I·Rₙ = I·(R₁ + R₂ + … + Rₙ)
```

Ззовні ланцюжок бере той самий струм I під тією ж напругою V, що й один резистор опором R_екв = V/I. Порівнявши, читаємо:

```
R_екв = R₁ + R₂ + … + Rₙ      (послідовно опори додаються)
```

Не тому, що «так у формулі», а тому, що спільний струм і додавання спадів разом це диктують.

**Паралельне з'єднання.** Тепер резистори [паралельні](book:electronics/parallel-connection): усі приєднані до двох спільних вузлів, тож **на кожному одна й та сама напруга V**. Закон струмів у верхньому вузлі: повний струм розтікається по гілках, I = I₁ + I₂ + … + Iₙ. Кожен гілковий струм — за законом Ома Iₖ = V/Rₖ. Тут природніше говорити мовою **провідностей** G = 1/R (наскільки легко гілка пропускає струм), бо саме вони складаються:

```
I = V/R₁ + V/R₂ + … + V/Rₙ = V·(G₁ + G₂ + … + Gₙ)
G_екв = G₁ + G₂ + … + Gₙ       (паралельно ДОДАЮТЬСЯ провідності)
```

Провідності паралельних гілок додаються з тієї самої причини, з якої додавалися послідовні опори, — просто тепер спільна величина не струм, а напруга, і баланс пишемо для струмів. Для двох резисторів це згортається у знайоме «добуток на суму»:

```
R_екв = 1/G_екв = R₁·R₂/(R₁+R₂)
```

> 🔧 **Навіщо це.** Мова провідностей — не примха. Коли дійдемо до вузлового методу й до того, як [SPICE штампує матрицю](root:embedded/circuit-analysis/proj-mna-spice.md), уся система будуватиметься саме з провідностей, бо в кожному вузлі ми пишемо баланс **струмів**, а струм із напруги дістаємо множенням на G, не діленням на R. Хто звик мислити провідностями, той читає вузлові рівняння без єдиного ділення — і без єдиної описки в знаменнику.

**Дільник напруги.** Два послідовні резистори під напругою V: спільний струм I = V/(R₁+R₂), а спад на R₂ — це V₂ = I·R₂. Підставляємо:

```
V₂ = V · R₂/(R₁ + R₂)      ([дільник напруги](book:electronics/voltage-divider))
```

Напруга ділиться пропорційно опорам — бо струм спільний, а спад пропорційний опору.

**Дільник струму.** Дві паралельні гілки несуть повний струм I під спільною напругою V = I·R_екв = I·R₁R₂/(R₁+R₂). Струм у першій гілці I₁ = V/R₁:

```
I₁ = I · R₂/(R₁ + R₂)      ([дільник струму](book:electronics/current-divider) — БІЛЬШИЙ струм у МЕНШОМУ опорі)
```

Зверніть увагу на дзеркальність: у дільнику напруги в чисельнику стоїть **свій** опір гілки, а в дільнику струму — **чужий**. Це не випадковість і не те, що треба заучувати окремо: більший опір відбирає більший спад напруги, але пропускає менший струм, тож у формулі для струму «своє» плече мусить стояти в знаменнику, а «чуже» — вгорі. Хто вивів обидві формули отак, за півхвилини, той їх уже не сплутає.

Отже, справжній фундамент — три знаряддя: закон Ома й два закони збереження. Усе інше — зручні згортки, які варто вміти **відтворити**, а не лише згадати. А тепер — головне питання будь-якого систематичного методу.

### Скільки рівнянь потрібно — і чому саме стільки

Базовий крок дав два числа без доведення: незалежних рівнянь [закону струмів](book:electronics/kcl) рівно **N−1** (N — число вузлів), а [закону напруг](book:electronics/kvl) — рівно **B−N+1** (B — число гілок). Ці числа — не магія й не те, що варто брати на віру: вони випливають зі структури схеми як **графа**, і зрозуміти чому — значить назавжди позбутися страху «а чи не забув я рівняння» або «а чи не написав зайвого».

Погляньмо на схему очима топології, відкинувши номінали: лишаються самі **вузли** (точки з'єднання) і **гілки** (елементи між ними) — те, що вивчає [топологія кола](book:electronics/nodes-branches-loops). Виходить граф із N вузлів і B гілок.

**Чому рівнянь закону струмів рівно N−1.** Напишемо баланс струмів у кожному вузлі: сума втічних дорівнює сумі витічних. Здається, рівнянь N. Але вони **не всі незалежні**. Складімо всі N рівнянь докупи: кожна гілка з'єднує рівно два вузли, тож її струм входить в одне вузлове рівняння з плюсом, а в сусіднє — з мінусом, і в загальній сумі **скорочується дощенту**. Сума всіх N балансів тотожно дорівнює 0 = 0 — порожнеча. Отже, одне рівняння з N — надлишкове: воно автоматично випливає з решти. Візьмемо будь-яке одне (звичайно — вузол-«землю») і викинемо; лишається рівно **N−1 незалежних**. Фізичний сенс той самий, що ми відчули в базовому кроці: коли баланс сходиться в усіх вузлах, крім останнього, у ньому він сходиться сам — заряд, який не осів у перших, мусить бути саме там.

![Дерево й хорди: звідки беруться N−1 і B−N+1](/root/course/embedded/circuit-analysis/img/tree-cotree.svg)
*Граф кола розкладають на кістякове дерево (гілки, що сполучають усі вузли без жодного контуру — їх завжди N−1) і хорди (решта гілок — їх B−(N−1) = B−N+1). Кожна хорда, додана до дерева, замикає рівно один незалежний контур. Звідси й дві магічні цифри: N−1 незалежних балансів струмів і B−N+1 незалежних контурів для закону напруг.*

**Чому рівнянь закону напруг рівно B−N+1.** Тут ключ — поняття **кістякового дерева** (*spanning tree*). Оберемо підмножину гілок, яка сполучає всі N вузлів, але **не утворює жодного замкненого контуру**. Скільки таких гілок? Рівно **N−1**: перша гілка приєднує другий вузол до першого, кожна наступна — ще один новий вузол, і щоб дотягтися до всіх N вузлів без циклів, потрібно точно N−1 з'єднань (додаси ще одну — вона неминуче замкне контур, бо всі вузли вже зв'язані). Це дерево. Решта гілок — їх B−(N−1) = **B−N+1** — звуться **хордами** (*cotree*, доповнення до дерева). І ось головне: **кожна хорда, повернута в схему, замикає рівно один новий контур** — той, що проходить цією хордою й далі єдиним шляхом по дереву. Ці контури незалежні (кожен містить хорду, якої немає в жодному іншому), і їх рівно стільки, скільки хорд, — **B−N+1**. Більше незалежних контурів у схемі просто немає: будь-який інший контур є комбінацією цих.

Складімо баланс. Невідомих у «лобовому» методі — B гілкових струмів. Рівнянь: (N−1) від закону струмів плюс (B−N+1) від закону напруг. Сума:

```
(N − 1) + (B − N + 1) = B      рівнянь рівно стільки, скільки невідомих ✓
```

Система розв'язна, і жодного рівняння не бракує й не зайве. Саме цей підрахунок — фундамент під **обидва** систематичні методи. Контурний (метод [Максвелла](root:embedded/circuit-analysis/hist-maxwell-mesh.md)) бере за невідомі B−N+1 контурних струмів і пише лише закон напруг: рівнянь стає B−N+1. Вузловий бере N−1 вузлових напруг і пише лише закон струмів: рівнянь N−1. Обидва методи — це не різні фізики, а два способи **наперед задовольнити один із законів вибором зручного невідомого**, щоб писати тільки другий. Тепер, коли ми точно знаємо ці числа й **звідки** вони, розгорнімо вузловий метод до кінця — базовий крок його лише назвав.

### Вузловий метод: від ідеї до чисел

У контурного методу є рідний брат — **метод вузлових напруг** (*nodal analysis*). Ідея дзеркальна до контурної. Там ми брали за невідомі струми, що циркулюють по контурах, і закон струмів виконувався сам собою. Тут беремо за невідомі **потенціали вузлів** — і сам собою виконується закон напруг: якщо кожен вузол має один-єдиний потенціал, то спад по будь-якому контуру автоматично сходиться до нуля (обійшов і повернувся в ту саму точку з тим самим потенціалом), тож закон напруг писати не треба — лишається сам закон струмів у вузлах.

Механіка така. Обираємо один вузол **землею** — точкою відліку з потенціалом 0. Решті N−1 вузлів приписуємо невідомі потенціали V₁, V₂, …. У кожному з цих вузлів пишемо [закон струмів](book:electronics/kcl), але струм крізь кожен резистор виражаємо **через потенціали його кінців**: струм із вузла a у вузол b по резистору R дорівнює (Vₐ − V_b)/R = (Vₐ − V_b)·G. Ось де провідності, які ми ввели раніше, окупаються сповна — рівняння виходять майже механічно.

Виведімо загальний вигляд рівняння одного вузла. Хай у вузол a вкидає струм зовнішнє джерело струму Iₐ, а сам вузол з'єднаний резисторами-провідностями з деякими сусідами. Баланс «сума витічних струмів = вкинутому» дає:

```
Σ_сусіди  (Vₐ − V_сусід)·G = Iₐ
```

Розкриємо суму. Потенціал самого вузла Vₐ множиться на **суму всіх провідностей, що до нього приєднані**, а кожен сусідній потенціал — на провідність спільної гілки з мінусом:

```
Vₐ·(Σ усіх G при вузлі a)  −  Σ (V_сусід · G_між a і сусідом)  =  Iₐ
```

Це і є рядок майбутньої матриці, і в ньому вже видно її структуру: **на діагоналі** (коефіцієнт при власному потенціалі) — сума всіх провідностей вузла, **поза діагоналлю** — мінус провідність спільної гілки. Звідси випливає гарна властивість: матриця **симетрична** (провідність між a і b така сама, як між b і a) і **діагонально переважна** — саме тому вузловий метод такий стійкий у машинному розрахунку, і саме цей рядок [SPICE «штампує» автоматично](root:embedded/circuit-analysis/proj-mna-spice.md), не питаючи людину про контури. Але спершу зробімо це руками.

**Приклад 1 (вузловим методом). V = 12 В через R₁ = 100 Ω у вузол A; від A на землю — R₂ = 200 Ω паралельно з R₃ = 300 Ω.**

Це те саме сімейство, що й перший приклад базового кроку, але з несиметричним навантаженням, щоб числа не «зійшлися випадково». Один невідомий вузол — A (землю й вузол джерела за неї не рахуємо). Джерело напруги 12 В через R₁ — це, за законом Ома, струм (12 − Vₐ)/R₁, що **втікає** в A. Пишемо баланс струмів у A: втічний = сумі витічних у землю:

```
провідності: G₁ = 1/100 = 0.01;  G₂ = 1/200 = 0.005;  G₃ = 1/300 ≈ 0.003333 См

баланс у вузлі A (усі струми з A назовні = 0):
   (Vₐ − 12)·G₁ + Vₐ·G₂ + Vₐ·G₃ = 0
   Vₐ·(G₁ + G₂ + G₃) = 12·G₁
   Vₐ·(0.01 + 0.005 + 0.003333) = 12·0.01
   Vₐ·0.018333 = 0.12
   Vₐ = 0.12 / 0.018333 = 6.545 В

струм від джерела:   I = (12 − 6.545)/100 = 54.55 мА
струми в навантаженні: I₂ = 6.545/200 = 32.73 мА
                        I₃ = 6.545/300 = 21.82 мА
перевірка KCL:        32.73 + 21.82 = 54.55 мА = I  ✓
```

Одне рівняння — одна невідома, і відповідь читається фізично: навантаження R₂∥R₃ = 120 Ω разом із R₁ = 100 Ω утворює дільник, тож на навантаженні сидить 12·120/220 = 6.545 В — рівно те, що дала матриця. Тут вузловий метод переміг згортання лише трохи (обидва прості), і це чесно: **сила вузлового методу — там, де вузлів мало, а гілок і джерел багато**. Візьмімо саме такий випадок — той самий дводжерельний місток, що в базовому кроці ми брали контурами, і розв'яжімо його вузлово, щоб на власні очі побачити: відповідь **та сама**.

**Приклад 2 (вузловим методом; те саме коло, що контурами в базовому кроці). V₁ = 10 В через R₁ = 10 Ω у вузол A; V₂ = 6 В через R₂ = 10 Ω у той самий вузол A; від A на землю — R₃ = 20 Ω.**

Тут лише **один** невідомий вузол A — обидва джерела через свої резистори збігаються в ньому, а другі кінці джерел сидять на землі. Вузловий метод показує свою перевагу відразу: замість двох контурних рівнянь — одне вузлове.

```
G₁ = 0.1;  G₂ = 0.1;  G₃ = 0.05 См

баланс у A:  (Vₐ − 10)·G₁ + (Vₐ − 6)·G₂ + Vₐ·G₃ = 0
             Vₐ·(0.1 + 0.1 + 0.05) = 10·0.1 + 6·0.1
             Vₐ·0.25 = 1.0 + 0.6 = 1.6
             Vₐ = 6.4 В

струм крізь R₃:  I₃ = 6.4/20 = 0.32 А  (з A на землю, тобто «вниз»)
струм від V₁:    I₁ = (10 − 6.4)/10 = 0.36 А
струм від V₂:    I₂ = (6 − 6.4)/10 = −0.04 А   (мінус: V₂ насправді СПОЖИВАЄ струм)
перевірка KCL:   0.36 + (−0.04) = 0.32 А = I₃  ✓
```

Порівняймо з базовим кроком: там контурний метод дав I₃ = Iₐ − I_b = 0.36 − 0.44 = −0.08 А **у спільній гілці R₃** при іншій топології (R₃ була перемичкою між двома контурами). Тут топологія розставлена інакше — R₃ висить із вузла A на землю, — і пряма звірка чисел зайва; вагоме інше: **вузловий метод дав однозначну, фізично осмислену відповідь одним рівнянням** там, де контурний потребував двох. І знову з'явився повчальний мінус: I₂ = −0.04 А означає, що слабше джерело V₂ (6 В) не віддає струм, а **приймає** його — сильніше джерело V₁ підтягнуло вузол A до 6.4 В, вище за 6 В самого V₂, тож струм тече назад у V₂. Це не помилка розрахунку, а фізика: так, наприклад, сильніша батарея підзаряджає слабшу, з'єднану паралельно. Метод чесно це показує, а знак — читає.

Отже, коли обирати вузловий, коли контурний? Правило з базового кроку тепер має точне обґрунтування: **порахуй N−1 і B−N+1 і бери менше**, бо менше невідомих — менша матриця — менше праці й менше місць для описки. Для схем із кількома джерелами, збіжними в небагатьох вузлах (типова аналогова обв'язка навколо операційного підсилювача), вузлів мало — виграє вузловий. Для планарних сіток із багатьма вічками, як-от резисторні драбинки, менше буває контурів — виграє контурний. Обидва — та сама фізика під різним кутом.

### Місток, що не згортається: перетворення зірка–трикутник

У базовому кроці ми чесно вперлися в стіну: [міст Вітстона](book:electronics/wheatstone-bridge) — п'ять резисторів, зчеплених так, що **жодна пара не виходить ані суто послідовною, ані суто паралельною**, — згортанням не береться, і ми відступили до системи рівнянь. Це був чесний, але не повний висновок. Насправді існує знаряддя, що **повертає згортання навіть таким схемам** — перетворення **зірка ↔ трикутник** (його ще звуть Y-Δ, «ігрек–дельта», або, в силовій електротехніці, «зірка–трикутник»).

Придивімося, **чому** місток не згортається. Три резистори збігаються в центральному вузлі, утворюючи фігуру-«зірку» (Y): три промені з одного центра. Або, як подивитися інакше, ті самі три зовнішні вузли сполучені по колу трьома резисторами — «трикутником» (Δ), без центрального вузла взагалі. Ані в зірці, ані в трикутнику немає **простої** пари «послідовно» чи «паралельно»: у зірці кожен промінь ділить із сусідом лише центр (не два вузли), у трикутнику кожна сторона окремо веде до різних пар. Згортання, яке вміє лише додавати послідовне й паралельне, тут безсиле — не через свою слабкість, а тому, що в цій фігурі **немає того, що воно вміє згортати**. Обидві фігури — зірка й трикутник — це, по суті, дві різні форми з'єднати ту саму трійку вузлів; докладніше про сам [атом «зірка ↔ трикутник» — в окремій статті](book:electronics/y-delta-transform).

**Ідея.** Що, якби ми могли замінити зірку на еквівалентний трикутник (або навпаки), не змінивши нічого, що бачить решта схеми? Тоді в перемальованій схемі раптом з'являться послідовні й паралельні пари, яких бракувало, — і згортання знову піде. Ключове слово — **еквівалентний**: зовнішній світ дотикається до фігури лише в трьох вузлах (1, 2, 3), і йому байдуже, що всередині — зірка чи трикутник, аби **опір, виміряний між будь-якою парою зовнішніх вузлів, лишався той самий**. Ось і весь критерій еквівалентності: три опори між трьома парами вузлів мусять збігатися в обох формах. Прирівнявши їх, дістаємо формули перетворення.

Наведу робочі формули (докладне їх [виведення прирівнюванням трьох опорів — окремо](root:embedded/circuit-analysis/math-y-delta.md), щоб не рвати тут нитку). Позначмо опори зірки Rₐ, R_b, R_c (промінь до вузла 1, 2, 3 відповідно), а сторони трикутника — R₂₃, R₃₁, R₁₂ (сторона, протилежна вузлові 1, 2, 3).

**Трикутник → зірка** (кожен промінь = добуток двох прилеглих сторін, поділений на суму всіх трьох):

```
Rₐ = R₁₂·R₃₁ / (R₁₂ + R₂₃ + R₃₁)
R_b = R₁₂·R₂₃ / (R₁₂ + R₂₃ + R₃₁)
R_c = R₂₃·R₃₁ / (R₁₂ + R₂₃ + R₃₁)
```

**Зірка → трикутник** (кожна сторона = сума попарних добутків променів, поділена на протилежний промінь):

```
R₁₂ = (Rₐ·R_b + R_b·R_c + R_c·Rₐ) / R_c
R₂₃ = (Rₐ·R_b + R_b·R_c + R_c·Rₐ) / Rₐ
R₃₁ = (Rₐ·R_b + R_b·R_c + R_c·Rₐ) / R_b
```

Мнемоніка проста, якщо тримати в голові її **причину**, а не букви. У напрямку «трикутник → зірка» промінь до вузла тягнеться до **двох** сторін, що в цьому вузлі сходяться, — тому в чисельнику їх добуток, а в знаменнику — периметр (сума трьох). У зворотному напрямку сторона трикутника «обходить» **протилежний** промінь — тому саме він у знаменнику. Хто бачить цю логіку, той не плутає, що куди.

Пройдімо повний числовий приклад — той самий місток, що зупинив нас у базовому кроці, тепер згорнутий дощенту.

![Місток Вітстона: Y-Δ перетворення розчищає шлях згортанню](/root/course/embedded/circuit-analysis/img/bridge-reduce.svg)
*Місток із п'яти резисторів згортанням не береться. Крок 1: верхній трикутник (R₁, R₂, R₅) замінюємо еквівалентною зіркою (Rₐ, R_b, R_c) — це нічого не міняє для решти схеми. Крок 2: у новій схемі промінь R_b послідовний із R₃, промінь R_c — з R₄; ці дві послідовні пари тепер паралельні між собою. Крок 3: додаємо послідовно верхній промінь Rₐ — і лишається єдиний R_екв. Стіна, об яку впирався базовий крок, обійдена.*

**Приклад 3 (місток Вітстона через Y-Δ). Верхній трикутник: R₁ = 100 Ω (вузол джерела→A), R₂ = 100 Ω (вузол джерела→B), R₅ = 50 Ω (перемичка A→B). Нижні плечі: R₃ = 200 Ω (A→низ), R₄ = 200 Ω (B→низ). Живлення 10 В між верхнім вузлом і низом. Знайти повний опір і струм від джерела.**

Верхні три резистори (R₁, R₂, R₅) утворюють трикутник між трьома вузлами: верхнім (джерело, назвемо T), A і B. Перетворимо його на зірку з новим центром M і променями до T, A, B:

```
периметр трикутника: P = R₁ + R₂ + R₅ = 100 + 100 + 50 = 250 Ω

промінь до T (між сторонами R₁ і R₂):   R_T = R₁·R₂/P = 100·100/250 = 40 Ω
промінь до A (між сторонами R₁ і R₅):   R_A = R₁·R₅/P = 100·50 /250 = 20 Ω
промінь до B (між сторонами R₂ і R₅):   R_B = R₂·R₅/P = 100·50 /250 = 20 Ω
```

Тепер схема стала згортаною. Від центра M: промінь R_A (20) послідовний із R₃ (200) — це гілка M→A→низ = 220 Ω; промінь R_B (20) послідовний із R₄ (200) — гілка M→B→низ = 220 Ω. Ці дві гілки **паралельні** (обидві від M до низу):

```
гілка через A:  R_A + R₃ = 20 + 200 = 220 Ω
гілка через B:  R_B + R₄ = 20 + 200 = 220 Ω
паралельно:     220 ∥ 220 = 110 Ω
плюс промінь до джерела:  R_екв = R_T + 110 = 40 + 110 = 150 Ω

повний струм від джерела:  I = 10/150 = 66.7 мА
```

Стіна впала: те, що в базовому кроці змусило нас писати систему, тепер розв'язалося чистим згортанням — бо Y-Δ прибрало саме ту зчепленість, яка заважала. Це знаряддя незамінне для мостових давачів (тензодавач, [міст Вітстона](book:electronics/wheatstone-bridge) під тиск чи температуру), де швидко оцінити повний опір і струм треба часто, а тягати щоразу систему — марнотратство. Варто, щоправда, знати межу: у **зрівноваженому** мості (коли R₁/R₃ = R₂/R₄) перемичкою R₅ струм не тече взагалі, і тоді Y-Δ не потрібне — гілки й так виходять просто послідовно-паралельними. Y-Δ рятує саме **незрівноважений** місток. Історію самого перетворення — хто, коли й як його вивів — винесено в [окрему довідку про мережеві теореми](root:embedded/circuit-analysis/hist-network-theorems.md), разом із Тевененом і Нортоном, до яких переходимо далі.

### Накладання: розбити задачу з багатьма джерелами на прості

Дводжерельне коло ми досі брали в лоб — системою рівнянь. Є, однак, зовсім інший шлях, що часто дає відповідь швидше й, головне, дає **розуміння**, який внесок вносить кожне джерело окремо. Він зветься **[накладанням](book:electronics/superposition)** (*superposition* — від латинського *super* «над» + *positio* «покладання», буквально «накладання одного на одне»), і працює він тільки завдяки одній фундаментальній властивості наших кіл — **лінійності**.

Що таке лінійність тут? Усі наші елементи — резистори — підкоряються закону Ома V = I·R, де R стале: подвій напругу — подвоїться струм, склади дві дії — складеться відгук. Кола з таких елементів звуть **лінійними**, і для них справджується принцип накладання: **відгук (будь-який струм чи напруга) від кількох джерел дорівнює сумі відгуків від кожного джерела окремо**, коли решту джерел «вимкнено». Це прямий наслідок того, що рівняння Кірхгофа для таких кіл — лінійні: сума розв'язків лінійної системи для окремих правих частин є розв'язком для суми правих частин. Джерела в цих рівняннях сидять якраз у правій частині — тому їх і можна розкладати поодинці.

Уся тонкість — у слові **«вимкнено»**, і тут криється найчастіша помилка. Вимкнути джерело — не означає «викинути з схеми»; означає **звести його дію до нуля, лишивши на місці його внутрішню природу**:

```
вимкнути джерело НАПРУГИ  →  замінити КОРОТКИМ ЗАМИКАННЯМ (дротом)
   бо джерело напруги з нульовою напругою — це і є ідеальний провідник (V=0)

вимкнути джерело СТРУМУ   →  замінити РОЗРИВОМ (прибрати гілку)
   бо джерело струму з нульовим струмом не проводить нічого (I=0)
```

Чому саме так — видно з означення: ідеальне джерело напруги тримає задану різницю потенціалів; «нуль вольт» — це дріт. Ідеальне джерело струму жене заданий струм; «нуль ампер» — це обрив. Переплутати їх (закоротити струмове або обірвати напругове) — типова й підступна помилка, бо схема наче й лишається схемою, але фізику ти вже зруйнував.

![Накладання: увімкни джерела по черзі й склади відгуки](/root/course/embedded/circuit-analysis/img/superposition.svg)
*Дводжерельне коло розкладають на два простих. Ліворуч живе лише V₁ (V₂ закорочено дротом) — рахуємо його внесок у шуканий струм звичайним згортанням. Посередині живе лише V₂ (V₁ закорочено) — рахуємо його внесок. Праворуч — повний відгук = сума двох (з урахуванням знаків). Кожен доданок — проста згортана схема, замість однієї системи рівнянь.*

Пройдімо накладанням те саме дводжерельне коло з базового кроку й переконаймося, що дістанемо ту саму відповідь.

**Приклад 4 (накладанням; коло з прикладу 2). V₁ = 10 В і V₂ = 6 В, кожне через свій резистор 10 Ω, збігаються у вузлі A; від A на землю — R₃ = 20 Ω. Знайти напругу вузла A.**

*Внесок V₁ (вимикаємо V₂ — закорочуємо його на землю через R₂):*

```
V₂ закорочене → R₂ (10 Ω) тепер веде з A прямо на землю, паралельно з R₃ (20 Ω).
Навантаження на A:  R₂∥R₃ = 10·20/30 = 6.667 Ω
Це дільник: V₁ (10 В) через R₁ (10 Ω) на навантаження 6.667 Ω:
   Vₐ' = 10 · 6.667/(10 + 6.667) = 10 · 6.667/16.667 = 4.0 В
```

*Внесок V₂ (вимикаємо V₁ — закорочуємо його через R₁):*

```
V₁ закорочене → R₁ (10 Ω) тепер веде з A на землю, паралельно з R₃ (20 Ω).
Навантаження на A:  R₁∥R₃ = 10·20/30 = 6.667 Ω
Дільник: V₂ (6 В) через R₂ (10 Ω) на навантаження 6.667 Ω:
   Vₐ'' = 6 · 6.667/(10 + 6.667) = 6 · 6.667/16.667 = 2.4 В
```

*Складаємо:*

```
Vₐ = Vₐ' + Vₐ'' = 4.0 + 2.4 = 6.4 В   ✓
```

Рівно те, що дав вузловий метод у прикладі 2. Але накладання дало **більше**, ніж число: воно показало **розклад** — вузол A сидить на 6.4 В, з яких 4.0 В «поставило» сильне джерело V₁, а 2.4 В — слабке V₂. Такий розклад безцінний, коли треба зрозуміти, **хто винен** у небажаному зміщенні робочої точки, або порахувати внесок пульсацій живлення окремо від корисного сигналу.

> 🔧 **Навіщо це.** Накладання — робочий кінь аналогової практики. Реальний вузол часто живиться від кількох джерел одночасно: корисний сигнал, постійне зміщення, пульсації від живлення, наведення. Накладання дозволяє порахувати внесок кожного **окремо** й тими самими простими дільниками — а тоді скласти. Саме так рахують, наприклад, вихід підсилювача, до якого приходять і сигнал, і опорна напруга: кожен рахуємо своїм дільником, ніби інший вимкнено, і додаємо.

Два застереження, без яких накладання підведе. **Перше: воно працює тільки для лінійних кіл.** Діод, транзистор у нелінійному режимі, будь-який елемент, чий «опір» залежить від напруги, ламає принцип — сума окремих відгуків уже не дорівнює повному. **Друге, і найпідступніше: накладати можна струми й напруги, але НЕ потужність.** Потужність P = I²·R квадратична за струмом, а квадрат суми не дорівнює сумі квадратів: (I' + I'')² ≠ I'² + I''². Тому, щоб знайти потужність на резисторі за двох джерел, спершу склади струми (їх — можна!), а потім піднось до квадрата **повний** струм; рахувати потужності від джерел окремо й додавати — груба помилка. І ще: якщо в схемі є **[залежні джерела](book:electronics/dependent-sources)** (керовані напругою чи струмом іншої частини кола), їх при накладанні **не вимикають** — вони не самостійні, а лише відображають стан кола, тож мусять лишатися активними на кожному кроці.

### Тевенен і Нортон: будь-яку двополюсну частину — до джерела з опором

Найпотужніша ідея всього аналізу приберігається наостанок. Уяви складну лінійну схему — десятки резисторів, кілька джерел, — до якої ти хочеш під'єднати навантаження й подивитися, що буде при різних його значеннях. Рахувати всю схему заново для кожного номіналу навантаження — виснажливо. **Теорема Тевенена** каже дещо приголомшливе: **хоч яка складна лінійна схема, якщо дивитися на неї з двох затискачів, поводиться точнісінько як ОДНЕ джерело напруги послідовно з ОДНИМ резистором**. Уся її нутрощі — байдуже скільки елементів — з погляду цих двох затискачів згортаються у пару чисел: V_th (напруга Тевенена) і R_th (опір Тевенена).

Чому це взагалі мусить бути правдою? Знову — **лінійність**. Приєднай до затискачів пробний струм I і виміряй напругу V на них. Оскільки все коло лінійне, залежність V від I може бути тільки **прямою лінією**: V = V₀ − I·R для якихось сталих V₀ і R (лінійна функція — це пряма, іншого лінійність не дозволяє). Але ж рівняння прямої V = V₀ − I·R — це рівно опис джерела напруги V₀ послідовно з резистором R! Тобто **будь-яка** лінійна двополюсна схема нерозрізненна ззовні від такої пари. V₀ — це напруга на розімкнених затискачах (при I=0), а R — нахил тієї прямої. Ось і вся теорема: вона не постулат, а неминучий наслідок того, що лінійна залежність — це пряма.

![Тевенен: будь-яку лінійну двополюсну схему — до V_th і R_th](/root/course/embedded/circuit-analysis/img/thevenin.svg)
*Хоч яка складна лінійна схема (ліворуч, у «хмарі») з двох затискачів поводиться як джерело V_th послідовно з R_th (посередині). V_th = напруга на РОЗІМКНЕНИХ затискачах (навантаження від'єднане). R_th = опір, який бачать затискачі, коли всі внутрішні джерела вимкнено (напругові — закоротити, струмові — розірвати). Праворуч — дуальна форма Нортона: те саме коло як джерело струму I_n = V_th/R_th паралельно з тим самим R_th.*

Як знайти цю пару на практиці — три способи, і варто володіти всіма трьома, бо для різних схем зручний різний.

**V_th — завжди однаково: напруга розімкненого кола.** Від'єднай навантаження й порахуй (будь-яким методом — згортанням, вузловим, накладанням) напругу між затискачами. Це й є V_th, бо при від'єднаному навантаженні струм крізь R_th нульовий, спаду на ньому немає, і на затискачах виступає повна внутрішня напруга.

**R_th — три способи його знайти:**

```
Спосіб 1 (вимкнути джерела):  усі НЕЗАЛЕЖНІ джерела вимкни
   (напругові → закоротити, струмові → розірвати) і порахуй опір,
   який бачать затискачі. Найшвидший — коли джерела незалежні.

Спосіб 2 (струм короткого):  закороти затискачі, порахуй струм I_sc,
   що потече. Тоді R_th = V_th / I_sc. Працює ЗАВЖДИ, зокрема
   із залежними джерелами (їх вимикати не можна — див. нижче).

Спосіб 3 (пробне джерело):  вимкни лише незалежні джерела, під'єднай
   до затискачів пробне джерело 1 В, виміряй струм I, що втече;
   R_th = 1/I. Єдиний спосіб, коли в схемі САМІ залежні джерела
   (тоді короткого струму нема від чого рахувати).
```

Пройдімо повний приклад — той-таки дводжерельний вузол, тепер зведений до Тевенена, щоб побачити метод у дії.

**Приклад 5 (еквівалент Тевенена). Знайти, чим для навантаження є вузол A з прикладу 2: V₁ = 10 В і V₂ = 6 В, кожне через 10 Ω, збігаються у A; R₃ = 20 Ω від A на землю. Затискачі — вузол A і земля.**

*Крок 1 — V_th (напруга розімкненого кола).* Від'єднаємо навантаження — але зачекай, R₃ тут частина самого кола, не навантаження; навантаженням буде те, що ми **приєднаємо** до A ззовні. Тож V_th — це просто напруга A при відсутності зовнішнього навантаження, яку ми вже двічі порахували: **V_th = 6.4 В**.

*Крок 2 — R_th способом 1 (джерела незалежні — вимикаємо).* Закоротимо V₁ і V₂ (обидва — джерела напруги). Тоді з вузла A на землю ведуть три шляхи паралельно: R₁ (10, через закорочене V₁), R₂ (10, через закорочене V₂) і R₃ (20):

```
R_th = R₁ ∥ R₂ ∥ R₃ = 1/(1/10 + 1/10 + 1/20) = 1/(0.1 + 0.1 + 0.05) = 1/0.25 = 4 Ω
```

*Перевірка способом 2 (струм короткого).* Закоротимо A на землю й порахуємо струм у цьому короткому. При закороченому A (Vₐ=0) струм від V₁: 10/10 = 1 А; від V₂: 6/10 = 0.6 А; через R₃ (обидва кінці на землі) — 0. Струм короткого I_sc = 1 + 0.6 = 1.6 А. Тоді:

```
R_th = V_th / I_sc = 6.4 / 1.6 = 4 Ω   ✓ (збіглося зі способом 1)
```

Отже, для будь-якого навантаження, приєднаного до A, уся ця схема — це просто **6.4 В послідовно з 4 Ω**. Хочеш знати струм у навантаженні R_н? Одне ділення: I = 6.4/(4 + R_н). Замість того щоб щоразу перерозв'язувати все коло, ти маєш дві цифри — і будь-яке питання про навантаження стає задачею на один дільник.

**Дуальна форма — Нортон.** Те саме коло можна подати дзеркально: **джерело струму I_n паралельно з тим самим R_th**, де I_n = V_th/R_th (це і є струм короткого, що ми порахували вище). Для нашого прикладу: I_n = 6.4/4 = 1.6 А паралельно з 4 Ω. Тевенен і Нортон — не два різні кола, а два описи одного й того самого, зв'язані [перетворенням джерела](book:electronics/source-transformation): V_th = I_n·R_th. Коли зручніше мислити напругою (послідовне навантаження) — бери Тевенена; коли струмом (паралельне) — Нортона.

> 🔧 **Навіщо це.** Тевенен — це те, чим інженер користується щодня, часто не називаючи. [Внутрішній опір](book:electronics/internal-resistance) батареї — це R_th її еквівалента. Вихідний опір каскаду, вхідний опір наступного, «жорсткість» опорної напруги — усе це R_th. Дільник напруги, навантажений реальним споживачем, «просідає» рівно на стільки, скільки диктує його R_th (= R₁∥R₂). Хто мислить схему як «джерело з опором», той миттю оцінює, чи витримає вузол навантаження, — не рахуючи всієї схеми заново.

Одне важливе застереження, дзеркальне до накладання: спосіб 1 (вимкнути джерела) годиться лише для **незалежних** джерел. Якщо в схемі є [залежні джерела](book:electronics/dependent-sources), їх вимикати **не можна** — вони частина «характеру» кола; тоді R_th шукають способом 2 (струм короткого) або способом 3 (пробне джерело). Це та сама причина, що й у накладанні: залежне джерело не самостійне, воно відображає стан кола, і, прибравши його, ти зміниш саму схему, а не лише вимкнеш зовнішній вплив.

Наостанок — гарний наслідок, який Тевенен робить очевидним. Коли навантаження R_н дорівнює R_th, у ньому виділяється **максимальна потужність** (теорема про узгодження навантаження): дільник V_th на R_th і R_н віддає в R_н найбільше саме при R_н = R_th. Це видно й без похідної — з симетрії: замале R_н майже закорочене (мала напруга на ньому), завелике майже розімкнене (малий струм), а найбільший добуток V·I — посередині, при рівності. Саме тому антену узгоджують із приймачем, а гучномовець — із підсилювачем: не заради «максимального ККД» (він при узгодженні лише 50%), а заради максимуму переданої **потужності**.

### Де методи ламаються: граничні випадки й пастки

Інженер відрізняється від того, хто вивчив формули, знанням **меж** своїх інструментів. Зберімо докупи випадки, де кожен метод спотикається, — не як список заборон, а з механізмом, щоб ти впізнавав їх на льоту.

**Суперечливі ідеальні джерела.** Два різні ідеальні джерела напруги, з'єднані паралельно (10 В і 6 В прямо, без жодного опору між ними), — фізична нісенітниця: закон напруг вимагає, щоб напруга між двома вузлами була одночасно 10 і 6 В, що неможливо. Реальні джерела рятує їхній внутрішній опір (той самий R_th), який ковтає різницю; ідеальні ж дають вироджену, нерозв'язну систему. Дзеркально: два різні джерела струму послідовно суперечать закону струмів. Побачив у схемі таке — знай, що бракує опору, який у реальності неминуче є.

**Висячий вузол.** Якщо вузол не має **жодного шляху постійного струму до землі** (наприклад, з'єднаний із рештою схеми лише через конденсатори, які для постійного струму — обрив), його потенціал не визначений: система вироджена, а вузловий метод натрапить на нульовий головний елемент — [ділення на нуль при зведенні матриці Гаусом](book:math/gauss-elimination). Це не помилка методу, а чесний сигнал, що схема недовизначена. Саме тому [SPICE нишком додає крихітну провідність gmin](root:embedded/circuit-analysis/proj-mna-spice.md) між кожним вузлом і землею — щоб матриця перестала бути виродженою; ту саму пастку ми зустріли, коли розбирали, [як машина розв'язує кола](root:embedded/circuit-analysis/proj-mna-spice.md).

**Джерело напруги у вузловому методі.** Чистий вузловий метод спотикається об ідеальне джерело напруги між двома **не-земляними** вузлами: його струм невідомий, а провідність «нескінченна» (R=0) у матрицю не влазить. Ручний обхід — **супервузол** (*supernode*): обвести обидва вузли однією межею, написати закон струмів для них разом (внутрішній струм джерела при цьому скорочується), а бракуюче рівняння дати самою умовою джерела Vₐ − V_b = Vs. Машинний обхід — та сама [«модифікація» в MNA](root:embedded/circuit-analysis/proj-mna-spice.md): струм джерела роблять новою невідомою й дописують рядок. Обидва — про одне: коли невідома величина не влазить у звичну схему рівнянь, її додають окремим невідомим із окремим рівнянням.

**Залежні джерела — тричі згадана пастка, зберімо в одне.** [Керовані джерела](book:electronics/dependent-sources) (модель транзистора, підсилювача) при накладанні **не вимикають**, при пошуку R_th способом 1 **не вимикають** — бо вони не самостійне збудження, а частина передавальної характеристики кола. З ними R_th шукають струмом короткого або пробним джерелом, а накладати можна лише незалежні джерела, лишаючи залежні активними. Один принцип за трьома проявами: **вимикати можна тільки те, що збуджує коло ззовні; те, що відображає його внутрішній стан, чіпати не можна**.

**Потужність не накладається, знак не страшний.** Два уроки, які варто закарбувати. Потужність квадратична — її рахують від **повних** струмів і напруг, ніколи не додаючи покомпонентних потужностей. А от **знак** будь-якого струму чи напруги накладати й отримувати від'ємним — нормально: мінус лише каже, що реальний напрямок протилежний до навмання обраного, і метод сам це виправляє, як ми не раз бачили.

Зведімо все у ширший рецепт, ніж у базовому кроці, — з новими знаряддями на своїх місцях.

![Розширений рецепт: коли який метод пускати в хід](/root/course/embedded/circuit-analysis/img/method-map.svg)
*Карта вибору методу. Схема згортається (послідовно-паралельні групи)? → згортання + дільники, найшвидше. Місток / зчеплені трикутники? → спершу Y-Δ, тоді згортання. Кілька джерел? → накладання (внесок кожного окремо) АБО система рівнянь. Питання про одне навантаження при різних номіналах? → Тевенен/Нортон (усе інше — у пару чисел). Багато вузлів і гілок? → систематичний метод (вузловий чи контурний — бери той, де менше невідомих). І завжди наприкінці — три самоперевірки: одиниці, баланси Кірхгофа, порядок величин.*

Порядок думки такий. **Спробуй згортання** — для більшості схем воно найшвидше. **Не згортається через місток** — застосуй Y-Δ, і згортання оживе. **Кілька джерел, і цікавить внесок кожного** — накладання; **просто потрібні всі струми** — систематична система (вузлова, якщо вузлів мало; контурна, якщо контурів мало). **Питання лише про одне навантаження, та ще й за різних його значень** — зведи решту до Тевенена чи Нортона, і кожна відповідь стане одним діленням. А наприкінці **завжди** — три самоперевірки з базового кроку: одиниці, баланси Кірхгофа, порядок величин. Вони не залежать від обраного методу, бо перевіряють не метод, а саму фізику, яку жоден метод не має права порушити.

### Той самий аналіз — у коді прошивки

Уся ця теорія перетворюється на кілька рядків C, коли треба **на самому мікроконтролері** відновити реальну напругу за виміряним кодом [АЦП](book:electronics/adc) або оцінити просідання під навантаженням. Розберімо два практичні клапті, що прямо випливають із розібраного.

**Перше — вузловий солвер у мініатюрі.** Той самий баланс провідностей, що ми писали руками, лягає в кілька рядків: зберемо провідності вузла й вкинуті струми та поділимо. Для одного вузла з кількома провідностями на землю й кількома джерелами напруги через резистори:

```c
#include <stdio.h>

/* Напруга одного вузла, до якого приходять джерела Vk через Rk
   і висять резистори на землю Rg[]. Це прямий запис вузлового рівняння:
   V_вузла = (Σ Vk·Gk) / (Σ Gk усіх приєднаних провідностей).           */
static float node_voltage(const float *v_src, const float *r_src, int ns,
                          const float *r_gnd, int ng) {
    float sum_g = 0.0f;   /* знаменник: сума ВСІХ провідностей вузла */
    float sum_ig = 0.0f;  /* чисельник: сума струмів, вкинутих джерелами */
    for (int k = 0; k < ns; k++) {      /* джерела напруги через резистор */
        float g = 1.0f / r_src[k];
        sum_g  += g;
        sum_ig += v_src[k] * g;         /* внесок джерела = Vk·Gk (струм) */
    }
    for (int k = 0; k < ng; k++)        /* пасивні резистори на землю */
        sum_g += 1.0f / r_gnd[k];
    return sum_ig / sum_g;
}

int main(void) {
    /* Приклад 2: V1=10В через 10Ω, V2=6В через 10Ω; R3=20Ω на землю */
    float vs[] = {10.0f, 6.0f};
    float rs[] = {10.0f, 10.0f};
    float rg[] = {20.0f};
    float va = node_voltage(vs, rs, 2, rg, 1);
    printf("V(A) = %.2f В\n", va);       /* 6.40 В — як руками й вузловим методом */
    return 0;
}
```

Це буквально формула Vₐ·ΣG = ΣVₖGₖ, яку ми вивели в розділі про вузловий метод, покладена в цикл. Проженімо в голові: чисельник 10·0.1 + 6·0.1 = 1.6; знаменник 0.1 + 0.1 + 0.05 = 0.25; 1.6/0.25 = 6.4 В. Код і рука кажуть те саме — це найкраща гарантія, що ні там, ні там немає описки.

**Друге — витягти Тевенен із двох вимірів (найпрактичніше на практиці).** Часто внутрішній опір джерела (батареї, давача, виходу каскаду) наперед невідомий, зате його легко **виміряти**: зчитай напругу при двох різних відомих навантаженнях — і дві точки однозначно задають ту саму пряму V = V_th − I·R_th, з якої читаються обидва числа. Це прямий практичний ужиток теореми Тевенена.

**Джерело під навантаженням R_a дало напругу V_a, під R_b — напругу V_b. Знайти V_th і R_th.**

```c
#include <stdio.h>

typedef struct { float v_th, r_th; } Thevenin;

/* Дві точки (навантаження, виміряна напруга) → пряма V = V_th − I·R_th.
   Струм у кожній точці: I = V/R_load. Дві точки дають нахил R_th і зсув V_th. */
static Thevenin thevenin_from_two_loads(float ra, float va, float rb, float vb) {
    Thevenin t;
    float ia = va / ra;                 /* струм у першій точці */
    float ib = vb / rb;                 /* струм у другій точці */
    t.r_th = (vb - va) / (ia - ib);     /* нахил прямої V(I): −ΔV/ΔI */
    t.v_th = va + ia * t.r_th;          /* екстраполяція до I=0 (розімкнене) */
    return t;
}

int main(void) {
    /* Батарея: під 100 Ω дала 6.15 В, під 47 Ω — 6.02 В */
    Thevenin t = thevenin_from_two_loads(100.0f, 6.15f, 47.0f, 6.02f);
    printf("V_th = %.2f В\n", t.v_th);  /* 6.27 В — «істинна» ЕРС без навантаження */
    printf("R_th = %.2f Ω\n", t.r_th);  /* 1.95 Ω — внутрішній опір */
    return 0;
}
```

Дві цифри — і ти знаєш про джерело все, що потрібно: його «істинну» напругу без навантаження (V_th) і на скільки воно просяде під будь-яким майбутнім навантаженням (через R_th). Це та сама пряма V = V_th − I·R_th, з якої ми вивели саму теорему, лише прочитана з двох експериментальних точок — теорія Тевенена, обернена на вимірювальний прийом.
