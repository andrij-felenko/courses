Колаборативний маніпулятор або повітряний дрон із механічним захоплювачем наближається до тонкостінної скляної колби чи плоду рослини. Контур позиційного регулювання веде кінцеву ланку за заданою траєкторією. Якщо через похибку калібрування камери чи випадковий зсув перешкоди поверхня предмета виявляється на два міліметри ближче, ніж розраховано в моделі, замкнений за положенням ПІД-регулятор бачить неусувну позиційну неузгодженість. Намагаючись повернути ланку в заплановану точку простору, інтегральна складова регулятора нарощує струм обмоток двигуна до максимального апаратного ліміту. У результаті захоплювач розчавлює предмет або ламає зубці власного хвильового редуктора.

Ця проблема виникає тому, що класичний робот із жорстким позиційним керуванням має нескінченну механічну жорсткість. Щоб робот міг безпечно торкатися крихких предметів, взаємодіяти з людиною та адаптувати силу стискання, система керування повинна отримувати миттєвий зворотний зв'язок про силу контакту. У вбудованих системах і робототехніці існують два фізично відмінні шляхи отримання цього сигналу: непряма оцінка крутного моменту за фазним струмом приводів та пряме вимірювання механічної деформації за допомогою тензорезистивних давачів.

## Оцінка моменту за струмом двигуна

Найпростіший спосіб дізнатися, з якою силою робот тисне на перешкоду, полягає у вимірюванні електричного струму, що протікає крізь обмотки його власних електродвигунів. У синхронних безколекторних двигунах із постійними магнітами (англ. *Brushless DC Motor*, BLDC / PMSM), які працюють під керуванням векторного алгоритму (англ. *Field-Oriented Control*, FOC), вектор струму статора розкладається на дві ортогональні складові: поздовжню намагнічувальну вісь `I_d` та поперечну силову вісь `I_q`.

Поперечний струм `I_q` створює магнітне поле, напрямлене строго перпендикулярно до поля ротора. Завдяки цьому електромагнітний момент, що генерується на валу ротора, пропорційний величині струму:

```
T_m = K_t · I_q
```

де `T_m` — електромагнітний момент двигуна (Н·м), `I_q` — квадратурна складова струму статора (А), а `K_t` — конструктивна стала моменту двигуна (англ. *torque constant*, Н·м/А). У трифазних синхронних моторах стала моменту безпосередньо пов'язана зі сталою проти-ЕРС `K_e` через число пар полюсів.

Коли вал двигуна з'єднаний із суглобом маніпулятора через понижувальний редуктор із передавальним числом `N` (англ. *gear ratio*) та коефіцієнтом корисної дії `η`, теоретичний крутний момент на вихідній осі суглоба становить:

```
T_joint = N · η · T_m = N · η · K_t · I_q
```

Знаючи кінематичну матрицю Якобі маніпулятора `J(q)`, яка пов'язує швидкості суглобів із лінійною швидкістю робочого органу, вектор контактної сили на кінці інструмента `F_ext` можна виразити через вектор суглобових моментів `τ`:

```
τ = Jᵀ(q) · F_ext
```

На перший погляд здається, що наявності шунта або давача Холла в колі фазного струму інвертора достатньо, аби перетворити будь-який привід на повноцінний давач сили без жодної додаткової деталі. Проте на практиці між виміряним струмом ротора і реальною силою на кінцевій ланці стоїть нелінійний бар'єр механіки редуктора.

![Оцінка сили за струмом: вплив сухого тертя та мертвої зони редуктора](/root/course/embedded/strum-i-tenzodavach-iak-dotyk/img/motor-current-friction.svg)
*Зв'язок між зовнішнім моментом на валу та виміряним струмом ротора. Наявність сухого тертя Кулона утворює мертву зону навколо нуля, в межах якої двигун не відчуває слабких зовнішніх дотиків.*

### Механічний бар'єр: тертя, люфт та інерція

У реальному редукторі крутний момент частково поглинається внутрішніми силами опору. Повна динамічна модель моменту суглоба включає сухе кулонівське тертя, в'язке тертя та ефект Страйбека:

```
T_fric(q̇) = [ τ_c + (τ_s - τ_c) · e^(-(|q̇|/v_s)ᵟ) ] · sgn(q̇) + b · q̇
```

де `τ_c` — момент сухого тертя Кулона (англ. *Coulomb friction*), `τ_s` — момент тертя спокою (зрушення, англ. *static breakaway friction*), `v_s` — швидкість Страйбека, `b` — коефіцієнт в'язкого тертя (англ. *viscous damping*), а `q̇` — кутова швидкість суглоба.

У редукторах із високим передавальним числом (`N ≥ 50:1` — планетарні передачі, хвильові редуктори *Harmonic Drive*, циклоїдні редуктори) виникають три критичні обмеження:

1. **Зона нечутливості сухого тертя (Deadband):** Якщо зовнішній предмет торкається робочого органу з малою силою, результуючий момент на валу не перевищує момент тертя спокою `τ_s`. Зубчасті колеса перебувають у стані заклинювання, вал двигуна не рухається, а фазний струм не зазнає жодних змін. Робот виявляється повністю сліпим до контактів, сила яких менша за поріг зрушення редуктора.
2. **Втрата зворотної рушійності (Backdrivability):** Здатність механізму передавати рух від вихідного вала назад до двигуна стрімко падає зі збільшенням `N`. Редуктори з високим тертям незворотні: спроба штовхнути ланку рукою створює механічне напруження в корпусі, але не прокручує ротор мотора.
3. **Квадратичне відбиття інерції ротора:** Момент інерції ротора `J_m`, зведений до вихідного вала суглоба, множиться на квадрат передавального числа:
   ```
   J_eff = J_load + N² · J_m
   ```
   При `N = 100` інерція ротора масою в сотню грамів еквівалентна тонній масі на вихідному валу. При швидкому динамічному ударі об перешкоду вся кінетична енергія руйнує контактну поверхню за мілісекунди, перш ніж контур регулювання струму встигне зафіксувати сплеск `I_q` і вжити заходів.

> 🔧 **Навіщо це.** У крокуючих роботах (Boston Dynamics Spot, Unitree) та прямих маніпуляторах безпечної взаємодії застосовують квазіпрямий привід (англ. *Quasi-Direct Drive*, QDD): двигуни з великим діаметром ротора («млинці» з високим `K_t`) поєднують із редукторами малого передавального числа (`N ≤ 10:1`). У таких приводах сухе тертя мінімальне, зворотна рушійність майже ідеальна, а оцінка сили за струмом `I_q` дає змогу виявляти дотики з точністю до 0.5 Н без використання додаткових силових давачів. Для важких промислових маніпуляторів із `N ≥ 100`, навпаки, пряма тензометрія є єдиним надійним джерелом інформації про зусилля.

## Тензорезистивні давачі та міст Вітстона

Коли оцінки сили за струмом недостатньо через тертя в трансмісії або коли потрібна вища точність і стабільність вимірювання, зусилля реєструють безпосередньо в місці його прикладання — на фланці кінцевого інструмента чи в пружних елементах суглобів. Фізичною основою для цього слугує тензорезистивний ефект (лат. *tensus* — натягнутий та лат. *resisto* — опираюся).

Тензорезистор (англ. *strain gauge*) являє собою тонку металеву фольгову решітку (найчастіше зі сплаву константану або карми) товщиною 3–5 мкм, наклеєну на поліімідну підкладку. Підкладку жорстко приклеюють епоксидним або ціанакрилатним клеєм до поверхні пружного металевого тіла (балки з авіаційного алюмінію 6061-T6 або загартованої нержавіючої сталі 17-4PH).

![Тензоміст Вітстона: мостова схема на згинальній балці](/root/course/embedded/strum-i-tenzodavach-iak-dotyk/img/wheatstone-bridge-strain.svg)
*Розташування чотирьох тензорезисторів на пружній балці вигину та їхнє з'єднання в повний міст Вітстона. Розтяг верхніх волокон і стиск нижніх збільшують корисний диференційний сигнал учетверо.*

Коли зовнішня сила деформує балку, поверхневий шар розтягується або стискається. Відносна деформація `ε` (англ. *strain*) визначається відношенням зміни довжини провідника `ΔL` до його початкової довжини `L`:

```
ε = ΔL / L
```

Зміна довжини провідника та звуження його поперечного перерізу (внаслідок коефіцієнта Пуассона `ν`), а також зміна питомого опору матеріалу під дією механічного напруження призводять до зміни електричного опору тензорезистора `ΔR`:

```
ΔR / R = GF · ε
```

де `GF` (англ. *Gauge Factor*, коефіцієнт тензочутливості) для металевих фольгових давачів становить `GF ≈ 2.0 ... 2.15`. Напівпровідникові кремнієві тензорезистори мають значно вищий коефіцієнт (`GF ≈ 100 ... 150`), але вирізняються сильною температурною нелінійністю та крихкістю.

За законом Гука механічне напруження в матеріалі становить `σ = E · ε`, де `E` — модуль пружності Юнга (для алюмінію `E ≈ 70` ГПа, для сталі `E ≈ 200` ГПа). При типових робочих навантаженнях металу деформація балки становить від `500` до `1500` мікродеформацій (мкε, або `10⁻⁶`). При номінальному опорі тензорезистора `R = 350` Ом відносне збільшення опору при `ε = 1000` мкε становить:

```
ΔR = R · GF · ε = 350 · 2.0 · 0.001 = 0.7 Ом
```

Виміряти зміну в 0.7 Ом на тлі базового опору 350 Ом за допомогою звичайного дільника напруги з мікроконтролерним АЦП неможливо: нагрів резистора власним струмом або зміна температури навколишнього середовища зміщують базовий опір на одиниці омів, повністю знищуючи корисний сигнал.

### Топології моста Вітстона

Для виділення мікроскопічної зміни `ΔR` та компенсації синфазних спотворень використовують чотириплечовий міст Вітстона (англ. *Wheatstone bridge*). Живлення моста `V_EXC` подається у верхній і нижній вузли ромба, а вимірювальний диференційний сигнал `V_SIG = V_A - V_B` знімається з діагоналі між середніми точками двох дільників.

Залежно від кількості активних тензорезисторів на пружному тілі розрізняють три схеми вмикання:

1. **Чвертьміст (Quarter-Bridge):** Один активний тензорезистор `R1 = R + ΔR`, решта три — пасивні прецизійні резистори з фіксованим опором `R`. Вихідна напруга моста:
   ```
   V_out ≈ V_EXC · (1/4) · GF · ε
   ```
   Схема не компенсує температурне розширення матеріалу балки та дрейф опору підвідних дротів. Застосовується лише в найдешевших індикаторах присутності.

2. **Півміст (Half-Bridge):** Два активні тензорезистори. Один наклеюється на верхню поверхню згинальної балки (`R1 = R + ΔR`, розтяг), другий — на нижню поверхню (`R2 = R - ΔR`, стиск). Сусідні плечі ділять напругу симетрично:
   ```
   V_out = V_EXC · (1/2) · GF · ε
   ```
   Чутливість зростає вдвічі порівняно з чвертьмостом. Головна перевага півмоста — **автоматична компенсація температури**: нагрів балки однаково видовжує обидва резистори (`+ΔR_T`), і оскільки вони стоять у сусідніх плечах одного дільника, синфазний зсув потенціалу середньої точки взаємно віднімається.

3. **Повний міст (Full-Bridge):** Чотири активні тензорезистори. Два розміщені в зоні розтягу (`R1, R3 = R + ΔR`), два — в зоні стиску (`R2, R4 = R - ΔR`). Виведемо точну вихідну напругу повного моста:

```
V_out = V_A - V_B
= V_EXC · [ R2 / (R1 + R2) ] - V_EXC · [ R3 / (R3 + R4) ]     [потенціали дільників напруги]
= V_EXC · [ (R - ΔR) / (2·R) - (R + ΔR) / (2·R) ]             [підстановка опорів плечей]
= V_EXC · [ (R - ΔR - R - ΔR) / (2·R) ]                        [зведення до спільного знаменника]
= - V_EXC · (ΔR / R)                                           [скорочення R у чисельнику]
= - V_EXC · GF · ε                                             [підстановка закону тензорезистивності]
```

Повний міст забезпечує вчетверо більшу крутість сигналу порівняно з чвертьмостом, ідеальну теоретичну лінійність та повну компенсацію як температурного дрейфу, так і паразитних поздовжніх сил розтягування балки (які однаково деформують усі 4 резистори).

### Апаратна компенсація модуля Юнга та дрейфу нуля (Zero & Span Trim)

У високоточних промислових давачах сили виникає додатковий фізичний ефект: зі зростанням температури модуль Юнга металевого пружного тіла зменшується. Для сталі коефіцієнт становить `dE/dT ≈ -0.02%/°C`, а для алюмінію — `dE/dT ≈ -0.04%/°C`. При нагріванні метал стає м'якшим, тому під дією тієї самої сили `F` деформація `ε` зростає, що викликає температурний дрейф масштабу (чутливості) давача (англ. *Span Thermal Drift*).

Для компенсації цього ефекту в ланцюг живлення моста послідовно вмикають термочутливий нікелевий резистор `R_m` (англ. *modulus resistor*). Нікель має високий додатний температурний коефіцієнт опору (ТКО `≈ +0.6%/°C`). Зі зростанням температури опір `R_m` збільшується, на ньому падає більша частина напруги живлення, напруга на вершинах моста `V_EXC` пропорційно зменшується, і це падіння точно нейтралізує розм'якшення пружного металу.

Для усунення початкового перекосу нуля через допуски наклеювання тензорезисторів у кути моста впаюють прецизійні підстроювальні мідні чи нікелеві шлейфи `R_z` (англ. *zero balance resistors*), що зводить початкову напругу зміщення до величини менше 0.05% FS.

При віддаленому розташуванні давача (коли кабель від роборуки до плати керування сягає 3–5 метрів) опір мідних жил дроту `R_wire` (близько 0.5–1 Ом) та його нагрів у кабелеукладачі спотворюють напругу живлення моста. У таких вузлах застосовують **шестипровідне підключення Кельвіна**:
- Дві силові лінії `EXC+` та `EXC-` несуть струм живлення моста.
- Дві окремі високоомні сигнальні лінії зворотного зв'язку `SENSE+` та `SENSE-` підключаються безпосередньо до вершин моста на самій балці та ведуть до входу стабілізатора напруги або АЦП.
- Дві лінії `SIG+` та `SIG-` передають вимірювальний диференційний сигнал.

Оскільки лініями `SENSE` струм майже не тече, падіння напруги на кабелі автоматично компенсується схемою стабілізації, гарантуючи незмінну амплітуду збудження моста на будь-якій довжині кабелю.

## Механіка пружних елементів: від консольної балки до бінокулярної комірки

Чутливість і точність силового давача залежать не лише від електричної схеми, а й від геометричної форми металевого пружного тіла.

У простій консольній балці (англ. *cantilever beam*) прямокутного перерізу з шириною `b`, висотою `h` і довжиною `L` згинальний момент у точці розташування тензорезистора `x` становить `M(x) = F · (L - x)`. Механічне напруження на поверхні балки:

```
σ = M(x) / W_z = (6 · F · (L - x)) / (b · h²)
```

де `W_z = (b · h²) / 6` — осьовий момент опору перерізу.

Головний недолік простої консольної балки — **залежність сигналу від точки прикладання сили**. Якщо робочий інструмент або захват торкається об'єкта кінчиком пальця (велика довжина плеча `L`), згинальний момент виходить значно більшим, ніж при контакті біля основи пальця, хоча нормальна сила `F` однакова.

![Механіка бінокулярної балки: паралелограмний механізм компенсації плеча сили](/root/course/embedded/strum-i-tenzodavach-iak-dotyk/img/binocular-load-cell-mechanics.svg)
*Конструкція бінокулярної зсувної балки (Parallel-Beam Load Cell). Внутрішні циліндричні вирізи утворюють паралелограмний механізм із чотирма гнучкими перемичками, що усуває вплив точки прикладання зусилля.*

Для усунення цієї похибки в робототехнічних тензодатчиках та вагових модулях застосовують конструкцію **бінокулярної паралельної балки** (англ. *Parallel-Beam / Binocular Load Cell*).

У суцільному металевому бруску фрезерують два паралельні наскрізні круглі отвори, з'єднані вузьким горизонтальним прорізом. Ця геометрія перетворює монолітну балку на плоский паралелограмний шарнірний чотириланковик із чотирма тонкими гнучкими перемичками (англ. *flexure hinges*).

Коли до рухомого кінця балки прикладається вертикальна сила `F`, паралелограм зазнає плоскопаралельного зсуву:
- Верхня і нижня полиці залишаються суворо паралельними.
- У тонких перемичках виникає чистий S-подібний згин: над першим отвором верхня поверхня розтягується (`R1`), а над другим — стискається (`R2`). На нижньому боці розподіл напружень протилежний (`R4` стискається, `R3` розтягується).
- Завдяки паралелограмній кінематиці деформація у гнучких зонах пропорційна **виключно поперечній зсувній силі `F`** і не залежить від того, на якій відстані від центру балки прикладено навантаження. Момент перекидання врівноважується парою поздовжніх сил у верхній та нижній полицях, не деформуючи вимірювальні зони тензорезисторів.

Для захисту від випадкових механічних перевантажень у конструкцію бінокулярного давача обов'язково інтегрують механічні упори-обмежувачі ходу (англ. *overload mechanical stops*). Пружний хід балки обмежують зазором у 0.1–0.2 мм: при навантаженні понад 150% FS балка лягає на жорсткий упор, що запобігає переходу металу в зону пластичної деформації та зриву тензорезисторів із клейового шару.

## Аналоговий тракт: АЦП, інструментальні підсилювачі та раціометричність

Типовий промисловий тензодавач має номінальну чутливість `S = 2.0` мВ/В при повному навантаженні (англ. *Full Scale*, FS). Це означає, що при напрузі збудження моста `V_EXC = 3.3` В максимальний вихідний диференційний сигнал становить лише:

```
V_out_max = 3.3 В · 2.0 мВ/В = 6.6 мВ
```

Якщо нам потрібно детектувати слабкий дотик величиною `0.1%` від максимального навантаження давача, аналоговий тракт повинен реєструвати зміну напруги в `6.6` мікровольта (`6.6` мкВ) на тлі синфазної напруги `V_CM = V_EXC / 2 = 1.65` В.

Для обробки таких мікровольтових сигналів застосовують дві архітектури аналогового фронтенду (AFE):

### 1. Спеціалізовані сигма-дельта АЦП (на прикладі HX711)

Мікросхема HX711 є спеціалізованим 24-бітним аналого-цифровим перетворювачем для мостових тензодавачів. Вона містить усередині:
- Малошумний диференційний підсилювач із фіксованим коефіцієнтом підсилення `Gain = 128` (для каналу A), що перетворює діапазон `±20` мВ на повну шкалу внутрішнього АЦП.
- Вбудований низькошумний стабілізатор напруги (LDO) для формування чистої напруги збудження моста `V_AVDD`.
- Сигма-дельта модулятор 24-бітного розряду з частотою видачі даних 10 вибірок/с (із глибоким придушенням мережевих завад 50/60 Гц) або 80 вибірок/с (для динамічних робототехнічних завдань).
- Дводротовий цифровий інтерфейс керування (`PD_SCK`, `DOUT`), який не потребує апаратного SPI і опитується за допомогою звичайних виводів GPIO.

```
HX711 (24-bit ADC)
┌────────────────────────────────────────────────────────┐
│  E+ (V_AVDD) ────► До верхньої вершини моста           │
│  E- (GND)    ────► До нижньої вершини моста            │
│  A+ (V_SIG+) ────► Диференційний вхід (+) [PGA 128x]   │
│  A- (V_SIG-) ────► Диференційний вхід (-) [PGA 128x]   │
│  DOUT        ────► До входу GPIO МК (лінія даних)      │
│  PD_SCK      ────► Від виходу GPIO МК (тактовий сигнал)│
└────────────────────────────────────────────────────────┘
```

### 2. Дискретні інструментальні підсилювачі (INA128, AD8421)

Для високошвидкісних контурів зворотного зв'язку (із частотою опитування `1 ... 10` кГц), де швидкість HX711 (80 Гц) є занизькою, застосовують прецизійні трьохопераційні інструментальні підсилювачі (англ. *Instrumentation Amplifier*, In-Amp) — наприклад, INA128, AD8421 або підсилювачі з автопідстроюванням нуля (англ. *Chopper-Stabilized*, LTC2053).

Коефіцієнт підсилення такого каскаду задається одним зовнішнім прецизійним резистором `R_G`:

```
G = 1 + (49.4 кОм / R_G)
```

In-Amp має коефіцієнт придушення синфазної завади `CMRR > 110` дБ і передає посилений сигнал `0 ... 3.3` В безпосередньо на швидкісний 16-бітний SAR АЦП мікроконтролера, звідки вибірки забираються контролером прямого доступу до пам'яті (DMA).

### Раціометричний принцип вимірювання (Ratiometric Sensing)

Критичною вимогою до прецизійної тензометрії є **раціометричність**. Якщо напруга живлення моста `V_EXC` просяде на `1%` через нагрів або коливання навантаження, вихідна напруга моста `V_out` також зменшиться на `1%`, що призведе до фальшивої похибки вимірювання сили.

Щоб усунути цей дрейф, опорну напругу АЦП `V_REF` беруть **від того самого джерела**, яке живить міст (`V_REF = V_EXC`).

Код на виході АЦП визначається формулою:

```
ADC_code = 2ᴺ · (V_out / V_REF)
= 2ᴺ · ( (V_EXC · S · F) / V_EXC )     [підстановка V_out через чутливість моста]
= 2ᴺ · S · F                          [скорочення V_EXC]
```

Оскільки напруга збудження `V_EXC` скорочується в чисельнику й знаменнику, результат оцифрування залежить виключно від механічної деформації, повністю ігноруючи коливання напруги живлення.

## Багатоосьові силомоментні давачі (6-Axis Force/Torque Sensors)

У зап'ястках промислових маніпуляторів, антропоморфних кистях та точках кріплення інструментів недостатньо міряти зусилля лише по одній осі. Робот повинен одночасно знати повний просторовий вектор сил і моментів — силомоментний гвинт (англ. *wrench*):

```
W = [ F_x,  F_y,  F_z,  M_x,  M_y,  M_z ]ᵀ
```

де `F_x, F_y, F_z` — лінійні сили вздовж декартових осей (у ньютонах), а `M_x, M_y, M_z` — крутні моменти довкола цих осей (у ньютон-метрах).

![6-осьовий силомоментний давач: структура хрестовини та калібрувальна матриця](/root/course/embedded/strum-i-tenzodavach-iak-dotyk/img/six-axis-ft-sensor.svg)
*Конструкція пружної монолітної хрестовини (Мальтійський хрест) 6-осьового силомоментного давача та матричне перетворення сигналів тензомостів у просторовий вектор сил і моментів.*

### Конструкція пружного тіла: Мальтійський хрест

Найпоширенішою геометрією 6-осьового давача є монолітна хрестоподібна структура (хрестовина або структура Мальтійського хреста). Вона складається з жорсткої внутрішньої втулки (яка кріпиться до фланця робота), жорсткого зовнішнього кільця (до якого кріпиться інструмент) та чотирьох радіальних пружних балок, розташованих під кутом 90° одна до одної.

На поверхнях кожного з чотирьох променів наклеєно кілька тензомостів:
- Мости на бічних гранях променів реагують на згин у горизонтальній площині XY (лінійні сили `F_x, F_y` та момент `M_z`).
- Мости на верхніх і нижніх гранях променів реагують на вертикальний згин (сила `F_z` та моменти `M_x, M_y`).
- Загалом на хрестовині розміщують від 6 до 12 незалежних тензомостів, кожен із яких підключається до власного каналу АЦП.

### Перехресна чутливість та матриця розділення каналів (Decoupling Matrix)

Через геометричні допуски виготовлення металевого тіла, неідеальність позиціонування тензорезисторів та коефіцієнт Пуассона пружна деформація вздовж однієї осі неминуче викликає паразитний відгук у мостах інших осей (англ. *cross-axis sensitivity*, або *cross-talk*). Наприклад, прикладання чистої вертикальної сили `F_z` створює невелику паразитну напругу в мостах, призначених для вимірювання `M_x`.

Для лінійного розділення взаємопов'язаних каналів застосовують калібрувальну матрицю декуплінгу `C` розмірністю `6 × 6` (або `6 × n`, якщо використовується `n > 6` каналів):

```
W = C · (V_raw - V_tare)
```

де `V_raw` — вектор виміряних напруг мостів, `V_tare` — вектор зміщення нуля (зсув тари без навантаження), а `C` — матриця калібрування, елементи якої мають розмірність Н/В та (Н·м)/В.

У розгорнутому матричному вигляді:

```
⎡ F_x ⎤   ⎡ C₁₁  C₁₂  C₁₃  C₁₄  C₁₅  C₁₆ ⎤   ⎡ V₁ - V₁₀ ⎤
⎢ F_y ⎥   ⎢ C₂₁  C₂₂  C₂₃  C₂₄  C₂₅  C₂₆ ⎥   ⎢ V₂ - V₂₀ ⎥
⎢ F_z ⎥   ⎢ C₃₁  C₃₂  C₃₃  C₃₄  C₃₅  C₃₆ ⎥   ⎢ V₃ - V₃₀ ⎥
⎢ M_x ⎥ = ⎢ C₄₁  C₄₂  C₄₃  C₄₄  C₄₅  C₄₆ ⎥ · ⎢ V₄ - V₄₀ ⎥
⎢ M_y ⎥   ⎢ C₅₁  C₅₂  C₅₃  C₅₄  C₅₅  C₅₆ ⎥   ⎢ V₅ - V₅₀ ⎥
⎣ M_z ⎦   ⎣ C₆₁  C₆₂  C₆₃  C₆₄  C₆₅  C₆₆ ⎦   ⎣ V₆ - V₆₀ ⎦
```

Діагональні елементи `C_ii` відповідають за пряму чутливість каналу, а позадіагональні елементи `C_ij` компенсують взаємний вплив осей. Калібрувальна матриця визначається виробником на спеціалізованому стенді шляхом послідовного прикладання шести еталонних навантажень та обчислення псевдооберненої матриці методом найменших квадратів.

### Динамічна компенсація ваги інструмента (Gravity Compensation)

Коли маніпулятор переорієнтовує кисть у тривимірному просторі, маса закріпленого захоплювача `m_tool` та його центр мас `r_com` створюють постійний гравітаційний силовий вплив на давач. Якщо робот нахиляє зап'ясток на 90°, вага захоплювача перетікає з осі `F_z` на вісь `F_x`, викликаючи хибне відчуття контакту.

Контролер робота в реальному часі обчислює орієнтацію кінцевого фланця за допомогою матриці обертання прямої кінематики `R(q)` і віднімає гравітаційний вектор із виміряного силомоментного гвинта:

```
F_gravity = Rᵀ(q) · [ 0, 0, -m_tool · g ]ᵀ
M_gravity = r_com × F_gravity
W_contact = W_measured - [ F_gravity ; M_gravity ]
```

Тільки після гравітаційного віднімання вектор `W_contact` передається в алгоритми силового зворотного зв'язку.

## Швидке виявлення контакту та зіткнення: Спостерігач імпульсу

Коли маніпулятор рухається на високій швидкості (до 2–3 м/с), аварійне зіткнення з перешкодою чи людиною має бути зафіксоване за лічені мілісекунди, щоб зупинити приводи до того, як сила перевищить поріг травмування за стандартом ISO/TS 15066 (зазвичай 140–150 Н для грудної клітки).

Наївний підхід до виявлення зіткнень полягає в прямому обчисленні динамічної моделі Ньютона-Ейлера:

```
τ_ext = τ_cmd - [ M(q) · q̈ + C(q, q̇) · q̇ + g(q) + τ_fric(q̇) ]
```

де `M(q)` — матриця інерції маніпулятора, `C(q, q̇)` — матриця сил Коріоліса та відцентрових сил, `g(q)` — вектор гравітаційних моментів, а `q̈` — суглобове прискорення.

Цей метод зазнає повної невдачі на практиці: оптичні чи магнітні енкодери міряють кут `q`. Щоб отримати прискорення `q̈`, сигнал треба двічі чисельно продиференціювати. Чисельне диференціювання багаторазово підсилює високочастотний квантувальний шум енкодера. Якщо ж застосувати цифровий фільтр низьких частот для згладжування шуму `q̈`, він внесе фазову затримку в 30–50 мс, протягом якої зіткнення вже встигне завдати механічних руйнувань.

![Спостерігач імпульсу: детектування зіткнення за стрибком нев'язки без подвійного диференціювання](/root/course/embedded/strum-i-tenzodavach-iak-dotyk/img/momentum-observer-collision.svg)
*Архітектура спостерігача узагальненого імпульсу та часова діаграма відгуку нев'язки r(t) при аварійному контакті.*

### Спостерігач узагальненого імпульсу Де Луки — Хаддадіна

Для усунення потреби в чисельному обчисленні прискорення `q̈` професор Алессандро Де Лука (англ. *Alessandro De Luca*) та Самі Хаддадін (англ. *Sami Haddadin*) розробили алгоритм спостерігача узагальненого імпульсу (англ. *Generalized Momentum Observer*, або *Residual-Based Collision Detection*).

Узагальнений механічний імпульс системи суглобів визначається як:

```
p(t) = M(q) · q̇
```

Похідна імпульсу за часом становить:

```
ṗ = M(q) · q̈ + Ṁ(q) · q̇
```

Використовуючи фундаментальну властивість кососиметричності динаміки робота (матриця `Ṁ(q) - 2·C(q, q̇)` є кососиметричною, звідки випливає `Ṁ · q̇ = Cᵀ · q̇ + C · q̇`), рівняння руху маніпулятора переписується у вигляді:

```
ṗ = τ + Cᵀ(q, q̇) · q̇ - g(q) + τ_ext
```

де `τ` — виміряний або заданий керівний момент моторів.

Ми вводимо вектор спостережуваної нев'язки `r(t)`:

```
r(t) = K_I · [ p(t) - ∫₀ᵗ ( τ + Cᵀ(q, q̇) · q̇ - g(q) - τ_fric(q̇) + r(s) ) ds - p(0) ]
```

де `K_I = diag(k₁, k₂, ..., kₙ) > 0` — діагональна матриця коефіцієнтів підсилення спостерігача.

Візьмемо похідну за часом від обох частин рівняння нев'язки `r(t)`:

```
ṙ(t) = K_I · [ ṗ(t) - ( τ + Cᵀ · q̇ - g - τ_fric + r(t) ) ]    [диференціювання інтеграла]
= K_I · [ (τ + Cᵀ · q̇ - g + τ_ext) - (τ + Cᵀ · q̇ - g + r(t)) ] [підстановка рівняння динаміки ṗ]
= K_I · [ τ_ext(t) - r(t) ]                                      [скорочення внутрішніх динамічних сил]
```

Це диференціальне рівняння першого порядку описує класичний лінійний фільтр низьких частот:

```
ṙ(t) + K_I · r(t) = K_I · τ_ext(t)
```

Сигнал нев'язки `r(t)` асимптотично збігається до реального зовнішнього моменту зіткнення `τ_ext` зі сталою часу `T_i = 1 / k_i`. При цьому в алгоритмі **взагалі немає прискорення `q̈`**: імпульс `p(t) = M(q)·q̇` обчислюється через швидкість першого порядку, а динамічні сили інтегруються в часі!

### Фільтрація Калмана та смуговий аналіз ударного спектра

Фізичний удар твердого робочого органу об перешкоду породжує хвилю механічного напруження з характерним високочастотним спектром (50–300 Гц), що випливає з теорії пружного контакту Герца. Водночас корисний динамічний рух ланок маніпулятора зосереджений у низькочастотній зоні (0–10 Гц).

Для розділення високочастотного удару та повільних похибок ідентифікації маси/тертя застосовують двоетапну обробку:

1. **Смуговий фільтр різкого фронту (Bandpass Transient Filter):** Нев'язка `r(t)` пропускається крізь цифровий смуговий фільтр Баттерворта 2-го порядку (смуга 20–150 Гц). Фільтр повністю придушує повільний дрейф через нагрів мастила в редукторі, але миттєво видає високоамплітудний сплеск у момент механічного удару.
2. **Двовимірний фільтр Калмана для оцінки зовнішнього моменту та ривка:**
   Вектор стану суглоба задається вектором `x = [ τ_ext,  τ̇_ext ]ᵀ` (зовнішній момент і його похідна — ривок моменту).
   Рівняння прогнозу стану для кроку дискретизації `Δt`:
   ```
   x_{k|k-1} = [ 1, Δt; 0, 1 ] · x_{k-1|k-1}
   P_{k|k-1} = A · P_{k-1|k-1} · Aᵀ + Q
   ```
   Вектор інновації Калмана `γ_k = r_k - H · x_{k|k-1}` (де `H = [1, 0]`) слугує наднадійним детектором аномалій: при зіткненні інновація різко зростає, перевищуючи коваріаційний коридор `3·√(H P Hᵀ + R)`, що фіксує аварію за 2–3 такти АЦП.

### Динамічні пороги зіткнення

Оскільки математична модель робота ніколи не є абсолютно точною, у спокійному русі нев'язка `r(t)` коливається в межах невизначеності моделі. Динамічний поріг спрацьовування адаптується до поточної швидкості та величини моменту:

```
τ_threshold(i) = τ_base(i) + α_i · |q̇_i| + β_i · |τ_cmd_i|
```

Коли модуль нев'язки `|r_i(t)|` перевищує поріг `τ_threshold(i)` протягом двох послідовних тактів контролера (захист від одиничного спайку шуму), система фіксує подію зіткнення (англ. *Collision Event*) і протягом 1–2 мс перемикає контролер у режим гравітаційного розвантаження або негайної аварійної зупинки Cat 1.

## Програмна реалізація: модуль обробки сенсорики та детектування контакту

Нижче наведено закінчену реалізацію модуля обробки силомоментного давача та детектування зіткнень на базі спостерігача імпульсу. Модуль підтримує калібрувальне матричне множення, обнулення тари та розрахунок динамічного порогу контакту.

#include <stdio.h>
#include <stdbool.h>
#include <string.h>
#include <math.h>

#define JOINTS_COUNT 3
#define WRENCH_AXES  6

/* Структура конфігурації та стану 6-осьового силомоментного давача */
typedef struct {
    float calib_matrix[WRENCH_AXES][WRENCH_AXES]; /* Калібрувальна матриця 6x6 */
    float tare_offset[WRENCH_AXES];               /* Зсув тари для кожного каналу */
    float counts_to_volts;                         /* Множник АЦП (Вольт / Count) */
} ForceTorqueSensor;

/* Структура силомоментного вектора (гвинта) */
typedef struct {
    float fx, fy, fz; /* Сили в Ньютонах */
    float mx, my, mz; /* Моменти в Ньютон-метрах */
} Wrench6D;

/* Структура спостерігача узагальненого імпульсу */
typedef struct {
    float k_i[JOINTS_COUNT];            /* Коефіцієнти підсилення спостерігача K_I */
    float integral_state[JOINTS_COUNT];  /* Акумулятор інтегратора */
    float p_prev[JOINTS_COUNT];         /* Попередній стан імпульсу M*dq */
    float r[JOINTS_COUNT];              /* Вектор поточної нев'язки r(t) ~ tau_ext */
    float base_threshold[JOINTS_COUNT]; /* Базовий поріг детектування зіткнення */
    float vel_threshold_gain[JOINTS_COUNT]; /* Чутливість порогу до швидкості */
} MomentumObserver;

/* Ініціалізація силомоментного давача */
void ft_sensor_init(ForceTorqueSensor* sensor, const float calib[WRENCH_AXES][WRENCH_AXES], float lsb_volts) {
    memcpy(sensor->calib_matrix, calib, sizeof(sensor->calib_matrix));
    sensor->counts_to_volts = lsb_volts;
    for (int i = 0; i < WRENCH_AXES; i++) {
        sensor->tare_offset[i] = 0.0f;
    }
}

/* Калібрування тари за сирими відліками АЦП у ненавантаженому стані */
void ft_sensor_tare(ForceTorqueSensor* sensor, const int32_t raw_adc[WRENCH_AXES]) {
    for (int i = 0; i < WRENCH_AXES; i++) {
        sensor->tare_offset[i] = (float)raw_adc[i] * sensor->counts_to_volts;
    }
}

/* Обчислення вектора сил і моментів через множення на калібрувальну матрицю */
Wrench6D ft_sensor_process(const ForceTorqueSensor* sensor, const int32_t raw_adc[WRENCH_AXES]) {
    float v_diff[WRENCH_AXES];
    float wrench_raw[WRENCH_AXES] = {0};

    for (int i = 0; i < WRENCH_AXES; i++) {
        v_diff[i] = ((float)raw_adc[i] * sensor->counts_to_volts) - sensor->tare_offset[i];
    }

    /* Матричне множення W = C * v_diff */
    for (int row = 0; row < WRENCH_AXES; row++) {
        for (int col = 0; col < WRENCH_AXES; col++) {
            wrench_raw[row] += sensor->calib_matrix[row][col] * v_diff[col];
        }
    }

    Wrench6D out;
    out.fx = wrench_raw[0];
    out.fy = wrench_raw[1];
    out.fz = wrench_raw[2];
    out.mx = wrench_raw[3];
    out.my = wrench_raw[4];
    out.mz = wrench_raw[5];
    return out;
}

/* Ініціалізація спостерігача імпульсу */
void momentum_observer_init(MomentumObserver* obs, const float gains[JOINTS_COUNT],
                            const float base_thr[JOINTS_COUNT], const float vel_gains[JOINTS_COUNT]) {
    for (int i = 0; i < JOINTS_COUNT; i++) {
        obs->k_i[i] = gains[i];
        obs->base_threshold[i] = base_thr[i];
        obs->vel_threshold_gain[i] = vel_gains[i];
        obs->integral_state[i] = 0.0f;
        obs->p_prev[i] = 0.0f;
        obs->r[i] = 0.0f;
    }
}

/* Крок оновлення спостерігача імпульсу та перевірка наявності зіткнення */
bool momentum_observer_update(MomentumObserver* obs,
                              const float q_vel[JOINTS_COUNT],
                              const float tau_cmd[JOINTS_COUNT],
                              const float mass_matrix[JOINTS_COUNT][JOINTS_COUNT],
                              const float coriolis_gravity[JOINTS_COUNT],
                              float dt) {
    bool collision_detected = false;
    float p_current[JOINTS_COUNT] = {0};

    /* Розрахунок узагальненого імпульсу p = M(q) * q_dot */
    for (int i = 0; i < JOINTS_COUNT; i++) {
        for (int j = 0; j < JOINTS_COUNT; j++) {
            p_current[i] += mass_matrix[i][j] * q_vel[j];
        }
    }

    /* Оновлення нев'язки r(t) через чисельне інтегрування за Ейлером */
    for (int i = 0; i < JOINTS_COUNT; i++) {
        /* Підінтегральний вираз: tau + C^T*q_dot - g + r */
        float integrand = tau_cmd[i] + coriolis_gravity[i] + obs->r[i];
        obs->integral_state[i] += integrand * dt;

        /* Нев'язка r_i(t) = K_I * [ p_i(t) - integral - p_i(0) ] */
        obs->r[i] = obs->k_i[i] * (p_current[i] - obs->integral_state[i]);

        /* Динамічний поріг детектування контакту */
        float dynamic_thr = obs->base_threshold[i] + obs->vel_threshold_gain[i] * fabsf(q_vel[i]);

        if (fabsf(obs->r[i]) > dynamic_thr) {
            collision_detected = true;
        }
        obs->p_prev[i] = p_current[i];
    }

    return collision_detected;
}

#include <array>
#include <span>
#include <cmath>
#include <cstdint>
#include <optional>

namespace robotics::sensing {

constexpr size_t WrenchDimensions = 6;

struct Wrench6D {
    float fx{0.0f};
    float fy{0.0f};
    float fz{0.0f};
    float mx{0.0f};
    float my{0.0f};
    float mz{0.0f};

    [[nodiscard]] constexpr float force_norm() const noexcept {
        return std::sqrt(fx * fx + fy * fy + fz * fz);
    }
};

/* Клас обробки 6-осьового силомоментного давача на базі C++20 */
class ForceTorqueSensor {
public:
    using Matrix6x6 = std::array<std::array<float, WrenchDimensions>, WrenchDimensions>;
    using RawChannels = std::array<int32_t, WrenchDimensions>;

    constexpr ForceTorqueSensor(const Matrix6x6& calib_matrix, float counts_to_volts) noexcept
        : calib_matrix_{calib_matrix}, counts_to_volts_{counts_to_volts} {}

    void tare(const RawChannels& raw_adc) noexcept {
        for (size_t i = 0; i < WrenchDimensions; ++i) {
            tare_offset_[i] = static_cast<float>(raw_adc[i]) * counts_to_volts_;
        }
        is_tared_ = true;
    }

    [[nodiscard]] Wrench6D process(const RawChannels& raw_adc) const noexcept {
        std::array<float, WrenchDimensions> v_diff{};
        for (size_t i = 0; i < WrenchDimensions; ++i) {
            const float v = static_cast<float>(raw_adc[i]) * counts_to_volts_;
            v_diff[i] = is_tared_ ? (v - tare_offset_[i]) : v;
        }

        std::array<float, WrenchDimensions> wrench_raw{};
        for (size_t row = 0; row < WrenchDimensions; ++row) {
            for (size_t col = 0; col < WrenchDimensions; ++col) {
                wrench_raw[row] += calib_matrix_[row][col] * v_diff[col];
            }
        }

        return Wrench6D{
            .fx = wrench_raw[0],
            .fy = wrench_raw[1],
            .fz = wrench_raw[2],
            .mx = wrench_raw[3],
            .my = wrench_raw[4],
            .mz = wrench_raw[5]
        };
    }

private:
    Matrix6x6 calib_matrix_{};
    std::array<float, WrenchDimensions> tare_offset_{};
    float counts_to_volts_{1.0f};
    bool is_tared_{false};
};

/* Клас спостерігача узагальненого імпульсу та детектування зіткнень */
template <size_t JointsCount>
class MomentumCollisionObserver {
public:
    using JointArray = std::array<float, JointsCount>;
    using MassMatrix = std::array<std::array<float, JointsCount>, JointsCount>;

    struct Config {
        JointArray gains;
        JointArray base_thresholds;
        JointArray vel_threshold_gains;
    };

    explicit MomentumCollisionObserver(const Config& config) noexcept : cfg_{config} {
        integral_state_.fill(0.0f);
        residuals_.fill(0.0f);
    }

    struct UpdateResult {
        JointArray estimated_ext_torque;
        bool collision_triggered;
    };

    [[nodiscard]] UpdateResult update(std::span<const float, JointsCount> q_vel,
                                     std::span<const float, JointsCount> tau_cmd,
                                     const MassMatrix& mass_matrix,
                                     std::span<const float, JointsCount> coriolis_gravity,
                                     float dt) noexcept {
        JointArray p_current{};
        for (size_t i = 0; i < JointsCount; ++i) {
            for (size_t j = 0; j < JointsCount; ++j) {
                p_current[i] += mass_matrix[i][j] * q_vel[j];
            }
        }

        bool collision = false;
        for (size_t i = 0; i < JointsCount; ++i) {
            const float integrand = tau_cmd[i] + coriolis_gravity[i] + residuals_[i];
            integral_state_[i] += integrand * dt;
            residuals_[i] = cfg_.gains[i] * (p_current[i] - integral_state_[i]);

            const float dynamic_thr = cfg_.base_thresholds[i] +
                                      cfg_.vel_threshold_gains[i] * std::abs(q_vel[i]);

            if (std::abs(residuals_[i]) > dynamic_thr) {
                collision = true;
            }
        }

        return UpdateResult{
            .estimated_ext_torque = residuals_,
            .collision_triggered = collision
        };
    }

    void reset() noexcept {
        integral_state_.fill(0.0f);
        residuals_.fill(0.0f);
    }

private:
    Config cfg_;
    JointArray integral_state_{};
    JointArray residuals_{};
};

} // namespace robotics::sensing
