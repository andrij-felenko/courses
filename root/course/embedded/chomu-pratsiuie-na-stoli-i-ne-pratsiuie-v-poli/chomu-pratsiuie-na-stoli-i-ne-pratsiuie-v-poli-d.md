На лабораторному столі пристрій працював без жодного збою три тижні поспіль: стабілізатор тримав 3.30 В без жодної пульсації від лабораторного джерела живлення, термометр у кімнаті показував стабільні +22 °C, а щупи осцилографа знімали ідеальні прямокутні імпульси на шині зв'язку. Але варто було змонтувати ту саму друковану плату в металевий бокс на дизельний генератор чи раму всюдихода — як у першу ж ніч мікроконтролер пішов у нескінченний цикл перезавантажень, покази давачів зсунулися на третину шкали, а на світанку шина I²C наглухо зависла. Код прошивки не змінився ні на байт; спаяна схема була точним повторенням лабораторного зразка. Пристрій зламався тому, що потрапив у фізично інший світ, якого стіл розробника не містив і не моделював.

Цей розрив між лабораторним стендом і польовою експлуатацією інженери називають розривом надійності (англ. *Lab-to-Field Reliability Gap*). Більшість приладів гине не через логічні помилки в алгоритмах, а через зіткнення з неврахованими фізичними, електричними та кліматичними факторами середовища. Робота на столі доводить лише одне: схема здатна функціонувати в ідеальному штучному коконі. Щоб пристрій вижив у полі, інженер мусить знати кожен фізичний механізм, що намагається знищити його виріб за межами лабораторії.

> 🔧 **Навіщо це.** Створення надійної електроніки починається з усвідомлення: польове середовище вороже за замовчуванням. Якщо ви не розрахували індуктивність лінії живлення, температурний дрейф кристалів, конденсацію вологи та втому паяних з'єднань під вібрацією, пристрій обов'язково зламається в полі. Розрахунок цих факторів на етапі проєктування коштує кількох годин схемотехнічного аналізу; виправлення помилок після відвантаження серії клієнтам коштує репутації та відкликання всієї партії.

*Розрив надійності між лабораторним столом і полем. На столі схема живе в захищеному штучному коконі з нульовим опором джерела й стабільним кліматом. У полі на пристрій одночасно тиснуть індуктивні викиди живлення, кліматичні екстремуми, роса та механічні гармоніки.*

## Електричне середовище: брудна лінія, самоіндукція та стрибок землі

Головна ілюзія лабораторного столу — джерело живлення. Лабораторний блок має динамічну компенсацію, вихідний опір у міліоми, нульові пульсації та під'єднується до плати короткими мідними дротами довжиною 20 см. 

У реальному польовому виробі живлення подається через кабельний джгут довжиною 1–10 метрів від автомобільного акумулятора, промислової шини 24 В або генератора. Кожен провідник у просторі володіє власною розподіленою індуктивністю `L` (типово `1–1.5 мкГн` на кожен метр довжини) та омічним опором `R`.

```
L_wire ≈ 1.2 мкГн / м
```

Коли цифрове навантаження (наприклад, радіомодем під час передачі кадру, спалах світлодіода чи драйвер соленоїда) стрибкоподібно змінює споживання струму з крутим фронтом `di/dt`, на індуктивності підвідного проводу виникає миттєвий спад напруги за фундаментальним законом електромагнітної індукції:

```
ΔV_line = L · (di / dt) + I · R
```

Розглянемо числовий розрахунок реального перехідного процесу. Нехай радіомодуль переходить зі сплячого режиму в режим передачі, споживаючи імпульс струму `ΔI = 2 А` з часом наростання фронту `dt = 40 нс`. Довжина живильного кабелю становить `2 м`, отже його індуктивність `L = 2.4 мкГн`.

```
di/dt = 2 А / (40 · 10⁻⁹ с)            [швидкість наростання струму передавача]
      = 5 · 10⁷ А/с

ΔV_drop = 2.4 · 10⁻⁶ Гн · (5 · 10⁷ А/с) [індуктивний спад напруги на лінії: L · di/dt]
        = 120 В                         [амплітуда просадки на клемах приладу]
```

Цей індуктивний спад напруги тривалістю в частки мікросекунди повністю зрізає вхідну напругу стабілізатора до нуля. Навіть якщо середня напруга акумулятора становить 12 В, на клемах плати напруга миттєво падає нижче порогу спрацьовування захисту від просадки [UVLO](root:hw-power/uvlo). Мікроконтролер сприймає це як аварію живлення і йде на перезавантаження (англ. *Brownout Reset*, BOR). На лабораторному столі цей дефект не проявлявся, оскільки 20-сантиметровий дріт мав індуктивність у 10 разів меншу, а вихідні конденсатори лабораторного блока миттєво компенсували спад.

Друга смертельна загроза польового живлення — комутація індуктивних навантажень: реле, електромагнітних клапанів, соленоїдів та колекторних двигунів. При розмиканні транзисторного ключа струм в індуктивності `L_load` намагається зберегтися. Виникає викид ЕРС самоіндукції зворотної полярності:

```
V_spike = -L_load · (di / dt)
```

Без правильно розрахованого [снабера](root:hw-components/arc-suppression) чи зворотного діода Шотткі (англ. *Flyback Diode*) напруга на стоці польового транзистора або на шині живлення підскакує до сотен вольт за кілька наносекунд. Цей високовольтний імпульс пробиває p-n переходи мікросхем, підпалює вхідні діоди електростатичного захисту (ESD) та викликає ефект тиристорного замикання (англ. *Latch-up*), коли паразитні p-n-p-n структури всередині кремнієвого кристала відкриваються й закорочують шину живлення на землю, спалюючи кристал струмом.

Третій фактор — спільний опір землі та ефект стрибка потенціалу (англ. *Ground Bounce*). Якщо силовий струм двигуна (наприклад, 10 А) повертається до мінусової клеми тим самим проводом або полігоном, до якого під'єднана цифрова земля чутливого давача, падіння напруги на опорі землі зсуває нульовий потенціал:

```
V_gnd_shift = I_power · R_gnd_wire + L_gnd · (di_power / dt)
```

Якщо `V_gnd_shift` перевищує поріг логічного нуля інтерфейсу UART чи SPI (`V_IL ≈ 0.8 В` для 3.3-вольтової логіки), мікроконтролер читає одиницю замість нуля. Виникають спотворені байти, фальшиві спрацьовування зовнішніх переривань та зависання кінцевих автоматів драйверів.

```
Схемотехнічні бар'єри захисту:
1. Вхідний TVS-діод (придушення викидів напруги вище робочого діапазону).
2. Послідовний дросель або феритова намистина + керамічний конденсатор низького ESR (LC-фільтр низьких частот).
3. Зворотний діод Шотткі паралельно кожному індуктивному навантаженню.
4. Розділення силової та сигнальної землі зі з'єднанням виключно в одній «зірковій» точці (Star Ground).
```

## Кліматичні фактори: -40 °C..+85 °C, деградація електролітів та дрейф кварцу

У лабораторії температура підтримується кондиціонером на рівні +20..+24 °C. У польових умовах електроніка повинна працювати в промисловому діапазоні температур від -40 °C до +85 °C (а в підкапотному просторі автомобіля чи всередині герметичного корпусу на сонці — до +105 °C). Зміна температури на 100 °C докорінно змінює фізичні властивості напівпровідників, пасивних компонентів та хімічних джерел струму.

### Поведінка напівпровідників на краях діапазону

При підвищенні температури експоненційно зростають зворотні струми витоку p-n переходів кремнію (англ. *leakage current*):

```
I_leak(T) ≈ I_0 · 2^((T - T_0) / 10)
```

При нагріванні від +25 °C до +85 °C струм витоку кожного закритого транзистора всередині мікроконтролера зростає у `2^6 = 64 рази`. Це призводить до того, що струм споживання мікроконтролера в режимі глибокого сну (англ. *Deep Sleep*) замість паспортних 5 мкА підскакує до 300–500 мкА, висаджуючи автономну батарею за кілька місяців замість запланованих п'яти років. 

Крім того, пряме падіння напруги на p-n переході діодів та біполярних транзисторів зменшується з коефіцієнтом приблизно `-2 мВ/°C`. Напруга відкривання польових MOSFET-транзисторів (англ. *Gate Threshold Voltage*, `V_GS(th)`) при нагріванні падає, що збільшує ризик випадкового відкривання ключа від незначної завади на затворі.

### Температурний дрейф кварцових резонаторів

Кварцові резонатори забезпечують тактову частоту мікроконтролера та радіочастотних трансиверів. Залежність частоти кварцового кристала зі зрізом AT від температури описується кубічною кривою, а часових резонаторів 32.768 кГц (зріз типу «камертон», англ. *Tuning Fork*) — параболою:

```
Δf / f = -k · (T - T_0)²
```

де `k ≈ 0.035 ppm / °C²`, а `T_0 = +25 °C`.

Розрахуємо відхилення частоти годинникового кварцу при морозі -40 °C:

```
ΔT = -40 - 25                          [відхилення температури від номінальних +25 °C]
   = -65 °C

Δf / f = -0.035 · (-65)²               [параболічна температурна залежність]
       = -0.035 · 4225
       = -147.9 ppm                    [дрейф частоти годинникового резонатора]
```

Відхилення у `-148 ppm` означає похибку ходу годинника реального часу (RTC) майже на 13 секунд за добу. Але справжня катастрофа стається, коли прошивка використовує не зовнішній кварц, а внутрішній вбудований RC-генератор мікроконтролера. 

Внутрішні RC-генератори при зміні температури від +20 °C до -40 °C дрейфують на 3–8% за частотою. Асинхронний протокол UART вимагає узгодження швидкостей передавача та приймача з точністю не гірше ніж `±2.5%`. Як тільки швидкість UART «пливе» на 4%, приймач розсинхронізується всередині 10-бітного кадру, і зв'язок повністю припиняється (помилки Framing Error). На столі зв'язок працював ідеально; на морозі в полі пристрій стає глухим.

### Замерзання електролітичних конденсаторів

Алюмінієві електролітичні конденсатори містять рідкий електроліт. При зниженні температури нижче -20 °C в'язкість електроліту різко зростає, а при -40 °C він замерзає. Це викликає два фізичні наслідки:
1. Ємність конденсатора `C` падає на 60–80% від номіналу.
2. Еквівалентний послідовний опір (англ. *Equivalent Series Resistance*, ESR) зростає в 20–50 разів (наприклад, з 0.1 Ом до 4–5 Ом).

Імпульсний DC-DC перетворювач використовує вихідний конденсатор для згладжування струму дроселя та стабілізації петлі зворотного зв'язку. Зростання ESR у 30 разів призводить до того, що розмах пульсацій напруги на виході перетворювача `ΔV_ripple = ΔI_L · ESR` зростає з 20 мВ до 600 мВ. Більше того, нуль передавальної функції петлі регулювання, що залежить від `1 / (2π · C · ESR)`, зміщується, петля зворотного зв'язку втрачає запас стійкості за фазою, перетворювач зривається в генерацію паразитних коливань, а мікроконтролер постійно перезавантажується.

```
Правило вибору компонентів для поля:
- Замість рідких алюмінієвих електролітів — полімерні (Solid Polymer) або танталові конденсатори (ESR стабільний до -55 °C).
- Для радіочастотних та точних часових вузлів — термокомпенсовані кварцові генератори (TCXO) замість простих резонаторів.
- Використання керамічних конденсаторів з діелектриком X7R або C0G/NP0 (діелектрик Y5V заборонено: при -40 °C він втрачає до 85% ємності).
```

### Замерзання літієвих батарей

Хімічні джерела струму на основі літію (Li-ion, LiPo) на морозі зазнають різкого сповільнення швидкості дифузії іонів у рідкому електроліті. Внутрішній опір акумулятора `R_int` при -30 °C зростає в 8–15 разів. 

Коли пристрій намагається ввімкнути навантаження (наприклад, GSM/LTE передавач зі струмом 2 А в імпульсі), падіння напруги на внутрішньому опорі акумулятора `ΔV = I · R_int` досягає 1.5–2.0 В. Напруга на клемах миттєво просідає нижче критичного порогу 3.0 В, хоча акумулятор заряджений на 90%.

Крім того, заряджання звичайних літієвих акумуляторів при температурі нижче 0 °C суворо заборонено: через сповільнену інтеркаляцію іони літію не встигають проникнути в структуру графітового анода і відновлюються на його поверхні у вигляді металевого літію (англ. *Lithium Plating*). Металеві голки проростають крізь сепаратор, викликаючи внутрішнє коротке замикання, тепловий розгін і пожежу.

## Вологість, конденсація та електрохімічна міграція

Лабораторне приміщення зазвичай має відносну вологість 30–50% за стабільної температури. У польових умовах відносна вологість сягає 95–100%, але головну небезпеку становить не сама волога в повітрі, а явище фазового переходу — випадання конденсату.

### Точка роси (Dew Point)

Точка роси (лат. *condensatio*, «згущення») — це температура, до якої повинно охолонути повітря з певною вологістю, щоб водяна пара наситилася й почала конденсуватися в рідку воду на поверхнях.

Уявімо типовий польовий сценарій: вдень герметичний або напівгерметичний корпус приладу нагрівається на сонці до +35 °C, затягуючи вологе повітря крізь мікрощілини або неякісні ущільнювачі. Вночі температура навколишнього середовища стрімко падає до +8 °C. Стінки корпусу та масивні металеві деталі друкованої плати охолоджуються швидше за повітря всередині. Щойно температура поверхні плати опускається нижче точки роси, вся внутрішня площадка покривається мікроскопічною рідкою плівкою води.

*Електрохімічна міграція та ріст дендритів під дією напруги й конденсату. Наявність рідкої водноної плівки, іонів солей і постійної різниці потенціалів перетворює проміжок між ніжками QFN-чіпа на електрохімічну комірку. Дендрити проростають від катода до анода, формуючи коротке замикання.*

### Електрохімічна міграція та ріст дендритів

Сама по собі дистильована вода має низьку електропровідність. Проте на поверхні змонтованої друкованої плати завжди присутні залишки солей, атмосферного пилу та активаторів паяльного флюсу (хлориди, броміди, органічні кислоти). Розчиняючись у плівці конденсату, вони утворюють агресивний рідкий електроліт.

Коли на сусідні доріжки або виводи мікросхеми подано постійну напругу (наприклад, 3.3 В або 12 В на ніжках з кроком 0.5 мм у корпусі QFN), виникає електрохімічна комірка. Розпочинається процес електрохімічної міграції (англ. *Electrochemical Migration*, ECM):

1. **Анодна реакція (окиснення металу):** під дією позитивного потенціалу атоми міді, срібла чи свинцю втрачають електрони й переходять у розчин у вигляді позитивних іонів:
```
Cu → Cu²⁺ + 2e⁻
Ag → Ag⁺ + e⁻
```
2. **Міграція іонів:** позитивні катіони `Cu²⁺` рухаються крізь шар електроліту під дією напруженості електричного поля в бік негативно зарядженого катода (земляної доріжки).
3. **Катодна реакція (відновлення металу):** на катоді іони приєднують електрони й осаджуються назад у металеву форму:
```
Cu²⁺ + 2e⁻ → Cu⁰
```

Осадження металу відбувається не рівномірним шаром, а у вигляді деревоподібних кристалічних ниток — дендритів (грец. *δένδρον*, «дерево»). Дендрити ростуть від катода назустріч аноду зі швидкістю до кількох мікрометрів на секунду.

Щойно вістря дендрита дотикається протилежного виводу:
- Виникає мікрошунт з опором від десятків ом до кілоомів. Це призводить до спотворення показань високоомних аналогових ланцюгів (АЦП починає показувати випадковий шум або фіксоване зміщення).
- Якщо напруга в колі висока, через дендрит протікає імпульс струму короткого замикання. Дендрит миттєво перегорає (як плавка вставка), залишаючи на текстоліті шар карбонізованого вуглецю, який сам по собі є провідником і формує постійний струм витоку.

```
Методи захисту від конденсації та електроміграції:
1. Відмивання плат: ультразвукове очищення у деіонізованій воді зі спеціальними розчинниками для повного видалення залишків флюсу (рівень іонної чистоти < 1.56 мкг NaCl-екв/см² за IPC-J-STD-001).
2. Захисне лакування (Conformal Coating): нанесення плівки товщиною 25–75 мкм (акрил, силікон, поліуретан або парофазний парилен) для ізоляції міді від повітря.
3. Мембранні вентиляційні клапани (Gore-Tex ePTFE): пропускають молекули водяної пари назовні для вирівнювання вологості, але блокують проникнення крапель води та пилу.
```

## Механічні вібрації, удари та втомна деградація пайки

Лабораторний стіл нерухомий. У польових умовах пристрій піддається постійним синусоїдальним та випадковим вібраціям від двигунів (діапазон 20–2000 Гц з прискоренням від 2 G до 20 G), а також ударним навантаженням під час транспортування, пострілів чи посадки безпілотника (удари до 50–100 G тривалістю 11 мс).

### Резонанс друкованої плати та відрив масивних компонентів

Друкована плата, закріплена на кутових стійках усередині корпусу, являє собою механічну коливальну систему з власною резонансною частотою `f_res` (лат. *resono*, «відгукуюсь»). Якщо спектр вібрації транспортного засобу містить гармоніку, що збігається з `f_res` плати, амплітуда вигину текстоліту зростає в 5–15 разів.

Масивні компоненти (електролітичні конденсатори, силові котушки індуктивності, трансформатори, важкі роз'єми) мають значну інерційну масу `m`. При коливаннях плати на виводи компонента діє механічна сила `F = m · a`.

Якщо високий конденсатор стоїть на платі лише на двох тонких дротяних ніжках без додаткової фіксації, циклічний згин виводів призводить до втомного зламу металу біля кореня за кілька годин роботи. Конденсатор відпадає, і схема втрачає фільтрацію.

### Втомне руйнування безсвинцевих паяних з'єднань (Solder Joint Fatigue)

Сучасна електроніка виготовляється з використанням безсвинцевих припоїв (найчастіше сплав SAC305: 96.5% олова, 3.0% срібла, 0.5% міді). На відміну від класичного свинцевого припою Sn63Pb37, безсвинцеві сплави значно жорсткіші, мають вищий модуль пружності та низьку пластичність.

Під час одночасної дії вібрації та термоциклування виникає конфлікт коефіцієнтів теплового розширення (англ. *Coefficient of Thermal Expansion*, CTE):
- Кремнієвий кристал мікросхеми: `CTE ≈ 2.6 ppm / °C`.
- Пластиковий корпус мікросхеми (QFP/BGA): `CTE ≈ 15 ppm / °C`.
- Склотекстоліт FR-4: `CTE ≈ 14–17 ppm / °C` у площині XY та до `60 ppm / °C` по осі Z.

Через різницю розширення матеріалів паяні кульки корпусів BGA та торцеві контакти SMD-компонентів розмірів 1206 і 0805 зазнають постійних зсувних деформацій.

```
Цикл: Нагрів → Розширення FR-4 > Кремній → Зсув пайки
      Охолодження → Стиск FR-4 → Зсув у зворотний бік + Вібрація
```

Через 200–500 циклів усередині паяного з'єднання зароджується мікротріщина. Виникає класичний «плаваючий» інтермітуючий дефект: у холодній лабораторії тріщина стиснута і контакт є; під час нагрівання в роботі метал розходиться, і прилад раптово зависає. Діагностувати такий дефект на столі практично неможливо, оскільки контакт відновлюється, щойно інженер торкається плати щупом тестера.

### Деренч контактів і фретинг-корозія роз'ємів

Гвинтові клемники під дією вібрації мають схильність до саморозкручування. Зниження сили притискання призводить до збільшення перехідного опору контакту, локального нагрівання струмом та обвуглювання клемника.

У роз'ємних з'єднаннях (штирьові роз'єми, автомобільні конектори) мікровібрації викликають взаємне тертя контактних поверхонь з амплітудою в кілька мікрометрів. Це явище називають фретинг-корозією (англ. *Fretting Corrosion*): захисне золоте або олов'яне покриття стирається, оголена мідь окиснюється на повітрі, а оксид міді є ізолятором. Опір лінії передачі даних підскакує з 0.05 Ом до сотень ом, руйнуючи цілісність сигналів.

```
Механічний захист конструкції:
1. Анкерування: фіксація всіх компонентів вагою понад 5 грамів нейтральним силіконовим герметиком (RTV) або епоксидним клеєм до поверхні плати.
2. Кутові підпори та ребра жорсткості для зміщення власної резонансної частоти друкованої плати вище 200 Гц.
3. Пружинні клемники (WAGO Push-In) замість гвинтових затискачів.
4. Заливка блоку еластичним поліуретановим компаундом (Potting) у критичних вузлах з екстремальною вібрацією.
```

## Методологія стрес-тестування HALT та HASS

Як гарантувати, що виріб витримає польове середовище, ще до запуску у масове виробництво? Звичайні функціональні тести («увімкнули на 2 години при +20 °C — працює») не несуть жодної інформації про реальний запас міцності конструкції.

Для виявлення прихованих дефектів у передовій інженерії застосовують методологію прискорених стрес-тестів: **HALT** та **HASS**.

![Методологія стрес-тестування HALT: межі специфікації компонентів (Spec Limits), робочі межі виникнення зворотних збоїв (LOL/UOL), межі незворотного руйнування (LDL/UDL) та контрольована зона виробничого скринінгу HASS](/root/course/embedded/chomu-pratsiuie-na-stoli-i-ne-pratsiuie-v-poli/img/halt-operating-limits.svg)
*Карта стрес-тестування HALT. Тест навмисно виводить прилад за паспортні межі специфікації до точок зворотного збою (Operating Limits) та фізичного руйнування (Destruct Limits). Розширення запасу міцності (Design Margin) гарантує безвідмовність у полі.*

### HALT (Highly Accelerated Life Testing)

HALT — це метод випробувань на етапі розробки прототипу (англ. *DVT*, Design Validation Testing). Його мета — **знайти найслабшу ланку схеми й зламати прилад якомога швидше**.

Виріб поміщають у спеціальну камеру, де одночасно діють комбіновані руйнівні стрес-фактори:
- Швидкісна зміна температури зі швидкістю до `60 °C / хвилину` (термоудар від -65 °C до +130 °C за допомогою рідкого азоту та потужних нагрівачів).
- 6-осьова випадкова вібрація з широким спектром частот (пневматичні вібромолоти з енергією удару до 50 Grms).
- Стрибки напруги живлення від мінімального до максимального порогу.

Під час тестування визначають чотири критичні точки:
1. **Нижня та верхня робочі межі (LOL / UOL — Lower/Upper Operating Limit):** граничні значення стресу, за яких пристрій починає давати програмні або функціональні збої, але повністю повертається до нормальної роботи, щойно стрес знято.
2. **Нижня та верхня межі руйнування (LDL / UDL — Lower/Upper Destruct Limit):** значення стресу, за яких стається незворотне фізичне пошкодження (пробій силового транзистора, відрив ніжки мікросхеми, розрив доріжки текстоліту).

Після виявлення першої відмови інженери не зупиняють тест: вони ремонтують пошкоджений вузол, модифікують схему або топологію плати, усуваючи знайдену слабкість, і продовжують піднімати стрес далі. Мета HALT — розсунути робочі межі LOL/UOL та межі руйнування LDL/UDL якомога далі за межі паспортної специфікації, створивши максимальний запас надійності (англ. *Design Margin*).

### HASS (Highly Accelerated Stress Screen)

HASS (англ. *screening*, «просіювання, відбір») застосовується вже на етапі серійного виробництва. На відміну від HALT, HASS **не повинен руйнувати справний виріб** чи вичерпувати його залишковий ресурс.

Рівні навантаження в HASS підбирають у безпечному діапазоні — вище паспортних меж специфікації, але нижче межі LOL, знайденої під час HALT. Короткий 15-хвилинний комбінований стрес-прогін кожної випущеної плати дозволяє миттєво відсіяти приховані виробничі дефекти: мікропустоти в паяних кульках BGA, дефектні компоненти з мікротріщинами кристала та неякісну відмивку флюсу.

## Програмно-апаратна самооборона: надійний код на C та C++

Навіть після оптимізації схеми та конструкції польове середовище рано чи пізно створить екстремальну ситуацію. Прошивка польового пристрою не має права наївно сподіватися на стабільність заліза. Вона мусить активно захищати пристрій: діагностувати аварії, реєструвати причини перезапусків у нелеткій пам'яті та безпечно деградувати (англ. *Graceful Degradation*).

Розглянемо повнофункціональний модуль польового моніторингу середовища. Модуль вирішує чотири критичні задачі:
1. **Діагностика джерела перезапуску:** зчитування апаратних регістрів мікроконтролера при старті для виявлення просадок живлення (Brownout), спрацьовування сторожового таймера чи апаратного збою (HardFault).
2. **Адаптивне зниження частоти (Thermal Throttling):** автоматичне зменшення тактової частоти ядра та вимкнення енергоємних блоків (радіо, підсвітка, нагрівачі) при наближенні температури до верхньої робочої межі (+80 °C).
3. **Захист батареї на морозі:** заборона вмикання потужних передавачів та заряду акумулятора при температурі нижче 0 °C.
4. **Валідація інтерфейсів:** детектування зависання шини I²C/SPI через контактний деренч та її апаратне примусове скидання (Clock Toggling).

#include <stdint.h>
#include <stdbool.h>

/* Коди причин апаратного перезапуску системи */
typedef enum {
    RESET_CAUSE_UNKNOWN      = 0x00,
    RESET_CAUSE_POWER_ON     = 0x01,
    RESET_CAUSE_BROWNOUT     = 0x02, /* Просадка живлення через перехідний процес */
    RESET_CAUSE_WATCHDOG     = 0x03, /* Зависання через перешкоду або втрату тактування */
    RESET_CAUSE_THERMAL_LOCK = 0x04  /* Захисне вимкнення через перегрів */
} reset_cause_t;

/* Структура стану фізичного середовища */
typedef struct {
    float    temperature_c;
    float    supply_voltage_v;
    uint32_t brownout_count;
    bool     throttling_active;
    bool     heater_active;
} system_telemetry_t;

/* Емуляція апаратних регістрів мікроконтролера */
extern uint32_t MCU_RESET_FLAGS_REG;
extern void mcu_set_cpu_frequency_mhz(uint32_t freq);
extern void mcu_disable_high_power_peripherals(void);
extern void mcu_enable_high_power_peripherals(void);
extern void nonvolatile_log_write(reset_cause_t cause);

/* Зчитування та фіксація причини останнього перезапуску */
reset_cause_t system_diagnose_boot_cause(void) {
    reset_cause_t cause = RESET_CAUSE_UNKNOWN;
    uint32_t flags = MCU_RESET_FLAGS_REG;

    if (flags & (1 << 3)) {
        cause = RESET_CAUSE_BROWNOUT;
    } else if (flags & (1 << 2)) {
        cause = RESET_CAUSE_WATCHDOG;
    } else if (flags & (1 << 0)) {
        cause = RESET_CAUSE_POWER_ON;
    }

    /* Очищення регістру прапорів після зчитування */
    MCU_RESET_FLAGS_REG = 0;
    nonvolatile_log_write(cause);
    return cause;
}

/* Обробка стрес-факторів середовища в головному циклі керування */
void system_environmental_guard(system_telemetry_t *telemetry) {
    /* 1. Захист від перегріву: динамічне зниження частоти */
    if (telemetry->temperature_c >= 80.0f) {
        if (!telemetry->throttling_active) {
            mcu_set_cpu_frequency_mhz(24); /* Скидаємо тактову частоту з 160 МГц */
            mcu_disable_high_power_peripherals();
            telemetry->throttling_active = true;
        }
    } else if (telemetry->temperature_c <= 65.0f && telemetry->throttling_active) {
        mcu_set_cpu_frequency_mhz(160); /* Повертаємо номінальну швидкість */
        mcu_enable_high_power_peripherals();
        telemetry->throttling_active = false;
    }

    /* 2. Захист від замерзання електролітів та конденсату: увімкнення підігріву */
    if (telemetry->temperature_c < -10.0f) {
        telemetry->heater_active = true;
    } else if (telemetry->temperature_c > 0.0f) {
        telemetry->heater_active = false;
    }

    /* 3. Контроль просадки напруги живлення під навантаженням */
    if (telemetry->supply_voltage_v < 3.10f) {
        /* Напруга наближається до порогу UVLO (2.9 В) — аварійне вимкнення передавача */
        mcu_disable_high_power_peripherals();
    }
}

#include <cstdint>
#include <array>
#include <string_view>
#include <expected>

namespace field_guard {

enum class ResetCause : uint8_t {
    Unknown     = 0x00,
    PowerOn     = 0x01,
    Brownout    = 0x02,
    Watchdog    = 0x03,
    ThermalLock = 0x04
};

struct Telemetry {
    float temperature_c       { 25.0f };
    float supply_voltage_v    { 3.30f };
    uint32_t brownout_count   { 0 };
    bool throttling_active    { false };
    bool heater_active        { false };
};

class EnvironmentalSupervisor {
public:
    constexpr EnvironmentalSupervisor() noexcept = default;

    [[nodiscard]] ResetCause diagnose_boot_flags(uint32_t raw_flags) noexcept {
        ResetCause cause = ResetCause::Unknown;

        if (raw_flags & (1U << 3)) {
            cause = ResetCause::Brownout;
        } else if (raw_flags & (1U << 2)) {
            cause = ResetCause::Watchdog;
        } else if (raw_flags & (1U << 0)) {
            cause = ResetCause::PowerOn;
        }

        current_cause_ = cause;
        return cause;
    }

    void evaluate_state(Telemetry& telemetry) noexcept {
        // 1. Адаптивне керування теплом при переході межі +80 °C
        if (telemetry.temperature_c >= 80.0f) {
            if (!telemetry.throttling_active) {
                apply_thermal_throttling(true);

## Підсумковий інженерний синтез

Польова надійність не з'являється в результаті успішного завершення лабораторних тестів. Вона закладається на кожному рівні піраміди розробки:

1. **Схемотехнічний рівень:** розрахунок індуктивності живильних ліній `L · (di/dt)`, установка TVS-діодів, діодів захисту від самоіндукції, вибір полімерних та керамічних конденсаторів X7R/C0G замість рідких електролітів, використання термокомпенсованих генераторів (TCXO).
2. **Конструктивний рівень:** відмивання залишків флюсу в ультразвуковій ванні, захисне лакування плати (Conformal Coating), установка мембранних клапанів для компенсації тиску без випадання конденсату, анкерування масивних компонентів силіконом RTV та використання пружинних клемників.
3. **Методологічний рівень:** обов'язкове проведення стрес-тестування HALT для визначення реального запасу міцності (Design Margin) та скринінгу HASS для виявлення дефектів монтажу.
4. **Програмний рівень:** постійний моніторинг температури та напруги, детектування зависання шин, логування причин Brownout-перезапусків та адаптивне зниження навантаження при наближенні до меж експлуатації.

Тільки системне врахування всіх чотирьох складових перетворює крихкий лабораторний прототип на безвідмовний пристрій, здатний роками працювати в найжорсткіших польових умовах.
