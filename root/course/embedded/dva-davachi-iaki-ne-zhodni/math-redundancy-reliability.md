# 🧮 Розрахунок надійності та ймовірності відмови в надлишкових архітектурах

Цей розрахунок дає математичну основу для вибору між одиночним каналом (1oo1), дублюванням (1oo2, 2oo2), дублюванням із самодіагностикою (1oo2D) та потрійною мажоритарною структурою (2oo3 / TMR), зіставляючи середню ймовірність небезпечної відмови на вимогу (PFD_avg), частку безпечних відмов (SFF), частоту хибних спрацьовувань та вплив відмов за спільною причиною (CCF).

## 1. Класифікація відмов та базова експоненційна модель (1oo1)

Відповідно до стандарту функційної безпеки IEC 61508 загальна інтенсивність відмов вимірювального перетворювача `λ` (вимірюється у відмовах за годину `год⁻¹` або `FIT = 10⁻⁹ год⁻¹`) поділяється на чотири ортогональні складові:

```
λ = λ_sd + λ_su + λ_dd + λ_du
```

де:
* `λ_sd` (англ. *Safe Detected*) — безпечні виявлені відмови (пристрій переходить у безпечний стан самостійно, наприклад обрив лінії струмової петлі 4–20 мА з рівнем струму `< 3.6 мА`);
* `λ_su` (англ. *Safe Undetected*) — безпечні невиявлені відмови (збій, який не призводить до втрати захисної функції, але залишається непоміченим внутрішньою діагностикою);
* `λ_dd` (англ. *Dangerous Detected*) — небезпечні виявлені відмови (викривлення виміру, яке перехоплюється внутрішнім сторожовим таймером, контрольною сумою CRC або перевіркою виходу за діапазон);
* `λ_du` (англ. *Dangerous Undetected*) — небезпечні невиявлені відмови (прихований дрейф сенсора, заклинювання мембрани або деградація АЦП, за яких сигнал залишається у валідному діапазоні, але спотворює реальне значення).

Ключовим показником внутрішнього контролю є коефіцієнт діагностичного покриття (англ. *Diagnostic Coverage*, `DC`):

```
DC = λ_dd / (λ_dd + λ_du)
```

Частка безпечних відмов (англ. *Safe Failure Fraction*, `SFF`) визначає архітектурну придатність вузла до рівнів безпеки SIL (Safety Integrity Level):

```
SFF = (λ_s + λ_dd) / (λ_s + λ_d) = (λ_sd + λ_su + λ_dd) / (λ_sd + λ_su + λ_dd + λ_du)
```

Для одиночного каналу (1oo1) за постійної інтенсивності прихованих відмов `λ_du` функція надійності `R(t)` та функція ненадійності `F(t)` описуються законом Пуассона:

```
R(t) = e^(-λ_du·t)
F(t) = 1 - R(t) = 1 - e^(-λ_du·t)
```

Для типових інтервалів між періодичними ручними повірками `T_i` (англ. *Proof Test Interval*, зазвичай `8760 год` = 1 рік), коли добуток `λ_du·T_i ≪ 1`, застосовуємо лінійний розклад Тейлора:

```
e^(-λ_du·t)
≈ 1 - λ_du·t + (λ_du·t)² / 2 - ...   [розклад експоненти в ряд Тейлора]
≈ 1 - λ_du·t                         [лінійне наближення першого порядку]
```

Середня ймовірність небезпечної відмови на вимогу (`PFD_avg_1oo1`):

```
PFD_avg_1oo1
= (1 / T_i) · ∫₀^(T_i) F(t) dt       [інтегральне середнє ненадійності на інтервалі T_i]
= (1 / T_i) · ∫₀^(T_i) (λ_du·t) dt   [підстановка лінійного виразу F(t)]
= (1 / T_i) · (λ_du · T_i² / 2)      [інтегрування за часом]
= (λ_du · T_i) / 2                   [середнє значення PFD для 1oo1]
```

Середній час безвідмовної роботи до небезпечного збою (MTTF_d):

```
MTTF_d_1oo1
= ∫₀^∞ R(t) dt                       [інтеграл функції надійності]
= ∫₀^∞ e^(-λ_du·t) dt                [підстановка експоненційного закону]
= 1 / λ_du                           [обчислення інтеграла]
```

## 2. Архітектура 1oo2 (1 out of 2 — дублювання для безпеки)

В архітектурі 1oo2 захисне відключення або зупинка технологічного процесу виконується, якщо *хоча б один* із двох каналів подав сигнал тривоги. 

Небезпечна відмова системи виникає лише тоді, коли *обидва* незалежні давачі одночасно зазнали прихованої небезпечної відмови `λ_du` і не змогли зафіксувати аварійний стан:

```
F_1oo2(t)
= F₁(t) · F₂(t)                      [правило множення для незалежних подій]
= (1 - e^(-λ_du·t)) · (1 - e^(-λ_du·t)) [підстановка однакових каналів]
= (1 - e^(-λ_du·t))²                 [квадрат функції ненадійності]
≈ (λ_du·t)²                          [наближення Тейлора для малих λ_du·t]
```

Функція надійності системи 1oo2:

```
R_1oo2(t)
= 1 - F_1oo2(t)                      [доповнення до повної ймовірності]
= 1 - (1 - e^(-λ_du·t))²             [підстановка квадратичної ненадійності]
= 1 - (1 - 2·e^(-λ_du·t) + e^(-2λ_du·t)) [розкриття квадрата різниці]
= 2·e^(-λ_du·t) - e^(-2λ_du·t)       [зведення подібних членів]
```

Розрахунок середньої ймовірності відмови на вимогу `PFD_avg_1oo2`:

```
PFD_avg_1oo2
= (1 / T_i) · ∫₀^(T_i) (λ_du·t)² dt  [інтегрування квадратичної ненадійності]
= (1 / T_i) · (λ_du² · T_i³ / 3)     [взяття первісної t³/3]
= (λ_du² · T_i²) / 3                 [середнє значення PFD для 1oo2]
```

### Частота хибних спрацьовувань (Spurious Trip Rate)

Будь-яка безпечна або виявлена відмова в будь-якому з двох каналів призводить до помилкового спрацьовування системи:

```
λ_spurious_1oo2
= λ_s1 + λ_dd1 + λ_s2 + λ_dd2        [сума інтенсивностей хибних відмов двох каналів]
= 2 · (λ_s + λ_dd)                   [для двох ідентичних давачів]
```

Середній час між хибними відключеннями (MTTF_spurious):

```
MTTF_spurious_1oo2
= 1 / (2 · (λ_s + λ_dd))             [удвічі менший, ніж для одиночного каналу]
```

Висновок: архітектура 1oo2 зменшує ймовірність небезпечної відмови з лінійної залежності `λ·T_i / 2` до квадратичної `(λ·T_i)² / 3`, що дозволяє досягти рівнів SIL 2 або SIL 3, проте подвоює кількість хибних аварійних зупинок підприємства чи пристрою.

## 3. Архітектура 2oo2 (2 out of 2 — дублювання для доступності)

В архітектурі 2oo2 захисна дія активується лише за умови, коли *обидва* вимірювальні канали узгодили наявність небезпеки.

Функція надійності проти хибного спрацьовування (обидва канали повинні хибно спрацювати одночасно):

```
R_spurious_2oo2(t)
= 1 - (1 - e^(-λ_s·t))²
≈ 1 - (λ_s·t)²                       [хибне спрацьовування вимагає збою обох каналів]
```

Проте з погляду небезпечної відмови система виходить із ладу, якщо *хоча б один* із двох каналів зазнав відмови `λ_du` (оскільки зламаний канал заблокує згоду другого):

```
R_2oo2(t)
= R₁(t) · R₂(t)                      [обидва канали зобов'язані бути справними]
= e^(-λ_du·t) · e^(-λ_du·t)          [добуток експоненційних функцій]
= e^(-2λ_du·t)                       [сума показників]
```

Ненадійність 2oo2:

```
F_2oo2(t)
= 1 - R_2oo2(t)                      [доповнення]
= 1 - e^(-2λ_du·t)                   [підстановка R_2oo2]
≈ 2 · λ_du · t                       [лінійне наближення]
```

Звідси:

```
PFD_avg_2oo2
= (1 / T_i) · ∫₀^(T_i) (2 · λ_du · t) dt [інтегрування лінійної функції]
= λ_du · T_i                         [вдвічі гірше, ніж для одиночного каналу 1oo1!]
```

Висновок: архітектура 2oo2 повністю захищає від хибних спрацьовувань (найвища експлуатаційна доступність), проте збільшує ймовірність небезпечної катастрофи у 2 рази порівняно з одинарним давачем.

## 4. Архітектура 1oo2D (1 out of 2 з внутрішньою крос-діагностикою)

Архітектура 1oo2D поєднує переваги 1oo2 та 2oo2 за допомогою постійного програмного порівняння каналів (діагностичне тестування в реальному часі з періодом `T_d ≪ T_i`, наприклад `T_d = 20 мс`).

Поки обидва канали згодні між собою, система працює в режимі 2oo2 (висока стійкість до завад). Щойно виникає розбіжність `|x₁ - x₂| > ε`, внутрішня діагностика переводить виявлену відмову в розряд `λ_dd`, ізолює збійний канал і перемикає систему на керування за єдиним здоровим каналом (1oo1) або в безпечне зміщення.

Середня ймовірність небезпечної відмови для 1oo2D:

```
PFD_avg_1oo2D
= (1 - DC) · (λ_du · T_i) / 2 + DC · (λ_du² · T_i²) / 3 [комбінація виявленої та невиявленої часток]
```

При високому діагностичному покритті `DC ≥ 90%` перший доданок знижується на порядок, а другий залишається квадратично малим, забезпечуючи високу безпеку без надмірних хибних відключень.

## 5. Потрійна мажоритарна структура: 2oo3 (TMR — Triple Modular Redundancy)

В архітектурі 2oo3 кінцеве рішення ухвалюється мажоритарним воутером за правилом більшості (2 з 3). Система працездатна, якщо справні всі 3 давачі або будь-які 2 з 3:

```
R_2oo3(t)
= R³ + 3·R²·(1 - R)                  [формула Бернуллі для k ≥ 2 успіхів з 3]
= R³ + 3·R² - 3·R³                   [розкриття дужок]
= 3·R² - 2·R³                        [класична поліноміальна функція TMR]
= 3·e^(-2λ_du·t) - 2·e^(-3λ_du·t)    [підстановка експоненційного закону R = e^(-λ_du·t)]
```

Розклад ненадійності `F_2oo3(t)` у ряд Тейлора другого порядку:

```
F_2oo3(t)
= 1 - R_2oo3(t)                      [доповнення до 1]
= 1 - (3·e^(-2λ_du·t) - 2·e^(-3λ_du·t)) [підстановка R_2oo3]
≈ 1 - (3·(1 - 2λt + 2λ²t²) - 2·(1 - 3λt + 4.5λ²t²)) [розклад експонент другого порядку]
= 1 - (3 - 6λt + 6λ²t² - 2 + 6λt - 9λ²t²) [розкриття дужок і зведення]
= 1 - (1 - 3λ²t²)                    [скорочення лінійних членів 6λt]
= 3 · (λ_du · t)²                    [квадратична ненадійність 2oo3]
```

Розрахунок `PFD_avg_2oo3`:

```
PFD_avg_2oo3
= (1 / T_i) · ∫₀^(T_i) 3 · (λ_du · t)² dt [інтегральне середнє квадратичної функції]
= (1 / T_i) · (3 · λ_du² · T_i³ / 3) [взяття інтеграла]
= λ_du² · T_i²                       [середня ймовірність відмови для 2oo3]
```

Розрахунок середнього часу безвідмовної роботи MTBF:

```
MTBF_2oo3
= ∫₀^∞ (3·e^(-2λ·t) - 2·e^(-3λ·t)) dt [інтегрування функції надійності від 0 до нескінченності]
= 3 / (2λ) - 2 / (3λ)                [обчислення табличних інтегралів]
= 9 / (6λ) - 4 / (6λ)                [зведення дробів до спільного знаменника]
= 5 / (6λ)                           [MTBF для TMR становить 83.3% від одиночного каналу]
```

*Парадокс MTBF у мажоритарних системах:* Інтегральний показник `MTBF_2oo3 = 0.833 / λ` формально менший, ніж у простого давача `1 / λ`, через те що в системі працює втричі більше фізичних напівпровідникових елементів. Проте на часовому горизонті експлуатації `t < 0.7 / λ` надійність `R_2oo3(t)` істотно перевершує `R_1oo1(t)`, а ймовірність раптової відмови знижується на два-три порядки.

## 6. Вплив відмов за спільною причиною (CCF та β-фактор)

У реальних вбудованих пристроях давачі ніколи не є цілком незалежними. Спільна друкована плата, єдине джерело опорної напруги АЦП, спільний джгут проводів (електромагнітна наводка) або однакова партія кремнієвих кристалів (систематична помилка топології) створюють відмови за спільною причиною (англ. *Common Cause Failures*, CCF).

За моделлю стандартів IEC 61508 / ISO 26262 інтенсивність відмов `λ_du` розділяється за допомогою коефіцієнта `β` (типово `1% ≤ β ≤ 10%`, тобто `0.01 ≤ β ≤ 0.10`):

```
λ_ind = (1 - β) · λ_du               [незалежна складова окремого каналу]
λ_ccf = β · λ_du                     [спільна складова, що одночасно виводить з ладу всі канали]
```

З урахуванням β-фактора формули `PFD_avg` трансформуються:

Для архітектури 1oo2:

```
PFD_avg_1oo2_ccf
= (1 - β)² · ((λ_du² · T_i²) / 3) + (β · λ_du · T_i) / 2 [сума незалежної квадратичної та спільної лінійної частин]
≈ (λ_du² · T_i² / 3) + (β · λ_du · T_i) / 2              [лінійний член β домінує при надійних давачах]
```

Для архітектури 2oo3 (TMR):

```
PFD_avg_2oo3_ccf
≈ λ_du² · T_i² + (β · λ_du · T_i) / 2                    [спільна причина встановлює теоретичну межу TMR]
```

## 7. Числовий розрахунок надійності реального промислового вузла

Розглянемо промисловий давач тиску котла з такими вихідними метрологічними та надійнісними характеристиками:
* Повна інтенсивність небезпечних прихованих відмов: `λ_du = 2 · 10⁻⁶ год⁻¹` (`MTTF_d ≈ 57 років`).
* Інтервал між регулярними перевірками: `T_i = 8760 год` (1 рік).
* Фактор спільної причини відмов: `β = 0.05` (5%).

Обчислимо базовий безрозмірний добуток:

```
λ_du · T_i
= (2 · 10⁻⁶) · 8760                  [підстановка числових значень λ_du та T_i]
= 0.01752                            [обчислення добутку]
```

Розрахуємо значення середньої ймовірності відмови `PFD_avg` для кожної архітектури:

```
PFD_1oo1
= 0.01752 / 2                        [формула (λ_du · T_i) / 2]
= 0.00876                            [8.76 · 10⁻³, відповідає рівню SIL 2]
```

```
PFD_1oo2_ідеальний
= 0.01752² / 3                       [формула (λ_du² · T_i²) / 3]
= 0.0003069 / 3                      [піднесення до квадрата]
= 0.0001023                          [1.02 · 10⁻⁴, відповідає рівню SIL 3]
```

```
PFD_1oo2_реальний_з_CCF
= 0.0001023 + (0.05 · 0.01752) / 2   [додавання складової спільної причини (β·λ_du·T_i)/2]
= 0.0001023 + 0.0004380              [обчислення лінійного внеску β-фактора]
= 0.0005403                          [5.40 · 10⁻⁴, спільна причина збільшила PFD у 5.3 раза]
```

```
PFD_2oo3_реальний_з_CCF
= 0.01752² + 0.0004380               [формула λ_du²·T_i² + внесок CCF]
= 0.0003069 + 0.0004380              [додавання доданків]
= 0.0007449                          [7.45 · 10⁻⁴]
```

### Підсумкова інженерна матриця вибору структури

| Архітектура | PFD_avg (з CCF β=5%) | Рівень безпеки (SIL) | Стійкість до хибних зупинок (Доступність) | Область інженерного застосування |
|---|---|---|---|---|
| **1oo1** | `8.76 · 10⁻³` | SIL 1 / SIL 2 | Базова (будь-який збій = зупинка або аварія) | Некритичні виміри, споживча електроніка |
| **2oo2** | `1.75 · 10⁻²` | Не придатна для захисту | Найвища (виключає одиничні хибні тривоги) | Системи сигналізації з високою ціною хибного виклику |
| **1oo2** | `5.40 · 10⁻⁴` | SIL 3 | Низька (подвоєна частота помилкових відключень) | Аварійні системи протиаварійного захисту (ПАЗ / ESD) |
| **1oo2D** | `9.74 · 10⁻⁴` | SIL 2 / SIL 3 | Висока (динамічний арбітраж знімає хибні зупинки) | Автомобільні педалі (APPS), сервоприводи, рульові рейки |
| **2oo3 (TMR)** | `7.45 · 10⁻⁴` | SIL 3 | Найвища (безперервна робота при ізоляції 1 каналу) | Авіоніка (Fly-by-Wire), ядерні реактори, залізнична сигналізація |

Цей розрахунок доводить: у системах із двома давачами просте дублювання (1oo2) дає максимальну безпеку лише ціною частих зупинок. Перехід до аналітичного оцінювання та архітектури 1oo2D дозволяє наблизитися до показників потрійного мажоритарного резервування 2oo3 без трикратного подорожчання апаратної частини.
