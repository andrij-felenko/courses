# 🧮 Ортогональність інновацій та перевірка узгодженості фільтра Калмана

Коли фільтр Калмана оцінює стан динамічної системи, він щотакту обчислює різницю між реальним показом давача `z[k]` та апріорним очікуваним виміром `H · x̂⁻[k]`. Цю різницю називають **інновацією** (або нев'язкою виміру, англ. *innovation*, від латинського *innovatio* — оновлення, внесення нового):

```
y[k] = z[k] − H · x̂⁻[k]
```

Центральна теорема оптимальної лінійної фільтрації стверджує: **якщо матриці математичної моделі `(F, H)` та коваріації шумів `(Q, R)` точно відповідають фізичній системі, то послідовність інновацій `y[k]` є послідовністю взаємно некорельованих випадкових величин із нульовим математичним сподіванням — тобто дискретним білим гауссовим шумом**.

Нижче наведено строге виведення коваріації інновації `S[k]`, алгебраїчне доведення ортогональності залишків у часі, розгляд крайових випадків кольорового шуму та виведення статистичних критеріїв узгодженості NIS і NEES.

---

## 1. Постановка задачі та модель похибок

Розглянемо дискретну лінійну стохастичну систему у просторі станів:

```
x[k] = F · x[k−1] + w[k−1],    w[k−1] ~ N(0, Q)
z[k] = H · x[k] + v[k],          v[k] ~ N(0, R)
```

де вектор стану `x[k] ∈ ℝⁿ`, вектор вимірювань `z[k] ∈ ℝᵐ`, `F` — матриця динаміки системи, `H` — матриця спостереження. Випадкові процеси `w[k]` (шум процесу) та `v[k]` (шум вимірювання) вважаються білими гауссовими шумами з нульовим середнім і відомими коваріаціями:

```
E[w[k]] = 0,    E[w[k] · w[j]ᵀ] = Q · δ_kj
E[v[k]] = 0,    E[v[k] · v[j]ᵀ] = R · δ_kj
```

де `δ_kj` — символ Кронекера (`δ_kj = 1` при `k = j`, і `0` при `k ≠ j`). Шум вимірювання не залежить від шуму процесу та початкового стану: `E[v[k] · w[j]ᵀ] = 0` для всіх `k, j`.

Введемо вектори похибок оцінки стану. Апріорна похибка перед приходом виміру на кроці `k`:

```
e⁻[k] = x[k] − x̂⁻[k]
```

Апостеріорна похибка після врахування виміру:

```
e[k] = x[k] − x̂[k]
```

Відповідні матриці коваріації похибок оцінки стану:

```
P⁻[k] = E[ e⁻[k] · (e⁻[k])ᵀ ]
P[k]  = E[ e[k] · (e[k])ᵀ ]
```

## 2. Виведення коваріації інновації S[k]

Підставимо рівняння фізичного виміру `z[k] = H · x[k] + v[k]` у формулу інновації:

```
y[k] = z[k] − H · x̂⁻[k]
     = (H · x[k] + v[k]) − H · x̂⁻[k]
     = H · (x[k] − x̂⁻[k]) + v[k]
     = H · e⁻[k] + v[k]
```

Цей вираз показує фізичну структуру інновації: вона складається з двох некорельованих частин — похибки поточної екстраполяції стану `e⁻[k]`, спроєктованої у вимір через матрицю `H`, та адитивного шуму давача `v[k]`.

Обчислимо математичне сподівання інновації:

```
E[y[k]] = E[ H · e⁻[k] + v[k] ]
        = H · E[e⁻[k]] + E[v[k]]
```

Оскільки фільтр Калмана є незміщеним оцінювачем за побудовою (`E[e⁻[k]] = 0`) і шум вимірювача центрований (`E[v[k]] = 0`), математичне сподівання інновації строго дорівнює нулю:

```
E[y[k]] = 0
```

Знайдемо матрицю коваріації інновації `S[k] = E[ y[k] · y[k]ᵀ ]`. Розпишемо добуток векторів:

```
S[k] = E[ (H · e⁻[k] + v[k]) · (H · e⁻[k] + v[k])ᵀ ]
     = E[ (H · e⁻[k] + v[k]) · ((e⁻[k])ᵀ · Hᵀ + v[k]ᵀ) ]
     = E[ H · e⁻[k] · (e⁻[k])ᵀ · Hᵀ  +  H · e⁻[k] · v[k]ᵀ  +  v[k] · (e⁻[k])ᵀ · Hᵀ  +  v[k] · v[k]ᵀ ]
```

Апріорна похибка `e⁻[k]` формується шумами попередніх кроків `w[0..k−1]` та `v[0..k−1]`. Оскільки шум вимірювача `v[k]` є білим, він статистично не залежить від подій минулого. Тому перехресні сподівання перетворюються на нуль:

```
E[ H · e⁻[k] · v[k]ᵀ ] = H · E[e⁻[k]] · E[v[k]ᵀ] = 0
E[ v[k] · (e⁻[k])ᵀ · Hᵀ ] = E[v[k]] · E[(e⁻[k])ᵀ] · Hᵀ = 0
```

Залишаються тільки два автоковаріаційні доданки:

```
S[k] = H · E[ e⁻[k] · (e⁻[k])ᵀ ] · Hᵀ + E[ v[k] · v[k]ᵀ ]
     = H · P⁻[k] · Hᵀ + R
```

Геометричний зміст `S[k]`: це повна невизначеність нового виміру. Вона складається з власної дисперсії шуму давача `R` та дисперсії моделі `P⁻[k]`, переведеної матрицею спостереження `H` у систему координат сенсора.

## 3. Доведення часової некорельованості (ортогональності) інновацій

Доведемо, що для будь-яких двох різних моментів часу `k` та `j` (нехай без обмеження загальності `k > j`) взаємна коваріація інновацій тотожно дорівнює нулю:

```
E[ y[k] · y[j]ᵀ ] = 0,    ∀ k ≠ j
```

Запишемо інновацію на кроці `k`:

```
y[k] = H · e⁻[k] + v[k]
```

Згадаємо рівняння корекції стану на кроці `j`:

```
x̂[j] = x̂⁻[j] + K[j] · y[j]
```

Відповідно, апостеріорна похибка оцінки на кроці `j`:

```
e[j] = x[j] − x̂[j]
     = x[j] − (x̂⁻[j] + K[j] · y[j])
     = e⁻[j] − K[j] · (H · e⁻[j] + v[j])
     = (I − K[j] · H) · e⁻[j] − K[j] · v[j]
```

де `I` — одинична матриця розмірності `n × n`.

Знайдемо взаємну кореляцію між апостеріорною похибкою `e[j]` та інновацією `y[j]` на тому самому кроці `j`:

```
E[ e[j] · y[j]ᵀ ] = E[ ((I − K[j] · H) · e⁻[j] − K[j] · v[j]) · (H · e⁻[j] + v[j])ᵀ ]
                  = (I − K[j] · H) · E[ e⁻[j] · (e⁻[j])ᵀ ] · Hᵀ − K[j] · E[ v[j] · v[j]ᵀ ]
                  = (I − K[j] · H) · P⁻[j] · Hᵀ − K[j] · R
                  = P⁻[j] · Hᵀ − K[j] · H · P⁻[j] · Hᵀ − K[j] · R
                  = P⁻[j] · Hᵀ − K[j] · (H · P⁻[j] · Hᵀ + R)
```

Згадаємо формулу для розрахунку оптимального підсилення Калмана `K[j]`:

```
K[j] = P⁻[j] · Hᵀ · (H · P⁻[j] · Hᵀ + R)⁻¹ = P⁻[j] · Hᵀ · S[j]⁻¹
```

Підставимо вираз для `K[j]` у попереднє рівняння:

```
E[ e[j] · y[j]ᵀ ] = P⁻[j] · Hᵀ − (P⁻[j] · Hᵀ · S[j]⁻¹) · S[j]
                  = P⁻[j] · Hᵀ − P⁻[j] · Hᵀ
                  = 0
```

Ця рівність виражає **принцип геометричної ортогональності**: оптимальна оцінка Калмана обирається так, що похибка оцінки після корекції ортогональна до поточної нев'язки (тобто нев'язка більше не містить інформації про помилку оцінки).

Тепер розглянемо наступний крок часу `k = j + 1`. Апріорна похибка екстраполюється матрицею системи:

```
e⁻[j+1] = x[j+1] − x̂⁻[j+1]
        = (F · x[j] + w[j]) − F · x̂[j]
        = F · e[j] + w[j]
```

Інновація на кроці `j+1`:

```
y[j+1] = H · e⁻[j+1] + v[j+1]
       = H · F · e[j] + H · w[j] + v[j+1]
```

Обчислимо взаємну коваріацію `E[ y[j+1] · y[j]ᵀ ]`:

```
E[ y[j+1] · y[j]ᵀ ] = E[ (H · F · e[j] + H · w[j] + v[j+1]) · y[j]ᵀ ]
                    = H · F · E[ e[j] · y[j]ᵀ ] + H · E[ w[j] · y[j]ᵀ ] + E[ v[j+1] · y[j]ᵀ ]
```

Оцінимо всі три доданки:
1. `E[ e[j] · y[j]ᵀ ] = 0` (щойно доведено вище завдяки оптимальності `K[j]`).
2. `E[ w[j] · y[j]ᵀ ] = 0` (шум процесу `w[j]` виникає після моменту `j` і не корелює з минулим).
3. `E[ v[j+1] · y[j]ᵀ ] = 0` (шум вимірювання `v[j+1]` виникає на кроці `j+1` і не залежить від вимірів на кроці `j`).

Отже:

```
E[ y[j+1] · y[j]ᵀ ] = 0
```

Застосовуючи математичну індукцію за кроками часу `k = j + 2, j + 3, ...`, оскільки `e⁻[k] = Fᵏ⁻ʲ · e[j] + ∑ Fⁱ w`, переконуємося:

```
E[ y[k] · y[j]ᵀ ] = 0,    ∀ k > j
```

Це строго доводить теорему: **інноваційна послідовність оптимального фільтра Калмана є білим шумом**. Жодної кореляції між залишками в різні моменти часу не існує. Якщо емпірична автокореляція виявляє статистично значущі ненульові значення на лагах `m ≥ 1`, фільтр не є оптимальним (невірна матриця `F`, занижена розмірність вектора стану або кольоровий шум на вході).

## 4. Статистичні критерії узгодженості: NIS та NEES

Для практичної перевірки гіпотези про коректність налаштування фільтра використовують нормалізовані квадратичні форми, зважені на обернені матриці коваріацій.

### 4.1. Нормований квадрат інновації (NIS — Normalized Innovation Squared)

Для вектора вимірів розмірності `m`:

```
ε_y[k] = y[k]ᵀ · S[k]⁻¹ · y[k]
```

Оскільки вектор інновацій має багатовимірний нормальний розподіл `y[k] ~ N(0, S[k])`, квадратична форма `ε_y[k]` є сумою квадратів `m` незалежних стандартних нормальних величин. Відповідно, вона має розподіл хі-квадрат із `m` ступенями вільності:

```
ε_y[k] ~ χ²(m)
```

Теоретичні числові характеристики розподілу:

```
E[ε_y[k]] = m
Var(ε_y[k]) = 2 · m
```

Якщо усереднити значення NIS за вікном вибірки довжиною `N` кроків:

```
ε̄_y = (1 / N) · ∑_{k=1}^N ε_y[k]
```

Сума `N` незалежних величин `χ²(m)` розподілена як `χ²(N · m)`. Відповідно, середня величина `ε̄_y` повинна потрапляти у двосторонній 95% довірчий інтервал:

```
r_low  = χ²_{0.025}(N · m) / N
r_high = χ²_{0.975}(N · m) / N
```

- Якщо `ε̄_y > r_high`: інновації систематично перевищують очікуваний розмір `S[k]`. Фільтр є надмірно самовпевненим (занижені шуми `Q` або `R`).
- Якщо `ε̄_y < r_low`: реальні нев'язки значно менші за `S[k]`. Фільтр є надмірно повільним і боязким (завищені шуми `Q` або `R`).

### 4.2. Нормований квадрат похибки стану (NEES — Normalized Estimation Error Squared)

Якщо під час випробувань відома наземна істина `x_true[k]`, можна обчислити реальну похибку оцінки стану `e[k] = x_true[k] − x̂[k]` для вектора стану розмірності `n`:

```
ε_x[k] = e[k]ᵀ · P[k]⁻¹ · e[k]
```

Якщо фільтр узгоджений і матриця `P[k]` точно відображає розсіювання помилок оцінки (`e[k] ~ N(0, P[k])`), то:

```
ε_x[k] ~ χ²(n)
E[ε_x[k]] = n
```

Для середнього за вибіркою з `N` кроків `ε̄_x = (1 / N) · ∑_{k=1}^N ε_x[k]` межі 95% довірчого інтервалу визначаються квантилями хі-квадрат:

```
r_1 = χ²_{0.025}(N · n) / N
r_2 = χ²_{0.975}(N · n) / N
```

Збіг емпіричного значення `ε̄_x` із теоретичним діапазоном `[r_1, r_2]` є неспростовним математичним доказом того, що фільтр працює оптимально, а внутрішній розрахунок непевності `P` точно відповідає реальним фізичним відхиленням апарата в просторі.
