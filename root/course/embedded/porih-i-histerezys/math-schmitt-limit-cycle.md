# 🧮 Математична модель гістерезису та граничний цикл реле

Коли аналоговий сигнал керує реле або транзисторним ключем через єдиний поріг, система здатна впасти в автоколивання нескінченної частоти — так званий граничний цикл (*limit cycle*). Математичний апарат нелінійних систем дає змогу точно порахувати, чому це відбувається, як шум сенсора модулює момент перемикання, якою має бути мінімальна ширина зони нечутливості для заданого співвідношення сигнал/шум, і як гістерезис задає період коливань реального об'єкта з урахуванням запізнення.

## 1. Модель системи з однопороговим релейним елементом

Розглянемо класичний тепловий об'єкт першого порядку (наприклад, камеру нагрівача або рідинний резервуар). Його динаміка описується диференціальним рівнянням:

```
τ · (dT/dt) + T(t) = T_env + K_p · u(t)
```

де:
- `T(t)` — поточна температура об'єкта у момент часу `t` (°C);
- `τ` — теплова стала часу системи (секунди);
- `T_env` — температура навколишнього середовища (°C);
- `K_p` — коефіцієнт підсилення нагрівача за потужністю (°C);
- `u(t) ∈ {0, 1}` — стан виконавчого реле (0 — нагрівач вимкнено, 1 — увімкнено).

Вимірювальний тракт містить аналоговий сенсор, сигнал якого спотворюється адитивним шумом `n(t)`:

```
y(t) = T(t) + n(t)
```

Шум `n(t)` вважаємо нормальним білим шумом із нульовим математичним сподіванням `E[n(t)] = 0` та дисперсією `σ²`.

### Релейний закон без гістерезису

Ідеальний однопороговий компаратор із заданою уставкою `T_set` формує керування за статичним правилом:

```
u(t) = 1, якщо y(t) < T_set
u(t) = 0, якщо y(t) ≥ T_set
```

Підставимо зашумлене вимірювання `y(t) = T(t) + n(t)` в умову перемикання:

```
T(t) + n(t) < T_set  ⇔  n(t) < T_set - T(t)
```

Коли температура об'єкта наближається до уставки `|T(t) - T_set| < 3σ`, ймовірність того, що шум перекине компаратор, описується функцією розподілу Гаусса:

```
P(u(t) = 1) = Φ((T_set - T(t)) / σ)
```

У точці `T(t) = T_set` аргумент дорівнює нулю, отже `P(u = 1) = 0.5`. Оскільки значення шуму в сусідні дискретні моменти часу `t_k` та `t_{k+1}` некорельовані, стан виходу `u(t)` стає послідовністю незалежних випадкових перемикань із частотою, обмеженою виключно частотою опитування АЦП `f_s = 1 / Δt`:

```
f_chatter = f_s / 2
```

Для АЦП із частотою опитування 1 кГц це означає 500 спроб комутації реле на секунду, що призводить до негайної теплової деградації контактної групи та пробою керуючого ключа.

## 2. Оператор гістерезису: нелінійність із пам'яттю

Щоб усунути нестійкість, функцію компаратора перетворюють на гістерезисний оператор із внутрішнім станом `S(t) ∈ {0, 1}`. Задамо два розділені пороги:
- `T_low` — нижній поріг увімкнення підігріву;
- `T_high` — верхній поріг вимкнення підігріву;
- `ΔT = T_high - T_low > 0` — ширина зони нечутливості (*deadband*).

Математично стан компаратора в дискретний час визначається кусочно-постійною функцією:

```
S[k] = 1,                 якщо y[k] ≤ T_low
S[k] = 0,                 якщо y[k] ≥ T_high
S[k] = S[k-1],            якщо T_low < y[k] < T_high
```

### Енергетична та фазова інтерпретація петлі

На фазовій площині `(y, S)` гістерезис утворює замкнену прямокутну траєкторію. Площа цієї петлі відповідає енергетичному бар'єру, який збурення має подолати, щоб спричинити перемикання:

```
∮ S dy = (1 - 0) · (T_high - T_low) = ΔT
```

Шум `n(t)` може перемкнути систему зі стану `S=0` у стан `S=1` лише тоді, коли його миттєва амплітуда перевищить повну відстань від поточної температури до нижнього порогу:

```
n(t) < T_low - T(t)
```

Коли система перебуває біля верхнього порогу `T(t) ≈ T_high`, відстань до порогу вимикання дорівнює `T(t) - T_high ≈ 0`, але відстань до порогу вмикання становить:

```
T(t) - T_low ≈ T_high - T_low = ΔT
```

## 3. Виведення мінімальної ширини зони нечутливості ΔT

Знайдемо мінімальне значення `ΔT`, за якого ймовірність помилкового перемикання від шуму падає нижче заданого порогу надійності.

Нехай шум `n(t)` підпорядковується нормальному розподілу `N(0, σ²)`. Ймовірність того, що одиничний випадковий викид перевищить рівень `ΔT`, визначається інтегралом імовірності:

```
P_error = P(n(t) > ΔT) = (1 / (σ · √(2π))) · ∫_{ΔT}^{∞} exp(-x² / (2σ²)) dx
```

Використовуючи додаткову функцію помилок `erfc`:

```
P_error = (1 / 2) · erfc(ΔT / (σ · √2))
```

Для інженерних розрахунків використовують правило сигм:
- `ΔT = 3σ` → `P_error ≈ 1.35 · 10⁻³` (один хибний імпульс на 740 відліків);
- `ΔT = 4σ` → `P_error ≈ 3.17 · 10⁻⁵` (один хибний імпульс на 31 500 відліків);
- `ΔT = 6σ` → `P_error ≈ 9.87 · 10⁻¹⁰` (один хибний імпульс на мільярд відліків).

Оскільки перемикання можливе в обидва боки (розмах шуму від піку до піку `V_noise_pk = 6σ`), мінімальна інженерна умова повної відсутності деренчання записується так:

```
ΔT_min ≥ 2 · (3σ) = 6σ
```

Якщо дисперсія шуму АЦП складає `σ = 0.08 °C`, мінімальна ширина гістерезису повинна становити:

```
ΔT_min = 6 · 0.08 °C = 0.48 °C
```

## 4. Період автоколивань системи з гістерезисом

Коли ширина петлі `ΔT` задовольняє умову стійкості проти шуму, система здійснює плавні циклічні коливання навколо заданої уставки. Розрахуємо тривалість фаз увімкненого та вимкненого нагрівача.

### Фаза нагрівання (u = 1)

Початкова умова: `T(0) = T_low`.
Рівняння динаміки:

```
τ · (dT/dt) + T(t) = T_max
```

де `T_max = T_env + K_p` — гранична температура, яку розвиває нагрівач при тривалій роботі.

Розв'язок диференціального рівняння:

```
T(t) = T_max - (T_max - T_low) · exp(-t / τ)
```

Час нагрівання `t_on` — це момент, коли температура досягає верхнього порогу `T(t_on) = T_high`:

```
T_high = T_max - (T_max - T_low) · exp(-t_on / τ)
(T_max - T_high) / (T_max - T_low) = exp(-t_on / τ)
```

Логарифмуючи обидві частини, дістаємо час увімкненого стану:

```
t_on = τ · ln((T_max - T_low) / (T_max - T_high))
```

### Фаза охолодження (u = 0)

Початкова умова: `T(0) = T_high`.
Рівняння динаміки при вимкненому нагрівачі (`u = 0`):

```
τ · (dT/dt) + T(t) = T_env
```

Розв'язок:

```
T(t) = T_env + (T_high - T_env) · exp(-t / τ)
```

Час охолодження `t_off` — це момент досягнення нижнього порогу `T(t_off) = T_low`:

```
T_low = T_env + (T_high - T_env) · exp(-t_off / τ)
(T_low - T_env) / (T_high - T_env) = exp(-t_off / τ)
```

Час вимкненого стану:

```
t_off = τ · ln((T_high - T_env) / (T_low - T_env))
```

### Повний період і частота комутації

Повний період коливального циклу `T_cycle` становить:

```
T_cycle = t_on + t_off
= τ · [ln((T_max - T_low) / (T_max - T_high)) + ln((T_high - T_env) / (T_low - T_env))]
```

### Лінійне наближення для малої зони гістерезису

Якщо ширина зони нечутливості `ΔT` мала порівняно з повним температурним діапазоном `(T_max - T_set)` та `(T_set - T_env)`, можна скористатися наближенням першого порядку `ln(1 + x) ≈ x`.

Швидкість нагрівання біля уставки `T_set`:

```
v_up = (dT/dt)|_on = (T_max - T_set) / τ
```

Швидкість охолодження біля уставки `T_set`:

```
v_down = -(dT/dt)|_off = (T_set - T_env) / τ
```

Тоді тривалості фаз становлять:

```
t_on ≈ ΔT / v_up = (τ · ΔT) / (T_max - T_set)
t_off ≈ ΔT / v_down = (τ · ΔT) / (T_set - T_env)
```

Повний період комутації у лінійному наближенні:

```
T_cycle ≈ τ · ΔT · (1 / (T_max - T_set) + 1 / (T_set - T_env))
= (τ · ΔT · (T_max - T_env)) / ((T_max - T_set) · (T_set - T_env))
```

Звідси очевидно, що період релейного циклу **прямо пропорційний** ширині гістерезису `ΔT` та сталій часу об'єкта `τ`. Збільшуючи `ΔT`, інженер лінійно знижує частоту спрацьовувань реле.

## 5. Вплив чистого транспортного запізнення τ_d

У реальних установках тепло від нагрівального елемента доходить до термодатчика не миттєво, а з транспортною затримкою `τ_d` (через теплопровідність металу та рух теплоносія). Модель об'єкта з запізненням записується як:

```
τ · (dT/dt) + T(t) = T_env + K_p · u(t - τ_d)
```

За наявності `τ_d > 0` після спрацьовування компаратора на порозі `T_high` нагрівач фізично продовжує віддавати енергію ще впродовж часу `τ_d`. Внаслідок цього виникає динамічний переліт (*overshoot*):

```
ΔT_over = v_up · τ_d = ((T_max - T_high) / τ) · τ_d
```

Аналогічно, при вимкненні на порозі `T_low` охолодження триває за інерцією ще `τ_d`, утворюючи динамічний недоліт (*undershoot*):

```
ΔT_under = v_down · τ_d = ((T_low - T_env) / τ) · τ_d
```

Фактичний розмах температурних коливань об'єкта виявляється ширшим за встановлену статичну петлю `ΔT`:

```
ΔT_real = ΔT + ΔT_over + ΔT_under
= ΔT + τ_d · [((T_max - T_high) / τ) + ((T_low - T_env) / τ)]
```

Цей результат показує, чому не можна зменшувати ширину гістерезису `ΔT` до нуля: навіть при ідеально відфільтрованому шумі наявність затримки `τ_d` породжує неминучі автоколивання амплітудою `(v_up + v_down) · τ_d`.

## 6. Числовий приклад розрахунку бойлера

**Умова:**
- Об'єм бака: 50 літрів, потужність ТЕНа 2.0 кВт.
- Теплова стала часу бака `τ = 7200 с` (2 години).
- Температура довкілля `T_env = 20.0 °C`.
- Максимальна рівноважна температура `T_max = 95.0 °C`.
- Бажана температура `T_set = 60.0 °C`.
- Транспортне запізнення термогільзи `τ_d = 15 с`.
- Шум АЦП з дільником `σ = 0.12 °C`.

**Розрахунок:**

1. Мінімальний гістерезис за критерієм 6-сигма:
```
ΔT_noise = 6 · 0.12 °C = 0.72 °C  →  обираємо симетричну зону ΔT = 2.0 °C
T_low = 59.0 °C, T_high = 61.0 °C
```

2. Швидкість нагрівання біля 60 °C:
```
v_up = (95.0 - 60.0) / 7200 ≈ 0.00486 °C/с  (≈ 0.29 °C/хв)
```

3. Швидкість охолодження біля 60 °C:
```
v_down = (60.0 - 20.0) / 7200 ≈ 0.00556 °C/с  (≈ 0.33 °C/хв)
```

4. Тривалість робочого циклу:
```
t_on = ΔT / v_up = 2.0 / 0.00486 ≈ 411.5 с  (≈ 6.86 хв)
t_off = ΔT / v_down = 2.0 / 0.00556 ≈ 360.0 с  (≈ 6.00 хв)
T_cycle = t_on + t_off ≈ 771.5 с  (≈ 12.86 хв)
```

5. Динамічний переліт від запізнення датчика:
```
ΔT_over = 0.00486 °C/с · 15 с ≈ 0.073 °C
ΔT_under = 0.00556 °C/с · 15 с ≈ 0.083 °C
ΔT_real = 2.0 + 0.073 + 0.083 = 2.156 °C
```

6. Кількість перемикань реле на добу:
```
N_switches = (86400 с / 771.5 с) · 2 ≈ 224 перемикання/добу
```

Без гістерезису (`ΔT = 0`) за рахунок шуму `σ = 0.12 °C` та затримки `τ_d = 15 с` реле здійснювало б тисячі комутацій на добу, що вичерпало б ресурс механічних контактів (типово 100 000 циклів) за кілька місяців. Гістерезис `2.0 °C` збільшує термін служби реле до понад 5–10 років щоденної експлуатації.
