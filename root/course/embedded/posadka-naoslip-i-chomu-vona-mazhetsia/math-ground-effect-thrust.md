# 🧮 Аеродинаміка екранного ефекту та розрахунок барометричного підпору

Коли пропелер або несучий гвинт наближається до твердої поверхні на відстань менше ніж один гідравлічний діаметр (`z < D = 2·R`), аеродинамічна картина обтікання кардинально змінюється. У вільному повітрі (англ. *Out of Ground Effect, OGE*) спадний індукований потік вільно розсіюється в просторі, утворюючи звужений конічний струмінь. Біля поверхні (англ. *In Ground Effect, IGE*) твердий екран блокує вертикальне розтікання струменя: потік гальмується, тиск під ротором зростає, а кінцеві вихори лопатей частково розмиваються, що зменшує індукований опір і підвищує тягу.

Розуміння цієї математики дає точні межі: на якій висоті вмикається екранний ефект, на скільки відсотків зростає підіймальна сила, як змінюється динамічна жорсткість повітряної подушки та який надлишковий динамічний тиск потрапляє на вхідний порт [барометра-альтиметра](root:embedded/barometric-altimeter).

## 1. Теоретична модель Чізмена-Беннета (Метод дзеркальних відображень)

Класичний розрахунок збільшення тяги несучого гвинта біля землі базується на теорії імпульсу та методі гідродинамічних дзеркальних відображень Чізмена і Беннета (англ. *Cheeseman & Bennett, 1955*). Тверда площина землі моделюється фіктивним «дзеркальним» гвинтом, розташованим під поверхнею на такій самій глибині `z`, що створює зустрічний потік угору.

Співвідношення тяги в екранному ефекті `T_IGE` до тяги у вільному просторі `T_OGE` за однакової споживаної потужності на валу описується рівнянням:

```
T_IGE / T_OGE = 1 / (1 - (R / (4 · z))²)      [за умови z ≥ 0.5·R]
```

де:
- `T_IGE` — аеродинамічна тяга біля поверхні (Н);
- `T_OGE` — аеродинамічна тяга у вільному повітрі (Н);
- `R` — радіус пропелера (м);
- `z` — відстань від площини обертання гвинта до твердої поверхні (м).

Розглянемо поведінку цієї функції на двох характерних висотах спуску.

Коли дрон опускається до висоти `z = R` (відстань до землі дорівнює радіусу гвинта, тобто половині діаметра):

```
T_IGE / T_OGE
= 1 / (1 - (R / (4 · R))²)      [підстановка z = R]
= 1 / (1 - (1/4)²)             [скорочення R]
= 1 / (1 - 1/16)               [піднесення до квадрата]
= 1 / (15/16)                  [віднімання знаменника]
= 16 / 15 ≈ 1.0667             [приріст тяги +6.7%]
```

Коли висота падає до `z = 0.5 · R` (відстань до землі чверть діаметра пропелера):

```
T_IGE / T_OGE
= 1 / (1 - (R / (4 · 0.5 · R))²) [підстановка z = 0.5·R]
= 1 / (1 - (1/2)²)               [скорочення R]
= 1 / (1 - 1/4)                  [піднесення до квадрата]
= 4 / 3 ≈ 1.3333                 [приріст тяги +33.3%]
```

Приріст тяги на 33.3% означає, що якби польотний контролер залишив вихідну шпаруватість ШІМ на регуляторах швидкості без змін, апарат замість рівномірного спуску отримав би значне надлишкове вертикальне прискорення вгору:

```
a_z = (T_IGE - m·g) / m = (1.333·m·g - m·g) / m = 0.333 · g ≈ +3.27 м/с²
```

## 2. Емпірична поліноміальна модель Гайдена для мультикоптерів

Для малорозмірних мультикоптерів із жорсткими пропелерами та великою швидкістю обертання (понад 5000–9000 об/хв) відхилення від ідеальної теорії дзеркальних джерел враховує емпірична формула Гайдена (англ. *Hayden Ground Effect Model*):

```
T_IGE / T_OGE = 1 / ( 0.9926 + 0.0379 · (2 · R / z)¹·²³ )
```

На відміну від моделі Чізмена-Беннета, яка має математичну сингулярність при `z → 0.25·R`, формула Гайдена зберігає чисельну стійкість аж до моменту фізичного торкання шасі поверхні.

### Динамічна жорсткість аеродинамічної подушки

Зміна тяги зі зміною висоти означає, що екранний ефект діє як нелінійна газова пружина. Візьмемо частинну похідну тяги за висотою `∂T/∂z`:

```
∂T_IGE / ∂z = T_OGE · ( - 1 / (1 - (R/(4·z))²)² ) · ( 2 · (R/(4·z)) · (R / (4·z²)) )
            = - T_OGE · ( R² / (8 · z³) ) / ( 1 - (R / (4·z))² )²
```

Знак «мінус» підтверджує: при зменшенні висоти (`dz < 0`) тяга зростає (`dT > 0`).

Еквівалентна жорсткість аеродинамічної пружини `k_aero = - ∂T/∂z` формує власну коливальну частоту вертикального руху апарата над землею:

```
ω_ground = √( k_aero / m )
```

Якщо швидкість оновлення контуру висоти або смуга пропускання регулятора вертикальної швидкості менша за `ω_ground`, автопілот потрапляє в параметричний резонанс, викликаючи незатухаючі вертикальні автоколивання біля поверхні.

## 3. Розрахунок аеродинамічного підпору тиску на барометрі

Середня швидкість спадного індукованого потоку під диском ротора у вільному повітрі `v_ind` визначається з класичної теореми збереження імпульсу:

```
v_ind = √( T_OGE / (2 · ρ_air · A_disk) )
```

де:
- `A_disk = π · R²` — площа, що омивається пропелером (м²);
- `ρ_air` — густина повітря (при `T = 20 °C` та атмосферному тиску `P = 101325 Па`, `ρ_air ≈ 1.204 кг/м³`).

Швидкість струменя на деякому віддаленні під диском подвоюється за рахунок звуження потоку: `v_downwash ≈ 2 · v_ind`.

Коли цей потік вдаряється об нерухому поверхню під кутом 90°, він гальмується в точці застою (англ. *stagnation point*). За законом Бернуллі вся кінетична енергія спрямованого руху газу переходить у статичний надлишковий тиск гальмування `ΔP_stag`:

```
ΔP_stag = ½ · ρ_air · (v_downwash)² = ½ · ρ_air · (2 · v_ind)² = 2 · ρ_air · v_ind²
```

Підставляючи вираз для квадрата індукованої швидкості `v_ind²`:

```
ΔP_stag = 2 · ρ_air · ( T_OGE / (2 · ρ_air · π · R²) ) = T_OGE / (π · R²)
```

Це фундаментальний висновок: максимальний можливий підпір у центрі плями відбиття під пропелером дорівнює **питомому навантаженню на диск** (англ. *Disk Loading, DL = T / A*).

Частина відбитого струменя закручується у вихори рециркуляції й піднімається до нижньої площини польотного контролера. Тиск на сенсорі пов'язаний із піковим підпором через геометричний коефіцієнт рециркуляції рами `k_geom`:

```
ΔP_sensor = k_geom · ΔP_stag
```

Для типових відкритих карбонових хрестовин `k_geom = 0.15–0.30`. Для апаратів із закритим обтічним фюзеляжем або широким монококом підпір може сягати `k_geom = 0.40–0.60`.

### Зв'язок аеродинамічного підпору з помилкою висоти EKF

У [барометричному альтиметрі](root:embedded/barometric-altimeter) висота обчислюється через диференціал гідростатичного тиску:

```
dP / dz = - ρ_air · g
```

Звідси похибка визначення висоти `Δh_baro` через помилковий надлишковий тиск `ΔP_sensor`:

```
Δh_baro = - ΔP_sensor / (ρ_air · g)
```

Знак «мінус» означає, що додатний підпір тиску (`ΔP > 0`) перетворюється автопілотом на **від'ємне зміщення висоти** (давач сигналізує, що дрон опустився глибше, ніж є насправді).

## 4. Вплив типу поверхні: поглинання проти відбиття

Аеродинамічний підпір та приріст тяги критично залежать від акустичних та газодинамічних властивостей поверхні приземлення:

1. **Твердий гладкий бетон або асфальт:** ідеальне дзеркальне відбиття (`k_surface ≈ 1.0`). Екранний ефект та барометричний стрибок проявляються з максимальною силою.
2. **Густа висока трава або пухкий сніг:** пористий шар товщиною 15–30 см працює як глушник та розсіювач струменя (`k_surface ≈ 0.35–0.50`). Кінетична енергія спадного потоку витрачається на деформацію стебел, підпір під фюзеляжем падає в 2–3 рази, але ультразвуковий чи ToF-далекомір отримує хаотичні відбиття від верхівок трави, генеруючи хибні показання відстані.
3. **Водна гладінь:** при наближенні важкого дрона на воді утворюється динамічна западина (хвильовий кратер), яка розсіює горизонтальне розтікання потоку, через що коефіцієнт підпору флуктує на частоті збурення хвиль.

## 5. Наскрізний числовий розрахунок для 10-дюймового квадрокоптера

Розглянемо типовий 4-роторний дрон:
- Повна злітна маса: `m = 1.8 кг` (вага `W = m · g = 1.8 · 9.81 = 17.658 Н`).
- Число пропелерів: `N = 4`.
- Тяга одного гвинта у стані висіння: `T_single = 17.658 / 4 = 4.4145 Н`.
- Діаметр пропелера: `D = 10 дюймів = 0.254 м` (радіус `R = 0.127 м`).
- Площа одного диска: `A = π · R² = 3.14159 · (0.127)² ≈ 0.05067 м²`.
- Висота фюзеляжу над землею: `z = 0.15 м` (відстань від кінчиків гвинтів до ґрунту `z/R = 0.15 / 0.127 ≈ 1.18`).

### Крок 1. Розрахунок швидкості потоку та підпору

```
v_ind
= √( 4.4145 / (2 · 1.204 · 0.05067) )  [підстановка T, ρ, A]
= √( 4.4145 / 0.12201 )                [множення знаменника]
= √( 36.181 )                          [ділення]
≈ 6.015 м/с                            [індукована швидкість у диску]

v_downwash = 2 · v_ind ≈ 12.03 м/с     [швидкість струменя перед землею]
```

### Крок 2. Розрахунок пікового підпору

```
ΔP_stag
= T_single / A                         [питоме навантаження на диск]
= 4.4145 / 0.05067
≈ 87.12 Па                             [максимальний підпір струменя]
```

### Крок 3. Розрахунок тиску на корпусі та похибки висоти

За коефіцієнта рециркуляції `k_geom = 0.22` (типова відкрита карбонова хрестовина):

```
ΔP_sensor = 0.22 · 87.12 ≈ 19.17 Па
```

Обчислюємо зміщення барометричної висоти:

```
Δh_baro
= - 19.17 / (1.204 · 9.81)             [підстановка ΔP, ρ, g]
= - 19.17 / 11.811
≈ - 1.623 м                            [помилка визначення висоти]
```

### Крок 4. Розрахунок інновації EKF та брами відсікання

У [розширеному фільтрі Калмана EKF](root:com-signal/kalman-ekf) різниця між виміряною висотою барометра `z_baro` та передбаченою моделлю руху висотою `h_pred` називається інновацією `y = z_baro - h_pred`.

Невпевненість інновації визначається як `S = H · P · Hᵀ + R_baro`, де для барометра `R_baro ≈ 0.25 м²` (середньоквадратичне відхилення `σ = 0.5 м`), а апріорна дисперсія висоти `P_zz ≈ 0.10 м²`:

```
S = 0.10 + 0.25 = 0.35 м²
```

Нормована відстань Махаланобіса:

```
d² = y² / S = (-1.623)² / 0.35 = 2.634 / 0.35 ≈ 7.526
```

Стандартна брама відсікання аномальних вимірювань (*Innovation Gate*) для 1D-виміру за критерієм хі-квадрат `χ²` на рівні довіри 99% становить `γ_gate = 6.635`.

Оскільки `d² = 7.53 > 6.635`, фільтр EKF ідентифікує показ барометра як **аномальний викид** і відкидає вимір. Проте якщо підпір наростає поступово протягом кількох тактів, EKF сприймає це як справжнє прискорення вниз, спотворюючи оцінку вертикальної швидкості `V_z` якраз у момент контакту з ґрунтом.
