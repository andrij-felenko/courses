# 🧮 Чому −6 dB — це вдвічі ближче: від оберненого квадрата до дальності

У тексті прозвучало правило «кожні −6 dB втрат — приблизно вдвічі менша дальність». Воно виглядає як магія, але виводиться з двох простих фактів за пару рядків: як спадає потужність із відстанню і що таке децибел. Розберімо від першопричини, бо саме на цьому правилі тримається вся прикидка бюджету радіолінії.

## Потужність розпливається по сфері: закон 1/d²

Уяви передавач як точкове джерело у відкритому просторі. Випущена потужність розходиться навсібіч і розмазується по поверхні уявної сфери, що дедалі більшає. Площа сфери — 4πd². Що далі, то по більшій площі розмазана та сама енергія, тож **густина потоку** (потужність на одиницю площі, яку й ловить приймальна антена) падає як один поділити на площу:

```
S(d) = P_пер / (4π·d²)   ∝  1 / d²
```

Це **закон оберненого квадрата** — той самий, що для яскравості лампи чи сили тяжіння; причина спільна: будь-що, що розходиться по сфері, не зникаючи дорогою, рідшає як 1/d². Звідси відразу видно ціну відстані: подвоїв d — площа вчетверо більша — потужності на приймачі **вчетверо менше**.

```
d → 2d   ⇒   S → S/4     (−6 dB, побачимо нижче)
d → 10d  ⇒   S → S/100   (−20 dB)
```

> 🔧 **Навіщо це.** Це пояснює, чому останні метри дальності даються найдорожче. Дотягтися з 10 до 20 м коштує тих самих −6 dB, що й з 100 до 200 м, — але коли запас лінії вже на нулі, цих −6 dB просто нема звідки взяти, і зв'язок обривається стрибком, а не плавно.

## Децибел: множення стає додаванням

[Децибел](topic:com-medium/power-decibels) міряє **відношення** двох потужностей логарифмом:

```
L(dB) = 10 · log₁₀ ( P / P₀ )
```

Логарифм перетворює множення на додавання — тому в децибелах втрати зручно складати. Підставмо два показові відношення:

```
удвічі менша потужність:   10·log₁₀(1/2)   = 10·(−0.301)  = −3.0 dB
учетверо менша:            10·log₁₀(1/4)   = 10·(−0.602)  = −6.0 dB
у сто разів менша:         10·log₁₀(1/100) = 10·(−2)      = −20 dB
```

Ось і місток: «вчетверо менше потужності» = «−6 dB». А вчетверо менше потужності, за законом 1/d², настає рівно тоді, коли відстань **подвоїлася**. Складаємо обидві ланки.

## Збираємо правило: −6 dB ⇄ ×½ дальності

Потужність ∝ 1/d², тож відношення потужностей на двох відстанях — це обернений квадрат відношення відстаней:

```
P₂ / P₁ = (d₁ / d₂)²
```

Переведемо в децибели:

```
L = 10·log₁₀ (P₂/P₁) = 10·log₁₀ (d₁/d₂)² = 20·log₁₀ (d₁/d₂)
```

(квадрат усередині логарифма виносить множник 2 — тому для **дальності** працює коефіцієнт **20**, а не 10, як для потужності). Тепер підставмо подвоєння відстані, d₂ = 2·d₁:

```
L = 20·log₁₀ (1/2) = 20·(−0.301) ≈ −6.0 dB
```

Готово: **подвоїти відстань коштує −6 dB**. Розвернувши, дістаємо правило прикидки, яким користуються в тексті: **кожні −6 dB втрат означають приблизно вдвічі коротшу дальність**. А оскільки децибели додаються, кратні −6 dB множать скорочення:

```
−6 dB   → ×1/2  дальності
−12 dB  → ×1/4
−18 dB  → ×1/8
−24 dB  → ×1/16
```

Звідси й число з прикладу: −12 dB від металевого корпусу — це два кроки по −6 dB, тобто ×¼ дальності; 40 м перетворюються на ~10 м.

## Той самий розрахунок як бюджет лінії

Зручність децибелів у тому, що всі виграші й втрати на шляху сигналу просто **додаються** одним стовпчиком — це й називають **бюджетом лінії** (*link budget*). Потужність передавача, підсилення обох антен, втрати у вільному просторі, втрати в кабелі й роз'ємах — усе в dBm чи dB, підсумок порівнюємо з чутливістю приймача. Доти, доки підсумок вищий за поріг чутливості, лінія працює; різниця між ними — **запас** (*link margin*), той самий, що зникає, коли антена в металі втрачає свої −12 dB.

Порахуймо для нашого датчика на ESP32. Передавач дає +20 dBm, обидві антени по +2 dBi, приймач шлюзу чує до −90 dBm. Втрати вільного простору на 2.4 ГГц рахують за стандартною формулою (вона і є децибельний запис закону 1/d² разом із частотним членом):

```
FSPL(dB) = 20·log₁₀(d) + 20·log₁₀(f) + 32.44     (d у км, f у МГц)
         = 20·log₁₀(0.04) + 20·log₁₀(2450) + 32.44   (40 м = 0.04 км)
         = (−27.96) + (67.78) + 32.44
         ≈ 72 dB
```

Зводимо стовпчик:

```
+20 dBm   передавач
 +2 dB    антена передавача
 +2 dB    антена приймача
−72 dB    втрати у вільному просторі (40 м)
───────
=  −48 dBm  на вході приймача
```

Прийняте −48 dBm проти порога −90 dBm дає **запас 42 dB** — лінія працює з величезним резервом. Тепер ховаємо пристрій у метал, не виносячи антени: мінус ті самі −12 dB. Запас падає до 30 dB — ще працює, але кожен наступний десяток метрів, стіна чи поворот тіла з'їдають його далі, і там, де відкритий модуль мав 42 dB на 40 м, закритий уже шкребе по дну.

> 🔧 **Навіщо це.** Бюджет лінії — це аркуш на п'ять рядків, який рахують **до** розведення плати. Він одразу каже, скільки в тебе резерву й чи витримає лінія «здешевлення» на кшталт металевого корпусу або дешевого кабелю. Дешевше відняти −12 dB на папері, ніж побудувати прилад і виявити, що зв'язок рветься за рогом.

## Інший важіль: підсилення антени проти втрат

Дальність визначає не лише спад 1/d². У бюджеті є й протилежний знак — [підсилення антени](topic:com-medium/antenna-gain) (*gain*, у dBi). Воно не додає енергії з нічого: антена просто **перерозподіляє** ту саму потужність, звужуючи її в певний бік, як рефлектор у ліхтарика збирає те саме світло в пляму. Тому виграш в одному напрямку оплачено програшем в інших. Але якщо передавач і приймач дивляться один на одного, ці dBi додаються до бюджету так само, як втрати віднімаються.

І ось чому це важить разом із правилом «−6 dB на подвоєння»: підсилення теж конвертується в дальність через ту саму арифметику. Зовнішня спрямована антена з виграшем +6 dBi на кожному кінці лінії дає сумарні +12 dB — рівно два кроки по +6 dB, тобто **вчетверо більшу** дальність на тій самій потужності. Та сама шкала, що карає за метал у корпусі, винагороджує за кращу антену:

```
+6 dB   → ×2  дальності
+12 dB  → ×4
−6 dB   → ×1/2
```

Звідси практичний висновок про U.FL і зовнішні антени: винести антену з металу — це не лише прибрати −12 dB поглинання, а ще й отримати змогу поставити спрямований штир із власним підсиленням. Дві дії складаються в децибелах і множаться в дальності.

## Де це правило ламається

Воно точне **лише у вільному просторі** — порожнеча, нічого не поглинає, не відбиває, не загороджує. Реальність м'якша й жорсткіша водночас:

- **У приміщенні** стіни поглинають, тож із відстанню сигнал падає **швидше** за квадрат — показник буває 3–4 замість 2; правило «−6 dB на подвоєння» стає оптимістичним.
- **Багатопроменевість**: хвиля приходить кількома шляхами (прямо й відбита), вони складаються то в плюс, то в мінус — і поряд із гладким спадом з'являються локальні провали й піки, яких формула 1/d² не знає.
- **Поглинання у середовищі** (волога, листя, людські тіла) додає втрат, що залежать уже не від геометрії, а від матеріалу.

Чому ж тоді ним користуються? Бо радіолінію однаково проєктують **із запасом**. Точне число дальності в захаращеному приміщенні не передбачить жодна формула на аркуші — там надто багато випадкового. Зате правило «−6 dB на подвоєння» миттєво дає **порядок величини**: чи в нас десятки метрів запасу, чи одиниці. А далі рятує сам децибельний бюджет — закладений резерв у 10–20 dB поглинає і похибку самого правила, і непередбачені стіни. Інженеру рідко треба знати, що дальність саме 37 м; йому треба знати, що її **вистачить із запасом** або що її **критично мало** — і на це питання прикидка відповідає чесно.

Тому −6 dB ⇄ ×½ — це **інструмент швидкої оцінки порядку величини**, а не точний розрахунок: він чесно каже, у скільки разів приблизно зміниться дальність, і саме для прикидок «вистачить — не вистачить» його й беруть.
