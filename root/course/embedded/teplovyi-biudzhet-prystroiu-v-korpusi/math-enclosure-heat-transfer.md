# 🧮 Теплове моделювання замкненого об'єму: конвекційні числа та радіаційний баланс

Розрахунок теплового стану пристрою в герметичному корпусі спирається на нелінійний зв'язок між температурою поверхонь і тепловіддачею. На відміну від простої кондукції в твердому тілі, де тепловий опір є фіксованим числом `R = L / (k · A)`, коефіцієнти природної конвекції та випромінювання змінюються разом із нагріванням поверхонь. Тут виведено точні рівняння зовнішнього та внутрішнього теплообміну, обчислено безрозмірні критерії подібності та наведено покроковий інженерний приклад числового розрахунку.

## 1. Фізичні критерії природної конвекції повітря

Природна (вільна) конвекція виникає під дією гравітаційної сили Архімеда, коли повітря біля нагрітої поверхні розширюється, його густина зменшується, і легші шари спливають угору, заміщуючись холодним повітрям довкілля.

Інтенсивність цього процесу визначається трьома безрозмірними числами:

### Число Грасгофа (Grashof, Gr)
Критерій, що показує співвідношення між підйомною силою плавучості та силами в'язкого тертя в газі:

```
Gr = (g · β · ΔT · L³) / ν²

g   — прискорення вільного падіння (9.81 м/с²)
β   — коефіцієнт об'ємного термічного розширення повітря (1 / T_сер, де T_сер у Кельвінах; для 300 K: β ≈ 0.00333 1/K)
ΔT  — різниця температур між поверхнею стінки та довкіллям: |T_s − T_amb| (K або °C)
L   — характерний геометричний розмір поверхні (м): висота для вертикальної стінки, або A / P_периметр для горизонтальної
ν   — кінематична в'язкість повітря (при 40 °C: ν ≈ 1.70 × 10⁻⁵ м²/с)
```

### Число Прандтля (Prandtl, Pr)
Співвідношення між швидкістю розсіювання імпульсу у флюїді (в'язкістю) та швидкістю молекулярного перенесення тепла (теплопровідністю). Для сухого повітря в діапазоні температур від −20 °C до +100 °C число Прандтля майже стале:

```
Pr = ν / α = (μ · c_p) / k_air ≈ 0.71
```

### Число Релея (Rayleigh, Ra)
Головний безрозмірний параметр вільної конвекції, що визначає динамічний режим течії (ламінарний чи турбулентний):

```
Ra = Gr · Pr = (g · β · ΔT · L³ · Pr) / ν²
```

Для типових компактних електронних корпусів (висота `L = 0.05..0.2` м, перегрів `ΔT = 10..40` °C) число Релея лежить у межах `10⁴ < Ra < 10⁷`. Це відповідає стійкому ламінарному пристінному межовому шару (турбулентний перехід настає лише при `Ra > 10⁹`).

### Число Нуссельта (Nusselt, Nu) та коефіцієнт тепловіддачі h_conv
Число Нуссельта показує, у скільки разів конвективний теплообмін ефективніший за чисту теплопровідність нерухомого шару повітря тієї самої товщини:

```
Nu = h_conv · L / k_air  =>  h_conv = Nu · k_air / L
```

Емпіричні критеріальні рівняння Черчилля-Чу (Churchill-Chu) для ламінарної природної конвекції дають усереднене число Нуссельта:

1. **Для вертикальних зовнішніх стінок корпусу** (`Ra < 10⁹`):

```
Nu_vert = 0.68 + (0.670 · Ra^(1/4)) / (1 + (0.492 / Pr)^(9/16))^(4/9)
```

Спрощена інженерна апроксимація для повітря при кімнатній температурі:

```
h_conv_vert ≈ 1.42 · (ΔT / L)^(1/4)   [Вт/(м²·К)]
```

2. **Для горизонтальної верхньої кришки (гаряча поверхня спрямована вгору)**:

```
Nu_top = 0.54 · Ra^(1/4)   (при 10⁴ ≤ Ra ≤ 10⁷)
h_conv_top ≈ 1.32 · (ΔT / L_char)^(1/4)   [Вт/(м²·К)]
де L_char = A_кришки / P_периметр
```

3. **Для горизонтального дна (гаряча поверхня спрямована вниз)**:
Спливання повітря заблоковане самою стінкою, тому тепловіддача падає вдвічі:

```
Nu_bottom = 0.27 · Ra^(1/4)
h_conv_bottom ≈ 0.59 · (ΔT / L_char)^(1/4)   [Вт/(м²·К)]
```

## 2. Конвекція всередині герметичного корпусу: блокування об'єму

Усередині закритого корпусу рух повітря обмежений геометрією. Між платою та стінкою утворюється вузький зазор товщиною `d`.

Поведінка повітряного прошарку залежить від критичного числа Релея, розрахованого за зазором `d`:

```
Ra_d = (g · β · (T_плата − T_стінка) · d³) / (ν · α)
```

- Якщо `Ra_d < 1708` (для зазорів `d < 10..15` мм при помірному перегріві): конвективні вихори Бенара взагалі не виникають. В'язкі сили переважають підйомну силу, і повітря перебуває в стані **механічного спокою**.
- У цьому режимі `Nu_in = 1.0`, тобто тепло переноситься виключно кондукцією повітря:

```
h_in_cond = k_air / d = 0.026 / 0.010 = 2.6 Вт/(м²·К)
```

Опір такого повітряного зазору площею `A = 0.01` м² (100 см²):

```
R_th_air_gap = d / (k_air · A) = 0.01 / (0.026 · 0.01) = 38.5 °C/Вт
```

Це доводить, що застійне внутрішнє повітря є фактично термоізолятором. Передати крізь нього навіть 3 Вт тепла призведе до внутрішнього температурного перепаду `ΔT = 3 · 38.5 = 115.5` °C, що гарантовано перегріє будь-яку електроніку.

## 3. Теплове випромінювання (радіаційний теплообмін)

Теплове випромінювання поверхні в навколишнє середовище описується інтегральним законом Стефана-Больцмана (Stefan-Boltzmann):

```
Q_rad = ε · σ · A · (T_s⁴ − T_amb⁴)

σ  — стала Стефана-Больцмана (5.67037 × 10⁻⁸ Вт/(м²·К⁴))
ε  — коефіцієнт випромінювання (емісійна здатність) поверхні (від 0.0 до 1.0)
A  — площа випромінюючої поверхні (м²)
T  — термодинамічна абсолютна температура в Кельвінах (K = °C + 273.15)
```

### Лінеаризований коефіцієнт радіаційної тепловіддачі h_rad
Для зручного включення в ланцюг теплових опорів різницю четвертих степенів розкладають на множники:

```
T_s⁴ − T_amb⁴ = (T_s² − T_amb²) · (T_s² + T_amb²)
              = (T_s − T_amb) · (T_s + T_amb) · (T_s² + T_amb²)
```

Якщо `(T_s − T_amb) ≪ T_amb`, можна покласти середню температуру `T_m = (T_s + T_amb) / 2`, тоді:

```
T_s⁴ − T_amb⁴ ≈ (T_s − T_amb) · 4 · T_m³

h_rad = 4 · ε · σ · T_m³   [Вт/(м²·К)]
```

Для температури поверхні 50 °C (323.15 K) та довкілля 25 °C (298.15 K), `T_m = 310.65` K:

```
h_rad_ідеальне = 4 · 1.0 · (5.67037 × 10⁻⁸) · (310.65)³ ≈ 6.79 Вт/(м²·К)
```

При реальній емісійній здатності поверхні:
- **Анодований алюміній або матовий пластик** (`ε = 0.90`): `h_rad = 0.90 · 6.79 = 6.11` Вт/(м²·К).
- **Необроблений фрезерований алюміній** (`ε = 0.08`): `h_rad = 0.08 · 6.79 = 0.54` Вт/(м²·К).

Радіаційний коефіцієнт анодованого корпусу (`6.11` Вт/(м²·К)) порівнянний із коефіцієнтом вільної конвекції (`h_conv ≈ 5..7` Вт/(м²·К)). Тобто випромінювання забезпечує рівно половину всього охолодження пристрою.

## 4. Повний інженерний розрахунок теплового балансу

Розглянемо практичний приклад герметичного вуличного блоку телеметрії.

### Вхідні дані
- Геометрія корпусу: довжина `0.12` м, ширина `0.08` м, висота `0.05` м (вертикальне настінне кріплення).
- Повна площа зовнішньої поверхні:
  `A_заг = 2 · (0.12·0.08 + 0.12·0.05 + 0.08·0.05) = 2 · (0.0096 + 0.0060 + 0.0040) = 0.0392` м² (392 см²).
  - Вертикальні стінки: `A_vert = 2 · (0.12 + 0.08) · 0.05 = 0.0200` м².
  - Горизонтальні кришка та дно: `A_horiz = 2 · (0.12 · 0.08) = 0.0192` м².
- Матеріал корпусу: литий алюмінієвий сплав ADC12 (`k = 150` Вт/(м·К)), чорне анодування (`ε = 0.88`).
- Сумарна розсіювана потужність електроніки: `P = 4.0` Вт.
- Головний гарячий компонент: процесорний модуль, що виділяє `P_cpu = 2.5` Вт на площі `20 × 20` мм (`0.0004` м²).
- Внутрішній тепловий міст: силіконова термопрокладка Gap Pad товщиною `d_gap = 1.5` мм з теплопровідністю `k_gap = 3.0` Вт/(м·К).
- Внутрішній опір переходу процесора (junction-to-case): `R_th_jc = 4.5` °C/Вт.
- Температура навколишнього повітря: `T_amb = 40.0` °C (максимальна літня спека).

---

### Крок 1. Розрахунок зовнішнього теплового опору корпусу R_th_ext

Зовнішній теплообмін відбувається через суму конвекції та випромінювання: `h_ext = h_conv + h_rad`.
Оскільки `h_conv` залежить від `ΔT_корпус`, застосуємо ітерацію. Припустимо попередній перегрів корпусу над довкіллям `ΔT_корпус ≈ 12` °C (`T_стінки ≈ 52` °C = 325.15 K).

1. **Конвективна тепловіддача**:
   - Вертикальні стінки (`L = 0.05` м):
     `h_c_vert = 1.42 · (12 / 0.05)^(1/4) = 1.42 · (240)^(1/4) = 1.42 · 3.936 = 5.59` Вт/(м²·К).
   - Горизонтальні поверхні (`L_char = 0.0096 / 0.40 = 0.024` м):
     `h_c_top = 1.32 · (12 / 0.024)^(1/4) = 1.32 · (500)^(1/4) = 1.32 · 4.729 = 6.24` Вт/(м²·К).
     `h_c_bot = 0.59 · (12 / 0.024)^(1/4) = 0.59 · 4.729 = 2.79` Вт/(м²·К).
   - Середньозважений коефіцієнт конвекції:
     `h_conv_сер = (5.59 · 0.0200 + 6.24 · 0.0096 + 2.79 · 0.0096) / 0.0392 = (0.1118 + 0.0599 + 0.0268) / 0.0392 = 5.06` Вт/(м²·К).

2. **Радіаційна тепловіддача**:
   `T_m = (325.15 + 313.15) / 2 = 319.15` K.
   `h_rad = 4 · 0.88 · (5.67037 × 10⁻⁸) · (319.15)³ = 6.48` Вт/(м²·К).

3. **Сумарний зовнішній коефіцієнт і опір**:
   `h_total = h_conv_сер + h_rad = 5.06 + 6.48 = 11.54` Вт/(м²·К).

```
R_th_ext = 1 / (h_total · A_заг)     [означення зовнішнього теплового опору]
         = 1 / (11.54 · 0.0392)      [підстановка h_total = 11.54 та A_заг = 0.0392]
         = 1 / 0.4524                [добуток знаменника]
         = 2.21 °C/Вт                [підсумковий зовнішній опір]
```

Перегрів зовнішньої стінки корпусу при потужності `P = 4.0` Вт:

```
ΔT_корпус = P · R_th_ext = 4.0 · 2.21 = 8.84 °C
T_корпус = T_amb + ΔT_корпус = 40.0 + 8.84 = 48.84 °C
```

---

### Крок 2. Розрахунок теплового опору стінки корпусу R_th_wall

Завдяки високій теплопровідності алюмінію (`k = 150` Вт/(м·К)) та товщині стінки `d_стінки = 3` мм (0.003 м), опір теплопровідності стінки при розподілі тепла площею кришки (`0.0096` м²):

```
R_th_wall = d_стінки / (k_Al · A_кришки)
          = 0.003 / (150 · 0.0096) = 0.003 / 1.44 = 0.0021 °C/Вт
```

Перепад температури в металі стінки становить мізерні `0.008` °C — алюмінієвий корпус є практично ізотермічним.

---

### Крок 3. Розрахунок теплового мосту Gap Pad R_th_gap

Тепло від корпусу процесора площею `A_cpu = 0.0004` м² відводиться через термопрокладку:

```
R_th_gap = d_gap / (k_gap · A_cpu)
         = 0.0015 / (3.0 · 0.0004) = 0.0015 / 0.0012 = 1.25 °C/Вт
```

Контактний опір між чіпом, прокладкою та стінкою при стисканні 25% додає `R_contact ≈ 0.35` °C/Вт:

```
R_th_bridge = R_th_gap + R_th_contact = 1.25 + 0.35 = 1.60 °C/Вт
```

Перепад температури на термопрокладці від потужності процесора `P_cpu = 2.5` Вт:

```
ΔT_bridge = P_cpu · R_th_bridge = 2.5 · 1.60 = 4.0 °C
```

---

### Крок 4. Розрахунок кінцевої температури кристала T_j

Температура кремнієвого переходу процесора складається з базової температури довкілля та суми перепадів на всіх послідовних ланках:

```
T_j = T_amb + (P_заг · R_th_ext) + (P_cpu · R_th_wall) + (P_cpu · R_th_bridge) + (P_cpu · R_th_jc)  [сума температурних перепадів уздовж ланцюга]
    = 40.0 + (4.0 · 2.21) + (2.5 · 0.002) + (2.5 · 1.60) + (2.5 · 4.5)                             [підстановка потужностей та опорів ланок]
    = 40.0 + 8.84 + 0.005 + 4.00 + 11.25                                                            [обчислення локальних перепадів]
    = 64.10 °C                                                                                      [підсумкова температура переходу]
```

### Висновок розрахунку
При максимальній спеці 40.0 °C температура кристала становить лише **64.1 °C**, що забезпечує запас понад 40 °C до типової критичної межі процесора `T_j_max = 105` °C.

Якби той самий пристрій було зібрано у пластиковому корпусі без термомосту (де `R_th_air ≈ 25` °C/Вт та `R_th_plastic ≈ 15` °C/Вт):

```
T_j_пластик = 40.0 + (4.0 · 6.5) + (2.5 · 25.0) + (2.5 · 4.5) = 40.0 + 26.0 + 62.5 + 11.25 = 139.75 °C
```

Кристал нагрівся б до **139.8 °C**, що призвело б до спрацьовування теплового захисту або фізичного виходу мікросхеми з ладу.
