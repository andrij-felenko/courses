# 🧮 Розрахунок втрат у статорній сталі: гістерезис і вихрові струми

У безколекторному моторі джерелом тепла є не лише омічний опір мідного дроту. Навіть коли двигун обертається на холостому ходу без будь-якого механічного навантаження на валу, статор помітно нагрівається. Це тепло виділяється всередині магнітопроводу — пакету тонких пластин електротехнічної сталі, крізь які зі швидкістю десятків тисяч обертів на хвилину проноситься змінне магнітне поле ротора. Ці втрати у сталі (англ. *iron losses* або *core losses*, від лат. *ferrum* — залізо) складаються з двох фундаментальних фізичних процесів: циклічного перемагнічування феромагнетика (гістерезис) та збудження вихрових струмів (струмів Фуко).

## Електрична частота комутації

У типовому безколекторному двигуні дрона ротор містить не одну пару магнітних полюсів, а від 12 до 14 постійних магнітів (конфігурації `12N14P` або `9N12P`, де `P` — кількість полюсів ротора, тобто `p = P/2` пар полюсів). 

Коли ротор здійснює один механічний оберт, магнітне поле в кожному зубці статора встигає пройти стільки повних періодів перемагнічування, скільки пар полюсів має магнітна система. Зв'язок між механічною швидкістю обертання вала `RPM` (англ. *revolutions per minute*) та електричною частотою перемагнічування статора `f_e` (Гц) задається співвідношенням:

```
f_e = (RPM · P) / 120
```

Для популярного FPV-мотора типорозміру 2207 з конфігурацією 14 полюсів (`P = 14`, `p = 7` пар полюсів) при швидкості обертання 25 000 об/хв:

```
f_e
= (25000 · 14) / 120  [підстановка обертів та 14 полюсів]
= 350000 / 120        [добуток механічних обертів і полюсів]
≈ 2916.7 Гц           [електрична частота перемагнічування статора]
```

Це означає, що залізо статора перемагнічується майже три тисячі разів на секунду. На таких частотах динамічні втрати в магнітопроводі стають порівнянними з омічними втратами в мідних обмотках.

## Втрати на гістерезис

Феромагнітна сталь складається з магнітних доменів. Під дією зовнішнього поля обмоток і магнітів домени змінюють орієнтацію свого магнітного моменту. Через наявність дефектів кристалічної ґратки та внутрішніх механічних напружень зміщення меж доменів є непружним процесом: частина енергії поля безповоротно розсіюється у кристалічній ґратці у вигляді тепла.

Енергія, втрачена за один цикл перемагнічування на одиницю об'єму матеріалу, дорівнює площі петлі гістерезису на графіку залежності магнітної індукції `B` від напруженості поля `H`:

```
w_h = ∮ H dB   [Дж/м³ за один цикл]
```

Потужність втрат на гістерезис `P_h` (Вт) у всьому об'ємі або масі статора `m` (кг) за емпіричним рівнянням Штейнмеца (англ. *Steinmetz equation*) залежить від електричної частоти лінійно, а від пікової магнітної індукції `B_m` — у степені `n` (де `n ≈ 1.6–2.0` для електротехнічних кременистих сталей):

```
P_h = k_h · f_e · B_mⁿ · m
```

де:
- `k_h` — коефіцієнт якості сталі за гістерезисом (Дж/(кг·Тлⁿ));
- `f_e` — електрична частота перемагнічування (Гц);
- `B_m` — амплітудне значення магнітної індукції в зубцях статора (Тл, типово 1.2–1.6 Тл);
- `n` — показник Штейнмеца (для ненасиченої сталі `n ≈ 1.6`, при наближенні до насичення `n → 2.0`);
- `m` — маса статорного заліза (кг).

Лінійна залежність `P_h` від `f_e` означає, що подвоєння обертів мотора подвоює втрати на гістерезис.

## Вихрові струми Фуко та ефект товщини пластин

Змінний магнітний потік `Φ(t) = B(t) · A`, що пронизує зубець статора, за законом електромагнітної індукції Фарадея наводить у електропровідному залізі вихрову електрорушійну силу:

```
e_ind = − dΦ / dt
```

Оскільки залізо є провідником з питомим електричним опором `ρ_fe` (для кременистої сталі з вмістом 3% Si питомий опір становить `ρ_fe ≈ 0.45–0.50 · 10⁻⁶ Ом·м`), ця індукована ЕРС породжує замкнені вихрові струми (струми Фуко). Ці струми циркулюють перпендикулярно до ліній магнітного поля і виділяють джоулеве тепло безпосередньо в товщі сталі.

Щоб розрахувати втрати, розглянемо одиничну пластину статора завтовшки `d` (м), завширшки `w` та завдовжки `L`. Нехай змінне поле `B(t) = B_m · sin(2π · f_e · t)` спрямоване вздовж довжини пластини.

У шарі пластини на відстані `x` від центральної площини (`−d/2 ≤ x ≤ d/2`) контур охоплює площу `2x · w`. Магнітний потік крізь цей контур:

```
Φ(x, t) = 2 · x · w · B_m · sin(2π · f_e · t)
```

Амплітуда індукованої ЕРС уздовж контуру довжиною `2w` (нехтуючи короткими торцями `2x` при `w ≫ d`):

```
E_m(x)
= dΦ / dt                                        [закон Фарадея]
= 2 · x · w · 2π · f_e · B_m · cos(2π · f_e · t) [диференціювання синусоїдального потоку]
```

Опір елементарного шару товщиною `dx`:

```
dR = ρ_fe · (2 · w) / (L · dx)
```

Миттєва джоулева потужність у шарі `dx`:

```
dP_e(x)
= E_m²(x) / (2 · dR)                                            [джоулева потужність у шарі]
= [4 · x² · w² · 4π² · f_e² · B_m²] / [4 · ρ_fe · w / (L · dx)] [підстановка ЕРС і опору dR]
= (4π² · f_e² · B_m² · w · L · x² · dx) / ρ_fe                  [скорочення спільних множників]
```

Інтегруючи по всій товщині пластини від `x = −d/2` до `x = +d/2`:

```
P_e_sheet
= (4π² · f_e² · B_m² · w · L / ρ_fe) · ∫[−d/2 .. d/2] x² dx [інтегрування по товщині d]
= (4π² · f_e² · B_m² · w · L / ρ_fe) · (d³ / 12)            [обчислення інтеграла x³ / 3]
= (π² · f_e² · B_m² · d² · V_sheet) / (6 · ρ_fe)            [виділення об'єму V_sheet = w·L·d]
```

де `V_sheet = w · L · d` — об'єм пластини.

Ділячи на масу `m = ρ_mass · V_sheet`, отримуємо класичну питому формулу втрат на вихрові струми у пластинах статора:

```
P_e = (π² · d² · f_e² · B_m² · m) / (6 · ρ_fe · ρ_mass)
```

де:
- `d` — товщина окремої пластини статора (м);
- `ρ_fe` — питомий опір сталі (Ом·м);
- `ρ_mass` — густина сталі (`≈ 7650 кг/м³`);
- `f_e` — електрична частота (Гц);
- `B_m` — амплітуда індукції (Тл).

### Квадратичний виграш від тонкої ламінації

Зверніть увагу на степінь `d²` у формулі: потужність нагріву від вихрових струмів пропорційна **квадрату товщини пластини** та **квадрату частоти**.

Порівняємо два статори однакової маси `m = 18 г` з амплітудою індукції `B_m = 1.3 Тл` на частоті `f_e = 2916 Гц`:
1. Дешевий статор із пластин товщиною `d₁ = 0.35 мм = 0.35 · 10⁻³ м`;
2. Висококласний FPV-статор із японської кремнієвої сталі (Kawasaki / Nippon Steel) товщиною `d₂ = 0.20 мм = 0.20 · 10⁻³ м`.

Співвідношення втрат на вихрові струми:

```
P_e(0.35 мм) / P_e(0.20 мм)
= (d₁ / d₂)²        [квадратична залежність втрат від товщини пластини]
= (0.35 / 0.20)²    [підстановка товщин 0.35 мм та 0.20 мм]
= 1.75²             [обчислення співвідношення товщин]
= 3.0625            [виграш у 3.06 раза за потужністю втрат]
```

Перехід з пластин 0.35 мм на 0.20 мм зменшує виділення тепла від вихрових струмів у статорі в **3.06 раза**. Для високооборотних мікромоторів (понад 40 000 об/хв) використовують ультратонкі пластини 0.15 мм або навіть 0.10 мм, де виграш становить `(0.35 / 0.15)² ≈ 5.44` раза.

## Повний баланс магнітних втрат

Сумарні втрати в залізі складаються з гістерезису, класичних вихрових струмів та так званих надлишкових (аномальних) втрат `P_exc`, зумовлених динамікою руху доменних стінок:

```
P_core = P_h + P_e + P_exc
       = k_h · f_e · B_mⁿ + k_e · d² · f_e² · B_m² + k_exc · f_e^1.5 · B_m^1.5
```

На низьких обертах (мала `f_e`) домінує гістерезис `P_h ∝ f_e`. На високих обертах (понад 20 000 об/хв у FPV або сервоприводах) вихрові струми `P_e ∝ f_e²` починають різко випереджати гістерезис і стають головним джерелом холостого нагріву двигуна.

Саме тому мотор, що обертається на максимальному газі з легким або знятим пропелером (струм фази малий, омічні втрати `I²R` мінімальні), все одно стає гарячим за лічені секунди — усе тепло генерується вихровими струмами та перемагнічуванням статора.
