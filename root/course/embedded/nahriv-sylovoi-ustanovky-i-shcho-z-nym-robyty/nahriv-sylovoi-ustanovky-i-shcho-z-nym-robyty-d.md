Коли важкий безпілотник висить на місці у спекотний літній день при температурі повітря +35 °C, чотири його безколекторні мотори сумарно споживають понад 1.2 кВт електричної потужності від акумуляторної батареї. Навіть у високоякісній безколекторній системі з коефіцієнтом корисної дії 82% різниця між підведеною електричною енергією та корисною механічною роботою на валу становить близько 216 Вт. Уся ця потужність виділяється всередині моторів та регуляторів швидкості у формі чистого тепла. Об'єм мідних обмоток кожного мотора типорозміру 2806.5 не перевищує 4 кубічних сантиметрів, а площа силових MOSFET-транзисторів на платі ESC — менше ніж 25 квадратних міліметрів. За відсутності набігаючого повітряного потоку густина теплового потоку у цих крихітних об'ємах досягає десятків ватів на квадратний сантиметр, що розігріває мідь і кремній зі швидкістю 5–15 °C за секунду.

Якщо тепловий баланс розраховано неправильно, наслідки настають швидко: емалевий лак обмоток статора зазнає термічної деструкції й виникає міжвиткове замикання, потужні неодимові магніти ротора необоротно розмагнічуються під дією високої температури та зустрічного магнітного поля, а кремнієві кристали силових ключів регулятора переходять у лавиноподібний тепловий розгін і вибухають коротким замиканням прямо в польоті. Щоб проєктувати надійні силові установки, інженер мусить бачити кожне джерело тепла, розуміти фізичні межі руйнування матеріалів і вміти керувати тепловими потоками як апаратно, так і програмно.

## Джерела тепла в безколекторному моторі

Безколекторний трифазний синхронний двигун з постійними магнітами (англ. *Brushless Direct Current*, BLDC) перетворює електричну енергію на механічний момент двома фізичними ланками: струм у мідних котушках створює обертове магнітне поле статора, а це поле взаємодіє з постійними магнітами ротора. Кожна з цих двох ланок має власний фундаментальний механізм генерування тепла.

### Омічні втрати в міді та позитивний тепловий зворотний зв'язок

Головне джерело нагріву двигуна під навантаженням — це класичні джоулеві втрати в активному електричному опорі мідного дроту обмоток. У трифазному двигуні при шестикроковій або синусоїдальній комутації одночасно струм тече крізь дві послідовно з'єднані фази (при з'єднанні зіркою). Потужність омічних втрат у міді `P_cu` (англ. *copper losses*) дорівнює:

```
P_cu = 3/2 · I_phase² · R_phase
```

де `I_phase` — амплітудне значення фазного струму, а `R_phase` — електричний опір однієї фази постійному струму.

Головна небезпека втрат у міді криється у квадратичній залежності від струму `P_cu ∝ I²`. Якщо пілот збільшує тягу на 40%, фазний струм зростає у 1.4 раза, але тепловиділення в обмотках підскакує майже вдвічі (`1.4² = 1.96`). 

До цієї квадратичної залежності додається другий деструктивний фактор: питомий електричний опір металів зростає з температурою. Для міді температурний коефіцієнт опору становить `α ≈ 0.00393 1/°C` (приблизно +0.4% на кожен градус Цельсія). Залежність опору фази від температури описується лінійним законом:

```
R_phase(T) = R_20 · (1 + α · (T − 20))
```

Коли обмотка мотора нагрівається від кімнатної температури 20 °C до робочих 120 °C (перепад `ΔT = 100 °C`):

```
R_phase(120 °C)
= R_20 · (1 + 0.00393 · 100)  [підстановка перепаду температури ΔT = 100 °C]
= R_20 · (1 + 0.393)          [обчислення температурного приросту]
= 1.393 · R_20                [зростання опору гарячої міді на 39.3%]
```

Опір обмотки зростає на 39.3%. Якщо регулятор підтримує той самий струм для забезпечення необхідної тяги, потужність тепловиділення в гарячій міді автоматично зростає майже на 40% порівняно з холодним станом виключно через фізичне зростання опору провідника. Це утворює замкнений контур позитивного зворотного зв'язку: струм гріє мідь → опір зростає → за того самого струму виділяється ще більше тепла → температура повзе вгору ще швидше.

### Втрати в залізі статора: гістерезис і струми Фуко

Якщо зняти з мотора пропелер і розкрутити його на столі на максимальних обертах, струм споживання складе всього 1–2 А, а омічні втрати в міді будуть мізерними (частки вата). Проте вже за хвилину корпус статора стане гарячим на дотик. Причина — втрати в залізі магнітопроводу (англ. *iron losses* або *core losses*, від лат. *ferrum* — залізо).

Магнітопровід статора набраний із тонких пластин електротехнічної кремнієвої сталі. Під час обертання ротора магнітне поле в зубцях статора постійно змінює свій напрямок з електричною частотою `f_e = (RPM · p) / 60`, де `p` — кількість пар магнітних полюсів (для типового ротора на 14 полюсів `p = 7`). При швидкості 25 000 об/хв частота перемагнічування становить майже 3 кГц. Втрати в залізі складаються з двох компонентів:

1. **Втрати на магнітний гістерезис (`P_h`):** енергія, яка витрачається на подолання внутрішнього тертя при переорієнтації магнітних доменів сталі під час кожного циклу перемагнічування. Згідно з емпіричним законом Штейнмеца, втрати на гістерезис пропорційні частоті в першому степені та індукції в степені `n ≈ 1.6–2.0`:

```
P_h = k_h · f_e · B_maxⁿ · m_core
```

2. **Втрати на вихрові струми Фуко (`P_e`):** змінний магнітний потік за законом Фарадея індукує всередині електропровідної сталі вихрову ЕРС, яка збуджує паразитні замкнені струми. Ці струми розсіюють тепло у товщі металу. Потужність втрат на вихрові струми залежить від **квадрата частоти** та **квадрата товщини пластини ламінації** `d`:

```
P_e = (π² · d² · f_e² · B_max² · m_core) / (6 · ρ_fe · ρ_mass)
```

Строге математичне виведення рівняння вихрових струмів та аналіз залежності від геометричних параметрів статора наведено у вставці [Розрахунок втрат у статорній сталі: гістерезис і вихрові струми](root:embedded/nahriv-sylovoi-ustanovky-i-shcho-z-nym-robyty/math-eddy-hysteresis-loss.md).

З цієї квадратичної формули випливає практичне правило підбору мотора: застосування якісної японської сталі з товщиною пластин `d = 0.20 мм` замість дешевої `0.35 мм` зменшує вихровий нагрів статора у `(0.35 / 0.20)² ≈ 3.06` раза. На високих обертах саме товщина ламінації визначає, чи зможе мотор працювати без перегріву на холостому ходу та частих перегазовках.

> 🔧 **Навіщо це.** Якщо мотор гріється при спокійному прямолінійному польоті на високій швидкості з малим газом — винуватцем є не струм, а висока частота обертання і втрати в залізі статора. Зниження значення таймінгу в налаштуваннях ESC або вибір мотора з тоншою ламінацією статора (0.15–0.20 мм) усуває цей паразитичний нагрів без заміни гвинта.

## Джерела тепла в електронному регуляторі швидкості (ESC)

Електронний регулятор швидкості керує фазами мотора за допомогою трифазного моста на шести (або 12 при паралельному з'єднанні) силових польових транзисторах MOSFET (англ. *Metal-Oxide-Semiconductor Field-Effect Transistor*). У регуляторі виділяються три незалежні види теплових втрат.

### Статичні втрати провідності (Conduction Losses)

Коли транзистор повністю відкритий, його канал поводиться як низькоомний резистор з опором `R_DS(on)` (типово 0.8–2.5 мОм для якісних транзисторів у корпусах PowerDFN 5×6 або 3×3 мм). Струм фази, що проходить крізь відкритий ключ, створює джоулеві втрати провідності:

```
P_cond = 2 · I_rms² · R_DS(on)
```

Множник 2 відображає той факт, що струм одночасно проходить крізь один верхній (High-Side) та один нижній (Low-Side) транзистор трифазного інвертора.

Головна підступність MOSFET полягає в тому, що напівпровідниковий канал на основі кремнію має позитивний температурний коефіцієнт опору через зниження рухливості електронів при підвищенні температури кристала. Опір `R_DS(on)` при нагріванні кристала `T_j` від 25 °C до 150 °C зростає в **1.6–2.0 раза** (точний коефіцієнт вказується на графіку `Normalized R_DS(on) vs Temperature` у даташиті транзистора).

Якщо холодний регулятор з транзисторами `R_DS(on) = 1.0 мОм` при струмі 50 А розсіює:

```
P_cond(25 °C)
= 2 · (50)² · 0.001   [підстановка струму 50 А та опору 1.0 мОм]
= 2 · 2500 · 0.001    [піднесення струму до квадрата]
= 5.0 Вт              [потужність втрат провідності при 25 °C]
```

то при розігріві кристалів до 125 °C опір каналу зростає до `1.7 мОм`, а тепловиділення підскакує до:

```
P_cond(125 °C)
= 2 · 2500 · 0.0017   [підстановка гарячого опору R_DS(on) = 1.7 мОм]
= 8.5 Вт              [потужність втрат провідності при 125 °C]
```

Ці додаткові 3.5 Вт тепла виділяються на тій самій крихітній площі плати, посилюючи розігрів регулятора.

### Динамічні комутаційні втрати (Switching Losses)

Регулятор регулює ефективну напругу на обмотках за допомогою широтно-імпульсної модуляції (ШІМ, англ. *Pulse-Width Modulation*, PWM) на несучій частоті `f_pwm` (зазвичай від 24 до 96 кГц). 

MOSFET не може відкритися або закритися миттєво. Під час перемикання затворний драйвер повинен зарядити або розрядити вхідну ємність затвора `C_iss` (заряд затвора `Q_g`). Упродовж часу наростання струму `t_r` (rise time) та спаду напруги `t_f` (fall time) транзистор перебуває в активному лінійному режимі: на ньому одночасно присутня висока напруга живлення батареї `V_in` і протікає повний робочий струм фази `I_out`.

Миттєва потужність у цей момент досягає сотень ватів. Усереднена за період ШІМ потужність динамічних комутаційних втрат для одного перемикання розраховується як:

```
P_sw = 1/2 · V_in · I_out · (t_r + t_f) · f_pwm
```

Комутаційні втрати **прямо пропорційні частоті ШІМ** `f_pwm` та вхідній напрузі живлення `V_in`. 

Коли пілот перемикає частоту ШІМ у прошивці регулятора (BLHeli_S, BLHeli_32 або AM32) з класичних 24 кГц на 48 кГц або 96 кГц задля плавності роботи мотора та економії заряду на висінні, динамічні втрати в силових ключах ESC зростають рівно у 2 або 4 рази. На високовольтних 6S–8S LiPo батареях (25–33 В) на частоті 96 кГц комутаційні втрати починають переважати над втратами провідності, перетворюючи регулятор на піч.

### Втрати мертвого часу та зворотного відновлення

Щоб уникнути наскрізного струму (англ. *shoot-through* — прямого короткого замикання батарейної шини на землю при одночасному відкритті верхнього й нижнього ключів однієї фази), апаратний драйвер вставляє захисний інтервал затримки — мертвий час (англ. *dead time*, типово 30–120 нс).

Упродовж мертвого часу обидва транзистори закриті, але індуктивний струм обмотки мотора не може зупинитися миттєво. Він змушений текти крізь внутрішній паразитичний діод (англ. *body diode*) зворотного транзистора. Пряме падіння напруги на кремнієвому body-діоді становить `V_sd ≈ 0.8–1.2 В` (на відміну від мілівольтів на відкритому каналі MOSFET). Втрати потужності на діоді за час `t_dead`:

```
P_diode = 2 · V_sd · I_out · t_dead · f_pwm
```

Сучасні прошивки використовують комплементарне ШІМ-керування з активним гальмуванням (англ. *Damped Light* / *Active Freewheeling* / синхронне випрямлення): після спливу короткого інтервалу `t_dead` протилежний транзистор відкривається, шунтуючи свій body-діод низькоомним каналом `R_DS(on)` і зменшуючи пряме падіння напруги в десятки разів.

## Ризики перегріву та фізичні механізми відмови

Перегрів силової установки — це не просто тимчасове зниження коефіцієнта корисної дії. Він викликає три незворотні процеси руйнування матеріалів.

![Криві розмагнічування неодимових магнітів NdFeB при нагріванні](/root/course/embedded/nahriv-sylovoi-ustanovky-i-shcho-z-nym-robyty/img/demagnetization-curve.svg)
*Вплив температури на коерцитивну силу магнітів NdFeB: поява коліна розмагнічування та різниця між класами N52, N52H і N52SH.*

### 1. Термічна деструкція ізоляційного лаку обмоток

Мідний дріт, яким намотано статор, вкритий тонким шаром полімерного емалевого лаку (товщина плівки 15–35 мкм). Ізоляційні матеріали класифікують за температурними класами стійкості згідно зі стандартом IEC 60085:
- **Клас 130 (B):** робоча температура до 130 °C (дешеві мотори);
- **Клас 155 (F):** робоча температура до 155 °C;
- **Клас 180 (H):** робоча температура до 180 °C (якісні модельні мотори);
- **Клас 200 (N) / 220 (R):** спеціальні високотемпературні авіаційні емалі з поліімідним покриттям.

Швидкість хімічного старіння та деструкції полімерної ізоляції описується рівнянням Арреніуса (правило Монтзінгера): **кожні додаткові 10 °C понад номінальний клас скорочують термін служби ізоляційного шару вдвічі**.

При перегріві понад 180–200 °C лак втрачає пластичність, висихає, тріскається під дією електродинамічних вібрацій провідників і обуглюється. У місці мікротріщини виникає електричний пробій між сусідніми витками котушки — **міжвиткове замикання**. Замкнений виток утворює короткозамкнений вторинний контур трансформатора з колосальним індукованим струмом. Виділення тепла миттєво концентрується в одній точці, мідь розплавляється, фаза вигоряє дотла, а надструм короткого замикання пробиває силові ключі регулятора.

### 2. Розмагнічування неодимових магнітів ротора (NdFeB)

У роторах безколекторних двигунів використовуються спечені магніти зі сплаву неодим-залізо-бор (NdFeB) з високою магнітною енергією (найчастіше марки N52).

Фізичні властивості магнітів визначаються двома критичними температурами:
- **Точка Кюрі (`T_C ≈ 310–320 °C`):** температура, за якої речовина повністю втрачає феромагнітні властивості й перетворюється на парамагнетик;
- **Максимальна робоча температура (`T_max`):** температура, вище якої магніт починає зазнавати **незворотної втрати залишкової магнітної індукції** `B_r` та коерцитивної сили `H_cJ`.

Для стандартного неодимового магніту без термостійких добавок (марка **N52**) гранична температура становить усього **80 °C**. При додаванні диспрозію та тербію створюються високотемпературні марки:
- **N52H:** робоча межа до **120 °C** (буква *H* — High Temperature);
- **N52SH:** робоча межа до **150 °C** (Super High);
- **N52UH:** робоча межа до **180 °C** (Ultra High).

Механізм розмагнічування посилюється магнітним полем статора. При нагріванні характеристика розмагнічування магніту в другому квадранті графіка `B-H` набуває точки перегину («коліна», англ. *knee point*). Якщо при температурі 100 °C пілот дає різкий газ, сильне зустрічне розмагнічувальне магнітне поле від статорних зубців зсуває робочу точку магніту нижче за це коліно. 

У результаті магніт незворотно втрачає 15–40% своєї сили. Константа швидкості мотора `K_v` зростає (оскільки `K_v ∝ 1 / B_r`), але крутний момент на ампер струму `K_t` катастрофічно падає (`K_t ∝ B_r`). Мотор починає споживати аномально високий струм при зниженій тязі, що призводить до лавиноподібного саморозігріву в наступних польотах.

### 3. Тепловий пробій MOSFET регулятора та тепловий розгін

Кремнієві силові транзистори мають абсолютну граничну температуру напівпровідникового p-n переходу `T_j(max) = 150 °C` (рідше 175 °C для промислових корпусів). При перевищенні цієї позначки кремній зазнає власної термогенерації носіїв заряду, замикаючи канал.

Критичний механізм руйнування регулятора — **тепловий розгін** (англ. *thermal runaway*). Він виникає тоді, коли швидкість зростання втрат у кристалі через нагрів перевищує здатність системи охолодження відводити тепло:

```
d P_loss / d T_j > 1 / R_th(ja)
```

де `R_th(ja)` — сумарний тепловий опір від кристала до навколишнього повітря.

Оскільки `R_DS(on)` зростає з температурою, потужність розсіювання `P_cond` збільшується. Якщо тепловідвід недостатній, кристал нагрівається ще сильніше, опір зростає ще більше, тепловиділення перевищує потік тепловідведення, і температура транзистора за частки секунди злітає від 150 °C до 300+ °C. Кристал фізично пробивається, утворюючи коротке замикання між стоком і витоком, силова батарея спалює мідні полігони плати ESC, і дрон миттєво втрачає живлення та керування.

## Методи охолодження та зниження нагріву

Тепловий стан силової установки визначається балансом двох потоків: швидкості генерації тепла `P_gen` та швидкості його відведення в довкілля `P_diss`. Інженер має важелі впливу на обидва потоки.

*Охолодження силової установки: набігаючий потік від гвинта, відцентрові крильчатки дзвона мотора та правильний монтаж ESC з радіатором.*

### Аеродинаміка та примусове обдування від пропелера

Закон тепловіддачі Ньютона-Ріхмана визначає конвективний тепловий потік від поверхні площею `A` до повітря:

```
P_conv = h_c · A · (T_surface − T_air)
```

Коефіцієнт тепловіддачі `h_c` (Вт/(м²·К)) фундаментально залежить від швидкості руху повітря повз поверхню. У стоячому повітрі при природній конвекції `h_c ≈ 10–25 Вт/(м²·К)`. Коли поверхню обдуває набігаючий потік від пропелера зі швидкістю 15–30 м/с, коефіцієнт примусової конвекції зростає до `h_c ≈ 80–150 Вт/(м²·К)`. 

**Примусовий обдув зменшує ефективний тепловий опір у повітря в 4–6 разів.**

Звідси випливають три критичні правила компонування:
1. **Небезпека тривалого зависання (Hover Trap):** Під час швидкого поступального польоту вперед весь корпус дрона та мотори обдуваються зустрічним холодним повітрям. На висінні ж відносна швидкість повітря навколо рами мінімальна, а під куполом штовхаючих моторів утворюється зона рециркуляції нагрітого повітря. Тепловий розрахунок завжди робиться за найгіршим сценарієм — зависанням у штиль;
2. **Тягнучий (Tractor) проти штовхаючого (Pusher) гвинта:** У класичній конфігурації квадрокоптера пропелер стоїть над мотором і нагнітає струмінь повітря безпосередньо крізь дзвін статора та вздовж променя, де змонтовано ESC. У штовхаючій конфігурації («пропелер знизу») мотор висить у затінку рами, а швидкість обдуву його корпусу значно нижча;
3. **Відцентрові вентиляційні отвори ротора (Centrifugal Bell Vents):** Сучасні дзвони моторів мають похилі вентиляційні отвори у верхній та нижній кришках ротора, що працюють як відцентровий вентилятор. Під час обертання вони примусово прокачують повітря знизу вгору прямо крізь зазор між статором і магнітами.

### Тепловідвід і монтаж регулятора (ESC)

Сучасні регулятори виконуються у вигляді окремих плат на променях рами або у форматі плати «4-в-1», встановленої у центральному скляному стеку під польотним контролером.
- **Товщина мідних шарів друкованої плати:** Оскільки текстоліт FR4 є теплоізолятором (теплопровідність `k ≈ 0.25 Вт/(м·К)`), тепло від кристалів MOSFET розтікається виключно по мідних полігонах (`k ≈ 390 Вт/(м·К)`). Використання плат з товщиною міді 2–4 oz (70–140 мкм) замість стандартного 1 oz знижує внутрішній тепловий опір плати у 2–3 рази;
- **Масиви теплових перехідних отворів (Thermal Vias):** Під кожним транзистором формується сітка перехідних отворів діаметром 0.3 мм з кроком 0.6–0.8 мм, покритих міддю, які передають тепло від верхнього майданчика до суцільного мідного шару на зворотному боці плати;
- **Пастка термоусадкової трубки (Heatshrink Trap):** Прозора пластикова термоусадка, в яку часто загортають регулятори для захисту від вологи, має вкрай низьку теплопровідність і працює як термоізоляційний кожух. Регулятор у суцільній термоусадці нагрівається на 25–40 °C сильніше. У зоні розташування транзисторів або алюмінієвого радіатора в термоусадці обов'язково прорізають вікно, забезпечуючи прямий контакт металу радіатора з набігаючим потоком повітря від гвинта.

### Оптимізація таймінгів комутації та параметрів прошивки

Програмні налаштування регулятора обертів прямо формують тепловий профіль мотора:
- **Частота ШІМ (PWM Frequency):** 
  - `24 кГц` — мінімальні комутаційні втрати в транзисторах ESC (регулятор холодний), але вищі пульсації струму в обмотках мотора;
  - `48 кГц` — збалансований стандарт для більшості коптерів;
  - `96–128 кГц` — плавний відгук і максимальна тиша, але комутаційні втрати в MOSFET зростають у 2–4 рази, створюючи ризик перегріву ESC;
- **Кут випередження комутації (Motor Timing):**
  - *Низький таймінг (0°–12°):* максимальний ККД, мінімальний нагрів на низьких і середніх обертах. Ідеальний для далекольотів та важких платформ;
  - *Середній / авто таймінг (15°–22.5°):* стандартний компроміс для фристайлу;
  - *Агресивний таймінг (25°–30°):* збільшує максимальну потужність і швидкість обертання на 5–10% ціною різкого зростання струму холостого ходу та сильного нагріву як мотора, так і ESC. Застосовується виключно в гоночних дронах на коротких 2-хвилинних заїздах.

## Теплова RC-модель силової установки та моніторинг температури

Для точного прогнозування та контролю нагріву силову установку моделюють у вигляді еквівалентного теплового RC-ланцюга, аналогічного електричній схемі.

![Еквівалентна багатоланкова теплова RC-схема](/root/course/embedded/nahriv-sylovoi-ustanovky-i-shcho-z-nym-robyty/img/thermal-rc-network.svg)
*Багатоланкова теплова RC-модель мотора та силових ключів регулятора для обчислення динаміки нагріву за змінної потужності.*

У цій моделі:
- Джерела втрат потужності `P_cu`, `P_fe`, `P_mos` є еквівалентами джерел струму;
- Теплоємності матеріалів `C_th` (Дж/°C) — еквіваленти конденсаторів;
- Теплові опори `R_th` (°C/Вт) — еквіваленти резисторів;
- Температури у вузлах `T_j`, `T_wind`, `T_core`, `T_hs` — еквіваленти електричних потенціалів (напруг) відносно температури навколишнього середовища `T_amb`.

Теплова стала часу вузла дорівнює:

```
τ_th = R_th · C_th
```

Для крихітного кристала MOSFET стала часу становить усього `τ_j ≈ 5–20 мс`. Це означає, що при імпульсному перевантаженні транзистор нагрівається практично миттєво. Для масивного статора мотора стала часу становить `τ_motor ≈ 15–45 с`. Мотор здатен поглинати короткі сплески струму тривалістю 3–5 секунд без небезпеки розплавлення, акумулюючи тепло у своїй теплоємності.

### Програмний термозахист у реальному часі

Сучасні регулятори з підтримкою цифрових протоколів передають польотному контролеру кадр телеметрії через зворотний канал DShot Telemetry або окремий дріт UART (ESC Telemetry). Пакет містить виміряний струм, напругу, частоту обертання eRPM та показання аналогового NTC-термістора на платі регулятора.

Оскільки мотор не має власного фізичного термодатчика, бортове програмне забезпечення польотного контролера використовує математичну модель спостерігача (англ. *Thermal Observer*): за інтегралом виміряного струму та обертів воно обчислює поточну розрахункову температуру обмоток мотора. 

При досягненні порогу попередження `T_warn` (наприклад, 95 °C для ESC або 100 °C для мотора) алгоритм активує **динамічний термотротлінг** (англ. *thermal throttling*): плавно знижує верхню межу газу згідно з лінійною або ПІ-залежністю, не даючи температурі досягти критичної межі руйнування `T_crit`.

Повну архітектуру бортового модуля обробки телеметрії, теплового спостерігача та плавного термотротлінгу наведено у вставці [Бортовий тепловий спостерігач і захист регулятора](root:embedded/nahriv-sylovoi-ustanovky-i-shcho-z-nym-robyty/proj-thermal-throttle.md).

Нижче наведено приклад обчислення температури вузлів та лінійного термотротлінгу для польотного контролера.

```c
// thermal_monitor.h / thermal_monitor.c
#include <stdint.h>
#include <stdbool.h>

typedef struct {
    float r_phase_20c;        // Опір фази мотора при 20°C (Ом)
    float alpha_cu;           // Температурний коефіцієнт міді (0.00393)
    float c_th_winding;       // Теплоємність обмотки (Дж/°C)
    float r_th_wind_to_air;   // Тепловий опір обмотка-повітря (°C/Вт)
    float esc_temp_limit_c;   // Гранична температура ESC (°C)
    float motor_temp_limit_c; // Гранична температура обмотки (°C)
} PropulsionThermalLimits;

typedef struct {
    float motor_temp_est;     // Оцінена температура обмотки (°C)
    float esc_temp_c;         // Виміряна температура регулятора (°C)
    float max_allowed_throttle;// Коефіцієнт обмеження газу (0.0 .. 1.0)
    bool  thermal_alert;      // Сигнал попередження про перегрів
} PropulsionThermalState;

void thermal_monitor_init(PropulsionThermalState *state, float ambient_temp_c) {
    state->motor_temp_est = ambient_temp_c;
    state->esc_temp_c = ambient_temp_c;
    state->max_allowed_throttle = 1.0f;
    state->thermal_alert = false;
}

void thermal_monitor_update(PropulsionThermalState *state,
                            const PropulsionThermalLimits *limits,
                            float phase_current_rms,
                            float esc_telemetry_temp,
                            float ambient_temp_c,
                            float dt_sec) {
    state->esc_temp_c = esc_telemetry_temp;

    // 1. Оновлення теплової моделі мотора (1-полюсна RC-модель)
    float r_copper = limits->r_phase_20c * (1.0f + limits->alpha_cu * (state->motor_temp_est - 20.0f));
    float p_loss_cu = 1.5f * phase_current_rms * phase_current_rms * r_copper;

    float heat_dissipated = (state->motor_temp_est - ambient_temp_c) / limits->r_th_wind_to_air;
    float d_temp = (p_loss_cu - heat_dissipated) / limits->c_th_winding;
    state->motor_temp_est += d_temp * dt_sec;

    // 2. Розрахунок коефіцієнта термотротлінгу
    float throttle_scale_esc = 1.0f;
    if (state->esc_temp_c > (limits->esc_temp_limit_c - 20.0f)) {
        float over = state->esc_temp_c - (limits->esc_temp_limit_c - 20.0f);
        throttle_scale_esc = 1.0f - (over / 20.0f);
        if (throttle_scale_esc < 0.3f) throttle_scale_esc = 0.3f;
    }

    float throttle_scale_motor = 1.0f;
    if (state->motor_temp_est > (limits->motor_temp_limit_c - 25.0f)) {
        float over = state->motor_temp_est - (limits->motor_temp_limit_c - 25.0f);
        throttle_scale_motor = 1.0f - (over / 25.0f);
        if (throttle_scale_motor < 0.3f) throttle_scale_motor = 0.3f;
    }

    state->max_allowed_throttle = (throttle_scale_esc < throttle_scale_motor)
                                  ? throttle_scale_esc : throttle_scale_motor;
    state->thermal_alert = (state->max_allowed_throttle < 0.95f);
}
```

```cpp
// ThermalMonitor.hpp — Ідіоматичний C++20 клас моніторингу
#pragma once
#include <algorithm>
#include <cmath>

namespace drone::propulsion {

struct ThermalLimits {
    float r_phase_20c{0.050f};         // Опір фази мотора при 20°C (Ом)
    float alpha_cu{0.00393f};          // Температурний коефіцієнт міді
    float c_th_winding{4.2f};          // Теплоємність обмотки (Дж/°C)
    float r_th_wind_to_air{2.5f};      // Тепловий опір обмотка-повітря (°C/Вт)
    float esc_temp_limit_c{105.0f};    // Гранична температура ESC (°C)
    float motor_temp_limit_c{125.0f};  // Гранична температура обмотки (°C)
};

class ThermalMonitor {
public:
    explicit constexpr ThermalMonitor(const ThermalLimits& limits, float ambient_c = 25.0f) noexcept
        : limits_{limits}, motor_temp_est_{ambient_c}, esc_temp_c_{ambient_c} {}

    void update(float phase_current_rms, float esc_telemetry_temp,
                float ambient_temp_c, float dt_sec) noexcept {
        if (dt_sec <= 0.0f) return;
        esc_temp_c_ = esc_telemetry_temp;

        // 1. Оцінка температури обмотки
        const float r_cu = limits_.r_phase_20c * (1.0f + limits_.alpha_cu * (motor_temp_est_ - 20.0f));
        const float p_loss_cu = 1.5f * phase_current_rms * phase_current_rms * r_cu;
        const float heat_dissipated = (motor_temp_est_ - ambient_temp_c) / limits_.r_th_wind_to_air;

        const float d_temp = (p_loss_cu - heat_dissipated) / limits_.c_th_winding;
        motor_temp_est_ += d_temp * dt_sec;

        // 2. Термотротлінг
        auto calc_scale = [](float val, float limit, float window) noexcept -> float {
            const float warn = limit - window;
            if (val <= warn) return 1.0f;
            if (val >= limit) return 0.3f;
            return std::clamp(1.0f - (val - warn) / window, 0.3f, 1.0f);
        };

        const float scale_esc = calc_scale(esc_temp_c_, limits_.esc_temp_limit_c, 20.0f);
        const float scale_mot = calc_scale(motor_temp_est_, limits_.motor_temp_limit_c, 25.0f);

        max_allowed_throttle_ = std::min(scale_esc, scale_mot);
        thermal_alert_ = (max_allowed_throttle_ < 0.95f);
    }

    [[nodiscard]] constexpr float motor_temperature() const noexcept { return motor_temp_est_; }
    [[nodiscard]] constexpr float esc_temperature() const noexcept { return esc_temp_c_; }
    [[nodiscard]] constexpr float throttle_limit() const noexcept { return max_allowed_throttle_; }
    [[nodiscard]] constexpr bool is_alert() const noexcept { return thermal_alert_; }

private:
    ThermalLimits limits_;
    float motor_temp_est_{25.0f};
    float esc_temp_c_{25.0f};
    float max_allowed_throttle_{1.0f};
    bool  thermal_alert_{false};
};
```

## Підсумковий інженерний чеклист теплової оптимізації

Під час проєктування та налаштування силової установки безпілотника дотримання такого алгоритму захищає апарат від термічних катастроф:

1. **Розрахунок теплового дератингу:** Вибирайте ESC із номінальним струмом, що щонайменше у **1.4–1.6 раза** перевищує максимальний струм мотора при 100% газі, з урахуванням подвоєння `R_DS(on)` при нагріванні транзисторів до 125 °C;
2. **Перевірка марки магнітів:** Для робочих та вантажних дронів використовуйте мотори виключно з магнітами серій **N52H** або **N52SH** (стійкість до 120–150 °C), уникаючи базових N52 (80 °C);
3. **Організація повітряного обдуву:** Встановлюйте регулятори безпосередньо у зоні активного набігаючого струменя пропелера на променях рами. Забезпечуйте вікно у термоусадці для прямого контакту радіатора з повітрям;
4. **Узгодження частоти ШІМ і таймінгів:** Не піднімайте частоту ШІМ понад 48 кГц без крайньої потреби (кожні +24 кГц подвоюють комутаційні втрати). Для тягових апаратів встановлюйте консервативний таймінг комутації 10°–15°;
5. **Активація бортової телеметрії:** Підключайте зворотний канал телеметрії ESC до польотного контролера та налаштовуйте пороги відсічення термотротлінгу в ArduPilot, Betaflight або PX4.
