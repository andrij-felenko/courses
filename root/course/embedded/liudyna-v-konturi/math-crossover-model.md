# 🧮 Модель перетину Макруера: математичне виведення та фазові межі стійкості

Цей математичний аналіз розгортає модель динаміки оператора Дуейна Макруера, виводить точний фазовий набіг чистої затримки та доводить закон перетину для розімкненого контуру керування «людина-машина». Без розуміння передатних функцій фізіологічного тракту, критерію Найквіста та з'їдання фазового запасу неможливо аналітично розрахувати граничну затримку радіоканалу, за якої система втрачає стійкість.

## 1. Квазілінійна передатна функція людини-оператора

У задачі неперервного компенсаторного стеження за візуальним сигналом похибки `e(t)` поведінка оператора описується квазілінійною передатною функцією `Y_p(s)` з адитивним некорельованим залишком (ремінантом `n(t)`). Передатна функція складається з трьох послідовних ланок: чистої фізіологічної затримки, адаптивного регулятора та нервово-м'язового фільтра:

```
Y_p(s) = K_p · [(T_L · s + 1) / (T_I · s + 1)] · exp(-τ_p · s) · [1 / (T_N · s + 1)]
```

де параметри мають фізичний і біомеханічний зміст:

- `K_p` — коефіцієнт підсилення оператора (безрозмірний або в одиницях відхилення органу керування на одиницю помилки на екрані);
- `τ_p` — чиста транспортна затримка зорово-моторного тракту (`τ_p = τ_vis + τ_cent + τ_mot ≈ 0.15–0.25` с);
- `T_L` — постійна часу диференціювання (випередження, Lead), яку людина формує за рахунок екстраполяції швидкості зміни сигналу (`T_L ≈ 0–2.5` с);
- `T_I` — постійна часу інтегрування (запізнення, Lag), яку людина вводить для покращення низькочастотної точності (`T_I ≈ 0–10` с);
- `T_N` — постійна часу нервово-м'язової системи (інерція скорочення м'язів та маса кінцівки, `T_N ≈ 0.08–0.12` с).

## 2. Закон перетину Макруера (Crossover Model Law)

Емпіричний закон Макруера стверджує: незалежно від порядку та передатної функції об'єкта керування `Y_c(s)`, людина-оператор адаптує параметри `K_p`, `T_L`, `T_I` у своїй передатній функції так, щоб у смузі частоти зрізу `ω_c` (де модуль підсилення розімкненого контуру дорівнює одиниці, `|Y_ol(j·ω_c)| = 1`) розімкнена система `Y_ol(s) = Y_p(s) · Y_c(s)` поводилася як інтегратор із сумарною еквівалентною затримкою `τ_e`:

```
Y_ol(s) = Y_p(s) · Y_c(s) ≈ (ω_c / s) · exp(-τ_e · s)
```

де `τ_e ≈ τ_p + T_N + τ_link` — ефективна затримка розімкненої петлі в околі частоти зрізу `ω_c`.

Розгляньмо, як саме людина адаптується до трьох базових класів динаміки апарата:

### А. Об'єкт без інерції (статична ланка): `Y_c(s) = K_c`

Щоб отримати `Y_ol(s) ≈ (ω_c / s) · exp(-τ_e · s)`, оператор генерує інтегрування (`T_I >> 1`, `T_L ≈ 0`):

```
Y_p(s) ≈ (K_p / (T_I · s)) · exp(-τ_p · s)
```

Тоді добуток дає:

```
Y_ol(s) = [K_p / (T_I · s)] · exp(-τ_p · s) · K_c
        = [(K_p · K_c / T_I) / s] · exp(-τ_p · s)       [групування коефіцієнтів]
        = (ω_c / s) · exp(-τ_e · s)                      [де ω_c = K_p · K_c / T_I]
```

### Б. Об'єкт з інтегруванням (режим Rate / кутова швидкість): `Y_c(s) = K_c / s`

Об'єкт уже містить `1/s`. Оператор діє як суто пропорційна ланка (`T_L ≈ 0`, `T_I ≈ 0`):

```
Y_p(s) ≈ K_p · exp(-τ_p · s)
```

Добуток:

```
Y_ol(s) = K_p · exp(-τ_p · s) · (K_c / s)
        = [(K_p · K_c) / s] · exp(-τ_p · s)             [де частота зрізу ω_c = K_p · K_c]
```

### В. Об'єкт з подвійним інтегруванням (прискорення / момент без демпфування): `Y_c(s) = K_c / s^2`

Об'єкт дає `1/s^2` і фазове відставання −180°. Без компенсації система нестійка за будь-якого підсилення. Оператор змушений генерувати сильне диференціювання (`T_L · s + 1`), компенсуючи один полюс:

```
Y_p(s) ≈ K_p · (T_L · s + 1) · exp(-τ_p · s)
```

Добуток в околі `ω_c` (де `T_L · ω_c >> 1`):

```
Y_ol(s) ≈ [K_p · T_L · s · exp(-τ_p · s)] · [K_c / s^2]
        = [(K_p · K_c · T_L) / s] · exp(-τ_p · s)       [скорочення одного степеня s]
```

Ціною цього є колосальне розумове й м'язове навантаження на оператора: людині важко утримувати `T_L > 1.5` с тривалий час без помилок і втоми.

## 3. Фазове відставання та аналітичне виведення запасу стійкості

Підставимо в модель розімкненого контуру гармонічний сигнал `s = j·ω`:

```
Y_ol(j·ω) = [ω_c / (j · ω)] · exp(-j · ω · τ_e)
```

Запишемо комплексну величину в показовій формі `Y_ol(j·ω) = |Y_ol(j·ω)| · exp(j · φ(ω))`:

```
1 / j = exp(-j · π / 2)                                 [поворот на -90 градусів]
exp(-j · ω · τ_e)                                       [фазовий зсув чистої затримки]
Y_ol(j·ω) = (ω_c / ω) · exp(-j · [π / 2 + ω · τ_e])    [добуток експонент]
```

Амплітудно-частотна характеристика (АЧХ) та фазо-частотна характеристика (ФЧХ):

```
|Y_ol(j·ω)| = ω_c / ω
φ(ω) = -π / 2 - ω · τ_e                                 [фаза у радіанах]
φ(ω) = -90° - (180 / π) · ω · τ_e                       [фаза у градусах]
```

### Визначення частоти зрізу `ω_c`

За визначенням, частота зрізу `ω_c` — це частота, на якій модуль розімкненого контуру дорівнює одиниці (0 дБ):

```
|Y_ol(j·ω_c)| = 1
ω_c / ω_c = 1                                           [рівність виконується тотожно]
```

### Запас стійкості по фазі (Phase Margin)

Запас по фазі `PM` — це різниця між фазою розімкненого контуру на частоті зрізу та критичною межею −180° (−π радіан):

```
PM = π + φ(ω_c)
   = π + (-π / 2 - ω_c · τ_e)                           [підстановка ФЧХ на частоті зрізу]
   = π / 2 - ω_c · τ_e                                  [запас по фазі у радіанах]
```

У градусній мірі:

```
PM = 90° - (180 / π) · ω_c · τ_e                        [запас по фазі у градусах]
```

## 4. Гранична затримка контуру (Delay Margin)

Критичний стан нестійкості настає тоді, коли запас по фазі зменшується до нуля (`PM = 0`). Розв'яжемо рівняння відносно затримки:

```
PM = 0
π / 2 - ω_c · τ_crit = 0                                [умова межі нестійкості]
τ_crit = π / (2 · ω_c)                                  [гранична повна затримка петлі]
```

Якщо контур без затримки мав початковий запас по фазі `PM_0`, то гранична додаткова транспортна затримка радіоканалу `Δτ_max`, яку витримає система до виникнення автоколивань (PIO):

```
Δτ_max = PM_0 / ω_c
```

### Числовий розрахунок для різних типів задач

| Задача керування | Частота зрізу ω_c (рад/с) | Початковий запас PM_0 | Гранична повна затримка τ_crit | Допустима додаткова затримка радіо Δτ_max |
|---|---|---|---|---|
| FPV гонки / Acro режим | 6.0 рад/с | 1.05 рад (60°) | 262 мс | 175 мс |
| Стабілізований нахил (Angle) | 2.5 рад/с | 1.22 рад (70°) | 628 мс | 488 мс |
| Наведення колісного ровера | 1.5 рад/с | 1.05 рад (60°) | 1047 мс | 700 мс |
| Утримання точки (Position Hold) | 0.5 рад/с | 1.31 рад (75°) | 3140 мс | 2620 мс |

З формули видно фундаментальну закономірність: гранична допустима затримка обернено пропорційна частоті зрізу контуру. Що динамічніший рух і вищі вимоги до смуги пропускання, то меншу затримку здатна витримати замкнена система до втрати стійкості.

## 5. Критерій Найквіста для контуру з затримкою

У частотній області стійкість замкненої системи визначається критерієм Найквіста. Годограф розімкненої передатної функції `Y_ol(j·ω)` на комплексній площині не повинен охоплювати критичну точку `(-1, j0)`.

Запишемо дійсну та уявну частини розімкненої системи з моделлю Макруера:

```
Y_ol(j·ω) = (ω_c / ω) · exp(-j · [π / 2 + ω · τ_e])
          = (ω_c / ω) · [cos(-π / 2 - ω · τ_e) + j · sin(-π / 2 - ω · τ_e)]
          = -(ω_c / ω) · sin(ω · τ_e) - j · (ω_c / ω) · cos(ω · τ_e)
```

Знайдемо точку перетину годографа з дійсною віссю (де уявна частина дорівнює нулю):

```
Im{Y_ol(j·ω)} = 0
-(ω_c / ω) · cos(ω · τ_e) = 0                           [умова перетину дійсної осі]
ω · τ_e = π / 2 + k · π
ω_180 = π / (2 · τ_e)                                   [перша частота фазового перевороту]
```

Значення дійсної частини на цій частоті:

```
Re{Y_ol(j·ω_180)} = -(ω_c / ω_180) · sin(π / 2)
                  = -ω_c / [π / (2 · τ_e)]
                  = -(2 / π) · ω_c · τ_e
```

За критерієм Найквіста для стійкості точка перетину мусить лежати праворуч від критичної точки `-1`:

```
-(2 / π) · ω_c · τ_e > -1
(2 / π) · ω_c · τ_e < 1                                 [множення на -1 зі зміною знаку]
τ_e < π / (2 · ω_c)
```

Цей результат строго збігається з граничною затримкою, виведеною через фазовий запас Боде. Якщо затримка `τ_e` перевищує `π / (2 · ω_c)`, годограф Найквіста охоплює точку `(-1, j0)`, створюючи пару нестабільних полюсів у правій півплощині коренів.

## 6. Апроксимація затримки Паде та передатна функція замкненого контуру

Для лінійного аналізу передатну функцію чистої затримки `exp(-s · τ)` апроксимують дробово-раціональним виразом Паде першого або другого порядку:

```
exp(-s · τ) ≈ (1 - s · τ / 2) / (1 + s · τ / 2)         [дробово-раціональна апроксимація Паде 1-го порядку]
```

Чисельник апроксимації Паде містить додатний нуль у правій комплексній півплощині:

```
s_zero = +2 / τ
```

Це перетворює замкнений контур «людина-лінк-машина» на систему з немінімальною фазою (Non-Minimum Phase System). Для таких систем характерний ефект зворотного початкового відгуку (undershoot): під час спроби різко повернути стік система на перших мілісекундах рухається у зворотний бік через набіг фази затримки, спонукаючи пілота смикати стік ще сильніше.

Замкнена передатна функція контуру за уставкою `W_cl(s) = Y_ol(s) / (1 + Y_ol(s))` з апроксимацією Паде першого порядку:

```
W_cl(s) = [(ω_c / s) · (1 - s · τ_e / 2) / (1 + s · τ_e / 2)] / [1 + (ω_c / s) · (1 - s · τ_e / 2) / (1 + s · τ_e / 2)]
```

Спростимо вираз, помноживши чисельник і знаменник на `s · (1 + s · τ_e / 2)`:

```
W_cl(s) = ω_c · (1 - s · τ_e / 2) / [s · (1 + s · τ_e / 2) + ω_c · (1 - s · τ_e / 2)]
        = ω_c · (1 - s · τ_e / 2) / [(τ_e / 2) · s^2 + (1 - ω_c · τ_e / 2) · s + ω_c]  [зведення подібних]
```

Характеристичне рівняння замкненої системи:

```
A(s) = (τ_e / 2) · s^2 + (1 - ω_c · τ_e / 2) · s + ω_c = 0
```

За критерієм стійкості Рауса-Гурвіца для полінома другого порядку `a_2 · s^2 + a_1 · s + a_0 = 0` усі коефіцієнти мусять бути строго додатними (`a_2 > 0, a_1 > 0, a_0 > 0`).

Перевіримо коефіцієнт `a_1`:

```
a_1 = 1 - ω_c · τ_e / 2 > 0
ω_c · τ_e / 2 < 1                                       [перенесення доданка]
τ_e < 2 / ω_c                                           [гранична умова стійкості]
```

Коли сумарна затримка `τ_e` наближається до `2 / ω_c`, коефіцієнт демпфування замкненої системи падає до нуля:

```
2 · ζ · ω_n = a_1 / a_2 = (1 - ω_c · τ_e / 2) / (τ_e / 2)
ζ = (1 - ω_c · τ_e / 2) / [2 · sqrt(ω_c · τ_e / 2)]    [коефіцієнт демпфування системи]
```

При `τ_e = 2 / ω_c` коефіцієнт демпфування `ζ = 0`, а полюси системи лягають безпосередньо на уявну вісь. Контур втрачає стійкість і переходить у режим незатухаючих автоколивань з частотою `ω_c`. Це і є точний аналітичний опис виникнення розкачки оператором (PIO).
