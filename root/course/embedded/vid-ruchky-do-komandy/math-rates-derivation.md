# 🧮 Математика кривих стіка: похідні, кривина та моделі швидкості

Вхідний сигнал ручки керування — це нормалізоване число від -1.0 до +1.0. Вихід — це цільова кутова швидкість апарата в градусах за секунду. Пряма лінійна залежність між ними непридатна для реального пілотування: якщо зробити весь хід стіка чутливим для мікроманеврів біля нуля, апарат не зможе швидко крутитися на краю; якщо ж задати високу кутову швидкість на упорі, найменший порух пальця біля центру збиватиме приціл або горизонт.

Математичне завдання формування кривих полягає у побудові гладкої, монотонно зростаючої непарної функції відхилення стіка, яка одночасно забезпечує задану низьку чутливість біля нуля, фіксовану максимальну швидкість на упорі та відсутність паразитних перегинів.

```
x ∈ [-1.0, +1.0]      [нормалізоване положення стіка]
y(x) ∈ [-1.0, +1.0]    [коефіцієнт передачі]
ω(x) = y(x) · ω_max    [кутова швидкість у deg/s]
```

## Базові аксіоми та граничні вимоги до кривої передачі

Будь-яка математична функція перетворення вхідного сигналу стіка `x` у нормалізований відгук `y(x)` повинна строго задовольняти чотири базові інженерні аксіоми:

1. **Симетрія та нульовий початок (непарність):**
Функція повинна бути непарною: `y(-x) = -y(x)`. Це гарантує, що апарат реагує абсолютно однаково при відхиленні ручки вліво та вправо, а в стані спокою при `x = 0` видає нульову кутову швидкість: `y(0) = 0`.

2. **Збереження одиничного діапазону (нормалізація країв):**
При повному механічному упорі ручки (`x = 1.0`) функція зобов'язана видавати рівно одиничний коефіцієнт: `y(1.0) = 1.0`. Функція не повинна обмежувати або штучно розширювати встановлений фізичний діапазон кутових швидкостей.

3. **Строга монотонність (відсутність зворотного ходу):**
Для будь-яких двох точок `x₁` та `x₂`, якщо `x₁ < x₂`, то обов'язково `y(x₁) < y(x₂)`. Це означає, що перша похідна функції на всій області визначення повинна бути строго додатною: `dy/dx > 0` для `x > 0`. Якщо похідна хоча б у одній точці стане від'ємною або нульовою, збільшення відхилення пальця призведе до уповільнення обертання або втрати реакції, що є неприпустимим для контуру керування.

4. **Монотонне зростання крутизни (опуклість):**
Чутливість повинна монотонно зростати від центру до краю: `d²y/dx² ≥ 0` для `x ≥ 0`. Це забезпечує плавний перехід від прецизійного мікрокерування до швидкого маневрування без різких сходинок та ривків.

## Кубічна експонента: аналіз чутливості та похідних

Базова модель експоненти (RC Expo) інтерполює між лінійною залежністю `x` та кубічною параболою `x³`. Оскільки функція симетрична відносно нуля (`y(-x) = -y(x)`), обмежимося додатним інтервалом `x ∈ [0, 1]`:

```
y(x) = x · (1 - e) + x³ · e
```

де `e ∈ [0, 1]` — коефіцієнт експоненти (в налаштуваннях пультів зазвичай від 0.0 до 0.9).

### Перша похідна (миттєва чутливість)

Перша похідна передавальної функції за аргументом `x` визначає коефіцієнт передачі на малому прирості відхилення ручки — тобто те, наскільки градусів за секунду зросте швидкість при русі пальця на один міліметр:

```
dy/dx = d/dx [ x · (1 - e) + x³ · e ]
dy/dx = (1 - e) + 3 · e · x²
```

Дослідимо значення похідної у характерних точках:

1. **Центральна точка (`x = 0`):**
```
S₀ = dy/dx |_{x=0} = 1 - e
```
При `e = 0.0` (чисто лінійна залежність) крутизна в нулі дорівнює 1.0. При збільшенні коефіцієнта `e` до 0.60 крутизна зменшується до `1 - 0.60 = 0.40`. Це означає, що навколо центрального положення чутливість ручки падає у 2.5 раза. Рука пілота отримує широку зону комфортного мікроприцілювання, де навіть помітне тремтіння пальця викликає лише незначний рух апарата. При екстремальному значенні `e = 0.85` чутливість становить лише `0.15` (зменшення на 85%).

2. **Крайній упор (`x = 1.0`):**
```
S₁ = dy/dx |_{x=1} = (1 - e) + 3 · e = 1 + 2 · e
```
При `e = 0.60` крутизна на краю зростає до `1 + 2 · 0.60 = 2.20`. На краю хід стіка стає у 5.5 раза гострішим, ніж у центрі.

Коефіцієнт динамічного контрасту чутливості визначається як відношення крутизни на краю до крутизни в центрі:

```
K_contrast = S₁ / S₀ = (1 + 2 · e) / (1 - e)
```

При `e = 0.70` контраст чутливості сягає:

```
K_contrast = (1 + 1.40) / (1 - 0.70) = 2.40 / 0.30 = 8.0
```

Це означає, що при однаковому зміщенні стіка на 1 мм на краю діапазону приріст кутової швидкості буде у 8 разів більшим, ніж такий самий рух на 1 мм біля нуля.

### Монотонність та кривина

Для безпечного керування функція обов'язково повинна бути строго монотонною (`dy/dx > 0` для всіх `x ∈ (0, 1]`). Оскільки `e ∈ [0, 1)`, маємо:

```
1 - e > 0
3 · e · x² ≥ 0
dy/dx = (1 - e) + 3 · e · x² > 0
```

Функція не має локальних екстремумів всередині робочого діапазону. Друга похідна визначає кривину графіка (швидкість наростання чутливості):

```
d²y/dx² = d/dx [ (1 - e) + 3 · e · x² ]
d²y/dx² = 6 · e · x
```

Оскільки при `x > 0` і `e > 0` друга похідна `d²y/dx² > 0`, крива є строго опуклою вниз на відрізку `(0, 1]`. Точка `x = 0` є єдиною точкою перегину функції.

## Модель Betaflight SuperRate (Legacy)

У класичних версіях польотних контролерів розрахунок швидкості виконувався через гіперболічний множник:

```
x_exp = x · (1 - e) + x³ · e
ω(x)  = (200 · R_rc · x_exp) / (1 - x · R_super)
```

де `R_rc` — базовий RC Rate, `R_super ∈ [0, 0.95)` — коефіцієнт SuperRate.

### Гранична швидкість на упорі

При максимальному відхиленні стіка (`x = 1`, отже `x_exp = 1`):

```
ω_max = (200 · R_rc) / (1 - R_super)
```

Звідси видно математичну проблему моделі: максимальна швидкість є комбінацією двох взаємозалежних параметрів. Якщо пілот хоче змінити лише максимальну швидкість фліпу, змінюючи `R_super`, знаменник `(1 - x · R_super)` деформує всю другу половину ходу стіка.

### Чутливість у нулі

Обчислимо похідну швидкості `dω/dx` у точці `x = 0` за правилом диференціювання частки `u(x)/v(x)`:

```
u(x)  = 200 · R_rc · (x · (1 - e) + x³ · e)
u'(0) = 200 · R_rc · (1 - e)
v(x)  = 1 - x · R_super
v(0)  = 1
v'(0) = -R_super

dω/dx |_{x=0} = (u'(0) · v(0) - u(0) · v'(0)) / (v(0))²
dω/dx |_{x=0} = 200 · R_rc · (1 - e)
```

Чутливість у центрі взагалі не залежить від `R_super`, але залежить від `R_rc`. Проте зміна `R_rc` для коригування центру автоматично масштабує і максимальну швидкість `ω_max`. Ця перехресна залежність змушувала пілотів підбирати параметри методом тривалих ітерацій.

## Модель Actual Rates: повне розділення параметрів

Модель Actual Rates повністю позбавлена взаємного впливу налаштувань. Вона оперує трьома незалежними інженерними величинами:

```
C   [Center Sensitivity — чутливість центру, deg/s]
M   [Max Rate — максимальна швидкість на краю, deg/s]
e   [Expo — нелінійність переходу, від 0.0 до 1.0]
```

Для забезпечення підвищеної плавності біля центру в Actual Rates застосовується степенева крива 5-го порядку:

```
p(x) = x · (1 - e) + x⁵ · e
ω(x) = x · C + (M - C) · p(x)
```

### Перевірка граничних умов

1. **У нулі (`x = 0`):**
```
p(0) = 0
ω(0) = 0 · C + (M - C) · 0 = 0
```

2. **На упорі (`x = 1`):**
```
p(1) = 1 · (1 - e) + 1 · e = 1
ω(1) = 1 · C + (M - C) · 1 = M
```
Максимальна швидкість **завжди строго дорівнює M** незалежно від обраних `C` та `e`.

### Аналіз похідної моделі Actual Rates

Диференціюємо формулу кутової швидкості:

```
dp/dx = (1 - e) + 5 · e · x⁴
dω/dx = C + (M - C) · ( (1 - e) + 5 · e · x⁴ )
```

1. **Чутливість у нулі (`x = 0`):**
```
dω/dx |_{x=0} = C + (M - C) · (1 - e)
```
Якщо `e = 1.0` (максимальне пом'якшення):
```
dω/dx |_{x=0} = C
```
Параметр `C` буквально задає фізичну крутизну відгуку в центрі в одиницях `(deg/s)/хід`.

2. **Чутливість на упорі (`x = 1`):**
```
dp/dx |_{x=1} = (1 - e) + 5 · e = 1 + 4 · e
dω/dx |_{x=1} = C + (M - C) · (1 + 4 · e)
```
При `e = 0.5`, `C = 200`, `M = 800`:
```
dω/dx |_{x=1} = 200 + (800 - 200) · (1 + 2.0)
dω/dx |_{x=1} = 200 + 600 · 3 = 2000 deg/s на повний хід
```

### Інтегральна оцінка енергії керування

Оцінимо середнє квадратичне значення кутової швидкості (інтеграл енергії сигналу уставки при рівномірному розподілі положення стіка):

```
E_rate = ∫₀¹ [ ω(x) ]² dx
```

Для лінійної моделі `ω = M · x`:
```
E_linear = ∫₀¹ M² · x² dx = M² / 3 ≈ 0.333 · M²
```

Для моделі Actual Rates з високою експонентою більша частина інтеграла зосереджена біля одиниці:
```
E_actual ≈ 0.12 · M²
```

Це математично доводить, що при збереженні однакової максимальної кутової швидкості `M` модель з експонентою знижує середнє навантаження на силові приводи та акумулятор майже у 3 рази під час спокійного пілотування.

## Модель QuickRates (RaceFlight / Apex)

Альтернативний підхід, розроблений для швидкісних гоночних дронів, використовує поліном 3-го порядку замість 5-го:

```
ω_quick(x) = x · [ C + (M - C) · (x² · e + x · (1 - e)) ]
```

Головна відмінність QuickRates від Actual Rates полягає у швидкості наростання крутизни в середній зоні (`x ∈ [0.4, 0.7]`): кубічний поліном починає набирати кутову швидкість раніше, ніж поліном 5-го порядку. Це дає гонщику відчуття більш «пружного» та зібраного керування на середніх кутах нахилу траєкторії.
