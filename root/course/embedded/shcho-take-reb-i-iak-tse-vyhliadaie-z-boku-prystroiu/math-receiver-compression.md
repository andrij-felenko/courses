# 🧮 Нелінійний аналіз радіоприймача: компресія 1 дБ, інтермодуляція IP3 та блокування LNA

Коли на вхід малошумного підсилювача (LNA, англ. *Low-Noise Amplifier*) надходить слабкий корисний сигнал потужністю від −110 до −80 дБм, транзистори працюють у лінійному режимі, а вихідна напруга пропорційна вхідній. Проте в зоні дії станції радіоелектронної боротьби (РЕБ) на антену пристрою одночасно потрапляють потужні випромінювання рівня від −20 до +10 дБм. За таких амплітуд підсилювач перестає бути лінійним чотириполюсником. Нелінійні члени передавальної характеристики породжують три фізичні ефекти: компресію коефіцієнта підсилення, блокування слабкого сигналу потужною завадою (десенсибілізацію) та інтермодуляційні спотворення, що створюють паразитні сигнали прямо всередині робочого каналу.

Нижче наведено строге математичне виведення цих явищ на основі поліноміальної моделі нелінійного тракту без пам'яті.

---

## 1. Поліноміальна модель нелінійного підсилювача

Зв'язок між миттєвою вхідною напругою `x(t)` та вихідною напругою `y(t)` підсилювача без пам'яті апроксимується рядом Тейлора:

```
y(t) = a₁·x(t) + a₂·x²(t) + a₃·x³(t) + O(x⁴(t))
```

де:
* `a₁` — коефіцієнт лінійного підсилення за напругою (англ. *small-signal voltage gain*);
* `a₂` — коефіцієнт нелінійності другого порядку (відповідає за випрямлення та генерацію другої гармоніки);
* `a₃` — коефіцієнт нелінійності третього порядку (відповідає за компресію підсилення, десенсибілізацію та непарну інтермодуляцію). Для реальних підсилювачів із насиченням `a₃ < 0`.

У диференційних і симетричних RF-каскадах парні гармоніки пригнічуються симетрією схеми (`a₂ ≈ 0`), тому домінуючим чинником спотворень є член третього порядку `a₃`.

## 2. Однотоновий вплив та точка компресії 1 дБ (P1dB)

Подамо на вхід гармонічний сигнал амплітудою `A` та круговою частотою `ω`:

```
x(t) = A·cos(ω·t)
```

Підставимо `x(t)` у поліноміальну характеристику, враховуючи тригонометричні тотожності `cos²(α) = 1/2 + 1/2·cos(2α)` та `cos³(α) = 3/4·cos(α) + 1/4·cos(3α)`:

```
y(t) = a₁·(A·cos(ω·t)) + a₂·(A·cos(ω·t))² + a₃·(A·cos(ω·t))³
= a₁·A·cos(ω·t) + a₂·A²·(1/2 + 1/2·cos(2ω·t)) + a₃·A³·(3/4·cos(ω·t) + 1/4·cos(3ω·t))      [підстановка тригонометричних тотожностей]
= 1/2·a₂·A² + (a₁·A + 3/4·a₃·A³)·cos(ω·t) + 1/2·a₂·A²·cos(2ω·t) + 1/4·a₃·A³·cos(3ω·t)      [групування доданків за гармоніками]
```

Виділимо складову основної частоти `ω`:

```
y_fund(t) = (a₁ + 3/4·a₃·A²) · A · cos(ω·t)
```

Ефективний коефіцієнт підсилення за напругою для основної частоти становить:

```
G_eff(A) = a₁ + 3/4·a₃·A²
```

Оскільки `a₃ < 0`, зі зростанням амплітуди сигналу `A` ефективне підсилення `G_eff(A)` зменшується.

**Точка компресії на 1 дБ** за входом (англ. *1-dB Input Compression Point*, `A_1dB`) визначається як амплітуда вхідного сигналу, за якої підсилення зменшується на 1 дБ (тобто становить `10^(-1/20) ≈ 0.89125` від номінального значення `a₁`):

```
20·log₁₀ |G_eff(A_1dB) / a₁| = -1 дБ
= 20·log₁₀ |1 + 3/4·(a₃/a₁)·A_1dB²| = -1 дБ      [підстановка виразу для G_eff]
= 1 + 3/4·(a₃/a₁)·A_1dB² = 10^(-1/20)            [потенціювання обох частин рівняння]
= 3/4·|a₃/a₁|·A_1dB² = 1 - 0.89125 = 0.10875     [перенесення одиниці з урахуванням a₃ < 0]
= A_1dB² = (4 · 0.10875) / (3 · |a₃/a₁|)         [множення на 4/3 та ділення на коефіцієнти]
= 0.145 · |a₁ / a₃|                              [обчислення числового коефіцієнта]
```

Звідси вхідна амплітуда точки компресії:

```
A_1dB = √(0.145 · |a₁ / a₃|)
```

Перерахунок амплітуди напруги `A` на навантаженні `R_in = 50` Ом у потужність у дБм виконується за стандартною формулою:

```
P_дБм = 10·log₁₀( (A² / (2 · R_in)) / 10⁻³ )
= 10·log₁₀( A² / (2 · 50 · 10⁻³) )               [підстановка R_in = 50 Ом]
= 10·log₁₀( A² · 10 )                            [спрощення знаменника 100 · 10⁻³ = 0.1]
= 20·log₁₀(A) + 10                               [розклад логарифма добутку]
```

## 3. Двотоновий вплив: засліплення та десенсибілізація LNA

Розглянемо випадок, коли на антену пристрою одночасно надходить слабкий корисний сигнал амплітудою `A_s` на частоті `ω_s` та потужна завада РЕБ амплітудою `A_j` на частоті `ω_j`:

```
x(t) = A_s·cos(ω_s·t) + A_j·cos(ω_j·t)
```

де `A_j ≫ A_s`. Підставимо цю суму в нелінійний член третього порядку `a₃·x³(t)`:

```
(A_s·cos(ω_s·t) + A_j·cos(ω_j·t))³
= A_s³·cos³(ω_s·t) + 3·A_s²·A_j·cos²(ω_s·t)·cos(ω_j·t) + 3·A_s·A_j²·cos(ω_s·t)·cos²(ω_j·t) + A_j³·cos³(ω_j·t)      [біноміальний розклад куба суми]
```

Знайдемо внесок цього виразу у вихідний сигнал на корисній частоті `ω_s`. Член `3·A_s·A_j²·cos(ω_s·t)·cos²(ω_j·t)` розкладається так:

```
3·A_s·A_j²·cos(ω_s·t) · (1/2 + 1/2·cos(2ω_j·t))
= 3/2·A_s·A_j²·cos(ω_s·t) + 3/2·A_s·A_j²·cos(ω_s·t)·cos(2ω_j·t)                         [розкриття дужок множення]
= 3/2·A_s·A_j²·cos(ω_s·t) + 3/4·A_s·A_j²·(cos((2ω_j + ω_s)·t) + cos((2ω_j - ω_s)·t))     [перетворення добутку косинусів у суму]
```

Зберемо всі доданки на частоті корисного сигналу `ω_s` на виході підсилювача:

```
y_s(t) = (a₁·A_s + 3/4·a₃·A_s³ + 3/2·a₃·A_s·A_j²) · cos(ω_s·t)
```

Оскільки корисний сигнал слабкий (`A_s ≪ A_j`), членом `3/4·a₃·A_s³` можна знехтувати порівняно з `3/2·a₃·A_s·A_j²`. Тоді вираз для вихідної амплітуди корисного сигналу спрощується:

```
y_s(t) ≈ (a₁ + 3/2·a₃·A_j²) · A_s · cos(ω_s·t)
```

Ефективний коефіцієнт підсилення для корисного сигналу під дією завади становить:

```
G_s(A_j) = a₁ + 3/2·a₃·A_j²
```

Порівняємо десенсибілізацію від завади з власною компресією:
* Власна компресія підсилення: коефіцієнт при `A²` дорівнює `3/4·a₃`.
* Блокування від чужої завади: коефіцієнт при `A_j²` дорівнює `3/2·a₃`, що рівно вдвічі більше (`3/2 = 2 · 3/4`).

Це означає, що **зовнішня завада пригнічує підсилення корисного сигналу на 6 дБ ефективніше, ніж сигнал тієї самої потужності пригнічував би сам себе**.

Потужність блокування, за якої підсилення корисного сигналу падає на 1 дБ (вхідний рівень блокування, `A_block,1dB`), обчислюється так:

```
1 + 3/2·(a₃/a₁)·A_block,1dB² = 10^(-1/20) ≈ 0.89125
= A_block,1dB² = (2 · 0.10875) / (3 · |a₃/a₁|)   [перенесення одиниці та множення на 2/3]
= 0.0725 · |a₁ / a₃| = 1/2 · A_1dB²              [зв'язок з амплітудою точки компресії A_1dB]
```

В логарифмічному масштабі:

```
P_block,1dB = P_1dB - 3.01 дБ
```

Потужній заваді РЕБ достатньо мати потужність на 3 дБ нижчу за `P_1dB`, щоб обвалити чутливість корисного радіотракту на 1 дБ, навіть якщо сама завада розташована на іншій частоті та не проходить крізь вузькосмуговий фільтр проміжної частоти після змішувача.

## 4. Інтермодуляційні спотворення третього порядку (IMD3 та IIP3)

Якщо в ефірі присутні два потужні випромінювачі РЕБ на частотах `ω₁` та `ω₂` однакової амплітуди `A`:

```
x(t) = A·cos(ω₁·t) + A·cos(ω₂·t)
```

Розклад кубічного члена `(A·cos(ω₁·t) + A·cos(ω₂·t))³` породжує комбінаційні частоти третього порядку:

```
(cos(ω₁·t) + cos(ω₂·t))³
= cos³(ω₁·t) + 3·cos²(ω₁·t)·cos(ω₂·t) + 3·cos(ω₁·t)·cos²(ω₂·t) + cos³(ω₂·t)      [біноміальний розклад куба]
```

Розкладемо перехресний член `3·cos²(ω₁·t)·cos(ω₂·t)`:

```
3·(1/2 + 1/2·cos(2ω₁·t)) · cos(ω₂·t)
= 3/2·cos(ω₂·t) + 3/2·cos(2ω₁·t)·cos(ω₂·t)                                         [розкриття дужок множення]
= 3/2·cos(ω₂·t) + 3/4·cos((2ω₁ - ω₂)·t) + 3/4·cos((2ω₁ + ω₂)·t)                     [перетворення добутку косинусів]
```

Аналогічно другий перехресний член породжує частоту `2ω₂ - ω₁`.

Частоти `2ω₁ - ω₂` та `2ω₂ - ω₁` є **інтермодуляційними продуктами третього порядку** (IMD3). Їхня небезпека полягає в тому, що якщо дві завади розташовані з інтервалом `Δω = ω₂ - ω₁`, то частота `2ω₁ - ω₂ = ω₁ - Δω` лежить впритул до них і може точно потрапити у робочу смугу корисного каналу приймача `ω₀`.

Амплітуда вихідної напруги продукту IMD3 становить:

```
A_IMD3 = 3/4·|a₃|·A³
```

Амплітуда основного лінійного сигналу на виході:

```
A_fund = a₁·A
```

**Точка перетину третього порядку за входом** (IIP3, англ. *Input Third-Order Intercept Point*) — це теоретична амплітуда вхідного сигналу `A_IIP3`, за якої амплітуда інтермодуляційного продукту зрівнялася б із амплітудою основного тону:

```
a₁ · A_IIP3 = 3/4 · |a₃| · A_IIP3³
= 1 = 3/4 · |a₃ / a₁| · A_IIP3²                  [скорочення обох частин на a₁ · A_IIP3]
= A_IIP3² = 4/3 · |a₁ / a₃|                      [множення на 4/3 та ділення на |a₃/a₁|]
= A_IIP3 = √(4/3 · |a₁ / a₃|)                    [добування квадратного кореня]
```

Зв'яжемо амплітуду `A_IIP3` з амплітудою точки компресії `A_1dB`:

```
A_IIP3² / A_1dB²
= (4/3 · |a₁ / a₃|) / (0.145 · |a₁ / a₃|)        [підстановка аналітичних виразів для квадратів амплітуд]
= (4/3) / 0.145                                  [скорочення спільного множника |a₁/a₃|]
= 1.3333 / 0.145 ≈ 9.195                         [обчислення числового співвідношення]
```

Переведемо це відношення у децибели:

```
P_IIP3 - P_1dB
= 10·log₁₀(A_IIP3² / A_1dB²)                     [перехід до децибел потужності]
= 10·log₁₀(9.195) ≈ 9.64 дБ                      [обчислення логарифма співвідношення]
```

Звідси отримуємо канонічне інженерне співвідношення для радіотрактів:

```
P_IIP3 ≈ P_1dB + 9.6 дБ
```

## 5. Практичний розрахунок деградації тракту

Розглянемо типовий вхідний LNA сучасного трансивера 868/915 МГц (наприклад, інтегрований у CC1312 або SX1262):
* Лінійне підсилення за напругою `a₁ = 10` (підсилення потужності `G₀ = 20` дБ);
* Вхідна точка компресії `P_1dB = -15` дБм;
* Точка інтермодуляції `P_IIP3 = -15 + 9.6 = -5.4` дБм;
* Опір тракту `R = 50` Ом.

### Розрахунок коефіцієнтів моделі

Амплітуда напруги точки компресії `P_1dB = -15` дБм:

```
P_Вт = 10^((-15 - 30) / 10) = 10^(-4.5) ≈ 3.162 · 10⁻⁵ Вт
= A_1dB = √(2 · R · P_Вт)                        [формула амплітуди напруги на опорі R]
= √(2 · 50 · 3.162 · 10⁻⁵) = √(3.162 · 10⁻³)     [підстановка R = 50 Ом]
≈ 0.0562 В (56.2 мВ)                             [обчислення кореня]
```

Знайдемо коефіцієнт нелінійності `a₃`:

```
|a₃| = (0.145 · a₁) / A_1dB²
= (0.145 · 10) / (0.0562)²                       [підстановка a₁ = 10 та A_1dB = 0.0562 В]
= 1.45 / 0.003162 ≈ 458.5 В⁻²                    [обчислення значення коефіцієнта a₃]
```

### Вплив завади рівня −10 дБм

Нехай поруч працює завада потужністю `P_j = -10` дБм (`0.1` мВт):

```
P_j,Вт = 10⁻⁴ Вт
= A_j = √(2 · 50 · 10⁻⁴)                         [розрахунок амплітуди завади на 50 Ом]
= √0.01 = 0.1 В (100 мВ)                         [добування квадратного кореня]
```

Обчислимо ефективне підсилення для корисного сигналу `G_s(A_j)`:

```
G_s = a₁ - 3/2 · |a₃| · A_j²
= 10 - 1.5 · 458.5 · (0.1)²                      [підстановка a₁ = 10, a₃ = 458.5, A_j = 0.1 В]
= 10 - 6.877 = 3.123                             [обчислення результуючого лінійного підсилення]
```

Підсилення впало з `a₁ = 10` (20 дБ) до `G_s = 3.123` (`20·log₁₀(3.123) ≈ 9.89` дБ). Втрата підсилення становить понад 10 дБ:

```
ΔG = 20 дБ - 9.89 дБ = 10.11 дБ
```

### Рівень паразитного продукту IMD3

Якщо дві завади на частотах `f₁ = 910` МГц та `f₂ = 912.5` МГц мають рівні `P_j = -20` дБм (`A_j = 0.0316` В), вони породжують паразитну несучу на частоті `2·f₁ - f₂ = 907.5` МГц:

```
A_IMD3 = 3/4 · |a₃| · A_j³
= 0.75 · 458.5 · (0.0316)³                       [підстановка коефіцієнта a₃ та амплітуди A_j]
= 343.9 · 3.155 · 10⁻⁵ ≈ 0.01085 В               [обчислення амплітуди напруги IMD3 (10.85 мВ)]
```

Потужність цього паразитного сигналу на виході:

```
P_out,IMD3 = (A_IMD3)² / (2 · R)
= (0.01085)² / 100                               [підстановка напруги та опору 2·50 = 100 Ом]
= 1.177 · 10⁻⁶ Вт ≈ -29.3 дБм                    [перерахунок вихідної потужності у дБм]
```

Перерахована до входу LNA потужність фантомного сигналу становить `-29.3 дБм - 20 дБ = -49.3 дБм`. Для чутливого приймача LoRa або FSK (чиє порогове значення становить від −110 до −130 дБм) паразитний інтермодуляційний сигнал потужністю −49.3 дБм є нездоланною завадою, що перевищує корисний сигнал на 60–80 дБ.
