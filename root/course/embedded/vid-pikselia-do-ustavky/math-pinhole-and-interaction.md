# 🧮 Геометрія проекції та матриця взаємодії IBVS

Ця математична вставка містить аналітичне виведення прямого проекційного перетворення піксельних координат у промені візування, аналіз матриці взаємодії (образного якобіана) контуру Image-Based Visual Servoing (IBVS), доведення стійкості замкненого контуру за другим методом Ляпунова, а також аналітичну інверсію радіальної дисторсії оптичної системи.

## 1. Модель камери-обскури та калібрувальна матриця

Камера відображає тривимірну точку простору `P = [X, Y, Z]ᵀ` у системі координат камери (де вісь `Z` спрямована вздовж оптичної осі вперед, `X` — праворуч, `Y` — вниз) на двовимірну площину матриці сенсора у піксельні координати `p = [u, v]ᵀ`.

Центральна проекція точки на віртуальну площину зображення на фокусній відстані `f` задається відношенням подібності просторових трикутників:

```
x_n = X / Z          [нормалізована координата x: проекція на одиничну площину]
y_n = Y / Z          [нормалізована координата y: проекція на одиничну площину]
```

Перехід від неперервних нормалізованих координат `(x_n, y_n)` до дискретних піксельних координат `(u, v)` на матриці сенсора з фізичним кроком пікселів `(p_x, p_y)` та координатами головної точки (оптичного центра) `(c_x, c_y)` описується внутрішньою калібрувальною матрицею камери `K`:

```
fx = f / p_x         [фокусна відстань за віссю x у пікселях]
fy = f / p_y         [фокусна відстань за віссю y у пікселях]
```

У матричній однорідній формі проекційне рівняння зв'язує простір камери та дискретний масив сенсора:

```
s · [u, v, 1]ᵀ = K · [X, Y, Z]ᵀ

де K = ⎡ fx   0   cx ⎤
       ⎢  0  fy   cy ⎥
       ⎣  0   0    1 ⎦
```

Розкриваючи скалярне рівняння для масштабу `s = Z`, отримуємо прямий перехід від просторових координат до пікселів зображення:

```
u = fx · (X / Z) + cx = fx · x_n + cx   [піксельна координата стовпця]
v = fy · (Y / Z) + cy = fy · y_n + cy   [піксельна координата рядка]
```

### Зворотне перетворення: від пікселя до променя візування

Маючи виміряний детектором центр об'єкта `(u, v)`, обчислюємо нормалізовані координати камери:

```
x_n = (u − cx) / fx   [нормалізоване зміщення за горизонталлю]
y_n = (v − cy) / fy   [нормалізоване зміщення за вертикаллю]
```

Одиничний напрямний вектор променя візування (line-of-sight unit vector) `r_c` у системі координат камери:

```
r_c = [x_n, y_n, 1]ᵀ / √(x_n² + y_n² + 1)   [одиничний вектор напрямку на ціль]
```

Кути візування (азимут `α_x` та тангаж `α_y`) визначаються безпосередньо зі сферичної геометрії променя:

```
α_x = arctan(x_n) = arctan((u − cx) / fx)              [азимутальний кут наведення (yaw error)]
α_y = arctan(y_n / √(1 + x_n²)) ≈ arctan((v − cy) / fy)  [кут піднесення наведення (pitch error)]
```

Для вузьких та середніх кутів огляду (параксіальне наближення при `|x_n| ≪ 1`, `|y_n| ≪ 1`):

```
α_x ≈ (u − cx) / fx   [лінійне наближення кута рискання в радіанах]
α_y ≈ (v − cy) / fy   [лінійне наближення кута тангажу в радіанах]
```

## 2. Аналітична корекція та інверсія радіальної дисторсії

Реальні об'єктиви мають викривлення поля зору. Пряма модель дисторсії Брауна — Конраді відображає ідеальні неспотворені координати `(x_u, y_u)` у спотворені координати на сенсорі `(x_d, y_d)`:

```
r_u² = x_u² + y_u²
x_d = x_u · (1 + k1·r_u² + k2·r_u⁴ + k3·r_u⁶) + 2·p1·x_u·y_u + p2·(r_u² + 2·x_u²)
y_d = y_u · (1 + k1·r_u² + k2·r_u⁴ + k3·r_u⁶) + p1·(r_u² + 2·y_u²) + 2·p2·x_u·y_u
```

Для задач наведення виникає зворотна задача: детектор видає спотворені пікселі `(u_d, v_d)`, з яких ми отримуємо `(x_d, y_d) = ((u_d − cx)/fx, (v_d − cy)/fy)`, а для точного розрахунку кутів необхідно знайти ідеальні `(x_u, y_u)`.

Оскільки пряме аналітичне обернення полінома вищого степеня є громіздким, застосовують ітераційне уточнення за методом Ньютона — Рафсона або наближене асимптотичне розкладання в ряд Тейлора:

```
r_d² = x_d² + y_d²
x_u ≈ x_d / (1 + k1·r_d² + k2·r_d⁴)   [перше наближення інверсії дисторсії]
y_u ≈ y_d / (1 + k1·r_d² + k2·r_d⁴)
```

Для високоточних систем виконують 2 ітерації методу Ньютона для нев'язки `f(x_u) = x_u · (1 + k1·r_u²) − x_d = 0`:

```
x_u_(k+1) = x_u_(k) − (x_u_(k) · (1 + k1·r_k²) − x_d) / (1 + 3·k1·x_u_(k)² + k1·y_u_(k)²)   [ітерація Ньютона]
```

Ця ітерація збігається за 2 кроки з точністю менше 0.01 пікселя, що гарантує бездоганне відновлення кута навіть на краю поля зору ширококутної камери (FOV > 90°).

## 3. Матриця взаємодії IBVS (Image Jacobian)

Контур прямого візуального керування IBVS формує уставки руху платформи на основі швидкості зміни ознак у площині зображення.

Нехай вектор просторової швидкості камери відносно сцени складається з лінійної швидкості `v_c = [v_x, v_y, v_z]ᵀ` та кутової швидкості `ω_c = [ω_x, ω_y, ω_z]ᵀ`:

```
V_c = [v_x, v_y, v_z, ω_x, ω_y, ω_z]ᵀ   [6-компонентний твіст камери]
```

Зв'язок між швидкістю руху тривимірної точки `P = [X, Y, Z]ᵀ` та швидкістю камери:

```
Ṗ = −v_c − ω_c × P
```

Розкриваючи векторний добуток покомпонентно:

```
Ẋ = −v_x − ω_y · Z + ω_z · Y   [швидкість зміни координати X]
Ẏ = −v_y − ω_z · X + ω_x · Z   [швидкість зміни координати Y]
Ż = −v_z − ω_x · Y + ω_y · X   [швидкість зміни координати Z]
```

### Диференціювання нормалізованих координат зображення

Диференціюємо `x_n = X / Z` за часом за правилом похідної частки:

```
ẋ_n = (Ẋ · Z − X · Ż) / Z²          [похідна частки: d/dt(X/Z)]
    = (Ẋ / Z) − (X / Z) · (Ż / Z)     [розділення дробів]
    = (Ẋ / Z) − x_n · (Ż / Z)         [підстановка означення x_n = X/Z]
```

Підставляємо вирази для `Ẋ` та `Ż`:

```
ẋ_n = (−v_x − ω_y · Z + ω_z · Y) / Z − x_n · (−v_z − ω_x · Y + ω_y · X) / Z   [підстановка Ẋ та Ż]
    = −(v_x / Z) − ω_y + ω_z · (Y / Z) + (x_n · v_z / Z) + x_n · ω_x · (Y / Z) − x_n · ω_y · (X / Z)   [розкриття дужок]
    = −(1/Z) · v_x + 0 · v_y + (x_n / Z) · v_z + (x_n · y_n) · ω_x − (1 + x_n²) · ω_y + y_n · ω_z     [групування за компонентами твіста]
```

Аналогічно диференціюємо `y_n = Y / Z`:

```
ẏ_n = (Ẏ · Z − Y · Ż) / Z²          [похідна частки: d/dt(Y/Z)]
    = (Ẏ / Z) − y_n · (Ż / Z)         [підстановка означення y_n = Y/Z]
    = (−v_y − ω_z · X + ω_x · Z) / Z − y_n · (−v_z − ω_x · Y + ω_y · X) / Z   [підстановка Ẏ та Ż]
    = 0 · v_x − (1/Z) · v_y + (y_n / Z) · v_z + (1 + y_n²) · ω_x − (x_n · y_n) · ω_y − x_n · ω_z     [групування за компонентами твіста]
```

Об'єднуючи рівняння у матричну форму `ṡ = L_s · V_c`, де `s = [x_n, y_n]ᵀ`:

```
⎡ ẋ_n ⎤ = ⎡ −1/Z    0    x_n/Z    x_n·y_n     −(1+x_n²)     y_n  ⎤ ⎡ v_x ⎤
⎣ ẏ_n ⎦   ⎣   0   −1/Z   y_n/Z   1+y_n²      −x_n·y_n     −x_n  ⎦ ⎢ v_y ⎥
                                                                  ⎢ v_z ⎥
                                                                  ⎢ ω_x ⎥
                                                                  ⎢ ω_y ⎥
                                                                  ⎣ ω_z ⎦
```

Матриця `L_s` розмірності `2 × 6` називається **матрицею взаємодії** (Interaction Matrix або Image Jacobian).

## 4. Доведення стійкості замкненого контуру за Ляпуновим

Розглянемо закон керування для зведення похибки `e = s − s*` до нуля. Бажана швидкість зміни похибки задається лінійною пропорційною залежністю: `ė = −λ · e`, де `λ > 0` — коефіцієнт підсилення.

Оскільки `ė = ṡ = L_s · V_c`, уставка просторової швидкості камери обчислюється через псевдоінверсну матрицю Мура — Пенроуза `L_s⁺`:

```
V_c_sp = −λ · L_s⁺ · e
```

Оскільки точна глибина `Z` у матриці `L_s` невідома і замінюється наближеною оцінкою `Ẑ`, реальна матриця керування є `L̂_s⁺`. Дослідимо стійкість замкненої системи за допомогою скалярної функції Ляпунова:

```
V(e) = 1/2 · eᵀ · e   [додатно визначена квадратична функція похибки]
```

Диференціюємо функцію Ляпунова за часом:

```
V̇(e) = eᵀ · ė                           [похідна квадратичної форми V(e)]
     = eᵀ · (L_s · V_c_sp)               [підстановка ė = L_s · V_c_sp]
     = eᵀ · (L_s · (−λ · L̂_s⁺ · e))      [підстановка закону керування V_c_sp]
     = −λ · eᵀ · (L_s · L̂_s⁺) · e        [винесення скаляра −λ]
```

Для забезпечення асимптотичної стійкості похідна `V̇(e)` має бути строго від'ємно визначеною (`V̇ < 0` при `e ≠ 0`). Це еквівалентно умові додатної визначеності матричного добутку:

```
L_s · L̂_s⁺ > 0   [умова додатної визначеності]
```

Для чисто кутового керування або випадку, коли оцінка глибини задовольняє умову `Ẑ > 0` та `Z > 0`, матричний добуток є діагонально домінантним із додатними власними числами:

```
L_s · L̂_s⁺ ≈ (Ẑ / Z) · I₂ > 0
```

Це строго доводить, що **похибка наведення експоненційно прямує до нуля за умови, що оцінка глибини має правильний знак (`Ẑ > 0`)**. Навіть груба похибка в оцінці дистанції у 200–300% не призводить до розхитування контуру, а лише змінює фактичний час перехідного процесу.

## 5. Зв'язок систем координат: від камери до корпусу апарата

Польотний контролер оперує в системі координат корпусу (Body Frame: `X_b` — вперед, `Y_b` — праворуч, `Z_b` — вниз). Оптична вісь камери може бути нахилена на фіксований кут тангажу `θ_mount` (наприклад, курсова камера FPV-дрона нахилена вгору на 20°–30° для компенсації нахилу корпусу під час швидкісного польоту).

Матриця повороту від системи камери до системи корпусу `R_b_c`:

```
R_b_c = ⎡ cos(θ_m)   0   sin(θ_m) ⎤
        ⎢    0       1      0     ⎥
        ⎣ −sin(θ_m)  0   cos(θ_m) ⎦
```

Трансформація уставки кутових швидкостей камери `ω_c = [ω_x, ω_y, ω_z]ᵀ` в уставки кутових швидкостей корпусу `ω_b = [p, q, r]ᵀ`:

```
⎡ p_sp ⎤ = R_b_c · ⎡ ω_x_cam ⎤
⎢ q_sp ⎥           ⎢ ω_y_cam ⎥
⎣ r_sp ⎦           ⎣ ω_z_cam ⎦
```

При нульовому нахилі (`θ_m = 0`) отримуємо простий прямий зв'язок: уставка рискання корпусу `r_sp` керується горизонтальним зсувом цілі `x_n`, а уставка тангажу корпусу `q_sp` — вертикальним зсувом `y_n`.

## 6. Аналітичний розрахунок коефіцієнтів фільтра Калмана

Для одновимірного супроводу кутової координати динаміка цілі описується моделлю подвійного інтегратора в неперервному часі:

```
ẋ(t) = A · x(t) + w(t)   [рівняння стану: швидкість інтегрується в положення]
z(t) = H · x(t) + v(t)   [рівняння вимірювання детектора]
```

де матриці системи мають вигляд:

```
A = ⎡ 0  1 ⎤,   H = [ 1  0 ]
    ⎣ 0  0 ⎦
```

Спектральна щільність шуму процесу (випадкові прискорення цілі) становить `Q = diag(0, q_acc)`, а дисперсія шуму вимірювання детектора дорівнює `r_meas`.

У стаціонарному режимі матриця коваріації похибок `P` задовольняє алгебраїчне рівняння Ріккаті (Algebraic Riccati Equation, ARE):

```
A · P + P · Aᵀ − P · Hᵀ · r_meas⁻¹ · H · P + Q = 0   [неперервне рівняння Ріккаті]
```

Розкриваючи матричне рівняння покомпонентно для симетричної матриці `P = [[p11, p12], [p12, p22]]`:

```
2 · p12 − p11² / r_meas = 0                           [елемент (1,1)]
p22 − (p11 · p12) / r_meas = 0                         [елемент (1,2)]
−p12² / r_meas + q_acc = 0                             [елемент (2,2)]
```

Розв'язуючи систему рівнянь знизу вгору:

```
p12 = √(q_acc · r_meas)                                [дисперсія взаємної кореляції]
p11 = √(2 · p12 · r_meas) = √(2) · (q_acc · r_meas³)¹/⁴ [дисперсія оцінки кута]
p22 = (p11 · p12) / r_meas = √(2) · (q_acc³ · r_meas)¹/⁴ [дисперсія оцінки швидкості]
```

Оптимальні стаціонарні коефіцієнти підсилення Калмана `K = P · Hᵀ / r_meas = [K_angle, K_rate]ᵀ`:

```
K_angle = p11 / r_meas = √(2) · (q_acc / r_meas)¹/⁴   [підсилення за кутовою похибкою]
K_rate  = p12 / r_meas = √(q_acc / r_meas)             [підсилення за швидкістю]
```

Цей аналітичний результат встановлює прямий фізичний зв'язок між параметрами шумів та динамікою фільтра:
- Власна резонансна частота спостерігача: `ω_n = (q_acc / r_meas)¹/⁴` (рад/с).
- Коефіцієнт демпфування: `ζ = 1 / √2 ≈ 0.707` (оптимальне баттервортівське затухання без перерегулювання).

Знаючи частоту кадрів камери та очікувану динаміку маневру цілі, інженер може розрахувати коефіцієнти `Q` та `R` аналітично, без сліпого підбору «на око».
