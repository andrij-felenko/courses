# 🧮 Зимовий енергетичний баланс сонячного IoT-вузла

Енергетичний розрахунок сонячного пристрою для безперервної цілорічної роботи спирається на інтегральну нерівність: середня енергія генерації за добу в найнесприятливіший місяць року (грудень) повинна строго перевищувати сумарні добові втрати та споживання вузла, а місткість буферного акумулятора має покривати найдовшу статистичну серію суцільної хмарності з урахуванням температурного зниження доступної ємності та імпульсного падіння напруги на внутрішньому опорі.

## 1. Геометрія інсоляції та вибір оптимального кута нахилу

Для широти `φ = 50°` пн. ш. (Київ, Львів, Прага, Франкфурт) у день зимового сонцестояння (21–22 грудня) схилення сонця становить `δ = −23.45°`. Максимальний кут піднесення сонця над горизонтом опівдні `h_noon` дорівнює:

```
h_noon
= 90° − φ + δ                      [зенітна формула піднесення світила опівдні]
= 90° − 50° + (−23.45°)            [підстановка широти та зимового схилення]
= 16.55°                           [максимальна висота сонця над горизонтом у грудні]
```

Для порівняння, у день літнього сонцестояння (21–22 червня при `δ = +23.45°`):

```
h_noon_summer
= 90° − 50° + 23.45°               [висота літнього сонцестояння]
= 63.45°                           [майже вчетверо вище над горизонтом]
```

Оптимальний кут нахилу нерухомої фотоелектричної панелі до горизонту `α_opt` для максимального вловлювання прямого сонячного випромінювання взимку становить `α_opt = 90° − h_noon = 73.45°`. На практиці кут обирають у діапазоні `65° ≤ α ≤ 75°` або встановлюють панель вертикально (`α = 90°`), оскільки при кутах понад 65° мокрий сніг не затримується на гладкому склі й самостійно зісковзує під дією гравітації, не утворюючи блокуючого шару.

Оптична маса атмосфери `AM` *(Air Mass)*, яку проходить промінь при низькому зимовому сонці:

```
AM_winter
≈ 1 ÷ sin(h_noon)                  [наближення пласкої атмосфери для кутів > 15°]
≈ 1 ÷ sin(16.55°)                  [підстановка синуса кута піднесення]
≈ 1 ÷ 0.2849                       [обчислення відношення оптичних товщин]
≈ 3.51                             [довжина шляху в атмосфері в 3.51 раза більша за зеніт]
```

Для стандартних тестових умов (STC: `AM = 1.5`, інтенсивність `G_0 = 1000 Вт/м²`). За рахунок розсіювання Релея та поглинання аерозолями прямий сонячний потік у ясний грудневий день падає з 1000 Вт/м² до 550–650 Вт/м².

## 2. Розрахунок добової сонячної генерації у грудні

Добова енергія `E_gen`, яку віддає фотоелектрична панель через MPPT-контролер до акумулятора, визначається номінальною піковою потужністю панелі `P_peak` (при STC), еквівалентним числом пікових сонячних годин `PSH` *(Peak Sun Hours)* та інтегральним коефіцієнтом корисної дії тракту `η_sys`.

Для помірних широт (50° пн. ш.) середньомісячна багаторічна інсоляція у грудні на горизонтальну поверхню становить близько 0.60 кВт·год/(м²·добу). При нахилі панелі `α = 70°` інсоляція зростає за рахунок ортогональності до променів та відбиття від снігового покриву (альбедо снігу `A ≈ 0.60`):

```
PSH_winter = 0.85 год/добу      [середньодобова еквівалентна інсоляція при нахилі 70°]
P_peak     = 10.0 Вт            [номінальна пікова потужність фотопанелі при STC]
η_mppt     = 0.92               [ККД MPPT-перетворювача при малій потужності]
η_opt      = 0.90               [коефіцієнт пилу, обмерзання та відбиття скла]
η_temp     = 1.05               [позитивний температурний коефіцієнт напруги кремнію при −10 °C]
```

Розрахунок інтегрального коефіцієнта системи `η_sys` та виробленої енергії `E_gen`:

```
η_sys
= η_mppt · η_opt · η_temp          [добуток апаратного, оптичного та температурного ККД]
= 0.92 · 0.90 · 1.05               [підстановка коефіцієнтів]
= 0.8694                           [підсумковий ККД енергетичного збору]

E_gen
= P_peak · PSH_winter · η_sys      [добуток номінальної потужності, PSH та ККД]
= 10.0 Вт · 0.85 год · 0.8694       [підстановка зимових параметрів системи]
= 7.390 Вт·год/добу                [середньодобова вироблена енергія у грудні]
= 26604 Дж/добу                    [еквівалент у джоулях: 1 Вт·год = 3600 Дж]
```

У дні суцільної низької хмарності (стратус, туман) пряме випромінювання відсутнє, а розсіяне падає до 50–90 Вт/м², зменшуючи `PSH_cloudy` до 0.35 год/добу:

```
E_gen_cloudy
= 10.0 Вт · 0.35 год · 0.8694       [генерація під час суцільної хмарності]
= 3.043 Вт·год/добу                [10955 Дж/добу]
```

## 3. Енергетичний бюджет споживання та втрат

Добове споживання вузла `E_cons` складається з енергії періодичних сеансів зв'язку `E_active`, енергії глибокого сну вузла `E_sleep`, власного струму спокою MPPT-контролера `E_mppt_q`, імпульсних втрат на внутрішньому опорі батареї `E_ir` та енергії термостатування `E_heater`:

```
E_cons = E_active + E_sleep + E_mppt_q + E_ir + E_heater
```

Параметри бездротового вузла телеметрії (LoRaWAN / NB-IoT):

```
V_sys      = 3.3 В              [номінальна робоча напруга системної шини]
I_sleep    = 15.0 мкА           [струм глибокого сну з активним RTC]
P_sleep    = 3.3 В · 15 мкА     [потужність сну: 49.5 мкВт]
E_tx       = 0.45 Дж            [корисна енергія сеансу: опрос датчиків + TX 20 dBm]
I_tx_peak  = 140 мА             [піковий струм під час радіопередачі]
t_tx       = 0.95 с             [тривалість активної фази радіотракту]
I_q_mppt   = 1.20 мА            [струм спокою вимірювальних кіл MPPT-контролера]
```

При базовому інтервалі зв'язку раз на 15 хвилин (`N_trans = 96` сеансів на добу):

```
E_active
= 96 · 0.45 Дж                     [енергія 96 сеансів радіопередачі]
= 43.20 Дж/добу                    [0.0120 Вт·год/добу]

E_sleep
= 49.5 мкВт · 86400 с              [енергія фонового сну за 24 години]
= 4.277 Дж/добу                    [0.00119 Вт·год/добу]

E_mppt_q
= 3.3 В · 1.20 мА · 86400 с        [добові втрати на живлення кіл стеження MPPT]
= 342.14 Дж/добу                   [0.0950 Вт·год/добу]
```

Втрати енергії на внутрішньому опорі батареї `R_int` на морозі. При температурі −15 °C внутрішній опір зростає в 3–4 рази порівняно з кімнатною нормою, досягаючи `R_int = 0.35 Ом`:

```
P_loss_ir
= I_tx_peak² · R_int               [миттєва потужність теплових втрат на опорі комірки]
= (0.140 А)² · 0.35 Ом             [підстановка пікового струму передачі]
= 0.00686 Вт                       [6.86 мВт]

E_ir
= 96 · (P_loss_ir · t_tx)          [сумарні імпульсні втрати на добу]
= 96 · (0.00686 Вт · 0.95 с)       [підстановка кількості сеансів та тривалості]
= 0.626 Дж/добу                    [0.00017 Вт·год/добу]
```

Для батареї типу LiFePO4 масою `m = 0.30 кг` (питома теплоємність `c = 1000 Дж/(кг·К)`), нагрів із −15 °C до +2 °C (`ΔT = 17 К`) з ефективністю термоізольованого боксу `η_th = 0.70` вимагає:

```
Q_heat
= c · m · ΔT                       [термодинамічна теплота нагріву]
= 1000 Дж/(кг·К) · 0.30 кг · 17 К  [підстановка маси та перепаду температур]
= 5100 Дж                          [1.417 Вт·год теплоти]

E_heater
= Q_heat ÷ η_th                    [витрата електричної енергії з урахуванням розсіювання]
= 5100 ÷ 0.70                      [ділення на коефіцієнт збереження тепла]
= 7285.7 Дж/добу                   [2.024 Вт·год/добу]
```

Сумарне добове навантаження вузла в морозний день:

```
E_total_winter
= E_active + E_sleep + E_mppt_q + E_ir + E_heater
= 0.0120 + 0.00119 + 0.0950 + 0.00017 + 2.0240
= 2.1324 Вт·год/добу               [7676.5 Дж/добу]
```

Енергетичний баланс у хмарний день: `E_gen_cloudy − E_total_winter = 3.043 − 2.132 = +0.911 Вт·год/добу`. Система зберігає стабільний позитивний баланс навіть під час тривалої хмарності.

## 4. Розрахунок місткості акумулятора для серії темних діб

У разі затяжного снігопаду чи обмерзання генерація падає до нуля (`E_gen = 0`). Розрахуємо акумулятор для повної автономності протягом `N_dark = 14` діб зимового затемнення:

```
E_storage_raw
= N_dark · E_total_winter          [необхідний запас енергії на 14 діб]
= 14 · 2.1324 Вт·год               [добуток днів на добову норму]
= 29.85 Вт·год                     [107.46 кДж]
```

Два критичні обмежувальні фактори зимової експлуатації:
1. Температурний коефіцієнт доступної ємності при −20 °C: `k_temp = 0.70` (30% ємності блокується високим внутрішнім опором та сповільненням дифузії літію).
2. Максимальна глибина розряду `DoD_max = 0.80` (залишок 20% заряду гарантує захист від перерозряду комірок та збереження ресурсу циклування).

Номінальна паспортна ємність батареї при +25 °C (`E_batt_nom`):

```
E_batt_nom
= E_storage_raw ÷ (k_temp · DoD_max)      [перерахунок на паспортні умови]
= 29.85 ÷ (0.70 · 0.80)                   [підстановка температурного та розрядного бар'єрів]
= 29.85 ÷ 0.56                            [спільний коефіцієнт корисної віддачі]
= 53.30 Вт·год                            [номінальний запас енергії акумуляторного блоку]
```

Для збірки на LiFePO4 з номінальною напругою банки `V_nom = 3.2 В`:

```
C_Ah_nom
= E_batt_nom ÷ V_nom               [електрична місткість у ампер-годинах]
= 53.30 Вт·год ÷ 3.2 В             [ділення енергії на робочу напругу]
= 16.66 А·год                      [16660 мА·год]
```

Це відповідає збірці з 5–6 паралельних елементів типу 32700 або єдиному промисловому призматичному модулю.

## 5. Імпульсне просідання напруги та поріг відсічки Brownout

Під час передачі пакету піковий струм `I_tx_peak = 140 мА` викликає миттєве просідання напруги на виводах батареї `ΔV_drop` через динамічний опір:

```
ΔV_drop
= I_tx_peak · R_int                [закон Ома для внутрішнього опору]
= 0.140 А · 0.35 Ом                [підстановка струму передавача та зимового опору]
= 0.049 В                          [49 мВ миттєвого спаду]
```

Якщо напруга розімкненого кола розрядженого LiFePO4 на морозі становить `V_ocv = 3.05 В`, фактична напруга на шині під імпульсним навантаженням падає до:

```
V_load
= V_ocv − ΔV_drop                  [фактична напруга на шині живлення]
= 3.05 В − 0.049 В                 [віднімання імпульсного спаду]
= 3.001 В                          [безпечний запас над порогом UVLO 2.70 В]
```

## 6. Розрахунок часу виживання в адаптивному режимі консервації

Якщо блекаут триває понад 14 діб і заряд падає до `SoC = 15%`, алгоритм Dynamic Duty Cycling повністю вимикає підігрів (`E_heater = 0`), переводить MPPT у мікропотужний режим (`I_q_mppt_sleep = 20 мкА`) та збільшує інтервал передачі телеметрії до 1 разу на 12 годин (`N_trans = 2` сеанси/добу):

```
E_throttled
= (2 · 0.45 Дж) + (49.5 мкВт · 86400 с) + (3.3 В · 20 мкА · 86400 с)
= 0.90 Дж + 4.28 Дж + 5.70 Дж      [активна передача + сон MCU + чергування MPPT]
= 10.88 Дж/добу                    [0.00302 Вт·год/добу]
```

Залишкова доступна енергія акумулятора при 15% SoC (з урахуванням `k_temp = 0.70`):

```
E_rem
= E_batt_nom · 0.15 · k_temp       [залишок корисної енергії в батареї]
= 53.30 Вт·год · 0.15 · 0.70       [підстановка початкової ємності та залишку]
= 5.596 Вт·год                     [20147 Дж]
```

Тривалість автономного чергування в режимі виживання `T_survival`:

```
T_survival
= E_rem ÷ E_throttled              [кількість діб до повного вичерпання залишку]
= 5.596 Вт·год ÷ 0.00302 Вт·год/добу [ділення залишкової енергії на адаптивне споживання]
= 1853 доби                        [понад 5 років теоретичної автономності]
```

## 7. Розрахунок енергії виходу з блекауту

Після виснаження батареї до порогу відсічки консервації (`SoC ≤ 5%`, `V_cell ≈ 2.80 В`) повернення системи в активний робочий режим потребує обов'язкового накопичення гістерезисного енергетичного запасу `ΔE_hyst`. Поріг відновлення встановлюється на рівні `SoC_recovery = 25%` (`V_cell ≥ 3.40 В` при зарядному струмі):

```
ΔE_hyst
= E_batt_nom · (SoC_recovery − SoC_cutoff)
= 53.30 Вт·год · (0.25 − 0.05)     [енергія накопичення 20% ємності]
= 10.66 Вт·год                     [38376 Дж]
```

При середньодобовій зимовій генерації у грудні `E_gen = 7.390 Вт·год/добу` та мінімальному споживанні під час консервації (`E_cons_hib ≈ 0.002 Вт·год/добу`):

```
T_recovery
= ΔE_hyst ÷ (E_gen − E_cons_hib)   [час поповнення гістерезисного буфера]
= 10.66 Вт·год ÷ 7.388 Вт·год/добу [ділення дефіциту на корисний баланс заряду]
= 1.44 доби                        [близько 35 годин суцільного зимового циклу]
```

Отриманий числовий результат доводить, що системі достатньо півтора помірно сонячного зимового дня для повного відновлення активної роботи без ризику повторного зриву в циклічне перезавантаження.
