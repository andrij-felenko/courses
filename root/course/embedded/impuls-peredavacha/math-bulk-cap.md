# 🧮 Розрахунок буферної ємності та динаміки відновлення шини живлення

Математичний розрахунок перехідних процесів у колі живлення радіопередавача базується на законі збереження електричного заряду та аналітичному розв'язку диференціального рівняння розряду й заряду конденсатора. Коли джерело живлення має значний внутрішній опір (як літієвий дисковий елемент CR2032 з опором `R_int = 15..50 Ом` або підвідні провідники зі стабілізатором LDO), імпульс струму вихідного підсилювача передавача `I_tx` практично повністю лягає на паралельно підключену буферну ємність `C_bulk`.

Цей аналіз визначає точне значення необхідної номінальної ємності з урахуванням еквівалентного послідовного опору (ESR), втрати ємності під постійною напругою зміщення (DC Bias) для кераміки MLCC та необхідного часу релаксації між пакетами.

---

## 1. Баланс заряду та виведення мінімальної ємності

Нехай радіомодуль випромінює пакет тривалістю `Δt` зі споживанням струму `I_tx`. Припустимо найгірший випадок, коли весь струм імпульсу постачається виключно буферним конденсатором `C` (струм від батареї обмежений великим опором `R_int`).

Зв'язок між струмом розряду та швидкістю спаду напруги на обкладках задається фундаментальним рівнянням конденсатора:

```formula
I(t) = C · (dV / dt)
```

Інтегруючи струм за час передачі пакета `Δt` при сталому значенні `I_tx`:

```
ΔQ = ∫[0..Δt] I_tx dt
= I_tx · Δt                   [інтегрування сталого струму]
= C · ΔV_cap                  [визначення ємності: Q = C·V]
```

Звідси спад напруги на суто ємнісній складовій `ΔV_cap`:

```
ΔV_cap = (I_tx · Δt) / C
```

Повний спад напруги на клемах конденсатора `ΔV_total` складається з миттєвого омічного стрибка на еквівалентному послідовному опорі `ESR` (англ. *Equivalent Series Resistance*) та похилого спаду через втрату заряду:

```
ΔV_total = ΔV_esr + ΔV_cap
= I_tx · ESR + (I_tx · Δt) / C  [сума омічного та ємнісного спадів]
```

Щоб мікроконтролер не пішов на апаратне перезавантаження Brown-out Reset (BOR), залишкове значення напруги на шині `V_bus(t)` у найнижчій точці імпульсу `t = Δt` має строго перевищувати максимальний поріг спрацьовування компаратора BOR `V_bor_max` із запасом надійності `V_margin` (зазвичай `100..200 мВ` проти шуму й пульсацій):

```
V_min = V_init - ΔV_total ≥ V_bor_max + V_margin
```

Звідси гранично допустиме просідання напруги `ΔV_allowed`:

```
ΔV_allowed = V_init - V_bor_max - V_margin
```

Прирівнюючи `ΔV_total ≤ ΔV_allowed`:

```
I_tx · ESR + (I_tx · Δt) / C_eff ≤ ΔV_allowed       [умова непорушності живлення]
= (I_tx · Δt) / C_eff ≤ ΔV_allowed - I_tx · ESR      [перенесення омічного члена]
= C_eff ≥ (I_tx · Δt) / (ΔV_allowed - I_tx · ESR)    [вираження ємності]
```

Де:
- `C_eff` — ефективна (фактична) ємність на робочій напрузі;
- `V_init` — початкова напруга на шині перед стартом передачі (В);
- `V_bor_max` — максимальний рівень порогу BOR за даташитом МК (В);
- `V_margin` — інженерний запас надійності (В);
- `I_tx` — піковий струм споживання радіотракту під час передачі (А);
- `Δt` — тривалість випромінювання пакета в ефірі (с);
- `ESR` — еквівалентний послідовний опір конденсатора (Ом).

## 2. Числовий приклад: передавач LoRa на батареї CR2032

Розглянемо практичний інженерний розрахунок для автономного маяка:
- Джерело: літієвий елемент CR2032, напруга `V_init = 2.8 В` (частково розряджена батарея);
- Радіомодуль: Semtech SX1262, режим передачі `+14 dBm`, струм `I_tx = 120 мА = 0.12 А`;
- Тривалість пакета: коротка телеметрія (SF7, BW 500 кГц, 16 байтів), `Δt = 12 мс = 0.012 с`;
- Мікроконтролер: STM32L4, поріг BOR рівень 0 (`V_bor_max = 2.0 В`);
- Запас надійності: `V_margin = 0.15 В`;
- Конденсатор: полімерний танталовий POSCAP з `ESR = 40 мОм = 0.040 Ом`.

### Крок 1. Розрахунок допустимого просідання напруги

```
ΔV_allowed = V_init - V_bor_max - V_margin
= 2.8 - 2.0 - 0.15          [підстановка значень напруг]
= 0.65 В                    [результат допустимого спаду]
```

### Крок 2. Розрахунок омічного падіння на ESR

```
ΔV_esr = I_tx · ESR
= 0.12 · 0.040              [закон Ома для ESR]
= 0.0048 В                  [4.8 мВ омічного падіння]
```

Оскільки опір POSCAP малий, `ΔV_esr` забирає менше `1%` допустимого бюджету. Допустимий спад на ємності:

```
ΔV_cap_allowed = ΔV_allowed - ΔV_esr
= 0.65 - 0.0048             [віднімання омічного падіння]
= 0.6452 В                  [запас для ємнісного розряду]
```

### Крок 3. Розрахунок мінімальної ефективної ємності

```
C_eff ≥ (I_tx · Δt) / ΔV_cap_allowed
= (0.12 · 0.012) / 0.6452   [підстановка заряду та спаду]
= 0.00144 / 0.6452          [обчислення відношення]
≈ 0.002232 Ф                [2232 мкФ мінімальної ємності]
```

Якщо тривалість передачі становить `12 мс`, для утримання напруги в межах `0.65 В` потрібна ефективна ємність щонайменше `2230 мкФ`.

Якщо скоротити пакет за рахунок оптимізації модуляції (наприклад, перехід на FSK/GFSK зі швидкістю 100 кбіт/с, де `Δt = 2 мс`):

```
C_eff(2 мс) ≥ (0.12 · 0.002) / 0.6452
= 0.00024 / 0.6452          [заряд за 2 мс]
≈ 0.000372 Ф                [372 мкФ для короткого пакета]
```

Для 2-мс імпульсу достатньо ємності `370..470 мкФ`.

## 3. Корекція на ефект постійного зміщення діелектрика (DC Bias Derating)

Для багатошарових керамічних конденсаторів (MLCC, англ. *Multi-Layer Ceramic Capacitor*) класу II (діелектрики `X5R`, `X7R`, `Y5V`) діє квантово-механічний ефект насичення спонтанної поляризації доменів титанату барію (`BaTiO3`). При прикладанні постійної напруги діелектрична проникність `ε_r` різко зменшується.

Фактична ємність `C_eff(V)` описується емпіричною залежністю:

```
C_eff(V) = C_nom · k_bias(V, Size, V_rated) · (1 - Tol) · (1 - k_temp)
```

Де:
- `C_nom` — номінальна ємність за маркуванням при `0 В` зміщення;
- `k_bias(V)` — коефіцієнт деградації від напруги (за графіком виробника);
- `Tol` — виробничий допуск (наприклад, `±20% → Tol = 0.20`);
- `k_temp` — температурний дрейф діелектрика (для X5R у діапазоні `-20..+70 °C` спад становить до `15% → k_temp = 0.15`).

### Приклад деградації MLCC 100 мкФ 0805 на напрузі 3.3 В

Типовий керамічний конденсатор `100 мкФ / 6.3 В` у корпусі `0805` діелектрика `X5R`:
1. При напрузі `V_bias = 3.0 В` (половина номіналу) `k_bias ≈ 0.35` (втрата 65% ємності!);
2. Врахування допуску виробництва `-20%`: множник `0.80`;
3. Врахування охолодження до `-10 °C`: множник `0.85`.

Результуюча ефективна ємність одного корпусу:

```
C_eff_1 = 100 мкФ · 0.35 · 0.80 · 0.85
= 23.8 мкФ                  [фактична залишкова ємність]
```

Щоб отримати розрахункові `C_eff = 372 мкФ`, потрібно встановити:

```
N = C_eff / C_eff_1
= 372 / 23.8                [кількість корпусів паралельно]
≈ 15.6                      [округлення до 16 штук]
```

Це демонструє, чому для великих буферних ємностей використовують полімерні танталові конденсатори (POSCAP/KO-CAP), де `k_bias = 1.0` (поляризація танталу не деградує від постійної напруги).

## 4. Динаміка відновлення заряду шини (Recharge Time)

Після завершення передачі передавач вимикається, і конденсатор `C_bulk` починає заряджатися від батареї через її внутрішній опір `R_int`. Схема перетворюється на класичне RC-коло заряду.

Напруга на конденсаторі в процесі заряду описується експоненційним законом:

```
V_bus(t) = V_bat - (V_bat - V_min) · e^(-t / τ)
```

Де:
- `V_bat` — напруга розімкненого кола джерела (ЕРС);
- `V_min` — напруга на шині в момент завершення передачі;
- `τ = R_int · C_bulk` — стала часу кола заряду (с).

### Розрахунок часу повного відновлення

Конденсатор вважається зарядженим до `95%` від початкового рівня за час `t = 3 · τ`, а до `99%` — за час `t = 5 · τ`.

Для батареї CR2032 (`R_int = 30 Ом`) та буферної ємності `C_bulk = 470 мкФ`:

```
τ = R_int · C_bulk
= 30 · 470 · 10⁻⁶           [підстановка опору та ємності]
= 0.0141 с                  [стала часу 14.1 мс]
```

Час до відновлення 99% початкової напруги:

```
t_recharge = 5 · τ
= 5 · 14.1 мс               [п'ять сталих часу для заряду до 99%]
= 70.5 мс                   [необхідна пауза між передачами]
```

Якщо мікроконтролер спробує надіслати повторний пакет раніше ніж через `70 мс`, передача почнеться з неповною напругою `V_init' < V_init`, і сумарне просідання гарантовано досягне порогу BOR.

```
Мінімальний інтервал між пакетами:  t_interval ≥ t_tx + 5 · R_int · C_bulk
```

## 5. Підсумкова інженерна таблиця вибору технології конденсатора

| Тип конденсатора | Питома ємність | ESR (100 кГц) | DC-bias деградація | Струм витоку (25 °C) | Температурна стабільність (-20 °C) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Кераміка MLCC X5R/X7R** | Середня | Ультранизький (<10 мОм) | Критична (-50..-80%) | Дуже низький (<10 нА) | Добра (ESR майже не росте) |
| **Полімерний тантал (POSCAP)** | Висока | Дуже низький (20..50 мОм) | Відсутня (0%) | Помірний (1..5 мкА) | Відмінна |
| **Звичайний тантал (MnO2)** | Висока | Середній (0.5..2 Ом) | Відсутня (0%) | Низький (0.5..2 мкА) | Добра |
| **Алюмінієвий електроліт** | Дуже висока | Високий (1..5 Ом) | Відсутня (0%) | Помірний (2..10 мкА) | Критична (ESR зростає в 10 разів) |
| **Суперконденсатор (EDLC)** | Екстремальна | Високий (10..50 Ом) | Відсутня (0%) | Високий (2..20 мкА) | Задовільна |

Для автономних радіовузлів найкращим балансом надійності, габаритів та стійкості до деградації є комбінація: **1× полімерний танталовий конденсатор 220–470 мкФ (низький ESR, стабільна ємність) паралельно з 2× MLCC 10 мкФ X7R 1206 (фільтрація високочастотних RF-гармонік)**.
