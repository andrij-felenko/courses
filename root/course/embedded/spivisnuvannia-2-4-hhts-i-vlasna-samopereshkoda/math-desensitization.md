# 🧮 Розрахунок десенситизації LNA та розв'язки колокрованих антен

Розрахунок визначає кількісну деградацію чутливості приймача (десенситизацію), зростання ефективного коефіцієнта шуму та рівень інтермодуляційних завад під дією випромінювання потужного сусіднього передавача на одній друкованій платі. Матеріал надає повний математичний апарат для оцінки необхідної просторової, фільтрової та часової ізоляції між радіотрактами стандарту IEEE 802.11 (Wi-Fi) та IEEE 802.15.4 / Bluetooth Low Energy (BLE).

---

## 1. Нелінійна модель LNA та співвідношення точок P1dB та IIP3

Вхідний каскад малошумлячого підсилювача (LNA) на польових або біполярних транзисторах описується нелінійною функцією передачі за напругою, яку можна розкласти в ряд Тейлора за степенями вхідного сигналу:

```
v_out(t) = a_1 * v_in(t) + a_2 * v_in(t)^2 + a_3 * v_in(t)^3 + ...
```

Коефіцієнт `a_1` відповідає лінійному підсиленню за малого сигналу (Small-Signal Gain). Коефіцієнт `a_2` породжує постійну складову та гармоніки другого порядку, а коефіцієнт `a_3` (який для реальних підсилювачів має від'ємний знак) спричиняє компресію підсилення для великого сигналу та створює інтермодуляцію третього порядку.

Якщо на вхід подається двочастотний сигнал `v_in(t) = V * (cos(omega_1 * t) + cos(omega_2 * t))`, амплітуда вихідного коливання на основній частоті становить:

```
V_out(omega_1) = (a_1 * V + (3/4) * a_3 * V^3)
```

Точка компресії на 1 дБ за входом (`P_1dB`) визначається як рівень вхідної потужності, за якого коефіцієнт підсилення падає на 1 дБ відносно лінійного значення `a_1`. Теоретична точка перехоплення третього порядку за входом (`IIP3`) — це екстрапольований рівень вхідної потужності, де амплітуда продуктів третього порядку дорівнювала б амплітуді основної гармоніки.

Між `P_1dB` та `IIP3` існує фундаментальне теоретичне співвідношення для безінерційних підсилювачів з кубічною нелінійністю:

```
IIP3 = P_1dB + 9.63 dB                                           [теоретичний зв'язок точок перехоплення та компресії]
```

Для інтегрованих RF-трансиверів діапазону 2,4 ГГц типове значення `P_1dB` складає від -15 до -10 dBm, а `IIP3` знаходиться в межах від -5 до 0 dBm.

## 2. Модель деградації коефіцієнта шуму та розрахунок втрати чутливості

Потужність блокуючої завади, яка потрапляє на вхідний пін LNA приймача, розраховується з урахуванням вихідної потужності передавача та сумарного згасання в тракті:

```
P_in_block = P_tx - L_iso - L_filt
```
де:
- `P_tx` — вихідна потужність передавача Wi-Fi, виражена в `dBm`;
- `L_iso` — просторова та поляризаційна розв'язка між антенами на друкованій платі, `dB`;
- `L_filt` — згасання смугового фільтра (RF Bandpass / SAW / BAW) на частоті завади, `dB`.

Коли рівень блокера `P_in_block` наближається до точки компресії `P_1dB`, зростання ефективного коефіцієнта шуму каскаду описується напівемпіричною моделлю десенситизації:

```
деградація_NF = 10 * log10(1 + 10^((P_in_block - P_1dB) / 10))   [зростання шумової полиці LNA, dB]
NF_eff        = NF_0 + деградація_NF                             [підсумковий коефіцієнт шуму, dB]
```

Чутливість приймача `S` для заданої шумової смуги `BW` та мінімально необхідного відношення сигнал/шум `SNR_min` для демодуляції розраховується за класичною формулою:

```
S_0   = -174 + 10 * log10(BW) + NF_0 + SNR_min                   [вихідна чутливість без завад, dBm]
S_eff = S_0 + деградація_NF                                      [реальна чутливість під час передачі завади, dBm]
```

де `-174 dBm/Hz` — спектральна густина теплового шуму за кімнатної температури (290 К).

## 3. Зворотне змішування шуму гетеродина (Reciprocal Mixing)

У супергетеродинних приймачах та приймачах прямого перетворення (Zero-IF / Low-IF) завада діє не лише на перший транзистор LNA, але й проходить на змішувач частоти.

Фазовий шум синтезатора гетеродина `L(delta_f)` (виражається в `dBc/Hz`) змішується з потужною позасмуговою несного коливання завади на відступі `delta_f = |f_block - f_rx|`. Це явище переносить енергію фазового шуму прямо в корисну смугу проміжної частоти.

Потужність шуму зворотного змішування на виході змішувача визначається рівнянням:

```
P_rm = P_in_block + L(delta_f) + 10 * log10(BW)
```

Щоб шум зворотного змішування не погіршував чутливість приймача більше ніж на 1 дБ, потужність `P_rm` повинна бути щонайменше на 6 дБ нижчою за власний тепловий шум приймача у відповідній смузі:

```
P_rm <= P_thermal - 6.0 dB
P_in_block + L(delta_f) + 10 * log10(BW) <= -174 + 10 * log10(BW) + NF_0 - 6.0
P_in_block <= -180 + NF_0 - L(delta_f)
```

Для типового приймача з `NF_0 = 4.0 dB` та фазовим шумом синтезатора `L(13 MHz) = -135 dBc/Hz` максимально допустимий рівень блокера за критерієм зворотного змішування складає:

```
P_in_block_max_rm = -180 + 4.0 - (-135.0) = -41.0 dBm
```

Цей результат доводить, що зворотне змішування фазового шуму є набагато жорсткішим обмеженням, ніж компресія підсилення LNA: для запобігання підйому шумової полиці потрібна сумарна ізоляція понад 61 дБ (`+20 dBm - (-41 dBm)`).

## 4. Інтермодуляція третього порядку (IMD3) у багатосигнальному середовищі

Якщо на нелінійний вхідний каскад надходять два потужні сигнали на частотах `f_1` (наприклад, несні Wi-Fi) та `f_2` (наприклад, інший передавач або потужна гармоніка), продукти нелінійності третього порядку породжують завади на частотах:

```
f_imd3_a = 2 * f_1 - f_2
f_imd3_b = 2 * f_2 - f_1
```

Потужність інтермодуляційної складової третього порядку за входом розраховується за формулою:

```
P_imd3 = 2 * P_in1 + P_in2 - 2 * IIP3
```

Якщо `P_in1 = P_in2 = P_in`, формула спрощується до:

```
P_imd3 = 3 * P_in - 2 * IIP3
```

Якщо частота `f_imd3` потрапляє в смугу корисного каналу Zigbee/BLE, вона діє як еквівалентний шум. Щоб рівень `P_imd3` не перевищував поріг чутливості `-95 dBm` для приймача з `IIP3 = 0 dBm`, максимальна потужність завад на вході не повинна перевищувати:

```
3 * P_in - 2 * 0.0 <= -95.0
P_in <= -95.0 / 3 = -31.67 dBm
```

## 5. Комплексний числовий приклад розрахунку для комбо-вузла (Wi-Fi + Zigbee)

Розглянемо практичний інженерний розрахунок для комбінованого шлюзу Інтернету речей (IoT Gateway), де на одній платі розміщено передавач Wi-Fi (ESP32) та приймач Zigbee (nRF52840).

### Вхідні інженерні параметри

```
Потужність передавача Wi-Fi (P_tx)       = +20.0 dBm    (100 мВт, канал 1: 2412 МГц)
Частота приймача Zigbee (f_rx)            = 2425.0 МГц    (канал 15, delta_f = 13 МГц)
Шумова смуга Zigbee (BW)                  = 2.0 МГц       (10*log10(BW) = 63.0 dB*Hz)
Власний коефіцієнт шуму Zigbee (NF_0)     = 4.0 dB
Вхідна точка 1 дБ компресії (P_1dB)      = -10.0 dBm
Точка перехоплення IIP3                   = 0.0 dBm
Мінімально необхідне SNR_min              = 4.0 dB
Фазовий шум на розстрочці 13 МГц          = -135.0 dBc/Hz
Просторова розв'язка антен на PCB (L_iso) = 22.0 dB
Додаткова фільтрація (L_filt)             = 0.0 dB       (без зовнішнього RF-фільтра)
```

### Покроковий розрахунок параметрів деградації

```
[Крок 1: Розрахунок потужності завади на вході LNA Zigbee]
P_in_block = P_tx - L_iso - L_filt                               [віднімання загасання в тракті]
           = 20.0 - 22.0 - 0.0                                   [підстановка значень потужності та розв'язки]
           = -2.0 dBm                                            [потужність завади на піні мікросхеми]

[Крок 2: Оцінка перевантаження точки стиснення P_1dB]
delta_P1dB = P_in_block - P_1dB                                  [різниця між рівнем сигналу та точкою компресії]
           = -2.0 - (-10.0)                                      [підстановка значень рівня та P1dB]
           = +8.0 dB                                             [передавач перевантажує вхід на 8 дБ понад P1dB]

[Крок 3: Розрахунок деградації коефіцієнта шуму LNA]
деградація_NF = 10 * log10(1 + 10^(8.0 / 10))                    [формула зростання шумової полиці LNA]
              = 10 * log10(1 + 6.31)                             [потенціювання відносного перевищення]
              = 10 * log10(7.31)                                 [сума теплового шуму та шуму компресії]
              = 8.64 dB                                          [деградація коефіцієнта шуму]

[Крок 4: Підсумковий коефіцієнт шуму та реальна чутливість]
NF_eff = NF_0 + деградація_NF                                    [підсумовування власного та наведеного шуму]
       = 4.0 + 8.64                                              [підстановка початкового шуму та деградації]
       = 12.64 dB                                                [реальний коефіцієнт шуму LNA під завадою]

S_0    = -174.0 + 63.0 + 4.0 + 4.0                               [розрахунок чутливості у чистому ефірі]
       = -103.0 dBm                                              [вихідна чутливість без завад]

S_eff  = S_0 + деградація_NF                                     [зміщення чутливості на величину деградації]
       = -103.0 + 8.64                                           [підстановка значень]
       = -94.36 dBm                                              [падіння енергетичного запасу лінка на 8.64 дБ]

[Крок 5: Оцінка шуму зворотного змішування фазового шуму]
P_rm = P_in_block + L(delta_f) + 10 * log10(BW)                  [перенесення фазового шуму в смугу каналу]
     = -2.0 + (-135.0) + 63.0                                    [підстановка потужності, фазового шуму і смуги]
     = -74.0 dBm                                                 [рівень шуму зворотного змішування на IF]

[Крок 6: Порівняння з власним тепловим шумом приймача]
P_thermal = -174.0 + 63.0 + 4.0                                  [тепловий шум у смузі 2 МГц]
          = -107.0 dBm                                           [власний фоновий шум каскаду]

перевищення_шуму = P_rm - P_thermal                              [відносне перевищення фону]
                 = -74.0 - (-107.0)                              [підстановка рівнів шуму]
                 = +33.0 dB                                      [фазовий шум передавача на 33 дБ вищий за фон!]
```

## 6. Розрахунок граничних вимог до ізоляції та фільтрації

Щоб утримати деградацію чутливості приймача на рівні не більше ніж `1.0 dB`, потужність завади на вході LNA мусить задовольняти математичну нерівність:

```
10 * log10(1 + 10^((P_in_block - P_1dB) / 10)) <= 1.0 dB          [допустиме зростання NF не більше 1 дБ]
1 + 10^((P_in_block - P_1dB) / 10)            <= 1.259           [потенціювання обох частин нерівності]
10^((P_in_block - P_1dB) / 10)                <= 0.259           [віднімання одиниці]
P_in_block - P_1dB                            <= 10 * log10(0.259) [логарифмування відносного рівня]
P_in_block - P_1dB                            <= -5.87 dB        [граничний відступ від точки компресії]
P_in_block                                    <= P_1dB - 5.87 dB [перенесення P_1dB у праву частину]
P_in_block                                    <= -10.0 - 5.87    [підстановка P_1dB = -10 dBm]
P_in_block                                    <= -15.87 dBm      [максимально допустима потужність блокера на піні LNA]
```

Мінімально необхідна сумарна ізоляція між передавачем та приймачем складає:

```
L_total_req = P_tx - P_in_block_max                              [бюджет необхідного загасання завади]
            = +20.0 - (-15.87)                                   [підстановка вихідної потужності та порогу]
            = 35.87 dB                                           [мінімальна сумарна розв'язка між радіомодулями]
```

Якщо просторове рознесення антен на компактній друкованій платі забезпечує `22.0 dB` розв'язки, дефіцит ізоляції становить:

```
дефіцит_ізоляції = L_total_req - L_iso                           [різниця необхідної та реальної розв'язки]
                 = 35.87 - 22.00                                 [підстановка значень]
                 = 13.87 dB                                      [додаткове загасання, яке має забезпечити фільтр або PTA]
```

Цей числовий розрахунок наочно доводить: без додаткового смугового фільтра з вибіркою не менше 14 дБ на розстрочці 13 МГц або без апаратного часового арбітражу пакетів (PTA) забезпечити стабільний одночасний зв'язок у діапазоні 2,4 ГГц фізично неможливо.
