# 🧮 Математика потужності у несинусоїдних колах

Миттєвий добуток струму й напруги `p(t) = v(t) · i(t)` єдиний для будь-якої форми сигналу, але вимірювальні прилади та лічильники електроенергії оперують усередненими за період величинами: активною, реактивною, повною потужністю та коефіцієнтом потужності. У чисто синусоїдній мережі з лінійним навантаженням ці величини утворюють класичний прямокутний трикутник потужностей. Проте в сучасній розетці більшість споживачів — імпульсні блоки живлення, світлодіодні драйвери, фазові димери — спотворюють форму струму, перетворюючи синусоїду на вузькі піки. Тут класична тригонометрія ламається: з'являється потужність спотворення гармонік, а поняття коефіцієнта потужності розпадається на дві незалежні складові.

Нижче наведено строге математичне виведення інтегралів потужності від гармонійного розкладання до стандартів Будяну та IEEE Std 1459-2010.

## 1. Миттєва потужність у синусоїдному колі

Нехай напруга в розетці є чистою синусоїдою амплітуди `V₀`, а струм навантаження відстає за фазою на кут `φ` через індуктивну складову (наприклад, електродвигун помпи чи компресора):

```
v(t) = V₀ · sin(ωt) = √2 · V_rms · sin(ωt)
i(t) = I₀ · sin(ωt − φ) = √2 · I_rms · sin(ωt − φ)
```

де `ω = 2πf` — кутова частота (для 50 Гц `ω ≈ 314.159 рад/с`).

Миттєва потужність `p(t)` — це прямий добуток функцій:

```
p(t) = v(t) · i(t)
     = 2 · V_rms · I_rms · sin(ωt) · sin(ωt − φ)                     [підстановка v(t) та i(t)]
     = 2 · V_rms · I_rms · ½ · [cos(ωt − (ωt − φ)) − cos(ωt + (ωt − φ))]  [тотожність sin α · sin β = ½·(cos(α−β) − cos(α+β))]
     = V_rms · I_rms · [cos φ − cos(2ωt − φ)]                        [скорочення 2 · ½ та спрощення аргументів]
```

Розкладемо косинус різниці `cos(2ωt − φ) = cos(2ωt)·cos φ + sin(2ωt)·sin φ`:

```
p(t) = V_rms · I_rms · cos φ · [1 − cos(2ωt)] − V_rms · I_rms · sin φ · sin(2ωt)
```

Отриманий вираз складається з двох фундаментальних компонентів:
1. **Активна складова** `p_a(t) = V_rms · I_rms · cos φ · [1 − cos(2ωt)]`: пульсує з подвійною частотою `2ω = 100 Гц`, але **ніколи не опускається нижче нуля** (оскільки `1 − cos(2ωt) ≥ 0`). Вона завжди односпрямовано переносить корисну енергію від мережі до навантаження (перетворюється на тепло чи механічну роботу).
2. **Реактивна складова** `p_q(t) = −V_rms · I_rms · sin φ · sin(2ωt)`: чисто гармонійне коливання із середнім значенням 0. Вона описує безперервне перекачування електромагнітної енергії туди й назад між джерелом та магнітним полем індуктивності (або електричним полем ємності).

## 2. Інтегральне усереднення: Активна, реактивна та повна потужність

**Активна потужність `P`** (вимірюється у ватах, Вт) визначається як середнє значення миттєвої потужності за період коливання `T = 1/f = 20 мс`:

```
P = (1/T) · ∫[0..T] p(t) dt                                          [означення середньої активної потужності]
  = (1/T) · ∫[0..T] (V_rms · I_rms · cos φ · [1 − cos(2ωt)]) dt      [інтеграл від sin(2ωt) за період дорівнює нулю]
  = V_rms · I_rms · cos φ · (1/T) · ∫[0..T] 1 dt                     [інтеграл від cos(2ωt) за період дорівнює нулю]
  = V_rms · I_rms · cos φ                                            [обчислення інтеграла (1/T) · T = 1]
```

**Реактивна потужність `Q`** (вимірюється у вольт-амперах реактивних, вар) характеризує амплітуду коливань енергетичного обміну:

```
Q = V_rms · I_rms · sin φ                                            [означення реактивної потужності зсуву фази]
```

**Повна потужність `S`** (вимірюється у вольт-амперах, ВА) — це добуток середньоквадратичних (діючих) значень напруги та струму без урахування їхнього фазового зсуву:

```
S = V_rms · I_rms                                                    [означення повної вольт-амперної потужності]
```

Зв'язок між ними описується тригонометричною тотожністю `cos²φ + sin²φ = 1`:

```
P² + Q² = (V_rms · I_rms · cos φ)² + (V_rms · I_rms · sin φ)²        [піднесення до квадрата складових P та Q]
        = (V_rms · I_rms)² · (cos²φ + sin²φ)                         [винесення спільного множника (V_rms · I_rms)²]
        = (V_rms · I_rms)² · 1                                       [тригонометрична тотожність cos²φ + sin²φ = 1]
        = S²                                                         [заміна (V_rms · I_rms)² на повну потужність S²]
```

Звідси отримуємо геометричний зв'язок гіпотенузи та катетів:

```
S = √(P² + Q²)                                                       [трикутник потужностей у синусоїдному режимі]
```

**Коефіцієнт потужності** (*Power Factor, PF*) у синусоїдному режимі дорівнює косинусу кута зсуву фаз:

```
PF = P / S = (V_rms · I_rms · cos φ) / (V_rms · I_rms) = cos φ      [відношення активної потужності до повної]
```

## 3. Несинусоїдний режим: Ортогональність гармонік та потужність спотворення

У реальній мережі напруга містить невеликі гармонійні спотворення, а струм нелінійних навантажень є сумою вищих гармонік. Розкладемо `v(t)` та `i(t)` у ряди Фур'є:

```
v(t) = V_dc + ∑[k=1..∞] √2 · V_k · sin(kωt + θ_k)
i(t) = I_dc + ∑[m=1..∞] √2 · I_m · sin(mωt + ψ_m)
```

де `V_k`, `I_m` — RMS-значення відповідних гармонік, `θ_k`, `ψ_m` — їхні початкові фази.

Обчислимо середнє значення добутку `P = (1/T) · ∫[0..T] v(t) · i(t) dt`. Скористаємося фундаментальною властивістю **ортогональності гармонійних функцій**:

```
(1/T) · ∫[0..T] sin(kωt + θ_k) · sin(mωt + ψ_m) dt = { 0,                     якщо k ≠ m
                                                     { ½ · cos(θ_k − ψ_k),    якщо k = m
```

Це означає, що **струм гармоніки `m` не переносить активної потужності із напругою гармоніки `k`, якщо `k ≠ m`**. Активна потужність виникає **лише від взаємодії однойменних гармонік**:

```
P = V_dc · I_dc + ∑[k=1..∞] V_k · I_k · cos(θ_k − ψ_k)
```

Для типової мережі 230 В постійна складова відсутня (`V_dc = 0`, `I_dc = 0`), а напруга майже ідеально синусоїдна (`V_k ≈ 0` для `k ≥ 2`). У цьому наближенні:

```
P ≈ V₁ · I₁ · cos φ₁
```

де `V₁ = V_rms`, `I₁` — RMS першої (основної) гармоніки струму 50 Гц, `φ₁ = θ₁ − ψ₁`.

Однак **повна потужність `S`** враховує всі гармоніки струму:

```
I_rms = √(I₁² + I₂² + I₃² + ... + I_n²) = √(I₁² + ∑[k=2..∞] I_k²)
S = V_rms · I_rms = V₁ · √(I₁² + I_h²)
```

де `I_h = √(∑[k=2..∞] I_k²)` — сумарне середньоквадратичне значення вищих гармонік струму.

Піднесемо повну потужність до квадрата:

```
S² = (V₁ · I_rms)²                                                   [визначення повної потужності за діючими значеннями]
   = V₁² · (I₁² + I_h²)                                              [розкладання струму I_rms² = I₁² + I_h²]
   = (V₁ · I₁)² + (V₁ · I_h)²                                        [розкриття дужок множення]
   = (V₁ · I₁ · cos φ₁)² + (V₁ · I₁ · sin φ₁)² + (V₁ · I_h)²         [тригонометричне розкладання (V₁·I₁)² = P₁² + Q₁²]
   = P₁² + Q₁² + D²                                                  [заміна складових: P₁, Q₁ та потужність спотворення D]
```

де:
* `P₁ = V₁ · I₁ · cos φ₁` — активна потужність основної гармоніки (Вт);
* `Q₁ = V₁ · I₁ · sin φ₁` — реактивна потужність зсуву основної гармоніки (вар);
* `D = V₁ · I_h = V₁ · √(∑[k=2..∞] I_k²)` — **потужність спотворення** (*Distortion Power*, вар або девар за стандартом Будяну).

Таким чином, у нелінійних колах простір потужностей стає тривимірним:

```
S = √(P² + Q² + D²)
```

## 4. Розкладання коефіцієнта потужності: Зсув проти спотворення

Коефіцієнт нелінійних спотворень струму (*Total Harmonic Distortion, THD_i*) визначається як відношення середньоквадратичного значення вищих гармонік до основної:

```
THD_i = I_h / I₁ = √(∑[k=2..∞] I_k²) / I₁
```

Тоді повний діючий струм можна виразити через `THD_i`:

```
I_rms = √(I₁² + I_h²) = I₁ · √(1 + (I_h / I₁)²) = I₁ · √(1 + THD_i²)
```

Підставимо це у формулу повного коефіцієнта потужності `PF`:

```
PF = P / S                                                           [визначення коефіцієнта потужності]
   = (V₁ · I₁ · cos φ₁) / (V₁ · I_rms)                               [підстановка активної та повної потужності]
   = (I₁ / I_rms) · cos φ₁                                           [скорочення спільної напруги V₁]
   = (I₁ / (I₁ · √(1 + THD_i²))) · cos φ₁                            [вираження I_rms через I₁ та THD_i]
   = (1 / √(1 + THD_i²)) · cos φ₁                                    [скорочення амплітуди I₁]
```

Цей вираз чітко розділяє коефіцієнт потужності на два незалежні співмножники:

```
PF = K_distortion · K_displacement
```

1. **Коефіцієнт зсуву** (*Displacement Factor*): `K_disp = cos φ₁` — обумовлений фазовим зсувом основної гармоніки струму відносно напруги (компенсується підключенням конденсаторних батарей).
2. **Коефіцієнт спотворення** (*Distortion Factor*): `K_dist = I₁ / I_rms = 1 / √(1 + THD_i²)` — обумовлений спотворенням форми хвилі струму через діодні мости та імпульсні перетворювачі (компенсується лише активними коректорами коефіцієнта потужності, APFC).

**Приклад розрахунку для світлодіодної лампи:**
Імпульсний драйвер без PFC має зсув фази `φ₁ ≈ 0` (`cos φ₁ = 1.0`), але високий рівень гармонік `THD_i = 120% = 1.2`:

```
K_dist = 1 / √(1 + 1.2²) = 1 / √(1 + 1.44) = 1 / √2.44 ≈ 0.64
PF = 0.64 · 1.0 = 0.64
```

Хоча струм збігається за фазою з напругою, лампа споживає з мережі повну потужність `S` на 56% більшу, ніж корисна активна потужність `P`, додатково навантажуючи дроти реактивними пульсаціями гармонік.

## 5. Дискретне інтегрування енергії у мікроконтролері

Енергія `E` (вимірюється в джоулях або кіловат-годинах) — це часовий інтеграл від активної потужності:

```
E(t) = ∫[0..t] P(τ) dτ
```

У цифровому вимірювачі мікроконтролер отримує дискретні відліки потужності `P[n]` через фіксований інтервал квантування `Δt` (для HLW8032 `Δt = 50 мс = 0.05 с`).

### Метод прямокутників
Найпростіша апроксимація інтеграла сумою:

```
E[N] = ∑[n=0..N-1] P[n] · Δt
```

### Метод трапецій
Для підвищення точності використовують формулу трапецій другого порядку точності `O(Δt²)`:

```
E[N] = ∑[n=0..N-1] ½ · (P[n] + P[n+1]) · Δt
```

### Переведення у кіловат-години (кВт·год)
Оскільки `1 Вт·с = 1 Дж`, а `1 кВт·год = 1000 Вт · 3600 с = 3 600 000 Дж`:

```
E_kWh = (∑ P_avg · Δt_sec) / 3 600 000
```

Для запобігання втрати точності через обмежену мантису 32-бітових чисел із рухомою комою (`float` має лише 24 біти значущості, тому додавання 0.00001 кВт·год до 1000.0 кВт·год призводить до повного ігнорування малих часток) інтегрування в прошивці завжди виконують у 64-бітовій цілочисельній арифметиці з фіксованою комою (наприклад, у мікроджоулях `мкДж` або нано-ват-годинах).
