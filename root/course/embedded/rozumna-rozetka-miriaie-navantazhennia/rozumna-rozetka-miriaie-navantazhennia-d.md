# Розумна розетка міряє навантаження: шунт, трансформатор струму, HLW8032 / BL0937, активна й реактивна потужність

<preknowlist>
- [Закон Ома й потужність](root:ph-electromagnetism/electric-power) — зв'язок напруги, струму та теплових втрат P = I²·R.
- [Діюче значення напруги та струму](root:ph-electromagnetism/rms-value) — визначення RMS як теплового еквівалента змінного сигналу.
- [Безпека роботи з високою напругою 230 В](root:hw-power/mains-safety) — правила ізоляції, категорії перенапруг CAT II та гальванічна розв'язка.
- [Шунти та чотирипровідне підключення Кельвіна](root:hw-sensing/kelvin-shunt) — вимірювання мілівольтових спадів напруги без похибки від опору підвідних доріжок.
</preknowlist>

Коли ви вмикаєте в розумну розетку електричний чайник потужністю 2.2 кВт, силовою лінією тече змінний струм близько 9.6 А діючого значення з амплітудними піками до 13.5 А. Якщо ж поруч увімкнути зарядний пристрій смартфона на 5 Вт або світлодіодну лампу з фазовим регулятором яскравості, форма струму перестає бути синусоїдою й перетворюється на вузькі голчасті імпульси тривалістю 1–2 мс, амплітуда яких перевищує середній струм у 4–6 разів. Спроба виміряти споживану потужність наївним множенням середнього випрямленого струму на напругу дасть похибку від 30% до 80%. Одночасно всередині крихітного закритого пластикового корпусу розетки габаритами 50×50 мм розсіюється тепло від силових контактів, реле та вимірювальних елементів, а потенціал вимірювальних кіл коливається разом із фазою мережі від −325 В до +325 В відносно землі.

Щоб розумна розетка показувала точні вати й кіловат-години, витримувала короткочасні імпульсні перенапруги до 2.5 кВ і не перетворювалася на джерело займання при тривалому навантаженні 16 А, у ній реалізують спеціалізований апаратно-програмний тракт вимірювання електромережі.

![Архітектура вимірювального тракту розумної розетки](/root/course/embedded/rozumna-rozetka-miriaie-navantazhennia/img/smart-plug-architecture.svg)
*Повний вимірювальний та комутаційний тракт розумної розетки: силова високовольтна частина 230 В AC, шунт, дільник, вимірювальна мікросхема, оптоізольований UART та безпечний низьковольтний мікроконтролерний домен.*

## 1. Первинні перетворювачі струму: Шунт проти трансформатора струму

Струм у провіднику не можна виміряти безпосередньо цифровим входом: його необхідно перетворити на пропорційний спад напруги або магнітний потік. У мережевих вимірювачах побутового класу для цього застосовують два фізичні принципи: пряме вимірювання спаду напруги на прецизійному резистивному шунті або електромагнітну індукцію в трансформаторі струму (*Current Transformer, CT*).

![Порівняння шунта та трансформатора струму](/root/course/embedded/rozumna-rozetka-miriaie-navantazhennia/img/shunt-vs-ct.svg)
*Порівняння первинних перетворювачів струму: компактний низькоомний манганіновий шунт із кельвінівськими відводами проти трансформатора струму з магнітним осердям та навантажувальним резистором.*

### Манганіновий шунт (Manganin Shunt)
Шунт — це низькоомний силовий резистор номіналом від 1 до 2 мОм (0.001–0.002 Ом), увімкнений безпосередньо в розрив фазного або нейтрального проводу. Вибір сплаву тут критичний: звичайний ніхром або константан має високий температурний коефіцієнт опору (ТКО), через що при нагріванні розетки покази лічильника «пливуть». Тому застосовують манганін (сплав Cu-Mn-Ni) або спеціальні прецизійні сплави на основі міді та нікелю з ТКО не гірше `15–30 ppm/°C` та близькою до нуля термо-ЕРС у парі з міддю.

Головне обмеження шунта — теплове розсіювання за законом Джоуля-Ленца:

```
P_heat = I_rms² · R_shunt
```

Порахуймо теплове навантаження для стандартного номіналу побутової розетки 16 А:
* При `R_shunt = 1.0 мОм`: `P_heat = 16² · 0.001 = 256 · 0.001 = 0.256 Вт` (256 мВт);
* При `R_shunt = 2.0 мОм`: `P_heat = 16² · 0.002 = 512 мВт` (понад піввата тепла на площі SMD-компонента 2512 або 3920).

У герметичному корпусі розумної розетки 0.5 Вт тепла на шунті разом із теплом від котушки реле (0.4–0.6 Вт) та перехідного опору контактів нагрівають плату до +65…+80 °C. Тому номінал шунта намагаються зменшити до 1 мОм або навіть 0.5 мОм. Проте при малому опорі падає вихідна напруга: при струмі чергового режиму 10 мА (0.01 А) на шунті 1 мОм спадає лише:

```
U_sense = 0.01 А · 0.001 Ом = 10 мкВ
```

Щоб виділити корисний сигнал 10 мкВ на тлі шумів імпульсного блоку живлення, диференційні входи вимірювальної мікросхеми підключають до шунта виключно за **чотирипровідною схемою Кельвіна**. Дві силові доріжки великої ширини проводять струм 16 А, а дві тонкі сигнальні доріжки підводяться до внутрішніх контактних майданчиків резистора без протікання робочого струму. Опір одного квадрата стандартної мідної фольги PCB товщиною 35 мкм (1 oz) становить близько `0.5 мОм`. Якби вимірювання знімалося із силових доріжок за 5 мм від шунта, паразитний опір додав би понад `1 мОм`, що подвоїло б похибку вимірювання.

> 🔧 **Навіщо це.** Шунт не дає гальванічної розв'язки: уся вимірювальна мікросхема перебуває під смертельним потенціалом 230 В. Але він не має феромагнітного осердя, тому абсолютно лінійний від міліампер до сотень ампер, не насичується від постійної складової і коштує від $0.05.

### Трансформатор струму (Current Transformer, CT)
Трансформатор струму являє собою тороїдальне осердя з електротехнічної сталі, пермалою або нанокристалічного сплаву. Первинною обмоткою виступає сам силовий провідник мережі, пропущений крізь вікно тора (один виток, `N₁ = 1`). Вторинна обмотка містить сотні або тисячі витків тонкого дроту (типово `N₂ = 1000` або `2000`).

Струм вторинної обмотки `I₂` трансформується обернено пропорційно кількості витків:

```
I₂ = I₁ · (N₁ / N₂) = I₁ / 1000
```

Цей струм замикається на низькоомний навантажувальний резистор `R_burden` (типово 10–50 Ом), на якому утворюється вимірювальна напруга `U_out = I₂ · R_burden`. При струмі навантаження 10 А вторинний струм дорівнює `10 мА`, а на резисторі `20 Ом` утворюється сигнал `200 мВ RMS`.

**Головна перевага ТС:** абсолютна гальванічна ізоляція (>3 кВ). Вимірювальні кола можна підключати до мікроконтролера без оптопар.

**Смертельна небезпека розриву вторинної обмотки ТС:**
У нормальному режимі вторинний струм `I₂` створює розмагнічувальний потік, який майже повністю компенсує намагнічувальний потік первинного струму `I₁`. Якщо розірвати коло вторинної обмотки (випаяти або обірвати `R_burden`) під навантаженням:
1. Розмагнічувальний потік вторинної обмотки зникає (`I₂ = 0`);
2. Увесь первинний струм (наприклад, 16 А) перетворюється на чисту намагнічувальну силу;
3. Осердя миттєво входить у глибоке магнітне насичення: у моменти переходу первинного струму через нуль магнітний потік `Φ` перекидається з граничною швидкістю `dΦ/dt`;
4. За законом Фарадея на вторинній обмотці з `N₂ = 2000` витків генеруються вузькі високовольтні імпульси з амплітудою **від 1.5 кВ до 5 кВ**:

```
e₂(t) = −N₂ · (dΦ / dt)
```

Ці імпульси пробивають міжвиткову ізоляцію ТС, виводять з ладу вимірювальні мікросхеми, створюють дуговий пробій на платі та становлять смертельну небезпеку для інженера під час налагодження. Тому трансформатори струму категорично заборонено залишати з розімкненою вторинною обмоткою: у промислових модулях паралельно вторинній обмотці завжди встановлюють захисні супресори (TVS-діоди на 6–10 В) або двосторонні стабілітрони.

### Котушка Роговського (Rogowski Coil)
У потужних промислових щитах або струмовимірювальних кліщах застосовують альтернативу — котушку Роговського. Це тороїдальна котушка без феромагнітного осердя (діелектричний каркас або гнучкий кабель). Оскільки осердя повітряне, вона взагалі не насичується навіть при струмах короткого замикання в тисячі ампер і має ідеальну лінійність.

Проте вихідна напруга котушки Роговського пропорційна не самому струму, а його похідній за часом:

```
e(t) = −M · (di(t) / dt)
```

де `M` — коефіцієнт взаємоіндукції. Для отримання значення струму сигнал необхідно пропускати крізь прецизійний аналоговий або цифровий інтегратор. Крім того, на частоті 50 Гц амплітуда вихідного сигналу становить лише одиниці мікровольтів на ампер (наприклад, `0.5 мВ` при струмі 10 А), що вимагає малошумливих операційних підсилювачів високого класу. Через високу вартість інтегратора та низьку чутливість на малих струмах у побутових розетках на 16 А котушки Роговського не використовують, залишаючи першість манганіновим шунтам.

## 2. Вимірювання напруги: Високовольтний резистивний дільник

Для вимірювання напруги мережі 230 В її амплітудне значення (±325 В у нормальному режимі, до ±400 В при аварійних підвищеннях) необхідно лінійно ослабити до діапазону вхідного АЦП вимірювальної мікросхеми (зазвичай ±150–500 мВ RMS). Це завдання вирішує резистивний дільник напруги.

![Схемотехніка високовольтного дільника](/root/course/embedded/rozumna-rozetka-miriaie-navantazhennia/img/voltage-divider-chain.svg)
*Схемотехніка високовольтного дільника напруги: небезпека пробою поодинокого SMD-резистора проти безпечного послідовного ланцюга резисторів (4×470 кОм + 1 кОм) для відповідності стандарту CAT II.*

### Чому заборонено ставити один SMD-резистор 1 МОм
Поширена помилка розробника-початківця — встановити у верхнє плече дільника один стандартний SMD-резистор типорозміру 0805 або 1206 номіналом 1 МОм. Ця схема порушує вимоги стандартів безпеки [IEC 61010-1](root:hw-power/mains-safety) та [координації ізоляції](root:hw-power/insulation-classes):
1. **Гранична робоча напруга компонента (*Max Working Voltage*)**: для корпусу 0805 вона становить лише `150 В DC/AC`, для 1206 — `200 В`. Пік нормальної синусоїди 230 В становить `325 В`, що вже перевищує паспортний ліміт діелектрика компонента.
2. **Імпульсні перенапруги категорії CAT II**: згідно з IEC 61000-4-5, прилад у побутовій розетці мусить витримувати мікросекундні викиди напруги амплітудою до `2500 В` (індуктивні викиди від вимкнення потужних двигунів, зварювальних апаратів, грозові наведення). Відстань між контактними майданчиками резистора 0805 становить лише 1.2 мм: при імпульсі 2.5 кВ виникає поверхневий дуговий пробій повітряного зазору (*clearance*) або пробій по діелектрику плати (*creepage*).
3. **Захист від одиночної відмови (*Single Fault Condition*)**: якщо єдиний резистор 1 МОм вийде з ладу через коротке замикання (металізація тріщини), на вхід низьковольтної мікросхеми піде повна напруга 230 В, що спричинить вибух кристала.

### Правильна топологія: Послідовний ланцюг резисторів
Верхнє плече дільника розбивають на ланцюг із 3–5 послідовно з'єднаних резисторів номіналом від 330 кОм до 510 кОм (наприклад, 4 резистори по 470 кОм сумарним опором `R_top = 1.88 МОм`).

Розрахуємо розподіл напруг і струмів:
* Сумарний опір верхнього плеча: `R_top = 4 × 470 кОм = 1 880 кОм = 1.88 МОм`;
* Опір нижнього плеча: `R_bot = 1.0 кОм` (прецизійний металоплівковий резистор 0.1% або 1%);
* Повний коефіцієнт ділення:

```
K_div = R_bot / (R_top + R_bot) = 1000 / (1880000 + 1000) = 1 / 1881 ≈ 0.0005316
```

При напрузі мережі `230 В RMS` (пік 325.3 В):
* Напруга на вході АЦП: `U_adc = 230 В / 1881 ≈ 122.3 мВ RMS` (пік `±173 мВ`);
* Струм крізь дільник: `I_div = 230 В / 1.881 МОм ≈ 0.122 мА` (122 мкА);
* Теплова потужність на всьому дільнику: `P_div = 230² / 1.881e6 ≈ 0.028 Вт` (28 мВт — по 7 мВт на кожен резистор, нагрів відсутній);
* Напруга на кожному з 4 резисторів: `325 В / 4 ≈ 81.3 В` (вдвічі нижче гранично допустимих 200 В для 1206).

Паралельно нижньому резистору 1 кОм встановлюють керамічний конденсатор ємністю 10–33 нФ (діелектрик C0G/NPO або X7R). Він утворює антиаліасинговий фільтр низьких частот першого порядку з частотою зрізу:

```
f_cutoff = 1 / (2π · R_bot · C) = 1 / (2π · 1000 Ом · 33 · 10⁻⁹ Ф) ≈ 4.82 кГц
```

Цей фільтр пропускає основну частоту 50 Гц та гармоніки до 50-ї (2.5 кГц) практично без фазового спотворення, але надійно придушує високочастотні шуми комутації імпульсних джерел живлення (>50 кГц).

### Трасування на платі та захисні прорізи
На друкованій платі під ланцюгом резисторів дільника заборонено розташовувати інші провідники чи полігони землі на внутрішніх шарах. Сумарна відстань уздовж поверхні діелектрика (*creepage distance*) від високовольтного входу 230 В до низьковольтного виходу дільника має становити не менше `6.3 мм` для забезпечення базової ізоляції. У місцях проходження ізоляційного бар'єра між високовольтною зоною та мікроконтролером на платі фрезерують наскрізний паз (*isolation slot*) шириною 1.5–2.0 мм: повітряний проріз повністю унеможливлює виникнення струмів витоку при осіданні вологи та пилу.

## 3. Спеціалізовані мікросхеми енергомоніторингу

Спроба виміряти параметри мережі звичайним АЦП мікроконтролера (наприклад, 12-бітним SAR АЦП у ESP32 чи STM32) стикається з трьома нездоланними проблемами: відсутністю апаратного множення відліків на високій швидкості, нелінійністю та температурним дрейфом вбудованого опорного джерела (VREF), а також колосальним навантаженням на процесорне ядро. Тому в розумних розетках застосовують спеціалізовані мікросхеми моніторингу енергії.

За принципом інтерфейсу їх поділяють на два великі класи: перетворювачі «потужність-частота» та цифрові процесори енергії з інтерфейсами UART/SPI.

| Характеристика | Частотні (BL0937, HLW8012) | Цифрові UART/SPI (HLW8032, BL0942) | Промислові DSP (ADE7753, ATM90E32) |
|---|---|---|---|
| **Архітектура АЦП** | Подвійний 16–24 біт ΣΔ | Подвійний 24-бітний ΣΔ + DSP | Подвійний/потрійний 24-біт ΣΔ + DSP |
| **Вихідний інтерфейс** | Імпульсні виходи CF, CF1 | Послідовний порт UART (4800–9600) | Шина SPI (до 10 МГц) / UART |
| **Вимірювані величини** | P_active (постійно), V_rms / I_rms (по черзі) | V_rms, I_rms, P_active, S, Energy | V, I, P, Q, S, PF, THD, Zero-Cross, Waveform |
| **Гальванічна розв'язка** | 2 дешеві оптопари (PC817) | 1–2 оптопари (TX/RX) | Цифрові ізолятори (ADuM1401) / оптопари |
| **Навантаження на МК** | Високе (обробка переривань таймера) | Мінімальне (фоновий парсинг буфера) | Мінімальне (читання регістрів за запитом) |
| **Ціна мікросхеми** | $0.15–0.25 | $0.30–0.45 | $1.50–4.00 |

### Частотні мікросхеми (BL0937 / HLW8012)
Це найдешевші мікросхеми, що масово встановлюються в базових розетках (Sonoff S20/S26, розетки на чипах Tuya TYWE3S):
* Всередині працюють два сигма-дельта модулятори та цифровий помножувач.
* Вихід `CF` генерує прямокутні імпульси, частота яких строго пропорційна активній потужності: `f_CF = P · C_const`. Мікроконтролер рахує кількість імпульсів за інтервал часу або вимірює тривалість періоду таймером захоплення.
* Вихід `CF1` передає частоту, пропорційну напрузі або струму. Вибір каналу здійснюється подачею логічного рівня на вхід `SEL`: при `SEL = 0` вихід CF1 транслює частоту струму `f_I`, при `SEL = 1` — частоту напруги `f_V`.
* **Головний недолік:** неможливість одночасного вимірювання напруги та струму. Мікроконтролер змушений перемикати пін `SEL`, чекати 200–500 мс на стабілізацію частоти вихідного фільтра й лише потім рахувати імпульси. Це унеможливлює точний розрахунок повної потужності `S` та коефіцієнта потужності `PF` на динамічному навантаженні.

### Цифрові мікросхеми (HLW8032 / BL0942)
Сучасний стандарт для розумних пристроїв. Мікросхема самостійно виконує фільтрацію, усереднення за цілі періоди мережі та транслює сформовані 24-розрядні значення напруги, струму й потужності по UART.
Детальний аналіз цоколівки, електричної схеми та внутрішньої структури регістрів наведено у [докладному реєстровому описі мікросхеми HLW8032](root:embedded/rozumna-rozetka-miriaie-navantazhennia/api-hlw8032.md).

![Формат кадру та обробка HLW8032](/root/course/embedded/rozumna-rozetka-miriaie-navantazhennia/img/hlw8032-packet-flow.svg)
*Структура 24-байтного кадру UART телеметрії мікросхеми HLW8032 та формули перерахунку 24-розрядних регістрів у фізичні значення напруги, струму та активної потужності.*

### Синхронізація з нулем (Zero-Crossing Detection)
Просунуті цифрові мікросхеми (BL0942, ADE7753) мають вивід апаратного детектора переходу напруги через нуль (*Zero-Crossing Output, ZX*). Цей сигнал використовують для [синхронної комутації реле](root:hw-power/zero-cross-switching). Якщо контакти електромеханічного реле замикаються на піку напруги (325 В), зарядний струм вхідних конденсаторів імпульсних блоків живлення досягає 50–100 А, що викликає мікрозварювання та ерозію контактів. Вмикання реле в момент переходу напруги через нуль зменшує пусковий струм до нуля, подовжуючи ресурс силового реле з 10 000 до понад 100 000 циклів спрацьовування.

## 4. Математика потужності змінного струму

Повна фізична потужність змінного струму складається з декількох взаємопов'язаних компонентів.

![Складові потужності та форми сигналів](/root/course/embedded/rozumna-rozetka-miriaie-navantazhennia/img/ac-power-components.svg)
*Форми напруги, струму та миттєвої потужності для активного (нагрівач, PF = 1.0), індуктивного (двигун, PF = 0.7) та нелінійного імпульсного навантаження (PF = 0.55) з гармонійним спотворенням.*

### 1. Активна потужність (Active Power, P)
Активна потужність — це та частина електроенергії, яка незворотно перетворюється на корисну роботу (тепло нагрівача, випромінювання світла, механічну енергію вала двигуна). Вона вимірюється у **ватах (Вт)** і математично визначається як середнє значення інтеграла добутку миттєвих значень напруги `v(t)` та струму `i(t)` за період коливань `T`:

```
P = (1/T) · ∫[0..T] v(t) · i(t) dt
```

Для чисто гармонійних коливань `v(t) = √2 · V_rms · sin(ωt)` та `i(t) = √2 · I_rms · sin(ωt − φ)` інтеграл зводиться до відомої формули:

```
P = V_rms · I_rms · cos φ
```

### 2. Повна потужність (Apparent Power, S)
Повна потужність характеризує загальне вольт-амперне навантаження, яке прилад створює на електромережу, трансформатор підстанції та підвідні кабелі. Вона вимірюється у **вольт-амперах (ВА)**:

```
S = V_rms · I_rms
```

### 3. Реактивна потужність (Reactive Power, Q)
Реактивна потужність виникає у колах з реактивними елементами (індуктивностями та ємностями) і характеризує швидкість оборотного обміну енергією між джерелом та електромагнітними полями навантаження. Вона вимірюється у **вольт-амперах реактивних (вар)**:

```
Q = V_rms · I_rms · sin φ
```

У чисто синусоїдному режимі діє класичний **трикутник потужностей**:

```
S² = P² + Q²   →   S = √(P² + Q²)
```

### 4. Нелінійні спотворення та потужність спотворення (D)
Більшість сучасних побутових приладів (комп'ютери, телевізори, LED-лампи) споживають струм несинусоїдно: діодний міст випрямляча заряджає конденсатор фільтра лише на самих піках синусоїди напруги. У цьому випадку струм містить широкий спектр вищих непарних гармонік (3-тя 150 Гц, 5-та 250 Гц, 7-ма 350 Гц тощо).

Згідно зі стандартом Будяну та IEEE Std 1459, повна потужність розкладається на три взаємно ортогональні складові:

```
S² = P² + Q² + D²
```

де `D` — **потужність спотворення** (*Distortion Power*), яка виникає внаслідок взаємодії вищих гармонік струму з напругою мережі:

```
D = V_rms · √(∑[k=2..∞] I_k²)
```

Повний коефіцієнт потужності (*True Power Factor, PF*) розпадається на два співмножники:

```
PF = P / S = K_distortion · K_displacement = (1 / √(1 + THD_i²)) · cos φ₁
```

де `THD_i` — коефіцієнт гармонійних спотворень струму, `φ₁` — зсув фази основної гармоніки 50 Гц.

Повні математичні виведення цих співвідношень, доведення ортогональності гармонік та аналіз методів числового інтегрування наведено у [математичному виведенні миттєвої, активної, реактивної потужностей та розкладання Будяну](root:embedded/rozumna-rozetka-miriaie-navantazhennia/math-ac-power.md).

## 5. Методика двоточкового калібрування

Через технологічний розкид номіналів пасивних компонентів (толерантність резисторів дільника ±1%, опір шунта ±1–5%, розкид внутрішнього джерела опорної напруги АЦП ±2%) розумна розетка після монтажу без калібрування має систематичну похибку вимірювання від 3% до 8%.

Для забезпечення метрологічного класу точності 1.0 (похибка < 1.0%) застосовують процедуру заводського калібрування за двома точками.

![Методика двоточкового калібрування](/root/course/embedded/rozumna-rozetka-miriaie-navantazhennia/img/calibration-curve.svg)
*Методика двоточкового калібрування вимірювального тракту: компенсація нульового зміщення (offset), налаштування коефіцієнтів масштабу (gain) на еталонному навантаженні та компенсація фазового зсуву.*

### Етап 1: Калібрування нульового зміщення (Offset Calibration)
* **Умова стенда:** Напруга 230 В подана на вхід розетки, реле замкнене, але навантаження відсутнє (`I_true = 0.000 А`).
* **Фізична суть:** Вхідний тракт фіксує теплові шуми АЦП, синфазні наведення та напругу зміщення операційного підсилювача (Offset Voltage `V_os`).
* **Алгоритм:** Мікроконтролер зчитує 50 послідовних кадрів, обчислює середній шум струму `I_noise_floor` (зазвичай 3–15 мА) і записує його як поріг відсікання (*Noise Gate*). Усі виміряні значення нижче цього порогу в робочому режимі примусово обнуляються.

### Етап 2: Калібрування масштабу напруги та струму (Gain Calibration)
* **Умова стенда:** До розетки підключають прецизійний еталонний нагрівач чисто активного опору (наприклад, ТЕН потужністю `P_ref = 1000.0 Вт ± 0.1%` при напрузі `V_ref = 230.0 В ± 0.1%`, струм `I_ref = 4.348 А`, `PF = 1.000`).
* **Алгоритм:**
  1. Зчитують сирі значення регістрів напруги `V_param` і `V_data`, струму `I_param` і `I_data`, потужності `P_param` і `P_data`.
  2. Обчислюють індивідуальні калібрувальні коефіцієнти розетки:

```
K_v = V_ref / (V_param / V_data)
K_i = I_ref / (I_param / I_data)
K_p = P_ref / ((P_param / P_data) · K_v · K_i)
```

  3. Отримані константи записуються в захищений сектор EEPROM або NVS-пам'яті мікроконтролера розетки.

### Етап 3: Калібрування фазового зсуву (Phase Angle Compensation)
* **Умова стенда:** До розетки підключають навантаження з відомим індуктивним зсувом фази (`PF_ref = 0.500`, `φ = 60.0°`).
* **Фізична суть:** Вхідні RC-фільтри каналу напруги та каналу струму мають незначний розкид ємностей, що вносить паразитний фазовий зсув `Δφ` між каналами (зазвичай 0.2–1.5°). При `cos φ ≈ 1.0` цей зсув майже не впливає на активну потужність, але при `PF = 0.5` похибка розрахунку ватів може сягати 5–10%.
* **Алгоритм:** Мікроконтролер розраховує похибку `Δφ = arccos(P_meas / S_meas) − 60.0°` і записує значення поправки у внутрішній фазокомпенсувальний регістр мікросхеми (якщо мікросхема підтримує фазове калібрування, як ADE7753/BL0942) або програмно коригує фазовий кут у драйвері.

Нижче наведено фрагмент інтеграції драйвера в робочий цикл мікроконтролера. #include <concepts>
#include <optional>

namespace socket {

struct Telemetry {
    float voltage_rms{0.0f};
    float current_rms{0.0f};
    float active_power{0.0f};
    float apparent_power{0.0f};
    float power_factor{1.0f};
    double energy_kwh{0.0};
};

class PowerMonitor {
public:
    constexpr explicit PowerMonitor(float max_current_limit = 16.0f) noexcept
        : max_current_{max_current_limit} {}

    [[nodiscard]] bool check_overcurrent(const Telemetry& data) const noexcept {
        return data.current_rms > max_current_;
    }

    [[nodiscard]] bool check_voltage_fault(const Telemetry& data) const noexcept {
        return (data.voltage_rms > 260.0f) || (data.voltage_rms < 175.0f);
    }

private:
    float max_current_{16.0f};
};

} // namespace socket

## 7. Підсумкова інженерна картина

Вимірювання параметрів змінного струму в розумній розетці базується на поєднанні трьох ключових рішень:
1. **Первинне зняття сигналу**: манганіновий шунт 1 мОм із 4-провідним підключенням Кельвіна забезпечує лінійність і компактність ціною тепловиділення 256 мВт при 16 А, тоді як трансформатор струму дає повну гальванічну розв'язку, але вимагає захисту вторинної обмотки від смертельного пробою при розриві кола навантаження.
2. **Високовольтний захист дільника**: ланцюг із 4 резисторів (4×470 кОм + 1 кОм) знижує робочу напругу на кожному компоненті до безпечних 80 В і забезпечує стійкість до імпульсних перенапруг 2.5 кВ стандарту CAT II.
3. **Обробка та калібрування**: спеціалізовані цифро-аналогові процесори (HLW8032, BL0942) беруть на себе апаратне інтегрування відліків та обчислення True-RMS, що після двоточкового калібрування гарантує похибку вимірювання активної енергії менше 1.0% на будь-якому типі навантаження.
