Інженер встановлює у степу автономний телеметричний пост: мікроконтролер, стільниковий модем LTE-M, датчики температури й вітру, сонячна панель на 10 Вт та літій-залізо-фосфатний акумулятор номіналом 12 Вт·год. Протягом усього літа та вересня вузол працює бездоганно: акумулятор заряджається до 100 % ще до полудня, а щогодинні звіти надходять на сервер щохвилини. Проте в середині грудня, на четверту добу безперервної зимової хмарності та снігопаду за температури -12 °C, передавач надсилає останній тривожний пакет із напругою живлення 2.8 В і пристрій назавжди зникає з ефіру.

Розтин вузла навесні не виявляє механічних пошкоджень чи виходу з ладу мікросхем: простої наївної арифметики «середня потужність 100 мВт означає добове споживання 2.4 Вт·год, отже десятиватна панель покриє його за 15 хвилин сонця» виявилося недостатньо, щоб пережити зимове сонцестояння. Реальний світ змушує враховувати чотири фундаментальні обмеження: падіння зимової інсоляції уп'ятеро проти літньої, температурне зростання напруги фотомодуля, деградацію хімічної ємності електроліту на морозі та необхідність мати запас енергії на `N` діб суцільної темряви з наступним швидким відновленням заряду.

Розрахунок автономного сонячного комплексу (*solar-battery autonomous system sizing*) — це задача суворого енергетичного балансу, де накопичувач і генератор розраховуються за взаємопов'язаною системою нерівностей для найгірших кліматичних умов року.

## 1. Добовий енергетичний бюджет вузла

Розрахунок автономної системи починається не з вибору сонячної панелі чи акумулятора, а з обчислення точної кількості енергії, яку електроніка безповоротно забирає з шини живлення за одну астрономічну добу (24 години).

Вбудований вузол майже ніколи не споживає постійний струм. Його робота складається з циклічного чергування фаз глибокого сну (*deep sleep*), зчитування сенсорів, обчислень і високопотужних радіоімпульсів. Якщо напруга живлення цифрової шини становить `V_bus`, а споживання струму в часі описується функцією `I(t)`, то повна добова енергія споживача `E_load_day` визначається визначеним інтегралом:

```
E_load_day = ∫₀²⁴ʰ V_bus · I(t) dt
```

Для типового циклічного профілю з періодом `T_cycle`, який містить `M` дискретних фаз тривалістю `t_k` зі струмами `I_k`, енергія одного робочого циклу `E_cycle` обчислюється як сума часток:

```
E_cycle = ∑ₖ₌₁ᴹ V_bus · I_k · t_k
```

Кількість таких циклів за добу дорівнює `N_cycles = 86400 / T_cycle` (де тривалість `T_cycle` задано в секундах). Тоді добове споживання цифрової частини становить:

```
E_load_day = N_cycles · E_cycle
```

### Врахування ККД перетворювачів на платі

Жодна цифрова схема не підмикається до акумулятора напряму без стабілізатора. Якщо акумуляторна батарея LiFePO4 має робочу напругу 12.8 В (або 3.2 В для однієї комірки), а мікроконтролеру та сенсорам потрібні стабільні 3.3 В, між акумулятором і навантаженням стоїть імпульсний знижувальний перетворювач (*buck converter*) або лінійний стабілізатор (*LDO*).

Імпульсний перетворювач має коефіцієнт корисної дії `η_conv`, який залежить від струму навантаження. У режимі передачі струмом 200 мА ККД якісного синхронного перетворювача становить 90–94 %, проте в режимі глибокого сну за струму 20 мкА більшість мікросхем переходять у режим пропуску імпульсів (*pulse-skipping / PFM*) з падінням ККД до 65–75 %.

Крім того, плата має неперервні паразитарні витоки:
1. Власний струм спокою схеми захисту акумулятора (*BMS quiescent current*, `I_bms`): від 10 до 50 мкА.
2. Струм витоку вихідних ключів і зворотний струм діодів MPPT-контролера у нічний час (`I_ctrl_dark`): від 20 мкА до 2 мА залежно від схемотехніки.
3. Природний саморозряд акумулятора (`k_self`): для LiFePO4 становить близько 1.0–1.5 % ємності на місяць (тобто `k_self_day ≈ 0.0005` на добу), а для свинцево-кислотних — до 4–6 % на місяць.

Підсумовуючи всі складові, дістаємо повне значення добової енергії `E_day` у ват-годинах (Вт·год), яку джерело живлення зобов'язане надати вузлу за добу:

```
E_day = (E_load_day / η_conv + V_batt · I_bms · 24 + V_batt · I_ctrl_dark · 24) · (1 + k_self_day)
```

> 🔧 **Навіщо це.** Якщо знехтувати струмом сну перетворювача та власним витоком контролера, розрахункова автономність у малопотужних системах (де середній струм вузла менший за 500 мкА) завищується у 2–3 рази, що гарантовано призводить до передчасної зупинки приладу взимку.

## 2. Розрахунок ємності накопичувача під N діб автономності

Акумуляторна батарея в автономній системі виконує подвійну функцію: згладжує добовий цикл «день/ніч» і накопичує запас енергії на період тривалої негоди (*autonomy period*), коли сонячна панель через суцільну хмарність, туман чи налипання снігу генерує менше 5–10 % від номіналу.

![Динаміка заряду акумулятора під час автономності](/root/course/embedded/rozrakhunok-vuzla/img/battery-autonomy-discharge.svg)
*Крива зміни рівня заряду (SoC) під час штатного чергування дня/ночі, 5 діб повної хмарності та наступного триденного відновлення.*

### Число діб автономності (N_autonomy)

Параметр `N_autonomy` вибирається на основі статистичних метеорологічних даних регіону розгортання:
- для помірних широт (45°–55° пн. ш., зокрема вся територія України та Центральної Європи) стандартне інженерне число становить `N_autonomy = 4..7 діб`;
- для критичної інфраструктури (оповіщення, шлюзи безпеки) запас збільшують до `N_autonomy = 10..14 діб`;
- для південних посушливих регіонів із малою хмарністю достатньо `N_autonomy = 3 діб`.

За цей час батарея повинна живити вузол, не опускаючись нижче гранично допустимого рівня розряду.

### Глибина розряду (Depth of Discharge, DoD)

Жоден акумулятор не можна розряджати до нульового залишку енергії без швидкої втрати ресурсу або незворотного пошкодження:
- **LiFePO4 (літій-залізо-фосфат):** стандартна робоча глибина розряду становить `DoD = 0.80` (80 %). Залишок 20 % заряду гарантує ресурс 3000–5000 повних циклів. При розряді до 100 % (`DoD = 1.0`) ресурс падає до 1000 циклів.
- **Li-ion (NMC / LiCoO2):** робоча глибина `DoD = 0.70..0.75` (залишок 25–30 %), ресурс 800–1500 циклів.
- **Свинцево-кислотні (AGM / GEL / VRLA):** допустима регулярна глибина розряду становить лише `DoD = 0.50` (50 %). Глибший розряд викликає сульфатацію пластин і знижує термін служби до 200–300 циклів.

### Температурний коефіцієнт ємності (η_temp)

Електрохімічні процеси уповільнюються на холоді через зростання в'язкості електроліту та підвищення опору переносу заряду. За температури -15 °C доступна ємність літієвого акумулятора зменшується навіть за малих струмів розряду:
- для якісних LiFePO4 комірок коефіцієнт доступної ємності за -15 °C становить `η_temp ≈ 0.70..0.75`;
- для стандартних Li-ion 18650 — `η_temp ≈ 0.75..0.80`;
- для свинцево-кислотних — `η_temp ≈ 0.60..0.65`.

### Формула необхідної номінальної ємності

З урахуванням коефіцієнта корисної дії самого процесу розряду акумулятора `η_batt ≈ 0.95` (кулонівська та омічна ефективність LiFePO4), потрібний паспортний запас енергії акумуляторної батареї `E_batt_nom` (у Вт·год) становить:

```
E_batt_nom = (E_day · N_autonomy) / (DoD · η_batt · η_temp)
```

Щоб перевести енергію у звичні ампер-години (А·год) для батареї з номінальною напругою `V_batt_nom`:

```
C_batt_Ah = E_batt_nom / V_batt_nom
```

> ⚠️ **Критичне правило зимової експлуатації LiFePO4:** Літієві акумулятори дозволяють розряд за температур від -20 °C до +60 °C, але **категорично забороняють заряд струмом за температури комірки нижче 0 °C**. Заряд на морозі призводить до осадження металевого літію на поверхні графітового анода у вигляді дендритів, що руйнує комірку й викликає внутрішнє коротке замикання. BMS або MPPT-контролер автономного вузла зобов'язані мати зовнішній датчик температури NTC і блокувати зарядний струм при `T_batt < 0 °C`, або спрямовувати перші надлишки сонячної потужності на підігрівний нагрівальний елемент акумуляторного відсіку.

## 3. Пікові сонячні години (PSH) та розрахунок фотопанелі

Паспортна потужність сонячної панелі `P_pv_STC` (у ватах, Вт або Вт_пік) вказується виробником для стандартних тестових умов (англ. *Standard Test Conditions*, STC):
- густина потоку випромінювання `G_STC = 1000 Вт/м²`;
- спектральний розподіл маси повітря `AM = 1.5` (AM1.5G);
- температура кремнієвого фотоелемента `T_cell = +25 °C`.

У реальних польових умовах сонце сходить, рухається небосхилом під змінним кутом і заходить, а атмосферні явища розсіюють світло.

![Сезонний розподіл пікових сонячних годин PSH](/root/course/embedded/rozrakhunok-vuzla/img/monthly-psh-energy-balance.svg)
*Сезонний профіль PSH на широті 50°N: критичний мінімум у грудні (1.1 PSH) диктує площу сонячного модуля для цілорічної автономності.*

### Концепція пікових сонячних годин (Peak Sun Hours, PSH)

Щоб спростити розрахунки інтегральної сонячної енергії, інженери використовують величину **PSH** (лат. *solaris* — сонячний). 

Один піковий сонячний час (1 PSH) еквівалентний отриманню поверхнею енергії `1 кВт·год/м²` (або `1000 Вт·год/м²`), що відповідає рівно одній годині опромінення з еталонною інтенсивністю 1000 Вт/м²:

```
1 PSH = 1000 Вт/м² · 1 год = 1 кВт·год/м² = 3.6 МДж/м²
```

Якщо протягом світлового дня інтегральна добова інсоляція на похилу поверхню становить `H_day = 3.3 кВт·год/м²·добу`, то еквівалентне число пікових сонячних годин для цієї доби дорівнює `PSH = 3.3 год/добу`.

### Сезонна нерівномірність інсоляції

Для географічної широти близько 50° пн. ш. (Київ, Львів, Харків, Краків, Франкфурт) за умови оптимального цілорічного кута нахилу панелі (близько 55°–60° на південь) спостерігається різка сезонна нерівномірність:
- **Червень:** `PSH_max ≈ 5.6..6.0 год/доба`;
- **Вересень:** `PSH_mid ≈ 3.8..4.2 год/доба`;
- **Грудень:** `PSH_min ≈ 1.0..1.2 год/доба`.

У грудні та січні сонячної енергії надходить **у 5 разів менше**, ніж у червні. Розрахунок системи, що повинна працювати безперервно цілий рік, завжди ведеться за найгіршим місяцем року — за грудневим значенням `PSH_worst`.

### Баланс генерації та швидкість відновлення після розряду

Сонячна панель в автономній системі повинна виконувати два завдання:
1. Забезпечувати поточне добове споживання вузла `E_day` навіть у найпохмуріший місяць року.
2. Після завершення періоду автономності (`N_autonomy` діб хмарності) повністю зарядити розряджений акумулятор за обмежену кількість сонячних діб `N_recovery` (зазвичай обирають `N_recovery = 3..5 діб`), одночасно продовжуючи живити сам вузол.

Сумарна енергія, яку панель має згенерувати за один день відновлювального періоду, складається з щоденного споживання та частки енергії на компенсацію виснаженого заряду:

```
E_gen_daily = E_day + (E_day · N_autonomy) / (N_recovery · η_batt)
```

Виносячи `E_day` за дужки:

```
E_gen_daily = E_day · [1 + N_autonomy / (N_recovery · η_batt)]
```

### Комплексний коефіцієнт делейтингу системи (η_sys)

Реальна потужність, що доходить від панелі до акумулятора, зменшується через системні втрати:
- `η_ctrl` — ККД контролера заряду (0.95–0.98 для MPPT, 0.65–0.75 для PWM);
- `η_dirt` — втрати від пилу, бруду, пташиного посліду та налипання листя (0.92–0.96);
- `η_snow` — втрати від снігового покриву (при нахилі панелі понад 60° сніг зісковзує, `η_snow ≈ 0.90..0.95`, при пологих кутах нахилу втрати можуть сягати 50–80 %);
- `η_wiring` — омічні втрати в кабелях і з'єднувачах (0.98–0.99);
- `η_temp_pv` — температурний коефіцієнт потужності панелі.

Загальний коефіцієнт передачі енергії системи становить:

```
η_sys = η_ctrl · η_dirt · η_snow · η_wiring · η_temp_pv
```

Звідси формула мінімально необхідної номінальної потужності фотопанелі `P_pv_STC` (у ватах):

```
P_pv_STC = (E_day / (PSH_worst · η_sys)) · [1 + N_autonomy / (N_recovery · η_batt)]
```

## 4. Фізика контролерів заряду: чому MPPT виграє 35 % саме взимку

Контролер заряду узгоджує вихід фотопанелі з хімічним накопичувачем. На ринку існують два принципово різних класи пристроїв: релейно-імпульсні ШІМ-контролери (англ. *Pulse-Width Modulation*, PWM) та контролери стеження за точкою максимальної потужності (англ. *Maximum Power Point Tracking*, MPPT).

![Порівняння ВАХ та робочих точок MPPT і PWM](/root/course/embedded/rozrakhunok-vuzla/img/mppt-vs-pwm-iv-power.svg)
*Вольт-амперна характеристика панелі взимку (-10 °C) та влітку (+45 °C): робочі точки MPPT і PWM та пояснення різниці ККД у 35% за низьких температур.*

### Фізика PWM-контролера: примусова фіксація напруги

PWM-контролер являє собою звичайний транзисторний ключ (MOSFET), увімкнений послідовно між сонячною панеллю та акумулятором. Коли транзистор відкритий, панель виявляється з'єднаною паралельно з акумулятором.

Згідно з законами напівпровідникових кіл, напруга на виході фотопанелі примусово затискається на поточному рівні напруги батареї `V_batt`:

```
V_pv_PWM = V_batt
```

Струм, який панель віддає в батарею, практично дорівнює її струму в цій точці вольт-амперної характеристики: `I_charge ≈ I_mp`.

Потужність, що надходить у батарею через PWM-контролер:

```
P_batt_PWM = V_batt · I_mp
```

Тим часом панель за поточного освітлення могла б видати максимальну потужність `P_max = V_mp · I_mp`. Ефективність використання потенціалу панелі ШІМ-контролером визначається співвідношенням напруг:

```
η_PWM_util = (V_batt · I_mp) / (V_mp · I_mp) = V_batt / V_mp
```

### Фізика MPPT-контролера: імпульсний трансформатор постійного струму

MPPT-контролер містить високочастотний синхронний знижувальний (*buck*) або підвищувально-знижувальний (*buck-boost*) перетворювач постійної напруги з мікроконтролерним керуванням. Контролер безперервно вимірює напругу `V_pv` та струм `I_pv`, підбираючи шпаруватість ШІМ так, щоб утримувати вхідний каскад у точці `(V_mp, I_mp)`, де потужність `P_pv = V_pv · I_pv` є максимальною.

Імпульсний перетворювач трансформує високу напругу панелі у вищий зарядний струм акумулятора зі збереженням балансу потужності за вирахуванням власного ККД перетворення `η_dcdc ≈ 96..98 %`:

```
P_batt_MPPT = P_max · η_dcdc
I_batt_MPPT = (V_mp · I_mp · η_dcdc) / V_batt
```

Оскільки `V_mp > V_batt`, зарядний струм `I_batt_MPPT` перевищує струм короткого замикання панелі.

### Температурний дрейф напруги: де ховається головна пастка

Кремнієвий фотоелемент має виражений негативний температурний коефіцієнт напруги холостого ходу `β_Voc ≈ -0.32..-0.38 %/°C` та напруги максимальної потужності `β_Vmp ≈ -0.35..-0.42 %/°C`. Зі зниженням температури заборонена зона напівпровідника розширюється, а напруга на контактах комірки зростає.

Для стандартної «12-вольтової» фотопанелі з номіналом `V_mp = 18.0 В` за STC (+25 °C):
- **Спекотне літо (+45 °C повітря, сонце розігріває елемент до +65 °C, `ΔT = +40 °C`):**
  Напруга в точці MPP просідає:
  ```
  V_mp(+65°C) = 18.0 В · [1 + (-0.0038) · 40] = 18.0 В · 0.848 = 15.26 В
  ```
  За напруги акумулятора `V_batt = 13.6 В` ефективність PWM становить:
  ```
  η_PWM = 13.6 / 15.26 ≈ 89.1 %
  ```
  Різниця між MPPT та PWM улітку становить лише 7–9 %. Проте влітку енергії сонця (5.8 PSH) завжди вистачає з надлишком.

- **Морозна зима (-15 °C повітря, сонце без вітру прогріває елемент до -5 °C, `ΔT = -30 °C`):**
  Напруга в точці MPP зростає:
  ```
  V_mp(-5°C) = 18.0 В · [1 + (-0.0038) · (-30)] = 18.0 В · 1.114 = 20.05 В
  ```
  За напруги розрядженого акумулятора `V_batt = 13.0 В` ефективність використання панелі через PWM обвалюється:
  ```
  η_PWM = 13.0 / 20.05 ≈ 64.8 %
  ```

PWM-контролер узимку викидає **35.2 % доступної сонячної енергії**, бо прибиває напругу високоефективного холодного фотоелемента до 13 вольтів. MPPT-контролер забирає всі 20.05 В і перетворює їх на додатковий зарядний струм, даючи критичний приріст потужності в той місяць, коли інсоляція найменша.

## 6. Наскрізний числовий розрахунок автономного польового поста

Розглянемо практичний інженерний приклад проєктування системи сонячного живлення для віддаленого автономного метеорологічного поста в околицях Житомира (широта 50.2° пн. ш.).

### Вхідні інженерні вимоги
1. **Навантаження:** Мікроконтролер STM32L4 + модем LTE-M/NB-IoT + датчики (BME280, ультразвуковий анемометр).
   - Режим сну (58 секунд): `V_bus = 3.3 В`, `I_sleep = 45 мкА = 0.045 мА`.
   - Режим зчитування датчиків (1 секунда): `I_sens = 15 мА`.
   - Режим радіопередачі звіту на сервер (1 секунда): `I_tx = 180 мА`.
   - Період циклу: `T_cycle = 60 с` (1 передача на хвилину).
2. **Електроніка живлення:** Синхронний DC-DC buck на платі з середнім ККД `η_conv = 0.90`.
3. **Кліматичні умови:**
   - Автономність при суцільній хмарності: `N_autonomy = 5 діб`.
   - Бажаний час повного відновлення заряду: `N_recovery = 4 доби`.
   - Найгірша середньодобова інсоляція (грудень): `PSH_worst = 1.10 год/доба`.
   - Мінімальна зимова температура: `-15 °C`.
4. **Компоненти:** Акумуляторна батарея LiFePO4 (4S, номінал `V_batt = 12.8 В`), контролер заряду MPPT.

---

### Крок 1. Розрахунок енергії одного циклу та добового споживання

Обчислюємо енергію одного 60-секундного циклу за фазами:

```
E_sleep = 3.3 В · 0.000045 А · 58 с = 0.008613 Дж
E_sens  = 3.3 В · 0.015 А · 1 с      = 0.049500 Дж
E_tx    = 3.3 В · 0.180 А · 1 с      = 0.594000 Дж
```

Сумарна енергія за один цикл:

```
E_cycle
= E_sleep + E_sens + E_tx               [додавання енергій окремих фаз]
= 0.008613 + 0.049500 + 0.594000
= 0.652113 Дж
```

Кількість циклів за 24 години:

```
N_cycles
= 86400 / 60                            [кількість секунд у 24 годинах / період циклу]
= 1440 циклів/доба
```

Добове споживання безпосередньо цифровою шиною 3.3 В (переведення джоулів у ват-години діленням на 3600):

```
E_load_day
= (1440 · 0.652113) / 3600              [енергія 1440 циклів у Вт·год]
= 939.04 Дж / 3600
= 0.2608 Вт·год/доба
```

Враховуємо ККД імпульсного стабілізатора плати (`η_conv = 0.90`), фоновий струм BMS (`I_bms = 25 мкА`) та нічний струм MPPT (`I_ctrl_dark = 50 мкА`):

```
E_bms_ctrl_day
= 12.8 В · (0.000025 А + 0.000050 А) · 24 год   [витоки BMS і темновий струм контролера]
= 12.8 В · 0.000075 А · 24 год
= 0.0230 Вт·год/доба
```

Повний добовий енергетичний попит системи з урахуванням саморозряду (`k_self = 1 %/міс`):

```
E_day
= (0.2608 / 0.90 + 0.0230) · 1.0005     [добове навантаження з витоками]
= (0.2898 + 0.0230) · 1.0005
= 0.3130 Вт·год/доба
```

---

### Крок 2. Розрахунок ємності акумуляторної батареї

Вихідні параметри накопичувача LiFePO4:
- Допустима глибина розряду: `DoD = 0.80`;
- ККД розряду-заряду: `η_batt = 0.95`;
- Температурний делейтинг ємності за -15 °C: `η_temp = 0.75`.

Розрахунок номінального запасу енергії:

```
E_batt_nom
= (E_day · N_autonomy) / (DoD · η_batt · η_temp)   [формула ємності під N діб]
= (0.3130 · 5) / (0.80 · 0.95 · 0.75)             [підстановка вхідних значень]
= 1.5650 / 0.5700
= 2.7456 Вт·год
```

Для батареї 4S LiFePO4 з номінальною напругою `V_batt_nom = 12.8 В`:

```
C_batt_Ah
= E_batt_nom / V_batt_nom                          [переведення енергії в ампер-години]
= 2.7456 / 12.8
= 0.2145 А·год = 214.5 мА·год
```

> 💡 **Практичний вибір компонентів:** Найменша стандартна промислова комірка циліндричного формату LiFePO4 IFR18650 має ємність 1500–1800 мА·год (1.5–1.8 А·год). Зібравши батарею 4S1P (12.8 В, 1.5 А·год, запас енергії `12.8 · 1.5 = 19.2 Вт·год`), ми отримуємо семикратний запас автономності (`N_real ≈ 35 діб`), що повністю нівелює ризик глибокого розряду та деградацію від старіння на роки вперед.

---

### Крок 3. Розрахунок потужності сонячної фотопанелі

Визначаємо сумарний системний ККД тракту генерації `η_sys`:
- ККД MPPT-контролера: `η_ctrl = 0.96`;
- Забруднення та пил: `η_dirt = 0.94`;
- Сніговий покрив (при куті нахилу 65°): `η_snow = 0.92`;
- Кабельні втрати: `η_wiring = 0.99`;
- Температурний коефіцієнт панелі на морозі (-5 °C на комірці): `η_temp_pv = 1.11`.

```
η_sys
= 0.96 · 0.94 · 0.92 · 0.99 · 1.11                 [добуток коефіцієнтів тракту]
= 0.9113
```

Обчислюємо необхідну пікову потужність панелі `P_pv_STC` за грудневим мінімумом `PSH_worst = 1.10 год/доба` та терміном відновлення `N_recovery = 4 доби`:

```
P_pv_STC
= (E_day / (PSH_worst · η_sys)) · [1 + N_autonomy / (N_recovery · η_batt)]  [формула з урахуванням відновлення]
= (0.3130 / (1.10 · 0.9113)) · [1 + 5 / (4 · 0.95)]
= (0.3130 / 1.0024) · [1 + 1.3158]
= 0.3122 · 2.3158
= 0.723 Вт_пік
```

> 💡 **Практичний вибір панелі:** Розрахункова потужність становить лише 0.72 Вт. Проте з міркувань механічної міцності, стійкості до граду та забезпечення заряду навіть під час суцільного щільного туману стандартно обирають невелику монокристалічну панель потужністю **5 Вт або 10 Вт** (з напругою `V_mp = 18 В`). Такий запас потужності гарантує відновлення заряду батареї навіть за один короткий проблиск сонця між хмарами тривалістю 40 хвилин.

## 7. Програмний калькулятор енергобалансу на C та C++

Наведений нижче програмний модуль реалізує повний інженерний алгоритм розрахунку автономної системи: обчислення добового споживання за циклічним профілем, визначення ємності акумулятора під задане число діб без сонця, розрахунок площі/потужності фотомодуля для MPPT та PWM варіантів, а також перевірку системи на ризик аварійного відключення.

```c
/* solar_sizing.h / solar_sizing.c — Інженерний калькулятор сонячного живлення */
#include <stdio.h>
#include <stdbool.h>
#include <math.h>

typedef struct {
    double bus_voltage_v;       /* Напруга цифрової шини, В (напр. 3.3) */
    double sleep_current_ma;    /* Струм глибокого сну, мА */
    double sleep_duration_s;    /* Тривалість сну в циклі, с */
    double active_current_ma;   /* Струм вимірювання, мА */
    double active_duration_s;   /* Тривалість вимірювання, с */
    double tx_current_ma;       /* Струм передавача, мА */
    double tx_duration_s;       /* Тривалість передачі, с */
    double conv_efficiency;     /* ККД стабілізатора плати (напр. 0.90) */
    double bms_dark_current_ua; /* Сумарний струм BMS і витоку MPPT, мкА */
} NodeProfile;

typedef struct {
    double autonomy_days;       /* Число діб без сонця (N_autonomy, напр. 5.0) */
    double recovery_days;       /* Доби на відновлення заряду (N_recovery, напр. 4.0) */
    double worst_psh;           /* Зимовий мінімум інсоляції, год (напр. 1.10) */
    double batt_nominal_v;      /* Номінальна напруга АКБ, В (12.8 для 4S LFP) */
    double max_dod;             /* Граничний DoD (0.80 для LiFePO4) */
    double batt_coulombic_eff;  /* ККД заряду батареї (0.95) */
    double temp_capacity_coeff; /* Температурний делейтинг АКБ (0.75 для -15°C) */
    bool   use_mppt;            /* true = MPPT (96%), false = PWM (65%) */
} SizingConstraints;

typedef struct {
    double e_day_wh;            /* Повне добове споживання, Вт·год/доба */
    double p_avg_mw;            /* Середня споживана потужність, мВт */
    double batt_energy_nom_wh;  /* Необхідний запас енергії АКБ, Вт·год */
    double batt_capacity_ah;    /* Необхідна ємність АКБ, А·год */
    double pv_power_required_w; /* Необхідна потужність панелі STC, Вт_пік */
    double system_efficiency;   /* Результуючий ККД тракту генерації */
} SizingResult;

bool calculate_solar_system(const NodeProfile *node,
                            const SizingConstraints *env,
                            SizingResult *res)
{
    if (!node || !env || !res) return false;
    if (node->conv_efficiency <= 0.0 || env->worst_psh <= 0.0 || env->batt_nominal_v <= 0.0)
        return false;

    /* 1. Енергія одного робочого циклу (в Джоулях) */
    double e_sleep_j = node->bus_voltage_v * (node->sleep_current_ma * 1e-3) * node->sleep_duration_s;
    double e_act_j   = node->bus_voltage_v * (node->active_current_ma * 1e-3) * node->active_duration_s;
    double e_tx_j    = node->bus_voltage_v * (node->tx_current_ma * 1e-3) * node->tx_duration_s;
    double e_cycle_j = e_sleep_j + e_act_j + e_tx_j;

    double t_cycle_s = node->sleep_duration_s + node->active_duration_s + node->tx_duration_s;
    if (t_cycle_s <= 0.0) return false;

    double cycles_per_day = 86400.0 / t_cycle_s;
    double e_load_day_wh  = (cycles_per_day * e_cycle_j) / 3600.0;

    /* Додавання втрат стабілізатора та постійних витоків */
    double e_leak_day_wh = env->batt_nominal_v * (node->bms_dark_current_ua * 1e-6) * 24.0;
    double e_day_gross   = (e_load_day_wh / node->conv_efficiency) + e_leak_day_wh;
    res->e_day_wh        = e_day_gross * 1.0005; /* +0.05% саморозряд на добу */
    res->p_avg_mw        = (res->e_day_wh / 24.0) * 1000.0;

    /* 2. Розрахунок акумулятора */
    double denom_batt = env->max_dod * env->batt_coulombic_eff * env->temp_capacity_coeff;
    if (denom_batt <= 0.0) return false;

    res->batt_energy_nom_wh = (res->e_day_wh * env->autonomy_days) / denom_batt;
    res->batt_capacity_ah   = res->batt_energy_nom_wh / env->batt_nominal_v;

    /* 3. Розрахунок сонячного модуля */
    double eta_ctrl = env->use_mppt ? 0.96 : 0.65;
    double eta_dirt = 0.94;
    double eta_snow = 0.92;
    double eta_wire = 0.99;
    double eta_temp_pv = 1.11; /* Зимовий приріст напруги Voc/Vmp */

    res->system_efficiency = eta_ctrl * eta_dirt * eta_snow * eta_wire * eta_temp_pv;

    double recovery_factor = 1.0 + (env->autonomy_days / (env->recovery_days * env->batt_coulombic_eff));
    res->pv_power_required_w = (res->e_day_wh / (env->worst_psh * res->system_efficiency)) * recovery_factor;

    return true;
}
```

```cpp
    double tx_duration_s       = 1.0;   // Час передачі, с
    double conv_efficiency     = 0.90;  // ККД DC-DC бака
    double bms_dark_current_ua = 75.0;  // Сумарний витік (BMS + темновий контролера), мкА
};

struct SizingConstraints {
    double autonomy_days       = 5.0;   // Число діб без сонця (N_autonomy)
    double recovery_days       = 4.0;   // Доби на відновлення (N_recovery)
    double worst_psh           = 1.10;  // Грудневий PSH, год/доба
    double batt_nominal_v      = 12.8;  // Номінальна напруга батареї, В (4S LiFePO4)
    double max_dod             = 0.80;  // Гранична глибина розряду (80% для LFP)
    double batt_coulombic_eff  = 0.95;  // Ефективність заряду АКБ
    double temp_capacity_coeff = 0.75;  // Делейтинг ємності при -15 °C
    bool   use_mppt            = true;  // Тип контролера: true = MPPT, false = PWM
};

struct SizingResult {
    double e_day_wh;            // Добовий бюджет, Вт·год/доба
    double p_avg_mw;            // Середня потужність, мВт
    double batt_energy_nom_wh;  // Номінальна енергія АКБ, Вт·год
    double batt_capacity_ah;    // Ємність АКБ, А·год
    double pv_power_required_w; // Необхідна потужність панелі STC, Вт_пік
    double system_efficiency;   // Підсумковий ККД тракту
};

[[nodiscard]] constexpr auto calculate_system(const NodeProfile& node,
                                              const SizingConstraints& env)
    -> std::expected<SizingResult, SizingError>
{
    if (node.bus_voltage_v <= 0.0 || env.batt_nominal_v <= 0.0) {
        return std::unexpected(SizingError::kInvalidVoltages);
    }
    if (node.conv_efficiency <= 0.0 || node.conv_efficiency > 1.0 ||
        env.max_dod <= 0.0 || env.max_dod > 1.0) {
        return std::unexpected(SizingError::kInvalidEfficiencyRange);
    }
    if (env.worst_psh <= 0.0) {
        return std::unexpected(SizingError::kZeroSolarIrradiance);
    }

    const double t_cycle = node.sleep_duration_s + node.active_duration_s + node.tx_duration_s;
    if (t_cycle <= 0.0) {
        return std::unexpected(SizingError::kInvalidTimeIntervals);
    }

    // 1. Інтегрування енергії робочого циклу
    const double e_sleep_j = node.bus_voltage_v * (node.sleep_current_ma * 1e-3) * node.sleep_duration_s;
    const double e_act_j   = node.bus_voltage_v * (node.active_current_ma * 1e-3) * node.active_duration_s;
    const double e_tx_j    = node.bus_voltage_v * (node.tx_current_ma * 1e-3) * node.tx_duration_s;
    const double e_cycle_j = e_sleep_j + e_act_j + e_tx_j;

    const double cycles_per_day = 86400.0 / t_cycle;
    const double e_load_day_wh  = (cycles_per_day * e_cycle_j) / 3600.0;

    const double e_leak_day_wh = env.batt_nominal_v * (node.bms_dark_current_ua * 1e-6) * 24.0;
    const double e_day_gross   = (e_load_day_wh / node.conv_efficiency) + e_leak_day_wh;
    const double e_day_wh      = e_day_gross * 1.0005; // Врахування саморозряду LFP
    const double p_avg_mw      = (e_day_wh / 24.0) * 1000.0;

    // 2. Розрахунок акумуляторного блоку
    const double denom_batt = env.max_dod * env.batt_coulombic_eff * env.temp_capacity_coeff;
    const double batt_energy_nom_wh = (e_day_wh * env.autonomy_days) / denom_batt;
    const double batt_capacity_ah   = batt_energy_nom_wh / env.batt_nominal_v;

    // 3. Розрахунок сонячного поля з урахуванням делейтингу
    const double eta_ctrl    = env.use_mppt ? 0.96 : 0.65;
    constexpr double kEtaDirt = 0.94;
    constexpr double kEtaSnow = 0.92;
    constexpr double kEtaWire = 0.99;
    constexpr double kEtaTemp = 1.11; // Зимовий температурний виграш

    const double sys_eff = eta_ctrl * kEtaDirt * kEtaSnow * kEtaWire * kEtaTemp;
    const double recovery_factor = 1.0 + (env.autonomy_days / (env.recovery_days * env.batt_coulombic_eff));
    const double pv_power_w = (e_day_wh / (env.worst_psh * sys_eff)) * recovery_factor;

    return SizingResult{
        .e_day_wh            = e_day_wh,
        .p_avg_mw            = p_avg_mw,
        .batt_energy_nom_wh  = batt_energy_nom_wh,
        .batt_capacity_ah    = batt_capacity_ah,
        .pv_power_required_w = pv_power_w,
        .system_efficiency   = sys_eff
    };
}

} // namespace power::solar
```

## 8. Практичний чеклист для польового монтажу

Перед тим як закрити герметичний корпус вузла й закріпити його на щоглі, перевірте систему за такими інженерними критеріями:

1. **Кут нахилу фотопанелі:** Для цілорічної автономії встановлюйте кут `Кут = Широта + 15°` (для України це 60°–65° від горизонту). Це мінімізує накопичення снігу взимку та максимізує збір енергії під час низького зимового сонця.
2. **Орієнтація за азимутом:** Суворо на південь (істинний географічний, а не магнітний з урахуванням магнітного схилення).
3. **Блокування заряду на морозі:** Перевірте спрацювання порогу відсічки заряду BMS або MPPT-контролера при температурі нижче 0 °C.
4. **Запас напруги MPPT:** Переконайтеся, що напруга панелі `V_mp` за найвищої літньої температури (+65 °C) перевищує кінцеву напругу заряду акумулятора (`V_charge_max = 14.4..14.6 В` для 4S LFP) щонайменше на 1.5–2.0 В, інакше понижувальний MPPT-контролер вийде з режиму стабілізації.
5. **Нічний розряд:** Виміряйте амперметром зворотний струм витоку з акумулятора в сонячну панель у повній темряві: він не повинен перевищувати 50–100 мкА.
