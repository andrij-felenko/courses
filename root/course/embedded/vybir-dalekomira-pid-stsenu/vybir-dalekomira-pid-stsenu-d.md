# Вибір далекоміра під сцену: ультразвук, оптичний ToF, LiDAR, радар

- [Бюджет похибок далекоміра](root:embedded/error-budget-ranging) — систематичний зсув, випадковий розкид та температурна залежність.
- [Архітектури LiDAR](root:embedded/lidar-architecture) — скануючі та твердотільні лазерні давачі, просторова роздільність.
- [Відбиття IR і оптичний бар'єр](root:hw-sensing/reflection-absorption) — оптичне альбедо поверхонь, поглинання та дзеркальність.
</preknowlist>

Колісний робот рухається коридором зі швидкістю півтора метра на секунду. Бортовий далекомір опитує простір перед бампером, щоб вчасно подати команду аварійного гальмування за двадцять сантиметрів до перешкоди. Якщо на роботі встановлено ультразвуковий сонар, а попереду стоїть офісний диван із м'якою оксамитовою оббивкою, звукова хвиля 40 кГц повністю затухає в порах тканини. Давач повертає таймаут луни — «простір вільний», і робот врізається в диван на повному ходу. Якщо замінити сонар на лазерний далекомір Time-of-Flight і пустити той самий апарат через терасу під пряме сонячне світло назустріч чорному гумовому колесу візка, фотонний приймач засліпне від інфрачервоного шуму сонця, а п'ятивідсоткове альбедо гуми не поверне достатньо лазерних фотонів. Робоча дальність сенсора миттєво впаде з двох метрів до двадцяти сантиметрів — робот знову не встигне зупинитися.

Ці аварії стаються не через несправність сенсорів чи помилки в таймерах мікроконтролера. Вони виникають тому, що вбудована система намагається виміряти геометрію простору хвилями, фізика яких несумісна з матеріалом конкретної сцени. Ультразвук, оптичний лазер і мікрохвильовий радар взаємодіють із речовиною за принципово різними законами: механічна пружність середовища, квантове поглинання фотонів у діелектриках та електромагнітна провідність на надвисоких частотах ставлять нездоланні межі кожному типу випромінювання. Універсального далекоміра не існує; надійність автономної системи залежить виключно від того, наскільки точно фізика зондувального променя відповідає оптичним, акустичним і радіолокаційним властивостям перешкод.

![Порівняння геометрії випромінювання та чутливих зон сенсорів відстані](/root/course/embedded/vybir-dalekomira-pid-stsenu/img/sensor-cone-comparison.svg)
*Геометрія випромінювання чотирьох класів далекомірів. Ультразвуковий сонар формує широкий акустичний конус 25°–30°, оптичний ToF покриває пірамідальне поле зору з розбиттям на матрицю зон, 2D LiDAR сканує простір голковим колімованим променем із роздільністю часток градуса, а mmWave радар випромінює широку радіопелюстку, вимірюючи вектор доплерівської швидкості.*

## 1. Фізичний ландшафт: швидкість хвилі та вимоги до кремнію

Усі активні далекоміри розв'язують одне й те саме фізичне рівняння: вони посилають хвильовий пакет у бік об'єкта, фіксують відбитий сигнал і перераховують час подвійного пробігу `t` або зсув фази у відстань `d`:

```
d = (v · t) / 2
```

де `v` — швидкість поширення зондувальної хвилі в середовищі. Головний вододіл між сенсорами пролягає у природі цієї хвилі: ультразвук є механічним коливанням молекул повітря, тоді як оптичний ToF, LiDAR і радар використовують електромагнітні коливання різної частоти.

Ця різниця задає розрив у швидкості поширення майже на шість порядків:

```
v_sound  ≈ 3.43 · 10² м/с      (повітря за нормальних умов, +20 °C)
c_em     ≈ 3.00 · 10⁸ м/с      (світло та радіохвилі у вакуумі й повітрі)
c_em / v_sound ≈ 874 600       (електромагнітна хвиля швидша у 875 тисяч разів)
```

Швидкість поширення безпосередньо визначає масштаб часових інтервалів, які має реєструвати цифрова електроніка мікроконтролера чи вбудованого кремнієвого кристала.

```
Час прольоту туди й назад на дистанції d = 1.0 м:
  Ультразвук:  t_us  = (2 · 1.0) / 343   ≈ 5.830 мс  = 5 830 000 нс
  Світло/Радіо: t_em  = (2 · 1.0) / 3·10⁸ ≈ 6.671 нс  = 6 671 пс

Часова роздільність таймера, необхідна для точності Δd = 1.0 мм:
  Ультразвук:  Δt_us = (2 · 0.001) / 343   ≈ 5.83 мкс (тактова частота всього 172 кГц)
  Світло/Радіо: Δt_em = (2 · 0.001) / 3·10⁸ ≈ 6.67 пс  (еквівалентна тактова частота 150 ГГц)
```

Ці розрахунки показують фундаментальну інженерну відмінність. Ультразвуковий далекомір не потребує спеціалізованої вимірювальної кремнієвої логіки: стандартний 16-бітний апаратний таймер загального призначення будь-якого мікроконтролера з тактовою частотою 16 МГц забезпечує апаратну дискретність відліку 62.5 нс, що теоретично відповідає просторовій роздільності близько 0.01 мм. Проте низька швидкість звуку обмежує темп оновлення даних: щоб дочекатися повернення луни з дистанції 4 метри, процесор змушений чекати щонайменше 24 мілісекунди. З урахуванням затухання залишкових реверберацій кімнати максимальна частота вимірювань ультразвуку рідко перевищує 20–30 Гц.

Навпаки, вимірювання затримки світла з точністю до міліметрів вимагає реєстрації одиничних пікосекунд. Жоден мікроконтролер не здатен тактувати лічильник на частотах сотень гігагерців. Тому оптичні Time-of-Flight сенсори та лазерні далекоміри містять спеціалізовані аналогово-цифрові перетворювачі часу на кристалі — перетворювачі часу в цифровий код (TDC, англ. *Time-to-Digital Converter*) на базі каліброваних ліній затримки інверторів, статистичні гістограмні процесори накопичення фотонів або змішувачі частоти для неперервного фазового детектування (iToF / FMCW).

> 🔧 **Навіщо це.** Співвідношення швидкостей пояснює архітектуру опитування сенсорів у прошивці: ультразвук створює відчутну затримку в циклі керування (десятки мілісекунд очікування відлуння блокують або змушують писати асинхронні переривання), тоді як оптичний ToF або LiDAR повертають готові цифрові пакети шиною I2C, SPI чи UART із внутрішнього сигнального співпроцесора з частотою до сотень герц або кілогерців.

## 2. Акустичний ультразвук: термодинаміка, конуси та сліпі кути

Ультразвуковий далекомір випромінює короткий пакет коливань на п'єзокерамічному випромінювачі (зазвичай 8–16 періодів частоти 40 кГц), після чого аналоговий тракт перемикається в режим прийому і чекає на появу напруги відбитої акустичної хвилі на п'єзоприймачі. За цим принципом побудовані як відкриті здвоєні модулі (HC-SR04), так і водонепроникні автомобільні однотрансд'юсерні сенсори (JSN-SR04T).

### Температурна залежність швидкості звуку

Оскільки звук є коливанням пружного середовища, швидкість його поширення в ідеальному газі залежить виключно від термодинамічної температури:

```
c = √(γ · R_spec · T_kelvin)
```

де `γ = 1.40` — показник адіабати для двоатомних газів повітря, `R_spec = 287.05 Дж/(кг·К)` — питома газова стала, а `T_kelvin = T_celsius + 273.15`. Для практичного діапазону температур від −20 °C до +50 °C функцію лінеаризують навколо точки замерзання води:

```
c(T) ≈ 331.3 + 0.606 · T        (м/с, де T — температура повітря в °C)
```

Якщо прошивка мікроконтролера розраховує дистанцію за фіксованою швидкістю звуку `c = 343 м/с` (значення для лабораторних +20 °C), зміна погоди вносить пряму масштабну систематичну похибку:

```
При температурі T = −10 °C:
  Справжня швидкість звуку: c(−10) = 331.3 + 0.606 · (−10) = 325.24 м/с
  Зашита в код константа:   c_fixed = 343.00 м/с
  Відносна похибка:         (343.00 − 325.24) / 325.24 = +5.46 %

На реальній відстані d_true = 3.000 м:
  Виміряний час прольоту:   t = (2 · 3.000) / 325.24 = 18.448 мс
  Обчислена мікроконтролером відстань: d = (343.00 · 0.018448) / 2 = 3.164 м
  Систематична помилка:     +16.4 см (апарат вважає, що стіна далі, ніж вона є)
```

Помилка у 16 сантиметрів на трьох метрах неприпустима для точного маневрування. Тому будь-який надійний ультразвуковий вузол повинен містити поруч цифровий термометр (термістор NTC або цифровий датчик температури) і динамічно перераховувати коефіцієнт часу в прошивці на кожному такті вимірювання.

### Просторова невизначеність широкого конуса

П'єзоелемент діаметром 10–16 мм на частоті 40 кГц (`λ ≈ 8.58 мм`) формує діаграму спрямованості з кутом розкриття головної пелюстки від 25° до 35°. Амплітуда звукового тиску спадає від центральної осі до країв за законом Бесселя, утворюючи конус чутливості.

```
Радіус конуса виявлення r_cone на дистанції d:
  r_cone = d · tan(θ / 2)
  Для кута θ = 30° та відстані d = 2.0 м:
  r_cone = 2.0 · tan(15°) ≈ 2.0 · 0.268 = 0.536 м (пляма діаметром понад метр)
```

Широкий конус має дві протилежні інженерні властивості:
1. **Перевага:** сонар надійно фіксує перешкоди, що знаходяться трохи збоку від осі руху робота (наприклад, кут столу, повз який проходить платформа), без необхідності механічного сканування;
2. **Недолік (просторова сліпота):** давач фіксує лише *перше найкоротше відлуння*. Якщо на відстані 1.5 метра збоку знаходиться стіна, а прямо по курсу на відстані 2.0 метри — вільний прохід, сонар поверне дистанцію 1.5 м. Робот знає, що всередині півметрової плями щось є, але не може визначити, під яким саме кутом лежить перешкода.

```
Звуковий тиск у вільному просторі спадає обернено пропорційно квадрату відстані:
  P(d) ∝ 1 / d
Для відбитої луни подвійного пробігу потужність сигналу спадає як 1 / d⁴.
Поглинання звуку в сухому повітрі на 40 кГц додає додаткове затухання ≈ 1.2 дБ/м.
```

### Дзеркальність площин та акустичне поглинання

Довжина хвилі 40 кГц дорівнює 8.6 мм. За критерієм Релея, поверхня вважається шорсткою і розсіює хвилю дифузно в усі боки лише тоді, коли висота її нерівностей співмірна з довжиною хвилі (`h > λ / 8 ≈ 1 мм`). Для звуку 40 кГц звичайна поштукатурена стіна, скло, поліроване дерево, листовий метал або плитка є ідеально гладкими дзеркалами.

![Фізичні пастки сцени для ультразвуку, оптичного ToF, LiDAR і радара](/root/course/embedded/vybir-dalekomira-pid-stsenu/img/scene-physics-traps.svg)
*Чотири фундаментальні пастки матеріалів: (1) Акустичне дзеркальне відбиття під кутом > 15° відводить звукову хвилю повз приймач; (2) Сонячне випромінювання на довжині 940 нм заливає SPAD-матрицю паразитною лавиною, а чорна гума поглинає 95% фотонів; (3) Лазерний промінь 905 нм проходить крізь прозоре віконне скло або відбивається у фальшиві кімнати; (4) mmWave радар вільно проходить крізь сухий пластиковий бампер, але зазнає інтерференційних перевідбиттів від металевих поверхонь.*

Згідно із законом геометричного відбиття, кут відбиття дорівнює куту падіння. Якщо робот наближається до стіни під кутом падіння `α > 15°–20°` відносно нормалі, звуковий пучок відбивається дзеркально вперед у бік кімнати, жодна частка енергії не повертається назад у приймач, і давач фіксує повну відсутність перешкоди аж до фізичного зіткнення.

Друга критична межа акустики — поглинання. Коли хвиля стикається з пористим матеріалом (одяг, м'які меблі, пінопласт, волокнисті утеплювачі, хутро), повітря в мікропорах починає коливатися, і кінетична енергія звуку через в'язке тертя перетворюється на тепло. Коефіцієнт відбиття таких матеріалів на 40 кГц падає нижче 0.05 (понад 95% енергії поглинається), амплітуда луни падає нижче порогу аналогового компаратора, і перешкода стає акустичною «чорною дірою».

### Дилема сенсорів: відкритий HC-SR04 проти герметичного JSN-SR04T

При виборі ультразвукового модуля інженер стикається з компромісом між сліпою зоною та кліматичною стійкістю:

| Параметр | HC-SR04 (відкритий) | JSN-SR04T (герметичний IP67) |
|---|---|---|
| **Конструкція** | 2 роздільні капсули (TX і RX) | 1 спільна герметична капсула (TX/RX) |
| **Мінімальна сліпа зона** | **2 см** | **20–25 см** |
| **Максимальна дальність** | 4.0 м | 4.5–5.0 м |
| **Стійкість до вологи/пилу** | Відсутня (сітка відкрита для води) | Повна (алюмінієва закрита чашка) |
| **Причина обмеження зблизька**| Геометричний паралакс капсул | Резонансний дзвін мембрани (Ring-down) |

У герметичному JSN-SR04T один і той самий важкий металевий диск випромінює імпульс збудження напругою близько 100 В і потім приймає мікровольтову луну. Після вимкнення імпульсу масивна мембрана за інерцією продовжує коливатися (процес «ring-down») протягом 1.0–1.5 мс. Якщо перешкода знаходиться ближче 20–25 см, відбита хвиля повертається в момент, коли мембрана ще дзвенить від власного пострілу. Аналоговий тракт не здатний відокремити власні залихові коливання від слабкої зовнішньої луни, тому приймач примусово блокується апаратним бланкуванням (blanking time) на перші 1.2 мс, створюючи непереборну чвертьметрову сліпу зону.

## 3. Оптичний Time-of-Flight: кремнієві SPAD-матриці та сонячний шум

Оптичні далекоміри прямого часу польоту (dToF, наприклад сімейство STMicroelectronics: VL53L0X, VL53L1X, VL53L5CX) зробили революцію у вимірюванні близьких дистанцій. Вони об'єднують на одному напівпровідниковому кристалі твердотільний лазерний діод вертикального резонатора (VCSEL) та матрицю лавинних фотодіодів одиничних фотонів (SPAD, англ. *Single-Photon Avalanche Diode*).

```
Джерело світла: Інфрачервоний напівпровідниковий лазер VCSEL
Довжина хвилі:   λ = 940 нм (невидимий діапазон, безпечний для очей Class 1)
Тривалість імпульсу: τ < 1.0 нс (пікова оптична потужність одиниці міліват)
```

### Принцип роботи SPAD у гейгерівському режимі

Звичайний фотодіод генерує один електрон на один поглинений фотон, створюючи мікроскопічний фотострум, який губиться в теплових шумах підсилювача при надкоротких наносекундних імпульсах. На противагу йому, SPAD зміщується зворотною напругою, яка на кілька вольт перевищує напругу лавинного пробою кремнієвого p-n переходу (режим Гейгера, англ. *Geiger-mode*).

У такому стані діод перебуває в метастабільній рівновазі з гігантською напруженістю внутрішнього електричного поля. Поглинання навіть одного-єдиного фотона оптичного сигналу породжує первинну пару електрон-дірка, яка миттєво запускає лавинний пробій кремнію. Протягом сотень пікосекунд виникає макроскопічний струмовий сплеск амплітудою в міліампери, що перемикає стандартний логічний КМОН-вентиль. Інтегрована схема пасивного або активного гасіння (quenching circuit) за кілька наносекунд знижує зворотну напругу нижче порогу пробою, зупиняє лавину і повертає піксель у стан очікування наступного фотона.

```
SPAD реєструє не амплітуду світлової хвилі, а точний момент прибуття першого фотона:
  1 фотон 940 нм → Лавинний пробій → Логічний рівень 3.3 В за час t_rise < 100 пс.
```

### Статистичне гістограмування та пікова фільтрація

Один виліт лазерного фотона не дає надійного вимірювання: фотон може бути випадковим квантом шуму, або лавина може не виникнути через квантову ефективність детектора (PDE ≈ 5–15% на довжині 940 нм). Тому мікропроцесор сенсора виконує цикл вимірювання пакетами:
1. VCSEL випромінює серію з десятків тисяч імпульсів на частотах до кількох мегагерців;
2. Внутрішній перетворювач TDC розбиває часову шкалу на дискретні корзини (bins) шириною від десятків до сотень пікосекунд;
3. Для кожного зафіксованого спрацювання SPAD збільшується лічильник відповідної часової корзини;
4. Апаратний DSP будує статистичну гістограму розподілу прибуття фотонів у часі.

Реальний фізичний об'єкт проявляється на гістограмі у вигляді чіткого гауссового піка над рівномірною шумовою підлогою фонового засвічення. Інтерполяція вершини цього піка дозволяє визначити центр імпульсу з суб-біновою точністю, досягаючи роздільності вимірювання дистанції до 1 міліметра.

```
Фотонна гістограма:
Лічильник
  ^
  |        Справжня ціль (пік лазера)
  |               / \
  |              /   \
  |             /     \
  |   Шум      /       \         Шум
  | =======---/         \---============  <- Фонове сонячне засвічення (Ambient)
  +-------------------------------------> Час t (bins, кроки по ~100 пс)
```

### Сонячне засвічення (Ambient IR Noise) та альбедо цілі

Оптичний ToF чудово працює в приміщеннях, але зазнає деградації на вулиці через два фізичні фактори:

**1. Фоновий потік сонячних фотонів.**
Сонячне випромінювання на поверхні Землі має безперервний спектр. На довжині хвилі 940 нм (яка обрана виробниками саме через наявність природної смуги поглинання водяної пари в атмосфері) спектральна густина сонячної потужності в ясний полудень досягає `~1.0 Вт/(м²·нм)`. Вузькосмуговий оптичний фільтр над кристалом пропускає частину цього потоку. Сонячні фотони бомбардують SPAD-матрицю з частотою мільйонів подій на секунду, викликаючи безперервні паразитні спрацювання. Коли лічильники всіх корзин гістограми заповнюються шумом, корисний лазерний пік тоне у шумових флуктуаціях (падає коефіцієнт сигнал/шум, SNR).

**2. Спектральне альбедо (відбивна здатність) матеріалу.**
Потужність сигналу, що повертається на матрицю від дифузного ламбертового об'єкта, пропорційна його альбедо `R`:

```
P_rx = P_tx · (R / π) · (A_lens / d²) · η_opt · exp(−2·α_atm·d)
```

де `R` — коефіцієнт відбиття на довжині хвилі 940 нм, `A_lens` — площа вхідної апертури приймача, `d` — дистанція, `η_opt` — оптичний ККД лінзи.

```
Порівняння поверхонь:
  Білий офісний папір / світла фарба: R ≈ 0.88–0.90 (відбиває 90% фотонів)
  Сірий бетон / дерево:                R ≈ 0.40–0.50 (відбиває 50% фотонів)
  Чорний матовий пластик / автомобільна гума: R ≈ 0.05–0.08 (відбиває лише 5% фотонів)
```

Падіння альбедо з 90% до 5% зменшує потік корисних фотонів у 18 разів. Оскільки дисперсія випадкового шуму реєстрації пропорційна квадратному кореню зі співвідношення сигнал/шум, вимірювання до чорних об'єктів мають у кілька разів більший випадковий розкид (джитер) і різко скорочену максимальну дальність:

```
Залежність максимальної дальності VL53L1X від умов середовища:
  Приміщення (темрява/штучне світло), біла ціль (R=90%): d_max = 4.0 м
  Приміщення, чорна ціль (R=5%):                        d_max = 1.3 м
  Яскраве сонце на вулиці (>50 клк), біла ціль (R=90%): d_max = 1.2 м
  Яскраве сонце на вулиці (>50 клк), чорна ціль (R=5%):  d_max = 0.4 м
```

### Захисне скло (Cover Glass) та паразитна засвітка (Cross-talk)

При проектуванні пристрою ToF-сенсор зазвичай ховають під захисне скло або прозору пластикову панель корпусу. Якщо скло встановлено неправильно (немає світлонепроникної прокладки між випромінювачем і приймачем або між склом і кристалом є зазор понад 0.5 мм), виникає явище оптичного перехресного зв'язку (Cross-talk).

Частина лазерного випромінювання відбивається від внутрішньої або зовнішньої поверхні захисного скла (через різницю показників заломлення скла `n ≈ 1.5` та повітря `n = 1.0` коефіцієнт відбиття за формулами Френеля становить близько 4% на кожній грані) і потрапляє прямо в сусідню SPAD-матрицю на відстані кількох міліметрів. Оскільки ця паразитна відстань прямує до нуля, на гістограмі з'являється потужний хибний пік на нульовій дистанції, який перекриває відлуння від реальних близьких об'єктів. Бруд, відбитки пальців чи подряпини на склі багаторазово підсилюють cross-talk, роблячи необхідним процедуру апаратного калібрування зсуву нуля та перехресних завад під час виробництва.

## 4. Скануючі та твердотільні LiDAR: кутова роздільність та середовище

LiDAR (Light Detection and Ranging) використовує ту саму фізику вимірювання часу польоту світла, що й ToF, але має оптичну систему зовсім іншого класу. Якщо ToF-сенсор заливає розсіяним світлом широку півсферу з кутом 25°–60°, то LiDAR фокусує випромінювання коліматорною лінзою у надтонкий промінь із розбіжністю (divergence) всього 0.1°–0.5° (менше 2–8 мілірадіан).

```
Діаметр світлової плями LiDAR на відстані d = 10 м:
  D_spot = D_initial + d · θ_div
  Для початкового діаметра 5 мм та розбіжності θ_div = 0.2° (0.0035 рад):
  D_spot = 0.005 + 10 · 0.0035 = 0.040 м = 4.0 см (вузька пляма замість 5-метрового конуса)
```

Завдяки цьому лазерний промінь зберігає високу густину енергії на великих дистанціях і забезпечує мікроскопічну просторову дискретність.

### Класифікація конструкцій: від 1D далекомірів до 2D/3D сканерів

1. **1D точкові далекоміри (TFmini Plus, Benewake, LeddarTech):**
   Нерухомий лазерний тракт, спрямований в одну точку. Частота опитування досягає 1000–4000 Гц. Застосовуються як оптичні висотоміри для дронів, датчики присутності на конвеєрах та далекоміри в бамперах для екстреного виявлення перешкод по курсу.
2. **2D механічні сканери (RPLIDAR A1/A2/A3, YDLIDAR):**
   Оптична голівка обертається електродвигуном на 360° у горизонтальній площині з частотою 5–15 Гц. Лазер імпульсно спрацьовує з частотою від 4 до 16 кГц, повертаючи в мікроконтролер суцільну кругову хмару точок: масив пар `(кут θ, відстань d)` для побудови двовимірних карт приміщень у SLAM.
3. **Твердотільні (Solid-State) та призматичні LiDAR (Livox Mid-360, Ouster):**
   Не мають масивних обертових голівок. Відхилення променя здійснюється за допомогою мікроелектромеханічних дзеркал (MEMS), обертових клиноподібних призм Ріслі або фазованих оптичних ґраток (OPA). Мають підвищену вібростійкість і створюють щільні тривимірні хмари точок.

### Атмосферні явища: розсіювання на пилу, димі та краплях дощу

Головний ворог лазерного променя у відкритому середовищі — завислі у повітрі мікрочастинки. Залежно від співвідношення між розміром частинки `a` та довжиною хвилі лазера `λ` (зазвичай 905 нм або 1550 нм) взаємодія описується двома режимами:

1. **Релеївське розсіювання (`a ≪ λ`, молекули газів, дрібний дим):**
   Інтенсивність розсіювання обернено пропорційна четвертій степені довжини хвилі (`I ∝ 1/λ⁴`). Лазерний промінь 905 нм проходить крізь чисте повітря практично без втрат, але сизий дим викликає затухання променя.
2. **Розсіювання Мі (`a ≳ λ`, пилова буря, туман, краплі дощу, сніг):**
   Розмір крапель туману (1–20 мкм) та дощу (0.5–5 мм) значно перевищує довжину хвилі. Світло відбивається, заломлюється і розсіюється назад прямо у вхідну зіницю приймача.

```
Фізичний наслідок дощу та пилу:
  Кожна крапля води на відстані 20 см від оптики відбиває частку світлового імпульсу.
  Одинарний піковий детектор фіксує цю луну як тверду перешкоду прямо перед лінзою.
```

Для подолання цієї проблеми професійні LiDAR використовують технологію **багатолунного детектування (Multi-echo / Multi-target)**: приймальний тракт реєструє до 3–5 послідовних піків від одного лазерного пострілу. Перший пік (слабкий, на відстані 0.3 м) відсіюється прошивкою як крапля дощу або завись пилу, а останній найпотужніший пік (на відстані 12.4 м) береться за справжню координату стіни чи стовпа.

### Оптичні пастки матеріалу: вікна та дзеркала

Скло та дзеркальні поверхні створюють для LiDAR критичні аномалії картографування:
* **Прозоре віконне скло:** коефіцієнт пропускання листового силікатного скла на довжині хвилі 905 нм перевищує 90%. Лазерний промінь безперешкодно проходить крізь вітрину чи двері і повертає відлуння від предметів усередині кімнати. Алгоритм SLAM позначає простір як вільний, і робот намагається проїхати крізь скляні двері.
* **Оптичне дзеркало:** промінь відбивається без дифузного розсіювання і летить під кутом убік, вимірюючи відстань до предметів, відбитих у дзеркалі. На карті простору виникає віртуальна кімната-двійник («дзеркальний фантом»), якої не існує у фізичній реальності.

## 5. Радіолокаційні mmWave радари: всепогодність і вектор швидкості

Мікрохвильові радари міліметрового діапазону (mmWave) працюють на несучих частотах 24 ГГц (довжина хвилі `λ = 12.5 мм`), 60–64 ГГц (`λ = 5.0 мм`) та 77–81 ГГц (`λ = 3.8 мм`). На відміну від оптичних систем, вони використовують хвилі, для яких більшість побутових матеріалів є прозорими діелектриками.

### Метод частотно-модульованої неперервної хвилі (FMCW)

Сучасні однокристальні радари (наприклад, Texas Instruments IWR6843, IWR1843 або сенсори HLK-LD2410) будуються на базі технології FMCW (англ. *Frequency Modulated Continuous Wave*). Передавач випромінює безперервний радіосигнал, частота якого лінійно зростає з часом — так званий **чирп** (chirp).

```
Частота випромінювання чирпа:
  f_tx(t) = f_start + S · t,   де t ∈ [0, T_chirp]
  S = B / T_chirp — швидкість зміни частоти (slope, МГц/мкс)
  B — смуга девіації частоти (наприклад, від 77 до 81 ГГц, B = 4 ГГц)
```

Прийнятий відбитий сигнал `f_rx(t)` є затриманою копією випроміненого на час прольоту `t_delay = 2·d / c`. В аналоговому змішувачі (радіочастотному мікшері) випромінюваний сигнал перемножується з прийнятим відлунням. Результатом низькочастотної фільтрації є сигнал проміжної частоти (IF, англ. *Intermediate Frequency*) або частота биття `f_beat`:

```
f_beat = |f_tx(t) − f_rx(t)| = S · t_delay = S · (2 · d / c)
```

Звідси відстань до перешкоди прямо пропорційна виміряній частоті биття:

```
d = (c · f_beat) / (2 · S)
```

```
Графік зміни частоти FMCW:
Частота f
  ^
  |      Випромінений чирп f_tx
  |     /              /
  |    /   Відбитий   /
  |   /   /          /
  |  /   / f_rx     /
  | /   /          /
  |/   /          /
  +---+----------+--------------------> Час t
      |<-t_delay>|
      |          |
  Різниця частот = f_beat (стала протягом чирпа, вимірюється звичайним АЦП!)
```

Замість надшвидкісних пікосекундних таймерів радар оцифровує сигнал биття стандартним звуковим чи інструментальним АЦП на частотах одиниць мегагерців. Роздільна здатність за відстанню `Δd` залежить виключно від ширини смуги модуляції `B`:

```
Δd = c / (2 · B)
Для автомобільного радара зі смугою B = 4 ГГц (77–81 ГГц):
  Δd = 3 · 10⁸ / (2 · 4 · 10⁹) = 0.0375 м = 3.75 см
```

### Двовимірне БПФ та миттєвий доплерівський вектор швидкості

Головна перевага mmWave радара перед усіма оптичними та ультразвуковими давачами — здатність вимірювати радіальну швидкість цілі безпосередньо у фізичному шарі в одному кадрі без чисельного диференціювання координат за часом.

Радар посилає кадр із пачки (frame of chirps), наприклад 64 або 128 послідовних чирпів. Обробка ведеться у два етапи за допомогою двовимірного швидкого перетворення Фур'є (2D-FFT):
1. **Range-FFT (по кожному окремому чирпу):** перетворює часовий сигнал биття у спектр дальності, визначаючи, на яких відстанях знаходяться відбивачі;
2. **Doppler-FFT (по однакових відліках дальності вздовж усіх чирпів кадру):** вимірює зміну початкової фази сигналу між послідовними чирпами.

Зсув фази `Δφ` між чирпами, розділеними інтервалом `T_c`, викликаний мікроскопічним переміщенням цілі на величину `Δd = v_r · T_c`:

```
Δφ = (4 · π · v_r · T_c) / λ
```

Частота зміни фази дає точну радіальну швидкість за законом Доплера:

```
v_r = (λ · f_Doppler) / 2
```

Оскільки вимірювання швидкості спирається на фазу несучої хвилі міліметрового масштабу, радар фіксує радіальну швидкість з точністю до десятих часток кілометра на годину (до кількох сантиметрів на секунду). Це дозволяє бортовому контролеру миттєво відокремлювати нерухомі предмети сцени (стовпи, стіни) від рухомих пішоходів і зустрічного транспорту.

### Проникність крізь діелектрики та перевідбиття металу

Довжина радіохвилі міліметрового діапазону (3.8–12.5 мм) зумовлює її унікальні властивості проходження:
* **Радіопрозорість пластику, дерева та тканини:** сухі діелектрики з низькою діелектричною проникністю (`ε_r ≈ 2–4`) та низьким тангенсом кута діелектричних втрат не створюють значного затухання хвилі. Радарний модуль можна повністю сховати всередину герметичного корпусу з ABS-пластику або за бампер автомобіля без жодних оптичних вікон і прорізів. Налипання бруду, снігу, пилу чи крапель води на захисний пластик практично не блокує радіопромінь;
* **Ефективна площа розсіювання (ЕПР, англ. *RCS — Radar Cross Section*):** радіовідбиття залежить від провідності матеріалу та його геометрії. Метал і вода мають майже 100% коефіцієнт відбиття, тіло людини має помітний ЕПР за рахунок солоної води в тканинах, але дрібні пластикові іграшки, гілки кущів чи натягнутий тонкий дріт мають мізерний ЕПР і можуть бути повністю невидимими для радара;
* **Багатопроменеві перевідбиття (Multipath Clutter):** у закритих промислових приміщеннях із металевими стінами або стелажами радіохвиля перед поверненням у приймач зазнає кількох послідовних відскоків від металевих поверхонь. Радар обчислює довгий шлях подвійного пробігу і формує помилкові фантомні цілі позаду реальних стін.

## 6. Зведена інженерна матриця вибору сенсора під середовище

Для системного вибору датчика під конкретне апаратне завдання необхідно порівняти їхні граничні фізичні та експлуатаційні показники:

|---|---|---|---|---|

### Типові архітектурні сценарії інтеграції

1. **Домашній робот-пилосос:**
   * *Основна навігація:* 2D лазерний LiDAR на вежі для глобальної SLAM-карти кімнат;
   * *Бамперний захист:* ультразвуковий сонар або ToF на бампері проти темних плінтусів, дзеркальних шаф-купе та прозорих скляних журнальних столів;
   * *Датчики обриву (Cliff detection):* оптичні ToF або ІЧ-тріангуляційні датчики під днищем, спрямовані вниз, для миттєвого виявлення сходів.
2. **Вуличний квадрокоптер / агродрон:**
   * *Висотомір над твердим грунтом:* 1D LiDAR (TFmini Plus) для точного утримання висоти 0.5–15 м;
   * *Політ над водною гладдю або високою травою:* mmWave радар 60/77 ГГц (лазер відбивається від води дзеркально геть або заплутується у кронах трави, тоді як радар стабільно бачить рівень вологи та тверду поверхню під рослинністю).
3. **Автомобільна система допомоги водієві (ADAS):**
   * *Паркування на малих швидкостях (< 10 км/год):* кільце з 8–12 ультразвукових герметичних датчиків у бамперах для контролю близькості до бордюрів та сусідніх авто;
   * *Адаптивний круїз-контроль та екстрене гальмування:* фронтальний далекобійний 77 ГГц mmWave радар (всепогодна робота в дощ, сніг, туман і проти сліпучого сонця на дистанціях до 150–200 м).

## 7. Алгоритм та реалізація злиття вимірів (Sensor Fusion Arbiter)

Коли робот оснащений кількома різнорідними датчиками (наприклад, фронтальний ультразвуковий сонар, оптичний ToF та мікрохвильовий радар), бортовий мікроконтролер не повинен сліпо довіряти жодному окремому числу. Необхідний арбітр злиття сенсорних даних (Range Fusion Arbiter), який виконує:
1. Температурну корекцію ультразвуку за показами поточного термодатчика;
2. Валідацію апаратних статусів достовірності (відсів засвічення оптичного ToF за порогом фонового рахунку `ambient_count`, відсів сліпої зони);
3. Динамічне призначення ваг довіри на базі поточних фізичних умов середовища;
4. Консервативний вибір безпечної дистанції гальмування (Fail-Safe Envelope).

![Конвеєр обробки та злиття показів далекомірів](/root/course/embedded/vybir-dalekomira-pid-stsenu/img/ranging-fusion-pipeline.svg)
*Чотирирівневий конвеєр агрегації: від зчитування сирих апаратних даних та їхньої фізичної компенсації — до динамічної оцінки ваг довіри та обчислення безпечного гальмівного коридору.*

Нижче наведено повну реалізацію фільтра-арбітра двома мовами: чистим C для низькорівневих вбудованих прошивок та сучасним ідіоматичним C++20.

```c
#include <stdint.h>
#include <stdbool.h>
#include <math.h>

#define MAX_SENSORS 4
#define RANGE_INVALID_MM 65535U

typedef enum {
    SENSOR_ULTRASONIC = 0,
    SENSOR_OPTICAL_TOF = 1,
    SENSOR_MMWAVE_RADAR = 2
} SensorType;

typedef struct {
    SensorType type;
    uint32_t raw_value;     /* УЗ: мкс; ToF/Радар: мм */
    uint16_t signal_quality;/* ToF: MCPS або SNR; Радар: дБ */
    uint16_t ambient_noise;  /* ToF: фоновий сонячний рахунок */
    bool hardware_ok;
} RawSensorReading;

typedef struct {
    float temperature_c;    /* Температура повітря для УЗ */
    bool outdoor_sunlight;  /* Ознака прямого сонячного світла */
} EnvironmentalContext;

typedef struct {
    uint16_t safe_distance_mm;
    float relative_velocity_mps;
    bool emergency_stop;
    uint8_t confident_sensors_count;
} FusionResult;

/* Розрахунок швидкості звуку c(T) у мм/мкс (для перерахунку з мікросекунд у мм) */
static inline float get_sound_speed_mm_per_us(float temp_c) {
    float speed_m_per_s = 331.3f + 0.606f * temp_c;
    return speed_m_per_s * 0.001f; /* мм / мкс */
}

/* Обробка та злиття вимірів */
FusionResult range_fusion_process(
    const RawSensorReading readings[MAX_SENSORS],
    uint8_t count,
    const EnvironmentalContext* env
) {
    FusionResult result = {
        .safe_distance_mm = RANGE_INVALID_MM,
        .relative_velocity_mps = 0.0f,
        .emergency_stop = false,
        .confident_sensors_count = 0
    };

    uint16_t valid_ranges[MAX_SENSORS];
    float weights[MAX_SENSORS];
    uint8_t valid_cnt = 0;

    for (uint8_t i = 0; i < count && i < MAX_SENSORS; ++i) {
        if (!readings[i].hardware_ok) continue;

        uint16_t dist_mm = RANGE_INVALID_MM;
        float weight = 0.0f;

        switch (readings[i].type) {
            case SENSOR_ULTRASONIC: {
                /* Перевірка таймауту та мінімальної сліпої зони (30 мм .. 4000 мм) */
                if (readings[i].raw_value >= 180 && readings[i].raw_value <= 24000) {
                    float v_sound = get_sound_speed_mm_per_us(env->temperature_c);
                    dist_mm = (uint16_t)((readings[i].raw_value * v_sound) * 0.5f);
                    weight = 0.70f; /* УЗ надійний на твердих площинах */
                }
                break;
            }

            case SENSOR_OPTICAL_TOF: {
                /* Якщо сонячний шум надто високий (>1500 kcps), знижуємо довіру */
                dist_mm = (uint16_t)readings[i].raw_value;
                if (dist_mm >= 20 && dist_mm <= 4000) {
                    if (env->outdoor_sunlight || readings[i].ambient_noise > 1500) {
                        weight = (readings[i].signal_quality > 500) ? 0.35f : 0.10f;
                    } else {
                        weight = 0.90f; /* У приміщенні ToF надзвичайно точний */
                    }
                }
                break;
            }

            case SENSOR_MMWAVE_RADAR: {
                dist_mm = (uint16_t)readings[i].raw_value;
                if (dist_mm >= 100 && dist_mm <= 15000) {
                    weight = 0.85f; /* Радар всепогодний і стійкий до сонця */
                }
                break;
            }
        }

        if (dist_mm != RANGE_INVALID_MM && weight > 0.0f) {
            valid_ranges[valid_cnt] = dist_mm;
            weights[valid_cnt] = weight;
            valid_cnt++;
        }
    }

    result.confident_sensors_count = valid_cnt;

    if (valid_cnt == 0) {
        /* Жоден сенсор не дав валідних даних — режим аварійної зупинки */
        result.emergency_stop = true;
        result.safe_distance_mm = 0;
        return result;
    }

    /* Консервативний вибір безпечної дистанції:
       Беремо мінімальну дистанцію серед датчиків із вагою довіри > 0.3 */
    uint16_t min_safe = RANGE_INVALID_MM;
    for (uint8_t i = 0; i < valid_cnt; ++i) {
        if (weights[i] >= 0.30f && valid_ranges[i] < min_safe) {
            min_safe = valid_ranges[i];
        }
    }

    if (min_safe == RANGE_INVALID_MM) {
        /* Якщо всі валідні показники мали низьку довіру, беремо найменший */
        min_safe = valid_ranges[0];
        for (uint8_t i = 1; i < valid_cnt; ++i) {
            if (valid_ranges[i] < min_safe) min_safe = valid_ranges[i];
        }
    }

    result.safe_distance_mm = min_safe;
    /* Аварійне спрацювання, якщо перешкода ближче 150 мм */
    result.emergency_stop = (min_safe <= 150);

    return result;
}
```

```cpp
#include <cstdint>
#include <cmath>
#include <span>
#include <optional>
#include <algorithm>
#include <array>

namespace embedded::sensing {

enum class SensorType : uint8_t {
    Ultrasonic,
    OpticalToF,
    MmWaveRadar
};

struct RawMeasurement {
    SensorType type;
    uint32_t raw_value;      // УЗ: час у мкс; ToF/Радар: дистанція в мм
    uint16_t signal_quality; // Оцінка сигналу (SNR або MCPS)
    uint16_t ambient_noise;  // Рівень фонового IR засвічення
    bool is_valid_hw;
};

struct EnvironmentState {
    float temperature_celsius{20.0f};
    bool bright_sunlight{false};
};

struct FusionOutput {
    uint16_t safe_distance_mm{0};
    uint8_t confident_sources{0};
    bool emergency_stop_required{false};
};

class RangeSensorFusion {
public:
    static constexpr uint16_t kInvalidRange = 0xFFFF;
    static constexpr uint16_t kEmergencyThresholdMm = 150;

    [[nodiscard]] static constexpr float CalculateSoundSpeed(float temp_c) noexcept {
        return (331.3f + 0.606f * temp_c) * 0.001f; // мм/мкс
    }

    [[nodiscard]] FusionOutput Evaluate(
        std::span<const RawMeasurement> measurements,
        const EnvironmentState& env
    ) const noexcept {
        struct FilteredPoint {
            uint16_t distance_mm;
            float confidence;
        };

        std::array<FilteredPoint, 8> valid_points{};
        size_t valid_count = 0;

        for (const auto& item : measurements) {
            if (!item.is_valid_hw || valid_count >= valid_points.size()) {
                continue;
            }

            auto processed = ValidateAndScale(item, env);
            if (processed.has_value()) {
                valid_points[valid_count++] = *processed;
            }
        }

        if (valid_count == 0) {
            // Повна втрата даних від сенсорів — безпечна зупинка
            return FusionOutput{
                .safe_distance_mm = 0,
                .confident_sources = 0,
                .emergency_stop_required = true
            };
        }

        // Консервативний пошук найближчої достовірної перешкоди
        uint16_t min_distance = kInvalidRange;
        for (size_t i = 0; i < valid_count; ++i) {
            if (valid_points[i].confidence >= 0.30f) {
                min_distance = std::min(min_distance, valid_points[i].distance_mm);
            }
        }

        // Якщо всі точки мали низьку довіру, беремо мінімум серед усіх наявних
        if (min_distance == kInvalidRange) {
            for (size_t i = 0; i < valid_count; ++i) {
                min_distance = std::min(min_distance, valid_points[i].distance_mm);
            }
        }

        return FusionOutput{
            .safe_distance_mm = min_distance,
            .confident_sources = static_cast<uint8_t>(valid_count),
            .emergency_stop_required = (min_distance <= kEmergencyThresholdMm)
        };
    }

private:
    struct FilteredPointInternal {
        uint16_t distance_mm;
        float confidence;
    };

    [[nodiscard]] std::optional<FilteredPointInternal> ValidateAndScale(
        const RawMeasurement& m,
        const EnvironmentState& env
    ) const noexcept {
        switch (m.type) {
            case SensorType::Ultrasonic: {
                if (m.raw_value >= 180 && m.raw_value <= 24000) {
                    const float v_sound = CalculateSoundSpeed(env.temperature_celsius);
                    const auto dist = static_cast<uint16_t>((m.raw_value * v_sound) * 0.5f);
                    return FilteredPointInternal{dist, 0.70f};
                }
                break;
            }

            case SensorType::OpticalToF: {
                const auto dist = static_cast<uint16_t>(m.raw_value);
                if (dist >= 20 && dist <= 4000) {
                    float conf = 0.90f;
                    if (env.bright_sunlight || m.ambient_noise > 1500) {
                        conf = (m.signal_quality > 500) ? 0.35f : 0.10f;
                    }
                    return FilteredPointInternal{dist, conf};
                }
                break;
            }

            case SensorType::MmWaveRadar: {
                const auto dist = static_cast<uint16_t>(m.raw_value);
                if (dist >= 100 && dist <= 15000) {
                    return FilteredPointInternal{dist, 0.85f};
                }
                break;
            }
        }
        return std::nullopt;
    }
};

} // namespace embedded::sensing
```

## 8. Підсумковий синтез вибору

Архітектурне рішення при виборі далекоміра вибудовується за трьома послідовними запитаннями:

1. **Що є ціллю за матеріалом та оптичними властивостями?**
   Якщо перешкодами є прозоре скло, дзеркала чи хромовані поверхні — лазерний LiDAR і ToF вимагають обов'язкового дублювання ультразвуковим сонаром. Якщо перешкодами є м'які меблі, шторами чи поролонова ізоляція — ультразвук відсіюється на користь оптичного ToF або LiDAR.
2. **Які погодні умови та оптичне оточення?**
   Для роботи на відкритому сонці пріоритет зміщується від ToF 940 нм до далекобійних LiDAR із вузькими смуговими інтерференційними фільтрами або до mmWave радарів. Для роботи в дощі, тумані та густій пилюці мікрохвильовий радар 60/77 ГГц стає безальтернативним вибором завдяки радіопрозорості завислих у повітрі крапель води й частинок грунту.
3. **Який динамічний профіль руху?**
   Якщо системі керування робота необхідно миттєво реагувати на рухомі зустрічні об'єкти з високими відносними швидкостями, FMCW радар надає прямий вектор доплерівської швидкості за один апаратний кадр без шуму чисельного диференціювання. Для високоточного картографування стаціонарних приміщень і розпізнавання контурів тонких ніжок столів вирішальною лишається кутова роздільність скануючого лазерного LiDAR.
