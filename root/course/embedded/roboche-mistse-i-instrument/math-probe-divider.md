# 🧮 Частотна компенсація RC-дільника щупа осцилографа

Щуп осцилографа з коефіцієнтом ділення 10X є частотно-компенсованим частотно-незалежним подільником напруги. Якщо розглядати вхідний каскад осцилографа лише як активний опір R_in = 1 МОм, виникає непереборна суперечність: коаксіальний кабель довжиною близько одного метра має власну розподілену ємність C_cable ≈ 70–100 пФ, а сам вхідний BNC-роз'єм осцилографа додає паразитну ємність C_in ≈ 12–20 пФ. Разом вони утворюють паралельну вхідну ємність C_2 = C_cable + C_in ≈ 100–120 пФ.

Без компенсації послідовний резистор R_1 = 9 МОм у голівці щупа разом із цією ємністю утворив би низькочастотний RC-фільтр із частотою зрізу:

```
f_c = 1 / (2π × R_1 × C_2)
    = 1 / (2π × 9·10⁶ Ом × 100·10⁻¹² Ф)
    ≈ 177 Гц
```

На будь-якій частоті вище кількох сотень герц реактивний опір ємності кабелю став би меншим за опір вхідного каскаду, амплітуда вимірюваного сигналу впала б до нуля, а прямокутний імпульс перетворився б на безформну завалену експоненту. Нижче наведено виведення умови, за якої коефіцієнт ділення залишається строго сталим на всіх частотах.

---

### Комплексний коефіцієнт передачі дільника

Еквівалентна схема щупа 10X складається з двох паралельних RC-ланок, з'єднаних послідовно:
1. Верхнє плече (голівка щупа): опір R_1 = 9 МОм та паралельний йому підлаштовний конденсатор C_1 (тример ємністю 10–15 пФ).
2. Нижнє плече (кабель і вхід приладу): опір R_2 = R_in = 1 МОм та паралельна сумарна ємність C_2 = C_cable + C_in ≈ 100 пФ.

Комплексний імпеданс кожної ланки записується через паралельне з'єднання резистора та ємності:

```
Z_1(jω) = (R_1 × (1 / jωC_1)) / (R_1 + 1 / jωC_1) = R_1 / (1 + jω × R_1 × C_1)
Z_2(jω) = (R_2 × (1 / jωC_2)) / (R_2 + 1 / jωC_2) = R_2 / (1 + jω × R_2 × C_2)
```

Передавальна функція дільника H(jω) = V_out(jω) / V_in(jω) визначається як відношення імпедансів:

```
H(jω) = Z_2(jω) / (Z_1(jω) + Z_2(jω))
      = [R_2 / (1 + jωR_2C_2)] / [R_1 / (1 + jωR_1C_1) + R_2 / (1 + jωR_2C_2)]
      = [R_2 × (1 + jωR_1C_1)] / [R_1 × (1 + jωR_2C_2) + R_2 × (1 + jωR_1C_1)]
      = [R_2 × (1 + jωR_1C_1)] / [(R_1 + R_2) + jωR_1R_2 × (C_1 + C_2)]
```

### Умова частотної незалежності

Проаналізуємо поведінку коефіцієнта передачі на крайніх частотах:
- При постійній напрузі (ω → 0, постійний струм DC): ємності розімкнені, поділ визначається виключно резисторами:
  ```
  H_DC = R_2 / (R_1 + R_2) = 1 МОм / (9 МОм + 1 МОм) = 1/10
  ```
- На надвисоких частотах (ω → ∞, де реактивний опір ємностей прямує до нуля): струм тече переважно крізь конденсатори:
  ```
  H_HF = C_1 / (C_1 + C_2)
  ```

Щоб передавальна функція не залежала від частоти й була строго рівною 1/10 для будь-якої гармоніки вхідного сигналу, коефіцієнти при ω → 0 та ω → ∞ повинні збігатися:

```
R_2 / (R_1 + R_2) = C_1 / (C_1 + C_2)
R_2 × (C_1 + C_2) = C_1 × (R_1 + R_2)
R_2 × C_1 + R_2 × C_2 = C_1 × R_1 + C_1 × R_2
R_1 × C_1 = R_2 × C_2
```

Підставимо умову балансу R_1 × C_1 = R_2 × C_2 у вираз знаменника передавальної функції:

```
Знаменник = (R_1 + R_2) + jω × R_1 × (R_2 × C_2)
          = (R_1 + R_2) + jω × R_1 × (R_1 × C_1)
          = (R_1 + R_2) × [1 + jω × (R_1 × C_1) × (R_1 / (R_1 + R_2))]
```

Оскільки R_1 × C_1 = R_2 × C_2, вираз спрощується, і частотно-залежний множник (1 + jωR_1C_1) у чисельнику та знаменнику взаємно скорочується:

```
H(jω) = R_2 / (R_1 + R_2) ≡ 1/10
```

Коефіцієнт передачі стає строго дійсним числом 0.1, не залежить від кругової частоти ω, а фазовий зсув дільника для всіх спектральних складових дорівнює нулю: φ(ω) = 0.

### Перехідний процес при ступінчастому вході

Коли на вхід щупа подається ідеальний прямокутний перепад напруги V_in(t) = V_0 (фронт тестового меандру калібратора), реакція напруги на вході осцилографа V_out(t) у часовій області описується виразом:

```
V_out(t) = V_0 × [ R_2 / (R_1 + R_2) + ( C_1 / (C_1 + C_2) - R_2 / (R_1 + R_2) ) × exp(-t / τ) ]
```

де постійна часу перехідного процесу τ дорівнює:

```
τ = (R_1 || R_2) × (C_1 + C_2) = [ (R_1 × R_2) / (R_1 + R_2) ] × (C_1 + C_2)
```

З формули видно фізичну природу трьох станів налаштування тримера:
1. **Ідеальна компенсація (R_1 × C_1 = R_2 × C_2):** різниця в дужках [ C_1 / (C_1 + C_2) - R_2 / (R_1 + R_2) ] дорівнює нулю. Експоненційний член зникає, вихідна напруга миттєво набуває значення 0.1 × V_0 і формує строго плоску вершину імпульсу.
2. **Недокомпенсація (C_1 < (R_2 / R_1) × C_2):** у момент стрибка t = 0⁺ ємнісний дільник видає напругу меншу за 0.1 × V_0, після чого вона повільно за експонентою з постійною часу τ підтягується до 0.1 × V_0. На екрані спостерігається закруглений передній фронт (спад високих частот).
3. **Перекомпенсація (C_1 > (R_2 / R_1) × C_2):** у момент стрибка t = 0⁺ ємнісний дільник створює початковий викид напруги вище 0.1 × V_0, який потім експоненційно спадає до стаціонарного рівня. На екрані видно штучний гострий пік (overshoot).

### Паразитна індуктивність земляного провідника

Земляний дріт щупа із затискачем-«крокодилом» довжиною l ≈ 12–15 см має власну погонну індуктивність близько 1 нГн/мм, тобто сумарну індуктивність L_gnd ≈ 120–150 нГн.

Разом із еквівалентною ємністю щупа 10X (C_probe = (C_1 × C_2) / (C_1 + C_2) ≈ 12–15 пФ) утворюється послідовний коливальний LC-контур. Власна резонансна частота цього контуру становить:

```
f_0 = 1 / (2π × √(L_gnd × C_probe))
    = 1 / (2π × √(120·10⁻⁹ Гн × 15·10⁻¹² Ф))
    ≈ 118.6 МГц
```

Коли крутий фронт цифрового сигналу мікроконтролера (час наростання t_rise ≈ 1–2 нс) збуджує цей контур, виникають незгасаючі високочастотні коливання на частоті f_0 ≈ 120 МГц. Цей фальшивий «дзвін» (ringing) є спотворенням самого вимірювального контуру, а не реальним шумом на платі. Заміна довгого дроту на коротку земляну пружинку довжиною 3–5 мм зменшує L_gnd до < 5 нГн, витісняючи резонанс за 600 МГц — далеко за межі смуги типового осцилографа.
