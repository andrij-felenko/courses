# 🧮 Математика рідкісних відмов: матриці спряженості, відношення шансів і точний тест Фішера

Аналіз польових дефектів із частотою один на тисячу (0.1% або 1000 ppm) стикається з фундаментальною математичною перешкодою: у вибірці з 10 000 пристроїв десять несправних плат легко загубити серед шуму випадкових коливань. Щоб довести, що причиною відмов є конкретний код дати мікросхеми чи вологість цеху, а не статистична випадковість, інженер використовує математичний апарат аналізу таблиць спряженості, відношення шансів та гіпергеометричного розподілу ймовірностей.

## Матриця спряженості 2×2 та формулювання задачі

Припустимо, що за перші шість місяців експлуатації партії з `N` пристроїв сервісні центри зафіксували `M` відмов із характерним симптомом (наприклад, циклічне перезавантаження процесора при низьких температурах). Досліджується гіпотеза, що дефект пов'язаний із певним виробничим фактором `F` (наприклад, встановленням мікроконтролера з кодом дати `DC2134`).

Усі виготовлені пристрої класифікуються за двома бінарними ознаками:
1. **Фактор ризику `F`:** присутній (партія `DC2134`) або відсутній (інші коди дат).
2. **Результат `R`:** відмова в полі (RMA) або безперебійна робота (OK).

Результати зводяться в матрицю спряженості розміром 2×2:

```
                  Відмова (RMA)    Справні (OK)       Разом
Фактор присутній        a               b            a + b = n₁
Фактор відсутній        c               d            c + d = n₀
Разом               a + c = m₁      b + d = m₀           N
```

У цій таблиці:
- `a` — кількість пристроїв із фактором `F`, які зазнали відмови;
- `b` — кількість пристроїв із фактором `F`, які працюють справно;
- `c` — кількість пристроїв без фактора `F`, які зазнали відмови (фоновий рівень браку);
- `d` — кількість пристроїв без фактора `F`, які працюють справно;
- `n₁ = a + b` — загальна кількість пристроїв із досліджуваним фактором;
- `n₀ = c + d` — загальна кількість пристроїв без фактора;
- `m₁ = a + c` — сумарна кількість зафіксованих відмов;
- `m₀ = b + d` — сумарна кількість справних пристроїв;
- `N = a + b + c + d` — загальний обсяг випущеної партії.

## Відносний ризик (Relative Risk) та відношення шансів (Odds Ratio)

Для оцінки сили зв'язку між фактором і відмовою застосовують дві метрики ризику.

### 1. Відносний ризик (RR)
Відносний ризик обчислюється як відношення ймовірності відмови в групі з фактором до ймовірності відмови в групі без фактора:

```
p₁ = a / (a + b)      [ймовірність відмови за наявності фактора]
p₀ = c / (c + d)      [ймовірність відмови за відсутності фактора]

RR = p₁ / p₀
   = (a / (a + b)) / (c / (c + d))    [відносний ризик]
```

Якщо `RR = 1`, фактор не впливає на надійність. Значення `RR > 1` свідчить про підвищений ризик у групі `F`.

### 2. Відношення шансів (Odds Ratio — OR)
У дослідженнях рідкісних польових дефектів розмір контрольної вибірки справних пристроїв часто оцінюється ретроспективно. Шанси (*Odds*) настання події визначаються як відношення кількості відмов до кількості справних виробів:

```
Odds₁ = a / b         [шанси відмови в групі з фактором]
Odds₀ = c / d         [шанси відмови в групі без фактора]

OR = Odds₁ / Odds₀
   = (a / b) / (c / d)
   = (a · d) / (b · c) [відношення шансів]
```

Для рідкісних подій, коли `a ≪ b` та `c ≪ d`, знаменники `a + b ≈ b` та `c + d ≈ d`, тому відношення шансів практично збігається з відносним ризиком: `OR ≈ RR`.

### Асимптотична дисперсія та довірчий інтервал для OR
Оскільки розподіл самого відношення шансів асиметричний і скошений праворуч, статистичний аналіз проводять для натурального логарифма `ln(OR)`.

За дельта-методом асимптотична дисперсія логарифма відношення шансів дорівнює сумі обернених величин частот клітинок:

```
Var(ln OR)
= 1/a + 1/b + 1/c + 1/d    [дисперсія логарифма відношення шансів за Вулфом]

SE(ln OR)
= √(1/a + 1/b + 1/c + 1/d) [стандартна похибка]
```

Двосторонній 95%-й довірчий інтервал для `ln(OR)` будується за нормальним розподілом із квантилем `Z = 1.96`:

```
ln(OR)_min = ln(OR) - 1.96 · SE(ln OR)    [нижня межа в логарифмічній шкалі]
ln(OR)_max = ln(OR) + 1.96 · SE(ln OR)    [верхня межа в логарифмічній шкалі]

CI_95% = [exp(ln(OR)_min), exp(ln(OR)_max)] [довірчий інтервал для OR]
```

Якщо довірчий інтервал `CI_95%` не містить одиницю (тобто `exp(ln(OR)_min) > 1.0`), статистичний зв'язок між фактором і відмовою вважається статистично значущим на рівні значущості `α = 0.05`.

## Межі критерію хі-квадрат та необхідність точного тесту Фішера

Класичний критерій незалежності Пірсона хі-квадрат (`χ²`) перевіряє нульову гіпотезу `H₀` про статистичну незалежність рядків і стовпців матриці:

```
E_ij = (R_i · C_j) / N    [очікувана частота клітинки при нульовій гіпотезі]

χ² = ∑ ((O_ij - E_ij)² / E_ij) [статистика Пірсона з 1 ступенем вільності]
```

Критерій хі-квадрат є асимптотичним і спирається на наближення дискретного біноміального розподілу неперервним розподілом `χ²`. За правилом Кокрена (*Cochran's rule*), це наближення є коректним лише тоді, коли:
1. Жодна очікувана частота `E_ij` не менша за 1.0.
2. Не більше ніж 20% клітинок мають очікувану частоту `E_ij < 5.0`.

При дослідженні дефектів рівня «одна відмова на тисячу» у вибірці з кількох тисяч плат очікувана кількість відмов у невеликій дефектній партії `E₁₁` часто становить від 0.2 до 1.5. У цьому діапазоні критерій хі-квадрат дає неприпустимо велику похибку першого роду (хибнопозитивні результати) або вироджується.

## Точний тест Фішера (Fisher's Exact Test)

Для довільних частот у клітинках застосовують точний тест Фішера, який не спирається на асимптотичні наближення, а обчислює точну комбінаторну ймовірність отримання даної таблиці за умови фіксованих маргінальних сум (`n₁, n₀, m₁, m₀`).

За нульової гіпотези `H₀` (відсутність зв'язку) розподіл величини `a` є гіпергеометричним:

```
P(X = a)
= (C(n₁, a) · C(n₀, c)) / C(N, m₁)
= ((n₁! / (a! · (n₁ - a)!)) · (n₀! / (c! · (n₀ - c)!))) / (N! / (m₁! · (N - m₁)!))
= (n₁! · n₀! · m₁! · m₀!) / (a! · b! · c! · d! · N!) [гіпергеометрична ймовірність]
```

Для обчислення двостороннього рівня значущості `p-value` підсумовують ймовірності `P(X = k)` для всіх можливих таблиць із тими самими маргінальними сумами, ймовірність яких менша або дорівнює ймовірності спостережуваної таблиці:

```
p_value = ∑ P(X = k) для всіх k таких, що P(X = k) ≤ P(X = a)
```

### Чисельна стійкість для великих вибірок
При аналізі партій у десятки тисяч штук обчислення факторіалів напряму призводить до арифметичного переповнення 64-бітних чисел із плаваючою комою (наприклад, `1000! > 10²⁵⁶⁷`, тоді як максимум стандарту IEEE 754 double становить `≈ 1.8 × 10³⁰⁸`).

Обчислення виконують у логарифмічному просторі через логарифм гамма-функції `ln Γ(n + 1) = ln(n!)`:

```
ln P(X = a)
= ln_fact(n₁) + ln_fact(n₀) + ln_fact(m₁) + ln_fact(m₀)
  - ln_fact(a) - ln_fact(b) - ln_fact(c) - ln_fact(d) - ln_fact(N)

де ln_fact(n) = lgamma(n + 1.0)
```

Після знаходження логарифма максимальної ймовірності всі компоненти суми масштабуються через `exp(ln P(k) - ln P_max)`, що усуває втрату точності та переповнення.

## Поправка на множинне тестування (Multiple Hypothesis Testing)

Сучасна друкована плата містить від 100 до 500 позицій компонентів (BOM items). Автоматизований аналізатор виконує тест Фішера послідовно для кожного компонента, кожного коду дати, кожної лінії SMT та кожної зміни монтажу — загалом до `m = 1000` перевірок гіпотез.

Якщо для кожної окремої перевірки обрати поріг значущості `α = 0.05`, то ймовірність знайти хоча б один хибний кореляційний зв'язок на чисто випадкових даних дорівнює:

```
P(хоча б 1 хибна тривога)
= 1 - (1 - α)ᵐ
= 1 - (1 - 0.05)¹⁰⁰⁰
= 1 - 5.29 × 10⁻²³
≈ 100.0%             [гарантована хибна тривога серед шуму]
```

Для захисту від хибних висновків застосовують два підходи:

1. **Поправка Бонферроні (консервативний контроль FWER):**
   Поріг значущості для кожної окремої перевірки ділиться на загальну кількість гіпотез:

```
α_adj
= α / m
= 0.05 / 1000
= 0.00005 = 5 × 10⁻⁵ [скорегований поріг відсікання]
```

2. **Процедура Беньяміні — Гохберга (контроль частки хибних відкриттів FDR):**
   Усі отримані `m` значень `p-value` сортуються за зростанням: `p₍₁₎ ≤ p₍₂₎ ≤ ... ≤ p₍ₘ₎`. Знаходять найбільший індекс `k`, для якого виконується умова:

```
p₍k₎ ≤ (k / m) · Q    [критерій Беньяміні — Гохберга для FDR рівному Q]
```

Усі гіпотези з індексами від 1 до `k` визнаються статистично значущими відкриттями з контролем частки хибнопозитивних результатів на рівні `Q` (зазвичай `Q = 0.05`).

## Покроковий числовий приклад розрахунку

Розгляньмо виробничий випуск `N = 20 000` контролерів системи поливу. Сервісні центри повернули `m₁ = 20` плат із пробоєм вхідного каскаду АЦП. Підозра впала на захисний TVS-діод `D3` з кодом дати `DC2140`, який був змонтований на `n₁ = 1000` платах, тоді як на решті `n₀ = 19 000` плат стояв діод із кодом `DC2122`.

Складемо матрицю спостережень:
- `a = 18` (відмови в партії `DC2140`);
- `b = 982` (справні в партії `DC2140`);
- `c = 2` (відмови в решті партій `DC2122`);
- `d = 18 998` (справні в решті партій).

### Крок 1. Розрахунок частот і відносного ризику

```
p₁ = 18 / (18 + 982)
   = 18 / 1000
   = 0.0180 = 1.80%       [частота збоїв у партії DC2140]

p₀ = 2 / (2 + 18 998)
   = 2 / 19 000
   = 0.0001053 = 0.01053% [частота збоїв у контрольних партіях]

RR = 0.0180 / 0.0001053
   = 170.94              [ризик відмови підвищений у 171 раз]
```

### Крок 2. Розрахунок відношення шансів та довірчого інтервалу

```
OR = (18 · 18 998) / (982 · 2)
   = 341 964 / 1 964
   = 174.116             [відношення шансів]

ln(OR) = ln(174.116)
       = 5.1597          [натуральний логарифм OR]

Var(ln OR)
= 1/18 + 1/982 + 1/2 + 1/18998
= 0.055556 + 0.001018 + 0.500000 + 0.000053
= 0.556627               [дисперсія оцінки]

SE(ln OR)
= √0.556627
= 0.74607                [стандартна похибка логарифма]

Похибка = 1.96 · 0.74607 = 1.4623

ln(OR)_min = 5.1597 - 1.4623 = 3.6974
ln(OR)_max = 5.1597 + 1.4623 = 6.6220

CI_95% = [exp(3.6974), exp(6.6220)]
       = [40.34, 751.45] [95% довірчий інтервал]
```

Нижня межа довірчого інтервалу дорівнює `40.34 > 1.0`, що свідчить про гігантський статистичний ефект навіть з урахуванням малої кількості спостережень.

### Крок 3. Розрахунок точного тесту Фішера
Гіпергеометрична ймовірність отримання поточної або ще більш екстремальної таблиці (`k ≥ 18` при `m₁ = 20`):

```
P(X = 18) = 1.34 × 10⁻¹⁹
P(X = 19) = 3.73 × 10⁻²²
P(X = 20) = 4.12 × 10⁻²⁵

p_value ≈ 2 · P(X ≥ 18)
        = 2.68 × 10⁻¹⁹   [рівень значущості тесту Фішера]
```

Отримане значення `p = 2.68 × 10⁻¹⁹ ≪ 5 × 10⁻⁵` проходить навіть найжорсткішу поправку Бонферроні для 1000 компонентів. Гіпотеза про випадковий розподіл браку відкидається з абсолютною математичною достовірністю: дефект жорстко локалізований у партії діодів `DC2140`.
