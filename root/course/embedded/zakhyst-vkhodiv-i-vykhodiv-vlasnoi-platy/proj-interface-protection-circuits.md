# ⚙️ Перевірені схеми захисту інтерфейсів та портів

Практична реалізація захисних вузлів у серійних виробах спирається на стандартизовані схемотехнічні модулі, перевірені на стійкість до промислових завад за стандартами IEC 61000-4-2 (ESD) та IEC 61000-4-5 (Surge). Кожен вузол розрахований на конкретний тип фізичного інтерфейсу, узгоджуючи швидкодію, паразитну ємність компонентів, рівень залишкової напруги та ціну компонентів (BOM).

## Модуль 1: Захищений порт USB 2.0 High-Speed (480 Мбіт/с)

Швидкісні лінії даних USB `D+` та `D−` вимагають захисту з ємністю не більше 0.5 пФ для збереження форми диференційного сигналу, тоді як лінія живлення `VBUS` потребує захисту від перевантаження за струмом та індуктивних сплесків при гарячому підключенні довгих кабелів.

```
Схема підключення порту USB 2.0 з повним захистом:

   Роз'єм Type-C / Micro-B                           До чипа МК / PHY
   +-------------------+                             +-----------------+
   | VBUS (+5 В)  [1]  |-----+-----[ PPTC 500mA ]----+--> VBUS_IN (МК) |
   |                   |     |                       |                 |
   |                   |   [ TVS ] SMAJ5.0A        [ C ] 4.7 мкФ       |
   |                   |     |                       |                 |
   |                   |    GND                     GND                |
   |                   |                                               |
   | D+           [2]  |--+--[ Common Mode ]---------+--> USB_DP       |
   |                   |  |  [    Choke    ]         |                 |
   | D−           [3]  |--+--[ 90 Ом @ 100М]---------+--> USB_DM       |
   |                   |  |                          |                 |
   |                   | [  TVS USBLC6-2SC6  ]       |                 |
   |                   | [  C_j = 0.35 пФ    ]       |                 |
   |                   | [  Flow-Through     ]       |                 |
   |                   |         |                   |                 |
   | GND          [4]  |---------+-------------------+--> GND (Плата)  |
   |                   |         |                                     |
   | SHIELD (Корпус)   |---+     |                                     |
   +-------------------+   |    GND                                    |
                           |                                           |
                 [ R ] 1 МОм || [ C ] 4.7 нФ / 2 кВ                    |
                           |                                           |
                          GND                                          |
```

### Специфікація компонентів та номінали:
1. **TVS-збірка для даних:** `USBLC6-2SC6` (STMicroelectronics) або `TPD2E001` (Texas Instruments) у корпусі SOT-23-6L або SOT-666. Власна ємність `C_j = 0.35 пФ`, робоча напруга `V_rwm = 5.0 В`, напруга фіксації `V_clamp = 11 В` при струмі 16 А (IEC 61000-4-2 Level 4). Трасування виконується прямо крізь виводи мікросхеми (flow-through).
2. **Синфазний дросель (Common-Mode Choke):** `DLW21SN900HQ2L` (Murata) — імпеданс 90 Ом на частоті 100 МГц, постійний опір `R_dc < 0.3 Ом`. Придушує синфазні електромагнітні завади від кабелю без спотворення диференційного сигналу.
3. **Захист лінії живлення VBUS:** самовідновний запобіжник `PPTC 0805` (Bourns MF-MSMF050-2, струм утримання `I_hold = 500 мА`, струм розмикання `I_trip = 1.0 А`) у парі з односпрямованим супресором `SMAJ5.0A` (`P_pp = 400 Вт`).
4. **Зв'язок екрана роз'єму (Shield) з землею:** паралельне RC-коло `1 МОм + 4.7 нФ (2000 В)` для стікання статичного заряду без утворення земляних петель на низьких частотах.

## Модуль 2: Промисловий інтерфейс RS-485 / CAN із захистом від зміщення земель

У промислових мережах зв'язку довжина кабелю RS-485 сягає 1000 метрів. Різниця потенціалів заземлення між двома віддаленими будівлями досягає ±7...±12 Вольт, а удари блискавок неподалік наводять потужні кіловольтні імпульси.

```
Схема захисту диференційної шини RS-485 (лінії A / B):

   Клемник лінії                    Ступінь 2 (TVS)      Трансивер RS-485
   +-------------+                  +--------------+     +--------------+
   |             |---[ PPTC 10Ω ]---+----+               |              |
   | Line A      |   (MF-RX012)     |    |-------------->| Pin A        |
   |             |                  | [  TVS SM712  ]    |              |
   |             |---[ PPTC 10Ω ]---+ [  Асиметричний]   |              |
   | Line B      |   (MF-RX012)     | [  +12 В / −7 В]   | Pin B        |
   |             |                  |    |-------------->|              |
   |             |                  +----+               |              |
   |             |                       |               |              |
   | Earth /     |--+                   GND              |              |
   | Шасі        |  |                                    +--------------+
   +-------------+  |
                    |
           [ Газорозрядник GDT ]
           (Bourns 2036-09-SM)
           Початок пробою = 90 В
                    |
                   GND
```

### Принцип дії триступеневого захисту:
1. **Перший ешелон (Грубий захист, GDT):** керамічний газорозрядник (Gas Discharge Tube) `Bourns 2036-09-SM` або `Epcos T83-A90X` між лініями та захисним заземленням Earth. При появі високовольтної хвилі перенапруги (> 90–150 В) газ іонізується, створюючи електричну дугу, що скидає струми до 10 000 Амперів (імпульс 8/20 мкс) у захисне заземлення.
2. **Координуючий опір (PPTC):** два самовідновні резистори `Bourns MF-RX012` або керамічні терморезистори з опором 10 Ом. Вони обмежують струм через тонкий TVS-діод під час затримки запалювання дуги в газорозряднику (час спрацьовування GDT становить 100–500 нс).
3. **Другий ешелон (Тонка фіксація, TVS):** спеціалізований асиметричний TVS `Semtech SM712` (SOT-23). Стандарт RS-485 передбачає діапазон синфазної напруги від −7 В до +12 В. Звичайний симетричний TVS на 12 В відкривався б при −12 В, дозволяючи негативному потенціалу −10 В пошкодити трансивер. TVS `SM712` має вбудовані діоди з напругою фіксації `+13.3 В` в прямому напрямку і `−7.5 В` у зворотному, ідеально повторюючи робочий діапазон приймача.

## Модуль 3: Універсальний аналоговий вхід (0–10 В / 4–20 мА) із захистом від ±36 В

Аналогові входи промислових контролерів (PLC) повинні зчитувати слабкі напруги від давачів і витримувати випадкове закорочування монтажником на шину живлення 24 В або переполюсовку.

```
Схема аналогового входу з захистом до ±36 В:

   Вхідна клема (Vin)
   +-------------+
   |             |----[ R1: 10 кОм / 0.5 Вт ]----+----[ R3: 1 кОм ]----> До АЦП (МК)
   | 0–10 В або  |                               |                        |
   | 4–20 мА     |                             +---+                    [ C1 ] 10 нФ
   +-------------+                             | D | BAT54S               |
                                               +---+ (Шотткі)            GND
                                               /   \
                                         +3.3В       GND
                                           |           |
                                       [ R_shunt ] 250 Ом (для 4–20 мА)
                                           |
                                       [ MOSFET Switch ]
                                           |
                                          GND
```

### Розрахунок вузла захисту:
1. **Резистор захисту `R1`:** застосовують резистор `10 кОм` у типорозмірі `1206` або `MELFs` із допустимою потужністю `P = 0.5 Вт` та імпульсною напругою до 200 В. При постійній аварійній напрузі `Vin = +36 В` струм складе:
   ```
   I_fault = (36 В − 3.6 В) / 10000 Ом = 3.24 мА
   P_res = I² · R1 = (0.00324 А)² · 10000 Ом = 0.105 Вт  [резистор 0.5 Вт працює з 5-кратним запасом]
   ```
2. **Зовнішній каскад Clamping:** здвоєний діод Шотткі `BAT54S` перехоплює струм 3.24 мА і фіксує напругу на вході в діапазоні `−0.3 В ... +3.6 В`.
3. **Фільтр нижніх частот `R3 + C1`:** формує частоту зрізу:
   ```
   f_c = 1 / (2 · π · R3 · C1)
   f_c = 1 / (2 · 3.14159 · 1000 Ом · 10 · 10⁻⁹ Ф) ≈ 15.9 кГц
   ```
   Фільтр відсікає високочастотний промисловий шум і радіозавади перед оцифруванням АЦП.

## Модуль 4: Захищений дискретний силовий вихід на Smart High-Side ключі

Для керування індуктивними реле, світлодіодними колонами та електромагнітними замками (24 В / 1–2 А) дискретні MOSFET замінюють на інтегровані смарт-ключі серії `TPS1H100` (Texas Instruments) або `VN7050` (STMicroelectronics).

```
Схема інтелектуального виходу High-Side Switch:

   Шина живлення +24 В
   +---------------------------------------+
   |                                       |
   |      +-------------------------+      |
   +----->| VBB       TPS1H100      |      |
          |                         |      |
   IN --->| IN                 OUT  |------+-----> До навантаження (Реле/Клапан)
   (МК)   |                         |      |
          |                    GND  |      |     [ TVS Zener ]
   ST <---| DIAG / FAULT            |      |     (Вбудований Active Clamp)
   (МК)   |                    CS   |      |
          +-------------------------+      |
                 |             |          GND
                GND            |
                               +---[ R_cs ] 1 кОм ---> До АЦП (Струм навантаження)
                               |
                              GND
```

### Функціонал вбудованого апаратного захисту TPS1H100:
- **Обмеження струму короткого замикання:** фіксує струм КЗ на рівні 2.5–4.0 А, не дозволяючи вигоріти доріжкам плати.
- **Вбудоване активне затискання (Active Clamp):** при вимкненні індуктивного навантаження вбудований стабілітрон фіксує викид напруги на рівні `V_clamp = VBB − 45 В`, поглинаючи магнітну енергію котушки без зовнішнього зворотного діода.
- **Діагностичний струмовий вихід `CS` (Current Sense):** віддає струм, пропорційний вихідному струму (`I_cs = I_out / K_ratio`). Дозволяє мікроконтролеру через АЦП вимірювати реальний струм клапана й детектувати обрив дроту (Open Load) та залипання якоря.

## Швидкодіюче розмикання: напівпровідникові TBU проти PPTC у шинах зв'язку

У високошвидкісних лініях передачі даних традиційний самовідновний запобіжник PPTC має суттєвий недолік — теплову інерцію. Час переходу PPTC у високоомний стан під час важкого короткого замикання на напругу 230 В становить від 10 до 100 мілісекунд. Протягом цього часу струм через малопотужний TVS-діод може перевищити його граничну імпульсну потужність, що призведе до теплового руйнування супресора.

Для захисту критичних вузлів застосовують напівпровідникові модулі блокування перехідних процесів — **TBU (англ. *Transient Blocking Unit*)**, наприклад серії Bourns TBU-CA:
1. **Принцип дії TBU:** пристрій складається з двох зустрічно включених польових транзисторів із вбудованим каналом (Depletion MOSFET) та схеми вимірювання струму. У нормальному стані опір TBU становить усього 3–5 Ом.
2. **Швидкість спрацьовування:** щойно струм у лінії перевищує граничний поріг (наприклад, 200 мА), TBU розриває коло за час менше ніж **1 мікросекунда** (у 10 000 разів швидше за PPTC!).
3. **Блокування високої напруги:** у розімкненому стані TBU витримує напругу до 850 Вольт із мікроскопічним струмом витоку менше 1 мкА. Після зняття перенапруги пристрій миттєво повертається у низькоомний стан без залишкового нагріву.

## Правила трасування захисних каскадів на друкованій платі (PCB Layout)

Навіть ідеально підібрані компоненти захисту втрачають ефективність при помилках у розведенні плати. При проектуванні топології дотримуються трьох фундаментальних правил:

1. **Ізоляція брудної та чистої зон заземлення:** виводи заземлення вхідних супресорів, газорозрядників і роз'ємів підключають до локального «захисного полігону» (Chassis / Shield GND), який з'єднується з металевим корпусом приладу або точкою введення заземлення. Неприпустимо пускати розрядні струми TVS крізь тихий аналоговий шар землі АЦП.
2. **Мінімальна площа контурів струму розряду:** перехідні отвори на шар землі розташовують безпосередньо на контактних майданчиках компонентів захисту (технологія Via-in-Pad або пари vias поруч із майданчиком). Індуктивність навіть 2 міліметрів друкованого провідника додає сплеск `V = L · (di/dt)`, здатний пробити вхідний каскад мікросхеми.
3. **Дотримання ізоляційних зазорів (Creepage & Clearance):** навколо високовольтних вузлів (вхідні клеми, контакти газорозрядників GDT) видаляють паяльну маску та витримують зазори по поверхні плати не менше 1.5–2.5 мм для запобігання поверхневого пробою по пилу та волозі.

## Лабораторна перевірка та діагностика осцилографом

При дослідженні роботи захисних кіл на стенді важливо правильно проводити вимірювання, щоб уникнути пошкодження вимірювальних приладів:
- **Заборона підключення загального «крокодила» щупа осцилографа до незаземлених клем:** екран стандартного щупа осцилографа з'єднаний із захисним заземленням мережі 230 В через вилку живлення. Дотик земляного затискача до плати, що тестується під перенапругою, створює коротке замикання через заземлення лабораторії.
- **Використання диференційних високовольтних пробників:** вимірювання напруги на TVS, стоках MOSFET та котушках реле проводять винятково активними диференційними щупами або осцилографом з гальванічно ізольованими каналами.
- **Виявлення теплового перегріву тепловізором:** під час тривалого тесту на перенапругу (наприклад, подача 36 В на аналоговий вхід або закорочування виходу смарт-ключа) контролюють температуру обмежувальних резисторів, стабілітронів і корпусів ключів; локальний перегрів понад 85–100 °C свідчить про недостатню розсіювану потужність компонентів або завищений струм аварії.

## Програмний драйвер діагностики та обробки аварій смарт-ключів

Наведемо закінчений програмний модуль, що зчитує діагностичні виводи смарт-ключів, виконує детекцію перевантаження за струмом та обриву навантаження і реалізує алгоритм аварійного відключення.

:::tabs
```c
// Драйвер діагностики та керування смарт-ключами (C99)
#include <stdint.h>
#include <stdbool.h>

#define CHANNELS_COUNT        4U
#define CS_ADC_VREF_MV        3300U
#define CS_ADC_MAX_CODE       4095U
#define CS_RESISTOR_OHMS      1000U
#define CURRENT_RATIO_K       1000U     // K_ratio = 1000 (1 мА на CS = 1 А на виході)
#define CURRENT_MAX_LIMIT_MA  2500U     // Поріг аварії за струмом 2.5 А
#define OPEN_LOAD_LIMIT_MA    10U       // Поріг детекції обриву навантаження

typedef enum {
    LOAD_OK = 0,
    LOAD_OPEN_CIRCUIT,
    LOAD_OVERCURRENT,
    LOAD_THERMAL_SHUTDOWN
} channel_diagnostic_t;

typedef struct {
    bool enabled_target;
    bool is_hardware_fault;
    uint32_t load_current_ma;
    channel_diagnostic_t status;
    uint32_t fault_timestamp_ms;
} channel_state_t;

static channel_state_t channels[CHANNELS_COUNT];

// Переведення коду АЦП виводу Current Sense у міліампери
static uint32_t calculate_current_ma(uint16_t adc_code) {
    uint32_t v_sense_mv = ((uint32_t)adc_code * CS_ADC_VREF_MV) / CS_ADC_MAX_CODE;
    // I_cs = V_sense / R_cs; I_out = I_cs * K_ratio
    uint32_t i_out_ma = (v_sense_mv * CURRENT_RATIO_K) / CS_RESISTOR_OHMS;
    return i_out_ma;
}

void smart_switch_init(void) {
    for (uint8_t i = 0; i < CHANNELS_COUNT; ++i) {
        channels[i].enabled_target = false;
        channels[i].is_hardware_fault = false;
        channels[i].load_current_ma = 0;
        channels[i].status = LOAD_OK;
        channels[i].fault_timestamp_ms = 0;
    }
}

// Періодичний цикл опитування діагностики (виклик раз на 10 мс)
void smart_switch_process(uint8_t ch, bool fault_pin_active, uint16_t cs_adc_code, uint32_t now_ms) {
    if (ch >= CHANNELS_COUNT) return;
    
    channel_state_t *c = &channels[ch];
    c->load_current_ma = calculate_current_ma(cs_adc_code);
    c->is_hardware_fault = fault_pin_active;

    if (fault_pin_active) {
        // Апаратне вимкнення за перегрівом кристала
        c->status = LOAD_THERMAL_SHUTDOWN;
        c->enabled_target = false;
        c->fault_timestamp_ms = now_ms;
        return;
    }

    if (c->enabled_target) {
        if (c->load_current_ma > CURRENT_MAX_LIMIT_MA) {
            c->status = LOAD_OVERCURRENT;
            c->enabled_target = false;
            c->fault_timestamp_ms = now_ms;
        } else if (c->load_current_ma < OPEN_LOAD_LIMIT_MA) {
            c->status = LOAD_OPEN_CIRCUIT;
        } else {
            c->status = LOAD_OK;
        }
    } else {
        // Якщо канал вимкнено, скидаємо статус після охолодження
        if (c->status != LOAD_OK && (now_ms - c->fault_timestamp_ms > 3000U)) {
            c->status = LOAD_OK;
        }
    }
}
```

```cpp
// Ідіоматичний C++20 клас захищеного силового комутатора
#include <array>
#include <cstdint>
#include <expected>
#include <span>

enum class ChannelFault : std::uint8_t {
    None = 0,
    OpenCircuit,
    Overcurrent,
    ThermalShutdown
};

struct ChannelTelemetry {
    std::uint32_t currentMa{0};
    ChannelFault fault{ChannelFault::None};
    bool isActive{false};
};

template <std::size_t ChannelCount = 4>
class SmartSwitchBank {
public:
    static constexpr std::uint32_t AdcVrefMv = 3300;
    static constexpr std::uint32_t AdcMaxCode = 4095;
    static constexpr std::uint32_t SenseResistorOhms = 1000;
    static constexpr std::uint32_t CurrentRatioK = 1000;
    static constexpr std::uint32_t MaxCurrentLimitMa = 2500;
    static constexpr std::uint32_t OpenLoadThresholdMa = 10;
    static constexpr std::uint32_t CoolDownPeriodMs = 3000;

    constexpr SmartSwitchBank() = default;

    constexpr void setDesiredState(std::size_t ch, bool enable) noexcept {
        if (ch < ChannelCount && states_[ch].fault != ChannelFault::ThermalShutdown) {
            states_[ch].enabledTarget = enable;
        }
    }

    [[nodiscard]] constexpr std::expected<ChannelTelemetry, ChannelFault>
    updateChannel(std::size_t ch, bool faultPinState, std::uint16_t csAdcCode, std::uint32_t currentTimeMs) noexcept {
        if (ch >= ChannelCount) {
            return std::unexpected(ChannelFault::None);
        }

        auto& c = states_[ch];
        const auto senseMv = (static_cast<std::uint32_t>(csAdcCode) * AdcVrefMv) / AdcMaxCode;
        c.currentMa = (senseMv * CurrentRatioK) / SenseResistorOhms;

        if (faultPinState) {
            c.fault = ChannelFault::ThermalShutdown;
            c.enabledTarget = false;
            c.faultTimeMs = currentTimeMs;
            return std::unexpected(ChannelFault::ThermalShutdown);
        }

        if (c.enabledTarget) {
            if (c.currentMa > MaxCurrentLimitMa) {
                c.fault = ChannelFault::Overcurrent;
                c.enabledTarget = false;
                c.faultTimeMs = currentTimeMs;
                return std::unexpected(ChannelFault::Overcurrent);
            }
            if (c.currentMa < OpenLoadThresholdMa) {
                c.fault = ChannelFault::OpenCircuit;
            } else {
                c.fault = ChannelFault::None;
            }
        } else {
            if (c.fault != ChannelFault::None && (currentTimeMs - c.faultTimeMs >= CoolDownPeriodMs)) {
                c.fault = ChannelFault::None;
            }
        }

        return ChannelTelemetry{
            .currentMa = c.currentMa,
            .fault = c.fault,
            .isActive = c.enabledTarget
        };
    }

    [[nodiscard]] constexpr std::span<const ChannelTelemetry> snapshot() const noexcept {
        // Повернення знімка стану всіх каналів
        return {};
    }

private:
    struct InternalChannelState {
        bool enabledTarget{false};
        std::uint32_t currentMa{0};
        ChannelFault fault{ChannelFault::None};
        std::uint32_t faultTimeMs{0};
    };

    std::array<InternalChannelState, ChannelCount> states_{};
};
```
