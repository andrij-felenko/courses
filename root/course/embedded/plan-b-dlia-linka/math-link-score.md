# 🧮 Математика оцінки якості лінка та динамічного арбітражу

Коли безпілотний апарат або мобільний робот пересувається в зоні активної радіоелектронної боротьби, рішення про перемикання каналів зв'язку не можна ухвалювати за одним втраченим кадром чи випадковим сплеском напруги на виході RSSI. Реальний радіоефір характеризується багатопроменевим згасанням (англ. *multipath fading*), коли відбиті від землі чи споруд копії сигналу додаються у протифазі, спричиняючи глибокі локальні провали потужності тривалістю в кілька мілісекунд.

Якщо алгоритм перемикання реагує на такі короткочасні провали миттєвою зміною робочого діапазону чи активацією РЧ-комутатора, виникає небезпечне явище «флапінгу» (англ. *flapping* / *ping-pong effect*) — нескінченна серія циклічних перемикань між основним і резервним трактами. Під час кожного перемикання втрачається фазова синхронізація приймача, очищуються буфери кодеків, і корисний потік даних повністю зупиняється. З іншого боку, надмірна затримка фільтрації призводить до того, що апарат продовжує передавати команди в заблокований канал, втрачаючи керованість.

Цей математичний апарат формалізує енергетичний розрахунок радіотраси, геометрію ретрансляції, експоненційне згладжування метрик, побудову інтегральної функції корисності та розрахунок захисного коридору гістерезису.

## Геометрія зони Френеля та втрати на дифракції

Радіохвиля поширюється у просторі не нескінченно тонким променем, а в межах концентричних еліпсоїдів обертання, фокусами яких є антени передавача `TX` та приймача `RX`. Перша зона Френеля визначає область простору, всередині якої різниця ходу прямого та відбитого променів не перевищує половини довжини хвилі `λ / 2`.

Радіус поперечного перерізу першої зони Френеля `r₁` у точці на відстані `d₁` від передавача та `d₂` від приймача (за умови загальної дистанції `d = d₁ + d₂`) виводиться з геометричного рівняння еліпса:

```
(d₁² + r₁²)⁰˙⁵ + (d₂² + r₁²)⁰˙⁵ = d + λ / 2
```

Застосовуючи біноміальний розклад першого порядку для малих відношень `r₁ / d << 1`:

```
d₁ · (1 + r₁² / (2·d₁²)) + d₂ · (1 + r₁² / (2·d₂²)) ≈ d₁ + d₂ + λ / 2
(d₁ + d₂) + (r₁² / 2) · (1/d₁ + 1/d₂) = (d₁ + d₂) + λ / 2
(r₁² / 2) · ((d₁ + d₂) / (d₁ · d₂)) = λ / 2
r₁² = (λ · d₁ · d₂) / (d₁ + d₂)
r₁ = √( (λ · d₁ · d₂) / (d₁ + d₂) )
```

Якщо на шляху променя виникає перешкода висотою `h` (де `h > 0` означає, що вершина перешкоди піднімається вище лінії прямої видимості), дифракційні втрати розраховуються через безрозмірний параметр Френеля-Кірхгофа `v`:

```
v = h · √( (2 · (d₁ + d₂)) / (λ · d₁ · d₂) ) = h · √2 / r₁
```

Додаткове затухання на клиноподібній перешкоді (англ. *knife-edge diffraction loss*) у децибелах апроксимується емпіричною формулою Лі:

```
J(v) = 6.9 + 20 · log₁₀( √( (v − 0.1)² + 1 ) + v − 0.1 )    при v > −0.78
```

При перекритті лінії прямої видимості на рівні вершини (`h = 0`, `v = 0`) втрати становлять рівно `6.0` дБ (половина напруженості поля екранується). Якщо ж перешкода перекриває радіус першої зони Френеля на `h = +r₁` (`v = 1.41`), втрати сягають `J(1.41) ≈ 16.5` дБ. Для частоти 5.8 ГГц (`λ = 0.052` м) на дистанції 10 км посередині траси радіус становить `r₁ ≈ 11.4` м, тоді як для 868 МГц (`λ = 0.345` м) він дорівнює `r₁ ≈ 29.4` м.

## Експоненційне згладжування фізичних метрик (EWMA)

Миттєві вимірювання потужності сигналу (RSSI, вимірюється в дБм) та відношення сигнал/шум (SNR, вимірюється в дБ) містять високочастотний шум. Для їхнього згладжування на вбудованому мікроконтролері з обмеженою пам'яттю використовують експоненційне виважене ковзне середнє (англ. *Exponentially Weighted Moving Average*, EWMA):

```
S[k] = α · X[k] + (1 − α) · S[k−1]
```

де:
- `X[k]` — нове вимірювання від трансивера на кроці `k`;
- `S[k]` — згладжене значення;
- `α` — ваговий коефіцієнт згладжування (`0 < α ≤ 1`).

Коефіцієнт `α` математично пов'язаний із постійною часу фільтра `τ` та періодом дискретизації `Δt` (інтервалом між пакетами телеметрії):

```
α = 1 − exp(−Δt / τ)
```

При малих відношеннях `Δt / τ` застосовуємо лінійне наближення першого порядку:

```
exp(−x) ≈ 1 − x       [розклад у ряд Тейлора при x << 1]
α ≈ 1 − (1 − Δt / τ)
α ≈ Δt / τ
```

Частота зрізу такого цифрового фільтра низьких частот першого порядку по рівню −3 дБ дорівнює:

```
f_c = 1 / (2 · π · τ)
```

Якщо пакети надходять з інтервалом `Δt = 20` мс (50 Гц), а постійна часу реакції на заваду обрана `τ = 200` мс (`f_c ≈ 0.8` Гц), отримуємо `α = 20 / 200 = 0.1`.

Для виконання обчислень без рухомої коми на 32-бітних ядрах Cortex-M0/M3 з фіксованою комою у форматі Q8 (`масштаб = 256`):

```
Scaled_α = round(0.1 · 256) = 26
S_q8[k] = (26 · X[k] + (256 − 26) · S_q8[k−1]) >> 8
```

## Оцінка коефіцієнта пакетних втрат (Sliding Window PER)

Втрачений у результаті глушіння пакет не генерує сигналу на приймачі: факт втрати фіксується виключно за розривом у послідовності монотонних номерів кадрів `Sequence Number`.

Оцінка втрат виконується у бітовій масці ковзного вікна розміром `W = 32` пакети. Стан останніх 32 очікуваних пакетів зберігається як ціле 32-бітне число `mask`, де біт `1` означає успішний прийом кадру, а `0` — втрату.

```
PER = (W − popcount(mask)) / W
```

де `popcount(mask)` — апаратна інструкція підрахунку встановлених бітів.

При надходженні пакета з номером `seq_curr` та попереднім найвищим номером `seq_last`:

```
Δseq = seq_curr − seq_last

Якщо Δseq == 1:
  mask = (mask << 1) | 1

Якщо Δseq > 1 (сталися втрати):
  mask = (mask << Δseq) | 1   [пропущені біти заповнюються нулями]
  
Якщо Δseq <= 0 (запізнілий пакет або дублікат):
  idx = seq_last − seq_curr
  якщо idx < W:
    mask = mask | (1 << idx)  [відновлення біта без зсуву вікна]
```

## Інтегральна функція корисності каналу (Composite Link Score)

Кожен фізичний носій зв'язку характеризується вектором метрик `M = ⟨PER, SNR, RTT⟩`.

Для зведення різнорідних фізичних величин до єдиної шкали кожна метрика нормалізується у безрозмірний діапазон `[0.0, 1.0]`:

1. **Корисність за втратами пакетів:**
```
U_per = 1.0 − min(1.0, PER / PER_max)
```
де `PER_max = 0.50` (50% втрат вважається повним руйнуванням каналу).

2. **Корисність за відношенням сигнал/шум:**
```
U_snr = clamp((SNR_згладж − SNR_min) / (SNR_target − SNR_min), 0.0, 1.0)
```
де для LoRa (SF7, BW 250 кГц) межі становлять `SNR_min = −12.5` дБ, `SNR_target = +5.0` дБ; для Wi-Fi OFDM: `SNR_min = +5.0` дБ, `SNR_target = +25.0` дБ.

3. **Корисність за круговою затримкою (RTT):**
```
U_rtt = clamp(1.0 − (RTT − RTT_min) / (RTT_max − RTT_min), 0.0, 1.0)
```
де `RTT_min = 15` мс, `RTT_max = 300` мс.

Підсумковий інтегральний бал лінка `Score` обчислюється як зважена лінійна комбінація:

```
Score = w_per · U_per + w_snr · U_snr + w_rtt · U_rtt
```

де сума ваг дорівнює одиниці: `w_per + w_snr + w_rtt = 1.0`. Для критичного контуру керування БПЛА пріоритет надається надійності доставки: `w_per = 0.55`, `w_snr = 0.30`, `w_rtt = 0.15`.

## Математика гістерезису та захист від флапінгу

Нехай поточний активний носій — `Primary` з оцінкою якості `S_prim`, а резервний носій — `Fallback` з оцінкою `S_fall`.

Для усунення блукання між каналами застосовується асиметрична порогова політика:

1. **Аварійне перемикання вниз (Failover):**
Відбувається з мінімальною затримкою при падінні інтегрального балу нижче порогу `θ_down` або при виявленні сплеску послідовних втрат `N_burst`:

```
Умова_Failover = (S_prim < θ_down) ∨ (N_consecutive_lost ≥ N_burst)
```
Типові значення для тактичного контуру: `θ_down = 0.35`, `N_burst = 4` пакети. Час спрацьовування становить менше 80 мс при частоті телеметрії 50 Гц.

2. **Повернення на основний канал (Recovery):**
Вимагає виконання двох умов одночасно: інтегральний бал основного каналу повинен перевищити підвищений поріг `θ_up`, бути вищим за резервний на величину запасу `Δ_margin`, і ця умова має безперервно утримуватися протягом часу стабілізації `T_dwell`:

```
Умова_Recovery = (S_prim ≥ θ_up) ∧ (S_prim ≥ S_fall + Δ_margin)  протягом  t ≥ T_dwell
```
де:
- `θ_up = 0.75` (величина захисного коридору гістерезису `Δ_hyst = θ_up − θ_down = 0.40`);
- `Δ_margin = 0.15`;
- `T_dwell = 4.0 ... 6.0` секунд.

Ймовірність помилкового подвійного перемикання при випадкових флуктуаціях шуму з дисперсією `σ²` за наявності коридору `Δ_hyst` підпорядковується функції розподілу Гаусса:

```
P_flapping ∝ Q(Δ_hyst / (2 · σ))
```
де `Q(x) = (1 / √(2π)) · ∫ [t = x .. ∞] exp(−t² / 2) dt`. При `Δ_hyst = 0.40` та рівні шумів `σ = 0.08` аргумент становить `x = 2.5`, що дає ймовірність помилкового спрацьовування `P_flapping < 6.2 · 10⁻³`, а з урахуванням часового утримання `T_dwell = 4` с ймовірність випадкового повернення практично дорівнює нулю.

## Метрика очікуваної кількості передач (ETX) у топології Mesh

При використанні ретранслятора маршрут складається з кількох послідовних радіопрольотів (hops). Оцінювати такий ланцюжок за середнім арифметичним RSSI не можна, оскільки єдина деградована ланка з високими втратами блокує весь трафік.

Метрика **ETX** (англ. *Expected Transmission Count*) розраховує математичне сподівання кількості спроб передачі кадру з урахуванням квитанцій підтвердження (ACK):

```
ETX_hop = 1 / (d_f · d_r)
```

де:
- `d_f` (forward delivery ratio) — ймовірність успішного проходження кадру вперед від вузла `A` до вузла `B`;
- `d_r` (reverse delivery ratio) — ймовірність успішного повернення кадру підтвердження ACK від `B` до `A`.

Для наскрізного маршруту з `H` проміжних прольотів сумарний ETX є сумою окремих ділянок:

```
ETX_total = ∑ [i = 1 .. H] (1 / (d_f[i] · d_r[i]))
```

Якщо прямий канал зв'язку GCS → БПЛА частково придушений РЕБ і має ймовірність проходження `d_f = 0.08, d_r = 0.08`:
```
ETX_direct = 1 / (0.08 · 0.08) = 1 / 0.0064 = 156.25 передачі
```

Якщо через піднятий дрон-ретранслятор організовано два якісні радіопрольоти з `d_f1 = 0.96, d_r1 = 0.96` та `d_f2 = 0.92, d_r2 = 0.92`:
```
ETX_relay = (1 / (0.96 · 0.96)) + (1 / (0.92 · 0.92))
ETX_relay = 1.085 + 1.181 = 2.266 передачі
```

Алгоритм маршрутизатора постійно порівнює `ETX_direct` та `ETX_relay`. Щойно прямий ETX перевищує сумарний ETX ретрансляційного ланцюжка з урахуванням додаткового коефіцієнта накладних витрат на ретрансляцію, трафік миттєво перенаправляється через повітряний ретранслятор.
