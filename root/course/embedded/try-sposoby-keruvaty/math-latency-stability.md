# 🧮 Фазовий зсув, затримка транспорту та стійкість контуру: чому ручне керування зривається при 100 мс

Будь-який дистанційно керований апарат — це замкнена динамічна система, у якій сигнал проходить ланцюг «давач → радіолінк передачі → зір/мозок людини → орган керування → радіолінк команд → автопілот → двигуни». Якщо в контурі з'являється чиста транспортна затримка (*pure transport delay*), вона вносить фазове запізнення, що безпосередньо з'їдає запас стійкості за фазою (*phase margin*).

Ця вставка математично доводить, чому при прямому ручному керуванні (Acro / Rate) затримка понад 80–100 мс призводить до неминучого розгойдування апарата людиною (Pilot-Induced Oscillation), тоді як при переході до керування з підтримкою (Fly-by-Wire) чи наглядового керування (Supervisory Control) система зберігає абсолютну стійкість навіть при затримках у сотні мілісекунд та одиниці секунд.

## 1. Математична модель чистої затримки та фазовий зсув

Транспортна затримка на час `τ` секунд у часовій області описується оператором зсуву сигналу:

```
y(t) = x(t − τ)
```

Застосувавши перетворення Лапласа, отримуємо передавальну функцію ланки затримки:

```
W_delay(s) = e^(−s · τ)
```

Щоб знайти амплітудно-фазову частотну характеристику (АФЧХ), підставимо `s = j·ω`, де `ω` — кругова частота коливань у контурі (рад/с):

```
W_delay(j·ω) = e^(−j·ω·τ) = cos(ω·τ) − j·sin(ω·τ)
```

Звідси амплітудна характеристика `|W(j·ω)|` та фазова характеристика `φ_delay(ω)`:

```
|W_delay(j·ω)| = √(cos²(ω·τ) + sin²(ω·τ)) = 1.0     [амплітуда не змінюється]
φ_delay(ω)     = −ω · τ  (радіан)                   [фазовий зсув лінійно падає]
```

Переведемо фазовий зсув у градуси:

```
Δφ_delay(ω) = −(ω · τ) · (180° / π) ≈ −57.3° · ω · τ
```

**Ключовий висновок:** транспортна затримка не зменшує амплітуду сигналу (коефіцієнт підсилення залишається рівним 1), але вносить фазове запізнення `Δφ`, пропорційне до частоти сигналу `ω` та величини затримки `τ`.

## 2. Критерій стійкості за фазою Найквіста-Боде

Для розімкненого контуру керування `L(s)` частота зрізу `ω_c` (*crossover frequency*) визначається як частота, на якій модуль коефіцієнта підсилення дорівнює одиниці:

```
|L(j·ω_c)| = 1  (тобто 0 дБ)
```

Запас стійкості за фазою `PM` (*Phase Margin*) показує, на скільки градусів фаза системи на частоті зрізу перевищує критичну точку розгойдування −180°:

```
PM = 180° + ∠L(j·ω_c)
```

Якщо `PM > 0°`, замкнена система стійка; для надійної роботи без перерегулювання в інженерній практиці вимагається `PM ≥ 45° .. 60°`. Якщо `PM ≤ 0°`, контур самозбуджується і переходить у незгасаючі коливання.

Додавання транспортної затримки `τ` зменшує фактичний запас фази:

```
PM_delayed = PM_0 − ω_c · τ · (180° / π)
```

Звідси критична затримка `τ_crit`, при якій контур повністю втрачає стійкість (`PM_delayed = 0`):

```
τ_crit = PM_0 / (ω_c · (180° / π)) = PM_0_rad / ω_c
```

Чим вища частота зрізу контуру `ω_c` (тобто чим швидше мусить реагувати контур), тим меншу затримку `τ` здатна витримати система.

## 3. Парадигма 1: Пряме ручне керування (Acro / Rate)

У режимі прямого ручного керування оператор намагається утримати кутове положення квадрокоптера. Фізика обертання твердого тіла навколо однієї осі описується другим законом Ньютона для обертального руху:

```
I · θ̈(t) = M(t)
```

де `I` — момент інерції (кг·м²), `θ` — кут нахилу (рад), `M` — сумарний керівний момент моторів (Н·м).

Передавальна функція апарата «момент → кут»:

```
G_plant(s) = 1 / (I · s²)
```

Це подвійний інтегратор. Власна фаза подвійного інтегратора дорівнює строго `−180°` на всіх частотах:

```
∠G_plant(j·ω) = ∠(1 / (j·ω)²) = ∠(−1 / ω²) = −180°
```

Подвійний інтегратор сам по собі перебуває на межі нестійкості. Щоб стабілізувати його, людина-пілот мусить сформувати випередження за фазою (діяти як диференціальна ланка PD-регулятора).

Згідно з класичною моделлю перетину Мак-Руера (*McRuer Crossover Model*), передавальна функція тренованого оператора в задачі компенсаційного стеження має вигляд:

```
Y_p(s) = K_p · (T_L · s + 1) · e^(−s · τ_h)
```

де:
- `K_p` — коефіцієнт підсилення пілота;
- `T_L ≈ 0.3 .. 0.6 с` — постійна часу диференціювання (пілот прогнозує рух);
- `τ_h ≈ 0.15 .. 0.25 с` (150–250 мс) — власна нейром'язова затримка реакції людини.

Сумарна затримка контуру складається з затримки людини `τ_h` та затримки радіо/відеоканалу `τ_link`:

```
τ_Σ = τ_h + τ_link
```

Типова частота зрізу контуру ручного утримання кута квадрокоптера в режимі Acro становить `ω_c ≈ 3.5 .. 5.0 рад/с` (це відповідає спробам пілота робити 0.6–0.8 коригувальних рухів за секунду).

Розрахуємо фазовий зсув для `ω_c = 4.0 рад/с`:

1. Базовий запас фази, який забезпечує пілот за рахунок випередження `T_L`:
   `PM_0 ≈ 40°` (0.70 рад).
2. Критична допустима затримка контуру:
   `τ_crit = 0.70 рад / 4.0 рад/с = 0.175 с = 175 мс`.

Тепер підставимо реальні затримки:
- Власна реакція пілота: `τ_h = 180 мс`.
- Цифровий FPV-відеолінк + RC-канал керування: `τ_link = 80 мс`.
- Сумарна затримка: `τ_Σ = 180 + 80 = 260 мс`.

Обчислимо реальний запас фази:

```
PM_delayed = 40° − (4.0 рад/с · 0.260 с · 57.3°/рад)
           = 40° − 59.6°     [фазове запізнення затримки 260 мс]
           = −19.6°          [від'ємний запас: втрата стійкості]
```

**Результат:** Запас фази від'ємний (`−19.6°`). Система розхитується. Виникає класичне явище **PIO** (*Pilot-Induced Oscillation*): пілот бачить нахил праворуч, дає лівий стік, але через 260 мс команда приходить тоді, коли апарат уже сам повертається, і команда штовхає його в ще більший крен ліворуч. За 2–3 цикли амплітуда коливань досягає 90°, і дрон падає.

## 4. Парадигма 2: Керування з підтримкою (Fly-by-Wire / Angle / Alt-Hold)

У парадигмі Fly-by-Wire автопілот розриває прямий зв'язок оператора з моментами й бере швидкісний контур стабілізації на себе.

Внутрішній контур кутових швидкостей працює безпосередньо на бортовому мікроконтролері з частотою `f_loop = 1000 .. 8000 Гц`. Його затримка `τ_board` становить менше `1 мс` (`0.001 с`), а частота зрізу сягає `ω_c,inner = 30 .. 50 рад/с`.

Втрата фази внутрішнього контуру на борту:

```
Δφ_inner = −(40 рад/с · 0.001 с · 57.3°) = −2.3°  [незначна втрата]
```

Бортовий контур орієнтації перетворює об'єкт керування для пілота з подвійного інтегратора `1 / (I·s²)` на аперіодичну ланку першого порядку:

```
G_closed_attitude(s) ≈ 1 / (T_att · s + 1)
```

де `T_att ≈ 0.15 .. 0.25 с` — постійна часу відпрацювання кута автопілотом.

Фазовий зсув аперіодичної ланки не перевищує `−90°` (на відміну від `−180°` некерованого дрона). Пілотові більше не потрібно диференціювати сигнал і працювати рефлекторним демпфером. Його робоча частота зрізу знижується до `ω_c,outer ≈ 1.0 .. 1.5 рад/с`.

Перерахуємо критичну затримку для зовнішнього контуру з `ω_c = 1.2 рад/с` та базовим запасом фази `PM_0 ≈ 65°` (1.13 рад):

```
τ_crit,assisted = 1.13 рад / 1.2 рад/с ≈ 0.94 с = 940 мс
```

При затримці каналу зв'язку `τ_link = 150 мс` і затримці оператора `τ_h = 200 мс` (`τ_Σ = 350 мс`):

```
PM_delayed = 65° − (1.2 рад/с · 0.350 с · 57.3°)
           = 65° − 24.1°     [фазове запізнення затримки 350 мс]
           = +40.9°          [додатний запас: система стійка]
```

**Результат:** Запас фази становить солідні `+40.9°`. Апарат керується передбачувано й плавно. Навіть якщо зв'язок пропаде на 300–500 мс, дрон не перекинеться, а просто утримуватиме поточний кут або автоматично повернеться в горизонт при нейтральному положенні стіка.

## 5. Парадигма 3: Наглядове керування (Supervisory Control)

У наглядовому керуванні замкнений контур динамічного руху повністю замикається на борту (включаючи позиціонування за GNSS, оптичним потоком або лідаром).

Оператор взаємодіє з системою не через безперервний потік у ставок, а дискретними високорівневими командами (поставити точку, змінити висоту, почати місію). Робоча частота зрізу людино-машинного діалогу падає до частоти планування:

```
ω_c,supervisory ≈ 0.01 .. 0.1 рад/с
```

Критична затримка каналу:

```
τ_crit,supervisory = PM_0_rad / 0.05 рад/с ≈ 1.2 рад / 0.05 рад/с = 24 секунди
```

Затримка радіоканалу повністю виводиться з контуру динамічної стійкості. Апарат може отримувати команду через супутниковий лінк Iridium із затримкою 5 секунд або через MAVLink High-Latency шлюз — це ніяк не впливає на стабільність його польоту, оскільки траєкторію розраховує та контролює бортовий комп'ютер.

## Зведена таблиця динамічної стійкості трьох парадигм

|---|---|---|---|
| **Об'єкт для людини** | Подвійний інтегратор `1/(I·s²)` | Аперіодична ланка `1/(T·s+1)` | Автономний агент (дискретні цілі) |
| **Власна фаза об'єкта** | −180° | −45° .. −90° | 0° (повна автономна ізоляція) |

| **Критична сумарна затримка `τ_crit`** | 120 – 180 мс | 700 – 1000 мс | 15 – 60 секунд (і більше) |
| **Граничний лаг радіолінка `τ_link`** | < 30 – 50 мс | < 250 – 400 мс | Не обмежений (секунди, хвилини) |
| **Наслідок перевищення затримки** | Катастрофічне розгойдування (PIO), падіння | Сповільнена реакція, переліт точки | Запізнення початку виконання задачі |
