# 🧮 Кінематичні рівняння Ейлера та виведення сингулярності

Тривісний гіроскоп вимірює вектор миттєвої кутової швидкості в осях корпусу апарата: `ω = [p, q, r]ᵀ`. Проте навігаційні алгоритми, контури стабілізації та людино-машинні інтерфейси вимагають знання швидкості зміни просторових кутів орієнтації — крену, тангажу й рискання (`dφ/dt`, `dθ/dt`, `dψ/dt`). Цей математичний розбір виводить пряму й обернену матриці кінематичного зв'язку між кутовими швидкостями тіла та похідними кутів Тейта-Браяна, аналітично доводить неминучість ділення на нуль при тангажі `±90°`, досліджує поведінку числа обумовленості матриці Якобі та виводить точні аналітичні розв'язки дискретної кінематики кватерніонів через матричну експоненту.

## Послідовність поворотів Тейта-Браяна Z-Y′-X″

Орієнтація зв'язаної з тілом системи координат (Body Frame) відносно вихідної навігаційної системи (Navigation Frame) задається трьома послідовними власними (intrinsic) поворотами:

1. Поворот навколо початкової вертикальної осі `Z` на кут рискання `ψ` (yaw, курс).
2. Поворот навколо проміжної поперечної осі `Y′` на кут тангажу `θ` (pitch).
3. Поворот навколо нової поздовжньої осі `X″` на кут крену `φ` (roll).

Повна кутова швидкість апарата `ω` є векторною сумою кутових швидкостей трьох окремих поворотів. Оскільки кожен поворот відбувається у власній проміжній системі координат, для їх проектування на осі кінцевої системи тіла необхідно застосувати матриці відповідних наступних поворотів:

```
ω_body = [dφ/dt, 0, 0]ᵀ + R_x(φ)·[0, dθ/dt, 0]ᵀ + R_x(φ)·R_y(θ)·[0, 0, dψ/dt]ᵀ
```

де елементарні матриці повороту навколо осей `X` та `Y` мають вигляд:

```
R_x(φ) = [ [1,      0,       0],
           [0,  cos(φ),  sin(φ)],
           [0, -sin(φ),  cos(φ)] ]

R_y(θ) = [ [ cos(θ),  0, -sin(θ)],
           [      0,  1,       0],
           [ sin(θ),  0,  cos(θ)] ]
```

## Проектування складових обертання на осі тіла

Обчислимо внесок кожної кутової швидкості в осі тіла крок за кроком.

Швидкість крену `dφ/dt` діє безпосередньо вздовж кінцевої осі `X` тіла, тому не потребує додаткових перетворень:

```
ω_roll = [dφ/dt, 0, 0]ᵀ
```

Швидкість тангажу `dθ/dt` діє вздовж проміжної осі `Y′`. Щоб перевести її в кінцеву систему тіла, множимо вектор на матрицю останнього повороту крену `R_x(φ)`:

```
ω_pitch = R_x(φ) · [0, dθ/dt, 0]ᵀ
        = [0, cos(φ)·dθ/dt, -sin(φ)·dθ/dt]ᵀ
```

Швидкість рискання `dψ/dt` діє вздовж вихідної осі `Z` навігаційної системи. Вона проходить крізь обидва наступні повороти — тангажу `R_y(θ)` та крену `R_x(φ)`:

```
R_y(θ) · [0, 0, dψ/dt]ᵀ = [-sin(θ)·dψ/dt, 0, cos(θ)·dψ/dt]ᵀ

ω_yaw = R_x(φ) · [-sin(θ)·dψ/dt, 0, cos(θ)·dψ/dt]ᵀ
      = [-sin(θ)·dψ/dt, sin(φ)·cos(θ)·dψ/dt, cos(φ)·cos(θ)·dψ/dt]ᵀ
```

Додаючи внески всіх трьох складових, отримуємо скалярні вирази для проекцій вектора кутової швидкості в осях тіла `[p, q, r]ᵀ`:

```
p = dφ/dt − sin(θ)·dψ/dt
q = cos(φ)·dθ/dt + sin(φ)·cos(θ)·dψ/dt
r = −sin(φ)·dθ/dt + cos(φ)·cos(θ)·dψ/dt
```

У матричній формі прямий зв'язок записується через кінематичну матрицю Якобі `W(φ, θ)`:

```
[p]   [ 1,       0,          −sin(θ) ]   [dφ/dt]
[q] = [ 0,  cos(φ),   sin(φ)·cos(θ) ] · [dθ/dt]
[r]   [ 0, −sin(φ),   cos(φ)·cos(θ) ]   [dψ/dt]
```

## Обернення кінематичної матриці та виникнення сингулярності

Щоб знайти швидкості зміни ейлерових кутів за показами бортового гіроскопа `[p, q, r]ᵀ`, необхідно знайти обернену матрицю `W⁻¹(φ, θ)`.

Обчислимо визначник матриці `W`, розклавши його за елементами першого стовпця:

```
det(W) = 1 · (cos(φ) · cos(φ)·cos(θ) − (−sin(φ)) · sin(φ)·cos(θ))
       = cos(θ) · (cos²(φ) + sin²(φ))    [винесення спільного множника cos(θ)]
       = cos(θ) · 1                      [основна тригонометрична тотожність]
       = cos(θ)
```

Визначник прямої кінематичної матриці залежить виключно від кута тангажу `θ` і обертається в нуль при:

```
cos(θ) = 0  ⇒  θ = ±90° (±π/2 рад)
```

Для обчислення оберненої матриці знайдемо матрицю алгебраїчних доповнень (adjugate matrix) `Adj(W)`:

```
C₁₁ = cos²(φ)·cos(θ) + sin²(φ)·cos(θ) = cos(θ)
C₁₂ = 0
C₁₃ = 0
C₂₁ = sin(φ)·sin(θ)·cos(θ)
C₂₂ = cos(φ)·cos(θ)
C₂₃ = sin(φ)·cos(θ)
C₃₁ = cos(φ)·sin(θ)·cos(θ)
C₃₂ = −sin(φ)·cos(θ)
C₃₃ = cos(φ)·cos(θ)
```

Транспонуючи матрицю доповнень і ділячи кожен елемент на визначник `det(W) = cos(θ)`, отримуємо обернену матрицю `W⁻¹(φ, θ)`:

```
W⁻¹(φ, θ) = [ [ 1,  sin(φ)·tan(θ),  cos(φ)·tan(θ) ],
              [ 0,         cos(φ),        −sin(φ) ],
              [ 0,  sin(φ)/cos(θ),  cos(φ)/cos(θ) ] ]
```

Множення матриці `W⁻¹` на вектор кутової швидкості `[p, q, r]ᵀ` дає диференціальні кінематичні рівняння для швидкостей зміни кутів Ейлера:

```
dφ/dt = p + (q·sin(φ) + r·cos(φ)) · tan(θ)
dθ/dt = q·cos(φ) − r·sin(φ)
dψ/dt = (q·sin(φ) + r·cos(φ)) / cos(θ)
```

## Дослідження поведінки та числа обумовленості біля сингулярності

Аналітичний вигляд рівнянь містить вирази `tan(θ)` та `1 / cos(θ)`. Дослідимо поведінку системи при наближенні кута тангажу `θ` до критичного значення `90°`.

Число обумовленості матриці `W` (Condition Number) за спектральною нормою визначається як відношення максимального сингулярного числа до мінімального:

```
cond(W) = σ_max(W) / σ_min(W)
```

Коли `θ → 0°`, матриця `W` є майже ортогональною:
```
cond(W) ≈ 1.0    [ідеальна числова стабільність]
```

Коли `θ → 90°`:
```
σ_min(W) = cos(θ) → 0
cond(W) = 1 / cos(θ) → ∞
```

Прямування числа обумовленості до нескінченності означає, що похибка обчислення кутових похідних зростає експоненційно. Розглянемо числовий приклад розрахунку на мікроконтролері.

Нехай апарат рухається з постійним кутом крену `φ = 1.0°` (`sin(1°) ≈ 0.017452`, `cos(1°) ≈ 0.999848`), а гіроскоп фіксує шум або малу кутову швидкість навколо осі тангажу `q = 0.05 рад/с` (`≈ 2.86 °/с`) при `p = 0` та `r = 0`.

При `θ = 0.0°` (горизонтальний політ):
```
dφ/dt = 0 + 0.05 · sin(1°) · tan(0°) = 0.0 рад/с
dθ/dt = 0.05 · cos(1°) = 0.04999 рад/с
dψ/dt = (0.05 · sin(1°)) / cos(0°) = 0.00087 рад/с (≈ 0.05 °/с)
```

При `θ = 89.0°` (`cos(89°) ≈ 0.017452`, `tan(89°) ≈ 57.29`):
```
dφ/dt = 0.05 · 0.017452 · 57.29 ≈ 0.050 рад/с (≈ 2.86 °/с)
dθ/dt = 0.05 · cos(1°) ≈ 0.050 рад/с
dψ/dt = (0.05 · 0.017452) / 0.017452 = 0.050 рад/с (≈ 2.86 °/с)
```

При `θ = 89.99°` (`cos(89.99°) ≈ 0.00017453`, `tan(89.99°) ≈ 5729.58`):
```
dφ/dt = 0.05 · 0.017452 · 5729.58 ≈ 5.0 рад/с (≈ 286.5 °/с)
dψ/dt = (0.05 · 0.017452) / 0.00017453 ≈ 5.0 рад/с (≈ 286.5 °/с)
```

При `θ = 89.9999°` (`cos(89.9999°) ≈ 1.745 · 10⁻⁶`):
```
dψ/dt = (0.05 · 0.017452) / (1.745 · 10⁻⁶) ≈ 500.0 рад/с (≈ 28647.9 °/с)
```

Зміна тангажу лише на кілька сотих градуса викликає катастрофічний стрибок розрахункової похідної курсу на десятки тисяч градусів на секунду. Будь-який цифровий фільтр із фіксованим кроком дискретизації `Δt` миттєво переповнюється або видає чисельне переповнення (`Inf`/`NaN`).

## Кінематика кватерніонів: доведення унітарності та гладкості

На противагу кутам Ейлера, одиничний кватерніон `q = [q₀, q₁, q₂, q₃]ᵀ` параметризує простір поворотів через тривимірну гіперсферу `S³` у просторі `ℝ⁴`.

Диференціальне кінематичне рівняння для кватерніона записується через гамільтонів добуток:

```
dq/dt = 0.5 · q ⊗ [0, p, q, r]ᵀ
```

У матричній формі це диференціальне рівняння першого порядку має вигляд:

```
[dq₀/dt]         [  0, −p, −q, −r ]   [q₀]
[dq₁/dt] = 0.5 · [  p,  0,  r, −q ] · [q₁]
[dq₂/dt]         [  q, −r,  0,  p ]   [q₂]
[dq₃/dt]         [  r,  q, −p,  0 ]   [q₃]
```

Позначимо кососиметричну матрицю зв'язку через `Ω(ω)`. Її ключова властивість — антисиметричність:

```
Ω(ω)ᵀ = −Ω(ω)
```

Доведемо строге збереження одиничної норми кватерніона в неперервному часі:

```
d/dt (||q||²) = d/dt (qᵀ · q)
              = (dq/dt)ᵀ · q + qᵀ · (dq/dt)
              = (0.5 · Ω(ω) · q)ᵀ · q + qᵀ · (0.5 · Ω(ω) · q)
              = 0.5 · qᵀ · Ω(ω)ᵀ · q + 0.5 · qᵀ · Ω(ω) · q
              = 0.5 · qᵀ · (−Ω(ω)) · q + 0.5 · qᵀ · Ω(ω) · q   [антисиметричність Ω]
              = −0.5 · qᵀ · Ω(ω) · q + 0.5 · qᵀ · Ω(ω) · q
              = 0
```

Похідна квадрата норми тотожно дорівнює нулю за будь-якої кутової швидкості `ω`. Одинична довжина кватерніона є строгим математичним інваріантом неперервної динамічної системи.

Обчислимо визначник матриці `Ω(ω)`:

```
det(Ω(ω)) = (p² + q² + r²)² = ||ω||⁴
```

Власні значення матриці `0.5 · Ω(ω)` є суто уявними: `λ₁,₂ = +0.5i·||ω||`, `λ₃,₄ = −0.5i·||ω||`. Це гарантує, що оператор обертання кватерніона здійснює чистий поворот фазового простору без дисипації та без сингулярностей за будь-якої просторової конфігурації.

## Точний дискретний розв'язок через матричну експоненту

У реальних вбудованих системах вимірювання кутової швидкості надходять дискретно з фіксованим періодом `Δt`. Якщо вважати вектор `ω` постійним протягом інтервалу дискретизації `[t, t + Δt]`, лінійне диференціальне рівняння `dq/dt = 0.5 · Ω(ω) · q` має строгий аналітичний розв'язок у формі матричної експоненти:

```
q(t + Δt) = exp(0.5 · Ω(ω) · Δt) · q(t)
```

Оскільки матриця `Ω(ω)` задовольняє характеристичне рівняння `Ω² = −||ω||² · I₄`, ряд Тейлора для експоненти згортається у замкнену тригонометричну форму:

```
exp(0.5 · Ω · Δt) = I₄ + (0.5 · Ω · Δt) + (0.5 · Ω · Δt)² / 2! + ...
                  = cos(0.5 · ||ω|| · Δt) · I₄ + (sin(0.5 · ||ω|| · Δt) / ||ω||) · Ω(ω)
```

Позначимо кутовий приріст за крок часу через `Δθ = ||ω|| · Δt`. Тоді точний розв'язок записується у вигляді:

```
q(t + Δt) = [ cos(Δθ / 2) · I₄ + (sin(Δθ / 2) / Δθ) · Ω(ω) · Δt ] · q(t)
```

При малих значеннях кутового приросту `Δθ → 0` вираз `sin(Δθ / 2) / Δθ` розкладається в ряд Маклорена:

```
sin(Δθ / 2) / Δθ = 0.5 − (Δθ)² / 48 + O(Δθ⁴)
```

Цей розклад усуває необхідність ділення на нуль при зупинці обертання апарата (`||ω|| = 0`) і забезпечує найвищу точність числового інтегрування без накопичення фазових похибок.
