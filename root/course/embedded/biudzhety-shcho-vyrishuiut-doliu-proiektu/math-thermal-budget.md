# 🧮 Розрахунок теплового ланцюга та перегріву компонентів на платі

Цей розрахунок дає покроковий інженерний метод обчислення температури напівпровідникового кристала, теплового опору друкованої плати та оцінки ефективності тепловідвідних мідних полігонів і масивів перехідних отворів, без яких неможливо гарантувати надійність силових стабілізаторів і процесорів у закритому корпусі.

Коли через лінійний стабілізатор або силове ядро мікроконтролера протікає струм, різниця потенціалів між входом і виходом неминуче розсіюється у вигляді теплової потужності. Якщо тепловий опір від кристала до навколишнього повітря зависокий, температура кремнієвого переходу перевищує критичну межу (зазвичай 125 °C або 150 °C), що спричиняє раптове спрацьовування внутрішнього теплового захисту (англ. *Thermal Shutdown*) або деградацію напівпровідникової структури.

## Еквівалентна теплова схема: аналогія закону Ома

Тепловий потік, що поширюється від нагрітого кристала крізь конструктивні шари в навколишнє середовище, підпорядковується закону теплопровідності Фур'є. У квазістатичному режимі тепловий процес описується лінійною еквівалентною схемою, де:
- Різниця температур ΔT (вимірюється в кельвінах або градусах Цельсія, °C) є аналогом електричної напруги ΔV.
- Теплова потужність розсіювання P_loss (вимірюється у ватах, Вт) є аналогом електричного струму I.
- Тепловий опір R_th (або θ, вимірюється в °C/Вт або K/Вт) є аналогом електричного опору R.

![Тепловий ланцюг: відведення потужності через полігони та thermal vias](/root/course/embedded/biudzhety-shcho-vyrishuiut-doliu-proiektu/img/thermal-via-conduction.svg)
*Пошарова структура відведення тепла від кристала напівпровідника крізь корпус, термопад, масив теплових перехідних отворів і мідні шари друкованої плати в повітря.*

Фундаментальне співвідношення теплового балансу для кристала, розташованого в повітряному середовищі з температурою T_a:

```
T_j = T_a + P_loss · R_th_JA
```

де:
- `T_j` — температура кремнієвого переходу (англ. *Junction Temperature*), °C.
- `T_a` — температура навколишнього середовища (англ. *Ambient Temperature*), °C. Для пристроїв усередині закритого пластикового корпусу температура повітря безпосередньо біля плати зазвичай на 15–30 °C вища за температуру за межами корпусу.
- `P_loss` — електрична потужність, яка перетворюється на тепло, Вт.
- `R_th_JA` (або `θ_JA`) — повний тепловий опір за маршрутом «кристал — навколишнє середовище» (англ. *Junction-to-Ambient Thermal Resistance*), °C/Вт.

Повний тепловий опір `R_th_JA` складається з послідовного ланцюга проміжних теплових опорів:

```
R_th_JA = R_th_JC + R_th_CS + R_th_SA
```

де:
- `R_th_JC` (`θ_JC`) — тепловий опір від кристала до металевого майданчика корпусу (англ. *Junction-to-Case*). Ця величина жорстко задана виробником мікросхеми та її конструкцією.
- `R_th_CS` (`θ_CS`) — тепловий опір контактного шару припою або термопасти між корпусом і друкованою платою (англ. *Case-to-Sink / Case-to-Board*).
- `R_th_SA` (`θ_SA`) — тепловий опір від мідного полігону плати (або радіатора) до вільного повітря (англ. *Sink-to-Ambient*).

## Теплова потужність: лінійний регулятор проти імпульсного перетворювача

Для лінійного стабілізатора напруги (LDO) струм навантаження `I_out` протікає безпосередньо від вхідного виводу до вихідного. Додатково через мікросхему протікає малий власний струм спокою `I_Q`. Теплова потужність розсіювання LDO обчислюється точно:

```
P_loss_LDO = (V_in - V_out) · I_out + V_in · I_Q
```

Оскільки струм спокою `I_Q` сучасних LDO становить від кількох мікроамперів до кількох міліамперів, при струмах навантаження понад 50 мА другим доданком часто можна знехтувати:

```
P_loss_LDO ≈ (V_in - V_out) · I_out
```

Для імпульсного знижувального перетворювача (Buck DC-DC) з коефіцієнтом корисної дії η теплові втрати визначаються виключно недосконалістю перемикання ключів і активним опором котушки індуктивності:

```
P_out = V_out · I_out
P_in  = P_out / η
P_loss_Buck = P_in - P_out = P_out · (1 - η) / η
P_loss_Buck = (V_out · I_out · (1 - η)) / η
```

## Тепловий опір мідного полігону та перехідних отворів (Thermal Vias)

Склотекстоліт FR4 є надзвичайно поганим провідником тепла: його питома теплопровідність становить лише `k_FR4 ≈ 0.25–0.30 Вт/(м·К)`. Натомість чиста мідь має питому теплопровідність `k_Cu ≈ 385–400 Вт/(м·К)`, що у 1300 разів вище за текстоліт.

Тому єдиним ефективним шляхом скидання тепла від безвивідних корпусів (QFN, DFN, SOT-223, TO-252/DPAK) є передача тепла на верхній мідний полігон і скидання його крізь товщу плати на нижній земляний полігон за допомогою масиву металізованих отворів.

### Розрахунок теплового опору одного перехідного отвору

Перехідний отвір (англ. *via*) являє собою порожнистий мідний циліндр усередині текстоліту. Нехай:
- `h` — товщина друкованої плати (зазвичай `1.6 мм = 0.0016 м`).
- `d_drill` — діаметр свердління отвору (типово `0.3 мм = 0.0003 м`, радіус `r_ext = 0.15 мм`).
- `t_plating` — товщина металізації міддю на стінках отвору (стандарт IPC Class 2: `25 мкм = 0.000025 м`).
- `r_int` — внутрішній радіус порожнини: `r_int = r_ext - t_plating = 0.15 мм - 0.025 мм = 0.125 мм`.

Площа поперечного перерізу мідної стінки одного отвору:

```
A_via_Cu = π · (r_ext² - r_int²)
A_via_Cu = 3.14159 · ((0.00015)² - (0.000125)²)
A_via_Cu = 3.14159 · (0.0000000225 - 0.000000015625)
A_via_Cu = 3.14159 · 0.000000006875 = 2.16 · 10⁻⁸ м² = 0.0216 мм²
```

Тепловий опір одного перехідного отвору:

```
R_th_1via = h / (k_Cu · A_via_Cu)
R_th_1via = 0.0016 / (385 · 2.16 · 10⁻⁸)
R_th_1via = 0.0016 / 8.316 · 10⁻⁶ ≈ 192.4 °C/Вт
```

Оскільки перехідні отвори під термопадом розміщуються паралельно у вигляді регулярної матриці (наприклад, 3×3 = 9 отворів або 4×4 = 16 отворів з кроком 1.0–1.2 мм), їхній сумарний тепловий опір зменшується пропорційно кількості отворів `N`:

```
R_th_vias = R_th_1via / N
```

Для масиву з `N = 9` перехідних отворів:

```
R_th_vias_9 = 192.4 °C/Вт / 9 ≈ 21.4 °C/Вт
```

Для масиву з `N = 16` перехідних отворів:

```
R_th_vias_16 = 192.4 °C/Вт / 16 ≈ 12.0 °C/Вт
```

### Тепловідведення мідного полігону в повітря (R_th_SA)

Тепловий опір полігону друкованої плати площею `A_copper` (з урахуванням конвекції та теплового випромінювання для зовнішнього шару за відсутності примусового обдуву) емпірично описується співвідношенням для двостороннього розсіювання:

```
R_th_SA ≈ 1 / (h_eff · A_eff)
```

де `h_eff` — узагальнений коефіцієнт тепловіддачі у спокійному повітрі (`h_eff ≈ 10–15 Вт/(м²·К)`), а `A_eff` — ефективна площа мідного полігону.

На практиці для стандартної двошарової плати з товщиною міді 35 мкм (1 oz) результуючий тепловий опір полігону площею `A` (в см²) приблизно оцінюється як:

```
R_th_copper ≈ 55 / √(A_cm²)  [°C/Вт]
```

При збільшенні площі понад 15–20 см² ефективність подальшого нарощування міді різко падає через кінцеву теплопровідність самої тонкої мідної фольги (ефект насичення площі охолодження).

## Worked-приклад 1: Перегрів лінійного LDO-стабілізатора в автомобільному трекері

Розгляньмо реальний інженерний вузол:
- Пристрій живиться від бортової мережі автомобіля: `V_in = 12.0 В`.
- Вихідна напруга LDO: `V_out = 3.3 В`.
- Сумарний струм навантаження цифрової частини (МК + LTE-модем у режимі прийому): `I_out = 200 мА = 0.200 А`.
- Корпус мікросхеми: SOT-223 (з внутрішнім `R_th_JC = 15 °C/Вт`).
- Паспортний тепловий опір без виділеного полігону (на мінімальних контактних майданчиках): `R_th_JA_nom = 65 °C/Вт`.
- Температура всередині герметичного корпусу під панеллю авто влітку: `T_a = 55 °C`.
- Максимально допустима температура кристала за даташитом: `T_j_max = 125 °C`.

### Крок 1. Розрахунок теплової потужності розсіювання

```
P_loss = (V_in - V_out) · I_out
P_loss = (12.0 В - 3.3 В) · 0.200 А
P_loss = 8.7 В · 0.200 А = 1.74 Вт
```

### Крок 2. Розрахунок температури кристала без додаткового охолодження

```
T_j = T_a + P_loss · R_th_JA_nom
T_j = 55 °C + 1.74 Вт · 65 °C/Вт
T_j = 55 °C + 113.1 °C = 168.1 °C
```

### Крок 3. Висновок за базовим розрахунком

Кристал розігрівається до 168.1 °C, що на 43.1 °C перевищує абсолютний максимум `T_j_max = 125 °C`. Стабілізатор вимкнеться захистом через кілька секунд після ввімкнення модема.

### Крок 4. Розрахунок модифікації з мідним полігоном і масивом 3×3 Thermal Vias

Додаємо на платі:
1. Верхній мідний полігон під табом SOT-223 площею 4 см².
2. Масив із 9 перехідних отворів діаметром 0.3 мм (`R_th_vias ≈ 21.4 °C/Вт`).
3. Нижній суцільний земляний шар площею 16 см² (`R_th_copper ≈ 55 / √16 = 13.75 °C/Вт`).

Результуючий тепловий опір системи плати:

```
R_th_total = R_th_JC + R_th_solder + (R_th_vias || R_th_FR4) + R_th_copper
R_th_total ≈ 15.0 + 1.5 + 20.0 + 13.8 ≈ 50.3 °C/Вт
```

Перераховуємо температуру кристала:

```
T_j_mod = 55 °C + 1.74 Вт · 50.3 °C/Вт
T_j_mod = 55 °C + 87.5 °C = 142.5 °C
```

Навіть із великим мідним радіатором температура кристала становить 142.5 °C, що все ще перевищує надійну робочу межу 125 °C. Це доводить фундаментальне інженерне правило: **при перепаді напруги понад 5–6 В і струмах понад 100–150 мА лінійний стабілізатор є непридатним для використання в герметичних корпусах**.

## Worked-приклад 2: Заміна на синхронний імпульсний перетворювач (Buck DC-DC)

Замінюємо лінійний стабілізатор на інтегрований синхронний Buck-перетворювач з ККД `η = 90% = 0.90` у компактному корпусі QFN-16 (`R_th_JA = 45 °C/Вт`).

### Крок 1. Розрахунок вихідної та теплової потужності

```
P_out = V_out · I_out = 3.3 В · 0.200 А = 0.66 Вт
P_in  = P_out / η = 0.66 Вт / 0.90 = 0.733 Вт
P_loss_Buck = P_in - P_out = 0.733 Вт - 0.660 Вт = 0.0733 Вт ≈ 73.3 мВт
```

### Крок 2. Розрахунок температури кристала Buck-перетворювача

```
T_j_Buck = T_a + P_loss_Buck · R_th_JA
T_j_Buck = 55 °C + 0.0733 Вт · 45 °C/Вт
T_j_Buck = 55 °C + 3.3 °C = 58.3 °C
```

### Крок 3. Порівняльний аналіз

```
Перегрів кристала LDO:   ΔT_LDO  = 113.1 °C  (T_j = 168.1 °C → Аварія)
Перегрів кристала Buck:  ΔT_Buck = 3.3 °C    (T_j = 58.3 °C  → Безпечний запас 66.7 °C)
```

Зменшення теплових втрат у 23.7 раза (з 1.74 Вт до 0.073 Вт) повністю знімає теплову кризу пристрою, усуває потребу у важких зовнішніх радіаторах і забезпечує безвідмовну роботу електроніки в максимальному температурному діапазоні.
