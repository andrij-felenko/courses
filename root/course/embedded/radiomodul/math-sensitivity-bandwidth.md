# 🧮 Чутливість, тепловий шум і смуга пропускання

Коли інженер обирає радіомодуль для автономного датчика чи пульта керування, у таблиці характеристик першим впадає в око параметр чутливості: наприклад, «−112 dBm при 1.2 кбіт/с» або «−137 dBm для LoRa SF12 на 125 кГц». Якщо перевести ці децибели у фізичну потужність, виявиться, що приймач здатен виловити з ефіру сигнал потужністю у частки фемтовата (10⁻¹⁵ Вт) — напругу менше одного мікровольта на 50-омному вході антени. Звідки береться це граничне число, чому його не можна покращувати нескінченно простим підсиленням і чому за кожен децибел чутливості доводиться платити швидкістю передачі даних?

Відповідь лежить у фундаментальній термодинаміці: будь-який провідник при температурі вище абсолютного нуля генерує непереборний тепловий шум. Щоб виділити корисний сигнал, потужність цього сигналу на вході демодулятора має перевищувати шум на строго визначену величину. Розгляньмо математичний ланцюг від теплового руху електронів до підсумкової чутливості приймача.

## Тепловий шум Джонсона-Найквіста

Вільні електрони в будь-якому резистивному середовищі (включно з опором випромінювання антени та вхідними ланцюгами LNA) перебувають у постійному хаотичному тепловому русі. Цей рух створює випадкові флуктуації напруги, спектральна густина потужності яких у радіочастотному діапазоні є рівномірною («білий шум»).

Згідно з формулою Джонсона-Найквіста, потужність теплового шуму P_noise на виході узгодженого джерела залежить лише від абсолютної температури T та смуги пропускання вимірювального тракту B:

```
P_noise = k · T · B                                [формула теплового шуму]
де:
  k = 1.380649 · 10^(-23) Дж/К                     [стала Больцмана]
  T = 290 К                                        [стандартна кімнатна температура, 16.85 °C]
  B = смуга пропускання фільтра приймача, Гц
```

Обчислимо спектральну густину теплового шуму для одиничної смуги B = 1 Гц при кімнатній температурі T_0 = 290 К:

```
P_0 = (1.380649 · 10^(-23)) · 290 · 1              [потужність у ватах на 1 Гц смуги]
    = 4.00388 · 10^(-21) Вт                        [джоулі за секунду на герц]
    = 4.00388 · 10^(-18) мВт                       [переведення у мілівати]

P_0_dBm = 10 · log10(4.00388 · 10^(-18))           [логарифмічний перерахунок у dBm]
        = 10 · (-17.3975)                          [обчислення десяткового логарифма]
        ≈ -173.98 dBm/Hz                           [стандартна константа: -174 dBm/Hz]
```

Число **−174 dBm/Hz** — це фундаментальна нижня межа шуму за кімнатної температури. Жоден приймач у Всесвіті, працюючи за температури 290 К без кріогенного охолодження, не може мати рівень теплового шуму нижчий за −174 dBm у смузі 1 Гц.

Якщо смуга пропускання каналу розширюється, загальна інтегральна потужність шуму зростає пропорційно ширині смуги:

```
P_noise_dBm = -174 + 10 · log10(B)                 [шумове дно у смузі B герц, dBm]
```

Порахуймо шумове дно для типових смуг пропускання вбудованих радіомодулів:

```
Для смуги B = 10 кГц (вузькосмуговий FSK):
  P_noise = -174 + 10 · log10(10 000)
          = -174 + 40
          = -134 dBm                               [шумове дно в смузі 10 кГц]

Для смуги B = 125 кГц (стандартний канал LoRa):
  P_noise = -174 + 10 · log10(125 000)
          = -174 + 50.97
          ≈ -123.03 dBm                            [шумове дно в смузі 125 кГц]

Для смуги B = 2 МГц (BLE 2 Mbps / nRF24L01):
  P_noise = -174 + 10 · log10(2 000 000)
          = -174 + 63.01
          ≈ -110.99 dBm                            [шумове дно в смузі 2 МГц]
```

Кожне десятикратне розширення смуги пропускання фільтра приймача додає рівно +10 dB теплового шуму, піднімаючи шумове дно.

## Коефіцієнт шуму тракту та деградація сигналу

Ідеальний приймач підсилював би сигнал разом із тепловим шумом антени, не додаючи нічого свого. Реальні напівпровідникові транзистори малошумного підсилювача (LNA), змішувачів та АЦП самі генерують дробовий і тепловий шум.

Міру погіршення відношення сигнал/шум у приймальному тракті описує **коефіцієнт шуму (Noise Figure, NF)**:

```
NF = SNR_in_dB - SNR_out_dB                        [деградація SNR у децибелах]
де:
  SNR_in_dB  = відношення сигнал/шум на вході антени
  SNR_out_dB = відношення сигнал/шум на вході цифрового демодулятора
```

У сучасних інтегрованих CMOS-трансиверах (наприклад, SX1262 чи CC1101) інтегральний коефіцієнт шуму всього приймального тракту становить від 4 dB до 8 dB. Тобто реальне шумове дно на вході детектора зміщується вгору ще на 4..8 dB відносно теоретичного термодинамічного мінімуму.

```
P_floor = -174 dBm/Hz + 10 · log10(B) + NF          [реальне шумове дно приймача]
```

## Поріг демодуляції SNRmin і підсумкова чутливість

Щоб цифровий демодулятор зміг декодувати символи із заданою ймовірністю бітової помилки (Bit Error Rate, BER = 10⁻³, тобто не більше однієї помилки на 1000 переданих бітів), потужність сигналу повинна перевищувати реальне шумове дно на мінімальне співвідношення SNR_min:

```
S = P_floor + SNR_min                              [чутливість приймача, dBm]
  = -174 dBm/Hz + 10 · log10(B) + NF + SNR_min     [повна інженерна формула чутливості]
```

Для класичних некогерентних та когерентних модуляцій (FSK, GFSK, PSK) мінімальне відношення SNR_min для забезпечення BER = 10⁻³ є строго додатним:
- Некогерентний 2-FSK демодулятор: SNR_min ≈ +9..+11 dB;
- Оптимальний когерентний/квазікогерентний GFSK демодулятор із цифровим дискримінатором: SNR_min ≈ +5..+7 dB;
- BPSK / QPSK з кодами прямого виправлення помилок (FEC): SNR_min ≈ +2..+4 dB.

Розрахуємо теоретичну чутливість приймача 2-FSK при швидкості 1.2 кбіт/с (смуга приймального фільтра B = 5 кГц, NF = 6 dB, SNR_min = 6 dB):

```
S_FSK = -174 + 10 · log10(5000) + 6 + 6            [підстановка параметрів]
      = -174 + 36.99 + 6 + 6                       [обчислення складових]
      = -125.01 dBm                                [гранична чутливість]
```

У реальних даташитах трансивера CC1101 для швидкості 1.2 кбіт/с вказано чутливість від −112 dBm до −116 dBm. Різниця в 9..13 dB зумовлена запасом на нестабільність частоти кварцового генератора (через що смугу фільтра доводиться відкривати ширше, ніж теоретичні 5 кГц), втратами в балуні та неідеальністю АЦП.

## Як LoRa працює нижче рівня шуму: виграш від розширення спектра

У даташитах модулів LoRa (SX1262, SX1276) наведено значення чутливості до −137 dBm чи навіть −148 dBm. Звідки береться така цифра, якщо при смузі B = 125 кГц і NF = 6 dB реальне шумове дно дорівнює −123 + 6 = −117 dBm? Чутливість −137 dBm лежить на 20 dB **нижче** теплового шуму.

Це стає можливим завдяки модуляції з лінійно-частотною маніпуляцією (Chirp Spread Spectrum, CSS) та когерентному накопиченню енергії чірпа.

У LoRa символ кодується у вигляді одного частотного чирпа, тривалість якого T_sym залежить від коефіцієнта розширення (Spreading Factor, SF від 5 до 12) та ширини смуги BW:

```
N_chips = 2^SF                                     [кількість чіпів на один символ]
T_sym   = (2^SF) / BW                              [тривалість символу, секунд]
R_sym   = BW / (2^SF)                              [символьна швидкість, бод]
R_bit   = SF · (BW / (2^SF)) · CR                  [бітова швидкість з урахуванням коду CR]
```

Під час прийому сигнал множиться на опорний спадний чірп (дечірпінг). Уся енергія корисного сигналу, розмазана за часом T_sym у смузі BW, згортається в один спектральний пік на виході БПФ (Швидкого перетворення Фур'є). Водночас нескорельований тепловий шум залишається рівномірно розподіленим по всіх 2^SF спектральних бінах.

Виграш від обробки (Processing Gain, PG) становить:

```
PG = 10 · log10(N_chips)
   = 10 · log10(2^SF)                              [виграш від розширення спектра, dB]
   ≈ SF · 3.01                                     [кожен крок SF додає ~3 dB]
```

Завдяки цьому піковий рівень енергії після БПФ зростає на величину PG, що дозволяє демодулятору детектувати пік навіть тоді, коли середня потужність вхідного радіосигналу значно менша за інтегральний шум у смузі BW.

Мінімально допустиме співвідношення сигнал/шум SNR_min для демодуляції LoRa стає від'ємним і залежить від SF:

```
SF = 7:   SNR_min ≈ -7.5 dB                        [поріг детектування для SF7]
SF = 8:   SNR_min ≈ -10.0 dB                       [поріг детектування для SF8]
SF = 9:   SNR_min ≈ -12.5 dB                       [поріг детектування для SF9]
SF = 10:  SNR_min ≈ -15.0 dB                       [поріг детектування для SF10]
SF = 11:  SNR_min ≈ -17.5 dB                       [поріг детектування для SF11]
SF = 12:  SNR_min ≈ -20.0 dB                       [поріг детектування для SF12]
```

Розрахуємо теоретичну чутливість приймача LoRa для смуги BW = 125 кГц, NF = 6 dB при SF = 12:

```
S_LoRa = -174 + 10 · log10(125 000) + NF + SNR_min [формула чутливості LoRa]
       = -174 + 50.97 + 6 + (-20.0)                [підстановка параметрів для SF12]
       = -137.03 dBm                               [теоретична чутливість]
```

Ці розрахункові −137 dBm в точності збігаються з табличними даними даташиту SX1262 для режиму SF12 / 125 кГц.

## Плата за чутливість: межа Шеннона-Гартлі

Збільшення чутливості не є безкоштовним: воно прямо вимагає уповільнення передачі інформації. Зв'язок між граничною пропускною здатністю каналу C (біт/с), смугою B (Гц) та відношенням потужності сигналу до шуму S/N задається теоремою Шеннона-Гартлі:

```
C = B · log2(1 + S / N)                            [теоретична ємність каналу зв'язку]
```

Коли потужність сигналу набагато менша за потужність шуму (S/N << 1), застосовуємо наближення ln(1 + x) ≈ x:

```
C ≈ B · (S / N) / ln(2)                            [гранична швидкість при глибокому шумі]
  ≈ 1.4427 · (S / N) · B                           [лінійна залежність від енергії сигналу]
```

Звідси видно: якщо ми зменшуємо потужність сигналу S на вході приймача (працюємо на більшій відстані з гіршим відношенням S/N), то для передачі того самого обсягу інформації нам фізично необхідно збільшувати час передачі кожного біта (зменшувати бітову швидкість R).

Порівняємо часові параметри передачі корисного пакета розміром 32 байти (256 біт) для двох радіосистем:

```
1. Трансивер 2.4 GHz nRF24L01 (2 Mbps GFSK):
   Чутливість: S ≈ -85 dBm
   Час передачі пакета:
     t_air = 256 біт / 2 000 000 біт/с = 128 мкс
   Енергія при струмі Tx 12 мА (3.3 В):
     E = 3.3 В · 0.012 А · 0.000128 с = 5.07 мкДж

2. Трансивер Sub-GHz LoRa SX1262 (SF12, BW 125 kHz, CR 4/5):
   Чутливість: S ≈ -137 dBm  (на 52 dB чутливіший, дальність у 20-50 разів більша)
   Бітова швидкість:
     R_bit = 12 · (125 000 / 4096) · (4 / 5) ≈ 293 біт/с
   Час передачі пакета:
     t_air = 256 біт / 293 біт/с ≈ 0.874 с = 874 мс
   Енергія при струмі Tx 120 мА (+22 dBm, 3.3 В):
     E = 3.3 В · 0.120 А · 0.874 с ≈ 346.1 мДж
```

Збільшення чутливості на 52 dB розширило радіус дії у десятки разів, але тривалість перебування в ефірі зросла у 6800 разів, а споживання енергії на один пакет — майже у 70 000 разів.

Розуміння балансу між смугою пропускання B, коефіцієнтом шуму NF, відношенням SNR_min та тривалістю пакета в ефірі дає інженеру точний критерій вибору конфігурації радіотракту під енергетичні та часові обмеження вбудованого пристрою.
