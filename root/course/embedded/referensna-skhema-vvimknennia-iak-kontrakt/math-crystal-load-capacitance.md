# 🧮 Розрахунок навантажувальних конденсаторів та демпфування кварцового резонатора

Цей математичний аналіз виводить точні формули для узгодження п'єзоелектричного кварцового резонатора з інверторним генератором Пірса в мікроконтролерах. Розрахунок дозволяє визначити номінали зовнішніх навантажувальних конденсаторів, оцінити зсув резонансної частоти від паразитної ємності плати, обмежити потужність збудження демпфуючим резистором і перевірити коефіцієнт запасу збудження коливань.

## 1. Еквівалентна електрична схема кварцового резонатора (модель BVD)

Кварцовий резонатор є електромеханічною коливальною системою, яка у вузькому діапазоні частот поблизу резонансу описується зосередженими параметрами моделі Баттерворта — Ван Дайка (англ. *Butterworth–Van Dyke*, BVD):

```
       ┌────── Lm ─────── Rm ─────── Cm ──────┐
───o───┤   (динамічна  (втрати  (динамічна   ├───o───
       │  індуктивність) п'єзо)   ємність)   │
       └────────────────── C0 ────────────────┘
                     (статична ємність)
```

де:
- `Lm` — динамічна (модальна) індуктивність, що моделює коливну масу кристала (одиниці або десятки Генрі);
- `Cm` — динамічна ємність, що визначається механічною пружністю кварцової пластини (частки фемтофарада: `10⁻¹⁵ Ф`);
- `Rm` — динамічний опір втрат (еквівалентний послідовний опір, ESR), що відображає внутрішнє механічне тертя кристала (типово `20–80 Ом` для HSE та `30–70 кОм` для годинникових резонаторів 32.768 кГц);
- `C0` — статична шунтуюча ємність, утворена металевими електродами на гранях пластини та виводами корпусу (типово `1–5 пФ`).

Комплексний імпеданс резонатора має дві характеристичні частоти: частоту послідовного резонансу `f_s` (де реактивний опір гілки `Lm-Cm` дорівнює нулю) та частоту паралельного (антирезонансу) `f_a`:

```
f_s = 1 / (2 · π · √(Lm · Cm))             [послідовний резонанс гілки]
f_a = f_s · √(1 + Cm / C0)                 [паралельний антирезонанс]
```

Генератор Пірса збуджує резонатор в індуктивній ділянці між `f_s` та `f_a`, де резонатор діє як високодобротна котушка індуктивності, що формує разом із зовнішнім навантаженням `C_L` паралельний коливальний контур на робочій частоті `f_L`:

```
f_L = f_s · √(1 + Cm / (2 · (C0 + C_L)))   [робоча частота під навантаженням]
```

## 2. Виведення формули зовнішніх навантажувальних конденсаторів

Паспортна навантажувальна ємність кварцу `C_L` (англ. *Load Capacitance*) — це еквівалентна ємність усього зовнішнього кола, яку резонатор повинен «бачити» між своїми виводами `OSC_IN` та `OSC_OUT` для генерації точної номінальної частоти.

Зовнішнє коло складається з двох дискретних конденсаторів `C_L1` та `C_L2`, з'єднаних послідовно через спільну земляну площину, а також розподіленої паразитної ємності монтажу `C_stray`:

```
C_L = (C_L1 · C_L2) / (C_L1 + C_L2) + C_stray   [еквівалентна ємність навантаження]
```

Паразитна ємність `C_stray` складається з:
- Вхідної та вихідної ємності виводів мікроконтролера `C_pin_in` та `C_pin_out` (типово `2–4 пФ` на вивід);
- Паразитної ємності друкованих доріжок та контактних майданчиків відносно внутрішніх шарів землі `C_pcb` (типово `1–2 пФ` при правильному компактному трасуванні).
Сумарна величина `C_stray` для типової 2- чи 4-шарової плати становить `3–6 пФ`.

Для симетричної схеми, де номінали обох конденсаторів обираються однаковими (`C_L1 = C_L2 = C_e`):

```
C_L = (C_e · C_e) / (C_e + C_e) + C_stray       [підстановка рівних ємностей]
    = C_e² / (2 · C_e) + C_stray                 [скорочення на C_e]
    = C_e / 2 + C_stray                          [послідовне з'єднання двох однакових C]
```

Виразимо необхідний номінал зовнішнього конденсатора `C_e`:

```
C_e / 2 = C_L − C_stray                          [перенесення C_stray ліворуч]
C_e     = 2 · (C_L − C_stray)                    [множення обох частин на 2]
```

**Worked-приклад 1. Розрахунок конденсаторів для кварцу 16 МГц.**

```
Вихідні дані:
   Паспортна навантажувальна ємність кварцу: C_L = 12.0 пФ
   Виміряна/оцінена паразитна ємність плати: C_stray = 4.0 пФ

Розрахунок номіналу зовнішніх конденсаторів:
   C_e = 2 · (12.0 пФ − 4.0 пФ)
   C_e = 2 · 8.0 пФ = 16.0 пФ

Вибір стандартного номіналу:
   Обираємо керамічні конденсатори 16 пФ або 15 пФ / 18 пФ (ряд E24, діелектрик NP0/C0G, ±5%).
```

## 3. Чутливість частоти до похибки ємності (тяговий коефіцієнт)

Якщо номінали конденсаторів обрано неточно або паразитна ємність плати відрізняється від розрахункової, робоча частота генератора `f_L` зміщується відносно номіналу.

Знайдемо диференціал робочої частоти за навантажувальною ємністю:

```
df_L / dC_L = d/dC_L [ f_s · (1 + Cm / (2 · (C0 + C_L)))^(1/2) ]
            ≈ f_s · (1/2) · (Cm / (2 · (C0 + C_L))) · (-1 / (C0 + C_L))   [лінеаризація для Cm << C0]
            ≈ -f_s · Cm / (2 · (C0 + C_L)²)                               [диференційна чутливість]
```

Відносне зміщення частоти `Δf / f` (в одиницях ppm, лат. *partes per millionem* — часток на мільйон, `10⁻⁶`) при зміні навантажувальної ємності на `ΔC_L`:

```
Δf / f ≈ - (Cm / (2 · (C0 + C_L)²)) · ΔC_L       [відхилення частоти від похибки ємності]
```

Коефіцієнт підтягування (англ. *Pullability*) `S` показує, на скільки ppm зміститься частота при зміні навантаження на 1 пФ:

```
S = (Cm · 10⁶) / (2 · (C0 + C_L)²)   [ppm / пФ]
```

**Worked-приклад 2. Оцінка похибки частоти від паразитної ємності.**

```
Параметри кварцу:
   Cm = 3.0 фФ = 3.0 · 10⁻¹⁵ Ф
   C0 = 2.0 пФ = 2.0 · 10⁻¹² Ф
   C_L = 12.0 пФ = 12.0 · 10⁻¹² Ф

Обчислення чутливості:
   S = (3.0 · 10⁻¹⁵ · 10⁶) / (2 · (2.0 · 10⁻¹² + 12.0 · 10⁻¹²)²)
   S = 3.0 · 10⁻⁹ / (2 · (14.0 · 10⁻¹²)²)
   S = 3.0 · 10⁻⁹ / (2 · 1.96 · 10⁻²²)
   S = 3.0 · 10⁻⁹ / 3.92 · 10⁻²² ≈ 7.65 ppm / пФ

Якщо паразитна ємність плати недооцінена на ΔC_stray = +2 пФ:
   Похибка частоти: Δf/f = -7.65 ppm/пФ · 2 пФ = -15.3 ppm.
   Для тактової частоти 16 МГц абсолютне відхилення становить:
   Δf = 16 · 10⁶ Гц · (-15.3 · 10⁻⁶) = -244.8 Гц.
```

## 4. Розрахунок потужності збудження кристала (Drive Level)

Потужність збудження `DL` (англ. *Drive Level*) — це електрична потужність, яка розсіюється на внутрішньому механічному опорі втрат `ESR` резонатора.

Перевищення паспортного ліміту `DL_max` (зазвичай `50–200 мкВт` для малогабаритних SMD-кварців) призводить до нелінійних механічних деформацій п'єзокристала, прискореного старіння і навіть фізичного руйнування кристалічної пластини.

Потужність визначається середньоквадратичним струмом `I_RMS`, що протікає крізь резонатор:

```
DL = I_RMS² · ESR                                [потужність на опорі втрат]
```

При гармонійних коливаннях пікова напруга на конденсаторі навантаження `C_L2` з боку виходу інвертора становить `V_pp / 2`. Тоді амплітуда струму через кварц наближено дорівнює:

```
I_peak ≈ 2 · π · f · C_L2 · (V_pp / 2)           [піковий струм заряду навантаження]
I_RMS  = I_peak / √2                             [перехід до середньоквадратичного струму]
I_RMS  = (π · f · C_L2 · V_pp) / √2              [вираз через розмах напруги]
```

Підставляючи `I_RMS` у формулу потужності:

```
DL = [ (π · f · C_L2 · V_pp) / √2 ]² · ESR       [підстановка струму]
   = (1/2) · (π · f · C_L2 · V_pp)² · ESR        [потужність збудження резонатора]
```

де `V_pp` — повний розмах напруги на виводі `OSC_OUT` (вимірюється осцилографом із малоємнісним активним щупом, типово `0.8 · VDD` до `VDD`).

## 5. Розрахунок демпфуючого резистора Rd

Якщо розрахована потужність `DL` перевищує паспортний ліміт виробника `DL_max`, послідовно між виходом внутрішнього інвертора `OSC_OUT` та конденсатором `C_L2` встановлюють струмообмежувальний (демпфуючий) резистор `Rd`.

Резистор `Rd` виконує дві критичні функції:
1. Знижує амплітуду струму збудження через кварц, захищаючи його від перевантаження;
2. Створює разом із конденсатором `C_L2` додатковий фільтр низьких частот, що пригнічує паразитне збудження генератора на вищих обертонах (негармонійних модах).

Орієнтовне значення `Rd` для забезпечення фазового зсуву та демпфування:

```
Rd ≈ 1 / (2 · π · f · C_L2)                      [реактивний опір вихідного навантаження]
```

Після додавання `Rd` сумарний еквівалентний опір втрат у колі зростає до величини:

```
ESR_total = ESR + Rd · (C_L2 / (C_L1 + C_L2))²   [еквівалентний опір з урахуванням Rd]
```

**Worked-приклад 3. Розрахунок демпфуючого резистора.**

```
Параметри кола:
   Частота: f = 16.0 МГц = 16.0 · 10⁶ Гц
   Конденсатор навантаження: C_L2 = 18 пФ = 18.0 · 10⁻¹² Ф
   Розмах вихідного сигналу інвертора: V_pp = 3.0 В
   ESR кварцу: ESR = 40 Ом
   Максимально допустима потужність: DL_max = 100 мкВт = 1.0 · 10⁻⁴ Вт

1. Розрахунок потужності БЕЗ резистора Rd:
   DL = 0.5 · (π · 16.0 · 10⁶ · 18.0 · 10⁻¹² · 3.0)² · 40
   DL = 0.5 · (2.714 · 10⁻³)² · 40
   DL = 0.5 · 7.368 · 10⁻⁶ · 40 = 1.474 · 10⁻⁴ Вт = 147.4 мкВт

   Оскільки 147.4 мкВт > 100 мкВт, кристал перевантажений на 47 %!

2. Оцінка номіналу демпфуючого резистора Rd:
   Rd ≈ 1 / (2 · π · 16.0 · 10⁶ · 18.0 · 10⁻¹²)
   Rd ≈ 1 / (1.810 · 10⁻³) ≈ 552.6 Ом

   Обираємо стандартний резистор Rd = 470 Ом або 510 Ом.
   Після встановлення Rd струм I_RMS зменшується приблизно в 1.4 раза, а потужність DL падає нижче 75 мкВт.
```

## 6. Критерій надійного запуску генератора (Gain Margin)

Внутрішній інвертор мікроконтролера характеризується транскондуктансом (крутизною передавальної характеристики) `g_m` (вимірюється в мА/В або А/В).

Для виникнення та стійкого підтримання коливань відповідно до критерію Баркгаузена крутизна `g_m` повинна перевищувати критичне значення `g_mcrit`, за якого втрати в контурі повністю компенсуються підсилювачем:

```
g_mcrit = 4 · π² · f² · ESR_total · (C0 + C_L)²   [критична крутизна інвертора]
```

Для гарантованого, швидкого та надійного запуску генератора в усьому діапазоні робочих температур (від `-40 °C` до `+85 °C / +125 °C`), при коливаннях напруги живлення та з урахуванням старіння компонентів інженерний стандарт вимагає запасу підсилення (англ. *Gain Margin* або *Oscillation Allowance*):

```
Gain Margin = g_m / g_mcrit                       [коефіцієнт запасу підсилення]
```

Норми запасу підсилення:
- `Gain Margin < 1` — генератор фізично не запуститься (зрив генерації);
- `1 ≤ Gain Margin < 5` — ненадійний запуск: генератор може запуститися на тестовому столі за кімнатної температури, але відмовляє при охолодженні до `-20 °C` або просіданні живлення;
- `Gain Margin ≥ 5` — надійний промисловий запуск (золотий стандарт проектування вбудованих систем);
- `Gain Margin > 20` — надлишкове підсилення, можлива генерація на вищих гармоніках або перевантаження кристала (вимагає збільшення `Rd`).

**Worked-приклад 4. Перевірка запасу підсилення для STM32.**

```
Параметри мікроконтролера та кварцу:
   Крутизна інвертора STM32 (HSE medium-high drive): g_m = 10.0 мА/В = 10.0 · 10⁻³ А/В
   Частота: f = 16.0 МГц = 16.0 · 10⁶ Гц
   Сумарний опір з Rd: ESR_total = 80 Ом
   C0 = 2.0 пФ, C_L = 12.0 пФ  =>  (C0 + C_L) = 14.0 пФ = 14.0 · 10⁻¹² Ф

Розрахунок g_mcrit:
   g_mcrit = 4 · π² · (16.0 · 10⁶)² · 80 · (14.0 · 10⁻¹²)²
   g_mcrit = 4 · 9.8696 · 2.56 · 10¹⁴ · 80 · 1.96 · 10⁻²²
   g_mcrit = 1.0106 · 10¹⁶ · 80 · 1.96 · 10⁻²²
   g_mcrit = 1.585 · 10⁻⁴ А/В = 0.1585 мА/В

Розрахунок запасу Gain Margin:
   Gain Margin = g_m / g_mcrit
   Gain Margin = 10.0 мА/В / 0.1585 мА/В ≈ 63.1

Висновок:
   Запас Gain Margin = 63.1 >> 5. Контур гарантовано та надійно запускається за будь-яких температурних умов.
```
