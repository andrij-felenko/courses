# 🧮 Математична модель витоків струму та деградації батареї

Під час проектування автономного пристрою інженер стикається з парадоксом: розрахунок середнього споживання за паспортом компонентів обіцяє роки безперервної роботи, проте натурні випробування показують розряд батареї за лічені тижні. Причина криється у фізичній природі паразитних струмів, які не підкоряються лінійним законам і експоненційно зростають під впливом температури, плаваючих потенціалів напівпровідникових затворів та опору діелектриків.

Цей математичний апарат дає кількісну оцінку чотирьох головних джерел втрат: наскрізного струму пари КМОН-інвертора при проміжній напрузі, температурного дрейфу зворотного струму бар'єрів Шотткі, витоків діелектриків конденсаторів та інтегрального впливу паразитного фону на ефективну ємність літієвого джерела струму за законом Пейкерта.

## Модель наскрізного струму КМОН-інвертора при плаваючому вході

Цифровий вхідний буфер мікроконтролера складається з комплементарної пари польових транзисторів: верхнього p-канального (PMOS) та нижнього n-канального (NMOS). Коли вивід залишається непідключеним (floating), наведені електромагнітні поля та поверхневі витоки плати встановлюють на ньому потенціал, близький до половини напруги живлення.

У стані насичення струм стоку польового транзистора описується квадратичною моделлю Шіхмана-Ходжеса. Для напруги живлення V_DD та вхідної напруги V_in напруги затвор-витік становлять:

```text
V_GS_n = V_in                     [напруга затвор-витік для NMOS]
V_GS_p = V_in - V_DD              [напруга затвор-витік для PMOS]
```

Обидва транзистори одночасно переходять у провідний стан, коли абсолютна напруга перевищує їхні порогові значення:

```text
V_in > V_th_n                     [умова відкриття NMOS]
V_DD - V_in > |V_th_p|            [умова відкриття PMOS]
```

Якщо обидва транзистори працюють в області насичення (що відбувається у вузькому діапазоні довкола V_DD / 2), наскрізний струм короткого замикання (crowbar current) виражається через питомі крутизни k_n та k_p:

```text
k_n = mu_n * C_ox * (W_n / L_n)   [фактор крутизни NMOS]
k_p = mu_p * C_ox * (W_p / L_p)   [фактор крутизни PMOS]
```

За умови симетричного інвертора (k_n = k_p = k) та однакових порогових напруг (V_th_n = |V_th_p| = V_th), струм досягає абсолютного максимуму при V_in = V_DD / 2:

```text
I_crowbar_peak = (k / 2) * (V_DD / 2 - V_th)^2   [піковий наскрізний струм]
```

Для типового сучасного мікроконтролера з технологічним процесом 90 нм та живленням 3.3 В підставимо типові фізичні параметри:

```text
V_DD = 3.3 В                      [напруга живлення]
V_th = 0.65 В                     [порогова напруга затвора]
k    = 420 мкА / В^2              [фактор крутизни каналу]

I_crowbar_peak = (420 / 2) * (1.65 - 0.65)^2
               = 210 * (1.0)^2
               = 210 мкА          [струм одного плаваючого піна]
```

Якщо плаваючий потенціал здійснює випадкові коливання довкола середньої точки під впливом мережевої наводки 50 Гц або цифрового шуму з амплітудою V_m:

```text
V_in(t) = V_DD / 2 + V_m * sin(omega * t)
```

Середній струм витоку за період визначається інтегруванням миттєвого значення:

```text
I_crowbar_avg = (1 / T) * integral[0..T] I_crowbar(V_in(t)) dt
```

Розклавши функцію струму в ряд Тейлора довкола робочої точки V_DD / 2, отримуємо аналітичний вираз для середнього струму:

```text
I_crowbar_avg = I_crowbar_peak - (k / 4) * V_m^2
```

Навіть при значних флуктуаціях напруги середній струм через один плаваючий цифровий буфер складає від 150 до 350 мкА. При наявності 8 невживаних виводів сумарний паразитний струм мікроконтролера сягає:

```text
I_total_crowbar = 8 * 210 мкА = 1680 мкА = 1.68 мА
```

Це перевищує власний струм глибокого сну ядра (2–5 мкА) майже на три порядки.

## Температурний дрейф зворотного струму діода Шотткі

Діоди Шотткі широко застосовуються в схемах комутації живлення (Power OR-ing) та захисту від зворотної полярності завдяки низькому прямому спаду напруги. Проте зворотний струм бар'єра Шотткі формується переважно механізмом термоемісії електронів над потенційним бар'єром Ф_B і описується рівнянням Річардсона:

```text
I_R(T, V_R) = A * A_star * T^2 * exp(-q * Phi_B / (k_B * T)) * exp(q * sqrt(q * E / (4 * pi * epsilon_s)) / (k_B * T))
```

де A — площа переходу, A_star — модифікована стала Річардсона, q — елементарний заряд, k_B — стала Больцмана, T — абсолютна температура в Кельвінах, E — напруженість електричного поля на переході при зворотній напрузі V_R.

Для практичних інженерних розрахунків у робочому температурному діапазоні від -40 °C до +85 °C експоненційну залежність спрощують до емпіричного правила подвоєння струму на кожні 10 Кельвінів приросту температури:

```text
I_R(T) = I_R(T_0) * 2^((T - T_0) / 10)
```

де T_0 = 25 °C (298.15 K) — нормальна температура градуювання за паспортом.

Розглянемо популярний діод Шотткі на 1 А (наприклад, SS14 або B140), який використовується для захисту від переполюсовки батареї:

```text
I_R(25 °C) = 1.5 мкА              [паспортне значення при 25 °C]
T_1        = 50 °C                [робота в корпусі на сонці]
T_2        = 85 °C                [максимальна робоча температура]
```

Розрахунок витоку при підвищенні температури:

```text
I_R(50 °C) = 1.5 * 2^((50 - 25) / 10)
           = 1.5 * 2^(2.5)
           = 1.5 * 5.657
           = 8.48 мкА             [при 50 °C]

I_R(85 °C) = 1.5 * 2^((85 - 25) / 10)
           = 1.5 * 2^6
           = 1.5 * 64
           = 96.0 мкА             [при 85 °C]
```

Зворотний витік діода зростає з 1.5 мкА до майже 100 мкА. Якщо схема містить захисний діод на вході живлення та діод розв'язки сонячної панелі, при високій температурі ці компоненти стають домінуючим споживачем енергії.

## Опір ізоляції та струм витоку конденсаторів

Керамічні багатошарові конденсатори (MLCC) і танталові конденсатори утворюють фільтруючу ємність шини живлення. Струм витоку конденсатора визначається його опором ізоляції R_ins:

```text
I_leak_cap = V_oper / R_ins       [закон Ома для діелектрика]
```

Виробники MLCC нормують опір ізоляції через добуток опору на ємність (параметр R_ins * C, вимірюється в МОм * мкФ або секундах):

```text
R_ins = (R_ins * C)_spec / C      [опір ізоляції ємності C]
```

Порівняємо три класи конденсаторів ємністю 47 мкФ при робочій напрузі 3.3 В:

```text
1. Кераміка Класу 1 (C0G/NP0):
   (R_ins * C)_spec = 10000 МОм * мкФ (при 25 °C)
   R_ins = 10000 / 47 = 212.8 МОм
   I_leak = 3.3 В / 212.8 МОм = 0.0155 мкА = 15.5 нА

2. Кераміка Класу 2 (X7R / X5R):
   (R_ins * C)_spec = 500 МОм * мкФ (при 25 °C)
   R_ins = 500 / 47 = 10.64 МОм
   I_leak(25 °C) = 3.3 В / 10.64 МОм = 0.31 мкА

   При нагріванні до 85 °C опір діелектрика X7R падає на порядок:
   (R_ins * C)_85C = 50 МОм * мкФ
   R_ins(85 °C) = 50 / 47 = 1.064 МОм
   I_leak(85 °C) = 3.3 В / 1.064 МОм = 3.10 мкА

3. Танталовий конденсатор (MnO2 / полімер):
   Паспортний витік нормується формулою I_leak = 0.01 * C * V:
   I_leak_tant = 0.01 * 47 * 3.3 = 1.551 мкА (при 25 °C)
   I_leak_tant(85 °C) ≈ 10 * I_leak_tant(25 °C) = 15.5 мкА
```

Сумарна фільтруюча батарея з трьох паралельних конденсаторів X5R по 47 мкФ на платі при температурі 60 °C створює постійний струм витоку близько 5–8 мкА виключно через діелектрик.

## Інтегральна модель розряду хімічного джерела за законом Пейкерта

Автономний вузол працює циклічно: короткий спалах активності тривалістю t_act зі струмом I_act та тривала пауза сну тривалістю t_sleep зі струмом I_sleep. Робочий період та шпаруватість:

```text
T_period = t_act + t_sleep
D = t_act / T_period
```

Середній струм споживання розраховується як зважена сума:

```text
I_avg = I_act * (t_act / T_period) + I_sleep * (t_sleep / T_period)
```

Ємність хімічного джерела струму C_bat (наприклад, дискової літій-діоксидмарганцевої батареї CR2032 з номіналом C_nom = 220 мА·год) не є абсолютною константою. Закон Пейкерта описує зменшення ефективної ємності C_eff при збільшенні струму навантаження I:

```text
t_discharge = C_nom / (I^k_p)     [закон Пейкерта]
```

де k_p — коефіцієнт Пейкерта (для літієвих елементів CR2032 становить k_p ≈ 1.08...1.15).

Проте головною загрозою для малопотужних джерел є внутрішній саморозряд батареї (self-discharge rate, SDR ≈ 1% на рік для Li-MnO2) у поєднанні з постійним фоновим витоком.

Розглянемо чисельний приклад сенсора з наступним профілем:

```text
C_nom   = 220 мА·год = 220 000 мкА·год  [батарея CR2032]
I_act   = 25 000 мкА                    [активний радіотракт 25 мА]
t_act   = 40 мс = 0.040 с               [час вимірювання та передачі]
T_period= 60 с                          [період опитування 1 раз на хвилину]
```

Розрахуємо внесок активної фази у середній струм:

```text
I_act_avg = 25000 * (0.040 / 60)
          = 25000 * 0.000667
          = 16.67 мкА             [середній активний струм]
```

Порівняємо два сценарії стану сну:

### Сценарій А: Ідеальний стан плати (без витоків)

Усі виводи переведені в режим Analog, периферія знеструмлена, налагоджувач відключений:

```text
I_sleep_clean = 3.5 мкА           [чистий струм мікроконтролера та LDO]
I_avg_A       = 16.67 + 3.5 = 20.17 мкА

Час життя:
T_life_A = C_nom / I_avg_A
         = 220000 мкА·год / 20.17 мкА
         = 10907 годин
         = 454.4 днів ≈ 1.25 року
```

Якщо інтервал опитування збільшити до 10 хвилин (T_period = 600 с):

```text
I_act_avg_10m = 25000 * (0.040 / 600) = 1.67 мкА
I_avg_A_10m   = 1.67 + 3.5 = 5.17 мкА
T_life_A_10m  = 220000 / 5.17 = 42553 годин ≈ 4.86 року
```

### Сценарій Б: Плата з типовими паразитними витоками

1) Два плаваючих входи GPIO: 2 * 180 мкА = 360 мкА
2) Зворотне живлення вимкненого датчика через підтяжку I2C: 120 мкА
3) Витік діода Шотткі при 45 °C: 15 мкА

```text
I_leak_total  = 360 + 120 + 15 = 495 мкА
I_sleep_leak  = 3.5 + 495 = 498.5 мкА
I_avg_B       = 16.67 + 498.5 = 515.17 мкА

Час життя:
T_life_B = C_nom / I_avg_B
         = 220000 мкА·год / 515.17 мкА
         = 427 годин
         = 17.8 днів
```

При 10-хвилинному інтервалі:

```text
I_avg_B_10m  = 1.67 + 498.5 = 500.17 мкА
T_life_B_10m = 220000 / 500.17 = 439.8 годин ≈ 18.3 днів
```

## Висновок з математичного аналізу

При наявності нескомпенсованого паразитного витоку збільшення періоду сну пристрою практично не впливає на загальний час автономності: при переході від 1 хвилини до 10 хвилин життя батареї зростає лише з 17.8 до 18.3 днів, оскільки 99.7% енергії витрачається на підтримку наскрізних струмів у напівпровідниках та резисторах.

Лише усунення статичних паразитів повертає пристрій на теоретичну експоненту автономності, де оптимізація прошивки забезпечує кратне подовження ресурсу джерела живлення.
