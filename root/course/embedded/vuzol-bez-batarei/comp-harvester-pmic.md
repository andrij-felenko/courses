# 🔌 Спеціалізовані мікросхеми керування живленням (EH PMIC)

Звичайні лінійні стабілізатори (LDO) та імпульсні перетворювачі постійного струму (DC-DC) розраховані на роботу від джерел із низьким внутрішнім опором і струмами від міліамперів до амперів. Під час підключення до збирачів енергії довкілля (фотоелементів, термоелектрогенераторів, п'єзоперетворювачів) звичайна мікросхема споживає у власному стані спокою більше струму, ніж джерело здатне згенерувати, а падіння напруги на випрямлячах і кремнієвих переходах блокує старт системи з нуля. Спеціалізовані мікросхеми збору енергії (англ. *Energy Harvesting Power Management IC*, EH PMIC) вирішують цю проблему завдяки інтеграції трьох фундаментальних підсистем: схеми ультранизьковольтного холодного старту, динамічного модуля відстеження точки максимальної потужності (MPPT) та гістерезисного комутатора силового тракту з власним струмом спокою у сотні наноамперів.

## Анатомія та функціональні вузли спеціалізованого PMIC

Архітектура мікросхеми збору енергії кардинально відрізняється від класичних стабілізаторів наявністю розділених кіл керування енергетичними потоками та автономної системи самозапуску.

```
       +-------------------------------------------------------------------+
       |                            EH PMIC                                |
       |                                                                   |
       |  +--------------+       +------------------+     +-------------+  |
IN --->|  Холодний старт |--->---|  Головний Boost  |---->| V_STOR      |  |
       |  (Charge Pump)  |       |  (MPPT Регулятор)|     | (Накопичувач|  |
       +-------+---------+       +--------+---------+     +------+------+  |
               |                          |                      |         |
               |                 +--------+---------+            |         |
               |                 | MPPT Вибірка     |            |         |
               |                 | (FOCV 50%/80%)   |            |         |
               |                 +------------------+            |         |
               |                                                 |         |
               |                 +------------------+     +------+------+  |
               +-----------------| Гістерезисний    |---->| Силовий     |  |
                                 | супервізор напруг|     | ключ VOUT   |  |
                                 +------------------+     +------+------+  |
                                                                 |         |
       +---------------------------------------------------------+---------+
                                                                 |
                                                                 v
                                                      VOUT (До навантаження)
```

### 1. Тракт холодного старту (Cold Start Circuit)

Коли буферний накопичувач повністю розряджений (`V_STOR = 0 В`), головний цифровий та аналоговий контролер PMIC знеструмлений, а польові транзистори з ізольованим затвором (MOSFET) закриті через брак напруги відмикання затвора.

Для подолання цієї мертвої зони PMIC використовує один із двох апаратних підходів:
1. **Інтегрована діодно-ємнісна зарядна помпа (Charge Pump):** застосовується в мікросхемах сонячного живлення (наприклад, TI BQ25570, e-peas AEM10941). Вона починає коливання при вхідній напрузі від 330–380 мВ і некеровано перекачує мікроструми в накопичувач, поки напруга на `V_STOR` не досягне порога ввімкнення основної логіки (зазвичай 1.5–1.8 В).
2. **Трансформаторний автогенератор Мейснера на збідненому польовому транзисторі (Depletion-mode JFET):** застосовується для термоелектрогенераторів Зеєбека (наприклад, Analog Devices LTC3108). Оскільки збіднений JFET відкритий за нульової напруги на затворі, навіть 20–50 мВ на первинній обмотці підвищувального трансформатора 1:100 збуджують резонансні коливання, індукуючи у вторинній обмотці амплітуду понад 2 В.

### 2. Модуль стеження за точкою максимальної потужності (MPPT)

Будь-який збирач довкілля володіє нелінійною вольт-амперною характеристикою. Максимальна вихідна потужність досягається лише за точної відповідності динамічного вхідного опору перетворювача внутрішньому опору джерела.

Найбільш енергоефективний метод, реалізований в інтегральних PMIC, — вибірка напруги холостого ходу за частковим коефіцієнтом (англ. *Fractional Open-Circuit Voltage*, FOCV):
* Кожні 16–256 секунд PMIC на короткий час (10–50 мс) відключає вхідний перетворювач від збирача.
* Зовнішній конденсатор вибірки `C_mppt` запам'ятовує напругу холостого ходу `V_oc`.
* Вбудований дільник формує опорний рівень регулювання:
  * `V_mpp = 0.70...0.80 · V_oc` — оптимально для кремнієвих та перовськітних сонячних панелей;
  * `V_mpp = 0.50 · V_oc` — оптимально для термоелектрогенераторів (теорема Якобі про узгодження лінійного джерела).
* Головний синхронний boost-перетворювач імпульсно споживає струм з такою шпаруватістю, щоб утримувати вхідну напругу точно на рівні `V_mpp`.

### 3. Гістерезисний супервізор та ізоляція навантаження

Головна причина відмови звичайних систем живлення при підключенні до слабких збирачів — передчасне прокидання мікроконтролера. Якщо навантаження почне споживати струм при напрузі 1.8 В безпосередньо від накопичувача, що заряджається, споживання ядра (навіть 1–2 мА) миттєво перевищить струм збирача (10–50 мкА). Напруга просяде, мікроконтролер скинеться і цикл повторюватиметься нескінченно.

EH PMIC запобігає цьому через фізичний розрив силового ключа виходу (`VOUT_EN`):
* Під час заряду силовий MOSFET повністю закритий, ізолюючи мікроконтролер від шини `V_STOR`. Струм у навантаження дорівнює нулю.
* Щойно напруга на накопичувачі перетинає верхній поріг `V_high` (наприклад, 3.3 В), внутрішній нанопотужний компаратор відкриває силовий ключ і виставляє прапорець `STATUS_OK` / `POWER_GOOD`.
* Навантаження отримує живлення і працює, розряджаючи накопичувач до нижнього порога `V_low` (наприклад, 1.8 В).
* При перетині `V_low` супервізор миттєво відсікає навантаження, дозволяючи накопичувачу знову безперешкодно накопичувати заряд.

## Інженерні правила проектування обв'язки EH PMIC

При розведенні друкованої плати та підборі пасивних компонентів для PMIC збору енергії зневага дрібними паразитними параметрами повністю руйнує роботу вузла:

1. **Конденсатор вибірки MPPT (`C_mppt`):** повинен мати діелектрик класу C0G/NP0 або якісний поліпропілен ємністю 10–22 нФ. Використання діелектриків X5R/X7R з високим струмом діелектричної абсорбції та витоку призводить до спотворення збереженого значення `V_oc` під час фази регулювання.
2. **Індуктивність головного перетворювача (L_boost):** вимагає мінімального опору постійному струму (DCR < 0.2 Ом) та екранованого магнітопроводу. Струми підкачування мають піковий характер навіть при середній потужності в мікровати; високий DCR індуктивності знижує ККД boost-каскаду на 15–25 %.
3. **Дільники програмування порогів напруг:** повинні складатися з мегаомних резисторів (сумарний опір плеча 10–20 МОм). Для запобігання витоку струмів по поверхні друкованої плати через вологу та залишки флюсу плату обов'язково покривають гідрофобним захисним лаком (англ. *conformal coating*), а довкола контактних майданчиків високоомних входів прокладають захисні охоронні кільця (англ. *guard rings*), з'єднані з шиною опорного потенціалу.
