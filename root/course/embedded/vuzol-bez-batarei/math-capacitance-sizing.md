# 🧮 Розрахунок буферної ємності та енергетичного балансу

Визначення номіналу накопичувального конденсатора для безбатарейного вузла вимагає точного математичного узгодження двох протилежних обмежень: ємність має бути достатньо великою, щоб забезпечити енергію активного радіосплеску без провалу напруги нижче порога скидання мікроконтролера, але водночас достатньо малою, щоб час накопичення енергії від слабкого джерела залишався прийнятним, а струм власного витоку діелектрика не перевищував струм збирача.

## Енергетичний баланс одиничного імпульсу

Корисна електрична енергія, яку можна вилучити з конденсатора ємністю `C` при зниженні напруги від верхнього порога спрацьовування супервізора `V_high` до нижнього порога відсікання `V_low`, визначається інтегралом потужності розряду:

```
E_avail = ∫[t0..t1] V(t) · I_load(t) dt
= 1/2 · C · (V_high² − V_low²) · η_reg    [інтегрування лінійної ємності з урахуванням ККД стабілізатора η_reg]
```

Активний сплеск навантаження тривалістю `T_burst` складається з послідовності `N` дискретних фаз (пробудження ядра, запуск тактового генератора, ініціалізація та опитування сенсора, формування пакета, випромінювання в ефір, запис стану в енергонезалежну пам'ять). Повна енергія, необхідна для виконання одного циклу:

```
E_burst = ∑[k=1..N] (V_k · I_k · t_k)
```

де:
* `V_k` — робоча напруга шини живлення мікроконтролера та периферії на фазі `k` (В);
* `I_k` — середній струм споживання на фазі `k` (А);
* `t_k` — тривалість фази `k` (с).

Для гарантованого завершення циклу без аварійного скидання системи енергія накопичувача має покривати енергію навантаження з інженерним запасом надійності `k_safe` (зазвичай `k_safe ≈ 1.25...1.35` для компенсації температурного дрейфу ємності та старіння діелектрика):

```
E_avail ≥ k_safe · E_burst
```

Звідси виводиться базове рівняння для мінімально необхідної ємності `C_min`:

```
1/2 · C_min · (V_high² − V_low²) · η_reg = k_safe · E_burst
C_min = (2 · k_safe · E_burst) / (η_reg · (V_high² − V_low²))    [вираження C_min через різницю квадратів напруг]
```

## Динамічна просадка напруги на еквівалентному послідовному опорі (ESR)

Реальний накопичувач володіє активним внутрішнім опором (англ. *Equivalent Series Resistance*, ESR). Під час піка передавача струм розряду різко зростає від часток мікроампера до `I_peak` (15–30 мА). Це створює миттєвий стрибок напруги `ΔV_esr`:

```
ΔV_esr = I_peak · R_esr    [закон Ома для послідовного активного опору]
```

Через це фактична напруга на виводах мікроконтролера в момент увімкнення підсилювача потужності падає нижче теоретичної кривої розряду ємності:

```
V_mcu(t) = V_cap(t) − I_load(t) · R_esr
```

Щоб запобігти передчасному спрацьовуванню детектора провалу напруги (англ. *Brown-Out Reset*, BOR) при напрузі `V_bor`, дійсний нижній поріг відключення накопичувача `V_low` повинен обиратися з урахуванням динамічного запасу:

```
V_low ≥ V_bor + I_peak · R_esr + V_margin    [компенсація просадки на ESR та шуму живлення]
```

Якщо використовується іоністор з відносно високим ESR (`R_esr ≈ 5...20 Ом`), просадка `ΔV_esr` при струмі 25 мА становить:

```
ΔV_esr = 0.025 А · 10 Ом = 0.25 В    [динамічний спад на внутрішньому опорі іоністора]
```

Такий спад здатен миттєво перезавантажити мікроконтролер ще до того, як конденсатор віддасть хоча б 10 % накопиченої корисної енергії. Для усунення цього ефекту паралельно іоністору встановлюють керамічний конденсатор MLCC ємністю 22–47 мкФ з ESR менше 10 мОм, який приймає на себе високочастотний фронт струму.

## Баланс струмів та час заряду накопичувача

Швидкість накопичення енергії від збирача довкілля описується диференціальним рівнянням заряду ємності:

```
C · (dV_cap / dt) = I_harvest(V_cap) − I_leak(V_cap, T) − I_pmic_q
```

де:
* `I_harvest(V_cap)` — корисний вихідний струм перетворювача енергії збирача;
* `I_leak(V_cap, T)` — струм власного витоку конденсатора за поточної напруги та температури;
* `I_pmic_q` — власний струм спокою схеми керування живленням (PMIC) у стані заряду.

Умова принципової працездатності безбатарейного вузла за мінімальної освітленості або мінімального градієнта температур формулюється як додатність похідної напруги в усьому діапазоні від 0 до `V_high`:

```
I_harvest(V_cap) > I_leak(V_cap, T) + I_pmic_q,   ∀ V_cap ∈ [0, V_high]
```

Якщо за максимальної напруги `V_high` струм витоку `I_leak` зрівнюється зі струмом генератора `I_harvest`, накопичення заряду асимптотично зупиняється, напруга ніколи не досягає порога запуску `V_high`, і вузол переходить у стан нескінченного енергетичного блокування (англ. *energy lockup*).

Час відновлення заряду між двома послідовними імпульсами `T_recharge` (за середнього струму заряду `I_ch_avg = I_harvest − I_leak − I_pmic_q`):

```
T_recharge = ∫[V_low..V_high] (C / (I_harvest(V) − I_leak(V) − I_pmic_q)) dV
≈ (C · (V_high − V_low)) / I_ch_avg    [наближення для квазісталого середнього струму заряду]
```

## Покроковий чисельний розрахунок автономного BLE-маяка

Розглянемо практичний проект безбатарейного термометра з радіопередачею нез'єднуваних рекламних пакетів (BLE Non-connectable Advertising) на трьох радіоканалах (37, 38, 39) за вихідної потужності 0 дБм.

### 1. Бюджет заряду та енергії фаз активності

Складемо часовий профіль споживання вузла при стабілізованій напрузі шини ядра 2.2 В:

```
Фаза 1 (Старт генератора та ініціалізація ядра):
t1 = 150 мкс,  I1 = 1.2 мА
q1 = 1.2 мА · 0.15 мс = 0.18 мкКл
E1 = 2.2 В · 0.18 мкКл = 0.396 мкДж

Фаза 2 (Вимірювання температури через вбудований АЦП):
t2 = 800 мкс,  I2 = 0.9 мА
q2 = 0.9 мА · 0.80 мс = 0.72 мкКл
E2 = 2.2 В · 0.72 мкКл = 1.584 мкДж

Фаза 3 (Запис калібрувального стану та лічильника пакетів у FRAM):
t3 = 50 мкс,   I3 = 1.5 мА
q3 = 1.5 мА · 0.05 мс = 0.075 мкКл
E3 = 2.2 В · 0.075 мкКл = 0.165 мкДж

Фаза 4 (Синтез частоти та передача BLE adv на 3 каналах):
t4 = 2.8 мс,   I4 = 7.5 мА
q4 = 7.5 мА · 2.80 мс = 21.0 мкКл
E4 = 2.2 В · 21.0 мкКл = 46.200 мкДж

Повна енергія активного імпульсу E_burst:
E_burst = 0.396 + 1.584 + 0.165 + 46.200 = 48.345 мкДж ≈ 48.4 мкДж
Повний заряд активного імпульсу Q_burst:
Q_burst = 0.18 + 0.72 + 0.075 + 21.0 = 21.975 мкКл ≈ 22.0 мкКл
```

### 2. Розрахунок мінімальної ємності накопичувача

Параметри системи керування живленням (PMIC):
* Верхній поріг увімкнення навантаження: `V_high = 3.3 В`;
* Нижній поріг вимкнення навантаження: `V_low = 2.4 В` (забезпечує запас над порогом роботи вбудованого buck-стабілізатора 2.2 В);
* Середній ККД імпульсного стабілізатора: `η_reg = 0.85`;
* Коефіцієнт запасу: `k_safe = 1.30`.

Підставимо значення у формулу розрахунку ємності:

```
C_min = (2 · k_safe · E_burst) / (η_reg · (V_high² − V_low²))
= (2 · 1.30 · 48.4·10⁻⁶ Дж) / (0.85 · (3.3² − 2.4²))    [підстановка параметрів]
= (125.84·10⁻⁶) / (0.85 · (10.89 − 5.76))              [обчислення різниці квадратів]
= (125.84·10⁻⁶) / (0.85 · 5.13)
= (125.84·10⁻⁶) / 4.3605
≈ 28.86·10⁻⁶ Ф ≈ 29 мкФ                                [результат розрахунку]
```

З урахуванням деградації ємності керамічних конденсаторів класу X7R під дією постійної напруги зміщення (англ. *DC bias effect*, втрата до 40–50 % номінальної ємності при напрузі 3.3 В для типорозміру 0805/1206) обираємо комерційний номінал з запасом:
`C_ном = 100 мкФ` (або два паралельних керамічних конденсатори по 47 мкФ, 10 В, X7R).

### 3. Розрахунок часу між передачами при кімнатному освітленні

Невелика фотоелектрична комірка розміром 30 × 15 мм під кімнатним флуоресцентним або світлодіодним освітленням (200 люкс) генерує струм `I_in ≈ 18 мкА` при напрузі максимальної потужності `V_mpp ≈ 1.5 В` (потужність збирача `P_in ≈ 27 мкВт`).

Вихідний струм заряду накопичувача на конденсаторі при середній напрузі 2.85 В та ККД boost-перетворювача PMIC `η_boost = 0.80`:

```
P_out = P_in · η_boost = 27 мкВт · 0.80 = 21.6 мкВт
I_harvest_avg = P_out / V_avg = 21.6 мкВт / 2.85 В ≈ 7.58 мкА
```

Струм власного витоку керамічного конденсатора 100 мкФ при 3.3 В становить менше `0.05 мкА`, струм спокою PMIC `I_pmic_q = 0.35 мкА`. Чистий струм заряду:

```
I_ch_net = 7.58 мкА − 0.05 мкА − 0.35 мкА = 7.18 мкА
```

Час накопичення енергії між послідовними радіопосилками:

```
ΔV = V_high − V_low = 3.3 В − 2.4 В = 0.9 В
T_recharge = (C_ном · ΔV) / I_ch_net
= (100·10⁻⁶ Ф · 0.9 В) / (7.18·10⁻⁶ А)
= 90·10⁻⁶ / 7.18·10⁻⁶
≈ 12.5 с    [інтервал передачі пакетів без батареї]
```

Отриманий результат показує, що безбатарейний термометр на конденсаторі 100 мкФ під звичайним штучним світлом стабільно передає виміри кожні 12.5 секунд, не потребуючи заміни елементів живлення протягом усього життєвого циклу обладнання.
