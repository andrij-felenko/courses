# 🧮 Математика КСВ, відбиття хвилі та розрахунку узгоджувальних ланок

Коли вхідний імпеданс антени відрізняється від хвильового опору тракту (50 Ом), частина високочастотної енергії відбивається від точки живлення й повертається назад до генератора. Взаємодія прямої та відбитої хвиль утворює в лінії передачі просторовий розподіл інтерференційних максимумів і мінімумів напруги — стоячу хвилю. Нижче наведено суворе математичне виведення взаємозв'язку між комплексним імпедансом навантаження, коефіцієнтом відбиття, коефіцієнтом стоячої хвилі (КСВ / VSWR), втратами передачі потужності, конформним відображенням на діаграмі Сміта та аналітичними формулами розрахунку реактивних узгоджувальних L-, T- та Pi-ланок.

## Комплексний коефіцієнт відбиття та стояча хвиля

Розглянемо однорідну лінію передачі без втрат із дійсним хвильовим опором `Z₀ = 50` Ом, навантажену на довільний комплексний імпеданс `Z_L = R_L + j·X_L`.

Нехай вздовж осі `x` від генератора до навантаження поширюється пряма хвиля напруги з комплексною амплітудою `V⁺(x) = V₀⁺ · e^(-j·β·x)`, де `β = 2·π / λ` — фазова стала лінії. У точці навантаження `x = 0` виникає відбита хвиля `V⁻(x) = V₀⁻ · e^(+j·β·x)`.

Комплексний коефіцієнт відбиття за напругою `Γ` (гамма) у площині навантаження визначається як відношення амплітуди відбитої хвилі до прямої:

```
Γ = V₀⁻ / V₀⁺
  = (Z_L - Z₀) / (Z_L + Z₀)      [гранична умова нерозривності напруги й струму]
```

Якщо нормалізувати імпеданс навантаження відносно хвильового опору лінії `z_L = Z_L / Z₀ = r_L + j·x_L`, формула коефіцієнта відбиття набуває канонічного вигляду дробово-лінійного перетворення:

```
Γ = (z_L - 1) / (z_L + 1)        [нормалізована форма коефіцієнта відбиття]
```

Оскільки `Z_L` є комплексним числом, `Γ` також є комплексним і записується в показовій або тригонометричній формі:

```
Γ = |Γ| · e^(j·θ) = |Γ| · cos(θ) + j · |Γ| · sin(θ)      [показова та алгебраїчна форми]
```

де `|Γ|` — модуль коефіцієнта відбиття (дійсне число в діапазоні від 0 до 1), а `θ` — фазовий зсув відбитої хвилі відносно прямої в точці стику:

```
|Γ| = √((R_L - Z₀)² + X_L²) / √((R_L + Z₀)² + X_L²)      [модуль комплексного дробу]
θ   = arctan2(X_L, R_L - Z₀) - arctan2(X_L, R_L + Z₀)    [аргумент комплексного дробу]
```

Сумарна напруга в будь-якій точці лінії на відстані `d = -x` від навантаження дорівнює суперпозиції двох хвиль:

```
V(d) = V₀⁺ · e^(j·β·d) + V₀⁻ · e^(-j·β·d)                  [суперпозиція прямої та відбитої хвиль]
     = V₀⁺ · e^(j·β·d) · (1 + Γ · e^(-j·2·β·d))            [винесення прямої хвилі за дужки]
```

Амплітуда (обвідна) напруги вздовж лінії:

```
|V(d)| = |V₀⁺| · |1 + |Γ| · e^(j·(θ - 2·β·d))|               [модуль добутку комплексних чисел]
       = |V₀⁺| · √(1 + |Γ|² + 2·|Γ|·cos(θ - 2·β·d))          [розкриття модуля комплексної суми]
```

Ця величина періодично коливається вздовж лінії між максимальним і мінімальним значеннями:

```
|V_max| = |V₀⁺| · (1 + |Γ|)      [коли cos(θ - 2·β·d) = +1, конструктивна інтерференція]
|V_min| = |V₀⁺| · (1 - |Γ|)      [коли cos(θ - 2·β·d) = -1, деструктивна інтерференція]
```

Відстань між двома сусідніми максимумами або мінімумами напруги становить рівно половину довжини хвилі в лінії: `Δd = λ / 2`. Відстань від навантаження до першого максимуму напруги визначається фазою коефіцієнта відбиття: `d_max = (θ / (4·π)) · λ`.

## Коефіцієнт стоячої хвилі (КСВ / VSWR)

Коефіцієнт стоячої хвилі за напругою (англ. *Voltage Standing Wave Ratio*, VSWR) визначається як відношення максимальної амплітуди напруги в лінії до мінімальної:

```
VSWR = |V_max| / |V_min|
     = (|V₀⁺| · (1 + |Γ|)) / (|V₀⁺| · (1 - |Γ|))      [підстановка V_max та V_min]
     = (1 + |Γ|) / (1 - |Γ|)                          [скорочення на |V₀⁺|]
```

Обернене перетворення дозволяє знайти модуль коефіцієнта відбиття за виміряним значенням КСВ:

```
VSWR · (1 - |Γ|) = 1 + |Γ|                [множення обох частин на знаменник]
VSWR - VSWR · |Γ| = 1 + |Γ|               [розкриття дужок у лівій частині]
VSWR - 1 = |Γ| · (VSWR + 1)               [групування доданків з |Γ|]
|Γ| = (VSWR - 1) / (VSWR + 1)             [ділення на (VSWR + 1)]
```

Граничні випадки:
- Ідеальне узгодження: `Z_L = Z₀` → `|Γ| = 0` → `VSWR = 1.0` (чиста біжуча хвиля);
- Повний розрив (холостий хід): `Z_L = ∞` → `|Γ| = 1.0` → `VSWR = ∞` (чиста стояча хвиля, `V_min = 0`);
- Коротке замикання: `Z_L = 0` → `|Γ| = 1.0` → `VSWR = ∞` (чиста стояча хвиля, фазовий зсув 180°);
- Чисто реактивне навантаження: `Z_L = j·X_L` → `|Γ| = 1.0` → `VSWR = ∞` (вся потужність відбивається).

## Зворотні втрати (Return Loss) та енергетичний баланс

У радіочастотній інженерії замість лінійного модуля `|Γ|` частіше використовують логарифмічну шкалу — зворотні втрати (англ. *Return Loss*, `RL`) або параметр розсіювання `S₁₁`:

```
S₁₁ (дБ) = 20 · log₁₀(|Γ|)               [логарифмічний коефіцієнт відбиття за напругою]
RL (дБ)  = -20 · log₁₀(|Γ|)              [зворотні втрати, модуль S11 зі знаком плюс]
```

Повна потужність, що падає на навантаження від генератора, дорівнює `P_fwd = |V₀⁺|² / (2·Z₀)`. Потужність, відбита назад від навантаження:

```
P_refl = |V₀⁻|² / (2·Z₀)
       = |Γ|² · P_fwd                     [зв'язок відбитої потужності з квадратом модуля гамма]
```

Частка потужності, яка поглинається навантаженням (випромінюється антеною та частково перетворюється на теплові втрати в металі й діелектрику):

```
P_deliv = P_fwd - P_refl
        = P_fwd · (1 - |Γ|²)              [баланс потужності в лінії передачі без втрат]
```

Втрати через неузгодженість (англ. *Mismatch Loss*, `ML`):

```
ML (дБ) = -10 · log₁₀(1 - |Γ|²)                                          [визначення втрат неузгодженості]
        = -10 · log₁₀(1 - ((VSWR - 1) / (VSWR + 1))²)                    [підстановка виразу для |Γ|]
        = -10 · log₁₀((4 · VSWR) / (VSWR + 1)²)                          [спрощення алгебраїчного дробу]
```

## Конформне відображення на діаграмі Сміта

Діаграма Сміта базується на білінійному конформному відображенні правої комплексної півплощини нормалізованого імпедансу `z = r + j·x` (де `r ≥ 0`) всередину одиничного круга на комплексній площині коефіцієнта відбиття `Γ = u + j·v` (де `u² + v² ≤ 1`):

```
u + j·v = ((r + j·x) - 1) / ((r + j·x) + 1)
        = ((r - 1) + j·x) / ((r + 1) + j·x)                              [дробово-лінійний вираз]
```

Домноживши чисельник і знаменник на комплексно-спряжений знаменник `(r + 1) - j·x`, виділимо дійсну `u` та уявну `v` частини:

```
u = (r² - 1 + x²) / ((r + 1)² + x²)                                      [дійсна частина коефіцієнта відбиття]
v = (2 · x) / ((r + 1)² + x²)                                            [уявна частина коефіцієнта відбиття]
```

Шляхом виключення змінної `x` отримуємо рівняння сімейства кіл постійного активного опору `r = const`:

```
(u - r / (r + 1))² + v² = (1 / (r + 1))²                                  [кола постійного активного опору]
```

Це коло на площині `(u, v)` із центром у точці `(r / (r + 1), 0)` та радіусом `R_circ = 1 / (r + 1)`. Усі кола проходять через точку холостого ходу `(1, 0)`.

Шляхом виключення змінної `r` отримуємо рівняння сімейства кіл постійного реактивного опору `x = const`:

```
(u - 1)² + (v - 1 / x)² = (1 / x)²                                        [кола постійного реактивного опору]
```

Це дуги кіл із центром у точці `(1, 1 / x)` та радіусом `R_x = 1 / |x|`. Верхня половина круга (`v > 0`) відповідає індуктивній реактивності (`x > 0`), нижня (`v < 0`) — ємнісній (`x < 0`). Центр діаграми `(0, 0)` відповідає ідеальному узгодженню `z = 1.0 + j·0.0` (50 Ом).

## Додаткові втрати в лінії передачі через КСВ

Якщо лінія передачі має власне погонне згасання `α₀` (дБ/м) при ідеальному узгодженні, то при наявності стоячої хвилі сумарні втрати в лінії збільшуються, оскільки струми у пучностях напруги створюють додаткове омічне нагрівання провідників, а напруги у пучностях збільшують діелектричні втрати:

```
α_total = α₀ · ((1 + |Γ|²) / (1 - |Γ|²))                                  [збільшення згасання в лінії через КСВ]
        = α₀ · ((VSWR² + 1) / (2 · VSWR))                                 [вираження через КСВ]
```

Для короткої лінії на платі (довжиною 10–20 мм) цей ефект додає десяті частки децибела, проте в довгих фідерних кабелях (наприклад, між базовою станцією та винесеною антеною) високий КСВ призводить до катастрофічного розсіювання вихідної потужності прямо всередині кабелю.

## Числовий приклад розладнання антени

Нехай налаштована на столі антена мала `Z_L = 50 + j·0` Ом на частоті `f₀ = 2.44` ГГц (`|Γ| = 0`, `VSWR = 1.0`, `S₁₁ = -∞`).

Після встановлення у пластиковий корпус та наближення руки імпеданс антени змістився до `Z_L = 15 - j·35` Ом.

Розрахуємо коефіцієнт відбиття:

```
Z_L - Z₀ = (15 - j·35) - 50 = -35 - j·35                         [різниця імпедансів]
Z_L + Z₀ = (15 - j·35) + 50 = 65 - j·35                          [сума імпедансів]
|Z_L - Z₀| = √((-35)² + (-35)²) = √(1225 + 1225) ≈ 49.497 Ом     [модуль чисельника]
|Z_L + Z₀| = √(65² + (-35)²) = √(4225 + 1225) ≈ 73.824 Ом       [модуль знаменника]
|Γ| = 49.497 / 73.824 ≈ 0.6705                                   [модуль коефіцієнта відбиття]
```

Розрахуємо КСВ:

```
VSWR = (1 + 0.6705) / (1 - 0.6705)
     = 1.6705 / 0.3295 ≈ 5.07             [обчислення КСВ за формулою]
```

Розрахуємо зворотні втрати та відбиту потужність:

```
S₁₁ = 20 · log₁₀(0.6705) ≈ -3.47 дБ                              [логарифмічні зворотні втрати]
P_refl_ratio = (0.6705)² ≈ 0.4496                                [частка відбитої потужності, 45.0%]
ML = -10 · log₁₀(1 - 0.4496) = -10 · log₁₀(0.5504) ≈ 2.59 дБ    [додаткове згасання в тракті]
```

Якщо передавач генерує `+20` дБм (100 мВт), то в антену надходить лише 55.0 мВт, а 45.0 мВт відбивається назад і розсіюється на вихідному транзисторі підсилювача.

## Аналітичний розрахунок узгоджувальної L-ланки

L-ланка складається з двох реактивних елементів: одного послідовного `X` та одного паралельного `B`. Вона може трансформувати довільний імпеданс `Z_L = R_L + j·X_L` у 50 Ом на фіксованій частоті `f₀`.

Конфігурація залежить від співвідношення активного опору навантаження `R_L` та опору джерела `R_S = 50` Ом:

### Випадок 1: `R_L < R_S` (наприклад, `R_L = 15` Ом < 50 Ом)
Паралельний елемент ставиться з боку джерела (більшого опору), послідовний — з боку навантаження.

Добротність схеми `Q`:

```
Q = √((R_S / R_L) - 1)
  = √((50 / 15) - 1) = √(3.333 - 1) = √2.333 ≈ 1.5275            [навантажена добротність кола]
```

Необхідна реактивна провідність паралельного елемента `B_p` (з боку джерела):

```
B_p = Q / R_S
    = 1.5275 / 50 ≈ 0.03055 См                                    [паралельна ємнісна провідність]
```

Якщо обираємо паралельний конденсатор (`B_p > 0`):

```
C_p = B_p / (2 · π · f₀)
    = 0.03055 / (2 · π · 2.44 · 10⁹)
    ≈ 1.99 · 10⁻¹² Ф = 1.99 пФ                                    [номінал паралельного конденсатора]
```

Необхідний реактивний опір послідовної гілки `X_s`:

```
X_s = Q · R_L - X_L                                               [компенсація власної реактивності антени]
    = (1.5275 · 15) - (-35)
    = 22.91 + 35.0 = +57.91 Ом                                    [необхідний індуктивний опір]
```

Для отримання позитивного реактивного опору потрібен послідовний індуктор:

```
L_s = X_s / (2 · π · f₀)
    = 57.91 / (2 · π · 2.44 · 10⁹)
    ≈ 3.78 · 10⁻⁹ Гн = 3.78 нГн                                   [номінал послідовної котушки індуктивності]
```

Таким чином, L-ланка з паралельного конденсатора `C_p = 2.0` пФ і послідовного індуктора `L_s = 3.8` нГн повністю компенсує детьюнінг антени й повертає імпеданс у точку 50 Ом (`VSWR = 1.0`).

### Випадок 2: `R_L > R_S` (наприклад, `R_L = 120` Ом > 50 Ом)
Паралельний елемент ставиться з боку антени (більшого опору), послідовний — з боку джерела 50 Ом.

Добротність схеми `Q`:

```
Q = √((R_L / R_S) - 1)                                            [добротність при підвищеному опорі антени]
```

Паралельна провідність перераховується з урахуванням вихідної провідності антени `Y_L = 1 / Z_L`.

## Аналітичний розрахунок узгоджувального Pi-контуру

L-ланка має суворе обмеження: фіксовану добротність `Q = √((R_high / R_low) - 1)`, яка жорстко прив'язана до відношення опорів. Pi-контур (Shunt C1 — Series L — Shunt C2) додає третій ступінь свободи, дозволяючи незалежно обирати робочу добротність `Q` (і відповідно смугу пропускання), а також узгоджувати опір як у бік підвищення, так і в бік зниження.

Pi-контур математично розглядається як дві L-ланки, з'єднані послідовно через проміжний віртуальний опір `R_int`:

```
R_int = min(R_S, R_L) / (Q² + 1)                                  [проміжний віртуальний опір вузла]
```

Де `Q` — обрана інженером добротність контуру (зазвичай `Q = 2 ... 5` для компромісу між смугою пропускання та фільтрацією гармонік).

Розрахунок розпадається на два кроки:
1. Трансформація `R_S = 50` Ом у `R_int` за допомогою `C₁` та першої половини `L`;
2. Трансформація `R_int` у `Z_L = R_L + j·X_L` за допомогою другої половини `L` та `C₂`.

Отримані точні аналітичні рівняння служать ядром для розрахункових утиліт та оптимізаторів компонентів стандартного ряду.
