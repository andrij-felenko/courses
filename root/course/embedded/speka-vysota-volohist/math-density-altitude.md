# 🧮 Виведення густини вологого повітря та формули Density Altitude

Густина атмосферного повітря визначає кожен грам аеродинамічної сили, яку здатні створити гвинти або крило безпілотного апарата. Щоб розрахувати точну втрату тяги та зростання струму двигунів у спеку, бортовий комп'ютер чи інженерний калькулятор не можуть спиратися на приблизні таблиці — потрібна термодинамічно точна математична модель. Розгляньмо послідовне виведення рівняння стану для вологого повітря з парціальних тисків Дальтона, концепцію віртуальної температури та строге аналітичне виведення висоти за густиною (Density Altitude, DA) з рівнянь Міжнародної стандартної атмосфери ISA.

### 1. Рівняння стану та закон Дальтона для вологого повітря

Атмосферне повітря є сумішшю сухого газу (переважно азот N₂, кисень O₂, аргон Ar) та водяної пари H₂O. За законом Дальтона повний барометричний тиск `p` дорівнює сумі парціального тиску сухого повітря `p_d` та парціального тиску водяної пари `p_v`:

```
p = p_d + p_v
```

Застосуємо [рівняння стану ідеального газу](root:ph-thermodynamics/ideal-gas-law) окремо для кожної компоненти суміші через питомі газові сталі:

```
p_d = ρ_d · R_d · T   →   ρ_d = p_d / (R_d · T)
p_v = ρ_v · R_v · T   →   ρ_v = p_v / (R_v · T)
```

де:
- `T` — абсолютна температура повітря в кельвінах (`T = T_C + 273.15`);
- `R_d = R_univ / M_d` — питома газова стала сухого повітря (`M_d ≈ 0.028965` кг/моль, `R_d ≈ 287.058` Дж/(кг·К));
- `R_v = R_univ / M_v` — питома газова стала водяної пари (`M_v ≈ 0.018015` кг/моль, `R_v ≈ 461.495` Дж/(кг·К)).

Оскільки молекулярна маса водяної пари `M_v = 18.015` г/моль суттєво менша за середню молекулярну масу сухого повітря `M_d = 28.965` г/моль, їхнє відношення становить:

```
ε = M_v / M_d = R_d / R_v = 18.01528 / 28.96546 ≈ 0.62197
```

Загальна густина вологого повітря `ρ` є сумою парціальних густин `ρ_d` та `ρ_v`. Виведемо кінцевий вираз через повний тиск `p` та парціальний тиск пари `p_v`:

```
ρ = ρ_d + ρ_v
  = p_d / (R_d·T) + p_v / (R_v·T)                       [підстановка парціальних густин]
  = (p − p_v) / (R_d·T) + p_v / (R_v·T)                  [закон Дальтона: p_d = p − p_v]
  = p / (R_d·T) − p_v / (R_d·T) + (p_v / (R_d·T)) · (R_d / R_v) [приведення до спільного знаменника R_d·T]
  = (p / (R_d·T)) · [ 1 − (p_v / p) · (1 − R_d / R_v) ]  [винесення p/(R_d·T) за дужки]
  = (p / (R_d·T)) · [ 1 − 0.37803 · (p_v / p) ]         [обчислення 1 − ε = 1 − 0.62197 = 0.37803]
```

Отриманий результат наочно демонструє так званий «вологий парадокс» аеронавтики: оскільки коефіцієнт `0.37803` додатний, а `p_v > 0`, наявність водяної пари в повітрі **завжди зменшує його густину** за фіксованих температури й тиску.

### 2. Віртуальна температура

В авіаційній метеорології зручно подавати густину вологого повітря за формулою для сухого газу, ввівши фіктивну еквівалентну температуру — **віртуальну температуру** `T_v`:

```
ρ = p / (R_d · T_v)
```

Прирівнюючи цей вираз до виведеного рівняння густини, отримуємо:

```
p / (R_d · T_v) = (p / (R_d · T)) · [ 1 − 0.37803 · (p_v / p) ]
```

Скоротивши `p / R_d` з обох боків:

```
1 / T_v = (1 / T) · [ 1 − 0.37803 · (p_v / p) ]
```

Звідси віртуальна температура дорівнює:

```
T_v = T / [ 1 − 0.37803 · (p_v / p) ]
```

Оскільки знаменник менший за одиницю, віртуальна температура `T_v` завжди вища за дійсну термодинамічну температуру `T`. Водне повітря поводиться в аеродинамічному сенсі точно так само, як сухе, але нагріте на кілька градусів вище.

### 3. Парціальний тиск насиченої пари (формула Магнуса-Тетенса)

Парціальний тиск водяної пари `p_v` розраховують через відносну вологість `RH` (у відсотках від 0 до 100%) та тиск насиченої пари `p_sat(T_C)` при температурі `T_C` (у градусах Цельсія):

```
p_v = (RH / 100) · p_sat(T_C)
```

Для визначення `p_sat(T_C)` у діапазоні від −40 °C до +50 °C високу точність (похибка менше 0.1%) дає напівімпірична формула Магнуса-Тетенса:

```
p_sat(T_C) = 6.1078 · 10^( (7.5 · T_C) / (237.3 + T_C) )  [тиск у гектопаскалях, гПа]
```

Для обчислень у паскалях (Па, система SI):

```
p_sat_Pa(T_C) = 610.78 · exp( (17.27 · T_C) / (237.3 + T_C) )
```

Підставивши виміряні давачами значення температури, відносної вологості та статичного тиску, алгоритм однозначно визначає точну густину повітря `ρ`.

### 4. Виведення формули Density Altitude з Міжнародної стандартної атмосфери (ISA)

Міжнародна стандартна атмосфера (ISA, ICAO Doc 7488) задає такі опорні параметри на рівні моря (`H = 0` м):
- Стандартний тиск: `p_0 = 101325` Па (1013.25 гПа);
- Стандартна температура: `T_0 = 288.15` К (+15.0 °C);
- Стандартна густина: `ρ_0 = p_0 / (R_d · T_0) = 101325 / (287.058 · 288.15) ≈ 1.2250` кг/м³;
- Вертикальний градієнт температури в тропосфері: `L = 0.0065` К/м (6.5 °C на 1000 м підйому).

У стандартній тропосфері температура спадає лінійно з геопотенційною висотою `H`:

```
T_ISA(H) = T_0 − L · H
```

З основного рівняння гідростатики `dp = −ρ · g · dH` та рівняння стану ідеального газу `ρ = p / (R_d · T)` маємо диференціальне рівняння:

```
dp / p = − (g / (R_d · (T_0 − L · H))) · dH
```

Інтегруючи від рівня моря `H = 0` (де `p = p_0`) до висоти `H`:

```
ln(p / p_0) = (g / (R_d · L)) · ln(1 − (L · H) / T_0)
```

Потенціюючи, отримуємо барометричну формулу розподілу тиску в ISA:

```
p_ISA(H) = p_0 · (1 − (L · H) / T_0)^( g / (R_d · L) )
```

Тепер знайдемо аналітичний закон зміни густини повітря `ρ_ISA(H)` з висотою в стандартній атмосфері:

```
ρ_ISA(H) = p_ISA(H) / (R_d · T_ISA(H))
         = [ p_0 · (1 − L·H / T_0)^( g / (R_d·L) ) ] / [ R_d · T_0 · (1 − L·H / T_0) ]
         = (p_0 / (R_d · T_0)) · (1 − L·H / T_0)^( (g / (R_d·L)) − 1 )
         = ρ_0 · (1 − L·H / T_0)^( (g / (R_d·L)) − 1 )
```

Обчислимо показник степеня, використовуючи стандартні константи `g = 9.80665` м/с², `R_d = 287.058` Дж/(кг·К), `L = 0.0065` К/м:

```
g / (R_d · L) = 9.80665 / (287.058 · 0.0065) = 9.80665 / 1.865877 ≈ 5.25588
Показник степеня густини: 5.25588 − 1 = 4.25588
```

Отже, зв'язок між висотою та густиною в ISA має точний степеневий вигляд:

```
ρ_ISA(H) = ρ_0 · (1 − L · H / T_0)^4.25588
```

**Висота за густиною (Density Altitude, DA)** — це висота в стандартній атмосфері ISA, на якій густина повітря `ρ_ISA(DA)` дорівнює поточній фактичній густині повітря `ρ`. Прирівняємо їх:

```
ρ = ρ_0 · (1 − L · DA / T_0)^4.25588
```

Розв'яжемо це рівняння відносно `DA`:

```
(1 − L · DA / T_0)^4.25588 = ρ / ρ_0
1 − L · DA / T_0 = (ρ / ρ_0)^(1 / 4.25588)
1 − L · DA / T_0 = (ρ / ρ_0)^0.23497
L · DA / T_0 = 1 − (ρ / ρ_0)^0.23497
DA = (T_0 / L) · [ 1 − (ρ / ρ_0)^0.23497 ]
```

Підставимо значення константи масштабу висоти `T_0 / L = 288.15 / 0.0065 ≈ 44330.8` метрів та стандартної густини `ρ_0 = 1.2250` кг/м³:

```
DA = 44330.8 · [ 1 − (ρ / 1.2250)^0.23497 ]  [висота в метрах]
```

### 5. Виведення лінійного авіаційного наближення

Класичне практичне авіаційне правило стверджує: «кожен градус Цельсія перевищення температури над стандартом ISA додає близько 120 метрів до висоти за густиною». Покажемо, як це правило випливає з лінеаризації розкладу Тейлора.

Барометрична висота (Pressure Altitude, `H_p`) — це висота за стандартним тиском:

```
H_p = 44330.8 · [ 1 − (p / 101325)^0.190263 ]
```

Стандартна температура на цій барометричній висоті становить:

```
T_ISA = 15.0 − 0.0065 · H_p  [у °C]
```

Розклавши степеневу формулу `DA` в ряд Тейлора першого порядку в околі точки `T = T_ISA` за відхиленням температури `ΔT = T_ambient − T_ISA`, отримуємо:

```
DA ≈ H_p + (T_0 / (L · T_0)) · ΔT · (T_0 / T_ambient) · ...
DA ≈ H_p + 118.8 · (T_ambient − T_ISA)  [у метрах]
```

Для практичних польотних розрахунків у полі це наближення дозволяє миттєво оцінити висоту за густиною без калькулятора. Проте в бортовій прошивці автопілота використовується повна термодинамічна формула з урахуванням вологості, оскільки в умовах тропічної спеки (+35...+40 °C) висока вологість здатна додати ще 200–400 метрів еквівалентної висоти.
