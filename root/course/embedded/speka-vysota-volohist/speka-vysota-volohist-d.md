Квадрокоптер масою два кілограми, який у травні на рівнині біля моря (+15 °C, рівень моря 0 м, стандартний тиск 1013 гПа) стабільно зависав на 45% газу, витрачав 18 ампер струму й тримався в небі 22 хвилини, привозять на літню польову базу в гори. Висота стартового майданчика — 1600 метрів над рівнем моря, опівдні термометр показує +38 °C у затінку, а після ранкової зливи відносна вологість сягає 65%. Оператор ставить той самий акумулятор, чіпляє звичне корисне навантаження, знімає апарат із запобіжника й плавно додає газ.

Апарат ледь відривається від землі на 75% стика, загрозливо хитається від найменшого пориву вітру, а автопілот видає попередження про просідання напруги батареї вже на четвертій хвилині польоту. Під час спроби зупинити вертикальне зниження дрон не встигає загальмувати, провалюється крізь власний потік і розбивається об каміння. Термопара на регуляторі обертів встигає зафіксувати +118 °C перед аварією, а обмотки безколекторних двигунів темніють від згорілого лаку.

Жоден електронний вузол не був несправним. Причина аварії — невидима термодинамічна трансформація повітря, яку в авіації називають умовами «High & Hot» (високо і гаряче). Повітря — це не порожнеча, а робоче тіло, маса якого створює підіймальну силу. Коли тиск падає, температура підскакує, а вологість зростає, густина повітря стрімко деградує. З'ясуймо фізичний механізм цієї деградації, розрахуймо каскадне зростання навантаження на силову установку та розгляньмо інженерні правила, які повертають дрону здатність впевнено літати в розрідженій спекотній атмосфері.

### 1. Повітря як робоче тіло: механіка створення тяги

Будь-який повітряний рушій — від крила літака до несного гвинта квадрокоптера чи вертольота — працює за фундаментальним законом збереження імпульсу. Щоб створити підіймальну силу або тягу `T`, гвинт мусить щосекунди захоплювати певний об'єм повітря й відкидати його вниз із приростом швидкості `Δv`. Тяга дорівнює масовій витраті повітря `ṁ` (кілограмів за секунду), помноженій на приріст швидкості потоку:

```
T = ṁ · Δv = (ρ · A · v_flow) · Δv
```

де `ρ` (грец. *rho*) — густина повітря (маса одиниці об'єму, кг/м³), `A` — площа диска, що його описують лопаті гвинта, а `v_flow` — середня швидкість проходження повітря крізь площину обертання.

Класична аеродинамічна формула для тяги повітряного гвинта діаметром `D` (метрів), який обертається з частотою `n` (обертів за секунду), виражається через безрозмірний коефіцієнт тяги `C_T`:

```
T = C_T · ρ · n² · D⁴
```

Потужність `P`, яку двигун повинен передати на вал для подолання аеродинамічного опору лопатей, описується через безрозмірний коефіцієнт потужності `C_P`:

```
P = C_P · ρ · n³ · D⁵
```

Зверніть увагу на множник `ρ` в обох рівняннях. Він стоїть у першому степені: **тяга за фіксованих геометричних параметрів і обертів гвинта падає прямо пропорційно густині повітря**. Якщо густина атмосфери зменшилася на 30%, то на тих самих максимальних обертах гвинт здатний створити лише 70% своєї номінальної тяги.

> 🔧 **Навіщо це.** Безпілотник не має приладу, який би безпосередньо вимірював «залишок підіймальної сили». Автопілот реагує на наслідок: щоб утримати незмінну масу `m` у повітрі, підіймальна сила повинна строго дорівнювати силі тяжіння `m·g`. Якщо повітря розріджене, регулятор обертів змушений автоматично розкручувати двигуни до значно вищої швидкості `n`, витрачаючи більше енергії акумулятора щомиті.

### 2. Термодинаміка атмосфери: три фактори падіння густини

Густина газу не є сталою величиною. Вона визначається трьома незалежними параметрами довкілля: статичним барометричним тиском `p`, абсолютною термодинамічною температурою `T` та відносною вологістю `RH`.

```
p_d = ρ_d · R_d · T   →   ρ_d = p_d / (R_d · T)
```

де `R_d ≈ 287.058` Дж/(кг·К) — питома газова стала сухого повітря. З цього зв'язку випливають три головні рушії зміни густини:

1. **Висота над рівнем моря (барометричний тиск `p`):** Що вище піднімається апарат, то менший стовп атмосфери тисне згори. Зі зменшенням тиску молекули газу розташовуються далі одна від одної, і маса одиниці об'єму падає. На висоті 2000 метрів тиск становить близько 795 гПа проти 1013 гПа на рівні моря — падіння густини сягає понад 21% суто через висоту.
2. **Температура (`T`):** Температура в знаменнику рівняння стану означає, що при нагріванні газ розширюється. Кінетична енергія молекул зростає, вони сильніше розштовхуються, тому той самий об'єм містить менше маси речовини. Перехід від весняних +15 °C (288.15 К) до літньої спеки +40 °C (313.15 К) зменшує густину повітря на `1 − 288.15 / 313.15 ≈ 8.0%` навіть без зміни висоти.
3. **Вологість (водяна пара):** Це найбільш парадоксальний фактор для багатьох інженерів-початківців. Побутова інтуїція підказує, що вологе повітря «важке», бо вода асоціюється з важкою рідиною. Проте в газоподібній фазі діє закон Авогадро: за однакових тиску й температури однаковий об'єм газу містить однакову кількість молекул. Молекулярна маса водяної пари H₂O становить `M_v = 18.015` г/моль (два атоми водню по 1.008 плюс кисень 16.0), тоді як середня молекулярна маса сухого повітря (азот N₂ 28 г/моль, кисень O₂ 32 г/моль) дорівнює `M_d = 28.965` г/моль. Коли вологість зростає, легші молекули води витісняють важчі молекули азоту й кисню. **Вологе повітря завжди легше за сухе**.

За законом Дальтона повний тиск вологого повітря складається з парціального тиску сухого повітря `p_d` та парціального тиску водяної пари `p_v`: `p = p_d + p_v`. Повна густина суміші визначається як:

```
ρ = (p / (R_d · T)) · [ 1 − 0.37803 · (p_v / p) ]
```

Парціальний тиск водяної пари `p_v` розраховують через відносну вологість `RH` та тиск насиченої пари за формулою Магнуса-Тетенса. Повне математичне виведення цієї формули та концепцію віртуальної температури наведено у вставці [🧮 Виведення густини вологого повітря та формули Density Altitude](root:embedded/speka-vysota-volohist/math-density-altitude.md).

### 3. Барометрична висота проти висоти за густиною (Density Altitude)

В авіації для кількісної оцінки сукупного впливу висоти, спеки та вологості використовують поняття **висоти за густиною** (англ. *Density Altitude*, скорочено *DA*).

Для стандартизації Міжнародна організація цивільної авіації (ICAO) запровадила модель Міжнародної стандартної атмосфери (ISA, від англ. *International Standard Atmosphere*):
- рівень моря: `H = 0` м;
- стандартний тиск: `p_0 = 1013.25` гПа (101325 Па);
- стандартна температура: `T_0 = +15.0` °C (288.15 К);
- стандартна густина сухого повітря: `ρ_0 = 1.2250` кг/м³;
- вертикальний температурний градієнт: `L = 0.0065` К/м (температура спадає на 6.5 °C на кожні 1000 м підйому).

**Висота за густиною (Density Altitude)** — це висота в стандартній атмосфері ISA, на якій густина повітря точно дорівнює поточній фактичній густині повітря на майданчику.

![Концепція Density Altitude: вплив спеки та висоти на еквівалентну густину повітря](/root/course/embedded/speka-vysota-volohist/img/density-altitude-concept.svg)
*Співвідношення геодезичної висоти та Density Altitude. Зліва — стандартні умови ISA на рівні моря (густина 1.225 кг/м³). Посередині — реальний майданчик на висоті 1500 м за температури +38 °C та вологості 65% (густина 0.932 кг/м³). Справа — еквівалентна висота в атмосфері ISA (3880 м), яка має таку саму густину. Дрон аеродинамічно «відчуває» себе на висоті майже 4 кілометри над рівнем моря.*

Якщо аеродром розташований на геометричній висоті 1500 м, але надворі стоїть спека +38 °C, повітря розширюється настільки, що його густина падає до `0.932` кг/м³. У стандартній атмосфері ISA така розрідженість спостерігається лише на позначці **3880 метрів**! Це означає, що дрон, перебуваючи на висоті людського зросту над землею, летить в аеродинамічних умовах гірської вершини заввишки майже 4 кілометри.

Для швидкої практичної оцінки пілоти використовують лінійне наближення:

```
DA ≈ H_p + 118.8 · (T_ambient − T_ISA)
```

де `H_p` — барометрична висота (Pressure Altitude, м), `T_ambient` — поточна температура (°C), а `T_ISA = 15.0 − 0.0065 · H_p` — стандартна температура для цієї висоти. Просте правило пам'яті: **кожен градус перевищення температури над стандартом додає приблизно 120 метрів до ефективної висоти за густиною**.

### 4. Деградація тяги та вибухоподібне зростання енерговитрат

З'ясуймо, що відбувається з силовими установками апарата, коли густина повітря `ρ` падає нижче стандартної норми `ρ_0`.

#### Падіння максимальної тяги
Максимальні оберти двигуна `n_max` обмежені напругою акумулятора `U` та характеристикою двигуна `KV` (оберти на вольт): `n_max ≈ KV · U`. Оскільки геометричні параметри гвинта незмінні, максимальна тяга симетрично пропорційна густині:

```
T_max(ρ) = T_max_0 · (ρ / ρ_0)
```

Якщо апарат мав запас тяги до ваги `TWR_0 = T_max_0 / (m·g) = 2.0` (двократний запас) на рівні моря, то при падінні густини до `ρ / ρ_0 = 0.65` (типово для спекотного гірського плато) фактичний максимальний запас становить:

```
TWR_actual = 2.0 · 0.65 = 1.30
```

Запас тяги скоротився зі 100% надлишку до критичних 30%. Дрон стає млявим, втрачає динаміку розгону, а будь-який різкий маневр або порив вітру спричиняє неконтрольоване просідання по висоті.

#### Зростання обертів і потужності висіння
Для утримання апарата масою `m` у стаціонарному зависанні необхідна тяга не змінюється: `T_hover = m · g = const`. Запишемо умову сталості тяги через формулу рушія:

```
C_T · ρ_0 · n_0² · D⁴  =  C_T · ρ · n_hov² · D⁴
```

Скоротивши спільні множники, знаходимо закон масштабування обертів висіння:

```
n_hov = n_0 · √(ρ_0 / ρ)
```

Щоб компенсувати падіння густини на 30% (`ρ / ρ_0 = 0.70`), оберти двигунів повинні зрости в `√(1 / 0.70) ≈ 1.195` раза — тобто **на 19.5%**.

Тепер підставимо нові оберти `n_hov` у формулу механічної потужності на валу `P = C_P · ρ · n³ · D⁵`:

```
P_hov = C_P · ρ · (n_0 · √(ρ_0 / ρ))³ · D⁵      [підстановка n_hov у формулу потужності P = C_P·ρ·n³·D⁵]
      = C_P · ρ · n_0³ · (ρ_0 / ρ)^(1.5) · D⁵   [розкриття степеня куба добутку]
      = P_0 · (ρ / ρ_0) · (ρ_0 / ρ)^(1.5)       [виділення базової потужності P_0 = C_P·ρ_0·n_0³·D⁵]
      = P_0 · √(ρ_0 / ρ)                        [множення степенів: (ρ/ρ_0) · (ρ_0/ρ)^1.5 = (ρ_0/ρ)^0.5]
```

Потужність на валу, необхідна суто для компенсації сили тяжіння у зависанні, **зростає обернено пропорційно квадратному кореню з густини повітря**.

![Деградація льотних показників від густини повітря](/root/course/embedded/speka-vysota-volohist/img/thrust-power-vs-density.svg)
*Залежність характеристик силової установки від відносної густини повітря ρ/ρ₀. Червона пряма — падіння максимальної тяги T_max ∝ ρ. Синя лінія — зростання обертів та потужності висіння ∝ 1/√(ρ/ρ₀). Коричнева пунктирна крива — катастрофічне зростання теплових втрат в обмотках двигунів I²·R ∝ 1/ρ (+67% тепла при ρ = 0.60).*

### 5. Електричні втрати та подвійна теплова пастка «High & Hot»

Зростання необхідної механічної потужності `P_hov` запускає ланцюгову реакцію в електричному тракті апарата.

#### Джоулів нагрів обмоток (`I²·R`)
Струм двигуна `I` пропорційний механічній потужності `P`, поділеній на напругу шини `U`: `I ∝ P / U`. Якщо потужність зросла у `√(ρ_0 / ρ)` разів, то й фазний струм зростає у такій самій пропорції:

```
I_hov = I_0 · √(ρ_0 / ρ)
```

Теплова потужність, яка безпосередньо розсіюється на активному омічному опорі мідних обмоток двигуна `R_phase` (втрати Джоуля-Ленца), зростає у квадраті від струму:

```
P_loss_copper = I_hov² · R_phase = (I_0² · R_phase) · (ρ_0 / ρ) = P_loss_0 · (ρ_0 / ρ)
```

**Тепловиділення в двигунах зростає обернено пропорційно першому степеню густини повітря**. При падінні густини на 30% обмотки статора виділяють на 43% більше тепла щосекунди, а при падінні густини на 40% — на 67% більше тепла.

#### Подвійна теплова пастка
Чому в спеку двигуни та регулятори швидкості (ESC) згорають учетверо частіше? Працює подвійний негативний фактор:

1. **Генерація тепла різко зросла:** вищий струм збільшує нагрів обмоток (`I²·R`) та силових польових транзисторів MOSFET на платах ESC (`I²·R_DS(on)`). Опір відкритих транзисторів `R_DS(on)` має позитивний температурний коефіцієнт: нагріваючись, кристал транзистора підвищує власний опір, що ще сильніше розганяє тепловиділення.
2. **Ефективність охолодження катастрофічно впала:** конвективне тепловідведення від корпусу двигуна та радіатора ESC здійснюється набіжним повітряним потоком. Коефіцієнт тепловіддачі `h_conv` залежить від масової витрати повітря: `h_conv ∝ (ρ · v)^0.8`. У розрідженому повітрі маса газу, що контактує з радіатором за одиницю часу, менша на 20–35%. До того ж об'ємна теплоємність повітря `C_v = ρ · c_p` менша, а початкова температура середовища (+35...+45 °C) зменшує температурний напір `ΔT = T_motor − T_ambient`.

![Подвійна теплова пастка High & Hot](/root/course/embedded/speka-vysota-volohist/img/high-hot-cooling-trap.svg)
*Механізм теплового розгону в умовах High & Hot. Одночасне зростання генерації тепла в обмотках (I²R) та деградація конвективного тепловідведення призводять до нагріву понад критичні 100 °C, деградації неодимових магнітів та виходу з ладу силових ключів ESC.*

При досягненні температури статора понад 85–100 °C неодимові магніти ротора (NdFeB) зазнають **термічного розмагнічування** — незворотно втрачають залишкову магнітну індукцію `B_r`. Це призводить до зростання сталої швидкості `KV` двигуна, падіння крутного моменту на ампер струму (`K_t = 1 / KV`) та лавиноподібного збільшення робочого струму аж до повного вигорання ізоляції.

#### Просадка напруги батареї та падіння тривалості польоту
Зростання струму на 20–30% збільшує внутрішнє падіння напруги на внутрішньому омічному опорі акумулятора `R_int`:

```
U_terminal = E_emf − I · R_int
```

Через [просадку під навантаженням](root:hw-power/battery-sag) робоча напруга шини живлення просідає швидше. Контролер польоту досягає порогу відсічки розряду (Low Voltage Cutoff) значно раніше за реальне вичерпання хімічної енергії комірок. Додатково вмикається ефект Пойкерта: при вищих розрядних струмах ефективна віддавана ємність Li-Po/Li-ion батареї скорочується на 10–15%. У підсумку тривалість польоту скорочується не на 15%, а на **35–50%**.

### 6. Деградація динаміки та межі керованості автопілота

Окрім енергетики, розріджене повітря змінює динамічні характеристики апарата в замкненому контурі керування:

1. **Падіння аеродинамічного демпфування:** Аеродинамічний момент опору повороту апарата по кутах крену й тангажу прямо пропорційний густині `ρ`. У розрідженому повітрі власне аеродинамічне демпфування рами зникає. Дрон схильний до паразитних високочастотних коливань (осциляцій), якщо в налаштуваннях автопілота (Betaflight, ArduPilot, PX4) не підняти коефіцієнт `D` (диференційний член PID-регулятора).
2. **Падіння кутового прискорення:** Оскільки гвинт працює на вищих базових обертах висіння, у двигуна залишається менший динамічний запас обертів до насичення `n_max`. Відгук апарата на крен чи тангаж стає в'ялим, час реакції на порив вітру подвоюється.
3. **Небезпека вихорового кільця (Vortex Ring State, VRS):** Під час вертикального зниження лопаті потрапляють у власний турбулентний слід. У розрідженому повітрі швидкість індукованого потоку вища, а критична межа зриву потоку зміщується в зону менших швидкостей зниження. Дрон провалюється крізь власний вихор, а спроба дати повний газ лише підсилює рециркуляцію вихору, позбавляючи апарат тяги.

> 🔧 **Навіщо це.** Якщо автопілот оснащено функцією TPA (Throttle PID Attenuation) або барометричною компенсацією PID-коефіцієнтів, прошивка здатна автоматично масштабувати відгук контуру стабілізації відповідно до поточної розрахованої густини повітря `ρ / ρ_0`, запобігаючи втраті стійкості на висоті.

### 7. Практичні правила експлуатації в умовах «High & Hot»

Щоб запобігти аваріям та забезпечити виконання польотного завдання в спеку або на гірських висотах, застосовують такі перевірені інженерні практики:

1. **Оптимізація вибору гвинтів (Propeller Sizing):**
   - *Збільшення діаметра (`D`):* Найефективніший спосіб повернути втрачену тягу, оскільки `T ∝ D⁴`. Перехід із 9-дюймових гвинтів на 10-дюймові компенсує до 35% дефіциту густини. **Застереження:** момент опору росте як `D⁵`, що різко навантажує ESC по струму — обов'язково контролюйте піковий струм на стенді.
   - *Збільшення кроку лопаті (Pitch):* Дозволяє відкидати більший об'єм повітря на тих самих обертах. Проте гвинти з надто високим кроком (наприклад, 10x6 замість 10x4.5) схильні до зриву потоку на малих швидкостях та мають низький ККД у режимі висіння.
   - *Збільшення кількості лопатей:* Заміна 2-лопатевих пропелерів на 3-лопатеві того самого діаметра збільшує сумарну площу контакту з повітрям без збільшення геометричних габаритів променів рами.
2. **Зменшення злітної маси (Payload Reduction):**
   - Зменшення маси апарата на 15–20% (демонтаж вторинного обладнання, полегшення корисного навантаження) знижує необхідну тягу висіння `T_hover = m·g`.
   - *Парадокс легшої батареї:* Встановлення акумулятора меншої ємності (наприклад, 4S 3000 мАг замість 4S 5000 мАг) зменшує масу на 250 грамів. Завдяки цьому двигуни повертаються в робочу точку з вищим ККД, менше гріються, а час польоту скорочується значно менше, ніж різниця номінальних ємностей.
3. **Температурний менеджмент на майданчику:**
   - Категорично заборонено зберігати акумулятори та дрон під прямим сонячним промінням перед вильотом. Якщо початкова температура батареї становить +45 °C, внутрішній опір під навантаженням розігріє її вище безпечних +65 °C за 3 хвилини польоту.
   - Забезпечте примусовий обдув плати ESC та двигунів між вильотами.
4. **Передпольотний розрахунок запасу тяги (Checklist):**
   - Перед кожним стартом розрахуйте висоту за густиною `DA` та відносну густину `ρ / ρ_0`.
   - Перевірте розрахунковий `TWR_actual = TWR_nominal · (ρ / ρ_0)`. Якщо фактичний коефіцієнт тяги до ваги менший за `1.40`, зліт заборонено — апарат не матиме достатнього запасу керованості для безпечної посадки у вітряну погоду.
   - Зменшіть граничну швидкість вертикального зниження в налаштуваннях автопілота на 30–40% для виключення режиму вихорового кільця.

### 8. Інженерний калькулятор Density Altitude та тягового дефіциту

Нижче наведено закінчену реалізацію розрахункового модуля для прошивок безпілотників або польових діагностичних утиліт. Алгоритм приймає поточні метеодані (температуру, тиск, відносну вологість), базову масу та параметри силової установки, обчислює точну густину вологого повітря `ρ`, висоту за густиною `DA`, коефіцієнт втрати тяги, прогнозоване зростання струму та падіння тривалості польоту.

#include <stdio.h>
#include <stdbool.h>
#include <math.h>

/* Фізичні константи Міжнародної стандартної атмосфери ISA */
#define ISA_P0_PA        101325.0f   /* Стандартний тиск на рівні моря, Па */
#define ISA_T0_K         288.15f     /* Стандартна температура на рівні моря, К (+15 °C) */
#define ISA_RHO0         1.2250f     /* Стандартна густина повітря, кг/м³ */
#define ISA_LAPSE_RATE   0.0065f     /* Температурний градієнт, К/м */
#define GAS_CONST_DRY    287.058f    /* Газова стала сухого повітря, Дж/(кг·К) */

/* Структура вхідних метеорологічних та польотних параметрів */
typedef struct {
    float pressure_hpa;     /* Барометричний тиск, гПа */
    float temp_celsius;     /* Температура навколишнього повітря, °C */
    float rel_humidity_pct; /* Відносна вологість, % (0..100) */
    float nominal_twr;      /* Номінальний запас тяги TWR на рівні моря ISA (напр. 2.0) */
    float nominal_time_min; /* Номінальний час польоту на рівні моря ISA, хв */
} FlightEnvInput;

/* Структура результатів розрахунку деградації характеристик */
typedef struct {
    float air_density;       /* Фактична густина вологого повітря, кг/м³ */
    float density_ratio;     /* Відносна густина (rho / rho0) */
    float pressure_alt_m;    /* Барометрична висота Pressure Altitude, м */
    float density_alt_m;     /* Висота за густиною Density Altitude, м */
    float actual_twr;        /* Фактичний максимальний запас тяги до ваги */
    float hover_rpm_mult;    /* Множник необхідних обертів висіння (n / n0) */
    float hover_current_mult;/* Множник струму висіння (I / I0) */
    float copper_heat_mult;  /* Множник виділення тепла в обмотках I²R */
    float est_flight_time_m; /* Оцінкова тривалість польоту, хв */
    bool  is_safe_to_fly;    /* Чи безпечно здійснювати виліт (TWR >= 1.4) */
} AeroDensityReport;

/*
 * Розрахунок параметрів атмосфери та деградації силової установки.
 * Повертає false при некоректних вхідних даних (від'ємний тиск, нереальна температура).
 */
bool calculate_flight_degradation(const FlightEnvInput* in, AeroDensityReport* out) {
    if (!in || !out) return false;
    if (in->pressure_hpa < 300.0f || in->pressure_hpa > 1100.0f) return false;
    if (in->temp_celsius < -50.0f || in->temp_celsius > 65.0f) return false;
    if (in->rel_humidity_pct < 0.0f || in->rel_humidity_pct > 100.0f) return false;
    if (in->nominal_twr <= 0.5f) return false;

    float p_pa = in->pressure_hpa * 100.0f;
    float t_k = in->temp_celsius + 273.15f;

    /* 1. Тиск насиченої пари за формулою Магнуса-Тетенса (у Па) */
    float p_sat_pa = 610.78f * expf((17.27f * in->temp_celsius) / (237.3f + in->temp_celsius));
    float p_v_pa = (in->rel_humidity_pct / 100.0f) * p_sat_pa;

    /* 2. Точна густина вологого повітря за законом Дальтона */
    float rho = (p_pa / (GAS_CONST_DRY * t_k)) * (1.0f - 0.37803f * (p_v_pa / p_pa));
    out->air_density = rho;

    float rho_rel = rho / ISA_RHO0;
    out->density_ratio = rho_rel;

    /* 3. Барометрична висота (Pressure Altitude) */
    out->pressure_alt_m = 44330.8f * (1.0f - powf(p_pa / ISA_P0_PA, 0.190263f));

    /* 4. Точна висота за густиною (Density Altitude) з формули тропосфери ISA */
    out->density_alt_m = 44330.8f * (1.0f - powf(rho_rel, 0.23497f));

    /* 5. Деградація максимальної тяги та TWR */
    out->actual_twr = in->nominal_twr * rho_rel;

    /* 6. Зростання обертів, потужності та струму зависання */
    float hover_scale = 1.0f / sqrtf(rho_rel);
    out->hover_rpm_mult = hover_scale;
    out->hover_current_mult = hover_scale;
    out->copper_heat_mult = 1.0f / rho_rel;

    /* 7. Оцінка часу польоту з урахуванням просадки напруги та ККД */
    float time_reduction_factor = powf(rho_rel, 0.75f);
    out->est_flight_time_m = in->nominal_time_min * time_reduction_factor;

    /* 8. Критерій безпеки вильоту */
    out->is_safe_to_fly = (out->actual_twr >= 1.40f);

    return true;
}

#include <iostream>
#include <cmath>
#include <numbers>
#include <expected>

#include <format>

namespace aero {

// Фізичні константи Міжнародної стандартної атмосфери ISA
inline constexpr float isa_p0_pa        = 101325.0f;
inline constexpr float isa_t0_k         = 288.15f;
inline constexpr float isa_rho0         = 1.2250f;
inline constexpr float gas_const_dry    = 287.058f;
inline constexpr float density_exp      = 0.23497f;
inline constexpr float pressure_exp     = 0.190263f;
inline constexpr float scale_height_m   = 44330.8f;

struct FlightEnv {
    float pressure_hpa;     // Барометричний тиск, гПа
    float temp_celsius;     // Температура повітря, °C
    float rel_humidity_pct; // Відносна вологість, % (0..100)
    float nominal_twr;      // Номінальний TWR на рівні моря ISA
    float nominal_time_min; // Номінальний час польоту ISA, хв
};

struct FlightReport {
    float air_density_kg_m3;
    float density_ratio;
    float pressure_alt_m;
    float density_alt_m;
    float actual_twr;
    float hover_rpm_multiplier;
    float hover_current_multiplier;
    float copper_heat_multiplier;
    float estimated_time_min;
    bool  is_safe_to_fly;
};

enum class InputError {
    InvalidPressure,
    InvalidTemperature,
    InvalidHumidity,
    InvalidTwr
};

[[nodiscard]] constexpr std::expected<FlightReport, InputError>
evaluate_flight_conditions(const FlightEnv& env) noexcept {
    if (env.pressure_hpa < 300.0f || env.pressure_hpa > 1100.0f) {
        return std::unexpected(InputError::InvalidPressure);
    }
    if (env.temp_celsius < -50.0f || env.temp_celsius > 65.0f) {
        return std::unexpected(InputError::InvalidTemperature);
    }
    if (env.rel_humidity_pct < 0.0f || env.rel_humidity_pct > 100.0f) {
        return std::unexpected(InputError::InvalidHumidity);
    }
    if (env.nominal_twr <= 0.5f) {
        return std::unexpected(InputError::InvalidTwr);
    }

    const float p_pa = env.pressure_hpa * 100.0f;
    const float t_k  = env.temp_celsius + 273.15f;

    // Тиск насиченої пари (Магнус-Тетенс)
    const float p_sat_pa = 610.78f * std::exp((17.27f * env.temp_celsius) / (237.3f + env.temp_celsius));
    const float p_v_pa   = (env.rel_humidity_pct / 100.0f) * p_sat_pa;

    // Густина вологого повітря за законом Дальтона
    const float rho = (p_pa / (gas_const_dry * t_k)) * (1.0f - 0.37803f * (p_v_pa / p_pa));
    const float rho_rel = rho / isa_rho0;

    const float p_alt_m = scale_height_m * (1.0f - std::pow(p_pa / isa_p0_pa, pressure_exp));
    const float d_alt_m = scale_height_m * (1.0f - std::pow(rho_rel, density_exp));

    const float actual_twr = env.nominal_twr * rho_rel;
    const float hover_scale = 1.0f / std::sqrt(rho_rel);

    return FlightReport{
        .air_density_kg_m3       = rho,
        .density_ratio           = rho_rel,
        .pressure_alt_m          = p_alt_m,
        .density_alt_m           = d_alt_m,
        .actual_twr              = actual_twr,
        .hover_rpm_multiplier    = hover_scale,
        .hover_current_multiplier= hover_scale,
        .copper_heat_multiplier  = 1.0f / rho_rel,
        .estimated_time_min      = env.nominal_time_min * std::pow(rho_rel, 0.75f),
        .is_safe_to_fly          = (actual_twr >= 1.40f)
    };
}

### Підсумок

Льотні характеристики безпілотника визначаються не геодезичною висотою майданчика, а масою повітря, яку захоплюють і прискорюють лопаті його гвинтів. Спека, висота та вологість створюють потрійний синергетичний ефект розрідження атмосфери:
- **Максимальна тяга** падає прямо пропорційно густині повітря `ρ`, скорочуючи критичний запас керованості TWR.
- **Оберти та потужність висіння** зростають як `1 / √(ρ/ρ_0)`, змушуючи двигуни працювати на підвищених струмах.
- **Теплові втрати в обмотках (`I²·R`)** зростають обернено пропорційно `ρ`, що в поєднанні з погіршенням конвективного охолодження створює ризик теплового розгону та розмагнічування двигунів.
- **Передпольотний розрахунок Density Altitude** є обов'язковою інженерною процедурою: своєчасне збільшення діаметра пропелерів або зниження злітної маси повертає апарату проектну надійність у найсуворіших кліматичних умовах.
