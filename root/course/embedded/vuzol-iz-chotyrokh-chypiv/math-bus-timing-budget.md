# 🧮 Розрахунок таймінгів шин, ємнісного навантаження та перехресних завад

Цей інженерний розрахунок надає математичне обґрунтування часових параметрів, опорів підтяжки та геометрії друкованих провідників для сумісної роботи швидкісної шини SPI (50 МГц) та високоомної шини I2C (400 кГц) у чотиричиповому вузлі збору даних.

---

## 1. Розрахунок часового бюджету та резисторів підтяжки шини I2C

Шина I2C використовує топологію з відкритим колектором (відкритим стоком). Перехід лінії з низького рівня у високий забезпечується виключно зовнішнім резистором підтяжки `R_pullup` та сумарною паразитною ємністю шини `C_bus`.

```
        +3.3V
          |
       [R_pullup]
          |
SDA/SCL --+--------+-----------+-----------+
          |        |           |           |
       [ C_pin ] [ C_pin ]  [ C_pin ]   [ C_trace ]
        ( STM32 ) ( BME280 ) ( DS3231 )  ( PCB )
```

### Сумарна ємність шини

Сумарна ємність лінії `C_bus` складається з вхідних ємностей усіх підключених виводів та погонної ємності друкованої доріжки:

```
C_bus = C_mcu + C_bme + C_rtc + C_trace + C_stray  [сума складових ємностей]
```

Значення параметрів за технічною документацією компонентів:
* Вхідна ємність піна STM32 (`C_mcu`): `5.0 пФ`
* Вхідна ємність піна BME280 (`C_bme`): `4.5 пФ`
* Вхідна ємність піна DS3231 (`C_rtc`): `10.0 пФ`
* Погонна ємність мікросмужкової лінії на текстоліті FR-4 (`w = 0.2 мм`, `h = 0.2 мм`, `ε_r = 4.2`): `C_per_cm ≈ 1.1 пФ/см`
* Довжина траси на платі `L = 6.5 см` → `C_trace = 6.5 · 1.1 = 7.15 пФ`
* Паразитна ємність монтажних майданчиків та переходів (`C_stray`): `3.35 пФ`

Розрахунок загальної ємності:

```
C_bus = 5.0 + 4.5 + 10.0 + 7.15 + 3.35  [підстановка значень компонентів]
      = 30.0 пФ                         [підсумок сумарної ємності]
```

### Визначення допустимого діапазону `R_pullup` для режиму Fast Mode (400 кГц)

Стандарт I2C для частоти 400 кГц задає максимальний час наростання фронту `t_r ≤ 300 нс` від рівня `V_IL = 0.3 · V_DD` (0.99 В) до `V_IH = 0.7 · V_DD` (2.31 В).

Заряд конденсатора `C_bus` через резистор `R_pullup` описується експоненційним законом:

```
V(t) = V_DD · (1 - e^(-t / (R · C)))    [експоненційний заряд ємності]
```

Час досягнення рівня `0.3 · V_DD`:

```
t1 = -R · C · ln(1 - 0.3)               [рівняння для порогу 0.3 VDD]
   = -R · C · ln(0.70)                  [обчислення аргументу логарифма]
   = 0.3567 · R · C                     [значення коефіцієнта -ln(0.70)]
```

Час досягнення рівня `0.7 · V_DD`:

```
t2 = -R · C · ln(1 - 0.7)               [рівняння для порогу 0.7 VDD]
   = -R · C · ln(0.30)                  [обчислення аргументу логарифма]
   = 1.2040 · R · C                     [значення коефіцієнта -ln(0.30)]
```

Тривалість наростання фронту `t_r`:

```
t_r = t2 - t1                           [різниця часових відліків]
    = (1.2040 - 0.3567) · R_pullup · C_bus [віднімання коефіцієнтів]
    = 0.8473 · R_pullup · C_bus         [підсумкова формула часу наростання]
```

Звідси максимальний опір підтяжки `R_max`:

```
R_max = t_r_max / (0.8473 · C_bus)       [вираження опору з формули t_r]
      = 300 · 10⁻⁹ / (0.8473 · 30.0 · 10⁻¹²) [підстановка часового ліміту 300 нс]
      = 300 · 10⁻⁹ / (25.419 · 10⁻¹²)    [обчислення знаменника]
      = 11802 Ом ≈ 11.8 кОм              [максимальний опір підтяжки]
```

Мінімальний опір підтяжки `R_min` обмежується максимально допустимим струмом вихідного транзистора `I_OL = 3 мА` при напрузі низького рівня `V_OL ≤ 0.4 В`:

```
R_min = (V_DD - V_OL) / I_OL             [закон Ома для струму насичення]
      = (3.3 - 0.4) / (3.0 · 10⁻³)       [підстановка напруг та струму 3 мА]
      = 2.9 / 0.003                      [падіння напруги на резисторі]
      = 966.7 Ом ≈ 967 Ом                [мінімальний допустимий опір]
```

**Інженерний вибір:** Для забезпечення швидких фронтів (`t_r ≈ 56 нс`), високої завадостійкості та помірного енергоспоживання обирається стандартний номінал **`R_pullup = 2.2 кОм`** (струм при логічному нулі `I_sink = 3.3 В / 2.2 кОм = 1.5 мА`, що удвічі нижче межі насичення вихідного каскаду).

## 2. Часовий бюджет та обмеження петлі затримок шини SPI (50 МГц)

При роботі мікросхеми Flash W25Q128JV на тактовій частоті `f_sck = 50 МГц` період тактового сигналу становить `T_clk = 20.0 нс`. Тривалість напівперіоду (High/Low) дорівнює `10.0 нс`.

### Петля зворотного зв'язку при зчитуванні даних (MISO Loop Delay)

Під час транзакції читання мікроконтролер виставляє спадний фронт SCK, сигнал доходить до Flash, пам'ять виставляє біт на лінію MISO, і сигнал повертається до мікроконтролера, де має бути зафіксований до наступного тактового фронту з запасом на час встановлення (`t_setup`).

```
T_clk ≥ t_co_mcu + t_prop_sck + t_co_flash + t_prop_miso + t_su_mcu  [умова синхронного захоплення]
```

Параметри за документацією:
* Затримка генерації SCK в МК (`t_co_mcu`): `1.5 нс`
* Час виходу даних Flash W25Q128 (`t_co_flash`): `6.0 нс` (при `C_L = 15 пФ`)
* Час встановлення вхідного тригера МК (`t_su_mcu`): `2.5 нс`
* Швидкість поширення сигналу у мікросмужковій лінії на FR-4:

```
v = c₀ / √(ε_r_eff)                     [швидкість ЕМ хвилі в діелектрику]
  = 3 · 10⁸ / √(3.1)                    [підстановка ефективної проникності]
  ≈ 1.7 · 10⁸ м/с = 17 см/нс            [швидкість поширення сигналів]
```

Затримка поширення на 1 см траси: `t_pd = 1 / 17 ≈ 0.059 нс/см` (59 пс/см).

При довжині траси на платі `L_spi = 3.5 см`:

```
t_prop_sck = t_prop_miso = 3.5 · 0.059 = 0.207 нс  [затримка траси 35 мм]
```

Підсумок затримок петлі читання:

```
t_total = 1.5 [t_co_mcu] + 0.207 [t_prop_sck] + 6.0 [t_co_flash] + 0.207 [t_prop_miso] + 2.5 [t_su_mcu]
        = 10.414 нс                     [повна затримка кругового циклу]
```

Запас за часом (Timing Margin) для частоти 50 МГц (`T_clk = 20.0 нс`):

```
T_margin = T_clk - t_total              [обчислення запасу стійкості]
         = 20.0 - 10.414                [віднімання затримок від періоду]
         = 9.586 нс                     [підсумковий часовий запас]
```

**Висновок:** Запас у 9.58 нс гарантує стабільну роботу SPI Mode 0/3 без використання спеціальних фазових зсувів або апаратних ліній зворотного тактування (DQS).

### Узгодження хвильового імпедансу доріжки SPI

Хвильовий опір мікросмужкової лінії `Z_0` для геометрії `w = 0.2 мм`, `h = 0.2 мм`, `t = 35 мкм`, `ε_r = 4.2` становить приблизно `55 Ом`.
Вихідний опір драйвера виводу STM32 у режимі High-Speed дорівнює `R_out ≈ 22 Ом`.

Для усунення хвильових відбиттів на крутих фронтах (`t_rise = 1.5 нс`) на стороні передавача встановлюється послідовний демпфуючий резистор `R_damping`:

```
R_damping = Z_0 - R_out                  [умова узгодження вихідного імпедансу]
          = 55 - 22                      [різниця хвильового та вихідного опорів]
          = 33 Ом                        [номінал послідовного резистора]
```

Номінал **`33 Ом`**, розміщений впритул до виводів SCK/MOSI мікроконтролера, зрізає паразитні дзвінки та обмежує високочастотне випромінювання.

## 3. Математична модель перехресних завад (Crosstalk) між SPI та I2C

Ємнісний зв'язок між паралельними провідниками на друкованій платі спричиняє індукцію струму завади `I_noise` у сусідню лінію при кожному перемиканні швидкісного сигналу SPI SCK:

```
I_noise = C_m · (dV_sck / dt)           [ємнісний струм зміщення]
```

де:
* `C_m` — взаємна паразитна ємність між доріжками;
* `dV_sck / dt` — швидкість наростання напруги на тактовій лінії SPI (`3.3 В / 1.5 нс = 2.2 · 10⁹ В/с`).

### Порівняння конфігурацій трасування

Напруга завади `V_noise`, що наводиться на високоомну лінію I2C (`R_eq = R_pullup || R_in ≈ 2.2 кОм`), обчислюється як:

```
V_noise = I_noise · R_eq
        = C_m · (dV_sck / dt) · R_eq    [падіння напруги на еквівалентному опорі]
```

#### Варіант А: Паралельні доріжки без зазору (відстань `S = W = 0.2 мм`, довжина паралельної ділянки `L = 25 мм`)

Взаємна ємність `C_m ≈ 0.18 пФ/см` → для 2.5 см: `C_m = 0.45 пФ`.

```
V_noise = 0.45 · 10⁻¹² · (2.2 · 10⁹) · 2200  [підстановка параметрів для зазору 1W]
        = 0.45 · 2.2 · 2.2 · 10⁻¹² · 10⁹ · 10³ [групування числових множників]
        = 2.178 В                       [наведена амплітуда імпульсного шуму]
```

**Результат:** Амплітуда сплеску `2.18 В` перевищує поріг спрацьовування логічного нуля КМОН (`0.3 · V_DD = 0.99 В`). Контролер I2C або датчик BME280 розпізнає заваду як хибний тактовий імпульс або перехід шини, що призводить до зависання апаратного автомата стану.

#### Варіант Б: Застосування правила 3W (`S = 3 · W = 0.6 мм`) та охоронної доріжки Guard Trace

Взаємна ємність з охоронною лінією, прошитою перехідними отворами на шар GND, падає до `C_m ≤ 0.008 пФ/см` → для 2.5 см: `C_m = 0.02 пФ`.

```
V_noise = 0.02 · 10⁻¹² · (2.2 · 10⁹) · 2200  [підстановка параметрів для правила 3W]
        = 0.02 · 2.2 · 2.2              [спрощення степенів]
        = 0.0968 В = 96.8 мВ            [залишкова завада після екранування]
```

**Результат:** Амплітуда завади менше `100 мВ`, що вдесятеро нижче порогу перемикання цифрових входів і гарантує абсолютну стабільність шини I2C під час безперервного обміну по SPI.

## 4. Енергетичний баланс та розрахунок автономності

Вузол працює за циклічним профілем опитування з періодом `T_period = 10 с` (0.1 Гц або 1 Гц).

### Струмовий профіль активної фази (тривалість `t_active = 12.5 мс`):
1. Пробудження ядра STM32 (80 МГц): `I_mcu = 14.5 мА`
2. Зчитування BME280 (I2C 400 кГц, 1.2 мс): `I_bme = 0.7 мА`
3. Зчитування мітки часу DS3231 (0.8 мс): `I_rtc = 0.2 мА`
4. Запис порції даних у W25Q128 (SPI 50 МГц, 256 байтів, 0.8 мс): `I_flash = 18.0 мА`
5. Відповідь через трансивер SN65HVD72 на термінатор 54 Ом (2.5 мс): `I_485 = 45.0 мА`

Середньозважений струм під час активного вікна:

```
I_active = (14.5 · 12.5 + 0.7 · 1.2 + 0.2 · 0.8 + 18.0 · 0.8 + 45.0 · 2.5) / 12.5  [зважування струмів]
         = (181.25 + 0.84 + 0.16 + 14.4 + 112.5) / 12.5 [сума часток споживання]
         = 309.15 / 12.5                [ділення на тривалість активного вікна]
         = 24.73 мА                     [середній активний струм]
```

### Струмовий профіль фази сну (`t_sleep = 9987.5 мс`):
* STM32 у режимі Stop 2 з пробудженням по EXTI: `I_mcu_sleep = 5.2 мкА`
* BME280 у режимі Sleep: `I_bme_sleep = 0.2 мкА`
* DS3231 живлення від VCC: `I_rtc_sleep = 1.5 мкА`
* W25Q128 у режимі Deep Power-Down: `I_flash_sleep = 1.0 мкА`
* SN65HVD72 у режимі Shutdown (`/RE = 1`, `DE = 0`): `I_485_sleep = 0.1 мкА`

Загальний струм сну:

```
I_sleep = 5.2 + 0.2 + 1.5 + 1.0 + 0.1   [підсумок струмів витоку в сні]
        = 8.0 мкА                       [базовий струм у режимі Stop 2]
```

### Середній інтегральний струм споживання вузла

```
I_avg = (I_active · t_active + I_sleep · t_sleep) / T_period  [інтеграл споживання за період]
      = (24.73 · 10⁻³ · 0.0125 + 8.0 · 10⁻⁶ · 9.9875) / 10.0 [підстановка активної та пасивної фаз]
      = (0.0003091 + 0.0000799) / 10.0  [сума енергії фаз]
      = 0.000389 / 10.0                 [усереднення на період 10 с]
      = 38.9 мкА                        [середній струм вузла]
```

При живленні від акумуляторної батареї LiFePO4 ємністю `1500 мА·год` теоретичний термін безперервної автономної роботи вузла становить:

```
T_life = 1500 мА·год / 0.0389 мА        [ділення ємності батареї на середній струм]
       = 38560 годин                    [тривалість роботи в годинах]
       ≈ 4.4 року                       [оцінка автономності в роках]
```
