# 🧮 Точний розрахунок коефіцієнтів Стейнгарта-Гарта за трьома точками

Рівняння Стейнгарта-Гарта (англ. *Steinhart-Hart equation*) перетворює виміряний опір напівпровідникового NTC-термістора на абсолютну температуру з похибкою менше ніж 0.01 °C у діапазоні 100 °C. Паспортний B-параметр дає швидку оцінку, але на краях робочого інтервалу його похибка досягає 1–3 °C через нелінійну зміну енергії активації носіїв заряду. Тут виведено систему лінійних рівнянь для трьох експериментальних точок калібрування, подано точний аналітичний розв'язок за правилом Крамера, розраховано матричні визначники для типового термістора 10 кОм та проаналізовано поширення похибок вимірювання на коефіцієнти моделі.

---

## 1. Фізичне підґрунтя моделі та вибір калібрувальних точок

Електрична провідність напівпровідникової оксидної кераміки терморезисторів визначається активаційним перенесенням носіїв заряду між локалізованими центрами перехідних металів (іонами `Mn³⁺` та `Mn⁴⁺`). У вузькому інтервалі температур провідність наближено підпорядковується закону Арреніуса, проте зі зміною температури від −40 °C до +125 °C ефективна енергія активації зазнає повільного дрейфу через перебудову фононного спектра кристалічної ґратки.

Класична емпірична модель Стейнгарта-Гарта апроксимує цю складну квантову залежність розкладом зворотної абсолютної температури `1/T` (у Кельвінах) за степенями натурального логарифма електричного опору `ln(R)`:

```
1/T = A + B·ln(R) + C·(ln(R))³
```

Квадратичний член `(ln(R))²` у рівнянні навмисно опущено. Дослідження Стейнгарта та Гарта показали, що для полікристалічних оксидних керамік коефіцієнт при другому степені логарифма є практично нульовим (на два-три порядки меншим за лінійний і кубічний внески). Виключення квадратичного члена значно покращує числову обумовленість матриці системи та усуває паразитні осциляції апроксимаційного полінома між вузлами калібрування.

Для визначення трьох невідомих коефіцієнтів `A`, `B`, `C` необхідно провести калібрувальні вимірювання опору `R₁, R₂, R₃` за трьох точно відомих температур `T₁, T₂, T₃`. Щоб мінімізувати максимальну залишкову похибку інтерполяції (мінімаксний критерій Чебишова), точки калібрування розташовують на нижній межі, у центрі та на верхній межі планового робочого діапазону:

- Точка 1 (нижня робоча межа): `t₁ = 0.0 °C` → `T₁ = 273.15 K`, виміряний опір `R₁ = 32650 Ом`;
- Точка 2 (опорний центр): `t₂ = 25.0 °C` → `T₂ = 298.15 K`, виміряний опір `R₂ = 10000 Ом`;
- Точка 3 (верхня робоча межа): `t₃ = 85.0 °C` → `T₃ = 358.15 K`, виміряний опір `R₃ = 1070 Ом`.

Для спрощення подальших алгебраїчних виразів перейдемо до логарифмічних координат `L = ln(R)` та зворотної температури `Y = 1/T`:

```
L₁ = ln(R₁) = ln(32650) ≈ 10.39359
L₂ = ln(R₂) = ln(10000) ≈ 9.21034
L₃ = ln(R₃) = ln(1070)  ≈ 6.97541

Y₁ = 1 / T₁ = 1 / 273.15 ≈ 0.00366099
Y₂ = 1 / T₂ = 1 / 298.15 ≈ 0.00335402
Y₃ = 1 / T₃ = 1 / 358.15 ≈ 0.00279213
```

## 2. Побудова системи лінійних алгебраїчних рівнянь

Підставляючи експериментальні координати трьох точок у базове рівняння Стейнгарта-Гарта, формуємо систему трьох лінійних рівнянь відносно вектора невідомих коефіцієнтів `[A, B, C]ᵀ`:

```
A + B·L₁ + C·L₁³ = Y₁
A + B·L₂ + C·L₂³ = Y₂
A + B·L₃ + C·L₃³ = Y₃
```

У векторно-матричній формі `M · X = Y`:

```
┌                  ┐   ┌   ┐   ┌    ┐
│ 1   L₁    L₁³   │   │ A │   │ Y₁ │
│ 1   L₂    L₂³   │ · │ B │ = │ Y₂ │
│ 1   L₃    L₃³   │   │ C │   │ Y₃ │
└                  ┘   └   ┘   └    ┘
```

Матриця `M` є узагальненою матрицею Вандермонда з пропущеним квадратичним стовпчиком. Її невиродженість та числова стабільність забезпечуються монотонним спаданням опору термістора при збільшенні температури.

## 3. Аналітичне виведення коефіцієнтів за методом Крамера

Обчислимо визначник основної матриці системи `Δ = det(M)`:

```
Δ = 1·(L₂·L₃³ − L₃·L₂³) − 1·(L₁·L₃³ − L₃·L₁³) + 1·(L₁·L₂³ − L₂·L₁³)   [розклад за елементами першого стовпчика]
  = L₂·L₃·(L₃² − L₂²) − L₁·L₃·(L₃² − L₁²) + L₁·L₂·(L₂² − L₁²)             [винесення спільних множників]
  = (L₂ − L₁)·(L₃ − L₁)·(L₃ − L₂)·(L₁ + L₂ + L₃)                           [факторизація різниці кубів]
```

Оскільки всі три калібрувальні температури строго різні, логарифми опорів задовольняють нерівність `L₁ > L₂ > L₃ > 0`, отже, всі різниці `(L₂ − L₁)`, `(L₃ − L₁)`, `(L₃ − L₂)` ненульові, а сума `L₁ + L₂ + L₃ > 0`. Визначник `Δ ≠ 0`, що строго гарантує існування та єдиність розв'язку.

Для послідовного виключення коефіцієнта `A` віднімемо перше рівняння від другого та третього:

```
(1)  B·(L₂ − L₁) + C·(L₂³ − L₁³) = Y₂ − Y₁    [віднімання 1-го рівняння від 2-го]
(2)  B·(L₃ − L₁) + C·(L₃³ − L₁³) = Y₃ − Y₁    [віднімання 1-го рівняння від 3-го]
```

Використовуючи алгебраїчну формулу різниці кубів `a³ − b³ = (a − b)·(a² + a·b + b²)`:

```
L₂³ − L₁³ = (L₂ − L₁) · (L₂² + L₁·L₂ + L₁²)    [розклад різниці кубів для 1-ї пари]
L₃³ − L₁³ = (L₃ − L₁) · (L₃² + L₁·L₃ + L₁²)    [розклад різниці кубів для 2-ї пари]
```

Поділимо перше рівняння на ненульову різницю `(L₂ − L₁)`, а друге — на `(L₃ − L₁)`:

```
B + C · (L₁² + L₁·L₂ + L₂²) = (Y₂ − Y₁) / (L₂ − L₁)    [скорочення спільного множника (L₂ − L₁)]
B + C · (L₁² + L₁·L₃ + L₃²) = (Y₃ − Y₁) / (L₃ − L₁)    [скорочення спільного множника (L₃ − L₁)]
```

Введемо коефіцієнти нахилу січної `γ₁` та `γ₂`:

```
γ₁ = (Y₂ − Y₁) / (L₂ − L₁)
γ₂ = (Y₃ − Y₁) / (L₃ − L₁)
```

Віднімаючи отримані лінійні вирази один від одного, знаходимо аналітичний вираз для коефіцієнта `C`:

```
C · [(L₁² + L₁·L₃ + L₃²) − (L₁² + L₁·L₂ + L₂²)] = γ₂ − γ₁   [віднімання лінеаризованих рівнянь]
C · [L₁·(L₃ − L₂) + (L₃² − L₂²)] = γ₂ − γ₁                  [спрощення різниці квадратів]
C · (L₃ − L₂) · (L₁ + L₂ + L₃) = γ₂ − γ₁                    [винесення множника (L₃ − L₂)]

C = (γ₂ − γ₁) / ((L₃ − L₂) · (L₁ + L₂ + L₃))                 [кінцева формула коефіцієнта C]
```

Знаючи `C`, знаходимо коефіцієнти `B` та `A`:

```
B = γ₁ − C · (L₁² + L₁·L₂ + L₂²)    [вираження коефіцієнта B]
A = Y₁ − B·L₁ − C·L₁³                [вираження коефіцієнта A]
```

## 4. Числовий розрахунок для калібрувального прикладу 10 кОм NTC

Підставимо числові значення калібрувальних точок:

```
L₁ = 10.39359,   Y₁ = 0.00366099
L₂ = 9.21034,    Y₂ = 0.00335402
L₃ = 6.97541,    Y₃ = 0.00279213

L₂ − L₁ = 9.21034 − 10.39359 = −1.18325
L₃ − L₁ = 6.97541 − 10.39359 = −3.41818
L₃ − L₂ = 6.97541 − 9.21034  = −2.23493

L₁ + L₂ + L₃ = 10.39359 + 9.21034 + 6.97541 = 26.57934

Y₂ − Y₁ = 0.00335402 − 0.00366099 = −0.00030697
Y₃ − Y₁ = 0.00279213 − 0.00366099 = −0.00086886

γ₁ = −0.00030697 / −1.18325 ≈ 0.00025943
γ₂ = −0.00086886 / −3.41818 ≈ 0.00025419

γ₂ − γ₁ = 0.00025419 − 0.00025943 = −0.00000524
Знаменник C = (L₃ − L₂) · (L₁ + L₂ + L₃) = −2.23493 · 26.57934 = −59.4030

C = −0.00000524 / −59.4030 ≈ 8.8211 · 10⁻⁸
```

Розраховуємо коефіцієнт `B`:

```
L₁² + L₁·L₂ + L₂²
= (10.39359)² + (10.39359)·(9.21034) + (9.21034)²     [підстановка логарифмів L₁ та L₂]
= 108.0267 + 95.7285 + 84.8304                        [піднесення до квадрата і добуток]
= 288.5856                                            [сума доданків]

B = 0.00025943 − (8.8211 · 10⁻⁸ · 288.5856)           [віднімання кубічної поправки від γ₁]
  = 0.00025943 − 0.00002546                           [множення C на суму квадратів]
  = 2.3397 · 10⁻⁴                                     [результат коефіцієнта B]
```

Розраховуємо коефіцієнт `A`:

```
L₁³ = (10.39359)³ ≈ 1122.786

A = 0.00366099 − (2.3397 · 10⁻⁴ · 10.39359) − (8.8211 · 10⁻⁸ · 1122.786) [підстановка B та C в перше рівняння]
  = 0.00366099 − 0.00243179 − 0.00009904                                    [віднімання лінійного і кубічного членів]
  = 1.13016 · 10⁻³                                                           [результат коефіцієнта A]
```

Отриманий вектор коефіцієнтів Стейнгарта-Гарта:

```
A = 1.13016 · 10⁻³
B = 2.33970 · 10⁻⁴
C = 8.82110 · 10⁻⁸
```

## 5. Оцінка залишкової нелінійності та поширення похибок

Перевіримо точність калібрування в проміжній контрольній точці `t = 50.0 °C` (`T = 323.15 K`), якій відповідає виміряний опір термістора `R = 3603 Ом`:

```
ln(R) = ln(3603) ≈ 8.18952                             [логарифм контрольного опору]

1/T_calc
= A + B·(8.18952) + C·(8.18952)³                       [підстановка в рівняння Стейнгарта-Гарта]
= 0.00113016 + 0.00191610 + 0.00004845                 [обчислення трьох членів ряду]
= 0.00309471 K⁻¹                                       [сума зворотної температури]

T_calc = 1 / 0.00309471 ≈ 323.132 K                    [обернення в градуси Кельвіна]
t_calc = 323.132 − 273.15 = 49.982 °C                  [переведення в шкалу Цельсія]
```

Залишкова абсолютна похибка апроксимації становить:

```
Δt = 49.982 − 50.000 = −0.018 °C
```

Для порівняння, проста модель за B-параметром (`B₂₅/₈₅ = 3950 K`), прив'язана до точок 25 °C та 85 °C, у цій же самій контрольній точці дає похибку `+0.42 °C`. Застосування рівняння Стейнгарта-Гарта зменшує похибку моделювання більш ніж у 23 рази.

## 6. Числова стійкість та правила вибору калібрувальних точок

Числова стійкість розв'язку системи залежить від числа обумовленості матриці `cond(M)`. Якщо калібрувальні точки обрати занадто близько одна до одної (наприклад, 20 °C, 25 °C та 30 °C), різниці логарифмів `(L₂ − L₁)` стають надзвичайно малими, що спричиняє катастрофічну втрату точності (англ. *catastrophic cancellation*) при обчисленнях з обмеженою розрядністю.

При правильному рознесенні точок по краях робочого інтервалу (0 °C, 25 °C, 85 °C) число обумовленості є мінімальним, а матриця стабільно розв'язується навіть на мікроконтролерах із 32-бітною арифметикою з плаваючою комою.

### Чутливість моделі до метрологічних похибок калібрування

Під час проведення калібрування в рідинному термостаті похибки вимірювання еталонної температури `δT` та опору `δR` переносяться на вихідні коефіцієнти. Дослідимо чутливість функції температури через частинні похідні (коефіцієнти чутливості):

```
dT / dR = −T² · (B/R + 3·C·(ln(R))² / R)
```

При кімнатній температурі (+25 °C, `R = 10000 Ом`):

```
dT / dR ≈ −(298.15)² · (2.3397·10⁻⁴ / 10000 + 3·8.82·10⁻⁸·(9.21)² / 10000)
        ≈ −88893 · (2.3397·10⁻⁸ + 2.245·10⁻⁸)
        ≈ −88893 · (4.585·10⁻⁸)
        ≈ −0.00407 °C / Ом = −4.07 мК / Ом
```

Це означає, що похибка вимірювання опору в 1 Ом на рівні 10 кОм (відносна похибка 0.01%) призводить до зміщення розрахованої температури всього на `0.004 °C`. Відповідно, використання прецизійного мультиметра класу 0.02% та еталонного платинового термометра опору Pt100 (клас точності 1/10 DIN, ±0.03 °C) дозволяє отримати абсолютну точність вимірювального тракту краще ніж `±0.05 °C` у всьому робочому діапазоні.
