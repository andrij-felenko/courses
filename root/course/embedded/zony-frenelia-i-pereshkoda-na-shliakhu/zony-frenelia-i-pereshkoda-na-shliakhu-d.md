Під час розгортання радіомосту між двома телеметричними вузлами на відстані 5 км інженери нерідко стикаються з незрозумілою поведінкою зв'язку. Передавач LoRa на частоті 868 МГц має вихідну потужність `+20 дБм` (100 мВт), на обох кінцях встановлено спрямовані антени з підсиленням `+8 дБі`, а чутливість приймача становить `-135 дБм`. Розрахунок за рівнянням Фрііса для вільного простору обіцяє рівень сигналу на вході приймача `-89 дБм`, що дає комфортний запас у 46 дБ над порогом демодуляції. В оптичний бінокль антена приймача чітко проглядається над верхівками лісового масиву. Проте після увімкнення приймач фіксує рівень сигналу лише `-128 дБм`, пакети масово губляться, а під час дощу канал повністю розривається.

Причина цієї аварії криється в оманливій аналогії між світловим променем геометричної оптики та поширенням радіохвиль. Світловий промінь здається нескінченно тонкою прямою лінією, але електромагнітна хвиля переносить енергію не через математичну лінію нульової товщини, а через тривимірний просторовий об'єм навколо неї. Якщо тверді предмети, будівлі, крони дерев або навіть рельєф ґрунту вторгаються у цей просторовий коридор, сигнал зазнає фазового самознищення та дифракційного затінення, навіть якщо геометрична пряма видимість між антенами зберігається на 100%.

## Фізика просторового каналу: принцип Гюйгенса–Френеля

У класичній геометричній оптиці розповсюдження випромінювання розглядають як рух променів прямолінійними траєкторіями. Таке наближення працює лише тоді, коли розміри перешкод та апертур у тисячі разів перевищують довжину хвилі. Для видимого світла довжина хвилі становить близько 0.5 мкм (мікрометра), тому будь-яка будівля чи дерево є практично нескінченно великим об'єктом, що відкидає різку тінь.

У радіозв'язку довжини хвиль вимірюються сантиметрами й десятками сантиметрів: від 12.5 см на частоті 2.4 ГГц до 34.5 см на 868 МГц і 69.2 см на 433 МГц. На цих масштабах хвильова природа випромінювання стає домінуючою.

Поведінку радіохвилі описує хвильовий принцип Гюйгенса–Френеля (лат. *principium*, фр. *Fresnel*): кожна точка простору, якої досягає електромагнітний хвильовий фронт, стає джерелом вторинних сферичних хвиль. Хвиля, що приходить до антени приймача, є не просто одним прямим променем, а векторною суперпозицією (інтерференцією, лат. *inter* — взаємно, *ferio* — вдаряю) нескінченної кількості вторинних хвиль, які пройшли через усі ділянки простору між передавачем і приймачем.

Якщо середовище між антенами повністю вільне, вторинні хвилі, що рухаються під невеликими кутами до осі траси, приходять до приймача майже з тією самою фазою, що й прямий промінь. Вони додаються конструктивно, формуючи основну напруженість поля. Але якщо на деякому віддаленні від осі траси поставити екран або якщо там знаходиться ґрунт, частина вторинних хвиль затримується або зазнає додаткового фазового зсуву при відбитті. В результаті баланс інтерференції порушується: вторинні хвилі можуть прийти у протифазі та частково або повністю загасити прямий сигнал.

Область простору, де зосереджені вторинні хвилі, які відіграють вирішальну роль у формуванні результуючого поля, поділяють на концентричні просторові зони — зони Френеля.

## Геометрія зон Френеля

Зона Френеля являє собою тривимірний еліпсоїд обертання (грец. *elleipsis*), у фокусах якого розташовані передавальна антена Tx та приймальна антена Rx.

Нехай загальна відстань між антенами по прямій дорівнює `D`. Виберемо в просторі точку `M`, розташовану на відстані `d₁` від передавача та `d₂` від приймача. Відстань, яку проходить хвиля від Tx через точку `M` до Rx, дорівнює `d₁ + d₂`.

![Геометрія зон Френеля між антенами](/root/course/embedded/zony-frenelia-i-pereshkoda-na-shliakhu/img/fresnel-ellipsoid-geometry.svg)
*Геометрія зон Френеля: еліпсоїд обертання між антенами Tx і Rx, промені вторинних хвиль та 60-відсоткова межа чистого кліренсу.*

Різниця довжин шляхів `Δd` між траєкторією через точку `M` та прямою лінією прямої видимості (англ. *Line of Sight*, LOS) визначається співвідношенням:

```
Δd = (d₁ + d₂) - D                                                     [різниця ходу променів]
```

Зсув фази `Δφ` вторинної хвилі, що приходить через точку `M`, відносно прямого променя залежить від робочої довжини хвилі `λ`:

```
Δφ = (2·π / λ) · Δd                                                    [фазовий набіг вторинного коливання]
```

Межею `n`-ї зони Френеля називають геометричне місце точок у просторі, для яких різниця ходу `Δd` становить рівно `n` напівхвиль:

```
(d₁ + d₂) - D = n · (λ / 2)                                            [визначення межі n-ї зони Френеля]
```

Це рівняння задає сімейство вкладених еліпсоїдів обертання:

1. **Перша зона Френеля (`n = 1`):** різниця ходу вторинних хвиль становить від `0` до `λ / 2`, що відповідає фазовому зсуву `Δφ` від `0°` до `180°` (від `0` до `π` радіан). Вторинні хвилі з цієї області мають додатну проекцію на вектор прямого сигналу і додаються з ним переважно конструктивно. Через першу зону Френеля передається понад 85% усієї корисної потужності радіолінії.
2. **Друга зона Френеля (`n = 2`):** різниця ходу лежить у межах від `λ / 2` до `λ` (фазовий зсув від `180°` до `360°`). Хвилі з цієї зони приходять у протифазі до прямого сигналу і діють деструктивно, послаблюючи результуюче поле.
3. **Третя зона Френеля (`n = 3`):** різниця ходу від `λ` до `3·λ / 2` (зсув `360°...540°`), де хвилі знову додаються у фазі, але їхній внесок суттєво менший через більший кут розсіювання та більше затухання на подовженій траєкторії.

Чергування фаз у вищих зонах призводить до того, що внески парних і непарних зон взаємно компенсуються на периферії. Тому в інженерній практиці проектування ліній зв'язку розраховують і захищають від перекриття насамперед **першу зону Френеля**.

## Розрахунок радіуса першої зони Френеля

Щоб визначити радіус поперечного перерізу першої зони Френеля на довільній ділянці траси, скористаємося геометрією прямокутних трикутників.

Нехай точка `M` віддалена від осі траси на радіальну відстань `r₁`. Проекції точки `M` на вісь ділять загальну дистанцію `D` на відрізки `d₁` та `d₂` (`d₁ + d₂ = D`). Відстані від антен до точки `M` за теоремою Піфагора становлять:

```
d₁_M = √(d₁² + r₁²)
d₂_M = √(d₂² + r₁²)
```

На реальних лінках радіус зони `r₁` (одиниці або десятки метрів) у сотні й тисячі разів менший за відстані `d₁` та `d₂` (кілометри), тобто `r₁ ≪ d₁, d₂`. Це дозволяє використати розклад кореня у ряд Тейлора:

```
√(d₁² + r₁²) = d₁ · √(1 + (r₁/d₁)²)
             ≈ d₁ · (1 + r₁² / (2·d₁²))
             = d₁ + r₁² / (2·d₁)                                       [параксіальне наближення Тейлора]
```

Аналогічно для другого відрізка `√(d₂² + r₁²) ≈ d₂ + r₁² / (2·d₂)`. Підставимо ці наближення в умову першої зони Френеля `(d₁_M + d₂_M) - (d₁ + d₂) = λ / 2`:

```
(d₁ + r₁² / (2·d₁) + d₂ + r₁² / (2·d₂)) - (d₁ + d₂) = λ / 2
r₁² / (2·d₁) + r₁² / (2·d₂) = λ / 2                                    [скорочення d₁ та d₂]
(r₁² / 2) · ((d₁ + d₂) / (d₁ · d₂)) = λ / 2                            [зведення до спільного знаменника]
r₁² · ((d₁ + d₂) / (d₁ · d₂)) = λ                                      [множення обох частин на 2]
r₁² = (λ · d₁ · d₂) / (d₁ + d₂)                                        [вираження r₁²]
r₁ = √((λ · d₁ · d₂) / (d₁ + d₂))                                      [формула радіуса 1-ї зони Френеля]
```

Оскільки загальна довжина траси `D = d₁ + d₂`, формулу можна записати через повну дистанцію:

```
r₁(d₁) = √((λ · d₁ · (D - d₁)) / D)
```

Цей вираз описує еліпс вздовж координати `d₁`. Біля самих антен (`d₁ → 0` або `d₁ → D`) радіус наближається до нуля. Свого максимального значення `r_max` зона Френеля досягає точно посередині траси, де `d₁ = d₂ = D / 2`:

```
r_max = √((λ · (D/2) · (D/2)) / D)
      = √((λ · D² / 4) / D)
      = √((λ · D) / 4)
      = (1/2) · √(λ · D)                                               [максимальний радіус у центрі траси]
```

Для довільної `n`-ї зони Френеля радіус розраховується аналогічно через множник `√n`:

```
r_n(d₁, d₂) = √((n · λ · d₁ · d₂) / (d₁ + d₂)) = √n · r₁(d₁, d₂)        [радіус n-ї зони Френеля]
```

### Практичні розрахунки для типових частот

Розрахуємо довжину хвилі `λ = c / f` (де `c ≈ 3·10⁸ м/с`) та максимальний радіус `r_max` першої зони Френеля на дистанціях 100 м, 500 м, 1 км, 5 км і 10 км для основних бездротових діапазонів вбудованої електроніки:

1. **433 МГц (Telemetry, ISM, RFM69, LoRa 433):**
   `λ = 300 / 433 ≈ 0.6928 м`
2. **868 МГц (LoRaWAN Європа, 868 МГц ISM, ELRS 868):**
   `λ = 300 / 868 ≈ 0.3456 м`
3. **2.4 ГГц (Wi-Fi 802.11b/g/n, BLE, Zigbee, ExpressLRS 2.4):**
   `λ = 300 / 2400 = 0.1250 м`
4. **5.8 ГГц (FPV відео, 802.11a/ac Wi-Fi міст):**
   `λ = 300 / 5800 ≈ 0.0517 м`

> 🔧 **Навіщо це.**
> Зі зниженням робочої частоти радіус зони Френеля збільшується обернено пропорційно кореню з частоти (`r ∝ 1/√f`). Хоча радіохвилі частоти 433 МГц мають значно менше погонне згасання у вільному просторі та краще огинають перешкоди, ніж 2.4 ГГц, вони вимагають учетверо більшого поперечного перерізу вільного простору. На дистанції 5 км на частоті 433 МГц лінія потребує вільного коридору діаметром майже 60 метрів, тоді як на частоті 5.8 ГГц достатньо коридору діаметром 16 метрів.

## Правило 60% чистоти просвіту та дифракційні втрати

Коли тверда перешкода (верхівка пагорба, гребінь даху чи ліс) наближається до лінії прямої видимості, вона частково перекриває першу зону Френеля. Ступінь перекриття оцінюють за кліренсом (англ. *clearance* — просвіт) — висотою `h` між прямою лінією LOS та найвищою точкою перешкоди.

За конвенцією дифракційних розрахунків:
- `h < 0` (від'ємне значення) означає, що перешкода знаходиться нижче лінії прямої видимості (є вільний просвіт);
- `h = 0` означає, що перешкода торкається лінії LOS (верхівка перешкоди лежить на осі траси);
- `h > 0` (додатне значення) означає, що перешкода піднімається вище прямої видимості, перекриваючи прямий геометричний промінь.

Для розрахунку дифракційного поля перешкоду моделюють у вигляді напівнескінченного непрозорого екрана з тонким краєм — модель «лезо ножа» (англ. *knife-edge diffraction*). Ступінь згасання залежить від безрозмірного дифракційного параметра Френеля `ν`:

```
ν = h · √((2 / λ) · (1/d₁ + 1/d₂))
  = √2 · (h / r₁)                                                      [нормований параметр перешкоди]
```

![Крива дифракційних втрат на лезі ножа](/root/course/embedded/zony-frenelia-i-pereshkoda-na-shliakhu/img/diffraction-loss-curve.svg)
*Залежність дифракційних втрат від відносного кліренсу перешкоди: безпечна зона 60%, падіння на 6 дБ на лінії прямої видимості та швидке згасання при перекритті.*

Строге математичне виведення коефіцієнта передачі наведено в окремій вставці: [Виведення дифракційного інтеграла Френеля та моделі леза ножа](root:embedded/zony-frenelia-i-pereshkoda-na-shliakhu/math-knife-edge-diffraction.md).

З аналізу кривої втрат `J(ν)` випливають три фундаментальні інженерні висновки:

### 1. Правило 60% просвіту (Clearance Rule)

Якщо перешкода перекриває менше 40% радіуса першої зони Френеля знизу (тобто вільний просвіт `|h| ≥ 0.6 · r₁`, або `h / r₁ ≤ -0.6`, що відповідає `ν ≤ -0.85`), дифракційні втрати становлять:

```
J(ν) < 0.5 дБ                                                          [втрати на межі 60% кліренсу]
```

Втрати менше 0.5 дБ є нехтовно малими порівняно з іншими похибками радіотраси. Траса з кліренсом `≥ 0.6 · r₁` поводиться так, ніби поширення хвилі відбувається в абсолютно вільному просторі (англ. *free space propagation*).

Звідси формулюється головне правило планування радіоліній: **для забезпечення зв'язку без додаткових втрат не менше 60% радіуса першої зони Френеля має бути повністю вільним від будь-яких перешкод уздовж усієї траси.**

### 2. Втрати на лінії прямої видимості (h = 0)

Якщо перешкода піднімається рівно до лінії прямої видимості (`h = 0`, `ν = 0`), екран перекриває рівно половину площини хвильового фронту.

Амплітуда електричного поля на вході приймача падає рівно вдвічі (`E = E₀ / 2`), а потужність прийнятого сигналу — у 4 рази:

```
P / P₀ = (E / E₀)² = (1/2)² = 1/4
J(0) = -10 · log₁₀(1/4) = 10 · log₁₀(4) ≈ 6.02 дБ                     [втрата 6 дБ на лінії прямої видимості]
```

Це пояснює типову помилку розгортання: якщо антени бачать одна одну «впритул» над дахом сусідньої будівлі, лінк втрачає **6 дБ потужності** (у 4 рази) лише через те, що нижня половина першої зони Френеля перекрита.

### 3. Зона глибокого затінення (h > 0)

Коли перешкода піднімається вище прямої видимості (`h > 0`), дифракційні втрати лавиноподібно зростають:

```
h = +0.5 · r₁  (ν ≈ +0.71)  →  J ≈ 11.7 дБ  (потужність падає у 15 разів)
h = +1.0 · r₁  (ν ≈ +1.41)  →  J ≈ 16.0 дБ  (потужність падає у 40 разів)
h = +2.0 · r₁  (ν ≈ +2.83)  →  J ≈ 22.0 дБ  (потужність падає у 160 разів)
```

Якщо енергетичний запас лінка (англ. *fade margin*) становить типові 15–20 дБ, перекриття зони Френеля лише на висоту `h = r₁` повністю вичерпує весь запас і розриває зв'язок.

### Вплив характеру перешкод: ліс, будівлі та камінь

Модель «лезо ножа» описує ідеальну гостру перешкоду (наприклад, одиночний скелястий гребінь або кут металевого даху). У реальних умовах природа перешкоди вносить додаткове згасання:

- **Лісові масиви та крони дерев (модель ITU-R P.833):** дерево не є ідеальним тонким екраном. Воно являє собою напівпрозоре дифузне середовище з діелектричними втратами. Листя, гілки та стовбури викликають комбінацію затінення, поглинання водою всередині рослин та хаотичного багаторазового розсіювання. Погонне згасання в лісовому масиві становить близько `0.2–0.3 дБ/м` на частоті 868 МГц і досягає `0.8–1.2 дБ/м` на частоті 5.8 ГГц. Окреме дерево на шляху дає додаткове згасання від 5 до 15 дБ. Під час дощу, коли листя мокре, втрати в лісовому масиві зростають ще на 6–12 дБ. У розрахунках верхівки дерев обов'язково розглядають як непрозорий масив із додаванням 2–4 метрів запасу на сезонний приріст крони.
- **Округлі пагорби:** пологий ґрунтовий схил поводиться гірше за тонке лезо ножа. Електромагнітна хвиля огинає криволінійну поверхню, зазнаючи додаткового поверхневого згасання в ґрунті. Втрати на округлому пагорбі зазвичай на 5–10 дБ вищі, ніж на тонкому лезі тієї самої висоти.
- **Міська забудова (модель ITU-R P.1411):** паралельні ряди багатоповерхових будинків утворюють множинні перешкоди (англ. *multiple knife-edge*). Сигнал зазнає послідовної дифракції на кожному даху, що збільшує сумарні втрати за методом Дейго або Буллінгтона.

## Відбиття від землі та інтерференційні провали

Особливий випадок виникає тоді, коли траса проходить над рівною відкритою поверхнею (водойма, асфальтований плац, солончак або рівне поле).

Якщо дзеркальна поверхня землі потрапляє всередину першої або другої зони Френеля, сигнал поширюється двома основними шляхами: прямим променем та променем, відбитим від поверхні (двопроменева модель, англ. *Two-Ray Ground Reflection*).

При падінні радіохвилі під малим кутом ковзання до ґрунту (менше 2–3°) коефіцієнт відбиття за модулем наближається до одиниці (`|R| ≈ 1`), а фаза хвилі при відбитті змінюється на протилежну (`Δφ_refl ≈ 180° = π`).

Різниця ходу між прямим та відбитим променями для висот антен `h_tx` та `h_rx` на відстані `D` дорівнює:

```
Δd_ground = √((h_tx + h_rx)² + D²) - √((h_tx - h_rx)² + D²)
          ≈ (2 · h_tx · h_rx) / D                                      [наближення різниці ходу відбитого променя]
```

Повний фазовий зсув між прямим і відбитим сигналами в точці прийому складається з різниці ходу та фазового стрибка на 180°:

```
ΔΦ_total = (2·π / λ) · ((2 · h_tx · h_rx) / D) + π                     [повний фазовий зсув двох променів]
```

Якщо різниця ходу мала (`Δd_ground ≪ λ / 2`), прямий сигнал і відбита протифазна хвиля практично повністю віднімаються одна від одної. Це призводить до катастрофічного згасання сигналу: потужність падає не як `1 / D²` (вільний простір), а як `1 / D⁴` (четверта степінь дистанції).

Щоб розірвати деструктивне відбиття від землі, застосовують два інженерних прийоми:
1. **Збільшення висоти підвісу антен:** піднімають антени настільки, щоб різниця ходу досягла `Δd_ground = λ / 2`. Тоді геометричний фазовий набіг у 180° разом зі стрибком при відбитті у 180° дає сумарний зсув 360° (повний синфазний збіг), що підсилює сигнал на `+6 дБ` порівняно з вільним простором.
2. **Екранування точки відбиття:** використовують природні нерівності рельєфу або вибирають висоти щогл так, щоб дзеркальна точка відбиття на ґрунті перекривалася пагорбом чи будівлею, тоді як прямий промінь зберігав чистий 60% кліренс.

## Вплив кривини Землі та атмосферної рефракції

На коротких трасах (до 1–2 км) поверхню Землі можна вважати плоскою. Однак на міжміських дистанціях або при розгортанні далекосяжної телеметрії (5–30 км) поверхня земної кулі помітно вигинається вгору між передавачем і приймачем, утворюючи так званий «горб Землі» (англ. *Earth bulge*).

![Профіль траси з урахуванням кривини Землі](/root/course/embedded/zony-frenelia-i-pereshkoda-na-shliakhu/img/earth-bulge-and-clearance.svg)
*Профіль радіотраси з урахуванням кривини Землі, пагорба з деревами та розрахунку необхідної висоти підвісу щогл.*

Геометричний підйом поверхні Землі над хордою, що з'єднує основи антен, у точці, яка ділить трасу на відрізки `d₁` та `d₂`, становить:

```
h_geom = (d₁ · d₂) / (2 · R_z)                                         [геометрична стріла прогину сфери]
```

де `R_z ≈ 6371 км` — фізичний радіус Землі.

Однак радіохвиля поширюється не у вакуумі, а в атмосфері, де густина повітря, тиск і вологість зменшуються з висотою. Це створює вертикальний градієнт діелектричної проникності, через що радіопромінь зазнає рефракції (лат. *refractio* — заломлення) і плавно викривляється в бік поверхні Землі.

Для врахування стандартної атмосферної рефракції в радіофізиці використовують поняття **еквівалентного радіуса Землі** `R_eff = k · R_z`. Для стандартної атмосфери в помірних широтах фактор рефракції приймають рівним `k = 4/3 ≈ 1.333`:

```
R_eff = (4/3) · 6371 км ≈ 8495 км                                      [еквівалентний радіус для стандартної рефракції]
```

Еквівалентна висота підйому горба Землі з урахуванням викривлення променя в атмосфері становить:

```
h_bulge = (d₁ · d₂) / (2 · R_eff)
        = (d₁ · d₂) / (2 · 8495)
        ≈ (d₁ · d₂) / 16990 км                                         [d₁, d₂ у км, результат у км]
h_bulge(м) ≈ (d₁ · d₂) / 17                                            [інженерна формула: d₁, d₂ у км, h у метрах]
```

У центрі траси (`d₁ = d₂ = D / 2`):

```
h_bulge_max ≈ (D / 2)² / 17 = D² / 68                                  [максимальний підйом Землі у центрі траси]
```

Підйом поверхні Землі у центрі ідеально рівної ділянки:
- на дистанції `D = 5 км`: `h_bulge ≈ 25 / 68 ≈ 0.37 м`;
- на дистанції `D = 10 км`: `h_bulge ≈ 100 / 68 ≈ 1.47 м`;
- на дистанції `D = 20 км`: `h_bulge ≈ 400 / 68 ≈ 5.88 м`;
- на дистанції `D = 30 км`: `h_bulge ≈ 900 / 68 ≈ 13.24 м`.

На дистанції 20 км горб Землі висотою майже 6 метрів здатен повністю заблокувати лінію зв'язку між антенами, встановленими на звичайних триметрових щоглах, навіть на ідеально рівній поверхні водойми або степу.

## Специфіка зв'язку з рухомими об'єктами та БПЛА

Окремим випадком розрахунку зон Френеля є зв'язок між наземною станцією керування (НСК) та безпілотним літальним апаратом (БПЛА) або автономним мобільним роботом (UGV).

При зміні висоти польоту БПЛА від 10 м до 300 м геометрія зони Френеля динамічно трансформується:

1. **Низьковисотний політ над лісом:**
   Коли БПЛА летить на висоті 15–20 м на дистанції 3 км, а навколо наземної станції ростуть дерева висотою 15 м, нижня частина зони Френеля на частоті 868 МГц (`r₁ ≈ 16 м`) повністю занурена у рослинність. Навіть якщо камера дрона бачить дах ангара, телеметрія постійно збоїть. Перехід на частоту 5.8 ГГц (`r₁ ≈ 6.2 м`) на коротких дистанціях різко зменшує розмір еліпсоїда, виводячи 60% зону з лісового масиву і стабілізуючи відеопотік.
2. **Підйом БПЛА у повітря:**
   Зі збільшенням висоти кут нахилу лінії LOS зростає. Критична точка перекриття зони Френеля зміщується впритул до наземної антени. Тому в польових умовах щоглу з антеною НСК достатньо підняти на 4–6 метрів над місцевими перешкодами поблизу позиції оператора.

## Інженерна методика розрахунку висоти підвісу антен

Для надійного проектування польової радіолінії застосовують покроковий алгоритм розрахунку мінімальної висоти щогл.

### Алгоритм розрахунку траси

1. **Визначення робочої частоти `f` та довжини хвилі `λ`:**
   `λ = 300 / f_МГц` (у метрах).
2. **Отримання профілю рельєфу:**
   За географічними координатами антен Tx і Rx будують висотний профіль місцевості (наприклад, за даними SRTM або радіопланувальними картами) з кроком дискретизації 50–100 м.
3. **Розрахунок повної ефективної висоти перешкоди `H_obs(x)` для кожної точки профілю:**
   У кожній точці траси на відстані `d₁` від Tx та `d₂` від Rx повна висота точки складається з чотирьох складових:
   ```
   H_total(x) = H_topo(x) + H_veg(x) + h_bulge(x) + 0.6 · r₁(x)
   ```
   де:
   - `H_topo(x)` — абсолютна висота рельєфу за топографічною картою;
   - `H_veg(x)` — висота рослинності та забудови (10–25 м для лісу, 5–15 м для малоповерхової забудови);
   - `h_bulge(x) = (d₁ · d₂) / 17` — поправка на кривину Землі;
   - `0.6 · r₁(x) = 0.6 · √((λ · d₁ · d₂) / D)` — необхідний 60% просвіт першої зони Френеля.
4. **Побудова лінії візирного променя:**
   Пряма лінія між верхівками антен Tx (`H_Tx = H_topo_Tx + h_mast_Tx`) та Rx (`H_Rx = H_topo_Rx + h_mast_Rx`) повинна проходити **вище або на рівні** розрахованої кривої `H_total(x)` у всіх точках траси:
   ```
   H_LOS(x) ≥ H_total(x)   для всіх x ∈ [0, D]
   ```
5. **Вибір висот щогл:**
   Вибирають доступні висоти підвісу антен `h_mast_Tx` та `h_mast_Rx`, що задовольняють цю нерівність.

### Числовий приклад розрахунку в польових умовах

Розглянемо практичну задачу організації телеметричного каналу LoRa 868 МГц між базовою станцією та автономним датчиком:

- Відстань між точками: `D = 6 км` (`6000 м`).
- Робоча частота: `868 МГц` (`λ = 0.3456 м`).
- Топографія: антена Tx встановлена на пагорбі з відміткою `120 м`, антена Rx — на висоті `110 м`.
- Перешкода: на відстані `d₁ = 2.5 км` (`2500 м`) від Tx знаходиться лісистий гребінь з висотою рельєфу `115 м`. Висота дерев складає `H_veg = 12 м`.

**Крок 1. Розрахунок кривини Землі на гребені:**
```
d₂ = D - d₁
   = 6.0 - 2.5                                                         [відстань від гребеня до приймача Rx]
   = 3.5 км
h_bulge = (2.5 · 3.5) / 17                                             [інженерна формула стріли прогину Землі]
        = 8.75 / 17                                                    [добуток дистанцій d₁ · d₂]
        ≈ 0.51 м                                                       [підйом рельєфу за рахунок кривини кулі]
```

**Крок 2. Розрахунок радіуса 1-ї зони Френеля на гребені:**
```
r₁ = √((0.3456 · 2500 · 3500) / 6000)                                  [підстановка параметрів: λ = 0.3456 м, d₁ = 2500 м, d₂ = 3500 м]
   = √(3024000 / 6000)                                                 [добуток у чисельнику під коренем]
   = √504                                                              [ділення на повну дистанцію траси]
   ≈ 22.45 м                                                           [радіус першої зони Френеля над гребенем]
```

**Крок 3. Розрахунок необхідного кліренсу 60%:**
```
h_clear = 0.6 · r₁
        = 0.6 · 22.45                                                  [вимога 60% чистоти першої зони]
        ≈ 13.47 м                                                      [мінімально необхідний вільний просвіт]
```

**Крок 4. Повна критична висота перешкоди з урахуванням кліренсу:**
```
H_crit = H_topo + H_veg + h_bulge + h_clear
       = 115.0 + 12.0 + 0.51 + 13.47                                   [додавання висот рельєфу, лісу, горба Землі та кліренсу]
       = 140.98 м                                                      [точна сума складових]
       ≈ 141.0 м                                                       [округлена критична відмітка траси]
```

**Крок 5. Визначення необхідних висот щогл:**
Пряма лінія прямої видимості `H_LOS(x)` на позначці `d₁ = 2.5 км` при базових висотах рельєфу без щогл складає:
```
H_LOS_base = 120 + (2.5 / 6.0) · (110 - 120)                           [лінійне рівняння прямої між основами антен]
           = 120 - 4.17                                                [інтерполяція висотного перепаду між точками]
           = 115.83 м                                                  [висота прямої без щогл над рівнем моря]
```

Дефіцит висоти між візирною прямою та критичною межею зони Френеля:
```
ΔH = H_crit - H_LOS_base
   = 141.0 - 115.83                                                    [різниця між критичною відміткою та візирною лінією]
   = 25.17 м                                                           [необхідний сумарний підйом антен над землею]
```

Щоб підняти візирну лінію на 25.17 м над гребенем, інженери можуть розподілити висоту між щоглами: наприклад, встановити щоглу `h_mast_Tx = 16 м` на базовій станції та щоглу `h_mast_Rx = 12 м` на об'єкті моніторингу:

```
H_LOS(2.5) = (120 + 16) + (2.5 / 6.0) · ((110 + 12) - (120 + 16))      [рівняння променя з урахуванням щогл 16 м та 12 м]
           = 136.0 + (2.5 / 6.0) · (122.0 - 136.0)                     [висоти верхівок антен Tx та Rx над рівнем моря]
           = 136.0 - 5.83                                              [похил візирної лінії на позначці 2.5 км]
           = 130.17 м                                                  [фактична висота візирного променя над гребенем]
```

У цьому випадку лінія пройде на позначці `130.17 м`, тоді як верхній край лісу з урахуванням кривини Землі знаходиться на висоті `115 + 12 + 0.51 = 127.51 м`. Просвіт між лінією LOS та лісом становитиме `130.17 - 127.51 = 2.66 м`, що відповідає `h / r₁ = -2.66 / 22.45 ≈ -0.12`.

Дифракційні втрати складуть близько 4.5 дБ. Якщо підняти щоглу на передавачі до 22 метрів, просвіт досягне необхідних 60% (`13.5 м`), і дифракційні втрати повністю зникнуть.

## Програмна реалізація розрахунку кліренсу та втрат

Для автоматизації аналізу траси у вбудованих утилітах та системах планування нижче наведено алгоритм розрахунку радіуса зони Френеля, стріли прогину Землі та дифракційних втрат за рекомендацією ITU-R P.526.

:::tabs
```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

#define SPEED_OF_LIGHT 299792458.0
#define EARTH_RADIUS_EFF 8495000.0  /* 4/3 * 6371000 м */

typedef struct {
    double dist_from_tx_m;
    double ground_alt_m;
    double clutter_height_m;
} TerrainPoint;

typedef struct {
    double r1_radius_m;
    double earth_bulge_m;
    double los_height_m;
    double obstacle_top_m;
    double clearance_m;
    double clearance_ratio;
    double diffraction_loss_db;
    bool is_60_percent_clear;
} ClearanceResult;

/* Апроксимація дифракційних втрат за ITU-R P.526 */
static double calculate_itu_loss(double v) {
    if (v <= -0.78) {
        return 0.0;
    }
    double term = sqrt((v - 0.1) * (v - 0.1) + 1.0) + (v - 0.1);
    return 6.9 + 20.0 * log10(term);
}

ClearanceResult evaluate_clearance(
    double freq_hz,
    double total_distance_m,
    double tx_total_alt_m,
    double rx_total_alt_m,
    TerrainPoint obstacle
) {
    ClearanceResult res;
    double lambda = SPEED_OF_LIGHT / freq_hz;
    double d1 = obstacle.dist_from_tx_m;
    double d2 = total_distance_m - d1;

    /* 1. Радіус першої зони Френеля */
    res.r1_radius_m = sqrt((lambda * d1 * d2) / total_distance_m);

    /* 2. Кривина Землі зі стандартною рефракцією (k = 4/3) */
    res.earth_bulge_m = (d1 * d2) / (2.0 * EARTH_RADIUS_EFF);

    /* 3. Висота лінії прямої видимості (LOS) у точці перешкоди */
    double slope = (rx_total_alt_m - tx_total_alt_m) / total_distance_m;
    res.los_height_m = tx_total_alt_m + slope * d1;

    /* 4. Повна висота перешкоди з урахуванням рельєфу, дерев та горба Землі */
    res.obstacle_top_m = obstacle.ground_alt_m + obstacle.clutter_height_m + res.earth_bulge_m;

    /* 5. Кліренс: додатний, якщо є вільний просвіт (перешкода нижче LOS) */
    res.clearance_m = res.los_height_m - res.obstacle_top_m;
    res.clearance_ratio = res.clearance_m / res.r1_radius_m;

    /* 6. Дифракційний параметр v = -h_clearance * sqrt(2) / r1 */
    double h_obstacle_rel = -res.clearance_m;
    double v = sqrt(2.0) * (h_obstacle_rel / res.r1_radius_m);

    res.diffraction_loss_db = calculate_itu_loss(v);
    res.is_60_percent_clear = (res.clearance_ratio >= 0.60);

    return res;
}
```

```cpp
#include <cmath>
#include <numbers>
#include <optional>
#include <span>
#include <vector>

struct TerrainPoint {
    double dist_from_tx_m{0.0};
    double ground_alt_m{0.0};
    double clutter_height_m{0.0};
};

struct ClearanceResult {
    double r1_radius_m{0.0};
    double earth_bulge_m{0.0};
    double los_height_m{0.0};
    double obstacle_top_m{0.0};
    double clearance_m{0.0};
    double clearance_ratio{0.0};
    double diffraction_loss_db{0.0};
    bool is_60_percent_clear{false};
};

class FresnelClearanceCalculator {
public:
    static constexpr double SpeedOfLight = 299792458.0;
    static constexpr double EarthEffectiveRadius = 8495000.0; // 4/3 * R_earth

    static constexpr double calculate_itu_loss(double v) noexcept {
        if (v <= -0.78) {
            return 0.0;
        }
        const double term = std::sqrt((v - 0.1) * (v - 0.1) + 1.0) + (v - 0.1);
        return 6.9 + 20.0 * std::log10(term);
    }

    [[nodiscard]] static ClearanceResult evaluate_point(
        double freq_hz,
        double total_dist_m,
        double tx_alt_m,
        double rx_alt_m,
        const TerrainPoint& obstacle
    ) noexcept {
        const double lambda = SpeedOfLight / freq_hz;
        const double d1 = obstacle.dist_from_tx_m;
        const double d2 = total_dist_m - d1;

        ClearanceResult res;
        res.r1_radius_m = std::sqrt((lambda * d1 * d2) / total_dist_m);
        res.earth_bulge_m = (d1 * d2) / (2.0 * EarthEffectiveRadius);

        const double slope = (rx_alt_m - tx_alt_m) / total_dist_m;
        res.los_height_m = tx_alt_m + slope * d1;
        res.obstacle_top_m = obstacle.ground_alt_m + obstacle.clutter_height_m + res.earth_bulge_m;

        res.clearance_m = res.los_height_m - res.obstacle_top_m;
        res.clearance_ratio = res.clearance_m / res.r1_radius_m;

        const double h_obstacle = -res.clearance_m;
        const double v = std::numbers::sqrt2 * (h_obstacle / res.r1_radius_m);

        res.diffraction_loss_db = calculate_itu_loss(v);
        res.is_60_percent_clear = (res.clearance_ratio >= 0.60);

        return res;
    }

    [[nodiscard]] static ClearanceResult find_worst_obstacle(
        double freq_hz,
        double total_dist_m,
        double tx_alt_m,
        double rx_alt_m,
        std::span<const TerrainPoint> profile
    ) noexcept {
        ClearanceResult worst{};
        double max_loss = -1.0;

        for (const auto& point : profile) {
            if (point.dist_from_tx_m <= 0.0 || point.dist_from_tx_m >= total_dist_m) {
                continue;
            }
            auto current = evaluate_point(freq_hz, total_dist_m, tx_alt_m, rx_alt_m, point);
            if (current.diffraction_loss_db > max_loss) {
                max_loss = current.diffraction_loss_db;
                worst = current;
            }
        }
        return worst;
    }
};
```

## Чекліст проектування радіолінії в польових умовах

Перед остаточним монтажем щогл та налаштуванням бездротового обладнання перевіряють виконання наступних правил:

1. **Частота визначає розмір коридору:** якщо немає можливості підняти антени вище 5–6 метрів над землею, переходять на вищі частотні діапазони (2.4 ГГц або 5.8 ГГц замість 433 МГц), де радіус зони Френеля у 2–4 рази менший.
2. **Запас на 60% кліренсу:** лінія прямої видимості повинна проходити так, щоб між нею та найвищою точкою перешкоди залишався зазор не менше `0.6 · r₁`.
3. **Облік сезонів та вологості:** для лісових масивів до висоти дерев додають не менше 3–4 метрів запасу на літнє листя та закладають у бюджет лінка додаткові 6–10 дБ запасу на мокре листя під час дощу.
4. **Горб Землі понад 3 км:** для будь-яких дистанцій понад 3 км поправка `h_bulge = (d₁ · d₂) / 17` є обов'язковою, інакше лінк втратить сигнал на середині траси навіть у степу.
5. **Тест на дотик до LOS:** якщо оптична видимість є, але сигнал на 6–10 дБ нижчий за розрахунковий за Фріісом, перешкода знаходиться точно на лінії прямої видимості або зачіпає край зони Френеля.
