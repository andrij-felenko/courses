# 🧮 Виведення дифракційного інтеграла Френеля та моделі леза ножа

Дифракційні втрати на перешкоді виникають через просторове перекриття частини вторинних хвиль хвильового фронту, що змінює результуючу амплітуду та фазу поля в точці прийому від режиму вільного простору до глибокого затінення. Цей розрахунок дає строге математичне виведення коефіцієнта передачі напівнескінченного екрана (модель «лезо ножа», англ. *knife-edge diffraction*) через інтеграли Френеля, розглядає геометричну інтерпретацію на спіралі Корню, обґрунтовує граничні значення 0 дБ, 6 дБ та наводить асимптотичні формули стандарту ITU-R P.526 і метод Дейго для множинних перешкод.

## Геометрія задачі та безрозмірний параметр Френеля

Розглянемо поширення сферичної електромагнітної хвилі між передавачем Tx та приймачем Rx, розділеними відстанню `D`. На відстані `d₁` від передавача та `d₂` від приймача (`d₁ + d₂ = D`) перпендикулярно до осі траси розташована напівнескінченна непрозора площина, верхній край якої утворює горизонтальне лезо на висоті `h` відносно прямої лінії прямої видимості (англ. *Line of Sight*, LOS).

Координатна система в площині перешкоди орієнтована так, що вісь `Y` спрямована вертикально вгору, а точка `y = 0` лежить точно на лінії LOS. Верхній край екрана знаходиться в точці `y = h`. Якщо перешкода не перекриває пряму видимість і знаходиться нижче осі, значення `h` вважається від'ємним (`h < 0`); якщо перешкода перекриває прямий промінь, `h > 0`.

Для довільної точки на екрані з висотою `y` повний шлях вторинної хвилі від Tx через точку `(x, y)` до Rx дорівнює:

```
r_path(y) = √(d₁² + y²) + √(d₂² + y²)                                   [довжина траєкторії через точку перешкоди]
```

Оскільки на практиці відстані між антенами значно перевищують характерні висоти перешкод (`y ≪ d₁` та `y ≪ d₂`), застосуємо параксіальний розклад кореня у ряд Тейлора:

```
√(d₁² + y²) = d₁ · √(1 + (y/d₁)²)
            ≈ d₁ · (1 + y² / (2·d₁²))
            = d₁ + y² / (2·d₁)                                         [наближення Тейлора першого порядку]
```

Аналогічно для другого плеча траси `√(d₂² + y²) ≈ d₂ + y² / (2·d₂)`. Різниця ходу `Δd(y)` між променем через точку `y` та прямою візирною лінією `D = d₁ + d₂` становить:

```
Δd(y) = (d₁ + y² / (2·d₁) + d₂ + y² / (2·d₂)) - (d₁ + d₂)
      = y² / (2·d₁) + y² / (2·d₂)                                       [скорочення прямої дистанції d₁ + d₂]
      = (y² / 2) · ((d₁ + d₂) / (d₁ · d₂))
      = (y² / 2) · (1/d₁ + 1/d₂)                                       [зведення різниці ходу до єдиного множника]
```

Фазовий зсув вторинної хвилі `Δφ(y)` на довжині хвилі `λ` дорівнює:

```
Δφ(y) = (2·π / λ) · Δd(y)
      = (2·π / λ) · (y² / 2) · (1/d₁ + 1/d₂)
      = (π / λ) · (1/d₁ + 1/d₂) · y²                                    [фазовий набіг вторинного випромінювання]
```

Для спрощення інтеграла введемо безрозмірну нормовану змінну `t` та геометричний параметр перешкоди `ν` (параметр дифракції Френеля):

```
(π/2) · t² = Δφ(y) = (π / λ) · (1/d₁ + 1/d₂) · y²                       [прирівнювання аргументу гармонічного коливання]
t² = (2 / λ) · (1/d₁ + 1/d₂) · y²
t = y · √((2 / λ) · (1/d₁ + 1/d₂))                                      [безрозмірна висотна координата]
ν = h · √((2 / λ) · (1/d₁ + 1/d₂))                                      [значення t на верхньому зрізі перешкоди]
```

Згадавши вираз для радіуса першої зони Френеля `r₁ = √((λ · d₁ · d₂) / (d₁ + d₂))`, встановимо прямий геометричний зв'язок параметра `ν` із відносним кліренсом перешкоди `h / r₁`:

```
1 / r₁² = (d₁ + d₂) / (λ · d₁ · d₂) = (1 / λ) · (1/d₁ + 1/d₂)
ν = h · √(2 · (1 / r₁²))
  = √2 · (h / r₁)                                                      [нормований параметр дифракції Френеля]
```

## Інтеграл Кірхгофа та комплексний коефіцієнт передачі

Згідно з хвильовим принципом Гюйгенса–Френеля у скалярному формулюванні Кірхгофа, напруженість електричного поля `E` в точці прийому розраховується як інтеграл від вторинних джерел по відкритій напівплощині (від верхнього краю екрана `y = h` до `y = +∞` та від `x = -∞` до `x = +∞`).

Інтегрування по горизонтальній координаті `x` дає постійний фазовий множник `exp(-j·π/4)`, який нормалізується полем вільного простору `E₀`. В результаті комплексний коефіцієнт передачі поля `F(ν) = E / E₀` зводиться до одновимірного інтеграла:

```
F(ν) = ((1 + j) / 2) · ∫[від ν до ∞] exp(-j · (π/2) · t²) dt            [комплексний інтеграл дифракції на напівплощині]
```

За формулою Ейлера розкладемо комплексну експоненту на косинусну та синусну складові:

```
exp(-j · (π/2) · t²) = cos((π/2) · t²) - j · sin((π/2) · t²)            [тригонометричний розклад Ейлера]
```

Введемо стандартні інтеграли Френеля `C(w)` та `S(w)`:

```
C(w) = ∫[від 0 до w] cos((π/2) · t²) dt                                 [косинус-інтеграл Френеля]
S(w) = ∫[від 0 до w] sin((π/2) · t²) dt                                 [синус-інтеграл Френеля]
```

Оскільки функції під інтегралами є парними, а повні невласні інтеграли на нескінченності дорівнюють `C(∞) = 1/2` та `S(∞) = 1/2`, межі інтегрування від `ν` до `+∞` перетворюються на:

```
∫[від ν до ∞] cos((π/2) · t²) dt = ∫[від 0 до ∞] cos((π/2)·t²) dt - ∫[від 0 до ν] cos((π/2)·t²) dt
                                 = 1/2 - C(ν)                           [різниця повного та неповного інтегралів]
∫[від ν до ∞] sin((π/2) · t²) dt = 1/2 - S(ν)
```

Підставимо ці вирази у формулу коефіцієнта передачі:

```
F(ν) = ((1 + j) / 2) · [ (1/2 - C(ν)) - j · (1/2 - S(ν)) ]
     = (1/2) · [ (1/2 - C(ν) + 1/2 - S(ν)) + j · (1/2 - C(ν) - 1/2 + S(ν)) ]
     = (1/2) · [ (1 - C(ν) - S(ν)) + j · (S(ν) - C(ν)) ]               [дійсна та уявна частини поля]
```

Квадрат амплітуди нормованого поля (відношення потужності прийнятого сигналу `P` до потужності у вільному просторі `P₀`) розраховується як квадрат модуля комплексного числа:

```
|F(ν)|² = Re(F(ν))² + Im(F(ν))²
        = (1/4) · [ (1 - (C(ν) + S(ν)))² + (S(ν) - C(ν))² ]
        = (1/4) · [ 1 - 2·(C(ν) + S(ν)) + (C(ν) + S(ν))² + S(ν)² - 2·C(ν)·S(ν) + C(ν)² ]
        = (1/4) · [ 1 - 2·(C(ν) + S(ν)) + C(ν)² + 2·C(ν)·S(ν) + S(ν)² + S(ν)² - 2·C(ν)·S(ν) + C(ν)² ]
        = (1/4) · [ 1 - 2·(C(ν) + S(ν)) + 2·C(ν)² + 2·S(ν)² ]
        = (1/2) · [ 1/2 - (C(ν) + S(ν)) + C(ν)² + S(ν)² ]
        = (1/2) · [ (1/4 - C(ν) + C(ν)²) + (1/4 - S(ν) + S(ν)²) ]
        = (1/2) · [ (1/2 - C(ν))² + (1/2 - S(ν))² ]                     [нормована потужність за інтегралами Френеля]
```

Дифракційні втрати `J(ν)` у децибелах визначаються як від'ємний логарифм відношення потужностей:

```
J(ν) = -10 · log₁₀(|F(ν)|²)                                             [визначення дифракційного згасання в дБ]
     = -10 · log₁₀((1/2) · [ (1/2 - C(ν))² + (1/2 - S(ν))² ])
```

## Геометрична інтерпретація на спіралі Корню

Графічним відображенням інтегралів Френеля на комплексній площині `(C, S)` є спіраль Корню (фр. *spirale de Cornu*, або клотоїда). Параметричні координати кривої задаються рівняннями `x = C(t)`, `y = S(t)`.

Коли параметр `t` змінюється від `-∞` до `+∞`, точка на площині рухається вздовж плавної подвійної спіралі з центрами у фокусах `W₁(-1/2, -1/2)` при `t → -∞` та `W₂(1/2, 1/2)` при `t → +∞`.

Вектор напруженості поля `E(ν)` на діаграмі Корню з'єднує точку на спіралі `P(ν) = (C(ν), S(ν))` з фокусом `W₂(1/2, 1/2)`. Довжина цього вектора прямо пропорційна амплітуді сигналу на вході приймача:

1. **При відсутності перешкоди (`ν → -∞`):** початкова точка знаходиться у фокусі `W₁`. Довжина вектора між `W₁` та `W₂` становить `√((1/2 - (-1/2))² + (1/2 - (-1/2))²) = √(1² + 1²) = √2`. З урахуванням множника `1/√2` амплітуда дорівнює `1.0` (0 дБ).
2. **При наближенні перешкоди до променя знизу (`ν` від `-3.0` до `0`):** вектор описує концентричні завитки навколо фокуса `W₁`. Відстань періодично то зростає, то спадає. Це породжує дифракційні пульсації поля: при `ν ≈ -1.2` втрати падають нижче нуля (сигнал підсилюється на `+1.3 дБ` за рахунок синфазного додавання крайової хвилі), а при `ν ≈ -1.8` з'являється невеликий провал.
3. **На межі прямої видимості (`ν = 0`):** точка знаходиться в початку координат `(0, 0)`. Відстань до фокуса `W₂` становить `√((1/2)² + (1/2)²) = √(1/4 + 1/4) = 1/√2`. Квадрат амплітуди падає рівно вдвічі відносно вільного простору (втрата 6.02 дБ).
4. **У зоні глибокої тіні (`ν > 0`):** точка плавно закручується у спіраль навколо фокуса `W₂`, а довжина вектора монотонно прямує до нуля без пульсацій.

## Аналітичні граничні режими

### 1. Точний дотик до лінії прямої видимості (`h = 0`, `ν = 0`)

На межі прямої видимості `C(0) = 0` та `S(0) = 0`:

```
|F(0)|² = (1/2) · [ (1/2 - 0)² + (1/2 - 0)² ]
        = (1/2) · [ 1/4 + 1/4 ]
        = (1/2) · (1/2)
        = 1/4                                                           [потужність становить чверть від вільного простору]
J(0) = -10 · log₁₀(1/4)
     = 10 · log₁₀(4)
     ≈ 6.0206 дБ                                                        [точна втрата 6.02 дБ на лінії LOS]
```

### 2. Вільний просвіт (`ν < -1`)

Для від'ємних значень `ν`, модуль яких перевищує `1`, використовують асимптотичний розклад інтегралів Френеля при `|ν| ≫ 1`:

```
C(ν) = -1/2 + sin((π/2)·ν²) / (π·|ν|) + cos((π/2)·ν²) / (π²·|ν|³) - ...
S(ν) = -1/2 - cos((π/2)·ν²) / (π·|ν|) + sin((π/2)·ν²) / (π²·|ν|³) - ...
```

Підставляючи ці ряди у вираз для потужності, отримуємо формулу пульсацій на відкритій трасі:

```
|F(ν)|² ≈ 1 + (√2 / (π·|ν|)) · sin((π/2)·ν² - π/4)                      [інтерференційні коливання на межі зони]
```

При кліренсі `h = -0.6 · r₁` параметр дифракції `ν = -0.6 · √2 ≈ -0.8485`. Точне чисельне обчислення інтегралів дає `C(-0.8485) ≈ -0.7725`, `S(-0.8485) ≈ -0.4411`:

```
|F(-0.8485)|² = (1/2) · [ (1/2 - (-0.7725))² + (1/2 - (-0.4411))² ]
              = (1/2) · [ 1.2725² + 0.9411² ]
              = (1/2) · [ 1.6192 + 0.8857 ]
              = (1/2) · 2.5049
              ≈ 1.2525                                                  [потужність з урахуванням конструктивної інтерференції]
```

Коливання навколо одиниці не перевищують `+1 дБ` ... `-0.4 дБ`, що підтверджує: кліренс `0.6 · r₁` практично повністю еквівалентний вільному простору.

### 3. Глибоке затінення (`ν > 1`)

При `ν ≫ 1` інтегрування методом частин дає асимптотику хвоста інтеграла Френеля:

```
∫[від ν до ∞] exp(-j·(π/2)·t²) dt ≈ exp(-j·(π/2)·ν²) / (j · π · ν)       [головний член асимптотичного розкладу]
|F(ν)|² ≈ | ((1 + j) / 2) · (exp(-j·(π/2)·ν²) / (j·π·ν)) |²
        = | (1 + j) / 2 |² · (1 / (π² · ν²))
        = (1/2) · (1 / (π² · ν²))
        = 1 / (2 · π² · ν²)                                             [асимптотична потужність у глибокій тіні]
J(ν) ≈ -10 · log₁₀(1 / (2 · π² · ν²))
     = 10 · log₁₀(2 · π²) + 20 · log₁₀(ν)
     = 10 · log₁₀(19.7392) + 20 · log₁₀(ν)
     ≈ 12.953 + 20 · log₁₀(ν) дБ                                        [логарифмічний закон згасання при ν > 1]
```

Звідси видно, що кожне подвоєння висоти перешкоди в зоні тіні збільшує дифракційні втрати рівно на `20 · log₁₀(2) ≈ 6.02 дБ`.

## Інженерні наближення ITU-R P.526

Для швидкого розрахунку втрат у вбудованих системах без обчислення спеціальних інтегралів Френеля Міжнародний союз електрозв'язку (ITU-R) у рекомендації P.526-15 стандартизував емпіричну формулу Лі (англ. *Lee approximation*):

```
J(ν) = 0                                         для ν ≤ -0.78
J(ν) = 6.9 + 20·log₁₀(√((ν - 0.1)² + 1) + ν - 0.1)    для ν > -0.78     [інженерне наближення ITU-R P.526]
```

Перевіримо значення формули у ключових точках:
- при `ν = 0`: `J(0) = 6.9 + 20·log₁₀(√(0.01 + 1) - 0.1) = 6.9 + 20·log₁₀(1.005 - 0.1) = 6.9 + 20·log₁₀(0.905) = 6.9 - 0.87 = 6.03 дБ` (відповідає теоретичним 6.02 дБ);
- при `ν = 1`: `J(1) = 6.9 + 20·log₁₀(√(0.81 + 1) + 0.9) = 6.9 + 20·log₁₀(1.345 + 0.9) = 6.9 + 20·log₁₀(2.245) = 6.9 + 7.02 = 13.92 дБ`;
- при `ν = 2`: `J(2) = 6.9 + 20·log₁₀(√(3.61 + 1) + 1.9) = 6.9 + 20·log₁₀(2.147 + 1.9) = 6.9 + 20·log₁₀(4.047) = 6.9 + 12.14 = 19.04 дБ`.

Похибка формули ITU-R P.526 не перевищує 0.2 дБ у всьому діапазоні значень `ν`.

## Множинні перешкоди: метод Дейго (Deygout Method)

Якщо на шляху поширення радіохвилі зустрічаються два або більше пагорбів, просте додавання втрат на кожному з них дає надмірно завищене згасання. Для коректного розрахунку використовують метод Дейго (фр. *Deygout*):

1. **Пошук головної перешкоди:** Для кожного пагорба `i` розраховують параметр `ν_i` відносно прямої лінії між антенами Tx та Rx. Пагорб із максимальним значенням `ν_main = max(ν_i)` оголошується головною перешкодою траси.
2. **Розрахунок головних втрат:** Обчислюють `J(ν_main)` за формулою ITU-R P.526.
3. **Розрахунок вторинних перешкод:**
   - Для перешкод ліворуч від головної будують нову візирну лінію між Tx та верхівкою головного пагорба, знаходячи параметр `ν_sub1` та втрати `J(ν_sub1)`;
   - Для перешкод праворуч будують візирну лінію між верхівкою головного пагорба та Rx, знаходячи `ν_sub2` та `J(ν_sub2)`.
4. **Сумарні втрати:**
   ```
   J_total = J(ν_main) + J(ν_sub1) + J(ν_sub2)                         [сумарні дифракційні втрати за методом Дейго]
   ```

Метод Дейго дає точність до 1.5–2.0 дБ при плануванні радіоліній над складним горбистим рельєфом.
