# 🧮 Термодинаміка тиску та розрахунок дихальних мембран

Ця вставка містить строге фізико-математичне виведення термодинамічних процесів у замкненому об'ємі електронного приладу: зміну тиску під час нагрівання й охолодження, кінетику вирівнювання тиску крізь мікропористу мембрану ePTFE та розрахунок гідростатичного тиску прориву води за рівнянням Юнга-Лапласа.

## 1. Ізохорний стрибок тиску в жорсткому корпусі

Розглянемо абсолютно герметичний об'єм `V`, заповнений сухим повітрям під час складання пристрою за початкової абсолютної температури `T₁` та атмосферного тиску `P₁`. Оскільки стінки суцільного корпусу недеформовні (або їхня пружна деформація мізерна порівняно з повним об'ємом), процес зміни стану газу є ізохорним (`V = const`).

Закон стану ідеального газу пов'язує тиск, об'єм, кількість речовини та абсолютну температуру:

```
P · V = n · R · T
```

де:
* `P` — абсолютний тиск усередині корпусу (Па);
* `V` — внутрішній вільний об'єм повітря (м³);
* `n` — кількість моль газу (моль);
* `R` — універсальна газова стала (8.31446 Дж/(моль·К));
* `T` — абсолютна температура повітря (К).

Під час роботи електроніки та нагрівання від зовнішнього сонячного випромінювання температура внутрішнього повітря зростає до значення `T₂`. За умови повної герметичності маса повітря не змінюється (`n = const`). Звідси випливає закон Гей-Люссака:

```
P₁ / T₁ = P₂ / T₂
```

Виразимо кінцевий абсолютний тиск `P₂` та надлишковий перепад тиску `ΔP = P₂ − P₁`:

```
ΔP = P₂ − P₁                 [означення перепаду тиску]
   = P₁ · (T₂ / T₁) − P₁      [підставили P₂ із закону Гей-Люссака]
   = P₁ · (T₂ / T₁ − 1)       [винесли P₁ за дужки]
   = P₁ · (T₂ − T₁) / T₁      [звели до спільного знаменника]
```

### Числовий розрахунок нагрівання

Нехай прилад складено в цеху за температури `t₁ = +20 °C` (`T₁ = 293.15 К`) за нормального атмосферного тиску `P₁ = 101325 Па` (101.325 кПа). Під час пікового навантаження під прямим сонцем повітря всередині прогрівається до `t₂ = +75 °C` (`T₂ = 348.15 К`).

```
ΔT = T₂ − T₁ = 348.15 − 293.15 = 55.0 К
P₂ = 101325 · (348.15 / 293.15) = 120335 Па (120.34 кПа)
ΔP = 120335 − 101325 = 19010 Па ≈ 19.01 кПа (190.1 мбар)
```

Результуюча механічна сила, що намагається відірвати кришку корпусу з площею `A = 0.04 м²` (200 мм × 200 мм):

```
F = ΔP · A                   [сила тиску на площу]
  = 19010 Па · 0.04 м²       [підставили значення ΔP та A]
  = 760.4 Н                  [обчислено підсумкове зусилля]
```

Сила понад 760 Н еквівалентна навантаженню масою приблизно 77.5 кг, прикладеній зсередини до тонкої стінки. Цей тиск вигинає кришку між гвинтами, створює мікрощілини в зоні пружного ущільнювача та виштовхує частину сухого повітря назовні.

## 2. Термічний удар і розрахунок розрідження (вакууму)

Припустимо, що під час нагрівання до `T₂ = 348.15 К` через нерівномірну деформацію ущільнювальної прокладки стравлюється частка маси повітря `α = 0.15` (15%). Усередині лишається кількість речовини `n₂ = (1 − α) · n₁ = 0.85 · n₁`.

Після цього прилад потрапляє під різку зливу, і стінки корпусу охолоджуються до температури води `t₃ = +12 °C` (`T₃ = 285.15 К`). Новий внутрішній тиск `P₃` становить:

```
P₃ = (n₂ · R · T₃) / V         [рівняння стану газу для охолодженого залишку]
   = 0.85 · (n₁ · R · T₃) / V  [підставили n₂ = 0.85 · n₁]
   = 0.85 · P₁ · (T₃ / T₁)     [замінили n₁·R/V на P₁/T₁]
   = 0.85 · 101325 · (285.15 / 293.15) [підставили числові значення]
   = 83777 Па (83.78 кПа)      [обчислений внутрішній тиск]
```

Перепад тиску відносно зовнішньої атмосфери (`P_зовн = 101.325 кПа`):

```
ΔP_вакуум = P₃ − P_зовн = 83.78 − 101.33 = −17.55 кПа (−175.5 мбар)
```

Від'ємний перепад тиску 17.55 кПа діє як потужна вакуумна помпа. Якщо по периметру ущільнення або на різьбі кабельних вводів є плівка води, зовнішній атмосферний тиск заштовхує цю воду в мікрозазори. Оскільки гідростатичний тиск 1 м водяного стовпа становить `ρ · g · h = 1000 · 9.81 · 1 = 9.81 кПа`, перепад −17.55 кПа еквівалентний зануренню приладу на глибину майже 1.8 метра з одночасним розкриттям ущільнювальних кромок.

## 3. Фізика проникності ePTFE та рівняння Юнга-Лапласа

Дихальна мембрана з розширеного політетрафторетилену (ePTFE) запобігає утворенню перепаду тиску завдяки капілярній структурі. Мембрана складається з вузлів полімеру, з'єднаних тонкими фібрилами, утворюючи тривимірний мікропористий лабіринт із характерним радіусом пор `r_пори = 0.1...1.5 мкм`.

### Гідрофобний бар'єр для рідкої води

Політетрафторетилен має вкрай низьку поверхневу енергію, через що кут змочування водою перевищує 90° (типово `θ ≈ 110°...120°`).

Капілярний тиск, необхідний для проштовхування рідини крізь циліндричну пору радіусом `r_пори`, описується рівнянням Юнга-Лапласа (тиск прориву води, Water Entry Pressure, WEP):

```
ΔP_entry = − (2 · γ_L · cos θ) / r_пори
```

де:
* `γ_L` — поверхневий натяг води на межі з повітрям (0.0728 Н/м при 20 °C);
* `θ` — крайовий кут змочування PTFE водою (`θ = 115°`, `cos 115° = −0.4226`);
* `r_пори` — ефективний радіус найбільшої пори (візьмемо несприятливий випадок `r = 0.5 мкм = 0.5 · 10⁻⁶ м`).

Обчислимо граничний тиск прориву води:

```
ΔP_entry = − (2 · 0.0728 · (−0.4226)) / (0.5 · 10⁻⁶)
         = 0.06153 / (0.5 · 10⁻⁶)
         = 123060 Па ≈ 123.1 кПа (1.231 бар)
```

Отримане значення 123.1 кПа відповідає висоті водяного стовпа:

```
h = ΔP_entry / (ρ · g) = 123060 / (1000 · 9.81) ≈ 12.54 метра води
```

Це доводить, чому мембрана ePTFE із середнім розміром пор до 1 мкм надійно витримує статичний тиск занурення за стандартом IP67 (1 м води, тобто ≈ 9.81 кПа) та IP68 (2...5 м води), зберігаючи повну бар'єрну герметичність для рідини.

## 4. Динаміка вирівнювання тиску крізь дихальний клапан

Розглянемо кінетику газообміну крізь пористу мембрану площею `A_вент` за наявності змінного перепаду тиску `ΔP(t) = P(t) − P_зовн`.

Для мікропористих структур газовий потік визначається комбінацією пуазейлівської в'язкої течії та дифузії Кнудсена. Інженерно повітропроникність мембрани нормується питомою пропускною здатністю `q_пит` (в літрах повітря на годину крізь квадратний сантиметр за перепаду `ΔP = 70 мбар = 7 кПа`):

```
Q_повітря = A_вент · q_пит · (ΔP / ΔP_ном)
```

Запишемо диференціальне рівняння балансу кількості газу в об'ємі `V` під час охолодження з постійною швидкістю `β = dT/dt < 0`:

```
dP/dt + (1 / τ_вент) · (P − P_зовн) = (P_зовн / T₀) · (dT/dt)
```

де `τ_вент` — характерна гідродинамічна стала часу вирівнювання тиску корпусу:

```
τ_вент = V / K_вент
```

де `K_вент = A_вент · (q_пит / ΔP_ном)` — коефіцієнт пропускної провідності клапана (м³/с·Па).

### Розрахунок площі мембрани

Для запобігання пошкодженню ущільнень максимальний перепад тиску під час різкого термічного удару не повинен перевищувати допустимої межі `ΔP_макс = 2.0 кПа` (20 мбар).

У квазістаціонарному режимі за постійної швидкості охолодження `β = |dT/dt|`:

```
ΔP_макс = τ_вент · (P_зовн / T₀) · β = (V / K_вент) · (P_зовн / T₀) · β
```

Звідси мінімально необхідна провідність дихального елемента:

```
K_вент ≥ (V · P_зовн · β) / (T₀ · ΔP_макс)
```

**Приклад розрахунку:**
* Вільний внутрішній об'єм: `V = 2.0 л = 2.0 · 10⁻³ м³`;
* Максимальна швидкість охолодження під зливою: `β = 30 °C/хв = 0.5 К/с`;
* Допустимий перепад: `ΔP_макс = 2000 Па`;
* Середня температура: `T₀ = 320 К`;
* Атмосферний тиск: `P_зовн = 101325 Па`.

```
K_вент ≥ (2.0 · 10⁻³ · 101325 · 0.5) / (320 · 2000)
       = 101.325 / 640000
       ≈ 1.583 · 10⁻⁴ м³/(с·кПа)
```

Це дорівнює:

```
K_вент ≥ 0.570 л/(хв·кПа) = 5.70 л/год на кожні 10 мбар перепаду.
```

Якщо обрана мембрана ePTFE за перепаду `ΔP = 70 мбар` забезпечує питомий потік `q_пит = 120 л/(год·см²)`, її ефективна площа `A_вент` має бути:

```
A_вент = Q_req / q_пит                 [необхідний потік поділити на питому провідність]
       = (5.70 · (70 / 10)) / 120      [приведення до перепаду 70 мбар]
       = 39.9 / 120                    [обчислення частки]
       ≈ 0.333 см²                     [площа активного вікна мембрани]
```

Ефективний діаметр дискової мембрани:

```
d_вент = √(4 · A_вент / π)            [діаметр кола через площу]
       = √(4 · 0.333 / 3.1416)         [підставили числові значення]
       = √0.424                        [обчислення кореня]
       ≈ 0.65 см = 6.5 мм              [мінімальний діаметр мембрани]
```

Таким чином, стандартний дихальний клапан із діаметром мембрани 10...12 мм (типорозмір різьби M12) повністю задовольняє вимоги компенсації тиску для дводіапазонного герметичного блоку об'ємом до 2 літрів.

## 5. Тепловий опір монолітного тепловідводу через термоміст

При прямій передачі тепла від кристала мікросхеми до стінки корпусу загальний тепловий опір `R_th,total` розраховується як послідовний ланцюг:

```
R_th,total = R_th,jc + R_th,tim + R_th,boss + R_th,wall + R_th,ext
```

де:
1. `R_th,jc` — тепловий опір «перехід-корпус» мікросхеми (задається даташитом, типово `0.5...2.5 °C/Вт` для FCBGA/QFN);
2. `R_th,tim` — опір теплопровідної еластичної прокладки (Gap Pad):

```
R_th,tim = t_tim / (k_tim · A_tim)
```

де `t_tim` — товщина прокладки під стисненням (0.5...1.5 мм), `k_tim` — теплопровідність матеріалу (1.5...6.0 Вт/(м·К)), `A_tim` — площа контакту (`25 × 25 мм = 6.25 · 10⁻⁴ м²`).

```
R_th,tim = (1.0 · 10⁻³ м) / (3.0 Вт/(м·К) · 6.25 · 10⁻⁴ м²)
         = 0.001 / 0.001875
         ≈ 0.533 °C/Вт
```

3. `R_th,boss` — тепловий опір алюмінієвого внутрішнього приливка (термомоста) висотою `L_boss = 8 мм` та площею `A_boss = 9 · 10⁻⁴ м²` (30 × 30 мм) для сплаву Al 6061 (`k_Al ≈ 170 Вт/(м·К)`):

```
R_th,boss = (8.0 · 10⁻³ м) / (170 Вт/(м·К) · 9.0 · 10⁻⁴ м²)
          = 0.008 / 0.153
          ≈ 0.052 °C/Вт
```

4. `R_th,ext` — тепловий опір зовнішньої поверхні корпусу з ребрами до навколишнього повітря за природної конвекції та випромінювання (загальна ефективна площа `A_ext = 0.08 м²`, коефіцієнт тепловіддачі `h_ext ≈ 12 Вт/(м²·К)`):

```
R_th,ext = 1 / (h_ext · A_ext)         [опір конвективної тепловіддачі]
         = 1 / (12 · 0.08)             [підставили площу та h_ext]
         = 1 / 0.96                    [обчислення знаменника]
         ≈ 1.042 °C/Вт                 [тепловий опір зовнішнього корпусу]
```

Сумарний тепловий опір від кристала до зовнішнього середовища:

```
R_th,total = 1.20 (R_th,jc) + 0.533 (R_th,tim) + 0.052 (R_th,boss) + 0.080 (R_th,wall) + 1.042 (R_th,ext)
           ≈ 2.91 °C/Вт
```

За розсіюваної потужності процесора `P_chip = 12 Вт` перегрів кристала відносно зовнішнього повітря становитиме:

```
ΔT_j-amb = P_chip · R_th,total        [закон Ома для теплового кола]
         = 12 Вт · 2.91 °C/Вт         [підставили потужність та опір]
         = 34.9 °C                    [перегрів кристала над довкіллям]
```

За максимальної температури навколишнього повітря +50 °C температура кремнієвого переходу складе `T_j = 50 + 34.9 = 84.9 °C`, що знаходиться глибоко всередині допустимої зони для промислових чипів (`T_j,max = 105...125 °C`).
