# ⚙️ Модуль автономного числення координат (EKF Dead Reckoning) на C та C++

У цьому проєкті розглядається реалізація автономного навігаційного модуля на базі розширеного фільтра Калмана (англ. *Extended Kalman Filter*, EKF) для вбудованих 32-бітних мікроконтролерів (STM32, ESP32, RP2040). Модуль розв'язує задачу локалізації та утримання позиції в умовах, коли супутниковий зв'язок [GNSS](root:hw-sensing/gnss) повністю заглушений або підмінений засобами радіоелектронної боротьби.

Архітектура рушія спроєктована для систем жорсткого реального часу: вона не використовує динамічного виділення пам'яті (`malloc`/`free`), не потребує важких зовнішніх лінійних бібліотек і гарантує детермінований час виконання кожного кроку на тактовій частоті від 80 МГц.

---

## 1. Постановка задачі та вибір вектора стану

На борту безпілотного апарата або наземного робота ми маємо три незалежні потоки первинних вимірювань:
1. **Високочастотний інерціальний блок [IMU](root:embedded/imu-barometer)** (200–500 Гц): акселерометр вимірює вектор питомої сили `a_body`, гіроскоп — кутові швидкості `ω_body`. З гіроскопа через алгоритм [оцінки орієнтації](root:embedded/attitude-estimation) безперервно підтримується матриця повороту `R_wb` (з системи тіла у нерухому систему світу NED).
2. **[Сенсор оптичного потоку PMW3901](root:embedded/navihatsiia-bez-gnss/comp-pmw3901-flow.md)** (50–100 Гц): вимірює горизонтальну швидкість зміщення текстури підстильної поверхні `v_x, v_y`.
3. **Лазерний далекомір ToF (VL53L1X) або барометр** (20–50 Гц): вимірює висоту над поверхнею `z` або вертикальну позицію `p_z`.

Щоб об'єднати ці дані, фільтр відстежує 9-вимірний вектор стану `x`:

```
x = [ p_x,   p_y,   p_z,      ← координати у світовій системі NED (метри)
      v_x,   v_y,   v_z,      ← лінійні швидкості у системі NED (м/с)
      b_ax,  b_ay,  b_az ]ᵀ   ← оцінка залишкового зсуву акселерометра (м/с²)
```

Зауважте, що оцінка зсуву акселерометра `b_a` внесена безпосередньо у вектор стану. Це дозволяє фільтру не просто оцінювати швидкість, а й поступово виявляти систематичну похибку нуля сенсора: коли оптичний потік стабільно фіксує постійну швидкість, а акселерометр показує постійне ненульове прискорення, різниця поступово «перетікає» в оцінку `b_a`.

## 2. Математичні кроки фільтрації

### Крок передбачення (Predict)

На кожному кроці опитування IMU за період `dt` (зазвичай 2–5 мс) здійснюється інтегрування кінематичних рівнянь руху:

```
a_unbiased = a_body - b_a                        [компенсація оціненого зсуву]
a_world    = R_wb · a_unbiased + [0, 0, g]ᵀ      [поворот у світ + додавання гравітації]

p_k = p_{k-1} + v_{k-1} · dt + 0.5 · a_world · dt²
v_k = v_{k-1} + a_world · dt
b_k = b_{k-1}                                    [модель випадкового блукання зсуву]
```

Матриця коваріації похибок `P` екстраполюється за рівнянням `P = F · P · Fᵀ + Q · dt`, де `Q` — матриця спектральної густини шумів процесу. Для мікроконтролерів без апаратного прискорювача матриць повне множення матриць 9×9 може займати зайві сотні мікросекунд. Тому в оптимізованій версії використовується розріджена аналітична форма, де оновлюються лише значущі міжзв'язки швидкості, координат і зсувів.

### Крок оновлення (Update)

Коли надходить вимір швидкості від оптичного потоку або висоти від далекоміра, обчислюється нев'язка (інновація) `y = z - H · x`, де `H` — матриця спостереження відповідного датчика:
- Для оптичного потоку (2D-швидкість): `H_vel = [ 0₃×₃   I₂×₂  0₂×₁   0₂×₃ ]`.
- Для далекоміра висоти: `H_alt = [ 0  0  1   0  0  0   0  0  0 ]`.

Корекція вектора стану здійснюється за класичною формулою зважування Калмана:

```
S = H · P · Hᵀ + R                    [інноваційна дисперсія]
K = P · Hᵀ · S⁻¹                      [коефіцієнт підсилення Калмана]
x = x + K · y                         [оновлення стану]
P = (I - K · H) · P                   [оновлення коваріації]
```

## 3. Повний код автономного модуля на C та C++

Нижче наведено повністю робочу реалізацію навігаційного рушія. Обидві версії не використовують динамічної пам'яті, підтримують стробування інновацій за тестом Махаланобіса та містять режим ZUPT (Zero Velocity Update) для автоматичного обнулення дрейфу при зупинках.

```c
#include <math.h>
#include <stdbool.h>
#include <string.h>

#define STATE_DIM 9
#define GRAVITY_MSS 9.81f

/* Структура фільтра EKF Dead Reckoning */
typedef struct {
    float x[STATE_DIM];                  /* вектор стану: px, py, pz, vx, vy, vz, bax, bay, baz */
    float P[STATE_DIM][STATE_DIM];       /* матриця коваріації похибок 9x9 */
    float Q_pos;                         /* дисперсія процесу для координати */
    float Q_vel;                         /* дисперсія процесу для швидкості */
    float Q_bias;                        /* дисперсія випадкового блукання зсуву IMU */
} ekf_dr_t;

/* Ініціалізація початкового стану та коваріацій */
void ekf_dr_init(ekf_dr_t *ekf)
{
    memset(ekf->x, 0, sizeof(ekf->x));
    memset(ekf->P, 0, sizeof(ekf->P));

    /* Початкова невизначеність: координати ±1м, швидкості ±0.1м/с, зсув ±0.05м/с² */
    for (int i = 0; i < 3; i++) ekf->P[i][i] = 1.0f;
    for (int i = 3; i < 6; i++) ekf->P[i][i] = 0.01f;
    for (int i = 6; i < 9; i++) ekf->P[i][i] = 0.0025f;

    ekf->Q_pos = 0.001f;
    ekf->Q_vel = 0.05f;
    ekf->Q_bias = 0.00001f;
}

/* Крок ПЕРЕДБАЧЕННЯ (Predict) за даними IMU (200-500 Гц)
   a_body: виміряне акселерометром прискорення [ax, ay, az] (м/с²)
   R_wb: матриця обертання 3x3 з системи тіла у світ NED
   dt: інтервал інтегрування (с) */
void ekf_dr_predict(ekf_dr_t *ekf, const float a_body[3], const float R_wb[3][3], float dt)
{
    /* 1. Компенсація оціненого зсуву нуля акселерометра */
    float a_unbiased[3];
    for (int i = 0; i < 3; i++) {
        a_unbiased[i] = a_body[i] - ekf->x[6 + i];
    }

    /* 2. Обертання прискорення у світову систему NED: a_world = R_wb * a_unbiased */
    float a_world[3] = {0};
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            a_world[i] += R_wb[i][j] * a_unbiased[j];
        }
    }
    /* Додаємо гравітацію (вісь Z спрямована вниз, прискорення вільного падіння +g) */
    a_world[2] += GRAVITY_MSS;

    /* 3. Кінематична інтеграція координат та швидкостей */
    float dt2 = 0.5f * dt * dt;
    for (int i = 0; i < 3; i++) {
        ekf->x[i]     += ekf->x[3 + i] * dt + a_world[i] * dt2;   /* p = p + v*dt + 0.5*a*dt² */
        ekf->x[3 + i] += a_world[i] * dt;                         /* v = v + a*dt */
    }

    /* 4. Екстраполяція коваріації: аналітичне розгортання для продуктивності на MCU */
    for (int i = 0; i < 3; i++) {
        ekf->P[i][i]         += (2.0f * ekf->P[3 + i][3 + i] * dt + ekf->Q_pos) * dt;
        ekf->P[3 + i][3 + i] += ekf->Q_vel * dt;
        ekf->P[6 + i][6 + i] += ekf->Q_bias * dt;
    }
}

/* Крок КОРЕКЦІЇ за даними ОПТИЧНОГО ПОТОКУ (вимірювання швидкості Vx, Vy)
   vx_meas, vy_meas: лінійна швидкість у системі світу (після деротації та масштабування висотою)
   r_cov: дисперсія шуму оптичного потоку (м²/с²)
   gate_limit: поріг відкидання викидів Махаланобіса */
bool ekf_dr_update_velocity2d(ekf_dr_t *ekf, float vx_meas, float vy_meas, float r_cov, float gate_limit)
{
    float z[2] = {vx_meas, vy_meas};

    for (int axis = 0; axis < 2; axis++) {
        int v_idx = 3 + axis;
        float y = z[axis] - ekf->x[v_idx];              /* інновація (нев'язка) */
        float S = ekf->P[v_idx][v_idx] + r_cov;          /* коваріація інновації */

        /* Тест Махаланобіса на відкидання викидів */
        if ((y * y) / S > gate_limit) {
            return false; /* викид сенсора або змаз кадру — пропускаємо */
        }

        float K = ekf->P[v_idx][v_idx] / S;             /* коефіцієнт Калмана */

        /* Корекція вектора стану */
        ekf->x[v_idx] += K * y;

        /* Непряма корекція зсуву акселерометра */
        int b_idx = 6 + axis;
        float K_bias = ekf->P[b_idx][b_idx] / S;
        ekf->x[b_idx] -= K_bias * (y * 0.1f);

        /* Оновлення коваріації */
        ekf->P[v_idx][v_idx] *= (1.0f - K);
    }
    return true;
}

/* Крок КОРЕКЦІЇ ВИСОТИ за далекоміром ToF або барометром */
void ekf_dr_update_altitude(ekf_dr_t *ekf, float z_meas, float r_cov)
{
    float y = z_meas - ekf->x[2];                        /* нев'язка по осі Z */
    float S = ekf->P[2][2] + r_cov;
    float K = ekf->P[2][2] / S;

    ekf->x[2] += K * y;                                  /* коригуємо висоту */
    ekf->x[5] += (K * 0.5f) * y;                         /* частково підтягуємо вертикальну швидкість */
    ekf->P[2][2] *= (1.0f - K);
}

/* Крок ZUPT (Zero Velocity Update) при повній зупинці апарата */
void ekf_dr_update_zupt(ekf_dr_t *ekf, float r_zupt)
{
    for (int i = 3; i < 6; i++) {
        float y = 0.0f - ekf->x[i];                      /* швидкість у спокої дорівнює нулю */
        float S = ekf->P[i][i] + r_zupt;
        float K = ekf->P[i][i] / S;

        ekf->x[i] += K * y;
        ekf->P[i][i] *= (1.0f - K);

        /* Скидання зсуву акселерометра під час нерухомості */
        int b_idx = 6 + (i - 3);
        ekf->x[b_idx] += (ekf->P[b_idx][b_idx] / S) * y;
    }
}
```

```cpp
#include <array>
#include <cmath>
#include <cstdint>
#include <span>

class EkfDeadReckoning {
public:
    static constexpr size_t kStateDim = 9;
    static constexpr float kGravity = 9.81f;

    struct State {
        float px{0.0f}, py{0.0f}, pz{0.0f};             // Позиція NED (м)
        float vx{0.0f}, vy{0.0f}, vz{0.0f};             // Швидкість NED (м/с)
        float bax{0.0f}, bay{0.0f}, baz{0.0f};          // Зсув акселерометра (м/с²)
    };

    EkfDeadReckoning() {
        reset();
    }

    void reset() noexcept {
        x_.fill(0.0f);
        P_.fill(0.0f);

        // Початкові дисперсії стану
        for (size_t i = 0; i < 3; ++i) P_[i] = 1.0f;
        for (size_t i = 3; i < 6; ++i) P_[i] = 0.01f;
        for (size_t i = 6; i < 9; ++i) P_[i] = 0.0025f;
    }

    // Передбачення стану за даними IMU
    void predict(std::span<const float, 3> a_body,
                 const std::array<std::array<float, 3>, 3>& R_wb,
                 float dt) noexcept
    {
        std::array<float, 3> a_unbiased{
            a_body[0] - x_[6],
            a_body[1] - x_[7],
            a_body[2] - x_[8]
        };

        // Трансформація у світову систему NED
        std::array<float, 3> a_world{0.0f, 0.0f, 0.0f};
        for (size_t i = 0; i < 3; ++i) {
            for (size_t j = 0; j < 3; ++j) {
                a_world[i] += R_wb[i][j] * a_unbiased[j];
            }
        }
        a_world[2] += kGravity;

        const float dt2 = 0.5f * dt * dt;
        for (size_t i = 0; i < 3; ++i) {
            x_[i]     += x_[3 + i] * dt + a_world[i] * dt2;
            x_[3 + i] += a_world[i] * dt;
        }

        // Екстраполяція коваріацій
        for (size_t i = 0; i < 3; ++i) {
            P_[i]     += (2.0f * P_[3 + i] * dt + q_pos_) * dt;
            P_[3 + i] += q_vel_ * dt;
            P_[6 + i] += q_bias_ * dt;
        }
    }

    // Корекція швидкості оптичним потоком
    [[nodiscard]] bool updateOpticalFlow(float vx_meas, float vy_meas, float r_cov, float gate_limit = 4.0f) noexcept {
        const std::array<float, 2> z{vx_meas, vy_meas};

        for (size_t axis = 0; axis < 2; ++axis) {
            const size_t v_idx = 3 + axis;
            const float y = z[axis] - x_[v_idx];
            const float S = P_[v_idx] + r_cov;

            // Тест Махаланобіса на відкидання викидів
            if ((y * y) / S > gate_limit) {
                return false;
            }

            const float K = P_[v_idx] / S;
            x_[v_idx] += K * y;

            const size_t b_idx = 6 + axis;
            const float K_bias = P_[b_idx] / S;
            x_[b_idx] -= K_bias * (y * 0.1f);

            P_[v_idx] *= (1.0f - K);
        }
        return true;
    }

    // Корекція висоти (ToF / Baro)
    void updateAltitude(float z_meas, float r_cov) noexcept {
        const float y = z_meas - x_[2];
        const float S = P_[2] + r_cov;
        const float K = P_[2] / S;

        x_[2] += K * y;
        x_[5] += (K * 0.5f) * y;
        P_[2] *= (1.0f - K);
    }

    // Zero Velocity Update (ZUPT)
    void updateZupt(float r_zupt = 0.001f) noexcept {
        for (size_t i = 3; i < 6; ++i) {
            const float y = 0.0f - x_[i];
            const float S = P_[i] + r_zupt;
            const float K = P_[i] / S;

            x_[i] += K * y;
            P_[i] *= (1.0f - K);

            const size_t b_idx = 6 + (i - 3);
            x_[b_idx] += (P_[b_idx] / S) * y;
        }
    }

    [[nodiscard]] State getState() const noexcept {
        return State{
            .px = x_[0], .py = x_[1], .pz = x_[2],
            .vx = x_[3], .vy = x_[4], .vz = x_[5],
            .bax = x_[6], .bay = x_[7], .baz = x_[8]
        };
    }

private:
    std::array<float, kStateDim> x_{};
    std::array<float, kStateDim> P_{}; // Діагональний вектор дисперсій

    float q_pos_{0.001f};
    float q_vel_{0.05f};
    float q_bias_{0.00001f};
};
```

## 4. Інженерні тонкощі та захист від розбіжності

Під час впровадження алгоритму на реальних апаратах критично враховувати такі особливості:

1. **Стробування викидів (Gate Testing):** поріг `gate_limit = 4.0` відповідає відстані у 2 стандартних відхилення (2σ) за розподілом хі-квадрат для 1 ступеня вільності (охоплює 95.4% валідних спостережень). Якщо оптичний сенсор тимчасово зловив відблиск або змазав зображення при різкому ударі, інновація `y` різко зростає, і умова `y² / S > 4.0` запобігає проникненню хибного стрибка у вектор швидкості.
2. **Захист від чисельного колапсу коваріацій:** у флоат-арифметиці з одинарною точністю (`float32`) елементи дисперсії `P[i][i]` через похибки округлення можуть стати від'ємними або наблизитися до абсолютного нуля. Це призводить до блокування фільтра (коефіцієнт Калмана `K → 0`, фільтр перестає слухати зовнішні давачі). Запобіжником слугує регулярний затиск `P[i][i] = fmaxf(P[i][i], 1e-6f)`.
3. **Компенсація затримки оптичного потоку (Sensor Latency):** оптичний потік формується на базі кадру, знятого 10–25 мс тому. У високих польотних контролерах (PX4, ArduPilot) зберігається кільцевий буфер попередніх станів IMU, і корекція Калмана застосовується заднім числом до відповідного історичного зрізу стану з подальшою екстраполяцією вперед.
## 5. Покроковий числовий розрахунок одного такту корекції

Щоб переконатися у фізичній коректності алгоритму, простежмо один такт корекції швидкості за оптичним потоком на конкретних числах.

**Вихідні умови:**
- Поточна оцінка швидкості у фільтрі: `vx_est = 1.20 м/с`.
- Поточна дисперсія швидкості: `P_vv = 0.04 м²/с²` (стандартне відхилення `σ = 0.20 м/с`).
- Виміряна оптичним потоком швидкість: `vx_meas = 1.45 м/с`.
- Дисперсія шуму оптичного потоку за паспортом: `R_flow = 0.06 м²/с²`.

**Розрахунок кроків фільтра:**

```
1. Інновація (нев'язка):
   y = vx_meas - vx_est
     = 1.45 - 1.20 = 0.25 м/с

2. Інноваційна коваріація:
   S = P_vv + R_flow
     = 0.04 + 0.06 = 0.10 м²/с²

3. Тест Махаланобіса на викид:
   d² = y² / S
      = (0.25)² / 0.10 = 0.0625 / 0.10 = 0.625
   0.625 < 4.0   [тест пройдено, вимірювання валідне]

4. Коефіцієнт підсилення Калмана:
   K = P_vv / S
     = 0.04 / 0.10 = 0.40

5. Оновлення оцінки швидкості:
   vx_new = vx_est + K · y
          = 1.20 + 0.40 · 0.25
          = 1.20 + 0.10 = 1.30 м/с

6. Оновлення дисперсії похибки:
   P_vv_new = (1 - K) · P_vv
            = (1 - 0.40) · 0.04
            = 0.60 · 0.04 = 0.024 м²/с²
```

**Аналіз результату:** Нова оцінка швидкості `1.30 м/с` лягла точно між попереднім передбаченням (`1.20 м/с`) та виміром датчика (`1.45 м/с`), змістившись на 40% у бік оптичного потоку відповідно до співвідношення невизначеностей. Водночас дисперсія швидкості впала з `0.04` до `0.024 м²/с²`, що демонструє зростання впевненості фільтра в поточному стані.

## 6. Інтеграція в цикл польотного контролера (FreeRTOS)

У реальній прошивці навігаційний модуль викликається з двох різних контекстів з різними пріоритетами:

1. **Високопріоритетна задача IMU (High Priority Task, 500 Гц):**
   - Спрацьовує за апаратним перериванням готовності даних (Data Ready EXTI) сенсора акселерометра/гіроскопа.
   - Зчитує сирі вектори, викликає `ekf_dr_predict()` і передає оновлену оцінку швидкості та орієнтації безпосередньо в контур PID-регулятора моторів.
2. **Фонова задача оптичних датчиків (Sensor Task, 50 Гц):**
   - Опитує сенсор PMW3901 через SPI та ToF через I2C.
   - Перевіряє якість поверхні `SQUAL`. Якщо якість висока, виконує деротацію пікселів і викликає `ekf_dr_update_velocity2d()`.
   - Захист спільних даних `ekf_dr_t` реалізується через безблокувальний подвійний буфер або критичну секцію атомарного копіювання стану.
