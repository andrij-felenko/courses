# 🧮 Виведення кубічного та квадратичного дрейфу інерціальної навігації

Коли безпілотний апарат або наземний робот втрачає супутниковий сигнал [GNSS](root:hw-sensing/gnss), його навігаційна система вимушена спиратися на власні внутрішні давачі руху — акселерометри та гіроскопи [інерціального блока IMU](root:embedded/imu-barometer). У теорії все виглядає бездоганно: двічі проінтегрувавши прискорення, отримуємо точну координату. На практиці ж за лічені десятки секунд автономного руху розрахована позиція «вибухає» похибкою в сотні метрів або навіть кілометри.

Цей математичний розбір показує строге аналітичне виведення того, чому похибка координати росте саме за квадратичним та кубічним законами від часу, звідки береться головний внесок у розбіжність траєкторії та як шуми чутливих елементів обмежують тривалість чисто інерціального руху.

---

## 1. Структура похибок вимірювання в MEMS IMU

Вихідний сигнал реального мікроелектромеханічного (MEMS) сенсора не збігається з фізично істинною величиною. Для кожної осі акселерометра та гіроскопа виміряне значення моделюється сумою трьох компонентів:

```
a_meas(t) = a_true(t) + b_a + w_a(t)      [акселерометр: істина + зсув + шум]
ω_meas(t) = ω_true(t) + b_ω + w_ω(t)      [гіроскоп: істина + зсув + шум]
```

Тут:
- `a_true(t)`, `ω_true(t)` — справжнє лінійне прискорення та кутова швидкість апарата;
- `b_a`, `b_ω` — постійне зміщення нуля (англ. *sensor bias*), що виникає через неідеальність кристала, механічні напруження корпусу та температурний градієнт;
- `w_a(t)`, `w_ω(t)` — високочастотний некорельований білий шум сенсора (англ. *white noise*) з нульовим математичним сподіванням і спектральною густиною потужності.

Розгляньмо вплив кожної з цих складових на розрахунок положення окремо.

## 2. Квадратичний дрейф від зсуву нуля акселерометра

Припустімо, що орієнтація апарата відома ідеально (похибка гіроскопа тимчасово відсутня), але акселерометр має нескомпенсований постійний зсув нуля `b_a` уздовж осі руху.

Навігаційний алгоритм обчислює швидкість `v(t)` та координату `p(t)` послідовним інтегруванням прискорення:

```
v(t) = v₀ + ∫₀ᵗ a_meas(τ) dτ
p(t) = p₀ + ∫₀ᵗ v(τ) dτ
```

Підставимо модель вимірювання зі зсувом нуля `a_meas(t) = a_true(t) + b_a`:

```
v(t) = v₀ + ∫₀ᵗ (a_true(τ) + b_a) dτ
     = v_true(t) + b_a · t                 [лінійне накопичення похибки швидкості]

p(t) = p₀ + ∫₀ᵗ (v_true(τ) + b_a · τ) dτ
     = p_true(t) + (1/2) · b_a · t²        [квадратичне накопичення похибки позиції]
```

Похибка положення `Δp_acc(t) = p(t) - p_true(t)` залежить виключно від зсуву нуля та квадрата часу:

```
Δp_acc(t) = (1/2) · b_a · t²
```

### Числовий розрахунок для типового MEMS акселерометра

Візьмемо типовий польотний акселерометр з залишковим після калібрування зсувом нуля `b_a = 0.05 м/с²` (приблизно 5 mg):

```
t = 10 с:   Δp = 0.5 · 0.05 · (10)²  = 0.025 · 100   = 2.5 м
t = 30 с:   Δp = 0.5 · 0.05 · (30)²  = 0.025 · 900   = 22.5 м
t = 60 с:   Δp = 0.5 · 0.05 · (60)²  = 0.025 · 3600  = 90.0 м
t = 120 с:  Δp = 0.5 · 0.05 · (120)² = 0.025 · 14400 = 360.0 м
```

Лише за одну хвилину апарат відхиляється на 90 метрів від точки розрахунку. Проте, як показує наступний крок, зсув акселерометра — це лише менша частина проблеми.

## 3. Кубічний дрейф від зсуву нуля гіроскопа

Акселерометр закріплений усередині корпусу апарата і вимірює питому силу у зв'язаній системі координат (англ. *body frame*). Щоб перенести виміряні вектори в нерухому систему світу (англ. *navigation frame*, NED — North-East-Down) і відняти вектор вільного падіння Землі `g = 9.81 м/с²`, необхідно безперервно знати матрицю орієнтації корпусу.

Орієнтацію обчислюють інтегруванням виміряних кутових швидкостей `ω_meas(t)`. Якщо гіроскоп має постійний зсув нуля `b_ω`, накопичена кутова похибка орієнтації `Δθ(t)` росте лінійно з часом:

```
Δθ(t) = ∫₀ᵗ b_ω dτ = b_ω · t
```

Під час проєкції виміряного прискорення в систему світу навігаційний фільтр намагається скомпенсувати силу тяжіння, віднімаючи вектор `g`. Але через помилку в куті `Δθ(t)` вектор гравітації компенсується під хибним нахилом. 

У результаті з'являється уявне горизонтальне прискорення `a_err(t)`, пропорційне синусу кутової похибки:

```
a_err(t) = g · sin(Δθ(t))
```

Для малих кутів (`Δθ << 1 рад`) наближення `sin(Δθ) ≈ Δθ` дає:

```
a_err(t) ≈ g · b_ω · t                     [лінійно зростаюче хибне прискорення]
```

Тепер знайдемо похибку швидкості `Δv_gyro(t)` подвійним інтегруванням цієї штучної сили:

```
Δv_gyro(t) = ∫₀ᵗ a_err(τ) dτ
           = ∫₀ᵗ (g · b_ω · τ) dτ
           = (1/2) · g · b_ω · t²          [квадратична похибка швидкості]
```

Інтегруючи похибку швидкості ще раз за часом, отримуємо похибку координати `Δp_gyro(t)`:

```
Δp_gyro(t) = ∫₀ᵗ Δv_gyro(τ) dτ
           = ∫₀ᵗ ((1/2) · g · b_ω · τ²) dτ
           = (1/6) · g · b_ω · t³          [кубічна похибка координати!]
```

Це фундаментальний закон інерціальної навігації: **зсув нуля гіроскопа призводить до кубічного накопичення похибки позиції з часом**, оскільки він нахиляє вектор гравітації Землі `g`.

```
Δp_gyro(t) = (1/6) · g · b_ω · t³
```

### Числовий розрахунок кубічного дрейфу

Візьмемо типовий дешевий MEMS гіроскоп польотного контролера (серії ICM-42688 або BMI270). Нескомпенсований температурний дрейф нуля після взльоту становить приблизно `b_ω = 0.5 °/с` (переведемо в радіани: `0.5 · π / 180 ≈ 0.008726 рад/с`).

Прискоримо розрахунок за формулою при `g = 9.81 м/с²`:

```
Множник: (1/6) · g · b_ω = (1/6) · 9.81 · 0.008726 ≈ 0.014267 м/с³

t = 10 с:   Δp = 0.014267 · (10)³   = 0.014267 · 1000     = 14.3 м
t = 30 с:   Δp = 0.014267 · (30)³   = 0.014267 · 27000    = 385.2 м
t = 60 с:   Δp = 0.014267 · (60)³   = 0.014267 · 216000   = 3081.7 м
t = 120 с:  Δp = 0.014267 · (120)³  = 0.014267 · 1728000  = 24653.8 м
```

Порівняйте: через 60 секунд зсув акселерометра дав 90 метрів похибки, тоді як зсув гіроскопа через проекцію сили тяжіння дав понад **3 кілометри** розбіжності! Гіроскоп руйнує автономне числення координат у десятки разів швидше за акселерометр.

## 4. Випадковий блукаючий шум (Random Walk)

Окрім постійних зміщень нуля `b`, кожен сенсор має білий шум вимірювань `w(t)` зі спектральною густиною `N_a` (для акселерометра, вимірюється в `м/с²/√Гц`) та `N_ω` (для гіроскопа, вимірюється в `рад/с/√Гц` або `°/√год`).

Інтегрування білого шуму породжує нестаціонарний випадковий процес — випадкове блукання (англ. *Random Walk*):

### Похибка швидкості та положення від шуму акселерометра (Velocity Random Walk, VRW)

Дисперсія інтеграла швидкості зростає лінійно з часом:

```
σ_v²(t) = N_a² · t
```

Дисперсія позиції після другого інтегрування зростає як куб часу:

```
σ_p_acc²(t) = (1/3) · N_a² · t³
```

Відповідно, середньоквадратичне відхилення (стандартна похибка) положення росте пропорційно `t^(3/2)`.

### Похибка орієнтації та положення від шуму гіроскопа (Angular Random Walk, ARW)

Дисперсія кута орієнтації росте лінійно:

```
σ_θ²(t) = N_ω² · t
```

Шум кута призводить до стохастичного хибного нахилу сили тяжіння `g`. Дисперсія похибки координати через шум гіроскопа зростає пропорційно **п'ятому ступеню часу**:

```
σ_p_gyro²(t) = (1/20) · g² · N_ω² · t⁵
```

Стандартне середньоквадратичне відхилення положення через випадковий шум гіроскопа збільшується як `t^(5/2)`:

```
σ_p_gyro(t) = (g · N_ω / √20) · t^(2.5)
```

## 5. Підсумковий баланс похибок автономної інерціальної системи

Зведемо всі компоненти розбіжності координат у єдину таблицю за їхнім внеском у часі:

| Джерело похибки | Фізична причина | Похибка швидкості `Δv(t)` | Похибка координати `Δp(t)` | Порядок величини за 60 с |
|---|---|---|---|---|
| **Зсув акселерометра `b_a`** | Несиметрія MEMS-балок | `b_a · t` (лінійна) | `(1/2) · b_a · t²` (квадратична) | 50 – 150 м |
| **Зсув гіроскопа `b_ω`** | Температурний дрейф нуля | `(1/2) · g · b_ω · t²` (квадратична) | `(1/6) · g · b_ω · t³` (**кубічна**) | **1000 – 4000 м** |
| **Білий шум акселерометра `N_a`** | Тепловий шум сенсора | `~ √t` | `~ t^(1.5)` | 2 – 10 м |
| **Білий шум гіроскопа `N_ω`** | Тепловий шум кристала | `~ t^(1.5)` | `~ t^(2.5)` | 20 – 100 м |

### Інженерний висновок

1. Оцінка орієнтації є критично важливішою за оцінку прискорення: будь-яка мікроскопічна похибка в кутах нахилу множиться на величезне земне прискорення `g = 9.81 м/с²` і тричі інтегрується в координату.
2. Чисто інерціальна автономна навігація на бюджетних MEMS-сенсорах без зовнішньої корекції фізично обмежена інтервалом часу в **10–20 секунд**, після чого розбіжність робить політ або рух неконтрольованим.
3. Щоб зупинити кубічний розгін похибки, навігаційна система потребує прямого вимірювання швидкості (оптичний потік, енкодери коліс, доплерівський радар) або періодичної корекції нульової швидкості (ZUPT).
