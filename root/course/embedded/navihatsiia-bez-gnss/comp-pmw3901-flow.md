# 🔌 Давач оптичного потоку PMW3901 та лазерний ToF-висотомір

Коли безпілотний літальний апарат або колісний робот опиняється в умовах придушення чи підміни сигналів супутникової навігації [GNSS](root:hw-sensing/gnss), найефективнішим способом зупинити кубічний дрейф інерціальної системи стає відстеження підстильної поверхні. Для цього використовують зв'язку з двох датчиків: сенсора **оптичного потоку** (англ. *optical flow*, типовий представник — чіп **PMW3901** від PixArt Imaging) та **лазерного далекоміра** часу прольоту (англ. *Time-of-Flight*, ToF, наприклад **VL53L1X** від STMicroelectronics).

Цей огляд розбирає внутрішній устрій та фізику вимірювань сенсора оптичного потоку, схему його сполучення з лазерним висотоміром, математичний алгоритм деротації на мікроконтролері та граничні умови, за яких сенсор втрачає зчеплення з поверхнею.

---

## 1. Фізичний принцип оптичного потоку та архітектура PMW3901

Сенсор PMW3901 являє собою мініатюрну монохромну камеру з вбудованим цифровим сигнальним процесором (DSP). На кристалі розміщено світлочутливу матрицю розміром 35×35 або 30×30 пікселів, спеціалізовану оптику з фіксованим фокусом та апаратний корелятор зображень, який працює на надвисокій частоті кадрів (від 100 до кількох сотень кадрів на секунду).

### Як обчислюється зміщення

Сенсор не передає сирі зображення на головний процесор польотного контролера (це перевантажило б шину зв'язку). Натомість внутрішній DSP самостійно порівнює сусідні кадри, обчислюючи двовимірну просторову автокореляцію характерних градієнтів яскравості (текстури ґрунту, трави, асфальту, підлоги):

1. **Захоплення опорного кадру:** фіксується матриця яскравості `I(x, y, t)`.
2. **Захоплення наступного кадру:** через короткий фіксований проміжок часу `Δt` зчитується матриця `I(x, y, t + Δt)`.
3. **Пошук вектора зсуву:** апаратний корелятор знаходить вектор `[Δu, Δv]` (у пікселях), який мінімізує різницю між зображеннями за формулою оптичного потоку:

```
I(u + Δu, v + Δv, t + Δt) ≈ I(u, v, t)
```

4. **Видача результату:** у вихідних регістрах сенсора з'являються цілочисельні дельти зміщення пікселів `delta_x` та `delta_y`, а також оцінка якості підстильної текстури (регістр `SQUAL` — Surface Quality).

## 2. Апаратне підключення та інтерфейси

Модуль оптичного потоку зазвичай об'єднує сенсор PMW3901 та лазерний далекомір ToF на єдиній мініатюрній друкованій платі, змонтованій на днищі апарата об'єктивом суворо вертикально вниз.

```
┌─────────────────────────────────────────────────────────────┐
│                    Бортовий контролер (MCU)                 │
│                                                             │
│   [ SPI Master ]              [ I2C Master ]    [ GPIO In ] │
│   SCK  MISO MOSI CS               SCL  SDA         INT      │
└────┬────┬────┬───┬─────────────────┬────┬───────────┬───────┘
     │    │    │   │                 │    │           │
     │    │    │   │                 │    │           │
┌────┴────┴────┴───┴─────┐     ┌─────┴────┴───────────┴───────┐
│     PMW3901 Flow       │     │       VL53L1X ToF            │
│  (Оптичний потік)      │     │    (Лазерний далекомір)      │
│  - SPI до 2–4 МГц      │     │    - I2C Fast-Mode 400 кГц   │
│  - Інтеграл зміщення   │     │    - Дистанція: 0.04–4.00 м  │
│  - Регістр якості SQUAL│     │    - Точність: ±1–2 см       │
└────────────────────────┘     └──────────────────────────────┘
```

### Особливості шини SPI для PMW3901

- Сенсор використовує 4-провідний SPI (режим Mode 3: `CPOL = 1`, `CPHA = 1`).
- Максимальна частота тактування шини `SCK` становить зазвичай 2–4 МГц.
- Для коректного скидання та ініціалізації потрібна завантаження пропрієтарної послідовності регістрів (мікрокоду оптимізації оптичного трекінгу PixArt).
- Читання дельт зміщення виконується за один пакетний виклик (Burst Read) регістрів `0x02`–`0x06` (статус руху, `delta_x_L`, `delta_x_H`, `delta_y_L`, `delta_y_H`, `squal`).

### Роль лазерного далекоміра ToF

Сам по собі оптичний потік вимірює лише **кутову швидкість зміщення пікселів** (радіани за секунду). Щоб перетворити кутовий потік у метричну лінійну швидкість (метри за секунду), необхідно знати точну відстань від об'єктива до площини землі:

```
v_metric (м/с) = ω_flow (рад/с) · висота_h (м)
```

Без далекоміра неможливо відрізнити політ на висоті 1 метр зі швидкістю 1 м/с від польоту на висоті 10 метрів зі швидкістю 10 м/с — картинка зміщуватиметься з однаковою піксельною швидкістю! Лазерний далекомір (ToF) випромінює безпечні для очей модульовані інфрачервоні імпульси (940 нм) і за часом їхнього повернення вимірює справжню фізичну висоту `h` з міліметровою точністю.

## 3. Алгоритм деротації (компенсація нахилів апарата)

Головна пастка під час використання оптичного потоку на рухомих платформах (особливо на квадрокоптерах) полягає в тому, що камера обертається разом із корпусом.

Коли квадрокоптер гальмує або розганяється, він нахиляється за креном чи тангажем. Обертання камери на кут `Δθ` зміщує зображення в кадрі точно так само, як і лінійне переміщення над землею. Якщо використати сирі піксельні дельти без обробки, автопілот сприйме нахил корпусу як «політ убік» і почне помилково компенсувати неіснуючий рух, що призведе до розгойдування та аварії.

### Математичне розділення лінійного руху та обертання

Виміряний сенсором піксельний зсув `Δu` складається з двох незалежних доданків:

```
Δu_meas = Δu_linear + Δu_angular
        = (v_x / h) · focal_px · Δt  +  ω_y · focal_px · Δt
```

Тут:
- `v_x` — справжня лінійна швидкість відносно землі;
- `h` — висота від далекоміра ToF;
- `focal_px` — ефективна фокусна відстань об'єктива в пікселях;
- `ω_y` — кутова швидкість обертання навколо поперечної осі, виміряна гіроскопом [IMU](root:embedded/imu-barometer);
- `Δt` — інтервал часу між опитуваннями сенсора.

### Кроки деротації в прошивці:

1. Опитуємо гіроскоп IMU та інтегруємо кутову швидкість за час експозиції кадру: `Δθ_gyro = ω_gyro · Δt`.
2. Обчислюємо кутове зміщення пікселів: `Δu_rot = Δθ_gyro · focal_px`.
3. Віднімаємо паразитарне обертання від виміряного зсуву (деротація): `Δu_clean = Δu_meas - Δu_rot`.
4. Переводимо чистий зсув у метричну швидкість за допомогою висоти:

```
v_x = (Δu_clean / focal_px) · (h / Δt)
```

Після деротації вихідний сигнал стає чистим вимірюванням лінійної швидкості апарата відносно землі.

## 4. Фізичні обмеження та умови відмови

Оптичний потік не є універсальною заміною супутників. Як і будь-яка оптична система, він має чіткі фізичні межі застосування:

| Сценарій поверхні | Що відбувається з сенсором | Як реагує фільтр навігації |
|---|---|---|
| **Однорідна гладка поверхня** (дзеркальна вода, свіжий рівний сніг, полірована плитка) | Немає контрастних перепадів яскравості; регістр `SQUAL` падає до 0–5. Корелятор видає нульове зміщення або шум. | Автопілот повинен відкинути виміри за порогом якості `SQUAL < 15` і тимчасово перейти на чисте інтегрування прискорень IMU. |
| **Повна темрява без підсвітки** | Матриця фіксує лише темновий шум пікселів; відстеження неможливе. | Необхідне встановлення інфрачервоного світлодіода підсвітки (850/940 нм) або перехід на тепловізійний потік. |
| **Вихід за межі діапазону висотоміра** (політ вище 3–4 метрів для ToF) | Лазерний далекомір перестає бачити відбитий сигнал і повертає помилку `Out of Range`. Без висоти `h` масштабувати потік неможливо. | Перемикання оцінки висоти на барометричний висотомір або лідар дальньої дії (10–50 м). |
| **Рухома текстура** (висока трава чи крони дерев, які колишуться від повітряного потоку гвинтів) | Сенсор відстежує рух самої трави від вітру, а не нерухому землю. | Виникає систематична похибка оцінки швидкості (дрейф за напрямком потоку повітря від пропелерів). |
| **Сліпуче сонячне світло** (пряме сонячне засвічення підлоги) | Перевантаження чутливих елементів пікселів (Saturation), втрата динамічного діапазону контрасту. | Застосування оптичних нейтральних або смугових ІЧ-фільтрів на об'єктив. |

### Практичний індикатор якості `SQUAL`

Регістр `SQUAL` сенсора PMW3901 повертає число від 0 до 255 (кількість знайдених валідних оптичних ознак). У надійній прошивці використовують гістерезис:
- Якщо `SQUAL > 25` і висота `0.08 м < h < 3.5 м`: вимірювання швидкості вважаються валідними та подаються в контур розширеного фільтра Калмана (EKF).
- Якщо `SQUAL < 15`: вимірювання оптичного потоку негайно вимикаються, коваріація шуму збільшується, а система сигналізує про втрату оптичного зачеплення.
