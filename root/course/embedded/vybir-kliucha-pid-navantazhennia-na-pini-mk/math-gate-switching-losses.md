# 🧮 Розрахунок динамічних втрат на перемиканні затвора MOSFET

Динамічні втрати в силовому транзисторі під час широтно-імпульсної модуляції (ШІМ) виникають через скінченну швидкість перезаряджання ємностей затвора: поки напруга на стоку спадає, а струм зростає, на кристалі одночасно присутні висока напруга і великий струм. Цей розрахунок дозволяє інженеру точно визначити час наростання і спаду фронтів, обчислити теплову потужність перемикання, оцінити вплив паразитної індуктивності витоку та розрахувати номінали захисного демпфера (RC-снубера).

---

## 1. Чотири інтервали процесу вмикання польового ключа

Затвор польового транзистора являє собою нелінійну ємнісну структуру, утворену паразитними міжелектродними ємностями: затвор-виток `C_gs` та затвор-сток `C_gd` (прохідна ємність Міллера). У процесі перемикання транзистор проходить чотири послідовні фази:

```
Напруга V_gs
     ^
     │                 /──────── V_drive (Повне відкриття)
     │                /
     │   ┌───────────┘           V_plat (Плато Міллера)
     │  /
     │ /                         V_th (Поріг відкриття)
     └─┴───┴─────────┴───┴──────> Час t
       t1  t2        t3  t4
```

1. **Інтервал затримки увімкнення `t_d(on)` (від 0 до `t1`):**
   Струм драйвера заряджає вхідну ємність від 0 В до порогової напруги відкриття `V_gs(th)`. Струм стоку дорівнює нулю (`I_d = 0`), напруга на стоку дорівнює напрузі живлення (`V_ds = V_supply`). Енергетичні втрати на кристалі в цьому інтервалі відсутні.

2. **Інтервал наростання струму стоку `t_ri` (від `t1` до `t2`):**
   Напруга на затворі зростає від `V_gs(th)` до напруги плато Міллера `V_plat`. Струм стоку лінійно наростає від 0 до повного струму навантаження `I_load`. Напруга на стоку залишається високою (`V_ds ≈ V_supply`). Енергія втрат за цей інтервал:
   ```
   E_on1 = ½ · V_supply · I_load · t_ri
   ```

3. **Інтервал спаду напруги стоку `t_fv` (від `t2` до `t3`, плато Міллера):**
   Струм стоку досяг максимуму `I_load`, а напруга на стоку спадає від `V_supply` до залишкового падіння відкритого каналу `V_ds_on ≈ 0`. Увесь струм драйвера витрачається на перезаряджання ємності Міллера `C_gd`, тому напруга на затворі фіксується на постійному рівні `V_plat`. Енергія втрат за цей інтервал:
   ```
   E_on2 = ½ · V_supply · I_load · t_fv
   ```

4. **Інтервал повного насичення каналу (від `t3` до `t4`):**
   Напруга на затворі дозаряджається від `V_plat` до повної напруги керування `V_drive`. Опір каналу спадає до мінімального значення `R_ds(on)`.

Сумарна тривалість перехідного процесу вмикання дорівнює сумі `t_r = t_ri + t_fv`.

---

## 2. Розрахунок струму затвора та тривалості комутації

Сумарний опір кола керування затвором під час увімкнення складається з вихідного опору драйвера (або GPIO), зовнішнього резистора затвора та внутрішнього розподіленого опору полікремнієвого затвора:

```
R_on_total
= R_driver + R_gate_ext + R_gate_int          [додавання послідовних опорів вихідного каскаду, резистора та кристала]
```

Середній струм заряджання затвора на ділянці плато Міллера визначається різницею потенціалів керування та плато:

```
I_gate_on
= (V_drive − V_plat) / R_on_total             [закон Ома для ділянки заряду плато Міллера]
```

Тривалість проходження плато Міллера обчислюється через паспортний заряд `Q_gd`:

```
t_fv
= Q_gd / I_gate_on                            [час перезаряджання ємності Міллера струмом драйвера]
```

Аналогічно, під час вимикання транзистора затвор розряджається через опір `R_off_total`:

```
I_gate_off
= V_plat / R_off_total                        [струм розряду затвора від напруги плато до нуля]
```

```
t_rv
= Q_gd / I_gate_off                           [час наростання напруги на стоку під час вимикання]
```

## 3. Енергія комутаційних втрат і динамічна потужність

За один цикл перемикання сумарна енергія, що виділяється на кристалі транзистора у вигляді тепла, дорівнює сумі енергії вмикання та вимикання:

```
E_sw
= E_on + E_off                                [сума енергії втрат при вмиканні та вимиканні]
= ½ · V_supply · I_load · t_r + ½ · V_supply · I_load · t_f  [підстановка інтегральних виразів лінійного перекриття]
= ½ · V_supply · I_load · (t_r + t_f)         [винесення спільного множника за дужки]
```

Середня динамічна потужність комутаційних втрат на частоті ШІМ `f_sw`:

```
P_sw
= E_sw · f_sw                                 [добуток енергії одного перемикання на частоту ШІМ]
= ½ · V_supply · I_load · (t_r + t_f) · f_sw  [кінцева формула динамічних втрат перемикання]
```

## 4. Вплив паразитної індуктивності витоку

У реальних друкованих платах провідник від витоку транзистора до спільної землі має власну паразитну індуктивність `L_source` (типово 2–8 нГн для дискретних корпусів TO-220/TO-247). Під час швидкого наростання струму стоку зі швидкістю `di/dt` на індуктивності витоку наводиться проти-ЕРС:

```
V_ind
= L_source · (di/dt)                          [напруга самоіндукції на паразитному провіднику витоку]
```

Ця напруга віднімається від напруги керування на затворі: `V_gs_real = V_gate − V_ind`. Виникає негативний зворотний зв'язок, який штучно затягує наростання струму, подовжує час `t_ri` у 2–4 рази і збільшує динамічні втрати `P_sw`. Для усунення цього ефекту розробники мінімізують довжину земляної доріжки або використовують корпуси з виділеним виводом витоку Кельвіна *(Kelvin Source)*.

## 5. Розрахунок параметрів захисного RC-демпфера (Snubber)

Для гасіння високочастотних коливань на стоку, викликаних резонансом індуктивності розсіювання навантаження `L_leak` та вихідної ємності транзистора `C_oss`, паралельно до ключа встановлюють послідовне RC-коло.

1. **Вибір демпферної ємності `C_snub`:**
   Ємність снубера вибирають у 2–3 рази більшою за власну вихідну ємність польового транзистора `C_oss`:
   ```
   C_snub = 2 · C_oss
   ```

2. **Вибір демпферного резистора `R_snub`:**
   Опір резистора повинен відповідати характеристичному хвильовому опору паразитного коливального контуру для забезпечення коефіцієнта згасання `ζ = 1` (аперіодичний процес):
   ```
   R_snub
   = √(L_leak / C_oss)                        [формула характеристичного опору демпфованого контуру]
   ```

3. **Потужність розсіювання на резисторі снубера:**
   ```
   P_R_snub
   = C_snub · V_supply² · f_sw                [потужність перезаряджання ємності снубера за період ШІМ]
   ```

## 6. Порівняльний розрахунок: Пряме керування від GPIO проти Драйвера затвора

**Параметри задачі:**
- Напруга шини навантаження: `V_supply = 24 В`;
- Струм навантаження: `I_load = 5 А`;
- Робоча частота ШІМ: `f_sw = 30 кГц` (`30 000 Гц`);
- Коефіцієнт заповнення ШІМ: `D = 0.5` (50%);
- Транзистор: N-MOSFET (IRLB8721), паспортні параметри: `R_ds(on) = 0.010 Ом`, `Q_gd = 12 нКл`, `V_plat = 2.4 В`.

---

### Варіант А: Пряме керування від GPIO 3.3 В через резистор R_gate = 150 Ом

1. Загальний опір кола затвора (`R_gpio = 30 Ом`):
```
R_on_total
= R_gpio + R_gate_ext                         [додавання внутрішнього опору GPIO та зовнішнього резистора]
= 30 Ом + 150 Ом                              [підстановка номіналів]
= 180 Ом                                      [повний опір заряду]
```

2. Струм заряду на плато Міллера:
```
I_gate_on
= (3.3 В − 2.4 В) / 180 Ом                    [різниця логічної напруги 3.3 В та напруги плато 2.4 В]
= 0.9 В / 180 Ом                              [падіння напруги на резисторі]
= 0.005 А = 5 мА                              [струм заряду затвора]
```

3. Тривалість фронтів увімкнення та вимкнення:
```
t_r
= Q_gd / I_gate_on                            [відношення заряду Міллера до струму заряду]
= 12 · 10⁻⁹ Кл / 0.005 А                      [підстановка параметрів]
= 2.4 · 10⁻⁶ с = 2.4 мкс                      [тривалість увімкнення]
```
При вимиканні через `R_off_total = 180 Ом`: `I_gate_off = 2.4 В / 180 Ом = 13.3 мА`, звідки `t_f = 12 · 10⁻⁹ / 0.0133 = 0.9 мкс`.

4. Динамічні втрати комутації:
```
P_sw
= ½ · 24 В · 5 А · (2.4 · 10⁻⁶ с + 0.9 · 10⁻⁶ с) · 30 000 Гц  [підстановка напруги, струму, тривалості фронтів та частоти]
= 60 · 3.3 · 10⁻⁶ · 30 000                    [обчислення добутку]
= 5.94 Вт                                     [динамічна теплова потужність]
```

5. Статичні втрати відкритого стану:
```
P_cond
= (5 А)² · 0.010 Ом · 0.5                     [струм у квадраті на опір каналу та шпаруватість]
= 25 · 0.010 · 0.5                            [обчислення статичної потужності]
= 0.125 Вт = 125 мВт                          [статичні втрати провідності]
```

6. Сумарні втрати та перегрів:
```
P_total = 0.125 Вт + 5.94 Вт = 6.065 Вт
```
Для корпусу TO-220 без радіатора (`R_th_ja = 62 °C/Вт`):
```
ΔT = 6.065 Вт · 62 °C/Вт ≈ 376 °C
```
Транзистор руйнується за лічені секунди.

---

### Варіант Б: Керування через Gate Driver (TC4427) від 12 В з R_gate = 4.7 Ом

1. Загальний опір кола затвора (`R_drv = 2.5 Ом`):
```
R_on_total = 2.5 + 4.7 = 7.2 Ом
```

2. Струм заряду на плато Міллера (`V_drive = 12 В`):
```
I_gate_on
= (12 В − 2.4 В) / 7.2 Ом                     [різниця напруги 12 В та плато 2.4 В]
= 9.6 В / 7.2 Ом                              [падіння напруги на резисторі драйвера]
= 1.33 А                                      [піковий струм заряду]
```

3. Тривалість фронтів:
```
t_r
= 12 · 10⁻⁹ Кл / 1.33 А                       [заряд Міллера поділений на струм драйвера]
= 9 · 10⁻⁹ с = 9 нс                           [тривалість увімкнення скоротилася у 260 разів]
```
Аналогічно час вимикання `t_f ≈ 15 нс`.

4. Динамічні втрати комутації:
```
P_sw
= ½ · 24 В · 5 А · (9 · 10⁻⁹ с + 15 · 10⁻⁹ с) · 30 000 Гц  [підстановка наносекундних фронтів]
= 60 · 24 · 10⁻⁹ · 30 000                     [спрощення коефіцієнтів]
= 0.043 Вт = 43 мВт                           [динамічні втрати впали у 138 разів]
```

5. Повний тепловий баланс:
```
P_total = 0.125 Вт + 0.043 Вт = 0.168 Вт (168 мВт)
ΔT = 0.168 Вт · 62 °C/Вт ≈ 10.4 °C
```

Застосування виділеного драйвера затвора скорочує перехідний інтервал до наносекунд і усуває перегрів ключа, забезпечуючи надійну та холодну роботу силового каскаду.
