# 🧮 Розрахунок магнітних полів від силових провідників і петель

Силові ланцюги безпілотних апаратів прокачують імпульсні та постійні струми від десятків до сотень ампер. За законом електромагнітної індукції та законом Біо — Савара — Лапласа кожен рухомий заряд створює навколо себе векторне магнітне поле. Для чутливих магніторезистивних давачів (магнітометрів), які вимірюють геомагнітне поле Землі величиною від `30` до `60 мкТл` (мікротесла), ці струмові поля є потужним джерелом адитивної електромагнітної завади (англ. *electromagnetic interference*, EMI).

Розрахуймо аналітично просторовий розподіл і швидкість спадання магнітної індукції для чотирьох типових конфігурацій бортової мережі: одиночного прямого провідника, двопровідної паралельної лінії, скрученої пари та замкненої кругової петлі друкованої плати.

---

## 1. Одиночний нескінченний провідник

Розглянемо нескінченно довгий тонкий провідник, крізь який протікає постійний струм `I` уздовж осі `Z`. Елемент провідника довжиною `d l` створює в точці спостереження на радіальній відстані `r` диференціал магнітної індукції `d B` за законом Біо — Савара — Лапласа:

```
d B = (μ₀ · I · (d l × r̂)) / (4 · π · R²)
```

де:
- `μ₀ = 4 · π · 10⁻⁷ Гн/м` (або `Тл · м / А`) — магнітна стала вакууму;
- `r̂` — одиничний вектор напрямку від елемента струму до точки спостереження;
- `R` — повна відстань від елемента струму `d l` до точки спостереження (`R = √(r² + z²)`).

Інтегруємо внески всіх елементів струму вздовж осі від `z = −∞` до `z = +∞`. Зручно перейти до кутової змінної `θ` між віссю провідника та радіус-вектором точки:

```
z = r · ctg(θ)
d z = − r · d θ / sin²(θ)
R = r / sin(θ)
```

Покрокове обчислення інтеграла:

```
B = ∫ [−∞ ... +∞] (μ₀ · I · r · d z) / (4 · π · (r² + z²)^(3/2))     [закон Біо — Савара]
  = (μ₀ · I / (4 · π · r)) · ∫ [0 ... π] sin(θ) d θ                  [підстановка кутової змінної]
  = (μ₀ · I / (4 · π · r)) · (− cos(π) − (− cos(0)))                 [первісна від sin(θ) є −cos(θ)]
  = (μ₀ · I / (4 · π · r)) · (1 − (−1))                              [обчислення меж cos(π)=−1, cos(0)=1]
  = (μ₀ · I / (4 · π · r)) · 2                                       [спрощення суми]
  = (μ₀ · I) / (2 · π · r)                                           [підсумкова індукція прямого струму]
```

Підставимо числове значення магнітної сталої `μ₀ = 4 · π · 10⁻⁷`:

```
B(r, I) = (4 · π · 10⁻⁷ · I) / (2 · π · r)                           [підстановка значення μ₀]
        = (2 · 10⁻⁷ · I) / r                                         [скорочення на 2·π]
```

Переведемо індукцію в мікротесла (`1 мкТл = 10⁻⁶ Тл`), а відстань `r` — у сантиметри (`r_см = 100 · r`):

```
B_мкТл(r_см, I) = 20 · I / r_см
```

### Числовий розрахунок завади від одиночного дроту

Розрахуємо напруженість поля для типових струмів квадрокоптера на різних відстанях від силового кабелю:

| Струм `I` (А) | Відстань `r = 1 см` | Відстань `r = 3 см` | Відстань `r = 10 см` | Відстань `r = 25 см` |
|---|---|---|---|---|
| **20 А** (зависання) | 400 мкТл | 133.3 мкТл | 40.0 мкТл | 16.0 мкТл |
| **60 А** (крейсерський рух) | 1200 мкТл | 400.0 мкТл | 120.0 мкТл | 48.0 мкТл |
| **120 А** (вертикальний підйом) | 2400 мкТл | 800.0 мкТл | 240.0 мкТл | 96.0 мкТл |
| **180 А** (максимальний форсаж) | 3600 мкТл | 1200.0 мкТл | 360.0 мкТл | 144.0 мкТл |

Для порівняння: горизонтальна складова магнітного поля Землі в помірних широтах становить лише `B_E ≈ 20...45 мкТл`. Якщо компас змонтований на відстані `3 см` від силового дроту з піковим струмом `120 А`, завада від струму (`800 мкТл`) перевищує земний сигнал майже у **вісімнадцять разів**.

## 2. Паралельна пара зустрічних провідників (DC-лінія)

У реальній бортовій системі струм тече замкненим контуром: від акумулятора до плати розподілу живлення (PDB) або регуляторів (ESC) по плюсовому дроту (`+I`), а повертається по мінусовому (`−I`).

Нехай два провідники розташовані паралельно на відстані `d` один від одного вздовж осі `Z`. Точка спостереження розташована у площині, перпендикулярній до проводів, на відстані `r` від осьового центру пари (`r >> d`).

Вектори магнітної індукції від двох провідників направлені в протилежні боки й частково компенсують один одного. Нехай відстані від провідників до точки спостереження становлять `r₁ = r − d/2` та `r₂ = r + d/2`.

Результуюче поле в дальній зоні:

```
B_net = B₁ − B₂
      = ((μ₀ · I) / (2 · π)) · (1 / (r − d/2) − 1 / (r + d/2))       [суперпозиція полів протилежних струмів]
      = ((μ₀ · I) / (2 · π)) · ((r + d/2 − (r − d/2)) / (r² − d²/4))  [зведення до спільного знаменника]
      = ((μ₀ · I) / (2 · π)) · (d / (r² · (1 − d² / (4 · r²))))       [винесення r² за дужки]
```

Оскільки `r >> d`, нехтуємо членом другого порядку малості `d² / (4 · r²) ≈ 0`:

```
B_net(r) ≈ (μ₀ · I · d) / (2 · π · r²)                                [дипольний спад для паралельної пари]
```

### Коефіцієнт послаблення поля

Порівняємо поле паралельної пари `B_net` із полем одиночного дроту `B_single` на тій самій відстані `r`:

```
η_par = B_net / B_single
      = ((μ₀ · I · d) / (2 · π · r²)) / ((μ₀ · I) / (2 · π · r))      [ділення двох виразів]
      = d / r                                                         [коефіцієнт геометричного придушення]
```

Приклад: якщо товщина ізоляції та зазор між проводами дають відстань між жилами `d = 4 мм` (`0.004 м`), а компас винесено на відстань `r = 12 см` (`0.12 м`), геометричне послаблення становить:

```
η_par = 0.004 / 0.12 = 1 / 30 ≈ 0.0333  (придушення на 96.7%)
```

При струмі `120 А` одиночний дріт на відстані `12 см` створив би заваду `200 мкТл`. Паралельна пара з зазором `4 мм` створює на тій самій відстані поле лише `6.67 мкТл`. Це все ще помітно для компаса, але вже на порядок безпечніше за одиночний провідник.

## 3. Скручена вита пара (Twisted Pair)

Якщо два зустрічні проводи скрутити разом із постійним кроком скрутки `λ` (довжина одного повного оберту на 360°), напрямок вектора магнітного диполя змінюється на 180° на кожному напіввитку `λ / 2`.

Кожен напіввиток площею `A_half = d · (λ / 2) / 2 = d · λ / 4` формує елементарний магнітний момент `m_k = (−1)ᵏ · I · A_half`.

Сумарний потенціал магнітного поля утворюється знакозмінним рядом диполів. При обчисленні поля в точці на відстані `r` внески сусідніх напіввитків мають протилежний знак і взаємно віднімаються:

```
B_twist(r) ≈ B_dipole · exp(− 2 · π · r / λ)
```

Або через мультипольне розкладання: дипольний член першого порядку строго дорівнює нулю за рахунок просторової симетрії інтегрування по періоду `λ`. Головний ненульовий член поля є квадрупольним або гексапольним, спадаючи за степеневим законом:

```
B_twist(r) ∝ (μ₀ · I · d² · λ) / (r⁴)
```

Завдяки показниковому або швидкоспадному степеневому закону завада від витої пари на відстані `r > λ` практично зникає. Якщо крок скрутки становить `λ = 20 мм` (`2 см`), а відстань до давача `r = 10 см` (`r / λ = 5`), поле послаблюється більш ніж на **99.8%** порівняно з нескрученими паралельними кабелями.

## 4. Кругова петля струму (контур друкованої плати PDB / батареї)

У платах розподілу живлення (PDB) або 4-in-1 ESC силовий струм часто проходить замкненим контуром або петлею радіуса `R`, охоплюючи площу `A = π · R²`.

Знайдемо магнітне поле на осі симетрії `Z`, перпендикулярній до площини кільця зі струмом `I`. Елемент кільця `d l = R · d φ` розташований на відстані `s = √(R² + z²)` від точки на осі.

Проєкція індукції на вісь `Z` від одного елемента:

```
d B_z = d B · cos(α)                                                   [проєкція елементарного вектора на вісь z]
      = ((μ₀ · I · R · d φ) / (4 · π · (R² + z²))) · (R / √(R² + z²))  [підстановка закону Біо — Савара та cos(α) = R/s]
      = (μ₀ · I · R² · d φ) / (4 · π · (R² + z²)^(3/2))               [перемноження знаменників]
```

Інтегруємо по куту `φ` від `0` до `2 · π`:

```
B_z(z) = ∫ [0 ... 2·π] (μ₀ · I · R² · d φ) / (4 · π · (R² + z²)^(3/2))  [інтегрування по всьому колу]
       = ((μ₀ · I · R²) / (4 · π · (R² + z²)^(3/2))) · 2 · π            [інтеграл d φ дає довжину кута 2π]
       = (μ₀ · I · R²) / (2 · (R² + z²)^(3/2))                          [точне значення поля на осі петлі]
```

Введемо магнітний момент петлі `m = I · A = I · π · R²`. Тоді для великих відстаней (`z >> R`):

```
(R² + z²)^(3/2) = z³ · (1 + R²/z²)^(3/2) ≈ z³
```

Підставляємо в точний вираз:

```
B_z(z) ≈ (μ₀ · I · R²) / (2 · z³)                                      [наближення для z >> R]
       = (μ₀ · (I · π · R²)) / (2 · π · z³)                            [множення чисельника й знаменника на π]
       = (μ₀ · m) / (2 · π · z³)                                       [вираз через магнітний момент m]
```

### Фізичні висновки з формули петлі

1. **Кубічний спад (`1/z³`).** Поле петлі на великій відстані спадає швидше, ніж поле одиночного нескінченного дроту (`1/r`) і навіть паралельних дротів (`1/r²`). Але на малих відстанях (`z < 2 · R`), де розміри петлі співмірні з відстанню до компаса на польотному контролері, індукція досягає колосальних значень:

```
B_z(0) = (μ₀ · I) / (2 · R)                                            [поле в центрі петлі]
```

Для петлі радіусом `R = 1.5 см` (типовий контур силових конденсаторів ESC) при струмі `100 А`:

```
B_z(0) = (4 · π · 10⁻⁷ · 100) / (2 · 0.015)
       ≈ 4188 мкТл  (майже в 100 разів вище за поле Землі!)
```

2. **Пряма пропорційність площі контуру `A`.** Щоб зменшити магнітний момент `m = I · A`, інженер зобов'язаний мінімізувати геометричну площу петлі `A`. На друкованій платі це досягається взаємним накладанням силових полігонів живлення та землі на сусідніх шарах (товщина діелектрика `h ≈ 0.15...0.2 мм`), що зводить площу ефективного магнітного контуру майже до нуля.

## 5. Зведена інженерна таблиця топологій провідників

Порівняння законів спадання індукції та залишкової завади для струму `I = 100 А` на відстані `r = 10 см`:

| Топологія провідників | Закон спадання вдалині | Формула `B(r)` | Індукція при 100 А на 10 см | Відносний рівень завади |
|---|---|---|---|---|
| **Одиночний дріт** | `∝ 1 / r` | `(μ₀ · I) / (2 · π · r)` | `200.0 мкТл` | `100 %` (критично) |
| **Паралельна пара (`d = 5 мм`)** | `∝ 1 / r²` | `(μ₀ · I · d) / (2 · π · r²)` | `10.0 мкТл` | `5.0 %` (відчутно) |
| **Вита пара (`λ = 20 мм`)** | `∝ exp(−2πr/λ)` або `1/r⁴` | `B₀ · exp(−2·π·r / λ)` | `< 0.15 мкТл` | `< 0.08 %` (безпечно) |
| **Кругова петля (`R = 15 мм`)** | `∝ 1 / z³` | `(μ₀ · I · R²) / (2 · z³)` | `14.1 мкТл` | `7.0 %` (помітно) |

Ці аналітичні розрахунки доводять: найпотужнішим інструментом захисту навігаційного компаса від струмових завад є не програмні фільтри, а **геометрія провідників** — щільне скручування кабелів живлення та мінімізація площі силових петель на платах.
