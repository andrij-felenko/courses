# 🧮 Векторний метод динамічного балансування ротора

Обертовий ротор із невідомим розподілом маси збуджує вібрацію на частоті обертання `1× RPM`. Щоб звести цю вібрацію до нуля за мінімальну кількість випробувальних пусків, пружно-інерційну систему ротора й опори розглядають як лінійний механічний перетворювач: будь-який вектор незрівноваженої маси породжує строго пропорційний вектор коливань із фіксованим амплітудним коефіцієнтом передачі та фазовим зсувом. Векторний метод коефіцієнтів впливу дає змогу точно знайти масу й кут коригувального тягарця без тривалого емпіричного підбору й багаторазових спроб.

### Одноплощинне балансування: лінійна векторна модель

Нехай ротор обертається зі сталою кутовою швидкістю `ω = 2π·f_r`, де `f_r` — частота обертання вала в герцах. Первинний невідомий дисбаланс ротора описується комплексним вектором `U_0 = m_0 · r_0 · e^{j·θ_0}`, де `m_0` — еквівалентна неврівноважена маса, `r_0` — радіус її віддалення від осі, а `θ_0` — її кутове положення відносно нульової фазової мітки ротора.

Датчик вібрації (п'єзоелектричний або MEMS-акселерометр, встановлений на моторному щиті або підшипниковому вузлі) разом із фазовим маркером (оптичним чи магнітним датчиком обертів) вимірює вектор базової вібрації `V_0`:

```
V_0 = A_0 · e^{j·φ_0} = A_0 · (cos(φ_0) + j·sin(φ_0))
```

де `A_0` — амплітуда віброшвидкості або віброприскорення на частоті `1× RPM`, а `φ_0` — фазовий кут між моментом проходження мітки та піком вібраційного сигналу.

Якщо швидкість обертання стала й далека від критичних резонансів рами, механічна система поводиться лінійно: зв'язок між вектором дисбалансу та виміряною вібрацією описується комплексним коефіцієнтом динамічного впливу `S`:

```
V_0 = S · U_0
```

Комплексний коефіцієнт `S` має розмірність `(мм/с)/(г·мм)` або `(м/с²)/(г·мм)` і містить як коефіцієнт передачі механічної пружності, так і фазове запізнення коливального контуру опори. Оскільки ані `S`, ані `U_0` заздалегідь невідомі, одного базового вимірювання `V_0` принципово недостатньо для визначення координат дисбалансу: ми маємо одне рівняння з двома комплексними невідомими.

### Пробний пуск і вимірювання коефіцієнта впливу

Для експериментального визначення невідомого оператора `S` на ротор встановлюють штучне калібрувальне збурення — відомий пробний вантаж масою `m_t` на радіусі `r_t` під кутом `θ_t` (найчастіше для зручності обирають `θ_t = 0°`):

```
U_t = m_t · r_t · e^{j·θ_t}
```

Під час другого пуску, проведеного на тій самій частоті обертання, датчик фіксує сумарний вектор вібрації `V_1`, що виникає під дією суми початкового та пробного дисбалансів:

```
V_1 = A_1 · e^{j·φ_1} = S · (U_0 + U_t) = V_0 + S · U_t
```

Вектор чистого приросту вібрації `ΔV`, викликаний виключно дією пробного вантажу, визначається векторною різницею:

```
ΔV = V_1 − V_0
```

Знаючи величину збурення `U_t` та викликаний ним відгук `ΔV`, комплексний коефіцієнт динамічного впливу `S` визначається однозначно:

```
S = ΔV / U_t = (V_1 − V_0) / (m_t · r_t · e^{j·θ_t})
```

### Розрахунок параметрів коригувального вантажу

Мета балансування полягає у встановленні такого коригувального вектора дисбалансу `U_c = m_c · r_c · e^{j·θ_c}`, який повністю компенсує початковий дисбаланс ротора `U_0`, створюючи вібрацію з протилежним знаком:

```
S · (U_0 + U_c) = 0
V_0 + S · U_c = 0
U_c = −V_0 / S
```

Підставляючи вираз для коефіцієнта впливу `S`, отримуємо формулу розрахунку коригувального дисбалансу:

```
U_c = −V_0 · (U_t / ΔV) = −U_t · (V_0 / (V_1 − V_0))
```

Якщо коригувальний вантаж встановлюється на тому самому радіусі, що й пробний (`r_c = r_t`), необхідна маса `m_c` та кут її розміщення `θ_c` визначаються модулем та аргументом комплексної величини:

```
m_c = m_t · (|V_0| / |V_1 − V_0|)
θ_c = θ_t + arg(−V_0) − arg(V_1 − V_0)
```

Враховуючи, що зміна знака комплексного числа додає до його фази 180° (`arg(−V_0) = φ_0 + 180°`), розрахункова формула кута встановлення вантажу набуває вигляду:

```
θ_c = θ_t + φ_0 + 180° − arg(V_1 − V_0)
```

Кут `θ_c` відраховується від нульової мітки ротора в напрямку обертання вала (якщо фазовий кут вимірювався із затримкою) або проти нього (залежно від конвенції знаків у вимірювальному тракті).

### Числовий приклад розрахунку балансування

Розглянемо практичний розрахунок балансування безколекторного мотора типорозміру 2207 при швидкості обертання 12 000 об/хв (`f_r = 200` Гц).

**Крок 1. Базовий прогін:**
- Амплітуда вібрації: `A_0 = 12.0` м/с²
- Фазовий кут: `φ_0 = 40.0°`
- Комплексна форма вектора `V_0`:
```
V_0 = 12.0 · (cos(40°) + j·sin(40°)) = 9.192 + j·7.713 м/с²
```

**Крок 2. Прогін із пробним вантажем:**
- Пробний вантаж: `m_t = 0.10` г (100 мг) на радіусі `r_t = 12` мм під кутом `θ_t = 0°`
- Виміряна вібрація: `A_1 = 6.5` м/с², фазовий кут `φ_1 = 110.0°`
- Комплексна форма вектора `V_1`:
```
V_1 = 6.5 · (cos(110°) + j·sin(110°)) = −2.223 + j·6.108 м/с²
```

**Крок 3. Обчислення вектора реакції `ΔV`:**
```
ΔV = V_1 − V_0 = (−2.223 − 9.192) + j·(6.108 − 7.713)
   = −11.415 − j·1.605 м/с²
|ΔV| = √((−11.415)² + (−1.605)²) = √(130.30 + 2.58) = 11.53 м/с²
arg(ΔV) = atan2(−1.605, −11.415) = −172.0°  (або 188.0°)
```

**Крок 4. Розрахунок маси коригувального тягарця `m_c`:**
```
m_c = m_t · (|V_0| / |ΔV|)
    = 0.10 · (12.0 / 11.53) = 0.1041 г ≈ 104 мг
```

**Крок 5. Розрахунок кута розміщення `θ_c`:**
```
θ_c = 0° + 40.0° + 180.0° − (−172.0°)
    = 392.0° ≡ 32.0°
```

**Результат:** Пробний вантаж знімають, а на куті `32°` відносно фазової мітки закріплюють постійний балансувальний вантаж масою `104 мг`. Після установки вібрація ротора падає з початкових 12.0 м/с² до менш ніж 0.8 м/с² (зменшення на 93%).

### Крайові випадки та нелінійності

Векторний метод передбачає сувору лінійність механічної системи. На практиці інженер стикається з трьома крайовими випадками, що вимагають особливої обробки:

1. **Замала маса пробного вантажу (`|ΔV| < 0.1 · |V_0|`).** Якщо пробний вантаж занадто малий, векторна різниця `V_1 − V_0` тоне в шумах вимірювального тракту й випадковій вібрації підшипників. Обчислення коефіцієнта впливу `S` призводить до ділення на нуль або колосальної похибки кута. Правило вибору пробної маси: вага `m_t` має викликати зміну вектора вібрації щонайменше на 30–50% від базового значення `V_0`.
2. **Перехід через резонансну частоту під час тесту.** Якщо робоча швидкість калібрування збігається з власною частотою рами чи кронштейна, фаза вібрації зазнає різкого стрибка на 90–180° при найменшій зміні обертів (навіть на 1–2%). Балансування поблизу резонансу заборонене: швидкість калібрувального прогону обирають або на 30% нижче, або на 30% вище зони резонансного піка.
3. **Механічний люфт у підшипниках чи посадці.** Якщо ротор має радіальний зазор, вал змінює своє положення під час кожного пуску випадковим чином. Фазовий кут `φ_0` починає дрейфувати від прогону до прогону, що робить точну компенсацію неможливою до заміни зношених підшипників.

### Двоплощинне балансування (для видовжених роторів)

Коли довжина ротора сумірна з його діаметром або перевищує його (наприклад, видовжені безколекторні мотори авіамоделей, вали приводів, ротори помп чи генераторів), одноплощинного балансування недостатньо, оскільки статичний і моментний дисбаланси діють одночасно в різних площинах.

Для повного врівноваження використовують дві площини корекції (площину 1 і площину 2) та два датчики вібрації на передній і задній опорах (опори A і B).

Комплексний зв'язок між двома площинами збурення та відгуками двох опор описується матричним рівнянням впливу `2 × 2`:

```
[ V_A ]   [ S_A1  S_A2 ]   [ U_1 ]
[     ] = [            ] · [     ]
[ V_B ]   [ S_B1  S_B2 ]   [ U_2 ]
```

де:
- `V_A, V_B` — комплексні вектори вібрації на передній і задній опорах;
- `U_1, U_2` — вектори дисбалансів у площинах корекції 1 і 2;
- `S_A1` — прямий коефіцієнт впливу площини 1 на опору A;
- `S_B2` — прямий коефіцієнт впливу площини 2 на опору B;
- `S_A2, S_B1` — коефіцієнти перехресного динамічного зв'язку (англ. *cross-coupling*).

Матриця динамічного впливу визначається за три прогони:
1. Базовий прогін → замір `V_A0, V_B0`.
2. Прогін із пробним вантажем `U_t1` у площині 1 → замір `V_A1, V_B1`. Коефіцієнти першого стовпчика:
```
S_A1 = (V_A1 − V_A0) / U_t1
S_B1 = (V_B1 − V_B0) / U_t1
```
3. Прогін із пробним вантажем `U_t2` у площині 2 (при знятому `U_t1`) → замір `V_A2, V_B2`. Коефіцієнти другого стовпчика:
```
S_A2 = (V_A2 − V_A0) / U_t2
S_B2 = (V_B2 − V_B0) / U_t2
```

Для знаходження векторів компенсації `U_c1, U_c2` матрицю інвертують через її детермінант `det(S) = S_A1 · S_B2 − S_A2 · S_B1`:

```
[ U_c1 ]            1         [  S_B2  −S_A2 ]   [ V_A0 ]
[      ] = − ─────────────── · [             ] · [      ]
[ U_c2 ]         det(S)       [ −S_B1   S_A1 ]   [ V_B0 ]
```

Встановлення розрахованих вантажів у площинах 1 і 2 одночасно ліквідує як радіальну відцентрову силу незрівноваженого центру мас, так і знакозмінний перекидний момент пари сил ротора.
