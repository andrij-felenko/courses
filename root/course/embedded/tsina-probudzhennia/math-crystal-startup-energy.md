# 🧮 Математика розгону кварцу та межа вигоди RC-генератора

Цей розрахунок дає точні аналітичні формули для часових та енергетичних витрат на розгойдування механічного кварцового резонатора в генераторі Пірса проти миттєвого релаксаційного RC-генератора, без яких неможливо обґрунтовано визначити граничну тривалість задачі, коли підйом зовнішнього кварцу стає виправданим.

## 1. Еквівалентна схема резонатора та від'ємний опір

Кварцовий резонатор описується еквівалентною електричною моделлю Баттерворта — Ван-Дайка (англ. *Butterworth–Van Dyke model*, BVD). Модель складається з послідовної динамічної вітки (п'єзоелектрична маса, пружність та тертя кристала) і паралельної статичної ємності електродів і корпусу:

```
        ┌────── L_m ────── R_m ────── C_m ──────┐
───o────┤                                       ├────o───
        └───────────────── C_0 ─────────────────┘
```

Де:
- `L_m` — динамічна індуктивність (еквівалент коливної маси кристала, типово від `10` мГн до `50` Гн);
- `C_m` — динамічна ємність (еквівалент механічної піддатливості п'єзоелемента, типово `1`–`30` фФ);
- `R_m` — еквівалентний послідовний опір втрат (внутрішнє механічне тертя й акустичні втрати у кварці, `20`–`100` Ом для ВЧ резонаторів, до `50`–`90` кОм для часових резонаторів 32.768 кГц);
- `C_0` — статична ємність між металевими обкладками електродів та виводами корпусу (`1`–`7` пФ).

Інверторний підсилювач мікроконтролера (транзистор з крутістю перехідної характеристики `g_m` у лінійній зоні) разом із навантажувальними конденсаторами `C_L1` та `C_L2` створює між виводами резонатора активний від'ємний динамічний опір `R_neg`.

Знайдемо дійсну частину вхідного імпедансу ланки зворотного зв'язку на резонансній кутовій частоті `ω = 2 · π · f`:

```
Z_in(ω)
= (1 / (j · ω · C_L1)) + (1 / (j · ω · C_L2)) + (g_m / ((j · ω · C_L1) · (j · ω · C_L2)))   [послідовне з'єднання ємностей та залежного джерела струму]
= -j · ((C_L1 + C_L2) / (ω · C_L1 · C_L2)) - (g_m / (ω² · C_L1 · C_L2))                     [винесення уявної одиниці j у чисельник: 1/j = -j, j² = -1]
```

Дійсна частина імпедансу `Re(Z_in)` і є тим самим від'ємним опором `R_neg`, який компенсує внутрішній опір втрат `R_m`:

```
R_neg = - g_m / (ω² · C_L1 · C_L2)
```

Для виникнення генерації сумарний дійсний опір кола мусить бути від'ємним: `R_total = R_m + R_neg < 0`, звідки `|R_neg| > R_m`. Для гарантованого швидкого старту за будь-яких температур і розкиду напруг живлення вводять коефіцієнт запасу підсилення (англ. *Gain Margin* або *Safety Factor*):

```
SF = |R_neg| / R_m ≥ 3 ... 5
```

Якщо навантажувальні ємності обрано асиметричними (`C_L1 ≠ C_L2`), формула від'ємного опору узагальнюється через ефективну навантажувальну ємність `C_L = (C_L1 · C_L2) / (C_L1 + C_L2)` та коефіцієнт асиметрії `k = C_L1 / C_L2`:

```
R_neg = - g_m / (ω² · C_L² · (k + 2 + 1/k))
```

Максимум модуля від'ємного опору досягається при симетричному навантаженні `C_L1 = C_L2` (де `k = 1`). Будь-яка суттєва асиметрія ємностей зменшує `|R_neg|` і прямо пропорційно затягує час виходу генератора на стабільну амплітуду.

## 2. Диференціальне рівняння наростання амплітуди

На початковому етапі розгону інвертор працює в лінійному класі A, де `g_m` є сталою величиною. Струм у коливальному контурі `i(t)` підпорядковується лінійному однорідному диференціальному рівнянню другого порядку:

```
L_m · (d²i/dt²) + (R_m - |R_neg|) · (di/dt) + (1 / C_m) · i(t) = 0
```

Характеристичне рівняння системи має вигляд:

```
L_m · λ² + (R_m - |R_neg|) · λ + (1 / C_m) = 0
```

Корені характеристичного рівняння при високій добротності `Q = (ω · L_m) / R_m ≫ 1`:

```
λ₁,₂ = α ± j · ω_r
```

Де коефіцієнт зростання амплітуди `α`:

```
α
= - (R_m - |R_neg|) / (2 · L_m)      [коефіцієнт згасання/наростання з характеристичного рівняння]
= (|R_neg| - R_m) / (2 · L_m)        [зміна знака для додатного наростання при |R_neg| > R_m]
```

Амплітудна обвідна напруги на виводі резонатора `V(t)` наростає за експоненційним законом:

```
V(t) = V_noise · exp(α · t)
```

Початкова напруга `V_noise` формується виключно тепловим шумом Джонсона — Найквіста в еквівалентному опорі втрат `R_m` у вузькій смузі пропускання `Δf = f_r / Q`:

```
V_noise = √(4 · k_B · T · R_m · Δf)
```

Де:
- `k_B = 1.380649 · 10⁻²³` Дж/К — стала Больцмана;
- `T ≈ 300` К — абсолютна температура;
- `Δf` — смуга пропускання резонатора (`Δf ≈ 16 · 10⁶ / 50 000 = 320` Гц).

Для `R_m = 30` Ом маємо:

```
V_noise
= √(4 · 1.38 · 10⁻²³ · 300 · 30 · 320)  [підстановка фізичних сталих та параметрів контуру]
= √(1.589 · 10⁻¹⁶)                      [добуток під коренем]
≈ 1.26 · 10⁻⁸ В = 12.6 нВ               [обчислення квадратного кореня]
```

Розгойдування триває від мікровольтового теплового шуму `V_noise` до цільового порогу детектора амплітуди `V_target ≈ 0.8 · V_DD` (наприклад, `1.0` В при `V_DD = 3.3` В), після чого вихідний каскад входить у нелінійне обмеження.

Виведемо формулу часу старту кварцу `t_start`:

```
V_target = V_noise · exp(α · t_start)
ln(V_target / V_noise) = α · t_start
t_start = (1 / α) · ln(V_target / V_noise)
t_start = (2 · L_m / (|R_neg| - R_m)) · ln(V_target / V_noise)
```

**Числовий приклад розрахунку часу розгону 16 МГц кварцу:**
- `L_m = 12` мГн (`0.012` Гн);
- `R_m = 35` Ом;
- `|R_neg| = 180` Ом (при `g_m = 15` мА/В, `C_L1 = C_L2 = 18` пФ);
- `V_target = 1.0` В;
- `V_noise = 12.6` нВ.

Обчислюємо покроково:

```
|R_neg| - R_m
= 180 - 35                               [різниця від'ємного опору та опору втрат]
= 145 Ом                                 [чистий надлишковий від'ємний опір]

2 · L_m / (|R_neg| - R_m)
= 2 · 0.012 / 145                        [підстановка динамічної індуктивності та опору]
= 0.024 / 145                            [множення в чисельнику]
≈ 1.655 · 10⁻⁴ с = 165.5 мкс             [постійна часу наростання контуру]

ln(V_target / V_noise)
= ln(1.0 / (12.6 · 10⁻⁹))                [відношення цільової напруги до шуму]
= ln(7.936 · 10⁷)                        [коефіцієнт необхідного підсилення]
≈ 18.19                                  [натуральний логарифм підсилення]

t_start
= 165.5 мкс · 18.19                      [добуток постійної часу на логарифм]
≈ 3010 мкс = 3.01 мс                     [повний час виходу на стабільну амплітуду]
```

Коливання розгойдуються понад 3 мілісекунди, і весь цей час підсилювач генератора працює в активному режимі, споживаючи від 1.5 до 2.5 мА.

## 3. Чому годинниковий кварц 32.768 кГц стартує сотні мілісекунд

Для низькочастотних резонаторів LSE (32.768 кГц) динамічні параметри разюче відрізняються через гігантські механічні розміри камертона (tuning fork):
- `L_m ≈ 4000`–`10 000` Гн (у сотні тисяч разів більше, ніж у ВЧ кварцу);
- `C_m ≈ 2`–`4` фФ;
- `R_m ≈ 40 000`–`80 000` Ом (40–80 кОм);
- `|R_neg| ≈ 200 000`–`350 000` Ом (при наднизькому струмі інвертора `g_m ≈ 5`–`15` мкА/В).

Розрахуємо постійну часу наростання для типового LSE резонатора (`L_m = 6000` Гн, `R_m = 50` кОм, `|R_neg| = 250` кОм):

```
|R_neg| - R_m
= 250 000 - 50 000                       [надлишковий від'ємний опір інвертора]
= 200 000 Ом                             [чистий від'ємний імпеданс]

2 · L_m / (|R_neg| - R_m)
= 2 · 6000 / 200 000                     [підстановка індуктивності та опору]
= 12 000 / 200 000                       [ділення чисельника на знаменник]
= 0.060 с = 60 мс                        [постійна часу наростання LSE контуру]

t_start_LSE
= 60 мс · 18.0                           [множення на коефіцієнт логарифма шуму]
≈ 1080 мс = 1.08 с                       [час стабілізації годинникового кварцу]
```

Ось чому годинниковий кварц LSE **ніколи не вимикають** під час сну: його розгін триває близько секунди. LSE залишають постійно активним від резервного домену живлення (VBAT / Backup Domain), де він споживає менш як `150`–`350` нА.

## 4. Енергетичний баланс і критична точка перетину

Порівняємо сумарну енергію одного циклу пробудження для виконання короткої задачі (обробка `N` тактових інструкцій) за двома стратегіями:

1. **Стратегія RC (MSI / HSI):** миттєвий запуск внутрішнього релаксаційного генератора на частоті `f_RC` (наприклад, 16 МГц) за час `t_start_RC ≈ 2` мкс, виконання задачі за час `t_exec_RC = N / f_RC` при струмі споживання ядра `I_run_RC`.
2. **Стратегія HSE (кварцовий резонатор):** очікування стабілізації кварцу протягом часу `t_start_HSE ≈ 2.5` мс при струмі генератора `I_osc ≈ 2.0` мА, після чого виконання задачі на частоті `f_HSE` (наприклад, 80 МГц) за час `t_exec_HSE = N / f_HSE` при струмі ядра `I_run_HSE`.

Сумарний електричний заряд, спожитий від джерела `V_DD`:

```
Q_RC = (I_start_RC · t_start_RC) + (I_run_RC · (N / f_RC))

Q_HSE = (I_osc · t_start_HSE) + (I_run_HSE · (N / f_HSE))
```

Знайдемо критичну кількість інструкцій `N_crit`, за якої заряди зрівнюються (`Q_RC = Q_HSE`):

```
(I_start_RC · t_start_RC) + (I_run_RC · (N_crit / f_RC)) = (I_osc · t_start_HSE) + (I_run_HSE · (N_crit / f_HSE))

N_crit · [ (I_run_RC / f_RC) - (I_run_HSE / f_HSE) ] = (I_osc · t_start_HSE) - (I_start_RC · t_start_RC)

N_crit = [ (I_osc · t_start_HSE) - (I_start_RC · t_start_RC) ] / [ (I_run_RC / f_RC) - (I_run_HSE / f_HSE) ]
```

Підставимо типові паспортні значення для сучасного 32-бітного Cortex-M4 мікроконтролера:
- `t_start_RC = 2.5` мкс, `I_start_RC = 1.0` мА;
- `f_RC = 16` МГц, `I_run_RC = 3.2` мА (`200` мкА/МГц);
- `t_start_HSE = 2000` мкс, `I_osc = 2.0` мА;
- `f_HSE = 80` МГц, `I_run_HSE = 8.8` мА (`110` мкА/МГц на високій частоті з оптимізованим DC-DC живленням ядра).

Обчислюємо постійні заряди старту:

```
Q_start_HSE = 2.0 мА · 2000 мкс = 4000 нКл = 4.0 мкКл
Q_start_RC  = 1.0 мА · 2.5 мкс  = 2.5 нКл = 0.0025 мкКл
ΔQ_start    = 4000 - 2.5 = 3997.5 нКл
```

Обчислюємо питомий заряд на один такт:

```
q_tick_RC  = 3.2 мА / 16 МГц = 0.200 нКл/такт
q_tick_HSE = 8.8 мА / 80 МГц = 0.110 нКл/такт
Δq_tick    = 0.200 - 0.110 = 0.090 нКл/такт
```

Обчислюємо критичну кількість тактів `N_crit`:

```
N_crit
= 3997.5 нКл / 0.090 нКл/такт            [відношення дельти заряду старту до дельти заряду на такт]
≈ 44 417 тактів                         [гранична кількість тактів рівноваги]
```

Критичний час виконання на частоті 80 МГц:

```
t_crit_HSE
= N_crit / f_HSE                         [час виконання на частоті 80 МГц]
= 44 417 / (80 · 10⁶)                    [підстановка частоти 80 МГц]
≈ 5.55 · 10⁻⁴ с = 555 мкс                [граничний час на максимальній частоті]
```

Критичний час виконання на частоті 16 МГц:

```
t_crit_RC
= N_crit / f_RC                          [час виконання на частоті 16 МГц]
= 44 417 / (16 · 10⁶)                    [підстановка частоти 16 МГц]
≈ 2.776 · 10⁻³ с = 2.78 мс               [граничний час на базовій частоті RC]
```

## 5. Вплив рівня збудження на деградацію кристала

Окрім витрат енергії, надмірне форсування старту кварцу високою крутістю `g_m` несе ризик механічного пошкодження. Рівень розсіюваної потужності (Drive Level, DL) у кварцовому резонаторі визначається середньоквадратичним струмом `I_rms` через динамічну вітку:

```
DL = I_rms² · R_m
```

Паспортний ліміт для мініатюрних SMD-кварців розміру 2016 або 1612 становить `50`–`100` мкВт. Якщо під час розгону інвертор з надлишковим `g_m` розгойдує струм понад `2` мА, пікова потужність перевищує `300`–`500` мкВт. Це спричиняє:
1. Незворотне зміщення резонансної частоти через мікротріщини в місцях кріплення кварцової пластини (прискорене старіння кристала);
2. Збудження паразитних обертонів (Spurious Modes), коли генератор замість основної гармоніки 16 МГц несподівано захоплює паразитну частоту 48 МГц;
3. Теплове дрейфування параметрів під час кожного старту.

Тому сучасні мікроконтролери мають конфігуровані регістри обмеження потужності генератора (наприклад, біти `HSEDRV[1:0]` у STM32 або `HFXODEBOUNCE` у Silicon Labs), що дозволяють динамічно обирати компроміс між часом старту та механічним ресурсом кристала.

## Висновок і межі застосування

1. Якщо задача вимагає виконання менше ніж `44 000` тактів (наприклад, опитування АЦП, фільтрація 16 значень, збереження в Retention RAM займає близько 1 500–3 000 тактів), виконання на внутрішньому RC-генераторі витрачає в 15–20 разів менше енергії, ніж один лише холостий розгін кварцу HSE.
2. Кварцовий резонатор HSE стає енергетично вигідним лише тоді, коли обчислювальна задача триває понад `2.8` мс безперервної роботи (або коли потрібна надвисока стабільність несучої для радіотракту чи таймінгу точного протоколу на зразок USB/CAN).
