# 🧮 Математична модель теплопередачі й теплового RC-ланцюжка на друкованій платі

Розрахунок теплових полів на друкованій платі спирається на пряму математичну аналогію між законами електродинаміки та теплопередачі. Електричному потенціалу (напрузі) відповідає різниця температур, електричному струму — тепловий потік (потужність тепловиділення у ватах), електричному опору — тепловий опір матеріалів, а електричній ємності — теплоємність маси речовини. Ця вставка містить аналітичне виведення теплового опору провідників плати, розрахунок масиву теплових перехідних отворів, рівняння ребра охолодження для виносного язичка та математичну побудову еквівалентної RC-моделі нагріву.

## Закон Фур'є та тепловий опір прямокутного провідника

Поширення тепла в однорідному ізотропному твердому тілі описується диференціальним законом Фур'є (фр. *Jean-Baptiste Joseph Fourier*):

```
Q = −k · A · (dT / dx)
```

де `Q` — теплова потужність теплового потоку у ватах (Вт), `k` — коефіцієнт теплопровідності матеріалу у Вт/(м·К), `A` — площа поперечного перерізу у м², крізь яку проходить потік, а `dT / dx` — градієнт температури вздовж напрямку поширення `x` у К/м.

Для одновимірного стаціонарного теплового потоку вздовж однорідного провідника довжиною `L` з постійним поперечним перерізом шириною `w` і товщиною `t` інтегрування дає лінійний розподіл температури:

```
ΔT = T_hot − T_cold
= (Q · L) / (k · A)            [інтегрування закону Фур'є вздовж довжини L]
= Q · (L / (k · w · t))        [підстановка площі поперечного перерізу A = w · t]
```

Звідси тепловий опір провідності `R_th` у кельвінах на ват (К/Вт або °C/Вт) визначається відношенням перепаду температури до теплового потоку:

```
R_th = ΔT / Q
= L / (k · A)                  [за визначенням закону Ома для теплових кіл]
= L / (k · w · t)              [розкриття геометричного перерізу прямокутного шару]
```

Ця формула показує, що тепловий опір прямо пропорційний довжині теплового шляху `L` та обернено пропорційний теплопровідності матеріалу `k`, ширині провідника `w` і його товщині `t`.

## Порівняльний розрахунок теплопровідності міді та склотекстоліту FR4

Розглянемо ділянку друкованої плати, що з'єднує джерело тепла з термодавачем, за таких геометричних розмірів: довжина теплового перешийка `L = 20 мм` (0.020 м), ширина перешийка `w = 10 мм` (0.010 м).

Порівняємо тепловий опір стандартного мідного шару товщиною `t_cu = 35 мкм` (1 oz фольга, `35 · 10⁻⁶ м`) з теплопровідністю `k_copper = 385 Вт/(м·К)` та діелектричної основи FR4 товщиною `t_FR4 = 1.53 мм` (`1.53 · 10⁻³ м`) з теплопровідністю `k_FR4 = 0.3 Вт/(м·К)`.

Обчислення теплового опору для мідного шару:

```
R_th_cu = L / (k_copper · w · t_cu)
= 0.020 / (385 · 0.010 · 35 · 10⁻⁶)    [підстановка числових значень у системі SI]
= 0.020 / (1.3475 · 10⁻⁴)              [обчислення знаменника: теплопровідність перерізу]
≈ 148.4 К/Вт                           [результат ділення: тепловий опір мідної смужки]
```

Обчислення теплового опору для склотекстоліту FR4:

```
R_th_FR4 = L / (k_FR4 · w · t_FR4)
= 0.020 / (0.3 · 0.010 · 1.53 · 10⁻³)  [підстановка числових значень діелектрика]
= 0.020 / (4.59 · 10⁻⁶)                [обчислення знаменника для основи FR4]
≈ 4357 К/Вт                            [результат: тепловий опір масиву склотекстоліту]
```

Знайдемо співвідношення теплових потоків через мідь та FR4 при паралельному з'єднанні:

```
Q_cu / Q_FR4 = R_th_FR4 / R_th_cu
= 4357 / 148.4                         [відношення теплових опорів гілок]
≈ 29.36                                [мідь проводить у 29.4 раза більше тепла]
```

Попри те, що шар FR4 у 44 рази товщий за мідну фольгу (`1.53 мм / 0.035 мм ≈ 43.7`), тонка мідна доріжка проводить майже 97% усього теплового потоку (`29.36 / (29.36 + 1) ≈ 0.967`). Якщо ж плата містить внутрішні суцільні шари землі та живлення (чотири шари міді по 35 мкм), тепловий опір міді зменшується до `37.1 К/Вт`, і через мідь проходить понад 99.1% усього паразитного тепла.

## Модель одновимірного теплового ребра для виносного язичка

Виносний консольний язичок друкованої плати, відокремлений фрезерованим прорізом, можна аналітично описати як теплопровідне ребро охолодження (англ. *thermal fin*), що передає тепло від гарячої основи плати та одночасно охолоджується конвекцією у навколишнє повітря.

Розглянемо диференціальний елемент перешийка довжиною `dx`, шириною `w` і товщиною `t`. Рівняння стаціонарного теплового балансу для цього елемента враховує приплив тепла теплопровідністю та конвективну тепловіддачу з верхньої і нижньої граней:

```
k · A · (d²T / dx²) · dx − 2 · h_conv · w · dx · (T(x) − T_ambient) = 0
```

Введемо надлишкову температуру `θ(x) = T(x) − T_ambient` та характерний параметр затухання ребра `m`:

```
d²θ(x) / dx² − m² · θ(x) = 0
де m = √((2 · h_conv) / (k · t))
```

де `h_conv` — коефіцієнт тепловіддачі природної конвекції (типово `h_conv ≈ 10 Вт/(м²·К)` для нерухомого повітря), `k` — еквівалентна теплопровідність перешийка, а `t` — товщина плати (1.6 мм).

Для виносного язичка довжиною `L` з адіабатичним (теплоізольованим) кінцем на кінчику язичка (`dθ/dx = 0` при `x = L`) розв'язок крайової задачі має вигляд гіперболічного косинуса:

```
θ(x) = θ_0 · (cosh(m · (L − x)) / cosh(m · L))
```

де `θ_0 = T_board − T_ambient` — надлишкова температура гарячої зони плати.

Температура на самому термодавачі (при `x = L`):

```
θ(L) = θ_0 / cosh(m · L)
```

Звідси видно математичну причину високої ефективності прорізів: при збільшенні довжини перешийка `L` передана паразитна температура падає обернено пропорційно гіперболічному косинусу, тобто експоненційно затухає зі зростанням `L`. Якщо ж видалити суцільні мідні шари, еквівалентна теплопровідність `k` падає від 385 до 0.3 Вт/(м·К), параметр `m` зростає у десятки разів, що викликає практично повне згасання температурної хвилі на відстані перших кількох міліметрів перешийка.

## Тепловий опір масиву перехідних отворів

Для відведення або передачі тепла між зовнішніми та внутрішніми шарами плати застосовують масив теплових перехідних отворів (англ. *thermal vias*). Металізований отвір являє собою циліндричну трубку з міді, утворену гальванічним осадженням на стінках просвердленого в FR4 отвору.

Геометричні параметри отвору: діаметр свердла `d_via = 0.3 мм` (`0.3 · 10⁻³ м`), товщина мідного покриття стінок `t_plating = 25 мкм` (`25 · 10⁻⁶ м`), висота отвору (товщина плати) `h = 1.6 мм` (`1.6 · 10⁻³ м`).

Площа поперечного перерізу мідної гільзи отвору:

```
A_via = π · ((d_via / 2)² − ((d_via / 2) − t_plating)²)
≈ π · d_via · t_plating                        [наближення тонкої стінки: t << d]
= 3.14159 · (0.3 · 10⁻³) · (25 · 10⁻⁶)         [підстановка геометричних розмірів]
≈ 2.356 · 10⁻⁸ м²                              [площа мідного перерізу однієї гільзи]
```

Тепловий опір одного перехідного отвору вздовж вертикальної осі:

```
R_th_via_1 = h / (k_copper · A_via)
= (1.6 · 10⁻³) / (385 · 2.356 · 10⁻⁸)          [підстановка значень товщини та площі]
= (1.6 · 10⁻³) / (9.0706 · 10⁻⁶)               [обчислення знаменника]
≈ 176.4 К/Вт                                   [тепловий опір одного отвору 0.3 мм]
```

При паралельному розміщенні масиву з `N = 16` отворів під контактним майданчиком еквівалентний тепловий опір масиву дорівнює:

```
R_th_vias = R_th_via_1 / N
= 176.4 / 16                                   [паралельне з'єднання 16 однакових опорів]
≈ 11.0 К/Вт                                    [еквівалентний опір порожніх отворів]
```

Якщо отвори заповнюються припоєм під час хвильового або оплавлювального паяння (питома теплопровідність припою SAC305 `k_solder ≈ 58 Вт/(м·К)`), серцевина площею `A_core = π · (0.25 · 10⁻³ / 2)² ≈ 4.91 · 10⁻⁸ м²` додає провідність:

```
R_th_solder_core = h / (k_solder · A_core)
= (1.6 · 10⁻³) / (58 · 4.91 · 10⁻⁸)            [підстановка параметрів припою]
≈ 561.8 К/Вт                                   [опір олов'яно-срібного стрижня]
```

Повний тепловий опір одного заповненого отвору становить `R_th_filled = (176.4⁻¹ + 561.8⁻¹)⁻¹ ≈ 134.3 К/Вт`, а масив із 16 заповнених отворів разом із теплопровідністю навколишнього FR4 забезпечує тепловий опір `R_th(vias) ≈ 3.2–8.4 К/Вт`, що утворює швидкий міст для тепла між протилежними площинами друкованої плати.

## Теплоємність та динамічна постійна часу

Теплова ємність `C_th` у джоулях на кельвін (Дж/К) визначає кількість теплової енергії `E`, необхідну для нагрівання фізичного об'єкта на один градус:

```
C_th = m · c = V · ρ · c
```

де `m` — маса об'єкта (кг), `c` — питома теплоємність матеріалу в Дж/(кг·К), `V` — об'єм у м³, а `ρ` — густина речовини в кг/м³.

Для міді (`ρ_cu = 8960 кг/м³`, `c_cu = 385 Дж/(кг·К)`):

```
C_v_cu = ρ_cu · c_cu
= 8960 · 385                                   [добуток густини на питому теплоємність]
≈ 3.45 · 10⁶ Дж/(м³·К)                         [об'ємна теплоємність міді]
```

Для склотекстоліту FR4 (`ρ_FR4 = 1900 кг/м³`, `c_FR4 = 1200 Дж/(кг·К)`):

```
C_v_FR4 = ρ_FR4 · c_FR4
= 1900 · 1200                                  [обчислення для епоксидно-скляного композиту]
≈ 2.28 · 10⁶ Дж/(м³·К)                         [об'ємна теплоємність FR4]
```

Диференціальне рівняння теплового балансу для вузла термодавача з власною теплоємністю `C_th`, підключеного через тепловий опір `R_th` до гарячої ділянки плати з температурою `T_board(t)` та розсіюванням тепла в довкілля `T_ambient`:

```
C_th · (dT_sensor(t) / dt) = (T_board(t) − T_sensor(t)) / R_th_board − (T_sensor(t) − T_ambient) / R_th_ambient
```

Позначивши еквівалентний опір `R_eq = (R_th_board⁻¹ + R_th_ambient⁻¹)⁻¹`, теплова постійна часу перехідного процесу набуває стандартного вигляду:

```
τ = R_eq · C_th                                [добуток еквівалентного опору на ємність]
```

При стрибкоподібному виділенні потужності `P_heat` на платі у момент `t = 0` зміна температури описується експонентою першого порядку:

```
ΔT(t) = P_heat · R_eq · (1 − exp(−t / τ))
```

## Каскадна модель Фостера та дискретне рівняння для прошивки

Реальна друкована плата містить щонайменше два виражені масштаби часу: швидкий прогрів кремнієвого кристала й корпусу мікросхеми (`τ_1 = R_1 · C_1 ≈ 5–15 с`) та повільний розподіл тепла масивом склотекстоліту й мідних полігонів усієї конструкції (`τ_2 = R_2 · C_2 ≈ 60–300 с`).

Передатна функція теплового імпедансу `Z_th(s)` у просторі Лапласа для двоелементного каскаду Фостера:

```
Z_th(s) = R_1 / (1 + s · τ_1) + R_2 / (1 + s · τ_2)
```

Для реалізації компенсаційного алгоритму на мікроконтролері з постійним кроком дискретизації за часом `Δt` диференціальне рівняння кожної ланки перетворюється на різницеве рівняння першого порядку методом експоненційного інтегрування:

```
ΔT_1[n] = exp(−Δt / τ_1) · ΔT_1[n−1] + (1 − exp(−Δt / τ_1)) · R_1 · P_heat[n]
ΔT_2[n] = exp(−Δt / τ_2) · ΔT_2[n−1] + (1 − exp(−Δt / τ_2)) · R_2 · P_heat[n]
```

Повний змодельований паразитно внесений нагрів у момент дискретного часу `n`:

```
ΔT_self[n] = ΔT_1[n] + ΔT_2[n]                 [сума відгуків швидкої та повільної ланок]
```

Відновлена істинна температура навколишнього середовища обчислюється шляхом віднімання змодельованого самонагріву від сирих показань термодавача `T_raw[n]`:

```
T_ambient[n] = T_raw[n] − ΔT_self[n]           [алгоритмічна динамічна компенсація]
```

Отримана система рівнянь вимагає лише кількох операцій множення та додавання з рухомою або фіксованою комою на кожен крок дискретизації, що дозволяє виконувати прецизійну динамічну компенсацію навіть на найпростіших 32-розрядних мікроконтролерах.
