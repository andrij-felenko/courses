# ⚙️ Практичні методи пригнічення EMI: від розрахунку демпферів до налаштування драйверів

Ця вставка містить практичні методики розрахунку демпфуючих кіл, покроковий експериментальний алгоритм синтезу RC-снабера для комутаційного вузла DC-DC, правила вибору феритових фільтрів з урахуванням струмового насичення, конфігурацію крутості фронтів GPIO на рівні регістрів та чекліст топології перед передачею плати на виробництво.

---

### 1. Розрахунок послідовного демпфуючого резистора шини

Коли мікроконтролер керує швидкою лінією (тактовий сигнал SPI, QSPI, SDIO, строб паралельної пам'яті), його вихідний буфер має низький внутрішній опір (зазвичай R_drv ≈ 10–25 Ом). Типова мікросмужкова доріжка на друкованій платі над шаром землі має характеристичний опір Z₀ ≈ 50 Ом, а вхід приймача становить майже нескінченний опір (розрив) із паразитними ємностями виводу та контактного майданчика C_in ≈ 3–7 пФ.

Без узгодження хвиля напруги багаторазово відбивається від обох кінців лінії передачі. На приймальному кінці амплітуда перерегулювання (overshoot) може досягати майже подвоєної напруги живлення, що перевантажує захисні діоди входу мікросхеми та породжує згасаючий високочастотний дзвін. Цей дзвін безпосередньо випромінюється доріжкою як антеною і генерує спектральні піки на частотах 100–500 МГц.

Щоб усунути відбиття, узгодити лінію за джерелом (source termination) та обмежити крутість фронту, безпосередньо біля вихідного виводу передавача встановлюють послідовний демпфуючий резистор R_s.

```
R_s = Z₀ − R_drv
```

Для типових значень у 3.3-вольтовій CMOS-системі:
- Z₀ = 50 Ом (хвильовий опір типової мікросмужки шириною 0.25–0.3 мм на діелектрику FR-4 товщиною 0.15 мм);
- R_drv = 18 Ом (вихідний опір драйвера мікроконтролера при струмі насичення каналу);
- R_s = 50 − 18 = 32 Ом (найближчий стандартний номінал з ряду E24 — 33 Ом).

Час наростання фронту на вході приймача з урахуванням сумарного опору та ємності навантаження C_load (ємність самої доріжки C_trace + ємність вхідного каскаду C_in):

```
t_r ≈ 2.2 · (R_drv + R_s) · C_load
```

Якщо сумарна ємність навантаженої лінії C_load = 15 пФ, а сумарний опір виходу R_total = 50 Ом:

```
t_r ≈ 2.2 · 50 Ом · 15·10⁻¹² Ф = 1.65 нс
```

Частота зламу спектра гармонік, після якої амплітуда завад спадає зі швидкістю −40 дБ/декаду:

```
f_knee = 1 / (π · t_r) ≈ 0.35 / t_r
f_knee = 0.35 / (1.65 · 10⁻⁹ с) ≈ 212 МГц
```

Без резистора R_s фронт формувався виключно опором R_drv (18 Ом), час наростання становив t_r ≈ 0.59 нс, а частота зламу сягала f_knee ≈ 593 МГц. Встановлення резистора 33 Ом знижує граничну частоту інтенсивного випромінювання майже втричі, послаблюючи гармоніки в діапазоні 300–800 МГц на 15–20 дБ. При цьому на стабільність передачі даних SPI на частоті 25 МГц (період 40 нс, тривалість фронту 1.65 нс становить лише 4% періоду) демпфер не чинить жодного негативного впливу.

### 2. Покроковий синтез RC-снабера для Switch Node DC-DC

У імпульсних перетворювачах напруги комутаційний вузол (SW) у моменти закриття силових ключів демонструє паразитний високочастотний дзвін (зазвичай у діапазоні 100–300 МГц). Він викликаний коливальним контуром між вихідною ємністю нижнього ключа C_oss та розподіленою індуктивністю монтажу і виводів корпусу L_par.

Цей дзвін створює потужні піки випромінювання, які потрапляють у діапазони FM-радіо (88–108 МГц), авіаційного зв'язку (118–137 МГц) або цифрового телеметрійного радіоканалу.

Параметри паразитного контуру неможливо прочитати з даташита чіпа, оскільки індуктивність L_par значною мірою створюється геометрією трасування конкретної друкованої плати. Їх визначають експериментальним чотирикроковим методом на зібраному прототипі.

#### Методика вимірювання дзвону осцилографом

Стандартний щуп осцилографа з довгим дротом заземлення («крокодилом» довжиною 10–15 см) має власну індуктивність близько 100–150 нГн. Разом із вхідною ємністю щупа (10–15 пФ) він утворює резонансний контур на частоті ~120 МГц і ловить магнітне поле від перетворювача, показуючи на екрані фальшивий артефактний дзвін, якого насправді немає на платі.

Вимірювання слід проводити **виключно за допомогою короткої пружинки заземлення (ground spring)**, притиснутої безпосередньо до земляного полігону за 1–2 мм від точки вимірювання, або через припаяний мініатюрний коаксіальний роз'єм U.FL.

```
Крок 1: Вимірювання первинної частоти дзвону f_ring1
Підключи щуп з короткою пружинкою до виводу SW та силової землі PGND.
Зафіксуй період дзвону T₁ на передньому фронті імпульсу напруги.
f_ring1 = 1 / T₁  (наприклад, 180 МГц)

Крок 2: Додавання тестової ємності C_test
Припаяй високочастотний керамічний конденсатор C_test (діелектрик C0G/NP0, типорозмір 0402/0603)
паралельно нижньому транзистору (між точкою SW та PGND).
Підбирай номінал C_test так, щоб нова частота дзвону f_ring2 зменшилася рівно вдвічі:
f_ring2 = f_ring1 / 2 = 90 МГц  (припустимо, цього досягнуто при C_test = 470 пФ)

Крок 3: Розрахунок паразитної ємності C_p та індуктивності L_p
Оскільки додавання C_test зменшило резонансну частоту контуру вдвічі, сумарна ємність зросла вчетверо:
C_p + C_test = 4 · C_p
C_p = C_test / 3 = 470 пФ / 3 ≈ 156 пФ

Паразитна індуктивність силової петлі:
L_p = 1 / (4 · π² · f_ring1² · C_p)
L_p = 1 / (4 · π² · (180·10⁶)² · 156·10⁻¹²) ≈ 5.0 нГн

Характеристичний опір паразитного контуру дзвону:
Z_ring = √(L_p / C_p) = √(5.0·10⁻⁹ / 156·10⁻¹²) ≈ 5.66 Ом

Крок 4: Вибір номіналів та перевірка теплової потужності снабера
Опір резистора снабера R_snub обирають рівним характеристичному опору для критичного демпфування:
R_snub = Z_ring ≈ 5.6 Ом (стандартний номінал 5.6 Ом або діапазон 4.7–6.8 Ом)

Ємність конденсатора снабера C_snub обирають у 2–3 рази більшою за паразитну ємність C_p:
C_snub = 2 · C_p ≈ 330 пФ  (високочастотна кераміка C0G/NP0)

Розрахунок розсіюваної потужності на резисторі снабера:
P_snub = C_snub · V_in² · f_sw
При V_in = 12 В та частоті комутації f_sw = 500 кГц:
P_snub = 330·10⁻¹² Ф · (12 В)² · 500·10³ Гц = 0.0238 Вт = 23.8 мВт
Цю потужність впевнено розсіює стандартний SMD-резистор типорозміру 0603 (номінал 0.1 Вт) або 0805.
```

### 3. Фільтрація ліній живлення: пастка струмового насичення феритів

Феритові намистини (Ferrite Beads) широко застосовують на вводах живлення та кабельних роз'ємах для поглинання високочастотного шуму. На низьких частотах ферит поводиться як низькоомний провідник (опір постійному струму DCR становить 0.05–0.2 Ом), а в діапазоні 30–500 МГц його комплексний опір стає переважно активним (резистивним), перетворюючи енергію радіозавад на тепло.

Проте при практичному застосуванні феритів легко припуститися двох типових помилок:

1. **Деградація імпедансу через постійний струм підмагнічування (DC Bias Current).** Якщо ферит з номінальним опором 1000 Ом на частоті 100 МГц і максимальним струмом 1 А працює при реальному робочому струмі навантаження 0.6 А, його магнітний сердечник насичується. Реальний опір фериту на високій частоті падає з 1000 Ом до 80–120 Ом, і фільтр практично перестає пригнічувати перешкоди.
   > 🔧 **Правило вибору фериту:** Обирай феритову намистину з номінальним струмом I_max, що перевищує максимальний робочий струм ланцюга щонайменше у 2.5–3 рази, і обов'язково звіряй графік залежності імпедансу від постійного струму в даташиті.

2. **Антирезонансний пік добротності (LC-дзвін).** Індуктивність фериту на середніх частотах (1–10 МГц) разом із вхідними керамічними конденсаторами плати утворює паралельний LC-контур. Якщо добротність цього контуру висока, перехідні процеси при різкій зміні споживання викликають підсилення пульсацій напруги на резонансній частоті (до +10–15 дБ замість пригнічення). Для демпфування резонансу паралельно керамічним конденсаторам обов'язково ставлять електролітичний або танталовий конденсатор із власним ESR близько 0.5–1 Ом, або резистор 1–2 Ом послідовно з додатковою демпфуючою керамічною ємністю.

### 4. Програмне керування крутістю фронтів GPIO

Більшість сучасних мікроконтролерів (STM32, NXP LPC/Kinetis, ESP32, SAM) мають апаратні регістри налаштування вихідних каскадів портів вводу-виводу (GPIO Speed / Slew Rate / Drive Strength).

За замовчуванням багато бібліотек і генераторів коду (як-от STM32CubeMX) виставляють швидкість `GPIO_SPEED_FREQ_VERY_HIGH` (фронти < 1 нс). Якщо такий вихід живить світлодіод, сигнал реле або низькошвидкісний UART на 115200 бод, надшвидкий фронт нічого не покращує у роботі протоколу, але генерує спектр завад аж до 1 ГГц.

Зниження швидкості виводу до `GPIO_SPEED_FREQ_LOW` сповільнює фронт до 10–20 нс, що зрізає частоту зламу f_knee нижче 30 МГц і знижує випромінювання на 20–30 дБ без будь-яких апаратних витрат.

:::tabs
@tab C (CMSIS / LL)
```c
#include <stdint.h>
#include "stm32f4xx.h"

/* Рівні швидкості вихідного каскаду GPIO */
typedef enum {
    GPIO_SPEED_LOW_2MHZ      = 0x00U, /* Фронти ~15-25 нс: UART, LED, реле, повільний I2C */
    GPIO_SPEED_MEDIUM_25MHZ  = 0x01U, /* Фронти ~4-6 нс: SPI до 10 МГц, ШІМ до 100 кГц */
    GPIO_SPEED_FAST_50MHZ    = 0x02U, /* Фронти ~2-3 нс: швидкий SPI, дисплеї */
    GPIO_SPEED_HIGH_100MHZ   = 0x03U  /* Фронти <1.2 нс: тільки SDIO, FMC, паралельні шини */
} gpio_slew_rate_t;

typedef struct {
    GPIO_TypeDef     *port;
    uint32_t          pin_mask;
    gpio_slew_rate_t  slew_rate;
} pin_emi_config_t;

void gpio_configure_slew_rate(const pin_emi_config_t *configs, size_t count)
{
    for (size_t i = 0; i < count; ++i) {
        GPIO_TypeDef *port = configs[i].port;
        uint32_t mask = configs[i].pin_mask;
        uint32_t speed = (uint32_t)configs[i].slew_rate;

        for (uint32_t pin = 0; pin < 16; ++pin) {
            if (mask & (1U << pin)) {
                /* Очищення двох бітів конфігурації швидкості в OSPEEDR */
                port->OSPEEDR &= ~(0x03U << (pin * 2U));
                /* Встановлення обраної крутості фронту */
                port->OSPEEDR |= (speed << (pin * 2U));
            }
        }
    }
}

/* Приклад налаштування плати для мінімізації EMI */
void board_optimize_emi_gpio(void)
{
    static const pin_emi_config_t emi_rules[] = {
        /* Світлодіод статусу та реле — мінімальна швидкість (2 МГц) */
        { GPIOC, (1U << 13) | (1U << 14), GPIO_SPEED_LOW_2MHZ },
        
        /* UART телеметрії (TX/RX) — мінімальна швидкість (2 МГц) */
        { GPIOA, (1U << 9) | (1U << 10), GPIO_SPEED_LOW_2MHZ },
        
        /* Шина I2C датчиків (SCL/SDA, 400 кГц) — помірна швидкість (25 МГц) */
        { GPIOB, (1U << 6) | (1U << 7), GPIO_SPEED_MEDIUM_25MHZ },
        
        /* Тактовий сигнал SPI флеш-пам'яті (SCK, 20 МГц) — швидкість 50 МГц */
        { GPIOA, (1U << 5), GPIO_SPEED_FAST_50MHZ }
    };

    gpio_configure_slew_rate(emi_rules, sizeof(emi_rules) / sizeof(emi_rules[0]));
}
```

@tab C++ (Modern C++20)
```cpp
#include <cstdint>
#include <span>
#include <array>

namespace emi {

enum class SlewRate : uint32_t {
    Low2MHz     = 0x00U, // Фронти ~15-25 нс: UART, LED, низькочастотні сигнали
    Medium25MHz = 0x01U, // Фронти ~4-6 нс: SPI до 10 МГц, стандартні шини
    Fast50MHz   = 0x02U, // Фронти ~2-3 нс: швидкий SPI, інтерфейси датчиків
    High100MHz  = 0x03U  // Фронти <1.2 нс: лише QSPI/SDIO/FMC
};

// Абстракція регістра порту GPIO на базі адреси
struct GpioRegisters {
    volatile uint32_t MODER;
    volatile uint32_t OTYPER;
    volatile uint32_t OSPEEDR;
    volatile uint32_t PUPDR;
    volatile uint32_t IDR;
    volatile uint32_t ODR;
    volatile uint32_t BSRR;
    volatile uint32_t LCKR;
    volatile uint32_t AFR[2];
};

struct PinSlewConfig {
    GpioRegisters *port;
    uint16_t       pin_mask;
    SlewRate       slew_rate;
};

class EmiController {
public:
    static constexpr void applySlewRates(std::span<const PinSlewConfig> configs) noexcept
    {
        for (const auto& cfg : configs) {
            if (cfg.port == nullptr) {
                continue;
            }

            const auto speed_val = static_cast<uint32_t>(cfg.slew_rate);
            for (uint32_t pin = 0; pin < 16; ++pin) {
                if (cfg.pin_mask & (1U << pin)) {
                    const uint32_t shift = pin * 2U;
                    const uint32_t mask = 0x03U << shift;
                    
                    uint32_t reg_val = cfg.port->OSPEEDR;
                    reg_val = (reg_val & ~mask) | (speed_val << shift);
                    cfg.port->OSPEEDR = reg_val;
                }
            }
        }
    }
};

} // namespace emi

// Адреси портів для конкретного мікроконтролера
inline auto* const PORTA = reinterpret_cast<emi::GpioRegisters*>(0x40020000UL);
inline auto* const PORTB = reinterpret_cast<emi::GpioRegisters*>(0x40020400UL);
inline auto* const PORTC = reinterpret_cast<emi::GpioRegisters*>(0x40020800UL);

void configure_board_emi_profiles()
{
    static constexpr std::array<emi::PinSlewConfig, 4> pin_profiles{{
        { PORTC, (1U << 13) | (1U << 14), emi::SlewRate::Low2MHz },     // LED / Силові ключі
        { PORTA, (1U << 9)  | (1U << 10), emi::SlewRate::Low2MHz },     // UART зв'язку
        { PORTB, (1U << 6)  | (1U << 7),  emi::SlewRate::Medium25MHz }, // I2C датчиків
        { PORTA, (1U << 5),               emi::SlewRate::Fast50MHz }    // SPI тактовий сигнал
    }};

    emi::EmiController::applySlewRates(pin_profiles);
}

### 5. Чекліст перевірки топології перед виробництвом (EMI Pre-Layout Audit)

Перед експортом виробничих Gerber-файлів перевір проєкт друкованої плати за такими обов'язковими пунктами:

```
[ ] 1. Суцільність шару землі під критичними доріжками:
    - Жодна швидка лінія (тактові сигнали, SPI, USB, SDIO, ШІМ) не перетинає
      розрізів, щілин або розривів у сусідньому опорному шарі землі.
    - Якщо сигнал переходить між шарами через via, поруч стоїть земляний перехідний
      отвір (ground return via) для безперервного переходу зворотного струму.

[ ] 2. Гаряча петля кожного імпульсного DC-DC перетворювача:
    - Вхідний керамічний конденсатор Cin розташований на відстані не більше 1-2 мм
      від виводів VIN та PGND мікросхеми на тому ж шарі.
    - Зворотний вивід Cin з'єднаний із силовою землею PGND безпосередньо широким полігоном
      перед тим, як іти на внутрішні шари через перехідні отвори.
    - Площа полігону Switch Node (SW) мінімальна, але достатня за допустимим струмом.

[ ] 3. Демпфування швидких ліній:
    - На кожній лінії тактового сигналу (SCK, CLK) або швидких даних передбачено
      місце під послідовний резистор (22–47 Ом) безпосередньо біля виводу передавача.

[ ] 4. Трасування кварцового резонатора:
    - Кварц розміщений впритул до виводів мікроконтролера (< 5 мм).
    - Під кварцом та його навантажувальними конденсаторами на верхньому шарі немає
      чужих цифрових доріжок.
    - Зворотні виводи конденсаторів кварцу з'єднані між собою і підключені в єдину
      точку тихої землі мікроконтролера.

[ ] 5. Периметр плати та фільтрація кабельних роз'ємів:
