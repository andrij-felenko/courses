# Математична модель точки перегину: розрахунок кросовер-тиражу

При виборі між використанням готового сертифікованого модуля (англ. *Modular Carrier Approach*) та розпайкою голого чипа з дискретним обв'язуванням на власній платі (англ. *Chip-down Design*) інженер спирається на розрахунок сукупної вартості володіння (англ. *Total Cost of Ownership*, TCO).

Ця математична модель дозволяє точно визначити граничний тираж випуску пристроїв — точку перегину або кросовер-тираж (англ. *Crossover Production Volume*, `N_cross`), вище якого початкові капітальні витрати на проектування та сертифікацію власного радіотракту повністю окупаються за рахунок нижчої вартості специфікації матеріалів (BOM).

## Структура витрат життєвого циклу

Сукупні витрати на випуск тиражу з `N` виробів для кожної з двох стратегій складаються з двох компонентів:
1. **Одноразові інженерні витрати (NRE — Non-Recurring Engineering):** фіксовані витрати на проектування, виготовлення прототипів, оснащення виробничої лінії та сертифікацію. Вони не залежать від розміру партії.
2. **Змінні витрати на одиницю продукції (Unit Recurring Cost):** собівартість компонентів, виготовлення друкованої плати, монтажу, тестування та втрати від технологічного браку виробництва.

### Компоненти витрат для готового модуля

```
NRE_mod = Cost_CAD_mod + Cost_Proto_mod + Cost_EMC_Part15B + Cost_Fixture_mod
```

де:
* `Cost_CAD_mod` — вартість людино-годин проектування простої 2-шарової базової плати-носія;
* `Cost_Proto_mod` — виготовлення 1–2 ревізій макетних зразків плати;
* `Cost_EMC_Part15B` — вартість спрощеної сертифікації ненавмисного випромінювача (FCC Part 15B / CE Class B), оскільки радіомодуль уже має власний FCC ID;
* `Cost_Fixture_mod` — проста тестова оснастка для програмування та функціонального контролю хост-контролера.

Змінні витрати на один виріб із модулем розраховуються з урахуванням виходу придатних виробів:

```
Unit_mod = (BOM_mod + PCB_2L + SMT_mod) / Yield_mod
```

де:
* `BOM_mod` — ціна закупівлі готового сертифікованого модуля та решти компонентів базової плати;
* `PCB_2L` — вартість простої 2-шарової друкованої плати без жорсткого контролю хвильового імпедансу;
* `SMT_mod` — вартість автоматизованого монтажу меншої кількості компонентів на лінію;
* `Yield_mod` — коефіцієнт виходу придатних виробів (для готових модулів зазвичай становить 0.98–0.99, тобто технологічний брак 1–2%).

### Компоненти витрат для голого чипа (Chip-down)

```
NRE_chip = Cost_CAD_chip + Cost_Proto_chip + Cost_FCC_Full + Cost_ATE_Fixture + Cost_Stencils
```

де:
* `Cost_CAD_chip` — суттєво вища вартість проектування високочастотного тракту 50 Ом, шин швидкісної пам'яті (Octal SPI / PSRAM) та 4–6-шарової структури друкованої плати;
* `Cost_Proto_chip` — виготовлення 3–4 ревізій прототипів (налагодження RF-погодження, температурні випробування, коригування імпедансів);
* `Cost_FCC_Full` — повний комплекс випробувань у безлунній камері для навмисного випромінювача (FCC Part 15C / RED / MIC / SRRC) вартістю $15,000–$50,000+;
* `Cost_ATE_Fixture` — автоматизований тестовий стенд (англ. *Automated Test Equipment*, ATE) із прецизійними радіочастотними пробниками та спектроаналізатором для заводського калібрування потужності передавача та частоти кварца кожного виготовленого чипа;
* `Cost_Stencils` — високоточні лазерні трафарети з нанопокриттям під дрібні корпуси QFN (крок 0.4–0.5 мм) та пасивні елементи 0201/0402.

Змінні витрати на один виріб із голим чипом:

```
Unit_chip = (BOM_chip + PCB_4L + SMT_chip + Test_calib) / Yield_chip
```

де:
* `BOM_chip` — сумарна вартість голого кремнієвого SoC, зовнішньої мікросхеми Flash-пам'яті, кварцових резонаторів, LC-балуна, розсипу фільтрів та захисних діодів;
* `PCB_4L` — вартість 4- або 6-шарової плати з прецизійним контролем імпедансу 50 Ом;
* `SMT_chip` — вартість монтажу значно більшої кількості дрібних компонентів;
* `Test_calib` — витрати часу та амортизації обладнання на радіокалібрування на виробничій лінії;
* `Yield_chip` — коефіцієнт виходу придатних виробів (через складність пайки QFN/BGA та чутливість RF-обв'язки становить 0.94–0.96).

## Математичне моделювання впливу браку (Yield Loss)

Нерідко розробники роблять помилку, порівнюючи «чистий» BOM компонентів без врахування коефіцієнта виходу придатних виробів `Yield`. 

Нехай вартість матеріалів та монтажу становить `Cost_direct`, а ймовірність успішного виготовлення працездатної плати дорівнює `Y` (де `0 < Y ≤ 1`). Якщо бракована плата не підлягає відновленню (scrap), то витрати на її виготовлення розподіляються між придатними виробами:

```
Unit_effective = Cost_direct / Y
```

Якщо для модуля `Yield_mod = 0.99`, то надбавка за брак становить лише:

```
Delta_scrap_mod = Cost_mod · (1/0.99 - 1) ≈ Cost_mod · 0.0101  (близько 1.0%)
```

Для голого чипа в корпусі QFN48 із дрібними пасивами 0201 технологічний вихід на неоптимізованій лінії часто падає до `Yield_chip = 0.94`. Надбавка за брак зростає в шість разів:

```
Delta_scrap_chip = Cost_chip · (1/0.94 - 1) ≈ Cost_chip · 0.0638  (близько 6.4%)
```

Ця різниця у $0.35–$0.50 на кожному виробі здатна повністю «з'їсти» теоретичну економію на ціні мікросхем.

## Виведення формули кросовер-тиражу

Сукупні витрати для кожної зі стратегій виражаються лінійними рівняннями:

```
TCO_module(N) = NRE_mod  + N · Unit_mod
TCO_chip(N)   = NRE_chip + N · Unit_chip
```

Точка перетину (кросовер-тираж `N_cross`) відповідає рівності сукупних витрат:

```
   TCO_module(N_cross) = TCO_chip(N_cross)
   NRE_mod + N_cross · Unit_mod = NRE_chip + N_cross · Unit_chip                      [підставляємо рівняння витрат]
   N_cross · Unit_mod - N_cross · Unit_chip = NRE_chip - NRE_mod                      [групуємо доданки з N_cross]
   N_cross · (Unit_mod - Unit_chip) = NRE_chip - NRE_mod                              [виносимо спільний множник]
   N_cross = (NRE_chip - NRE_mod) / (Unit_mod - Unit_chip)                            [ділимо на різницю собівартостей]
   N_cross = ΔNRE / ΔUnitCost                                                         [остаточний вигляд формули]
```

## Числовий worked-приклад розрахунку для бездротового пристрою

Розглянемо практичний інженерний кейс комерційного пристрою розумного будинку на базі платформи ESP32 (Wi-Fi 802.11 b/g/n + Bluetooth 5.0).

### 1. Вихідні дані моделі готового модуля (ESP32-WROOM-32E)

```
NRE витрати для модуля:
   Розробка схемотехніки й 2-шарової плати (80 год · $50/год): Cost_CAD_mod   = $4,000
   Виготовлення двох ревізій прототипів (10 плат):              Cost_Proto_mod = $1,500
   Спрощена сертифікація FCC Part 15B / CE Unintentional:        Cost_EMC_mod   = $2,500
   Базовий тестовий джиг для прошивки через UART:                Cost_Fixt_mod  = $1,000
   Сумарний NRE_mod = $4,000 + $1,500 + $2,500 + $1,000                        = $9,000

Змінні витрати на одиницю (модульний варіант):
   Закупівля сертифікованого модуля ESP32-WROOM-32E-N4:         BOM_modul_ic   = $3.20
   Решта компонентів (LDO, роз'єми, пасиви хоста):               BOM_other      = $2.10
   Проста 2-шарова плата 80×50 мм (партія 5k–10k):              PCB_2L         = $0.45
   Монтаж SMT (25 компонентів):                                  SMT_mod        = $0.35
   Коефіцієнт виходу придатних виробів:                          Yield_mod      = 0.985

   Unit_mod = ($3.20 + $2.10 + $0.45 + $0.35) / 0.985
   Unit_mod = $6.10 / 0.985 ≈ $6.19 на один готовий виріб
```

### 2. Вихідні дані для голого чипа (ESP32-D0WD-V3 Chip-down)

```
NRE витрати для власного радіотракту:
   Розробка 4-шарової ВЧ плати та погодження (220 год · $50/год): Cost_CAD_chip  = $11,000
   Чотири ревізії прототипів (Rev A, B, C, D) з монтажем:          Cost_Proto_chip = $6,500
   Повна радіосертифікація FCC Part 15C + RED (2.4 ГГц камера):   Cost_FCC_Full   = $32,000
   Виробничий ATE-стенд з радіопробниками та спектроаналізатором:  Cost_ATE        = $8,500
   Прецизійні трафарети для пайки QFN48 і 0201:                   Cost_Stencils   = $1,200
   Сумарний NRE_chip = $11,000 + $6,500 + $32,000 + $8,500 + $1,200               = $59,200

Змінні витрати на одиницю (chip-down варіант):
   Голий мікроконтролер ESP32-D0WD-V3 (QFN48):                   BOM_mcu_chip   = $1.15
   Мікросхема Flash-пам'яті 4 МБ (QSPI SOP8):                    BOM_flash      = $0.42
   Високочастотний кварц 40 МГц (±10 ppm):                       BOM_xtal_hf    = $0.14
   Годинниковий кварц 32.768 кГц:                                BOM_xtal_rtc   = $0.08
   Дискретний LC-балун і Pi-фільтр узгодження:                   BOM_rf_match   = $0.12
   Екрануюча кришка (Metal Shield Can):                          BOM_shield     = $0.15
   Решта компонентів (LDO, роз'єми, пасиви):                     BOM_other      = $2.10
   4-шарова плата 80×50 мм з контролем 50 Ом:                    PCB_4L         = $0.85
   Монтаж SMT (52 компоненти, дрібний крок):                     SMT_chip       = $0.55
   Час радіокалібрування та ATE-тестування на лінії:             Test_calib     = $0.15
   Коефіцієнт виходу придатних виробів:                          Yield_chip     = 0.950

   Сума прямих витрат = $1.15 + $0.42 + $0.14 + $0.08 + $0.12 + $0.15 + $2.10 + $0.85 + $0.55 + $0.15 = $5.71
   Unit_chip = $5.71 / 0.950 ≈ $6.01 на один готовий виріб
```

### 3. Обчислення точки перетину

```
Різниця одноразових витрат:
   ΔNRE = NRE_chip - NRE_mod
   ΔNRE = $59,200 - $9,000 = $50,200

Різниця собівартості одиниці:
   ΔUnitCost = Unit_mod - Unit_chip
   ΔUnitCost = $6.19 - $6.01 = $0.18

Кросовер-тираж:
   N_cross = ΔNRE / ΔUnitCost
   N_cross = $50,200 / $0.18 ≈ 278,889 одиниць
```

## Аналіз чутливості (Sensitivity Analysis)

Кросовер-тираж сильно залежить від трьох параметрів: ціни закупівлі кремнію у виробника, вартості радіолабораторії та технологічного виходу.

### Сценарій А: Масштабні знижки на кремній при великих партіях

Якщо компанія укладає контракт на закупівлю чипів партіями від 50,000 штук, виробник кремнію надає пряму дистриб'юторську знижку: ціна SoC падає з $1.15 до $0.78, а Flash-пам'яті — з $0.42 до $0.26. За рахунок цього різниця собівартостей зростає:

```
   Прямі витрати chip-down зі знижкою = $5.18
   Unit_chip = $5.18 / 0.950 ≈ $5.45
   ΔUnitCost = $6.19 - $5.45 = $0.74
   N_cross = $50,200 / $0.74 ≈ 67,838 одиниць
```

### Сценарій Б: Оптимізація виробничої лінії (Yield = 98%)

Після налагодження термопрофілю печі та встановлення прецизійного трафарету з нанопокриттям вихід придатних плат chip-down зростає до 98.0%:

```
   Unit_chip = $5.18 / 0.980 ≈ $5.29
   ΔUnitCost = $6.19 - $5.29 = $0.90
   N_cross = $50,200 / $0.90 ≈ 55,778 одиниць
```

### Сценарій В: Повторна сертифікація через зміну ревізії кремнію (Silicon Errata)

Якщо виробник чипа випускає нову ревізію кремнію (Rev V3 -> Rev V4), яка змінює параметри вихідного каскаду передавача, компанія з Chip-down дизайном змушена повторно проходити радіосертифікацію:

```
   NRE_retest = $18,000
   Сумарний NRE_chip_new = $59,200 + $18,000 = $77,200
   ΔNRE_new = $77,200 - $9,000 = $68,200
   N_cross = $68,200 / $0.90 ≈ 75,778 одиниць
```

Для компанії, що використовує готовий модуль, цю ресертифікацію виконує сам виробник модуля, а ідентифікатор FCC ID залишається незмінним.

## Висновки аналізу

1. **Тиражі до 10,000–20,000 штук:** готовий модуль завжди економічно вигідніший. Спроба зекономити кілька центів на BOM при малих тиражах ніколи не окупає витрати на радіолабораторію, розробку складних 4-шарових плат та втрати від технологічного браку.
2. **Тиражі від 20,000 до 60,000 штук:** перехідна сіра зона. Рішення залежить від жорсткості вимог до габаритів корпусу, доступності кваліфікованих RF-інженерів та наявності вільних обігових коштів для фінансування NRE.
3. **Тиражі понад 60,000–100,000 штук:** перехід на голий чип є обов'язковим кроком оптимізації маржинальності бізнесу. На тиражі 100,000 одиниць економія навіть $0.90 на кожному виробі дає чистий прибуток у $90,000, повністю перекриваючи початкові витрати на сертифікацію FCC/RED та виготовлення тестових джигів.
