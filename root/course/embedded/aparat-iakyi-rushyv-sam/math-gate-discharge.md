# 🧮 Математика плаваючого затвора: розряд ємності та наведення Міллера

Коли вивід мікроконтролера переходить у високоімпедансний стан, затвор польового транзистора перетворюється на ізольовану обкладку конденсатора. Шар діоксиду кремнію під затвором має питомий електричний опір понад `10¹² Ом`, тому постійний струм крізь діелектрик практично не тече. Поведінка напівпровідникового ключа у фазі невизначеності повністю визначається динамікою накопичення та стікання електричного заряду на паразитних ємностях структури транзистора і монтажу друкованої плати.

Розгляньмо фізико-математичну модель затворного вузла у чотирьох критичних режимах: самовільне накопичення заряду від струмів витоку плати, примусове розряджання затвора через зовнішній резистор підтяжки, ємнісне наведення Міллера при комутації високої напруги на стоку та резистивний подільник із внутрішніми підтяжками мікроконтролера.

## Модель вхідної ємності та накопичення заряду витоку

Повна вхідна ємність польового транзистора `C_iss` утворюється паралельним з'єднанням ємності затвор-витік `C_gs` та ємності затвор-стік `C_gd`:

```
C_iss = C_gs + C_gd
```

Для типового силового транзистора з логічним рівнем керування (наприклад, IRLZ44N, IRLB8721 або аналогічних польових ключів у корпусах TO-220 чи DPAK) ємність `C_iss` становить приблизно `1500–2000 пФ`, а порогова напруга відкриття `V_th` лежить у межах `1.0–2.0 В`.

Якщо вивід мікроконтролера переходить у стан високого імпедансу (High-Z), до затвора більше не прикладено фіксованого потенціалу від вихідного драйвера. На реальній друкованій платі завжди присутні струми витоку `I_leak` через залишки хімічно активного флюсу після пайки, мікроплівку атмосферної вологи та поверхневе забруднення діелектрика текстоліту. Типовий струм витоку між сусідніми доріжками живлення та затвора за нормальної вологості становить від `10 нА` до `100 нА`, а у вологому промисловому середовищі сягає мікроамперних значень.

Оскільки електричний опір діелектрика затвора прямує до нескінченності, навіть слабкий струм витоку заряджає затворну ємність лінійно в часі за фундаментальним законом електростатики:

```
Q(t) = I_leak · t
V_gs(t) = Q(t) / C_iss = (I_leak · t) / C_iss
```

Обчислімо час `t_open`, за який транзистор без зовнішньої підтяжки самочинно досягне порогової напруги відкриття `V_th = 1.5 В` при вхідній ємності `C_iss = 1800 пФ` та помірному струмі витоку плати `I_leak = 50 нА`:

```
t_open
= (V_th · C_iss) / I_leak                              [визначення часу заряду ємності постійним струмом]
= (1.5 В · 1800 · 10⁻¹² Ф) / (50 · 10⁻⁹ А)             [підстановка числових параметрів схеми]
= (2.7 · 10⁻⁹ Кл) / (50 · 10⁻⁹ А)                      [обчислення повного заряду затвора]
= 0.054 с = 54 мс                                      [результат: час до самовільного відкриття ключа]
```

Усього за 54 мілісекунди після переходу мікроконтролера в режим скидання затвор заряджається до порогової напруги без жодної команди керування. Привід мимовільно вмикається і починає рух ще до того, як ядро процесора завершить виконання стартового коду завантажувача.

## Динаміка примусового розряджання через підтяжку

Щоб запобігти небезпечному накопиченню заряду, паралельно ємності затвор-витік встановлюють резистор підтяжки до землі `R_pd` (англ. *pull-down resistor*). У такому разі еквівалентна схема перетворюється на класичне розрядне RC-коло першого порядку.

Якщо в момент вимкнення або переходу виводу в High-Z на затворі була початкова напруга `V_0` (наприклад, рівень логічної одиниці `3.3 В`), напруга на затворі спадає за експоненційним законом:

```
V_gs(t) = V_0 · e^(-t / τ)
де τ = R_pd · C_iss
```

Стала часу кола `τ` визначає темп згасання потенціалу на затворі. Для гарантованого закриття транзистора напруга на затворі повинна впасти нижче безпечного рівня відсічки `V_safe ≤ 0.3 В`, де опір каналу транзистора прямує до гігаомів.

Розрахуймо сталу часу розряду `τ` при номіналі підтяжки `R_pd = 4.7 кОм` та ємності `C_iss = 1800 пФ`:

```
τ
= R_pd · C_iss                                         [формула сталої часу RC-кола]
= 4700 Ом · 1800 · 10⁻¹² Ф                             [підстановка номіналів компонентів]
= 8.46 · 10⁻⁶ с = 8.46 мкс                             [результат: час спаду напруги в e разів]
```

Знайдемо повний час розряду `t_off`, необхідний для зниження потенціалу від `V_0 = 3.3 В` до безпечного порогу `V_safe = 0.3 В`:

```
0.3 В = 3.3 В · e^(-t_off / τ)                         [рівняння перехідного процесу розряду]
e^(-t_off / τ) = 0.3 / 3.3 = 0.0909                    [нормування напруги відсічки]
-t_off / τ = ln(0.0909) ≈ -2.398                       [логарифмування обох частин]
t_off
= 2.398 · τ                                            [вираження часу через сталу кола]
= 2.398 · 8.46 мкс                                     [підстановка розрахованої сталої τ]
= 20.29 мкс                                            [результат: повний час закриття транзистора]
```

За наявності резистора `4.7 кОм` затвор гарантовано розряджається до безпечного рівня всього за `20.3 мікросекунди`. Перевіримо також статичне падіння напруги, яке створює постійний струм витоку плати `50 нА` на цьому резисторі:

```
V_leak_drop
= I_leak · R_pd                                        [закон Ома для кола витоку]
= 50 · 10⁻⁹ А · 4700 Ом                                [підстановка струму витоку та опору підтяжки]
= 0.000235 В = 0.235 мВ                                [результат: паразитичне зміщення потенціалу]
```

Падіння напруги `0.235 мВ` у шість тисяч разів менше за поріг відкриття транзистора `1.5 В`, що забезпечує надійне утримання ключа в закритому стані незалежно від поверхневих витоків плати.

## Динамічний стрибок напруги через ємність Міллера

Найнебезпечнішим динамічним явищем під час комутації силових кіл є ємнісне наведення через внутрішній конденсатор затвор-стік `C_gd` (ємність зворотного зв'язку або ємність Міллера).

Коли на сусідньому плечі моста або на загальній шині живлення мотора комутується висока напруга живлення `V_bus` (наприклад, `24 В` або `48 В`), на стоку закритого транзистора напруга стрибає від нуля до `V_bus` з крутизною наростання `dV_ds / dt`. Цей стрімкий стрибок напруги викликає струм зміщення крізь ємність Міллера `C_gd`:

```
I_miller = C_gd · (dV_ds / dt)
```

Цей струм зміщення стікає на землю через резистор підтяжки `R_pd` та паралельну ємність `C_gs`. Якщо опір підтяжки занадто великий, струм Міллера створює на затворі короткочасний піковий імпульс напруги `V_gs_peak`:

```
V_gs_peak ≈ R_pd · C_gd · (dV_ds / dt)
```

Припустимо, що при вмиканні силового реле або перемиканні сусіднього транзистора напруга `48 В` наростає за час `dt = 50 нс`:

```
dV_ds / dt
= 48 В / (50 · 10⁻⁹ с)                                 [крутизна наростання фронту напруги]
= 0.96 · 10⁹ В/с = 960 В/мкс                           [швидкість наростання потенціалу стоку]
```

Для польового транзистора з ємністю Міллера `C_gd = 100 пФ` порівняємо пікову напругу на затворі для двох різних номіналів підтяжки:

**Варіант 1: помилковий вибір високоомної підтяжки `R_pd = 100 кОм`**

```
V_gs_peak
= 100000 Ом · 100 · 10⁻¹² Ф · 0.96 · 10⁹ В/с           [підстановка параметрів для R = 100 кОм]
= 100000 · 0.096                                       [проміжний розрахунок амплітуди]
= 9600 В                                               [теоретичний результат без захисних діодів]
```

На практиці напруга обмежиться напівпровідниковим пробоєм затвора, але транзистор повністю відкриється на час фронту імпульсу, спричинивши аварійний наскрізний струм короткого замикання (англ. *shoot-through current*).

**Варіант 2: правильний вибір низькоомної підтяжки `R_pd = 4.7 кОм`**

```
V_gs_peak
= 4700 Ом · 100 · 10⁻¹² Ф · 0.96 · 10⁹ В/с             [підстановка параметрів для R = 4.7 кОм]
= 4700 · 0.096 · 10⁻³                                  [зведення порядків величин]
= 0.451 В                                              [результат: пікова напруга на затворі]
```

Отриманий пік `0.451 В` значно менший за мінімальну порогову напругу відкриття `V_th = 1.0 В`. Транзистор лишається надійно закритим, а силовий привід не здійснює жодного паразитного ривка.

## Подільник напруги з внутрішньою підтяжкою мікроконтролера

Багато виводів сучасних мікроконтролерів (зокрема конфігураційні виводи завантаження або порти інтерфейсу зневадження) апаратно мають активний внутрішній резистор підтяжки до живлення `R_pu_int ≈ 30–50 кОм` у стані скидання.

Якщо до такого виводу підключено зовнішній резистор підтяжки до землі `R_pd`, утворюється класичний резистивний подільник від шини живлення ядра `V_dd = 3.3 В`. Напруга на затворі у стані спокою визначається співвідношенням опорів:

```
V_gate_idle = V_dd · (R_pd / (R_pu_int + R_pd))
```

Для гарантованого блокування транзистора необхідно, щоб напруга `V_gate_idle` не перевищувала `0.4 В`. Перевіримо виконання цієї умови для `R_pu_int = 40 кОм` та `R_pd = 4.7 кОм`:

```
V_gate_idle
= 3.3 В · (4.7 кОм / (40 кОм + 4.7 кОм))               [формула резистивного подільника напруги]
= 3.3 · (4.7 / 44.7)                                   [обчислення коефіцієнта ділення]
= 3.3 · 0.1051                                         [проміжне значення коефіцієнта]
= 0.347 В                                              [результат: напруга зміщення на затворі]
```

Оскільки `0.347 В < 0.4 В < V_th`, транзистор гарантовано утримується у закритому стані навіть за наявності активної внутрішньої підтяжки мікроконтролера до шини живлення три і три десятих вольта.
