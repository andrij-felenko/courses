# 🧮 Розрахунок динамічного просідання напруги та буферної ємності

Ця вставка наводить повний математичний розрахунок динамічного просідання напруги хімічного джерела під час імпульсного струмового навантаження, виводить аналітичні формули для визначення мінімальної ємності буферного накопичувача (суперконденсатора EDLC або гібридного конденсатора HLC) та оцінює динаміку відновлення заряду при серійних сеансах передачі пакетів.

У бездротових вузлах зв'язку (LoRa, NB-IoT, BLE, GSM) струм споживання має різко виражений імпульсний характер: тривалий мікрострумовий сон раптово змінюється короткочасним сплеском струму передавача амплітудою I_pulse і тривалістю t_pulse. Якщо внутрішній опір хімічного джерела живлення R_bat є завеликим, падіння напруги призводить до перетину критичного порогу V_min, викликаючи аварійне перезавантаження.

### 1. Просідання напруги на внутрішньому опорі батареї

Розглянемо еквівалентну схему хімічного джерела, представлену ідеальним джерелом ЕРС з напругою холостого ходу V_ocv та послідовним активним внутрішнім опором R_bat. Під час підключення активного навантаження зі струмом I_pulse миттєва напруга на клемах джерела V_term становить:

```
V_term = V_ocv - V_drop                  [базове рівняння напруги на клемах]
V_drop = I_pulse * R_bat                 [падіння напруги за законом Ома]
V_term = V_ocv - I_pulse * R_bat         [підстановка виразу падіння напруги]
```

Якщо пристрій живиться від бобінного елемента Li-SOCl₂ (V_ocv = 3.65 В, R_bat = 40 Ом) і вмикає радіопередавач зі струмом I_pulse = 150 мА = 0.15 А:

```
V_drop = 0.15 * 40                       [підстановка значень струму та опору]
       = 6.00 В                          [теоретичне падіння напруги]
V_term = 3.65 - 6.00                     [розрахунок напруги на клемах]
       = -2.35 В                         [повний колапс джерела нижче нуля]
```

Очевидно, що батарея з таким опором фізично не здатна віддати струм 150 мА: реальна напруга впаде до мінімуму V_term ≈ 1.2–1.6 В, струм обмежиться значенням близько 40–60 мА, а мікроконтролер піде в постійне циклічне перезавантаження.

### 2. Буферизація конденсатором: аналітичне виведення ємності

Для стабілізації шини живлення паралельно до батареї встановлюється накопичувальний конденсатор ємністю C з еквівалентним послідовним опором R_esr.

Сумарне просідання напруги Delta_V_total на буферному конденсаторі під час прямокутного імпульсу I_pulse тривалістю t_pulse складається з двох фізичних процесів:
1. Миттєвого омічного стрибка на послідовному активному опорі діелектрика й виводів конденсатора: Delta_V_esr = I_pulse · R_esr.
2. Поступового інтегрального розряду ємності під дією відібраного електричного заряду: Delta_V_cap = (I_pulse · t_pulse) / C.

```
Delta_V_total = Delta_V_esr + Delta_V_cap           [сума омічного та ємнісного спадів]
Delta_V_total = I_pulse * R_esr + (I_pulse * t) / C [розгортання складових спаду]
```

Враховуючи, що частина струму I_bat підживлюється безпосередньо від батареї через її опір R_bat, результуючий струм розряду ємності дорівнює (I_pulse - I_bat). Для консервативного інженерного розрахунку найгіршого випадку (пасивована батарея або мороз -30 °C, коли R_bat > 100 Ом і I_bat ≈ 0) весь струмовий імпульс забезпечується суто буферною ємністю.

Встановимо максимально допустиме просідання напруги Delta_V_max = V_initial - V_min. Умова безперебійної роботи системи формулюється так:

```
Delta_V_total <= Delta_V_max                                  [критерій безперебійної роботи]
I_pulse * R_esr + (I_pulse * t_pulse) / C <= Delta_V_max      [підстановка рівняння спаду]
(I_pulse * t_pulse) / C <= Delta_V_max - I_pulse * R_esr      [перенесення омічного члена]
C >= (I_pulse * t_pulse) / (Delta_V_max - I_pulse * R_esr)    [виведення мінімальної ємності]
```

### 3. Числовий приклад розрахунку для NB-IoT та LoRaWAN

Розглянемо типовий бездротовий вузол зв'язку:
- Початкова напруга на шині живлення: V_initial = 3.6 В;
- Мінімальна робоча напруга лінійного стабілізатора / радіомодуля: V_min = 2.8 В, звідки допустиме вікно просідання Delta_V_max = 3.6 - 2.8 = 0.8 В;
- Струм передавача під час випромінювання сигналу (TX Burst): I_pulse = 300 мА = 0.3 А;
- Тривалість пакету зв'язку NB-IoT (включаючи синхронізацію з базовою станцією): t_pulse = 500 мс = 0.5 с;
- Еквівалентний послідовний опір суперконденсатора (EDLC або HLC): R_esr = 0.1 Ом.

```
Delta_V_esr = 0.3 * 0.1                                       [омічне просідання на ESR]
            = 0.03 В                                          [всього 30 мВ омічних втрат]
Delta_V_avail = 0.8 - 0.03                                    [доступний запас для розряду ємності]
              = 0.77 В                                        [корисне динамічне вікно]
C_min = (0.3 * 0.5) / 0.77                                    [розрахунок ємності за формулою]
      = 0.15 / 0.77                                           [перемноження відібраного заряду в Кулонах]
      = 0.1948 Ф                                              [мінімальна теоретична ємність]
```

### 4. Врахування температури та старіння діелектрика

Будь-який електрохімічний конденсатор (EDLC або HLC) зазнає деградації параметрів під впливом низьких температур і тривалого часу експлуатації:
1. **Температурний коефіцієнт k_temp:** При зниженні температури до -20 °C опір R_esr зростає у 2–3 рази, а ефективна ємність знижується приблизно на 15–20% через зростання в'язкості електроліту.
2. **Коефіцієнт старіння k_age:** За 10 років експлуатації ємність зменшується на 10–15%, а ESR подвоюється.

Вводимо сумарний інженерний коефіцієнт запасу k_margin = 1.30 (30% запасу):

```
C_design = C_min * 1.30                                       [інженерний розрахунок з запасом]
         = 0.1948 * 1.30                                      [множення на коефіцієнт надійності]
         = 0.253 Ф                                            [номінал 250 мФ / 0.25 Ф]
```

### 5. Динаміка відновлення заряду буфера (RC-релаксація)

Після завершення імпульсу передавача буферний конденсатор відновлює свій заряд через внутрішній опір батареї R_bat. Цей процес описується диференціальним рівнянням першого порядку, розв'язком якого є експоненційний закон заряду RC-ланцюга:

```
V_cap(t) = V_ocv - (V_ocv - V_end) * exp(-t / tau)            [експоненційне відновлення напруги]
tau = R_bat * C                                               [стала часу перехідного процесу]
```

де V_end — напруга на конденсаторі в момент вимкнення передавача (V_end = 3.6 - 0.8 = 2.8 В).

Для батареї Li-SOCl₂ (R_bat = 40 Ом) та буферного конденсатора C = 250 мФ = 0.25 Ф:

```
tau = 40 * 0.25                                               [розрахунок сталої часу RC]
    = 10.0 с                                                  [стала часу становить 10 секунд]
t_95 = 3 * tau                                                [час відновлення до 95% повного заряду]
     = 3 * 10.0                                               [множення трьох сталих часу]
     = 30.0 с                                                 [мінімальний інтервал повторної передачі]
```

### 6. Серія повторних імпульсів (Multi-packet Retransmission)

Якщо протокол зв'язку виконує швидкі повторні спроби передачі пакетів (Retries) з інтервалом t_rep < 3·tau (наприклад, t_rep = 2 секунди при таймауті CSMA/CA), конденсатор не встигає повністю відновити заряд між пакетами.

Залишковий дефіцит напруги після першого імпульсу становить:

```
Delta_V_recovery = (V_ocv - V_end) * (1 - exp(-t_rep / tau))  [відновлена напруга за час t_rep]
```

При t_rep = 2 с і tau = 10 с:

```
exp(-2 / 10) = exp(-0.2) = 0.8187                             [коефіцієнт незавершеної релаксації]
Delta_V_recovery = 0.8 * (1 - 0.8187) = 0.145 В               [конденсатор відновив лише 145 мВ]
```

Це означає, що другий імпульс почнеться не з 3.6 В, а з 2.8 + 0.145 = 2.945 В. Під час другого імпульсу напруга просяде ще на 0.8 В, досягнувши 2.145 В, а третій імпульс призведе до гарантованого аварійного скидання (BOR).

**Інженерне правило:** Прошивка автономного пристрою повинна або примусово обмежувати мінімальний інтервал між повторними радіопосилками часом t_rep >= 3·R_bat·C, або динамічно контролювати напругу шини VCC за допомогою АЦП перед кожною повторною спробою відправки пакету.
