# Вибір пакета під профіль струму: детально

<preknowlist>
- [Хімії батарей](root:embedded/battery-chemistries) — електрохімічні основи, стандартні потенціали та відмінності між катодними матеріалами.
- [Внутрішній опір джерела](root:hw-analog/internal-resistance) — еквівалентна схема батареї, падіння напруги на внутрішньому активному та реактивному опорі.
- [Просідання напруги батареї](root:hw-power/battery-sag) — динамічний спад напруги під час імпульсного струму навантаження та ризик аварійного перезавантаження (Brownout Reset).
</preknowlist>

Автономний датчик із радіомодулем LoRaWAN або NB-IoT, підключений до щойно розпакованої батареї Li-SOCl₂, стабільно вимикається під час першої ж спроби передачі пакету. Вольтметр на клемах батареї показує зразкові 3.65 В, паспортна ємність елемента становить 2400 мА·год, а середнє розрахункове споживання схеми не перевищує 15 мкА, що обіцяє понад десять років безперервної роботи. Проте щойно мікроконтролер переводить радіотрансивер у режим передачі зі струмом 150–300 мА, напруга живлення за лічені мікросекунди падає нижче 2.0 В, спрацьовує апаратний детектор просідання живлення (Brownout Reset, BOR), і пристрій іде в нескінченний цикл перезавантажень.

Причина цієї аварії криється у фатальній невідповідності між навантажувальним профілем струму пристрою та електрохімічною динамікою обраного джерела живлення. Інженер, який обирає батарею виключно за номінальною ємністю (мА·год) або гравіметричною щільністю енергії (Вт·год/кг), потрапляє в пастку: літій-тіонілхлоридні елементи бобінної конструкції володіють рекордною енергоємністю та мінімальним саморозрядом, але їхній внутрішній опір досягає десятків Ом, а на поверхні літію утворюється пасиваційна плівка, яка фізично блокує миттєву віддачу імпульсних струмів. Спроба ж використати звичайні літій-іонні акумулятори (NMC) для вуличного датчика призводить до відмови вузла взимку: при температурах нижче 0 °C стандартний Li-Ion заборонено заряджати через ризик незворотного осадження металевого літію та внутрішнього короткого замикання.

Правильний інженерний вибір хімічної системи та форм-фактора батареї вимагає детального зіставлення повного профілю споживання — мікрострумів глибокого сну, активних обчислювальних вікон, амплітуди й тривалості радіочастотних сплесків, робочого температурного діапазону та цільового терміну служби. Нижче наведено детальний аналіз первинних і вторинних хімій, фізичних механізмів пасивації та динамічного просідання напруги, а також схемотехнічних рішень на базі буферних гібридних конденсаторів.

## Анатомія навантажувального профілю вбудованого пристрою

Сучасні автономні пристрої інтернету речей (IoT), бездротові сенсорні вузли, трекери та лічильники ресурсів не споживають струм рівномірно. Їхній навантажувальний профіль являє собою різко змінну в часі функцію I(t), що складається з трьох характерних фаз.

```
       I (мА)
         ▲
 200 мА ─┼────────────────────────┐  ◄── Фаза 3: Радіопередача (TX Burst)
         │                        │      LoRa / NB-IoT / GSM (10–500 мс)
         │                        │
  15 мА ─┼──────────┐             │  ◄── Фаза 2: Обчислення (Active MCU)
         │          │             │      Зчитування сенсорів, криптографія (2–20 мс)
   2 мкА ─┴──────────┴─────────────┴────────────────────────► Час (t)
          ◄─── Фаза 1: Сон (Deep Sleep) ───►
               99.0%–99.9% усього часу
```

### Три фази споживання енергії

1. **Глибокий сон (Deep Sleep):** Мікроконтролер вимикає більшість тактових генераторів і периферійних модулів, залишаючи активними лише таймер реального часу (RTC) або контролер низькоспоживчих переривань. Струм споживання становить від 0.5 до 10 мкА. У цій фазі пристрій проводить 99.0–99.9% свого життєвого циклу. Основним критерієм для батареї тут є **струм саморозряду**: якщо хімічний елемент втрачає 3–5% ємності на рік через внутрішні паразитарні реакції, цей саморозряд багаторазово перевищує корисне споживання схеми під час сну.
2. **Активне вимірювання та обчислення (Active Processing):** Ядро мікроконтролера прокидається, запускає вбудовані АЦП, подає живлення на зовнішні сенсори, виконує цифрову фільтрацію даних і формує пакет корисного навантаження. Струм споживання становить 2–20 мА протягом 2–50 мс.
3. **Радіопередача (RF Transmission Burst):** Найбільш енергоємна фаза, під час якої вихідний каскад підсилювача потужності (PA) радіотрансивера випромінює сигнал в антену. Струм має характер різкого прямокутного імпульсу:
   - **Bluetooth Low Energy (BLE):** амплітуда 10–25 мА, тривалість 1–5 мс;
   - **LoRaWAN (14–20 dBm):** амплітуда 40–130 мА, тривалість 50–500 мс;
   - **NB-IoT / LTE-M (23 dBm):** амплітуда 150–500 мА, тривалість від 200 мс до 2 секунд;
   - **GSM / 2G (Class 10/12):** імпульси амплітудою до 1.5–2.0 А з шпаруватістю 577 мкс під час передачі слотів TDMA.

### Коефіцієнт розряду C-Rate та закон Пейкерта

Навантажувальну здатність будь-якого хімічного елемента описує коефіцієнт розряду **C-Rate**, що визначає відношення струму розряду I до паспортної ємності батареї C_nom:

```
C_Rate = I / C_nom                       [визначення відносного струму розряду]
```

Для батареї ємністю 1000 мА·год струм 1000 мА відповідає розряду 1C (повний розряд за одну годину), струм 100 мА — 0.1C (розряд за 10 годин), а струм 5 А — 5C.

Кожна хімічна система та конструктивний форм-фактор мають фізичну межу допустимого C-rate. Перевищення цієї межі викликає різке зростання внутрішніх омічних втрат, локальний перегрів електродів, падіння відданої ємності внаслідок закону Пейкерта та глибокий спад напруги на клемах:

```
C_actual = C_nom / (I / I_nom)^(k - 1)   [закон Пейкерта для хімічних джерел]
```

де k — показник Пейкерта (зазвичай 1.05–1.15 для літієвих хімій та 1.25–1.40 для свинцевих і лужних). При розряді імпульсами 2C реальна ємність, яку батарея здатна віддати до досягнення порогу відсічки, може зменшуватися на 20–40% порівняно з тестом на мікрострумах 0.01C.

### Вхідні пускові струми (Inrush Currents)

Окремою прихованою небезпекою є заряд розв'язувальних керамічних конденсаторів (Decoupling Capacitors) на платі. Коли мікроконтролер через ключ живлення (Load Switch) подає живлення на радіомодуль із вхідною ємністю 47–100 мкФ, у перші 2–5 мікросекунд виникає пусковий струм заряду ємності:

```
I_inrush = C_in * (dV / dt)              [струм заряду вхідної ємності]
```

Якщо ключ живлення не має схеми плавного пуску (Soft-Start), піковий струм I_inrush сягає 2–5 А. Для високоомної батареї цей мікросекундний сплеск викликає миттєвий провал напруги VCC до нуля, перезавантажуючи мікроконтролер ще до початку ініціалізації радіотракту.

## Первинні (неперезарядні) елементи: щільність проти імпульсу

Первинні батареї обирають для пристроїв, які повинні працювати від 3 до 20 років без технічного обслуговування: лічильників води, газу та тепла, автономних сейсмічних датчиків, протипожежних сповіщувачів та трекерів контейнерів.

### Літій-тіонілхлорид (Li-SOCl₂)

Хімічна пара літій-тіонілхлорид є лідером за питомою енергоємністю серед комерційно доступних джерел струму. Напруга розімкненого кола становить 3.65 В (робоча напруга під невеликим навантаженням — 3.60 В). Питома об'ємна енергія досягає 1300 Вт·год/л, а масова — до 650–700 Вт·год/кг.

В основі роботи елемента лежить відновлення рідкого тіонілхлориду SOCl₂ на високопористому вуглецевому катоді при окисненні металевого літієвого анода:

```
4Li + 2SOCl2 -> 4LiCl + S + SO2          [сумарна електрохімічна реакція]
```

Саморозряд Li-SOCl₂ становить менше 1% на рік при зберіганні при температурі +20 °C, що теоретично дає змогу зберігати працездатність понад 20 років. Температурний діапазон стандартних комірок становить від -55 °C до +85 °C, а спеціальних високотемпературних версій — до +130 °C.

Проте внутрішня конструкція комірки фундаментально визначає її імпульсні можливості:

1. **Бобінна конструкція (Bobbin type):** Елемент складається з суцільного циліндра металевого літію, нанесеного на внутрішні стінки корпусу, центрального вуглецевого стрижня-катода та рідкого електроліту між ними. Така геометрія максимізує об'єм активних речовин, забезпечуючи максимальну ємність (наприклад, 2600 мА·год для типорозміру AA / ER14505 або 8500 мА·год для ER26500 типорозміру C). Проте площа контакту між електродами мала (близько 10 см²), що дає високий внутрішній опір (20–50 Ом). Максимальний неперервний струм таких елементів обмежений 5–10 мА, а імпульсний — не більше 20–50 мА.
2. **Спіральна конструкція (Spiral type):** Літієвий анод, пористий сепаратор і катодна стрічка згорнуті в щільний багатошаровий рулет («jelly roll»). Площа активної поверхні зростає у 10–15 разів (до 150 см²), внутрішній опір падає нижче 0.5–1 Ом, а імпульсний струм сягає 1.5–3.0 А (наприклад, елементи серії ER14505M). Платою за це є зменшення корисної ємності на 30–40% (через об'єм сепаратора та струмовідводів) і збільшення саморозряду до 2–3% на рік, що скорочує максимальний ресурс до 5–8 років.

### Літій-діоксид марганцю (Li-MnO₂)

Елементи Li-MnO₂ мають номінальну напругу 3.0 В (напруга розімкненого кола 3.2–3.3 В, відсічка 2.0 В). Твердотільний катод на базі діоксиду марганцю MnO₂ контактує з органічним електролітом (солі літію в органічних розчинниках).

- **Дискові елементи (Coin cells: CR2032, CR2450, CR2477):** Широко застосовуються в автомобільних ключах, бездротових кнопках Zigbee та маячках BLE. При ємності 220–240 мА·год для CR2032 її внутрішній опір становить 10–30 Ом при +25 °C і зростає до 80–150 Ом при 0 °C. Максимальний рекомендований імпульсний струм не повинен перевищувати 15–20 мА. Спроба відібрати від CR2032 струм 50 мА просаджує її вихідну напругу нижче 2.0 В за перші ж 2 мс.
- **Циліндричні спіральні елементи (CR123A, CR2):** Розроблені для високих струмів (первинно для фотоспалахів). Завдяки розвиненій площі спіральних електродів внутрішній опір становить менше 0.3–0.5 Ом. Елемент CR123A (1500 мА·год, 3.0 В) вільно віддає імпульси до 1.5–3.0 А без глибокого просідання напруги, має саморозряд менше 1–1.5% на рік і працює в діапазоні від -40 °C до +70 °C. На відміну від Li-SOCl₂, хімія Li-MnO₂ практично не піддається важкій пасивації.

### Лужні елементи (Alkaline Zn-MnO₂)

Класичні лужні батарейки типорозмірів AAA (LR03) та AA (LR6) на базі пари цинк — діоксид марганцю з водним електролітом KOH мають початкову напругу 1.5–1.6 В, яка плавно спадає до 0.9 В наприкінці розряду.

Переваги: мінімальна ціна та повна доступність у будь-якому магазині.

Недоліки для вбудованих систем:
- **Похила розрядна крива:** для живлення мікроконтролера 3.3 В необхідно ставити 2 або 3 елементи послідовно разом із понижувально-підвищувальним (Buck-Boost) перетворювачем.
- **Внутрішній опір:** свіжий елемент AA має опір 0.15–0.3 Ом, але в міру розряду він зростає до 1–3 Ом. Під час імпульсу 500 мА на розрядженій батареї падає до 1.5 В.
- **Температурна деградація:** при температурі нижче 0 °C рухливість іонів у водному електроліті різко сповільнюється; при -15 °C лужна батарея втрачає до 80–90% своєї номінальної ємності.
- **Ризик протікання:** у процесі тривалого глибокого розряду металевий цинковий корпус стоншується, і агресивний електроліт KOH витікає назовні, руйнуючи плату та контакти батарейного відсіку.

## Вторинні (акумуляторні) хімії: ресурс, безпека та холод

Якщо пристрій підтримує регулярну підзарядку від сонячної панелі, мережі живлення або бездротового зарядного пристрою, використовують вторинні хімічні системи.

### Літій-іонні та літій-полімерні (Li-Ion / Li-Po: NMC, LCO)

Стандартні літій-іонні акумулятори на базі нікель-марганець-кобальту (LiNiMnCoO₂, NMC) або оксиду кобальту (LiCoO₂, LCO) мають номінальну напругу 3.7 В (повний заряд 4.2 В, напруга відсічки 3.0 В).

- **Питома енергія:** 180–260 Вт·год/кг, що робить їх стандартом для смартфонів, планшетів, портативних приладів і БПЛА.
- **Імпульсний струм:** від 1C (стандартні призматичні акумулятори) до 10C–30C (силові Li-Po акумулятори з низьким внутрішнім опором 5–15 мОм).
- **Ресурс:** від 300 до 1000 повних циклів до падіння ємності до 80% від початкової.

**Головне критичне обмеження:** температурне вікно заряду. Розряджати Li-Ion можна при температурах від -20 °C до +60 °C, але **заряджати суворо дозволено лише в діапазоні від 0 °C до +45 °C**. При спробі заряду акумулятора при негативній температурі швидкість інтеркаляції іонів літію у графітову ґратку анода стає меншою за швидкість надходження іонів з електроліту. Замість проникнення всередину ґратки іони відновлюються на поверхні анода у вигляді металевого літію. Утворюються гострі кристалічні дендрити, які проростають крізь сепаратор, спричиняючи внутрішнє коротке замикання, перегрів і пожежу (Thermal Runaway).

### Літій-залізо-фосфатні (LiFePO₄ / LFP)

Акумулятори LFP використовують катод на базі фосфату заліза-літію LiFePO₄ та графітовий анод. Номінальна напруга становить 3.2 В (повний заряд 3.65 В, відсічка 2.5 В).

- **Ресурс:** 2000–5000 повних циклів, що у 4–5 разів перевищує ресурс стандартного Li-Ion.
- **Термічна та хімічна стабільність:** міцний ковалентний зв'язок P–O у кристалічній ґратці фосфату заліза запобігає виділенню кисню навіть при сильному перегріві до +270 °C або механічному пробитті комірки. LFP практично не схильний до самозаймання.
- **Розрядна крива:** дуже пласке плато (90% енергії віддається в діапазоні напруг 3.20–3.25 В).
- **Недоліки:** нижча питома енергія (90–120 Вт·год/кг) та аналогічна заборона на швидкий заряд при температурах нижче 0 °C без попереднього підігріву.

### Літій-титанатні (LTO: Li₄Ti₅O₁₂)

У літій-титанатних акумуляторах графітовий анод замінено на шпінельний титанат літію Li₄Ti₅O₁₂. Номінальна напруга становить 2.4 В (робочий діапазон 1.5–2.8 В).

- **Надвисокий ресурс:** від 10 000 до 30 000 циклів заряду/розряду. Навіть при щоденному циклуванні батарея здатна пропрацювати понад 25–40 років.
- **Робота на екстремальному морозі:** шпінельна структура LTO є матеріалом з нульовою деформацією ґратки (Zero-Strain). Потенціал анода відносно металевого літію становить близько 1.55 В, що повністю виключає осадження металевого літію та ріст дендритів. Акумулятори LTO безпечно **заряджаються та розряджаються при температурах від -30 °C до -40 °C** струмами до 1C–5C.
- **Імпульсні можливості:** тривалий струм розряду до 10C, імпульсний — до 20C–30C. Час повного заряду становить від 6 до 15 хвилин.
- **Ціна витривалості:** низька напруга 2.4 В і помірна питома енергія (60–90 Вт·год/кг), а також висока початкова вартість комірки.

## Явище пасивації літієвих батарей: фізика, ризики та боротьба

Пасивація — це спонтанна хімічна реакція, що виникає в усіх первинних літієвих батареях із рідким католітом (насамперед Li-SOCl₂ та Li-SO₂). Вона є водночас головною перевагою і найбільшим викликом при проектуванні низькоспоживчих пристроїв.

### Хімічний механізм росту плівки LiCl

Металевий літій є надзвичайно активним лужним металом. Щойно рідкий оксихлорид сірки SOCl₂ контактує з поверхнею літієвого анода, починається бурхлива окисно-відновна реакція. Продуктом цієї реакції є нерозчинний у тіонілхлориді твердий хлорид літію (LiCl).

Кристали LiCl випадають в осад безпосередньо на поверхні металевого літію, утворюючи тонку первинну плівку товщиною в кілька молекулярних шарів. Ця плівка є діелектриком для електронів, але має обмежену іонну провідність завдяки точковим дефектам кристалічної ґратки (дефекти Френкеля).

![Механізм росту та руйнування плівки LiCl](/root/course/embedded/vybir-paketa-pid-profil-strumu/img/passivation-mechanism.svg)
*Етапи утворення пасиваційного шару LiCl та його руйнування під струмом.*

1. **Захисна роль (благо):** Шар LiCl герметично ізолює металевий літій від рідкого тіонілхлориду, зупиняючи пряму хімічну реакцію між ними. Завдяки цьому струм корозійного саморозряду падає нижче 0.1 мкА/см², що й забезпечує рекордний термін зберігання батареї понад 15–20 років.
2. **Паразитна роль (прокляття):** Якщо батарея зберігається тривалий час (особливо при високій температурі понад +30...+50 °C) без відбору струму або з мікроспоживанням менше 5 мкА, шар кристалів LiCl продовжує поступово товщати, формуючи вторинний макропористий шар. Внутрішній електричний опір комірки зростає від початкових 10–20 Ом до 100–500 Ом.

### Динаміка перехідного мінімуму напруги (TMV)

Коли мікроконтролер після тривалого сну підключає навантаження (наприклад, радіомодуль зі струмом 100 мА), товстий шар LiCl не пропускає потрібну кількість іонів Li⁺.

Напруга на клемах миттєво просідає до критично низького значення, яке називають **перехідним мінімумом напруги** (Transient Minimum Voltage, TMV). Якщо TMV опускається нижче порогу скидання живлення мікроконтролера (зазвичай 1.8–2.2 В), схема перезавантажується ще до завершення передачі першого байту.

![Динаміка перехідного провалу напруги](/root/course/embedded/vybir-paketa-pid-profil-strumu/img/voltage-sag-transient.svg)
*Перехідний мінімум напруги (TMV) пасивованої батареї проти депасивованої та гібридної системи.*

Під дією протікаючого струму висока напруженість електричного поля механічно розриває та поступово розчиняє кристалічний шар LiCl. Протягом кількох десятків мілісекунд (або секунд) внутрішній опір падає, і напруга відновлюється до робочих 3.2–3.4 В. Проте для системи, яка вже пішла у перезавантаження, це відновлення настає занадто пізно.

### Методи та алгоритми депасивації

Для запобігання аварійним збоям застосовують регулярну профілактичну або адаптивну **депасивацію**:

- **Апаратне баластне навантаження:** На друкованій платі встановлюють польовий N-канальний транзистор MOSFET і резистор номіналом 50–150 Ом, підключені паралельно до батареї.
- **Програмний алгоритм розминки:** Раз на добу (або перед кожним запланованим сеансом зв'язку) прошивка активує MOSFET серією коротких імпульсів струму 20–50 мА, поступово збільшуючи шпаруватість. Струм розбиває плівку LiCl, після чого АЦП вимірює напругу під навантаженням. Тільки коли напруга під навантаженням перевищить безпечний поріг (наприклад, 3.0 В), пристрій вмикає радіопередавач.

Детальний вихідний код прошивки для керування баластним MOSFET і контролю внутрішнього опору наведено в окремому модулі: [Депасивація літієвих батарей](root:embedded/vybir-paketa-pid-profil-strumu/proj-depassivation-routine.md).

## Імпульсна віддача та узгодження імпедансу: HLC та суперконденсатори

Якщо пристрій повинен працювати 10–15 років від бобінного елемента Li-SOCl₂, але водночас регулярно відправляє пакети через енергоємні радіоінтерфейси (NB-IoT зі струмом до 500 мА або GSM до 2 А), бобінний елемент фізично не може забезпечити такий струм навіть після повної депасивації.

Єдиним надійним інженерним рішенням є створення **гібридної системи живлення**, де паралельно до хімічного елемента встановлюється імпульсний накопичувач енергії з ультранизьким внутрішнім опором.

![Схема гібридного джерела Li-SOCl2 з HLC](/root/course/embedded/vybir-paketa-pid-profil-strumu/img/hlc-hybrid-circuit.svg)
*Архітектура паралельного з'єднання первинного елемента Li-SOCl₂ та гібридного конденсатора HLC.*

### Гібридні шарові конденсатори (HLC / PulsesPlus)

Гібридний шаровий конденсатор (Hybrid Layer Capacitor, HLC) — це спеціалізований літієвий електрохімічний конденсатор, оптимізований для тривалої спільної роботи з елементами Li-SOCl₂:

1. **Робоча напруга:** HLC розрахований на тривалу роботу під постійною напругою 3.6–3.9 В без деградації діелектрика (на відміну від звичайних суперконденсаторів EDLC, максимальна напруга яких обмежена 2.7 В на комірку).
2. **Внутрішній опір:** ESR становить менше 0.1–0.3 Ом, що дає змогу віддавати імпульсні струми до 1–3 А.
3. **Саморозряд:** Струм витоку HLC при +25 °C становить менше 1–2 мкА, що практично не впливає на загальний бюджет споживання у режимі глибокого сну.

Під час глибокого сну батарея Li-SOCl₂ безперервно підзаряджає HLC мікрострумом, підтримуючи його напругу на рівні 3.65 В. Під час увімкнення радіопередавача 95–99% пікового імпульсного струму віддає саме HLC. Напруга на шині живлення VCC просідає лише на 100–200 мВ, гарантуючи безперебійну роботу мікроконтролера.

Математичне виведення необхідної ємності накопичувача та розрахунок часу відновлення напруги між сеансами зв'язку винесено у теоретичний блок: [Розрахунок динамічного просідання напруги](root:embedded/vybir-paketa-pid-profil-strumu/math-voltage-sag-budget.md).

## Вибір топології вторинного перетворювача (LDO проти DC-DC)

Тип стабілізатора напруги між батареєю та мікроконтролером безпосередньо впливає на те, наскільки глибоке просідання напруги батареї витримує система:

1. **Лінійний стабілізатор із малим падінням напруги (LDO):**
   - Наприклад, стабілізатор на 3.0 В або 3.3 В. LDO має власне мінімальне падіння напруги (Dropout Voltage) V_drop ≈ 100–250 мВ під максимальним струмом.
   - Якщо вихідна напруга стабілізатора 3.0 В, а V_drop = 200 мВ, напруга на батареї не повинна падати нижче 3.2 В під час передачі. Для елемента Li-MnO₂ (номінал 3.0 В) або розрядженої Li-SOCl₂ LDO швидко переходить у режим насичення (Drop-out), і напруга живлення МК починає дзеркально повторювати всі провали батареї.
2. **Понижувальний імпульсний перетворювач (Buck Converter):**
   - Ефективний при високій напрузі свіжої батареї (ККД 90–95%), проте вимагає, щоб вхідна напруга завжди була вищою за вихідну плюс внутрішнє падіння на ключах.
3. **Понижувально-підвищувальний перетворювач (Buck-Boost):**
   - Єдине надійне рішення для повного викачування енергії з первинних батарей аж до напруги відсічки 1.8–2.0 В при стабільній шині 3.3 В. Перетворювач автоматично підвищує напругу, коли під час імпульсу радіопередавача напруга на хімічному елементі просідає нижче 3.3 В.

### Типові інженерні сценарії вибору

1. **Квартирний лічильник води / тепла (термін служби 12–16 років, підвал):**
   - Профіль: сон 2 мкА (99.99% часу), раз на добу відправка звіту через NB-IoT (пік 300 мА протягом 2 с).
   - Рішення: **Li-SOCl₂ Bobbin (ER26500) + паралельний конденсатор HLC1550**. Батарея забезпечує мізерний саморозряд і колосальну ємність, а HLC бере на себе імпульс модему.
2. **Вуличний агродатчик вологості ґрунту (LoRaWAN, робота від сонячної панелі):**
   - Профіль: сон 10 мкА, сеанс LoRa щогодини (80 мА, 200 мс), цілорічна робота в полі від -20 °C до +50 °C.
   - Рішення: **Невелика сонячна панель + LiFePO₄ акумулятор 18650**. Ресурс понад 3000 циклів забезпечує 8+ років роботи. Контролер заряду повинен мати терморезистор (NTC) для блокування заряду при температурі нижче 0 °C.
3. **Автомобільний протиугінний GPS/LTE маяк-закладка (автономність 3 роки):**
   - Профіль: глибокий сон із споживанням 5 мкА, раз на добу фіксація GPS (50 мА, 30 с) та передача через LTE-M (250 мА, 5 с). Взимку в неопалюваному авто температура падає до -30 °C.
   - Рішення: **3x Li-MnO₂ (CR123A послідовно/паралельно)** або **Li-SOCl₂ Spiral**. Хімія Li-MnO₂ гарантовано тримає високий струм при -30 °C без ризику важкої пасивації.
4. **Мініатюрний трекер для ключів / датчик відкриття дверей (BLE / Zigbee):**
   - Профіль: сон 1.5 мкА, раз на хвилину маяк BLE (15 мА, 3 мс).
   - Рішення: **Дисковий елемент Li-MnO₂ CR2032** з обов'язковим танталовим або керамічним буферним конденсатором 47–100 мкФ з низьким струмом витоку безпосередньо біля виводів живлення мікроконтролера.

## Практична реалізація: вимірювання динамічного просідання та контроль батареї

Нижче наведено практичну реалізацію вбудованого модуля для мікроконтролера, що виконує тестове навантаження батареї, вимірює напругу під струмом, обчислює внутрішній опір і повертає вердикт щодо готовності до увімкнення радіотракту.

:::tabs
```c
// battery_monitor.c — Модуль динамічної діагностики батареї (C99)
#include <stdint.h>
#include <stdbool.h>

#define TEST_LOAD_RESISTOR_OHM   68.0f    // Номінал тестового резистора (Ом)
#define VOLTAGE_MIN_SAFE_MV      2800U    // Поріг безпечної напруги (2.8 В)
#define RESISTANCE_MAX_WARN_OHM  15.0f    // Максимально допустимий опір джерела (Ом)

typedef struct {
    uint32_t (*get_adc_voltage_mv)(void);
    void (*set_load_mosfet)(bool state);
    void (*sleep_us)(uint32_t us);
} pwr_hal_t;

typedef enum {
    BATTERY_OK = 0,
    BATTERY_WARN_HIGH_IMPEDANCE,
    BATTERY_ERR_VOLTAGE_SAG,
    BATTERY_ERR_DEPLETED
} battery_health_t;

typedef struct {
    uint32_t ocv_mv;
    uint32_t v_sag_mv;
    float dynamic_esr_ohm;
    battery_health_t health;
} battery_report_t;

battery_health_t battery_evaluate_health(const pwr_hal_t *hal, battery_report_t *report) {
    if (!hal || !report) {
        return BATTERY_ERR_DEPLETED;
    }

    // 1. Зняття напруги розімкненого кола (OCV)
    hal->set_load_mosfet(false);
    hal->sleep_us(1000); // 1 мс пауза для стабілізації
    report->ocv_mv = hal->get_adc_voltage_mv();

    if (report->ocv_mv < VOLTAGE_MIN_SAFE_MV) {
        report->health = BATTERY_ERR_DEPLETED;
        return BATTERY_ERR_DEPLETED;
    }

    // 2. Короткочасне підключення тестового навантаження (5 мс)
    hal->set_load_mosfet(true);
    hal->sleep_us(2000); // Очікування встановлення перехідного процесу
    report->v_sag_mv = hal->get_adc_voltage_mv();
    hal->set_load_mosfet(false);

    // 3. Розрахунок внутрішнього динамічного опору ESR
    // Струм навантаження I = V_sag / R_load
    // Падіння напруги Delta_V = OCV - V_sag
    // ESR = Delta_V / I = (OCV - V_sag) * R_load / V_sag
    if (report->v_sag_mv > 0) {
        float delta_v = (float)(report->ocv_mv - report->v_sag_mv);
        report->dynamic_esr_ohm = (delta_v * TEST_LOAD_RESISTOR_OHM) / (float)report->v_sag_mv;
    } else {
        report->dynamic_esr_ohm = 999.0f;
    }

    // 4. Оцінка стану здоров'я джерела
    if (report->v_sag_mv < VOLTAGE_MIN_SAFE_MV) {
        report->health = BATTERY_ERR_VOLTAGE_SAG;
    } else if (report->dynamic_esr_ohm > RESISTANCE_MAX_WARN_OHM) {
        report->health = BATTERY_WARN_HIGH_IMPEDANCE;
    } else {
        report->health = BATTERY_OK;
    }

    return report->health;
```

```cpp
// battery_monitor.hpp — Ідіоматичний C++20 модуль діагностики живлення
#include <cstdint>
#include <concepts>
#include <chrono>
#include <expected>

enum class PowerDiagnosticError {
    DeviceDepleted,
    ExcessiveVoltageSag,
    HardwareInterfaceFault
};

struct PowerAssessment {
    std::uint32_t open_circuit_voltage_mv{0};
    std::uint32_t loaded_voltage_mv{0};
    float internal_impedance_ohm{0.0f};
    bool requires_depassivation{false};
};

template <typename HAL>
concept PlatformPowerHAL = requires(HAL hal, bool enable, std::chrono::microseconds us) {
    { hal.read_adc_millivolts() } -> std::same_as<std::uint32_t>;
    { hal.enable_test_load(enable) } -> std::same_as<void>;
    { hal.delay(us) } -> std::same_as<void>;
};

template <PlatformPowerHAL HAL>
class BatteryImpedanceAnalyzer {
public:
    static constexpr float TestLoadResistanceOhm = 68.0f;
    static constexpr std::uint32_t SafeVoltageThresholdMv = 2'800;
    static constexpr float MaxAllowedImpedanceOhm = 15.0f;

    explicit constexpr BatteryImpedanceAnalyzer(HAL& hal) noexcept : hal_(hal) {}

    [[nodiscard]] std::expected<PowerAssessment, PowerDiagnosticError> assess_pack_state() noexcept {
        PowerAssessment assessment{};

        // 1. Напруга холостого ходу
        hal_.enable_test_load(false);
        hal_.delay(std::chrono::microseconds(1000));
        assessment.open_circuit_voltage_mv = hal_.read_adc_millivolts();

        if (assessment.open_circuit_voltage_mv < SafeVoltageThresholdMv) {
            return std::unexpected(PowerDiagnosticError::DeviceDepleted);
        }

        // 2. Імпульсне навантаження (2 мс стабілізація + замір)
        hal_.enable_test_load(true);
        hal_.delay(std::chrono::microseconds(2000));
        assessment.loaded_voltage_mv = hal_.read_adc_millivolts();
        hal_.enable_test_load(false);

        if (assessment.loaded_voltage_mv < SafeVoltageThresholdMv) {
            return std::unexpected(PowerDiagnosticError::ExcessiveVoltageSag);
        }

        // 3. Розрахунок ESR
        const float delta_v = static_cast<float>(assessment.open_circuit_voltage_mv - assessment.loaded_voltage_mv);
        assessment.internal_impedance_ohm = (delta_v * TestLoadResistanceOhm) / static_cast<float>(assessment.loaded_voltage_mv);

        if (assessment.internal_impedance_ohm > MaxAllowedImpedanceOhm) {
            assessment.requires_depassivation = true;
        }

        return assessment;
    }

private:
    HAL& hal_;
};
```
