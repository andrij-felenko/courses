# 🧮 Механіка силового контакту та динаміка імпедансу

Коли маніпулятор рухається у вільному просторі, його робочий орган переміщує точку в тривимірному просторі без жодного механічного опору, крім власної маси й тертя в підшипниках. Позиційний регулятор вимірює розбіжність між заданою координатою та поточною, збільшує струм моторів і приводить інструмент у ціль. Щойно кінцевий інструмент торкається твердої поверхні — бетонної стіни, металевого вентиля чи фланця труби, — механіка системи докорінно змінюється: відкритий кінематичний ланцюг замикається на зовнішнє пружне тіло, і будь-яка спроба позиційного контуру посунути ланку далі породжує стрибок сили реакції.

Цей розділ розгортає математичний апарат, що описує перехід від вільного руху до контактної взаємодії: динаміку системи у просторі завдань, постановку цільового імпедансу, аналіз стійкості замкненого контуру при контакті з жорстким середовищем та розщеплення простору завдань на підпростори сили й положення.

## 1. Динаміка маніпулятора у просторі суглобів та просторі завдань

Динамічний стан `n`-ланкового маніпулятора в узагальнених координатах суглобів `q = [q_1, q_2, ..., q_n]^T` описується рівнянням Лагранжа — Ейлера, до якого додається вектор зовнішніх сил, приведених до суглобів через транспоновану матрицю Якобі:

```text
M(q) · q'' + C(q, q') · q' + g(q) = tau + J(q)^T · F_ext
```

де:
- `M(q)` — симетрична додатно визначена матриця інерції розмірності `n × n`;
- `C(q, q') · q'` — вектор коріолісових та відцентрових сил розмірності `n × 1`;
- `g(q)` — вектор гравітаційних моментів розмірності `n × 1`;
- `tau` — вектор узагальнених сил (моментів керування моторів) розмірності `n × 1`;
- `J(q)` — геометричний якобіан маніпулятора розмірності `6 × n`, що пов'язує швидкість суглобів `q'` зі швидкістю робочого органа `x'` у декартовому просторі (`x' = J(q) · q'`);
- `F_ext = [f_x, f_y, f_z, m_x, m_y, m_z]^T` — вектор зовнішньої сили та моменту, що діють на робочий орган з боку середовища (розмірність `6 × 1`).

Щоб керувати взаємодією безпосередньо в точці контакту, систему необхідно спроектувати у простір завдань (Cartesian / Operational Space). Диференціюючи кінематичний зв'язок `x' = J(q) · q'` за часом, отримуємо прискорення робочого органа:

```text
x'' = J(q) · q'' + J'(q) · q'
```

Виражаючи кутове прискорення суглобів `q''` з основного рівняння динаміки:

```text
q'' = M(q)^(-1) · (tau + J(q)^T · F_ext - C(q, q') · q' - g(q))
```

і підставляючи його у вираз для декартового прискорення `x''`, маємо рівняння динаміки робочого органа у просторі операцій:

```text
x'' = J · M^(-1) · (tau - C · q' - g) + J · M^(-1) · J^T · F_ext + J' · q'
```

Вводимо операційну матрицю маси `Lambda(q)` розмірності `6 × 6`:

```text
Lambda(q) = (J(q) · M(q)^(-1) · J(q)^T)^(-1)
```

Множачи вираз для прискорення на `Lambda(q)`, отримуємо компактну форму динаміки у просторі завдань:

```text
Lambda(q) · x'' + mu(q, q') + p(q) = F_cmd + F_ext
```

де `mu(q, q')` — коріолісові й відцентрові сили у просторі завдань, `p(q)` — декартова гравітаційна складова, а `F_cmd = Lambda · J · M^(-1) · tau` — просторове зусилля керування, що створюється моментами приводів.

## 2. Постановка задачі імпедансного та адмітансного керування

Якщо робот намагається рухатися за чисто позиційною траєкторією `x_d(t)`, виникає помилка позиціювання `e(t) = x(t) - x_d(t)`. Замість того, щоб нескінченно збільшувати момент керування у спробі ліквідувати `e(t)`, імпедансне керування (за Невілом Гоґаном) нав'язує робочому органу поведінку віртуальної динамічної системи другого порядку:

```text
M_d · e''(t) + D_d · e'(t) + K_d · e(t) = -F_ext(t)
```

де:
- `M_d` — віртуальна додатно визначена діагональна матриця інерції (`6 × 6`);
- `D_d` — віртуальна матриця демпфування (`6 × 6`);
- `K_d` — віртуальна матриця жорсткості (`6 × 6`).

Знак «мінус» перед `F_ext` вказує на податливість: якщо середовище тисне на інструмент із силою `F_ext > 0`, інструмент мусить відступити назад (`e < 0`), знижуючи контактне напруження.

### Адмітансна форма (Admittance Control)

У мобільних роботах і серійних маніпуляторах приводи часто мають вбудовані жорсткі позиційні або швидкісні контури. У такому разі використовується адмітансна схема: сенсор вимірює реальну силу `F_ext`, а алгоритм реального часу генерує поправку до траєкторії руху:

```text
e''(t) = M_d^(-1) · ( -F_ext(t) - D_d · e'(t) - K_d · e(t) )
```

Інтегруючи це диференціальне рівняння чисельно на кожному такті контуру з періодом `dt`:

```text
e'(t + dt) = e'(t) + e''(t) · dt            [крок інтегрування швидкості]
e(t + dt)  = e(t)  + e'(t + dt) · dt        [крок інтегрування зміщення]
x_cmd(t + dt) = x_d(t + dt) + e(t + dt)     [коригована команда положення для приводів]
```

Отримане значення `x_cmd` передається на внутрішній позиційний регулятор маніпулятора.

## 3. Аналіз стійкості контакту з жорстким середовищем

Розглянемо одновимірний випадок контакту інструмента з нерухомою перешкодою, що має власну пружність `K_env` та координату поверхні `x_env`. Сила реакції середовища визначається законом Гука:

```text
F_ext = K_env · (x - x_env)   при x > x_env
F_ext = 0                     при x <= x_env
```

Підставимо модель сили реакції у рівняння цільового імпедансу для випадку стаціонарної цільової точки `x_d`:

```text
M_d · x'' + D_d · x' + K_d · (x - x_d) = -K_env · (x - x_env)
```

Перегрупуємо члени рівняння відносно змінної стану `x(t)`:

```text
M_d · x'' + D_d · x' + (K_d + K_env) · x = K_d · x_d + K_env · x_env
```

Ділимо на `M_d` для приведення до стандартного вигляду коливальної ланки другого порядку:

```text
x'' + (D_d / M_d) · x' + ((K_d + K_env) / M_d) · x = (K_d · x_d + K_env · x_env) / M_d
```

Власна частота коливань системи в контакті `omega_n` та коефіцієнт демпфування `zeta` набувають вигляду:

```text
omega_n = sqrt( (K_d + K_env) / M_d )
zeta    = D_d / (2 · sqrt( M_d · (K_d + K_env) ))
```

### Причина виникнення нестійкості та контактного брязкоту (Chattering)

У вільному просторі (`K_env = 0`) інженер налаштовує критичне демпфування:

```text
zeta_free = D_d / (2 · sqrt(M_d · K_d)) = 1.0
```

Проте під час контакту з металом або бетоном жорсткість середовища досягає значень `K_env = 10^5 ... 10^6 Н/м`, тоді як віртуальна жорсткість зазвичай обирається в межах `K_d = 200 ... 1000 Н/м`. Відношення `K_env / K_d >> 1000`.

Підставимо ці порядки величин у коефіцієнт демпфування при контакті:

```text
zeta_contact = D_d / (2 · sqrt(M_d · (K_d + K_env))) 
             = zeta_free · sqrt( K_d / (K_d + K_env) )
             << 1.0
```

Коефіцієнт демпфування падає до значень 0.01–0.05. Система перетворюється на високочастотний слабкодемпфований осцилятор.

Якщо врахувати затримку дискретизації цифрового контуру `T_d` (типово 1–2 мс) та фазовий зсув силового датчика, фазовий запас стійкості вичерпується, і система переходить у режим автоколивань (граничний цикл з чергуванням ударів і відскоків від поверхні).

### Умова стійкості за Найквістом та вибір параметрів

Щоб запобігти високочастотному брязкоту, параметри адмітансу повинні задовольняти нерівність пасивності з урахуванням періоду дискретизації `dt`:

```text
D_d > (K_env · dt) / 2
```

Якщо жорсткість середовища заздалегідь невідома або надзвичайно висока, алгоритм зобов'язаний застосовувати адаптивне демпфування: збільшувати `D_d` пропорційно виміряній похідній сили `dF_ext / dt` у момент первинного зіткнення.

## 4. Гібридне керування силою та положенням (Hybrid Force/Position Control)

У багатьох практичних завданнях (наприклад, проведення ультразвуковим щупом уздовж труби або закручування гвинта) рух не є однаковим за всіма осями: вздовж нормалі до поверхні необхідно точно підтримувати зусилля притискання `F_d`, а в дотичній площині — переміщувати інструмент за траєкторією `x_d` з нульовим опором.

Для цього простір завдань розщеплюється матрицею селекції `S`:

```text
S = diag(s_1, s_2, s_3, s_4, s_5, s_6),   де s_i in {0, 1}
```

Якщо вісь `Z` спрямована за нормаллю до поверхні, то `s_z = 1` (силовий підпростір), а `s_x = 0, s_y = 0` (позиційні підпростори).

Повний сигнал керування формується сумою двох неколінеарних проекцій:

```text
F_total = (I - S) · F_pos + S · F_force
```

де:
- `(I - S) · F_pos` — позиційна складова:
```text
F_pos = K_p · (x_d - x) + K_v · (x'_d - x')
```
- `S · F_force` — силова складова (ПІ-регулятор сили):
```text
F_force = F_d + K_fp · (F_d - F_ext) + K_fi · integral(F_d - F_ext) dt
```

Завдяки ортогональності проекцій `S · (I - S) = 0` силовий контур не бореться з позиційним: зміщення вздовж поверхні не створює хибних корекцій за нормаллю, а зусилля притискання підтримується сталим незалежно від кривини оброблюваної деталі.
