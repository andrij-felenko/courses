# 🧮 Точний розрахунок динаміки тяги, інерції коліс та межі зчеплення

Коли ровер масою 20 кг рушає на крутому підйомі з сипучим ґрунтом, спрощена статична формула «момент дорівнює силі тяги на радіус» дає збій: машина або зривається в пробуксовування, або мотор задихається на перших же мілісекундах розгону. Цей розрахунок розгортає повну динамічну модель руху колісного рушія: як обертова інерція ротора двигуна й редуктора перетворюється на еквівалентну додаткову масу, як нормальне навантаження перерозподіляється між осями на ухилі, і де проходить точна межа між зупинкою приводу від нестачі моменту та зривом коліс у юз через перевищення коефіцієнта зчеплення.

## Повний баланс сил на поздовжньому ухилі

Розглянемо ровер загальною масою `m`, що рухається вгору по похилій площині з кутом нахилу `θ` до горизонту з лінійним прискоренням `a` та поточною швидкістю `v`.

```
Повна маса машини:              m      [кг]
Кут нахилу поверхні:            θ      [рад або градуси]
Лінійне прискорення:            a      [м/с²]
Лінійна швидкість:              v      [м/с]
Радіус колеса під навантаженням: r      [м]
Кількість тягових коліс:        N_d    [одиниць]
Загальна кількість коліс:       N_w    [одиниць]
```

Гравітаційна сила ваги `W = m · g` діє вертикально вниз із центра мас. Розкладемо її на дві взаємно перпендикулярні складові відносно площини руху:

```
Нормальна складова сили ваги:
N_grav = m · g · cos(θ)

Скочувальна складова сили ваги:
F_slope = m · g · sin(θ)
```

Нормальна сила `N_grav` притискає колеса до ґрунту, формуючи реакцію опори `N`. Через непружну деформацію матеріалу шини та зминання поверхні точка прикладання сумарної нормальної реакції зміщується вперед на відстань плеча опору коченню `b`. Безрозмірний коефіцієнт опору коченню визначається як `C_rr = b / r`. Звідси сила опору коченню дорівнює:

```
F_rr = N_grav · (b / r)
     = C_rr · m · g · cos(θ)
```

Аеродинамічний опір середовища розраховується за класичною формулою лобового опору для щільності повітря `ρ` (приблизно `1.204 кг/м³` за нормальних умов), лобової площі `A` та коефіцієнта обтічності `C_d`:

```
F_aero = 0.5 · ρ · C_d · A · v²
```

Для типових роверів на швидкостях до `2 м/с` (`7.2 км/год`) і лобовій площі `0.15 м²` величина `F_aero` не перевищує `0.2–0.5 Н`, тому нею часто нехтують порівняно з гравітаційними й деформаційними силами в десятки й сотні ньютонів. Проте під час швидкісного руху легких платформ проти зустрічного вітру її необхідно додавати до загального балансу.

## Обертова інерція та коефіцієнт зведеної маси

Щоб розігнати платформу поступально з прискоренням `a`, двигун одночасно змушений розкручувати всі обертові компоненти трансмісії з відповідним кутовим прискоренням:
- колеса: `ε_w = a / r`;
- проміжні шестерні редуктора;
- ротор електродвигуна з передавальним числом `i`: `ε_m = i · ε_w = i · a / r`.

Запишемо повну кінетичну енергію системи `E_k`:

```
E_k = E_поступальна + E_обертання_коліс + E_обертання_роторів

E_k = 0.5 · m · v² + N_w · (0.5 · J_w · ω_w²) + N_d · (0.5 · J_m · ω_m²)
```

де `J_w` — момент інерції одного колеса (`кг·м²`), `J_m` — момент інерції ротора двигуна разом із первинним валом редуктора, `ω_w = v / r`, `ω_m = i · ω_w = i · v / r`.

Підставимо кутові швидкості через лінійну швидкість `v`:

```
E_k = 0.5 · m · v² + 0.5 · N_w · J_w · (v / r)² + 0.5 · N_d · J_m · (i · v / r)²
    = 0.5 · v² · [ m + N_w · J_w / r² + N_d · J_m · i² / r² ]
```

Вираз у квадратних дужках являє собою **еквівалентну динамічну масу** системи `m_eq`. Введемо безрозмірний коефіцієнт обертової інерції `δ_rot`:

```
δ_rot = 1 + (N_w · J_w) / (m · r²) + (N_d · J_m · i²) / (m · r²)
```

Зверніть увагу на член `i²`: інерція ротора двигуна множиться на **квадрат передавального числа**. У високоредукторних приводах (наприклад, `i = 50` чи `i = 100`) навіть крихітний ротор вагою 80 грамів створює еквівалентну поступальну інерцію, що може сягати 20–40% від повної ваги всього ровера.

Динамічна сила розгону з урахуванням обертання становить:

```
F_acc = m · δ_rot · a
```

## Повний тяговий баланс і крутний момент на колесі

Сумарна сила тяги `F_tract_total`, яку мають створити всі тягові колеса в плямах контакту з ґрунтом:

```
F_tract_total = F_rr + F_slope + F_aero + F_acc
              = C_rr · m · g · cos(θ) + m · g · sin(θ) + F_aero + m · δ_rot · a
```

За умови рівномірного розподілу тяги між `N_d` ведучими колесами, тягова сила на одному колесі:

```
F_wheel = F_tract_total / N_d
```

Необхідний крутний момент на осі одного колеса:

```
T_wheel = F_wheel · r
        = (r / N_d) · [ m · g · (C_rr · cos(θ) + sin(θ)) + m · δ_rot · a + F_aero ]
```

## Перерахунок моменту на вал двигуна через ККД редуктора

Редуктор підвищує момент у `i` разів, але зменшує його на величину механічних втрат на тертя в зубчастих зачепленнях та підшипниках (ККД `η_gb`). Якщо між редуктором і колесом є додаткова ремінна або ланцюгова передача з ККД `η_ext` та коефіцієнтом `i_ext`, сумарний ККД становить `η_total = η_gb · η_ext`, а загальне передавальне число — `i_total = i_gb · i_ext`.

```
Необхідний крутний момент на валу двигуна:
T_motor = T_wheel / (i_total · η_total)

Кутова швидкість вала двигуна:
ω_motor = (v / r) · i_total        [рад/с]

Оберти вала двигуна:
n_motor = (ω_motor · 60) / (2 · π) [об/хв, RPM]

Корисна механічна потужність на валу двигуна:
P_mech = T_motor · ω_motor = (T_wheel · ω_wheel) / η_total
```

## Межа зчеплення та максимальний кут подолання підйому

Привід може розвинути колосальний крутний момент завдяки великому `i`, проте максимальна сила, яку колесо здатне передати ґрунту без пробуксовування, жорстко обмежена законом сухого тертя Кулона:

```
F_grip_max = μ · N_i
```

де `μ` — коефіцієнт поздовжнього зчеплення колеса з поверхнею, `N_i` — нормальне навантаження, що припадає саме на дане ведуче колесо.

Максимальний момент, який можна прикласти до колеса без зриву в юз:

```
T_wheel_max = μ · N_i · r
```

Якщо `T_wheel > T_wheel_max`, колесо миттєво зривається в ковзання, витрачаючи енергію акумулятора на полірування ґрунту або закопування в пісок.

### Граничний кут підйому за умовою зчеплення

Для повнопривідного ровера (4WD / 6WD, де всі колеса тягові: `sum(N_i) = m · g · cos(θ)`), на сталій швидкості (`a = 0`, `F_aero ≈ 0`) умова руху без пробуксовування має вигляд:

```
F_tract_total ≤ μ · N_total

m · g · [ C_rr · cos(θ) + sin(θ) ] ≤ μ · m · g · cos(θ)
```

Скоротимо на `m · g` і поділимо обидві частини нерівності на `cos(θ)` (при `θ < 90°` `cos(θ) > 0`):

```
C_rr + tan(θ) ≤ μ

tan(θ_макс) = μ − C_rr

θ_макс = arctan(μ − C_rr)
```

Цей фундаментальний висновок показує: **граничний кут підйому ровера визначається виключно коефіцієнтом зчеплення та опором коченню**, а не потужністю моторів. Якщо на мокрій траві з глиною `μ = 0.40`, а `C_rr = 0.10`, то `tan(θ_макс) = 0.30`, що відповідає куту `θ_макс = arctan(0.30) ≈ 16.7°`. Навіть якщо встановити двигуни потужністю 10 кВт, на ухилі понад 17° повнопривідний ровер буде буксувати й скочуватися вниз.

### Випадок моноприводу (2WD)

Для задньопривідного ровера з часткою ваги на ведучій осі `k_axle = N_rear / N_total` (наприклад, `k_axle = 0.55` з урахуванням динамічного перетоку ваги):

```
F_tract_max = μ · (k_axle · m · g · cos(θ))

m · g · [ C_rr · cos(θ) + sin(θ) ] ≤ μ · k_axle · m · g · cos(θ)

tan(θ_макс_2wd) = μ · k_axle − C_rr

θ_макс_2wd = arctan(μ · k_axle − C_rr)
```

При `μ = 0.40`, `k_axle = 0.55` і `C_rr = 0.10`:
`tan(θ) = 0.40 · 0.55 − 0.10 = 0.22 − 0.10 = 0.12`, тобто `θ_макс_2wd ≈ 6.8°`. Монопривідна машина втрачає здатність лізти вгору більш ніж удвічі порівняно з повнопривідною.

## Числовий приклад розрахунку динамічного підйому

Розрахуємо параметри для чотириколісного повнопривідного ровера (4WD):
- Маса `m = 18.0 кг`;
- Радіус коліс `r = 0.08 м` (діаметр 160 мм);
- Момент інерції колеса `J_w = 0.0012 кг·м²`;
- Момент інерції ротора двигуна `J_m = 1.8 · 10⁻⁵ кг·м²`;
- Передавальне число `i = 40`, ККД редуктора `η_gb = 0.82`;
- Умови: розгін `a = 0.8 м/с²` до швидкості `v = 1.2 м/с` на підйомі `θ = 20°` по утрамбованому ґрунту з травою (`C_rr = 0.07`, `μ = 0.55`).

### 1. Розрахунок коефіцієнта зведеної інерції

```
δ_rot = 1 + (4 · 0.0012) / (18.0 · 0.08²) + (4 · 1.8·10⁻⁵ · 40²) / (18.0 · 0.08²)  [підстановка параметрів системи]
      = 1 + 0.0048 / 0.1152 + 0.1152 / 0.1152                                       [обчислення часток інерції]
      = 1 + 0.0417 + 1.0000                                                         [додавання інерції коліс і роторів]
      = 2.0417                                                                      [підсумок: зведена маса подвоєна]
```

Поступальна маса машини становить 18.0 кг, а еквівалентна динамічна маса через розкручування чотирьох роторів двигунів подвоюється: `m_eq = 18.0 · 2.0417 = 36.75 кг`!

### 2. Розрахунок сил

```
cos(20°) ≈ 0.9397
sin(20°) ≈ 0.3420

F_rr    = 0.07 · 18.0 · 9.81 · 0.9397 = 11.62 Н
F_slope = 18.0 · 9.81 · 0.3420        = 60.39 Н
F_acc   = 18.0 · 2.0417 · 0.8         = 29.40 Н
F_total = 11.62 + 60.39 + 29.40       = 101.41 Н
```

### 3. Момент на колесах і двигунах

```
T_total_wheel = 101.41 · 0.08 = 8.113 Н·м

На одне колесо (N_d = 4):
T_wheel = 8.113 / 4 = 2.028 Н·м

На вал одного двигуна:
T_motor = 2.028 / (40 · 0.82) = 2.028 / 32.8 = 0.0618 Н·м  (61.8 мН·м)
```

### 4. Оберти та механічна потужність

```
Кутова швидкість колеса:
ω_wheel = 1.2 / 0.08 = 15.0 рад/с  (≈ 143.2 RPM)

Кутова швидкість двигуна:
ω_motor = 15.0 · 40 = 600.0 рад/с  (≈ 5730 RPM)

Механічна потужність одного мотора:
P_mech = 0.0618 · 600.0 = 37.08 Вт

Сумарна механічна потужність чотирьох приводів:
P_total_mech = 4 · 37.08 = 148.3 Вт
```

### 5. Перевірка на пробуксовування

```
Нормальне навантаження на 1 колесо:
N_wheel = (18.0 · 9.81 · 0.9397) / 4 = 41.48 Н

Максимальна сила зчеплення 1 колеса:
F_grip = 0.55 · 41.48 = 22.81 Н

Фактична тягова сила на 1 колесі:
F_wheel = 101.41 / 4 = 25.35 Н
```

Оскільки `F_wheel (25.35 Н) > F_grip (22.81 Н)`, ровер **зірветься в пробуксовування** при спробі розгону з `a = 0.8 м/с²` на 20° схилі. Щоб зберегти зчеплення, максимальне прискорення розгону на цьому ухилі не повинно перевищувати:

```
F_acc_max = 4 · F_grip − F_rr − F_slope  [рівновага граничної сили тяги]
          = 4 · 22.81 − 11.62 − 60.39    [підстановка обчислених сил]
          = 91.24 − 72.01                [обчислення різниці тяги й опору]
          = 19.23 Н                      [максимальний залишок тяги на розгін]

a_max = F_acc_max / (m · δ_rot)
      = 19.23 / 36.75 ≈ 0.523 м/с²
```

Це демонструє, як повний динамічний розрахунок вберігає від проектування надто агресивних профілів розгону в системі керування ровером.
