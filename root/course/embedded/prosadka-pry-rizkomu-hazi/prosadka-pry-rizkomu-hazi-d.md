У момент, коли пілот або автопілот різко переводить важіль газу з режиму спокійного висіння (20 А сумарного струму) у 100% тяги для швидкого набору висоти чи виходу з пікірування, чотири безколекторні мотори дрона миттєво переходять у режим форсованого розгону. Обмотки нерухомих або повільно обертових роторів ще не генерують зустрічної електрорушійної сили (проти-ЕРС), тому їхній електричний опір визначається майже виключно активним опором мідного дроту статора (кілька десятків міліом). Сумарний струм силової шини підскакує від 20 А до 180–200 А за лічені 2–4 мілісекунди. 

Цей стрибок струму проходить крізь хімічне джерело живлення, силове розведення плати та кабельний джгут. На внутрішньому активному опорі літій-полімерного акумулятора та паразитній індуктивності проводів виникає різке падіння напруги: шина 6S-акумулятора з 25.2 В провалюється нижче 15–16 В, а індуктивні імпульси створюють високочастотні викиди амплітудою понад 35 В. Якщо вхідна напруга імпульсного або лінійного стабілізатора польотного контролера падає нижче його мінімального робочого порогу, вторинна цифрова лінія 3.3 В просідає. Вбудований апаратний супервізор мікроконтролера фіксує перетин порогу недопустимої напруги (Brown-out Reset, BOR) і миттєво скидає процесор у стан перезавантаження. Генерація сигналів керування моторами DShot припиняється, радіоприймач і відеопередавач втрачають зв'язок, а безконтрольний дрон падає на землю.

### Фізика та розрахунок динамічної просадки (Throttle Punch Sag)

Бортова силова мережа безпілотного апарата являє собою замкнене електричне коло з розподіленими паразитними параметрами. Джерелом енергії є хімічна акумуляторна батарея (найчастіше LiPo або Li-ion конфігурацій від 4S до 12S), що живить силове навантаження (електронні регулятори швидкості ESC та мотори BLDC) і чутливу електроніку (польотний контролер FC, давачі, радіоприймач та відеосистему).

![Схема бортової мережі та падіння напруги](/root/course/embedded/prosadka-pry-rizkomu-hazi/img/sag-mechanism.svg)
*Еквівалентна електрична схема бортової мережі дрона: падіння напруги на внутрішньому хімічному опорі батареї R_int, паразитних імпедансах джгута та роз'єму XT60 під час пікового навантаження 4 моторів.*

#### Еквівалентна схема джерела живлення

Акумуляторна батарея не є ідеальним джерелом напруги. Її можна представити як джерело ЕРС розімкненого кола `E_ocv` (англ. *Open Circuit Voltage*), послідовно з яким увімкнено комплексний внутрішній імпеданс `Z_int`. У режимі короткочасного імпульсного навантаження головний внесок у просадку роблять дві фізичні складові:

1. **Омічний опір електроліту та струмознімальних фольг (`R_ohm`):** чисто активний опір металевих контактів, мідних і алюмінієвих струмовідводів, контактного зварювання та питомий опір рідкого електроліту. Це безінерційна складова: падіння напруги на ній виникає синхронно зі наростанням струму.
2. **Опір переносу заряду на межі розділу фаз (`R_ct`, Charge Transfer Resistance):** електрохімічний бар'єр, що виникає при переході іонів літію крізь пасивуючу плівку (SEI, *Solid Electrolyte Interphase*) на поверхні графітового анода та катода. Разом із подвійним електричним шаром (ємність `C_dl`) цей вузол формує часову сталу порядку десятків мікросекунд.

Сумарний активний внутрішній опір свіжої якісної батареї 6S (ємністю 1300–1500 мА·год з паспортним C-рейтингом 100C–150C) становить від 3.5 до 4.5 мОм на одну комірку, що дає сумарний опір пакета:

```
R_int = 6 · 4.0 мОм = 24.0 мОм = 0.024 Ом
```

Якщо батарея охолоджена до температури +5 °C або нижче, рухливість іонів літію в електроліті різко падає, а товщина і в'язкість SEI зростають. У результаті `R_int` збільшується у 2–3 рази, досягаючи 50–70 мОм. Зношені акумулятори, що пройшли понад 80–100 циклів глибокого розряду, також деградують зі зростанням внутрішнього опору через руйнування кристалічної решітки катода.

#### Внесок джгутів, паяних з'єднань та роз'ємів

Між клемами акумулятора та силовими входами ESC перебувають:
- Силовий роз'єм (наприклад, AMASS XT60 або XT90): контактний опір нової пари контактів становить близько `R_xt60 = 0.8–1.2 мОм`. Під дією нагару від іскор при підключенні та вібрації цей опір може зростати до 2.5–4.0 мОм.
- Силовий силіконовий кабель AWG12 або AWG14 довжиною близько 10 см: активний опір мідної жили AWG12 становить приблизно 5.2 мОм/м, тобто для 20 см загальної довжини двох провідників `R_wire ≈ 1.0–1.2 мОм`.
- Власна паразитна індуктивність петлі силових проводів `L_wire`: два паралельних дроти довжиною 10 см з відстанню між осями 5 мм утворюють контур з індуктивністю приблизно `L_wire ≈ 60–90 нГн`.

Сумарний опір силового тракту постійному струму від хімічної реакції всередині банок до транзисторів ESC складає:

```
R_total = R_int + R_xt60 + R_wire
R_total = 24.0 мОм + 1.2 мОм + 1.2 мОм = 26.4 мОм = 0.0264 Ом
```

#### Розрахунок просадки напруги при ривку

При різкому відкритті ключів ESC мотори споживають сумарний піковий струм `I_peak = 180 А`. Швидкість наростання струму в перші мілісекунди обмежена лише індуктивністю фаз моторів та швидкістю розгону ШІМ-сигналу, досягаючи `di/dt = 180 А / 0.004 с = 45 000 А/с (45 А/мс)`.

Повна динамічна напруга на шині живлення в точці підключення електроніки `V_bus(t)` описується рівнянням:

```
V_bus(t) = E_ocv - I(t) · R_total - L_wire · (di/dt)
```

Проведемо покроковий розрахунок падіння напруги для повністю зарядженого акумулятора 6S (`E_ocv = 6 · 4.2 В = 25.2 В`):

```
ΔV_res = I_peak · R_total
= 180 А · 0.0264 Ом     [множимо піковий струм на сумарний опір]
= 4.75 В               [активне омічне падіння напруги]

ΔV_ind = L_wire · (di/dt)
= 80·10⁻⁹ Гн · 45 000 А/с  [множимо індуктивність на швидкість наростання]
= 0.0036 В = 3.6 мВ    [динамічне падіння на наростанні струму]
```

Проте на частоті комутації ключів ШІМ ESC (від 24 до 48 кГц) комутація кожної мікросекунди формує локальні фронти `di/dt` порядку `50 А / 100 нс = 5·10⁸ А/с`. На таких ультракоротких інтервалах навіть крихітна паразитна індуктивність джгута `80 нГн` генерує високочастотний зворотний індуктивний викид:

```
ΔV_spike = 80·10⁻⁹ Гн · 5·10⁸ А/с = 40.0 В
```

Таким чином, усереднена напруга батареї на клемах ESC просідає з 25.2 В до:

```
V_bus_min = 25.2 В - 4.75 В = 20.45 В   [для свіжої батареї 100% заряду]
```

Якщо ж цей самий маневр виконується на наполовину розрядженому або охолодженому акумуляторі, де початкова напруга становить `E_ocv = 6 · 3.7 В = 22.2 В`, а внутрішній опір піднявся до `R_int = 50 мОм` (`R_total = 52.4 мОм`), просадка досягає:

```
ΔV_res = 180 А · 0.0524 Ом = 9.43 В
V_bus_min = 22.2 В - 9.43 В = 12.77 В
```

Напруга силової шини 6S миттєво падає нижче рівня 4S-батареї, що накладається на високочастотні коливальні сплески від комутації MOSFET-транзисторів.

> 🔧 **Навіщо це.**
> Розрахунок `ΔV = I_peak · R_total` визначає нижню межу напруги, яку гарантовано має витримувати бортова схема перетворення живлення. Якщо ви встановлюєте важкі пропелери з великим кроком чи переходите на мотори з високим KV, піковий струм розгону зростає непропорційно швидко. Знання точного значення `R_total` дозволяє заздалегідь оцінити, чи вистачить запасу регулювання стабілізаторам контролера польоту при глибокому розряді акумулятора наприкінці місії.

### Анатомія катастрофи: Brown-out польотного контролера та периферії

Польотний контролер (FC) не живиться безпосередньо від напруги 25 В. Для роботи його обчислювальних ядер і давачів на платі розгорнуто каскад вторинних перетворювачів живлення.

![Осцилограма перехідного процесу при різкому газі](/root/course/embedded/prosadka-pry-rizkomu-hazi/img/voltage-current-transient.svg)
*Осцилограми перехідного процесу: стрибок струму моторів до 180 А провокує глибоку просадку напруги батареї, провал виходу BEC 5V та зниження шини 3.3V нижче порогу BOR, що призводить до апаратного скидання STM32.*

#### Каскадна структура бортового перетворення

Типова архітектура розподілу живлення польотного контролера складається з двох послідовних ступенів:

1. **Імпульсний понижувальний стабілізатор (Step-Down Buck BEC):** перетворює вхідну напругу батареї `V_bat` (від 12 до 25.2 В) на проміжну шину 5.0 В (або 9.0/10.0 В для живлення цифрових відеопередавачів DJI O3 / Walksnail). Типові мікросхеми BEC — Texas Instruments TPS54302, Monolithic Power Systems MP1584 або MP2459.
2. **Лінійний стабілізатор з малим падінням напруги (LDO, Low-Dropout Regulator):** перетворює стабільні 5.0 В на напругу 3.3 В для живлення ядра мікроконтролера (STM32F405, STM32F722, STM32H743), гіроскопа/акселерометра (BMI270, ICM-42688-P), магнітометра, барометра та мікросхеми Flash-пам'яті Blackbox.

Кожен із цих стабілізаторів має чіткі фізичні обмеження за мінімальною вхідною напругою та динамічною реакцією на зміну входу.

#### Механізм зриву стабілізації BEC та LDO

Імпульсний перетворювач Buck працює за принципом періодичного відкриття верхнього силового ключа на час `t_on = D · T_sw`, де `D = V_out / V_in` — коефіцієнт заповнення (duty cycle). В інтегрованих DC-DC конвертерах максимальний коефіцієнт заповнення обмежений схемотехнікою плаваючого драйвера затвора (Bootstrap circuit) і зазвичай не перевищує `D_max = 85–92%`.

Мінімальна вхідна напруга, за якої мікросхема ще здатна утримувати вихідні 5.0 В, визначається формулою:

```
V_in_min = (V_out + I_out · (R_dson + R_inductor)) / D_max
```

Для типового бортового BEC при навантаженні 2 А мінімальна напруга входу становить близько `6.2–6.8 В`. Крім того, мікросхеми перетворювачів мають вбудований захист від недостатньої напруги (UVLO, *Under-Voltage Lockout*), який примусово вимикає генерацію ШІМ, якщо вхідна напруга провалюється нижче встановленого порогу (зазвичай 4.5–5.5 В) навіть на час у 5–10 мікросекунд.

Якщо силова напруга батареї під час ривка газу з високою амплітудою пульсацій провалюється нижче порогу UVLO або заходить у зону dropout імпульсного стабілізатора, шина 5.0 В починає стрімко падати слідом за входом:

```
V_5V(t) ≈ V_bat(t) - V_drop_bec
```

Як тільки напруга шини 5.0 В падає нижче `3.6–3.5 В`, вичерпується запас регулювання (Dropout Voltage `V_do ≈ 200–300 мВ`) лінійного стабілізатора LDO 3.3 В. Напруга живлення мікроконтролера `V_DD` провалюється нижче номінальних 3.3 В.

#### Спрацьовування апаратного Brown-out Reset (BOR)

Усередині мікроконтролерів STM32 інтегровано прецизійний апаратний супервізор напруги живлення — схему скидання при зниженні напруги (Brown-out Reset, BOR). Його призначення — захистити внутрішню Flash-пам'ять і комірки SRAM від спотворення даних, яке неминуче виникає, коли логічні рівні КМОН-транзисторів втрачають чіткість через нестачу напруги живлення ядра.

Рівень спрацьовування BOR задається на етапі прошивки в байтах конфігурації (Flash Option Bytes, біти `BOR_LEV[1:0]`):
- **BOR Level 0 (Reset):** поріг POR/PDR близько `1.7–1.8 В` (небезпечний режим: на 168–480 МГц пам'ять збоїть раніше, ніж спрацює скидання);
- **BOR Level 1:** поріг відключення `2.1–2.4 В`;
- **BOR Level 2:** поріг відключення `2.4–2.7 В`;
- **BOR Level 3:** поріг відключення `2.7–2.9 В` (типовий заводський стан більшості плат польотних контролерів).

```
┌─────────────────────────────────────────────────────────────────────────┐
│              Хронологія аварійного перезапуску MCU                      │
├───────────┬─────────────────────────────────────────────────────────────┤
│ t = 0.0 мс│ Ривок газу 100%. Струм = 180 А. Напруга V_bat просідає.     │
│ t = 2.5 мс│ Шина 5V провалюється до 3.2 В. LDO 3.3V виходить з режиму.  │
│ t = 2.8 мс│ Напруга ядра V_DD падає до 2.68 В (< BOR Level 3 = 2.70 В). │
│ t = 2.81мс│ Апаратний супервізор опускає внутрішню лінію NRST в лог. 0. │
│           │ Процесор негайно зупиняє виконання коду.                    │
│ t = 3.0 мс│ Генерація таймерів ШІМ / DShot переривається.               │
│           │ ESC втрачають пакети й блокують силові ключі.               │
│ t = 15.0мс│ Напруга батареї відновлюється (струм спав, бо мотори стали).│
│ t = 20.0мс│ V_DD повертається до 3.3 В. Супервізор знімає сигнал NRST.  │
│ t = 22.0мс│ Старт Bootloader, скидання стеків, реініціалізація RCC/PLL. │
│ t = 75.0мс│ Ініціалізація шин SPI/I2C, калібрування гіроскопа BMI270.   │
│ t = 250 мс│ Відновлення радіопротоколу ELRS/CRSF. Дрон уже в падінні.   │
└───────────┴─────────────────────────────────────────────────────────────┘
```

Мікроконтролер не може миттєво продовжити керування після зняття сигналу скидання. Відбувається повний холодний перезапуск прошивки (System Reset):
1. Тактовий генератор повертається на внутрішнє RC-джерело HSI 16 МГц, після чого заново ініціалізується фазове автопідлаштування частоти (PLL) до 168–480 МГц.
2. Прошивка заново конфігурує порти введення-виведення, DMA-канали й таймери.
3. Процедура ініціалізації IMU-давача (гіроскопа) вимагає зчитування регістрів через SPI та перевірки нерухомості для скидання інтегратора дрейфу нуля. Оскільки дрон у цей момент хаотично обертається й падає, гіроскоп видає помилку калібрування, блокуючи переведення системи в стан `ARMED`.

#### Втрата радіокерування, відеозв'язку та ефект Ground Bounce

Окрім процесора польотного контролера, від просадки страждають інші вузли дрона:

- **Приймачі радіокерування (ExpressLRS, TBS Crossfire):** працюють на базі мікроконтролерів ESP8285 або STM32 та радіочипів SX1280. Короткочасне знеструмлення перезавантажує приймач, що викликає розрив сесії телеметрії на 200–500 мс до завершення повторного пошуку каналу (FHSS Sync).
- **Цифрові відеопередавачі (VTX):** споживають від 8 до 15 Вт потужності. Провал вхідної напруги нижче 7–9 В призводить до аварійного перезавантаження відеопроцесора. Відновлення відеопотоку в окулярах пілота триває від 4 до 12 секунд.
- **Зсув потенціалу нульової шини (Ground Bounce):** коли зворотний силовий струм 180 А протікає по тонкому шару міді полігону заземлення друкованої плати, закон Ома створює різницю потенціалів між мінусовим виводом ESC та мінусовим виводом польотного контролера:

```
ΔV_gnd = I_peak · R_gnd_pcb = 180 А · 0.003 Ом = 0.54 В
```

Потенціал логічної землі контролера польоту підскакує на 0.54 В відносно землі ESC. Для сигналу DShot300/DShot600 з амплітудою 3.3 В рівень логічного нуля стає рівним `0.54 В` замість `0 В`. Запас завадостійкості зменшується, пакети спотворюються помилками CRC, викликаючи раптові розсинхронізації моторів (Motor Desync).

### Силова фільтрація: Low-ESR конденсатори та TVS-діоди

Керамічні конденсатори поверхневого монтажу (SMD MLCC ємністю 10–22 мкФ типорозмірів 0805 чи 1206), які виробники встановлюють безпосередньо на платах регуляторів 4-in-1 ESC, мають критичний фізичний недолік — сильний ефект діелектричного насичення під дією постійної напруги зміщення (DC Bias Effect). Під напругою 24 В керамічний діелектрик X7R/X5R втрачає до 60–75% своєї номінальної ємності: конденсатор на 22 мкФ реально перетворюється на елемент ємністю 5–7 мкФ.

Крім того, загального запасу енергії керамічних конденсаторів (`E = 0.5 · C · V²`) вистачає лише на фільтрацію частот від 500 кГц до десятків мегагерц. Вони не здатні компенсувати просідання струму на часових інтервалах у кілька мікросекунд, де потрібна ємність у сотні й тисячі мікрофарад.

![Вплив силового Low-ESR конденсатора на пульсації та індуктивні викиди](/root/course/embedded/prosadka-pry-rizkomu-hazi/img/capacitor-esr-ripple.svg)
*Порівняння пульсацій живлення: без додаткової фільтрації виникають небезпечні індуктивні викиди амплітудою понад 35 В; встановлення Low-ESR конденсатора 1000 мкФ з TVS-діодом знижує пульсації до безпечних 0.4 В.*

#### Фізика силових електролітичних конденсаторів з низьким ESR

Для силової шини живлення застосовують алюмінієві електролітичні конденсатори радіального типу спеціалізованих серій з ультранизьким еквівалентним послідовним опором (Low-ESR) — наприклад, Rubycon ZLH / ZLS, Panasonic FM / FR, Nichicon UHW.

Еквівалентна схема реального конденсатора містить три ключові параметри:
1. Номінальна ємність `C` (зазвичай 470–1000 мкФ на напругу 35 В для 6S-систем або 50 В для 8S-систем).
2. Еквівалентний послідовний опір `ESR` (Equivalent Series Resistance): визначається питомим опором рідкого електроліту, паперового сепаратора та алюмінієвої оксидної плівки. У якісних Low-ESR конденсаторів `ESR = 10–15 мОм` на частоті 100 кГц (проти 150–400 мОм у звичайних побутових конденсаторів загального призначення).
3. Еквівалентна послідовна індуктивність `ESL` (Equivalent Series Inductance): індуктивність виводів та згорнутої в рулон алюмінієвої стрічки (зазвичай 5–15 нГн).

Чому стандартний конденсатор вибухає на дроні? Струм пульсацій комутації ШІМ регуляторів моторів (Ripple Current), що проходить крізь конденсатор, досягає діючого значення `I_rms = 15–25 А`. На внутрішньому опорі `ESR` виділяється активна потужність у вигляді тепла:

```
P_loss = I_rms² · ESR
```

Порівняємо два конденсатори однакової ємності 1000 мкФ:

```
P_стандартний = (20 А)² · 0.250 Ом = 100 Вт   [миттєве закипання електроліту й вибух]
P_Low_ESR     = (20 А)² · 0.012 Ом = 4.8 Вт    [допустимий нагрів у потоці повітря від гвинтів]
```

#### Розрахунок необхідної ємності буферного конденсатора

Конденсатор на силових клемах повинен утримувати напругу шини `V_bus` протягом часу `Δt_lag`, поки струм у довгих силових кабелях наростає під дією їхньої індуктивності `L_wire`:

```
Δt_lag = L_wire · I_peak / (E_ocv - V_bus_target)
```

Необхідна мінімальна ємність розраховується з допустимого провалу напруги `ΔV_allow` (наприклад, не більше 3.0 В):

```
C_bulk ≥ (I_peak · Δt_lag) / ΔV_allow
```

Розглянемо числовий приклад розрахунку:

```
Δt_lag = (80·10⁻⁹ Гн · 180 А) / (25.2 В - 22.0 В)
= 14.4·10⁻⁶ / 3.2
= 4.5·10⁻⁶ с = 4.5 мкс    [час відставання струму в індуктивності проводів]

C_min = (180 А · 4.5·10⁻⁶ с) / 3.0 В
= 810·10⁻⁶ Ф = 810 мкФ    [потрібна ємність для компенсації індуктивного відставання]
```

Отримане значення показує, чому ємність **1000 мкФ** є інженерним стандартом для 5-дюймових 6S-дронів. Встановлення меншої ємності (наприклад, 220–330 мкФ) залишає часове «вікно» провалу напруги тривалістю 2–3 мкс, що достатньо для скидання чутливого LDO-стабілізатора.

#### Захист від рекуперативних викидів: TVS-діоди

Сучасні регулятори швидкості використовують режим активного рекуперативного гальмування (*Damped Light* або комплементарний ШІМ). Коли мотор повинен швидко зменшити оберти, транзистори ESC замикають обмотки так, що магнітна енергія статора через зворотні діоди MOSFET скидається назад у шину живлення.

Якщо в цей момент акумулятор частково від'єднано або силові дроти мають помітну індуктивність, рекуперативний струм заряджає паразитні ємності, викликаючи різкий високовольтний сплеск напруги амплітудою до 35–45 В тривалістю від 10 до 500 мкс. Цей сплеск пробиває затвори польових транзисторів і випалює вхідні каскади BEC.

Для придушення таких викидів паралельно конденсатору встановлюють напівпровідниковий обмежувач напруги — **TVS-діод** (Transient Voltage Suppressor, супресор):

```
                               ┌──────┐
               +V_bat ─────────┤ TVS  ├───────── GND
                               └──────┘
               (Катод до плюса, Анод до мінуса)
```

Параметри вибору TVS-діода для мережі 6S LiPo (максимальна напруга 25.2 В):
1. **Робоча напруга відсічки (`V_RWM`, Reverse Standoff Voltage):** напруга, за якої діод повністю закритий і струм витоку не перевищує кількох мікроампер. Повинна бути вищою за максимальну напругу батареї: `V_RWM ≥ 26.0 В` (для 6S обирають діоди на 26 В або 28 В, наприклад серію `SMBJ28A`).
2. **Напруга пробою (`V_BR`, Breakdown Voltage):** напруга, за якої діод починає лавинно відкриватися і проводити струм (для SMBJ28A `V_BR = 31.1–34.4 В`).
3. **Максимальна напруга обмеження (`V_C`, Clamping Voltage):** максимальна напруга на діоді при протіканні пікового струму перенапруги (для SMBJ28A `V_C ≈ 45.4 В` при струмі 13 А).

TVS-діод зрізає ультракороткі наносекундні та мікросекундні піки, які електролітичний конденсатор не встигає поглинути через власну паразитну індуктивність виводів `ESL`.

### Програмні методи: Throttle Slew Rate Limit та компенсація просадки

Апаратний захист конденсаторами та діодами обов'язково повинен доповнюватися алгоритмічним контролем у прошивці польотного контролера (Betaflight, INAV, ArduPilot, PX4).

![Програмне обмеження швидкості газу](/root/course/embedded/prosadka-pry-rizkomu-hazi/img/slew-rate-control.svg)
*Порівняння динаміки перехідного процесу: миттєвий стрибок газу створює небезпечний сплеск струму та просадку; введення обмеження швидкості наростання (Slew Rate 30 мс) усуває пік без відчутної для пілота затримки тяги.*

#### Фізична невідповідність механіки та електрики

Ротор безколекторного мотора з пропелером має момент інерції `J`. При миттєвому стрибку завдання газу від 0% до 100% ротор механічно не може розігнатися швидше за 30–60 мс через закони механіки:

```
M_acc = J · (dω/dt) = k_t · I - M_drag(ω)
```

Подача повного шпаруватості ШІМ (100%) на мотор, що обертається повільно, створює максимальний струм короткого замикання обмоток, який генерує виключно теплові втрати `I²·R_stator` і просадку напруги батареї, але не створює додаткової динамічної тяги в перші 10 мс.

#### Алгоритм обмеження швидкості наростання газу (Slew Rate Limit)

Для усунення марного струмового удару в контур керування вводиться обмежувач швидкості зміни сигналу газу (Slew Rate Limiter):

```
u_target[k] = Throttle_Input[k]
Δu = u_target[k] - u_filtered[k-1]

Якщо Δu > Δu_max:
    u_filtered[k] = u_filtered[k-1] + Δu_max
Інакше, якщо Δu < -Δu_max:
    u_filtered[k] = u_filtered[k-1] - Δu_max
Інакше:
    u_filtered[k] = u_target[k]
```

Де величина `Δu_max` розраховується з періоду виклику циклу ПІД-регулятора `T_loop` (наприклад, для частоти 8 кГц `T_loop = 125 мкс`) та заданого часу повного рампу `T_ramp` (від 25 до 40 мс):

```
Δu_max = (100% / T_ramp) · T_loop
Δu_max = (1.0 / 0.030 с) · 0.000125 с = 0.00416 (0.416% за такт)
```

Введення рампу тривалістю 30 мс зменшує величину `di/dt` майже в 10 разів, зрізаючи піковий струм перехідного процесу зі 180 А до 95–100 А. Для пілота затримка у 30 мс знаходиться нижче порогу відчуття (час реакції людини становить 150–200 мс), але бортова мережа повністю позбавляється ризику падіння нижче порогу Brown-out.

#### Динамічне масштабування ПІД-коефіцієнтів (Battery Sag Compensation)

Зі зниженням напруги батареї зменшується коефіцієнт підсилення силової установки (ефективність тяги на 1% газу падає пропорційно `V_bat`). Це змушує ПІД-регулятор збільшувати інтегральну та диференціальну складові, що при різких маневрах призводить до перевирегулювання (Overshoot) і додаткових струмових ударів.

У сучасних польотних контролерах реалізовано алгоритм компенсації просадки напруги в реальному часі:

```
V_nominal = 4.0 В · S_cells
V_measured = LowPassFilter(ADC_Vbat, f_cutoff = 20 Гц)
K_comp = V_nominal / clamp(V_measured, V_min_safe, V_max)

Throttle_Compensated = Throttle_PID · K_comp
```

Коли напруга просідає, алгоритм плавно коригує відгук моторів, не дозволяючи контуру Feedforward створювати надмірні імпульси струму.

### Симулятор просадки напруги та перевірки Brown-out на C та C++

Для перевірки стійкості бортової електромережі та тестування параметрів фільтрації розроблено чисельний симулятор перехідного процесу. Програма дискретно моделює акумулятор, еквівалентний імпеданс джгута, динаміку заряду буферного конденсатора, стабілізатор BEC 5V, LDO 3.3V та стан супервізора STM32 BOR.

:::tabs
```c
#include <stdio.h>
#include <stdbool.h>
#include <math.h>

#define SIM_TIME_SEC       0.050f   /* Час симуляції 50 мс */
#define SIM_DT_SEC         0.00001f /* Крок інтегрування 10 мкс */

/* Параметри джерела живлення LiPo 6S */
#define BAT_CELLS          6
#define BAT_OCV_PER_CELL   4.10f    /* Початковий заряд на банку, В */
#define BAT_R_INT_OHM      0.024f   /* 24 мОм внутрішній опір батареї */

/* Параметри силового джгута та роз'єму */
#define WIRE_R_OHM         0.003f   /* 3 мОм опір дротів і XT60 */
#define WIRE_L_HENRY       80e-9f   /* 80 нГн індуктивність джгута */

/* Параметри Low-ESR конденсатора */
#define CAP_C_FARAD        1000e-6f /* 1000 мкФ */
#define CAP_ESR_OHM        0.012f   /* 12 мОм */

/* Параметри вторинних стабілізаторів польотного контролера */
#define BEC_TARGET_V       5.00f    /* Цільова напруга BEC 5V */
#define BEC_DROPOUT_V      1.40f    /* Мінімальне падіння напруги Buck */
#define BEC_UVLO_V         6.00f    /* Поріг відсічки UVLO BEC */

#define LDO_TARGET_V       3.30f    /* Цільова напруга ядра 3.3V */
#define LDO_DROPOUT_V      0.25f    /* Падіння напруги LDO */

/* Поріг супервізора STM32 BOR Level 3 */
#define STM32_BOR_THRESH_V 2.70f

typedef struct {
    float v_ocv;
    float r_total;
    float l_wire;
    float cap_c;
    float cap_esr;
    float v_cap;       /* Напруга безпосередньо на ємності */
    float i_wire;      /* Струм через силовий джгут */
} PowerBus;

typedef struct {
    float v_5v;
    float v_3v3;
    bool  in_brownout;
    float brownout_time_ms;
} FlightControllerPower;

static void power_bus_init(PowerBus *bus, float ocv, float r_int, float r_wire, 
                           float l_wire, float c_farad, float esr) {
    bus->v_ocv = ocv;
    bus->r_total = r_int + r_wire;
    bus->l_wire = l_wire;
    bus->cap_c = c_farad;
    bus->cap_esr = esr;
    bus->v_cap = ocv;
    bus->i_wire = 0.0f;
}

static void simulate_step(PowerBus *bus, FlightControllerPower *fc, 
                          float i_load, float dt) {
    /* 1. Струм через внутрішній конденсатор і напруга на шині */
    /* V_bus = v_cap + i_cap * cap_esr */
    /* i_wire = (v_ocv - v_bus - i_wire * r_total) / l_wire (динаміка індуктивності) */
    
    float v_bus_est = bus->v_cap + (bus->i_wire - i_load) * bus->cap_esr;
    float di_wire = ((bus->v_ocv - v_bus_est - bus->i_wire * bus->r_total) / bus->l_wire) * dt;
    bus->i_wire += di_wire;
    if (bus->i_wire < 0.0f) bus->i_wire = 0.0f;

    float i_cap = bus->i_wire - i_load;
    bus->v_cap += (i_cap / bus->cap_c) * dt;
    float v_bus = bus->v_cap + i_cap * bus->cap_esr;

    /* 2. Модель стабілізатора Buck BEC 5.0V */
    if (v_bus < BEC_UVLO_V) {
        fc->v_5v = 0.0f; /* UVLO відсічка */
    } else if (v_bus < (BEC_TARGET_V + BEC_DROPOUT_V)) {
        fc->v_5v = v_bus - BEC_DROPOUT_V;
    } else {
        fc->v_5v = BEC_TARGET_V;
    }

    /* 3. Модель лінійного стабілізатора LDO 3.3V */
    if (fc->v_5v < (LDO_TARGET_V + LDO_DROPOUT_V)) {
        fc->v_3v3 = fc->v_5v - LDO_DROPOUT_V;
        if (fc->v_3v3 < 0.0f) fc->v_3v3 = 0.0f;
    } else {
        fc->v_3v3 = LDO_TARGET_V;
    }

    /* 4. Стан супервізора STM32 Brown-Out Reset (BOR) */
    if (fc->v_3v3 < STM32_BOR_THRESH_V) {
        if (!fc->in_brownout) {
            fc->in_brownout = true;
            fc->brownout_time_ms = 0.0f;
        }
        fc->brownout_time_ms += dt * 1000.0f;
    } else {
        fc->in_brownout = false;
    }
}

int main(void) {
    PowerBus bus;
    FlightControllerPower fc = {0};
    
    float ocv = BAT_CELLS * BAT_OCV_PER_CELL;
    power_bus_init(&bus, ocv, BAT_R_INT_OHM, WIRE_R_OHM, 
                   WIRE_L_HENRY, CAP_C_FARAD, CAP_ESR_OHM);

    printf("=== Симуляція просадки напруги при ривку газу (C) ===\n");
    printf("Початкова напруга 6S: %.2f В, R_int: %.1f мОм, Cap: %.0f мкФ\n\n",
           ocv, BAT_R_INT_OHM * 1000.0f, CAP_C_FARAD * 1e6f);
    printf("Час(мс) | Струм(А) | V_bat(В) | BEC(В) | MCU(В) | Стан BOR\n");
    printf("-----------------------------------------------------------\n");

    bool brownout_detected = false;
    float max_sag_v = ocv;

    for (float t = 0.0f; t <= SIM_TIME_SEC; t += SIM_DT_SEC) {
        /* Профіль струму: ривок на t = 5 мс від 15 А до 180 А за 3 мс */
        float i_load = 15.0f;
        if (t >= 0.005f && t < 0.008f) {
            float ramp = (t - 0.005f) / 0.003f;
            i_load = 15.0f + ramp * (180.0f - 15.0f);
        } else if (t >= 0.008f && t < 0.030f) {
            i_load = 180.0f;
        } else if (t >= 0.030f) {
            i_load = 60.0f; /* Вихід на стабільну тягу */
        }

        simulate_step(&bus, &fc, i_load, SIM_DT_SEC);

        float v_bus_now = bus.v_cap;
        if (v_bus_now < max_sag_v) {
            max_sag_v = v_bus_now;
        }

        if (fc.in_brownout) {
            brownout_detected = true;
        }

        /* Вивід зразків кожні 5 мс */
        int step_idx = (int)(t / SIM_DT_SEC);
        if (step_idx % 500 == 0) {
            printf("%6.1f  | %7.1f  | %7.2f  | %5.2f  | %5.2f  | %s\n",
                   t * 1000.0f, i_load, v_bus_now, fc.v_5v, fc.v_3v3,
                   fc.in_brownout ? "FAIL (RESET!)" : "OK (Норма)");
        }
    }

    printf("-----------------------------------------------------------\n");
    printf("Результат: Мін. напруга батареї: %.2f В. Аварійний BOR: %s\n",
           max_sag_v, brownout_detected ? "СПРАЦЮВАВ (АВАРІЯ)" : "НЕ ВИЯВЛЕНО");

    return 0;
}
```

```cpp
#include <iostream>
#include <iomanip>
#include <vector>
#include <string_view>
#include <algorithm>
#include <cstdint>

struct PowerProfileConfig {
    uint8_t cells{6};
    float cell_ocv{4.10f};       // В
    float r_int{0.024f};          // 24 мОм
    float r_wire{0.003f};         // 3 мОм
    float l_wire{80e-9f};         // 80 нГн
    float c_bulk{1000e-6f};       // 1000 мкФ
    float cap_esr{0.012f};        // 12 мОм
};

struct RegulatorSpec {
    float bec_target_v{5.00f};
    float bec_dropout_v{1.40f};
    float bec_uvlo_v{6.00f};
    float ldo_target_v{3.30f};
    float ldo_dropout_v{0.25f};
    float stm32_bor_thresh_v{2.70f};
};

enum class BorSupervisorState {
    NormalOperation,
    ResetTriggered
};

class PowerNetworkSimulator {
public:
    explicit PowerNetworkSimulator(const PowerProfileConfig& cfg, 
                                   const RegulatorSpec& spec)
        : config_(cfg), spec_(spec),
          v_ocv_(cfg.cells * cfg.cell_ocv),
          r_total_(cfg.r_int + cfg.r_wire),
          v_cap_(v_ocv_),
          i_wire_(0.0f) {}

    struct StepResult {
        float time_ms;
        float load_current_a;
        float bus_voltage_v;
        float bec_voltage_v;
        float mcu_voltage_v;
        BorSupervisorState bor_state;
    };

    StepResult advance(float load_current, float dt_sec, float current_time_sec) {
        // Динаміка RLC силової шини
        float v_bus_approx = v_cap_ + (i_wire_ - load_current) * config_.cap_esr;
        float di_wire = ((v_ocv_ - v_bus_approx - i_wire_ * r_total_) / config_.l_wire) * dt_sec;
        i_wire_ = std::max(0.0f, i_wire_ + di_wire);

        float i_cap = i_wire_ - load_current;
        v_cap_ += (i_cap / config_.c_bulk) * dt_sec;
        float v_bus = v_cap_ + i_cap * config_.cap_esr;

        // Поведінка імпульсного регулятора Buck BEC 5V
        float v_5v = 0.0f;
        if (v_bus >= spec_.bec_uvlo_v) {
            v_5v = (v_bus < spec_.bec_target_v + spec_.bec_dropout_v) 
                   ? (v_bus - spec_.bec_dropout_v) 
                   : spec_.bec_target_v;
        }

        // Поведінка лінійного LDO 3.3V
        float v_3v3 = (v_5v < spec_.ldo_target_v + spec_.ldo_dropout_v)
                      ? std::max(0.0f, v_5v - spec_.ldo_dropout_v)
                      : spec_.ldo_target_v;

        // Апаратний стан супервізора BOR
        auto state = (v_3v3 < spec_.stm32_bor_thresh_v) 
                     ? BorSupervisorState::ResetTriggered 
                     : BorSupervisorState::NormalOperation;

        return StepResult{
            .time_ms = current_time_sec * 1000.0f,
            .load_current_a = load_current,
            .bus_voltage_v = v_bus,
            .bec_voltage_v = v_5v,
            .mcu_voltage_v = v_3v3,
            .bor_state = state
        };
    }

private:
    PowerProfileConfig config_;
    RegulatorSpec spec_;
    float v_ocv_;
    float r_total_;
    float v_cap_;
    float i_wire_;
};

int main() {
    PowerProfileConfig cfg;
    RegulatorSpec spec;
    PowerNetworkSimulator simulator(cfg, spec);

    constexpr float dt = 0.00001f;      // 10 мкс крок
    constexpr float t_end = 0.050f;     // 50 мс симуляції

    std::cout << "=== Симулятор перехідних процесів бортової мережі (C++20) ===\n";
    std::cout << "Конфігурація: 6S LiPo, 1000 мкФ Low-ESR, поріг BOR = 2.70 В\n\n";
    std::cout << std::left << std::setw(9)  << "Час(мс)" 
              << std::setw(11) << "Струм(А)" 
              << std::setw(11) << "V_bat(В)" 
              << std::setw(9)  << "BEC(В)" 
              << std::setw(9)  << "MCU(В)" 
              << "Стан супервізора BOR\n";
    std::cout << std::string(60, '-') << "\n";

    bool was_reset = false;
    float min_battery_v = cfg.cells * cfg.cell_ocv;

    for (float t = 0.0f; t <= t_end; t += dt) {
        float i_load = 15.0f;
        if (t >= 0.005f && t < 0.008f) {
            float ramp = (t - 0.005f) / 0.003f;
            i_load = 15.0f + ramp * (180.0f - 15.0f);
        } else if (t >= 0.008f && t < 0.030f) {
            i_load = 180.0f;
        } else if (t >= 0.030f) {
            i_load = 60.0f;
        }

        auto res = simulator.advance(i_load, dt, t);
        min_battery_v = std::min(min_battery_v, res.bus_voltage_v);

        if (res.bor_state == BorSupervisorState::ResetTriggered) {
            was_reset = true;
        }

        auto step_idx = static_cast<int>(t / dt);
        if (step_idx % 500 == 0) {
            std::cout << std::fixed << std::setprecision(2)
                      << std::setw(9)  << res.time_ms
                      << std::setw(11) << res.load_current_a
                      << std::setw(11) << res.bus_voltage_v
                      << std::setw(9)  << res.bec_voltage_v
                      << std::setw(9)  << res.mcu_voltage_v
                      << (res.bor_state == BorSupervisorState::ResetTriggered 
                          ? "RESET (Brown-out!)" 
                          : "OK (Норма)") << "\n";
        }
    }

    std::cout << std::string(60, '-') << "\n";
    std::cout << "Аналіз: Мінімальна напруга: " << min_battery_v << " В. "
              << "Підсумок: " << (was_reset ? "АВАРІЯ (BOR RESET)" : "БЕЗПЕЧНО") << "\n";

    return 0;
}
```
