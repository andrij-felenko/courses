# 🧮 Математична модель часу в ефірі та розрахунок заряду транзакції

Час перебування пакета в ефірі (Time on Air, ToA) та інтегральний електричний заряд, вилучений із хімічного джерела живлення під час радіотранзакції, підпорядковуються строгим аналітичним залежностям. Цей математичний апарат дозволяє розрахувати тривалість передачі для модуляцій LoRa (Chirp Spread Spectrum) та FSK, оцінити сумарний заряд у кулонах або міліампер-годинах і точно спрогнозувати термін автономної служби батареї з урахуванням струму спокою та саморозряду.

## Аналітична модель тривалості кадру LoRa (Time on Air)

Модуляція LoRa кодує інформацію лінійними частотно-модульованими імпульсами (чірпами). Базовим квантом передачі є тривалість одного символу `T_sym`. Оскільки кожен символ кодує `SF` бітів інформації (де `SF` — коефіцієнт розширення спектра, Spreading Factor, ціле число від 7 до 12), один символ складається з `2^SF` чіпів.

Тривалість символу залежить виключно від ширини смуги пропускання `BW` (Гц) та коефіцієнта `SF`:

```
T_sym = 2^SF / BW     [тривалість передачі одного символу LoRa]
```

**Приклад залежності T_sym від SF при ширині смуги BW = 125 кГц:**

```
SF7:   T_sym = 2⁷  / 125000 = 128  / 125000 = 0.001024 с = 1.024 мс
SF8:   T_sym = 2⁸  / 125000 = 256  / 125000 = 0.002048 с = 2.048 мс
SF9:   T_sym = 2⁹  / 125000 = 512  / 125000 = 0.004096 с = 4.096 мс
SF10:  T_sym = 2¹⁰ / 125000 = 1024 / 125000 = 0.008192 с = 8.192 мс
SF11:  T_sym = 2¹¹ / 125000 = 2048 / 125000 = 0.016384 с = 16.384 мс
SF12:  T_sym = 2¹² / 125000 = 4096 / 125000 = 0.032768 с = 32.768 мс
```

Повний час у ефірі складається з тривалості преамбули `t_preamble` та тривалості передачі корисного навантаження `t_payload`:

```
ToA = t_preamble + t_payload     [повний час у ефірі]
```

### 1. Тривалість преамбули

Преамбула містить `N_preamble` програмованих символів синхронізації (стандартно 8 символів у LoRaWAN) плюс 4.25 символа службової синхронізації кадру (Sync Word та частотний трекінг):

```
t_preamble = (N_preamble + 4.25) · T_sym     [тривалість преамбули]
```

Для `N_preamble = 8` при `SF7` (BW = 125 кГц):

```
t_preamble = (8 + 4.25) · 1.024 мс = 12.25 · 1.024 мс = 12.544 мс
```

Для `N_preamble = 8` при `SF12` (BW = 125 кГц):

```
t_preamble = (8 + 4.25) · 32.768 мс = 12.25 · 32.768 мс = 401.408 мс
```

### 2. Кількість символів та тривалість корисного навантаження

Кількість символів корисного навантаження `N_payload` визначається розміром пакета `PL` (байти), параметрами прямої корекції помилок (Forward Error Correction, FEC), наявністю заголовка (Header) та апаратного контролю надлишковості (CRC).

Формула кількості символів LoRa:

```
N_payload = 8 + max(ceil((8·PL - 4·SF + 28 + 16·CRC - 20·IH) / (4·(SF - 2·DE))) · (CR + 4), 0)
```

Параметри формули:
- `PL` — довжина корисного навантаження в байтах (1..255).
- `SF` — коефіцієнт розширення спектра (7..12).
- `CRC` — наявність контрольної суми CRC у кадрі: `CRC = 1` (увімкнено, стандартно для аплінків), `CRC = 0` (вимкнено, для низхідних кадрів шлюзу).
- `IH` — прапорець неявного заголовка (Implicit Header): `IH = 0` (явний заголовок Explicit Header, стандарт), `IH = 1` (фіксована довжина без заголовка).
- `DE` — оптимізація низької швидкості (Low Data Rate Optimization): `DE = 1`, якщо тривалість символу `T_sym > 16 мс` (обов'язково для SF11 та SF12 при BW = 125 кГц для компенсації температурного дрейфу кварцу), інакше `DE = 0`.
- `CR` — швидкість кодування FEC: `CR = 1` для коду 4/5, `CR = 2` для 4/6, `CR = 3` для 4/7, `CR = 4` для 4/8.

Тривалість блоку даних:

```
t_payload = N_payload · T_sym     [час передачі даних]
```

**Покроковий розрахунок ToA для пакета PL = 20 байтів (SF7, BW = 125 кГц, CR = 1, CRC = 1, IH = 0, DE = 0):**

```
Крок 1 (Чисельник):
8·PL - 4·SF + 28 + 16·CRC - 20·IH
= 8·20 - 4·7 + 28 + 16·1 - 20·0
= 160 - 28 + 28 + 16 - 0
= 176

Крок 2 (Знаменник):
4·(SF - 2·DE)
= 4·(7 - 2·0)
= 28

Крок 3 (Ділення та округлення вгору):
ceil(176 / 28) = ceil(6.2857) = 7

Крок 4 (Множення на коефіцієнт кодування CR + 4):
7 · (1 + 4) = 7 · 5 = 35

Крок 5 (Додавання 8 службових символів):
N_payload = 8 + 35 = 43 символи

Крок 6 (Час передачі корисного навантаження):
t_payload = 43 · 1.024 мс = 44.032 мс

Крок 7 (Повний час кадру в ефірі ToA):
ToA = t_preamble + t_payload
    = 12.544 мс + 44.032 мс
    = 56.576 мс
```

**Покроковий розрахунок ToA для того самого пакета PL = 20 байтів при SF12 (DE = 1):**

```
Крок 1 (Чисельник):
8·20 - 4·12 + 28 + 16·1 - 0 = 160 - 48 + 28 + 16 = 156

Крок 2 (Знаменник з урахуванням DE=1):
4·(12 - 2·1) = 4·10 = 40

Крок 3 (Ділення та округлення):
ceil(156 / 40) = ceil(3.9) = 4

Крок 4 (Множення на CR+4):
4 · 5 = 20

Крок 5 (Символи навантаження):
N_payload = 8 + 20 = 28 символів

Крок 6 (Час корисного навантаження):
t_payload = 28 · 32.768 мс = 917.504 мс

Крок 7 (Повний час ToA при SF12):
ToA = t_preamble + t_payload
    = 401.408 мс + 917.504 мс
    = 1318.912 мс ≈ 1.319 с
```

Порівняння результатів: збільшення SF з 7 до 12 збільшує час у ефірі з 56.6 мс до 1318.9 мс — рівно в 23.3 раза при ідентичному корисному навантаженні!

## Аналітична модель Time on Air для модуляції FSK / GFSK

Для класичної частотної маніпуляції (Frequency Shift Keying, FSK) зв'язок між кількістю бітів та часом у ефірі є лінійним і визначається бітрейтом передачі `R_bit` (біт/с).

Структура FSK-кадру:
- `N_preamble` — байти преамбули (стандартно 4–8 байтів, чергування 0xAA).
- `N_sync` — байти синхрослова Sync Word (2–4 байти).
- `N_hdr` — байти заголовка/довжини (1–2 байти).
- `N_payload` — корисні дані (PL байтів).
- `N_crc` — контрольна сума (2 байти CRC-16).

```
N_total_bytes = N_preamble + N_sync + N_hdr + PL + N_crc     [сумарний обсяг кадру]
ToA_FSK = (N_total_bytes · 8) / R_bit                       [час в ефірі FSK]
```

**Приклад розрахунку для пакета PL = 20 байтів при бітрейті 50 кбіт/с:**
- Преамбула: 4 байти
- Синхрослово: 4 байти
- Довжина: 1 байт
- Дані: 20 байтів
- CRC: 2 байти
- Сумарно: `4 + 4 + 1 + 20 + 2 = 31 байт = 248 бітів`

```
ToA_FSK = 248 біт / 50000 біт/с = 0.00496 с = 4.96 мс
```

При швидкості FSK 250 кбіт/с той самий кадр передається за:

```
ToA_FSK = 248 біт / 250000 біт/с = 0.000992 с = 0.992 мс
```

## Інтегральна модель заряду транзакції та середнього струму

Електричний заряд `Q` (Кулони або міліампер-секунди), вилучений із джерела за один повний робочий цикл `T_cycle`, є визначеним інтегралом струму за часом:

```
Q_транзакції = ∫ I(t) dt
```

Розбиваючи профіль на дискретні фази, отримуємо суму складових:

```
Q_транзакції = I_pll·t_pll + I_tx·ToA + I_rx1·t_rx1 + I_rx2·t_rx2 + I_сон·t_сон
```

де:
- `I_pll·t_pll` — фаза запуску кварцу та фіксації частоти синтезатора (типово 5 мА · 1.5 мс = 0.0075 мА·с = 7.5 мкКл).
- `I_tx·ToA` — фаза активної передачі вихідного підсилювача (типово 45 мА · ToA при +14 дБм або 120 мА · ToA при +22 дБм).
- `I_rx1·t_rx1` — перше приймальне вікно (типово 10 мА · 15 мс = 0.15 мА·с = 150 мкКл).
- `I_rx2·t_rx2` — друге приймальне вікно у разі відсутності відповіді в RX1 (10 мА · 15 мс = 150 мкКл).
- `I_сон·t_сон` — струм глибокого сну вузла між циклами передачі (типово 1.5 мкА · `T_cycle`).

Середній струм споживання за період `T_cycle`:

```
I_сер = Q_транзакції / T_cycle     [середній струм вузла]
```

## Модель прогнозування терміну служби батареї

Батарея ємністю `C_nom` (мА·год) втрачає заряд як через активність схеми `I_сер`, так і внаслідок внутрішнього хімічного саморозряду.

Річний відсоток саморозряду `S_self` (%/рік) переводиться у постійний еквівалентний струм витоку:

```
I_self = (C_nom · S_self / 100) / 8760     [струм саморозряду в мА]
```

де 8760 — кількість годин у невисокосному році (365 · 24).

Крім того, імпульсний струм передавача (40–120 мА) викликає просідання напруги на внутрішньому опорі батареї `R_int`. Через це кінцева напруга відсічки мікроконтролера досягається раніше, ніж хімічна ємність вичерпається на 100%. Для врахування цього ефекту вводиться коефіцієнт корисної віддачі ємності `k_pulse` (для літій-тіонілхлоридних батарей LiSOCl2 `k_pulse ≈ 0.85–0.90`, для дискових CR2032 `k_pulse ≈ 0.65–0.75` через високий `R_int`).

Розрахунковий час автономної роботи в роках:

```
T_років = (C_nom · k_pulse) / ((I_сер + I_self) · 8760)     [термін служби батареї]
```

## Зведений розрахунковий приклад: вплив SF та періоду відправки

Розглянемо батарею LiSOCl2 типорозміру AA ємністю `C_nom = 2400 мА·год`, напруга 3.6 В, річний саморозряд `S_self = 1 %/рік`, коефіцієнт імпульсної віддачі `k_pulse = 0.85`.

```
I_self = (2400 · 0.01) / 8760 = 24 / 8760 ≈ 0.00274 мА = 2.74 мкА
Корисна ємність = 2400 · 0.85 = 2040 мА·год
Струм сну вузла I_сон = 1.8 мкА = 0.0018 мА
Струм передавача SX1262 при +14 дБм I_tx = 45 мА
Струм прийому I_rx = 10 мА (вікно 15 мс = 0.15 мА·с)
Розмір корисного навантаження PL = 20 байтів
```

### Сценарій 1: LoRa SF7, передача 1 раз на 10 хвилин (T_cycle = 600 с)
- `ToA = 56.6 мс = 0.0566 с`
- Заряд передачі: `Q_tx = 45 мА · 0.0566 с = 2.547 мА·с`
- Заряд приймального вікна: `Q_rx = 10 мА · 0.015 с = 0.150 мА·с`
- Заряд запуску PLL: `Q_pll = 5 мА · 0.0015 с = 0.0075 мА·с`
- Сумарний імпульсний заряд: `Q_pulse = 2.547 + 0.150 + 0.0075 = 2.7045 мА·с`
- Струм від радіотранзакцій: `I_rf_avg = 2.7045 мА·с / 600 с = 0.00451 мА = 4.51 мкА`
- Загальний середній струм: `I_сер = I_rf_avg + I_сон = 4.51 + 1.80 = 6.31 мкА`
- Струм з урахуванням саморозряду: `I_total = 6.31 + 2.74 = 9.05 мкА = 0.00905 мА`

```
T_років = 2040 мА·год / (0.00905 мА · 8760 год)
        = 2040 / 79.278
        = 25.7 року  (реально обмежено фізичним терміном деградації батареї ≈ 10–15 років)
```

### Сценарій 2: LoRa SF12, передача 1 раз на 10 хвилин (T_cycle = 600 с)
- `ToA = 1318.9 мс = 1.3189 с`
- Заряд передачі: `Q_tx = 45 мА · 1.3189 с = 59.35 мА·с`
- Заряд приймальних вікон (вікно RX1 при SF12 триває довше, ~65 мс): `Q_rx = 10 мА · 0.065 с = 0.65 мА·с`
- Сумарний імпульсний заряд: `Q_pulse = 59.35 + 0.65 + 0.0075 = 60.01 мА·с`
- Струм від радіотранзакцій: `I_rf_avg = 60.01 мА·с / 600 с = 0.1000 мА = 100.0 мкА`
- Загальний середній струм: `I_сер = 100.0 + 1.80 = 101.8 мкА`
- Струм із саморозрядом: `I_total = 101.8 + 2.74 = 104.54 мкА = 0.10454 мА`

```
T_років = 2040 мА·год / (0.10454 мА · 8760 год)
        = 2040 / 915.77
        = 2.23 року
```

### Порівняльний підсумок математичного аналізу

| Параметр | LoRa SF7 (10 хв) | LoRa SF12 (10 хв) | FSK 50k (10 хв) | LoRa SF12 (1 хв) |
|---|---|---|---|---|
| Час у ефірі ToA | **56.6 мс** | **1318.9 мс** | **4.96 мс** | **1318.9 мс** |
| Заряд імпульсу Q_pulse | **2.70 мА·с** | **60.01 мА·с** | **0.37 мА·с** | **60.01 мА·с** |
| Середній струм I_сер | **6.31 мкА** | **101.8 мкА** | **2.42 мкА** | **1001.8 мкА** |
| Термін служби батареї | **> 15 років** | **2.2 року** | **> 15 років** | **0.23 року (2.7 міс)** |

Математичний розрахунок наочно доводить: правильний вибір коефіцієнта розширення спектра (SF) та перехід на адаптивне регулювання швидкості (ADR) є не оптимізацією «на кілька відсотків», а фундаментальним фактором, який визначає, чи пропрацює автономний вузол десятиліття, чи вичерпає батарею за кілька місяців.
