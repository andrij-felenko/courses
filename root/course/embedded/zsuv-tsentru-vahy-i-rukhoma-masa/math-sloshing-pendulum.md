# 🧮 Механічний маятниковий еквівалент плескання рідини

Цей розрахунок дає строге аналітичне виведення еквівалентної механічної моделі «жорстке тіло + маятник із демпфером» із перших принципів гідродинаміки нестисливої рідини з вільною поверхнею. Отримана дискретна система замінює нескінченновимірні рівняння Нав'є–Стокса скінченною системою звичайних диференціальних рівнянь, придатних для обчислення в реальному часі всередині 6-DOF симуляторів польоту та адаптивних контурів польотного контролера.

│         │ ~~~~~~~~~ │  Вільна хвиля           │     O     │ Шарнір h₁   │

### Гідродинамічна постановка: потенціал швидкостей та граничні умови

Розглядаємо рух ідеальної однорідної нестисливої рідини густиною `ρ` у вертикальному циліндричному резервуарі радіусом `R`, заповненому до початкової висоти спокою `h`. Вважаємо течію безвихровою (ірротаційною), що дає змогу описати поле швидкостей через скалярний потенціал швидкостей `Φ(r, θ, z, t)`:

```
v = ∇Φ = [∂Φ/∂r, (1/r)·(∂Φ/∂θ), ∂Φ/∂z]ᵀ
```

У циліндричних координатах `(r, θ, z)` нестисливість рідини (`∇ · v = 0`) зводить рівняння руху до класичного рівняння Лапласа:

```
∇²Φ = ∂²Φ/∂r² + (1/r)·(∂Φ/∂r) + (1/r²)·(∂²Φ/∂θ²) + ∂²Φ/∂z² = 0
```

Для бака, який здійснює поступальний рух у горизонтальній площині вздовж осі `x` із прискоренням `a_x(t)`, діють три граничні умови:

1. **Непроникність жорсткого плоского дна (`z = 0`)**: вертикальна складова відносної швидкості частинок рідини на дні тотожно дорівнює нулю:

```
∂Φ/∂z = 0   [при z = 0]
```

2. **Непроникність бічної циліндричної стінки (`r = R`)**: радіальна швидкість рідини на стінці повинна дорівнювати проекції швидкості руху стінки на нормаль:

```
∂Φ/∂r = v_x(t) · cos(θ)   [при r = R]
```

3. **Динамічна та кінематична граничні умови на вільній поверхні (`z = h + η(r, θ, t)`)**: тиск на вільній поверхні дорівнює постійному атмосферному тиску, а частинки рідини не покидають поверхню. Після лінеаризації за малими амплітудами хвилі `η` та виключення висоти підйому через інтеграл Коші–Лагранжа отримуємо комбіновану хвильову умову на незбуреній поверхні:

```
∂²Φ/∂t² + g · (∂Φ/∂z) = 0   [при z = h]
```

Розв'язок крайової задачі шукаємо методом розділення змінних Фур'є. Враховуючи періодичність за кутом `θ`, симетрію збурення вздовж осі `x` та регулярність у центрі `r = 0`, розв'язок для фундаментальної першої асиметричної моди коливань (яка відповідає за перенесення маси та створення головної поперечної сили) набуває вигляду:

```
Φ(r, θ, z, t) = A₁(t) · J₁(ξ₁ · r / R) · cos(θ) · cosh(ξ₁ · z / R)
```

де `J₁(·)` — функція Бесселя першого роду першого порядку, а `ξ₁ ≈ 1.84118` — перший додатний нуль похідної функції Бесселя `J₁'(ξ) = 0`, що забезпечує виконання умови непроникності стінки при `r = R`.

### Виведення власної частоти коливань рідини

Підставивши функцію потенціалу `Φ` у динамічну умову вільної поверхні при `z = h`, отримуємо характеристичне рівняння для гармонічного коливного процесу `A₁(t) = C · sin(ω₁ · t)`:

```
-ω₁² · cosh(ξ₁ · h / R) + g · (ξ₁ / R) · sinh(ξ₁ · h / R)
= 0                                                        [підстановка Φ у хвильову умову]
ω₁² · cosh(ξ₁ · h / R)
= g · (ξ₁ / R) · sinh(ξ₁ · h / R)                         [перенесення доданка]
ω₁²
= (g · ξ₁ / R) · (sinh(ξ₁ · h / R) / cosh(ξ₁ · h / R))    [ділення на cosh]
= (g · ξ₁ / R) · tanh(ξ₁ · h / R)                         [означення гіперболічного тангенса]
```

Власна колова частота коливань першої моди плескання:

```
ω₁ = √( (g · ξ₁ / R) · tanh(ξ₁ · h / R) )
```

Циклічна частота коливань у герцах:

```
f₁ = ω₁ / (2π)
```

### Крайові випадки: мілка та глибока рідина

Поведінка розв'язку суттєво залежить від відносного рівня заповнення бака `h / R`:

1. **Режим глибокої рідини (`h / R > 1.5–2.0`)**:
   Аргумент гіперболічного тангенса великий, тому `tanh(ξ₁ · h / R) → 1`. Власна частота перестає залежати від глибини й визначається лише радіусом бака:
   `ω₁ ≈ √(g · ξ₁ / R)`. При цьому придонні шари рідини залишаються практично нерухомими (гідродинамічний рух експоненційно згасає за законом `cosh(ξ₁ · z / R)`).
2. **Режим мілкої рідини (`h / R < 0.5`)**:
   Для малих аргументів справедлива апроксимація `tanh(x) ≈ x`. Підстановка дає:
   `ω₁ ≈ √(g · ξ₁² · h / R²) = (ξ₁ / R) · √(g · h)`.
   Частота стає прямо пропорційною кореню з глибини `√h`. У цьому режимі виникає нелінійний ефект гідравлічного удару об стінки (хвильовий бор), що супроводжується різкими імпульсними сплесками тиску.

### Параметри еквівалентної маятникової моделі

Повна маса рідини в циліндричному резервуарі:

```
M = ρ · π · R² · h
```

Щоб дискретний маятник масою `m₁` на невагомому підвісі довжини `L₁` створював таку саму результуючу поперечну силу та перекидний момент відносно центру дна бака при довільних прискореннях, параметри еквівалента визначаються шляхом інтегрування поля гідродинамічного тиску `p = -ρ · (∂Φ/∂t)` по всій змоченій поверхні:

#### 1. Коливна маса рідини (маса маятника `m₁`):

```
m₁
= M · (2 · R / (ξ₁ · h · (ξ₁² - 1))) · tanh(ξ₁ · h / R)   [інтегрування тиску по бічній стінці]
= M · (2 / (1.84118 · 2.38994)) · (R / h) · tanh(1.84118 · h / R)   [підстановка кореня ξ₁ = 1.84118]
= M · 0.4545 · (R / h) · tanh(1.84118 · h / R)             [числове зведення коефіцієнта]
```

#### 2. Жорстко зв'язана (нерухома) маса `m₀`:

Частина маси рідини, яка жорстко рухається разом із баком як монолітне тіло:

```
m₀ = M - m₁
```

#### 3. Довжина еквівалентного маятника `L₁`:

Довжина підвісу вибирається з умови ідеального збігу власної частоти маятника `ω = √(g / L₁)` із гідродинамічною частотою `ω₁`:

```
L₁
= g / ω₁²                                                 [зв'язок довжини й власної частоти маятника]
= g / ( (g · ξ₁ / R) · tanh(ξ₁ · h / R) )                [підстановка формули власної частоти ω₁²]
= R / ( ξ₁ · tanh(ξ₁ · h / R) )                           [скорочення прискорення вільного падіння g]
= R / ( 1.84118 · tanh(1.84118 · h / R) )                 [підстановка числового значення ξ₁]
```

#### 4. Висота точки підвісу маятника `h₁` від дна бака:

Точка кріплення шарніра виводиться з рівності перекидного моменту маятника сумарному моменту сил тиску на дно та бічні стінки бака:

```
h₁
= h · ( 1 - (R / (ξ₁ · h)) · ( 2 - cosh(ξ₁ · h / R) ) / sinh(ξ₁ · h / R) )  [рівність гідродинамічного моменту]
= h · ( 1 - (R / (1.84118 · h)) · tanh(0.92059 · h / R) )                  [перетворення гіперболічних функцій]
```

#### 5. Висота центра нерухомої маси `h₀` від дна бака:

Центр ваги нерухомої частки рідини розташовується так, щоб спільний статичний центр мас системи `(m₀ · h₀ + m₁ · (h₁ - L₁)) / M` точно збігався зі статичним центром мас незбуреної рідини в стані спокою `h_cg = h / 2`:

```
h₀ = ( (M · h / 2) - m₁ · (h₁ - L₁) ) / m₀
```

#### 6. Еквівалентний коефіцієнт демпфування `c₁`:

В'язке тертя рідини об стінки резервуара в ламінарному пограничному шарі створює коефіцієнт демпфування коливань:

```
ζ₁ = 0.79 · √( ν / (ω₁ · R²) ) · ( 1 + 0.318 / sinh(1.84118 · h / R) )
c₁ = 2 · m₁ · ω₁ · ζ₁
```

де `ν` — кінематична в'язкість рідини (для води `ν ≈ 1.004 × 10⁻⁶` м²/с при 20 °C).

### Числовий розрахунок для агродрона (20-літровий бак)

**Вхідні параметри:**
- Робоча рідина: вода з гербіцидом (`ρ = 1000` кг/м³, `ν = 1.0 × 10⁻⁶` м²/с)
- Радіус бака: `R = 0.15` м (діаметр 300 мм)
- Висота рівня рідини: `h = 0.28` м (280 мм, об'єм `V = π · 0.15² · 0.28 ≈ 0.01979` м³ ≈ 19.8 л)
- Повна маса рідини: `M = 19.79` кг
- Прискорення вільного падіння: `g = 9.80665` м/с²

**Крок 1. Геометричне співвідношення та гіперболічні функції:**

```
ξ₁ · h / R
= 1.84118 · 0.28 / 0.15
= 3.43687

tanh(3.43687)
= 0.99723                                       [глибока рідина: tanh ≈ 1]
```

**Крок 2. Власна частота коливань рідини:**

```
ω₁
= √( (9.80665 · 1.84118 / 0.15) · 0.99723 )   [підстановка параметрів у формулу частоти]
= √( 120.378 · 0.99723 )                       [обчислення підкореневого виразу]
= √( 120.045 )                                 [проміжне значення]
= 10.956 рад/с                                 [результат: колова частота]

f₁
= 10.956 / (2 · 3.14159)                       [переведення в герци]
= 1.744 Гц                                     [потрапляє в смугу PID-контуру!]
```

**Крок 3. Розрахунок коливної та нерухомої мас:**

```
m₁
= 19.79 · 0.4545 · (0.15 / 0.28) · 0.99723      [розрахунок коливної маси m₁]
= 19.79 · 0.4545 · 0.53571 · 0.99723           [проміжне множення]
= 4.802 кг                                     [24.3% від усієї маси розгойдується!]

m₀
= 19.79 - 4.802                                 [віднімання коливної маси]
= 14.988 кг                                     [нерухома маса]
```

**Крок 4. Довжина підвісу та координати шарнірів:**

```
L₁
= 0.15 / ( 1.84118 · 0.99723 )                  [розрахунок довжини еквівалентного маятника]
= 0.15 / 1.83608                                [обчислення знаменника]
= 0.0817 м                                     [81.7 мм]

h₁
= 0.28 · ( 1 - (0.15 / (1.84118 · 0.28)) · tanh(0.92059 · 0.28 / 0.15) )  [розрахунок висоти шарніра]
= 0.28 · ( 1 - 0.29095 · tanh(1.7184) )         [обчислення аргументу]
= 0.28 · ( 1 - 0.29095 · 0.93766 )              [обчислення тангенса]
= 0.28 · ( 1 - 0.27281 )                        [різниця в дужках]
= 0.28 · 0.72719                                [фінальне множення]
= 0.2036 м                                     [203.6 мм від дна бака]

h₀
= ( (19.79 · 0.140) - 4.802 · (0.2036 - 0.0817) ) / 14.988  [висота центра нерухомої маси]
= ( 2.7706 - 4.802 · 0.1219 ) / 14.988          [різниця моментів]
= ( 2.7706 - 0.5854 ) / 14.988                  [чисельник]
= 2.1852 / 14.988                               [ділення на масу m₀]
= 0.1458 м                                     [145.8 мм від дна бака]
```

**Крок 5. Розрахунок демпфування:**

```
ζ₁
= 0.79 · √( 10⁻⁶ / (10.956 · 0.15²) ) · ( 1 + 0.318 / sinh(3.43687) )  [безрозмірний коефіцієнт загасання]
= 0.79 · √( 10⁻⁶ / 0.24651 ) · ( 1 + 0.318 / 15.502 )                  [обчислення знаменників]
= 0.79 · √( 4.0566 × 10⁻⁶ ) · 1.0205                                  [значення під коренем]
= 0.79 · 0.002014 · 1.0205                                            [множення компонентів]
= 0.00162                                                             [вкрай мале демпфування: 0.16%!]

c₁
= 2 · 4.802 · 10.956 · 0.00162                                        [коефіцієнт в'язкого тертя]
= 0.1706 Н·с/м
```

### Диференціальні рівняння динаміки маятника для 6-DOF інтегратора

Для інтеграції в симулятор польоту рух маятника описується кутом відхилення `ψ` від вертикалі бака. 

При кутовій швидкості корпусу `ω_b` та лінійному прискоренні точки кріплення `a_h`:

```
L₁ · d²ψ/dt² + (c₁ / m₁) · L₁ · dψ/dt + g · sin(ψ) = - a_h_x · cos(ψ) - a_h_z · sin(ψ)
```

Сила реакції маятника `F_p` та крутний момент `M_p`, що передаються на раму дрона в точці `(x_tank, y_tank, z_tank + h₁)`:

```
F_p_x = - m₁ · ( a_h_x + L₁ · (d²ψ/dt² · cos(ψ) - (dψ/dt)² · sin(ψ)) )
F_p_z = - m₁ · ( g + a_h_z + L₁ · (d²ψ/dt² · sin(ψ) + (dψ/dt)² · cos(ψ)) )
M_p_y = F_p_x · L₁ · cos(ψ) + F_p_z · L₁ · sin(ψ)
```

Ці сили безпосередньо додаються до вектора зовнішніх збурень у рівняннях динаміки Ньютона–Ейлера для польотного контролера.
