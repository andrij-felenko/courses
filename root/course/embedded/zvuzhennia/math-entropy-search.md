# 🧮 Ентропія пошуку та зважена бісекція

Коли вбудована система відмовляє серед сотень компонентів і тисяч рядків коду, інженер стикається з невизначеністю: будь-який вузол може бути джерелом збою. Цей математичний аналіз виводить, як саме теорія інформації Клода Шеннона перетворює хаотичне тестування на точний алгоритм із логарифмічною складністю, чому симетричний поділ навпіл максимізує інформаційний виграш, і як модифікувати бісекцію, коли ймовірності виходу з ладу або ціна перевірки окремих каскадів різняться в десятки разів.

### Кількість інформації та ентропія простору гіпотез

Нехай система містить N потенційних елементів (компонентів схеми, регістрів периферії або комітів у репозиторії), серед яких є рівно одна несправність. Простір станів визначається дискретною випадковою величиною X з можливими значеннями x₁, x₂, ..., x_N.

Апріорна невизначеність щодо того, який саме елемент пошкоджено, вимірюється ентропією Шеннона H(X). Якщо всі N елементів апріорно мають однакову ймовірність відмови:

```text
p_i = 1 / N                                  [рівномірний розподіл імовірностей]

H(X) = - ∑ (p_i * log2(p_i))                 [означення ентропії Шеннона]
     = - ∑ ((1 / N) * log2(1 / N))           [підстановка рівних імовірностей]
     = - N * (1 / N) * (-log2(N))            [спрощення суми N однакових доданків]
     = log2(N)                               [початкова невизначеність у бітах]
```

Для системи з N = 1024 підозрілих точок початкова ентропія становить рівно 10 бітів інформації. Локалізувати конкретний дефект означає зменшити ентропію системи до нуля (H_кінцева = log₂(1) = 0).

### Чому поділ рівно 50/50 максимізує інформаційний виграш

Кожен діагностичний тест ділить множину підозрюваних елементів N на дві підмножини: групу A розміром k елементів та групу B розміром (N - k) елементів. Тест дає бінарний результат: «дефект у групі A» (подія з імовірністю P_A = k / N) або «дефект у групі B» (подія з імовірністю P_B = (N - k) / N).

Залишковий середній обсяг невизначеності після проведення тесту описується умовною ентропією H(X | T):

```text
H(X | T) = P_A * log2(k) + P_B * log2(N - k)  [математичне сподівання залишкової ентропії]
         = (k / N) * log2(k) + ((N - k) / N) * log2(N - k)
```

Інформаційний виграш тесту (взаємна інформація I(X; T)) дорівнює різниці між початковою та залишковою ентропією:

```text
I(X; T) = H(X) - H(X | T)                     [інформаційний виграш тесту]
        = log2(N) - (k/N)*log2(k) - ((N-k)/N)*log2(N-k)
        = - (k/N)*log2(k/N) - ((N-k)/N)*log2((N-k)/N)
        = - P_A * log2(P_A) - (1 - P_A) * log2(1 - P_A)
```

Цей вираз є функцією двійкової ентропії H_bin(P_A). Знайдемо її екстремум, узявши першу похідну за параметром P_A і прирівнявши її до нуля:

```text
d(I) / d(P_A) = - log2(P_A) - 1/ln(2) + log2(1 - P_A) + 1/ln(2)   [похідна ентропії]
              = log2((1 - P_A) / P_A)

log2((1 - P_A) / P_A) = 0                     [умова максимуму функції]
(1 - P_A) / P_A = 1
1 - P_A = P_A
P_A = 1 / 2 = 0.5                             [оптимальний розріз простору]
```

Оскільки друга похідна d²(I) / d(P_A)² = -1 / (ln(2) * P_A * (1 - P_A)) < 0 для всіх P_A ∈ (0, 1), точка P_A = 0.5 є строгою точкою глобального максимуму.

При симетричному поділі k = N / 2 інформаційний виграш кожного кроку становить:

```text
I_max = - 0.5 * log2(0.5) - 0.5 * log2(0.5)  [підстановка P_A = 0.5]
      = - 0.5 * (-1) - 0.5 * (-1)
      = 1.00 біт                              [максимальна інформація за 1 тест]
```

При рівномірній ймовірності будь-який відхил від пропорції 50/50 зменшує отриману інформацію. Наприклад, перевірка одного підозрілого компонента з 1024 (k = 1) дає:

```text
P_A = 1 / 1024 ≈ 0.000976
I = - (1/1024)*log2(1/1024) - (1023/1024)*log2(1023/1024)
  ≈ 0.00976 + 0.00141
  ≈ 0.011 біта                                [у 90 разів менше за бісекцію]
```

Перевірка одиночних елементів (лінійний пошук) генерує мізерний інформаційний потік, через що математичне сподівання кількості кроків зростає з log₂(N) до (N + 1) / 2.

### Нерівномірні апріорні ймовірності: ентропійний розріз

У реальній схемотехніці надійність компонентів неоднакова. Силовий MOSFET або танталовий конденсатор на шині живлення мають інтенсивність відмов λ у 10–100 разів вищу, ніж пасивний резистор 0402.

Якщо елементи x_i мають нерівні апріорні ймовірності відмови p_i (де ∑ p_i = 1), оптимальний поділ множини {X} на дві групи G₁ та G₂ полягає не в рівній кількості компонентів (|G₁| = |G₂|), а в рівній сумарній ймовірності:

```text
P(G₁) = ∑_{i ∈ G₁} p_i ≈ 0.5                 [умова максимального виграшу інформації]
P(G₂) = ∑_{j ∈ G₂} p_j ≈ 0.5
```

Якщо один силовий модуль має ймовірність відмови p_vuzol = 0.5, а решта 50 дрібних давачів сумарно мають ймовірність 0.5, перший діагностичний крок зобов'язаний ізолювати саме цей силовий модуль від решти схеми. Це розсікає ймовірнісний простір рівно навпіл і дає 1 повний біт інформації за перший крок, попри те, що геометрично ми відрізали 1 компонент проти 50.

### Врахування вартості діагностичного тесту

У фізичному залізі та в складних тестах прошивки різні перевірки мають суттєво різну вартість (у секундах, годинах або ризику пошкодження плати).

Нехай:
- C_i — вартість i-го тесту (наприклад, перевірка осцилографом C_osc = 10 с, демонтаж мікросхеми феном C_rework = 1200 с).
- ΔH_i — зменшення ентропії, яке забезпечує цей тест.

Цільова функція оптимального пошуку полягає в мінімізації сумарної вартості діагностики до знаходження дефекту:

```text
E[C_total] = ∑ (P_шляху * C_кроків) -> min    [мінімізація середньої вартості локалізації]
```

Згідно з узагальненим правилом Хаффмана–Джонсона, індекс пріоритетності вибору наступного тесту визначається питомою інформаційною віддачею на одиницю вартості:

```text
Ефективність тесту = ΔH / C                   [біт інформації на одиницю вартості]
```

Розглянемо практичне порівняння двох діагностичних кроків на платі з підозрою на коротке замикання:

```text
Тест A (Осцилограф/Мілівольтметр на контрольних точках):
  ΔH_A = 1.0 біт (ділить плату 50/50)
  C_A  = 15 секунд
  Віддача = 1.0 / 15 ≈ 0.0667 біт/с

Тест B (Випаювання головного BGA-контролера):
  ΔH_B = 1.0 біт (ізолює MCU від периферії)
  C_B  = 1800 секунд (підготовка станції, нагрів, ризик відриву доріжок)
  Віддача = 1.0 / 1800 ≈ 0.00055 біт/с
```

Тест A ефективніший за Тест B у 120 разів. Оптимальна стратегія завжди вимагає спочатку виконати всі дешеві розсічення простору з високим показником ΔH / C, навіть якщо вони ділять простір у пропорції 80/20, перш ніж переходити до дорогих руйнівних операцій.

### Логарифмічний бар'єр у часі локалізації

Зведена таблиця показує різницю між сліпим лінійним перебором та ентропійно-оптимальною бісекцією при зростанні розміру системи N:

| Розмір простору N | Лінійний перебір E[K] = (N+1)/2 | Бісекція 50/50 K = ⌈log₂(N)⌉ | Виграш у кроках |
| :--- | :--- | :--- | :--- |
| 16 вузлів / функцій | 8.5 перевірок | 4 перевірки | 2.1x |
| 64 вузли / регістри | 32.5 перевірки | 6 перевірок | 5.4x |
| 256 комітів у git | 128.5 перевірок | 8 перевірок | 16.0x |
| 1024 рядки / деталі | 512.5 перевірок | 10 перевірок | 51.2x |
| 4096 компонентів | 2048.5 перевірок | 12 перевірок | 170.7x |

Логарифмічна основа половинного поділу гарантує: подвоєння складності системи додає всього один додатковий крок вимірювання, тоді як для лінійного перебору подвоєння складності подвоює час роботи інженера.
