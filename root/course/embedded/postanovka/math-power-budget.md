# 🧮 Розрахунок енергетичного бюджету автономного вузла

Цей розрахунок визначає реальний строк служби автономного сенсорного вузла від хімічного джерела струму та мінімальну площу сонячної панелі для безперервної роботи взимку. Без точного балансу заряду неможливо обрати типорозмір батареї: наївне ділення номінальної ємності на середній струм дає похибку у 2–3 рази через саморозряд, температурну деградацію та імпульсні просідання напруги.

## Базова модель середнього струму споживання

Робота сенсорного вузла є циклічною. Повний період циклу `T_cycle` складається з інтервалів сну та активних фаз:

```
T_cycle = t_sleep + t_wake + t_measure + t_tx + t_rx
```

Кожна фаза характеризується власним струмом споживання та тривалістю:
- `t_sleep` — тривалість фази глибокого сну (мікроконтролер у режимі Deep Sleep, живлення давачів вимкнене ключем, активний лише низькоспоживаючий таймер RTC).
- `t_wake` — час виходу мікроконтролера зі сну, стабілізації тактового генератора та ініціалізації шин вводу-виводу.
- `t_measure` — час опитування сенсорів (подача живлення на вимірювальний міст, аналогово-цифрове перетворення, фільтрація).
- `t_tx` — час передачі пакета в радіоефір або кадру в лінію зв'язку.
- `t_rx` — тривалість вікна очікування квитанції (ACK) або команди з сервера.

Сумарний електричний заряд `Q_cycle` (в міліампер-секундах або кулонах), що витрачається за один повний цикл, дорівнює сумі зарядів окремих фаз:

```
Q_cycle = I_sleep·t_sleep + I_wake·t_wake + I_measure·t_measure + I_tx·t_tx + I_rx·t_rx
```

Середній струм споживання пристрою `I_avg` визначається відношенням сумарного заряду до періоду циклу:

```
I_avg
= Q_cycle / T_cycle                                           [визначення середнього струму через повний заряд]
= (I_sleep·t_sleep + ∑(I_k·t_k)) / T_cycle                    [виділення струму сну та суми активних фаз]
```

Оскільки `t_sleep ≈ T_cycle` (скважність активних фаз становить менше 0.1%), формулу зручно звести до вигляду:

```
I_avg = I_sleep + Q_active / T_cycle
```

де `Q_active = ∑(I_k·t_k)` — заряд, спожитий під час усіх активних операцій одного вимірювального сеансу.

## Температурні коефіцієнти та саморозряд батареї

Номінальна ємність батареї `C_nom` (вказана виробником у паспорті для температури +20 °C і постійного розряду мікрострумами) не може бути повністю використана у польових умовах. Доступна ємність `C_eff` зменшується під дією трьох фізичних факторів:

```
C_eff = C_nom · k_temp · k_discharge · k_aging
```

1. **Температурний коефіцієнт `k_temp`**:
При зниженні температури до -20...-40 °C в'язкість рідкого електроліту зростає, швидкість дифузії іонів падає, а внутрішній опір комірки `R_int` зростає у 3–8 разів.
- Для хімії Li-SOCl2 (літій-тіонілхлорид):
  `k_temp(+20 °C) = 1.00`
  `k_temp(0 °C) = 0.90`
  `k_temp(-20 °C) = 0.75`
  `k_temp(-40 °C) = 0.50`
- Для звичайних Li-Ion / LiFePO4:
  `k_temp(-20 °C) = 0.40...0.55` (при цьому заряджання при температурі нижче 0 °C заборонене через осадження металевого літію на аноді).

2. **Коефіцієнт імпульсного навантаження `k_discharge`**:
Під час передачі радіомодуль споживає піковий струм `I_tx` (від 100 до 500 мА). На внутрішньому опорі батареї `R_int` виникає падіння напруги:

```
ΔU = I_tx · R_int
```

Якщо напруга під навантаженням `U_batt - ΔU` впаде нижче порогу вимкнення супервізора живлення `U_cutoff` (Brown-out Reset, зазвичай 2.4–2.7 В), мікроконтролер піде в перезавантаження до вичерпання хімічної енергії. Для високоімпедансних комірок `k_discharge ≈ 0.80...0.90`, якщо паралельно не встановлено суперконденсатор (EDLC або гібридний шар HLC).

3. **Саморозряд `k_aging` та річна втрата заряду**:
Хімічні джерела струму втрачають відсоток ємності `σ_self` щороку навіть без навантаження:
- Li-SOCl2: `σ_self ≈ 1%...2%` на рік (завдяки захисній плівці пасивації LiCl).
- Li-MnO2: `σ_self ≈ 1.5%...2.5%` на рік.
- Li-Ion / LiFePO4: `σ_self ≈ 3%...6%` на рік (плюс струм власного споживання плати захисту BMS 5–15 мкА).

Розрахунковий час автономної роботи `T_life` (у роках) обчислюється розв'язанням балансового рівняння з урахуванням тривалості роботи `N_years`:

```
C_nom · k_temp · k_discharge · (1 - σ_self)ⁿ
= I_avg · 8760 · n                                            [де n = T_life у роках, 8760 — годин у році]
```

## Числовий приклад 1: Автономний польовий вузол LoRaWAN

**Вихідні дані:**
- Батарея: 1× Li-SOCl2 типорозміру D (ER34615), `C_nom = 19000 мА·год`, напруга 3.6 В.
- Струм глибокого сну вузла (MCU + LDO + RTC): `I_sleep = 12 мкА = 0.012 мА`.
- Опитування сенсорів (температура, вологість ґрунту): `I_measure = 8 мА`, тривалість `t_measure = 50 мс = 0.05 с`.
- Передача LoRa (SF10, CR 4/5, BW 125 кГц, 20 байт, потужність +14 dBm): `I_tx = 90 мА`, час у ефірі (Time-on-Air) `t_tx = 370 мс = 0.37 с`.
- Вікна прийому LoRaWAN (RX1 + RX2): `I_rx = 15 мА`, сумарний час `t_rx = 200 мс = 0.20 с`.
- Інтервал відправки: 1 раз на 15 хвилин (`T_cycle = 900 с`).
- Кліматичні умови: зимова температура до -20 °C (`k_temp = 0.75`), `k_discharge = 0.90` (з HLC), `σ_self = 0.015` (1.5%/рік).

**Крок 1. Розрахунок заряду активної фази:**
```
Q_active
= I_measure·t_measure + I_tx·t_tx + I_rx·t_rx                 [підстановка значень фаз]
= 8 мА · 0.05 с + 90 мА · 0.37 с + 15 мА · 0.20 с             [обчислення добутків окремих фаз]
= 0.40 мА·с + 33.30 мА·с + 3.00 мА·с                          [сума витрат заряду]
= 36.70 мА·с = 0.01019 мА·год                                 [переведення в міліампер-години]
```

**Крок 2. Розрахунок середнього струму:**
```
I_avg
= I_sleep + Q_active / T_cycle                                [середній струм за цикл]
= 0.012 мА + (36.70 мА·с / 900 с)                             [підстановка заряду активної фази та періоду]
= 0.012 мА + 0.04078 мА                                       [ділення заряду на час]
= 0.05278 мА ≈ 52.8 мкА                                       [сумарний середній струм]
```

**Крок 3. Річне споживання енергії:**
```
Q_year
= I_avg · 8760 год                                            [витрата заряду за рік]
= 0.05278 мА · 8760 год                                       [підстановка середнього струму та годин у році]
= 462.3 мА·год / рік                                          [річне споживання заряду]
```

**Крок 4. Розрахунок строку служби з деградацією:**
Доступна ємність при -20 °C:
```
C_eff
= 19000 мА·год · 0.75 · 0.90                                  [номінальна ємність з урахуванням k_temp та k_discharge]
= 12825 мА·год                                                [доступна ємність при -20 °C]
```

За 10 років експлуатації сумарні втрати від саморозряду складуть `1 - (1 - 0.015)¹⁰ ≈ 14%`.
Реальна корисна ємність:
```
C_usable = 12825 · 0.86 = 11029 мА·год
```

Строк служби:
```
T_life
= C_usable / Q_year                                           [ділення корисної ємності на річну витрату]
= 11029 мА·год / 462.3 мА·год/рік                             [підстановка числових значень]
= 23.8 року                                                   [теоретичний термін автономності]
```
*Висновок:* Енергетичного запасу елемента живлення з надлишком вистачає для покриття проектного терміну служби системи у 10 років. Головним обмежувальним фактором є хімічна деградація ущільнювачів та пасивація, а не ємність.

## Числовий приклад 2: Розрахунок сонячного живлення для зимового дефіциту

Для вузлів із високим споживанням (наприклад, стільниковий зв'язок NB-IoT/LTE-M із щохвилинними вимірюваннями) первинної батареї недостатньо, тому використовується тандем: сонячна панель + LiFePO4 акумулятор.

Критичним періодом є **грудень** у помірних широтах (50° пн. ш., Україна):
- Середньодобова еквівалентна сонячна інсоляція: `H_sun = 0.9 PSH` (Peak Sun Hours, 0.9 кВт·год/м² на добу).
- Тривалість безперервної хмарності (автономний резерв): `T_dark = 14 діб`.

**Вихідні дані:**
- Середнє споживання вузла: `P_load = 40 мВт` (при напрузі системи `U_sys = 3.3 В`, середній струм `I_avg = 12.1 мА`).
- ККД контролера заряду MPPT: `η_mppt = 0.90`.
- Кулонівський ККД заряду LiFePO4 акумулятора: `η_batt = 0.92`.
- Забруднення поверхні панелі та сніг: `k_dust = 0.80`.

**Крок 1. Добове споживання енергії навантаженням:**
```
E_day_load
= P_load · 24 год                                             [добова витрата енергії]
= 0.040 Вт · 24 год                                           [підстановка потужності та годин на добу]
= 0.96 Вт·год / добу                                          [добова витрата енергії]
```

**Крок 2. Необхідна пікова потужність сонячної панелі `P_pv`:**
Енергія, яку повинна згенерувати панель у найгірший грудневий день:
```
E_pv_gen · η_mppt · η_batt · k_dust ≥ E_day_load
```

```
P_pv · H_sun · (η_mppt · η_batt · k_dust) ≥ E_day_load
```

```
P_pv
≥ E_day_load / (H_sun · η_mppt · η_batt · k_dust)             [вираження потужності панелі]
= 0.96 / (0.9 · 0.90 · 0.92 · 0.80)                           [підстановка параметрів грудневої інсоляції та ККД]
= 0.96 / 0.596                                                [добуток коефіцієнтів втрат]
= 1.61 Вт                                                     [мінімальна пікова потужність]
```
З урахуванням коефіцієнта запасу 1.5 обирається стандартна сонячна панель потужністю **2.5–3.0 Вт** (наприклад, 6 В, 500 мА).

**Крок 3. Розрахунок ємності буферного акумулятора на період хмарності:**
Акумулятор повинен живити вузол протягом 14 діб без підзарядки при морозі -20 °C (`k_temp = 0.60` для LiFePO4), з максимально допустимою глибиною розряду 80% (`DoD = 0.80`):

```
E_storage
= (E_day_load · T_dark) / (k_temp · DoD)                      [розрахунок мінімального запасу енергії]
= (0.96 Вт·год · 14) / (0.60 · 0.80)                          [підстановка 14 діб темряви та морозного коефіцієнта]
= 13.44 / 0.48                                                [обчислення відношення]
= 28.0 Вт·год                                                 [необхідний запас енергії акумулятора]
```

При робочій напрузі комірки LiFePO4 `3.2 В` необхідна ємність:
```
C_batt_Ah
= E_storage / 3.2 В                                           [переведення енергії у ват-годинах в ампер-години]
= 28.0 / 3.2                                                  [ділення на номінальну напругу комірки]
= 8.75 А·год                                                  [мінімальна ємність батареї]
```
*Рішення:* Встановлюється акумуляторна збірка ємністю **9.0–10.0 А·год** (наприклад, 3 паралельні комірки типорозміру 26650 або 32700 по 3.2 А·год або 3.3 А·год), що гарантує безперебійну роботу впродовж найважчих зимових місяців.
