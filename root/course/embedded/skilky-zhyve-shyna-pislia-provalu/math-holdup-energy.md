# 🧮 Математичний вивід і баланс енергії hold-up

Розрахунок часу утримання напруги живильної шини (*hold-up time*) є критичним етапом проектування систем аварійного завершення роботи (*Power Loss Protection*), оскільки помилка у визначенні ємності накопичувача або неврахування нелінійної поведінки навантаження призводить до передчасного вимкнення мікроконтролера ще до завершення запису критичних даних.

Нижче наведено строгий математичний апарат розрахунку перехідних процесів розряду конденсаторів для двох фундаментальних типів навантаження (постійної потужності та постійного струму), виведено рівняння енергетичного балансу з урахуванням ККД перетворювача, динамічних втрат на еквівалентному послідовному опорі (*ESR*) та нелінійної деградації ємності керамічних діелектриків під дією постійної напруги (*DC-bias effect*).

### Розряд ємності на навантаження постійної потужності (DC-DC перетворювач)

Імпульсні стабілізатори напруги (*DC-DC buck converters*) підтримують стабільну напругу `V_out` на вторинній шині мікроконтролера за незмінного струму навантаження `I_out`. Отже, вихідна потужність є постійною величиною:

```
P_load = V_out · I_out = const
```

Якщо внутрішній ККД перетворювача дорівнює `η` (де `0 < η < 1`), то вхідна потужність, яку перетворювач відбирає від накопичувального конденсатора `C`, також є постійною в часі:

```
P_in(t) = P_load / η = const
```

Миттєвий струм `i_in(t)`, що споживається перетворювачем від конденсатора напругою `V(t)`:

```
i_in(t) = P_in / V(t) = P_load / (η · V(t))
```

Зв'язок між струмом розряду `i_in(t)` та швидкістю зміни напруги на ємності `C`:

```
i_in(t) = - C · (dV(t) / dt)
```

Прирівнюючи обидва вирази для струму, отримуємо нелінійне диференціальне рівняння першого порядку з відокремлюваними змінними:

```
- C · (dV(t) / dt) = P_load / (η · V(t))
```

Розділимо змінні: перенесемо члени з напругою `V` у ліву частину, а члени з часом `t` — у праву:

```
V(t) dV = - (P_load / (η · C)) dt
```

Проінтегруємо обидві частини рівняння від початкового моменту знеструмлення `t = 0` (коли напруга на конденсаторі дорівнювала `V_start`) до моменту вичерпання буфера `t = t_hold` (коли напруга опустилася до мінімальної вхідної напруги стабілізації `V_min`):

```
∫[V_start → V_min] V dV = - (P_load / (η · C)) · ∫[0 → t_hold] dt
```

Виконаємо інтегрування лівої та правої частин:

```
[V² / 2][V_start → V_min]
= (V_min² - V_start²) / 2          [первісна лівої частини]
= - (V_start² - V_min²) / 2        [винесення знака мінус]

- (P_load / (η · C)) · [t][0 → t_hold]
= - (P_load · t_hold) / (η · C)    [первісна правої частини]
```

Прирівнюємо отримані результати інтегрування:

```
- (V_start² - V_min²) / 2 = - (P_load · t_hold) / (η · C)
```

Скорочуємо знаки мінуса в обох частинах рівняння та виражаємо шуканий час утримання `t_hold`:

```
(V_start² - V_min²) / 2 = (P_load · t_hold) / (η · C)
(V_start² - V_min²) · η · C = 2 · P_load · t_hold
t_hold = (η · C · (V_start² - V_min²)) / (2 · P_load)
```

Отриманий вираз є фундаментальною формулою розрахунку часу утримання для імпульсних джерел живлення.

Необхідну ємність буферного банку `C` для забезпечення гарантованого часу збереження `t_hold` визначають зворотним перетворенням:

```
C = (2 · P_load · t_hold) / (η · (V_start² - V_min²))
```

### Порівняльний вивід: розряд при постійному струмі (LDO / лінійне навантаження)

Якщо навантаження живиться через лінійний стабілізатор (*LDO*) або безпосередньо становить стабільний струм `I_load = const`, вхідний струм розряду не залежить від напруги:

```
i_in(t) = I_load = const
```

Диференціальне рівняння розряду набуває вигляду:

```
- C · (dV / dt) = I_load
dV = - (I_load / C) dt
```

Інтегруємо від `0` до `t_hold_lin`:

```
∫[V_start → V_min] dV = - (I_load / C) · ∫[0 → t_hold_lin] dt
V_min - V_start = - (I_load · t_hold_lin) / C
t_hold_lin = (C · (V_start - V_min)) / I_load
```

Порівняння обох формул демонструє ключову фізичну відмінність:
1. При лінійному навантаженні час утримання пропорційний **першому степеню різниці напруг** `(V_start - V_min)`.
2. При навантаженні постійної потужності (DC-DC) час пропорційний **різниці квадратів напруг** `(V_start² - V_min²)`. Це означає, що енергія, запасена у верхньому діапазоні високої напруги (наприклад, між 24 В і 12 В), віддається значно ефективніше, оскільки при високій напрузі імпульсний стабілізатор споживає мінімальний струм `i_in = P / V`.

### Вплив еквівалентного послідовного опору (ESR)

Кожен реальний конденсатор має внутрішній омічний опір виводів та обкладок — еквівалентний послідовний опір (*Equivalent Series Resistance*, `R_ESR`).

Струм навантаження, що протікає через ємність, створює спад напруги на активному опорі `R_ESR`:

```
ΔV_ESR(t) = i_in(t) · R_ESR
```

У момент зникнення первинного живлення струм миттєво починає протікати через `R_ESR`, що спричиняє стрибкоподібне просідання початкової напруги на клемах конденсатора від `V_start` до ефективного значення `V_start_eff`:

```
V_start_eff
= V_start - i_in(0) · R_ESR                           [омічний спад на старті]
= V_start - (P_load / (η · V_start)) · R_ESR          [підстановка вхідного струму]
```

Найбільш критичний вплив `R_ESR` проявляється наприкінці інтервалу розряду, коли напруга наближається до мінімального порогу `V_min`. Оскільки напруга падає, струм імпульсного перетворювача зростає до свого пікового значення:

```
i_in_max = P_load / (η · V_min)
```

Максимальний спад напруги на внутрішньому опорі конденсатора досягає величини:

```
ΔV_ESR_max = (P_load · R_ESR) / (η · V_min)
```

Щоб регулятор не вийшов із режиму стабілізації (*dropout*) через цей спад, реальна напруга на внутрішній ємності повинна бути вищою за `V_min`. Отже, мінімальна напруга вимкнення збільшується на величину `ΔV_ESR_max`:

```
V_min_eff
= V_min + ΔV_ESR_max                                  [динамічний підйом порогу]
= V_min + (P_load · R_ESR) / (η · V_min)              [підстановка пікового струму]
```

Підставляючи скориговані границі `V_start_eff` та `V_min_eff` у формулу часу утримання, отримуємо точне інженерне рівняння з урахуванням втрат на ESR:

```
t_hold_real = (η · C · (V_start_eff² - V_min_eff²)) / (2 · P_load)
```

### Нелінійність керамічних конденсаторів (DC-Bias Effect)

Багатошарові керамічні конденсатори класу II (діелектрики `X5R`, `X7R`, `Y5V`) мають суттєву залежність діелектричної проникності від напруженості прикладеного електричного поля. Реальна диференціальна ємність `C(V)` зменшується зі зростанням постійної напруги `V` за емпіричною моделлю:

```
C(V) = C_0 / (1 + (V / V_half)²)
```

де `C_0` — номінальна ємність при нульовій напрузі зміщення, а `V_half` — напруга, за якої ємність зменшується вдвічі (типово 40–60% від номінальної напруги конденсатора `V_rated`).

Загальна енергія `E_cap`, накопичена в нелінійному керамічному конденсаторі при заряді до напруги `V_start`:

```
E_cap
= ∫[0 → V_start] C(V) · V dV                          [інтеграл потужності заряду]
= ∫[0 → V_start] (C_0 · V) / (1 + (V / V_half)²) dV   [підстановка моделі діелектрика]
```

Зробимо заміну змінної `u = 1 + (V / V_half)²`, тоді `du = (2 · V / V_half²) dV`, звідки `V dV = (V_half² / 2) du`:

```
E_cap
= (C_0 · V_half² / 2) · ∫[1 → 1 + (V_start/V_half)²] (1 / u) du   [заміна змінної інтегрування]
= (C_0 · V_half² / 2) · ln(1 + (V_start / V_half)²)               [інтеграл натурального логарифма]
```

Енергія, доступна для віддачі в навантаження в робочому діапазоні від `V_start` до `V_min`:

```
ΔE_usable
= E_cap(V_start) - E_cap(V_min)                                                            [різниця енергій станів]
= (C_0 · V_half² / 2) · ln((1 + (V_start / V_half)²) / (1 + (V_min / V_half)²))            [логарифм відношення аргументів]
```

Звідси реальний час утримання для MLCC-масивів з урахуванням ефекту DC-bias:

```
t_hold_mlcc
= (η · ΔE_usable) / P_load                                                                 [баланс енергії та потужності]
= (η · C_0 · V_half²) / (2 · P_load) · ln((1 + (V_start / V_half)²) / (1 + (V_min / V_half)²)) [підстановка корисної енергії]
```

Якщо підставити типові параметри керамічного конденсатора (номінал 47 мкФ, 16 В, робоча напруга 12 В, де `V_half ≈ 6 В`), виявляється, що реальна накопичена енергія становить лише **35–40%** від розрахованої за ідеальною формулою `½ · C_0 · V²`. Це доводить необхідність або значного запасу за ємністю MLCC (у 2.5–3 рази), або переходу на полімерні танталові конденсатори, які позбавлені ефекту DC-bias.

### Практичний числовий розрахунок

Розглянемо типовий вбудований вузол керування з такими вихідними параметрами:
- Постійне навантаження системи під час аварійного збереження: `P_load = 400 мВт` (`0.4 Вт`);
- Початкова напруга на накопичувальній шині: `V_start = 12.0 В`;
- Мінімальна вхідна напруга DC-DC buck стабілізатора (поріг dropout): `V_min = 4.5 В`;
- Середній ККД DC-DC перетворювача: `η = 0.88` (88%);
- Необхідний гарантований час на відключення периферії та запис 512 байтів у Flash: `t_req = 20 мс` (`0.020 с`);
- Коефіцієнт запасу надійності: `k_margin = 1.5` (цільовий `t_hold = 30 мс`).

**1. Розрахунок мінімально необхідної ємності:**

```
C_ideal
= (2 · P_load · t_hold) / (η · (V_start² - V_min²))   [вихідна формула ємності]
= (2 · 0.4 · 0.030) / (0.88 · (12.0² - 4.5²))        [підстановка числових параметрів]
= 0.024 / (0.88 · (144.0 - 20.25))                   [піднесення напруг до квадрата]
= 0.024 / (0.88 · 123.75)                            [обчислення різниці квадратів]
= 0.024 / 108.9                                      [множення на ККД перетворювача]
≈ 0.0002204 Ф = 220.4 мкФ                            [ділення та переведення в мікрофаради]
```

**2. Корекція на допуски та старіння конденсаторів:**
- Допуск номіналу ємності: `±20%` (коефіцієнт `k_tol = 1 / 0.80 = 1.25`);
- Температурна деградація та старіння: `k_temp = 1.15`.

```
C_required
= 220.4 мкФ · 1.25 · 1.15                            [врахування виробничого допуску та старіння]
≈ 316.8 мкФ                                          [результуюча розрахункова ємність]
```

**3. Вибір апаратного компонента:**
Обираємо полімерний танталовий конденсатор номіналом `330 мкФ` з робочою напругою `16 В` (derating 25% відносно 12 В) та `R_ESR = 25 мОм`.

**4. Перевірка динамічного спаду напруги на ESR:**
Максимальний струм напруги розряду біля `V_min = 4.5 В`:

```
i_in_max
= 0.4 Вт / (0.88 · 4.5 В)                            [піковий вхідний струм при мінімальній напрузі]
≈ 0.101 А = 101 мА                                   [значення максимального струму перетворювача]

ΔV_ESR_max
= 0.101 А · 0.025 Ом                                 [падіння напруги на послідовному опорі]
= 0.0025 В = 2.5 мВ                                  [значення максимального спаду ESR]
```

Спад напруги `2.5 мВ` становить менше 0.06% від `V_min`, що свідчить про повну зневажливість впливу ESR для обраного полімерного танталу в цьому режимі споживання. Розрахована ємність `330 мкФ` гарантує понад `31 мс` утримання стабільної шини 3.3 В, забезпечуючи трикратний запас часу над інтервалом запису у Flash.
