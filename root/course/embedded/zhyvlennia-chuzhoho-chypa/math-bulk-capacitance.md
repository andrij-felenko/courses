# 🧮 Розрахунок буферних ємностей для імпульсного навантаження

Коли зовнішній чип активує вбудований радіопередавач або виконує запис у енергонезалежну пам'ять, споживання струму стрибає від мікроамперів режиму очікування до кількох амперів за лічені мікросекунди. Жоден лінійний або імпульсний стабілізатор не здатний зреагувати на такий стрибок миттєво: петля зворотного зв'язку джерела живлення має кінцеву смугу пропускання і затримку реакції. Увесь початковий дефіцит заряду бере на себе буферний конденсаторний банк, установлений безпосередньо біля виводів живлення мікросхеми. Помилка в розрахунку ємності або нехтування паразитним послідовним опором (ESR) призводить до просадки напруги нижче порогу скидання Brown-Out Reset і циклічного перезавантаження мікроконтролера.

---

### Модель перехідного процесу в шині живлення

Повна зміна напруги на виводах живлення навантаження під час прямокутного імпульсу струму складається з трьох незалежних фізичних складових:

1. **Індуктивний сплеск на фронті (ESL):** падіння напруги на еквівалентній послідовній індуктивності виводів конденсатора та доріжок плати в момент швидкого наростання струму `di/dt`.
2. **Омічна сходинка (ESR):** миттєве падіння напруги на активному послідовному опорі обкладок і електроліту при протіканні пікового струму.
3. **Ємнісний розряд (C):** монотонне зниження напруги в міру відкачування заряду з обкладок конденсатора до моменту, поки джерело живлення не збільшить вихідний струм до потрібного рівня.

```
ΔV_total = ΔV_ESL + ΔV_ESR + ΔV_C
```

де складові визначаються фізичними законами:

```
ΔV_ESL = L_loop · (di / dt)
ΔV_ESR = I_peak · ESR
ΔV_C   = (1 / C) · ∫ (I_load(t) - I_source(t)) dt
```

Для якісного монтажу на друкованій платі з суцільним шаром землі індуктивність контуру `L_loop` становить 1–5 нГн. При часі наростання фронту передавача `dt = 1 мкс` та стрибку струму `2 А`:

```
ΔV_ESL = 3·10⁻⁹ Гн · (2 А / 10⁻⁶ с) = 0.006 В = 6 мВ
```

Індуктивна складова за правильного трасування є знехтовно малою, тому основний розрахунок зосереджується на сумі активного опору та ємнісного розряду:

```
ΔV_total ≈ (I_peak · ESR) + (ΔQ / C)
```

### Виведення мінімальної буферної ємності

Нехай навантаження створює прямокутний імпульс струму амплітудою `I_peak` і тривалістю `t_pulse`. Стабілізатор живлення має час реакції петлі регулювання `t_resp` (типово 15–40 мкс для LDO і 30–100 мкс для DC-DC перетворювача), а його максимальний тривалий струм обмежений величиною `I_source_max`.

Розглянемо найгірший випадок: передавач GSM/LTE створює імпульс `I_peak = 2.0 А` тривалістю `t_pulse = 577 мкс` (тайм-слот TDMA). Джерело живлення розраховане на постійний струм `I_source = 0.5 А`. Залишковий струм `I_diff = I_peak - I_source = 1.5 А` протягом усього імпульсу повинен постачатися конденсатором.

Загальний дефіцит електричного заряду `ΔQ`, який має віддати конденсатор за час `t_pulse`:

```
ΔQ = (I_peak - I_source) · t_pulse
```

Зв'язок між втраченим зарядом, ємністю та зміною напруги на обкладках:

```
ΔQ = C_bulk · ΔV_C
```

Звідси отримуємо базову формулу необхідної ємності:

```
C_bulk ≥ ((I_peak - I_source) · t_pulse) / ΔV_C_allowed
```

Якщо допустиме загальне просідання напруги становить `ΔV_max`, ми повинні виділити частку бюджету на омічне падіння в ESR конденсатора:

```
ΔV_C_allowed = ΔV_max - (I_peak · ESR)
```

Підставляючи це обмеження у вираз для ємності, отримуємо повне інженерне рівняння вибору ємності:

```
C_bulk ≥ ((I_peak - I_source) · t_pulse) / (ΔV_max - I_peak · ESR)
```

### Розрахунок граничного опору ESR

Щоб конденсатор узагалі міг виконати свою функцію, сходинка падіння напруги на ESR не повинна вичерпувати весь запас допустимої просадки. З умови `ΔV_C_allowed > 0` випливає суворе обмеження на еквівалентний послідовний опір:

```
ESR_max < ΔV_max / I_peak
```

На практиці під омічне падіння на ESR виділяють не більше 30–40% від сумарного бюджету просадки напруги:

```
ESR_target ≤ 0.35 · (ΔV_max / I_peak)
```

### Числовий приклад розрахунку для модуля стільникового зв'язку

**Вхідні параметри системи:**
- Номінальна напруга живлення модуля: `V_nom = 3.8 В`
- Мінімальна робоча напруга до відключення (Undervoltage Lockout): `V_min = 3.4 В`
- Допустима максимальна просадка з урахуванням запасу надійності: `ΔV_max = 300 мВ = 0.3 В`
- Піковий струм у режимі передачі 2G/LTE: `I_peak = 2.0 А`
- Максимальний вихідний струм головного LDO-стабілізатора: `I_source = 0.5 А`
- Тривалість імпульсу передачі: `t_pulse = 577 мкс = 577 · 10⁻⁶ с`

**Крок 1: Розрахунок цільового значення ESR**

```
ESR_max = ΔV_max / I_peak
= 0.3 В / 2.0 А       [підстановка: ΔV_max = 0.3 В, I_peak = 2.0 А]
= 0.150 Ом = 150 мОм  [обчислення максимального допустимого опору]

ESR_target = 0.35 · 150 мОм = 52.5 мОм  [запас: виділення 35% бюджету просадки]
```

Обираємо танталовий полімерний конденсатор або масив керамічних конденсаторів із сумарним `ESR = 40 мОм` (0.040 Ом).

**Крок 2: Обчислення падіння напруги на активному опорі**

```
ΔV_ESR = I_peak · ESR
= 2.0 А · 0.040 Ом  [підстановка: I_peak = 2.0 А, ESR = 0.040 Ом]
= 0.080 В = 80 мВ   [омічна сходинка напруги на початку імпульсу]
```

**Крок 3: Визначення залишкового бюджету на ємнісний розряд**

```
ΔV_C_allowed = ΔV_max - ΔV_ESR
= 300 мВ - 80 мВ    [підстановка: повний бюджет 300 мВ мінус падіння на ESR]
= 220 мВ = 0.220 В  [залишок для ємнісного розряду конденсатора]
```

**Крок 4: Розрахунок мінімальної номінальної ємності**

```
C_min = ((I_peak - I_source) · t_pulse) / ΔV_C_allowed
= ((2.0 А - 0.5 А) · 577 · 10⁻⁶ с) / 0.220 В  [підстановка: дефіцит струму 1.5 А, час 577 мкс]
= (1.5 А · 577 · 10⁻⁶ с) / 0.220 В            [обчислення заряду дефіциту]
= 0.0008655 Кл / 0.220 В                      [ділення сумарного заряду на допустиму напругу]
= 0.003934 Ф ≈ 3934 мкФ                       [мінімальна ємність при повільному стабілізаторі]
```

Якщо стабілізатор встигає повністю підняти струм за час реакції `t_resp = 30 мкс`, то після 30 мкс дефіцит струму зникає (`I_source` досягає 2.0 А, якщо це дозволяє його струмовий ліміт). Проте якщо стабілізатор обмежений величиною 0.5 А апаратно, вся різниця 1.5 А тягнеться повні 577 мкс, вимагаючи майже 4000 мкФ.

Якщо ж стабілізатор здатний видати повні 2.0 А після перехідного процесу за `t_resp = 30 мкс`, інтеграл дефіциту заряду стає значно меншим:

```
ΔQ_fast = 0.5 · I_peak · t_resp
= 0.5 · 2.0 А · 30 · 10⁻⁶ с  [трикутна апроксимація перехідного процесу]
= 30 · 10⁻⁶ Кл = 30 мкКл     [дефіцит заряду до виходу LDO на робочий режим]

C_min_fast = ΔQ_fast / ΔV_C_allowed
= 30 · 10⁻⁶ Кл / 0.220 В     [ділення заряду на залишковий бюджет напруги]
= 136.3 мкФ                  [необхідна ємність при швидкому стабілізаторі]
```

Це демонструє колосальну залежність: швидкий стабілізатор із широкою смугою пропускання зменшує вимогу до буферної ємності з 4000 мкФ до 150–220 мкФ.

### Поправкові коефіцієнти реальних компонентів

Номінальна ємність, указана на маркуванні компонента, не дорівнює ефективній ємності в робочих умовах. При проектуванні конденсаторного банку застосовують чотири коригувальні фактори:

```
C_nominal = C_min / (k_bias · k_temp · k_aging · k_tol)
```

1. **DC Bias ефект кераміки (k_bias):** керамічні діелектрики класу 2 (X5R, X7R) різко втрачають проникність під дією постійної напруги зміщення. Для конденсатора 10 мкФ типорозміру 0603 на напругу 6.3 В при робочій напрузі 3.8 В реальна ємність падає на 50–70% (`k_bias = 0.35..0.50`). Для танталових і полімерних конденсаторів цей ефект відсутній (`k_bias = 1.0`).
2. **Температурний коефіцієнт (k_temp):** у діапазоні від -40 °C до +85 °C для матеріалу X7R ємність змінюється в межах ±15% (`k_temp = 0.85`).
3. **Виробничий допуск (k_tol):** стандартний допуск промислових конденсаторів становить ±20% (`k_tol = 0.80`).
4. **Старіння діелектрика (k_aging):** втрата близько 1.5–2% ємності на декаду часу для титанату барію (`k_aging = 0.95`).

Підсумковий коефіцієнт запасу для керамічного банку становить:

```
k_total_ceramic = 0.40 · 0.85 · 0.80 · 0.95 = 0.258
```

Отже, якщо розрахунок дав `C_min_fast = 136 мкФ`, сумарна номінальна керамічна ємність за специфікацією повинна складати не менше:

```
C_nominal_ceramic = 136 мкФ / 0.258 = 527 мкФ
```

Оптимальне інженерне рішення полягає в паралельному комбінуванні:
- Один полімерний танталовий конденсатор `150 мкФ / 6.3 В` з гарантованим `ESR = 35 мОм` (не чутливий до DC-bias).
- Три керамічні конденсатори `22 мкФ / 10 В` X7R типорозміру 0805 для придушення високочастотних складових та зниження сумарного ESR.
- Два керамічні конденсатори `0.1 мкФ` 0402 безпосередньо біля виводів живлення модуля для фільтрації радіочастотних наведень.
