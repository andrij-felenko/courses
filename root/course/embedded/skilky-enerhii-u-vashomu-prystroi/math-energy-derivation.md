# 🧮 Виведення енергетичних рівнянь та динаміки розряду

Накопичення та вивільнення енергії в електричних, магнітних і хімічних підсистемах вбудованих пристроїв підпорядковуються фундаментальним диференціальним рівнянням поля і термодинаміки. Нижче наведено суворе математичне виведення енергетичних інтегралів, розрахунок перехідних процесів розряду конденсаторів, динаміку спаду струму в індуктивностях, аналітичну модель демпфування RC-снабера та теплові моделі акумуляторів при аварійних режимах.

## 1. Інтеграл енергії електричного поля конденсатора

Конденсатор накопичує енергію за рахунок просторового розділення електричних зарядів під дією прикладеної різниці потенціалів. Миттєва потужність `p(t)`, що надходить у конденсатор ємністю `C`, визначається добутком миттєвої напруги `v(t)` на миттєвий струм `i(t)`.

Оскільки струм через ідеальну ємність пов'язаний зі швидкістю зміни напруги як `i(t) = C · (dv/dt)`, повна робота `E_C`, витрачена на заряд конденсатора від нульової напруги до кінцевого потенціалу `V`, є інтегралом миттєвої потужності за часом:

```
E_C = ∫₀^T p(t) dt               [означення повної роботи джерела]
    = ∫₀^T v(t) · i(t) dt        [підстановка миттєвої потужності p = v · i]
    = ∫₀^T v(t) · (C · dv/dt) dt [зв'язок струму і напруги ємності i = C · dv/dt]
    = C · ∫₀^V v dv              [перехід від інтегрування за часом до напруги]
    = C · [v² / 2]₀^V            [первісна від лінійної функції v]
    = 0.5 · C · V²               [підстановка меж інтегрування: кінцева енергія в Дж]
```

Якщо конденсатор розряджається від початкової напруги `V_init` до залишкової напруги `V_final`, вивільнена в навантаження або тіло людини енергія становить різницю квадратів:

```
ΔE_C = 0.5 · C · (V_init² - V_final²)  [енергія, вивільнена за час розряду]
```

Звідси випливає фундаментальна залежність: небезпека конденсатора пропорційна **квадрату напруги**, тому подвоєння напруги збільшує накопичену руйнівну енергію в чотири рази при тій самій ємності.

## 2. Термодинамічний парадокс заряду ємності: втрата 50% енергії

Розглянемо процес заряду конденсатора ємністю `C` від джерела постійної напруги `V_src` через опір підвідних провідників або обмежувального резистора `R`.

Струм у контурі змінюється за експоненційним законом `i(t) = (V_src / R) · exp(-t / (R · C))`.
Повна енергія `E_src`, віддана джерелом живлення за весь час заряду від `0` до нескінченності:

```
E_src = ∫₀^∞ V_src · i(t) dt                                   [енергія джерела]
      = V_src · ∫₀^∞ (V_src / R) · exp(-t / (R · C)) dt        [підстановка струму]
      = (V_src² / R) · [- R · C · exp(-t / (R · C))]₀^∞        [інтегрування експоненти]
      = (V_src² / R) · (0 - (- R · C · 1))                     [підстановка меж 0 та ∞]
      = C · V_src²                                             [повна енергія джерела]
```

Оскільки в електричному полі конденсатора накопичується лише `E_C = 0.5 · C · V_src²`, енергія `E_loss`, розсіяна у вигляді тепла на резисторі та паразитних опорах доріжок:

```
E_loss = E_src - E_C                      [закон збереження енергії]
       = C · V_src² - 0.5 · C · V_src²    [різниця енергій]
       = 0.5 · C · V_src²                 [теплові втрати в контурі]
```

Цей результат не залежить від величини опору `R`: незалежно від того, чи заряджається конденсатор через резистор 1 Ом чи 100 кОм, рівно половина енергії джерела неминуче перетворюється на тепло під час прямого комутаційного заряду.

## 3. Інтеграл енергії магнітного поля індуктивності

Індуктивний елемент (котушка реле, соленоїд, обмотка електродвигуна) накопичує енергію у векторному магнітному полі при протіканні струму. За законом електромагнітної індукції Фарадея, зміна струму в індуктивності `L` породжує електрорушійну силу самоіндукції `e(t) = -L · (di/dt)`.

Для подолання проти-ЕРС джерело живлення має прикласти протилежну напругу `v(t) = L · (di/dt)`. Повна енергія `E_L`, передана магнітному полю під час наростання струму від `0` до усталеного значення `I`, розраховується інтегруванням:

```
E_L = ∫₀^T p(t) dt               [повна робота створення магнітного поля]
    = ∫₀^T v(t) · i(t) dt        [миттєва потужність електричного кола]
    = ∫₀^T (L · di/dt) · i(t) dt [прикладена напруга v = L · di/dt]
    = L · ∫₀^I i di              [перехід до інтегрування за струмом]
    = L · [i² / 2]₀^I            [первісна струму]
    = 0.5 · L · I²               [накопичена енергія магнітного поля в Дж]
```

При раптовому розриві кола (`dt → 0`) магнітне поле колапсує, змушуючи накопичену енергію `E_L` миттєво трансформуватися у високовольтний електричний потенціал на розімкнених клемах.

## 4. Диференціальне рівняння та час розряду RC-кола

Розглянемо замкнений контур, що складається з конденсатора ємністю `C` із початковою напругою `V_0` та паралельного розрядного резистора `R` (Bleeder resistor).

За першим законом Кірхгофа, сума струмів у вузлі дорівнює нулю:

```
i_C(t) + i_R(t) = 0             [перший закон Кірхгофа]
C · (dv/dt) + v(t) / R = 0      [диференціальне рівняння розряду]
dv / v = -dt / (R · C)          [розділення змінних]
```

Інтегруючи обидві частини рівняння від часу `t = 0` (де `v(0) = V_0`) до довільного моменту `t`:

```
∫_{V_0}^{v(t)} (1/v) dv = - (1 / (R · C)) · ∫₀^t dt [інтегрування лівої і правої частин]
ln(v(t) / V_0) = - t / (R · C)                       [логарифмічна форма розв'язку]
v(t) = V_0 · exp(-t / (R · C))                       [експоненційний закон розряду]
```

Постійна часу кола позначається як `τ = R · C`.

Для забезпечення вимог електробезпеки (стандарт IEC 62368-1) напруга на вимкненому пристрої повинна знизитися від початкового рівня `V_0` до безпечної наднизької напруги `V_safe` (зазвичай `V_safe ≤ 50 В` DC) за регламентований час `t_safe` (1–5 секунд).

Виведемо необхідний максимальний опір розрядного резистора `R_max`:

```
V_safe = V_0 · exp(-t_safe / (R · C))               [підстановка безпечного порогу]
exp(t_safe / (R · C)) = V_0 / V_safe                 [інверсія експоненти]
t_safe / (R · C) = ln(V_0 / V_safe)                  [логарифмування]
R_max = t_safe / (C · ln(V_0 / V_safe))              [формула розрахунку номіналу розрядника]
```

Постійні теплові втрати потужності `P_loss` на цьому резисторі під час штатної роботи пристрою під напругою `V_0` складають:

```
P_loss = V_0² / R_max  [постійна теплова потужність розсіювання]
```

## 5. Динаміка спаду струму в індуктивності з діодом та стабілітроном

При закритті силового ключа, що комутує індуктивне навантаження з активним опором обмотки `R_coil`, струм `i(t)` замикається через захисне коло. Порівняємо два варіанти захисту: звичайний діод вільного ходу та послідовну пару «діод + стабілітрон» (Zener clamp).

### Варіант А: Діод вільного ходу (Flyback Diode)

Диференціальне рівняння контуру розмагнічування з урахуванням прямого падіння напруги на діоді `V_F`:

```
L · (di/dt) + R_coil · i(t) + V_F = 0  [рівняння стану контуру]
di / dt + (R_coil / L) · i = -V_F / L  [лінійне неоднорідне ДР першого порядку]
```

Розв'язок рівняння для початкового струму `i(0) = I_0`:

```
i(t) = (I_0 + V_F / R_coil) · exp(-t / τ_L) - V_F / R_coil  [загальний розв'язок]
τ_L = L / R_coil                                             [постійна часу індуктивності]
```

Оскільки пряме падіння на кремнієвому діоді мале (`V_F ≈ 0.7 В`), спад струму визначається головним чином власним опором котушки `R_coil`. Час повного згасання струму `t_decay`:

```
t_decay ≈ (3 … 5) · (L / R_coil)  [тривалий спад струму, затримка відпускання реле]
```

### Варіант Б: Діод + Стабілітрон (Zener Clamp)

У контур додається стабілітрон із напругою стабілізації `V_Z`. Рівняння набуває вигляду:

```
L · (di/dt) + R_coil · i(t) + (V_Z + V_F) = 0  [контур із високою напругою гасіння]
```

Якщо напруга стабілізації значно перевищує спад на активному опорі (`V_Z >> I_0 · R_coil`), швидкість зміни струму стає майже сталою:

```
di / dt ≈ - (V_Z + V_F) / L  [майже лінійний крутий спад струму]
t_quench ≈ (L · I_0) / (V_Z + V_F)  [час форсованого згасання магнітного поля]
```

Форсоване гасіння зменшує час відпускання контактів реле в 10–50 разів, запобігаючи виникненню руйнівної електричної дуги між механічними контактами.

## 6. Розрахунок демпфування паразитного коливального контуру (RC-снабер)

При розмиканні індуктивного кола паразитна індуктивність монтажу або розсіювання трансформатора `L_par` утворює з паразитною вихідною ємністю силового транзистора `C_par` паралельний LC-контур другого порядку. Без демпфування в контурі виникають високочастотні коливання (дзвоніння) з резонансною частотою:

```
f_res = 1 / (2 · π · √(L_par · C_par))  [частота паразитного дзвоніння]
```

Щоб подавити резонансний викид напруги, паралельно ключу встановлюють послідовний RC-снабер (`R_snub`, `C_snub`). Диференціальне рівняння контуру другого порядку набуває вигляду:

```
d²v/dt² + 2 · α · (dv/dt) + ω₀² · v = 0  [рівняння затухаючих коливань]
ω₀ = 1 / √(L_par · C_par)                [власна кутова частота контуру]
α = R_snub / (2 · L_par)                 [коефіцієнт затухання]
```

Критичний коефіцієнт демпфування `ζ = 1` досягається при характеристичному опорі контуру:

```
R_crit = 2 · √(L_par / C_par)  [критичний опір безперегинного аперіодичного розряду]
```

Інженерна методика розрахунку снабера:
1. Ємність снабера обирають у 2–4 рази більшою за власну паразитну ємність ключа: `C_snub ≈ (2 … 4) · C_par`.
2. Резистор снабера обирають рівним характеристичному опору нового контуру: `R_snub = √(L_par / C_snub)`.
3. Потужність, розсіювана на резисторі снабера при частоті комутації `f_sw`: `P_snub = C_snub · V_peak² · f_sw`.

## 7. Адіабатична теплова модель короткого замикання акумулятора

Під час металевого короткого замикання акумуляторної батареї з еквівалентним внутрішнім опором `R_int` та напругою холостого ходу `V_oc` виникає піковий струм `I_sc`:

```
I_sc = V_oc / (R_int + R_ext)  [струм короткого замикання за законом Ома]
```

У перші секунди КЗ тепловіддача в навколишнє середовище не встигає розвинутися, тому нагрів комірки розглядається як строго **адіабатичний** процес. Уся розсіяна всередині комірки електрична енергія перетворюється на внутрішню теплову енергію маси `m` із питомою теплоємністю `c_p`:

```
dQ_heat = I_sc² · R_int · dt           [диференціал виділеного тепла Джоуля-Ленца]
dQ_heat = m · c_p · dT                 [термодинамічне рівняння нагріву тіла]
m · c_p · dT = I_sc² · R_int · dt      [рівність теплових потоків в адіабатичному режимі]
dT / dt = (I_sc² · R_int) / (m · c_p)  [швидкість самонагріву комірки в °C/с]
```

Інтегруючи за часом від початкової температури `T_0` до критичної температури початку термічного розпаду пасивуючої плівки SEI (`T_crit ≈ 80 … 100 °C`):

```
ΔT_crit = T_crit - T_0                                     [критичний перепад температури]
t_thermal_runaway = (m · c_p · ΔT_crit) / (I_sc² · R_int)   [час до настання теплового розгону]
```

### Числовий приклад адіабатичного нагріву елемента 18650

Для стандартного Li-ion елемента типорозміру 18650 масою `m = 0.045 кг`, питомою теплоємністю `c_p ≈ 1000 Дж / (кг · °C)`, внутрішнім опором `R_int = 20 мОм = 0.020 Ом` та напругою `V_oc = 4.0 В`:

```
I_sc = 4.0 / 0.020 = 200 А              [струм КЗ]
P_int = 200² · 0.020 = 800 Вт           [внутрішня теплова потужність]
dT/dt = 800 / (0.045 · 1000) ≈ 17.8 °C/с [темп нагріву]
```

При початковій температурі `T_0 = 25 °C` перегрів до критичної точки `T_crit = 85 °C` (`ΔT = 60 °C`) відбувається за:

```
t_runaway = 60 / 17.8 ≈ 3.37 с  [час до незворотної термічної деградації]
```

## 8. Неадіабатична теплова модель: конвективний теплообмін

При тривалому струмовому перевантаженні (наприклад, розряд струмом 3C–5C) тепловіддача через поверхню корпусу площею `A` з коефіцієнтом тепловіддачі `h` (при природній конвекції повітря `h ≈ 10 … 25 Вт / (м² · °C)`) вступає в дію за законом охолодження Ньютона-Ріхмана:

```
m · c_p · (dT/dt) = P_gen - h · A · (T(t) - T_amb)  [диференціальне рівняння теплового балансу]
P_gen = I_load² · R_int                             [внутрішнє джоулеве тепловиділення]
```

Розв'язок цього лінійного рівняння відносно перегріву `θ(t) = T(t) - T_amb`:

```
θ(t) = θ_max · (1 - exp(-t / τ_th))  [крива нагріву акумулятора]
θ_max = P_gen / (h · A)              [граничний установившийся перегрів у стаціонарному режимі]
τ_th = (m · c_p) / (h · A)           [теплова постійна часу комірки (зазвичай 300–800 с)]
```

Якщо струм навантаження такий, що `T_amb + θ_max > 60 °C`, акумулятор неминуче деградує за рахунок прискореного наростання внутрішнього опору та газоутворення, навіть якщо аварійного короткого замикання не відбулося.
