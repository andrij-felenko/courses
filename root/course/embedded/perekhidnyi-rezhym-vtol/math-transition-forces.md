# 🧮 Баланс сил, перехідний коридор та динамічний тиск VTOL

Ця вставка містить аналітичне виведення балансу сил, кінематики розгону, поздовжнього балансування та законів масштабування авторитету керування для комбінованого безпілотного апарата вертикального зльоту та посадки (VTOL) під час проходження перехідного коридору швидкостей.

Розуміння точного математичного зв'язку між квадратичним зростанням підйомної сили крила, спаданням тяги підйомних роторів, зміщенням аеродинамічного фокуса та динамічним тиском дозволяє розрахувати мінімальну дистанцію переходу, уникнути від'ємного вертикального прискорення та запобігти насиченню контурів стабілізації.

---

### 1. Межі перехідного коридору швидкостей

Політ апарата масою `m` у спокійній атмосфері з густиною повітря `ρ` визначається двома критичними швидкостями: швидкістю звалювання крила `V_stall` та безпечною швидкістю завершення переходу `V_trans`.

Підйомна сила крила площею `S` з максимальним коефіцієнтом підйомної сили `C_L_max` на критичному куті атаки `α_crit` задається формулою:

```
L_max = 0.5 · ρ · V² · S · C_L_max
```

Швидкість звалювання `V_stall` відповідає умові, коли максимальна підйомна сила крила здатна врівноважити повну силу тяжіння апарата `m · g`:

```
0.5 · ρ · V_stall² · S · C_L_max = m · g                                   [рівновага підйомної сили та ваги]
V_stall²                         = (2 · m · g) / (ρ · S · C_L_max)        [вираження квадрата швидкості]
V_stall                          = √((2 · m · g) / (ρ · S · C_L_max))     [добування квадратного кореня]
```

Безпечна швидкість завершення переходу `V_trans` обирається з урахуванням запасу за кутом атаки на випадок турбулентності та маневрування (коефіцієнт безпеки `k_safe = 1.15 ÷ 1.30`, типово `k_safe = 1.2`):

```
V_trans = k_safe · V_stall                          [коефіцієнт безпеки від звалювання]
        = 1.20 · √((2 · m · g) / (ρ · S · C_L_max)) [підстановка формули швидкості звалювання]
```

Нижня межа початку змішування керування `V_blend_start` відповідає моменту, коли динамічний тиск стає достатнім для створення вимірюваного аеродинамічного моменту на рульових поверхнях (типово `V_blend_start ≈ 0.4 · V_trans`).

### 2. Баланс сил та вертикальне прискорення при переході

Під час прямого переходу на апарат одночасно діють вертикальна підйомна сила крила `L(v)` та сумарна тяга підйомних гвинтів `T_v(v)`.

Рівняння руху за вертикальною віссю `Z` (напрямленій вгору) має вигляд:

```
m · a_z = L(v) + T_v(v) - m · g                    [сума вертикальних сил за другим законом Ньютона]
a_z(v)  = (L(v) + T_v(v)) / m - g                  [виведення вертикального прискорення]
```

Для підтримання строго горизонтальної траєкторії (`a_z = 0`) вертикальна тяга роторів повинна точно компенсувати дефіцит підйомної сили крила:

```
T_v_req(v) = m · g - L(v)                          [компенсація дефіциту сили крила]
           = m · g - 0.5 · ρ · v² · S · C_L(α)     [підстановка квадратичної підйомної сили]
```

Враховуючи, що на швидкості переходу `V_trans` підйомна сила на номінальному крейсерському куті атаки дорівнює повній вазі `L(V_trans) = m · g`, відносна підйомна сила змінюється квадратично:

```
L(v) / (m · g) = (v / V_trans)²                    [відношення сили крила до ваги]
```

Звідси ідеальний закон спадання вертикальної тяги:

```
T_v_req(v) = m · g · (1 - (v / V_trans)²)          [закон розвантаження для v ∈ [0, V_trans]]
```

#### Розрахунок дефіциту тяги при передчасному вимкненні

Якщо підйомні двигуни вимикаються на швидкості `v_cut < V_trans`, вертикальна тяга `T_v` миттєво стає рівною нулю. Тоді вертикальне прискорення (провал):

```
a_z = g · ((v_cut / V_trans)² - 1)                 [вертикальне прискорення при v_cut < V_trans]
```

**Числовий приклад:**
Нехай `V_trans = 16 м/с`, а ротори вимкнули на `v_cut = 10 м/с`:

```
a_z = 9.81 · ((10 / 16)² - 1)  [підстановка v_cut = 10 м/с та V_trans = 16 м/с]
    = 9.81 · (0.3906 - 1)       [обчислення квадрата відношення швидкостей]
    = 9.81 · (-0.6094)          [віднімання одиниці, дефіцит 60.9%]
    = -5.98 м/с²                [множення на прискорення вільного падіння g]
```

Апарат набуває від'ємного вертикального прискорення близько `0.61 g`. За інтервал часу `t = 1.5 с` без підхвату вертикальна швидкість падіння досягає `v_z = a_z · t = -8.97 м/с`, а втрата висоти становить:

```
Δh = 0.5 · a_z · t²             [інтегрування прискорення за часом]
   = 0.5 · 5.98 · (1.5)²        [підстановка a_z = 5.98 м/с² та t = 1.5 с]
   = 6.73 м                     [кінцева втрата висоти без підхвату]
```

### 3. Кінематика горизонтального розгону та довжина дистанції

Горизонтальне прискорення `a_x` забезпечується маршовим штовхачем або горизонтальною проєкцією нахилених роторів `T_h` за вирахуванням повного аеродинамічного лобового опору `D(v)`:

```
m · (dv / dt) = T_h(v) - D(v)                      [рівняння руху за віссю X]
```

Повний опір `D(v)` гібридного апарата складається з паразитного опору планера `D_0`, індуктивного опору крила `D_ind` та додаткового опору нерухомих підйомних гвинтів і балок `D_rot`:

```
D(v) = 0.5 · ρ · v² · S · (C_D0 + C_D_rot + C_L² / (π · e · AR))
```

де:
* `C_D0` — коефіцієнт паразитного опору фюзеляжу та крила;
* `C_D_rot` — еквівалентний коефіцієнт опору зупинених гвинтів та опорних труб;
* `AR = b² / S` — подовження крила (aspect ratio);
* `e` — коефіцієнт Освальда (ефективність форми крила).

Диференціал часу розгону від `0` до `V_trans`:

```
dt = m / (T_h(v) - D(v)) · dv                      [диференціал часу розгону]
t_trans = ∫ [від 0 до V_trans] (m / (T_h(v) - D(v))) dv [повний час переходу]
```

Для спрощеного інженерного розрахунку з постійною середньою надлишковою тягою `ΔT_avg = T_h_avg - D_avg`:

```
a_x_avg = ΔT_avg / m                                       [середнє прискорення за другим законом Ньютона]
t_trans ≈ V_trans / a_x_avg                                [оцінка часу розгону до швидкості переходу]
s_trans ≈ 0.5 · a_x_avg · t_trans² = V_trans² / (2 · a_x_avg) [оцінка пройденої дистанції розгону]
```

**Приклад розрахунку дистанції:**
Для апарата масою `m = 8 кг`, тяги маршового двигуна `T_h = 24 Н`, середнього опору `D_avg = 6 Н` та `V_trans = 15 м/с`:

```
ΔT_avg  = 24 - 6 = 18 Н                     [надлишкова середня тяга штовхача]
a_x_avg = 18 / 8 = 2.25 м/с²                [середнє горизонтальне прискорення]
t_trans = 15 / 2.25 = 6.67 с                [тривалість прямого переходу]
s_trans = 15² / (2 · 2.25) = 50.0 м         [дистанція перехідного коридору]
```

### 4. Нелінійне перерахування тяги в сигнал газу ESC

Статична тяга безколекторного мотора з повітряним гвинтом пропорційна квадрату кутової швидкості обертання `Ω²`, яка у першому наближенні лінійно залежить від середньої напруги, що подається контролером швидкості (ESC):

```
T_rotor = C_T · ρ · Ω² · D_prop⁴                   [аеродинамічна тяга повітряного гвинта]
Ω       = K_v · U_eff = K_v · U_bat · Throttle     [зв'язок обертів із напругою та газом]
T_rotor ∝ Throttle²                                [квадратична залежність тяги від газу]
```

Тому лінійне зменшення сигналу газу `Throttle(v) = 1 - v / V_trans` призводить до надмірно швидкого падіння сили тяги на початку переходу:

```
T_v_linear(v) = m · g · (1 - v / V_trans)²         [падіння тяги при лінійному керуванні]
```

Замість необхідного падіння `T_v_req = m · g · (1 - (v / V_trans)²)`.
При `v = 0.5 · V_trans` лінійний газ дасть тягу `T = m · g · (0.5)² = 0.25 m · g`, тоді як крило створює лише `L = 0.25 m · g`. Сумарна підйомна сила складе `0.50 m · g` — виникає 50% дефіцит сили тяжіння!

Щоб тяга відповідала теоретичному балансу сил, команда керування газом підйомних моторів повинна лінеаризувати залежність за квадратним коренем:

```
Throttle_cmd(v) = √( T_v_req(v) / T_max )                                      [лінеаризація сигналу газу]
                = √((m · g) / T_max) · √( 1 - (v / V_trans)² )                 [команда газу для квадроплана]
```

### 5. Динамічний тиск та масштабування коефіцієнтів PID

Керівний момент `M_aero`, що створюється аеродинамічною поверхнею (елероном чи кермом висоти) з площею `S_surf` та кутом відхилення `δ`, прямо пропорційний динамічному тиску потоку `q = 0.5 · ρ · v²`:

```
M_aero(v, δ) = q · S · c_chord · C_m_delta · δ                                 [аеродинамічний момент рульової поверхні]
             = 0.5 · ρ · v² · S · c_chord · C_m_delta · δ                      [розгортання формули динамічного тиску]
```

Оскільки кутове прискорення літака `ε = M_aero / I_yy`, ефективність однакового відхилення руля `δ` на швидкості `24 м/с` у `16 разів вища`, ніж на швидкості `6 м/с`:

```
(M_aero(24) / M_aero(6)) = (24 / 6)² = 4² = 16                                [відношення моментів при зміні швидкості]
```

Щоб передавальна функція замкненого контуру стабілізації кутової швидкості залишалася стабільною за змінної швидкості польоту, коефіцієнт пропорційного підсилення регулятора `K_p` повинен масштабуватися обернено пропорційно квадрату приладової швидкості відносно базової швидкості калібрування `V_calib`:

```
K_p_scaled(v) = K_p_calib · (V_calib / max(v, V_min_scale))²                  [масштабування підсилення PID за тиском q]
```

де `V_min_scale` обмежує коефіцієнт знизу для запобігання нескінченному зростанню підсилення при нульовій швидкості.

### 6. Поздовжнє балансування та зміщення фокуса крила

У міру розгону безпілотника розподіл аеродинамічного навантаження змінює повний поздовжній момент літака `M_pitch` відносно центру мас `CG`.

Сумарний момент тангажу складається з чотирьох компонент:

```
M_pitch = M_wing(α, q) + M_tail(q, δ_e) + z_push · T_push + Δx_rotors · ΔT_v   [баланс поздовжніх моментів]
```

де:
* `M_wing = q · S · c_chord · (C_m0 + C_L · (x_CG - x_AC) / c_chord)` — момент крила, де `x_AC` — координата аеродинамічного фокуса;
* `M_tail = q · S_tail · l_tail · C_L_tail(δ_e)` — відновлювальний момент горизонтального оперення;
* `z_push · T_push` — плече тяги маршового двигуна відносно вертикальної координати центру мас;
* `Δx_rotors · ΔT_v = (T_rear - T_front) · d_rotor` — поздовжній диференціал тяги підйомних роторів.

Під час розгону прискорення `a_x` вимагає від штовхача максимальної тяги `T_push`. Якщо вісь двигуна проходить вище центру мас (`z_push > 0`), виникає паразитичний пікіруючий момент. Для його компенсації в режимі висіння автопілот перерозподіляє тягу роторів (`T_front > T_rear`).

У міру зростання швидкості `v` ротори розвантажуються (`T_v → 0`), і обов'язок поздовжнього балансування переходить до керма висоти `δ_e`. Необхідний балансувальний кут відхилення елеватора:

```
δ_e_trim(v) = - (M_wing(v) + z_push · T_push) / (q(v) · S_tail · l_tail · C_L_delta_e)
```

На швидкостях `v < V_blend_start` знаменник прямує до нуля, тому кермо висоти не може врівноважити момент тяги штовхача. Будь-яка спроба вимкнути передні ротори до досягнення швидкості `V_trans` призводить до миттєвого опускання або задирання носа апарата.

### 7. Збільшення швидкості звалювання при маневруванні в переході

Якщо під час проходження перехідного коридору апарат здійснює розворот із кутом крену `ϕ`, потрібна підйомна сила крила зростає для компенсації відцентрової сили:

```
L_req = (m · g) / cos(ϕ) = n_z · m · g                                        [потрібна підйомна сила у віражі]
```

де `n_z = 1 / cos(ϕ)` — коефіцієнт перевантаження (*load factor*).

Швидкість звалювання крила при наявності крену збільшується пропорційно квадратному кореню з перевантаження:

```
V_stall_bank = V_stall · √(n_z) = V_stall / √(cos(ϕ))                          [швидкість звалювання у крені]
```

**Розрахунок впливу кута крену:**
При крені `ϕ = 45°` перевантаження становить `n_z = 1 / cos(45°) = 1.414`, а швидкість звалювання зростає на 19%:

```
V_stall_45 = 13.0 · √(1.414)                                                  [підстановка V_stall = 13 м/с]
           = 13.0 · 1.189                                                     [обчислення кореня з перевантаження]
           = 15.46 м/с                                                        [збільшена швидкість звалювання]
```

Якщо швидкість завершення переходу `V_trans` була налаштована на 15.0 м/с для прямолінійного польоту, крен 45° у момент вимкнення роторів призведе до зриву потоку з крила.
*Правило проектування:* Під час перехідного режиму автопілот повинен суворо обмежувати кут крену значенням `ϕ_max ≤ 15° ÷ 20°`.

### 8. Енергетичний бюджет переходу

Порівняння витрат енергії під час розгону дозволяє оптимізувати темп переходу `a_x`.

Електрична потужність підйомних роторів `P_hover` та маршового штовхача `P_push`:

```
P_hover(t) = P_hover_0 · (T_v(t) / (m · g))^(1.5)                              [потужність роторів за теорією ідеального рушія]
P_push(t)  = (T_push · v(t)) / η_prop + P_elec_loss                           [потужність маршового двигуна]
```

Сумарна енергія, витрачена акумулятором на виконання переходу тривалістю `t_trans`:

```
E_trans = ∫ [від 0 до t_trans] (P_hover(t) + P_push(t)) dt                    [інтеграл повної спожитої енергії]
```

Швидкий перехід з високим прискоренням `a_x = 3.0 м/с²` скорочує час небезпечного висіння `t_trans` до `5.0 с`, заощаджуючи до 40% енергії порівняно з повільним розгоном з `a_x = 1.0 м/с²` (`t_trans = 15.0 с`), де підйомні двигуни тривалий час працюють на високих струмах.

### 9. Підсумковий довідник формул переходу

| Параметр | Формула | Фізичне призначення |
|---|---|---|
| Швидкість звалювання `V_stall` | `√((2 · m · g) / (ρ · S · C_L_max))` | Фізична нижня межа польоту на крилі |
| Швидкість переходу `V_trans` | `1.20 · V_stall` | Поріг повного вимкнення підйомних роторів |
| Необхідна тяга роторів `T_v(v)` | `m · g · (1 - (v / V_trans)²)` | Забезпечення горизонтального польоту `a_z = 0` |
| Команда газу ESC | `Throttle_hover · √(1 - (v / V_trans)²)` | Лінеаризація нелінійної тяги роторів |
| Масштабування PID рулів | `K_p0 · (V_calib / v)²` | Компенсація динамічного тиску `q = 0.5 · ρ · v²` |
| Звалювання у віражі | `V_stall / √(cos(ϕ))` | Врахування зростання перевантаження у крені |
| Балансувальний елеватор | `δ_e_trim(v) ∝ 1 / q(v)` | Компенсація паразитного моменту штовхача |
