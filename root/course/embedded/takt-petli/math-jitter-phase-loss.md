# 🧮 Математика часового джитера та фазового зсуву затримки транспорту

Ця вставка розгортає повний математичний апарат дискретизації контурів керування: строгий аналітичний зв'язок між часовим джитером такту вибірки, спектральним фазовим відставанням екстраполятора нульового порядку (ZOH), накладанням спектрів (аліасингом) та неминучою деградацією запасу стійкості за фазою.

---

### 1. Дискретизація аналогового ПІД-регулятора

Неперервний закон пропорційно-інтегрально-диференціального керування в часовій області описується класичним інтегро-диференціальним рівнянням неперервного часу:

```
u(t) = Kp · e(t) + Ki · ∫ e(τ) dτ + Kd · (de(t) / dt)
```

У частотній області перетворення Лапласа передатна функція ідеального неперервного регулятора має вигляд:

```
C(s) = Kp + Ki / s + Kd · s
```

Для чисельної реалізації в цифровому обчислювачі неперервний часовий континуум замінюється дискретною послідовністю відліків `t[k] = k · Ts`, де `Ts` — період квантування (`dt`), а `k = 0, 1, 2, ...` — цілочисельний індекс кроку.

#### Метод зворотної різниці Ейлера (Backward Euler)
Оператор диференціювання Лапласа `s` замінюється першою різницею назад:

```
s ≈ (1 − z^(−1)) / Ts

Інтегрувальна ланка (1 / s):
1 / s ≈ Ts / (1 − z^(−1))
I[k] = I[k−1] + Ki · Ts · e[k]

Диференціювальна ланка (s):
s ≈ (1 − z^(−1)) / Ts
D[k] = Kd · (e[k] − e[k−1]) / Ts
```

#### Білінійне перетворення Тастіна (Tustin / Bilinear Transform)
Метод трапецій відображає всю ліву півплощину комплексної площини `s` усередину одиничного кола z-площини без спотворення стійкості полюсів:

```
s ≈ (2 / Ts) · (1 − z^(−1)) / (1 + z^(−1))

Інтегрувальна ланка Тастіна:
I[k] = I[k−1] + (Ki · Ts / 2) · (e[k] + e[k−1])

Диференціювальна ланка з фільтром першого порядку (Tustin):
D(s) = Kd · s / (1 + Tf · s)
```

Перевага методу Тастіна полягає у відсутності фазового спотворення на середніх частотах, проте наближення до частоти Найквіста `ω_s / 2` вимагає врахування частотного стиснення (frequency pre-warping).

### 2. Стохастична модель джитера та шум диференціювання

Нехай реальний фізичний момент запуску `k`-го кроку відхиляється від ідеального математичного положення на випадкову стохастичну величину джитера `δt[k]`:

```
t[k] = k · Ts + δt[k]
δt[k] ~ N(0, σ_t^2)   [Джитер — центрований білий або слабокорельований шум]
```

Реальний часовий інтервал між двома послідовними вибірками датчика становить:

```
Δt[k] = t[k] − t[k−1] = Ts + (δt[k] − δt[k−1])
```

Якщо програмний алгоритм у мікроконтролері ділить приріст сигналу на фіксоване номінальне значення `Ts`, обчислена дискретна похідна набуває вигляду:

```
D_calc[k] = Kd · (e(t[k]) − e(t[k−1])) / Ts
```

Розкладемо значення сигналу помилки `e(t)` у ряд Тейлора навколо ідеальних точок `k · Ts` та `(k−1) · Ts`:

```
e(t[k]) = e(k·Ts) + e'(k·Ts) · δt[k] + O(δt^2)
e(t[k−1]) = e((k−1)·Ts) + e'((k−1)·Ts) · δt[k−1] + O(δt^2)
```

Підставляючи ці розклади у формулу обчисленої похідної:

```
D_calc[k] = Kd · [ e(k·Ts) − e((k−1)·Ts) + e'(k·Ts)·δt[k] − e'((k−1)·Ts)·δt[k−1] ] / Ts
```

Вважаючи, що швидкість зміни сигналу на інтервалі одного такту змінюється незначно `e'(k·Ts) ≈ e'((k−1)·Ts) = e'[k]`:

```
D_calc[k] = Kd · e'[k] + Kd · e'[k] · (δt[k] − δt[k−1]) / Ts
            \________/   \______________________________/
           Істинний D              Шум джитера
```

#### Аналітична дисперсія шуму диференціатора
Оскільки випадкові похибки `δt[k]` та `δt[k−1]` є незалежними некорельованими величинами з дисперсією `σ_t^2`:

```
Var(δt[k] − δt[k−1]) = Var(δt[k]) + Var(δt[k−1]) = 2 · σ_t^2

Var(Шум_D) = (Kd · e'[k] / Ts)^2 · 2 · σ_t^2
```

Середньоквадратичне відхилення паразитного шуму на виході D-каналу:

```
σ_D = (√2 · Kd · |e'[k]| · σ_t) / Ts
```

> 📌 **Фізичний висновок.** Амплітуда високочастотного шуму на виході диференціатора зростає прямо пропорційно модулю швидкості руху об'єкта `|e'[k]|` та зворотно пропорційно періоду дискретизації `Ts`. Чим швидший контур і чим менший крок квантування, тим небезпечнішим стає софтверне тремтіння часу виклику.

### 3. Спектральний аналіз аліасингу (накладання спектрів)

Дискретизація аналогового сигналу `x(t)` у часовій області математично еквівалентна множенню сигналу на нескінченний гребінь дельта-функцій Дірака `p(t)`:

```
p(t) = ∑[k=−∞..+∞] δ(t − k·Ts)
x_sampled(t) = x(t) · p(t) = ∑[k=−∞..+∞] x(k·Ts) · δ(t − k·Ts)
```

За теоремою про згортку у частотній області перетворення Фур'є дискретизованого сигналу `X_sampled(jω)` є згорткою спектра вхідного сигналу `X(jω)` зі спектром імпульсного гребеня `P(jω) = (2π / Ts) · ∑ δ(ω − n·ω_s)`:

```
X_sampled(jω) = (1 / Ts) · ∑[n=−∞..+∞] X(j(ω − n·ω_s))
```

де `ω_s = 2π / Ts` — кругова частота дискретизації.

Спектр дискретного сигналу містить нескінченну кількість дзеркальних повторень (сайдбендів), центрованих навколо кожної гармоніки `n · ω_s`.

```
Якщо спектр x(t) містить високочастотну гармоніку шуму ω_noise > ω_s / 2:
ω_aliased = |ω_noise − n · ω_s|   [Гармоніка незворотно потрапляє в смугу керування 0..ω_BW]
```

Оскільки операція вибірки АЦП безповоротно складає амплітуди `X(jω)` та `X(j(ω − ω_s))`, програмні цифрові фільтри після АЦП не здатні відокремити корисний сигнал від аліасингового дзеркала. Аналоговий фільтр низьких частот перед УВХ АЦП є математично необхідною умовою єдиності відновлення сигналу.

### 4. Передатна функція екстраполятора нульового порядку (ZOH)

Цифровий процесор обчислює значення керування миттєво в дискретні моменти `k·Ts`, але силовий ключ чи ЦАП повинен утримувати напругу на обмотках протягом інтервалу `Ts`. Ця операція є згорткою потоку відліків з прямокутним імпульсом тривалістю `Ts`:

```
h_zoh(t) = 1  при  0 ≤ t < Ts
h_zoh(t) = 0  при  t ≥ Ts
```

Перетворення Лапласа імпульсної характеристики ZOH:

```
G_zoh(s) = ∫[0..Ts] e^(−s·t) dt
         = [ −(1/s) · e^(−s·t) ] від 0 до Ts
         = (1 − e^(−s·Ts)) / s
```

#### Виведення частотної характеристики ZOH
Підставимо комплексну частоту `s = j·ω`:

```
G_zoh(jω) = (1 − e^(−j·ω·Ts)) / (j·ω)
          = e^(−j·ω·Ts/2) · [ e^(j·ω·Ts/2) − e^(−j·ω·Ts/2) ] / (j·ω)
          = e^(−j·ω·Ts/2) · [ 2·j · sin(ω·Ts/2) ] / (j·ω)
          = Ts · e^(−j·ω·Ts/2) · [ sin(ω·Ts/2) / (ω·Ts/2) ]
          = Ts · sinc(ω·Ts / 2) · e^(−j·ω·Ts/2)
```

Амплітудно-частотна та фазо-частотна характеристики:

```
|G_zoh(jω)| = Ts · |sinc(ω·Ts / 2)|
∠G_zoh(jω) = −ω · Ts / 2   [Фазовий зсув у радіанах]
```

Переведемо фазове запізнення в градуси:

```
Δφ_zoh(f) = −(2π·f · Ts / 2) · (180° / π) = −180° · (f / f_s)
```

> 📌 **Фазове відставання квантування.** Навіть за нульового часу виконання коду в мікроконтролері сам факт ступінчастої фіксації виходу на період `Ts` вносить еквівалентне запізнення на половину такту: `T_delay_zoh = Ts / 2`.

### 5. Повна затримка транспорту та ерозія запасу за фазою

Повний часовий тракт цифрового регулятора складається з чотирьох послідовних апаратних інтервалів:
1. `T_sample + T_conv` — тривалість захоплення заряду ємністю УВХ та SAR-конверсії АЦП;
2. `T_calc` — час виконання асемблерних інструкцій алгоритму керування в ядрі CPU;
3. `T_pwm_sync` — очікування події синхронного оновлення тіньового регістра таймера (Update Event);
4. `T_zoh` — еквівалентна затримка утримувача ЦАП/ШІМ (`Ts / 2`).

Сумарна затримка транспорту:

```
T_d = T_sample + T_conv + T_calc + T_pwm_sync + Ts / 2
```

У частотній області чиста затримка `T_d` моделюється трансцендентною ланкою:

```
W_delay(s) = e^(−s · T_d)
|W_delay(jω)| = 1
∠W_delay(jω) = −ω · T_d
```

#### Формула деградації запасу стійкості за фазою (Phase Margin Loss)
Нехай вихідна неперервна розімкнена система `L(s) = C(s) · P(s)` має частоту одиничного зрізу петлі `ω_c`, де `|L(jω_c)| = 1` (0 дБ), та неперервний запас за фазою:

```
PM_cont = 180° + ∠L(jω_c)
```

Дискретизація із сумарною затримкою `T_d` зменшує запас за фазою за лінійним законом:

```
PM_discrete = PM_cont − ω_c · T_d · (180° / π)
```

Критична гранична затримка, за якої система повністю втрачає запас стійкості (`PM_discrete ≤ 0°`) і переходить у незгасаючі автоколивання:

```
T_d_max = PM_cont / (ω_c · (180° / π)) = PM_cont / (360° · f_c)
```

### 6. Числовий інженерний розрахунок сервоприводу

Розглянемо параметри контуру регулювання швидкості тягового серводвигуна:
- Частота зрізу контуру: `f_c = 400 Гц` (`ω_c = 2π · 400 ≈ 2513 рад/с`);
- Базовий неперервний запас за фазою: `PM_cont = 55°`;
- Частота тактування контуру: `f_s = 10 кГц` (`Ts = 100 мкс`).

#### Розрахунок граничної затримки стійкості:
```
T_d_max = 55° / (360° · 400 Гц) = 55 / 144000 ≈ 381.9 мкс
```

#### Варіант 1: Апаратний детермінований контур (TRGO + ADC ISR)
- `T_sample + T_conv = 1.8 мкс`;
- `T_calc = 3.2 мкс`;
- `T_pwm_sync = 0.0 мкс` (розрахунок завершується до вершини ШІМ);
- `T_zoh = Ts / 2 = 50.0 мкс`.

```
Повна затримка:
T_d = 1.8 + 3.2 + 0.0 + 50.0 = 55.0 мкс

Втрата запасу за фазою:
Δφ = 360° · 400 Гц · 55.0·10^(−6) с = 7.92°

Реальний запас за фазою:
PM_real = 55.0° − 7.92° = 47.08°   [Стійкий контур, плавний відгук]
```

#### Варіант 2: Запуск із періодичної задачі RTOS (vTaskDelayUntil + джитер)
- `T_sample + T_conv = 15.0 мкс` (софтверний запуск);
- `T_calc = 45.0 мкс` (витіснення іншим перериванням зв'язку);
- `T_pwm_sync = 100.0 мкс` (пропуск поточної верхівки, затримка на цілий такт);
- `T_zoh = 50.0 мкс`;
- Джитер планувальника: `δt = 180.0 мкс`.

```
Повна затримка в найгіршому випадку:
T_d = 15.0 + 45.0 + 100.0 + 50.0 + 180.0 = 390.0 мкс

Втрата запасу за фазою:
Δφ = 360° · 400 Гц · 390.0·10^(−6) с = 56.16°

Реальний запас за фазою:
PM_real = 55.0° − 56.16° = −1.16°   [СИСТЕМА ВТРАЧАЄ СТІЙКІСТЬ → РЕЗОНАНСНІ АВТОКОЛИВАННЯ]
```

Математичний аналіз неспростовно доводить: стабільність контуру регулювання визначається не рядками коду, а фізичним часовим детермінізмом конвеєра обробки сигналів.
