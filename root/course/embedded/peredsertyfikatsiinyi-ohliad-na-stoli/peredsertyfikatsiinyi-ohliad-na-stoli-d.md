# Передсертифікаційний огляд на столі: бюджетний EMC-тест зондом ближнього поля, струмові кліщі, SDR

<preknowlist>
- [Електромагнітна сумісність](root:hw-pcb/electromagnetic-compatibility) — джерело завади, шлях передачі та жертва; чому пристрій не повинен заважати іншим і собі.
- [Синфазна й диференціальна завади](root:hw-analog/common-mode-noise) — як струм однакового напрямку в усіх провідниках перетворює кабелі на антени.
- [Шум імпульсного перетворювача](root:hw-power/switching-noise) — як швидке перемикання ключів dI/dt та dV/dt породжує широкосмуговий спектр гармонік.
- [Фільтри електромагнітних завад](root:embedded/emi-filter-design) — синфазні дроселі та X/Y-конденсатори для придушення кондуктивного шуму.
</preknowlist>

Пристрій зібрано, прошивку налагоджено, плата бездоганно працює на столі: мікроконтролер на 160 МГц опитує сенсори, імпульсний перетворювач живлення видає стабільні 3.3 В під змінним навантаженням, метровий джгут проводів надійно передає цифрові пакети. Зразок везуть на обов'язкову сертифікацію за стандартами CE або FCC (CISPR 32 Class B для побутової та комерційної техніки). Оренда екранованої безлунної камери з вимірювальною антеною коштує від $1500 до $3000 за робочу зміну. На першій же хвилині панорамного сканування приймач фіксує на частоті 120 МГц вузький пік, який на 3.2 дБ перевищує нормативну межу 40 дБмкВ/м на відстані 3 метри. Інженер лабораторії зупиняє тест, оформлює протокол із позначкою «FAIL», і зміна завершується: усередині камери ніхто не дозволить перепаювати компоненти навмання. Розробники втрачають вартість оренди, місяць черги на повторне вікно випробувань і стикаються з необхідністю термінового редизайну друкованої плати.

Цей сценарій — найпоширеніша і найдорожча помилка в серійному приладобудуванні, яка виникає через спробу використовувати сертифікаційну лабораторію як інструмент налагодження. Сертифікаційна безлунна камера — це ваги, а не мікроскоп: вона фіксує лише сумарну напруженість поля в дальній зоні на відстані 3 чи 10 метрів, але фізично не здатна вказати, який саме компонент, доріжка, роз'єм чи шов металевого корпусу випустили цю заваду в простір. Шукати джерело в камері — це марнування бюджету.

Щоб пройти сертифікацію з першого разу, діагностику та локалізацію всіх витоків виконують заздалегідь, безпосередньо на робочому столі розробника (*Pre-Compliance EMC Testing*, від лат. *prae* — «попереду» та *complere* — «виконувати вимоги»). Завдання попереднього лабораторного огляду полягає не в абсолютному відтворенні метрологічних умов безлунної камери, а у вирішенні чотирьох інженерних задач: знайти кожне фізичне джерело радіочастотного шуму на платі, розділити кондуктивні завади на диференційну й синфазну складові, виявити паразитні антени в джгутах підключення та забезпечити гарантований інженерний запас придушення не менше 6–10 дБ до нормативної межі. Для цього не потрібні прилади за сотні тисяч доларів: повний комплекс передсертифікаційного аудиту розгортається на базі бюджетного програмно-визначеного радіо (SDR) або портативного спектроаналізатора, зондів ближнього поля, саморобного еквівалента мережі (LISN) та струмових кліщів.

### Ближнє й дальнє поле: фізика детектування та робота з SDR

Щоб зрозуміти, чому простий контактний щуп осцилографа не підходить для пошуку випромінюваних завад, розгляньмо структуру електромагнітного поля навколо працюючої друкованої плати. Простір навколо джерела випромінювання розділяється на дві принципово різні зони: **ближнє поле** (*near-field*, реактивна зона) та **дальнє поле** (*far-field*, зона хвильового випромінювання).

Межа переходу між цими зонами визначається довжиною електромагнітної хвилі `λ` та радіальною відстанню `r` від джерела:

```
r_межа = λ / (2π) = c / (2π · f)
```

Порахуймо положення цієї межі для характерних частот роботи цифрової електроніки:

**Обчислення радіуса ближньої зони для тактових частот і гармонік перемикання:**

```
f = 30 МГц   (λ = 10 м)   →  r_межа = 10 / (2 · 3.14159) ≈ 1.59 м
f = 100 МГц  (λ = 3 м)    →  r_межа = 3 / (2 · 3.14159)  ≈ 0.48 м = 48 см
f = 300 МГц  (λ = 1 м)    →  r_межа = 1 / (2 · 3.14159)  ≈ 0.16 м = 16 см
f = 1 ГГц    (λ = 0.3 м)  →  r_межа = 0.3 / 6.28318      ≈ 0.048 м = 4.8 см
```

![Ближнє й дальнє електромагнітне поле: перехідна зона та розділення E і H](/root/course/embedded/peredsertyfikatsiinyi-ohliad-na-stoli/img/near-vs-far-field.svg)
*У ближній зоні (r < λ / 2π) електричне E-поле та магнітне H-поле існують незалежно, а їхнє співвідношення визначається імпедансом джерела. У дальній зоні (r >> λ / 2π) формується поперечна електромагнітна хвиля з фіксованим хвильовим опором Z₀ ≈ 377 Ом, яку вимірює приймальна антена в безлунній камері.*

У дальньому полі електрична складова `E` (В/м) та магнітна складова `H` (А/м) жорстко пов'язані між собою через хвильовий опір вільного простору `Z₀` (*characteristic impedance of free space*, від гр. *charaktēr* — «відмітна ознака»):

```
Z₀ = E / H = √(μ₀ / ε₀) ≈ 120π ≈ 376.73 Ом ≈ 377 Ом
```

Тут `μ₀ = 4π × 10⁻⁷ Гн/м` — магнітна стала, а `ε₀ = 8.854 × 10⁻¹² Ф/м` — електрична стала. У дальньому полі енергія незворотно відривається від плати й летить у простір у вигляді поперечної електромагнітної хвилі (TEM). Саме її на відстані 3 м або 10 м фіксує калібрована логоперіодична антена лабораторії.

Натомість у ближньому полі (`r < λ / 2π`), тобто на відстані кількох сантиметрів або міліметрів від друкованої плати, поля `E` та `H` розділені, а їхнє хвильове відношення `Z = E / H` не дорівнює 377 Ом і повністю залежить від природи конкретного схемного вузла:

1. **Вузли з високим хвильовим імпедансом (`Z >> 377 Ом`):** ділянки схеми з високою амплітудою напруги та малим струмом, де діє стрімка швидкість наростання напруги `dV/dt`. Це незаземлені радіатори охолодження транзисторів, виводи високовольтних драйверів, кінці довгих розімкнених сигнальних провідників. Вони випромінюють переважно **електричне поле (E-field)**.
2. **Вузли з низьким хвильовим імпедансом (`Z << 377 Ом`):** замкнені струмові контури зі значним імпульсним струмом і високою швидкістю наростання струму `dI/dt`. Це контур комутації ключів імпульсного перетворювача, струмові петлі заряду затворів польових транзисторів, зворотні струми цифрових шин у шарі землі. Вони генерують потужне **магнітне поле (H-field)**.

В електронних пристроях понад 90% проблем з електромагнітним випромінюванням на частотах до 1 ГГц породжуються саме паразитними струмовими петлями (`dI/dt`). Тому головним інструментом діагностики на столі є **зонд магнітного поля (H-field probe)**.

> 🔧 **Навіщо це.** Якщо піднести до плати звичайний щуп осцилографа з довгим земляним крокодилом, цей земляний провід сам перетвориться на петлеву антену, що наловить шум з усього приміщення й спотворить вимір. Зонд ближнього поля дозволяє безконтактно, без паяння та без внесення паразитних ємностей у схему сканувати електромагнітну активність кожного міліметра друкованої плати.

Зонд магнітного поля являє собою екрановану рамку (*shielded loop probe*), виконану з напівжорсткого коаксіального кабелю або у вигляді витка на багатошаровій друкованій платі. Конструктивна особливість такого зонда — наявність навмисного технологічного розрізу (*shield gap*) у верхній точці зовнішнього мідного екрана.

![Екранований зонд магнітного поля: розріз екрана та детектування струму](/root/course/embedded/peredsertyfikatsiinyi-ohliad-na-stoli/img/h-field-shielded-loop.svg)
*Зовнішній мідний екран блокує паразитне ємнісне E-поле. Розріз у верхній точці не дає утворитися короткозамкненому витку, дозволяючи магнітному потоку Φ проникати всередину. Поворот площини зонда паралельно або перпендикулярно провіднику дозволяє визначити точний напрямок протікання ВЧ-струму.*

Розріз екрана виконує подвійну фізичну функцію:
1. Мідний екран перехоплює лінії електричного поля `E` і зливає ємнісні струми на зовнішню оплітку роз'єму, не пускаючи їх у внутрішній вимірювальний тракт.
2. Якби екран був суцільним круговим кільцем, він утворив би короткозамкнений виток, у якому наведений струм повністю скомпенсував би зовнішнє магнітне поле всередині трубки. Розріз розриває екранне кільце, дозволяючи магнітному потоку `Φ` вільно пронизувати площу рамки.

Напруга `V_ind`, що індукується на виході центральної жили зонда, підпорядковується закону електромагнітної індукції Фарадея (*Faraday's law of induction*):

```
V_ind = - dΦ / dt = - A · μ₀ · (dH / dt) · cos(θ)
```

Для гармонійної складової магнітного поля з круговою частотою `ω = 2π·f` амплітуда вихідної напруги становить:

```
V_ind = 2π · f · A · μ₀ · H · cos(θ)
```

де:
- `A` — площа внутрішнього вікна петлі (м²);
- `f` — частота завади (Гц);
- `H` — напруженість магнітного поля (А/м);
- `θ` — кут між вектором магнітної індукції `B` та нормаллю до площини петлі зонда.

З цієї формули випливають два фундаментальні правила роботи із зондами магнітного поля:

1. **Компроміс між чутливістю та просторовою роздільністю:** Чутливість прямо пропорційна площі `A`. Велика петля (діаметром 20–30 мм) захоплює великий магнітний потік і здатна виявити слабкі сигнали на відстані кількох сантиметрів від плати — її використовують для швидкого панорамного огляду всієї плати. Мала петля (діаметром 2–5 мм) має на 20–30 дБ меншу чутливість, проте її локальна роздільність дозволяє позиціонувати джерело випромінювання з точністю до окремого виводу мікросхеми, конкретного блокувального конденсатора або перехідного отвору.
2. **Спрямованість детектування (векторний пошук):** Напруга залежить від `cos(θ)`. Якщо площина рамки паралельна друкованій доріжці, лінії магнітного поля пронизують петлю під кутом `θ = 0°` (`cos 0° = 1`), даючи максимальний сигнал на приймачі. Якщо розвернути зонд на 90° перпендикулярно лініям поля, сигнал падає практично до нуля (`cos 90° = 0`). Обертаючи зонд навколо осі над підозрілою ділянкою, інженер визначає точний вектор і траєкторію протікання високочастотного зворотного струму на платі.

Зонд електричного поля (E-field probe) влаштований інакше: це мініатюрний штир або металева кулька, захищена ізолятором, яка працює як обкладка малого конденсатора. Зв'язок із джерелом здійснюється через паразитну ємність `C_p` (зазвичай 0.1–1 пФ):

```
I_ind = C_p · (dV / dt)
```

E-зонд притискають до тепловідводів, металевих екранів, корпусів дроселів або роз'ємів, щоб виявити металеві конструкції, які не несуть великих струмів, проте заряджаються швидкими стрибками напруги й діють як штирові антени.

Сигнали від зондів малого розміру мають мізерну амплітуду — типово від -90 дБм до -60 дБм. Щоб підняти їх над власним шумом приймача, між зондом і входом аналізатора обов'язково встановлюють високочастотний малошумний підсилювач (LNA — *Low Noise Amplifier*, від англ. *low* — «низький» та *noise* — «шум»). Типовий широкосмуговий LNA на базі MMIC (наприклад, SPF5189Z або подібних) забезпечує підсилення `+20...+30 дБ` у смузі від 50 кГц до 3 ГГц із коефіцієнтом власного шуму `NF < 1.5 дБ`.

У ролі вимірювального приймача застосовують:
- **Портативний спектроаналізатор (TinySA / TinySA Ultra):** автономний прилад вартістю близько $60–$120, який має апаратні смуги пропускання фільтра роздільної здатності (RBW — *Resolution Bandwidth*), вбудовані ступінчасті атенюатори та режим утримання максимальних значень (*Max Hold*).
- **Програмно-визначене радіо (SDR — RTL-SDR v4, HackRF One):** бюджетний приймач із прямою оцифровкою квадратурних складових IQ, який у поєднанні з безкоштовним софтом (SDR++, GQRX або консольною утилітою `rtl_power`) перетворює ноутбук на повноцінний панорамний аналізатор спектра.

При налаштуванні приймача параметри вибирають відповідно до сертифікаційних стандартів CISPR 16:
- У діапазоні A (9 кГц – 150 кГц): смуга `RBW = 200 Гц`.
- У діапазоні B (150 кГц – 30 МГц): смуга `RBW = 9 кГц`.
- У діапазонах C і D (30 МГц – 1 ГГц): смуга `RBW = 120 кГц`.

Режим детектора завжди перемикають у **Peak** або **Max Hold**. Сертифікаційні лабораторії використовують повільний квазіпіковий детектор (*Quasi-Peak*), чиї покази зважуються за часом і для імпульсних завад завжди на 2–6 дБ нижчі за піковий детектор. Тобто вимірювання за піковим детектором у режимі Max Hold гарантує, що оцінка завади на столі буде суворішою за лабораторну, створюючи додатковий запас надійності.

### Кондуктивні завади та використання LISN на лабораторному столі

Електромагнітні завади поширюються від приладу двома шляхами: через просторове випромінювання (*radiated emissions*, частоти 30 МГц – 6 ГГц) та через проводи підключення (*conducted emissions*, частоти 150 кГц – 30 МГц). Кондуктивні завади створюються високочастотними пульсаціями струму, які просочуються по силових лініях живлення назад у мережу 230 В, акумуляторну батарею або бортову мережу транспортного засобу.

Підключити вхід спектроаналізатора чи SDR безпосередньо до проводів живлення плати не можна з трьох критичних причин:
1. Постійна напруга живлення (12 В, 24 В або мережеві 230 В) миттєво випалить чутливі вхідні змішувачі приймача, розраховані на максимальну потужність не більше +10...+20 дБм (близько 1–2 В).
2. Імпеданс лабораторного джерела живлення та довгих з'єднувальних проводів невідомий, нестабільний і непередбачувано змінюється з частотою через паразитну індуктивність дротів. Виміряна напруга шуму залежатиме не від схеми, а від довжини кабелю на столі.
3. Сам імпульсний лабораторний блок живлення випромінює значний високочастотний шум, який заллє вимірювальний вхід і замаскує шум тестованого пристрою (DUT — *Device Under Test*).

Для розв'язання цих проблем між джерелом живлення та тестованим пристроєм встановлюють **еквівалент мережі**, або **LISN** (*Line Impedance Stabilization Network*, в європейській термінології AMN — *Artificial Mains Network*, від лат. *impedio* — «перешкоджаю»).

![Схема еквівалента мережі DC-LISN та захисний вхідний тракт](/root/course/embedded/peredsertyfikatsiinyi-ohliad-na-stoli/img/dc-lisn-topology.svg)
*Схема стандартизованого DC-LISN. Дросель L1 блокує зовнішній шум блоку живлення та ізолює ВЧ-тракт. Конденсатор C1 відтинає постійну напругу, а резистор 50 Ом створює стабільний імпеданс навантаження для ВЧ-шуму. Захисний Transient Limiter зрізає імпульси комутації діодами Шотткі.*

LISN виконує три базові інженерні функції:
1. **Стабілізація імпедансу лінії:** Забезпечує фіксований високочастотний опір `50 Ом` між кожною лінією живлення та опорною землею в діапазоні від 150 кГц до 30 МГц (стандартні схеми `50 мкГн // 50 Ом` за CISPR 16 або `5 мкГн // 50 Ом` за CISPR 25 для низьковольтних DC-систем).
2. **Фільтрація шуму живлення:** Індуктивність `L1` разом із конденсатором `C2` формують потужний LC-фільтр низьких частот, що затримує шум із боку мережного блоку живлення.
3. **Безпечне зняття ВЧ-сигналу:** Високовольтний конденсатор `C1` блокує постійну складову струму й пропускає лише змінну напругу завади на вимірювальний порт 50 Ом.

Для лабораторного столу найпростіший DC-LISN для тестування низьковольтних пристроїв (5–48 В) можна зібрати самостійно на двосторонній друкованій платі, змонтованій на алюмінієвій або мідній пластині заземлення.

> ⚠️ **Обов'язковий захист входу: Transient Limiter.** При вмиканні або вимиканні тумблера живлення конденсатор `C1` перезаряджається за мікросекунди. Стрибок струму створює на виході LISN імпульс напруги амплітудою в десятки вольтів. Цей перехідний імпульс миттєво знищує вхідний підсилювач або змішувач SDR. Тому між виходом LISN і входом SDR обов'язково встановлюють **обмежувач перехідних процесів (Transient Limiter)** — вузол, що містить вхідний атенюатор 10 дБ (який покращує узгодження імпедансу), ВЧ-фільтр зрізу частот нижче 9 кГц і зустрічно-паралельні діоди Шотткі, що жорстко обмежують розмах імпульсу на рівні `±0.7 В`.

Кондуктивний шум завжди складається з двох компонентів:
- **Диференційна завада (DM — Differential Mode):** струм завади тече по плюсовому проводу в бік навантаження й повертається по мінусовому проводу у зворотному напрямку (`I_DM+ = -I_DM-`). Вона домінує на низьких частотах (до 1–2 МГц) і породжується пульсаціями струму через заряд/розряд вхідних конденсаторів DCDC.
- **Синфазна завада (CM — Common Mode):** струм завади тече по обох проводах живлення в одному напрямку одночасно, а повертається через паразитні ємності плати на корпус і захисну землю. Вона домінує на високих частотах (від 2 МГц до 30 МГц).

Щоб локалізувати, яка саме складова пробиває обмеження, виходи LISN ліній `+` і `-` підключають до високочастотного розщеплювача/суматора потужності (*power combiner / splitter*):
- Синфазний сигнал отримують сумуванням: `V_CM = (V_+ + V_-) / 2`.
- Диференційний сигнал отримують відніманням через інвертор фази 180°: `V_DM = (V_+ - V_-) / 2`.

Якщо пік завади зникає при відніманні — це синфазний шум: його усувають встановленням [синфазного дроселя](root:hw-components/common-mode-choke) та Y-конденсаторів на землю. Якщо пік залишається в різницевому каналі — це диференційний шум: його лікують збільшенням ємності вхідних керамічних конденсаторів з низьким ESR, додаванням феритової намистини або П-подібного LC-фільтра.

### Пошук паразитних антен у джгутах та роз'ємах струмовими кліщами

Чому компактна друкована плата розміром `5 × 5 см` часто провалює сертифікацію за випромінюванням на частотах 100–300 МГц, хоча на ній немає радіомодулів?

Відповідь полягає в геометрії антени: ефективність випромінювання структури залежить від відношення її фізичного розміру `L` до довжини хвилі `λ`. На частоті 100 МГц довжина хвилі становить `λ = 3 м`, а довжина резонансного чвертьхвильового вібратора `λ/4 = 75 см`. Плата розміром 5 см є мізерним, вкрай неефективним випромінювачем (`L << λ/4`).

Але щойно до плати підключають метровий кабель живлення, неекранований USB-дріт або шлейф зовнішнього датчика, цей провід стає повноцінною антеною-монополем. Будь-яка високочастотна синфазна напруга шуму `V_cm`, присутня між опорною землею плати та кабелем, заштовхує в кабель синфазний струм `I_cm`.

![RF струмові кліщі: детектування синфазного струму та випромінювання кабелю](/root/course/embedded/peredsertyfikatsiinyi-ohliad-na-stoli/img/rf-current-clamp-physics.svg)
*Диференційний струм живлення взаємно компенсує своє магнітне поле в осерді кліщів. Синфазний струм завади I_cm наводить напругу у вторинній обмотці кліщів. Навіть мізерний струм 5 мкА у метровому проводі на частоті 100 МГц створює випромінювання, що перевищує жорстку межу CISPR 32 Class B.*

Оцінимо максимальну напруженість електричного поля `E_max` на відстані `r = 3 м`, яку створює тонкий провідник довжиною `L` зі струмом `I_cm` над заземленою поверхнею в умовах резонансу:

```
E_max ≈ (μ₀ · f · L · I_cm) / r
```

Розрахуймо критичну величину синфазного струму `I_cm`, яка призводить до провалу сертифікації за стандартом CISPR 32 Class B:

**Розрахунок гранично допустимого синфазного струму в кабелі:**
- Частота завади: `f = 100 МГц = 10⁸ Гц`
- Довжина кабелю: `L = 1 м`
- Відстань до вимірювальної антени: `r = 3 м`
- Нормативна межа CISPR 32 Class B: `E_норм = 40 дБмкВ/м = 100 мкВ/м = 10⁻⁴ В/м`

```
I_cm = (E_норм · r) / (μ₀ · f · L)              [виразили струм із формули випромінювання]
     = (10⁻⁴ · 3) / (4π × 10⁻⁷ · 10⁸ · 1)       [підставили параметри: f = 100 МГц, r = 3 м, L = 1 м]
     = 3 × 10⁻⁴ / 125.6637                      [перемножили сталі: 4π · 10 = 125.66]
     ≈ 2.39 × 10⁻⁶ А = 2.39 мкА                 [отримали критичний синфазний струм]
```

Результат вражає: **синфазний струм величиною лише 2.4–5 мікроамперів у метровому кабелі гарантує повний провал офіційної сертифікації!**

Струм у кілька мікроамперів неможливо побачити звичайним осцилографом на тлі робочого струму живлення в сотні міліамперів чи ампери. Для його виявлення використовують **високочастотні струмові кліщі (RF Current Clamp)**.

RF-кліщі являють собою високочастотний струмовий трансформатор, виконаний на базі рознімного феритового тороїда з високою магнітною проникністю (`μ_r = 800...2000`, ферити типу 43 або 31) із вторинною обмоткою на 10–20 витків, навантаженою на коаксіальний роз'єм 50 Ом.

Кліщі охоплюють весь кабель цілком (усі жили разом):
1. **Диференційні струми (`I_+` та `I_-`):** прямий струм живлення та зворотний струм навантаження протікають у кабелі у протилежних напрямках. Їхні магнітні потоки в осерді кліщів мають рівну амплітуду й протилежний знак, тому вони повністю віднімаються до нуля:
   ```
   Φ_diff = Φ_+ + Φ_- = μ · (I_+ - I_-) = 0
   ```
   Кліщі абсолютно не реагують на робочий струм пристрою, навіть якщо він становить 10 А.
2. **Синфазний струм (`I_cm`):** завадний струм тече по всіх жилах в один і той самий бік, створюючи сумарний магнітний потік `Φ_cm`. Цей потік індукує у вторинній обмотці кліщів радіочастотну напругу `V_out`, яка подається на вхід SDR:
   ```
   V_out = Z_T · I_cm
   ```
   де `Z_T` — передавальний імпеданс кліщів (*Transfer Impedance*, від лат. *transfero* — «переношу»), який для типових лабораторних кліщів становить від 5 до 20 Ом (14–26 дБ·Ом) у смузі 10–300 МГц.

Методика роботи з кліщами на столі:
1. Затисніть кліщі навколо кабелю впритул до роз'єму плати.
2. Увімкніть SDR у режимі спектрограми (Waterfall) і зафіксуйте спектральні піки.
3. Повільно переміщуйте кліщі вздовж довжини кабелю: на стоячій хвилі амплітуда піку змінюватиметься, досягаючи максимуму в пучності струму.
4. Одягніть рознімне феритове кільце (*ferrite snap-on choke*) на кабель у точці виходу з плати. Якщо пік на SDR миттєво просідає на 12–18 дБ, проблему паразитної антени локалізовано й успішно усунуто.

### Повний інженерний регламент перевірки та аналізатор спектральних піків

Щоб передсертифікаційний аудит був системним і не перетворювався на хаотичне торкання плати щупами, перевірку проводять за суворим 7-кроковим інженерним регламентом.

![Покроковий регламент передсертифікаційного тестування плати на столі](/root/course/embedded/peredsertyfikatsiinyi-ohliad-na-stoli/img/tabletop-emc-workflow.svg)
*Інженерний маршрут послідовного аудиту. Вимірювання починаються зі зняття фону ефіру, переходять через LISN до оглядових та точкових зондів, локалізують витоки в кабелях і завершуються контролем запасу придушення ΔдБ ≥ 6–10 дБ.*

#### 7-кроковий лабораторний регламент аудиту

1. **Крок 1: Зняття базового фону кімнати (Baseline Ambient Scan):**
   Вимкніть живлення тестованого пристрою. Увімкніть SDR або TinySA з підключеним зондом і запишіть спектр ефірного шуму в приміщенні від 100 кГц до 1 ГГц. Усі зовнішні сигнали — місцеве FM-радіо (88–108 МГц), базові станції мобільного зв'язку (900/1800 МГц), Wi-Fi роутери (2.4 ГГц) та перешкоди від моніторів — зберігаються як фонова маска. Це запобігає витрачанню часу на «боротьбу» з радіостанціями, які приходять з ефіру через вікно лабораторії.
2. **Крок 2: Вимірювання кондуктивних завад через LISN (150 кГц – 30 МГц):**
   Підключіть пристрій до DC-LISN через Transient Limiter. Зафіксуйте фундаментальну частоту комутації перетворювача `f_sw` (наприклад, 400 кГц, 1.2 МГц або 2.2 МГц) та її гармоніки. Перевірте дію вхідного фільтра живлення.
3. **Крок 3: Панорамний огляд H-зондом великого діаметра (30 МГц – 1 ГГц):**
   Увімкніть режим Max Hold. Проведіть великою петлею (20–30 мм) на висоті 2–3 см над усією площею плати. Зафіксуйте найвищі піки, що виділяються над фоновою маскою більш ніж на 15–20 дБ.
4. **Крок 4: Точкова локалізація малим H-зондом та E-зондом:**
   Змініть петлю на мініатюрну (2–5 мм) і скануйте плату впритул:
   - Вузол комутації DCDC (*switch node*) та виводи силового дроселя;
   - Корпуси мікроконтролера, пам'яті та трансиверів шин (Ethernet PHY, USB, CAN);
   - Траси тактових генераторів і кварцових резонаторів;
   - Межі розділу полігонів землі та шви металевого корпусу.
5. **Крок 5: Аудит кабелів і роз'ємів RF-кліщами:**
   Одягніть струмові кліщі на кожен зовнішній кабель (живлення, шлейфи датчиків, інтерфейсні лінії) і перевірте амплітуду синфазних гармонік.
6. **Крок 6: Внесення інженерних контрзаходів:**
   - Встановлення RC-снабера паралельно нижньому діоду/транзистору DCDC для придушення дзвону комутації (*ringing*);
   - Зниження швидкості наростання фронтів (*slew rate*) у прошивці мікроконтролера для ліній GPIO, SPI, SDIO;
   - Встановлення синфазних дроселів на сигнальні лінії та феритових кілець на кабелі;
   - Проклеювання швів корпусу струмопровідною мідною стрічкою з проводячим клеєм.
7. **Крок 7: Контрольне порівняння «До і Після» (Delta Verification):**
   Повторіть сканування та розрахуйте дельту зменшення піків `Δ дБ = P_до - P_після`. Якщо на всіх критичних частотах досягнуто зниження на 12–20 дБ, а розрахунковий інженерний запас до межі CISPR становить не менше 6–10 дБ — плата готова до офіційної сертифікації.

#### Програмний аналізатор спектральних піків та гармонійних сіток

Для автоматизації обробки спектральних дампів (отриманих через `rtl_power`, `hackrf_sweep` або знятих із TinySA через USB/CSV) розроблено алгоритм детектування піків. Він розраховує адаптивну ковзну підлогу шуму, знаходить локальні викиди за порогом дельти й автоматично ідентифікує їхнє походження шляхом зіставлення з гармонійними сітками відомих тактових генераторів схеми (`f_0, 2·f_0, 3·f_0, ...`).

```c
#include <stdio.h>
#include <stdbool.h>
#include <math.h>

#define MAX_BINS 1024
#define MAX_PEAKS 64
#define MAX_SOURCES 8

typedef struct {
    double freq_hz;
    double power_dbm;
} SpectrumBin;

typedef struct {
    double freq_hz;
    double power_dbm;
    double delta_over_floor_db;
    const char* matched_source;
    int harmonic_order;
} DetectedPeak;

typedef struct {
    const char* name;
    double fund_freq_hz;
    double tolerance_hz;
} KnownSource;

/* Знаходження ковзної підлоги шуму та локальних піків */
int detect_emc_peaks(const SpectrumBin* bins, int num_bins,
                     int window_half_width, double threshold_delta_db,
                     const KnownSource* sources, int num_sources,
                     DetectedPeak* out_peaks, int max_out_peaks) {
    int peak_count = 0;

    for (int i = window_half_width; i < num_bins - window_half_width; ++i) {
        /* Локальний максимум: точка вища за найближчих сусідів */
        if (bins[i].power_dbm <= bins[i - 1].power_dbm ||
            bins[i].power_dbm <= bins[i + 1].power_dbm) {
            continue;
        }

        /* Обчислення локального середнього рівня шуму навколо піку */
        double sum_power = 0.0;
        int count = 0;
        for (int w = -window_half_width; w <= window_half_width; ++w) {
            if (w >= -1 && w <= 1) continue; /* пропускаємо саму вершину */
            sum_power += bins[i + w].power_dbm;
            count++;
        }
        double local_floor = (count > 0) ? (sum_power / count) : bins[i].power_dbm;
        double delta = bins[i].power_dbm - local_floor;

        if (delta >= threshold_delta_db) {
            if (peak_count >= max_out_peaks) break;

            DetectedPeak* p = &out_peaks[peak_count++];
            p->freq_hz = bins[i].freq_hz;
            p->power_dbm = bins[i].power_dbm;
            p->delta_over_floor_db = delta;
            p->matched_source = "Невідоме джерело";
            p->harmonic_order = 0;

            /* Ідентифікація за гармонійними сітками */
            for (int s = 0; s < num_sources; ++s) {
                double ratio = p->freq_hz / sources[s].fund_freq_hz;
                int n = (int)(ratio + 0.5);
                if (n >= 1) {
                    double expected_freq = n * sources[s].fund_freq_hz;
                    if (fabs(p->freq_hz - expected_freq) <= sources[s].tolerance_hz) {
                        p->matched_source = sources[s].name;
                        p->harmonic_order = n;
                        break;
                    }
                }
            }
        }
    }
    return peak_count;
}
```

```cpp
#include <iostream>
#include <vector>
#include <span>
#include <string_view>
#include <optional>
#include <cmath>
#include <algorithm>
#include <numeric>
#include <format>

struct SpectrumBin {
    double freq_hz{0.0};
    double power_dbm{0.0};
};

struct KnownSource {
    std::string_view name;
    double fund_freq_hz{0.0};
    double tolerance_hz{50000.0};
};

struct DetectedPeak {
    double freq_hz{0.0};
    double power_dbm{0.0};
    double delta_over_floor_db{0.0};
    std::string_view matched_source{"Невідоме джерело"};
    int harmonic_order{0};
};

class EmcPeakAnalyzer {
public:
    explicit EmcPeakAnalyzer(int window_half_width = 8, double threshold_delta_db = 10.0)
        : window_half_width_{window_half_width}, threshold_delta_db_{threshold_delta_db} {}

    [[nodiscard]] std::vector<DetectedPeak> analyze(
        std::span<const SpectrumBin> spectrum,
        std::span<const KnownSource> sources) const {
        
        std::vector<DetectedPeak> detected_peaks;
        const int n = static_cast<int>(spectrum.size());
        if (n < 2 * window_half_width_ + 1) return detected_peaks;

        for (int i = window_half_width_; i < n - window_half_width_; ++i) {
            // Перевірка на локальний максимум
            if (spectrum[i].power_dbm <= spectrum[i - 1].power_dbm ||
                spectrum[i].power_dbm <= spectrum[i + 1].power_dbm) {
                continue;
            }

            // Розрахунок середньої підлоги шуму у ковзному вікні (без верхівки)
            double sum_noise = 0.0;
            int count = 0;
            for (int w = -window_half_width_; w <= window_half_width_; ++w) {
                if (std::abs(w) <= 1) continue;
                sum_noise += spectrum[i + w].power_dbm;
                count++;
            }
            const double local_floor = (count > 0) ? (sum_noise / count) : spectrum[i].power_dbm;
            const double delta = spectrum[i].power_dbm - local_floor;

            if (delta >= threshold_delta_db_) {
                DetectedPeak peak{
                    .freq_hz = spectrum[i].freq_hz,
                    .power_dbm = spectrum[i].power_dbm,
                    .delta_over_floor_db = delta
                };

                // Зіставлення з відомими тактовими генераторами
                for (const auto& src : sources) {
                    const double ratio = peak.freq_hz / src.fund_freq_hz;
                    const int order = static_cast<int>(std::round(ratio));
                    if (order >= 1) {
                        const double expected_freq = order * src.fund_freq_hz;
                        if (std::abs(peak.freq_hz - expected_freq) <= src.tolerance_hz) {
                            peak.matched_source = src.name;
                            peak.harmonic_order = order;
                            break;
                        }
                    }
                }
                detected_peaks.push_back(peak);
            }
        }
        return detected_peaks;
    }

private:
    int window_half_width_{8};
    double threshold_delta_db_{10.0};
};
```

```python
#!/usr/bin/env python3
"""Аналізатор спектральних піків та гармонійних сіток для CSV-дампів SDR/TinySA."""
import csv
import sys
import math

KNOWN_SOURCES = [
    {"name": "DCDC Switcher (Buck)", "fund_freq": 1.2e6, "tolerance": 25e3},
    {"name": "Кварц MCU (HSE)", "fund_freq": 25.0e6, "tolerance": 50e3},
    {"name": "USB 2.0 PHY Clock", "fund_freq": 48.0e6, "tolerance": 80e3},
    {"name": "SPI Flash Bus", "fund_freq": 80.0e6, "tolerance": 150e3},
]

def analyze_spectrum(csv_path, threshold_delta_db=10.0, window=8):
    frequencies = []
    powers = []
    
    with open(csv_path, 'r', encoding='utf-8') as f:
        reader = csv.reader(f)
        for row in reader:
            if not row or row[0].startswith('#'):
                continue
            try:
                frequencies.append(float(row[0]))
                powers.append(float(row[1]))
            except ValueError:
                continue

    n = len(frequencies)
    peaks = []

    for i in range(window, n - window):
        # Локальний максимум
        if powers[i] <= powers[i - 1] or powers[i] <= powers[i + 1]:
            continue

        # Підлога шуму навколо піку
        window_powers = [powers[i + w] for w in range(-window, window + 1) if abs(w) > 1]
        noise_floor = sum(window_powers) / len(window_powers)
        delta = powers[i] - noise_floor

        if delta >= threshold_delta_db:
            freq = frequencies[i]
            matched_src = "Невідоме джерело"
            harmonic_num = 0

            for src in KNOWN_SOURCES:
                ratio = freq / src["fund_freq"]
                order = round(ratio)
                if order >= 1 and abs(freq - order * src["fund_freq"]) <= src["tolerance"]:
                    matched_src = src["name"]
                    harmonic_num = order
                    break

            peaks.append({
                "freq_mhz": freq / 1e6,
                "power_dbm": powers[i],
                "delta_db": delta,
                "source": matched_src,
                "harmonic": harmonic_num
            })

    print(f"Знайдено небезпечних піків: {len(peaks)}")
    print(f"{'Частота (МГц)':<15} {'Рівень (дБм)':<14} {'Дельта (дБ)':<12} {'Джерело випромінювання':<25} {'Гармоніка'}")
    print("-" * 75)
    for p in peaks:
        h_str = f"H{p['harmonic']}" if p['harmonic'] > 0 else "-"
        print(f"{p['freq_mhz']:<15.3f} {p['power_dbm']:<14.1f} {p['delta_db']:<12.1f} {p['source']:<25} {h_str}")

if __name__ == "__main__":
    if len(sys.argv) > 1:
        analyze_spectrum(sys.argv[1])
    else:
        print("Використання: python emc_peak_hunter.py <spectrum_data.csv>")
```
