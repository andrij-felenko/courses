# 🔌 Датчики розкриття корпусу та фізичного втручання: кінцевики, струмопровідні сітки, оптичні та вібраційні сенсори

У захищених вбудованих пристроях — від платіжних терміналів (POS-терміналів) і промислових лічильників енергії до польових контролерів зв'язку та криптографічних модулів — корпус перестає бути просто механічною коробкою для захисту від пилу та вологи. Корпус стає першою лінією активної оборони. Якщо зловмисник отримує прямий фізичний доступ до плати, у нього з'являється можливість підпаяти щупи логічного аналізатора до шин SPI або I2C, підключити зневаджувач SWD чи зняти дамп мікросхеми Flash-пам'яті.

Апаратна детекція фізичного втручання (англ. *Anti-Tamper Detection*, де *tamper* походить від середньоангл. *tamperen*, втручатися, пошкоджувати) покликана зафіксувати будь-яку спробу порушення цілісності оболонки ще до того, як щуп торкнеться провідників друкованої плати.

---

## 1. Механічні кінцевики розкриття (Tamper Switches)

Найпростішим і водночас високонадійним методом контролю розкриття є встановлення електромеханічних мікроперемикачів (кінцевиків). Вони монтуються на друкованій платі таким чином, що їхні пружні штоки або пелюстки впираються у внутрішні ребра жорсткості чи кришку корпусу.

```
       [ Верхня кришка корпусу ]
                  │
                  ▼ (тиск кришки)
             ┌─────────┐
             │  Шток   │
         ┌───┴─────────┴───┐
         │  Мікроперемикач │
         │   (Позолочені   │
         │    контакти)    │
         └───┬─────────┬───┘
             │         │
       ──────┴─────────┴────── [ Друкована плата PCB ]
```

### Особливості вибору та схемотехніки:

1. **Позолочені контакти (Gold-Plated Contacts).** Оскільки кінцевик перебуває у замкненому стані роками, звичайні срібні або мідні контакти неминуче окислюються під дією вологи й температурних коливань, утворюючи тонкий шар діелектрика. При знятті кришки окислений контакт може не розімкнутися або дати брязкіт із затримкою. Позолота гарантує низький перехідний опір навіть при мізерних комутованих струмах у сотні наноамперів.
2. **Струмова петля з резистором кінця лінії (End-Of-Line, EOL).** Найпримітивніша схема — підтяжка до живлення `3.3 В` резистором і замикання контакту на землю. Проте нападник, виявивши таку лінію, може акуратно підпаяти дріт до землі або шини живлення перед зняттям кришки, знешкодивши захист. Для захисту від обходу застосовують резистивний подільник: усередині корпусу послідовно з кнопкою встановлюють опір `R1 = 10 кОм`, а паралельно — `R2 = 100 кОм`. АЦП або віконний компаратор контролює точний рівень напруги: розрив кола (відкриття), закорочення на землю або подача `3.3 В` сприймаються як тривога.
3. **Двоточкове діагональне розміщення.** Якщо корпус закріплений чотирма гвинтами, відкручування одного кута дає змогу відігнути пластик на 2–3 мм і ввести голчастий зонд. Тому кнопки встановлюють парами на протилежних кутах або по периметру роз'єму.

## 2. Активна струмопровідна сітка (Active Tamper Mesh)

Кінцевики захищають від зняття кришки, але безсилі проти локального свердління корпусу тонким свердлом для доступу до окремої мікросхеми чи контрольної точки (Test Point). Для захисту від механічного проникнення застосовують активну захисну сітку.

Сітка є щільним звивистим провідником (змійкою, англ. *serpentine trace*), надрукованим на внутрішній поверхні корпусу методом LDS (Laser Direct Structuring), у вигляді гнучкого шлейфа (FPC), наклеєного зсередини, або на внутрішніх шарах багатошарової друкованої плати, що накривають чутливі мікросхеми.

```
 [ Захисна кришка ] ──► ╔═══════════════════════════════╗
                        ║ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ║ ◄── Звивиста мікродоріжка
                        ║ │ └─┘ │ └─┘ │ └─┘ │ └─┘ │ └─┘ ║     ширина: 0.1 мм
                        ║ └─────┴─────┴─────┴─────┴───► ║     зазор:  0.1 мм
                        ╚═══════════════════════════════╝
```

### Принципи контролю цілісності сітки:

- **Статичний міст Уїтстона (Wheatstone Bridge).** Дві паралельні змійки утворюють плечі вимірювального моста. Спроба просвердлити отвір діаметром понад 0.3 мм перерізає принаймні одну доріжку (опір стає нескінченним) або закорочує сусідні витки між собою (опір падає). Вимірювальний компаратор миттєво фіксує розбаланс моста.
- **Динамічне кодове опитування (Active Dynamic Scanning).** На один кінець сітки мікроконтролер із псевдовипадковими інтервалами подає кодові імпульси або псевдовипадкову послідовність (PRBS). Другий кінець приймає сигнал. Якщо зловмисник спробує підпаяти шунтуючу перемичку, щоб обійти ділянку сітки перед свердлінням, зміна фазової затримки та форми імпульсу викличе тривогу.

## 3. Оптичні сенсори в темній замкненій порожнині (Dark Cavity Sensors)

Усередині герметично закритого непрозорого корпусу панує абсолютна темрява. Будь-яке розкриття кришки, виникнення тріщини або отвору від свердла впускає всередину корпусу фотони зовнішнього освітлення.

Для фіксації світла на платі встановлюють кремнієвий фотодіод або чутливий фототранзистор, оптимізований для видимої та ближньої інфрачервоної областей спектра (400–1000 нм).

```
   Зовнішнє світло (hv) ──► ░░░ (щілина в корпусі)
                               │
                               ▼
                       ┌───────────────┐
                       │   Фотодіод    │
                       │ (Зворотне     │
                       │  зміщення)    │
                       └───────┬───────┘
                               │ Фотострум I_ph (1–10 мкА)
                               ▼
                  ┌─────────────────────────┐
                  │ Ультранизькоспоживаючий │
                  │     компаратор ULP      │ ──► Сигнал TAMPER_INT
                  └─────────────────────────┘
```

### Схемотехнічний розрахунок:

У темряві зворотний струм витоку якісного PIN-фотодіода (темновий струм `I_dark`) становить менше `100 пА` (`10⁻¹⁰ А`) при кімнатній температурі.

При появі навіть тьмяного розсіяного світла (освітленість `E ≈ 1–5 лк`) фотодіод генерує фотострум порядка `1–10 мкА`, що на чотири порядки перевищує темновий струм.

Схема підключення використовує високоомний навантажувальний резистор `R_load = 10 МОм`:

```
V_out = I_ph · R_load
```

При струмі `I_ph = 1 мкА`:

```
V_out
= 1 · 10⁻⁶ А · 10 · 10⁶ Ом                                [закон Ома для фотоструму]
= 10 В                                                     [обмежується напругою живлення 3.3 В]
```

Вихідна напруга миттєво насичується до шини живлення `3.3 В`, перекидаючи логічний вхід або вбудований компаратор мікроконтролера за час менше `1 мкс`.

## 4. Сенсори граничних умов та аномалій середовища (Environmental Out-of-Bounds)

Окрім прямого механічного злому, нападники застосовують фізичні впливи, спрямовані на порушення стабільності кремнію або збереження залишкових зарядів у пам'яті:

1. **Кріогенна заморозка (Cold Boot Attack).** Охолодження мікросхем SRAM та DRAM до температури нижче `-40 °C` (наприклад, за допомогою охолоджувального спрею або рідкого азоту) сповільнює розряд комірок пам'яті в сотні разів. Навіть після вимкнення живлення дані залишаються в замерзлих комірках протягом кількох хвилин. Захист: моніторинг температури кристала через вбудований датчик або зовнішній терморезистор NTC. При падінні температури нижче `-30 °C` контролер генерує подію Tamper і занулює ключі до охолодження.
2. **Стрибки та провали живлення (Voltage Glitching / Fault Injection).** Короткочасне (на 50–200 нс) просаджування напруги живлення ядра під час перевірки пароля або підпису збиває лічильник інструкцій процесора. Захист: апаратний монітор напруги живлення (BOD/PVD) із жорстким вікном допуску (наприклад, `3.0–3.6 В`). Вихід за межі вікна викликає негайне блокування.
3. **Вібрація та свердління.** Трьохосьовий акселерометр MEMS, налаштований на детекцію високих прискорень та високочастотної вібрації (характерної для роботи бормашини чи пилки), сигналізує про спробу механічного розтину ще до руйнування корпусу.

## 5. Інтерфейс із резервним доменом живлення (VBAT Domain)

Усі перелічені сенсори повинні функціонувати навіть тоді, коли прилад повністю вимкнений користувачем і лежить на полиці або транспортується.

Для цього підсистема анти-темпер моніторингу підключається безпосередньо до **домену резервного живлення** мікроконтролера (вивід `VBAT`), що живиться від літієвої дискової батарейки (CR2032) або суперконденсатора (іоністора).

```
 +─────────────────────────────────────────────────────────────────+
 │                       МІКРОКОНТРОЛЕР                            │
 │                                                                 │
 │   Головне живлення VDD ──[ Регулятор ]──► Ядро Cortex-M / Flash │
 │                                                  ▲              │
 │                                                  │ Аварійне     │
 │                                                  │ скидання     │
 │   Резервне живлення VBAT ──► ┌───────────────────┴──────────┐   │
 │   (Літієва таблетка)         │   Tamper & Backup Domain     │   │
 │                              │  - Low-Power RTC (32.768 кГц)│   │
 │   Тампер-виводи ───────────► │  - Компаратори тампера       │   │
 │   (Сітка / Кнопки / Оптика)  │  - Backup Registers / SRAM   │   │
 │                              └──────────────────────────────┘   │
 +─────────────────────────────────────────────────────────────────+
```

Сумарне енергоспоживання домену в режимі сну становить усього `0.5–1.5 мкА`, що забезпечує безперервний захист і готовність до гарантованого очищення протягом 5–10 років автономної роботи.
