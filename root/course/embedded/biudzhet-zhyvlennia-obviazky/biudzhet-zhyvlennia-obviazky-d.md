# Бюджет живлення обв'язки: проектування системи живлення багатокомпонентної плати

<preknowlist>
- [Лінійний регулятор (LDO)](root:hw-power/ldo) — розсіювання різниці напруг у вигляді тепла, струм спокою та напруга падіння.
- [Знижувальний імпульсний перетворювач (Buck)](root:hw-power/buck) — імпульсна комутація енергії через котушку, високий ККД та спектр перемикальних завад.
- [Тепловий ланцюг і тепловідведення](root:hw-components/thermal-chain) — тепловий опір перехід-середовище, межі температури кристала та розсіювання на платі.
- [Розв'язувальні конденсатори](root:hw-components/decoupling) — локальне накопичення заряду, фільтрація імпульсних просідань та імпеданс шини живлення.
</preknowlist>

Плата автономного реєстратора бездоганно працює на лабораторному столі від USB-порту комп'ютера, але під час першого ж польового тесту від літій-іонного акумулятора стикається з трьома критичними відмовами: мікроконтролер циклічно перезавантажується щоразу, коли радіомодуль вмикає передавач на повну потужність; лінійний стабілізатор у компактному корпусі розігрівається до 98 °C і вимикається внутрішнім термозахистом; а виміряна ємність акумулятора вичерпується за три тижні замість очікуваних двох років роботи. Усі компоненти схеми підібрані строго за технічними паспортами, проте плата як цілісна енергетична система виявилася нежиттєздатною.

Причина таких аварій полягає в ігноруванні балансу між статичним споживанням периферії, динамічними піковими струмами, тепловими обмеженнями корпусів та спектральним шумом перетворювачів. Сучасна друкована плата об'єднує цифрові обчислювальні ядра, радіочастотні трансивери, зовнішню пам'ять і прецизійні аналогові сенсори, кожен із яких висуває взаємовиключні вимоги до шин живлення. Проектування надійного вузла живлення починається не зі схеми стабілізатора, а зі складання повного енергетичного бюджету всієї обв'язки.

## Анатомія енергетичного бюджету: струми спокою, динаміка та витоки

Струм, який плата споживає від первинного джерела, ніколи не є сталою величиною. Він складається з кількох фізично різних компонентів, що змінюються на кілька порядків залежно від стану мікроконтролера та зовнішніх мікросхем.

```
I_total(t) = I_Q_total + I_leak + I_static + I_dyn(t) + I_transient(t)
```

Розгляньмо фізичну природу кожної складової:

1. **Струм спокою (англ. *Quiescent Current*, `I_Q`):** внутрішній струм, необхідний для функціонування внутрішніх кіл самих мікросхем (джерел опорної напруги типу [bandgap](root:hw-power/ldo-internals), підсилювачів похибки, схем контролю зсуву рівнів). Цей струм протікає через вивід заземлення стабілізатора або внутрішні вузли мікросхеми навіть тоді, коли корисне вихідне навантаження дорівнює нулю.
2. **Струм витоку напівпровідникових структур (`I_leak`):** зворотні струми закритих p-n переходів захисних TVS-діодів, підкладкових діодів польових транзисторів і діелектричні витоки керамічних та танталових конденсаторів. Витік діодів експоненційно зростає з температурою: діод із витоком 1 мкА при 25 °C може споживати понад 30–50 мкА при нагріванні до 70 °C.
3. **Статичний струм резистивних кіл (`I_static`):** струм, який безперервно стікає в землю через підтягувальні резистори (англ. *pull-up / pull-down*), резистивні дільники напруги для моніторингу батареї через АЦП або світлодіоди індикації. Наприклад, класичний вимірювальний дільник напруги акумулятора з опором верхнього й нижнього плеча по 100 кОм при напрузі 4.0 В постійно спалює струм:

```
I_div = V_bat / (R1 + R2)
I_div = 4.0 В / (100000 Ом + 100000 Ом) = 0.000020 А = 20 мкА
```

Для пристрою, чиє процесорне ядро в глибокому сні споживає 5 мкА, один такий нескомпенсований дільник збільшує розряд батареї у чотири рази.

4. **Динамічний струм цифрової логіки (`I_dyn`):** струм заряду й перезаряду паразитної ємності внутрішніх вузлів і вивідних ліній КМОН-вентилів ([CMOS](root:hw-digital/cmos-gate)) під час перемикання тактової частоти:

```
I_dyn = C_eff · V_DD · f_clk
```

де `C_eff` — еквівалентна ємність перемикання кристала, `V_DD` — напруга живлення, а `f_clk` — тактова частота ядра або шини. З цієї залежності випливає прямий інженерний висновок: зниження робочої напруги цифрового ядра з 3.3 В до 1.8 В скорочує динамічне енергоспоживання у 1.83 раза при тій самій частоті.

5. **Імпульсний піковий струм (`I_transient`):** високоамплітудні сплески струму тривалістю від сотень мікросекунд до кількох мілісекунд під час роботи вихідних підсилювачів радіотрансиверів (Wi-Fi передає пакети струмом 250–400 мА, GSM/LTE-модеми генерують імпульси до 2.0 А), запису сторінок у зовнішню енергонезалежну пам'ять [SPI Flash](root:hw-components/spi-flash) (20–40 мА) або запуску електродвигунів і зумерів.

> 🔧 **Навіщо це.** Розрахунок джерел живлення за «середнім» значенням споживання призводить до раптових перезавантажень процесора через імпульсні просідання, тоді як розрахунок за «максимальним» струмом без оптимізації струмів спокою вбиває автономність пристрою. Повний бюджет зводить усі ці режими в єдину розрахункову таблицю.

### Методологія зведення Power Budget Sheet

Для аналізу енергетичного балансу пристрій розбивають на функціональні фази роботи (англ. *operational states*). Для типового вбудованого вузла формують матрицю з чотирьох основних станів:
- **Глибокий сон (Deep Sleep):** мікроконтролер зупинений, тактовий генератор вимкнений, працює лише годинник реального часу (RTC), периферія знеструмлена або в режимі Standby.
- **Зчитування сенсорів (Sensor Acquisition):** процесор прокинувся, живить зовнішні датчики через шини I²C/SPI, запускає перетворення АЦП.
- **Обробка даних (Active Processing):** ядро працює на максимальній частоті, виконує обчислення або шифрування даних.
- **Радіообмін (TX/RX Burst):** увімкнено підсилювач потужності трансивера, відбувається передача або прийом пакета по радіоефіру.

У кожній фазі підсумовують споживання всіх активних мікросхем по окремих шинах живлення (наприклад, 3.3 В для цифрової частини, 3.0 В для аналогової, 5.0 В для зовнішніх датчиків).

**Таблиця 1. Типовий енергетичний бюджет автономного вимірювального вузла**

| Компонент | Стан Deep Sleep (мкА) | Зчитування (мА) | Обробка (мА) | Радіопередача TX (мА) |
|---|---|---|---|---|
| Мікроконтролер (STM32/ESP32) | 12.0 | 4.5 | 24.0 | 18.0 |
| Радіомодуль (Sub-GHz / BLE) | 0.8 | 0.0 | 0.0 | 120.0 |
| Зовнішня SPI Flash | 1.0 | 0.0 | 15.0 (запис) | 0.0 |
| Аналоговий АЦП + Опори | 0.0 (вимкнено) | 2.2 | 0.0 | 0.0 |
| Сенсори I²C (темп./тиск) | 1.5 | 1.8 | 0.0 | 0.0 |
| Підтяжки шин + Дільники | 8.0 | 8.0 | 8.0 | 8.0 |
| Власний струм LDO / Buck (I_Q) | 4.0 | 18.0 | 25.0 | 35.0 |
| **Сумарний струм фази** | **27.3 мкА** | **26.5 мА** | **47.0 мА** | **181.0 мА** |
| **Тривалість фази в циклі** | **59.2 с** | **0.3 с** | **0.1 с** | **0.4 с** |

Середній інтегральний струм за повний період циклу `T_period = 60 с` обчислюється за формулою:

```
I_avg = (1 / T_period) · ∑ (I_k · t_k)
```

**Worked-приклад. Інтегральний розрахунок середнього споживання вузла.**

```
Параметри фаз:
   Фаза 1 (Сон):       I_1 = 0.0273 мА,  t_1 = 59.2 с
   Фаза 2 (Сенсори):   I_2 = 26.5 мА,    t_2 = 0.3 с
   Фаза 3 (Обробка):   I_3 = 47.0 мА,    t_3 = 0.1 с
   Фаза 4 (Передача):  I_4 = 181.0 мА,   t_4 = 0.4 с
   Період циклу:       T = 60.0 с

Обчислення накопиченого заряду за один цикл:
   Q_1 = 0.0273 мА · 59.2 с = 1.616 мА·с
   Q_2 = 26.5 мА · 0.3 с    = 7.950 мА·с
   Q_3 = 47.0 мА · 0.1 с    = 4.700 мА·с
   Q_4 = 181.0 мА · 0.4 с   = 72.400 мА·с

Сумарний заряд:
   Q_total = 1.616 + 7.950 + 4.700 + 72.400 = 86.666 мА·с

Середній струм споживання:
   I_avg = Q_total / T
   I_avg = 86.666 мА·с / 60.0 с ≈ 1.444 мА
```

Цей розрахунок демонструє парадокс імпульсних систем: радіопередавач працював лише 0.67% часу циклу (0.4 с із 60 с), але саме він сформував 83.5% усього енергетичного бюджету пристрою.

## Вибір архітектури стабілізації: Buck DC-DC проти LDO

Коли відомі рівні напруги та струмові профілі кожної гілки, розробник постає перед вибором топології первинних і вторинних стабілізаторів. Основний конфлікт тут розгортається між двома класами перетворювачів: високоефективними імпульсними перетворювачами ([Buck DC-DC](root:hw-power/buck)) та лінійними регуляторами з малим падінням напруги ([LDO](root:hw-power/ldo)).

![Архітектура розподілу живлення багатокомпонентної плати](/root/course/embedded/biudzhet-zhyvlennia-obviazky/img/power-tree-architecture.svg)
*Двокаскадна архітектура живлення: синхронний імпульсний перетворювач забезпечує високий ККД для цифрового ядра, а вторинний LDO фільтрує комутаційні завади для аналогових кіл.*

### Фізика ККД і втрат енергії

Лінійний регулятор працює за принципом регульованого подільника напруги: надлишок напруги `(V_in - V_out)` скидається на послідовному регулювальному транзисторі у вигляді чистого тепла. Коефіцієнт корисної дії лінійного регулятора математично обмежений відношенням напруг:

```
η_LDO = P_out / P_in
η_LDO = (V_out · I_out) / (V_in · (I_out + I_Q))
```

Якщо струм навантаження `I_out` у сотні разів перевищує власний струм спокою `I_Q`, формула спрощується до граничного співвідношення:

```
η_LDO ≈ V_out / V_in
```

Якщо на платі необхідно отримати напругу 3.3 В від акумуляторної батареї з номіналом 12.0 В (або від літій-іонної батареї 2S на 7.4 В):
- При `V_in = 12.0 В` ККД становить: `3.3 В / 12.0 В = 27.5%`. Більше ніж 72% енергії акумулятора безповоротно перетворюється на нагрів текстоліту.
- При `V_in = 7.4 В` ККД становить: `3.3 В / 7.4 В = 44.6%`.

Імпульсний знижувальний перетворювач (Buck DC-DC) діє інакше: він передає енергію порціями високої частоти через котушку індуктивності та накопичувальний конденсатор. Оскільки силові ключі перебувають або у повністю відкритому стані (опір близький до нуля), або у повністю закритому (струм дорівнює нулю), статичні втрати мінімальні. ККД сучасних синхронних Buck-перетворювачів становить 88–95% у широкому діапазоні струмів.

При цьому струм, який імпульсний стабілізатор споживає від джерела живлення, зменшується пропорційно коефіцієнту трансформації напруги:

```
I_in_buck = (V_out · I_out) / (V_in · η_buck)
```

**Worked-приклад. Порівняння споживання струму від батареї 12 В при навантаженні 3.3 В / 500 мА.**

```
Параметри навантаження:
   V_out = 3.3 В,  I_out = 0.500 А,  P_out = 1.65 Вт
   Джерело живлення: V_in = 12.0 В

1. Лінійний регулятор (LDO):
   I_in_ldo = I_out + I_Q ≈ 0.500 А
   P_in_ldo = 12.0 В · 0.500 А = 6.00 Вт
   Втрати на нагрів: P_loss = P_in - P_out = 4.35 Вт
   ККД: η = 1.65 Вт / 6.00 Вт = 27.5%

2. Синхронний Buck DC-DC (ККД η = 92%):
   P_in_buck = P_out / η = 1.65 Вт / 0.92 = 1.793 Вт
   I_in_buck = P_in_buck / V_in = 1.793 Вт / 12.0 В = 0.149 А (149 мА)
   Втрати на нагрів: P_loss = 1.793 - 1.65 = 0.143 Вт
```

Використання Buck-перетворювача скоротило навантаження на акумуляторну батарею з 500 мА до 149 мА (більш ніж у 3.3 раза), а теплові втрати на платі знизилися з 4.35 Вт до мізерних 143 мВт.

### Проблема шумів перемикання та PSRR

Чому ж інженери не використовують імпульсні перетворювачі для живлення абсолютно всіх компонентів плати? Причина криється в комутаційному шумі.

Процес перемикання транзисторів у Buck DC-DC на частотах від 500 кГц до 3 МГц генерує два типи високочастотних завад:
1. **Низькочастотні пульсації вихідної напруги (англ. *Output Ripple*):** пилкоподібні коливання на частоті комутації амплітудою 10–50 мВ, зумовлені зарядом і розрядом вихідного фільтрувального конденсатора струмом дроселя.
2. **Високочастотний дзвін (англ. *Switching Spikes / Ringing*):** короткі голчасті імпульси тривалістю кілька наносекунд з частотним спектром від 50 до 300 МГц, що виникають через паразитну індуктивність виводів ключів і зворотне відновлення діодів.

Якщо такий шум проникне в аналогову частину, 16-бітний [АЦП](root:hw-analog/adc) або чутливий інструментальний підсилювач повністю втратять точність. Коефіцієнт придушення пульсацій живлення (англ. *Power Supply Rejection Ratio*, PSRR) операційних підсилювачів та АЦП стрімко падає зі зростанням частоти. Якщо на частоті 100 Гц мікросхема може придушувати завади живлення на 80 дБ, то на частоті перемикання DC-DC (1 МГц) придушення деградує до 10–20 дБ.

Лінійні стабілізатори (LDO), навпаки, не містять вузлів перемикання і забезпечують рівень власного шуму менше ніж 10–20 мкВ RMS, діючи як активний високочастотний фільтр.

### Гібридна двокаскадна топологія «Buck + Post-LDO»

Оптимальним компромісом для складних змішаних систем є гібридна архітектура розподілу живлення (англ. *Intermediate Bus Architecture*):
1. Первинний синхронний Buck DC-DC перетворює нестабільну високу напругу батареї (наприклад, 7.4–12.0 В) на проміжну шину живлення з високим ККД.
2. Цифрові компоненти з високим струмом і низькою чутливістю до шуму (ядро МК, радіотрансивери, підсвічування) живляться безпосередньо від виходу DC-DC або через окремі цифрові стабілізатори.
3. Аналогові домени (прецизійні АЦП, джерела опорної напруги `Vref`, вхідні операційні підсилювачі) живляться через вторинний малошумний LDO (англ. *Post-Regulator LDO*).

Напругу проміжної шини обирають так, щоб падіння напруги на LDO було мінімально необхідним для забезпечення високого PSRR (зазвичай `ΔV = 0.3...0.5 В` вище номіналу LDO). Наприклад, для отримання аналогових 3.3 В проміжну шину Buck налаштовують на 3.6 В. За струму аналогової частини 50 мА теплові втрати на LDO становлять лише:

```
P_loss = (3.6 В - 3.3 В) · 0.050 А = 0.015 Вт (15 мВт)
```

Аналоговий тракт отримує абсолютно чисте живлення без шкоди для загального ККД плати та без перегріву компонентів.

## Тепловий розрахунок силових компонентів і геометрія мідних радіаторних полігонів

Кожен міліват електричної потужності, розсіяний на перетворювачі напруги, перетворюється на тепловий потік. Якщо швидкість відведення тепла в навколишнє середовище менша за швидкість його виділення, температура напівпровідникового кристала зростає до критичної межі `T_j,max` (зазвичай 125 °C або 150 °C), після чого мікросхема або деградує за надійністю, або аварійно вимикається.

![Тепловий ланцюг силового компонента на друкованій платі](/root/course/embedded/biudzhet-zhyvlennia-obviazky/img/thermal-resistance-stack.svg)
*Теплова модель переходу кристал-довкілля: тепловий потік від джерела тепла через внутрішній опір корпусу, пайку та мідний полігон плати розсіюється в навколишнє повітря.*

### Тепловий еквівалент закону Ома

Теплопередача підпорядковується законам, повністю аналогічним законам електротехніки. Тепловий потік (розсіювана потужність `P_loss`, Вт) відіграє роль струму; різниця температур (`ΔT`, °C або K) — роль різниці потенціалів (напруги); а термічний опір матеріалів (`θ`, °C/Вт) — роль електричного опору:

```
T_j = T_a + P_loss · θ_JA
```

де:
- `T_j` — температура напівпровідникового кристала (англ. *Junction Temperature*);
- `T_a` — максимальна температура навколишнього повітря всередині корпусу приладу (англ. *Ambient Temperature*);
- `P_loss` — потужність теплових втрат на компоненті;
- `θ_JA` — повний тепловий опір «перехід – навколишнє середовище» (англ. *Junction-to-Ambient Thermal Resistance*).

Повний опір `θ_JA` є сумою послідовних ділянок теплового ланцюга:

```
θ_JA = θ_JC + θ_CS + θ_SA
```

де:
- `θ_JC` — тепловий опір від кристала до корпусу або відкритого теплового майданчика (англ. *Junction-to-Case*). Задається конструкцією мікросхеми у паспорті (datasheet).
- `θ_CS` — тепловий опір шару припою або термоінтерфейсу (англ. *Case-to-Sink / Case-to-PCB*).
- `θ_SA` — тепловий опір тепловідводу (мідного полігону плати) в навколишній простір (англ. *Sink-to-Ambient*).

### Вплив корпусу та геометрії друкованої плати

Для SMD-компонентів тепло не розсіюється пластиковим корпусом у повітря (теплопровідність компаунда мізерна). Понад 90–95% тепла передається через виводи та нижній відкритий майданчик (англ. *Exposed Pad*) безпосередньо в мідні провідники друкованої плати.

**Таблиця 2. Порівняння теплового опору типових корпусів лінійних регуляторів**

| Тип корпусу | Наявність Exposed Pad | Типовий θ_JA на стандартній платі (JEDEC) | Типовий θ_JA з радіаторним полігоном 500 мм² | Максимально допустима P_loss (при T_a = 50 °C, T_j ≤ 105 °C) |
|---|---|---|---|---|
| SOT-23-5 | Ні | 220–250 °C/Вт | 160–180 °C/Вт | 0.30 Вт |
| SOT-89-3 | Так (широкий таб) | 100–120 °C/Вт | 55–65 °C/Вт | 0.85 Вт |
| SOT-223 | Так (масивний таб) | 60–80 °C/Вт | 35–45 °C/Вт | 1.25 Вт |
| DFN-8 / QFN-16 (3×3 мм) | Так (нижнє падло) | 40–50 °C/Вт | 25–30 °C/Вт | 1.80 Вт |
| TO-252 (DPAK) | Так (масивне падло) | 45–50 °C/Вт | 20–25 °C/Вт | 2.20 Вт |

### Розрахунок площі мідного полігону та масиву теплових отворів

Для ефективного охолодження компонента з Exposed Pad на платі реалізують три інженерні заходи:

1. **Верхній мідний полігон:** мідь товщиною 35 мкм (1 oz/ft²) або 70 мкм (2 oz/ft²) безпосередньо під мікросхемою. Тепловіддача зростає зі збільшенням площі полігону, проте має насичення: площа понад 600–900 мм² майже не дає додаткового ефекту через омічний тепловий опір тонкого шару самої міді вздовж плати.
2. **Масив теплових перехідних отворів (Thermal Vias):** оскільки теплопровідність діелектрика FR4 надзвичайно низька (`k_FR4 ≈ 0.25...0.3 Вт/(м·К)` проти `k_Cu ≈ 385...400 Вт/(м·К)` у міді), тепло через товщу плати передають металеві отвори.
   - Оптимальний діаметр отвору: 0.3 мм (менший діаметр запобігає витіканню припою під час пайки розплавленням);
   - Товщина міді на стінках отвору: `t_wall ≈ 20...25 мкм`;
   - Крок сітки: 1.0–1.2 мм (масив 3×3 або 4×4 безпосередньо під Exposed Pad);
   - Тепловий опір одного отвору заввишки 1.6 мм становить близько 120–160 °C/Вт. Паралельне включення 9 отворів (сітка 3×3) знижує сумарний опір переходу між шарами плати до:

```
θ_vias = θ_single_via / N
θ_vias = 135 °C/Вт / 9 = 15 °C/Вт
```

3. **Нижній суцільний шар заземлення (Bottom Ground Plane):** тепловий потік через віаси скидається у суцільний внутрішній або нижній полігон землі, площа якого може досягати всієї площі плати.

**Worked-приклад. Перевірка теплового режиму LDO у корпусі SOT-23 проти DFN-8.**

```
Умови задачі:
   Вхідна напруга: V_in = 5.0 В (шина USB)
   Вихідна напруга: V_out = 3.3 В
   Струм споживання плати: I_out = 300 мА (0.3 А)
   Температура повітря всередині корпусу: T_a = 55 °C
   Максимально допустима температура кристала з запасом надійності: T_j_limit = 105 °C

Розрахунок теплової потужності втрат:
   P_loss = (V_in - V_out) · I_out
   P_loss = (5.0 В - 3.3 В) · 0.300 А = 1.7 В · 0.300 А = 0.51 Вт

1. Перевірка варіанта в корпусі SOT-23-5 (θ_JA = 180 °C/Вт на полігоні):
   T_j = T_a + P_loss · θ_JA
   T_j = 55 °C + 0.51 Вт · 180 °C/Вт = 55 °C + 91.8 °C = 146.8 °C
   Висновок: T_j (146.8 °C) > T_j_limit (105 °C). Кристал перегріється, 
   спрацює термозахист або станеться відмова. Корпус SOT-23 НЕ підходить.

2. Перевірка варіанта в корпусі DFN-8 (3×3 мм) з Exposed Pad і масивом віасів (θ_JA = 35 °C/Вт):
   T_j = T_a + P_loss · θ_JA
   T_j = 55 °C + 0.51 Вт · 35 °C/Вт = 55 °C + 17.85 °C = 72.85 °C
   Висновок: T_j (72.85 °C) значно нижча за 105 °C. Запас за температурою становить понад 32 °C.
```

## Динамічні пікові струми, падіння напруги та вибір розв'язувальних конденсаторів

Навіть якщо стабілізатор повністю розрахований за статичним струмом і не перегрівається, плата може виходити з ладу через швидкоплинні перехідні процеси.

Коли мікроконтролер виходить зі сну або радіомодуль переходить у режим передачі, швидкість наростання струму `di/dt` досягає гігантських значень: від 100 мА до кількох амперів за лічені частки мікросекунди. Жоден лінійний або імпульсний стабілізатор не здатний миттєво відреагувати на такий стрибок: петлі зворотного зв'язку регулятора потрібен час реакції `t_response` (від 5 до 50 мкс), щоб переналаштувати шпаруватість або відкрити прохідний транзистор.

Протягом цього інтервалу часу стабілізатор фактично відсутній для навантаження — єдиним джерелом струму для мікросхеми виступає локальний банк розв'язувальних конденсаторів ([Decoupling](root:hw-components/decoupling)).

![Динамічний сплеск струму та утримання напруги ємністю](/root/course/embedded/biudzhet-zhyvlennia-obviazky/img/pulse-profile-capacitor-hold.svg)
*Динаміка струму під час передачі радіопакета: локальний буферний конденсатор утримує напругу живлення вище критичного порога скидання Brownout Reset до моменту реакції регулятора.*

### Розрахунок буферної ємності (Bulk Capacitance)

Необхідна мінімальна буферна ємність `C_bulk` для утримання шини живлення під час імпульсу струму `I_pulse` тривалістю `Δt_transient` визначається допустимим просіданням напруги `ΔV_allowed`:

```
C_bulk ≥ (I_pulse · Δt_transient) / ΔV_allowed
```

Якщо напруга шини 3.3 В просяде нижче порога скидання мікроконтролера за зниженням напруги (англ. *Brownout Reset*, `V_BOR ≈ 2.7...2.9 В`), процесор аварійно скинеться, а поточний стан програми буде втрачено.

**Worked-приклад. Розрахунок буферної ємності під радіомодуль Wi-Fi / LoRa.**

```
Параметри імпульсу:
   Сплеск струму передавача: I_pulse = 0.350 А (350 мА)
   Час реакції стабілізатора: Δt_transient = 20 мкс (20 · 10⁻⁶ с)
   Номінальна напруга шини: V_nom = 3.3 В
   Поріг спрацьовування Brownout Reset: V_BOR = 2.8 В
   Максимально допустиме просідання з запасом: ΔV_allowed = 0.15 В (150 мВ)

Розрахунок ємності:
   C_bulk = (0.350 А · 20 · 10⁻⁶ с) / 0.15 В
   C_bulk = 7.0 · 10⁻⁶ Кл / 0.15 В ≈ 4.67 · 10⁻⁵ Ф = 46.7 мкФ

Врахування ефекту DC-bias для кераміки X5R/X7R (втрата ємності до 40% під робочою напругою):
   C_nominal = C_bulk / 0.60 = 46.7 мкФ / 0.60 ≈ 77.8 мкФ
   Інженерне рішення: встановлення двох керамічних конденсаторів MLCC 47 мкФ 
   типорозміру 1206 або одного танталового полімерного конденсатора 100 мкФ з низьким ESR.
```

### Структура каскаду розв'язки (PDN Hierarchy)

Один великий конденсатор не здатен забезпечити низький імпеданс у всьому частотному діапазоні через власні паразитні параметри: еквівалентний послідовний опір (англ. *Equivalent Series Resistance*, ESR) та еквівалентну послідовну індуктивність (англ. *Equivalent Series Inductance*, ESL).

Мережу розподілу живлення (англ. *Power Distribution Network*, PDN) будують як трирівневу ієрархію:
1. **Низькочастотний буфер (Bulk / 10–100 мкФ):** електролітичні, танталові або великоформатні керамічні MLCC конденсатори біля виходу стабілізатора. Покривають діапазон від постійного струму до 100 кГц.
2. **Середньочастотна підтримка (1–10 мкФ, типорозмір 0603/0805):** кераміка X7R, розташована на відстані кількох міліметрів від мікросхеми. Покриває діапазон від 100 кГц до 10 МГц.
3. **Високочастотне блокування (0.1 мкФ / 100 нФ + 1 нФ, типорозмір 0402/0201):** кераміка з мінімальною індуктивністю виводів, підключена безпосередньо між ніжкою живлення чипа і земляним полігоном найкоротшими доріжками без перехідних отворів. Придушує наносекундні комутаційні голки в діапазоні 10–200 МГц.

## Модель розрахунку тривалості автономної роботи батарейного вузла

Для пристроїв з автономним живленням підсумком розрахунку бюджету є час життя від хімічного джерела струму (Li-Ion, LiFePO4, літієві первинні елементи Li-SOCl2).

![Розрядні криві акумуляторів та поріг відсікання](/root/course/embedded/biudzhet-zhyvlennia-obviazky/img/battery-discharge-and-cutoff.svg)
*Розрядні характеристики Li-Ion та LiFePO4: підвищення мінімальної вхідної напруги стабілізатора відсікає значну частину корисної ємності акумулятора.*

### Вплив напруги відсікання (Cut-off Voltage)

Номінальна ємність батареї `C_nom` (мА·год), вказана виробником, вимірюється при розряді до мінімальної напруги `V_min` (зазвичай 2.8–3.0 В для Li-Ion і 2.0–2.5 В для LiFePO4).

Якщо для живлення плати на 3.3 В використано лінійний стабілізатор із напругою падіння `V_drop = 0.2 В`, схема припиняє нормальну стабілізацію вже тоді, коли напруга акумулятора опускається до:

```
V_cutoff = V_out + V_drop = 3.3 В + 0.2 В = 3.5 В
```

Поглянувши на розрядну криву Li-Ion, бачимо, що ділянка від 3.5 В до 3.0 В містить близько 30–40% усієї збереженої енергії. Пристрій вимкнеться задовго до реального вичерпання хімічного заряду батареї.

Для повної утилізації енергії акумулятора використовують такі підходи:
- Переведення всієї цифрової обв'язки на живлення 2.8 В або 3.0 В (що дозволяє звичайному LDO працювати до повної розрядки банки до 3.0 В);
- Застосування неінвертувального [Buck-Boost](root:hw-power/buck-boost) перетворювача, здатного підтримувати 3.3 В як при свіжій батареї (4.2 В), так і при глибоко розрядженій (2.8 В).

### Математична модель часу автономної роботи

Час життя батарейного вузла `t_hours` з урахуванням саморозряду та ККД перетворення описується співвідношенням:

```
t_hours = (C_nom · k_usable · k_temp · k_aging) / (I_avg / η_conv + I_self + I_Q_system)
```

де:
- `C_nom` — паспортна ємність акумулятора (мА·год);
- `k_usable` — коефіцієнт доступної ємності за порогом відсікання напруги `V_cutoff` (0.65 для LDO на 3.3 В; 0.98 для Buck-Boost);
- `k_temp` — температурний коефіцієнт ємності (1.0 при 25 °C; 0.75–0.80 при 0 °C; 0.50 при −20 °C);
- `k_aging` — коефіцієнт деградації ємності від кількості циклів або терміну служби (0.80–0.90);
- `I_avg` — середній струм споживання навантаження (мА);
- `η_conv` — середній ККД системи стабілізації;
- `I_self` — струм внутрішнього саморозряду батареї (мА):

```
I_self = (C_nom · S_month) / (100% · 720 годин)
```

де `S_month` — місячний саморозряд (для Li-Ion близько 1.5–2.0% на місяць; для Li-SOCl2 менше 0.1% на рік).

## Програмно-апаратна реалізація розрахунку енергетичного профілю

У прошивці вбудованих пристроїв динамічний контроль енергетичного бюджету реалізують за допомогою модуля оцінки профілю споживання та моніторингу залишкового ресурсу батареї. Наведений модуль обчислює середньозважений струм за історією станів, залишок заряду та прогнозований час до повного розряду.

:::tabs
```c
#include <stdint.h>
#include <stdbool.h>

typedef enum {
    POWER_STATE_DEEP_SLEEP = 0,
    POWER_STATE_SENSOR_ACQ = 1,
    POWER_STATE_PROCESSING = 2,
    POWER_STATE_RADIO_TX   = 3,
    POWER_STATE_COUNT      = 4
} power_state_t;

typedef struct {
    uint32_t state_current_ua[POWER_STATE_COUNT];
    uint32_t state_duration_ms[POWER_STATE_COUNT];
    uint32_t battery_capacity_mah;
    uint32_t battery_self_discharge_ua;
    uint16_t converter_efficiency_pct;
} power_budget_config_t;

typedef struct {
    uint32_t total_cycle_time_ms;
    uint32_t avg_current_ua;
    uint32_t battery_lifetime_hours;
} power_budget_result_t;

bool power_budget_calculate(const power_budget_config_t *cfg, power_budget_result_t *res) {
    if (!cfg || !res || cfg->converter_efficiency_pct == 0) {
        return false;
    }

    uint64_t total_charge_uas = 0;
    uint32_t total_time_ms = 0;

    for (int i = 0; i < POWER_STATE_COUNT; i++) {
        uint64_t state_charge = (uint64_t)cfg->state_current_ua[i] * cfg->state_duration_ms[i];
        total_charge_uas += state_charge;
        total_time_ms += cfg->state_duration_ms[i];
    }

    if (total_time_ms == 0) {
        return false;
    }

    res->total_cycle_time_ms = total_time_ms;
    
    // Середній струм навантаження (мкА)
    uint32_t load_avg_ua = (uint32_t)(total_charge_uas / total_time_ms);

    // Врахування ККД перетворювача та власного саморозряду батареї
    uint32_t effective_draw_ua = (load_avg_ua * 100) / cfg->converter_efficiency_pct;
    effective_draw_ua += cfg->battery_self_discharge_ua;

    res->avg_current_ua = effective_draw_ua;

    if (effective_draw_ua > 0) {
        uint64_t cap_uah = (uint64_t)cfg->battery_capacity_mah * 1000ULL;
        res->battery_lifetime_hours = (uint32_t)(cap_uah / effective_draw_ua);
    } else {
        res->battery_lifetime_hours = 0;
    }

    return true;
}
```

```cpp
#include <cstdint>
#include <array>
#include <span>
#include <optional>

enum class PowerState : uint8_t {
    DeepSleep = 0,
    SensorAcquisition,
    Processing,
    RadioTx,
    Count
};

struct PowerStateProfile {
    uint32_t current_ua{0};
    uint32_t duration_ms{0};
};

struct BatteryModel {
    uint32_t capacity_mah{0};
    uint32_t self_discharge_ua{0};
    uint16_t converter_efficiency_pct{90};
};

struct PowerBudgetResult {
    uint32_t total_cycle_time_ms{0};
    uint32_t avg_current_ua{0};
    uint32_t battery_lifetime_hours{0};
};

class PowerBudgetEstimator {
public:
    static constexpr size_t StateCount = static_cast<size_t>(PowerState::Count);

    [[nodiscard]] static std::optional<PowerBudgetResult> calculate(
        std::span<const PowerStateProfile, StateCount> states,
        const BatteryModel& battery) noexcept 
    {
        if (battery.converter_efficiency_pct == 0) {
            return std::nullopt;
        }

        uint64_t total_charge_uas = 0;
        uint32_t total_time_ms = 0;

        for (const auto& state : states) {
            total_charge_uas += static_cast<uint64_t>(state.current_ua) * state.duration_ms;
            total_time_ms += state.duration_ms;
        }

        if (total_time_ms == 0) {
            return std::nullopt;
        }

        PowerBudgetResult result{};
        result.total_cycle_time_ms = total_time_ms;

        const uint32_t load_avg_ua = static_cast<uint32_t>(total_charge_uas / total_time_ms);
        const uint32_t effective_draw_ua = 
            ((load_avg_ua * 100U) / battery.converter_efficiency_pct) + battery.self_discharge_ua;

        result.avg_current_ua = effective_draw_ua;

        if (effective_draw_ua > 0) {
            const uint64_t cap_uah = static_cast<uint64_t>(battery.capacity_mah) * 1000ULL;
            result.battery_lifetime_hours = static_cast<uint32_t>(cap_uah / effective_draw_ua);
        }

        return result;
    }
};
```

## Інженерний чекліст проектування системи живлення

Перед відправкою друкованої плати у виробництво перевірте вузол живлення за контрольним списком:

1. **Струмовий запас джерел:** максимальний імпульсний вихідний струм кожного перетворювача перевищує сумарний піковий струм споживачів відповідної шини щонайменше на 30–50%.
2. **Теплова стійкість регуляторів:** для кожного лінійного регулятора розраховано розсіювану потужність `P = (V_in - V_out) · I_out`, а під мікросхемами з Exposed Pad створено суцільний мідний полігон із масивом металізованих отворів (Thermal Vias 3×3). Розрахункова температура кристала `T_j` не перевищує 100–105 °C при максимальній температурі навколишнього середовища.
3. **Захист від переполюсовки та кидків струму:** вхідний каскад містить P-канальний польовий транзистор або спеціалізований контролер ідеального діода, а також обмежувач пускового струму заряду ємностей (Inrush current limiter).
4. **Ієрархія розв'язки (PDN):** кожен радіомодуль та мікроконтролер мають індивідуальний банк танталових або великоформатних керамічних конденсаторів (10–100 мкФ) для придушення просідань, доповнений високочастотними керамічними конденсаторами 0.1 мкФ безпосередньо на кожній парі виводів живлення `VDD/VSS`.
5. **Розділення аналогових і цифрових доменів:** прецизійні аналогові мікросхеми та джерела опорної напруги живляться через окремий малошумний вторинний LDO (Post-Regulator) з високим PSRR, а не напряму від імпульсного DC-DC перетворювача.
6. **Утилізація енергії батареї:** мінімальна робоча напруга стабілізатора дозволяє розряджати акумулятор до нижньої межі його паспорта (3.0 В для Li-Ion або 2.5 В для LiFePO4) без передчасного вимкнення через брак запасу за падінням напруги (Dropout).
