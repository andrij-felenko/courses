# 🔌 Архітектура та схемотехніка трансивера RS-485

Трансивер RS-485 (transceiver, від англ. *transmitter-receiver*) — це напівпровідникова мікросхема, яка перетворює цифрові логічні рівні мікроконтролера (TTL або CMOS 3.3 В / 5 В) у симетричні диференціальні напруги промислової лінії зв'язку та виконує зворотне перетворення з придушенням синфазних завад. Розуміння внутрішньої схемотехніки трансивера дозволяє інженеру правильно обирати мікросхеми під конкретні умови експлуатації, розраховувати навантажувальну здатність шини та уникати апаратних колізій.

```
       ┌────────────────────────────────────────────────────────┐
       │                 Трансивер RS-485                       │
       │                                                        │
TXD ───┼───►[ Буфер передавача ]───►[ H-міст (Push-Pull) ]──────┼───► A (+)
       │                                   │                    │
 DE ───┼───►[ Керування передавачем ]──────┘                    │
       │                                                        │
/RE ───┼───►[ Керування приймачем ]────────┐                    │
       │                                   ▼                    │
RXD ◄──┼───[ Вихідний буфер ]◄───[ Компаратор із гістерезисом ]─┼───► B (-)
       │                                                        │
       └────────────────────────────────────────────────────────┘
```

## Структурна організація передавача (Driver)

Передавач трансивера складається з логічного вхідного каскаду, схеми керування напрямком (Driver Enable, `DE`), формувача швидкості наростання фронтів та вихідного диференціального H-моста.

Коли на вході `DE` встановлено високий логічний рівень, вихідний каскад активується. Залежно від стану входу даних `TXD` (або `DI` — *Driver Input*), H-міст комутує вихідні виводи `A` та `B`:

* Якщо `TXD = 1` (стан спокою / Mark): верхній ключ плеча `A` відкритий і підтягує лінію `A` до напруги живлення `V_CC`, а нижній ключ плеча `B` відкритий і з'єднує лінію `B` із `GND`. Диференціальна вихідна напруга `V_OD = V_A - V_B > 0` (зазвичай від `+1.5 В` до `+3.3 В` під навантаженням).
* Якщо `TXD = 0` (стан активності / Space): верхній ключ плеча `B` підтягує лінію `B` до `V_CC`, а нижній ключ плеча `A` з'єднує лінію `A` із `GND`. Диференціальна напруга `V_OD = V_A - V_B < 0` (від `-1.5 В` до `-3.3 В`).

Коли `DE = 0`, усі чотири ключі H-моста закриваються. Виводи `A` та `B` переходять у високоімпедансний стан (High-Z), у якому вихідний струм витоку не перевищує кількох мікроамперів. Це дозволяє підключати до однієї пари десятків інших передавачів без взаємного шунтування.

### Обмеження швидкості наростання фронту (Slew-Rate Limiting)

Стандартні високошвидкісні трансивери (наприклад, класичний SN75176 або швидкісні версії MAX3485) здатні перемикати вихідні каскади за 5–10 нс, забезпечуючи швидкість передачі даних до 10–50 Мбіт/с. Проте надзвичайно круті фронти генерують потужний спектр високочастотних гармонік у діапазоні десятків і сотень мегагерців. На довгих лініях зв'язку це призводить до значного електромагнітного випромінювання (EMI) та викликає сильні паразитні відбиття на будь-яких неоднорідностях кабелю або нетермінованих відгалуженнях.

Трансивери з обмеженням швидкості наростання фронту (Slew-Rate Limited, такі як MAX483, MAX3082, SN65HVD12) містять у колі керування затворами вихідних польових транзисторів внутрішні стабілізатори струму заряду. Час наростання та спаду фронтів `t_r / t_f` у таких мікросхемах примусово збільшено до 200–800 нс. Це обмежує максимальну швидкість передачі значенням 115.2–250 кбіт/с, але кардинально покращує електромагнітну сумісність і дозволяє експлуатувати лінії довжиною сотні метрів навіть за наявності коротких нетермінованих відгалужень.

## Будова приймача (Receiver) та пороги спрацьовування

Приймальний каскад складається з високоомного резистивного дільника напруги, прецизійного диференціального компаратора та вихідного логічного буфера зі станом High-Z, керованого входом `/RE` (Receiver Enable, активний низький рівень).

Стандарт TIA/EIA-485-A визначає такі вимоги до вхідного компаратора:

1. Якщо диференціальна напруга `V_AB = V_A - V_B ≥ +200 мВ`, на виході `RXD` (або `RO` — *Receiver Output*) гарантовано встановлюється логічна `1`.
2. Якщо `V_AB = V_A - V_B ≤ -200 мВ`, на виході `RXD` гарантовано встановлюється логічний `0`.
3. Діапазон напруг від `-200 мВ` до `+200 мВ` є зоною невизначеності (гістерезису або переходу).

### Вхідний імпеданс та поняття Unit Load

Навантаження, яке приймач створює для лінії зв'язку, стандартизовано через поняття одиничного навантаження (Unit Load, `1 UL`). За стандартом `1 UL` відповідає вхідному опору близько 12 кОм при синфазній напрузі до `+12 В` (або струму витоку не більше 1.0 мА).

Стандартний передавач RS-485 розрахований на роботу з мінімальним еквівалентним навантаженням 54 Ом, що відповідає двом паралельним термінаторам по 120 Ом (60 Ом) та сумарному вхідному опору підключених вузлів:

```
1/R_total = 1/R_term_eq + N · (1/R_in)
```

Для класичних мікросхем із вхідним опором `1 UL` (12 кОм) максимальна кількість пристроїв на шині становить `N = 32`.

Сучасні трансивери використовують високоомні вхідні структури на польових транзисторах:
* `1/2 UL` (`R_in ≥ 24 кОм`) — до 64 вузлів на шині;
* `1/4 UL` (`R_in ≥ 48 кОм`) — до 128 вузлів на шині;
* `1/8 UL` (`R_in ≥ 96 кОм`) — до 256 вузлів на шині.

### Справжній апаратний захист від невизначеного стану (True Fail-Safe)

У класичних трансиверах поріг перемикання компаратора розташовано симетрично довкола нуля (`V_th = 0 В ± 20 мВ` гістерезису). Коли всі передавачі вимкнені або дріт обірвано, `V_AB = 0 В`, і вихід приймача потрапляє в зону невизначеності.

Трансивери із функцією *True Fail-Safe* мають штучно зміщений діапазон порогів компаратора:

```
-200 мВ ≤ V_th_min < V_th_max ≤ -50 мВ
```

У такій структурі, якщо диференціальна напруга `V_AB` перевищує `-50 мВ` (зокрема при `V_AB = 0 В` під час стану спокою, обриву кабелю або короткого замикання ліній між собою), компаратор однозначно фіксує стан логічної `1` на виході `RO`. Це усуває потребу у зовнішніх резисторах зміщення (Fail-Safe Biasing) для ліній помірної довжини.

## Внутрішні захисні механізми

Інтегральні трансивери RS-485 розраховані на суворі умови експлуатації та містять комплекс внутрішніх апаратних блоків захисту кристала:

1. **Захист від короткого замикання (Current Limiting):** вихідні драйвери оснащені схемами відстеження струму, які обмежують вихідний струм на рівні 150–250 мА навіть при тривалому замиканні виводів `A` або `B` на шини живлення від `-7 В` до `+12 В`.
2. **Теплове вимкнення (Thermal Shutdown):** при тривалій апаратній колізії (коли два передавачі намагаються передавати протилежні логічні рівні на спільну шину) температура кристала зростає. При досягненні порогу близько `+150..+165 °C` вбудований термодатчик примусово переводить вихідний каскад у стан High-Z. Після охолодження до `+140 °C` драйвер автоматично повертається до роботи (температурний гістерезис запобігає автогенерації).
3. **Вбудований ESD-захист:** спеціалізовані діодні та стабілітронні структури на виводах підключення шини витримують електростатичні розряди до `±15 кВ` (за моделлю людського тіла HBM або IEC 61000-4-2 при повітряному розряді).
