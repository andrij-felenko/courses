# 🧮 Хвильові процеси та відбиття в довгій лінії зв'язку

Коли довжина дроту стає співмірною із часом зміни електричного сигналу, провідник перестає поводитися як ідеальний еквіпотенціальний вузол із законів Кірхгофа. Електромагнітне поле поширюється вздовж лінії зі скінченною швидкістю, утворюючи біжучі хвилі напруги та струму. Якщо лінія на своєму кінці зустрічає зміну хвильового опору, виникає відбита хвиля, яка накладається на корисний сигнал і спотворює цифрову інформацію.

## Модель довгої лінії з розподіленими параметрами

Нескінченно малий відрізок витої пари довжиною `Δx` описується чотирма погонними параметрами:
* `R'` — погонний омічний опір провідників (Ом/м);
* `L'` — погонна індуктивність провідників (Гн/м);
* `C'` — погонна ємність між провідниками (Ф/м);
* `G'` — погонна провідність діелектрика (См/м).

```
   x ───[ R'·Δx ]───[ L'·Δx ]───┬──────── x + Δx
                                │
                              [ C'·Δx ]
                                │
                              [ G'·Δx ]
                                │
   ─────────────────────────────┴────────
```

Рівняння зміни напруги `V(x, t)` та струму `I(x, t)` вздовж відрізка `Δx` (телеграфні рівняння у диференціальній формі):

```
∂V(x, t)/∂x = -R' · I(x, t) - L' · ∂I(x, t)/∂t
∂I(x, t)/∂x = -G' · V(x, t) - C' · ∂V(x, t)/∂t
```

Для гармонічних коливань із частотою `ω` (`V(x) = V₀ · e^(jωt)`):

```
dV/dx = -(R' + jωL') · I
dI/dx = -(G' + jωC') · V
```

Диференціюючи перше рівняння за координатою `x` і підставляючи друге, отримуємо класичне хвильове рівняння:

```
d²V/dx²
= -(R' + jωL') · (dI/dx)                [диференціювання за координатою x]
= (R' + jωL') · (G' + jωC') · V         [підстановка виразу для dI/dx]
= γ² · V                                [введення коефіцієнта поширення γ]
```

Комплексний коефіцієнт поширення `γ = α + jβ`, де `α` — коефіцієнт згасання (Непер/м), а `β` — фазовий коефіцієнт (рад/м):

```
γ = √((R' + jωL') · (G' + jωC'))
```

## Хвильовий опір лінії (Characteristic Impedance)

Загальний розв'язок хвильового рівняння для напруги та струму є сумою прямої (падаючої) та зворотної (відбитої) хвиль:

```
V(x) = V⁺ · e^(-γx) + V⁻ · e^(+γx)
I(x) = I⁺ · e^(-γx) - I⁻ · e^(+γx)
```

Хвильовий опір лінії `Z₀` визначається як відношення напруги прямої хвилі до її струму у довільній точці:

```
Z₀
= V⁺ / I⁺                               [за означенням хвильового опору]
= (R' + jωL') / γ                       [зв'язок із першого телеграфного рівняння]
= √((R' + jωL') / (G' + jωC'))          [підстановка виразу для γ]
```

Для високочастотних складових сигналу (де `ωL' >> R'` та `ωC' >> G'`, що повністю виконується для цифрових фронтів перемикання RS-485 із тривалістю менше мікросекунди):

```
Z₀
≈ √( (jωL') / (jωC') )                  [нехтування втратами: R' → 0, G' → 0]
= √(L' / C')                            [скорочення jω: суто активний опір]
```

Для стандартного промислового кабелю витої пари категорії 5e або спеціалізованого кабелю RS-485 (наприклад, Belden 9841):
* `L' ≈ 0.6 мкГн/м`;
* `C' ≈ 42 пФ/м`.

Обчислюємо хвильовий опір:

```
Z₀
= √( (0.6 · 10⁻⁶ Гн/м) / (42 · 10⁻¹² Ф/м) )  [підстановка погонних L' та C']
= √( 14285.7 Ом² )                           [ділення під коренем]
≈ 119.5 Ом                                   [стандартний номінал 120 Ом]
```

Швидкість поширення електромагнітної хвилі в діелектрику кабелю:

```
v
= 1 / √(L' · C')                        [фазова швидкість хвилі в лінії]
= c / √(ε_r)                            [через швидкість світла c та проникність ε_r]
```

Для суцільного поліетиленового діелектрика (`ε_r ≈ 2.25`):

```
v
= (3.0 · 10⁸ м/с) / √(2.25)             [підстановка швидкості c та проникності ε_r]
= (3.0 · 10⁸ м/с) / 1.5                 [обчислення кореня з 2.25]
= 2.0 · 10⁸ м/с = 200 мм/нс             [затримка поширення t_d = 5 нс/м]
```

Для лінії довжиною `L = 100 м` час проходження хвилі в один кінець становить:

```
t_prop = 100 м / (2.0 · 10⁸ м/с) = 500 нс
```

Час подвійного пробігу (туди й назад) становить `τ = 2 · t_prop = 1.0 мкс`.

## Вплив розподіленої ємності підключених трансиверів на хвильовий опір

У реальній промисловій мережі до стометрової магістралі підключаються десятки вузлів. Кожен трансивер RS-485 разом із захисними діодами TVS, роз'ємом та друкованими доріжками плати вносить у точку підключення зосереджену паразитну ємність `C_node ≈ 15..25 пФ`.

Якщо на лінії довжиною `L = 100 м` рівномірно розташовано `N = 32` пристрої, сумарна додаткова ємність становить:

```
C_add_total = 32 · 20 пФ = 640 пФ
```

Це збільшує еквівалентну погонну ємність кабелю:

```
C_d = C_add_total / L = 640 пФ / 100 м = 6.4 пФ/м
C'_eff = C' + C_d = 42 пФ/м + 6.4 пФ/м = 48.4 пФ/м
```

Ефективний хвильовий опір навантаженої лінії `Z₀_eff` знижується:

```
Z₀_eff
= √(L' / C'_eff)                        [загальна формула з новою ємністю]
= Z₀ / √(1 + C_d / C')                  [факторизація відносно початкового Z₀]
= 120 Ом / √(1 + 6.4 / 42)              [підстановка числових значень]
= 120 Ом / √(1.152)                     [обчислення виразу під коренем]
= 120 Ом / 1.073                        [добування кореня]
≈ 111.8 Ом                              [зниження хвильового опору на 7%]
```

Якщо ж вузли згруповані щільно (наприклад, 16 модулів у межах однієї монтажної шафи на відрізку 2 метри), погонна ємність на цій ділянці зростає в кілька разів, знижуючи локальний хвильовий опір до 60–80 Ом. Це створює локальну неоднорідність, яка відбиває частину енергії сигналу навіть за ідеальної кінцевої термінації 120 Ом.

## Коефіцієнт відбиття на межі середовищ

Нехай лінія з хвильовим опором `Z₀` навантажена на кінці на опір `R_L`. У точці з'єднання `x = L` повна напруга є сумою падаючої та відбитої хвиль, а повний струм — їхньою різницею:

```
V_total = V⁺ + V⁻
I_total = I⁺ - I⁻ = (V⁺ / Z₀) - (V⁻ / Z₀)
```

За законом Ома на навантаженні `V_total = I_total · R_L`:

```
V⁺ + V⁻ = ( (V⁺ - V⁻) / Z₀ ) · R_L
```

Розкриваючи дужки та групуючи доданки:

```
Z₀ · (V⁺ + V⁻) = R_L · (V⁺ - V⁻)        [множення обох частин на Z₀]
Z₀·V⁺ + Z₀·V⁻ = R_L·V⁺ - R_L·V⁻         [розкриття дужок]
V⁻ · (R_L + Z₀) = V⁺ · (R_L - Z₀)       [перенесення V⁻ ліворуч, V⁺ праворуч]
```

Коефіцієнт відбиття за напругою `Γ_L` визначається як відношення амплітуди відбитої хвилі до амплітуди падаючої:

```
Γ_L
= V⁻ / V⁺                               [за означенням коефіцієнта відбиття]
= (R_L - Z₀) / (R_L + Z₀)               [виведення з граничної умови на навантаженні]
```

### Аналіз трьох граничних випадків

1. **Розімкнений кінець (Open Circuit, R_L → ∞):**

```
Γ_L
= lim(R_L → ∞) (R_L - Z₀) / (R_L + Z₀)  [граничний перехід при нескінченному опорі]
= +1                                    [відбиття у тій самій фазі]
```

Відбита хвиля повертається з тією ж полярністю. На кінці лінії напруга подвоюється: `V_end = V⁺ + (+1 · V⁺) = 2 · V⁺`.

2. **Коротке замикання (Short Circuit, R_L = 0):**

```
Γ_L
= (0 - Z₀) / (0 + Z₀)                   [підстановка нульового опору навантаження]
= -1                                    [відбиття у протифазі]
```

Відбита хвиля інвертує знак і гасить падаючу хвилю: `V_end = V⁺ + (-1 · V⁺) = 0 В`.

3. **Узгоджене навантаження (Matched Termination, R_L = Z₀ = 120 Ом):**

```
Γ_L
= (120 - 120) / (120 + 120)             [підстановка узгодженого номіналу 120 Ом]
= 0                                     [повне поглинання енергії]
```

Відбита хвиля відсутня (`V⁻ = 0`). Енергія повністю поглинається термінатором, як у нескінченній лінії.

## Багаторазові відбиття та ступеневий відгук (Діаграма решітки)

Розглянемо передавач із внутрішнім опором `R_S = 20 Ом`, який формує перепад напруги `V_src = 5 В` у нетерміновану лінію `Z₀ = 120 Ом` із розімкненим кінцем (`R_L = ∞`, `Γ_L = +1`).

Коефіцієнт відбиття на стороні джерела:

```
Γ_S
= (R_S - Z₀) / (R_S + Z₀)               [формула коефіцієнта відбиття]
= (20 - 120) / (20 + 120)               [підстановка значень R_S = 20 та Z₀ = 120]
= -100 / 140                            [обчислення чисельника та знаменника]
≈ -0.714                                [відбиття у протифазі від низькоомного виходу]
```

Початкова напруга, що входить у лінію у момент `t = 0`:

```
V₁⁺
= V_src · (Z₀ / (R_S + Z₀))             [дільник напруги між джерелом і лінією]
= 5 В · (120 / (20 + 120))              [підстановка V_src = 5 В, R_S = 20 Ом]
= 5 В · 0.857                           [коефіцієнт передачі дільника]
= 4.286 В                               [амплітуда прямої хвилі]
```

Розрахунок напруги на приймачі `V_rx(t)` на часовій осі:

* `t = 0.5 τ` (перша хвиля дійшла до кінця):
  `V_rx = V₁⁺ + Γ_L · V₁⁺ = 4.286 В + 4.286 В = 8.572 В` (небезпечний викид перенапруги, здатний пробити вхідний каскад).

* `t = 1.0 τ` (хвиля повернулася до джерела):
  Від джерела відбивається хвиля `V₂⁺ = Γ_S · (Γ_L · V₁⁺) = -0.714 · 4.286 В = -3.060 В`.

* `t = 1.5 τ` (друга хвиля дійшла до приймача):
  `V_rx = 8.572 В + V₂⁺ + Γ_L · V₂⁺ = 8.572 В + (-3.060 В) + (-3.060 В) = 2.452 В`.

* `t = 2.0 τ` (хвиля знову відбилася від джерела):
  `V₃⁺ = Γ_S · (-3.060 В) = -0.714 · (-3.060 В) = +2.185 В`.

* `t = 2.5 τ`:
  `V_rx = 2.452 В + 2.185 В + 2.185 В = 6.822 В`.

* `t = 3.5 τ`:
  `V_rx = 6.822 В - 1.560 В - 1.560 В = 3.702 В`.

Коливання напруги ("дзвін" або *ringing*) тривають протягом багатьох мікросекунд, багаторазово перетинаючи пороги компаратора приймача і викликаючи помилкові біти даних.

## Критерій критичної довжини лінії та часу наростання фронту

Відбиття стають руйнівними, якщо фронт сигналу встигає повністю встановитися до того, як перше відбиття повернеться до передавача.

Нехай час наростання фронту сигналу становить `t_r` (від 10% до 90% амплітуди). Час повернення відбитої хвилі до джерела дорівнює `2 · t_prop = 2L / v`.

Умова переходу лінії у категорію довгих (розподілених):

```
t_r < 2 · t_prop = 2L / v
```

Звідси критична довжина лінії `L_crit`, понад яку узгодження стає строго обов'язковим:

```
L_crit
= (v · t_r) / 2                         [критерій подвійного пробігу]
```

Для швидкісного трансивера з крутим фронтом `t_r = 10 нс`:

```
L_crit = (200 мм/нс · 10 нс) / 2 = 1000 мм = 1.0 м
```

Будь-який кабель довжиною понад 1 метр для такого трансивера є довгою лінією і без термінації 120 Ом генеруватиме спотворення.

Для трансивера з обмеженням швидкості фронту (Slew-Rate Limited) `t_r = 250 нс`:

```
L_crit = (200 мм/нс · 250 нс) / 2 = 25000 мм = 25.0 м
```

Звідси випливає важливий практичний висновок: уповільнення фронту передавача у 25 разів збільшує допустиму довжину нетермінованих відгалужень (stubs) на шині від кількох сантиметрів до кількох метрів.

## Згасання високих частот через скін-ефект та діелектричні втрати

На довжинах кабелю від 100 до 1200 метрів істотну роль відіграє частотно-залежне згасання коефіцієнта `α(ω)`.

Опір провідника `R'(ω)` зростає пропорційно `√f` внаслідок скін-ефекту (витіснення струму до поверхні провідника). Глибина проникнення струму в мідь дорівнює:

```
δ = 1 / √(π · f · μ · σ)
```

На частоті `f = 10 МГц` глибина скін-шару для міді становить лише `δ ≈ 21 мкм`, що зменшує ефективний переріз жили діаметром 0.5 мм (24 AWG) у кілька разів. Високочастотні гармоніки прямокутного імпульсу згасають швидше, ніж низькочастотні, що призводить до «завалювання» крутизни фронтів (дисперсії) та викликає міжсимвольну інтерференцію (Inter-Symbol Interference, ISI). Для збереження форми очного графіка (Eye Diagram) на довжинах понад 500 метрів швидкість передачі даних у промислових мережах обмежують значеннями 9600–38400 біт/с.
