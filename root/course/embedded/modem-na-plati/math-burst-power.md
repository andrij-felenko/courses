# 🧮 Розрахунок імпульсної просадки шини живлення модема (PDN)

У цьому розрахунку виведено аналітичну модель розподільчої мережі живлення (Power Delivery Network — PDN) стільникового модема під час випромінювання високопотужних передавальних пакетів (Tx Bursts). Розрахунок дозволяє точно визначити мінімальну ємність накопичувальних конденсаторів, допустимий еквівалентний послідовний опір (ESR) та геометрію мідних провідників друкованої плати для запобігання спрацьовуванню захисту від зниження напруги (Under-Voltage Lockout — UVLO).

---

## 1. Енергетичні параметри передавального сплеску (Tx Burst)

У стандартах GSM/GPRS (2G) передача даних здійснюється за схемою часового мультиплексування TDMA (Time Division Multiple Access). Несуча частота розбивається на кадри тривалістю `T_frame = 4.615 мс`, кожен із яких містить 8 часових інтервалів (таймслотів). Один передавальний слот триває:

```
t_burst = 3 / 5200 с ≈ 576.92 мкс ≈ 577 мкс
```

Під час цього таймслоту підсилювач потужності (Power Amplifier — PA) випромінює радіочастотний сигнал максимальною потужністю:

```
P_RF = +33 dBm = 10^(33 / 10) мВт = 1995.26 мВт ≈ 2.0 Вт (GSM 850/900 МГц)
```

Коефіцієнт корисної дії (ККД) сучасного інтегрованого кремнієвого PA у режимі насичення становить `η_PA ≈ 42–48%` (приймемо розрахункове значення `η = 0.45`). Необхідна електрична потужність постійного струму тільки для живлення вихідного каскаду PA:

```
P_DC_PA
= P_RF / η
= 2.0 / 0.45       [підстановка значень потужності та ККД]
≈ 4.44 Вт
```

Додатково цифрове ядро модема (Baseband DSP + ARM SoC), приймальний тракт та пам'ять LPDDR споживають базову потужність `P_baseband ≈ 0.8 Вт`. Загальна миттєва потужність, споживана модемом від шини живлення під час передавального імпульсу:

```
P_total
= P_DC_PA + P_baseband
= 4.44 + 0.8       [додавання потужності каскадів]
= 5.24 Вт
```

При номінальній напрузі шини `V_BAT = 3.8 В` струм споживання модема становить:

```
I_peak
= P_total / V_BAT
= 5.24 / 3.8       [закон збереження потужності]
≈ 1.38 А
```

Якщо ж напруга на батареї або виході стабілізатора просідає до нижньої робочої межі `V_BAT = 3.4 В`, для забезпечення тієї самої випромінюваної потужності 2 Вт струм зростає:

```
I_peak_max
= 5.24 / 3.4       [струм при мінімальній робочій напрузі]
≈ 1.54 А
```

З урахуванням перехідних процесів заряду внутрішніх паразитарних ємностей та роботи антенного тюнера піковий струм у специфікаціях виробників (Quectel, SIMCom, Telit) нормується на рівні:

```
I_burst = 2.0 А
```

## 2. Аналітична модель просадки напруги в розподільчій мережі (PDN)

Еквівалентна схема підсистеми живлення містить джерело стабілізованої напруги (DC-DC Buck перетворювач), активний опір доріжки друкованої плати `R_trace`, індуктивність доріжки `L_trace` та батарею паралельних конденсаторів із загальною ємністю `C_total` і сумарним послідовним опором `ESR_total`.

Повна динамічна просадка напруги на виводах модема `ΔV_total(t)` під час прямокутного імпульсу струму амплітудою `I_burst` складається з трьох фізичних складових:

```
ΔV_total(t) = ΔV_trace + ΔV_ESR + ΔV_cap(t)
```

Розглянемо кожну складову окремо.

### Складова 1: Падіння напруги на мідному провіднику друкованої плати (`ΔV_trace`)

Питомий поверхневий опір шару міді товщиною `t_cu = 35 мкм` (стандартна фольга 1 oz) при питомому об'ємному опорі міді `ρ = 1.72·10⁻⁸ Ом·м` становить:

```
R_sq
= ρ / t_cu
= 1.72·10⁻⁸ / 35·10⁻⁶   [питомий опір квадрата фольги 1 oz]
≈ 0.491 мОм / square
```

Для провідника довжиною `L = 30 мм` і шириною `W = 2.0 мм` кількість квадратів складає `N_sq = L / W = 30 / 2.0 = 15`. Опір доріжки:

```
R_trace
= N_sq · R_sq
= 15 · 0.491·10⁻³       [добуток кількості квадратів на опір квадрата]
≈ 7.37 мОм
```

Падіння напруги на доріжці при струмі 2.0 А:

```
ΔV_trace
= I_burst · R_trace
= 2.0 · 7.37·10⁻³       [закон Ома для омічного опору доріжки]
≈ 14.74 мВ ≈ 15 мВ
```

### Складова 2: Миттєвий стрибок напруги на еквівалентному послідовному опорі (`ΔV_ESR`)

У момент виникнення фронту струму (`t = 0+`) ємність конденсатора ще не встигає розрядитися, але через його внутрішній опір `ESR` виникає миттєвий стрибок падіння напруги:

```
ΔV_ESR = I_burst · ESR_total
```

Якщо використовується танталовий конденсатор з `ESR = 50 мОм`, миттєве падіння становить:

```
ΔV_ESR
= 2.0 · 0.05            [миттєвий резистивний стрибок]
= 100 мВ
```

*Примітка:* Якщо розробник помилково встановить стандартний алюмінієвий електролітичний конденсатор з `ESR = 0.5 Ом`, стрибок складе `2.0 · 0.5 = 1.0 В`, що миттєво опустить напругу нижче порогу UVLO (3.3 В) та спричинить перезавантаження процесора.

### Складова 3: Інтегральний розряд ємності конденсаторного буфера (`ΔV_cap`)

DC-DC Buck перетворювач має скінченну смугу пропускання контуру зворотного зв'язку (зазвичай `f_BW ≈ 30–60 кГц`), тому час його реакції на різкий стрибок навантаження становить `t_resp ≈ 1 / (2·π·f_BW) ≈ 5–10 мкс`.

Після виходу регулятора на робочий режим він здатний забезпечувати стабільний середній струм `I_reg`. Якщо DC-DC перетворювач розрахований на струм `I_reg = 1.5 А`, решту струмового дефіциту `I_cap = I_burst - I_reg = 2.0 - 1.5 = 0.5 А` протягом усього імпульсу `t_burst = 577 мкс` має віддавати накопичувальна ємність:

```
ΔV_cap
= (1 / C_total) · ∫ [0 to t_burst] I_cap dt
= (I_cap · t_burst) / C_total     [інтегрування постійного струму дефіциту]
```

Для батареї конденсаторів номіналом `C_total = 470 мкФ`:

```
ΔV_cap
= (0.5 · 577·10⁻⁶) / (470·10⁻⁶)
= 288.5·10⁻⁶ / 470·10⁻⁶           [підстановка часу 577 мкс і ємності 470 мкФ]
≈ 0.614 В / 1.0
≈ 61.4 мВ
```

## 3. Загальний баланс просадки та перевірка запасу надійності

Підсумуємо всі три складові просадки для конфігурації з танталовим конденсатором 470 мкФ (Low-ESR 50 мОм) та мідною шиною 2 мм:

```
ΔV_total
= ΔV_trace + ΔV_ESR + ΔV_cap
= 14.74 + 100.0 + 61.38          [додавання омічної, ESR та ємнісної складових]
≈ 176.12 мВ ≈ 176 мВ
```

Перевіримо мінімальну напругу на виводах модема при номінальному рівні стабілізатора `V_out = 3.80 В`:

```
V_min_pin
= V_out - ΔV_total
= 3.80 - 0.176                   [розрахунок найнижчої точки просадки]
= 3.624 В
```

Запас до порогу аварійного вимкнення модема `V_UVLO = 3.30 В`:

```
V_margin
= V_min_pin - V_UVLO
= 3.624 - 3.300                  [перевірка запасу надійності]
= 0.324 В = 324 мВ
```

Отриманий запас 324 мВ гарантує стабільну роботу радіомодема навіть за умов коливань температури навколишнього середовища та старіння компонентів.

## 4. Врахування ефекту деградації ємності керамічних конденсаторів (DC-Bias Effect)

При виборі керамічних конденсаторів класу II (діелектрики X5R, X7R) необхідно враховувати фізичне явище падіння ефективної ємності під дією прикладеної постійної напруги зміщення (DC-Bias Voltage).

У сегнетоелектричних доменах діелектрика титанату барію (`BaTiO_3`) постійне електричне поле насичує диполі, внаслідок чого диференціальна діелектрична проникність `ε_r(V)` різко падає:

```
C_eff(V) = C_0 · (1 + (V_bias / V_crit)^2)^(-μ)
```

Для типового MLCC конденсатора номіналом 100 мкФ у корпусі 0805 на робочу напругу 6.3 В:
- При `V_bias = 0 В`: `C_eff = 100 мкФ`;
- При робочій напрузі модема `V_bias = 3.8 В`: ефективна ємність падає на 65–70%, тобто реальна ємність становить лише:

```
C_eff_3.8V
= 100 · (1 - 0.68)
= 32 мкФ                         [врахування падіння ємності через DC-Bias]
```

**Інженерний висновок:** Спроба набрати необхідні 470 мкФ виключно компактними керамічними конденсаторами 0805/0603 призведе до того, що реальна ємність під напругою 3.8 В виявиться втричі меншою за розрахункову. Саме тому основу силового буфера модема повинен складати полімерний танталовий (POSCAP) або ніобієвий конденсатор ємністю 330–470 мкФ (у яких ефект DC-Bias повністю відсутній), доповнений керамічними MLCC для придушення високої частоти.
