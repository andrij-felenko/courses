# 🧮 Тепловий баланс силової доріжки: від рівняння Фур'є до норм IPC-2152

Спроба оцінити допустимий струм друкованої доріжки за спрощеними емпіричними формулами без розуміння теплового балансу призводить або до кількаразового перевитрачання міді на платі, або до локального перегріву й розшарування склотекстоліту FR-4. Тепло в провіднику генерується об'ємно через джоулеві втрати, але відводиться через складний тривимірний ланцюг: теплопровідність через тонкий діелектрик у внутрішні мідні шари, поперечне розтікання тепла по полігонах заземлення та конвективно-радіаційний теплообмін із навколишнім повітрям. Тут виведено точні рівняння стаціонарного та перехідного теплового балансу, показано математичну границю застосовності формули IPC-2221 та побудовано фізично обґрунтовану модель IPC-2152.

## Теплове рівняння та температурна залежність опору

Електричний опір мідного провідника довжиною L, шириною w і товщиною t за температури T визначається питомим опором міді ρ(T). Питомий опір електролітичної міді (annealed copper, IACS 100%) зростає лінійно з температурою в робочому діапазоні від −40 °C до +150 °C:

```
rho(T) = rho_0 * [1 + alpha_0 * (T - T_0)]
```
де:
- `rho_0 = 1.724e-8 Ом*м` — питомий опір міді за базової температури `T_0 = 20 °C` (293.15 K);
- `alpha_0 = 0.00393 1/°C` (або `3.93e-3 K^-1`) — температурний коефіцієнт опору (ТКО) чистої міді.

Опір доріжки площею поперечного перерізу `A = w * t` записується як:

```
R(T) = rho(T) * L / A
     = (rho_0 * L / A) * [1 + alpha_0 * (T - T_0)]
     = R_0 * [1 + alpha_0 * (T - T_0)]
```

Під час протікання постійного струму I в об'ємі провідника виділяється потужність джоулевого нагріву `P_gen`:

```
P_gen(T) = I^2 * R(T)
         = I^2 * R_0 * [1 + alpha_0 * (T - T_0)]     [підстановка лінійної моделі опору]
```

Зверніть увагу на позитивний зворотний зв'язок: нагрівання збільшує опір, що при фіксованому струмі навантаження збільшує генерацію тепла.

## Стаціонарний тепловий баланс та тепловідведення

У стаціонарному стані вся згенерована потужність `P_gen` має передаватися в навколишнє середовище через ефективний тепловий опір `R_th` (вимірюється в °C/Вт або K/Вт). Тепловий потік розсіювання `P_diss` за температури навколишнього середовища `T_amb` дорівнює:

```
P_diss(T) = (T - T_amb) / R_th = Delta_T / R_th
```

Прирівнюючи генерацію тепла та тепловідведення, отримуємо фундаментальне рівняння стаціонарної температури доріжки:

```
I^2 * R_0 * [1 + alpha_0 * (T - T_0)] = (T - T_amb) / R_th
```

Розгорнемо вираз відносно усталеної температури провідника T:

```
I^2 * R_0 * [1 + alpha_0 * (T - T_amb + T_amb - T_0)] = Delta_T / R_th
I^2 * R_0 * [1 + alpha_0 * (T_amb - T_0)] + I^2 * R_0 * alpha_0 * Delta_T = Delta_T / R_th
I^2 * R_amb + I^2 * R_0 * alpha_0 * Delta_T = Delta_T / R_th
Delta_T * [1 / R_th - I^2 * R_0 * alpha_0] = I^2 * R_amb
Delta_T = (I^2 * R_amb * R_th) / [1 - I^2 * R_0 * alpha_0 * R_th]
```
де `R_amb = R_0 * [1 + alpha_0 * (T_amb - T_0)]` — початковий опір доріжки за температури навколишнього середовища.

### Умова теплової стійкості (Thermal Runaway Criterion)

Знаменник отриманого виразу показує критичну границю стійкості. Якщо потужність нагріву перевищує здатність системи відводити додаткове тепло від зростання ТКО, знаменник прямує до нуля, і температура нескінченно зростає до перегорання провідника. Умова теплової стійкості:

```
I^2 * R_0 * alpha_0 * R_th < 1
I_crit = sqrt( 1 / (R_0 * alpha_0 * R_th) )
```

Для реальних друкованих доріжок струм експлуатації вибирають так, щоб `I <= 0.5 * I_crit`, де коефіцієнт нелінійності від ТКО дає помірну поправку (збільшення перегріву на 10..25% порівняно з розрахунком на холодному опорі).

## Модель IPC-2221: емпірична степенева апроксимація

Історичний стандарт IPC-2221 (що спирався на дані NBS 1954 року) апроксимував тепловий баланс ізольованої доріжки у вільному повітрі степеневою функцією:

```
I = k * (Delta_T)^0.44 * A^0.725
```
де:
- `I` — допустимий струм в амперах [А];
- `Delta_T = T - T_amb` — допустимий перегрів у градусах Цельсія [°C];
- `A` — площа поперечного перерізу доріжки в квадратних мілах [mil²] (1 mil = 0.0254 мм, 1 mil² = 6.4516e-4 мм²);
- `k = 0.048` — для зовнішніх шарів плати (External traces);
- `k = 0.024` — для внутрішніх шарів (Internal traces, укладених між шарами склотекстоліту).

У метричній системі СІ (де площа A виражена в мм²):

```
A_mil2 = A_mm2 / 6.4516e-4 = A_mm2 * 1550.003
A_mil2^0.725 = (A_mm2 * 1550.003)^0.725 = 207.28 * A_mm2^0.725
```

Підставляючи метричні одиниці для зовнішнього шару:

```
I_ext = 0.048 * 207.28 * (Delta_T)^0.44 * (A_mm2)^0.725 [підстановка коефіцієнта переведення площі]
      = 9.95 * (Delta_T)^0.44 * (A_mm2)^0.725           [результуюча метрична формула для зовнішнього шару]
```

Для внутрішнього шару:

```
I_int = 0.024 * 207.28 * (Delta_T)^0.44 * (A_mm2)^0.725 [підстановка коефіцієнта переведення площі]
      = 4.97 * (Delta_T)^0.44 * (A_mm2)^0.725           [результуюча метрична формула для внутрішнього шару]
```

Звідси розрахунок необхідної ширини доріжки `w` за заданої товщини мідної фольги `t` (наприклад, 1 oz = 35 мкм = 0.035 мм):

```
A_req = [ I / (k_metric * Delta_T^0.44) ]^(1 / 0.725)
w = A_req / t
```

### Фізична вада IPC-2221

Формула IPC-2221 вважає, що тепло відводиться виключно з поверхні самої доріжки в нерухоме повітря. Вона повністю ігнорує:
1. Теплопровідність діелектрика плати у вертикальному та горизонтальному напрямках;
2. Наявність сусідніх та внутрішніх шарів суцільної міді (GND/Power planes);
3. Загальну товщину плати (1.6 мм плата відводить тепло значно краще за 0.8 мм);
4. Довжину доріжки та теплопередачу в масивні полігони компонентів на її кінцях.

Через це IPC-2221 завищує перегрів для внутрішніх шарів сучасної 4-шарової або 6-шарової плати у 2–3 рази, оскільки внутрішня доріжка, розташована за 0.15 мм від суцільного внутрішнього екрана GND, охолоджується через тонкий препрег набагато ефективніше, ніж ізольований провідник.

## Двовимірна теплова модель IPC-2152

Стандарт IPC-2152 базується на прямому розв'язанні диференціального рівняння теплопровідності Фур'є з урахуванням кондуктивного зв'язку між доріжкою та площинами плати:

```
-div( k_mat * grad(T) ) = q_gen
```
де:
- `k_mat` — тензор теплопровідності матеріалу (для FR-4: в площині шарів `k_xy = 0.8..1.0 Вт/(м*К)`, крізь товщину `k_z = 0.25..0.35 Вт/(м*К)`; для міді `k_cu = 385..400 Вт/(м*К)`);
- `q_gen = I^2 * rho / A^2` — об'ємна густина тепловиділення в міді [Вт/м³].

Границя між платою та навколишнім повітрям описується граничною умовою третього роду (Робіна):

```
-k_mat * (dT/dn)_surf = h_eff * (T_surf - T_amb)
```
де `h_eff = h_conv + h_rad` — сумарний коефіцієнт тепловіддачі (для природної конвекції та випромінювання у вільному повітрі `h_eff = 12..18 Вт/(м²*К)`).

### Тепловий опір через шар діелектрика до опорного полігону

Нехай доріжка шириною `w` і довжиною `L` розташована над внутрішнім суцільним мідним полігоном на відстані `h_diel` (товщина діелектрика). Ефективна площа теплопередачі з урахуванням бічного розтікання під кутом приблизно 45° становить `A_eff = (w + 2 * h_diel) * L`.

Питомий кондуктивний тепловий опір діелектрика на одиницю довжини:

```
R_th_diel' = h_diel / [ k_z * (w + 2 * h_diel) ]     [К*м/Вт]
```

Для типових параметрів 4-шарової плати:
- `w = 2 мм = 0.002 м`;
- `h_diel = 0.2 мм = 0.0002 м`;
- `k_z = 0.3 Вт/(м*К)`.

```
R_th_diel' = 0.0002 / [ 0.3 * (0.002 + 2 * 0.0002) ]    [підстановка геометричних параметрів]
           = 0.0002 / [ 0.3 * 0.0024 ]                  [сума в знаменнику]
           = 0.0002 / 0.00072                           [добуток у знаменнику]
           = 0.278 К*м/Вт                               [питомий тепловий опір діелектрика]
```

Для доріжки довжиною `L = 0.1 м` (10 см):

```
R_th_diel = R_th_diel' / L = 0.278 / 0.1 = 2.78 К/Вт
```

Це означає, що при виділенні на 10-сантиметровій доріжці потужності `P = 1 Вт`, перепад температури між самою доріжкою та внутрішнім полігоном заземлення складе всього `Delta_T = 1 Вт * 2.78 К/Вт = 2.78 °C`. Вся решта тепла розподіляється по великій площі полігону GND і скидається з усієї поверхні друкованої плати в повітря.

Саме цей механізм пояснює, чому стандарти IPC-2152 дозволяють у 1.5–2 рази вищий струм для доріжок над суцільними площинами живлення/землі при тому самому допустимому перегріві `Delta_T = 10..20 °C`.

## Адіабатний імпульсний нагрів: інтеграл Джоуля I²t доріжки

Під час короткого замикання час наростання та відсічки струму становить від кількох сотень мікросекунд до кількох мілісекунд. За цей час тепло не встигає покинути об'єм міді через низьку швидкість теплопровідності склотекстоліту (адіабатний режим).

Диференціальне рівняння адіабатного нагріву:

```
rho_m * c_p * A * L * dT = I(t)^2 * (rho(T) * L / A) * dt
```
де:
- `rho_m = 8960 кг/м³` — густина міді;
- `c_p = 385 Дж/(кг*К)` — питома теплоємність міді;
- `A` — площа перерізу доріжки [м²];
- `rho(T) = rho_0 * [1 + alpha_0 * (T - T_0)]`.

Розділяючи змінні та інтегруючи від початкової температури `T_init` до критичної температури плавлення або пошкодження `T_crit`:

```
rho_m * c_p * A^2 * [ dT / (rho_0 * [1 + alpha_0 * (T - T_0)]) ] = I(t)^2 * dt
(rho_m * c_p / (rho_0 * alpha_0)) * ln( [1 + alpha_0 * (T_crit - T_0)] / [1 + alpha_0 * (T_init - T_0)] ) * A^2 = integral( I(t)^2 dt )
```

Позначимо ліву константу матеріалу для міді:

```
K_cu = rho_m * c_p / (rho_0 * alpha_0)              [означення питомої константи плавлення]
     = (8960 * 385) / (1.724e-8 * 0.00393)          [підстановка фізичних властивостей міді]
     = 3.4496e6 / 6.7753e-11                        [обчислення чисельника і знаменника]
     = 5.091e16 А²*с / м⁴                           [значення в системі СІ]
     = 5.091e4 А²*с / мм⁴                           [переведення одиниць у міліметри]
```

Одержуємо точну формулу допустимого імпульсу струму `I^2 * t` для мідної доріжки площею `A` (у мм²):

```
(I^2 * t)_limit = K_cu * A^2 * ln( [1 + alpha_0 * (T_crit - T_0)] / [1 + alpha_0 * (T_init - T_0)] )
```

### Практичний розрахунок стійкості доріжки до КЗ

Нехай доріжка має ширину `w = 2.0 мм` і товщину 1 oz (`t = 0.035 мм`): `A = 2.0 * 0.035 = 0.070 мм²`.
Початкова температура `T_init = 60 °C`, гранично допустима температура без відшарування маски та текстоліту `T_crit = 150 °C`:

```
ln_term = ln( [1 + 0.00393 * (150 - 20)] / [1 + 0.00393 * (60 - 20)] )  [підстановка температур]
        = ln( [1 + 0.5109] / [1 + 0.1572] )                             [обчислення множників ТКО]
        = ln( 1.5109 / 1.1572 )                                         [ділення аргументів]
        = ln( 1.3056 )                                                  [результат ділення]
        = 0.2667                                                        [значення логарифмічного фактора]
```

Розраховуємо допустиму енергію імпульсу `(I^2 * t)_limit`:

```
(I^2 * t)_limit = 5.091e4 * (0.070)^2 * 0.2667  [підстановка площі та логарифмічного фактора]
                = 5.091e4 * 0.00490 * 0.2667    [піднесення площі до квадрата]
                = 66.5 А²*с                     [гранична енергетична міцність доріжки]
```

Якщо аварійний запобіжник у цьому ланцюзі має енергію повного вимкнення `I^2*t_clear = 18 А²*с`, доріжка гарантовано витримує струм короткого замикання без локального руйнування (`18 < 66.5 А²*с`). Якщо ж встановлено запобіжник на `100 А²*с`, доріжка перетвориться на плавку вставку і випарується швидше за спрацювання захисту.
