# 🔌 Архітектурні шаблони апаратної ізоляції вразливих мікросхем на платі

Коли на друкованій платі (*PCB*) розміщено сторонній співпроцесор зв'язку (наприклад, чип Wi-Fi, Bluetooth або стільниковий модем) або основний мікроконтролер із зафіксованою кремнієвою вразливістю, покладатися лише на програмні обмеження стає фатальною помилкою. Якщо вразливий чип може бути скомпрометований через радіоефір або фізичний інтерфейс, він стає плацдармом для атаки на всю систему: він може перехоплювати сигнали спільних шин зв'язку, подавати паразитне живлення через лінії вводу-виводу або блокувати системні переривання.

Щоб локалізувати загрозу та не допустити розповсюдження компрометації на критичні вузли керування, схемотехніка вбудованих пристроїв використовує чотири узагальнені апаратні шаблони ізоляції на рівні друкованої плати.

---

### Шаблон 1: Керування доменом живлення (Power Domain Gating)

Якщо в прошивці бездротового чипа виникає неконтрольований стан (зависання стека, переповнення буфера або захоплення зловмисником), програмне скидання (*Soft Reset*) через команду AT або лінію `RESET` може бути проігнороване мікросхемою, якщо її внутрішній контролер шини або ядро заблоковані.

Єдиний надійний спосіб повернути співпроцесор до гарантованого детермінованого початкового стану — **повне апаратне знеструмлення** (*Cold Power Cycle*).

```
          +3.3V System Power
                │
                ▼
        ┌───────────────┐
        │  P-MOSFET /   │
  GPIO ─┤  Load Switch  │
  Host  │  (High-Side)  │
        └───────┬───────┘
                │  VCC_COPROC
                ├─────────────────┐
                ▼                 ▼
        ┌───────────────┐  ┌─────────────┐
        │  Розрядний    │  │  Вразливий  │
        │  резистор     │  │ співпроцесор│
        │  (100–470 Ом) │  │  (Wi-Fi/BLE)│
        └───────┬───────┘  └──────┬──────┘
                │                 │
               GND               GND
```

#### Принцип схемотехнічної реалізації:
1. **Комутатор верхнього плеча (High-Side Switch)**: Живлення співпроцесора подається через P-канальний польовий транзистор (*P-MOSFET*) або інтегрований інтелектуальний ключ живлення (*High-Side Load Switch*) із захистом від зворотного струму та контрольованою швидкістю наростання напруги (*Slew Rate Control*).
2. **Активний розрядний контур (Active Pull-Down / Discharge)**: Після розмикання ключа на лініях живлення мікросхеми залишається залишковий заряд у блокувальних керамічних конденсаторах. Якщо напруга спадає повільно, внутрішні регістри пам'яті співпроцесора можуть зберегти спотворений стан, викликаючи стан «зависання при зниженій напрузі» (*Brownout Latch-up*). Схема обов'язково повинна містити розрядний резистор (100–470 Ом) або активний ключ швидкого розряду, який примусово стягує шину живлення до 0 В за кілька мікросекунд.

### Шаблон 2: Цифрова розв'язка та ізоляція шин (Digital Bus Isolation)

Класична помилка початківців — знеструмити вразливий чип комутатором живлення, залишивши активними сигнальні лінії UART, SPI або I2C, підключені до основного мікроконтролера. 

У цей момент спрацьовує ефект **паразитного живлення (Phantom Powering)**: напруга високого логічного рівня (3.3 В) з виводів TX/SCL/MOSI головного процесора через внутрішні захисні ESD-діоди знеструмленої мікросхеми перетікає на її внутрішню шину живлення. Чип живиться паразитним струмом у 2–5 мА, частково стартує в нестабільному напівпровідниковому стані, перегрівається або блокує шину зв'язку для всіх інших пристроїв.

```
       Головний MCU                 Ізолятор шини              Вразливий чип
  ┌────────────────────┐         ┌──────────────────┐       ┌─────────────────┐
  │                    │  3.3V   │  74LVC2G241 /    │       │                 │
  │  UART_TX ──────────┼─────────┤  ISO77xx         ├───────┤ RXD (Знеструм-  │
  │                    │         │  (Tri-state)     │       │     лений чип)  │
  │  GPIO_ISO_EN ──────┼─────────┤ OE (Output En)   │       │                 │
  └────────────────────┘         └──────────────────┘       └─────────────────┘
```

#### Принцип захисту:
- **Буфери з трьома станами (Tri-State Buffers / Bus Switches)**: Між головним процесором і співпроцесором встановлюються цифрові буфери (наприклад, мікросхеми сімейств `74LVC1G125`, `74LVC2G241` або цифрові ізолятори `ISO77xx`).
- **Синхронне відсікання**: Лінія керування буфером `Output Enable (OE)` прив'язується до сигналу ввімкнення живлення співпроцесора. Щойно живлення знімається, усі виводи автоматично переходять у стан високого імпедансу (*Hi-Z*), фізично розриваючи шлях для паразитного струму.

### Шаблон 3: Апаратне глушіння конфігураційних виводів (Strapping Pins Hardwiring)

Більшість сучасних систем-на-кристалі (ESP32, STM32, Allwinner, NXP i.MX) використовують виводи вибору режиму завантаження (*Strapping / Boot Pins*) для перемикання процесора у заводський масковий завантажувач (UART Bootloader, USB DFU або RCM). 

Якщо ці лінії виведені на тестові майданчики (*Test Points*) або мають слабку внутрішню підтяжку, зловмисник із фізичним доступом до плати може замкнути пін пінцетом під час скидання живлення, активувавши вразливий заводський ROM.

```
┌─────────────────────────────────────────────────────────────┐
│ Правило трасування конфігураційних пінів на платі:         │
│                                                             │
│  ВРАЗЛИВО (Помилка):                                        │
│  MCU_BOOT0 ─────[ 10k Pull-Down ]───── GND                  │
│       │                                                     │
│       └─────────○ [ Відкритий Test Point TP1 ]              │
│                                                             │
│  БЕЗПЕЧНО (Захищено):                                       │
│  MCU_BOOT0 ─────[ Прямий мідний полігон 0 Ом ]───── GND     │
│                 (Глухий перехідник у внутрішній шар,        │
│                  жодних відкритих майданчиків)              │
└─────────────────────────────────────────────────────────────┘
```

#### Правила захищеного трасування:
1. **Жорстке низькоомне глушіння**: Якщо режим BootROM не використовується у виробничому циклі після першої прошивки на заводі, лінія вибору режиму припаюється прямою мідною доріжкою (або резистором 0 Ом) до землі `GND` або лінії живлення `VDD`.
2. **Ліквідація тестових майданчиків**: Тестові точки ліній `BOOT`, `SWD_CLK`, `SWD_DIO` та `JTAG` видаляються з фінальних ревізій гербер-файлів, або ховаються у внутрішні шари плати через сліпі/глухі мікроперехідні отвори (*Blind/Buried Vias*).
3. **Заливка компаундом (Potting)**: Критичні вузли плати покриваються непрозорим термореактивним епоксидним компаундом, що унеможливлює механічне підключення зондів та локальне опромінення чипа імпульсним лазером без фізичного руйнування компонентів.

### Шаблон 4: Зовнішній криптографічний корінь довіри (Secure Element)

Якщо основний мікроконтролер має невиправну вразливість у вбудованій Flash-пам'яті (наприклад, обхід захисту читання RDP Level 1 через глітчинг напруги), зберігати у ньому майстер-ключі шифрування та унікальні сертифікати пристрою категорично заборонено.

Рішення полягає у винесенні всіх криптографічних операцій на спеціалізовану мікросхему безпеки — **апаратний корінь довіри (Secure Element / RoT IC)**, наприклад Microchip ATECC608B, NXP SE050 або STMicroelectronics STSAFE-A110.

```
  Головний MCU (Вразливий Flash)                Secure Element (Апаратно захищений)
┌────────────────────────────────┐            ┌────────────────────────────────────┐
│                                │  I2C_SEC   │  Внутрішній захист від глітчингу   │
│  • Не містить приватних ключів ├────────────┤  • Фізична активна сітка (Shield)  │
│  • Відправляє дайджест хешу    │  (Приватна │  • Невивантажуваний ключ ECC P-256 │
│  • Отримує підпис ECDSA        │   шина)    │  • Сесійне шифрування (AES-CMAC)   │
└────────────────────────────────┘            └────────────────────────────────────┘
```

#### Переваги винесення ключів:
- **Фізична стійкість до розкриття**: Кристал Secure Element оснащено активним екрануючим шаром металізації (*Active Shielding Mesh*), детекторами лазерного опромінення, датчиками температури та апаратними генераторами шуму живлення.
- **Принцип «чорної скриньки»**: Приватний ключ генерується всередині Secure Element і ніколи, за жодних умов, не передається по зовнішній шині I2C. Головний мікроконтролер передає чипу безпеки лише 32-байтний хеш повідомлення, а чип повертає 64-байтний криптографічний підпис ECDSA. Навіть якщо Flash-пам'ять головного процесора повністю вичитана зловмисником, майстер-ключ залишається неушкодженим.
