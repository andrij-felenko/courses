# 🧮 Розрахунок середнього струму та автономності батарейного давача

У батарейному пристрої тривалість роботи визначається не номінальною ємністю елемента живлення, а інтегралом струму за повний робочий цикл і здатністю джерела віддавати піковий струм без просідання напруги нижче порогу скидання мікроконтролера.

Ця математична модель розкриває розрахунок середнього струму споживання багатофазного циклу, урахування деградації ємності під імпульсним навантаженням і методику розрахунку буферного конденсатора для компенсації внутрішнього опору батареї.

---

## 1. Інтеграл заряду та середній струм циклу

Робочий процес автономного вузла складається з періодичних фаз: очікування (глибокий сон), вимірювання фізичної величини датчиком, обмін даними по шині, обчислення мікроконтролером та передача звіту.

Загальний електричний заряд `Q_cycle`, спожитий системою за один повний період `T_cycle`, є інтегралом миттєвого струму за часом:

```
Q_cycle = ∫[0..T_cycle] i(t) dt
```

Оскільки кожна фаза `k` має наближено сталий струм `I_k` та фіксовану тривалість `t_k`, неперервний інтеграл переходить у дискретну суму часток заряду:

```
Q_cycle = ∑[k=1..N] (I_k · t_k)
```

Середній струм системи `I_avg` за період дорівнює відношенню повного заряду до тривалості періоду:

```
I_avg = Q_cycle / T_cycle
      = (∑[k=1..N] I_k · t_k) / T_cycle
```

Якщо розділити споживання на активну фазу тривалістю `t_act` із сумарним струмом `I_act` та фазу глибокого сну тривалістю `t_sleep = T_cycle - t_act` зі струмом `I_sleep`, вираз набуває канонічного вигляду коефіцієнта заповнення (duty cycle `D = t_act / T_cycle`):

```
I_avg = I_act · D + I_sleep · (1 - D) + I_leak
```

де:
* `I_act` — струм під час перетворення та передачі (давач + МК + підтяжки шини);
* `t_act` — сумарна тривалість активного стану;
* `I_sleep` — сумарний струм спокою в режимі сну (струм витоку сенсора, струм режиму Stop/Standby МК);
* `I_leak` — постійний струм витоку друкованої плати, блокувальних конденсаторів та власний струм спокою стабілізатора (LDO `I_q`).

## 2. Пофазний баланс струмів у вимірювальному вузлі

Розглянемо вузол із цифровим давачем (наприклад, MEMS-барометром) та мікроконтролером малої потужності. Період вибірки `T_cycle = 1.0` с.

Фази споживання:
1. **Сон системи (`t_sleep = 988` мс):**
   * МК у режимі Stop/Standby з увімкненим RTC: `I_mcu_sleep = 1.2` мкА.
   * Давач у режимі Standby: `I_sens_sleep = 0.5` мкА.
   * Власний струм LDO та витоки керамічних конденсаторів: `I_leak = 0.3` мкА.
   * `I_1 = 1.2 + 0.5 + 0.3 = 2.0` мкА = `0.002` мА.
2. **Активне вимірювання давача (`t_meas = 8.0` мс):**
   * Давач виконує оверсемплінг (аналоговий тракт + АЦП): `I_sens_meas = 2.4` мА.
   * МК перебуває в сні (очікує апаратного переривання DRDY): `I_mcu_sleep = 1.2` мкА ≈ `0.001` мА.
   * `I_2 = 2.4 + 0.001 = 2.401` мА.
3. **Зчитування по шині SPI та обробка МК (`t_proc = 4.0` мс):**
   * МК активний (тактова частота 16 МГц, виконання обчислень): `I_mcu_act = 3.5` мА.
   * Інтерфейс давача (передача даних по SPI на 8 МГц): `I_sens_comm = 1.1` мА.
   * `I_3 = 3.5 + 1.1 = 4.6` мА.

### Покроковий розрахунок заряду

```
Q_sleep = I_1 · t_sleep                  [фаза сну]
        = 0.002 мА · 988 мс              [підстановка струму й часу]
        = 1.976 мкКл (мА·мс)             [заряд фази сну]

Q_meas  = I_2 · t_meas                   [фаза вимірювання сенсором]
        = 2.401 мА · 8.0 мс              [підстановка значень]
        = 19.208 мкКл                    [заряд фази вимірювання]

Q_proc  = I_3 · t_proc                   [фаза зчитування МК]
        = 4.600 мА · 4.0 мс              [підстановка значень]
        = 18.400 мкКл                    [заряд фази обробки]

Q_total = Q_sleep + Q_meas + Q_proc      [сума зарядів усіх трьох фаз]
        = 1.976 + 19.208 + 18.400        [додавання складових]
        = 39.584 мкКл (мА·мс)            [повний заряд циклу]
```

Обчислюємо середній струм:

```
I_avg = Q_total / T_cycle                [означення середнього струму]
      = 39.584 мА·мс / 1000 мс           [ділення на період 1 с]
      = 0.039584 мА ≈ 39.58 мкА          [середній струм вузла]
```

## 3. Розрахунок тривалості автономної роботи

Номінальна ємність батареї `C_nom` (зазначена виробником у мА·год) не може бути використана на 100% через саморозряд, температурні коливання та зростання внутрішнього опору наприкінці життєвого циклу.

Дійсна корисна ємність `C_eff` визначається через коефіцієнти запасу:

```
C_eff = C_nom · η_temp · η_load · (1 - α_self · T_years)
```

де:
* `η_temp` — температурний коефіцієнт (за кімнатної температури `+20 °C` становить `0.95..0.98`, при `-10 °C` падає до `0.70..0.80`);
* `η_load` — коефіцієнт корисної дії за імпульсного навантаження (`0.85..0.92` для літієвих дискових елементів через просідання напруги);
* `α_self` — річна швидкість саморозряду (`0.01..0.02`, тобто 1–2% на рік для Li-MnO2 елементів типу CR2032);
* `T_years` — розрахунковий термін служби в роках.

Теоретичний час роботи в годинах `T_hours`:

```
T_hours = C_eff / I_avg
```

Розрахунок у роках `T_years`:

```
T_years = T_hours / (24 · 365.25)
        = C_eff / (I_avg · 8766)
```

### Числовий приклад для батареї CR2032

Вихідні дані:
* `C_nom = 225` мА·год;
* `η_temp = 0.95`;
* `η_load = 0.90`;
* Втрати на саморозряд за 1 рік: `~1.5%` (`α_self = 0.015`);
* `I_avg = 0.03958` мА (з попереднього розрахунку).

Розрахунок:

```
C_eff = 225 мА·год · 0.95 · 0.90 · (1 - 0.015)   [урахування деградації ємності]
      = 225 · 0.855 · 0.985                      [перемноження коефіцієнтів]
      = 189.49 мА·год                            [дійсна корисна ємність]

T_hours = 189.49 мА·год / 0.03958 мА             [час роботи в годинах]
        = 4787.5 годин                           [результат ділення]

T_years = 4787.5 / 8766                          [переведення у роки (8766 год/рік)]
        ≈ 0.546 року                             [близько 6.5 місяців автономності]
```

Якщо збільшити період вибірки `T_cycle` з 1 с до 10 с:

```
Q_sleep_10s = 0.002 мА · 9988 мс = 19.976 мкКл     [заряд сну за 10 с]
Q_total_10s = 19.976 + 19.208 + 18.400 = 57.584 мкКл [сумарний заряд циклу 10 с]
I_avg_10s   = 57.584 мА·мс / 10000 мс = 0.005758 мА = 5.76 мкА [середній струм при T=10 с]

T_hours_10s = 189.49 мА·год / 0.00576 мА = 32897 годин  [ресурс у годинах при T=10 с]
T_years_10s = 32897 / 8766 ≈ 3.75 року                  [ресурс у роках при T=10 с]
```

Збільшення інтервалу сну в 10 разів подовжує автономність вузла з пів року майже до 4 років.

## 4. Падіння напруги на внутрішньому опорі (ESR) та вибір буферного конденсатора

Дискові елементи CR2032 мають високий внутрішній опір `R_int`. У свіжої батареї `R_int ≈ 10..20` Ом, але під час розряду та при зниженні температури до `0 °C` опір зростає до `100..200` Ом.

Під час стрибка активного струму `I_peak = 4.6` мА спад напруги на внутрішньому опорі становить:

```
ΔV_drop = I_peak · R_int                         [закон Ома для внутрішнього опору]
```

При `R_int = 150` Ом:

```
ΔV_drop = 4.6 мА · 150 Ом                        [підстановка пікового струму й опору]
        = 0.0046 А · 150 Ом                      [переведення міліамперів в ампери]
        = 0.69 В                                 [спад напруги на батареї]
```

Якщо напруга холостого ходу батареї становить `V_ocv = 2.8` В, напруга на шині живлення в момент імпульсу просяде до:

```
V_rail = V_ocv - ΔV_drop                         [напруга під навантаженням]
       = 2.8 В - 0.69 В                          [віднімання спаду напруги]
       = 2.11 В                                  [кінцева напруга на шині]
```

Якщо поріг апаратного скидання мікроконтролера (BOD — Brown-Out Detector) налаштовано на `2.2` В, мікроконтролер піде в нескінченний перезапуск (Brown-out reset), хоча в батареї ще залишилося понад 50% номінальної енергії.

```
+----------------+      R_int (150 Ом)
|  Батарея OCV   |------/\/\/\/\/-------+---------> До системи (V_rail)
|     2.8 В      |                      |
+----------------+                   +--+--+
                                     |     |
                                    ===   ---  C_bulk
                                     |     |
                                     +--+--+
                                        |
                                       GND
```

### Розрахунок мінімальної ємності накопичувального конденсатора `C_bulk`

Конденсатор `C_bulk` має живити навантаження протягом тривалості імпульсу `t_pulse`, обмежуючи максимальне просідання напруги до допустимого рівня `ΔV_max`.

За законом збереження заряду конденсатора `Q = C · ΔV`:

```
I_cap · t_pulse = C_bulk · ΔV_max
```

Враховуючи, що струм підтримується паралельно батареєю (обмеженою опором `R_int`) та конденсатором:

```
I_cap = I_peak - (V_ocv - V_min) / R_int
```

У найгіршому випадку (консервативна оцінка, де весь імпульс забезпечує виключно конденсатор):

```
C_bulk ≥ (I_peak · t_pulse) / ΔV_max             [необхідна ємність буфера]
```

Для значень:
* `I_peak = 4.6` мА = `0.0046` А;
* `t_pulse = 4.0` мс = `0.004` с;
* Допустиме просідання `ΔV_max = 0.20` В:

```
C_bulk ≥ (0.0046 А · 0.004 с) / 0.20 В           [підстановка числових параметрів]
       = 0.0000184 Кл / 0.20 В                   [обчислення заряду імпульсу]
       = 0.000092 Ф = 92 мкФ                     [мінімальна розрахункова ємність]
```

З урахуванням деградації ємності керамічних конденсаторів під дією постійної напруги зміщення (DC bias effect, що забирає до 40–50% ємності в типорозмірах 0805/0603) обирається номінал **100 мкФ** або пара паралельних конденсаторів по **47 мкФ** з діелектриком X5R/X7R.

## 5. Вплив струму витоку конденсатора

Великі танталові або електролітичні конденсатори мають власний струм витоку `I_leak_cap`, який може перевищувати струм сну системи:

```
I_leak_tantalum ≈ 0.01 · C · V ≈ 0.01 · 100 мкФ · 3 В = 3 мкА
```

Струм витоку 3 мкА подвоїть фонове споживання всієї схеми в режимі сну. Тому в автономних вузлах застосовують багатошарові керамічні конденсатори (MLCC) класу X7R/X5R, струм витоку яких за температури до `+40 °C` не перевищує **10–50 нА**, що зберігає мікроамперний бюджет сну.
