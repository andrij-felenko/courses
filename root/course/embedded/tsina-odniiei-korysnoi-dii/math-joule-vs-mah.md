# 🧮 Математика енергетичного балансу: інтеграл джоулів проти міліампер-годин

Оцінка часу автономної роботи пристрою за електричним зарядом батареї у міліампер-годинах (`мА·год`) або кулонах спирається на неявне припущення: напруга живлення залишається абсолютно стабільною від першої секунди роботи до повного вичерпання хімічного джерела. У реальних вбудованих системах це припущення не виконується ніколи: хімічні джерела (літій-тіонілхлоридні `Li-SOCl2`, літій-діоксидмарганцеві `Li-MnO2`, літій-іонні `Li-Ion` та літій-залізо-фосфатні `LiFePO4`) мають похилу розрядну криву, динамічне просідання напруги під навантаженням через внутрішній опір, а імпульсні перетворювачі живлення змінюють струм споживання обернено пропорційно вхідній напрузі.

Розглянемо математичний зв'язок між електричним зарядом `Q`, миттєвою потужністю `P(t)` та повною енергією `E`, а також виведемо систематичну похибку спрощеного розрахунку для двох фундаментальних топологій живлення: лінійного регулятора (LDO) та імпульсного понижувального перетворювача (DC-DC Buck).

---

## 1. Фундаментальні рівняння: заряд проти енергії

Електричний заряд `Q`, відданий джерелом за інтервал часу `[0, T]`, визначається інтегруванням миттєвого струму `I(t)`:

```
Q = ∫₀ᵀ I(t) dt
```

Повна виконана робота та розсіяна енергія `E` визначаються інтегралом миттєвої електричної потужності `P(t) = V(t) · I(t)`:

```
E = ∫₀ᵀ V(t) · I(t) dt
```

де `V(t)` — миттєва напруга на клемах джерела живлення під навантаженням.

Якщо спрощено вважати напругу константою `V_ном` (номінальна напруга з технічного опису батареї), оцінка енергії набуває вигляду:

```
E_спрощ = V_ном · Q = V_ном · ∫₀ᵀ I(t) dt
```

Абсолютна похибка енергетичного балансу `ΔE`:

```
ΔE = E_спрощ − E                   [різниця спрощеної та істинної енергії]
   = ∫₀ᵀ (V_ном − V(t)) · I(t) dt  [підстановка інтегральних виразів]
```

Відносна похибка розрахунку `δ_E`:

```
δ_E = (∫₀ᵀ (V_ном − V(t)) · I(t) dt) / (∫₀ᵀ V(t) · I(t) dt)
```

Звідси видно: знак і величина похибки прямо залежать від форми функції `V(t)` під час розряду та від того, як корелює струм навантаження `I(t)` з падінням напруги `V(t)`.

---

## 2. Динаміка напруги реального хімічного джерела

Напруга на клемах хімічного елемента `V(t)` формується з двох компонентів: електрорушійної сили відкритого кола `V_ocv(SoC)` (Open-Circuit Voltage), що залежить від ступеня заряду (State of Charge, `SoC ∈ [0, 1]`), та омічного падіння на внутрішньому імпедансі джерела `R_int`:

```
V(t) = V_ocv(SoC(t)) − I(t) · R_int(SoC(t), T_темп)
```

Внутрішній опір `R_int` не є сталим:
- У свіжому елементі `Li-SOCl2` (наприклад, типорозміру ER14505 AA) `R_int ≈ 2..5 Ом` за кімнатної температури;
- Наприкінці розряду або при температурі −20 °C опір зростає до `20..50 Ом` через пасивацію літієвого анода плівкою хлориду літію `LiCl`;
- Під час імпульсу струму передавача `I_tx = 100 мА` просідання напруги становить:

```
ΔV_drop = I_tx · R_int = 0.100 А · 30 Ом = 3.00 В
```

Якщо напруга холостого ходу становила 3.60 В, напруга на вході схеми миттєво падає до `3.60 − 3.00 = 0.60 В`, що спричиняє негайне спрацьовування детектора коричневого знеструмлення (Brown-Out Reset, BOR), хоча за залишковим хімічним зарядом батарея віддала лише 10% паспортної ємності.

## 3. Топологія 1: Лінійний регулятор напруги (LDO)

Розглянемо живлення мікроконтролера від батареї з початковою напругою `V_bat,0 = 4.2 В`, яка розряджається до кінцевої напруги відсічки `V_bat,end = 3.3 В`. Навантаження живиться стабілізованою напругою `V_reg = 3.0 В` і споживає фіксований профіль струму `I_load(t)`.

У лінійному стабілізаторі вхідний струм практично дорівнює струму навантаження (нехтуючи власним струмом споживання спокою `I_q ≪ I_load`):

```
I_in(t) = I_load(t) + I_q ≈ I_load(t)
```

### Витрата заряду від батареї:

```
Q_bat = ∫₀ᵀ I_load(t) dt = Q_load
```

Заряд, спожитий від батареї, точно дорівнює заряду, отриманому навантаженням.

### Витрата енергії від батареї:

```
E_bat = ∫₀ᵀ V_bat(t) · I_load(t) dt
```

### Корисна енергія, спожита навантаженням:

```
E_load = ∫₀ᵀ V_reg · I_load(t) dt = V_reg · Q_load
```

### Енергія, втрачена на LDO у вигляді тепла:

```
E_loss = E_bat − E_load                       [втрати на регуляторі]
       = ∫₀ᵀ (V_bat(t) − V_reg) · I_load(t) dt [різниця вхідної та вихідної енергії]
```

### Миттєвий коефіцієнт корисної дії:

```
η_LDO(t) = P_load(t) / P_in(t)                          [означення ККД]
         = (V_reg · I_load(t)) / (V_bat(t) · I_load(t)) [розкриття потужностей]
         = V_reg / V_bat(t)                             [скорочення струму навантаження]
```

При `V_bat = 4.2 В` і `V_reg = 3.0 В`:
```
η_LDO = 3.0 / 4.2 ≈ 71.4%   (28.6% енергії спалюється в тепло)
```

При `V_bat = 3.3 В`:
```
η_LDO = 3.0 / 3.3 ≈ 90.9%
```

Середній ККД за цикл розряду:

```
η̄_LDO = (V_reg · Q_load) / (∫₀ᵀ V_bat(t) · I_load(t) dt)
```

При лінійній апроксимації розряду `V_bat(t) = V_max − (V_max − V_min) · (t / T)` і постійному середньому струмі навантаження:

```
V̄_bat = (V_max + V_min) / 2 = (4.2 + 3.3) / 2 = 3.75 В

η̄_LDO = 3.00 / 3.75 = 80.0%
```

Якщо розробник оцінює ресурс як `Час = Емність_(мА·год) / I_сер`, він отримує правильний час життя, але не бачить, що 20% повної хімічної енергії батареї пішло на марний нагрів корпусу LDO.

## 4. Топологія 2: Імпульсний понижувальний перетворювач (DC-DC Buck)

Імпульсний перетворювач підтримує сталу вихідну напругу `V_out = 3.0 В` за рахунок перетворення потужності з коефіцієнтом корисної дії `η_buck` (типово 88–95% для сучасних мікропотужних synchronous buck converters):

```
P_in(t) = P_out(t) / η_buck
```

Розгорнемо через струми та напруги:

```
V_bat(t) · I_bat(t) = (V_out · I_out(t)) / η_buck
```

Звідси струм, який перетворювач забирає від батареї:

```
I_bat(t) = (V_out · I_out(t)) / (η_buck · V_bat(t))
```

### Ключовий ефект:
У міру розряду батареї (`V_bat(t)` зменшується) вхідний струм `I_bat(t)` **неминуче зростає**, щоб забезпечити ту саму вихідну потужність навантаження.

Розрахуємо повний заряд, який забере DC-DC перетворювач від батареї за час роботи `T`:

```
Q_bat = ∫₀ᵀ I_bat(t) dt                                 [означення заряду]
      = (V_out / η_buck) · ∫₀ᵀ (I_out(t) / V_bat(t)) dt [підстановка виразу для I_bat]
```

Для постійного навантаження `I_out = const`:

```
Q_bat = ((V_out · I_out) / η_buck) · ∫₀ᵀ (1 / V_bat(t)) dt
```

При лінійному спаді напруги батареї `V_bat(t) = V_0 − k·t`, де `k = (V_0 − V_end) / T`:

```
∫₀ᵀ (1 / (V_0 − k·t)) dt = (1 / k) · ln(V_0 / V_end)                  [інтегрування дробу]
                         = (T / (V_0 − V_end)) · ln(V_0 / V_end)       [підстановка коефіцієнта k]
```

Підставивши цей інтеграл у вираз для заряду:

```
Q_bat = ((V_out · I_out · T) / η_buck) · (ln(V_0 / V_end) / (V_0 − V_end))
```

Оскільки `I_out · T = Q_load`:

```
Q_bat = Q_load · (V_out / η_buck) · (ln(V_0 / V_end) / (V_0 − V_end))
```

### Числовий приклад порівняння LDO та Buck:
- Напруга батареї: `V_0 = 4.2 В`, `V_end = 3.0 В`;
- Вихідна напруга: `V_out = 3.0 В`;
- ККД імпульсника: `η_buck = 0.90` (90%);
- Заряд, необхідний навантаженню: `Q_load = 1000 мА·год`.

Для LDO:
```
Q_bat,LDO = Q_load = 1000 мА·год
```

Для Buck:
```
ln(4.2 / 3.0) / (4.2 − 3.0) = ln(1.4) / 1.2 = 0.33647 / 1.2 = 0.28039 В⁻¹

Q_bat,Buck = 1000 · (3.0 / 0.90) · 0.28039 [підстановка параметрів]
           = 1000 · 3.3333 · 0.28039       [множення вихідних величин]
           = 934.6 мА·год                  [кінцевий результат]
```

Імпульсний перетворювач зберіг `65.4 мА·год` (6.54% заряду) за рахунок високої напруги на початку розряду, попри втрати на власне перемикання (ККД 90%). Якби напруга батареї була 7.2 В (дві послідовні банки), виграш за зарядом перевищив би 45%.

## 5. Розрахунок енергетичної вартості атомарної дії

Нехай пристрій виконує одну атомарну операцію (наприклад, оцифрування вибірки та радіопередачу), що складається з `N` дискретних фаз. Кожна `k`-та фаза триває `Δt_k` і характеризується середнім струмом `I_k` та напругою живлення ядра `V_core`:

```
E_дія = ∑_{k=1}^{N} V_core · I_k · Δt_k
```

Якщо живлення здійснюється через DC-DC перетворювач з ККД `η_buck`, витрати енергії безпосередньо з акумулятора:

```
E_bat,дія = E_дія / η_buck = (1 / η_buck) · ∑_{k=1}^{N} V_core · I_k · Δt_k
```

Кількість таких дій `N_total`, яку здатне забезпечити джерело з повною запасеною енергією `E_хім`:

```
E_хім = ∫₀^{Q_ном} V_ocv(q) dq − I_сер² · R_int · T_розряд

N_total = (E_хім · η_buck − E_сон) / E_дія
```

де `E_сон = V_bat,сер · I_сон · T_життя` — енергія, витрачена на струм витоку та сон за весь термін служби виробу.

Перехід від оперування зарядом `Q` до точного інтегрування енергії `E = ∫ V(t)·I(t) dt` усуває систематичну похибку розрахунку, що в реальних бездротових сенсорах сягає від 15% до 35% залежно від профілю струму та внутрішнього опору хімічного джерела.
