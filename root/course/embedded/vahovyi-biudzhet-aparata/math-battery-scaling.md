# 🧮 Закон спадної віддачі та межа маси акумулятора

Математичне виведення аналітичної залежності тривалості висіння мультикоптера від частки маси батареї, знаходження точки екстремуму та фізичне пояснення спадної віддачі при нарощуванні енергетичної ємності.

У безпілотній авіації побутова інтуїція «подвоїмо ємність батареї — отримаємо вдвічі довший політ» зазнає краху. Причина полягає в тому, що акумулятор одночасно є джерелом корисної енергії і важким баластом, на підтримання якого у повітрі мотори змушені витрачати додаткову потужність. Нижче наведено суворе аналітичне виведення цієї нелінійності на основі класичної імпульсної теорії ідеального повітряного гвинта (диска Ренкіна — Фруда).

---

## 1. Потужність висіння та імпульсна теорія диска

Для утримання апарата повної маси `m` у режимі статичного висіння сумарна вертикальна тяга гвинтів `T` повинна точно врівноважувати силу тяжіння:

```
T = m · g
```

Згідно з одновимірною імпульсною теорією повітряного гвинта (Actuator Disk Theory), швидкість повітряного потоку, індукована крізь площину обертання гвинтів площею `A`, дорівнює:

```
v_i = √(T / (2 · ρ · A))
```

де:
* `T` — сумарна тяга апарата (Н);
* `ρ` — густина навколишнього повітря (кг/м³, для стандартної атмосфери на рівні моря `ρ ≈ 1.225` кг/м³);
* `A = N_m · (π · D² / 4)` — сумарна площа ометання всіх `N_m` гвинтів діаметром `D` (м²).

Ідеальна індукована потужність `P_i`, необхідна для створення тяги `T`, дорівнює добутку сили на швидкість відкидання струменя:

```
P_i = T · v_i
= T · √(T / (2 · ρ · A))    [підстановка індукованої швидкості v_i]
= T^(3/2) / √(2 · ρ · A)    [об'єднання степенів тяги T]
```

Оскільки `T = m · g`, індукована потужність зростає пропорційно масі апарата у степені `3/2`:

```
P_i = (m · g)^(3/2) / √(2 · ρ · A)
```

Реальна електрична потужність `P_hover`, що споживається від акумулятора в режимі висіння, враховує гідродинамічний коефіцієнт якості гвинта (Figure of Merit, `FM ≈ 0.65–0.75`), електричний ККД моторів `η_m ≈ 0.80–0.88` та регуляторів швидкості ESC `η_esc ≈ 0.95–0.98`:

```
P_hover = P_i / (FM · η_m · η_esc)
= (m · g)^(3/2) / (√(2 · ρ · A) · η_total)
```

де `η_total = FM · η_m · η_esc` — загальний коефіцієнт корисної дії силової групи.

Введемо константу аеродинамічної ефективності планера `C_aero`:

```
C_aero = (g^(3/2)) / (√(2 · ρ · A) · η_total)
```

Тоді споживана потужність висіння виражається простою степеневою функцією повної маси `m`:

```
P_hover(m) = C_aero · m^(3/2)
```

## 2. Запас енергії та баланс маси

Повна маса апарата `m` складається з двох ключових компонентів:
1. «Суха» маса апарата `m_0` (конструкція рами, мотори, регулятори, авіоніка, корисне навантаження та проводка);
2. Маса акумуляторної батареї `m_b`.

```
m = m_0 + m_b
```

Введемо безрозмірну частку маси акумулятора `β`:

```
β = m_b / m = m_b / (m_0 + m_b),    де 0 < β < 1
```

Звідси повну масу апарата можна виразити через суху масу `m_0` та частку `β`:

```
m = m_0 / (1 - β)
```

А масу батареї:

```
m_b = m_0 · β / (1 - β)
```

Запас корисної електричної енергії `E_avail`, доступний для польоту, визначається питомою енергоємністю акумулятора `e_s` (вираженою в Дж/кг або Вт·с/кг), глибиною допустимого розряду `D_DoD` (Depth of Discharge, зазвичай `0.80–0.85` для збереження ресурсу комірок) та масою батареї:

```
E_avail = m_b · e_s · D_DoD
= (m_0 · β / (1 - β)) · e_s · D_DoD
```

Для типових хімічних джерел питома енергія становить:
* LiPo (High-C): `e_s ≈ 150–180` Вт·год/кг = `540 000–648 000` Дж/кг;
* Li-ion 21700 / 18650: `e_s ≈ 230–260` Вт·год/кг = `828 000–936 000` Дж/кг.

## 3. Функція часу польоту та пошук максимуму

Час статичного висіння `t_hover` визначається відношенням доступної енергії до споживаної потужності:

```
t_hover = E_avail / P_hover
```

Підставимо отримані вирази для енергії та потужності:

```
t_hover(m_b) = (m_b · e_s · D_DoD) / (C_aero · (m_0 + m_b)^(3/2))
```

Згрупуємо всі фізичні та конструктивні константи в єдиний коефіцієнт масштабу `K_t`:

```
K_t = (e_s · D_DoD) / C_aero
= (e_s · D_DoD · √(2 · ρ · A) · η_total) / (g^(3/2))
```

Тоді час польоту стає явною функцією маси акумулятора `m_b`:

```
t_hover(m_b) = K_t · (m_b / (m_0 + m_b)^(3/2))
```

Або через безрозмірну частку `β`:

```
t_hover(β) = K_t · (m_0 · β / (1 - β)) / (m_0 / (1 - β))^(3/2)
= (K_t / √m_0) · β · √(1 - β)
```

Знайдемо екстремум функції `f(β) = β · √(1 - β)` на інтервалі `β ∈ (0, 1)`. Для цього візьмемо першу похідну за змінною `β` і прирівняємо її до нуля:

```
df/dβ = d/dβ [ β · (1 - β)^(1/2) ]
= 1 · (1 - β)^(1/2) + β · (1/2) · (1 - β)^(-1/2) · (-1)    [правило добутку та складеної функції]
= √(1 - β) - (β / (2 · √(1 - β)))                         [зведення до спільного знаменника]
= (2 · (1 - β) - β) / (2 · √(1 - β))
= (2 - 3·β) / (2 · √(1 - β))
```

Прирівнюємо чисельник похідної до нуля для знаходження критичної точки:

```
2 - 3·β = 0
= 3·β = 2        [перенесення доданка]
= β_opt = 2/3 ≈ 0.6667    [ділення на 3]
```

Перевіримо знак другої похідної в точці `β = 2/3`:

```
d²f/dβ² |_(β=2/3) < 0
```

Оскільки друга похідна від'ємна, точка `β_opt = 2/3` є строгим локальним і глобальним **максимумом** тривалості польоту.

У термінах співвідношення мас:

```
m_b / (m_0 + m_b) = 2/3
= 3 · m_b = 2 · m_0 + 2 · m_b    [перемноження пропорції навхрест]
= m_b = 2 · m_0                  [віднімання 2·m_b від обох частин]
```

> **Теоретична теорема спадної віддачі:**
> Для будь-якого літального апарата вертикального зльоту з фіксованою площею гвинтів і сухою масою `m_0`, максимальний час висіння досягається тоді, коли маса акумулятора рівно **вдвічі перевищує суху масу всього апарата** (`m_b = 2 · m_0`), тобто становить `66.7%` від максимальної злітної маси.
> Подальше збільшення маси акумулятора призводить до **зменшення** абсолютного часу перебування у повітрі.

## 4. Гранична ефективність (Marginal Returns)

Похідна `dt / dm_b` показує граничний приріст часу польоту на кожен доданий кілограм акумулятора:

```
dt / dm_b = K_t · (m_0 - (1/2)·m_b) / (m_0 + m_b)^(5/2)
```

Проаналізуємо поведінку системи на трьох характерних інтервалах частки батареї `β`:

1. **Початковий інтервал (`β < 0.35` або `m_b < 0.54 · m_0`):**
   Маса батареї невелика порівняно з планером. Знаменник `(m_0 + m_b)^(5/2)` зростає повільно, приріст часу близький до лінійного. Кожні +100 г батареї дають помітний виграш у тривалості.

2. **Зона спадної віддачі (`0.45 < β < 0.60`):**
   Чисельник `m_0 - 0.5·m_b` стрімко прямує до нуля. Додавання 500 г батареї збільшує час польоту лише на 2–3 хвилини, при цьому струм висіння зростає у півтора раза, спричиняючи значне нагрівання обмоток моторів.

3. **Закритична зона (`β > 0.67`):**
   Похідна `dt / dm_b < 0`. Будь-який додатковий грам батареї збільшує енергетичну потребу на власне утримання більше, ніж додає запасеної енергії. Апарат летить **менше часу**, ніж із легшою батареєю.

## 5. Практичні обмеження реального польоту

Аналітичний оптимум `β = 66.7%` базується на припущенні, що мотори та електроніка мають нескінченний запас потужності та незмінний ККД. У реальному інженерному виробі практична стеля частки акумулятора зміщується ліворуч у діапазон **`β_real ≈ 45–55%`** через дію чотирьох нелінійних фізичних факторів:

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. Внутрішній опір комірок (R_int) та ефект Пойкерта:                  │
│    Зі зростанням повної маси m зростає струм I_hover ∝ m^(3/2).         │
│    Теплові втрати P_loss = I² · R_int зростають як m³, знижуючи         │
│    реально віддану ємність батареї на 10–18%.                           │
├─────────────────────────────────────────────────────────────────────────┤
│ 2. Теплове перевантаження моторів (Джоулеве нагрівання):                │
│    Струм фази двигуна зростає, нагріваючи мідні обмотки. З ростом       │
│    температури опір міді R_cu зростає за лінійним законом:              │
│    R(T) = R_20 · (1 + 0.00393 · (T - 20°C)), що додатково знижує ККД.  │
├─────────────────────────────────────────────────────────────────────────┤
│ 3. Втрата керованості (динамічний запас тяги TWR):                      │
│    Для парирування вітрових поривів та стабілізації по кутах тангажу/   │
│    крену потрібен запас тяги TWR = T_max / (m · g) ≥ 1.7–2.0.           │
│    При β > 0.60 робоча точка висіння зміщується до 75–85% газу,         │
│    спричиняючи насичення регуляторів і зрив стабілізації.                │
├─────────────────────────────────────────────────────────────────────────┤
│ 4. Зростання маси самої силової установки:                             │
│    Щоб створити тягу для важчого дрона, потрібні важчі мотори зі        │
│    збільшеним статором (наприклад, перехід від 2207 до 2806.5 або 3115),│
│    що збільшує суху масу m_0 і зсуває точку балансу.                    │
└─────────────────────────────────────────────────────────────────────────┘
```

### Числовий розрахунок на прикладі 7-дюймового квадрокоптера

Розглянемо практичний розрахунок для апарата з фіксованою сумою компонентів `m_0 = 580` г (рама, 4 мотори 2806.5, пропелери 7.5", FC, ESC, VTX, камера):
* Сумарна площа ометання 4 гвинтів `D = 0.19` м: `A = 4 · (π · 0.19² / 4) ≈ 0.1134` м²;
* Загальний ККД силової установки: `η_total = 0.58`;
* Густина повітря: `ρ = 1.225` кг/м³.

Коефіцієнт аеродинамічної сили:
```
C_aero = (9.81^(3/2)) / (√(2 · 1.225 · 0.1134) · 0.58)
= 30.71 / (0.527 · 0.58)    [обчислення чисельника і кореня знаменника]
= 100.48 Вт / (кг^(3/2))    [ділення чисельника на знаменник]
```

Порівняння конфігурацій акумуляторів Li-ion (питома енергія `e_s = 240` Вт·год/кг, доступна частка `D_DoD = 0.85`):

```

│ батареї       │   (г)    │   (г)    │   β    │   (Вт)    │ E_avail    │  t_hover    │
├───────────────┼──────────┼──────────┼────────┼───────────┼────────────┼─────────────┤
│ 6S1P (21700)  │  430 г   │  1010 г  │ 42.6%  │ 102.0 Вт  │  87.7 Вт·г │ 51.6 хв     │
│ 6S2P (21700)  │  860 г   │  1440 г  │ 59.7%  │ 173.6 Вт  │ 175.4 Вт·г │ 60.6 хв     │

```

Результати розрахунку демонструють фундаментальну інженерну закономірність:
* Перехід від `6S1P` (430 г) до `6S2P` (860 г) подвоює масу батареї (+430 г), але збільшує час польоту лише на **9 хвилин** (+17.4%);
* Перехід від `6S2P` до `6S3P` додає ще +430 г батареї, але додає лише **0.8 хвилини** польоту, при цьому споживана потужність зростає на 48%, перевантажуючи силову мережу;
* Перехід до `6S4P` призводить до **падіння** часу польоту порівняно з `6S3P`, перетворюючи апарат на некеровану конструкцію з TWR < 1.3.
