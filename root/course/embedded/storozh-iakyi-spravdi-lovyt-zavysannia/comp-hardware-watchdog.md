# 🔌 Узагальнений апаратний супервізор: схемотехніка підключення

Апаратний супервізор сторожового таймера (Watchdog Supervisor IC) — це спеціалізована інтегральна мікросхема, призначена для зовнішнього апаратного нагляду за працездатністю цифрового процесора та якістю його напруги живлення. На відміну від внутрішніх сторожів мікроконтролера, супервізор виготовляється на фізично відокремленому кристалі кремнію, має власний незалежний прецизійний генератор опорної частоти, вбудоване джерело опорної напруги (Bandgap Reference) та каскад формування імпульсу апаратного скидання.

## Функціональна структура та типові виводи

Типовий супервізор у компактному корпусі (SOT-23-5, SOT-23-6 або MSOP-8) об'єднує в собі три ключові вузли: компаратор напруги живлення з фіксованим порогом спрацьовування, таймер моніторингу активності процесора та схему затримки сигналу скидання.

```
       ┌──────────────────────────────────────────────────┐
       │             Watchdog Supervisor IC               │
       │                                                  │
VDD ───┤ 1 VDD              (Вхід живлення)     RESET 5 ├───→ /RESET MCU
       │                                                  │   (Open-Drain)
GND ───┤ 2 GND              (Спільний мінус)              │
       │                                                  │
/MR ───┤ 3 /MR              (Ручне скидання)      WDI 4 ├───← GPIO WDT
       │                                                  │   (Імпульси)
       └──────────────────────────────────────────────────┘
```

Призначення виводів:
* **`VDD`**: лінія живлення та вимірювання напруги. Внутрішній дільник і компаратор постійно порівнюють цю напругу з внутрішнім еталоном (типові фіксовані пороги: 2.63 В, 2.93 В, 3.08 В або 4.63 В з точністю ±1–1.5%). Якщо напруга просідає нижче порогу хоча б на кілька мікросекунд, вихід скидання активується негайно.
* **`GND`**: спільний провід живлення та сигнальної землі.
* **`WDI` (Watchdog Input)**: вхід контрольних імпульсів сторожа. Мікросхема містить внутрішній детектор фронтів (Edge Detector). Кожен логічний перепад (з 0 в 1 або з 1 в 0) скидає внутрішній лічильник часу нагляду (`t_WD`). Якщо протягом інтервалу `t_WD` на виводі WDI не відбулося жодного перепаду, супервізор ініціює апаратний перезапуск процесора.
* **`/RESET` або `RESET`**: вихід апаратного скидання. Найчастіше реалізується за схемою з відкритим стоком (Open-Drain, активний низький рівень). При спрацьовуванні вихід утримується в активному стані протягом фіксованого часу скидання (`t_RST`, зазвичай 140–280 мс), що гарантує повну стабілізацію перехідних процесів у живленні та кварцових резонаторах процесора.
* **`/MR` (Manual Reset)**: вхід ручного скидання. Активується низьким рівнем від тактової кнопки або зовнішньої логіки захисту (наприклад, аварійного вимикача E-Stop). Містить вбудований тригер Шмітта та підтягувальний резистор до VDD для придушення брязкоту контактів.

## Розрахунок та конфігурація часових параметрів

Супервізори поділяються на мікросхеми з фіксованими часовими інтервалами (наприклад, `t_WD = 1.6` с, `t_RST = 200` мс) та варіанти з можливістю налаштування через зовнішній конденсатор або виводи конфігурації (Pin-Strapping).

У мікросхемах із зовнішнім часозадавальним конденсатором тривалість сторожового інтервалу визначається струмом заряду внутрішнього генератора:

```
t_WD = C_T · (V_TH / I_CHG)      [заряд стабільним струмом до порогу V_TH]
```

Для типових значень внутрішнього джерела струму 2 мкА та порогу перемикання 1.2 В залежність зводиться до практичної формули:

```
t_WD = C_T · 1.55 · 10⁶ Ом
```

Якщо під'єднати конденсатор `C_T = 100 нФ`, сторожовий інтервал становитиме:

```
t_WD = 100 · 10⁻⁹ Ф · 1.55 · 10⁶ Ом
     = 0.155 с (155 мс)
```

## Схемотехнічна обв'язка та фільтрація завад

Надійність зовнішнього наглядача залежить від чистоти ліній підключення до мікроконтролера. Імпульсні завади від силових ключів або електростатичні наведення не повинні сприйматися входом `WDI` як хибні імпульси життєздатності.

```
       VDD ────────┬─────────────────────────┬──────── VDD_MCU
                   │                         │
                 ┌─┴─┐                     ┌─┴─┐
                 │ C │ 100nF               │ R │ 10k (Pull-up)
                 └─┬─┘                     └─┬─┘
                   │                         │
                   ├─────────────┐           ├──────── /RESET MCU
                   │             │           │
                 ┌─┴─────────────┴───────────┴─┐
                 │ 1 VDD               RESET 5 │
                 │                             │
                 │ 2 GND                 WDI 4 ├─┐
                 │                             │ │
                 │ 3 /MR                 NC  6 │ │
                 └─┬───────────────────────────┘ │
                   │                             │
                  GND                            │  R_filt 1k
                                                 ├───═══───← GPIO Heartbeat
                                                 │
                                               ┌─┴─┐
                                               │ C │ 100pF (ESD/EMI filter)
                                               └─┬─┘
                                                 │
                                                GND
```

Критичні правила трасування та схемотехніки:
1. **Блокувальний конденсатор**: керамічний конденсатор ємністю 100 нФ (X7R) встановлюється безпосередньо біля виводу `VDD` супервізора (не далі ніж 2 мм від корпусу) з мінімальною індуктивністю доріжок до полігону заземлення.
2. **Фільтр лінії WDI**: якщо вивід процесора віддалений від супервізора на відстань понад 30–50 мм або проходить поруч із силовими трасами (ШІМ моторів, DC-DC перетворювачі), послідовно в лінію вмикається резистор номіналом 470 Ом – 1 кОм, а біля виводу WDI ставиться конденсатор ємністю 47–100 пФ на землю. Це усуває паразитарні фронти від высокочастотних шумів.
3. **Підтягувальний резистор лінії скидання**: оскільки вихід `/RESET` зазвичай є відкритим стоком, обов'язковим є встановлення зовнішнього резистора підтяжки (Pull-Up) номіналом 4.7 кОм – 10 кОм до лінії живлення процесора. Якщо лінія скидання з'єднує кілька мікросхем (MCU, FPGA, радіотрансивер), сумарна паразитарна ємність траси не повинна сповільнювати час наростання фронту (Rise Time) понад 1 мкс.

## Пастка внутрішнього стану WDI та режим зневадження (Debug)

Поширена проблема під час розробки — неможливість покрокового налагодження коду через JTAG/SWD, коли на платі розпаяно апаратний супервізор. Щойно зневаджувач зупиняє процесор на точці зупинки (Breakpoint), вивід GPIO припиняє перемикатися, і через 1.6 секунди зовнішній супервізор апаратно скидає мікроконтролер, розриваючи сесію налагодження.

Для запобігання цьому застосовують одну з трьох схемотехнічних стратегій:
1. **Використання виводу з трьома станами (High-Z Detect)**: більшість сучасних супервізорів мають функцію деактивації WDT, якщо вхід `WDI` переведено у високоімпедансний стан (High-Z) або залишено підтягнутим до середньої точки напруги. Під час ініціалізації зневаджувача вивід GPIO конфігурується як плаваючий вхід.
2. **Апаратне відключення через тестовий джампер / нульовий резистор**: послідовно в лінію WDI або RESET встановлюється джампер, який розмикають на час розробки та налагодження.
3. **Керування через лінію SWO / TRST**: сигнал активності відлагоджувача блокує проходження імпульсів скидання на лінію `NRST` через зовнішній логічний елемент "АБО" (OR gate) або транзисторний ключ.
