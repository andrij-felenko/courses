# 🧮 Виведення оптимуму швидкості проти вітру й енергетичного інтеграла

Цей розбір дає строге математичне виведення двох фундаментальних рівнянь навігаційного повернення: оптимальної повітряної швидкості польоту проти зустрічного вітру (принцип Маккреді для моторного польоту) та інтеграла ефективної енергії батареї з урахуванням динамічного просідання напруги. Без цих рівнянь оцінка точки неповернення лишається евристикою, яка дає збій при першій зміні сили вітру.

## 1. Аеродинамічна крива потужності та фізичний баланс сил

Для прямолінійного горизонтального польоту літального апарата з фіксованим крилом підйомна сила повинна врівноважувати вагу апарата, а сила тяги гвинтомоторної групи — повний аеродинамічний опір.

Повний аеродинамічний опір складається з двох фундаментальних компонентів:
* **Індуктивний опір**: виникає внаслідок скосу потоку за кінцями крила під час створення підйомної сили. Коефіцієнт індуктивного опору обернено пропорційний квадрату швидкості. Зі зменшенням швидкості для створення тієї самої підйомної сили крило вимагає більшого кута атаки, що різко збільшує індуктивний опір.
* **Паразитний (профільний і шкідливий) опір**: тертя повітря об обшивку фюзеляжу, консолей і виступів. Сила паразитного опору зростає прямо пропорційно квадрату повітряної швидкості.

Механічна потужність тяги, необхідна для подолання аеродинамічного опору зі швидкістю `V_a`:

```
P_aero(V_a) = Drag(V_a) · V_a = Drag_ind(V_a) · V_a + Drag_par(V_a) · V_a     [механічна потужність руху]
```

Оскільки сила індуктивного опору пропорційна `1 / V_a²`, а сила паразитного опору пропорційна `V_a²`, потужність горизонтального польоту набуває канонічного вигляду:

```
P_aero(V_a) = k_ind / V_a + k_par · V_a³     [сума індуктивної та паразитної складових потужності]
```

Електрична потужність, споживана від акумуляторної батареї, враховує коефіцієнт корисної дії пропелера, безколекторного двигуна, регулятора швидкості (ESC) та постійне споживання бортової авіоніки:

```
P_elec(V_a) = P_aero(V_a) / (η_prop · η_motor · η_esc) + P_avionics     [електрична потужність системи]
```

Об'єднавши аеродинамічні коефіцієнти з ККД гвинтомоторної групи, отримуємо розрахункову криву електричної потужності:

```
P(V_a) = c_ind / V_a + c_par · V_a³ + P_avionics     [двопараметрична модель електричної потужності]
```

де `c_ind` — узагальнений коефіцієнт індуктивної складової (Вт·м/с), а `c_par` — узагальнений коефіцієнт паразитної складової (Вт·с³/м³).

## 2. Оптимальна повітряна швидкість проти зустрічного вітру

Мета польоту на повернення — подолати фіксовану шляхову дистанцію `D` від поточної точки до точки старту з **мінімальною витратою електричної енергії** `E`.

Позначимо:
* `V_a` — повітряна швидкість *(true airspeed)*, м/с;
* `V_w` — проєкція швидкості вітру на лінію шляху (додатна для зустрічного вітру, від'ємна для попутного), м/с;
* `V_g = V_a - V_w` — шляхова швидкість відносно землі *(ground speed)*, м/с;
* `P(V_a)` — електрична потужність, споживана силовою установкою для підтримки повітряної швидкості `V_a`, Вт;
* `t = D / V_g = D / (V_a - V_w)` — час руху, с.

Повна енергія, витрачена на крейсерський переліт дистанції `D`:

```
E(V_a) = P(V_a) · t = P(V_a) · [D / (V_a - V_w)]     [закон збереження енергії: E = P · t]
e(V_a) = E(V_a) / D = P(V_a) / (V_a - V_w)           [питома витрата енергії на 1 метр шляху, Дж/м]
```

Щоб знайти швидкість `V_a*`, за якої питома витрата `e(V_a)` мінімальна, беремо похідну `de / dV_a` і прирівнюємо її до нуля:

```
d/dV_a [ P(V_a) / (V_a - V_w) ] = 0                                       [умова екстремуму функції]
[ P'(V_a) · (V_a - V_w) - P(V_a) · 1 ] / (V_a - V_w)² = 0                 [правило диференціювання частки]
P'(V_a) · (V_a - V_w) - P(V_a) = 0                                         [знаменник строго додатний при V_a > V_w]
P'(V_a) = P(V_a) / (V_a - V_w)                                            [рівняння оптимальної швидкості]
```

### Геометричний зміст умови Маккреді

Рівняння `P'(V_a) = P(V_a) / (V_a - V_w)` має фундаментальний геометричний зміст, аналогічний принципу Маккреді в планеризмі:
1. По осі абсцис відкладаємо швидкість `V_a`, по осі ординат — споживану потужність `P`.
2. Ставимо точку на осі абсцис, що відповідає вітру: `(V_w, 0)`. При зустрічному вітрі `V_w > 0`, точка лежить праворуч від початку координат.
3. Проводимо дотичну з точки `(V_w, 0)` до кривої `P(V_a)`.
4. Нахил дотичної дорівнює похідній `P'(V_a)`, а за означенням тангенса кута нахилу він дорівнює `(P(V_a) - 0) / (V_a - V_w)`.
5. Точка дотику однозначно задає шукану оптимальну повітряну швидкість `V_a*`.

```
У штиль (V_w = 0):     дотична з точки (0, 0)   → V_a* = V_best_range (максимальна дальність у штиль)
При зустрічному вітрі: дотична з точки (V_w, 0) → V_a* > V_best_range (потрібно летіти ШВИДШЕ)
При попутному вітрі:   дотична з точки (-V_w, 0)→ V_a* < V_best_range (потрібно летіти ПОВІЛЬНІШЕ)
```

Фізична причина збільшення швидкості проти зустрічного вітру полягає у зменшенні часу польоту: летіти повільно означає годинами живити авіоніку та долати індуктивний опір, майже не наближаючись до бази. Збільшуючи швидкість, апарат збільшує хвилинну витрату енергії, але драматично скорочує час перебування в повітрі, завдяки чому сумарна енергія на маршрут зменшується.

### Аналітичний розв'язок для аеродинамічної моделі літака

Підставимо формулу потужності `P(V_a) = c_ind / V_a + c_par · V_a³` у похідну:

```
P'(V_a) = -c_ind / V_a² + 3 · c_par · V_a²     [диференціювання виразу потужності за V_a]
```

Підставляємо в рівняння рівноваги `P'(V_a) · (V_a - V_w) = P(V_a)`:

```
(-c_ind / V_a² + 3 · c_par · V_a²) · (V_a - V_w) = c_ind / V_a + c_par · V_a³     [підстановка похідної та функції]
-c_ind / V_a + c_ind · V_w / V_a² + 3 · c_par · V_a³ - 3 · c_par · V_w · V_a² = c_ind / V_a + c_par · V_a³     [розкриття дужок]
2 · c_par · V_a³ - 3 · c_par · V_w · V_a² - 2 · c_ind / V_a + c_ind · V_w / V_a² = 0     [зведення подібних доданків]
```

Помноживши на `V_a²`, отримуємо алгебраїчне рівняння 5-го степеня:

```
2 · c_par · V_a⁵ - 3 · c_par · V_w · V_a⁴ - 2 · c_ind · V_a + c_ind · V_w = 0     [канонічне рівняння оптимальної швидкості]
```

Для практичних обчислень у мікроконтролері застосовують лінеаризоване наближення навколо швидкості найкращої дальності у штиль `V_0 = (c_ind / c_par)^(1/4)`:

```
V_a*(V_w) ≈ V_0 + k_w · V_w     [де k_w ≈ 0.35 … 0.50 для типових БПЛА літакового типу]
```

## 3. Розрахунок шляхової швидкості при довільному куті вітру

Коли вітер дме під кутом `θ` до лінії заданого шляху повернення (де `θ = 0°` — чистий попутний, `θ = 180°` — чистий зустрічний, `θ = 90°` — чистий боковий вітер):

Векторне рівняння швидкостей:

```
V_ground_vec = V_air_vec + V_wind_vec     [трикутник швидкостей навігації]
```

Розкладемо на поздовжню вісь (вздовж бажаної лінії шляху) та поперечну вісь (перпендикулярно шляху):

```
V_ground = V_a · cos(WCA) - V_w · cos(θ)      [поздовжня складова швидкості]
0        = V_a · sin(WCA) - V_w · sin(θ)      [поперечна компенсація зносу: бічна шляхова швидкість = 0]
```

де `WCA` *(Wind Correction Angle)* — кут випередження вітру (кутовий доворот носа апарата у бік вітру).

З поперечного рівняння:

```
sin(WCA) = (V_w / V_a) · sin(θ)                                   [кут утримання лінії шляху]
cos(WCA) = √(1 - sin²(WCA)) = √(1 - (V_w / V_a)² · sin²(θ))       [тригонометрична тотожність]
```

Підставляючи `cos(WCA)` у поздовжнє рівняння, отримуємо точну аналітичну формулу шляхової швидкості зближення з базою:

```
V_g(θ) = V_a · √(1 - (V_w / V_a)² · sin²(θ)) - V_w · cos(θ)      [шляхова швидкість проти довільного вітру]
V_g(θ) = √(V_a² - V_w² · sin²(θ)) - V_w · cos(θ)                 [еквівалентний алгебраїчний вигляд формули]
```

### Граничні умови та фізичні обмеження навігації

1. **Знос непереборний**: якщо `V_w · sin(θ) > V_a`, підкореневий вираз стає від'ємним. Апарат фізично не здатен утримати пряму лінію шляху — його здуває вбік навіть при розвороті носа на 90° проти вітру. Автопілот повинен негайно перейти в режим аварійної посадки або змінити курс убік запасного майданчика.
2. **Зустрічний вітер переважає тягу**: якщо `θ = 180°` і `V_w ≥ V_a`, то `V_g ≤ 0`. Апарат віддаляється від бази задом наперед або зависає на місці, витрачаючи енергію даремно.
3. **Енергетична сингулярність**: при наближенні `V_g` до нуля час польоту `t = D / V_g` прямує до нескінченності, через що необхідна енергія `E_return` стрімко перетинає фізичну ємність батареї навіть на відстані у кілька сотень метрів.

## 4. Електрохімічний баланс батареї та інтеграл Voltage Sag

Енергія `E_batt(t)`, яку хімічне джерело може віддати в навантаження до моменту спрацьовування апаратного захисту за напругою `V_cutoff`, не дорівнює добутку паспортної ємності на поточний ступінь заряду SoC.

Миттєва напруга на клемах акумуляторної батареї описується еквівалентною схемою Тевена:

```
V_term(t) = V_ocv(SoC(t)) - I(t) · R_int(T, SoC) - V_pol(I, t)     [модель Тевена із внутрішнім опором]
```

де:
* `V_ocv(SoC)` — напруга розімкненого кола *(Open Circuit Voltage)*, яка нелінійно зменшується під час розряду;
* `R_int(T, SoC)` — внутрішній омічний опір збірки, який зростає при охолодженні за законом Арреніуса;
* `V_pol` — поляризаційне перенапруження дифузії в електроліті;
* `I(t) = P(t) / V_term(t)` — струм розряду батареї.

Температурна залежність внутрішнього опору підпорядковується експоненційному закону:

```
R_int(T) = R_0 · exp( E_act / (R_gas · T_kelvin) )     [рівняння Арреніуса для внутрішнього опору]
```

При падінні температури з +25°C до 0°C опір типових Li-ion комірок формату 21700 (Samsung 50E / Molicel P42A) зростає у 2.2–2.8 раза.

Під час повернення проти сильного вітру необхідна тяга вимагає струму `I_ret ≫ I_cruise_still`. За рахунок спаду `I_ret · R_int` термінальна напруга досягає порогу `V_cutoff` задовго до того, як хімічний заряд вичерпається:

```
V_term = V_cutoff  ⟺  V_ocv(SoC_cutoff) = V_cutoff + I_ret · R_int(T)     [умова досягнення апаратної відсічки]
```

Критичний залишковий заряд `SoC_cutoff`, нижче якого політ з високою тягою неможливий без переривання живлення:

```
SoC_cutoff(I_ret, T) = V_ocv⁻¹(V_cutoff + I_ret · R_int(T))     [поріг невикористовуваного залишку заряду]
```

Фактична корисна енергія, доступна для маневру повернення:

```
E_usable = Q_nom · ∫_{SoC_cutoff}^{SoC_current} [ V_ocv(s) - I_ret · R_int(T, s) ] ds     [інтеграл корисної енергії]
```

### Числовий розрахунок на прикладі збірки Li-ion 6S2P

Розглянемо акумуляторний блок 6S2P на елементах Molicel P42A (номінальна напруга 21.6 В, ємність 8.4 А·год, повний запас 181.4 Вт·год). Поріг апаратного відсікання польотного контролера встановлено на рівні `V_cutoff = 3.0 В / cell` (18.0 В на збірку).

1. **Штатний режим у штиль / за вітром**:
   * Струм розряду `I = 8 А` (потужність 170 Вт);
   * Внутрішній опір при температурі +15°C `R_int = 50 мОм`;
   * Просідання напруги `ΔV = 8 А · 0.050 Ом = 0.40 В` (0.067 В на комірку);
   * Напруга розімкненого кола при відсічці `V_ocv = 3.0 + 0.067 = 3.067 В`, що відповідає `SoC_cutoff ≈ 3.5%`;
   * Доступна корисна ємність: **96.5% від номіналу**.

2. **Форсоване повернення проти вітру 12 м/с**:
   * Струм розряду `I = 45 А` (потужність 850 Вт для підтримки швидкості 20 м/с і набору висоти);
   * Внутрішній опір на холоді +2°C `R_int = 75 мОм`;
   * Просідання напруги `ΔV = 45 А · 0.075 Ом = 3.375 В` (0.563 В на комірку);
   * Напруга розімкненого кола при відсічці `V_ocv = 3.0 + 0.563 = 3.563 В`, що відповідає `SoC_cutoff ≈ 28%`;
   * Доступна корисна ємність: **лише 72% від номіналу**.

Різниця між цими режимами становить майже чверть повної енергії батареї. Якщо алгоритм розрахунку RTL не враховує динамічне просідання напруги від розрахункового струму повернення `I_ret`, борт почне зворотний рух із запізненням і зазнає аварії через раптове відсікання живлення.
