# 🧮 Розрахунок точки роси та маси осушувача в закритому об'ємі

Повністю герметичний відсік безпілотного катера чи наземного робота, зібраний у теплому цеху за кімнатної температури й закритий без вакуумування, містить у собі фіксовану масу атмосферного повітря з певною часткою водяної пари. Коли апарат виходить на місію й занурюється в холодну водойму чи працює взимку на снігу, температура внутрішніх стінок корпусу та оптичного скла камер швидко падає. Якщо температура поверхні опускається нижче точки роси замкненого всередині повітря, водяна пара переходить у рідкий стан, утворюючи плівку конденсату або мікрокраплі. Для запобігання корозії та запітнінню оптики у гермобокс закладають сорбційний осушувач (силікагель або синтетичний цеоліт). Нижче наведено термодинамічний розрахунок точки роси за рівнянням Магнуса-Тетенса, визначення початкової вологи в об'ємі та точний розрахунок необхідної маси осушувача з урахуванням дифузійного проникнення вологи крізь полімерні ущільнювачі.

---

## 1. Парціальний тиск насиченої пари та точка роси (рівняння Магнуса-Тетенса)

Тиск насиченої водяної пари `P_sat` (тиск, за якого пара перебуває у термодинамічній рівновазі з рідкою водою за даної температури `T`) експоненційно залежить від температури. Для діапазону температур від −45 °C до +60 °C високу точність (похибка менше 0.4%) забезпечує апроксимаційна формула Магнуса-Тетенса:

```
P_sat(T) = a · exp((b · T) / (T + c))   [гПа або мбар]
```

де константи для рідкої води становлять:
- `a = 6.112 гПа` (тиск насиченої пари при 0 °C);
- `b = 17.67` (безрозмірний коефіцієнт);
- `c = 243.5 °C` (температурна стала);
- `T` — температура повітря в градусах Цельсія (°C).

Якщо повітря в боксі має температуру `T` і відносну вологість `RH` (у відсотках від 0 до 100%), фактичний парціальний тиск водяної пари `P_v` дорівнює:

```
P_v = (RH / 100) · P_sat(T)   [гПа]
```

Точка роси `T_dp` — це температура, до якої треба охолодити ізобарно (за незмінного тиску та вологовмісту) повітря, щоб водяна пара досягла 100% насичення (`P_v = P_sat(T_dp)`). Обертаючи рівняння Магнуса відносно температури, отримуємо вираз для точки роси:

```
γ(T, RH) = ln(RH / 100) + (b · T) / (T + c)

T_dp = (c · γ(T, RH)) / (b - γ(T, RH))   [°C]
```

### Числовий приклад обчислення точки роси

Герметичний бокс камери ровера закрили в майстерні за температури `T = +25 °C` і відносної вологості `RH = 70%`:
1. Тиск насиченої пари при +25 °C:
   `P_sat(25) = 6.112 · exp((17.67 · 25) / (25 + 243.5)) = 6.112 · exp(1.645) = 31.67 гПа`.
2. Фактичний парціальний тиск пари:
   `P_v = 0.70 · 31.67 = 22.17 гПа`.
3. Розрахунок проміжної функції `γ`:
   `γ = ln(0.70) + (17.67 · 25) / (268.5) = −0.3567 + 1.6453 = 1.2886`.
4. Точка роси:
   `T_dp = (243.5 · 1.2886) / (17.67 − 1.2886) = 313.77 / 16.3814 = +19.15 °C`.

Висновок: якщо катер спустити у воду з температурою +15 °C (що значно нижче +19.15 °C), внутрішня поверхня алюмінієвого корпусу та оптичне скло камери миттєво вкриються конденсатом, оскільки їхня температура нижча за точку роси замкненого повітря.

## 2. Абсолютна вологість і початкова маса води в гермобоксі

Щоб дізнатися, скільки грамів рідкої води виділиться у вигляді роси, необхідно обчислити абсолютну вологість `ρ_v` — густину водяної пари в одиниці об'єму (г/м³). З рівняння стану ідеального газу для водяної пари (`P_v · V = (m / M_w) · R · T_kelvin`, де `M_w = 18.015 г/моль`, `R = 8.3144 Дж/(моль·К)`):

```
ρ_v = m_v / V = (M_w · P_v) / (R · (T + 273.15))
```

Підставляючи числові константи (`M_w / R ≈ 2.1667` при тиску `P_v` у Паскалях, або з урахуванням гПа):

```
ρ_v(T, RH) = (216.7 · P_v) / (T + 273.15) = (2.1667 · RH · P_sat(T)) / (T + 273.15)   [г/м³]
```

Для боксу об'ємом `V` (в літрах або м³) початкова маса вільної водяної пари становить:

```
m_water,0 = V_м³ · ρ_v(T_0, RH_0)   [г]
```

Для нашого боксу об'ємом `V = 4.0 л = 0.004 м³` за початкових умов (+25 °C, RH 70%, `P_v = 22.17 гПа`):
```
ρ_v = (216.7 · 22.17) / (298.15) = 4804.2 / 298.15 = 16.11 г/м³
m_water,0 = 0.004 м³ · 16.11 г/м³ = 0.0644 г (64.4 мг води)
```

Ці 64.4 мг води, осідаючи на друкованій платі площею 100 см², утворюють суцільну водяну плівку завтовшки 6.4 мікрона, достатню для виникнення гальванічної корозії та мікрострумів витоку між сусідніми виводами мікросхем.

## 3. Дифузійний приплив вологи крізь полімерні ущільнення за час місії

Жоден еластомер (нітрил NBR, силікон, EPDM) і жоден пластиковий корпус не є абсолютно непроникними для газів на молекулярному рівні. Водяна пара постійно дифундує крізь товщу ущільнювального кільця O-ring або пластикову стінку з області з високим парціальним тиском пари (вологе зовнішнє середовище) в область із низьким парціальним тиском (осушений внутрішній об'єм).

За першим законом Фіка дифузійний потік водяної пари `J` крізь бар'єр площею `A_seal` і товщиною `L_seal` становить:

```
dm / dt = P_perm · (A_seal / L_seal) · ΔP_v
```

де:
- `P_perm` — коефіцієнт паропроникності матеріалу ущільнення `[г · мм / (м² · доба · кПа)]`;
- `A_seal` — ефективна площа контакту ущільнення з довкіллям `[м²]`;
- `L_seal` — довжина шляху дифузії (ширина паза або товщина стінки) `[мм]`;
- `ΔP_v = P_v,ext − P_v,int` — різниця парціальних тисків пари зовні та всередині `[кПа]`.

Типові коефіцієнти паропроникності еластомерів за температури +25 °C:
- **Силікон (VMQ):** `P_perm ≈ 15.0...25.0 г·мм/(м²·доба·кПа)` (дуже висока проникність для пари);
- **Нітрильний каучук (NBR):** `P_perm ≈ 0.8...1.5 г·мм/(м²·доба·кПа)`;
- **Фтореластомер (FKM / Viton):** `P_perm ≈ 0.15...0.35 г·мм/(м²·доба·кПа)` (найкращий бар'єр проти вологи);
- **EPDM:** `P_perm ≈ 1.0...2.0 г·мм/(м²·доба·кПа)`.

Загальна маса вологи `m_diff`, що проникне в бокс за час автономної роботи чи зберігання `t_days` (у добах):

```
m_diff = P_perm · (A_seal / L_seal) · ΔP_v · t_days   [г]
```

Якщо периметр ущільнення кришки становить 500 мм, товщина шнура O-ring 2.5 мм, відкрита площа `A_seal = 0.5 м · 0.001 м = 0.0005 м²`, ширина паза `L_seal = 3.0 мм`, матеріал — NBR (`P_perm = 1.0`), при зовнішній вологості 100% (+25 °C, `P_v,ext = 3.17 кПа`) та сухому боксі (`P_v,int ≈ 0.3 кПа`, `ΔP_v = 2.87 кПа`), за 30 діб проникне:

```
m_diff = 1.0 · (0.0005 / 3.0) · 2.87 · 30 = 1.0 · 0.000167 · 2.87 · 30 ≈ 0.0144 г (14.4 мг)
```

## 4. Розрахунок необхідної маси сорбційного осушувача (Desiccant Sizing)

Осушувач повинен зв'язати як початкову вологу `m_water,0`, так і дифузійний приплив `m_diff`, утримуючи рівноважну відносну вологість усередині боксу нижче цільового безпечного порогу `RH_target` (зазвичай `RH_target ≤ 10...15%` за найнижчої робочої температури, щоб точка роси була нижчою за −30 °C).

### Ізотерма адсорбції

Вологоємність осушувача `w(RH)` (маса поглиненої води на одиницю сухої маси сорбенту, %) залежить від типу матеріалу та рівноважної відносної вологості повітря:
1. **Силікагель типу A (дрібнопористий, SiO₂):**
   - При `RH = 10%`: `w ≈ 6...8%` (0.06–0.08 г води / г силікагелю);
   - При `RH = 20%`: `w ≈ 13...16%`;
   - При `RH = 50%`: `w ≈ 28...32%`.
2. **Молекулярні сита (синтетичний цеоліт 4A / 13X):**
   - Має практично лінійну або круту характеристику навіть за дуже низької вологості:
   - При `RH = 10%`: `w ≈ 16...19%`;
   - При `RH = 20%`: `w ≈ 20...22%`.

Розрахункова робоча вологоємність сорбенту `Δw` — це різниця між рівноважною ємністю при допустимому порозі `RH_target` та початковою залишковою вологістю регенерованого осушувача `w_0` (зазвичай `w_0 ≤ 1.5%` після прожарювання):

```
Δw = w(RH_target) − w_0   [г води / г сорбенту]
```

### Інженерна формула маси осушувача за стандартом MIL-D-3464E

Загальна формула розрахунку маси сухого осушувача:

```
m_des = (m_water,0 + m_diff) / (η_eff · Δw)   [г]
```

де `η_eff` — коефіцієнт експлуатаційного запасу та старіння сорбенту (приймається `η_eff = 0.6...0.7` для врахування нерівномірності насичення та температурних коливань).

### Комплексний числовий розрахунок для приладового відсіку катера

**Вихідні дані:**
- Об'єм відсіку електроніки: `V = 6.0 л = 0.006 м³`;
- Умови герметизації: `T_0 = +28 °C`, `RH_0 = 80%`;
- Матеріал ущільнення: NBR, розрахунковий дифузійний приплив за 90 діб місії: `m_diff = 0.050 г`;
- Цільова відносна вологість у закритому боксі: `RH_target = 10%`;
- Тип сорбенту: силікагель типу A (`w(10%) = 0.07 г/г`, `w_0 = 0.01 г/г`, `Δw = 0.06 г/г`);
- Коефіцієнт запасу: `η_eff = 0.65`.

**Розрахунок:**
1. Тиск насиченої пари при +28 °C:
   `P_sat(28) = 6.112 · exp((17.67 · 28) / (28 + 243.5)) = 37.79 гПа`.
2. Фактична абсолютна вологість:
   `ρ_v = (216.7 · 0.80 · 37.79) / (301.15) = 6554.4 / 301.15 = 21.76 г/м³`.
3. Початкова маса вологи в 6 літрах:
   `m_water,0 = 0.006 м³ · 21.76 г/м³ = 0.1306 г (130.6 мг)`.
4. Сумарна волога для поглинання:
   `m_total = m_water,0 + m_diff = 0.1306 + 0.050 = 0.1806 г`.
5. Необхідна маса сухого силікагелю:
   `m_des = 0.1806 / (0.65 · 0.06) = 0.1806 / 0.039 = 4.63 г`.

**Інженерний висновок:** для надійного захисту 6-літрового відсіку протягом 3 місяців автономної роботи достатньо закласти стандартний заводський пакетик індикаторного силікагелю номіналом **5–10 грамів**. Закладання менше 5 грамів призведе до вичерпання ресурсу сорбенту та випадання роси при першому переході через нульову ізотерму.
