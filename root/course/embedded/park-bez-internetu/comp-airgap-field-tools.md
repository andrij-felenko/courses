# Апаратні інструменти польового техніка для ізольованих систем

Цей огляд узагальнює клас спеціалізованих апаратних інструментів, захисних перехідників та автономних програматорів, які польові інженери використовують для безпечного обслуговування, діагностики та оновлення прошивки промислових контролерів, приладів обліку та систем під суворим режимом повітряного зазору (англ. *air-gap*).

Робота на реальних об'єктах (шафах релейного захисту, газорозподільних станціях, промислових насосних установках чи вуличних шафах автоматики) докорінно відрізняється від підключення налагоджувальної плати на лабораторному столі. Пряме встромляння стандартного кабелю USB чи перехідника UART у промисловий пристрій загрожує випалюванням порту через різницю потенціалів «землі», вибухом через іскроутворення у вибухонебезпечних зонах або занесенням шкідливого програмного забезпечення з комп'ютера техніка.

---

### 1. Оптичні зчитувальні голівки (IEC 62056-21 / ANSI C12.18)

Для герметичних приладів обліку (електролічильників, витратомірів газу, теплолічильників) стандартом де-факто є безконтактне оптичне з'єднання. На лицьовій панелі приладу відсутні будь-які металеві роз'єми — зв'язок здійснюється через інфрачервоний порт.

```
       ТЕХНІК / ПЛАНШЕТ                            ПРОМИСЛОВИЙ ПРИЛАД
+---------------------------+             +----------------------------------+
|   Оптична голівка         |             |   Лицьова панель приладу         |
| +-----------------------+ |             | +------------------------------+ |
| | Магнітне кільце (N/S) | |  Магнітне   | | Сталеве кільце / магніт      | |
| |     [  ○  ○  ]        | === притяг. ==| |     [  ○  ○  ]               | |
| |  IR LED    Photodiode | |             | | Photodiode   IR LED          | |
| | (940 нм)   (RX сенсор)| |  Оптичний   | | (RX сенсор) (940 нм)         | |
| +-----------------------+ |  IR-промінь | +------------------------------+ |
|        |                  |             |         |                        |
|   USB / Bluetooth         |             |    Внутрішній UART MCU           |
+---------------------------+             +----------------------------------+
```

#### Принцип роботи та конструкція:
- **Оптичний тракт:** пара з інфрачервоного світлодіода (довжина хвилі 900–940 нм) та фотодіода або фототранзистора. Швидкість передачі становить від 300 бод (для первинного автовизначення) до 115200 бод під час потокового заливання прошивки.
- **Магнітне кріплення:** всередині корпусу голівки встановлено кільцевий постійний неодимовий магніт із зусиллям утримання 15–20 Н. Він автоматично центрує оптичні осі голівки навпроти фотоприймачів приладу крізь прозоре захисне скло полікарбонатного корпусу.
- **Повна гальванічна ізоляція:** оптичний інтерфейс фізично виключає електричний контакт. Напруга пробою визначається лише товщиною повітряного проміжку та пластикового корпусу (понад 15 кВ).

#### Польові пастки оптичного каналу:
- **Засвічування прямим сонячним світлом:** спектр яскравого сонця містить потужну інфрачервону складову. Якщо прилад встановлено на відкритій опорі, сонячне світло насичує фотодіод, через що приймач бачить суцільну логічну `0` (постійне засвічення). Професійні голівки використовують гумові бленди для захисту від бокового світла.
- **Забруднення та подряпини полікарбонату:** пил, конденсат або жирні відбитки на склі розсіюють ІЧ-промінь, викликаючи сплеск бітових помилок (BER). Протокол оновлення обов'язково повинен підтримувати поблокове квитування та повторну передачу пошкоджених секторів.

### 2. Гальванічні ізолятори інтерфейсів (USB, RS-485, CAN)

Якщо оновлення виконується через дротові шини (RS-485, CAN або інженерний USB-порт на дверцятах шафи), використання гальванічної розв'язки є обов'язковою вимогою безпеки персоналу та апаратури.

```
НОУТБУК ТЕХНІКА                  ГАЛЬВАНІЧНИЙ ІЗОЛЯТОР             ПРОМИСЛОВИЙ КОНТРОЛЕР
+---------------+            +---------------------------+            +---------------+
| Земля GND_PC  |            |   Ємнісний або оптичний   |            | Земля GND_PLC |
| (Автомобіль / | ---------> |   бар'єр ізоляції         | ---------> | (Контур цеху  |
| мережа 230 В) |            |   (Пробій до 3000–5000 В) |            | 380 В / PE)   |
+---------------+            +---------------------------+            +---------------+
                                          ▲
                                          │
                        Усуває вирівнювальний струм петлі!
```

#### Чому це критично:
У промислових установках потенціал заземлення шафи автоматики може відрізнятися від потенціалу «землі» ноутбука техніка (наприклад, якщо ноутбук заряджається від автомобільного інвертора або розетки іншої підстанції) на десятки або сотні вольтів. Під час з'єднання звичайного USB-кабелю екран роз'єму замкне цю різницю через себе — вирівнювальний струм у десятки ампер миттєво випалює USB-контролер материнської плати або порти мікроконтролера.

#### Апаратні рішення:
- **USB-ізолятори:** побудовані на базі спеціалізованих мікросхем (наприклад, Analog Devices ADuM3160 або TI ISOUSB211) із вбудованими ізольованими DC-DC перетворювачами, що забезпечують захист до 2.5–5 кВ RMS.
- **Ізольовані конвертери RS-485 / CAN:** містять роздільне живлення трансивера, вбудовані супресори TVS (Transient Voltage Suppressor) та самовідновні запобіжники (PTC) для захисту від наведених імпульсів блискавки.

### 3. Захищені апаратні USB-накопичувачі та криптотокени

У контурах із високими вимогами безпеки (енергетика, військова техніка, банки) заборонено використовувати звичайні споживчі флешки. 

#### Класи захищених накопичувачів:
1. **Флеш-носії з апаратним перемикачем захисту від запису (Hardware Write-Protect Switch):**
   - Фізичний перемикач розриває лінію сигналу дозволу запису на мікросхему Flash. Навіть якщо ноутбук техніка заражений шпигунським ПЗ, вірус не може змінити бінарний образ прошивки на носії або заразити флешку авторан-скриптом.
2. **Накопичувачі з апаратною клавіатурою введення PIN-коду:**
   - Дешифрування вмісту відбувається автономним криптопроцесором усередині флешки лише після введення пін-коду на кнопках корпусу. Ключ шифрування ніколи не потрапляє в пам'ять комп'ютера.
3. **Захист від атак класу BadUSB:**
   - Промислові токени мають захищену OTP-пам'ять мікроконтролера USB-мосту, що унеможливлює модифікацію дескрипторів пристрою (перетворення флешки на віртуальну клавіатуру, яка вводить шкідливі команди).

### 4. Автономні польові прошивачі (Handheld Flasher Jigs)

Найбезпечнішим рішенням для масового оновлення парку без інтернету є використання **спеціалізованого портативного прошивача** («автономної кнопки»).

```
+-------------------------------------------------------------+
|               АВТОНОМНИЙ ПОЛЬОВИЙ ПРОШИВАЧ                  |
|                                                             |
|   +-----------------------+     +-----------------------+   |
|   |  OLED / E-Paper Екран |     |  Кнопка «START FLASH» |   |
|   |  «v1.3 Ready | 98%»   |     |  (Одна велика кнопка) |   |
|   +-----------------------+     +-----------------------+   |
|               │                             │               |
|               ▼                             ▼               |
|   +-----------------------------------------------------+   |
|   |       Внутрішній контролер прошивача (STM32/ESP32)  |   |
|   |  • Зчитує підписаний .upkg із захищеної SD-карти    |   |
|   |  • Живиться від власного акумулятора 18650 (3.7 В)  |   |
|   |  • Має гальванічно ізольований вихід SWD/UART/RS485 |   |
|   +-----------------------------------------------------+   |
|                              │                              |
+------------------------------┼------------------------------+
                               ▼ Ізольований кабель до плати
```

#### Переваги портативного прошивача:
- **Виключення комп'ютера з польового ланцюга:** прошивач не містить повноцінної ОС (Windows/Linux), не має доступу до інтернету і не виконує стороннього коду. Ризик занесення вірусів або помилки оператора зведений до нуля.
- **Двокнопковий інтерфейс:** технік під'єднує роз'єм до шафи, дивиться на зелений світлодіод готовності та натискає одну кнопку. Контролер прошивача самостійно проводить діагностику, перевіряє сумісність заліза, заливає прошивку, верифікує відгук і записує результат в автономний журнал аудиту.
- **Вбудоване резервне живлення:** прошивач може живити цільовий мікроконтролер власним стабілізованим джерелом 3.3 В / 5 В під час оновлення, якщо основне живлення об'єкта тимчасово знеструмлене під час регламентних робіт.
