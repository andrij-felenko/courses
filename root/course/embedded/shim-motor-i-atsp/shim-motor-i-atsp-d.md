Розробник збирає плату керування колекторним або безколекторним мотором, де мікроконтролер одночасно генерує сигнали широтно-імпульсної модуляції (ШІМ) для силових транзисторів і вимірює напругу давача струму або аналогового положення за допомогою 12-бітного аналого-цифрового перетворювача (АЦП). Коли двигун зупинений, показ давача ідеально стабільний: перетворювач видає чіткі 1.650 В із розкидом у межах ±1 одиниці найменшого значущого розряду (англ. *Least Significant Bit*, LSB). Проте щойно на затвори польових транзисторів подається ШІМ із коефіцієнтом заповнення 30% на частоті 20 кГц і через обмотки починає текти струм у 15 А, вимірювання миттєво руйнується. Код АЦП починає хаотично скакати на ±150 LSB (розкид у сотні мілівольтів), середнє обчислене значення напруги зміщується на 8–10%, а контур зворотного зв'язку фіксує хибні аварійні перевантаження за струмом. Спроба врятувати ситуацію стандартним програмним фільтром ковзного середнього лише сповільнює реакцію пристрою на зміну навантаження, але не прибирає систематичний зсув виміряної величини.

Ця проблема виникає не через апаратну несправність кремнієвого кристала АЦП і не через похибку самого давача. Вона є прямим наслідком взаємодії наносекундних комутаційних фронтів силового струму з паразитними параметрами друкованої плати та асинхронного моменту зняття вибірки. У цьому матеріалі ми розберемо фізичні шляхи проникнення силових завад у чутливий аналоговий тракт, правила топологічного розділення силової та аналогової земель, техніку апаратної фазової синхронізації вибірки АЦП із центром імпульсу ШІМ, а також математику нелінійної цифрової фільтрації комутаційних глітчів.

## Анатомія комутаційного хаосу: три шляхи проникнення завади

Щоб зрозуміти причину спотворень, розглянемо перехідні процеси, які виникають під час кожного перемикання силового польового транзистора (MOSFET). Нехай напівміст керує індуктивним навантаженням двигуна з напругою живлення шини `V_bus = 24 В` та струмом навантаження `I_load = 15 А`. Сучасні силові ключі вмикаються і вимикаються за час `t_sw = 15...30 нс`. Це породжує два екстремальні фізичні чинники:

1. Швидкість наростання струму:
```
di/dt = 15 А / (20 · 10⁻⁹ с) = 7.5 · 10⁸ А/с
```

2. Швидкість наростання напруги на середній точці півмоста:
```
dV/dt = 24 В / (15 · 10⁻⁹ с) = 1.6 · 10⁹ В/с
```

Такі швидкості перетворюють кожен міліметр мідного провідника та кожну пікофараду паразитної ємності на ефективний канал передачі енергії від силового контуру в аналоговий тракт. Виділяють три незалежні механізми проникнення завади: кондуктивний (гальванічний), ємнісний та індуктивний.

![Шляхи проникнення ШІМ-завад у вимірювальний тракт](/root/course/embedded/shim-motor-i-atsp/img/coupling-mechanisms.svg)
*Три фізичні шляхи наведення завад від силового ШІМ-комутатора на вимірювальне коло: кондуктивний струм по спільному імпедансу, ємнісний струм зміщення та взаємна індуктивність просторових петель.*

### 1. Гальванічний зв'язок по спільному імпедансу землі (Common Ground Impedance Coupling)

Найпоширеніша топологічна помилка — використання спільного земляного провідника або послідовного земляного ланцюга для сильнострумової силової частини та слаботочного аналогового давача. Мідна доріжка друкованої плати завдовжки 15 мм і завширшки 0.5 мм володіє активним опором близько `R_gnd = 8 мОм` та власною індуктивністю (лат. *inductio* — наведення) близько `L_gnd = 15 нГн` (приблизно 1 нГн на кожен міліметр довжини).

Коли струм мотора повертається до джерела живлення через цю ділянку, на ній виникає сумарне падіння напруги згідно з рівнянням:

```
V_gnd_noise = I_motor · R_gnd + L_gnd · (di/dt)
```

**Worked-приклад: Розрахунок амплітуди комутаційного стрибка напруги на спільній землі.**

```
Вихідні дані:
   Постійний струм навантаження: I_motor = 15 А
   Активний опір спільної ділянки землі: R_gnd = 0.008 Ом
   Паразитна індуктивність ділянки: L_gnd = 15 · 10⁻⁹ Гн
   Швидкість комутації струму: di/dt = 7.5 · 10⁸ А/с

Крок 1. Розрахунок постійного резистивного падіння напруги:
   V_res = I_motor · R_gnd
   V_res = 15 А · 0.008 Ом = 0.120 В = 120 мВ

Крок 2. Розрахунок індуктивного сплеску напруги під час перемикання ключа:
   V_ind = L_gnd · (di/dt)
   V_ind = (15 · 10⁻⁹ Гн) · (7.5 · 10⁸ А/с) = 11.25 В

Крок 3. Підсумок:
   У момент комутації потенціал локальної землі давача стрибає на 11.25 В відносно мікроконтролера!
```

Навіть якщо сплеск триває лічені десятки наносекунд, опорна напруга АЦП (VREF-) та аналоговий вхід миттєво виходять за межі допустимого діапазону. Захисні діоди кристала АЦП відкриваються, струм інжектується в підкладку мікроконтролера (англ. *substrate injection*), заряджаючи сусідні внутрішні вузли, а перетворювач видає значення насичення (0 або 4095).

### 2. Ємнісний зв'язок (dV/dt наведення)

Вузол комутації фази мотора (точка з'єднання верхнього і нижнього транзисторів) перемикається між 0 В та напругою живлення з крутизною фронту понад `10⁹ В/с`. Між силовим полігоном фази (або радіатором транзисторів) та високоомною доріжкою аналогового сигналу неминуче існує взаємна паразитна ємність монтажу `C_par` величиною від 0.5 до 3 пФ.

Змінне електричне поле породжує струм зміщення через цю ємність:

```
I_disp = C_par · (dV/dt)
```

При `C_par = 2 пФ` та `dV/dt = 1.6 · 10⁹ В/с` маємо:

```
I_disp = 2 · 10⁻¹² Ф · 1.6 · 10⁹ В/с = 3.2 мА
```

Якщо вхідний імпеданс (лат. *impedimentum* — перешкода) аналогового кола чи внутрішнього дільника напруги становить `R_in = 20 кОм`, цей струм зміщення створює на вході АЦП імпульс напруги:

```
V_noise_cap = I_disp · R_in = 3.2 · 10⁻³ А · 20000 Ом = 64 В
```

Цей імпульс зрізається внутрішніми діодами захисту кристала мікроконтролера до рівня живлення плюс напруга прямого падіння на діоді (`3.3 В + 0.6 В = 3.9 В`), але одночасно викликає значний розряд вибіркового конденсатора АЦП (англ. *Sample & Hold capacitor*) і зсув напруги внутрішнього джерела опорної напруги на час відновлення стабілізатора.

### 3. Індуктивний зв'язок силових петель (di/dt наведення)

Силовий струм мотора циркулює по замкненому контуру: вивід конденсатора живлення → верхній транзистор → обмотка двигуна → нижній транзистор → струмовимірювальний шунт → земляний вивід конденсатора. Цей контур охоплює певну геометричну площу `A_power`.

Аналогове коло (від вимірювального шунта чи давача до входу АЦП і назад по землі) також утворює контур площею `A_sense`. Згідно із законом електромагнітної індукції Фарадея, змінне магнітне поле струму мотора пронизує вимірювальний контур. Взаємна індуктивність `M` між двома петлями наводить у сигнальному колі паразитну електрорушійну силу (ЕРС):

```
V_ind_loop = -M · (di/dt)
```

Взаємна індуктивність пропорційна добутку площ обох петель та обернено пропорційна кубу відстані між ними у просторі:

```
M ≈ μ₀ · (A_power · A_sense) / (2 · π · d³)
```

Якщо силова та вимірювальна петлі мають велику площу або прокладені паралельно на відстані кількох міліметрів, величина `M` легко сягає 1–5 нГн, що під дією `di/dt = 7.5 · 10⁸ А/с` генерує паразитну ЕРС амплітудою від 0.75 В до 3.75 В безпосередньо всередині вимірювального контуру, навіть за умови ідеально розділених провідників живлення.

## Топологічне лікування: розведення AGND/PGND та вимірювання Кельвіна

Боротьба із силовими завадами починається з геометрії провідників на друкованій платі. Жоден програмний алгоритм не здатний відновити корисний сигнал, якщо апаратний тракт фізично спотворюється на десятки вольт.

![Топологія друкованої плати: послідовна земля проти зіркової](/root/course/embedded/shim-motor-i-atsp/img/pcb-grounding-star-split.svg)
*Порівняння земляної топології: послідовне об'єднання створює паразитичний зсув опорної напруги, тоді як зіркова структура ізолює силовий струм мотора від чутливого аналогового тракту.*

### Розділення силової та аналогової зон: правило суцільного полігону

У сучасних багатошарових друкованих платах застаріла практика фізичного розрізання земляного шару на дві ізольовані пластини (AGND та PGND), з'єднані феритовою бусиною або тонкою перемичкою, часто створює більше проблем, ніж вирішує. Якщо будь-яка цифрова чи аналогова лінія перетинає щілину розрізаного полігону землі, зворотний високочастотний струм змушений огинати розріз по периметру. Це різко збільшує площу сигнальної петлі, перетворюючи розріз на щілинну антену, яка збирає та випромінює гігантські завади.

Сучасний підхід до змішаного трасування полягає в збереженні **єдиного суцільного земляного полігону** (зазвичай на 2-му шарі 4-шарової плати) з жорстким **просторовим зонуванням**:

1. **Силова зона (Power Domain / PGND):** Конденсатори фільтра живлення шини (Bulk capacitors), керамічні блокувальні конденсатори, ключі півмостів, драйвери затворів та силові клеми двигуна розміщуються компактно в одному кутку плати.
2. **Аналогова зона (Analog Domain / AGND):** Давачі, вимірювальні операційні підсилювачі, джерело опорної напруги та аналогові виводи мікроконтролера розміщуються в протилежній частині плати.
3. **Шлях повернення струму (Return Path):** На частотах комутації понад 100 кГц зворотний струм у суцільній мідній площині тече строго під прямим провідником, повторюючи його траєкторію (шлях найменшої індуктивності). Оскільки силова частина розташована компактно, сильні імпульсні зворотні струми мотора циркулюють виключно всередині силової зони між транзисторами та конденсатором шини живлення, фізично не заходячи на територію аналогового полігону.

Якщо ж плата 2-шарова, використовується класичне **зіркове заземлення (Star Ground Topology)**. Центральною точкою зірки обирається мінусовий контакт основного електролітичного конденсатора живлення або шунта. Провідник аналогової землі підключається до цієї точки окремою тонкою доріжкою, по якій не тече жоден міліампер силового струму двигуна.

### Чотирипровідне підключення Кельвіна (Kelvin Sensing)

При вимірюванні струму мотора за допомогою низькоомного шунта (наприклад, `R_shunt = 5 мОм`) напруга при струмі 15 А становить лише `75 мВ`. Якщо підсилювач підключити до силових контактних майданчиків шунта тими самими доріжками, якими протікає струм двигуна, падіння напруги на паяному з'єднанні та перехідних отворах (зазвичай 1–3 мОм) створить похибку вимірювання до 40–60%.

Підключення Кельвіна вимагає прокладання окремої пари вимірювальних доріжок безпосередньо з внутрішньої поверхні контактних майданчиків резистора шунта:

- Силовий струм заходить на зовнішні краї контактних майданчиків шунта через широкі полігони.
- Вимірювальні доріжки виходять із центру внутрішньої зони контактних майданчиків шунта і прокладаються до диференційного підсилювача у вигляді тісно зв'язаної диференційної пари (з мінімальним зазором між ними).
- Оскільки вимірювальні доріжки навантажені лише на високий вхідний опір операційного підсилювача, струм у них практично дорівнює нулю, а падіння напруги на паразитному опорі провідників відсутнє. Тісне паралельне трасування зводить площу контуру `A_sense` до нуля, нівелюючи магнітну наводку `V_ind = -M · (di/dt)`.

## Фазово-синхронізована вибірка: як упіймати тихе вікно ШІМ

Навіть за бездоганної топології плати комутація транзисторів створює затухаючі високочастотні коливання — **комутаційний дзвін (Switching Ringing)**. Коли нижній або верхній MOSFET закривається, індуктивність розсіювання провідників у поєднанні з вихідною ємністю транзистора `C_oss` та паразитними ємностями обмоток утворює паразитний коливальний LC-контур. Частота цього дзвону лежить у діапазоні 30–100 МГц, а час його повного затухання становить від 200 до 800 нс.

### Чому асинхронне зчитування АЦП зазнає краху

Якщо АЦП працює в режимі вільного перетворення (англ. *free-running*) або запускається від незалежного періодичного таймера (наприклад, із частотою 1 кГц чи 10 кГц), момент фіксації напруги пристроєм вибірки-зберігання (англ. *Sample & Hold*) є випадковим відносно періоду ШІМ:

- Частина вибірок потрапляє в момент ідеального спокою між комутаціями, показуючи точне значення.
- Частина вибірок припадає строго на момент перемикання ключа, захоплюючи пік високочастотного дзвону амплітудою в кілька вольтів.
- Решта вибірок захоплює фазу наростання або спаду струму в індуктивності обмотки.

У результаті вихідний масив відліків АЦП перетворюється на хаотичний набір випадкових чисел із гігантською дисперсією. Просте усереднення таких даних не рятує: через несиметричність комутаційних викидів (викиди при вмиканні та вимиканні мають різну амплітуду й полярність) середнє значення зміщується на десятки мілівольтів.

![Синхронізація вибірки АЦП за центром імпульсу ШІМ](/root/course/embedded/shim-motor-i-atsp/img/pwm-adc-sync-timing.svg)
*Часова діаграма фазової синхронізації: запуск вибірки АЦП апаратним сигналом TRGO таймера на вершині симетричного рахунку строго в середині тихого вікна між комутаційними сплесками.*

### Центрований ШІМ та апаратний тригер TRGO

Єдиний надійний інженерний спосіб отримати точне вимірювання — прив'язати момент запуску АЦП до фази ШІМ так, щоб вибірка відбувалася **строго в момент максимального спокою системи (Quiet Window)**.

Для цього таймер мікроконтролера налаштовується в режим **симетричного (центрованого) ШІМ (Center-Aligned PWM / Up-Down Mode)**:

1. Лічильник таймера `CNT` рахує вгору від 0 до значення автоперезавантаження `ARR`, а потім рахує вниз від `ARR` до 0.
2. Імпульс ШІМ формується симетрично відносно вершини рахунку `ARR` або відносно нуля.
3. Комутація транзисторів відбувається двічі за період: коли лічильник збігається з регістром порівняння `CCR` під час руху вгору, і під час руху вниз.
4. **Тихе вікно №1 (Center of ON-time):** Знаходиться на самій вершині рахунку (`CNT = ARR`). У цей момент транзистори увімкнені вже тривалий час, усі комутаційні перехідні процеси повністю затухли, а струм через індуктивність мотора дорівнює своєму точному середньому значенню за період ШІМ.
5. **Тихе вікно №2 (Center of OFF-time):** Знаходиться в нижній точці рахунку (`CNT = 0`). У цей момент активні ключі вимкнені, струм замикається через діоди або нижні транзистори (вільне обертання, англ. *freewheeling*), а комутаційні шуми відсутні.

Мікроконтролер конфігурується так, щоб таймер генерував апаратний імпульс тригера **TRGO (Trigger Output)** в момент переповнення `ARR` (або за сигналом окремого каналу порівняння `CCR4`, зміщеного на середину тихої зони). АЦП налаштовується на апаратний запуск від цієї події (`ADC_EXTERNALTRIGCONV_Tx_TRGO`).

**Worked-приклад: Розрахунок мінімальної тривалості тихого вікна для коректної вибірки.**

```
Параметри системи:
   Частота ШІМ: f_pwm = 20 кГц (Період T_pwm = 50 мкс)
   Коефіцієнт заповнення ШІМ: D = 20% (Тривалість імпульсу t_on = 10 мкс)
   Тривалість мертвого часу: t_dead = 500 нс
   Тривалість комутаційного дзвону: t_ring = 800 нс
   Час заряду конденсатора вибірки АЦП: t_sample = 1.5 мкс

Крок 1. Розрахунок часу від комутаційного фронту до центру імпульсу:
   t_half_on = t_on / 2 = 10 мкс / 2 = 5.0 мкс

Крок 2. Розрахунок тривалості безпечного тихого вікна до початку вибірки:
   t_quiet = t_half_on - t_dead - t_ring
   t_quiet = 5.0 мкс - 0.5 мкс - 0.8 мкс = 3.7 мкс

Крок 3. Перевірка достатності часу для АЦП:
   Оскільки t_quiet (3.7 мкс) > t_sample (1.5 мкс), вибірка АЦП гарантовано
   відбувається в стаціонарному стані без завад.
```

## Цифрова фільтрація: чому звичайний IIR безсилий проти глітчів

Навіть за повної фазової синхронізації в реальній системі час від часу виникають поодинокі аномальні викиди (глітчі, англ. *glitches*). Їхньою причиною можуть бути різкі динамічні зміни коефіцієнта заповнення ШІМ контуром стабілізації, зворотне відновлення діодів (англ. *diode reverse recovery*), або випадкові іскріння щіткового вузла мотора.

![Робота цифрових фільтрів під дією комутаційних викидів](/root/course/embedded/shim-motor-i-atsp/img/glitch-filtering-median-iir.svg)
*Порівняння відгуку фільтрів на одиночний комутаційний викид: лінійний IIR розмазує помилку на десятки циклів, тоді як каскад Медіана+IIR повністю відсікає аномалію та зберігає стабільність сигналу.*

### Проблема лінійних фільтрів (IIR / EMA / Ковзне середнє)

Більшість інженерів намагається згладити шум за допомогою класичного лінійного експоненційного фільтра (фільтра нескінченної імпульсної характеристики, IIR першого порядку / Exponential Moving Average, EMA):

```
y[n] = α · x[n] + (1 - α) · y[n-1]
```

де `α` — коефіцієнт згладжування (`0 < α ≤ 1`).

Лінійний фільтр володіє фундаментальною вадою: він **не розрізняє природу шуму**. Якщо на вхід подати стабільний сигнал `1000 LSB`, і на одному відліку виникне поодинокий комутаційний глітч амплітудою `3000 LSB`, фільтр з `α = 0.1` виконає наступний розрахунок:

```
y[n] = 0.1 · 3000 + 0.9 · 1000 = 300 + 900 = 1200 LSB
```

Вихідний показ миттєво підскакує на 200 LSB. Що гірше, повернення до істинного значення `1000 LSB` відбуватиметься експоненційно і триватиме десятки періодів дискретизації:

```
y[n+1] = 0.1 · 1000 + 0.9 · 1200 = 1180 LSB
y[n+2] = 0.1 · 1000 + 0.9 · 1180 = 1162 LSB
...
y[n+20] ≈ 1024 LSB
```

Один короткий імпульс спотворює середнє значення на десятки мілісекунд, викликаючи фазову затримку та хибні спрацьовування пропорційно-інтегрально-диференціального (ПІД) регулятора.

### Медіанний фільтр: математичне видалення імпульсного шуму

Медіанний фільтр (лат. *medianus* — середній) — це нелінійний цифровий фільтр, який сортує вікно з `N` останніх послідовних відліків (де `N` — непарне число, зазвичай 3 або 5) і обирає центральний елемент впорядкованого ряду.

Математична властивість медіанного фільтра полягає в тому, що він **повністю пригнічує будь-які поодинокі імпульси**, тривалість яких менша за половину ширини вікна `(N - 1) / 2`, не вносячи абсолютно жодної зміни в плавні перепади корисного сигналу і не розмиваючи круті фронти.

Для вікна розміром `N = 3` над вибірками `[x[n-2], x[n-1], x[n]]`:
- Якщо вибірки мають значення `[1002, 3000, 1005]` (глітч `3000`), після сортування отримуємо `[1002, 1005, 3000]`.
- Медіана дорівнює `1005 LSB`. Аномальний викид амплітудою 3000 знищується повністю за нульову кількість наступних кроків.

### Двокаскадний фільтрувальний тракт (Median + EMA)

Оптимальна архітектура цифрової обробки сигналів для вимірювань під ШІМ будується у вигляді каскаду з двох послідовних блоків:

1. **Каскад 1 (Швидка медіана N=3 або N=5):** Відсікає комутаційні викиди, глітчі та аномальні стрибки напруги.
2. **Каскад 2 (Експоненційний IIR з α = 0.05...0.2):** Згладжує залишковий нормальний (гауссів) тепловий шум АЦП та квантування.

Такий каскад забезпечує бездоганну гладкість сигналу, миттєве відновлення після імпульсних наводок і мінімальну фазову затримку для контуру керування.

## Програмно-апаратний драйвер синхронного вимірювання

Розглянемо практичну реалізацію драйвера синхронного зчитування АЦП під ШІМ для мікроконтролерів сімейства STM32 (або еквівалентних ARM Cortex-M з таймерами з розширеним функціоналом).

Архітектура драйвера:
- **Таймер TIM1:** Працює в режимі центрованого ШІМ (`TIM_COUNTERMODE_CENTERALIGNED1`), генеруючи симетричні імпульси на каналах `CH1/CH2/CH3` для керування транзисторами мотора. Подія оновлення (Update Event) на вершині рахунку формує вихідний апаратний сигнал `TRGO`.
- **АЦП ADC1:** Працює в режимі зовнішнього тригера від `TIM1_TRGO`, опитуючи вимірювальні канали (струм, напруга, температура) за допомогою DMA в кільцевий буфер.
- **Обробник потоку:** Обчислює медіану 3-го порядку за допомогою швидкого безрозгалуженого порівняння та передає значення в експоненційний фільтр з фіксованою комою.

> 🔧 **Навіщо це.**
> У сервоприводах, тягових інверторах електротранспорту та польотних контролерах дронів вимірювання фазного струму за допомогою нижніх шунтів можливе **виключно** тоді, коли нижні транзистори відкриті. Фазова синхронізація через TRGO гарантує, що АЦП зчитує сигнал строго всередині дозволеного інтервалу провідності ключів, усуваючи необхідність у дорогих гальванічно ізольованих давачах Холла.

Нижче наведено повну реалізацію програмно-апаратного драйвера мовами C та ідіоматичною C++.

```c
#include <stdint.h>
#include <stdbool.h>

#define ADC_CHANNELS_COUNT 3
#define MEDIAN_WINDOW_SIZE 3
#define EMA_ALPHA_FP_SHIFT 8  /* Фіксована кома: масштаб 256 */
#define EMA_ALPHA_FP       38 /* alpha = 38 / 256 ≈ 0.15 */

/* Структура конфігурації фільтра для одного каналу */
typedef struct {
    uint16_t history[MEDIAN_WINDOW_SIZE];
    uint8_t  history_idx;
    uint32_t ema_accumulator; /* Накопичувач з фіксованою комою Q24.8 */
    bool     initialized;
} AdcChannelFilter;

/* Стан синхронізованого драйвера */
typedef struct {
    volatile uint16_t dma_raw_buffer[ADC_CHANNELS_COUNT];
    AdcChannelFilter  filters[ADC_CHANNELS_COUNT];
    uint16_t          filtered_values[ADC_CHANNELS_COUNT];
} SynchronizedAdcDriver;

/* Швидкий пошук медіани 3 чисел без розгалужень на масивах */
static inline uint16_t median_of_three(uint16_t a, uint16_t b, uint16_t c) {
    if (a > b) {
        if (b > c) return b;
        if (a > c) return c;
        return a;
    } else {
        if (a > c) return a;
        if (b > c) return c;
        return b;
    }
}

/* Ініціалізація структур фільтрації */
void adc_driver_init(SynchronizedAdcDriver *driver) {
    for (uint32_t ch = 0; ch < ADC_CHANNELS_COUNT; ++ch) {
        driver->dma_raw_buffer[ch] = 0;
        driver->filtered_values[ch] = 0;
        driver->filters[ch].history_idx = 0;
        driver->filters[ch].ema_accumulator = 0;
        driver->filters[ch].initialized = false;
        for (uint32_t i = 0; i < MEDIAN_WINDOW_SIZE; ++i) {
            driver->filters[ch].history[i] = 0;
        }
    }
}

/* Обробка нових відліків АЦП (викликається в DMA-перериванні або циклі) */
void adc_driver_process_sample(SynchronizedAdcDriver *driver) {
    for (uint32_t ch = 0; ch < ADC_CHANNELS_COUNT; ++ch) {
        uint16_t raw_sample = driver->dma_raw_buffer[ch];
        AdcChannelFilter *f = &driver->filters[ch];

        /* Оновлення кільцевого буфера історії */
        f->history[f->history_idx] = raw_sample;
        f->history_idx = (f->history_idx + 1) % MEDIAN_WINDOW_SIZE;

        /* Каскад 1: 3-точковий медіанний фільтр */
        uint16_t median_val = median_of_three(f->history[0], f->history[1], f->history[2]);

        /* Каскад 2: Експоненційний IIR-фільтр з фіксованою комою */
        if (!f->initialized) {
            f->ema_accumulator = ((uint32_t)median_val) << EMA_ALPHA_FP_SHIFT;
            f->initialized = true;
        } else {
            /* EMA: acc = acc + alpha * (median - acc) */
            int32_t current_val_fp = ((int32_t)median_val) << EMA_ALPHA_FP_SHIFT;
            int32_t diff = current_val_fp - (int32_t)f->ema_accumulator;
            f->ema_accumulator += (diff * EMA_ALPHA_FP) >> EMA_ALPHA_FP_SHIFT;
        }

        /* Вихідне згладжене значення */
        driver->filtered_values[ch] = (uint16_t)(f->ema_accumulator >> EMA_ALPHA_FP_SHIFT);
    }
}

/* Отримання очищеного результату вимірювання каналу */
uint16_t adc_driver_get_channel_value(const SynchronizedAdcDriver *driver, uint32_t channel) {
    if (channel >= ADC_CHANNELS_COUNT) {
        return 0;
    }
    return driver->filtered_values[channel];
}
```
```cpp
#include <array>
#include <concepts>
#include <cstdint>
#include <span>

template <std::size_t ChannelsCount, std::size_t MedianWindow = 3>
class SynchronizedAdcSampler {
    static_assert(MedianWindow == 3, "Дана реалізація оптимізована під 3-точкове вікно медіани");

public:
    static constexpr std::uint32_t AlphaFpShift = 8;
    static constexpr std::uint32_t AlphaFp = 38; // alpha = 38 / 256 ≈ 0.15

    struct alignas(4) DmaRawBuffer {
        std::array<std::uint16_t, ChannelsCount> data{};
    };

    SynchronizedAdcSampler() noexcept {
        reset();
    }

    void reset() noexcept {
        raw_dma_buffer_.data.fill(0);
        filtered_values_.fill(0);
        for (auto& filter : channel_filters_) {
            filter.history.fill(0);
            filter.history_idx = 0;
            filter.ema_accumulator = 0;
            filter.initialized = false;
        }
    }

    // Доступ до сирого буфера для прив'язки дескриптора DMA
    [[nodiscard]] std::uint16_t* raw_buffer_ptr() noexcept {
        return raw_dma_buffer_.data.data();
    }

    [[nodiscard]] constexpr std::size_t raw_buffer_size() const noexcept {
        return ChannelsCount;
    }

    // Обробка пакету вибірок після завершення транзакції DMA
    void process_samples() noexcept {
        for (std::size_t ch = 0; ch < ChannelsCount; ++ch) {
            const std::uint16_t raw_sample = raw_dma_buffer_.data[ch];
            auto& f = channel_filters_[ch];

            f.history[f.history_idx] = raw_sample;
            f.history_idx = (f.history_idx + 1) % MedianWindow;

            // Каскад 1: Швидкий 3-точковий медіанний фільтр
            const std::uint16_t median_val = compute_median3(f.history[0], f.history[1], f.history[2]);

            // Каскад 2: IIR згладжування з цілочисельною математикою
            if (!f.initialized) {
                f.ema_accumulator = static_cast<std::uint32_t>(median_val) << AlphaFpShift;
                f.initialized = true;
            } else {
                const auto current_val_fp = static_cast<std::int32_t>(median_val) << AlphaFpShift;
                const auto diff = current_val_fp - static_cast<std::int32_t>(f.ema_accumulator);
                f.ema_accumulator += static_cast<std::uint32_t>((diff * static_cast<std::int32_t>(AlphaFp)) >> AlphaFpShift);
            }

            filtered_values_[ch] = static_cast<std::uint16_t>(f.ema_accumulator >> AlphaFpShift);
        }
    }

    [[nodiscard]] std::uint16_t get_channel_value(std::size_t channel) const noexcept {
        if (channel < ChannelsCount) {
            return filtered_values_[channel];
        }
        return 0;
    }

    [[nodiscard]] std::span<const std::uint16_t, ChannelsCount> get_all_channels() const noexcept {
        return std::span<const std::uint16_t, ChannelsCount>(filtered_values_);
    }

private:
    struct FilterState {
        std::array<std::uint16_t, MedianWindow> history{};
        std::size_t history_idx{0};
        std::uint32_t ema_accumulator{0};
        bool initialized{false};
    };

    static constexpr std::uint16_t compute_median3(std::uint16_t a, std::uint16_t b, std::uint16_t c) noexcept {
        if (a > b) {
            if (b > c) return b;
            if (a > c) return c;
            return a;
        } else {
            if (a > c) return a;
            if (b > c) return c;
            return b;
        }
    }

    DmaRawBuffer raw_dma_buffer_{};
    std::array<FilterState, ChannelsCount> channel_filters_{};
    std::array<std::uint16_t, ChannelsCount> filtered_values_{};
};
```

## Підсумок: чекліст стабільного вимірювання під навантаженням

Коли аналогові покази мікроконтролера починають стрибати під час відкриття дроселя ШІМ, лікування проблеми вимагає системної координації заліза та коду:

1. **Топологія:** Суцільний земляний полігон із просторовим відокремленням силової зони від аналогової. Силовий поворотний струм мотора замикається на конденсатор живлення шини, не протікаючи під лініями АЦП.
2. **Кельвін:** Підключення вимірювальних шунтів строго диференційною парою з внутрішньої зони контактних майданчиків резистора безпосередньо до диференційного підсилювача.
3. **Синхронізація:** Переведення ШІМ-таймера в симетричний режим (Center-Aligned) та запуск вибірки АЦП апаратним сигналом `TRGO` строго посередині імпульсу провідності транзисторів (у центрі тихого вікна).
4. **Фільтрація:** Відмова від одиночного лінійного усереднення на користь каскаду «3-точкова медіана + експоненційний фільтр IIR», що забезпечує повне відсікання одиночних комутаційних викидів без зміщення постійної складової сигналу.
