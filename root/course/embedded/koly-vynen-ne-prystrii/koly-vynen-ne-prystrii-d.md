# Коли винен не пристрій

<preknowlist>
- [Захисне заземлення](root:hw-power/protective-grounding) — вирівнювання потенціалів корпусів та захист від наведеної фазної напруги.
- [Земляні петлі](root:hw-pcb/ground-loops) — виникнення паразитних струмів через різницю потенціалів між точками заземлення.
- [Гальванічна розв'язка](root:hw-components/galvanic-isolation) — розрив електричного контакту для захисту низьковольтних кіл від високої синфазної напруги.
- [Диференційні пари](root:com-medium/differential-pair) — передача сигналів протифазними лініями для пригнічення синфазного шуму.
- [Комутаційні перехідні процеси](root:hw-components/switching-transients) — високовольтні сплески напруги під час розмикання індуктивних навантажень.
</preknowlist>

Контролер автоматизації бездоганно проходить лабораторні випробування: на інженерному столі від стабілізованого лабораторного джерела живлення з короткими джгутами по 20 см прошивка працює тижнями без жодного збою. Але варто змонтувати той самий модуль у металеву шафу керування на реальному об'єкті, під'єднати 100-метровий кабель шини до віддалених датчиків або частотних перетворювачів — і починається незрозуміле. Трансивери інтерфейсів вигорають під час увімкнення верстата, мікроконтролер хаотично скидається через апаратний Watchdog, а пакети даних спотворюються лавиною помилок контрольної суми CRC.

Розробник перевіряє тактування шин, переписує таймери обміну або замовляє нову ревізію плати з товстішими полігонами живлення. Проте заміна мікросхем чи оптимізація алгоритмів нічого не змінює: прилад знову виходить з ладу. Причина криється не у помилках розробки плати і не в алгоритмах мікроконтролера — відмову диктує фізичне середовище промислової інфраструктури. Непідключене захисне заземлення, вирівнювальні струми по екранах кабелів, кіловольтні індуктивні сплески від пускачів та перекоси потенціалів ґрунту перетворюють лінію зв'язку на провідник руйнівної енергії.

## Промислові завади та руйнівний потенціал польової інфраструктури

Лабораторне середовище ізолює електронний пристрій від реальності силових електромереж. На робочому столі всі вузли живляться від спільного подовжувача або гальванічно розв'язаних трансформаторних джерел. Різниця потенціалів між «землею» плати та «землею» комп'ютера розробника становить частки мілівольта, а мала довжина ліній виключає антенний ефект.

У промисловому цеху або на польовому розподільчому вузлі топологія живлення зовсім інша. Силові кабелі живлення асинхронних двигунів потужністю в десятки кіловат прокладаються в одних кабельних лотках поруч зі слабкострумовими вимірювальними трасами. Частотні перетворювачі (англ. *Variable Frequency Drive*, VFD) комутують напругу 400 В трифазного мосту за допомогою IGBT-транзисторів із частотою широтно-імпульсної модуляції від 2 до 16 кГц. Швидкість наростання фронту комутації досягає величезних значень:

```
dV/dt = 500 В / 50 нс
= 10 кВ/мкс                           [швидкість зміни напруги IGBT-модуля]
```

Через паразитну ємність між жилами кабелю (навіть якщо вона становить лише 10–20 пФ на метр) такий крутий фронт напруги інжектує струмовий імпульс безпосередньо у сусідній сигнальний провід:

```
I_couple = C_parasitic · (dV/dt)
= (20·10⁻¹² Ф) · (10·10⁹ В/с)        [ємнісне наведення струму завади]
= 0.2 А                               [200 мА струму у сигнальне коло]
```

Струм величиною 200 мА, що потрапляє у високоомний вхід аналогово-цифрового перетворювача (АЦП) або на чутливу сигнальну ніжку мікроконтролера, здатний миттєво підняти потенціал виводу вище напруги живлення, відкрити захисні внутрішні діоди кристала та спричинити тиристорне замикання (англ. *latch-up*).

Усі зовнішні впливи інфраструктури поділяються на три фізичні механізми зв'язку:
1. **Ємнісний зв'язок (електричне поле `E`):** передача швидких перепадів напруги `dV/dt` через паразитні ємності між паралельно прокладеними проводами або між платою та корпусом шафи.
2. **Індуктивний зв'язок (магнітне поле `H`):** генерація електрорушійної сили в сигнальних проводах через взаємну індуктивність `M` під час протікання великих змінних струмів `dI/dt` у силових кабелях.
3. **Гальванічний (кондуктивний) зв'язок через спільний опір:** протікання струмів навантаження через ненульовий опір спільних провідників заземлення та нейтралі, що безпосередньо зміщує опорні рівні сигналів.

Також фундаментально розрізняють два типи напруг на клемах приладу:
- **Диференційна напруга (англ. *differential-mode voltage*)** — різниця потенціалів безпосередньо між двома сигнальними провідниками однієї пари (наприклад, між лініями `A` та `B` інтерфейсу RS-485 або `CAN_H` та `CAN_L`). Це корисний сигнал передачі даних або вимірювання, до якого додається диференційний шум.
- **Синфазна напруга (англ. *common-mode voltage*)** — середній електричний потенціал обох сигнальних провідників відносно локальної землі пристрою `GND` (`V_CM = (V_A + V_B)/2`). Якщо на обох лініях `A` і `B` одночасно виникає потенціал +35 В відносно землі приймача, диференційна напруга `V_diff = V_A - V_B` може залишатися правильною (наприклад, 2.0 В), але синфазний зсув змусить вхідний диференційний каскад приймача вийти в режим глибокого насичення.

Коли прилад зазнає регулярних збоїв у полі, першим кроком має бути не перепаювання компонентів, а фізичний аудит кабельних трас, топології заземлення та наявності захисних бар'єрів.

## Відсутність заземлення, вирівнювальні струми та плаваючий нуль

Найпоширеніша причина виходу з ладу польової електроніки — ілюзія того, що клема заземлення потрібна лише для електробезпеки персоналу. В імпульсних блоках живлення (англ. *Switched-Mode Power Supply*, SMPS) вона є невіддільною частиною фільтра електромагнітної сумісності (англ. *Electromagnetic Interference*, EMI).

На вході будь-якого промислового джерела живлення встановлено фільтр придушення завад. Він містить дросель спільного синфазного струму, X-конденсатори між фазою `L` та нейтраллю `N`, а також два Y-конденсатори (`C_Y1` та `C_Y2`), увімкнені між кожним силовим проводом мережі та металевим корпусом шафи (клемою `PE`, *Protective Earth*).

![Ємнісний дільник Y-конденсаторів та вирівнювальний струм](/root/course/embedded/koly-vynen-ne-prystrii/img/floating-ground-y-capacitors.svg)
*Ємнісний дільник Y-конденсаторів мережевого фільтра БЖ: відсутність PE виносить 115 В змінного струму на корпус, породжуючи вирівнювальний струм крізь сигнальну землю кабелю.*

Y-конденсатори утворюють класичний ємнісний дільник мережевої напруги 230 В:

```
V_chassis = V_mains · (C_Y1 / (C_Y1 + C_Y2))
= 230 В · (2.2 нФ / (2.2 нФ + 2.2 нФ)) [дільник з однакових ємностей]
= 115 В                               [RMS потенціал незаземленого корпусу]
```

Якщо захисний провідник `PE` фізично підключений до контуру заземлення будівлі з опором < 4 Ом, цей потенціал надійно стікає в землю. Але якщо заземлення обірване, розетка двопровідна або монтажники тимчасово під'єднали щит через двожильний подовжувач, металевий корпус шафи та електрична земля `GND` всієї низьковольтної плати опиняються під змінним потенціалом 115 В RMS (пікове значення досягає ±162 В) відносно реальної фізичної Землі.

Струм витоку через один конденсатор ємністю 2.2 нФ на частоті 50 Гц розраховується за законом Ома для змінного струму:

```
X_C = 1 / (2·π·f·C_Y)
= 1 / (2 · 3.14159 · 50 · 2.2·10⁻⁹)   [реактивний опір Y-конденсатора]
≈ 1.447 МОм                            [опір конденсатора на 50 Гц]

I_leak = 115 В / X_C
= 115 / 1.447·10⁶                      [струм витоку на незаземлений корпус]
≈ 0.08 мА                              [струм одного джерела живлення]
```

Якщо в шафі встановлено п'ять таких блоків живлення, сумарний струм витоку на незаземлений корпус сягає майже 0.5 мА. Для людини дотик до такого корпусу відчувається як легке пощипування. Проте для напівпровідникових мікросхем наслідки катастрофічні.

Уявімо типовий монтажний сценарій: налагоджувальник під'єднує сигнальний кабель (наприклад, USB, RS-485 або Ethernet з екранованим роз'ємом RJ-45), який іде від надійно заземленого сервера чи ПК, до незаземленої шафи приладу. У момент торкання роз'єму першим контактує не заземлений екран, а сигнальна лінія. Накопичений заряд ємностей `C_Y` миттєво розряджається в кремнієвий кристал трансивера. Виникає імпульс струму з крутизною наростання в десятки амперів на мікросекунду, який випалює вхідні структури мікросхеми.

Якщо з'єднання відбулося без миттєвого пробою, через сигнальний провідник `GND` або екран кабелю починає безперервно протікати вирівнювальний струм промислової частоти 50 Гц. Падіння напруги на опорі сигнальної жили зміщує логічні пороги, породжуючи періодичні збої кадрування (англ. *framing errors*) та CRC-помилки під час кожного напівперіоду мережевої напруги.

Окрему загрозу в трифазних промислових мережах становить **перекіс фаз та плаваючий нуль (обрив нейтралі `N`)**. У системах розподілу електроенергії споживачі 230 В підключаються між однією з фаз (`L1`, `L2`, `L3`) та нейтральним провідником `N`. Якщо нульовий провідник відгорає або розмикається на ввідному щиті, потенціал точки нейтралі починає «плавати» залежно від співвідношення опорів навантажень на різних фазах.

```
V_phase_max = V_line · √( (R_B² + R_B·R_C + R_C²) / (R_A·R_B + R_B·R_C + R_C·R_A) )
```

Коли до фази `L1` підключено потужні промислові ТЕНи (низький опір), а до фази `L2` — лише слабкострумова шафа автоматики (високий опір), напруга на вході блоку живлення автоматики миттєво підскакує з 230 В до 380–400 В. Вхідні захисні варистори блоку живлення перегріваються, закорочують мережу і вибухають, нерідко випалюючи внутрішні доріжки плати.

В промислових електромережах застосовують різні системи заземлення за стандартом IEC 60364:
- **TN-S:** нейтраль `N` та захисне заземлення `PE` розділені по всій довжині від підстанції. Найбезпечніша система для електроніки, де струми навантаження ніколи не течуть по провіднику `PE`.
- **TN-C:** функції `N` та `PE` об'єднані в одному проводі `PEN`. Категорично небезпечна система для ліній зв'язку: будь-який робочий струм верстатів створює падіння напруги на проводі `PEN`, автоматично перетворюючи його на синфазну заваду для всіх підключених плат.
- **TN-C-S:** розділення `PEN` на `PE` та `N` відбувається на вводі в будівлю. Вимагає суворого повторного заземлення точки розділення.
- **IT:** нейтраль генератора або трансформатора повністю ізольована від землі або заземлена через великий опір. Застосовується в шахтах, лікарнях і на безперервних хімічних виробництвах. Якщо в мережі IT виникає замикання однієї з фаз на землю, обладнання продовжує працювати, але потенціал землі відносно двох інших фаз підскакує до повної лінійної напруги 400 В. Прилади, розраховані на стандартну ізоляцію 250 В відносно землі, миттєво зазнають електричного пробою.

## Земляні петлі та спотворення сигналів на довгих кабельних трасах

Коли лінія зв'язку з'єднує два прилади, розташовані на відстані понад 50–100 метрів (у різних цехах або різних кінцях одного виробничого корпусу), поняття «єдиної землі» перестає існувати.

Кожна будівля або технологічна установка має свій локальний контур заземлення. Між цими точками в ґрунті постійно протікають зворотні струми важкого електрообладнання, зварювальних апаратів, тягових підстанцій та струми витоку силових трансформаторів. Внаслідок закону Ома на опорі ґрунту `R_earth` виникає постійна або змінна **різниця потенціалів заземлення**:

```
ΔV_GND = V_Earth1 - V_Earth2
```

У промислових умовах `ΔV_GND` між сусідніми цехами зазвичай становить від 3 до 15 В, а під час пуску потужних двигунів або коротких замикань на підстанції може досягати 50–100 В.

![Земляна петля та синфазна напруга](/root/course/embedded/koly-vynen-ne-prystrii/img/ground-loop-common-mode.svg)
*Земляна петля між віддаленими вузлами: різниця потенціалів ґрунту та магнітна індукція створюють синфазну напругу, що перевищує допустимий діапазон приймача.*

Якщо екран або сигнальний провідник `GND` кабелю з'єднати із землею на **обох** кінцях лінії, утворюється замкнений контур величезної площі `S`:
`Вузол 1 (GND1) → Кабель (сигнальна земля) → Вузол 2 (GND2) → Контур заземлення 2 → Ґрунт → Контур заземлення 1`.

Цей замкнений контур (земляна петля, англ. *ground loop*) спричиняє дві руйнівні проблеми:
1. **Вирівнювальний струм петлі:** Різниця потенціалів `ΔV_GND` змушує струм величиною від кількох амперів до десятків амперів текти по тонкому екрану кабелю зв'язку. Опір жили кабелю перетворює цей струм на теплове перегрівання: екран плавить ізоляцію, а доріжки `GND` на друкованих платах обох приладів перегорають, як плавкі запобіжники.
2. **Електромагнітна індукція:** Контур площею в сотні квадратних метрів працює як гігантська рамкова антена. Змінне магнітне поле від сусідніх силових шин із густиною магнітного потоку `B(t)` пронизує площу петлі `S`. За законом електромагнітної індукції Фарадея в петлі наводиться електрорушійна сила (ЕРС):

```
V_ind = -dΦ/dt = -S · (dB/dt)
```

Ця наведена напруга додається безпосередньо до синфазної напруги на входах трансиверів.

Розглянемо стандартний трансивер інтерфейсу RS-485 (наприклад, MAX485 або SN65HVD3082). За стандартом TIA/EIA-485 діапазон синфазної напруги на лініях `A` і `B` відносно локального `GND` мікросхеми обмежений діапазоном:

```
V_CM_allowed = -7 В ... +12 В
```

Якщо внаслідок перекосу потенціалів `ΔV_GND = +18 В` синфазна напруга виходить за межу +12 В, відбуваються такі процеси:
- Вхідні біполярні або польові транзистори диференційного каскаду входять у насичення. Коефіцієнт придушення синфазного сигналу (англ. *Common-Mode Rejection Ratio*, CMRR) падає майже до нуля.
- Приймач перестає розрізняти корисну диференційну напругу 200 мВ між `A` і `B`. На виході `RO` з'являються фіктивні логічні нулі або одиниці, які сприймаються контролером як помилки кадру.
- Якщо `V_CM` перевищує абсолютний максимальний рейтинг мікросхеми (зазвичай -9 В ... +14 В), відкриваються паразитно сформовані PN-переходи кристала. Струм, що через них тече, руйнує металізацію виводів мікросхеми.

Додатково на довгих лініях (понад 100 м) суттєвий вплив мають **розподілені параметри кабелю**:
- Погонний активний опір петлі: `R_loop ≈ 0.1–0.2 Ом/м`. На довжині 500 м опір сягає 100 Ом, викликаючи падіння амплітуди диференційного сигналу.
- Погонна ємність пари: `C_line ≈ 50 пФ/м`. На 500 м сумарна ємність становить 25 нФ, що разом із вихідним опором передавача утворює фільтр низьких частот, який завалює крутизну фронтів і обмежує швидкість передачі даних.
- Хвильовий опір кабелю: вита пара категорії Cat5e або спеціалізований кабель для RS-485 (наприклад, Belden 9841) має хвильовий опір `Z_0 = 120 Ом`. Якщо на обох кінцях лінії відсутні узгоджувальні термінатори 120 Ом, електромагнітна хвиля відбивається від відкритих кінців.

Коефіцієнт відбиття електромагнітної хвилі від кінця лінії розраховується через хвильовий опір `Z_0` та опір навантаження `Z_L`:

```
Γ = (Z_L - Z_0) / (Z_L + Z_0)
```

Якщо лінія розімкнена (`Z_L → ∞`), коефіцієнт `Γ = +1`: хвиля повністю відбивається у тій самій фазі, подвоюючи амплітуду напруги на кінці лінії та створюючи фальшиві повторні фронти. Якщо лінія навантажена на резистор 120 Ом (`Z_L = 120 Ом`), коефіцієнт `Γ = 0`: відбиття повністю зникає, а сигнал поглинається без спотворень.

Для шини CAN (англ. *Controller Area Network*) окрім стандартної термінації застосовують **розщеплену термінацію (англ. *split termination*)**: замість одного резистора 120 Ом ставлять два послідовні резистори по 60 Ом, а їхню середню точку з'єднують із землею через конденсатор ємністю 4.7 нФ. Це створює низький імпеданс для високочастотного синфазного шуму, стабілізуючи рецесивний рівень шини 2.5 В і значно покращуючи електромагнітну емісію.

## Гальванічна розв'язка та каскадний захист від перенапруг

Єдиний надійний спосіб розірвати земляну петлю та убезпечити мікроконтролер від руйнівних перекосів потенціалів — **повна гальванічна розв'язка інтерфейсу**.

Гальванічна розв'язка вимагає розділення двох середовищ:
1. Сигнальних ліній (Rx, Tx, Enable керування драйвером).
2. Ліній живлення вузла інтерфейсу.

Якщо розв'язати цифрові сигнали оптично чи ємнісно, але живити польовий трансивер від спільної шини +5 В мікроконтролера, захист не працюватиме, оскільки земля `GND` залишиться спільною. Тому гальванічно ізольований вузол завжди містить мініатюрний ізольований перетворювач напруги DC-DC (наприклад, з напругою пробою бар'єра 3000–5000 В RMS).

| Тип ізолятора | Фізичний принцип | Макс. швидкість | Стійкість CMTI | Деградація з часом |
|---|---|---|---|---|
| **Оптопара (Optocoupler)** | Випромінювання світлодіода (GaAs/AlGaAs) → фототранзистор | 1–10 Мбіт/с | 15–25 кВ/мкс | Так (зниження коефіцієнта передачі CTR на 20–50% за 5 років) |
| **Ємнісний (Capacitive)** | Диференційні мікроконденсатори з діелектриком SiO2 (діоксид кремнію) | 150–200 Мбіт/с | > 100–150 кВ/мкс | Немає (стабільність характеристик понад 25 років) |
| **Магнітний (Magnetic/iCoupler)** | Мікротрансформатори на поліімідній підкладці | 100–150 Мбіт/с | 50–100 кВ/мкс | Вкрай низька |

Критичним параметром для цифрових ізоляторів у зашумленому промисловому середовищі є **CMTI (англ. *Common-Mode Transient Immunity*, стійкість до швидкості наростання синфазної напруги)**, що вимірюється в кВ/мкс. Якщо поруч комутується потужний силовий контактор і синфазна напруга між польовою землею `ISO_GND` та землею контролера `MCU_GND` стрибає зі швидкістю 30 кВ/мкс, ізолятор із низьким CMTI (наприклад, 15 кВ/мкс) через ємність бар'єра інжектує паразитний струм у приймальний підсилювач і генерує фальшивий імпульс на вході UART мікроконтролера. Сучасні ємнісні ізолятори (наприклад, родини ISO77xx від Texas Instruments або Si86xx від Silicon Labs) мають CMTI понад 100–150 кВ/мкс, що повністю усуває цю проблему.

Важливу роль відіграє також правильне проєктування топології друкованої плати навколо бар'єра ізоляції. Стандарти безпеки (IEC 60950-1, IEC 62368-1) оперують двома геометричними величинами:
- **Зазор у повітрі (англ. *clearance*):** найкоротша відстань між провідниками високої та низької напруги по прямій крізь повітря. Захищає від іскрового пробою газу. Для напруги 2.5 кВ пік зазор має бути не менше 3.2–4.0 мм.
- **Шлях струму витоку по поверхні (англ. *creepage*):** найкоротша відстань між провідниками вздовж поверхні текстоліту. Захищає від утворення електропровідних вуглецевих доріжок під впливом вологи та промислового пилу. Для посиленої ізоляції (англ. *reinforced isolation*) вимагається creepage не менше 6.3–8.0 мм. Щоб забезпечити необхідний creepage під компактними корпусами SOIC-8 або SOIC-16, у платі під ізолятором фрезерують наскрізний паз (англ. *air slot*) завширшки 1.5–2.0 мм.

Але ізолятор захищає лише логічну частину мікроконтролера від високої напруги на шині. Сам польовий трансивер залишається віч-на-віч із кабелем, у якому під час комутації індуктивних навантажень або грозових розрядів виникають кіловольтні сплески (англ. *surges* та *bursts/EFT* за стандартом IEC 61000-4-5 / IEC 61000-4-4).

Комутація обмоток реле, електромагнітних клапанів чи двигунів без захисних діодів породжує імпульс самоіндукції:

```
V_spike = -L · (di/dt)
```

При розмиканні контактів пускача струм 10 А переривається за 10 наносекунд. На індуктивності кабелю чи котушки всього 100 мкГн виникає сплеск:

```
V_spike = (100·10⁻⁶ Гн) · (10 А / 10·10⁻⁹ с)
= 100 000 В                          [100 кВ теоретичний пік без обмеження]
```

Цей імпульс пробиває повітряний зазор у контактах пускача, утворюючи іскрову дугу, і випромінює в кабельні траси пачку наносекундних перешкод (EFT, *Electrical Fast Transients*).

Для захисту польового каскаду застосовують **трирівневий каскадний захист**:

![Багаторівневий каскадний захист](/root/course/embedded/koly-vynen-ne-prystrii/img/surge-protection-cascade-stages.svg)
*Багаторівневий каскадний захист інтерфейсної лінії: грубий первинний розрядник GDT скидає струм у PE, координаційний резистор PTC узгоджує затримки, а швидкодійний TVS фіксує залишкову напругу.*

Каскад працює за чіткою ієрархією швидкості та енергоємності:
1. **Ступінь 1 (Грубий захист великої енергії):** Газорозрядник (англ. *Gas Discharge Tube*, GDT) або потужний варистор MOV між сигнальними лініями та захисним заземленням `PE`. GDT здатний безпечно пропустити через себе струм імпульсу блискавки до 10–20 кА (форма хвилі 8/20 мкс). Проте GDT відносно повільний: час запалювання плазмового шнура становить від 0.1 до 1 мкс, а динамічна напруга пробою може досягати 400–600 В. Окрім того, GDT має ефект супроводжуючого струму дуги (англ. *power follow current*): якщо розрядник підключено до лінії з постійною напругою, плазмова дуга не згасає після завершення імпульсу завади, тому в ланцюгах живлення GDT завжди ставлять послідовно з варистором.
2. **Елемент узгодження (Координація каскадів):** Послідовно у кожну лінію вмикається самовідновний полімерний запобіжник PTC (англ. *Positive Temperature Coefficient*, наприклад PolySwitch на 10–20 Ом) або імпульсний дросель/безіндуктивний керамічний резистор. Його завдання — створити падіння напруги `ΔV = I · R + L · (di/dt)` під час протікання фронту перенапруги. Без цього резистора швидкодійний діод TVS відкриється першим, візьме на себе всю енергію сплеску і миттєво згорить до того, як встигне запалитися потужний розрядник GDT.
3. **Ступінь 2 (Тонке швидкодіюче обмеження):** Двонаправлений TVS-діод (англ. *Transient Voltage Suppressor*, супресор), встановлений безпосередньо біля виводів трансивера паралельно лініям `A` і `B` відносно `ISO_GND`. TVS-діод має субнаносекундний час реакції (< 1 пс) і жорстко обмежує напругу на рівні `V_clamp ≈ ±15 В`, скидаючи залишковий струм у локальну землю ізольованого вузла.

## Програмно-апаратний модуль моніторингу синфазних перешкод та контролю лінії

Надійний пристрій не повинен бути «сліпим» до стану зовнішньої лінії зв'язку. Якщо на кабелі наростає синфазна завада, виникають періодичні високовольтні імпульси або погіршується опір ізоляції на землю, мікроконтролер має своєчасно виявити аномалію, зафіксувати її у журналі діагностики, попередити оператора та, за потреби, програмно відключити приймач або ізолювати шину до прибуття сервісної бригади.

![Апаратна топологія моніторингу синфазного шуму та опору ізоляції](/root/course/embedded/koly-vynen-ne-prystrii/img/insulation-and-cm-monitor-circuit.svg)
*Апаратна топологія моніторингу лінії: виділення синфазної напруги дільником, зсув рівня на АЦП та керована інжекція тестового струму для перевірки опору ізоляції.*

Апаратна частина діагностичного модуля складається з:
- Високоомного симетричного резистивного дільника (два резистори по 1 МОм, під'єднані до ліній `A` і `B`), середня точка якого виділяє чисту синфазну напругу:

```
V_CM = (V_A + V_B) / 2
```

- Схеми масштабування та зсуву рівня на операційному підсилювачі (англ. *Level Shifter*), яка перетворює двополярний діапазон напруги `V_CM` від -15 В до +15 В в уніполярний діапазон АЦП мікроконтролера 0...3.3 В із віртуальною нульовою точкою `V_ref / 2 = 1.65 В`.
- Каналу контролю опору ізоляції: через високовольтний оптоелектронний ключ та вимірювальний шунт мікроконтролер періодично подає мікрострумовий тестовий імпульс у лінію відносно захисного заземлення `PE` для вимірювання опору витоку `R_iso`.

Програмний драйвер реалізує обчислення середнього постійного зсуву, середньоквадратичного значення синфазного шуму (англ. *Root Mean Square*, RMS) та автомат станів захисту з гістерезисом.

```cpp
/*
 * line_diagnostics.hpp - C++20 модуль діагностики синфазних перешкод та цілісності лінії
 */

#pragma once

#include <array>
#include <cstdint>
#include <cmath>
#include <algorithm>
#include <numeric>
#include <span>
#include <expected>

namespace embedded::diagnostics {

enum class LineSafetyState : uint8_t {
    Ok = 0,
    WarningNoGround,        // Витік мережевої частоти 50 Гц (обрив PE)
    WarningHighCommonMode, // Постійний перекіс потенціалу GND
    CriticalSurgeEvent,    // Фіксація високовольтного імпульсу
    CriticalInsulationFail // Деградація опору ізоляції на PE
};

struct LineHealthMetrics {
    float v_cm_instant_volts{0.0F};
    float v_cm_dc_bias_volts{0.0F};
    float v_cm_noise_rms_volts{0.0F};
    float insulation_res_kohm{10000.0F};
    uint32_t surge_event_count{0};
    LineSafetyState state{LineSafetyState::Ok};
};

struct LineDiagConfig {
    float v_cm_warn_threshold_volts{7.0F};
    float v_cm_rms_warn_threshold_volts{12.0F};
    float r_iso_min_kohm{500.0F};
    float adc_vref_volts{3.3F};
    float divider_ratio{10.0F};
    uint16_t adc_midscale{2048}; // 12-бітний АЦП: середина 1.65 В
};

template <size_t WindowSize = 64>
class LineDiagnosticsMonitor {
public:
    explicit constexpr LineDiagnosticsMonitor(const LineDiagConfig& cfg) noexcept
        : config_(cfg) {}

    void add_sample(uint16_t adc_raw) noexcept {
        samples_[sample_idx_] = adc_raw;
        sample_idx_ = (sample_idx_ + 1U) % WindowSize;
        if (sample_count_ < WindowSize) {
            ++sample_count_;
        }
    }

    [[nodiscard]] LineHealthMetrics evaluate(float raw_r_iso_adc_volts) noexcept {
        LineHealthMetrics metrics{};
        metrics.surge_event_count = surge_counter_;

        if (sample_count_ == 0U) {
            metrics.state = LineSafetyState::Ok;
            return metrics;
        }

        // Обчислення напруг за даними вікна вибірок
        float sum_v = 0.0F;
        float sum_sq_diff = 0.0F;
        const size_t n = sample_count_;

        for (size_t i = 0; i < n; ++i) {
            const float v = convert_adc_to_vcm(samples_[i]);
            sum_v += v;
        }
        const float mean_v = sum_v / static_cast<float>(n);

        for (size_t i = 0; i < n; ++i) {
            const float v = convert_adc_to_vcm(samples_[i]);
            const float diff = v - mean_v;
            sum_sq_diff += diff * diff;
        }
        const float rms_noise = std::sqrt(sum_sq_diff / static_cast<float>(n));

        metrics.v_cm_instant_volts = convert_adc_to_vcm(samples_[(sample_idx_ + WindowSize - 1U) % WindowSize]);
        metrics.v_cm_dc_bias_volts = mean_v;
        metrics.v_cm_noise_rms_volts = rms_noise;

        // Розрахунок опору ізоляції
        metrics.insulation_res_kohm = calculate_insulation(raw_r_iso_adc_volts);

        // Класифікація стану лінії
        metrics.state = classify_state(metrics);
        current_state_ = metrics.state;

        return metrics;
    }

    void record_surge_event() noexcept {
        ++surge_counter_;
    }

    [[nodiscard]] LineSafetyState current_state() const noexcept {
        return current_state_;
    }

private:
    [[nodiscard]] constexpr float convert_adc_to_vcm(uint16_t raw) const noexcept {
        const float adc_volts = (static_cast<float>(raw) * config_.adc_vref_volts) / 4095.0F;
        // Зсув відносно віртуального нуля Vref/2
        const float bipolar_adc_v = adc_volts - (config_.adc_vref_volts * 0.5F);
        return bipolar_adc_v * config_.divider_ratio;
    }

    [[nodiscard]] float calculate_insulation(float sense_volts) const noexcept {
        if (sense_volts <= 0.01F) {
            return 10000.0F; // Високий опір (ідеальна ізоляція)
        }
        constexpr float r_shunt_kohm = 10.0F;
        constexpr float v_test_volts = 24.0F;
        const float i_leak_ma = sense_volts / r_shunt_kohm;
        if (i_leak_ma <= 0.0001F) {
            return 10000.0F;
        }
        return (v_test_volts - sense_volts) / i_leak_ma;
    }

    [[nodiscard]] LineSafetyState classify_state(const LineHealthMetrics& m) const noexcept {
        if (m.insulation_res_kohm < config_.r_iso_min_kohm) {
            return LineSafetyState::CriticalInsulationFail;
        }
        if (m.v_cm_noise_rms_volts > config_.v_cm_rms_warn_threshold_volts) {
            return LineSafetyState::WarningNoGround;
        }
        if (std::abs(m.v_cm_dc_bias_volts) > config_.v_cm_warn_threshold_volts) {
            return LineSafetyState::WarningHighCommonMode;
        }
        return LineSafetyState::Ok;
    }

    LineDiagConfig config_;
    std::array<uint16_t, WindowSize> samples_{};
    size_t sample_idx_{0};
    size_t sample_count_{0};
    uint32_t surge_counter_{0};
    LineSafetyState current_state_{LineSafetyState::Ok};
};

} // namespace embedded::diagnostics

```c
/*
 * line_diagnostics.c - Реалізація математики моніторингу та класифікації станів
 */

#include "line_diagnostics.h"
#include <math.h>
#include <string.h>

void line_diag_init(line_diag_handle_t *handle, const line_diag_config_t *config)
{
    if (!handle || !config) {
        return;
    }
    handle->config = *config;
    handle->sample_idx = 0;
    handle->surge_counter = 0;
    handle->current_state = LINE_STATE_OK;
    memset(handle->adc_buffer, 0, sizeof(handle->adc_buffer));
}

void line_diag_push_adc_sample(line_diag_handle_t *handle, uint16_t adc_raw)
{
    if (!handle) {
        return;
    }
    handle->adc_buffer[handle->sample_idx] = adc_raw;
    handle->sample_idx = (handle->sample_idx + 1U) % LINE_DIAG_SAMPLE_WINDOW_SIZE;
}

static float adc_to_vcm(const line_diag_config_t *cfg, uint16_t raw)
{
    float v_adc = ((float)raw * cfg->adc_vref_volts) / 4095.0f;
    float v_centered = v_adc - (cfg->adc_vref_volts * 0.5f);
    return v_centered * cfg->divider_ratio;
}

void line_diag_process(line_diag_handle_t *handle, float raw_r_iso_adc, line_health_metrics_t *out_metrics)
{
    if (!handle || !out_metrics) {
        return;
    }

    float sum_v = 0.0f;
    float sum_sq_diff = 0.0f;
    const uint32_t n = LINE_DIAG_SAMPLE_WINDOW_SIZE;

    for (uint32_t i = 0; i < n; ++i) {
        float v = adc_to_vcm(&handle->config, handle->adc_buffer[i]);
        sum_v += v;
    }
    float mean_v = sum_v / (float)n;

    for (uint32_t i = 0; i < n; ++i) {
        float v = adc_to_vcm(&handle->config, handle->adc_buffer[i]);
        float diff = v - mean_v;
        sum_sq_diff += diff * diff;
    }
    float rms_noise = sqrtf(sum_sq_diff / (float)n);

    uint32_t last_idx = (handle->sample_idx + LINE_DIAG_SAMPLE_WINDOW_SIZE - 1U) % LINE_DIAG_SAMPLE_WINDOW_SIZE;
    out_metrics->v_cm_instant_volts = adc_to_vcm(&handle->config, handle->adc_buffer[last_idx]);
    out_metrics->v_cm_dc_bias_volts = mean_v;
    out_metrics->v_cm_noise_rms_volts = rms_noise;
    out_metrics->surge_event_count = handle->surge_counter;

    /* Розрахунок опору ізоляції за напругою на шунті R_shunt = 10 кОм */
    if (raw_r_iso_adc <= 0.01f) {
        out_metrics->insulation_res_kohm = 10000.0f;
    } else {
        const float r_shunt = 10.0f; /* кОм */
        const float v_test = 24.0f;  /* В */
        float i_leak_ma = raw_r_iso_adc / r_shunt;
        out_metrics->insulation_res_kohm = (i_leak_ma > 0.0001f) ? ((v_test - raw_r_iso_adc) / i_leak_ma) : 10000.0f;
    }

    /* Автомат рішень безпеки */
    if (out_metrics->insulation_res_kohm < handle->config.r_iso_min_kohm) {
        out_metrics->state = LINE_STATE_CRITICAL_INSULATION_FAIL;
    } else if (out_metrics->v_cm_noise_rms_volts > handle->config.v_cm_rms_warn_threshold_volts) {
        out_metrics->state = LINE_STATE_WARNING_NO_GROUND;
    } else if (fabsf(out_metrics->v_cm_dc_bias_volts) > handle->config.v_cm_warn_threshold_volts) {
        out_metrics->state = LINE_STATE_WARNING_HIGH_COMMON_MODE;
    } else {
        out_metrics->state = LINE_STATE_OK;
    }

    handle->current_state = out_metrics->state;
}

Інтеграція модуля вимірювання синфазної напруги та аналізу шуму лінії дозволяє автоматиці приладу самостійно виявити відсутність захисного заземлення (за наявністю синусоїди 50 Гц із розмахом понад 30 В) або небезпечний перекіс потенціалів між будівлями ще до того, як трансивер згорить. Це перетворює прилад із пасивної жертви зовнішніх аварій на активний діагностичний інструмент, який зберігає логи перенапруг для сервісних інженерів.
