# 🧮 Ентропія вибору за Хіком-Хайманом та час візуального сканування

Коли оператор дивиться на екран диспетчерської станції або пульта керування, час виявлення аномалії та ухвалення рішення не є випадковою величиною. Він підпорядковується законам теорії інформації, психофізики зорового пошуку та математичної статистики. Нижче наведено математичні моделі часу реакції, саккадичного сканування, ентропійного захаращення та детекції прихованого дрейфу в операторських інтерфейсах.

---

## 1. Закон Хіка-Хаймана: час реакції від інформаційної ентропії

Закон Хіка-Хаймана (*Hick-Hyman Law*) визначає час реакції оператора T як лінійну функцію інформаційної ентропії H вибору серед n доступних альтернатив або візуальних об'єктів.

Якщо на екрані розміщено n однакових за помітністю віджетів, і ймовірність виникнення аварії на будь-якому з них однакова (p_i = 1/n), ентропія системи за Шенноном становить:

```
H = log2(n + 1)               [інформаційна ентропія вибору у бітах]
```

Час реакції оператора T_decision на вибір правильної дії виражається формулою:

```
T_decision = a + b * H        [базова формула Хіка-Хаймана]
           = a + b * log2(n + 1)
```

де:
- a — базовий час простої рухової та сенсорної реакції людини (a ≈ 0.15–0.25 с);
- b — емпіричний коефіцієнт обробки інформації мозком (b ≈ 0.15–0.22 с/біт для досвідчених операторів, b ≈ 0.35–0.45 с/біт для новачків або в умовах стресу й втоми).

Якщо елементи на екрані мають різну апріорну ймовірність привертання уваги p_i, інформаційна ентропія узагальнюється через зважену суму:

```
H = - sum_{i=1}^n p_i * log2(p_i)   [ентропія Шеннона для нерівноймовірних сигналів]
```

### Числовий розрахунок для чистого та захаращеного дисплеїв

Нехай базовий сенсомоторний час становить a = 0.20 с, а коефіцієнт когнітивної складності b = 0.20 с/біт.

**Варіант А (Чистий дисплей за стандартом ISA-101):** на екрані виведено n = 5 інтегрованих функціональних груп.

```
H_clean        = log2(5 + 1) = log2(6) ≈ 2.585 біт
T_clean        = 0.20 + 0.20 * 2.585
               = 0.20 + 0.517
               = 0.717 с            [менше 1 секунди на вибір дії]
```

**Варіант Б (Захаращений дисплей, 45 розрізнених індикаторів):** n = 45.

```
H_cluttered    = log2(45 + 1) = log2(46) ≈ 5.524 біт
T_cluttered    = 0.20 + 0.20 * 5.524
               = 0.20 + 1.105
               = 1.305 с            [чистий час ухвалення рішення без урахування пошуку]
```

## 2. Модель часу візуального пошуку (Visual Search Time)

Перш ніж прийняти рішення за законом Хіка, оператор мусить знайти аварійний параметр очима серед N елементів на екрані.

Зоровий пошук складається з послідовності фіксацій погляду (де фовеальний зір аналізує віджет) та перевідних стрибків (саккад):

```
T_cycle = T_fixation + T_saccade    [час одного кроку сканування]
```

Емпіричні параметри зорової системи людини:
- Середня тривалість фіксації: T_fixation ≈ 0.250 с (250 мс);
- Середня тривалість саккади: T_saccade ≈ 0.040 с (40 мс).

Тривалість одного повного кроку сканування:

```
T_cycle = 0.250 + 0.040 = 0.290 с   [сума тривалості фіксації та саккади]
```

### Випадковий та послідовний пошук без візуального контрасту

Якщо на екрані відсутній яскравий колірний контраст (*Pop-Out Effect*), мозок змушений виконувати послідовний перебір елементів (*Serial Search*).

Математичне сподівання кількості перевірених елементів K_mean до виявлення шуканої аномалії серед N віджетів становить:

```
K_mean = (N + 1) / 2          [середня кількість фіксацій]
```

Повний середній час візуального виявлення T_search:

```
T_search = K_mean * T_cycle
         = ((N + 1) / 2) * (T_fixation + T_saccade)
```

Підставимо реальні значення:

```
Для N = 7 (Dark Cockpit):
K_mean   = (7 + 1) / 2 = 4
T_search = 4 * 0.290 с = 1.16 с

Для N = 50 («Новорічна ялинка» з 50 показників):
K_mean   = (50 + 1) / 2 = 25.5
T_search = 25.5 * 0.290 с = 7.395 с
```

Повний час реакції системи «людина-інтерфейс» складається з часу виявлення та часу ухвалення рішення:

```
T_total = T_search + T_decision

Для чистого екрана:
T_total_clean     = 1.16 с + 0.72 с = 1.88 с      [оператор встигає врятувати борт]

Для захаращеного екрана:
T_total_cluttered = 7.40 с + 1.31 с = 8.71 с      [дрон встигає зіткнутися з перешкодою]
```

```
Порівняння затримки когнітивного контуру:
+-------------------+----------------+------------------+----------------+
| Конфігурація      | Кількість (N)  | Пошук T_search   | Повний час T   |
+-------------------+----------------+------------------+----------------+
| Чистий (ISA-101)  | 7 віджетів     | 1.16 с           | 1.88 с         |
| Захаращений       | 50 віджетів    | 7.40 с           | 8.71 с         |
+-------------------+----------------+------------------+----------------+
```

## 3. Модель візуального захаращення Розенгольц (Feature Congestion Model)

Для кількісної оцінки візуального шуму на екрані застосовують метрику захаращеності Розенгольц (*Rosenholtz Visual Clutter Metric*). Вона оцінює локальну ентропію за трьома вимірами: яскравістю (Luminance), колірністю (Color Chrominance C_b, C_r) та орієнтацією просторових градієнтів (Orientation).

Для ділянки екрана розміром W x H обчислюється коваріаційна матриця ознак Sigma_feat:

```
Sigma_feat = (1 / M) * sum_{k=1}^M (x_k - mu) * (x_k - mu)^T   [коваріація візуальних ознак]
```

де x_k — тривимірний вектор (яскравість, колір, орієнтація) у точці k, а mu — вектор середнього.

Інтегральний показник візуального захаращення Clutter_score визначається через логарифм об'єму еліпсоїда коваріації:

```
Clutter_score = (1/2) * log2(det(Sigma_feat))                   [візуальна ентропія ділянки]
```

Коли екран заповнений різнокольоровими кнопками, миготливими рамками та 3D-градієнтами, значення `det(Sigma_feat)` зростає в десятки разів. Це руйнує здатність зорової кори до попередньої паралельної сегментації, змушуючи мозок перемикатися в режим повільного перебору, де коефіцієнт b у законі Хіка зростає від 0.20 до 0.45 с/біт.

## 4. Математика детектора дрейфу: вибір порогу швидкості зміни

Щоб подолати сліпоту до повільних змін (*Change Blindness*), програмний модуль HUD обчислює першу похідну сигналу за часом. Проте сире чисельне диференціювання v_raw = (x_k - x_{k-1}) / dt надзвичайно чутливе до шуму квантування АЦП та тремтіння періоду дискретизації.

Для згладжування шуму застосовується експоненційне ковзне середнє (EMA) над модулем швидкості зміни:

```
v_filt[k] = alpha * v_raw[k] + (1 - alpha) * v_filt[k-1]        [фільтрація похідної]
```

Коефіцієнт згладжування alpha обирається через компроміс між затримкою виявлення tau_delay та дисперсією шуму sigma_v^2:

```
tau_delay ≈ dt / alpha                                          [еквівалентна затримка фільтра]
sigma_filt^2 = (alpha / (2 - alpha)) * sigma_raw^2              [придушення дисперсії шуму]
```

Для типової частоти оновлення телеметрії f_s = 10 Гц (dt = 0.10 с) вибір alpha = 0.20 дає:

```
tau_delay    = 0.10 / 0.20 = 0.50 с                            [затримка виявлення лише пів секунди]
sigma_filt^2 = (0.20 / 1.80) * sigma_raw^2 ≈ 0.111 * sigma_raw^2 [дисперсія шуму зменшується в 9 разів]
```

Поріг спрацьовування алерту дрейфу V_threshold встановлюється за правилом трьох сигм над фоновим шумом:

```
V_threshold = 3 * sigma_filt + V_safe_nominal                   [поріг детекції Change Blindness]
```

Якщо швидкість спаду напруги чи наростання температури перевищує V_threshold протягом трьох послідовних відліків, система генерує попереджувальний колірний транзієнт, повертаючи подію в поле зорового сприйняття оператора задовго до фізичної аварії.

## 5. Закон Фіттса: час наведення на елементи керування

Після того, як аномалію виявлено (T_search) і рішення прийнято (T_decision), оператор повинен фізично навести курсор миші, доторкнутися до сенсорного екрана або перевести тумблер на пульті.

Час моторного наведення T_motor описується законом Фіттса (*Fitts' Law*):

```
ID      = log2((2 * D) / W)       [індекс складності цілі за Фіттсом]
T_motor = a_f + b_f * ID          [час наведення на ціль]
```

де:
- D — відстань від поточної позиції курсора/руки до центру цільової кнопки;
- W — ширина (лінійний розмір) кнопки вздовж осі руху;
- a_f, b_f — емпіричні коефіцієнти маніпулятора (для миші a_f ≈ 0.10 с, b_f ≈ 0.14 с/біт; для сенсорного екрана в умовах вібрації b_f зростає до 0.28 с/біт).

### Розрахунок часу квитування для маленької та великої кнопки

Нехай курсор розташований на відстані D = 300 мм від аварійної панелі.

**Випадок 1: Маленька кнопка підтвердження (W = 10 мм):**

```
ID_small = log2((2 * 300) / 10) = log2(60) ≈ 5.907 біт  [індекс складності цілі]
T_small  = 0.10 + 0.14 * 5.907                           [підстановка значень у формулу Фіттса]
         = 0.10 + 0.827                                  [обчислення когнітивно-моторної складової]
         = 0.927 с                                       [підсумковий час моторної реакції]
```

**Випадок 2: Велика контекстна плашка аварії (W = 80 мм):**

```
ID_large = log2((2 * 300) / 80) = log2(7.5) ≈ 2.907 біт [індекс складності для широкої кнопки]
T_large  = 0.10 + 0.14 * 2.907                           [підстановка значень у формулу Фіттса]
         = 0.10 + 0.407                                  [обчислення моторного часу]
         = 0.507 с                                       [виграш у 420 мс на фізичній дії]
```

Збільшення розміру критичної кнопки в 8 разів скорочує час фізичного натискання майже вдвічі та знижує ймовірність промаху (*motor slip*) з 18% до менше 0.5% в умовах стресового тремору рук оператора.
