# 🧮 Математичний розрахунок дільників PLL під довільний кварц

Математичний розрахунок ланцюга фазового автопідстроювання частоти (PLL) дозволяє знайти точні цілочисельні коефіцієнти множення та ділення під довільний зовнішній резонатор, забезпечуючи максимальну частоту ядра, точні 48 МГц для шини USB та мінімальний фазовий джиттер внутрішнього генератора.

В основі блоку PLL лежить контур фазового автопідстроювання, який синтезує високу частоту з відносно низької опорної частоти кварцового резонатора. Спроба обрати коефіцієнти «на око» або довільним перемноженням майже завжди призводить до порушення апаратних меж напівпровідникового кристала: перевантаження фазового детектора, виходу генератора керованого напругою (VCO) за межі стійкого захоплення або спотворення частоти USB, через що апаратний трансивер не зможе зафіксувати пакетний потік.

## Система рівнянь тактового тракту

Тактовий тракт містить чотири ключові коефіцієнти ділення та множення:
- `M` — вхідний дільник опорної частоти кварцу `f_XTAL`;
- `N` — множник зворотного зв'язку генератора керованого напругою (VCO);
- `P` — вихідний дільник системної тактової частоти ядра `f_SYSCLK`;
- `Q` — вихідний дільник периферійної шини USB OTG, апаратного генератора випадкових чисел (RNG) та інтерфейсу SDIO `f_USB`.

```
f_PFD = f_XTAL / M                      [частота фазового детектора]
f_VCO = f_PFD · N = (f_XTAL · N) / M    [частота керованого генератора]
f_SYSCLK = f_VCO / P = (f_XTAL · N) / (M · P) [частота ядра процесора]
f_USB = f_VCO / Q = (f_XTAL · N) / (M · Q)    [частота шини USB 48 МГц]
```

## Апаратні обмеження кремнієвого тракту

Для забезпечення стабільності фазової петлі та запобігання тепловому або електричному пробою виробник встановлює суворі діапазони для кожної проміжної точки:

1. **Частота фазово-частотного детектора `f_PFD`:**
```
1.0 МГц ≤ f_PFD ≤ 2.0 МГц, рекомендовано: f_PFD = 2.0 МГц
```
При `f_PFD = 2.0 МГц` фазовий шум та джиттер контуру мінімальні, оскільки фазовий компаратор коригує напругу генератора вдвічі частіше, ніж при 1.0 МГц. Це розширює смугу пропускання петльового фільтра і прискорює вихід PLL на усталений режим.

2. **Частота керованого генератора `f_VCO`:**
```
100 МГц ≤ f_VCO ≤ 432 МГц  (для ядер класу 168/180 МГц)
```
Якщо `f_VCO` опуститься нижче 100 МГц, варикапи внутрішнього LC/RC контуру втратять лінійність, і PLL не зможе захопити частоту. Якщо `f_VCO` перевищить 432 МГц, виникне ризик фазового зриву через граничну швидкодію внутрішніх тригерів дільника.

3. **Діапазони цілих коефіцієнтів:**
```
M ∈ [2 .. 63]
N ∈ [50 .. 432]
P ∈ {2, 4, 6, 8}
Q ∈ [2 .. 15]
```

4. **Вимога стандарту USB 2.0 Full Speed:**
```
f_USB = 48.0 МГц ± 0.25%  (допустимий діапазон 47.88 .. 48.12 МГц)
```

## Фізика фазового шуму та оптимізація дільника M

Вибір значення `M` безпосередньо визначає динаміку контуру фазового автопідстроювання. Фазовий детектор порівнює фронти вхідного сигналу з частотою `f_PFD` та фронти сигналу зворотного зв'язку, поділеного на `N`. На кожному періоді компаратор формує імпульси струму заряду або розряду петльового фільтра.

Коли дільник `M` обрано так, що `f_PFD = 1.0 МГц`, період корекції становить 1 мікросекунду. За цей час внутрішній генератор VCO встигає накопичити фазову похибку через власний тепловий шум транзисторів. Якщо ж обрати `M` таким чином, щоб отримати `f_PFD = 2.0 МГц`, період корекції скорочується до 500 наносекунд. Фазова петля відпрацьовує збурення вдвічі швидше, що суттєво пригнічує низькочастотний фазовий шум у смузі захоплення.

Крім того, вища частота порівняння зсуває паразитні дискретні гармоніки (reference spurs) далі від несучої частоти, спрощуючи їх фільтрацію інтегрованим RC-фільтром на кристалі.

## Покроковий розрахунок для типових кварцових резонаторів

Розглянемо задачу синтезу максимальної частоти ядра `f_SYSCLK = 168 МГц` та точної частоти `f_USB = 48 МГц` для чотирьох поширених номіналів кварцу: 8 МГц, 12 МГц, 16 МГц та 25 МГц.

### 1. Розрахунок для кварцу 8 МГц

Маємо `f_XTAL = 8.0 МГц`.

**Крок 1. Вибір вхідного дільника M:**
```
M = f_XTAL / f_PFD_target
= 8.0 МГц / 2.0 МГц
= 4                                   [f_PFD = 2.0 МГц, умова 1.0..2.0 МГц виконана]
```

**Крок 2. Розрахунок множника N та дільника P:**
Цільова системна частота `f_SYSCLK = 168 МГц`. При мінімальному дільнику `P = 2`:
```
f_VCO = f_SYSCLK · P
= 168 МГц · 2
= 336 МГц                             [умова 100..432 МГц виконана]

N = f_VCO / f_PFD
= 336 МГц / 2.0 МГц
= 168                                 [умова 50..432 виконана]
```

**Крок 3. Розрахунок дільника Q для USB 48 МГц:**
```
Q = f_VCO / f_USB_target
= 336 МГц / 48.0 МГц
= 7                                   [умова 2..15 виконана]

f_USB = 336 МГц / 7 = 48.0 МГц        [похибка 0.00%]
```

Підсумкова конфігурація для 8 МГц: `M = 4, N = 168, P = 2, Q = 7`.

---

### 2. Розрахунок для кварцу 12 МГц

Маємо `f_XTAL = 12.0 МГц` (типовий кварц для плат розробки на зразок Raspberry Pi Pico або звукових інтерфейсів).

**Крок 1. Вибір дільника M:**
```
M = 12.0 МГц / 2.0 МГц
= 6                                   [f_PFD = 2.0 МГц]
```

**Крок 2. Розрахунок N та P:**
```
f_VCO = 168 МГц · 2 = 336 МГц
N = 336 МГц / 2.0 МГц = 168           [P = 2]
```

**Крок 3. Розрахунок Q:**
```
Q = 336 МГц / 48.0 МГц = 7            [f_USB = 48.0 МГц, похибка 0.00%]
```

Підсумкова конфігурація для 12 МГц: `M = 6, N = 168, P = 2, Q = 7`.

---

### 3. Розрахунок для кварцу 16 МГц

Маємо `f_XTAL = 16.0 МГц`.

**Крок 1. Вибір дільника M:**
```
M = 16.0 МГц / 2.0 МГц
= 8                                   [f_PFD = 2.0 МГц]
```

**Крок 2. Розрахунок N та P:**
```
f_VCO = 168 МГц · 2 = 336 МГц
N = 336 МГц / 2.0 МГц = 168           [P = 2]
```

**Крок 3. Розрахунок Q:**
```
Q = 336 МГц / 48.0 МГц = 7            [f_USB = 48.0 МГц, похибка 0.00%]
```

Підсумкова конфігурація для 16 МГц: `M = 8, N = 168, P = 2, Q = 7`.

---

### 4. Розрахунок для кварцу 25 МГц

Маємо `f_XTAL = 25.0 МГц` (часто застосовується на платах з апаратним трансивером Ethernet PHY, де потрібна саме опорна частота 25 МГц).

Оскільки 25 не ділиться націло на 2.0 МГц, обираємо `f_PFD = 1.0 МГц`:

**Крок 1. Вибір дільника M:**
```
M = 25.0 МГц / 1.0 МГц
= 25                                  [f_PFD = 1.0 МГц, умова 1.0..2.0 МГц виконана]
```

**Крок 2. Розрахунок N та P:**
```
f_VCO = 168 МГц · 2 = 336 МГц
N = 336 МГц / 1.0 МГц
= 336                                 [умова 50..432 виконана, P = 2]
```

**Крок 3. Розрахунок Q:**
```
Q = 336 МГц / 48.0 МГц = 7            [f_USB = 48.0 МГц, похибка 0.00%]
```

Підсумкова конфігурація для 25 МГц: `M = 25, N = 336, P = 2, Q = 7`.

## Конфлікт частоти ядра 180 МГц та шини USB

Якщо цільовою частотою ядра є максимальна частота 180 МГц (наприклад, для кристалів лінійок STM32F427/429/446/469), виникає математична суперечність цілочисельного ділення.

Для отримання частоти ядра 180 МГц при `P = 2`:
```
f_SYSCLK = 180 МГц
f_VCO = f_SYSCLK · 2 = 360 МГц        [при P = 2]
```

Спробуємо знайти цілочисельний дільник `Q` для отримання стандартної частоти USB 48 МГц:
```
Q = f_VCO / f_USB_target
= 360 МГц / 48 МГц
= 7.5                                 [не є цілим числом!]
```

Оскільки дільник `Q` у регістрі `RCC_PLLCFGR` є 4-бітним цілим числом від 2 до 15, ми можемо обрати лише сусідні значення 7 або 8:

```
Якщо обрати Q = 7:
f_USB = 360 МГц / 7 ≈ 51.428 МГц      [відхилення +7.14%, USB не працює]

Якщо обрати Q = 8:
f_USB = 360 МГц / 8 = 45.000 МГц      [відхилення -6.25%, USB не працює]
```

Обидва значення значно перевищують допустиме відхилення стандарту USB 2.0 (±0.25%). Фізичний USB-хост комп'ютера не зможе зафіксувати пакетний потік і видасть помилку розпізнавання пристрою (Device Descriptor Request Failed).

### Інженерні способи вирішення конфлікту 180 МГц

В інженерній практиці для роботи на максимальній частоті 180 МГц з одночасною підтримкою USB використовують один із трьох підходів:
1. **Використання виділеного блоку PLL (PLLSAI або PLLI2S):** Допоміжний фазовий контур налаштовується на генерацію незалежної частоти 48 МГц для домену USB/SDIO, тоді як головний PLL забезпечує 180 МГц для ядра.
2. **Компромісна частота 168 МГц:** Якщо апаратний чіп не має другого блоку PLL, ядро встановлюють на 168 МГц замість 180 МГц, зберігаючи точні 48 МГц для USB від головного генератора.
3. **Тактування USB від внутрішнього генератора HSI48:** У новіших сімействах мікроконтролерів інтегрують окремий прецизійний генератор на 48 МГц із функцією автоматичного підстроювання частоти за пакетами синхронізації шини USB (Clock Recovery System — CRS).
