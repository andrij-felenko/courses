# Розподіл густини зворотного струму в земляному полігоні

Коли високочастотний цифровий сигнал біжить по сигнальній доріжці друкованої плати, закон збереження заряду вимагає повернення рівно такого самого струму назад до джерела. На постійному струмі (DC) зворотний струм розтікається по всій площі опорного шару міді, обираючи шлях найменшого омічного опору. Проте щойно частота перевищує кілька десятків кілогерців, картина змінюється: струм починає обирати шлях найменшого індуктивного опору, тобто найменшої площі контуру. Розглянемо точний математичний розподіл густини зворотного струму в суцільному земляному полігоні під мікросмужковою лінією, умови частотного переходу та розрахунок магнітної наводки на сусідні траси.

## Геометрія моделі та крайова задача

Розглянемо нескінченно довгий тонкий сигнальний провідник, розташований на висоті `h` над нескінченною ідеально провідною площиною (опорним полігоном землі). Провідник орієнтований уздовж осі `z`, а поперечний переріз плати лежить у площині `(x, y)`. Координата `x = 0` відповідає положенню осі сигнальної траси, а поверхня земляного полігону збігається з площиною `y = 0`. Сигнальний провідник знаходиться в точці `(x = 0, y = h)`.

По сигнальній трасі тече високочастотний струм `I₀`. Завдяки скін-ефекту та високій провідності міді зворотний струм тече у тонкому поверхневому шарі полігону `y = 0`.

У квазістатичному наближенні для високочастотного струму магнітне поле над провідною площиною визначається методом дзеркальних зображень. Щоб задовольнити граничну умову відсутності нормальної складової магнітного поля `B_y = 0` на поверхні ідеального провідника `y = 0`, ми подумки вводимо дзеркальний фіктивний провідник зі струмом `-I₀` у точці `(x = 0, y = -h)`.

Магнітне поле `B_x(x, 0)` на поверхні землі створюється суперпозицією полів від реального провідника та його дзеркального відображення:

```
B_x(x, 0) = 2 · (μ₀ · I₀ / (2 · π · r)) · cos(θ)
```

де `r = √(x² + h²)` — відстань від реального провідника до точки `(x, 0)` на площині землі, а `cos(θ) = h / r = h / √(x² + h²)` — косинус кута між вектором поля та віссю `x`.

Підставляючи геометричні співвідношення:

```
B_x(x, 0)
= 2 · (μ₀ · I₀ / (2 · π · √(x² + h²))) · (h / √(x² + h²))    [геометрія: cos(θ) = h/r]
= (μ₀ · I₀ · h) / (π · (x² + h²))                           [спрощення: r · r = x² + h²]
= (μ₀ · I₀ / (π · h)) · (1 / (1 + (x/h)²))                  [винесення h² у знаменнику]
```

## Густина поверхневого струму: розподіл Лоренца

За теоремою про циркуляцію магнітного поля (гранична умова для тангенціальної складової `B_x` на поверхні провідника), лінійна густина поверхневого зворотного струму `j(x)` (у вимірі А/м) пов'язана з магнітною індукцією співвідношенням:

```
j(x) = B_x(x, 0) / μ₀
```

Підставляючи отримане значення магнітного поля `B_x(x, 0)`:

```
j(x)
= ((μ₀ · I₀ / (π · h)) · (1 / (1 + (x/h)²))) / μ₀           [підстановка поля B_x]
= (I₀ / (π · h)) · (1 / (1 + (x/h)²))                       [скорочення магнітної сталої μ₀]
```

Ця формула являє собою класичний розподіл Лоренца (розподіл Коші).

Пікова густина струму досягається строго під сигнальним провідником при `x = 0`:

```
j_max = j(0) = I₀ / (π · h)
```

При віддаленні від осі траси на відстань `x = h` густина струму спадає вдвічі:

```
j(h) = j_max / (1 + 1²) = j_max / 2
```

При віддаленні на відстань `x = 3·h` густина струму спадає вдесятеро:

```
j(3h) = j_max / (1 + 3²) = j_max / 10
```

При віддаленні на відстань `x = 10·h` густина струму спадає в 101 раз (понад 40 дБ затухання):

```
j(10h) = j_max / (1 + 10²) = j_max / 101 ≈ 0.0099 · j_max
```

## Інтегральна частка зворотного струму в межах смуги шириною 2w

Щоб з'ясувати, яка частка загального струму `I₀` зосереджена у смузі певної ширини `[-w, +w]` відносно осі доріжки, проінтегруємо функцію густини струму:

```
I(w) = ∫_{-w}^{+w} j(x) dx
```

Обчислюємо первісну:

```
I(w)
= ∫_{-w}^{+w} (I₀ / (π · h)) · (1 / (1 + (x/h)²)) dx
= (I₀ / π) · ∫_{-w/h}^{+w/h} (1 / (1 + u²)) du              [заміна змінної: u = x/h, du = dx/h]
= (I₀ / π) · [arctan(u)]_{-w/h}^{+w/h}                      [табличний інтеграл arctan]
= (I₀ / π) · [arctan(w/h) − arctan(−w/h)]                   [підстановка меж інтегрування]
= (2 · I₀ / π) · arctan(w/h)                                [непарність функції: arctan(-z) = -arctan(z)]
```

Повний інтеграл по всій нескінченній площині дає повний струм контуру:

```
I_total
= lim_{w → ∞} (2 · I₀ / π) · arctan(w/h)
= (2 · I₀ / π) · (π / 2)                                    [границя arctan(∞) = π/2]
= I₀                                                        [струм повністю зійшовся]
```

## Числові оцінки частки струму для стандартного діелектрика

Обчислимо відносну частку струму `η(w) = I(w) / I₀ = (2 / π) · arctan(w/h)` для різних співвідношень напівширини смуги `w` до товщини діелектрика `h`:

```
Для w = 1·h (загальна ширина 2h):
   η(1h) = (2 / π) · arctan(1) = (2 / π) · (π / 4) = 0.5000   (рівно 50.0 % струму)

Для w = 2·h (загальна ширина 4h):
   η(2h) = (2 / π) · arctan(2) ≈ (2 / π) · 1.1071 ≈ 0.7048   (70.5 % струму)

Для w = 3·h (загальна ширина 6h):
   η(3h) = (2 / π) · arctan(3) ≈ (2 / π) · 1.2490 ≈ 0.7952   (79.5 % струму)

Для w = 5·h (загальна ширина 10h):
   η(5h) = (2 / π) · arctan(5) ≈ (2 / π) · 1.3734 ≈ 0.8743   (87.4 % струму)

Для w = 10·h (загальна ширина 20h):
   η(10h) = (2 / π) · arctan(10) ≈ (2 / π) · 1.4711 ≈ 0.9365 (93.7 % струму)

Для w = 20·h (загальна ширина 40h):
   η(20h) = (2 / π) · arctan(20) ≈ (2 / π) · 1.5208 ≈ 0.9682 (96.8 % струму)
```

## Гранична частота переходу: від омічного шляху до індуктивного

На якій саме частоті струм припиняє розтікатися по найкоротшій прямій (DC-режим) і починає притискатися під доріжку (HF-режим)?

Ця гранична частота переходу `f_c` визначається точкою, де індуктивний реактивний опір зворотного контуру зрівнюється з поверхневим омічним опором земляного шару. Для площини з поверхневим квадратичним опором `R_sq` (Ом/квадрат) та висотою діелектрика `h`:

```
f_c = R_sq / (π · μ₀ · h)
```

Для стандартної мідної фольги вагою 1 унція (товщина 35 мкм) питомий поверхневий опір на постійному струмі становить:

```
R_sq = ρ_cu / t_cu
R_sq = (1.72 · 10⁻⁸ Ом·м) / (35 · 10⁻⁶ м) ≈ 0.00049 Ом/квадрат = 0.49 мОм
```

Для типової чотиришарової плати з товщиною шару препрегу `h = 0.15 мм` (0.00015 м):

```
f_c
= 0.00049 / (π · 4·π·10⁻⁷ · 0.00015)                       [підстановка: R_sq, μ₀ та h]
= 0.00049 / (5.92 · 10⁻¹⁰)                                  [обчислення знаменника]
≈ 827 000 Гц ≈ 830 кГц                                      [ділення: частота переходу]
```

Для двошарової плати з товщиною склотекстоліту `h = 1.6 мм` (0.0016 м):

```
f_c
= 0.00049 / (π · 4·π·10⁻⁷ · 0.0016)                        [підстановка: товщина h = 1.6 мм]
≈ 77 000 Гц ≈ 77 кГц                                        [обчислення: частота переходу]
```

Висновки щодо частотної поведінки:
- На частотах `f << f_c` (звукові частоти, повільні зміни постійної напруги) зворотний струм тече найкоротшим геометричним шляхом найменшого опору `R`.
- На частотах `f >> f_c` (вище 1 МГц, а також у спектрі будь-яких логічних фронтів з `t_r < 100 нс`) струм на 100 % контролюється індуктивністю і тече строго під сигнальною трасою.

## Розрахунок взаємної індуктивності та перехресного наведення

Знаючи розподіл магнітного поля, оцінимо взаємну індуктивність `M` між паралельною цифровою трасою та сусідньою аналоговою лінією, розташованою на відстані `D` на тому ж шарі.

Магнітний потік `Φ`, що пронизує контур аналогової лінії довжиною `l` та висотою `h` над землею:

```
Φ = ∫₀ʰ dy ∫_D^{D+w_analog} B_x(x, y) dx ≈ (μ₀ · I₀ · l / (2 · π)) · ln(1 + (2·h / D)²)
```

Для випадку `D >> h` (коли відстань між трасами значно перевищує товщину діелектрика до землі) розклад логарифма дає:

```
ln(1 + (2·h / D)²) ≈ (2·h / D)² = 4 · h² / D²
```

Тоді коефіцієнт взаємної індуктивності на одиницю довжини становить:

```
M / l ≈ (2 · μ₀ / π) · (h² / D²)
```

А наведена напруга завади в аналоговій лінії дорівнює:

```
V_noise = M · (di/dt) = l · (2 · μ₀ / π) · (h² / D²) · (di/dt)
```

З цієї формули чітко видно дві фундаментальні закономірності змішаного трасування:
1. **Квадратична залежність від товщини діелектрика `h²`**: перехід від 2-шарової плати (`h = 1.6 мм`) до 4-шарової плати з тонким препрегом (`h = 0.15 мм`) зменшує магнітну наводку в `(1.6 / 0.15)² ≈ 113 разів` (більш ніж на 41 дБ придушення шуму!).
2. **Квадратична залежність від відстані `1/D²`**: збільшення дистанції між цифровою та аналоговою лінією від `D = 1 мм` до `D = 3 мм` зменшує наведену заваду в 9 разів.

## Інженерні висновки для проектування друкованих плат

Отримані співвідношення дають математичне обґрунтування ключовим правилам проектування:

1. Смуга шириною `±3·h` концентрує близько 80 % усього зворотного струму цифрової лінії, а смуга `±10·h` — майже 94 %.
2. Оскільки в сучасних багатошарових платах `h = 0.1…0.2 мм`, коридор зворотного струму має ширину всього 1–2 мм.
3. Просторовий зазор між аналоговим і цифровим секторами плати величиною 3–5 мм на суцільному земляному полігоні гарантує затухання перехресних високочастотних струмів понад 50 дБ, роблячи фізичні прорізи в землі абсолютно зайвими та шкідливими.
