# 🧮 Біомеханіка контактної взаємодії та розрахунок силових порогів за ISO/TS 15066

Розрахунок визначає максимальні допустимі швидкості ланок маніпулятора з урахуванням ефективної маси, пружності контакту та біомеханічних больових порогів для захисту людини від травм при зіткненні.

У колаборативній робототехніці неможливо гарантувати відсутність фізичного контакту, якщо машина діє в спільному просторі з оператором без суцільних механічних огорож. Щоб контакт не призвів до травмування або больового шоку, система керування повинна обмежувати механічну енергію, пікову контактну силу та контактний тиск відповідно до фізіологічних меж людського тіла. Технічна специфікація ISO/TS 15066 регламентує фізичні моделі удару та граничні значення навантаження для різних анатомічних ділянок.

## 1. Модель механічного контакту та ефективна маса

При контакті рухомого робота з тілом людини взаємодіють дві інерційні маси з пружно-в'язкими властивостями поверхні.

```
+──────────────────+                   +──────────────────+
│   Ланка робота   │────► v_rel ◄─────│   Сегмент тіла   │
│      (m_R)       │   [ Контакт ]    │      (m_H)       │
+──────────────────+   [ k_contact ]  +──────────────────+
```

Ефективна зведена маса системи визначається еквівалентним послідовним з'єднанням інерцій:

```
1 / m_eff = (1 / m_R) + (1 / m_H)             [еквівалентний зв'язок мас]
m_eff = (m_R · m_H) / (m_R + m_H)             [зведена ефективна маса зіткнення]
```

Значення ефективної маси робота `m_R` залежить від кінематичної конфігурації маніпулятора й напрямку руху. У декартовому просторі для заданого напрямку одиничного вектора контакту `u` ефективна маса визначається через матрицю маніпуляційної інерції `Lambda(q)`:

```
m_R = 1 / (u^T · Lambda^-1(q) · u)            [декартова ефективна маса в напрямку u]
Lambda(q) = (J(q) · M^-1(q) · J^T(q))^-1      [декартова матриця інерції]
```

Тут `M(q)` — матриця інерції зчленувань, а `J(q)` — матриця Якобі маніпулятора.

### Режими контакту: затискання проти вільного удару

Стандарт ISO/TS 15066 чітко розрізняє два фізичні сценарії:

1. **Квазістатичний контакт (Quasi-static clamping / Pinching):** частина тіла затискається між ланкою робота та нерухомою перешкодою (стіл, конвеєр, станина, стіна). Маса перешкоди вважається нескінченною (`m_H → ∞`), тому людина не може ухилитися або відсахнутися:

```
m_eff = m_R                                   [при затисканні об жорстку опору]
```

2. **Транзієнтний удар (Transient dynamic impact):** короткочасне зіткнення у відкритому просторі (тривалість `t < 50` мс), коли сегмент тіла людини може вільно рухатися після удару. У цьому випадку `m_H` дорівнює масі ураженої анатомічної ділянки:

- Кисть / пальці: `m_H = 0.6` кг
- Передпліччя: `m_H = 2.0` кг
- Плече / рука цілком: `m_H = 4.0` кг
- Голова / шия: `m_H = 4.4` кг
- Торс / тулуб: `m_H = 40.0` кг

## 2. Розрахунок передачі енергії та пікової сили

При зіткненні відносна кінетична енергія перетворюється на потенціальну енергію пружної деформації тканин тіла та покриття робота:

```
E_contact = 0.5 · m_eff · v_rel²              [кінетична енергія у системі центру мас]
```

Якщо контактні тканини моделюються лінійною пружністю з еквівалентною жорсткістю `k` (Н/м), максимальна пружна деформація `Δx` та пікова сила контакту `F_max` пов'язані співвідношенням:

```
E_contact = 0.5 · k · (Δx)²                   [потенціальна енергія деформації]
F_max = k · Δx                                [закон Гука для пружного стискання]
E_contact = 0.5 · F_max² / k                  [вираз енергії через силу]
```

Прирівнюючи кінетичну енергію до енергії стискання, отримуємо рівняння зв'язку між силою та швидкістю:

```
0.5 · m_eff · v_rel² = 0.5 · F_max² / k       [рівновага енергії]
F_max² = m_eff · k · v_rel²                   [множення на 2k]
F_max = v_rel · √(m_eff · k)                  [пікова динамічна сила контакту]
```

Звідси гранична допустима відносна швидкість ланки `v_limit(F)` для заданого больового порогу сили `F_limit`:

```
v_limit(F) = F_limit / √(m_eff · k)           [максимальна швидкість за критерієм сили]
```

## 3. Критерій контактного тиску та площа інструменту

Сила, прикладена до великої площі, сприймається як тупий поштовх. Та сама сила, прикладена до тонкої кромки, створює колосальний тиск, пробиває шкірний покрив і руйнує м'які тканини.

Піковий контактний тиск `p_max` визначається відношенням сили до ефективної площі контакту `A`:

```
p_max = F_max / A                             [визначення середнього тиску на площі A]
```

Підставляючи вираз для `F_max`, отримуємо критерій швидкості за тиском:

```
p_max = (v_rel · √(m_eff · k)) / A            [тиск як функція швидкості]
v_limit(p) = (p_limit · A) / √(m_eff · k)     [максимальна швидкість за критерієм тиску]
```

Остаточна допустима швидкість робота є мінімумом із двох обмежень:

```
v_max = min( v_limit(F), v_limit(p) )         [підсумковий ліміт швидкості]
```

### Чому транзієнтні пороги вдвічі вищі за квазістатичні

Для транзієнтних ударів стандартом дозволено підвищення граничної сили у 2 рази (`F_TR = 2 · F_QS`), якщо тривалість динамічного піку не перевищує `t_peak ≤ 0.5` с, а стале зусилля спадає до квазістатичного рівня за час `t < 0.05` с.

Фізіологічна причина криється в динаміці больових ноцицепторів та в'язкопружних властивостях підшкірної клітковини: короткий імпульс демпфується водонасиченими тканинами без структурного розриву капілярів і клітинних мембран, тоді як статичне здавлювання порушує локальний кровообіг і викликає ішемію та розчавлювання.

## 5. Практичний інженерний приклад розрахунку

Розглянемо випадок, коли робот масою `m_R = 15` кг із плоским заокругленим інструментом площею `A = 5` см² (`500` мм²) працює біля конвеєра, де можливе затискання передпліччя оператора.

Параметри за стандартом ISO/TS 15066:
- Квазістатичний поріг сили для передпліччя: `F_limit = 160` Н
- Квазістатичний поріг тиску для передпліччя: `p_limit = 190` Н/см² = `1.9` Н/мм²
- Жорсткість контакту тканин передпліччя: `k = 40` Н/мм = `40 000` Н/м
- Ефективна маса при затисканні: `m_eff = m_R = 15` кг

### Крок 1: Розрахунок обмеження за силою

```
v_limit(F)
= F_limit / √(m_eff · k)                      [формула швидкості]
= 160 / √(15 · 40000)                         [підстановка значень]
= 160 / √(600000)                             [обчислення підкореневого виразу]
= 160 / 774.6                                 [добування квадратного кореня]
= 0.2065 м/с ≈ 206 мм/с                       [гранична швидкість за силою]
```

### Крок 2: Розрахунок обмеження за тиском

Площа інструменту `A = 5` см².
Максимально допустима сила за критерієм тиску:

```
F_pressure_max
= p_limit · A                                 [сила від граничного тиску]
= 190 Н/см² · 5 см²                           [підстановка площі]
= 950 Н                                       [допустима сила за площею]
```

Оскільки `950` Н значно більше за абсолютний ліміт сили `160` Н, критичним обмеженням для цієї геометрії є саме загальна сила затискання `160` Н, а не тиск.

### Крок 3: Висновок та налаштування лімітів безпеки

Щоб робот гарантовано задовольняв вимоги ISO/TS 15066 у зоні потенційного квазістатичного затискання передпліччя, контур обмеження швидкості Safely-Limited Speed (SLS) у системі керування повинен бути налаштований на рівень не більше:

```
v_safe = 200 мм/с                             [інженерний ліміт з урахуванням 5% запасу]
```

Якщо технологічний процес вимагає більшої швидкості переміщення (наприклад, `v = 800` мм/с), застосування одного лише принципу Power and Force Limiting (PFL) недостатньо — система зобов'язана перейти в режим моніторингу швидкості та розділення (SSM) з використанням захисних лідарів.
