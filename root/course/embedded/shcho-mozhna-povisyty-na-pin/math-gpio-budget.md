# 🧮 Розрахунок струмового бюджету виводів і падіння напруги GPIO

Ця математична вставка містить строгі аналітичні моделі та числові розрахунки електричних режимів виводу мікроконтролера: виведення формул вихідного дільника напруги, точний розрахунок струмообмежувального резистора для світлодіода з урахуванням опору каналів польових транзисторів, тепловий баланс кристала, енергетику перезаряджання ємнісного навантаження та розрахунок захисного резистора від струмів інжекції.

---

## 1. Модель вихідного каскаду як реального джерела напруги

У режимі віддачі струму *(sourcing / active-high)* відкритий P-канальний MOSFET моделюється послідовним з'єднанням ідеального джерела напруги живлення `V_DD` та внутрішнього опору відкритого каналу `R_DS(on)_P`. При підключенні зовнішнього резистивного навантаження `R_L` відносно шини землі `GND` утворюється класичний дільник напруги між внутрішнім кремнієвим каналом та зовнішнім колом.

Струм у колі та вихідна напруга високого рівня `V_OH` визначаються виразами:

```
I_source = V_DD / (R_DS(on)_P + R_L)             [закон Ома для повного послідовного кола]
V_OH     = V_DD − I_source · R_DS(on)_P          [падіння напруги на внутрішньому P-MOSFET]
         = V_DD · (R_L / (R_DS(on)_P + R_L))     [коефіцієнт передачі вихідного дільника]
```

Аналогічно, у режимі втікання струму *(sinking / active-low)* відкритий N-канальний MOSFET з'єднує вивід із шиною землі `V_SS = 0 В` через внутрішній опір `R_DS(on)_N`. Якщо навантаження `R_L` підключене до шини `V_DD`, струм втікає у кристал і зміщує напругу низького рівня `V_OL` вгору відносно ідеального нуля:

```
I_sink = (V_DD − V_load) / (R_DS(on)_N + R_L)    [струм через відкритий нижній ключ]
V_OL   = I_sink · R_DS(on)_N                     [підйом потенціалу виводу над нулем]
```

Через фундаментальну фізичну різницю в рухливості основних носіїв заряду (електронів у зоні провідності N-каналу проти дірок у валентній зоні P-каналу, де `μ_n ≈ 2.5…3 · μ_p`) N-канальний транзистор при однаковій геометричній площі затвора має суттєво менший опір. Навіть із компенсаційним збільшенням площі P-MOSFET у сучасних мікроконтролерах зберігається асиметрія:

```
R_DS(on)_P ≈ 1.3…1.8 · R_DS(on)_N                [співвідношення внутрішніх опорів каскаду]
```

Типові практичні значення для 3.3-вольтового мікроконтролера: `R_DS(on)_N ≈ 20…25 Ом`, тоді як `R_DS(on)_P ≈ 32…45 Ом`.

## 2. Запас завадостійкості та деградація логічних рівнів

Спад напруги під навантаженням безпосередньо впливає на **запас статичної завадостійкості** *(Noise Margin)* цифрового інтерфейсу. Запас завадостійкості за високим рівнем `NM_H` та низьким рівнем `NM_L` визначається відстанню між вихідними рівнями передавача `V_OH`, `V_OL` та вхідними порогами розпізнавання приймача `V_IH_min`, `V_IL_max`:

```
NM_H = V_OH − V_IH_min                           [запас завадостійкості логічної одиниці]
NM_L = V_IL_max − V_OL                           [запас завадостійкості логічного нуля]
```

Для стандартної 3.3-вольтової КМОН-логіки вхідні пороги становлять `V_IH_min = 0.7 · V_DD = 2.31 В` та `V_IL_max = 0.3 · V_DD = 0.99 В`.

Якщо вивід не навантажений струмом (`I_source ≈ 0`), вихідна напруга `V_OH ≈ 3.30 В`, і запас завадостійкості максимальний:

```
NM_H_idle = 3.30 − 2.31                          [віднімання мінімального вхідного порогу]
          = 0.99 В                               [майже 1 вольт запасу від завад]
```

Якщо ж вивід перевантажений струмом `I_source = 20 мА` при `R_DS(on)_P = 40 Ом`:

```
V_OH_loaded = 3.30 − 0.020 · 40                  [падіння на внутрішньому опорі 0.8 В]
            = 3.30 − 0.80
            = 2.50 В                             [фактична напруга на виводі]
NM_H_loaded = 2.50 − 2.31                        [запас завадостійкості під навантаженням]
            = 0.19 В                             [критичне зниження запасу до 190 мВ!]
```

Запас завадостійкості скоротився більш ніж у 5 разів. Будь-яка короткочасна перешкода амплітудою всього 200 мВ на трасі друкованої плати призведе до хибного зчитування сигналу як логічного нуля.

## 3. Точний розрахунок струмообмежувального резистора для LED

Розгляньмо розрахунок номіналу струмообмежувального резистора `R_limit` для індикаторного світлодіода з прямим падінням напруги `V_F` та номінальним струмом `I_LED`.

### Топологія 1: Active-High (Sourcing — живлення від піна)

Світлодіод анодом підключено через резистор `R_limit` до піна GPIO, а катодом — до землі `GND`. Рівняння за другим правилом Кірхгофа:

```
V_DD − I_LED · R_DS(on)_P − I_LED · R_limit − V_F = 0
```

Виражаємо аналітичний вираз для резистора:

```
R_limit = (V_DD − V_F − I_LED · R_DS(on)_P) / I_LED
        = (V_DD − V_F) / I_LED − R_DS(on)_P       [віднімання внутрішнього опору P-MOSFET]
```

**Числовий приклад розрахунку:**
Нехай `V_DD = 3.3 В`, зелений світлодіод із `V_F = 2.1 В`, бажаний робочий струм `I_LED = 5 мА = 0.005 А`, внутрішній опір верхнього плеча `R_DS(on)_P = 35 Ом`.

```
R_limit = (3.3 − 2.1) / 0.005 − 35       [підстановка V_DD, V_F, I_LED та R_DS(on)_P]
        = 1.2 / 0.005 − 35               [падіння напруги на діодно-резистивному колі]
        = 240 − 35                       [повний еквівалентний опір кола]
        = 205 Ом                         [чистий опір зовнішнього резистора]
```

Обираємо найближчий стандартний номінал ряду E24 у бік більшого опору — **220 Ом**. Перевіримо фактичний струм та напругу:

```
I_LED_real = (3.3 − 2.1) / (220 + 35)    [закон Ома з урахуванням R_limit та R_DS(on)_P]
           = 1.2 / 255                   [ділення напруги на сумарний опір 255 Ом]
           ≈ 0.0047 А = 4.71 мА          [фактичний робочий струм діода]
V_OH_real  = 3.3 − 0.00471 · 35          [напруга високого рівня під навантаженням]
           = 3.3 − 0.165
           ≈ 3.135 В                     [просідання вихідної напруги на 165 мВ]
```

### Топологія 2: Active-Low (Sinking — стік у пін)

Світлодіод анодом підключено до шини `V_DD`, а катодом через `R_limit` — до піна GPIO. При виведенні логічного «0» N-MOSFET відкривається і замикає коло на землю:

```
V_DD − V_F − I_LED · R_limit − I_LED · R_DS(on)_N = 0
```

Аналітичний вираз:

```
R_limit = (V_DD − V_F) / I_LED − R_DS(on)_N
```

При тих самих умовах (`V_DD = 3.3 В`, `V_F = 2.1 В`, `I_LED = 5 мА`), але з `R_DS(on)_N = 22 Ом`:

```
R_limit = 240 − 22                       [віднімання меншого опору N-MOSFET]
        = 218 Ом                         [теоретичний опір резистора]
```

Обираємо стандартний номінал **220 Ом**. Фактичний струм і напруга:

```
I_LED_real = 1.2 / (220 + 22)            [закон Ома для кола з N-MOSFET]
           = 1.2 / 242                   [ділення на сумарний опір 242 Ом]
           ≈ 4.96 мА                     [фактичний робочий струм діода]
V_OL_real  = 0.00496 · 22                [підйом потенціалу низького рівня]
           ≈ 0.109 В                     [підйом на 109 мВ відносно GND]
```

Порівняння показує: завдяки меншому опору N-MOSFET схема Sinking забезпечує вищий ККД, менше нагрівання кристала та стабільніший струм.

## 4. Динамічні втрати та перезаряджання ємності навантаження

Коли вивід перемикається з частотою `f_sw` на ємнісне навантаження `C_L` (траса друкованої плати, вхідні ємності приймачів, кабель), кожен цикл перемикання супроводжується зарядом і розрядом конденсатора.

Енергія, що відбирається від джерела живлення за один цикл заряду:

```
E_cycle = C_L · V_DD²                    [повна енергія заряду конденсатора за цикл]
```

Рівно половина цієї енергії `0.5 · C_L · V_DD²` розсіюється у вигляді тепла на внутрішньому опорі P-MOSFET під час заряду, а друга половина накопичується в електричному полі ємності і розсіюється на N-MOSFET під час розряду на землю.

Середня динамічна потужність розсіювання вихідного каскаду становить:

```
P_dyn = C_L · V_DD² · f_sw               [динамічна потужність перемикання]
```

**Числовий приклад:**
Вивід тактує лінію SPI з частотою `f_sw = 20 МГц` (`20·10⁶ Гц`) на ємність навантаження `C_L = 50 пФ` (`50·10⁻¹² Ф`) при `V_DD = 3.3 В`:

```
P_dyn = 50·10⁻¹² · (3.3)² · 20·10⁶        [підстановка параметрів лінії]
      = 50·10⁻¹² · 10.89 · 20·10⁶
      = 10.89 · 10⁻³ Вт
      ≈ 10.89 мВт                        [динамічне тепловиділення лише одного піна]
```

Якщо мікроконтролер одночасно перемикає 8 швидкісних ліній шини пам'яті або дисплея, динамічне тепловиділення лише вихідних буферів сягає майже `88 мВт`, що можна порівняти зі споживанням усього обчислювального ядра.

## 5. Розрахунок захисного резистора від струмів інжекції

Коли на вхідний вивід може потрапити зовнішня напруга `V_in`, що перевищує напругу живлення `V_DD` (наприклад, 5-вольтовий сигнал на 3.3-вольтовий не-FT вивід), прямий струм через верхній захисний ESD-діод обмежують послідовним захисним резистором `R_prot`.

Рівняння кола струму інжекції:

```
V_in − I_INJ · R_prot − V_diode − V_DD = 0
```

Виражаємо мінімально допустимий номінал захисного резистора з умови неперевищення максимального струму інжекції `I_INJ_max ≤ 2 мА` (безпечний запас при паспортному ліміті 5 мА):

```
R_prot_min = (V_in − V_DD − V_diode) / I_INJ_max
```

**Числовий розрахунок для сигналу 5 В на пін 3.3 В:**
Нехай `V_in = 5.0 В`, `V_DD = 3.3 В`, пряме падіння на ESD-діоді `V_diode = 0.6 В`, максимальний допустимий струм `I_INJ = 1.0 мА = 0.001 А`.

```
R_prot_min = (5.0 − 3.3 − 0.6) / 0.001    [чисельник: надлишкова напруга 1.1 В]
           = 1.1 / 0.001
           = 1100 Ом = 1.1 кОм           [мінімальний захисний опір]
```

Обираємо стандартний номінал **2.2 кОм** або **4.7 кОм**. При резисторі `4.7 кОм` струм інжекції складе:

```
I_INJ_real = 1.1 В / 4700 Ом
           ≈ 0.000234 А = 0.234 мА        [у 20 разів нижче межі небезпеки]
```

Цей розрахунок підтверджує, що простий послідовний резистор надійно захищає кристал від струмів інжекції та запобігає виникненню тиристорної защіпки *(Latch-Up)*.
