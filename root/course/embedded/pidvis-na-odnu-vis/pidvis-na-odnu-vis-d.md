# Підвіс на одну вісь: IMU, ПІД, серво

<preknowlist>
- [Дискретний ПІД](root:com-signal/discrete-pid) — пропорційно-інтегрально-диференціальний закон регулювання у дискретному часі.
- [Комплементарний фільтр](root:com-signal/complementary-filter) — злиття низькочастотного акселерометра та високочастотного гіроскопа.
- [IMU-давач](root:hw-sensing/imu) — шість ступенів свободи: три осі лінійного прискорення та три осі кутової швидкості.
- [Протокол RC-сервоприводів](root:com-devices/pwm-servo-protocol) — керування положенням вала імпульсами шпаруватості 1.0–2.0 мс на частоті 50 Гц.
</preknowlist>

Оптична вісь камери або промінь далекоміра, встановлений на рухомому апараті, відхиляється від горизонту за кожним поштовхом рами: кутове збурення амплітудою всього 5° на відстані ста метрів зміщує пляму огляду майже на дев'ять метрів. Якщо закріпити корисне навантаження на жорсткій стійці, будь-яка вібрація двигунів та крен корпусу безпосередньо передаються на оптику. Щоб утримати цільовий напрямок нерухомим у просторі незалежно від коливань носія, застосовують активний стабілізуючий підвіс (англ. *gimbal*, від давньофранцузького *gemel* — «близнюк», латинського *gemellus*). Найпростіший і водночас фундаментальний варіант такої системи — одноосьовий шарнір, де мікроконтролер замкнено узгоджує покази інерційного давача з положенням виконавчого електроприводу.

На перший погляд, завдання здається тривіальним: виміряти нахил платформи, відняти його від нуля та повернути мотор на ту саму величину у зворотний бік. Проте спроба реалізувати таку пряму схему розбивається об фізику: акселерометр у русі реагує на лінійні прискорення й вібрації, гіроскоп безперервно накопичує дрейф інтегрування, редуктор сервоприводу вносить люфт і фазову затримку, а нелінійне насичення приводу викликає катастрофічне роздування інтегральної ланки регулятора. Стійка та швидка стабілізація виникає лише тоді, коли механіка, частотне злиття сигналів і нелінійні захисти регулятора спроєктовані як єдиний узгоджений мехатронний вузол.

*Мехатроніка та потік сигналів одноосьового підвісу. Платформа шарнірно спирається на підшипникові вузли рами. IMU встановлено безпосередньо на стабілізованому майданчику (Direct Sensing), замикаючи повний контур зворотного зв'язку за горизонтом. Керівний контролер вираховує кутову похибку та формує сигнал ШІМ для компенсаційного повороту сервоприводу.*

## 1. Мехатроніка стабілізуючого підвісу: сенсор, шарнір та виконавчий привід

Кінематика одноосьової системи розглядається у площині обертання відносно нерухомої інерційної системи відліку (світовий горизонт). Нехай кут нахилу базової рами носія відносно горизонту дорівнює `θ_base`, абсолютний кут платформи з корисним вантажем — `θ_load`, а кут взаємного повороту між базою та валом приводу — `θ_act`. Геометричний зв'язок між цими величинами виражається сумою:

```
θ_load = θ_base + θ_act
```

Мета системи стабілізації полягає в утриманні платформою постійного заданого кута `θ_target` (зазвичай нульового кута горизонту `θ_target = 0°`) за наявності довільного зовнішнього збурення `θ_base(t)`. Отже, ідеальний виконавчий привід у кожен момент часу повинен відпрацьовувати кут:

```
θ_act = θ_target - θ_base
```

Динаміка обертання платформи з корисним вантажем описується диференціальним рівнянням другого порядку відносно моменту інерції `J` навколо осі підшипника:

```
J · d²(θ_load)/dt² + B · d(θ_load)/dt = M_act - M_gravity - M_disturb
```

де `B` — коефіцієнт в'язкого тертя у підшипниках шарніра, `M_act` — крутний момент, що розвивається приводом, `M_gravity` — момент сили тяжіння через незбалансованість маси, а `M_disturb` — зовнішній аеродинамічний або інерційний момент збурення.

### Топологія розміщення сенсора: Direct Sensing проти Base Sensing

Місце монтажу 6-осьового модуля IMU (англ. *Inertial Measurement Unit*, від латинського *inertia* — «бездіяльність, спокій» та *mensura* — «вимір») визначає архітектуру всього контуру керування. Існують дві принципово різні конфігурації:

1. **Сенсор на платформі (Direct Closed-Loop Sensing):**
   Модуль IMU закріплено безпосередньо на стабілізованій платформі з корисним навантаженням. Сенсор вимірює не збурення бази, а безпосередньо вихідну величину `θ_load` та її кутову швидкість `ω_load`. Будь-яка неточність передачі редуктора, пружна деформація кріплення чи прослизання муфти потрапляють усередину петлі зворотного зв'язку і автоматично компенсуються регулятором. Це класичне замикання контуру за відхиленням. Головна плата за це рішення — динамічна затримка: регулятор дізнається про зовнішній поштовх лише тоді, коли цей поштовх уже встиг зрушити саму платформу.
2. **Сенсор на базі носія (Feedforward / Base Sensing):**
   IMU встановлено на зовнішній рамі апарата й вимірює кут `θ_base`. Контролер працює за принципом прямого компенсаційного зв'язку (англ. *feedforward*): щойно корпус нахилився на +10°, мотор негайно повертається на −10°. Така схема реагує значно швидше, оскільки не чекає наростання похибки на вантажі. Проте вона абсолютно «сліпа» до внутрішніх дефектів приводу: якщо сервопривід має люфт або нелінійність передаточної характеристики, платформа ніколи не стане в ідеальний горизонт, бо датчик не бачить кінцевого положення вантажу. Для точної роботи цієї схеми потрібен прецизиційний абсолютний енкодер безпосередньо на осі вала.

У компактних прикладних стендах стандартом є саме **Direct Sensing**: монтаж IMU на стабілізованій платформі гарантує утримання абсолютного горизонту без потреби у дорогих кутових енкодерах.

### Вибір приводу: хобі-сервопривід проти безколекторного прямого приводу

Виконавчий привід (англ. *actuator*, від латинського *actuare* — «приводити в дію») є найбільш інерційною ланкою системи. В інженерній практиці одноосьових систем застосовують два типи приводу:

```
+──────────────────────────+────────────────────────────────+────────────────────────────────+
| Параметр                 | Хобі-сервопривід (RC Servo)    | BLDC Gimbal Motor (FOC)        |
+──────────────────────────+────────────────────────────────+────────────────────────────────+
| Принцип передачі руху    | Колекторний мотор + редуктор   | Прямий привід (Direct Drive)   |
| Наявність люфту          | Присутній (0.3°–1.5°)          | Повна відсутність люфту (0°)   |
| Інтерфейс керування      | ШІМ 50–330 Гц (1000–2000 мкс)  | 3-фазний векторний міст / FOC  |
| Внутрішній контур        | Власний аналоговий/цифровий ПІД| Повний доступ до струму/моменту|
| Динамічна смуга (Band)   | Низька (5–15 Гц)               | Висока (50–150 Гц)             |
| Маса та вартість         | Низька маса, бюджетне рішення  | Потребує енкодера та FOC-драйв.|
+──────────────────────────+────────────────────────────────+────────────────────────────────+
```

Для класичного хобі-сервоприводу (від латинського *servus* — «слуга, помічник») кут повороту задається тривалістю імпульсу стандартного протоколу ШІМ: імпульс тривалістю 1.5 мс відповідає центру (0°), 1.0 мс — лівому крайньому положенню (−45° або −90°), а 2.0 мс — правому крайньому положенню (+45° або +90°). Вбудований контролер сервоприводу самостійно відпрацьовує положення за допомогою внутрішнього потенціометра. Проте редуктор сервоприводу вносить **мертву зону** (англ. *deadband*) та **люфт** (англ. *backlash*): поки похибка регулятора менша за зону нечутливості, вихідний вал не рухається. Щойно похибка зростає, мотор рушає з місця ривком. Це фундаментальне обмеження вимагає обережного налаштування коефіцієнтів ПІД.

Безколекторні мотори прямого приводу (BLDC Gimbal Motors) позбавлені редуктора: ротор із великою кількістю полюсів (типово 14–24 полюси) з'єднано безпосередньо з віссю платформи. Такий мотор вимагає швидкого векторного керування (FOC) та зовнішнього магнітного енкодера, забезпечуючи абсолютно безшумний, безлюфтовий відгук із мілісекундною реакцією.

### Механічне балансування мас

Найбільш підступна помилка під час конструювання підвісу — ігнорування статичного балансування. Якщо центр мас платформи `CoM` зміщений відносно осі обертання підшипника на відстань `r_cm`, сила тяжіння `m · g` створює паразитичний гравітаційний момент:

```
M_gravity = m · g · r_cm · sin(θ_load)
```

При відхиленні платформи на кут `θ_load` цей момент намагається перекинути систему. Щоб компенсувати його, привід змушений постійно розвивати зустрічний крутний момент, споживаючи струм у статиці та нагріваючи обмотки. Що ще гірше — незбалансований вантаж перетворює лінійну вібрацію основи на кутове коливання платформи. Тому механічне регулювання положення батареї чи камери до досягнення стану байдужої рівноваги (`r_cm → 0`) є обов'язковою передумовою стабільної роботи алгоритмів.

> 🔧 **Навіщо це.** Ідеально збалансований підвіс залишається у будь-якому заданому куті навіть при повністю знеструмленому моторі. Це знімає статичне навантаження з інтегральної ланки регулятора, запобігає перегріву сервоприводу та збільшує час автономної роботи системи від акумулятора в рази.

## 2. Комплементарна фільтрація: злиття гіроскопа та акселерометра

Для точного керування приводом необхідно щомиті знати дві величини: поточний кут нахилу `θ_load` та поточну кутову швидкість `ω_load`. 6-осьовий IMU містить два тривісні сенсори: мікроелектромеханічний гіроскоп (від грецького *gyros* — «коло, оберт» та *skopeo* — «спостерігаю») та акселерометр (від латинського *accelero* — «прискорюю» та грецького *metron* — «міра»).

Жоден із цих сенсорів не здатен видати чистий кут самостійно:

1. **Гіроскоп** вимірює кутову швидкість обертання `ω_meas(t)`. Він має високу динамічну смугу (до сотень герц) і не чутливий до лінійних поштовхів. Щоб отримати кут, кутову швидкість необхідно інтегрувати в часі: `θ(t) = ∫ ω(t) dt`. Проте сирий сигнал гіроскопа неминуче містить постійне зміщення нуля (англ. *zero-rate bias*) `b(t)` та випадковий шум `η_g(t)`:

```
ω_meas(t) = ω_true(t) + b(t) + η_g(t)
```

Навіть якщо зміщення складає всього 0.5°/с, за одну хвилину чисте інтегрування накопичить похибку у 30°, а за десять хвилин — розгорне систему на повне коло.

2. **Акселерометр** вимірює питому силу (вектор уявного прискорення), яка у стані спокою складається виключно з реакції опори проти сили тяжіння Землі `g ≈ 9.81 м/с²`. Якщо вісь обертання підвісу збігається з віссю `X`, кут нахилу платформи визначається тригонометричним співвідношенням проєкцій вектора тяжіння на осі `Y` та `Z`:

```
θ_acc = atan2(a_y, a_z)
```

Акселерометр не має накопичувального дрейфу: його середнє значення на довгому інтервалі часу строго вказує на центр Землі. Проте під час руху апарата сенсор вимірює повне прискорення `a_meas = g + a_linear + a_vib`. Лінійні прискорення маневру та високочастотна вібрація мотора повністю спотворюють миттєвий вектор, генеруючи фальшиві стрибки кута.

*Частотна структура комплементарного фільтра. Сигнал гіроскопа проходить крізь високочастотний тракт (дискретне інтегрування з коефіцієнтом довіри α), а сигнал акселерометра — крізь низькочастотний тракт (1 − α). Їхня сума відновлює повний спектр кута орієнтації без накопичення дрейфу нуля та без високочастотного тремтіння.*

### Математичне виведення дискретного комплементарного фільтра

Комплементарний фільтр (від латинського *complementum* — «доповнення») поєднує сильні сторони обох сенсорів за принципом частотного поділу: швидкі кутові рухи беруться з інтеграла гіроскопа (High-Pass Filter), а повільна абсолютна прив'язка до горизонту береться з акселерометра (Low-Pass Filter).

У безперервному частотному просторі Лапласа оцінка кута `θ̂(s)` записується через передавальні функції:

```
θ̂(s) = [ s / (s + ω_c) ] · (1/s · ω(s))  +  [ ω_c / (s + ω_c) ] · θ_acc(s)
```

Сума двох передавальних функцій тотожно дорівнює одиниці на всіх частотах:

```
[ s / (s + ω_c) ] + [ ω_c / (s + ω_c) ]
= (s + ω_c) / (s + ω_c)      [зведення дробів до спільного знаменника]
= 1                          [скорочення чисельника й знаменника: смуга пропускання ідеальна]
```

Для реалізації у прошивці мікроконтролера з фіксованим періодом дискретизації `Δt` записується різницеве рівняння першого порядку:

```
θ_filt[k] = α · (θ_filt[k-1] + ω[k] · Δt) + (1 - α) · θ_acc[k]
```

де `ω[k] = ω_raw[k] - b_0` — кутова швидкість із віднятим початковим калібрувальним зсувом.

Зв'язок безрозмірного коефіцієнта фільтрації `α` зі сталою часу зрізу `τ` та частотою поділу `f_c` визначається через перехід до експоненційного згладжування:

```
α = τ / (τ + Δt)
```

де стала часу `τ = 1 / (2 · π · f_c)`.

**Числовий розрахунок робочої точки фільтра:**
Нехай такт контуру стабілізації виконується на частоті 200 Гц (`Δt = 0.005 с`). Обираємо частоту зрізу `f_c = 0.32 Гц` (відповідна стала часу `τ ≈ 0.5 с`). Це означає, що будь-яким коливанням, швидшим за 0.5 секунди, фільтр довіряє за гіроскопом, а повільнішим змінам — за акселерометром:

```
τ = 1 / (2 · π · 0.32) ≈ 0.4974 с
α = 0.4974 / (0.4974 + 0.005)
  = 0.4974 / 0.5024
  ≈ 0.99005
```

Коефіцієнт `α = 0.99` означає, що на кожному такті оцінка на 99% спирається на внутрішній інтеграл гіроскопа і лише на 1% підтягується до вектора акселерометра. За один крок (5 мс) 1% корекції не здатний пропустити високочастотний удар чи вібрацію, проте за двісті тактів (1 секунда) сумарна дія поправки повністю ліквідує дрейф нуля гіроскопа.

### Температурний дрейф та статична похибка кута

Якщо зсув нуля гіроскопа зазнає температурного дрейфу під час роботи на величину `Δb` (°/с), комплементарний фільтр набуває залишкової статичної похибки кута `Δθ_static`. Рівновага настає, коли поправка від акселерометра точно компенсує швидкість дрейфу:

```
(1 - α) · Δθ_static = α · Δb · Δt
```

Звідси при `α = τ / (τ + Δt)` отримуємо:

```
Δθ_static = Δb · τ = Δb / (2 · π · f_c)
```

Якщо нескомпенсований дрейф становить `Δb = 1.0°/с`, а стала часу `τ = 0.5 с`, платформа стабілізується з постійним перекосом у `0.5°`. Зменшення сталої часу `τ` (збільшення довіри до акселерометра) зменшує статичний перекіс від дрейфу, але пропускає більше механічної вібрації. Тому процедура точного калібрування зсуву нуля гіроскопа перед стартом залишається критичною.

### Гравітаційний строб (g-force gating)

Коли носій виконує різкий лінійний розгін або зазнає сильного удару, модуль вектора виміряного прискорення `|a| = √(a_x² + a_y² + a_z²)` значно відхиляється від константи земного тяжіння `g ≈ 1.0 g`. У цей момент показам акселерометра не можна довіряти взагалі.

У бойових прошивках застосовують адаптивне стробування:

```
якщо | |a| - 1.0g | < 0.15g :
    α_eff = α             [система у квазістатиці, довіряємо акселерометру]
інакше:
    α_eff = 1.0           [сильний маневр/удар: вимикаємо акселерометр, суто гіроскоп]
```

Це запобігає «завалюванню» горизонту під час розгону або вібраційного навантаження.

## 3. ПІД-стабілізація кута: компенсація збурень та Anti-Windup

Отримавши надійну та гладку оцінку кута `θ_filt[k]`, мікроконтролер обчислює сигнал керування для приводу. Контур стабілізації горизонту підтримує задане значення `θ_target = 0°`.

Похибка керування на такті `k` дорівнює:

```
e[k] = θ_target - θ_filt[k] = -θ_filt[k]
```

![Повна структура замкненого контуру стабілізації підвісу: формувач уставки, ПІД-регулятор із затисканням Anti-Windup та фільтрацією похідної, обмеження ШІМ, механіка шарніра та зворотний зв'язок IMU](/root/course/embedded/pidvis-na-odnu-vis/img/gimbal-control-loop.svg)
*Функціональна схема контуру стабілізації. Сигнал похибки e[k] надходить на паралельні ланки регулятора. Інтегратор охоплено логікою динамічного затискання (Clamping Anti-Windup) для запобігання перенасиченню при упорах. Диференціальна ланка спирається на чисту швидкість гіроскопа через ФНЧ. Сумарний вихід обмежується за діапазоном ШІМ і керує шарніром.*

### Роль складових класичного ПІД-регулятора

1. **Пропорційна ланка (`P = K_p · e[k]`):**
   Формує відновлювальний момент, пропорційний куту відхилення. Працює подібно до віртуальної торсіонної пружини: чим сильніше нахилився вантаж, тим жорсткіше привід тягне його назад. Збільшення `K_p` прискорює реакцію системи та зменшує динамічну помилку, але надмірний коефіцієнт призводить до високочастотного автоколивання всього підвісу.
2. **Диференціальна ланка (`D`):**
   Формує демпфуючий момент, пропорційний швидкості зміни кута. Працює подібно до віртуального гідравлічного демпфера: створює опір будь-якому швидкому руху, гасячи закидання та коливання, спричинені пропорційною ланкою.
3. **Інтегральна ланка (`I`):**
   Накопичує похибку в часі: `I[k] = I[k-1] + K_i · e[k] · Δt`. Необхідна для усунення статичної похибки, викликаної гравітаційним моментом незбалансованого вантажу або сухим тертям спокою в підшипнику. Навіть при мікроскопічному відхиленні 0.2°, якого недостатньо для подолання тертя пропорційною ланкою, інтегратор поступово накопичує зусилля, поки привід нарешті не зрушить вал у точний нуль.

### Проблема Integrator Windup та механізм динамічного затискання (Clamping)

Сервопривід або мотор мають фізичні обмеження: максимальний кут повороту шарніра (наприклад, ±45°) та максимальну швидкість обертання вала. Коли носій підвісу зазнає різкого нахилу на +60°, привід миттєво повертається на свій механічний упор −45° і зупиняється.

У цей момент система переходить у розімкнений стан: кутова похибка `e = -15°` продовжує існувати, бо привід фізично не може нахилитися сильніше. Якщо інтегратор продовжує підсумовувати похибку за стандартною формулою, значення `I[k]` починає стрімко роздуватися (явище **Integrator Windup**, від англійського *wind up* — «заводити пружину до упору»).

Коли носій нарешті повертається у нормальне положення, регулятор повинен негайно повернути вал у центр. Проте роздутий до гігантських значень інтегратор утримує команду насичення. Системі потрібні кілька секунд зворотного руху, щоб інтегратор «розрядився». У результаті підвіс пролітає повз горизонт у протилежний бік із величезним перерегулюванням (overshoot) або входить у тривалі коливання.

![Динаміка регулятора при насиченні приводу: порівняння катастрофічного роздування інтегратора без захисту та миттєвого відновлення при використанні Clamping Anti-Windup](/root/course/embedded/pidvis-na-odnu-vis/img/anti-windup-clamping.svg)
*Порівняння реакції контуру керування. Ліворуч: без захисту інтегральна ланка роздувається під час упору, викликаючи глибокий провал і запізнілий вихід із насичення. Праворуч: алгоритм Clamping Anti-Windup миттєво заморожує підсумовування інтегратора при досягненні межі виходу, якщо похибка діє у бік насичення, гарантуючи негайне повернення до горизонту.*

Для усунення цього дефекту застосовують алгоритм **динамічного затискання інтегратора (Conditional Integration / Clamping Anti-Windup)**.

Алгоритм виконує перевірку на кожному такті:

```
u_tentative = P + I_prev + D

якщо u_tentative > U_MAX або u_tentative < U_MIN :
    привід_у_насиченні = true
інакше:
    привід_у_насиченні = false

якщо привід_у_насиченні І (u_tentative · error > 0) :
    I_new = I_prev          [заморожуємо інтегрування: похибка лише погіршує перенасичення]
інакше:
    I_new = I_prev + Ki · error · Δt   [штатне накопичення інтеграла]
```

Умова `u_tentative · error > 0` перевіряє знак: якщо вихід уже зашкалив у плюс, а похибка теж додатна, інтегрувати заборонено. Але якщо вихід у плюсі, а нова похибка від'ємна (носій рушив назад до центру), інтегратор негайно починає розряджатися. Це забезпечує нульову затримку реакції під час виходу з насичення.

## 4. Захист від шуму похідної та налаштування контуру на реальному стенді

Диференціальна ланка ПІД-регулятора призначена реагувати на швидкість зміни помилки. Проте пряма реалізація через скінченні різниці похибки:

```
D_naive[k] = K_d · (e[k] - e[k-1]) / Δt
```

є непридатною для реальних мікроконтролерних систем із кількох причин:

1. **Множення шуму на високу частоту дискретизації:**
   Ділення на малий крок `Δt = 0.005 с` еквівалентне множенню будь-якого високочастотного шуму квантування АЦП на коефіцієнт 200. Якщо шум вимірювання становить всього 0.05°, диференціатор генерує паразитні сплески амплітудою 10°/с, що призводить до постійного шипіння та перегріву моторів.
2. **Удар похідної (Derivative Kick):**
   Якщо оператор або польотний контролер стрибкоподібно змінює цільовий кут `θ_target` (наприклад, перемикає режим з 0° на −20°), вираз `e[k] - e[k-1]` миттєво створює гігантський імпульс, здатний зламати пластиковий редуктор сервоприводу.

### Похідна за вимірюванням (Derivative on Measurement) та ФНЧ

Обидві проблеми вирішуються двома послідовними інженерними кроками:

**Крок 1: Заміна диференціювання помилки виміряною швидкістю гіроскопа.**
Оскільки `θ_target` у задачі стабілізації є постійною або повільною величиною (`d(θ_target)/dt ≈ 0`), похідна від похибки перетворюється на швидкість зміни самої платформи зі зворотним знаком:

```
d(e)/dt = d(θ_target - θ_load)/dt = - d(θ_load)/dt = -ω_load
```

Гіроскоп IMU вже видає апаратну, фізично неперервну кутову швидкість `ω_load` без потреби в чисельному диференціюванні. Тому диференціальну ланку формують безпосередньо з сигналу гіроскопа:

```
D_raw[k] = -K_d · (ω_raw[k] - b_0)
```

Це повністю ліквідує удар Derivative Kick при будь-яких змінах цільового кута.

**Крок 2: Фільтрація похідної фільтром низьких частот (LPF D-term).**
Щоб заблокувати вібраційний шум двигунів, сигнал `D_raw[k]` пропускають крізь дискретний цифровий ФНЧ першого порядку:

```
D_filt[k] = D_filt[k-1] + β · (D_raw[k] - D_filt[k-1])
```

де коефіцієнт згладжування `β` розраховується за частотою зрізу шуму `f_d_cut ≈ 20…30 Гц`:

```
β = Δt / (Δt + RC_d) = Δt / (Δt + 1 / (2 · π · f_d_cut))
```

При `Δt = 0.005 с` та `f_d_cut = 25 Гц` (`RC_d ≈ 0.00637 с`):

```
β = 0.005 / (0.005 + 0.00637) ≈ 0.44
```

Такий фільтр пропускає корисне низькочастотне демпфування кутового руху, але зрізає високочастотний акустичний і вібраційний бруд.

### Інженерна методика налаштування контуру на стенді

Налаштування одноосьового стабілізатора виконується за чіткою послідовністю (варіація методу Зіглера — Ніколса для мехатронних підвісів):

```
Крок 1: Обнулення інтегратора та диференціатора: Ki = 0, Kd = 0.
Крок 2: Поступове збільшення Kp:
        Починаємо з Kp = 0.5. Рукою відхиляємо платформу та відпускаємо.
        Збільшуємо Kp, поки платформа не почне швидко повертатися, але з 1–2 перельотами.
        Якщо з'являється незгасаюче високочастотне тремтіння — Kp надмірний, зменшуємо на 30%.
Крок 3: Введення Kd (демпфування):
        Поступово піднімаємо Kd (починаючи з 0.02).
        Перевіряємо реакцію: відхилена рукою платформа повинна повертатися у центр
        без жодного перельоту (критичне демпфування).
Крок 4: Введення Ki (зняття статичної похибки):
        Повільно піднімаємо Ki (типово 0.2–1.0).
        Перевіряємо утримання горизонту при зміщенні центру ваги або при плавному
        нахилі базової платформи.
```

## 5. Архітектура прошивки та стендовий проєкт

Повний контур стабілізатора реалізується у вигляді періодичної задачі реального часу. Для забезпечення строгого кроку `Δt = 5 мс` (200 Гц) обчислення прив'язуються до апаратного таймера або прапорця готовності даних IMU (Data Ready Interrupt).

Часовий бюджет одного такту (5000 мкс) на типовому мікроконтролері Cortex-M4 розподіляється так:

- Читання 14 байт IMU (акселерометр, термометр, гіроскоп) по шині I2C 400 кГц: ~350 мкс (або ~35 мкс по шині SPI 8 МГц).
- Математика комплементарного фільтра та розрахунок ПІД із плаваючою комою: ~3.5 мкс.
- Оновлення регістру захоплення/порівняння таймера ШІМ сервоприводу: ~0.5 мкс.
- Запас процесорного часу для телеметрії та фільтрації: понад 92%.

Нижче наведено модульний приклад ядра регулятора:

:::tabs
```c
/* ============================================================================
 * gimbal_core.c — Ядро одноосьової стабілізації на C
 * ============================================================================ */

#include <stdint.h>
#include <stdbool.h>
#include <math.h>

#define DT 0.005f  /* 200 Гц */

typedef struct {
    float angle_deg;
    float alpha;
} CompFilter;

typedef struct {
    float kp, ki, kd;
    float out_min, out_max;
    float integrator;
    float d_filter_state;
    float d_lpf_beta;
} GimbalPID;

float comp_filter_step(CompFilter *f, float gyro_rate_dps, float ay, float az) {
    /* 1. Інтегрування гіроскопа */
    float pred = f->angle_deg + gyro_rate_dps * DT;

    /* 2. Нахил за вектором тяжіння */
    float acc_angle = atan2f(ay, az) * (180.0f / 3.14159265f);

    /* 3. Злиття */
    f->angle_deg = f->alpha * pred + (1.0f - f->alpha) * acc_angle;
    return f->angle_deg;
}

float pid_step(GimbalPID *pid, float setpoint, float measured_angle, float gyro_rate_dps) {
    float error = setpoint - measured_angle;
    float p_term = pid->kp * error;

    /* D-терм за гіроскопом з ФНЧ */
    float d_raw = -gyro_rate_dps;
    pid->d_filter_state += pid->d_lpf_beta * (d_raw - pid->d_filter_state);
    float d_term = pid->kd * pid->d_filter_state;

    /* Попередній вихід для перевірки насичення */
    float u_tentative = p_term + pid->integrator + d_term;

    /* Clamping Anti-Windup */
    bool saturated = (u_tentative > pid->out_max || u_tentative < pid->out_min);
    bool same_direction = (u_tentative * error > 0.0f);

    if (!saturated || !same_direction) {
        pid->integrator += pid->ki * error * DT;
    }

    float u_out = p_term + pid->integrator + d_term;
    if (u_out > pid->out_max) u_out = pid->out_max;
    if (u_out < pid->out_min) u_out = pid->out_min;

    return u_out;
}
```
```cpp
// ============================================================================
// GimbalCore.hpp — Ядро одноосьової стабілізації на C++20
// ============================================================================

#include <cmath>
#include <algorithm>
#include <numbers>

namespace gimbal {

inline constexpr float DT = 0.005f; // 200 Гц

class ComplementaryFilter {
public:
    explicit constexpr ComplementaryFilter(float alpha = 0.99f) noexcept
        : alpha_{alpha}, angle_deg_{0.0f} {}

    [[nodiscard]] float update(float gyro_rate_dps, float ay, float az) noexcept {
        const float pred = angle_deg_ + gyro_rate_dps * DT;
        const float acc_angle = std::atan2(ay, az) * (180.0f / std::numbers::pi_v<float>);
        angle_deg_ = alpha_ * pred + (1.0f - alpha_) * acc_angle;
        return angle_deg_;
    }

    [[nodiscard]] constexpr float angle() const noexcept { return angle_deg_; }

private:
    float alpha_;
    float angle_deg_;
};

class PidController {
public:
    struct Config {
        float kp{2.0f};
        float ki{0.5f};
        float kd{0.06f};
        float out_min{-45.0f};
        float out_max{45.0f};
        float d_lpf_beta{0.44f};
    };

    explicit constexpr PidController(const Config& cfg) noexcept : cfg_{cfg} {}

    [[nodiscard]] float update(float setpoint, float measured_angle, float gyro_rate_dps) noexcept {
        const float error = setpoint - measured_angle;
        const float p_term = cfg_.kp * error;

        // D-терм за вимірюванням гіроскопа + ФНЧ
        const float d_raw = -gyro_rate_dps;
        d_filter_state_ += cfg_.d_lpf_beta * (d_raw - d_filter_state_);
        const float d_term = cfg_.kd * d_filter_state_;

        const float u_tentative = p_term + integrator_ + d_term;
        const bool saturated = (u_tentative > cfg_.out_max || u_tentative < cfg_.out_min);
        const bool same_direction = (u_tentative * error > 0.0f);

        if (!saturated || !same_direction) {
            integrator_ += cfg_.ki * error * DT;
        }

        const float u_out = p_term + integrator_ + d_term;
        return std::clamp(u_out, cfg_.out_min, cfg_.out_max);
    }

private:
    Config cfg_;
    float integrator_{0.0f};
    float d_filter_state_{0.0f};
};

} // namespace gimbal
```

## Підсумок інженерних рішень

Побудова надійного одноосьового гіропідвісу спирається на чотири взаємопов'язані механізми:

1. **Прямий зворотний зв'язок (Direct Closed-Loop Sensing):** встановлення IMU безпосередньо на стабілізовану платформу гарантує усунення люфтів та нелінійностей механічної передачі.
2. **Комплементарне розділення частот:** висока динаміка інтегрування гіроскопа відсікає вібраційні завади акселерометра, тоді як низькочастотний вектор тяжіння `g` безупинно утримує довготривалий горизонт без дрейфу.
3. **Derivative on Measurement із низькочастотною фільтрацією:** використання апаратної кутової швидкості гіроскопа замість чисельного диференціювання похибки усуває ударні стрибки регулятора при зміні завдання та запобігає посиленню високочастотного шуму.
4. **Clamping Anti-Windup:** динамічне блокування підсумовування інтегратора під час механічного упору захищає контур від запізнілого виходу з насичення та руйнівного перерегулювання.
