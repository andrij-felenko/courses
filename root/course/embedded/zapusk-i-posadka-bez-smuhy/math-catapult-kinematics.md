# 🧮 Кінематика й динаміка катапультного старту: банджі, пневматика та пікові перевантаження

Головна інженерна суперечність катапульти полягає у виборі між довжиною напрямної рейки `L_rail` та піковим перевантаженням `a_max`. Якщо зробити рейку надто короткою (наприклад, `1.5 м`), для розгону 5-кілограмового літака до безпечної швидкості відриву `V_launch = 18 м/с` знадобиться прискорення понад `11g`, що деформує акумуляторні відсіки, згинає лонжерони крила й перевантажує датчики. Якщо ж подовжити рейку до `5 м`, стартовий комплекс стає громіздким і непридатним для швидкого польового розгортання двома операторами. Розгляньмо аналітичний розрахунок динаміки розгону для двох головних типів приводу: гумового джгута (еластичного банджі) та пневматичного циліндра.

## 1. Енергетичний баланс та необхідна швидкість виходу

Літак на виході з напрямної рейки мусить мати повітряну швидкість `V_launch`, яка перевищує швидкість звалювання `V_stall` щонайменше на 20–30%. Це необхідно для створення запасу керованості по елеронах та керму висоти в умовах можливого попутного пориву вітру або турбулентності біля поверхні землі:

```
V_launch = 1.25 · V_stall
```

Кінетична енергія, яку катапульта має передати рухомій системі масою `M_total = m_plane + m_carriage` (де `m_plane` — маса літака, `m_carriage` — маса стартової каретки), визначається класичним виразом:

```
E_k = ½ · M_total · V_launch²
```

Під час руху каретки по рейці частина енергії безповоротно втрачається на подолання тертя ковзання або кочення каретки по напрямних `F_friction = μ · M_total · g · cos(θ)`, аеродинамічного опору планера `F_drag = ½ · ρ · V² · S · C_D` та подолання гравітаційного підйому вздовж нахилу рейки на кут `θ` (`F_gravity = M_total · g · sin(θ)`). Повна робота рушія катапульти `W_launch` на робочому ході рейки `L_stroke` повинна покривати всі втрати:

```
W_launch
= E_k + W_loss                                          [енергетичний баланс розгону]
= ½·M_total·V_launch² + ∫ (F_friction + F_drag + F_gravity) dx  [розгортання інтегралу втрат]
```

Паразитна маса каретки `m_carriage` відіграє критичну роль. Оскільки каретка розганяється до тієї ж кінцевої швидкості `V_launch`, що й літак, вона забирає на себе частку корисної кінетичної енергії `η_mass = m_plane / (m_plane + m_carriage)`. Якщо 4-кілограмовий літак встановлено на важку сталеву каретку масою 1.5 кг, понад 27% усієї енергії приводу витрачається на розгін каретки, яку наприкінці рейки доводиться екстрено гасити демпферами. Зменшення маси каретки шляхом використання фрезерованого алюмінію або композитів — головний резерв підвищення ефективності катапульти.

## 2. Гумовий джгут (Банджі): розрахунок нелінійної пружності

Латексний або гумовий джгут (bungee cord) на початку розгону розтягнутий на величину `Δx_0 = L_stretch`. У першому наближенні сила натягу підпорядковується закону Гука з еквівалентною жорсткістю `k`, проте в реальних силових гумах присутній гістерезис і нелінійне зростання жорсткості при розтягуванні понад 150–200%.

Сила, прикладена до каретки в поточній точці координати розгону `x` (де `x ∈ [0, L_stroke]`):

```
F_bungee(x) = k · (Δx_0 - x)
```

Інтегруючи силу вздовж робочого ходу рейки `L_stroke`, дістаємо потенціальну енергію натягу, перетворену на роботу:

```
W_bungee
= ∫ F_bungee(x) dx                                      [інтегрування від 0 до L_stroke]
= k · ∫ (Δx_0 - x) dx                                   [винесення коефіцієнта жорсткості]
= k · [Δx_0 · L_stroke - ½ · L_stroke²]                 [первісна полінома]
```

Якщо робочий хід дорівнює повному розтягуванню гуми (`L_stroke = Δx_0`), формула спрощується до класичного вигляду `W = ½ · k · Δx_0²`.

### Пікове перевантаження при старті з гуми

Оскільки сила натягу гуми максимальна в початковий момент (`x = 0`), саме в момент розблокування замка катапульти літак зазнає максимального перевантаження:

```
a_max
= F_bungee(0) / M_total                                 [другий закон Ньютона в точці x = 0]
= (k · Δx_0) / M_total                                  [максимальна сила натягу]
```

Приклад числового розрахунку для розвідувального БПЛА:
- Маса літака з корисним навантаженням `m_plane = 4.5 кг`, маса каретки `m_carriage = 0.5 кг` (`M_total = 5.0 кг`).
- Швидкість звалювання `V_stall = 12.0 м/с`, необхідна швидкість виходу `V_launch = 1.25 · 12.0 = 15.0 м/с`.
- Необхідна кінетична енергія: `E_k = ½ · 5.0 · 15.0² = 562.5 Дж`.
- З урахуванням втрат на тертя каретки (коефіцієнт тертя ковзання фторопластових вкладишів по алюмінію `μ ≈ 0.15`) та нахилу рейки `θ = 12°` загальний ККД розгінного тракту становить `η ≈ 0.80`.
- Повна потрібна енергія натягу: `W_bungee = 562.5 / 0.80 = 703.1 Дж`.
- Довжина робочого ходу рейки: `L_stroke = 2.5 м`, початкове розтягування джгута `Δx_0 = 3.5 м`.

Звідси визначаємо необхідну жорсткість гумового джгута `k`:

```
W_bungee = k · [Δx_0 · L_stroke - ½ · L_stroke²]
703.1 = k · [3.5 · 2.5 - ½ · 2.5²]
703.1 = k · [8.75 - 3.125]
703.1 = k · 5.625
k = 703.1 / 5.625 ≈ 125 Н/м
```

Початкова сила натягу:
```
F_0 = k · Δx_0 = 125 · 3.5 = 437.5 Н  (≈ 44.6 кгс)
```

Пікове прискорення на замку:
```
a_max = F_0 / M_total = 437.5 / 5.0 = 87.5 м/с²  (≈ 8.9g)
```

Це наочно демонструє головний недолік простого гумового приводу: експоненційно-спадний профіль сили створює жорсткий удар `8.9g` на перших міліметрах руху, тоді як наприкінці рейки сила падає до `F_end = 125 · (3.5 - 2.5) = 125 Н (2.5g)`.

## 3. Пневматична катапульта: термодинаміка розширення та рівномірність тяги

Пневматичний привід використовує енергію стисненого повітря в ресивері об'ємом `V_res`, яке через швидкодіючий клапан (quick-exhaust valve з перетином `Ду 25–40 мм`) подається в робочий пневмоциліндр діаметром `D_cyl` та ходом штока `L_cyl`. Для зменшення габаритів циліндра використовується тросовий поліспаст із передаточним числом `N_pulley = 2` або `N_pulley = 4`. При цьому хід каретки зростає у `N_pulley` разів, а тягова сила зменшується у стільки ж:

```
L_stroke = N_pulley · L_cyl
F_carriage = (P(t) · A_piston) / N_pulley
```

де `A_piston = π · D_cyl² / 4` — площа поршня циліндра.

Оскільки розгін триває частки секунди (`0.2–0.3 с`), теплообмін газу зі стінками ресивера та циліндра знехтовно малий. Розширення газу є адіабатичним процесом із показником адіабати для повітря `γ = 1.4`:

```
P(x) · [V_res + A_piston · (x / N_pulley)]^γ = P_0 · V_res^γ
```

Тиск у циліндрі в міру переміщення каретки `x`:

```
P(x) = P_0 · [ V_res / (V_res + A_piston · x / N_pulley) ]^γ
```

Робота газу при розширенні:

```
W_gas
= ∫ P(x) · (A_piston / N_pulley) dx                     [інтегрування тиску по об'єму циліндра]
= [ (P_0 · V_res) / (γ - 1) ] · [ 1 - (V_res / V_final)^(γ - 1) ]  [адіабатична робота газу]
```

### Порівняння перевантажень: банджі проти пневматики

Завдяки наявності ресивера відношення початкового тиску до кінцевого `P_0 / P_final` у пневматиці зазвичай становить `1.2–1.4` (тиск просідає лише на 20–30% до кінця рейки), тоді як у гуми сила падає в 3–4 рази.

```
-------------------------------------------------------------------------
Параметр розгону           Гумовий джгут (Банджі)    Пневматичний циліндр
-------------------------------------------------------------------------
Профіль сили F(x)          Лінійно-спадний           Майже прямокутний (квазісталий)
Пікове перевантаження      a_max ≈ 7g–10g            a_max ≈ 3.5g–5g
Середнє перевантаження     a_avg ≈ 4g–5g             a_avg ≈ 3.2g–4.5g
Коефіцієнт піку a_max/a_avg  1.75–2.0                 1.15–1.25
Вплив температури          Гума дубіє на морозі      Падіння тиску за законом Шарля (P ∝ T)
-------------------------------------------------------------------------
```

## 4. Динаміка перехідного процесу після сходу з каретки

Найнебезпечніший момент катапультного старту настає в перші 100–300 мілісекунд після того, як літак зійшов з каретки, але тяга маршового двигуна ще не вийшла на стаціонарний рівень.

Вектор швидкості на зрізі рейки спрямований під кутом нахилу катапульти `θ`:

```
V_x0 = V_launch · cos(θ)
V_y0 = V_launch · sin(θ)
```

Вертикальна складова швидкості `V_y0` компенсує силу тяжіння на початковій ділянці. Якщо кут нахилу рейки недостатній (наприклад, `θ < 8°`), вертикальна швидкість `V_y0` замала, і літак під дією гравітаційного прискорення просідає вниз раніше, ніж крило створить повну підйомну силу. Траєкторія руху центру ваги літака до підхоплення мотором описується системою:

```
y(t) = y_rail_end + V_y0 · t - ½ · g · t² + ∫ (L(t) / m) dt²
```

Якщо підйомна сила крила на швидкості відриву точно дорівнює вазі (`L = m·g`), літак летить по прямолінійній похилій траєкторії без просідання. Проте якщо швидкість виходу виявилася меншою за розрахункову (`V_launch < V_stall`), виникає від'ємне вертикальне прискорення `a_y = (L - m·g)/m < 0`, яке спричиняє просідання планера (sink depth). Розрахунковий запас за кутом нахилу рейки `θ = 12°–15°` створює початковий вертикальний імпульс `V_y0 = 3.5–5.0 м/с`, що повністю виключає торкання землі навіть за тимчасового падіння підйомної сили при зустрічному пориві вітру.

## 5. Вимоги до часу спрацьовування та інтегрування прискорення

Час розгону літака на рейці розраховується з кінематичних рівнянь руху:

```
t_launch = ∫ dx / V(x) ≈ (2 · L_stroke) / (V_launch + V_0)
```

Для типових значень `L_stroke = 3.0 м` та `V_launch = 18 м/с` (при `V_0 = 0`):

```
t_launch ≈ (2 · 3.0) / 18.0 = 0.33 с
```

Ці 330 мілісекунд визначають жорсткі вимоги до цифрової фільтрації в автопілоті:
1. **Частота опитування IMU:** при частоті `100 Гц` автопілот встигає отримати лише 33 відліки акселерометра за весь час знаходження на рейці. Тому детектор старту повинен працювати на частоті не нижче `400–1000 Гц`.
2. **Динамічний діапазон акселерометра:** при піковому прискоренні `8.9g` типовий діапазон датчика `±4g` або `±8g` перейде в режим апаратного насичення (saturation clip). Насичення спотворює інтеграл швидкості в навігаційному фільтрі EKF. Для катапультного старту автопілот повинен перемикати шкалу акселерометра на `±16g` або `±32g` перед зведенням замка катапульти.
3. **Демпфування гальмування каретки:** наприкінці робочого ходу рейки каретка на швидкості 18 м/с мусить бути зупинена на дистанції демпфування `s_brake = 0.15–0.25 м`. Гідравлічні або поліуретанові буфери катапульти зазнають уповільнення `a_brake = V² / (2 · s_brake) ≈ 65g–100g`. Механічний замок відділення літака від каретки повинен мати форму розімкнених напрямних штирів, спрямованих строго вперед-вгору, щоб при раптовій зупинці каретки літак вільно продовжував політ за інерцією, не отримуючи зворотного ривка через заклинювання фіксаторів.
