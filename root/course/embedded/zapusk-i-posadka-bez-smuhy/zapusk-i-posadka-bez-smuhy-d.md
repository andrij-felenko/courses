Злітно-посадкова смуга дає літаку простір для поступового розгону на колесах шасі до швидкості відриву й довгу дистанцію для розсіювання кінетичної енергії гальмами під час пробігу. У польових умовах — на розкислій ріллі, у лісосмузі, серед міської забудови чи на палубі катера — смуги немає. Безпілотний літак мусить розігнатися від нуля до швидкості вище за швидкість звалювання `V_stall` на дистанції від одного до трьох метрів за частки секунди, а повернутися на землю без коліс і стійок амортизаторів, контактуючи днищем фюзеляжу безпосередньо з ґрунтом.

Помилка оператора чи алгоритму автопілота на зльоті всього на 2 м/с призводить до того, що багатокілограмовий апарат зривається в звалювання й б'ється об землю, не встигнувши набрати керованість. На посадці ж необережний дотик обертового пропелера до ґрунту миттєво згинає гартований сталевий вал безколекторного двигуна, вириває мотораму або випалює силові ключі регулятора швидкості (ESC) через струм короткого замикання заблокованого ротора. Експлуатація без смуги — це комплексна інженерна задача, де аеродинаміка звалювання жорстко переплітається з механікою імпульсних навантажень, алгоритмами цифрової фільтрації акселерометрів та автоматами станів польотного контролера.

## 1. Фізичний бар'єр: підйомна сила на нульовій швидкості

Коли літак стоїть на старті, швидкість обтікання крила повітрям дорівнює нулю (`V = 0`). Оскільки аеродинамічна [підіймальна сила крила](root:ph-mechanics/fixed-wing-lift) пропорційна квадрату швидкості:

```
L = ½ · ρ · V² · S · C_L
```

на старті підйомна сила суворо дорівнює нулю (`L = 0`). Силі тяжіння `m·g` у цей момент нічого не протистоїть, якщо тільки тяга силової установки не перевищує вагу літака (`T/W > 1.0`), як у ракети чи 3D-пілотажної моделі. Для класичних літаків та планерів тягоозброєність зазвичай становить `T/W = 0.35–0.60`. Це означає, що двигун не здатний утримати літак вертикально на гвинті: апарат обов'язково повинен рухатися вперед, щоб крило почало створювати підйомну силу.

Мінімальна швидкість, на якій крило з площею `S` та максимальним коефіцієнтом підйомної сили `C_L_max` здатне компенсувати вагу `m·g`, називається [швидкістю звалювання](root:ph-mechanics/navantazhennia-na-krylo-i-shvydkist-zvaliuvannia) `V_stall`:

```
V_stall = √( (2 · m · g) / (ρ · S · C_L_max) )
```

Поки швидкість літака `V < V_stall`, він фізично перебуває в стані вільного падіння по балістичній траєкторії, причому будь-яка спроба автопілота задерти ніс кермом висоти лише збільшує кут атаки понад критичний `α_crit`, провокуючи зрив потоку й миттєве звалювання на крило. Більше того, ефективність елеронів та рулів також пропорційна швидкісному напору `q = ½·ρ·V²`: на малій швидкості апарат практично некерований по крену.

Тому будь-який спосіб старту без смуги має єдину фізичну мету: надати літаку початкову безпечну швидкість `V_launch ≥ 1.2 · V_stall` раніше, ніж він втратить висоту під дією сили тяжіння, і втримати нульовий крен, доки крило не вийде на стабільний режим польоту.

## 2. Старт з руки (Hand Launch): біомеханіка та алгоритми автопілота

Старт з руки — найпростіший і наймобільніший спосіб запуску літаків масою до 2.5–3.5 кг із помірним навантаженням на крило (`m/S < 45 г/дм²`) та швидкістю звалювання `V_stall ≤ 10–11 м/с`. Усе стартове обладнання зводиться до рук оператора, що робить розгортання миттєвим. Проте цей спосіб містить два критичні ризики: людський фактор під час кидка та смертельну небезпеку штовхаючого пропелера для пальців.

### Геометрія та кінематика кидка

Людина під час енергійного помаху рукою здатна розігнати 3-кілограмовий планер до горизонтальної швидкості `V_throw = 8–12 м/с` на дистанції розмаху `1.2–1.8 м`. Якщо швидкість звалювання літака становить `V_stall = 10 м/с`, кидок на швидкості `10 м/с` перебуває на самій межі зриву.

Ключовим параметром є **кут кидка (Launch Pitch)**:
- **Занадто крутий кидок (Pitch > 25°):** літак швидко втрачає кінетичну енергію кидка на подолання гравітації, швидкість падає нижче `V_stall`, кут атаки перевищує критичний, і планер завалюється на крило (stall spin) на висоті 2–3 метри над землею, де автопілот не встигає зреагувати.
- **Пологий або спрямований вниз кидок (Pitch < 5°):** до моменту, коли тяга двигуна розжене літак, він просідає під дією гравітації на величину `h_drop = ½ · g · t²`. Затримка підхоплення всього на `0.4 с` дає просідання `h = ½ · 9.81 · 0.16 ≈ 0.8 м`, що за початкової висоти кидка з плеча (`1.6 м`) призводить до черкання крилом чи черевом об траву.
- **Оптимальний кут:** кидок виконується суворо проти вітру з нахилом тангажу **12°–18°** відносно горизонту. Зустрічний вітер зі швидкістю `V_wind = 4–6 м/с` безпосередньо додається до швидкості кидка, забезпечуючи початкову повітряну швидкість `V_air = V_throw + V_wind = 14–17 м/с`, що повністю знімає ризик звалювання.

### Небезпека штовхаючого гвинта (Pusher Propeller)

Більшість польових літаків і літаючих крил будуються за схемою зі штовхаючим гвинтом, розташованим у хвостовій частині. Це захищає камеру та мотор при посадці на черево. Проте під час ручного старту рука оператора, яка тримає літак за нижній кіль чи спеціальне заглиблення у фюзеляжі, у момент випуску планера опиняється рівно в площині обертання пропелера.

Якщо мотор увімкнений на повну тягу ще до кидка, жорсткий карбоновий пропелер, що обертається зі швидкістю 12 000–18 000 об/хв, завдає глибоких різаних травм кисті та пальців у момент вислизання фюзеляжу з руки. Спроби запускати літак із працюючим мотором вимагають специфічного бокового хвату за консоль крила з розкручуванням корпусу («дисковий запуск» / DLG), що для важких апаратів створює небезпечний несиметричний момент крену в момент відриву.

Єдиним надійним інженерним рішенням є **автоматичний старт мотора за даними сенсорів (Auto-Takeoff / Shake-to-Arm)**.

### Алгоритм автоматичного розпізнавання кидка (Throw Detection)

Польотний контролер, що перебуває в режимі очікування старту, безперервно зчитує показання трьохосьового [акселерометра IMU](root:embedded/imu-barometer) на частоті 400–1000 Гц. Процедура автостарту виконує такі кроки:

1. **Очікування помаху:** апарат зазброєний (Armed), але вихідний сигнал на [регулятор швидкості ESC](root:embedded/esc-bldc-driver) заблокований на нулі (`throttle = 0%`).
2. **Детектування прискорення розгону:** під час помаху руки поздовжнє прискорення вздовж осі літака `a_x` зростає понад поріг `a_trig = 1.8g–2.5g` і утримується протягом щонайменше `Δt = 50–80 мс`. Це відсікає випадкові короткі струшування при ходьбі чи коригуванні хвату.
3. **Детектування моменту вильоту (Release / Zero Jerk):** у момент, коли пальці відпускають корпус, прискорення `a_x` різко падає, а модуль нормального перевантаження наближається до невагомості (`|a| ≈ 1.0g` або менше).
4. **Захисна затримка (Throttle Delay):** таймер автопілота відраховує `t_delay = 200–400 мс`. За цей час літак, рухаючись за інерцією зі швидкістю 11 м/с, віддаляється від руки оператора на відстань:
   ```
   s_safe = V_throw · t_delay = 11.0 · 0.3 = 3.3 м
   ```
5. **Плавне наростання тяги (Throttle Slew Rate):** після виходу з небезпечної зони автопілот плавно нарощує тягу від 0% до злітної (85–100%) зі швидкістю не більше 200%/с. Плавний старт запобігає різкому перекиданню літака від реактивного моменту пропелера (torque roll).
6. **Утримання горизонту автопілотом (Takeoff Mode):** з моменту розпізнавання кидка контур стабілізації блокує крен на нулі (`roll = 0°`) за допомогою елеронів і тримає кут набору тангажу `pitch = +12°...+15°`. Кермо напряму активно компенсує гіроскопічний момент і косий обдув кіля (P-factor) від розгону гвинта. Режим набору діє до досягнення безпечної висоти (25–30 м) та крейсерської швидкості.

Повну програмну реалізацію драйвера детектора старту наведено в окремому [проєктному розборі детектора запуску на базі IMU](root:embedded/zapusk-i-posadka-bez-smuhy/proj-takeoff-detector.md).

> 🔧 **Навіщо це.** Затримка подачі газу `t_delay` усуває 100% травм рук при старті штовхаючих літаків. Проте якщо встановити затримку завеликою (понад `0.6 с`), літак встигне втратити швидкість і просісти нижче точки старту. Число `250–350 мс` є збалансованим галузевим стандартом для апаратів вагою до 3 кг.

## 3. Катапультний старт: гумовий джгут і пневматична рейка

Коли маса літака перевищує 4–5 кг, або планер оптимізовано під високу крейсерську швидкість (стрілоподібне тонке крило з малим `C_L_max` та високим `V_stall = 15–20 м/с`), м'язової сили людини стає недостатньо. Спроба кинути такий апарат з руки гарантовано призведе до падіння в землю на першому метрі польоту.

Для таких літаків застосовують рейкові катапульти (Launch Rails), де енергія накопичується заздалегідь у пружній деформації гуми або стисненому газі.

### Гумовий джгут (Bungee Launch)

Найбільш автономною польовою катапультою є еластичний джгут із трубчастого латексу або багатожильного авіаційного банджі-шнура. Один кінець джгута фіксується в ґрунті сталевим анкерним кілком, а інший чіпляється до стартової каретки на розбірній алюмінієвій рейці завдовжки `2.5–3.5 м`.

Каретка з літаком відтягується назад і ставиться на механічний спусковий замок (педаль або електромагнітний тригер).
- **Початковий натяг:** силу натягу встановлюють рівною `F_0 = (4–6) · m · g`. Для літака масою 5 кг початкова сила натягу становить `200–300 Н (20–30 кгс)`.
- **Профіль прискорення:** за законом Гука сила натягу лінійно спадає в міру руху каретки вперед `F(x) = k · (Δx_0 - x)`. Це означає, що **максимальне перевантаження діє на літак у першу мілісекунду після відкриття замка**, досягаючи пікових значень `a_max = 6g–10g`, після чого плавно падає до нуля на виході з рейки.
- **Вплив температури:** головний недолік гуми — сильна термозалежність. При падінні температури нижче +5 °C латекс втрачає еластичність («дубіє»), через що робота розгону падає на 30–50%, що вимагає перерахунку довжини натягу або підігріву джгутів у машині перед стартом.

### Пневматична рейка (Pneumatic Launcher)

Для важких комплексів масою від 8 до 30 кг застосовують пневматичні катапульти. Вони складаються зі сталевого або композитного ресивера об'ємом 10–25 л, робочого циліндра високого тиску (6–10 бар), швидкодіючого пневмоклапана великого прохідного перетину та тросового поліспаста (коефіцієнт передачі 1:2 або 1:4), що збільшує хід каретки відносно штока циліндра.

Головна перевага пневматики над гумою — **рівномірний профіль сили**. Завдяки розширенню газу з великого об'єму ресивера тиск у циліндрі під час руху поршня просідає лише на 20–30%. Відповідно, при тому самому кінцевому розгоні `V_launch = 20 м/с` на рейці завдовжки 3 м пікове перевантаження становить усього `3.5g–5g` проти `8g–10g` у гумового джгута. Детальний математичний вивід і порівняння термодинаміки пневматики з пружністю гуми винесено в [математичний розрахунок кінематики катапульти](root:embedded/zapusk-i-posadka-bez-smuhy/math-catapult-kinematics.md).

### Захист бортової електроніки та механіки від стартового удару

Прискорення `6g` означає, що всі внутрішні компоненти апарата стають у 6 разів важчими у напрямку, протилежному до руху:

1. **Акумуляторна батарея:** акумуляторний блок 6S4P із елементів 18650 масою 1.8 кг під дією перевантаження 6g тисне на внутрішню перегородку із силою:
   ```
   F_batt = m_batt · a = 1.8 · (6 · 9.81) ≈ 106 Н (≈ 10.8 кгс)
   ```
   Якщо батарея тримається лише на текстильній стрічці-липучці (Velcro), липучка зрізається, батарея зсуває центр ваги назад або виламує передній шпангоут, зминаючи нікелеві стрічки точкового зварювання. Для катапультних літаків акумуляторний відсік обов'язково оснащують жорстким переднім і заднім упором із фанери чи карбону.
2. **Пробивання демпферів IMU:** більшість польотних контролерів встановлюються на м'які силіконові демпфери для захисту від вібрацій моторів. Під час удару 6g демпфери повністю стискаються до упору («пробиваються»), передаючи жорсткий механічний удар на текстоліт плати.
3. **Насичення акселерометра (Sensor Saturation):** якщо в налаштуваннях IMU вказано чутливість `±4g` або `±8g`, прискорення катапульти `6g–8g` призводить до насичення вихідного АЦП. Інтеграл швидкості в [розширеному фільтрі Калмана (EKF)](root:embedded/imu-barometer) спотворюється: фільтр починає вважати, що літак нахилений назад із тангажем +70°, і після сходу з рейки різко відхиляє руль висоти вниз, заганяючи літак у землю. Щоб цього уникнути:
   - IMU на час старту налаштовують на повну шкалу `±16g` або `±32g`;
   - В автопілоті активують параметр `LAUNCH_CATAPULT = 1`, який заморожує корекцію нахилу за акселерометром на час перебування на рейці (`t < 0.5 с`), покладаючись виключно на гіроскопи.

## 4. Посадка на черево (Belly Landing): глісада, вирівнювання та захист гвинта

Посадка на черево — основний спосіб завершення польоту для безпілотників без колісного шасі. Апарат сідає на траву, сніг чи ґрунт, гасячи швидкість тертям днища фюзеляжу. На відміну від колісної посадки, тут немає права на довгий пробіг чи повторне викочування: після першого ж дотику планер незворотно ковзає по землі.

![Етапи посадки на черево: підхід по глісаді 3°-5°, вирівнювання (flare) над землею на висоті 1 м, відсічення тяги з активним гальмом ESC і складанням лопатей](/root/course/embedded/zapusk-i-posadka-bez-smuhy/img/belly-landing-flare.svg)
*Профіль автоматичної посадки на черево: стабілізація на глісаді (Approach), вирівнювання над землею (Flare), зупинка та складання лопатей пропелера для захисту мотора від ударного навантаження.*

### Підбір посадкової глісади (Approach & Flare)

Траєкторія автоматичної посадки на черево ділиться на чотири чітко розмежовані фази:

1. **Захід на посадкову пряму (Final Approach):**
   - Літак виходить на посадковий курс суворо **проти вітру**. Посадка з попутним вітром збільшує шляхову швидкість дотику на величину швидкості вітру `V_ground = V_air + V_wind`, що збільшує кінетичну енергію удару в 2–3 рази (`E_k ∝ V_ground²`).
   - Автопілот знижується по фіксованій глісаді з кутом нахилу траєкторії **γ = 3°–5°**.
   - Повітряна швидкість на глісаді суворо контролюється тягою мотора на рівні `V_app = 1.25–1.30 · V_stall`, що гарантує запас керованості по елеронах у разі турбулентності.
2. **Вирівнювання (Flare):**
   - На висоті **h_flare = 1.0–1.5 м** над поверхнею (визначається за даними оптичного лідара, ультразвукового далекоміра або барометра) автопілот ініціює перехід до вирівнювання.
   - Тяга двигуна негайно скидається до нуля (`throttle = 0%`).
   - Кермо висоти плавно відхиляється вгору, збільшуючи тангаж на **+4°...+8°**.
   - Літак переходить у режим згасання швидкості: вертикальна швидкість зниження гаситься від початкових `V_z = -1.5...-2.0 м/с` до безпечних **V_z ≤ -0.3...-0.4 м/с** завдяки виходу на екранний ефект землі (Ground Effect) та збільшенню кута атаки.
3. **Дотик (Touchdown):**
   - Літак торкається землі на мінімально можливій швидкості, близькій до `V_stall`, плазом або з невеликим диферентом на хвіст (на 2°–3°), щоб удар прийняла найтовстіша частина днища фюзеляжу, а не скляний обтічник оптичної камери в носі.
4. **Пробіг-ковзання (Ground Slide):**
   - Літак ковзає по траві чи снігу на дистанції 5–15 м. Елерони та рулі фіксуються в нейтралі або піднімаються вгору (spoilerons), притискаючи планер до землі, щоб порив бічного вітру не перекинув апарат через крило.

### Захист пропелера та валу електродвигуна

Найвразливіший вузол при посадці на черево — пропелер. Якщо в момент торкання ґрунту лопать стоїть вертикально вниз або продовжує вільно обертатися від зустрічного потоку (авторотація), вона діє як важіль завдовжки 150–250 мм.

Удар лопаті об камінь чи твердий ґрунт спричиняє:
- Згинальний момент, що ламає або вигинає сталевий вал мотора діаметром 4–6 мм;
- Зрив моторами з пінопластового фюзеляжу;
- **Випалювання ключів ESC:** якщо мотор не був знеструмлений або автопілот намагався додати газу, механічне заклинювання ротора спричиняє стрибок струму до рівня короткого замикання обмоток (Stall Current `I_stall = U_bat / R_phase`), що за 20–50 мілісекунд випалює вихідні MOSFET-транзистори інвертора.

Для запобігання аварії застосовують три інженерні рішення:

#### 1. Активне динамічне гальмування ESC (Active Braking / Damped Light)
У звичайному режимі при скиданні газу до нуля ESC просто відключає ключі, дозволяючи мотору вільно обертатися за інерцією під дією зустрічного вітру. При посадці на черево в ESC активують функцію **Brake on Stop**: контролер відкриває всі три нижні (або верхні) MOSFET-транзистори інвертора, замикаючи обмотки BLDC-двигуна накоротко.
Генерована обертанням ротора проти-ЕРС створює потужний гальмівний електромагнітний момент, який миттєво (за 50–100 мс) повністю зупиняє пропелер у повітрі ще на етапі глісади.

#### 2. Складані пропелери (Folding Propellers)
Для планерів та літаючих крил стандартом є складані дволопатеві гвинти. Лопаті закріплені на хабі на шарнірних осях. Під час роботи відцентрова сила розгортає лопаті в робоче положення (перпендикулярно валу). Щойно тяга зникає і спрацьовує гальмо ESC, зустрічний потік повітря складає лопаті назад уздовж бічних стінок фюзеляжу. При контакті з землею складені лопаті вільно відхиляються й не зазнають ударних навантажень.

#### 3. Позиціонування гвинта в горизонталь (Propeller Parking / Indexing)
Якщо конструкція вимагає жорсткого монолітного пропелера (наприклад, для важких БПЛА з підвищеним ККД), застосовують сенсорні ESC з датчиками Холла або магнітними енкодерами на валу мотора. Після відсічення тяги контролер плавно довертає вал двигуна так, щоб лопаті зафіксувалися суворо горизонтально — паралельно площині крила, вище за лінію контакту днища із землею.

### Механічний захист днища

Днище фюзеляжу та нижні поверхні консолей крила обладнують швидкозмінними захисними лижами (skid plates) зі зносостійких матеріалів:
- Склотекстоліт товщиною 1.0–1.5 мм або тонкий листовий карбон;
- Накладки з високомолекулярного поліетилену (UHMW-PE), що має мінімальний коефіцієнт тертя по ґрунту;
- Захисні пластикові ковпаки (сервоковпаки) над тягами та гойдалками сервоприводів на нижній поверхні крил, щоб стебла трави чи ґрунт не зірвали шестерні редуктора сервопривода при ковзанні.

## 5. Альтернативні методи повернення: посадка в сітку та парашут

Коли посадка на черево неможлива через тверде кам'янисте покриття, обмежений простір (корабельна палуба, дах будівлі) або наявність дорогої гіростабілізованої оптики на днищі, застосовують спеціальні системи вловлювання.

![Геометрія посадки в сітку з навантаженням на лонжерони крила та схема парашутного спуску з багатоточковою підвіскою](/root/course/embedded/zapusk-i-posadka-bez-smuhy/img/net-and-parachute.svg)
*Альтернативні способи повернення: вловлювання в сітку (Net Recovery) з ударом по передній кромці крила та парашутний спуск (Parachute Recovery) з підвіскою за центр ваги.*

### Вловлювання в сітку (Net Recovery / Skyhook)

Система використовує вертикальну еластичну капронову сітку розміром від `3x3 м` до `6x8 м`, натягнуту на двох щоглах з амортизаційними тросовими поліспастами та гальмівними лебідками.

1. **Вимоги до навігації:** щоб влучити літаком із розмахом крил 2.5 м у стулку сітки на швидкості 15 м/с (54 км/год), автопілот повинен забезпечувати точність траєкторії не гірше ніж `±0.5–0.8 м` по висоті та боковому зміщенню. Це вимагає обов'язкового використання супутникової навігації з фазовою корекцією **RTK GNSS** або оптичної системи наведення на ІЧ-маяки на щоглах сітки.
2. **Динаміка зупинки та перевантаження:** на дистанції гальмування `s_stop = 2.0 м` літак, що влітає на швидкості `V = 15 м/с`, зазнає уповільнення:
   ```
   a_stop = V² / (2 · s_stop) = 15² / (2 · 2.0) = 225 / 4.0 = 56.25 м/с² (≈ 5.7g)
   ```
3. **Навантаження на лонжерони крила:** сітка вловлює літак ударом по передній кромці консолей крила. На відміну від звичайного польоту, де крило навантажене вертикально підйомною силою, при контакті із сіткою виникає **колосальний поздовжній згинальний момент назад**. Якщо трубчастий карбоновий лонжерон розрахований лише на вертикальний вигин і не має діагональних підкосів або достатньої товщини стінки в кореневій нервюрі, крило ламається в точці кріплення до фюзеляжу. Для запобігання зісковзуванню сітки на кінцях крил встановлюють фіксатори-гаки (wing hooks).

### Парашутна посадка (Parachute Recovery)

Парашутна система забезпечує вертикальний спуск апарата в задану точку з мінімальним горизонтальним пробігом. Детальний аеродинамічний аналіз куполів наведено в [довіднику парашутних систем для дронів](root:sys-dron/parashut).

Критичні інженерні фактори парашутної посадки літака:

1. **Точки кріплення стропного павука (Harness Geometry):**
   - Стропи підвіски (2-точкова або 3-точкова система) кріпляться до силових шпангоутів фюзеляжу так, щоб у завішеному стані літак висів із невеликим додатним тангажем (+3°...+6° на хвіст).
   - При приземленні першим ґрунту торкається посилений хвостовий кіль або нижня захисна п'ята, приймаючи на себе залишковий удар, після чого літак лягає на площину крил. Якщо підвіска зсунута вперед, літак встромляється в землю носовим оптичним блоком.
2. **Швидкість спуску:** площа купола розраховується на усталену швидкість зниження `V_term = 3.5–5.0 м/с`. При швидкості понад `5.5 м/с` зростає ризик розтріскування склопластикового фюзеляжу від ударного навантаження.
3. **Алгоритм розкриття та безпеки:**
   - Постріл піропатрона або спрацьовування пружинного викидача кришки люка.
   - **Миттєве знеструмлення мотора (`throttle = 0`) та блокування гальма ESC:** обертовий гвинт, захопивши капронову стропу парашута, намотує її на вал за 0.1 с, що призводить до обриву стропи та падіння апарата.
   - Підйом елеронів угору в момент розкриття купола, що руйнує підйомну силу крила й запобігає «плануванню» літака під парашутом під час сильних поривів вітру.

## 6. Архітектура кінцевого автомата (FSM) польотного контролера

Процедури беззлітного запуску та посадки на черево є критичними фазами місії, де найменша затримка чи збій умови переходу веде до аварії. В архітектурі вбудованого ПЗ польотного контролера ці фази реалізуються у вигляді детермінованого кінцевого автомата (Finite State Machine, FSM).

![Граф переходів скінченного автомата автозльоту та посадки на черево з обробкою аварійного переривання посадки Go-Around](/root/course/embedded/zapusk-i-posadka-bez-smuhy/img/takeoff-landing-fsm.svg)
*Граф станів FSM: повний цикл автозльоту з детектуванням імпульсу та посадкової послідовності з можливістю аварійного виходу на друге коло (Go-Around).*

### Граф станів польотного автомата

Автомат керування рухом містить такі базові стани:

```
[TAKEOFF_PREARM]
       │  (Перевірка сенсорів, зведення замка / готовність кидка)
       ▼
[TAKEOFF_WAIT_TRIGGER]
       │  (a_x > a_threshold протягом t > t_min)
       ▼
[TAKEOFF_MOTOR_RAMPUP]
       │  (Закінчення затримки безпеки, наростання газу)
       ▼
[TAKEOFF_CLIMB]
       │  (Висота > h_safe, швидкість > V_cruise)
       ▼
[MISSION_NAV] ─────────────── Політ за маршрутом ───────────────┐
                                                                │ (Команда посадки)
                                                                ▼
                                                       [LAND_APPROACH]
                                                                │ (Вихід на глісаду проти вітру)
                                                                ▼
                                                       [LAND_GLIDESLOPE]
                                                                │ (Висота h < h_flare)
                                                                ▼
                                                       [LAND_FLARE]
                                                                │ (Газ = 0, Гальмо ESC, Pitch+)
                                                                ▼
                                                       [LAND_TOUCHDOWN]
                                                                │ (V_z ≈ 0, a_z удар, Disarm)
                                                                ▼
                                                       [LAND_COMPLETED]
```

Особливе місце посідає стан **LAND_ABORT (Go-Around)**: якщо під час зниження на глісаді літак зносить бічним поривом вітру за межі коридору безпеки або на смузі виявлено перешкоду, автомат миттєво перериває посадку: газ переводиться на 100%, тангаж перемикається в режим набору, і літак повертається у стан `MISSION_NAV` для виходу на друге коло. Проте після переходу у стан `LAND_FLARE` (на висоті менше 1 м) переривання посадки блокується, оскільки на вихід мотора з нульової тяги на повну потрібно 1.5–2.0 секунди, за які літак неминуче торкнеться ґрунту.

### Реалізація FSM на C та C++

Нижче наведено повну вбудовану реалізацію автомата керування зльотом та посадкою. Модуль розрахований на роботу в детермінованому циклі автопілота (період `dt = 10 мс`, частота 100 Гц).

:::tabs
```c
#include <stdint.h>
#include <stdbool.h>

typedef enum {
    FLIGHT_STATE_IDLE = 0,
    FLIGHT_STATE_TAKEOFF_WAIT_TRIGGER,
    FLIGHT_STATE_TAKEOFF_RAMPUP,
    FLIGHT_STATE_TAKEOFF_CLIMB,
    FLIGHT_STATE_MISSION_NAV,
    FLIGHT_STATE_LAND_APPROACH,
    FLIGHT_STATE_LAND_GLIDESLOPE,
    FLIGHT_STATE_LAND_FLARE,
    FLIGHT_STATE_LAND_TOUCHDOWN,
    FLIGHT_STATE_LAND_ABORT
} flight_fsm_state_t;

typedef struct {
    float accel_launch_threshold_g; /* Поріг стартового перевантаження (2.2g) */
    float safe_climb_alt_m;         /* Безпечна висота завершення зльоту (25.0 м) */
    float flare_alt_m;              /* Висота вирівнювання над землею (1.2 м) */
    float approach_airspeed_ms;     /* Цільова швидкість на глісаді (14.0 м/с) */
    float climb_pitch_deg;          /* Тангаж набору висоти (+14.0°) */
    float flare_pitch_deg;          /* Тангаж вирівнювання (+6.0°) */
} flight_fsm_config_t;

typedef struct {
    float target_pitch_deg;
    float target_roll_deg;
    float throttle_cmd;             /* 0.0 .. 1.0 */
    bool esc_brake_enable;
    bool is_disarmed;
} flight_fsm_output_t;

typedef struct {
    flight_fsm_state_t state;
    flight_fsm_config_t config;
    uint32_t state_timer_ms;
    float current_throttle;
} flight_fsm_t;

void flight_fsm_init(flight_fsm_t *fsm, const flight_fsm_config_t *cfg) {
    fsm->state = FLIGHT_STATE_IDLE;
    fsm->config = *cfg;
    fsm->state_timer_ms = 0;
    fsm->current_throttle = 0.0f;
}

void flight_fsm_start_takeoff(flight_fsm_t *fsm) {
    fsm->state = FLIGHT_STATE_TAKEOFF_WAIT_TRIGGER;
    fsm->state_timer_ms = 0;
    fsm->current_throttle = 0.0f;
}

void flight_fsm_start_landing(flight_fsm_t *fsm) {
    if (fsm->state == FLIGHT_STATE_MISSION_NAV) {
        fsm->state = FLIGHT_STATE_LAND_APPROACH;
        fsm->state_timer_ms = 0;
    }
}

flight_fsm_output_t flight_fsm_update(flight_fsm_t *fsm,
                                      float accel_x_g,
                                      float alt_agl_m,
                                      float airspeed_ms,
                                      bool abort_requested,
                                      uint32_t dt_ms) {
    flight_fsm_output_t out = {
        .target_pitch_deg = 0.0f,
        .target_roll_deg = 0.0f,
        .throttle_cmd = 0.0f,
        .esc_brake_enable = false,
        .is_disarmed = false
    };

    fsm->state_timer_ms += dt_ms;

    switch (fsm->state) {
    case FLIGHT_STATE_IDLE:
        out.is_disarmed = true;
        break;

    case FLIGHT_STATE_TAKEOFF_WAIT_TRIGGER:
        out.target_pitch_deg = fsm->config.climb_pitch_deg;
        out.target_roll_deg = 0.0f;
        out.throttle_cmd = 0.0f;
        if (accel_x_g >= fsm->config.accel_launch_threshold_g) {
            fsm->state = FLIGHT_STATE_TAKEOFF_RAMPUP;
            fsm->state_timer_ms = 0;
        }
        break;

    case FLIGHT_STATE_TAKEOFF_RAMPUP:
        out.target_pitch_deg = fsm->config.climb_pitch_deg;
        out.target_roll_deg = 0.0f;
        /* Затримка 250 мс перед набором газу */
        if (fsm->state_timer_ms > 250) {
            fsm->current_throttle += 2.0f * ((float)dt_ms / 1000.0f);
            if (fsm->current_throttle >= 0.90f) {
                fsm->current_throttle = 0.90f;
                fsm->state = FLIGHT_STATE_TAKEOFF_CLIMB;
                fsm->state_timer_ms = 0;
            }
        }
        out.throttle_cmd = fsm->current_throttle;
        break;

    case FLIGHT_STATE_TAKEOFF_CLIMB:
        out.target_pitch_deg = fsm->config.climb_pitch_deg;
        out.target_roll_deg = 0.0f;
        out.throttle_cmd = 0.90f;
        if (alt_agl_m >= fsm->config.safe_climb_alt_m) {
            fsm->state = FLIGHT_STATE_MISSION_NAV;
            fsm->state_timer_ms = 0;
        }
        break;

    case FLIGHT_STATE_MISSION_NAV:
        out.target_pitch_deg = 2.0f;
        out.target_roll_deg = 0.0f;
        out.throttle_cmd = 0.60f;
        break;

    case FLIGHT_STATE_LAND_APPROACH:
        out.target_pitch_deg = -3.0f; /* Зниження по глісаді */
        out.target_roll_deg = 0.0f;
        out.throttle_cmd = (airspeed_ms < fsm->config.approach_airspeed_ms) ? 0.45f : 0.20f;
        if (alt_agl_m <= 10.0f) {
            fsm->state = FLIGHT_STATE_LAND_GLIDESLOPE;
            fsm->state_timer_ms = 0;
        }
        if (abort_requested) {
            fsm->state = FLIGHT_STATE_LAND_ABORT;
            fsm->state_timer_ms = 0;
        }
        break;

    case FLIGHT_STATE_LAND_GLIDESLOPE:
        out.target_pitch_deg = -3.5f;
        out.target_roll_deg = 0.0f;
        out.throttle_cmd = 0.25f;
        if (alt_agl_m <= fsm->config.flare_alt_m) {
            fsm->state = FLIGHT_STATE_LAND_FLARE;
            fsm->state_timer_ms = 0;
        }
        if (abort_requested) {
            fsm->state = FLIGHT_STATE_LAND_ABORT;
            fsm->state_timer_ms = 0;
        }
        break;

    case FLIGHT_STATE_LAND_FLARE:
        out.target_pitch_deg = fsm->config.flare_pitch_deg; /* Вирівнювання носа */
        out.target_roll_deg = 0.0f;
        out.throttle_cmd = 0.0f;
        out.esc_brake_enable = true; /* Активне гальмування пропелера */
        if (alt_agl_m <= 0.2f || fsm->state_timer_ms > 2500) {
            fsm->state = FLIGHT_STATE_LAND_TOUCHDOWN;
            fsm->state_timer_ms = 0;
        }
        break;

    case FLIGHT_STATE_LAND_TOUCHDOWN:
        out.target_pitch_deg = 0.0f;
        out.target_roll_deg = 0.0f;
        out.throttle_cmd = 0.0f;
        out.esc_brake_enable = true;
        out.is_disarmed = true;
        break;

    case FLIGHT_STATE_LAND_ABORT:
        out.target_pitch_deg = fsm->config.climb_pitch_deg;
        out.target_roll_deg = 0.0f;
        out.throttle_cmd = 1.0f; /* Максимальна тяга для набору */
        if (alt_agl_m >= fsm->config.safe_climb_alt_m) {
            fsm->state = FLIGHT_STATE_MISSION_NAV;
            fsm->state_timer_ms = 0;
        }
        break;
    }

    return out;
}
```

```cpp
#include <cstdint>
#include <algorithm>

enum class FlightFsmState : uint8_t {
    Idle = 0,
    TakeoffWaitTrigger,
    TakeoffRampup,
    TakeoffClimb,
    MissionNav,
    LandApproach,
    LandGlideslope,
    LandFlare,
    LandTouchdown,
    LandAbort
};

struct FlightFsmConfig {
    float accel_launch_threshold_g{2.2f};
    float safe_climb_alt_m{25.0f};
    float flare_alt_m{1.2f};
    float approach_airspeed_ms{14.0f};
    float climb_pitch_deg{14.0f};
    float flare_pitch_deg{6.0f};
};

struct FlightFsmOutput {
    float target_pitch_deg{0.0f};
    float target_roll_deg{0.0f};
    float throttle_cmd{0.0f};
    bool esc_brake_enable{false};
    bool is_disarmed{false};
};

class FlightFsm {
public:
    constexpr explicit FlightFsm(const FlightFsmConfig& config = {}) noexcept
        : config_(config) {}

    void start_takeoff() noexcept {
        state_ = FlightFsmState::TakeoffWaitTrigger;
        state_timer_ms_ = 0;
        current_throttle_ = 0.0f;
    }

    void start_landing() noexcept {
        if (state_ == FlightFsmState::MissionNav) {
            state_ = FlightFsmState::LandApproach;
            state_timer_ms_ = 0;
        }
    }

    [[nodiscard]] FlightFsmOutput update(float accel_x_g,
                                         float alt_agl_m,
                                         float airspeed_ms,
                                         bool abort_requested,
                                         uint32_t dt_ms) noexcept {
        FlightFsmOutput out{};
        state_timer_ms_ += dt_ms;

        switch (state_) {
        case FlightFsmState::Idle:
            out.is_disarmed = true;
            break;

        case FlightFsmState::TakeoffWaitTrigger:
            out.target_pitch_deg = config_.climb_pitch_deg;
            out.target_roll_deg = 0.0f;
            out.throttle_cmd = 0.0f;
            if (accel_x_g >= config_.accel_launch_threshold_g) {
                state_ = FlightFsmState::TakeoffRampup;
                state_timer_ms_ = 0;
            }
            break;

        case FlightFsmState::TakeoffRampup: {
            out.target_pitch_deg = config_.climb_pitch_deg;
            out.target_roll_deg = 0.0f;
            if (state_timer_ms_ > 250) {
                current_throttle_ += 2.0f * (static_cast<float>(dt_ms) * 0.001f);
                if (current_throttle_ >= 0.90f) {
                    current_throttle_ = 0.90f;
                    state_ = FlightFsmState::TakeoffClimb;
                    state_timer_ms_ = 0;
                }
            }
            out.throttle_cmd = current_throttle_;
            break;
        }

        case FlightFsmState::TakeoffClimb:
            out.target_pitch_deg = config_.climb_pitch_deg;
            out.target_roll_deg = 0.0f;
            out.throttle_cmd = 0.90f;
            if (alt_agl_m >= config_.safe_climb_alt_m) {
                state_ = FlightFsmState::MissionNav;
                state_timer_ms_ = 0;
            }
            break;

        case FlightFsmState::MissionNav:
            out.target_pitch_deg = 2.0f;
            out.target_roll_deg = 0.0f;
            out.throttle_cmd = 0.60f;
            break;

        case FlightFsmState::LandApproach:
            out.target_pitch_deg = -3.0f;
            out.target_roll_deg = 0.0f;
            out.throttle_cmd = (airspeed_ms < config_.approach_airspeed_ms) ? 0.45f : 0.20f;
            if (alt_agl_m <= 10.0f) {
                state_ = FlightFsmState::LandGlideslope;
                state_timer_ms_ = 0;
            }
            if (abort_requested) {
                state_ = FlightFsmState::LandAbort;
                state_timer_ms_ = 0;
            }
            break;

        case FlightFsmState::LandGlideslope:
            out.target_pitch_deg = -3.5f;
            out.target_roll_deg = 0.0f;
            out.throttle_cmd = 0.25f;
            if (alt_agl_m <= config_.flare_alt_m) {
                state_ = FlightFsmState::LandFlare;
                state_timer_ms_ = 0;
            }
            if (abort_requested) {
                state_ = FlightFsmState::LandAbort;
                state_timer_ms_ = 0;
            }
            break;

        case FlightFsmState::LandFlare:
            out.target_pitch_deg = config_.flare_pitch_deg;
            out.target_roll_deg = 0.0f;
            out.throttle_cmd = 0.0f;
            out.esc_brake_enable = true;
            if (alt_agl_m <= 0.2f || state_timer_ms_ > 2500) {
                state_ = FlightFsmState::LandTouchdown;
                state_timer_ms_ = 0;
            }
            break;

        case FlightFsmState::LandTouchdown:
            out.target_pitch_deg = 0.0f;
            out.target_roll_deg = 0.0f;
            out.throttle_cmd = 0.0f;
            out.esc_brake_enable = true;
            out.is_disarmed = true;
            break;

        case FlightFsmState::LandAbort:
            out.target_pitch_deg = config_.climb_pitch_deg;
            out.target_roll_deg = 0.0f;
            out.throttle_cmd = 1.0f;
            if (alt_agl_m >= config_.safe_climb_alt_m) {
                state_ = FlightFsmState::MissionNav;
                state_timer_ms_ = 0;
            }
            break;
        }

        return out;
    }

    [[nodiscard]] FlightFsmState state() const noexcept { return state_; }

private:
    FlightFsmConfig config_{};
    FlightFsmState state_{FlightFsmState::Idle};
    uint32_t state_timer_ms_{0};
    float current_throttle_{0.0f};
};
```
