# 🧮 Балістичні рівняння вільного падіння вантажу з аеродинамічним опором

Падіння тіла в реальній атмосфері суттєво відрізняється від безповітряної параболи: опір повітря не просто сповільнює рух, а нелінійно перекошує траєкторію, перетворюючи симетричну дугу на асиметричну криву зі спадною горизонтальною швидкістю та асимптотичним виходом на граничну швидкість падіння. Для точного наведення скидуваного вантажу польотний контролер має розв'язувати систему диференціальних рівнянь руху в тривимірному просторі з урахуванням висотного профілю вітру та змінюваної густини атмосфери.

Нижче розібрано аналітичний розв'язок одновимірного вертикального падіння з квадратичним опором, точну залежність часу падіння від висоти та формулювання тривимірної векторної моделі для чисельного інтегрування методами Ейлера та Рунге-Кутти четвертого порядку.

## Одновимірне падіння: термінальна швидкість та аналітичний інтеграл

Розглянемо тіло масою `m`, що падає вертикально вниз під дією сили тяжіння та сили аеродинамічного опору. Сила опору пропорційна квадрату миттєвої швидкості `v`:

```
F_drag = (1/2) · ρ · C_d · A · v²
```

де `ρ` — густина повітря (кг/м³), `C_d` — безрозмірний коефіцієнт лобового опору, `A` — площа міделевого перерізу тіла (м²).

Другий закон Ньютона для вертикальної осі `z`, спрямованої вниз, записується у вигляді диференціального рівняння:

```
m · (dv / dt) = m · g − (1/2) · ρ · C_d · A · v²
```

Поділимо обидві частини рівняння на масу `m`:

```
dv / dt = g − (ρ · C_d · A / (2 · m)) · v²
```

Коли сила опору зрівнюється з силою тяжіння, прискорення `dv / dt` спадає до нуля. Швидкість, за якої це відбувається, називається **термінальною (граничною) швидкістю** `v_t`:

```
g − (ρ · C_d · A / (2 · m)) · v_t² = 0
v_t² = 2 · m · g / (ρ · C_d · A)
v_t = √(2 · m · g / (ρ · C_d · A))
```

Введемо позначення `k = g / v_t² = ρ · C_d · A / (2 · m)`. Тоді диференціальне рівняння набуває канонічного вигляду:

```
dv / dt = g · (1 − v² / v_t²)
```

Розділимо змінні та проінтегруємо від початкового моменту `t = 0` (за початкової швидкості `v(0) = 0`) до моменту `t`:

```
∫ [0..v] dv / (1 − (v / v_t)²)
= g · ∫ [0..t] dt
= g · t                             [інтегрування правої частини за dt]
```

Скористаємося табличним інтегралом `∫ dx / (1 − x²) = artanh(x)` для `|x| < 1`:

```
v_t · artanh(v / v_t)
= g · t                             [інтеграл від гіперболічного тангенса]
artanh(v / v_t)
= (g · t) / v_t                     [поділили на граничну швидкість v_t]
v(t)
= v_t · tanh((g · t) / v_t)         [взяли гіперболічний тангенс від обох частин]
```

Це рівняння показує, що швидкість падіння спочатку наростає майже лінійно (`tanh(x) ≈ x` при малих `x`), а потім експоненційно наближається до асимптоти `v_t`.

## Висота та точний час падіння

Щоб знайти пройдену відстань `z(t)`, проінтегруємо швидкість `v(t) = dz / dt` за часом:

```
z(t)
= ∫ [0..t] v_t · tanh((g · τ) / v_t) dτ
= (v_t² / g) · ln(cosh((g · t) / v_t))    [інтеграл від tanh(u) du є ln(cosh(u))]
```

Якщо скид здійснюється з поточної висоти `h`, тіло досягає поверхні землі (`z = h`), коли виконується рівність:

```
h = (v_t² / g) · ln(cosh((g · t_fall) / v_t))
```

Виразимо час падіння `t_fall` у явному вигляді через функції, обернені до гіперболічних:

```
ln(cosh((g · t_fall) / v_t))
= (g · h) / v_t²                    [поділили на масштабний коефіцієнт v_t² / g]
cosh((g · t_fall) / v_t)
= exp((g · h) / v_t²)               [взяли експоненту від обох частин]
(g · t_fall) / v_t
= arcosh(exp((g · h) / v_t²))       [взяли ареакосинус arcosh(y) = ln(y + √(y² − 1))]
t_fall
= (v_t / g) · arcosh(exp((g · h) / v_t²)) [помножили на v_t / g]
```

Порівняємо цей результат із часом падіння у вакуумі `t_0 = √(2 · h / g)`. Розкладемо функцію `exp(x)` та `arcosh(y)` у ряд Тейлора за малим параметром `ε = (g · h) / v_t²`:

```
exp(ε) ≈ 1 + ε + ε² / 2
arcosh(1 + δ) ≈ √(2 · δ) · (1 − δ / 12)
```

Підставивши `δ = ε + ε² / 2`, отримуємо наближення для часу падіння з урахуванням слабкого опору:

```
t_fall
≈ (v_t / g) · √(2 · (g · h / v_t²)) · (1 + (g · h) / (6 · v_t²))
= √(2 · h / g) · (1 + (g · h) / (6 · v_t²))
= t_0 · (1 + (g · h) / (6 · v_t²))  [поправка першого порядку на опір повітря]
```

Цей вираз чітко показує: чим вища висота скиду `h` і чим менша термінальна швидкість `v_t` (легкий або габаритний вантаж), тим довше вантаж перебуває в повітрі порівняно з вакуумною формулою, і тим сильнішим буде накопичений вітровий знос.

## Горизонтальне гальмування під дією аеродинамічного опору

Розглянемо рух по осі `x` за відсутності вітру. Якщо вантаж відокремлюється з горизонтальною швидкістю `v_x0`, на нього діє проекція сили опору:

```
dv_x / dt = − k · v_total · v_x
```

де `v_total = √(v_x² + v_z²)`. На початковій ділянці, коли вертикальна швидкість `v_z` ще мала порівняно з `v_x` (`v_total ≈ v_x`), рівняння спрощується до одновимірного гальмування:

```
dv_x / dt = − k · v_x²
```

Розділивши змінні та проінтегрувавши:

```
∫ [v_x0..v_x] dv_x / v_x² = − k · ∫ [0..t] dt
− (1 / v_x − 1 / v_x0) = − k · t
1 / v_x = 1 / v_x0 + k · t
v_x(t) = v_x0 / (1 + k · v_x0 · t)
```

Інтегруючи швидкість `v_x(t)` за часом, отримуємо горизонтальну відстань `x(t)`:

```
x(t)
= ∫ [0..t] (v_x0 / (1 + k · v_x0 · τ)) dτ
= (1 / k) · ln(1 + k · v_x0 · t)    [інтеграл від раціонального дробу]
```

Ця формула демонструє логарифмічне насичення горизонтального переміщення: зі зростанням часу швидкість `v_x` невпинно падає, і тіло ніколи не подолає відстань, більшу за теоретичну межу без вертикального падіння.

## Тривимірна модель польоту з урахуванням зсуву вітру

У реальному польоті вантаж рухається у тривимірному просторі під дією гравітації та вектора відносного набігаючого потоку повітря. Нехай `r = (x, y, z)` — радіус-вектор положення вантажу, а `v = (v_x, v_y, v_z)` — вектор його швидкості відносно землі.

Вектор швидкості вітру `W(z) = (W_x(z), W_y(z), 0)` змінюється за висотою відповідно до логарифмічного профілю приземного шару атмосфери:

```
W(z) = W_ref · (ln(z / z_0) / ln(z_ref / z_0))
```

де `z_0` — динамічна шорсткість підстильної поверхні (0.01 м для відкритого поля, 0.1 м для чагарнику, 0.5 м для лісу чи забудови), `W_ref` — швидкість вітру, виміряна або розрахована на опорній висоті `z_ref` (зазвичай 10 м або висота польоту БПЛА).

Вектор швидкості руху вантажу відносно повітряної маси дорівнює:

```
v_rel = v − W(z) = (v_x − W_x(z), v_y − W_y(z), v_z)
```

Модуль відносної швидкості:

```
|v_rel| = √((v_x − W_x(z))² + (v_y − W_y(z))² + v_z²)
```

Векторне диференціальне рівняння другого закону Ньютона має вигляд:

```
m · (dv / dt) = m · g_vec − (1/2) · ρ(z) · C_d · A · |v_rel| · v_rel
```

де вектор прискорення вільного падіння `g_vec = (0, 0, g)`, а густина повітря `ρ(z)` залежить від висоти над рівнем моря за барометричною формулою міжнародної стандартної атмосфери (ISA):

```
ρ(z) = ρ_0 · (1 − L_b · z / T_0)^(g · M / (R_gas · L_b) − 1)
```

Поділивши на масу `m`, отримуємо систему диференціальних рівнянь першого порядку для шести змінних стану `S = (x, y, z, v_x, v_y, v_z)`:

```
dx / dt = v_x
dy / dt = v_y
dz / dt = v_z
dv_x / dt = − (ρ(z) · C_d · A / (2 · m)) · |v_rel| · (v_x − W_x(z))
dv_y / dt = − (ρ(z) · C_d · A / (2 · m)) · |v_rel| · (v_y − W_y(z))
dv_z / dt = g − (ρ(z) · C_d · A / (2 · m)) · |v_rel| · v_z
```

## Чисельне інтегрування: метод Рунге-Кутти 4-го порядку проти Ейлера

Оскільки система не має загального аналітичного розв'язку в елементарних функціях через нелінійну зв'язаність компонентів швидкості у величині `|v_rel|`, бортовий комп'ютер інтегрує її чисельно з фіксованим або адаптивним кроком `Δt`.

### Схема Ейлера (1-й порядок)

Найпростіша схема прямого інтегрування оновлює вектор стану за формулою:

```
S(t + Δt) = S(t) + f(t, S(t)) · Δt
```

Локальна похибка схеми Ейлера становить `O(Δt²)`, а глобальна накопичена похибка — `O(Δt)`. За кроку `Δt = 0.05` с на траєкторії тривалістю 6 с похибка у визначенні кінцевої точки падіння сягає `1.2–2.5` м через систематичне заниження сили опору на кожному кроці (запізнювання оцінки квадрата швидкості).

### Схема Рунге-Кутти 4-го порядку (RK4)

Для отримання сантиметрової точності розрахунку застосовується класичний метод RK4:

```
k_1 = f(t, S)
k_2 = f(t + Δt / 2, S + (Δt / 2) · k_1)
k_3 = f(t + Δt / 2, S + (Δt / 2) · k_2)
k_4 = f(t + Δt, S + Δt · k_3)

S(t + Δt) = S(t) + (Δt / 6) · (k_1 + 2 · k_2 + 2 · k_3 + k_4)
```

Локальна похибка методу становить `O(Δt⁵)`, а глобальна — `O(Δt⁴)`. При тому ж кроці `Δt = 0.05` с похибка інтегрування траєкторії падає нижче `0.005` м (5 мм), що повністю усуває математичну похибку калькулятора як джерело промаху, залишаючи похибку виключно в межах невизначеності вимірювання вітру та координат.

### Критерій числової стійкості вибору кроку dt

Для забезпечення числової стійкості диференціального розв'язувача крок за часом `Δt` має задовольняти умову Куранта для нелінійного загасання:

```
Δt < 2 / λ_max
```

де `λ_max = (ρ · C_d · A / m) · |v_rel_max|` — максимальне власне число якобіана системи. Для швидкісного скиду з `v_rel = 35 м/с` та `k = 0.015 м⁻¹` максимальне власне число `λ_max ≈ 0.525 с⁻¹`, що вимагає `Δt < 3.8 с`. Фіксований крок `Δt = 0.05 с` дає майже 80-кратний запас стійкості, повністю виключаючи числові автоколивання інтегратора.

## Уточнення точки торкання землі: лінійна інтерполяція

В процесі чисельного інтегрування останній крок `n` перетинає площину землі: `z_n < z_ground`, а `z_{n+1} ≥ z_ground`. Застосування кінцевого положення `S_{n+1}` дасть дискретизаційну похибку координати величиною `v_x · Δt ≈ 18 м/с · 0.05 с = 0.9 м`.

Для усунення цієї похибки обчислюється точний дріб останнього часового інтервалу `θ ∈ [0, 1]`:

```
θ = (z_ground − z_n) / (z_{n+1} − z_n)
```

Кінцеві горизонтальні координати точки падіння на поверхні землі уточнюються зворотною лінійною корекцією:

```
x_impact = x_n + θ · (x_{n+1} − x_n)
y_impact = y_n + θ · (y_{n+1} − y_n)
t_impact = t_n + θ · Δt
```

Це дозволяє бортовому калькулятору з високою точністю розраховувати точку скиду без необхідності надмірного подрібнення кроку інтегрування.
