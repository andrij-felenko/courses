# 🧮 Математична модель енергоспоживання стільникового вузла

Ця математична вставка містить строгу аналітичну модель розрахунку енергетичного бюджету, середнього струму споживання, падіння напруги на внутрішньому опорі батареї під час радіоімпульсів та теоретичного строку служби автономного IoT-пристрою в стільникових мережах NB-IoT та LTE-M.

## Інтегральна модель заряду за цикл передачі

Повний електричний заряд, спожитий пристроєм за один сеанс передачі даних Q_cycle, визначається інтегралом миттєвого струму i(t) за часом активної фази t_active:

```text
Q_cycle = ∫ i(t) dt   [інтеграл струму активної фази]
```

Оскільки профіль струму складається з дискретних фаз із квазіпостійним споживанням, інтеграл розкладається на суму добутків струму та тривалості кожної окремої фази:

```text
Q_cycle = Q_boot + Q_sync + Q_tx + Q_rx + Q_tail
        = I_boot · t_boot + I_sync · t_sync + I_tx · t_tx + I_rx · t_rx + I_tail · t_tail   [сума зарядів окремих фаз]
```

де:
- Q_boot: фаза холодного старту або пробудження мікроконтролера та модема, ініціалізація шини живлення та опитування SIM-карти (I_boot ≈ 25 мА, t_boot ≈ 0.2 с).
- Q_sync: пошук несівної частоти базової станції, процедура випадкового доступу PRACH та встановлення з'єднання RRC (I_sync ≈ 80 мА, t_sync ≈ 1.5 с за нормального покриття).
- Q_tx: випромінювання корисного радіопакета на максимальній потужності передавача +23 дБм (I_tx ≈ 300 мА, t_tx залежить від розміру кадру та рівня повторів).
- Q_rx: прийом канального підтвердження на рівні RLC або прикладної відповіді сервера (I_rx ≈ 60 мА, t_rx ≈ 0.2 с).
- Q_tail: утримання виділеного каналу в режимі RRC Connected за таймером неактивності мережі (I_tail ≈ 25 мА, t_tail ≈ 10–20 с без RAI; t_tail ≈ 0 с із використанням RAI).

## Вплив радіопокриття та рівня повторів (ECL)

У стандартах 3GPP NB-IoT визначено три класи радіопокриття (Enhanced Coverage Level, ECL):
1. **ECL0 (Normal Coverage)**: рівень сигналу RSRP > −105 дБм. Передача відбувається без повторів або з мінімальним дублюванням (1–2 повтори). Ефективна швидкість висхідного каналу складає R_up ≈ 16 кбіт/с (2000 байт/с).
2. **ECL1 (Robust Coverage)**: рівень сигналу −115 дБм < RSRP ≤ −105 дБм. Базова станція призначає від 4 до 8 повторень кожного радіоблоку.
3. **ECL2 (Extreme Coverage)**: рівень сигналу RSRP ≤ −115 дБм (підвали, металеві шафи, глибокі колодязі). Кількість повторів сягає від 32 до 128 разів, а швидкість каналу падає до R_up ≈ 0.5–1.0 кбіт/с.

Тривалість передачі t_tx виражається через розмір кадру S_total, кількість повторів N_rep та базову швидкість каналу R_base:

```text
t_tx = (S_total · 8 · N_rep) / R_base   [тривалість з урахуванням повторів]
```

Для кадру розміром 6400 байтів (наївний HTTPS) у зоні слабкого покриття ECL2 тривалість передачі зростає до 40–60 секунд безперервного випромінювання на струмі 300 мА, що спалює до 5.0 мА·год заряду на одне повідомлення. Для 28-байтового бінарного кадру навіть за максимальної кількості повторів час передачі не перевищує 0.8 секунди.

## Розрахунок спожитого заряду для умов нормального покриття (ECL0)

### 1. Наївний стек (HTTPS / JSON без RAI)

```text
Q_boot = 25 мА · 0.2 с   = 5.0 мА·с
Q_sync = 80 мА · 1.5 с   = 120.0 мА·с
Q_tx   = 300 мА · 3.2 с  = 960.0 мА·с   [передача 6.4 КБ при 2 КБ/с]
Q_rx   = 60 мА · 0.5 с   = 30.0 мА·с
Q_tail = 25 мА · 15.0 с  = 375.0 мА·с   [холостий хвіст таймера]

Q_cycle_naive = 5.0 + 120.0 + 960.0 + 30.0 + 375.0
              = 1490.0 мА·с
              = 1490.0 / 3600
              ≈ 0.4139 мА·год   [заряд одного наївного сеансу]
```

### 2. Оптимізований стек (CoAP / UDP + Binary + RAI)

Завдяки прапорцю Release Assistance Indication (RAI) таймер неактивності t_tail = 0, а радіоз'єднання розривається негайно після отримання першої відповіді:

```text
Q_boot = 25 мА · 0.2 с    = 5.0 мА·с
Q_sync = 80 мА · 1.5 с    = 120.0 мА·с
Q_tx   = 300 мА · 0.032 с = 9.6 мА·с    [передача 64 байтів при 2 КБ/с]
Q_rx   = 60 мА · 0.2 с    = 12.0 мА·с
Q_tail = 25 мА · 0.0 с    = 0.0 мА·с    [скинуто прапорцем RAI]

Q_cycle_opt = 5.0 + 120.0 + 9.6 + 12.0 + 0.0
            = 146.6 мА·с
            = 146.6 / 3600
            ≈ 0.0407 мА·год   [заряд оптимізованого сеансу]
```

При використанні збереженого радіоконтексту eDRX або швидкого відновлення з'єднання фаза синхронізації скорочується до t_sync ≈ 0.3 с:

```text
Q_cycle_fast = 5.0 + (80 · 0.3) + 9.6 + 12.0
             = 50.6 мА·с
             = 50.6 / 3600
             ≈ 0.0141 мА·год   [заряд швидкого сеансу]
```

## Падіння напруги на внутрішньому опорі батареї та пасивація

Хімічні первинні джерела живлення типу LiSOCl2 (літій-тіонілхлорид, номінальна напруга 3.6 В) мають високу питому енергоємність, але страждають від ефекту хімічної пасивації — утворення плівки хлориду літію LiCl на аноді при тривалому зберіганні або слабкому струмі сну (3–5 мкА).

Пасивація різко збільшує внутрішній динамічний опір джерела R_int до 20–50 Ом. Під час стрибка струму передавача I_pulse = 300 мА напруга на виводах батареї миттєво просідає:

```text
ΔV_drop = I_pulse · R_int
        = 0.300 А · 30 Ом
        = 9.0 В   [падіння напруги перевищує всю ЕРС батареї!]
```

Напруга падає нижче порогу вимкнення мікроконтролера (Brownout Reset, зазвичай 2.7 В), що спричиняє циклічне аварійне перезавантаження пристрою.

### Розрахунок буферного суперконденсатора (Hybrid Layer Capacitor, HLC)

Для захисту від падіння напруги паралельно елементу LiSOCl2 встановлюється іоністор або спеціальний імпульсний конденсатор HLC. Необхідна ємність C_buf розраховується з умови утримання допустимого падіння напруги ΔV_allowed (наприклад, не більше 0.4 В при вихідній напрузі 3.6 В) протягом імпульсу передачі t_pulse:

```text
C_buf = (I_pulse · t_pulse) / ΔV_allowed   [формула ємності буфера]
```

Для оптимізованого кадру (t_pulse = 32 мс, I_pulse = 300 мА):

```text
C_buf_opt = (0.300 А · 0.032 с) / 0.4 В
          = 0.0096 / 0.4
          = 0.024 Ф
          = 24 мФ = 24 000 мкФ   [компактний танталовий або іоністорний буфер]
```

Для наївного стека (t_pulse = 3.2 с) потрібна ємність C_buf = 2.4 Ф, що вимагає громіздкого та дорогого суперконденсатора з високим власним струмом витоку (15–30 мкА), який сам по собі виснажить батарею швидше, ніж корисне навантаження.

## Розрахунок терміну служби для різних інтервалів відправки

Нехай корисна ємність батареї з урахуванням ККД перетворювача та температури становить C_eff = 2040 мА·год, струм сну в режимі PSM I_sleep = 0.004 мА, річний саморозряд S_self = 1.0%/рік.

Загальне добове споживання енергії:

```text
Q_day = (N_day · Q_cycle) + (I_sleep · (24 - N_day · t_active / 3600))   [добовий баланс]
```
