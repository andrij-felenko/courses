# 🧮 Розрахунок віброізоляції: власна частота, добротність та підбір демпферів

М'який підвіс корисного навантаження — це не просто «поставити камеру на будь-які гумові кульки». Якщо пружність підвісу обрана навмання, конструкція ризикує потрапити в механічний резонанс, де амплітуда вібрацій зросте в рази замість очікуваного гасіння. Щоб перетворити підвіс на ефективний механічний фільтр низьких частот, потрібен точний розрахунок динамічної системи з одним або кількома ступенями вільності.

## 1. Динамічна модель: маса, пружність, в'язке демпфування

Розглянемо корисне навантаження масою `m` (кг), закріплене на синій пластині рами через `N` однакових силіконових демпферів.

Кожен окремий демпфер має власну динамічну жорсткість `k_1` (Н/м) та коефіцієнт в'язкого тертя `c_1` (Н·с/м). Оскільки всі `N` демпферів з'єднані паралельно між рамою та плитою навантаження, загальна еквівалентна жорсткість `k` та коефіцієнт демпфування `c` дорівнюють сумі складових:

```
k = N · k_1
c = N · c_1
```

Нехай рама дрона здійснює гармонічні коливання з амплітудою `u(t) = U_0 · sin(ω · t)`, спричинені обертанням моторів та лопатей гвинтів. Рух корисного навантаження позначимо як `x(t)`.

Рівняння руху маси за другим законом Ньютона враховує силу пружності, пропорційну відносному зміщенню `(x - u)`, та силу демпфування, пропорційну відносній швидкості `(ẋ - u̇)`:

```
m · ẍ + c · (ẋ - u̇) + k · (x - u) = 0
```

Перенесемо збурення рами в праву частину рівняння:

```
m · ẍ + c · ẋ + k · x = c · u̇ + k · u
```

## 2. Власна частота та статичний прогин

Розділимо рівняння на масу `m` і введемо канонічні динамічні параметри:

1. **Власна кутова частота** `ω_0` (рад/с) та циклічна власна частота `f_0` (Гц):

```
ω_0 = √(k / m)
f_0 = ω_0 / (2 · π) = (1 / (2 · π)) · √(k / m)
```

2. **Коефіцієнт демпфування** `ζ` (безрозмірна величина) та критичне демпфування `c_crit`:

```
c_crit = 2 · √(k · m) = 2 · m · ω_0
ζ = c / c_crit = c / (2 · m · ω_0)
```

У статичному стані під дією сили тяжіння `F_g = m · g` демпфери стискаються на величину статичного прогину `δ` (м):

```
δ = (m · g) / k
```

Підставивши вираз для `k = (m · g) / δ` у формулу власної частоти, отримуємо зручну пряму залежність між статичним прогином підвісу та його власною частотою:

```
f_0 = (1 / (2 · π)) · √(g / δ)
```

Підставивши прискорення вільного падіння `g = 9.80665 м/с²`, спрощуємо розрахунок для прогину `δ_mm`, вираженого в міліметрах:

```
f_0 = (1 / (2 · π)) · √(9806.65 / δ_mm)   [підстановка g = 9.80665 м/с² та переведення в мм]
    ≈ 15.76 / √δ_mm  [Гц]                 [спрощений інженерний коефіцієнт]
```

Ця формула дає швидку інженерну оцінку: якщо 500-грамова камера прогинає демпфери на `δ = 2.5 мм`, власна частота такого підвісу становитиме:

```
f_0 = 15.76 / √2.5 ≈ 9.97 Гц
```

## 3. Виведення коефіцієнта передавання (Transmissibility)

Коефіцієнт передавання вібрації `T_R` (англ. *Transmissibility Ratio*) визначає відношення амплітуди коливань навантаження `X_0` до амплітуди коливань рами `U_0`:

```
T_R = X_0 / U_0
```

Шукаємо усталений розв'язок у комплексній формі, де `u(t) = U_0 · e^(j·ω·t)` та `x(t) = X_0 · e^(j·(ω·t - φ))`.

Підставляючи похідні `u̇ = j·ω·u`, `ẋ = j·ω·x`, `ẍ = -ω²·x` у диференціальне рівняння, отримуємо:

```
(-m · ω² + j · c · ω + k) · X_0 = (j · c · ω + k) · U_0
```

Звідси комплексна передавальна функція `H(j·ω)` дорівнює:

```
H(j·ω) = X_0 / U_0 = (k + j · c · ω) / ((k - m · ω²) + j · c · ω)
```

Поділимо чисельник і знаменник на `k`, враховуючи, що `ω_0² = k/m` та `c/k = 2·ζ/ω_0`. Введемо безрозмірне відношення частот `r = ω / ω_0 = f / f_0`:

```
H(j·r) = (1 + j · 2 · ζ · r) / ((1 - r²) + j · 2 · ζ · r)
```

Модуль цієї комплексної величини визначає шуканий коефіцієнт передавання `T_R`:

```
T_R = |H(j·r)| = √ ( Re(H)² + Im(H)² )
    = √ [ (1 + (2 · ζ · r)²) / ((1 - r²)² + (2 · ζ · r)²) ]   [модуль комплексного дробу]
```

### Аналіз трьох характерних зон кривої передавання

1. **Зона низьких частот (`r ≪ 1` або `f ≪ f_0`):**
   Коли частота коливань рами значно нижча за власну частоту підвісу, `r → 0`. Підставляючи `r = 0` у формулу, маємо:
   ```
   T_R ≈ √(1 / 1) = 1.0
   ```
   Навантаження жорстко повторює всі рухи рами без затримки та підсилення.

2. **Зона резонансу (`r = 1` або `f = f_0`):**
   При збігу частоти збудження з власною частотою підвісу знаменник спрощується до `2·ζ`:
   ```
   T_R(r=1) = √ [ (1 + 4 · ζ²) / (4 · ζ²) ]   [підстановка r = 1 у формулу T_R]
            = √ [ 1 + 1 / (4 · ζ²) ]          [почленне ділення під коренем]
   ```
   Для малих значень демпфування (`ζ < 0.15`) одиницею під коренем можна знехтувати:
   ```
   T_R(r=1) ≈ 1 / (2 · ζ) = Q
   ```
   де `Q` — добротність механічної системи. Наприклад, для гумового демпфера з `ζ = 0.05` коефіцієнт передачі сягає `T_R ≈ 10`, тобто амплітуда вібрацій навантаження зростає в 10 разів порівняно з вібрацією рами!

3. **Межова точка нейтральності (`r = √2`):**
   Знайдемо точку, де демпфер перестає підсилювати коливання і починає їх ізолювати, тобто `T_R = 1`:
   ```
   (1 + (2 · ζ · r)²) / ((1 - r²)² + (2 · ζ · r)²) = 1
   1 + (2 · ζ · r)² = (1 - r²)² + (2 · ζ · r)²         [прирівнювання чисельника й знаменника]
   (1 - r²)² = 1                                      [скорочення однакових доданків]
   1 - r² = -1                                        [добування кореня при r > 1]
   r² = 2  →  r = √2 ≈ 1.414                          [знаходження граничного відношення частот]
   ```
   **Фундаментальний висновок:** віброізоляція (`T_R < 1`) фізично виникає **виключно** при частотах збудження, що перевищують `√2 · f_0`:
   ```
   f_збудження > √2 · f_0 ≈ 1.414 · f_0
   ```

4. **Зона високоефективної ізоляції (`r ≫ √2`):**
   На високих частотах (`r ≥ 3–5`) формула передавання спрощується:
   ```
   T_R ≈ (2 · ζ) / r  (для помірного демпфування)
   T_R ≈ 1 / r²        (для ідеально пружного тіла без втрат, ζ → 0)
   ```
   Звідси видно класичний компроміс віброзахисту: **високе демпфування `ζ` зменшує пік руйнації на резонансі, але дещо погіршує якість ізоляції на ультрависоких частотах**. Для дронів оптимумом є силіконові суміші з `ζ ≈ 0.20–0.28`.

## 4. Покроковий алгоритм розрахунку підвісу під робочі оберти

Припустимо, ми проектуємо підвіс для 3-осьового гімбала з камерою загальною масою `m = 0.650 кг` на 4 силіконових демпферах (`N = 4`).

Силова установка дрона використовує 2-лопатеві гвинти (`N_blades = 2`). Робочий діапазон обертів моторів на висінні та в польоті становить `4200–7800 об/хв`.

### Крок 1. Розрахунок частот збудження рами
Розраховуємо фундаментальну частоту обертання роторів `f_rot` та частоту проходження лопатей BPF (англ. *Blade Pass Frequency*):

```
f_rot_min = 4200 / 60 = 70 Гц
f_rot_max = 7800 / 60 = 130 Гц

f_BPF_min = f_rot_min · N_blades = 70 · 2 = 140 Гц
f_BPF_max = f_rot_max · N_blades = 130 · 2 = 260 Гц
```

Найнижча небезпечна частота вібрацій — це `f_rot_min = 70 Гц`.

### Крок 2. Визначення цільової власної частоти
Щоб надійно уникнути резонансу і забезпечити коефіцієнт ізоляції `T_R ≤ 0.10` (гасіння 90% вібрації) на найнижчих обертах, обираємо відношення частот `r_min ≥ 3.0`:

```
f_0 = f_rot_min / r_min = 70 / 3.0 ≈ 23.3 Гц
```

Перевіримо умову межі ізоляції: `√2 · f_0 = 1.414 · 23.3 = 32.9 Гц ≪ 70 Гц`. Умова виконується з великим запасом.

### Крок 3. Розрахунок необхідної жорсткості
Знаходимо загальну динамічну жорсткість системи:

```
k_tot = (2 · π · f_0)² · m
      = (2 · π · 23.3)² · 0.650          [підстановка власної частоти f_0 та маси m]
      = (146.4)² · 0.650                 [обчислення кутової частоти ω_0]
      ≈ 13 930 Н/м ≈ 13.93 Н/мм          [знаходження сумарної жорсткості]
```

Жорсткість одного демпфера з чотирьох:

```
k_1 = k_tot / N = 13.93 / 4 ≈ 3.48 Н/мм = 3480 Н/м
```

### Крок 4. Перевірка статичного та динамічного прогину
Статичний прогин підвісу під власною вагою:

```
δ_stat = (m · g) / k_tot
       = (0.650 · 9.81) / 13.93          [підстановка маси, гравітації та жорсткості]
       = 6.38 / 13.93                    [обчислення сили тяжіння навантаження]
       ≈ 0.46 мм                         [отримання величини статичного прогину]
```

При динамічному маневрі з перевантаженням `G_max = 4.0 g` максимальне зміщення центру мас підвісу складе:

```
Δx_max = G_max · δ_stat = 4.0 · 0.46 мм ≈ 1.84 мм
```

Робочий хід силіконового демпфера діаметром 12–15 мм типово становить 3.0–4.5 мм, отже зміщення 1.84 мм не призведе до пробою демпфера чи заклинювання в обмежувальних кільцях.

### Крок 5. Вибір твердості демпфера за шкалою Шора
За каталогами виробників силіконових демпферних куль (Damper Balls) жорсткість на стиск співвідноситься зі шкалою твердості Shore A або Shore OO:
- **Shore 20A / 40OO:** `k_1 ≈ 1.5–2.2 Н/мм` (для надлегких камер 100–250 г);
- **Shore 30A / 55OO:** `k_1 ≈ 3.2–3.8 Н/мм` (ідеально підходить під наш розрахунок `k_1 = 3.48 Н/мм`);
- **Shore 50A / 70OO:** `k_1 ≈ 6.5–8.0 Н/мм` (для важких навантажень 1.5–3 кг).

Обираємо 4 силіконові демпфери твердістю **Shore 30A**.
