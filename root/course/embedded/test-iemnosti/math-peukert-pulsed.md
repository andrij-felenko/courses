# 🧮 Математична модель закону Пейкерта та імпульсного розряду

Коли акумулятор розряджають струмом, що перевищує стандартний паспортний режим (зазвичай 0.05C або 0.2C), його доступна ємність падає нелінійно. Це явище емпірично описав німецький фізик Вільгельм Пейкерт (*Wilhelm Peukert*, 1897 рік) для свинцево-кислотних акумуляторів. У сучасних автономних вбудованих системах навантаження є імпульсним: радіомодуль (LoRa, BLE, Cellular IoT) споживає короткі пікові струми на тлі тривалого сну. Ця вставка містить аналітичне виведення закону Пейкерта, адаптацію моделі до імпульсного розряду, розрахунок еквівалентного постійного струму, методику калібрування коефіцієнта Пейкерта за двома точками вимірювання та врахування теплового фактора самонагріву.

## Класичне рівняння Пейкерта

Закон Пейкерта стверджує, що для фіксованого струму розряду `I` час розряду `t` до досягнення кінцевої напруги відсічки задовольняє степеневу залежність:

```
Iᵏ · t = Cₚ

I   — постійний струм розряду (А)
t   — час розряду до напруги відсічки (год)
k   — коефіцієнт Пейкерта (безрозмірний показник чутливості, k ≥ 1)
Cₚ  — ємність Пейкерта (чисельно дорівнює А·год при струмі I = 1 А)
```

Для ідеального хімічного джерела, в якому немає дифузійних обмежень і втрат на внутрішньому опорі, `k = 1.0`, і віддана ємність `C = I · t` не залежить від сили струму. Для реальних джерел коефіцієнт `k` лежить у межах:
* Li-ion (NMC, LCO): `k ≈ 1.02 – 1.08` (дуже малий вплив струму в межах допустимих C-рейтів);
* LiFePO4: `k ≈ 1.03 – 1.06`;
* Лужні елементи (Alkaline Zn-MnO2): `k ≈ 1.20 – 1.40` (сильне падіння ємності при струмах > 100 мА);
* Свинцево-кислотні акумулятори (SLA/AGM): `k ≈ 1.15 – 1.35`;
* Li-SOCl2 первинні елементи: при високих струмах `k` може перевищувати `1.50` через пасивацію та високий внутрішній опір.

### Зв'язок між номінальною ємністю та ємністю Пейкерта

У даташитах ємність `C_nom` зазначають для певного базового часу розряду `t_nom` (наприклад, `t_nom = 20 год` для свинцю або `t_nom = 5 год` для літію) за номінального струму `I_nom = C_nom / t_nom`.

Підставимо номінальний режим у рівняння Пейкерта:

```
Cₚ
= I_nomᵏ · t_nom                   [за означенням рівняння Пейкерта]
= (C_nom / t_nom)ᵏ · t_nom         [підстановка I_nom = C_nom / t_nom]
= C_nomᵏ · t_nom¹⁻ᵏ               [спрощення степенів часу]
```

Звідси доступний час розряду `t` для довільного постійного струму `I`:

```
t
= Cₚ / Iᵏ                         [вираження часу з базового рівняння]
= (C_nomᵏ · t_nom¹⁻ᵏ) / Iᵏ        [підстановка Cₚ через номінальні величини]
= t_nom · (C_nom / (I · t_nom))ᵏ  [групування відношення струмів]
= t_nom · (I_nom / I)ᵏ            [заміна C_nom / t_nom = I_nom]
```

Фактична ємність `C(I)`, знята з батареї при струмі `I`, становить:

```
C(I)
= I · t                           [означення ампер-годинної ємності]
= I · t_nom · (I_nom / I)ᵏ        [підстановка часу t]
= C_nom · (I_nom / I)ᵏ⁻¹          [оскільки I_nom · t_nom = C_nom]
= C_nom · (C_nom / (I · t_nom))ᵏ⁻¹ [розгорнута форма через вихідні дані]
```

## Методика визначення коефіцієнта Пейкерта за двома тестами

Якщо коефіцієнт `k` не вказано в документації виробника, його можна точно обчислити за результатами двох випробувань на електронному навантаженні при двох різних постійних струмах `I_1` та `I_2`.

Нехай у результаті першого тесту струмом `I_1` батарея пропрацювала час `t_1`, а в другому тесті струмом `I_2` — час `t_2`.

Запишемо систему рівнянь Пейкерта для двох вимірів:

```
I_1ᵏ · t_1 = Cₚ
I_2ᵏ · t_2 = Cₚ
```

Прирівняємо ліві частини та прологарифмуємо:

```
I_1ᵏ · t_1
= I_2ᵏ · t_2                      [оскільки обидва вирази дорівнюють константі Cₚ]

(I_1 / I_2)ᵏ
= t_2 / t_1                       [перенесення множників]

ln((I_1 / I_2)ᵏ)
= ln(t_2 / t_1)                   [логарифмування обох частин]

k · ln(I_1 / I_2)
= ln(t_2 / t_1)                   [властивість степеня логарифма]

k
= ln(t_2 / t_1) / ln(I_1 / I_2)   [кінцева розрахункова формула]
```

Знаючи коефіцієнт `k`, можна розрахувати час автономної роботи для будь-якого іншого струму без проведення тривалого експерименту.

## Чисельний приклад розрахунку доступної ємності

**Умова:** Лужна батарея типорозміру AA має номінальну ємність `C_nom = 2500 мА·год` при струмі `I_nom = 25 мА` (розряд протягом `t_nom = 100 год`). Коефіцієнт Пейкерта для цієї хімії `k = 1.30`. Необхідно обчислити доступну ємність і час роботи, якщо пристрій споживає постійний струм `I = 500 мА`.

```
I_ratio
= I / I_nom                       [відношення фактичного струму до номінального]
= 500 мА / 25 мА                  [підстановка значень]
= 20                              [струм у 20 разів перевищує тестовий]

C(500 мА)
= C_nom · (1 / I_ratio)ᵏ⁻¹        [формула втрати ємності]
= 2500 · (1 / 20)⁰·³⁰             [підстановка чисел: k - 1 = 0.30]
= 2500 · (0.05)⁰·³⁰               [обчислення 0.05⁰·³⁰ ≈ 0.4074]
= 2500 · 0.4074                   [перемноження]
= 1018.5 мА·год                   [доступна ємність при 500 мА]

t_work
= C(500 мА) / I                   [час роботи]
= 1018.5 мА·год / 500 мА          [ділення]
= 2.037 год                       [≈ 2 години 2 хвилини замість очікуваних 5 годин]
```

Батарея віддала лише `1018.5 / 2500 = 40.7%` своєї паспортної ємності через дифузійні обмеження електроліту та внутрішній опір.

## Узагальнення для імпульсного профілю навантаження

Вбудовані мікроконтролерні пристрої рідко споживають постійний струм. Типовий профіль живлення складається з періодичних циклів періодом `T`, де час `t_tx` пристрій передає радіопакет зі струмом `I_tx`, а решту часу `t_sleep = T - t_tx` перебуває в глибокому сні зі струмом `I_sleep`.

Коефіцієнт заповнення імпульсу (*duty cycle*):

```
D = t_tx / T
```

Середній арифметичний струм за період:

```
I_avg
= (1 - D) · I_sleep + D · I_tx    [зважений середній струм]
```

Однак швидкість витрати ємності за Пейкертом пропорційна `Iᵏ`, а не `I`. Еквівалентний струм Пейкерта `I_eff`, який спричиняє таку саму швидкість втрати хімічного ресурсу, визначається через усереднення потужності розряду за ступенем `k`:

```
I_effᵏ
= (1 / T) · ∫₀ᵀ [i(t)]ᵏ dt        [інтегральне усереднення за законом Пейкерта]
= (1 - D) · I_sleepᵏ + D · I_txᵏ  [дискретна форма для двох станів]

I_eff
= [ (1 - D) · I_sleepᵏ + D · I_txᵏ ]¹ᐟᵏ [еквівалентний постійний струм]
```

### Ефект відновлення концентрації (Diffusion Relaxation)

Під час постійного розряду великим струмом концентрація активних іонів біля поверхні електроду стрімко вичерпується. Швидкість надходження нових іонів із глибини об'єму обмежена швидкістю рідкої дифузії Фіка (*Fick's laws of diffusion*). Навколо активних центрів виникає зона збіднення, що спричиняє додаткову дифузійну поляризацію та передчасне просідання напруги до порогу відсічки.

Під час імпульсного розряду картина принципово змінюється:
1. За час короткого імпульсу `t_tx` (10–50 мс) збіднюється лише тонкий приповерхневий шар електроліту;
2. Протягом тривалого інтервалу сну `t_sleep` (1–60 с) зовнішній струм практично відсутній (`I_sleep ≈ 1 – 10 мкА`);
3. Якщо час сну значно перевищує характерну дифузійну постійну часу `τ_diff` (`t_sleep >> τ_diff`, де `τ_diff = L² / (2 · D_ion) ≈ 50 – 300 мс`), градієнт концентрації повністю вирівнюється за рахунок теплового руху молекул.

Завдяки цьому ефекту хімічної релаксації імпульсне навантаження з низькою шпаруватістю не призводить до накопичення дифузійного збіднення, і батарея здатна віддати практично всю номінальну ємність, наближаючись до режиму еквівалентного струму `I_eff`.

### Порівняльний розрахунок: постійний струм проти імпульсного режиму

**Умова:** Бездротовий вузол зв'язку LoRaWAN передає телеметрію один раз на хвилину (`T = 60 с`).
* Струм у режимі передачі: `I_tx = 150 мА`, тривалість імпульсу `t_tx = 60 мс` (`D = 0.060 / 60 = 0.001`);
* Струм у режимі сну: `I_sleep = 5 мкА = 0.005 мА`;
* Хімія первинної батареї: `C_nom = 1200 мА·год`, `I_nom = 10 мА`, `k = 1.25`.

Розрахуємо середній струм `I_avg` та еквівалентний струм Пейкерта `I_eff`:

```
I_avg
= (1 - 0.001) · 0.005 мА + 0.001 · 150 мА [підстановка параметрів]
= 0.004995 + 0.150 мА                     [обчислення доданків]
= 0.154995 мА ≈ 0.155 мА                  [середній арифметичний струм]

I_eff
= [ (1 - 0.001) · (0.005)¹·²⁵ + 0.001 · (150)¹·²⁵ ]¹ᐟ¹·²⁵ [розрахунок за степенем k=1.25]
= [ 0.999 · 0.00133 + 0.001 · 531.83 ]⁰·⁸⁰                 [обчислення 150¹·²⁵ ≈ 531.83]
= [ 0.00133 + 0.53183 ]⁰·⁸⁰                                [сума під коренем]
= [ 0.53316 ]⁰·⁸⁰                                          [піднесення до степеня 0.80]
= 0.605 мА                                                 [еквівалентний струм розряду]
```

Оскільки `I_eff = 0.605 мА < I_nom = 10 мА`, батарея працює в області малих еквівалентних струмів і віддасть практично `100%` паспортної ємності. Якби той самий струм `150 мА` подавався безперервно, ефективна ємність становила б лише:

```
C(150 мА)
= 1200 · (10 / 150)⁰·²⁵           [підстановка для постійного струму 150 мА]
= 1200 · (0.0667)⁰·²⁵             [обчислення кореня 4-го степеня]
= 1200 · 0.508                    [множення на коефіцієнт]
= 609.6 мА·год                    [втрата майже 50% ємності]
```

## Неізотермічна корекція закону Пейкерта та самонагрів

Класичний закон Пейкерта передбачає ізотермічні умови (`T = const`). Проте при високих постійних струмах розряду (1C–3C) джоулеве тепловиділення на внутрішньому опорі стає відчутним:

```
P_heat = I² · R_int
```

Виділене тепло нагріває комірку, що за рівнянням Арреніуса знижує в'язкість електроліту та зменшує внутрішній опір `R_int(T)`. У результаті нагрівання дещо компенсує дифузійні втрати, і реальна крива розряду за високих струмів може показати вищу ємність, ніж прогнозує чистий ізотермічний закон Пейкерта.

Навпаки, в імпульсному режимі середнє тепловиділення мізерне (`P_avg = I_avg · V_drop ≈ 0.155 мА · 0.1 В = 15.5 мкВт`), самонагрів відсутній, і батарея працює суто за температури навколишнього середовища. Цей факт підкреслює необхідність випробування джерел живлення саме на реальних шпаруватих профілях, а не на постійному струмі еквівалентної амплітуди.
