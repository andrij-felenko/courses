# 📋 Повідомлення уставок MAVLink: SET_POSITION_TARGET_LOCAL_NED та SET_ATTITUDE_TARGET

Цей довідник визначає двійковий контракт MAVLink-повідомлень, якими бортовий супутній комп'ютер (*companion computer*) передає динамічні уставки польотному контролеру (PX4 / ArduPilot) у режимах Offboard та Guided. Описано призначення полів, кодування інвертованої бітової маски, вибір систем координат, математичні вимоги до параметрів, коди підтвердження та механіку взаємодії з каскадом регуляторів.

## SET_POSITION_TARGET_LOCAL_NED (Message #84)

Повідомлення `SET_POSITION_TARGET_LOCAL_NED` є основним каналом для позиційного, швидкісного та комбінованого ведення апарата в локальній навігаційній системі. Воно дає змогу задавати цільові координати, вектор лінійної швидкості, вектор лінійного прискорення (або сили тяги), а також кут курсу чи швидкість рискання.

### Структура двійкового кадру

| Байт | Поле | Тип | Одиниця | Призначення |
|---|---|---|---|---|
| 0–3 | `time_boot_ms` | `uint32_t` | мс | Часова мітка від старту бортового комп'ютера або FCU (0, якщо не синхронізовано) |
| 4–7 | `x` | `float` | м | Позиція X у вибраній системі координат (North / Forward) |
| 8–11 | `y` | `float` | м | Позиція Y у вибраній системі координат (East / Right) |
| 12–15 | `z` | `float` | м | Позиція Z у вибраній системі координат (Down / глибина, від'ємна при наборі висоти) |
| 16–19 | `vx` | `float` | м/с | Швидкість уздовж осі X |
| 20–23 | `vy` | `float` | м/с | Швидкість уздовж осі Y |
| 24–27 | `vz` | `float` | м/с | Швидкість уздовж осі Z (додатна — зниження, від'ємна — підйом) |
| 28–31 | `afx` | `float` | м/с² | Лінійне прискорення або складова сили тяги вздовж осі X |
| 32–35 | `afy` | `float` | м/с² | Лінійне прискорення або складова сили тяги вздовж осі Y |
| 36–39 | `afz` | `float` | м/с² | Лінійне прискорення або складова сили тяги вздовж осі Z |
| 40–43 | `yaw` | `float` | рад | Цільовий абсолютний кут курсу (0 = Північ, зростає за годинниковою) |
| 44–47 | `yaw_rate` | `float` | рад/с | Цільова кутова швидкість обертання навколо вертикальної осі Z |
| 48–49 | `type_mask` | `uint16_t` | біти | Бітова маска ігнорування полів (1 = ігнорувати, 0 = обробляти) |
| 50 | `target_system` | `uint8_t` | id | Ідентифікатор цільової системи (зазвичай 1 для головного автопілота) |
| 51 | `target_component` | `uint8_t` | id | Ідентифікатор цільового компонента (`MAV_COMP_ID_AUTOPILOT1` = 1) |
| 52 | `coordinate_frame` | `uint8_t` | enum | Базова система координат (`MAV_FRAME`) |

### Інженерні вимоги до полів повідомлення

1. **Часова мітка `time_boot_ms`:**
   Поле визначає час за внутрішнім монотонним годинником апарата. Якщо супутній комп'ютер синхронізований з польотним контролером через механізм `TIMESYNC` MAVLink, сюди записується обчислений час автопілота. Якщо жорстка синхронізація відсутня, поле заповнюється нулем (`0`). Польотний контролер при значенні `0` застосовує уставку негайно в момент прийому пакета, використовуючи локальну мітку часу EKF.

2. **Вектори прискорення та сили (`afx, afy, afz`):**
   За замовчуванням поля виражаються в м/с². Якщо біт `POSITION_TARGET_TYPEMASK_FORCE_SET` (`0x0200`) виставлений у `0` (тобто сила активна), автопілот трактує значення в Ньютонах. Для перерахунку сили в необхідне прискорення польотний контролер використовує оцінку поточної злітної маси апарата (`vehicle_mass` або параметр `WEIGHT_GROSS`).

3. **Координата Z та швидкість Vz:**
   Оскільки стандартною системою відліку є NED (*North-East-Down*), вертикальна вісь спрямована вниз. Щоб піднятися на висоту 20 метрів над точкою старту, у поле `z` необхідно передати `-20.0f`. Щоб підійматися вгору зі швидкістю 2 м/с, у поле `vz` передається `-2.0f`. Передача додатних значень без урахування знаку NED спричиняє команду на зниження або зіткнення з поверхнею.

### Бітова маска `type_mask` (POSITION_TARGET_TYPEMASK)

Поле `type_mask` побудоване за принципом **ігнорування**: виставлений біт `1` вказує автопілоту **не зважати** на відповідне поле структури. Якщо біт дорівнює `0`, поле вважається активною уставкою.

| Біт | Шістнадцяткове | Назва константи | Призначення при значенні 1 |
|---|---|---|---|
| 0 | `0x0001` | `POSITION_TARGET_TYPEMASK_X_IGNORE` | Ігнорувати позицію X |
| 1 | `0x0002` | `POSITION_TARGET_TYPEMASK_Y_IGNORE` | Ігнорувати позицію Y |
| 2 | `0x0004` | `POSITION_TARGET_TYPEMASK_Z_IGNORE` | Ігнорувати позицію Z |
| 3 | `0x0008` | `POSITION_TARGET_TYPEMASK_VX_IGNORE` | Ігнорувати швидкість Vx |
| 4 | `0x0010` | `POSITION_TARGET_TYPEMASK_VY_IGNORE` | Ігнорувати швидкість Vy |
| 5 | `0x0020` | `POSITION_TARGET_TYPEMASK_VZ_IGNORE` | Ігнорувати швидкість Vz |
| 6 | `0x0040` | `POSITION_TARGET_TYPEMASK_AX_IGNORE` | Ігнорувати прискорення Ax |
| 7 | `0x0080` | `POSITION_TARGET_TYPEMASK_AY_IGNORE` | Ігнорувати прискорення Ay |
| 8 | `0x0100` | `POSITION_TARGET_TYPEMASK_AZ_IGNORE` | Ігнорувати прискорення Az |
| 9 | `0x0200` | `POSITION_TARGET_TYPEMASK_FORCE_SET` | Трактувати поля `afx/afy/afz` як силу (Ньютони), а не прискорення |
| 10 | `0x0400` | `POSITION_TARGET_TYPEMASK_YAW_IGNORE` | Ігнорувати абсолютний кут `yaw` |
| 11 | `0x0800` | `POSITION_TARGET_TYPEMASK_YAW_RATE_IGNORE` | Ігнорувати швидкість `yaw_rate` |

### Крайові випадки та конфлікти бітових масок

- **Конфлікт усіх нулів (`0x0000`):** Якщо всі біти виставлені в 0, автопілот намагається одночасно замкнути контури за позицією, швидкістю та прискоренням. Якщо вектор швидкості не узгоджений із різницею позицій, регулятори починають боротися між собою, спричиняючи високочастотні коливання моторів.
- **Конфлікт курсу (`yaw` та `yaw_rate` обидва 0):** Якщо біти 10 і 11 скинуті в нуль одночасно, автопілот надає перевагу абсолютному куту `yaw`, а поле `yaw_rate` ігнорує, або відхиляє кадр через неоднозначність цілі.
- **Повна маска ігнорування (`0x0FFF`):** Якщо всі біти виставлені в 1, повідомлення не несе жодної уставки. Автопілот фіксує отримання порожнього пакета, не змінює цільовий стан і при збереженні такої маски понад 500 мс активує аварійний відкат Offboard.

### Типові робочі конфігурації масок

- **Тільки позиція (Position control, фіксований курс):**
  Ігноруються швидкості, прискорення та швидкість курсу.
  Маска: `0x0008 | 0x0010 | 0x0020 | 0x0040 | 0x0080 | 0x0100 | 0x0800` = `0x0DF8` (десяткове `3576`).
- **Тільки швидкість (Velocity control, фіксований курс):**
  Ігноруються позиції, прискорення та швидкість курсу.
  Маска: `0x0001 | 0x0002 | 0x0004 | 0x0040 | 0x0080 | 0x0100 | 0x0800` = `0x0DC7` (десяткове `3527`).
- **Тільки швидкість зі швидкістю рискання (Velocity + Yaw Rate):**
  Ігноруються позиції, прискорення та абсолютний кут курсу.
  Маска: `0x0001 | 0x0002 | 0x0004 | 0x0040 | 0x0080 | 0x0100 | 0x0400` = `0x05C7` (десяткове `1479`).
- **Комбіноване керування (Position + Feed-forward Velocity):**
  Активні позиція та лінійна швидкість одночасно.
  Маска: `0x0040 | 0x0080 | 0x0100 | 0x0800` = `0x09C0` (десяткове `2496`).

### Перелік систем координат (`coordinate_frame`)

| Значення | Енумератор MAVLink | Базова площина | Орієнтація осей |
|---|---|---|---|
| 1 | `MAV_FRAME_LOCAL_NED` | Точка зльоту / Home | X — Північ, Y — Схід, Z — вниз до центру Землі |
| 7 | `MAV_FRAME_LOCAL_OFFSET_NED` | Поточна позиція апарата | Зсув у метрах паралельно світовим осям NED |
| 8 | `MAV_FRAME_BODY_NED` | Центр мас апарата | Осі закріплені на апараті, орієнтовані на Північ/Схід |
| 12 | `MAV_FRAME_BODY_OFFSET_NED` | Центр мас апарата | X — ніс (Forward), Y — правий борт (Right), Z — днище (Down) |

## SET_ATTITUDE_TARGET (Message #83)

Повідомлення `SET_ATTITUDE_TARGET` передає уставки безпосередньо в контур стабілізації орієнтації, минаючи розрахунок траєкторії та позиційні регулятори. Воно використовується для швидкісного маневрування, утримання специфічних кутів крену/тангажу та прямого керування кутовими швидкостями (*rate control*).

### Структура кадру

| Байт | Поле | Тип | Одиниця | Призначення |
|---|---|---|---|---|
| 0–3 | `time_boot_ms` | `uint32_t` | мс | Часова мітка від старту системи |
| 4–19 | `q` | `float[4]` | кватерніон | Цільова орієнтація у формі одиничного кватерніона `[w, x, y, z]` |
| 20–23 | `body_roll_rate` | `float` | рад/с | Кутова швидкість крену у зв'язаній системі апарата |
| 24–27 | `body_pitch_rate` | `float` | рад/с | Кутова швидкість тангажу у зв'язаній системі апарата |
| 28–31 | `body_yaw_rate` | `float` | рад/с | Кутова швидкість рискання у зв'язаній системі апарата |
| 32–35 | `thrust` | `float` | 0.0..1.0 | Нормована колективна тяга пропелерів (0.0 — зупинка, 1.0 — 100% потужність) |
| 36 | `target_system` | `uint8_t` | id | Ідентифікатор системи |
| 37 | `target_component` | `uint8_t` | id | Ідентифікатор компонента |
| 38 | `type_mask` | `uint8_t` | біти | Бітова маска ігнорування складових орієнтації |

### Вимоги до кватерніона `q` та тяги `thrust`

1. **Нормалізація кватерніона:**
   Кватерніон орієнтації обов'язково повинен задовольняти умову одиничної норми: `w² + x² + y² + z² = 1.0`. Якщо через помилку обчислень або втрату точності норма відхиляється від одиниці більш ніж на 1%, фільтр EKF та регулятори PX4 скидають орієнтацію в нуль або генерують попередження `CRITICAL_NAV_ATTITUDE_INVALID`.
2. **Масштабування тяги:**
   Поле `thrust` нормоване в діапазоні від `0.0f` (мотори вимкнено або мінімальний газ холостого ходу) до `1.0f` (максимальна злітна тяга). Для більшості коптерів тяга зависання (*hover thrust*) становить близько `0.25f – 0.40f`. Передача `thrust = 1.0f` призводить до екстремального вертикального прискорення (до 2–4 g).

### Бітова маска `type_mask` для орієнтації

| Біт | Шістнадцяткове | Назва константи | Призначення при значенні 1 |
|---|---|---|---|
| 0 | `0x01` | `ATTITUDE_TARGET_TYPEMASK_BODY_ROLL_RATE_IGNORE` | Ігнорувати швидкість крену |
| 1 | `0x02` | `ATTITUDE_TARGET_TYPEMASK_BODY_PITCH_RATE_IGNORE` | Ігнорувати швидкість тангажу |
| 2 | `0x04` | `ATTITUDE_TARGET_TYPEMASK_BODY_YAW_RATE_IGNORE` | Ігнорувати швидкість рискання |
| 6 | `0x40` | `ATTITUDE_TARGET_TYPEMASK_THROTTLE_IGNORE` | Ігнорувати поле колективної тяги `thrust` |
| 7 | `0x80` | `ATTITUDE_TARGET_TYPEMASK_ATTITUDE_IGNORE` | Ігнорувати кватерніон орієнтації `q` |

- **Керування кутами та тягою (Attitude + Thrust):**
  Ігноруються кутові швидкості: маска = `0x01 | 0x02 | 0x04` = `0x07` (`7`).
- **Керування кутовими швидкостями (Body Rates + Thrust):**
  Ігнорується кватерніон орієнтації: маска = `0x80` (`128`). Контролер стабілізує лише динаміку обертання, як у спортивному режимі Acro.

## Команда активації режиму: MAV_CMD_DO_SET_MODE (#176)

Для перемикання автопілота в режим Offboard (у PX4) або Guided (в ArduPilot) використовується універсальна команда `COMMAND_LONG` (Message #76) із номером команди `MAV_CMD_DO_SET_MODE` = `176`.

### Параметри для PX4

| Параметр | Поле команди | Значення для PX4 Offboard |
|---|---|---|
| Param 1 | `base_mode` | `MAV_MODE_FLAG_CUSTOM_MODE_ENABLED` (`1` або `209` при armed) |
| Param 2 | `custom_main_mode` | `PX4_CUSTOM_MAIN_MODE_OFFBOARD` (`6`) |
| Param 3 | `custom_sub_mode` | `0` (за замовчуванням) |

### Параметри для ArduPilot (Copter)

| Параметр | Поле команди | Значення для ArduPilot Guided |
|---|---|---|
| Param 1 | `base_mode` | `MAV_MODE_FLAG_CUSTOM_MODE_ENABLED` (`1`) |
| Param 2 | `custom_main_mode` | `COPTER_MODE_GUIDED` (`4`) |
| Param 3 | `custom_sub_mode` | `0` |

### Коди підтвердження автопілота (COMMAND_ACK #77)

Після відправки команди автопілот повертає кадр `COMMAND_ACK` із кодом результату `result`:
- `MAV_RESULT_ACCEPTED (0)` — режим успішно увімкнено;
- `MAV_RESULT_TEMPORARILY_REJECTED (1)` — перехід тимчасово заблоковано (немає потоку уставок, EKF ще не оцінив позицію або апарат не озброєно);
- `MAV_RESULT_DENIED (2)` — команду відхилено конфігурацією безпеки (наприклад, спрацював геофенс або увімкнено блокування двигунів kill-switch);
- `MAV_RESULT_UNSUPPORTED (3)` — прошивка не підтримує запитаний режим;
- `MAV_RESULT_FAILED (4)` — загальна внутрішня помилка автопілота.

## Зворотний зв'язок: обов'язкові повідомлення телеметрії

Бортовий комп'ютер зобов'язаний зчитувати зворотну телеметрію від польотного контролера для контролю відпрацювання уставок:
- `LOCAL_POSITION_NED (#32)` — поточна оцінка координат `x, y, z` та лінійних швидкостей `vx, vy, vz` від EKF;
- `ATTITUDE (#30)` — поточні кути крену, тангажу, курсу та кутові швидкості;
- `ESTIMATOR_STATUS (#230)` — прапорці здоров'я фільтра оцінки (біти інновацій та точності позиціонування);
- `HEARTBEAT (#0)` — поточний режим польоту (`custom_mode`), прапорець озброєння (`base_mode & MAV_MODE_FLAG_SAFETY_ARMED`) та стан системи.

#include <stdint.h>
#include <string.h>
#include <common/mavlink.h>

void pack_velocity_setpoint(mavlink_message_t *msg,
                            uint8_t sys_id, uint8_t comp_id,
                            float vx_ms, float vy_ms, float vz_ms,
                            float yaw_rad)

    mavlink_set_position_target_local_ned_t sp;
    memset(&sp, 0, sizeof(sp));

    sp.time_boot_ms = 0;
    sp.target_system = 1;
    sp.target_component = MAV_COMP_ID_AUTOPILOT1;
    sp.coordinate_frame = MAV_FRAME_LOCAL_NED;

    /* Маска: ігноруємо позицію, прискорення та швидкість yaw */
    sp.type_mask = MAVLINK_MSG_SET_POSITION_TARGET_LOCAL_NED_POSITION_TRAINED_IGNORE
                 | 0x0001 | 0x0002 | 0x0004   /* ignore X, Y, Z */
                 | 0x0040 | 0x0080 | 0x0100   /* ignore AFX, AFY, AFZ */
                 | 0x0800;                    /* ignore yaw_rate */

    sp.vx = vx_ms;
    sp.vy = vy_ms;
    sp.vz = vz_ms;
    sp.yaw = yaw_rad;

    mavlink_msg_set_position_target_local_ned_encode(sys_id, comp_id, msg, &sp);
}
