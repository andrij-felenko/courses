# 🧮 Схема розділення секрету Шаміра: поліноми над скінченними полями

Схема розділення секрету (англ. *secret sharing scheme*) розв'язує фундаментальну суперечність безпеки: як зберегти криптографічний ключ так, щоб його не можна було скомпрометувати через зраду однієї особи, але водночас не втратити назавжди через раптову загибель чи втрату доступу одного зі співробітників. Якщо створити одну копію ключа, виникає єдина точка відмови (англ. *single point of failure*); якщо створити п'ять однакових копій і роздати п'яти людям, імовірність витоку зростає вп'ятеро. Математичне розв'язання цієї проблеми, запропоноване Аді Шаміром (івр. עדי שמיר) у 1979 році, спирається на базову теорему алгебри: крізь `k` точок на площині проходить один і лише один поліном степеня `k − 1`.

Ця математична вставка розбирає алгебраїчний апарат схеми порогу `(k, n)`, виводить формули інтерполяції Лагранжа над скінченними полями Галуа `GF(p)` та `GF(256)`, доводить абсолютну інформаційну стійкість схеми за Шенноном і показує покрокове числове відновлення ключа.

## Алгебраїчна побудова схеми (k, n)

Нехай нам потрібно розділити секрет `S`, представлений у вигляді цілого числа, між `n` учасниками так, щоб будь-які `k` учасників могли відновити `S`, але будь-яка група з `k − 1` або меншої кількості учасників не отримала жодної інформації про значення `S`.

Обираємо просте число `p`, яке строго більше за значення секрету `S` та загальну кількість часток `n` (`p > S` і `p > n`). Усі подальші арифметичні операції виконуються в скінченному полі `GF(p)` (або `ℤ/pℤ`).

Будуємо випадковий поліном `P(x)` степеня `k − 1`:

```
P(x) = a₀ + a₁·x + a₂·x² + … + aₖ₋₁·xᵏ⁻¹  (mod p)
```

Коефіцієнти полінома обираються за такими правилами:
1. Вільний член `a₀` встановлюється рівним самому секрету: `a₀ = S`.
2. Решта `k − 1` коефіцієнтів `a₁, a₂, …, aₖ₋₁` генеруються незалежно та рівноймовірно як випадкові числа з інтервалу `[0, p − 1]`.

Для кожного з `n` учасників обчислюється його частка секрету як пара координат `(xᵢ, yᵢ)`, де:
- `xᵢ` — ненульовий відкритий індекс учасника (`xᵢ ∈ {1, 2, …, n}`, причому всі `xᵢ` попарно різні);
- `yᵢ` — значення полінома в точці `xᵢ`: `yᵢ = P(xᵢ) mod p`.

Кожен учасник отримує свою частку `(xᵢ, yᵢ)`. Самі коефіцієнти `a₁, …, aₖ₋₁` та значення `P(0)` негайно знищуються в пам'яті комп'ютера.

*Геометрична сутність схеми Шаміра для порогу k = 3: через три точки (частки) на площині проходить єдина парабола, вільний член якої P(0) дорівнює секрету S. Дві точки залишають вільним один ступінь свободи, роблячи будь-яке значення S на осі Y однаково ймовірним.*

## Відновлення секрету через інтерполяційний поліном Лагранжа

Нехай зібралося довільне підмножина з `k` учасників із частками `(x₁, y₁), (x₂, y₂), …, (xₖ, yₖ)`. Оскільки степінь полінома дорівнює `k − 1`, за теоремою про єдиність інтерполяційного полінома існує рівно один такий поліном, що проходить крізь ці `k` точок.

За формулою Лагранжа поліном `P(x)` записується як лінійна комбінація базисних поліномів:

```
P(x) = ∑ [j=1..k] yⱼ · ℓⱼ(x)  (mod p)
```

де базисні поліноми Лагранжа `ℓⱼ(x)` мають вигляд:

```
ℓⱼ(x) = ∏ [m=1..k, m≠j] (x − xₘ) / (xⱼ − xₘ)  (mod p)
```

Оскільки нам не потрібен весь поліном `P(x)`, а лише вільний член `S = P(0)`, підставляємо `x = 0`:

```
S = P(0) = ∑ [j=1..k] yⱼ · ℓⱼ(0)  (mod p)
```

Обчислення коефіцієнтів Лагранжа `ℓⱼ(0)` у точці нуля спрощується до добутку:

```
ℓⱼ(0) = ∏ [m=1..k, m≠j] (0 − xₘ) / (xⱼ − xₘ)
       = ∏ [m=1..k, m≠j] (−xₘ) / (xⱼ − xₘ)
       = ∏ [m=1..k, m≠j] xₘ / (xₘ − xⱼ)  (mod p)
```

Ділення у виразі `xₘ / (xₘ − xⱼ) mod p` виконується як множення на модульне обернене значення знаменника:

```
(xₘ − xⱼ)⁻¹ mod p
```

яке обчислюється за розширеним алгоритмом Евкліда або за малою теоремою Ферма: `a⁻¹ ≡ aᵖ⁻² (mod p)`.

## Доведення досконалої секретності за Шенноном

Схема Шаміра володіє властивістю **досконалої секретності** (англ. *information-theoretic security*): знання будь-яких `k − 1` часток не дає атакуючому жодного біта інформації про секрет `S`. Його шанси вгадати секрет становлять рівно `1 / p`, ніби він не знає жодної частки взагалі.

Доведемо це математично.

Нехай зловмисник перехопив `k − 1` часток: `(x₁, y₁), (x₂, y₂), …, (xₖ₋₁, yₖ₋₁)`. Розглянемо довільне гіпотетичне значення секрету `S' ∈ GF(p)`.

Складемо систему з `k` лінійних рівнянь відносно `k` невідомих коефіцієнтів `a₀, a₁, …, aₖ₋₁`:

```
a₀ = S'
a₀ + a₁·x₁ + a₂·x₁² + … + aₖ₋₁·x₁ᵏ⁻¹ = y₁  (mod p)
a₀ + a₁·x₂ + a₂·x₂² + … + aₖ₋₁·x₂ᵏ⁻¹ = y₂  (mod p)
…
a₀ + a₁·xₖ₋₁ + a₂·xₖ₋₁² + … + aₖ₋₁·xₖ₋₁ᵏ⁻¹ = yₖ₋₁  (mod p)
```

Матриця цієї системи є матрицею Вандермонда розміру `k × k` для точок `0, x₁, x₂, …, xₖ₋₁`:

```
V = [
  1   0     0     …  0
  1   x₁    x₁²   …  x₁ᵏ⁻¹
  1   x₂    x₂²   …  x₂ᵏ⁻¹
  …   …     …     …  …
  1   xₖ₋₁  xₖ₋₁² …  xₖ₋₁ᵏ⁻¹
]
```

Визначник матриці Вандермонда дорівнює:

```
det(V) = ∏ [0 ≤ i < j ≤ k−1] (xⱼ − xᵢ)  (mod p)
```

Оскільки всі `xᵢ` ненульові та попарно різні, `det(V) ≢ 0 (mod p)`. Отже, матриця невироджена, і за теоремою Крамера система має **єдиний** розв'язок для вектора коефіцієнтів `(a₀, a₁, …, aₖ₋₁)`.

Це означає, що для **кожного** можливого значення `S' ∈ GF(p)` існує рівно один поліном степеня `k − 1`, який узгоджується як із перехопленими частками `(x₁, y₁), …, (xₖ₋₁, yₖ₋₁)`, так і з умовою `P(0) = S'`.

Оскільки випадкові коефіцієнти `a₁, …, aₖ₋₁` обиралися незалежно та рівноймовірно з простору `GF(p)`, усі ці поліноми рівноймовірні. Звідси апріорна ймовірність дорівнює апостеріорній:

```
P(S = s | (x₁, y₁), …, (xₖ₋₁, yₖ₋₁)) = P(S = s) = 1 / p
```

Отже, взаємна інформація між секретом `S` та будь-яким набором із `k − 1` часток дорівнює нулю: `I(S; Y₁, …, Yₖ₋₁) = 0`.

## Покроковий числовий приклад

Розглянемо схему `(3, 5)`: розділимо секрет `S = 1234` на 5 часток із порогом відновлення 3.

Обираємо просте число `p = 2089` (`p > 1234` та `p > 5`).

### 1. Генерація полінома

Потрібен поліном степеня `k − 1 = 2`:

```
P(x) = a₀ + a₁·x + a₂·x²  (mod 2089)
```

Встановлюємо:
- `a₀ = 1234` (секрет)
- `a₁ = 166` (випадковий коефіцієнт)
- `a₂ = 94` (випадковий коефіцієнт)

Поліном набуває вигляду:

```
P(x) = 1234 + 166·x + 94·x²  (mod 2089)
```

### 2. Обчислення часток для 5 учасників

Обчислюємо значення `yᵢ = P(xᵢ) mod 2089` для `x ∈ {1, 2, 3, 4, 5}`:

```
P(1) = 1234 + 166·1 + 94·1²   = 1494 mod 2089  →  Частка 1: (1, 1494)
P(2) = 1234 + 166·2 + 94·2²   = 1942 mod 2089  →  Частка 2: (2, 1942)
P(3) = 1234 + 166·3 + 94·3²   = 2578 = 489 mod 2089 → Частка 3: (3, 489)
P(4) = 1234 + 166·4 + 94·4²   = 3402 = 1313 mod 2089 → Частка 4: (4, 1313)
P(5) = 1234 + 166·5 + 94·5²   = 4414 = 236 mod 2089 → Частка 5: (5, 236)
```

### 3. Відновлення секрету за 3 частками

Припустимо, для відновлення зібралися учасники з частками 2, 3 та 5:
- `(x₁, y₁) = (2, 1942)`
- `(x₂, y₂) = (3, 489)`
- `(x₃, y₃) = (5, 236)`

Обчислюємо базисні коефіцієнти Лагранжа `ℓⱼ(0) mod 2089`:

```
ℓ₁(0) = (x₂ / (x₂ − x₁)) · (x₃ / (x₃ − x₁))  [формула базису Лагранжа для першої точки]
      = (3 / (3 − 2)) · (5 / (5 − 2))         [підстановка x₁=2, x₂=3, x₃=5]
      = (3 / 1) · (5 / 3)                     [обчислення різниць]
      = 5 mod 2089                            [скорочення на 3 у полі GF(2089)]

ℓ₂(0) = (x₁ / (x₁ − x₂)) · (x₃ / (x₃ − x₂))  [формула базису Лагранжа для другої точки]
      = (2 / (2 − 3)) · (5 / (5 − 3))         [підстановка x₁=2, x₂=3, x₃=5]
      = (2 / −1) · (5 / 2)                    [обчислення різниць]
      = −5 = 2084 mod 2089                    [скорочення на 2 та зведення за модулем 2089]

ℓ₃(0) = (x₁ / (x₁ − x₃)) · (x₂ / (x₂ − x₃))  [формула базису Лагранжа для третьої точки]
      = (2 / (2 − 5)) · (3 / (3 − 5))         [підстановка x₁=2, x₂=3, x₃=5]
      = (2 / −3) · (3 / −2)                   [обчислення різниць]
      = 1 mod 2089                            [скорочення однакових множників]
```

Обчислюємо відновлений секрет `S`:

```
S = y₁·ℓ₁(0) + y₂·ℓ₂(0) + y₃·ℓ₃(0)  (mod 2089)  [лінійна комбінація часток із вагами Лагранжа]
  = 1942 · 5 + 489 · (−5) + 236 · 1             [підстановка обчислених ваг і часток]
  = 9710 − 2445 + 236                           [множення компонент]
  = 7501                                        [арифметична сума]
  = 3 · 2089 + 1234                             [виділення цілої частини модуля: 7501 = 6267 + 1234]
  = 1234 mod 2089                               [остаточне значення відновленого секрету S]
```

Секрет `1234` відновлено безпомилково.

## Реалізація над полем Галуа GF(256) для бінарних даних

У практичних криптосистемах довжина секретного ключа становить 256 біт (32 байти для Ed25519 або AES-256). Розбивати 256-бітне число як єдине ціле над великим простим полем `GF(p)` вимагає бібліотеки довгої арифметики.

Набагато ефективніше застосовувати схему Шаміра **побайтово** над полем `GF(2⁸) = GF(256)`. У цьому разі кожен байт ключа розглядається як незалежний секрет `S ∈ GF(256)`. Довжина кожної частки залишається рівно 32 байти (плюс 1 байт індексу `x`), що виключає роздування розміру даних.

Операції в `GF(256)`:
- Додавання та віднімання збігаються і виконуються як побітове виключне АБО (`XOR`): `a ⊕ b`.
- Множення виконується як множення многочленів за незвідним модулем `m(x) = x⁸ + x⁴ + x³ + x + 1` (число `0x11B` у шістнадцятковому записі).

У табличному вигляді множення в `GF(256)` реалізується за `O(1)` за допомогою таблиць логарифмів `exp_table` та `log_table` на основі генератора поля `g = 0x03`:

```
a · b = exp_table[(log_table[a] + log_table[b]) mod 255]  (якщо a ≠ 0 і b ≠ 0)
```

Такий побайтовий підхід працює швидко, детерміновано та з постійним часом виконання, що унеможливлює атаки за часом (англ. *timing attacks*).
