# 🧮 Розрахунок цільового імпедансу шини живлення та паразитних резонансів

Коли навантаження у вбудованій системі змінює споживання на величину `ΔI` за проміжок часу `Δt`, напруга на шині живлення змінюється на величину `ΔU`. Щоб цифрові та аналогові компоненти працювали стабільно без збоїв логіки, напруга живлення повинна залишатися у строго визначених межах допуску (зазвичай `±5 %` від номіналу). Розподільча мережа живлення (Power Distribution Network, PDN) повинна мати повний опір (імпеданс), який не перевищує критичної межі на всіх робочих частотах спектра перехідного процесу.

### 1. Визначення та розрахунок цільового імпедансу (Target Impedance)

Повний частотний опір шини живлення позначають як імпеданс `Z_pdn(ω)`. Якщо номінальна напруга живлення дорівнює `V_nom`, а максимальне дозволене відносне відхилення напруги становить частку `δ` (наприклад, `5 % = 0.05`), то максимальний допустимий абсолютний спад напруги дорівнює:

```
ΔU_max
= V_nom · δ               [допустимий абсолютний спад напруги шини]
```

За законом Ома для змінного струму, якщо навантаження здійснює стрибок споживання на величину `ΔI_step`, імпеданс шини живлення `Z_pdn(ω)` на жодній частоті спектра комутації не повинен перевищувати розрахункового **цільового імпедансу** `Z_target`:

```
Z_target
= ΔU_max / ΔI_step        [означення цільового імпедансу розподільчої мережі]
= (V_nom · δ) / ΔI_step   [підстановка допустимого спаду напруги через допуск]
```

**Практичний числовий приклад.** Мікроконтролерний модуль із напругою живлення `3.3 В` вмикає інтегрований радіопередавач із вихідним підсилювачем потужності. Струм споживання стрибає на `ΔI_step = 1.2 А`. Допустиме відхилення напруги становить `5 %` (`δ = 0.05`):

```
ΔU_max
= 3.3 · 0.05             [обчислення максимального абсолютного спаду]
= 0.165 В                 [максимально дозволена просадка становить 165 мВ]

Z_target
= 0.165 / 1.2             [ділення допустимого спаду на стрибок струму]
= 0.1375 Ом               [імпеданс PDN на всіх частотах має бути нижчим за 137.5 мОм]
```

Це означає, що на будь-якій частоті — від постійного струму (0 Гц) до частот перемикання вентилів (сотні мегагерців) — повний опір між живильною шиною та землею повинен бути меншим за `137.5 мОм`.

### 2. Розрахунок мінімальної ємності накопичувального резервуара (Bulk Capacitance)

Електронний стабілізатор джерела живлення (лінійний LDO або імпульсний DC-DC перетворювач) має кінцеву смугу пропускання петлі зворотного зв'язку. Час реакції стабілізатора `t_response` на раптову зміну струму становить від 5 до 50 мікросекунд. Упродовж усього цього проміжку часу стабілізатор ще «не знає» про збільшення навантаження, і весь додатковий струм `ΔI_step` повинен постачатися виключно локальними накопичувальними конденсаторами плати.

Зв'язок між струмом розряду ємності та швидкістю спаду напруги визначається фундаментальним рівнянням конденсатора:

```
I = C · (dU/dt)
```

Інтегруючи це рівняння за часом реакції джерела `t_response` за умови постійного струму розряду під час комутації:

```
C_bulk
= (ΔI_step · t_response) / ΔU_max   [мінімально необхідна ємність накопичувального резервуара]
```

Підставивши значення для нашого числового прикладу (`ΔI_step = 1.2 А`, `t_response = 20 мкс = 20 · 10⁻⁶ с`, `ΔU_max = 0.165 В`):

```
C_bulk
= (1.2 · 20·10⁻⁶) / 0.165          [підстановка значень струму, часу та напруги]
= (24·10⁻⁶) / 0.165                [обчислення заряду в кулонах]
= 145.45·10⁻⁶ Ф                    [результат у фарадах]
≈ 150 мкФ                          [вибір найближчого стандартного номіналу ємності]
```

Окрім самої ємності, еквівалентний послідовний опір (ESR) цього конденсатора не повинен перевищувати величину `Z_target`. У першу ж наносекунду після стрибка струму напруга на виводах конденсатора стрибкоподібно падає на омічний спад `ΔU_esr = ΔI_step · ESR`:

```
ESR_max
= ΔU_max / ΔI_step                 [граничний опір втрат конденсатора]
= Z_target                         [рівність цільовому імпедансу]
= 0.1375 Ом                        [ESR конденсатора повинен бути суворо меншим за 137.5 мОм]
```

### 3. Паразитний паралельний антирезонанс конденсаторів

На практиці інженери встановлюють паралельно два типи конденсаторів: великий електролітичний конденсатор `C_1` (з ємністю `C_1 ≈ 100 мкФ` та індуктивністю виводів `L_1 ≈ 5 нГн`) для низьких частот і малий високочастотний керамічний конденсатор `C_2` (з ємністю `C_2 ≈ 0.1 мкФ` та індуктивністю `L_2 ≈ 0.8 нГн`) для високих частот.

Кожен реальний конденсатор має власну послідовну резонансну частоту (Self-Resonant Frequency, SRF):
- Нижче своєї власної частоти SRF конденсатор поводиться як **ємність** (імпеданс падає зі зростанням частоти як `1 / (ω·C)`).
- Вище своєї частоти SRF через паразитну індуктивність виводів і корпусу (ESL) конденсатор починає поводитися як **індуктивність** (імпеданс росте зі зростанням частоти як `ω·L`).

У проміжному діапазоні частот між резонансами двох конденсаторів виникає небезпечний ефект: великий конденсатор `C_1` вже перейшов свою частоту SRF і поводиться як індуктивність `L_1`, а малий конденсатор `C_2` ще не дійшов до власного SRF і працює як ємність `C_2`. Їхнє паралельне з'єднання утворює паралельний коливальний контур — **антирезонанс шини живлення**.

Комплексна провідність паралельної пари на кутовій частоті `ω`:

```
Y_total(ω)
= Y_1(ω) + Y_2(ω)                                        [сума комплексних провідностей гілок]
= 1 / (ESR_1 + j·ω·L_1) + 1 / (ESR_2 + 1 / (j·ω·C_2))    [підстановка імпедансів кожної гілки]
```

Частота паралельного антирезонансу `ω_anti` визначається взаємною компенсацією реактивних провідностей індуктивності `L_1` та ємності `C_2`:

```
ω_anti · L_1
= 1 / (ω_anti · C_2)                                     [умова рівності реактивних провідностей]

ω_anti²
= 1 / (L_1 · C_2)                                        [алгебраїчне перенесення змінних]

ω_anti
= 1 / √(L_1 · C_2)                                       [кутова частота антирезонансу]

f_anti
= 1 / (2·π · √(L_1 · C_2))                               [лінійна частота піку імпедансу]
```

**Пікове значення імпедансу на частоті антирезонансу.** На частоті `f_anti` повний опір шини різко підскакує вгору, утворюючи вузький високоомний пік:

```
Z_peak
≈ (L_1 / C_2) / (ESR_1 + ESR_2)                          [піковий імпеданс паралельного антирезонансу]
```

**Числовий розрахунок піку антирезонансу.** Нехай `L_1 = 5 нГн` (виводи об'ємного електроліту), `C_2 = 100 нФ` (локальна кераміка MLCC), `ESR_1 = 0.05 Ом`, `ESR_2 = 0.01 Ом`:

```
f_anti
= 1 / (2 · 3.14159 · √(5·10⁻⁹ · 100·10⁻⁹))               [підстановка фізичних значень]
= 1 / (6.28318 · √(500·10⁻¹⁸))                          [обчислення підкореневого виразу]
= 1 / (6.28318 · 22.36·10⁻⁹)                            [видобування кореня]
= 1 / (1.405·10⁻⁷)                                      [обчислення знаменника]
≈ 7.12·10⁶ Гц                                            [результат у герцах]
= 7.12 МГц                                               [частота антирезонансного піку]

Z_peak
= (5·10⁻⁹ / 100·10⁻⁹) / (0.05 + 0.01)                    [розрахунок пікового опору]
= 0.05 / 0.06                                            [ділення характеристичного опору на втрати]
= 0.833 Ом                                               [піковий опір шини на частоті 7.12 МГц]
```

Отриманий піковий імпеданс `0.833 Ом` у 6 разів перевищує цільовий рівень `Z_target = 0.1375 Ом`. Якщо спектр перемикання цифрових сигналів, ШІМ або радіомодема містить гармоніку на частоті 7.12 МГц, шина живлення зазнає сильного резонансного розгойдування (дзвону).

### 4. Критерій демпфування RLC-контуру та добротність (Q-factor)

Шина живлення з індуктивністю провідників `L_wire`, сумарним омічним опором втрат `R_total` та блокувальною ємністю `C_total` являє собою послідовний RLC-контур.

Хвильовий опір `Z_0` та коефіцієнт загасання `α` такого контуру:

```
Z_0
= √(L_wire / C_total)                                    [хвильовий опір контуру]

α
= R_total / (2 · L_wire)                                 [коефіцієнт загасання коливань]

ω_0
= 1 / √(L_wire / C_total)                                [власна кутова частота контуру]
```

Добротність контуру `Q` (від англ. *Quality factor*):

```
Q
= Z_0 / R_total                                          [означення добротності контуру]
= √(L_wire / C_total) / R_total                          [вираження через параметри елементів]
```

Умови виникнення перехідного процесу за величиною добротності `Q`:

1. **Недодемпфований режим (`Q > 0.5` або `R_total < 2 · √(L/C)`):**
   Корені характеристичного рівняння комплексні. Відгук на стрибок струму супроводжується затухаючим дзвоном. Максимальна перенапруга (викид) при увімкненні досягає:

```
U_max
= V_nom · (1 + exp(-π / √(4·Q² - 1)))                    [максимальна амплітуда перерегулювання]
```

2. **Критично демпфований режим (`Q = 0.5` або `R_total = 2 · √(L/C)`):**
   Найшвидше повернення напруги до номіналу без жодного перерегулювання.

```
R_crit
= 2 · √(L_wire / C_total)                                [критичний опір демпфування]
```

3. **Передемпфований режим (`Q < 0.5` або `R_total > 2 · √(L/C)`):**
   Плавний монотонний вихід на режим без коливань, але з підвищеними статичними втратами на нагрів.

### 5. Розрахунок демпферного RC-ланцюга (Snubber)

Щоб ліквідувати паразитний дзвін керамічного конденсатора `C_mlcc` з індуктивністю з'єднувальних проводів `L_wire` без погіршення ККД силової лінії, паралельно шині встановлюють демпферний RC-ланцюг (снубер) `R_d - C_d`.

Формули оптимального вибору компонентів демпфера:

```
C_d
= 4 · C_mlcc                                             [ємність демпфера обирається в 4 рази більшою]

R_d
= √(L_wire / C_mlcc)                                     [опір демпфера дорівнює хвильовому опору]
```

**Практичний розрахунок демпфера.** Нехай індуктивність кабелю становить `L_wire = 100 нГн = 100 · 10⁻⁹ Гн`, а сумарна локальна керамічна ємність на платі `C_mlcc = 10 мкФ = 10 · 10⁻⁶ Ф`:

```
C_d
= 4 · 10·10⁻⁶                                            [множення ємності кераміки на 4]
= 40 мкФ                                                 [обираємо стандартний танталовий номінал 47 мкФ]

R_d
= √(100·10⁻⁹ / 10·10⁻⁶)                                  [підстановка індуктивності та ємності]
= √(10⁻²)                                                [обчислення підкореневого виразу]
= 0.10 Ом                                                [демпферний резистор 100 мОм]
```

Встановлення послідовного ланцюга `47 мкФ + 0.1 Ом` паралельно кераміці повністю гасить резонансні коливання, знижуючи добротність контуру до `Q ≈ 0.5` та захищаючи напівпровідникові компоненти від перенапруг при гарячому підключенні кабелю.
