# 🧮 Алгебра кватерніонів та просторова кінематика

Алгебра кватерніонів надає математично замкнений, строгий і вільний від сингулярностей апарат для моделювання тривимірних обертань твердого тіла. У цьому розділі наведено фундаментальні співвідношення гіперкомплексних чисел Гамільтона, виведення оператора повороту векторів, кінематичне диференціальне рівняння орієнтації та його зв'язок із матрицею напрямних косинусів.

У класичній механіці група неперервних тривимірних обертань позначається як `SO(3)` — спеціальна ортогональна група розмірності 3. Топологічно простір обертань `SO(3)` є тривимірним дійсним проективним простором `ℝP³`, який є двічі зв'язним. Це означає, що будь-яка спроба параметризувати обертання рівно трьома глобальними числовими координатами (такими як кути Ейлера) неминуче стикається з топологічною сингулярністю — точками координатного виродження. Алгебра кватерніонів розв'язує цю проблему шляхом вкладення обертань у чотиривимірний простір, де одиничні кватерніони утворюють групу `Spin(3)`, яка є універсальним подвійним накриттям групи `SO(3)`.

### Базис Гамільтона та операція множення

Кватерніон є елементом чотиривимірного нормованого простору над полем дійсних чисел із базисом `{1, i, j, k}`:

```
q = q_w · 1 + q_x · i + q_y · j + q_z · k
```

де `q_w, q_x, q_y, q_z ∈ ℝ`. Базисні уявні одиниці підпорядковуються фундаментальним правилам Гамільтона:

```
i² = j² = k² = i · j · k = -1
```

Звідси безпосередньо випливають некомутативні правила множення уявних одиниць:

```
i · j =  k,    j · i = -k
j · k =  i,    k · j = -i
k · i =  j,    i · k = -j
```

Добуток двох довільних кватерніонів `p = [p_w, p_x, p_y, p_z]^T` та `q = [q_w, q_x, q_y, q_z]^T` розкривається за правилом дистрибутивності:

```
p ⊗ q = (p_w + p_x·i + p_y·j + p_z·k) · (q_w + q_x·i + q_y·j + q_z·k)
```

Згрупувавши дійсні та уявні коефіцієнти при базисних ортах, отримуємо:

```
(p ⊗ q)_w = p_w·q_w - p_x·q_x - p_y·q_y - p_z·q_z
(p ⊗ q)_x = p_w·q_x + p_x·q_w + p_y·q_z - p_z·q_y
(p ⊗ q)_y = p_w·q_y - p_x·q_z + p_y·q_w + p_z·q_x
(p ⊗ q)_z = p_w·q_z + p_x·q_y - p_y·q_x + p_z·q_w
```

Якщо подати кватерніон у формі скалярно-векторної пари `p = [p_w, p_v]` та `q = [q_w, q_v]`, де `p_v, q_v ∈ ℝ³`, добуток набуває елегантного векторного вигляду:

```
p ⊗ q = [ p_w·q_w - (p_v · q_v),   p_w·q_v + q_w·p_v + (p_v × q_v) ]
```

де `·` — стандартний скалярний добуток, а `×` — векторний добуток у `ℝ³`. Некомутативність кватерніонного множення `p ⊗ q ≠ q ⊗ p` безпосередньо випливає з антисиметричності векторного добутку `p_v × q_v = -(q_v × p_v)`. Ця алгебраїчна властивість точно відтворює фізичну некомутативність тривимірних просторових поворотів: результат послідовного обертання твердого тіла залежить від черговості виконання маневрів.

### Спряження, норма та обернений кватерніон

Спряженим до кватерніона `q = [q_w, q_v]` називається кватерніон `q*` із протилежним знаком векторної частини:

```
q* = [ q_w, -q_v ] = [ q_w, -q_x, -q_y, -q_z ]
```

Розгорнемо добуток кватерніона на свій спряжений покроково:

```
q ⊗ q*
= [ q_w·q_w - (q_v · (-q_v)),  q_w·(-q_v) + q_w·q_v + (q_v × (-q_v)) ] [за векторною формулою добутку]
= [ q_w² + (q_v · q_v),  -q_w·q_v + q_w·q_v + 0 ]                      [лінійність скалярного добутку та q_v × q_v = 0]
= [ q_w² + |q_v|², 0 ]                                                  [скорочення протилежних векторів]
= q_w² + q_x² + q_y² + q_z²                                             [розкриття евклідової норми у координатах]
```

Квадрат евклідової норми кватерніона визначається як:

```
|q|² = q ⊗ q* = q_w² + q_x² + q_y² + q_z²
```

Обернений кватерніон `q⁻¹`, для якого `q ⊗ q⁻¹ = 1`, виражається через спряжений:

```
q⁻¹ = q* / |q|²
```

Для одиничних кватерніонів (`|q| = 1`), які утворюють групу `Spin(3)` і покривають групу просторових обертань `SO(3)`:

```
q⁻¹ = q*
```

Ця властивість робить операцію обернення кватерніона практично безкоштовною в обчислювальному сенсі: замість обчислення оберненої матриці 3×3 процесору достатньо лише інвертувати знак трьох векторних компонент.

### Доведення формули обертання вектора

Нехай вектор `v ∈ ℝ³` задано у вигляді чисто уявного кватерніона `v_q = [0, v]`. Поворотом вектора `v` на кут `alpha` навколо одиничної осі `u` (`|u| = 1`) за допомогою одиничного кватерніона `q = [cos(alpha/2), u·sin(alpha/2)]` є перетворення:

```
v'_q = q ⊗ v_q ⊗ q*
```

Розгорнемо це перетворення покроково:

```
q ⊗ v_q
= [ cos(alpha/2), u·sin(alpha/2) ] ⊗ [ 0, v ]                       [за означенням q та v_q]
= [ -(u · v)·sin(alpha/2),  v·cos(alpha/2) + (u × v)·sin(alpha/2) ]  [за формулою множення пар]
```

Позначимо для стислості `c = cos(alpha/2)`, `s = sin(alpha/2)`. Тепер помножимо результат праворуч на `q* = [c, -u·s]`:

```
v'_q = [ -(u · v)·s,  v·c + (u × v)·s ] ⊗ [ c, -u·s ]
```

Обчислимо скалярну частину `(v'_q)_w`:

```
(v'_q)_w
= (-(u · v)·s)·c - ( (v·c + (u × v)·s) · (-u·s) )                 [скалярна частина добутку пар]
= -(u · v)·s·c + (u · v)·s·c + ((u × v) · u)·s²                    [розкриття скалярного добутку]
= 0                                                                [оскільки (u × v) ⊥ u, скалярний добуток (u × v) · u = 0]
```

Скалярна частина оберненого вектора тотожно дорівнює нулю. Це доводить, що перетворення зберігає тривимірний векторний характер об'єкта.

Тепер обчислимо векторну частину `v'`:

```
v'
= (-(u · v)·s)·(-u·s) + c·(v·c + (u × v)·s) + (v·c + (u × v)·s) × (-u·s)  [векторна частина за формулою пар]
= u·(u · v)·s² + v·c² + (u × v)·s·c - (v × u)·s·c - ((u × v) × u)·s²      [розкриття дужок та векторного добутку]
= v·c² + 2·(u × v)·s·c + u·(u · v)·s² + (u × (u × v))·s²                  [антисиметричність: -(v × u) = u × v та зміна знаку]
```

Використовуючи векторну тотожність подвійного векторного добутку Лагранжа:

```
u × (u × v)
= u·(u · v) - v·(u · u)                                            [формула подвійного векторного добутку]
= u·(u · v) - v                                                    [оскільки |u|² = 1 для одиничного вектора осі]
```

Підставимо це співвідношення у вираз для `v'`:

```
v'
= v·c² + 2·(u × v)·s·c + u·(u · v)·s² + (u·(u · v) - v)·s²        [підстановка тотожності Лагранжа]
= v·(c² - s²) + 2·(u × v)·s·c + 2·u·(u · v)·s²                     [групування доданків при v та u]
= v·cos(alpha) + (u × v)·sin(alpha) + u·(u · v)·(1 - cos(alpha))    [тригонометричні тотожності c²-s² = cos(a), 2sc = sin(a), 2s² = 1-cos(a)]
```

Отриманий вираз є класичною **формулою повороту Родрігеса**. Вона строго доводить, що перетворення `q ⊗ v_q ⊗ q*` повертає вектор `v` навколо осі `u` точно на кут `alpha`.

Окрім збереження орієнтації, це перетворення є ізометрією — воно строго зберігає довжину вектора та кути між векторами:

```
|v'| = |q ⊗ v_q ⊗ q*| = |q| · |v_q| · |q*| = 1 · |v| · 1 = |v|
```

Це гарантує, що при переведенні векторів сил і швидкостей між системами координат корпусний вектор не зазнає штучного розтягнення чи стиснення.

### Виведення кінематичного диференціального рівняння

Нехай орієнтація апарата змінюється в часі як `q(t)`. За нескінченно малий інтервал часу `dt` тіло повертається на кут `|omega|·dt` навколо миттєвої осі `omega / |omega|`, де `omega = [p, q, r]^T` — кутова швидкість у системі тіла.

Нескінченно малий кватерніон повороту `delta_q` записується як:

```
delta_q = [ cos(|omega|·dt / 2),  (omega / |omega|) · sin(|omega|·dt / 2) ]
```

Розкладемо тригонометричні функції в ряд Тейлора при `dt -> 0`:

```
cos(|omega|·dt / 2) ≈ 1
sin(|omega|·dt / 2) ≈ 0.5 · |omega| · dt
```

Звідси нескінченно малий кватерніон набуває вигляду:

```
delta_q ≈ [ 1,  0.5 · omega · dt ]
```

Орієнтація в момент `t + dt` дорівнює композиції поворотів:

```
q(t + dt) = q(t) ⊗ delta_q = q(t) ⊗ [ 1,  0.5 · omega · dt ]
```

Розкриємо границю похідної за означенням:

```
dq/dt
= lim_{dt -> 0} (q(t + dt) - q(t)) / dt                            [означення похідної за часом]
= lim_{dt -> 0} ( q(t) ⊗ [1, 0] + q(t) ⊗ [0, 0.5·omega·dt] - q(t) ) / dt [дистрибутивність множення кватерніонів]
= lim_{dt -> 0} ( q(t) + 0.5 · dt · (q(t) ⊗ [0, omega]) - q(t) ) / dt [винесення скаляра dt за знак множення]
= 0.5 · q(t) ⊗ [0, omega]                                          [скорочення q(t) та ділення на dt]
```

Це завершує строге виведення фундаментального рівняння орієнтації:

```
dq/dt = 0.5 · q ⊗ omega_quat
```

У матричному вигляді для чисельного розрахунку на процесорі це диференціальне рівняння записується через кососиметричну матрицю кутової швидкості:

```
[ dq_w/dt ]          [  0  -p  -q  -r ] [ q_w ]
[ dq_x/dt ] = 0.5 ·  [  p   0   r  -q ] [ q_x ]
[ dq_y/dt ]          [  q  -r   0   p ] [ q_y ]
[ dq_z/dt ]          [  r   q  -p   0 ] [ q_z ]
```

Ця матрична система є абсолютно лінійною відносно компонент кватерніона. Це дозволяє застосовувати класичні методи Рунге-Кутти або експоненційні інтегратори високих порядків без жодних тригонометричних обчислень у швидкому циклі.

### Зв'язок кватерніона з матрицею напрямних косинусів

Підставивши одиничні барицентричні вектори `[1, 0, 0]^T`, `[0, 1, 0]^T`, `[0, 0, 1]^T` у формулу Родрігеса, отримуємо повну 3×3 матрицю повороту `R(q)` через компоненти кватерніона `q = [q_w, q_x, q_y, q_z]`:

```
R(q) =
[ 1 - 2(q_y² + q_z²)     2(q_x·q_y - q_w·q_z)     2(q_x·q_z + q_w·q_y) ]
[ 2(q_x·q_y + q_w·q_z)   1 - 2(q_x² + q_z²)     2(q_y·q_z - q_w·q_x) ]
[ 2(q_x·q_z - q_w·q_y)   2(q_y·q_z + q_w·q_x)   1 - 2(q_x² + q_y²)     ]
```

Ця матриця повністю еквівалентна матриці поворотів Ейлера Тейта-Браяна:

```
R_euler(psi, theta, phi) = R_z(psi) · R_y(theta) · R_x(phi)
```

Порівнюючи відповідні елементи матриць `R(q)` та `R_euler`, отримуємо явні аналітичні вирази для кутів Ейлера:

```
phi   = atan2( R[2][1], R[2][2] ) = atan2( 2(q_w·q_x + q_y·q_z),  1 - 2(q_x² + q_y²) )
theta = -asin( R[2][0] )          = asin( 2(q_w·q_y - q_z·q_x) )
psi   = atan2( R[1][0], R[0][0] ) = atan2( 2(q_w·q_z + q_x·q_y),  1 - 2(q_y² + q_z²) )
```

Універсальне накриття групи `SO(3)` групою одиничних кватерніонів має двократний характер: кватерніони `q` та `-q` відповідають абсолютно однаковій матриці `R(q) = R(-q)`. Це пояснюється тим, що поворот на кут `alpha` навколо осі `u` тотожний повороту на кут `2*pi - alpha` навколо протилежної осі `-u`. У практичних алгоритмах це вимагає перевірки знаку скалярного добутку перед операціями інтерполяції, щоб завжди обирати геодезично найкоротший шлях на чотиривимірній сфері.

### Геодезична відстань та метрика на сфері `S³`

Кутова похибка між двома просторовими орієнтаціями `q1` та `q2` не може бути обчислена простим евклідовим відніманням векторів `q1 - q2`. Справжня геометрична метрика визначається довжиною дуги великого кола на 4D-гіперсфері:

```
cos(theta / 2) = |q1_w·q2_w + q1_x·q2_x + q1_y·q2_y + q1_z·q2_z| = |q1 · q2|
```

Фізичний кут різниці орієнтацій між апаратами виражається формулою:

```
theta = 2 · acos( clamp(|q1 · q2|, 0.0, 1.0) )
```

Ця метрика лежить в основі алгоритмів сферичної лінійної інтерполяції (**Slerp**, *Spherical Linear Interpolation*), які використовуються в системах траєкторного планування для плавного з'єднання цільових точок орієнтації з постійною кутовою швидкістю обертання.
