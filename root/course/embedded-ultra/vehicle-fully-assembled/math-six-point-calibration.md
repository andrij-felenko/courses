# 🧮 Математика 6-позиційного калібрування триосьового акселерометра

Математичний апарат калібрування триосьового кремнієвого акселерометра за шістьма ортогональними орієнтаціями в гравітаційному полі Землі дозволяє обчислити невідомі зміщення нуля (нульовий зсув) та масштабні коефіцієнти чутливості кожної осі. Без цього розрахунку сирі покази інерційного давача описують деформований еліпсоїд замість сфери одиничного радіуса, що призводить до постійної накопичувальної помилки визначення кутів орієнтації та вертикального прискорення апарата.

### Фізична модель вимірювань і геометрія похибок

Кремнієвий мікроелектромеханічний акселерометр вимірює питому силу реакції опори, що діє на чутливу масу. У стані спокою на поверхні Землі єдиним джерелом прискорення є гравітаційне поле Землі з еталонною величиною прискорення вільного падіння `g₀ = 9.80665 м/с²` (приймається за `1.0 g`).

Реальний триосьовий сенсор має апаратні недосконалості виготовлення: технологічний розкид ємнісних перетворювачів, нерівномірність механічної пружності кремнієвих підвісів, неідеальну взаємну перпендикулярність кристалів і температурний дрейф. Математичний зв'язок між вектором сирих вимірів `a_raw = [a_x, a_y, a_z]ᵀ` та істинним вектором фізичного прискорення `a_true` описується узагальненою лінійною моделлю:

```
a_raw
= S · T · (a_true + b) + n                             [узагальнена модель триосьового чутливого елемента]
= S · T · a_true + S · T · b + n                       [розкриття дужок для виділення статичного офсету]
```

Тут:
- `b = [b_x, b_y, b_z]ᵀ` — вектор статичного зміщення нуля (zero-g bias), виражений в одиницях `g`.
- `S = diag(S_x, S_y, S_z)` — діагональна матриця масштабних коефіцієнтів чутливості осей (scale factors).
- `T` — матриця неортогональності осей (cross-axis misalignment), яка враховує перехресні зв'язки між осями сенсора:

```
T = [    1       0       0   ]
    [ -α_yx      1       0   ]
    [  α_zx    -α_zy     1   ]
```

Де `α_ij` — малі кути відхилення вимірювальних осей від ідеальної декартової системи координат.
- `n` — вектор адитивного білого гаусового шуму з нульовим математичним сподіванням `E[n] = 0` та коваріаційною матрицею `R = σ² · I`.

У випадку, коли перехресні зв'язки між осями незначні (кут неортогональності `< 0.5°`), матрицею `T` на першому етапі можна знехтувати, поклавши `T ≈ I`. Тоді модель спрощується до незалежного калібрування трьох каналів:

```
a_raw,x = S_x · (a_true,x + b_x) + n_x
a_raw,y = S_y · (a_true,y + b_y) + n_y
a_raw,z = S_z · (a_true,z + b_z) + n_z
```

Якщо апарат перебуває в нерухомому стані, модуль істинного вектора прискорення за фундаментальним законом гравітації суворо дорівнює одиниці:

```
||a_true||²
= a_true,x² + a_true,y² + a_true,z²                    [квадрат норми вектора прискорення]
= 1.0² = 1.0                                           [умова нерухомості в полі тяжіння 1g]
```

Підставивши вираз для істинного прискорення через сирі покази `a_true,i = (a_raw,i / S_i) - b_i`, отримуємо геометричне рівняння поверхні відгуку сенсора в просторі сирих відліків:

```
((a_raw,x / S_x) - b_x)² + ((a_raw,y / S_y) - b_y)² + ((a_raw,z / S_z) - b_z)²
= 1.0                                                  [рівняння деформованого триосьового еліпсоїда]
```

Невідкалібрований сенсор замість ідеальної сфери радіуса `1.0 g` із центром на початку координат описує зміщений і витягнутий еліпсоїд. Мета калібрування полягає в знаходженні шести параметрів `{b_x, b_y, b_z, S_x, S_y, S_z}`, які трансформують виміряний еліпсоїд назад у сферу.

### Алгебраїчне виведення для 6 ортогональних позицій

Для знаходження шести невідомих параметрів необхідно скласти систему щонайменше з шести незалежних рівнянь. Найпростішим і найбільш стійким методом є розміщення апарата в шести базових ортогональних положеннях, де вісь кожного сенсора по черзі вирівнюється суворо паралельно та антипаралельно вектору гравітації:

1. **Позиція +Z (горизонт):** вектор гравітації спрямований уздовж осі Z: `a_true = [0, 0, +1]ᵀ`.
2. **Позиція −Z (догори дном):** вектор гравітації спрямований проти осі Z: `a_true = [0, 0, −1]ᵀ`.
3. **Позиція +X (вертикально носом униз):** вектор гравітації спрямований уздовж осі X: `a_true = [+1, 0, 0]ᵀ`.
4. **Позиція −X (вертикально носом угору):** вектор гравітації спрямований проти осі X: `a_true = [−1, 0, 0]ᵀ`.
5. **Позиція +Y (на правому боці):** вектор гравітації спрямований уздовж осі Y: `a_true = [0, +1, 0]ᵀ`.
6. **Позиція −Y (на лівому боці):** вектор гравітації спрямований проти осі Y: `a_true = [0, −1, 0]ᵀ`.

У кожній позиції знімається вибірка з `N` вимірів (зазвичай `N = 500...1000` відліків на частоті 100 Гц), і обчислюється середнє арифметичне значення, що повністю усуває випадковий шум `n`:

```
a_mean,i
= (1 / N) · Σ a_raw,i,k                                [усереднення вибірки для придушення білого шуму]
```

Позначимо усереднені сирі покази по осі `Z` у положеннях +Z та −Z як `Z_plus` та `Z_minus`. Запишемо модель вимірювань для цих двох станів:

```
Z_plus
= S_z · (+1.0 + b_z)                                   [вимір у положенні горизонт +1g]
= S_z + S_z · b_z                                      [розкриття дужок для виділення компонент]

Z_minus
= S_z · (-1.0 + b_z)                                   [вимір у перевернутому положенні -1g]
= -S_z + S_z · b_z                                     [розкриття дужок для виділення компонент]
```

Віднімемо друге рівняння від першого:

```
Z_plus - Z_minus
= (S_z + S_z · b_z) - (-S_z + S_z · b_z)               [віднімання двох вимірювань осі Z]
= S_z + S_z · b_z + S_z - S_z · b_z                    [розкриття знаків]
= 2 · S_z                                              [взаємне скорочення зміщення нуля]

S_z
= (Z_plus - Z_minus) / 2.0                             [кінцева формула масштабного коефіцієнта по осі Z]
```

Додамо перше та друге рівняння:

```
Z_plus + Z_minus
= (S_z + S_z · b_z) + (-S_z + S_z · b_z)               [додавання двох вимірювань осі Z]
= 2 · S_z · b_z                                        [взаємне скорочення амплітуди гравітації]

b_z
= (Z_plus + Z_minus) / (2 · S_z)                       [підстановка розрахованого масштабу]
= (Z_plus + Z_minus) / (Z_plus - Z_minus)              [кінцева формула зміщення нуля по осі Z]
```

Аналогічно, повторюючи розрахунок для осей `X` та `Y` за відповідними парами ортогональних вимірів `{X_plus, X_minus}` та `{Y_plus, Y_minus}`, отримуємо повну систему калібрувальних формул:

```
S_x = (X_plus - X_minus) / 2.0
b_x = (X_plus + X_minus) / (X_plus - X_minus)

S_y = (Y_plus - Y_minus) / 2.0
b_y = (Y_plus + Y_minus) / (Y_plus - Y_minus)

S_z = (Z_plus - Z_minus) / 2.0
b_z = (Z_plus + Z_minus) / (Z_plus - Z_minus)
```

Після обчислення цих коефіцієнтів будь-який наступний сирий вимір у польоті коригується за формулою:

```
a_cal,i
= (a_raw,i / S_i) - b_i                                [приведення сирого відліку до нормованого прискорення]
= (a_raw,i - S_i · b_i) / S_i                          [алгебраїчно еквівалентна форма для цілочисельних МК]
```

### Числовий приклад розрахунку та оцінка похибки

Припустимо, 16-бітний АЦП акселерометра з діапазоном `±4g` видає сирі значення з номінальною чутливістю 8192 LSB/g. Під час тестування на 6 позиціях отримано такі усереднені значення:

- По осі X: `X_plus = +8450 LSB`, `X_minus = -7950 LSB`
- По осі Y: `Y_plus = +8210 LSB`, `Y_minus = -8290 LSB`
- По осі Z: `Z_plus = +8600 LSB`, `Z_minus = -7800 LSB`

Обчислимо параметри для осі X:

```
S_x
= (8450 - (-7950)) / 2.0                               [різниця показів поділена на два]
= 16400 / 2.0
= 8200 LSB/g                                           [фактичний масштаб осі X замість номіналу 8192]

b_x
= (8450 + (-7950)) / (8450 - (-7950))                  [сума показів поділена на розмах]
= 500 / 16400
= +0.030488 g                                          [статичний офсет осі X становить 30.5 мг]
```

Обчислимо параметри для осі Y:

```
S_y
= (8210 - (-8290)) / 2.0                               [різниця показів поділена на два]
= 16500 / 2.0
= 8250 LSB/g                                           [фактичний масштаб осі Y]

b_y
= (8210 + (-8290)) / (8210 - (-8290))                  [сума показів поділена на розмах]
= -80 / 16500
= -0.004848 g                                          [статичний офсет осі Y становить -4.8 мг]
```

Обчислимо параметри для осі Z:

```
S_z
= (8600 - (-7800)) / 2.0                               [різниця показів поділена на два]
= 16400 / 2.0
= 8200 LSB/g                                           [фактичний масштаб осі Z]

b_z
= (8600 + (-7800)) / (8600 - (-7800))                  [сума показів поділена на розмах]
= 800 / 16400
= +0.048780 g                                          [статичний офсет осі Z становить 48.8 мг]
```

**Критичний вплив на інерційну інтеграцію.** Якби офсет осі Z величиною `b_z = +0.04878 g` не було скориговано, навігаційний фільтр EKF інтерпретував би цей постійний зсув як постійне фізичне прискорення вгору:

```
a_err
= b_z · g₀                                             [похибка прискорення у фізичних одиницях]
= 0.04878 · 9.80665
= 0.4783 м/с²                                          [постійна помилка прискорення]
```

При подвійному інтегруванні прискорення в просторі без корекції від барометра або супутників накопичення помилки швидкості та позиції описується законами кінематики:

```
Δv(t)
= a_err · t                                            [лінійне зростання помилки швидкості]

Δh(t)
= 0.5 · a_err · t²                                     [квадратичне наростання помилки висоти]
```

Підставивши час автономного польоту `t = 10 с`:

```
Δv(10)
= 0.4783 · 10
= 4.783 м/с                                            [помилка швидкості майже 5 м/с за 10 секунд]

Δh(10)
= 0.5 · 0.4783 · 100
= 23.915 м                                             [помилка висоти майже 24 метри!]
```

Цей розрахунок доводить, що без попереднього 6-позиційного калібрування інерційна навігація розходиться за лічені секунди, приводячи до некерованого падіння або зіткнення з землею.

### Узагальнений метод найменших квадратів для довільних положень

Коли апарат неможливо виставити суворо під кутами 90° (наприклад, у польових умовах), застосовують метод апроксимації еліпсоїда найменшими квадратами за множиною з `M` довільних статичних положень (`M ≥ 9`).

Загальне рівняння тривимірного еліпсоїда записується в алгебраїчній формі квадрики:

```
A·x² + B·y² + C·z² + 2·D·x·y + 2·E·x·z + 2·F·y·z + 2·G·x + 2·H·y + 2·I·z + J = 0
```

Складається вектор невідомих параметрів `p = [A, B, C, D, E, F, G, H, I, J]ᵀ` та матриця спостережень `H_obs` розміром `M × 10`, де кожен рядок формується з відліків `[x_k, y_k, z_k]`.

Розв'язок системи рівнянь методом сингулярного розкладу (SVD) знаходить вектор `p`, що мінімізує суму квадратів геометричних нев'язок:

```
p_opt
= argmin || H_obs · p ||²  при умові ||p|| = 1         [знаходження власного вектора найменшого власного значення]
```

Знайдені коефіцієнти квадрики алгебраїчно розкладаються на координати центру еліпсоїда (вектор зміщень `b`), довжини півосей (масштабні коефіцієнти `S`) та власні вектори матриці орієнтації (кути неортогональності `T`), забезпечуючи повне виправлення геометрії сенсора.
