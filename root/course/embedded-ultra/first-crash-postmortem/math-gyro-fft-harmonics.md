# Розрахунок моторних гармонік і фазової затримки фільтрації гіроскопа

Встановлення агресивних коефіцієнтів ПІД-регулятора на апараті з незафільтрованими вібраціями неминуче веде до некерованого розгону автоколивань або термічного руйнування двигунів. Цей розрахунок виводить математичний зв'язок між швидкістю обертання ротора, числом магнітних полюсів, лопатевою частотою та передавальною функцією D-терма, показуючи, чому диференційний контур підсилює високочастотний шум пропорційно частоті й яка фазова затримка від фільтрів призводить до втрати стійкості замкненого контуру керування.

## Генерація вібраційних гармонік механічною системою

Джерелом шуму гіроскопа на борту є механічний дисбаланс ротора двигуна, геометрична несиметрія пропелера та аеродинамічна взаємодія лопатей із набігаючим повітрям і карбоновими променями рами.

### 1. Електрична та механічна частота обертання мотора

Нехай ротор безколекторного двигуна обертається зі швидкістю `RPM` (англ. *revolutions per minute* — обертів на хвилину). Механічна частота обертання `f_mech` у герцах дорівнює:

```
f_mech = RPM / 60
```

Якщо статор і ротор мають `P_poles` постійних магнітних полюсів (для типового безколекторного мотора типорозміру 2207 чи 2806 кількість магнітів на дзвінку `P_poles = 14`, тобто 7 пар магнітних полюсів `N-S`), електрична частота комутації фаз `f_elec` становить:

```
f_elec = (RPM / 60) · (P_poles / 2)
       = f_mech · 7                         [для мотора з 14 магнітами]
```

Для типової робочої точки зависання або крейсерського польоту (`RPM = 18 000 об/хв`):

```
f_mech = 18 000 / 60 = 300 Гц
f_elec = 300 · 7 = 2100 Гц
```

Механічний дисбаланс дзвона (центробіжна сила через нерівномірність маси або мікровигин вала) створює синусоїдальну вібрацію точно на частоті `f_mech = 300 Гц`.

### 2. Лопатева частота проходження (Blade Pass Frequency)

Кожна лопать пропелера при обертанні створює зону підвищеного аеродинамічного тиску. При проходженні кожної лопаті над променем рами виникає імпульс стиснення повітря, що передається на карбонову структуру. Для пропелера з кількістю лопатей `N_blades` частота лопатевих збурень `f_bpf` обчислюється як:

```
f_bpf = f_mech · N_blades = (RPM / 60) · N_blades
```

Для популярного 3-лопатевого гвинта (`N_blades = 3`) при швидкості обертання `18 000 об/хв`:

```
f_bpf = (18 000 / 60) · 3 = 300 · 3 = 900 Гц
```

Окрім першої гармоніки `f_bpf`, нелінійність аеродинамічного удару генерує вищі кратні гармоніки: `2 · f_bpf = 1800 Гц`, `3 · f_bpf = 2700 Гц`.

### 3. Дискретизація та теорема Найквіста-Шеннона

MEMS-гіроскоп вимірює кутову швидкість із частотою опитування `f_sample` (зазвичай 8 кГц у датчиках типу ICM-42688-P або BMI270). За теоремою Котельникова-Найквіста, максимальна частота, яку датчик здатний однозначно зареєструвати без спотворень, становить половину частоти дискретизації (частота Найквіста `f_Nyquist = f_sample / 2`):

```
f_Nyquist = 8000 / 2 = 4000 Гц
```

Якщо механічна вібрація містить компоненти вище 4000 Гц, а вбудований апаратний антиаліасинговий фільтр датчика (AIF) вимкнено, високочастотний шум дзеркально відбивається в низькочастотну робочу смугу (явище накладання спектрів або аліасингу, англ. *aliasing*). Вібрація на частоті 7800 Гц відображається як псевдошум на частоті `8000 − 7800 = 200 Гц`, прямо потрапляючи в робочу смугу ПІД-контуру.

## Диференційний контур (D-терм) як підсилювач високочастотного шуму

Ідеальний диференціатор має комплексну передавальну функцію `H_ideal(s) = K_D · s`. На дійсній частоті `s = j·ω` модуль частотного підсилення становить:

```
|H_ideal(jω)| = K_D · ω = K_D · 2·π·f
```

Підсилення лінійно зростає зі зростанням частоти `f`. Вібраційний шум на частоті 500 Гц підсилюється у 50 разів інтенсивніше, ніж корисний рух апарата на частоті 10 Гц.

Щоб запобігти миттєвому насиченню моторів високочастотним шумом, у контур диференціювання вводиться фільтр нижніх частот першого порядку зі сталою часу `T_f = 1 / (2·π·f_cutoff)`:

```
H_D(s) = (K_D · s) / (1 + s · T_f)
```

Амплітудно-частотна характеристика (АЧХ) диференційного каскаду з фільтрацією:

```
|H_D(jω)| = (K_D · ω) / √(1 + (ω · T_f)²)
```

Розгляньмо поведінку модуля підсилення в різних частотних діапазонах:

```
При ω << 1/T_f :  |H_D(jω)| ≈ K_D · ω             [чисте диференціювання сигналу помилки]
При ω >> 1/T_f :  |H_D(jω)| ≈ (K_D · ω) / (ω · T_f)
                             = K_D / T_f          [асимптотична стеля підсилення шуму]
```

Якщо частота зрізу фільтра `f_cutoff = 150 Гц`, а стала часу `T_f = 1 / (2·π·150) ≈ 0.001061 с`:

```
Стеля шуму = K_D / T_f = K_D · 2·π·150 ≈ 942.5 · K_D
```

Кожен мікровольт високочастотного шуму MEMS-сенсора множиться майже в 1000 разів відносно коефіцієнта `K_D`, перетворюючись на високочастотний змінний струм у фазах двигунів, що викликає паразитичний нагрів магнітопроводу та силових ключів.

## Розрахунок фазової затримки фільтрів і межа стійкості системи

Ціною придушення вібраційного шуму фільтрами низьких частот (Lowpass Filter, LPF) та динамічними режекторними фільтрами (Dynamic Notch Filter) є поява фазової затримки `Δθ(ω)`.

Фільтр низьких частот першого порядку додає від'ємний фазовий зсув:

```
Δθ_lpf1(ω) = -arctan(ω · T_f) = -arctan(f / f_cutoff)
```

Для фільтра другого порядку (наприклад, цифрового біквадратного фільтра Баттерворта з добротністю `Q = 0.707`):

```
Δθ_lpf2(ω) = -arctan( (√2 · (f / f_cutoff)) / (1 - (f / f_cutoff)²) )
```

Динамічний режекторний фільтр (Notch Filter) із центральною частотою `f_0`, добротністю `Q = f_0 / BW` та шириною смуги придушення `BW` описується передавальною функцією другого порядку. На частотах `f < f_0` (нижче смуги вирізання) він додає фазове запізнення:

```
Δθ_notch(f) ≈ -arctan( (f · BW) / (f_0² − f²) )
```

### Числовий приклад розрахунку затримки

Обчислимо сумарну затримку в мілісекундах `τ_delay` на частоті корисного маневрування апарата `f_ctrl = 20 Гц` при типовому ланцюжку фільтрації сучасного автопілота:
1. Два каскади фільтра низьких частот другого порядку з частотою зрізу `f_cutoff = 120 Гц`;
2. Три динамічні режекторні фільтри, налаштовані за даними телеметрії RPM на частоти трьох моторних гармонік: `f_01 = 220 Гц`, `f_02 = 440 Гц`, `f_03 = 660 Гц` з шириною смуги `BW = 40 Гц`.

```
1. Фазовий зсув одного каскаду LPF2 на частоті 20 Гц:
   f / f_cutoff = 20 / 120 = 0.1667
   Δθ_lpf = -arctan( (1.414 · 0.1667) / (1 − 0.1667²) )
          = -arctan( 0.2357 / 0.9722 )
          = -arctan( 0.2424 ) ≈ -13.63°

2. Фазовий зсув двох каскадів LPF2:
   Δθ_lpf_total = 2 · (-13.63°) = -27.26°

3. Фазовий зсув трьох режекторних фільтрів на 20 Гц:
   Δθ_notch1 = -arctan( (20 · 40) / (220² − 20²) ) = -arctan( 800 / 48 000 ) ≈ -0.95°
   Δθ_notch2 = -arctan( (20 · 40) / (440² − 20²) ) = -arctan( 800 / 193 200 ) ≈ -0.24°
   Δθ_notch3 = -arctan( (20 · 40) / (660² − 20²) ) = -arctan( 800 / 435 200 ) ≈ -0.11°
   Δθ_notch_total = -0.95° + (-0.24°) + (-0.11°) = -1.30°

4. Сумарний фазовий зсув контуру фільтрації:
   Δθ_total = -27.26° + (-1.30°) = -28.56°  (-0.498 рад)

5. Еквівалентна часова затримка сигналу:
   τ_delay = |Δθ_total| / (360° · f_ctrl)
           = 28.56 / (360 · 20)
           = 28.56 / 7200 ≈ 0.00397 с = 3.97 мс
```

Затримка майже у 4.0 мс на частоті контуру 2 кГц (період квантування 0.5 мс) означає, що керівний вплив запізнюється на 8 повних кроків регулятора.

## Чому IIR-біквадрат переважає FIR-фільтри у контурах автопілота

У цифровій обробці сигналів для фільтрації застосовують два класи алгоритмів: фільтри зі скінченною імпульсною характеристикою (FIR) та з нескінченною імпульсною характеристикою (IIR).

FIR-фільтр із лінійною фазою має строго постійну групову затримку `τ_fir = (N - 1) / (2 · f_sample)`, де `N` — кількість вагових коефіцієнтів (відліків). Щоб забезпечити крутий спад АЧХ у смузі загородження (придушення шуму на 40 дБ на частотах вище 200 Гц), потрібен фільтр порядку не менше `N = 64..128`. На частоті дискретизації `f_sample = 8 кГц`:

```
τ_fir = (64 - 1) / (2 · 8000) = 63 / 16000 ≈ 0.00394 с = 3.94 мс
```

Ця затримка є фіксованою для **всіх** частот, включаючи низькі частоти корисного сигналу (1–20 Гц). У контурі швидкісного автопілота постійна затримка 4 мс призводить до фазового відставання фактичного кута від заданого, змушуючи знижувати коефіцієнти `K_P` та `K_D` вдвічі, що робить апарат в'ялим і нестійким до вітрових збурень.

На противагу FIR, IIR-біквадрати (Biquad Filter Direct Form II Transposed) вимагають лише 5 коефіцієнтів множення та 2 комірки пам'яті станів на каскад другого порядку. Їхня фазова затримка на низьких частотах становить менше 0.5–1.0 мс, а круте придушення зосереджене у високочастотній зоні. Саме тому в реальних прошивках польотних контролерів фільтрація гіроскопа будується виключно на каскадах IIR-біквадратів.
