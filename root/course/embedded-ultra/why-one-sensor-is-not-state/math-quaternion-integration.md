# 🧮 Математика кватерніонної кінематики та дискретного інтегрування

Орієнтація твердого тіла в тривимірному просторі без сингулярностей і карданного блокування задається одиничним нормованим **кватерніоном** (лат. *quaterni* — по чотири, четвірка):

```
q = [q₀, q₁, q₂, q₃]ᵀ = [q_w, q_x, q_y, q_z]ᵀ = [cos(θ/2), u · sin(θ/2)]ᵀ
```

де `θ` — скалярний кут просторового повороту навколо одиничної осі обертання `u = [u_x, u_y, u_z]ᵀ`. Кватерніон є гіперкомплексним числом із трьома ортогональними уявними одиницями `i, j, k`, які задовольняють фундаментальні співвідношення Гамільтона: `i² = j² = k² = i·j·k = -1`. Норма кватерніона повинна строго дорівнювати одиниці:

```
‖q‖² = q₀² + q₁² + q₂² + q₃² = 1.0
```

### Диференціальне рівняння просторового обертання

Нехай вектор кутової швидкості апарата у зв'язаній системі координат корпусу дорівнює `ω = [ω_x, ω_y, ω_z]ᵀ` (вимірюється в радіанах за секунду). Зв'язок між миттєвою кутовою швидкістю та похідною кватерніона орієнтації `q̇` виводиться через кватерніонний добуток Гамільтона:

```
q̇(t) = 0.5 · q(t) ⊗ ω_quat
```

де `ω_quat = [0, ω_x, ω_y, ω_z]ᵀ` — чисто уявний кватерніон кутової швидкості. Якщо розписати правила множення уявних одиниць, матрично-векторне диференціальне рівняння набуває строгого вигляду:

```
⎡ q̇₀ ⎤       ⎡  0    -ω_x  -ω_y  -ω_z ⎤ ⎡ q₀ ⎤
⎢ q̇₁ ⎥ = 0.5 ⎢  ω_x    0    ω_z  -ω_y ⎥ ⎢ q₁ ⎥
⎢ q̇₂ ⎥       ⎢  ω_y  -ω_z    0    ω_x ⎥ ⎢ q₂ ⎥
⎣ q̇₃ ⎦       ⎣  ω_z   ω_y  -ω_x    0   ⎦ ⎣ q₃ ⎦
```

Позначивши кососиметричну матрицю кутової швидкості як `Ω(ω)` розмірністю 4×4, отримаємо компактну матричну форму:

```
q̇(t) = 0.5 · Ω(ω(t)) · q(t)
```

Властивістю кососиметричної матриці `Ω` є рівність `Ωᵀ = -Ω`. Це гарантує, що скалярний добуток вектора кватерніона на його власну похідну тотожно дорівнює нулю: `qᵀ · q̇ = 0.5 · qᵀ · Ω · q = 0`. Отже, у безперервному часі довжина кватерніона залишається незмінною.

### Матриця напрямних косинусів (DCM)

Для перетворення виміряних векторів між глобальною навігаційною системою відліку (NED — North-East-Down) та зв'язаною системою координат апарата використовується матриця повороту `R(q)`, складена з компонентів кватерніона:

```
R(q) = 
⎡ q₀²+q₁²-q₂²-q₃²    2(q₁q₂ - q₀q₃)    2(q₁q₃ + q₀q₂) ⎤
⎢  2(q₁q₂ + q₀q₃)   q₀²-q₁²+q₂²-q₃²    2(q₂q₃ - q₀q₁) ⎥
⎣  2(q₁q₃ - q₀q₂)    2(q₂q₃ + q₀q₁)   q₀²-q₁²-q₂²+q₃² ⎦
```

Очікуваний напрямок вектора сили тяжіння Землі у зв'язаній системі датчиків отримується множенням транспонованої матриці `R(q)ᵀ` на одиничний вертикальний вектор `[0, 0, 1]ᵀ`:

```
v_gravity_body = R(q)ᵀ · ⎡ 0 ⎤ = ⎡ 2(q₁q₃ - q₀q₂) ⎤
                         ⎢ 0 ⎥   ⎢ 2(q₂q₃ + q₀q₁) ⎥
                         ⎣ 1 ⎦   ⎣ q₀²-q₁²-q₂²+q₃² ⎦
```

Саме цей обчислений вектор `v_gravity_body` порівнюється з нормалізованим виміром триосьового акселерометра в орієнтаційних фільтрах Махоні та Калмана.

### Вектор просторової похибки через косий векторний добуток

Коли апарат нахилений, виміряний акселерометром нормалізований вектор питомої сили `a = [a_x, a_y, a_z]ᵀ` відхиляється від розрахункового вектора гравітації `v = [v_x, v_y, v_z]ᵀ`. Кутова похибка між цими двома тривимірними векторами визначається за допомогою векторного добутку:

```
e_acc = a × v
```

Оскільки модуль векторного добутку дорівнює `‖e_acc‖ = ‖a‖ · ‖v‖ · sin(α) = sin(α)`, де `α` — кут розходження між орієнтацією оцінювача та фізичною вертикаллю, для малих кутів (`α < 15°`) виконується наближення `sin(α) ≈ α`. Вектор `e_acc` лежить точно на осі, навколо якої необхідно здійснити поворот для усунення розходження:

```
e_acc_x = a_y · v_z - a_z · v_y   [похибка за креном Roll]
e_acc_y = a_z · v_x - a_x · v_z   [похибка за тангажем Pitch]
e_acc_z = a_x · v_y - a_y · v_x   [похибка за курсом Yaw]
```

### Проєкція геомагнітного поля та компенсація магнітного нахилу

Магнітометр вимірює вектор магнітної індукції Землі `m_meas`, який у більшості географічних широт спрямований не суто горизонтально на північ, а під кутом до земної поверхні (магнітне схилення та нахил — dip angle).

Щоб магнітний нахил не вносив штучної похибки в крен і тангаж, виміряний вектор спочатку трансформують у горизонтальну площину навігаційної системи:

```
h = R(q) · m_meas = [h_x, h_y, h_z]ᵀ
```

Горизонтальна складова поля проєктується строго вздовж північної осі `X`, а поперечна складова `Y` примусово обнуляється для формування еталонного вектора геомагнітного поля `b`:

```
b = [ √(h_x² + h_y²), 0, h_z ]ᵀ = [ b_x, 0, b_z ]ᵀ
```

Після цього еталонний вектор `b` повертається назад у зв'язану систему координат апарата:

```
w_mag_body = R(q)ᵀ · b
```

Похибка курсу за магнітометром обчислюється як додатковий векторний добуток:

```
e_mag = m_meas × w_mag_body
```

Сумарний вектор неузгодженості орієнтації для пропорційно-інтегрального коректора становить суму двох джерел: `e = e_acc + e_mag`.

### Аналіз конічних похибок (Coning Motion)

Коли літальний апарат одночасно здійснює гармонічні кутові коливання за двома ортогональними осями зі зсувом фази на 90° (наприклад, `ω_x(t) = Ω_c · cos(ω_vib · t)` та `ω_y(t) = Ω_c · sin(ω_vib · t)`), виникає так званий **конічний рух** (англ. *coning motion*).

Хоча середнє значення виміряної кутової швидкості за період дорівнює нулю (`⟨ω_x⟩ = 0`, `⟨ω_y⟩ = 0`), реальна просторова орієнтація дрейфує навколо осі `Z` із постійною швидкістю:

```
ω_drift_z = 0.5 · Ω_c² / ω_vib
```

Простий метод Ейлера першого порядку не в змозі відстежити перехресний векторний добуток `ω_x × ω_y` за високих частот вібрацій двигунів. Для усунення конічного дрейфу на високодинамічних апаратах використовують двоетапне інтегрування другого порядку (метод середньої точки / Runge-Kutta 2):

```
ω_mid = 0.5 · (ω[k-1] + ω[k])
q[k] = q[k-1] + 0.5 · (q[k-1] ⊗ [0, ω_mid]ᵀ) · Δt
```

Це знижує похибку апроксимації траєкторії до `O(Δt³)` без відчутного збільшення обчислювального навантаження на ядро мікроконтролера.

### Дискретні методи чисельного інтегрування

У бортових обчислювачах вимірювання надходять дискретно з періодом квантування `Δt`.

#### 1. Схема Ейлера першого порядку

За припущення малості кута повороту за один такт (`‖ω‖ · Δt ≪ 1` рад) розв'язок на кроці `k` апроксимується лінійним кроком:

```
q[k] = q[k-1] + q̇ · Δt
     = q[k-1] + 0.5 · (q[k-1] ⊗ [0, ω_x, ω_y, ω_z]ᵀ) · Δt
```

Покомпонентні вирази для програмного коду:

```
q₀[k] = q₀[k-1] + 0.5 · (-q₁·ω_x - q₂·ω_y - q₃·ω_z) · Δt   [приріст дійсної частини]
q₁[k] = q₁[k-1] + 0.5 · ( q₀·ω_x + q₂·ω_z - q₃·ω_y) · Δt   [приріст осі X]
q₂[k] = q₂[k-1] + 0.5 · ( q₀·ω_y - q₁·ω_z + q₃·ω_x) · Δt   [приріст осі Y]
q₃[k] = q₃[k-1] + 0.5 · ( q₀·ω_z + q₁·ω_y - q₂·ω_x) · Δt   [приріст осі Z]
```

Цей метод потребує мінімальної кількості тактів ALU (всього 16 множень і 12 додавань), що ідеально підходить для високочастотних циклів обробки переривань (1–8 кГц).

#### 2. Точний експоненціальний розклад (Zero-Order Hold)

Якщо вважати кутову швидкість `ω` незмінною протягом інтервалу `Δt`, аналітичний інтеграл має замкнений розв'язок через матричну експоненту:

```
q[k] = exp(0.5 · Ω(ω) · Δt) · q[k-1]
```

Оскільки для матриці чисто уявного кватерніона виконується `Ω² = -‖ω‖² · I₄`, нескінченний ряд Тейлора згортається в точні тригонометричні функції:

```
Δθ = ‖ω‖ · Δt
Δq = [ cos(0.5 · Δθ),  (ω / ‖ω‖) · sin(0.5 · Δθ) ]ᵀ
q[k] = q[k-1] ⊗ Δq
```

За агресивних поворотів зі швидкістю понад 1000°/с (наприклад, у перегонових квадрокоптерах) експоненціальний розклад запобігає викривленню орієнтації, властивому методу Ейлера.

### Чисельна ортонормалізація

Через скінченну розрядність 32-бітних чисел із плаваючою комою IEEE 754 одинична норма кватерніона після тисяч ітерацій неминуче відхиляється від 1.0. Збільшення норми кватерніона призводить до масштабного спотворення перерахованих прискорень і виходу контуру регулятора зі стійкості.

Тому після кожного кроку інтегрування кватерніон обов'язково перенормовується:

```
norm_sq = q₀² + q₁² + q₂² + q₃²
inv_norm = 1.0 / √(norm_sq)
q = q · inv_norm
```

Для оптимізації на процесорах без апаратного модуля апаратного квадратного кореня використовують швидке наближення Тейлора першого порядку `inv_norm ≈ 0.5 · (3.0 - norm_sq)`, що ефективно усуває необхідність у важких трансцендентних викликах.

### Перерахунок кватерніона в кути Ейлера

Для візуалізації на екрані польотного диспетчера та телеметрії кватерніон трансформується у звичні навігаційні кути: крен (Roll, `ϕ`), тангаж (Pitch, `θ`) та курс (Yaw, `ψ`):

```
ϕ = atan2( 2(q₀q₁ + q₂q₃),  1 - 2(q₁² + q₂²) )
θ =  asin( 2(q₀q₂ - q₃q₁) )
ψ = atan2( 2(q₀q₃ + q₁q₂),  1 - 2(q₂² + q₃²) )
```

Коли тангаж наближається до вертикалі `θ → ±90°`, аргумент арксинуса прямує до `±1`, і крен із курсом стають невизначеними (класична ейлерова сингулярність). Самі ж внутрішні розрахунки орієнтаційного фільтра у кватерніонній формі ніколи не зазнають цієї сингулярності.
