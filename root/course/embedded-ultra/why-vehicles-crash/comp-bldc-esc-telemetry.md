# 🔌 Регулятори швидкості BLDC: комутація, desync та зворотна телеметрія

Електронний регулятор швидкості (ESC, *Electronic Speed Controller*) — це спеціалізований силовий перетворювач, що транслює низьковольтні команди польотного контролера у трифазний високочастотний струм для безколекторного двигуна (BLDC). Розуміння внутрішньої фізики комутації та причин зриву синхронізації дозволяє запобігти одній із найпідступніших механіко-електричних відмов безпілотного апарата — втраті тяги на критичному маневрі.

## Архітектура силового трифазного моста

Безколекторний двигун не має механічного колектора зі щітками. Щоб створити обертове магнітне поле, регулятор комутує напругу постійного струму від акумулятора на три обмотки статора (фази `U`, `V`, `W`) за допомогою шести польових транзисторів (N-канальних MOSFET).

```
          +V_BAT (12–25 В)
             │
     ┌───────┼───────┐
     │       │       │
   ┌─┴─┐   ┌─┴─┐   ┌─┴─┐
   │Q1 │   │Q3 │   │Q5 │  Верхні ключі (High-Side MOSFET)
   └─┬─┘   └─┬─┘   └─┬─┘
     ├───────┼───────┼────── До обмоток двигуна (U, V, W)
   ┌─┴─┐   ┌─┴─┐   ┌─┴─┐
   │Q2 │   │Q4 │   │Q6 │  Нижні ключі (Low-Side MOSFET)
   └─┬─┘   └─┬─┘   └─┬─┘
     │       │       │
     └───────┼───────┘
             │
         [Шунт R_s] -> Вимірювання струму
             │
            GND
```

У кожен момент часу в класичній шестикроковій (трапецеподібній) комутації задіяно рівно дві фази:
1. Одна фаза підключена до плюса живлення через верхній ключ (*High-Side*).
2. Друга фаза підключена до загального проводу через нижній ключ (*Low-Side*).
3. Третя фаза залишається електрично відключеною (плаваючою, *floating phase*).

## Визначення положення ротора за проти-ЕРС (Back-EMF)

Щоб перемкнути струм на наступну пару обмоток у правильний мікросекундний момент, мікроконтролер ESC повинен знати кутове положення постійних магнітів ротора відносно статора. У безсенсорних (*sensorless*) авіаційних моторах немає датчиків Холла або оптичних енкодерів.

Роль датчика виконує плаваюча третя обмотка. Коли ротор обертається, його постійні магніти перетинають витки цієї обмотки, індукуючи в ній напругу — **протиелектрорушійну силу** (проти-ЕРС, або *Back-EMF*).

Форма наведеної проти-ЕРС має трапецеподібний або синусоїдальний вигляд. Момент, коли ця напруга перетинає нульовий рівень відносно віртуальної середньої точки зірки двигуна (*zero-crossing point*, ZCP), настає рівно за 30 електричних градусів до необхідного моменту комутації наступного кроку.

```
Напруга фази
  ^
  │         /───\ [Верхній напівперіод]
  │        /     \
0 ┼───────/───────X───────\─────── [Zero-Crossing Point: перетин нуля]
  │                \     /
  │                 \───/ [Нижній напівперіод]
  └──────────────────────────────> Час (t)
                  ▲
                  │ Затримка 30° -> Команда перемикання ключів
```

## Механізм зриву синхронізації (ESC Desync)

Зрив синхронізації (*desync*, від латинського *de-* — роз'єднання, та грецького *synchronos* — одночасний) — це стан, за якого алгоритм регулятора втрачає правильний момент детекції перетину нуля проти-ЕРС і починає подавати силові імпульси у протифазі з обертанням магнітного поля ротора.

### Першопричина: стрибок шпаруватості ШІМ (High di/dt)

У польоті дрон стикається з поривом вітру або виконує різкий маневр. Польотний контролер миттєво піднімає команду тяги з 15% до 100% за один цикл (менш ніж за 1 мс).

1. **Сплеск струму розмагнічування (*Demagnetization current*):** Індуктивність обмотки статора перешкоджає миттєвій зміні струму (`V = L · di/dt`). Після вимкнення ключа струм продовжує текти через паразитний діод MOSFET, створюючи на плаваючій фазі викид напруги. Якщо цей викид триває довше, ніж очікував алгоритм, аналоговий компаратор ESC бачить хибний «нуль» проти-ЕРС.
2. **Падіння амплітуди проти-ЕРС під навантаженням:** При різкому уповільненні обертання під дією важкого гвинта амплітуда сигналу проти-ЕРС падає нижче порогу чутливості АЦП/компаратора, гублячись у високочастотних шумах ШІМ-комутації.
3. **Хибне перемикання фази:** Регулятор вмикає транзистори не в той момент часу. Замість прискорення магнітне поле статора гальмує ротор, струм зростає до струму короткого замикання (десятки ампер), двигун видає характерний високий писк (*motor squeal*) або тріск, а тяга падає до нуля.

```
Різкий стрибок газу (15% -> 100% за 1 мс)
       │
       ▼
Викид струму самоіндукції обмотки (L · di/dt)
       │
       ▼
Засліплення компаратора ZCP шумами та розмагнічуванням
       │
       ▼
Хибне визначення кута ротора (помилка комутації)
       │
       ▼
Струм гальмує магніти -> Двигун виє, тяга зникає -> Перекидання апарата
```

## Двосторонній DShot та апаратний захист

Для запобігання фатальним наслідкам desync сучасні системи використовують цифровий протокол керування **DShot** (Digital Shot) з підтримкою зворотної телеметрії (*Bidirectional DShot* / *Extended DShot Telemetry*).

Замість аналогового ШІМ-імпульсу польотний контролер надсилає цифровий 16-бітний пакет по одній сигнальній лінії, а регулятор у паузі між пакетами відповідає контролеру телеметрією (частота обертання `ERPM`, температура ключів, споживаний струм).

Нижче наведено модуль фільтрації десинхронізації та захисту від надструму для мікроконтролера ESC на мовах C та C++.

```c
#include <stdint.h>
#include <stdbool.h>

#define MAX_CURRENT_AMPS         45.0f
#define DESYNC_RPM_DROP_RATIO    0.40f
#define ZCP_TIMEOUT_MICROS       1500

typedef struct {
    float filtered_current;
    uint32_t expected_erpm;
    uint32_t measured_erpm;
    uint32_t last_commutation_us;
    uint8_t desync_counter;
    bool motor_stalled;
} esc_health_monitor_t;

void esc_monitor_init(esc_health_monitor_t *mon) {
    mon->filtered_current = 0.0f;
    mon->expected_erpm = 0;
    mon->measured_erpm = 0;
    mon->last_commutation_us = 0;
    mon->desync_counter = 0;
    mon->motor_stalled = false;
}

bool esc_check_commutation_health(esc_health_monitor_t *mon,
                                  float raw_current,
                                  uint32_t current_erpm,
                                  uint32_t now_us) {
    /* 1. Фільтрація струму (експоненційне ковзне середнє) */
    mon->filtered_current = 0.85f * mon->filtered_current + 0.15f * raw_current;

    /* 2. Перевірка таймауту детекції нульової проти-ЕРС */
    if ((now_us - mon->last_commutation_us) > ZCP_TIMEOUT_MICROS && mon->expected_erpm > 3000) {
        mon->desync_counter++;
    } else if (mon->desync_counter > 0) {
        mon->desync_counter--;
    }

    /* 3. Детекція раптового падіння обертів під великим струмом */
    if (mon->filtered_current > MAX_CURRENT_AMPS &&
        current_erpm < (uint32_t)(mon->expected_erpm * DESYNC_RPM_DROP_RATIO)) {
        mon->desync_counter += 3;
    }

    /* 4. Захисне вимкнення при накопиченні помилок */
    if (mon->desync_counter >= 6) {
        mon->motor_stalled = true;
        return false; /* Зрив синхронізації виявлено: скинути шпаруватість у 0! */
    }

    mon->measured_erpm = current_erpm;
    mon->last_commutation_us = now_us;
    return true;
}
```
```cpp
#include <cstdint>
#include <algorithm>

class EscHealthMonitor {
public:
    static constexpr float kMaxCurrentAmps = 45.0f;
    static constexpr float kDesyncRpmDropRatio = 0.40f;
    static constexpr uint32_t kZcpTimeoutMicros = 1500;
    static constexpr uint8_t kFaultThreshold = 6;

    struct Status {
        float filtered_current{0.0f};
        uint32_t measured_erpm{0};
        uint8_t desync_score{0};
        bool is_stalled{false};
    };

    constexpr EscHealthMonitor() noexcept = default;

    [[nodiscard]] bool update(float raw_current,
                             uint32_t target_erpm,
                             uint32_t current_erpm,
                             uint32_t now_us) noexcept {
        // 1. Фільтрація вимірювання шунта струму
        status_.filtered_current = 0.85f * status_.filtered_current + 0.15f * raw_current;

        // 2. Аналіз таймауту чергового перетину нуля
        const uint32_t dt = now_us - last_commutation_us_;
        if (dt > kZcpTimeoutMicros && target_erpm > 3000) {
            status_.desync_score = static_cast<uint8_t>(std::min<int>(status_.desync_score + 1, 10));
        } else if (status_.desync_score > 0) {
            --status_.desync_score;
        }

        // 3. Перевірка надструму при загальмованому роторі
        if (status_.filtered_current > kMaxCurrentAmps &&
            current_erpm < static_cast<uint32_t>(target_erpm * kDesyncRpmDropRatio)) {
            status_.desync_score = static_cast<uint8_t>(std::min<int>(status_.desync_score + 3, 10));
        }

        // 4. Фіксація аварійного стану
        if (status_.desync_score >= kFaultThreshold) {
            status_.is_stalled = true;
            return false; // Помилка: негайне зняття напруги з ключів
        }

        status_.measured_erpm = current_erpm;
        last_commutation_us_ = now_us;
        return true;
    }

    [[nodiscard]] const Status& get_status() const noexcept { return status_; }

private:
    Status status_{};
    uint32_t last_commutation_us_{0};
};
```

## Інженерні заходи запобігання desync

1. **Компенсація часу розмагнічування (*Demag compensation*):** Налаштування прошивки ESC (BLHeli_32 / AM32), що вводить паузу фільтрації компаратора після кожного перемикання фази для ігнорування викидів самоіндукції.
2. **Встановлення силових електролітичних конденсаторів Low-ESR:** Монтаж конденсатора ємністю від 470 до 1000 мкФ безпосередньо на клемах живлення ESC поглинає індуктивні викиди `L · (di/dt)` довгих дротів живлення й запобігає просіданню напруги на силовому мості.
3. **Обмеження швидкості наростання газу в польотному контролері (*Throttle slew rate limit*):** Програмне згладжування кроку газу на рівні 5–10 мс гарантує, що ротор встигає наростити швидкість без виходу за межі стійкості безсенсорного алгоритму.
