## 2. Детальний аналіз окремих радіонуклідних груп

### Природні довгоживучі радіонукліди (Первинні нукліди)

Первинні нукліди існують на Землі з моменту формування Сонячної системи близько 4.57 мільярдів років тому. Вони збереглися до нашого часу завдяки тому, що їхній період напіврозпаду співмірний з віком Землі або перевищує його.

Уран-238 становить понад 99.27% всієї маси природного урану. Завдяки альфа-розпаду з періодом напіврозпаду 4.468 мільярдів років Уран-238 дає початок природному радіоактивному ряду урану-радію, який завершується стабільним свинцем-206. Завдяки стабільному накопиченню свинцю-206 у мінералах уран-свинцевий метод є найточнішим інструментом визначення віку геологічних порід та метеоритів.

Калій-40 є головним джерелом внутрішньої радіоактивності людського організму. У тілі дорослої людини масою 70 кг міститься близько 140 грамів калію, з яких приблизно 16.5 міліграмів припадає на радіоактивний ізотоп Калій-40. Це забезпечує постійну внутрішню активність близько 4400 Беккерелів (4400 розпадів за секунду в організмі). Калій-40 розпадається двома шляхами: в 89% випадків через бета-мінус розпад у Кальцій-40, а в 11% випадків — через електронне захоплення (EC) у збуджений Аргон-40 із випромінюванням кванту з енергією 1.46 МеВ.

### Короткоживучі медичні ізотопи

У ядерній медицині застосовуються нукліди з короткими періодами напіврозпаду від кількох годин до кількох діб. Це дає змогу отримати високу інтенсивність сигналу для діагностики при мінімальному сумарному дозовому навантаженні на пацієнта.

Технецій-99m є метастабільним ядерним ізомером з періодом напіврозпаду 6.006 годин. Він випромінює моноенергетичні гамма-кванти з енергією 140 кеВ без супутнього альфа- чи бета-випромінювання. Ця енергія ідеально підходить для реєстрації гамма-камерами в однофотонній емісійній томографії (ОФЕТ). Технецій-99m отримують безпосередньо в лікарнях за допомогою радіоізотопного генератора на основі Молібдену-99 (`T₁/₂ = 66` годин).

Йод-131 застосовується для діагностики та терапії захворювань щитоподібної залози. Завдяки здатності щитоподібної залози вибірково накопичувати йод, випромінювані бета-частинки з енергією до 606 кеВ локально знищують пухлинні клітини, не пошкоджуючи навколишні здорові тканини, а супутнє гамма-випромінювання (364 кеВ) дає змогу візуалізувати процес лікування.

### Техногенні та промислові радіонукліди

Цезій-137 та Стронцій-90 є основними довгоживучими продуктами поділу Урану-235 у ядерних реакторах. З періодами напіврозпаду близько 30 років вони визначають радіоекологічний стан територій, забруднених унаслідок ядерних аварій або випробувань ядерної зброї. 

Цезій-137 хімічно подібний до калію і легко засвоюється рослинами та тваринними тканинами. Його дочірній нуклід Барій-137m випромінює інтенсивні гамма-кванти з енергією 662 кеВ. Стронцій-90 є хімічним аналогом кальцію і накопичується в кістковій тканині, де його бета-випромінювання вражає кістковий мозок.

Америцій-241 утворюється в ядерних реакторах у результаті послідовного захоплення нейтронів плутонієм. Він є альфа-випромінювачем з періодом напіврозпаду 432.2 роки. Завдяки високій іонізаційній здатності альфа-частинок Америцій-241 масово використовується в побутових іонізаційних сповіщувачах диму: крихітна кількість речовини (близько 0.9 мікрограма з активністю 33 кБк) іонізує повітря у вимірювальній камері, а поява частинок диму зменшує іонізаційний струм, що запускає тривожну сигналізацію.

## 3. Математичні формули зв'язку активності, маси та дози

Для обчислення активності `A` (в Беккерелях) чистого зразка масою `m` (в грамах) з молярною масою `M` (г/моль) та періодом напіврозпаду `T₁/₂` (в секундах) використовується співвідношення:

```
A = λ · N = (ln(2) / T₁/₂) · (m · N_A / M)
```

де `N_A = 6.02214076 · 10²³` моль⁻¹ — число Авогадро.

Питома активність `A_spec` на 1 грам речовини обчислюється як:

```
A_spec = A / m = (ln(2) · N_A) / (T₁/₂ · M) ≈ (4.177 · 10²³) / (T₁/₂ · M)  [Бк/г]
```

### Перерахунок ефективного періоду напіввиведення з організму

У біології та медицині випромінювальна речовина виводиться з організму не лише внаслідок радіоактивного розпаду, а й у результаті метаболічних біологічних процесів (екскреція, обмін речовин).

Біологічний період напіввиведення `T_bio` — це час, за який організм виводить половину накопиченого елемента біологічним шляхом.

Спільна дія фізичного розпаду та біологічного виведення описується **ефективним періодом напіввиведення** `T_eff`:

```
1 / T_eff = 1 / T_phys + 1 / T_bio
```

або у вигляді добутку:

```
T_eff = (T_phys · T_bio) / (T_phys + T_bio)
```

Ефективний період напіввиведення завжди є меншим за менше з двох значений `T_phys` та `T_bio`. Для короткоживучих медичних нуклідів `T_phys << T_bio`, тому `T_eff ≈ T_phys`. Натомість для нерозчинних довгоживучих нуклідів `T_eff ≈ T_bio`.

## 4. Фізика тепловиділення та генератори РІТЕГ

Кожен ядерний розпад супроводжується виділенням кінетичної енергії частинок або гамма-квантів `E_decay`. Оскільки поглинання цих частинок у навколишній речовині перетворює їхню кінетичну енергію на теплову, радіоактивне джерело постійно виділяє теплову потужність `P_th`.

Теплова потужність радиоізотопного джерела активністю `A` (Бк) при енергії розпаду `E_decay` (МеВ):

```
P_th = A · E_decay · (1.60218 · 10⁻¹³ Дж/МеВ)  [Ватт]
```

Для 1 грама чистого Полонію-210 (`T₁/₂ = 138.38` діб, `E_α = 5.30` МеВ) питома теплова потужність становить приголомшливі `140` Ватт/грам. Невеликий ампульний зразок полонію розжарюється до червоного світіння виключно за рахунок власного альфа-розпаду.

У радіоізотопних термоелектричних генераторах (РІТЕГ) найчастіше застосовують Плутоній-238 (`T₁/₂ = 87.7` років, питома потужність `0.57` Вт/г). Його теплова потужність спадає настільки повільно, що забезпечує стабільну роботу термоелементів космічних апаратів (наприклад, зондів Voyager 1 та Voyager 2) протягом понад 50 років безперервної експлуатації.

## 5. Дозиметричні характеристики та гамма-постійна

При роботі з гамма-випромінюючими радіонуклідами потужність експозиційної дози `H_dot` на відстані `r` від точкового джерела без самопоглинання обчислюється за допомогою **гамма-постійної нукліда** `Г`:

```
H_dot = Г · A / r²
```

де `A` — активність джерела, `r` — відстань від джерела до точки вимірювання, а `Г` — іонізаційна гамма-постійна, що залежить від енергії та виходу гамма-квантів на один розпад.

Приклади гамма-постійних для популярних нуклідів:
- Кобальт-60 (`⁶⁰Co`): `Г = 1.32` (Р·см²)/(год·мКі);
- Цезій-137 (`¹³⁷Cs`): `Г = 0.33` (Р·см²)/(год·мКі);
- Радій-226 (`²²⁶Ra` у рівновазі з дочірніми): `Г = 0.825` (Р·см²)/(год·мКі).

Ці параметри дозволяють обчислити необхідну товщину матеріалів захисту (свинцю, бетону, води) за допомогою шар-послаблення половинного поглинання (HVL — Half-Value Layer):

```
I(x) = I₀ · 2^(-x / HVL)
```

де `x` — товщина захисного екрана, а `HVL` — товщина шару половинного послаблення для даної енергії гамма-квантів у конкретному матеріалі.
