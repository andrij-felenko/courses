# 📋 Довідник фундаментальних квантових носіїв та констант взаємодії

Цей довідник містить систематизовані числові значення, квантові числа, параметри калібрувальних груп та фундаментальні константи чотирьох типів взаємодій у Стандартній моделі фізики елементарних частинок.

## 1. Фундаментальні калібрувальні бозони (переносники сил)

Усі носії фундаментальних взаємодій у рамках квантової теорії поля є векторними бозонами зі спіном 1 (за винятком гіпотетичного тензорного ґравітона зі спіном 2). Вони виникають як необхідні коваріантні поля компенсації при забезпеченні локальної калібрувальної інваріантності відповідних груп симетрії.

| Частинка-носій | Символ | Взаємодія | Електричний заряд (`e`) | Спін (`ħ`) | Маса спокою | Ширина розпаду `Γ` | Час життя `τ` (с) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **Фотон** | `γ` | Електромагнітна | `0` | `1` | `< 10⁻¹⁸ еВ/c²` | Стійкий | `> 10³³` (стабільний) |
| **Ґлюон** (8 типів) | `g` | Сильна (колірна) | `0` | `1` | `0` (теоретично) | Невідомо (конфайнмент) | Втрачає свободу у адронах |
| **W-бозон** | `W⁺`, `W⁻` | Слабка (заряджена) | `+1`, `-1` | `1` | `80.377 ± 0.012 ҐеВ/c²` | `2.085 ± 0.042 ҐеВ` | `~ 3.15 · 10⁻²⁵` |

Константи зв'язку визначають інтенсивність розсіяння, переріз реакцій та швидкість перебігу квантових процесів на характерних енергетичних масштабах.

## 3. Специфікація прецизійних електрослабких параметрів

Прецизійні вимірювання на коллайдерах LEP (CERN), SLC (SLAC) та Tevatron (Fermilab) визначили базові фізичні величини Стандартної моделі:

### 1. Константа Фермі `G_F`
Константа Фермі визначається з прецизійного часу життя мюона `τ_μ` з урахуванням вищих операндних поправок QED:

```
G_F = (1.1663788 ± 0.0000006) · 10⁻⁵ ҐеВ⁻²
```

Зв'язок константи Фермі з масою `W`-босона та калібрувальною константою `g`:

```
G_F / √2 = g² / (8 · m_W²)
```

### 2. Електрослабкий кут змішування (кут Вайнберґа `θ_W`)
Ефективний синус слабкого кута змішування визначається відношенням мас бозонів та зв'язків полів:

```
sin² θ_W = 1 - (m_W / m_Z)² ≈ 0.22305
sin² θ_W^(eff) (M_Z) = 0.23153 ± 0.00016
```

### 3. Вакуумне очікуване значення поля Хіґґса `v`
Значення `v` характеризує масштаб спонтанного порушення електрослабкої симетрії `SU(2)_L × U(1)_Y → U(1)_EM`:

```
v = (√2 · G_F)⁻¹/² ≈ 246.22 ҐеВ
```

Скалярний бозон Хіґґса `H⁰` володіє експериментально виміряною масою `m_H = 125.25 ± 0.17` ҐеВ/c² та повною шириною розпаду `Γ_H ≈ 4.1` МеВ.

## 4. Матриця Кабіббо — Кобаяші — Маскава (CKM) для слабких заряджених струмів

Матриця CKM описує змішування кваркових ароматів при взаємодії із зарядженими `W⁺` та `W⁻` бозонами. Вона є унітарною матрицею 3×3, яка пов'язує фізичні масові власні стани нижніх кварків `(d, s, b)` із їхніми слабозарядженими власними станами `(d', s', b')`:

```
|d'>   ( V_ud  V_us  V_ub )   |d>
|s'> = ( V_cd  V_cs  V_cb ) * |s>
|b'>   ( V_td  V_ts  V_tb )   |b>
```

### Експериментальні модулі елементів CKM-матриці (PDG 2024)

```
|V_CKM| = 
[ 0.97373 ± 0.00031   0.22430 ± 0.00080   0.00382 ± 0.00020 ]
[ 0.22100 ± 0.00800   0.97500 ± 0.00600   0.04080 ± 0.00140 ]
[ 0.00860 ± 0.00020   0.04150 ± 0.00090   1.01300 ± 0.03000 ]
```

- **Діагональні елементи (`V_ud, V_cs, V_tb`):** Близькі до 1, що означає переважний розпад кварка у межах власного покоління (наприклад, `u → d`, `t → b`).
- **Недіагональні елементи (`V_us, V_cb`):** Придушені кутом Кабіббо `θ_C ≈ 13°` (`sin θ_C ≈ 0.225`).
- **Елементи третього покоління (`V_ub, V_td`):** Надзвичайно малі, що зумовлює тривалий час життя `b`-кварків.
- **Комплексна фаза `δ_13`:** Спричиняє пряме порушення CP-симетрії у слабких розпадах K- та B-мезонів.

Параметризація Вольфенштайна (у степенях `λ = sin θ_C ≈ 0.225`) виражає химерну ієрархію CKM-елементів:

```
V_CKM = 
[ 1 - λ²/2         λ          A λ³ (ρ - i η) ]
[ -λ               1 - λ²/2   A λ²           ]
[ A λ³ (1 - ρ - i η)  -A λ²   1              ] + O(λ⁴)
```

де `A ≈ 0.826`, `ρ ≈ 0.159`, `η ≈ 0.348`. Присутність ненульового фазового параметра `η` прямо відповідає за неінваріантність щодо операції комбінованої парності CP у баріонному Всесвіті. Порушення CP-симетрії характеризується інваріантом Ярльског `J_CP`:

```
J_CP = Im(V_us V_cb V_ub* V_cs*) ≈ 3.08 · 10⁻⁵
```

Унітарність CKM-матриці вимагає виконання трьох трикутних співвідношень у комплексній площині, найвідомішим із яких є трикутник для `B`-мезонів:

```
V_ud · V_ub* + V_cd · V_cb* + V_td · V_tb* = 0
```

Вимірювання кутів цього трикутника (`α, β, γ`) на B-фабриках (Belle, BaBar, LHCb) є одним із найточніших способів перевірки Стандартної моделі.

## 5. Матриця Понтекорво — Макі — Накаґава — Саката (PMNS) для нейтрино

Матриця PMNS описує змішування нейтринних ароматів `(ν_e, ν_μ, ν_τ)` та визначає ймовірність осциляцій нейтрино в процесі їхнього поширення у просторі:

```
|ν_e>   ( U_e1  U_e2  U_e3 )   |ν_1>
|ν_μ> = ( U_μ1  U_μ2  U_μ3 ) * |ν_2>
|ν_τ>   ( U_τ1  U_τ2  U_τ3 )   |ν_3>
```

### Експериментальні значення кутів змішування PMNS (PDG)

- **Кут змішування Сонця `θ_12`:** `33.41° ± 0.75°` (`sin² θ_12 ≈ 0.304`)
- **Кут змішування атмосфери `θ_23`:** `49.1° ± 1.0°` (`sin² θ_23 ≈ 0.573`)
- **Кут змішування реакторів `θ_13`:** `8.54° ± 0.15°` (`sin² θ_13 ≈ 0.022`)
- **Квадрат різниці мас (сонячний):** `Δm²_21 = (7.41 ± 0.21) · 10⁻⁵ еВ²`
- **Квадрат різниці мас (атмосферний):** `|Δm²_31| = (2.511 ± 0.027) · 10⁻³ еВ²`

На відміну от CKM-матриці кварків, де кути змішування малі, PMNS-матриця лептонів містить два великих кути змішування (`θ_12` та `θ_23`), що вказує на максимальну осциляційну перемішаність нейтринних станів. Ефект Михеєва — Смірнова — Вольфенштайна (MSW ефект) описує резонансне посилення осциляцій нейтрино при проходженні крізь речовину з високою електронною густиною (наприклад, у надрах Сонця).

## 6. Тензори напруженостей калібрувальних полів та лаґранжіани

Математична структура квантових полів записується через коваріантну похідну `D_μ` та тензори напруженостей `F_μν`:

### 1. Квантова електродинаміка (QED — абелева U(1) група)
```
D_μ = ∂_μ + i · e · A_μ
F_μν = ∂_μ A_ν - ∂_ν A_μ
```
Лаґранжіан полів: `L_QED = - (1/4) · F_μν · F^μν`.

### 2. Квантова хромодинаміка (QCD — неабелева SU(3) група)
```
D_μ = ∂_μ - i · g_s · T^a · G^a_μ
G^a_μν = ∂_μ G^a_ν - ∂_ν G^a_μ + g_s · f^abc · G^b_μ · G^c_ν
```
де `T^a` — генератори групи SU(3) (матриці Ґелл-Манна, `a = 1..8`), `f^abc` — структурні константи групи SU(3). Наявність самодіяльного додатка `g_s f^abc G^b_μ G^c_ν` обумовлює взаємодію ґлюонів між собою (самодії) та призводить до асимптотичної свободи і конфайнменту.

### 3. Електрослабке поєднання (SU(2)_L × U(1)_Y)
```
W^a_μν = ∂_μ W^a_ν - ∂_ν W^a_μ + g · ε^abc · W^b_μ · W^c_ν     (a = 1, 2, 3)
B_μν   = ∂_μ B_ν - ∂_ν B_μ
```

Змішування нейтральних полів `W³_μ` та `B_μ` утворює фізичний фотон `A_μ` та `Z⁰`-бозон `Z_μ` через кут Вайнберґа (слабкий кут `θ_W ≈ 28.7°`):

```
A_μ = B_μ · cos(θ_W) + W³_μ · sin(θ_W)
Z_μ = - B_μ · sin(θ_W) + W³_μ · cos(θ_W)
```

Зв'язок мас бозонів через вакуумне очікуване значення поля Хіґґса (`v ≈ 246` ҐеВ) та кут Вайнберґа:

```
m_W = (1/2) · g · v
m_Z = m_W / cos(θ_W) = (1/2) · √(g² + g'²) · v
```

Ці співвідношення підтверджені прецизійними експериментами на коллайдерах LEP (CERN) та Tevatron (Fermilab).

## 7. Фейнманівські вершини та правила взаємодії

Кожен тип фундаментальної взаємодії характеризується відповідними фейнманівськими вершинами зв'язку:

- **QED (Електромагнетизм):** Вершина `-i e γ^μ`, що зв'язує два заряжені ферміони та один фотон `γ`. Збереження електричного заряду виконане строго.
- **QCD (Сильна взаємодія):** Кварк-ґлюонна вершина `-i g_s T^a_ij γ^μ`, а також триґлюонна вершина `~ g_s f^abc` та чотириґлюонна вершина `~ g_s² (f^eab f^ecd)`.
- **Weak Charged Current (Слабка заряджена):** Вершина `-i (g / √2) γ^μ (1 - γ⁵) V_ij` для переходу кварків `q_i → q_j + W`, що включає оператор `(1 - γ⁵)` (максимальне порушення парності, взаємодія лише з лівокіральними компонентами) та матрицю CKM `V_ij`.
- **Weak Neutral Current (Слабка нейтральна):** Вершина `-i (g / (2 cos θ_W)) γ^μ (g_v - g_a γ⁵)` для взаємодії ферміонів із нейтральним `Z⁰`-бозоном, де векторний та аксіально-векторний заряди дорівнюють `g_v = T₃ - 2 Q sin² θ_W` та `g_a = T₃`.

## 8. Нерозв'язані фундаментальні константи та загадки

Незважаючи на високу точність Стандартної моделі, вона містить 19 вільних параметрів, які не виводяться з перших принципів і вимагають експериментального вимірювання:

1. **Три константи зв'язку:** `g_1, g_2, g_3` (або `α_1, α_2, α_3`).
2. **Два параметри потенціалу Хіґґса:** `v` (вакуумне очікування) та `λ` (самодія).
3. **Дев'ять мас ферміонів:** Маси шести кварків `(u, d, c, s, t, b)` та трьох заряджених лептонів `(e, μ, τ)`.
4. **Чотири параметри CKM-матриці:** Три кути змішування `θ_12, θ_23, θ_13` та фаза CP-порушення `δ`.
5. **Параметр вакууму QCD:** `θ_QCD` (значення близьке до 0, що становить сильну CP-проблему).

Пояснення походження цих констант є однією з головних задач фізики майбутнього.
