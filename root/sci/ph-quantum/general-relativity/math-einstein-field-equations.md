# 🧮 Математичний апарат і виведення рівнянь Ейнштейна

Математична будова загальної теорій відносності (ЗТВ) спирається на диференціальну геометрію ріманових і псевдоріманових многовидів. На відміну від плоского простору Мінковського спеціальної теорії відносності, у ЗТВ простір-час є чотиривимірним псевдорімановим многовидом `M` із сигнатурою метрики `(-, +, +, +)` або `(+, -, -, -)`. Гравітаційне поле більше не описується скалярним потенціалом Ньютона `Φ`, а втілюється у сам метричний тензор `g[μν]`.

## 1. Метричний тензор і квадрат інтервалу

Фундаментальним об'єктом геометрії є інваріантний квадрат інтервалу між двома нескінченно близькими подіями `dx^μ` у криволінійних координатах `x^μ = (x⁰, x¹, x², x³)`:

```
ds² = g_00·(dx⁰)² + g_01·dx⁰·dx¹ + ... + g_33·(dx³)²
= g_μν · dx^μ · dx^ν      [згортка за повторюваними індексами Ейнштейна]
```

Тензор метрики `g[μν]` є симетричним тензором валентності (0,2): `g[μν] = g[νμ]`. Він має 10 незалежних компонентів у чотиривимірному просторі-часі. Обернений метричний тензор `g^[μν]` задовольняє умову ортогональності:

```
g^μλ · g_λν = δ^μ_ν      [δ^μ_ν — символ Кронекера: 1 при μ=ν, 0 при μ≠ν]
```

Вільне тіло або промінь світла рухається у викривленому просторі по найкоротшій або найдовшій лінії — **геодезичній**, яка мінімізує інтеграл власного часу `τ`:

```
δ ∫ dτ = 0      [варіаційний принцип екстремуму інтервалу]
```

Рівняння геодезичної лінії виводиться за допомогою рівнянь Ейлера — Лаґранжа для лагранжіана `L = (1/2) · g_[μν] · (dx^μ/dτ) · (dx^ν/dτ)`. Після диференціювання за власним часом `τ` отримуємо стандартне рівняння геодезичної:

```
d²x^μ / dτ² + Γ^μ_αβ · (dx^α / dτ) · (dx^β / dτ) = 0
```

де `Γ^μ_[αβ]` — **символи Крістоффеля** (зв'язаність), які описують сили інерції та викривлення координатних сіток.

## 2. Зв'язаність Крістоффеля та коваріантне диференціювання

Звичайне частинне диференціювання `∂_ν V^μ = ∂V^μ / ∂x^ν` не є тензором у криволінійних координатах, оскільки самі базисні вектори змінюються від точки до точки. Щоб утворити тензорну похідну, вводять **коваріантну похідну** `∇_ν V^μ`:

```
∇_ν V^μ = ∂_ν V^μ + Γ^μ_να · V^α      [коваріантна похідна контраваріантного вектора]
∇_ν W_μ = ∂_ν W_μ - Γ^α_νμ · W_α      [коваріантна похідна коваріантного вектора]
```

Вимога узгодженості метрики (теорема Леві-Чивіти) полягає у тому, що коваріантна похідна самого метричного тензора дорівнює нулю у всьому просторі: `∇_λ g[μν] = 0`. З цієї умови однозначно виражаються символи Крістоффеля другого роду через частинні похідні компонент метрики:

```
Γ^λ_μν
= (1/2) · g^λσ · (∂_μ g_σν + ∂_ν g_σμ - ∂_σ g_μν)      [визначення символів Крістоффеля]
```

Символи Крістоффеля є симетричними за нижніми індексами: `Γ^λ_[μν] = Γ^λ_[νμ]`, бо у ЗТВ розглядається геометрія без кручення (тензор кручення Картана дорівнює нулю).

Розглянемо практичний приклад розрахунку символів Крістоффеля для сферичної симетрії метрики Шварцшильда у вакуумі. Оскільки метрика є діагональною `g = diag(g_00, g_rr, r², r²·sin²θ)`, ненульові символи Крістоффеля виражаються безпосередньо через логарифмічні похідні компонент метрики. Наприклад, для радіального прискорення маємо `Γ^r_00 = -(1/2) · (1 - r_s/r) · (r_s / r²)`, що у ньютонівському гравистатичному наближенні точно відновлює класичну силу притягання `G·M / r²`.

## 3. Тензор кривини Рімана, тензор Річчі та скалярна кривина

Внутрішнє викривлення простору-часу визначається некоммутативністю двох послідовних коваріантних похідних. Для довільного векторного поля `V^ρ`:

```
(∇_μ ∇_ν - ∇_ν ∇_μ) · V^ρ = R^ρ_σμν · V^σ
```

Тензор валентності (1,3) `R^ρ_[σμν]` називається **тензором кривини Рімана**. Його явна формула через символи Крістоффеля та їхні частинні похідні має вигляд:

```
R^ρ_σμν
= ∂_μ Γ^ρ_νσ - ∂_ν Γ^ρ_μσ + Γ^ρ_μλ · Γ^λ_νσ - Γ^ρ_νλ · Γ^λ_μσ      [тензор Рімана]
```

Тензор Рімана має 256 компонентів у чотиривимірному просторі-часі, але завдяки алгебраїчним симетріям кількість незалежних компонентів скорочується до 20:
- Антисиметрія за першою та другою парою індексів: `R_[ρσμν] = -R_[σρμν] = -R_[ρσνμ]`.
- Перестановочна симетрія пар: `R_[ρσμν] = R_[μνρσ]`.
- Перша тотожність Б'янкі: `R_[ρσμν] + R_[ρμνσ] + R_[ρνσμ] = 0`.

Згорткою тензора Рімана за першим та третім індексами отримують симетричний **тензор Річчі** `R[μν]` валентності (0,2):

```
R_μν
= R^λ_μλν      [згортка тензора Рімана за верхнім і середнім нижнім індексом]
= ∂_λ Γ^λ_μν - ∂_ν Γ^λ_λμ + Γ^λ_λσ · Γ^σ_μν - Γ^σ_νλ · Γ^λ_λσ
```

Польдальша згортка тензора Річі з оберненою метрикою дає скалярну кривину (скаляр Річчі) `R`:

```
R = g^μν · R_μν      [скалярна кривина Рімана]
```

Повний тензор кривини Рімана можна математично розкласти на три незалежні складові частини:
1. Скалярну кривину `R` (характеризує зміну 4-об'єму під дією ізотропного стиснення).
2. Безслідову частину тензора Річчі `R_[μν] - (1/4)·g_[μν]·R` (характеризує припливні сили, створені матерією у цій точці).
3. **Тензор Вейля** `C_[ρσμν]` (безслідова частина тензора Рімана). Тензор Вейля описує викривлення геометрії у вакуумі (вільні гравітаційні хвилі та гравітаційне поле поза масами).

## 4. Друга тотожність Б'янкі та тензор Ейнштейна

Друга коваріантна тотожність Б'янкі описує зв'язок коваріантних похідних тензора Рімана:

```
∇_λ R^ρ_σμν + ∇_μ R^ρ_σνλ + ∇_ν R^ρ_σλμ = 0      [друга тотожність Б'янкі]
```

Згортаючи цю тотожність двічі за допомогою метричного тензора `g^[μν]`, отримуємо фундаментальне дифференціальне співвідношення:

```
∇_μ R^μ_ν - (1/2) · ∇_ν R = 0
= ∇_μ (R^μ_ν - (1/2) · δ^μ_ν · R) = 0      [дивергенція тензора Ейнштейна дорівнює нулю]
```

Це дозволяє ввести **тензор Ейнштейна** `G[μν]`:

```
G_μν
= R_μν - (1/2) · g_μν · R      [визначення тензора Ейнштейна]
```

Головна властивість тензора Ейнштейна полягає у тому, що його коваріантна дивергенція є тотожним нулем у будь-якому криволінійному просторі-часі: `∇_μ G^[μν] = 0`. Це ідеально відповідає фізичному законові збереження енергії та імпульсу.

## 5. Варіаційний принцип і дія Гільберта — Айнштайна

Рівняння поля Ейнштейна можна строго вивести з фундаментального варіаційного принципу найменшої дії Гамільтона. Загальна дія гравітаційного поля та матерії `S` має вигляд:

```
S = S_g + S_m
= (1 / (2·κ)) · ∫ R · √(-g) · d⁴x + ∫ L_m · √(-g) · d⁴x      [дія Гільберта — Айнштайна]
```

де `g = det(g_[μν])` — детермінант метричного тензора, `√(-g)·d⁴x` — інваріантний елемент 4D-об'єму, `L_m` — лагранжіан матерії, `κ = 8·π·G / c⁴` — стала Айнштайна.

Варіювання дії `S` за оберненим метричним тензором `g^[μν]` вимагає розрахунку трьох варіаційних внесків:

1. **Варіація елемента об'єму за формулою Якобі:**

```
δ √(-g) = -(1/2) · √(-g) · g_μν · δg^μν      [варіація детермінанта метрики]
```

2. **Варіація скаляра Річчі `R = g^[μν] R_[μν]`:**

```
δ R = R_μν · δg^μν + g^μν · δR_μν
```

Внесок `g^[μν] δR_[μν]` за тотожністю Палатіні зводиться до повної коваріантної дивергенції `∇_λ (g^[μν] δΓ^λ_[μν] - g^[μλ] δΓ^ν_[μν])`. За теоремою Гаусса цей поверхневий інтеграл перетворюється на нуль на безкінечній межі інтегрування.

3. **Варіація дії матерії визначає тензор енергії-імпульсу `T[μν]`:**

```
T_μν = -(2 / √(-g)) · (δ(√(-g) · L_m) / δg^μν)      [визначення тензора енергії-імпульсу]
```

Збираючи всі три варіації докупи та прирівнюючи повну варіацію дії `δS = 0` для довільних варіацій `δg^[μν]`:

```
δS = (1 / (2·κ)) · ∫ ( R_μν - (1/2)·g_μν·R - κ·T_μν ) · δg^μν · √(-g) · d⁴x = 0
```

Оскільки варіація `δg^[μν]` є довільною у кожній точці простору-часу, вираз у дужках мусить тотожно дорівнювати нулю. Це дає польові рівняння Айнштайна:

```
R_μν - (1/2) · g_μν · R + Λ · g_μν = (8·π·G / c⁴) · T_μν      [повне рівняння поля]
```

Для ідеальної рідини з густиною енергії `ρ·c²` та ізотропним тиском `P` тензор енергії-імпульсу записується як:

```
T_μν = (ρ + P / c²) · u_μ · u_ν + P · g_μν      [тензор енергії-імпульсу ідеальної рідини]
```

де `u_μ` — 4-швидкість суцільного середовища (`u_μ u^μ = -c²`).

## 6. Граничний перехід до ньютонівської механіки

Щоб вивести константу `κ = 8·π·G / c⁴`, розглянемо слабке статичне гравітаційне поле з повільним рухом частинок (`v << c`). Метрику подамо у вигляді малого збурення плаского простору Мінковського `η[μν]`:

```
g_μν = η_μν + h_μν      [де |h_μν| << 1]
```

Для статичного поля всі часові похідні дорівнюють нулю (`∂_0 h_μν = 0`). Символи Крістоффеля першого порядку малості беруться як:

```
Γ⁰_00 = 0
Γ^i_00 = -(1/2) · ∂_i h_00      [i = 1, 2, 3]
```

Рівняння геодезичної для повільної частинки (`dx⁰/dτ ≈ c`, `dx^i/dτ << c`) спрощується до:

```
d²x^i / dt²
= -c² · Γ^i_00      [зв'язок релятивістського прискорення з символами Крістоффеля]
= (c² / 2) · ∂_i h_00      [підстановка Γ^i_00]
```

Порівнюючи це з ньютонівським рівнянням руху `d²x^i / dt² = -∂_i Φ` (де `Φ` — ньютонівський потенціал), отримуємо зв'язок часового компонента метрики з потенціалом:

```
h_00 = -2·Φ / c²
g_00 = -(1 + 2·Φ / c²)      [ньютонівське наближення метрики]
```

Розраховуючи тензор Річчі для слабкого статичного поля пилу з густиною маси `ρ` (`T_00 = ρ·c²`, `T_ij = 0`), маємо `R_00 ≈ (1/2) · ∇² h_00 = -(1/c²) · ∇² Φ`.

Згортаючи рівняння Ейнштейна `R_μν = κ · (T_μν - (1/2)·g_μν·T)` для 00-компонента:

```
R_00 = (1/2) · κ · ρ · c²
-(1/c²) · ∇² Φ = (1/2) · κ · ρ · c²
∇² Φ = -(1/2) · κ · ρ · c⁴      [отримане рівняння для потенціалу]
```

Зіставляючи це з класичним рівнянням Пуассона `∇² Φ = 4·π·G·ρ`:

```
-(1/2) · κ · c⁴ = -4·π·G
κ = 8·π·G / c⁴      [коефіцієнт зв'язку Айнштайна]
```

Цей вивід доводить, що загальна теорія відносності строго містить ньютонівську теорію тяжіння як слабкопольове гравистатичне наближення.
