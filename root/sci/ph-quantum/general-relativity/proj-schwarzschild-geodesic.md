# ⚙️ Моделювання геодезичних ліній у метриці Шварцшильда

У загальній теорії відносності рух частинок із масою та фотонів навколо необертальної центральної маси `M` описується геодезичними лініями у просторі-часі Шварцшильда. Оскільки аналітичне вираження траєкторій через еліптичні інтеграли Якобі є складним для швидкого обчислювального аналізу, в астрофізиці та комп'ютерній фізиці застосовують чисельне інтегрування диференціальних рівнянь руху.

## 1. Ефективний потенціал та рівняння руху

Розглянемо рух у екваторіальній площині `θ = π/2`. Квадрат чотиривимірного інтервалу у геометрії Шварцшильда має вигляд:

```
ds² = -(1 - r_s / r) · c² · dt² + (1 - r_s / r)⁻¹ · dr² + r² · dφ²
```

де `r_s = 2·G·M / c²` — гравітаційний радіус (радіус Шварцшильда) маси `M`.

Завдяки симетрії метрики відносно часу `t` та азимутального кута `φ`, існують дві інтегральні величини руху: питома енергія `E` та питомий кутовий момент `L`. Закон збереження чотириімпульсу приводить до фундаментального рівняння для радіального руху:

```
(dr / dτ)² + 2 · V_eff(r) = E² - c²      [рівняння радіальної швидкості]
```

де **ефективний потенціал** `V_eff(r)` містить три різновиди фізичних внесків:

```
V_eff(r) = -G·M / r + L² / (2·r²) - G·M·L² / (c² · r³)     [ефективний потенціал ЗТВ]
```

Розберемо детально фізичний зміст кожного з трьох доданків у формулі ефективного потенціалу:

1. **`-G·M / r` — класичний ньютонівський потенціал тяжіння.** Входить зі знаком «мінус» і забезпечує притягання мас на великих відстанях. Цей додаток є домінуючим на астрономічних відстанях у Сонячній системі.
2. **`+L² / (2·r²)` — відцентровий потенціальний бар'єр.** Входить зі знаком «плюс» і виникає через наявність кутового моменту. У ньютонівській механіці саме цей член не дає планетам впасти на Сонце, створюючи відштовхувальну силу при наближенні тіла до центру.
3. **`-G·M·L² / (c² · r³)` — чисто релятивістська поправка ЗТВ.** Вона зменшується пропорційно до куба відстані `1/r³` зі знаком «мінус», тож стає домінуючою на дуже малих відстанях від центральної маси. Вона повністю перемагає позитивний відцентровий бар'єр при наближенні до горизонту подій. Це призводить до того, що на близьких відстанях від чорної діри відцентрова сила перестає захищати тіло від падіння, безповоротно втягуючи його під горизонт подій.

З аналізу ефективного потенціалу випливають два фундаментальні межі геометрії Шварцшильда:

- **Найвнутрішніша стабільна колова орбіта (ISCO):** Для масивних частинок коловий рух стає нестійким при радіусах `r < r_ISCO = 3·r_s = 6·G·M / c²`. Будь-яке найменше збурення орбіти частинки на `r < 3·r_s` призводить до незворотного падіння у чорну діру.
- **Фотонна сфера:** Для фотонів (`m = 0`) відцентровий бар'єр має максимум при `r_ph = 1.5·r_s = 3·G·M / c²`. На цій відстані світло може рухатися по нестабільній коловій орбіті навколо чорної діри, утворюючи фотонне кільце.

Шляхом введення оберненої радіальної координати `u = 1 / r` рівняння траєкторії фотона як функції кута `φ` набуває вигляду:

```
d²u / dφ² + u = (3/2) · r_s · u²     [рівняння траєкторії фотона]
```

Для вивчення траєкторії замінимо диференціальне рівняння другого порядку на еквівалентну систему двох рівнянь першого порядку щодо `u` та його кутової похідної `w = du/dφ`:

```
du / dφ = w
dw / dφ = (3/2) · r_s · u² - u     [система рівнянь першого порядку]
```

Для масивної частинки (наприклад, для розрахунку прецесії перигелію Меркурія) рівняння руху набуває вигляду:

```
d²u / dφ² + u = (G·M / L²) + (3/2) · r_s · u²     [рівняння для масивної частинки]
```

## 2. Чисельний метод інтегрування Рунге — Кутти 4-го порядку (RK4)

Для інтегрування системи диференціальних рівнянь використовується класичний метод Рунге — Кутти четвертого порядку (RK4). Порівняно з простим методом Ейлера, RK4 забезпечує четвертий порядок точності за кроком `dφ` (локальна похибка `O(dφ⁵)`), що гарантує збереження фазового об'єму та високу точність обчислення траєкторії навіть при проходженні фотона поблизу фотонної сфери.

Алгоритм обчислення одного кроку інтегрування для вектора стану `Y = (u, w)^T` при кроці `dφ`:

```
k1 = f(u, w)
k2 = f(u + 0.5·dφ·k1_u, w + 0.5·dφ·k1_w)
k3 = f(u + 0.5·dφ·k2_u, w + 0.5·dφ·k2_w)
k4 = f(u + dφ·k3_u, w + dphi·k3_w)
Y_(n+1) = Y_n + (dφ / 6) · (k1 + 2·k2 + 2·k3 + k4)     [схема інтегрування RK4]
```

Для фотона, що налітає з великої відстані `r_initial >> r_s` з пристрільним параметром `b`, початкові значення `u` та `w` дорівнюють:

```
u_0 = 1 / r_initial
w_0 = √( max(0, 1/b² - u_0² · (1 - r_s · u_0)) )
```

Фізичні умови зупинки чисельного інтегрування:
1. **Захоплення горизонтом подій:** Якщо `u >= 1 / r_s`, фотон перетнув горизонт подій `r <= r_s` і більше не повернуться назовні.
2. **Розсіювання на нескінченність:** Якщо `u <= 0` при `φ > π/2`, фотон віддалився від маси на безкінечну відстань.
3. **Перевищення ліміту кроків:** Запобігання безкінечному циклу у випадку руху по зацикленій орбіті біля фотонної сфери.

## 5. Порівняння режиму малих і критичних пристрільних параметрів

Аналіз результатів чисельного інтегрування демонструє два суттєво відмінних фізичних режими руху світла у полі Шварцшильда:

1. **Режим пристрільних параметрів слабкого поля (`b >> r_s`):**
   При `b = 6.96 × 10⁸ м` (край Сонця, де `b / r_s ≈ 235 000`), релятивістська поправка `(3/2)·r_s·u²` виявляється дуже малою порівняно з лінійним членом `u`. Кут відхилення обчислюється як `θ ≈ 4·G·M / (c²·b) = 2·r_s / b`, що дає точно `1.75` кутових секунд. Чисельний розрахунок повністю збігається з аналітичною формулою першого порядку малості.

2. **Режим пристрільних параметрів критичного поля (`b -> b_crit = (3·√3 / 2) · r_s ≈ 2.598 · r_s`):**
   Коли пристрільний параметр фотона наближається до критичного значення `b_crit ≈ 2.598 · r_s`, релятивістський додаток у потенціалі врівноважує відцентровий бар'єр біля фотонної сфери `r_ph = 1.5 · r_s`. Фотон робить один, два чи навіть декілька повних обертів навколо чорної діри перед тим, як вирватися назовні або впасти за горизонт подій. У цьому режимі кут відхилення логарифмічно розбігається:

   ```
   θ(b) ≈ -ln(b / b_crit - 1) + const     [розбіжність кута відхилення біля фотонної сфери]
   ```

Цей чисельний результат лежить в основі розрахунку геометричного вигляду «тіні» чорних дір, яку спостерігає Телескоп горизонту подій (EHT): радіус тіні на далекій відстані дорівнює саме критичному пристрільному параметру `b_crit = 3·√3/2 · r_s ≈ 2.6 · r_s`.

## 6. Чисельна оптимізація та адаптивний крок інтегрування

У реальних астрофізичних обчисленнях постійний крок за кутом `dφ` має недоліки: далеко від чорної діри обчислювальні ресурси витрачаються на дрібні кроки в майже пласкому просторі, тоді як біля горизонту подій швидкі зміни `du/dφ` вимагають ще дрібнішої сітки.

Для підвищення ефективності застосовують адаптивні схеми інтегрування, такі як метод Рунге — Кутти — Фельберга 4(5) (RKF45) або Дормана — Принса. Вони оцінюють локальну похибку на кожному кроці за різницею між схемами 4-го та 5-го порядків і автоматично зменшують крок `dφ` біля периастра та збільшують його далеко від центральної маси. Також у сучасних кодах рендерингу чорних дір (наприклад, для фільмів та астрофізичних візуалізацій) інтегрування геодезичних розпаралелюють на графічних процесорах (GPU за допомогою CUDA/OpenCL), де кожен фотон обробляється окремим обчислювальним потоком.
