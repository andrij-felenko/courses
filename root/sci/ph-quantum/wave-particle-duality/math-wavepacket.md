# 🧮 Математика хвильових пакетів та співвідношення невизначеностей

Вставка містить суворе виведення математичного апарату квантових хвиль матерії: побудову хвильового пакета як суперпозиції плоско-гармонічних хвиль, виведення фазової та групової швидкостей, аналіз дисперсійного розпливання квантового стану з часом за допомогою часового рівняння Шредінгера, операторний розрахунок фази Ааронова — Бома та спектральний доказ співвідношення невизначеностей Гейзенберга за допомогою перетворення Фур'є.

## 1. Неможливість локалізації монохроматичної хвилі та поняття хвильового пакета

Поодинока плоска монохроматична хвиля де Бройля описується комплексною хвильовою функцією:

```
ψ(x, t) = A · exp(i · (k · x - ω · t))
```

де `k = 2π / λ = p / ℏ` — хвильове число, а `ω = E / ℏ` — кругова частота.

Обчислимо густину ймовірності виявлення частинки з так визначеною хвильовою функцією в просторі:

```
P(x, t) = |ψ(x, t)|² = ψ*(x, t) · ψ(x, t) = |A|² = const
```

Оскільки густина ймовірності є строго постійною в усіх точках простору від `-∞` до `+∞`, монохроматична хвиля описує стан зі строго визначеним імпульсом `p = ℏ k` (`Δp = 0`), але повністю невизначеною координатою частинки (`Δx → ∞`). Така функція не належить до гіільбертового простору `L²(-∞, +∞)` і не піддається стандартній інтегральній нормалізації на одиницю.

Для опису реальної фізичної частинки, локалізованої у скінченній області простору `Δx`, побудуємо хвильовий пакет — неперервну суперпозицію монохроматичних плоскохвиль із спектральним розподілом амплітуд `ϕ(k)`:

```
ψ(x, t) = (1 / √(2π)) · ∫₋∞⁺∞ ϕ(k) · exp(i · (k · x - ω(k) · t)) dk
```

Функція `ϕ(k)` представляє амплітудний спектр у к-просторі і визначається зворотним перетворенням Фур'є просторової хвильової функції `ψ(x, 0)` в початковий момент часу `t = 0`:

```
ϕ(k) = (1 / √(2π)) · ∫₋∞⁺∞ ψ(x, 0) · exp(-i · k · x) dx
```

За теоремою Парсеваля норма хвильової функції у координатному та імпульсному просторах зберігається:

```
∫₋∞⁺∞ |ψ(x, t)|² dx = ∫₋∞⁺∞ |ϕ(k)|² dk = 1
```

## 2. Формальне виведення фазової та групової швидкостей

Припустимо, що спектральна функція `ϕ(k)` має вузький симетричний пік біля середнього хвильового числа `k₀` з шириною `Δk << k₀`. Розкладемо дисперсійну функцію `ω(k)` у ряд Тейлора в околі точкового значення `k = k₀`:

```
ω(k) = ω(k₀) + (dω / dk)|_k₀ · (k - k₀) + (1/2) · (d²ω / dk²)|_k₀ · (k - k₀)² + ...
```

Обмежимося на першому етапі лінійним наближенням по `(k - k₀)`. Позначивши змінну інтегрування як `ξ = k - k₀`, підставимо розклад у формулу хвильового пакета:

```
ψ(x, t) ≈ (1 / √(2π)) · ∫₋∞⁺∞ ϕ(k₀ + ξ) · exp(i · ( (k₀ + ξ) · x - (ω(k₀) + (dω/dk)|_k₀ · ξ) · t )) dξ
```

Винесемо за знак інтеграла фазовий множник середньої хвилі `exp(i (k₀ x - ω(k₀) t))`:

```
ψ(x, t) = exp(i · (k₀ · x - ω(k₀) · t)) · [ (1 / √(2π)) · ∫₋∞⁺∞ ϕ(k₀ + ξ) · exp(i · ξ · (x - (dω/dk)|_k₀ · t)) dξ ]
```

Отриманий вираз розпадається на два помножені фактори:
1. **Високочастотна несуча хвиля**: `exp(i (k₀ x - ω(k₀) t))`, фазові фронти якої рухаються зі швидкістю, званою фазовою швидкістю:

```
v_phase = ω(k₀) / k₀
```

2. **Просторова огинаюча (амплітудний профіль)**: `A(x, t) = A(x - v_group · t)`, яка поширюється як цілісний огинаючий профіль зі швидкістю:

```
v_group = (dω / dk)|_k₀
```

Здійснимо математичну перевірку значення групової швидкості для нерелятивістської частинки маси `m`. Кінетична енергія класичної частинки дорівнює `E = p² / (2m)`. Використовуючи формули де Бройля `E = ℏ ω` та `p = ℏ k`, запишемо квантове дисперсійне співвідношення:

```
ω(k) = (ℏ · k²) / (2 · m)
```

Обчислимо фазову та групову швидкості як функції хвильового вектора:

```
v_phase = ω / k = (ℏ · k) / (2 · m) = p / (2 · m) = v / 2       [фазова швидкість удвічі менша за класичну швидкість]
```

```
v_group = dω / dk = d/dk [ (ℏ · k²) / (2 · m) ] = (ℏ · k) / m = p / m = v    [групова швидкість строго дорівнює класичній швидкості частинки]
```

Таким чином, центроїд амплітудної густини ймовірності частинки переміщується у просторі строго зі швидкістю фізичного перенесення маси та енергії `v`.

Для релятивістської частинки з масою спокою `m₀`:

```
E = √(c² · p² + m₀² · c⁴) = ℏ · ω
```

Обчислимо похідні:

```
v_group = dE / dp = d/dp [ √(c² · p² + m₀² · c⁴) ] = (c² · p) / √(c² · p² + m₀² · c⁴) = (c² · p) / E = v
```

```
v_phase = E / p = (m · c²) / (m · v) = c² / v > c
```

Фазова швидкість перевищує швидкість світла у вакуумі `c`, однак це не порушує СТО, оскільки фазові фронти монохроматичної хвилі не переносять інформації або енергії — сигнал транспортується виключно з груповою швидкістю `v_group = v < c`.

## 3. Точне розв'язання рівняння Шредінгера для Ґаусового пакета

Врахуємо другу похідну розкладу `(1/2) (d²ω / dk²)|_k₀ (k - k₀)²`, яка відповідає за дисперсійне розпливання стану.

Розглянемо нормований Ґаусів хвильовий пакет у початковий момент часу `t = 0` з початковою дисперсією `σ₀`:

```
ψ(x, 0) = (1 / (2 · π · σ₀²)¹/⁴) · exp(- x² / (4 · σ₀²)) · exp(i · k₀ · x)
```

Обчислимо спектральну функцію `ϕ(k)` через пряме перетворення Фур'є:

```
ϕ(k) = (2 · σ₀² / π)¹/⁴ · exp(- σ₀² · (k - k₀)²)
```

Для вільної частинки часове рівняння Шредінгера має вигляд:

```
i · ℏ · (∂ψ / ∂t) = - (ℏ² / (2 · m)) · (∂²ψ / ∂x²)
```

У `k`-просторі це рівняння стає диференціальним рівнянням першого порядку зі звичайними похідними:

```
i · ℏ · (∂ϕ(k, t) / ∂t) = (ℏ² · k² / (2 · m)) · ϕ(k, t)
```

Розв'язок у `k`-просторі дається точним виразом:

```
ϕ(k, t) = ϕ(k, 0) · exp(-i · (ℏ · k² / (2 · m)) · t)
```

Виконуючи обернене перетворення Фур'є та обчислюючи Ґаусів інтеграл, отримуємо точну хвильову функцію у координатному просторі для довільного моменту часу `t`:

```
ψ(x, t) = (1 / (2 · π · σ(t)²)¹/⁴) · exp(i · θ(x, t)) · exp(- (x - v · t)² / (4 · σ₀ · σ(t)))
```

де комплексна часова ширина пакета визначається співвідношенням:

```
σ(t) = σ₀ · ( 1 + i · (ℏ · t) / (2 · m · σ₀²) )
```

Обчислимо модуль квадрата хвильової функції (густину ймовірності):

```
|ψ(x, t)|² = (1 / (√(2 · π) · |σ(t)|)) · exp(- (x - v · t)² / (2 · |σ(t)|²))
```

де фізична ширина пакета `|σ(t)|` зростає за гіперболічним законом:

```
|σ(t)| = σ₀ · √( 1 + ( (ℏ · t) / (2 · m · σ₀²) )² )
```

Обчислимо часову характеристику розпливання — час `t_double`, за який просторовий розмір пакета збільшується удвічі (`|σ(t)| = 2 σ₀`):

```
t_double = 2 · √3 · (m · σ₀²) / ℏ
```

Проаналізуємо чисельні значення для електронів та макроскопічних тіл:

1. **Електрон у мікросвіті**: маса `m_e = 9.11 × 10⁻³¹ kg`, початковий розмір `σ₀ = 0.1 nm = 10⁻¹⁰ m`.

```
t_double = 2 · 1.732 · (9.11 × 10⁻³¹ × 10⁻²⁰) / (1.055 × 10⁻³⁴) ≈ 2.99 × 10⁻¹⁶ s = 0.30 fs
```

Хвильовий пакет електрона в атомарних масштабах розпливається менше ніж за одну фемтосекунду.

2. **Макроскопічна піщинка**: маса `m = 1 mg = 10⁻⁶ kg`, початковий розмір `σ₀ = 1 μm = 10⁻⁶ m`.

```
t_double = 2 · 1.732 · (10⁻⁶ × 10⁻¹²) / (1.055 × 10⁻³⁴) ≈ 3.28 × 10¹⁶ s ≈ 1.04 × 10⁹ років
```

Час розпливання макроскопічного об'єкта перевищує мільярд років, що доводить абсолютну стійкість класичних траєкторій у макросвіті.

## 4. Ефект Ааронова — Бома та фазовий сув де Бройля

Корпускулярно-хвильовий дуалізм проявляється не лише через просторову амплітуду, а й через фазу хвильової функції `S / ℏ`, де `S` — класична дія Гамільтона — Якобі.

У 1959 році Якір Ааронов та Девід Бом передбачили, що хвильова функція зарядженої частинки `q` виявляє фазовий зсув при русі в просторі з електромагнітними потенціалами `(Φ, A)`, навіть якщо в області руху частинки магнітне `B = ∇ × A` та електричне `E = -∇Φ - ∂A/∂t` поля дорівнюють нулю.

Розглянемо часове рівняння Шредінгера у зовнішньому електромагнітному полі:

```
i · ℏ · (∂ψ / ∂t) = [ (1 / (2 · m)) · (-i · ℏ · ∇ - q · A)² + q · Φ ] · ψ
```

За допомогою підстановки під калібрувальне перетворення:

```
ψ(r, t) = ψ₀(r, t) · exp( (i · q / ℏ) · ∫ (A · dr - Φ · dt) )
```

отримуємо фазовий зсув `Δφ` між двома траєкторіями електронів, що обгинають нескінченно довгий соленоїд із магнітним потоком `Ф_mag`, усередині якого `B ≠ 0`, але зовні `B = 0`:

```
Δφ = (q / ℏ) · ∮ A · dr = (q / ℏ) · ∬ (∇ × A) · dS = (q / ℏ) · Ф_mag
```

Ефект Ааронова — Бома довів, що хвилі де Бройля відчувають потенціали поля `A` безпосередньо, підкреслюючи квантовий лоренц-інваріантний характер хвильової функції.

## 5. Спектральний доказ співвідношення невизначеностей Гейзенберга

Співвідношення невизначеностей є строгим математичним наслідком теореми про фундаментальну межу розмитості пари перетворень Фур'є.

Введемо математичні визначення операторних середніх та дисперсій координати `x̂ = x` та імпульсу `p̂_x = -i ℏ (∂/∂x)` для нормованого стану `ψ(x)`:

```
<x> = ∫₋∞⁺∞ ψ*(x) · x · ψ(x) dx
```

```
<p_x> = ∫₋∞⁺∞ ψ*(x) · (-i · ℏ · (∂ψ / ∂x)) dx
```

```
(Δx)² = <(x - <x>)²> = ∫₋∞⁺∞ (x - <x>)² · |ψ(x)|² dx
```

```
(Δp_x)² = <(p_x - <p_x>)²> = ∫₋∞⁺∞ |(-i · ℏ · (∂/∂x) - <p_x>) · ψ(x)|² dx
```

Для спрощення розрахунку без втрати загальності виконаємо зсув координат так, щоб `<x> = 0` та `<p_x> = 0`. Розглянемо допоміжну інтегральну функцію для довільного дійсного параметра `α ∈ ℝ`:

```
I(α) = ∫₋∞⁺∞ | α · x · ψ(x) + ℏ · (dψ / dx) |² dx ≥ 0
```

Розкриємо квадрат модуля під інтегралом:

```
I(α) = α² · ∫₋∞⁺∞ x² · |ψ|² dx + α · ℏ · ∫₋∞⁺∞ x · ( ψ* · (dψ/dx) + ψ · (dψ*/dx) ) dx + ℏ² · ∫₋∞⁺∞ |dψ/dx|² dx
```

Проінтегруємо середній доданок по частинах:

```
∫₋∞⁺∞ x · (d/dx |ψ|²) dx = [ x · |ψ|² ]₋∞⁺∞ - ∫₋∞⁺∞ |ψ|² dx = 0 - 1 = -1
```

Підставляючи отримані значення дисперсій `(Δx)²` та `(Δp_x)²`, перепишемо квадратну нерівність щодо `α`:

```
I(α) = α² · (Δx)² - α · ℏ + (Δp_x)² ≥ 0
```

Для того щоб квадратний тричлен щодо `α` був невід'ємним для всіх дійсних значень `α`, його дискримінант `D` мусить бути меншим або дорівнювати нулю:

```
D = ℏ² - 4 · (Δx)² · (Δp_x)² ≤ 0
```

Виносячи квадратний корінь, отримуємо строгу математичну межу Гейзенберга:

```
(Δx)² · (Δp_x)² ≥ ℏ² / 4
```

```
Δx · Δp_x ≥ ℏ / 2
```

Рівність `Δx · Δp_x = ℏ / 2` досягається тоді й лише тоді, коли `I(α) = 0`, що означає виконання диференціального рівняння `α x ψ + ℏ (dψ/dx) = 0`. Розв'язком цього рівняння є строго Ґаусів хвильовий пакет, доводячи, що Ґаусові стани володіють мінімально можливим добутком невизначеностей.
