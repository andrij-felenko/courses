# 🧮 Математична теорія та виведення формул гальмівного випромінювання

Вставка містить послідовні математичні виведення класичних та квантово-електродинамічних співвідношень гальмівного випромінювання: від класичної формули Лармора для прискореного заряду до закону Дуана — Ганта, напівкласичного спектра Крамерса, співвідношення радіаційних та іонізаційних втрат енергії та релятивістського перерізу Бете — Гайтлера.

## Класичне випромінювання заряду у кулонівському полі

Розглянемо нерелятивістський електрон з масою `m_e` та зарядом `-e`, який рухається у кулонівському полі атомного ядра із зарядом `+Z e`. Згідно з класичною електродинамікою Максвелла, миттєва потужність випромінювання `P` зарядженої частинки, що рухається з векторним прискоренням `a`, визначається фундаментальною формулою Лармора:

```
P = (2 / 3) · [e² / (4 π ε₀ c³)] · a²
```

Електрична кулонівська сила `F`, що діє на електрон на миттєвій відстані `r` від точкового ядра, та викликане цією силою векторіальне прискорення `a` обчислюються за законом Кулона та другим законом Ньютона:

```
F = (Z e²) / (4 π ε₀ r²)               [закон Кулона для точкових зарядів]
a = F / m_e = (Z e²) / (4 π ε₀ m_e r²)  [другий закон Ньютона: a = F / m]
```

Підставляючи прискорення `a` у формулу Лармора, отримуємо залежність миттєвої випромінюваної потужності від миттєвої відстані до ядра `r`:

```
P(r) = (2 / 3) · [e² / (4 π ε₀ c³)] · [(Z e²) / (4 π ε₀ m_e r²)]²  [підстановка прискорення a]
= (2 / 3) · [Z² e⁶ / ((4 π ε₀)³ m_e² c³ r⁴)]                       [алгебраїчне спрощення]
```

Для обчислення повної енергії `ΔE`, випроміненої електроном за один акт прольоту повз ядро з прицільним параметром `b` та початковою швидкістю `v`, необхідно проінтегрувати потужність `P(r(t))` вздовж всієї траєкторії руху електрона від нескінченного віддалення до прольоту і подальшого віддалення:

```
ΔE = ∫ P(r(t)) dt      [інтегрування миттєвої потужності від t = -∞ до t = +∞]
```

У наближенні прямолінійного руху для маловідхиленого прольоту миттєва відстань до ядра залежить від часу як `r(t) = √(b² + v² t²)`, де `t = 0` відповідає точці найменшого зближення. Підставляючи `r(t)` у вираз для потужності:

```
ΔE = (2 / 3) · [Z² e⁶ / ((4 π ε₀)³ m_e² c³)] · ∫ [1 / (b² + v² t²)²] dt  [заміна змінної r(t)]
```

Для обчислення визначеного інтеграла виконуємо тригонометричну заміну `v t = b tg(φ)`, де `dt = (b / v) sec²(φ) dφ`, а межі інтегрування змінюються від `φ = -π/2` до `φ = +π/2`:

```
∫ [1 / (b² + v² t²)²] dt = ∫ [1 / (b⁴ sec⁴(φ))] · (b / v) sec²(φ) dφ   [тригонометрична заміна]
= (1 / (v b³)) · ∫ cos²(φ) dφ                                           [спрощення sec²(φ)]
= (1 / (v b³)) · [π / 2]                                               [значення інтеграла від -π/2 до +π/2]
```

Множачи константний коефіцієнт на результат інтегрування, отримуємо остаточну класичну формулу випроміненої енергії за один проліт:

```
ΔE = (2 / 3) · [Z² e⁶ / ((4 π ε₀)³ m_e² c³)] · [π / (2 v b³)]  [підстановка обчисленого інтеграла]
= (π Z² e⁶) / (3 (4 π ε₀)³ m_e² c³ v b³)                       [остаточний класичний вираз]
```

Отриманий класичний результат свідчить, що випромінена енергія є обернено пропорційною кубу прицільного параметра `b³` та квадрату маси частинки `m_e²`. Для масивних частинок (наприклад, протонів з масою `m_p ≈ 1836 m_e`) випромінювана енергія є меншою у `(m_p / m_e)² ≈ 3.37 × 10⁶` разів, що пояснює, чому гальмівне випромінювання є домінуючим саме для легких електронів та позитронів.

## Строгий вивід короткохвильової межі Дуана — Ганта

Розглянемо квантовий акт випромінювання при зіткненні електрона з масивним ядром. Нехай вхідний електрон має повну релятивістську енергію `E_i` та імпульс `p_i`, а розсіяний електрон після випромінювання фотона з частотою `ν` та хвильовим вектором `k` має енергію `E_f` та імпульс `p_f`.

Закон збереження 4-імпульсу у процесі випромінювання має вигляд:

```
P_i + P_N = P_f + P_N' + K_photon               [збереження 4-імпульсу]
```

Де `P_N` та `P_N'` — початковий та кінцевий 4-імпульси ядра. Проектуючи співвідношення на часову компоненту, отримуємо закон збереження повної енергії:

```
E_i + M_N c² = E_f + E_N' + h ν                 [збереження повної енергії]
```

Де `E_N' = √(M_N² c⁴ + q_N² c²)` — енергія ядра віддачі після розсіювання, а `q_N = p_i - p_f - ℏ k` — імпульс віддачі, переданий ядру. Розкладаючи енергію ядра в ряд за малим імпульсом віддачі `q_N << M_N c`:

```
E_N' - M_N c² = q_N² / (2 M_N) = E_rec           [кінетична енергія віддачі ядра]
```

Оскільки маса ядра `M_N` переважає масу електрона більш ніж у 1836 разів (`M_N >> m_e`), кінетична енергія віддачі ядра є зневажливо малою у порівнянні з енергією електрона:

```
E_rec ≈ 0                                        [унаслідок M_N >> m_e]
E_i - E_f = h ν                                  [базовий енергетичний баланс]
```

Виражаючи повну релятивістську енергію електрона через його масу спокою `m_e c²` та кінетичну енергію `E_k`:

```
E_i = m_e c² + E_k;i                             [початкова енергія електрона]
E_f = m_e c² + E_k;f                             [кінцева енергія електрона]
h ν = (m_e c² + E_k;i) - (m_e c² + E_k;f) = E_k;i - E_k;f  [зміна кінетичної енергії]
```

Максимально можлива частота випроміненого фотона `ν_max` досягається у граничному випадку, коли електрон віддає фотону абсолютно всю свою початкову кінетичну енергію, зупиняючись відносно ядра (`E_k;f = 0`):

```
h ν_max = E_k;i                                  [гранична умова повністю зупиненого електрона]
```

Якщо електрон прискорюється у вакуумному проміжку електростатичним полюсом із різницею потенціалів (анодною напругою) `U`, його початкова кінетична енергія дорівнює `E_k;i = e · U`.

```
h ν_max = e · U                                  [закон Дуана — Ганта для частоти]
ν_max = (e · U) / h
```

Переходячи від частоти до мінімальної довжини хвилі `λ_min = c / ν_max`:

```
λ_min = (h · c) / (e · U)                        [закон Дуана — Ганта для довжини хвилі]
```

Підставляючи значення фундаментальних фізичних констант (`h ≈ 6.62607015 × 10⁻³⁴ Дж·с`, `c ≈ 2.99792458 × 10⁸ м/с`, `e ≈ 1.602176634 × 10⁻¹⁹ Кл`), отримуємо зручну практичну формулу:

```
λ_min (нм) = (6.62607 × 10⁻³⁴ · 2.99792 × 10⁸) / (1.60218 × 10⁻¹⁹ · U)
= 1.23984 × 10⁻⁶ / U (В) = 1239.84 / U (В)
```

**Числовий приклад:** Для рентгенівської трубки з анодною напругою `U = 40 кВ = 40 000 В`:

```
λ_min = 1239.84 / 40000 = 0.030996 нм ≈ 0.31 Å
ν_max = (1.60218 × 10⁻¹⁹ · 40000) / (6.62607 × 10⁻³⁴) ≈ 9.672 × 10¹⁸ Гц
```

## Напівкласична формула спектра Крамерса та ККД анода

Для визначення спектрального розподілу випромінюваної енергії суцільного спектра скористаємося виведенням Крамерса. Диференціальний переріз випромінювання фотона з частотою в інтервалі `[ν, ν + dν]` при зіткненні електрона з ядром дорівнює:

```
dσ_K = (8 π / (3 √3)) · [Z² r_e² α / ν] · (m_e c² / E_k) dν  [переріз Крамерса]
```

Де `r_e = e² / (4 π ε₀ m_e c²) ≈ 2.8179 × 10⁻¹⁵ м` — класичний радіус електрона, а `α = e² / (4 π ε₀ ℏ c) ≈ 1 / 137.036` — стала тонкої структури.

Спектральна інтенсивність випромінювання `dI / dν = h ν · (dσ_K / dν)` для моноенергетичного електронного пучка з струмом `I_e` має вигляд:

```
dI / dν = C_K · Z · I_e · (ν_max - ν)            [спектральний закон Крамерса]
```

Де `C_K` — представлена константа Крамерса. Загальна випромінювана потужність гальмівного випромінювання `P_rad` обчислюється шляхом інтегрування спектральної інтенсивності від `ν = 0` до верхньої межі `ν_max`:

```
P_rad = ∫ (dI / dν) dν                           [межі інтегрування від 0 до ν_max]
= C_K · Z · I_e · ∫ (ν_max - ν) dν
= C_K · Z · I_e · [ν_max t - ν²/2]                [первісна функція]
= C_K · Z · I_e · [ν_max² / 2]                   [значення визначеного інтеграла]
```

Підставляючи граничну частоту Дуана — Ганта `ν_max = (e U) / h`:

```
P_rad = C_K · Z · I_e · [(e U / h)² / 2]         [підстановка закону Дуана — Ганта]
= [(C_K e²) / (2 h²)] · Z · I_e · U²
= k · Z · I_e · U²                               [загальна потужність гальмівного випромінювання]
```

Де `k ≈ 1.1 × 10⁻⁹ В⁻¹` — емпіричний коефіцієнт ефективності.

Електрична потужність `P_el`, що споживається рентгенівською трубкою від джерела живлення, дорівнює:

```
P_el = U · I_e                                  [електрична потужність джерела]
```

Коефіцієнт корисної дії (ККД) `η` перетворення електричної енергії електронного пучка в гальмівне рентгенівське випромінювання становить:

```
η = P_rad / P_el = (k · Z · I_e · U²) / (U · I_e)
= k · Z · U                                     [формула ККД рентгенівського анода]
```

**Числовий розрахунок ККД:** Для вольфрамового анода (`Z = 74`) при напрузі `U = 100 кВ = 10⁵ В`:

```
η = 1.1 × 10⁻⁹ · 74 · 10⁵ = 0.00814 ≈ 0.81%
```

Отже, понад 99.19% споживаної електричної потужності розсіюється у вигляді тепла в анодному блоці, що вимагає інтенсивного примусового охолодження.

## Співвідношення радіаційних та іонізаційних втрат енергії

Під час руху електрона у речовині відбуваються два принципово різних процеси втрати кінетичної енергії на одиницю довжини шляху `x` (гальмівна здатність речовини `dE / dx`):
1. **Іонізаційні (зіткнювальні) втрати `(dE / dx)_coll`** — непружні зіткнення з атомними електронами (формула Бете — Блоха).
2. **Радіаційні втрати `(dE / dx)_rad`** — випромінювання гальмівних фотонів у кулонівському полі атомних ядер.

Для релятивістського електрона з повною енергією `E` у середовищі з атомним номером `Z` іонізаційні втрати зростають логарифмічно з енергією `(dE / dx)_coll ∝ ln(E)`, тоді як радіаційні втрати зростають строго лінійно з енергією `(dE / dx)_rad ∝ Z² · E`.

Співвідношення між радіаційними та іонізаційними втратами описується наближеною математичною формулою:

```
[(dE / dx)_rad] / [(dE / dx)_coll] ≈ (Z · E) / E_c
```

Де `E_c` — критична енергія речовини, при якій радіаційні втрати дорівнюють іонізаційним втратам:

```
E_c ≈ 800 МеВ / (Z + 1.2)                       [емпірична формула критичної енергії]
```

**Порівняльний розрахунок для різних середовищ:**

1. **Свинець (`Z = 82`):**
```
E_c ≈ 800 / (82 + 1.2) ≈ 9.61 МеВ
```
Для електронів з енергією `E > 10 МеВ` у свинці радіаційні втрати на гальмівне випромінювання переважають іонізаційні втрати.

2. **Повітря або біологічна тканина (`Z_eff ≈ 7.4`):**
```
E_c ≈ 800 / (7.4 + 1.2) ≈ 93.0 МеВ
```
У легких елементах радіаційні втрати стають домінуючими лише при високих релятивістських енергіях понад 90 МеВ.

Радіаційна довжина `X₀` визначається як середня відстань, на якій енергія релятивістського електрона внаслідок гальмівного випромінювання зменшується в `e` разів (`E(x) = E₀ · exp(-x / X₀)`):

```
1 / X₀ = 4 n_a Z² r_e² α · [ ln(183 / Z^(1/3)) ]  [формула радіаційної довжини Бете — Гайтлера]
```

Де `n_a` — концентрація атомів у середовищі. Для свинцю радіаційна довжина становить `X₀ ≈ 0.56 см`, для води `X₀ ≈ 36.1 см`, для повітря за нормальних умов `X₀ ≈ 304 м`.

## Диференціальний переріз Бете — Гайтлера в КЕД

У квантовій електродинаміці процес гальмівного випромінювання описується фейнманівськими діаграмами першого порядку по внутрішньому квантово-електродинамічному зв'язку `α` у зовнішньому статичному кулонівському полі `A_ext^μ(q)`.

Диференціальний переріз Бете — Гайтлера для випромінювання фотона з енергією `ℏ ω` у неізольованому кулонівському полі ядра без урахування атомного екранування має вигляд:

```
dσ / dω = (4 Z² r_e² α / ω) · (p_f / p_i) · {
    (4 / 3) - 2 E_i E_f (p_i² + p_f²) / (p_i² p_f²)
    + (m_e² c⁴) · [ (ε_i E_f / p_i³) + (ε_f E_i / p_f³) - (ε_i ε_f / (p_i p_f)) ]
    + L · [ (8 E_i E_f / (3 p_i p_f)) + (k² (E_i² E_f² + p_i² p_f²) / (p_i³ p_f³)) ]
}
```

Де `p_i, p_f` — початковий та кінцевий імпульси електрона, `k = ℏ ω / c` — імпульс фотона, а кінематичні логарифмічні множники `L, ε_i, ε_f` визначаються як:

```
L = ln [ (E_i E_f + p_i p_f c² - m_e² c⁴) / (E_i E_f - p_i p_f c² - m_e² c⁴) ]
ε_i = ln [ (E_i + p_i c) / (E_i - p_i c) ]
ε_f = ln [ (E_f + p_f c) / (E_f - p_f c) ]
```

Для ультрарелятивістських електронів (`E_i, E_f >> m_e c²`) формула Бете — Гайтлера спрощується до виразу:

```
dσ / dω ≈ (4 Z² r_e² α / ω) · (E_f / E_i) · [ (E_i / E_f) + (E_f / E_i) - (2 / 3) ] · [ ln(2 E_i E_f / (m_e c² ℏ ω)) - (1 / 2) ]
```

Аналіз асимптотики показує:
1. При `ω → 0` переріз поводиться як `dσ / dω ∝ 1 / ω`, що підтверджує наявність інфрачервоної дивергенції.
2. При `ℏ ω → E_k` (межа Дуана — Ганта) переріз прямує до скінченного квантового значення, на відміну від класичного опису.
