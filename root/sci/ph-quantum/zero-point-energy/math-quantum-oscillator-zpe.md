# 🧮 Математичне виведення енергії нульових коливань

Енергія нульових коливань квантового гармонічного осцилятора та її прояв у квантовій електродинаміці виводяться з фундаментальних математичних операторів квантової механіки. Ця вставка містить детальні та строгі виведення трима математичними методами: через алгебраїчний метод операторів знищення й народження (драбинні оператори), через варіаційну мінімізацію з використанням співвідношення невизначеностей Гейзенберга, а також через сумування і регулярізацію мод вакуумного поля за допомогою дзета-функції Римана для розрахунку макроскопічного ефекту Казимира.

## 1. Алгебраїчний метод операторів драбини (ladder operators)

Класична механіка описує гармонічний осцилятор масою `m` із власною круговою частотою `ω` за допомогою функції Гамільтона. Загальна енергія системи складається з суми кінетичної енергії частинки з імпульсом `p` та потенціальної енергії квазіпружної сили з координатою `x`:

```
H = p² / (2·m) + ½ · m · ω² · x²
```

У квантовій механіці координата `x` та імпульс `p` замінюються на самоспряжені квантові оператори `x̂` та `p̂`, які діють у гільбертовому просторі станів. Канонічне співвідношення перестановки для цих операторів визначається квантом дії Планка `ℏ`:

```
[x̂, p̂] = x̂·p̂ - p̂·x̂ = i·ℏ
```

Це комутаційне співвідношення є основою усієї квантової алгебри. Для факторизації квадратичної форми гамільтоніана введемо комплексні безрозмірні оператори пониження (знищення `â`) та підвищення (народження `â†`):

```
â = √(m·ω / (2·ℏ)) · (x̂ + i·p̂ / (m·ω))
â† = √(m·ω / (2·ℏ)) · (x̂ - i·p̂ / (m·ω))
```

Оператор знищення `â` є неермітовим, а оператор `â†` є його сопряженим. Обчислимо комутаційне співвідношення між операторами `â` та `â†`, розкривши їхні вирази через канонічний комутатор координати й імпульсу:

```
[â, â†]
= (m·ω / (2·ℏ)) · [x̂ + i·p̂/(m·ω),  x̂ - i·p̂/(m·ω)]
= (m·ω / (2·ℏ)) · ( [x̂, -i·p̂/(m·ω)] + [i·p̂/(m·ω), x̂] )       [лінійність комутатора]
= (m·ω / (2·ℏ)) · ( -i/(m·ω)·[x̂, p̂] + i/(m·ω)·[p̂, x̂] )
= (m·ω / (2·ℏ)) · ( -i/(m·ω)·(i·ℏ) + i/(m·ω)·(-i·ℏ) )       [використано [x̂,p̂] = i·ℏ]
= (m·ω / (2·ℏ)) · ( ℏ/(m·ω) + ℏ/(m·ω) )
= 1
```

Результат `[â, â†] = 1` показує, що оператори народження та знищення задовольняють канонічну бозе-алгебру. Виразимо тепер вихідні оператори координати `x̂` та імпульсу `p̂` через введені драбинні оператори `â` і `â†`:

```
x̂ = √(ℏ / (2·m·ω)) · (â + â†)
p̂ = -i · √(m·ℏ·ω / 2) · (â - â†)
```

Підставимо ці операторні вирази безпосередньо у вихідний оператор Гамільтона `Ĥ`:

```
Ĥ = p̂² / (2·m) + ½ · m · ω² · x̂²
= (1 / (2·m)) · (-m·ℏ·ω / 2) · (â - â†)² + (½ · m · ω²) · (ℏ / (2·m·ω)) · (â + â†)²   [підставлено x̂ та p̂ через â, â†]
= - ¼ · ℏ·ω · (â² - â·â† - â†·â + (â†)²) + ¼ · ℏ·ω · (â² + â·â† + â†·â + (â†)²)          [піднесено дужки до квадрата]
= ¼ · ℏ·ω · ( 2·â·â† + 2·â†·â )                                                           [скорочено однакові квадрати â² та (â†)²]
= ½ · ℏ·ω · ( â·â† + â†·â )                                                               [винесено спільний множник 2]
```

Застосувавши комутаційну тотожність `â·â† = â†·â + 1`, переставимо оператори та приведемо гамільтоніан до симетричного вигляду:

```
Ĥ = ½ · ℏ·ω · ( (â†·â + 1) + â†·â )   [підставлено â·â† = â†·â + 1]
= ℏ·ω · ( â†·â + ½ )                 [зведено подібні доданки]
= ℏ·ω · ( N̂ + ½ )                    [введено оператор кількості квантів N̂ = â†·â]
```

Оператор `N̂ = â†·â` називається оператором числа квантів (чисел заповнення). Оскільки він є самоспряженим та невід'ємно визначеним (`⟨ψ|â†·â|ψ⟩ = ||â|ψ⟩||² ≥ 0`), його власні значення `n` є цілими невід'ємними числами: `n = 0, 1, 2, 3...`.

Оскільки для основного (вакуумного) стану системи `|0⟩` діє математична умова відсутності квантів знищення `â|0⟩ = 0`, середня енергія осцилятора у стані `|0⟩` дорівнює:

```
E₀ = ⟨0|Ĥ|0⟩ = ℏ·ω · (0 + ½) = ½ · ℏ·ω
```

Цей результат доводить: навіть коли в системі немає жодного реального кванта збудження (`n = 0`), енергія осцилятора не вирівнюється з нулем, а дорівнює півкванту `½·ℏ·ω`.

## 2. Варіаційне виведення з принципу невизначеності

Альтернативним фізико-математичним методом оцінки енергії основного стану є варіаційний принцип, який спирається на нерівність Гейзенберга. Розглянемо квантовий осцилятор у симетричному стані, де середні значення координати й імпульсу дорівнюють нулю: `⟨x⟩ = 0` та `⟨p⟩ = 0`. Тоді дисперсії вимірювань координати та імпульсу збігаються з їхніми середньоквадратичними значеннями:

```
(Δx)² = ⟨x²⟩ - ⟨x⟩² = ⟨x²⟩
(Δp)² = ⟨p²⟩ - ⟨p⟩² = ⟨p²⟩
```

Виразимо повне математичне очікування енергії квантової системи через середньоквадратичні відхилення:

```
⟨E⟩ = ⟨p²⟩ / (2·m) + ½ · m · ω² · ⟨x²⟩
= (Δp)² / (2·m) + ½ · m · ω² · (Δx)²
```

Використовуючи грань фундаментального співвідношення невизначеностей Гейзенберга `Δx · Δp ≥ ℏ / 2`, виразимо мінімально припустиме значення невизначеності імпульсу через просторову локалізацію частинки `Δp = ℏ / (2·Δx)`:

```
E(Δx) = ℏ² / (8·m · (Δx)²) + ½ · m · ω² · (Δx)²
```

Отримана функціональна залежність описує фізичну конкуренцію двох протилежних процесів: зменшення просторової розмитості `Δx` знижує потенціальну енергію, але викликає гіперболічне зростання кінетичної енергії `1/(Δx)²`. Натомість розширення `Δx` зменшує кінетичну енергію, але збільшує потенціальну енергію за квадратичним законом. Для пошуку точного глобального мінімуму знайдемо першу похідну функції `E(Δx)` за змінною `Δx` та прирівняємо її до нуля:

```
dE / d(Δx) = - ℏ² / (4·m · (Δx)³) + m · ω² · Δx = 0
```

Розв'яжемо отримане алгебраїчне рівняння для знаходження оптимального просторового радіуса нульових коливань `(Δx)₀`:

```
m · ω² · Δx = ℏ² / (4·m · (Δx)³)               [прирівняно похідну dE/d(Δx) до нуля]
(Δx)⁴ = ℏ² / (4 · m² · ω²)                      [помножено обидві частини на (Δx)³ / (m·ω²)]
(Δx)₀ = √( ℏ / (2 · m · ω) )                    [добуто квадратний корінь із двох частин]
```

Підставимо знайдений оптимальний радіус локалізації `(Δx)₀` у вихідний вираз для функції енергії:

```
E_min = ℏ² / (8·m · (ℏ / (2·m·ω))) + ½ · m · ω² · (ℏ / (2·m·ω))   [підставлено (Δx)₀² = ℏ / (2·m·ω)]
= ¼ · ℏ·ω + ¼ · ℏ·ω                                               [спрощено дробові коефіцієнти]
= ½ · ℏ·ω                                                         [додано два однакові доданки]
```

Математичний аналіз показує, що потенціальна та кінетична складові нульової енергії роблять абсолютно однаковий внесок (по `¼·ℏ·ω` кожна), даючи в сумі точно `½·ℏ·ω`.

## 3. Регулярізація дзета-функцією Римана та виведення ефекту Казимира

У квантовій електродинаміці для розрахунку макроскопічної сили Казимира розглянемо прямокутний резонатор об'ємом `V = S · d` між двома незарядженими провідними пластинами площею `S`, рознесеними на відстань `d` уздовж осі `z`.

Хвильовий вектор електромагнітного поля підпорядковується межовим умовам для провідних поверхонь, що квантує компоненту `k_z = n·π / d` (де `n = 1, 2, 3...`). Власна частота кожної моди з двома незалежними полярнізаціями фотонів описується виразом:

```
ω_{n, k_⊥} = c · √(k_x² + k_y² + (n·π / d)²)
```

Повна нульова енергія вакуумного поля в резонаторі задається тривимірною сумою по модах:

```
E(d) = ℏ · (S / (4·π²)) · ∫∫ d²k_⊥ ∑_{n=1}^∞ c · √(k_⊥² + (n·π / d)²)
```

Ця інтегральна сума є макроскопічно розбіжною. Для виділення скінченного фізичного внеску проведемо аналітичне регулювання через дзета-функцію Римана або формулу Ейлера — Маклорена.

Розглянемо одновимірну суму частот мод вздовж осі `z`. Сума нульових частот прямо пропорційна сумі натуральних чисел:

```
S_z = ∑_{n=1}^∞ n
```

Дзета-функція Римана визначається для комплексної області `Re(s) > 1` через ряд:

```
ζ(s) = ∑_{n=1}^∞ n^{-s}
```

Аналітичне продовження дзета-функції Римана на усю комплексну площину дає точне значення у точці `s = -1`:

```
ζ(-1) = - 1 / 12
```

Застосовуючи регулярне віднімання енергії вільного вакууму (без пластин), різниця між дискретним сумуванням між пластинами та неперервним інтегруванням у вільному просторі дає регулярізоване значення густини енергії на одиницю площі:

```
ΔE(d) / S = - (π² · ℏ · c) / (720 · d³)
```

Взявши від'ємну похідну за відстані `d`, ми отримуємо макроскопічний тиск притягання Казимира між пластинами:

```
P = - d/dd [ ΔE(d) / S ] = - (π² · ℏ · c) / (240 · d⁴)
```

Отже, регулярізаційне значення `ζ(-1) = -1/12` безпосередньо узгоджується з виміряними механічними силами у вакуумному резонаторі.

## 4. Хвильові функції та поліноми Ерміта

Для повного опису нульового стану квантового осцилятора розглянемо диференціальне стаціонарне рівняння Шредінгера:

```
- (ℏ² / (2m)) · (d²ψ / dx²) + ½ m ω² x² ψ = E ψ
```

Ввівши безрозмірну змінну `ξ = x · √(m·ω / ℏ)`, рівняння зводиться до стандартного вигляд диференціального рівняння для ортогональних поліномів Ерміта `H_n(ξ)`:

```
ψ_n(x) = (m·ω / (π·ℏ))^(1/4) · (1 / √(2^n · n!)) · H_n(ξ) · exp(- ξ² / 2)
```

Для основного стану `n = 0` поліном Ерміта дорівнює одиниці `H₀(ξ) = 1`. Отже, хвильова функція основного стану є чистою гаусовою функцією:

```
ψ₀(x) = (m·ω / (π·ℏ))^(1/4) · exp(- m·ω·x² / (2·ℏ))
```

Ширина цього гаусового пакета на висоті `1/e` дорівнює точно `(Δx)₀ = √(ℏ / (2mω))`. Ймовірність виявлення частинки в класично забороненій області `|x| > x_cl` (де `x_cl = √(2E₀ / (mω²)) = √(ℏ / (mω))`) обчислюється через інтеграл помилок:

```
P(|x| > x_cl) = 2 · ∫_{x_cl}^∞ |ψ₀(x)|² dx ≈ 0.157  (тобто 15.7%)
```

Це доводить, що квантовий осцилятор в основному стані проводить понад `15.7%` часу в області, куди класична частинка не може проникнути через брак енергії.
