# 🧮 Математичний вивід співвідношення E² = (pc)² + (m₀c²)²

Математичний вивід співвідношення між енергією, імпульсом та масою дає суворе обґрунтування релятивістської механіки без припущень феноменологічного характеру. Виведення формули еквівалентності маси та енергії спирається на принципи варіаційного числення, чотиривимірну геометрію простору Мінковського та фундаментальні закони збереження класичної динаміки.

Цей документ містить три незалежні математичні доведення:
1. Аналітичний вивід релятивістської кінетичної енергії через інтеграл роботи сили при зміні релятивістського імпульсу.
2. Алгебраїчний вивід фундаментального інваріанта чотиривектора імпульсу у псевдоевклідовому просторі Мінковського.
3. Класичний думовий експеримент Ейнштейна 1906 року з коробкою випромінювання та збереженням руху центра мас.

## Вивід релятивістської кінетичної енергії через інтеграл роботи

У класичній механіці Ньютона сила визначається як похідна імпульсу за часом `F = dp/dt`, де імпульс вважається лінійно пропорційним швидкості `p = m₀·v`. У спеціальній теорії відносності імпульс частинки з масою спокою `m₀` включає релятивістський лоренц-множник `γ`, який ураховує спотворення часового інтервалу між подіями у різних інерційних системах відліку:

```
p = γ · m₀ · v = (m₀ · v) / √(1 - v²/c²)    [визначення релятивістського імпульсу]
```

Кінетична енергія `E_k`, набута частинкою при розгоні зі стану спокою `v = 0` до певної швидкості `v` під дією сили `F` вздовж просторової координати `x`, за визначенням дорівнює роботі цієї сили. Переходячи від інтегрування за координатою `x` до інтегрування за часом `t`, а потім до інтегрування за імпульсом `p`, ми отримуємо фундаментальне співвідношення:

```
E_k = ∫₀ˣ F dx                               [визначення роботи сили]
    = ∫₀ᵗ (dp/dt) · v dt                     [підстановка F = dp/dt та dx = v dt]
    = ∫₀ᵖ v dp                               [зміна змінної інтегрування з t на p]
```

Для обчислення інтеграла `∫ v dp` застосовуємо формулу інтегрування за частинами `∫ u dv = u·v - ∫ v du`. Це дозволяє звести інтегрування за імпульсом до інтегрування швидкості за імпульсом:

```
E_k = v · p - ∫₀ᵛ p(u) du                    [інтегрування за частинами]
```

Підставляємо функціональний вираз релятивістського імпульсу `p(u) = m₀·u / √(1 - u²/c²)` під знак другого інтеграла, де `u` є змінною інтегрування швидкості від 0 до підсумкового значення `v`:

```
E_k = v · (γ · m₀ · v) - ∫₀ᵛ (m₀ · u / √(1 - u²/c²)) du    [підстановка релятивістського імпульсу]
    = γ · m₀ · v² - m₀ · ∫₀ᵛ (u / √(1 - u²/c²)) du         [винесення константи m₀]
```

Обчислюємо первісну для виразу `u / √(1 - u²/c²)`. Використовуючи заміну змінної `w = 1 - u²/c²`, бачимо, що дифференціал `dw = -2u/c² du`, звідки `u du = -c²/2 dw`. Отже, інтеграл легко обчислюється:

```
∫ (u / √(1 - u²/c²)) du = -c² · √(1 - u²/c²)              [первісна підкореневого виразу]
```

Підставляємо знайдену первісну та межі інтегрування від `0` до `v`:

```
E_k = γ · m₀ · v² - m₀ · (-c² · √(1 - v²/c²) - (-c² · √(1 - 0)))    [підстановка меж 0 та v]
    = γ · m₀ · v² + m₀ · c² · √(1 - v²/c²) - m₀ · c²                 [розкриття знаків мінус]
```

Виразимо квадрат швидкості `v²` через релятивістський множник `γ`. З визначення `γ = 1 / √(1 - v²/c²)` послідовно отримуємо квадрат підкореневого виразу, квадрат швидкості та обернене значення лоренц-множника:

```
1 - v²/c² = 1 / γ²                           [піднесення лоренц-множника до квадрата]
v² = c² · (1 - 1/γ²)                         [вираження квадрата швидкості]
√(1 - v²/c²) = 1 / γ                         [корінь з підкореневого виразу]
```

Тепер підставляємо знайдені вирази для `v²` та `√(1 - v²/c²)` у підсумковий вираз для кінетичної енергії:

```
E_k = γ · m₀ · (c² · (1 - 1/γ²)) + m₀ · c² · (1 / γ) - m₀ · c²    [підстановка γ у рівняння]
    = γ · m₀ · c² - (γ · m₀ · c²) / γ² + (m₀ · c²) / γ - m₀ · c²  [розкриття дужок]
    = γ · m₀ · c² - (m₀ · c²) / γ + (m₀ · c²) / γ - m₀ · c²        [скорочення γ у другому доданку]
    = γ · m₀ · c² - m₀ · c²                                        [взаємне знищення протилежних доданків]
    = (γ - 1) · m₀ · c²                                            [винесення m₀·c² за дужки]
```

Звідси слідує, що релятивістська кінетична енергія дорівнює різниці між повною енергією `E = γ·m₀·c²` та енергією спокою `E₀ = m₀·c²`:

```
E = E_k + m₀ · c²                            [визначення повної енергії]
  = (γ - 1) · m₀ · c² + m₀ · c²               [підстановка обчисленої E_k]
  = γ · m₀ · c²                              [остаточний вираз повної енергії]
```

## Вивід інваріанта енергії-імпульсу у просторі Мінковського

Чотиривимірний простір-час Мінковського описується псевдоевклідовою метрикою з інвариантною сигнатурою `η_μν = diag(-1, 1, 1, 1)`. Траєкторія частинки у цьому просторі задається чотиривектором положення `x^μ = (c·t, x, y, z)`.

Диференціювання чотиривектора положення за інваріантним власним часом частинки `τ` (пов'язаним із лабораторним часом співвідношенням `dτ = dt / γ`) дає чотиривектор швидкості `u^μ`:

```
u^μ = dx^μ / dτ = γ · (c, v_x, v_y, v_z)     [визначення чотиривектора швидкості]
```

Обчислимо скалярний квадрат чотиришвидкості `u_μ · u^μ` за правилом згортки з метричним тензором `η_μν`:

```
u_μ · u^μ = η_μν · u^μ · u^ν                  [скалярний добуток у псевдоевклідовому просторі]
          = -(γ · c)² + (γ · v_x)² + (γ · v_y)² + (γ · v_z)²    [розгортання компонент]
          = -γ² · c² + γ² · (v_x² + v_y² + v_z²)               [винесення γ²]
          = -γ² · c² + γ² · v²                                 [позначення v² = v_x² + v_y² + v_z²]
          = -γ² · c² · (1 - v²/c²)                             [винесення -γ²·c² за дужки]
          = -c²                                               [ураховано тотожність γ² · (1 - v²/c²) = 1]
```

Звідси видно, що скалярний квадрат чотиришвидкості є лоренц-інваріантною величиною і стабільно дорівнює від'ємній константі `-c²` для будь-якого масивного тіла в будь-якій інерційній системі відліку.

Чотиривектор імпульсу `p^μ` визначається як добуток інваріантної маси спокою `m₀` на чотиривектор швидкості `u^μ`:

```
p^μ = m₀ · u^μ = (γ · m₀ · c, γ · m₀ · v_x, γ · m₀ · v_y, γ · m₀ · v_z)    [визначення 4-імпульсу]
    = (E / c, p_x, p_y, p_z)                                              [підстановка E = γ·m₀·c² та p⃗ = γ·m₀·v⃗]
```

Обчислимо інваріантний скалярний квадрат чотиривектора імпульсу двох різних способів для встановлення фундаментального геометричного співвідношення.

Спочатку розкриваємо скалярний добуток через явні компоненти часової `E/c` та просторової `p⃗` частин:

```
p_μ · p^μ = -(E / c)² + p⃗ · p⃗                [скалярний квадрат компонент 4-імпульсу]
          = -(E / c)² + p²                   [позначення p² = |p⃗|²]
```

Тепер обчислимо цей самий скалярний квадрат, використовуючи визначення `p^μ = m₀ · u^μ` та доведену вище властивість `u_μ · u^μ = -c²`:

```
p_μ · p^μ = (m₀ · u_μ) · (m₀ · u^μ)          [підстановка 4-імпульсу через 4-швидкість]
          = m₀² · (u_μ · u^μ)                [винесення квадрата маси спокою]
          = m₀² · (-c²)                      [підстановка інваріанта 4-швидкості]
          = -m₀² · c²                        [остаточний вираз через інваріантну масу]
```

Прирівнюємо два отриманих вирази для скалярного інваріанта `p_μ · p^μ`:

```
-(E / c)² + p² = -m₀² · c²                   [прирівнювання двох виразів для інваріанта]
(E / c)² - p² = m₀² · c²                     [помноження обох частин на -1]
E² - (p · c)² = (m₀ · c²)²                   [помноження обох частин на c²]
```

Отримуємо фундаментальне релятивістське співвідношення між енергією, імпульсом та масою спокою:

```
E = √((p · c)² + (m₀ · c²)²)                 [добування квадратного кореня]
```

Проведем докладний аналіз фізичних границь отриманої формули:

1. **Стан спокою частинки (`p = 0`):**
Коли частинка не рухається у даній системі відліку, її просторовий імпульс дорівнює нулю. Тоді енергія зводиться виключно до енергії спокою:
```
E = √((0 · c)² + (m₀ · c²)²) = m₀ · c²       [енергія спокою]
```

2. **Безмасова частинка (`m₀ = 0`, фотон):**
Для квантів світла або інших безмасових частинок маса спокою дорівнює нулю. Зв'язок між енергією та імпульсом стає строго лінійним:
```
E = √((p · c)² + 0) = p · c                  [зв'язок енергії та імпульсу фотона]
```

3. **Нерелятивістська межа малих швидкостей (`p ≪ m₀·c`):**
Розкладемо корінь у ряд Тейлора за малим параметром `x = (p / (m₀·c))²`, використовуючи наближення `√(1 + x) ≈ 1 + ½·x`:

```
E = m₀ · c² · √(1 + (p / (m₀ · c))²)         [винесення m₀·c² за корінь]
  ≈ m₀ · c² · (1 + ½ · p² / (m₀² · c²))     [розклад Тейлора першого порядку]
  = m₀ · c² + p² / (2 · m₀)                 [підстановка класичного імпульсу p = m₀·v]
  = m₀ · c² + ½ · m₀ · v²                   [отримання суми енергії спокою та ньютонівської E_k]
```

Звідси чітко видно, що класична кінетична енергія Ньютона `½·m₀·v²` є лише першим динамічним поправковим членом нерелятивістського розкладу повної енергії Ейнштейна.

## Думовий експеримент Ейнштейна з коробкою випромінювання (1906)

Для наочного фізичного обґрунтування передачі маси енергією випромінювання розглядаємо замкнений циліндр (коробку) з масою `M` та довжиною `L`, який початково перебуває у стані спокою на абсолютній гладкій поверхні без тертя.

З внутрішнього лівого торця коробки випромінюється короткий світловий спалах з енергією `E`.

1. **Імпульс фотонного спалаху:**
За хвильовою та квантовою теорією, імпульс випромінюваного електромагнітного спалаху дорівнює:
```
p_ph = E / c                                 [імпульс світлового спалаху]
```

2. **Реактивна віддача коробки:**
За законом збереження повного імпульсу ізольованої системи, у момент випромінювання світла коробка набуває швидкості віддачі `v_box` у протилежному напрямку:

```
M · v_box = E / c                            [закон збереження імпульсу]
v_box = E / (M · c)                          [швидкість віддачі коробки]
```

3. **Час польоту світлового імпульсу:**
Світловий спалах поширюється зі швидкістю `c` і долає внутрішню довжину коробки `L` за інтервал часу:

```
Δt = L / c                                   [час польоту світла]
```

4. **Просторове зміщення коробки:**
Протягом часу польоту світла `Δt` коробка рухається вліво і зміщується на відстань `Δx`:

```
Δx = v_box · Δt                              [відстань зміщення коробки]
   = (E / (M · c)) · (L / c)                 [підстановка v_box та Δt]
   = (E · L) / (M · c²)                      [остаточний зсув коробки]
```

5. **Поглинання світла та зупинка:**
Коли світловий спалах досягає правого внутрішнього торця коробки, він повністю поглинається стінкою. Переданий світлом імпульс компенсує імпульс віддачі коробки, і вона миттєво зупиняється.

6. **Умова незмінності центра мас:**
Оскільки на коробку не діяли жодні зовнішні сили, центр мас всієї ізольованої системи за законом Ньютона повинен залишатися абсолютно непорушним. Проте сам корпус коробки масою `M` змістився вліво на відстань `Δx`.

Для забезпечення непорушності центра мас ми змушені визнати, що разом зі світловим спалахом енергії `E` від лівої стінки до правої перенеслася деяка еквівалентна маса `Δm` на відстань `L`:

```
Δm · L = M · Δx                              [умова незмінності центра мас]
Δm · L = M · ((E · L) / (M · c²))            [підстановка зсуву Δx]
Δm · L = (E · L) / c²                        [скорочення маси коробки M]
Δm = E / c²                                  [формула еквівалентності маси та енергії]
```

Цей елегантний думовий експеримент доводить, що якби енергія електромагнітного випромінювання `E` не володіла інертною масою `Δm = E / c²`, закон збереження центру мас замкненої системи був би грубо порушений.
