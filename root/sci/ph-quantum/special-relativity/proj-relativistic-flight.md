# ⚙️ Симуляція релятивістського перельоту та перетворення чотири-імпульсу

Обчислювальна фізика спеціальної теорії відносності поєднує точні математичні моделі, чисельні методи, аналіз крайових випадків та програмні реалізації двох фундаментальних релятивістських задач: розрахунку кінематики міжзоряного космічного перельоту зі сталим власним прискоренням і чисельного перетворення чотири-імпульсу елементарних частинок при переході між рухомими системами відліку. Симуляція реалізує обчислювальні алгоритми та фізичні моделі з урахуванням граничних умов, надаючи повністю робочі, високопродуктивні реалізації мовами C та сучасною C++23.

## 1. Фізична та математична модель

### Задача 1: Переліт зі сталим власним прискоренням (гіперболічний рух)

У класичній механіці Ньютона тіло, на яке діє постійна за модулем сила `F`, рухається з постійним прискоренням `a = F / m`, і його швидкість зростає лінійно безмежно: `v(t) = a·t`. У релятивістській фізиці постійна сила викликає стале **власне прискорення** `a` — прискорення у миттєво супутній інерціальній системі відліку (те, що показує бортовий акселерометр екіпажу, наприклад `a = 9.81` м/с² для імітації стандартного земного тяжіння `1g`).

Нехай `τ` — власний час мандрівника (час на бортовому годиннику корабля), а `t` — час у лабораторній системі відліку Землі. Зв'язок між диференціалом власного часу `dτ` та диференціалом земного часу `dt` описується фактором Лоренца `γ`:

```
dt = γ(v)·dτ = (1 / √(1 - v² / c²))·dτ           [зв'язок земного та власного часу]
```

Другий закон Ньютона у релятивістській формі зв'язує похідну координатного імпульсу `p = m·γ·v` за земним часом `t` з власною силою `F = m·a`:

```
dp / dt = d(m·γ·v) / dt = m·a                     [другий закон Ньютона в СТВ]
```

Інтегруючи це диференціальне рівняння з початковими умовами `t = 0`, `v = 0`, отримуємо вираз для релятивістського імпульсу `γ·v = a·t`. Виразивши звідси координату швидкості `v(t)` у земному часі, маємо:

```
v(t) = a·t / √(1 + (a·t / c)²)                   [координатна швидкість у земному часі]
```

При малих часах `t << c/a` ця формула дає ньютонівський розклад `v(t) ≈ a·t`. Проте при `t → ∞` координатна швидкість асимптотично наближається до швидкості світла `c`, але ніколи не перевищує її, скільки б часу не працювали двигуни.

Інтегруючи співвідношення `dτ = dt / γ(t) = dt / √(1 + (a·t/c)²)` за часом `t`, отримуємо точний вираз для зв'язку часу Землі `t` та власного часу мандрівника `τ`:

```
a·τ / c = arcsinh(a·t / c)                       [зв'язок власного та земного часу]
t(τ) = (c / a)·sinh(a·τ / c)                       [накопичений земний час t(τ)]
```

Переходячи до власного часу мандрівника `τ` за допомогою гіперболічних функцій, отримуємо замкнену аналітичну систему формул для кінематичних параметрів міжзоряного перельоту:

1. **Координатна швидкість у власному часі:**

```
v(τ) = c·tanh(a·τ / c)                            [координатна швидкість v(τ)]
```

2. **Земний час (лабораторний час Землі):**

```
t(τ) = (c / a)·sinh(a·τ / c)                       [накопичений земний час t(τ)]
```

3. **Пройдена відстань у системі відліку Землі:**

```
x(τ) = (c² / a)·(cosh(a·τ / c) - 1)                [пройдена відстань x(τ)]
```

Для чисельних розрахунків при малих значеннях `α = a·τ / c << 1` формула для `x(τ)` через `cosh(α) - 1` може втрачати точність через віднімання близьких чисел у обчисленнях із плаваючою крапкою. Точне тотожне перетворення використовує квадрат синуса половинного аргументу:

```
x(τ) = (2·c² / a)·sinh²(a·τ / (2·c))               [стійка форма для пройденої відстані]
```

4. **Фактор Лоренца:**

```
γ(τ) = cosh(a·τ / c)                               [фактор Лоренца γ(τ)]
```

Ці вирази задають траєкторію у просторі Мінковського — гіперболу `(x + c²/a)² - c²·t² = (c²/a)²`, через що такий рух називається **гіперболічним рухом**.

### Релятивістське рівняння ракети Ціолковського

Для здійснення такого перельоту фотонна ракета має витрачати масу палива. Релятивістська формула Ціолковського для фотонного двигуна (витікання фотонів зі швидкістю `c`) пов'язує початкову масу ракети `m₀` та кінцеву масу `m` з власним часом прискорення `τ`:

```
m₀ / m = exp(a·τ / c)                             [релятивістська формула ракети]
```

Для перельоту з прискоренням `1g` протягом `5` років власного часу коефіцієнт `a·τ / c ≈ 5.16`, тому відношення мас палива до корисної маси становить `m₀ / m = exp(5.16) ≈ 174`. Це означає, що на `1` тонну корисної маси потрібно потратити `173` тонни палива та антипалива (антиматерії) для повної анігіляції.

### Задача 2: Буст чотири-імпульсу частинок

У релятивістській фізиці елементарних частинок стан частинки описується 4-вектором імпульсу `P^μ = (E/c, p_x, p_y, p_z)`, де `E` — повна енергія, а `p` — трьохвимірний імпульс.

При переході до системи відліку `S'`, що рухається зі відносною швидкістю `v` вздовж осі `x`, компоненти 4-імпульсу змінюються згідно з матричним перетворенням Лоренца:

```
E' / c = γ·(E / c - (v / c)·p_x)                   [буст часової компоненти 4-імпульсу]
p_x'   = γ·(p_x - (v / c)·(E / c))                 [буст поздовжнього імпульсу]
p_y'   = p_y                                       [збереження поперечного імпульсу Y]
p_z'   = p_z                                       [збереження поперечного імпульсу Z]
```

Скалярний квадрат 4-імпульсу описує інваріантну масу спокою частинки `m`:

```
m = √((E / c)² - p_x² - p_y² - p_z²) / c           [інваріантна маса частинки]
```

При чисельних розрахунках величина `m` має залишатися строго незмінною в усіх системах відліку, що виступає фундаментальним тестом точності та когерентності обчислень.

## 2. Детальний розбір реалізації мовами C та C++

### Архітектура мови C (стандарт C11)
У версії мовою C використовуються дві базові структури даних: `FlightState` для збереження кінематичних параметрів перельоту та `FourMomentum` для збереження компонентів 4-імпульсу.
- Функція `simulate_flight` приймає власний час мандрівника у роках та прискорення у м/с². Для обчислення гіперболічних функцій застосовуються стандартні функції бібліотеки `<math.h>` (`sinh`, `cosh`, `tanh`).
- Функція `boost_four_momentum` здійснює перевірку вхідних параметрів на некоректні значення (у тому числі надсвітлові швидкості `|v/c| >= 1.0` та нульові вказівники). У разі некоректних даних функція повертає `false`, запобігаючи аварійному завершенню програми.
- Обчислення маси частинки у функції `calculate_invariant_mass` містить перевірку на від'ємне значення підкореневого виразу (що можливе через чисельні округлення плаваючої крапки при дуже великих енергіях) і повертає `0.0` для світлоподібних імпульсів фотонів.

### Архітектура мови C++23
У реалізації C++23 застосовано сучасні стандарти проектування безпечного та виразового коду:
- Інші модулі ізольовано у власному просторі імен `relativity`.
- Фізичні константи визначено через `constexpr double`, що дозволяє проводити обчислення на етапі компіляції.
- Метод `FourMomentum::invariant_mass()` поченачений атрибутами `[[nodiscard]]` та `noexcept`, що гарантує відсутність винятків та сповіщає компілятор про обов'язковість використання результату.
- Функція `RelativisticSimulator::boost` повертає новий стандартний тип `std::expected<FourMomentum, BoostError>`. Це усуває потребу у винятках `throw` та гарантує явну обробку помилок на рівні викликаючого коду через перевірку `if (boosted)`.
- Для форматування виводу у консоль застосовано стандартну бібліотеку `std::format`, що забезпечує високу швидкість форматування та типобезпечність виводу.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

/* Фізичні константи в системі SI */
#define C_SPEED 299792458.0             /* швидкість світла у м/с */
#define SEC_PER_YEAR (365.25 * 86400.0)  /* кількість секунд у тропічному році */
#define G_ACCEL 9.80665                 /* стандартне прискорення вільного падіння м/с² */

/* Структура результатів симуляції космічного перельоту */
typedef struct {
    double proper_time_years;   /* власний час мандрівника τ (роки) */
    double earth_time_years;    /* земний час t (роки) */
    double distance_light_years;/* пройдена відстань x (світлові роки) */
    double velocity_c;          /* відносна швидкість (v/c) */
    double gamma;               /* фактор Лоренца γ */
} FlightState;

/* Структура 4-імпульсу релятивістської частинки (у фізичних одиницях ҐеВ) */
typedef struct {
    double energy_gev;          /* повна енергія E (ҐеВ) */
    double px_gev;              /* поздовжній імпульс p_x (ҐеВ/c) */
    double py_gev;              /* поперечний імпульс p_y (ҐеВ/c) */
    double pz_gev;              /* поперечний імпульс p_z (ҐеВ/c) */
} FourMomentum;

/* 
 * Розрахунок гіперболічного руху зі сталим власним прискоренням.
 * proper_years — власний час екіпажу в роках;
 * accel_m_s2 — власне прискорення корабля в м/с² (за замовчуванням 1g).
 */
FlightState simulate_flight(double proper_years, double accel_m_s2) {
    FlightState state;
    state.proper_time_years = proper_years;

    /* Перехід від років до секунд */
    double tau_sec = proper_years * SEC_PER_YEAR;
    
    /* Безрозмірний аргумент гіперболічних функцій α = a·τ / c */
    double alpha = (accel_m_s2 * tau_sec) / C_SPEED;

    /* Обчислення гіперболічних функцій для розрахунку кінематики */
    double sinh_alpha = sinh(alpha);
    double cosh_alpha = cosh(alpha);
    double tanh_alpha = tanh(alpha);

    /* Розрахунок часу Землі t та пройденої відстані x */
    double t_sec = (C_SPEED / accel_m_s2) * sinh_alpha;
    
    /* Стійка чисельна формула через sinh^2 для збереження точності при малих α */
    double sinh_half = sinh(alpha / 2.0);
    double x_meters = (2.0 * C_SPEED * C_SPEED / accel_m_s2) * (sinh_half * sinh_half);

    /* Заповнення вихідної структури */
    state.earth_time_years = t_sec / SEC_PER_YEAR;
    state.distance_light_years = x_meters / (C_SPEED * SEC_PER_YEAR);
    state.velocity_c = tanh_alpha;
    state.gamma = cosh_alpha;

    return state;
}

/* 
 * Перетворення Лоренца для чотири-імпульсу частинки (буст вздовж осі X).
 * in — початковий 4-імпульс у система S;
 * v_c — швидкість руху системи S' відносно S у одиницях c;
 * out — перетворений 4-імпульс у системі S'.
 */
bool boost_four_momentum(const FourMomentum* in, double v_c, FourMomentum* out) {
    if (in == NULL || out == NULL || fabs(v_c) >= 1.0) {
        return false; /* захист від надсвітлових швидкостей та нульових вказівників */
    }

    double gamma = 1.0 / sqrt(1.0 - v_c * v_c);
    
    /* Матричний лоренцівський буст вздовж осі X */
    out->energy_gev = gamma * (in->energy_gev - v_c * in->px_gev);
    out->px_gev     = gamma * (in->px_gev - v_c * in->energy_gev);
    out->py_gev     = in->py_gev;
    out->pz_gev     = in->pz_gev;

    return true;
}

/* Обчислення інваріантної маси спокою частинки m = √((E/c)² - p²) */
double calculate_invariant_mass(const FourMomentum* p) {
    if (p == NULL) return 0.0;
    
    double p2 = p->px_gev * p->px_gev + p->py_gev * p->py_gev + p->pz_gev * p->pz_gev;
    double m2 = p->energy_gev * p->energy_gev - p2;
    
    return (m2 >= 0.0) ? sqrt(m2) : 0.0;
}

int main(void) {
    printf("=========================================================\n");
    printf("  СИМУЛЯЦІЯ РЕЛЯТИВІСТСЬКОГО ПЕРЕЛЬОТУ ТА БУСТУ (C11)\n");
    printf("=========================================================\n\n");

    /* Симуляція експедиції з прискоренням 1g протягом 5 років власного часу */
    double tau_years = 5.0;
    FlightState res = simulate_flight(tau_years, G_ACCEL);

    printf("--- РЕЗУЛЬТАТИ ПЕРЕЛЬОТУ (Прискорення a = 1g) ---\n");
    printf(" Власний час кораблів (tau) : %.2f років\n", res.proper_time_years);
    printf(" Час на Землі (t)           : %.2f років\n", res.earth_time_years);
    printf(" Пройдена відстань (x)       : %.2f св. років\n", res.distance_light_years);
    printf(" Відносна швидкість (v/c)   : %.8f\n", res.velocity_c);
    printf(" Фактор Лоренца (gamma)      : %.2f\n\n", res.gamma);

    /* Демонстрація перетворення 4-імпульсу протона у системі відліку корабля */
    FourMomentum proton_rest = {0.938272, 0.0, 0.0, 0.0}; /* протон у спокої на Землі */
    FourMomentum proton_boosted;

    if (boost_four_momentum(&proton_rest, res.velocity_c, &proton_boosted)) {
        printf("--- БУСТ ЧОТИРИ-ІМПУЛЬСУ ПРОТОНА У СИСТЕМУ КОРАБЛЯ ---\n");
        printf(" Початкова маса у спокої   : %.6f ГеВ/c²\n", calculate_invariant_mass(&proton_rest));
        printf(" Повна енергія у S'        : %.4f ГеВ\n", proton_boosted.energy_gev);
        printf(" Поздовжній імпульс px'    : %.4f ГеВ/c\n", proton_boosted.px_gev);
        printf(" Кінцева інваріанта маса   : %.6f ГеВ/c² (інваріант збережено)\n", 
               calculate_invariant_mass(&proton_boosted));
    }

    return 0;
}
```

```cpp
#include <iostream>
#include <cmath>
#include <expected>
#include <format>
#include <numbers>

namespace relativity {

/* Фізичні константи C++23 */
constexpr double c_speed = 299792458.0;
constexpr double sec_per_year = 365.25 * 86400.0;
constexpr double g_accel = 9.80665;

/* Результати симуляції кінематики */
struct FlightState {
    double proper_time_years;
    double earth_time_years;
    double distance_light_years;
    double velocity_c;
    double gamma;
};

/* Чотири-імпульс релятивістської частинки */
struct FourMomentum {
    double energy_gev{0.0};
    double px_gev{0.0};
    double py_gev{0.0};
    double pz_gev{0.0};

    [[nodiscard]] constexpr double invariant_mass() const noexcept {
        const double p2 = px_gev * px_gev + py_gev * py_gev + pz_gev * pz_gev;
        const double m2 = energy_gev * energy_gev - p2;
        return m2 >= 0.0 ? std::sqrt(m2) : 0.0;
    }
};

/* Перелік помилок перетворення */
enum class BoostError {
    SuperluminalSpeed,
    InvalidMomentum
};

class RelativisticSimulator {
public:
    /* Розрахунок міжзоряного перельоту зі сталим прискоренням */
    [[nodiscard]] static FlightState simulate_flight(
        double proper_years, double accel_m_s2 = g_accel) noexcept 
    {
        const double tau_sec = proper_years * sec_per_year;
        const double alpha = (accel_m_s2 * tau_sec) / c_speed;

        const double sinh_a = std::sinh(alpha);
        const double cosh_a = std::cosh(alpha);
        const double tanh_a = std::tanh(alpha);

        const double t_sec = (c_speed / accel_m_s2) * sinh_a;
        
        /* Використання sinh^2 для запобігання втраті точності при малих значеннях alpha */
        const double sinh_half = std::sinh(alpha / 2.0);
        const double x_meters = ((2.0 * c_speed * c_speed) / accel_m_s2) * (sinh_half * sinh_half);

        return FlightState{
            .proper_time_years = proper_years,
            .earth_time_years = t_sec / sec_per_year,
            .distance_light_years = x_meters / (c_speed * sec_per_year),
            .velocity_c = tanh_a,
            .gamma = cosh_a
        };
    }

    /* Лоренцівський буст 4-імпульсу з обробкою помилок через std::expected */
    [[nodiscard]] static std::expected<FourMomentum, BoostError> boost(
        const FourMomentum& p, double v_c) noexcept 
    {
        if (std::abs(v_c) >= 1.0) {
            return std::unexpected(BoostError::SuperluminalSpeed);
        }

        const double gamma = 1.0 / std::sqrt(1.0 - v_c * v_c);
        return FourMomentum{
            .energy_gev = gamma * (p.energy_gev - v_c * p.px_gev),
            .px_gev     = gamma * (p.px_gev - v_c * p.energy_gev),
            .py_gev     = p.py_gev,
            .pz_gev     = p.pz_gev
        };
    }
};

} // namespace relativity

int main() {
    using namespace relativity;

    constexpr double tau_years = 5.0;
    const auto flight = RelativisticSimulator::simulate_flight(tau_years);

    std::cout << std::format("=========================================================\n");
    std::cout << std::format("  СИМУЛЯЦІЯ РЕЛЯТИВІСТСЬКОГО РУХУ ТА БУСТУ (C++23)\n");
```

## 3. Аналіз обчислювальних результатів та крайових випадків

Запуск симулятора дозволяє проаналізувати фізичні результати та поведінку чисельного алгоритму на крайових режимах:

### Фізичні результати перельоту
1. **Ефект часової розбіжності (хронодесинхронізація):** Під час польоту з постійним комфортним прискоренням `1g` протягом всього `5` років власного часу на бортовому годиннику екіпажу, на Землі минає **`83.7` років**! Корабель долає відстань у **`82.7` світлових років**, що дозволило б екіпажу дістатися до віддалених зоряних систем у межах одного людського життя.
2. **Асимптотичний поріг швидкості:** За `5` років прискорення координатна швидкість досягає `v / c ≈ 0.999928`. Подальше витрачання палива не призводить до перевищення швидкості світла, а викликає експоненційне зростання фактора Лоренца `γ ≈ 83.7` та повної кінетичної енергії корабля.
3. **Чисельне збереження інваріанта:** При здійсненні бусту Лоренца для протона енергія у рухомій системі зростає з `0.938` ҐеВ до `78.5` ҐеВ, а імпульс — до `78.5` ҐеВ/c. Проте обчислена маса спокою `m = √(E² - p²)` залишається строго рівною `0.938272` ҐеВ/c² з точністю до `15`-ти значущих цифр подвійної точності (`double`), що підтверджує сувору математичну коректність реалізації алгоритму.

### Обчислювальні крайові випадки та стійкість
- **Некласичні ультрарелятивістські швидкості (`γ >> 1`):** При екстремальних значеннях власного часу `τ > 20` років значення `cosh(α)` перевищує межі представлення чисел у форматі IEEE 754 `double` (`1.7e308`), що призводить до переповнення `INF`. Для таких екстремальних розрахунків кінематики застосовується логарифмічне вираження швидкоплинності `α`.
- **Класична границя малих швидкостей (`v << c`):** При `α << 1` формула `v = c·tanh(α) ≈ c·α = a·τ`, а пройдена відстань `x ≈ a·τ² / 2`, що точно відтворює класичні формули Ньютона.
- **Захист від надсвітлових швидкостей (`|v/c| >= 1.0`):** У коді передбачено перевірку вхідного аргументу швидкості. При спробі передати `v/c >= 1.0` алгоритм повертає помилку `BoostError::SuperluminalSpeed` або булевий прапорець `false`, запобігаючи виконанню операції добування квадратного кореня з від'ємного числа при обчисленні `γ = 1 / √(1 - v²/c²)`.
