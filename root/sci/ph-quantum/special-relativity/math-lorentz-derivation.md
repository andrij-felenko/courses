# 🧮 Виведення перетворень Лоренца та геометрія Мінковського

Математичний апарат спеціальної теорії відносності описує симетрії простору-часу та перетворення координат між інерціальними системами відліку. Ця вставка містить суворе аксіоматичне виведення перетворень Лоренца, аналіз їхньої групової структури за допомогою гіперболічних поворотів, алгебру Лі групи Лоренца, виведення томасівської прецесії, визначення 4-векторів і тензора метрики, а також математичне доведення лоренц-інваріантності просторово-часового інтервалу Мінковського.

## 1. Аксіоматичне виведення перетворень Лоренца

Розглянемо дві інерціальні системи відліку `S` та `S'`. Нехай система `S'` рухається відносно `S` зі сталою швидкістю `v` вздовж осі `x`. Осі `y` та `z` систем `S` і `S'` паралельні відповідним осям, а у початковий момент часу `t = t' = 0` початки координат двох систем збігалися: `O = O'`.

### Крок 1: Лінійність перетворень
Вимога **однорідності простору і часу** означає, що жодна точка простору чи момент часу не мають привілейованих властивостей. Зміщення початку відліку не повинно змінювати законів фізики. Звідси випливає, що перетворення координат `(t, x, y, z) ↦ (t', x', y', z')` мають бути лінійними функціями. Якщо б перетворення містили квадратичні чи вищі ступені (наприклад, `x' = a·x²`), то рівномірному руху частинки у системі `S` відповідав би прискорений рух у системі `S'`, що порушувало б інерціальність системи `S'`.

Оскільки рух відбувається лише вздовж осі `x`, з міркувань **ізотропії простору** поперечні координати не змінюють своїх масштабів:

```
y' = y                                           [поперечна координата Y]
z' = z                                           [поперечна координата Z]
```

Для поздовжньої координати `x'` та часу `t'` шукаємо лінійні перетворення вигляду:

```
x' = γ·x + δ·t                                   [лінійна форма для x']
t' = α·t + β·x                                   [лінійна форма для t']
```

де коефіцієнти `γ`, `δ`, `α`, `β` залежать лише від відносної швидкості `v`.

### Крок 2: Рух початку координат
Початок координат системи `S'` (`x' = 0`) у системі `S` рухається за законом `x = v·t`. Підставимо це у рівняння для `x'`:

```
0 = γ·(v·t) + δ·t                                [умова x' = 0 при x = v·t]
δ = -γ·v                                         [зв'язок коефіцієнтів δ та γ]
```

Отже, вираз для `x'` спрощується до:

```
x' = γ·(x - v·t)                                 [вираз для x' через γ]
```

### Крок 3: Застосування постулату сталості швидкості світла
Нехай у момент `t = t' = 0` з спільного початку координат випромінюється світловий імпульс. Згідно з другим постулатом Айнштайна, швидкість поширення світла у вакуумі є однаковою у системі `S` та у системі `S'`.

Рівняння фронту світлової хвилі, що поширюється вздовж осі `x`:
- У системі `S`: `x = c·t`
- У системі `S'`: `x' = c·t'`

Підставимо рівняння руху світлового фронту з системи `S` у вирази для `x'` та `t'`:

```
c·t' = γ·(c·t - v·t) = γ·t·(c - v)               [підстановка x = c·t у x']
t' = α·t + β·c·t = t·(α + β·c)                   [підстановка x = c·t у t']
```

Поділивши перше рівняння на `c`, отримуємо вираз для `t'`:

```
t' = γ·t·(1 - v / c)                             [вираз для t' через γ]
```

Оскільки обидва вирази для `t'` мають бути тотожно рівними для довільного часу `t`, прирівнюємо їхні коефіцієнти:

```
α + β·c = γ·(1 - v / c)                          [рівняння 1 для напрямку +x]
```

Тепер розглянемо світловий імпульс, що поширюється у протилежному напрямку (`x = -c·t` та `x' = -c·t'`):

```
-c·t' = γ·(-c·t - v·t) = -γ·t·(c + v)            [підстановка x = -c·t у x']
t' = α·t - β·c·t = t·(α - β·c)                   [підстановка x = -c·t у t']
```

Поділивши на `-c`, отримуємо друге рівняння для коефіцієнтів:

```
α - β·c = γ·(1 + v / c)                          [рівняння 2 для напрямку -x]
```

Додамо та віднімемо рівняння 1 та рівняння 2:

```
2·α = 2·γ                                        [додавання рівнянь 1 і 2]
α = γ                                            [коефіцієнт часу α]

2·β·c = -2·γ·(v / c)                             [віднімання рівнянь 1 і 2]
β = -γ·v / c²                                    [коефіцієнт змішування β]
```

Підставивши знайдені значення `α` та `β` у вираз для `t'`, отримуємо:

```
t' = γ·(t - v·x / c²)                            [перетворення часу через γ]
```

### Крок 4: Визначення фактора Лоренца γ з принципу відносності
За першим постулатом Айнштайна (принципом відносності), усі інерціальні системи відліку є повністю рівноправними. Це означає, що зворотне перетворення від `S'` до `S` має мати абсолютно тотожну алгебраїчну форму, з єдиною різницею: швидкість `v` змінює знак на `-v` (оскільки система `S` рухається відносно `S'` зі швидкістю `-v`):

```
x = γ·(x' + v·t')                                [зворотне перетворення для x]
```

Підставимо раніше знайдені вирази для `x'` та `t'` у це зворотне перетворення:

```
x
= γ·[γ·(x - v·t) + v·γ·(t - v·x / c²)]           [підстановка x' та t']
= γ²·[(x - v·t) + v·t - v²·x / c²]               [винесення γ за дужки]
= γ²·[x - v²·x / c²]                             [взаємне знищення членів v·t]
= γ²·x·(1 - v² / c²)                             [винесення x за дужки]
```

Оскільки це рівняння має виконуватися для будь-якої координати `x ≠ 0`, маємо тотожність:

```
1 = γ²·(1 - v² / c²)                             [скорочення на x]
γ² = 1 / (1 - v² / c²)                           [ділення на (1 - v²/c²)]
γ = 1 / √(1 - v² / c²)                           [підсумковий фактор Лоренца]
```

Вибір додатного знака кореня `γ > 0` забезпечує співпадіння напрямків осей часу при `v = 0`.

Отже, ми вивели повну пряму та зворотну системи перетворень Лоренца:

```
x' = γ·(x - v·t)
y' = y
z' = z
t' = γ·(t - v·x / c²)                            [прямі перетворення Лоренца]

x = γ·(x' + v·t')
y = y'
z = z'
t = γ·(t' + v·x' / c²)                           [зворотні перетворення Лоренца]
```

## 2. Гіперболічна геометрія та алгебра групи Лоренца SO(1,3)

Перетворення Лоренца мають глибоку геометричну аналогію з поворотами евклідового простору. Якщо звичайний поворот на кут `θ` в евклідовій площині `(x, y)` зберігає суму квадратів `x² + y²` і описується тригонометричними функціями `cos(θ)` та `sin(θ)`, то буст Лоренца зберігає різницю квадратів `c²·t² - x²` і описується гіперболічними функціями.

Введемо безрозмірний параметр **швидкоплинності** (*англ. rapidity*) або кут гіперболічного повороту `ψ`, визначений через відносну швидкість:

```
tanh(ψ) = v / c                                  [визначення швидкоплинності]
```

Використовуючи фундаментальні гіперболічні тотожності:

```
cosh²(ψ) - sinh²(ψ) = 1                          [основна гіперболічна тотожність]
cosh(ψ) = 1 / √(1 - tanh²(ψ)) = 1 / √(1 - v² / c²) = γ  [вираження γ через cosh]
sinh(ψ) = tanh(ψ)·cosh(ψ) = γ·v / c              [вираження sinh через γ]
```

Перетворення Лоренца для часової координати `x⁰ = c·t` та поздовжньої координати `x¹ = x` набувають вигляду чистого гіперболічного повороту:

```
c·t' = c·t·cosh(ψ) - x·sinh(ψ)                    [гіперболічний поворот для часу]
x' = -c·t·sinh(ψ) + x·cosh(ψ)                    [гіперболічний поворот для координати]
```

У матричній формі це записується за допомогою 4-матриці бусту `L(ψ)`:

```
┌ c·t' ┐   ┌  cosh(ψ)  -sinh(ψ)   0   0 ┐ ┌ c·t ┐
│  x'  │   │ -sinh(ψ)   cosh(ψ)   0   0 │ │  x  │
│  y'  │ = │    0          0      1   0 │ │  y  │
└  z'  ┘   └    0          0      0   1 ┘ └  z  ┘
```

### Алгебра Лі групи Лоренца

Група Лоренца `SO(1,3)` містить 6 генераторів: 3 генератори звичайних просторових поворотів `J_i` та 3 генератори релятивістських бустів `K_i` (де `i = 1, 2, 3`).

Комутаційні співвідношення алгебри Лі групи Лоренца мають вигляд:

```
[J_i, J_j] = ε_ijk·J_k                           [комутація просторових поворотів]
[J_i, K_j] = ε_ijk·K_k                           [комутація повороту та бусту]
[K_i, K_j] = -ε_ijk·J_k                          [комутація двох непоколінеарних бустів]
```

Мінусовий знак у комутаторі двох генераторів бусту `[K_i, K_j] = -ε_ijk·J_k` виражає фундаментальну фізичну властивість: **композиція двох бустів у різних напрямках не є чистим бустом, а містить додатковий просторовий поворот**.

### Томасівська прецесія

Неможливість звести два послідовних неколінеарних бусти до одного чистих бусту викликає кінематичне явище — **томасівську прецесію** (*англ. Thomas precession*). Якщо спін частинки чи вісь гіроскопа рухається по криволінійній траєкторії з прискоренням `a` та швидкістю `v`, вісь спіна прецесує у просторі з кутовою швидкістю:

```
Ω_T = (γ² / (γ + 1))·[a × v] / c²                [кутова швидкість томасівської прецесії]
```

Томасівська прецесія є суто кінематичним ефектом СТВ. Вона відіграє вирішальну роль у атомній фізиці, пояснюючи тонку структуру спектральних ліній та спин-орбітальну взаємодію електронів у атомах.

Головна перевага швидкоплинності полягає у її **адитивності** для колінеарних бустів. Послідовне застосування двох бустів Лоренца у тому самому напрямку зі швидкоплинностями `ψ₁` та `ψ₂` відповідає матричному множенню `L(ψ₁)·L(ψ₂) = L(ψ₁ + ψ₂)`.

Сумарна швидкоплинність дорівнює простому добутку:

```
ψ_total = ψ₁ + ψ₂                                [адитивність швидкоплинності]
```

Виразимо підсумкову швидкість `v_total / c = tanh(ψ_total)` через вихідні швидкості:

```
v_total / c
= tanh(ψ₁ + ψ₂)                                  [визначення швидкоплинності для сумарного руху]
= (tanh(ψ₁) + tanh(ψ₂)) / (1 + tanh(ψ₁)·tanh(ψ₂)) [формула додавання аргументів гіперболічного тангенса]
= (v₁ / c + v₂ / c) / (1 + v₁·v₂ / c²)           [підстановка визначення tanh(ψ) = v/c]
```

Помноживши обидві частини на `c`, ми миттєво отримуємо релятивістську формулу додавання швидкостей Айнштайна:

```
v_total = (v₁ + v₂) / (1 + v₁·v₂ / c²)           [формула додавання швидкостей]
```

## 3. 4-вектори та тензорна форма в просторі Мінковського

Для побудови лоренц-інваріантних фізичних законів використовується чотиривимірний формалізм простору Мінковського.

Чотири-вектор положення (подія) задається контраваріантними компонентами `x^μ`:

```
x^μ = (x⁰, x¹, x², x³) = (c·t, x, y, z)          [4-вектор координат]
```

Метричний тензор простору Мінковського у плоских декартових координатах має вигляд:

```
η_μν = diag(-1, +1, +1, +1)                      [метричний тензор Мінковського]
```

Коваріантний вектор `x_μ` отримується опусканням індексу за допомогою метричного тензора `x_μ = η_μν·x^ν = (-c·t, x, y, z)`.

Скалярний добуток двох 4-векторів `A^μ` та `B^μ` визначається як згортка з метричним тензором:

```
A·B = η_μν·A^μ·B^ν = -A⁰·B⁰ + A¹·B¹ + A²·B² + A³·B³  [скалярний добуток 4-векторів]
```

Величина скалярного добутку двох 4-векторів є лоренц-інваріантом — вона приймає однакове значення у всіх інерціальних системах відліку.

### Квадрат інваріантного інтервалу

Квадрат просторово-часового інтервалу `(Δs)²` між двома подіями з координатами `x₁^μ` та `x₂^μ` є квадрат норми 4-вектора різниці координат `Δx^μ = x₂^μ - x₁^μ`:

```
(Δs)²
= η_μν·Δx^μ·Δx^ν
= -c²·(Δt)² + (Δx)² + (Δy)² + (Δz)²             [квадрат інтервалу Мінковського]
```

Доведемо лоренц-інваріантність квадрата інтервалу прямим обчисленням. Підставимо перетворення Лоренца для `Δx'` та `Δt'` у вираз `(Δs')²`:

```
(Δs')²
= -c²·(Δt')² + (Δx')² + (Δy')² + (Δz')²         [інтервал у система S']
= -c²·γ²·(Δt - v·Δx / c²)² + γ²·(Δx - v·Δt)² + Δy² + Δz²  [підстановка перетворень Лоренца]
= γ²·[-c²·(Δt² - 2·v·Δx·Δt / c² + v²·Δx² / c⁴) + (Δx² - 2·v·Δx·Δt + v²·Δt²)] + Δy² + Δz²  [піднесення до квадрата]
= γ²·[-c²·Δt² + 2·v·Δx·Δt - v²·Δx² / c² + Δx² - 2·v·Δx·Δt + v²·Δt²] + Δy² + Δz²  [раскриття дужок]
= γ²·[-c²·Δt²·(1 - v² / c²) + Δx²·(1 - v² / c²)] + Δy² + Δz²  [групування членів]
= γ²·(1 - v² / c²)·[-c²·Δt² + Δx²] + Δy² + Δz²   [винесення (1 - v²/c²)]
```

Оскільки `γ²·(1 - v² / c²) = 1`, перехресні члени повністю скорочуються, і ми отримуємо тотожність:

```
(Δs')² = -c²·(Δt)² + (Δx)² + (Δy)² + (Δz)² = (Δs)²  [доведення інваріантності]
```

Інтервал `(Δs)²` є фундаментальним інваріантом простору-часу.

### Фундаментальні 4-вектори релятивістської фізики

1. **4-швидкість `U^μ`:** Визначена як похідна 4-вектора координат за власним часом `τ`:

```
U^μ = dx^μ / dτ = γ·(c, v_x, v_y, v_z)           [4-вектор швидкості]
```

Квадрат норми 4-швидкості є сталою величиною для будь-якого масивного тіла:

```
U^μ·U_μ = η_μν·U^μ·U^ν = -γ²·c² + γ²·v² = -γ²·c²·(1 - v² / c²) = -c²  [інваріант 4-швидкості]
```

2. **4-прискорення `A^μ`:** Визначено як похідна 4-швидкості за власним часом `τ`:

```
A^μ = dU^μ / dτ = γ·(c·(dγ/dt), d(γ·v)/dt)        [4-вектор прискорення]
```

Оскільки `U^μ·U_μ = -c²`, дифенціювання по `τ` дає скалярну ортогональність 4-швидкості та 4-прискорення: `U^μ·A_μ = 0`.

3. **4-імпульс `P^μ`:** Визначений як добуток маси спокою `m` на 4-швидкість `U^μ`:

```
P^μ = m·U^μ = (E / c, p_x, p_y, p_z)             [4-вектор імпульсу]
```

де `E = γ·m·c²` — повна енергія частинки, а `p = γ·m·v` — трьох-імпульс.

Обчислимо скалярний квадрат 4-імпульсу:

```
P^μ·P_μ = η_μν·P^μ·P^ν = -(E / c)² + p²           [скалярний квадрат 4-імпульсу]
```

З іншого боку, використовуючи `P^μ = m·U^μ`:

```
P^μ·P_μ = m²·(U^μ·U_μ) = -m²·c²                   [інваріант 4-імпульсу через масу]
```

Прирівнюючи обидва вирази, отримуємо релятивістське співвідношення енергії та імпульсу:

```
-(E / c)² + p² = -m²·c²                          [рівність скалярів]
E² / c² - p² = m²·c²                             [множення на -1]
E² - p²·c² = m²·c⁴                               [фундаментальне співвідношення енергії й імпульсу]
```

4. **4-хвильовий вектор `K^μ`:** Описує поширення світлової хвилі:

```
K^μ = (ω / c, k_x, k_y, k_z)                      [4-хвильовий вектор]
```

Для світлової хвилі квадрат норми 4-хвильового вектора дорівнює нулю `K^μ·K_μ = -(ω/c)² + k² = 0`, що означає світлоподібність 4-вектора фотона.

Це доведення показує, що інваріантна маса спокою `m` є довжиною (нормою) 4-вектора імпульсу у просторі Мінковського. Тензорний формалізм Мінковського забезпечує лоренц-інваріантність усіх законів релятивістської фізики.
