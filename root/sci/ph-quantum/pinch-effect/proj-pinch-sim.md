# ⚙️ Чисельне моделювання динаміки Z-пінчу та рівноваги Беннетта

Ця вставка містить детальний фізичний опис, математичне обґрунтування, архітектурний розбір та практичну реалізацію чисельних алгоритмів для моделювання радіальної динаміки Z-пінчу та обчислення самоузгоджених стаціонарних профілів рівноваги Беннетта.

---

### 1. Фізична модель динамічного стискання («снігоочисник» / Snowplow model)

Для опису часової еволюції швидкозмінного Z-пінчу під дією синусоїдального імпульсу струму `I(t) = I₀ · sin(ω · t)` у розрядній камері радіуса `R₀` застосовується макроскопічна модель плазмового поршня (модель «снігоочисника» або *Snowplow model*).

Фізична ідея моделі полягає у тому, що на початковій стадії розряду електричний струм протікає по тонкому поверхневому шару плазмового циліндра (скінування струму). Власне азимутальне магнітне поле `B_φ = (μ₀ · I) / (2 · π · R)` створює магнітний тиск `P_mag = B_φ² / (2 μ₀)` на зовнішній поверхні.

Цей тиск діє як суцільний поршень, який рухається до осі `r = 0` і згрібає перед собою увесь фоновий газ, перетворюючи його на розпечену плазмову оболонку.

Рівняння руху плазмового поршня радіуса `R(t)` з урахуванням маси згребеного газу `M_L(R)` та внутрішнього газокінетичного тиску `p_th(R)` описується другим законом Ньютона у диференціальній формі:

```
(d / dt) [ M_L(R) · (dR / dt) ] = F_mag(R, t) + F_th(R)
```

де:
- `M_L(R) = π · (R₀² - R(t)²) · ρ₀` — погонна маса плазми, згребена поршнем від стінки `R₀` до поточного радіуса `R(t)`, де `ρ₀` — початкова густина газу.
- `F_mag(R, t) = - (μ₀ · I(t)²) / (4 · π · R)` — сумарна магнітна сила стискання, що діє на одиницю довжини циліндра.
- `F_th(R) = 2 · π · R · p_th(R)` — сила внутрішнього газокінетичного протитиску.

Газокінетичний тиск всередині стисненого ядра обчислюється за адіабатичним законом стискання для одноатомного газу (показник адіабати `γ = 5/3`):

```
p_th(R) = p₀ · ( R₀ / R )^( 2 · γ ) = p₀ · ( R₀ / R )^( 10 / 3 )
```

### 2. Енергетичний баланс та випромінювальні втрати

Окрім механічної динаміки, чисельна модель враховує збереження повної енергії плазмового шнура. Загальна енергія складається з кінетичної енергії поршня, внутрішньої теплової енергії та енергії накопиченого магнітного поля:

```
E_total = (1 / 2) · M_L · (dR / dt)² + (3 / 2) · N · k_B · T + ∫ (B_φ² / (2 μ₀)) dV
```

Під час кумулятивного стискання робота магнітного тиску `W_mag = ∫ F_mag dR` частково переходить у кінетичну енергію поршня, а після зупинки на осі — у теплову енергію плазми (ударний нагрів).

При високотемпературній кумуляції необхідно враховувати втрати енергії на гальмівне випромінювання (*Bremsstrahlung*). Потужність об'ємних випромінювальних втрат іонізованої плазми дорівнює:

```
P_rad = C_br · Z_eff² · n_e² · √T_e
```

де `C_br ≈ 1.69 · 10⁻³² Вт · м³ / eV^(1/2)` — константа гальмівного випромінювання, `Z_eff` — ефективний заряд іонів.

Якщо струм розряду перевищує межу Піса-Брагінського (`I_PB ≈ 1.4 MA`), потужність гальмівного випромінювання починає перевищувати джоульову потужність нагріву `P_ohm = j_z² / σ`. У цьому випадку газовий протитиск більше не здатний зупинити стискання, і виникає катастрофічний **радіаційний колапс** (*Radiative collapse*), при якому радіус шнура зменшується до мікронергових розмірів.

### 3. Чисельна схема та умова стійкості Куранта-Фрідріхса-Леві

Для дискретизації диференціального рівняння руху застосовується симплектичний інтегратор Ейлера-Кромра (Symplectic Euler), який зберігає фазовий об'єм і забезпечує високу точність та стабільність розв'язку при наявності нелінійних повертальних сил.

Крок за часом `Δt` повинен задовольняти умову Куранта-Фрідріхса-Леві (CFL), щоб чисельна хвиля розрахунку не випереджала фізичну швидкість поширення альфвенівських та акустичних хвиль у плазмі:

```
Δt < min ( ΔR / v_A, ΔR / v_sound )
```

де `v_A = B_φ / √(μ₀ ρ)` — альфвенівська швидкість, `v_sound = √(γ p / ρ)` — швидкість звуку.

Для запобігання математичній сингулярності рівнянь у точці кумуляції при `R → 0` вводиться пороговий граничний радіус `R_min = 0.005 · R₀`, при досягненні якого здійснюється пружне неідеальне відбиття плазмової оболонки з коефіцієнтом відновлення імпульсу.

### 4. Крайові випадки та обробка сингулярностей

При чисельному інтегруванні МГД-рівнянь виникають три критичних крайових випадки, які вимагають спеціальної алгоритмічної обробки:

1. **Проходження струму через нуль (`I(t) → 0`):** На початку розряду або при зміні напівхвилі синусоїди струм обнуляється. Магнітна сила `F_mag` перетворюється на нуль, і плазмовий поршень рухається виключно за інерцією під дією накопиченого імпульсу та відновлювального газового тиску.
2. **Наближення до осі циліндра (`R → 0`):** У точці `R = 0` вирази для магнітного поля `B_φ ∝ 1/R` та тиску `p_th ∝ 1/R^(10/3)` прямують до безкінечності, викликаючи ділення на нуль та числову нестійкість. Для усунення сингулярності додається регуляризаційний параметр `ε = 1e-12` у знаменник та вводиться фізичний радіус відскоку `R_min`.
3. **Облік вторинного пробою біля стінки:** Після кумуляції первинного Z-пінчу висока індуктивна напруга може викликати вторинний електричний пробій у залишковому газі біля стінки розрядної камери. Для моделювання цього ефекту в алгоритмі відстежується перерозподіл струму між центральним шнуром та пристінковим плазмовим шаром.

### 6. Архітектурний аналіз та практичні результати чисельного моделювання

Аналіз чисельних результатів, отриманих за допомогою розроблених модулів, дозволяє зробити кілька фундаментальних практичних висновків щодо динаміки Z-пінчу:

1. **Нелінійний фазовий характер стискання (Кумулятивний стрибок):** На початковій стадії розряду (перші 0.2–0.4 мкс) радіус шнура зменшується повільно, оскільки струм лише наростає за синусоїдальним законом, а маса згребеного газу `M_L` збільшується. Проте на фінальній стадії при наближенні до осі швидкість поршня стрімко зростає, досягаючи 50–150 км/с.
2. **Індуктивний сплеск напруги:** У момент максимальної кумуляції (`R → R_min`) індуктивність плазмового циліндра `L_p = (μ₀ L / 2π) ln(R₀/R)` отримує логарифмічний приріст. Швидка зміна індуктивності `dL/dt` викликає появу високовольтного індукційного піку на аноді, який може перевищувати початкову напругу конденсаторної батареї у 5–10 разів.
3. **Формування ударної хвилі:** При швидкостях поршня, що перевищують місцеву швидкість звуку у незабуреній плазмі (`v > v_sound`), перед магнітним поршнем відривається радіальна ударна хвиля, яка здійснює первинне ударне іонізаційне та термічне розігрівання іонів перед кумулятивним стисканням.
4. **Простеження діагностичних параметрів:** У розроблених програмах вираховується індуктивна напруга `V_ind = d(L_p I)/dt` та максимальне поверхневе магнітне поле `B_surface`. Це дозволяє порівнювати чисельні осцилограми струму й напруги з реальними експериментальними даними, знятими за допомогою пояса Роговського та індуктивних датчиків.
5. **Порівняння симплектичного Ейлера з методом Рунге-Кутти 4-го порядку (RK4):** Тестові прогони показують, що симплектичний метод Ейлера зберігає повну енергію системи на квазіперіодичних осциляціях після відскоку краще ніж класичний RK4, який має схильність до штучної числової дисипації амплітуди радіальних колівань.
