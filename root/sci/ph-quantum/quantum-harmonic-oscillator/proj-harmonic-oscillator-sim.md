# ⚙️ Чисельне розв'язання рівняння Шредінгера для гармонічного осцилятора

У цій практичній вставці детально розглянуто чисельні алгоритми, їхній математичний аналіз, крайові умови та програмну реалізацію методу кінцевих різниць для обчислення власних значень енергії `E_n` та хвильових функцій `ψ_n(x)` одновимірного квантового гармонічного осцилятора.

## 1. Постановка завдання та знерозмірення диференціального рівняння

Стаціонарне рівняння Шредінгера для частинки маси `m`, яка рухається у параболічному потенціальному полі `V(x) = (1/2) m ω² x²`, є диференціальним рівнянням другого порядку у частинних похідних:

```
- (ℏ² / (2m)) · (d²ψ / dx²) + (1/2) · m · ω² · x² · ψ(x) = E · ψ(x)
```

При проведенні чисельного моделювання на комп'ютері робота з фізичними величинами у системах SI (маса електрона `m_e ≈ 9.11 × 10⁻³¹ kg`, стала Планка `ℏ ≈ 1.055 × 10⁻³⁴ J·s`, енергії `10⁻¹⁹ J`) є вкрай небажаною через швидке накопичення похибок округлення плаваючої коми. 

Для розв'язання цієї проблеми проведем повне знерозмірення рівняння. Введемо характерні масштабні одиниці квантового осцилятора:
- **Характерний масштаб довжини (амплітуда нульових коливань)**: `x_0 = √(ℏ / (m · ω))`
- **Характерний масштаб енергії (квант коливань)**: `E_0 = ℏ · ω`

Ввівши безрозмірну координату `ξ = x / x_0` та безрозмірне власне значення енергії `ε = E / (ℏ ω)`, рівняння Шредінгера набуває універсального безрозмірного вигляду:

```
- (1/2) · (d²ψ / dξ²) + (1/2) · ξ² · ψ(ξ) = ε · ψ(ξ)
```

Математичне завдання полягає у знаходженні таких власних значень `ε`, при яких існує нетривіальний розв'язок `ψ(ξ)`, що задовольняє крайові умови згасання на нескінченності: `ψ(ξ) → 0` при `|ξ| → ∞`.

## 2. Дискретизація просторової сітки та матриця Гамільтоніана

Оскільки комп'ютер оперує скінченними масивами, обмежимо нескінченну просторову область `(-∞, +∞)` скінченним інтервалом `ξ ∈ [-L, +L]`. Значення `L` обирається з фізичної умови, щоб хвильова функція досліджуваних станів уже експоненційно згасала до нуля на межах: `ψ(±L) ≈ 0`. Для перших 10 енергетичних рівнів достатньо обрати `L = 5.0` або `L = 6.0`, адже поворотна точка для `n = 4` становить `ξ_4 = √(2 · 4 + 1) = 3.0`.

Розіб'ємо інтервал `[-L, +L]` на `N` рівновіддалених вузлів із кроком дискретизації `h`:

```
h = 2 L / (N - 1)
ξ_i = -L + i · h,    i = 0, 1, 2, ..., N-1
```

Застосуємо симетричний триточковий шаблон для апроксимації другої похідної:

```
(d²ψ / dξ²)|_(ξ_i) = (ψ_(i+1) - 2 ψ_i + ψ_(i-1)) / h² + O(h²)
```

Підставивши цю скінченно-різницеву апроксимацію у безрозмірне рівняння Шредінгера, отримуємо дискретне рівняння для кожного внутрішнього вузла `i`:

```
- (1 / (2 h²)) · (ψ_(i+1) - 2 ψ_i + ψ_(i-1)) + (1/2) · ξ_i² · ψ_i = ε · ψ_i
```

Перегрупувавши доданки при `ψ_(i-1)`, `ψ_i` та `ψ_(i+1)`, сформуємо систему лінійних алгебраїчних рівнянь:

```
- (1 / (2 h²)) · ψ_(i-1) + [ (1 / h²) + (1/2) · ξ_i² ] · ψ_i - (1 / (2 h²)) · ψ_(i+1) = ε · ψ_i
```

Ця система еквівалентна задачі на власні значення симетричної тридіагональної матриці Гамільтоніана `H · ψ = ε · ψ`, де:
- **Діагональні елементи `H_ii`**: `H_ii = (1 / h²) + (1/2) · ξ_i²`
- **Позадіагональні елементи `H_(i, i+1) = H_(i+1, i)`**: `H_(i, i+1) = - 1 / (2 h²)`

## 3. Математичні алгоритми: послідовності Штурма та метод Нумерова

Для знаходження власних значень симетричної тридіагональної матриці можна використовувати два основні підходи:

1. **Метод бісекції на основі послідовностей поліномів Штурма**:
   Характеристичний поліном тридіагональної матриці `P_n(λ) = det(H - λ I)` задовольняє рекурентне співвідношення:
   ```
   P_0(λ) = 1
   P_1(λ) = H_11 - λ
   P_i(λ) = (H_ii - λ) · P_(i-1)(λ) - H_(i, i-1)² · P_(i-2)(λ)
   ```
   Згідно з теоремою Штурма, кількість змін знаку в послідовності поліномів `{P_0(λ), P_1(λ), ..., P_N(λ)}` для заданого значення `λ` строго дорівнює кількості власних значень матриці `H`, які є меншими за `λ`. Це дозволяє методом бісекції (ділення навпіл) шукати будь-яке `k`-те власне значення з наперед заданою точністю `10⁻¹⁴` за 50–60 ітерацій.

2. **Порівняння з методом Нумерова (O(h⁴))**:
   Стандартний триточковий шаблон дає похибку `O(h²)`. Для досягнення вищої точності використовується спеціалізований метод Нумерова для рівнянь вигляду `y'' = f(x) y`. Метод Нумерова враховує четверту похідну і дає похибку `O(h⁴)`:
   ```
   (1 - (h²/12) g_(i+1)) ψ_(i+1) - 2 (1 + (5h²/12) g_i) ψ_i + (1 - (h²/12) g_(i-1)) ψ_(i-1) = 0
   ```
   де `g_i = 2 ε - ξ_i²`. Проте класичний скінченно-різницевий тридіагональний Гамільтоніан є значно простішим у реалізації та дозволяє одразу знаходити всі власні вектори матричними методами.

## 5. Аналіз обчислювальної складності та крайових пасток

Аналіз обчислювальної ефективності та практичних пасток демонструє важливі інженерні риси чисельних розв'язувачів квантовомеханічних задач:

### Обчислювальна складність
1. **Затрати пам'яті (Memory Space)**:
   Оскільки зберігаються лише три діагоналі тридіагональної матриці, складність по пам'яті є строго лінійною `O(N)`. Для `N = 1000` вузлів три масиви типу double займають менше 24 кілобайт оперативної пам'яті, що дозволяє виконувати розрахунки на будь-якому мікроконтролері або мобільному пристрої.
2. **Часова складність (Execution Time)**:
   Обчислення послідовності Штурма для одного значення `λ` вимагає `N` операцій. Бісекційний метод з 60 ітераціями для кожного з `k` власних значень виконується за `O(k · N)` операцій. Для 5 станів це становить близько 300 000 елементарних операцій, що займає менше 0.5 мілісекунди процесорного часу.

### Інженерні пастки та крайові випадки при моделюванні:
- **Штучна обмеженість потенціалу (Boundary truncation effect)**: Якщо обрати занадто мале значення `L = 2.0`, для стану `n = 4` класична поворотна точка `ξ_4 = √9 = 3.0` опиниться поза межами обчислювальної сітки. Хвильова функція штучно стиснеться у нуль у точці `ξ = 2.0`, а обчислене власне значення енергії буде завищеним на 15-20%. Рекомендується обирати `L > √(2 n_max + 5)`.
- **Ділення на нуль при розрахунку послідовності Штурма**: У рекурентному виразі `p_i = d_i - λ - e_(i-1)² / p_(i-1)` випадкове збігання `p_(i-1) = 0` приводить до ділення на нуль. У наведеному коді C та C++ це захищено регуляризацією `(std::abs(p) < 1e-14) ? 1e-14 : p`.
- **Падіння точності для високозбуджених станів**: Зі зростанням квантового числа `n` де Бройлівська довжина хвилі `λ_n` зменшується. Якщо на один період хвильової функції припадає менше 10 вузлів сітки, похибка обчислення енергії починає зростати. Для моделювання вищих станів слід масштабувати кількість вузлів `N` пропорційно `√n`.
- **Перевід у фізичні одиниці SI**: Для отримання реальної фізичної енергії у Джоулях або електрон-вольтах обчислене безрозмірне власне значення `ε_n` необхідно помножити на `ℏ ω`: `E_n = ε_n · ℏ ω`. Для молекули `HCl` з циклічною частотою коливань `ω ≈ 5.65 × 10¹⁴ rad/s` квант енергії становить `ℏ ω ≈ 0.37 eV`.
