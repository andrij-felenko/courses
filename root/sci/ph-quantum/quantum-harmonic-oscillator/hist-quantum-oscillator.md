# 📜 Історія розвитку концепції квантового гармонічного осцилятора

Квантовий гармонічний осцилятор пройшов шлях від формальної математичної гіпотези до фундаменту сучасної квантової теорії поля, квантової оптики та фізики твердого тіла. Історія цього поняття відображає трансформацію у всій квантовій фізиці: від відчайдушної спроби уникнути «ультрафіолетової катастрофи» до відкриття квантових флуктуацій вакууму та створення теорії лазерного випромінювання.

## 1. Макс Планк і народження кванту енергії (1900)

Наприкінці XIX століття класична фізика зіткнулася з розрухою в теорії теплового випромінювання абсолютно чорного тіла. Формула Релея — Джинса, виведена з класичної термодинаміки та теореми про рівномірний розподіл енергії за ступенями вільності (equipartition theorem), передбачала, що середня кінетична та потенціальна енергія кожного класичного осцилятора з частотою `ω` дорівнює `k_B · T`. Це вело до неминучого висновку: спектральна густина енергії випромінювання мала зростати пропорційно квадрату частоти `ω²` аж до нескінченності:

```
u(ω, T) = (ω² / (π² · c³)) · k_B · T
```

Цей результат означав, що будь-яке нагріте тіло мусило б миттєво випромінити всю свою енергію у високочастотному спектрі (ультрафіолетовому, рентгенівському та гамма-діапазонах). Пол Еренфест згодом охрестив цю суперечність «ультрафіолетовою катастрофою».

14 грудня 1900 року на засіданні Німецького фізичного товариства Макс Планк виголосив доповідь, у якій запропонував радикальний вихід. Він розглянув стінки випромінюючої порожнини як набір атомних гармонічних осциляторів. Планк припустив, що осцилятор з власною частотою `ν` не може поглинати чи випромінювати енергію неперервно, а здійснює це лише дискретними порціями — квантами:

```
ΔE = h · ν = ℏ · ω
```

де `h` — стала Планка (`6.626 × 10⁻³⁴ J·s`), а `ℏ = h / (2π)`. Завдяки цьому припущенню середня енергія осцилятора визначалася не рівномірним розподілом `k_B · T`, а статистичним розподілом Больцмана за дискретними рівнями енергії:

```
⟨E⟩ = (ℏ · ω) / (exp(ℏ · ω / (k_B · T)) - 1)
```

При високих температурах (`k_B · T >> ℏ · ω`) цей вираз переходив у класичний `k_B · T`, але при високих частотах (`ℏ · ω >> k_B · T`) середня енергія експоненційно прямувала до нуля. Це повністю усунуло ультрафіолетову катастрофу й бездоганно узгодилося з експериментальними вимірюваннями Рубенса та Кульбаума.

Проте сам Планк тривалий час вважав квантування лише формальним математичним трюком, застосовним виключно до процесу випромінювання та поглинання світла матерією.

## 2. Альберт Ейнштейн і теплоємність кристалів (1907)

У 1907 році Альберт Ейнштейн зробив наступний вирішальний крок, поширивши гіпотезу Планка з електромагнітного поля на механічний рух атомів у твердому тілі.

Класичний закон Дюлонга — Пті стверджував, що молярна теплоємність усіх простих кристалічних тіл за постійного об'єму є постійною величиною `C_v = 3 · R` (де `R` — універсальна газова стала). Проте експерименти при низьких температурах показували стрімке падіння теплоємності алмазу, кремнію та металів майж до нуля при наближенні до `T → 0 K`.

Ейнштейн запропонував модель, у якій кристал складався з `N` однакових атомів, кожен з яких незалежно коливався навколо вузла кристалічної ґратки вздовж трьох осей як квантовий гармонічний осцилятор із частотою `ω_E`. Застосувавши формулу Планка для середньої енергії, Ейнштейн отримав вираз для теплоємності:

```
C_v = 3 · R · (T_E / T)² · (exp(T_E / T) / (exp(T_E / T) - 1)²)
```

де `T_E = ℏ · ω_E / k_B` — характеристична температура Ейнштейна. Модель Ейнштейна вперше пояснила, чому при низьких температурах теплові коливання ґратки «виморажуються»: енергії теплового руху `k_B · T` просто недостатньо для збудження першого квантового рівня `ℏ · ω_E`. Це переконливо довело, що квантування енергії гармонічного осцилятора є фундаментальним законом механіки атомного світу, а не специфічною властивістю випромінювання.

## 3. Вальтер Нернст, Пітер Дебай та гіпотеза нульової енергії (1911–1913)

У 1911–1912 роках фізики Вальтер Нернст та Арнольд Зоммерфельд активно обговорювали наслідки третього начала термодинаміки (теореми Нернста). Якщо при `T = 0 K` абсолютна температура дорівнює нулю, чи зупиняється всякий рух атомів повністю?

У 1913 році Альберт Ейнштейн та Отто Штерн опублікували працю, у якій провели аналіз ротаційного руху молекул водню та дійшли висновку, що для узгодження з термодинамічними даними спектр гармонічного осцилятора повинен містити додатковий сталий член:

```
E_n = ℏ · ω · n + (1/2) · ℏ · ω
```

Термін `(1/2) · ℏ · ω` отримав назву «нульова енергія» (нім. *Nullpunktsenergie*). Він означав, що навіть при абсолютному нулю температур, коли `n = 0`, осцилятор не перебуває у стані спокою, а зберігає залишок енергії коливань.

Хоча у 1913 році цей додатковий доданок ще здавався багатьом фізикам суперечливим гіпотетичним припущенням, подальший розвиток квантової механіки довів його неминучість.

## 4. Матрична механіка Гейзенберга та хвильове рівняння Шредінгера (1925–1926)

Справжнє теоретичне обґрунтування квантового гармонічного осцилятора відбулося під час квантової революції 1925–1926 років.

У літку 1925 року Вернер Гейзенберг, відновлюючи здоров'я на острові Гельголанд, створив матричну механіку. Замість класичних координати `x(t)` та імпульсу `p(t)` він представив фізичні величини як нескінченні матриці `X` та `P`. Гейзенберг застосував свій фундаментальний комутаційний співвідношення:

```
X · P - P · X = i · ℏ · I
```

до гамільтоніана гармонічного осцилятора `H = P² / (2m) + (1/2) m ω² X²`. Діагоналізація матриці гамільтоніана дала точний спектр власних значень:

```
E_n = ℏ · ω · (n + 1/2),    n = 0, 1, 2, ...
```

Це було перше строге виведення квантового спектра осцилятора та нульової енергії без використання додаткових штучних припущень.

На початку 1926 року Ервін Шредінгер опублікував свою знамениту серію статей про хвильову механіку. Розв'язуючи стаціонарне рівняння Шредінгера для параболічного потенціалу `V(x) = (1/2) m ω² x²`, він знайшов неперервні, обмежені та однозначні хвильові функції `ψ_n(x)`. Вимоги належної поведінки хвильової функції на нескінченності (`ψ(x) → 0` при `|x| → ∞`) приводять до диференціального рівняння для поліномів Ерміта `H_n(ξ)` та дають точно ті самі дискретні значення енергії `E_n`, що й матрична механіка Гейзенберга. Шредінгер довів математичну еквівалентність обох підходів.

## 5. Оператори Дірака та вторинне квантування (1928–1930)

У 1928–1930 роках Поль Дірак розробив абстрактну операторну формулювання квантової механіки у векторному просторі Гільберта. Він ввів безрозмірні оператори знищення `a` та народження `a†` (ladder operators):

```
a = √(m ω / (2 ℏ)) · (x + i · p / (m ω))
a† = √(m ω / (2 ℏ)) · (x - i · p / (m ω))
```

з комутатором `[a, a†] = 1`. Алгебра операторів Дірака виявилася надзвичайно елегантною: вона дозволила знаходити спектр та матричні елементи осцилятора чисто алгебраїчно, взагалі не розв'язуючи диференціальних рівнянь.

Поняття операторів народження та знищення стало містком до створення квантової теорії поля (вторинного квантування). У 1930-х роках Володимир Фок, Вернер Гейзенберг та Вольфганг Паулі показали, що вільне квантове електромагнітне поле або поле елементарних частинок можна представити як нескінченний набір незалежних квантових гармонічних осциляторів, де кожне збудження осцилятора `n` відповідає наявності `n` фотонів чи фононів із даним імпульсом та поляризацією.

## 6. Когерентні стани Глаубера та сучасна квантова оптика (1963)

У 1963 році Рой Глаубер переосмислив квантовий осцилятор у контексті квантової оптики та фізики лазерів. Він ввів клас квантових станів, які є власними станами оператора знищення:

```
a |α⟩ = α |α⟩
```

Ці стани отримали назву «когерентні стани Глаубера». Хвильовий пакет когерентного стану описується Гауссовим розподілом з мінімально можливим співвідношенням невизначеностей `Δx · Δp = ℏ / 2`. Найдивовижнішою властивістю когерентного стану є те, що під дією гамільтоніана осцилятора гауссів хвильовий пакет здійснює коливання у параболічному потенціалі вздовж класичної траєкторії, **взагалі не змінюючи своєї форми та не розпливаючись у часі**.

За фундаментальний внесок у квантову теорію оптичної когерентності Рой Глаубер у 2005 році був удостоєний Нобелівської премії з фізики.

Сьогодні квантовий гармонічний осцилятор залишається головною модельною системою для квантових обчислень (кубіти на надпровідних LC-контурах), іонних пасток, квантової оптоелектромеханіки та аналізу ефекту Казимира.
