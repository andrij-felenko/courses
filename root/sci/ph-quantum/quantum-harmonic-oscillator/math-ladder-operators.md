# 🧮 Виведення спектра та власних станів осцилятора алгебраїчним методом

Ця математична вставка містить строге та вичерпне виведення енергетичного спектра, операторних співвідношень, матричних елементів та явного вигляду хвильових функцій одновимірного квантового гармонічного осцилятора. Замість традиційного розв'язання диференціального рівняння Шредінгера у частинних похідних через степеневі ряди, тут застосовано алгебраїчний метод підвищувальних та понижувальних операторів (операторів драбини), розроблений Полем Діраком.

Алгебраїчний метод володіє високою математичною витонченістю: він дозволяє обчислити власні значення енергії, нормуючі множники та матричні елементи будь-яких фізичних величин суто з комутаційних співвідношень між операторами координати та імпульсу, взагалі не інтегруючи диференціальні рівняння.

## 1. Канонічні оператори та знерозмірення

Розглянемо частинку маси `m`, яка здійснює одновимірні коливання у параболічному потенціальному полі `V(x) = (1/2) m ω² x²` з власною циклічною частотою `ω`. Оператор повної енергії (Гамільтоніан системи) у координатному представленні записується як:

```
H = p² / (2m) + (1/2) · m · ω² · x²
```

де `x` — оператор координати (оператор множення на `x`), а `p = -i ℏ (d/dx)` — оператор імпульсу. Ці фундаментальні квантові оператори задовольняють канонічне комутаційне співвідношення Гейзенберга:

```
[x, p] = x · p - p · x = i · ℏ
```

Некомутативність координати та імпульсу означає, що квантовий стан не може одночасно мати точно визначені значення обох величин.

Для звільнення від розмірних параметрів маси `m`, частоти `ω` та сталої Планка `ℏ`, введемо природний квантовий масштаб довжини `x_0` та характерний масштаб імпульсу `p_0`:

```
x_0 = √(ℏ / (m · ω))
p_0 = √(m · ℏ · ω)
```

Масштаб `x_0` описує просторовий розмір нульових коливань квантового осцилятора в основному стані, а `p_0` відповідає середньоквадратичному квантовому імпульсу цього стану. Звернемо увагу, що добуток цих масштабів дорівнює сталій Планка: `x_0 · p_0 = ℏ`.

Введемо безрозмірні лінійні комбінації операторів координати та імпульсу — **оператор знищення** `a` та **оператор народження** `a†` (приєднаний до `a` Ермітово):

```
a = (1 / √2) · (x / x_0 + i · p / p_0) = (1 / √(2 m ℏ ω)) · (m ω x + i p)
a† = (1 / √2) · (x / x_0 - i · p / p_0) = (1 / √(2 m ℏ ω)) · (m ω x - i p)
```

Оскільки оператор координати `x` та оператор імпульсу `p` є самоспряженими (Ермітовими) операторами (`x† = x`, `p† = p`), оператори `a` та `a†` є сопряженими один до одного, але самі не є Ермітовими (`a† ≠ a`). Отже, вони не відповідають безпосередньо вимірюваним фізичним величинам, а виступають у ролі допоміжних алгебраїчних операторів ступенів збудження.

Знайдемо комутаційне співвідношення між операторами `a` та `a†`:

```
[a, a†]
= a · a† - a† · a                                                                                     [означення комутатора]
= (1/2) · (x / x_0 + i p / p_0) · (x / x_0 - i p / p_0) - (1/2) · (x / x_0 - i p / p_0) · (x / x_0 + i p / p_0) [підстановка a та a†]
= (1/2) · [ (x² / x_0² + p² / p_0² - (i / (x_0 p_0)) (x p - p x)) - (x² / x_0² + p² / p_0² + (i / (x_0 p_0)) (x p - p x)) ] [розкриття дужок]
= (1/2) · [ - (2 i / (x_0 p_0)) · (x p - p x) ]                                                      [скорочення імпульсних квадратів]
= - (i / (x_0 p_0)) · (i ℏ)                                                                           [підстановка комутатора [x, p] = i ℏ]
= ℏ / (x_0 p_0)                                                                                       [спрощення: i² = -1]
= ℏ / (√(ℏ / (m ω)) · √(m ℏ ω))                                                                      [підстановка масштабів x_0 та p_0]
= ℏ / ℏ                                                                                               [обчислення добутку знаменників]
= 1                                                                                                   [кінцевий результат: [a, a†] = 1]
```

Отримане співвідношення `[a, a†] = 1` є фундаментальною бозонною алгеброю комутаторів. Вона показує, що оператори `a` та `a†` поводяться як оператори знищення та народження для квантових бозонних частинок або квазічастинок (фотонів, фононів, магнонів).

## 2. Представлення Гамільтоніана через оператор числа частинок

Обчислимо добуток операторів `a† a`:

```
a† a
= (1/2) · (x / x_0 - i p / p_0) · (x / x_0 + i p / p_0)                                               [підстановка операторів]
= (1/2) · (x² / x_0² + p² / p_0² + (i / (x_0 p_0)) (x p - p x))                                        [розкриття добутку]
= (1/2) · (m ω x² / ℏ + p² / (m ℏ ω) - 1)                                                             [підстановка x_0, p_0 та [x, p] = i ℏ]
= (1 / (ℏ ω)) · [ p² / (2m) + (1/2) m ω² x² ] - 1/2                                                   [винесення 1/(ℏ ω)]
= H / (ℏ ω) - 1/2                                                                                     [вираження через Гамільтоніан H]
```

Виразимо Гамільтоніан `H` через добуток `a† a`:

```
H = ℏ · ω · (a† a + 1/2)
```

Введемо важливий безрозмірний оператор `N`:

```
N = a† a
```

Оператор `N` є Ермітовим (`N† = (a† a)† = a† (a†)† = a† a = N`), отже його власні значення є дійсними числами. Вказаний оператор називається **оператором числа збуджень** (або оператором числа частинок/квантів).

Завдяки цьому Гамільтоніан `H` і оператор `N` є пропорційними з точністю до зсуву на константу: `H = ℏ ω (N + 1/2)`. Це означає, що оператори `H` та `N` мають спільну систему власних векторів. Задача про визначення власних значень Гамільтоніана зводиться до знаходження власних значень оператора `N`.

## 3. Комутаційна алгебра та перетворення власних станів

Знайдемо комутатори Гамільтоніана `H` та оператора `N` з підвищувальним та понижувальним операторами.

Для оператора знищення `a`:

```
[N, a] = [a† a, a] = a† a a - a a† a = (a† a - a a†) a = - [a, a†] a = -1 · a = -a
```

Звідси для Гамільтоніана `H`:

```
[H, a]
= [ℏ ω (a† a + 1/2), a]            [підстановка H через a† a]
= ℏ ω · [a† a, a]                   [винесення константи та сталого доданку]
= ℏ ω · (a† a a - a a† a)           [за визначенням комутатора]
= ℏ ω · [a†, a] · a                 [групування за комутатором [a†, a]]
= ℏ ω · (-1) · a                    [використання [a†, a] = -[a, a†] = -1]
= - ℏ · ω · a                       [остаточний вираз]
```

Для оператора народження `a†`:

```
[N, a†] = [a† a, a†] = a† a a† - a† a† a = a† (a a† - a† a) = a† [a, a†] = a† · 1 = +a†
```

Звідси для Гамільтоніана `H`:

```
[H, a†]
= [ℏ ω (a† a + 1/2), a†]           [підстановка H через a† a]
= ℏ ω · [a† a, a†]                  [винесення константи]
= ℏ ω · a† · [a, a†]                [використання тотожності комутаторів]
= + ℏ · ω · a†                      [використання [a, a†] = 1]
```

Нехай `|E⟩` — власний вектор Гамільтоніана `H`, що відповідає власному значенню енергії `E`: `H |E⟩ = E |E⟩`.

Проаналізуємо дію оператора `H` на вектор `a† |E⟩`:

```
H (a† |E⟩)
= (a† H + [H, a†]) |E⟩              [перестановка операторів через комутатор]
= (a† E + ℏ ω a†) |E⟩               [підстановка H|E⟩ = E|E⟩ та [H, a†] = ℏω a†]
= (E + ℏ ω) · (a† |E⟩)              [винесення спільного вектора a†|E⟩]
```

Ця рівність доводить, що вектор `a† |E⟩` також є власним вектором Гамільтоніана `H`, але його власне значення енергії на один квант `ℏω` більше: `E' = E + ℏω`. Саме тому оператор `a†` називають **оператором народження** (або підвищувальним оператором).

Аналогічно дослідиємо дію Гамільтоніана `H` на вектор `a |E⟩`:

```
H (a |E⟩)
= (a H + [H, a]) |E⟩                [перестановка операторів через комутатор]
= (a E - ℏ ω a) |E⟩                 [підстановка H|E⟩ = E|E⟩ та [H, a] = -ℏω a]
= (E - ℏ ω) · (a |E⟩)               [винесення спільного вектора a|E⟩]
```

Це означає, що вектор `a |E⟩` є власним вектором Гамільтоніана `H` з енергією, зменшеною на один квант `ℏω`: `E'' = E - ℏω`. Саме тому оператор `a` називають **оператором знищення** (або понижувальним оператором).

## 4. Обмеженість спектра знизу та дискретизація енергетичних рівнів

Якщо послідовно застосовувати оператор знищення `a` до вектора стану `|E⟩`, ми отримуємо нові стани з енергіями `E - ℏω`, `E - 2ℏω`, `E - 3ℏω`, і так далі. 

Чи може цей процес зниження енергії тривати нескінченно?

Розглянемо квадрат норми вектора `a |E⟩`. Для будь-якого фізично реалізованого вектора стану в Гільбертовому просторі квадрат норми виражається як скалярний добуток і мусить бути невід'ємною величиною:

```
||a |E⟩||² = ⟨E| a† a |E⟩ = ⟨E| N |E⟩ ≥ 0
```

Якщо `|E⟩` є власним вектором оператора `N` із власним значенням `n` (`N |E⟩ = n |E⟩`), то:

```
⟨E| N |E⟩ = n · ⟨E|E⟩ = n ≥ 0
```

Отже, всі власні значення `n` оператора числа частинок `N` є строго невід'ємними дійсними числами: `n ≥ 0`.

Це вимагає існування у гільбертовому просторі станів найнижчого стану — **основного (вакуумного) стану** `|0⟩`, при дії оператора знищення на який отримується нуль-вектор:

```
a |0⟩ = 0
```

Знайдемо власне значення енергії основного стану `E_0`:

```
H |0⟩
= ℏ ω (a† a + 1/2) |0⟩              [підстановка H через a† a]
= ℏ ω (a† (a |0⟩) + (1/2) |0⟩)       [розкриття дужок і дія на вакуум]
= ℏ ω (0 + (1/2) |0⟩)               [застосування умови вакууму a|0⟩ = 0]
= (1/2) · ℏ · ω · |0⟩               [спрощення виразу]
```

Отже, енергія основного стану квантового осцилятора строго дорівнює:

```
E_0 = (1/2) · ℏ · ω
```

Послідовно діючи підвищувальним оператором `a†` на основний стан `|0⟩`, будуємо весь дискретний спектр збуджених станів:

```
|1⟩ = C_1 · a† |0⟩,      E_1 = (3/2) ℏ ω
|2⟩ = C_2 · (a†)² |0⟩,   E_2 = (5/2) ℏ ω
...
|n⟩ = C_n · (a†)ⁿ |0⟩,   E_n = ℏ ω (n + 1/2),    n = 0, 1, 2, 3, ...
```

Обчислимо нормуючі коефіцієнти `C_n` з умови нормування `⟨n|n⟩ = 1`. 

Знайдемо матричний елемент `⟨n| a a† |n⟩`:

```
⟨n| a a† |n⟩ = ⟨n| (a† a + 1) |n⟩ = ⟨n| (N + 1) |n⟩ = (n + 1) · ⟨n|n⟩ = n + 1
```

Оскільки `a† |n⟩ = A_n |n+1⟩`, то квадрат норми вектора `a† |n⟩` дорівнює:

```
||a† |n⟩||² = |A_n|² · ⟨n+1|n+1⟩ = |A_n|² = n + 1  ⇒  A_n = √(n + 1)
```

Отже, дія операторів народження та знищення на нормовані стани `|n⟩` визначається точними матричними співвідношеннями:

```
a† |n⟩ = √(n + 1) |n + 1⟩
a |n⟩ = √n |n - 1⟩
```

Звідси нормалізований власний стан `|n⟩` через дію оператора `a†` на вакуум `|0⟩` виражається формулою:

```
|n⟩ = (1 / √(n!)) · (a†)ⁿ |0⟩
```

## 5. Перехід до координатного представлення та поліноми Ерміта

Перейдемо від абстрактних кет-векторів `|n⟩` до просторових хвильових функцій у координатному представленні `ψ_n(x) = ⟨x|n⟩`.

Запишемо умову основного стану `a |0⟩ = 0` у координатному представленні, виразивши `a` через `x` та `d/dx`:

```
(1 / √2) · (x / x_0 + i p / p_0) ψ_0(x) = 0    [визначення a|0⟩ = 0 у координатному представленні]
(x / x_0 + (ℏ / (m ω)) · (d / dx)) ψ_0(x) = 0   [підстановка оператора p = -i ℏ d/dx]
(x / x_0 + x_0 · (d / dx)) ψ_0(x) = 0           [підстановка x_0² = ℏ / (m ω)]
```

Отримуємо диференціальне рівняння першого порядку з відокремлюваними змінними:

```
(dψ_0 / dx) = - (x / x_0²) · ψ_0(x)
```

Інтегруючи це рівняння:

```
∫ (dψ_0 / ψ_0) = - ∫ (x / x_0²) dx  ⇒  ln(ψ_0) = - x² / (2 x_0²) + C
```

Отримуємо Гауссів купол для хвильової функції основного стану:

```
ψ_0(x) = A_0 · exp(- x² / (2 x_0²))
```

Нормуюча константа `A_0` визначається з умови інтеграла ймовірності `∫_{-∞}^{+∞} |ψ_0(x)|² dx = 1`:

```
|A_0|² · ∫_{-∞}^{+∞} exp(- x² / x_0²) dx = |A_0|² · x_0 · √π = 1  ⇒  A_0 = (1 / (π · x_0²))^(1/4)
```

Для обчислення хвильових функцій збуджених станів `ψ_n(x)` застосуємо вираз для `|n⟩ = (1 / √(n!)) (a†)ⁿ |0⟩` у координатному представленні:

```
ψ_n(x) = (1 / √(2ⁿ n!)) · (x / x_0 - x_0 · d/dx)ⁿ ψ_0(x)
```

Введемо безрозмірну координату `ξ = x / x_0`. Зауважимо операторну тотожність:

```
(ξ - d/dξ) f(ξ) = - exp(ξ² / 2) · (d/dξ) [ exp(-ξ² / 2) · f(ξ) ]
```

Послідовне застосування цієї тотожності `n` разів веде до родинної формули Родріга для **поліномів Ерміта** `H_n(ξ)`:

```
H_n(ξ) = (-1)ⁿ · exp(ξ²) · (dⁿ / dξⁿ) exp(-ξ²)
```

Отже, хвильові функції квантового осцилятора мають явний аналітичний вигляд:

```
ψ_n(x) = N_n · H_n(x / x_0) · exp(- x² / (2 x_0²))

N_n = 1 / √(2ⁿ · n! · x_0 · √π)
```

Перші чотири поліноми Ерміта:
- `H_0(ξ) = 1`
- `H_1(ξ) = 2 ξ`
- `H_2(ξ) = 4 ξ² - 2`
- `H_3(ξ) = 8 ξ³ - 12 ξ`

Поліноми Ерміта задовольняють умову ортогональності на інтервалі `(-∞, +∞)` з ваговій функцією `exp(-ξ²)`:

```
∫_{-∞}^{+∞} H_m(ξ) · H_n(ξ) · exp(-ξ²) dξ = 2ⁿ · n! · √π · δ_mn
```

це гарантує ортонормованість хвильових функцій станів `∫_{-∞}^{+∞} ψ_m*(x) ψ_n(x) dx = δ_mn`.

## 6. Матричні елементи, дисперсії та принципи невизначеності

Виразимо оператори координати `x` та імпульсу `p` через оператори драбини `a` та `a†`:

```
x = (x_0 / √2) · (a + a†)
p = (i p_0 / √2) · (a† - a)
```

Обчислимо ненульові матричні елементи координати та імпульсу у базисі станів `|n⟩`:

```
⟨m| x |n⟩ = (x_0 / √2) · [ √n · δ_(m, n-1) + √(n + 1) · δ_(m, n+1) ]
⟨m| p |n⟩ = (i p_0 / √2) · [ √(n + 1) · δ_(m, n+1) - √n · δ_(m, n-1) ]
```

Звідси середні значення координати та імпульсу у будь-якому стаціонарному стані `|n⟩` є строго нульовими:

```
⟨x⟩_n = ⟨n| x |n⟩ = 0
⟨p⟩_n = ⟨n| p |n⟩ = 0
```

Обчислимо середні значення квадратів координати та імпульсу `⟨x²⟩_n` та `⟨p²⟩_n`:

```
⟨x²⟩_n = (x_0² / 2) · ⟨n| (a + a†)² |n⟩ = (x_0² / 2) · ⟨n| (a² + (a†)² + a a† + a† a) |n⟩
```

Оскільки `⟨n| a² |n⟩ = 0`, `⟨n| (a†)² |n⟩ = 0`, а `a a† + a† a = 2 N + 1`:

```
⟨x²⟩_n = (x_0² / 2) · (2n + 1) = (ℏ / (m ω)) · (n + 1/2) [підстановка x через a, a†]
⟨p²⟩_n = (p_0² / 2) · ⟨n| (a† - a)² |n⟩ = (p_0² / 2) · (2n + 1) = (m ℏ ω) · (n + 1/2) [підстановка p через a, a†]
```

Середня потенціальна енергія `⟨V⟩_n` та середня кінетична енергія `⟨K⟩_n` у стані `|n⟩` дорівнюють одна одній (квантова теорема віріалу):

```
⟨K⟩_n = ⟨p²⟩_n / (2m) = (1/2) · ℏ ω · (n + 1/2) = (1/2) · E_n
⟨V⟩_n = (1/2) m ω² ⟨x²⟩_n = (1/2) · ℏ ω · (n + 1/2) = (1/2) · E_n
```

Обчислимо середньоквадратичні відхилення (дисперсії) `Δx = √(⟨x²⟩ - ⟨x⟩²)` та `Δp = √(⟨p²⟩ - ⟨p⟩²)`:

```
Δx_n = x_0 · √(n + 1/2) = √(ℏ / (m ω)) · √(n + 1/2)
Δp_n = p_0 · √(n + 1/2) = √(m ℏ ω) · √(n + 1/2)
```

Знайдемо добуток неокресленостей coordinate-momentum для стаціонарного стану `|n⟩`:

```
Δx_n · Δp_n = ℏ · (n + 1/2)
```

Для основного стану `n = 0`:

```
Δx_0 · Δp_0 = (1/2) · ℏ
```

Це доводить, що основний стан `|0⟩` квантового гармонічного осцилятора досягає точної теоретичної межі мінімальної невизначеності принципу Гейзенберга `Δx · Δp = ℏ / 2`.
