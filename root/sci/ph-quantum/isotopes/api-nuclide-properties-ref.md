# 📋 Довідник ядерних характеристик та параметрів ізотопів

Цей довідник містить фундаментальні систематизовані дані про фізичні, ядерні та квантово-механічні характеристики найважливіших нуклідів у всьому діапазоні періодичної системи елементів. Параметри подано у єдиному стандарті згідно з останніми виданнями міжнародних баз даних *Atomic Mass Evaluation (AME)* та *Evaluated Nuclear Structure Data File (ENSDF)*.

Довідник розроблений для швидкого пошуку ядерно-фізичних констант, оцінки енергетики ядерних перетворень, обчислення дефекту мас, балансу енергії ядерних реакцій `Q`, кінетики радіоактивного розпаду, розрахунку біологічного захисту від випромінювання та моделювання розділення ізотопів.

### 1. Фізична інтерпретація та номенклатура ядерних параметрів

Для кожного нукліда в наведених нижче систематичних таблицях вказується повний набір фундаментальних квантових та масових характеристик:

1. **Позначення та назва нукліда:** зазначається у форматі `ᴬZ` або `ᴬElement` (наприклад, `¹²C` — вуглець-12, `²³⁸U` — уран-238).
2. **Атомний номер `Z` (заряд ядра):** чисельно дорівнює кількості протонів у ядрі та кількості електронів у нейтральному атомі, що однозначно задає його хімічну ідентичність і позицію у періодичній таблиці Менделєєва.
3. **Кількість нейтронів `N`:** чисельно дорівнює `N = A - Z` і визначає ізотопічний стан елемента та ступінь заповнення нейтронних ядерних оболонок.
4. **Масове число `A`:** загальна кількість нуклонів у ядрі (`A = Z + N`).
5. **Спін та парність основного квантового стану `J^π`:** 
   - Ядра з непарним масовим числом `A` володіють напівцілим спіном (`1/2, 3/2, 5/2...`) і підпорядковуються ферміївській статистиці Фермі — Дірака.
   - Непарно-непарні ядра (непарне `Z` та непарне `N`) мають цілочисельний спін (`1, 2, 3...`) і підпорядковуються бозевській статистиці Бозе — Ейнштейна.
   - Усі без винятку парно-парні ядра (парне `Z` та парне `N`) у збудженому або основному стані мають спін і парність `0⁺` завдяки ефекту куперовського спарювання нуклонів з протилежно орієнтованими моментами імпульсу.
6. **Точна атомна маса `M` (в а.о.м.):** маса нейтрального атома у шкалі вуглецю-12 (`¹²C = 12.00000000 а.о.м.`), яка враховує масу ядер та електронної оболонки з урахуванням їхньої енергії зв'язку.
7. **Надлишок маси `Δ` (*Mass Excess*):** фундаментальна величина в ядерній фізиці, що визначається як різниця між точною атомною масою `M` (в а.о.м.) та масовим числом `A`, виражена в енергетичних одиницях МеВ:
   ```
   Δ = (M - A) · c²  (у МеВ)
   ```
   Використання надлишку маси значно спрощує розрахунок енергетичного виходу ядерних реакцій `Q`: для реакції `A + B → C + D` енерговиділення дорівнює `Q = (Δ_A + Δ_B) - (Δ_C + Δ_D)`.
8. **Природна поширеність (*Abundance*):** мольна відсоткова частка даного ізотопу у природній суміші елемента на Землі. Для штучно синтезованих або короткоживучих радіоактивних ізотопів зазначається «Синтетичний».
9. **Період напіврозпаду `T_1/2`:** час, за який початкова кількість радіоактивних ядер зменшується вдвічі. Для абсолютно стабільних ядер зазначається «Стабільний».
10. **Головні канали розпаду:** 
    - `β⁻` — випромінювання електрона та антинейтрино (`n → p + e⁻ + ν̄_e`).
    - `β⁺` — випромінювання позитрона та нейтрино (`p → n + e⁺ + ν_e`).
    - `EC` — електронне захоплення (захоплення електрона з K-оболонки: `p + e⁻ → n + ν_e`).
    - `α` — випромінювання ядра гелію-4 (`⁴He`).
    - `SF` — спонтанний поділ важкого ядра на два осколки середньої маси.
    - `IT` — ізомерний перехід (гамма-випромінювання без зміни `Z` та `N`).
11. **Переріз захоплення теплових нейтронів `σ_n`:** імовірність взаємодії ядра з тепловим нейтроном (з кінетичною енергією `E_k = 0.0253 еВ` або швидкістю `v = 2200 м/с`), виражена в барнах (`1 б = 10⁻²⁸ м² = 100 фм²`).

### 5. Природні радіоактивні ряди (родини важких елементів)

Усі важчі за свинець радіоактивні нукліди в земній корі належать до трьох природних радіоактивних родин, кожна з яких починається з прабатьківського нукліда з екстремально довгим періодом напіврозпаду і закінчується відповідним стабільним ізотопом свинцю:

1. **Ряд урану-238 (ряд `4n + 2`):** починається з `²³⁸U` (`T_1/2 = 4.47 млрд років`) і після послідовності з 8 `α`-розпадів та 6 `β⁻`-розпадів закінчується стабільним свинцем-206 (`²⁰⁶Pb`). Проміжними членами є радій-226 (`²²⁶Ra`) та газ радон-222 (`²²²Rn`).
2. **Ряд актинію / урану-235 (ряд `4n + 3`):** починається з `²³⁵U` (`T_1/2 = 704 млн років`) і після 7 `α`- та 4 `β⁻`-розпадів закінчується стабільним свинцем-207 (`²⁰⁷Pb`).
3. **Ряд торію-232 (ряд `4n`):** починається з `²³²Th` (`T_1/2 = 14.05 млрд років`) і після 6 `α`- та 4 `β⁻`-розпадів закінчується стабільним подвійно магічним свинцем-208 (`²⁰⁸Pb`).
4. **Ряд нептунію-237 (ряд `4n + 1`):** починається з штучного `²³⁷Np` (`T_1/2 = 2.14 млн років`) і закінчується талієм-205 (`²⁰⁵Tl`). Усі члени цього ряду вимерли на Землі за час існування Сонячної системи і відновлюються лише у ядерних реакторах.

### 6. Фундаментальні константи та переводні коефіцієнти

Для проведення високоточних ядерно-фізичних розрахунків використовуються такі фундаментальні фізико-математичні константи згідно зі стандартом CODATA:

```
Атомна одиниця маси (а.о.м. / u):
1 а.о.м. = 1/12 маси атома ¹²C
1 а.о.м. = 1.660 539 066 60(50) × 10⁻²⁷ кг
1 а.о.м. · c² = 931.494 102 42(28) МеВ

Маси спокою нуклонів та фундаментальних частинок:
Маса протона m_p   = 1.007 276 466 621 а.о.м. = 938.272 088 16 МеВ/c²
Маса нейтрона m_n  = 1.008 664 915 95 а.о.м.  = 939.565 420 52 МеВ/c²
Маса електрона m_e = 0.000 548 579 909 а.о.м. = 0.510 998 950 00 МеВ/c²

Різниця мас вільних нуклонів:
(m_n - m_p) · c² = 1.293 332 36 МеВ

Енергетичні одиниці:
1 еВ  = 1.602 176 634 × 10⁻¹⁹ Дж
1 МеВ = 1.602 176 634 × 10⁻¹³ Дж
1 ГеВ = 1.602 176 634 × 10⁻¹⁰ Дж

Одиниці перерізу та ядерних відстаней:
1 фм (фермі) = 10⁻¹⁵ м
1 б (барн)   = 10⁻²⁸ м² = 100 фм²
```
