# 🧮 Математична модель ізотопного фракціонування та парабола стійкості

Ізотопні ефекти у фізиці та хімії виникають внаслідок відмінностей у масі атомних ядер. Хоча квантово-електродинамічний потенціал взаємодії між атомами визначається винятково зарядом ядра `Z` і є ідентичним для всіх ізотопів даного елемента, ядерна маса `M` входить у розрахунки квантових коливальних станів, кінетики хімічних реакцій та статистичних термодинамічних функцій.

Нижче наведено три фундаментальних математичних апарати:
1. **Квантово-механічну модель зсуву нульової енергії та кінетичного ізотопного ефекту (KIE).**
2. **Термодинамічну модель фракціонування Рейлея у відкритих багатофазних системах.**
3. **Алгебраїчний вивід нуклідної параболи бета-стійкості та подвійної параболи парності.**

---

### 1. Зсув енергії нульових коливань та кінетичний ізотопний ефект (KIE)

Розглянемо двохатомну молекулу або ковалентний зв'язок (наприклад, `C-H` проти `C-D`). Поблизу положення рівноваги потенціальну яму взаємодії можна апроксимувати квантовим гармонічним осцилятором із жорсткістю зв'язку `k`.

Власна коливальна частота `ω` визначається зведеною масою системи `μ`:

```
μ = (m_1 · m_2) / (m_1 + m_2)
```

Частота класичних та квантових коливань зв'язку дорівнює:

```
ω = √(k / μ)
```

Згідно з стаціонарним рівнянням Шредінгера, найнижчий дозволений квантовий рівень енергії гармонічного осцилятора (**енергія нульових коливань**, *Zero-Point Energy, ZPE*) не дорівнює нулю навіть при абсолютному нулю температур (`T = 0 К`):

```
E_0 = 1/2 · ħ · ω = 1/2 · ħ · √(k / μ)
```

Для двох ізотопів одного елемента — легшого `L` (наприклад, протій `¹H`) та важчого `H` (наприклад, дейтерій `²H`) — жорсткість хімічного зв'язку `k` є строго однаковою, оскільки електронна структура ідентична. Проте зведена маса легшого зв'язку `μ_L` є суттєво меншою за зведену масу важкого зв'язку `μ_H`:

```
μ_L < μ_H  ⇒  ω_L > ω_H  ⇒  E_0(L) > E_0(H)
```

Отже, нульовий коливальний рівень легшого ізотопу `E_0(L)` розташований **вище** в потенціальній ямі, ніж рівень важчого ізотопу `E_0(H)`. Це означає, що зв'язок із важким ізотопом лежить глибше на дні потенційного рельєфу і є термодинамічно міцнішим.

Різниця в енергії нульових коливань `ΔE_0` становить:

```
ΔE_0 = E_0(L) - E_0(H)
= 1/2 · ħ · (ω_L - ω_H)        [вираження через квантові частоти]
= 1/2 · ħ · √(k / μ_L) · [ 1 - √(μ_L / μ_H) ]
```

#### Розрахунок констант швидкості реакції (Арреніусовська кінетика)
Щоб розірвати хімічний зв'язок у хімічній реакції, молекула повинна подолати потенціальний бар'єр активації `E_act`. Оскільки потенціал дисоціації `V_max` однаковий для обох ізотопів, ефективна енергія активації для важчого ізотопу є більшою:

```
E_act(H) = V_max - E_0(H)
E_act(L) = V_max - E_0(L)
ΔE_act = E_act(H) - E_act(L) = E_0(L) - E_0(H) = ΔE_0 > 0
```

Відношення констант швидкості реакції `k_L / k_H` за законом Арреніуса визначається виразом:

```
k_L / k_H = e^(-E_act(L) / (k_B · T)) / e^(-E_act(H) / (k_B · T))
= e^(ΔE_0 / (k_B · T))
```

##### Кількісний приклад для зв'язків C-H та C-D
Обчислимо кінетичний ізотопний ефект для розриву зв'язку вуглець-водень за кімнатної температури (`T = 298.15 К`):
- Маса атома вуглецю `m_C = 12.000 а.о.м.`
- Маса протію `m_H = 1.0078 а.о.м.` ⇒ `μ_CH = (12 · 1.0078) / (12 + 1.0078) ≈ 0.929 а.о.м.`
- Маса дейтерію `m_D = 2.0141 а.о.м.` ⇒ `μ_CD = (12 · 2.0141) / (12 + 2.0141) ≈ 1.725 а.о.м.`

Співвідношення частот нульових коливань:

```
ω_CD / ω_CH = √(μ_CH / μ_CD) = √(0.929 / 1.725) ≈ 0.734
```

Типова частота валентних коливань зв'язку `C-H` становить `ν_CH = 3000 см⁻¹`, що відповідає енергії `ħ · ω_CH ≈ 0.372 еВ`. 

Різниця нульових енергій:

```
ΔE_0 = 1/2 · (ħ · ω_CH) · [ 1 - (ω_CD / ω_CH) ]
= 0.5 · 0.372 еВ · [ 1 - 0.734 ]
≈ 0.0495 еВ  (близько 4.77 кДж / моль)
```

Обчислимо співвідношення швидкостей реакцій при `T = 298.15 К` (`k_B · T ≈ 0.0257 еВ`):

```
k_H / k_D = e^(0.0495 / 0.0257) = e^(1.926) ≈ 6.86
```

Висновок: хімічні реакції з розривом зв'язку `C-H` перебігають майже у **7 разів швидше**, ніж для зв'язку `C-D`.

#### Рівняння Бігалейзена — Майєра для рівноважного ізотопного обміну
Для рівноважних хімічних реакцій (наприклад, обміну кисню між водою та карбонатом `H₂¹⁶O + C¹⁸O₃²⁻ ⇄ H₂¹⁸O + C¹⁶O₃²⁻`) константа рівноваги `K` виражається через відношення статистичних сум по станах (*partition functions*) за формулою Бігалейзена — Майєра:

```
K = (Q_H / Q_L)_продукт / (Q_H / Q_L)_реагент
```

При високих температурах квантовий ефект спадає як `1 / T²`, що робить термодинамічне фракціонування чутливим термометром для палеокліматології та геології глибинних мантійних процесів.

### 2. Рівняння Рейлея для фракціонування у відкритих системах

Під час фазових переходів (випаровування води з океану, конденсація вологи в хмарах, кристалізація магматичних порід) ізотопне співвідношення у залишковому резервуарі змінюється за диференціальним законом дистиляції Рейлея.

Нехай `N_L` та `N_H` — кількість легких і важких ізотопних молекул (наприклад, `H₂¹⁶O` та `H₂¹⁸O`) у рідкій фазі. Співвідношення вмісту ізотопів у рідині визначається як `R = N_H / N_L`.

Фактор одноступеневого фракціонування `α` визначає співвідношення ізотопів у випаровуваній парі відносно рідини:

```
α = R_пар / R_рідина = (d N_H / d N_L) / (N_H / N_L)
```

Враховуючи, що легкий ізотоп є переважним у масі речовини (`N_L ≈ N_загальне`), продиференціюємо співвідношення `R`:

```
d R / R = d (N_H / N_L) / (N_H / N_L)
= d N_H / N_H - d N_L / N_L
= α · (d N_L / N_L) - d N_L / N_L      [використано d N_H = α · R · d N_L]
= (α - 1) · (d N_L / N_L)
```

Позначаючи частку залишкової речовини у резервуарі як `f = N_L / N_L,0`, проінтегруємо обидві частини від початкового стану (`f = 1`, `R = R_0`) до поточного стану `f`:

```
∫_(R_0)^(R) (d R / R) = (α - 1) · ∫_1^f (d f / f)

ln(R / R_0) = (α - 1) · ln(f)
```

Потенціюючи обидві частини, отримуємо класичний **закон дистиляції Рейлея**:

```
R = R_0 · f^(α - 1)
```

У геохімії та палеокліматології вміст ізотопів виражають у відносних одиницях проміле (`‰`, дельта-нотація):

```
δ (‰) = [ (R_виміряне / R_стандарт) - 1 ] · 1000
```

Для випаровування води з океану (`α ≈ 0.991` для `¹⁸O` при `25 °C`), коли у материковій хмарі залишається лише `f = 0.1` від початкового об'єму вологи, збіднення залишку пароводневої суміші на важкий ізотоп досягає понад `-40 ‰`...`-60 ‰`. Це створює так званий «широтний ізотопний ґрадієнт», за яким по осадженню `δ¹⁸O` у льодовикових кернах Гренландії та Антарктиди відновлюють температуру планети за останні 800 000 років.

### 3. Алгебраїчний вивід нуклідної параболи бета-стійкості та ефекту парності

Для ізобар із фіксованим масовим числом `A` залежність маси ядра `M(Z, A)` від атомного номера `Z` описується напівемпіричною формулою Вейцзеккера (модель краплі ядерної рідини):

```
M(Z, A) = Z · m_p + (A - Z) · m_n - [ a_v · A - a_s · A^(2/3) - a_c · Z² / A^(1/3) - a_a · (A - 2 Z)² / A + δ_p ] / c²
```

Розкриємо квадрат асиметричного додатка:

```
(A - 2 Z)² = A² - 4 A Z + 4 Z²
```

Перегрупуємо члени формули Вейцзеккера як квадратний тричлен відносно змінної заряда `Z`:

```
M(Z, A) = A · C_0 + Z · C_1 + Z² · C_2 - δ_p / c²
```

де коефіцієнти квадратичної параболи дорівнюють:

```
C_2 = [ a_c / A^(1/3) + 4 · a_a / A ] / c²
C_1 = [ (m_p - m_n) · c² - 4 · a_a ] / c²
```

Оскільки `C_2 > 0`, залежність маси ізобар `M(Z)` від заряду ядра `Z` являє собою **параболу з мінімумом у точці стійкості** `Z_min`.

Знайдемо мінімум параболи, продиференціювавши масу за зарядом `Z` і прирівнявши похідну до нуля:

```
∂ M(Z, A) / ∂ Z = 0  ⇒  C_1 + 2 · Z_min · C_2 = 0

Z_min = - C_1 / (2 · C_2)
= [ 4 · a_a - (m_p - m_n) · c² ] / [ 2 · (a_c / A^(1/3) + 4 · a_a / A) ]
```

Нехтуючи малою різницею мас нуклонів `(m_n - m_p) · c² ≈ 1.293 МеВ` порівняно з симетричною енергією `4 a_a ≈ 93 МеВ`, ділимо чисельник і знаменник на `4 a_a / A`:

```
Z_min = A / [ 2 + (a_c / (2 · a_a)) · A^(2/3) ]
```

Підставляючи експериментальні значення коефіцієнтів Вейцзеккера (`a_c ≈ 0.71 МеВ`, `a_a ≈ 23.2 МеВ`), отримуємо фундаментальне співвідношення для лінії бета-стійкості нуклідів:

```
Z_min = A / [ 2 + 0.0153 · A^(2/3) ]
```

#### Вплив члена парності δ_p та розщеплення парабол
Член парності `δ_p` у формулі Вейцзеккера істотно змінює вигляд масової поверхні залежно від парності `A`, `Z` та `N`:

```
δ_p = + a_p / A^(1/2)    для парно-парних ядер (парне Z, парне N)
δ_p = 0                  для непарно-парних або парно-непарних ядер (непарне A)
δ_p = - a_p / A^(1/2)    для непарно-непарних ядер (непарне Z, непарне N)
```

Це математично приводить до двох принципово різних випадків:

1. **Непарне масове число `A` (`δ_p = 0`):**
   Існує **одна парабола мас** `M(Z)`. Вона має єдиний мінімум, якому відповідає один-єдиний стійкий ізобар `Z_min`. Усі інші суміжні ізобари нестійкі й послідовно розпадаються через `β⁻` або `β⁺` (електронне захоплення), рухаючись до дна параболічного жолоба.

2. **Парне масове число `A` (`δ_p ≠ 0`):**
   Виникають **дві паралельні параболи мас**, рознесені по висоті на величину `2 · δ_p / c²`:
   - Нижче розташована парабола парно-парних ядер (*Even-Even*), які мають підвищену енергію зв'язку завдяки квантовому спарюванню нуклонів із протилежними спінами.
   - Вище розташована парабола непарно-непарних ядер (*Odd-Odd*), позбавлених енергії спарювання.

Через таке розщеплення непарно-непарне ядро на верхній параболі може бета-розпадатися **в обидва боки** — і ліворуч, і праворуч, перетворюючись на два різні парно-парні сусіди на нижній параболі. Нижчна парабола при цьому може мати **два або навіть три місцевих мінімуми**. 

Саме тому в природі існують стабільні **ізобарні пари-двійники** (наприклад, `⁴⁰Ar` та `⁴⁰Ca`, розділені нестійким `⁴⁰K`). Прямий бета-перехід між двома парно-парними ізобарами заборонений, а подвійний бета-розпад (*Double Beta Decay, 2β*) є надзвичайно рідкісним квантовим процесом із періодом напіврозпаду понад `10¹⁹...10²5` років.
