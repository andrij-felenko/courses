# 📋 Довідник інтерфейсу бібліотеки обчислення алгебри Вірасоро

Цей технічний довідник надає повний і вичерпний опис програмного інтерфейсу (API), структур даних, сигнатур функцій, кодій помилок та CLI-інтерфейсу утиліти `libvirasoro` — спеціалізованої системної C/C++ бібліотеки, призначеної для обчислення алгебраїчних операцій у конформній теорій поля, аналізу представлень алгебри Вірасоро, побудови матриць Грама та оцінки визначника Каца.

Документ слугує нормативним контрактом для розробників та дослідників, які інтегрують обчислювальні модулі алгебри Вірасоро у власні науково-дослідні комплекси, алгоритми символьної математики, системне програмне забезпечення або обчислювальні моделі теорії струн і фізики конденсованого стану.

---

### 1. Загальна архітектура та принципи використання

Бібліотека `libvirasoro` розроблена у відповідності до суворих вимог стандартів ANSI C (C99/C11) для забезпечення максимальної сумісності з низькорівневими системними середовищами та надає ідіоматичні C++23 обгортки для використання у сучасних об'єктно-орієнтованих проєктах.

Основними функціональними підсистемами та обчислювальними модулями бібліотеки є:

1. **Модуль комутаційної алгебри та 2-коциклів**: Забезпечує точне обчислення структурних констант алгебри Вірасоро, розрахунок квантових центральних членів для довільних модових чисел `n` та `m`, перевірку виконання алгебраїчних тотожностей Якобі та побудову комутаторів у модовому базисі.
2. **Модуль аналізу представлень та модулів Верма**: Виконує побудову комбінаторного базису векторів народження на заданому рівні `N`, будує симетричні матриці Грама `M⁽ᴺ⁾`, виконує чисельне розкладання за власними значеннями (SVD-розклад) для знаходження нуль-векторів та обчислює точні значення визначника Каца.
3. **Модуль перевірки квантових конформних аномалій**: Здійснює аналіз та підсумовування центральних зарядів матеріальних (бозонних та ферміонних) і духових (BRST-калібрувальних) секторів для аналізу квантової узгодженості та визначення критичної вимірності простору-часу.
4. **Модуль операторного розкладу (OPE)**: Проводити символьний та чисельний розрахунок коефіцієнтів операторного розкладу для тензора енергії-імпульсу `T(z)` та первинних полів `Φ_h(z)`.

### 3. Детальний опис контракту функцій, параметрів та пам'яті

#### Контракт функції `virasoro_commutator`
Функція `virasoro_commutator` є базовою обчислювальною точкою для визначення результату дії комутатора `[Lₙ, Lₘ]` двох генераторів Вірасоро. 
- **Передумови (Preconditions)**: Вказівник `cfg` повинен посилатися на дійсний, ініціалізований екземпляр структури `virasoro_config_t`. Передані вказівники на вихідні змінні `out_target_mode`, `out_linear_coeff` та `out_central_term` не повинні бути рівними `NULL`.
- **Постдумови (Postconditions)**: Передані вихідні змінні заповнюються відповідними обчисленими значеннями. При `n + m = 0` у змінну `out_central_term` записується значення квантового розширення `(c / 12) * (n³ - n)`. При `n + m ≠ 0` член розширення тотожно дорівнює нулю.
- **Керування пам'яттю**: Функція не виконує динамічного виділення пам'яті у купі (Heap allocation) і є повністю безпечною для використання у багатопотокових середовищах (Thread-safe, reentrant).

#### Контракт функції `virasoro_eval_kac_det`
Функція `virasoro_eval_kac_det` виконує комбінаторну побудову базису станів на рівні `level` у модулі Верма `V(c, h)`, обчислює елементи симетричної матриці Грама `M⁽ᴺ⁾` розміром `p(N) × p(N)` та знаходить її визначник.
- **Параметр `conformal_weight_h`**: Задає значення конформної ваги основного стану. Дійсне число.
- **Параметр `level`**: Задає рівень зрізання `N`. Приймає цілочисельні значення від `1` до `20`. При спробі передати `level > max_level` функція негайно повертає код помилки `VIRASORO_ERR_LEVEL_EXCEEDED`.
- **Прапор унітарності `is_unitary`**: Після обчислення власних значень матриці Грама прапор `is_unitary` отримує значення `true` лише тоді, коли всі власні значення є строго додатними (`λᵢ > 0`). Якщо виявлено принаймні одне від'ємне власне значення (`λᵢ < 0`), прапор встановлюється у `false` (виявлено духи з від'ємною нормою).

### 4. Детальний опис полів конфігурації та результатів

#### Структура `virasoro_config_t`
- **`central_charge`** (`double`): Значення центрального заряду `c` алгебри Вірасоро. Може набувати довільних дійсних значень у діапазоні `(-∞, +∞)`. Для класичної бозонної струни дорівнює `26.0`, для квантової суперструни — `10.0`, для критичної двохвимірної моделі Ізинга — `0.5`, а для трикритичної моделі Ізинга — `0.7`.
- **`max_level`** (`int`): Максимальний рівень зрізання `N` модових генераторів у модулі Верма. Обмежує обчислювальні набори векторів народження для запобігання переповненню оперативної пам'яті. Допустимий діапазон від `1` до `20`.
- **`use_ghost_sector`** (`bool`): Логічний прапор. Якщо встановлено у значення `true`, бібліотека автоматично додає духовий внесок `c_ghost = -26` при обчисленні підсумкової конформної аномалії.

#### Структура `virasoro_kac_result_t`
- **`c`** (`double`): Скопійоване значення центрального заряду з конфігурації.
- **`h`** (`double`): Конформна вага первинного стану `|h, c⟩`.
- **`level`** (`int`): Рівень `N` підпростору модуля Верма.
- **`dim`** (`size_t`): Обчислена вимірність базису на даному рівні, що дорівнює кількості цілочисельних розбиттів `p(N)`.
- **`determinant`** (`double`): Обчислене чисельне значення визначника Каца `det M⁽ᴺ⁾(c, h)`.
- **`is_unitary`** (`bool`): Прапор квантової унітарності. Тотожно дорівнює `true`, якщо всі власні значення матриці Грама є строго додатними, і `false`, якщо виявлено стани з від'ємною нормою (духи).

### 5. Таблиця кодій помилок викликів API

Усі функції С-інтерфейсу повертають цілочисельний статус виконання. Нульове значення вказує на успішне завершення операції, а від'ємні значення відповідають конкретним критичним помилкам та виключним ситуаціям.

| Код помилки | Константа | Опис та причини виникнення | Рекомендована дія |
| :--- | :--- | :--- | :--- |
| `0` | `VIRASORO_SUCCESS` | Операція успішно виконана без жодних зауважень. | Продовжити стандартне виконання програми. |
| `-1` | `VIRASORO_ERR_INVALID_MODE` | Передано некоректне модове число `n` або `m` за межами масиву. | Перевірити відповідність модових чисел межам. |
| `-2` | `VIRASORO_ERR_LEVEL_EXCEEDED` | Запитаний рівень `N` перевищує встановлений `max_level`. | Збільшити параметр `max_level` у конфігурації. |
| `-3` | `VIRASORO_ERR_NON_UNITARY` | Матриця Грама містить від'ємні власні значення (знайдено духи). | Перевірити параметри `(c, h)` на належність унітарній серії. |
| `-4` | `VIRASORO_ERR_NULL_POINTER` | Передано `NULL` у якості вхідного вказівника структури. | Забезпечити коректну ініціалізацію та виділення пам'яті. |
| `-5` | `VIRASORO_ERR_OUT_OF_MEMORY` | Не вдалося виділити оперативну пам'ять під матрицю Грама. | Зменшити рівень `N` або звільнити непідтримувані ресурси. |

### 6. Консольна утиліта `virasoro-tool` та CLI-інтерфейс

Бібліотека постачається разом із зручною виконуваною консольною утилітою `virasoro-tool`, яка дозволяє виконувати швидкі розрахунки та діагностику моделей безпосередньо з командного рядка Linux/Unix/Windows.

#### Синтаксис виклику утиліти:

```bash
virasoro-tool [ОПЦІЇ] --c <VAL> --h <VAL> --level <N>
```

#### Повний перелік прапорів командного рядка:

- `-c, --central-charge <float>` — задає значення центрального заряду `c`.
- `-h, --weight <float>` — задає конформну вагу первинного поля `h`.
- `-l, --level <int>` — рівень підпростору у модулі Верма `N` (за замовчуванням `1`).
- `--eval-kac` — прапор запуску розрахунку визначника Каца та аналізу унітарності.
- `--check-string` — автоматичний режим перевірки компенсації аномалії `c_total = 0`.
- `--json` — форматування результатів виводу у виглядала JSON-структури для автоматичної інтеграції з зовнішніми аналітичними скриптами.

#### Приклади використання та сценарії роботи:

1. **Розрахунок визначника Каца для моделі Ізинга**:
```bash
virasoro-tool --c 0.5 --h 0.0625 --level 2 --eval-kac
```
