# ⚙️ Обчислювальна перевірка алгебри Вірасоро та визначника Каца

У цьому проектному розділі наведено детальну обчислювальну реалізацію програмних утиліт для символьної та чисельної перевірки комутаційних співвідношень алгебри Вірасоро, алгебраїчної тотожності Якобі, а також побудови матриць Грама та обчислення визначників Каца на зрізаних підпросторах модулів Верма.

Комп'ютерне моделювання алгебраїчних структур конформної теорії поля є критично важливим інструментом при розрахунку вищих рівнів збуджень у теорії струн, аналізі унітарності квантових моделей та перевірці відсутності станів із від'ємною нормою (духів).

### 1. Алгоритм та математична модель програмного комплексу

Основою алгоритму є побудова матричного представлення операторів Вірасоро `Lₙ` у базисі модуля Верма `V(c, h)`. Для заданого значення центрального заряду `c` та конформної ваги основного стану `h` модуль Верма розпадається у пряму суму скінченновимірних векторних підпросторів за рівнями `N`:

```
V(c, h) = ⊕₝₌₀⁺∞ V⁽ᴺ⁾(c, h)
```

На кожному рівні `N` векторний базис формується із застосування спідніх генераторів Вірасоро `L₋ₖ` (`k > 0`) до первинного стану `|h, c⟩` таким чином, щоб сума модових індексів дорівнювала `N`:

```
|k₁, k₂, ..., kᵣ⟩ = L₋ₖ₁ L₋ₖ₂ ... L₋ₖᵣ |h, c⟩,    k₁ ≥ k₂ ≥ ... ≥ kᵣ > 0,    ∑ᵢ kᵢ = N
```

Для аналізу унітарності програмний модуль обчислює елементи матриці Грама `M⁽ᴺ⁾ᵢⱼ = ⟨h| (vᵢ)⁺ vⱼ |h⟩`, використовуючи виключно комутаційні співвідношення алгебри Вірасоро:

```
[Lₙ, L☿] = (n - m) Lₙ₊ᵐ + (c / 12) · (n³ - n) · δₙ₊ᵐ,₀ · I
```

Алгоритм виконує послідовне просування операторів знищення `Lₖ` (`k > 0`) праворуч за допомогою комутаторів доти, доки вони не досягнуть вакуумного стану `|h, c⟩` і не обнулять його (`Lₖ|h, c⟩ = 0`).

На рівні `N = 2` базис складається з двох векторів: `|1⟩ = L₋₂|h⟩` та `|2⟩ = L₋₁²|h⟩`. Точні аналітичні вирази для матричних елементів мають вигляд:
- `M₁₁ = ⟨h| L₂ L₋₂ |h⟩ = 4h + c/2`
- `M₁₂ = M₂₁ = ⟨h| L₂ L₋₁² |h⟩ = 6h`
- `M₂₂ = ⟨h| L₁² L₋₁² |h⟩ = 4h(2h + 1)`

Обчислений чисельно визначник цієї матриці порівнюється з точним аналітичним визначником Каца:

```
det M⁽²⁾(c, h) = 2 · h · (16 h² + 2 c h - 10 h + c)
```

### 4. Покрокове генератування базису розбиттів та обчислення рівнів N = 3, 4

Для розширення обчислень на вищі рівні збуджень `N = 3` та `N = 4` програма виконує комбінаторну генерацію розбиттів. Розбиття цілого числа `N` описується списком цілих додатних чисел `λ = (k₁, k₂, ..., kᵣ)`, таких що `k₁ ≥ k₂ ≥ ... ≥ kᵣ > 0` та `∑ kᵢ = N`.

На рівні `N = 3` маємо `p(3) = 3` базисних вектори:
1. `|v₁⟩ = L₋₃ |h, c⟩`
2. `|v₂⟩ = L₋₁ L₋₂ |h, c⟩`
3. `|v₃⟩ = L₋₁³ |h, c⟩`

Елементи тривимірної матриці Грама `M⁽³⁾` обчислюються за допомогою коммутаторів:
- `M₁₁ = ⟨h| L₃ L₋₃ |h⟩ = 6h + c`
- `M₁₂ = ⟨h| L₃ L₋₁ L₋₂ |h⟩ = 5 ⟨h| L₂ L₋₂ |h⟩ = 5(4h + c/2) = 20h + 5c/2`
- `M₁₃ = ⟨h| L₃ L₋₁³ |h⟩ = 18h`
- `M₂₂ = ⟨h| L₂ L₁ L₋₁ L₋₂ |h⟩ = 8h² + 8h + (c/2)(2h + 1)`
- `M₂₃ = ⟨h| L₂ L₁ L₋₁³ |h⟩ = 24h(2h + 1)`
- `M₃₃ = ⟨h| L₁³ L₋₁³ |h⟩ = 24h(2h + 1)(h + 1)`

Обчислений визначник цієї матриці дорівнює точній теоретичній формулі Каца на рівні `N = 3`:

```
det M⁽³⁾(c, h) = 24 · h² · (h - h₁,(c)) · (h - h₂,₁(c)) · (h - h₁,₂(c))
```

### 5. Обчислювальна складність, чисельні крайові випадки та виправлення помилок

При розширенні програми для обчислення визначників Каца на вищих рівнях `N` виникає низка важливих системних та чисельних особливостей, які слід враховувати:

1. **Комбінаторне зростання вимірності**: Кількість базисних векторів на рівні `N` задається кількістю цілочисельних розбиттів `p(N)`. За відомою асимптотичною формулою Гарді-Рамануджана-Успенського, вимірність зростає експоненційно:
```
p(N) ~ (1 / (4 N √3)) · exp( π √(2N / 3) )
```
Для рівнів `N = 1, 2, 3, 4, 5` вимірності дорівнюють відповідним значенням `p(N) = 1, 2, 3, 5, 7`. Однак вже для `N = 10` вимірність становить `p(10) = 42`, для `N = 20` досягає `p(20) = 627`, а для `N = 50` вимірність становить `p(50) = 204226`. 

Обчислення визначника квадратних матриць таких розмірів вимагає застосування виключно точних матричних алгоритмів (наприклад, LU-розкладу чи методу Гаусса з вибором головного елемента), оскільки стандартна плаваюча точка типу `double` накопичує значні помилки округлення при вирахуванні великих чисел.

2. **Діагностика нуль-векторів та вироджених матриць**: У випадках, коли параметри `(c, h)` потрапляють на криві нулів Каца `h = hᵣ,ₛ(c)`, визначник Каца стає строго рівним нулю (`det M⁽ᴺ⁾ = 0`). Чисельно це означає, що матриця Грама отримує одне або декілька власних значень, які прямують до нуля у межах машинного точнісного поргу `ε_mach ≈ 1e-15`. 

Для виявлення нуль-векторів програма повинна виконувати не пряме обчислення визначника через добуток діагональних елементів, а спектральний розклад матриці за власними значеннями (метод SVD). Власні вектори, що відповідають нульовим власним значенням `λᵢ ≈ 0`, визначають точні коефіцієнти лінійних комбінацій, які формують нуль-вектори модуля Верма.

3. **Оптимізація обчислення комутаційних ланцюжків**: Для мінімізації повторних дій при перестановках операторів `Lₖ` рекомендується застосовувати методи динамічного програмування та мемоізації (Memoization), зберігаючи вже обчислені матричні елементи `⟨h| Lₖ₁...Lₖᵣ L₋ₗ₁...L₋ₗₛ |h⟩` у хеш-таблиці. Це зменшує часову складність побудови матриці Грама від факторіальної до поліноміальної відносно вимірності `p(N)`.

4. **Паралелізація та векторні обчислення**: Оскільки побудова окремих строчок та стовпчиків матриці Грама `M⁽ᴺ⁾` виконується повністю незалежно для кожного комбінаторного розбиття, алгоритм ідеально піддається паралелізації за допомогою технологій OpenMP або MPI. Обчислення векторних скалярних добутків на процесорних ядрах із підтримкою інструкцій AVX-512 або SIMD прискорює виконання процедур SVD-розкладу на великих рівнях у десятки разів.
