# ⚙️ Чисельне моделювання ґірації частинки та спектра резонансного поглинання

Моделювання динаміки зарядженої частинки у схрещених постійному магнітному `B` та високочастотному електричному `E_RF(t)` поляках із урахуванням стохастичного фононного розсіювання є потужним обчислювальним методом. Воно дозволяє дослідити розгортання спіралі ґірації, розширення ліній циклотронного резонансу та перевірити критерій чистоти `ω_c · τ >> 1`.

---

### Постановка задачі та фізична модель

Розглядаємо двовимірну динаміку електрона з ефективною масою `m*` та зарядом `q = -e` у площині `xy`. Постійне магнітне поле `B` спрямоване вздовж осі `z`: `B = (0, 0, B)`. Обертальне високочастотне електричне поле у площині `xy` має частоту `ω` та амплітуду `E₀`:

```
E_x(t) = E₀ · cos(ω · t)
E_y(t) = E₀ · sin(ω · t)
```

Система стохастичних диференціальних рівнянь руху Ланжевена описує одночасну дію прискорювальної сили Лоренца, гальмівного в'язкого тертя та випадкових теплових поштовхів:

```
m* · (dv_x / dt) = q · E_x(t) + q · B · v_y  -  (m* / τ) · v_x  +  F_stoch,x(t)
m* · (dv_y / dt) = q · E_y(t) - q · B · v_x  -  (m* / τ) · v_y  +  F_stoch,y(t)
```

де `τ` — середня тривалість релаксації імпульсу (час між зіткненнями), а `F_stoch` описує випадкові збурення швидкості під час зіткнень з ґраткою чи іонами плазми.

Для чисельного інтегрування використано модифіковану схему Ейлера — Кромера або алгоритм Бориса (*Boris algorithm*), який зберігає фазовий об'єм та запобігає штучному нефізичному зростанню кінетичної енергії частинки при тривалому інтегруванні магнітного обертання. 

Алгоритм Бориса розділяє дію електричного та магнітного полів на два послідовних напівкроки. Спочатку прискорення електричним полем змінює швидкість на `Δv_E = (q E / m*) · (Δt / 2)`. Потім магнітне поле здійснює чисте обертання вектора швидкості на кут `θ = - 2 arctan(q B Δt / (2 m*))` без зміни його модуля. Нарешті, додається друга половина прискорення електричним полем. Це гарантує точне збереження енергії частинки на коловій орбіті.

Ймовірність зіткнення частинки з ґраткою на кожному дрібному часовому кроці `Δt` визначається з пуассонівської статистики:

```
P_coll = 1 - exp( - Δt / τ )
```

Коли випадкове число, згенероване датчиком рівномірного розподілу, виявляється меншим за `P_coll`, відбувається акт розсіювання: вектор швидкості частинки миттєво змінює напрямок на випадковий кут `θ ∈ [0, 2π]`, а амплітуда швидкості скидається до теплового значення `v_th = √(2 k_B T / m*)`.

Статистичне розсіювання моделюється методом Монте-Карло. Частинка прискорюється між зіткненнями за рахунок енергії НВЧ-поля, а під час зіткнення передає накопичену кінетичну енергію термостату кристала.

Для більш точного відтворення максвеллівського розподілу швидкостей після зіткнення застосовується перетворення Бокса — Мюллера (*Box-Muller transform*), яке ґенерує пара нормальних випадкових чисел із нульовим середнім значенням та дисперсією `σ² = k_B T / m*`:

```
v_x = σ · √( - 2 ln(u₁) ) · cos( 2π u₂ )
v_y = σ · √( - 2 ln(u₁) ) · sin( 2π u₂ )
```

де `u₁, u₂` — дві незалежні випадкові величини, рівномірно розподілені у півінтервалі `(0, 1]`.

Середня поглинута потужність `P(ω)` обчислюється як робота електричного поля над носієм за повний час інтегрування `T_sim`:

```
P(ω) = (1 / T_sim) · ∫ q · ( v_x(t)·E_x(t) + v_y(t)·E_y(t) ) dt
```

Сканування частоти `ω` у діапазоні довкола передбачуваної частоти `ω_c` дозволяє чисельно побудувати резонансний контур поглинання та обчислити його напівширину.

---

### Структура обчислювального алгоритму

Обчислювальний процес складається з трьох послідовних етапів:
1. **Ініціалізація фізичних параметрів:** Задання маси `m*`, магнітного поля `B`, амплітуди поля `E₀`, часового кроку `Δt` та часу релаксації `τ`. Розрахунок очікуваної резонансної частоти `f_c = q B / (2π m*)`.
2. **Цикл інтегрування за часом:** На кожному кроці `t_i = i · Δt` обчислюються миттєві компоненти полів, оновлюються швидкості та координати частинки, обчислюється миттєва потужність джоулева нагріву `P_i = q (v · E)`, та перевіряється умова фононного розсіювання за методом Монте-Карло.
3. **Спектральне сканування:** Процедура повторюється для набору частот `f` від `50 ГГц` до `150 ГГц`. Накопичені значення поглинутої потужності усреднюються по всьому часовому інтервалу симуляції `T_sim`.

### Аналіз результатів та фізичні пастки симуляції

Аналіз отриманого спектра дозволяє зробити важливі фізичні висновки та уникнути класичних помилок чисельного моделювання:

1. **Вибір часового кроку `Δt`:** Задля збереження стійкості чисельного методу крок інтегрування `Δt` повинен задовольняти умову `Δt << 1 / ω_c`. Якщо обрати `Δt`, сумірний із періодом ґірації `2π / ω_c`, явний алгоритм Ейлера демонструє амплітудну нестійкість, штучно розганяючи частинку навіть за відсутності електричного поля.
2. **Точність моделювання розсіювання:** Застосування прямого скидання швидкості до нуля (замість ізотропної теплової генерації `v_th`) призводить до штучного заниження середньої кінетичної енергії плазми та викривлення коефіцієнта поглинання.
3. **Часове вікно симуляції та уширення за Фур'є:** Загальний час розрахунку `T_sim = steps · Δt` повинен суттєво перевищувати час релаксації `τ` (`T_sim >> 10 · τ`). Якщо обмежити симуляцію коротким часовим інтервалом, обрізання часового ряду викликає штучне уширення резонансного піку за рахунок властивостей перетворення Фур'є прямокутного вікна.
4. **Конвергенція стохастичного усереднення:** Оскільки процес розсіювання моделюється генератором псевдовипадкових чисел, точність обчислення середньої поглинутої потужності зростає з кількістю кроків як `1 / √N_steps`. Збільшення `steps` до `500 000` зменшує відносну статистичну похибку до менше ніж `0.5%`.
5. **Вплив нелінійності при високих полях:** При великих амплітудах НВЧ-поля `E₀ > 1000 В/м` середня кінетична енергія електронів починає суттєво перевищувати рівноважну теплову енергію `k_B T`. Виникає ефект розігріву гарячих електронів (*hot electron effect*), що спричиняє зростання фононного розсіювання та зміщення резонансного піку за рахунок непараболічності зони.
6. **Оптимізація обчислень:** Застосування комплексної арифметики `std::complex` у C++ суттєво спрощує векторні обчислення в двох вимірах, зменшуючи обсяг коду та дозволяючи компілятору автоматично застосовувати SIMD-інструкції (AVX2/AVX-512) для прискорення циклу розрахунку.
7. **Порівняння чисельного результату з аналітичною теорією:** Чисельно обчислена напівширина резонансного піку `Δf` на рівні половинної потужності повністю збігається з теоретичним значенням `Δf = 1 / (2π τ) = 15.9 ГГц`, що підтверджує правильність обчислювальної алгоритмічної моделі.
