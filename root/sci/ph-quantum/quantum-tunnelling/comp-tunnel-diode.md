# 🔌 Тунельний діод та резонансні тунельні структури

Узагальнений клас тунельних напівпровідникових приладів — тунельні діоди Лео Есакі (1957), резонансно-тунельні діоди (RTD) та тунельні польові транзистори (TFET) — функціонує за рахунок квантового проникнення носіїв заряду крізь вузький потенціальний бар'єр p-n переходу. Описано фізичні принципи роботи, вольт-амперну характеристику (ВАХ) з ділянкою від'ємного диференціального опору, еквівалентні схеми, розрахунок граничних частот та сфери застосування у високочастотній імпульсній та мікрохвильовій техніці.

## 1. Фізичні принципи та гетероструктура тунельного p-n переходу

Тунельний діод являє собою напівпровідниковий p-n перехід, виготовлений на основі сильнолегованих (вироджених) напівпровідникових матеріалів, таких як германій (`Ge`), арсенід галію (`GaAs`), антимонід галію (`GaSb`) або кремній (`Si`).

Концентрація донорно-акцепторних домішок в p- та n-областях перевищує `10¹⁹–10²⁰ см⁻³`, що у `10³–10⁴` разів більше, ніж у звичайних випрямних діодах.

Унаслідок екстремально високого рівню легування виникають дві фундаментальні напівпровідникові властивості:

1. **Виродження напівпровідника:** Рівень Фермі `E_F` в n-області опиняється вище дна зони провідності `E_c`, а в p-області — нижче стелі валентної зони `E_v`. Це означає, що електронами повністю заповнена нижня частина зони провідності n-області, а у валентній зоні p-області виникає висока концентрація вільних заповнених станів (дірок).
2. **Ультратонка область збеднення:** Ширина потенціального бар'єра (знеструмленої зони об'ємного заряду) `W` обернено пропорційна квадратному кореню з концентрації домішок:
   ```
   W = √[ (2 ε ε₀ (V_bi - V)) / e (1/N_A + 1/N_D) ]
   ```
   У тунельних діодах ширина збеднення становить усього `W ≈ 5–10 нм` (близько 50 атомних шарів), що сумірне з дебройлівською довжиною хвилі електронів.

```
       n++ область (вироджена)           |      p++ область (вироджена)
----------------------------------------|----------------------------------------
Зона провідності (E_c) ░░░░[E_F]░░░░░   |  
----------------------------------------|  Зона провідності (E_c)
                                        |  --------------------------------------
   Заборонена зона (E_g)                |     Заборонена зона (E_g)
                                        |  --------------------------------------
Валентна зона (E_v)                     |  ░░░░░░░░[E_F]░░░░░ Валентна зона (E_v)
```

За такої малої ширини бар'єра коефіцієнт прозорості `T` для електронів провідності стає достатньо високим, що дозволяє їм тунелювати крізь заборонену зону без зміни енергії.

## 2. Фізика формування ВАХ та п'ять режимів роботи

Вольт-амперна характеристика (ВАХ) тунельного діода має немонотонний N-подібний вигляд із вираженою ділянкою від'ємного диференціального опору.

```
Струм I
  ^
  |      Пік (I_p)
  |       /\
  |      /  \  <- Від'ємний диференціальний опір (dI/dV < 0)
  |     /    \
  |    /      \  Впадина (I_v)
  |   /        \_______
  |  /                 \  <- Тепловий дифузійний струм
  +-------------------------> Напруга V
     V_p       V_v
```

Аналіз зміщення енергетичних зон дозволяє виділити п'ять послідовних режимів роботи:

1. **Зворотний зсув (`V < 0`):** При прикладанні зворотного потенціалу валентна зона p-області зміщується вгору відносно зони провідності n-області. Заповнені стани валентної зони p-області опиняються навпроти порожніх станів зони провідності n-області. Електрони масово тунелюють з p- у n-область. Зворотний струм стрімко зростає при найменшій напрузі без явищ пробою. Оскільки діод чудово проводить зворотний струм і не має дифузійної затримки, тунельні діоди при роботі на зворотній гілці називають **обращеними діодами** і використовують як надшвидкі детектори малоамплітудних НВЧ сигналів.
2. **Рівноважний стан (`V = 0`):** Рівні Фермі в n- та p-областях вирівнюються (`E_Fn = E_Fp`). Потік електронів, що тунелюють з n- у p-область, суворо дорівнює зустрічному потоку електронів з p- у n-область. Сумарний струм у колі дорівнює нулю (`I = 0`).
3. **Прямий зсув: Піковий струм (`0 < V ≤ V_p`):** При прикладанні невеликої прямої напруги рівень Фермі n-області піднімається відносно p-області. Заповнені стани зони провідності n-області опиняються строго навпроти вільних станів валентної зони p-області. Струм тунелювання стрімко зростає і досягає максимального **пікового струму `I_p`** при піковій напрузі `V_p` (типово `V_p ≈ 50–100 mV` для германію та `GaAs`).
4. **Прямий зсув: Від'ємний диференціальний опір (`V_p < V < V_v`):** При подальшому збільшенні прямої напруги зони продовжують зміщуватися, і область енергетичного перекриття заповнених станів n-області з вільними станами p-області починає зменшуватися. Кількість електронів, здатних тунелювати без зміни енергії, падає. В результаті зростання напруги приводить до **зменшення струму**. Виникає ділянка від'ємної диференціальної провідності:
   ```
   G_N = dI / dV < 0  ⇒  R_N = (dI / dV)⁻¹ < 0
   ```
   Струм падає до мінімального значення — **струму впадини `I_v`** при напрузі впадини `V_v` (типово `V_v ≈ 350–500 mV`).
5. **Високий прямий зсув (`V > V_v`):** Енергетичне перекриття зон повністю зникає, і тунельне тунелювання стає фізично неможливим. Напруга на p-n переході стає достатньою для зниження потенціального бар'єра, і через перехід починають інжектуватися класичні носії заряду над бар'єром. Струм визначається експоненціальною дифузійною залежністю, як у звичайному напівпровідниковому діоді.

Головним показником якості ВАХ тунельного діода є відношення пікового струму до струму впадини (PVCR — *Peak-to-Valley Current Ratio*):

```
PVCR = I_p / I_v
```

Для германієвих діодів `PVCR ≈ 6–10`, для діодів з арсеніду галію `GaAs` `PVCR ≈ 15–20`, а для антимоніду галію `GaSb` значення `PVCR` може досягати `30`.

## 3. Резонансно-тунельні діоди (RTD)

Резонансно-тунельний діод (RTD — *Resonant Tunneling Diode*) є квантоворозмірною гетероструктурою, створеною чергуванням тонких шарів напівпровідників із різною шириною забороненої зони (наприклад, `AlGaAs / GaAs / AlGaAs`).

СТруктура складається з вузького шару `GaAs` (квантової ями шириною `3–5 нм`), затиснутого між двома тонкими потенціальними бар'єрами `AlGaAs` (шириною `1.5–2 нм`). Усередині квантової ями внаслідок розмірного квантування виникає дискретний енергетичний рівень `E_1`.

```
Емітер (n-GaAs)  | Бар'єр (AlGaAs) | Квантова яма | Бар'єр (AlGaAs) | Колектор (n-GaAs)
-----------------|-----------------|--------------|-----------------|------------------
                 |  +-----------+  |              |  +-----------+  |
E_F ░░░░░░░░░    |  |           |  | -- E_1 ----  |  |           |  |
-----------------+  |           +--+ (квантований)+--+           +-----------------
                 |  |              |  рівень)    |  |
                 +--+              +-------------+  +--+
```

Електрони з емітера можуть тунелювати крізь подвійний бар'єр у колектор лише тоді, коли їхня енергія суворо збігається з резонансним рівнем `E_1` у ямі (резонансне тунелювання). При зміні напруги зсуву рівень `E_1` зміщується відносно рівня Фермі емітера:
- При `E_F = E_1` спостерігається гострий резонансний пік струму `I_p`.
- Збільшення напруги виводить рівень `E_1` з резонансу, викликаючи стрімке падіння струму до `I_v`.

Завдяки гостроті резонансного тунелювання RTD-діоди мають значення `PVCR > 30` при кімнатній температурі та забезпечують роботу на частотах понад `1 THz`.

## 4. Еквівалентна схема та високочастотний розрахунок

Малосигнальна еквівалентна схема тунельного діода на ділянці від'ємного опору містить чотири основних елементи:

```
               +---[ -R_N ]---+
---[ R_s ]---[ L_s ]---|              |---
               +----[ C_j ]---+
```

- `-R_N` — від'ємний диференціальний опір p-n переходу (`R_N = |dI/dV|⁻¹`).
- `C_j` — бар'єрна ємність p-n переходу (через малу товщину `W` ємність є високою: `1–10 pF`).
- `R_s` — послідовний опір втрат напівпровідникових областей та контактів (`1–5 Ом`).
- `L_s` — паразитна індуктивність корпусу та виводів (`0.1–1 nH`).

Вхідний комплексний імпеданс схеми без урахування `L_s` дорівнює:

```
Z(ω) = R_s + (-R_N) / (1 + i ω R_N C_j) = R_s - R_N / (1 + ω² R_N² C_j²) + i [ (ω R_N² C_j) / (1 + ω² R_N² C_j²) ]
```

Для того щоб прилад міг виконувати роль активного елемента (підсилювача або генератора), дійсна частина імпедансу має бути від'ємною: `Re[Z(ω)] < 0`.

Прирівнюючи `Re[Z(ω)] = 0`, знаходимо **максимальну граничну частоту генерації `f_max`**:

```
f_max = (1 / (2 π R_N C_j)) √( (R_N / R_s) - 1 )
```

Умовою існування від'ємного опору на високих частотах є `R_N > R_s`.

Другою важливою частотою є **авторезонансна частота `f_0`**, на якій реактивна частина імпедансу компенсується паразитною індуктивністю `L_s`:

```
f_0 = (1 / (2 π)) √( 1 / (L_s C_j) - 1 / (R_N² C_j²) )
```

Для стабільної роботи генератора необхідно забезпечити виконання умови `f_max > f_0`.

## 5. Порівняльні параметри та сфери застосування

| Параметр | Звичайний PN-діод (1N4148) | Тунельний діод (3І306) | Резонансно-тунельний діод (RTD) |
|---|---|---|---|
| Механізм провідності | Термічна інжекція над бар'єром | Квантове тунелювання p-n | Резонансне тунелювання в ямі |
| Ширина бар'єра `W` | `100–1000 нм` | `5–10 нм` | `1.5–3 нм` (гетеробар'єр) |
| Відношення струмів `PVCR` | Відсутнє | `6–15` | `20–50` |
| Час носіїв / інерційність | `2–4 нс` (дифузія) | `10–100 пс` (тунелювання) | `0.1–1 пс` (резонанс) |
| Гранична частота `f_max` | `< 500 MHz` | `10–100 GHz` | `0.5–2.5 THz` |
| Сфери застосування | Випрямлення, детектування | НВЧ-генератори, тригери | Терагерцові локатори, тригери |

Тунельні діоди застосовуються у надшвидких імпульсних генераторах з часом наростання фронту менше `30 пс`, генераторах НВЧ та ТГц діапазонів, регенеративних приймачах та елементах багатозначної логіки.
