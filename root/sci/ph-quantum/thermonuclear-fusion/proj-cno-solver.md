# ⚙️ Чисельне моделювання нуклеосинтезу та кінетики CNO-циклу

Ця вставка містить практичну програмну реалізацію чисельного розв'язування жорсткої системи диференціальних рівнянь кінетики реакцій CNO-I циклу мовами C та C++. Програма моделює часову еволюцію ізотопних концентрацій вуглецю, азоту та кисню в зоряному ядрі, обчислює часові масштаби виходу на динамічну рівновагу та визначає підсумкові співвідношення хімічних елементів.

## Фізико-математична модель зоряного нуклеосинтезу

У зоряному ядрі за постійної температури `T` та густини `ρ` зміна молярних концентрацій ізотопів описується системою зв'язаних звичайних диференціальних рівнянь першого порядку. Молярна частка кожного ізотопу визначається як `Y_i = N_i / (ρ · N_A)`, де `N_i` — числова об'ємна концентрація ядер даного сорту, `ρ` — масова густина плазми, а `N_A` — число Авогадро. Завдяки такому нормуванню величина `Y_i` не залежить від стискання чи розширення середовища і змінюється виключно через ядерні перетворення.

Загальне рівняння кінетики для балансу речовини кожного ізотопу має вигляд:

```
dY_i / dt = ∑ (швидкості утворення) - ∑ (швидкості руйнування)
```

Розглянемо шість етапів основного CNO-I циклу:

1. **Реакція `¹²C + p → ¹³N + γ`**. Швидкість радіаційного захоплення протона дорівнює `R₁ = λ₁ · Y(p) · Y(¹²C)`, де питома швидкість реакції `λ₁ = ρ · N_A · ⟨σv⟩₁` виражається у `с⁻¹`.
2. **Бета-розпад `¹³N → ¹³C + e⁺ + νₑ`**. Швидкість позитронного розпаду становить `R₂ = λ₂ · Y(¹³N)`, де константа розпаду `λ₂ = ln(2) / T₁/₂ = 1.159 · 10⁻³ с⁻¹` визначена півперіодом `T₁/₂ = 9.97 хв`.
3. **Реакція `¹³C + p → ¹⁴N + γ`**. Швидкість захоплення протона дорівнює `R₃ = λ₃ · Y(p) · Y(¹³C)`.
4. **Реакція `¹⁴N + p → ¹⁵O + γ` (найповільніший крок)**. Швидкість дорівнює `R₄ = λ₄ · Y(p) · Y(¹⁴N)`. Константа `λ₄` є найменшою серед усіх реакцій циклу.
5. **Бета-розпад `¹⁵O → ¹⁵N + e⁺ + νₑ`**. Швидкість розпаду становить `R₅ = λ₅ · Y(¹⁵O)`, де константа розпаду `λ₅ = ln(2) / T₁/₂ = 5.681 · 10⁻³ с⁻¹` визначена півперіодом `T₁/₂ = 122.2 с`.
6. **Реакція `¹⁵N + p → ¹²C + ⁴He`**. Швидкість утворення гелію й відновлення вуглецю дорівнює `R₆ = λ₆ · Y(p) · Y(¹⁵N)`.

Позначаючи вектором стан системи `Y = [Y(¹²C), Y(¹³N), Y(¹³C), Y(¹⁴N), Y(¹⁵O), Y(¹⁵N)]ᵀ` та вважаючи масову частку водню `Y_p` постійною, отримуємо систему з шести диференціальних рівнянь:

```
dY(¹²C)/dt = λ₆ · Y_p · Y(¹⁵N) - λ₁ · Y_p · Y(¹²C)
dY(¹³N)/dt = λ₁ · Y_p · Y(¹²C) - λ₂ · Y(¹³N)
dY(¹³C)/dt = λ₂ · Y(¹³N) - λ₃ · Y_p · Y(¹³C)
dY(¹⁴N)/dt = λ₃ · Y_p · Y(¹³C) - λ₄ · Y_p · Y(¹⁴N)
dY(¹⁵O)/dt = λ₄ · Y_p · Y(¹⁴N) - λ₅ · Y(¹⁵O)
dY(¹⁵N)/dt = λ₅ · Y(¹⁵O) - λ₆ · Y_p · Y(¹⁵N)
```

## Проблема жорсткості диференціальних рівнянь (Stiffness) та чисельні методи

Система рівнянь CNO-циклу є класичним прикладом **математично жорсткої системи диференціальних рівнянь** (*stiff ODE system*). Жорсткість виникає через велетенську різницю у власних часових масштабах окремих ядерних процесів:

- Швидкі радіоактивні бета-розпади азоту-13 та кисню-15 відбуваються за хвилини (`10² – 10³ секунд`).
- Захоплення протонів вуглецем-12 та азотом-15 відбуваються за години або дні за зоряних температур.
- Найповільніше захоплення протона азотом-14 `¹⁴N(p,γ)¹⁵O` має характерний час перебігу в мільйони секунд і навіть років за температур `15–25 мільйонів кельвінів`.

Співвідношення між найбільшим та найменшим власними значеннями матриці Якобі цієї системи (число жорсткості `S = |Re(λ_max)| / |Re(λ_min)|`) перевищує `10⁵`. Застосування простих явних чисельних методів (як-от явний метод Ейлера) вимагає вибору надзвичайно малого кроку за часом (`dt < 0.1 секунди`), інакше чисельне розв'язання миттєво втрачає стійкість і розганяється до нефізичної нескінченності через зростання похибок заокруглення.

Для збереження високої точності при прийнятному часі обчислень у нашому моделюванні використовується класичний явний метод Рунґе — Кутти 4-го порядку (RK4). Метод RK4 обчислює чотири проміжні оцінки похідних на кожному кроці `dt`, забезпечуючи локальну похибку апроксимації порядку `O(dt⁵)`. У професійних астрофізичних кодах нуклеосинтезу (таких як MESA чи XNet) для розв'язування мереж із сотнями ізотопів застосовуються неявні методи, такі як класична схема Гіра (BDF) або неявні методи Розенброка.

## Детальний розбір чисельного алгоритму RK4

Метод Рунґе — Кутти четвертого порядку обчислює вектор стану `Y_{n+1}` на наступному часовому кроці `t_{n+1} = t_n + dt` за допомогою зваженого усереднення чотирьох коефіцієнтів-оцінок:

1. `k₁ = f(t_n, Y_n)` — значення похідних на початку інтервалу.
2. `k₂ = f(t_n + dt/2, Y_n + (dt/2) · k₁)` — оцінка похідних посередині інтервалу з використанням евольованого стану по `k₁`.
3. `k₃ = f(t_n + dt/2, Y_n + (dt/2) · k₂)` — друга оцінка похідних посередині інтервалу з уточненим станом по `k₂`.
4. `k₄ = f(t_n + dt, Y_n + dt · k₃)` — оцінка похідних наприкінці інтервалу по `k₃`.

Остаточний крок обчислюється як комбінація: `Y_{n+1} = Y_n + (dt / 6) · (k₁ + 2·k₂ + 2·k₃ + k₄)`. Ця схема забезпечує мінімізацію похибки зрізання до п'ятого степеня кроку за часом.

## Порівняльний аналіз програмних архітектур C та C++

Реалізація чисельного алгоритму двома мовами показує ключові відмінності між системними підходами:

1. **Системний підхід мови C**. Процедурна програма на C спирається на пряму роботу з пам'яттю. Конфігурація параметрів передається через структуру `CNOParams`, а вектор стану представлений стандартним масивом `double Y[6]`. Розрахунок похідних виконується функцією `cno_derivatives`, яка приймає вказівники на масиви. Перевагою цього підходу є абсолютна мінімальність накладних витрат, відсутність метаданих класів та прозорість генерації машинного коду для компиляторів системного рівня.

2. **Ідіоматичний об'єктно-орієнтований підхід C++**. Версія мовою C++ інкапсулює логіку в безпечний клас `cno::CNOSolver`. Замість неекранованих C-масивів застосовано статично типізований контейнер `std::array<double, 6>`, що повністю запобігає виходу за межі масиву на етапі компіляції та дозволяє передавати стан системи за значенням і посиланню без виділення пам'яті у купі (`malloc`/`free`). Позначення ізотопів винесено в строго типізований перелік `enum Isotope`, а рядкові назви представлені легковаговими видами `std::string_view`.

Обидва варіанти мають нульові накладні витрати у часі виконання (Zero-Overhead Principle у C++): при оптимізації `-O3` компілятор генератор однаковий високоефективний машинний код із використанням SIMD-інструкцій процесора.

## Детальний аналіз часових фаз нуклеосинтезу

Вихідні дані симуляції дозволяють детально простежити три послідовні фази еволюції зоряної плазми:

### Фаза 1: Первинне вигоряння вуглецю-12 (`t = 0 … 10⁴ с`)
Початковий вуглець-12 захоплює протони середовища і швидко перетворюється на короткоживучий азот-13. Концентрація `¹²C` стрімко знижується від `1.0` до `0.1`. Паралельно спостерігається тимчасовий сплеск концентрації азоту-13, яка сягає максимуму біля `t ≈ 1000 секунд`.

### Фаза 2: Встановлення проміжної бета-рівноваги (`t = 10⁴ … 10⁵ с`)
Бета-розпади азоту-13 та кисню-15 виходять на стаціонарний насичений режим. Оскільки півперіоди їхнього розпаду є малими (`10 хвилин` та `2 хвилини`), їхні молярні частки стабілізуються на низьких рівноважних рівнях (`Y(¹³N) < 0.05`, `Y(¹⁵O) < 0.01`). У цей же час утворюється проміжний вуглець-13, який активно захоплює наступний протон і переходить у азот-14.

### Фаза 3: Вихід на стаціонарне азотне плато (`t > 10⁶ с`)
Оскільки константа швидкості `λ₄` найповільнішої реакції `¹⁴N(p,γ)¹⁵O` дорівнює всього `1.8 · 10⁻⁶ с⁻¹` (майже у `100 разів` менше за швидкість захоплення на вуглеці), вихід речовини з азоту-14 стає принципово заблокованим. Азот-14 неухильно накопичується, акумулюючи в собі ядерний матеріал з усіх інших ізотопів циклу. На момент `t = 10⁷ секунд` частка азоту-14 сягає **понад 94%** від усього сумарного запасу CNO-елементів.

## Крайові випадки та астрофізичні застосування

Програму можна легко адаптувати для розрахунку екстремальних умов у нестаціонарних астрофізичних об'єктах:

1. **Гарячий CNO-цикл у спалахах Нових зір**. При підвищенні температури до `T > 10⁸ K` швидкості протонних захоплень `λ₁`, `λ₃`, `λ₄` зростають на кілька порядків і перевищують константи бета-розпаду `λ₂` та `λ₅`. У програмі це відповідає зміні співвідношення між коефіцієнтами: обмежувальною ланкою стають не протонні захоплення, а бета-розпади кисню-14 та кисню-15.
2. **Первинні зорі без металів (Population III)**. У перших зорях Всесвіту, які складалися виключно з первинного водню й гелію, масова частка `X_CNO = 0`. Система рівнянь CNO дає тотожний нуль енерговиділення, змушуючи зорю стискатися до тих пір, поки температура в центрі не сягне `10⁸ K`, запустивши потрійну альфа-реакцію синтезу першого вуглецю.

Чисельне моделювання повністю підтверджує аналітичні висновки: стаціонарний CNO-цикл неминуче перетворює вуглецево-кисневу суміш зоряного ядра на чистий азот-14, що точно збігається зі спостереженнями спектрів червоних гігантів.
